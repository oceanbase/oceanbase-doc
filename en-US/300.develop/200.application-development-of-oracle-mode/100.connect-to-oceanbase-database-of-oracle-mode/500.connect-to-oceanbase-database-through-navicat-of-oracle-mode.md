# Connect to OceanBase Database in Oracle mode by using Navicat

Navicat is a powerful database management tool that supports connecting to various databases, including OceanBase Database in Oracle mode. This topic describes how to use Navicat to connect to OceanBase Database in Oracle mode.

<main id="notice" type="explain">
    <h4>Note</h4>
    <p>This topic describes how to connect to OceanBase Database in Oracle mode by using Navicat through the Oracle protocol. </p>
</main>

## Compatibility

* Navicat Premium 16.1.9 or later supports OceanBase Database Enterprise Edition in Oracle mode V3 or later.
* Navicat for Oracle 16.1.9 or later supports OceanBase Database Enterprise Edition in Oracle mode V3 or later.

<main id="notice" type="notice">
    <h4>Notice</h4>
    <p>The macOS version of Navicat does not support OceanBase Database in Oracle mode. </p>
</main>

## Prerequisites

* You have installed Navicat Premium 16.1.9 or later or Navicat for Oracle 16.1.9 or later.
* You have obtained the connection information of OceanBase Database, including:
  * The IP address and port number of the database server
  * The tenant name
  * The username and password

## Download the OceanBase JDBC driver

1. Go to the [OceanBase software download center](https://www.oceanbase.com/softwarecenter-enterprise) and download OceanBase Connector/J from the **Drivers and Middleware** section.

2. Save the JAR file to a local directory, for example, `/path/to/oceanbase-client.jar`.

## Configure the Navicat connection

1. Start Navicat and choose **File** > **New Connection** > **Oracle**.

2. On the connection settings page, specify the following parameters:

   | Parameter | Description | Example value |
   |------|------|--------|
   | Host | The IP address of the OceanBase server. | 127.0.0.1 |
   | Port | The port number of the database. The default value is 2881. | 2881 |
   | Username | The username of the database. | user@tenant |
   | Password | The password of the database. | ******** |

3. Go to the **Advanced** tab.
   * In the **OCI Library** section, select **Use OCI**.
   * In the **OCI Library Path** field, select the `oci.dll` file for Windows or the `libclntsh.dylib` file for macOS.

4. Go to the **Driver** tab.
   * Select **Use Custom JDBC Driver**.
   * Click **Add** and select the OceanBase JDBC driver JAR file that you downloaded.
   * In the **Class Name** field, enter `com.alipay.oceanbase.jdbc.Driver`.
   * In the **URL Template** field, enter `jdbc:oceanbase://{host}:{port}/{database}`.

5. Click **Test Connection** to verify the connection.

## Manage OceanBase Database by using Navicat

After the connection is established, you can use the graphical interface of Navicat to perform the following operations:

* Browse database objects (tables, views, stored procedures, and so on)
* Execute SQL queries
* Import and export data
* Manage database users and permissions
* Monitor database performance
