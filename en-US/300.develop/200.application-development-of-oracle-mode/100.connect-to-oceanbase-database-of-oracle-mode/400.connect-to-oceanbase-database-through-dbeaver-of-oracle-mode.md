# Connect to OceanBase Database using DBeaver (Oracle-compatible mode)

DBeaver is a universal database management tool that supports connecting to various databases, including OceanBase Database's Oracle-compatible mode. This topic describes how to connect to OceanBase Database in Oracle-compatible mode using DBeaver.

<main id="notice" type="explain">
    <h4>Note</h4>
    <p>This topic uses the Generic mode with the OceanBase driver. This setup has some limitations, such as the inability to modify field information on the interface.</p>
</main>

## Prerequisites

* You have installed DBeaver Community or Enterprise edition (we recommend using the latest version).
* You have obtained the connection information for OceanBase Database, including:
  * Database server address and port
  * Tenant name
  * Username and password

## Download the OceanBase JDBC driver

1. Visit the [OceanBase Download Center](https://en.oceanbase.com/softwarecenter-cloud) and download the OceanBase JDBC driver (OceanBase Connector/J).

2. Save the downloaded JAR file to a local directory, for example: `/path/to/oceanbase-client.jar`

## Create a new driver

1. Open DBeaver and click **Database** > **Driver Manager**.

2. Click the **New** button to create a new driver.

3. On the **Libraries** tab:
   * Click **Add Folder** and select the downloaded OceanBase JDBC driver JAR file
   * Click **OK** to save the driver configuration

## Create a new connection

1. Click **Database** > **New Database Connection**.
2. In the database selection interface, select the **OceanBase Oracle** driver and click **Next**.
3. On the connection settings page, fill in the following information:

   | Parameter | Description | Example Value |
   |------|------|--------|
   | Host | OceanBase server address | 127.0.0.1 |
   | Port | Database port (default 2881) | 2881 |
   | Username | Database username | user@tenant |
   | Password | Database password | ******** |

4. Click the **Test Connection** button to verify the connection

## Manage OceanBase Database using DBeaver

After a successful connection, you can use DBeaver's graphical interface to perform the following operations:

* Browse database objects (tables, views, stored procedures, etc.)
* Execute SQL queries
* Import/export data
* Manage database users and permissions
* Monitor database performance
