# Prepare installation packages

Before you deploy OceanBase Database, make sure that you have obtained the images and installation packages of OceanBase Database and the accompanying tools, drivers, and middleware for future installation and deployment.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Download the installation packages of OceanBase Database, the accompanying tools, drivers, and middleware from <a href="https://www.oceanbase.com/softwarecenter-enterprise">OceanBase Download Center</a>. If you cannot find the packages of the corresponding version, contact OceanBase Technical Support.</p>
</main>

**The following table lists the images and installation packages required for deploying an OceanBase cluster:**

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>When you use the CLI to deploy an OceanBase cluster, you do not need to prepare the images or installation packages of OceanBase Cloud Platform.</p>
</main>
