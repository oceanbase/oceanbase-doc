# Install OceanBase Desktop

This topic describes how to install OceanBase Desktop on Windows and macOS operating systems.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>OceanBase Desktop is intended for learning or testing purposes only. Please do not use it in production environments.</p>
</main>

## Background information

OceanBase Desktop is a desktop application designed for managing and operating OceanBase databases. It provides a graphical interface that allows users to easily perform tasks such as database management, query execution, and data import/export.

OceanBase Desktop has the following features:

* **Graphical interface**: An intuitive and user-friendly graphical interface that simplifies database management tasks.

* **Database management**: Supports the creation and management of database instances.

* **Query execution**: Provides an SQL command line for executing queries.

* **Monitoring and logs**: Offers real-time monitoring of database status.

tab Windows operating system

### Prerequisites

Before proceeding with the instructions below, ensure that your machine is running the Windows (x86-64 architecture) operating system.

### Procedure

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This topic uses Windows 11 Pro 24H2 (build 26100.4349) as an example. The procedure may vary slightly depending on the version of your operating system.</p>
</main>

#### Step 1: Install dependencies

To install OceanBase Desktop on a Windows operating system, you need to install Windows Subsystem for Linux (WSL). WSL is a feature released by Microsoft in 2016 for Windows 10. It allows you to run ELF-format Linux executable files on the Windows operating system.

Currently, two generations of WSL are available: WSL 1 and WSL 2. WSL 1 provides a Linux compatibility layer that translates Linux system calls into Windows NT system calls. WSL 2, on the other hand, leverages Windows Hyper-V functionality to run Linux virtual machines through virtualization technology, providing a more native Linux experience.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>WSL 2 is not an upgraded version of WSL 1. Therefore, you do not need to install WSL 1 before installing WSL 2. OceanBase Desktop images can only be used with WSL 2.</p>
</main>

1. Check your Windows version.

   WSL requires **Windows 10 Professional Version 1709** or **Windows 10 Home Version 1803 or later**. WSL 2 requires Windows 10 Version 1903 (build 18362) or a later version (x64). If your version is earlier, update your Windows 10 system.

   You can check the Windows version by pressing Win+Q on your keyboard, searching for **Settings**, and clicking to open it. On the **Settings** page, choose **System** > **About** to view the Windows version.

   ![Version](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/OceanBase-Database-EN/1.about.png)

2. Check if virtualization is enabled.

   Press Ctrl+Alt+Delete on your keyboard to open **Task Manager**. On the **<UI-TERM key="src.component.ODCSetting.config.353C6B46">Performance</UI-TERM>** tab, check the **CPU** section. As shown in the figure below, if virtualization is enabled, **Virtualization** is displayed as **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.Enabled.1">Enabled</UI-TERM>**. If **Virtualization** is displayed as **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Disabled">Disabled</UI-TERM>**, you need to enable the virtualization feature in the BIOS. The steps to access and enable virtualization in BIOS vary depending on your computer model, so you can search for the instructions for your specific model online.

   ![Virtualization](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/OceanBase-Database-EN/2.virtualization.png)

3. Enable the WSL and virtual machine platform features.

   There are two methods to enable the WSL and virtual machine platform features. Choose the method based on your needs.

   * Method 1: Enable the features using command lines

     Press the Win+Q keys on your keyboard, search for **powershell** or **Windows Powershell**, click **Run as Administrator**, and enter the following commands in the opened command line. After both commands are executed successfully, restart your computer.

     ```shell
     # Enable the WSL feature
     dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

     # Enable the virtual machine platform feature
     dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
     ```

   * Method 2: Enable the features using the graphical interface

     Press Win+Q on your keyboard, search for **Turn Windows features on or off**, and click the result to open it. Scroll down to find and select **Windows Subsystem for Linux** and **Virtual Machine Platform**. Click **<UI-TERM key="ocp-v2.page.AuditEvent.Determine">OK</UI-TERM>** and restart the computer.

     ![Configuration](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/OceanBase-Database-EN/3.config.png)

4. Install the WSL 2 kernel component.

   There are two methods to install the WSL 2 kernel component. Choose the method based on your needs.

   * Method 1: Download and install the installation package

     Select [wsl_update_x64.msi](https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi) or [wsl_update_arm64.msi](https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_arm64.msi) based on your processor architecture. Run the installation package you downloaded and click **Next** to install it.

   * Method 2: Install it using command lines

     Press Win+R to open cmd, or press Win+Q, search for and open **powershell** or **Windows Powershell** (you can use a regular user or run as Administrator). Enter the following command in the command line window:

     ```shell
     wsl --update
     ```

5. Set WSL 2 as the default version.

   Enter the following command in the cmd or powershell window:

   ```shell
   wsl --set-default-version 2
   ```

6. Verify the installation.

   Enter the following command in the cmd or powershell window. If `VERSION` is displayed as `2` in the output, WSL 2 is installed.

   ```shell
   wsl --list --verbose
   ```

#### Step 2: Install OceanBase Desktop

1. Obtain the installation package.

   Go to [OceanBase Download Center](https://en.oceanbase.com/softwarecenter), search for **OceanBase Desktop**, and click **Windows** to download the installation package.

2. Install the application and start OceanBase Desktop.

   Double-click the installation package to install OceanBase Desktop. After installation, an OceanBase database instance in the `STOPPED` state is automatically deployed. You can click `START` on the graphical interface to start the OceanBase database.

#### Step 3: Connect to OceanBase Desktop

Press **Win+R** on your keyboard to open **cmd**, or press **Win+Q**, search for and open **powershell** or **Windows Powershell**. Execute the following command in the command line to connect to the launched OceanBase Desktop.

```shell
wsl.exe -d oceanbase-desktop --exec obclient -h127.0.0.1 -P2881 -uroot@test -Doceanbase -A
```

### Prerequisites

### Procedure

<main id="notice" type='explain'>

#### Step 1: Install the dependency

To install OceanBase Desktop on macOS, you need to install OrbStack first. OrbStack is a modern container and virtual machine management tool designed for macOS users. It provides efficient container operation (such as Docker containers) and lightweight virtual machine support. OrbStack aims to replace Docker Desktop and other cumbersome virtualization tools, significantly improve performance, save system resources, and simplify the user experience for developers.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The official OrbStack documentation provides two installation methods: downloading the installation package or executing the brew command. This section uses the installation package method as an example. For other methods, please refer to the <a href="https://docs.orbstack.dev/quick-start">official documentation</a>.</p>
</main>

1. Download the installation package.

   You can download the installation package from the [official website](https://orbstack.dev/download). Two installation packages are provided for macOS, one for Apple Silicon chips and one for Intel chips. To view the type of chip in your computer, click the Apple icon in the top left corner of the screen and select **About This Mac**.

   ![Processor](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/OceanBase-Database-EN/4.mac.jpg)

2. Install OrbStack.

   Double-click the corresponding dmg installation package and drag the icon to the **Applications** folder.

   <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>If this is your first installation, we recommend that you complete the initial OrbStack boot process. Otherwise, you cannot import the image normally.</p>
   </main>

   ![Installation](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.deploy-oceanbase-desktop/800.deploy-oceanbase-desktop-06.png)

3. Verify the installation.

   Go to the **Machines (Virtual Machines)** section and install the latest Ubuntu image. This process may take some time, so please be patient.

   ![ubuntu](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.deploy-oceanbase-desktop/800.deploy-oceanbase-desktop-07.png)

   After the installation is complete, double-click the corresponding virtual machine. If you can access the command-line interface, OrbStack is installed successfully.

   ![Verification](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.deploy-oceanbase-desktop/800.deploy-oceanbase-desktop-08.png)

#### Step 2: Install OceanBase Desktop

1. Obtain the installation package from the Technical Support.

   <!-- Go to [OceanBase Download Center](https://en.oceanbase.com/softwarecenter) and search for **OceanBase Desktop**. Click **Mac** to download the installation package. -->

2. Install and start OceanBase Desktop.

   Double-click the installation package and drag the icon to the **Applications** folder to install OceanBase Desktop. After OceanBase Database is installed in the stop state, click `start` in the graphical interface to start OceanBase Database.

   If you encounter an issue with a damaged file, it is because OceanBase Desktop is not yet registered as an Apple Developer. You can resolve this issue by running the following commands:

   ```shell
   # Remove the application isolation attribute
   > sudo xattr -rd com.apple.quarantine /Applications/OceanBase-Desktop.app

   # Allow running unverified applications (temporarily)
   > sudo spctl --master-disable
   ```

#### Step 3: Connect to OceanBase Desktop

Run the following command in the command line to connect to OceanBase Desktop.

```shell
mysql -h127.0.0.1 -P2881 -uroot@test -Doceanbase -A
```
