# Use OMS to migrate data from a MySQL-compatible tenant of OceanBase Database to a DB2 LUW database

This topic briefly describes the background information for using OceanBase Migration Service (OMS) to migrate data from a MySQL-compatible tenant of OceanBase Database to a DB2 LUW database.

## Background information

You can create a data migration project in the OMS console to migrate data from a MySQL-compatible tenant of OceanBase Database to a DB2 LUW database through schema migration, full migration, and incremental synchronization.

## References

For more information about how to use OMS to migrate data from a MySQL-compatible tenant of OceanBase Database to a DB2 LUW database, see [Migrate data from a MySQL-compatible tenant of OceanBase Database to a DB2 LUW database](https://docs.oceanbase.com/oms/V4.0.2-create-a-project-to-migrate-data-from-a-mysql-tenant-of-oceanbase-database-to-a-db2-luw-database).
