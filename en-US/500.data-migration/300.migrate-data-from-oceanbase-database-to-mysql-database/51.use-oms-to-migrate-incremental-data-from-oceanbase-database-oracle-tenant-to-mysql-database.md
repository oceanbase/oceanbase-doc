# Use OMS to migrate incremental data from an Oracle-compatible tenant of OceanBase Database to a MySQL database

This topic briefly describes the background information for using OceanBase Migration Service (OMS) to migrate incremental data from an Oracle-compatible tenant of OceanBase Database to a MySQL database.

## Background information

After you create a data migration project that migrates data from an Oracle-compatible tenant of OceanBase Database to a MySQL database in the OMS console, you can use incremental synchronization to migrate incremental data from the source Oracle-compatible tenant of OceanBase Database to the MySQL database.

## References

For more information about how to use OMS to migrate incremental data from an Oracle-compatible tenant of OceanBase Database to a MySQL database, see [Migrate incremental data from an Oracle-compatible tenant of OceanBase Database to a MySQL database](https://docs.oceanbase.com/oms/V4.2.3-create-a-project-to-migrate-data-from-an-oracle-tenant-of-oceanbase-database-to-a-mysql-database).
