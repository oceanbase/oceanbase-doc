# Use OMS to migrate data from a DB2 LUW database to an Oracle-compatible tenant of OceanBase Database

This topic briefly describes the background information for using OceanBase Migration Service (OMS) to migrate data from a DB2 LUW database to an Oracle-compatible tenant of OceanBase Database. 

## Background information

You can create a data migration project in the OMS console to migrate data from a DB2 LUW database to an Oracle-compatible tenant of OceanBase Database through schema migration, full migration, and incremental synchronization. 

## References

For more information about how to use OMS to migrate data from a DB2 LUW database to an Oracle-compatible tenant of OceanBase Database, see [Migrate data from a DB2 LUW database to an Oracle-compatible tenant of OceanBase Database](https://docs.oceanbase.com/oms/V4.0.2-create-a-project-to-migrate-data-from-a-db2-luw-database-to-an-oracle-tenant-of-oceanbase-database).
