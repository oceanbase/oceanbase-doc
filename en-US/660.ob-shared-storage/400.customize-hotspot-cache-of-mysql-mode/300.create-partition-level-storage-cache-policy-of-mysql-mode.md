# Create a partition-level hot cache strategy

This topic describes how to create a partition-level hot cache strategy (`STORAGE_CACHE_POLICY`) by using SQL statements.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Starting from OceanBase Database V4.4.1, you can specify a partition-level hot cache strategy when you create a table in shared storage mode.</p>
</main>

## Considerations

You can specify a partition-level hot cache strategy only in shared storage mode when you create a table.

## Syntax

When you create a partitioned table, you can specify a partition-level hot cache strategy for a partition or a subpartition. To specify a partition-level hot cache strategy for a partition, you must add the `STORAGE_CACHE_POLICY` clause to the partition. The syntax is as follows:

```sql
CREATE TABLE table_name (table_definition_list)
    partition_option
        (partition_list [STORAGE_CACHE_POLICY = {"hot" | "auto" | "none"}])
    subpartition_option
        (subpartition_list [STORAGE_CACHE_POLICY = {"hot" | "auto" | "none"}]);
```

### Parameters

The `STORAGE_CACHE_POLICY` clause specifies the partition-level hot cache strategy. Valid values: `hot`, `auto`, and `none`. The default value is `none`.

* `hot`: specifies that all data in the partition is hot data. If the cache disk space is sufficient, all data in the partition will be cached to the local cache disk.
* `auto`: specifies that the system automatically identifies the hot data in the partition.
* `none`: specifies that the hot cache strategy of the partition follows the `STORAGE_CACHE_POLICY` value of the parent partition. This value is the default value.

For more information about how to create a partitioned table, see [Create a partitioned table](../300.manage-partitions-of-mysql-mode/200.create-a-partition-table-of-mysql-mode.md).

## Examples

* Specify the `STORAGE_CACHE_POLICY` value for a partition when you create a partitioned table.

    ```sql
    CREATE TABLE tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY RANGE(col1)
        SUBPARTITION BY KEY(col2, col3) SUBPARTITIONS 5
            (PARTITION p0 VALUES LESS THAN(0) STORAGE_CACHE_POLICY = "hot",
             PARTITION p1 VALUES LESS THAN(100) STORAGE_CACHE_POLICY = "auto"
            );
    ```

* Specify the `STORAGE_CACHE_POLICY` value for a subpartition when you create a partitioned table.

    ```sql
    CREATE TABLE tbl2 (col1 INT, col2 INT)
        PARTITION BY RANGE(col1)
        SUBPARTITION BY RANGE(col2)
            (PARTITION p0 VALUES LESS THAN(100)
                (SUBPARTITION sp0 VALUES LESS THAN(2020) STORAGE_CACHE_POLICY = "hot",
                 SUBPARTITION sp1 VALUES LESS THAN(2021)),
            PARTITION p1 VALUES LESS THAN(200)
                (SUBPARTITION sp2 VALUES LESS THAN(2020),
                 SUBPARTITION sp3 VALUES LESS THAN(2021) STORAGE_CACHE_POLICY = "hot",
                 SUBPARTITION sp4 VALUES LESS THAN(2022))
            );
    ```
