# Maintain a custom hot cache strategy

This topic describes how to control the execution of background tasks for a custom hot cache strategy by using SQL statements, including how to pause, resume, and manually trigger the tasks.

## Pause or resume background cache tasks

OceanBase Database provides the `suspend_storage_cache_task` parameter to specify whether to pause background cache tasks. Valid values: 

* `True`: Pauses (suspends) all ongoing and newly initiated cache tasks.
* `False`: Does not pause background cache tasks, which resumes suspended cache tasks.

For more information about this parameter, see [suspend_storage_cache_task](../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/8070.suspend_storage_cache_task.md).

### Examples

* Execute the following command to suspend all hot cache tasks in the tenant.

    ```shell
    obclient> ALTER SYSTEM SET suspend_storage_cache_task = true;
    ```

* Execute the following command to resume all suspended hot cache tasks in the tenant.

    ```shell
    obclient> ALTER SYSTEM SET suspend_storage_cache_task = false;
    ```

## Manually trigger a hot data cache task

After a custom hot cache strategy is enabled, you can execute the following SQL statement to manually trigger a hot data cache task:

```sql
ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```

### Examples

Execute the following command to manually trigger a hot cache task.

```shell
obclient> ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```
