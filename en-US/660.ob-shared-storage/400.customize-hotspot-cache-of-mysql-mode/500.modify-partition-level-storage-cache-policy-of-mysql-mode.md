# Modify the partition-level hotspot cache strategy

This topic describes how to use SQL statements to modify the partition-level hotspot cache strategy (`STORAGE_CACHE_POLICY`).

## Considerations

You can modify the partition-level hotspot cache strategy only in shared storage mode.

## Modify the partition-level hotspot cache strategy

After you create a partitioned table, you can use the `ALTER TABLE` statement to specify the `STORAGE_CACHE_POLICY` when you add partitions to the table or to modify the `STORAGE_CACHE_POLICY` of an existing partition. Syntax:

* Specify the `STORAGE_CACHE_POLICY` when you add a partition:

    ```sql
    ALTER TABLE table_name
        ADD PARTITION (partition_list [STORAGE_CACHE_POLICY = {"hot" | "auto" | "none"}]);
    ```

* Modify the `STORAGE_CACHE_POLICY` of an existing partition:

    ```sql
    ALTER TABLE table_name
        ALTER PARTITION (partition_list [STORAGE_CACHE_POLICY = {"hot" | "auto" | "none"}]);
    ```

### Parameters

The `STORAGE_CACHE_POLICY` at the partition level is optional. Valid values:

* `hot`: indicates that all data in the specified partition is hot data. If the local cache disk space is sufficient, all data in the partition will be cached to the local cache disk.
* `auto`: indicates that the hot data in the specified partition is automatically identified by the system.
* `none`: the default value. Indicates that the hotspot cache strategy of the partition follows the value of the `STORAGE_CACHE_POLICY` at the upper level.

For more information about how to modify a partitioned table, see [Add a partition](../300.manage-partitions-of-mysql-mode/400.add-a-partition-of-mysql-mode.md) and [Modify a partition rule](../300.manage-partitions-of-mysql-mode/300.modify-partition-rules-of-mysql-mode.md).

## Examples

* Add a partition `p2` to the `tbl1` table. The hot data in the `p2` partition is automatically identified by the system.

    ```sql
    ALTER TABLE tbl1 ADD PARTITION (PARTITION p2 VALUES LESS THAN(300) STORAGE_CACHE_POLICY = "auto");
    ```

* Modify the data in the `p1` partition of the `tbl1` table to hot data.

    ```sql
    ALTER TABLE tbl1 ALTER PARTITION p1 STORAGE_CACHE_POLICY = "hot";
    ```

* Modify the data in the `sp3` subpartition of the `tbl2` table to hot data, which is automatically identified by the system.

    ```sql
    ALTER TABLE tbl2 ALTER SUBPARTITION sp3 STORAGE_CACHE_POLICY = "auto";
    ```
