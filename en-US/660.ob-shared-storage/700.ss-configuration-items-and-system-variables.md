# Overview of shared storage configuration items and system variables

## Configuration items

### Cluster level

#### Arbitration service-related

| Configuration item | Description |
|---------|---------|
| [ob_startup_mode](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/16400.ob_startup_mode.md) | Sets the startup mode of the OBServer node. This parameter can be modified only during the first startup. |

#### Memory space-related

| Configuration item | Description |
|---------|---------|
| [datafile_size](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/4700.datafile_size.md) | Sets the size of the local cache space. |
| [datafile_next](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/4600.datafile_next.md) | In shared storage mode, the value of this parameter is meaningless. You can modify it, but the modification will not take effect. |
| [datafile_disk_percentage](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/4400.datafile_disk_percentage.md) | Sets the percentage of available local disk space to the total disk space. |

### Tenant level

#### Cache-related

| Configuration item | Description |
|---------|---------|
| [default_storage_cache_policy](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2120.default_storage_cache_policy.md) | Configures the default cache strategy. This is the default value of the `storage_cache_policy` parameter at the tenant level. It only takes effect for newly created tables. |
| [enable_manual_storage_cache_policy](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2650.enable_manual_storage_cache_policy.md) | Enables the user-specified hot cache strategy. |
| [suspend_storage_cache_task](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/8070.suspend_storage_cache_task.md) | Sets whether to suspend the background cache task. |

#### Shared log-related

| Configuration item | Description |
|---------|---------|
| [shared_log_retention](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7430.shared_log_retention.md) | Sets the retention period of shared log files in shared storage mode. |

#### Background execution thread-related

| Configuration item | Description |
|---------|---------|
| attach_shared_sstable_thread_score | Configures the number of threads available for the tenant to execute shared data reference tasks in shared storage mode. |
| inc_sstable_upload_thread_score | Configures the number of threads available for the tenant to execute data sharing tasks in shared storage mode. |
