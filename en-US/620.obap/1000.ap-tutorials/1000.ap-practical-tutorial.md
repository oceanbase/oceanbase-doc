# AP tutorial

## Build a real-time data warehouse based on Flink and OceanBase

**Objective**: This tutorial demonstrates how to build a real-time data warehouse by integrating OceanBase's HTAP capabilities with Flink's unified stream and batch processing features. It covers the process of data layering from the original data layer (ODS) to the detailed data layer (DWD) and finally to the application data layer (ADS). It also includes the setup of a visualization dashboard using compatible ecosystem tools.

For detailed steps, see [Build a real-time data warehouse and visualization dashboard based on OceanBase](../../690.practical-tutorial/300.dw_based_on_ob.md).

## Process and analyze massive data in OceanBase with Spark

**Objective**: This tutorial demonstrates how to leverage OceanBase's strong consistency and distributed query capabilities, combined with Spark's distributed computing framework and OceanBase's high scalability, to achieve optimal data processing speed and system responsiveness.

For detailed steps, see [Process and analyze massive data in OceanBase with Spark](../../690.practical-tutorial/700.rapidly-analyze-data-by-spark.md).
