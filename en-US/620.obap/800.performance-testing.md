# Performance test

OceanBase Database is a high-performance distributed relational database. You can use the Sysbench and TPC-H benchmarks to verify its performance in the AP scenario. This topic describes the performance test results from two aspects:

## OceanBase Database Sysbench benchmark

The Sysbench benchmark tests the throughput (QPS) and latency of OceanBase Database in high-concurrency transaction scenarios. It also compares the performance of OceanBase Database with that of traditional single-node databases, such as MySQL.

- [Analyze performance issues in OceanBase Database Sysbench benchmark](../700.reference/1100.performance-test/200.sysbench-benchmark-testing-on-oceanbase-database/400.oceanbase-sysbench-performance-issue-analysis.md)

## OceanBase Database TPC-H benchmark

TPC-H is a standard benchmark for business intelligence (BI) applications. It contains 22 complex queries covering scenarios such as aggregation, join, and sorting. The key metrics include:

- QphH@size: the number of queries processed per hour (QphH) divided by the data size (size, in GB).
- Response time: the time taken for each query to return results after it is submitted.
