# Data synchronization

Data synchronization means that a migration or synchronization tool **continuously reads upstream changes** and **writes the results to the target OceanBase database** (or another downstream), so that the target stays consistent with the source database within a latency that the business can tolerate. Compared with one-time migration, it places more emphasis on long-running links, latency monitoring, and replay consistency.

In the OceanBase ecosystem, **OMS (OceanBase Migration Service)** is one of the main solutions for migrating relational source databases to OceanBase. It usually covers **schema + full data + incremental data** and supports switchover orchestration.
