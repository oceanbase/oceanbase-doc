# Import data via direct load using the CREATE TABLE AS SELECT statement

This topic describes how to use **`CREATE TABLE AS SELECT` (CTAS)** to write query results into a new table while creating it, and how to combine it with the **direct load** hint and [default_load_mode](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2050.default_load_mode.md).

Data sources can be **internal tables, external tables, or SELECT statements with `FILES(...)`**.

## Direct load modes (full/incremental)

The `CREATE TABLE AS SELECT` statement specifies the direct load mode by using the `DIRECT()` hint. If this hint is not specified, the default behavior can be controlled by the [default_load_mode](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2050.default_load_mode.md) parameter.

### Syntax

```sql
CREATE /*+ [APPEND | DIRECT(need_sort,max_error,{'full'|'inc'|'inc_replace'})] parallel(N) */ TABLE table_name [AS] select_sentence
```

For more information about the `CREATE TABLE AS SELECT` syntax, see [CREATE TABLE (MySQL-compatible mode)](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2600.create-table-of-mysql-mode.md) and [CREATE TABLE (Oracle-compatible mode)](../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/2400.create-table-of-oracle-mode.md).

**Parameter description:**

| Parameter | Description |
| ------ | ------ |
| APPEND \ | DIRECT() | Use hints to enable the direct load feature. <ul><li>The <code>APPEND</code> hint is equivalent to using <code>DIRECT(true, 0)</code> by default and also enables online statistics collection (<code>GATHER_OPTIMIZER_STATISTICS</code> hint).</li><li>The parameters of <code>DIRECT()</code> are described as follows:<ul><li><code>need_sort</code>: Indicates whether the data to be written requires sorting. The value is of type <code>bool</code>:<ul><li><code>true</code>: Sorting is required.</li><li><code>false</code>: Sorting is not required.</li></ul></li><li><code>max_error</code>: The maximum number of erroneous rows allowed. The value is of type <code>INT</code>. If this value is exceeded, the import task will fail.</li><li><code>full</code>: Indicates full direct load.</li><li><code>inc\ | inc_replace</code>: Indicates the two modes of incremental direct load. <ul><li><code>inc</code>: Indicates incremental import. It checks for duplicate primary keys and supports the <code>INSERT</code> and <code>IGNORE</code> semantics.</li><li><code>inc_replace</code>: Indicates incremental import without checking for duplicate primary keys, equivalent to an incremental import with the <code>REPLACE</code> semantics.</li></ul></li></ul></li></ul><main id="notice" type='notice'><h4>Notice</h4><p>When <code>load_mode</code> is set to <code>inc_replace</code>, the <code>CREATE TABLE AS SELECT</code> statement must not contain the <code>REPLACE</code> or <code>IGNORE</code> keywords.</p></main> |
| parallel(N) | The degree of parallelism for loading data. This parameter is required and must be an integer greater than 1. |

### Examples

:::tab
tab MySQL-compatible mode

Use direct load to import data from table `tbl1` into other tables.

1. Create table `tbl1` and write test data into it.

   ```shell
   obclient [test]> CREATE TABLE tbl1(c1 int);
   obclient [test]> INSERT INTO tbl1 VALUES (1),(2),(3);
   obclient [test]> SELECT * FROM tbl1;
   ```

2. Use `CREATE TABLE AS SELECT` to import data into `tbl2`.

   * Full mode:

     ```shell
     obclient [test]> CREATE /*+ direct(true, 0, 'full') parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     ```

   * Incremental mode:

     ```shell
     obclient [test]> CREATE /*+ direct(true, 0, 'inc') parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     obclient [test]> CREATE /*+ direct(true, 0, 'inc_replace') parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     ```

   * Optional: Use `APPEND` (equivalent to `DIRECT(true, 0)`):

     ```shell
     obclient [test]> CREATE /*+ append parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     ```

3. If no hint is specified, you can control the default mode by using the configuration item:

   ```shell
   obclient [test]> ALTER SYSTEM SET default_load_mode ='FULL_DIRECT_WRITE';
   obclient [test]> CREATE TABLE tbl2 AS SELECT * FROM tbl1;
   ```

   or:

   ```shell
   obclient [test]> ALTER SYSTEM SET default_load_mode ='INC_DIRECT_WRITE';
   obclient [test]> CREATE TABLE tbl2 AS SELECT * FROM tbl1;
   ```
