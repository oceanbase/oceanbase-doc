# Overview

This topic describes how to import data from an external data source to OceanBase Database.

OceanBase Database provides flexible data import methods to import data from various data sources. Different import methods are suitable for different scenarios. You can select an appropriate data import tool based on the data source type and business scenario. As scenarios become more complex, multiple import methods can be used together. When importing data, you need to consider the data source, data file format, and the supported data import tools. If the data source and data file format are already determined, you can design the data import solution based on the data source and supported data import tools. If you have a preferred data import tool, you can design the data import solution based on the supported data import tools and business scenario. This topic describes the data import solutions from the perspectives of data source types and data import tools.
