# View resource pools

After resource pools are created successfully, you can view the resource pools in the cluster and the distribution of each resource pool.

## Procedure

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Execute the following statement to view resource pool information in the cluster:

   ```sql
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS\G

   RESOURCE_POOL_ID: 1
               NAME: sys_pool
          TENANT_ID: 1

        MODIFY_TIME: 2022-11-15 14:26:23.044325
         UNIT_COUNT: 1
     UNIT_CONFIG_ID: 1
          ZONE_LIST: zone1
       REPLICA_TYPE: FULL
   *************************** 2. row ***************************
   RESOURCE_POOL_ID: 1001
               NAME: pool_mysql001_zone1_bmg

          ZONE_LIST: zone1
       REPLICA_TYPE: FULL
   5 rows in set
   ```

   The fields are described as follows:

   * `RESOURCE_POOL_ID`: the resource pool ID. Each resource pool has one resource pool ID.

   * `TENANT_ID`: the tenant ID to which the resource pool belongs. Each tenant has one tenant ID. The tenant ID of the `sys` tenant is `1`. For instructions on viewing detailed information about the current tenant, see [View tenant and resource information](../400.view-tenant-information.md).

      If the value of `TENANT_ID` is `NULL` in the query result, the resource pool is not bound to any tenant. You can allocate the resource pool to a tenant. For instructions on allocating a resource pool to a tenant, see [Allocate a resource pool to a tenant](../1500.resource-pool-management/200.assign-a-resource-pool-to-a-tenant.md).

   * `UNIT_COUNT`: the number of resource units in the resource pool.

   * `UNIT_CONFIG_ID`: the resource unit specification ID of the resource pool. Each resource unit has one resource unit specification ID.

      For instructions on viewing resource unit specifications (resource unit configurations), see [View resource unit configurations](../1600.resource-specification-management/100.view-resource-unit-configuration.md).

   * `ZONE_LIST`: the zone list of the resource pool, indicating in which zones the resources of the resource pool are used.
