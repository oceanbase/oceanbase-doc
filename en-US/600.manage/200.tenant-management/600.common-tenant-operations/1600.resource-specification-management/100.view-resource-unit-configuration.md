# Query resource specifications (unit configs)

Before creating a resource pool, you need to query resource specifications to select a suitable resource template.

## Procedure

A resource unit can be understood as a template for using server resources. By querying the view, you can obtain the configuration information of existing resource units in the current cluster.

The querying method is as follows:

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Execute the following statement to query all resource specifications in the cluster:

   ```sql
   obclient> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS\G
   ```
