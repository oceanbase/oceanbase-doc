# Check OBServer status

This topic describes how to check OBServer status. You can choose the method that suits your needs.

## Check OBServer status on the host

1. Log in to the host where the OBServer is deployed.

2. Run the following command to check the observer process:

   ```shell
   ps -ef |grep observer
   root       6136      0 99 11:23 ?        08:53:50 ./bin/observer
   root      20514  19521  0 16:09 pts/25   00:00:00 grep --color=auto observer
   ```

## Check OBServer status in the view

```sql
obclient> SELECT status FROM oceanbase.DBA_OB_SERVERS;
+--------+
| status |
+--------+
| active |
| active |
+--------+
2 rows in set (0.00 sec)
```

* If the returned result is `active`, the OBServer is running properly.

* If the returned result is `inactive`, the OBServer is offline.

* If the returned result is `deleting`, the OBServer is being deleted.
