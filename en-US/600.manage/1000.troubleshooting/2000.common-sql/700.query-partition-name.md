# Query the partition name

If you know the `table_id` of a table, you can query the partition names of all partitions in the table from the `CDB_OB_TABLE_LOCATIONS` view (for the sys tenant) or the `DBA_OB_TABLE_LOCATIONS` view (for a user tenant).

* For the sys tenant

  In the sys tenant, you can execute the following statement:

  ```shell
  obclient> SELECT * FROM oceanbase.CDB_OB_TABLE_LOCATIONS WHERE TENANT_ID=tenant_id AND TABLE_ID=table_id;
  ```

* For a user tenant

  In a user tenant in MySQL mode, you can execute the following statement:

  ```shell
  obclient> SELECT * FROM oceanbase.DBA_OB_TABLE_LOCATIONS WHERE TABLE_ID=table_id;
  ```

  In a user tenant in Oracle mode, you can execute the following statement:

  ```shell
  obclient> SELECT * FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_ID=table_id;
  ```
