# Disable security audit

This topic disables how to disable security audit. After you audit specific events by using a series of filters, you can remove filter configurations, delete the filters, and clear audit logs to release the environment.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support security audit. </p>
</main>

## Remove filter configurations

You can use the `AUDIT_LOG_FILTER_REMOVE_USER` function to remove a filter from a user.

### Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_USER('user_name');
```

The following table describes the fields in the syntax.

| Field | Description |
|------|-----|
| user_name | The username. <main id="notice" type='explain'><h4>Note</h4><p>The <code>AUDIT_LOG_FILTER_REMOVE_USER</code> function adopts the <code>DROP IF EXISTS</code> semantics. It does not return an error when the object to be deleted does not exist. </p></main> |

### Example

Remove a filter from the `user001` user.

```shell
obclient [test]> SELECT AUDIT_LOG_FILTER_REMOVE_USER('user001');
```

The return result is as follows:

```shell
+-----------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_USER('user001') |
+-----------------------------------------+
| OK                                      |
+-----------------------------------------+
1 row in set
```

## Delete filters

You can use the `AUDIT_LOG_FILTER_REMOVE_FILTER` function to delete a filter.

### Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_FILTER('filter_name');
```

The following table describes the field in the syntax.

| Field | Description |
|------|-----|
| filter_name | The name of the filter. <main id="notice" type='explain'><h4>Note</h4><p>The <code>AUDIT_LOG_FILTER_REMOVE_FILTER</code> function adopts the <code>DROP IF EXISTS</code> semantics. It does not return an error when the object to be deleted does not exist. </p></main> |

### Example

Delete the `log_all` filter.

```shell
obclient [test]> SELECT AUDIT_LOG_FILTER_REMOVE_FILTER('log_all');
```

The return result is as follows:

```shell
+-------------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_FILTER('log_all') |
+-------------------------------------------+
| OK                                        |
+-------------------------------------------+
1 row in set
```
