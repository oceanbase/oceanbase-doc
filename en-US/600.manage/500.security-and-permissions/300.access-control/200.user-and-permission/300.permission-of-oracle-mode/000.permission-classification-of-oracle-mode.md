# Privilege types in Oracle mode

This topic describes the privilege types in Oracle mode of OceanBase Database.

In Oracle mode, privileges are divided into two types:

* Object privileges: Privileges to operate on specific objects, such as ALTER, SELECT, and UPDATE on a table.
* System privileges: Privileges that allow a user to perform specific database operations on a schema or any schema.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>System privileges provide more extensive permissions than object privileges. </p>
  </main>

| User-level privilege | CREATE SENSITIVE RULE | The privilege to determine whether a user can execute the `CREATE/DROP SENSITIVE RULE` statements. | User-level privilege | PLAINACCESS | The privilege to determine whether a user can access all plaintext data, including sensitive data, without being restricted by sensitive rules. This privilege is also automatically granted when a new cluster is created or after an upgrade. |
