# Resume log replay of a standby tenant

After the restore is successful, all tenants are standby tenants. You can execute the `RECOVER` command to continue replaying logs from the log archive source specified during the restore.

## Background information

The physical restore process is the same as that of a physical standby database. After the physical restore, the tenant is a standby tenant. It can provide services as a standby tenant or be converted to a primary tenant to provide services.

## Prerequisites

The restore operation has been successfully completed. For more information about how to view the restore result, see [View the restore result](../600.restore-data/500.view-the-restore-history.md).

## Specify a standby tenant to replay logs

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Execute the following statement to replay logs.

   The statements are as follows:

   * Replay logs to the specified timestamp, including the timestamp point.

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name UNTIL TIME='timestamp';
     ```

   * Replay logs to the specified SCN, including the SCN point.

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name UNTIL SCN=scn;
     ```

   * Continuously replay logs from the archive source without a specified end point.

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name UNTIL UNLIMITED;
     ```

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>This command can only specify one standby tenant at a time. If you need to specify multiple tenants, you must repeat the command for each tenant.</p>
     </main>

   After the statement is executed successfully, you can execute the following statement to cancel the log replay of the standby tenant.

   ```shell
   obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name CANCEL;
   ```

3. View the log replay progress of the standby tenant.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, LS_ID, STATUS, READABLE_SCN FROM oceanbase.CDB_OB_LS WHERE TENANT_ID=xxx;
   ```

   If you need to view the timestamp to which the logs have been replayed, you can convert it using the `SCN_TO_TIMESTAMP` function. The statement is as follows.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, LS_ID, STATUS, SCN_TO_TIMESTAMP(READABLE_SCN) FROM oceanbase.CDB_OB_LS WHERE TENANT_ID=xxx;
   ```

## Trigger log replay of a standby tenant

A standby tenant can also initiate its own log replay.

1. Log in to the database as the tenant administrator of the user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>In MySQL mode, the administrator user is <code>root</code>. In Oracle mode, the administrator user is <code>SYS</code>.</p>
   </main>

2. Execute the following statement to replay logs.

   The statements are as follows:

   * Replay logs to the specified timestamp, including the timestamp point.

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY UNTIL TIME='timestamp';
     ```

   * Replay logs to the specified SCN, including the SCN point.

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY UNTIL SCN=scn;
     ```

   * Continuously replay logs from the archive source without a specified end point.

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY UNTIL UNLIMITED;
     ```

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>This command can only specify one standby tenant at a time. If you need to specify multiple tenants, you must repeat the command for each tenant.</p>
     </main>

   After the statement is executed successfully, you can execute the following statement to cancel the log replay of the standby tenant.

   ```shell
   obclient> ALTER SYSTEM RECOVER STANDBY CANCEL;
   ```

3. View the log replay progress of the standby tenant.

   ```shell
   obclient> SELECT LS_ID, STATUS, READABLE_SCN FROM oceanbase.DBA_OB_LS;
   ```

   If you need to view the timestamp to which the logs have been replayed, you can convert it using the `SCN_TO_TIMESTAMP` function. The statement is as follows.

   ```shell
   obclient> SELECT LS_ID, STATUS, SCN_TO_TIMESTAMP(READABLE_SCN) FROM oceanbase.DBA_OB_LS;
   ```
