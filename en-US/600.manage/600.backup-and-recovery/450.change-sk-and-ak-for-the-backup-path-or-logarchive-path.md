# Update `access_id` and `access_key` of the backup or archive path

OceanBase Database allows you to dynamically update the `access_id` and `access_key` and other information of a backup or archive path. After you set a backup or archive path, you may change the credential information of object storage due to security or other reasons. To ensure the normal backup or archiving, you can update the `access_id` and `access_key` of the backup or archive path.

## Limitations

* For V4.3.5, the change of the backup or archiving path is supported in V4.3.5 BP2 and later.

* Only the `access_id` and `access_key` in the object storage path can be changed.

* Only the user tenant can change the key information of the backup or archiving path of the current tenant. The sys tenant is not allowed to change the key information of the backup or archiving path of a specified user tenant.

## Considerations

* During backup or archiving, if you change the key information of the object storage path, you must change the `access_id` and `access_key` of the backup or archiving path. Otherwise, the backup task may fail or the archiving may not proceed.

* In a physical standby database based on log archiving, if you change the key information of the object storage path, you must update the `access_id` and `access_key` in the log restore path of the standby tenant as soon as possible. Otherwise, log synchronization may not proceed. For more information about how to update the `access_id` and `access_key` in the log restore path of the standby tenant, see [Set log restore source](../400.high-availability/300.physical-standby-database-disaster-recovery/300.log-transport-service/200.configure-the-log-transport-service/100.set-log-restore-source.md).

## Procedure

1. Log in to the user tenant of the cluster as the tenant administrator of the user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>In MySQL mode, the administrator user is the <code>root</code> user, and in Oracle mode, the administrator user is the <code>SYS</code> user.</p>
   </main>

   The following code is a sample code. You must modify it based on your actual database environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Execute the following statement to change the key information of the backup path or archive path.

   The sample SQL statement is as follows:

   ```sql
   ALTER SYSTEM {ALTER|CHANGE|MODIFY} EXTERNAL_STORAGE_DEST PATH [=] 'path' SET ACCESS_INFO = 'access_id=new_access_id&access_key=new_access_key';
   ```

   The parameters in the statement are described as follows:

   * `path`: the backup path or archive path whose key information is to be changed. The path must be an object storage path configured for the current tenant, and must contain the `host` information.

     For example, in the case of Alibaba Cloud Object Storage Service (OSS), the path is in the following format: `oss://oceanbase-test-bucket/backup/data?host=***`.

   * `access_id=new_access_id&access_key=new_access_key`: the new `access_id` and `access_key` after the change. You must specify both `access_id` and `access_key`.

   For example, assuming that the backup path and archive path configured for the current user tenant during backup are `oss://oceanbase-test-bucket/backup/data?host=cn-****.aliyuncs.com` and `oss://oceanbase-test-bucket/backup/archive?host=cn-****.aliyuncs.com` respectively, the key information of the backup path and archive path can be changed as follows:

   * Change the key information of the backup path

      ```shell
      obclient> ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST PATH='oss://oceanbase-test-bucket/backup/data?host=cn-****.aliyuncs.com' SET ACCESS_INFO = 'access_id=******&access_key=******';
      ```

   * Change the key information of the archive path

      ```shell
      obclient> ALTER SYSTEM CHANGE ARCHIVELOG DESTINATION PATH='oss://oceanbase-test-bucket/backup/archive?host=cn-****.aliyuncs.com' SET ACCESS_INFO = 'access_id=******&access_key=******';
      ```

    For more information, see [ALTER/CHANGE/MODIFY EXTERNAL_STORAGE_DEST](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1430.alter-system-change-external-storage-dest-of-mysql-mode.md).

3. Query the `DBA_OB_BACKUP_STORAGE_INFO` view to confirm the change.

   :::tab
   tab MySQL mode

   * Confirm the `access_id` and `access_key` of the backup path.

      ```shell
      obclient[oceanbase]> SELECT AUTHORIZATION FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/data' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      The query result is as follows:

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```

   * Confirm the `access_id` and `access_key` of the archive path.

      ```shell
      obclient[oceanbase]> SELECT AUTHORIZATION FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/archive' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      The query result is as follows:

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```

   tab Oracle mode

   * Confirm the `access_id` and `access_key` of the backup path.

      ```shell
      obclient[SYS]> SELECT AUTHORIZATION FROM SYS.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/data' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      The query result is as follows:

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```

   * Confirm the `access_id` and `access_key` of the archive path.

      ```shell
      obclient[SYS]> SELECT AUTHORIZATION FROM SYS.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/archive' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      The query result is as follows:

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```
   :::
