# Cancel backup validation

After initiating a backup validation task, you can cancel the ongoing validation task.

## Cancel backup validation tasks for user tenants from the system tenant (`sys` tenant)

1. Log in to the cluster as the `root` user of the system tenant (`sys` tenant).

   The following is a sample connection command. Use the actual environment parameters when connecting to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Execute the following command to cancel the ongoing validation task for the user tenant.

   The statement is as follows:

   ```sql
   ALTER SYSTEM CANCEL VALIDATE BACKUP [TENANT = tenant_name];
   ```

   In the statement, `TENANT` specifies the tenant for which to cancel the backup validation task. If not specified, it cancels the backup validation tasks for all user tenants in the cluster.

   Examples:

   * The system tenant (`sys` tenant) cancels backup validation tasks for all user tenants.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP;
     ```

   * The system tenant (`sys` tenant) cancels the backup validation task for the specified user tenant `mysqltenant`.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP TENANT = mysqltenant;
     ```

## User tenant cancels backup validation tasks for the current tenant

1. Log in to the database as the administrator of the user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>For a MySQL-compatible tenant, the administrator user is the <code>root</code> user. For an Oracle tenant, it is the <code>SYS</code> user.</p>
   </main>

   The following is a sample connection command. Use the actual environment parameters when connecting to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. Execute the following command to cancel the ongoing validation task for the current tenant.

   ```shell
   obclient> ALTER SYSTEM CANCEL VALIDATE BACKUP;
   ```
