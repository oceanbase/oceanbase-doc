# Cancel a backup validation task

After you initiate a backup validation task, you can cancel the task.

## Cancel a backup validation task of a user tenant as a system tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Replace the actual environment variables with the values in your environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Execute the following command to cancel the backup validation task of the user tenant.

   The statement is as follows:

   ```sql
   ALTER SYSTEM CANCEL VALIDATE BACKUP [TENANT = tenant_name];
   ```

   In the statement, `TENANT` specifies the tenant whose backup validation task you want to cancel. If you do not specify `TENANT`, the backup validation tasks of all user tenants in the cluster are canceled.

   Here are some examples:

   * Cancel the backup validation tasks of all user tenants.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP;
     ```

   * Cancel the backup validation task of the specified user tenant `mysqltenant`.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP TENANT = mysqltenant;
     ```

## Cancel a backup validation task of the current user tenant

1. Log in to the database as the tenant administrator of the user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator user of a MySQL tenant is <code>root</code>, and the administrator user of an Oracle tenant is <code>SYS</code>. </p>
   </main>

   The following example shows how to connect to the database. Replace the actual environment variables with the values in your environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. Execute the following command to cancel the backup validation task of the current user tenant.

   ```shell
   obclient> ALTER SYSTEM CANCEL VALIDATE BACKUP;
   ```
