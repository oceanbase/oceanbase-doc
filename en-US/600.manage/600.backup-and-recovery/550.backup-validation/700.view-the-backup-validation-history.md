# View the backup validation result

After a backup validation task is completed, you can view the execution result of the task in the view.

## View the backup validation result of a user tenant in the system tenant

As a system tenant, you can view the execution result of all backup validation tasks in each user tenant in the views `CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` and `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY`.

The views are described as follows:

* In the view `CDB_OB_BACKUP_VALIDATE_JOB_HISTORY`, each job corresponds to a backup validation instruction. If the instruction involves multiple user tenants, the view may contain multiple sub-jobs at the user tenant level.

* In the view `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY`, each task corresponds to a backup validation task for a backup set (backup_set) or a log archive piece (archive_piece).

To view the backup validation result in the system tenant, perform the following steps:

1. Log in to the `sys` tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Replace the actual environment variables.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. View the execution result of the job-level backup validation task.

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_JOB_HISTORY\G
   ```

   The query result is as follows:

   ```shell
   *************************** 1. row ***************************
             TENANT_ID: 1002
                JOB_ID: 2
           INCARNATION: 1
   INITIATOR_TENANT_ID: 1002
      INITIATOR_JOB_ID: 0

                  TYPE: DATABASE

                    ID:
        VALIDATE_LEVEL: basic
       START_TIMESTAMP: 2026-03-03 13:58:07.778690
         END_TIMESTAMP: 2026-03-03 13:58:09.864257
                STATUS: COMPLETED
           RETRY_COUNT: 0
            TASK_COUNT: 1
    SUCCESS_TASK_COUNT: 1
                RESULT: 0
           DESCRIPTION:
               COMMENT: all archive pieces are not support for backup validate or not find any piece
   1 row in set
   ```

   The query result shows the execution result of the job-level backup validation task in the user tenant with the tenant ID 1002. In this case, `job_id` is 2, the initiator tenant ID is 1002, the executor tenant ID is empty, the backup validation task validates all backup sets and log archive pieces in the entire backup path and archive path (`TYPE` is `DATABASE`), the validation path is not specified (`PATH`, `PATH_TYPE`, and `ID` are empty), the validation level is basic (`VALIDATE_LEVEL` is `basic`), and the task is completed (`STATUS` is `COMPLETED`). The validation result is `all archive pieces are not support for backup validate or not find any piece`.

3. View the execution result of the task-level backup validation task, that is, the backup validation result of a backup set or a log archive piece.

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_TASK_HISTORY\G
   ```

   The query result is as follows:


   The query result shows the execution result of the task-level backup validation task in the user tenant with the tenant ID 1002. In this case, `task_id` is 3, the corresponding `job_id` is 2, the backup set ID is 1 (`TASK_TYPE` is `BACKUPSET` and `ID` is 1), the backup set is stored in the path `file:///data/nfs/backup/data/backup_set_1_full`, the backup path ID is 1002 (`DEST_ID` is 1002), the backup set does not contain compensation logs (`PLUS_ARCHIVELOG` is `OFF`), the validation level is basic (`VALIDATE_LEVEL` is `basic`), and the task is completed (`STATUS` is `COMPLETED`).

## View the backup validation result of a user tenant in the user tenant

As a user tenant, you can view the execution result of all backup validation tasks in each user tenant in the views `DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` and `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY`.

The views are described as follows:

* In the view `DBA_OB_BACKUP_VALIDATE_JOB_HISTORY`, each job corresponds to a backup validation instruction.

* In the view `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY`, each task corresponds to a backup validation task for a backup set (backup_set) or a log archive piece (archive_piece).

To view the backup validation result in the user tenant, perform the following steps:

1. Log in to the database as the tenant administrator.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator of a MySQL tenant is the <code>root</code> user. The administrator of an Oracle tenant is the <code>SYS</code> user. </p>
   </main>

   The following example shows how to connect to the database. Replace the actual environment variables.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. View the execution result of the job-level backup validation task.

   :::tab
   tab MySQL mode

   The following example shows how to query the execution result of the job-level backup validation task in MySQL mode:

   ```shell
   obclient(root@mysqltenant)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY;
   ```

   tab Oracle mode

   The following example shows how to query the execution result of the job-level backup validation task in Oracle mode:

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY;
   ```

   :::
