# View the results of backup cleanup

After you set a cleanup policy and the automatic cleanup is triggered, you can view the results of the cleanup tasks in the history table after the cleanup tasks are completed.

## View the history of cleanup tasks as the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Replace the actual environment variables with the values in your environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. View the history of cleanup tasks.

## View the history of cleanup tasks as a user tenant

1. Log in to the database as the tenant administrator of the user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator user of a MySQL tenant is <code>root</code>, and the administrator user of an Oracle tenant is <code>SYS</code>. </p>
   </main>

   The following example shows how to connect to the database. Replace the actual environment variables with the values in your environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. View the history of cleanup tasks.

   * View the history of job-level cleanup tasks.

     The job-level cleanup tasks record the information about the initiation of the cleanup tasks.

     :::tab
     tab MySQL mode

     The following example shows how to query the history of job-level cleanup tasks in MySQL mode:

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     tab Oracle mode

     The following example shows how to query the history of job-level cleanup tasks in Oracle mode:

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     :::

     The `DBA_OB_BACKUP_DELETE_JOB_HISTORY` view contains all the fields of the `CDB_OB_BACKUP_DELETE_JOB_HISTORY` view except the `TENANT_ID` field. For more information about the query result, see **View the history of cleanup tasks as the sys tenant**.

   * View the history of task-level cleanup tasks.

     The task-level cleanup tasks record the details about the cleanup of `backup_set/backup_piece`.

     :::tab
     tab MySQL mode

     The following example shows how to query the history of task-level cleanup tasks in MySQL mode:

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     tab Oracle mode

     The following example shows how to query the history of task-level cleanup tasks in Oracle mode:

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     :::

     The `DBA_OB_BACKUP_DELETE_TASK_HISTORY` view contains all the fields of the `CDB_OB_BACKUP_DELETE_TASK_HISTORY` view except the `TENANT_ID` field. For more information about the query result, see **View the history of cleanup tasks as the sys tenant**.
