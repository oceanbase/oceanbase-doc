# View the progress of table-level restore

After you execute a table-level restore command, you can view the progress of the table-level restore task in a view.

## Procedure

1. Log in to the `sys` tenant of the cluster where the target tenant whose tables are to be restored is located as the `root` user.

2. View the progress of the table-level restore task.

   You can view the progress of the entire table-level restore task in the `CDB_OB_RECOVER_TABLE_JOBS` view of the system tenant.

   ```sql
   obclient [(none)]> SELECT * FROM oceanbase.CDB_OB_RECOVER_TABLE_JOBS\G
   ```

   A sample query result is as follows:

   ```shell
   *************************** 1. row ***************************

                     JOB_ID: 1
        INITIATOR_TENANT_ID: 1
           INITIATOR_JOB_ID: 0

                     STATUS: RECOVERING
            AUX_TENANT_NAME: AUX_RECOVER$1692106995896258
         TARGET_TENANT_NAME: backup_tenant
                 IMPORT_ALL: 0
                    DB_LIST: 
                 TABLE_LIST: `TEST`.`T1`
                RESTORE_SCN: 1692104831498747191
        RESTORE_SCN_DISPLAY: 2023-06-01 00:00:00.000000
             RESTORE_OPTION: pool_list=small_pool_0&primary_zone=z1
                BACKUP_DEST: file:///data2/nfs/ob_backup_oracle_tenant/archive,file:///data2/nfs/ob_backup_oracle_tenant/data
            BACKUP_SET_LIST: file:///data2/nfs/ob_backup_oracle_tenant/data/backup_set_1_full
          BACKUP_PIECE_LIST: file:///data2/nfs/ob_backup_oracle_tenant/archive/piece_d1001r1p1

      REMAP_TABLESPACE_LIST:
                     RESULT: 
                    COMMENT: 
   1 row in set
   ```

   This view records the restore parameters specified by you during the restore process and the restore results.

   The table-level restore process consists of two phases: restore in the auxiliary tenant and import to the target tenant. The `CDB_OB_RECOVER_TABLE_JOBS` view contains two task records: one for the `sys` tenant and one for the target user tenant. Specifically:

   * The task record in the `sys` tenant mainly records the progress of table-level restore in the target user tenant. If the table-level restore task in the target tenant is completed, the task is considered to be completed.

   * The task record in the target user tenant records the progress of restore in the auxiliary tenant and the progress of table import. If the restore task in the auxiliary tenant and the table import task are completed, the task is considered to be completed.

   In the query result, `AUX_RECOVER$1692106995896258` indicates the auxiliary tenant, `backup_tenant` indicates the target user tenant, and `TEST`.`T1` indicates the table to be restored. The `STATUS` field indicates the current stage of the table-level restore task:

   * `PREPARE`: the task is in the initialization phase.
   * `RECOVERING`: the target tenant is in the restore process. This status is displayed only in the `sys` tenant.
   * `RESTORE_AUX_TENANT`: the auxiliary tenant is being restored.
   * `PRECHECK_IMPORT`: a precheck is being performed before the import.
   * `GEN_IMPORT_JOB`: the import task is being initialized.
   * `IMPORTING`: the table is being imported.
   * `CANCELING`: the task is being canceled.
   * `COMPLETED`: the task is completed.
   * `FAILED`: the task has failed.

   If the value of `STATUS` in the view is `COMPLETED`, the table-level restore task is completed. For more information about the fields in the `CDB_OB_RECOVER_TABLE_JOBS` view, see [Table-level restore views](700.views-of-the-table-recovery.md).

3. Before the table-level restore task is completed, you can view the progress of the auxiliary tenant restore task and the target tenant import task based on the current stage of the table-level restore task.

   * During the restore in the auxiliary tenant, view the progress of the auxiliary tenant restore task.

      ```sql
      obclient [(none)]> SELECT * FROM oceanbase.CDB_OB_RESTORE_PROGRESS\G
      ```

      The restore process in the auxiliary tenant is the same as the tenant-level physical restore process. For more information about how to view the progress of physical restore, see [View the progress of physical restore](../600.restore-data/400.view-the-restore-progress.md).

   * During the import of tables, view the progress of the target tenant import task.

      ```sql
      obclient [(none)]> SELECT * FROM oceanbase.CDB_OB_IMPORT_TABLE_JOBS\G
      ```

      A sample query result is as follows:

