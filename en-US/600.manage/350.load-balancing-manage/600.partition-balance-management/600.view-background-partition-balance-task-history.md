# View the history of partition balancing tasks in the background

After a partition balancing task is completed, you can view the task execution history in the view.

## View the partition balance tasks in the background for the system tenant

1. Log in to the sys tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Please replace the actual environment parameters with the correct ones.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Execute the following statement to view the partition balance tasks in the background for the specified tenant.

   * View the partition balance tasks in the background for the specified tenant.

     The `CDB_OB_BALANCE_JOB_HISTORY` view displays the macro-level balance tasks for all tenants, including scaling out, scaling in, migration balancing, and partition balancing.

     ```shell
     obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_JOB_HISTORY WHERE TENANT_ID = 1002 AND JOB_TYPE = 'PARTITION_BALANCE';
     ```

     The query result is as follows:

     ```shell
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     | TENANT_ID | JOB_ID | CREATE_TIME                | FINISH_TIME                | BALANCE_STRATEGY                | JOB_TYPE          | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS    | COMMENT | MAX_END_TIME | ZONE_UNIT_NUM_LIST | PARAMETER_LIST                                                                               |
     ```

     For more information about the fields in the `CDB_OB_BALANCE_JOB_HISTORY` view, see [CDB_OB_BALANCE_JOB_HISTORY](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7700.o-cdb_ob_balance_job_history-of-sys-tenant.md).

   * Query the history of partition balance tasks at the LS level for the specified tenant.

The `CDB_OB_BALANCE_TASK_HISTORY` view displays all tenant-level log stream tasks, including LS splits (LS_SPLIT), LS merges (LS_MERGE), LS transfers (LS_TRANSFER), and modifications to LS attributes (LS_ALTER).

## View the partition balance tasks in the background of the user tenant

1. Log in to the MySQL tenant or Oracle tenant of the cluster as the tenant administrator of the user tenant.

   Here is an example of the connection command. Please replace the parameters with those in your environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```
