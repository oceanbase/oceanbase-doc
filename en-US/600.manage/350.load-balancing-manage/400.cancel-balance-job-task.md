# Cancel a Balance Job

Only one load balancing job (Balance Job) can be running at a time for each tenant. If the current Balance Job does not meet your business requirements, you can cancel it. Additionally, if you have initiated a Transfer Partition task but there is an ongoing Balance Job causing delays, you can cancel the Balance Job first.

## Limitations

You can cancel a balance job only on the primary database (that is, the primary tenant).

## Background information

Only one balance job can be in progress for each tenant at a time. Balance jobs include scaling up, scaling down, load balancing, and partition balancing. Each balance job consists of multiple balance tasks that perform the specific operations for load balancing. Canceling a balance job will cancel all running tasks under that job.

## Cancel a running balance job in the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Please replace the actual environment parameters.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Query the `CDB_OB_BALANCE_JOBS` view to obtain the current running tasks.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, BALANCE_STRATEGY, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   The query result is as follows:

   ```shell
   +-----------+--------+----------------------+------------+--------+
   | TENANT_ID | JOB_ID | BALANCE_STRATEGY     | JOB_TYPE   | STATUS |
   +-----------+--------+----------------------+------------+--------+
   |      1002 | 520683 | LS balance by shrink | LS_BALANCE | DOING  |
   +-----------+--------+----------------------+------------+--------+
   1 row in set
   ```

3. If the task does not meet your expectations, you can execute the following statement to cancel the balance job.

   ```sql
   ALTER SYSTEM CANCEL BALANCE JOB TENANT = 'tenant_name';
   ```

   Here is an example:

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM CANCEL BALANCE JOB TENANT ='mysql_tenant';
   ```

## Cancel a running balance job in a user tenant

1. Connect to the database as the tenant administrator of a MySQL or Oracle tenant.

   The following example shows how to connect to the database. Please replace the actual environment parameters.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Query the `DBA_OB_BALANCE_JOBS` view to obtain the current running tasks.

   :::tab
   tab MySQL mode

   The following example shows how to query the `DBA_OB_BALANCE_JOBS` view in MySQL mode:

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

   tab Oracle mode

   The following example shows how to query the `DBA_OB_BALANCE_JOBS` view in Oracle mode:

   ```shell
   obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOBS;
   ```

   :::

3. If the task does not meet your expectations, you can execute the following statement to cancel the balance job.

   ```shell
   obclient> ALTER SYSTEM CANCEL BALANCE JOB;
   ```
