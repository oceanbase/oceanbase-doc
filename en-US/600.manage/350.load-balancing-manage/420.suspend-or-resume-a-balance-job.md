# Pause and resume a Balance Job

If a Balance Job is running for a tenant and there is an urgent change that needs to be executed, you can choose to pause the current Balance Job to prevent it from affecting the urgent change. Once the urgent change is completed, you can resume the Balance Job to continue its execution.

## Limitations

* You can pause or resume a balance job only on the primary database (primary tenant).

* You can pause or resume a balance job only when the status of the balance job is not `CANCELING`.

## Pause the ongoing Balance Job

### Suspend a Balance Job in a User Tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Replace the actual environment parameters in the example.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Query the `DBA_OB_TENANTS` view to obtain the information about the tenant.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE tenant_name = 'mq_t1';
   ```

   The query result is as follows:

   ```shell
   +-------------+-----------+-------------+
   | TENANT_NAME | TENANT_ID | TENANT_ROLE |
   +-------------+-----------+-------------+
   | mq_t1       |      1002 | PRIMARY     |
   +-------------+-----------+-------------+
   1 row in set
   ```

3. Query the `CDB_OB_BALANCE_JOBS` view to obtain the current task and its status.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   The query result is as follows:

   ```shell
   +-----------+--------+--------------------+--------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS |
   +-----------+--------+--------------------+--------+
   |      1002 |  62944 | TRANSFER_PARTITION | DOING  |
   +-----------+--------+--------------------+--------+
   1 row in set
   ```

   According to the query result, the status of the current Balance Job is `DOING`, not `CANCELING`. Therefore, you can suspend the job.

4. Execute the following statement to suspend the Balance Job.

   ```sql
   ALTER SYSTEM SUSPEND BALANCE JOB TENANT = 'tenant_name';
   ```

   Here is an example:

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM SUSPEND BALANCE JOB TENANT ='mq_t1';
   ```

5. After the execution succeeds, query the `CDB_OB_BALANCE_JOBS` view again. You can see that the status of the current task is changed to `SUSPEND`.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   The query result is as follows:

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION | SUSPEND |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```

### Pause the Balance Job in the Current Tenant

1. Connect to the database as the tenant administrator of the MySQL or Oracle tenant.

   The following example shows how to connect to the database. Please replace the parameters with those in your environment.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Query the `DBA_OB_BALANCE_JOBS` view to obtain the current task and its status.

   :::tab
   tab MySQL Mode

   The query statement in MySQL mode is as follows:

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT JOB_ID, JOB_TYPE, STATUS FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

   tab Oracle Mode

   The query statement in Oracle mode is as follows:

   ```shell
   obclient(SYS@oracle001)[SYS]> SELECT JOB_ID, JOB_TYPE, STATUS FROM SYS.DBA_OB_BALANCE_JOBS;
   ```

   :::

   The query result is as follows:

   ```shell
   +--------+--------------------+---------+
   | JOB_ID | JOB_TYPE           | STATUS  |
   +--------+--------------------+---------+
   |  62944 | TRANSFER_PARTITION |   DOING |
   +--------+--------------------+---------+
   1 row in set
   ```

   The query result shows that the status of the current Balance Job is `DOING`, not `CANCELING`. Therefore, you can pause the job.

3. Execute the following statement to pause the Balance Job.

   ```shell
   obclient> ALTER SYSTEM SUSPEND BALANCE JOB;
   ```

4. After the execution succeeds, query the `DBA_OB_BALANCE_JOBS` view again. The status of the current task changes to `SUSPEND`.

   :::tab
   tab MySQL Mode

   The query statement in MySQL mode is as follows:

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT JOB_ID, JOB_TYPE, STATUS FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

   tab Oracle Mode

   The query statement in Oracle mode is as follows:

   ```shell
   obclient(SYS@oracle001)[SYS]> SELECT JOB_ID, JOB_TYPE, STATUS FROM SYS.DBA_OB_BALANCE_JOBS;
   ```

   :::

   The query result is as follows:

   ```shell
   +--------+--------------------+---------+
   | JOB_ID | JOB_TYPE           | STATUS  |
   +--------+--------------------+---------+
   |  62944 | TRANSFER_PARTITION | SUSPEND |
   +--------+--------------------+---------+
   1 row in set
   ```

## Resume a paused Balance Job

### Resume a balance job of a user tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   The following example shows how to connect to the database. Replace the actual environment parameters.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Query the `DBA_OB_TENANTS` view to obtain the information about the user tenant.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE tenant_name = 'mq_t1';
   ```

   The query result is as follows:

   ```shell
   +-------------+-----------+-------------+
   | TENANT_NAME | TENANT_ID | TENANT_ROLE |
   +-------------+-----------+-------------+
   | mq_t1       |      1002 | PRIMARY     |
   +-------------+-----------+-------------+
   1 row in set
   ```

3. Query the `CDB_OB_BALANCE_JOBS` view to obtain the current suspended balance job and its status.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   The query result is as follows:

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION | SUSPEND |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```

   The query result shows that the status of the balance job is `SUSPEND`.

4. Execute the following statement to resume the balance job.

   ```sql
   ALTER SYSTEM RESUME BALANCE JOB TENANT = 'tenant_name';
   ```

   The following example shows how to execute this statement.

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM RESUME BALANCE JOB TENANT ='mq_t1';
   ```

5. After the execution is successful, query the `CDB_OB_BALANCE_JOBS` view again. The status of the balance job changes to `DOING`.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   The query result is as follows:

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION |  DOING  |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```

### Resume the Balance Job of the Suspended Tenant

1. Connect to the database as the tenant administrator of the MySQL or Oracle mode tenant.

   The following example shows how to connect to the database. Please replace the actual environment parameters.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Query the `DBA_OB_BALANCE_JOBS` view to obtain the suspended tasks and their status.

   :::tab
   tab MySQL mode

   The following example shows how to query the `DBA_OB_BALANCE_JOBS` view in MySQL mode:

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT JOB_ID, JOB_TYPE, STATUS FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

   tab Oracle mode

   The following example shows how to query the `DBA_OB_BALANCE_JOBS` view in Oracle mode:

   ```shell
   obclient(SYS@oracle001)[SYS]> SELECT JOB_ID, JOB_TYPE, STATUS FROM SYS.DBA_OB_BALANCE_JOBS;
   ```

   :::

   The query result is as follows:

   ```shell
   +--------+--------------------+---------+
   | JOB_ID | JOB_TYPE           | STATUS  |
   +--------+--------------------+---------+
   |  62944 | TRANSFER_PARTITION | SUSPEND |
   +--------+--------------------+---------+
   1 row in set
   ```

   The status of the current Balance Job is `SUSPEND`.

3. Execute the following statement to resume the suspended Balance Job.

   ```shell
   obclient> ALTER SYSTEM RESUME BALANCE JOB;
   ```

4. After the execution is successful, query the `DBA_OB_BALANCE_JOBS` view again. The status of the current task changes to `DOING`.

   ```shell
   +--------+--------------------+---------+
   |  62944 | TRANSFER_PARTITION |  DOING  |
   ```
