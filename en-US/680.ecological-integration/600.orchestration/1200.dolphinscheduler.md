# Configure OceanBase as the data source for DolphinScheduler

DolphinScheduler supports OceanBase Database. If you use the MySQL mode of OceanBase Database, you can configure OceanBase Database as the data source for DolphinScheduler.

Log in to the DolphinScheduler console. In the navigation pane, click Data Source Management > Create Data Source > Select Data Source Type. Select MySQL as the data source type. If you are using the latest version of DolphinScheduler, you can select OCEANBASE as the data source type.

To configure OceanBase Database as the data source for DolphinScheduler, you must provide the following parameters:

| Parameter | Description |
| ---- | ---- |
| Data Source | Select OCEANBASE. |
| Data Source Name | Enter the name of the data source. |
| IP | Host Name: enter the IP address for connecting to OceanBase Database. |
| Port | Enter the port for connecting to OceanBase Database. |
| Username | Enter the username for connecting to OceanBase Database. |
| Password | Enter the password for connecting to OceanBase Database. |
| Database Name | Enter the name of the database for connecting to OceanBase Database. |

For more information, see [Configure OceanBase Database as the data source for DolphinScheduler](https://dolphinscheduler.apache.org/en-us/docs/3.2.1/guide/datasource/mysql).
