# Integrate OceanBase Database with Linkis

Linkis is an open-source distributed computing middleware that provides unified management of computing resources, task scheduling, and execution services. Linkis creates an intermediate layer that allows different data processing applications (such as Apache Spark, Hadoop, and TensorFlow) to interact with data storage and computing resources.

Linkis V3.1.2 supports OceanBase Database. This topic describes how to create an OceanBase Database task in Linkis. OceanBase Database is compatible with most features and syntaxes of MySQL 5.7. Therefore, you can use OceanBase Database as a MySQL database.

## Prerequisites

Before you integrate OceanBase Database with Linkis, make sure that:

- You have installed and deployed OceanBase Database. For more information, see [Try OceanBase Database for free](https://www.oceanbase.com/docs/community-observer-cn-10000000000901197).
- You have installed and deployed Linkis. For more information, see [Deploy Linkis](https://linkis.apache.org/zh-CN/docs/1.3.2/deployment/deploy-quick).

## Submit a task by using the shell

```shell
 sh ./bin/linkis-cli -engineType jdbc-4 -codeType jdbc -code "show tables" -submitUser hadoop -proxyUser hadoop -runtimeMap wds.linkis.jdbc.connect.url=jdbc:mysql://${ip}:${port}/${db_name} -runtimeMap wds.linkis.jdbc.driver=com.mysql.jdbc.Driver -runtimeMap wds.linkis.jdbc.username=${username} -runtimeMap wds.linkis.jdbc.password=${password}
```

### Submit a task by using the Linkis SDK

`Linkis` provides `SDKs` for `Java` and `Scala` to submit tasks to the `Linkis` server. For more information, see [JAVA SDK documentation](https://linkis.apache.org/zh-CN/docs/latest/user-guide/sdk-manual). You can modify only the `EngineConnType` and `CodeType` parameters in the `Demo` section for an `OceanBase` task:

```java
Map<String, Object> labels = new HashMap<String, Object>();
labels.put(LabelKeyConstant.ENGINE_TYPE_KEY, "jdbc-4"); // required engineType Label
labels.put(LabelKeyConstant.USER_CREATOR_TYPE_KEY, "hadoop-IDE");// required execute user and creator
labels.put(LabelKeyConstant.CODE_TYPE_KEY, "jdbc"); // required codeType
```

## Submit an OceanBase task by using the Linkis console

### Add an OceanBase data source

1. Log in to the Linkis console.
2. In the left-side navigation pane, click **<UI-TERM key="odc.Record.RecordPage.interface.DataSourceManagement">Data source management</UI-TERM>**.
3. On the **<UI-TERM key="odc.Record.RecordPage.interface.DataSourceManagement">Data source management</UI-TERM>** page, click **Create Data Source** in the upper-right corner.
4. In the **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.NewButton.CreateADataSource">Create Data Source</UI-TERM>** dialog box, select **<UI-TERM key="odc.Form.DBTypeItem.DataSourceType">Data Source Type</UI-TERM>** as **MySQL**.
5. Configure the parameters.

    | Parameter | Description |
    | --- | --- |
    | Data Source Name | The identifier of the data source. |
    | Host | The IP address of the host where OceanBase Database is deployed. |
    | Port | The port of the host where OceanBase Database is deployed. |
    | Username | The username of the user in OceanBase Database. |
    | Password | The password of the user in OceanBase Database. |

6. Click **<UI-TERM key="odc.NewSSODrawerButton.SSOForm.TestConnection">Test Connection</UI-TERM>** to verify the network connection between Linkis and the database, and the validity of the username and password.
7. After the test connection is successful, click **<UI-TERM key="odc.component.StatusBar.Complete">Complete</UI-TERM>**.
8. Publish the data source.

    On the **<UI-TERM key="odc.Record.RecordPage.interface.DataSourceManagement">Data source management</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Version">Version</UI-TERM>** of the OceanBase data source. In the **Edit Version List** dialog box that appears, click **Publish**.

### Submit an OceanBase task

Specify the name of the data source to submit an OceanBase task.

Request URL: `http://${gateway_url}:${port}/api/rest_j/v1/entrance/submit`

Request method: POST

Request parameters:

```json
{
    "executionContent": {
        "code": "show databases",
        "runType": "jdbc"
    },
    "params": {
        "variable": {},
        "configuration": {
            "startup": {},
            "runtime": {
                "wds.linkis.engine.runtime.datasource": "ob-test"
            }
        }
    },
    "labels": {
        "engineType": "jdbc-4"
    }
}
```

Response result:

```json
{
    "method": "/api/entrance/submit",
    "status": 0,
    "message": "OK",
    "data": {
        "taskID": 93,
        "execID": "exec_id018017linkis-cg-entrance000830fb1364:9104IDE_hadoop_jdbc_0"
    }
}
```
