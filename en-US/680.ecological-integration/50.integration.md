# Overview of the ecosystem

OceanBase Database, a high-performance distributed relational database, has built an ecosystem that integrates a wide range of tools to simplify database management, improve operational efficiency, and seamlessly integrate with diverse IT environments.

## Development languages

* C: a high-performance general-purpose programming language widely used in system software and application development. For more information, see [Connect to OceanBase Database by using MySQL Connector/C](../300.develop/100.application-development-of-mysql-mode/200.sample-program-of-mysql-mode/300.c-of-mysql-mode/100.connect-to-the-oceanbase-database-through-mysql-connector-c-of-mysql-mode.md) and [Connect to OceanBase Database by using OceanBase Connector/C](../300.develop/200.application-development-of-oracle-mode/200.sample-program-of-oracle-mode/300.c-of-oracle-mode/200.oceanbase-connector-odbc-connection-to-oceanbase-database-sample-program.md).
* Java: a popular object-oriented programming language applicable to various fields. For more information, see [Connect to OceanBase Database by using OceanBase Connector/J](../300.develop/200.application-development-of-oracle-mode/200.sample-program-of-oracle-mode/100.java-of-oracle-mode/100.oceanbase-connector-j-connection-to-oceanbase-database-sample-program.md).
* Python: a multi-purpose, high-level programming language with a readable syntax. For more information, see [Connect to OceanBase Database by using mysqlclient](../300.develop/100.application-development-of-mysql-mode/200.sample-program-of-mysql-mode/200.python-of-mysql-mode/100.mysqlclient-connection-to-oceanbase-database-sample-program.md).

* PHP: an open-source server-side scripting language widely used in website development and server-side application development. ## ORM frameworks

### Java

* SpringBoot: a framework that simplifies the development of Spring applications and enables you to quickly create independent, production-level Spring applications. For more information, see [Connect to OceanBase Database by using SpringBoot](200.orms-frameworks/100.java/100.connect-to-the-oceanbase-database-through-spring-boot.md).
* SpringBatch: a framework for batch processing tasks that supports large-scale data processing and provides flexible execution and monitoring mechanisms. For more information, see [Connect to OceanBase Database by using SpringBatch](200.orms-frameworks/100.java/200.connect-to-the-oceanbase-database-through-spring-batch.md).
* SpringJDBC: a module in the Spring framework that simplifies database access. It provides a series of classes and interfaces that make it easier and more efficient for Java applications to interact with relational databases. For more information, see [Connect to OceanBase Database by using SpringJDBC](200.orms-frameworks/100.java/300.connect-to-the-oceanbase-database-through-spring-jdbc.md).
* SpringJPA: the persistence layer of the Spring framework based on the JPA specification. It simplifies database operations and enhances code readability. For more information, see [Connect to OceanBase Database by using SpringJPA](200.orms-frameworks/100.java/400.connect-to-the-oceanbase-database-through-springjpa.md).
* Hibernate: a powerful ORM framework that automatically maps Java objects to database tables and supports complex queries and transaction management. For more information, see [Connect to OceanBase Database by using Hibernate](200.orms-frameworks/100.java/500.connect-to-the-oceanbase-database-through-hibernate.md).
* MyBatis: a semi-automatic persistence layer framework that allows developers to customize SQL statements and map them to Java objects. It is highly flexible. For more information, see [Connect to OceanBase Database by using MyBatis](200.orms-frameworks/100.java/600.connect-to-the-oceanbase-database-through-mybatis.md).

### Go

* **GORM**: a powerful ORM library that provides a concise API, efficient database operations, support for multiple databases, and migration capabilities. For more information, see [Connect to OceanBase Database by using GORM](200.orms-frameworks/300.go/100.gorm-connection-oceanbase-database-program.md).

## Data integration

* Flink CDC: Flink is an open-source framework for large-scale data processing and analysis. Flink CDC is a component on the platform that captures database change events. Together, they provide a powerful solution for real-time data processing and analysis. For more information, see [Synchronize data from a MySQL database to OceanBase Database by using Flink CDC](../500.data-migration/200.migrate-data-from-mysql-database-to-oceanbase-database/600.use-flink-cdc-to-migrate-data-from-mysql-database-to-oceanbase-database.md) and [Migrate data from OceanBase Database to a MySQL database by using Flink CDC](../500.data-migration/300.migrate-data-from-oceanbase-database-to-mysql-database/500.use-flink-cdc-to-migrate-data-from-oceanbase-database-to-mysql-database.md).
* Canal: a change data capture (CDC) framework for database synchronization and integration. For more information, see [Synchronize data from a MySQL database to OceanBase Database by using Canal](../500.data-migration/200.migrate-data-from-mysql-database-to-oceanbase-database/500.use-canal-to-migrate-data-from-mysql-database-to-oceanbase-database.md) and [Synchronize data from OceanBase Database to a MySQL database by using Canal](../500.data-migration/300.migrate-data-from-oceanbase-database-to-mysql-database/300.use-canal-to-migrate-data-from-oceanbase-database-to-mysql-database.md).
* AWS Glue: a serverless data integration service that helps users easily discover, prepare, move, and integrate data from multiple sources for analytics, machine learning, and application development. It provides comprehensive data integration capabilities, including data discovery, modern ETL, data cleaning and transformation, and centralized cataloging, all integrated in one service. For more information, see [Migrate data to OceanBase Database by using AWS Glue](https://www.oceanbase.com/docs/common-oceanbase-cloud-1000000001478166).
* dbt: an open-source data transformation tool that converts data through SQL and converts commands into tables or views. For more information, see [Analyze OceanBase data by using dbt](400.data-ingestion/200.dbt.md).
* Maxwell: a change data capture (CDC) tool for MySQL databases. For more information, see [Read OceanBase data by using Maxwell](400.data-ingestion/1500.maxwell.md).
* SeaTunnel: a distributed and high-performance data integration platform for data migration and real-time stream processing. For more information, see [Read and synchronize OceanBase data by using SeaTunnel](400.data-ingestion/1300.seatunnel.md). It is currently in the Beta stage and has been tested to some extent. However, it needs to be further adapted.
* Debezium: an open-source distributed platform that monitors database changes and captures data change events in the form of event streams, which are then delivered to various consumers. For more information, see [Connect to OceanBase Database by using Debezium](400.data-ingestion/1600.debezium.md).
