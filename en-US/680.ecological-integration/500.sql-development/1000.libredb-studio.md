# Connect to OceanBase Database in LibreDB Studio

LibreDB Studio is an open-source, self-hosted SQL IDE that runs in the browser. You deploy it once on a server, and team members connect to their databases from a web browser without installing a desktop client. This topic takes a MySQL-compatible tenant of OceanBase Database and the Docker image of LibreDB Studio as an example to describe how to connect to OceanBase Database in LibreDB Studio.

## Prerequisites

* You have deployed LibreDB Studio. For example, run `docker run -p 3000:3000 ghcr.io/libredb/libredb-studio:latest` and open `http://localhost:3000` in a browser. On the first start, the administrator password is printed to the container log. For more information, see the [LibreDB Studio GitHub repository](https://github.com/libredb/libredb-studio).

* The IP address of the OBServer node to be connected has access to the server where LibreDB Studio is deployed.

* You have installed OceanBase Database and created a MySQL-compatible tenant.

## Procedure

### Step 1: Obtain the OceanBase Database connection string

Contact the deployment personnel or administrator of OceanBase Database to obtain the database connection string. For example:

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: the IP address for connecting to OceanBase Database. It is the IP address of OceanBase Database Proxy (ODP) for connection through ODP, or the IP address of an OBServer node for direct connection.
* `$port`: the port for connecting to OceanBase Database. For connection through ODP, the default value is `2883`, which can be customized when ODP is deployed. For direct connection, the default value is `2881`, which can be customized when OceanBase Database is deployed.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user for connecting to a tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on the database. For more information about user privileges, see <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL-compatible mode</a>. </p>
    </main>

* `$user_name`: the tenant account. For connection through ODP, two account formats are supported: `username@tenant name#cluster name` and `cluster name:tenant name:username`. For direct connection, the `username@tenant name` format is supported.
* `$password`: the password of the account.

For more information about the connection string, see [Connect to an OceanBase Database tenant by using OBClient](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md).

**Here is an example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Create an OceanBase connection in LibreDB Studio

1. Open LibreDB Studio in a browser and sign in. If you sign in as an administrator, click **Editor** to open the editor.

2. In the header of the sidebar on the left, click the plus sign (+) to the right of **LibreDB Studio** to open the **New Connection** dialog box.

3. Select **MySQL** as the database type.

4. Specify the following parameters based on the connection string obtained in **Step 1: Obtain the OceanBase Database connection string**.

   |Parameter|Description|
   |-----|----|
   |Connection Name| The name of the custom connection. |
   |Host & Instance| The IP address and the port for connecting to OceanBase Database. Enter the IP address from the `-h` parameter in the first box and the port from the `-P` parameter in the second box. |
   |Username| The username of the account for connecting to OceanBase Database, for example, `root@test`. The value is sourced from the `-u` parameter in the connection string. |
   |Password| The password of the account. The value is sourced from the `-p` parameter in the connection string. |
   |Database Name| The name of the database to be accessed. The value is sourced from the `-D` parameter in the connection string. |

5. Click **Test Connection**. If a message that starts with **Connected successfully** is displayed, the connection is successful.

6. Click **Establish Connection** to save the connection. The connection appears in the sidebar, and the databases of the tenant are listed below it.

## What to do next

After the connection is established, you can run SQL statements in the editor and browse the databases and tables of the tenant in the sidebar. For more information about how to use LibreDB Studio, see the [LibreDB Studio GitHub repository](https://github.com/libredb/libredb-studio).
