# Connect to OceanBase Database by using Navicat

Navicat is a general-purpose database client that uses JDBC drivers provided by various databases to connect to databases. It supports common relational databases, NoSQL databases, and distributed databases.

You can use either the OceanBase driver or the MySQL driver that is built into Navicat to connect to a MySQL tenant of OceanBase Database. This topic describes how to connect to a MySQL tenant of OceanBase Database by using Navicat with the OceanBase driver.

## Prerequisites

* You have obtained and installed Navicat. You can download the corresponding version of Navicat from the [official website of Navicat Premium](https://navicat.com.cn/download/navicat-premium).

* The IP address of the OBServer node to be connected to is reachable from the machine where Navicat is located.

* You have installed OceanBase Database and created a MySQL mode tenant.

## Procedure

### Step 1: Obtain a database connection string

Obtain a database connection string from the deployment personnel or administrator of OceanBase Database. For example:

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**The parameters are described as follows:**

* `$host`: the IP address for connecting to OceanBase Database. For connection through OceanBase Database Proxy (ODP), this parameter is the IP address of an ODP. For direct connection, this parameter is the IP address of an OBServer node.
* `$port`: the port for connecting to OceanBase Database. For connection through ODP, the default value is `2883`, which can be customized when ODP is deployed. For direct connection, the default value is `2881`, which can be customized when OceanBase Database is deployed.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user for connecting to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on the database. For more information about user privileges, see <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL mode</a>. </p>
    </main>

* `$user_name`: the tenant account. For connection through ODP, the tenant account can be in the `username@tenant name#cluster name` or `cluster name:tenant name:username` format. For direct connection, the tenant account is in the `username@tenant name` format.
* `$password`: the account password.

For more information about database connection strings, see [Connect to an OceanBase tenant by using OBClient](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md).

**Here is an example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Connect to OceanBase Database by using the Navicat console

<main id="notice" type='notice'>
    <h4>Note</h4>
    <p>The UI of Navicat of different versions may vary. This topic describes how to connect to OceanBase Database by using Navicat 16.3.7. For other versions, see the documentation of the corresponding version of Navicat. </p>
</main>

1. Click **Connect** <img src=https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-01.png width=8% /> > **<UI-TERM key="ocp-v2.src.constant.credential.ObCluster">OceanBase</UI-TERM>** > **OceanBase Database (MySQL mode)**, and go to the **<UI-TERM key="odc.components.RecordPage.CreateConnection">Create Connection</UI-TERM>** page.

   ![Select your database](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-02.png)

2. On the **<UI-TERM key="odc.components.RecordPage.CreateConnection">Create Connection</UI-TERM>** page, enter the information of the database to be connected to, and then click **<UI-TERM key="oms-cloud.EndpointPublic.components.FormContent.TestConnection">Test Connection</UI-TERM>**.

   ![Test](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-03.png)

   <main id="notice" type='notice'>
       <h4>Note</h4>
       <p>You can connect to the database by using IP direct connection or OceanBase Database Proxy (ODP) proxy. When you connect to the database by using IP direct connection, enter the `mysql_port` parameter for the Port field. The default value is 2881. When you connect to the database by using ODP proxy, enter the `proxy_port` parameter for the Port field. The default value is 2883. </p>
   </main>

4. If **<UI-TERM key="portal.connection.form.test">Test Connection</UI-TERM>** displays **Connected**, the connection is successful. Click **<UI-TERM key="odc.components.CreateSQLPlanTaskModal.Save">Save</UI-TERM>**.

5. Double-click the name of the database in the **Database Navigator** pane. The following figure shows the connection result.

   ![Connection result](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-05.png)
