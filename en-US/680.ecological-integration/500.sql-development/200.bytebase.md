# Manage an OceanBase instance by using Bytebase

Bytebase is an open-source database change management and collaboration tool that provides both a SaaS service and a local deployment version. This topic describes how to manage an OceanBase instance by using Bytebase in MySQL mode.

## Prerequisites

1. Deploy Bytebase. For more information, see [GitHub](https://github.com/bytebase/bytebase).

2. Obtain the connection information of the OceanBase cluster, including the instance name, IP address, port, username, and password. If you want to create a new user, grant permissions to the account based on the Bytebase permission requirements and your business needs. For more information, see [Create a user](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000642577).

## Procedure

1. Log in to the Bytebase console, and follow the prompts to create a new workspace and enter your workspace.
   ![](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/420/zh/20240325.png)

2. Click **Add Instance**. In the dialog box that appears, select **OceanBase (MySQL)**.
    ![](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/420/zh/2024032501.png)

    The following parameters are used as an example.

    ```shell
    obclient -h10.10.10.1 -uusername@obtenant#obdemo -P2883 -p****** -c -A oceanbase
    ```

    |Parameter|Description|
    |-----|-----|
    |Instance Name|Specify the name of the instance. For example, you can enter obdemo.|
    |Environment|Select the test or production environment based on your business needs. For example, you can select the test environment.|
    |Host or Socket|The IP address after the `-h` parameter in the connection string. For example, enter 10.10.10.1.|
    |Port|The port number after the `-P` parameter in the connection string. For example, enter 2883.|
    |Username|The username after the `-u` parameter in the connection string. For example, enter username@obtenant.|
    |Password|The user password after the `-p` parameter in the connection string. For example, enter ******.|

3. Click **<UI-TERM key="ocp-v2.page.External.CreateDrawer.TestConnection">Test Connection</UI-TERM>**. After the connection is established, click **<UI-TERM key="oms-cloud.components.AlertContent.Create">Create</UI-TERM>**.

4. After the instance is created, you can integrate it with GitOps.
   - If you want to enable the GitOps workflow, you can integrate your code repository service, such as GitHub, GitLab, or Bitbucket Cloud, with Bytebase.
   - Configure a Git repository to store database change scripts and submit the changes to the corresponding branch. Bytebase will automatically pull the changes and initiate the approval and release processes.

5. Manage database changes.
   - Create an SQL migration script and submit a change request through the Bytebase console.
   - Participate in the review process to collaborate with other team members to review the SQL changes.
   - After the changes are approved, Bytebase will automatically apply them to the target database within the specified time window.
