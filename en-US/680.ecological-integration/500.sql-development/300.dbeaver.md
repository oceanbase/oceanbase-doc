# Connect to OceanBase Database by using DBeaver

DBeaver is a general-purpose database client that uses JDBC drivers provided by databases to connect to databases. It supports common relational databases, non-relational databases, and distributed databases.

You can use either the OceanBase driver or the MySQL driver provided by DBeaver to connect to a MySQL tenant of OceanBase Database. This topic describes how to connect to a MySQL tenant of OceanBase Database by using DBeaver.

## Prerequisites

* You have obtained and installed DBeaver. You can download the corresponding version of DBeaver from the [official DBeaver download page](https://dbeaver.io/download/).

* The IP address of the target OBServer node is reachable from the server where DBeaver is installed.

* You have installed OceanBase Database and created a MySQL mode tenant.

## Procedure

### Step 1: Obtain a database connection string

Obtain a database connection string from the deployment personnel or administrator of OceanBase Database. For example:

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**The parameters are described as follows:**

* `$host`: the IP address for connecting to OceanBase Database. For connection through OceanBase Database Proxy (ODP), this parameter is the IP address of an ODP. For direct connection, this parameter is the IP address of an OBServer node.
* `$port`: the port for connecting to OceanBase Database. For connection through ODP, the default value is `2883`, which can be customized when ODP is deployed. For direct connection, the default value is `2881`, which can be customized when OceanBase Database is deployed.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user used to connect to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on the database. For more information about user privileges, see [Privilege types in MySQL mode](../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md). </p>
    </main>

* `$user_name`: the tenant account. For connection through ODP, the tenant account can be in the `username@tenant name#cluster name` or `cluster name:tenant name:username` format. For direct connection, the tenant account is in the `username@tenant name` format.
* `$password`: the password of the account.

For more information about connection strings, see [Connect to an OceanBase tenant by using OBClient](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md).

**Here is an example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Connect to OceanBase Database by using the DBeaver console

<main id="notice" type='notice'>
    <h4>Note</h4>
    <p>The user interface of DBeaver may vary across different versions. This topic describes how to connect to OceanBase Database by using DBeaver 22.0.5. For other versions, see the documentation of the corresponding version of DBeaver. </p>
</main>

1. (Optional) Change the driver file version.

   The default driver file for the OceanBase driver in DBeaver is mysql-connector-java-5.1.44. In this topic, the mysql-connector-java-5.1.47 driver file is used as an example. You can perform the following steps to change the driver file.

   1. Download the 5.1.47 driver file from the [official MySQL JDBC driver download page](https://downloads.mysql.com/archives/c-j/).

   2. Click **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.SupspiciousSQL.Database">Database</UI-TERM>** > **Driver Manager**, search for OceanBase, select OceanBase driver, and click **<UI-TERM key="odc.components.UserPage.Editing">Edit</UI-TERM>**. The Edit Driver dialog box appears.

   3. On the **<UI-TERM key="oms-cloud.Detail.components.StructMigration.Schema">Schema</UI-TERM>** tab, select the driver file provided by OceanBase driver and click **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.Delete">Delete</UI-TERM>**.

   4. Click **Add File**, add the downloaded driver file to the database, and click **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.Ok">OK</UI-TERM>**.

2. Click **<UI-TERM key="src.page.Datasource.Datasource.NewDatasourceDrawer.Form.BDA4C2AB">Database</UI-TERM>** > **New Database Connection**, go to the **Select Your Database** page. You can also click **<UI-TERM key="odc.src.constant.label.File">File</UI-TERM>** > ![Connect](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-01.png) to go to the **Select Your Database** page.

   ![Select Your Database](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-02.png)

3. On the **Select Your Database** page, select **<UI-TERM key="ocp-v2.src.constant.credential.ObCluster">OceanBase</UI-TERM>**, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step1.NextStep">Next</UI-TERM>**, go to the **Connection Settings** page, and enter the `Host`, `Port`, `Tenant`, username, and password. Then, click **<UI-TERM key="oms-cloud.EndpointPublic.components.FormContent.TestConnection">Test Connection</UI-TERM>**.

   ![Test](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-03.png)

   <main id="notice" type='notice'>
       <h4>Note</h4>
       <p>You can connect to the database by using IP direct connection or OceanBase Database Proxy (ODP). When you connect by using IP direct connection, the value of the `Port` field is the value of the <code>mysql_port</code> parameter, which is 2881 by default. When you connect by using ODP, the value of the `Port` field is the value of the <code>proxy_port</code> parameter, which is 2883 by default. </p>
   </main>

4. If the **Connection Test** window displays **Connected**, you can click **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.Ok">OK</UI-TERM>** and then click **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>** to connect to OceanBase Database.

   ![Connected](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-04.png)

5. Double-click the name of the database in the **Database Navigation** pane. The following figure shows the database after it is expanded. This indicates that you have successfully connected to OceanBase Database.

   ![Connection result](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-05.png)
