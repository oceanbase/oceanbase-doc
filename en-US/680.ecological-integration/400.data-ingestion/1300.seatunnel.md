# Read and synchronize data from OceanBase Database by using SeaTunnel

SeaTunnel is a distributed and highly scalable data integration platform for transferring data between various data storage systems. It provides easily configurable data stream task plugins that allow users to define data processing and transformation processes. For more information about SeaTunnel, see [GitHub](https://github.com/apache/incubator-seatunnel).

## Prerequisites

Before you start, make sure that:

- You have downloaded SeaTunnel.
- You have installed Java 1.8 or later.
- You have downloaded the MySQL driver and saved it to the `lib` directory.
- You have installed oblogproxy. For more information, see [Install oblogproxy](https://www.oceanbase.com/docs/community-oblogproxy-doc-1000000000438540).

# Read data by using SeaTunnel

This topic describes how to use the MySQL CDC Source Connector of SeaTunnel to execute an SQL query in a MySQL tenant of OceanBase Database. `connector-cdc-mysql` is a plugin of SeaTunnel that captures and streams real-time change data (Change Data Capture, CDC) in a MySQL database.

## Procedure

To synchronize data between MySQL tenants of OceanBase Database, perform the following steps:

1. Create a SeaTunnel user.

   ```sql
    CREATE USER 'username'@'%' IDENTIFIED BY 'password';
    GRANT SELECT ON *.* TO 'username';
   ```

2. Configure `config/plugin_config`.

    Specify `connector-cdc-mysql` and run `sh bin/install-plugin.sh 2.3.3`.

3. Configure SeaTunnel.

    Modify the `config/v2.streaming.conf.template` file:

    ```yml
    source {
    # This is a example source plugin **only for test and demonstrate the feature source plugin**
    MySQL-CDC {
    result_table_name = "fake"
    parallelism = 1
    server-id = 5656
    username = "username"
    password = "password"
    table-names = ["seatunnel.full_types"]
    base-url = "jdbc:mysql://xx.xxx.x.xx:2881/seatunnel"
    }

    # If you would like to get more information about how to configure SeaTunnel and see full list of source plugins,
    # please go to https://seatunnel.apache.org/docs/category/source-v2
    }
    ```

4. Start SeaTunnel.

    Run the following command to start SeaTunnel:

    ```shell
    ./bin/seatunnel.sh --config ./config/v2.streaming.conf.template -e local
    ```

# Synchronize data by using SeaTunnel

This topic describes how to use the JDBC OceanBase Source Connector and JDBC OceanBase Sink Connector of SeaTunnel to synchronize data. The JDBC OceanBase Source Connector supports full data read and write for a single table in OceanBase Database. For more information, see [JDBC OceanBase Source Connector](https://seatunnel.apache.org/docs/2.3.3/connector-v2/source/OceanBase/). The JDBC OceanBase Sink Connector supports full data read and write for multiple tables in OceanBase Database. For more information, see [JDBC OceanBase Sink Connector](https://seatunnel.apache.org/docs/2.3.3/connector-v2/sink/OceanBase/).

## Procedure

To synchronize data between MySQL tenants of OceanBase Database, perform the following steps:

1. Create a SeaTunnel user.

   ```sql
    CREATE USER 'username'@'%' IDENTIFIED BY 'password';
    GRANT SELECT, INSERT, UPDATE, DELETE ON *.* TO 'username';
   ```

2. Configure `config/plugin_config`.
3. Download the OceanBase JDBC driver to the `lib` directory. For more information, see [OceanBase Client](https://mvnrepository.com/artifact/com.oceanbase/oceanbase-client).
4. Configure SeaTunnel.

    Modify the `config/ob_to_ob` file:

    ```yml
    env {
    parallelism = 1
    job.mode = "BATCH"
    }

    source {
    # This is a example source plugin **only for test and demonstrate the feature source plugin**
    Jdbc {
        driver = com.oceanbase.jdbc.Driver
        url = "jdbc:oceanbase://e2e_oceanbase_mysql:2881/seatunnel?useUnicode=true&characterEncoding=UTF-8&rewriteBatchedStatements=true&serverTimezone=UTC"
        user = "username"
        password = "password"
        query = "SELECT c_bit_1, c_bit_8 FROM source"
        compatible_mode = "mysql"
    }

    # If you would like to get more information about how to configure seatunnel and see full list of source plugins,
    # please go to https://seatunnel.apache.org/docs/connector-v2/source/FakeSource
    }

    sink {
    Jdbc {
        driver = com.oceanbase.jdbc.Driver
        url = "jdbc:oceanbase://e2e_oceanbase_mysql:2881/seatunnel?useUnicode=true&characterEncoding=UTF-8&rewriteBatchedStatements=true&serverTimezone=UTC"
        user = "username"
        password = "password"
        query = "insert into sink(c_bit_1, c_bit_8) values (?, ?);"
        compatible_mode = "mysql"
    }
    # If you would like to get more information about how to configure seatunnel and see full list of sink plugins,
    # please go to https://seatunnel.apache.org/docs/connector-v2/sink
    }
    ```

5. Start SeaTunnel.

    Run the following command to start SeaTunnel:

    ```shell
    ./bin/seatunnel.sh --config ./config/ob_to_ob -e local
    ```
