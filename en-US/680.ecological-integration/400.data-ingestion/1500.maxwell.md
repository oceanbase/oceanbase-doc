# Read data from OceanBase Database using Maxwell

Maxwell is an application that reads MySQL Binlog and converts it into JSON format. It is designed to capture all data change events in a database. This topic describes how to use Maxwell to output data from a MySQL tenant of OceanBase Database in JSON format.

## Prerequisites

Before you start, make sure that the following conditions are met:

- You have installed oblogproxy. For more information, see [Install oblogproxy](https://www.oceanbase.com/docs/community-oblogproxy-doc-1000000000438540).
- You have installed Java 1.8 or later.
- You have downloaded Maxwell. For more information, see [Maxwell on GitHub](https://github.com/zendesk/maxwell/releases).

## Procedure

1. Configure Maxwell.
   Edit the `config.properties` file in the Maxwell directory. If the file does not exist, copy the `config.properties.example` file and edit it.

    ```yml
    user=maxwell
    password=yourpassword
    host=the address of the source MySQL server of OceanBase Database
    producer=stdout
    ```

    This configuration sets Maxwell to output events to standard output (the console). To send data to other destinations such as Kafka, change the producer attribute and related configurations.

2. Start Maxwell.

    Run the following command to start Maxwell:

    ```shell
    bin/maxwell --config config.properties
    ```

3. View data changes.
   Change data (such as insert, update, and delete data) in OceanBase Database and observe the JSON data output by Maxwell. The command in step 3 sets Maxwell to output data to standard output (stdout). The possible return result is as follows:

   ```shell
    {
    "database": "mydb",
    "table": "mytable",
    "type": "insert",
    "ts": 1589372847,
    "xid": 12345678,
    "commit": true,
    "data": {
        "id": 1,
        "column1": "value1",
        "column2": "value2"
    }
    }
   ```

    The return result indicates that an insert operation is performed on the `mydb.mytable` table.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>OceanBase Database supports the Latin character set from V4.1.0. If you use an earlier version of OceanBase Database as the metadata database for Maxwell, you must manually build the metadata tables of Maxwell. </p>
</main>

For example, the following statement deletes the latin1 character set from the CREATE TABLE statement of Maxwell.

```sql
CREATE TABLE IF NOT EXISTS `databases` (
  id        bigint auto_increment NOT NULL primary key,
  schema_id bigint,
  name      varchar(255) charset 'utf8',
  charset   varchar(255),
  index (schema_id)
);
```

For convenience, this topic provides only one example. Perform the same operation on other metadata tables.
