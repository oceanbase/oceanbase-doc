# Synchronize OceanBase data using Dataphin

## Overview

Dataphin is a cloud-based implementation of the OneData data governance methodology used internally by Alibaba Group. It provides a comprehensive set of big data capabilities for the entire lifecycle of data collection, construction, management, and utilization. This helps enterprises significantly improve their data governance levels and build enterprise-grade data middleware platforms that are reliable, convenient, and secure.

This topic describes how to configure an OceanBase Database data source in Dataphin to integrate offline and real-time data.

## Version compatibility

- OceanBase Database version: ≥ V4.2.1.

## Prerequisites

Before you use Dataphin, make sure that:

- You have an [Dataphin account](https://dataphin.console.aliyun.com/workingArea).
- You have deployed OceanBase Database and created a MySQL compatible user tenant. For more information about how to create a user tenant, see <a href="../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md">Create a tenant</a>.
- You have enabled the Binlog service in the MySQL compatible user tenant. For more information, see <a href="../../700.reference/1500.Components-and-Tools/300.data-integrate/100.oblogproxy-overview.md">OceanBase Binlog service</a>.

## Procedure

### Step 1: Obtain the database connection string

Contact the OceanBase Database deployment personnel to obtain the connection string, for example:

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**
* `$host`: the IP address for connection. For ODP connection, use the ODP IP address. For direct connection, use the OBServer IP address.
* `$port`: the connection port. For ODP connection, the default value is `2883`. For direct connection, the default value is `2881`.
* `$database_name`: the database name.
    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user used to connect to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on the database. For more information about user privileges, see <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL mode</a>. </p>
    </main>
* `$user_name`: the connection account. For ODP connection, the format is `user@tenant#cluster` or `cluster:tenant:user`. For direct connection, the format is `user@tenant`.
* `$password`: the account password.

For more information about the connection string, see <a href="../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md">Connect to an OceanBase tenant by using OBClient</a>.

**Here is an example:**
```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Configure a Dataphin compute task

Dataphin allows you to synchronize offline data from an OceanBase data source and process real-time data by connecting to OceanBase through a MySQL data source. It is suitable for enterprise data warehouse construction, data lake building, and real-time data analysis.

#### Offline compute task

You can directly connect to an OceanBase data source to create an offline compute task.

1. In the Dataphin management center, click **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** and then click **<UI-TERM key="dss.List.NewBtn.NewDataSource">Create Data Source</UI-TERM>**. Select **OceanBase**.
2. Fill in the OceanBase database information (obtained in step 1) and click **<UI-TERM key="oms-cloud.EndpointPublic.components.FormContent.TestConnection">Test Connection</UI-TERM>** to verify the connection.
3. In the management center, click **<UI-TERM key="src.component.WorkflowDag.DE9C6691">Data Integration</UI-TERM>** and select **Offline Pipeline** to create a task.
4. Select **Manual Node** (for testing) or **Periodic Node** (for regular execution).
5. In the component library, you can select an existing OceanBase data source as the input or output.
6. After the configuration is complete, click **<UI-TERM key="odc.components.ImportDrawer.Submit">Submit</UI-TERM>** and then click **Go to O&M** to go to the development page.
7. Click **<UI-TERM key="src.component.EditorToolBar.actions.C07F15B8">Run</UI-TERM>** to execute the data migration task.

<main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Each execution of an offline compute task collects full data. If the data does not exist in the target table, it is inserted. If the data exists, it is not inserted. </p>
</main>

#### Real-time compute task

To create a real-time compute task, you must connect to OceanBase through a MySQL data source. It supports full and incremental data collection.

1. In the Dataphin management center, click **System Settings** and then click **Real-time Compute Engine**. Select **Flink**.
2. Click **<UI-TERM key="oms-v2.utils.hooks.useLayoutMenus.DataSourceManagement">Data Source Management</UI-TERM>** and then click **<UI-TERM key="dss.List.NewBtn.NewDataSource">Create Data Source</UI-TERM>**. Select **MySQL**.
3. Fill in the OceanBase connection information:

| Parameter | Required | Default Value | Type | Description |
|--------|------|--------|------|------|
| JDBC URL | Yes | N/A | String | `jdbc:mysql://$host:$port/$database_name` |
| Username | Yes | N/A | String | `$user_name` |
| Password | Yes | N/A | String | `$password` |
| Version | Yes | N/A | String | MySQL 5.6/5.7 |

4. Click **<UI-TERM key="src.page.ExternalIntegration.SSO.NewSSODrawerButton.SSOForm.DCF54625">Test Connection</UI-TERM>** to verify the connection.
5. On the development page, click **+** and select **Metadata Table**. Fill in the metadata table name and select the data source.
6. Click **<UI-TERM key="oat.ProductManage.CreatePage.Submit">Submit</UI-TERM>** and then select **Compute Task**.
7. Create an **Flink SQL** task and fill in the relevant information.
8. Click **<UI-TERM key="oms-v2.JDBCWriter.New.Submitted">Submit</UI-TERM>** and then click **Go to O&M** to go to the real-time compute page.
9. On the real-time compute page, you can edit and execute Flink SQL statements to process data in real time.

<main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Dataphin does not support directly selecting OceanBase as a data source for real-time compute. In Flink, the OceanBase connector can only be used as a destination table or dimension table, not as a source table. </p>
</main>
