# Manage an OceanBase data source by using NineData

NineData Database DevOps provides powerful features such as data asset management, data query, SQL execution, data editing, data import and export, SQL approval flow, SQL specification precheck, approval process, and sensitive data protection, helping you quickly manage data in various environments.

## Prerequisites

* You have registered a NineData account. For more information, see [Register a NineData account](https://console.ninedata.cloud/user/register).
* You have installed OceanBase Database.
* You have the read-only, DML, or DDL privilege on the target data source.
* In the pay-as-you-go version (Professional Edition and Enterprise Edition), your subscription is not expired. Otherwise, you cannot use the Database DevOps service.

## Procedure

### Step 1: Obtain the connection information of OceanBase Database

Obtain the database connection information from the deployment personnel or administrator of OceanBase Database.

```sql
obclient -hxx.xx.xx.xx -P2883 -uroot@mysql#cluster -p**** -A
```

### Step 2: Add an OceanBase for MySQL data source

1. Log in to the [NineData](https://console.ninedata.cloud) console.
2. In the left-side navigation pane, choose **<UI-TERM key="odc.Record.RecordPage.interface.DataSourceManagement">Data source management</UI-TERM>** > **<UI-TERM key="odc.PermissionApplication.CreateModal.DataSource">Data Source</UI-TERM>**.

    ![](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.2/1..png)

3. On the **<UI-TERM key="src.component.Task.component.CommonDetailModal.AB5C26BA">Data Source</UI-TERM>** tab, click **<UI-TERM key="odc.Record.RecordPage.interface.CreateADataSource">Create a data source</UI-TERM>** in the upper-right corner. In the data source type window that appears, select **<UI-TERM key="oms-cloud.src.constants.endpoint.SelfBuiltDatabase">Self-managed database</UI-TERM>** > **OceanBase for MySQL**, and configure the parameters on the **<UI-TERM key="odc.Record.RecordPage.interface.CreateADataSource">Create a data source</UI-TERM>** page as described in the following table.

    ![](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.2/2.png)

    **The following table describes the parameters.**

    |Parameter|Description|

    |Connection Method|Specify the method for connecting to the data source.     |Parameters for connecting through a public IP address|Public IP Address: The public IP address and port of the data source.|
    |Parameters for connecting through a gateway|<ul><li>Gateway: Select the NineData gateway installed on the host of the data source. </li><li>Public IP Address: Specify the public IP address or the internal IP address of the host of the data source. </li>|

If no password is specified when the key file is generated, leave this field blank. </li><main id="notice" type='explain'><h4>Note</h4><p>After you configure the SSH settings, click Connect Test in the upper-right corner.     |Database Username|The username of the data source.|
    |Database Password|The password of the data source.|

    |SSL|Specify whether to use SSL for data source access (the default is Yes). If the data source requires an SSL connection, you must select Yes. 4. To ensure that the service can connect to the data source, select the region where the data source is located on the **<UI-TERM key="odc.Record.RecordPage.interface.CreateADataSource">Create a data source</UI-TERM>** page, and add the IP address of the NineData service in the preceding figure to the white list of your server.

    ![](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.2/3.png)

5. After all the configurations are completed, click **<UI-TERM key="odc.Record.RecordPage.interface.CreateADataSource">Create a data source</UI-TERM>** in the upper-right corner. If the connection test is successful, click **<UI-TERM key="odc.Record.RecordPage.interface.CreateADataSource">Create a data source</UI-TERM>** to add the data source. Otherwise, check the connection settings and try again until the connection test is successful.
