### Step 1: Obtain the connection string of OceanBase Database

1. Contact the deployment personnel or administrator of OceanBase Database to obtain the database connection string.

    ```shell
    obclient -hxx.xx.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. Fill in the corresponding information in the URL below based on the deployed OceanBase Database.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The URL information is required in the <code>hibernate.cfg.xml</code> file. </p>
    </main>

    ```java
    jdbc:oceanbase://host:port/schema_name?user=$user_name&password=$password
    ```

    **The parameters are described as follows:**

    * `host`: the IP address for connecting to OceanBase Database. It is the IP address of an OceanBase Database Proxy (ODP) node for ODP connection, or the IP address of an OBServer node for direct connection.
    * `port`: the port for connecting to OceanBase Database. It is `2883` by default for ODP connection, which can be customized when ODP is deployed; it is `2881` by default for direct connection, which can be customized when OceanBase Database is deployed.
    * `schema_name`: the name of the schema to be accessed.
    * `user_name`: the username specified with the `-u` parameter in the format of **username@tenant name#cluster name** or **username@SERVICE:service name**. When the username is specified in the format of **username@tenant name#cluster name**, the default tenant is `sys`, and the administrator user is `root`. When you connect to the database directly, you can skip the cluster name, but you must specify the cluster name when you connect to the database through ODP.
    * `password`: the account password.

For more information about URL parameters, see [Database URL](https://www.oceanbase.com/docs/common-oceanbase-connector-j-cn-10000000001943209).

### Code in the User.hbm.xml file

The `User.hbm.xml` file is a Hibernate mapping file that maps Java objects to tables in the database.

The code in the `User.hbm.xml` file mainly includes the following parts:

1. Declaration statement.

    Declare the file to be an XML file that uses XML standard `1.0` and character encoding `UTF-8`. At the same time, specify the DTD version and URL of the Hibernate mapping file, set the DTD document type to `hibernate-mapping`, set the version to 3.0, set the language to EN, and set the URL of the file to `http://www.hibernate.org/dtd/hibernate-mapping-3.0.dtd`.

    **The sample code is as follows:**

    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE hibernate-mapping PUBLIC
            "-//Hibernate/Hibernate Mapping DTD 3.0//EN"
            "http://www.hibernate.org/dtd/hibernate-mapping-3.0.dtd">
    ```

2. Configure the mapping file.

    Define a Hibernate mapping file to map the `User` entity class to the `test_hibernate_mysql` table in the database.
    1. Use the `package` attribute to set the Java package in the mapping file to `com.oceanbase.pojo`.
    2. Use the `class` tag to map the data in the data table, set the `name` attribute to `User`, and set the `table` attribute to `test_hibernate_mysql`.
    3. Use the `id` tag to define the primary key attribute, set the `name` attribute to the member variable `id` of the `User` class, and set the `column` attribute to the field name `USER_ID`.
    4. Use the `generator` tag to define the primary key generation strategy, set the `class` attribute to `sequence`, set the `param` element to the sequence name `SQ_USER` in the database, set the `name` attribute to the `USER_NAME` column in the corresponding database table, and set the data type of the attribute to string.

    **The sample code is as follows:**

    ```xml
    <hibernate-mapping package="com.oceanbase.pojo">
    <class name="User" table="test_hibernate_mysql">
        <!-- Configure primary key generation strategy -->
        <id name="id" column="USER_ID">
            <generator class="sequence">
                <param name="sequence">SQ_USER</param>
            </generator>
        </id>
        <!-- Configuration Tables and Properties -->
        <property name="name" column="USER_NAME" type="string"/>
    </class>
    </hibernate-mapping>
    ```

   The <hibernate-configuration> root element contains the <session-factory> element, which is used to set the Hibernate session factory. The session factory is used to create and manage session objects. The session factory includes the driver class name, URL, username, and password for connecting to the database, parameters for the connection pool, database dialect, SQL output and formatting, automatic creation of database tables, current session context, batch processing, and second-level cache.

### UserDao.java code

The `UserDao.java` file uses the user data access object (DAO) class and the session object to implement the CRUD operations on user data.

The code in the `UserDao.java` file mainly includes the following parts:

    * `Session` class: used for interacting with the database.
    * `SessionFactory` class: used for creating session instances.
    * `Transaction` class: used for managing database transactions.
    * `Configuration` class: used for loading the Hibernate configuration file.
    * `Query` class: used for executing query operations.
    * `List` interface: used for operating the query result set.

    **The sample code is as follows:**

    import com.oceanbase.pojo.User;

    import org.hibernate.SessionFactory;
    import org.hibernate.Transaction;
    import org.hibernate.cfg.Configuration;
    import org.hibernate.query.Query;
    import java.util.List;

2. Define the `UserDao` class.

  The `UserDao` class is defined as a data access object in the Java class to persist user objects. The class encapsulates methods for interacting with the database and provides methods for adding, deleting, modifying, and querying user objects. By calling the methods in the `UserDao` class, you can interact with the database and perform persistence operations.

  1. Initialize an instance of the `UserDao` class.

     Use an object initialization block to initialize the `Session` object during the instantiation of the class.

     First, create a `Configuration` object and call the `configure` method to read the Hibernate configuration file (`hibernate.cfg.xml`). Then, call the `buildSessionFactory` method to create a `SessionFactory` object. Finally, call the `openSession` method to create a `Session` object and assign it to the `session` variable.

      **The sample code is as follows:**

      ```java
      private Session session;
      {
          Configuration cfg = new Configuration().configure();
          // Create SessionFactory
          SessionFactory sessionFactory = cfg.buildSessionFactory();
          session = sessionFactory.openSession();
      } //Read the hibernate.cfg.xml file
      ```

  2. Query user information based on the ID.

     Call the `selectUserById` method to query user information based on the ID.

     Use the `get` method of the `session` object to query the `User` record with the specified ID from the database and store it in the `user` variable.

     **The sample code is as follows:**

      ```java
      public User selectUserById(int ID) {
          User user = session.get(User.class, ID);
          return user;
      }
      ```

  3. Query user information based on the username.

     Call the `selectUserbyName` method to query user information based on the username.
     Define an HQL (Hibernate Query Language) statement to query user data with the specified username. The table name is `test_hibernate_mysql`, the alias is `u`, and the query field name is `name`. Use the `createQuery` method of the `Session` object to create a `Query` object and pass the HQL statement and entity class as parameters. Use the `setParameter` method of the `Query` object to set the query parameters, where `0` indicates the parameter position and `name` indicates the parameter value. Use the `list` method of the `Query` object to execute the query and convert the query result to a `User` object list.

     **The sample code is as follows:**

      ```java
      public List<User> selectUserbyName(String name) {
        String sql = "FROM test_hibernate_mysql u WHERE u.name =?";
        Query<User> query = session.createQuery(sql, User.class);
        query.setParameter(0, name);
        List<User> users = query.list();
        return users;
      }
      ```

  4. Query all user data.

     Call the `selectUser` method to query all user data.
