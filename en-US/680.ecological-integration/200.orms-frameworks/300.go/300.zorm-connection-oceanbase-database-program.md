# Connect to OceanBase Database by using zorm

zorm is a lightweight ORM framework for Go based on native SQL, designed for Go applications. It provides the following features:

* Constructs SQL statements by using `Finder`, retaining the flexibility of native SQL with a low learning curve.
* The core library has no dependencies, and database drivers are imported on demand.
* Uses `context.Context` for transaction propagation and supports multiple data sources and read/write splitting.
* Supports MySQL, PostgreSQL, Oracle, SQLite, and other databases.

This topic describes how to use zorm to connect to OceanBase Database and perform basic database operations, including creating tables, inserting data, updating data, querying data, and deleting data.

<main id="notice" type='explain'>
  <h4>Applicability</h4>
  <p>zorm ORM is applicable to OceanBase Database in MySQL mode.</p>
</main>

## Prerequisites

* Go 1.13 or later is installed.
* OceanBase Database is installed and a MySQL-mode tenant is created.
* The OceanBase Database connection string is obtained.

## Procedure

1. Obtain the OceanBase Database connection string.
2. Install Go and zorm.
3. Create the `main.go` file to implement database operations.
4. Run the program and verify the result.

### Step 1: Obtain the OceanBase Database connection string

Contact the OceanBase Database deployment personnel or administrator to obtain the required database connection string.

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: the IP address for connecting to OceanBase Database. For an OceanBase Database Proxy (ODP) connection, use an ODP address. For a direct connection, use the IP address of an OBServer node.
* `$port`: the port for connecting to OceanBase Database. The default port for an ODP connection is `2883`, which can be customized when ODP is deployed. The default port for a direct connection is `2881`, which can be customized when OceanBase Database is deployed.
* `$database_name`: the name of the database to access.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user that connects to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>UPDATE</code>, <code>SELECT</code>, and <code>DELETE</code> privileges on the database. For more information about user privileges, see <a href="../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL mode</a>.</p>
    </main>

* `$user_name`: the account for connecting to the tenant. The common ODP connection formats are `username@tenant_name#cluster_name` and `cluster_name:tenant_name:username`. The direct connection format is `username@tenant_name`.
* `$password`: the account password.

For more information about the connection string, see [Connect to an OceanBase tenant by using OBClient](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md).

**Example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Install Go and zorm

If Go is already installed, you can skip Step 1 (Install Go) only. You must still create a working directory, initialize the Go module, and install the example's dependencies in Step 2, even if you have used zorm in another project.

1. Install Go.

    1. Update system packages and install the required dependencies:

        ```bash
        sudo apt update
        sudo apt install -y wget
        ```

    2. Download and install Go:

        ```bash
        # Download Go 1.25.14 (1.25.14 is used as an example. Visit https://go.dev/dl/ for the latest version.)
        wget https://go.dev/dl/go1.25.14.linux-amd64.tar.gz

        # Extract the package to /usr/local.
        sudo tar -C /usr/local -xzf go1.25.14.linux-amd64.tar.gz

        # Delete the installation package.
        rm go1.25.14.linux-amd64.tar.gz
        ```

    3. Configure environment variables:

        ```bash
        # Edit the ~/.bashrc file.
        echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
        echo 'export GOPATH=$HOME/go' >> ~/.bashrc
        echo 'export PATH=$PATH:$GOPATH/bin' >> ~/.bashrc

        # Apply the configuration.
        source ~/.bashrc
        ```

    4. Verify the installation:

        ```bash
        go version
        ```

        If the installation is successful, output similar to the following is displayed:

        ```bash
        go version go1.25.14 linux/amd64
        ```

2. Install zorm and the MySQL driver.

    1. Create a working directory and initialize the Go module:

       ```bash
       mkdir -p ~/go/src/zorm-oceanbase
       cd ~/go/src/zorm-oceanbase
       go mod init zorm-oceanbase
       ```

    2. Install zorm and the MySQL driver:

       ```bash
       go get gitee.com/chunanyong/zorm
       go get github.com/go-sql-driver/mysql@v1.7.1
       ```

    3. (Optional) If the packages cannot be installed directly due to network issues, set the Go proxy:

       ```bash
       go env -w GOPROXY=https://goproxy.cn,direct
       ```

       Then run the installation commands again.

3. Verify the installation:

    ```bash
    go list -m gitee.com/chunanyong/zorm
    go list -m github.com/go-sql-driver/mysql
    ```

    If the installation is successful, the corresponding version information is displayed.

### Step 3: Create the main.go file and implement database operations

zorm does not provide automatic migration, and write operations such as `Insert`, `Update`, and `Delete` must be explicitly executed within `zorm.Transaction`. This example creates the `users` table by using `UpdateFinder` and completes data writes within a transaction. In a production environment, use a database version management tool to maintain the table schema.

Replace the DSN in the following code with the connection information obtained in Step 1, and save the code as `main.go`. Make sure the username, tenant name, database name, and port match the connection string in Step 1.

1. Create a file named `main.go` and add the following code:

    ```go
    package main

    import (
        "context"
        "fmt"
        "log"
        "time"

        "gitee.com/chunanyong/zorm"
        _ "github.com/go-sql-driver/mysql"
    )

    const usersTableName = "users"

    // User defines the user model.
    type User struct {
        zorm.EntityStruct

        ID        int64     `column:"id"`
        Username  string    `column:"username"`
        Email     string    `column:"email"`
        Age       int       `column:"age"`
        CreatedAt time.Time `column:"created_at"`
        UpdatedAt time.Time `column:"updated_at"`
    }

    // GetTableName specifies the table name.
    func (u *User) GetTableName() string {
        return usersTableName
    }

    // GetPKColumnName specifies the primary key column name.
    func (u *User) GetPKColumnName() string {
        return "id"
    }

    // initDB initializes the database connection.
    func initDB() error {
        config := zorm.DataSourceConfig{
            // parseTime=true in the DSN automatically converts time types to time.Time, and loc=Local sets the time zone.
            DSN:                   "root@mysql001:**********@tcp(xxx.xxx.xxx.xxx:2881)/db_test?charset=utf8mb4&parseTime=true&loc=Local",
            DriverName:            "mysql",
            Dialect:               "mysql",
            MaxOpenConns:          50,
            MaxIdleConns:          20,
            ConnMaxLifetimeSecond: 600,
            SlowSQLMillis:         -1,
        }

        if _, err := zorm.NewDBDao(&config); err != nil {
            return fmt.Errorf("failed to initialize zorm: %w", err)
        }
        return nil
    }

    // createTable creates the users table.
    func createTable(ctx context.Context) error {
        const ddl = `CREATE TABLE IF NOT EXISTS users (
            id BIGINT NOT NULL AUTO_INCREMENT,
            username VARCHAR(100) NOT NULL,
            email VARCHAR(100) NOT NULL,
            age INT NOT NULL DEFAULT 0,
            created_at DATETIME NOT NULL,
            updated_at DATETIME NOT NULL,
            PRIMARY KEY (id)
        ) DEFAULT CHARSET = utf8mb4`

        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.UpdateFinder(ctx, zorm.NewFinder().Append(ddl))
            return nil, err
        })
        return err
    }

    // createUser inserts user data.
    func createUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Insert(ctx, user)
            return nil, err
        })
        return err
    }

    // getUserByID queries a user by primary key.
    func getUserByID(ctx context.Context, id int64) (*User, error) {
        user := &User{}
        finder := zorm.NewSelectFinder(usersTableName).Append("WHERE id = ?", id)
        has, err := zorm.QueryRow(ctx, finder, user)
        if err != nil {
            return nil, err
        }
        if !has {
            return nil, fmt.Errorf("user %d does not exist", id)
        }
        return user, nil
    }

    // updateUser updates user data.
    func updateUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Update(ctx, user)
            return nil, err
        })
        return err
    }

    // listUsers queries the user list.
    func listUsers(ctx context.Context) ([]User, error) {
        users := make([]User, 0)
        finder := zorm.NewSelectFinder(usersTableName).Append("ORDER BY id")
        if err := zorm.Query(ctx, finder, &users, nil); err != nil {
            return nil, err
        }
        return users, nil
    }

    // deleteUser deletes user data.
    func deleteUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Delete(ctx, user)
            return nil, err
        })
        return err
    }

    func main() {
        ctx := context.Background()

        // Initialize the database connection.
        if err := initDB(); err != nil {
            log.Fatal(err)
        }
        fmt.Println("zorm initialized successfully")

        // Create the data table.
        if err := createTable(ctx); err != nil {
            log.Fatalf("Failed to create the data table: %v", err)
        }
        fmt.Println("Data table created successfully")

        // Insert a user record.
        now := time.Now()
        user := &User{
            Username:  "oceanbase_user",
            Email:     "zorm@oceanbase.com",
            Age:       28,
            CreatedAt: now,
            UpdatedAt: now,
        }
        if err := createUser(ctx, user); err != nil {
            log.Fatalf("Failed to insert data: %v", err)
        }
        fmt.Printf("Inserted successfully, ID: %d\n", user.ID)

        // Query user data.
        queried, err := getUserByID(ctx, user.ID)
        if err != nil {
            log.Fatalf("Failed to query data: %v", err)
        }
        fmt.Printf("Queried successfully: ID=%d, Username=%s, Age=%d\n", queried.ID, queried.Username, queried.Age)

        // Update user data.
        queried.Age = 29
        queried.UpdatedAt = time.Now()
        if err := updateUser(ctx, queried); err != nil {
            log.Fatalf("Failed to update data: %v", err)
        }
        fmt.Println("Updated successfully")

        // Query the user list.
        users, err := listUsers(ctx)
        if err != nil {
            log.Fatalf("Failed to query the list: %v", err)
        }
        fmt.Printf("Found %d record(s)\n", len(users))
        for _, item := range users {
            fmt.Printf("ID=%d, Username=%s, Age=%d\n", item.ID, item.Username, item.Age)
        }

        // Delete user data.
        if err := deleteUser(ctx, queried); err != nil {
            log.Fatalf("Failed to delete data: %v", err)
        }
        fmt.Println("Deleted successfully")
    }
    ```

### Step 4: Run the program and verify the result

1. Run the program:

    ```bash
    cd ~/go/src/zorm-oceanbase
    go run main.go
    ```

2. If the `go: command not found` error occurs, make sure that the Go environment variables are correctly set as described in Step 2.

3. After the program finishes running, output similar to the following is displayed:

    ```bash
    zorm initialized successfully
    Data table created successfully
    Inserted successfully, ID: 1
    Queried successfully: ID=1, Username=oceanbase_user, Age=28
    Updated successfully
    Found 1 record(s)
    ID=1, Username=oceanbase_user, Age=29
    Deleted successfully
    ```

    `ID` is an auto-increment primary key, so its value increases when you run the example again.
