## Procedure

<main id="notice" type='explain'>
  <h4>Note</h4>

### Step 1: (Optional) Install Go and the driver

If you have already installed Go and the Go-SQL-Driver/MySQL driver, skip this step. Otherwise, perform the following steps.

1. Install Go

    1. Download the Go installation package: You can download the installation package for your operating system from [the official website of Go](https://golang.org/dl/).

        <main id="notice" type='explain'>
         <h4>Note</h4>
         <p>The Go installation package used in this topic is named go1.20.6.windows-amd64.msi. </p>
        </main>

    2. Install Go: Double-click the downloaded installation package and follow the instructions to install it.

    3. Configure the environment variables: Add the installation path of Go to the system PATH environment variable.
       * In the Windows environment, you can add the value of `C:\usr\local\go\bin` to the Path variable in **Control Panel > System and Security > System > Advanced System Settings > Environment Variables > System Variables**.
       * In the Linux or macOS environment, you can edit the `~/.bashrc` or `~/.bash_profile` file and add the following content:

            ```shell
            export PATH=$PATH:/usr/local/go/bin
            ```

        <main id="notice" type='explain'>
         <h4>Note</h4>
         <p><code>\usr\local\go\bin</code> is the default installation directory. If you have modified the installation directory when installing Go, replace it with the corresponding directory. </p>
        </main>

    4. Verify the installation: Enter the following command in the shell command line to view the version information of Go and verify whether the installation is successful:

        ```shell
        C:\Users\admin\> go version
        go version go1.20.6 windows/amd64
        ```

2. Install the Go-SQL-Driver/MySQL driver

    You can choose different installation methods based on the version of Go. You need to open a command-line terminal in the corresponding project directory when you install the Go-SQL-Driver/MySQL driver. For more information about `Go-SQL-Driver/MySQL`, visit [Github](https://github.com/go-sql-driver/mysql).

    The installation command is as follows:

    ```shell
    C:\Users\admin\Desktop\go-oceanbase>go get -u github.com/go-sql-driver/mysql
    go: downloading github.com/go-sql-driver/mysql v1.7.1
    go: added github.com/go-sql-driver/mysql v1.7.1
    ```

    If you cannot install `go-sql-driver/mysql` by using the `go get` command due to version or network issues, you can use the `go install` command to install it.

   1. Clone the `go-sql-driver/mysql` repository from GitHub to the `go/src` directory.

        ```bash
        cd /usr/local/go/src   
        git clone https://github.com/go-sql-driver/mysql.git
        ```

        <main id="notice" type='notice'>
            <h4>Notice</h4>
            <p><code>/usr/local/go/src</code> must be replaced with the actual installation directory of Go. </p>
        </main>

   2. Run the `go install` command.

        ```bash
        go install mysql
        ```

        <main id="notice" type='notice'>
            <h4>Notice</h4>
            <p>The default execution directory of <code>go install</code> may not be <code>/src</code>. You can determine the actual directory based on the error message after you run <code>go install</code>. For example, if the error message is <code>cannot find package &quot;mysql&quot; in: /usr/local/go/src/vendor/mysql</code>, you should place the mysql folder in the <code>/src/vendor</code> directory and then run the installation command. </p>
        </main>

   3. Check whether the Go-SQL-Driver/MySQL driver is installed. If the installation fails, modify the parameters based on the error message.

        ```bash
        go list -m github.com/go-sql-driver/mysql
        ```

### Step 2: Obtain the connection information of OceanBase Database

Obtain the database connection information from the deployment personnel or administrator of OceanBase Database.

```sql
obclient  -h{host} -u{user_name} -p****** -P{port} -D{schema_name}
```

The database connection string contains the parameters required for accessing the database. You can log in to the database by using the database connection string to verify whether the parameters are correct.

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>The URL information in this topic is required in the <code>test.go</code> file. </p>
</main>

**The parameters are described as follows:**

* `host`: the IP address for connecting to OceanBase Database. For connection through ODP, this is the IP address of an ODP; for direct connection, this is the IP address of an OBServer node.
* `user_name`: the tenant account. For connection through ODP, the tenant account can be in the `username@tenant name#cluster name` or `cluster name:tenant name:username` format; for direct connection, the tenant account is in the `username@tenant name` format.
* `password`: the account password.
* `port`: the port for connecting to OceanBase Database. For connection through ODP, the default value is `2883`, which can be customized when ODP is deployed; for direct connection, the default value is `2881`, which can be customized when OceanBase Database is deployed.
* `schema_name`: the name of the schema to be accessed.

### test.go code

The `test.go` file defines how to use the Go-SQL-Driver/MySQL driver to connect to a MySQL database and use the APIs provided by GORM to operate the database.
The `test.go` file contains the following information:

1. Define the `main` package.
     The `package main` statement indicates that this is a package of an executable program, which contains a `main()` function that is executed when the program is run.

2. Define the `import` packages.

    The `import` statements import the following packages:

    * `fmt`: provides functions for formatted input and output. It defines a set of functions for formatting data into strings and outputting them to the console or other devices.
    * `time`: provides time-related functions and types.
    * `os`: provides operating system-related functions and types.
    * `gorm.io/driver/mysql`: the MySQL driver for connecting to and operating a MySQL database.
    * `gorm.io/gorm`: maps Go language structures to database tables and provides methods for querying and operating databases.
    * `golang.org/x/text/transform`: provides fundamental text processing features such as character set conversion and Unicode processing.
    * `github.com/sirupsen/logrus`: provides features such as logging output and formatting.

    **The sample code is as follows:**

    ```go
    import (
      "fmt"
      "time"
      "os"
      "gorm.io/driver/mysql"
      "gorm.io/gorm"
      "golang.org/x/text/transform"
      "github.com/sirupsen/logrus"
    )
    ```

3. Define the `User` structure.

     Define a `User` structure to represent the basic information of a user, which contains four fields: `ID`, the unique identifier of the user; `Name`, the name of the user; `Age`, the age of the user; and `Birthday`, the birthday of the user.

    **The sample code is as follows:**

    ```go
    type User struct {
    ID       int
    Name     string
    Age      int
    Birthday time.Time

    }
    ```

4. Define the `transformString` function.
   Define a `transformString` function to convert a string to the specified encoding format. It accepts two parameters: `str` and `encoder`. The function calls the `transform.String` function to convert the string to the specified encoding format. If an error occurs during the conversion, the original string is returned. Finally, the function returns the converted string or the original string.

    **The sample code is as follows:**

    ```go
    func transformString(str string, encoder transform.Transformer) string {
        result, _, err := transform.String(encoder, str)
        if err != nil {
            return str
        }
        return result
    }
    ```

5. Define the `main` function.

    Call the `main` function to perform database operations such as data insertion, data query, data update, and data deletion, and output the corresponding debugging logs to the console by using `logrus`.

   1. Initialize `logrus`.

        Initialize `logrus` to set the log output format to text format, the log level to `Debug`, and the log output stream to the standard output stream.

        **The sample code is as follows:**

        ```go
        logrus.SetFormatter(&logrus.TextFormatter{})
        logrus.SetLevel(logrus.DebugLevel)
        logrus.SetOutput(os.Stdout)
        ```

   2. Connect to the database.

        Define a string variable named `dsn`, which contains the information required for connecting to the MySQL database, including the username, password, host address, port number, database name, and character set. Call the `gorm.Open` function to connect to the MySQL database, pass the `dsn` variable and a `gorm.Config` type parameter to the function, and return a connection object. If an error occurs during the connection, output the error information and exit the program.

        **The sample code is as follows:**

        ```go
        dsn := "user_name:******@tcp(host:port)/schema_name?charset=utf8mb4&parseTime=True&loc=Local"
        db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{})
        if err != nil {
            fmt.Println(err.Error())
            return
        }
        ```

   3. Perform database operations.

        Use the `gorm.DB` object to perform database operations, including automatic migration, data insertion, data query, data update, and data deletion. The specific steps are as follows:

        1. Call the `db.AutoMigrate` function to automatically migrate the table corresponding to the `User` structure. If the table does not exist, create the table. Use the `defer` keyword and the `db.Migrator().DropTable` function to delay the deletion of the `users` table, which is deleted when the program ends.
        2. Create a `User` structure instance named `user` and insert it into the database.
        3. Query the user whose ID is 1 and output the query result.
        4. Update the information of the user whose ID is 1 and save it to the database.
        5. Delete the user whose ID is 1 and output the deletion result.

       **The sample code is as follows:**

       ```go
       db.AutoMigrate(&User{})
       defer db.Migrator().DropTable("users")
       // Record the start time.
       start := time.Now()
       // Create a `User` structure instance named `user` and insert it into the database.
       user := User{Name: "OceanBase", Age: 12, Birthday: time.Date(2022, 06, 01, 00, 00, 00, 00, time.UTC)}
       result := db.Create(&user)
       fmt.Println(user.ID)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       // Query the user whose ID is 1 and output the query result.
       user = User{ID: 1}
       result = db.First(&user)
       fmt.Println(user)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       // Update the information of the user whose ID is 1 and save it to the database.
       user = User{ID: 1, Name: "ob", Age: 13, Birthday: time.Date(2023, 06, 01, 00, 00, 00, 00, time.UTC)}
       result = db.Save(&user)
       fmt.Println(user)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       // Delete the user whose ID is 1 and output the deletion result.
       user = User{ID: 1}
       result = db.Delete(&user)
       fmt.Println(user.ID)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       ```

6. Output logs.

   Call the `time.Since` function to calculate the runtime of the program, call the `logrus.WithFields` function to create a logger with fields, and call the `Debug` function to output log information.

    **The sample code is as follows:**

    ```go
    logrus.WithFields(logrus.Fields{
        "duration": time.Since(start),
        }).Debug("DropTable")
    ```

package main

import (
  "fmt"
  "time"
  "os"
  "gorm.io/driver/mysql"
  "gorm.io/gorm"

    "github.com/sirupsen/logrus"

  ID       int
  Name     string
  Age      int
  Birthday time.Time

    result, _, err := transform.String(encoder, str)
    if err != nil {
        return str
    }
    return result
}

func main() {

      // Initialize logrus.
