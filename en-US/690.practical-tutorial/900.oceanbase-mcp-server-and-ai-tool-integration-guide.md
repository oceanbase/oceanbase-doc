# OceanBase MCP Server Integration with AI Tools

## Background

AI tools are rapidly evolving, with graphical tools like Cursor, Windsurf, and Trae, as well as command-line tools like Claude Code, Gemini CLI, and Qwen Code. With the addition of Agent mode, these tools are incredibly powerful. However, they cannot directly access databases, creating a gap between the tools and the data. The MCP protocol bridges this gap. OceanBase MCP Server interacts with AI tools via the MCP protocol, enabling these tools to directly read data from databases.

Traditionally, data analysis tasks such as user analysis, product analysis, order analysis, and user behavior analysis require developers to build backend platforms for data retrieval and frontend pages for data visualization. Even with BI tools, some SQL knowledge is often necessary. While data is displayed, the underlying logic and the necessary business changes based on the data still rely on the insights of data analysts.

With the integration of AI tools, MCP, and large language models (LLMs), the landscape of data analysis is changing. Analysts no longer need developers or SQL expertise. They can simply communicate their needs to these AI tools, which will generate the desired results, create beautiful charts, and provide initial data insights.

## Feature architecture

### Core toolkits

OceanBase MCP Server provides standardized interfaces for AI tools to directly access database features:

|            Tool Name          | Description |
|-----------------------------|----------|
| `execute_sql`               | Executes any SQL statement (`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `DDL`, etc.). |
| `get_current_tenant`        | Retrieves the name of the current tenant. |
| `get_all_server_nodes`      | Retrieves cluster node information (only available for the `sys` tenant). |
| `get_resource_capacity`     | Queries cluster resource capacity (only available for the `sys` tenant). |
| `get_ob_ash_report`         | Retrieves the OceanBase Active Session History (ASH) report for performance diagnostics. |
| `get_current_time`          | Returns the current time of the OceanBase cluster. |
| `search_oceanbase_document` | Searches the OceanBase official documentation (experimental feature). |
| `oceanbase_text_search`     | Performs full-text search in OceanBase database tables. |
| `oceanbase_vector_search`   | Executes vector similarity search in OceanBase database tables. |
| `oceanbase_hybrid_search`   | Performs hybrid search, combining relational condition filtering and vector search. |
| `ob_memory_query`           | Performs semantic search in the AI memory system to retrieve historical conversation records. (AI Memory System tool) |
| `ob_memory_insert`          | Automatically captures and stores important conversation content to build a knowledge base. (AI Memory System tool) |
| `ob_memory_delete`          | Deletes outdated or redundant conversation memories. (AI Memory System tool) |
| `ob_memory_update`          | Updates or evolves memory content based on new information. (AI Memory System tool) |

### Resource interfaces

Resource interfaces exposed through the MCP protocol for AI tools to directly access:

|          Resource Path            | Description |
|------------------------------|---------|
| `oceanbase://tables`         | Lists all tables in the database. |
| `oceanbase://sample/{table}` | Retrieves sample data (first 100 rows) for a specified table, supporting dynamic replacement of `{table}` with the actual table name. |

## Prerequisites

* You have installed Cursor or another tool that supports the MCP protocol, such as Windsurf or Qwen Code.
* You have deployed an OceanBase cluster and created a MySQL user tenant. The user connecting to the user tenant must have the `CREATE`, `INSERT`, `DROP`, and `SELECT` privileges on the target database.

  * For more information about deploying an OceanBase cluster, see [Overview](../400.deploy/100.deploy-overview.md).
  * For more information about creating a user tenant, see [Create a tenant](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md).
  * For more information about user privileges, see [Privilege types in MySQL mode](../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

* You have installed a Python environment (version 3.10 to 3.12).

  * You can download the Python installation package from the [Python official website](https://www.python.org/downloads/).

## Integration steps

### Step 1: Obtain the database connection information

Contact the OceanBase Database deployment personnel or administrator to obtain the database connection string, for example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: the IP address for connecting to OceanBase Database. For connection through OceanBase Database Proxy (ODP), use the IP address of an ODP. For direct connection, use the IP address of an OBServer node.
* `$port`: the port for connecting to OceanBase Database. For connection through ODP, the default port is `2883`, which can be customized when ODP is deployed. For direct connection, the default port is `2881`, which can be customized when OceanBase Database is deployed.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user for connecting to a tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on the database. For more information about user privileges, see <a href="../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL mode</a>. </p>
    </main>

* `$user_name`: the connection account of the tenant. For connection through ODP, the common format is `username@tenant name#cluster name` or `cluster name:tenant name:username`. For direct connection, the format is `username@tenant name`.
* `$password`: the password of the account.

For more information about the connection string, see [Connect to an OceanBase tenant by using OBClient](../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md).

**Here is an example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Install the Python dependencies

#### Prepare the environment

1. Install the uv package manager.

   * Run the following command in macOS or Linux:

       ```shell
       curl -LsSf https://astral.sh/uv/install.sh | sh
       ```

   * Run the following command in Windows:

       ```shell
       irm https://astral.sh/uv/install.ps1 | iex
       ```

   * Or run the following command to install the uv package manager:

       ```shell
       pip install uv
       ```

2. Verify whether the uv package manager is installed.

    ```shell
    uv --version
    ```

#### Install OceanBase MCP Server

1. Run the following command to create a virtual environment in a directory:

    ```shell
    uv venv
    ```

2. Run the following command to activate the virtual environment:

    ```shell
    source .venv/bin/activate
    ```

3. Run the following command to install OceanBase MCP Server:

    ```shell
    uv pip install oceanbase-mcp
    ```

### Step 3: Configure the MCP Server environment

1. Create a `.env` file.

    ```shell
    cat > .env <<EOF
    OB_HOST=127.0.0.1
    OB_PORT=2881
    OB_USER=test_user001@mysql001  # Example: MySQL tenant user
    OB_PASSWORD=your_password
    OB_DATABASE=test
    EOF
    ```

2. Start the MCP Server.

    ```shell
    uv run oceanbase_mcp_server \
        --transport sse \           # Supports stdio/streamable-http/sse modes
        --host 0.0.0.0 \            # Allows external access; can be changed to 127.0.0.1 for local access only
        --port 8000                 # Custom port (e.g., 8001 requires adjustment in subsequent configurations)
    ```

### Step 4: Configure Cursor to connect to the MCP Server

1. Access the Cursor settings page: Click the gear icon in the top right → Select MCP → Click New MCP Server.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/1.0.png)

2. Edit the `mcp.json` configuration.

    ```shell
    {
      "mcpServers": {
        "ob-sse": {
          "autoApprove": [],
          "disabled": false,       # Must be set to false to enable the service
          "timeout": 60,
          "type": "sse",
          "url": "http://127.0.0.1:8000/sse"  # Must match the port from Step 3
        }
      }
    }
    ```

3. Verify the connection.

    After saving, return to the MCP page, where you should see the newly added MCP.

4. When you ask a question in the Chat window after adding it, Cursor will automatically use the MCP tool.

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/2.png)

## Quick experience examples

After you have set up OceanBase Database with MCP Server, you can quickly experience data analysis. Other AI tools can also achieve the effects described in this topic. This topic uses Cursor as an example to demonstrate how powerful AI tools can work with OceanBase MCP Server.

### User data analysis

1. Enter the following command:

    ```shell
    Analyze the user data to see the age and city distribution.
    ```

2. Cursor executes the following steps:

    1. Cursor calls the `execute_sql` function to execute the aggregation query.

        ```sql
        SELECT age, city, COUNT(*) AS user_count
        FROM users
        GROUP BY age, city;
        ```

    2. Cursor automatically generates a structured analysis result.

        ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/3.png)

3. Extend the command.

    ```shell
    Convert the above result to a chart.
    ```

4. Output the result.

    Cursor automatically generates a pie chart showing the age and city distribution.

    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/4.png)

### Product sales analysis

1. Enter the following command:

    ```shell
    Analyze the product sales data to find the most popular product categories and brands.
    ```

2. Output the result.

    Cursor generates an analysis report and provides insights and recommendations based on the data.

    ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/5.png)

### Order trend analysis

1. Enter the following command:

    ```shell
    Analyze the order data to see the sales trends and user purchasing behavior.
    ```

2. Output the result.

    Cursor generates an order data analysis report and provides recommendations based on the data.

    ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/6.png)
