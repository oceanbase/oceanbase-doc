# Build a WordPress website based on OceanBase Database

This topic describes how to build a WordPress website based on OceanBase Database.

## Background information

* WordPress: WordPress is an open-source content management system (CMS) built with PHP and MySQL. For more information, visit the [official website of WordPress](https://www.hostinger.com/wordpress-hosting?ppc_campaign=google_search_generic_hosting_wordpress&bidkw=wordpress&gad_source=1&gclid=EAIaIQobChMIi9-WkdmIigMV8lsPAh2tpR84EAAYASAAEgIgo_D_BwE). WordPress is user-friendly, scalable, and backed by a large community, making it the first choice of many users. Therefore, we chose WordPress to show you how to build a website using OB Cloud.
* MAMP: MAMP is a package for macOS and Windows that provides a complete local development environment, allowing developers to easily develop and test PHP and MySQL web applications on their computers. It also provides a runtime environment for WordPress. For more information, visit the [official website of MAMP](https://www.mamp.info/). 


## Prerequisites

* You have deployed an OceanBase cluster of version 4.3.3 or later and created a MySQL tenant. For more information about how to deploy an OceanBase cluster, see [Deployment overview](../400.deploy/100.deploy-overview.md).

* The privileges to insert data and query data have been granted to the MySQL tenant you created. For more information about how to grant privileges, see [Directly grant privileges](../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md).

* You have created a database. For more information, see [Create a database](../300.develop/100.application-development-of-mysql-mode/300.database-object-planning-of-mysql-mode/100.create-database-of-mysql-mode-in-develop.md).

* Apache and PHP have been installed.

  * Run the following command to install Apache.

    ```shell
    brew install httpd
    ```

  * Run the following command to install PHP.

    ```shell
    brew install php

## Procedure

1. Install WordPress.

    1. Run the following command to download WordPress.

        ```shell
        curl -O https://wordpress.org/latest.tar.gz
        ```

    2. Run the following command to decompress WordPress.

        ```shell
        tar -xzvf latest.tar.gz
        ```

    3. Rename the decompressed WordPress folder to the name you want (such as your-wordpress-site), and move it to the htdocs directory of MAMP, which is usually ` /Applications/MAMP/htdocs/ `.

        ```shell
        mv wordpress /Applications/MAMP/htdocs/your-wordpress-site
        ```

2. Edit the WordPress configuration file.

    * Edit the `wp-config-sample.php` file in the installation directory of WordPress. Configure the database connection information.

        ```php
            /** The name of the database for WordPress */
            define('DB_NAME', 'your_db_name');    ## Set the database name.
            /** MySQL database username */
            define('DB_USER', 'your_db_user');    ## Set the tenant and username.
            /** MySQL database password */
            define('DB_PASSWORD', 'your_db_password');  ## Set the password of the tenant user.
            /** MySQL hostname */
            define('DB_HOST', 'your_ob_cloud_host'); // ## Set the IP address and port of the tenant.
        ```

    * Edit the `class-wpdb.php` file in the WordPress directory. Change utf8mb4_unicode_520_ci to utf8mb4_general_ci.

        ```php
            if ( $this->has_cap( 'utf8mb4_520' ) && 'utf8mb4_unicode_ci' === $collate ) {
                        $collate = 'utf8mb4_general_ci';
                    }
        ```

3. Access your website: http://localhost:8888/your-wordpress-site
