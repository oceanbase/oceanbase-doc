# OceanBase Database TPC-DS benchmark report

This topic describes the test environment, test plan, and detailed test data results of the TPC-DS test.

## Test environment

The following example uses Alibaba Cloud ECS as the deployment environment.

* Hardware Configuration

    | Service Type | ECS Type | Number of Instances | Number of Cores per Machine | Memory |
    | ------- | -------- | ------ | -------- | ----- |
    | OceanBase Database | ecs.r8i.8xlarge | 3 | 32C | 256G <br>Each machine has a 400G log disk and a 1200G data disk, with a performance level of PL1|
    | ODP | ecs.r8i.8xlarge | 1 | 32c | 256G |

* Software Versions

    | Service Type | Software Version |
    | --- | --- |
    | OceanBase Database |  <ul><li>Enterprise Edition: OceanBase 4.4.2.0</li> <li>Community Edition: OceanBase_CE 4.4.2.0 </li></ul>|
    | TPC-DS | V3.0.0 |
    | OS | CentOS Linux release 7.9.2009 (Core) |

* Tenant Specification

    ```sql
    obd cluster tenant create obperf -n tpcds_tenant --max-cpu=28 --memory-size=180G --zone-list=zone1,zone2,zone3 --primary-zone=RANDOM --locality=F@zone1,F@zone2,F@zone3 --charset=utf8 -s 'ob_tcp_invited_nodes="%"' --optimize=htap
    ```

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>In this example, <code>--optimize=htap</code> is the default workload type. In a production environment, select the appropriate workload type based on your actual cluster type.</p>
    </main>

## Test plan

* This test requires four machines. TPC-DS and OBD are deployed on a separate machine, which serves as the stress machine for clients. To deploy the OceanBase cluster using OBD, three additional machines are required, with the OceanBase cluster scaled at a ratio of 1:1:1.

* After successful deployment, first create a new tenant and user for running the TPC-DS test (`sys` is the built-in system tenant for managing clusters; do not use the `sys` tenant directly for testing). Set the tenant's `primary_zone` to RANDOM.

* Test data volume: 100G.

* For detailed test steps, see [OceanBase Database TPC-DS testing](100.run-the-tpc-ds-benchmark-on-oceanbase-database.md).
