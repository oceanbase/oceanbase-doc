# Unique and non-unique indexes

Index tables are divided into unique and non-unique indexes. A unique index ensures that no two rows in the table have the same value in the indexed column, while a non-unique index allows for duplicate values. In OceanBase Database, NULL values are also stored in the index.

## Storage keys

* Non-unique indexes

  For non-unique indexes, the storage key of the index table is the **index column + primary key column of the main table**.

* Unique index columns

  For unique index columns, the storage key of the index table is the **index column + variable primary key column of the main table**. The term "variable" means that the value of the primary key column changes based on the value of the index column:

  * When the **index column** is not NULL, the **variable primary key column** does not come into play, and the value of the **index column** is used for storage.
  * When the **index column** is NULL, the **variable primary key column** is set to the same value as the **primary key column of the main table**, allowing for differentiation among multiple NULL values in the unique index table.

**Here is an example:**

* For the non-unique index table `idx1_tbl1`, the storage key is `col2` and `col1`.
* For the unique index table `idx2_tbl1`, the storage key is:

  * When the index column `col3` is `NULL`, the variable `col1` column value is the same as the main table's `col1` column value. The storage key is `col1`.
  * When the index column `col3` is not `NULL`, the variable `col1` column value is `NULL` and does not come into play. The storage key is `col3`.

1. Create the `tbl1` table.

    ```shell
    CREATE TABLE tbl1(col1 INT, col2 INT, col3 INT, col4 INT, PRIMARY KEY(col1));
    ```

2. Create the non-unique index `idx1_tbl1`.

    ```shell
    CREATE INDEX idx1_tbl1 ON tbl1(col2);
    ```

3. Create the unique index `idx2_tbl1`.

    ```shell
    CREATE UNIQUE INDEX idx2_tbl1 ON tbl1(col3);
    ```
