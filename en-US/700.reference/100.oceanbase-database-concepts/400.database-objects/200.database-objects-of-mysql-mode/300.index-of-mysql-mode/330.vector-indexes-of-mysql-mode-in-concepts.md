# Vector Index

This topic describes the principles of HNSW and IVF vector indexes.

## IVF vector index

An IVF vector index is a vector index based on inverted indexing. It uses clustering algorithms to divide a high-dimensional vector space into `nlist` subregions defined by cluster centers. Each cluster center is associated with an inverted bucket that stores vectors (or their quantized compressed encoding) belonging to that subregion. During search, only the buckets closest to the query vector are accessed, achieving a balance between computational overhead and retrieval accuracy.

### Internal structure

An IVF vector index can be logically divided into two layers:

* Cluster center layer (coarse clustering layer): Maintains `nlist` center vectors to determine which buckets to prioritize during queries. The search parameter `nprobe` specifies the number of closest centers to consider.
* Inverted bucket data layer: Each center corresponds to a bucket, which stores vectors falling within that cluster region (which can be compressed using techniques like product quantization).

The cluster center layer (coarse clustering layer) has two primary physical organization methods, each suitable for different scales of `nlist`:

| Organization Method | Applicable Scenario | Search Method | Features |
|---------------------|---------------------|----------------|----------|
| ARRAY               | Small `nlist`      | Linear distance calculation and sorting | Simple implementation, low constant overhead |
| HGRAPH              | Large `nlist`      | Graph traversal | Supports large-scale centers, efficient |

In practice, after the centers are loaded into memory, the system automatically selects the optimal organization method based on the scale. If `nlist` is below the threshold, the `ARRAY` structure is used; if it exceeds the threshold, an `HGraph` is built, and the original large contiguous array can be released based on the implementation strategy. Subsequent access to center information is done through a unified interface.
