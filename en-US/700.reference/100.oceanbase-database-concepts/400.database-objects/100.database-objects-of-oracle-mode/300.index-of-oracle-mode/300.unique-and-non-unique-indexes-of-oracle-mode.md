# Unique and non-unique indexes

Indexes are classified into unique and non-unique indexes. Unique indexes ensure that no two rows of a table have duplicate values in an indexed column. Non-unique indexes allow duplicate values in an indexed column. In OceanBase Database, `NULL` values are also stored in indexes.

## Storage keys

* Non-unique indexes

  Storage keys of a non-unique index table are the user-specified indexed column and the primary key column in the primary table.

* Unique indexes

  Storage keys of a unique index table are the user-specified indexed column and a variable primary key column in the primary table. "Variable" means that values of the primary key column vary with the values of the indexed column.

  * When the indexed column is not `NULL`, the value of the variable primary key column is the same as that of the indexed column.
  * When the indexed column is `NULL`, the value of the variable primary key column is the same as that of the primary key column in the primary table.

**Here is an example:**

* For the `idx1_tbl1` table with a non-unique index, the storage keys are `col2` and `col1`.
* For the `idx2_tbl1` table with a unique index:

  * When the indexed column `col3` is `NULL`, the value of the variable primary key column `col1` is the same as that of the primary key column `col1` in the primary table. The storage key is `col1`.
  * When the indexed column `col3` is not `NULL`, the value of the variable primary key column `col1` is `NULL`. The storage key is `col3`.

1. Create the `tbl1` table.

    ```shell
    CREATE TABLE tbl1(col1 INT, col2 INT, col3 INT, col4 INT, PRIMARY KEY(col1));
    ```

2. Create the `idx1_tbl1` non-unique index.

    ```shell
    CREATE INDEX idx1_tbl1 ON tbl1(col2);
    ```

3. Create the `idx2_tbl1` unique index.

    ```shell
    CREATE UNIQUE INDEX idx2_tbl1 ON tbl1(col3);
    ```
