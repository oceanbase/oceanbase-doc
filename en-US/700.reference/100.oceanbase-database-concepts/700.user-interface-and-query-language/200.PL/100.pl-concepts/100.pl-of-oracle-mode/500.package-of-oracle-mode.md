# Packages

A package (or pkg) is a user-defined group of related subprograms, including the cursors and variables used by the subprograms, stored and used in the database as a unit.

OceanBase Database provides many system packages that extend the database functionality. You can use these packages when you create applications. For example, the DBMS_RANDOM package makes it easy to generate a random value.

## Benefits of packages

PL packages offer many benefits to developers:

* Encapsulation

  Packages encapsulate features similar to those in object-oriented programming languages. You can encapsulate subprograms, variables, and custom data types in a package. This makes it easier to organize and manage these smaller units. Packages are similar to classes in C++ and Java. Variables in a package are similar to member variables in a class, while subprograms and functions in a package are similar to methods in a class. Package encapsulation simplifies privilege management. If a user has privileges on a package, the user has privileges on the individual structures within the package.

* High data security

  You can declare package variables, cursors, and subprograms as public or private. "Public" means that they can be directly accessed by users of the package. "Private" means that they cannot be directly accessed by users of the package.

  For example, a package contains three variables and five subprograms. You can declare two of the variables and three of the subprograms as private. Then, the private variables and subprograms can be accessed only within the package, and users of the package can access only the remaining variables and two subprograms.

## Create a package

A package consists of two parts: the package header and the package body. The package header must declare all public structures, and the package body must define all structures, including public and private ones.

In the following example, a `students` table and a `students_adm` package are created. The package contains two subprograms. When a student enrolls, you can call the `students_adm.stu_entrance` subprogram to insert the student's information into the `students` table. When a student graduates, you can call the `students_adm.graduate` subprogram to delete the student's information from the `students` table.

```sql
obclient> CREATE TABLE students (id INT, name VARCHAR2(100), class INT, grade INT, dorm VARCHAR2(100), year INT);

obclient> CREATE OR REPLACE PACKAGE students_adm AS
  PROCEDURE stu_entrance(id INT, name VARCHAR2, class INT, grade INT, dorm VARCHAR2, year INT);
  PROCEDURE graduate(id INT);
END students_adm;
/

obclient> CREATE OR REPLACE PACKAGE BODY students_adm AS
 PROCEDURE stu_entrance(id INT, name VARCHAR2, class INT, grade INT, dorm VARCHAR2, year INT) AS
  BEGIN
    INSERT INTO students VALUES (id, name, class, grade, dorm, year);
  END;
PROCEDURE graduate(id INT) AS
  BEGIN
    DELETE from students s WHERE s.id = id;
  END;
END students_adm;
/

obclient> CALL students_adm.stu_entrance(1001, 'Curry', 5, 10, '1-1-3', 12);
Query OK, 0 rows affected 

obclient> SELECT * from students WHERE id = 1001;
+------+-------+-------+-------+-------+------+
| ID   | NAME  | CLASS | GRADE | DORM  | YEAR |
+------+-------+-------+-------+-------+------+
| 1001 | Curry |     5 |    10 | 1-1-3 |   12 |
+------+-------+-------+-------+-------+------+
1 row in set 

obclient> CALL students_adm.graduate(1001);
Query OK, 0 rows affected 

obclient> SELECT * from students WHERE id = 1001;
Empty set
```
