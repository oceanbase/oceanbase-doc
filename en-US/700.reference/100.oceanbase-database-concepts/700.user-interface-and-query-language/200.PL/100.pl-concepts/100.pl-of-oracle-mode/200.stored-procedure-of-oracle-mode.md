# Stored procedures

A stored procedure (SP) is a set of precompiled PL/SQL statements stored in a database and executed as a unit. It is similar to a function in other programming languages, accepting parameters, performing operations, and returning a value.

## Structure of a stored procedure

The structure of a stored procedure is as follows:

```sql
PROCEDURE name [ ( parameter_list ) ]
{ IS | AS }
[ declarative_part ]
BEGIN    -- Start execution
statement; [ statement; ]...
[ EXCEPTION ]
exception_handler; [ exception_handler; ]... ]
END;
```

## Create a stored procedure

You can execute the `CREATE PROCEDURE` statement to create a stored procedure. The syntax is as follows:

```sql
CREATE [OR REPLACE] PROCEDURE Procedure_name
[ (argment [ { IN | IN OUT }] Type,
      argment [ { IN | OUT | IN OUT } ] Type ]
    [ AUTHID DEFINER | CURRENT_USER ]
{ IS | AS }
delarification_block 
BEGIN
    procedure_body
EXCEPTION
  exception_handler
END;
```

A stored procedure without parameters is created as follows:

```sql
obclient> CREATE TABLE loghistory 
      (userid VARCHAR2(20), 
      logdate DATE DEFAULT SYSDATE);
Query OK, 0 rows affected 
obclient> DELIMITER /
obclient> CREATE OR REPLACE PROCEDURE userlogin 
      IS
  BEGIN
      INSERT INTO loghistory (userid) VALUES (USER);
  END;
  /
Query OK, 0 rows affected 
```

## Call a stored procedure

After a stored procedure is created, the user can call it by using OBClient, OceanBase Developer Center ODC, or a third-party development tool to which you have granted the corresponding privilege.

A sample call to a stored procedure is as follows:

```sql
obclient> SELECT * FROM loghistory;
Empty set 

obclient> BEGIN
     userlogin;
     END;
     /
Query OK, 0 rows affected

obclient> SELECT * FROM loghistory;
+--------+-----------+
| USERID | LOGDATE   |
+--------+-----------+
| HR     | 27-SEP-20 |
+--------+-----------+
1 row in set

obclient> COMMIT;
Query OK, 0 rows affected 
```
