# Plugin mechanism of OceanBase Database

As database technology evolves and business scenarios diversify, flexibility and scalability have become a core capability of modern distributed database systems. To adapt to this trend, OceanBase Database introduces a plugin mechanism to allow users to expand the database's features in a modular and non-intrusive way. With the plugin mechanism, users can dynamically load, unload, and update feature modules without modifying the core code, thus enabling efficient customization and expansion of the database.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p><ul><li>The plugin mechanism is supported in OceanBase Database V4.3.5 and later, starting from V4.3.5 BP1. </li><li>The plugin mechanism of OceanBase Database is currently in the experimental stage. Therefore, it is not recommended for use in production environments. </li></ul></p>
</main>

## Simplified expansion

The plugin mechanism of OceanBase Database allows you to add new features to the database without modifying the core code. This modular design makes feature expansion easier and more intuitive.

## Efficient updates

The plugin mechanism supports rapid iteration and update. You can promptly obtain and apply the latest feature improvements and fixes. This quick response ensures that the system remains in its optimal state to meet changing business needs.

## Customized features

The plugin mechanism allows you to customize features based on your business needs, enhancing the flexibility and adaptability of the system. You can selectively load or unload plugins to ensure that the system runs only the required feature modules.

## Community and ecosystem support

Through the plugin mechanism, OceanBase database users can share and publish custom plugins, promoting communication and collaboration within the community and enriching the plugin ecosystem. This not only enhances the functional diversity of the OceanBase database but also drives the development of the entire community.

## Experimental feature

The plugin mechanism of OceanBase Database is currently in the experimental stage. Its functionality and stability are being enhanced. At present, the plugin mechanism supports the following scenarios:

* Disassembler plug-ins: Extend the full-text search capability of the database. Custom disassembly logic can be implemented.
* Feature verification: Allow you to try out the plugin mechanism in advance and provide feedback for future feature expansions.

In the future, OceanBase Database will support more scenarios for the plugin mechanism and improve its stability and performance in production environments.
