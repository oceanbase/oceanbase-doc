# Memory-related views

OceanBase Database supports viewing memory usage through views.

| View | Description |
|---------------------------------------|----------------------------------------------------------------------|
| GV$OB_MEMORY | Statistics of memory labels for OBServer nodes. |
| GV$OB_MEMSTORE | MemStore statistics. |
| GV$OB_KVCACHE | Kvcache statistics. |
