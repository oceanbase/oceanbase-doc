## ORA-00600: arbitration service does not exist

* OceanBase error code: 4747

* SQLSTATE: HY000

* Cause: The arbitration service address has not been configured for the cluster.

* Solution: You cannot perform arbitration-related operations without configuring the arbitration service address. You can use OCP or execute the `alter system add arbitration service‘$svr_ip:$svr_port’;` statement to add the arbitration service address to the cluster.

## ORA-00600: arbitration service already exist

* OceanBase error code: 4748

* SQLSTATE: HY000

* Cause: The cluster already has a valid arbitration service address.

* Solution: You cannot configure multiple arbitration services for a cluster at the same time.

## ORA-00600: internal error code, arguments: -4781, The service has not started on all servers

* OceanBase error code: 4781

* SQLSTATE: HY000

* Cause: When a `service_name`-related operation (such as creating or deleting a `service_name`) notifies each OBServer node to apply the change, some servers failed.

* Solution: Wait for a while. In normal cases, a background thread refreshes periodically, with a default refresh interval of about 10 seconds.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This error code was introduced in V4.2.4.</p>
</main>

## ORA-00600: internal error code, arguments: -4782, The tenant is not PRIMARY

* OceanBase error code: 4782

* SQLSTATE: HY000

* Cause: When a `service_name` and `failover_mode` are specified, the tenant must be a primary tenant. If the current tenant is no longer the primary tenant, this indicates a Proxy routing error.

* Solution: The Proxy or OCP cache may be incorrect. If both caches are normal, the system retries and refreshes automatically. Re-execute the SQL statement to route to the correct primary tenant.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This error code was introduced in V4.2.4.</p>
</main>
