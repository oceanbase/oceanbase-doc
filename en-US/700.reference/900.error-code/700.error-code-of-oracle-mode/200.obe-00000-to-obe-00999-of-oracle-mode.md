## OBE-00600: arbitration service does not exist

* OceanBase error code: 4747

* SQLSTATE: HY000

* Cause: The address of the arbitration service has not been configured for the cluster.

* Solution: Arbitration-related operations cannot be performed without the arbitration service address configured. You can use OCP or execute the SQL statement `alter system add arbitration service‘$svr_ip:$svr_port’;` to add an arbitration service address for the cluster.

## OBE-00600: arbitration service already exist

* OceanBase error code: 4748

* SQLSTATE: HY000

* Cause: The cluster already has a valid arbitration service address.

* Solution: A cluster supports only one arbitration service.
