## OBE-00600: arbitration service does not exist

* OceanBase Database error code: 4747

* SQLSTATE: HY000

* Cause: The arbitration service address is not configured for the cluster.

* Solution: If no arbitration service address is configured, you cannot perform operations related to arbitration. You can add an arbitration service address for the cluster through OCP or by executing the `alter system add arbitration service '$svr_ip:$svr_port';` statement.

## OBE-00600: arbitration service already exist

* OceanBase Database error code: 4748

* SQLSTATE: HY000

* Cause: The cluster already has an effective arbitration service address.

* Solution: You cannot configure multiple arbitration service addresses for a cluster.

---------------------

* OceanBase error code: 5198

* SQLSTATE: 42000

* Cause: The specified string length exceeds the maximum length supported by the data type. The maximum length is 2,000 for the CHAR and RAW data types, and 4,000 for other data types.

* Solution: Reduce the string length or switch to another data type that supports longer strings, such as VARCHAR2, LONG CHAR, or LONG RAW.
