## OBE-00600: arbitration service does not exist

* OceanBase error code: 4747

* SQLSTATE: HY000

* Error reason: The arbitration service address has not been configured for the cluster.

* Solution: You cannot perform arbitration-related operations without configuring the arbitration service address. You can add the arbitration service address to the cluster by using OCP or executing the `alter system add arbitration service‘$svr_ip:$svr_port’;` statement.

## OBE-00600: arbitration service already exist

* OceanBase error code: 4748

* SQLSTATE: HY000

* Error reason: The cluster already has a valid arbitration service address.

* Solution: A cluster does not support configuring multiple arbitration services at the same time.
