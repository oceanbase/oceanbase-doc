## OBE-20000: operator binding does not exist

* OceanBase error code: 7299

* SQLSTATE: 42000

* Cause: The specified operator binding was not found when attempting to execute the operation.

* Solution: Verify that the operator or function name used is correct and free of spelling errors.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This error code is introduced in V4.3.2 of OceanBase Database V4.3.x series.</li><li>This error code is introduced in V4.2.4 of OceanBase Database V4.2.x series.</li></ul>
</main>

## OBE-20000: '%.*s' invalid partition name

* OceanBase error code: 11002

* SQLSTATE: HY000

* Cause: The partition name '%.*s' is invalid.
* Solution: Check whether the partition name '%.*s' is correct and complies with the partition naming rules. Ensure a valid partition name is used for the operation.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This error code is introduced in V4.3.0 of OceanBase Database.</p>
</main>

## OBE-21560: argument %.\*s is null, invalid, or out of range

* OceanBase error code: 5934

* SQLSTATE: HY000

* Cause: The passed parameter value is `NULL`, invalid, or out of range. For example, the value of the position or size parameter for `LOB / FILE` exceeds the range of 1 to (4 GB - 1), or a file is opened in an invalid mode.

* Solution: Check and correct the program to ensure that no `NULL`, invalid, or out-of-range parameter values are passed.
