# 9500 ~ 9999

This range indicates process language (PL) error codes.

## ERROR 9502 (HY000) : OUT and IN/OUT modes cannot be used in this context

* OceanBase Database error code: 9502

* Cause: The `OUT` parameter can be used only for dynamic statements whose DML statement contains the `RETURNING` clause and does not have an `INTO` variable.

* Solution: Check whether the use of the `OUT` parameter conforms to the specifications.

## ERROR 9503 (HY000) : object '%.\*s' of type %.\*s not found in schema '%.\*s'

* OceanBase Database error code: 9503

* Cause: The specified object does not exist.

* Solution: Specify the correct object name and type.

## ERROR 9506 (HY000) : Only schema-level programs allow %s

* OceanBase Database error code: 9506

* Cause: The `INVOKER RIGHT` clause can be used only for standalone procedures or functions.

* Solution: Remove the `INVOKER RIGHT` clause.

## ERROR 9507 (HY000) : at most one declaration for '%.\*s' is permitted

* OceanBase Database error code: 9507

* Cause: A duplicate identifier is found in the same namespace.

* Solution: Ensure the uniqueness of identifiers in the same namespace.

## ERROR 9508 (HY000) : duplicate fields in RECORD, TABLE, or argument list are not permitted

* OceanBase Database error code: 9508

* Cause: The PL has parameters with the same name.

* Solution: Make the parameter names in the PL unique.

## ERROR 9509 (HY000) : Pragma AUTONOMOUS_TRANSACTION cannot be specified here

* OceanBase Database error code: 9509

* Cause: The position of the AUTONOMOUS_TRANSACTION pragma is incorrect. It must be specified only in the first-level block.

* Solution: Change the position of the AUTONOMOUS_TRANSACTION pragma.

## ERROR 9510 (HY000) : illegal EXIT/CONTINUE statement; it must appear inside a loop

* OceanBase Database error code: 9510

* Cause: The `EXIT` or `CONTINUE` statement must be used inside a loop.

* Solution: Check whether the `EXIT` or `CONTINUE` clause is used correctly.

## ERROR 9512 (HY000) : EXIT/CONTINUE label '%.\*s' must label a LOOP statement

* OceanBase Database error code: 9512

* Cause: The `EXIT` or `CONTINUE` clause targets an invalid label.

* Solution: Check whether the label targeted by the `EXIT` or `CONTINUE` clause is valid.

## ERROR 9513 (HY000) : expression '%.\*s' is inappropriate as the left hand side of an assignment statement

* OceanBase Database error code: 9513

* Cause: Static cursors cannot be used to assign values.

* Solution: Check whether the assignment statement is correct.

## ERROR 9514 (HY000) : a variable declared NOT NULL must have an initialization assignment

* OceanBase Database error code: 9514

* Cause: The `NOT NULL`-constrained variable is not explicitly initialized.

* Solution: Remove the `NOT NULL` constraint, or explicitly initialize the variable.

## ERROR 9515 (HY000) : Constant declarations should contain initialization assignments

* OceanBase Database error code: 9515

* Cause: The constant variable is not explicitly initialized.

* Solution: Remove the constant declaration, or explicitly initialize the variable.

## ERROR 9516 (HY000) : Cursor variables cannot be declared as part of a package

* OceanBase error code: 9516

* Cause: Cursors are not allowed in packages.

## ERROR 9518 (HY000) : value in LIMIT clause: \\'%.\*s\\' use is invalid

* OceanBase error code: 9518

* Cause: The data type of the expression in the `LIMIT` clause is incorrect.

* Solution: Change the data type of the expression to a numeric type.

## ERROR 9519 (HY000) : expression is of wrong type

* OceanBase error code: 9519

* Cause: The result type of the expression does not meet the expectation.

* Solution: Check the result type of the expression.

## ERROR 9520 (HY000) : cannot compile body of '%.\*s' without its specification

* OceanBase error code: 9520

* Cause: The UDT lacks a SPEC declaration.

* Solution: Add a SPEC declaration.

## ERROR 9521 (HY000) : subprogram '%.\*s' is declared in an object type body and must be defined in the object type specification

* OceanBase error code: 9521

* Cause: A function definition in an object must be declared in the SPEC section.

* Solution: Declare the function in the SPEC section.

## ERROR 9522 (HY000) : subprogram or cursor '%.\*s' is declared in an object type specification and must be defined in the object type body

* OceanBase error code: 9522

* Cause: A function or cursor declared in the SPEC section of an object must be defined in the BODY section.

* Solution: Remove the declaration or define the declared function or cursor.

## ERROR 9523 (HY000) : An object type may have only 1 MAP or 1 ORDER method

* OceanBase error code: 9523

* Cause: An object type can define only one of the `MAP` or `ORDER` function (but not both).

* Solution: Remove the redundant `MAP` or `ORDER` function and retain an appropriate one.

## ERROR 9524 (HY000) : A MAP or ORDER function is required for comparing objects in PL/SQL

-

* OceanBase error code: 9524

* Cause: To compare objects in PL/SQL, a `MAP` or `ORDER` function must be defined.

* Solution: Define a `MAP` or `ORDER` comparison function.

## ERROR 9525 (HY000) : Only a function may be a MAP, ORDER or CONSTRUCTOR method

* OceanBase error code: 9525

* Cause: `MAP`, `ORDER`, or `CONSTRUCTOR` must be defined as a function.

* Solution: Modify the definition and recompile.

## ERROR 9526 (HY000) : identifier '%.\*s' too long

* OceanBase error code: 9526

* Cause: The name of the label is more than 128 characters long.

* Solution: Shorten the name.

## ERROR 9527 (HY000) : a static method cannot be invoked on an instance value

* OceanBase error code: 9527

* Cause: An instance cannot call a static function.

* Solution: Call the static function by using the type name.

## ERROR 9528 (HY000) ：constructor method name must match type name

* OceanBase Error Code: 9528

* Cause of error: The constructor name must be the same as the type name.

* Solution: Ensure they are the same.

## ERROR 9529 (HY000) : previous use of '%.\*s' conflicts with this use

* OceanBase Error Code: 9529

* Cause of error: Naming conflict. For example, defining variables of different types, but the variable name has already been used elsewhere.

* Solution: Ensure that the named variable names are not duplicated.

## ERROR 9530 (HY000) : the SELF parameter can be declared only as IN or as IN OUT

* OceanBase Error Code: 9530

* Cause of error: The modifier of the `SELF` parameter must be `IN` or `IN OUT`, and cannot be any other modifier.

* Solution: Modify the modifier to meet the requirements.

## ERROR 9531 (HY000) : MAP methods must return a scalar type

* OceanBase Error Code: 9531

* Cause of error: The `MAP` function must return a scalar value and cannot be a complex type.

* Solution: Modify the return type of the function.

## ERROR 9532 (HY000) : MAP methods must be declared without any parameters other than (optional) SELF

* OceanBase Error Code: 9532

* Cause of error: The `MAP` function has only one `SELF` parameter (the `SELF` parameter can be explicitly or implicitly defined).

* Solution: Remove the extra parameters.

## ERROR 9533 (HY000) : ORDER methods must return an INTEGER

* OceanBase Error Code: 9533

* Cause of error: The `ORDER` function must return an integer.

* Solution: Modify the return type of the function.

## ERROR 9534 (HY000) : The parameter type in an ORDER method must be the containing object type

* OceanBase Error Code: 9534

* Cause of error: The argument type of the `ORDER` function must be the type of the owning type.

* Solution: Modify the parameter type.

## ERROR 9535 (HY000) : Within SQL statements, only equality comparisons of objects are allowed without a map or order function

* OceanBase Error Code: 9535

* Reason for the error: In the SQL statement, there is no `MAP` or `ORDER` function, and only equality comparisons can be performed.

* Solution: Add the `MAP` or `ORDER` function, or perform only equality comparisons.

## ERROR 9537 (HY000) : The parameters to an ORDER function must have IN mode

* OceanBase Error Code: 9537

* Cause of error: The argument modifier of the `ORDER` function must be `IN`.

* Solution: Modify the parameter modifier.

## ERROR 9538 (HY000) : ORDER methods must be declared with 1 (one) parameter in addition to (optional) SELF

* OceanBase Error Code: 9538

* Cause of error: The `ORDER` function must define parameters other than the `SELF` parameter.

* Solution: Define an additional parameter of the owning type.

## ERROR 9539 (HY000) : type '%.\*s' is malformed because it is a non-REF mutually recursive type

* OceanBase Error Code: 9539

* Cause of error: Types reference each other recursively.

* Solution: Resolve the issue of recursive references.

## ERROR 9540 (HY000) : $ERROR: %.\*s

* OceanBase Error Code: 9540

* Cause of error: Exception generated by the `$ERROR` instruction, expected exception.

* Solution: No action required.

## ERROR 9541 (HY000) : RETURN statement in a CONSTRUCTOR cannot include an expression

* OceanBase error code: 9541

* Cause: The `RETURN` statement in a `CONSTRUCTOR` function cannot have an expression.

* Solution: Remove the expression after `RETURN`.

## ERROR 9542 (HY000) : wrong number or types of arguments in call to '%.\*s'

* OceanBase error code: 9542

* Cause: When calling a subprocedure, no matching function is found. This may be because the function name is incorrect, the number of arguments is incorrect, or the argument types are not compatible.

* Solution: Check the function name, the number of arguments, and the argument types. If the issue still exists, check the access scope of the function.

## ERROR 9543 (HY000) : '%.\*s' must be a type

* OceanBase error code: 9543

* Cause: The type modifier in a declaration or expression is not a valid type. For example, `%type` or `%rowtype` may be missed.

* Solution: Modify the type modifier to a valid type.

## ERROR 9544 (HY000) : too many declarations of '%.\*s' match this call

* OceanBase error code: 9544

* Cause: Multiple matching functions are found but none of them can be precisely matched.

* Solution: Check whether the function name and parameter types are correct.

## ERROR 9694 (42000) : Duplicate condition information item '%s'

* OceanBase error code: 9694

## ERROR 9760 (HY000): cannot fast refresh materialized view %s: %s

* OceanBase error code: 9760

* Cause: The basic requirements for creating an incremental refresh materialized view are not met. For example:

  * The base table specified in the definition of the incremental refresh materialized view does not have a materialized log (mlog) table created for it.
  * The definition of the incremental refresh materialized view contains set operators.
  * The columns used in the incremental refresh materialized view are not maintained in the mlog of the base table.

* Solution: Check whether the definition of the incremental refresh materialized view meets the incremental refresh requirements. For more information, see [Refresh materialized views](../../300.database-object-management/100.manage-object-of-mysql-mode/600.manage-views-of-mysql-mode/200.manage-materialized-views-of-mysql-mode/400.refresh-materialized-views-of-mysql-mode.md).

## ERROR 9762 (42000) : Loading local data is disabled; this must be enabled on both the client and server sides

* OceanBase error code: 9762

* MySQL compatible error code: 3948

* Cause: The local data import fails.
* Solution: If you want to use the load data local feature, make sure that:

  * OBClient version is not earlier than 2.2.4.
  * ODP version is not earlier than 3.2.4 (not required for direct connection to OBServer).
  * OBJDBC version is not earlier than 2.4.8 (if you use Java + OBJDBC).

    Alternatively, you can use the native client of MySQL or MariaDB. The client version does not matter.

    <main id="notice" type='explain'>

    * Enable the variable.

        ```shell
        set @@local_infile=1;
        ```

    * Check the variable.

        ```shell
        show variables like 'local_infile';
        ```

## ERROR 20000 (HY000) : The stored procedure 'raise_application_error' was called which causes this error to be generated","-%05ld: %.\*s

* OceanBase error code: 20000

* Cause: A user-defined exception is generated by calling the `RAISE_APPLICATION_ERROR` procedure. This error code is an implicit code, and the actual error code specified by the user takes precedence. The range of user error codes specified by the `RAISE_APPLICATION_ERROR` procedure is 20000 - 20999.

* Solution: No action is required for a user-defined exception, which is thrown explicitly by the user.

## ERROR 21000 (HY000) : error number argument to raise_application_error of '%d' is out of range

* OceanBase error code: 21000

* Cause: The error code of the user-defined exception generated by calling the `RAISE_APPLICATION_ERROR` procedure is out of range. The specified error code must be in the range of 20000 - 20999.

* Solution: Set the error code to a value in the range of 20000 - 20999.

## ERROR 32491 (HY000) : snapshot expression not allowed here

* OceanBase error code: 32491

* Cause: A SNAPSHOT expression is not allowed here. SNAPSHOT expressions are supported only for read-only statements.

* Solution: Remove the SNAPSHOT expression or modify the statement into a read-only one.
