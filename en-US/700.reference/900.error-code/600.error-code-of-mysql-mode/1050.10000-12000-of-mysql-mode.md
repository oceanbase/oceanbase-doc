## ERROR 11032 (HY000) : HDFS path message %s

* OceanBase error code: 11032

* Cause: The HDFS path message %s error occurs, typically in the following scenarios:

  1. In an HDFS environment with Kerberos authentication enabled, if access to an HDFS external table fails due to insufficient permissions, the -11032 error is returned.

  2. If the Kerberos authentication configuration is correct but the "HDFS: path not found" error still occurs, it may be because the external table path specified in the external table creation statement is incorrect and points to a non-existent path.

  3. External table access works normally initially, but after running queries for a while, the 11032 error appears. This may be because a bad block has occurred in a file under the HDFS external table path. Specifically, the HDFS DataNode reports an error and makes the data block inaccessible, triggering the error.

* Solution:
  1. Ensure that the Kerberos authentication keytab and principal are valid and that the corresponding user has access permissions to the HDFS cluster. Then, reconfigure the external table permissions and set up Kerberos authentication.

  2. Verify that the corresponding HDFS path is correct and exists. Re-establish the HDFS path mapping for the external table.

  3. Report the issue to the customer's operations team. After confirming the bad block situation, you can choose to adjust the bad blocks or switch environments to continue verification.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This error code is introduced in V4.5.0.</p>
</main>
