## ERROR 11032 (HY000) : HDFS path message %s

* OceanBase error code: 11032

* Cause: The HDFS path message %s error occurs, typically in the following scenarios:

  1. In an HDFS environment with Kerberos authentication enabled, if access to an HDFS external table is denied due to insufficient permissions, a -11032 error will be returned.

  2. If Kerberos authentication is correctly configured but the HDFS: path not found error still occurs, it may be because the external table path specified in the external table creation statement is incorrect and points to a non-existent path.

  3. External table access initially works normally, but after running queries for a period of time, a 11032 error occurs. This might be because a bad block exists in a file under the HDFS external table path. Specifically, the HDFS DataNode reports an error on that data block, making it inaccessible, which triggers the error.

* Solution:
  1. Ensure the Kerberos authentication keytab and principal are valid, and the corresponding user has access permissions to the HDFS cluster. Then, reconfigure the external table permissions and set up Kerberos authentication.

  2. Verify that the corresponding HDFS path is correct and exists. Re-establish the HDFS path mapping for the external table.

  3. Report the issue to the customer's operations team. After confirming the bad block situation, you can choose to adjust the bad blocks or switch environments to continue verification.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This error code is introduced in V4.5.0.</p>
</main>

## ERROR 11126 (HY000) : unit \'%.*s\' not recognized

* OceanBase error code: 11126
* Error cause: The time unit parameter is not recognized when calling the date truncation function (such as DATE_TRUNC or DATETRUNC).
  
* Solution: Check the first parameter of the date truncation function in your SQL statement to ensure that its spelling is correct and it is a valid time unit keyword supported by OceanBase Database.

## ERROR 11127 (HY000) : Privilege not allowed for sensitive rules

* OceanBase error code: 11127

* Cause: An operation related to sensitive data rules was performed, but the privileges held are insufficient for this operation.
  
* Solution: Confirm the required privileges for the operation and grant the corresponding privileges.
