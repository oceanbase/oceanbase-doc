# 9000 ~ 9499

This range represents backup and restore error codes and STORAGE 3.0 error codes.

## ERROR 9001 (HY000) : URI error


* OceanBase Error 9001:

* Cause: The link of the destination of the backup restore task is incorrect.

* Solution: Check and modify the relevant configurations for backup and restore.

## ERROR 9002 (HY000) : OSS file MD5 error


* OceanBase Database error code: 9002

* Reason for the error: The data of the object stored in Alibaba Cloud OSS is incorrect. This error may be caused by an abnormally large file.

* Solution: Contact Alibaba Cloud Technical Support to identify the specific cause of the error.

## ERROR 9003 (HY000) : OSS error


* OceanBase error code: 9003

* The error is due to an unknown error in Object Storage Service (OSS).

* Solution: Contact Alibaba Cloud technical support to find out the cause.

* OceanBase error code: 9010

* Cause: The checksum of the file stored in Alibaba Cloud OSS does not match that of the restored or backup file, which might indicate an abnormal Alibaba Cloud OSS file or a bug in the backup and restore program.

* Solution: Contact OceanBase Technical Support to help troubleshoot the issue.

## ERROR 9038 (HY000) : Cannot add replica during set member list in restore


* OceanBase Database error code: 9038

* Error reason: The `set member list` phase does not support replication.

* Solution: The `set member list` step of the restore does not support replica replication. If a majority of replicas still exist, the restore can continue. If no majority of replicas exists, you must cancel the restore and reschedule the restore task.

## ERROR 9039 (HY000) : pg log archive leader changed


* OceanBase Database error code: 9039

* Error reason: The leader of the log archive has changed.

* Solution: This is an internal error. After the leader change is detected, the current PG log archive process is interrupted. The new leader will automatically continue the backup process. No manual intervention is required.

## ERROR 9040 (HY000) : backup can not start


* OceanBase Database error code: 9040

* Error reason: The log archive is not in the `DOING` state. Therefore, you cannot start the data backup.

* Solution: Wait until the log archive enters the `DOING` state. If the log archive remains in the `BEGINNING` state for a long time, contact OceanBase Technical Support for assistance.
