# 9000 ~ 9499

This range indicates backup and restore error codes and STORAGE 3.0 error codes.

## ERROR 9001 (HY000) : URI error

* OceanBase error code: 9001

* Cause: The destination endpoint URL for backup and restore may be incorrect.

* Solution: Check and modify the backup and restore configurations.

## ERROR 9002 (HY000) : OSS file MD5 error

* OceanBase error code: 9002

* Cause: The data check of the OSS file fails. There may be abnormal errors on OSS.

* Solution: Contact OSS Technical Support to troubleshoot the issue.

## ERROR 9003 (HY000) : OSS error

* OceanBase error code: 9003

* Cause: An unknown error occurs on OSS.

* Solution: Contact OSS Technical Support to troubleshoot the issue.

Sample cases:

* [Failed to set backup path: OSS error](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000208059)
* [Backup and restore failed, and the tenant is in the restoring state](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000340640)

## ERROR 9004 (HY000) : Init MD5 fail

* OceanBase error code: 9004

* Cause: There is an error in initializing MD5 in OpenSSL.

* Solution: Contact OceanBase Technical Support for troubleshooting.

## ERROR 9005 (HY000) : Out of element

* OceanBase error code: 9005

* Cause: The number of shards exceeds the limit.

* Solution: Contact OceanBase Technical Support for troubleshooting.

## ERROR 9006 (HY000) : Update MD5 fail

* OceanBase error code: 9006

* Cause: There is an error in updating MD5.

* Solution: Contact OceanBase Technical Support for troubleshooting.

## ERROR 9007 (HY000) : Invalid OSS file length

* OceanBase error code: 9007

* Cause: The length of the OSS file is invalid. The file may be invalid.

* Solution: Contact OceanBase Technical Support for troubleshooting.

## ERROR 9010 (HY000) : OSS file MD5 not match

* OceanBase error code: 9010

* Cause: The checksums of the OSS file do not match. The data on OSS may be abnormal, or there may be a bug in the backup and restore process.

* Solution: Contact OceanBase Technical Support for troubleshooting.

## ERROR 9011 (HY000) : cannot find backup file

* OceanBase error code: 9011

* Cause: The backup file cannot be found. The configurations for backup and restore may be incorrect.

* Solution: Check and modify the backup and restore configurations.

Sample cases:

* [Error occurred during cross-region restore: backup object cannot be restored to the specified time point](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000208064)

## ERROR 9012 (HY000) : Can not get data version from timestamp

* OceanBase error code: 9012

* Cause: The `data version` parameter is not passed in the logical restore parameters.

* Solution: Contact OceanBase Technical Support for troubleshooting.

## ERROR 9013 (HY000) : Write OSS file error

* OceanBase error code: 9013

* Cause: There is an abnormal error when writing an OSS file. An unknown issue may occur on OSS.

* Solution: Contact OSS Technical Support to troubleshoot the issue.

## ERROR 9014 (HY000) : Another restore is in progress

* OceanBase error code: 9014

* Cause: The destination endpoint URL for backup and restore may be incorrect.

* Solution: Check and modify the backup and restore configurations.

## ERROR 9016 (HY000) : ob cluster name not equal

## ERROR 9017 (HY000) : rs list invalid

* Solution: Contact OceanBase Technical Support for assistance.

## ERROR 9018 (HY000) : agent has failed task

* Solution: Contact OceanBase Technical Support for assistance.

## ERROR 9019 (HY000) : restore partition is complete

## ERROR 9035 (HY000) : restore index failed

* OceanBase error code: 9035

* Cause: The index rebuilding failed after data restore.

## ERROR 9036 (HY000) : Backup is in progress

* OceanBase error code: 9036

* Cause: This error is generally caused by executing an operation that conflicts with backup operations.

## ERROR 9037 (HY000) : log archive status is not valid

## ERROR 9038 (HY000) : Cannot add replica during set member list in restore

* OceanBase error code: 9038

* Cause: Adding replicas is not supported during the `set member list` phase.

* Solution: The `set member list` phase does not support replica addition. If the majority of the replicas still exist, the restore operation can continue. If the majority of the replicas no longer exist, cancel the restore operation and reschedule a new restore task.

## ERROR 9039 (HY000) : pg log archive leader changed

* OceanBase error code: 9039

* Cause: The log archive leader has changed.

* Solution: This is an internal error. When the system detects that the leader has changed, it will interrupt the log archiving process of the current PG. The new leader will automatically continue the backup work without manual intervention from the O&M personnel.

## ERROR 9040 (HY000) : backup can not start

* OceanBase error code: 9040

* Cause: The log archive is not in the `DOING` state, so data backup cannot be started.

* Solution: Wait for the log archive to enter the `DOING` state. If it remains in the `BEGINNING` state for a long time, contact OceanBase Technical Support for troubleshooting.
