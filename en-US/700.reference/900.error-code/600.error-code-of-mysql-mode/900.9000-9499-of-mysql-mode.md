# 9000 ~ 9499

This range indicates backup and restore error codes and STORAGE 3.0 error codes.

## ERROR 9001 (HY000): URI error


* OceanBase error code: 9001

* Cause: The destination link specified in the backup and restore settings may be incorrect.

* Solution: Check the backup and restore configurations and modify them as needed.

## ERROR 9002 (HY000): OSS file MD5 error


* OceanBase error code: 9002

* Cause: Data verification for the OSS file failed. This may indicate an abnormality with the data on OSS.

* Solution: Contact OSS technical support to investigate the specific cause.

## ERROR 9003 (HY000): OSS error


* OceanBase error code: 9003

* Cause: An unknown error occurred in OSS.

* Solution: Contact OSS technical support to investigate the specific cause.

## ERROR 9033 (HY000): Backup meta info stored in system dictionary does not match with current system status


* OceanBase error code: 9033

  * For logs of the root service, contact OceanBase Technical Support to investigate the specific cause.

## ERROR 9035 (HY000): restore index failed


* OceanBase error code: 9035

* Error cause: Index rebuilding failed after restore completion.

* Solution: Check for indexes with a lock status of `error` on internal tables within the restored tenant and recreate those indexes.

## ERROR 9036 (HY000): Backup is in progress


* OceanBase error code: 9036

* Error cause: Generally, an operation that is mutually exclusive with backup is being performed.

* Solution: Stop data backup and log archiving before executing this command.

## ERROR 9037 (HY000): log archive status is not valid


* OceanBase error code: 9037

* Error cause: The log archive status is invalid.

* Solution: Contact OceanBase Technical Support for assistance in troubleshooting.

## ERROR 9038 (HY000): Cannot add replica during set member list in restore


* OceanBase error code: 9038

* Cause: Replication is not supported during the `set member list` phase.

* Solution: The `set member list` step of restore does not support replica replication. If a majority of replicas still exist, the restore can continue. If no majority replicas remain, you must cancel the restore and reschedule the restore task.

## ERROR 9039 (HY000): pg log archive leader changed


* OceanBase error code: 9039

* Cause: The log archive leader has switched.

* Solution: This is an internal error code. Detection of a leader switch interrupts the current PostgreSQL log archiving process. The new leader will automatically resume the backup work without requiring operational intervention.

## ERROR 9040 (HY000): backup can not start


* OceanBase error code: 9040

* Cause: Data backup cannot be started if log archiving is not in the `DOING` state.

* Solution: Wait for log archiving to enter the `DOING` state. If it remains in the `BEGINNING` state for a long time, contact OceanBase Technical Support to investigate the specific cause.

## ERROR 9041 (HY000): cancel backup do not allow


* OceanBase error code: 9041

* Cause: Canceling a backup task repeatedly is not allowed.

* Solution: Avoid repeatedly canceling a task that is already being canceled.

## ERROR 9042 (HY000): backup data version gap over limit


* OceanBase error code: 9042

* Cause: If data backup is not completed within 16 consecutive `Major Merges`, it will fail automatically.

* Solution: Investigate the cause of the slow data backup or confirm whether the `Major Merges` are occurring too frequently.

## ERROR 9044 (HY000): delete backup data is in progress
