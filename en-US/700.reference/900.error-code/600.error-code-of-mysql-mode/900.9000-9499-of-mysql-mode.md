# 9000 to 9499

This range indicates backup and restore error codes and STORAGE 3.0 error codes.

## ERROR 9001 (HY000): URI error

* OceanBase error code: 9001

* Cause: The destination link for backup and restore is incorrect.

* Solution: Check the backup and restore configurations and make the necessary modifications.

## ERROR 9002 (HY000): OSS file MD5 error

* OceanBase error code: 9002

* Cause: The data of the OSS file is corrupted, or the data on OSS is abnormal.

* Solution: Contact OSS technical support for troubleshooting.

## ERROR 9003 (HY000): OSS error

* OceanBase error code: 9003

* Cause: An unknown error occurred on OSS.

* Solution: Contact OSS technical support for troubleshooting.

## ERROR 9010 (HY000): OSS file MD5 not match

* OceanBase error code: 9010

* Cause: The checksum of the OSS file does not match, which means that the data on OSS is abnormal or there is a bug in the backup and restore program.

* Solution: Contact OceanBase technical support for troubleshooting.

## ERROR 9011 (HY000): cannot find backup file

* OceanBase error code: 9011

* Cause: The backup file cannot be found, which means that the specified backup and restore configurations are incorrect.

* Solution: Check the backup and restore configurations and make the necessary modifications.

## ERROR 9033 (HY000): Backup meta info stored in system dictionary does not match with current system status

* OceanBase error code: 9033

* Cause: The status of the backup is inconsistent.

* Solution:

  * If the error occurred during log archive of an OBServer node, it is generally caused by the start or stop of log archive. In this case, no manual intervention is needed.

  * If the error occurred during log archive of the RootService, contact OceanBase technical support for help.

## ERROR 9035 (HY000): restore index failed

* OceanBase error code: 9035

## ERROR 9036 (HY000): Backup is in progress

* OceanBase error code: 9036

* Cause: Generally, this error occurs when you perform an operation that conflicts with a backup.

* Solution: Run the command again after the data backup and log archive are stopped.

## ERROR 9037 (HY000): log archive status is not valid

* OceanBase error code: 9037

* Solution: Contact OceanBase technical support for help.

## ERROR 9038 (HY000): Cannot add replica during set member list in restore

* OceanBase error code: 9038

* Cause: Replication is not supported during the `set member list` phase of the restore.

* Solution: Replication is not supported during the `set member list` step of restore. If a majority of replicas still exists, restore can continue; if not, cancel the restore and reschedule the restore task.

## ERROR 9039 (HY000): pg log archive leader changed

* OceanBase error code: 9039

* Cause: The log archive leader has switched.

* Solution: Internal error code. After detecting a leader switchover, the current PG will be interrupted. The new leader will automatically continue the backup work without O&M intervention.

## ERROR 9040 (HY000): backup can not start

* OceanBase error code: 9040

* Cause: The log archive is not in the `DOING` state, and therefore data backup cannot be started.

* Solution: Wait for the log archive to enter the `DOING` state. If it stays in the `BEGINNING` state for a long time, contact OceanBase technical support for help.

* Cause: The archived logs or backup data are discontinuous.

## ERROR 9080 (HY000): format file does not exist%s

* OceanBase error code: 9080

* Cause: The format file at the backup destination does not exist. The possible causes are as follows:

  * The format file is removed before the destination participates in a backup task.
  * The specified destination is not empty, and it does not contain a format file.

* Solution: Check whether the format file exists at the backup destination. If it does not, the destination is no longer valid. When you set a new destination, clear all files in the destination before adding it to backup.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This error code was introduced in V4.0.0. In V4.2.5 and earlier versions, the error message is <code>the format file does not exist under the destination</code>.</p>
</main>

## ERROR 9081 (HY000): format file does not match%s

* OceanBase error code: 9081

* Cause: The format file information at the backup destination does not match. The possible causes are as follows:

  * When you set the destination, you use a destination that belongs to another cluster, tenant, or backup type.
  * The format file at the destination is corrupted.

* Solution: Verify that the cluster, tenant, and backup type of the destination match those of the backup task. If they do not match, use the correct destination.

<main id="notice" type='explain'>
  <h4>Note</h4>

## ERROR 9200 (HY000): Extend ssblock file to smaller is not allowed

* OceanBase error code: 9200

* Cause: SSBlock files cannot be shrunk.

* Solution: Check whether the size specified in `ALTER SYSTEM SET datafile_size` is greater than the current SSBlock file size. If not, contact technical support for help.

## ERROR 9201 (HY000): Mark blocks timeout(5s) in auto extend process when alloc block fail

* OceanBase error code: 9201

* Cause: Macroblocks cannot be marked after the SSBlock file is automatically expanded.

* Solution: Contact technical support for help.

## ERROR 9202 (HY000): Auto extend param is not ready to start extending file

* OceanBase error code: 9202

* Cause: Automatic expansion may not be enabled due to configuration issues, or the preset disk usage of `datafile` has reached its upper limit.

* Solution: Check whether the `free_size` field in the `__all_virtual_disk_stat` table is 0. If yes, disk space is exhausted. Increase the `datafile` threshold or expand the disk.

## ERROR 9129 (HY000): object storage io error

* OceanBase error code: 9129

* Cause: An object storage error occurred. Common causes include connectivity and compatibility issues with object storage.

* Solution: Check object storage connectivity. After confirming that connectivity is normal, contact technical support for help.

## ERROR 9133 (HY000): locality do not exist in locality list. can not set:

* OceanBase error code: 9133

* Cause: The source endpoint specified for the backup or archive path does not exist.

* Solution: Query the `DBA_OB_ZONES` view to verify whether the specified locality exists. Correct the locality and try again.

## ERROR 9135 (HY000): tmp file exceeds disk quota

* OceanBase error code: 9135

* Cause: The amount of data written to disk by temporary files exceeds the configured upper limit.

* Solution: Check whether the SQL statement that triggered the error produces more data than expected (for example, whether the maximum temporary file data written to disk is expected to be 500 GB). If the data volume is as expected, adjust the `temporary_file_max_disk_size` parameter to an appropriate value.

## ERROR 9147 (HY000): can not access backup set file

* OceanBase error code: 9147

* Cause: During physical restore, an OBServer node cannot access the backup set file in the specified backup media.

* Solution: Check object storage connectivity. After confirming that connectivity is normal, contact technical support for help.
