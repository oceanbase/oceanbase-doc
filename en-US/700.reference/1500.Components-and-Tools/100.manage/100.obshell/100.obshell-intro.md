# obshell overview

OceanBase Shell (obshell) is a local command-line tool provided by the OceanBase community for operations and development teams. It requires no installation and is ready to use out of the box. obshell supports cluster management and maintenance, and exposes management APIs based on OBServer nodes. This enables unified management of clusters across different ecosystem products, making it easier for third-party tools to integrate with OceanBase and reducing the complexity and cost of cluster management.

No additional installation is needed for obshell. After installing the OceanBase-CE database by any method, you will find the obshell executable file in the `bin` directory of the working directory on any node.
