# obshell overview

OceanBase Shell (obshell) is a CLI tool that is installed with OceanBase Database Community Edition (OceanBase-CE) and is provided for the operations and maintenance (O&M) personnel and developers. obshell supports cluster O&M and provides O&M management APIs based on OBServer nodes. This allows different ecosystem products to manage the same cluster. This facilitates the integration of third-party products with OceanBase Database and reduces the complexity and costs of managing OceanBase clusters.

You do not need to separately install obshell. After you install OceanBase-CE, you can find the obshell executable file in the `bin` directory of the working directory of any node.
