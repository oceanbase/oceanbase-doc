# obshell backup commands

This topic introduces the obshell backup commands, which are used to set backup configurations and view backup tasks. The commands require that an OceanBase cluster has been initialized. You can run the command with the `-h` or `--help` option to view the help information.

## obshell backup set-config

You can use this command to set backup configurations for all tenants or a specified tenant.

```shell
${home_path}/bin/obshell backup set-config [flags]

# example
/home/admin/oceanbase/bin/obshell backup set-config -t tenant1 -d /path/to/backup/data -a /path/to/backup/archive
```

`home_path` is the installation directory of OceanBase Database. obshell is located in the `bin` directory of the installation directory.

The following table describes the parameters:

| Parameter | Required | Data type | Default value | Description |
| --- | --- | --- | --- | --- |
| -t/--tenant_name | No | string | N/A | The name of the tenant for which to set the backup configurations. If this parameter is not specified, configurations will be set for all tenants in the cluster. |
| -d/--data_backup_uri | No | string | N/A | The destination for backing up tenant data. If this parameter is not specified, the previously configured destination will be used. If no destination has been configured, the destination will be empty.<main id="notice" type='explain'><h4>Note</h4><p>This parameter takes effect only when the <code>-t<code>/<code>--tenant_name</code> parameter is specified. </p></main> |
| -a/--archive_log_uri  | No | string | N/A | The destination for archiving tenant logs. If this parameter is not specified, the previously configured destination will be used. If no destination has been configured, the destination will be empty.<main id="notice" type='explain'><h4>Note</h4><p>This parameter takes effect only when the <code>-t<code>/<code>--tenant_name</code> parameter is specified. </p></main> |
| -u/--backup_base_uri | No | string | N/A | The destination for backing up all tenants. After this parameter is configured, the data backup path and log archive path of each tenant will be automatically generated based on a specific rule under this path. <main id="notice" type='explain'><h4>Note</h4><p>This parameter takes effect only when the <code>-t<code>/<code>--tenant_name</code> parameter is not specified. An error will be returned if both parameters are specified. </p></main> |
| -c/--log_archive_concurrency | No | int | N/A | The total number of threads for archiving logs. |
| -b/--binding   | No | string | Optional | Specifies whether to prioritize user business or log archiving. Valid values: `Optional` (prioritize user business) and `Mandatory` (prioritize log archiving). The default value is `Optional`. |
| -i/--piece_switch_interval | No | string | N/A | The cycle for switching pieces. Valid values: [1d, 7d]. |
| -l/--archive_lag_target   | No | string | N/A | The maximum allowed log archive latency for a tenant. You must configure the log archive destination before you modify this parameter. |
| -D/--delete_policy | No | string | default | The cleanup strategy. A tenant that has a cleanup strategy will trigger an automatic cleanup every hour. Valid values: `default` (only backups in `-d`/`--data_backup_uri` and `-a`/`--archive_log_uri` are cleaned up). |
| -r/--delete_recovery_window | No | string | N/A | The time window for restoring backup data. The value must be specified with a time unit. For more information about this parameter, see [Parameters for cleaning up backup data](../../../../../600.manage/600.backup-and-recovery/500.clear-backup-data/500.parameters-of-cleaning-up-backup.md). |
| -s/--ha_low_thread_score    | No | int | N/A | The current number of threads for backup, backup cleanup, and other tasks with low priority. Valid values: [0, 100]. |

## obshell backup show

You can use this command to view backup tasks for all tenants or a specified tenant.

```shell
${home_path}/bin/obshell backup show [flags]

# example
/home/admin/oceanbase/bin/obshell backup show -d
```

`home_path` is the installation directory of OceanBase Database. obshell is located in the `bin` directory of the installation directory.

The following table describes the parameters:

| Parameter | Required | Data type | Default value | Description |
| --- | --- | --- | --- | --- |
| -t/--tenant_name | No | string | N/A | The name of the tenant whose backup tasks to view. If this parameter is not specified, backup tasks for all tenants in the cluster will be displayed. |
| -d/--show_detail | No | 无 | N/A | Specifies whether to display detailed information about backup tasks. This parameter does not require a value. |
