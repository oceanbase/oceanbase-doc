# Terminate a tenant session query

This topic describes how to terminate a query being executed by a specified tenant session while keeping the session connection.

## API description

If a password is set, you must authenticate. For more information, see [API hybrid encryption](../20.api-hybrid-encryption.md).

### Request path

DELETE /api/v1/tenant/:name/sessions/queries

### Request parameters

| Parameter | Type | Required | Example value | Description |
| --- | --- | --- | --- | --- |
| name | string | Yes | t1 | The name of the tenant. This parameter is specified in the path. |
| session_ids | []int | Yes | [12345, 12346] | The list of session IDs to terminate. |

### Response

| Parameter | Type | Description |
| --- | --- | --- |
| successful | bool | Indicates whether the request was successful. |
| timestamp | time.Time | The timestamp when the server completed the request. |
| duration | int | The time taken by the server to process the request, in milliseconds. |
| status | int | The HTTP status code. |
| traceId | string | The trace ID of the request. |
| error | ApiError | The error information returned by the request, including the following parameters:<ul><li>`code`: the error code.</li><li>`message`: the detailed error information.</li><li>`subErrors`: the sub-error information.</li></ul> |
