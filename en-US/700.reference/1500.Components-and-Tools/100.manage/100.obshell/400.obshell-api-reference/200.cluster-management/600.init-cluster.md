# Initialize cluster

## Call instructions

### API constraints

obshell Server performs security verification on this API. For more information, see [API hybrid encryption](../20.api-hybrid-encryption.md).

### Request path

POST /api/v1/ob/init

### Request parameters

| Parameter | Type | Required | Example value | Description |
| --- | --- | --- | --- | --- |
| import_script | bool | No | false | Specifies whether to import timezone data and GIS metadata to the sys tenant. The default value is `false`. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is supported in obshell V4.2.4.2 and later. </p></main> |
| create_proxyro_user | bool | No | false | Specifies whether to create the `proxyro` user and set the corresponding permissions in the `sys` tenant. The default value is `false`. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is supported in obshell V4.2.6 and later. </p></main> |
| proxyro_password | string | No | ***** | Specifies the password of the `proxyro` user. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is supported in obshell V4.2.6 and later. </p></main> |

### Return result

| Parameter | Type | Description |
| --- | --- | --- |
| successful | bool | Specifies whether the request is successful. |
| timestamp | time.Time | The timestamp indicating when the server finishes processing the request. |
| duration | int | The time taken by the server to process the request in milliseconds. |
| status | int | The HTTP status code conforming to the HTTP status code specification. |
| traceId | string | The trace ID of the request. |
| data | DagDetailDTO | For more information, see the **DagDetailDTO information data structure** section below. |
| error | ApiError | The error generated by the request, which contains the following information: <ul><li>`code`: the error code. </li><li>`message`: the detailed error message. </li><li>`subErrors`: the sub-error message. </li></ul> |

The data structure of the DagDetailDTO information is as follows:

| Parameter | Type | Description |
| --- | --- | --- |
| id | string | The general ID of the DAG. |
| dag_id | int | The DAG ID, which is the primary key recorded in OceanBase Database. |
| name | string | The name of the DAG. |
| stage | int | The current execution stage of the DAG. |
| max_stage | int | The total number of stages in the DAG execution process. |
| state | string | The execution status of the DAG. |
| operator | string | The type of DAG operation. |
| start_time | time.Time | The start time of DAG execution. |
| end_time | time.Time | The end time of DAG execution. |
| additional_data | map[string]any | Other data of the DAG. |
| nodes | []NodeDetailDTO | The information of all nodes in the DAG. For more information, see [Obtain the details of a node](../1000.task-management/2100.get-node-detail.md). |
