# Upload an OBProxy installation package

This topic describes how to upload an OBProxy installation package to the obshell meta-database by using obshell-sdk-python.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This API is supported in obshell V4.2.6 and later. </p>
</main>

## Considerations

* Make sure that obshell is running normally.

* Make sure that OBProxy is deployed on the node corresponding to the client.

## Sample code

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# Create a client instance. The node address is '10.10.10.1', the port is 2886, and the agent password is '***'.
client = ClientSet("10.10.10.1", 2886, PasswordAuth(agent_password='***'))

client.v1.upload_obproxy_pkg(
        "/home/download/obproxy-ce-4.3.3.0-5.el7.x86_64.rpm")
```
