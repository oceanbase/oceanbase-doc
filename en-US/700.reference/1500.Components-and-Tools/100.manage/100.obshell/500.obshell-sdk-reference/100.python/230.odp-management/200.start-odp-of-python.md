# Start ODP

This topic describes how to start OceanBase Database Proxy (ODP) on a specified node by using obshell-sdk-python.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This API is supported starting with obshell V4.2.6. </p>
</main>

## Considerations

* Make sure that obshell is running normally.

* Make sure that ODP is deployed on the node corresponding to the client.

## Sample code

:::tab

tab Synchronous task execution

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# Create a client instance. The node address is '10.10.10.1', the port is 2886, and the agent password is '***'.
client = ClientSet("10.10.10.1", 2886, PasswordAuth(agent_password='***'))

client.v1.start_obproxy_sync()
```

tab Asynchronous task execution

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# Create a client instance. The node address is '10.10.10.1', the port is 2886, and the agent password is '***'.
client = ClientSet("10.10.10.1", 2886, PasswordAuth(agent_password='***'))

dag = client.v1.start_obproxy()
# Wait for the task to complete.
client.v1.wait_dag_succeed(dag.generic_id)
```

:::
