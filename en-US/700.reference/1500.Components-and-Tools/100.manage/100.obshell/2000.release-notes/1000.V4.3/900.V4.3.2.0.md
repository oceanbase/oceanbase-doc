# OceanBase Shell V4.3.2.0

## Version information

* Release date: September 25, 2025

* Version: V4.3.2.0

* RPM version: obshell-4.3.2.0-52025092411

## New features

1. Multi-tenant support: Supports the creation and management of Oracle-type tenants.

2. Monitoring integration: Supports the configuration of Prometheus and Alertmanager components, and provides a complete performance monitoring and alerting solution.

3. New features in OB-Dashboard include:

   1. Backup and restore management: Supports tenant-level backup and restore functionality. For more information, see [Backup and restore overview](../../350.ob-dashboard/400.ob-dashboard-tenant/500.backup-and-recovery/100.tenant-backup-and-recovery-overview.md).

   2. Alert center: Supports the integration of a unified alert management and notification system. For more information, see [Alert overview](../../350.ob-dashboard/450.alarm-center/100.alarm-overview.md).

   3. Performance monitoring: Supports fine-grained performance monitoring at the cluster and tenant levels. For more information, see [Performance monitoring](../../350.ob-dashboard/420.Performance-monitoring.md).

   4. Tenant creation optimization: Enhances the creation process, supporting configuration options such as business load type, time zone, and case sensitivity (for MySQL tenants).

## Bug fixes

1. Fixed several display issues in OB-Dashboard.

2. Fixed the issue where the tenant's recoverable time interval was inaccurate.
