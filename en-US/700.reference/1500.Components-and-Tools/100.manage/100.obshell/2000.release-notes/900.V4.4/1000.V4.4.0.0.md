# OceanBase Shell V4.4.0.0 for local clusters

## Version information

* Release date: January 7, 2026

* Version: V4.4.0.0

* RPM version: obshell-4.4.0.0-32026010814

## New features

1. OceanBase Shell V4.4.0.0 provides inspection capabilities for clusters and tenants based on obdiag. This helps users identify system issues in advance and improve system stability. For more information, see [Manage inspection services](../../350.ob-dashboard/480.inspection-service.md).
   OceanBase Shell V4.4.0.0 allows you to analyze OceanBase clusters from the system kernel parameters and internal tables to identify existing or potential issues that may cause cluster anomalies.

2. OceanBase Shell V4.4.0.0 supports session management. For more information, see [Manage sessions](../../350.ob-dashboard/400.ob-dashboard-tenant/450.session-management.md). The following features are supported:

   * Session operations: You can close a specified session or abort the current query.

   * Session analysis: You can view session statistics to learn about the connection status and resource consumption.

   * Deadlock management: You can enable or disable the deadlock detection mechanism and view the history of deadlocks.

3. OceanBase Shell V4.4.0.0 supports credential management. For more information, see [Manage credentials](../../350.ob-dashboard/650.credential-management.md). The following features are supported:

   * Credential lifecycle management: You can create, edit, and delete host credentials.

   * Batch operations: You can verify and delete credentials in batches to improve management efficiency.

4. OceanBase Shell V4.4.0.0 supports the deletion of software packages. By removing unnecessary software packages, you can optimize the storage space of the system. For more information, see **Manage software packages**.

5. By default, OceanBase Shell V4.4.0.0 enables the dump feature before stopping a cluster. This significantly speeds up the restart of the cluster.
