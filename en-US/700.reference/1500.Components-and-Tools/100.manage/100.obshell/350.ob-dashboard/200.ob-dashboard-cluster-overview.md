# Cluster information

After logging in to the obshell Dashboard, the system defaults to the **Cluster Management** page. The **Cluster Management** page displays an overview of clusters under the current user, including: **Allocated Resources**, **OBServer Statistics**, **Tenant Statistics**, **Top 3 Tenants by Compaction Time**, **Top 3 Tenants by Resource Usage**, and **Topology Structure**. It also supports parameter management, cluster start/stop, version upgrades, and obshell upgrades.

This topic only covers the display information on the **Cluster Management** page. For other operational steps, see [Manage clusters](300.ob-dashboard-cluster.md).

## Cluster Resources

The **Cluster** section displays the cluster's operational status and the percentage of CPU, memory, and disk resources allocated to tenants. Hovering over the resource bar chart will show detailed allocation information. When you hover over the **···** in the top-right corner of the module, you can view the cluster name and deployment mode information.

## OBServer Statistics

The **OBServer Statistics** module allows you to view the operational status of OBServer nodes within the cluster, enabling you to promptly manage and maintain any OBServer nodes with abnormal statuses.

<!-- ![OBServer Statistics](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-02.png) -->

## Tenant Statistics

The **Tenant Statistics** module allows you to view the operational status of tenants within the cluster, enabling you to promptly manage and maintain any tenants with abnormal statuses. Clicking on the number following the operational status will take you to the **Tenant Management** page.

<!-- ![Tenant Statistics](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-03.png) -->

## Top 3 Tenants by Major Freeze Time

The **Top 3 Tenants by Major Freeze Time** section displays the three tenants sorted by their most recent major freeze time. A major freeze operation merges static and dynamic data, which can be time-consuming. When incremental data from dumps accumulates to a certain extent, a major freeze operation is performed to merge large versions.

This section displays the **CPU usage ratio**, **memory usage ratio**, and **data volume** of the top 3 OceanBase tenants.
