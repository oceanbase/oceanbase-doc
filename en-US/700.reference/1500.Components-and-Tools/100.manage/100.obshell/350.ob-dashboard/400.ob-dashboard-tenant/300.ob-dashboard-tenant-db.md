# Database Management

Click **Tenant Management** in the left-side navigation pane. On the **Tenant Management** page, click the name of the tenant in the **Tenant List** list to go to the **Overview** page of the tenant. Then, click **Database Management** in the left-side navigation pane to go to the **Database Management** page. This topic describes the information on the **Database Management** page and the operations you can perform on this page.

<!-- ![Overview](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-01.png) -->

## Create a database

Click **Create Database** in the upper-right corner of the **Database Management** page. In the **Create Database** dialog box, configure the **Database Name**, **Character Set**, **Collation**, and whether the database is read-only. Then, click **Submit** to complete the creation.

<!-- ![Create a database](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-03.png) -->

| Parameter  | Description  |
|-------|------|
| Database Name | The name of the database to be created. The database name must meet the following requirements:<ul><li>The length must be 2 to 128 characters.</li><li>The name must start with a lowercase letter and can contain lowercase letters, digits, and underscores. </li></ul> |
| Character Set | The character set of the database. You can select a character set from the drop-down list. |
| Collation  | The collation of the database. You can select a collation from the drop-down list. |
| Read-only | Specifies whether the database is read-only.  |

## Modify a database

Click **Edit** in the **Actions** column to modify the **Character Set**, **Collation**, and whether the database is read-only. After the modification, click **Submit** to complete the modification.

<!-- ![Edit a database](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-02.png) -->

## Delete a database

Click **Delete** in the **Actions** column. In the dialog box that appears, enter `delete` and click **Delete**.
