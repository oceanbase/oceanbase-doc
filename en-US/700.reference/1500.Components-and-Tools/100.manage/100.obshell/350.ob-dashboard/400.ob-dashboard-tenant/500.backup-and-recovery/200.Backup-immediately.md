# Immediately backup

## Prerequisites

* Before you perform a backup, make sure that you have deployed NFS. For more information, see [Deploy NFS](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971092).

* Create data storage directories and log storage directories and grant read and write permissions. Each tenant must have an independent empty directory for backup.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Currently, obshell Dashboard only supports NFS as a backup media type.</p>
</main>

## Procedure

1. Log in to obshell Dashboard.

2. In the left-side navigation pane, click **TENANTS**.

3. In the **TENANTS** page, click the name of the tenant in the **TENANT LIST** list.

4. On the **Overview** page of the tenant, click **Backup & Restore** in the left-side navigation pane to go to the **Backup & Restore** page.

5. In the upper-right corner of the page, click **Immediately Backup** to go to the **Immediately Backup** page.

6. Fill in or modify the storage configuration.

   * If the tenant to be backed up has a backup storage configuration, the storage configuration will be automatically filled in, and you can modify it in the editing box.

   * If the tenant to be backed up does not have a backup storage configuration, you need to manually fill in the storage configuration.

7. After filling in or modifying the storage configuration, click **Test and Configure** to test and configure the storage configuration.

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>After you click <b>Test and Configure</b>, obshell will create a task to test and configure the storage configuration. You can click <b>View Task</b> to view the task. Normally, the task will be completed within a few seconds. If the task fails, go to the task center to view and fix the error. You can click <b>Immediately Backup</b> only after the task is completed.</p>
   </main>

   <!-- ![Immediately backup](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/200.Backup-immediately.png) -->

8. Select the data backup method.

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>In physical backup mode, an incremental backup must be preceded by a full data backup.</p>
   </main>

9. Click **Immediately Backup** to generate a backup task. You can click **View Task** to view the backup task progress.
