# Overview of Backup and Restore

Click **Tenant Management** in the left-side navigation pane. On the **Tenant Management** page, click the name of the tenant in the **Tenant List** to go to the **Overview** page of the tenant. Click **Backup and Restore** in the left-side navigation pane to go to the **Backup and Restore** page. This topic describes the information on the **Backup and Restore** page and the operations that you can perform on the page.

On the **Backup and Restore** page, you can view the basic information about backup and restore operations in the obshell Dashboard, as well as the backup and restore tasks. You can also go to the corresponding page to initiate a restore or perform an immediate backup.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>You cannot perform backup and restore operations on the sys tenant. </p>
</main>

## Basic information

In the Basic information section, you can view the **Last Full Backup**, **Last Log Backup**, and **Log Delay** to understand the current backup and restore time point information.

## Backup tasks

Backup tasks include data backups and log backups.

### Data backup

On the **Data Backup** tab, you can view the **ID**, **Backup Method**, **Backup Set ID**, **Start Time**, **End Time**, **Status**, and **Actions** of data backups. You can filter backup tasks based on different statuses. For more information, see the table below. You can click the sort icon next to **Start Time** or **End Time** to sort data backup information in ascending or descending order. You can also select **Last 24 Hours**, **Last 7 Days**, or **Last 30 Days** in the upper-right corner of this module to view data backup tasks within the specified time period. You can also select **Custom** to view data backup tasks within a specific time period.

<!-- ![Backup tasks](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.tenant-backup-and-recovery-overview-06.png) -->

| Parameter | Description |
|-------|------|
| ID | The unique identifier of the data backup task. Click the + sign to the left of the ID to view the **Backup Method**, **Backup Duration**, **Data Version**, and **Storage Directory**. Click the - sign to the left of the ID to hide the details.  |
| Backup Method | The backup method. Valid values: **Incremental** and **Full**. |
| Backup Set ID | The ID of the backup set.  |
| Start Time | The start time of the backup.  |
| End Time | The end time of the backup.  |
| Status | The status of the data backup. You can filter backup tasks based on their status. |
| Actions | <ul><li>Click **View Reason** under **Actions** to view the reason for a failed data backup task. </li><li>Click **Cancel** under **Actions** to cancel a data backup task. </li></ul> |

### Log backup

On the **Log Backup** tab, you can view the **Backup Method**, **Last Backup Time**, **Delay (s)**, **Storage Directory**, **Start Time**, **Status**, and **Actions** of the data. For more information, see the following table. You can click the sort icon next to **Last Backup Time** or **Delay (s)** to sort the data backup information in ascending or descending order. You can also select **Last 24 Hours**, **Last 7 Days**, or **Last 30 Days** in the upper-right corner of this section to view the data backup tasks in the corresponding time period. You can also select **Custom** to view the data backup tasks in a specific time period.

<!-- ![Log backup](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.backup-and-recovery-overview-03.png) -->

| Parameter | Description |
|-------|------|
| Backup Method | The backup method of the backup tenant. Only **Physical Backup** is supported.  |
| Last Backup Time | The time when the latest log backup was completed.  |
| Delay (s) | The time difference between the backup data and the actual data, in seconds.  |
| Storage Directory | The backup storage directory.  |
| Start Time | The start time of the backup.
| Status | The status of the log backup.  |
| Actions | You can stop or pause a running tenant, or resume or stop a paused tenant. <main id="notice" type='explain'><h4>Note</h4><p>After you stop log backup, you cannot restore data to any point in time. This may compromise data security. Proceed with caution. </p></main>|

## Restore tasks

On the **Restore Tasks** tab, you can view the **ID**, **Backup Cluster**, **Backup Tenant**, **Backup Method**, **Target Tenant**, **Restore Object**, **Start Time**, **Duration**, **Status**, and **Actions** of a restore task. You can filter restore tasks based on their status. In the upper-right corner of this tab, you can select **Last 24 Hours**, **Last 7 Days**, or **Last 30 Days** to view restore tasks within the specified time range. You can also select **Custom** to view restore tasks within a specific time range.

<!-- ![Restore tasks](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.tenant-backup-and-recovery-overview-09.png) -->

| Parameter | Description |
|-------|------|
| ID | The unique identifier of the restore task. Click the + sign to the left of the ID to expand and view the **Restore Time Point**, **End Time**, **Log Storage Directory**, and **Data Storage Directory**. Click the - sign to the left of the ID to collapse the view.  |
| Backup Cluster | The cluster where the backup tenant is located. |
| Backup Tenant | The tenant in the backup cluster that has been backed up. You can restore the data of this tenant to another tenant in the same cluster.|
| Backup Method | The backup method of the backup tenant. Only physical backup is supported. |
| Target Tenant | The tenant to which the data is restored. The data of the backup tenant is restored to this tenant. |
| Restore Object | The type of the restore target. |
| Start Time | The start time of the restore task. |
| Duration | The time taken for the restore task. |
| Status | You can filter tasks by status. The status of a physical backup task can be: **Restoring**, **Tenant Created**, **Upgrading**, **Restore Succeeded**, **Restore Failed**, **Waiting for Tenant Restoration to Complete**, **Completed**, or **Failed**. |
| Actions | You can click **Cancel** to cancel a task in the **Tenant Created** or **Waiting for Tenant Restoration to Complete** state. You can also click **View Reason** to view the reason for a task in the **Failed** state. |
