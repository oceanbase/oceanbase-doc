# Session management

In the left-side navigation pane, click **<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">Tenants</UI-TERM>**. On the **<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">Tenants</UI-TERM>** page, click the name of the tenant in the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** list to go to the **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">Overview</UI-TERM>** page of the tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">Session Management</UI-TERM>** page automatically appears, and the **<UI-TERM key="oas.components.SessionTabs.TenantSession">Tenant Session</UI-TERM>** tab is displayed. The **<UI-TERM key="odc.component.AskEventTrackingModal.SessionManagement">Session Management</UI-TERM>** page contains three tabs: **<UI-TERM key="ocp-v2.Detail.Session.TenantSession">Tenant Session</UI-TERM>**, **<UI-TERM key="ocp-v2.Realtime.Session.SessionStatistics">Session Statistics</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Session.ViewDeadlockHistory">View Deadlock History</UI-TERM>**. This topic describes the information on the **<UI-TERM key="workspace.header.session.management">Session Management</UI-TERM>** page and the operations that you can perform on this page.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>obshell supports session management starting from V4.4.0. To obtain the installation package, visit <a href="https://mirrors.aliyun.com/oceanbase/community/stable/el/7/x86_64/?spm=a2c6h.25603864.0.0.23db5d3eN9iVGQ">the Alibaba Cloud mirror site</a>. For information about how to upgrade obshell, see <a href="../../100.obshell-intro.md">Manage clusters</a>.</p>
</main>

## Manage tenant sessions

The **<UI-TERM key="ocp-v2.Detail.Session.TenantSession">Tenant Session</UI-TERM>** tab displays all the current sessions of the tenant, including the session ID, SQL statement, SQL ID, user, source, database name, command, execution time (s), status, OBServer, and OBProxy. You can search for sessions by session ID, user, source, or database name.

![Tenant sessions](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E7%A7%9F%E6%88%B7%E4%BC%9A%E8%AF%9D.png)

* View SQL information.

  When the session status is **ACTIVE**, click the value in the **<UI-TERM key="workspace.window.session.management.column.sql">SQL</UI-TERM>** column to view the SQL details of the session in a dialog box. You can click **<UI-TERM key="dss.List.DataSourceList.BtnList.Copy">Copy</UI-TERM>** to copy the SQL information.

  ![View SQL information](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%9F%A5%E7%9C%8B%20SQL%20%E4%BF%A1%E6%81%AF.png)

  ![Copy SQL information](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/450.session-management-%E5%A4%8D%E5%88%B6SQL.png)

* Search for sessions.

  You can search for sessions by user, source, or database name. Click the magnifying glass icon on the right side of the column name to open a search input box. Enter the user, source, or database name, and click **<UI-TERM key="odc.component.OSSDragger2.Search">Search</UI-TERM>** to view only the sessions that match the search criteria.

  ![Search for sessions](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%A3%80%E7%B4%A2%E4%BC%9A%E8%AF%9D.png)

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can also search for sessions by session ID in the upper-right corner of the <b>Session Management</b> tab. </p>
  </main>

* View only active sessions.

  After you enable **<UI-TERM key="oas.components.SessionTabs.ViewOnlyActiveSessions">View Only Active Sessions</UI-TERM>** in the upper-right corner of the session list, only the sessions with the **ACTIVE** status are displayed.

  ![View only active sessions](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%9F%A5%E7%9C%8B%E6%B4%BB%E8%B7%83%E4%BC%9A%E8%AF%9D.png)

* Terminate a session.

  In the operation column of the session list, click **<UI-TERM key="oas.MultiCloud.Optimization.constants.CloseSession">Close Session</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="obcloud-console.User.AccessKey.Determine">OK</UI-TERM>** to terminate the current session. If you select one or more sessions, the **<UI-TERM key="odc.components.RecordPage.CloseSession">Close Session</UI-TERM>** button appears in the lower-right corner of the **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">Session Management</UI-TERM>** tab. Click **<UI-TERM key="oas.MultiCloud.Optimization.constants.CloseSession">Close Session</UI-TERM>** and click **<UI-TERM key="oas.components.Session.PopConfirmKillSessions.Ok">OK</UI-TERM>** in the dialog box that appears to terminate the selected sessions.

* Terminate the current query.

  In the operation column of the session list, select **···** > **<UI-TERM key="ocp-v2.Detail.Session.List.CloseTheCurrentQuery">Close Current Query</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="obcloud-console.components.MetadataRuleTree.Determine">OK</UI-TERM>** to terminate the current query. If you select one or more sessions, the **<UI-TERM key="ocp-v2.Detail.Session.List.CloseTheCurrentQuery">Close Current Query</UI-TERM>** button appears in the lower-right corner of the **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>** tab. Click **<UI-TERM key="ocp-v2.Detail.Session.List.DisableTheCurrentQuery">Close Current Query</UI-TERM>** and click **<UI-TERM key="obcloud-console.ClusterSecurity.TDEEncryption.OpenEncryptionModal.Determine">OK</UI-TERM>** in the dialog box that appears to terminate the current queries of the selected sessions.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Terminating a session terminates the session with the specified Client Session ID. Terminating the current query terminates the statement that is currently being executed, but keeps the session connection unchanged. For more information, see <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004479616">KILL</a>. </p>
  </main>

## View session statistics

Click **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">Session Management</UI-TERM>** in the upper-right corner of the page, and then click **<UI-TERM key="oas.components.SessionTabs.SessionStatistics">Session Statistics</UI-TERM>** in the left-side navigation pane. The session statistics are displayed.

The statistics include overall session details such as **<UI-TERM key="ocp-v2.Detail.Session.Statistics.TotalNumberOfSessions">Total Sessions</UI-TERM>**, **<UI-TERM key="oas.CardAbnormalTable.hooks.AbnormalMonitor.NumberOfActiveSessions">Active Sessions</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Session.Statistics.MaximumActiveSessionTimeIn">Maximum Session Duration (s)</UI-TERM>**. The **<UI-TERM key="ocp-v2.Realtime.Session.SessionStatistics">Session Statistics</UI-TERM>** tab also displays the **<UI-TERM key="oas.CardAbnormalTable.hooks.AbnormalMonitor.NumberOfActiveSessions">Active Sessions</UI-TERM>** and **<UI-TERM key="ocp-v2.page.Diagnosis.TotalSessions">Total Sessions</UI-TERM>** for each **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.User.1">User</UI-TERM>**, **Source**, and **<UI-TERM key="odc.Database.AddDataBaseButton.Database">Database</UI-TERM>**.

![View sessions chart](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E4%BC%9A%E8%AF%9D%E7%BB%9F%E8%AE%A1.png)

* You can count the number of active sessions and total sessions for an object based on users, sources, or databases. For example, in the **<UI-TERM key="ocp-v2.Detail.Session.List.User">User</UI-TERM>** column of the list, click the magnifier to display the search field. Type a username and click **<UI-TERM key="obcloud-business.CostUnit.ResourceTable.config.Search">Search</UI-TERM>** to view only the session counts for that user.

* Support ascending and descending order for the number of active sessions and total number of sessions in each statistic. You can click the sort icon on the right of the Active Number and Total columns in the session statistics list to sort the sessions by ascending or descending order.

* Click the **<UI-TERM key="oat.src.utils.menu.UserManagement">User</UI-TERM>** > **Source** > **<UI-TERM key="obcloud-console.TenantWorkspace.TenantLoadData.config.Database">Database</UI-TERM>** in the Total field to go to the session details page of the corresponding user, source, or database, where all session details are displayed. For more information, see **Manage sessions of a tenant**.

## View deadlock history information

On the **Session Management** page, click **View Deadlock History** in the upper-right corner to go to the **Deadlock History** tab and view information about the deadlock history.

![View deadlock history information](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%9F%A5%E7%9C%8B%E6%AD%BB%E9%94%81%E5%8E%86%E5%8F%B2.png)

<main id="notice" type='explain'>
  <h4>Description</h4>
  <p>Deadlock detection is enabled by default at the cluster level and is a cluster-wide feature. To disable it, go to the <b>Clusters</b> page, click <b>···</b> in the upper-right corner, select <b>Disable Automatic Deadlock Detection</b> from the drop-down menu, and confirm the action in the modal dialog. After it's disabled, you can enable it again by following the same steps.</p>
</main>
