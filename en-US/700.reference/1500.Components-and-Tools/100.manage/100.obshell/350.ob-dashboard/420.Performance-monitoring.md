# Performance monitoring

Performance monitoring is one of the core modules of obshell Dashboard. It provides real-time monitoring capabilities for OceanBase clusters across multiple dimensions, including cluster, host, tenant, OBServer, and unit levels. This helps you quickly identify performance bottlenecks and optimize system resource usage.

## Access path

Log in to the obshell console and enter the address, username, and password of the Prometheus server. Then, click **<UI-TERM key="ocp-v2.SecurityCard.SSL.Open">Enable</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">Performance Monitoring</UI-TERM>** page. You can use the existing Prometheus server to enable performance monitoring. If you have not deployed a Prometheus server, we recommend that you use obd to deploy one. You can click **<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.OceanbaseCluster">OceanBase Cluster</UI-TERM>** or **<UI-TERM key="ocp-v2.page.Monitor.OceanbaseTenants">OceanBase Database Tenant</UI-TERM>** in the upper-right corner of the **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">Performance Monitoring</UI-TERM>** page to go to the corresponding tab.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>You need to enter the address, username, and password of the Prometheus server only when you log in to the <b>Performance Monitoring</b> page for the first time. </p>
</main>

## OceanBase cluster

The OceanBase cluster page displays data in five dimensions: cluster, host, tenant, OBServer, and unit. By default, it displays data in the cluster dimension of the database performance section. The monitoring items supported in different dimensions vary.

| Page  | Monitoring items  |
|-------|------|
| Database performance | The database performance section displays data in four dimensions: cluster, tenant, OBServer, and unit. It displays charts of the following performance metrics over different periods of time: **QPS**, **SQL response time**, **TPS**, **<UI-TERM key="oas.src.constants.monitor.TransactionResponseTime">Transaction Response Time</UI-TERM>**, **<UI-TERM key="obcloud-console.CardTable.monitor.MetricsPanel.NumberOfSessions">Sessions</UI-TERM>**, **<UI-TERM key="oas.CardAbnormalTable.hooks.AbnormalMonitor.RequestWaitingQueueTime">Request Waiting Queue Time</UI-TERM>**, **number of transaction logs**, **size of transaction logs**, **transaction log time**, **number of physical I/O operations**, **physical I/O time**, **physical I/O throughput**, and **number of transactions**.  |
| Host performance | The host performance section displays data in two dimensions: cluster and host. It displays charts of the following performance metrics: **Linux system load**, **<UI-TERM key="oms-community.Operation.Overview.constants.CpuUsage">CPU Utilization</UI-TERM>**, **<UI-TERM key="oat.Server.SystemInfo.Memory">Memory</UI-TERM>**, **<UI-TERM key="oms-community.Operation.Overview.constants.MemoryUsage">Memory Usage</UI-TERM>**, **<UI-TERM key="oceanbase-intl-business.components.BillingCalculator.IOPS">IOPS</UI-TERM>**, **<UI-TERM key="oas.CardAbnormalTable.hooks.AbnormalMonitor.IoTime">I/O Latency</UI-TERM>**, **IO throughput**, and **network throughput**. |

The following example describes how to view data in the cluster dimension of the database performance section.

4. In the **<UI-TERM key="ocp-v2.component.MonitorSearch.DataFiltering">Data Filtering</UI-TERM>** section, configure the data filtering conditions.

   | Filter  | Description  |

## OceanBase tenants

The obshell Dashboard allows you to view the performance, SQL, transaction, storage, and cache monitoring data of OceanBase tenants from the tenant and unit dimensions. You can view the monitoring data from the following two entry points:

* **Entry 1**: Log in to the obshell Dashboard. In the left-side navigation pane, click **<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">Tenants</UI-TERM>**. In the **<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.TenantManagement">Tenants</UI-TERM>** page, click the name of the target tenant to go to the management page of the tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">Performance Monitoring</UI-TERM>**. The system automatically displays the **Performance and SQL** tab.

* **Entry 2**: Log in to the obshell Dashboard. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>**. In the **<UI-TERM key="ocp-v2.page.Overview.OceanbaseCluster">OceanBase Cluster</UI-TERM>** section, click **<UI-TERM key="ocp-v2.page.Overview.OceanbaseTenants">OceanBase Database Tenant</UI-TERM>**. The **Performance and SQL** tab is displayed.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>When you select the <b>Performance Monitoring</b> tab from the <b>Tenant Management</b> page, you can view only the monitoring data of the current tenant. </p>
</main>
  
The OceanBase tenant page displays the performance data of OceanBase tenants from the tenant and unit dimensions in the **Performance and SQL**, **<UI-TERM key="ocp-v2.Detail.Monitor.Transaction">Transaction</UI-TERM>**, and **Storage and Cache** tabs. By default, the **Performance and SQL** tab is displayed. The monitoring metrics supported in different tabs are different.

| Tab | Monitoring metrics  |
|-------|------|
| Performance and SQL | Displays charts of the following metrics: **QPS**, **<UI-TERM key="oms-community.Home.Toolbar.ResponseTime">Response Time</UI-TERM>**, **SQL Execution Plan Category**, **SQL Execution Time**, **<UI-TERM key="obcloud-console.CardTable.monitor.MetricsPanel.NumberOfSessions">Sessions</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.WaitingTime">Waiting Time</UI-TERM>**, **Waiting Event Duration**, **Request Waiting Queue**, **<UI-TERM key="oas.CardAbnormalTable.hooks.AbnormalMonitor.RequestWaitingQueueTime">Request Waiting Queue Time</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.monitor.TenantCpuConsumption">CPU Consumption of Tenant</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.TabSqlMonitor.TenantThreadUsage">Thread Usage of Tenant</UI-TERM>**, **<UI-TERM key="src.component.Task.component.ThrottleFormItem.0A36C296">Memory Usage</UI-TERM>**, **MEMStore Usage Percentage**, **RPC Packet Duration**, **RPC Packet Throughput**, **Number of Open Cursors**, **RPC Request Success Rate**, **GTS Requests**, **RPC Network Latency**, and **RPC Delivery Failure**.  |
