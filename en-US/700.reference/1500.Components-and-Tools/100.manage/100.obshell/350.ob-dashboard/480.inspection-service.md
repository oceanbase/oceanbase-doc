# Manage inspection services

In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**. This topic describes how to initiate an inspection by using the obshell Dashboard.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>obshell V4.4.0 and later support the inspection service. You can download the installation package from <a href="https://mirrors.aliyun.com/oceanbase/community/stable/el/7/x86_64/?spm=a2c6h.25603864.0.0.23db5d3eN9iVGQ">the Alibaba Cloud mirror site</a> and upgrade obshell directly. For more information, see <a href="../100.obshell-intro.md">Manage clusters</a>. </p>
</main>

On the **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** page, you can view the ID, inspection scenario, start time, end time, task status, inspection result, and actions of an inspection task. You can click the icon next to **<UI-TERM key="ocp-v2.Inspection.Task.InspectionScenario">Inspection Scenario</UI-TERM>** to filter the inspection scenarios. You can also click the icon next to **<UI-TERM key="oma-pro.EvaluationLabel.DocumentEvaluation.StartTime">Start Time</UI-TERM>** or **<UI-TERM key="oat.Inspection.History.EndTime">End Time</UI-TERM>** to sort the inspection tasks in ascending or descending order.

| Parameter | Description |
|-------|------|
| ID | The unique identifier of the inspection task. |
| Inspection Scenario | The inspection scenario. Valid values: **Basic Inspection** and **Performance Inspection**. For more information about the inspection tasks of these scenarios, see [Initiate an inspection](../400.obshell-api-reference/750.inspection-service-management/100.trigger-inspection.md). |
| Start Time | The start time of the inspection task. |
| End Time | The end time of the inspection task.  |
| Task Status | The status of the inspection task. Valid values: **<UI-TERM key="odc.CommonDetailModal.Nodes.RollbackNode.Success">Successful</UI-TERM>**, **<UI-TERM key="oat.src.constants.task.Failed">Failed</UI-TERM>**, and **<UI-TERM key="ocp-v2.src.constant.compute.Running">Running</UI-TERM>**.  |
| Inspection Result | <ul><li>When the status of the inspection task is **<UI-TERM key="oma-pro.src.components.databaseForm.Successful">Successful</UI-TERM>**, the number of inspection results in the **<UI-TERM key="oms-cloud.pages.LoadPlaybackReport.PlaybackChart.Failed">Failed</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.HighRisk">High Risk</UI-TERM>**, and **<UI-TERM key="odc.page.Secure.interface.MediumRisk">Medium Risk</UI-TERM>** categories is displayed.</li><li>When the status of the inspection task is **<UI-TERM key="ocp-v2.src.constant.compaction.Failed">Failed</UI-TERM>**, no inspection result is displayed.</li></ul>  |
| Actions | <ul><li>When the status of the inspection task is **<UI-TERM key="oma-pro.EvaluationLabel.ObjectEvaluation.formComponent.Successful">Successful</UI-TERM>**, you can click **<UI-TERM key="ocp-v2.src.constant.inspection.ViewReports">View Report</UI-TERM>** to view the inspection report.</li><li>When the status of the inspection task is **<UI-TERM key="oms-v2.Overview.constants.Failed">Failed</UI-TERM>**, you can click **<UI-TERM key="oms-cloud.AlertTips.commponents.ErrorDetail.ErrorMessage">Error Message</UI-TERM>** to view the error message.</li></ul>  |

## Initiate an inspection

Point the pointer to the **<UI-TERM key="ocp-v2.Inspection.Item.InitiateInspection">Initiate Inspection</UI-TERM>** button in the upper-right corner of the **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** page. In the drop-down list, select **Basic Inspection** or **Performance Inspection** to initiate a basic or performance inspection.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Before you initiate an inspection service, make sure that obdiag V3.7.2 or later is installed on an OBServer node, or that the installation package of obdiag V3.7.2 or later is uploaded to <b>Software Packages</b>. Otherwise, the system displays the error message "The work directory or system path does not contain a valid obdiag package (>=3.7.2). Please upload or install (upgrade) the oceanbase-diagnostic-tool package. Go to <b>Software Packages</b>." For more information about how to install obdiag, see <a href="https://www.oceanbase.com/docs/common-obdiag-cn-1000000004494302">Install obdiag</a>. </p>
</main>

## View an inspection report

Click **<UI-TERM key="oma-pro.EvaluationLabel.EvaluationReport.ViewReports">View Report</UI-TERM>** in the Actions column of the inspection task. The **<UI-TERM key="ocp-v2.page.Report.InspectionReport">Inspection report</UI-TERM>** page automatically appears. This page displays the basic information, overview of inspection results, summary, and all results of the inspection task.

* The Basic Information section displays the inspection scenario, start time, and end time of the inspection task.

* The Overview of Inspection Results section displays the total number of inspection results, the number of high-risk inspection results, the number of medium-risk inspection results, and the number of failed inspection results.

* The Summary tab displays the overall inspection results, which are divided into the following categories: high-risk inspection items and results, medium-risk inspection items and results, and failed inspection items.

* The All Results tab displays the inspection items and their corresponding inspection results.
