# Manage credentials

In the left-side navigation pane, choose **<UI-TERM key="oms-v2.utils.hooks.useLayoutMenus.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.auditEvent.CredentialManagement">Credential Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.CredentialManagement">Credential Management</UI-TERM>** page. This topic describes how to create a connection credential for a host where a node in the cluster is located by using the obshell Dashboard.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>obshell supports credential management starting from V4.4.0. You can download the installation package from <a href="https://mirrors.aliyun.com/oceanbase/community/stable/el/7/x86_64/?spm=a2c6h.25603864.0.0.23db5d3eN9iVGQ">Alibaba Cloud mirror site</a> and use obshell to upgrade it. For more information, see <a href="../100.obshell-intro.md">Manage clusters</a>. </p>
</main>

## Create a credential

On the **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.CredentialManagement">Credential Management</UI-TERM>** page, click **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.CreateCredentials">Create Credential</UI-TERM>** in the upper-right corner. In the **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CreateCredentials">Create Credential</UI-TERM>** dialog box, configure the credential information. After the configuration is complete, click **<UI-TERM key="ocp-v2.page.AuditEvent.Determine">OK</UI-TERM>**.

![Create a credential](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E6%96%B0%E5%BB%BA%E5%87%AD%E6%8D%AE.png)

| Parameter | Description |
|-------|------|
| Credential Name | The name of the new credential. The username must meet the following requirements:<ul><li>It must be 2 to 64 characters in length.</li><li>It must start with a lowercase letter and can contain lowercase letters, digits, and underscores (_).</li><li>It must be unique.</li></ul> |
| User Type | The user type. Valid values: **<UI-TERM key="oat.components.CredentialModal.RootUser">root user</UI-TERM>** and **<UI-TERM key="oat.components.CredentialModal.CommonUsers">Ordinary User</UI-TERM>**. |
| Username | The username of the new credential. This parameter is displayed only when you select **<UI-TERM key="oat.components.CredentialModal.CommonUsers">Ordinary User</UI-TERM>**. |
| Password | The login password of the user specified in the username parameter.<main id="notice" type='explain'><h4>Note</h4><p>Currently, the only authentication method for a credential is password authentication. Make sure that the IP address of the application host to which you want to connect can be successfully connected to the username and password specified in the credential. </p></main> |
| Application Host | The IP address of the host to which the new credential is applied.<main id="notice" type='explain'><h4>Note</h4><p>The IP address cannot be used by an existing credential. </p></main> |
| SSH Port | The SSH port used by the host. |
| Description (Optional) | You can add a description to the credential to facilitate subsequent identification and use. |

## Verify a credential

On the **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">Credential Management</UI-TERM>** page, find the credential that you want to verify and click **<UI-TERM key="ocp-v2.page.Credential.OBProxy.Verification">Verify</UI-TERM>** in the **<UI-TERM key="obcloud-console.mergeData.ManageMergeTime.Operation">Actions</UI-TERM>** column of the row. If the verification is successful, the system displays **<UI-TERM key="ocp-v2.Credential.Component.ConnectTag.VerifiedSuccessfully">Verified.</UI-TERM>** at the top of the page and displays the **<UI-TERM key="ocp-v2.Credential.Component.ConnectTag.VerifiedSuccessfully">Verified.</UI-TERM>** tag next to the credential name. If the verification fails, you need to re-enter the credential information.

![Verify a credential](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E9%AA%8C%E8%AF%81%E5%87%AD%E6%8D%AE.png)

## Edit a credential

On the **<UI-TERM key="oat.ProductDeploy.Evidence.CredentialManagement">Credential Management</UI-TERM>** page, find the credential that you want to edit, hover the cursor over the **···** button in the **<UI-TERM key="src.pages.TaskList.components.ExecuteHistoryTable.7EF876C0">Actions</UI-TERM>** column of the row, and click **<UI-TERM key="obcloud-console.actions.base.ActionButton.Edit">Edit</UI-TERM>**. In the **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.EditCredentials">Edit Credential</UI-TERM>** dialog box, modify the credential information, including **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.SecretName">Credential Name</UI-TERM>**, **<UI-TERM key="oat.ProductDeploy.Evidence.UserType">User Type</UI-TERM>**, **<UI-TERM key="oms-community.components.OracleForm.FormItem.UserName">Username</UI-TERM>**, **<UI-TERM key="odc.components.UserPage.component.Password">Password</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.ApplicationHost">Application Hosts</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Description">Description</UI-TERM>**. After the modification is complete, click **<UI-TERM key="ocp-v2.Detail.Monitor.Determine">OK</UI-TERM>**.

![Edit a credential](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E7%BC%96%E8%BE%91%E5%87%AD%E6%8D%AE.png)

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>If you select multiple credentials, you can edit them in batches. </p>
</main>

## Delete a credential

On the **<UI-TERM key="ocp-v2.src.hook.useMenu.CredentialManagement">Credential Management</UI-TERM>** page, find the credential that you want to delete and hover the pointer over the **···** icon in the **<UI-TERM key="oms-cloud.components.MigrationPreTable.Operation">Actions</UI-TERM>** column of the credential. In the drop-down list, click **<UI-TERM key="src.page.WorkBench.SideBar.DashBoard.1BD93C73">Delete</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="obcloud-console.Alarm.NotificationTemplate.Detail.Delete">Delete</UI-TERM>**.

![Delete a credential](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E5%88%A0%E9%99%A4%E5%87%AD%E6%8D%AE.png)

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>You can also select multiple credentials and delete them in batches. </p>
</main>
