# Cluster Management

This topic describes some cluster management operations, including starting and stopping a cluster, upgrading a cluster, and upgrading obshell.

## Start and stop a cluster

In the left-side navigation pane, click **Cluster Management** to go to the **Cluster Management** page. In the upper-right corner of the page, click **Stop Cluster**. In the dialog box that appears, click **Stop**. The obshell Dashboard submits a task to stop the cluster and displays the task ID. You can click the ID to view the task execution status.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>Stopping a cluster terminates all services in the cluster. Proceed with caution. </p>
</main>

In the upper-right corner of the page, click **Start Cluster**. In the dialog box that appears, click **Start**. The obshell Dashboard submits a task to start the cluster and displays the task ID. You can click the ID to view the task execution status.

## Upgrade a cluster

In the left-side navigation pane, click **Cluster Management** to go to the **Cluster Management** page. Hover the cursor over **···** and click **Upgrade Version**. In the **Upgrade Version** page that appears, configure the upgrade information. After the configuration is complete, click **Upgrade**. In the dialog box that appears, click **OK**. The obshell Dashboard submits a task to upgrade the cluster and displays the task ID. You can click the ID to view the task execution status.

<!-- ![Upgrade a cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/300.ob-dashboard-cluster-01.png) -->

| Parameter | Description |
|-------|------|
| Cluster | The name of the cluster to be upgraded. This parameter is read-only. |
| OceanBase Database Version | The current version of the cluster to be upgraded. |
| Upgrade Method | You can choose **Rolling Upgrade** or **Planned Upgrade**. We recommend that you choose **Rolling Upgrade**.<ul><li>Rolling Upgrade: This method does not interrupt database access. </li><li>Planned Upgrade: This method interrupts database access and makes the database unavailable. Proceed with caution. </li></ul>  |
| Upgrade Version | Select the version from the list of uploaded OceanBase Database software packages. If no software package with a version higher than the current one is available, click **+ Upload Software Package** in the drop-down list to upload one.  |

## Upgrade OBShell

In the left-side navigation pane, click **Clusters** to go to the **Clusters** page. In the Actions column of the target cluster, click **...** and select **Upgrade OBShell**.

In the **Upgrade OBShell Agent Version** dialog box, select the OBShell Agent version from the list of uploaded OBShell packages. If no newer version is available, click **+ Upload Package** to upload a new package.

After configuring the settings, click **Upgrade**. In the confirmation dialog box, click **OK**. The OBShell Dashboard will submit the upgrade task and display the task ID. You can click the ID to view the task execution status.
