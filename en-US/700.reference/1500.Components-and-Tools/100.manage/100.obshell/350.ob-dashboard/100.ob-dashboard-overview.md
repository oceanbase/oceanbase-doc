# obshell Dashboard

The obshell Dashboard is an interactive web-based management interface provided by obshell, specifically designed for managing resources in OceanBase clusters and tenants. It offers monitoring capabilities for key resources and performance metrics, enabling efficient management of OceanBase clusters.

The obshell Dashboard service is fully integrated into the obshell process. Users can access and manage OceanBase clusters by visiting the service address where obshell is deployed. This design simplifies the management process and ensures minimal resource overhead, providing a simple and user-friendly control experience.

## Features

obshell Dashboard supports the following features for managing OceanBase clusters:

* Cluster management: View [cluster information](200.ob-dashboard-cluster-overview.md), including core details such as status, resource consumption, and topology. You can also manage clusters and parameters through [Manage Cluster](300.ob-dashboard-cluster.md) and [Manage Parameters](500.ob-dashboard-parameter.md).

* Tenant management: Manage tenants, databases, users, and parameters within a cluster. For more details, see [Manage Tenants](400.ob-dashboard-tenant/100.ob-dashboard-tenant.md).

* Backup and restore: Supports tenant-level backup and restore capabilities. For more information, see [Backup and Restore](400.ob-dashboard-tenant/500.backup-and-recovery/100.tenant-backup-and-recovery-overview.md).

* Performance monitoring: Displays performance data across multiple dimensions, including cluster, tenant, host, OBServer, and unit levels. It covers various aspects such as databases, hosts, performance and SQL, transactions, and storage and caching. For more details, see [Performance Monitoring](420.Performance-monitoring.md).

* Alarm center: obshell Dashboard provides alarm capabilities. You can view alarm events, set alarm suppression, and configure alarm rules to respond to and handle exceptions promptly, ensuring system stability. For more information, see [Alarm Center](450.alarm-center/100.alarm-overview.md).

* Package management: Upload software packages and ensure the target version is available for cluster and obshell upgrades. For more details, see [Package Management](600.ob-dashboard-package.md).

## Login and Logout

Starting from V4.3.0.0, obshell supports interactive cluster management through a graphical interface. After successfully installing obshell, you can access the obshell Dashboard (interactive management page) using the obshell node IP and port. By default, the login user is the root user under the sys tenant, with the password set during OceanBase cluster deployment. If the root@sys password is empty, you can directly click **Login**.

After logging in to the obshell Dashboard console, hover the cursor over the <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-overview-01.png" alt="User" style="height: 20px;"></span> icon in the upper-right corner and click **Log Out**. In the pop-up window, click **OK** to log out.

## View the version

Log in to the obshell Dashboard console, and click **Help** > **About obshell Dashboard** in the upper-right corner of the page to view the version.
