# Managing Alert Suppression

## Create a shield

### Procedure

1. Log in to the obshell console.

2. In the left-side navigation pane, click **Alert Center**.

3. Click the **Alert Shielding** tab.

4. On the **Alert Shielding** tab, click **Create Shield**.

5. On the **Shield Conditions** page, configure the shielding conditions.

   | Parameter | Description |
   |-------|------|
   | Shielding Object Type | Select the type of the shielding object from the drop-down list. The options are obcluster, obtenant, and observer. <ul><li>When the shielding object type is obcluster, select the target cluster as the shielding object. </li><li>When the shielding object type is obtenant, select the target cluster and the target tenant (all tenants or a specified tenant) as the shielding object. </li><li>When the shielding object type is observer, select the target cluster and the target host (all hosts or a specified IP address) as the shielding object. </li></ul> |
   | Shielding Alert Rule | Select the alert rule to be shielded from the drop-down list. You can select multiple alert rules. The alert rules listed on the **Alert Rules** tab are the same as those listed here. You can go to the **Alert Rules** tab to view the details. |
   | Tag | You can specify the metric to be shielded based on the tag matching condition. The system supports value matching and regular expressions. An alert will be shielded only when all conditions are met. This parameter is optional. |
   | Shielding End Time | Specify the end time of the alert shielding. Alerts will not be sent before the end time. This parameter is required. You can configure the end time in one of the following ways: <ul><li>Click the field to specify a custom end time. </li><li>Click the time after the field, such as 6 hours. The system will automatically fill in the current time plus 6 hours into the field. </li></ul> |
   | Remarks | You can add remarks to describe the shielding rule for easier identification and reuse. This parameter is required. |

   <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>If you want to shield an alert, we recommend that you click the <b>Shield</b> button in the Actions column of the alert event in the <b>Alert Events</b> tab. The system will automatically jump to the <b>Shield Conditions</b> page under the <b>Alert Shielding</b> tab and automatically fill in the shielding object type, shielding alert rule, and tag information associated with the alert event. You only need to configure the end time of the alert shielding and add remarks to successfully shield the alert. </p>
   </main>

   <!-- ![Shield Conditions](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-01.png) -->

6. Click **Submit**. The system returns to the **Shielding List** tab, and a new record is added to the list, indicating the newly created shielding.

## Edit a shielded alert

This section describes how to edit the conditions of an existing shielded alert.

### Prerequisites

The shielded alert list contains the shielded alert that you want to modify.

### Procedure

1. Log in to the obshell console.

2. In the left-side navigation pane, choose **Alert Center**.

3. Click the **Alert Shielding** tab.

4. In the query field on the **Alert Shielding** tab, enter the query conditions to search for the shielded alert. The **Shielded Alert List** displays all shielded alerts that match the query conditions.

5. Find the shielded alert that you want to edit and click **Edit** in the **Actions** column.

   <!-- ![Edit](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-02.png) -->

6. On the **Shielded Alert Conditions** page, you can edit the conditions of the shielded alert, including the type, name, and ID of the shielded object, the alert rule, tags, time, and remarks. For more information about the parameters, see the parameters described in **Create a shielded alert**.

   <!-- ![Shielded Alert Conditions](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-03.png) -->

7. Click **Submit**. The shielded alert is edited.

## Unshield

This section describes how to unshield an alert.

### Prerequisites

You have created a shield.

### Procedure

1. Log in to the obshell console.

2. In the left-side navigation pane, choose **Alert Center**.

3. Click the **Alert Shielding** tab.

4. In the query field on the **Alert Shielding** tab, enter the query conditions to search for the shield. The **Shield List** displays all shields that match the query conditions.

5. Select the shield that you want to unshield and click **Unshield** in the **Actions** column.

   <!-- ![Unshield](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-04.png) -->

6. In the confirmation dialog box that appears, click **Unshield**.

   <!-- ![Click Unshield](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-05.png) -->

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>Once a shield is unshielded, it cannot be restored. Proceed with caution.</p>
   </main>

7. After the shield is unshielded, the status of the shielded object in the **Shield List** changes from **Active** to **Expired**, and the **Edit** and **Unshield** buttons in the Actions column turn gray and become unavailable.
