# Parameter management

This topic describes how to view and modify the parameters of an OceanBase cluster by using the obshell Dashboard.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The parameters displayed on the <b>Cluster Management</b> page are the cluster-level and tenant-level parameters of the OceanBase cluster. The parameters displayed on the <b>Tenant Management</b> page are the tenant-level parameters and global system variables of the OceanBase cluster. </p>
</main>

## Cluster Management

Click **Cluster Management** in the left-side navigation pane. On the **Cluster Management** page, click **Parameter Management** in the upper-right corner to go to the **Parameter Management** page.

The **Parameter Management** page displays the **Parameter Name**, **Category**, **Current Value**, **Description**, **Effective Scope**, and **Read-only** columns. You can also modify parameters on this page. You can search for a specific parameter in the search box in the upper-right corner of the page. You can also filter parameters by **Category**, **Effective Scope**, **Effective Method**, and **Read-only**.

<!-- ![Cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-01.png) -->

You can click **Modify Value** in the **Actions** column to modify the **Value**, **Effective Scope**, and **Effective Object** of a parameter. You can click **+ Add Value** to set multiple values for different effective scopes. After you set the values, click **OK** to confirm the changes.

<!-- ![Modify Parameter](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-02.png) -->

## Manage tenants

In the left-side navigation pane, click **Tenants** to go to the **Tenants** page. In the **Tenants** list, click the name of the target tenant to go to the **Overview** page of the tenant. In the left-side navigation pane of the page, click **Parameter Management** to go to the **Parameter Management** page.

On the **Parameter Management** page, you can view the **Parameter Name**, **Current Value**, **Description**, and whether the parameter is **Read-only**. You can also view the operations that you can perform on the parameter. You can search for a specific parameter in the search box in the upper-right corner of the page. You can also filter parameters by whether they are modifiable by clicking the <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="Filter" style="height: 20px;"></span> icon next to **Read-only**.

Click **Modify Value** in the **Actions** column to change the value of the parameter. After you change the value, click **Submit** to save the changes.
