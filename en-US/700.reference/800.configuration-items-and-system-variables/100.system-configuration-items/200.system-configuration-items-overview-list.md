# Overview

This topic describes the cluster-level and tenant-level parameters of OceanBase Database.

## Cluster-level parameters

### Security

| Parameter | Description |
|---------|---------|
| [mysql_port](300.cluster-level-configuration-items/15400.mysql_port.md) | The port number of the SQL service protocol. |
| [rpc_port](300.cluster-level-configuration-items/19000.rpc_port.md)  | The port number of the remote access protocol.   |
