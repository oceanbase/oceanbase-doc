# audit_log_enable

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database V4.2.4. </p>
</main>

## Description

`audit_log_enable` specifies whether to enable the audit feature.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This parameter is applicable to only OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support the audit feature. </p>
</main>

## Limitations

* Query the parameter

  In the `sys` tenant or a user tenant, you can execute the `SHOW PARAMETERS` statement to query the parameter or query the `GV$OB_PARAMETERS` view for the parameter.

* Modify the parameter

  You can use the `ALTER SYSTEM SET` statement to modify the parameter in the `sys` tenant or a user tenant.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type | Boolean |
| Default value | FALSE |
| Value range | </li><li>TRUE</li><li>FALSE</li></ul> |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.   |

## Examples

Specify to enable the audit feature in a MySQL tenant.

```shell
obclient> ALTER SYSTEM SET audit_log_enable=TRUE;
```
