# ob_vector_index_merge_trigger_percentage

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.6.0, this parameter is available starting with V4.6.0. </p>
</main>

## Description

`ob_vector_index_merge_trigger_percentage` specifies the ratio of the memory occupied by the incremental segments to the total memory occupied by the partitioned indexes. When the ratio exceeds the value specified by this parameter, the system automatically triggers a segment merge to merge the incremental segments with the baseline segments.

<main id="notice" type='notice'>
  <h4>Applicability</h4>
  <p>This parameter is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query the parameter

  You can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view as the `sys` tenant or a MySQL user tenant.

* Modify the parameter

  You can execute the `ALTER SYSTEM SET` statement as the `sys` tenant or a MySQL user tenant.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Int |
| Default value | 20 |
| Value range | [0, 100), in percentage |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Considerations

* Default value (20%): The default value is applicable to most scenarios.
* Increase the value: To reduce the frequency of segment merges, especially when the write speed is high.
* Decrease the value: We recommend that you do not decrease the value in most scenarios.
* Set to `0`: This is equivalent to using the default value.

## Examples

Set the maximum ratio of the memory occupied by the incremental segments to the total memory occupied by the partitioned indexes to 30%.

```sql
ALTER SYSTEM SET ob_vector_index_merge_trigger_percentage = 30;
```

Query the current value of this parameter.

```sql
SHOW PARAMETERS LIKE 'ob_vector_index_merge_trigger_percentage';
```
