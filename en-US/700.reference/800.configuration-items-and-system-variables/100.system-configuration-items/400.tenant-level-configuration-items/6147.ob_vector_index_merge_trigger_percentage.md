# ob_vector_index_merge_trigger_percentage

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.6.0, this parameter is available starting with V4.6.0.</p>
</main>

## Description

`ob_vector_index_merge_trigger_percentage` specifies the maximum percentage of memory used by incremental segments in a partitioned index. When the memory used by incremental segments exceeds this percentage, the system automatically triggers a segment merge to combine the incremental segments with baseline segments.

<main id="notice" type='notice'>
  <h4>Applicability</h4>
  <p>This parameter is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query the parameter

  You can use the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view in the `sys` tenant or a MySQL user tenant to query this parameter.

* Modify the parameter

  You can modify this parameter in the `sys` tenant or a MySQL user tenant.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type | Int |
| Default value | 20 |
| Value range | [0, 100). The unit is percentage. |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Considerations

* Default value (20%): In most scenarios, you can use the default value.
* Increase the value: This reduces the frequency of segment merges between incremental segments and baseline segments, thereby avoiding excessive resource consumption during high write speeds.
* Decrease the value: We recommend that you do not decrease the threshold value in scenarios other than special testing.
* Set to `0`: This is equivalent to using the default value.

## Examples

Set the maximum percentage of memory used by incremental segments in a partitioned index to 30%.

```sql
ALTER SYSTEM SET ob_vector_index_merge_trigger_percentage = 30;
```

Query the current value of this parameter.

```sql
SHOW PARAMETERS LIKE 'ob_vector_index_merge_trigger_percentage';
```
