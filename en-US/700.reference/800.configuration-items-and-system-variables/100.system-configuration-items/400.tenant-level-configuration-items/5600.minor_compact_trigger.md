# minor_compact_trigger

`minor_compact_trigger` specifies the threshold for the total number of mini SSTables and minor SSTables for triggering a minor compaction. When the total number of mini SSTables and minor SSTables reaches the value of `minor_compact_trigger`, the system triggers a minor compaction in the background.

## Privilege requirements

* Query the parameter

  Users can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view to view this parameter in both `sys` and user tenants.

* Modify the parameter

  Users can modify this parameter in both `sys` and user tenants.

## Attribute description

| **Attribute** | **Description** |
|------------------|-----------|
| Type | Int |
| Default value | 2 |
| Value range | \[0, 16\] |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify it. |
| Effective upon OBServer node restart | No |

## Examples

Here is an example of setting `minor_compact_trigger` to 10, which specifies that a minor compaction is triggered when the total number of mini SSTables and minor SSTables reaches 10.

```shell
obclient> ALTER SYSTEM SET minor_compact_trigger = 10;
```
