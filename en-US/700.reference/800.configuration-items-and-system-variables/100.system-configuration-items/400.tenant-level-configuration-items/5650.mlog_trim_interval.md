# mlog_trim_interval

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.4.x, this parameter is available starting with V4.4.2. </li><li>For V4.3.5, this parameter is available starting with V4.3.5 BP4. </li></ul></p>
</main>

## Description

`mlog_trim_interval` specifies the scheduling cycle of the background automatic trimming task for materialized views (mlogs).

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type  | Time |
| Default value    | 1d |
| Value range  | [5s, 30d] |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Set the time interval of the background automatic trimming task for mlogs to `5s`.

    ```shell
    obclient> ALTER SYSTEM SET mlog_trim_interval = '5s';
    ```

* Set the time interval of the background automatic trimming task for mlogs to `1d`.

    ```shell
    obclient> ALTER SYSTEM SET mlog_trim_interval = '1d';
    ```
