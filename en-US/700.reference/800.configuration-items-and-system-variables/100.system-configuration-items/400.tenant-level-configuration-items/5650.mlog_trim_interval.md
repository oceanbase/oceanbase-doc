# mlog_trim_interval

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.6.x, this parameter is available starting with V4.6.0.</li><li>For V4.4.x, this parameter is available starting with V4.4.2.</li><li>For V4.3.5, this parameter is available starting with V4.3.5 BP4.</li></ul></p>
</main>

## Description

`mlog_trim_interval` specifies the interval at which the background automatic trimming task for materialized views (mlogs) is scheduled.

## Privilege requirements

* Query the parameter

  You can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter in the `sys` tenant and all user tenants.

* Modify the parameter

  You can modify this parameter in the `sys` tenant and all user tenants.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type  | Time |
| Default value    | 1d |
| Value range  | [5s, 30d] |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Set the interval for the background automatic trimming task for mlogs to `5s`.

    ```shell
    obclient> ALTER SYSTEM SET mlog_trim_interval = '5s';
    ```

* Set the interval for the background automatic trimming task for mlogs to `1d`.

    ```shell
    obclient> ALTER SYSTEM SET mlog_trim_interval = '1d';
    ```
