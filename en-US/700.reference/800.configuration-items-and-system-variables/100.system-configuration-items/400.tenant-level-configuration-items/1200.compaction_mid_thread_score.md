# compaction_mid_thread_score

The `compaction_mid_thread_score` parameter specifies the number of worker threads for medium-priority compactions.

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Integer       |
| Default value              | 0        |
| Valid range             | \[0,100\] |
| Take effect after a restart of an OBServer node | No        |
