# compaction_mid_thread_score

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.0.0, this parameter is available starting with V4.0.0. </p>
</main>

## Description

`compaction_mid_thread_score` specifies the number of threads for Compaction with medium priority. Compaction with medium priority refers to Compaction of Minor SSTables.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Int      |
| Default value              | 0, which indicates that the default value of 6 is used.        |
| Value range             | \[0,100\] |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Set the number of threads for Compaction with medium priority to 6.

```shell
obclient> ALTER SYSTEM SET compaction_mid_thread_score= 6;
```
