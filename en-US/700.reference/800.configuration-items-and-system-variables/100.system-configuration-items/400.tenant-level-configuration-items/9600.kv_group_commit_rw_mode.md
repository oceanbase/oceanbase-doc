# kv_group_commit_rw_mode

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This parameter was introduced in OceanBase Database V4.2.5. </li>
  <li>This parameter takes effect only in the OBKV-Table model. </li></ul>
</main>

## Description

`kv_group_commit_rw_mode` specifies the operation types supported for group commit.

## Limitations

* Query the parameter

  In the `sys` tenant or a user tenant, you can execute the `SHOW PARAMETERS` statement to query the parameter or query the `GV$OB_PARAMETERS` view for the parameter.

* Modify the parameter

  You can modify the parameter in the `sys` tenant or a user tenant.

## Attributes

| **Attribute** | **Description** |
|------------------|--------------|
| Type | String |
| Default value | ALL |
| Value range | </li><li>`ALL`: enables group commit for read and write operations. </li><li>`WRITE`: enables group commit only for write operations. </li><li>`READ`: enables group commit only for read operations. </li></ul>|
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Enable group commit only for read operations.

```shell
obclient> ALTER SYSTEM SET kv_group_commit_rw_mode = 'READ' tenant=<tenant_name>;
```
