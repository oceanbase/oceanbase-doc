# mds_minor_compact_trigger

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.1, this parameter is available starting with V4.4.1.</p>
</main>

## Description

`mds_minor_compact_trigger` specifies the number of MDS SSTables that triggers an MDS minor compaction. When the total number of MDS SSTables exceeds or equals the threshold, an MDS minor compaction is triggered to merge all MDS SSTables into a new MDS minor SSTable.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Int      |
| Default value               | 2        |
| Value range             | [2,16] |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.     |

## Examples

* Set the number of MDS SSTables that triggers an MDS minor compaction for the current user tenant to 2.

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2;
  ```

* Set the number of MDS SSTables that triggers an MDS minor compaction for the `mysql` tenant to 2.

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2 TENANT = 'mysql';
  ```
