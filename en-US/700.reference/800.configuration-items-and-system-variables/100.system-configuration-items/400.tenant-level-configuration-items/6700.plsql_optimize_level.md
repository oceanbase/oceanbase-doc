# plsql_optimize_level

The plsql_optimize_level parameter specifies the compilation optimization level.

|        Attribute        |                 Description                 |
|------------------|------------------------------------|
| Type             | Integer                               |
| Default value              | 1                                  |
| Valid values             | 0: indicates that optimization is disabled 1: indicates that optimization is enabled |
| Effective upon OBServer node restart for the change to take effect | No                                  |

Here is an example:

```sql
obclient> ALTER SYSTEM SET plsql_optimize_level=1;
```
