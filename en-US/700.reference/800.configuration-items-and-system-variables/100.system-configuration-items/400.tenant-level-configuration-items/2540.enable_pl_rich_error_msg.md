# enable_pl_rich_error_msg

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.4.x, this parameter is available starting with V4.4.1. </li><li>For V4.6.x, this parameter is available starting with V4.6.0. </li></ul></p>
</main>

## Description

`enable_pl_rich_error_msg` specifies whether to enable the feature that adds extra content to exceptions in PLSQL.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

# Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Bool |
| Default value               | False|
| Value range             |<ul><li>True: enabled. </li><li> False: disabled. </li></ul>|
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Enable the feature that adds extra content to exceptions in PLSQL.

    ```shell
    obclient> ALTER SYSTEM SET enable_pl_rich_error_msg = TRUE;
    ```

* Disable the feature that adds extra content to exceptions in PLSQL.

    ```shell
    obclient> ALTER SYSTEM SET enable_pl_rich_error_msg = FALSE;
    ```
