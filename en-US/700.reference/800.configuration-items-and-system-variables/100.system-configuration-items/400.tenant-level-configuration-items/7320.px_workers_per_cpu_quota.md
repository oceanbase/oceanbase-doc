# px_workers_per_cpu_quota

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>For V4.1.0 and later, this parameter is at the tenant level. <li></li>
<li>This parameter is available starting with V2.2.50. </li></ul>
</main>

## Description

`px_workers_per_cpu_quota` specifies the maximum number of parallel execution threads that can be allocated to each CPU.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Int        |
| Default value               | 10        |
| Value range             | [0, 20] |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Set the maximum number of parallel execution threads that can be allocated to each CPU to 10.

```shell
obclient> ALTER SYSTEM SET px_workers_per_cpu_quota =10;
```
