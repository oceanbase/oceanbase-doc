# mds_compaction_high_thread_score

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.1, this parameter is available starting with V4.4.1. </p>
</main>

## Description

`mds_compaction_high_thread_score` specifies the number of DAG threads for high-priority MDS compaction. The high-priority MDS compaction queue is used by MDS Mini Dump.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Int      |
| Default value               | 0, which indicates that the default value of 4 is used.        |
| Value range             | [0,100] |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.     |

## Examples

* Set the number of DAG threads for high-priority MDS compaction of the current user tenant to 4.

  ```shell
  obclient> ALTER SYSTEM SET mds_compaction_high_thread_score = 4;
  ```

* Set the number of DAG threads for high-priority MDS compaction of the `mysql` tenant to 4 in the `sys` tenant.

  ```shell
  obclient> ALTER SYSTEM SET mds_compaction_high_thread_score = 4 TENANT = 'mysql';
  ```
