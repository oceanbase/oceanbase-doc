# ob_enable_batched_multi_statement

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.2.30, this parameter is available starting with V2.2.30.</p>
</main>

## Description

`ob_enable_batched_multi_statement` specifies whether to enable the group execution optimization for batch processing.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Bool                       |
| Default value               | False                      |
| Value range             | <ul><li>False: Disable the group execution optimization for batch processing. </li><li>True: Enable the group execution optimization for batch processing.  </li></ul> |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Disable the group execution optimization for batch processing.

```shell
obclient> ALTER SYSTEM SET ob_enable_batched_multi_statement= False;
```
