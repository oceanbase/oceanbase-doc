# enable_sql_extension

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V3.2.1, this parameter is available starting with V3.2.1. </p>
</main>

## Description

`enable_sql_extension` specifies whether to enable the SQL extension feature for a tenant.

<main id="notice">
  <h4>Applicability</h4>
  <p>This parameter is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query the parameter

  You can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view in the `sys` tenant or a user tenant to query this parameter.

* Modify the parameter

  You can modify this parameter in the `sys` tenant or a user tenant.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Bool |
| Default value               | False |
| Value range             | <ul><li> True: enabled </li><li> False: disabled </li></ul>|
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.   |

## Examples

Disable the SQL extension feature for a tenant.

```shell
obclient> ALTER SYSTEM SET enable_sql_extension = False;
```
