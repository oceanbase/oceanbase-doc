# enable_manual_storage_cache_policy

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.4.x, this parameter is available starting with V4.4.0. </li>
<li>For V4.3.5, this parameter is available starting with V4.3.5 BP2. </li></ul>
</main>

## Description

`enable_manual_storage_cache_policy` specifies whether to enable the user-defined hot data caching policy.

<main id="notice">
<h4>Applicability</h4>
<p>This parameter is available only in OceanBase Database Shared-Storage (SS) mode. </p>
</main>

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query the value of this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

  <main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>If you are in Oracle-compatible mode, you cannot enable the hot data caching policy. If you modify this parameter in an Oracle-compatible mode user tenant or specify an Oracle-compatible mode user tenant or other non-user tenant (such as the <code>sys</code> tenant or the Meta tenant) to modify this parameter, the parameter value can be modified, but the hot data caching policy is not enabled. </p>
  </main>

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Parameter type  | Bool  |
| Default value    | True |
| Value range   | <ul><li>`True`: Enables all user-defined hot data caching policies. The system adopts the value of the `storage_cache_policy` parameter specified in the table, partition, or index. </li> <li> `False`: Disables all user-defined hot data caching policies. The system does not use the value of the `storage_cache_policy` parameter specified in the table, partition, or index. All tables, partitions, and indexes use the value of the `default_storage_cache_policy` parameter. </li></ul> |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Enable the user-defined hot data caching policy in the user tenant.

  ```shell
  obclient> ALTER SYSTEM SET enable_manual_storage_cache_policy= True;
  ```

* Enable the user-defined hot data caching policy for the `mysqltenant` tenant in the system tenant.

  ```shell
  obclient> ALTER SYSTEM SET enable_manual_storage_cache_policy= True TENANT = mysqltenant;
  ```
