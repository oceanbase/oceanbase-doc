# suspend_storage_cache_task

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.4.x, this parameter is available starting with V4.4.0. </li>
<li>For V4.3.5, this parameter is available starting with V4.3.5 BP2. </li></ul>
</main>

## Description

The `suspend_storage_cache_task` parameter specifies whether to suspend background cache tasks.

<main id="notice">
<h4>Applicability</h4>
<p>This parameter is applicable only to OceanBase Database in shared storage (SS) mode. </p>
</main>

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

  <main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>When you modify this parameter in an Oracle-compatible tenant or in the <code>sys</code> tenant by specifying an Oracle-compatible tenant or a non-user tenant (such as the <code>sys</code> tenant or the meta tenant), the parameter value can be modified, but the feature does not take effect. This is because the feature to manually specify a hot data caching strategy is effective only in MySQL-compatible tenants. </p>
  </main>

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type  | Bool  |
| Default value    | False |
| Value range   | <ul><li>`True`: Suspends current and new cache tasks. </li> <li> `False`: Does not suspend background cache tasks. </li></ul> |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* User tenant

  1. Suspend cache tasks in the current user tenant.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = True;
     ```

  2. Resume cache tasks in the current user tenant.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = False;
     ```

* System tenant

  1. Suspend cache tasks in the `mysqltenant` tenant.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = True TENANT = mysqltenant;
     ```

  2. Resume cache tasks in the `mysqltenant` tenant.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = False TENANT = mysqltenant;
     ```
