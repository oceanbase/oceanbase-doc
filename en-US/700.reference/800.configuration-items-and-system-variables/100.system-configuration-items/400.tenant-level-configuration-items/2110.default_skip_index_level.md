# default_skip_index_level

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.3.5, this parameter is available starting with V4.3.5 BP5. </li><li>For V4.4.x, this parameter is available starting with V4.4.2. </li></ul></p>
</main>

## Description

`default_skip_index_level` specifies the mechanism for generating Skip Indexes in incremental SSTables for a tenant.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type  | INT |
| Default value    | 0 |
| Value range   | <ul><li>0: Incremental SSTables do not generate Skip Indexes. </li> <li> 1: Incremental SSTables generate Skip Indexes for columns that have Skip Indexes in the baseline. This setting applies only to tables where `merge_engine = 'delete_insert'`. </li></ul>|
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Considerations

The `default_skip_index_level` parameter only affects tables created in user tenants.

* If `default_skip_index_level = 0`, incremental SSTables do not generate Skip Indexes.
* If `default_skip_index_level = 1`, incremental SSTables generate Skip Indexes for columns that have Skip Indexes in the baseline. This setting applies only to tables where `merge_engine = 'delete_insert'`.

## Examples

* MySQL-compatible mode: Set the default value of the `skip_index_level` parameter for tables created in user tenants to 1. The following example shows how to do this in MySQL-compatible mode.

    ```shell
    obclient> ALTER SYSTEM SET default_skip_index_level = 1;
    ```

* Oracle-compatible mode: Set the default value of the `skip_index_level` parameter for tables created in user tenants to 1. The following example shows how to do this in Oracle-compatible mode.

    ```shell
    obclient> ALTER SYSTEM SET "default_skip_index_level" = 1;
    ```
