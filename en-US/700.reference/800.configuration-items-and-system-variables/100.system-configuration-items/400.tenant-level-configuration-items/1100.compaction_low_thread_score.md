# compaction_low_thread_score

The `compaction_low_thread_score` parameter specifies the number of worker threads for low-priority compactions.

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Integer       |
| Default value              | 0        |
| Valid values             | \[0, 100\] |
| Take effect after a restart of an OBServer node? | No        |
