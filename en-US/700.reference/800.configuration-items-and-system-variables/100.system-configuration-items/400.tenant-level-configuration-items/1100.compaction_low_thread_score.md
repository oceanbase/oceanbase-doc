# compaction_low_thread_score

`compaction_low_thread_score` specifies the weight of the CPU time slice occupied by the worker threads for low-priority compaction tasks. Low-priority compactions are performed on major SSTables.

| **Attribute** | **Description** |
|------------------|----------|
| Type | Integer |
| Default value | 0, which means to use the internal default value 6. |
| Value range | \[0, 100\] |
| Effective upon OBServer node restart | No |
