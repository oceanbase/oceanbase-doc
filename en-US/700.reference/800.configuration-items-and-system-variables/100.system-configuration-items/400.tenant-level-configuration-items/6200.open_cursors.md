# open_cursors

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database V2.2.77. </p>
</main>

## Description

`open_cursors` specifies the maximum number of cursors that can be concurrently opened in a single session.

<main id="notice" type="">
  <h4>Applicability</h4>
  <p>This parameter is applicable to only OceanBase Database in Oracle mode. </p>
</main>

## Attributes

| Attribute | Description |
|------------------|-------------|
| Type | Integer |
| Default value | 50 |
| Value range | [0, 65535] |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No |

## Considerations

If the number of cursors concurrently opened in a session exceeds this limit, the error `OBE-01000: maximum open cursors exceeded` is returned.

## Examples

Set the maximum number of cursors that can be concurrently opened in a single session to 20.

```shell
obclient> ALTER SYSTEM SET open_cursors = 20;
```
