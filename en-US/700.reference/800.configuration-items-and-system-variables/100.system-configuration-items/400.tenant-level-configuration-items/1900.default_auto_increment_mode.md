# default_auto_increment_mode

`default_auto_increment_mode` specifies the default auto-increment mode of auto-increment columns.

| **Attribute** | **Description** |
| --- | --- |
| Type | String |
| Default value | order |
| Value range | <li>`order`: The values of the auto-increment column increase sequentially.<li>`noorder`: The values of the auto-increment column are only guaranteed to be unique. |
| Effective upon OBServer node restart | No |
