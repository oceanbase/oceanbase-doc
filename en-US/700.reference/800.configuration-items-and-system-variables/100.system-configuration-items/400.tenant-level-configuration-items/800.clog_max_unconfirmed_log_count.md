# clog_max_unconfirmed_log_count

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, the corresponding feature is no longer available, and this parameter is removed starting with V4.0.0. </p>
</main>

## Description

`clog_max_unconfirmed_log_count` specifies the maximum number of unconfirmed logs in the transaction module.

## Attributes

|      **Attribute**      |     **Description**     |
|------------------|----------------|
| Parameter type             | Int             |
| Default value              | 1500           |
| Value range             | \[100, 50000\] |
| Effective upon OBServer node restart | No              |
