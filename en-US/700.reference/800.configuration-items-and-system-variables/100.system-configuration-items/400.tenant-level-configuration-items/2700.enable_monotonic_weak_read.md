# enable_monotonic_weak_read

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is available starting with V1.4. </p>
</main>

## Description

`enable_monotonic_weak_read` specifies whether to enable monotonic weak reads.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**    |      **Description**      |
|------------------|--------------------|
| Type             | Bool                |
| Default value               | False<main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.2.1, the default value of this parameter is changed from True to False. </p></main>               |
| Value range             | <ul><li>True: enable monotonic weak reads. </li><li>False: disable monotonic weak reads. </li></ul>    |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.    |

## Examples

Disable monotonic weak reads.

```shell
obclient> ALTER SYSTEM SET enable_monotonic_weak_read =False;
```
