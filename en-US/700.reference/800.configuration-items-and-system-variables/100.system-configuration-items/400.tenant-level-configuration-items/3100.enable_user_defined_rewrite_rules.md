# enable_user_defined_rewrite_rules

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.1.0, this parameter is available starting with V4.1.0.</p>
</main>

## Description

`enable_user_defined_rewrite_rules` specifies whether to enable the rewrite binding feature.

## Privilege requirements

* Query the parameter

  `sys` and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  `sys` and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Bool |
| Default value               | False |
| Value range             |<ul><li> True: enable the feature. </li><li>False: disable the feature. </li></ul>|
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Considerations

The [DBMS_UDR](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/100.dbms-udr-overview-mysql.md) package provides the rewrite binding feature:

* Create a rewrite rule: [CREATE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/200.create-rule-mysql.md)
* Disable a rewrite rule: [DISABLE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/300.disable-rule-mysql.md)
* Enable a rewrite rule: [ENABLE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/400.enable-rule-mysql.md)
* Remove a rewrite rule: [REMOVE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/500.remove-rule-mysql.md)

## Examples

Disable the rewrite binding feature.

```shell
obclient> ALTER SYSTEM SET enable_user_defined_rewrite_rules = False;
```
