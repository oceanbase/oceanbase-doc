# compaction_high_thread_score

The `compaction_high_thread_score` parameter specifies the number of threads for high-priority compactions.

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Integer       |
| Default value              | 0        |
| Valid values             | \[0, 100\] |
| Effective upon OBServer node restart | No        |
