# enable_clog_persistence_compress

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the change in the storage architecture in V4.x, the log storage compression feature is not supported in V4.0.0. This parameter is therefore removed starting from V4.0.0. </li>
<li>Based on business requirements, OceanBase Database has re-enabled the log storage compression feature starting from V4.2.1. In V4.2.1 and later versions (excluding V4.3.0), you can use the tenant-level parameter <code>log_storage_compress_all</code> to control whether to enable the log storage compression feature. For more information about the <code>log_storage_compress_all</code> parameter, see <a href="5100.log_storage_compress_all.md">log_storage_compress_all</a>. </li></ul>
</main>

## Description

`enable_clog_persistence_compress` specifies whether to enable transaction log disk persistence compression.

## Attributes

|      **Attribute**      | **Description** |
|------------------|--------|
| Parameter type             | Bool                     |
| Default value              | false  |
| Effective upon OBServer node restart | No      |
