# enable_mlog_auto_maintenance

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.6.x, this parameter is available starting with V4.6.0.</li><li>For V4.4.x, this parameter is available starting with V4.4.2.</li><li>For V4.3.5, this parameter is available starting with V4.3.5 BP4.</li></ul></p>
</main>

## Description

`enable_mlog_auto_maintenance` specifies whether to enable the automatic management of materialized view logs (mlogs).

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type  | Bool |
| Default value    | True <main id="notice" type='notice'><h4>Notice</h4><p>In OceanBase Database V4.3.5 BP4: <ul><li>For newly created tenants, the default value is <code>True</code>.</li><li>For tenants upgraded from earlier versions of OceanBase Database (before V4.3.5 BP4), the default value is <code>False</code>.</li></ul></p></main>|
| Value range  | <ul><li>True: enables the automatic management of mlogs.</li><li>False: disables the automatic management of mlogs.</li></ul> |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Disable the automatic management of mlogs.

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = False;
    ```

* Enable the automatic management of mlogs.

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = True;
    ```
