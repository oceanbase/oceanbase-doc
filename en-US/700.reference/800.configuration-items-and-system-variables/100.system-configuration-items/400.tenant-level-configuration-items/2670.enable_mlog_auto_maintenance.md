# enable_mlog_auto_maintenance

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.4.x, this parameter was introduced starting with V4.4.2.</li><li>For V4.3.5, this parameter was introduced starting with V4.3.5 BP4.</li></ul></p>
</main>

## Description

The `enable_mlog_auto_maintenance` clause enables or disables the automatic management feature of materialized view logs (mlogs).

## Privilege requirements

* Query the parameter

  `sys` and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this configuration.

* Modify the parameter

  You can change the value of this parameter in the `sys` tenant or user tenants.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Parameter type | Bool |
| Default value    | True <main id="notice" type='notice'><h4>Notice</h4><p>In OceanBase Database V4.3.5 BP4: <ul><li>For a newly created tenant, the default value of this parameter is <code>True</code>.</li><li>For a tenant that was upgraded from an earlier version of OceanBase Database (before V4.3.5 BP4), the default value of this parameter is <code>False</code>.</li></ul></p></main>|
| Value range  | <ul><li>True: Enables MLog automated management feature. </li><li>False: Disables MLog automated management feature. </li></ul> |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Disable the automatic management of mlogs.

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = False;
    ```

* Enable mlog automation.

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = True;
    ```
