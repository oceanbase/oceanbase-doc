# plsql_v2_compatibility

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V3.2.3. </p>
</main>

## Description

`plsql_v2_compatibility` specifies the compatibility with Oracle 8.

<main id="notice">
  <h4>Applicability</h4>
  <p>This parameter is applicable only to OceanBase Database in Oracle mode. </p>
</main>

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|        Attribute      |  Description  |
|------------------|-------|
| Type             | Bool                    |
| Default value               | False                   |
| Value range             | <ul><li>True: compatible. </li><li>False: not compatible. </li></ul>   |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Disable the compatibility with Oracle 8.

```shell
obclient> ALTER SYSTEM SET plsql_v2_compatibility=false;
```
