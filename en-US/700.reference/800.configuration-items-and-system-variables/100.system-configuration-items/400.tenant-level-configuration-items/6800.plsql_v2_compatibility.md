# plsql_v2_compatibility

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.2.3, this parameter is available starting with V4.2.3. </p>
</main>

## Description

`plsql_v2_compatibility` specifies whether to enable the compilation disk-down feature for DDL operations of stored procedures.

## Privilege requirements

* Query the parameter
  `sys` tenants and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.
* Modify the parameter
  `sys` tenants and user tenants can modify this parameter.

## Attributes

|        Attribute        |                                                      Description                                                       |
|------------------|---------------------------------------------------------------------------------------------------------------|
| Type             | Boolean                       |
| Default value              | False                      |
| Value range             | <li> True: enabled   <li> False: disabled    |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Run the following command to disable the compilation disk-down feature:

```sql
obclient> ALTER SYSTEM SET plsql_v2_compatibility=false;
```
