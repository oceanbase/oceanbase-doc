# clog_persistence_compress_func

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the change in the storage architecture in V4.x, the log storage compression feature is not supported in V4.0.0. This parameter is removed starting from V4.0.0. </li>
<li>Based on business needs, OceanBase Database has re-supported the log storage compression feature starting from V4.2.1. In V4.2.1 and later versions (excluding V4.3.0), you can use the tenant-level parameter <code>log_storage_compress_func</code> to control the compression algorithm for log storage. </li></ul><p></p>
</main>

## Description

`clog_persistence_compress_func` specifies the compression algorithm for transaction log persistence.

## Attributes

|      **Attribute**      |                                 **Description**                               |
|------------------|--------------------------------------------------------------------------|
| Type             | String      |
| Default value              | lz4_1.0     |
| Value range             | <ul><li> none   </li><li> lz4_1.0   </li><li> zstd_1.0   </li><li> zstd_1.3.8</li></ul>    |
| Effective upon OBServer node restart | No          |
