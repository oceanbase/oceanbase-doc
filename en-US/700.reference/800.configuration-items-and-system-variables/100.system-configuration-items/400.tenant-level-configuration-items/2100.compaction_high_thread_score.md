# compaction_high_thread_score

`compaction_high_thread_score` is used to set the number of worker threads for high-priority Compaction. High priority refers to the Compaction operation on Mini SSTables.


| **Attribute** | **Description** |
|------------------|----------|
| Type | Integer |
| Default value | 0, which indicates to use the internal default value 6. |
| Value range | \[0, 100\] |
| Effective upon OBServer node restart | No |
