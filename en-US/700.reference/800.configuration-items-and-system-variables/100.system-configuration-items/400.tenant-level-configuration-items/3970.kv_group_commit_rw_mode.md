# kv_group_commit_rw_mode

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This parameter is available starting with V4.2.5. </li>
  <li>This parameter takes effect only in the OBKV-Table model. </li></ul>
</main>

## Description

`kv_group_commit_rw_mode` specifies whether to enable group commit for read and write operations.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**    |   **Description**   |
|------------------|--------------|
| Type             | String     |
| Default value               | ALL       |
| Value range             | <ul><li>ALL: group commit is enabled for read and write operations. </li><li>WRITE: group commit is enabled only for write operations. </li><li>READ: group commit is enabled only for read operations. </li></ul>|
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Enable group commit only for read operations.

```shell
obclient> ALTER SYSTEM SET kv_group_commit_rw_mode = 'READ' tenant=<tenant_name>;
```
