# sql_func_extension_mode

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.6.0, this parameter is available starting with V4.6.0. </p>
</main>

## Description

`sql_func_extension_mode` specifies whether to enable the mainstream compatible mode functions that do not conform to the naming conventions of MySQL.

<main id="notice">
  <h4>Applicability</h4>
  <p>This parameter applies only to MySQL mode of OceanBase Database. </p>
</main>

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type | Varchar |
| Default value | Empty string |
| Value range | <ul><li>Empty string: do not enable any compatible mode function extensions. </li><li>ClickHouse: enable the ClickHouse compatible mode functions. </li></ul> |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Considerations

OceanBase Database maintains a list of functions specific to each compatible mode. By default, these functions are not available. When you set the `sql_func_extension_mode` parameter to the corresponding mode, all functions in the list become available. You can then call these functions in SQL statements.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>The visibility of functions that are available by default in MySQL mode is not affected by this parameter. </p>
</main>

### Overlapping compatible modes

You can enable multiple compatible modes at the same time. When you enable multiple compatible modes, you can use commas to separate the names of the compatible modes:

```shell
ALTER SYSTEM SET sql_func_extension_mode = "mode1, mode2";
```

## Examples

Enable the ClickHouse compatible mode functions.

```shell
obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
```
