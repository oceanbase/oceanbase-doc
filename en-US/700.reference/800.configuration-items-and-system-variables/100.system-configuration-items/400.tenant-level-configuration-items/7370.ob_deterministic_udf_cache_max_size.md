# ob_deterministic_udf_cache_max_size

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database V4.2.5 BP6. </p>
</main>

## Description

`ob_deterministic_udf_cache_max_size` specifies the maximum amount of memory (in bytes) that can be used by the cache pool for all `deterministic` user-defined functions (UDFs) during statement execution.

## Privilege requirements

* Querying the parameter

  You can run the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view to query the value of this parameter in the `sys` tenant and all user tenants.

* Modifying the parameter

  You can modify this parameter in the `sys` tenant and all user tenants.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Parameter type    |    Capacity        |
| Default value      |  16M  |
| Value range    |    [0,+∞)<main id="notice" type='explain'><h4>Note</h4><p>If the value is 0, the execution cache feature is disabled. </p></main>       |
| Modifiability | Yes. You can modify this parameter by using the `ALTER SYSTEM SET` statement. |
| Effective only after OBServer restart | No. This parameter takes effect immediately after the setting. |

## Examples

* Run the following command to disable the execution cache feature:

    ```shell
    obclient> ALTER SYSTEM SET ob_deterministic_udf_cache_max_size='0B';
    ```

* Run the following command to set the maximum amount of memory that can be used by the cache pool for all `deterministic` UDFs to 16M:

    ```shell
    obclient> ALTER SYSTEM SET ob_deterministic_udf_cache_max_size='16M';
    ```
