tde_method
===============================

`tde_method` specifies the transparent data encryption (TDE) method.


| **Attribute** | **Description** |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Type | String |
| Default value | none |
| Value range | <li> `none`: TDE cannot be used.   <li> `internal`: Internal tables are used for TDE.   <li> `bkmi`: TDE is based on the BKMI. |
| Effective upon OBServer node restart | No |

The column encryption feature is also controlled by the `tde_method` parameter. For more information about the column encryption feature, see [ENHANCED_AES_ENCRYPT](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md) and [ENHANCED_AES_DECRYPT](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md).
