# tde_method

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in V2.2.50.</p>
</main>

## Purpose

The `tde_method` parameter is used to set the method for transparent tablespace encryption.

## Privilege requirements

* Query the parameter

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

|    Attribute           | Description  |
|------------------------|-------------|
| Parameter type         | String      |
| Default value          | none        |
| Value range            | <ul><li>none: Transparent tablespace encryption cannot be used.</li><li>internal: TDE uses internal tables for master key management.</li><li>bkmi: TDE uses external bkmi for master key management.</li><li>obcloud: TDE uses a unified KMS proxy service for master key management.<main id="notice" type='explain'><h4>Note</h4><p>The <code>obcloud</code> option is available starting from V4.3.5 BP2.</p></main></li></ul> |
| Modifiable             | Yes. You can modify this parameter using the `ALTER SYSTEM SET` statement. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.   |

## How to use

The `tde_method` parameter also determines whether column encryption is enabled. For more details on column encryption, see [ENHANCED_AES_ENCRYPT](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md) and [ENHANCED_AES_DECRYPT](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md).

### `obcloud` mode description

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This mode is available starting from V4.3.5 BP2.</p>
</main>

Starting from V4.3.5 BP2, the `obcloud` option is added, which enables TDE master key management via a unified KMS proxy service.

To enable this mode, follow these steps:

1. Enable encryption: Set master key management to use the unified KMS proxy service with `obcloud`.

   ```sql
   ALTER SYSTEM SET tde_method = 'obcloud';
   ```

2. Configure parameters: Set the required properties for the KMS proxy service in the `external_kms_info` parameter:
   * `kms_host`: The endpoint for the OceanBase Cloud KMS service
   * `access_key_id`: The AK used for signature authentication
   * `access_key_secret`: The SK used for signature authentication
   * `cmk_id`: The user's master key ID

## Configuration examples

Set the transparent tablespace encryption method to `internal`:

```shell
obclient> ALTER SYSTEM SET tde_method= 'internal';
```

Set the transparent tablespace encryption method to `obcloud`:

```shell
obclient> ALTER SYSTEM SET tde_method= 'obcloud';
```
