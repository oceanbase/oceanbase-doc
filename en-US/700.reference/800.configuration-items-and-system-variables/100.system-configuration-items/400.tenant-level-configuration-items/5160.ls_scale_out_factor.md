# ls_scale_out_factor

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>For OceanBase Database V4.4.x, this parameter is introduced in V4.4.1. <li></li>
<li>For OceanBase Database V4.2.5, this parameter is introduced in V4.2.5 BP1. </li></ul>
</main>

## Description

`ls_scale_out_factor` specifies the scale-out factor of a log stream. This parameter specifies the number of log streams per OBServer node for a tenant.

## Privilege requirements

* Query the parameter

  Users in the `sys` tenant and all user tenants can query the value of this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Users in the `sys` tenant and all user tenants can modify the value of this parameter by using the `ALTER SYSTEM SET` statement.

## Attribute description

| Attribute | Description |
| --- | --- |
| Parameter type | Int |
| Default value | 1 |
| Value range | \[1, 10\] |
| Modifiable | Yes. You can modify this parameter by using the `ALTER SYSTEM SET` statement. |
| Effective only after OBServer restart | No. This parameter takes effect immediately after the setting is applied. |

## Examples

* In the `sys` tenant, set the scale-out factor of the `mytest` tenant to 2.

  ```shell
  obclient> ALTER SYSTEM SET ls_scale_out_factor = 2 TENANT = mytest;
  ```

* In a user tenant, set the scale-out factor of the current tenant to 2.

  ```shell
  obclient> ALTER SYSTEM SET ls_scale_out_factor = 2;
  ```
