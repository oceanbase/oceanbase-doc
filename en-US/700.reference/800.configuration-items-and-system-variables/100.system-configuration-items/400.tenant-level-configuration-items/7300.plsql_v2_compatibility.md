# plsql_v2_compatibility

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V4.2.3. </p>
</main>

## Description

`plsql_v2_compatibility` specifies whether to enable the compilation disk-offload feature for stored procedure DDL statements.

## Privilege requirements

* Query the parameter
  You can use the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view to query this parameter in the `sys` tenant and all user tenants.
* Modify the parameter
  You can modify this parameter in the `sys` tenant and user tenants.

## Attributes

|        Attribute        |                                                      Description                                                       |
|------------------|---------------------------------------------------------------------------------------------------------------|
| Type             | Boolean                       |
| Default value              | False                      |
| Value range             | <li> True: enabled   <li> False: disabled    |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Run the following command to disable the compilation disk-offload feature:

```sql
obclient> ALTER SYSTEM SET plsql_v2_compatibility=false;
```
