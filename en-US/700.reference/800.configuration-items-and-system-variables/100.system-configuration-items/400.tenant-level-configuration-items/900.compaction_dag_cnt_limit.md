# compaction_dag_cnt_limit

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V4.2.1. </p>
</main>

## Description

`compaction_dag_cnt_limit` specifies the maximum number of DAGs in the Compaction DAG queue.

## Privilege requirements

* Query the parameter

  You can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter for the `sys` tenant and all user tenants.

* Modify the parameter

  You can modify this parameter for the `sys` tenant and user tenants.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type           | Int  |
| Default value             | 50000 <main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.4.0, the default value is changed from 15000 to 50000. </p></main> |
| Value range           | [10000, 500000] <main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.4.0, the value range is changed from [10000, 200000] to [10000, 500000]. </p></main> |
| Modifiable         | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Set the maximum number of DAGs in the Compaction DAG queue to 50000.

```shell
obclient> ALTER SYSTEM SET compaction_dag_cnt_limit = 50000;
```
