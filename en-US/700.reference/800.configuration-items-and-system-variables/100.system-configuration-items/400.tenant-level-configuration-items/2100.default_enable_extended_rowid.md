# default_enable_extended_rowid

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.0.0, this parameter is available starting with V4.0.0.</p>
</main>

## Description

`default_enable_extended_rowid` specifies whether to create tables in Extended ROWID mode.

## Privilege requirements

* Query the parameter

  You can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter in the `sys` tenant and all user tenants.

* Modify the parameter

  You can modify this parameter in the `sys` tenant and user tenants.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Boolean |
| Default value               | False |
| Value range             | <ul><li>True: When you create a table, the tablet ID is allocated in the range (2<sup>60</sup>, 2<sup>61</sup> - 1) in Extended ROWID format. </li> <li>False: When you create a table, the tablet ID is allocated in the range (200000, 2<sup>37</sup>  - 1) in 10-byte ROWID format. </li></ul> |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Disable Extended ROWID mode when you create tables.

```shell
obclient> ALTER SYSTEM SET default_enable_extended_rowid= false;
```
