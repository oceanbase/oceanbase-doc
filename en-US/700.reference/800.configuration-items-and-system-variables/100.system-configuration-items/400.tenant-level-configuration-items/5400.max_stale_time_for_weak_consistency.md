# max_stale_time_for_weak_consistency

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database V1.4. </p>
</main>

## Description

`max_stale_time_for_weak_consistency` specifies the maximum staleness of data that can be read in weak-consistency read mode.

## Privilege requirements

* Querying the parameter

  You can query the value of this parameter by executing the `SHOW PARAMETERS` statement or querying the `GV$OB_PARAMETERS` view in the `sys` tenant and all user tenants.

* Modifying the parameter

  You can modify this parameter in the `sys` tenant and user tenants.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time      |
| Default value               | 5s        |
| Value range             | [5s, +∞) |
| Modifiability           | Modifiable. You can execute the `ALTER SYSTEM SET` statement to modify this parameter. |
| Effective only after OBServer restart | No. This parameter takes effect immediately after it is set.     |

## Examples

Set the maximum staleness of data that can be read in weak-consistency read mode to 5s.

```shell
obclient> ALTER SYSTEM SET max_stale_time_for_weak_consistency= '5s';
```
