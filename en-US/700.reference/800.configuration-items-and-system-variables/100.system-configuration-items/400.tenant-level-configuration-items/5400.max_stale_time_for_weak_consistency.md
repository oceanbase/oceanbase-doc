# max_stale_time_for_weak_consistency

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database V1.4. </p>
</main>

## Description

`max_stale_time_for_weak_consistency` specifies how stale the data can be when performing weak consistency reads.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time      |
| Default value               | 5s        |
| Value range             | [5s, +∞) |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer restart | No. This parameter takes effect immediately after it is set.     |

## Examples

Set the maximum lag time for data read in weak consistency mode to no more than 5 seconds behind the leader replica.

```shell
obclient> ALTER SYSTEM SET max_stale_time_for_weak_consistency= '5s';
```
