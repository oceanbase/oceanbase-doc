# tenant_sql_net_thread_count

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.1.0, this parameter is available starting with V4.1.0. </p>
</main>

## Description

`tenant_sql_net_thread_count` specifies the number of I/O threads for a MySQL tenant, that is, the number of `sql_nio_server` threads.

## Privilege requirements

* Query the parameter

  You can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter in the `sys` tenant and all user tenants.

* Modify the parameter

  You can modify this parameter in the `sys` tenant and user tenants.

## Attributes

|        Attribute      |  Description  |
|------------------|-------|
| Type            | Int |
| Default value              | 0, which indicates the value of `min_cpu` in the tenant unit. |
| Value range             | [0, 64] |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.   |

## Examples

Set the number of I/O threads for a MySQL tenant to 4.

```shell
obclient> ALTER SYSTEM SET tenant_sql_net_thread_count= 4;
```
