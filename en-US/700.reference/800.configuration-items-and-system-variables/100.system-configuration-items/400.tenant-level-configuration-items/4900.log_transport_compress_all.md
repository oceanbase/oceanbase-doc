# log_transport_compress_all

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.1.0, this parameter is available starting with V4.1.0. </p>
</main>

## Description

`log_transport_compress_all` specifies whether to compress logs during log transmission.

## Privilege requirements

* Query the parameter

  `sys` and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  `sys` and user tenants can modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Bool |
| Default value               | False |
| Value range             |<ul><li>False: do not compress logs during log transmission.  </li><li>True: compress logs during log transmission.</li></ul>|
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.   |

## Examples

Disable log compression during log transmission.

```shell
obclient> ALTER SYSTEM SET log_transport_compress_all= False;
```
