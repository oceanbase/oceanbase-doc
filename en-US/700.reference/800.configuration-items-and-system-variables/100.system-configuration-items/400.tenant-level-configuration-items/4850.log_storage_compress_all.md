# log_storage_compress_all

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>For V4.3.x, this parameter is available starting with V4.3.1. </li><li>For V4.2.x, this parameter is available starting with V4.2.2. </li></ul>
</main>

## Description

`log_storage_compress_all` specifies whether to enable the clog storage compression feature.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  The `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Boolean |
| Default value | False |
| Value range |<ul><li>true</li> <li>false</li></ul>|
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

* Enable the clog storage compression feature for the `tenant_name` tenant in the `sys` tenant.

  ```shell
  obclient> ALTER SYSTEM SET log_storage_compress_all='True'  tenant = 'tenant_name';
  ```

* Enable the clog storage compression feature for all tenants.

  ```shell
  obclient> ALTER SYSTEM SET log_storage_compress_all='True' tenant=all;
  ```

* Enable the clog storage compression feature for the current tenant.

  ```shell
  obclient> ALTER SYSTEM SET log_storage_compress_all='True';
  ```
