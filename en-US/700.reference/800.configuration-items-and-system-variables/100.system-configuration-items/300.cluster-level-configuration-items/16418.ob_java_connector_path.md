# ob_java_connector_path

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.3.5, this parameter is available starting with V4.3.5. </p>
</main>

## Description

`ob_java_connector_path` specifies the root path of the Connector file required for accessing and executing external tables (such as ODPS external tables) through JNI (Java Native Interface). This path is concatenated with the path specified by the `ob_java_home` parameter to form the class loading path of the JVM.

<main id="notice">
  <h4>Applicability</h4>
  <p>This parameter is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query the parameter
  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.
* Modify the parameter
  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute**  | **Description** |
|---|---|
| Parameter type | String |
| Default value | `""` (empty string) |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Considerations

* This parameter is part of the configuration required to enable the Java environment in OceanBase Database to support JNI features such as ODPS external tables. Typically, it is used in conjunction with the `ob_enable_java_env`, `ob_java_home`, and `ob_java_opts` parameters.
* **Initialization time**: The initial setup of the Java environment may take a long time, potentially causing timeouts during the first query of related external tables. It is recommended to adjust the query timeout time appropriately, as subsequent queries will not require reinitialization.
* **Deployment consistency**: In a multi-node deployment environment, ensure that all OBServer nodes are configured to point to the same and existing directory to maintain functionality.
* **Path requirements**: The configured path should be the root directory where Connector Jar packages are stored. For example, the `jni_package` directory obtained by decompressing `jni_packages_new.tar` can be used as the value for `ob_java_connector_path`.
* **Environmental dependencies**: Before using this feature, ensure that the Java environment (such as OpenJDK 8) is correctly installed on the server and that necessary environment variables (such as `LD_LIBRARY_PATH` pointing to the directory containing `libhdfs.so`) are properly configured.

## Examples

Set the root path of the Java Connector to `/home/admin/jni_packages/`.

```shell
obclient> ALTER SYSTEM SET ob_java_connector_path = '/home/admin/jni_packages/';
```
