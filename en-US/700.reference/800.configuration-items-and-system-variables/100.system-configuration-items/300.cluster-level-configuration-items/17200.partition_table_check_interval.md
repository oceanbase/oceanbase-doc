# partition_table_check_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer has the concept of partition replicas, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`partition_table_check_interval` specifies the time interval at which an OBServer node removes non-existent replicas from a partitioned table.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time         |
| Default value              | 30m, which indicates 30 minutes |
| Value range             | \[1m, +∞)    |
| Effective upon OBServer node restart | No            |
