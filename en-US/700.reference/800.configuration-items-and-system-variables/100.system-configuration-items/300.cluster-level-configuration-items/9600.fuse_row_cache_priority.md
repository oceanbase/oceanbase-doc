# fuse_row_cache_priority

`fuse_row_cache_priority` specifies the priority of the fuse row cache in the cache system.

| **Attribute** | **Description** |
|------------------|----------|
| Type | Integer |
| Default value | 1 |
| Value range | \[1, +∞) |
| Effective upon OBServer node restart | No |
