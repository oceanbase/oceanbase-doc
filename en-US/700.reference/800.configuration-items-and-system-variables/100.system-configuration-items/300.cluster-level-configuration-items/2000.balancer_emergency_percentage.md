# balancer_emergency_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture has been upgraded. This parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`balancer_emergency_percentage` specifies the unit load threshold. When the unit load exceeds this threshold, you can enable replica migration, even during major compactions.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value               | 80         |
| Value range             | \[1, 100\] |
| Effective upon OBServer node restart | No          |
