# balancer_emergency_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x has upgraded the storage architecture, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`balancer_emergency_percentage` specifies the unit load threshold. When the unit load exceeds this threshold, the system allows replica migration even during major compactions.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Type             | Int         |
| Default value               | 80         |
| Value range             | \[1, 100\] |
| Effective upon OBServer node restart | No          |
