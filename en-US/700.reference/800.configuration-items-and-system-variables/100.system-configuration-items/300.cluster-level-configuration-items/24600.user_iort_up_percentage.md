# user_iort_up_percentage

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is removed starting with V4.0.0 because the algorithm for I/O scheduling has been adjusted and the corresponding feature is no longer available. </p>
</main>

## Description

`user_iort_up_percentage` specifies the user disk I/O latency threshold. If the user disk I/O latency exceeds this threshold, the system will throttle the background I/O tasks.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Integer       |
| Default value              | 100      |
| Value range             | \[0, +∞) |
| Effective upon OBServer node restart | No        |
