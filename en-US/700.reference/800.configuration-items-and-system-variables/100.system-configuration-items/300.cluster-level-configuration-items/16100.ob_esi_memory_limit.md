# ob_esi_memory_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the feature corresponding to this parameter is no longer supported and has been removed starting from V4.0.0. </p>
</main>

## Description

`ob_esi_memory_limit` specifies the maximum memory usage of the obesi process.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Capacity |
| Default value | 0M |
| Value range | [64M, +∞) |
| Effective upon OBServer node restart | No |
