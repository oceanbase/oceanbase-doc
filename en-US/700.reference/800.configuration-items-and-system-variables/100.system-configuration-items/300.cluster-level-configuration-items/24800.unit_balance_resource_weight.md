# unit_balance_resource_weight

<main id="notice" type='explain'>
<h4>Note</h4>
<p>After V4.x is upgraded to a standalone log stream architecture, the replicas are distributed in log streams. The load balancing module cannot directly control the partition balancing. This parameter is no longer applicable and has been removed starting from V4.0.0.  </p>
</main>

## Description

`unit_balance_resource_weight` specifies the resource weight used in the unit balancing strategy. This parameter is not usually manually configured.

## Attributes

|      **Attribute**      | **Description** |
|------------------|--------|
| Parameter type                      | String  |
| Default value              | NULL     |
| Effective upon OBServer node restart | No      |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <ul>
  <li>By default, the weight value is NULL. If you set the weight value, the total of all weight values must be 100.  </li>
  <li>When <code>enable_unit_balance_resource_weight</code> is enabled, the <code>unit_balance_resource_weight</code> parameter takes effect.  </li>
  </ul>
</main>
