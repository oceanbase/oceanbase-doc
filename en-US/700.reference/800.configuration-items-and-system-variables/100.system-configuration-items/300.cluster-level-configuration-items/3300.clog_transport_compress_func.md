# clog_transport_compress_func

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the lack of support for transaction log compression in V4.0.0, this parameter is removed starting from V4.0.0. </li>
<li>Starting from V4.1.0, OceanBase Database supports transaction log compression again. In V4.1.0 and later versions, you can use the tenant-level parameter <code>log_transport_compress_func</code> to configure the compression algorithm used for internal transaction log transmission. For more information about the <code>log_transport_compress_func</code> parameter, see <a href="../400.tenant-level-configuration-items/5000.log_transport_compress_func.md">log_transport_compress_func</a>. </li></ul>
</main>

## Description

`clog_transport_compress_func` specifies the compression algorithm used for internal transaction log transmission.

## Attributes

|      **Attribute**      |               **Description**                                    |
|------------------|-------------------------------------------------------------------------------------------------------------------------|
| Type             | String                 |
| Default value              | lz4_1.0                                |
| Value range             | <ul><li> none</li>   <li> lz4_1.0</li>   <li> snappy_1.0</li>   <li> zlib_1.0</li>   <li> zstd_1.0</li>   <li> zstd_1.3.8</li></ul>    |
| Effective upon OBServer node restart | No                |
