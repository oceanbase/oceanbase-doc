# enable_auto_leader_switch

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the system architecture has been optimized. Automatic leader switch is now controlled by a single log stream, and load balancing is no longer required. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`enable_auto_leader_switch` specifies whether to enable automatic leader switch.

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Parameter type             | Bool                                                                                                   |
| Default value              | True                                                                                                   |
| Value range             | </li><li> True   </li><li> False    |
| Effective upon OBServer node restart | No.                                                                                                      |
