# enable_election_group

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architectural optimization in V4.x, the concept of election groups has been removed. This parameter is deprecated starting from V4.0.0. </p>
</main>

## Description

`enable_election_group` specifies whether to enable the election group strategy.

## Attributes

|        Attribute        |                                                   Description                                                   |
|------------------|--------------------------------------------------------------------------------------------------------|
| Parameter type             | Bool                                                                                                   |
| Default value              | True                                                                                                   |
| Value range             | </li><li> True   </li><li> False    |
| Effective upon OBServer node restart | No                                                                                                      |
