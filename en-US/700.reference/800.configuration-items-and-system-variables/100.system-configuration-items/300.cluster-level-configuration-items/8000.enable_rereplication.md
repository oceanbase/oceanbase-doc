# enable_rereplication

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`enable_rereplication` specifies whether to enable automatic migration and replication of log stream replicas.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**    |   **Description**   |
|------------------|--------------|
| Type             | Bool                |
| Default value               | True                |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>    |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.    |

# Considerations

If you set the `enable_rereplication` parameter to `False`:

* The following scenarios will not trigger migration and replication of log stream replicas:

  * Adding or removing replicas by changing locality
  * Unit migration (excluding unit migration from an `INACTIVE` OBServer node)
  * Changing the `UNIT_NUM` parameter

* The following scenarios will still trigger migration and replication of log stream replicas:

  * Unit migration from an `INACTIVE` OBServer node

## Examples

Enable automatic migration and replication of log stream replicas.

```shell
obclient> ALTER SYSTEM SET enable_rereplication = True;
```
