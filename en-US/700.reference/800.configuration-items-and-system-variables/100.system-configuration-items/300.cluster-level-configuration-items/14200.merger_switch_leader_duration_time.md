# merger_switch_leader_duration_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports zone-level minor compactions, this parameter is no longer available starting with V4.0.0. </p>
</main>

## Description

`merger_switch_leader_duration_time` specifies the time interval for batch leader switching during daily minor compactions.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type                       | Time       |
| Default value                        | 3m, which indicates 3 minutes |
| Value range             | \[0s, 30m\] |
| Effective upon OBServer node restart | No          |
