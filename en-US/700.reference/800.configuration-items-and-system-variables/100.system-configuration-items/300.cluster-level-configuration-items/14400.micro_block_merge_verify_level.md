# micro_block_merge_verify_level

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.2.30, this parameter is available starting with V2.2.30. </p>
</main>

## Description

`micro_block_merge_verify_level` specifies the verification level of macroblocks during a major compaction.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query the value of this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Int            |
| Default value               | 2             |
| Value range             | <ul><li> 0: No verification is performed. </li><li>1: The encoding algorithm is verified. The encoded microblocks are read to ensure data correctness. </li><li>2: The encoding and compression algorithms are verified. In addition to encoding verification, the compression blocks are decompressed to ensure data correctness. </li><li>3: The encoding, compression, and lost write protection algorithms are verified. </li></ul>  |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Set the verification level of macroblocks during a major compaction to 2.

```shell
obclient> ALTER SYSTEM SET micro_block_merge_verify_level = 2;
```
