# ob_esi_io_concurrency

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the feature corresponding to this parameter is no longer supported and has been removed starting from V4.0.0. </p>
</main>

## Description

`ob_esi_io_concurrency` specifies the number of concurrent I/O operations for the obesi process.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Int |
| Default value | 0 |
| Value range | [0, +∞) |
| Effective upon OBServer node restart | No |
