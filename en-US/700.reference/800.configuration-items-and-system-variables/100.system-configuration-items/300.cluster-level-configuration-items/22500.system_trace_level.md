# system_trace_level

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the corresponding logic has changed and the feature is no longer used. This parameter is removed starting with V4.2.0. </p>
</main>

## Description

`system_trace_level` specifies the log level of the trace log.

## Attributes

|  **Attribute**   |      **Description**      |
|-------------|--------------------|
| Type     | Int  |
| Default value       | 1    |
| Value range     |<ul><li>0: None</li><li>1: Standard</li><li>2: Debug</li></ul>     |
| Modifiable   | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.     |

## Examples

Set the log level of the trace log to Debug.

```shell
obclient> ALTER SYSTEM SET system_trace_level=2;
```
