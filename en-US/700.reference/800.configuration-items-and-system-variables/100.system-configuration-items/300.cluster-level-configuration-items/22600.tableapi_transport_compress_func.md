# kv_transport_compress_func

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.5.x, this parameter is available starting with V4.5.0.</p>
</main>

## Description

`kv_transport_compress_func` specifies the compression algorithm used for transmitting query results of an OBKV table.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|   **Attribute**   |   **Description**    |
|------------------|--------------|
| Type             | Capacity   |
| Default value              | none |
| Value range             | <ul><li> none</li><li> lz4_1.0</li><li> snappy_1.0</li><li> zlib_1.0, viewable only</li><li> zstd_1.0</li><li> zstd 1.3.8</li><li> zstd 1.5.7</li></ul><main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.5.0, the value zstd 1.5.7 is added to this parameter.</p></main>  |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Set the compression algorithm used for transmitting query results of an OBKV table to lz4_1.0.

```shell
obclient> ALTER SYSTEM SET kv_transport_compress_func = 'lz4_1.0';
```
