# tcp_keepintvl

`tcp_keepintvl` specifies the interval between two probes in seconds when you enable the keepalive mechanism for client connections.

| Attribute | Description |
|------------------|----------|
| Type | Time |
| Default value | 6s |
| Value range | \[1s, +∞) |
| Effective upon OBServer node restart | No |
