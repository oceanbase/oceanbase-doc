# ofs_list

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, this parameter is removed starting with V4.0.0. </p>
</main>

## Description

`ofs_list` specifies the OceanBase File System (OFS) connection URLs for each zone. This parameter is used to enable RootService to access files across zones in OFS deployment mode.

## Attributes

|        Attribute        |            Description            |
|------------------|--------------------------|
| Type             | String                    |
| Default value              | The OFS list at deployment              |
| Value range             | Format: `[zone]@[ofs_url];` |
| Effective upon OBServer node restart | No                        |
