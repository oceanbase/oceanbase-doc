# zone_merge_concurrency

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports zone-based control of major compactions, this parameter is removed starting from V4.0.0. </p>
</main>

## Description

`zone_merge_concurrency` specifies the maximum number of zones that can be concurrently compacted. When the value is 0, the system automatically selects the optimal concurrency level based on the deployment configuration.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Int      |
| Default value              | 0        |
| Value range             | \[0, +∞) |
| Effective upon OBServer node restart | No        |
