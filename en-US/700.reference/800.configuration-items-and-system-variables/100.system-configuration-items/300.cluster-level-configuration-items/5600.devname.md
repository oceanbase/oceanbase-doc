# devname

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`devname` specifies the name of the network interface card (NIC) to which the service process is bound.

## Privilege requirements

The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

## Attributes

|      **Attribute**      | **Description** |
|------------------|------------|
| Type             | String    |
| Default value               | bond0  |
| Modifiable           | No. It is read-only. <main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.2.0, the effective scope of this parameter is changed from dynamic to read-only. </p></main>|
