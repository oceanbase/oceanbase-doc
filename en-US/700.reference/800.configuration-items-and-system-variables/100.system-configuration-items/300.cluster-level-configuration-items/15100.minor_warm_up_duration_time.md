# minor_warm_up_duration_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is no longer recommended for use starting with V2.2.3x and was removed starting with V4.0.0. </p>
</main>

## Description

`minor_warm_up_duration_time` specifies the warm-up time for generating new dump files.

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Type                      | Time       |
| Default value              | 30s         |
| Value range             | \[0s, 60m\] |
| Effective upon OBServer node restart | No           |

## Considerations

If the value of `minor_warm_up_duration_time` is 0s, no warm-up is performed.
