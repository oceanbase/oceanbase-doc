# enable_election_group

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Starting from V4.0.0, this parameter is deprecated because the system architecture was optimized in V4.x. </p>
</main>

## Description

`enable_election_group` specifies whether to enable the election group strategy.

## Attributes

|        Attribute        |                        Description                    |
|------------------|--------------------------------------------------|
| Parameter type             | Boolean                                         |
| Default value              | True                                           |
| Value range             | <ul><li>True: enabled. </li><li>False: disabled. </li></ul>    |
| Effective upon OBServer node restart | No.                                        |
