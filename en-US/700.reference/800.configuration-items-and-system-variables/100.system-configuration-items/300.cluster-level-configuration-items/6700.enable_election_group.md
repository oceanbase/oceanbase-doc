# enable_election_group

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x optimizes the system architecture, the concept of an election group no longer exists. This parameter is deprecated starting with V4.0.0. </p>
</main>

## Description

`enable_election_group` specifies whether to enable the election group policy.

## Attributes

|        Attribute        |                        Description                    |
|------------------|--------------------------------------------------|
| Parameter type             | Bool                                         |
| Default value              | True                                           |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>    |
| Effective upon OBServer node restart | No.                                      |
