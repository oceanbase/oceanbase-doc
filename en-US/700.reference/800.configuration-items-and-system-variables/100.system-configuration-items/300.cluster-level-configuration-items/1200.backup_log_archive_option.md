# backup_log_archive_option

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Due to the architectural optimization of physical backup and restore in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, the corresponding functionality of this parameter is as follows:
<ul><li>Configuring the backup mode is no longer supported. You can use the <code>BINDING</code> option in the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3800.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a> statement to set the priority mode for log archiving and business operations for the system tenant and all user tenants. </li>
<li>Log archiving compression is not supported. </li></ul>
</li></ul>
</main>

## Description

`backup_log_archive_option` specifies the log archiving options for backup.

## Attributes

|**Attribute**|   **Description**      |
|------------------|--------------------------|
| Type             | String                      |
| Default value              | `OPTIONAL COMPRESSION=ENABLE`                    |
| Value range             | <ul><li>`MANDATORY`: specifies backup priority. If log archiving is too slow, write operations are suspended. </li><li>`OPTIONAL`: specifies write priority. If write operations are too fast, log archiving is suspended. </li><li>`COMPRESSION`: specifies the compression algorithm. Valid values: `ENABLE`, `DISABLE`, `LZ4_1.0`, and `ZSTD_1.3.8`. Default value: `ENABLE`, which uses the LZ4_1.0 compression algorithm. </li></ul>     |
| Effective upon OBServer node restart |No     |
