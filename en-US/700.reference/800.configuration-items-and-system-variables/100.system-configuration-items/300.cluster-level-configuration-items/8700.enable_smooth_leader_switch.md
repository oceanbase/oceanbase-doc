# enable_smooth_leader_switch

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the partition leader switch feature is no longer supported. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`enable_smooth_leader_switch` specifies whether to enable the smooth leader switch feature.

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Type             | Bool                                                                                                    |
| Default value              | True                                                                                                   |
| Value range             | </li><li> True   </li><li> False    |
| Effective upon OBServer node restart | No.                                                                                                      |
