# multiblock_read_size

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the storage architecture changes in V4.x, this parameter is no longer applicable and was removed starting with V4.0.0. </p>
</main>

## Description

`multiblock_read_size` specifies the I/O aggregation size when data is read.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Capacity         |
| Default value              | 128k       |
| Value range             | \[0K, 2M\] |
| Effective upon OBServer node restart | No          |
