# ignore_replica_checksum_error

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.0.0, this parameter is removed because it may cause serious issues by ignoring the checksum check errors between replicas. </p>
</main>

## Description

`ignore_replica_checksum_error` specifies whether to ignore the checksum check errors between replicas.

## Attributes

|    **Attribute**      |            **Description**   |
|------------------|-----------------------|
| Type | Boolean |
| Default value | False |
| Value range | </li><li>True</li><li>False</li></ul> |
| Effective upon OBServer node restart | No. The setting takes effect immediately.     |
