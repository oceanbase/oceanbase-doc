# merger_completion_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is available starting with V4.0.0. </p>
</main>

## Description

`merger_completion_percentage` specifies the percentage threshold of the number of replicas that are merged in a major compaction. If the number of replicas that are merged reaches the threshold, the major compaction is considered to be completed.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value              | 100        |
| Value range             | \[5, 100\] |
| Effective upon OBServer node restart | No          |
