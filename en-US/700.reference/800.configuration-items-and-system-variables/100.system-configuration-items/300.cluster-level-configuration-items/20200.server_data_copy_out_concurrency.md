# server_data_copy_out_concurrency

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to limited thread resources, V4.x no longer supports configuring thread resources by task type. This parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you can use the <code>ha_mid_thread_score</code> parameter to set the number of working threads for high-priority threads in migration tasks. For more information about the tenant-level parameter <code>ha_mid_thread_score</code>, see <a href="../400.tenant-level-configuration-items/3600.ha_mid_thread_score.md">ha_mid_thread_score</a>. </li></ul>
</main>

## Description

`server_data_copy_out_concurrency` specifies the maximum number of concurrent data migration tasks on a single node.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Type             | Int          |
| Default value               | 2           |
| Value range             | \[1, 1000\] |
| Effective upon OBServer node restart | No           |
