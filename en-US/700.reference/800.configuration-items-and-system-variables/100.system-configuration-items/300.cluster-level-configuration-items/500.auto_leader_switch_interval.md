# auto_leader_switch_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the system architecture is optimized. Leader election no longer requires a refresh interval. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`auto_leader_switch_interval` specifies the working interval of the background thread for automatic leader switching.

## Attributes

|     **Attribute**     |  **Description**  |
|----------------|----------|
| Parameter type           |  Time     |
| Default value             | 30s, indicating 30 seconds       |
| Value range           | [1s, +∞) |
| Effective upon OBServer node restart | No        |
