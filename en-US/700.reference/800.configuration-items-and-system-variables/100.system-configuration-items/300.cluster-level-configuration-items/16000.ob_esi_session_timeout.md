# ob_esi_session_timeout

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is no longer supported in V4.x and has been removed starting from V4.0.0. </p>
</main>

## Description

`ob_esi_session_timeout` specifies the timeout period for the obesi process to hold active session resources.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Time |
| Default value | 1m |
| Value range | [10s, 30m] |
| Effective upon OBServer node restart | No |
