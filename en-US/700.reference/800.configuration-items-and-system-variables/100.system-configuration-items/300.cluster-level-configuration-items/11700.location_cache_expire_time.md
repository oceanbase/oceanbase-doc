# location_cache_expire_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`location_cache_expire_time` specifies the duration for which partition location information is cached. We recommend that you do not modify this parameter.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Time      |
| Default value              | 600s      |
| Value range             | \[1s, +∞) |
| Effective upon OBServer node restart | No         |
