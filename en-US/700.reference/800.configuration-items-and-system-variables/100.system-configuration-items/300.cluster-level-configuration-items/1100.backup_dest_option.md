# backup_dest_option

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, the functionality of each parameter in this parameter is as follows:
<ul><li>The interval for log archive delay can be set by using the tenant-level parameter <a href="../400.tenant-level-configuration-items/200.archive_lag_target.md">archive_lag_target</a>. </li>
<li>Setting the time window for which backed-up data can be restored is no longer supported. The system tenant and user tenants can use the <code>RECOVERY_WINDOW</code> option in the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/1270.delete-backup.md">ALTER SYSTEM ADD DELETE BACKUP POLICY</a> statement to set the time window. </li>
<li>Automatic and manual backup cleanup are supported. For more information, see <a href="../../../../600.manage/600.backup-and-recovery/500.clear-backup-data/50.automatic-backup-cleanup/100.cleaning-up-backed-up-data-automatically.md">Clean up backup data</a>. </li>
<li>The switching cycle of a piece can be set by using the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3800.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a> statement. </li>
<li>Secondary backup is no longer supported. Therefore, the redundancy level of a backup set cannot be specified. </li></ul>
</li></ul>
</main>

## Description

`backup_dest_option` specifies parameters related to backup.
