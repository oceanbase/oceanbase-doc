# enable_cgroup

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V3.2.4, this parameter is available starting with V3.2.4.</p>
</main>

## Description

`enable_cgroup` specifies whether to enable the cgroup feature on an OBServer node.

## Privilege requirements

* Query the parameter

  The sys tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the sys tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------ | ------ |
| Type | Bool |
| Default value | True |
| Value range |<ul><li>True: If the cgroup directory is mounted, the cgroup feature is enabled. If not, a warning is generated.</li><li>False: The cgroup feature is not enabled.</li></ul>|
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. <main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.3.5, this parameter takes effect dynamically. </p></main> |

## Examples

Enable the cgroup feature.

```shell
obclient> ALTER SYSTEM SET enable_cgroup = true;
```
