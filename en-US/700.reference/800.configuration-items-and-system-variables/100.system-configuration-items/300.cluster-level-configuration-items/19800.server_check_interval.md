# server_check_interval

`server_check_interval` specifies the interval at which the server checks the table consistency.

| **Attribute** | **Description** |
|------------------|-----------|
| Type | Time |
| Default value | 30s |
| Value range | \[1s, +∞) |
| Effective upon OBServer node restart | No |
