# sys_cpu_limit_trigger

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the changes in the storage architecture in V4.x, this parameter is no longer applicable and was removed starting with V4.0.0. </li>
<li>In V4.x, you cannot use this parameter to control resources. Instead, you can use the <code>DBMS_RESOURCE_MANAGER</code> system package to isolate resources and achieve resource control. For more information about how to use the <code>DBMS_RESOURCE_MANAGER</code> system package to isolate resources, see <a href="../../../../600.manage/200.tenant-management/600.common-tenant-operations/300.resource-isolation/100.resource-isolation-overview.md">Overview</a>. </li></ul>
</main>

## Description

`sys_cpu_limit_trigger` specifies the CPU utilization threshold. When the CPU utilization exceeds this threshold, the execution of system background tasks is suspended.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Int        |
| Default value              | 80        |
| Value range             | \[50, +∞) |
| Effective upon OBServer node restart | No         |
