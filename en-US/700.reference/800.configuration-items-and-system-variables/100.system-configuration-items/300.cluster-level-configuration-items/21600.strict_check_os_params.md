# strict_check_os_params

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V4.2.2. </p>
</main>

## Description

`strict_check_os_params` specifies whether to enable the check for OS configuration parameters.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Type | Bool |
| Default value | false |
| Value range | <ul><li>`true`: If the parameters are out of the specified range, an ERROR is returned and OBServer cannot be started. </li><li>`false`: If the parameters are out of the specified range, a WARNING is returned, but OBServer can be started. </li></ul>|
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Disable the check for OS configuration parameters.

```shell
obclient> ALTER SYSTEM SET strict_check_os_params=false;
```
