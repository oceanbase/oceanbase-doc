# max_kept_major_version_number

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is removed starting with V4.0.0. This is because it consumes additional storage space by retaining old baseline versions, which is not cost-effective for most users. </p>
</main>

## Description

`max_kept_major_version_number` specifies the maximum number of frozen major versions to retain.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Int        |
| Default value              | 2         |
| Value range             | \[1, 16\] |
| Effective upon OBServer node restart | No         |
