# backup_recovery_window

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you cannot set the backup data recovery window by using this parameter. You can use the <code>RECOVERY_WINDOW</code> option in the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/1270.delete-backup.md">ALTER SYSTEM ADD DELETE BACKUP POLICY</a> statement to set the backup data recovery window for the sys tenant and user tenants. </li></ul>
</main>

## Description

`backup_recovery_window` specifies the time window during which backup data can be restored.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Time    |
| Default value              | 0, indicating that automatic cleanup is disabled.        |
| Value range             | \[0, +∞) |
| Effective upon OBServer node restart | No        |
