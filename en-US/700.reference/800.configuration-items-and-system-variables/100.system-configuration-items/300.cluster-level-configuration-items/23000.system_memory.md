# system_memory

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4.  </p>
</main>

## Description

`system_memory` specifies the memory size reserved for the tenant with ID `500`.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Capacity      |
| Default value               | 0M, indicating that the system automatically adjusts the memory usage strategy based on the current memory status.   |
| Value range             | [0M, +∞) |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Examples

Set the memory capacity reserved for the tenant with ID `500` to 0M.

```shell
obclient> ALTER SYSTEM SET system_memory = '0M';
```
