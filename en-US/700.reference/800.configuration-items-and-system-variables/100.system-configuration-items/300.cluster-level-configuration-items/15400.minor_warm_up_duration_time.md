# minor_warm_up_duration_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is no longer recommended for use in V2.2.3x and has been removed in V4.0.0. </p>
</main>

## Description

`minor_warm_up_duration_time` specifies the warm-up time for generating new dump files.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type                      | Time       |
| Default value              | 30s         |
| Value range             | \[0s, 60m\] |
| Effective upon OBServer node restart | No           |

## Considerations

When the value of the `minor_warm_up_duration_time` parameter is 0s, no warm-up is performed.
