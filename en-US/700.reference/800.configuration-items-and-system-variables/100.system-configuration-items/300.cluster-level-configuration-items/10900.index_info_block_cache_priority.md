# index_info_block_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and has been removed starting from V4.0.0. </li>
<li>In V4.x, use the <code>index_block_cache_priority</code> parameter to set the cache priority for metadata index microblocks. For more information about the <code>index_block_cache_priority</code> parameter, see <a href="10600.index_block_cache_priority.md">index_block_cache_priority</a>. </li></ul>
</main>

## Description

`index_info_block_cache_priority` specifies the cache priority of block indexes.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Int       |
| Default value              | 1        |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
