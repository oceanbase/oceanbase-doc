# merger_warm_up_duration_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the storage architecture upgrade in V4.x, this parameter is no longer supported and was removed starting from V4.0.0. </p>
</main>

## Description

`merger_warm_up_duration_time` specifies the warm-up time for new baseline data during a major compaction.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type             | Time        |
| Default value              | 0s          |
| Value range             | \[0s, 60m\] |
| Effective upon OBServer node restart | No           |
