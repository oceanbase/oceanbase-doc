# lease_time

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`lease_time` specifies the heartbeat lease time.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type    | Time         |
| Default value      | 10s          |
| Value range    | [1s, 5min] |
| Modifiable | Yes <main id="notice" type='explain'><h4>Note</h4><p>Generally, we do not recommend that you modify this parameter. </p></main>|
| Effective upon OBServer node restart | No  |

## Considerations

If the Root Service does not receive heartbeat information from an OBServer node within the heartbeat lease time, the OBServer node is considered to be offline.

## Examples

Set the heartbeat lease time to 10s.

```shell
obclient> ALTER SYSTEM SET lease_time ='10s';
```
