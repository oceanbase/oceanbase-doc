# replica_safe_remove_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the replica management feature has been optimized. Therefore, you do not need to control the deletion time of invalid replicas. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`replica_safe_remove_time` specifies the safe retention period for deleted replicas.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Time      |
| Default value              | 2h        |
| Value range             | \[1m, +∞) |
| Effective upon OBServer node restart | No         |
