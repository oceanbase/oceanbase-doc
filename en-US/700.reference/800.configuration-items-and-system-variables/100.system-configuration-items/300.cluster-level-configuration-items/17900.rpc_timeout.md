rpc_timeout
================================

`rpc_timeout` specifies the timeout duration of internal requests of the cluster.


| **Attribute** | **Description** |
|------------------|----------|
| Type | Time |
| Default value | 2s |
| Value range | \[0, +∞) |
| Effective upon OBServer node restart | No |
