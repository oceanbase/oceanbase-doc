# minor_freeze_times

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li> Due to the upgrade of the storage architecture in V4.x and the fact that this parameter has the same meaning as the <code>major_compact_trigger</code> parameter, this parameter is deleted in V4.0.0. </li>
<li> In V4.x, only the tenant-level parameter <code>major_compact_trigger</code> can be used to control how many times the tenant is frozen before a major compaction is triggered. For more information about the <code>major_compact_trigger</code> parameter, see <a href="../400.tenant-level-configuration-items/1800.major_compact_trigger.md">major_compact_trigger</a>. </li></ul>
</main>

The `minor_freeze_times` parameter specifies the number of minor freezes that occur before a major compaction is triggered.

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Int           |
| Default value              | 100          |
| Value range             | \[0, 65535\] |
| Take effect after         | No need to restart the OBServer node. |

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li> If the value of this parameter is 0, major compactions will not be triggered automatically regardless of the number of freezes. </li>
  <li> This parameter and the <code>major_compact_trigger</code> parameter have the same functionality. </li>
  </ul>
</main>
