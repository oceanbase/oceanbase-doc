# tablet_ls_cache_priority

`tablet_ls_cache_priority` specifies the priority of the tablet mapping cache.

| **Attribute** | **Description** |
| --- | --- |
| Type | Integer |
| Default value | 1000 |
| Value range | [1, +∞) |
| Effective upon OBServer node restart | No |
