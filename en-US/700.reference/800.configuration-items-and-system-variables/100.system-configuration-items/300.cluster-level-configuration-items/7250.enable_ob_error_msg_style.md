# enable_ob_error_msg_style

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is available starting with V4.3.1.</p>
</main>

## Overview

`enable_ob_error_msg_style` is used to select the error code type for OBServer.

## Privilege requirements

* Query parameters \

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify parameters.

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ------------------------------------------------------------------ |
| Parameter type | Bool |
| Default Value | True |
| Value range | <ul><li>True: Use the OBE-xx format for error codes.  </li><li>False: Use the ORA-xx format for error codes.  </li></ul> |
| Whether to Restart the OBServer Node for the Change to Take Effect | No |

## Configuration example

Set the error code format to OBE-xx.

```shell
obclient> ALTER SYSTEM SET enable_ob_error_msg_style = True;
```
