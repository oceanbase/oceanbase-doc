# enable_ob_error_msg_style

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is available starting with V4.3.1.</p>
</main>

## Description

`enable_ob_error_msg_style` selects the error code type used by OBServer.

## Privilege requirements

* Query the parameter

  Both the `sys` tenant and all user tenants can query this configuration item using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can modify this configuration item. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ------------------------------------------------------------------ |
| Parameter type | Bool |
| Default value | True |
| Value range | <ul><li>True: Use error codes in the OBE-xx format.</li><li>False: Use error codes in the ORA-xx format.</li></ul> |
| Effective upon OBServer node restart | No |

## Configuration example

Set the error code format to OBE-xx.

```shell
obclient> ALTER SYSTEM SET enable_ob_error_msg_style = True;
```
