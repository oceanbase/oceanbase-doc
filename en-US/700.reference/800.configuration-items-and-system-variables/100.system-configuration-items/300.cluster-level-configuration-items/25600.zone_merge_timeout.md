# zone_merge_timeout

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports zone-based major compactions, this parameter is removed starting from V4.0.0. </p>
</main>

## Description

`zone_merge_timeout` specifies the timeout period for a single zone.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type                      | Time      |
| Default value              | 3h        |
| Value range             | \[1s, +∞) |
| Effective upon OBServer node restart | No         |
