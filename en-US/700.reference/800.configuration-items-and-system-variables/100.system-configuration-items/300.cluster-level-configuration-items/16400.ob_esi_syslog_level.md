# ob_esi_syslog_level

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architectural optimization of the physical backup and restore feature in V4.x, the feature corresponding to this parameter is no longer supported in V4.x and has been removed starting from V4.0.0. </p>
</main>

## Description

`ob_esi_syslog_level` specifies the current log recording level of the obesi process.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | String |
| Default value | WDIAG |
| Value range |  <ul><li>DEBUG   </li><li> TRACE   </li><li>WDIAG </li><li>EDIAG  </li><li> INFO   </li><li> WARN  </li><li> ERROR </li></ul> |
| Effective upon OBServer node restart | No |
