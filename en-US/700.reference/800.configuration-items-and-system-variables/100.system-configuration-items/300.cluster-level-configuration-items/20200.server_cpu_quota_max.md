# server_cpu_quota_max

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V2.2.50. </p>
</main>

## Description

The `server_cpu_quota_max` parameter specifies the maximum CPU quota available to the system.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query the parameter.

* Modify the parameter

  The `sys` tenant can modify the parameter. User tenants cannot.

## Attributes

|      **Attribute**      |  **Description**   |
|--------------------|-----------|
| Type             | Double    |
| Default value               | 0 <main id="notice" type='explain'><h4>Note</h4><ul><li>Starting from V4.0.0, the default value changed from 5 to 1.  </li><li>Starting from V4.2.1, the default value changed from 1 to 0. </li></ul></main> |
| Value range             | [0, 16]  <main id="notice" type='explain'><h4>Note</h4><ul><li>Starting from V4.0.0, the value range changed from [0, 16] to [1, 16].</li><li>Starting from V4.2.1, the value range changed from [1, 16] to [0, 16]. </li></ul></main>   |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify this parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.<main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.1.0, the effectiveness of this parameter changed from requiring a restart to immediate effect. </p></main>           |

## Considerations

When the value is set to 0, the system will adaptively adjust the maximum CPU quota based on the number of CPU cores (`cpu_count`) in the server:

1. If `cpu_count` < 8, `server_cpu_quota_max` is adaptively set to 1.
2. If 8 ≤ `cpu_count` < 16, `server_cpu_quota_max` is adaptively set to 2.
3. If 16 ≤ `cpu_count` < 32, `server_cpu_quota_max` is adaptively set to 3.
4. If `cpu_count` ≥ 32, `server_cpu_quota_max` is adaptively set to 4.

## Examples

Set the maximum CPU quota for the system to be adaptively adjusted.

```shell
obclient> ALTER SYSTEM SET server_cpu_quota_max=0;
```
