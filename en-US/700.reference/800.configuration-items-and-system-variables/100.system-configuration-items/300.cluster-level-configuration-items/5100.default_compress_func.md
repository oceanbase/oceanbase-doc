# default_compress_func

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`default_compress_func` specifies the default compression algorithm for table data. You can also specify a different compression algorithm when you create a table.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**  |    **Description**  |
|----------------|--------------|
| Type             | String      |
| Default value               | zstd_1.3.8   |
| Value range             | <ul><li>none </li><li>lz4_1.0 </li><li>snappy_1.0 </li><li>zstd_1.0 </li><li>zstd_1.3.8 </li><li>zlib_lite_1.0 </li></ul>      |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.           |

## Considerations

Due to the inconsistency in compression results for the same data caused by different minor versions of zlib, OceanBase Database no longer supports the <code>zlib_1.0</code> compression algorithm starting from V4.2.2 to avoid issues with data recovery during upgrades.

## Examples

Set the default compression algorithm for table data to lz4_1.0.

```shell
obclient> ALTER SYSTEM SET default_compress_func = 'lz4_1.0';
```
