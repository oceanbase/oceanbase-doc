# get_leader_candidate_rpc_timeout

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is no longer applicable after the architecture upgrade in V4.x and has been removed starting from V4.0.0. </p>
</main>

## Description

`get_leader_candidate_rpc_timeout` specifies the timeout period for internal requests to obtain a leader candidate in an automatic failover strategy.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time         |
| Default value              | 9s           |
| Value range             | \[2s, 180s\] |
| Effective upon OBServer node restart | No            |
