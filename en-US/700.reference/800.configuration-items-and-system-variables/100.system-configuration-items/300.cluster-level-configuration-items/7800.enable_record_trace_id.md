# enable_record_trace_id

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is available starting with V2.2.77.  </p>
</main>

## Description

`enable_record_trace_id` specifies whether to record the trace ID set on the application side.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**    |    **Description**    |
|------------------|----------------|
| Type            | Boolean                |
| Default value              | False <main id="notice" type='explain'><h4>Note</h4><p>Starting with V4.2.0, the default value is changed from True to False. </p></main>               |
| Value range             | <ul><li>True: record </li><li>False: do not record</li></ul>    |
| Modifiable  | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.        |

## Examples

Set the trace ID of the application side not to be recorded.

```shell
obclient> ALTER SYSTEM SET enable_record_trace_id = False;
```
