# enable_record_trace_id

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V2.2.77, this parameter is available starting with V2.2.77.</p>
</main>

## Description

The `enable_record_trace_id` parameter specifies whether to record the trace ID set on the application end.

## Privilege requirements

* Query the parameter

  In the `sys` tenant and user tenants, you can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query the parameter.

* Modify the parameter

  Only the `sys` tenant can modify the parameter. User tenants cannot modify the parameter.

## Attributes

|      **Attribute**    |    **Description**    |
|------------------|----------------|
| Parameter type            | Boolean                |
| Default value              | False <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.0, the default value of this parameter is changed from True to False.</p></main>               |
| Value range             | <ul><li>True: record the trace ID </li><li>False: do not record the trace ID.</li></ul>    |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.        |

## Examples

Configure the trace ID setting so that the trace ID is not recorded.

```shell
obclient> ALTER SYSTEM SET enable_record_trace_id = False;
```
