# log_archive_batch_buffer_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

When physical backup is enabled, the `log_archive_batch_buffer_limit` parameter specifies the maximum memory usage for log archiving.

## Attributes

|        Attribute        |    Description     |
|------------------|-----------|
| Parameter type             | Capacity      |
| Default value              | 1G        |
| Value range             | \[2M, +∞) |
| Effective upon OBServer node restart | No         |

## Examples

```shell
obclient> ALTER SYSTEM SET log_archive_batch_buffer_limit = 1GB;
```
