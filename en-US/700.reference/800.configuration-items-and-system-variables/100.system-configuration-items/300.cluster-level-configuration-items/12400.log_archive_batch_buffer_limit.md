# log_archive_batch_buffer_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, this parameter is no longer applicable and was removed starting with V4.0.0. </p>
</main>

## Description

When physical backup is enabled, `log_archive_batch_buffer_limit` specifies the maximum memory usage for log archiving.

## Attributes

|        Attribute        |    Description     |
|------------------|-----------|
| Type             | Capacity      |
| Default value              | 1G        |
| Value range             | \[2M, +∞) |
| Effective upon OBServer node restart | No         |

## Examples

```shell
obclient> ALTER SYSTEM SET log_archive_batch_buffer_limit = 1GB;
```
