# enable_rootservice_standalone

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the optimization of the storage architecture in V4.x, the system tenant only stores cluster private data and no longer stores user tenant data. Therefore, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`enable_rootservice_standalone` specifies whether to allow the system tenant and RootService to exclusively use an OBServer node.

## Attributes

|      **Attribute**    |       **Description**      |
|------------------|---------------------|
| Type             | Bool                                                                                                  |
| Default value               | False                                                                                                  |
| Value range             | <ul><li> True   </li><li> False </li></ul>   |
| Effective upon OBServer node restart | No.                                                                                                      |
