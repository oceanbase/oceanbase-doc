# merger_switch_leader_duration_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>OceanBase Database V4.x does not support zone-level rotating compactions. Therefore, you do not need to specify the interval for a batch leader switchover in a major compaction. This parameter has been deprecated since OceanBase Database V4.0.0. </p>
</main>

`merger_switch_leader_duration_time` specifies the interval for a batch leader switchover in a daily compaction.

| **Attribute** | **Description** |
|------------------|------------|
| Type | Time |
| Default value | `3m`, which indicates 3 minutes. |
| Value range | \[0s, 30m\] |
| Effective upon OBServer node restart | No |
