# ob_storage_s3_url_encode_type

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For OceanBase Database V4.2.1, this parameter was introduced in OceanBase Database V4.2.1 BP9. For other versions of OceanBase Database V4.2.x, this parameter was introduced in OceanBase Database V4.2.5. </p>
</main>

## Description

`ob_storage_s3_url_encode_type` specifies whether the URL encoding method used when a request is sent over the S3 protocol complies with the RFC 3986 standard.

## Limitations

* Query the parameter

  In the `sys` tenant or a user tenant, you can execute the `SHOW PARAMETERS` statement to query the parameter or query the `GV$OB_PARAMETERS` view for the parameter.

* Modify the parameter

  You can modify the parameter only in the `sys` tenant.

## Attributes

| **Attribute** | **Description** |
|-----------|------------|
| Type | String |
| Default value | default |
| Value range | </li><li>compliantRfc3986Encoding</li> <li>default</li></ul> |
| Effective upon OBServer node restart | No |

## Considerations

This parameter specifies whether to access Tencent Cloud Object Storage (COS) over the S3 protocol. For more information, see [Preparations](../../../../600.manage/600.backup-and-recovery/300.log-archive/200.preparation-before-log-archive.md).

## Examples

Specifies that the URL encoding method used when a request is sent over the S3 protocol complies with the RFC 3986 standard.

```shell
obclient> ALTER SYSTEM SET ob_storage_s3_url_encode_type='compliantRfc3986Encoding';
```
