# log_archive_checkpoint_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you can set the archive lag time by using the <code>archive_lag_target</code> parameter. For more information about the tenant-level <code>archive_lag_target</code> parameter, see <a href="../400.tenant-level-configuration-items/200.archive_lag_target.md">archive_lag_target</a>. </li></ul>
</main>

## Description

`log_archive_checkpoint_interval` specifies the interval between log archive checkpoints for cold data.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Time       |
| Default value              | 120s       |
| Value range             | \[5s, 1h\] |
| Effective upon OBServer node restart | No          |
