# enable_pg

<main id="notice" type='explain'>
  <h4>Note</h4>
    <p>Due to the optimization of the system architecture in V4.x, the concept of partitions has been removed. This parameter is removed starting from V4.0.0. </p>
</main>

## Description

`enable_pg` specifies whether to enable the partition group feature.

## Attributes

|        Attribute        |                                                   Description                                                   |
|------------------|--------------------------------------------------------------------------------------------------------|
| Type                     | Bool      |
| Default value                       | False     |
| Value range                     | <ul><li>True: enabled</li><li>False: disabled</li></ul>     |
| Effective upon OBServer node restart    | No     |

## Examples

Enable the partition group feature.

```shell
obclient> ALTER SYSTEM SET enable_pg = True;
```
