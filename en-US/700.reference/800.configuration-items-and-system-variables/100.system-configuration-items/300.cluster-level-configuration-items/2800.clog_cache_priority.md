# clog_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the architecture was upgraded, and transaction logs no longer use cache. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`clog_cache_priority` specifies the priority of transaction logs in cache.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Integer       |
| Default value              | 1        |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
