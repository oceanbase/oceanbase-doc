# tenant_groups

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Starting from V4.0.0, this parameter is removed because the tenant group feature is no longer supported in V4.x. </p>
</main>

## Description

`tenant_groups` specifies the tenant groups used in the load balancing strategy.

| Parameter type                      | String  |
