# max_kept_major_version_number

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the fact that this parameter retains old baseline versions, which consume additional storage space, and the overall usage rate is relatively low, it has been removed starting from V4.0.0. </p>
</main>

## Description

`max_kept_major_version_number` specifies the number of frozen versions to be retained.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Int        |
| Default value              | 2         |
| Value range             | \[1, 16\] |
| Effective upon OBServer node restart | No         |
