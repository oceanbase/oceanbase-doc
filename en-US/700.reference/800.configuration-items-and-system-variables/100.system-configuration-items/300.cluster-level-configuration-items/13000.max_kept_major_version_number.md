# max_kept_major_version_number

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the additional storage space required by this parameter, which retains old baseline versions and results in low overall usage, it was removed starting with V4.0.0. </p>
</main>

## Description

`max_kept_major_version_number` specifies the number of frozen versions to retain.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Int        |
| Default value              | 2         |
| Value range             | \[1, 16\] |
| Effective upon OBServer node restart | No         |
