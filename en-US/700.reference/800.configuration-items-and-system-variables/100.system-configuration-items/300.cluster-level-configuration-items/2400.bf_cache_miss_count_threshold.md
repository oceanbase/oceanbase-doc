# bf_cache_miss_count_threshold

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`bf_cache_miss_count_threshold` specifies the threshold for triggering the BloomFilter cache. When the number of macroblock misses reaches this value, a BloomFilter cache is created.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**    |  **Description**  |
|------------------|------------|
| Type             | Int       |
| Default value               | 100      |
| Value range             | [0, +∞) <br>When the value is 0, the creation of the BloomFilter cache is disabled. |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.    |
| Effective upon OBServer node restart | No. The setting takes effect immediately.      |

## Examples

Set the number of macroblock misses to 100 to create a BloomFilter cache.

```shell
obclient> ALTER SYSTEM SET bf_cache_miss_count_threshold=100;
```
