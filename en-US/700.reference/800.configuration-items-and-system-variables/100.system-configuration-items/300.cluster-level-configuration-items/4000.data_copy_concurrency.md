# data_copy_concurrency

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>OceanBase Database V4.x does not support configuration of thread resources by task type due to limited thread resources. This parameter has been deprecated since OceanBase Database V4.0.0. </li>
<li>In OceanBase Database V4.x, you can use the <code>ha_high_thread_score</code> parameter to specify the number of worker threads for high-availability high-priority tasks such as replication, rebuild, and restore tasks. For more information about the tenant-level parameter <code>ha_high_thread_score</code>, see ha_high_thread_score. </li></ul>
</main>

`data_copy_concurrency` specifies the maximum number of concurrent data migration and replication tasks allowed in the system.

| **Attribute** | **Description** |
|--------|----------|
| Type | Integer |
| Default value | 20 |
| Value range | \[1, +∞) |
| Effective upon OBServer node restart | No |
