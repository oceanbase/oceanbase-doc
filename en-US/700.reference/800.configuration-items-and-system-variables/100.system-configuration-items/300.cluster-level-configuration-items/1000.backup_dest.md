# backup_dest

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Due to the architectural optimization of physical backup and restore in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you cannot set the destination for data backup and log archiving by using this parameter. You can use the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3800.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a> and <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3500.set-data-backup-dest.md">ALTER SYSTEM SET DATA_BACKUP_DEST</a> statements to set the log archive destination and data backup destination for a tenant, respectively. </li>
</ul>
</main>

## Description

`backup_dest` specifies the path for baseline backup and log archiving.
