# global_index_build_single_replica_timeout

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, the timeout for data construction is no longer set externally due to logical optimization. This parameter is removed starting from V4.0.0. </p>
</main>

## Description

`global_index_build_single_replica_timeout` specifies the timeout for building a replica when a global index is created.

## Attributes

| **Attribute**  |  **Description**   |
|-----------|-------------|
| Type             | Time      |
| Default value               | 48h       |
| Value range             | [1h, +∞) |
| Effective upon OBServer node restart    | No    |
