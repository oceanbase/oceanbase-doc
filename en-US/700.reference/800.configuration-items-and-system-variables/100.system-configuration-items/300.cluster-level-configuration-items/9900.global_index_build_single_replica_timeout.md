# global_index_build_single_replica_timeout

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, the corresponding feature is no longer available because the timeout for data construction is no longer required. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`global_index_build_single_replica_timeout` specifies the timeout for constructing each replica when you create a global index.

## Attributes

| **Attribute**  |  **Description**   |
|-----------|-------------|
| Type             | Time      |
| Default value               | 48h       |
| Value range             | [1h, +∞) |
| Effective upon OBServer node restart    | No    |
