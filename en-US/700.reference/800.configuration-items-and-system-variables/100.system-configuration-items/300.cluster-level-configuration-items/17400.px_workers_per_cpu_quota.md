# px_workers_per_cpu_quota

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database V2.2.50. </p>
</main>

## Description

`px_workers_per_cpu_quota` specifies the maximum number of parallel execution threads that can be allocated to each CPU.

## Privilege requirements

* To query the parameter:

  Users of the `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* To modify the parameter:

  Only users of the `sys` tenant can modify this parameter. Users of user tenants cannot modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Int        |
| Default value               | 10        |
| Value range             | [0, 20] |
| Modifiability           | This parameter can be modified by using the `ALTER SYSTEM SET` statement. |
| Effective only after OBServer restart | This parameter takes effect immediately after the setting.    |

## Examples

Set the maximum number of parallel execution threads that can be allocated to each CPU to 10.

```shell
obclient> ALTER SYSTEM SET px_workers_per_cpu_quota =10;
```
