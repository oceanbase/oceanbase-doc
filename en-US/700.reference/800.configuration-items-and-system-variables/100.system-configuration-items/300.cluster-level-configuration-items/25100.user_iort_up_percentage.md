# user_iort_up_percentage

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Due to the algorithm adjustment for IO scheduling, this parameter is removed starting with V4.0.0. </p>
</main>

## Description

`user_iort_up_percentage` specifies the user disk I/O latency threshold. If the user disk I/O latency exceeds this threshold, the system will limit the background I/O tasks.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Int       |
| Default value              | 100      |
| Value range             | \[0, +∞) |
| Effective upon OBServer node restart | No        |
