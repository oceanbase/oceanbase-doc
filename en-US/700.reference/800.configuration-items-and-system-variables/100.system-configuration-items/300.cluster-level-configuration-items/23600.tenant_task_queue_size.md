# tenant_task_queue_size


`tenant_task_queue_size` specifies the request queue size of each tenant.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The default value is changed from <code>65536</code> to <code>16384</code> in OceanBase Database V4.1.0 and later.</p>
</main>

| **Attribute** | **Description** |
|------------------|-------------|
| Type | Integer |
| Default value | 16384 |
| Value range | \[1024, +∞) |
| Effective upon OBServer node restart | No |
