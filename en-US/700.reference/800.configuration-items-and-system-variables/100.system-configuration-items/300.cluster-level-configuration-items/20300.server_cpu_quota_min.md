# server_cpu_quota_min

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.2.50, this parameter is available starting with V2.2.50.</p>
</main>

## Description

The `server_cpu_quota_min` parameter specifies the minimum CPU quota of the system, which is automatically reserved.

## Privilege requirements

* Query the parameter

  You can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view to obtain the value of this parameter in the `sys` tenant and user tenants.

* Modify the parameter

  Only the `sys` tenant has the privilege to modify this parameter. User tenants do not have the privilege to modify it.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Double    |
| Default value       | 0, which indicates adaptive adjustment.<main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.0.0, the default value is changed from 2.5 to 1.  </li><li>For V4.2.1, the default value is changed from 1 to 0. </li></ul></main>  |
| Value range     | [0, 16]<main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.0.0, the value range is changed from [0, 16] to [1, 16].</li><li>For V4.2.1, the value range is changed from [1, 16] to [0, 16]. </li></ul></main>       |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.<main id="notice" type='explain'><h4>Note</h4><p>For V4.1.0, the setting takes effect immediately instead of after the restart of an OBServer node.</p></main>             |

## Considerations

When the value is 0, the system performs adaptive adjustment on the value of the `server_cpu_quota_min` parameter based on the value of the `cpu_count` parameter of the server node.

1. If the `cpu_count` parameter is less than 8, the `server_cpu_quota_min` parameter is adaptively adjusted to 1.
2. If the `cpu_count` parameter is between 8 and 16 (inclusive), the `server_cpu_quota_min` parameter is adaptively adjusted to 2.
3. If the `cpu_count` parameter is between 16 and 32 (inclusive), the `server_cpu_quota_min` parameter is adaptively adjusted to 3.
4. If the `cpu_count` parameter is 32 or more, the `server_cpu_quota_min` parameter is adaptively adjusted to 4.

## Examples

Set the minimum CPU quota of the system to be adaptively adjusted.

```shell
obclient> ALTER SYSTEM SET server_cpu_quota_min=0;
```
