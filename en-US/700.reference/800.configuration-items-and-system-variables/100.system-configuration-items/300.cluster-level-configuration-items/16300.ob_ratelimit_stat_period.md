# ob_ratelimit_stat_period

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V3.2.2, this parameter is available starting with V3.2.2. </p>
</main>

## Description

`ob_ratelimit_stat_period` specifies the time interval for an OBServer node to calculate and update the maximum bandwidth.

## Privilege requirements

* Query the parameter

  You can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter in the `sys` tenant and all user tenants.

* Modify the parameter

  You can modify this parameter only in the `sys` tenant. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Time           |
| Default value               | 1s          |
| Value range             | [100ms,+∞) |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.    |

## Examples

Set the time interval for an OBServer node to calculate and update the maximum bandwidth to 1s.

```shell
obclient> ALTER SYSTEM SET ob_ratelimit_stat_period = '1s';
```
