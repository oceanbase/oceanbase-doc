# auto_broadcast_location_cache_rate_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade of OceanBase Database V4.x, this parameter is no longer applicable and has been deprecated since OceanBase Database V4.0.0. </p>
</main>

`auto_broadcast_location_cache_rate_limit` specifies the maximum number of partitions whose location changes can be broadcast on each OBServer node per second.

| **Attribute** | **Description** |
|------------------|---------------|
| Type | Integer |
| Default value | 1000 |
| Value range | \[1, 100000\] |
| Effective upon OBServer node restart | No |
