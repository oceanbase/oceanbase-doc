# balance_blacklist_retry_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture has been upgraded, and this parameter is no longer applicable. It is removed starting with V4.0.0. </p>
</main>

## Description

`balance_blacklist_retry_interval` specifies the retry interval for background tasks such as replica migration after they are added to the blacklist.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time        |
| Default value               | 30m, which indicates 30 minutes |
| Value range             | \[0s, 180m\] |
| Effective upon OBServer node restart | No            |
