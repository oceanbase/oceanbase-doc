# election_blacklist_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the system architecture has been optimized. The election blacklist no longer relies on time but on events. Therefore, this parameter is removed starting from V4.0.0. </p>
</main>

## Description

`election_blacklist_interval` specifies the interval during which a removed primary replica cannot be elected as the primary replica again.

## Attributes

|        Attribute        |     Description      |
|------------------|-------------|
| Parameter type                      | Time        |
| Default value              | 1800s       |
| Value range             | \[0s, 24h\] |
| Effective upon OBServer node restart | No           |
