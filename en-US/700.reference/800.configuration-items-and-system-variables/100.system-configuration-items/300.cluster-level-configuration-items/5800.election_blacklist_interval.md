# election_blacklist_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the system architecture has been optimized. The election blacklist now depends on events rather than time. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`election_blacklist_interval` specifies the time interval during which a failed primary replica cannot be elected as the primary again.

## Attributes

|        Attribute        |     Description      |
|------------------|-------------|
| Parameter type                      | Time        |
| Default value              | 1800s       |
| Value range             | \[0s, 24h\] |
| Effective upon OBServer node restart | No           |
