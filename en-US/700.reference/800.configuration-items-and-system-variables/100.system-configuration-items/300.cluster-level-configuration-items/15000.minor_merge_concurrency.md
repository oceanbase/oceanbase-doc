# minor_merge_concurrency

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to limited thread resources, V4.x no longer supports configuring thread resources by task type. This parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you can use the tenant-level parameter <code>compaction_mid_thread_score</code> to set the number of work threads for medium-priority major compactions. For more information about the <code>compaction_mid_thread_score</code> parameter, see <a href="../400.tenant-level-configuration-items/1200.compaction_mid_thread_score.md">compaction_mid_thread_score</a>. </li></ul>
</main>

## Description

`minor_merge_concurrency` specifies the number of concurrent threads for minor compactions.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Int        |
| Default value              | 0. The number of concurrent threads is min[10, cpu_cnt].        |
| Value range             | [0, 64] |
| Effective upon OBServer node restart | No         |
