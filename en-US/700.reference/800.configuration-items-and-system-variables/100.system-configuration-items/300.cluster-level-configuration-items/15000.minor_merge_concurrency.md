# minor_merge_concurrency

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>OceanBase Database V4.x does not support configuration of thread resources by task type due to limited thread resources. This parameter has been deprecated since OceanBase Database V4.0.0. </li>
<li>In OceanBase Database V4.x, you can use the tenant-level parameter <code>compaction_mid_thread_score</code> to specify the weight of the CPU time slice occupied by the worker threads for medium-priority compaction tasks. For more information about the parameter, see <a href="../400.tenant-level-configuration-items/1200.compaction_mid_thread_score.md">compaction_mid_thread_score</a>. </li></ul>
</main>

`minor_merge_concurrency` specifies the number of concurrent threads in a minor compaction.

| **Attribute** | **Description** |
|------------------|-----------|
| Type | Integer |
| Default value | `0`, which indicates that the number of concurrent threads is min[10, cpu_cnt]. |
| Value range | [0, 64] |
| Effective upon OBServer node restart | No |
