# backup_backup_dest_option

<main id="notice" type='explain'>
<h4>Note</h4>
<p>OceanBase Database V4.x does not support second backup (or backup of the backup). This parameter has been deprecated since OceanBase Database V4.0.0. </p>
</main>

`backup_backup_dest_option` specifies the parameters for second backup.

| Attribute | Description |
|------------------|-------|
| Type | String |
| Default value | Empty string |
| Value range | N/A |
| Effective upon OBServer node restart | No |

Parameters available in `backup_backup_dest_option` are a subset of those in `backup_dest_option`. You cannot specify the `backup_copies` or `log_archive_piece_switch_interval` parameter in `backup_backup_dest_option`.
