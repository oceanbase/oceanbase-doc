# election_cpu_quota

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the number of threads for the election timer task changes with the number of log streams. Only one thread is needed, so you do not need to configure the CPU quota. This parameter is removed starting from V4.0.0. </p>
</main>

## Description

`election_cpu_quota` specifies the CPU quota allocated to background tasks related to replica elections.

## Attributes

|      **Attribute**     |  **Description**   |
|-------------------|-------------|
| Parameter type            | Double    |
| Default value              | 3         |
| Value range            | [0, 10] |
| Effective upon OBServer node restart | No         |
