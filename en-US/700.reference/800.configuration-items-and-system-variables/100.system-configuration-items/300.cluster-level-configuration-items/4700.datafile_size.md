# datafile_size

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter was introduced in V2.2.50. </p>
</main>

## Description

* In shared-nothing (SN) mode, the `datafile_size` parameter specifies the size of data files.

* In shared storage (SS) mode, the `datafile_size` parameter specifies the size of local cache space.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Capacity  |
| Default value              | 0M, which is in MB. The unit must be specified when you configure this parameter.       |
| Valid values             | [0M, +∞) |
| Changeable  | Yes. You can execute the `ALTER SYSTEM SET` statement.|
| Effective upon OBServer node restart| No         |

## Considerations

If you configure both the `datafile_size` parameter and the <code>datafile_disk_percentage</code> parameter, the value of the `datafile_size` parameter takes precedence. For more information about the <code>datafile_disk_percentage</code> parameter, see <a href="4400.datafile_disk_percentage.md">datafile_disk_percentage</a>.

## Example

In shared storage mode, set the size of data files to 80G.

```shell
obclient> ALTER SYSTEM SET datafile_size='80G';
```
