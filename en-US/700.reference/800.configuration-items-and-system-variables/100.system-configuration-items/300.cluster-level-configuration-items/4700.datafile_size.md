# datafile_size

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V2.2.50, this parameter is available starting with V2.2.50.</p>
</main>

## Description

The `datafile_size` parameter specifies the size of data files.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Capacity  |
| Default value              | 0M. The default unit is MB. You must specify the unit when you configure this parameter.       |
| Value range             | [0M, +∞) |
| Modifiable  | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Considerations

* After this parameter is set, you can only increase the value but cannot reduce it.
* When this parameter and the <code>datafile_disk_percentage</code> parameter are both configured, the value of this parameter takes precedence. For more information about the <code>datafile_disk_percentage</code> parameter, see <a href="4400.datafile_disk_percentage.md">datafile_disk_percentage</a>.

## Examples

Set the size of data files to 80 GB.

```shell
obclient> ALTER SYSTEM SET datafile_size='80G';
```
