# enable_merge_by_turn

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports the round-robin merge feature, this parameter is removed starting from V4.0.0. </p>
</main>

## Description

`enable_merge_by_turn` specifies whether to enable the round-robin merge strategy.

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Type             | Bool                                                                                                  |
| Default value              | False                                                                                                  |
| Value range             | </li><li> True   </li><li> False    |
| Effective upon OBServer node restart | No                                                                                                      |
