# resource_soft_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the storage architecture upgrade in V4.x, the semantics described by this parameter are no longer applicable and were removed starting from V4.0.0. </li>
<li>In V4.x, only the tenant-level parameter <code>enable_rebalance</code> is used to control the Unit migration switch. For more information about the <code>enable_rebalance</code> parameter, see <a href="../400.tenant-level-configuration-items/2900.enable_rebalance.md">enable_rebalance</a>. </li></ul>
</main>

## Description

`resource_soft_limit` specifies whether to enable Unit rebalancing.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Int           |
| Default value              | 50           |
| Value range             | \[1, 10000\] |
| Effective upon OBServer node restart | No            |

## Considerations

When the value of `resource_soft_limit` is less than `100`, Unit rebalancing is enabled. When the value of `resource_soft_limit` is greater than or equal to `100`, Unit rebalancing is disabled.
