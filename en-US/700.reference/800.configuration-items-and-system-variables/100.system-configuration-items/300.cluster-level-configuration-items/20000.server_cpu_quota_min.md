# server_cpu_quota_min

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.2.50, this parameter is available starting with V2.2.50.</p>
</main>

## Description

`server_cpu_quota_min` specifies the minimum CPU quota available to the system. The system reserves this quota.

## Privilege requirements

* Query the parameter

  `sys` tenant and all user tenants can query the parameter by executing the `SHOW PARAMETERS` statement or querying the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can modify the parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Double    |
| Default value               | 0, which indicates adaptive adjustment<main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.0.0, the default value is changed from 2.5 to 1.  </li><li>For V4.2.1, the default value is changed from 1 to 0. </li></ul></main>  |
| Value range             | [0, 16]<main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.0.0, the value range is changed from [0, 16] to [1, 16].</li><li>For V4.2.1, the value range is changed from [1, 16] to [0, 16]. </li></ul></main>       |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. <main id="notice" type='explain'><h4>Note</h4><p>For V4.1.0, the setting takes effect immediately instead of after an OBServer node restart.</p></main>             |

## Considerations

When the value is 0, the minimum CPU quota is adaptively adjusted based on the value of `cpu_count`:

1. If `cpu_count` is less than 8 cores, the minimum CPU quota is adaptively adjusted to 1 core.
2. If 8 ≤ `cpu_count` < 16, the minimum CPU quota is adaptively adjusted to 2 cores.
3. If 16 ≤ `cpu_count` < 32, the minimum CPU quota is adaptively adjusted to 3 cores.
4. If 32 ≤ `cpu_count`, the minimum CPU quota is adaptively adjusted to 4 cores.

## Examples

Set the maximum CPU quota to the adaptive adjustment.

```shell
obclient> ALTER SYSTEM SET server_cpu_quota_max=0;
```
