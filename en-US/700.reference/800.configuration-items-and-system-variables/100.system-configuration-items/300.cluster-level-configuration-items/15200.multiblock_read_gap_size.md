# multiblock_read_gap_size

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the storage architecture changes in V4.x, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`multiblock_read_gap_size` specifies the maximum capacity of the block cache for a single I/O aggregation read.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type          | Capacity       |
| Default value              | 0K         |
| Value range             | \[0k, 2M\] |
| Effective upon OBServer node restart | No          |
