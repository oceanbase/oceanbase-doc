# enable_record_trace_id

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is available starting with V2.2.77. </p>
</main>

## Description

`enable_record_trace_id` specifies whether to record the trace ID set by the application.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**    |    **Description**    |
|------------------|----------------|
| Type            | Boolean                |
| Default value              | False <main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.2.0, the default value of this parameter is changed from True to False. </p></main>               |
| Value range             | <li> True   <li> False    |
| Modifiable  | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No                   |

## Examples

Disable recording of the trace ID set by the application.

```shell
obclient> ALTER SYSTEM SET enable_record_trace_id = False;
```
