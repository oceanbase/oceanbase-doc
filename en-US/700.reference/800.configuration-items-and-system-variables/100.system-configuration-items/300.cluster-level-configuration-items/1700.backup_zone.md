# backup_zone

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>For V4.2.5, you can use the <code>ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST</code> statement to specify a zone for backup starting from V4.2.5 BP2. </li></ul>
</main>

## Description

`backup_zone` specifies the zone for backup.

## Attributes

|      **Attribute**      | **Description** |
|------------------|--------|
| Parameter type             | String  |
| Default value              | Empty string   |
| Effective upon OBServer node restart | No      |
