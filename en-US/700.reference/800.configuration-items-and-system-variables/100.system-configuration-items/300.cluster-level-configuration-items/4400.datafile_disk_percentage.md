# datafile_disk_percentage

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in V2.2.50. </p>
</main>

## Description

* In shared-nothing (SN) mode, the `datafile_disk_percentage` parameter specifies the percentage of space occupied by data files on the disk where the `data_dir` directory is located (which is initialized by OceanBase Database for storing data).

* In shared storage (SS) mode, the `datafile_disk_percentage` parameter specifies the percentage of space available for local caching on the disk.

## Attributes

|  **Attribute**  | **Description**|
|------------|---------|
| Type    | INT    |
| Default value      | 0 <main id="notice" type='explain'><h4>Note</h4><p>In V4.0.0 and later, the default value was changed from 90 to 0. </p></main>       |
| Valid values    | [0, 99]<main id="notice" type='explain'><h4>Note</h4><p>In V4.0.0 and later, the valid value range was changed from [5, 99] to [0, 99]. </p></main> |
| Modifiable  | Yes. You can execute the `ALTER SYSTEM SET` statement to modify this parameter.|
| Effective upon OBServer node restart | No        |

## Considerations

* If the value of this parameter is 0, the system automatically calculates the percentage of space occupied by data files (in SN mode) or local caching space (in SS mode) on the disk where the `data_dir` directory is located based on whether logs and data are stored on the same disk:

  * If logs and data are stored on the same disk, the percentage of space occupied by data files or local caching space on the disk is 60%.
  * If logs and data are stored on different disks, the percentage of space occupied by data files or local caching space on the disk is 90%.

* If the `datafile_disk_percentage` parameter is configured together with the <code>datafile_size</code> parameter, the value of the <code>datafile_size</code> parameter takes precedence. For more information about the <code>datafile_size</code> parameter, see <a href="4700.datafile_size.md">datafile_size</a>.

## Examples

The following example shows how to set the percentage of space occupied by data files on the disk where the `data_dir` directory is located to 90% in SN mode.

```shell
obclient> ALTER SYSTEM SET datafile_disk_percentage=90;
```
