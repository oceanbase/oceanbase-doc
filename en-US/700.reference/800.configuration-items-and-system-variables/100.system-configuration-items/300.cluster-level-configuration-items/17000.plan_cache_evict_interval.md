# plan_cache_evict_interval

## Description

The `plan_cache_evict_interval` parameter specifies the time interval for evicting execution plans from the execution plan cache.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Time      |
| Default value              | 5s <main id="notice" type='explain'><h4>Note</h4><p>The default value of this parameter was changed from 1s to 5s in V4.2.0. </p></main>      |
| Value range             | \[0s, +∞) |
| Effective upon OBServer node restart for the change to take effect | No         |
