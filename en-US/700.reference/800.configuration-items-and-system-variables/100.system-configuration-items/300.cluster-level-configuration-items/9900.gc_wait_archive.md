# gc_wait_archive

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture is upgraded. This parameter is no longer applicable and is removed starting from V4.0.0. </p>
</main>

## Description

`gc_wait_archive` specifies whether to wait for all logs on the partition to be archived before performing partition garbage collection.

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Type             | Bool                                                                                                   |
| Default value              | True                                                                                                   |
| Value range             | </li><li> False   </li><li> True    |
| Effective upon OBServer node restart | No.                                                                                                      |
