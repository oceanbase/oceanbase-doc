# auto_leader_switch_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the optimization of the system architecture in V4.x, the election no longer requires a refresh interval. This parameter is removed starting from V4.0.0. </p>
</main>

## Description

`auto_leader_switch_interval` specifies the working interval of the background thread for automatic leader switch.

## Attributes

|     **Attribute**     |  **Description**  |
|----------------|----------|
| Type           |  Time     |
| Default value             | 30s, which indicates 30 seconds       |
| Value range           | [1s, +∞) |
| Effective upon OBServer node restart | No        |
