# election_blacklist_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the system architecture is optimized. The election blacklist is now event-based rather than time-based. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`election_blacklist_interval` specifies the interval during which the dismissed leader cannot be re-elected as the leader.

## Attributes

| Attribute | Description |
|------------------|-------------|
| Type | Time |
| Default value | 1800s |
| Value range | \[0s, 24h\] |
| Effective upon OBServer node restart | No |
