# zone_merge_order

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, zone-based and round-robin major compactions are no longer supported. This parameter is removed starting from V4.0.0. </p>
</main>

## Description

`zone_merge_order` specifies the order of zones for round-robin major compactions. If you do not specify this parameter, the system automatically determines the order.

## Attributes

|      **Attribute**      | **Description** |
|------------------|---------------------|
| Parameter type                      | String  |
| Default value              | NULL     |
| Effective upon OBServer node restart | No      |
