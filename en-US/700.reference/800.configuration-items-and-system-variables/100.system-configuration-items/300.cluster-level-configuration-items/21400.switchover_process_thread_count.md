# switchover_process_thread_count

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, this parameter is removed starting with V4.0.0 because the logic of switchover is adapted to the change in the log stream, and no independent working thread is required. </p>
</main>

## Description

`switchover_process_thread_count` specifies the size of the thread pool for primary-standby database switchover.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type             | Int         |
| Default value              | 4           |
| Value range             | \[1, 1000\] |
| Effective upon OBServer node restart | No           |
