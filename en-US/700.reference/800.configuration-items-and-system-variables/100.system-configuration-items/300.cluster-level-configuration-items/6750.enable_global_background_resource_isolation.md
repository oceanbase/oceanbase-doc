# enable_global_background_resource_isolation

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>For V4.3.x, this parameter is available starting with V4.3.2.</li><li>For V4.2.x, this parameter is available starting with V4.2.3.</li></ul>
</main>

## Description

`enable_global_background_resource_isolation` specifies whether to enable the global background resource isolation feature.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query the value of this parameter. The `sys` tenant can also use the `information_schema.PARAMETERS` view to query the value of this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type   | Boolean |
| Default value     | false |
| Value range   |[true, false]<ul><li>true: Background tasks are isolated from foreground tasks at the tenant level.</li><li>false: Background tasks are isolated from foreground tasks at the tenant level.</li></ul>|
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | Yes. If the modification involves multiple OBServer nodes, you must restart all OBServer nodes. |

## Examples

Set the value of `enable_global_background_resource_isolation` to `false`.

```shell
obclient> ALTER SYSTEM SET enable_global_background_resource_isolation=false;
```
