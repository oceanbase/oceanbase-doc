# enable_merge_by_turn

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports the turn-based merge feature, this parameter was removed starting with V4.0.0. </p>
</main>

## Description

`enable_merge_by_turn` specifies whether to enable the turn-based merge strategy.

## Attributes

|      **Attribute**      |                          **Description**                            |
|------------------|------------------------------------------------------------------|
| Type             | Boolean                                                         |
| Default value              | False                                                            |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>     |
| Effective upon OBServer node restart | No.                                                      |
