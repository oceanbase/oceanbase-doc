# merger_warm_up_duration_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture was upgraded, but the feature corresponding to this parameter was not supported. Therefore, this parameter was removed starting with V4.0.0. </p>
</main>

## Description

`merger_warm_up_duration_time` specifies the warm-up duration for new baseline data during a major compaction.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type             | Time        |
| Default value              | 0s          |
| Value range             | \[0s, 60m\] |
| Effective upon OBServer node restart | No           |
