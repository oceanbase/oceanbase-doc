# tenant_cpu_variation_per_server

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V2.x, the corresponding feature is no longer supported. This parameter is removed starting with V2.2.77. </p>
</main>

## Description

`tenant_cpu_variation_per_server` specifies the percentage of CPU quota variation for any tenant on each OBServer node.

## Attributes

|    Attribute    |    Description     |
|------------|------------|
| Type    | Double     |
| Default value      | 50         |
| Value range    | [0, 100] |
| Effective upon OBServer node restart | No          |

## Examples

Set the CPU quota variation for any tenant on each OBServer node to 50.

```shell
obclient> ALTER SYSTEM SET tenant_cpu_variation_per_server=50;
```
