# index_clog_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`index_clog_cache_priority` specifies the priority of transaction log indexes in the cache system.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Int       |
| Default value              | 1        |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
