# ignore_replica_checksum_error

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is removed starting with V4.0.0 because it may cause serious issues by ignoring errors in checksum checks between replicas. </p>
</main>

## Description

`ignore_replica_checksum_error` specifies whether to ignore errors in checksum checks between replicas.

## Attributes

|    **Attribute**      |            **Description**   |
|------------------|-----------------------|
| Type             | Boolean   |
| Default value               | False      |
| Value range             | <ul><li>True: separate storage</li><li>False: no separate storage</li></ul>    |
| Effective upon OBServer node restart    | No     |
