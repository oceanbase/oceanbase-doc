# ignore_replica_checksum_error

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is removed starting with V4.0.0 because it may cause serious issues by ignoring checksum errors between replicas. </p>
</main>

## Description

`ignore_replica_checksum_error` specifies whether to ignore checksum errors between replicas.

## Attributes

|    **Attribute**      |            **Description**   |
|------------------|-----------------------|
| Type             | Bool   |
| Default value               | False      |
| Value range             | <ul><li>True: separate storage</li><li>False: not separate storage</li></ul>    |
| Effective upon OBServer node restart    | No     |
