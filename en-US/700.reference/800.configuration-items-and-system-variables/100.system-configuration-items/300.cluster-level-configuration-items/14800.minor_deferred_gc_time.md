# minor_deferred_gc_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is no longer recommended for use starting with V2.2.3x and is removed starting with V4.0.0. </p>
</main>

## Description

`minor_deferred_gc_time` specifies the interval between the time when a major compaction is completed and the time when the SSTables generated by the major compaction are recycled.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type             | Time       |
| Default value              | 0s          |
| Value range             | \[0s, 24h] |
| Effective upon OBServer node restart | No           |
