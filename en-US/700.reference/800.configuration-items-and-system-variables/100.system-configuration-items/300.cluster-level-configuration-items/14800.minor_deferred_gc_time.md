# minor_deferred_gc_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is deprecated starting from V2.2.3x and removed starting from V4.0.0. </p>
</main>

## Description

`minor_deferred_gc_time` specifies the time interval for delaying the minor compaction of an SSTable.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type             | Time       |
| Default value              | 0s          |
| Value range             | \[0s, 24h] |
| Effective upon OBServer node restart | No           |
