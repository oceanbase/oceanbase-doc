# px_task_size

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V2.2.50. </p>
</main>

## Description

`px_task_size` specifies the amount of data processed by each task in the SQL parallel query engine.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Capacity      |
| Default value               | 2 MB. The default unit is MB. You must specify the unit when you configure this parameter.        |
| Value range             | [2 MB, +∞) |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.     |

## Examples

Set the amount of data processed by each task in the SQL parallel query engine to 2 MB.

```shell
obclient> ALTER SYSTEM SET px_task_size ='2M';
```
