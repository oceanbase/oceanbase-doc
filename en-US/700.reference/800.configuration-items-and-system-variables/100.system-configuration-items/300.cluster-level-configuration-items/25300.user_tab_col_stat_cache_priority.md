# user_tab_col_stat_cache_priority

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is removed starting with V4.0.0 because the method for maintaining statistics has been changed. The corresponding feature is no longer available. </p>
</main>

## Description

`user_tab_col_stat_cache_priority` specifies the priority of the statistics cache in the cache system.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Int       |
| Default value              | 1        |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
