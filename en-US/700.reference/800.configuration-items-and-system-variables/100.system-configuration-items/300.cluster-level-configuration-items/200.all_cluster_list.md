# all_cluster_list

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.x, the cluster configuration has been optimized. This parameter is available starting with V2.2.50. </p>
</main>

## Description

`all_cluster_list` specifies the list of servers that access the same `config_url`.

## Attributes

|      **Attribute**      | **Description** |
|------------------|--------|
| Type             | String    |
| Default value               | NULL     |
| Effective upon OBServer node restart | No      |
