# zone_merge_order

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports zone-based major compactions and round-robin major compactions, this parameter is removed starting from V4.0.0. </p>
</main>

## Description

`zone_merge_order` specifies the order of zone-based major compactions. If you do not specify this parameter, the system automatically determines the order.

## Attributes

|      **Attribute**      | **Description** |
|------------------|---------------------|
| Parameter type                      | String  |
| Default value              | NULL     |
| Effective upon OBServer node restart | No      |
