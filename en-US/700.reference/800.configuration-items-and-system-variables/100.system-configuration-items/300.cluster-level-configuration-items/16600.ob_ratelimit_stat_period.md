# ob_ratelimit_stat_period

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V3.2.2. </p>
</main>

## Description

`ob_ratelimit_stat_period` specifies the interval at which the OBServer node calculates and updates the maximum bandwidth.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Time           |
| Default value               | 1s          |
| Value range             | [100ms,+∞) |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.            |

## Examples

Set the interval at which the OBServer node calculates and updates the maximum bandwidth to 1s.

```shell
obclient> ALTER SYSTEM SET ob_ratelimit_stat_period = '1s';
```
