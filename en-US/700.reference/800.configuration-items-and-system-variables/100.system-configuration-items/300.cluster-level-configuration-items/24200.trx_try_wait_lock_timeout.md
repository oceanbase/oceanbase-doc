# trx_try_wait_lock_timeout

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V3.1.0, this parameter is removed due to feature adjustments. </p>
</main>

## Description

`trx_try_wait_lock_timeout` specifies the maximum wait time for a row lock during statement execution.

## Attributes

|      **Attribute**      |     **Description**     |
|------------------|----------------|
| Parameter type             | Time           |
| Default value               | 0ms            |
| Value range             | [0ms, 100ms] |
| Effective upon OBServer node restart | No              |
