# backup_net_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<P>Due to the architectural optimization of the physical backup and restore feature in V4.x, cluster-level backup is no longer supported. This parameter is removed starting from V4.0.0. </P>
</main>

## Description

`backup_net_limit` specifies the total bandwidth for cluster backup.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Capacity     |
| Default value              | 0M        |
| Value range             | \[0M, +∞) |
| Effective upon OBServer node restart | No         |
