# ob_esi_max_syslog_file_count

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architectural optimization of physical backup and restore in V4.x, this parameter is no longer supported in V4.x and was removed starting from V4.0.0. </p>
</main>

## Description

`ob_esi_max_syslog_file_count` specifies the maximum number of log files that the obesi process can retain before recycling.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Int |
| Default value | 0 |
| Value range | [0, +∞) |
| Effective upon OBServer node restart | No |

## Considerations

Each log file can occupy up to 256 MB of disk space. If the value of this parameter is 0, no log files are deleted.
