# merge_stat_sampling_ratio

<main id="notice" type='explain'>
<h4>Note</h4>
<p></p>
<ul><li>Starting from V4.0.0, this parameter is removed because the new statistics collection feature in V4.x does not collect statistics during major compactions. </li>
<li>In V4.x, you can call the DBMS_STATS system package to collect statistics. For more information, see <a href="../../../../600.manage/900.performance-tuning/400.sql-tuning/200.execution-plan-optimization/100.statistics-and-cost-based-optimization/200.statistic-information/200.collect-statistic-information/100.collect-statistic-information-overview.md">Overview of statistics collection</a>. </li></ul>
</main>

## Description

`merge_stat_sampling_ratio` specifies the sampling ratio for statistics collection during major compactions.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value              | 100        |
| Value range             | \[0, 100\] |
| Effective upon OBServer node restart | No          |
