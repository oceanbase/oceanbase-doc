# merger_completion_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to low usage, this parameter is deprecated starting from V4.0.0. </p>
</main>

## Description

`merger_completion_percentage` specifies the percentage of replicas that must be completed for a major compaction to be considered complete.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value              | 100        |
| Value range             | \[5, 100\] |
| Effective upon OBServer node restart | No          |
