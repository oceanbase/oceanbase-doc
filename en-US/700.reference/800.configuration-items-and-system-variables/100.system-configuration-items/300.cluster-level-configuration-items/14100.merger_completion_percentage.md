# merger_completion_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is removed starting with V4.0.0 because it is rarely used since its introduction. </p>
</main>

## Description

`merger_completion_percentage` specifies the percentage of replicas that are completed in a major compaction. When the percentage reaches the specified value, the major compaction is considered to be completed.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value              | 100        |
| Value range             | \[5, 100\] |
| Effective upon OBServer node restart | No          |
