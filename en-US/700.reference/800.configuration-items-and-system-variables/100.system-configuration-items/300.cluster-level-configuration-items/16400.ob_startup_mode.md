# ob_startup_mode

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.1.0, this parameter is available starting with V4.1.0.</p>
</main>

## Description

`ob_startup_mode` specifies the startup mode of an OBServer node. You can modify this parameter only during the first startup of the node.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  You can modify this parameter only during the first startup of the cluster.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type | String |
| Default value | NORMAL |
| Value range |<ul><li>`NORMAL`: specifies the Shared-Nothing (SN) mode. </li><li>`ARBITRATION`: specifies the arbitration mode. </li><li>`SHARED_STORAGE`: specifies the Shared-Storage (SS) mode. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>The `SHARED_STORAGE` value is available starting with V4.3.4. </p></main>|
| Modifiable | No. You cannot use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The parameter is read-only. |
