# ob_startup_mode

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in V4.1.0. </p>
</main>

## Description

The `ob_startup_mode` parameter specifies the startup mode of an OBServer node. This parameter can be modified only when the node is started for the first time.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view to query the parameter.

* Modify the parameter

  Only the `sys` tenant can modify the parameter. User tenants cannot modify the parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type | String |
| Default value | NORMAL |
| Valid values |<ul><li> NORMAL: specifies to start in normal mode.  </li><li>ARBITRATION: specifies to start in arbitration mode. </li><li>SHARED_STORAGE: specifies to start in shared storage (SS) mode. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>The `SHARED_STORAGE` value was introduced in V4.3.4. </p></main>|
| Modifiable | Yes. You can execute the `ALTER SYSTEM SET` statement to modify this parameter. |
| Effective upon OBServer node restart | No |

## Examples

This example shows how to set the startup mode of an OBServer node in the `sys` tenant to `SHARED_STORAGE`.

```shell
obclient> ALTER SYSTEM SET ob_startup_mode='SHARED_STORAGE';
```
