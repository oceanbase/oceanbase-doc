# default_transport_compress_func

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the architectural optimization in V4.x, each module now independently controls its compression algorithm, and the default_transport_compress_func parameter was removed starting from V4.0.0. </li>
<li>For V4.x:
<ul><li>Starting from V4.1.0, the <code>log_transport_compress_func</code> tenant-level parameter is used to control the compression algorithm for log transmission. For more information about the <code>log_transport_compress_func</code> parameter, see <a href="../400.tenant-level-configuration-items/5000.log_transport_compress_func.md">log_transport_compress_func</a>. </li>
<li>Starting from V4.2.1, the <code>kv_transport_compress_func</code> tenant-level parameter is used to control the compression algorithm for OBKV-Table query results in V4.2.x. In V4.3.x, the <code>tableapi_transport_compress_func</code> cluster-level parameter is used to control the compression algorithm for OBKV-Table query results. For more information about the <code>tableapi_transport_compress_func</code> parameter, see <a href="22600.tableapi_transport_compress_func.md">tableapi_transport_compress_func</a>. </li></ul></li></ul>
</main>

## Description

`default_transport_compress_func` specifies the RPC compression algorithm for the entire cluster.

## Attributes

| **Attribute**                      |       **Description**                        |
|------------------------------|----------------------------------------|
| Parameter type                      | String                                 |
| Default value                        | none                                   |
| Value range                      | <ul><li>none </li><li>lz4_1.0    </li><li>snappy_1.0    </li><li>zlib_1.0    </li><li> zstd_1.0    </li><li>zstd_1.3.8    </li></ul>    |
| Modifiable                    | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart    | No                     |

## Examples

Set the RPC compression algorithm for the entire cluster to `lz4_1.0`.

```shell
obclient> ALTER SYSTEM SET default_transport_compress_func = 'lz4_1.0';
```
