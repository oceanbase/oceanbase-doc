# rebuild_replica_data_lag_threshold

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`rebuild_replica_data_lag_threshold` specifies the threshold of the gap between the transaction logs of a standby replica and those of the primary replica. When the gap exceeds the threshold, the system triggers a replica rebuild.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Capacity    |
| Default value              | 0     |
| Value range             | \[0, +∞) |
| Effective upon OBServer node restart | No        |

## Considerations

When the value of the `rebuild_replica_data_lag_threshold` parameter is 0, the system does not trigger a replica rebuild.
