# rebuild_replica_data_lag_threshold

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture changes in V4.x, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`rebuild_replica_data_lag_threshold` specifies the threshold for the gap between the transaction logs of a standby replica and those of the primary replica. When the gap exceeds this threshold, the replica is rebuilt.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Capacity    |
| Default value              | 0     |
| Value range             | \[0, +∞) |
| Effective upon OBServer node restart | No        |

## Considerations

When the value of the `rebuild_replica_data_lag_threshold` parameter is 0, replica rebuilding is not triggered.
