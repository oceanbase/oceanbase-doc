# strict_check_os_params

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter was introduced in V4.3.0 for V4.3.x and V4.2.2 for V4.2.x. </p>
</main>

## Description

The `strict_check_os_params` parameter specifies whether to enable the OS parameter check feature.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This parameter can be set only for the sys tenant. </p>
</main>

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Type | Bool |
| Default value | false |
| Value range |[true, false]<ul><li>If set to true, an error will be returned when the parameter value is out of range, and the OBServer node cannot start. </li><li>If set to false, a warning will be returned when the parameter value is out of range, and the OBServer node can start. </li></ul>|
| Modifiable | Yes. You can execute the `ALTER SYSTEM SET` statement to modify this parameter. |
| Effective upon OBServer node restart | No |

## Example

    ```shell
    obclient> ALTER SYSTEM SET strict_check_os_params=false;
    ```
