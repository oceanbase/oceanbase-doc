# datafile_next

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database V3.1.4. </p>
</main>

## Description

* In shared-nothing (SN) mode, the `datafile_next` parameter specifies the increment step for automatic expansion of disk files.

* In shared storage (SS) mode, the value of the `datafile_next` parameter has no meaning and can be modified, but the modification will not take effect.

## Attributes

| Attribute | Description |
| --- | --- |
| Type | Capacity |
| Default value | 0 |
| Valid values | [0M, +∞) |
| Effective upon OBServer node restart of the OceanBase Server node | No |

## Considerations

In SN mode, the default value of `datafile_next` is 0, which indicates that automatic expansion is disabled. If you want to enable automatic expansion, set a new value:

* If `datafile_next` is set to a value smaller than 1 GB, the value min (1 GB, datafile_maxsize * 10%) is used.
* If `datafile_next` is set to a value greater than 1 GB, the value min (datafile_next, remaining disk space) is used.

## Examples

In SN mode, set the increment step for automatic expansion of disk files to 10 GB.

```shell
obclient> ALTER SYSTEM SET datafile_next = '10G';
```
