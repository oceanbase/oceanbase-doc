# user_tab_col_stat_cache_priority

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Due to the change in the maintenance method of statistics, this parameter is deprecated starting with V4.0.0. </p>
</main>

## Description

`user_tab_col_stat_cache_priority` specifies the priority of the statistics cache in the cache system.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Integer       |
| Default value              | 1        |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
