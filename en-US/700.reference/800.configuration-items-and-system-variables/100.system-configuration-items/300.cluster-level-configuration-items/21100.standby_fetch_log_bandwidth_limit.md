# standby_fetch_log_bandwidth_limit

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in V4.2.0. </p>
</main>

## Description

The `standby_fetch_log_bandwidth_limit` parameter specifies the total bandwidth available in the standby tenant's cluster for log synchronization from the primary tenant or source tenant.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type | Capacity |
| Default value | 0 MB, which indicates no traffic limit. |
| Value range | [0, 10000G] |
| Modifiable | Yes. You can execute the `ALTER SYSTEM SET` statement to modify this parameter. |
| Effective upon OBServer node restart | No |

## Considerations

When you set this parameter, you must specify the unit (B, KB, MB, or GB), which is case-insensitive. The default unit is bytes.

## Example

Set the total bandwidth available in the standby tenant's cluster for log synchronization from the primary tenant or source tenant to 200 MB.

```shell
obclient> ALTER SYSTEM SET standby_fetch_log_bandwidth_limit = '200M';
```
