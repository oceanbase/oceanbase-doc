# ob_esi_rpc_port

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is no longer supported in V4.x and was removed starting from V4.0.0. </p>
</main>

## Description

`ob_esi_rpc_port` specifies the communication port between the obesi process and the observer process.

## Attributes

| **Attribute**    | **Description**        |
|-------------|-----------------|
| Type | Int |
| Default value   | 2501 |
| Value range | [1025, 65535] |
| Effective upon OBServer node restart | No |
