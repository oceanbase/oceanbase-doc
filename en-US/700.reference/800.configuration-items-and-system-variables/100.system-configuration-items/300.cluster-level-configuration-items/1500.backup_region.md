# backup_region

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the architectural optimization of physical backup and restore in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you cannot specify a region for backup. </li></ul>
</main>

## Description

`backup_region` specifies the region where backup is performed.

## Attributes

|      **Attribute**      | **Description** |
|------------------|--------|
| Parameter type             | String  |
| Default value              | Empty string   |
| Effective upon OBServer node restart | No      |
