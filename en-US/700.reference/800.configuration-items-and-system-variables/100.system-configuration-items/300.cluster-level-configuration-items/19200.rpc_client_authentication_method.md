# rpc_client_authentication_method

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V3.2.4. </p>
</main>

## Description

`rpc_client_authentication_method` specifies the security authentication method for the RPC client.

For the `sys` tenant, you only need to set the authentication method on the client and server.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------ | ------ |
| Parameter type             | String |
| Default value               | NONE |
| Value range             |<ul> <li>NONE: the default authentication method for the client, which indicates that no authentication is performed.</li> <li>SSL_NO_ENCRYPT: authentication is performed based on the local SSL certificate and private key through an SSL handshake, but subsequent communication is not encrypted.</li></ul>|
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |

## Considerations

* On the server, you need to configure the <code>rpc_server_authentication_method</code> parameter. For more information, see [rpc_server_authentication_method](19400.rpc_server_authentication_method.md).
* If the value of this parameter is set correctly, the latest configuration takes effect. Otherwise, the original authentication method remains in effect, and the current configuration does not take effect.
* The client can only configure one authentication method at a time. The default value is <code>NONE</code>, and this parameter is case-insensitive.

## Examples

Set the security authentication method for the RPC client to NONE.

```shell
obclient> ALTER SYSTEM SET rpc_client_authentication_method = 'NONE';
```
