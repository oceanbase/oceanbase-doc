# row_purge_thread_count

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is removed starting from V4.0.0 because the corresponding feature has never been enabled. </p>
</main>

## Description

`row_purge_thread_count` specifies the maximum number of worker threads for performing in-memory row data compactions.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Int        |
| Default value              | 4         |
| Value range             | \[1, 64\] |
| Effective upon OBServer node restart | No         |
