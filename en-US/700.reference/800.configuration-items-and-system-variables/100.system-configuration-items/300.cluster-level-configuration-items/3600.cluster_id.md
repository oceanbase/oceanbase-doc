# cluster_id

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.2.50, this parameter is available starting with V2.2.50. </p>
</main>

## Description

`cluster_id` specifies the ID of the OceanBase cluster.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can query this parameter by using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify the parameter

  Only the `sys` tenant can set this parameter during cluster deployment. After the cluster is started, this parameter cannot be modified. User tenants do not have the privilege to modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Type             | Int                |
| Default value               | 0                 |
| Value range             | [1, 4294901759] |
| Modifiable | No. You cannot use the `ALTER SYSTEM SET` statement to modify the parameter.  |
| Effective upon OBServer node restart | No. The parameter is read-only. |
