# plan_cache_high_watermark

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is removed starting with V4.2.0 because the feature it corresponds to has never been effective. </p>
</main>

## Description

`plan_cache_high_watermark` specifies the threshold of memory occupied by the execution plan cache. If the threshold is exceeded, the system automatically evicts execution plans.

## Attributes

|      **Attribute**             |  **Description**               |
|---------------------------|-------------------------|
| Parameter type                   | Capacity   |
| Default value                     | 2000M. The default unit is MB. You must specify the unit when you configure this parameter.  |
| Value range                   | [0, +∞)   |
| Effective upon OBServer node restart  | No      |
