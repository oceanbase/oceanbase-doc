# plan_cache_high_watermark

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Because the feature corresponding to this parameter has never been enabled, this parameter is removed starting from V4.2.0. </p>
</main>

## Description

`plan_cache_high_watermark` specifies the memory threshold for the execution plan cache. When the cache exceeds this threshold, automatic eviction is triggered.

## Attributes

|      **Attribute**             |  **Description**               |
|---------------------------|-------------------------|
| Parameter type                   | Capacity   |
| Default value                     | 2000M. The default unit is MB. You must specify the unit when you configure this parameter.  |
| Value range                   | [0, +∞)   |
| Effective upon OBServer node restart  | No      |
