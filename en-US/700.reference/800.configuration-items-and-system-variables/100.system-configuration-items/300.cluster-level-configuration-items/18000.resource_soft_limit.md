# resource_soft_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the storage architecture upgrade in V4.x, this parameter is no longer applicable and was removed starting with V4.0.0. </li>
<li>In V4.x, only the tenant-level parameter <code>enable_rebalance</code> controls whether unit migration is enabled. For more information about the <code>enable_rebalance</code> parameter, see <a href="../400.tenant-level-configuration-items/2800.enable_rebalance.md">enable_rebalance</a>.</li></ul>
</main>

## Description

`resource_soft_limit` specifies whether to enable unit balancing.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Int           |
| Default value              | 50           |
| Value range             | \[1, 10000\] |
| Effective upon OBServer node restart | No            |

## Considerations

If the value of the `resource_soft_limit` parameter is less than `100`, unit balancing is enabled. If the value of the `resource_soft_limit` parameter is greater than or equal to `100`, unit balancing is disabled.
