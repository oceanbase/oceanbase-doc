# resource_soft_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the upgrade of the storage architecture in V4.x, the semantics described by this parameter are no longer applicable and it has been removed starting from V4.0.0. </li>
<li>In V4.x, only the tenant-level parameter <code>enable_rebalance</code> controls whether to enable unit migration. For more information about the <code>enable_rebalance</code> parameter, see <a href="../400.tenant-level-configuration-items/2800.enable_rebalance.md">enable_rebalance</a>. </li></ul>
</main>

## Description

`resource_soft_limit` specifies whether to enable unit migration.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Type             | Int           |
| Default value              | 50           |
| Value range             | \[1, 10000\] |
| Effective upon OBServer node restart | No            |

## Considerations

If the value of the `resource_soft_limit` parameter is less than `100`, unit migration is enabled. If the value is greater than or equal to `100`, unit migration is disabled.
