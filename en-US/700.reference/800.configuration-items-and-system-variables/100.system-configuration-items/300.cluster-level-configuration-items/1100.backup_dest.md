# backup_dest

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Due to the architectural optimization of the physical backup and restore feature in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you cannot set the destination for data backup and log archiving by using this parameter. You can use the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/150.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a> and <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3500.set-data-backup-dest.md">ALTER SYSTEM SET DATA_BACKUP_DEST</a> statements to separately configure the log archive destination and data backup destination for a tenant. </li>
</ul>
</main>

## Description

`backup_dest` specifies the path for baseline backup and log archiving.
