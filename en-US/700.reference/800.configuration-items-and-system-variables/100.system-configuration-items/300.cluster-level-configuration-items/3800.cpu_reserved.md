# cpu_reserved

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Due to the architecture changes in V4.x, this parameter is no longer supported and was removed starting from V4.0.0. </p>
</main>

## Description

`cpu_reserved` specifies the number of CPU cores reserved for the system. The remaining CPU cores are exclusively used by OceanBase Database.

## Attributes

|  **Attribute**    |  **Description**   |
|----------------|-----------|
| Parameter type            | Int        |
| Default value              | 2         |
| Value range            | [0, 15] |
| Effective upon OBServer node restart | No         |
