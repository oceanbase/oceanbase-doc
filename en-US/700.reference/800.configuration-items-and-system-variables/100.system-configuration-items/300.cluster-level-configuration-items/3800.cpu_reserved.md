# cpu_reserved

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, the system architecture was changed and the corresponding feature is no longer supported. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`cpu_reserved` specifies the number of CPU cores reserved for the system. The remaining CPU cores are exclusively used by OceanBase Database.

## Attributes

|  **Attribute**    |  **Description**   |
|----------------|-----------|
| Type            | Int        |
| Default value              | 2         |
| Value range            | [0, 15] |
| Effective upon OBServer node restart | No         |
