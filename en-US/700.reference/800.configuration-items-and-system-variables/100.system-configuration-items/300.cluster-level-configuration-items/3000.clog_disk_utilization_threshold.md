# clog_disk_utilization_threshold

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Since V4.x, log disk space is managed at the tenant level. Therefore, this parameter is no longer available and was removed starting with V4.0.0. </li>
<li>In V4.x, use the tenant-level parameter <code>log_disk_utilization_threshold</code> to control the water level for log disk space reuse. For more information about the <code>log_disk_utilization_threshold</code> parameter, see <a href="../400.tenant-level-configuration-items/4700.log_disk_utilization_threshold.md">log_disk_utilization_threshold</a>. </li></ul>
</main>

## Description

`clog_disk_utilization_threshold` specifies the water level for log disk space reuse.

## Attributes

|        Attribute        |     Description     |
|------------------|------------|
| Parameter type             | Int         |
| Default value               | 80         |
| Value range             | \[10, 100) |
| Effective upon OBServer node restart | No          |

## Examples

Set the water level for log disk space reuse to 80.

```shell
obclient> ALTER SYSTEM SET clog_disk_utilization_threshold=80;
```
