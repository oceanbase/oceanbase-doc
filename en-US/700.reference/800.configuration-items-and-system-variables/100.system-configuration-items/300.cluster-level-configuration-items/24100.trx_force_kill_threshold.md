# trx_force_kill_threshold

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Due to changes in the corresponding logic in V4.x, this parameter is no longer available starting with V4.0.0. </p>
</main>

## Description

`trx_force_kill_threshold` specifies the maximum waiting time for killing a transaction when a transaction is frozen or the primary node is switched.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time         |
| Default value              | 100ms        |
| Value range             | \[1ms, 10s\] |
| Effective upon OBServer node restart | No            |
