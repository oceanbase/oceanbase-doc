# bf_cache_priority

`bf_cache_priority` specifies the priority of the Bloom filter cache.

| **Attribute** | **Description** |
|------------------|----------|
| Type | Integer |
| Default value | 1 |
| Value range | \[1, +∞) |
| Effective upon OBServer node restart | No |
