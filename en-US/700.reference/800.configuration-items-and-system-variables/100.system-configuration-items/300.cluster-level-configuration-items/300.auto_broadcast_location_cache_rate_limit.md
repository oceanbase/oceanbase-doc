# auto_broadcast_location_cache_rate_limit

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture changes in V4.x, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`auto_broadcast_location_cache_rate_limit` specifies the maximum number of partitions per OBServer node that can broadcast location information changes per second.

## Attributes

|      **Attribute**      |    **Description**     |
|------------------|---------------|
| Parameter type             | Int            |
| Default value              | 1000          |
| Value range             | \[1, 100000\] |
| Effective upon OBServer node restart | No             |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p> This parameter takes effect only when the automatic refresh of location cache information is enabled. </p>
</main>
