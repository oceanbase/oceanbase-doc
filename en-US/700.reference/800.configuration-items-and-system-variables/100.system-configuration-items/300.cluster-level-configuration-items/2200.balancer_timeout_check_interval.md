# balancer_timeout_check_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture was upgraded, and this parameter is no longer applicable. It was removed starting with V4.0.0. </p>
</main>

## Description

`balancer_timeout_check_interval` specifies the interval at which to check for timeouts in background tasks such as load balancing.

## Attributes

|      **Attribute**    |   **Description** |
|------------------|------------|
| Parameter type            | Time      |
| Default value              | 1m, which indicates 1 minute |
| Value range            | [1s, +∞)  |
| Effective upon OBServer node restart | No          |
