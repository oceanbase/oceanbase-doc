# balancer_timeout_check_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the upgrade of the storage architecture in V4.x, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`balancer_timeout_check_interval` specifies the interval for checking the timeout of background tasks such as load balancing.

## Attributes

|      **Attribute**    |   **Description** |
|------------------|------------|
| Parameter type            | Time      |
| Default value              | 1m, which indicates 1 minute |
| Value range            | [1s, +∞)  |
| Effective upon OBServer node restart | No          |
