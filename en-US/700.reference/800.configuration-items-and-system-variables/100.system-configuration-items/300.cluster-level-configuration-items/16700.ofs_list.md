# ofs_list

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, this parameter is removed starting with V4.0.0. </p>
</main>

## Description

`ofs_list` specifies the OceanBase File System (OFS) connection URLs of each zone. This parameter is used in the OFS deployment mode to allow RootService to access files across zones.

## Attributes

|        Attribute        |            Description            |
|------------------|--------------------------|
| Type             | String                    |
| Default value              | The OFS list at deployment              |
| Value range             | The format is: `[zone]@[ofs_url];` |
| Effective upon OBServer node restart | No                        |
