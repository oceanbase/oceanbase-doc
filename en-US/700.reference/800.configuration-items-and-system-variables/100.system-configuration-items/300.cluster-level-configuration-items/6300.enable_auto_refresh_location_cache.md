# enable_auto_refresh_location_cache

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is no longer available starting with V4.0.0 because the architecture was upgraded in V4.x. </p>
</main>

## Description

`enable_auto_refresh_location_cache` specifies whether to enable the automatic refresh of location cache information.

## Attributes

|      **Attribute**      |          **Description**                               |
|------------------|---------------------------------------------------|
| Type             | Bool                             |
| Default value              | True                                 |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>    |
| Effective upon OBServer node restart | No                             |
