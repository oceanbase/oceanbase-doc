# minor_freeze_times

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Due to the storage architecture upgrade in V4.x, this parameter has the same meaning as the <code>major_compact_trigger</code> parameter and was removed starting from V4.0.0. </li>
<li>In V4.x, you can only use the tenant-level parameter <code>major_compact_trigger</code> to specify the number of minor freezes after which a major compaction is triggered. For more information about the <code>major_compact_trigger</code> parameter, see <a href="../400.tenant-level-configuration-items/5200.major_compact_trigger.md">major_compact_trigger</a>. </li></ul>
</main>

## Description

`minor_freeze_times` specifies the number of minor freezes after which a major compaction is triggered.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Int           |
| Default value              | 100          |
| Value range             | \[0, 65535\] |
| Effective upon OBServer node restart | No            |

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li> If the value of this parameter is 0, a major compaction is not triggered regardless of the number of minor freezes. </li>
  <li> This parameter has the same function as the <code>major_compact_trigger</code> parameter. </li>
  </ul>
</main>
