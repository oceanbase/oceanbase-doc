# gc_wait_archive

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x introduced a new storage architecture, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`gc_wait_archive` specifies whether to wait for all logs on a partition to be archived before performing partition garbage collection (GC).

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Type             | Bool                                                                                                   |
| Default value              | True                                                                                                   |
| Value range             | <ul><li>True: wait for all logs to be archived. </li><li>False: do not wait. </li></ul>    |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |
