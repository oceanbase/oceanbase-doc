# gc_wait_archive

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture has been upgraded. This parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`gc_wait_archive` specifies whether to wait for all logs of a partition to be archived before performing partition garbage collection.

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Type             | Bool                                                                                                   |
| Default value              | True                                                                                                   |
| Value range             | <ul><li>True: wait </li><li>False: do not wait </li></ul>    |
| Effective upon OBServer node restart | No. The setting takes effect immediately. |
