# enable_auto_leader_switch

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the optimization of the system architecture in V4.x, automatic leader switching is controlled by a single log stream and no load balancing is required. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`enable_auto_leader_switch` specifies whether to enable automatic leader switching.

## Attributes

|      **Attribute**      |                     **Description**                |
|------------------|---------------------------------------------------------|
| Parameter type             | Bool                                                 |
| Default value              | True                                                  |
| Value range             | False: disables automatic leader switching.    |
| Effective upon OBServer node restart | No                                               |
