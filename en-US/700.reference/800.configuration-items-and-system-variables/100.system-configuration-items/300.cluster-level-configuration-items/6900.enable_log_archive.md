# enable_log_archive

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Due to the architectural optimization of physical backup and restore in V4.x, this parameter is removed starting from V4.0.0. </li>
<li>In V4.x, you can use the <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/200.archivelog.md">ALTER SYSTEM ARCHIVELOG</a> statement in the sys tenant and all user tenants to enable the archive mode. For more information, see <a href="../../../../600.manage/600.backup-and-recovery/300.log-archive/300.open-the-log-archive-mode.md">Enable the archive mode</a>. </li></ul>
</main>

## Description

`enable_log_archive` specifies whether to enable the log archive feature.

## Attributes

|      **Attribute**      |             **Description**               |
|------------------|-------------------------------------|
| Type             | Bool                              |
| Default value              | False                              |
| Value range             | <ul><li>True: enable the log archive feature. </li><li>False: do not enable the log archive feature. </li></ul>     |
| Effective upon OBServer node restart | No                             |
