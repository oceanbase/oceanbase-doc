# enable_global_freeze_trigger

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x implements tenant-level freezing, this parameter is no longer applicable and has been removed starting from V4.0.0.  </p>
</main>

## Description

`enable_global_freeze_trigger` specifies whether to enable automatic global freeze triggering.

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Parameter type             | Bool                                                                                                    |
| Default value              | False                                                                                                  |
| Value range             | </li><li> True   </li><li> False    |
| Effective upon OBServer node restart | No                                                                                                      |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>  This parameter remains at its default value and is not recommended for modification.  </p>
</main>
