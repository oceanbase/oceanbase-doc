# devname

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`devname` specifies the name of the network interface card (NIC) that the service process is bound to.

## Privilege requirements

The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

## Attributes

|      **Attribute**      | **Description** |
|------------------|------------|
| Type             | String    |
| Default value               | bond0  |
| Modifiable           | No. This parameter is read-only. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is read-only starting with V4.2.0. </p></main>|
