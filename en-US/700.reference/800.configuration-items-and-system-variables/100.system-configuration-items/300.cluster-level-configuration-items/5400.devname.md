# devname

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is applicable to OBServer nodes of OceanBase Database V4.2.0 and later. Its value is read-only. </p>
</main>

## Description

The devname parameter specifies the name of the network device to which the service process is bound.

## Attributes

|      **Attribute**      | **Description** |
|------------------|------------|
| Type             | String    |
| Default value              | bond0  |
| Value range             | NULL   |
| Effective upon OBServer node restart | No. This is a read-only parameter. |
