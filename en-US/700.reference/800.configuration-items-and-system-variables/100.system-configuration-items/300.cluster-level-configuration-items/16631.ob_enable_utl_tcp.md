# ob_enable_utl_tcp

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.5.0, this parameter is available starting with V4.5.0. </p>
</main>

## Description

`ob_enable_utl_tcp` specifies whether to enable the UTL_TCP system package.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type    |    Boolean             |
| Default value      |  FALSE  |
| Value range    |      TRUE/FALSE          |
| Modifiable | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.  |

## Examples

Run the following command in the `sys` tenant to enable the UTL_TCP system package:

```shell
obclient> ALTER SYSTEM SET ob_enable_utl_tcp=true;;
```

## References

`UTL_TCP` is a system package that communicates with an external server over the TCP/IP protocol. For more information, see [UTL_TCP](../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/27100.utl-tcp-oracle/100.utl-tcp-overview-oracle.md).
