# clog_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, transaction logs no longer use cache. This parameter is removed starting from V4.0.0. </p>
</main>

## Description

`clog_cache_priority` specifies the priority of transaction logs in cache.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Type             | Int       |
| Default value               | 1        |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
