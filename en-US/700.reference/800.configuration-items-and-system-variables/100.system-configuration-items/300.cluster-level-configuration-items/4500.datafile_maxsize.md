# datafile_maxsize

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter was introduced in OceanBase Database V3.1.5. </p>
</main>

## Description

* In shared-nothing (SN) mode, the `datafile_maxsize` parameter specifies the maximum size of space for automatic disk file expansion.

* In shared storage (SS) mode, the value of the `datafile_maxsize` parameter is meaningless and can be modified, but the modification will not take effect.

## Attributes

| Parameter | Description |
| --- | --- |
| Type | Capacity |
| Default value | 0 |
| Value range | [0M, +∞) |
| Whether to take effect after an OBServer node is restarted | No |

## Example

In SN mode, set the maximum size of space for automatic disk file expansion to 10 GB.

```shell
obclient> ALTER SYSTEM SET datafile_maxsize = '10G';
```
