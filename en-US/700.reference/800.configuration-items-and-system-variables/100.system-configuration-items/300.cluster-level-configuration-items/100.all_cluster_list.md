# all_cluster_list

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Due to the optimization of cluster configurations in V2.x, this parameter is removed starting from V2.2.50. </p>
</main>

## Description

`all_cluster_list` specifies the list of servers that access the same `config_url`.

## Attributes

|      **Attribute**      | **Description** |
|------------------|--------|
| Type             | String    |
| Default value               | NULL     |
| Value range             | NULL   |
| Effective upon OBServer node restart | No      |
