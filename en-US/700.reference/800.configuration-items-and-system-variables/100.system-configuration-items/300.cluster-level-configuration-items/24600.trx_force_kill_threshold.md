# trx_force_kill_threshold

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.x, the corresponding feature is no longer available, and this parameter is removed starting with V4.0.0. </p>
</main>

## Description

`trx_force_kill_threshold` specifies the maximum waiting time for a transaction to be killed when it is frozen or the primary node is switched.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time         |
| Default value              | 100ms        |
| Value range             | \[1ms, 10s\] |
| Effective upon OBServer node restart | No            |
