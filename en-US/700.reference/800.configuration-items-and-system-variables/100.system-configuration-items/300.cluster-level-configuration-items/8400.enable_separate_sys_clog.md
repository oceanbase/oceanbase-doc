# enable_separate_sys_clog

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is removed starting with V4.0.0 because the corresponding feature has never been enabled. </p>
</main>

## Description

`enable_separate_sys_clog` specifies whether to store system transaction logs separately from user transaction logs.

## Attributes

|      **Attribute**    |       **Description**  |
|------------------|-----------------|
| Type             | Bool      |
| Default value               | False     |
| Value range             | <ul><li>True: store system transaction logs separately from user transaction logs.</li><li>False: do not store system transaction logs separately from user transaction logs.</li></ul> |
| Effective upon OBServer node restart    | No     |
