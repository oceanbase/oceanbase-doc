# wait_leader_batch_count

<main id="notice" type='explain'>
<h4>Note</h4>
<p>After V4.x is upgraded to a standalone log stream architecture, the leader switch is controlled by a single log stream. This parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`wait_leader_batch_count` specifies the maximum number of partitions that RootService sends a leader switch command for each time.

## Attributes

|      **Attribute**      |    **Description**     |
|------------------|---------------|
| Parameter type             | Int            |
| Default value              | 1024          |
| Value range             | \[128, 5000\] |
| Effective upon OBServer node restart | No             |
