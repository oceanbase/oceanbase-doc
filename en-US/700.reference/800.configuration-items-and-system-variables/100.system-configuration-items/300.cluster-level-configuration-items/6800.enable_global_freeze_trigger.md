# enable_global_freeze_trigger

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x supports tenant-level freezing, this parameter is no longer applicable and was removed starting with V4.0.0.  </p>
</main>

## Description

`enable_global_freeze_trigger` specifies whether to enable automatic triggering of global freezing.

## Attributes

|      **Attribute**      |    **Description**                                 |
|------------------|-----------------------------------------------|
| Type             | Boolean                                          |
| Default value              | False                                           |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>    |
| Effective upon OBServer node restart | No                                        |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>  This parameter remains at its default value. We recommend that you do not modify it.  </p>
</main>
