# enable_auto_refresh_location_cache

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, this parameter is no longer available starting with V4.0.0. </p>
</main>

## Description

`enable_auto_refresh_location_cache` specifies whether to enable the automatic refresh of location cache information.

## Attributes

|      **Attribute**      |                                                 **Description**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| Parameter type             | Bool                                                                                                   |
| Default value              | True                                                                                                   |
| Value range             | </li><li> True   </li><li> False    |
| Effective upon OBServer node restart | No                                                                                                      |
