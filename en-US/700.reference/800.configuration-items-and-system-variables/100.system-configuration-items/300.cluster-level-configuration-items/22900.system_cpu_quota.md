# system_cpu_quota

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`system_cpu_quota` specifies the CPU quota for the system tenant.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Double    |
| Default value              | 10        |
| Value range             | \[0, 16\] |
| Effective upon OBServer node restart | No         |
