# election_cpu_quota

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the number of threads for the election task varies with the number of log streams. Only one thread is needed, so you do not need to configure the CPU quota. This parameter is removed starting with V4.0.0. </p>
</main>

## Description

`election_cpu_quota` specifies the CPU quota for background tasks related to replica election.

## Attributes

|      **Attribute**     |  **Description**   |
|-------------------|-------------|
| Type            | Double    |
| Default value              | 3         |
| Value range            | [0, 10] |
| Effective upon OBServer node restart | No         |
