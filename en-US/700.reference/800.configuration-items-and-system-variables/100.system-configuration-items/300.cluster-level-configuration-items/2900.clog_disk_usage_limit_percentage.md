# clog_disk_usage_limit_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>Since V4.x, log disk space management is tenant-level, this parameter is no longer available and was removed starting with V4.0.0. </li>
<li>In V4.x, use the tenant-level parameter <code>log_disk_utilization_limit_threshold</code> to control the write stop threshold for log disk space. For more information about the <code>log_disk_utilization_limit_threshold</code> parameter, see <a href="../400.tenant-level-configuration-items/4600.log_disk_utilization_limit_threshold.md">log_disk_utilization_limit_threshold</a>. </li></ul>
</main>

## Description

`clog_disk_usage_limit_percentage` specifies the maximum percentage of available disk space for transaction logs.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Parameter type             | Int          |
| Default value              | 95          |
| Value range             | \[80, 100\] |
| Effective upon OBServer node restart | No           |

## Considerations

**When the disk space used by transaction logs reaches the value specified by this parameter, the disk will stop writing and will no longer receive logs.**
