# sys_bkgd_io_low_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x supports tenant-level I/O isolation, this parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`sys_bkgd_io_low_percentage` specifies the minimum percentage of system background I/O.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value              | 0          |
| Value range             | \[0, 100\] |
| Effective upon OBServer node restart | No          |

## Considerations

If the value of `sys_bkgd_io_low_percentage` is 0, the system automatically configures the ratio based on the environment.
