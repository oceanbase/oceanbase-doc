# system_memory

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with OceanBase Database V1.4. </p>
</main>

## Description

`system_memory` specifies the memory capacity reserved for the tenant whose ID is `500`.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The memory reserved for the system cannot be used by regular tenants. </p>
  </main>

## Privilege requirements

* Query the parameter:

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type             | Capacity      |
| Default value               | 0M, which indicates that the system automatically adjusts the memory usage strategy based on the current memory situation.   |
| Value range             | [0M, +∞) |
| Modifiable                    | Yes. You can execute the `ALTER SYSTEM SET` statement to modify this parameter.         |
| Effective upon OBServer node restart    | No. The parameter takes effect immediately after it is set.     |

## Examples

Set the memory capacity reserved for the tenant whose ID is `500` to 0M.

```shell
obclient> ALTER SYSTEM SET system_memory = '0M';
```
