# system_memory

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database V1.4. </p>
</main>

## Description

`system_memory` specifies the memory capacity reserved for the tenant whose ID is `500`.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The memory reserved for the system cannot be used by regular tenants. </p>
  </main>

## Permissions

* To query this parameter:

  You can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view as the `sys` tenant or any user tenant.

* To modify this parameter:

  You can modify this parameter only as the `sys` tenant.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type             | Capacity      |
| Default value               | 0M, which indicates that the system automatically adjusts the memory usage strategy based on the current memory situation.   |
| Value range             | [0M, +∞) |
| Modifiability           | Modifiable by using the `ALTER SYSTEM SET` statement. |
| Effective only after OBServer restart | No, it takes effect immediately after the setting. |

## Examples

Set the memory capacity reserved for the tenant whose ID is `500` to 0M.

```shell
obclient> ALTER SYSTEM SET system_memory = '0M';
```
