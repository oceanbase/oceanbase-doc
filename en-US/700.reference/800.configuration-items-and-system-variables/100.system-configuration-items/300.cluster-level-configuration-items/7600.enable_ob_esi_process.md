# enable_ob_esi_process

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architectural optimization of the physical backup and restore feature in V4.x, the functionality corresponding to this parameter is no longer supported in V4.x and has been removed starting from V4.0.0. </p>
</main>

## Description

`enable_ob_esi_process` specifies whether to enable the obesi (external storage interface) process.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type |  Bool |
| Default value | False |
| Value range | <li>True: enable<li>False: disable |
| Effective upon OBServer node restart | No |
