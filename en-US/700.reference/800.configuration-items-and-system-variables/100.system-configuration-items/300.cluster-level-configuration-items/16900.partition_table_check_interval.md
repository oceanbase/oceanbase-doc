# partition_table_check_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports partition replicas, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`partition_table_check_interval` specifies the time interval for OBServer to remove non-existent replicas from a partition table.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time         |
| Default value              | 30m, indicating 30 minutes |
| Value range             | \[1m, +∞)    |
| Effective upon OBServer node restart | No           |
