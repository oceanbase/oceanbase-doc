# partition_table_check_interval

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer has the concept of partition replicas, this parameter is no longer applicable and was removed starting with V4.0.0. </p>
</main>

## Description

`partition_table_check_interval` specifies the interval at which OBServer nodes remove non-existent replicas from partitioned tables.

## Attributes

|      **Attribute**      |    **Description**    |
|------------------|--------------|
| Parameter type             | Time         |
| Default value              | 30m, which means 30 minutes |
| Value range             | \[1m, +∞)    |
| Effective upon OBServer node restart | No            |
