# enable_smooth_leader_switch

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is removed starting with V4.0.0 because V4.x no longer supports partition leader switching. </p>
</main>

## Description

`enable_smooth_leader_switch` specifies whether to enable the smooth leader switching feature.

## Attributes

|      **Attribute**      |                  **Description**                                 |
|------------------|------------------------------------------------------------|
| Type             | Bool                                                |
| Default value              | True                                                  |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>    |
| Effective upon OBServer node restart | No                                               |
