# enable_smooth_leader_switch

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x no longer supports partition leader switching, this parameter is removed starting from V4.0.0. </p>
</main>

## Description

`enable_smooth_leader_switch` is the switch for the smooth leader switching feature.

## Attributes

|      **Attribute**      |                  **Description**                                 |
|------------------|------------------------------------------------------------|
| Parameter type             | Bool                                                |
| Default value              | True                                                  |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>    |
| Effective upon OBServer node restart | No                                               |
