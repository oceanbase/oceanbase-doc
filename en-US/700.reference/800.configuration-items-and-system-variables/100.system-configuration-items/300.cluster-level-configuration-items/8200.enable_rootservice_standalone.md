# enable_rootservice_standalone

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the optimized storage architecture in V4.x, the system tenant now stores only cluster private data and no longer user tenant data. Therefore, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`enable_rootservice_standalone` specifies whether to allow the system tenant and RootService to exclusively occupy an OBServer node.

## Attributes

|      **Attribute**    |       **Description**      |
|------------------|---------------------|
| Parameter type             | Bool                                                                                                  |
| Default value               | False                                                                                                  |
| Value range             | <ul><li>True: enabled </li><li>False: disabled </li></ul>   |
| Effective upon OBServer node restart | No                                                                                                      |
