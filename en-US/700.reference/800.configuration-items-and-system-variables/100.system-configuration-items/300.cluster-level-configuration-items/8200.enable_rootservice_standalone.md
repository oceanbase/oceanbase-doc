# enable_rootservice_standalone

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the optimized storage architecture in V4.x, the system tenant now only stores cluster private data and does not store user tenant data. This parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`enable_rootservice_standalone` specifies whether to enable the system tenant and RootService to exclusively use the OBServer node.

## Attributes

|      **Attribute**    |       **Description**      |
|------------------|---------------------|
| Parameter type             | Boolean                                                                                                  |
| Default value               | False                                                                                                  |
| Value range             | <ul><li>True: Enabled </li><li>False: Disabled </li></ul>   |
| Effective upon OBServer node restart | No.                                                                                                      |
