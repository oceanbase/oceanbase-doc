# index_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade of OceanBase Database V4.x, this parameter is no longer applicable and has been deprecated since OceanBase Database V4.0.0. </p>
</main>

`index_cache_priority` specifies the priority of the index cache in the cache system.

| **Attribute** | **Description** |
|------------------|----------|
| Type | Integer |
| Default value | 10 |
| Value range | \[1, +∞) |
| Effective upon OBServer node restart | No |
