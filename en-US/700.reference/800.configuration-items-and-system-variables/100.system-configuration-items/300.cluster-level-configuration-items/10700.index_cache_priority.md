# index_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the architecture has been upgraded. This parameter is no longer applicable and has been removed starting from V4.0.0. </p>
</main>

## Description

`index_cache_priority` specifies the priority of an index in the cache system.

## Attributes

|      **Attribute**      |  **Description**  |
|------------------|----------|
| Parameter type             | Int       |
| Default value              | 10       |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No        |
