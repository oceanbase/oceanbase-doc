# balance_blacklist_failure_threshold

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.x, the storage architecture has been upgraded, and this parameter is no longer applicable. It has been removed starting from V4.0.0. </p>
</main>

## Description

`balance_blacklist_failure_threshold` specifies the threshold for the number of consecutive failures of background tasks such as replica migration. If the number of consecutive failures exceeds the threshold, the tasks are added to the blacklist.

## Attributes

|      **Attribute**      |   **Description**    |
|------------------|-------------|
| Type             | Int          |
| Default value              | 5           |
| Value range             | \[0, 1000\] |
| Effective upon OBServer node restart | No           |
