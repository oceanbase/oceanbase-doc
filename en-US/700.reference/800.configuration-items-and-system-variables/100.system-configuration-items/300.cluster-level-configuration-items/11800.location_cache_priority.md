# location_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to the architecture upgrade in V4.x, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`location_cache_priority` specifies the priority of the location cache in the system cache service.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Int        |
| Default value              | 1000      |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No         |
