# location_cache_priority

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x has undergone a major architecture change, this parameter is no longer supported. It was removed in V4.0.0. </p>
</main>

The `location_cache_priority` parameter specifies the priority of location cache in the system cache service.

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Type             | Int        |
| Default value              | 1000      |
| Value range             | \[1, +∞) |
| Effective upon OBServer node restart | No         |
