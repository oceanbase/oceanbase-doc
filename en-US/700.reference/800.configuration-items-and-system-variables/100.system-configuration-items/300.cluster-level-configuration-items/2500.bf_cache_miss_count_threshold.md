# bf_cache_miss_count_threshold

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting with V1.4. </p>
</main>

## Description

`bf_cache_miss_count_threshold` specifies the threshold for triggering BloomFilter Cache. When the number of macroblock misses reaches this threshold, a BloomFilter cache is created.

## Privilege requirements

* Query the parameter

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|      **Attribute**    |  **Description**  |
|------------------|------------|
| Type             | Int       |
| Default value               | 100      |
| Value range             | [0, +∞) <br> When the value is 0, BloomFilter cache creation is disabled. |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.    |
| Effective upon OBServer node restart | No. The setting takes effect immediately.      |

## Examples

Create a BloomFilter cache when the number of macroblock misses reaches 100.

```shell
obclient> ALTER SYSTEM SET bf_cache_miss_count_threshold=100;
```
