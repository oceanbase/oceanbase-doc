# row_purge_thread_count

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.0.0, this parameter is removed because the corresponding feature has never been enabled. </p>
</main>

## Description

`row_purge_thread_count` specifies the maximum number of worker threads for in-memory row data compaction.

## Attributes

|      **Attribute**      |  **Description**   |
|------------------|-----------|
| Parameter type             | Int        |
| Default value              | 4         |
| Value range             | \[1, 64\] |
| Effective upon OBServer node restart | No         |
