# wait_leader_batch_count

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter is no longer available starting with V4.0.0. This is because V4.x is upgraded to a single log stream architecture, where the leader switch is controlled by a single log stream. </p>
</main>

## Description

`wait_leader_batch_count` specifies the maximum number of partitions that RootService sends a leader switch command for each batch.

## Attributes

|      **Attribute**      |    **Description**     |
|------------------|---------------|
| Type             | Int            |
| Default value              | 1024          |
| Value range             | \[128, 5000\] |
| Effective upon OBServer node restart | No             |
