# backup_backup_dest

<main id="notice" type='explain'>
<h4>Note</h4>
<p>OceanBase Database V4.x does not support second backup (or backup of the backup). This parameter has been deprecated since OceanBase Database V4.0.0. </p>
</main>

`backup_backup_dest` specifies the destination for second backup.

| Attribute | Description |
|------------------|-------|
| Type | String |
| Default value | Empty string |
| Value range | N/A |
| Effective upon OBServer node restart | No |
