# sys_bkgd_io_high_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Since V4.x implements tenant-level I/O isolation, this parameter is no longer applicable and was removed starting from V4.0.0. </p>
</main>

## Description

`sys_bkgd_io_high_percentage` specifies the maximum percentage of system background I/O.

## Attributes

|      **Attribute**      |   **Description**   |
|------------------|------------|
| Parameter type             | Int         |
| Default value              | 90         |
| Value range             | \[1, 100\] |
| Effective upon OBServer node restart | No          |
