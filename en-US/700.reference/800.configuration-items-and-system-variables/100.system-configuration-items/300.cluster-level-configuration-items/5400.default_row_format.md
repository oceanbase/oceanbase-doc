# default_row_format

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V2.2.50, this parameter is available starting with V2.2.50. </p>
</main>

## Description

`default_row_format` specifies the default row format when you create a table in MySQL mode.

<main id="notice">
  <h4>Applicability</h4>
  <p>This parameter is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query the parameter

  You can execute the `SHOW PARAMETERS` statement or query the `GV$OB_PARAMETERS` view in the `sys` tenant and all user tenants to query this parameter.

* Modify the parameter

  Only the `sys` tenant can modify this parameter. User tenants cannot modify this parameter.

## Attributes

|   **Attribute**      |    **Description**   |
|-----------------|---------------|
| Type             | String                                 |
| Default value               | DYNAMIC                             |
| Value range             | <ul><li>REDUNDANT</li> <li>COMPACT</li><li>DYNAMIC</li><li>COMPRESSED</li></ul>   |
| Modifiable           | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter.|
| Effective upon OBServer node restart | No. The setting takes effect immediately.         |

## Examples

Set the default row format to DYNAMIC when you create a table in MySQL mode.

```shell
obclient> ALTER SYSTEM SET default_row_format= 'DYNAMIC';
```
