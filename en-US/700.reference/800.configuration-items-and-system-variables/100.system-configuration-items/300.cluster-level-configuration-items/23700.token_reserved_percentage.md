# token_reserved_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Due to changes in tenant CPU scheduling logic in V4.x, this parameter was removed starting from V4.2.0. </p>
</main>

## Description

`token_reserved_percentage` specifies the percentage of idle tokens to be reserved for each tenant.

## Attributes

|    **Attribute**      |   **Description** |
|------------------|------------|
| Type          | Double     |
| Default value            | 30         |
| Value range          | [0, 100] |
| Modifiable        | Yes. You can use the `ALTER SYSTEM SET` statement to modify the parameter. |
| Effective upon OBServer node restart | No. The setting takes effect immediately.          |

## Examples

Set the percentage of idle tokens to be reserved for each tenant to 30.

```shell
obclient> ALTER SYSTEM SET token_reserved_percentage=30;
```
