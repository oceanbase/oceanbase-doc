# Changes in parameters and system variables in V3.x and V4.x

Due to the architecture upgrade and reconstruction of OceanBase Database V4.x, many parameters or variables no longer take effect. Invalid parameters or variables are deleted or changed in OceanBase Database V4.x. For example, the `minor_freeze_times` parameter that specifies the threshold for triggering a major compaction has been deleted. The default values of some parameters are also changed. For example, we change the default value of the `freeze_trigger_percentage` parameter to 20% in OceanBase Database V4.x, to better support large transaction processing and prevent transactions from being affected by the freeze operation.

### Parameters with the effective scope changed

OceanBase Database is built based on a multitenant architecture. Most users create multiple tenants in a cluster and manage them by business type. To allow one tenant to represent one business unit, OceanBase Database V4.x splits cluster-level capabilities into tenant-level capabilities, such as tenant-level backup, minor compactions, and major compactions.
