# Overview of system variables

This topic describes the system variables of OceanBase Database based on the functions of the system variables.

## Global level

### Security-related

| Variable | Description |
|-------|---------|
| [validate_password_check_user_name](300.global-system-variable/13800.validate_password_check_user_name-global.md)    | Specifies whether to allow a user password to be the same as the username.               |
| [validate_password_length](300.global-system-variable/13900.validate_password_length-global.md)             | Specifies the minimum length of a user password.                     |
| [validate_password_mixed_case_count](300.global-system-variable/14000.validate_password_mixed_case_count-global.md)   | Specifies the minimum number of uppercase and lowercase letters in a user password. |
| [validate_password_number_count](300.global-system-variable/14100.validate_password_number_count-global.md)       | Specifies the minimum number of digits in a user password.                |
| [validate_password_policy](300.global-system-variable/14200.validate_password_policy-global.md) | Specifies the password check strategy.                       |
| [validate_password_special_char_count](300.global-system-variable/14300.validate_password_special_char_count-global.md) | Specifies the minimum number of special characters in a user password. |
| [ob_tcp_invited_nodes](300.global-system-variable/9700.ob_tcp_invited_nodes-global.md) | Specifies the IP address list of the tenant, which is used as the IP address whitelist. The IP address list can contain the following characters: the percent sign (%), the hyphen (-), and the IP address. Multiple IP addresses are separated with commas (,). The IP address list supports IP address list matching, mask matching, and fuzzy matching. |
| [default_password_lifetime](300.global-system-variable/2300.default_password_lifetime-global.md) | Specifies the password expiration period.             |
| [block_encryption_mode](300.global-system-variable/800.block_encryption_mode-global.md)           | Specifies the encryption algorithm used in the aes_encrypt and aes_decrypt functions.   |
| [sql_safe_updates](300.global-system-variable/11900.sql_safe_updates-global.md)                | Specifies whether to enable the SQL safe mode of MySQL. The default value is OFF. |
