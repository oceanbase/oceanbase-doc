# enable_sql_plan_monitor

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V4.2.4. </p>
</main>

## Description

`enable_sql_plan_monitor` specifies whether to record SQL statements in the current session to the SQL plan monitor.

## Privilege requirements

* Query variables

  `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode) to obtain the values of session system variables.

* Modify variables

  `sys` tenants and all user tenants can modify the values of session system variables in their own tenants.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type    |  Boolean                |
| Default value      |  False |
| Value range    |  <ul><li>False: The SQL statements in the current session are recorded to the SQL plan monitor only when any of the following conditions is met:<ul><li>The specific hint is used to enable monitoring. </li><li>The SQL execution time exceeds the preset threshold. </li><li>Parallel processing is used for SQL execution with a parallelism degree greater than 1. </li></ul> </li><li>True: All SQL statements executed in the current session are automatically recorded to the SQL plan monitor without any additional conditions. </li></ul>              |
| Scope    |  Session |
| Modifiable  |  Yes. You can execute the `SET` statement to modify the value. |

## Examples

Record all SQL statements in the current session to the SQL plan monitor.

```shell
obclient> SET  enable_sql_plan_monitor =True;
```
