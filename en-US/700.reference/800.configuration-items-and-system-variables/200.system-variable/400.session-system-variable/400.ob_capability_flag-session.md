# ob_capability_flag

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V1.4. </p>
</main>

## Description

`ob_capability_flag` specifies the capabilities provided by the OBServer node. It is used for capability negotiation with obproxy to inform obproxy about the supported and unsupported features of the current OBServer node.

## Attributes

| **Attribute** |              **Description**              |
|--------|----------------------------------|
| Type   | uint                             |
| Default value     | 0                                |
| Value range   | \[0,18446744073709551615\]       |
| Scope   | Session                          |
| Modifiable  | No. This variable can be specified when creating a tenant, but cannot be modified after the tenant is created. |
| Visibility   | No. This variable is not visible to any tenant.                               |

## Usage

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode). You can query the value of this variable from the `SYS.DBA_OB_SYS_VARIABLES` view (Oracle mode) or the `oceanbase.DBA_OB_SYS_VARIABLES` view (MySQL mode).
