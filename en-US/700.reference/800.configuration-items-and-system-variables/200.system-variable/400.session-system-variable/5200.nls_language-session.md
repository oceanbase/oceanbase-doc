# nls_language

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`nls_language` specifies the default language for internationalization support in the database. It is used for prompts, dates, month names, and as the default value for `NLS_SORT` and `NLS_DATE_LANGUAGE`.

<main id="notice" >
<h4>Applicability</h4>
<p>This variable is applicable only to OceanBase Database in Oracle mode. </p>
</main>

## Privilege requirements

* Query variables

  `sys` tenants and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) to view the values of session system variables.

* Modify variables

  This variable cannot be modified.
