# ob_hnsw_ef_search

The `ob_hnsw_ef_search` variable specifies the number of neighbor points to be retrieved from each graph layer by the HNSW algorithm when a vector index query is performed. The larger the variable value, the more neighbor points the algorithm will explore, which increases the chances of finding the true nearest neighbor and improves the search accuracy. However, the search time will also increase.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable was introduced in V4.3.3 and is supported only for MySQL tenants. </p>
</main>

| **Attribute**  | **Description**  |
|---------|---------|
| Type    | unit |
| Default value     | 64    |
| Value range    | [1,1000]    |
| Effective scope    | SESSION |
| Involved in serialization | Yes       |

**Examples**

```sql
SET ob_hnsw_ef_search = 50;
```
