# ob_trx_timeout

`ob_trx_timeout` specifies the transaction timeout period in microseconds.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The default value has been changed from <code>100000000</code> to <code>86400000000</code> since OceanBase Database V4.0.0.</p>
</main>

| **Attribute** | **Description** |
|---------|------------------------------------------------------------------------------------------------------------|
| Type | Integer |
| Default value | 86400000000 |
| Value range | NULL |
| Effective scope | <li>Global <li>Session |
| Involved in serialization | Yes |
