# ob_enable_blk_nestedloop_join

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In OceanBase Database V4.x, the corresponding logic is changed, and the corresponding feature is no longer available. This variable has been deprecated since OceanBase Database V4.0.0. </p>
</main>

## Description

`ob_enable_blk_nestedloop_join` specifies whether to enable Block Nested Loop (BNL) join.

## Attributes

| **Attribute** | **Description** |
|----------------|-------------------|
| Type | Boolean |
| Default value | 0 |
| Value range | </li><li>`0`: disable</li><li>`1`: enable</li></ul> |
| Effective scope | </li><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes. You can use the `SET` statement to modify the variable.                 |
| Plan generation affected | Yes |
