# ob_global_debug_sync

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V1.4. </p>
</main>

## Description

`ob_global_debug_sync` specifies the synchronization point for debugging. This variable affects all sessions.

## Attributes

| **Attribute** |   **Description**   |
|--------|------------|
| Type   | Varchar    |
| Default value    | Empty string       |
| Scope   | Session     |
| Visibility   | Not visible.       |

## Usage

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode). You can query the value of this variable by using the `SYS.DBA_OB_SYS_VARIABLES` view (Oracle mode) or the `oceanbase.DBA_OB_SYS_VARIABLES` view (MySQL mode).

This setting is effective only when the value of the [debug_sync_timeout](../../100.system-configuration-items/300.cluster-level-configuration-items/5100.debug_sync_timeout.md) parameter is not 0.
