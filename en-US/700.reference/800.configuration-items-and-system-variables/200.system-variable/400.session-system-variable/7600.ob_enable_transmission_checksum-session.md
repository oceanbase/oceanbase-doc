# ob_enable_transmission_checksum

`ob_enable_transmission_checksum` specifies whether to perform checksum comparison on data packets between OceanBase Database Proxy (ODP) and the OBServer node. The setting takes effect immediately.

| **Attribute** | **Description** |
|---------|--------------------------------------------------------------------------------------------------------------|
| Type | Boolean |
| Default value | 1 |
| Value range | <li> `0`: specifies not to perform checksum comparison.   <li> `1`: specifies to perform checksum comparison. |
|  Effective scope | <li>Global <li>Session |
| Involved in serialization | Yes |
