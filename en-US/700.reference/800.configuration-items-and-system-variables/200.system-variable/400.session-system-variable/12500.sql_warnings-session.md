# sql_warnings

`sql_warnings` specifies whether to generate an information string for single-row `INSERT` statements in the event of an alert.

| **Attribute** | **Description** |
|--------|-----------------------------------------------------------------------------------------------------------------------|
| Type | Boolean |
| Default value | OFF |
| Value range | <li> `ON`: specifies to generate an information string. <li> `OFF`: specifies not to generate an information string. |
|  Effective scope | <li>Global <li>Session |
