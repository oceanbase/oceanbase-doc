# ob_org_cluster_id

`ob_org_cluster_id` specifies the session-level ID of the OceanBase cluster. This value is persisted to the transaction log.

Generally, you do not need to set this variable. The default value is used when OceanBase Database generates clogs. OceanBase Migration Service (OMS) uses this variable for data filtering. For more information about OMS data filtering, see **Create a project to migrate data from a MySQL database to a MySQL tenant of OceanBase Database** in OMS documentation.

For example, the `cluster_id_black_list` parameter is set to `2147473648` in the obcdc component of OMS, and the `ob_org_cluster_id` variable is set to `2147473648` for data writes to the OBServer node. In this case, obcdc will filter out the received data whose `cluster_id` is `2147473648`.

| **Attribute** | **Description** |
|---------|-------------------|
| Type | Integer |
| Default value | 0 |
| Value range | \[0, 4294967295\] |
| Effective scope | Session |
| Involved in serialization | Yes |
