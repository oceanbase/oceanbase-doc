# auto_increment_increment

`auto_increment_increment` specifies the auto-increment step size. It is only used for MySQL client login.

| **Attribute** | **Description** |
|---------|------------------------------------------------------------------------------------------------------------|
| Type | UINT |
| Default value | 1 |
| Value range | \[1, 65535\] |
| Effective scope | <li>Global <li>Session |
| Involved in serialization | Yes |
