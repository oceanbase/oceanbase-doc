# explicit_defaults_for_timestamp

## Description

`explicit_defaults_for_timestamp` specifies whether to enable non-standard behaviors for processing default values and NULL values in TIMESTAMP columns.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is applicable to only OceanBase Database in MySQL mode. </p>
</main>

## Attributes

| **Attribute** | **Description** |
|----------|------------------------------------------------------------------------------------------------------------|
| Type | Boolean |
| Default value | ON |
| Value range | <li> OFF <li> ON |
| Effective scope | <li>Global <li>Session |
| Plan generation affected | Yes |
