# ob_proxy_partition_hit

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`ob_proxy_partition_hit` specifies whether to send SQL statements to the OBServer node where the data of the requested partitions is stored.

## Attributes

| **Attribute** |                                               **Description**                                                |
|--------|-----------------------------------------------------------------------------------------------------|
| Type   | Bool             |
| Default value    | 1                |
| Value range   | <ul><li> 1: Yes   </li><li> 0: No </li></ul>    |
| Scope   | Session          |
| Modifiable  | No. This variable can be specified only when you create a tenant and cannot be modified by using an SQL statement after the tenant is created.                                                                    |

## Usage notes

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode). You can query the value of this variable from the `SYS.DBA_OB_SYS_VARIABLES` view (Oracle mode) or the `oceanbase.DBA_OB_SYS_VARIABLES` view (MySQL mode).

Alternatively, you can query the value of this variable by using the `SELECT` statement:

```shell
obclient> SELECT @@ob_proxy_partition_hit;
```

The query result is as follows:

```shell
+--------------------------+
| @@ob_proxy_partition_hit |
+--------------------------+
|                        1 |
+--------------------------+
1 row in set
```
