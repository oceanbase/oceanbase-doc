# ob_proxy_partition_hit

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with in V2.2.77. </p>
</main>

## Description

`ob_proxy_partition_hit` specifies whether to enable OceanBase Database Proxy (ODP) to send the data requested by SQL statements to the OBServer node where the primary partition of the data is located.

## Attributes

| **Attribute** | **Description** |
|--------|-----------------------------------------------------------------------------------------------------|
| Parameter type   | Bool             |
| Default value | 1 |
| Value range   | <ul><li> 1: Yes   </li><li> 0: No </li></ul>    |
| Effective scope | Session |
| Modifiable | You can set the variable when you create a tenant. After the tenant is created, you cannot modify the variable by executing SQL statements. |

## Considerations

Querying the value of this variable using the `SHOW VARIABLES` statement or views is not supported. Users can use a `SELECT` statement to return the value of this variable:

```shell
obclient> SELECT @@ob_proxy_partition_hit;
```

The result is as follows:

```shell
+--------------------------+
| @@ob_proxy_partition_hit |
+--------------------------+
|                        1 |
+--------------------------+
1 row in set
```
