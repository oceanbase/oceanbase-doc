# ob_ivf_nprobes

The `ob_ivf_nprobes` parameter specifies the number of nearest cluster centers to search during vector index query. This parameter affects the performance and recall rate of IVF queries: the larger the value, the higher the recall rate, but the longer the search time.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in V4.3.5 BP1 and applies only to MySQL tenants. </p>
</main>

| **Attribute**  | **Description**  |
|---------|---------|
| Parameter type    | int |
| Default value     | 8    |
| Value range    | [1,65536]    |
| Scope    | SESSION |
| Serialized | Yes       |

**Examples**

```sql
SET ob_ivf_nprobes = 10;
```
