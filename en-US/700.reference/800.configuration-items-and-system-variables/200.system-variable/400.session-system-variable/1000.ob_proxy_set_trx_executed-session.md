# ob_proxy_set_trx_executed

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with in V2.2.77. </p>
</main>

## Description

`ob_proxy_set_trx_executed` specifies whether to send `START TRANSACTION Syntax` to OBServer through OceanBase Database Proxy (ODP).

## Attributes

| **Attribute** | **Description** |
|--------|--------------------------------------------------------------------------------------------------------|
| Parameter type   | Bool                |
| Default value | 0 |
| Value range   | <ul><li> 0: No </li> <li> 1: Yes  </li></ul>  |
| Effective scope | Session |
| Modifiable | You can set the variable when you create a tenant. After the tenant is created, you cannot modify the variable by executing SQL statements. |

## Considerations

Querying the value of this variable using the `SHOW VARIABLES` statement or views is not supported. Users can use a `SELECT` statement to return the value of this variable:

```shell
obclient> SELECT @@ob_proxy_set_trx_executed;
```

The result is as follows:

```shell
+-----------------------------+
| @@ob_proxy_set_trx_executed |
+-----------------------------+
|                           0 |
+-----------------------------+
1 row in set
```
