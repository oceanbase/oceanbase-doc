# autocommit

`autocommit` specifies whether to automatically commit transactions.

| **Attribute** | **Description** |
|---------|------------------------------------------------------------------------------------------------------------|
| Type | Boolean |
| Default value | 1 |
| Value range | <li> `1`: specifies to automatically commit transactions. <li> `0`: specifies not to automatically commit transactions. |
| Effective scope | <li>Global <li>Session |
| Involved in serialization | Yes |
