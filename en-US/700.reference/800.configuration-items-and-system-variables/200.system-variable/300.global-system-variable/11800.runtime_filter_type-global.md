# runtime_filter_type

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V4.2.0. </p>
</main>

## Description

`runtime_filter_type` specifies the type of runtime filter at the tenant level.

## Privilege requirements

* Query variables

  * Global level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode) or the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode) to view the values of session system variables.

* Modify variables

  * Global level

    * `sys` tenants can directly modify the values of global system variables.

    * MySQL user tenants must have the `SUPER` or `ALTER SYSTEM` privilege to modify the values of global system variables.

    * Oracle user tenants must have the `ALTER SYSTEM` privilege to modify the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can directly modify the values of session system variables.

## Attributes

| Attribute | Description |
| --- | --- |
| Type | Varchar |
| Default value | BLOOM_FILTER,RANGE,IN |
| Value range | <ul><li>BLOOM_FILTER: specifies the Bloom filter as the runtime filter. The filter checks whether data is in the Bloom filter to filter data.  </li><li>RANGE: specifies the RANGE filter as the runtime filter. The filter stores the maximum and minimum values of the build table and checks whether data is in the range to filter data. </li><li>IN: specifies the IN filter as the runtime filter. The filter stores data in a hash table and checks whether data is in the hash table to filter data. </li><li>Empty string: disables the runtime filter. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>If the value is BLOOM_FILTER, RANGE, or IN, at least one of these values must be selected. </p></main> |
| Scope | <ul><li>Global  </li><li>Session </li></ul>|
| Modifiable | Yes. You can execute the `SET` statement to modify the value. |

## Examples

* Session level

  Set the runtime filter type to `range`, `bloom_filter`, or `in`.

  ```shell
  obclient> SET runtime_filter_type = 'range,in,bloom_filter';
  ```

  Disable the runtime filter. The statement is as follows:

  ```shell
  obclient> SET runtime_filter_type = '';
  ```

* Global level

  Set the runtime filter type to `range`.

  ```shell
  obclient> SET GLOBAL runtime_filter_type = 'range';
  ```
