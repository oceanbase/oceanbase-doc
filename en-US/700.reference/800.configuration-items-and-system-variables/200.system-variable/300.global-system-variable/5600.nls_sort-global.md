# nls_sort

## Description

The `nls_sort` variable specifies the sorting rule for string values.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You cannot modify this variable. </p>
  </main>

|  **Attribute**  |                                                   **Description**                                                   |
|----------|------------------------------------------------------------------------------------------------------------|
| Type | varchar                 |
| Default value | BINARY                  |
| Value range   | N/A                     |
| Effective scope | <li> Global   <li> Session    |
| Modifiable    | No  |
