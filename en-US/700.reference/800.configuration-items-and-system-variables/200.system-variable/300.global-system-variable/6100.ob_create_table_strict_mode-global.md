# ob_create_table_strict_mode

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>In V4.x, because there are no independent partitions, the system uses log streams as the carrier. Log streams record all change operations in the database, making the creation of partitions no longer require strict mode. This variable was removed starting with V4.0.0. For more information about the relationship between log streams and partitions, see <a href="../../../100.oceanbase-database-concepts/500.distributed-database-objects/300.data-partitions-and-replicas/200.logstream.md">Log streams</a>. </p>
</main>

## Description

`ob_create_table_strict_mode` is a dynamic variable used to set the strict mode for table creation.

## Attributes

| **Attribute** |    **Description**   |
|----------|---------------|
| Type   | Bool                         |
| Default value     | 0                |
| Value range   | <ul><li>1: Indicates that replicas are strictly established based on Locality. If any replica establishment fails, the table creation fails. </li><li>0: Indicates that at least one replica of each type is established, and the Paxos member group replicas reach a majority. </li></ul>     |
| Scope   | <ul><li>Global </li><li>Session </li></ul>  |
