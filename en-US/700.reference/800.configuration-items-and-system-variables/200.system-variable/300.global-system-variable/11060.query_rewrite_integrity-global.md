# query_rewrite_integrity

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V4.3.1. </p>
</main>

## Description

`query_rewrite_integrity` specifies the data consistency check level for query rewriting of materialized views.

## Privilege requirements

* Query variables

  * Global level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode) or the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode) to view the values of session system variables.

* Modify variables

  * Global level

    * `sys` tenants can directly modify the values of global system variables.

    * MySQL user tenants must have the `SUPER` or `ALTER SYSTEM` privilege to modify the values of global system variables.

    * Oracle user tenants must have the `ALTER SYSTEM` privilege to modify the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can directly modify the values of session system variables.

## Attributes

| **Attribute** |  **Description**    |
|----------|--------------|
| Parameter type   |   Enum                   |
| Default value     |   enforced                 |
| Value range   | [enforced, stale_tolerated]  <ul><li> enforced: Only real-time materialized views are used for query rewriting. The rewritten materialized view data is calculated online to ensure consistency with the original query results. </li><li>stale_tolerated: Non-real-time materialized views can be used for query rewriting. This may result in query results that differ from the original query. In this case, even if a real-time materialized view that can be calculated online is used for rewriting, it will not be calculated online to ensure consistency with the original query results. </li></ul>    |
| Scope | <ul><li>Global  </li><li>Session </li></ul>|
| Modifiable  | Yes. You can execute the `SET` statement to modify the value.|

## Usage

This variable is meaningful only when the value of the [query_rewrite_enabled](11050.query_rewrite_enabled-global.md) variable is not `false`.

## Examples

Set the query rewrite integrity level to `enforced`.

* Session level

  ```shell
  obclient> SET  query_rewrite_integrity= enforced;
  ```

* Global level

  ```shell
  obclient> SET GLOBAL  query_rewrite_integrity= enforced;
  ```
