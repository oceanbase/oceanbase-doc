# ob_enable_hash_group_by

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This feature is no longer available in V4.x due to system architecture optimization. This configuration item was removed starting from V4.0.0. </p>
</main>

## Description

`ob_enable_hash_group_by` specifies whether to enable the hash group by feature.

## Attributes

|  **Attribute**  |       **Description**       |
|------------|----------------------|
| Type     | Bool                 |
| Default value       | 1                    |
| Value range     | <ul><li>0: disabled. </li><li>1: enabled. </li></ul>|
| Scope     | <ul><li>Global </li><li>Session </li></ul>   |
