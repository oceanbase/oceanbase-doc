# query_cache_type

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`query_cache_type` specifies the query cache type.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is not effective at present. </p>
</main>

## Attributes

| **Attribute**  |                           **Description**                             |
|-----------|----------------------------------------------------------------|
| Type   | Varchar                                                     |
| Default value     | OFF                                                         |
| Value range   | <ul><li>OFF: do not cache or retrieve results. </li><li>ON: cache the results of all queries except `SELECT SQL_NO_CACHE ...` queries. </li><li>DEMAND: cache only the results of `SELECT SQL_CACHE ...` queries. </li></ul>    |
| Scope    | Global |
| Modifiable  | No. This variable can be specified only when you create a tenant. After a tenant is created, you cannot modify the value by executing an SQL statement. |
