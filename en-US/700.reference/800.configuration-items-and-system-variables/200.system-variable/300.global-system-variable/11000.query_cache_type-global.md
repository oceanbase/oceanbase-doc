# query_cache_type

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`query_cache_type` specifies the query cache type.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is not effective at present. </p>
</main>

## Attributes

| **Attribute**  |                           **Description**                             |
|-----------|----------------------------------------------------------------|
| Type   | Varchar                                                     |
| Default value     | OFF                                                         |
| Value range   | <ul><li>OFF: do not cache or retrieve results. </li><li>ON: cache all query results except for those of `SELECT SQL_NO_CACHE ...` queries. </li><li>DEMAND: cache only the results of `SELECT SQL_CACHE ...` queries. </li></ul>    |
| Scope    | Global |
| Modifiable  | No. This variable can be specified only when you create a tenant. You cannot modify it by executing an SQL statement after the tenant is created. |
