# init_connect

## Description

The `init_connect` variable specifies the string that the server executes for each client connection. The string consists of one or more SQL statements separated by semicolons.

## Privilege requirements

* Query variables

  Users of the `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or view the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (in Oracle mode) or the `information_schema.GLOBAL_VARIABLES` view (in MySQL mode) to query the values of global system variables.

* Modify variables

  * `sys` tenant

    Users of the `sys` tenant can directly modify the values of global system variables.

  * MySQL user tenant

    Users of a MySQL user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the values of global system variables.

  * V4.x

    Oracle user tenants must have the `ALTER SYSTEM` privilege to modify the values of global system variables, starting from V4.2.0.
