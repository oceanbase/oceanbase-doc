# nls_calendar

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`nls_calendar` specifies the calendar system used by the database.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to OceanBase Database in Oracle mode. </p>
</main>

## Privilege requirements

* Query variables

  * Global level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode) to obtain the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) to obtain the values of session system variables.

* Modify variables

  You cannot modify this variable.
