# debug_sync

## Description

The debug_sync variable specifies the synchronization point when debugging, which is compatible with MySQL.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This variable is effective only when the value of debug_sync_timeout is not 0. </p>
  </main>

## Attributes

| **Attribute** |   **Description**   |
|--------|------------|
| Type   | varchar    |
| Default value    | An empty string       |
| Value range   | None          |
| Effective scope   | SESSION    |
| Visibility   | No, not visible to any tenant |
