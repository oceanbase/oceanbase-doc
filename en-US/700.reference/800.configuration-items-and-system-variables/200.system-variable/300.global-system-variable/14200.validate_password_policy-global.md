# validate_password_policy

## Description

The validate_password_policy variable specifies the password check policy.

## Required privileges

* Query variables

  The `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or view the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` (Oracle mode) or `information_schema.GLOBAL_VARIABLES` (MySQL mode) view to query the value of a global system variable.

* Modify variables

  * The `sys` tenant can directly modify the value of a global system variable.

  * MySQL user tenants must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * In V4.x, Oracle user tenants must have the `ALTER SYSTEM` privilege to modify the value of a global system variable starting from V4.2.0.

## Attributes

| **Attribute**  |**Description**|
|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Type    | enum |
| Default value     | LOW  |
| Value range    | <li> LOW: specifies to check only common password rules.   <li> MEDIUM: specifies to check password length, the number of uppercase letters, the number of lowercase letters, the number of digits, the number of special characters, and whether the username and password are the same.    |
| Scope    | GLOBAL                                                                                  |
| Modifiable  | Yes. You can execute the `SET` statement to modify the value. |
