# ob_enable_aggregation_pushdown

The ob_enable_aggregation_pushdown variable specifies whether to allow aggregation operations to be pushed down.

|  **Attribute**  |                                                   **Description**                                                   |
|----------|------------------------------------------------------------------------------------------------------------|
| Type     | bool                    |
| Default value      | 1                       |
| Value range     | <li> 0: disabled   <li> 1: enabled        |
| Effective scope     | <li> GLOBAL   <li> SESSION    |
| Modifiable | Yes, you can execute the `SET` statement to modify this variable. |
