# system_time_zone

The `system_time_zone` variable specifies the system time zone of the server.

| **Attribute**  |                                                              **Description**                                                              |
|---------|----------------------------------------------------------------------------------------------------------------------------------|
| Data type    | varchar                                       |
| Default value | CST                                           |
| Valid values | <ul><li> Numeric values in the range of \[-12:59,+13:00\]. </li> <li> Time zones such as CDT (Central Daylight Time) and CST (China Standard Time). </li> </ul>     |
| Scope       | Global                                        |
| Modifiable  | This variable can be specified when a tenant is created. After a tenant is created, you cannot modify this variable by using an SQL statement. For more information, see [Set variables](../../../200.system-management/200.configuration-management/300.set-variables.md).                          |
