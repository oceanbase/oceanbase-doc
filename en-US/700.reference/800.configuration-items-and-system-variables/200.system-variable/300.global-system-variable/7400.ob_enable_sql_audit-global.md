# ob_enable_sql_audit

`ob_enable_sql_audit` specifies whether to enable SQL audit for the current tenant.

| **Attribute**  |                                                      **Description**                                                      |
|---------|------------------------------------------------------------------------------------------------------------------|
| Type    | bool                          |
| Default value     | true                          |
| Valid values    | <li> true: Enable SQL Audit.   <li> false: Disable SQL Audit.    |
| Scope    | GLOBAL                        |
| Modifiable  | Yes. You can execute the `SET` statement to modify this variable. |

If enable_sql_audit is set to false, SQL Audit is disabled in all tenants.
