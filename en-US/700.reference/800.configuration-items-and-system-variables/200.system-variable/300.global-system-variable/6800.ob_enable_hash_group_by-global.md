# ob_enable_hash_group_by

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>Due to the system architecture optimization in V4.x, this feature is no longer supported. This parameter has been removed starting from V4.0.0. </p>
</main>

## Description

`ob_enable_hash_group_by` specifies whether to enable the hash group by feature.

## Attributes

|  **Attribute**  |       **Description**       |
|------------|----------------------|
| Parameter type     | Bool                 |
| Default value       | 1                    |
| Value range     | <ul><li>0: Disabled. </li><li>1: Enabled. </li></ul>|
| Scope     | <ul><li>Global </li><li>Session </li></ul>   |
