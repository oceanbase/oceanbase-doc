# ob_enable_hash_group_by

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This configuration item is removed starting with V4.0.0. This is because the system architecture is optimized in V4.x. </p>
</main>

## Description

`ob_enable_hash_group_by` specifies whether to enable the hash group by path.

## Attributes

|  **Attribute**  |       **Description**       |
|------------|----------------------|
| Parameter type     | Boolean                 |
| Default value       | 1                    |
| Value range     | <ul><li>0: Disabled. </li><li>1: Enabled. </li></ul>|
| Scope     | <ul><li>Global </li><li>Session </li></ul>   |
