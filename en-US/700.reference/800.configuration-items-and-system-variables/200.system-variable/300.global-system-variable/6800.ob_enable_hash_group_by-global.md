# ob_enable_hash_group_by

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable was deprecated in V4.0.0. </p>
</main>

The `ob_enable_hash_group_by` variable specifies whether to enable the hash group by path.

|  **Attribute**  |                                                   **Description**                                                   |
|----------|------------------------------------------------------------------------------------------------------------|
| Type     | bool                                                                                                       |
| Default value      | 1                                                                                                          |
| Valid values     | </li><li> 0: disabled   </li><li> 1: enabled        |
| Scope     | </li><li> GLOBAL   </li><li> SESSION    |
