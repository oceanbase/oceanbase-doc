# port

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V4.2.5 BP1. </p>
</main>

## Description

`port` specifies the port number for the server to listen for TCP/IP connections when deploying an OBServer node.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query variables

  `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the values of global system variables.

* Modify variables

  You cannot modify this variable.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type    |  Int             |
| Default value      |  3306  |
| Scope    |  Global  |
| Modifiable  | No. This variable can only be specified when deploying an OBServer node and cannot be modified by using the `SET` statement. |

## Examples

Query the port number for the server to listen for TCP/IP connections.

```shell
obclient> SHOW VARIABLES LIKE 'port';
```

The query result is as follows:

```shell
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| port          | 2881  |
+---------------+-------+
1 row in set (0.003 sec)
```
