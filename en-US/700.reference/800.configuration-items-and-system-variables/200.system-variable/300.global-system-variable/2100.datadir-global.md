# datadir

<main id="notice" type='explain'>

## Description

`datadir` specifies the local disk path for data storage.

## Privilege requirements

The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode) and the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the value of Global system variables.
