# ob_plan_cache_evict_low_percentage

ob_plan_cache_evict_low_percentage specifies the percentage of the absolute memory limit at which plan cache eviction is stopped.

| **Attribute**  |   **Description**   |
|---------|------------|
| Type    | int        |
| Default value     | 50         |
| Valid range    | \[0, 100\] |
| Scope    | GLOBAL     |
| Modifiable  | Yes. You can execute the `SET` statement to modify this variable. |

The memory size (low water mark) at which plan cache eviction is stopped = absolute memory limit \* ob_plan_cache_evict_low_percentage/100. For more information about the absolute memory limit, see [ob_plan_cache_percentage](../300.global-system-variable/8400.ob_plan_cache_percentage-global.md).
