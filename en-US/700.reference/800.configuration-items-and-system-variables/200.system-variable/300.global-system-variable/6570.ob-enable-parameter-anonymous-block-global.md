# ob_enable_parameter_anonymous_block

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V4.2.5.</p>
</main>

## Overview

`ob_enable_parameter_anonymous_block` specifies whether to enable the global anonymous block parameterization feature.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to OceanBase Database in Oracle-compatible mode.</p>
</main>

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (in Oracle-compatible mode) to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (in Oracle-compatible mode) to view the values of session system variables.

* Modify variables

  * Set the variable at the global level

    * The `sys` tenant can directly modify the values of global system variables.

    * Oracle-compatible user tenants must have the `ALTER SYSTEM` privilege to modify the values of global system variables.

  * Set the variable at the session level

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| --------- | --------------- |
| Type | bool |
| Default value | ON |
| Value range | <ul><li>ON: enabled</li><li>OFF: disabled</li></ul> |
| Applicable scope | <ul><li>Global  </li><li>Session </li></ul> |
| Modifiable | Yes. You can modify it by using the `SET` statement. |

## Usage instructions

You can use the `ob_enable_parameter_anonymous_block` system variable to enable or disable anonymous block parameterization.

## Configuration example

* Set the variable at the session level

  ```shell
  obclient> SET ob_enable_parameter_anonymous_block = off;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL ob_enable_parameter_anonymous_block = on;
  ```
