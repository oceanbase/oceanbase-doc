# nls_territory

## Description

The `nls_territory` variable specifies the current territory in the database, which is used in conjunction with the nls_language variable.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You cannot modify this variable. </p>
  </main>
