# nls_comp

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Starting from V2.2.77, this variable was introduced. </p>
</main>

## Description

`nls_comp` specifies the string value comparison rule.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to the Oracle mode of OceanBase Database. </p>
</main>

## Permissions

* Query variables

  * Global scope

    Tenants of the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (in Oracle mode) to query the values of global system variables.

  * Session scope

    Tenants of the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (in Oracle mode) to query the values of session system variables.

* Modify variables

  Tenants of the `sys` tenant and all user tenants cannot modify the values of global or session system variables of their own.

## Attribute description

| **Attribute**  | **Description**  |
|---------|---------|
| Parameter type    | Varchar |
| Default value      | BINARY |
| Effective scope    | <ul><li>GLOBAL</li><li>SESSION</li></ul> |
| Modifiability      | No, the variable is not supported. |
| Plan generation affected | Yes |
