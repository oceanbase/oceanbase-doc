# nls_comp

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable was introduced in V2.2.77. </p>
</main>

## Description

`nls_comp` specifies the string value comparison rule.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to the Oracle mode of OceanBase Database. </p>
</main>

## Permissions

* Query variables

  * Global scope

    Tenants, including the `sys` tenant, and users can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (in Oracle mode) to view the values of global system variables.

  * Session scope

    Tenants, including the `sys` tenant, and users can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (in Oracle mode) to view the values of session system variables.

* Modify variables

  Tenants, including the `sys` tenant and user tenants, cannot modify the values of global or session system variables in their own tenants.

## Attribute description

| **Attribute** | **Description** |
|---------|---------|
| Parameter type    | Varchar |
| Default value      | BINARY |

| Modifiable | No, this variable cannot be modified. |
