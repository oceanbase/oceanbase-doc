# transaction_isolation

The transaction_isolation variable specifies the isolation level of a transaction.

| **Attribute**  |                            **Description**                            |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Type    | varchar                                                      |
| Default value     | READ-COMMITTED                                               |
| Valid values    | <li> READ-COMMITTED   <li> REPEATABLE-READ   <li> SERIALIZABLE    |
| Effective scope    | <li> GLOBAL   <li> SESSION                                         |
| Modifiable    | Yes. You can modify this variable by using the `SET` statement. |
