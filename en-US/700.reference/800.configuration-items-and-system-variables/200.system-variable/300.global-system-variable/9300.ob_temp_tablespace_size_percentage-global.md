# ob_temp_tablespace_size_percentage

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is no longer in use. The temporary space is controlled by the data_disk_usage_limit_percentage variable. </p>
</main>

The ob_temp_tablespace_size_percentage variable specifies the percentage limit for the size of temporary tablespace on the disk of a tenant.

| **Attribute** |                                                   **Description**                                                   |
|--------|------------------------------------------------------------------------------------------------------------|
| Type   | int                     |
| Default value    | 0                       |
| Value range   | \[0, 100\]              |
| Effective scope   | <li> GLOBAL   <li> SESSION    |
