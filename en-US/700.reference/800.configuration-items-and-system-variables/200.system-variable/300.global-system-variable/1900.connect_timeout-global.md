# connect_timeout

`connect_timeout` specifies the connection timeout duration in seconds.

| **Attribute** | **Description** |
|--------|------------------------------------------------------------------------------------------------------------|
| Type | INT |
| Default value | 10 |
| Value range | \[2, 31536000\] |
| Applicable scope | Global |
