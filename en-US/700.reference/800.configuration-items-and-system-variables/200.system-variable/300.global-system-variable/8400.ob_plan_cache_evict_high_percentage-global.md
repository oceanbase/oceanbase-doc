# ob_plan_cache_evict_high_percentage

`ob_plan_cache_evict_high_percentage` specifies the percentage of the absolute value of the maximum memory usage to trigger plan cache eviction.

| **Attribute** | **Description** |
|---------|------------|
| Type | Integer |
| Default value | 90 |
| Value range | \[0, 100\] |
| Effective scope | Global |
| Involved in serialization | Yes |

Memory threshold that triggers plan cache eviction (upper threshold for plan cache eviction) = Maximum memory × `ob_plan_cache_evict_high_percentage`/100. For more information about the absolute value of the maximum memory usage for the plan cache, see [ob_plan_cache_percentage](../300.global-system-variable/8600.ob_plan_cache_percentage-global.md).
