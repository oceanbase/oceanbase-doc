# ob_proxy_global_variables_version

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`ob_proxy_global_variables_version` is used when obproxy communicates with an OBServer node. It specifies the latest version of global variables that an OBServer node returns to obproxy.

## Attributes

| **Attribute** |                                                 **Description**                                                  |
|--------|---------------------------------------------------------------------------------------------------------|
| Type   | Int                  |
| Default value    | 0                    |
| Value range   | \[0, INT64_MAX)      |
| Scope   | Session              |
| Modifiable  | No. This variable can be specified only when you create a tenant. You cannot modify it by executing an SQL statement after the tenant is created. |

## Usage notes

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) or the `information_schema.SESSION_VARIABLES` view (MySQL mode). You can query the value of this variable from the `SYS.DBA_OB_SYS_VARIABLES` view (Oracle mode) or the `oceanbase.DBA_OB_SYS_VARIABLES` view (MySQL mode).

Alternatively, you can execute the `SELECT` statement to obtain the latest version number of the global variables:

```shell
obclient> SELECT @@ob_proxy_global_variables_version;
```

The returned result is as follows:

```shell
+-------------------------------------+
| @@ob_proxy_global_variables_version |
+-------------------------------------+
|                                   0 |
+-------------------------------------+
1 row in set
```
