# ob_default_replica_num

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Deprecated as of V3.2.1. </p>
</main>

ob_default_replica_num specifies the default number of replicas for tables in a cluster.

| **Attribute** |                                                   **Description**                                                   |
|--------|------------------------------------------------------------------------------------------------------------|
| Type   | int                                                                                                        |
| Default value    | 1                                                                                                          |
| Valid values   | \[1, 7\]                                                                                                   |
| Effective scope   | </li><li> GLOBAL   </li><li> SESSION    |
| Status   | Deprecated                                                                                                        |
