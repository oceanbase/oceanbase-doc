# ob_default_replica_num

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is deprecated starting from V3.2.1 because the system architecture in V3.x has been optimized. </p>
</main>

## Description

`ob_default_replica_num` specifies the default number of replicas for tables in each cluster.

## Attributes

| **Attribute**  |    **Description**     |
|-----------|-----------------|
| Type   | Int     |
| Default value     | 1   |
| Value range   | [1, 7] |
| Scope   | <ul><li>Global </li><li>Session </li></ul>    |
