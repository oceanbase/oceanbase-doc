# ob_enable_blk_nestedloop_join

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is removed starting with V4.0.0 because the corresponding logic was changed in V4.x. </p>
</main>

## Description

`ob_enable_blk_nestedloop_join` specifies whether to enable block nested loop join.

## Attributes

|    **Attribute**    |    **Description**       |
|----------------|-------------------|
| Type        | Boolean                                      |
| Default value          | 0                                         |
| Value range        | <ul><li>0: disabled</li><li>1: enabled</li></ul> |
| Scope        | <ul><li>Global</li><li>Session</li></ul>   |
| Modifiable      | Yes. You can execute the `SET` statement to modify the value.                 |
