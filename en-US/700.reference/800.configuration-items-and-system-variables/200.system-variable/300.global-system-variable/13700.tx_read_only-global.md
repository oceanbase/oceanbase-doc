# tx_read_only

`tx_read_only` specifies whether the transaction is read-only.

| **Attribute**  |                                                   **Description**                                                    |
|---------|-------------------------------------------------------------------------------------------------------------|
| Type    | int                      |
| Default value     | 0                        |
| Valid values    | <li> 1: read-only transaction   <li> 0: not a read-only transaction    |
| Valid scope    | <li> GLOBAL   <li> SESSION     |
| Modifiable    | Yes. You can execute the `SET` statement to modify the value.|

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This variable takes effect on the current user only. </p>
  </main>
