# ob_plan_cache_percentage

The ob_plan_cache_percentage variable specifies the percentage of tenant memory that can be used by the plan cache.

| **Attribute**  |   **Description**   |
|---------|------------|
| Type    | int        |
| Default value     | 5          |
| Value range    | \[0, 100\] |
| Effective scope    | GLOBAL     |

The maximum memory (absolute value) that the plan cache can use = tenant memory limit \* ob_plan_cache_percentage/100.
