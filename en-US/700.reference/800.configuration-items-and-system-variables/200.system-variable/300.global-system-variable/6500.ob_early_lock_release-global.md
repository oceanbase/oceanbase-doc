# ob_early_lock_release

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable was deprecated in V2.2.30. ELR is now controlled by the tenant-level parameter <code>enable_early_lock_release</code>. </p>
</main>

The `ob_early_lock_release` variable specifies whether to enable early lock release (ELR).

| **Attribute**  |                                                 **Description**                                                 |
|---------|--------------------------------------------------------------------------------------------------------|
| Type    | bool                |
| Default value     | 0                   |
| Valid values    | <li> 0: ELR is disabled.   <li> 1: ELR is enabled.    |
| Scope    | GLOBAL              |
| Serialized | Yes                   |
