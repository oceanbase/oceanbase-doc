# nls_nchar_characterset

## Description

The `nls_nchar_characterset` variable specifies the default character set of the database, which is used for data types such as NCHAR, NVARCHAR2, and NCLOB.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You cannot modify this variable. </p>
  </main>

## Attributes
