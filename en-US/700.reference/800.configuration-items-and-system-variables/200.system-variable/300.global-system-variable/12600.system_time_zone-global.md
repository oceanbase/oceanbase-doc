# system_time_zone

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter was introduced in V2.1. </p>
</main>

## Description

`system_time_zone` specifies the system time zone of the server.

## Privilege requirements

* Query variables

  `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode) and `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to query the values of Global system variables.

* Modify variables

  After you create a tenant, you cannot modify the value by using an SQL statement.

## Attributes

| **Property**  |                                   **Description**             |
|---------|-----------------------------------------------------------|
| Type | Varchar |
| Default value | CST |
| Value range | <ul><li> Numeric value range: \[-12:59, +13:00\]  </li> <li> CDT (Central Daylight Time), CST (China Standard Time), and other time zones.  </li> </ul> |
| Applicable scope | Global |
| Read-only   | No. This variable can be specified when a tenant is created and cannot be modified by SQL statements after the tenant is created.  |
