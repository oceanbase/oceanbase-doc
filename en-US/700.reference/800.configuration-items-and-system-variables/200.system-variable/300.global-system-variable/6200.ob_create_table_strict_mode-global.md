# ob_create_table_strict_mode

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>In OceanBase Database V4.x, because there are no independent partitions, the system uses log streams as the carrier. Log streams record all changes in the database, making the creation of partitions no longer require strict mode. This variable was removed starting with V4.0.0. For more information about the relationship between log streams and partitions, see <a href="../../../100.oceanbase-database-concepts/500.distributed-database-objects/300.data-partitions-and-replicas/200.logstream.md">Log streams</a>. </p>
</main>

## Description

`ob_create_table_strict_mode` is a dynamic variable that sets the strict mode for table creation.

## Attributes

| **Attribute** |    **Description**   |
|----------|---------------|
| Type   | Boolean                         |
| Default value     | 0                |
| Value range   | <ul><li>1: The system strictly follows the Locality to establish replicas. If any replica fails to be established, the table creation fails. </li><li>0: The system creates a table successfully if all types of replicas are available and the Paxos member group replicas reach a majority. </li></ul>     |
| Scope   | <ul><li>Global </li><li>Session </li></ul>  |
