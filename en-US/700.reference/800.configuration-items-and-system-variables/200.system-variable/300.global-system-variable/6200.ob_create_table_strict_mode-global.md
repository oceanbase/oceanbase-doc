# ob_create_table_strict_mode

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>Starting from OceanBase Database V4.0.0, the strict mode for table creation is no longer required because the system uses log streams to record all changes in the database. Log streams serve as the carrier for data partitioning, eliminating the need for strict mode. For more information about the relationship between log streams and data partitions, see <a href="../../../100.oceanbase-database-concepts/500.distributed-database-objects/300.data-partitions-and-replicas/200.logstream.md">Log streams</a>. </p>
</main>

## Description

`ob_create_table_strict_mode` is a dynamic variable that specifies the strict mode for table creation.

## Attributes

| **Attribute** |    **Description**   |
|----------|---------------|
| Type   | Bool                         |
| Default value     | 0                |
| Value range   | <ul><li>1: The system strictly follows the locality to create replicas. If any replica creation fails, the table creation fails. </li><li>0: The system creates a table if at least one replica of each type is created and the Paxos member group has a majority of replicas. </li></ul>     |
| Scope   | <ul><li>Global </li><li>Session </li></ul>  |
