# innodb_stats_persistent

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This variable is available starting with V4.3.2 in V4.3.x. </li><li>This variable is available starting with V4.2.3 in V4.2.x. </li></ul>
</main>

## Description

`innodb_stats_persistent` specifies whether to persist InnoDB index statistics to disk.

<main id="notice">
  <h4>Applicability</h4>
  <ul><li>This variable applies only to OceanBase Database in MySQL mode. </li>
  <li>This variable is for compatibility with ecosystem tools and does not affect OceanBase Database features. </li></ul>
</main>

## Privilege requirements

* Query variables

  `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the values of global system variables.

* Modify variables

  This variable is for compatibility and has no actual effect on parameter configuration.
