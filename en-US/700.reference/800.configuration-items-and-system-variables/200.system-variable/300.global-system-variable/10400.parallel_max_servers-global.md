# parallel_max_servers

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is deprecated in the current version. We recommend that you use the <a href="10600.parallel_servers_target-global.md">parallel_servers_target</a> variable to manage the resource consumption of parallel execution.  </p>
</main>

## Description

`parallel_max_servers` specifies the maximum number of threads in a parallel eXecution (PX) thread pool on each server.

## Attributes

| **Attribute**  |   **Description**    |
|---------|-------------|
| Type    | Int         |
| Default value     | 0           |
| Value range    | \[0, 1800\] |
| Scope    | Global      |
