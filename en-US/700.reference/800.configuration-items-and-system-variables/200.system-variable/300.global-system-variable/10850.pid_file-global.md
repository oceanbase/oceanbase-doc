# pid_file

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>For V4.3.x, this variable is available starting with V4.3.5 BP1. </li><li>For V4.2.x, this variable is available starting with V4.2.5 BP1. For V4.2.1, this variable is available starting with V4.2.1 BP10. </li></ul>
</main>

## Description

`pid_file` specifies the path of the file in which the server writes its process ID.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable is applicable only to OceanBase Database in MySQL-compatible mode. </p>
</main>

## Privilege requirements

* Query variables

  `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `information_schema.GLOBAL_VARIABLES` view (MySQL-compatible mode) to view the values of Global system variables.

* Modify variables

  This variable cannot be modified.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type    |  Varchar             |
| Default value      |  /run/observer.pid  |
| Scope    |  Global  |
| Modifiable  | No. This variable cannot be modified by using the `SET` statement.       |
| Read-only    | Yes       |

## Examples

Query the path of the file in which the server writes its process ID.

```shell
obclient> SHOW VARIABLES LIKE 'pid_file';
```

The query result is as follows:

```shell
+---------------+----------------------------------------+
| Variable_name | Value                                  |
+---------------+----------------------------------------+
| pid_file      | /home/admin/oceanbase/run/observer.pid |
+---------------+----------------------------------------+
1 row in set (0.004 sec)
```
