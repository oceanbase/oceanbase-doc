# ob_enable_jit

ob_enable_jit specifies whether to enable the JIT execution engine.

|  **Attribute**  |                                  **Description**                                  |
|----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Type | enum                                                                     |
| Default value | OFF                                                                      |
| Value range     | <li> OFF: Expression compilation and execution are disabled in the current session.   <li> AUTO: Expression compilation and execution are enabled in the current session only when the average execution RT of SQL statements is greater than 1s.   <li> FORCE: Expression compilation and execution are enabled in the current session.    |
| Scope of effect | <li> GLOBAL   <li> SESSION                                                     |
| Modifiable | Yes. You can execute the `SET` statement to modify the variable value. |
