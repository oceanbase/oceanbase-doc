# ob_bnl_join_cache_size

ob_bnl_join_cache_size specifies the number of data records to be cached in one batch for batch nested loop join.

|  **Attribute**  |                                                   **Description**                                                   |
|----------|------------------------------------------------------------------------------------------------------------|
| Type | int                     |
| Default value | 10485760                |
| Valid values | \[1, 9223372036854775807\]                                                                                 |
| Scope of effect | <li> GLOBAL   <li> SESSION    |
| Modifiable | Yes. You can execute the `SET` statement to modify this variable. |
