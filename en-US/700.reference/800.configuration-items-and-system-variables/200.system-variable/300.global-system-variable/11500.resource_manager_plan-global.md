# resource_manager_plan

## Description

The `resource_manager_plan` variable specifies the resource isolation plan for a tenant. The variable determines the CPU quota for user activities in a resource group.

## Privilege requirements

* Query variables

  The `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or view the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode) or the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to query the value of a Global system variable.

* Modify variables

  * The `sys` tenant can directly modify the value of a Global system variable.

  * A MySQL user tenant requires the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a Global system variable.

  * For V4.x, starting from V4.2.0, an Oracle user tenant requires the `ALTER SYSTEM` privilege to modify the value of a Global system variable.

## Attribute description

|   Attribute   |      Description       |
|--------|---------------|
| Type   | varchar       |
| Default value    | ""            |
| Value range   | N/A           |
| Effective scope   | GLOBAL        |
| Restart required | No, takes effect within 10s after the variable is set |

You can specify a resource isolation plan for a tenant to control the CPU resource contention strategy and limit the usage of resources.
