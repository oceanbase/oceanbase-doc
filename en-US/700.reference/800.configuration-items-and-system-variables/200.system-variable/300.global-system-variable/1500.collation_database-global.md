# collation_database

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable was introduced in V1.4 and is only used for compatibility with MySQL. While you can query and set it, the related features are not supported. Changing the value has no effect and does not produce an error. </p>
</main>

## Description

`collation_database` specifies the default character set and collation when a database is created.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to OceanBase Database MySQL-compatible mode. </p>
</main>

## Privilege requirements

* Query variables

  * Global variables

    The `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view (MySQL-compatible mode) to query the values of global system variables.

  * Session variables

    The `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view (MySQL-compatible mode) to query the values of session system variables.
