# query_cache_size

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.1. </p>
</main>

## Description

`query_cache_size` specifies the size of memory allocated to store historical query results, in bytes. This memory is not yet used.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This variable is not effective at present. </p>
  </main>
