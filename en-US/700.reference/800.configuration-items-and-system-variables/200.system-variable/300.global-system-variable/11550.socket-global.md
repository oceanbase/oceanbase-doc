# socket

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V4.2.5 BP1. </p>
</main>

## Description

`socket` specifies the name of the `Socket` file that is used to connect to the local client.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable is applicable only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query variables

  `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the values of global system variables.

* Modify variables

  You cannot modify this variable.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type    | Varchar              |
| Default value      | /run/sql.sock   |
| Scope    | Global  |
| Modifiable | No. This variable is read-only.       |

## Examples

Query the name of the `socket` file that is used to connect to the local client.

```shell
obclient> SHOW VARIABLES LIKE 'socket';
```

The query result is as follows:

```shell
+---------------+------------------------------------+
| Variable_name | Value                              |
+---------------+------------------------------------+
| socket        | /home/admin/oceanbase/run/sql.sock |
+---------------+------------------------------------+
1 row in set (0.003 sec)
```
