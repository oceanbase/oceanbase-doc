# nls_characterset

## Description

The `nls_characterset` variable is used to view the default character set of the CHAR, VARCHAR2, and CLOB data types in the database.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The variable is currently not in effect. </p>
</main>
