# nls_iso_currency

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The variable is available since V2.2.77.</p>
</main>

## Description

`nls_iso_currency` specifies the local currency symbol for the `C` number format element.

<main id="notice">
  <h4>Function Applicability</h4>
  <p>This variable is applicable only to OceanBase Database in Oracle mode. </p>
</main>

## Privilege requirements

* Query variables

  * Global level

    `sys` tenant and all user tenants can query global system variables by using the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle mode).

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle mode) to view the values of session system variables.

* Modify variables

  You cannot modify this variable.
