# ob_trx_timeout

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable was introduced in OceanBase Database V2.2.77. </p>
</main>

## Description

`ob_trx_timeout` specifies the transaction timeout period.

## Attributes

| **Attribute** | **Description** |
|----------|----------|
| Type | Integer |
| Default value | `86400000000`, in μs.  <main id="notice" type='explain'><h4>Note</h4><p>In OceanBase Database V4.0.0 and later, the default value of this variable is changed from `100000000` to `86400000000`.</p></main> |
| Value range | NULL |
| Effective scope |   <ul><li>Global  </li><li>Session </li></ul>    |
| Modifiable | Yes. You can use the `SET` statement to modify the variable. |
| Involved in serialization | Yes |

## Examples

* Session-level operation

    ```shell
    obclient> SET ob_trx_timeout=100000000;
    ```

* Global-level operation

    ```shell
    obclient> SET GLOBAL ob_trx_timeout=100000000;
    ```
