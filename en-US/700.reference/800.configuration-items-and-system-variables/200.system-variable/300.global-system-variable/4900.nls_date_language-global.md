# nls_date_language

## Description

The `nls_date_language` variable specifies the default language for date-related information such as dates, months, AM/PM, and BC/AD in internationalization support. The variable applies to dates, months, AM/PM, and BC/AD returned or input by the TO_DATE and TO_CHAR functions.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You cannot modify this variable. </p>
  </main>
