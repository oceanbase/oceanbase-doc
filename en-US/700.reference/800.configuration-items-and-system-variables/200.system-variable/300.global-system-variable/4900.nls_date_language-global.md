# nls_date_language

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p> This variable was introduced in V2.2.77. </p>
</main>

## Description

`nls_date_language` specifies the default date language of the information entered or returned by TO_DATE and TO_CHAR, including date, month, am/pm, and BC/AD.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to the Oracle mode of OceanBase Database. </p>
</main>

## Privilege requirements

* Query variables

  * Global scope

    Tenants of the `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or view `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` (Oracle mode) to view the values of global system variables.

  * Session scope

    Tenants of the `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or view `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` (Oracle mode) to view the values of session system variables.

* Modify variables

    Tenants of the `sys` tenant and all user tenants cannot modify the values of global or session system variables of their own tenants.
