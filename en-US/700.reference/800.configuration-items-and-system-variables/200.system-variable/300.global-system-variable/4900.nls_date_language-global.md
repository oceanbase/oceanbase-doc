# nls_date_language

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable was introduced in V2.2.77. </p>
</main>

## Description

`nls_date_language` specifies the default date language of the information entered or returned by `TO_DATE` and `TO_CHAR`, including date, month, am/pm, and BC/AD.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable applies only to the Oracle mode of OceanBase Database. </p>
</main>

## Permissions

* Query variables

  * Global scope

    Tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (in Oracle mode) to query global system variables.

  * Session scope

    Tenants can use the `SHOW VARIABLES` statement or the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (in Oracle mode) to query session system variables.

* Modify variables

    Tenants cannot modify the values of global or session system variables in their own tenants.
