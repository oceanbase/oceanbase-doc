# init_connect

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available only for compatibility with MySQL 5.7. The related feature is not supported. You can query and set this variable. The setting does not take effect and no error is returned. </p>
</main>

## Description

`init_connect` specifies a string to be executed for each client connection to the server. The string consists of one or more SQL statements separated by semicolons.

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type     | Varchar |
| Scope     | Global   |
