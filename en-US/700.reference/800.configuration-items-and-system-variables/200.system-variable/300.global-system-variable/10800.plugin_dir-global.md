# plugin_dir

## Description

The `plugin_dir` variable specifies the path where the plugin DLLs are stored.

## Privilege requirements

* Query variables

  The `sys` tenant and all user tenants can execute the `SHOW VARIABLES` statement or view the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` (Oracle mode) or `information_schema.GLOBAL_VARIABLES` (MySQL mode) view to query the value of a global system variable.

* Modify variables

  * The `sys` tenant can directly modify the value of a global system variable.

  * MySQL user tenants must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * For V4.x, starting from V4.2.0, Oracle user tenants must have the `ALTER SYSTEM` privilege to modify the value of a global system variable.
