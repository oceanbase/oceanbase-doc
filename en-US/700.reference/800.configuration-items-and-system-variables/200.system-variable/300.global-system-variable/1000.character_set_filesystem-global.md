# character_set_filesystem

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is available starting with V1.4. </p>
</main>

## Description

`character_set_filesystem` specifies the character set type of the file system.

## Privilege requirements

* Query variables

  * Global level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE` view (Oracle-compatible mode) or the `information_schema.GLOBAL_VARIABLES` view (MySQL-compatible mode) to view the value of a global system variable.

  * Session level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `SYS.TENANT_VIRTUAL_SESSION_VARIABLE` view (Oracle-compatible mode) or the `information_schema.SESSION_VARIABLES` view (MySQL-compatible mode) to view the value of a session system variable.

* Modify variables

  * Global level

    * `sys` tenants can modify the value of a global system variable.

    * MySQL user tenants must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

    * Oracle user tenants must have the `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session level

    `sys` tenants and all user tenants can modify the value of a session system variable.

## Attributes

| **Attribute**  |    **Description**  |
|-----------|---------------|
| Type    | String       |
| Default value      | BINARY                  |
| Value range    | BINARY                  |
| Scope    |  <ul><li>Global</li><li>Session</li></ul>  |
| Modifiable  | Yes. You can execute the `SET` statement to modify the value.|
| Nullable  | Yes          |

## Examples

Set the character set type of the file system to BINARY.

* Global level

  ```shell
  obclient> SET GLOBAL character_set_filesystem ='BINARY';
  ```

* Session level

  ```shell
  obclient> SET character_set_filesystem ='BINARY';
  ```
