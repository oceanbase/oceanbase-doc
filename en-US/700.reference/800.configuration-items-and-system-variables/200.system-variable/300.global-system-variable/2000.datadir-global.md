# datadir

The `datadir` variable indicates the local disk path for data storage.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The variable is provided for compatibility only. OceanBase Database does not implement the functionality of this variable. </p>
</main>

| **Attribute** |         **Description**         |
|--------|------------------------|
| Type   | varchar                |
| Default value    | /usr/local/mysql/data/ |
| Value range   | N/A                    |
| Scope   | Global                 |
| Modifiable  | No                      |
