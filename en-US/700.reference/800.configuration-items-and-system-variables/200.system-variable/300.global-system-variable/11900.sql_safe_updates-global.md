# sql_safe_updates

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.2.77. </p>
</main>

## Description

`sql_safe_updates` specifies whether to enable the SQL safe mode of MySQL. The default value is 0, which indicates that the SQL safe mode is disabled.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is provided only for compatibility. OceanBase Database does not support this variable. </p>
</main>

## Attributes

| **Attribute**  |                                                          **Description**                                                          |
|---------|--------------------------------------------------------------------------------------------------------------------------|
| Type    | Bool                                  |
| Default value     | 0                                     |
| Value range    |<ul><li> 0: FALSE, which indicates that the SQL safe mode is disabled. </li><li>1: TRUE, which indicates that the SQL safe mode is enabled. </li></ul>    |
| Scope    | <ul><li>Global   </li><li>Session </li></ul>   |
