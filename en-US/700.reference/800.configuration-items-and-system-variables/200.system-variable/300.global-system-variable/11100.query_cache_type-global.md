# query_cache_type

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available starting with V2.1. </p>
</main>

## Description

`query_cache_type` specifies the query cache type.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is not effective. </p>
</main>

## Attributes

| **Attribute**  |                           **Description**                             |
|-----------|----------------------------------------------------------------|
| Type   | Varchar                                                     |
| Default value     | OFF                                                         |
| Value range   | <ul><li> OFF: Do not cache or retrieve results.   </li><li> ON: Cache all results except for those of `SELECT SQL_NO_CACHE ...` queries. </li><li> DEMAND: Cache only the results of `SELECT SQL_CACHE ...` queries. </li></ul>   |
| Scope    | Global |
| Modifiable  | No. This variable is specified only when you create a tenant. You cannot modify it by executing an SQL statement after the tenant is created. |
