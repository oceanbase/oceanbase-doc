# performance_schema

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is available only for compatibility with MySQL 8.0. The related features are not supported. You can query and set this variable. The setting does not take effect and no error is returned. </p>
</main>

## Description

`performance_schema` specifies whether to support queries for performance information.

## Attributes

|   Attribute       |      Description                                             |
|--------------|-------------------------------------------------------|
| Type     | Bool                   |
| Default value       | OFF                    |
| Value range     | <ul><li>ON: Supported</li><li>OFF: Not supported</li></ul>    |
| Scope     | Global                |
| Modifiable | Yes. You can execute the `SET` statement to modify the value. |
