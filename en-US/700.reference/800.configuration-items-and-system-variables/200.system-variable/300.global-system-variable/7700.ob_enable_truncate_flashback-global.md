# ob_enable_truncate_flashback

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is no longer available. In V4.x, the TRUNCATE TABLE operation no longer supports the recycle bin. Although this variable can still be queried and set in V4.x, the related features will not take effect. </p>
</main>

## Description

`ob_enable_truncate_flashback` specifies whether to enable flashback for table truncation.

## Attributes

| **Attribute** |    **Description**      |
|----------|------------------|
| Type   | Bool                         |
| Default value     | OFF                          |
| Value range   | <ul><li>OFF (0): disabled</li><li>ON (1): enabled</li></ul>     |
| Scope   | <ul><li>Global</li><li>Session</li></ul>          |
| Modifiable | Yes. You can execute the `SET` statement to modify the value. |
