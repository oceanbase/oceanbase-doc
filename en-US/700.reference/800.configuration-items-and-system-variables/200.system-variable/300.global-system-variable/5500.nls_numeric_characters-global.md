# nls_numeric_characters

## Description

The `nls_numeric_characters` variable controls the characters used as the decimal and thousand separator in number and string conversions.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You cannot modify this variable. </p>
  </main>

## Attributes

| **Attribute**  |                                                   **Description**                                                   |
|---------|------------------------------------------------------------------------------------------------------------|
| Type    | varchar                 |
| Default value     | an empty string                    |
| Value range    | N/A                     |
| Effective scope    | <li> Global   <li> Session    |
| Modifiable    | No  |
