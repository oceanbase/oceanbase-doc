# ob_timestamp_service

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Starting with V4.x, GTS is used by default, and you do not need to specify the global timestamp service. This variable was removed starting with V4.0.0. </p>
</main>

## Description

`ob_timestamp_service` specifies the timestamp service to use.

## Attributes

| **Attribute**  |           **Description**                         |
|---------|----------------------------------------------|
| Type    | Enum                         |
| Default value     | GTS                            |
| Value range    | <ul><li>LTS: Uses the server's local timestamp as the transaction snapshot during execution. Does not support cross-partition access. </li><li>GTS: Retrieves a global timestamp from the GTS service during transaction execution, which serves as the transaction snapshot and commit version. No usage restrictions apply. </li><li>HA_GTS: Not supported. </li></ul>   |
| Scope    | Global            |
