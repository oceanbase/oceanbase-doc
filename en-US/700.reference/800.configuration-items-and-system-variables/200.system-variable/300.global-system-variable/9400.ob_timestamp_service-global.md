# ob_timestamp_service

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Starting from V4.x, GTS is used by default. Therefore, you do not need to specify the global timestamp service. This variable is removed starting from V4.0.0. </p>
</main>

## Description

`ob_timestamp_service` specifies the type of timestamp service.

## Attributes

| **Attribute**  |           **Description**                         |
|---------|----------------------------------------------|
| Type    | Enum                         |
| Default value     | GTS                            |
| Value range    | <ul><li>LTS: The server local timestamp is used as the snapshot of the transaction. It does not support cross-partition access. </li><li>GTS: The global timestamp is obtained from the GTS service as the snapshot of the transaction and the commit version number. There are no restrictions on its usage. </li><li>HA_GTS: Not supported. </li></ul>   |
| Scope    | Global            |
