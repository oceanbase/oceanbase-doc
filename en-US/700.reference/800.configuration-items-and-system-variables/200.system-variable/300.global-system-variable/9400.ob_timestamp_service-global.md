# ob_timestamp_service 

<main id="notice" type='explain'>
<h4>Note</h4>
<p>In OceanBase Database V4.x, the system uses the Global Timestamp Service (GTS) by default, and you do not need to specify the timestamp service. This variable has been deprecated since OceanBase Database V4.0.0. </p>
</main>

`ob_timestamp_service` specifies the timestamp service.

| **Attribute** | **Description** |
|---------|----------------------------------------------|
| Type | ENUM |
| Default value | GTS |
| Value range | <li>`LTS`: During transaction execution, the local timestamp on the server is used as the snapshot for transactions. Access across partitions is not supported.<li>`GTS`: During transaction execution, a global timestamp is obtained from GTS as the snapshot and commit version number of transactions. The use purpose is not limited.<li>`HA_GTS`: At present, this timestamp service is not supported. |
| Effective scope | Global |
| Involved in serialization | Yes |
