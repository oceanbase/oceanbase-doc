# lc_time_names

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This variable is available starting with V4.3.1 in the V4.3.x series. </li><li>This variable is available starting with V4.2.2 in the V4.2.x series. </li></ul>
</main>

## Description

`lc_time_names` specifies the language for displaying date and month names and abbreviations.

<main id="notice">
  <h4>Applicability</h4>
    <p>This variable applies only to OceanBase Database in MySQL mode. </p>
</main>

## Privilege requirements

* Query variables

  * Global level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `information_schema.GLOBAL_VARIABLES` view (MySQL mode) to view the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can execute the `SHOW VARIABLES` statement or query the `information_schema.SESSION_VARIABLES` view (MySQL mode) to view the values of session system variables.

* Modify variables

  * Global level

    * `sys` tenants can directly modify the values of global system variables.

    * MySQL user tenants must have the `SUPER` or `ALTER SYSTEM` privilege to modify the values of global system variables.

  * Session level

    `sys` tenants and all user tenants can directly modify the values of session system variables.

## Attributes

| **Attribute**  |    **Description**  |
|---------|---------------|
| Type    | Varchar                 |
| Default value     | en_US   |
| Value range    |  <ul><li>en_US: English.  </li><li>ja_JP: Japanese. </li><li>ko_KR: Korean. </li><li>zh_CN: Chinese. </li><li>zh_TW: Chinese (Taiwan). </li></ul>                    |
| Scope    |  <ul><li>Global  </li><li>SESSION </li></ul>|
| Modifiable | Yes. You can execute the `SET` statement to modify the value.|

## Usage

This variable affects the output of the `DATE_FORMAT()`, `DAYNAME()`, and `MONTHNAME()` functions, but does not affect the results of the `STR_TO_DATE()` or `GET_FORMAT()` functions.

## Examples

For example, display the result of a date function in Chinese:

1. Set the language for displaying date and month names and abbreviations to Chinese.

   * Session level

     ```shell
     obclient> SET lc_time_names='zh_CN';
     ```

   * Global level

     ```shell
     obclient> SET GLOBAL lc_time_names='zh_CN';
     ```

2. View the current value of `lc_time_names`.

   ```sehll
   obclient> show variables like "lc_time_names";
   ```

   The returned result is as follows:

   ```sehll
   +---------------+-------+
   | Variable_name | Value |
   +---------------+-------+
   | lc_time_names | zh_CN |
   +---------------+-------+
   1 row in set (0.015 sec)
   ```

3. Query the name of the day corresponding to the input date by using the `DAYNAME()` function.

   ```sehll
   obclient> select DAYNAME('2023-01-06');
   ```

   The returned result is as follows:

   ```sehll
   +-----------------------+
   | DAYNAME('2023-01-06') |
   +-----------------------+
   | Friday                |
   +-----------------------+
   1 row in set (0.000 sec)
   ```
