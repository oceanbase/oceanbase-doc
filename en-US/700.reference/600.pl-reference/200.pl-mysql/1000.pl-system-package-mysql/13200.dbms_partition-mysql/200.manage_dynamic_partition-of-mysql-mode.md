# MANAGE_DYNAMIC_PARTITION

The `MANAGE_DYNAMIC_PARTITION` procedure is used to perform a dynamic partition management task, pre-creating future partitions and deleting expired partitions for dynamic partition tables in the current tenant.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For OceanBase Database V4.3.5, the <code>MANAGE_DYNAMIC_PARTITION</code> procedure is supported starting from V4.3.5 BP2. </p>
</main>

## Syntax

```sql
DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION (
    precreate_time VARCHAR(64) DEFAULT NULL,
    time_unit VARCHAR(64) DEFAULT NULL);
```

## Parameters

|      Parameter      |   Description     |
|----------------|-----------|
| precreate_time | Optional. `n {hour \| day \| week \| month \| year}`.<ul><li>The default value is `null`, indicating that no specific precreation time is specified. </li><li>When explicitly specified, the larger value between the specified `precreate_time` and the `precreate_time` value of the table is used as the precreation time when precreating partitions for dynamic partition tables. </li></ul>|
| time_unit      | Optional. `null \| hour \| day \| week \| month \| year`.<ul><li>The default value is `null`, indicating that the dynamic partition management task is executed for all dynamic partition tables. </li><li>When the value is `hour`, the dynamic partition management task is executed only for tables where `time_unit` is `hour`. </li><li>When the value is `day`, the dynamic partition management task is executed only for tables where `time_unit` is `day`. </li><li>When the value is `week`, the dynamic partition management task is executed only for tables where `time_unit` is `week`. </li><li>When the value is `month`, the dynamic partition management task is executed only for tables where `time_unit` is `month`. </li><li>When the value is `year`, the dynamic partition management task is executed only for tables where `time_unit` is `year`. </li></ul>|

## Examples

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION();
```

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION('3DAY');
```

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION('3DAY', 'HOUR');
```
