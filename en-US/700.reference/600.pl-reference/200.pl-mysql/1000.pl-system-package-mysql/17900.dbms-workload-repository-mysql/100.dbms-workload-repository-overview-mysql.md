# Overview

The `DBMS_WORKLOAD_REPOSITORY` package is used to manage the Automatic Workload Repository (WR).

## Privilege requirements

All subprograms of the `DBMS_WORKLOAD_REPOSITORY` package require the `EXECUTE` privilege.

## Subprograms

The following table lists the subprograms of the `DBMS_WORKLOAD_REPOSITORY` package in the current OceanBase Database version and their brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [ASH_REPORT](200.ash-report-mysql.md) | Displays the ASH report in text format. |
| [CREATE_SNAPSHOT](300.create-snapshot-mysql.md) | Triggers the generation of a snapshot for a cluster. |
| [DROP_SNAPSHOT_RANGE](400.drop-snapshot-range-mysql.md) | Deletes snapshots within a specified range. |
| [MODIFY_SNAPSHOT_SETTINGS](500.modify-snapshot-settings-mysql.md) | Modifies the WORKLOAD_REPOSITORY configuration. |
