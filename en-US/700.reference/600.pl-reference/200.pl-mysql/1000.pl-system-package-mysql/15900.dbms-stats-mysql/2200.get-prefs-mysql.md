# GET_PREFS

The `GET_PREFS` function is used to retrieve the default value of a specified preference.

## Syntax

```sql
DBMS_STATS.GET_PREFS (
   pname     IN   VARCHAR2,
   ownname   IN   VARCHAR2 DEFAULT NULL,
   tabname   IN   VARCHAR2 DEFAULT NULL)
 RETURN VARCHAR2;
```

## Parameters

|   Parameter    |                Description              |
|---------|-----------------------------------|
| pname   | The name of the preference.                      |
| ownname | The username. If `ownname` is set to `NULL`, the current logged-in username will be used by default. |
| tabname | The name of the table.                              |

## Exceptions

|    Error code    |          Description          |
|-----------|----------------------|
| HY000     |  <ul><li>Resource Manager is not enabled, and statistics collection cannot be performed simultaneously.</li><li>Invalid input value. </li></ul>     |

## Examples

Retrieve the default value of the `GRANULARITY` parameter for the `tbl1` table of user `testUser01`.

```sql
obclient> SELECT DBMS_STATS.GET_PREFS ('GRANULARITY','testUser01','tbl1') FROM DUAL;
+----------------------------------------------------------+
| DBMS_STATS.GET_PREFS ('GRANULARITY','testUser01','tbl1') |
+----------------------------------------------------------+
| AUTO                                                     |
+----------------------------------------------------------+
1 row in set
```
