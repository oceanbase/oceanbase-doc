# UNLOCK_PARTITION_STATS

The `UNLOCK_PARTITION_STATS` procedure unlocks the statistics of a partition.

## Syntax

```sql
DBMS_STATS.UNLOCK_PARTITION_STATS (
  ownname      VARCHAR2,
  tabname      VARCHAR2,
  partname     VARCHAR2);
```

## Parameters

|    Parameter    |                Description                 |
|----------|-----------------------------------|
| ownname  | The username. If the username is set to `NULL`, the current login username is used by default. |
| tabname  | The table name.                              |
| partname | The name of the (sub)partition.                         |

## Considerations

To call this procedure, you must be the owner of the table. For objects owned by `SYS`, you must be the owner or have the `SYSDBA` privilege.

## Examples

Unlock the statistics of the `p0` partition of the `t1` table for the user `testUser01`.

```sql
obclient> CALL DBMS_STATS.UNLOCK_PARTITION_STATS ('testUser01', 't1', 'p0');
Query OK, 0 rows affected
```
