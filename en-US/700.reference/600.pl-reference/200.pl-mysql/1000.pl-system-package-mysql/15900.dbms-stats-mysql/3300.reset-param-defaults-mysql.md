# RESET_PARAM_DEFAULTS

The `RESET_PARAM_DEFAULTS` procedure resets all parameter default values to the database-recommended values.

## Syntax

```sql
DBMS_STATS.RESET_PARAM_DEFAULTS;
```

## Examples

```sql
obclient> CALL DBMS_STATS.RESET_PARAM_DEFAULTS;
Query OK, 0 rows affected
```
