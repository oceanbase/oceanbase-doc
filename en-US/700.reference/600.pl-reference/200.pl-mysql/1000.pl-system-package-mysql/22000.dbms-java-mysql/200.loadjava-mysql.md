# LOADJAVA

The `DBMS_JAVA.LOADJAVA` procedure uploads a jar package as an external resource to an OBServer.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package is available starting from OceanBase Database V4.4.0. </p>
</main>

## Syntax

```sql
DBMS_JAVA.LOADJAVA(IN jar_name VARCHAR(65535), IN content LONGBLOB, IN comment VARCHAR(65535) DEFAULT '');
```

## Parameters

| **Parameter**           | **Description**                                            |
|------------------|-----------------------------------------------------|
| jar_name | The name of the external resource. You can query this parameter from the `DBA_OB_EXTERNAL_RESOURCES` or `CDB_OB_EXTERNAL_RESOURCES` view.|
| content | The binary content of the jar package.|
| comment | Optional. The comment of the external resource. You can query this parameter from the `DBA_OB_EXTERNAL_RESOURCES` or `CDB_OB_EXTERNAL_RESOURCES` view.|

## Considerations

To upload a jar package as an external resource to an OBServer, call the `DBMS_JAVA.LOADJAVA` procedure and specify the following three parameters:

1. The name of the external resource. You can customize the name, which is case-insensitive and must be unique in the current database. You can reference this external resource by using the name.
2. The binary content of the jar package.
3. The comment of the external resource. You can customize the comment.

## Examples

Call the `DBMS_JAVA.LOADJAVA` procedure to upload a jar package as an external resource to an OBServer.

```java
String url = "<URL to Jar>";
InputStream is = new URL(url).openStream();

// conn is a connection to OceanBase
PreparedStatement ps = conn.prepareStatement("call dbms_java.loadjava(? ,? ,? )");
ps.setString(1, "my_add_jar");
ps.setBlob(2, is);
ps.setString(3, "my add UDF jar");

ps.execute();
```
