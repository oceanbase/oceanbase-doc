# DROPJAVA

The `DBMS_JAVA.DROPJAVA` procedure is used to delete an uploaded external resource Jar package.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package is introduced in OceanBase Database V4.4.0. </p>
</main>

## Syntax

```sql
DBMS_JAVA.DROPJAVA(IN jar_name VARCHAR(65535));
```

`jar_name` is the `jar_name` parameter of the `loadjava` procedure when the Jar package is uploaded.

## Examples

Execute the following command to delete an uploaded external resource Jar package:

```shell
obclient> CALL DBMS_JAVA.DROPJAVA('my_add_jar');
```
