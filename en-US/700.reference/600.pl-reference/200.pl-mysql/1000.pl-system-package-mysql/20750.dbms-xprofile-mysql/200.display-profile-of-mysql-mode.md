# DISPLAY_PROFILE

The `DISPLAY_PROFILE` procedure displays the performance analysis data of an SQL execution plan and shows the diagnostic information of operators for the specified `trace_id`.

## Syntax

```sql
DBMS_XPROFILE.DISPLAY_PROFILE(
    trace_id    varchar2 default null,
    tenant_id   integer default 0,
    format      varchar2 default 'AGGREGATED',
    level       integer default 1,
    svr_ip      varchar2 default null,
    svr_port    integer default 0,
    op_id       integer default null
    )
```

## Parameters

| **Parameter** | **Description** |
|-----------|----------|
| trace_id  | Optional. Specifies the trace id. Displays the profile under the specified `trace_id`. If omitted, `null`, or an empty string, the last trace id of the current session is used by default. |
| tenant_id | Optional. Specifies the tenant ID. If omitted or set to 0, the current tenant ID is used by default. For user tenants, specifying a tenant ID other than the system tenant will return an empty result. |
| format    | Optional. Specifies the display format. Valid values:<ul><li>`AGGREGATED`: Default value. Displays the aggregated profile.</li><li>`ORIGINAL`: Displays the thread-level profile before aggregation.</li></ul>|
| level     | Optional. Specifies the output level. Each metric has its own level, and metrics with a level higher than the specified level will not be displayed. Valid values:<ul><li>0: Core metrics that are always output, such as row output and dbtime.</li><li>1: Default value. Standard metrics, commonly used metrics can be set to this level.</li><li>2: Diagnostic metrics used for troubleshooting or further analysis. These are rarely used and may output too much information.</li></ul>|
| svr_ip    | Optional. Filters to display only profiles from the specified IP address. Default value is `null`, which means all profiles are displayed. |
| svr_port  | Optional. Filters to display only profiles from the specified port. Default value is 0, which means all profiles are displayed. |
| op_id     | Optional. Filters to display only the profile of the operator with the specified ID. Default value is `null`, which means all profiles are displayed. |

## Examples

* Query the profile of another tenant in the sys tenant.

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC30589818-0-0', tenant_id);
    ```

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Only the sys tenant can query the profile of another tenant, and you must specify <code>tenant_id</code>.</p>
    </main>

* Query the profile of the user tenant in MySQL mode.

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC30589818-0-0');
    ```
