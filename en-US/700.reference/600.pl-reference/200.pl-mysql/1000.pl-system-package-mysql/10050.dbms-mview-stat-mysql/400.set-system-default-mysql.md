# SET_SYSTEM_DEFAULT

The `SET_SYSTEM_DEFAULT` procedure sets the system default value for the refresh statistics parameter.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE set_system_default(
    IN     parameter_name         VARCHAR(65535),
    IN     value                  VARCHAR(65535));
```

## Parameters

| **Parameter**         | **Description**                                                                                         |
|------------------|--------------------------------------------------------------------------------------------------|
| parameter_name   | The parameter name. Valid values: <ul><li>COLLECTION_LEVEL: specifies the statistics collection level. The default value is TYPICAL.</ul></li><ul><li>RETENTION_PERIOD: specifies the number of days for which statistics are retained. The default value is 31 days. </ul></li> |
| value | <p>When the parameter name is COLLECTION_LEVEL: <ul><li>NONE: do not collect statistics.</ul></li><ul><li>TYPICAL: collect basic refresh statistics.</ul></li><ul><li>ADVANCED: collect detailed refresh statistics.</ul></li><ul><li>NULL: use the system default value, which is TYPICAL. </li></ul></p> <p>When the parameter name is RETENTION_PERIOD, the parameter value specifies the number of days for which statistics are retained: 1 to 365000. <ul><li>NULL: use the system default value. </ul></li><ul><li>-1: statistics are retained permanently. </ul></li></br> </p>|
