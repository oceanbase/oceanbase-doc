# SET_MVREF_STATS_PARAMS

The `SET_MVREF_STATS_PARAMS` procedure is used to configure the collection level and data retention period for statistics collection during materialized view refreshes.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE set_mvref_stats_params(
    IN     mv_name                VARCHAR(65535),
    IN     collection_level       VARCHAR(65535)     DEFAULT NULL,
    IN     retention_period       INT                DEFAULT NULL);
```

## Parameters

| **Parameter**           | **Description**                                                                                                                                          |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| mv_name         | The name of the materialized view. <ul><li>If this parameter is set to NULL, the procedure is applied to all materialized views. </ul></li>                                              |
| collection_level | The collection level of statistics. The default value is TYPICAL. Valid values: <ul><li>NONE: do not collect statistics.</ul></li><ul><li>TYPICAL: collect basic refresh statistics.</ul></li><ul><li>ADVANCED: collect detailed refresh statistics.</ul></li><ul><li>NULL: use the default value, which is TYPICAL.</ul></li> |
| retention_period | The number of days for which statistics are retained. Valid values: 1 to 365000. Statistics records are automatically deleted after the specified number of days. The default value is 31 days.<ul><li>If this parameter is set to NULL, the default value is used.</ul></li><ul><li>If this parameter is set to -1, statistics are retained permanently.</ul></li>                               |
