# REFRESH

`REFRESHE` is used to refresh a specified materialized view.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL mode. </p>
</main>

## Syntax

```sql
DBMS_MVIEW.REFRESH (
    mv_name                IN    VARCHAR(65535)
    [, method              IN    VARCHAR(65535) DEFAULT NULL]
    [, refresh_parallel    IN    INT DEFAULT 0]
    [, nested              IN    BOOLEAN DEFAULT FALSE]
    [, nested_refresh_mode IN    VARCHAR DEFAULT NULL]
);
```

## Parameters

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Non-nested materialized views do not support cascading refresh. Therefore, specifying the <code>nested</code> and <code>nested_refresh_mode</code> parameters is meaningless. By default, a non-nested materialized view is refreshed independently. </p>
</main>

|       **Parameter**      |       **Description**        |
|---------------------|-----------------------|
| mv_name             | The name of the materialized view to be refreshed.|
| method              | The refresh strategy of the materialized view. You can specify this parameter to set the default refresh strategy when you create a materialized view. Valid values: <ul><li>`F` or `f`: fast refresh.</li><li>`?`: force refresh.</li><li>`C` or `c`: complete refresh.</li><li>`A` or `a`: always refresh, which is equivalent to `C`. </li></ul>|
| refresh_parallel    | The concurrency level of the refresh operation, that is, the number of threads that can be executed in parallel.|
| nested              | The refresh mode of a nested materialized view. Valid values: <ul><li>`FALSE`: default value. This value indicates that the nested materialized view is refreshed independently. </li><li>`TRUE`: This value indicates that the nested materialized view is refreshed in a cascading manner. </li></ul>|
| nested_refresh_mode | The refresh mode of a cascading refresh. Valid values: <ul><li>If the value of the `nested` parameter is `FALSE`, the value of the `nested_refresh_mode` parameter will be invalid. </li><li>If the value of the `nested` parameter is `TRUE`: <ul><li>Valid values of the `nested_refresh_mode` parameter: <ul><li>`inconsistent`: indicates a cascading refresh in an inconsistent manner. </li><li>`consistent`: indicates a cascading refresh in a consistent manner. </li></ul> </li><li>By default, the cascading refresh is in an inconsistent manner. </li></ul> </li></ul>|

## Examples

* Independent refresh:

  * Specify only the `mv_name` parameter.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH('mv1');
    ```

  * Specify the `mv_name` parameter and set the value of the `nested` parameter to `false`.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false);
    ```

* Cascading refresh in an inconsistent manner:

  * Specify the `mv_name` parameter, set the value of the `nested` parameter to `true`, and do not specify the `nested_refresh_mode` parameter.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true);
    ```

  * Specify the `mv_name` parameter, set the value of the `nested` parameter to `true`, and set the value of the `nested_refresh_mode` parameter to `inconsistent`.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'inconsistent');
    ```

* Cascading refresh in a consistent manner:

  Specify the `mv_name` parameter, set the value of the `nested` parameter to `true`, and set the value of the `nested_refresh_mode` parameter to `consistent`.

  ```shell
  obclient> CALL DBMS_MVIEW.REFRESH(
      'mv1',
      nested=> true,
      nested_refresh_mode => 'consistent');
  ```

* The following examples show error scenarios:

  * Set the value of the `nested` parameter to `false` and specify the value of the `nested_refresh_mode` parameter. An error is returned.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false,
        nested_refresh_mode => 'xxxx');
    ```

  * Do not specify the value of the `nested` parameter and specify the value of the `nested_refresh_mode` parameter. An error is returned.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested_refresh_mode => 'xxxx');
    ```

  * Set the value of the `nested` parameter to `true` and set the value of the `nested_refresh_mode` parameter to an invalid string. An error is returned.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'invalid string');
    ```
