# REFRESH

`REFRESHE` is used to refresh a specified materialized view.
`REFRESHE` is used to refresh a specified materialized view.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_MVIEW.REFRESH (
    mv_name                IN    VARCHAR(65535)
    [, method              IN    VARCHAR(65535) DEFAULT NULL]
    [, refresh_parallel    IN    INT DEFAULT 0]
    [, nested              IN    BOOLEAN DEFAULT FALSE]
    [, nested_refresh_mode IN    VARCHAR DEFAULT NULL]
    mv_name                IN    VARCHAR(65535)
    [, method              IN    VARCHAR(65535) DEFAULT NULL]
    [, refresh_parallel    IN    INT DEFAULT 0]
    [, nested              IN    BOOLEAN DEFAULT FALSE]
    [, nested_refresh_mode IN    VARCHAR DEFAULT NULL]
);
```

## Parameters

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Non-nested materialized views do not support cascading refreshes. Therefore, specifying the <code>nested</code> and <code>nested_refresh_mode</code> parameters is meaningless. By default, independent refreshes are performed. </p>
</main>

|       **Parameter**      |       **Description**        |
|---------------------|-----------------------|
| mv_name             | The name of the materialized view to be refreshed.|
| method              | The refresh strategy of the materialized view. This parameter specifies the default refresh strategy when you create a materialized view. Valid values: <ul><li>`F` or `f`: fast refresh. </li><li>`?`: force refresh. </li><li>`C` or `c`: complete refresh. </li><li>`A` or `a`: always refresh, which is equivalent to `C`. </li></ul>|
| refresh_parallel    | The degree of concurrency of the refresh operation, that is, the number of threads that can be executed in parallel.|
| nested              | The refresh mode of the nested materialized view. Valid values: <ul><li>`FALSE`: default value. This value indicates that the nested materialized view is refreshed independently. </li><li>`TRUE`: indicates that the nested materialized view is refreshed in a cascading manner. </li></ul>|
| nested_refresh_mode | The refresh mode of the nested materialized view in a cascading manner. Valid values: <ul><li>If the value of the `nested` parameter is `FALSE`, specifying the value of the `nested_refresh_mode` parameter will result in an error. </li><li>If the value of the `nested` parameter is `TRUE`: <ul><li>Valid values of the `nested_refresh_mode` parameter: <ul><li>`inconsistent`: indicates that the nested materialized view is refreshed in a cascading manner in an inconsistent way. </li><li>`consistent`: indicates that the nested materialized view is refreshed in a cascading manner in a consistent way. </li></ul> </li><li>If the `nested_refresh_mode` parameter is not specified, the default value is `inconsistent`. </li></ul> </li></ul>|
