# REFRESH

`REFRESHE` is used to refresh a specified materialized view.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL mode. </p>
</main>

## Syntax

```sql
DBMS_MVIEW.REFRESH (
    mv_name                IN    VARCHAR(65535)
    [, method              IN    VARCHAR(65535) DEFAULT NULL]
    [, refresh_parallel    IN    INT DEFAULT 0]
    [, nested              IN    BOOLEAN DEFAULT FALSE]
    [, nested_refresh_mode IN    VARCHAR DEFAULT NULL]
);
```

## Parameters

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Non-nested materialized views do not support cascading refresh. Therefore, specifying the <code>nested</code> and <code>nested_refresh_mode</code> parameters has no effect. By default, the independent refresh mode is used. </p>
</main>

|       **Parameter**      |       **Description**        |
|---------------------|-----------------------|
| mv_name             | The name of the materialized view to be refreshed.|
| method              | The refresh strategy of the materialized view. You can specify a default strategy when you create a materialized view. Valid values: <ul><li>`F` or `f`: fast refresh. </li><li>`?`: force refresh. </li><li>`C` or `c`: complete refresh. </li><li>`A` or `a`: always refresh, which is equivalent to `C`. </li></ul>|
| refresh_parallel    | The concurrency level of the refresh operation, that is, the number of threads that can execute the refresh operation at the same time.|
| nested              | The refresh mode of the nested materialized view. Valid values: <ul><li>`FALSE`: independent refresh. This is the default value. </li><li>`TRUE`: cascading refresh. </li></ul>|
| nested_refresh_mode | The refresh mode of the nested materialized view. Valid values: <ul><li>When the value of the `nested` parameter is `FALSE`, specifying the value of the `nested_refresh_mode` parameter will result in an error. </li><li>When the value of the `nested` parameter is `TRUE`: <ul><li>Valid values of the `nested_refresh_mode` parameter: <ul><li>`inconsistent`: non-consistent cascading refresh. </li><li>`consistent`: consistent cascading refresh. </li></ul> </li><li>If the `nested_refresh_mode` parameter is not specified, the default value is `inconsistent`. </li></ul> </li></ul>|

## Examples

* Independent refresh:

  * Specify only the `mv_name` parameter.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH('mv1');
    ```

  * Specify the `mv_name` and `nested` parameters. The value of the `nested` parameter is `false`.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false);
    ```

* Non-consistent cascading refresh:

  * Specify the `mv_name` and `nested` parameters. The value of the `nested` parameter is `true`, and the `nested_refresh_mode` parameter is not specified.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true);
    ```

  * Specify the `mv_name`, `nested`, and `nested_refresh_mode` parameters. The value of the `nested` parameter is `true`, and the value of the `nested_refresh_mode` parameter is `inconsistent`.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'inconsistent');
    ```

* Consistent cascading refresh:

  Specify the `mv_name`, `nested`, and `nested_refresh_mode` parameters. The value of the `nested` parameter is `true`, and the value of the `nested_refresh_mode` parameter is `consistent`.

  ```shell
  obclient> CALL DBMS_MVIEW.REFRESH(
      'mv1',
      nested=> true,
      nested_refresh_mode => 'consistent');
  ```

* Error scenarios:

  * The value of the `nested` parameter is `false`, and the value of the `nested_refresh_mode` parameter is specified. An error is returned.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false,
        nested_refresh_mode => 'xxxx');
    ```

  * The value of the `nested` parameter is not specified, and the value of the `nested_refresh_mode` parameter is specified. An error is returned.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested_refresh_mode => 'xxxx');
    ```

  * The value of the `nested` parameter is `true`, and the value of the `nested_refresh_mode` parameter is an invalid string. An error is returned.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'invalid string');
    ```
