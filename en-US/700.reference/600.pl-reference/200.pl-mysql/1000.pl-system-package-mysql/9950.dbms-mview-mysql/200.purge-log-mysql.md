# PURGE_LOG

The `PURGE_LOG` procedure is used to clear materialized view logs, thereby reducing the size of the log files. Clearing materialized view logs will delete all log records related to the table.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE purge_log(
    IN     master_name            VARCHAR(65535));
```

## Parameters

| **Parameter**           | **Description**                                                                                                                                              |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| master      | The name of the materialized view log table whose data needs to be cleared.
The format is `schema.object or object`.                                                                         |
