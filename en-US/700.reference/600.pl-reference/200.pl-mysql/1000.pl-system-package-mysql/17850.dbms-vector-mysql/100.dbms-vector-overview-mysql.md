# Overview of DBMS_VECTOR

The `DBMS_VECTOR` system package is used to manage vector indexes.

## Overview of DBMS_VECTOR subprograms

The following table lists the `DBMS_VECTOR` subprograms supported in the current version of OceanBase Database and their brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [REBUILD_INDEX](300.rebuild-index-mysql.md) | Rebuilds the vector index. |
| [INDEX_VECTOR_MEMORY_ESTIMATE](400.index-vector-memory-estimate-mysql.md) | Estimates the memory usage of vector indexes. |
| [INDEX_VECTOR_MEMORY_ADVISOR](500.index-vector-memory-advisor-mysql.md) | Analyzes the memory usage of vector indexes. |
| `SET_ATTRIBUTE` | Sets the degree of parallelism, trigger threshold, and trigger interval for automatic rebuilding of vector indexes. |
