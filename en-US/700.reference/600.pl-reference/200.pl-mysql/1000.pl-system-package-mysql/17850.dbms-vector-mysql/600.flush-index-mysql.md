# FLUSH_INDEX

The `FLUSH_INDEX` procedure is used to manually trigger a flush operation, which corresponds to the process of **freezing and persisting the active incremental segments** in the HNSW vector index. For more information, see [Vector index principles](../../../../100.oceanbase-database-concepts/400.database-objects/200.database-objects-of-mysql-mode/300.index-of-mysql-mode/330.vector-indexes-of-mysql-mode-in-concepts.md).

## Syntax

```sql
PROCEDURE FLUSH_INDEX(
    IN     TABLE_NAME             VARCHAR(65535),                
    IN     IDX_NAME               VARCHAR(65535)
);
```

## Parameters

| Parameter | Description |
| --- | --- |
| table_name | The name of the table. |
| idx_name | The name of the index. |

## Examples

Create a test table.

```sql
CREATE TABLE vector_index_test(c1 INT, c2 VECTOR(3), PRIMARY KEY(c1), VECTOR INDEX idx1(c2) WITH (distance=l2, type=hnsw, lib=vsag));
```

```sql

```
