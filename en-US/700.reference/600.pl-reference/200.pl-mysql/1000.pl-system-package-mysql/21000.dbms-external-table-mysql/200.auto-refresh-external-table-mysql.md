# AUTO_REFRESH_EXTERNAL_TABLE

`auto_refresh_external_table` is used to periodically refresh the META of an external table.

## Syntax

```sql
DBMS_EXTERNAL_TABLE.auto_refresh_external_table(interval int)
```

## Parameters

| **Parameter**           | **Description**                                            |
|------------------|-----------------------------------------------------|
| interval int | Specifies the time interval for refreshing the META of an external table. The value range is [-1, ∞), and the unit is seconds. <ul><li>When the value is -1, the periodic refresh task is disabled.</li><li>When the value is 0, the META of an external table is refreshed immediately.</li><li>When the value is greater than 0, the META of an external table is refreshed every specified seconds.</li></ul>|

## Examples

Execute the following command to disable the periodic refresh task.

```shell
obclient> CALL DBMS_EXTERNAL_TABLE.auto_refresh_external_table(-1);
Query OK, 0 rows affected (0.104 sec)
```
