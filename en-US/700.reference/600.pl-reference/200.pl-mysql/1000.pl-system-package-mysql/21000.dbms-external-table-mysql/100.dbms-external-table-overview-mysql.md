# Overview of DBMS_EXTERNAL_TABLE

The `DBMS_EXTERNAL_TABLE` system package provides a programmatic interface for managing and operating external tables.

## Overview of DBMS_EXTERNAL_TABLE subprograms

The following table lists the `DBMS_EXTERNAL_TABLE` subprograms supported in the current version of OceanBase Database and their brief descriptions.

| Subprogram                   | Description                  |
| --------------------------- | ----------------------------- |
| [auto_refresh_external_table](../21000.dbms-external-table-mysql/200.auto-refresh-external-table-mysql.md) |Used to periodically refresh the META of an external table. |
