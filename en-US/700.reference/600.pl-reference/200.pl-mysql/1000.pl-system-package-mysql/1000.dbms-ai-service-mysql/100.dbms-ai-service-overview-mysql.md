# Overview of DBMS_AI_SERVICE

The `DBMS_AI_SERVICE` package is used to manage AI services, including AI model objects and AI model service endpoint objects.

## Overview of DBMS_AI_SERVICE subprograms

The following table lists the `DBMS_AI_SERVICE` subprograms supported in the current version of OceanBase Database and their brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [CREATE_AI_MODEL](200.create-ai-model-mysql.md) | Creates an AI model object. |
| [DROP_AI_MODEL](300.drop-ai-model-mysql.md) | Drops an AI model object. |
| [CREATE_AI_MODEL_ENDPOINT](400.create-ai-model-endpoint-mysql.md) | Creates an AI model service endpoint object. |
| [ALTER_AI_MODEL_ENDPOINT](500.alter-ai-model-endpoint-mysql.md) | Modifies an AI model service endpoint object. |
| [DROP_AI_MODEL_ENDPOINT](600.drop-ai-model-endpoint-mysql.md) | Drops an AI model service endpoint object. |
