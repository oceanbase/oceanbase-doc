# Overview of DBMS_HYBRID_SEARCH

The `DBMS_HYBRID_SEARCH` system package is used to manage hybrid vector indexes.

## Overview of DBMS_HYBRID_SEARCH subprograms

The following table lists the `DBMS_HYBRID_SEARCH` subprograms supported in the current version of OceanBase Database and their brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [SEARCH](200.search-mysql.md) | Returns the search results in JSON format, sorted by relevance. |
| [GET_SQL](300.get_sql-mysql.md) | Returns the actual executed SQL statement as a string. |
