# TRIGGER_PARTITION_BALANCE

The `TRIGGER_PARTITION_BALANCE` procedure is used to manually trigger partition balancing.

## Syntax

```sql
DBMS_BALANCE.TRIGGER_PARTITION_BALANCE(balance_timeout INT DEFAULT NULL);
```

## Parameters

The `balance_timeout` parameter specifies the timeout period (in seconds) for the background partition balancing task.

## Considerations

* You can call this procedure only in a user tenant. If you call it in the sys tenant, an error <code>OB_OP_NOT_ALLOW</code> is returned.
* If the tenant-level parameter <code>enable_rebalance</code> or <code>enable_transfer</code> is disabled, an error <code>OB_OP_NOT_ALLOW</code> is returned.
* If another partition balancing task is in progress, an error <code>OB_OP_NOT_ALLOW</code> is returned. You must wait for the current task to complete before you can execute this procedure.
* If the current tenant has already completed partition balancing, an error <code>OB_PARTITION_ALREADY_BALANCED</code> is returned.

## Examples

* Trigger a partition balancing task with no timeout.

    ```shell
    obclient> CALL DBMS_BALANCE.TRIGGER_PARTITION_BALANCE();
    ```

* Trigger a partition balancing task with a timeout of 2 hours.

    ```shell
    obclient> CALL DBMS_BALANCE.TRIGGER_PARTITION_BALANCE(7200);
    ```
