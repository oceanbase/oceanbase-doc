# CLEAR_TABLEGROUP_BALANCE_WEIGHT

The `CLEAR_TABLEGROUP_BALANCE_WEIGHT` procedure is used to delete the weights of a table group of the `SHARDING NONE` type.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This procedure is supported starting from V4.4.1. </p>
</main>

## Syntax

```sql
DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT(
    tablegroup_name       VARCHAR(65535)
    ); 
```

## Parameters

| Parameter | Description |
|------|------|
| tablegroup_name | The name of the table group. |

## Considerations

Call `DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT` to delete the weights of a sharding none table group.

## Examples

* Call this procedure in the sys tenant to delete the weights of the `TG_TD_test` table group in the `mysql` tenant.

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test') TENANT = 'mysql';
    ```

* Call this procedure in a user tenant to delete the weights of the `TG_TD_test` table group in the current tenant.

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test');
    ```
