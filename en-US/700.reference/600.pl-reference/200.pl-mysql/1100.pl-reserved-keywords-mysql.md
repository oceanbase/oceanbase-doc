# PL reserved and non-reserved keywords

PL reserved keywords are identifiers that have special meanings in PL and cannot be used as names for stored procedures, functions, types, variables, and so on. PL non-reserved keywords can be used as identifiers without enclosing them in quotation marks. They are not case-sensitive.

## PL reserved keywords

| Initial letter |                      Reserved keywords                              |
|-----|----------------------------------------------------------------|
| B   | BEFORE, BIGINT, BLOB, BY                                          |
| C   | CASE, CHAR, CHARACTER, CHARSET, COLLATE, COMMIT, CONDITION, CONTINUE, CURRENT_USER, CURSOR |
| D   | DEC, DECIMAL, DECLARE, DEFAULT, DELETE, DETERMINISTIC, DOUBLE        |
| E   | EACH, ELSE, ELSEIF, EXISTS, EXIT                                   |
| F   | FETCH, FLOAT, FLOAT4, FLOAT8, FOR, FROM                             |
| I   | IF, IN, INOUT, INSERT, INT, INT1, INT2, INT3, INT4, INT8, INTEGER, IS, ITERATE |
| L   | LEAVE, LIMIT, LONG, LONGBLOB, LONGTEXT, LOOP                        |
| M   | MEDIUMBLOB, MEDIUMINT, MEDIUMTEXT, MIDDLEINT, MODIFIES             |
| N   | NOT, NUMERIC                                                    |
| O   | ON, OR, OUT                                                      |
| P   | PRECISION                                                      |
| R   | READS, REAL, REPEAT, REPLACE, RESIGNAL, RETURN, ROLLBACK             |
| S   | SIGNAL, SMALLINT, SQL, SQLEXCEPTION, SQLSTATE, SQLWARNING           |
| T   | THEN, TINYBLOB, TINYINT, TINYTEXT                                 |
| U   | UNSIGNED, UNTIL, UPDATE, USING                                    |
| V   | VARBINARY, VARCHAR, VARCHARACTER, VARYING                         |
| W   | WHEN, WHILE                                                     |
| Z   | ZEROFILL                                                       |

## Query keywords

You can also query the `V$OB_KEYWORDS` view for a list of PL keywords for the current tenant. For more information about this view, see [V$OB_KEYWORDS](../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/31470.v-ob-keywords-of-mysql-mode.md).

```sql
obclient> SELECT KEYWORD, RESERVED FROM oceanbase.V$OB_KEYWORDS WHERE TYPE = 'PL' ORDER BY KEYWORD;
```
