# REPEAT

You can use the `REPEAT` statement to execute a statement repeatedly until the condition is True.

## Syntax

```sql
[begin_label:] REPEAT
    statement_list
UNTIL search_condition
END REPEAT [end_label]
```

## Parameters

| **Parameter** | **Description** |
|--------------|----------|
| begin_label | Optional. The label name at the beginning of the loop. |
| statement_list | The list of statements to be executed repeatedly. Each statement ends with a semicolon (;). |
| search_condition | The condition expression, evaluated at the end of each loop iteration. If the result is True, the loop exits; if False, the next iteration continues. |
| end_label | Optional. The label name at the end of the loop, which must match `begin_label`. |

`statement_list` in the `REPEAT` statement is executed repeatedly until the result of the `search_condition` expression is `True`. Therefore, `REPEAT` will enter a loop at least once. `statement_list` consists of one or more SQL statements. Each SQL statement ends with a semicolon (;). You can use `label` to label a `REPEAT` statement.

## Examples

Use the REPEAT loop to execute statements until the condition is met.

```sql
obclient> DELIMITER //

obclient> CREATE PROCEDURE rep_proc(p1 INT)
    BEGIN
        SET @x = 0;
        REPEAT
            SET @x = @x + 1;
        UNTIL @x > p1 END REPEAT;
    END //

obclient> DELIMITER ;

obclient> CALL rep_proc(100);

obclient> SELECT @x;
```

The query result is as follows:

```sql
+------+
| @x   |
+------+
|  101 |
+------+
1 row in set
```
