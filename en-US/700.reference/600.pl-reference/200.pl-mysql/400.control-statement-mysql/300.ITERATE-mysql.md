# ITERATE

You can use the `ITERATE` statement to skip the remaining part of the current iteration and continue to the next iteration.

## Syntax

```sql
ITERATE label
```

## Parameters

| **Parameter** | **Description** |
|--------------|----------|
| label | The label of the loop to which to jump. |

`ITERATE` can be used only in the `LOOP`, `REPEAT`, and `WHILE` statements. The `ITERATE` statement skips the remaining part of the current iteration and starts the next iteration.

## Examples

Use `ITERATE` in a `LOOP` statement to skip some iterations.

```sql
obclient> DELIMITER //

obclient> CREATE PROCEDURE iterate_example()
    BEGIN
        DECLARE i INT DEFAULT 0;
        DECLARE sum_result INT DEFAULT 0;
        loop_label: LOOP
            SET i = i + 1;
            IF i % 2 = 0 THEN
                ITERATE loop_label;
            END IF;
            SET sum_result = sum_result + i;
            IF i >= 10 THEN
                LEAVE loop_label;
            END IF;
        END LOOP loop_label;
        SELECT sum_result;
    END //

obclient> DELIMITER ;

obclient> CALL iterate_example();
```

The query result is as follows:

```sql
+------------+
| sum_result |
+------------+
|         36 |
+------------+
1 row in set
```
