# LEAVE

You can use the `LEAVE` statement to exit a throttling statement with the specified label. If the label is used in the outermost stored program block, use the `LEAVE` statement to exit the program.

## Syntax

```sql
LEAVE label
```

## Parameters

| **Parameter** | **Description** |
|--------------|----------|
| label | The label of the statement to exit. |

The `LEAVE` statement can be used in the `BEGIN ... END` block and the `LOOP`, `REPEAT`, and `WHILE` loop statements.

## Examples

Use the `LEAVE` statement to exit a loop.

```sql
obclient> DELIMITER //

obclient> CREATE PROCEDURE leave_example()
    BEGIN
        DECLARE i INT DEFAULT 0;
        loop_label: LOOP
            SET i = i + 1;
            IF i >= 5 THEN
                LEAVE loop_label;
            END IF;
        END LOOP loop_label;
        SELECT i;
    END //

obclient> DELIMITER ;

obclient> CALL leave_example();
```

The query result is as follows:

```sql
+------+
| i    |
+------+
|    5 |
+------+
1 row in set
```
