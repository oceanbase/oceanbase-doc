# DROP PROCEDURE

You can use the `DROP PROCEDURE` statement to drop a stored procedure.

## Syntax

```sql
DROP PROCEDURE [IF EXISTS] sp_name
```

## Parameters

| **Parameter** | **Description** |
|--------------|----------|
| IF EXISTS | Optional. If the stored procedure does not exist, it does not return an error but generates a warning. |
| sp_name | The name of the stored procedure to drop. You can use `database_name.sp_name` to specify the database. |

To drop a stored routine, you must have the `ALTER ROUTINE` privilege on the routine.

If the stored procedure does not exist, you can use the `IF EXISTS` clause to avoid errors and generate a warning. You can use the `SHOW WARNINGS` statement to view the warning.

## Examples

Drop a stored procedure.

```sql
obclient> DROP PROCEDURE IF EXISTS proc_name;
```

Drop a stored procedure in a specified database:

```sql
obclient> DROP PROCEDURE IF EXISTS test_db.get_employee_list;
```
