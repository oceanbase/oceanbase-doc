# DO

You can use the `DO` statement to execute an SQL expression without returning any result.

## Syntax

```sql
DO expr [, expr ...]
```

## Parameters

| **Parameter** | **Description** |
|--------------|----------|
| expr | The SQL expression to execute. You can specify multiple expressions, separated by commas. |

In some scenarios, the `DO` statement is equivalent to the `SELECT expr` statement, which provides a quick response without returning a result.

## Examples

Execute an expression without returning a result.

```sql
obclient> DO SLEEP(5);
```

Execute multiple expressions:

```sql
obclient> DO @var1 := 10, @var2 := 20, @var3 := @var1 + @var2;

obclient> SELECT @var1, @var2, @var3;
```

The query result is as follows:

```sql
+-------+-------+-------+
| @var1 | @var2 | @var3 |
+-------+-------+-------+
|    10 |    20 |    30 |
+-------+-------+-------+
1 row in set
```
