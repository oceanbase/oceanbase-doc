# Sequential control

Sequential control statements allow you to transfer to a specified labeled statement or do nothing.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

Compared with the `IF` and `LOOP` statements, the `GOTO` and `NULL` statements in sequential control are less important in PL programming. The `GOTO` statement is rarely used in PL programming to jump to a specified statement. The `NULL` statement does not perform any operations and is usually used to explain the meaning and operations of conditional statements to improve readability.

## GOTO statement

The `GOTO` statement supports unconditional jumps to other parts of the code block for continued execution. You need to define a label in advance and use the `GOTO` statement to jump to the label. The label must be placed before a statement, not within a statement.

Here is an example:

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    WHILE cnt < 3 LOOP
       DBMS_OUTPUT.PUT_LINE (cnt);
       cnt :=  cnt + 1;
       GOTO JUMP_OUT;
    END LOOP;
     cnt := 0;
     <<JUMP_OUT>>
    DBMS_OUTPUT.PUT_LINE (cnt);
END;
 /
Query OK, 0 rows affected

0
1
```

## NULL statement

The `NULL` statement is an empty statement that does not perform any operations and is usually used as a placeholder. For example, during code debugging, if the code is not yet fully written, you can use the `NULL` statement as a placeholder to avoid syntax errors.
