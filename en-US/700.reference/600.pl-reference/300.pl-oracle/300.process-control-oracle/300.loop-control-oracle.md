# Loop control

Loop statements are mainly used to repeatedly execute a set of operations.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

The `LOOP` statement can be declared in the following four forms:

* Basic `LOOP`

* `FOR LOOP`

* `FOR LOOP` for cursors

* `WHILE LOOP`

The following two statements are used to exit the entire loop:

* `EXIT`

* `EXIT WHEN`

The following two statements are used to exit the current iteration of the loop:

* `CONTINUE`

* `CONTINUE WHEN`

`EXIT`, `EXIT WHEN`, `CONTINUE`, and `CONTINUE WHEN` are used to exit loops and can be placed anywhere within the loop. It is recommended to use these statements to exit loops and avoid using the `GOTO` statement. The `EXIT` statement transfers control to the end of the `LOOP` statement. The `CONTINUE` statement exits the current iteration of the loop and transfers control to the start of the next iteration. Both `EXIT` and `CONTINUE` can be followed by an optional `WHEN` clause, which specifies a condition.

For nested loops, it is recommended to label the loops to improve readability.

## Basic LOOP

The basic `LOOP` statement repeatedly executes a sequence of statements. The syntax of the basic `LOOP` statement is as follows:

```javascript
[ label ] LOOP
    statements
END LOOP [ label ];
```

In a `LOOP` statement, the `statements` are executed repeatedly. To avoid an infinite loop, at least one statement within the `LOOP` and `END LOOP` statements must contain an `EXIT` statement. Otherwise, the `LOOP` statement will continue indefinitely.

The `EXIT` statement can be followed by an optional `WHEN` clause, indicating that when the condition is `TRUE`, the `EXIT` statement is executed, and control is transferred to the statement after `END LOOP`.

## EXIT statement

The `EXIT` statement unconditionally exits the current loop.

Here is an example:

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
        cnt := cnt + 1;
        IF cnt > 5 THEN
         EXIT;
        END IF;
     END LOOP;
     DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/
Query OK, 0 rows affected

INSIDE: 0

INSIDE: 2
INSIDE: 3
INSIDE: 4
INSIDE: 5
OUTSIDE: 6
```

## EXIT WHEN statement

The `EXIT WHEN` statement is used to exit the current loop when the condition in the `WHEN` clause is `TRUE`.

Here is an example:

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    LOOP
       DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
       cnt := cnt + 1;
       EXIT WHEN cnt >5;
     END LOOP;
     DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/

```

## CONTINUE statement

The `CONTINUE` statement is used to exit the current iteration of the loop, skipping the code from `CONTINUE` to the end of the loop, and continuing with the next iteration from the start of the loop.

```javascript
obclient> DECLARE
   cnt NUMBER := 0;
BEGIN
    LOOP
       cnt := cnt + 1;
       IF cnt < 4 THEN
         CONTINUE;
       END IF;
    DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
       EXIT WHEN cnt >5;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/
Query OK, 0 rows affected

INSIDE: 4
INSIDE: 5
INSIDE: 6
OUTSIDE: 6
```

## CONTINUE WHEN statement

The `CONTINUE WHEN` statement is also used to exit the current iteration of the loop, but it is executed only when the condition in the `WHEN` clause is `TRUE`.

Here is an example:

```javascript
obclient>DECLARE
   cnt NUMBER := 0;
BEGIN
    LOOP
       cnt := cnt + 1;
       CONTINUE WHEN cnt < 4;
       DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
       EXIT WHEN cnt >5;
     END LOOP;
     DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/
Query OK, 0 rows affected

INSIDE: 4
INSIDE: 5
INSIDE: 6
OUTSIDE: 6
```

## FOR LOOP statement

The `FOR LOOP` statement repeatedly executes a block of code for a range of index values. The syntax is as follows:

```javascript
[ label ] FOR index IN [ REVERSE ] lower_bound..upper_bound LOOP
    statements
END LOOP [ label ];
```

In the following example, without the `REVERSE` clause, the `index` variable starts at `lower_bound` and increments to `upper_bound`. With the `REVERSE` clause, the `index` variable starts at `upper_bound` and decrements to `lower_bound`.

```javascript
obclient> BEGIN
    FOR i IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE (i);
    END LOOP;
END;
/
Query OK, 0 rows affected

1
2
3
4
5

obclient>BEGIN
   FOR i IN REVERSE 1..5  LOOP
      DBMS_OUTPUT.PUT_LINE (i);
   END LOOP;
END;
/
Query OK, 0 rows affected
5
4
3
2
1
```

The index of the `FOR LOOP` statement is implicitly declared as a `PLS_INTEGER` variable local to the loop. Statements within the loop can read the value of the index, but cannot modify it. Statements outside the loop cannot reference the index. After the `FOR LOOP` statement is executed, the index is in an undefined state. The loop index is sometimes referred to as the loop counter.

The upper and lower bounds of the `FOR LOOP` statement can be numeric literals, numeric variables, or numeric expressions. If the bounds do not have numeric values, PL will raise the predefined exception `VALUE_ERROR`.

## WHILE LOOP statement

The `WHILE LOOP` statement is another form of loop control. It repeatedly executes a sequence of statements as long as the condition evaluates to `TRUE`. If the condition evaluates to `FALSE`, the loop exits. The syntax is as follows:

```javascript
[ label ] WHILE condition LOOP
    statements
END LOOP [ label ];
```

The loop continues as long as the `contidion` value is `TRUE`, until the `contidion` value is `FALSE` or `NULL`.

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    WHILE cnt < 3 LOOP
       DBMS_OUTPUT.PUT_LINE (cnt);
       cnt :=  cnt + 1;
    END LOOP;
END;
/
Query OK, 0 rows affected

0
1
2
```
