# Loop control

Loop statements are mainly used to repeatedly execute a set of operations.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

The `LOOP` statement has the following four forms:

* Basic `LOOP`

* `FOR LOOP`

* `FOR LOOP` for cursors

* `WHILE LOOP`

The following two statements are used to exit from the entire loop:

* `EXIT`

* `EXIT WHEN`

The following two statements are used to exit from the current iteration of the loop:

* `CONTINUE`

* `CONTINUE WHEN`

The `EXIT`, `EXIT WHEN`, `CONTINUE`, and `CONTINUE WHEN` statements can be used to exit from a loop. These statements can be placed at any position in the loop. We recommend that you use these statements instead of the `GOTO` statement to exit from a loop. The `EXIT` statement transfers control to the end of the `LOOP` statement. The `CONTINUE` statement exits the current iteration of the loop and transfers control to the start of the next iteration. The `EXIT` and `CONTINUE` statements can be followed by an optional `WHEN` clause, which specifies a condition.

We recommend that you label loops to improve readability, especially when multiple nested loops are used.

## Basic LOOP

The basic `LOOP` statement repeatedly executes a sequence of statements. The syntax of the basic `LOOP` statement is as follows:

```javascript
[ label ] LOOP
    statements
END LOOP [ label ];
```

The `statements` clause specifies the statements to be executed in the loop. To avoid an infinite loop, at least one statement in the `LOOP` and `END LOOP` clauses must contain the `EXIT` statement. Otherwise, the `LOOP` statement will keep executing indefinitely.

The `EXIT` statement can be followed by an optional `WHEN` clause, which specifies a condition. If the condition is `TRUE`, the `EXIT` statement is executed, and control is transferred to the statement after the `END LOOP` statement.

## EXIT statement

The `EXIT` statement is used to unconditionally exit from the current loop.

Here is an example:

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
        cnt := cnt + 1;
        IF cnt > 5 THEN
         EXIT;
        END IF;
     END LOOP;
     DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/
Query OK, 0 rows affected

INSIDE: 2

INSIDE: 5
OUTSIDE: 6
```

## EXIT WHEN statement

The `EXIT WHEN` statement is used to exit from the current loop when the condition specified in the `WHEN` clause is `TRUE`.

Here is an example:

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    LOOP
       DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
       cnt := cnt + 1;
       EXIT WHEN cnt >5;
     END LOOP;
     DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/

```

## CONTINUE statement

The `CONTINUE` statement is used to exit from the current iteration of the loop. That is, the code from the `CONTINUE` statement to the end of the loop is skipped, and the next iteration of the loop starts from the beginning of the loop.

```javascript
obclient> DECLARE
   cnt NUMBER := 0;
BEGIN
    LOOP
       cnt := cnt + 1;
       IF cnt < 4 THEN
         CONTINUE;
       END IF;
    DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
       EXIT WHEN cnt >5;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/
Query OK, 0 rows affected

INSIDE: 4
INSIDE: 5
INSIDE: 6
OUTSIDE: 6
```

## CONTINUE WHEN statement

The `CONTINUE WHEN` statement is also used to exit from the current iteration of the loop. However, it is executed only when the condition specified in the `WHEN` clause is `TRUE`.

Here is an example:

```javascript
obclient>DECLARE
   cnt NUMBER := 0;
BEGIN
    LOOP
       cnt := cnt + 1;
       CONTINUE WHEN cnt < 4;
       DBMS_OUTPUT.PUT_LINE ('INSIDE: ' || TO_CHAR(cnt));
       EXIT WHEN cnt >5;
     END LOOP;
     DBMS_OUTPUT.PUT_LINE('OUTSIDE: ' || TO_CHAR(cnt));
END;
/
Query OK, 0 rows affected

INSIDE: 4
INSIDE: 5
INSIDE: 6
OUTSIDE: 6
```

## FOR LOOP statement

The `FOR LOOP` statement repeatedly executes a set of statements for a range of index values. The syntax is as follows:

```javascript
[ label ] FOR index IN [ REVERSE ] lower_bound..upper_bound LOOP
    statements
END LOOP [ label ];
```

In the following example, if the `REVERSE` clause is not specified, the `index` variable increases from `lower_bound` to `upper_bound`. If the `REVERSE` clause is specified, the `index` variable decreases from `upper_bound` to `lower_bound`.

```javascript
obclient> BEGIN
    FOR i IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE (i);
    END LOOP;
END;
/
Query OK, 0 rows affected

1
2
3
4
5

obclient>BEGIN
   FOR i IN REVERSE 1..5  LOOP
      DBMS_OUTPUT.PUT_LINE (i);
   END LOOP;
END;
/
Query OK, 0 rows affected
5
4
3
2
1
```

The index of the `FOR LOOP` statement is implicitly declared as a local `PLS_INTEGER` variable. The statements in the loop can read the value of the index, but cannot modify it. The statements outside the loop cannot reference the index. After the `FOR LOOP` statement is executed, the index is in an undefined state. The loop index is also known as the loop counter.

The lower and upper bounds of the `FOR LOOP` statement can be numeric literals, numeric variables, or numeric expressions. If the bounds do not have numeric values, the PL compiler raises the predefined exception `VALUE_ERROR`.

## WHILE LOOP statement

The `WHILE LOOP` statement is another form of loop control. It repeatedly executes a sequence of statements as long as the condition specified in the `WHILE` clause is `TRUE`. If the condition is `FALSE`, the loop exits. The syntax is as follows:

```javascript
[ label ] WHILE condition LOOP
    statements
END LOOP [ label ];
```

The loop continues as long as the `contidion` value is `TRUE`, until the `contidion` value becomes `FALSE` or `NULL`.

```javascript
obclient> DECLARE
    cnt NUMBER := 0;
BEGIN
    WHILE cnt < 3 LOOP
       DBMS_OUTPUT.PUT_LINE (cnt);
       cnt :=  cnt + 1;
    END LOOP;
END;
/
Query OK, 0 rows affected

0
1
2
```
