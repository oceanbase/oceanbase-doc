# PL reserved keywords

PL reserved keywords are identifiers with special meanings in PL. They are not case-sensitive.

| Initial letter |                      PL reserved keywords                              |
|-----|----------------------------------------------------------------|
| A   | ALL, ALTER, AND, ANY, AS, ASC, AT                                    |
| B   | BEGIN, BEGIN_KEY, BETWEEN, BY                                     |
| C   | CASE, CHECK, CLUSTER, CLUSTERS, COLAUTH, COLUMNS, COMMIT, COMPRESS, CONNECT, CRASH, CREATE, CURSOR |
| D   | DECLARE, DEFAULT, DELETE, DESC, DISTINCT, DROP                      |
| E   | ELSE, ELSIF, END, END_KEY, EXCEPTION, EXCLUSIVE, EXISTS              |
| F   | FETCH, FOR, FROM, FUNCTION                                        |
| G   | GOTO, GRANT, GROUP                                               |
| H   | HAVING                                                         |
| I   | IDENTIFIED, IF, IN, INDEX, INDEXES, INSERT, INTERSECT, INTO, IS        |
| L   | LIKE, LOCK                                                      |
| M   | MINUS, MODE                                                     |
| N   | NOCOMPRESS, NOT, NOWAIT, NULLX                                    |
| O   | OF, ON, OPTION, OR, ORDER, OVERLAPS                                 |
| P   | PROCEDURE, PUBLIC                                               |
| R   | RESOURCE, RETURN, REVOKE, ROLLBACK                                |
| S   | SAVEPOINT, SELECT, SET, SHARE, SIZE, SQL, SQL_KEYWORD, START, SUBTYPE  |
| T   | TABAUTH, TABLE, THEN, TO                                          |
| U   | UNION, UNIQUE, UPDATE                                            |
| V   | VALUES, VIEW, VIEWS                                              |
| W   | WHEN, WHERE, WHILE, WITH                                          |

## Query keywords

You can also query the `V$OB_KEYWORDS` view for a list of PL keywords for the current tenant. For more information about this view, see [V$OB_KEYWORDS](../../700.system-views/500.system-view-of-oracle-mode/300.performance-view-of-oracle-mode/32110.v-ob-keywords-of-oracle-mode.md).

```sql
obclient> SELECT KEYWORD, RESERVED FROM sys.V$OB_KEYWORDS WHERE TYPE = 'PL' ORDER BY KEYWORD;
```
