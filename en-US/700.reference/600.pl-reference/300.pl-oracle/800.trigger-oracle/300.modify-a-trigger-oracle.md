# Modify and drop triggers

PL/SQL supports modifying and dropping triggers.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Modify a trigger

Currently, you can only use the `REPLACE TRIGGER` statement in DDL statements to modify a trigger.

Typically, you can write the creation and modification of a trigger in the following statement:

```javascript
CREATE OR REPLACE TRIGGER trigger_name ...
```

If the `trigger_name` does not exist, a trigger is created. If the `trigger_name` already exists, the trigger is modified.

## Drop a trigger

You can use the `DROP TRIGGER` statement to drop a trigger. The syntax is as follows:

```javascript
DROP TRIGGER trigger_name;
```

In addition, when you drop a table, any triggers defined on that table are also dropped.
