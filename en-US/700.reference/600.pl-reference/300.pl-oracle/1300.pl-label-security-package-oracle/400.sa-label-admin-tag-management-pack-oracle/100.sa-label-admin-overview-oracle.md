# Overview

The `SA_LABEL_ADMIN` package provides an interface for managing labels used by policies.

To use this PL/SQL package, you must be granted the `EXECUTE` privilege on the `SA_LABEL_ADMIN` package.

The following table lists the contents of the `SA_LABEL_ADMIN` package supported in the current version of OceanBase Database.

|                                  **Procedure**                                  | **Description**  |
|----------------------------------------------------------------------------|---------|
| [SA_LABEL_ADMIN.ALTER_LABEL](../400.sa-label-admin-tag-management-pack-oracle/200.sa-label-admin-alter-label-oracle.md)  | Modifies an existing label. |
| [SA_LABEL_ADMIN.CREATE_LABEL](../400.sa-label-admin-tag-management-pack-oracle/300.sa-label-admin-create-label-oracle.md) | Creates a data label. |
| [SA_LABEL_ADMIN.DROP_LABEL](../400.sa-label-admin-tag-management-pack-oracle/400.sa-label-admin-drop-label-oracle.md)   | Drops a label.   |
