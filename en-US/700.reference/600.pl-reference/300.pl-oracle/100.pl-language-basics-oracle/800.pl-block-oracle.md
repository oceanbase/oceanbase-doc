# PL blocks

A PL program consists of three blocks: the declaration block (`DECLARE`), the execution block (`BEGIN`), and the exception handling block (`EXCEPTION`).

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

The three blocks serve the following purposes:

* Declaration block: In this block, you can declare variables, types, cursors, and local stored procedures and functions used in the PL program.

* Execution block: This block displays the execution process and SQL statements, which are the main part of the program.

* Exception handling block: This block displays error handling.

The syntax of a PL block is as follows:

```sql
<< label >> --Label (optional)
DECLARE
    /* Declaration block: Declare variables, types, cursors, and local stored procedures and functions used in the PL program */
BEGIN
    /* Execution block: The execution process and SQL statements, which are the main part of the program */
EXCEPTION
   /* Exception handling block: Error handling */
END;
```

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The execution block is a required part of a PL block. </p>
  </main>

A PL block can be classified into the following three types:

* Anonymous block: An anonymous block is dynamically constructed and can be executed only once.

* Program: A program is a stored procedure, function, or package stored in the database. After a program is created in the database, it can be called by other programs.

* Trigger: A trigger is an event that is automatically executed when a specified operation is performed on the database.

Example: The following anonymous block prints "Hello World" to the screen.

```sql
obclient> DECLARE
        V_Str varchar(20) := 'World';
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Hello '||V_Str);
    END;
    /
Query OK, 0 rows affected (0.01 sec)

Hello World
```

The default delimiter of a PL block is "/". You can use the delimiter command to customize the delimiter so that the entire definition can be passed to the server as a single statement. The delimiter can consist of one or more characters. Avoid using the backslash (\) character, which is generally used as an escape character. Here is an example:

```sql
DELIMITER $$
DELIMITER //
```
