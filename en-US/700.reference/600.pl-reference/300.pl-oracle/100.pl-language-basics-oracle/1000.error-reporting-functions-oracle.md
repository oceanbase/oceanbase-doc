# Error reporting functions

PL/SQL supports two error reporting functions, `SQLCODE` and `SQLERRM`, which can be used in exception handling code.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature.</p>
  </main>

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You cannot use the <code>SQLCODE</code> and <code>SQLERRM</code> functions in SQL statements.</p>
  </main>

## SQLCODE function

In an exception handler, the `SQLCODE` function returns the error code corresponding to the exception being handled. (Outside an exception handler, `SQLCODE` always returns 0.)

For internally defined exceptions, the numeric code is associated with the database error number.

For user-defined exceptions, the numeric code is `+1` (the default) or the error code associated with the exception specified in the `EXCEPTION_INIT` compilation directive.

Syntax:

```sql
SQLCODE
```

## SQLERRM function

The `SQLERRM` function returns the error message associated with the error code.

Syntax:

```sql
SQLERRM [ ( error_code ) ]
```

In this syntax, the `error_code` parameter is optional. If no parameter is provided, the function returns the error message corresponding to the current `SQLCODE`.
