# Large object data types

Large object data types (LOBs) are used to store large, unstructured data such as text, images, video, and spatial data. Large object data types include `BLOB` and `CLOB`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## BLOB

`BLOB` is used to store large binary objects in the database. It can be considered as a stream of bits without character set semantics, such as images and videos.

## CLOB

`CLOB` is used to store single-byte and multi-byte character data. It supports both fixed-width and variable-width character sets, and both use the database character set.
