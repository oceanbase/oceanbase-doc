# READ_CLIENT_INFO

The `READ_CLIENT_INFO` procedure is used to read the value of the `client_info` field for the current session.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_APPLICATION_INFO.READ_CLIENT_INFO (
   client_info OUT VARCHAR2);
```

## Parameters

The `client_info` parameter is used to provide the latest client information value to the `SET_CLIENT_INFO` procedure.

## Examples

```sql
DECLARE
    myclient VARCHAR2(50);
    mymodule VARCHAR2(50);
    myaction VARCHAR2(50);

   BEGIN
      DBMS_APPLICATION_INFO.SET_CLIENT_INFO('OBClient');
      DBMS_APPLICATION_INFO.READ_CLIENT_INFO(myclient);
      DBMS_OUTPUT.PUT_LINE ('client='||myclient);
      DBMS_APPLICATION_INFO.SET_MODULE('OBmodule','inserting');
      DBMS_APPLICATION_INFO.READ_MODULE(mymodule,myaction);
      DBMS_OUTPUT.PUT_LINE('mod_name='||mymodule);
      DBMS_OUTPUT.PUT_LINE('act_name='||myaction);
   END;
client=OBClient
mod_name=OBmodule
act_name=inserting
```
