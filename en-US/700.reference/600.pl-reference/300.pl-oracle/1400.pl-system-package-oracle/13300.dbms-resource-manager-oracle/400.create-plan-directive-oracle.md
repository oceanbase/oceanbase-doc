# CREATE_PLAN_DIRECTIVE

The `CREATE_PLAN_DIRECTIVE` procedure is used to create a plan directive.

  <main id="notice" >
    <h4>Functionality applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature.</p>
  </main>

## Syntax

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE (
    PLAN                      IN VARCHAR2,
    GROUP_OR_SUBPLAN          IN VARCHAR2,
    COMMENT                   IN VARCHAR2 DEFAULT'',
    MGMT_P1                   IN NUMBER   DEFAULT 100,
    UTILIZATION_LIMIT         IN NUMBER   DEFAULT 100,
    MIN_IOPS                  IN NUMBER   DEFAULT 0,
    MAX_IOPS                  IN NUMBER   DEFAULT 100,
    WEIGHT_IOPS               IN NUMBER   DEFAULT 0,
    MAX_NET_BANDWIDTH         IN INT DEFAULT 100,
    NET_BANDWIDTH_WEIGHT      IN INT DEFAULT 0);
```

## Parameters

|    Parameter     |        Description         |
|-------------------|--------------------------|
| plan              | The name of the resource plan. |
| group_or_subplan  | The name of the resource usage group or subplan.    |
| comment           | The comment on the plan directive.   |
| mgmt_p1           | Specifies the relative maximum CPU usage under system overload. |
| utilization_limit | The upper limit of the CPU resource utilization. The value of this parameter ranges from 0 to 100. When the value is 100, the maximum available CPU resources in the tenant are used. When the value is 20, the maximum available CPU resources in the tenant are 20%. |
| MIN_IOPS | The percentage of IOPS resources reserved for resource groups. The sum of the `MIN_IOPS` values of all resource groups cannot exceed 100. The default value is 0. |
| MAX_IOPS |  The maximum IOPS value for resources. The sum of the `MAX_IOPS` values of all resource groups can exceed 100. The default value is 100. |
| WEIGHT_IOPS | IOPS resource weight when I/O resources are being contended. The total of `WEIGHT_IOPS` across all resource groups can exceed 100 and will be normalized. The default is 0. |
| MAX_NET_BANDWIDTH | Specifies the maximum amount of network bandwidth resource available. The sum can exceed 100, with a default value of `100`. |
| NET_BANDWIDTH_WEIGHT | Specifies the weight of network bandwidth. The total weight can exceed 100, and the weights are distributed proportionally. The default value is `0`.|

## Examples

* Bind resource group `group1` to the resource plan `DAY` and specify CPU resource plan commands for the resource group.

  ```shell
  obclient [SYS]> delimiter //
  ```

  ```shell
  obclient> BEGIN DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE(
      PLAN=>'DAY',
      GROUP_OR_SUBPLAN=>'group1',
      mgmt_p1=>80,
      utilization_limit=>100);
      END; //
  ```

  ```shell
  obclient [SYS]> delimiter ;
  ```

* Bind the `plan_a` resource plan to the `big_group` resource group and specify resource directives such as CPU, IOPS, and network bandwidth.

  ```shell
  obclient [SYS]> delimiter //
  ```

  ```shell
      obclient [SYS]> BEGIN DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE(
      PLAN => 'plan_a',
      GROUP_OR_SUBPLAN => 'big_group',
      COMMENT => 'TP priority',
      UTILIZATION_LIMIT =>60,
      MIN_IOPS => 20,
      MAX_IOPS => 100,
      WEIGHT_IOPS => 20,
      MAX_NET_BANDWIDTH => 50,
      NET_BANDWIDTH_WEIGHT =>50);
      END; //
  ```

  ```shell
  obclient [SYS]> delimiter ;
  ```
