# CREATE_PLAN

The `CREATE_PLAN` procedure is used to create a resource plan.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN (
    plan          IN   VARCHAR2,
    comment       IN   VARCHAR2 DEFAULT'');
```

## Parameters

|   Parameter    |    Description    |
|---------|----------|
| plan    | The name of the resource plan. |
| comment | User comments.    |

## Examples

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('DAY','This resource plan is used for transaction processing');
Query OK, 0 rows affected

obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('NIGHT','This resource plan is used for daily maintenance');
Query OK, 0 rows affected
```
