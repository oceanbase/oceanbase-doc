# DISPLAY

The `DISPLAY` function is used to query and format historical `EXPLAIN` plans.

  <main id="notice">
  <h4>Applicability</h4>
  <p>Available from V4.2.5 of the Community Edition. </p>
  </main>

## Syntax

```sql
TYPE DBMS_XPLAN_TYPE_TABLE IS TABLE OF VARCHAR2(4000);

DBMS_XPLAN.DISPLAY(format VARCHAR2 DEFAULT 'TYPICAL',
                  statement_id VARCHAR2 DEFAULT null,
                  table_name   VARCHAR2 DEFAULT 'PLAN_TABLE',
                  filter_preds VARCHAR2 DEFAULT null)
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## Parameters

| Parameter | Description |
| --- | --- |
| format | The plan format. Valid values: <ul><li>`'BASIC'`: displays basic information such as operator ID, operator name, operator remarks, and expression information. </li><li>`'TYPICAL'`: displays basic information such as operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression information. If the plan has been executed, it also displays the actual feedback information from the first execution, such as actual rows and cost. </li><li>`'ALL'`: displays comprehensive plan information such as operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression information, along with effective hints, query block name trace information, outline information, base table optimization information, constant parameterization information, constraint information, and plan notes. </li><li>`'ADVANCED'`: displays comprehensive plan information similar to the 'ALL' parameter. Additionally, it provides tree-structured information for complex plans. </li></ul>|
| statement_id | The statement ID for the `EXPLAIN` query. You can set the statement ID by using the `EXPLAIN SET STATEMENT_ID='XXX'` command. |
| table_name | The target table for saving the `EXPLAIN` plan. The default value is `PLAN_TABLE`. |
| filter_preds | Additional filter conditions for the `PLAN_TABLE`, used to filter specific operators or plans. |
