# DISPLAY_ACTIVE_SESSION_PLAN

The `DISPLAY_ACTIVE_SESSION_PLAN` function is used to display the real-time plan details of a specified session.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL-compatible mode. </p>
  </main>

## Function definition

```sql
DBMS_XPLAN.DISPLAY_ACTIVE_SESSION_PLAN(
           session_id   INTEGER DEFAULT 0,
           format       VARCHAR2  DEFAULT  'TYPICAL',
           svr_ip       VARCHAR2  DEFAULT  NULL,      -- default value: server connected by client
           svr_port     INTEGER DEFAULT 0           -- default value: server connected by client
           )
return DISPLAY_ACTIVE_SESSION_PLAN;
```

## Parameters

| Parameter | Description |
| --- | --- |
| session_id | The session ID of the user. This is the session ID of the server, not the proxy session ID. |
| format | The plan format. Valid values: <ul><li>`'BASIC'`: displays minimal information, such as the operator ID, operator name, operator remarks, and expression. </li><li>`'TYPICAL'`: displays basic information, such as the operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression. If the plan has been executed, it also displays the actual feedback information from the first execution, such as the actual number of rows and cost. </li><li>`'ALL'`: displays rich plan information, such as the operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression. It also displays the effective hint, query block name trace, outline, base table optimization, constant parameterization, constraint, and plan note. </li><li>`'ADVANCED'`: displays rich plan information, such as the operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression. It also displays the effective hint, query block name trace, outline, base table optimization, constant parameterization, constraint, and plan note. For complex plans, it displays the tree structure. </li></ul> |
| svr_ip | The IP address of the node where the plan is located. The default value is the IP address of the node to which the session is connected. |
| svr_port | The port number of the node where the plan is located. The default value is the port number of the node to which the session is connected. |
