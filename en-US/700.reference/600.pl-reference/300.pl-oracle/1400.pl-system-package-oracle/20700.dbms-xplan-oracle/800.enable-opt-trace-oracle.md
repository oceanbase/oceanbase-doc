# ENABLE_OPT_TRACE

The `ENABLE_OPT_TRACE` procedure is used to enable optimizer full-link tracing. Once enabled, the tracing process will track the plan generation for each SQL statement in the current session, including those within PL/SQL blocks, and generate a trace file in the execution node's log directory.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This content is applicable only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DEFAULT_INENTIFIER  constant VARCHAR2(20) := '';
DEFAULT_LEVEL       constant INT := 1;

DBMS_XPLAN.ENABLE_OPT_TRACE(
    sql_id          IN VARCHAR2 DEFAULT '',
    identifier      IN VARCHAR2 DEFAULT DEFAULT_INENTIFIER,
    level           IN INT DEFAULT DEFAULT_LEVEL
);
```

## Parameters

| Parameter | Description |
| --- | --- |
| sql_id | Used to mark the SQL statement to be traced. For example, if you need to run a PL/SQL program and only trace specific SQL statements within the PL/SQL functions, you can set the `sql_id` parameter. Once set, only the specified SQL statements will be traced; otherwise, all SQL statements will be traced. |
| identifier | Used to mark the suffix of the trace file, making it easier for users to locate their trace files. |
| level | Used to set the tracing level: <ul> <li> 0: Default behavior. </li> <li> 1: Additional printing of memory and time used by each module. </li> <li> 2: Additional printing of each rewritten query block's corresponding SQL, regardless of whether it was rewritten. </li></ul> <br> **Note**: `level` is a database keyword. In Oracle tenants, it must be enclosed in double quotes (" "), while in MySQL tenants, it must be enclosed in backticks (` ). |

## Examples

```shell
/* Connect to the database and enable optimizer tracing for the current session */
obclient> CALL DBMS_XPLAN.ENABLE_OPT_TRACE();
Query OK, 0 rows affected

/* Set the trace level and log file suffix */
obclient> CALL DBMS_XPLAN.SET_OPT_TRACE_PARAMETER(identifier=>'trace_test', "level"=>3);
Query OK, 0 rows affected

/* Execute a query */
obclient> SELECT * FROM t1;
Empty set

/* View the trace log with the 'trace_test' suffix in the OBServer node's log directory */
vi /data/1/observer/log/optimizer_trace_BkkGn1_trace_test.trac

/* Disable optimizer tracing for the current session */
obclient> CALL DBMS_XPLAN.DISABLE_OPT_TRACE();;
Query OK, 0 rows affected
```
