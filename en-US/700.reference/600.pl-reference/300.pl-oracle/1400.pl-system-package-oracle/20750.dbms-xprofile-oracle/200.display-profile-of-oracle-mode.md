# DISPLAY_PROFILE

The `DISPLAY_PROFILE` procedure is used to display the performance analysis data of an SQL execution plan and view the diagnostic information at the operator level for the specified `trace_id`.

## Syntax

```sql
DBMS_XPROFILE.DISPLAY_PROFILE(
    trace_id    varchar2 default null,
    tenant_id   integer default 0,
    format      varchar2 default 'AGGREGATED',
    level       integer default 1,
    svr_ip      varchar2 default null,
    svr_port    integer default 0,
    op_id       integer default null
    )
```

## Parameters

| **Parameter**  | **Description** |
|-----------|----------|
| trace_id  | Optional. Specifies the trace id. If omitted, set to `null`, or set to an empty string, the last trace id of the current session is used. |
| tenant_id | Optional. Specifies the tenant ID. If omitted or set to 0, the current tenant ID is used. For user tenants, if a tenant ID other than the system tenant is specified, the result will be empty. |
| format    | Optional. Specifies the display format. Valid values:<ul><li>`AGGREGATED`: Default value. Displays the aggregated profile.</li><li>`ORIGINAL`: Displays the thread-level profile before aggregation.</li></ul>|
| level     | Optional. Specifies the output level. Each metric has its own level, and metrics with a level higher than the specified level will not be displayed. Valid values:<ul><li>0: Core metrics that are always output, such as row output and dbtime.</li><li>1: Default value. Standard metrics that are commonly used can be set to this level.</li><li>2: Diagnostic metrics used for troubleshooting or further analysis. These metrics are not commonly used and output a large amount of information.</li></ul>|
| svr_ip    | Optional. Filters to display only the profile for the specified IP address. The default value is `null`, which means all profiles are displayed. |
| svr_port  | Optional. Filters to display only the profile for the specified port. The default value is 0, which means all profiles are displayed. |
| op_id     | Optional. Filters to display only the profile for the operator with the specified ID. The default value is `null`, which means all profiles are displayed. |

## Examples

* Query the profile of another tenant in the sys tenant.

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC2E689814-0-0', tenant_id);
    ```

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Only the sys tenant can query the profile of other tenants, and the <code>tenant_id</code> must be specified. </p>
    </main>

* Query the profile of the user tenant (Oracle mode).

    ```shell
    obclient> SELECT * FROM TABLE(DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC2E689814-0-0'));
    ```
