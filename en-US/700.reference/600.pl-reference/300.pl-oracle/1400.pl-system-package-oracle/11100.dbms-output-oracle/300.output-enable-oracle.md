# ENABLE

The `ENABLE` procedure allows calls to the PUT, PUT_LINE, NEW_LINE, and GET_LINE procedures.

If the DBMS_OUTPUT package is not activated, calls to these procedures will be ignored.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_OUTPUT.ENABLE (
buffer_size IN INTEGER DEFAULT 20000);
```

## Parameters

|     Parameter      |                        Description                         |
|-------------|---------------------------------------------------|
| buffer_size | The maximum size of the buffer (in bytes).<ul><li>`enable(null)`: No limit.</li><li>`enable()`: Use the default value, which is 20000. If you specify a numeric value for `buffer_size`, the value must be in the range [2000, 1000000].|

## Considerations

* If you use the `SET SERVEROUTPUT` option of the OBClient, you do not need to call this procedure.

* If multiple `ENABLE` procedures are called, the `buffer_size` value specified last is used. When you specify `buffer_size` (NOT NULL), the maximum value is 1,000,000, and the minimum value is 2,000.

* Usually, it is set to NULL. The default value is 20,000, which is backward compatible with earlier database versions that do not support unlimited buffering.
