# NEW_LINE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/NEW_LINE
The `NEW_LINE` procedure is used to place a line break.

The `GET_LINE` procedure returns a line separated by a line break. Each call to the `PUT_LINE` or `NEW_LINE` procedure generates a line that is returned by the `GET_LINE` procedure.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_OUTPUT.NEW_LINE;
```
