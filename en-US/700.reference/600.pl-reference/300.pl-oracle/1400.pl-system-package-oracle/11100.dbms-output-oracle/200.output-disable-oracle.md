# DISABLE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/DISABLE
The `DISABLE` procedure disables calls to the PUT, PUT_LINE, NEW_LINE, and GET_LINE procedures and clears all remaining information in the buffer.

Like the `ENABLE` procedure, if you use the `SERVEROUTPUT` option of OBClient, you do not need to call this procedure.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_OUTPUT.DISABLE;
```
