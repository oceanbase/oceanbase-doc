# GET_LINE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/GET_LINE
The `GET_LINE` procedure is used to retrieve buffered information for a single line.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This section applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support the feature described in this section. </p>
  </main>

## Syntax

```sql
DBMS_OUTPUT.GET_LINE (
line    OUT VARCHAR2,
status  OUT INTEGER);
```

## Parameters

| **Parameter** | **Description**                                  |
|--------|---------------------------------------------------------------------------|
| line | Returns the buffer information of one line, excluding the last newline character. The value of this parameter is of the VARCHAR2 type. The size of the VARCHAR2 value must be at least 32767 to avoid an error. |
| status | The status returns 0 if the procedure was successful. If no more rows are in the buffer, the status is 1.             |

## Considerations

You can retrieve one line or a line array from the buffer. To retrieve the buffered information for a single line, you can call the GET_LINE procedure. To retrieve an array of lines from the buffer while minimizing server calls, you can call the GET_LINES procedure.

* If you use OBClient, you can use the special `SET SERVEROUTPUT ON` command to automatically display the information.

* Rows that were not retrieved after a call to GET_LINE are available for retrieval during the next call to PUT, PUT_LINE, or NEW_LINE.

  The previously discarded information is retained to avoid confusion with future information.
