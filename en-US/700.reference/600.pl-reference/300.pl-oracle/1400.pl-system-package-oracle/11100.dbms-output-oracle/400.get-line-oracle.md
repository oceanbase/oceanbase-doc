# GET_LINE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/GET_LINE
The GET_LINE procedure retrieves buffer information about a specified line.

  <main id="notice" >
    <h4>Applies to</h4>
    <p>It applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this statement.</p>
  </main>

## Syntax

```sql
DBMS_OUTPUT.GET_LINE (
line    OUT VARCHAR2,
status  OUT INTEGER);
```

## Parameters

| **Parameter** |                                  **Description**                                   |
|--------|---------------------------------------------------------------------------|
| line | Returns a line of buffer information without the trailing newline character. This parameter is of the VARCHAR2 type and must be at least 32767 in size to avoid errors. |
| status | The return value is 0 if the procedure is successfully completed. If no more rows remain in the buffer, the return value is 1. |

## Considerations

* You can choose to retrieve a single row or an array of rows from the buffer. Call the GET_LINE procedure to retrieve information about a single row buffer. To reduce the number of calls to the server, call the GET_LINES procedure to retrieve an array of rows from the buffer.

* If you use OBClient, you can use the special `SET SERVEROUTPUT ON` command to display this information automatically.

* After the GET_LINE procedure is called, any lines not fetched will be available for the next call to PUT, PUT_LINE, or NEW_LINE.

  These are discarded to avoid confusion with information in the future.
