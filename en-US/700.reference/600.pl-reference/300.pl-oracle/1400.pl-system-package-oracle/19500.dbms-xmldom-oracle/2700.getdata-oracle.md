# GETDATA

The `GETDATA` function is used to obtain the text content within a DOM character data node, such as those of the `DOMCHARACTERDATA` or `DOMTEXT` types.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.getData (
   cd IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| cd | Character data node`DBMS_XMLDOM.DOMCHARACTERDATA`Handle. |

## Return value

Character data content, of type `VARCHAR2`.

## Usage instructions

If you hold a generic `DOMNODE`, you must first convert it to a `DOMCHARACTERDATA` using `MAKECHARACTERDATA` before calling this function.

## Examples

```sql
DECLARE
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
  data           VARCHAR2(32767);
BEGIN
  data := DBMS_XMLDOM.getData(character_data);
END;
/
```
