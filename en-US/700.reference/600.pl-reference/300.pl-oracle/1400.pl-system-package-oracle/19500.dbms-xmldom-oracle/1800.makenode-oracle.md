# MAKENODE

The `MAKENODE` function is used to convert specific DOM objects such as `DOMDOCUMENT`, `DOMELEMENT`, `DOMTEXT`, `DOMATTR`, and `DOMCHARACTERDATA` into a generic `DOMNODE` handle, facilitating unified use with node-level interfaces such as `APPENDCHILD`, `REMOVECHILD`, and `GETNODENAME`.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.makeNode (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);

DBMS_XMLDOM.makeNode (
   elem IN DBMS_XMLDOM.DOMELEMENT);

DBMS_XMLDOM.makeNode (
   text IN DBMS_XMLDOM.DOMTEXT);

DBMS_XMLDOM.makeNode (
   attr IN DBMS_XMLDOM.DOMATTR);

DBMS_XMLDOM.makeNode (
   character_data IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| doc / elem / text / attr / character_data | The handle of the specific DOM object to be converted. |

## Return value

A generic node handle of `DBMS_XMLDOM.DOMNODE`.

## Usage instructions

The different overloads accept document, element, text, attribute, or character data handlers and return a unified `DOMNODE`, facilitating subsequent node-level operations.

## Examples

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
  node DBMS_XMLDOM.DOMNODE;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  node := DBMS_XMLDOM.makeNode(elem);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
