# FREEDOCUMENT

The `FREEDOCUMENT` procedure releases a `DOMDOCUMENT` obtained through methods such as `GETDOCUMENT`, along with its associated DOM resources. After release, do not use the document handle or any references derived from it to avoid dangling references.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP2.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.freeDocument (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);
```

## Parameters

| **Parameter** | **Description** |
|----------|----------|
| doc | The `DBMS_XMLDOM.DOMDOCUMENT` handle to release. |

## Return value

None.

## Considerations

After the document is released, the application should avoid continuing to use that handle or any `DBMS_XMLDOM.DOMNODE` or `DBMS_XMLDOM.DOMNODELIST` references derived from it to prevent dangling access.
