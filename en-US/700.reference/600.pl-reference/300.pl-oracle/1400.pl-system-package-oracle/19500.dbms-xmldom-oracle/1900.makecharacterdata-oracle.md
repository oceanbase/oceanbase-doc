# MAKECHARACTERDATA

The `MAKECHARACTERDATA` function is used to convert a generic DOM node into a character data node handle, which can then be used with `GETDATA` to retrieve the character content within the node.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.makeCharacterData (
   node IN DBMS_XMLDOM.DOMNODE);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| node | To be converted`DBMS_XMLDOM.DOMNODE`Handle. |

## Return value

Handle of the `DBMS_XMLDOM.DOMCHARACTERDATA` character data node.

## Usage instructions

The conversion is meaningful only if the node itself is a character data node (such as a text node). After conversion, you can use `GETDATA` to read the content.

## Examples

```sql
DECLARE
  doc            DBMS_XMLDOM.DOMDOCUMENT;
  text           DBMS_XMLDOM.DOMTEXT;
  node           DBMS_XMLDOM.DOMNODE;
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  text := DBMS_XMLDOM.createTextNode(doc, 'hello');
  node := DBMS_XMLDOM.makeNode(text);
  character_data := DBMS_XMLDOM.makeCharacterData(node);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
