# WRITETOBUFFER

The `WRITETOBUFFER` procedure serializes a DOM document or DOM node and writes it to a `VARCHAR2` buffer, facilitating further processing or returning the XML text in PL/SQL.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.writeToBuffer (
   doc    IN DBMS_XMLDOM.DOMDOCUMENT,
   buffer IN OUT VARCHAR2);

DBMS_XMLDOM.writeToBuffer (
   n      IN DBMS_XMLDOM.DOMNODE,
   buffer IN OUT VARCHAR2);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| doc / n | To be serialized`DOMDOCUMENT`or`DOMNODE`Handle. |
| buffer | Used to receive the serialized result.`VARCHAR2`Buffer (`IN OUT`). |

## Return value

No return value; the result is written to `buffer`.

## Usage instructions

When the XML content may exceed the length limit of `VARCHAR2`, use `WRITETOCLOB` instead.

## Examples

```sql
DECLARE
  doc    DBMS_XMLDOM.DOMDOCUMENT;
  buffer VARCHAR2(32767);
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.writeToBuffer(doc, buffer);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
