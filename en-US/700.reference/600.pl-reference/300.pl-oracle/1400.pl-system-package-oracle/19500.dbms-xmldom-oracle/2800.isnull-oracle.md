# ISNULL

The `ISNULL` function is used to determine whether a DOM handle is null. It is commonly used to check for null values in return results from interfaces such as `GETFIRSTCHILD`, `GETDOCUMENTELEMENT`, and `MAKENODE`.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.isNull (
   n IN DBMS_XMLDOM.DOMNODE);

DBMS_XMLDOM.isNull (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);

DBMS_XMLDOM.isNull (
   elem IN DBMS_XMLDOM.DOMELEMENT);

DBMS_XMLDOM.isNull (
   text IN DBMS_XMLDOM.DOMTEXT);

DBMS_XMLDOM.isNull (
   attr IN DBMS_XMLDOM.DOMATTR);

DBMS_XMLDOM.isNull (
   character_data IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| n / doc / elem / text / attr / character_data | The DOM handle to be checked. |

## Return value

If the handle is null, `TRUE` is returned; otherwise, `FALSE` is returned.

## Usage instructions

The different overloads accept various DOM handles; it is recommended to call this function first to check for null values before proceeding to access the node.

## Examples

```sql
DECLARE
  n       DBMS_XMLDOM.DOMNODE;
  is_null BOOLEAN;
BEGIN
  is_null := DBMS_XMLDOM.isNull(n);
END;
/
```
