# WRITETOCLOB

The `WRITETOCLOB` procedure serializes a DOM document or DOM node and writes it to a `CLOB`, making it suitable for XML content that exceeds the length limit of `VARCHAR2`.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.writeToClob (
   doc  IN DBMS_XMLDOM.DOMDOCUMENT,
   clob IN OUT CLOB);

DBMS_XMLDOM.writeToClob (
   n    IN DBMS_XMLDOM.DOMNODE,
   clob IN OUT CLOB);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| doc / n | To be serialized`DOMDOCUMENT`or`DOMNODE`Handle. |
| clob | Used to receive the serialized result.`CLOB`(`IN OUT`). |

## Return value

No return value; the result is written to `clob`.

## Usage instructions

Before calling this function, you usually need to create a temporary `CLOB` using `DBMS_LOB.CREATETEMPORARY`; release it when no longer needed.

## Examples

```sql
DECLARE
  doc         DBMS_XMLDOM.DOMDOCUMENT;
  clob_buffer CLOB;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_LOB.createtemporary(clob_buffer, TRUE);
  DBMS_XMLDOM.writeToClob(doc, clob_buffer);
  DBMS_LOB.freetemporary(clob_buffer);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
