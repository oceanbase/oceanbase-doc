# DOMELEMENT

`DOMELEMENT` represents a DOM element node handle type, used to denote an XML element. It can serve as the return value or input parameter for interfaces such as `CREATEELEMENT`, `GETDOCUMENTELEMENT`, and `SETATTRIBUTE`. This handle itself is opaque and is only used for passing data into/out of DOM-related APIs; its internal structure cannot be directly accessed.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this type is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
elem DBMS_XMLDOM.DOMELEMENT;
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| elem | Element node handle. |

## Return value

Element node handle.

## Usage instructions

`DOMELEMENT` is typically returned by [CREATEELEMENT](1600.createelement-oracle.md) or [GETDOCUMENTELEMENT](2300.getdocumentelement-oracle.md); it can be converted into a generic `DOMNODE` using [MAKENODE](1800.makenode-oracle.md).

## Examples

```sql
DECLARE
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  NULL;
END;
/
```
