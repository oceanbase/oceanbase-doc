# DOMNODELIST

`DOMNODELIST` is a handle to an ordered collection of nodes, returned by methods such as `GETCHILDNODES` and `GETELEMENTSBYTAGNAME`. You can use `GETLENGTH` to obtain the number of nodes, and then access individual nodes by index using `ITEM`. This handle is opaque.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this type is available starting with OceanBase Database V4.4.2 BP2.</p>
</main>

## Syntax

```sql
nodelist DBMS_XMLDOM.DOMNODELIST;
```

## Parameters

| **Parameter** | **Description** |
| ---------- | ---------- |
| nodelist | Node list handle. |

## Return value

Node list handle.

## Considerations

`DOMNODELIST` represents a sequence of `DOMNODE` references. When traversing, first call [GETLENGTH](../19500.dbms-xmldom-oracle/800.getlength-xmldom-oracle.md) to obtain the length, then use [ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) to access elements by index to prevent out-of-bounds errors.
