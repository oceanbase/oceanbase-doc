# DOMCHARACTERDATA

`DOMCHARACTERDATA` represents the handle type for DOM character data nodes, used for unified processing of character data nodes such as text and CDATA. It can be used with `GETDATA` to retrieve the character content. This handle itself is opaque and is only used for input/output to DOM-related APIs; its internal structure cannot be directly accessed.

  <h4>Applicability</h4>

<main id="notice" type='explain'>

## Syntax

```sql
character_data DBMS_XMLDOM.DOMCHARACTERDATA;
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| character_data | Character data node handle. |

## Return value

Character data node handle.

## Usage instructions

`DOMCHARACTERDATA` is typically obtained by converting a generic `DOMNODE` using [MAKECHARACTERDATA](1900.makecharacterdata-oracle.md); the text content can be read using [GETDATA](2700.getdata-oracle.md).

```sql
DECLARE
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;

  NULL;
```
