# GETNODENAME

The `GETNODENAME` function is used to obtain the node name of a specified DOM node. Element nodes return the element name, attribute nodes return the attribute name, and text nodes return the corresponding node name according to Oracle DOM semantics.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.getNodeName (
   n IN DBMS_XMLDOM.DOMNODE);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| n | To query the`DBMS_XMLDOM.DOMNODE`Handle. |

## Return value

Node name, of type `VARCHAR2`.

## Usage instructions

For elements with a namespace prefix, the return value can include the prefix. If only the local name is needed, use `GETLOCALNAME`.

## Examples

```sql
DECLARE
  n         DBMS_XMLDOM.DOMNODE;
  node_name VARCHAR2(32767);
BEGIN
  node_name := DBMS_XMLDOM.getNodeName(n);
END;
/
```
