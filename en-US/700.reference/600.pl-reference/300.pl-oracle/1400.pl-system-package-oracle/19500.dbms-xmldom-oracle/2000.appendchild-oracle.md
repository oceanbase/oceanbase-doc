# APPENDCHILD

The `APPENDCHILD` function is used to append a child node `newchild` under a specified parent node `n`, for constructing or modifying the DOM tree structure. A typical scenario is to create nodes using `CREATEELEMENT` or `CREATETEXTNODE` and then mount them under the document's root node or another element node.

## Syntax

```sql
DBMS_XMLDOM.appendChild (
   n        IN DBMS_XMLDOM.DOMNODE,
   newchild IN DBMS_XMLDOM.DOMNODE);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| n | Parent Node`DBMS_XMLDOM.DOMNODE`Handle. |
| newchild | Child node to be appended`DBMS_XMLDOM.DOMNODE`Handle. |

## Return value

The handle of the appended child node (`DBMS_XMLDOM.DOMNODE`).

## Usage instructions

Both the parent and child nodes must be valid `DOMNODE` objects. Specific types such as elements and text must first be converted using `MAKENODE`.

## Examples

```sql
DECLARE
  doc        DBMS_XMLDOM.DOMDOCUMENT;
  root_elem  DBMS_XMLDOM.DOMELEMENT;
  child_elem DBMS_XMLDOM.DOMELEMENT;
  root_node  DBMS_XMLDOM.DOMNODE;
  child_node DBMS_XMLDOM.DOMNODE;
  ret_node   DBMS_XMLDOM.DOMNODE;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  root_elem := DBMS_XMLDOM.createElement(doc, 'root');
  child_elem := DBMS_XMLDOM.createElement(doc, 'item');
  root_node := DBMS_XMLDOM.makeNode(root_elem);
  child_node := DBMS_XMLDOM.makeNode(child_elem);
  ret_node := DBMS_XMLDOM.appendChild(root_node, child_node);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
