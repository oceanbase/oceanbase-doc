# SETVERSION

The `SETVERSION` procedure is used to set the XML version information for a DOM document. The common value is `1.0`, which is used for subsequent document serialization.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.setVersion (
   doc     IN DBMS_XMLDOM.DOMDOCUMENT,
   version IN VARCHAR2);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| doc | Target`DBMS_XMLDOM.DOMDOCUMENT`Handle. |
| version | XML version number, for example,`1.0`. |

## Return value

No return value.

## Usage instructions

It is usually set before calling the `WRITETOBUFFER` or `WRITETOCLOB` serialization.

## Examples

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.setVersion(doc, '1.0');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
