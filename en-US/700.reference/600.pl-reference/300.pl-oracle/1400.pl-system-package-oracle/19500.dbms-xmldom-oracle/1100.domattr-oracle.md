# DOMATTR

`DOMATTR` represents the DOM attribute node handle type, used to carry return values or input parameters for operations related to XML element attributes. This handle itself is opaque and is only used for passing data into/out of DOM-related APIs; its internal structure cannot be directly accessed.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this type is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
attr DBMS_XMLDOM.DOMATTR;
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| attr | Attribute node handle. |

## Return value

Attribute node handle.

## Usage instructions

`DOMATTR` is typically used as a return value or input parameter for attribute-related interfaces. It can be converted into the generic `DOMNODE` using [MAKENODE](1800.makenode-oracle.md).

## Examples

```sql
DECLARE
  attr DBMS_XMLDOM.DOMATTR;
BEGIN
  NULL;
END;
/
```
