# SETATTRIBUTE

The `SET ATTRIBUTE` procedure is used to set an attribute for a DOM element. If the attribute does not exist, it is added; if the attribute already exists, its value is updated.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.setAttribute (
   elem  IN DBMS_XMLDOM.DOMELEMENT,
   name  IN VARCHAR2,
   value IN VARCHAR2);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| elem | Target`DBMS_XMLDOM.DOMELEMENT`Handle. |
| name | Attribute name. |
| value | Attribute value. |

## Return value

No return value.

## Usage instructions

If you perform this procedure on an existing attribute with the same name, the original value will be overwritten.

## Examples

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  DBMS_XMLDOM.setAttribute(elem, 'id', '1001');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
