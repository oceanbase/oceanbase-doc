# DOMTEXT

`DOMTEXT` indicates the handle type for a DOM text node, representing an XML text node. It can be created using `CREATE TEXT NODE` and converted into a generic `DOMNODE` using `MAKE NODE`. This handle itself is opaque and is used only for input/output to DOM-related APIs; its internal structure cannot be directly accessed.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>

## Syntax

```sql
text DBMS_XMLDOM.DOMTEXT;
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| text | Text node handle. |

## Return value

Text node handle.

## Usage instructions

`DOMTEXT` nodes are typically created using [CREATETEXTNODE](1700.createtextnode-oracle.md). They can be converted into a generic `DOMNODE` using [MAKENODE](1800.makenode-oracle.md) for further node-level operations.

## Examples

```sql
DECLARE
  text DBMS_XMLDOM.DOMTEXT;
BEGIN
  NULL;
END;
/
```
