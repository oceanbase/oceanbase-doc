# REMOVECHILD

The `REMOVECHILD` function is used to remove a specified child node `oldchild` from its parent node `n`, which is used for DOM tree restructuring. The return value is the handle of the removed node.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.removeChild (
   n        IN DBMS_XMLDOM.DOMNODE,
   oldchild IN DBMS_XMLDOM.DOMNODE);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| n | Parent Node`DBMS_XMLDOM.DOMNODE`Handle. |
| oldchild | Child node to remove`DBMS_XMLDOM.DOMNODE`Handle. |

## Return value

The handle of the removed child node (`DBMS_XMLDOM.DOMNODE`).

## Usage instructions

`oldchild` must be a direct child of `n`. After removal, the handle of this child node is returned for subsequent processing.

## Examples

```sql
DECLARE
  parent_node DBMS_XMLDOM.DOMNODE;
  old_child   DBMS_XMLDOM.DOMNODE;
  ret_node    DBMS_XMLDOM.DOMNODE;
BEGIN
  ret_node := DBMS_XMLDOM.removeChild(parent_node, old_child);
END;
/
```
