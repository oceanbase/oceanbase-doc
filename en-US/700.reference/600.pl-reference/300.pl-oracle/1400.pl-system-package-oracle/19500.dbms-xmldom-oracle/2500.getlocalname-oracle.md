# GETLOCALNAME

The `GETLOCALNAME` function is used to obtain the local name of a specified node. For a node with a namespace prefix, it returns the local name without the prefix.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this subprogram is available starting with OceanBase Database V4.4.2 BP3.</p>
</main>

## Syntax

```sql
DBMS_XMLDOM.getLocalName (
   n IN DBMS_XMLDOM.DOMNODE);
```

## Parameters

| **Parameters** | **Explanation** |
| ---------- | ---------- |
| n | To query the`DBMS_XMLDOM.DOMNODE`Handle. |

## Return value

The local name of the node, in `VARCHAR2` type.

## Usage instructions

Compared with `GETNODENAME`, this function returns a local name without the namespace prefix.

## Examples

```sql
DECLARE
  n          DBMS_XMLDOM.DOMNODE;
  local_name VARCHAR2(32767);
BEGIN
  local_name := DBMS_XMLDOM.getLocalName(n);
END;
/
```
