# TRANSLATE

The `UTL_RAW.TRANSLATE` function is a byte-level translation function that converts `RAW` data byte by byte.

## Syntax

```sql
UTL_RAW.TRANSLATE (
   r        IN RAW,    
   from_set IN RAW,    
   to_set   IN RAW  
) RETURN RAW;
```

## Parameters

| **Parameter** |                  **Description**                  |
|--------|------------------------------------------|
| r |The source byte string.|
| from_set |The byte set to be searched and replaced.|
| to_set |The target byte set for replacement.|

## Considerations

The function scans the source byte string `r` byte by byte:

* If the value is found in `from_set`, it is replaced with the corresponding byte in `to_set`.
* If the byte is not found in `from_set`, it is copied directly to the result.
* If a byte in `from_set` does not have a corresponding byte in `to_set`, it is deleted.
* If `from_set` is longer than `to_set`, the extra bytes in `from_set` without corresponding translations are deleted.
* If `to_set` is longer than `from_set`, the extra bytes in `to_set` are ignored.
* If there are duplicate bytes in `from_set`, the duplicates are ignored (the second occurrence of the same byte in `from_set` is ignored).
* If any of the three parameters is `NULL` or has a length of `0`, a `ValueError` is raised.
* If the length of the byte string is odd, a `0` is added to the left side during processing.

## Examples

Execute the following command to use the `UTL_RAW.TRANSLATE` function to replace all occurrences of specific characters in the input byte sequence with `F`, while retaining other characters unchanged.

```shell
obclient> SELECT UTL_RAW.TRANSLATE('1236567812125612344434341234567890ABAA1234','12AA34','FFFFFF') FROM dual;
```

The result is as follows:

```sql
+-----------------------------------------------------------------------------------+
| UTL_RAW.TRANSLATE('1236567812125612344434341234567890ABAA1234','12AA34','FFFFFF') |
+-----------------------------------------------------------------------------------+
| FF365678FFFF56FFFF44FFFFFFFF567890ABFFFFFF                                        |
+-----------------------------------------------------------------------------------+
```
