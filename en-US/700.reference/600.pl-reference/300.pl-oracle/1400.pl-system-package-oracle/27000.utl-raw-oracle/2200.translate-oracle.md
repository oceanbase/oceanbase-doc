# TRANSLATE

The `UTL_RAW.TRANSLATE` function is a byte-level translation function that converts `RAW` data byte by byte.

## Syntax

```sql
UTL_RAW.TRANSLATE (
   r        IN RAW,    
   from_set IN RAW,    
   to_set   IN RAW  
) RETURN RAW;
```

## Parameters

| **Parameter** |                  **Description**                  |
|--------|------------------------------------------|
| r |The source byte string.|
| from_set |The byte set to be searched and replaced.|
| to_set |The target byte set for replacement.|

## Considerations

The function scans the source byte string `r` byte by byte:

* If the value appears in `from_set`, replace it with the corresponding value in `to_set`.
* If the byte does not appear in `from_set`, copy it to the result as is.
* If a byte in `from_set` has no corresponding byte in `to_set`, remove it.
* If `from_set` is longer than `to_set`, remove the extra bytes in `from_set` without a mapping.
* If `to_set` is longer than `from_set`, ignore the extra bytes in `to_set`.
* If there are duplicate bytes in `from_set`, ignore the duplicates, that is to ignore the second occurrence of the same byte in `from_set`.
* If any of the three parameters is `NULL` or has a length of `0`, raise a `ValueError`.
* If the length of the byte string is odd, pad a leading `0` before processing.

## Examples

Run the following command to use the `UTL_RAW.TRANSLATE` function to replace all occurrences of specific characters in the input byte sequence with `F`, while retaining other characters unchanged.

```shell
obclient> SELECT UTL_RAW.TRANSLATE('1236567812125612344434341234567890ABAA1234','12AA34','FFFFFF') FROM dual;
```

The result is as follows:

```sql
+-----------------------------------------------------------------------------------+
| UTL_RAW.TRANSLATE('1236567812125612344434341234567890ABAA1234','12AA34','FFFFFF') |
+-----------------------------------------------------------------------------------+
| FF365678FFFF56FFFF44FFFFFFFF567890ABFFFFFF                                        |
+-----------------------------------------------------------------------------------+
```
