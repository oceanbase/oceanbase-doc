# CAST_FROM_NUMBER

The `CAST_FROM_NUMBER` function returns a `NUMBER` value in binary `RAW` format.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>For the <code>NUMBER</code> type, OceanBase Database implements the type differently from Oracle Database. The returned <code>RAW</code> value is in the internal <code>NUMBER</code> format of OceanBase Database. </p>
  </main>

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL mode. </p>
</main>

## Syntax

```sql
UTL_RAW.CAST_FROM_NUMBER (
   n  IN NUMBER)
 RETURN RAW;
```

## Parameters

`n` specifies a `NUMBER` value.

## Return value

The binary representation of the `NUMBER` value in `RAW` format.

## Examples

```sql
obclient> SELECT UTL_RAW.CAST_FROM_NUMBER(123.456) FROM DUAL;
+-----------------------------------+
| UTL_RAW.CAST_FROM_NUMBER(123.456) |
+-----------------------------------+
| 020000C07B00000000022E1B          |
+-----------------------------------+
1 row in set

obclient> SELECT UTL_RAW.CAST_FROM_NUMBER(-123.456) FROM DUAL;
+------------------------------------+
| UTL_RAW.CAST_FROM_NUMBER(-123.456) |
+------------------------------------+
| 020000407B00000000022E1B           |
+------------------------------------+
1 row in set
```
