# CAST_TO_BINARY_INTEGER

The `CAST_TO_BINARY_INTEGER` function converts a `BINARY_INTEGER` value represented in `RAW` binary form to a `BINARY_INTEGER`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
UTL_RAW.CAST_TO_BINARY_INTEGER (
   r          IN RAW
   endianess  IN PLS_INTEGER DEFAULT BIG_ENDIAN)
RETURN BINARY_INTEGER;
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| r | The binary representation of a `BINARY_INTEGER` value. |
| endianess | The `BINARY_INTEGER` value that specifies whether the binary representation is in `big_endian` or `little-endian` format. The default value is `big_endian`. |

## Return value

The `BINARY_INTEGER` value.

## Examples

```sql
obclient> SELECT UTL_RAW.CAST_TO_BINARY_INTEGER('0') FROM DUAL;
+-------------------------------------+
| UTL_RAW.CAST_TO_BINARY_INTEGER('0') |
+-------------------------------------+
|                                   0 |
+-------------------------------------+
1 row in set

obclient> SELECT UTL_RAW.CAST_TO_BINARY_INTEGER('0F', 1) FROM DUAL;

+----------------------------------------+
|                                     15 |
+----------------------------------------+
1 row in set
```
