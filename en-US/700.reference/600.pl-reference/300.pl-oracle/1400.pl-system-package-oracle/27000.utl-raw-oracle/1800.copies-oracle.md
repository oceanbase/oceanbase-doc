# COPIES

The `COPIES` function returns the result of concatenating n copies of `r`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_RAW.COPIES (
     r IN RAW,
     n IN NUMBER)
  RETURN RAW;
```

## Parameters

| **Parameter** |       **Description**       |
|--------|--------------------|
| r      | The `RAW` value to be copied.         |
| n      | The number of times to copy the `RAW` value. This parameter must be a positive integer. |

## Return value

The `RAW` value copied n times.

## Exceptions

|   **Exception**    |        **Description**      |
|-------------|------------------------|
| VALUE_ERROR | The following conditions may occur: <ul><li> The value of `r` is `NULL`, or the length of `r` is 0. </li>   <li> The value of `n` is less than 1. </li>   <li> The length of the result exceeds the maximum length of `RAW`. </li></ul>    |
