# Overview of UTL_RAW

The `UTL_RAW` package provides SQL functions for working with the `RAW` data type.

Since standard SQL functions do not operate on `RAW` data, and PL/SQL does not allow overloading between `RAW` and `CHAR` data types, the `UTL_RAW` package is essential.

`UTL_RAW` is not limited to use within a database environment, hence the prefix `UTL` is used instead of `DBMS`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## UTL_RAW considerations

`UTL_RAW` allows for the composition of `RAW` "records" by many elements. Using the `RAW` data type avoids character set conversion, preserving the original format of `RAW` during remote calls.

## UTL_RAW subprograms

The following table lists the `UTL_RAW` subprograms supported in the current version of OceanBase Database, along with brief descriptions.

|                       **Subprogram**             |                **Description**                       |
|--------------------------------------------|---------------------------------------------------|
| [BIT_AND](../27000.utl-raw-oracle/200.bit-and-oracle.md)                 | Performs a bitwise logical "AND" on the values in `RAW r1` and `RAW r2` and returns the original "AND" result.   |
| [BIT_COMPLEMENT](../27000.utl-raw-oracle/300.bit-complement-oracle.md)   | Performs a bitwise logical "complement" on the value in `RAW r` and returns the "complement" result as `RAW`.            |
| [BIT_OR](../27000.utl-raw-oracle/400.bit-or-oracle.md)            | Performs a bitwise logical "OR" on the values in `RAW r1` and `RAW r2` and returns the original "OR" result.   |
| [BIT_XOR](../27000.utl-raw-oracle/500.bit-xor-oracle.md)          | Performs a bitwise logical "XOR" on the values in `RAW r1` and `RAW r2` and returns the original "XOR" result. |
| [CAST_FROM_BINARY_DOUBLE](../27000.utl-raw-oracle/600.cast-from-binary-double-oracle.md) | Returns the `BINARY_DOUBLE` value in `RAW` binary format. |
| [CAST_FROM_BINARY_FLOAT](../27000.utl-raw-oracle/700.cast-from-binary-float-oracle.md)   | Returns the `BINARY_FLOAT` value in `RAW` binary format.  |
| [CAST_FROM_BINARY_INTEGER](../27000.utl-raw-oracle/800.cast-from-binary-integer-oracle.md) | Returns the `BINARY_INTEGER` value in `RAW` binary format. |
| [CAST_FROM_NUMBER](../27000.utl-raw-oracle/900.cast-from-number-oracle.md)               | Returns the `NUMBER` value in `RAW` binary format. |
| [CAST_TO_BINARY_DOUBLE](../27000.utl-raw-oracle/1000.cast-to-binary-double-oracle.md)    | Converts the `BINARY_DOUBLE` value represented in `RAW` binary format to `BINARY_DOUBLE`.  |
| [CAST_TO_BINARY_FLOAT](../27000.utl-raw-oracle/1100.cast-to-binary-float-oracle.md)      | Converts the `BINARY_FLOAT` value represented in `RAW` binary format to `BINARY_FLOAT`.    |
| [CAST_TO_BINARY_INTEGER](../27000.utl-raw-oracle/1200.cast-to-binary-integer-oracle.md)  | Converts the `BINARY_INTEGER` value represented in `RAW` binary format to `BINARY_INTEGER`.|
| [CAST_TO_NUMBER](../27000.utl-raw-oracle/1300.cast-to-number-oracle.md)        | Converts the `NUMBER` value represented in `RAW` binary format to `NUMBER`.  |
| [CAST_TO_RAW](../27000.utl-raw-oracle/1400.cast-to-raw-oracle.md)           | Converts a `VARCHAR2` value to a `RAW` value.              |

| [COPIES](../27000.utl-raw-oracle/1600.compare-oracle.md)           | Returns the `n` copies of `r` concatenated together.                      |
| [COMPARE](../27000.utl-raw-oracle/1700.concat-utl-oracle.md)         | Compares `RAW r1` and `RAW r2`.                             |
| [CONCAT](../27000.utl-raw-oracle/1800.copies-oracle.md)        | Concatenates up to 12 `RAW` values into one `RAW` value.                  |
| [LENGTH](../27000.utl-raw-oracle/1900.length-utl-oracle.md)        | Returns the byte length of `RAW r`.                                |
| [REVERSE](../27000.utl-raw-oracle/2000.reverse-oracle.md)        | Reverses the byte sequence in `RAW r` from end to end.                       |
