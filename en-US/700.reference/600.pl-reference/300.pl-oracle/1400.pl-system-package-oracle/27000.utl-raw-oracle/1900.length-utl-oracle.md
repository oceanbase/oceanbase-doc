# LENGTH

The `LENGTH` function returns the length in bytes of the `RAW` value.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_RAW.LENGTH (
     r  IN RAW)
RETURN NUMBER;
```

## Parameters

| **Parameter** |    **Description**     |
|--------|---------------|
| r      | The `RAW` value for which to return the byte length. |

## Return value

| **Return value** |  **Description**   |
|---------|-----------|
| NUMBER  | The current length of the `RAW` value. |
