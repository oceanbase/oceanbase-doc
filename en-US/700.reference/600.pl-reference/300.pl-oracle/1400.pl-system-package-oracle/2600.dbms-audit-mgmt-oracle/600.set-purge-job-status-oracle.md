# SET_PURGE_JOB_STATUS

The `SET_PURGE_JOB_STATUS` procedure enables or disables a specified purge job.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_AUDIT_MGMT.SET_PURGE_JOB_STATUS(
audit_trail_purge_name    IN VARCHAR2,
audit_trail_status_value  IN PLS_INTEGER) ;
```

## Parameters

|            Parameter          |       Description       |
|--------------------------|-----------------|
| audit_trail_purge_name   | The name of the purge job to set the status for. This is the name specified in the `CREATE_PURGE_JOB` procedure.  |
| audit_trail_status_value | The value can be: <ul><li> `PURGE_JOB_ENABLE` to enable the specified purge job. The data type is `PLS_INTEGER`.   </li><li> `PURGE_JOB_DISABLE` to disable the specified purge job. The data type is `PLS_INTEGER`. </li></ul>    |

## Examples

The following example calls the `SET_PURGE_JOB_STATUS` procedure to enable the `MyCLEANUP` purge job.

```sql
BEGIN
   DBMS_AUDIT_MGMT.SET_PURGE_JOB_STATUS(
     audit_trail_purge_name      => 'MyCLEANUP',
     audit_trail_status_value    => DBMS_AUDIT_MGMT.PURGE_JOB_ENABLE);
END;
```
