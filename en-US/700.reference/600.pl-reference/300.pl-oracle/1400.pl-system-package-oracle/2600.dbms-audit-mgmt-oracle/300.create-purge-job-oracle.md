# CREATE_PURGE_JOB

The `CREATE_PURGE_JOB` procedure is used to create a purge job that periodically deletes audit trail records.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_AUDIT_MGMT.CREATE_PURGE_JOB(
audit_trail_type            IN PLS_INTEGER,
audit_trail_purge_interval  IN PLS_INTEGER,
audit_trail_purge_name      IN VARCHAR2,
use_last_arch_timestamp     IN BOOLEAN DEFAULT TRUE) ;
```

## Parameters

|             Parameter           |           Description           |
|----------------------------|--------------------------|
| audit_trail_type           | Specifies the audit trail type for the purge job. For more information, see [Audit trail types in DBMS_AUDIT_MGMT](../2600.dbms-audit-mgmt-oracle/100.dbms-audit-mgmt-overview-oracle.md).     |
| audit_trail_purge_interval | The time interval (in hours) at which the purge process is called. A lower value indicates more frequent purges.    |
| audit_trail_purge_name     | Specifies the name of the purge job.    |
| use_last_arch_timestamp    | Specifies whether to use the last archive timestamp to determine which records to delete. Valid values: <ul><li> `TRUE` indicates that only audit records created before the last archive timestamp should be deleted.   </li><li> `FALSE` indicates that all audit records should be deleted.</li></ul>    The default value is `TRUE`. |

## Considerations

This procedure calls the `CLEAN_AUDIT_TRAIL` procedure to perform audit trail record purges at the specified intervals.

## Examples

The following example calls the `CREATE_PURGE_JOB` procedure to create a purge job named `MyCLEANUP` for the operating system (OS) audit trail type. The purge job is called every 72 hours, and all audit records created before the last archive timestamp will be deleted.

```sql
BEGIN
   DBMS_AUDIT_MGMT.CREATE_PURGE_JOB(
     audit_trail_type             =>  DBMS_AUDIT_MGMT.AUDIT_TRAIL_OS,
     audit_trail_purge_interval   =>  72 /*hours*/,
     audit_trail_purge_name       =>  'MyCLEANUP',
     use_last_arch_timestamp      =>  TRUE);
END;
```
