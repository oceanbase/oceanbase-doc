# SET_MVREF_STATS_PARAMS

The `SET_MVREF_STATS_PARAMS` procedure is used to configure the parameters for collecting statistics and data retention period for materialized view refreshes.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_MVIEW_STATS.SET_MVREF_STATS_PARAMS (
		mv_list            IN    VARACHAR2,
		collection_level   IN    VARCHAR2 DEFAULT NULL,
		retention_period   IN    NUMBER DEFAULT NULL);
```

## Parameters

| **Parameter**           | **Description**                                                                                                                                          |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| mv_list          | A list of materialized view names, separated by commas. Currently, only a single materialized view is supported.<ul><li>If NULL, the operation applies to all materialized views. </ul></li>                                              |
| collection_level | The level of statistics collection. The default level is TYPICAL. Options include:<ul><li>NONE: No statistics are collected.</ul></li><ul><li>TYPICAL: Basic refresh statistics are collected.</ul></li><ul><li>ADVANCED: Detailed refresh statistics are collected.</ul></li><ul><li>NULL: The default value, TYPICAL, is used.</ul></li> |
| retention_period | The number of days to retain statistics. The value ranges from 1 to 365000 days. Statistics records are automatically deleted after exceeding the specified number of days. The default is 31 days.<ul><li>If NULL, the default setting is used.</ul></li><ul><li>If set to -1, statistics are permanently retained.</ul></li>                               |
