# PURGE_REFRESH_STATS

The `PURGE_REFRESH_STATS` procedure is used to forcibly delete materialized view refresh statistics that exceed the specified retention period.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_MVIEW_STATS.PURGE_REFRESH_STATS (
		mv_list               IN     VARACHAR2,
		retention_period      IN     NUMBER);
```

## Parameters

| **Parameter**           | **Description**                                            |
|------------------|-----------------------------------------------------|
| mv_list          | A list of materialized view names, separated by commas. This parameter does not support specifying multiple materialized views at the same time. <ul><li>When the value is NULL, the operation is performed on all materialized views. </ul></li> |
| retention_period | The number of days for which statistics are retained. The value ranges from 1 to 365000. Statistics records exceeding this period are automatically deleted. The default value is 31 days. <ul><li>If the value is NULL, the default cleanup strategy of the automatic statistics clearing mechanism is used. </ul></li><ul><li>If the value is set to -1, all related statistics records will be deleted. </ul></li> |
