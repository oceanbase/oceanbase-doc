# RESTORE_SCHEMA_STATS

The `RESTORE_SCHEMA_STATS` procedure is used to restore user-level historical statistics at a specified time.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_STATS.RESTORE_SCHEMA_STATS(
  ownname                VARCHAR2,
  as_of_timestamp        TIMESTAMP WITH TIME ZONE,
  force                  BOOLEAN DEFAULT FALSE,
  no_invalidate          BOOLEAN DEFAULT FALSE);
```

## Parameters

|       Parameter        |           Description            |
|-----------------|-------------------------|
| ownname         | The username. If the username is set to `NULL`, the current login username will be used by default.              |
| as_of_timestamp | The timestamp for restoring statistics.                 |
| force           | Specifies whether to forcibly restore statistics and ignore locks. The default value is `FALSE`. |
| no_invalidate   | Specifies whether to clear the plan cache when collecting statistics. If set to `TRUE`, the plan cache will not be cleared when collecting statistics.    |

## Exceptions

|    Error code    |         Description       |
|-----------|---------------------|
| OBE-20000 | The object does not exist or the user does not have sufficient privileges.      |
| OBE-20001 | Invalid or inconsistent value.           |
| OBE-20006 | Statistics cannot be restored because the statistics history is unavailable. |

## Considerations

To call this procedure, you must be the owner of the table. For objects owned by `SYS`, you must be the owner or have the `SYSDBA` privilege.

## Examples

Restore statistics for the `hr` user at a specific timestamp.

```sql
obclient> CALL DBMS_STATS.RESTORE_SCHEMA_STATS ('hr', TO_TIMESTAMP('2021-09-26 19:02:12.675729', 'YYYY-MM-DD HH24:MI:SS.FF'));
Query OK, 0 rows affected
```
