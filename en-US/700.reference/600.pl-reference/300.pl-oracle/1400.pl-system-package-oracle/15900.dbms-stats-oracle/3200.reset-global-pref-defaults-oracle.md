# RESET_GLOBAL_PREF_DEFAULTS

The `RESET_GLOBAL_PREF_DEFAULTS` procedure resets the global Prefs to their default values.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_STATS.RESET_GLOBAL_PREF_DEFAULTS;
```

## Examples

Reset all global Prefs to their default values.

```sql
obclient> CALL DBMS_STATS.RESET_GLOBAL_PREF_DEFAULTS();
Query OK, 0 rows affected
```
