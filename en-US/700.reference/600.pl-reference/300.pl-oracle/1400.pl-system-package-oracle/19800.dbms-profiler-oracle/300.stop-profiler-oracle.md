# STOP_PROFILE

The `STOP_PROFILE` procedure is used to stop the profiler.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_PROFILER.STOP_PROFILER
  RETURN BINARY_INTEGER;

DBMS_PROFILER.STOP_PROFILER;
```

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><code>RETURN BINARY_INTEGER</code> specifies the return data type as a binary integer. In practice, you typically do not need to explicitly declare <code>RETURN BINARY_INTEGER</code>; instead, you can directly call the <code>STOP_PROFILER</code> procedure. </p>
  </main>

## Example

Execute the following command to stop the profiler.

```shell
obclient> call DBMS_PROFILER.stop_profiler();
Query OK, 0 rows affected (1.238 sec)
```
