# INTERNAL_VERSION_CHECK

The `INTERNAL_VERSION_CHECK` procedure is used to verify whether the database version matches the `DBMS_PROFILER` version.
If the `dbms_profiler` system package fails to work properly or even affects the system stability due to unexpected modification of the admin package distributed with OBServer, we recommend that you back up data and deploy OBServer again using the installation media. Generally, no version mismatch issues will occur when you use the standard deployment and upgrade process.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_PROFILER.INTERNAL_VERSION_CHECK
  RETURN BINARY_INTEGER;
```

## Examples

```shell
obclient> select dbms_profiler.INTERNAL_VERSION_CHECK() from dual;
+----------------------------------------+
| DBMS_PROFILER.INTERNAL_VERSION_CHECK() |
+----------------------------------------+
|                                      0 |
+----------------------------------------+
1 row in set (0.063 sec)
```
