# OB_DROP_OBJECTS

The `OB_DROP_OBJECTS` procedure is used to drop statistics tables under the <code>schema</code> user.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```SQL
PROCEDURE OB_DROP_OBJECTS;
```

## Examples

```shell
obclient> call dbms_profiler.ob_drop_objects();
Query OK, 0 rows affected (0.06 sec)
```
