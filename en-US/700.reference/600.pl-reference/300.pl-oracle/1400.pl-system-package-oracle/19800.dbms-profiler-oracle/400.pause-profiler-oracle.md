# PAUSE_PROFILER

The `PAUSE_PROFILER` procedure is used to pause the profiler.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_PROFILER.PAUSE_PROFILER
  RETURN BINARY_INTEGER;

DBMS_PROFILER.PAUSE_PROFILER;
```

 <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><code>RETURN BINARY_INTEGER</code> specifies the return data type as a binary integer. In practice, you typically do not need to explicitly declare <code>RETURN BINARY_INTEGER</code>; instead, you directly call the <code>PAUSE_PROFILER</code> procedure. </p>
  </main>

## Examples

Execute the following statement to pause the profiler.

```shell
obclient> call DBMS_PROFILER.pause_profiler();
Query OK, 0 rows affected (0.012 sec)
```
