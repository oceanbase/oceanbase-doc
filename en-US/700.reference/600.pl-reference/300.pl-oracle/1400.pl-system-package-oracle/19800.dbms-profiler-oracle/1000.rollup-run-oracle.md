# ROLLUP_RUN

`ROLLUP_RUN` is used to calculate the execution time for each unit during an execution.

 <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE ROLLUP_RUN(run_number IN number);
```

## Parameters

|       Parameter       |               Description                |
|----------------|---------------------------------|
| run_number | The storage run number, which allows you to store and call the run data later. The values of the <code>run_number</code> IN parameter come from the <code>run_number OUT</code> parameter of <code>start_profiler</code>.|

## Examples

```shell
obclient> call dbms_profiler.rollup_run(1);
Query OK, 0 rows affected (0.06 sec)
```
