# ROLLUP_UNIT

The `ROLLUP_UNIT` procedure is used to calculate the execution time of a unit during a specific execution.

 <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE ROLLUP_UNIT(run_number IN number,unit IN number);
```

## Parameters

|       Parameter       |               Description                |
|----------------|---------------------------------|
| run_number | The run number, which allows you to store and retrieve execution data later. The values of the <code>run_number</code> IN parameter are obtained from the <code>run_number OUT</code> parameter of the <code>start_profiler</code> procedure. |
| unit | The object ID, which corresponds to the <code>unit_number</code> column in the statistics table. |

## Examples

```shell
obclient> call dbms_profiler.rollup_unit(1,501810);
Query OK, 0 rows affected (0.08 sec)
```
