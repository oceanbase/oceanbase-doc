# FLUSH_DATA

`FLUSH_DATA` is used to aggregate data to the statistics table.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_PROFILER.FLUSH_DATA
  RETURN BINARY_INTEGER;

DBMS_PROFILER.FLUSH_DATA;
```

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p><code>RETURN BINARY_INTEGER</code> specifies the return data type as a binary integer. In practice, you typically do not need to explicitly declare <code>RETURN BINARY_INTEGER</code>. Instead, you can directly call the <code>FLUSH_DATA</code> procedure. </p>
  </main>

## Examples

```shell
obclient> call DBMS_PROFILER.flush_data();
Query OK, 0 rows affected (0.012 sec)
```
