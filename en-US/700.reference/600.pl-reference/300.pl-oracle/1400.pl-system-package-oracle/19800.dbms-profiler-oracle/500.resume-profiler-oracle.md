# RESUME_PROFILER

The `RESUME_PROFILER` procedure resumes the performance profiler.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_PROFILER.RESUME_PROFILER
  RETURN BINARY_INTEGER;

DBMS_PROFILER.RESUME_PROFILER;
```

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p><code>RETURN BINARY_INTEGER</code> specifies the return data type as a binary integer. In practice, you typically do not need to explicitly declare <code>RETURN BINARY_INTEGER</code>. Instead, you can directly call the <code>RESUME_PROFILER</code> procedure. </p>
  </main>

## Example

Execute the following statement to resume the performance profiler.

```shell
obclient> call DBMS_PROFILER.resume_profiler();
Query OK, 0 rows affected (0.001 sec)
```
