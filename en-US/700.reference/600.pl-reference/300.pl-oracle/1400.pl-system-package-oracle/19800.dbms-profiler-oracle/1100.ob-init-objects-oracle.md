# OB_INIT_OBJECTS

The `OB_INIT_OBJECTS` procedure creates data statistics tables in the `schema` user.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE OB_INIT_OBJECTS(force_create IN boolean :=FALSE);
```

## Parameters

|       Parameter       |               Description                |
|----------------|---------------------------------|
| force_create IN boolean :=FALSE | <li>If the value is <code>FALSE</code>, an error is returned when a table with the same name as the statistics table already exists. <li>If the value is <code>TRUE</code>, the existing table with the same name as the statistics table is dropped before the statistics table is created. The default value is <code>FALSE</code>.|

## Examples

```shell
obclient> call dbms_profiler.ob_init_objects();
Query OK, 0 rows affected (0.06 sec)
```
