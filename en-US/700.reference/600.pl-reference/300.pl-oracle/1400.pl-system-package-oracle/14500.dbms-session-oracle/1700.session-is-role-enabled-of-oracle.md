# SESSION_IS_ROLE_ENABLED

`SESSION_IS_ROLE_ENABLED` determines whether a specified role is enabled at the session level.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This subprogram is introduced in V4.4.1.</p>
</main>

## Syntax

```sql
DBMS_SESSION.SESSION_IS_ROLE_ENABLED (
   rolename    VARCHAR2)
  RETURN BOOLEAN;
```

## Parameters

`rolename` specifies the name of the role. Returns `TRUE` if the role is enabled, or `FALSE` if it is not.

## Examples

```sql
BEGIN
  IF DBMS_SESSION.SESSION_IS_ROLE_ENABLED('DBA') THEN
    DBMS_OUTPUT.PUT_LINE('Role DBA is active');
  ELSE
    DBMS_OUTPUT.PUT_LINE('Role DBA is not active');
  END IF;
END;
/
```
