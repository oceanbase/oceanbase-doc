# Overview of DBMS_SESSION

The `DBMS_SESSION` system package provides access to the `ALTER SESSION` SQL statement and other session information from PL/SQL. You can use `DBMS_SESSION` to set preferences and security levels.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL-compatible mode. </p>
  </main>

## Privilege requirements for DBMS_SESSION

You need the privileges of the user who calls the `DBMS_SESSION` system package. You do not need the `SYS` privileges.

## Overview of DBMS_SESSION subprograms

The following table lists the DBMS_SESSION subprograms supported in the current version of OceanBase Database and their brief descriptions.

|        Subprogram            |      Description       |
|--------------------------|---------------|
| [CLEAR_ALL_CONTEXT](../14500.dbms-session-oracle/200.clear-all-context-oracle.md) | Clears all context information.    |
| [CLEAR_CONTEXT](../14500.dbms-session-oracle/300.clear-context-oracle.md)     | Clears the specified context information.   |
| [CLEAR_IDENTIFIER](../14500.dbms-session-oracle/400.clear-identifier-oracle.md)  | Clears identifiers.        |
| [RESET_PACKAGE](../14500.dbms-session-oracle/1300.reset-package-of-oracle-mode.md) | Clears all package variables in the session. |
| [SET_CONTEXT](../14500.dbms-session-oracle/1400.set-context-oracle.md)       | Sets or resets the value of a context attribute. |
| [SESSION_IS_ROLE_ENABLED](../14500.dbms-session-oracle/1700.session-is-role-enabled-of-oracle.md)|Determines whether the specified role is enabled at the session level.|
| [IS_ROLE_ENABLED](../14500.dbms-session-oracle/1800.is-role-enabled-of-oracle.md)|Determines whether the specified role is enabled in the session.|
