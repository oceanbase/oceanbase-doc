# SLEEP

The `SLEEP` procedure blocks the current session for the specified duration.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_LOCK.SLEEP (
seconds  IN NUMBER);
```

## Parameters

| **Parameter**  |                              **Description**                              |
|---------|------------------------------------------------------------------|
| seconds | The duration for which the session is blocked, in seconds. You can specify the value in increments of 0.01 seconds. For example, 1.95 is a valid value. |
