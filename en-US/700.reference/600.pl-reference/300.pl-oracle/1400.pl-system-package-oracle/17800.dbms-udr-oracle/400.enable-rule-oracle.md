# ENABLE_RULE

The `ENABLE_RULE` procedure is used to enable custom rewrite rules so that they take effect.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
PROCEDURE ENABLE_RULE (
    rule_name          VARCHAR(256));
```

## Parameters

| Parameter | Description |
| --- | --- |
| rule_name | The name of the rule. |

## Examples

```shell
obclient> CALL DBMS_UDR.ENABLE_RULE('rule1');
Query OK, 0 rows affected

obclient> SELECT 1 FROM DUAL;
+-------+
| ? + 1 |
+-------+
|     2 |
+-------+
1 row in set
```
