# Overview

The `DBMS_BALANCE` package provides methods for partition balancing.

## Privilege requirements

Only users with the privilege to execute PL/SQL can use this feature. If the sys tenant calls this feature, an error `OB_OP_NOT_ALLOW` is returned.

## Subprograms

The following table describes the `DBMS_BALANCE` subprograms supported in the current OceanBase Database version.

| Subprogram | Description |
| --- | --- |
|[TRIGGER_PARTITION_BALANCE](200.trigger-paptition-balance-oracle.md)|Triggers manual partition balancing.|
|[SET_BALANCE_WEIGHT](../2700.dbms-balance-oracle/150.set-balance-weight-oracle.md)              |Manually sets the partition weight.|
|[CLEAR_BALANCE_WEIGHT](../2700.dbms-balance-oracle/160.clear-balance-weight-oracle.md)          |Manually clears the partition weight.|
