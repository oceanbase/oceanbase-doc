# IS_CLUSTER_DATABASE

The `IS_CLUSTER_DATABASE` function determines whether the database is running in cluster database mode.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.IS_CLUSTER_DATABASE
RETURN BOOLEAN;
```

## Return value

This function returns `TRUE` if the instance is started in cluster database mode. Otherwise, it returns `FALSE`.
