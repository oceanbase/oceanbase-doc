# FORMAT_ERROR_STACK

The `FORMAT_ERROR_STACK` function is used to format the current error stack.

Exception handlers can use `FORMAT_ERROR_STACK` to view the complete error stack.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.FORMAT_ERROR_STACK
RETURN VARCHAR2;
```

## Return value

The error stack, up to 2000 bytes.
