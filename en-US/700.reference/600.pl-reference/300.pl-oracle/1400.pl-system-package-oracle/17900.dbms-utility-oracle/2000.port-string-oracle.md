# PORT_STRING

The `PORT_STRING` function returns a string that identifies the `TWO TASK PROTOCOL` version of the operating system and database.

The maximum length of the string depends on the port settings.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.PORT_STRING
RETURN VARCHAR2;
```
