# CURRENT_INSTANCE

The `CURRENT_INSTANCE` function returns the instance ID of the current connection. If the instance is not available, it returns `NULL`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.CURRENT_INSTANCE
RETURN NUMBER;
```
