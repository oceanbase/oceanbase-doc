# ACTIVE_INSTANCES

The `ACTIVE_INSTANCES` stored procedure returns the active instances.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.ACTIVE_INSTANCES (
instance_table   OUT INSTANCE_TABLE,
instance_count   OUT NUMBER);
```

## Parameters

|       Parameter       |               Description                |
|----------------|---------------------------------|
| instance_table | The list of active instances. If no instance is started, this list is empty. |
| instance_count | The number of active instances.                        |
