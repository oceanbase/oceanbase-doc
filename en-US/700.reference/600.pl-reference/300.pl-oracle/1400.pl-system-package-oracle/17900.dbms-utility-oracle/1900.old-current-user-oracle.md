# OLD_CURRENT_USER

The `OLD_CURRENT_USER` function returns session values from `sys_context` ( '`userenv`', '`current_user`' ).

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.OLD_CURRENT_USER
RETURN VARCHAR2;
```
