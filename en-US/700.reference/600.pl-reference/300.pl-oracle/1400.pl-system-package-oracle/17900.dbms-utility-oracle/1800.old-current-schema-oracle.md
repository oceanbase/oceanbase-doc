# OLD_CURRENT_SCHEMA

The `OLD_CURRENT_SCHEMA` function returns the session value of the '`userenv`' or '`current_schema`' parameter from the `sys_context` function.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.OLD_CURRENT_SCHEMA
RETURN VARCHAR2;
```
