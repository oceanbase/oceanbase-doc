# GET_HASH_VALUE

The `GET_HASH_VALUE` function computes the hash value of a specified string.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_UTILITY.GET_HASH_VALUE (
    name        VARCHAR2,
    base          NUMBER,
    hash_size   NUMBER)
  RETURN NUMBER;
```

## Parameters

|    Parameter     |      Description      |
|-----------|--------------|
| name      | The string to be hashed. |
| base      | The base value from which to start returning the hash value. |
| hash_size | The size of the hash table.    |

## Return value

The hash value of the input string. For example, to obtain the hash value of a string that is between 1000 and 3047, you can use 1000 as the base value and 2048 as the `hash_size` value. We recommend that you use a power of 2 for the `hash_size` parameter.
