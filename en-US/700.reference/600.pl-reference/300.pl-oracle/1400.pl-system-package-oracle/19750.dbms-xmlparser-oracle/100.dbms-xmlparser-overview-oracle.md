# Overview of DBMS_XMLPARSER

The `DBMS_XMLPARSER` system package is used to parse XML text from a `CLOB` or `VARCHAR2` and build a DOM parse tree that can be accessed by `DBMS_XMLDOM`.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL-compatible mode.</p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this system package is available starting with OceanBase Database V4.4.2 BP2.</p>
</main>

## DBMS_XMLPARSER Privileges

The `EXECUTE` privilege on the `DBMS_XMLPARSER` system package is granted to `PUBLIC`. The current user has the privilege to use the subprograms within this package.

## Usage instructions for DBMS_XMLPARSER

The `DBMS_XMLPARSER` reads XML from a `CLOB` or `VARCHAR2` and parses it into a DOM tree. After successful parsing, you can use `GETDOCUMENT` to obtain a `DOMDocument` handle, and then use subprograms in `DBMS_XMLDOM` to traverse nodes, read elements, and node values. If parsing fails, an application error is thrown.

The typical process is as follows:

1. Call `NEWPARSER` to create a parser (`Parser` handle).
2. Call `PARSECLOB` to parse the XML text in a `CLOB`, or call `PARSEBUFFER` to parse the short-text XML in a `VARCHAR2`.
3. Call `GETDOCUMENT` to obtain the `DBMS_XMLDOM.DOMDOCUMENT` handle.
4. Use the [DBMS_XMLDOM](../19500.dbms-xmldom-oracle/100.dbms-xmldom-overview-oracle.md) subprograms to access the parsed results.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The current version parses XML in <code>CLOB</code> using <code>PARSECLOB</code> and parses short-text XML in <code>VARCHAR2</code> using <code>PARSEBUFFER</code> (supported since V4.4.2 BP3), constructing a parse tree accessible via the DOM interface. Capabilities such as parsing from file paths or URLs, DTD validation, and error logging are not currently supported.</p>
</main>

For information about creating and converting `XMLType` objects, see [XMLType overview](../29600.xmltype-oracle/100.xmltype-overview-oracle.md).
