# Overview of DBMS_WORKLOAD_REPOSITORY

The `DBMS_WORKLOAD_REPOSITORY` package is used to manage the Automatic Workload Repository (AWR).

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Privilege requirements for DBMS_WORKLOAD_REPOSITORY

All subprograms of the `DBMS_WORKLOAD_REPOSITORY` package require the `EXECUTE` privilege.

## Overview of DBMS_WORKLOAD_REPOSITORY subprograms

The following table lists the `DBMS_WORKLOAD_REPOSITORY` subprograms supported in the current OceanBase Database version and their brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [ASH_REPORT](../18400.dbms-workload-repository-oracle/200.ash-report-oracle.md) | Displays the ASH report in text format. |
