# XA_GETLASTOER

The `XA_GETLASTOER` function returns the last OceanBase Database error code when a previous XA call fails.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
DBMS_XA.XA_GETLASTOER
RETURN PLS_INTEGER;
```

## Return value

The return value is the last OceanBase Database error code.
