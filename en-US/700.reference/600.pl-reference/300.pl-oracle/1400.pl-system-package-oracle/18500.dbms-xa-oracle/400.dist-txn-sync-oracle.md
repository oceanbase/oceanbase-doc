# DIST_TXN_SYNC

You can use this procedure to synchronize uncertain transactions when a database instance fails.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this. </p>
  </main>

## Syntax

```sql
DBMS_XA.DIST_TXN_SYNC;
```

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>OceanBase Database supports this procedure for compatibility only. It does not perform any actual operations. </p>
  </main>
