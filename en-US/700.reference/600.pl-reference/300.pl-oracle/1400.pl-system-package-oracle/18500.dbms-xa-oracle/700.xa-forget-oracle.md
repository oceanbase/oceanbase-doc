# XA_FORGET

The `XA_FORGET` function requests the resource manager (RM) to discard a transaction branch that has been committed or rolled back.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
DBMS_XA.XA_FORGET (
   xid       IN  DBMS_XA_XID)
RETURN PLS_INTEGER;
```

## Parameters

| **Parameter** |                                  **Description**                                   |
|--------|---------------------------------------------------------------------------|
| xid    | See [DBMS_XA_XID object type](../18500.dbms-xa-oracle/300.the-type-of-the-dbms-xa-xid-object-oracle.md). |

## Return value

See [Possible constant return values of DBMS_XA](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md).

The function may return the following values: `XA_OK`, `XAER_RMERR`, `XAER_RMFAIL`, `XAER_NOTA`, `XAER_INVAL`, or `XAER_PROTO`.
