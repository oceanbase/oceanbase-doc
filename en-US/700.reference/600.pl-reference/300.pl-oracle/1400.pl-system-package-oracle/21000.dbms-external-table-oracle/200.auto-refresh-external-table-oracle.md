# AUTO_REFRESH_EXTERNAL_TABLE

`auto_refresh_external_table` is used to periodically refresh the metadata of an external table.

## Syntax

```sql
DBMS_EXTERNAL_TABLE.auto_refresh_external_table(interval int)
```

## Parameters

| **Parameter**           | **Description**                                            |
|------------------|-----------------------------------------------------|
| interval int | The time interval for the refresh task, in seconds. The value ranges from -1 to infinity. <ul><li>When the value is -1, the periodic refresh task is disabled.</li><li>When the value is 0, the metadata of the external table is refreshed immediately.</li><li>When the value is greater than 0, the metadata of the external table is refreshed every specified number of seconds.</li></ul>|

## Examples

Execute the following command to disable the periodic refresh task.

```shell
obclient> CALL DBMS_EXTERNAL_TABLE.auto_refresh_external_table(-1);
Query OK, 0 rows affected (0.104 sec)
```
