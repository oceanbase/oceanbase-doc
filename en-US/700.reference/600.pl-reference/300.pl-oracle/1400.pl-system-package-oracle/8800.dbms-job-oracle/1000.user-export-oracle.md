# USER_EXPORT

`USER_EXPORT` generates the call text to recreate a specified job.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_JOB.USER_EXPORT (
job        IN BINARY_INTEGER,
mycall   IN OUT VARCHAR2);
```

## Parameters

|   Parameter   |                                          Description                                          |
|--------|--------------------------------------------------------------------------------------|
| job    | The unique ID of the job to be modified. To find this ID, query the `JOB` column of the `USER_JOBS` or `DBA_JOBS` view. |
| mycall | The call text to recreate the specified job.                                                                    |
