# OB_MOD_ACT_TRACE_DISABLE

The `OB_MOD_ACT_TRACE_DISABLE` procedure disables full-link tracing at the module/action level.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. </p>
</main>

## Syntax

```sql
DBMS_MONITOR.OB_MOD_ACT_TRACE_DISABLE(
 module_name     IN  VARCHAR2,
 action_name     IN  VARCHAR2)
```

## Parameters

| **Parameter**        | **Description**                                       |
|------------------|----------------------------------------------|
| module_name      | The `module_name` to disable full-link tracing.             |
| action_name      | The `action_name` to disable full-link tracing.             |
