# OB_SESSION_TRACE_DISABLE

The `OB_SESSION_TRACE_DISABLE` procedure disables full-link tracing at the session level.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. </p>
</main>

## Syntax

```sql
DBMS_MONITOR.OB_SESSION_TRACE_DISABLE(session_id   IN  BINARY_INTEGER);
```

## Parameters

| **Parameter**      | **Description**                                              |
|--------------|-------------------------------------------------------|
| session_id   | The `session_id` to disable full-link tracing. If this parameter is empty, the `session_id` of the current session is used. |
