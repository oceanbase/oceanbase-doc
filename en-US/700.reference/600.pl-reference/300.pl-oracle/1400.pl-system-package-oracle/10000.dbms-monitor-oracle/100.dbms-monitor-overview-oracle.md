# Overview of DBMS_MONITOR

The `DBMS_MONITOR` system package allows you to use PL/SQL to control the behavior of end-to-end tracing.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. </p>
</main>

## Privilege requirements for DBMS_MONITOR

All subprograms in the `DBMS_MONITOR` system package require the `EXECUTE` privilege. By default, the `SYSDBA` role has the `EXECUTE` privilege on this system package.

## Overview of DBMS_MONITOR subprograms

The following table lists the `DBMS_MONITOR` subprograms supported in the current version of OceanBase Database and their brief descriptions.

| Subprogram | Description |
| --- | --- |
| [OB_SESSION_TRACE_ENABLE](200.ob-session-trace-enable-oracle.md) | Enables end-to-end tracing at the session level. |
| [OB_SESSION_TRACE_DISABLE](300.ob-session-trace-disable-oracle.md) | Disables end-to-end tracing at the session level. |
| [OB_CLIENT_ID_TRACE_ENABLE](400.ob-client-id-trace-enable-oracle.md) | Enables end-to-end tracing at the client_identifier level. |
| [OB_CLIENT_ID_TRACE_DISABLE](500.ob-client-id-trace-disable-oracle.md) | Disables end-to-end tracing at the client_identifier level. |
| [OB_MOD_ACT_TRACE_ENABLE](600.ob-mod-act-trace-enable-oracle.md) | Enables end-to-end tracing at the module/action level. |
| [OB_MOD_ACT_TRACE_DISABLE](700.ob-mod-act-trace-disable-oracle.md) | Disables end-to-end tracing at the module/action level. |
| [OB_TENANT_TRACE_ENABLE](800.ob-tenant-trace-enable-oracle.md) | Enables end-to-end tracing for the current tenant. |
| [OB_TENANT_TRACE_DISABLE](900.ob-tenant-trace-disable-oracle.md) | Disables end-to-end tracing for the current tenant. |
