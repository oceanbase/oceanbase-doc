# NORMAL

The `NORMAL` function returns a random number that follows a standard normal distribution.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
DBMS_RANDOM.NORMAL
RETURN NUMBER;
```

## Return value

| **Parameter** |  **Description**  |
|--------|----------|
| number | A random number that follows a standard normal distribution. |
