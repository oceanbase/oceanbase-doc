# RANDOM

The `RANDOM` stored procedure generates a random number.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_RANDOM.RANDOM
RETURN binary_integer;
```

## Return value

|    **Return value**     |              **Description**              |
|----------------|----------------------------------|
| binary_integer | Returns a random integer in the range of \[-2\^31, 2\^31). |

## Considerations

This procedure is deprecated. Although it is supported in the current version, we recommend that you do not use it.
