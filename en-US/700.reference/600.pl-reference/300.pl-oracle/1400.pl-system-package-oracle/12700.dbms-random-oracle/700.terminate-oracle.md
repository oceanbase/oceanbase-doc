# TERMINATE

The `TERMINATE` function is used to terminate the use of a package.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_RANDOM.TERMINATE
```

## Considerations

This procedure does not perform any actions. Although it is supported, it is deprecated and should not be used.
