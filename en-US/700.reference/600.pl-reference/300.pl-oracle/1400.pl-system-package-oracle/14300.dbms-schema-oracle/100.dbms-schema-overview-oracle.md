# Overview of DBMS_SCHEMA

The `DBMS_SCHEMA` package provides the capability to manually trigger the recycling of schema multi-version history data (Schema History) and the Root Service self-inspection (Root Inspection).

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This system package was introduced in OceanBase Database V4.4.2 BP1. </p>
</main>

## Overview of DBMS_SCHEMA subprograms

The following table lists the `DBMS_SCHEMA` subprograms supported in the current version of OceanBase Database and their brief descriptions.

|                **Subprogram**             |                 **Description**                       |
|-----------------------------------------|------------------------------------------------|
|[RECYCLE_SCHEMA_HISTORY](200.recycle-schema-history-oracle.md)|Recycles schema multi-version history data manually.|
|[RUN_INSPECTION](300.run-inspection-oracle.md)|Triggers a Root Service self-inspection manually.|
