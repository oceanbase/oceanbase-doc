# TRUNCATE_UTL_RECOMP_SKIP_LIST

The `TRUNCATE_UTL_RECOMP_SKIP_LIST` procedure is used to truncate the `UTL_RECOMP_SKIP_LIST` table.

 <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_RECOMP.TRUNCATE_UTL_RECOMP_SKIP_LIST();
```

## Examples

```shell
EXECUTE UTL_RECOMP.TRUNCATE_UTL_RECOMP_SKIP_LIST();
Query OK, 1 row affected (23.463 sec)
```
