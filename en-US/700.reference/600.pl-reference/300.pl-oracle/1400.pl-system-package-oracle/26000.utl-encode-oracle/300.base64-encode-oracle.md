# BASE64_ENCODE

The `BASE64_ENCODE` function encodes the binary representation of a `RAW` value as a Base64 element and returns the result as a `RAW` string.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this function. </p>
  </main>

## Syntax

```sql
UTL_ENCODE.BASE64_ENCODE (
   r  IN RAW)
RETURN RAW;
```

## Parameters

| Parameter |           Description           |
|----|------------------------|
| r  | The `RAW` value to encode. This parameter is required. |

## Return value

| Return value |       Description        |
|-----|-----------------|
| RAW | The encoded Base64 element |
