# CLOSE_CURSOR

The `CLOSE_CURSOR` procedure is used to close a specified cursor.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_SQL.CLOSE_CURSOR(cursor_id    IN INTEGER);
```

## Parameters

|  **Parameter**   |    **Description**    |
|-----------|--------------|
| cursor_id | The ID of the cursor to be closed. |
