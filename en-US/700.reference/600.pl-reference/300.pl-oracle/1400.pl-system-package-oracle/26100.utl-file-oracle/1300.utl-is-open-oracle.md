# IS_OPEN

The `IS_OPEN` function tests whether a file handle identifies an open file.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_FILE.IS_OPEN (
   file  IN FILE_TYPE)
  RETURN BOOLEAN;
```

## Parameters

| Parameter | Description |
|------|------|
| file | The active file handle returned by the `FOPEN` or `FOPEN_NCHAR` function. |

## Return value

The `IS_OPEN` function returns a value of the `BOOLEAN` type.

* If the return value is `TRUE`, the file handle is valid and the corresponding file is open.
* If the return value is `FALSE`, the file is closed or the file handle is invalid.

## Exceptions

* `INVALID_FILEHANDLE`

## Considerations

* The file handle passed to `IS_OPEN` must be obtained from a successful call to `FOPEN` or `FOPEN_NCHAR`. An uninitialized or released handle will cause the function to return `FALSE`.
* `IS_OPEN` only reports whether the file handle represents a file that is open and has not been closed. It does not guarantee that no operating system errors will occur when using the file handle.
* Unlike most procedures in the `UTL_FILE` package, `IS_OPEN` does not typically raise an exception. Its design purpose is to safely query the status, so it will return `FALSE` instead of an error even if the handle is invalid.
