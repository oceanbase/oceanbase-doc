# FREMOVE

The `FREMOVE` procedure is used to delete a specified file.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_FILE.FREMOVE (
location IN VARCHAR2,
filename IN VARCHAR2);
```

## Parameters

|    Parameter    |       Description        |
|----------|-----------------|
| location | The path of the file (case-sensitive). |
| filename | The name of the file to be deleted.      |

## Exceptions

* `ACCESS_DENIED`

* `DELETE_FAILED`

* `INVALID_FILENAME`

* `INVALID_OPERATION`

* `INVALID_PATH`

## Considerations

`FREMOVE` does not verify the permissions before deleting a file. However, the operating system will verify the file and directory permissions.
