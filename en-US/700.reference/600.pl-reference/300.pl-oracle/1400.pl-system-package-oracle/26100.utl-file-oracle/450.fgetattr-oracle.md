# FGETATTR

The `FGETATTR` procedure reads and returns the attributes of a disk file.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_FILE.FGETATTR(
   location     IN VARCHAR2,
   filename     IN VARCHAR2,
   fexists      OUT BOOLEAN,
   file_length  OUT NUMBER,
   block_size   OUT BINARY_INTEGER);
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| location | The directory location of the source file, which is a `DIRECTORY_NAME` from the `ALL_DIRECTORIES` view (case-sensitive). |
| filename | The name of the file to be examined. |
| fexists | A Boolean value that indicates whether the file exists. |
| file_length | The length of the file in bytes. Returns `NULL` if the file does not exist. |
| block_size | The file system block size in bytes. Returns `NULL` if the file does not exist. |

## Considerations

`FGETATTR` retrieves information such as whether a file exists, its size, and the file system block size without opening the file. The `location` parameter must be a directory object name created by `CREATE DIRECTORY` and accessible to the current user.
