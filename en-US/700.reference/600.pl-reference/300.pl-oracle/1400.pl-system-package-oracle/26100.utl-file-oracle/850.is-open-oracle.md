# IS_OPEN

The `IS_OPEN` function tests a file handle to see if it identifies an open file.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_FILE.IS_OPEN (
   file  IN FILE_TYPE)
  RETURN BOOLEAN;
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| file | The active file handle returned by an `FOPEN` or `FOPEN_NCHAR` call. |

## Return value

Returns `TRUE` or `FALSE`.

## Exceptions

* `INVALID_FILEHANDLE`

## Considerations

`IS_OPEN` reports only whether a file handle represents a file that has been opened but not yet closed. It does not guarantee that there will be no operating system errors when you attempt to use the file handle.
