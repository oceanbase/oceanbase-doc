# PUTF

The `PUTF` procedure writes data to a specified file in the specified format. The procedure supports writing data to a file in the specified format, and supports writing data to a file in the specified format.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
UTL_FILE.PUTF (
    file   IN FILE_TYPE,
    format IN VARCHAR2,
    arg1   IN VARCHAR2 DEFAULT NULL,
    arg2   IN VARCHAR2 DEFAULT NULL,
    arg3   IN VARCHAR2 DEFAULT NULL,
    arg4   IN VARCHAR2 DEFAULT NULL,
    arg5   IN VARCHAR2 DEFAULT NULL
);
```

## Parameters

|    Parameter     |           Description            |
|-----------|-------------------------|
|file|The active file handle returned by the `FOPEN` procedure.|
|format|The format string, which can contain the following elements: <ul><li><code>%s</code>: up to five placeholders that are replaced by the values of the argN parameters in sequence. <li><code>\n</code>: a line break, which can be used multiple times in the string. </li></ul>|
|arg1 to arg5|Up to five optional parameters that replace the `%s` placeholders in the `format` string. If the number of parameters is less than the number of placeholders, the un-replaced `%s` placeholders are retained or ignored. |
