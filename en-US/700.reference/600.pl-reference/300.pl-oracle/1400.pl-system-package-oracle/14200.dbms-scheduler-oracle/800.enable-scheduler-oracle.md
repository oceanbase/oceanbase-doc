# ENABLE

The `ENABLE` procedure is used to enable jobs and programs.

When an object is enabled, its `enabled` attribute is set to `TRUE`. By default, newly created jobs and programs are disabled.

If a job is disabled and then enabled again, the Scheduler will start running the job according to its schedule.

Validity checks are performed before enabling an object. If the check fails, the object cannot be enabled, and an error message is returned. If the object is successfully enabled, no error message is returned.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_SCHEDULER.ENABLE (
job_name              IN VARCHAR2);
```

## Parameters

|        Parameter       |     Description       |
|------------------|----------------|
| job_name              | The name of the Scheduler object to be enabled. The name can be a comma-separated list. If a job class name is specified, all jobs in that class will be enabled.<p>The system-defined scheduled jobs are as follows:</p><ul><li>`SCHEDULED_TRIGGER_PARTITION_BALANCE`: the partition balancing task</li> <li>`DAILY_MAINTENANCE_WINDOW`: the window compaction task</li></ul>   |

## Considerations

* You can use the `ENABLE` procedure for any schema except the `SYS` schema.

* To enable the `SCHEDULED_TRIGGER_PARTITION_BALANCE` task, the tenant-level parameter [partition_balance_schedule_interval](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/6400.partition_balance_schedule_interval.md) must be set to 0. Otherwise, an error `OB_OP_NOT_ALLOW` will be returned. The parameter trigger and the scheduled task trigger cannot be enabled at the same time.

* To enable the `DAILY_MAINTENANCE_WINDOW` task, the tenant-level parameter [enable_window_compaction](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3150.enable_window_compaction.md) must be set to `True`. Otherwise, an error will be returned.

## Examples

* Enable the program named `job_test`.

  ```shell
  obclient(SYS@oracle001)[SYS]> delimiter //
  ```

  ```shell
  obclient(SYS@oracle001)[SYS]> BEGIN
    DBMS_SCHEDULER.ENABLE(job_name => 'job_test');
  END;//
  ```

  ```shell
  obclient(SYS@oracle001)[SYS]> delimiter ;
  ```

* Enable the scheduled partition balancing task.

  ```shell
  obclient(SYS@oracle001)[SYS]> CALL DBMS_SCHEDULER.ENABLE(job_name => 'SCHEDULED_TRIGGER_PARTITION_BALANCE');
  ```

  or

  ```shell
  obclient(SYS@oracle001)[SYS]> CALL DBMS_SCHEDULER.ENABLE('SCHEDULED_TRIGGER_PARTITION_BALANCE');
  ```

* Enable the window compaction task.

  ```shell
  obclient(SYS@oracle001)[SYS]> CALL DBMS_SCHEDULER.ENABLE(job_name => 'DAILY_MAINTENANCE_WINDOW');
  ```

  or

  ```shell
  obclient(SYS@oracle001)[SYS]> CALL DBMS_SCHEDULER.ENABLE('DAILY_MAINTENANCE_WINDOW');
  ```
