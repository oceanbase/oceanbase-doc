# WRITE_RAW

`WRITE_RAW` writes binary data to the HTTP request body.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package is available starting from V4.4.1. </p>
</main>

## Syntax

```sql
UTL_HTTP.WRITE_RAW(
   r     IN OUT NOCOPY REQ,
   data  IN            RAW);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|r|The HTTP request.|
|data|The binary data to be written.
