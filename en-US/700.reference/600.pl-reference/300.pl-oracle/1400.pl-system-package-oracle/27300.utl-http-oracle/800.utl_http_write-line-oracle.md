# WRITE_LINE

The `WRITE_LINE` procedure writes a line of text data to the HTTP request body.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package is introduced in V4.4.1. </p>
</main>

## Syntax

```sql
UTL_HTTP.WRITE_LINE(
   r     IN OUT NOCOPY req,
   data  IN VARCHAR2 CHARACTER SET ANY_CS);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|r|The HTTP request.|
|data|The text data to be written.
