# GET_TRANSFER_TIMEOUT

`GET_TRANSFER_TIMEOUT` is used to obtain the maximum timeout period for HTTP data transfer.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package was introduced in V4.4.1. </p>
</main>

## Syntax

```sql
UTL_HTTP.GET_TRANSFER_TIMEOUT (
   timeout  OUT PLS_INTEGER);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|timeout|The maximum timeout period for HTTP data transfer, in seconds|
