# Overview of UTL_HTTP

The `UTL_HTTP` system package is a system tool that enables HTTP and HTTPS communication in a PL/SQL environment. It allows the database to directly interact with external web services.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The system package was introduced in OceanBase Database V4.4.1. </p>
</main>

## Overview of UTL_HTTP subprograms

The following table lists the `UTL_HTTP` subprograms supported in the current version of OceanBase Database and their brief descriptions.

|                       **Subprogram**             |                **Description**                       |
|----------------------------------------------|-----------------------------------------------|
|[BEGIN_REQUEST](110.begin-request-oracle.md)|Establishes an HTTP connection with the given URL, sends an HTTP request to the URL, and returns a `req` variable|
|[END_REQUEST](200.end-request-oracle.md)|Forcibly closes a request, regardless of whether the request or subsequent response is completed, and closes the HTTP connection|
|[GET_RESPONSE](300.get-response-oracle.md)|Retrieves the response to an HTTP request|
|[END_RESPONSE](400.end-response-oracle.md)|Terminates the response to an HTTP request after the request is completed|
|[READ_LINE](500.read-line-oracle.md)|Reads a line of text data from the HTTP response body|
|[READ_RAW](600.read-raw-oracle.md)|Reads binary data from the HTTP response body|
|[READ_TEXT](700.read-text-oracle.md)|Reads text data|
|[WRITE_LINE](800.utl_http_write-line-oracle.md)|Writes a line of text data to the HTTP request body|
|[WRITE_RAW](900.utl_http_write-raw-oracle.md)|Writes binary data to the HTTP request body|
|[WRITE_TEXT](1000.utl_http_write-text-oracle.md)|Writes text data to the HTTP request body|
|[SET_TRANSFER_TIMEOUT](1100.set-transfer-timeout-oracle.md)|Sets the maximum timeout for HTTP data transfer|
|[GET_TRANSFER_TIMEOUT](1200.get-transfer-timeout-oracle.md)|Retrieves the current maximum timeout for HTTP data transfer|

## Examples

Send a GET request:

```sql
DECLARE
  req  UTL_HTTP.REQ;
  resp UTL_HTTP.RESP;
  url  VARCHAR2(256) := 'https://api.example.com/data';
  buf  VARCHAR2(4000);
BEGIN
  req := UTL_HTTP.BEGIN_REQUEST(url, 'GET');
  resp := UTL_HTTP.GET_RESPONSE(req);
  LOOP
    UTL_HTTP.READ_TEXT(resp, buf);
    DBMS_OUTPUT.PUT_LINE(buf);
  END LOOP;
EXCEPTION
  WHEN UTL_HTTP.END_OF_BODY THEN
    UTL_HTTP.END_RESPONSE(resp);
END;
```
