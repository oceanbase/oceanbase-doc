# WRITE_TEXT

`WRITE_TEXT` writes text data to the HTTP request body.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package is available starting from V4.4.1. </p>
</main>

## Syntax

```sql
UTL_HTTP.WRITE_TEXT(
   r     IN OUT NOCOPY REQ,
   data  IN            VARCHAR2 CHARACTER SET ANY_CS);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|r|The HTTP request.|
|data|The text data to be written.
