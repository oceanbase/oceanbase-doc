# Overview

`XMLType` is a system-defined type for handling XML data.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL-compatible mode. </p>
  </main>

PL/SQL `XMLType` supports any SQL expression that returns an XMLType value and can use the `GETCLOBVAL()` and `GETSTRINGVAL()` methods in SQL semantics. Here are some examples:

```sql

  -- Formats the input XSL according to the xsl:stylesheet defined in it and returns the result, which is of the XMLType type.
  MEMBER FUNCTION TRANSFORM(xsl IN XMLTYPE) RETURN XMLTYPE,

  -- Convert XMLType to CLOB or VARCHAR2 Function
  MEMBER FUNCTION GETCLOBVAL RETURN CLOB,
  MEMBER FUNCTION GETSTRINGVAL RETURN VARCHAR2,

  -- Map XMLType to PL/SQL object instances
  MEMBER PROCEDURE TOOBJECT(object OUT NOCOPY <object_type>),

  -- Converting input CLOB or VARCHAR2 data to XMLType involves performing validity checks.
  STATIC FUNCTION CREATEXML(xmldata IN CLOB) RETURN XMLTYPE,
  STATIC FUNCTION CREATEXML(xmldata IN VARCHAR2) RETURN XMLTYPE,

  -- Construct an instance of the XMLType data type.
  CONSTRUCTOR FUNCTION XMLTYPE(xmldata IN CLOB) RETURN SELF AS RESULT,
  CONSTRUCTOR FUNCTION XMLTYPE(xmldata IN VARCHAR2) RETURN SELF AS RESULT

```

The following table lists the XMLType subprograms supported in the current version of OceanBase Database and their brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [CREATEXML](200.getxml-oracle.md) | A static function for creating and returning an XMLType instance. |
| [GETCLOBVAL](300.getclobval-oracle.md) | Returns the value of an XMLType instance in `CLOB` format. |
| [GETSTRINGVAL](400.getstringval-oracle.md) | Returns the value of an XMLType instance as a string. |
| [TRANSFORM](500.transform-oracle.md) | Gets an XMLType instance and an associated stylesheet (also an XMLType instance), applies the stylesheet, and returns the result as XML. |
| [XMLTYPE](600.getxmltype-oracle.md) | Constructs an instance of the XMLType data type. The constructor can accept XML data as a `CLOB`, `VARCHAR2`, or corresponding object type. |
| [EXISTSNODE](700.existsnode-oracle.md) | Checks whether a node exists at the specified XPath path in the XML variable. |
| [EXTRACT](800.extract-oracle.md) | Similar to `EXISTSNODE`, returns the set of nodes if they exist. |
| [TOOBJECT](900.toobject-oracle.md) | Maps an XMLType instance to a PL/SQL object instance (supported starting from V4.4.2 BP3). |
