# Overview

`XMLType` is a system-defined type for handling XML data.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL-compatible mode. </p>
  </main>

PL/SQL `XMLType` supports any SQL expression that returns an XMLType value and can use the `GETCLOBVAL()` and `GETSTRINGVAL()` methods in SQL semantics. Here are some examples:

```sql

  -- Returns the input xsl formatted according to the xsl:stylesheet defined in it. The return value is of the XMLType type.
  MEMBER FUNCTION TRANSFORM(xsl IN XMLTYPE) RETURN XMLTYPE,

  -- Converts an XMLType to a CLOB or VARCHAR2.
  MEMBER FUNCTION GETCLOBVAL RETURN CLOB,
  MEMBER FUNCTION GETSTRINGVAL RETURN VARCHAR2,

  -- Converts an input CLOB or VARCHAR2 to an XMLType, and performs validity checks.
  STATIC FUNCTION CREATEXML(xmldata IN CLOB) RETURN XMLTYPE,
  STATIC FUNCTION CREATEXML(xmldata IN VARCHAR2) RETURN XMLTYPE,

  -- Constructs an instance of the XMLType data type.
  CONSTRUCTOR FUNCTION XMLTYPE(xmldata IN CLOB) RETURN SELF AS RESULT,
  CONSTRUCTOR FUNCTION XMLTYPE(xmldata IN VARCHAR2) RETURN SELF AS RESULT

```

The following table lists the XMLType subprograms supported in the current version of OceanBase Database and their brief descriptions.

|                       Subprogram                   |                      Description                     |
|-----------------------------------------------|-------------------------------------------------|
| [CREATEXML](../29600.xmltype-oracle/200.getxml-oracle.md)    | A static function for creating and returning an XMLType instance.    |
| [GETCLOBVAL](../29600.xmltype-oracle/300.getclobval-oracle.md)   | Returns the value of an XMLType instance in `CLOB` format.   |
| [GETSTRINGVAL](../29600.xmltype-oracle/400.getstringval-oracle.md) | Returns the value of an XMLType instance as a string.  |
| [TRANSFORM](../29600.xmltype-oracle/500.transform-oracle.md)    | Gets an XMLType instance and an associated stylesheet (also an XMLType instance), applies the stylesheet, and returns the result as XML. |
| [XMLTYPE](../29600.xmltype-oracle/600.getxmltype-oracle.md)      | Constructs an instance of the XMLType data type. The constructor can accept XML data as a `CLOB`, `VARCHAR2`, or corresponding object type.  |
| [EXISTSNODE](../29600.xmltype-oracle/700.existsnode-oracle.md)      | Checks whether a node exists at the specified XPath path in the XML variable.  |
| [XMLTYPE](../29600.xmltype-oracle/800.extract-oracle.md)      | Similar to `EXISTSNODE`, returns the set of nodes if they exist.  |
