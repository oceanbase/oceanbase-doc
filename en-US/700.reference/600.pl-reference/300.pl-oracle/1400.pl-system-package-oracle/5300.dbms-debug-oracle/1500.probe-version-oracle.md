# PROBE_VERSION

The `PROBE_VERSION` procedure returns the version number of `DBMS_DEBUG` on the server.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_DEBUG.PROBE_VERSION (
major out BINARY_INTEGER,
minor out BINARY_INTEGER);
```

## Parameters

| **Parameter** |        **Description**        |
|--------|----------------------|
| major  | The major version number.               |
| minor  | The minor version number (iterated as new features are added). |
