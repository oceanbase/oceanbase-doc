# DEBUG_OFF

The `DEBUG_OFF` procedure is used to notify the target session to stop debugging. This procedure is not required to be called before ending the session.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Syntax

```sql
DBMS_DEBUG.DEBUG_OFF;
```
