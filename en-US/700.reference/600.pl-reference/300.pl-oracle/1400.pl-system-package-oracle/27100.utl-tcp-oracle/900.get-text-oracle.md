# GET_TEXT

The `GET_TEXT` function returns the text data that is read.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_TCP.GET_TEXT (
   c    IN OUT NOCOPY connection,
   len  IN            PLS_INTEGER DEFAULT 1,
   peek IN            BOOLEAN     DEFAULT FALSE) 
 RETURN VARCHAR2;
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c| The TCP/IP connection. |
|len| The number of characters to receive. The default value is 1. |
When `peek` is set to `true`, the data is viewed but not removed from the input queue (requires the existence of an input buffer).

## Return value

The return value is the content of the text line that is read.

## Remarks

* The connection must be opened by using the `open_connection` function.
* If the buffer size is specified, it is in bytes. The parameter `len` specifies the maximum number of characters to read. Make sure that the buffer size is at least as large as one character. Generally, the buffer size is set to the product of the number of characters to be read and the maximum number of bytes per character.
* The message text is converted from the online character set when the connection is opened to the database character set, and then returned.
* If a packet transfer timeout is set when the connection is opened, this function will continue to wait for data packets until the timeout occurs, and then stop reading data. In this case, all the data that is successfully read is returned. If no data is successfully read, a `transfer_timeout` exception is thrown.
