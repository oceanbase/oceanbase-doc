# CLOSE_CONNECTION

The `CLOSE_CONNECTION` procedure is used to close an open TCP/IP connection.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_TCP.CLOSE_CONNECTION (
   c IN OUT NOCOPY connection);
```

## Parameter explanation

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The TCP/IP connection to be closed. |

## Considerations

* The connection to be closed must have been opened by using the `open_connection` procedure. After the connection is closed, the `remote_host`, `remote_port`, `local_host`, `local_port`, `charset`, and `private_sd` fields will be reset.
* You must explicitly close an open connection. If the `connection` variable goes out of scope, the connection will not be automatically closed.
* Any connections that are not closed before the session is closed will be closed automatically.
