# WRITE_RAW

The `WRITE_RAW` procedure is used to send binary data over an open connection.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_TCP.WRITE_RAW (
   c    IN OUT NOCOPY connection,
   data IN            RAW,
   len  IN            PLS_INTEGER DEFAULT NULL)
 RETURN PLS_INTEGER;
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c| The TCP/IP connection. |
|data| The buffer containing the data to be sent. |
|len| The number of bytes to be transmitted. If `NULL`, all data is transmitted. |

## Return value

The number of bytes of data actually transmitted.

## Considerations

* The connection must have been opened using the `open_connection` procedure.
* If `len` exceeds the amount of data in `data`, a `bad argument` exception is thrown.
