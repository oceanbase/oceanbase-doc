# DBMS_PARTITION overview

The `DBMS_PARTITION` package provides the dynamic partition management interface.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For OceanBase Database V4.3.5, the <code>DBMS_PARTITION</code> package is supported starting from V4.3.5 BP2. </p>
</main>

## Privilege requirements

You can execute this package only in a user tenant.

## Subprograms

The following table describes the subprograms supported in the current version of OceanBase Database and their descriptions.

|                                   Subprogram                                 |           Description          |
|--------------------------------------------------------------------------|------------------------|
| [MANAGE_DYNAMIC_PARTITION](200.manage_dynamic_partition-of-oracle-mode.md)|  Executes a dynamic partition management task to precreate future partitions and drop expired partitions for dynamic partition tables in the current tenant.|
