# REFRESH_REPORT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, <code>REFRESH_REPORT</code> was introduced starting from V4.4.2 BP2.</p>
</main>

`REFRESH_REPORT` is used to generate a hierarchical diagnostic report for a single materialized view refresh task.

## Limitations and considerations

Specify at least one of `refresh_id` and `mv_name`.

## Syntax

```sql
DBMS_MVIEW.REFRESH_REPORT(
    {refresh_id | mv_name}
    [, format]
    [, tenant_id])
```

## Parameters

| **Parameter** | **Note** |
| ------------ | ---------- |
| refresh_id | The unique identifier of a materialized view refresh batch, assigned by the new scheduling framework. <main id="notice" type='explain'><h4>Note</h4><p>You can view the <code>refresh_id</code> information in the <a href="../../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/9600.dba_mvref_run_stats-of-oracle-mode.md">DBA_MVREF_RUN_STATS</a> view.</p></main> |
| mv_name | Specify the name of the materialized view (for example,`SCHEMA.MV_NAME`). |
| format | Optional. Specifies the report output format. Valid values: <ul><li>`XML`(Default value)</li><li>`JSON`</li></ul> |
| tenant_id | Currently only`sys`Tenant available, used to query the materialized view refresh reports of other tenants. |

## Return value

* Return type: `CLOB`.
* Content format: Depends on the `format` parameter. It can be text in `XML` or `JSON` format.

## Examples

* Retrieve the diagnostic report in `XML` format by using the `refresh_id`.

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023) FROM DUAL;
    ```

* Obtain a report in JSON format.

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023, format => 'JSON') FROM DUAL;
    ```

* Retrieve the most recently refreshed report by its name.

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(mv_name=> 'TEST.MV_SALES_DAILY') FROM DUAL;
    ```

* The `sys` tenant queries the refresh reports of other tenants.

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023, tenant_id=> 1002) FROM DUAL;
    ```
