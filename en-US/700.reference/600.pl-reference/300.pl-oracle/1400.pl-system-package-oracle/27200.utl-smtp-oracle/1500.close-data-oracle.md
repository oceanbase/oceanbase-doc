# CLOSE_DATA

The `CLOSE_DATA` procedure sends a `<CR><LF>.<CR><LF>` sequence to indicate that the mail text has been sent completely.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to the Oracle mode of OceanBase Database. </p>
  </main>

## Syntax

```sql
UTL_SMTP.CLOSE_DATA (
   c     IN OUT NOCOPY connection) 
RETURN reply;

UTL_SMTP.CLOSE_DATA (
   c     IN OUT NOCOPY connection);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are received, the last reply is returned. |

## Remarks

The `OPEN_DATA`, `WRITE_DATA`, `WRITE_RAW_DATA`, and `CLOSE_DATA` procedures must be called in sequence. The `OPEN_DATA` procedure sends the `DATA` command to indicate that the mail content is about to be sent. Then, you can call the `WRITE_DATA` or `WRITE_RAW_DATA` procedure multiple times to send the mail body. Finally, the `CLOSE_DATA` procedure sends a termination sequence to indicate that the mail content has been sent completely.
