# MAIL

You can use the `MAIL` procedure to initiate a mail transaction with the SMTP service and declare the sender's email address.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.MAIL (
   c           IN OUT NOCOPY   connection, 
   sender      IN              VARCHAR2, 
   parameters  IN              VARCHAR2 DEFAULT NULL) 
RETURN reply;

UTL_SMTP.MAIL (
   c           IN OUT NOCOPY   connection, 
   sender      IN              VARCHAR2, 
   parameters  IN              VARCHAR2 DEFAULT NULL);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
|sender|The sender's email address. |
|parameters|The parameters must be in the "XXX=XXX (XXX=XXX ....)" format, which is defined in RFC 1869 for the SMTP protocol. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are returned, the last reply is returned. |

## Remarks

The `mail` command is used to notify the server that a new mail transaction is initiated. You must call the `rcpt` and `data` commands to complete the transaction. The connection to the SMTP server must be open, and you must have called the `helo` or `ehlo` command.
