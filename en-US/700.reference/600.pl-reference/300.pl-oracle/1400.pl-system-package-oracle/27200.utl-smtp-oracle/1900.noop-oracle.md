# NOOP

Verifies whether the server is still connected and listening.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.NOOP (
   c  IN OUT NOCOPY connection) 
RETURN reply;

UTL_SMTP.NOOP (
   c  IN OUT NOCOPY connection);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are returned, the last reply is returned. |

## Remarks

* It is used to elicit a successful reply from the server. After you establish an SMTP connection by using the `open_connect` procedure, you can use the `noop` procedure to verify whether the server is still connected and listening.
* The expected reply is a response that starts with `250`, which indicates that the server is connected and listening.
