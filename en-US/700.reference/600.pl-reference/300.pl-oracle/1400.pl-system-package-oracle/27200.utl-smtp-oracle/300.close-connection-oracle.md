# CLOSE_CONNECTION

The `CLOSE_CONNECTION` procedure is used to close an SMTP connection, which terminates the SMTP operation. It is only applicable for canceling an email in a data session.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.CLOSE_CONNECTION (
   c     IN OUT NOCOPY connection);
```

## Parameter explanation

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
