# HELP

Sends the `HELP` command to retrieve help information.

<main id="notice" >
    <h4>Applicability</h4>
    <p> This topic applies only to the Oracle mode of OceanBase Database. </p>
  </main>

## Syntax

```sql
UTL_SMTP.HELP (
   c         IN OUT NOCOPY   connection, 
   command   IN              VARCHAR2 DEFAULT NULL) 
RETURN replies;
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
|command|The command to retrieve help information. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are received, the last reply is returned. |
