# VRFY

Verifies the validity of a target email address by sending the `VRFY` command.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.VRFY (
   c          IN OUT NOCOPY connection
   recipient  IN VARCHAR2) 
RETURN reply;
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
|recipient|The email address to be verified. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are returned, the last reply is returned. |

## Remarks

* The server will attempt to parse the email address to be verified. If successful, it will return the full name of the recipient and the complete email address path.
* This procedure must be called after `open_connection` and `helo` or `ehlo`.
* The expected reply codes are `250` and `251`.
  * `250`: If the SMTP server successfully processes the VRFY (verify) request and can confirm that the queried email address is valid, this code is returned. This means that the email address exists and can receive emails.
  * `251`: If the requested email address does not belong to the local system but the server knows how to forward it to the correct destination, this code may be returned.
