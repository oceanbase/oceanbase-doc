# OPEN_DATA

The `OPEN_DATA` procedure is called to send the `data` command to the server to indicate the start of sending the email content. Then, you can use the `write_data` and `write_raw_data` procedures to write the email content.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to the Oracle mode of OceanBase Database. </p>
  </main>

## Syntax

```sql
UTL_SMTP.OPEN_DATA (
   c     IN OUT NOCOPY connection) 
RETURN reply;

UTL_SMTP.OPEN_DATA (
   c     IN OUT NOCOPY connection);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |

## Return values

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are received, the last reply is returned. |

## Considerations

* The `OPEN_DATA`, `WRITE_DATA`, `WRITE_RAW_DATA`, and `CLOSE_DATA` procedures must be called in sequence. After the `open_data` procedure sends the `data` command to indicate the start of sending the email content, you can call the `write_data` or `write_raw_data` procedure multiple times to send the email content. Finally, the `close_data` procedure is called to send the termination character to end the email content transmission.
* The `RCPT` procedure must be called after the `open_data` procedure.
* A reply starting with `250` or `251` indicates that the SMTP server successfully responded to and accepted the specified email content.
