# RSET

Sends the `RSET` command to terminate the current email transaction.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.RSET (
   c  IN OUT NOCOPY connection) 
RETURN reply;

UTL_SMTP.RSET (
   c  IN OUT NOCOPY connection);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are returned, the last reply is returned. |

## Remarks

* The `RSET` command allows you to cancel an email that you are writing and prevent it from being sent. You can use it between `open_connection` and `data` or `open_data`. However, once an email starts to be sent, it cannot be canceled.
* The expected reply is a response that starts with `250`, indicating that the current email transaction is terminated.
