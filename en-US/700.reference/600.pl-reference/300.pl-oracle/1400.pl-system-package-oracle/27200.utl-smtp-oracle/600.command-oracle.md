# COMMAND

The `COMMAND` procedure is used to execute general SMTP commands.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.COMMAND (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL)
RETURN reply;

UTL_SMTP.COMMAND (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
|cmd|The `command` to send to the server. |
|arg|Additional information or parameters related to the `cmd` command. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the `command`. If multiple replies are returned, the last reply is returned. |

## Remarks

This procedure returns only one reply line (the last reply line if multiple reply lines are returned). If you need to return multiple reply lines, use the `command_replies` procedure.
