# DATA

The `DATA` parameter specifies the email body. 

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.DATA (
   c     IN OUT NOCOPY connection
   body  IN  VARCHAR2 CHARACTER SET ANY_CS) 
RETURN reply;

UTL_SMTP.DATA (
   c     IN OUT NOCOPY connection
   body  IN VARCHAR2 CHARACTER SET ANY_CS);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection.|
|body|The text information to be sent, which includes headers and is in the [RFC822] format. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are received, the last reply is returned. |

## Remarks

* The application must ensure that the content of the body parameter complies with the `MIME (RFC822)` standard. The termination message `<CR><LF>.<CR><LF>` is added to the end of the text. The `<CR><LF>.<CR><LF>` in the text is translated into `<CR><LF>..<CR><LF>`. The `RCPT` command must be called before the text is sent.
* A response that starts with `250` is expected. The return code `354`, which indicates the start of the email body transmission after the `DATA` command is sent from the client to the SMTP server, is not returned. 

   * The `354` code indicates that the server is ready to receive the email body after the `DATA` command is sent from the client to the SMTP server.

   * The `250` code indicates that the request is successfully received and processed.
