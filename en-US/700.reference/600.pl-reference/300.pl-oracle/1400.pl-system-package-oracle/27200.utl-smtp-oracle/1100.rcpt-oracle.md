# RCPT

The `RCPT` package procedure is called to execute the `rcpt` command and specify the recipient of an email.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.RCPT (
   c           IN OUT NOCOPY     connection,
   recipient   IN                VARCHAR2,
   parameters  IN                VARCHAR2 DEFAULT NULL)
RETURN reply;

UTL_SMTP.RCPT (
   c           IN OUT NOCOPY     connection,
   recipient   IN                VARCHAR2,
   parameters  IN                VARCHAR2 DEFAULT NULL);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
|recipient|The recipient's email address. |
|parameters|The parameters must be in the "XXX=XXX (XXX=XXX ....)" format, which is defined in RFC 1869 for the SMTP protocol. |

## Return value

| **Return value** |          **Description**          |
|---------|--------------------------|
|reply|The reply to the command. If multiple replies are returned, the last reply is returned. |

## Remarks

* The `RCPT` procedure is called to specify a single recipient's email address each time. Multiple calls to the `RCPT` procedure are made to specify multiple recipients.
* The `mail` procedure must be called before you call the `RCPT` procedure.
* The expected replies are those whose status codes are `250` or `251`, indicating that the SMTP server successfully responded to and accepted the specified recipient's address.
