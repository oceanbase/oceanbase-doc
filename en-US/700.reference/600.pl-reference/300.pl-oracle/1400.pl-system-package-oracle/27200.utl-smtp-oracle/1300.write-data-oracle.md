# WRITE_DATA

The `WRITE_DATA` procedure sends the content of a text email. You can call this procedure multiple times to add data to the email.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.WRITE_DATA (
   c     IN OUT NOCOPY connection, 
   data  IN VARCHAR2 CHARACTER SET ANY_CS);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
|data|A part of the message text to send. The `headers` section is included. It is in the [RFC822] format. |

## Considerations

* You must call the `OPEN_DATA`, `WRITE_DATA`, `WRITE_RAW_DATA`, and `CLOSE_DATA` procedures in sequence. The `OPEN_DATA` procedure sends the `DATA` command to declare the start of the email content. Then you can call the `WRITE_DATA` or `WRITE_RAW_DATA` procedure multiple times to send the email body. Finally, the `CLOSE_DATA` procedure sends the termination character to end the email content.
* The application must ensure that the text content complies with the `MIME (RFC822)` specification. The application must send the termination message `.<CR><LF>`. In the text content, the `<CR><LF>.<CR><LF>` sequence will be translated into `<CR><LF>..<CR><LF>`.
* The text (varchar2) data will be converted to the `US7ASCII` character set before it is sent. If a character in the text data is a multi-byte character and cannot be converted to the `US7ASCII` character set, it will be converted to the `?` character.
* If the `ehlo` negotiation with the `smtp` server supports the `8BITMIME` extension, you can use the `utl_raw` package to convert the text data to raw data and then call the `WRITE_RAW_DATA` procedure to send the raw data.
