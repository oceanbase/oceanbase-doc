# About external tables and external files

The data of an external table is stored in a storage system outside the OceanBase cluster (such as local directories, object storage, or HDFS). The database only stores the metadata and access paths. After an external table is created, it can be used for operations such as `SELECT`, JOIN, and aggregation, just like a regular table. However, it is **read-only** and does not support DML, constraints, or indexes.

Differences from regular tables:

| Feature | External table | Regular table |
| ---- | ---- | ------ |
| Data location | External storage | Inside OceanBase |
| Read/write | External tables are **read-only**: you can perform `SELECT`, but cannot execute DML operations such as `INSERT`, `UPDATE`, or `DELETE`. | Read/write |
| Constraints and indexes | Not supported | Supported |
| Typical performance | Affected by the network and external systems | Faster local access |

## Considerations

* Files are collected based on the `LOCATION` and `PATTERN` parameters during creation. New files require a refresh. For more information, see [Manage external files](300.manage-external-files-of-oracle-mode.md) and [ALTER EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/100.alter-external-table-of-oracle-mode.md).
* For an external table partition with `PARTITION_TYPE = USER_SPECIFIED`, you can add or delete the partition `LOCATION` by using [ALTER EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/100.alter-external-table-of-oracle-mode.md). Note that the ALTER capabilities in MySQL-compatible mode may vary; refer to the corresponding documentation.
* A query will not report an error for deleted external files. Concurrently modifying an external file may result in unexpected outcomes.

## HDFS external table

To access HDFS, you must [deploy the Java SDK environment for OceanBase Database](../../../../../400.deploy/300.deploy-oceanbase-enterprise-edition/500.deploy-the-ob-java-sdk-environment.md) and configure parameters such as [ob_enable_java_env](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/16630.ob_enable_java_env.md). For details, see [CREATE EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1600.create-external-table-of-oracle-mode.md). For troubleshooting, see [Troubleshooting guide for external tables](../../../../../600.manage/1000.troubleshooting/1700.external-table-troubleshooting.md).
