# Drop a catalog

When a catalog is no longer in use, you can drop it by using the `DROP CATALOG external_catalog_name;` statement.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>Unlike MySQL-compatible mode, the <code>DROP CATALOG</code> statement in Oracle-compatible mode does not support the <code>IF EXISTS</code> clause. If the catalog to be dropped does not exist, an error with code <code>-11080</code> will be returned.</p>
</main>

After a catalog is dropped, other users' `USE CATALOG` object privileges on that catalog are also revoked.

## Privilege requirements

To drop an external catalog, the current user must have the `CREATE CATALOG` system privilege.

For more information about OceanBase Database privileges, see [Privilege types in Oracle-compatible mode](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Examples

```sql
obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

obclient> DROP CATALOG tmp_catalog;
```
