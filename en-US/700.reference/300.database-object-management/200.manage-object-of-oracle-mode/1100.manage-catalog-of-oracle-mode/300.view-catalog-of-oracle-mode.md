# View Catalogs

After creating a catalog, you can use SQL statements to view information about it.

## View the statement used to create a catalog

You can use the `SHOW CREATE CATALOG external_catalog_name;` statement to view the creation statement of a catalog.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>For security reasons, sensitive attributes in the creation statement (such as ODPS's <code>ACCESSID</code>, <code>ACCESSKEY</code>, <code>STSTOKEN</code>, and JDBC's <code>URL</code>) are masked.</p>
</main>

**Example:**

```sql
obclient> SHOW CREATE CATALOG test_jdbc_catalog;
```

## View catalogs visible to the current user

You can use the `SHOW CATALOGS;` statement to view the catalogs visible to the current user.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Catalogs for which the current user does not have the <code>USE CATALOG</code> privilege will not appear in the results.</p>
</main>

**Example:**

```sql
obclient> SHOW CATALOGS;
```

## View the current catalog

You can use the `CURRENT_CATALOG()` or `CATALOG()` function to view the catalog of the current session.

**Example:**

```sql
obclient> SELECT CURRENT_CATALOG() FROM dual;
```

## View data in a catalog

In a catalog, you can perform query operations just like on tables within a database, and you can also perform cross-catalog join queries.

**Example:**

* Access an external table directly using the three-part naming convention (catalog name.schema name.table name).

  ```text
  SELECT * FROM test_jdbc_catalog.dbo.table_name;
  ```

* Cross-Catalog joint query.

  ```text
  SELECT * FROM internal.system.test_t1, test_odps_catalog.project_name.test_t1;
  ```

## Catalog switching

You can use the `SET CATALOG catalog_name;` statement to switch Catalogs. For more information, see [SET CATALOG](../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/4900.set-catalog-of-oracle-mode.md).

**Examples:**

* Switch to the internal system Catalog.

  ```sql
  obclient> SET CATALOG internal;
  ```

* Switch to an external Catalog.

  ```sql
  obclient> SET CATALOG test_jdbc_catalog;
  ```
