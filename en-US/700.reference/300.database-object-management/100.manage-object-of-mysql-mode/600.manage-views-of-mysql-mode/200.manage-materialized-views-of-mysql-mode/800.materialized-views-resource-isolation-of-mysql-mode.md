# Materialized view resource isolation

OceanBase Database supports `DBMS_RESOURCE_MANAGER` to provide resource isolation for incremental refresh and MLOG purge of materialized views, allowing you to limit the upper limit of resources that materialized views can use.

## Examples

1. Create a resource plan named `mview_task`.

    ```sql
    CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('mview_task','This resource plan is used for materialized view processing');
    ```

    For more information about creating resource plans, see [CREATE_PLAN](../../../../600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/13300.dbms-resource-manager-mysql/300.create-plan-mysql.md).

2. Create a consumer group named `mview_group`.

    ```sql
    CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('mview_group','Materialized view processing group');
    ```

    For more information about creating consumer groups, see [CREATE_CONSUMER_GROUP](../../../../600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/13300.dbms-resource-manager-mysql/200.create-consumer-group-mysql.md).

3. Create a resource plan directive to limit the CPU resource usage to 5%.

    ```sql
    CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE(
        PLAN => 'mview_task',
        GROUP_OR_SUBPLAN => 'mview_group',
        UTILIZATION_LIMIT => 5
        );
    ```

    For more information about creating resource plan directives, see [CREATE_PLAN_DIRECTIVE](../../../../600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/13300.dbms-resource-manager-mysql/400.create-plan-directive-mysql.md).

4. Bind the consumer group `mview_group` to `FUNCTION`.

    ```sql
    CALL DBMS_RESOURCE_MANAGER.SET_CONSUMER_GROUP_MAPPING(
        ATTRIBUTE => 'FUNCTION',
        VALUE => 'MVIEW',
        CONSUMER_GROUP => 'mview_group'
        );
    ```

    For more information about mapping sessions to consumer groups, see [SET_CONSUMER_GROUP_MAPPING](../../../../600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/13300.dbms-resource-manager-mysql/800.set-consumer-group-mappingn-directive-mysql.md).

5. Activate the resource management plan `mview_task`.

    ```sql
    SET GLOBAL resource_manager_plan = 'mview_task';
    ```

    For more information about activating resource management plans, see [resource_manager_plan](../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/11500.resource_manager_plan-global.md).

6. Modify the CPU resource usage upper limit to 30%.

    ```sql
    CALL DBMS_RESOURCE_MANAGER.UPDATE_PLAN_DIRECTIVE(
        PLAN => 'mview_task',
        GROUP_OR_SUBPLAN => 'mview_group',
        NEW_UTILIZATION_LIMIT => 30
        );
    ```

    For more information about updating resource plans, see [UPDATE_PLAN_DIRECTIVE](../../../../600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/13300.dbms-resource-manager-mysql/900.update-plan-directive-mysql.md).
