# Overview of database object management

Database objects are a crucial component of a database, primarily including tables, indexes, views, triggers, sequences, and more. OceanBase Database provides relevant database object management capabilities based on two compatibility modes: MySQL and Oracle.

This chapter on database object management covers the following operations:

| Database Object Type | Supported modes | Database Object Management |
| ---------------------- | ------------ | -------------------------- |
| Database | MySQL-compatible mode | This topic describes how to create, view, modify, and drop databases. For more information, see [Create a database](100.manage-object-of-mysql-mode/100.manage-databases-of-mysql-mode/100.to-create-a-database-of-mysql-mode.md). |
| Table | MySQL/Oracle-compatible mode | This topic describes how to create, modify, drop, lock, and truncate tables, as well as define column attributes and set constraint types. For more information, see [About tables (MySQL-compatible mode)](100.manage-object-of-mysql-mode/200.manage-tables-of-mysql-mode/100.about-tables-of-mysql-mode.md) and [About tables (Oracle-compatible mode)](200.manage-object-of-oracle-mode/100.manage-tables-of-oracle-mode/100.about-tables-of-oracle-mode.md). |
| External Table | MySQL/Oracle-compatible mode | This topic describes how to create external tables, create partitions of external tables, manage external files, and perform data type mapping. For more information, see [About external tables (MySQL-compatible mode)](100.manage-object-of-mysql-mode/200.manage-tables-of-mysql-mode/1000.manage-external-tables-of-mysql-mode/100.about-external-tables-of-mysql-mode.md) and [About external tables (Oracle-compatible mode)](200.manage-object-of-oracle-mode/100.manage-tables-of-oracle-mode/1000.manage-external-tables-of-oracle-mode/100.about-external-tables-of-oracle-mode.md). |
| Partition | MySQL/Oracle-compatible mode | This topic describes how to create, split, and manage dynamic partitions of a partitioned table, as well as adjust partitioning rules and add or drop partitions. For more information, see [Partition overview (MySQL-compatible mode)](100.manage-object-of-mysql-mode/300.manage-partitions-of-mysql-mode/100.partition-overview-of-mysql-mode.md) and [Partition overview (Oracle-compatible mode)](200.manage-object-of-oracle-mode/200.manage-partitions-of-oracle-mode/100.partition-overview-of-oracle-mode.md). |
| TableGroup | MySQL/Oracle-compatible mode | This topic describes how to create, view, add tables to, modify the SHARDING attribute of, and delete a table group. For more information, see [About table groups (MySQL-compatible mode)](100.manage-object-of-mysql-mode/400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md) and [About table groups (Oracle-compatible mode)](200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md). |
| Index | MySQL/Oracle-compatible mode | This topic describes how to create, view, monitor, and drop indexes, and describes the support for function-based indexes. For more information, see [About indexes (MySQL-compatible mode)](100.manage-object-of-mysql-mode/500.manage-indexes-of-mysql-mode/100.about-indexes-of-mysql-mode.md) and [About indexes (Oracle-compatible mode)](200.manage-object-of-oracle-mode/400.manage-indexes-of-oracle-mode/100.about-indexes-of-oracle-mode.md). |
| View | MySQL/Oracle-compatible mode | This topic describes how to create, modify, and drop normal views. For more information, see [Manage normal views (MySQL-compatible mode)](100.manage-object-of-mysql-mode/600.manage-views-of-mysql-mode/100.manage-normal-views-of-mysql-mode.md) and [Manage normal views (Oracle-compatible mode)](200.manage-object-of-oracle-mode/500.manage-views-of-oracle-mode/100.manage-normal-views-of-oracle-mode.md). |
| Materialized view | MySQL/Oracle-compatible mode | This topic describes how to create and refresh materialized views, rewrite queries, modify their attributes, and isolate their resources. For more information, see [Materialized view overview (MySQL-compatible mode)](100.manage-object-of-mysql-mode/600.manage-views-of-mysql-mode/200.manage-materialized-views-of-mysql-mode/100.materialized-views-overview-of-mysql-mode.md) and [Materialized view overview (Oracle-compatible mode)](200.manage-object-of-oracle-mode/500.manage-views-of-oracle-mode/200.manage-materialized-views-of-oracle-mode/100.materialized-views-overview-of-oracle-mode.md). |
| Sequence | MySQL/Oracle-compatible mode | This topic describes how to create, view, modify, and drop sequences. For more information, see [Create a sequence (MySQL-compatible mode)](100.manage-object-of-mysql-mode/700.manage-sequence-of-mysql-mode/100.create-a-sequence-of-mysql-mode.md) and [Manage sequences (Oracle-compatible mode)](200.manage-object-of-oracle-mode/600.management-sequence-of-oracle-mode.md). |
| Trigger | MySQL/Oracle-compatible mode | This topic describes how to create, view, and drop triggers. For more information, see [Overview (MySQL-compatible mode)](100.manage-object-of-mysql-mode/800.manage-triggers-of-mysql-mode/100.trigger-overview-of-mysql-mode.md) and [Overview (Oracle-compatible mode)](200.manage-object-of-oracle-mode/800.manage-triggers-of-oracle-mode/100.trigger-overview-of-oracle-mode.md). |
| DBLink | MySQL/Oracle-compatible mode | This topic describes how to create, view, and delete DBLinks. For more information, see [Create a DBLink (MySQL-compatible mode)](100.manage-object-of-mysql-mode/900.manage-dblink-of-mysql-mode/100.create-a-dblink-of-mysql-mode.md) and [Create a DBLink (Oracle-compatible mode)](200.manage-object-of-oracle-mode/1000.manage-dblink-of-oracle-mode/100.create-a-dblink-of-oracle-mode.md). |
| Catalog | MySQL-compatible mode | This topic describes how to create, view, and delete a catalog. For more information, see [Catalog overview](100.manage-object-of-mysql-mode/1000.manage-catalog-of-mysql-mode/100.catalog-overview-of-mysql-mode.md). |
| Synonym | Oracle-compatible mode | This topic describes how to create and drop synonyms. For more information, see [Manage synonyms](200.manage-object-of-oracle-mode/700.manage-synonyms-of-oracle-mode.md). |
| Directory | Oracle-compatible mode | This topic describes how to create and drop directories. For more information, see [Manage directories](200.manage-object-of-oracle-mode/900.manage-directories-of-oracle-mode.md). |
