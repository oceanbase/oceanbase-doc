# Overview

Database objects are essential components of a database, including tables, indexes, views, triggers, and sequences. OceanBase Database provides database object management capabilities based on its compatibility with both MySQL and Oracle modes.

This chapter describes the operations of the following database objects:

|     Database Object Type    |  Supported Mode  |     Database Object Management Description     |
|----------------------|------------|--------------------------|
| Database (Database)    | MySQL mode | Describes how to create, view, modify, and delete databases. For more information, see [Create a database](100.manage-object-of-mysql-mode/100.manage-databases-of-mysql-mode/100.to-create-a-database-of-mysql-mode.md).|
| Table (Table)           | MySQL/Oracle mode | Describes how to create, modify, delete, lock, and clear tables, as well as define column attributes and set constraint types. For more information, see [About tables (MySQL mode)](100.manage-object-of-mysql-mode/200.manage-tables-of-mysql-mode/100.about-tables-of-mysql-mode.md) and [About tables (Oracle mode)](200.manage-object-of-oracle-mode/100.manage-tables-of-oracle-mode/100.about-tables-of-oracle-mode.md).|
| External Table (External Table) | MySQL/Oracle mode | Describes how to create external tables, create external table partitions, manage external files, and map data types. For more information, see [About external tables (MySQL mode)](100.manage-object-of-mysql-mode/200.manage-tables-of-mysql-mode/1000.manage-external-tables-of-mysql-mode/100.about-external-tables-of-mysql-mode.md) and [About external tables (Oracle mode)](200.manage-object-of-oracle-mode/100.manage-tables-of-oracle-mode/1000.manage-external-tables-of-oracle-mode/100.about-external-tables-of-oracle-mode.md).|
| Partition (Partition)     | MySQL/Oracle mode | Describes how to create, split, and dynamically manage partitions, as well as adjust partition rules, add, and delete partitions. For more information, see [Partition overview (MySQL mode)](100.manage-object-of-mysql-mode/300.manage-partitions-of-mysql-mode/100.partition-overview-of-mysql-mode.md) and [Partition overview (MySQL mode)](200.manage-object-of-oracle-mode/200.manage-partitions-of-oracle-mode/100.partition-overview-of-oracle-mode.md).|
| Table Group (TableGroup)    | MySQL/Oracle mode | Describes how to create, view, add tables, modify SHARDING attributes, and delete table groups. For more information, see [About table groups (MySQL mode)](100.manage-object-of-mysql-mode/400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md) and [About table groups (Oracle mode)](200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md).|
| Index (Index)         | MySQL/Oracle mode | Describes how to create, view, monitor, and delete indexes, as well as support for function indexes. For more information, see [About indexes (MySQL mode)](100.manage-object-of-mysql-mode/500.manage-indexes-of-mysql-mode/100.about-indexes-of-mysql-mode.md) and [About indexes (Oracle mode)](200.manage-object-of-oracle-mode/400.manage-indexes-of-oracle-mode/100.about-indexes-of-oracle-mode.md).|
| View (View)          | MySQL/Oracle mode | Describes how to create, modify, and delete normal views. For more information, see [Manage normal views (MySQL mode)](100.manage-object-of-mysql-mode/600.manage-views-of-mysql-mode/100.manage-normal-views-of-mysql-mode.md) and [Manage normal views (Oracle mode)](200.manage-object-of-oracle-mode/500.manage-views-of-oracle-mode/100.manage-normal-views-of-oracle-mode.md).|
| Materialized View (Materialized View) | MySQL/Oracle mode | Describes how to create, refresh, query rewrite, modify attributes, and isolate resources for materialized views. For more information, see [Materialized views overview (MySQL mode)](100.manage-object-of-mysql-mode/600.manage-views-of-mysql-mode/200.manage-materialized-views-of-mysql-mode/100.materialized-views-overview-of-mysql-mode.md) and [Materialized views overview (Oracle mode)](200.manage-object-of-oracle-mode/500.manage-views-of-oracle-mode/200.manage-materialized-views-of-oracle-mode/100.materialized-views-overview-of-oracle-mode.md).|
| Sequence (Sequence)    | MySQL/Oracle mode | Describes how to create, view, modify, and delete sequences. For more information, see [Create a sequence (MySQL mode)](100.manage-object-of-mysql-mode/700.manage-sequence-of-mysql-mode/100.create-a-sequence-of-mysql-mode.md) and [Manage sequences (Oracle mode)](200.manage-object-of-oracle-mode/600.management-sequence-of-oracle-mode.md).|
| Trigger (Trigger)   | MySQL/Oracle mode | Describes how to create, view, and delete triggers. For more information, see [Overview (MySQL mode)](100.manage-object-of-mysql-mode/800.manage-triggers-of-mysql-mode/100.trigger-overview-of-mysql-mode.md) and [Overview (Oracle mode)](200.manage-object-of-oracle-mode/800.manage-triggers-of-oracle-mode/100.trigger-overview-of-oracle-mode.md).|
| DBLink (database link)| MySQL/Oracle mode | Describes how to create, view, and delete a DBLink. For more information, see [Create a DBLink (MySQL mode)](100.manage-object-of-mysql-mode/900.manage-dblink-of-mysql-mode/100.create-a-dblink-of-mysql-mode.md) and [Create a DBLink (Oracle mode)](200.manage-object-of-oracle-mode/1000.manage-dblink-of-oracle-mode/100.create-a-dblink-of-oracle-mode.md).|
| Catalog (data catalog)| MySQL mode | Describes how to create, view, and delete a catalog. For more information, see **Overview of Catalog**.|
| Synonym| Oracle mode | Describes how to create and delete a synonym. For more information, see [Manage synonyms](200.manage-object-of-oracle-mode/700.manage-synonyms-of-oracle-mode.md).|
| Directory| Oracle mode | Describes how to create and delete a directory. For more information, see [Manage directories](200.manage-object-of-oracle-mode/900.manage-directories-of-oracle-mode.md).|
