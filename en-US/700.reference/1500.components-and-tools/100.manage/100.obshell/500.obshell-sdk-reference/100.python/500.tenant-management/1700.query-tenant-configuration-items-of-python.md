# Query tenant parameters

This topic describes how to query tenant parameters using obshell-sdk-python, including exact query and fuzzy query.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>We recommend that you first read through the <b>Quick start</b> section of obshell-sdk-python to understand how to use it.</p>
</main>

## Query specific tenant parameters

### Considerations

* Ensure that obshell is running normally.

* Ensure the specified tenant exists and its status is NORMAL.

* The node corresponding to the requesting client must be part of an initialized cluster.

### Sample code

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# Create a client instance with the node address '10.10.10.1' and port 2886.
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

client.v1.get_tenant_parameter("t1", "max_partition_num")
```

## Fuzzy query for tenant parameters

### Considerations

* Ensure that obshell is running normally.

* Ensure the specified tenant exists and its status is NORMAL.

* The node corresponding to the requesting client must be part of an initialized cluster.

### Sample code

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# Create a client instance with the node address '10.10.10.1' and port 2886.
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

parameters = client.v1.get_tenant_parameters("t1", "max_partition%")
```
