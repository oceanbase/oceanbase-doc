# Cache usage specifications

This topic describes the cache usage specifications of OceanBase Database.

* If a field is frequently written to, we recommend that you use a write cache mechanism, such as for a counter.

* Use hints to control plan caching.

  * `/*+ USE_PLAN_CACHE(NONE)*/` indicates that plan caching is not used.

  * `/*+USE_PLAN_CACHE(DEFAULT)*/` indicates that plan caching is used.

* SQL statements cannot use hints such as `force index`, `ignore index`, `straight_join`, and `SQL_no_cache`.
