# DDL statement writing specifications

This topic describes the specifications for writing DDL statements in OceanBase Database.

- We recommend that you use the `TRUNCATE TABLE` statement to delete all data from a table.

- We recommend that you perform online DDL operations during off-peak hours to minimize the impact on the system.

* In versions earlier than V3.x, the concurrency of DDL operations must be limited to 40 or less.
