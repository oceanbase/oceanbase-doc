# CREATE_PLAN

The `CREATE_PLAN` procedure is used to create a resource plan.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only MySQL mode. </p>
  </main>

## Syntax

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN (
    plan          IN   VARCHAR2,
    comment       IN   VARCHAR2 DEFAULT'');
```

## Parameters

|   Parameter    |    Description    |
|---------|----------|
| plan    | The name of the resource plan. |
| comment | The user comment.    |

## Examples

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.CREATE_PLAN('DAY','The resource plan is used for transaction processing');
END ;
```

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.CREATE_PLAN('NIGHT','The resource plan is used for daily maintenance');
END ;
```
