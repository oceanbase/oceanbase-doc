# Overview of UTL_TCP

`UTL_TCP` is a system package that enables communication with external servers using the TCP/IP protocol.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Overview of UTL_TCP subprograms

The following table lists the `UTL_TCP` subprograms supported in the current version of OceanBase Database and their brief descriptions.

|                       **Subprogram**             |                **Description**                       |
|----------------------------------------------|-----------------------------------------------|
|[OPEN_CONNECTION](200.open-connection-oracle.md)|Opens a TCP/IP connection to the specified service.|
|[CLOSE_CONNECTION](300.utl-tcp-close-connection-oracle.md)|Closes an open TCP/IP connection.|
|[CLOSE_ALL_CONNECTIONS](400.close-all-connections-oracle.md)|Closes all open TCP/IP connections.|
|[WRITE_LINE](500.write-line-oracle.md)|Transmits a text line to the service over an open connection.|
|[WRITE_TEXT](600.write-text-oracle.md)|Transmits a text message to the service over an open connection.|
|[WRITE_RAW](700.write-raw-oracle.md)|Transmits binary data to the service over an open connection.|
|[GET_LINE](800.get-line-of-oracle.md)|Returns the read text line data until the end of the line or input is reached.|
|[GET_TEXT](900.get-text-oracle.md)|Returns the read text data.|
