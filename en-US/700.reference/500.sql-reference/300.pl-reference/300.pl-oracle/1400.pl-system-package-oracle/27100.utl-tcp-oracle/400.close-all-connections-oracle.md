# CLOSE_ALL_CONNECTIONS

The `CLOSE_ALL_CONNECTIONS` procedure closes all the TCP/IP connections opened in the session.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_TCP.CLOSE_ALL_CONNECTIONS;
```
