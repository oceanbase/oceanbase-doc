# Overview of UTL_SMTP

`UTL_SMTP` is a system package used to send emails through the Simple Mail Transfer Protocol (SMTP).

`UTL_SMTP` relies on the `UTL_TCP` system package, so ensure that the `UTL_TCP` package is enabled.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Overview of UTL_SMTP subprograms

The following table lists the `UTL_SMTP` subprograms supported in the current version of OceanBase Database and their brief descriptions.

|                       **Subprogram**             |                **Description**                       |
|----------------------------------------------|-----------------------------------------------|
|[OPEN_CONNECTION](200.utl-smtp-open-connection-oracle.md)|Opens and returns a connection to the SMTP service.|
|[CLOSE_CONNECTION](300.close-connection-oracle.md)|Closes the SMTP connection, terminating the SMTP operation, and is used to cancel email sending during a data session.|
|[QUIT](400.quit-oracle.md)|Sends the `QUIT` command to the server, terminating the SMTP session and disconnecting from the server.|
|[AUTH](500.auth-oracle.md)|Sends an authentication command to the SMTP server.|
|[COMMAND](600.command-oracle.md)|Executes a general SMTP command.|
|[COMMAND_REPLIES](700.command-perlies-oracle.md)|Executes a general SMTP command and receives multiple reply lines.|
|[HELO](800.helo-oracle.md)|Executes the `HELO` command to initiate the initial handshake with the SMTP service.|
|[EHLO](900.ehlo-oracle.md)|Executes the `EHLO` command to initiate the initial handshake with the SMTP service.|
|[MAIL](1000.mail-oracle.md)|Executes the `MAIL` command to start an email transaction with the SMTP service and declare the sender's email address.|
|[RCPT](1100.rcpt-oracle.md)|Executes the `RCPT` command to specify the email recipient.|
|[OPEN_DATA](1200.open-data-oracle.md)|Sends the `DATA` command to the server to indicate the start of sending email content, with subsequent content written using `write_data` and `write_raw_data`.|
|[WRITE_DATA](1300.write-data-oracle.md)|Sends text email content and can be called multiple times to append data to the email.|
|[WRITE_RAW_DATA](1400.write-raw-data-oracle.md)|Sends raw data email content and can be called multiple times to append data to the email.|
|[CLOSE_DATA](1500.close-data-oracle.md)|Sends a `<CR><LF>.<CR><LF>` to indicate the completion of email text sending.|
|[DATA](1600.data-oracle.md)|Specifies the email body.|
|[VRFY](1700.vrfy-oracle.md)|Sends the `VRFY` command to verify the validity of the target email address.|
|[HELP](1800.help-oracle.md)|Sends the `HELP` command to retrieve help information.|
|[NOOP](1900.noop-oracle.md)|Sends the `NOOP` command to verify the validity of the target email address.|
|[RSET](2000.rset-oracle.md)|Sends the `RSET` command to terminate the current email transaction.|

## Examples

```sql
DECLARE
  -- Define email server information
  l_mailhost VARCHAR2(100) := 'smtp.example.com';  -- SMTP server address
  l_mail_conn UTL_SMTP.connection;                 -- Connection object

  -- Email content
  l_from VARCHAR2(100) := 'sender@example.com';    -- Sender's email address
  l_to VARCHAR2(100) := 'receiver@example.com';    -- Recipient's email address
  l_subject VARCHAR2(100) := 'Test Email';            -- Email subject
  l_message VARCHAR2(4000) := 'This is a test email from OceanBase Database.';  -- Email body
BEGIN
  -- Start connecting to the SMTP server
  l_mail_conn := UTL_SMTP.open_connection(l_mailhost, 25);  -- 25 is the standard port for SMTP service

  -- Send the HELO command to the server
  UTL_SMTP.helo(l_mail_conn, l_mailhost);

  -- Set the sender's email address
  UTL_SMTP.mail(l_mail_conn, l_from);

  -- Set the recipient's email address
  UTL_SMTP.rcpt(l_mail_conn, l_to);

  -- Start data transmission
  UTL_SMTP.open_data(l_mail_conn);

  -- Add email header information
  UTL_SMTP.write_data(l_mail_conn, 'From: ' || l_from || UTL_TCP.crlf);
  UTL_SMTP.write_data(l_mail_conn, 'To: ' || l_to || UTL_TCP.crlf);
  UTL_SMTP.write_data(l_mail_conn, 'Subject: ' || l_subject || UTL_TCP.crlf);
  UTL_SMTP.write_data(l_mail_conn, UTL_TCP.crlf);  -- Empty line to separate headers and body

  -- Write the email body
  UTL_SMTP.write_data(l_mail_conn, l_message || UTL_TCP.crlf);

  -- End data transmission
  UTL_SMTP.close_data(l_mail_conn);

  -- Close the connection
  UTL_SMTP.quit(l_mail_conn);

  DBMS_OUTPUT.PUT_LINE('Email sent successfully!');
EXCEPTION
  WHEN OTHERS THEN
    -- If an error occurs, attempt to close the connection (if it is open)
    IF UTL_SMTP.is_open(l_mail_conn) THEN
      UTL_SMTP.quit(l_mail_conn);
    END IF;

    -- Display the exception information
    RAISE;
END;
/
```
