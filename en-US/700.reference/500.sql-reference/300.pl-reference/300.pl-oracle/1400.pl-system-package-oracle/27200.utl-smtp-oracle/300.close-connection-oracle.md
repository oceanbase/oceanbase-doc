# CLOSE_CONNECTION

The `CLOSE_CONNECTION` procedure is used to close an SMTP connection, thereby terminating SMTP operations, and is only used to cancel email operations within a data session.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Syntax

```sql
UTL_SMTP.CLOSE_CONNECTION (
   c     IN OUT NOCOPY connection);
```

## Parameters

| **Parameter** |         **Description**         |
|--------|------------------------|
|c|The SMTP connection. |
