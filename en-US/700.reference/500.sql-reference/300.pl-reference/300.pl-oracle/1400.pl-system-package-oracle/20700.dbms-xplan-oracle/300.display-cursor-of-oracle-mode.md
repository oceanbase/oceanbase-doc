# DISPLAY_CURSOR

The `DISPLAY_CURSOR` function is used to show details of the execution plan of a query.

## Syntax

```sql
DBMS_XPLAN.DISPLAY_CURSOR(plan_id      INTEGER          DEFAULT    0,         -- default value: last plan
                          format       VARCHAR2         DEFAULT    'TYPICAL',
                          svr_ip       VARCHAR2         DEFAULT    null,   -- default value: server connected by client
                          svr_port     INTEGER          DEFAULT    0,     -- default value: server connected by client
                          tenant_id    INTEGER          DEFAULT    0,     -- default value: current tenant
                          sql_handle   VARCHAR2         DEFAULT    NULL,
                          plan_name    VARCHAR2         DEFAULT    NULL
                        )
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## Parameters

| Parameter | Description |
| ---- | ---- |
| plan_id     | The ID of the execution plan. If this parameter is not specified, the execution plan of the last query is used. |
| format      | The plan format. Valid values: <ul><li>`'BASIC'`: displays minimal information, such as the operator ID, operator name, operator remarks, and expression information.</li><li>`'TYPICAL'`: displays basic information, such as the operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression information. If the plan has been executed, it also displays the actual feedback information of the first execution, such as the actual number of rows and cost.</li><li>`'ALL'`: displays comprehensive plan information, such as the operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression information, as well as the effective hints, query block name trace information, outline information, base table optimization information, constant parameterization information, constraint information, and plan note.</li><li>`'ADVANCED'`: displays comprehensive plan information, which is the same as the information displayed when the 'ALL' parameter is used. In addition, it also displays the tree structure information for complex plans.</li></ul> |
| svr_ip      | The IP address of the node where the plan is stored. The default value is the IP address of the node to which the session is connected. |
| svr_port    | The port number of the node where the plan is stored. The default value is the port number of the node to which the session is connected. |
| tenant_id   | The tenant ID to which the plan belongs. The default value is the tenant ID to which the session is connected. |
| sql_handle  | The handle used to identify the SQL statement. When querying a specific execution plan for a particular SQL statement, you can use the sql_handle parameter to accurately specify the target statement when multiple similar SQL statements exist. |
| plan_name   | The name of the execution plan. |

## Examples

The `DISPLAY_CURSOR` function is used in an Oracle tenant.

1. Create a table.

    ```shell
    obclient [test]> CREATE TABLE t1(c1 INT);
    ```

2. Execute a query.

    ```shell
    obclient [SYS]> SELECT * FROM t1;
    ```

3. Use the `DBMS_XPLAN` package to view historical plans.
