## Query keywords

You can also query the `V$OB_KEYWORDS` view to obtain the complete list of keywords for the current tenant, including reserved and non-reserved keywords. For more information about this view, see [V$OB_KEYWORDS](../700.system-views/500.system-view-of-oracle-mode/300.performance-view-of-oracle-mode/32110.v-ob-keywords-of-oracle-mode.md).

* Reserved keywords for all SQL queries:

  ```sql
  obclient> SELECT KEYWORD FROM sys.V$OB_KEYWORDS WHERE TYPE = 'SQL' AND RESERVED = 1 ORDER BY KEYWORD;
  ```

* Reserved keywords for all PL queries:

  ```sql
  obclient> SELECT KEYWORD FROM sys.V$OB_KEYWORDS WHERE TYPE = 'PL' AND RESERVED = 1 ORDER BY KEYWORD;
  ```

* Check whether a specified identifier is a reserved keyword:

  ```sql
  obclient> SELECT KEYWORD, TYPE, RESERVED FROM sys.V$OB_KEYWORDS WHERE KEYWORD = 'SELECT';
  ```
