# Number format models

Number format models specify the format of fixed-point and floating-point numbers stored in the database. When you need to convert the NUMBER, BINARY_FLOAT, or BINARY_DOUBLE values in an SQL statement to the VARCHAR2 data type, you can use the number format model in the function.

## Number format models in functions

You can use number format models in the following functions:

* When `NUMBER`, `BINARY_FLOAT`, or `BINARY_DOUBLE` appears in an expression, condition, SQL function, or SQL statement, you can use the parameters of the `TO_CHAR` function to specify the format of the values. The `NLS_NUMERIC_CHARACTERS` parameter is not supported.

* When `CHAR` or `VARCHAR2` appears in an expression, condition, SQL function, or SQL statement, you can use the parameters of the `TO_NUMBER` function to specify the format of the values. The `NLS_NUMERIC_CHARACTERS` parameter is not supported.

* When `CHAR` or `VARCHAR2` appears in an expression, condition, SQL function, or SQL statement, you can use the parameters of the `TO_BINARY_FLOAT` and `TO_BINARY_DOUBLE` functions to specify the format of the values.

Number format models round numbers and retain only the significant digits. If the number of decimal places in a value exceeds the number of decimal places specified in the format, the value is replaced with a `#`.

If the positive value of a `NUMBER` is too large to be represented in the specified format, the value is replaced with the infinity symbol (~). If the negative value of a `NUMBER` is too small to be represented in the specified format, the value is replaced with the negative infinity symbol (-~).

## Elements of the numeric format model

### Number format elements

A number format model consists of one or more number format elements. Negative return values automatically include a leading minus sign, and positive return values automatically include a leading space, unless the format model contains elements such as MI, S, or PR that indicate the sign of the number.

### Example of formatting element conversion

The following table shows examples of converting different numbers using the `fmt` parameter of the formatting element. The results are obtained by executing the SQL command `SELECT TO_CHAR(number, 'fmt') FROM DUAL;`. If the format model parameter `fmt` is omitted, the number is converted to a `VARCHAR2` of sufficient length to retain all its significant digits.

|    Number    |  'fmt'  |     Result     |
|----------|---------|------------|
| 0        | 99.99   | '.00'      |
| +0.1     | 99.99   | '.10'      |
| -0.2     | 99.99   | '-.20'     |
| 0        | 90.99   | '0.00'     |
| +0.1     | 90.99   | '0.10'     |
| -0.2     | 90.99   | '-0.20'    |
| 0        | 9999    | '0'        |
| 1        | 9999    | '1'        |
| +123.456 | 999.999 | '123.456'  |
| -123.456 | 999.999 | '-123.456' |

## Examples

* Convert the number 0 to a value with a decimal point and two significant digits after the decimal point.

  ```sql
  obclient> SELECT TO_CHAR(0, '99.99') FROM DUAL;
  +--------------------+
  | TO_CHAR(0,'99.99') |
  +--------------------+
  |    .00             |
  +--------------------+
  1 row in set
  ```

* Omit the `fmt` parameter to retain all significant digits of the value.

  ```sql
  obclient> SELECT TO_CHAR(123.456) FROM DUAL;
  +------------------+
  | TO_CHAR(123.456) |
  +------------------+
  | 123.456          |
  +------------------+
  1 row in set
  ```

* When the result of `TO_CHAR` exceeds 40 bytes, or when the input parameter is of type `BINARY_DOUBLE` or `BINARY_FLOAT`, the result is converted to scientific notation.

  ```sql
  obclient> SELECT TO_CHAR(12355555555555555555555555555555555555555555555555) FROM DUAL;
  +-------------------------------------------------------------+
  | TO_CHAR(12355555555555555555555555555555555555555555555555) |
  +-------------------------------------------------------------+
  | 1.2355555555555555555555555555555556E+49                    |
  +-------------------------------------------------------------+
  1 row in set
  ```
