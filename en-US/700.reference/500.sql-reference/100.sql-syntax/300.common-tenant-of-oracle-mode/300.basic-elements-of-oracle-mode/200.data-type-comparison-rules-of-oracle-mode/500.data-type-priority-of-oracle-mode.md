# Data type priority

OceanBase Database uses data type priority to determine the order of implicit data type conversion. This topic describes the priority of data type conversion.

The data type conversion priority in OceanBase Database is as follows (from highest to lowest):

1. Date and time types and interval types

2. `BINARY_DOUBLE` data type

3. `BINARY_FLOAT` data type

4. `NUMBER` data type

5. Character data types

6. All other built-in data types
