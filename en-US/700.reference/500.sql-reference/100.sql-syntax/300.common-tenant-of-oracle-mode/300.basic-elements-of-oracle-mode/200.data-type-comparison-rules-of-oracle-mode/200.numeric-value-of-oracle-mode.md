# Comparison rules of numeric values

Numeric values include fixed-point numbers, floating-point numbers, and zero. This section describes the comparison rules of numeric values.

The numeric value comparison rules in OceanBase Database are as follows:

* A larger value is greater than a smaller value. For example, `5.5 > 2.1`.

* Negative numbers are less than zero. For example, `-3 < 0` and `-200 < -1`.

* Positive numbers are greater than zero. For example, `20 > 0` and `100 > 1`.

For more information about the numeric value comparison rules, see [Priority of numeric types](../100.built-in-data-types-of-oracle-mode/300.numeric-data-type-of-oracle-mode/500.numeric-priority-of-oracle-mode.md).
