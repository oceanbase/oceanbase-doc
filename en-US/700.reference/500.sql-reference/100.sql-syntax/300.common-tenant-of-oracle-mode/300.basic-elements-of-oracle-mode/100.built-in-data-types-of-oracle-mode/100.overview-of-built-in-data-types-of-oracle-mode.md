# Overview of built-in data types

OceanBase Database provides a variety of built-in data types, also known as basic data types of OceanBase Database. This chapter introduces the syntax, parameters, and usage of data types supported by the current version of OceanBase Database.

Each value in OceanBase Database has a data type. The data type of a value associates a set of fixed attributes with the value, which allows OceanBase Database to treat values of different data types differently.

The current version of OceanBase Database supports the following built-in data types:

* [Character data types](200.character-data-type-of-oracle-mode/100.overview-of-character-data-types-of-oracle-mode.md)

* [Numeric data types](300.numeric-data-type-of-oracle-mode/100.overview-of-numeric-data-types-of-oracle-mode.md)

* [Date and time, and interval data types](400.date-time-and-interval-data-types-of-oracle-mode/100.overview-of-date-time-and-interval-data-types-of-oracle-mode.md)

* [Large object data types](600.large-object-data-type-of-oracle-mode/100.data-types-of-large-objects-of-oracle-mode.md)

* [Rowid data type](../100.built-in-data-types-of-oracle-mode/700.rowid-datatype-of-oracle-mode.md)

* [JSON data type](1000.json-formatted-data-type-oracle-mode/100.json-data-type-overview-of-oracle-mode.md)
