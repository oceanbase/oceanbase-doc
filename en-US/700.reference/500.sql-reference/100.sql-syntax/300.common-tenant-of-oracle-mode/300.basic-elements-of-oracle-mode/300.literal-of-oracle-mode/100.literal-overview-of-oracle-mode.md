# Literals

A literal is a fixed value, which is equivalent to a constant. Many functions and SQL statements require specifying literals, which can also be part of expressions and conditions.

OceanBase Database supports the following literals:

* [Text literals](../300.literal-of-oracle-mode/200.literal-value-of-text-of-oracle-mode.md)
