# VARIANCE

## Purpose

This function returns the variance of a specified column. It can be used as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, the <code>OVER</code> clause is required to define the window for computation. It computes the variance over a set of rows and returns multiple values.</li>
    <li>When used as an aggregate function, the function computes the variance over a set of rows and returns a single value. In this case, the <code>OVER</code> clause is not required.</li>
    </ul>
  </main>

## Syntax

```sql
VARIANCE([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## Parameters

|            Parameter             |                                                                                                                                                Description                                                                                                                                                |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | Specifies whether to eliminate duplicates. This is an optional parameter with a default value of `ALL`. <ul><li> `ALL`: Does not eliminate duplicate values and ignores `NULL` values.   </li><li> `DISTINCT`: Eliminates duplicate values and ignores `NULL` values.   </li><li> `UNIQUE`: Eliminates duplicate values and ignores `NULL` values.</li></ul>     |
| expr                      | An expression of a numeric data type or any data type that can be implicitly converted to a numeric data type.                                                                                                                                                                                                                                                                      |
| OVER                      | Defines the window for computation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                                                                                          |

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>If you specify the <code>DISTINCT</code> or <code>UNIQUE</code> keyword, the <code>order_by_clause</code> and <code>windowing_clause</code> cannot be specified in the <code>analytic_clause</code>.</p>
  </main>

## Return type

The return type is the same as the data type of the `expr` parameter.

## Examples

Assume that the `employees` table has been created.

```sql
obclient> SELECT * FROM employees;
+---------------+-----------+------------+--------+
| DEPARTMENT_ID | LAST_NAME | HIREDATE   | SALARY |
+---------------+-----------+------------+--------+
|            30 | Raphaely  | 2017-07-01 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |
|            40 | Errazuriz | 2017-07-21 |   1400 |
|            50 | Hartstein | 2019-10-05 |  14000 |
|            50 | Raphaely  | 2017-07-22 |   1700 |
|            50 | Weiss     | 2019-10-05 |  13500 |
|            90 | Russell   | 2019-07-11 |  13000 |
|            90 | Partners  | 2018-12-01 |  14000 |
+---------------+-----------+------------+--------+
8 rows in set
```

### Aggregate function example

Compute the variance of all values in the `salary` column.

```sql
obclient> SELECT SUM(salary) FROM employees;
+-------------+
| SUM(SALARY) |
+-------------+
|       70300 |
+-------------+
1 row in set
```

### Analytic function example

Compute the cumulative variance of the `salary` column sorted in ascending order by the `hiredate` column.

```sql
obclient> SELECT last_name,hiredate,salary,VARIANCE(salary) OVER (ORDER BY hiredate) "Variance"
```
