# PERCENTILE_DISC

## Purpose

This function returns the minimum cumulative distribution value that is greater than or equal to the specified percentile value, based on the specified sorting criteria. Null values are ignored in the calculation.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for the calculation. It computes the value for a set of rows and returns multiple values. </li>
    <li>When used as an aggregate function, it computes the value for a set of rows and returns only one value. In this case, you do not need to use the <code>OVER</code> clause. </li>
    </ul>
  </main>

## Syntax

```sql
PERCENTILE_DISC(expr1) WITHIN GROUP (ORDER BY expr2 [ DESC | ASC ])
[ OVER (query_partition_clause) ]
```

## Parameters

|     Parameter      |                                                                             Description                                                                              |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr1       | The value of the percentile, which is a constant of a numeric data type. The value must be in the range of \[0,1\].                                                                                                                         |
| expr2       | The expression to be used for sorting and calculating the percentile. The data type of this expression must be a numeric or datetime type.                                                                                                                         |
| DESC \| ASC | The sorting order. This parameter is optional. <ul><li> `ASC` specifies ascending order, which is the default.    </li><li> `DESC` specifies descending order. </li></ul>    |
| OVER        | Use the `OVER` clause to define the window for the calculation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                     |

## Return type

The same data type as the `expr2` parameter.

### Aggregate function example

Calculate the median of the `col4` column.

```sql
obclient> SELECT PERCENTILE_DISC(0.5) WITHIN GROUP (ORDER BY col4) "PERCENTILE_DISC" FROM tbl1;
+-----------------+
| PERCENTILE_DISC |
+-----------------+
|              15 |
+-----------------+
1 row in set
```
