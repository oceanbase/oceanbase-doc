# PERCENT_RANK

## Purpose

This function calculates the cumulative distribution of a value within a set of values. It is similar to the `CUME_DIST` function. You can use this function as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>As an aggregate function, <code>PERCENT_RANK</code> calculates the percentage position of a value within a set. The return value ranges from (0, 1]. For <code>N</code> rows of data, if the value of <code>expr</code> is greater than the value of the second row and less than the value of the third row, the percentage position is equal to <code>2/N</code>. The number of constant parameter expressions must be the same as the number of expressions in the <code>ORDER BY</code> clause of the aggregate function, and their types must be compatible. If a specified value is repeated in a grouping sequence, the two identical values are treated as one value.</li>
    <li>As an analytic function, <code>PERCENT_RANK</code> calculates the percentage rank of each row after sorting by one or more columns. The return value ranges from [0, 1]. When there are duplicate sorted values, they will have the same rank, and the number of rows with the same value will be recorded in the next rank. The <code>PERCENT_RANK</code> function for the first row in any set is <code>0</code>. The formula for calculating the percentage position is: percentage position = rank / maximum rank. For example, see the table below:</li>
    </ul>
  </main>

| N | Rank | Percentage Position |
|---|----|-------|
| A | 0  | 0     |
| B | 1  | 0.25  |
| C | 2  | 0.5   |
| D | 3  | 0.75  |
| E | 4  | 1     |

## Syntax

```sql
/*Aggregate syntax*/
PERCENT_RANK(expr [, expr ...]) WITHIN GROUP
               ( ORDER BY expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
                          [,expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
               )

/*Analytic syntax*/
PERCENT_RANK( ) OVER ([query_partition_clause] order_by_clause)
```

## Parameters

|           Parameter            |                                                                                                            Description                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | The value to query.                                                                                                                                                                                                                 |
| expr_col                | The name of the column corresponding to the value to query.                                                                                                                                                                                                            |
| DESC \| ASC             | The sorting order. This is an optional parameter. <ul><li> `ASC` specifies ascending order, which is the default value.   </li><li> `DESC` specifies descending order. </li></ul>                                                                |
| NULLS { FIRST \| LAST } | The position of `NULL` values in the result set after sorting. This is an optional parameter. <ul><li> `NULLS FIRST` specifies that `NULL` values are placed before non-`NULL` values.   </li><li> `NULLS LAST` specifies that `NULL` values are placed after non-`NULL` values, which is the default value.</li></ul>    |
| OVER                    | The window clause for defining the window for calculation. For more information, see [Analytic Functions](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                  |

## Return type

The function returns a value of the `NUMBER` data type.

### Aggregate function example

Return the percentage position of the value `3300` in the `sal` column.

```sql
obclient> SELECT PERCENT_RANK(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+-------------------------------------------+
| PERCENT_RANK(3300)WITHINGROUP(ORDERBYSAL) |
+-------------------------------------------+
|                                        .8 |
+-------------------------------------------+
1 row in set
```
