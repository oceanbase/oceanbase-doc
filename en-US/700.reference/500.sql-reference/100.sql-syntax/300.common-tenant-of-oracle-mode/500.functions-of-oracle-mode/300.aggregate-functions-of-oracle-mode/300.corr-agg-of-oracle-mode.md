# CORR

## Purpose

This function calculates the correlation coefficient for a set of numeric pairs. The correlation coefficient represents the strength of the association between numeric pairs, ranging from \[-1,1\]. A value of `0` indicates no correlation, a value less than `0` indicates a negative correlation, and a value greater than `0` indicates a positive correlation. You can use this function as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for computation. It computes the correlation coefficient for a set of rows and returns multiple values.</li>
    <li>When used as an aggregate function, it computes the correlation coefficient for a set of rows and returns a single value. In this case, you do not need to use the <code>OVER</code> clause.</li>
    </ul>
  </main>

## Syntax

```sql
CORR(expr1, expr2) [ OVER (analytic_clause) ]
```

## Parameters

|  Parameter   |                                           Description                                            |
|-------|-----------------------------------------------------------------------------------------|
| expr1 | Specifies the first parameter, which is a numeric data type or can be implicitly converted to a numeric data type.                                                       |
| expr2 | Specifies the second parameter, which is a numeric data type or can be implicitly converted to a numeric data type.                                                       |
| OVER  | Specifies the window for computation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md). |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>The database determines the parameter with the highest numeric precedence, implicitly converts the other parameters to this data type, and returns the result in this data type.</li>
    <li>The positions of the parameters <code>expr1</code> and <code>expr2</code> do not affect the result.</li>
    <li>The formula for calculating the result is: <code>COVAR_POP(expr1, expr2) / (STDDEV_POP(expr1) * STDDEV_POP(expr2))</code>.</li>
    </ul>
  </main>

## Return type

If any parameter is `NULL` or only one row of data exists, it returns `NULL`. Otherwise, it returns a value of the `NUMBER` type.

### Aggregate function example

Calculate the correlation coefficient between the data in column `col3` and the data in column `col4`.

```sql
obclient> SELECT CORR(col3,col4) FROM tbl1;
+--------------------------------------------+
| CORR(COL3,COL4)                            |
+--------------------------------------------+
| -.2705008904002296868793073195758520224002 |

```
