# CUME_DIST

## Purpose

This function calculates the cumulative distribution of a value within a set of values and returns a value in the range (0,1\]. You can use this function as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>As an analytic function, this function calculates the relative position of a specified value within a set of values. For a row <code>row</code>, assuming the values are sorted in ascending order, the <code>cume_dist</code> of <code>row</code> is the number of rows with values less than or equal to the value in <code>row</code>, divided by the total number of rows (the entire query result set or partition) being calculated.</li>
    <li>As an aggregate function, the parameters identify a single assumed row within each aggregate group. Therefore, they must all be constant expressions within each aggregate group. Constant parameter expressions and expressions in the <code>ORDER BY</code> clause of the aggregate function match by position. Therefore, the number of parameters must be the same, and their types must be compatible. If a specified value is repeated in the grouping sequence, the two repeated values are treated as one value.</li>
    </ul>
  </main>

## Syntax

```sql
/*Aggregate syntax*/
CUME_DIST( expr[,expr]...)
  WITHIN GROUP (ORDER BY expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
                       [,expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
          )

/*Analytic syntax*/
CUME_DIST() OVER ([ query_partition_clause ] order_by_clause)
```

## Parameters

|           Parameter            |                                                                                                            Description                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | Specifies the value to query.                                                                                                                                                                                                                 |
| expr_col                | Specifies the column name corresponding to the queried value.                                                                                                                                                                                                            |
| DESC \| ASC             | Specifies the sort order. Optional. *`ASC` specifies ascending order, which is the default. * `DESC` specifies descending order.                                                                 |
| NULLS { FIRST \| LAST } | Specifies the position of `NULL` values in `expr_col` after sorting. Optional. *`NULLS FIRST` specifies that `NULL` values are placed before non-null values. * `NULLS LAST` specifies that `NULL` values are placed after non-null values, which is the default.    |
| OVER                    | Use the `OVER` clause to define the window for calculation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                  |

## Return type

The return type is `NUMBER`.

### Aggregate function example

Return the position of `3300` in the `sal` column.

```sql
obclient> SELECT CUME_DIST(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+----------------------------------------+
| CUME_DIST(3300)WITHINGROUP(ORDERBYSAL) |
+----------------------------------------+
|                                  .9375 |
+----------------------------------------+
1 row in set
```
