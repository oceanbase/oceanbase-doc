# VAR_POP

## Purpose

This function returns the population variance of a set of numeric values, ignoring `NULL` values. It can be used as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for computation. It computes the variance over a set of rows and returns multiple values.</li>
    <li>When used as an aggregate function, it computes the variance over a set of rows and returns a single value. In this case, the <code>OVER</code> clause is not required.</li>
    </ul>
  </main>

## Syntax

```sql
VAR_POP(expr) [ OVER (analytic_clause) ]
```

## Parameters

|  Parameter  |                                           Description                                            |
|------|-----------------------------------------------------------------------------------------|
| expr | Specifies the numeric expression to be computed. It can be a numeric data type or a value that can be implicitly converted to a numeric data type.                                                  |
| OVER | Defines the window for computation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md). |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If the function is applied to an empty set, it returns <code>NULL</code>. The calculation formula is: <code>SUM((expr - (SUM(expr) / COUNT(expr)))²)/ COUNT(expr)</code>. </p>
  </main>

## Return type

The same data type as the parameter `expr` or `NULL`.

|    2 | B3   |    8 |   13 |
|    2 | B4   |   11 |   16 |
|    3 | C1   |    8 |   18 |

### Aggregate function example

Calculate the population variance of the `col4` column.

```sql
obclient> SELECT VAR_POP(col4) FROM tbl1;
+------------------------------------------+
| VAR_POP(COL4)                            |
+------------------------------------------+
| 5.53846153846153846153846153846153846154 |
+------------------------------------------+
1 row in set
```
