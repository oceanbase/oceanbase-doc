# COVAR_SAMP

## Purpose

This function calculates the sample covariance of a set of numerical pairs. You can use this function as an aggregate function or an analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for calculation. It calculates the covariance for a set of rows and returns multiple values.</li>
    <li>When used as an aggregate function, it aggregates the covariance for a set of rows and returns a single value. In this case, the <code>OVER</code> clause is not required.</li>
    </ul>
  </main>

## Syntax

```sql
COVAR_SAMP(expr1, expr2) [ OVER (analytic_clause) ]
```

## Parameters

|  Parameter   |                                           Description                                            |
|-------|-----------------------------------------------------------------------------------------|
| expr1 | Specifies the first numerical expression, which can be a value of a numeric data type or a value that can be implicitly converted to a numeric data type.                                                    |
| expr2 | Specifies the second numerical expression, which can be a value of a numeric data type or a value that can be implicitly converted to a numeric data type.                                                    |
| OVER  | Specifies the <code>OVER</code> clause to define the window for calculation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md). |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>The database determines the parameter with the highest numeric precedence, implicitly converts the other parameters to this data type, and returns the result in this data type.</li>
    <li>The positions of parameters <code>expr1</code> and <code>expr2</code> do not affect the result, i.e., <code>COVAR_POP(expr1, expr2)</code> is equal to <code>COVAR_POP(expr2, expr1)</code>.</li>
    <li>The calculation formula for the result is: <code>(SUM(expr1 * expr2) - SUM(expr1) * SUM(expr2) / n) / (n-1)</code>, where <code>n</code> is the number of pairs of (<code>expr1</code>,<code>expr2</code>), and both <code>expr1</code> and <code>expr2</code> are not empty.</li>
    </ul>
  </main>

## Return type

If any parameter is empty or only one row of data exists, it returns `NULL`. Otherwise, it returns a value of the `NUMBER` type.

### Example of an aggregate function

Calculate the sample covariance of the numerical pairs in columns `col3` and `col4`.

```sql
obclient> SELECT COVAR_SAMP(col3,col4) FROM tbl1;
+--------------------------------------------+
| CORR(COL3,COL4)                            |
+--------------------------------------------+
| -.2705008904002296868793073195758520224002 |
+--------------------------------------------+
1 row in set
```
