# MAX

## Purpose

This function returns the maximum value of the specified column in the parameters. It can be used as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for computation. It computes over a set of rows and returns multiple values.   </li>
    <li>When used as an aggregate function, this function aggregates over a set of rows and returns a single value. In this case, the <code>OVER</code> clause is not required.   </li>
    </ul>
  </main>

## Syntax

```sql
MAX ([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## Parameters

|            Parameter             |                                                                                                                                           Description                                                                                                                                            |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | Specifies whether to eliminate duplicates. This is an optional parameter. The default value is `ALL`. <ul><li> `ALL`: returns all values, including duplicates, and ignores rows with a value of `NULL`.   </li><li> `DISTINCT`: returns rows with duplicates eliminated and ignores rows with a value of `NULL`.   </li><li> `UNIQUE`: returns rows with duplicates eliminated and ignores rows with a value of `NULL`. </li></ul>   |
| expr                      | A column or expression of numeric, character, date, or other data type.                                                                                                                                                                                                                                                               |
| OVER                      | Defines the window for computation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                                                                                 |

## Return type

The same data type as `expr`.

## Examples

An existing table named `employees` has been created.

```sql
obclient> SELECT * FROM employees;
+---------------+------------+-----------+------------+--------+
| DEPARTMENT_ID | MANAGER_ID | LAST_NAME | HIREDATE   | SALARY |
+---------------+------------+-----------+------------+--------+
|            30 |        100 | Raphaely  | 2017-07-01 |   1700 |
|            30 |        100 | De Haan   | 2018-05-01 |  11000 |
|            40 |        100 | Errazuriz | 2017-07-21 |   1400 |
|            50 |        100 | Hartstein | 2019-10-05 |  14000 |
|            50 |        100 | Raphaely  | 2017-07-22 |   1700 |
|            50 |        100 | Weiss     | 2019-10-05 |  13500 |
|            90 |        100 | Russell   | 2019-07-11 |  13000 |
|            90 |        100 | Partners  | 2018-12-01 |  14000 |
```

### Example of aggregate function

Query the maximum value in the `salary` column.

```sql
obclient> SELECT MAX(salary) FROM employees;
+-------------+
| MAX(SALARY) |
+-------------+
|       14000 |
+-------------+
1 row in set
```

### Example of analytic function

Group by `department_id` and query the maximum value in the `salary` column.

```sql
obclient> SELECT department_id,last_name,salary,
                 MAX(salary) OVER (PARTITION BY department_id) AS rmax_sal
          FROM employees;
+---------------+-----------+--------+----------+
| DEPARTMENT_ID | LAST_NAME | SALARY | RMAX_SAL |
+---------------+-----------+--------+----------+
|            30 | Raphaely  |   1700 |    11000 |
```
