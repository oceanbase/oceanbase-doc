# DENSE_RANK

## Purpose

This function calculates the rank of rows within an ordered group of rows. The rank values are consecutive integers starting from `1`, and the maximum rank value is the number of rows that meet the query conditions. Rows with the same value in the specified sorting criteria receive the same rank, and the number of rows with the same value is not counted in the next rank. It can be used as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>As an aggregate function, <code>DENSE_RANK</code> calculates the dense rank of the assumed rows identified by the function's parameters based on the specified sorting criteria. The constant parameter expressions <code>expr</code> and <code>order_by_clause</code> in the aggregate function match by position. Therefore, the number of parameters must be the same, and their types must be compatible.</li>
    <li>As an analytic function, <code>DENSE_RANK</code> calculates the rank of each row returned by the query relative to other rows based on the values of <code>value_exprs</code> in the <code>order_by_clause</code>.</li>
    </ul>
  </main>

## Syntax

```sql
/*Aggregate syntax*/
DENSE_RANK(expr [, expr ...])
  WITHIN GROUP ( ORDER BY expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
                        [,expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
                )

/*Analytic syntax*/
DENSE_RANK( ) OVER([ query_partition_clause ] order_by_clause)
```

## Parameters

|           Parameter            |                                                                                                            Description                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | The value of the data type in the corresponding column.                                                                                                                                                                                                              |
| expr_col                | The name of the column corresponding to the value to be queried.                                                                                                                                                                                                            |
| DESC \| ASC             | The sorting order, which is optional. <ul><li> `ASC` specifies ascending order, which is the default.   </li><li> `DESC` specifies descending order.  </li></ul>                                                                |
| NULLS { FIRST \| LAST } | The position of `NULL` values in `expr_col` after sorting, which is optional. <ul><li> `NULLS FIRST` specifies that `NULL` values are placed before non-NULL values.   </li><li> `NULLS LAST` specifies that `NULL` values are placed after non-NULL values, which is the default. </li></ul>    |
| OVER                    | Use the `OVER` clause to define the window for calculation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                  |

## Return type

The return value is of the `NUMBER` data type.

### Aggregate function example

Return the rank of `3300` in the `sal` column.

```sql
obclient> SELECT DENSE_RANK(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+-----------------------------------------+
| DENSE_RANK(3300)WITHINGROUP(ORDERBYSAL) |
+-----------------------------------------+
|                                      12 |
+-----------------------------------------+
1 row in set
```

### Analytic function example
