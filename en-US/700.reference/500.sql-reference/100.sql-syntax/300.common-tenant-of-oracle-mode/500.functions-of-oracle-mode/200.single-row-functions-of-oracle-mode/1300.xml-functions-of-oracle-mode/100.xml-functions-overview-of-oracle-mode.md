# Overview of XML functions

The following table lists the XML functions supported by OceanBase Database in the current version.

| **Function** | **Description** |
| --- | --- |
| [XMLAGG](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/100.xmlagg-function-of-oracle-mode.md) | Aggregates a set of XML fragments into a single XML document. |
| [XMLATTRIBUTES](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/200.xmlattributes-function-of-oracle-mode.md) | Specifies a set of attributes for an XML element. |
| [XMLELEMENT](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/300.xmlelement-function-of-oracle-mode.md) | Generates an XML element with a specified name, attributes, and content. |
| [XMLPARSE](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/400.xmlparse-function-of-oracle-mode.md)  | Parses a string into an XMLType data type. |
| [EXTRACT](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/100.extract-function-of-oracle-mode.md) | Extracts an XML fragment based on an XPath expression, and returns the concatenated result of all nodes matched by the XPath expression. |
| [EXTRACTVALUE](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/200.extract-value-function-of-oracle-mode.md) | Extracts an XML fragment based on an XPath expression and returns a scalar value. |
| [XMLSERIALIZE](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/300.xmlserialize-function-of-oracle-mode.md) | Serializes an XMLType data type into a `VARCHAR2` or `CLOB` data type. |
| [XMLCAST](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/400.xmlcast-function-of-oracle-mode.md) | Extracts the content of an XML document (excluding element names) and converts it into another data type. |
| [XMLTABLE](300.querying-xmltype-data-functions-of-oracle-mode/500.xmltable-function-of-oracle-mode.md) | Maps the results returned by an XPath expression to rows and columns of a relational table. |
| [XMLSEQUENCE](300.querying-xmltype-data-functions-of-oracle-mode/600.xmlsequence-function-of-oracle-mode.md) | Converts the content of an XML document into a VARRAY of XML elements. |
| [UPDATEXML](../1300.xml-functions-of-oracle-mode/400.modify-xmltype-data-functions-of-oracle-mode/100.updatexml-function-of-oracle-mode.md) | Modifies an XMLType data type. |
| [INSERTCHILDXML](400.modify-xmltype-data-functions-of-oracle-mode/200.insertchildxml-function-of-oracle-mode.md) | Inserts a specified XML fragment into a target XML document. |
| [DELETEXML](400.modify-xmltype-data-functions-of-oracle-mode/300.deletexml-function-of-oracle-mode.md) | Deletes one or more nodes matched by an XPath expression in an XML document. |

The following table lists the XML functions not supported by OceanBase Database in the current version.

| **Function**   | **Description**                                       |
|------------|--------------------------------------------|
| `XMLEXIST` | Checks whether a specified XPath path exists in XML data.  |
| `XMLISVALID` | Verifies whether an XML document conforms to its XML schema definition.   |
| `XMLQUERY` | Executes an XQuery expression to query XML data.           |
