# NLSSORT

## Purpose

This function returns the sort key value (Sortkey) of a character based on the specified collation, which can be specified explicitly or implicitly.

The `NLSSORT()` function generates a sort key value based on the specified collation. A sort key is a byte string that is used to sort characters based on the specified collation.

The length of the sort key is affected by the `MAX_STRING_SIZE` parameter. If `MAX_STRING_SIZE=EXTENDED`, the maximum length of the return value is 32767 bytes. If the sort key exceeds this limit, the function will fail and return an error message "unable to create the collation key".

## Syntax

```sql
NLSSORT(char [, 'nlsparam' ])
```

## Parameters

|    Parameter    |                                                                                                                                                                                                                                                                                                                                                           Description                                                                                                                                                                                                                                                                                                                                                           |
|----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| char     | This parameter supports literals and expressions (including column names). The data type can be `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2`. If the input data type is `CLOB`, it will be implicitly converted.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| nlsparam | Specifies the collation. The fixed format of `nlsparam` is `NLS_SORT = collation`. `collation` specifies the language collation name. OceanBase Database V4.2 and later versions support the GB18030_2022 character set for Chinese sorting. For the Chinese character set, the following three Chinese collations are supported: <ul><li>`SCHINESE_PINYIN2_M`: Sorts characters by pinyin.   </li><li> `SCHINESE_STROKE2_M`: Sorts characters by stroke count.   </li><li> `SCHINESE_RADICAL2_M`: Sorts characters by radical. </li></ul>     For Unicode, the following three Chinese collations are supported: <ul><li> `UCA0900_SCHINESE_PINYIN`: Sorts characters by pinyin.   </li><li> `UCA0900_SCHINESE_STROKE`: Sorts characters by stroke count  </li><li> `UCA0900_SCHINESE_RADICAL`: First sorts characters by radical, then by stroke count. </li></ul>    If `nlsparam` is omitted, the function uses the default collation of the character set. |
