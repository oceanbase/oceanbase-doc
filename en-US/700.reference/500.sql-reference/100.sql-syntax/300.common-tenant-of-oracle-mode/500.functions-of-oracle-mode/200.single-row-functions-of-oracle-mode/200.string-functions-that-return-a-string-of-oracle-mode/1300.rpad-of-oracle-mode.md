# RPAD

## Purpose

This function fills the right side of the string `char1` with the string `char2` until the total length reaches `n`.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>If the length of <code>char1</code> is greater than <code>n</code>, it returns the leftmost <code>n</code> characters of <code>char1</code>.</li>
    <li>If the length of <code>char1</code> is less than <code>n</code>, and the combined length of <code>char1</code> and <code>char2</code> is greater than <code>n</code>, it returns the leftmost <code>n</code> characters of the combined string.</li>
    <li>If the length of <code>char1</code> is less than <code>n</code>, and the combined length of <code>char1</code> and <code>char2</code> is less than <code>n</code>, it returns the leftmost <code>n</code> characters of the string formed by concatenating <code>char1</code> with multiple copies of <code>char2</code> (total length is greater than or equal to <code>n</code>). </li>
    </ul>
  </main>

## Syntax

```sql
RPAD(char1,n[,char2])
```

## Parameters

|  Parameter   |                                                      Description                                                      |
|-------|--------------------------------------------------------------------------------------------------------------|
| char1 | The string. The string type can be `CHAR`, `VARCHAR2`, `NCHAR`, `NVARCHAR2`, or `CLOB`.                                                |
| n     | The total length after appending. It must be a `NUMBER` type or a value that can be implicitly converted to `NUMBER`. <br>**Note**  For non-integer values, the decimal part is truncated to convert to an integer. |
| char2 | The string to append. The default value is a space. The string type can be `CHAR`, `VARCHAR2`, `NCHAR`, `NVARCHAR2`, or `CLOB`.                                       |

## Return type

* If `char1` is a character data type, it returns a `VARCHAR2` type.

* If `char1` is a national character data type, it returns an `NVARCHAR2` type.

* If `char1` is a `LOB` data type, it returns a `LOB` type.

## Examples

Use the asterisk `*` to right-fill the string `ABCDE` to a length of 10 characters.

```sql
obclient> SELECT  RPAD('ABCDE',10,'*') "RPAD" FROM DUAL;
+------------+
| RPAD       |
+------------+
| ABCDE***** |
+------------+
1 row in set
```
