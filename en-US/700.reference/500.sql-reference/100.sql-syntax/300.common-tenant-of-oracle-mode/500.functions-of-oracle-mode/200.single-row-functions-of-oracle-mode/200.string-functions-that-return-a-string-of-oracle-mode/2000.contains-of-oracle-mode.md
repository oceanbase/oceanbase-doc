# CONTAINS

## Purpose

This function is primarily used for string matching or full-text search within database fields.

## Syntax

```sql
CONTAINS(indexed_column, 'search_query' [, score_label])
```

## Parameters

* `indexed_column`: The name of the column for the full-text index.
* `search_query`: The keyword or phrase to be searched, which can be of the `VARCHAR2` or `CLOB` type.
* `score_label`: Optional. The matching number of the returned result, in `NUMBER` type.

## Examples

Execute the following statement to filter data rows from the `test` table where the content of column `c1` contains the string `city`.

```sql
obclient> SELECT id, c1 FROM test WHERE CONTAINS(c1, 'city') > 0;
```
