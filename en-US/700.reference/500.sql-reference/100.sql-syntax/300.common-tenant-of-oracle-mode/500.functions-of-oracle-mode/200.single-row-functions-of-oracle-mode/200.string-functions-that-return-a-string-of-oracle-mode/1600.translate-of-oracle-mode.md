# TRANSLATE

## Purpose

This function replaces the characters in `char1` that match the characters in `char2` with the corresponding characters in `char3`.

## Syntax

```sql
TRANSLATE(char1,char2,char3)
```

## Parameters

|  Parameter   |           Description            |
|-------|-------------------------|
| char1 | A character expression or variable.             |
| char2 | The set of characters in `char1` that need to be replaced. |
| char3 | The set of characters used to replace `char2`.   |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>The data types of <code>char1</code>, <code>char2</code>, and <code>char3</code> can be <code>CHAR</code>, <code>VARCHAR2</code>, <code>NCHAR</code>, <code>NVARCHAR2</code>, or <code>CLOB</code>.</li>
    <li>If the length of <code>char3</code> is greater than that of <code>char2</code>, the extra characters in <code>char3</code> are invalid.</li>
    <li>If the length of <code>char3</code> is less than that of <code>char2</code>, the extra characters in <code>char2</code> are replaced with empty characters (deleted). </li>
    <li>If the length of <code>char3</code> is <code>0</code>, <code>NULL</code> is returned. </li>
    <li>If <code>char2</code> contains duplicate characters, the replacement is based on the first occurrence of each duplicate character. For example, if <code>char2</code> is <code>aab</code> and <code>char3</code> is <code>123</code>, all <code>a</code> characters in <code>char1</code> are replaced with <code>1</code>, and all <code>b</code> characters in <code>char1</code> are replaced with <code>3</code>. </li>
    </ul>
  </main>

## Return type

The same data type as `char1`.

## Examples

Replace the characters `a` and `e` in the string `OceanBase` with `A` and `E`, respectively.

```sql
obclient> SELECT TRANSLATE('OceanBase','ae','AE') "TRANSLATE" FROM DUAL;
+-----------+
| TRANSLATE |
+-----------+
| OcEAnBAsE |
+-----------+
1 row in set
```
