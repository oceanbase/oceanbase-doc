# SUBSTR

## Purpose

This function is used to extract a substring from a string. Multibyte characters (such as Chinese characters and full-width characters) are counted as one character.

## Syntax

```sql
SUBSTR(char1,n1[,n2])
```

## Parameters

|  Parameter   |                                                                                                                                                                                                   Description                                                                                                                                                                                                    |
|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| char1 | The string to be extracted. The string can be of the `CHAR`, `VARCHAR2`, `NCHAR`, `NVARCHAR2`, or `CLOB` type.                                                                                                                                                                                                                                                                                                                                        |
| n1    | The starting position of the substring to be extracted. The data type is `NUMBER`. <br>**Description**  <ul><li> If `n1` is `0`, it is treated as `1`, meaning the extraction starts from the first character of `char1`.   </li><li> If `n1` is positive, the extraction starts from the `n1`th character of `char1`.   </li><li> If `n1` is negative, the extraction starts from the `n1`th character from the end of `char1`.  </li></ul>    |
| n2    | The length of the substring to be extracted. The data type is `NUMBER`, and this parameter is optional. <br>**Description**  <ul><li> If `n2` is not specified, the extraction starts from the `n1`th character and continues to the end of `char1`.  </li><li> If `n2` is less than `0`, `NULL` is returned. </li></ul>                                                                                                                                                                |

## Return type

The same data type as `char1`.

## Examples

Extract `5` characters starting from the `1`st character and `2.1` characters starting from the `-3`rd character of the string `OceanBase`.

```sql
obclient> SELECT SUBSTR('OceanBase',1,5) "SUBSTR1",SUBSTR('OceanBase',-3,2.1) "SUBSTR2" FROM DUAL;
+---------+---------+
| SUBSTR1 | SUBSTR2 |
+---------+---------+
| Ocean   | as      |
+---------+---------+
1 row in set
```
