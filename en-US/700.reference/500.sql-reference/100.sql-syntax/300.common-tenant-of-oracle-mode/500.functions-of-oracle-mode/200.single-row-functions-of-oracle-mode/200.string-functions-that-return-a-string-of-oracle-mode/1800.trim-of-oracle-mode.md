# TRIM

## Purpose

This function is used to remove characters from the beginning and/or end of a string.

## Syntax

```sql
TRIM([{{ LEADING | TRAILING | BOTH }[ trim_character ]|trim_character }FROM] trim_source)
```

## Parameters

|             Parameter              |                                                                                                                                                                                Description                                                                                                                                                                                 |
|-----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LEADING \| TRAILING \| BOTH | Specifies the location from which to remove characters. <ul><li> `LEADING` specifies the beginning of the string. If you specify `LEADING`, all characters in the `trim_character` parameter that are at the beginning of the string are removed.  </li><li> `TRAILING` specifies the end of the string. If you specify `TRAILING`, all characters in the `trim_character` parameter that are at the end of the string are removed.   </li><li> `BOTH` specifies the beginning and end of the string. If you specify `BOTH` or do not specify any of the three options, all characters in the `trim_character` parameter that are at the beginning and end of the string are removed.</li></ul>    |
| trim_character              | The character to be removed. It can be only a single character. If you do not specify the `trim_character` parameter, the default value is a space.                                                                                                                                                                                                                                                                                                    |
| trim_source                 | The string from which to remove characters. If you specify only the `trim_source` parameter, leading and trailing spaces are removed.                                                                                                                                                                                                                                                                                                      |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Both <code>trim_character</code> and <code>trim_source</code> can be of the <code>VARCHAR2</code> data type or any data type that can be implicitly converted to the <code>VARCHAR2</code> data type. If the function returns a value of the <code>VARCHAR2</code> data type, the maximum length of the value is the same as that of <code>trim_source</code>.</p>
  </main>

## Return type

* If `trim_source` is of the `CHAR` or `VARCHAR2` data type, the function returns a value of the `VARCHAR2` data type.

* If `trim_source` is of the `NCHAR` or `NVARCHAR2` data type, the function returns a value of the `NVARCHAR2` data type.

* If `trim_source` is of the `CLOB` data type, the function returns a value of the `CLOB` data type.

* If `trim_source` or `trim_character` is `NULL`, the `TRIM` function returns `NULL`.

## Examples

Remove the `XX` characters from the beginning and end of the string `XXOceanBaseXX`.

```sql
obclient> SELECT TRIM('X' FROM 'XXOceanBaseXX') "TRIM" FROM DUAL;
+-----------+
| TRIM      |
+-----------+
| OceanBase |
+-----------+
1 row in set
```
