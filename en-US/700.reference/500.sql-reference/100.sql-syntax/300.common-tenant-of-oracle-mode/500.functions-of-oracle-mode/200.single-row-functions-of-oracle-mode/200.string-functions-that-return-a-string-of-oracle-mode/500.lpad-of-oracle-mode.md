# LPAD

## Purpose

The `LPAD` function pads the left side of the string `char1` with the string `char2` until the length reaches `n`.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>If the length of <code>char1</code> is greater than <code>n</code>, the function returns the leftmost <code>n</code> characters of <code>char1</code>.</li>
    <li>If the length of <code>char1</code> is less than <code>n</code>, and the concatenation of <code>char2</code> and <code>char1</code> exceeds <code>n</code>, the function returns the rightmost <code>n</code> characters of the concatenated result.</li>
    </ul>
  </main>

## Syntax

```sql
LPAD(char1,n[,char2])
```

## Parameters

|  Parameter   |                                                      Description                                                      |
|-------|--------------------------------------------------------------------------------------------------------------|
| char1 | The string to be padded. The string type can be `CHAR`, `VARCHAR2`, `NCHAR`, `NVARCHAR2`, or `CLOB`.                                               |
| n     | The total length after padding. It must be a `NUMBER` type or a value that can be implicitly converted to `NUMBER`. <br>**Note**  For non-integer values, the decimal part is truncated to convert to an integer. |
| char2 | The string to be used for padding. The default is a space. The string type can be `CHAR`, `VARCHAR2`, `NCHAR`, `NVARCHAR2`, or `CLOB`.                                      |

## Return type

* If `char1` is a character data type, the function returns a `VARCHAR2` value.

* If `char1` is a national character data type, the function returns an `NVARCHAR2` value.

* If `char1` is a `LOB` data type, the function returns a `LOB` value.

## Examples

Use the star `*` to left-pad the string `ABCDE`.

```sql
obclient> SELECT  LPAD('ABCDE',10,'*') FROM DUAL;
+----------------------+
| LPAD('ABCDE',10,'*') |
+----------------------+
| *****ABCDE           |
+----------------------+
1 row in set
```
