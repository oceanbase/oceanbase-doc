# MAX_PT

## Purpose

This function returns the maximum value of the partition key of a partitioned table that contains data.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function was introduced in V4.6.0 of the V4.6.x series. </p>
</main>

## Limitations and considerations

* The queried table must be a partitioned table with RANGE or LIST partitioning.
* The queried table must be an internal table. External tables and DBLinks are not supported.
* Only single-column partitioning is supported. Multi-column or expression-based partitioning is not supported.
* For a subpartitioned table, only the values of the primary partitions are returned.
* If all partitions are empty, NULL is returned.
* If different partition values exist in the same partition, the result of `MAX_PT` is `undefined`, and the value of a randomly selected row from this partition is returned.

## Syntax

```sql
MAX_PT('[schema_name.]table_name')
```

## Parameters

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>In an Oracle database, when you pass the schema name and table name to the <code>MAX_PT</code> function, uppercase letters must be used. </p>
</main>

* `database_name`: Optional. The name of the schema where the table is located. If this parameter is not specified, the table in the current login schema is queried by default.
* `table_name`: The name of the table.

## Return value

The maximum value of the partition key of a partitioned table that contains data, based on the `max()` comparison logic. The data type is the same as that of the partition key.

## Examples

1. Create a partitioned table named `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY LIST (col1) (
            PARTITION P0 VALUES (1),
            PARTITION P1 VALUES (2),
            PARTITION P2 VALUES (3),
            PARTITION P3 VALUES (4)
        );
    ```

2. Insert test data.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1,1,1),
        (2,2,2),
        (3,3,3),
        (4,4,4),
        (1,1,2),
        (2,2,2);
    ```

    The return result is as follows:

    ```shell
    Query OK, 6 rows affected
    Records: 6  Duplicates: 0  Warnings: 0
    ```

3. Query the maximum value of the partition key of a partitioned table that contains data in the `test_tbl1` table.

    ```shell
    obclient> SELECT MAX_PT('TEST_TBL1') FROM DUAL;
    ```

    The return result is as follows:

    ```shell
    +---------------------+
    | MAX_PT('TEST_TBL1') |
    +---------------------+
    |                   4 |
    +---------------------+
    1 row in set
    ```
