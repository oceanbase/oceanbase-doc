# VSIZE

## Purpose

The function returns the length (in bytes) of the value that `expr` evaluates to.

## Syntax

```sql
VSIZE (expr)
```

## Parameters

The `expr` can be a value or expression of a numeric data type (`NUMBER`, `FLOAT`, `BINARY_FLOAT`, or `BINARY_DOUBLE`) or a character data type (`CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2`).

## Return type

* Returns a `NUMBER` value.

* If `expr` is `NULL`, then the function returns `NULL`.

## Examples

Query the number of bytes in the values `123456`, `ABCDEF`, and `People's Republic of China` by using the `VSIZE` function.

```sql
obclient> SELECT VSIZE(123456),VSIZE('ABCDEF'),VSIZE ('P R C') FROM DUAL;
+---------------+-----------------+--------------------------------+
| VSIZE(123456) | VSIZE('ABCDEF') | VSIZE('The People's Republic of China')        |
+---------------+-----------------+--------------------------------+
|             8 |               6 |                             21 |
+---------------+-----------------+--------------------------------+
1 row in set
```
