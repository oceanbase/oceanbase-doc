# EMPTY_CLOB

## Purpose

`EMPTY_CLOB()` returns an empty `CLOB` locator. The locator is not `NULL`, and the LOB length is 0.

## Syntax

```sql
EMPTY_CLOB()
```

## Return type

The return type is `CLOB`.

## Examples

The following example returns an empty `CLOB` locator and checks whether the locator is `NULL` and the length of the LOB:

```sql
obclient> SELECT CASE WHEN EMPTY_CLOB() IS NULL THEN 'NULL' ELSE 'NOT NULL' END AS clob_is_null,
          DBMS_LOB.GETLENGTH(EMPTY_CLOB()) AS clob_len
          FROM DUAL;
+--------------+----------+
| CLOB_IS_NULL | CLOB_LEN |
+--------------+----------+
| NOT NULL     |        0 |
+--------------+----------+
1 row in set
```
