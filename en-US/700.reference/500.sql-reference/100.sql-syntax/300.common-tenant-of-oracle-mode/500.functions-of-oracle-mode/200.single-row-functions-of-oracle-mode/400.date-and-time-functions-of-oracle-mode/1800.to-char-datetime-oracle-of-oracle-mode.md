# TO_CHAR (datetime)

## Purpose

This function converts the value of a `DATE`, `TIMESTAMP`, `TIMESTAMP WITH TIME ZONE`, `TIMESTAMP WITH LOCAL TIME ZONE`, `INTERVAL DAY TO SECOND`, or `INTERVAL YEAR TO MONTH` datetime or interval data type to a `VARCHAR2` value in the format specified by the `fmt` parameter.

## Syntax

```sql
TO_CHAR({ datetime | interval } [, fmt [, 'nlsparam' ] ])
```

## Parameters

|          Parameter          |                                                                                                                                                                                                  Description                                                                                                                                                                                                   |
|----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| datetime \| interval | The datetime or interval value to be converted. <ul><li> `datetime` specifies the value of a date or timestamp data type. This includes `DATE`, `TIMESTAMP`, `TIMESTAMP WITH TIME ZONE`, `TIMESTAMP WITH LOCAL TIME ZONE`, `INTERVAL DAY TO SECOND`, and `INTERVAL YEAR TO MONTH`.   </li><li> `interval` specifies the value of an interval data type.</li></ul>                                                                                                |
| fmt                  | The output format. This is an optional parameter. If you do not specify the `fmt` parameter, the value of the `datetime` parameter is converted to a `VARCHAR2` value in the following format: <ul><li> The values of `DATE`, `TIMESTAMP`, `TIMESTAMP WITH TIME ZONE`, and `TIMESTAMP WITH LOCAL TIME ZONE` are converted to the default datetime format in the database. You can view the default format for each datetime data type in the **Date and Interval Data Types** section.   </li><li> The values of `INTERVAL DAY TO SECOND` and `INTERVAL YEAR TO MONTH` are converted to numeric interval values. </li></ul>     |
| nlsparam             | The language used for the returned month and date.                                                                                                                                                                                                                                                                                                                                                                                   |

## Return type

`VARCHAR2`

## Examples

* Use the `TO_CHAR` function to return the current system date and convert the datetime value to the `DS DL` format.

  ```sql
  obclient> SELECT TO_CHAR(SYSDATE,'yyyy/mm/dd'),TO_CHAR(SYSDATE,'DS DL') FROM DUAL;
  +-------------------------------+----------------------------------------+
  | TO_CHAR(SYSDATE,'YYYY/MM/DD') | TO_CHAR(SYSDATE,'DSDL')                |
  +-------------------------------+----------------------------------------+
  | 2021/11/18                    | 11/18/2021 Thursday, November 18, 2021 |
  +-------------------------------+----------------------------------------+
  1 row in set
  ```

* Convert the interval value to the specified format and set the return language to `AMERICAN`.

  ```sql
  obclient> SELECT TO_CHAR(interval'1' year, 'SS-MI-HH', 'nls_language = AMERICAN') FROM DUAL;
  +-------------------------------------------------------------+
  | TO_CHAR(INTERVAL'1'YEAR,'SS-MI-HH','NLS_LANGUAGE=AMERICAN') |
  +-------------------------------------------------------------+
  | +01-00                                                      |
  +-------------------------------------------------------------+
  1 row in set
  ```
