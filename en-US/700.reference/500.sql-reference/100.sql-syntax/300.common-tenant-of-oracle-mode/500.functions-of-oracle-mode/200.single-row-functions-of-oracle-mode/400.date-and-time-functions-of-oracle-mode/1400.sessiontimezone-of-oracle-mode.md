# SESSIONTIMEZONE

## Purpose

This function returns the current session time zone.

## Syntax

```sql
SESSIONTIMEZONE
```

## Return type

`VARCHAR2`

## Examples

Return the database time zone and the current session time zone.

```sql
obclient> SELECT DBTIMEZONE,SESSIONTIMEZONE FROM DUAL;
+------------+-----------------+
| DBTIMEZONE | SESSIONTIMEZONE |
+------------+-----------------+
| +00:00     | +08:00          |
+------------+-----------------+
1 row in set
```
