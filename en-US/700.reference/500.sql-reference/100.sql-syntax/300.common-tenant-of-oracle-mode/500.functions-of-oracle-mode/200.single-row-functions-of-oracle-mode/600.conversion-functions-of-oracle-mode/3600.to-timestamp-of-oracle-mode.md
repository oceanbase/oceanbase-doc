# TO_TIMESTAMP

## Purpose

This function converts a string to the `TIMESTAMP` data type.

## Syntax

```sql
TO_TIMESTAMP (char,[fmt],['nlsparam'])
```

## Parameters

|    Parameter    |                                 Description                                 |
|----------|--------------------------------------------------------------------|
| char     | A string of the `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type.               |
| fmt      | The format of `char`, which is optional. If you omit `fmt`, `char` must be in the default format of the `TIMESTAMP` data type. |
| nlsparam | The `nlsparam` parameter specifies the date, time, and number formatting and parsing rules for the TO_TIMESTAMP function. OceanBase Database currently supports only `nls_date_language` for `nlsparam`, which specifies the language for the returned month and day. The default value is AMERICA, which cannot be modified.                                         |

## Return type

`TIMESTAMP`

## Examples

Convert the string `2021-11-11 11:11:11.11` to a timestamp.

```sql
obclient> SELECT TO_TIMESTAMP ('2021-11-11 11:11:11.11', 'YYYY-MM-DD HH24:MI:SS.FF')
    FROM DUAL;
+-----------------------------------------------------------------+
| TO_TIMESTAMP('2021-11-1111:11:11.11','YYYY-MM-DDHH24:MI:SS.FF') |
+-----------------------------------------------------------------+
| 11-NOV-21 11.11.11.110000000 AM                                 |
+-----------------------------------------------------------------+
1 row in set
```
