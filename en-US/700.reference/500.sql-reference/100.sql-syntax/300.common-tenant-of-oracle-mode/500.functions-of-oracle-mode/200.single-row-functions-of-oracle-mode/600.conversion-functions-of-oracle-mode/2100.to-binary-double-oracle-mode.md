# TO_BINARY_DOUBLE

## Purpose

This function returns a double-precision floating-point number.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Conversions from a <code>NUMBER</code> or a character value to a <code>BINARY_DOUBLE</code> may not be accurate because <code>NUMBER</code> and character types use decimal precision to represent numbers, whereas <code>BINARY_DOUBLE</code> uses binary precision. Conversions from a <code>BINARY_FLOAT</code> to a <code>BINARY_DOUBLE</code> are accurate. </p>
  </main>

## Syntax

```sql
TO_BINARY_DOUBLE(expr [, fmt [, 'nlsparam' ] ])
```

## Parameters

|    Parameter    |                                 Description                                 |
|----------|--------------------------------------------------------------------|
| expr     | A number of the <code>NUMBER</code>, <code>BINARY_FLOAT</code>, or <code>BINARY_DOUBLE</code> data type, or a string.              |
| fmt      | An optional output format parameter. If you omit <code>fmt</code>, then <code>n</code> is converted to a <code>VARCHAR2</code> value. For more information, see the description of the <code>fmt</code> parameter. |
| nlsparam | An optional parameter that defines the decimal character, group separator, local currency symbol, and international currency symbol.                                   |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If <code>expr</code> is a string, then the optional <code>fmt</code> and <code>nlsparam</code> parameters are effective. They function the same way as the <code>TO_CHAR (number)</code> function. If <code>expr</code> is a <code>BINARY_DOUBLE</code>, then this function returns <code>expr</code>. </p>
  </main>

## Return type

The function returns a value of the <code>BINARY_DOUBLE</code> data type.

## Examples

Convert the string `123.123` to a double-precision floating-point number.

```sql
obclient> SELECT TO_BINARY_DOUBLE('123.123') FROM DUAL;
+-----------------------------+
| TO_BINARY_DOUBLE('123.123') |
+-----------------------------+
|                1.23123E+002 |
+-----------------------------+
1 row in set
```
