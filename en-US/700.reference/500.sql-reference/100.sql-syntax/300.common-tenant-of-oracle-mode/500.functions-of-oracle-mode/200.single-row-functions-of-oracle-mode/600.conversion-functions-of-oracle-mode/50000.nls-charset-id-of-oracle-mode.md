# NLS_CHARSET_ID

The `NLS_CHARSET_ID` function returns the ID corresponding to the character set name.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available since OceanBase Database V4.4.2 BP1. </p>
</main>

## Syntax

```sql
NLS_CHARSET_ID(string)
```

## Parameter

The `string` parameter is a string of any character set.

* If the value of `string` is `CHAR_CS`, the function returns the ID of the default character set of the current database.
* If the value of `string` is `NCHAR_CS`, the function returns the ID of the national character set of the current database.
* If the value of `string` is invalid, the function returns `NULL`.

## Example

```shell
obclient> SELECT NLS_CHARSET_ID('ja16euc')
  FROM DUAL;
```

The execution result is as follows:

```sql
+---------------------------+
| NLS_CHARSET_ID('JA16EUC') |
+---------------------------+
|                      803  |
+---------------------------+
1 row in set (0.001 sec)
```
