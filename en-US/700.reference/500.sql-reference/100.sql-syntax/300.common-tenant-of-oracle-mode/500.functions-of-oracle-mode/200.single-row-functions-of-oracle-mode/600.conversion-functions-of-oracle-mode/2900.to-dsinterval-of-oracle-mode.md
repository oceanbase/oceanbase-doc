# TO_DSINTERVAL

## Purpose

This function converts a string of the `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type into a value of the `INTERVAL DAY TO SECOND` data type. You can use this function to add or subtract an interval from a datetime value.

## Syntax

```sql
/*SQL date format*/
TO_DSINTERVAL ('[+ | -] days hours:minutes:seconds[.frac_secs]')

/*ISO date format*/
TO_DSINTERVAL ('[-] P[days D]
[T[hours H][minutes M][seconds[.frac_secs]S]]')
```

## Parameters

|                                   Parameter                                    |                                                                                                                                                                                            Description                                                                                                                                                                                            |
|-------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \[+ \| -\]days hours:minutes:seconds\[.frac_secs\]                      | A string of the `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type that conforms to this parameter format. <ul><li> `days` specifies the number of days. It is an integer in the range of \[0,999999999\].   </li><li> `hours` specifies the number of hours. It is an integer in the range of \[0,23\].   </li><li> `minutes` specifies the number of minutes. It is an integer in the range of \[0,59\].   </li><li> `seconds` specifies the number of seconds. It is an integer in the range of \[0,59\]. </li></ul>   |
| \[-\] P\[days D\] \[T\[hours H\]\[minutes M\]\[seconds\[.frac_secs\]S\] | A string of the `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type that conforms to this parameter format. <br>**Notice**  No spaces are allowed in the value.                                                                                                                                                                                                                                                                             |
| frac_secs                                                               | The fractional part of the seconds. This is an optional parameter. It is an integer in the range of \[0,999999999\].                                                                                                                                                                                                                                                                                                                                                  |

## Return type

`INTERVAL DAY TO SECOND`

## Examples

* Use the SQL date format to return the datetime value 100 days after November 11, 2021.

  ```sql
  obclient> SELECT TO_CHAR(TIMESTAMP '2021-11-11 00:00:00'+TO_DSINTERVAL('100 00:00:00'),
       'YYYY-MM-DD HH24:MI:SS') "Time Stamp" FROM DUAL;
  +---------------------+
  | Time Stamp          |
  +---------------------+
  | 2022-02-19 00:00:00 |
  +---------------------+
  1 row in set
  ```

* Use the ISO date format to return the datetime value 100 days and 10 hours after December 12, 2021.

  ```sql
  obclient> SELECT TO_CHAR(TIMESTAMP '2021-11-11 00:00:00'+TO_DSINTERVAL('P100DT5H'),
      'YYYY-MM-DD HH24:MI:SS') "Time Stamp" FROM DUAL;
  +---------------------+
  | Time Stamp          |
  +---------------------+
  | 2022-02-19 05:00:00 |
  +---------------------+
  1 row in set
  ```
