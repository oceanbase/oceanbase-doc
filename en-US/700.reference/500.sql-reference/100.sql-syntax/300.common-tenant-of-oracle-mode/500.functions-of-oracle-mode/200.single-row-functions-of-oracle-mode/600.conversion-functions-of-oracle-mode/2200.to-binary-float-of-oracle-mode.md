# TO_BINARY_FLOAT

## Purpose

This function returns a single-precision floating-point number.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Conversion from a string or <code>NUMBER</code> to <code>BINARY_FLOAT</code> may not be precise because <code>NUMBER</code> and character types use decimal precision to represent numbers, while <code>BINARY_FLOAT</code> uses binary precision. If the precision of a <code>BINARY_DOUBLE</code> value exceeds the precision supported by <code>BINARY_FLOAT</code>, the conversion from <code>BINARY_DOUBLE</code> to <code>BINARY_FLOAT</code> is not precise. </p>
  </main>

## Syntax

```sql
TO_BINARY_FLOAT(expr [, fmt [, 'nlsparam' ] ])
```

## Parameters

|    Parameter    |                                 Description                                 |
|----------|--------------------------------------------------------------------|
| expr     | The data of the string, `NUMBER`, `BINARY_FLOAT`, or `BINARY_DOUBLE` type.              |
| expr     | The output format parameter. Optional. If you omit `fmt`, `n` is converted to a `VARCHAR2` value. For more information about the values, see the description of the `fmt` parameter. |
| nlsparam | Defines the decimal character, group separator, local currency symbol, and international currency symbol. Optional.                                   |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>When <code>expr</code> is a string, the optional <code>fmt</code> and <code>nlsparam</code> parameters are valid. They function the same as the <code>TO_CHAR (number)</code> function. When <code>expr</code> is a <code>BINARY_FLOAT</code>, the function returns <code>expr</code>. </p>
  </main>

## Return type

Returns data of the `BINARY_FLOAT` type.

## Examples

Convert the string `123.123` to a single-precision floating-point number.

```sql
obclient> SELECT TO_BINARY_FLOAT('123.123') FROM DUAL;
+----------------------------+
| TO_BINARY_FLOAT('123.123') |
+----------------------------+
|            1.23123001E+002 |
+----------------------------+
1 row in set
```
