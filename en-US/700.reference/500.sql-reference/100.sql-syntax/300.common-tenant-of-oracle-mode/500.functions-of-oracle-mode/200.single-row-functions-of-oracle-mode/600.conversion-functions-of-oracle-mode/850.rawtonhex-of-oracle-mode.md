# RAWTONHEX

## Purpose

`RAWTONHEX()` converts a `RAW` value to its hexadecimal string representation.

## Syntax

```sql
RAWTONHEX(raw)
```

## Parameters

`raw` specifies the `RAW` value to convert.

## Return type

The return type is `NVARCHAR2`.

## Examples

The following example converts a `RAW` value to its hexadecimal string representation:

```sql
obclient> SELECT RAWTONHEX(HEXTORAW('4F6365616E42617365')) AS result FROM DUAL;
+--------------------+
| RESULT             |
+--------------------+
| 4F6365616E42617365 |
+--------------------+
1 row in set
```
