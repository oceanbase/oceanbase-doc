# TO_YMINTERVAL

## Purpose

This function converts a string of `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type into an `INTERVAL YEAR TO MONTH` value, which can be used to add or subtract from a date or datetime value.

## Syntax

```sql
/*SQL date format*/
TO_YMINTERVAL([+|-] years-months)

/*ISO date format*/
TO_YMINTERVAL([-]P[ years Y][months M][days D][T[hours H][minutes M][seconds[.frac_secs]S]])
```

## Parameters

|                                               Parameter                                                |                                                                                                                        Description                                                                                                                        |
|-------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \[+\|-\] years-months                                                                           | A string of `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type that conforms to this parameter format. <ul><li> `years` indicates the number of years, which must be an integer in the range \[0,999999999\].   </li><li> `months` indicates the number of months, which must be an integer in the range \[0,11\].</li></ul>      |
| \[-\]P\[ years Y\]\[months M\]\[days D\]\[T\[hours H\]\[minutes M\]\[seconds\[.frac_secs\]S\]\] | A string of `CHAR`, `VARCHAR2`, `NCHAR`, or `NVARCHAR2` data type that conforms to this parameter format. `frac_secs` indicates the fractional part of the seconds, which must be an integer in the range \[0,999999999\]. <br>**Note**  The value cannot contain spaces.                                                                    |

## Return type

`INTERVAL YEAR TO MONTH`

## Examples

Return the date and time value 1 year and 2 months from the current time.

```sql
obclient> SELECT SYSDATE,SYSDATE+TO_YMINTERVAL('01-02') FROM DUAL;
+-----------+--------------------------------+
| SYSDATE   | SYSDATE+TO_YMINTERVAL('01-02') |
+-----------+--------------------------------+
| 18-NOV-21 | 18-JAN-23                      |
+-----------+--------------------------------+
1 row in set
```

Specify a time interval of 2 years, 6 months, 10 days, 4 hours, 30 minutes, and 15 seconds, as in the following example:

```sql
obclient> SELECT TO_YMINTERVAL('P2Y6M10DT4H30M15S') FROM dual;
+------------------------------------+
| TO_YMINTERVAL('P2Y6M10DT4H30M15S') |
+------------------------------------+
| +000000002-06                      |
+------------------------------------+
1 row in set
```

The following example shows a negative time interval. Assume that you want to subtract 3 years, 1 month, and 5 days. You can use the following example:

```sql
obclient> SELECT TO_YMINTERVAL('-P3Y1M5D') FROM dual;
+---------------------------+
| TO_YMINTERVAL('-P3Y1M5D') |
+---------------------------+
| -000000003-01             |
+---------------------------+
1 row in set
```
