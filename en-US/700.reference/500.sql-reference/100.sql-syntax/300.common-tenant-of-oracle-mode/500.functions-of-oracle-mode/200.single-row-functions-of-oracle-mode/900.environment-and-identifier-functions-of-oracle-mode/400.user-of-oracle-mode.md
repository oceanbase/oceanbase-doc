# USER

## Purpose

This function returns the name of the current user.

## Syntax

```sql
USER
```

## Return type

`VARCHAR2`

## Examples

Return the name of the current user.

```sql
obclient> SELECT USER FROM DUAL;
+------+
| USER |
+------+
| SYS  |
+------+
1 row in set
```
