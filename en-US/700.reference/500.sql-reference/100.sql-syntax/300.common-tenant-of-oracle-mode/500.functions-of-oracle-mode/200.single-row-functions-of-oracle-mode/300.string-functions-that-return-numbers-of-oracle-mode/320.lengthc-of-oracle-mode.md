# LENGTHC

## Purpose

`LENGTHC()` returns the length of a string in Unicode complete characters.

## Syntax

```sql
LENGTHC(char)
```

## Parameters

`char` specifies the string whose length is calculated.

## Return type

The return type is `NUMBER`.

## Examples

The string `éOceanBase` contains 10 Unicode complete characters:

```sql
obclient> SELECT LENGTHC('éOceanBase') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|     10 |
+--------+
1 row in set
```
