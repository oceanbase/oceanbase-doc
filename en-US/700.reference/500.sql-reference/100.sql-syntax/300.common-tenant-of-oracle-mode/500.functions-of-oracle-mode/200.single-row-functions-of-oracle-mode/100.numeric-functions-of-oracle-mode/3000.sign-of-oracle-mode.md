# SIGN

## Purpose

This function returns the sign of the input value. The sign can be `1`, `-1`, or `0`.

## Syntax

```sql
SIGN(numeric_expression)
```

## Parameters

`numeric_expression` is a numeric data type (`NUMBER`, `FLOAT`, `BINARY_FLOAT`, and `BINARY_DOUBLE`) or an argument that can be implicitly converted to a numeric data type.

## Return type

The function returns a `NUMBER` data type.

* If `numeric_expression > 0`, the function returns `1`.

* If `numeric_expression < 0`, the function returns `-1`.

* If `numeric_expression = 0`, the function returns `0`.

## Examples

Return the sign of `2`, `-2`, `0`, and `3+3`.

```sql
obclient> SELECT SIGN(2),SIGN(-2),SIGN(0),SIGN(3+3) FROM DUAL;
+---------+----------+---------+-----------+
| SIGN(2) | SIGN(-2) | SIGN(0) | SIGN(3+3) |
+---------+----------+---------+-----------+
|       1 |       -1 |       0 |         1 |
+---------+----------+---------+-----------+
1 row in set
```
