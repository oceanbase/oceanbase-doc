# ROUND

## Purpose

This function returns the value of the `numeric` parameter rounded to the nearest value.

## Syntax

```sql
ROUND (numeric[,decimal])
```

## Parameters

|   Parameter    |                                                                                                                                                                           Description                                                                                                                                                                            |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| numeric | A `NUMBER`, `FLOAT`, `BINARY_FLOAT`, or `BINARY_DOUBLE` expression.                                                                                                                                                                                                                                                                                            |
| decimal | <ul><li> If `decimal` is greater than or equal to `0`, the `numeric` value is rounded to `decimal` decimal places.   </li><li> If `decimal` is less than `0`, the `numeric` value is rounded to the `decimal`th digit to the left of the decimal point.   </li><li> If `decimal` is not an integer, the integer part of `decimal` is used.   </li><li> If `decimal` is not specified, the `numeric` value is rounded to the nearest integer. </li></ul>    |

## Return type

* If `decimal` is not specified, the return type is the same as the type of the `numeric` parameter.

* If `decimal` is specified, the return type is the `NUMBER` data type.

## Examples

The following examples show the result of rounding `666.666` when `decimal` is `1`, `-1`, `2.1`, and when `decimal` is not specified.

```sql
obclient> SELECT ROUND(666.666,1),ROUND(666.666,-1),ROUND(666.666,2.1),ROUND(666.666) FROM DUAL;
+------------------+-------------------+--------------------+----------------+
| ROUND(666.666,1) | ROUND(666.666,-1) | ROUND(666.666,2.1) | ROUND(666.666) |
+------------------+-------------------+--------------------+----------------+
|            666.7 |               670 |             666.67 |            667 |
+------------------+-------------------+--------------------+----------------+
1 row in set
```
