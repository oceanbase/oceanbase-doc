# REMAINDER

## Purpose

The `REMAINDER` function returns the remainder of `x` divided by `y`.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Both the <code>REMAINDER (x,y)</code> and <code>MOD (x,y)</code> functions use the formula <code>result=x-y*(x/y)</code>. The difference lies in the method used to calculate <code>x/y</code>. In the <code>REMAINDER (x,y)</code> function, <code>ROUND(x/y)</code> is used, while in the <code>MOD (x,y)</code> function, <code>FLOOR(x/y)</code> is used.</p>
    <p>In the <code>REMAINDER</code> function, if the fractional part of <code>ROUND(x/y)</code> is exactly <code>0.5</code>, the function rounds to the nearest even integer. For example, <code>ROUND(1.5)=2</code>, <code>ROUND(2.5)=2</code>, <code>ROUND(3.5)=4</code>, and <code>ROUND(4.5)=4</code>.</p>
  </main>

## Syntax

```sql
REMAINDER (x, y)
```

## Parameters

| **Parameter** |                                                 **Description**                                                  |
|--------|---------------------------------------------------------------------------------------------------------|
| x      | The dividend. It is a numeric expression of type `NUMBER`, `FLOAT`, `BINARY_FLOAT`, or `BINARY_DOUBLE`.                                        |
| y      | The divisor. It is a numeric expression of type `NUMBER`, `FLOAT`, `BINARY_FLOAT`, or `BINARY_DOUBLE`. <br>**Notice**  The parameter `y` cannot be `0`. |

## Return type

The return type is the data type of the numeric parameter with the higher precedence.

## Examples

Use the `MOD` and `REMAINDER` functions to return the remainder of `1.5` divided by `1`.

```sql
obclient> SELECT MOD(1.5,1),REMAINDER(1.5,1) FROM DUAL;
+------------+------------------+
| MOD(1.5,1) | REMAINDER(1.5,1) |
+------------+------------------+
|         .5 |              -.5 |
+------------+------------------+
1 row in set
```
