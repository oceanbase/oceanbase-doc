# COVAR_POP

## Purpose

This function calculates the population covariance of a set of pairs of values. You can use this function as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for computation. It calculates the covariance for a set of rows and returns multiple values.</li>
    <li>When used as an aggregate function, it aggregates the covariance for a set of rows and returns a single value. In this case, you do not need to use the <code>OVER</code> clause.</li>
    </ul>
  </main>

## Syntax

```sql
COVAR_POP(expr1, expr2)[ OVER (analytic_clause) ]
```

## Parameters

|  Parameter   |                                           Description                                            |
|-------|-----------------------------------------------------------------------------------------|
| expr1 | The first numeric expression, which is a value of a numeric data type or can be implicitly converted to a numeric data type.                                                    |
| expr2 | The second numeric expression, which is a value of a numeric data type or can be implicitly converted to a numeric data type.                                                    |
| OVER  | Use the `OVER` clause to define the window for computation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md). |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>The database determines the parameter with the highest numeric precedence, implicitly converts the other parameters to this data type, and returns the result in this data type.</li>
    <li>The positions of the parameters <code>expr1</code> and <code>expr2</code> do not affect the result. In other words, <code>COVAR_POP(expr1, expr2)</code> is equal to <code>COVAR_POP(expr2, expr1)</code>.</li>
    <li>The calculation formula for the result is: <code>(SUM(expr1 * expr2) - SUM(expr2) * SUM(expr1) / n) / n</code>, where <code>n</code> is the number of pairs of (<code>expr1</code>,<code>expr2</code>) expressions, and both <code>expr1</code> and <code>expr2</code> are not empty.</li>
    </ul>
  </main>

## Return type

If any parameter is empty, it returns `NULL`. Otherwise, it returns a value of the `NUMBER` type.

### Example of aggregate function

Calculate the population covariance of the pairs of values in the `col3` and `col4` columns.

```sql
obclient> SELECT COVAR_POP(col3,col4) FROM tbl1;
+----------------------+
| COVAR_POP(COL3,COL4) |
+----------------------+
|                 -.75 |
+----------------------+
1 row in set
```

### Example of analytic function

Group the data by the `col1` column and sort the data by the `col2` column. Calculate the cumulative population covariance of the pairs of values in the `col3` and `col4` columns.
