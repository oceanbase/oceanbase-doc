# NTH_VALUE

## Purpose

This function returns the value of the `measure_expr` field in the `n`th row of the window defined by the `analytic_clause`.

## Syntax

```sql
NTH_VALUE (measure_expr, n)
  [ FROM { FIRST | LAST } ][ { RESPECT | IGNORE } NULLS ]
OVER (analytic_clause)
```

## Parameters

|            Parameter             |                                                                                                           Description                                                                                                            |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| measure_expr              | The field to return data from.                                                                                                                                                                                                              |
| n                         | The `n`th row to return the measurement value from. `n` is a positive integer. **Notice**  <ul><li> If `n` is `NULL`, the function returns an error.   </li><li> If `n` exceeds the number of rows in the window, the function returns `NULL`. </li></ul>    |
| FROM { FIRST \| LAST }    | The calculation direction. Optional. Default value is `FROM FIRST`. <ul><li> `FROM FIRST` indicates to calculate from the first row of the window.   </li><li> `FROM LAST` indicates to calculate from the last row. </li></ul>                             |
| {RESPECT \| IGNORE} NULLS | Whether to ignore `NULL` values. Optional. Default value is `RESPECT NULLS`. <ul><li> `RESPECT  NULLS` indicates to not ignore `NULL` values.   </li><li> `IGNORE NULLS` indicates to ignore `NULL` values. </li></ul>      |
| OVER                      | Use the `OVER` clause to define the window for calculation. For more information, see [Analytic Functions](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                 |

## Return type

The return type is the same as the data type of the `measure_expr` parameter.
