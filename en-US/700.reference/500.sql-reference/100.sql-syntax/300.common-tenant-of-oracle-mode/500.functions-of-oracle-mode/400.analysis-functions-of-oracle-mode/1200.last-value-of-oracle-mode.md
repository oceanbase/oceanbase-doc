# LAST_VALUE

## Purpose

This function is an analytic function that returns the last value in an ordered set of values. If the last value in the set is `NULL`, the function returns `NULL`, unless you specify `IGNORE NULLS`, which is useful for data densification.

## Syntax

```sql
LAST_VALUE { (expr) [{RESPECT | IGNORE} NULLS ]
            | (expr [{RESPECT | IGNORE} NULLS ])
            }
OVER (analytic_clause)
```

## Parameters

|            Parameter             |                                                                                                          Description                                                                                                           |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                      | Specifies the expression. <br>**Note**  You cannot nest an analytic function, such as `LAST_VALUE`, in the `expr` parameter.                                                                                                                              |
| {RESPECT \| IGNORE} NULLS | Specifies whether to ignore `NULL` values. This is an optional parameter. The default value is `RESPECT NULLS`. <ul><li> `RESPECT  NULLS` specifies not to ignore `NULL` values.   </li><li> `IGNORE NULLS` specifies to ignore `NULL` values.</li></ul>    |
| OVER                      | Defines the window for calculation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                               |

## Return type

The return type is the same as the data type of `expr` or `NULL`.

## Examples
