# SUM

## Purpose

This function returns the sum of the specified parameter. It can be used as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for computation. It computes over a set of rows and returns multiple values. </li>
    <li>When used as an aggregate function, it aggregates a set of rows and returns a single value. In this case, the <code>OVER</code> clause is not required. </li>
    </ul>
  </main>

## Syntax

```sql
SUM([ DISTINCT | UNQIUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## Parameters

|            Parameter             |                                                                                                                                      Description                                                                                                                                       |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNQIUE \| ALL | Specifies whether to remove duplicates. This is an optional parameter with a default value of `ALL`. <ul><li> `ALL`: computes all values, including duplicates, and ignores rows with a value of `NULL`.   </li><li> `DISTINCT`: removes duplicates and ignores rows with a value of `NULL`.   </li><li> `UNIQUE`: removes duplicates and ignores rows with a value of `NULL`. </li></ul>   |
| expr                      | A numeric data type or any expression that can be implicitly converted to a numeric data type.                                                                                                                                                                                                                                                   |
| OVER                      | Specifies the <code>OVER</code> clause to define the window for computation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                                                                       |

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>If you specify the <code>DISTINCT</code> or <code>UNIQUE</code> keyword, the <code>order_by_clause</code> and <code>windowing_clause</code> parameters cannot be specified in the <code>analytic_clause</code>. </p>
  </main>

## Return type

The return type is the same as the data type of `expr`.

## Examples

Assume that the `employees` table has been created.

```sql
obclient> SELECT * FROM employees;
+---------------+-----------+------------+--------+
| DEPARTMENT_ID | LAST_NAME | HIREDATE   | SALARY |
+---------------+-----------+------------+--------+
|            30 | Raphaely  | 2017-07-01 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |
|            40 | Errazuriz | 2017-07-21 |   1400 |
|            50 | Hartstein | 2019-10-05 |  14000 |
|            50 | Raphaely  | 2017-07-22 |   1700 |
|            50 | Weiss     | 2019-10-05 |  13500 |
|            90 | Russell   | 2019-07-11 |  13000 |
|            90 | Partners  | 2018-12-01 |  14000 |
+---------------+-----------+------------+--------+
8 rows in set
```

### Aggregate function example

Compute the sum of the `salary` column in the `employees` table.

```sql
obclient> SELECT SUM(salary) FROM employees;
+-------------+
| SUM(SALARY) |
+-------------+
|       70300 |
+-------------+
1 row in set
```

### Analytic function example

Group by the `department_id` column and sort the `salary` column in ascending order, and return the cumulative sum of the `salary` column.

```sql
obclient> SELECT department_id, last_name, salary,
              SUM(salary) OVER
                  (PARTITION BY department_id ORDER BY salary RANGE UNBOUNDED PRECEDING) s_sum
    FROM employees
    ORDER BY department_id,s_sum;
+---------------+-----------+--------+-------+
| DEPARTMENT_ID | LAST_NAME | SALARY | S_SUM |
+---------------+-----------+--------+-------+
|            30 | Raphaely  |   1700 |  1700 |
|            30 | De Haan   |  11000 | 12700 |
|            40 | Errazuriz |   1400 |  1400 |
|            50 | Raphaely  |   1700 |  1700 |
|            50 | Weiss     |  13500 | 15200 |
|            50 | Hartstein |  14000 | 29200 |
|            90 | Russell   |  13000 | 13000 |
|            90 | Partners  |  14000 | 27000 |

```
