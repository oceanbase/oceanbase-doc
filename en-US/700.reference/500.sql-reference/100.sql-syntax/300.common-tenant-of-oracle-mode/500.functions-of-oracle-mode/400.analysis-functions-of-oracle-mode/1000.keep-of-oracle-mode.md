# KEEP

## Purpose

This function is used to operate on values in a set of rows, sort these rows according to the specified sort order, and return the value at the first or last position. It can be used as an aggregate or analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, the <code>OVER</code> clause must be used to define the window for calculation. This function partitions the query result set into several groups based on one or more expressions in <code>query_partition_clause</code>.</li>
    <li>When used as an aggregate function, this function performs aggregate calculations on a set of rows and returns only one value. In this case, the <code>OVER</code> clause is not required.</li>
    </ul>
  </main>

## Syntax

```sql
aggregate_function KEEP ( DENSE_RANK { FIRST | LAST }
                ORDER BY expr [ DESC | ASC ] [ NULLS { FIRST | LAST } ]
                      [, expr [ DESC | ASC ] [ NULLS { FIRST | LAST } ]]...
                        )
[ OVER ( [query_partition_clause] ) ]

aggregate_function:
  MIN
 |MAX
 |SUM
 |AVG
 |COUNT
 |VARIANCE
 |STDDEV
```

## Parameters

|           Parameter            |                                                                                                          Description                                                                                                          |
|-------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| aggregate_function      | Specifies the type of aggregate function.                                                                                                                                                                                                           |
| expr                    | Can be any expression.                                                                                                                                                                                                            |
| FIRST \| LAST           | Specifies the position of the value to be returned after sorting `expr`. <ul><li> `FIRST` specifies to return the value at the first position.   </li><li> `LAST` specifies to return the value at the last position. </li></ul>                                               |
| DESC \| ASC             | Specifies the sort order, which is optional. <ul><li> `ASC` specifies ascending order, which is the default.   </li><li> `DESC` specifies descending order. </li></ul>                                                              |
| NULLS { FIRST \| LAST } | Specifies the position of `NULL` values after sorting `expr`, which is optional. <ul><li> `NULLS FIRST` specifies that `NULL` values are placed before non-`NULL` values.   </li><li> `NULLS LAST` specifies that `NULL` values are placed after non-`NULL` values, which is the default. </li></ul>   |
| OVER                    | Defines the window for calculation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                              |

## Return type

The return type is the same as the data type of the column specified in `aggregate_function`.

### Aggregate function example

Sum the salaries of the employees with the highest salary and the lowest salary.

```sql
obclient> SELECT SUM(salary) KEEP (DENSE_RANK FIRST ORDER BY salary) "Worst",
    SUM(salary) KEEP (DENSE_RANK LAST ORDER BY HIREDATE) "Best"
    FROM employees;
+-------+-------+
| Worst | Best  |
+-------+-------+
|  1400 | 27500 |
+-------+-------+
1 row in set
```

### Analytic function example

For each department, sum the salaries of the employees with the highest salary and the lowest salary.

```sql
obclient> SELECT last_name,department_id,salary,
    SUM(salary) KEEP (DENSE_RANK FIRST ORDER BY salary)
        OVER (PARTITION BY department_id) "Worst",
    SUM(salary) KEEP (DENSE_RANK LAST ORDER BY HIREDATE)
        OVER (PARTITION BY department_id) "Best"
    FROM employees
    ORDER BY department_id, salary, last_name;
```
