# LAG

## Purpose

This function is an analytic function that retrieves the data of the preceding `offset` rows of the same field in a query and stores it as an independent column in the table. This operation can replace a self-join on the table.

## Syntax

```sql
LAG { (value_expr [,offset [,default]]) [{ RESPECT|IGNORE } NULLS ]
    | (value_expr [{ RESPECT|IGNORE } NULLS ] [,offset [,default] ])
    }
OVER([query_partition_clause] order_by_clause)
```

## Parameters

|            Parameter             |                                                                                                          Description                                                                                                           |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| value_expr                | Specifies the field to be queried. <br>**Notice**  You cannot nest `value_expr` in the `LAG` function or other analytic functions.                                                                                                                              |
| offset                    | Specifies the offset for querying `value_expr`. It is an integer greater than 0 and is optional. The default value is `1`.                                                                                                                                                                        |
| default                   | Specifies the default value. If the offset exceeds the window range, the value of `default` is returned. It is optional. The default value is `NULL`.                                                                                                                                                          |
| {RESPECT \| IGNORE} NULLS | Specifies whether to ignore `NULL` values. It is optional. The default value is `RESPECT NULLS`. <ul><li> `RESPECT  NULLS` specifies not to ignore `NULL` values.   </li><li> `IGNORE NULLS` specifies to ignore `NULL` values.</li></ul>    |
| OVER                      | Defines the window for calculation using the `OVER` clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                               |

## Return type

The data type of the return value is not limited.
