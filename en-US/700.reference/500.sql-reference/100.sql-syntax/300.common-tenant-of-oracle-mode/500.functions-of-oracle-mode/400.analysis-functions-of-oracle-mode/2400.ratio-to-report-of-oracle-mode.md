# RATIO_TO_REPORT

## Purpose

This function is an analytic function that calculates the ratio of a value to the sum of a group of values.

## Syntax

```sql
RATIO_TO_REPORT(expr) OVER ([query_partition_clause])
```

## Parameters

|  Parameter  |                                               Description                                               |
|------|------------------------------------------------------------------------------------------------|
| expr | The field to query. <br>**Notice**  You cannot nest `expr` in the `RATIO_TO_REPORT` function or other analytic functions. |
| OVER | Use the `OVER` clause to define the window for calculation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).        |

## Return type

If `expr` is `NULL`, the result is `NULL`. Otherwise, the result is a numeric data type.
