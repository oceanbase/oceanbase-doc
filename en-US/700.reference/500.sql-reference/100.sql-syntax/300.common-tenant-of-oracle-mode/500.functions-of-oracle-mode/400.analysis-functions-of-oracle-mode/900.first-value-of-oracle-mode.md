# FIRST_VALUE

## Purpose

This function is an analytic function that returns the first value in an ordered set. If the first value in the set is `NULL`, the function returns `NULL`, unless you specify `IGNORE NULLS`, which is useful for data densification. The return value for rows with `NULL` values in the `expr` column is `NULL`.

## Syntax

```sql
FIRST_VALUE { (expr) [{RESPECT | IGNORE} NULLS ]
            | (expr [{RESPECT | IGNORE} NULLS ])
            }
OVER (analytic_clause)
```

## Parameters

|            Parameter             |                                                                                                          Description                                                                                                           |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                      | Specifies the column name to return a value. <br>**Note**  You cannot nest an analytic function, such as `FIRST_VALUE`, in the `expr` column.                                                                                                                        |
| {RESPECT \| IGNORE} NULLS | Specifies whether to ignore `NULL` values. This is an optional parameter. The default value is `RESPECT NULLS`. <ul><li>  `RESPECT  NULLS` specifies not to ignore `NULL` values.   </li><li>`IGNORE NULLS` specifies to ignore `NULL` values.</li></ul>     |
| OVER                      | Use the `OVER` clause to define the window for calculation. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                               |

## Return type

The return value is the same as the data type of the `expr` parameter or `NULL`.
