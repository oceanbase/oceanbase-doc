# COUNT

## Purpose

This function returns the number of rows that match the query condition. It can be used as an aggregate function or an analytic function.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When used as an analytic function, you must use the <code>OVER</code> clause to define the window for calculation. It calculates over a set of rows and returns multiple values. </li>
    <li>When used as an aggregate function, this function aggregates a set of rows and returns a single value. In this case, the <code>OVER</code> clause is not required. </li>
    </ul>
  </main>

## Syntax

```sql
COUNT({ * | [ DISTINCT | UNIQUE | ALL ] expr }) [ OVER (analytic_clause) ]
```

## Parameters

|            Parameter             |                                                                                                                            Description                                                                                                                             |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \*                        | Indicates to return all rows that meet the condition, including duplicate rows and rows with NULL values.                                                                                                                                                                                                                                   |
| DISTINCT \| UNIQUE \| ALL | Specifies whether to remove duplicates. This is an optional parameter with a default value of `ALL`. <ul><li> `ALL`: returns all values, including duplicate rows, and ignores rows with NULL values.   </li><li> `DISTINCT`: returns rows with duplicates removed and ignores rows with NULL values.   </li><li> `UNIQUE`: returns rows with duplicates removed and ignores rows with NULL values.</li></ul>    |
| expr                      | Specifies the name of the column to be calculated.                                                                                                                                                                                                                                                |
| OVER                      | Defines the window for calculation using the <code>OVER</code> clause. For more information, see [Analytic Function Description](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md).                                                                                                                                                                   |

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <ul>
    <li>The <code>COUNT</code> function never returns <code>NULL</code>. If you specify <code>expr</code>, it returns the count of rows where <code>expr</code> is not <code>NULL</code>. If you specify <code>COUNT(*)</code>, it returns the total number of rows. When using the <code>DISTINCT</code>, <code>UNIQUE</code>, or <code>ALL</code> parameters, they must be separated from <code>expr</code> by a space. </li>
    <li>If you specify the <code>DISTINCT</code> or <code>UNIQUE</code> keyword, the <code>order_by_clause</code> and <code>windowing_clause</code> cannot appear in the <code>analytic_clause</code>. </li>
    </ul>
  </main>

## Return type

A natural number.

## Examples

Create a table named `tbl1` and insert test data.

```sql
obclient> CREATE TABLE tbl1 (col1 INT,col2 varchar(10),col3 INT);
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES

obclient> SELECT * FROM tbl1;
```

### Aggregate function example

Count the number of non-NULL rows in column `col3` of table `tbl1` and the total number of rows in table `tbl1`.

```sql
obclient> SELECT COUNT(col3),COUNT(*) FROM tbl1;
+-------------+----------+
| COUNT(COL3) | COUNT(*) |
+-------------+----------+
|          10 |       12 |
+-------------+----------+
1 row in set
```

### Analytic function example

Count the number of rows in table `tbl1` where the value of `col3` is between `1` and `3`.

```sql
obclient> SELECT col1,col2,
                 COUNT(*) OVER (ORDER BY col3 RANGE BETWEEN 1 PRECEDING AND 3 FOLLOWING) AS mov_count
          FROM tbl1;
+------+------+-----------+
| COL1 | COL2 | MOV_COUNT |
+------+------+-----------+
|    1 | aa   |         2 |
|    2 | bb   |         3 |
|    3 | cc   |         3 |
|   10 | jj   |         3 |
|    4 | dd   |         2 |
|    5 | ee   |         2 |
|    6 | ff   |         2 |
|    7 | gg   |         1 |
|    8 | hh   |         1 |
|    9 | ii   |         1 |
```
