# ALTER SYSTEM SET PARAMETER

## Purpose

This statement is used to modify the configuration parameters of the current tenant.

## Syntax

```sql
ALTER SYSTEM SET parameter_name = expression;
```

## Parameters

|     **Parameter**     |    **Description**    |
|----------------|--------------|
| parameter_name | Specifies the name of the configuration parameter to be modified. |
| expression     | Specifies the new value of the configuration parameter. |

## Examples

Modify the configuration parameter `log_disk_utilization_threshold`.

```sql
obclient> SHOW PARAMETERS LIKE 'log_disk_utilization_threshold';
```

```sql

obclient> ALTER SYSTEM SET log_disk_utilization_threshold = 20;
```
