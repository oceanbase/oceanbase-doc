# DROP PROFILE

## Purpose

This statement is used to drop a profile.

## Syntax

```sql
DROP PROFILE profile_name
```

## Parameters

|      Parameter      |       Description       |
|--------------|----------------|
| profile_name | The name of the profile to be dropped. |

## Examples

1. Create a profile named `profile1`.

   ```sql
   obclient> CREATE PROFILE profile1 LIMIT
       FAILED_LOGIN_ATTEMPTS 5
       PASSWORD_LOCK_TIME 1
       PASSWORD_LIFE_TIME 60;
   ```

2. Drop the `profile1` profile.

   ```sql
   obclient> DROP PROFILE profile1;
   ```
