# CREATE FORMAT OUTLINE

## Purpose

This statement is used to create a fuzzy outline. You can create a fuzzy outline in two ways: one is by using `FORMAT_SQL_TEXT` (the original statement with parameters executed by the user), and the other is by using `FORMAT_SQL_ID`.

## Limitations and considerations

* To create an outline, you must be logged in as the corresponding user.

* If `FORMAT_SQL_ID` is the same, the outline created by using `FORMAT_SQL_TEXT` will overwrite the outline created by using `FORMAT_SQL_ID`. The outline created by using `FORMAT_SQL_TEXT` has a higher priority. In addition, OceanBase Database distinguishes different SQL statements by using `FORMAT_SQL_ID`, which is obtained by taking the `MD5` hash of `FORMAT_SQL_TEXT`. In a production system, we recommend that you bind an outline by using `FORMAT_SQL_ID`.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><ul><li>The matching rules of <code>FORMAT_SQL_TEXT</code> ignore the differences in parameter content, case, and non-syntactic symbols such as spaces and line breaks. It only compares the processed text content. </li><li><code>FORMAT_SQL_ID</code> is generated by formatting <code>FORMAT_SQL_TEXT</code> (removing extra spaces and line breaks and converting all characters to uppercase or lowercase), and then applying the <code>MD5</code> hash encryption to the formatted result. </li></ul></p>
  </main>

## Syntax

```sql
/* Create an outline by using FORMAT_SQL_TEXT */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_stmt [ TO format_target_stmt ]

/* Create an outline by using FORMAT_SQL_ID */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_sql_id USING HINT hint;
```

## Parameters

|        Parameter           |            Description             |
|-----------------------|----------------------------|
| outline_name          | The name of the fuzzy outline to be created.|
| OR REPLACE            | If you specify `OR REPLACE`, the existing outline will be replaced if the specified outline already exists.|
| format_stmt           | The original SQL statement. <main id="notice" type='explain'><h4>Note</h4><p>OceanBase Database automatically converts the unformatted SQL statement into a formatted SQL statement. </p></main>|
| TO format_target_stmt | Optional. Specifies the target SQL statement to which `format_stmt` is converted or applied. This option allows the outline to be applicable to other SQL statements. <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>If you want to fix the execution plan of a statement with a hint, use <code>format_target_stmt</code> to specify the original SQL statement. </li><li>When using the <code>TO format_target_stmt</code> clause, the original SQL statement <code>format_stmt</code> must match <code>format_target_stmt</code> after removing the hint and formatting. </li></ul></p></main>|
| format_sql_id         | The `format_stmt` obtained after a series of rules are applied to the SQL statement to be bound. Then, the `MD5` value of `format_stmt` is calculated to obtain `format_sql_id`.|

## Examples

* Create an outline by using `FORMAT_SQL_TEXT`.

  ```sql
  CREATE FORMAT OUTLINE my_outline ON 'SELECT * FROM employees WHERE department_id = ?';
  ```

* Create an outline by using `FORMAT_SQL_ID`.

  ```sql
  CREATE FORMAT OUTLINE my_sql_id_outline ON 'ED570339F2C856BA96008A29EDF04C74' USING HINT /*+ index(tbl1 idx_col2)*/;
  ```
