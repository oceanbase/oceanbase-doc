# DROP ROLE

## Purpose

This statement is used to drop a role.

  <main id="notice" type='explain'>
    <h4>Note</h4>
      <p>After a role is dropped, the following changes will be made: </p>
      <ul>
      <li>The role will be revoked from all users and roles that have been granted the role. </li>
      <li>The role will be removed from the database. </li>
      <li>Existing sessions that have been enabled for the role will not be affected. </li>
      <li>New sessions will not be able to enable the role. </li>
      </ul>
  </main>

## Syntax

```sql
DROP ROLE role_name
```

## Parameters

|    Parameter     |      Description      |
|-----------|--------------|
| role_name | The name of the role to be dropped. |

## Examples

First, create a role named `sales_manager`, and then drop it.

```sql
obclient> CREATE ROLE sales_manager;
obclient> DROP ROLE sales_manager;
```
