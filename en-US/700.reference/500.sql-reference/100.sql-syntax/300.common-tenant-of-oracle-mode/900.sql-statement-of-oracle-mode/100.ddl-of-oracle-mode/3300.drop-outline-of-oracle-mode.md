# DROP OUTLINE

## Purpose

You can use this statement to drop an outline from OceanBase Database.

## Syntax

```sql
DROP [FORMAT] OUTLINE outline_name
    [BINDING_RULE (binding_item)];

binding_item:
    SCOPE = {DATABASE | TENANT}
```

## Parameters

| **Parameter** | **Description** |
|--------------|----------|
| FORMAT       | Optional. Indicates that a `FORMAT OUTLINE` (fuzzy outline) is to be dropped.|
| outline_name | The name of the outline to be dropped.|
| BINDING_RULE (binding_item) | Optional. Specifies the level at which the outline is dropped.<ul><li>`BINDING_RULE (SCOPE = DATABASE)`: the default value. Drops the outline at the current database level, which is equivalent to not explicitly specifying the `BINDING_RULE` parameter.</li><li>`BINDING_RULE (SCOPE = TENANT)`: drops the cross-database (tenant-level) outline with the specified name.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, the <code>BINDING_RULE</code> clause is supported starting from V4.4.2 BP3.</p></main>|

## Examples

Create a test table and a related outline, then delete them.

1. Create the `employees` table.

   ```shell
   obclient> CREATE TABLE employees (emp_id INT, emp_name VARCHAR(20));
   ```

2. Insert test data into the `employees` table.

   ```shell
   obclient> INSERT INTO employees VALUES (1, 'John'), (2, 'Alice');
   ```

3. Create an outline.

   ```shell
   obclient> CREATE OUTLINE emp_query_outline
       ON SELECT * FROM employees WHERE emp_id=1;
   ```

4. Drop the outline.

   ```shell
   obclient> DROP OUTLINE emp_query_outline;
   ```

5. Drop the test table.

   ```shell
   obclient> DROP TABLE employees;
   ```
