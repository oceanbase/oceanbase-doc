# MAJOR and MINOR

## Purpose

This statement is used to initiate a major or minor freeze in a user tenant. Manual major freezes are supported at the tenant, table, and partition levels. Minor freezes are supported at the tenant and partition levels.

## Syntax

```shell
ALTER SYSTEM merge_action;

merge_action:
      MAJOR FREEZE [TABLE_ID = table_id | TABLET_ID = tablet_id]
    | MINOR FREEZE [TABLET_ID = tablet_id]
    | {SUSPEND | RESUME} MERGE
    | CLEAR MERGE ERROR
```

## Parameters

|          **Parameter**           |      **Description**      |
|---------------------------|------------------|
| MAJOR FREEZE              | Initiates a major freeze. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can only initiate a major freeze for itself.</p></main>        |
| MINOR FREEZE              | Initiates a minor freeze. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can only initiate a minor freeze for itself.</p></main>    |
| {SUSPEND \| RESUME} MERGE | Suspends or resumes a major freeze. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can only suspend or resume a major freeze for itself.</p></main>        |
| CLEAR MERGE ERROR         | Clears a major freeze error. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can only clear a major freeze error for itself.</p></main>      |
| TABLE_ID                  | Specifies a table for a major freeze.                 |
| TABLET_ID                 | Specifies a partition for a minor freeze or a major freeze.          |

## Examples

### Examples related to major freezes

* Initiates a major freeze for the user tenant.

  ```shell
  obclient> ALTER SYSTEM MAJOR FREEZE;
  Query OK, 0 rows affected
  ```

* Initiates a table-level major freeze for the user tenant.

  1. Query the `table_id` of the table TBL1 to be major frozen.

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT DATABASE_NAME, TABLE_ID, TABLE_NAME FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_NAME = 'TBl1';
     ```

     The query result is as follows:

     ```shell
     +---------------+----------+------------+
     | DATABASE_NAME | TABLE_ID | TABLE_NAME |
     +---------------+----------+------------+
     | SYS           |   500002 | TBL1       |
     +---------------+----------+------------+
     1 row in set
     ```

  2. Execute the following command to initiate a table-level major freeze.

     ```shell
     obclient(SYS@oracle001)[SYS]> ALTER SYSTEM MAJOR FREEZE TABLE_ID = 500002;
     ```

* Initiates a partition-level major freeze for the user tenant.

  1. Query the `tablet_id` of the partition to be major frozen.

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT DATABASE_NAME, TABLE_ID, TABLE_NAME, TABLET_ID, PARTITION_NAME, SUBPARTITION_NAME FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_NAME = 'TBL1';
     ```

     The query result is as follows:

     ```shell
     +---------------+----------+------------+-----------+----------------+-------------------+
     | DATABASE_NAME | TABLE_ID | TABLE_NAME | TABLET_ID | PARTITION_NAME | SUBPARTITION_NAME |
     +---------------+----------+------------+-----------+----------------+-------------------+
     | SYS           |   500012 | TBL1       |    200007 | P01            | NULL              |
     | SYS           |   500012 | TBL1       |    200008 | P02            | NULL              |
     | SYS           |   500012 | TBL1       |    200009 | P03            | NULL              |
     +---------------+----------+------------+-----------+----------------+-------------------+
     3 rows in set
     ```

  2. Execute the following command to initiate a partition-level major freeze.

     ```shell
     obclient(SYS@oracle001)[SYS]> ALTER SYSTEM MAJOR FREEZE TABLET_ID = 200007;
     ```

### Examples of suspending or resuming a major freeze

* Suspends a major freeze for the user tenant.

  ```shell
  obclient> ALTER SYSTEM SUSPEND MERGE;
  Query OK, 0 rows affected
  ```

* Resumes a major freeze for the user tenant.

  ```shell
  obclient> ALTER SYSTEM RESUME MERGE;
  Query OK, 0 rows affected
  ```

### Examples of clearing a major freeze error

* Clears a major freeze error for the user tenant.

  ```shell
  obclient> ALTER SYSTEM CLEAR MERGE ERROR;
  Query OK, 0 rows affected
  ```

### Examples related to minor freezes

* Initiates a minor freeze for the user tenant.

  ```shell
  obclient> ALTER SYSTEM MINOR FREEZE;
  Query OK, 0 rows affected
  ```

* Initiates a partition-level minor freeze for the user tenant.

  ```shell
  obclient> ALTER SYSTEM MINOR FREEZE TABLET_ID = 5;
  Query OK, 0 rows affected
  ```
