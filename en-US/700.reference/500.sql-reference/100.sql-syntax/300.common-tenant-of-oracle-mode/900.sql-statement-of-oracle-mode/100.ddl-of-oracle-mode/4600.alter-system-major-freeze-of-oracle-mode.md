# MAJOR and MINOR

## Purpose

You can use this statement to initiate a major or minor compaction in the storage layer for a user tenant from the current tenant. You can initiate a major or minor compaction at the tenant, table, or partition level.

## Syntax

```shell
ALTER SYSTEM merge_action;

merge_action:
      MAJOR FREEZE [TABLE_ID = table_id | TABLET_ID = tablet_id]
    | MINOR FREEZE [TABLET_ID = tablet_id]
    | {SUSPEND | RESUME} MERGE
    | CLEAR MERGE ERROR
```

## Parameters

| **Parameter** | **Description** |
|---------------------------|------------------|
| MAJOR FREEZE | Initiates a major compaction. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can initiate a major compaction only for the current tenant.</p></main>        |
| MINOR FREEZE | Initiates a minor compaction.  <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can initiate a minor compaction only for the current tenant.</p></main>    |
| {SUSPEND \| RESUME} MERGE | Suspends or resumes a major compaction. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can suspend or resume a major compaction only for the current tenant.</p></main>        |
| CLEAR MERGE ERROR | Removes major compaction error tags. <main id="notice" type='explain'><h4>Note</h4><p>A user tenant can remove major compaction error tags only in the current tenant.</p></main>      |
| TABLE_ID                  | The table on which a major compaction is performed.                 |
| TABLET_ID                 | The partition on which a minor compaction is performed.          |

## Examples

### Major compaction in the storage layer

* Initiate a major compaction for a user tenant.

  ```shell
   obclient> ALTER SYSTEM MAJOR FREEZE;
   Query OK, 0 rows affected
   ```

* Initiate a major compaction at the table level for a user tenant.

  1. Query the `table_id` of the table TBL1 to be compacted.

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT DATABASE_NAME, TABLE_ID, TABLE_NAME FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_NAME = 'TBl1';
     ```

     The query result is as follows:

     ```shell
     +---------------+----------+------------+
     | DATABASE_NAME | TABLE_ID | TABLE_NAME |
     +---------------+----------+------------+
     | SYS           |   500002 | TBL1       |
     +---------------+----------+------------+
     1 row in set
     ```

  2. Execute the following command to initiate a table-level major compaction.

     ```shell
     obclient(SYS@oracle001)[SYS]> ALTER SYSTEM MAJOR FREEZE TABLE_ID = 500002;
     ``` 

* Initiate a major compaction at the partition level for a user tenant.

  1. Query the `tablet_id` of the partition to be compacted.

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT DATABASE_NAME, TABLE_ID, TABLE_NAME, TABLET_ID, PARTITION_NAME, SUBPARTITION_NAME FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_NAME = 'TBL1';
     ```

     The query result is as follows:

     ```shell
     +---------------+----------+------------+-----------+----------------+-------------------+
     | DATABASE_NAME | TABLE_ID | TABLE_NAME | TABLET_ID | PARTITION_NAME | SUBPARTITION_NAME |
     +---------------+----------+------------+-----------+----------------+-------------------+
     | SYS           |   500012 | TBL1       |    200007 | P01            | NULL              |
     | SYS           |   500012 | TBL1       |    200008 | P02            | NULL              |
     | SYS           |   500012 | TBL1       |    200009 | P03            | NULL              |
     +---------------+----------+------------+-----------+----------------+-------------------+
     3 rows in set
     ```

  2. Execute the following command to initiate a partition-level major compaction.

     ```shell
     obclient(SYS@oracle001)[SYS]> ALTER SYSTEM MAJOR FREEZE TABLET_ID = 200007;
     ```

### Suspend or resume a major compaction

* Suspend the major compaction of a user tenant.

  ```shell
   obclient> ALTER SYSTEM SUSPEND MERGE;
   Query OK, 0 rows affected
   ```

* Resume the major compaction of a user tenant.

  ```shell
   obclient> ALTER SYSTEM RESUME MERGE;
   Query OK, 0 rows affected
   ```

### Remove major compaction error tags

* Remove the major compaction error tags of a user tenant.

  ```shell
   obclient> ALTER SYSTEM CLEAR MERGE ERROR;
   Query OK, 0 rows affected
   ```

### Minor compaction in the storage layer

* Initiate a minor compaction for a user tenant.

  ```shell
   obclient> ALTER SYSTEM MINOR FREEZE;
   Query OK, 0 rows affected
   ```

* Initiate a minor compaction at the partition level for a user tenant.

  ```shell
   obclient> ALTER SYSTEM MINOR FREEZE TABLET_ID = 5;
   Query OK, 0 rows affected
   ```
