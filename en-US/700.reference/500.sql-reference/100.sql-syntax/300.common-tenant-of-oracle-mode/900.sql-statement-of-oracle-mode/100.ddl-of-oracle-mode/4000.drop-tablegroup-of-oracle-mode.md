# DROP TABLEGROUP

## Purpose

This statement is used to drop a tablegroup.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>If any table's <code>TABLEGROUP</code> attribute references the target tablegroup, the tablegroup cannot be dropped.</p>
  </main>

## Privilege requirements

To execute `DROP TABLEGROUP`, you need the following privileges:

- You need the `DROP` privilege to drop a tablegroup.
- If the tablegroup contains tables, you need the `ALTER` privilege on those tables to modify their tablegroup attribute.

## Considerations

- Dropping a tablegroup does not delete the tables within it, but it removes the association between the tables and the tablegroup.
- Before dropping a tablegroup, ensure that no business processes depend on it.

## Syntax

```sql
DROP TABLEGROUP tablegroup_name
```

## Parameters

|       Parameter        |     Description      |
|-----------------|-------------|
| tablegroup_name | The name of the tablegroup to be dropped. |

## Examples

### Example 1: Drop a referenced tablegroup

When a tablegroup is referenced by tables through the `TABLEGROUP` attribute, you need to remove these references before dropping the tablegroup.

1. Attempting to drop a non-empty tablegroup will result in an error:

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ```

   Expected return result:

   ```sql
   OBE-00600: internal error code, arguments: -4615, tablegroup is not empty
   ```

2. View the tables in the `tblgroup1` tablegroup:

   ```sql
   obclient> SHOW TABLEGROUPS;
   obclient> SHOW TABLES IN tblgroup1;
   ```

3. Remove the `tbl1` table from the `tblgroup1` tablegroup:

   ```sql
   obclient> ALTER TABLE tbl1 SET TABLEGROUP = '';
   ```

4. Drop the `tblgroup1` tablegroup again:

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ```

### Example 2: Complete tablegroup usage process

1. Create a tablegroup:

   ```sql
   obclient> CREATE TABLEGROUP tg1;
   ```

2. Create a table and specify the tablegroup:

   ```sql
   obclient> CREATE TABLE t1 (id INT) TABLEGROUP = tg1;
   ```

3. View the tablegroup information:

   ```sql
   obclient> SHOW TABLEGROUPS;
   ```

4. Remove the `t1` table from the `tg1` tablegroup:

   ```sql
   obclient> ALTER TABLE t1 SET TABLEGROUP = '';
   ```

5. Drop the `tg1` tablegroup:

   ```sql
   obclient> DROP TABLEGROUP tg1;
   ```
