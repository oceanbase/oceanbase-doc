# DROP LOCATION

## Purpose

This statement is used to drop a location object.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For OceanBase Database V4.4.x, the <code>DROP LOCATION</code> statement is supported starting from V4.4.1. </p>
</main>

## Privilege requirements

To execute the `DROP LOCATION` statement, the current user must have the `CREATE LOCATION` privilege. For more information about privileges in OceanBase Database, see [Privilege classification in Oracle-compatible mode](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
DROP LOCATION location_name;
```

## Parameters

|   **Parameter**    | **Description** |
|---------------|----------|
| location_name | The name of the location object to be dropped. |

## Examples

Drop the location object `test_location_local`.

```shell
obclient> DROP LOCATION test_location_local;
```
