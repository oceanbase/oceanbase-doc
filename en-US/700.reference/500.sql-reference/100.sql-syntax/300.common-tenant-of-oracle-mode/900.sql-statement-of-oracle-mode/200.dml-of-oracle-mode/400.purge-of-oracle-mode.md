# PURGE

## Purpose

This statement is used to delete tables, indexes, or all content from the recycle bin.

## Syntax

```sql
PURGE  { {TABLE object_name | INDEX object_name }
| RECYCLEBIN
}
```

## Parameters

|     Parameter      | Description  |
|-------------|-----------------|
| object_name | The name of the table or index to be deleted in the recycle bin. Directly specifying the table or index name is not supported. <br>**Note**  <ul><li> When you directly drop an index, it will not be moved to the recycle bin.   </li><li> When you directly drop a table that contains an index, both the table and the index will be moved to the recycle bin. When you drop a table from the recycle bin, the associated indexes will also be deleted. </li></ul>    |
| RECYCLEBIN  | Clears the recycle bin. <br>**Note**  `PURGE RECYCLEBIN` will delete all content in the recycle bin. Please proceed with caution. |

## Examples

The following example creates a table and inserts data:

```sql
obclient> CREATE TABLE tbl1(col1 INT,col2 INT);
obclient> CREATE TABLE tbl2(col1 INT,col2 INT);
obclient> CREATE INDEX tbl1_idx1 ON tbl1(col1);
obclient> CREATE INDEX tbl2_idx2 ON tbl2(col1);
obclient> DROP TABLE tbl1;
obclient> DROP TABLE tbl2;
obclient> SHOW RECYCLEBIN;
```
