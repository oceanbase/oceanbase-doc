# STOP ROUTINE LOAD

This statement is used to stop a Routine Load task, which cannot be resumed.

## Syntax

```sql
STOP ROUTINE LOAD FOR job_name;
```

## Parameters

| **Parameter** |       **Description**           |
|----------|--------------------------|
| job_name | The name of the Routine Load task to be stopped.|

## Examples

Stop the Routine Load task `load_job_0`.

```shell
obclient> STOP ROUTINE LOAD FOR load_job_0;
```
