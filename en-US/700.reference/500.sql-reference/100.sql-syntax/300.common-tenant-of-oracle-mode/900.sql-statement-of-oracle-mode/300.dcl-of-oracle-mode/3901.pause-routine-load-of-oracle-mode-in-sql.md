# PAUSE ROUTINE LOAD

## Syntax

```sql
PAUSE ROUTINE LOAD FOR job_name;
```

## Parameters

| **Parameter** |       **Description**           |
|----------|--------------------------|
| job_name | The name of the Routine Load job to be paused. |

## Examples

Pause the Routine Load job `load_job_0`.

```shell
obclient> PAUSE ROUTINE LOAD FOR load_job_0;
```
