# FLASHBACK TABLE BEFORE DROP

## Purpose

You can use this statement to restore a dropped table from the recycle bin.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>Tables in the recycle bin are not actually deleted and still occupy resources. To permanently delete the contents of the recycle bin, execute the SQL statement <code>PURGE RECYCLEBIN;</code>. </li>
    <li>A dropped table is moved to the recycle bin only if the recycle bin is enabled.
    <ul>
    <li>You can execute the SQL statement <code>SHOW VARIABLES LIKE 'recyclebin';</code> to check whether the recycle bin is enabled. </li>
    <li>You can execute the SQL statement <code>SET RECYCLEBIN = ON;</code> to enable the recycle bin. </li>
    </ul>
    </li>
    </ul>
  </main>

## Syntax

```sql
FLASHBACK TABLE [schema.]table_name [, [schema.]table_name]...
TO BEFORE DROP
[RENAME TO [schema.]new_table_name]
```

## Parameters

|      Parameter       | Description         |
|---------------|-------------|
| table_name | the name of the table to be restored. <br>**Note**  When you restore a table, the indexes associated with the table are also restored. |
| RENAME TO     | the new name and schema of the table. If you omit `RENAME TO database_name.table_name`, the restored table retains its original name. |

## Examples

* Restore the dropped table `tbl1` from the recycle bin.

  **View the contents of the recycle bin.**

  ```sql
  obclient> SHOW RECYCLEBIN;
  ```

  **Return result**

  ```sql
  +-----------------------------------+---------------+-------+------------------------------+
  | OBJECT_NAME                       | ORIGINAL_NAME | TYPE  | CREATETIME                   |
  +-----------------------------------+---------------+-------+------------------------------+
  | RECYCLE_$_100004_1634807168766392 | TBL1          | TABLE | 21-OCT-21 05.06.08.767109 PM |
  | RECYCLE_$_100004_1634807177792816 | TBL2          | TABLE | 21-OCT-21 05.06.17.791967 PM |
  +-----------------------------------+---------------+-------+------------------------------+
  2 rows in set (0.00 sec)
  ```

  **Execute the restore operation.**

  ```sql
  obclient> FLASHBACK TABLE tbl1 TO BEFORE DROP;
  ```

  **Verify the restore result.**

  ```sql
  obclient> SELECT * FROM tbl1;
  ```

  **Return result**

  ```sql
  +------+------+
  | COL1 | COL2 |
  +------+------+
  |    1 |    1 |
  +------+------+
  1 row in set
  ```

* Restore the dropped table `tbl2` to the `user1` schema and rename it to `tbl_test`.

  **View the contents of the recycle bin.**

  ```sql
  obclient> SHOW RECYCLEBIN;
  ```

  **Return result**

  ```sql
  +-----------------------------------+---------------+-------+------------------------------+
  | OBJECT_NAME                       | ORIGINAL_NAME | TYPE  | CREATETIME                   |
  +-----------------------------------+---------------+-------+------------------------------+
  | RECYCLE_$_100004_1634807168766392 | TBL1          | TABLE | 21-OCT-21 05.06.08.767109 PM |
  | RECYCLE_$_100004_1634807177792816 | TBL2          | TABLE | 21-OCT-21 05.06.17.791967 PM |
  +-----------------------------------+---------------+-------+------------------------------+
  2 rows in set (0.00 sec)
  ```

  **Execute the restore and rename operation.**

  ```sql
  obclient> FLASHBACK TABLE tbl2 TO BEFORE DROP RENAME TO user1.tbl_test;
  ```

  **Verify the restore result.**

  ```sql
  obclient> SELECT * FROM user1.tbl_test;
  ```

  **Return result**

  ```sql
  +------+------+
  | COL1 | COL2 |
  +------+------+
  |    1 |    1 |
  +------+------+
  1 row in set
  ```

## Considerations

To use the FLASHBACK TABLE statement, you must enable the recycle bin. For more information, see [Recycle bin](../../../../../100.oceanbase-database-concepts/1000.high-data-reliability-and-availability/400.data-protection/400.recycle-bin.md).
