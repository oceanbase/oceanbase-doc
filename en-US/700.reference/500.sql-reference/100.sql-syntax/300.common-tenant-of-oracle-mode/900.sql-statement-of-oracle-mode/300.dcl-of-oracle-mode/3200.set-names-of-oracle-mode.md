# SET NAMES

## Purpose

This statement is used to set the character set and collation for the current session.

## Syntax

```sql
SET NAMES 'charset_name' [COLLATE 'collation_name']
```

## Parameters

|       Parameter       |                Description                |
|----------------|----------------------------------|
| charset_name   | Specifies the character set.                           |
| collation_name | Specifies the collation for the character set. If not specified, the default collation for the character set is used. |

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can use <code>SHOW CHARSET;</code> to query the supported character sets and <code>SHOW COLLATION;</code> to query the supported collations. </p>
  </main>

## Examples

* Set the character set for the current session to `gbk` with the default collation.

  ```sql
  obclient> SET NAMES 'gbk';

  obclient> SHOW VARIABLES LIKE 'character_set_c%';

  obclient> SHOW VARIABLES LIKE 'collation_connection';
  ```

* Set the character set for the current session to `utf8mb4` with the `utf8mb4_general_ci` collation.

  ```sql
  obclient> SET NAMES 'utf8mb4' COLLATE 'utf8mb4_general_ci';

  obclient> SHOW VARIABLES LIKE 'character_set_c%';

  obclient> SHOW VARIABLES LIKE 'collation_connection';
  ```
