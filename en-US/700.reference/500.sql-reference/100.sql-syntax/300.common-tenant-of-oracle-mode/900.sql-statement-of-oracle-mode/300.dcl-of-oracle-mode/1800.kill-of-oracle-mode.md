# KILL

## Purpose

This statement is used to terminate a session.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>In Oracle mode, a regular user can only view and terminate their own sessions. A tenant administrator can view and terminate all sessions. If a regular user has the <code>SHOW PROCESS</code> privilege, they can view all sessions.</p>
  </main>

## Syntax

```sql
KILL [CONNECTION | QUERY] 'session_id'
```

## Parameters

|       Parameter      |    Description    |
|-----------------|----------------------|
| KILL CONNECTION | Same as the `KILL` statement without modifiers, it terminates the specified Client Session ID. |
| KILL QUERY      | Terminates the current statement being executed, but keeps the session connected.    |
| session_id      | The Client Session ID of the current session, which uniquely identifies the session on the client. You can query it using the `SHOW PROCESSLIST` or `SHOW FULL PROCESSLIST` command.|

## Examples

Query the connected sessions and terminate the session.

```sql
obclient> SHOW PROCESSLIST;
```

Expected return result:

```sql
+------------+------+----------------------+------+---------+------+--------+------------------+
| ID         | USER | HOST                 | DB   | COMMAND | TIME | STATE  | INFO             |
+------------+------+----------------------+------+---------+------+--------+------------------+
| 3221849635 | SYS  | 10.10.10.10:49142 | SYS  | Sleep   |  426 | SLEEP  | NULL             |
| 3221656012 | SYS  | 10.10.10.10:57140 | SYS  | Sleep   |  426 | SLEEP  | NULL             |
| 3221671483 | SYS  | 10.10.10.10:43154 | SYS  | Query   |    0 | ACTIVE | show processlist |
+------------+------+----------------------+------+---------+------+--------+------------------+
3 rows in set
```

Terminate the session:

```sql
obclient> KILL 3221849635;

obclient> KILL QUERY 3221656012;

obclient> KILL CONNECTION 3221671483;
```
