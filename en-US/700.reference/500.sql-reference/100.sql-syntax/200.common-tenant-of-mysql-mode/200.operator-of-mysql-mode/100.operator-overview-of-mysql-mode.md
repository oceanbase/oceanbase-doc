# Overview of operators

Operators are generally used to connect individual data items such as operands or parameters and return results. In terms of syntax, operators can appear before, after, or between operands.

Common operators can be further classified into unary and binary operators:

* Unary operators

  Unary operators operate on a single operand. The common format of a unary operator is as follows:

  ```sql
  Operator operand
  ```

* Binary operators

  Binary operators operate on two operands. The common format of a binary operator is as follows:

  ```sql
  Operand1 operator Operand2
  ```

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>Other operators with special formats can accept more than two operands.</li>
    <li>If an operator is provided with a <code>NULL</code> operand, the result is always <code>NULL</code>. The only exception is the character concatenation operator (||).</li>
    </ul>
  </main>
