# Overview

A pseudocolumn behaves like a column in a table, but it does not store specific values. Therefore, pseudocolumns have only read attributes, and you cannot insert, update, or delete values in pseudocolumns. This topic describes the pseudocolumns supported in OceanBase Database.

OceanBase Database in MySQL-compatible mode supports the following pseudocolumns:

* [PARTITIONID pseudocolumn](200.partititionid-pseudo-column-of-mysql-mode.md)
* [Sequence pseudocolumn](300.sequence-pseudo-column-of-mysql-mode.md)
