# Overview

A pseudocolumn behaves like a column in a table but does not store specific values. Therefore, pseudocolumns have only read attributes and cannot be inserted, updated, or deleted. This topic describes the pseudocolumns supported by OceanBase Database in the current version.

OceanBase Database in MySQL mode supports the following pseudocolumns:

* [PARTITIONID pseudocolumn](200.partititionid-pseudo-column-of-mysql-mode.md)
* [Sequence pseudocolumn](300.sequence-pseudo-column-of-mysql-mode.md)
