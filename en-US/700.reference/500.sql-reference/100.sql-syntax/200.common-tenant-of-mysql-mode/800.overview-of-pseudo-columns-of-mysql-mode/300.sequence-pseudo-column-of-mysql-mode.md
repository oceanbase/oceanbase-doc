# Sequence pseudo-column

A sequence is a set of incrementing numbers generated in a database according to a certain rule. It is typically a set of equally spaced numbers of the numeric type. Because of the incremental nature of sequences, they are commonly used as primary keys and unique keys.

## How to obtain the value of a sequence

You can use the `CURRVAL` and `NEXTVAL` pseudo-columns to obtain the current value and the next value of a sequence, respectively.

* `CURRVAL`: returns the current value of the sequence.

* `NEXTVAL`: returns the next value of the sequence.

When you use a sequence, you must specify the sequence name before `CURRVAL` and `NEXTVAL` and use a period (.) to reference the sequence.

For example, if the sequence name is `SEQ_FOO`, you can use `SEQ_FOO.CURRVAL` to obtain the current value of `SEQ_FOO`. Similarly, you can use `SEQ_FOO.NEXTVAL` to obtain the next value of `SEQ_FOO`.

## Limitations on the use of sequences

* You cannot use sequences with statements such as `HAVING`, `ORDER BY`, and `GROUP BY`.
* Sequences cannot appear in subqueries, except for `INSERT INTO SELECT` statements.
* Sequences cannot appear in `WHERE` expressions.

## Use of sequences

You can use the values of the `CURRVAL` and `NEXTVAL` pseudo-columns in the following locations:

* In the select list of a top-level `SELECT` statement.

* In the `VALUE` clause of an `INSERT` statement.

* In the `SET` clause of an `UPDATE` statement.

Here is an example of a query that retrieves the value of a sequence:

```sql
SELECT SEQUENCE_NAME.NEXTVAL FROM DUAL;      /*The sequence number increases every time it is executed.*/

SELECT SEQUENCE_NAME.CURRVAL FROM DUAL;     /*The sequence number does not change after it is executed. */
```

When you create a sequence, you must specify its initial value and increment. The first time you reference `NEXTVAL`, it returns the initial value of the sequence. Subsequent references to `NEXTVAL` return a new value by adding the defined increment to the previous value returned by the sequence. Any reference to `CURRVAL` returns the current value of the sequence, which is the value returned by the last reference to `NEXTVAL`.

Before you reference the `CURRVAL` pseudo-column of a sequence in a session, you must first apply the `NEXTVAL` pseudo-column of the sequence to initialize the sequence value for the session.

When you create a sequence, you can specify its initial value and the increment between values. The first time you reference `NEXTVAL`, it returns the initial value of the sequence. Subsequent references to `NEXTVAL` return a new value by adding the defined increment to the previous value returned by the sequence. Any reference to `CURRVAL` returns the current value of the sequence, which is the value returned by the last reference to `NEXTVAL`. For more information about how to create and drop a sequence, see [CREATE SEQUENCE](../../200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2500.create-sequence-of-mysql-mode.md) and [DROP SEQUENCE](../../200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/3900.drop-sequence-of-mysql-mode.md).

## Examples

```sql
obclient> CREATE SEQUENCE s1 START WITH 95 INCREMENT BY 1 NOORDER CACHE 10000;
Query OK, 0 rows affected

obclient> CREATE TABLE tbl1 (i INT,j INT);
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES(1,70),(2,71),(3,3),(4,4);
4 rows affected

obclient> SELECT * FROM tbl1;
+---+------+
| I | J    |
+---+------+
| 1 |   70 |
| 2 |   71 |
| 3 |    3 |
| 4 |    4 |
+---+------+
4 rows in set

obclient> SELECT s1.nextval, i, j FROM tbl1;
+------------+---+------+
| S1.NEXTVAL | I | J    |
+------------+---+------+
|         95 | 1 |   70 |
|         96 | 2 |   71 |
|         97 | 3 |    3 |
|         98 | 4 |    4 |
+------------+---+------+
4 rows in set

obclient> SELECT s1.nextval, i, j FROM tbl1;
+------------+---+------+
| S1.NEXTVAL | I | J    |
+------------+---+------+
|        99  | 1 |   70 |
|        100 | 2 |   71 |
|        101 | 3 |    3 |
|        102 | 4 |    4 |
+------------+---+------+
4 rows in set

obclient> UPDATE tbl1 SET i = s1.nextval;
Query OK, 4 rows affected
Rows matched: 4  Changed: 4  Warnings: 0

obclient> SELECT * FROM tbl1;
+-----+------+
| I   | J    |
+-----+------+
| 103 |   70 |
| 104 |   71 |
| 105 |    3 |
| 106 |    4 |
+-----+------+
4 rows in set

obclient> SELECT s1.currval FROM DUAL;
+---------+
| currval |
+---------+
| 106     |
+---------+
1 row in set
```
