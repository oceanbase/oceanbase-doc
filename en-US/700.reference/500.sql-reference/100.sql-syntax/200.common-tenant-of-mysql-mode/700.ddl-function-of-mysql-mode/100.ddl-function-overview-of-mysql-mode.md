# Overview of DDL operations

DDL operations in OceanBase Database are used to modify database objects.

The following DDL operations are supported in OceanBase Database in MySQL mode:

* Index operations
* Primary key operations
* Column operations
* Generated column operations
* Foreign key operations
* Table operations
* Partitioning operations
