# Create an array column

OceanBase Database allows you to create an array column by using the `CREATE TABLE` statement.

## Considerations

* You cannot set a default value for an array column.

* For information about the supported array types, see [Overview of array element types](100.array-data-type-overview-of-mysql-mode.md).

## Examples

You can use the `CREATE TABLE` statement to create a table with an array column. Here is the syntax:

```sql
CREATE TABLE t1(
    c1 ARRAY(INT),
    c2 ARRAY(VARCHAR(256)),
    c3 ARRAY(BIGINT),
    c4 ARRAY(TINYINT),
    c5 ARRAY(FLOAT),
    c6 ARRAY(DOUBLE),
    c7 ARRAY(SMALLINT));
```

```sql
CREATE TABLE t2(
    c1 INT[],
    c2 VARCHAR(256)[],
    c3 BIGINT[],
    c4 TINYINT[],
    c5 FLOAT[],
    c6 DOUBLE[],
    c7 SMALLINT[]);
```

```sql
CREATE TABLE t3(
    c1 ARRAY<INT>,
    c2 ARRAY<VARCHAR(256)>,
    c3 ARRAY<BIGINT>,
    c4 ARRAY<TINYINT>,
    c5 ARRAY<FLOAT>,
    c6 ARRAY<DOUBLE>,
    c7 ARRAY<SMALLINT>);
```

Here is an example of defining a nested array:

```sql
CREATE TABLE t4(c1 ARRAY(ARRAY(INT)));
CREATE TABLE t5(c1 INT[][]);
CREATE TABLE t6(c1 ARRAY<ARRAY<INT>>);
```

OceanBase Database supports up to six levels of array nesting. Here is an example:

```sql
CREATE TABLE t7 (c1 INT[][][][][][]);

DESC t7;
+-------+-----------------------------------------------+------+-----+---------+-------+
| Field | Type                                          | Null | Key | Default | Extra |
+-------+-----------------------------------------------+------+-----+---------+-------+
| c1    | ARRAY(ARRAY(ARRAY(ARRAY(ARRAY(ARRAY(INT)))))) | YES  |     | NULL    |       |
+-------+-----------------------------------------------+------+-----+---------+-------+
1 row in set
```

Here are examples of writing and querying array data.

Create a test table named t8:

```shell
obclient> CREATE TABLE t8(
    c1 ARRAY(INT),
    c2 ARRAY(VARCHAR(256)),
    c3 ARRAY(BIGINT)
);
```

The return result is as follows:

```shell
obclient> DESC t8;
+-------+---------------------+------+------+---------+-------+
| Field | Type                | Null | Key  | Default | Extra |
+-------+---------------------+------+------+---------+-------+
| c1    | ARRAY(INT)          | YES  |      | NULL    |       |
| c2    | ARRAY(VARCHAR(256)) | YES  |      | NULL    |       |
| c3    | ARRAY(BIGINT)       | YES  |      | NULL    |       |
+-------+---------------------+------+------+---------+-------+
3 rows in set
```

Insert data:

```shell
// Construct an array object by using an array function.
obclient> INSERT INTO t8 VALUES (ARRAY(1,2), ARRAY(1,2), ARRAY(1,2));
// Construct an array object by using [].
obclient> INSERT INTO t8 VALUES ([1,2], [1,2], [1,2]);
// Write array data by using a formatted string.
obclient> INSERT INTO t8 VALUES ("[1,2]", "[1,2]", "[1,2]");
```

Query the test table. The result is as follows:

```shell
obclient> SELECT * FROM t8;
+-------+-----------+-------+
| c1    | c2        | c3    |
+-------+-----------+-------+
| [1,2] | ["1","2"] | [1,2] |
| [1,2] | ["1","2"] | [1,2] |
| [1,2] | ["1","2"] | [1,2] |
+-------+-----------+-------+
3 rows in set
```
