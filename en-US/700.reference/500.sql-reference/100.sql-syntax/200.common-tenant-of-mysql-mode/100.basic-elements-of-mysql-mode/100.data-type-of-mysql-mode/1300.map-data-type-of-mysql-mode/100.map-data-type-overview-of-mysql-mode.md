# Overview of mapped data types

OceanBase Database supports the MAP data type, which is used to store unordered key-value pairs. A MAP data type consists of keys and corresponding values. This data type allows you to easily manage unordered key-value pairs, such as `{a:1, b:2, c:3}`, which is very useful for scenarios such as saving configuration options, user attributes, and product information.

At present, MAP supports only DDL and DML operations for mapping data. You can build mappings in the following ways: by using mapping expressions or strings. In addition, the `map_keys` and `map_values` expressions are provided to facilitate data processing and analysis by extracting arrays of keys or values from mappings.

The following table describes the element types that are supported by the Key data type in the current version of OceanBase Database.

* Integer types: `TINYINT`, `SMALLINT`, `INT` or `INTEGER`, and `BIGINT`. The `UNSIGNED` modifier is supported.
* Floating-point types: `FLOAT` and `DOUBLE`.
* Character string type: `VARCHAR`.

The following elements are supported by the Value attribute:

* Integer types: `TINYINT`, `SMALLINT`, `INT` or `INTEGER`, and `BIGINT`. The `UNSIGNED` modifier is supported.
* Floating-point types: `FLOAT` and `DOUBLE`.
* Character string type: `VARCHAR`.
* Array type: `ARRAY`.

The following limitations apply:

* The comparison operators `<`, `>`, `>=`, and `<=` are not supported.
* Does not support the `ORDER BY`, `GROUP BY`, `MIN`, `MAX`, `AVG`, and `SUM` aggregate operations.
* The value of the nested array cannot exceed 6 levels.

In addition to mapping data types, functions are also provided for mapping data. For more information, see [Mapping functions](../../../400.functions-of-mysql-mode/980.map-functions-of-mysql-mode/100.map-functions-overview-of-mysql-mode.md).
