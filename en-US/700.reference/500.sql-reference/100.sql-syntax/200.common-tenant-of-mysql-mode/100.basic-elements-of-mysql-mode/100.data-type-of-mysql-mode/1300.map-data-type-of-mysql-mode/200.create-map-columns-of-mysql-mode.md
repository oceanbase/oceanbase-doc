# Create a mapped column

OceanBase Database allows you to create a mapped column by using the `CREATE TABLE` statement.

## Considerations

* Default values cannot be set.
* For information about supported mapped types and limitations, see [Overview of mapped data types](100.map-data-type-overview-of-mysql-mode.md).

## Examples

Here are some examples of creating a table by using the `CREATE TABLE` statement, with a mapped column.

```sql
CREATE TABLE t1 (
  id INT, 
  c1 MAP(INT, FLOAT), 
  c2 MAP(VARCHAR(10), VARCHAR(2)), 
  c3 MAP(FLOAT UNSIGNED, ARRAY(INT)), 
  c4 MAP(VARCHAR(3), ARRAY(ARRAY(VARCHAR(20))))
);
```

The following example shows how to define a mapped type whose value is a nested array:

```sql
CREATE TABLE t2(c1 MAP(INT, ARRAY(INT)));
CREATE TABLE t3(c1 MAP(INT, INT[][]));
```

The value of a MAP can contain up to 6 nested levels. Example:

```sql
CREATE TABLE t4 (c1 MAP(INT, INT[][][][][]));

DESC t4;
+-------+-------------------------------------------------+------+------+---------+-------+
| Field | Type                                            | Null | Key  | Default | Extra |
+-------+-------------------------------------------------+------+------+---------+-------+
| c1    | MAP(INT,ARRAY(ARRAY(ARRAY(ARRAY(ARRAY(INT)))))) | YES  |      | NULL    |       |
+-------+-------------------------------------------------+------+------+---------+-------+
1 row in set
```

The following examples show how to write data and query mapped data.

First, create a test table named t5:

```shell
obclient> CREATE TABLE t5(
    c1 MAP(INT, INT), 
    c2 MAP(VARCHAR(256), VARCHAR(256)), 
    c3 MAP(BIGINT, BIGINT)
);
```

The return result is as follows:

```shell
obclient> DESC t5;
+-------+--------------------------------+------+------+---------+-------+
| Field | Type                           | Null | Key  | Default | Extra |
+-------+--------------------------------+------+------+---------+-------+
| c1    | MAP(INT,INT)                   | YES  |      | NULL    |       |
| c2    | MAP(VARCHAR(256),VARCHAR(256)) | YES  |      | NULL    |       |
| c3    | MAP(BIGINT,BIGINT)             | YES  |      | NULL    |       |
+-------+--------------------------------+------+------+---------+-------+
3 rows in set
```

Then, insert data into the table:

```shell
obclient> INSERT INTO t5 VALUES (MAP(1,2), MAP(1,2), MAP(1,2));
```

Finally, query data from the test table. The result is as follows:

```shell
obclient> SELECT * FROM t5;
+-------+-----------+-------+
| c1    | c2        | c3    |
+-------+-----------+-------+
| {1:2} | {"1":"2"} | {1:2} |
+-------+-----------+-------+
1 row in set
```
