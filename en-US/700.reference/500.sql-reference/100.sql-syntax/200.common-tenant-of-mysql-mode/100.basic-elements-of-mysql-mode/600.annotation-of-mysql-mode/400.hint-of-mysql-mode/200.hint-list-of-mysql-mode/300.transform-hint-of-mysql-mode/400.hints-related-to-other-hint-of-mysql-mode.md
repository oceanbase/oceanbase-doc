# Other hints in the Transform Hint category

| Hint type     | Description                                           |
|----------------|----------------------------------------------|
| `DECORRELATE`  | Enables lateral query rewrite for de-correlation. The inverse operation is `NO_DECORRELATE`.               |
| `NO_DECORRELATE` | Disable query rewriting for lateral tables. Its opposite is `DECORRELATE`.           |

## `DECORRELATE` Hint

The `DECORRELATE` hint is used to enable query rewriting for lateral tables in a query by decorrelating correlated subqueries. This means converting correlated subqueries that depend on the outer query into independent queries or uncorrelated subqueries.

The reverse of `DECORRELATE` Hint is the `NO_DECORRELATE` Hint, which is used to disable query rewriting for lateral tables.

### Syntax

```sql
/*+ DECORRELATE [ ( [ @ qb_name ] ) ] */
```

#### Parameters

- `@qb_name`: Optional. Specifies the name of the query block to be deassociated from the rewritten query.

### Examples

In the following query example, the `DECORRELATE` hint is used to enable query rewriting to decorrelate lateral tables in the query.

```sql
The `NO_MERGE` hint is used with `DECORRELATE` to ensure that the subquery will not be merged with the outer query, and explicitly requests the optimizer to decorrelate the subquery.
SELECT *
FROM t1, LATERAL (SELECT /*+ NO_MERGE DECORRELATE */ *
                  FROM t2
                  WHERE t2.c2 = t1.c1) v
WHERE v.c1 = 1;
```

## `NO_DECORRELATE` Hint

The `NO_DECORRELATE` hint disables decorrelation of lateral tables.

### Syntax

```sql
/*+ NO_DECORRELATE [ ( [ @ qb_name ] ) ] */
```

#### Parameters

- `@qb_name`: Optional. The name of the query block whose query rewrite is to be suppressed.

### Examples

In the following query examples, the `NO_DECORRELATE` hint is used to disable query decorrelation for lateral tables.

```sql
-- Use the `NO_MERGE` hint with `NO_DECORRELATE` to ensure that the optimizer does not merge subqueries into outer queries, nor does it rewrite the de-correlated queries.
SELECT *
FROM t1, LATERAL (SELECT /*+ NO_MERGE NO_DECORRELATE */ *
                  FROM t2
                  WHERE t2.c2 = t1.c1) v
WHERE v.c1 = 1;
```
