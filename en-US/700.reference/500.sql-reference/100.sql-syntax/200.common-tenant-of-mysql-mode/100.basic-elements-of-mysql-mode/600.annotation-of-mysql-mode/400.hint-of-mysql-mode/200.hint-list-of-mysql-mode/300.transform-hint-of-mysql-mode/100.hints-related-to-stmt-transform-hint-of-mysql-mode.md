# Stmt Transform Hint

Stmt Transform Hint allows you to control specific query transformation operations in an SQL query.

| Hint Type      | Description                               |
|----------------|----------------------------------|
| `NO_REWRITE`   | Prevents any form of query rewriting.       |

## `NO_REWRITE` Hint

The `NO_REWRITE` hint prevents query rewriting in the query. After using this hint, the affected query block will not participate in any query rewriting operations.

### Syntax

```sql
/*+ NO_REWRITE [ ( [ @ qb_name ] ) ] */
```

#### Parameters

- `@qb_name`: Optional. Specifies the name of the query block to which the `NO_REWRITE` attribute is applied. If you do not specify a query block name, the hint applies to the entire SQL statement.

### Examples

```sql
-- In the following query, the NO_REWRITE hint is added to prevent view merging.
SELECT /*+ NO_REWRITE */ * FROM (SELECT * FROM t1);
```

Although the `NO_REWRITE` hint prevents query rewriting, you can use other query rewriting hints to allow specific types of query rewriting. For example, using the `MERGE` hint in an inner query block can force view merging, even if the outer query block uses the `NO_REWRITE` hint.

```sql
-- The outer query uses the NO_REWRITE hint, so no automatic rewriting is performed.
SELECT /*+ NO_REWRITE */
    *
FROM
    (SELECT /*+ MERGE */ * FROM t1) -- The inner query uses the MERGE hint to force view merging.
WHERE
    t1.column1 = 'somevalue';
```
