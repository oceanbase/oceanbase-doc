# DROP SERVER

## Purpose

You can use this statement to drop a server definition.

## Syntax

```sql
DROP SERVER [ IF EXISTS ] server_name
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Only the keyword syntax is supported. The functionality does not actually take effect. </p>
</main>
