# STOP ROUTINE LOAD

## Purpose

This statement is used to stop a Routine Load task, which cannot be resumed.

## Syntax

```sql
STOP ROUTINE LOAD FOR job_name;
```

## Parameters

| **Parameter** |       **Description**           |
|----------|--------------------------|
| job_name | The name of the Routine Load task to stop.|

## Examples

Stop the Routine Load job `load_job_0`.

```shell
obclient> STOP ROUTINE LOAD FOR load_job_0;
```
