# DROP TABLE

## Purpose

This statement is used to drop a table in OceanBase Database.

## Syntax

```sql
DROP {TABLE | TABLES} [TEMPORARY] [IF EXISTS]
table_name [,table_name]...
[RESTRICT | CASCADE]
```

## Parameters

|       **Parameter**        |                                             **Description**                                             |
|---------------------|------------------------------------------------------------------------------------------------|
| table_name          | The name of the table to be dropped. When dropping multiple tables, separate the table names with commas.                                                                      |
| TEMPORARY           | Indicates that a temporary table is to be dropped. <main id="notice" type='explain'><h4>Note</h4><p><ul><li>Starting from OceanBase Database V4.1.0 BP4, the temporary table feature is disabled in MySQL mode. </li><li>Starting from OceanBase Database V4.3.5 BP4, the temporary table feature is supported in MySQL mode. </li></p></main>|
| IF EXISTS           | If you specify `IF EXISTS`, an error is not returned when the table to be dropped does not exist. If you do not specify this option, an error is returned.                                                  |
| RESTRICT \| CASCADE | Used in scenarios where tables are migrated from other databases to OceanBase Database. <br>**Note** This parameter is not supported in the current version. If specified, it will be parsed and ignored. </br> |

## Examples

* Specify `IF EXISTS` to drop the `test1` table.

  ```sql
  obclient> DROP TABLE IF EXISTS test1;
  Query OK, 0 rows affected
  ```

* Specify `IF EXISTS` to drop the `test1` and `test2` tables.

  ```sql
  obclient> DROP TABLES IF EXISTS test1,test2;
  Query OK, 0 rows affected
  ```

* Do not specify `IF EXISTS`. If any of the tables to be dropped does not exist, an error is returned.

  ```sql
  obclient> DROP TABLES test1,test2;
  ERROR 1051 (42S02): Unknown table 'test.test2'
  ```

* Drop the temporary table `tset3`.

  ```sql
  obclient> DROP TEMPORARY TABLE test3;
  Query OK, 0 rows affected
  ```
