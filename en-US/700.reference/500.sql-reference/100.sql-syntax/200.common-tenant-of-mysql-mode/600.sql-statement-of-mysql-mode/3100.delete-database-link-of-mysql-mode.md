# DROP DATABASE LINK

## Purpose

This statement is used to drop a database link (i.e., `dblink`).

<main id="notice" >
   <h4>Applicability</h4>
   <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support the <code>dblink</code> feature. </p>
</main>

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>To drop a database link, you must have the <code>DROP DATABASE LINK</code> system privilege. </p>
</main>

## Syntax

```sql
DROP DATABASE LINK [IF EXISTS] dblink_name;
```

## Parameters

`dblink_name` specifies the name of the database link to be dropped.

## Examples

```sql
obclient> DROP DATABASE LINK IF EXISTS ob_dblink;
Query OK, 1 row affected
```
