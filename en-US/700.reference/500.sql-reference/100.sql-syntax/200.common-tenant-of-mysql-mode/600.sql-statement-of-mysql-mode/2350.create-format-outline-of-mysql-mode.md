# CREATE FORMAT OUTLINE

## Purpose

This statement is used to create a fuzzy outline. You can create a fuzzy outline in two ways: one is by using `FORMAT_SQL_TEXT` (the original statement with parameters executed by the user), and the other is by using `FORMAT_SQL_ID`.

## Limitations and considerations

* You must execute the statement under the corresponding user.

* When `FORMAT_SQL_ID` is the same, the outline created by using `FORMAT_SQL_TEXT` will overwrite the outline created by using `FORMAT_SQL_ID`. The outline created by using `FORMAT_SQL_TEXT` has higher priority. In addition, OceanBase Database distinguishes different SQL statements by using `FORMAT_SQL_ID`, which is obtained by encrypting the `FORMAT_SQL_TEXT` with the `MD5` algorithm. In a production system, it is recommended to bind an outline by using `FORMAT_SQL_ID`.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><ul><li>The matching rules of <code>FORMAT_SQL_TEXT</code> ignore differences in parameter content, case, and non-syntactic symbols such as spaces and line breaks, and only compare the processed text content. </li><li><code>FORMAT_SQL_ID</code> is generated by first formatting <code>FORMAT_SQL_TEXT</code> (removing extra spaces and line breaks, and converting all characters to uppercase or lowercase), and then applying the <code>MD5</code> hash encryption to the formatted result. </li></ul></p>
  </main>

## Syntax

```sql
/* Create an outline by using FORMAT_SQL_TEXT */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_stmt [ TO format_target_stmt ]

/* Create an outline by using FORMAT_SQL_ID */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_sql_id USING HINT hint;
```

## Parameters

|        Parameter          |            Description             |
|----------------------|----------------------------|
| outline_name         | The name of the fuzzy outline to be created.|
| OR REPLACE           | If you specify `OR REPLACE`, the existing outline will be replaced when the outline to be created already exists.|
| format_stmt          | The original SQL text to be applied with the outline. <main id="notice" type='explain'><h4>Note</h4><p>OceanBase Database automatically converts non-formatted SQL text into formatted SQL text. </p></main>|
| TO format_target_stmt | Optional. Specifies the target SQL statement to which the `format_stmt` will be converted or applied. This option allows the outline to be applicable to other SQL statements. <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>If you want to fix the plan for a statement with a hint, you should use <code>format_target_stmt</code> to specify the original SQL. </li><li>When using the <code>TO format_target_stmt</code> clause, the original SQL <code>format_stmt</code> must match <code>format_target_stmt</code> after removing the hint and formatting. </li></ul></p></main>|
| format_sql_id        | The `format_stmt` obtained after a series of rules are applied to the SQL statement to be bound, and then the `MD5` value is calculated based on the `format_stmt`.|

## Examples

* Create an outline by using `FORMAT_SQL_TEXT`.

  ```sql
  CREATE FORMAT OUTLINE my_outline ON SELECT * FROM employees WHERE department_id = ?;
  ```

* Create an outline by using `FORMAT_SQL_ID`.

  ```sql
  CREATE FORMAT OUTLINE my_sql_id_outline ON 'ED570339F2C856BA96008A29EDF04C74' USING HINT /*+ index(t1 idx_c2)*/;

  ```
