# RENAME TABLE

## Purpose

This statement is used to rename a table or a materialized view.

## Limitations and considerations

* During the renaming of a table, the system automatically locks the table and prevents any other threads from reading the table until the renaming is complete.

* If there are active transactions on the target table, the renaming operation will wait until all active transactions are either committed or rolled back.

* If this statement is used to rename multiple tables, the renaming operation proceeds from left to right.

* When executing `RENAME TABLE`, there should be no locked tables and no active transactions.

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>After enabling the tenant-level configuration item <a href="../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2650.enable_lock_priority.md">enable_lock_priority</a>, the <code>RENAME TABLE</code> statement has the highest lock priority.</p>
   </main>

* The `RENAME TABLE` statement can be used for views, but it does not support moving the view to another database.

* During the `RENAME TABLE` operation, table locking and read/write protection measures are added, which will increase the operation time. To avoid affecting other users' DDL operations, it is recommended to avoid batch `RENAME TABLE` operations.

## Privilege requirements

This operation requires the `ALTER` and `DROP` privileges on the original table, as well as the `CREATE` and `INSERT` privileges on the new table.

## Syntax

```sql
RENAME TABLE table_name TO [new_database_name.]new_table_name
    [, table_name2 TO [new_database_name.]new_table_name2 ...];
```

## Parameters

|                               **Parameter**                                |                                  **Description**                                   |
|---------------------------------------------------------------------|---------------------------------------------------------------------------|
| table_name                                                          | The name of the original table.                                                                      |
| new_table_name                                                      | The name of the new table.                                                                      |
| table_name  TO \[new_database_name.\]new_table_name | When renaming multiple tables, separate them with commas (,). You can specify `new_database_name` to move the table to another database. |

## Examples

1. Create tables `t1` and `t2`.

   ```sql
   obclient> CREATE TABLE t1(c1 INT);
   obclient> CREATE TABLE t2(c1 INT);
   ```

2. Rename table `t1` to `t11`.

   ```sql
   obclient> RENAME TABLE t1 TO t11;
   ```

3. Rename table `t11` to `t111` and table `t2` to `t22`.

   ```sql
   obclient> RENAME TABLE t11 TO t111, t2 TO t22;
   ```

4. Move table `t22` to the `mysql` database.

   ```sql
   obclient> RENAME TABLE t22 TO mysql.t22;
   ```
