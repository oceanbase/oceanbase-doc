# SET PASSWORD

## Purpose

This statement is used to modify the password of the current login user or another user in OceanBase Database.

## Limitations and considerations

* After you use the `SET PASSWORD` or `ALTER USER` statement to change a password, the cached old password becomes invalid quickly, and you cannot log in using the old password.
* Authentication string format validation: The `IDENTIFIED AS` and `BY PASSWORD` clauses validate the `$S$` format and reject incorrect formats such as `$A$` (e.g., `sha2`).

## Syntax

```sql
SET PASSWORD [FOR user] = password_option [RETAIN CURRENT PASSWORD];

password_option: {
PASSWORD('authstring')
|'hashstring'
}
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The optional <code>RETAIN CURRENT PASSWORD</code> clause is used to retain the old password while setting a new password, applicable for dual-password scenarios. This feature is available from V4.4.2 BP1 onwards.</p>
</main>

## Parameters

|  **Parameter**  |                                                                       **Description**                                                                        |
|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| FOR user | If the `FOR user` clause is not specified, the password of the current user is modified. Any successfully logged-in user can modify the password of the current user. If the `FOR user` clause is specified, the password of the specified user is modified. To modify the password of the specified user, you must have the `CREATE USER` privilege in the MySQL database. |
|password|By default, the `password` is transmitted in plaintext and will be encoded in the kernel.|
| RETAIN CURRENT PASSWORD | Optional. Specify this option after the `password_option` on the right side of the `=` sign. This option takes effect along with the new password set in this operation. It retains the old password before the password change and enables dual passwords. |

## Examples

* Modify the password of the current user.

  ```sql
  obclient> SET PASSWORD = PASSWORD('**1***');
  Query OK, 0 rows affected
  ```

* Modify the password of the `sqluser01` user.

  ```sql
  obclient> SET PASSWORD FOR sqluser01 = PASSWORD('**2***');
  Query OK, 0 rows affected
  ```
* Modify the password of the `sqluser01` user and retain the old password (double password).

  ```sql
  obclient> SET PASSWORD FOR sqluser01 = PASSWORD('**2***') RETAIN CURRENT PASSWORD;
  Query OK, 0 rows affected
  ```

* Write the serialized authentication string (`$S$...`) directly.

    ```shell
    SET PASSWORD FOR user001 = PASSWORD('$S$005$ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789.');
    ```
