# SET ROLE

## Purpose

This statement is used to activate the roles granted to the current login user in the current session.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The roles activated by the <code>SET ROLE</code> statement only take effect in the current session and do not affect subsequent sessions.</p>
</main>

## Syntax

```sql
SET ROLE {
    DEFAULT
    | NONE
    | ALL
    | ALL EXCEPT role_name [, role_name ...]
    | role_name [, role_name ...]
};
```

## Parameters

|       **Parameter**      | **Description** |
|---------------------|----------|
| DEFAULT             | Specifies the setting to keep the default role. The system activates roles based on the value of the `activate_all_roles_on_login` variable and the default activated roles set by the `SET DEFAULT ROLE` or `ALTER USER` statement:<ul><li>If the value of the <code>activate_all_roles_on_login</code> variable is <code>on</code>, all roles granted to the user are activated in the session.</li><li>If the value of the <code>activate_all_roles_on_login</code> variable is <code>off</code>, the default activated roles specified by the <code>SET DEFAULT ROLE</code> or <code>ALTER USER</code> statement are activated in the session.</li></ul>|
| NONE                | Specifies to disable all roles granted to the user.|
| ALL                 | Specifies to activate all roles granted to the user.|
| ALL EXCEPT          | Specifies to deactivate roles granted to the user.|
| role_name           | Specifies the name of the role. When activating multiple roles, separate the role names with commas (`,`).|

## Examples

* Specify to activate all roles granted to the user in the current session, except for the `role001` role.

  ```shell
  obclient [(none)]> SET ROLE ALL EXCEPT role001;
  ```

* Specify to activate the `role001` and `role002` roles of the user in the current session.

  ```shell
  obclient [(none)]> SET ROLE role001, role002;
  ```
