# STORAGE_CACHE_POLICY_EXECUTOR

## Purpose

In shared storage mode, this statement is used to manually trigger a hot data caching task.

## Syntax

```sql
ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```

## Parameters

|          **Parameter**           |      **Description**      |
|---------------------------|------------------|
|TRIGGER|Used to manually trigger the execution of a hot data caching task.|

## Examples

Execute the following command to immediately trigger a hot data caching task.

```shell
obclient> ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```
