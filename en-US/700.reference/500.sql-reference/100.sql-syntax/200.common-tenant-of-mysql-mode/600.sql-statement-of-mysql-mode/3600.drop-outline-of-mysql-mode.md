# DROP OUTLINE

## Purpose

This statement is used to drop an outline in OceanBase Database.

## Syntax

```sql
DROP OUTLINE outline_name
DROP OUTLINE database_name.outline_name
```

## Parameters

|      **Parameter**      |           **Description**           |
|------------------|----------------------------|
| outline_name     | The name of the outline to be dropped.        |
| database_name    | The name of the database to which the outline belongs. Optional. |

## Examples

* Drop the outline `olt_1` in the current database.

```sql
obclient> DROP OUTLINE olt_1;
```

* Drop the outline in the specified database.

```sql
obclient> DROP OUTLINE ol_db.olt_2;
```
