# DROP DATABASE

## Purpose

This statement is used to delete a database.

## Syntax

```sql
DROP DATABASE [IF EXISTS] database_name
```

## Parameters

|    **Parameter**     |      **Description**       |
|---------------|-------------------|
| IF EXISTS     | Prevents an error when the database does not exist. |
| database_name | Specifies the name of the database to be deleted.       |

## Examples

* Drop the `test2` database.

  ```sql
  obclient> DROP DATABASE test2;
  ```

* Drop the non-existent `notest` database.

  ```sql
  obclient> DROP DATABASE notest;
  ```

  Expected return result:

  ```sql
  ERROR 1008 (HY000): Can't drop database 'notest'; database doesn't exist
  ```

  ```sql
  obclient> DROP DATABASE IF EXISTS notest;
  ```

  Expected return result:

  ```sql
  Query OK, 0 rows affected, 1 warning
  ```

  ```sql
  obclient> SHOW WARNINGS;
  ```

  Expected return result:

  ```sql
  
  +-------+------+------------------------------------------------------+
  | Level | Code | Message                                              |
  +-------+------+------------------------------------------------------+
  | Note  | 1008 | Can't drop database 'notest'; database doesn't exist |
  +-------+------+------------------------------------------------------+
  1 row in set
  ```
