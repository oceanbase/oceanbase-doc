# CANCEL JOB

Used to cancel an asynchronous task.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p><ul><li>To execute the <code>CANCEL JOB</code> statement, you must specify the <code>job_id</code> parameter. </li><li>Running tasks are terminated, and tasks that have not started are not executed. </li><li>For tasks that have already completed, executing the <code>CANCEL JOB</code> statement returns the <code>ERROR 4018 (HY000): Entry not exist</code> error. </li><li>After a task is canceled, you can still view the job status. </li></ul></p>
</main>

## Syntax

```sql
CANCEL JOB 'job_id';
```

## Examples

```shel
obclient> CANCEL JOB '2010011125899906847397';
3 rows in set (0.00 sec)
```
