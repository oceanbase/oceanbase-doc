# REPLACE

## Purpose

You can use this statement to replace one or more records in a table. If no primary key or unique key conflict exists, records are directly inserted. If a conflict exists, the conflicting records are deleted. Then, the new records are inserted.

## Syntax

```sql
REPLACE [INTO] table_factor [PARTITION (partition_name_list)] [(column_name_list)]
    {VALUES | VALUE} column_value_lists

partition_name_list:
    partition_name [, partition_name ...]

column_name_list:
    column_name [, column_name ...]

column_value_lists:
    (column_value_list) [, (column_value_list) ...]

column_value_list:
    column_value [, column_value ...]

column_value:
    {expression | DEFAULT}
```

## Parameters

| **Parameter** | **Description** |
|---------------------|------------|
| table_factor | The name of the table in which data is to be replaced.  |
| column_name_list | The name of the column in which data is to be replaced.  |
| partition_name_list | The name of the partition in which data is to be replaced.  |

## Examples

The table used in the examples is defined as follows:

```sql
obclient> CREATE TABLE product_info (product_id INT PRIMARY KEY, product_name VARCHAR(40));
```

1. Replace the values in the two records of table `product_info`.

   ```sql
   obclient> REPLACE INTO product_info VALUES (1, 'Product A'),(2, 'Product B');
   ```

2. Query the data in table `product_info`.

   ```sql
   obclient> SELECT * FROM product_info;
   ```

   The query result is as follows:

   ```sql
   +------------+-------------+
   | product_id | product_name|
   +------------+-------------+
   |          1 | Product A   |
   |          2 | Product B   |
   +------------+-------------+
   2 rows in set
   ```

3. Replace the records in table `product_info`. If a record with `product_id=2` already exists, it will be replaced.

   ```sql
   obclient> REPLACE INTO product_info VALUES (3, 'Product C'),(2, 'Product B Updated');
   ```

4. Query the data in table `product_info`.

   ```sql
   obclient> SELECT * FROM product_info;
   ```

   The query result is as follows:

   ```sql
   +------------+------------------+
   | product_id | product_name     |
   +------------+------------------+
   |          1 | Product A        |
   |          2 | Product B Updated|
   |          3 | Product C        |
   +------------+------------------+
   3 rows in set
   ```
