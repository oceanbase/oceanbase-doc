# RENAME USER

## Purpose

This statement is used to modify the username of a user who logs in to OceanBase Database.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You must have the global <code>CREATE USER</code> privilege to use this statement to rename a user. </p>
  </main>

## Syntax

```sql
RENAME USER
    'old_user_name' TO 'new_user_name'
  [,'old_user_name' TO 'new_user_name'...]
```

## Parameters

|               **Parameter**               |                           **Description**                            |
|------------------------------------|-------------------------------------------------------------|
| old_user_name                      | The original username.                                                       |
| new_user_name                      | The new username. The username must be less than or equal to 16 bytes in length.                                      |
| 'old_user_name' TO 'new_user_name' | The new username. When you modify multiple usernames, separate them with commas (,). The privileges of the new and old users remain consistent before and after the modification. |

## Examples

1. Before the modification, execute the following statement to view the user.

   ```sql
   obclient> SELECT user FROM mysql.user;
   ```

   The query result is as follows:

   ```sql
   +-----------+
   | user      |
   +-----------+
   | root      |
   | admin     |
   | sqluser01 |
   | sqluser02 |
   +-----------+
   4 rows in set
   ```

2. Execute the following statement to rename the username of the `sqluser01` user to `obsqluser01`.

   ```sql
   obclient> RENAME USER 'sqluser01' TO 'obsqluser01';
   ```

3. After the modification, execute the following statement to view the user.

   ```sql
   obclient> SELECT user FROM mysql.user;
   ```

   The query result is as follows:

   ```sql
   +-------------+
   | user        |
   +-------------+
   | root        |
   | admin       |
   | obsqluser01 |
   | sqluser02   |
   +-------------+
   4 rows in set
   ```

   The username of the `sqluser01` user has been changed to `obsqluser01`.
