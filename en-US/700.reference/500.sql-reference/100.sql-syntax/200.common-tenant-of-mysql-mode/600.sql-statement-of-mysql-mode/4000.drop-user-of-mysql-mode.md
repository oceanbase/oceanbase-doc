# DROP USER

## Purpose

This statement is used to delete one or more database users.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <ul>
    <li>You must have the global <code>CREATE USER</code> privilege to use the <code>DROP USER</code> command.</li>
    <li>You cannot delete data from the <code>mysql.user</code> table using the <code>DELETE</code> statement. You can only use the <code>DROP</code> statement to delete users.</li>
    <li>When a user is successfully deleted, all their privileges are also revoked.</li>
    </ul>
  </main>

## Syntax

```sql
DROP USER [IF EXISTS] user_name [, user_name...]
```

## Parameters

|    **Parameter**     |          **Description**           |
|-----------|-----------------------|
| IF EXISTS | Optional. When this clause is used, attempting to delete a non-existent user will generate a warning instead of an error. If this clause is not used, attempting to delete a non-existent user will result in an error.|
| user_name | The username. When deleting multiple users, separate them with commas. |

## Examples

* Delete the user `sales_user`.

```sql
obclient> DROP USER sales_user;
```

* Use `IF EXISTS` to delete a user without generating an error if the user does not exist.

```sql
obclient> DROP USER IF EXISTS finance_user;
```

* Delete multiple users at once.

```sql
obclient> DROP USER user1, user2, user3;
```
