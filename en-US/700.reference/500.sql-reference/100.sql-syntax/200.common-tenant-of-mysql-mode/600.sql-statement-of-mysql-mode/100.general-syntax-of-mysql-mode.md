# General syntax

This section describes the general syntax of SQL statements, including constants, character sets, data types, SQL properties, distributed properties, and storage properties.

## Constants

* `INT_VALUE`: matches an integer constant, such as `123`.

* `DECIMAL_VALUE`: matches a fixed-point constant, such as `123.456`.

* `STR_VALUE`: matches a string constant, such as `abc`.

* `NULL`: matches the `NULL` constant.

* `STORAGE_SIZE`: matches a storage size constant. The default unit for an integer constant is bytes. For a string constant, you can specify the unit as M or G. For example, `1024` or `'500M'`.

```sql
const_value:
      INT_VALUE
    | DECIMAL_VALUE
    | STR_VALUE
    | NULL
    | STORAGE_SIZE

STORAGE_SIZE:
      INT_VALUE
    | 'INT_VALUE[M|G]'
```

## Character sets

```sql
charset:
      default_charset
    | column_charset

default_charset:
    [DEFAULT] {CHARSET | CHARACTER SET} [=] charset_name

column_charset:
    {CHARSET | CHARACTER SET} charset_name

charset_name:
    STR_VALUE
```

`charset_name` can be any valid character set name. For more information about character sets, see [MySQL compatibility](../../../../../100.learn-more-about-oceanbase/500.compatibility-with-mysql.md).

## Collations

```sql
collate:
      default_collate
    | column_collate

default_collate:
    [DEFAULT] COLLATE [=] collation_name

column_collate:
    COLLATE collation_name

collation_name:
    STR_VALUE
```

`collation_name` can be any valid collation name. For more information about collations, see [MySQL compatibility](../../../../../100.learn-more-about-oceanbase/500.compatibility-with-mysql.md).

## Data types

```sql
data_type:
      TINYINT[(precision)] [UNSIGNED] [ZEROFILL]

    | MEDIUMINT[(precision)] [UNSIGNED] [ZEROFILL]
    | INT[(precision)] [UNSIGNED] [ZEROFILL]
    | INTEGER[(precision)] [UNSIGNED] [ZEROFILL]
    | BIGINT[(precision)] [UNSIGNED] [ZEROFILL]
    | FLOAT[(precision, scale)] [UNSIGNED] [ZEROFILL]
    | DOUBLE[(precision, scale)] [UNSIGNED] [ZEROFILL]
    | DECIMAL[(precision [, scale])] [UNSIGNED] [ZEROFILL]
    | NUMERIC[(precision [, scale])] [UNSIGNED] [ZEROFILL]
    | BOOL
    | BOOLEAN
    | DATETIME[(scale)]
    | TIMESTAMP[(scale)]
    | DATE
    | TIME[(scale)]
    | YEAR
    | VARCHAR(length) column_charset column_collate
    | VARBINARY(length)
    | CHAR[(length)] column_charset column_collate
    | BINARY[(length)]
    | TINYTEXT column_charset column_collate
    | TINYBLOB
    | TEXT[(length)] column_charset column_collate
    | BLOB[(length)]
    | MEDIUMTEXT column_charset column_collate
    | MEDIUMBLOB
    | LONGTEXT column_charset column_collate
    | LONGBLOB
    | STRING

precision | scale | length:
    INT_VALUE
```

## SQL properties

* Object name

  ```sql
  tenant_name | pool_name | unit_name | zone_name | region_name:
      STR_VALUE

  database_name | table_name | table_alias_name | column_name| column_alias_name  | partition_name | subpartition_name:
      STR_VALUE

  index_name | view_name | object_name | constraint_name | tablegroup_name:
      STR_VALUE

  outline_name | user_name:
      STR_VALUE

  table_factor:
      [[database_name].] table_name

  column_factor:
      [table_factor.] column_name
  ```

* Expression

  ```sql
  expression:
        const_value
      | column_factor
      | operator_expression
      | function_expression
  ```

* Comment

  ```sql
  comment:
      COMMENT 'comment_text'

  comment_text:
      STR_VALUE
  ```

## Distributed properties

* `PRIMARY_ZONE`: specifies the primary replica distribution strategy.

  ```sql
  primary_zone:
  PRIMARY_ZONE [=] zone_name
  ```

* `ZONE_LIST`: specifies the resource distribution strategy of a tenant.

  ```sql
  zone_list:
  ZONE_LIST [=] (zone_name [, zone_name ...])
  ```

* `REPLICA_NUM`: specifies the number of replicas.

  ```sql
  replica_num:
  REPLICA_NUM [=] INT_VALUE
  ```

* `TABLEGROUP`: specifies the primary replica distribution strategy of multiple data sets.

  ```sql
  tablegroup:
        default_tablegroup
      | table_tablegroup

  default_tablegroup:
      DEFAULT TABLEGROUP [=] {tablegroup_name | NULL}

  table_tablegroup:
      TABLEGROUP [=] {tablegroup_name | NULL}
  ```

## Storage properties

* `BLOCK_SIZE`: specifies the microblock length of object storage.

  ```sql
  block_size:
  BLOCK_SIZE [=] INT_VALUE
  ```

* `COMPRESSION`: specifies the compression algorithm of object storage.

  ```sql
  compression:
  COMPRESSION [=] {NONE | LZ4_1.0 | LZ0_1.0 | SNAPPY_1.0}
  ```

* `PCTFREE`: specifies the percentage of macroblock reservation in object storage.

  ```sql
  pctfree:
  PCTFREE [=] INT_VALUE
  ```

* `TABLET_SIZE`: specifies the minimum shard size of a single task during parallel major compactions.

  ```sql
  tablet_size:
  TABLET_SIZE [=] INT_VALUE
  ```
