# DROP EVENT

You can use this statement to drop an event.

## Syntax

```sql
DROP EVENT [IF EXISTS] event_name
```

## Parameters

|   Parameter   |     Description    |
|-------|-----------|
|event_name| The name of the event to be dropped. |

## Examples

```shell
obclient> DROP EVENT myevent;
```
