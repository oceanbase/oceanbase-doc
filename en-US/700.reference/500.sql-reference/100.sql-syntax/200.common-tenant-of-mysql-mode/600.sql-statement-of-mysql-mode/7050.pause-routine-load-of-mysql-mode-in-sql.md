# PAUSE ROUTINE LOAD

## Purpose

This statement is used to pause a Routine Load task and stop data import.

## Syntax

```sql
PAUSE ROUTINE LOAD FOR job_name;
```

## Parameters

| **Parameter** |       **Description**           |
|----------|--------------------------|
| job_name | The name of the Routine Load task to be paused.|

## Examples

Pause the Routine Load task `load_job_0`.

```shell
obclient> PAUSE ROUTINE LOAD FOR load_job_0;
```
