# LOAD_FILE

## Purpose

The `LOAD_FILE` function reads external storage files into the database based on the external table interface. It supports reading files from local storage, HDFS, OSS, COS, and S3.

Before using this function, you must create a location object using [CREATE LOCATION](2230.create-location-of-mysql-mode-in-sql.md) and specify the location name and file name when calling the function.

### Syntax

```sql
LOAD_FILE(location_name, file_name)
```

Parameters:

| Parameter | Description | Type | Nullable |
|------|------|------|----------|
| location_name | The name of the external storage file. | VARCHAR(128) | Yes |
| file_name | The name of the external storage file. | VARCHAR(4096) | No |

If either `location_name` or `file_name` is `NULL`, the output will be `NULL`.

Return value:

* The content of the external storage file as BLOB data.

### Limitations and considerations

#### Expression type and visibility

* When called in an expression context such as `SELECT`, it behaves the same as `LOAD_FILE(location_name, file_name)` in this document.
* It cannot be used for generated columns.

#### Error and boundary behavior

| Scenario | Behavior |
|------|------|
| `location_name` or `file_name` is an empty string | Error `OB_INVALID_ARGUMENT` is returned. |
| The location does not exist | Error `OB_LOCATION_OBJ_NOT_EXIST` is returned. |
| The current session does not have read permissions for the location | An error is returned due to failed permission verification. |
| The file does not exist | Error `OB_OBJECT_NAME_NOT_EXIST` is returned. |
| The file size is 0 | Error `OB_INVALID_DATA` is returned (the file is considered invalid). |
| The file size exceeds `document_ai_file_max_size` | Error `OB_NOT_SUPPORTED` is returned. |

#### Configuration item and scenario constraints

`LOAD_FILE` must be constrained by configuration items and scenario constraints to ensure security and stability.

When using the `LOAD_FILE` expression to read external files, it is subject to the following two configuration items to ensure that the size of external files is controllable. The maximum file size allowed for reading is the smaller of the two, i.e., `effective_max_file_size = min(max_allowed_packet, document_ai_file_max_size)`.

Specific configuration item information is as follows:

| Configuration item | Scope | Default value | Value range | Unit | Description |
|------|------|------|------|------|------|
| [max_allowed_packet](../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/3700.max_allowed_packet-global.md) | Global network packet size limit. | 16,777,216 (16 MB) | [1048576, 1073741824] (1 MB ~ 1 GB) | Bytes (Byte) | Controls the maximum size of all interactive data packets between the database and external sources (including clients and other OceanBase Database nodes). Any single transmission of data (including the content of files read by `LOAD_FILE`) must not exceed this value. |
| [document_ai_file_max_size](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2280.document_ai_file_max_size.md) | Maximum file size limit for `LOAD_FILE`. | 100 MB | [0, 500MB] | Bytes (Byte) | Limits the maximum size of a file that can be processed by the `LOAD_FILE` function. Setting it to `0` disables the use of `LOAD_FILE` for reading files. |

### Examples

1. Read a local file (<= 16 MB)

    ```sql
    -- Configure the location path
    CREATE OR REPLACE LOCATION local_data
    URL = 'file:///home/';

    -- Read the local file
    SELECT load_file('local_data', 'test_16MB.pdf');
    ```

2. Read a local file (50 MB)

    ```sql
    -- Set the max_allowed_packet size to 100 MB
    SET GLOBAL max_allowed_packet=104,857,600;

    -- Read the local file
    select load_file('load_file', 'test_50MB.pdf');
    ```

3. Read an OSS file

    ```sql
    CREATE LOCATION oss_t
    URL = 'oss://dir'
    CREDENTIAL = (
    ACCESSID = '123'
    ACCESSKEY = '456'
    HOST = '789'
    );
    -- Read the OSS file
    SELECT load_file('oss_t', 'test_oss.pdf');
    ```

4. Read an HDFS file

    ```sql
    CREATE LOCATION hdfs_user
    URL = 'hdfs://namenode:8020/'
    CREDENTIAL (
    USER = 'hdfs_user_name'
    );
    -- Read the HDFS file
    SELECT load_file('hdfs_user', 'test_hdfs.pdf');
    ```
