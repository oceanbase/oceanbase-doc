# LOAD_FILE

## Purpose

The `LOAD_FILE` function reads files from external storage to the database through the external table interface. It supports reading files from local file systems, HDFS, OSS, COS, and S3.

Before using this function, you must create a location object by executing the [CREATE LOCATION](2230.create-location-of-mysql-mode-in-sql.md) statement and specify the location name and file name when calling this function.

### Syntax

```sql
LOAD_FILE(location_name, file_name)
```

Parameters:

| Parameter | Description | Type | Nullable |
|------|------|------|----------|
| location_name | The name of the external storage file. | VARCHAR(128) | Yes |
| file_name | The name of the external storage file. | VARCHAR(4096) | No |

If either `location_name` or `file_name` is `NULL`, the output is `NULL`.

Return value:

* The content of the external storage file in BLOB format.

### Limitations and considerations

The `LOAD_FILE` function is subject to configuration and scenario constraints to ensure security and stability.

When using the `LOAD_FILE` function to read an external file, the file size is constrained by the following two parameters. The maximum file size that can be read is the smaller of the two values, i.e., `effective maximum file size = min(max_allowed_packet, document_ai_file_max_size)`.

The following table describes the parameters.

| Parameter | Scope | Default value | Value range | Unit | Description |
|------|------|------|------|------|------|
| [max_allowed_packet](../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/3700.max_allowed_packet-global.md) | Global | 16,777,216 (16 MB) | [1048576, 1073741824] (1 MB ~ 1 GB) | Byte | Specifies the maximum size of data packets exchanged between the database and external systems (such as clients and other OceanBase Database nodes). The size of any single transmission, including the content of a file read by `LOAD_FILE`, cannot exceed this value. |
| [document_ai_file_max_size](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2280.document_ai_file_max_size.md) | Tenant-level | 100 MB | [0, 500MB] | Byte | Specifies the maximum size of a file that can be processed by the `LOAD_FILE` function. Set this parameter to `0` to disable the `LOAD_FILE` function. |

### Examples

1. Read a local file (<= 16 MB)

    ```sql
    -- Configure the location path.
    CREATE OR REPLACE LOCATION local_data
    URL = 'file:///home/';

    -- Read the local file.
    SELECT load_file('local_data', 'test_16MB.pdf');
    ```

2. Read a local file (50 MB)

    ```sql
    -- Set the max_allowed_packet parameter to 100 MB.
    SET GLOBAL max_allowed_packet=104,857,600;

    -- Read the local file.
    select load_file('load_file', 'test_50MB.pdf');
    ```

3. Read an OSS file

    ```sql
    CREATE LOCATION oss_t
    URL = 'oss://dir'
    CREDENTIAL = (
    ACCESSID = '123'
    ACCESSKEY = '456'
    HOST = '789'
    );
    -- Read the OSS file.
    SELECT load_file('oss_t', 'test_oss.pdf');
    ```

4. Read an HDFS file

    ```sql
    CREATE LOCATION hdfs_user
    URL = 'hdfs://namenode:8020/'
    CREDENTIAL (
    USER = 'hdfs_user_name'
    );
    -- Read the HDFS file.
    SELECT load_file('hdfs_user', 'test_hdfs.pdf');
    ```
