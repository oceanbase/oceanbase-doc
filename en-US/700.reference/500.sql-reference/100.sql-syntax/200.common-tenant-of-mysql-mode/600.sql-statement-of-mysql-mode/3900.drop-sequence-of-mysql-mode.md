# DROP SEQUENCE

## Purpose

You can use this statement to drop a sequence.

## Syntax

```sql
DROP SEQUENCE [IF EXISTS] [schema.]sequence_name
```

## Parameters

| Parameter | Description |
|-------------------|-----------------------------------------------|
| IF EXISTS         | Specifies to display prompt information if the sequence does not exist, without returning an error. Optional.             |
| schema            | The schema where the sequence is located. If `schema.` is not specified, the sequence is located in the schema of the currently logged-on user. Optional. |
| sequence_name     | The name of the sequence to be dropped.                                   |

## Examples

* Drop the sequence named `user_seq`.

```sql
obclient> DROP SEQUENCE user_seq;
```

* Drop the sequence named `product_seq`, without returning an error if the sequence does not exist.

```sql
obclient> DROP SEQUENCE IF EXISTS product_seq;
```
