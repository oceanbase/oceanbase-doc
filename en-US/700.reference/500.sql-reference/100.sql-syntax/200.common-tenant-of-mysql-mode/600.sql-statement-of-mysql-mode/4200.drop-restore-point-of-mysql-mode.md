# DROP RESTORE POINT

## Purpose

This statement is used to drop a restore point.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li> DROP RESTORE POINT is not supported in V4.x. </li><li> System tenants do not support creating and dropping restore points. </li></ul></p>
  </main>

## Syntax

```sql
DROP RESTORE POINT restore_point
```

## Parameters

|      Parameter       |    Description    |
|---------------|----------|
| restore_point | The name of the restore point. |

## Examples

1. View existing restore points of the tenant.

   ```sql
   obclient> SELECT * FROM V$RESTORE_POINT;
   ```

   Expected return result:

   ```sql
   +-----------+------------------+----------------------------+------+
   | TENANT_ID | SNAPSHOT         | TIME                       | NAME |
   +-----------+------------------+----------------------------+------+
   |      1001 | 1630407064663511 | 2021-08-31 18:51:04.665692 | rp1  |
   +-----------+------------------+----------------------------+------+
   1 row in set
   ```

2. Drop the restore point `rp1`.

   ```sql
   obclient> DROP RESTORE POINT rp1;
   ```
