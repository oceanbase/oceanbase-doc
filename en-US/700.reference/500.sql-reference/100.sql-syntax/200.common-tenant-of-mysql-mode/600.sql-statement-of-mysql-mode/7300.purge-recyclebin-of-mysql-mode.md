# PURGE RECYCLEBIN

## Purpose

This statement is used to clear the recycle bin.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><code>PURGE RECYCLEBIN</code> will clear all database objects in the recycle bin. Only the root user can execute this statement. Please proceed with caution. </p>
  </main>

## Syntax

```sql
PURGE RECYCLEBIN
```

## Examples

Clear the recycle bin:

```sql
obclient> PURGE RECYCLEBIN;
```
