# DROP LOGFILE GROUP

## Purpose

You can use this statement to drop a log file group.

## Syntax

```sql
DROP LOGFILE GROUP logfile_group
    ENGINE [=] engine_name
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Only the keyword syntax is supported. The functionality does not actually take effect. </p>
</main>
