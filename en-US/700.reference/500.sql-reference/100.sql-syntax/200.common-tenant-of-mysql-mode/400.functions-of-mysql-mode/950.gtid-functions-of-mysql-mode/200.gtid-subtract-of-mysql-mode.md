# GTID_SUBTRACT()

## Purpose

`GTID_SUBTRACT()` returns all global transaction IDs (GTIDs) in a set that do not belong to another set.

## Syntax

```sql
GTID_SUBTRACT(set1,set2)
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Only the keyword syntax is supported. The functionality does not actually take effect. </p>
</main>
