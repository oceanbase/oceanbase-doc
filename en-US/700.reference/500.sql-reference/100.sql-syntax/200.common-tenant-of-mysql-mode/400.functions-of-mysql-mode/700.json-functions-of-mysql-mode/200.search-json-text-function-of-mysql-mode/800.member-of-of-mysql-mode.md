# MEMBER OF

## Purpose

The function returns 1 if the retrieved element is the same as any element in the JSON array, and 0 otherwise.

## Syntax

```sql
value MEMBER OF(json_array)
```

## Considerations

The function returns 1 if `value` is an element of `json_array`, and 0 otherwise.

`value` must be a scalar or a JSON document. If it is a scalar, the operator treats it as an element of the JSON array.

## Examples

```sql
obclient> SELECT 45 MEMBER OF('[123, "abc", 45, "ab", 10]');
+--------------------------------------------+
| 45 MEMBER OF('[123, "abc", 45, "ab", 10]') |
+--------------------------------------------+
|                                          1 |
+--------------------------------------------+
1 row in set

obclient> SELECT 'cd' MEMBER OF('[23, "abc", 17, "cd", 10]');
+---------------------------------------------+
| 'cd' MEMBER OF('[23, "abc", 17, "cd", 10]') |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set

obclient> SELECT 5 MEMBER OF('[123, "abc", 45, "ab", 10]');
+-------------------------------------------+
| 5 MEMBER OF('[123, "abc", 45, "ab", 10]') |
+-------------------------------------------+
|                                         0 |
+-------------------------------------------+
1 row in set

obclient> SELECT
```
