# JSON_OVERLAPS

## Purpose

This function compares two JSON documents. It returns 1 if the two documents share one or more key-value pairs or array elements, and 0 otherwise.

## Syntax

```sql
JSON_OVERLAPS(json_doc1, json_doc2)
```

## Considerations

The `json_doc1` and `json_doc2` parameters specify the two JSON documents to compare. If both parameters are scalars, the function performs a simple equality test.

This function is similar to JSON_CONTAINS(), which requires that all elements of the search array exist in the searched array. Therefore, JSON_CONTAINS() performs an `AND` operation on the search key, while JSON_OVERLAPS() performs an `OR` operation.

When comparing two arrays, JSON_OVERLAPS() returns `1` if they share one or more array elements, and `0` otherwise.

Queries on JSON columns in InnoDB tables using the JSON_OVERLAPS() function in the `WHERE` clause can be optimized using multi-value indexes.
