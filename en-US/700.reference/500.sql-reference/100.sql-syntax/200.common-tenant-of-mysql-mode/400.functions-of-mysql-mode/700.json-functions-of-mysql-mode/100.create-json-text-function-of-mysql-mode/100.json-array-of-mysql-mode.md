# JSON_ARRAY

## Purpose

This function returns a JSON array containing the input values, which may be empty.

## Syntax

```sql
JSON_ARRAY([val[, val] ...])
```

## Parameters

The `val` parameter specifies the input value.

## Examples

```sql
obclient> SELECT JSON_ARRAY(1, "abcd", NULL, TRUE, CURTIME(),'[a,b,c]','{"d":100}');
+---------------------------------------------------------------------+
| JSON_ARRAY(1, "abcd", NULL, TRUE, CURTIME(),'[a,b,c]','{"d":100}')   |
+---------------------------------------------------------------------+
| [1, "abcd", null, true, "21:49:37.000000", "[a,b,c]", "{\"d\":100}"] |
+---------------------------------------------------------------------+
1 row in set

obclient> SELECT JSON_ARRAY(NULL);
+------------------+
| JSON_ARRAY(NULL) |
+------------------+
| [null]           |
+------------------+
1 row in set

obclient> SELECT JSON_ARRAY();
+--------------+
| JSON_ARRAY() |
+--------------+
| []           |
+--------------+
1 row in set
```
