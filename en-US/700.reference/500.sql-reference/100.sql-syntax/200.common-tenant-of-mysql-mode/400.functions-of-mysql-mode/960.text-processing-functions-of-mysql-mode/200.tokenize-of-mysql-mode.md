# TOKENIZE

## Purpose

This function is used to tokenize text based on a specified tokenizer and JSON-formatted parameters, returning the tokenization results.

## Syntax

```sql
TOKENIZE('text', ['parser'], ['behavior_ctrl'])
```

## Parameters

|    **Field**   | **Description** |
|---------------|----------|
| text          | The text to be tokenized. Supports `TEXT`, `CHAR`, and `VARCHAR` data types.|
| parser        | The name of the tokenizer. Supports `BENG` (basic English), `NGRAM` (Chinese), `SPACE` (space), and `IK` (Chinese) tokenizers.<main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, support for the <code>IK</code> tokenizer was introduced starting from V4.3.5 BP1. </p></main></li></ul> |
| behavior_ctrl | JSON-formatted parameters for optional configurations. The supported options are as follows:<ul><li>`stopwords`: the stopword table. If not provided, the global default stopword table is applied. If empty, it remains empty.</li><li>`case`: if not provided, the system default behavior is applied; if provided, the text is processed in upper or lower case.</li><li>`output`: specifies the output format. The supported options are as follows:<ul><li>`default`: outputs a JSON array containing only the tokens, such as `["hello", "world", "english"]`.</li><li>`all`: outputs a JSON object containing the document length and token frequencies, such as `{"doc_len":3, "tokens":["i":1, "love":1, "china":1]}`.</li><li>`additional-args`: specifies additional parameters for specific tokenizers, such as `ngram`.</li></ul>|

## Examples

Use the `TOKENIZE` function to split the string `I Love China` into words, using `beng` as the delimiter. Then, use JSON-formatted parameters to set the output options.

```sql
SELECT TOKENIZE('I Love China','beng', '[{"output": "all"}]');
```

The result is as follows:

```shell
+--------------------------------------------------------+
| TOKENIZE('I Love China','beng', '[{"output": "all"}]') |
+--------------------------------------------------------+
| {"tokens": [{"love": 1}, {"china": 1}], "doc_len": 2}  |
+--------------------------------------------------------+
1 row in set
```
