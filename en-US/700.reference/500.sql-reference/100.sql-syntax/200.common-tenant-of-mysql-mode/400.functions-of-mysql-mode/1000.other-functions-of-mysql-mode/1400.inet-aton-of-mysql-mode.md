# INET_ATON

## Syntax

```sql
INET_ATON(expr)
```

## Purpose

Converts an IPv4 network address in string format to an integer that represents the address value in network byte order (big-endian). If the input parameter is invalid, it returns `NULL`.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Use the <code>INT UNSIGNED</code> data type to store values generated by the <code>INET_ATON()</code> function. Do not use the <code>INT</code> data type with a signed attribute. If you use a signed <code>INT</code> column, the value cannot be correctly stored when the first octet of the IP address is greater than 127. </p>
  </main>

## Examples

```sql
obclient> SELECT INET_ATON('1.1.1.1');
+----------------------+
|  INET_ATON('1.1.1.1') |
+----------------------+
|             16843009 |
+----------------------+
1 row in set
```
