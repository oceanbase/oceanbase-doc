# ISNAN

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available from V4.6.0. </p>
</main>

## Syntax

```sql
ISNAN(number)
```

## Purpose

This function determines whether the value of `number` is a "Not a Number" (NaN). It returns `NULL` (true) if the value is NaN, or 0 (false) otherwise.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is not enabled. You must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <strong>sql_func_extension_mode</strong>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Return 0.

    ```shell
    obclient> SELECT ISNAN(1.5);
    ```

    The return result is as follows:

    ```shell
    +------------+
    | ISNAN(1.5) |
    +------------+
    |          0 |
    +------------+
    1 row in set
    ```

3. Return `NULL`.

    ```shell
    obclient> SELECT ISNAN(1/0);
    ```

    The return result is as follows:

    ```shell
    +------------+
    | ISNAN(1/0) |
    +------------+
    |       NULL |
    +------------+
    1 row in set
    ```
