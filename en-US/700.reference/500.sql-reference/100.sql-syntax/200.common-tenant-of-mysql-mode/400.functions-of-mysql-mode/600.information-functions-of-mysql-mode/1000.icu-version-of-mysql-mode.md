# ICU_VERSION

## Syntax

```sql
ICU_VERSION()
```

## Purpose

This function returns the version of the ICU library that supports regular expression operations.
OceanBase Database uses the International Components for Unicode (ICU) library to support regular expressions. ICU provides full Unicode support and is safe for multibyte characters.

## Examples

```sql
obclient> SELECT ICU_VERSION();
+---------------+
| ICU_VERSION() |
+---------------+
| 69.1          |
+---------------+
1 row in set
```
