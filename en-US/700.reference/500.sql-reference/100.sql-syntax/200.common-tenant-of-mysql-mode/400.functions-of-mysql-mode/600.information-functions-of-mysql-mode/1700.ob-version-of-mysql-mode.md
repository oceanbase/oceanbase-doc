# OB_VERSION

## Syntax

```sql
OB_VERSION()
```

## Purpose

Returns the version information of the current OceanBase Database instance in the utf8mb4 character set.

## Examples

```sql
obclient> SELECT OB_VERSION();
+--------------+
| OB_VERSION() |
+--------------+
| 4.1.0.0      |
+--------------+
1 row in set
```
