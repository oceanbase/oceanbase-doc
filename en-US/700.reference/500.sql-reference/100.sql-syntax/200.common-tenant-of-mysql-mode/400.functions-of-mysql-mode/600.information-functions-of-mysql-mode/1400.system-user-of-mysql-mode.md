# SYSTEM_USER

## Syntax

```sql
SYSTEM_USER()
```

## Purpose

Returns the current username and hostname. This function is a synonym for `USER()`.

## Examples

```sql
obclient> SELECT SYSTEM_USER();
+---------------------+
| SYSTEM_USER()       |
+---------------------+
| root@xxx.xx.xxx.xxx |
+---------------------+
1 row in set
```
