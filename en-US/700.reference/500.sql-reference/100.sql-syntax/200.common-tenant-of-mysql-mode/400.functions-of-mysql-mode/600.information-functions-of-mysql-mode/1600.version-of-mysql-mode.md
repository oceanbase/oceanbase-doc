# VERSION

## Syntax

```sql
VERSION()
```

## Purpose

Returns the version number of the MySQL-compatible OceanBase Database instance, in the utf8mb4 character set.

## Examples

```sql
obclient> SELECT VERSION();
+---------------------------+
| VERSION()                 |
+---------------------------+
| 5.7.25-OceanBase-v4.1.0.0 |
+---------------------------+
1 row in set
```
