# Overview of lock functions

OceanBase Database in MySQL mode provides the following lock functions:

| **Function** | **Description** |
|--------------|----------|
| [GET_LOCK](200.get-lock-of-mysql-mode.md) | Acquires a named lock.|
| [IS_FREE_LOCK](300.is-free-lock-of-mysql-mode.md) | Checks whether the specified lock is free.|
| [IS_USED_LOCK](400.is-used-lock-of-mysql-mode.md) | Checks whether the specified lock is in use.|
| [RELEASE_ALL_LOCKS](500.release-all-locks-of-mysql-mode.md) | Releases all locks held by the current session.|
| [RELEASE_LOCK](600.release-lock-of-mysql-mode.md) | Releases the specified lock.|

## Prerequisites

If you connect to the cluster by using a proxy, you must also enable the following proxy configurations:

```sql
ALTER PROXYCONFIG SET proxy_id = 1;
ALTER PROXYCONFIG SET client_session_id_version = 2;
ALTER PROXYCONFIG SET enable_single_leader_node_routing = false;
```
