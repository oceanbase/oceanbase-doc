# ORA_DECODE

## Syntax

```sql
ORA_DECODE(condition, value1, return_val1, value2, return_val2, ... valuen, return_val, omit_val)
```

## Purpose

The `ORA_DECODE()` function is equivalent to the `DECODE()` function in an Oracle database.

The function is defined as follows:

```sql
IF condition = value1
THEN RETURN(return_value1)
ELSIF condition = value2
THEN RETURN(return_value2)
......
ELSIF condition = valueN
THEN RETURN(return_valueN)
ELSE RETURN(default_value)
END IF
```

## Examples

```sql
obclient> SELECT * FROM films ORDER BY ORA_DECODE(id,1,'lala',2,'mua');

+------+--------------+-------------+--------+
| id   | release_year | category_id | rating |
+------+--------------+-------------+--------+
|    3 |         2015 |           3 |   9.00 |
|    4 |         2016 |           2 |   8.20 |
|    5 |         2016 |           1 |   8.40 |
|    6 |         2017 |           2 |   7.00 |
|    1 |         2015 |           1 |   8.00 |
|    2 |         2015 |           2 |   8.50 |
+------+--------------+-------------+--------+
```
