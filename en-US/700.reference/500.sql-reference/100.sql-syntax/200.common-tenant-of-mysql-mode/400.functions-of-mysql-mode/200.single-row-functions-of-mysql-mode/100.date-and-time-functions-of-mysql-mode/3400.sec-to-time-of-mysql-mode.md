# SEC_TO_TIME

## Syntax

```sql
SEC_TO_TIME(seconds)
```

## Purpose

Returns the time value corresponding to the `seconds` argument. The result is limited to the range of the `TIME` data type.

## Examples

```sql
obclient> SELECT SEC_TO_TIME(2378);
+-------------------+
| SEC_TO_TIME(2378) |
+-------------------+
| 00:39:38          |
+-------------------+
1 row in set

obclient> SELECT SEC_TO_TIME(2378) + 0;
+-----------------------+
| SEC_TO_TIME(2378) + 0 |
+-----------------------+
|                  3938 |
+-----------------------+
1 row in set
```
