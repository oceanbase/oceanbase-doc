# PERIOD_ADD

## Syntax

```sql
PERIOD_ADD(P,N)
```

## Purpose

Adds `N` months to the period `P`. The format of `P` is `YYMM` or `YYYYMM`.

The return value is in the `YYYYMM` format.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The parameter <code>P</code> cannot be a <code>DATE</code> value. </p>
  </main>

## Examples

```sql
obclient> SELECT PERIOD_ADD(200801,2);
+----------------------+
| PERIOD_ADD(200801,2) |
+----------------------+
|               200803 |
+----------------------+
1 row in set
```
