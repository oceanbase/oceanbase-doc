# ADDDATE

## Syntax

### Syntax 1

```sql
ADDDATE(date, INTERVAL expr unit)
```

### Syntax 2

```sql
ADDDATE(expr, days)
```

## Purpose

* The first declaration of this function is a synonym for `DATE_ADD()`, which adds a specified time interval to the date value `date`. For more information about the `unit` parameter, see [DATE_ADD](../100.date-and-time-functions-of-mysql-mode/900.date-add-of-mysql-mode.md).
* The second declaration of this function adds `days` to the date specified by `expr`.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This function is a ClickHouse-compatible function. By default, it is disabled. You must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>.</p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Add 3 days to the specified date.

    ```shell
    obclient> SELECT ADDDATE('2026-03-30', 3);
    ```

    The return result is as follows:

    ```shell
    +--------------------------+
    | ADDDATE('2026-03-30', 3) |
    +--------------------------+
    | 2026-04-02 00:00:00.000  |
    +--------------------------+
    1 row in set
    ```

3. Add 1 hour and 30 minutes to the specified date and time.

    ```shell
    obclient> SELECT ADDDATE('2026-03-30 10:00:00', INTERVAL 90 MINUTE);
    ```

    The return result is as follows:

    ```shell
    +----------------------------------------------------+
    | ADDDATE('2026-03-30 10:00:00', INTERVAL 90 MINUTE) |
    +----------------------------------------------------+
    | 2026-03-30 11:30:00.000                            |
    +----------------------------------------------------+
    1 row in set
    ```
