# TIME

## Syntax

```javascript
TIME(datetime)
```

## Purpose

Returns the time information of `datetime` in `TIME` type.

## Examples

```javascript
obclient> SELECT TIME('2003-12-31 01:02:03');
+-----------------------------+
| TIME('2003-12-31 01:02:03') |
+-----------------------------+
| 01:02:03.000000             |
+-----------------------------+
1 row in set
```
