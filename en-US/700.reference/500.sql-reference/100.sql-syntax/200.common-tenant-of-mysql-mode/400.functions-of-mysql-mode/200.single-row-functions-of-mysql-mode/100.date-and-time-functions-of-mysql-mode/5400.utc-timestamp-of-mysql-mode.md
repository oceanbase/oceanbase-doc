# UTC_TIMESTAMP

## Syntax

```javascript
UTC_TIMESTAMP([fsp])
```

## Purpose

Returns the current UTC time in the `%Y-%m-%d %H:%i:%s` format.

The `fsp` parameter specifies the precision of seconds, and its value ranges from 0 to 6.

## Examples

```javascript
obclient> SELECT UTC_TIMESTAMP(), UTC_TIMESTAMP() + 0, UTC_TIMESTAMP() + 6;
+---------------------+---------------------+---------------------+
| UTC_TIMESTAMP()     | UTC_TIMESTAMP() + 0 | UTC_TIMESTAMP() + 6 |
+---------------------+---------------------+---------------------+
| 2021-07-13 13:10:28 |      20210713131028 |      20210713131034 |
+---------------------+---------------------+---------------------+
1 row in set
```
