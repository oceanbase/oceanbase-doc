# TIME_TO_USEC

## Syntax

```javascript
TIME_TO_USEC(date)
```

## Purpose

Converts the `date` value to the number of microseconds since `1970-01-01 00:00:00.000000`, taking into account the time zone.

`date` can represent a date or a datetime.

## Examples

```javascript
obclient> SELECT TIME_TO_USEC('2014-03-25'), TIME_TO_USEC(NOW());
+----------------------------+---------------------+
| TIME_TO_USEC('2014-03-25') | TIME_TO_USEC(NOW()) |
+----------------------------+---------------------+
|           1395676800000000 |    1525528100000000 |
+----------------------------+---------------------+
1 row in set
```
