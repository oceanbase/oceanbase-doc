# CURRENT_TIME

## Syntax

```javascript
CURRENT_TIME([scale])
```

## Purpose

Returns the current time without the date part.

`scale` specifies the precision of the microseconds part, which is an integer from `0` to `6`. The default value is `0`.

## Examples

```javascript
obclient> SELECT CURRENT_TIME(6);
+-----------------+
| CURRENT_TIME(6) |
+-----------------+
| 11:11:45.215311 |
+-----------------+
1 row in set
```
