# WEEKOFYEAR

## Syntax

```sql
WEEKOFYEAR(date)
```

## Purpose

Returns the week of the year for the `date` value of the `date` or `datetime` type.

## Examples

```sql
obclient> SELECT WEEKOFYEAR('2020-07-16');
+--------------------------+
| WEEKOFYEAR('2020-07-16') |
+--------------------------+
|                       29 |
+--------------------------+
1 row in set
```
