# UTC_TIME

## Syntax

```sql
UTC_TIME([fsp])
```

## Purpose

Returns the current UTC time in the `%H:%i:%s` format.

The `fsp` parameter specifies the precision of the seconds, with a value between 0 and 6.

## Examples

```sql
obclient> SELECT UTC_TIME(), UTC_TIME() + 0, UTC_TIME() + 6;
+------------+----------------+----------------+
| UTC_TIME() | UTC_TIME() + 0 | UTC_TIME() + 6 |
+------------+----------------+----------------+
| 13:07:35   |         130735 |         130741 |
+------------+----------------+----------------+
1 row in set
```
