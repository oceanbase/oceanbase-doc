# DAYNAME

## Syntax

```sql
DAYNAME(date)
```

## Purpose

Returns the name of the weekday corresponding to the date.

## Examples

```sql
obclient> SELECT DAYNAME('2022-09-08');
+-----------------------+
| DAYNAME('2022-09-08') |
+-----------------------+
| Thursday              |
+-----------------------+
1 row in set
```
