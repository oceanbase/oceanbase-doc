# YEAR

## Syntax

```sql
YEAR(date)
```

## Purpose

Returns the year part of the `date` value.

## Examples

```sql
obclient> SELECT YEAR('1987-01-01');
+--------------------+
| YEAR('1987-01-01') |
+--------------------+
|               1987 |
+--------------------+
1 row in set
```
