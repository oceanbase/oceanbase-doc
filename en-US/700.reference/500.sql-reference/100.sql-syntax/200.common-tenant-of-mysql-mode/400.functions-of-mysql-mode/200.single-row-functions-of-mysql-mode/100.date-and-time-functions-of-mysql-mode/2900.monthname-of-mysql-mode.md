# MONTHNAME

## Syntax

```sql
MONTHNAME(date)
```

## Purpose

Returns the full name of the month for the specified date `date`.

## Examples

```sql
obclient> SELECT MONTHNAME('2008-02-03');
+-------------------------+
| MONTHNAME('2008-02-03') |
+-------------------------+
| February                |
+-------------------------+
1 row in set
```
