# TIME_TO_SEC

## Syntax

```sql
TIME_TO_SEC(time)
```

## Purpose

Converts the `time` parameter of the time type to seconds.

## Examples

```sql
obclient> SELECT TIME_TO_SEC('22:23:00');
+-------------------------+
| TIME_TO_SEC('22:23:00') |
+-------------------------+
|                   80580 |
+-------------------------+
1 row in set

obclient> SELECT TIME_TO_SEC('00:39:38');
+-------------------------+
| TIME_TO_SEC('00:39:38') |
+-------------------------+
|                    2378 |
+-------------------------+
1 row in set
```
