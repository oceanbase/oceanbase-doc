# FORMATDATETIME

<main id="notice" type='explain'>
  <h4>Considerations</h4>
  <p>This function was introduced in version V4.6.0. </p>
</main>

## Syntax

```sql
FORMATDATETIME(date, format)
```

## Purpose

The `FORMATDATETIME` function takes a date or date-time expression `date` and a format string `format` and returns a string that represents `date` in the specified `format`. For example, `FORMATDATETIME(date, '%Y-%m-%d %H:%i:%s')`.

<main id="notice" type='notice'>
  <h4>Important</h4>
  <p>This function is compatible with ClickHouse. By default, it is not enabled. To enable it, you must set the <code>sql_func_extension_mode</code> parameter. For more information, see <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>.</p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Format the current date and time into the `YYYY-MM-DD HH:MI:SS` format.

    ```shell
    obclient> SELECT FORMATDATETIME(NOW(), '%Y-%m-%d %H:%i:%s') AS formatted_date;
    ```

    The return result is as follows:

    ```shell
    +---------------------------------+
    | formatted_date                  |
    +---------------------------------+
    | March 30, 2026 10:44:53     |
    +---------------------------------+
    1 row in set
    ```
