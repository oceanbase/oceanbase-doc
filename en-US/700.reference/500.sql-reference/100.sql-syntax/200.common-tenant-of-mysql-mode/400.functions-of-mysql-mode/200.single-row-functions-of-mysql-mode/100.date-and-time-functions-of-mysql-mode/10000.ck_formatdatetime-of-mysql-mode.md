# FORMATDATETIME

<main id="notice" type='explain'>
  <h4>Purpose</h4>
  <p>This function is introduced in V4.6.0. </p>
</main>

## Syntax

```sql
FORMATDATETIME(date, format)
```

## Purpose

This function formats a date or date time expression `date` in a specified format string `format` and returns a formatted string. For example, `FORMATDATETIME(date, '%Y-%m-%d %H:%i:%s')`.

<main id="notice" type='notice'>
  <h4>Warning</h4>
  <p>This function is a ClickHouse compatible function. It is disabled by default. To enable it, set the <code>sql_func_extension_mode</code> parameter to <code>ON</code>. For more information, see <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>.</p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Format the current date and time in the `YYYY-MM-DD HH:MI:SS` format.

    ```shell
    obclient> SELECT FORMATDATETIME(NOW(), '%Y year %m month %d day %H:%i:%s') AS formatted_date;
    ```

    The returned result is as follows:

    ```shell
    +---------------------------------+
    | formatted_date                  |
    +---------------------------------+
    | 2026 March 30 10:44:53    |
    +---------------------------------+
    1 row in set
    ```
