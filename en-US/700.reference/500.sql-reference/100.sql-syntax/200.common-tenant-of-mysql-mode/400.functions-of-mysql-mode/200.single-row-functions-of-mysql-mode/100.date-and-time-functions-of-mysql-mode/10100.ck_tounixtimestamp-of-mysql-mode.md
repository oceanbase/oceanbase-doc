# TOUNIXTIMESTAMP

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting from V4.6.0. </p>
</main>

## Syntax

```sql
TOUNIXTIMESTAMP(datetime)
```

## Purpose

This function converts a datetime expression `datetime` to a Unix timestamp (the number of seconds since '1970-01-01 00:00:00' UTC). If the parameter is of the `DATE` type, the time part is by default set to midnight (00:00:00).

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is not enabled. You must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <strong>sql_func_extension_mode</strong>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode. 

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Return an integer timestamp. 

    ```shell
    obclient> SELECT TOUNIXTIMESTAMP('2026-03-30 12:00:00');
    ```

    The return result is as follows:

    ```shell
    +----------------------------------------+
    | TOUNIXTIMESTAMP('2026-03-30 12:00:00') |
    +----------------------------------------+
    |                             1774843200 |
    +----------------------------------------+
    1 row in set
    ```

3. Return the Unix timestamp for midnight of the current day. 

    ```shell
    obclient> SELECT TOUNIXTIMESTAMP(DATE '2026-03-30');
    ```

    The return result is as follows:

    ```shell
    +------------------------------------+
    | TOUNIXTIMESTAMP(DATE '2026-03-30') |
    +------------------------------------+
    |                         1774800000 |
    +------------------------------------+
    1 row in set
    ```
