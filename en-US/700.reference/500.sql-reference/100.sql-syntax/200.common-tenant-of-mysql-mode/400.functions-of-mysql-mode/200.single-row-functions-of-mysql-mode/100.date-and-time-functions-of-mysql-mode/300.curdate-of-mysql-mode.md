# CURDATE

## Syntax

```javascript
CURDATE()
```

## Purpose

Returns the current date without the time component.

## Examples

```javascript
obclient> SELECT CURDATE();
+------------+
| CURDATE()  |
+------------+
| 2018-05-05 |
+------------+
1 row in set
```
