# DAYOFMONTH

## Syntax

```sql
DAYOFMONTH(date)
```

## Purpose

Returns the position of the date or datetime `date` in the month.

## Examples

```sql
obclient> SELECT DAYOFMONTH('2008-12-31');
+--------------------------+
| DAYOFMONTH('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
```
