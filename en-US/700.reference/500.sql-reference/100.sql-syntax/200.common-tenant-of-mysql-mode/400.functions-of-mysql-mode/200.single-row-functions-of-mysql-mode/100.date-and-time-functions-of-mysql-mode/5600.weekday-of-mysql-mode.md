# WEEKDAY

## Syntax

```sql
WEEKDAY(date)
```

## Purpose

Returns the position of a `date` value in the week.

## Examples

```sql
obclient> SELECT WEEKDAY('2021-07-16 00:00:00');
+--------------------------------+
| WEEKDAY('2020-07-16 00:00:00') |
+--------------------------------+
|                              5 |
+--------------------------------+
1 row in set
```
