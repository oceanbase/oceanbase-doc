# SECOND

## Syntax

```sql
SECOND(time)
```

## Purpose

Returns the number of seconds in the `time` value.

## Examples

```sql
obclient> SELECT SECOND('18:20:17');
+--------------------+
| SECOND('18:20:17') |
+--------------------+
|                 17 |
+--------------------+
1 row in set
```
