# DAYOFYEAR

## Syntax

```sql
DAYOFYEAR(date)
```

## Purpose

Returns the position of the date or datetime `date` in the year.

## Examples

```sql
obclient> SELECT DAYOFYEAR('2021-07-15');
+-------------------------+
| DAYOFYEAR('2021-07-15') |
+-------------------------+
|                     196 |
+-------------------------+
1 row in set
```
