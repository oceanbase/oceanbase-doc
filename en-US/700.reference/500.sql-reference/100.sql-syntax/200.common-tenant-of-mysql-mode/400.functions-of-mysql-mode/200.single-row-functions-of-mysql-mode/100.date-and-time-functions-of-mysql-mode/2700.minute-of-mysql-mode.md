# MINUTE

## Syntax

```sql
MINUTE(time)
```

## Purpose

Returns the number of minutes in the `time` value.

## Examples

```sql
obclient> SELECT MINUTE('18:20:17');
+--------------------+
| MINUTE('18:20:17') |
+--------------------+
|                 20 |
+--------------------+
1 row in set
```
