# DATE_TRUNC

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting from V4.6.0. </p>
</main>

## Syntax

```sql
DATE_TRUNC(precision, source)
```

## Purpose

This function truncates the datetime `source` to the specified `precision` level (such as `year`, `month`, `day`, or `hour`) and returns the value at the beginning of the time unit.

## Examples

Truncate `2026-03-24 14:30:00` to the month precision by using `date_trunc`.

```shell
obclient> SELECT date_trunc('month', timestamp '2026-03-24 14:30:00');
```

The result is as follows:

```shell
+------------------------------------------------------+
| date_trunc('month', timestamp '2026-03-24 14:30:00') |
+------------------------------------------------------+
| 2026-03-01 00:00:00                                  |
+------------------------------------------------------+
1 row in set
```
