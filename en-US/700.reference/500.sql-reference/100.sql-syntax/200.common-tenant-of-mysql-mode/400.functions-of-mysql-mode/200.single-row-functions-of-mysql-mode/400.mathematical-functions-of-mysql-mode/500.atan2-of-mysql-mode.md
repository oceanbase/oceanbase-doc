# ATAN2

## Syntax

```sql
ATAN2(X,Y)
```

## Purpose

Returns the arctangent of `X` and `Y`. It is similar to computing the arctangent of `Y/X`, but the signs of both parameters are used to determine the quadrant of the result.

This function can also be written as `ATAN(X,Y)`. See [ATAN](../400.mathematical-functions-of-mysql-mode/400.atan-of-mysql-mode.md).

## Examples

```sql
obclient> SELECT ATAN(PI(),0);
+--------------------+
| ATAN(PI(),0)       |
+--------------------+
| 1.5707963267948966 |
+--------------------+
1 row in set
```
