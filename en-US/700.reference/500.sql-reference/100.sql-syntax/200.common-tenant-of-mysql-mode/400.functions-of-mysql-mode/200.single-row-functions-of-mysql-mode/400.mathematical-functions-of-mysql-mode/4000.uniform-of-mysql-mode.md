# UNIFORM

## Syntax

```sql
UNIFORM(<min> , <max> , <gen>)
```

## Purpose

This function returns an integer or a float value that follows a uniform distribution.

* `min` and `max` must be scalar values that do not change with row iteration. For example, constants and scalar functions. In PL, they can also be expressions like `@v1` or `1+@v3`.
* In MySQL mode, if both `min` and `max` are integers, the output of the `UNIFORM()` function is an integer. Otherwise, the output is a float.
* `gen` is a value generation function, typically using the `RANDOM()` function. If the input value is a constant, the `UNIFORM()` function returns a fixed value.

## Examples

The following example generates an integer between 1 and 10 uniformly.

```shell
obclient> SELECT v, COUNT(*) FROM (SELECT UNIFORM(1, 10, RANDOM()) v FROM TABLE(GENERATOR(1000000))) x GROUP BY v ORDER BY v;
+------+----------+
| v    | count(*) |
+------+----------+
|    1 |   100738 |
|    2 |   100119 |
|    3 |   100223 |
|    4 |    99537 |
|    5 |   100125 |
|    6 |   100001 |
|    7 |   100275 |
|    8 |    99235 |
|    9 |    99837 |
|   10 |    99910 |
+------+----------+
10 rows in set
```

The following example shows that the result type depends on the parameter type.

