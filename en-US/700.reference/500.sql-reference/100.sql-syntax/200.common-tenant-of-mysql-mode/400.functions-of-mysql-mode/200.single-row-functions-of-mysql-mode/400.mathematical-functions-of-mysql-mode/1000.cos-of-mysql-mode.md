# COS

## Syntax

```sql
COS(X)
```

## Purpose

Returns the cosine of the given radians `X`.

## Examples

```sql
obclient> SELECT COS(PI());
+-----------+
| COS(PI()) |
+-----------+
|        -1 |
+-----------+
1 row in set
```
