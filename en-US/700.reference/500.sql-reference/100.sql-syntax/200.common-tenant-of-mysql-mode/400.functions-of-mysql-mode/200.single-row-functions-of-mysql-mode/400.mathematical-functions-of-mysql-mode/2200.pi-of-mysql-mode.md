# PI

## Syntax

```sql
PI()
```

## Purpose

Returns the value of `π` (pi).

## Examples

```sql
obclient> SELECT PI();
+----------+
| PI()     |
+----------+
| 3.141593 |
+----------+
1 row in set

obclient> SELECT ROUND(2*PI(),2);
+----------------+
| ROUND(2*PI(),2)|
+----------------+
| 6.28           |
+----------------+
1 row in set
```
