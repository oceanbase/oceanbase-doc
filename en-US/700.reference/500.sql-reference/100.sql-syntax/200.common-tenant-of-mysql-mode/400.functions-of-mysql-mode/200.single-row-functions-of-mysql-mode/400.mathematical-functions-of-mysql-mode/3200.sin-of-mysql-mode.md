# SIN

## Syntax

```sql
SIN(X)
```

## Purpose

Returns the sine of the given radians `X`.

## Examples

```sql
obclient> SELECT SIN(PI());
+------------------------+
| SIN(PI())              |
+------------------------+
| 1.2246467991473532e-16 |
+------------------------+
1 row in set
```
