# POWER

## Syntax

```sql
POWER(X,Y)
```

## Purpose

Returns the value of `X` raised to the power of `Y`. This function is an alias for `POW()`.

If either `X` or `Y` is `NULL`, the result is `NULL`.

## Examples

```sql
obclient> SELECT POWER(2,8);
+------------+
| POWER(2,8) |
+------------+
|        256 |
+------------+
1 row in set
```
