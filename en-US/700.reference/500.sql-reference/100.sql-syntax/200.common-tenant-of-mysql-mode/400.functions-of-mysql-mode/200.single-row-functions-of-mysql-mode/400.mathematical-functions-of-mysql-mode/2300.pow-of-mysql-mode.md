# POW

## Syntax

```sql
POW(X,Y)
```

## Purpose

Returns the value of `X` raised to the power of `Y`.

If either `X` or `Y` is `NULL`, the result is `NULL`.

## Examples

```sql
obclient> SELECT POW(4,2), POW(4,-2), POW(1,NULL);
+----------+-----------+-------------+
| POW(4,2) | POW(4,-2) | POW(1,NULL) |
+----------+-----------+-------------+
|       16 |    0.0625 |        NULL |
+----------+-----------+-------------+
1 row in set
```
