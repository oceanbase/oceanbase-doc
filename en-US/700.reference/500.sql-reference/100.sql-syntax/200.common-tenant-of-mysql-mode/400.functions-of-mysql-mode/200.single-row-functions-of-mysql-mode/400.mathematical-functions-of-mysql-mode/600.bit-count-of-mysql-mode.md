# BIT_COUNT

## Syntax

```sql
BIT_COUNT(N)
```

## Purpose

Returns the number of `1` bits in the binary representation of `N`. If `N` is `NULL`, it returns `NULL`.

## Examples

```sql
obclient> SELECT BIT_COUNT(42), BIT_COUNT(b'1010');
+---------------+--------------------+
| BIT_COUNT(42) | BIT_COUNT(b'1010') |
+---------------+--------------------+
|             3 |                  2 |
+---------------+--------------------+
1 row in set
```
