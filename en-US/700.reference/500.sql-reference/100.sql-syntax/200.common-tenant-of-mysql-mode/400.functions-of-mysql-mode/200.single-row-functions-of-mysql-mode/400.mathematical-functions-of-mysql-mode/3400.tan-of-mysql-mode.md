# TAN

## Syntax

```sql
TAN(X)
```

## Purpose

Returns the tangent of the given radians X.

## Examples

```sql
obclient> SELECT TAN(PI());
+-------------------------+
| TAN(PI())               |
+-------------------------+
| -1.2246467991473532e-16 |
+-------------------------+
1 row in set
```
