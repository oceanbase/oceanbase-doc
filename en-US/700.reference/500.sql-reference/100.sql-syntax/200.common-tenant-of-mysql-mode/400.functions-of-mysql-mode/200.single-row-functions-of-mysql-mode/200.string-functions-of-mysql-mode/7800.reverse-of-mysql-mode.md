# REVERSE

## Syntax

```sql
REVERSE(str)
```

## Purpose

Returns the reverse of the string `str`.

This function is multibyte-safe.

## Examples

```sql
obclient> SELECT REVERSE('oceanbase');
+----------------------+
| REVERSE('oceanbase') |
+----------------------+
| esabnaeco            |
+----------------------+
1 row in set

obclient> SELECT REVERSE(1000);
+---------------+
| REVERSE(1000) |
+---------------+
| 0001          |
+---------------+
1 row in set
```
