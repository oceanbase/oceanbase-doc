# EDITDISTANCE

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting from V4.6.0. </p>
</main>

## Syntax

```sql
EDITDISTANCE(string1, string2)
```

## Purpose

This function calculates the edit distance between two strings `string1` and `string2`. The edit distance is the minimum number of single-character edits (insertions, deletions, or substitutions) required to convert one string into the other.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is not enabled. To use it, you must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <strong>sql_func_extension_mode</strong>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Calculate the edit distance between the strings `Base` and `OceanBase`.

    ```shell
    obclient> SELECT EDITDISTANCE('Base', 'OceanBase');
    ```

    The returned result is as follows:

    ```shell
    +-----------------------------------+
    | EDITDISTANCE('Base', 'OceanBase') |
    +-----------------------------------+
    |                                 5 |
    +-----------------------------------+
    1 row in set
    ```
