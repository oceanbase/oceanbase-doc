# REGEXP_REPLACE

## Syntax

```sql
REGEXP_REPLACE(expr, pat, repl[, pos[, occurrence[, match_type]]])
```

## Purpose

Replaces substrings in the string `expr` that match `pat` with the string specified by `repl` and returns the modified string. If `expr`, `pat`, or `repl` is `NULL`, the function returns `NULL`.

* `pos` specifies the starting position in the expression `expr` for the search, with a default value of `1`.

* `occurrence` specifies the number of the match to replace with `repl`. The default value of `0` indicates that all matching substrings are replaced.

* `match_type` specifies the matching rules. For more information about the matching rules, see [REGEXP_LIKE](../200.string-functions-of-mysql-mode/7300.regexp-like-of-mysql-mode.md).

