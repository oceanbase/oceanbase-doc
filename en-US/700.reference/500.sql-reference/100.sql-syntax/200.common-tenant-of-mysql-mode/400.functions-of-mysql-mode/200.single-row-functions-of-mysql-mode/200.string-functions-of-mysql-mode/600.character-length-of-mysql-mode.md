# CHARACTER_LENGTH

## Syntax

```sql
CHARACTER_LENGTH(str)
```

## Purpose

`CHARACTER_LENGTH()` is an alias for `CHAR_LENGTH()`.

## Examples

```sql
obclient> SELECT CHARACTER_LENGTH('China'), LENGTH('China'),CHARACTER_LENGTH('hello');
+----------------------------+------------------+---------------------------+
| CHARACTER_LENGTH('China')  | LENGTH('China')  | CHARACTER_LENGTH('hello') |
+----------------------------+------------------+---------------------------+
|                          2 |                6 |                         5 |
+----------------------------+------------------+---------------------------+
1 row in set
```
