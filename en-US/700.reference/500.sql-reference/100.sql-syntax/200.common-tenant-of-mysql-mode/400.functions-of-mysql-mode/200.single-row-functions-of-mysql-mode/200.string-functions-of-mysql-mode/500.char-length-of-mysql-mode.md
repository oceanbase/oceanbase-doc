# CHAR_LENGTH

## Syntax

```sql
CHAR_LENGTH(str)
```

## Purpose

Returns the number of characters in the string `str`.

For multi-byte characters, each character is counted as one, for example, if the input is five 2-byte characters, `LENGTH()` returns `10`, while `CHAR_LENGTH()` returns `5`.

## Examples

```sql
obclient> SELECT CHAR_LENGTH('China'), LENGTH('China'),CHAR_LENGTH('hello');
+-----------------------+------------------+----------------------+
| CHAR_LENGTH('China')  | LENGTH('China')  | CHAR_LENGTH('hello') |
+-----------------------+------------------+----------------------+
|                     2 |                6 |                    5 |
+-----------------------+------------------+----------------------+
1 row in set
```
