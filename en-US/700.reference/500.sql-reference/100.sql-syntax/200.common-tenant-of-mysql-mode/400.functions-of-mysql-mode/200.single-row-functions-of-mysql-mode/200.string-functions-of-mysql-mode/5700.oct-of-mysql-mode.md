# OCT

## Syntax

```sql
OCT(N)
```

## Purpose

Returns the octal value of `N`. This function is equivalent to `CONV(N,10,8)`.

If `N` is `NULL`, this function returns `NULL`.

## Examples

```sql
obclient> SELECT OCT(12);
+---------+
| OCT(12) |
+---------+
| 14      |
+---------+
1 row in set
```
