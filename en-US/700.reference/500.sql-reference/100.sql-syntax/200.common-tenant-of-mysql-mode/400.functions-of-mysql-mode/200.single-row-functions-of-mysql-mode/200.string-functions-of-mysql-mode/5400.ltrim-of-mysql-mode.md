# LTRIM

## Syntax

```sql
LTRIM(str)
```

## Purpose

Removes leading spaces from a string.

## Examples

```sql
obclient> SELECT LTRIM('    obclient    ') AS ltrim;
+--------------+
| ltrim        |
+--------------+
| obclient     |
+--------------+
1 row in set
```
