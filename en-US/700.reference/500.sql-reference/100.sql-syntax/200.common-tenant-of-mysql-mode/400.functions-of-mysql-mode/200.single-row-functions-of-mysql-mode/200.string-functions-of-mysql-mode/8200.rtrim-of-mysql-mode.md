# RTRIM

## Syntax

```sql
RTRIM(str)
```

## Purpose

Removes trailing spaces from the string `str`.

## Examples

```sql
obclient> SELECT RTRIM('    obclient    ') AS rtrim;
+--------------+
| rtrim        |
+--------------+
|     obclient |
+--------------+
1 row in set
```
