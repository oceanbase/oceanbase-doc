# TO_BASE64

## Syntax

```sql
TO_BASE64(str)
```

## Purpose

Converts a string parameter to base-64 encoding. You can use the `FROM_BASE64` function to decode a base-64 encoded string. For more information, see [FROM_BASE64()](../200.string-functions-of-mysql-mode/9400.from-base64-of-mysql-mode.md).

## Examples

```sql
obclient> SELECT TO_BASE64('OB');
+-----------------+
| TO_BASE64('OB')
+-----------------+
| T0I=            |
+-----------------+
1 row in set
```
