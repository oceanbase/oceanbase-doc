# LOWER

## Syntax

```sql
LOWER(str)
```

## Purpose

Converts uppercase letters to lowercase letters in a string.

The `LOWER()` function is a synonym for `LCASE()`.

## Examples

```sql
obclient> SELECT LOWER('OBCLIENTHello!');
+-----------------------------+
| LOWER('OBCLIENTHello！') |
+-----------------------------+
| Hello obclient!         |
+-----------------------------+
1 row in set
```
