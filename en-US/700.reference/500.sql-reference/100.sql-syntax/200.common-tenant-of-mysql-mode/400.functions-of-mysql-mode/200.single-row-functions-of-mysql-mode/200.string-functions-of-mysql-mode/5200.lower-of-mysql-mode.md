# LOWER

## Syntax

```sql
LOWER(str)
```

## Purpose

Converts uppercase letters in a string to lowercase.

This function is a synonym for `LCASE()`.

## Examples

```sql
obclient> SELECT LOWER('OBCLIENT Hello!');
+-----------------------------+
| LOWER('OBCLIENT Hello!') |
+-----------------------------+
| obclient! |
+-----------------------------+
1 row in set
```
