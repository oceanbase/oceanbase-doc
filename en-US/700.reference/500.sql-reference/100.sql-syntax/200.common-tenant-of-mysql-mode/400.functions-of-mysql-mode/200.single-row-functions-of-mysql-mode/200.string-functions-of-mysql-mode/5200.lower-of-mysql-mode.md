# LOWER

## Syntax

```sql
LOWER(str)
```

## Purpose

Convert uppercase letters in the string to lowercase letters.

It is a synonym for the `LCASE()` function.

## Examples

```sql
obclient> SELECT LOWER('OBCLIENTHello!');
+-----------------------------+
| LOWER('OBCLIENT hello!') |
+-----------------------------+
| Hello!           |
+-----------------------------+
1 row in set
```
