# REGEXP

## Syntax

```sql
str [NOT] REGEXP | RLIKE pat
```

## Purpose

The regular expression matches. If the parameter contains `NULL`, `NULL` is returned.

## Examples

```sql
obclient> SELECT
     1234 REGEXP 1,
     'hello' RLIKE 'h%'
     \G
*************************** 1. row ***************************
     1234 REGEXP 1: 1
'hello' RLIKE 'h%': 0
1 row in set
```
