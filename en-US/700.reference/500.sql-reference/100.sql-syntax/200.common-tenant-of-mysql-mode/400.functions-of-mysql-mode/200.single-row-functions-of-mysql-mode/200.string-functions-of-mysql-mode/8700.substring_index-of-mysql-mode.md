# SUBSTRING_INDEX

## Syntax

```sql
SUBSTRING_INDEX(str, delim, count)
```

## Purpose

Returns a substring from the string `str` before the `delim` delimiter and the `count` occurrence.

* If `count` is positive, it returns the substring before the `count`th occurrence of the delimiter, starting from the left.

* If `count` is negative, it returns the substring after the `count`th occurrence of the delimiter, starting from the right.

* If any parameter is `NULL`, it returns `NULL`.

* If `str` or `delim` is an empty string, it returns an empty string.

* If `count=0`, it also returns an empty string.

* The `str`, `delim`, and `count` parameters support implicit conversion between numeric and string types.
