# MAX_PT

## Purpose

This function returns the maximum value of the partitioning key among the partitions that contain data in a partitioned table.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is supported starting from OceanBase Database V4.4.2 BP3. </p>
</main>

## Limitations and considerations

* The caller must have the **SELECT** privilege on the target table (MySQL-compatible mode checks the table-level privilege). Otherwise, the call fails.
* Table names in parameters must be **constants** (string literals that can be determined during parsing). Variables or non-constant expressions are not supported as table name parameters.
* The table to be queried must be a partitioned table with a partition type of **RANGE** or **LIST**.
* The table to be queried must be an **internal table**. External tables and DBLink are not supported.
* Only **single-column** partitioning keys are supported; **multi-column** partitioning keys are not supported.
* **Expression partitioning** is not supported. If the partitioning key is not a direct reference to a single column but an expression in the partition definition, `MAX_PT` cannot be used.
* For a subpartitioned table, only the values of the first-level partitions are returned.
* If all partitions are empty, NULL is returned.
* If different partition values exist in the same partition, the result of `MAX_PT` is `undefined`, and a value from any row in that partition will be returned.

## Syntax

```sql
MAX_PT('[database_name.]table_name')
```

## Parameters

* `database_name`: Optional. The name of the database where the table is located. If not specified, the table is in the default database of the **current session**. You can also specify both the database and table names in the first string parameter in the `'db_name.table_name'` format (separated by at most one `.`).
* `table_name`: The name of the table. The database and table names are resolved according to the current session's case-sensitivity policy and valid character rules, and must match the names stored in the data dictionary (including case).

## Return type

Returns the maximum partition value (compared by using the `max()` logic) among the partitions that contain data. The data type is the same as the partitioning key type.

## Examples

1. Create a partitioned table named `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY LIST (col1) (
            PARTITION P0 VALUES IN (1),
            PARTITION P1 VALUES IN (2),
            PARTITION P2 VALUES IN (3),
            PARTITION P3 VALUES IN (4)
        );
    ```

2. Insert test data.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1,1,1),
        (2,2,2),
        (3,3,3),
        (4,4,4),
        (1,1,2),
        (2,2,2);
    ```

    The return result is as follows:

    ```shell
    Query OK, 6 rows affected
    Records: 6  Duplicates: 0  Warnings: 0
    ```

3. View the maximum value of the partitioning key for the partition containing data in table `test_tbl1`.

    ```shell
    obclient> SELECT MAX_PT('test_tbl1');
    ```

    The return result is as follows:

    ```shell
    +---------------------+
    | MAX_PT('test_tbl1') |
    +---------------------+
    |                   4 |
    +---------------------+
    1 row in set
    ```
