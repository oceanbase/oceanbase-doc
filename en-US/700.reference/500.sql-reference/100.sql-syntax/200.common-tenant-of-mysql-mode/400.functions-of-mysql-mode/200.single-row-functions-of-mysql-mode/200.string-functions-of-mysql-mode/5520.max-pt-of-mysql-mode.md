# MAX_PT

This function returns the maximum value of the partitioning key for partitions that contain data in a partitioned table.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function was introduced in V4.6.0 of the V4.6.x series. </p>
</main>

## Limitations and considerations

* The table must be a partitioned table with either RANGE or LIST partitioning.
* The table must be an internal table. External tables and DBLinks are not supported.
* Only single-column partitioning keys are supported. Multi-column or expression-based partitioning keys are not supported.
* For a subpartitioned table, only the values of the primary partitions are returned.
* If all partitions are empty, NULL is returned.
* If different partitioning key values exist in the same partition, the result of `MAX_PT` is `undefined`, and the value of any row in the partition is returned.

## Syntax

```sql
MAX_PT('[database_name.]table_name')
```

## Parameters

* `database_name`: Optional. The name of the database where the table is located. If not specified, the table in the current login database is used.
* `table_name`: The name of the table.

## Return value

The maximum value of the partitioning key for partitions that contain data, based on the `max()` comparison logic. The data type of the return value is the same as the partitioning key.

## Examples

1. Create a partitioned table named `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY LIST (col1) (
            PARTITION P0 VALUES IN (1),
            PARTITION P1 VALUES IN (2),
            PARTITION P2 VALUES IN (3),
            PARTITION P3 VALUES IN (4)
        );
    ```

2. Insert test data.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1,1,1),
        (2,2,2),
        (3,3,3),
        (4,4,4),
        (1,1,2),
        (2,2,2);
    ```

    The return result is as follows:

    ```shell
    Query OK, 6 rows affected
    Records: 6  Duplicates: 0  Warnings: 0
    ```

3. Query the maximum value of the partitioning key for partitions that contain data in the `test_tbl1` table.

    ```shell
    obclient> SELECT MAX_PT('test_tbl1');
    ```

    The return result is as follows:

    ```shell
    +---------------------+
    | MAX_PT('test_tbl1') |
    +---------------------+
    |                   4 |
    +---------------------+
    1 row in set
    ```
