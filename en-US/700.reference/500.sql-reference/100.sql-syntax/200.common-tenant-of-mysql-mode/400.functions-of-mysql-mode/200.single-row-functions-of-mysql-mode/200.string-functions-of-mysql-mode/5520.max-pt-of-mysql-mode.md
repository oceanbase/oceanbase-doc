# MAX_PT

## Purpose

This function returns the maximum partition key value of a partitioned table that contains data.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting from V4.6.0 in V4.6.x versions. </p>
</main>

## Limitations and considerations

* The table must be a partitioned table with RANGE or LIST partitioning.
* The table must be an internal table. External tables and DBLink tables are not supported.
* Only single-column partitioning is supported. Multi-column or expression-based partitioning is not supported.
* For a subpartitioned table, only the values of the primary partitions are returned.
* If all partitions are empty, NULL is returned.
* If different partition values exist in the same partition, the `MAX_PT` result is `undefined`, and the value of a randomly selected row from the partition is returned.

## Syntax

```sql
MAX_PT('[database_name.]table_name')
```

## Parameters

* `database_name`: Optional. The name of the database where the table is located. If not specified, the default is the current login database.
* `table_name`: The name of the table.

## Return value

Returns the maximum partition key value of a partitioned table that contains data, based on the `max()` comparison logic. The data type of the return value is the same as that of the partition key.

## Examples

1. Create a partitioned table named `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY LIST (col1) (
            PARTITION P0 VALUES IN (1),
            PARTITION P1 VALUES IN (2),
            PARTITION P2 VALUES IN (3),
            PARTITION P3 VALUES IN (4)
        );
    ```

2. Insert test data.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1,1,1),
        (2,2,2),
        (3,3,3),
        (4,4,4),
        (1,1,2),
        (2,2,2);
    ```

    The return result is as follows:

    ```shell
    Query OK, 6 rows affected
    Records: 6  Duplicates: 0  Warnings: 0
    ```

3. Query the maximum partition key value of the partitioned table `test_tbl1` that contains data.

    ```shell
    obclient> SELECT MAX_PT('test_tbl1');
    ```

    The return result is as follows:

    ```shell
    +---------------------+
    | MAX_PT('test_tbl1') |
    +---------------------+
    |                   4 |
    +---------------------+
    1 row in set
    ```
