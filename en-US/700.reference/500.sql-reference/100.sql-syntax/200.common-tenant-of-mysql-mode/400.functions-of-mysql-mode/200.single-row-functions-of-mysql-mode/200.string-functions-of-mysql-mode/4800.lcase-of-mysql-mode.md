# LCASE

## Syntax

```sql
LCASE(str)
```

## Purpose

Convert uppercase letters in the string to lowercase letters.

The `LOWER()` function is a synonym for the `LOWER` function.

## Examples

```sql
obclient> SELECT LCASE('OBCLIENTHello!');
+----------------------------+
| LCASE('OBCLIENTHello!')    |
+----------------------------+
| obclient!              |
+----------------------------+
1 row in set
```
