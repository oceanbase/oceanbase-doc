# LCASE

## Syntax

```sql
LCASE(str)
```

## Purpose

Convert the string to lowercase.

This function is a synonym for the `LOWER()` function.

## Examples

```sql
obclient> SELECT LCASE('OBCLIENTHello!');
+----------------------------+
| LCASE('OBCLIENT Hello!')    |
+----------------------------+
| Hello, obclient!             |
+----------------------------+
1 row in set
```
