# LCASE

## Syntax

```sql
LCASE(str)
```

## Purpose

Convert the characters in the string to lowercase.

The function is a synonym for `LOWER()`.

## Examples

```sql
obclient> SELECT LCASE('OBCLIENTHello!');
+----------------------------+
| LCASE('OBCLIENT hello!')    |
+----------------------------+
| Hi, obclient!             |
+----------------------------+
1 row in set
```
