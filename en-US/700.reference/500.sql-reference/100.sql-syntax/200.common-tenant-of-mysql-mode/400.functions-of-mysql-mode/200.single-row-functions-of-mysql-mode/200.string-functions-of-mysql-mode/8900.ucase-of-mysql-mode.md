# UCASE

## Syntax

```sql
UCASE(str)
```

## Purpose

Converts lowercase letters in the string `str` to uppercase. This function is synonymous with the `UPPER()` function.

## Examples

```sql
obclient> SELECT UCASE('obclientHello!');
+----------------------------+
| UCASE('obclientHello!')    |
+----------------------------+
| OBCLIENT Hello!             |
+----------------------------+
1 row in set
```
