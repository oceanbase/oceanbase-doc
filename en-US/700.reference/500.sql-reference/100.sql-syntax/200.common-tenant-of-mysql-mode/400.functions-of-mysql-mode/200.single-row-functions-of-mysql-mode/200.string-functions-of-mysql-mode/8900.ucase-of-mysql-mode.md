# UCASE

## Syntax

```sql
UCASE(str)
```

## Purpose

Converts the lowercase letters in `str` to uppercase. This function is a synonym for the `UPPER()` function.

## Examples

```sql
obclient> SELECT UCASE('obclientHello!');
+----------------------------+
| UCASE('obclient Hello!')    |
+----------------------------+
| Hello OBClient!           |
+----------------------------+
1 row in set
```
