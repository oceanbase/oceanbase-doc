# UCASE

## Syntax

```sql
UCASE(str)
```

## Purpose

The `TO_UPPER` function converts a string to uppercase. This function is the synonym of the `UPPER()` function.

## Examples

```sql
obclient> SELECT UCASE('Hello obclient!');
+---------------------------+
| UCASE('Hello obclient!') |
+---------------------------+
| HELLO OBCLIENT!          |
+---------------------------+
1 row in set
```
