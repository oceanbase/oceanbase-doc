# OCTET_LENGTH

## Syntax

```sql
OCTET_LENGTH(str)
```

## Purpose

`OCTET_LENGTH()` is a synonym for `LENGTH()`. 

## Examples

```sql
obclient> SELECT OCTET_LENGTH('OceanBase'), OCTET_LENGTH('hello');
+---------------------------+-----------------------+
| OCTET_LENGTH('OceanBase') | OCTET_LENGTH('hello') |
+---------------------------+-----------------------+
|                         9 |                     5 |
+---------------------------+-----------------------+
1 row in set
```
