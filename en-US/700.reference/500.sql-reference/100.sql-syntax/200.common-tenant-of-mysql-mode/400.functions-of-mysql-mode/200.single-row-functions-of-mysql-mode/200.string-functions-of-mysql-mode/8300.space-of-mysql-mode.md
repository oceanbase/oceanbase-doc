# SPACE

## Syntax

```sql
SPACE(N)
```

## Purpose

Returns a string containing `N` spaces.

## Examples

Returns a string containing 5 spaces.

```sql
obclient> SELECT SPACE(5);
+----------+
| SPACE(5) |
+----------+
|          |
+----------+
1 row in set
```
