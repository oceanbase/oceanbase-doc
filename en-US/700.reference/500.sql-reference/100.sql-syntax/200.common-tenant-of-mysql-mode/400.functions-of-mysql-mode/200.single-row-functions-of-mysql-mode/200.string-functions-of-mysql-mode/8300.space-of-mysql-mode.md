# SPACE

## Syntax

```sql
SPACE(N)
```

## Purpose

`SPACE()` returns a string with `N` space characters.

## Examples

Return a string with five spaces.

```sql
obclient> SELECT SPACE(5);
+----------+
| SPACE(5) |
+----------+
|          |
+----------+
1 row in set
```
