# UPPER

## Syntax

```sql
UPPER(str)
```

## Purpose

Converts lowercase letters in the string `str` to uppercase.

## Examples

```sql
obclient> obclient> SELECT UPPER('obclient Hello!');
+----------------------------+
| UPPER('obclient Hello!') |
+----------------------------+
| OBCLIENT: Hello!             |
+----------------------------+
1 row in set
```
