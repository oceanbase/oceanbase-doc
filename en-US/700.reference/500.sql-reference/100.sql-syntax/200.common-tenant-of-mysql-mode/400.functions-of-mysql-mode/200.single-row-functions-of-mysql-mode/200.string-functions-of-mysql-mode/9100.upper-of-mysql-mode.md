# UPPER

## Syntax

```sql
UPPER(str)
```

## Purpose

The string `str` is converted to uppercase letters.

## Examples

```sql
obclient> obclient> SELECT UPPER('obclient Hello!');
+----------------------------+
| 'OBCLIENTHELLO!' |
+----------------------------+
| Hello, OBClient!             |
+----------------------------+
1 row in set
```
