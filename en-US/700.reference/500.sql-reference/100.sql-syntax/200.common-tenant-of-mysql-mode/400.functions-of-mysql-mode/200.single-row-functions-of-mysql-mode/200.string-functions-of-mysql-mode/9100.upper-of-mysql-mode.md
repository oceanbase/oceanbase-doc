# UPPER

## Syntax

```sql
UPPER(str)
```

## Purpose

The function converts lowercase letters in the string `str` to uppercase letters.

## Examples

```sql
obclient> obclient> SELECT UPPER('obclient您好！');
+----------------------------+
| 'OBCLIENT HI!'    |
+----------------------------+
| Hello OBClient!              |
+----------------------------+
1 row in set
```
