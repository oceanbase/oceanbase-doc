# INSTR

## Syntax

```sql
INSTR(str,substr)
```

## Purpose

Returns the position of the first occurrence of a substring in the string `str`. This is equivalent to the two-argument form of `LOCATE()` with the arguments reversed.

## Examples

```sql
obclient> SELECT INSTR('foobarbar', 'bar'), INSTR('xbar', 'foobar');
+---------------------------+-------------------------+
| INSTR('foobarbar', 'bar') | INSTR('xbar', 'foobar') |
+---------------------------+-------------------------+
|                         4 |                       0 |
+---------------------------+-------------------------+
1 row in set
```
