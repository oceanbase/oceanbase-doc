# BIT_LENGTH

## Syntax

```sql
BIT_LENGTH(str)
```

## Purpose

Returns the number of bits in the string `str`.

## Examples

```sql
obclient> SELECT BIT_LENGTH('oceanbase');
+-------------------------+
| BIT_LENGTH('oceanbase') |
+-------------------------+
|                      72 |
+-------------------------+
1 row in set
```
