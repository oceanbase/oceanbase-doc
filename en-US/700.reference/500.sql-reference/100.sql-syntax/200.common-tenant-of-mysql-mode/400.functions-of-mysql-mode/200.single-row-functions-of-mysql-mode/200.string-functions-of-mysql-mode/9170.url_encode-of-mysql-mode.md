# URL_ENCODE

## Purpose

This function is used to encode non-ASCII characters in a string into ASCII characters. It converts non-alphanumeric characters in `expr` to the form of `%` followed by two hexadecimal digits.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is supported starting from OceanBase Database V4.3.5 BP1. </p>
</main>

## Limitations and considerations

* This function only supports the `utf8` character set.
* If the input is a string, the output collation remains the same as the input. If the input is not a string, the output collation is the default collation of the current session.

## Syntax

```sql
URL_ENCODE(expr)
```

## Parameters

`expr`: the string to be URL-encoded.

## Return type

* Returns a URL-encoded string (`VARCHAR` type).
* If `expr` is `NULL`, returns `NULL`.

## Examples

```sql
SELECT URL_ENCODE('https://example.com/path?name=John Doe&age=25'), URL_ENCODE(NULL);
```

The execution result is as follows:

```shell
+-----------------------------------------------------------------+------------------+
| URL_ENCODE('https://example.com/path?name=John Doe&age=25')     | URL_ENCODE(NULL) |
+-----------------------------------------------------------------+------------------+
| https%3A%2F%2Fexample.com%2Fpath%3Fname%3DJohn%20Doe%26age%3D25 | NULL             |
+-----------------------------------------------------------------+------------------+
1 row in set
```
