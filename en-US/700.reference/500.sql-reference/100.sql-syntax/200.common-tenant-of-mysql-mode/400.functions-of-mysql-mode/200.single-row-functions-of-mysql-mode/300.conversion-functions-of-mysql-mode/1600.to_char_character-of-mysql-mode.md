# TO_CHAR(character)

## Purpose

This function converts character data to a `VARCHAR` string.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is supported starting from OceanBase Database V4.3.5 BP1. </p>
</main>

## Syntax

```sql
TO_CHAR(character)
```

## Parameters

`character`: the character data to be converted.

## Return type

* Returns data of the `VARCHAR` type.
* Returns `NULL` if the value of `character` is `NULL`.

## Examples

```sql
SELECT TO_CHAR('Hello, World!'), TO_CHAR(NULL);
```

The return result is as follows:

```shell
+--------------------------+---------------+
| TO_CHAR('Hello, World!') | TO_CHAR(NULL) |
+--------------------------+---------------+
| Hello, World!            |          NULL |
+--------------------------+---------------+
1 row in set
```
