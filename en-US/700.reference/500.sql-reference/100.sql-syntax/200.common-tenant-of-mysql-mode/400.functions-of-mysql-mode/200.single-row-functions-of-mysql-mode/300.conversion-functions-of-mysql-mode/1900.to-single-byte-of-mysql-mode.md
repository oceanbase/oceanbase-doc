# TO_SINGLE_BYTE

## Purpose

This function converts multibyte characters in a string to their corresponding single-byte character forms.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.4.2, this function is available starting from V4.4.2 BP2.</p>
</main>

## Syntax

```sql
TO_SINGLE_BYTE(str)
```

## Parameters

`str`: The string to be converted.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>If any multibyte character in <code>str</code> has no single-byte equivalent, it is displayed as a multibyte character in the output string.</p>
</main>

## Return type

The return value has the same data type as `str`.

## Examples

Converts full-width characters in a string to half-width characters.

```shell
obclient> SELECT TO_SINGLE_BYTE('China A')
```

The return result is as follows:

```shell
+-----------------------------+
| TO_SINGLE_BYTE('China A')    |
+-----------------------------+
| China A                       |
+-----------------------------+
1 row in set
```
