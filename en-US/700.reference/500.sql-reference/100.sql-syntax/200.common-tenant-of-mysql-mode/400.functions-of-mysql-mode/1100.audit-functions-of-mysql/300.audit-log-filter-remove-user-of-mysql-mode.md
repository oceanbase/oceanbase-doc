# AUDIT_LOG_FILTER_REMOVE_USER

## Purpose

`AUDIT_LOG_FILTER_REMOVE_USER()` removes a filter from a user.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support security audit. </p>
</main>

## Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_USER('user_name');
```

## Description

### Parameters

`user_name`: the username.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The <code>AUDIT_LOG_FILTER_REMOVE_USER</code> function adopts the <code>DROP IF EXISTS</code> semantics. It does not return an error if the object to be removed does not exist. </p>
</main>

### Return value

The input of the function must be a string constant and the output is a string.

* If the DDL operation is successful, the expression returns `OK`.
* If the DDL operation fails, the `SELECT` statement is still successfully executed, and the expression outputs an error message.

## Examples

Remove a filter from the `user001` user.

```sql
SELECT AUDIT_LOG_FILTER_REMOVE_USER('user001');
```

The return result is as follows:

```shell
+-----------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_USER('user001') |
+-----------------------------------------+
| OK                                      |
+-----------------------------------------+
1 row in set
```
