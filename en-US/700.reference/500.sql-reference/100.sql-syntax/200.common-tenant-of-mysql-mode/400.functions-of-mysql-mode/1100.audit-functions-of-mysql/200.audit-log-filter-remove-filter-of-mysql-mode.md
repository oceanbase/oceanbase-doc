# AUDIT_LOG_FILTER_REMOVE_FILTER

## Purpose

`AUDIT_LOG_FILTER_REMOVE_FILTER()` deletes a trigger.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support security audit. </p>
</main>

## Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_FILTER('filter_name');
```

## Description

### Parameters

`filter_name`: the name of the filter.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The <code>AUDIT_LOG_FILTER_REMOVE_FILTER</code> function adopts the <code>DROP IF EXISTS</code> semantics. It does not return an error if the object to be deleted does not exist. </p>
</main>

### Return value

The input of the function must be a string constant and the output is a string.

* If the DDL operation is successful, the expression returns `OK`.
* If the DDL operation fails, the `SELECT` statement is still successfully executed, and the expression outputs an error message.

## Examples

Delete the `log_all` filter.

```sql
SELECT AUDIT_LOG_FILTER_REMOVE_FILTER('log_all');
```

The return result is as follows:

```shell
+-------------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_FILTER('log_all') |
+-------------------------------------------+
| OK                                        |
+-------------------------------------------+
1 row in set
```
