# AUDIT_LOG_FILTER_SET_USER

## Purpose

`AUDIT_LOG_FILTER_SET_USER()` configures a filter for a user.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support security audit. </p>
</main>

## Syntax

```sql
AUDIT_LOG_FILTER_SET_USER('user_name', 'filter_name');
```

## Description

### Parameters

* `user_name`: the username.

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The value of <code>user@host</code> specified in the <code>AUDIT_LOG_FILTER_SET_USER</code> function is not necessarily the name of an existing user. It can be a wildcard character or the name of a user that does not exist. Take note of the following limitations when you specify <code>user_name</code>: <ul><li>The <code>host</code> field cannot be specified. </li><li>You can use a wildcard character, such as <code>%</code>, to replace the entire <code>user</code> field. You cannot use a wildcard character to replace only a part of the <code>user</code> field, for example, <code>test_%</code>. </li></ul></p>
    </main>

* `filter_name`: the name of the filter.

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The <code>AUDIT_LOG_FILTER_SET_USER</code> function adopts the <code>CREATE OR REPLACE</code> semantics. It overwrites an existing object when you perform a DDL operation on the object. If the filter specified by <code>filter_name</code> does not exist, the DDL operation neither takes effect nor returns an error. </p>
    </main>

### Return value

The input of the function must be a string constant and the output is a string.

* If the DDL operation is successful, the expression returns `OK`.
* If the DDL operation fails, the `SELECT` statement is still successfully executed, and the expression outputs an error message.

## Examples

Configure the `log_all` filter for the `user001` user.

```sql
SELECT AUDIT_LOG_FILTER_SET_USER('user001', 'log_all');
```

The return result is as follows:

```shell
+-------------------------------------------------+
| AUDIT_LOG_FILTER_SET_USER('user001', 'log_all') |
+-------------------------------------------------+
| OK                                              |
+-------------------------------------------------+
1 row in set
```
