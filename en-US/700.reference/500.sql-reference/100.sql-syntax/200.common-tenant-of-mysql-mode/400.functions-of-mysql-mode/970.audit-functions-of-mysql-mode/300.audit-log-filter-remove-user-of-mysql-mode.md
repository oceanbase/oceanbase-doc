# AUDIT_LOG_FILTER_REMOVE_USER

## Purpose

This function (expression) is used to remove a filter from a user.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support audit features. </p>
</main>

## Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_USER('user_name');
```

## Considerations

### Parameters

`user_name`: specifies the name of the user.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><code>AUDIT_LOG_FILTER_REMOVE_USER</code> is equivalent to <code>DROP IF EXISTS</code>. If the object to be dropped does not exist, no error is returned. </p>
</main>

### Return value

The input of the expression must be a string constant, and the output is of the string type.

* If the DDL statement is executed successfully, the expression returns `OK`.
* If the DDL statement is executed unsuccessfully, the `SELECT` statement still executes successfully, and the output of the expression is an error message.

## Examples

Remove a filter from the user `user001`.

```sql
SELECT AUDIT_LOG_FILTER_REMOVE_USER('user001');
```

The return result is as follows:

```shell
+-----------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_USER('user001') |
+-----------------------------------------+
| OK                                      |
+-----------------------------------------+
1 row in set
```
