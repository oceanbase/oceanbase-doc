# AUDIT_LOG_FILTER_SET_USER

## Purpose

This function (expression) is used to set a filter on a user.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This content applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support audit features. </p>
</main>

## Syntax

```sql
AUDIT_LOG_FILTER_SET_USER('user_name', 'filter_name');
```

## Considerations

### Parameters

* `user_name`: specifies the user name.

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The <code>user@host</code> specified by <code>AUDIT_LOG_FILTER_SET_USER</code> does not need to be an existing user. You can specify a wildcard or a non-existent user. The <code>user_name</code> parameter has the following limitations: <ul><li>You cannot specify the <code>host</code> field. </li><li>Only the wildcard <code>%</code> is supported for the <code>user</code> field. The partial wildcard <code>test_%</code> is not supported. </li></ul></p>
    </main>

* `filter_name`: specifies the filter name.

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><code>AUDIT_LOG_FILTER_SET_USER</code> has the <code>CREATE OR REPLACE</code> semantics. If an object already exists, the DDL operation will overwrite it. If the specified <code>filter_name</code> does not exist, the DDL operation will not take effect, but no error will be returned. </p>
    </main>

### Return value

The input must be a string constant, and the output is a string.

* If the DDL operation is successful, the expression returns `OK`.
* If the DDL operation fails, the `SELECT` statement still executes successfully, and the output of the expression is the error message.

## Examples

Set the `log_all` filter on the `user001` user.

```sql
SELECT AUDIT_LOG_FILTER_SET_USER('user001', 'log_all');
```

The return result is as follows:

```shell
+-------------------------------------------------+
| AUDIT_LOG_FILTER_SET_USER('user001', 'log_all') |
+-------------------------------------------------+
| OK                                              |
+-------------------------------------------------+
1 row in set
```
