# Array decision functions

Array decision functions evaluate input array data and return a boolean value. OceanBase Database supports the following array decision functions: `array_contains()`, `array_contains_all()`, and `array_overlaps()`. It also supports the `ANY()` operator.

## array_contains

The `array_contains()` function checks whether an array contains a specified element. Syntax:

```sql
array_contains(arr1, element)
```

The input parameters are described as follows:

* `arr1` must be an array.
* `element` can be of any type.

A return value of `1` indicates that the array contains the element, and a return value of `0` indicates that it does not.

Here are some examples:

```sql
SELECT array_contains([1,2,3], 2);
+----------------------------+
| array_contains([1,2,3], 2) |
+----------------------------+
|                          1 |
+----------------------------+
1 row in set
```

```sql
SELECT array_contains([1,2,3], 6);
+----------------------------+
| array_contains([1,2,3], 6) |
+----------------------------+
|                          0 |
+----------------------------+
1 row in set
```

```sql
SELECT array_contains(["hello", "hi"], "hel");
+----------------------------------------+
| array_contains(["hello", "hi"], "hel") |
+----------------------------------------+
|                                      0 |
+----------------------------------------+
1 row in set
```

```sql
SELECT array_contains(["hello", "hi"], "hi");
+---------------------------------------+
| array_contains(["hello", "hi"], "hi") |
+---------------------------------------+
|                                     1 |
+---------------------------------------+
1 row in set
```

```sql
SELECT array_contains([[1,2],[3,4]], [3.0,4.0]);
+------------------------------------------+
| array_contains([[1,2],[3,4]], [3.0,4.0]) |
+------------------------------------------+
|                                        1 |
+------------------------------------------+
1 row in set
```

## array_contains_all

The `array_contains_all()` function checks whether an array contains all elements of another array. Syntax:

```sql
array_contains_all(arr1, arr2)
```

The input parameters are described as follows:

* `arr1` must be an array.
* `arr2` must be an array.

A return value of `1` indicates that the array contains all elements of the other array, and a return value of `0` indicates that it does not.

The input parameters `arr1` and `arr2` must be of the same (or convertible) element type. Otherwise, the function returns a failure.

Here are some examples:

```sql
SELECT array_contains_all([1,2,3], [2]);
+----------------------------------+
| array_contains_all([1,2,3], [2]) |
+----------------------------------+
|                                1 |
+----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([2], [1,2,3]);
+----------------------------------+
| array_contains_all([2], [1,2,3]) |
+----------------------------------+
|                                0 |
+----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([1,2,3], null);
+-----------------------------------+
| array_contains_all([1,2,3], null) |
+-----------------------------------+
|                              NULL |
+-----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([1,2,3], [2.0]);
+------------------------------------+
| array_contains_all([1,2,3], [2.0]) |
+------------------------------------+
|                                  1 |
+------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all(["hello", "hi"], ["hi"]);
+---------------------------------------------+
| array_contains_all(["hello", "hi"], ["hi"]) |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([[1,2],[3,4]], [[3.0,4.0]]);
+------------------------------------------------+
| array_contains_all([[1,2],[3,4]], [[3.0,4.0]]) |
+------------------------------------------------+
|                                              1 |
+------------------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([["hello", "world"], ["hi", "what"], ["are you?"]], [["are you?"]]);
+----------------------------------------------------------------------------------------+
| array_contains_all([["hello", "world"], ["hi", "what"], ["are you?"]], [["are you?"]]) |
+----------------------------------------------------------------------------------------+
|                                                                                      1 |
+----------------------------------------------------------------------------------------+
1 row in set
```

## array_overlaps

The `array_overlaps()` function checks whether two arrays have any common elements. Syntax:

```sql
array_overlaps(arr1, arr2)
```

The input parameters are described as follows:

* `arr1` must be an array.
* `arr2` must be an array.

A return value of `1` indicates that the arrays have common elements, and a return value of `0` indicates that they do not.

The input parameters `arr1` and `arr2` must be of the same (or convertible) element type. Otherwise, the function returns a failure.

Here are some examples:

```sql
SELECT array_overlaps([1,2,3], [2]);
+------------------------------+
| array_overlaps([1,2,3], [2]) |
+------------------------------+
|                            1 |
+------------------------------+
1 row in set
```

## ANY

The `ANY()` operator has the same functionality, input parameters, and return value as the `array_contains()` function. The syntax is different:

```sql
element = ANY(arr1)
```

Here are some examples:

```sql
SELECT 2 = ANY([1,2,3]);
SELECT 6 = ANY([1,2,3]);
SELECT "hel" = ANY(["hello", "hi"]);
SELECT "hi" = ANY(["hello", "hi"]);
SELECT [3.0,4.0] = ANY([[1,2],[3,4]]);
```
