# Array constructor functions

Array constructor functions are used to construct new array data types. OceanBase Database currently supports the `array()` and `rb_build()` functions, and the `[]` operator.

## array

The `array()` function is used to construct an array data. The syntax is as follows:

```sql
array(elem1, elem2, elem3, ..., elemN)
[elem1, elem2, elem3, ..., elemN]
```

elem1~elmenN: The input parameters must be of the same data type. For more information about the supported array data types, see [Overview of array data types](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/1200.array-data-type-of-mysql-mode/100.array-data-type-overview-of-mysql-mode.md).

Here is an example:

```sql
SELECT array(1, 2, 3);
+----------------+
| array(1, 2, 3) |
+----------------+
| [1,2,3]        |
+----------------+
1 row in set
```

## rb_build

The `rb_build()` function is used to convert an array data of the integer type to a RoaringBitmap, which is a highly compressed bitset. The syntax is as follows:

```sql
rb_build(arr)
```

The input parameter is described as follows:

* `arr`: The input parameter must be an array.

The return value is a RoaringBitmap that contains all elements of the array.

Constraints:

* The array must not contain null elements.
* If the array is a nested array, recursively extract the base elements from each subarray and insert them into the RoaringBitmap.
* The RoaringBitmap supports inserting unsigned 64-bit integers (uint64) and signed 32-bit integers (int32) data. Similar to [rb_from_string](../940.roaring-bitmap-functions-of-mysql-mode/200.roaring-bitmap-constructor-functions-of-mysql-mode.md), negative signed 32-bit integers are first converted to unsigned 32-bit integers before being inserted into the RoaringBitmap. Therefore, the allowed range of input integers is from the minimum value of a signed 32-bit integer to the maximum value of an unsigned 64-bit integer, that is, `[INT32_MIN, UINT64_MAX]`.

Here are some examples:

```sql
SELECT rb_to_string(rb_build([1.2]));
ERROR 5083 (22000): Invalid data type for the operation
```

```sql
SELECT rb_to_string(rb_build([0,1,2]));
+---------------------------------+
| rb_to_string(rb_build([0,1,2])) |
+---------------------------------+
| 0,1,2                           |
+---------------------------------+
1 row in set
```

```sql
SELECT rb_to_string(rb_build([[0,1],[2],[2,3]]));
+-------------------------------------------+
| rb_to_string(rb_build([[0,1],[2],[2,3]])) |
+-------------------------------------------+
| 0,1,2,3                                   |
+-------------------------------------------+
1 row in set
```

## []

The `[]` operator can also be used to construct array data. Here is an example:

```sql
SELECT [1, 2, 3];
+-----------+
| [1, 2, 3] |
+-----------+
| [1,2,3]   |
+-----------+
1 row in set
```
