# Overview

OceanBase Database provides a collection of array functions for processing array data. You can use these functions to execute complex array queries and analysis.

The following table describes the array functions supported by OceanBase Database.

## Array functions

| Function type                               | Description                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [Array constructor functions](200.array-constructor-functions-of-mysql-mode.md) | Construct an array object. |
| [Array judgment functions](300.array-decision-functions-of-mysql-mode.md)  | Perform logic judgment on the input array data and return a Boolean value. |
| [Array output functions](500.array-output-functions-of-mysql-mode.md)  | Output input array data and returning the output array data. |
| [Array manipulation functions](600.array-manipulation-functions-of-mysql-mode.md)  | Perform basic operations on input array data, such as adding elements, deleting elements, and finding elements, and returning the resulting array data. |
