# AVG_WEIGHTED

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting with V5.0.1.</p>
</main>

## Declaration

```sql
AVGWEIGHTED([DISTINCT | ALL] value, weight)
```

## Description

`AVGWEIGHTED` (also written as `avgWeighted`) is a weighted average aggregation function that calculates the result using the following formula:

```text
Σ(value × weight) / Σ(weight)
```

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is not available. To use it, you must set the <code>sql_func_extension_mode</code> parameter to enable it.</p>
</main>

### Parameters

| Parameter | Description |
| ------ | ------ |
| value | The values involved in the calculation. |
| weight | Corresponding to`value`The weight. |
| DISTINCT | Optional. Yes`value`Deduplicate the data and then recalculate. |
| ALL | Optional. Default value. Specifies to compute for all rows. |

### Response parameters

* Returns the weighted average, with the same data type as `value`.
* Rows where `value` or `weight` is `NULL` will be skipped.
* Returns `NULL` when the sum of weights for valid rows is 0.
* Returns `NULL` if the input is empty or all rows are `NULL`.

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Calculate the weighted average.

    ```shell
    obclient> SELECT AVGWEIGHTED(v, w) FROM (SELECT 10 AS v, 2 AS w UNION ALL SELECT 20, 3) t;
    ```

    The return result is as follows:

    ```shell
    +-------------------+
    | AVGWEIGHTED(v, w) |
    +-------------------+
    |                16 |
    +-------------------+
    1 row in set
    ```

    The calculation process is `(10 × 2 + 20 × 3) / (2 + 3) = 16`.
