# ARG_MIN

## Syntax

```sql
ARG_MAX([DISTINCT] minimize_col, return_col)
```

## Purpose

The `ARG_MIN` function is used to find the row in the dataset that minimizes the target expression and returns the value of the specified column or the entire record corresponding to that row.

Where:

* `minimize_col` is the column to be minimized.
* `return_col` is the column corresponding to the return value, returning the value of this column for the row with the minimum value. If it is `NULL`, the row is ignored.

## Examples

```shell
obclient> SELECT * FROM test;
+------+------+
| a    | b    |
+------+------+
| a    |    1 |
| b    |    2 |
| c    |    2 |
| NULL |    3 |
| NULL | NULL |
| d    | NULL |
+------+------+
6 rows in set (0.000 sec)
```

```sql
obclient> SELECT arg_min(a, b), min(b) FROM test;
+---------------+--------+
| arg_min(a, b) | min(b) |
+---------------+--------+
| a             |      1 |
+---------------+--------+
1 row in set (0.006 sec)
```
