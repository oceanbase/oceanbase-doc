# STDDEVSAMP

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting from V4.6.0. </p>
</main>

## Syntax

```sql
STDDEVSAMP(expr)
```

## Purpose

This function returns the sample standard deviation of the expression `expr`.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is disabled. You must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <strong>sql_func_extension_mode</strong>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode. 

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Create a test table named `test_tbl1`. 

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(50), col3 INT);
    ```

3. Insert data into the `test_tbl1` table. 

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES(1, 'a1', 68), (2, 'a2', 88), (3, 'a2', 95);
    ```

4. Use the `STDDEVSAMP` function to calculate the standard deviation of the `col3` column. 

    ```shell
    obclient> SELECT STDDEVSAMP(col3) FROM test_tbl1;
    ```

    The returned result is as follows:

    ```shell
    +------------------+
    | STDDEVSAMP(col3) |
    +------------------+
    | 14.0118997046558 |
    +------------------+
    1 row in set
    ```
