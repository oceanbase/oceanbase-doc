# MIN

## Syntax

```sql
MIN([DISTINCT | ALL] expr)
```

## Purpose

Returns the minimum value in the specified data.

The `MIN()` function can take a string parameter and returns the minimum string value. The `DISTINCT` keyword specifies to calculate only distinct values, with the default being `ALL`.

## Examples

Assume table `a` has three rows of data: `id=1,num=10`, `id=2,num=20`, and `id=3,num=30`. To select the minimum value of `num`:

```sql
obclient> SELECT MIN(num) FROM a;
+----------------+
| MIN(num)       |
+----------------+
|             10 |
+----------------+
1 row in set
```
