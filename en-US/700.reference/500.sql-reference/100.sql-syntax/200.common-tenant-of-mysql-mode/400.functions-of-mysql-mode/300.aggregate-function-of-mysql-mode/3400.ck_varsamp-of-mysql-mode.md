# VARSAMP

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available from V4.6.0. </p>
</main>

## Syntax

```sql
VARSAMP(expr)
```

## Purpose

This function returns the sample variance of the `expr` expression. 

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse compatible function. By default, it is not enabled. To use it, you must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode. 

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Create a test table `test_tbl1`. 

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(50), col3 INT);
    ```

3. Insert data into the `test_tbl1` table. 

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES(1, 'a1', 6), (2, 'a2', 8), (3, 'a2', 10);
    ```

4. Use the `VARSAMP` function to calculate the variance of column `col3`. 

    ```shell
    obclient> SELECT VARSAMP(col3) FROM test_tbl1;
    ```

    The return result is as follows: 

    ```shell
    +---------------+
    | VARSAMP(col3) |
    +---------------+
    |             4 |
    +---------------+
    1 row in set
    ```
