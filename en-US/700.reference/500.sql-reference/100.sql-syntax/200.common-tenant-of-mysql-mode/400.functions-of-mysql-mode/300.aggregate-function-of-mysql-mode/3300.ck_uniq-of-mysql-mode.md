# UNIQ

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available starting from V4.6.0. </p>
</main>

## Syntax

```sql
UNIQ(expr)
```

## Purpose

This function is used to approximately calculate the number of distinct values in a column.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is not enabled. To use it, you must set the <code>sql_func_extension_mode</code> parameter to enable it. For more information, see <strong>sql_func_extension_mode</strong>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Create a test table `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(50), col3 INT);
    ```

3. Insert data into the table `test_tbl1`.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES(1, 'a1', 6), (2, 'a2', 8), (3, 'a2', 8);
    ```

4. Use the `UNIQ` function to calculate the number of distinct values in the `col3` column.

    ```shell
    obclient> SELECT UNIQ(col3) FROM test_tbl1;
    ```

    The returned result is as follows:

    ```shell
    +------------+
    | UNIQ(col3) |
    +------------+
    |          2 |
    +------------+
    1 row in set
    ```
