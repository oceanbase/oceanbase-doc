# ANY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This function is available from V4.6.0. </p>
</main>

## Syntax

```sql
ANY(expr)
```

## Purpose

This function selects an arbitrary value from a set of values. It is typically used in `GROUP BY` queries. `expr` specifies the column from which to select an arbitrary value. By default, this function ignores `NULL` values.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. By default, it is disabled. To enable it, set the <code>sql_func_extension_mode</code> parameter. For more information, see <strong>sql_func_extension_mode</strong>. </p>
</main>

## Examples

1. Enable the ClickHouse extension function mode. 

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Create a test table `test_tbl1`. 

    ```shell
    obclient> CREATE TABLE test_tbl1 (
        col1 INT AUTO_INCREMENT PRIMARY KEY,
        col2 INT NOT NULL,
        col3 DATETIME NOT NULL);
    ```

3. Insert data into the `test_tbl1` table. 

    ```shell
    obclient> INSERT INTO test_tbl1(col2, col3) VALUES
        (1, '2026-03-01 10:00:00'),
        (1, '2026-03-01 11:00:00'),
        (2, '2026-03-01 12:00:00'),
        (1, '2026-03-02 10:00:00');
    ```

4. Use the `ANY` function to retrieve an arbitrary access date (`col3`) for each `col2`. 

    ```shell
    obclient> SELECT col2, ANY(col3)
        FROM test_tbl1
        GROUP BY col2;
    ```

    The result is as follows: 

    ```shell
    +------+---------------------+
    | col2 | ANY(col3)           |
    +------+---------------------+
    |    1 | 2026-03-01 10:00:00 |
    |    2 | 2026-03-01 12:00:00 |
    +------+---------------------+
    2 rows in set
    ```
