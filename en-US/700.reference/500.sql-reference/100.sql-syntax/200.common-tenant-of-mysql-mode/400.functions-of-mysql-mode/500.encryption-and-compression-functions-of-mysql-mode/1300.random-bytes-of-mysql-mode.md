# RANDOM_BYTES

## Syntax

```sql
RANDOM_BYTES(len)
```

## Purpose

Returns a random binary string of len bytes, where len is in the range [1, 1024].

## Examples

```sql
obclient [test]> select RANDOM_BYTES(2);
+-----------------+
| RANDOM_BYTES(2) |
+-----------------+
| H              |
+-----------------+
1 row in set
```
