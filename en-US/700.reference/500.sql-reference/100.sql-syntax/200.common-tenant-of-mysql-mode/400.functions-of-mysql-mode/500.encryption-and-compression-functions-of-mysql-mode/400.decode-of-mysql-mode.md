# DECODE

## Syntax

```sql
DECODE(crypt_str,pass_str)
```

## Purpose

The `DECODE()` function decrypts the encrypted string `crypt_str` using the password `pass_str` and returns the decrypted string.

## Examples

```sql
obclient> SELECT DECODE(ENCODE('secret','cry'), 'cry');
+---------------------------------------+
| DECODE(ENCODE('secret','cry'), 'cry') |
+---------------------------------------+
| secret                                |
+---------------------------------------+
1 row in set
```
