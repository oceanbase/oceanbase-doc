# UNCOMPRESSED_LENGTH

## Syntax

```sql
UNCOMPRESSED_LENGTH(str)
```

## Purpose

Returns the length of the string before it was compressed by the [COMPRESS()](../500.encryption-and-compression-functions-of-mysql-mode/300.compress-of-mysql-mode.md) function.

## Examples

```sql
obclient [test]> SELECT UNCOMPRESSED_LENGTH(COMPRESS('abc'));
+--------------------------------------+
| UNCOMPRESSED_LENGTH(COMPRESS('abc')) |
+--------------------------------------+
|                                    3 |
+--------------------------------------+
1 row in set
```
