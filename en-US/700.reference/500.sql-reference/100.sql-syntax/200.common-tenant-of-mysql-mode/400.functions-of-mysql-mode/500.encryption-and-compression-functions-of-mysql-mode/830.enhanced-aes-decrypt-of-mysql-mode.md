# ENHANCED_AES_DECRYPT

## Syntax

```sql
ENHANCED_AES_DECRYPT(cipher_text[, iv])
```

## Purpose

* The `ENHANCED_AES_DECRYPT` function is used to decrypt data using the AES algorithm. This feature is controlled by the `tde_method` parameter. For more information, see [tde_method](../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7800.tde_method.md).

* The `ENHANCED_AES_DECRYPT` function requires the `DECRYPT` privilege.

* `cipher_text` is the ciphertext to be decrypted using the AES algorithm.

* `[, iv]` is an optional parameter that specifies the initialization vector.

* The `ENHANCED_AES_DECRYPT` function must be used with the `cipher_text` parameter, which is generated by the `ENHANCED_AES_DECRYPT` function. Otherwise, the error `OB_ERR_AES_DECRYPT` (4334) will occur.

## Examples

The `SELECT` statement uses the decryption function to return the plaintext column.

```sql
-- Return plaintext
SELECT ENHANCED_AES_DECRYPT(cipher_col) FROM tbl;
```

Direct comparison between ciphertext and plaintext is not supported. You must decrypt the ciphertext or encrypt the plaintext before performing the comparison.

```sql
-- Decrypt the cipher_col and expect to match the corresponding plaintext data '12345'. However, indexes cannot be used.
SELECT ... FROM tbl WHERE ENHANCED_AES_DECRYPT(cipher_col) = '12345';
```
