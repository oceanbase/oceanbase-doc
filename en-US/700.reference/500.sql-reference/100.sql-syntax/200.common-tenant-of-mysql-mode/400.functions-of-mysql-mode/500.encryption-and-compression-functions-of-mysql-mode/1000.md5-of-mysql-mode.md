# MD5

## Syntax

```javascript
MD5(str)
```

## Purpose

Returns the 128-bit MD5 checksum of the string.

The return value is a string of 32 hexadecimal digits. If `str` is `NULL`, the return value is `NULL`.

## Examples

```javascript
obclient> SELECT MD5(1);
+----------------------------------+
| MD5(1)                           |
+----------------------------------+
| c4ca4238a0b923820dcc509a6f75849b |
+----------------------------------+
1 row in set
```
