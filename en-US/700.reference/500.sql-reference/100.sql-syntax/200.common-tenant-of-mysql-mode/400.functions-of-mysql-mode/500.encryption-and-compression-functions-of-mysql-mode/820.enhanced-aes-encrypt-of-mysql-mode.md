# ENHANCED_AES_ENCRYPT

## Syntax

```sql
ENHANCED_AES_ENCRYPT(plaintext[, iv])
```

## Purpose

* The `ENHANCED_AES_ENCRYPT` function is used to encrypt data. This feature is enabled by setting the `tde_method` parameter. For more information, see [tde_method](../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7800.tde_method.md).

* The required privilege for this function is `ENCRYPT`.

* `plaintext` is the plaintext data to be encrypted.

* `[, iv]` is an optional parameter that specifies the initialization vector.

* This function uses the current tenant's primary key for encryption. The default encryption algorithm is AES-128-ECB, which can be changed by setting the system variable [block_encryption_mode](../../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/600.block_encryption_mode-global.md). Only AES encryption algorithms are supported.

* This function supports encryption algorithms that require an initialization vector `iv`, such as AES-128-CFB1. When using these algorithms for encryption or decryption, the initialization vector `iv` must be explicitly provided as the second parameter of the function. The minimum length of `iv` is 16 bytes.

* Key rotation does not affect decryption operations.

## Examples

Use the `ENHANCED_AES_ENCRYPT` function explicitly in `INSERT` or `UPDATE` statements for columns that require encryption.

```sql
-- Encrypt the plaintext data and write it to the cipher_col column in the tbl table.
-- If any value in the value list uses the encryption function, the corresponding privilege is required.
INSERT INTO tbl(cipher_col, ...) VALUES(ENHANCED_AES_ENCRYPT(plaintext), ...);
-- Update the cipher column
UPDATE tbl SET cipher_col = ENHANCED_AES_ENCRYPT(plaintext) WHERE ...;
```

Use the `SELECT` statement to query the cipher column and return the encrypted data.

```sql
-- Query the cipher column
SELECT cipher_col FROM tbl;
```

Direct comparison between cipher and plaintext data is not supported. You need to either decrypt the cipher data or encrypt the plaintext data before performing the comparison.

```sql
-- cipher_col is the cipher column, and 12345 is the plaintext data. No matching cipher data can be found.
SELECT ... FROM tbl WHERE cipher_col = '12345';
-- LIKE statements behave similarly and cannot match the corresponding cipher data.
SELECT ... FROM tbl WHERE cipher_col LIKE '123%';
-- After encrypting the plaintext data '12345', it should match the current cipher data encrypted with the key. Indexes can be used.
SELECT ... FROM tbl WHERE cipher_col = ENHANCED_AES_ENCRYPT('12345');
-- Encrypted columns can be used in various calculations, including comparisons.
SELECT ... FROM tbl WHERE tbl.cipher_col = another_tbl.another_cipher_col;
SELECT ... FROM tbl GROUP BY cipher_col ORDER BY cipher_col;
```
