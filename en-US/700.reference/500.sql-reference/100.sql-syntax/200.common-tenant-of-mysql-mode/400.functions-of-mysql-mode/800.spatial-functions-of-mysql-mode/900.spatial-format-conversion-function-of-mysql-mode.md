# Spatial format conversion functions

Spatial format conversion functions are used to convert spatial data between different formats, such as converting a geometry object to a text or binary format.

OceanBase Database currently supports the `ST_AsGeoJSON`, `_ST_AsMVT`, and `ST_AsMVTGeom` spatial format conversion functions.

## ST_AsGeoJSON

The `ST_AsGeoJSON` function converts a geometry object into a GeoJSON string. GeoJSON is a geographic data exchange format based on JavaScript Object Notation (JSON). The GeoJSON standard primarily supports the following geometry types: point (Point), multi-point (MultiPoint), line string (LineString), multi-line string (MultiLineString), polygon (Polygon), and multi-polygon (MultiPolygon).

Syntax:

```sql
ST_AsGeoJSON(g [, max_dec_digits [, options]])
```

Parameters:

* `g`: The main parameter of the function. It specifies the geometry object to be converted into a GeoJSON string. The geometry object `g` must be valid.

* `max_dec_digits` (optional): Specifies the precision of the output GeoJSON string, that is, the maximum number of decimal places to be displayed for the coordinates.

  * If this parameter is not specified, the default value is 2<sup>32</sup> - 1.
  * The minimum value is 0.

* `options` (optional): A 3-bit switch that specifies whether to output the bounding box (bounding box) and coordinate reference system (CRS) information in the JSON.

  * 0: Default value. All options are disabled.
  * 1: Enable the output of the bounding box.
  * 2: Enable the output of the short format of the CRS (`EPSG:srid`).
  * 4: Enable the output of the long format of the CRS (`urn:ogc:def:crs:EPSG::srid`). If both the long and short formats are enabled, the long format is output.

The following examples show how to use the `ST_AsGeoJSON` function to convert a geometry object into a GeoJSON string. The flag parameter of the function is used to control the output of the GeoJSON string.

Example 1:

```sql
-- Use the flag parameter to control the options of the GeoJSON output. The value of the flag ranges from 0 (binary 000) to 7 (binary 111).
obclient> SELECT ST_AsGeoJSON(ST_GeomFromText('POINT(11.11111 12.22222)', 4326),1,0);
```

Use the `ST_AsGeoJSON` function to convert a point geometry object into a GeoJSON string without any additional attributes (such as the bounding box or coordinate system).

The return result is as follows:

```shell
+---------------------------------------------------------------------+
| ST_AsGeoJSON(ST_GeomFromText('POINT(11.11111 12.22222)', 4326),1,0) |
+---------------------------------------------------------------------+
| {"type": "Point", "coordinates": [12.2, 11.1]}                      |
+---------------------------------------------------------------------+
1 row in set
```

Example 2:

```sql
obclient> SELECT ST_AsGeoJSON(ST_GeomFromText('POINT(11.11111 12.22222)', 4326),1,1);
```

Use the `ST_AsGeoJSON` function and set the `flag` parameter to 1 to include the bounding box information.

The return result is as follows:


## _ST_AsMVT

The `_ST_AsMVT` function aggregates all rows of a table containing geographic information system (GIS) data and returns a `mapbox` vector tile encoded in Google Protocol Buffers (Protobuf) binary format.

Syntax:

```sql
_ST_AsMVT(table_name.*, text name, integer extent, text geom_name, text feature_id_name);
```

Parameters:

- `table_name.*`: This represents all the columns returned by the query, which are used to construct the vector tile. Typically, an asterisk (*) is used to select all columns from the table. This parameter must point to an existing table that contains spatial data columns.
- `text name` (optional): The name of the vector layer. In the generated MVT, this name is used to identify the corresponding layer.
- `integer extent` (optional): The pixel range of the vector tile. This integer defines the spatial range of the tile, which is usually 4096 or 256.
- `text geom_name` (optional): The name of the column in the table that stores geometry data.
- `text feature_id_name` (optional): The name of the column in the table that stores the feature ID.

Example:

```sql
obclient> SELECT 'TG1', hex(_ST_AsMVT(q.*, 'test', 4096, 'geom')) FROM (SELECT 1 AS c1, ST_GeomFromText('POINT(25 17)')AS geom) AS q;
```

In this example, the `_ST_AsMVT` function converts the spatial data in the query result set into a Mapbox Vector Tile (MVT) format. We construct an inline query (subquery) q that contains only a column c1 with a constant value of 1 and a `POINT` geometry object geom created by the `ST_GeomFromText` function.

Then, the result set `q.*` of the subquery is used as the input of the `_ST_AsMVT` function, which includes:

- `'TG1'`: A simple string used as the first field in the query result set.
- `hex(_ST_AsMVT(q.*, 'test', 4096, 'geom'))`: Calls the `_ST_AsMVT` function and converts the result to a hexadecimal string. The function parameters include `'test'` as the layer name, `4096` as the tile range, and `'geom'` as the column name for generating MVT data.

The final result displays the encoded hexadecimal string, which contains the value 1 of field c1 and the `POINT(25 17)` geometry object.

The return result is as follows:

```shell
+-----+----------------------------------------------------------------------+
| TG1 | hex(_ST_AsMVT(q.*, 'test', 4096, 'geom'))                            |
+-----+----------------------------------------------------------------------+
| TG1 | 1A200A0474657374120B12020000180122030932221A026331220228012880207802 |
+-----+----------------------------------------------------------------------+
1 row in set
```

## ST_AsMVTGeom

The `ST_AsMVTGeom` function converts spatial objects to the coordinate system specified by the Mapbox Vector Tile (MVT) standard. This function ensures that the converted geometry conforms to the MVT specification and is suitable for tile rendering. If a geometry object extends beyond the rectangular boundary defined by `bounds` but remains within the buffer specified by `buffer`, its clipping behavior is determined by the `clip_geom` parameter. In the MVT coordinate system, the origin is at the top-left corner, consistent with the screen coordinate system. Ultimately, the function outputs a valid geometry object compatible with the MVT specification, typically used as an input parameter for the `ST_AsMVT` function.

Syntax:

```sql
ST_AsMVTGeom(geometry geom, box2d bounds, integer extent=4096, integer buffer=256, boolean clip_geom=true);
```

Parameters:

- `geom`: The input geometry to be converted. `geom` must be a valid geometry object.
- `bounds`: A 2D box defining the tile boundary. This box is typically a rectangular region defined by four values (xmin, ymin, xmax, ymax) that represent the spatial extent of the tile.
- `integer extent=4096` (optional): The pixel extent of the vector tile. The default value is 4096, and it must be a non-negative integer.
- `integer buffer=256` (optional): The size of the buffer added outside the tile boundary. The default value is 256 pixels, and it must be a non-negative integer.
- `boolean clip_geom=true` (optional): A boolean value indicating whether to clip geometry data that extends beyond the tile boundary but within the buffer to reduce the size of the output tile. The default value is `true`, meaning that parts exceeding the boundary will be clipped.

Example 1:

```sql
obclient> SELECT ST_AsText(_ST_AsMVTGeom(ST_GeomFromText('POLYGON ((0 0, 0 -5, 10 0, 10 5, 0 0))'),ST_GeomFromText('POLYGON((0 0,0 4096,4096 4096,4096 0,0 0))'),4096, 0, false));
```

In this example, the `ST_AsMVTGeom` function converts a given POLYGON geometry to MVT format:

First, we define a `POLYGON` geometry as the input.
Then, we set the `bounds` to a 4096*4096 pixel area; set the `extent` to 4096, indicating the tile size; set the `buffer` to 0, indicating no additional buffer outside the tile boundary; and set `clip_geom` to false, indicating that no clipping will be performed on the geometry exceeding the `bounds`.
Finally, we use the `ST_AsText` function to convert the converted geometry to text format.

The result is as follows:

```shell
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ST_AsText(_ST_AsMVTGeom(ST_GeomFromText('POLYGON ((0 0, 0 -5, 10 0, 10 5, 0 0))'),ST_GeomFromText('POLYGON((0 0,0 4096,4096 4096,4096 0,0 0))'),4096, 0, false)) |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| POLYGON((0 4101,0 4096,10 4091,10 4096,0 4101))                                                                                                                 |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```

Example 2:

```sql
obclient> SELECT ST_AsText(_ST_AsMVTGeom(ST_GeomFromText('POLYGON ((0 0, 0 -5, 10 0, 10 5, 0 0))'),ST_GeomFromText('POLYGON((0 0,0 4096,4096 4096,4096 0,0 0))'),4096, 0, true));
```

In this example, we use the same input geometry and `bounds` as in Example 1, but we set `clip_geom` to true. The `ST_AsMVTGeom` function will clip the geometry that extends beyond the `bounds`.

The result is as follows:

```shell
+----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ST_AsText(_ST_AsMVTGeom(ST_GeomFromText('POLYGON ((0 0, 0 -5, 10 0, 10 5, 0 0))'),ST_GeomFromText('POLYGON((0 0,0 4096,4096 4096,4096 0,0 0))'),4096, 0, true)) |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| POLYGON((10 4096,0 4096,10 4091,10 4096))                                                                                                                      |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```
