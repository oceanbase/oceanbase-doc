# Mapping comparison functions

Mapping comparison functions/operands evaluate mappings and return a boolean value. OceanBase Database supports the `=` and `!=` operators.

## =/!=

The `=` and `!=` operators check whether two mappings are equal. The syntax is as follows:

```sql
map1 = map2;
map1 != map2;
```

The parameters are described as follows:

* `map1` must be of the mapping type.
* `map2` must be of the mapping type.

The return values are described as follows:

* For the `=` operator, the return value `1` indicates equality, and `0` indicates inequality.
* For the `!=` operator, the return value `0` indicates equality, and `1` indicates inequality.
* A mapping is considered equal to another mapping only if both the keys and values are equal.

Here are some examples:

```sql
SELECT map(1,"a",2,"b") = map(1,"a",2,"b");
+-------------------------------------+
| map(1,"a",2,"b") = map(1,"a",2,"b") |
+-------------------------------------+
|                                   1 |
+-------------------------------------+
1 row in set
```

```sql
-- The system automatically converts arrays into comparable types during comparison.
SELECT map(1,"a",2,"b") = map("1","a","2","b");
+-----------------------------------------+
| map(1,"a",2,"b") = map("1","a","2","b") |
+-----------------------------------------+
|                                       1 |
+-----------------------------------------+
1 row in set
```

```sql
-- The return value is 0 because the keys are equal but the values are not.
SELECT map(1,"a",2,"b") = map(1,"a",2,"c");
+-------------------------------------+
| map(1,"a",2,"b") = map(1,"a",2,"c") |
+-------------------------------------+
|                                   0 |
+-------------------------------------+
1 row in set
```
