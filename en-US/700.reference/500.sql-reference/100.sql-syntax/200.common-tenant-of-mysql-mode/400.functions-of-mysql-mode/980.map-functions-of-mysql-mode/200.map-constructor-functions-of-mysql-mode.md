# Mapping constructor

Mapping constructors and operators are used to construct new mapping data types. OceanBase Database currently supports the `map()` constructor and the `{}` operator.

## map

The `map()` function is used to construct mapping data. The syntax is as follows:

```sql
map(key1, value1, key2, value2, ..., keyN, valueN)
```

The input parameters are described as follows:

* The number of input parameters must be even. Parameters with odd ordinal numbers form the key array, and parameters with even ordinal numbers form the value array.
* For the data element types of key1~keyN and value1~valueN, see [Overview of mapping data types](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/1300.map-data-type-of-mysql-mode/100.map-data-type-overview-of-mysql-mode.md).
* Note that the keys in the input key-value pairs must be unique. If there are duplicate keys, the value that appears later will overwrite the previous one.

The return value is of the mapping data type (MAP).

Here are some examples:

```sql
-- The constructed mapping data contains only one key-value pair: key = 1, value = 2.
SELECT map(1,2);
+----------+
| map(1,2) |
+----------+
| {1:2}    |
+----------+
1 row in set
```

```sql
-- The constructed mapping data contains three key-value pairs.
SELECT map(1,"a",2,"b",3,"c");
+------------------------+
| map(1,"a",2,"b",3,"c") |
+------------------------+
| {1:"a",2:"b",3:"c"}    |
+------------------------+
1 row in set
```

```sql
-- The data type of the Key array is determined by the odd-indexed parameter, and the data type of the Value array is determined by the even-indexed parameter.
SELECT map(1,"a","b",1.8,"ccc",3);
+-------------------------------+
| map(1,"a","b",1.8,"ccc",3)    |
+-------------------------------+
| {"1":"a","b":"1.8","ccc":"3"} |
+-------------------------------+
```

## {}

`{}` is used to construct mapping data as a string. After you write mapping data in the `{key1:value1, key2:value2, ..., keyN:valueN}` format as a string, OceanBase Database converts it into the mapping data type. Therefore, you can directly use this string when inserting data into a mapping column.

The input parameters are described as follows:

* Each key-value pair is separated by `,`. A colon `:` separates the key from its value.
* You can omit quotation marks for the key, for example, `{1:1,2:2,3:3}`.
* The keys in the input key-value pairs must be unique. If duplicate keys exist, the subsequent values will overwrite the earlier ones.

Here is an example:

```sql
CREATE TABLE t1 (
  id INT NOT NULL AUTO_INCREMENT,
  m MAP(INT, INT)
);

INSERT INTO t1 (m) VALUES ('{1:1,2:2,3:3}');

SELECT m FROM t1;
+---------------+
| m             |
+---------------+
| {1:1,2:2,3:3} |
+---------------+
+----------+
1 row in set
