# Map constructors

Map constructors and operators are used to build new mapped data types. OceanBase Database supports the `map()` constructor and the `{}` operator.

## map

The `map()` constructor is used to build a mapped data type. The syntax is as follows:

```sql
map(key1, value1, key2, value2, ..., keyN, valueN)
```

The meanings of the input parameters are as follows:

* You can specify an even number of parameters. The parameters with odd sequence numbers constitute the Key array, and the parameters with even sequence numbers constitute the Value array.
* For more information about the data types of the key1~keyN and value1~valueN parameters, see [Overview](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/1300.map-data-type-of-mysql-mode/100.map-data-type-overview-of-mysql-mode.md).
* Note that the keys must be unique. If duplicate keys are specified, the values specified later overwrite the earlier ones.

The return value is of the mapped data type (MAP).

Examples:

```sql
-- Only one key-value pair is contained in the mapped data. The key is 1 and the value is 2.
SELECT map(1,2);
+----------+
| map(1,2) |
+----------+
| {1:2}    |
+----------+
1 row in set
```

```sql
-- Three key-value pairs are contained in the mapped data.
SELECT map(1,"a",2,"b",3,"c");
+------------------------+
| map(1,"a",2,"b",3,"c") |
+------------------------+
| {1:"a",2:"b",3:"c"}    |
+------------------------+
1 row in set
```

```sql
-- The data types of the elements in the Key array are determined by the parameters with odd sequence numbers, and the data types of the elements in the Value array are determined by the parameters with even sequence numbers.
SELECT map(1,"a","b",1.8,"ccc",3);
+-------------------------------+
| map(1,"a","b",1.8,"ccc",3)    |
+-------------------------------+
| {"1":"a","b":"1.8","ccc":"3"} |
+-------------------------------+
```
