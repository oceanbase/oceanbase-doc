# Overview

Mapping functions are a group of functions provided by OceanBase Database for processing mapping data. Users can use mapping functions to perform complex mapping queries and analysis.

The following table describes some mapping functions in OceanBase Database and their uses.

## Mapping function types

| Mapping function type                               | Description                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [Mapping constructor functions](200.map-constructor-functions-of-mysql-mode.md) | Functions that are used to build new mapping data types. |
| [Mapping judgment functions](300.map-decision-functions-of-mysql-mode.md) | Functions that perform logical judgment on the input mapping data and return a boolean value. |
| [Mapping operation functions](600.map-manipulation-functions-of-mysql-mode.md)  | Functions that perform basic operations on the input mapping data, such as extracting keys and values, and return the operated mapping data. |

## Mapping functions

OceanBase Database supports the following mapping functions:

| Function type | Function name | Description |
|---------|---------|------|
| [Mapping constructor functions](200.map-constructor-functions-of-mysql-mode.md) | map | A constructor that is used to build a mapping data. |
| [Operator](200.map-constructor-functions-of-mysql-mode.md)  | {} | A constructor that is used to build a mapping data. |
| [Operator](300.map-decision-functions-of-mysql-mode.md)  | =/!= | A comparison operator that is used to compare two mapping data for equality. |
| [Mapping operation functions](600.map-manipulation-functions-of-mysql-mode.md) | map_keys | A function that returns the keys of a mapping data. |
| [Mapping operation functions](600.map-manipulation-functions-of-mysql-mode.md) | map_values | A function that returns the values of a mapping data. |
