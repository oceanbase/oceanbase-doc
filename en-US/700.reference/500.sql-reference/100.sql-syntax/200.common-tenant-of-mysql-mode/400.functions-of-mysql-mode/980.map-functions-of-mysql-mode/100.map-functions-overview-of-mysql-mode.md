# Overview of mapping functions

Mapping functions are a set of specialized functions provided by OceanBase Database for handling mapping data. These functions allow users to perform complex mapping queries and analyses.

Here is an overview of some mapping functions in OceanBase Database and their purposes:

## Types of mapping functions

| Mapping function type                               | Description                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [Mapping constructor functions](200.map-constructor-functions-of-mysql-mode.md) | Functions used to construct new mapping data types. |
| [Mapping decision functions](300.map-decision-functions-of-mysql-mode.md) | Functions that perform logical judgments on input mapping data and return boolean values. |
| [Mapping manipulation functions](600.map-manipulation-functions-of-mysql-mode.md)  | Functions used to perform basic operations on input mapping data, such as extracting keys and values, and returning the resulting mapping data. |

## List of mapping functions

The following table lists all mapping functions supported by OceanBase Database:

| Function type | Function name | Description |
|---------|---------|------|
| [Mapping constructor functions](200.map-constructor-functions-of-mysql-mode.md) | map | Constructs a mapping data type. |
| [Operators](200.map-constructor-functions-of-mysql-mode.md)  | {} | Constructs a mapping data type. |
| [Operators](300.map-decision-functions-of-mysql-mode.md)  | =/!= | Determines whether two mapping data types are equal. |
| [Mapping manipulation functions](600.map-manipulation-functions-of-mysql-mode.md) | map_keys | Retrieves the list of keys from mapping data. |
| [Mapping manipulation functions](600.map-manipulation-functions-of-mysql-mode.md) | map_values | Retrieves the list of values from mapping data. |
