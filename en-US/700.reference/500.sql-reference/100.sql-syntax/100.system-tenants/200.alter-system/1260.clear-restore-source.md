# CLEAR RESTORE SOURCE

## Purpose

This statement is used to remove the path added by the `ADD RESTORE SOURCE` statement.

## Privilege requirements

You must have the `ALTER SYSTEM` privilege to execute this statement.

## Syntax

```sql
ALTER SYSTEM CLEAR RESTORE SOURCE;
```
