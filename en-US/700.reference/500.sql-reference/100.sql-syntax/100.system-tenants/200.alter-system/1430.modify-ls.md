# MODIFY LS

## Purpose

This statement is used to modify the log stream, including modifying the `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode) of the log stream and the `PRIMARY_ZONE` of the log stream.

## Limitations and considerations

* OceanBase Database supports both homogeneous and heterogeneous zone modes for tenants. In homogeneous zone mode:

  * You can modify the `UNIT_GROUP` of the log stream distribution and the `PRIMARY_ZONE` of the log stream.

  * In heterogeneous zone mode, you can modify the `UNIT_LIST` of the log stream distribution and the `PRIMARY_ZONE` of the log stream.

* When modifying a log stream, the log stream to be changed must exist and be in the `NORMAL` state.

* When modifying a log stream, the tenant of the log stream must also be in the `NORMAL` state.

* When changing the `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode) of a log stream on the primary tenant, no load balancing tasks should be running for any log streams of that tenant.

* It is recommended not to manually modify the `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode) attribute of a log stream on a standby tenant, as this attribute is automatically adjusted. Manual modifications may not take effect.

* When modifying the `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode) attribute of a log stream, the target `UNIT_GROUP` or `UNIT_LIST` must be in the `ACTIVE` state.

* When modifying the `PRIMARY_ZONE` attribute of a log stream, ensure that the specified zone is included in the tenant’s `ZONE_LIST`. Only a single zone (such as `z1` or `z2`) can be set as the `PRIMARY_ZONE` for a log stream; settings like `z1,z2`, `z1; z2`, or `RANDOM` are not supported.

* When modifying a log stream, the tenant-level parameter `enable_rebalance` must be disabled (set to `False`). If `enable_rebalance` is enabled, the tenant's load balancing module may automatically adjust the log stream’s `PRIMARY_ZONE` and `UNIT_GROUP` or `UNIT_LIST` attributes.

* In homogeneous zone mode, only broadcast log streams and the system log stream (Log Stream 1) support setting `UNIT_GROUP` to 0.

* In heterogeneous zone mode, the `UNIT_LIST` of user log streams cannot be empty.

## Privilege requirements

To execute this statement, you must have the `ALTER SYSTEM` privilege. For more information about OceanBase Database privileges, see [Privilege types in MySQL-compatible mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege types in Oracle-compatible mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM MODIFY LS
    LS [=] ls_id
    [UNIT_GROUP [=] unit_group_id] | [UNIT_LIST [=] (unit_id_list)]
    [,PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

|     **Parameter**      |             **Description**               |
|-------------------|------------------------------------|
| ls_id             | The ID of the log stream to be modified.|
| unit_group_id     | The ID of the target unit group of the log stream to be modified. This parameter applies only to homogeneous zones. When you execute this statement, you must modify at least one attribute of the log stream, namely, `UNIT_GROUP` or `PRIMARY_ZONE`.|
| unit_id_list      | The list of units to which the log stream is distributed. Separate multiple unit IDs with commas (,). This parameter applies only to heterogeneous zones.|
| zone_name         | The name of the target primary zone of the log stream to be modified. When you execute this statement, you must modify at least one attribute of the log stream, namely, `UNIT_GROUP` or `PRIMARY_ZONE`.|
| tenant_name       | The name of the tenant to be operated. This parameter is optional. <main id="notice" type='notice'><h4>Notice</h4><p>Only the system tenant can specify other tenants. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</p></main>|

## Examples

:::tab
tab Homogeneous zone mode

* System tenant

  * Modify only the `UNIT_GROUP` parameter of the log stream

    The system tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the `obtenant` tenant.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002 TENANT = obtenant;
    ```

  * Modify only the `PRIMARY_ZONE` parameter of the log stream

    The system tenant changes the `PRIMARY_ZONE` parameter of the 1002 log stream of the `obtenant` tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

  * Modify both the `UNIT_GROUP` and `PRIMARY_ZONE` parameters of the log stream

    The system tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the `obtenant` tenant to `z1`, and changes the `PRIMARY_ZONE` parameter to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

* User tenant

  * Modify only the `UNIT_GROUP` parameter of the log stream

    The user tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the current tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002;
    ```

  * Modify only the `PRIMARY_ZONE` parameter of the log stream

    The user tenant changes the `PRIMARY_ZONE` parameter of the 1002 log stream of the current tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1';
    ```

  * Modify both the `UNIT_GROUP` and `PRIMARY_ZONE` parameters of the log stream

    The user tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the current tenant to `z1`, and changes the `PRIMARY_ZONE` parameter to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1';
    ```

tab Hybrid Zone mode

* System tenant

  * Modify only the `UNIT_LIST` of the log stream

    The system tenant modifies the location of the 1002 log stream of the `obtenant` tenant to the `UNIT_LIST` with `unit_id` values of 1001, 1002, and 1003.
 
    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003) TENANT = obtenant;
    ```

  * Modify only the `PRIMARY_ZONE` of the log stream

    The system tenant modifies the first priority of the leader of the 1002 log stream of the `obtenant` tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

  * Modify both the `UNIT_LIST` and `PRIMARY_ZONE` of the log stream

    The system tenant modifies the location of the 1002 log stream of the `obtenant` tenant to the `UNIT_LIST` with `unit_id` values of 1001, 1002, and 1003, and modifies the first priority of the leader to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003), PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

* User tenant

  * Modify only the `UNIT_LIST` of the log stream

    The user tenant modifies the location of the 1002 log stream to the `UNIT_LIST` with `unit_id` values of 1001, 1002, and 1003.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003);
    ```

  * Modify only the `PRIMARY_ZONE` of the log stream

    The user tenant modifies the first priority of the leader of the 1002 log stream to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1';
    ```

  * Modify both the `UNIT_LIST` and `PRIMARY_ZONE` of the log stream

    The user tenant modifies the location of the 1002 log stream to the `UNIT_LIST` with `unit_id` values of 1001, 1002, and 1003, and modifies the first priority of the leader to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003), PRIMARY_ZONE 'z1';
    ```
