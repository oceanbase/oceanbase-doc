# MODIFY LS

## Description

This statement is used to change the log stream, including modifying the `UNIT_GROUP` and `PRIMARY_ZONE` of the log stream.

## Limitations and considerations

* When changing the log stream, the log stream to be changed must exist and be in the `NORMAL` state.
* When changing the log stream, the tenant of the log stream must be in the `NORMAL` state.
* When modifying the `UNIT_GROUP` of a primary tenant, no load balancing task is running for all log streams of the tenant.
* We recommend that you do not modify the `UNIT_GROUP` attribute of a standby tenant. This is because the `UNIT_GROUP` attribute of a standby tenant is automatically adjusted. Therefore, manually modifying the `UNIT_GROUP` attribute of a standby tenant may not take effect.
* When modifying the `UNIT_GROUP` attribute of a log stream, the target `UNIT_GROUP` must be in the `ACTIVE` state.
* When modifying the `PRIMARY_ZONE` attribute of a log stream, make sure that the modified zone is included in the `ZONE_LIST` of the tenant. For a log stream, you can set only one zone as the `PRIMARY_ZONE`. For example, you can set `z1` or `z2`, but you cannot set `z1,z2`, `z1; z2`, or `RANDOM` for a log stream.
* When changing the log stream, the tenant-level parameter `enable_rebalance` must be disabled. The value of `enable_rebalance` must be `False`. When `enable_rebalance` is enabled, the tenant's load balancing module may automatically adjust the `PRIMARY_ZONE` and `UNIT_GROUP` attributes of the log stream.
* Only broadcast logs and system logs (Log Stream 1) support setting `UNIT_GROUP` to 0.

## Permissions

To execute this statement, you must have the `ALTER SYSTEM` privilege. For more information about OceanBase Database privileges, see [Privilege types in MySQL mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege types in Oracle mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM MODIFY LS
    LS [=] ls_id
    [UNIT_GROUP [=] unit_group_id],
    [PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

|     **Parameter**      |             **Description**               |
|-------------------|------------------------------------|
| ls_id             | The ID of the log stream to be modified.|
| unit_group_id     | The ID of the target unit group of the log stream to be modified. When you execute this statement, you must modify at least one attribute of the log stream, namely, `UNIT_GROUP` or `PRIMARY_ZONE`.|
| zone_name         | The name of the target primary zone of the log stream to be modified. When you execute this statement, you must modify at least one attribute of the log stream, namely, `UNIT_GROUP` or `PRIMARY_ZONE`.|
| tenant_name       | The name of the tenant to be operated. This parameter is optional. <main id="notice" type='notice'><h4>Notice</h4><p>Only the system tenant can specify other tenants. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</p></main>|

## Examples

* System tenant

  * Modify only the `UNIT_GROUP` parameter of the log stream

    The system tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the `obtenant` tenant.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002 TENANT = obtenant;
    ```

  * Modify only the `PRIMARY_ZONE` parameter of the log stream

    The system tenant changes the `PRIMARY_ZONE` parameter of the 1002 log stream of the `obtenant` tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

  * Modify both the `UNIT_GROUP` and `PRIMARY_ZONE` parameters of the log stream

    The system tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the `obtenant` tenant to `z1`, and changes the `PRIMARY_ZONE` parameter to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

* User tenant

  * Modify only the `UNIT_GROUP` parameter of the log stream

    The user tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the current tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002;
    ```

  * Modify only the `PRIMARY_ZONE` parameter of the log stream

    The user tenant changes the `PRIMARY_ZONE` parameter of the 1002 log stream of the current tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1';
    ```

  * Modify both the `UNIT_GROUP` and `PRIMARY_ZONE` parameters of the log stream

    The user tenant changes the `UNIT_GROUP` parameter of the 1002 log stream of the current tenant to `z1`, and changes the `PRIMARY_ZONE` parameter to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1';
    ```
