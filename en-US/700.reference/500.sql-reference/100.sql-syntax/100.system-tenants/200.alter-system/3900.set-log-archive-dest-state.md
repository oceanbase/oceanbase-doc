# SET LOG_ARCHIVE_DEST_STATE

## Purpose

The `SET LOG_ARCHIVE_DEST_STATE` statement is used to set the status of the archive destination.

## Privilege requirements

This statement must be executed by the `root` user of the `sys` tenant (`root@sys`) or the administrator user of each tenant. Specifically:

* The default administrator user in MySQL mode is the `root` user.
* The default administrator user in Oracle mode is the `SYS` user.

## Syntax

```sql
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE={'ENABLE' | 'DEFER'} [TENANT = tenant_name];
```

## Parameters

| Parameter                    | Description                                                                                                   |
|-------------------------|--------------------------------------------------------------------------------------------------------|
| 'ENABLE' \| 'DEFER'     | Specifies the status of the archive destination:<ul><li>`ENABLE`: Enabled status. If the archive mode is enabled and the archive destination is configured, the system will start executing the archiving task. After the archive destination is configured, it is in this status by default.</li> <li>`DEFER`: Deferred status. If the archive mode is enabled and there are archiving tasks, the system will pause the archiving tasks when the status is set to `DEFER`.</li></ul>                                                                   |
| tenant_name             | Specifies the tenant name for which the archive destination status is to be set. Each statement can only set the archive destination status for one tenant.<main id="notice" type='notice'><h4>Notice</h4><p>Only the system tenant needs to specify the target tenant using the <code>TENANT tenant_name</code> clause when executing this command. User tenants can only execute this command for themselves, so this clause is not required.</p></main>  |

## Examples

Assume that the archive destination has been configured for the `mysql_tenant` tenant. Here are some examples:

* The system tenant pauses log archiving for the `mysql_tenant` tenant at the archive destination.

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'DEFER' TENANT = mysql_tenant;
  ```

* The `mysql_tenant` tenant starts log archiving at the archive destination.

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'ENABLE';
  ```
