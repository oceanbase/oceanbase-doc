# LOAD MODULE DATA

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This statement was introduced in V4.4.0.</p>
</main>

## Description

This statement is used to load specified module data into a tenant.

## Syntax

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>Only the SYS tenant can execute this statement.</p>
</main>

```sql
ALTER SYSTEM LOAD MODULE DATA
 module = {gis|timezone}
 tenant = <tenant_name>
 infile = <file_name>;
```

## Parameter description

| **Parameter** | **Description** |
| ----------- | -------- |
| module     | Required. <ul><li><code>module = gis</code>: specifies the GIS module.</li><li><code>module = timezone</code>: specifies the timezone module.</li></ul> |
| tenant     | Required. The tenant to operate on. |
| infile     | Optional. The path of the data file to load. You can specify an absolute path or a path relative to the OBServer working directory. If this parameter is not specified, the default internal file path and file name are used. |

## Example

Load the GIS module data into the MySQL tenant:

```sql
ALTER SYSTEM LOAD MODULE DATA module=gis tenant=mysql;
```
