# LOAD MODULE DATA

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This statement is supported from V4.4.0. </p>
</main>

## Purpose

This statement is used to import a specified feature to a specific tenant.

## Syntax

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>Only the SYS tenant can execute this statement. </p>
</main>

The syntax is as follows:

```sql
ALTER SYSTEM LOAD MODULE DATA
 module = {gis|timezone}
 tenant = <tenant_name>
 infile = <file_name>;
```

## Syntax

|   **Field**  | **Description** |
| ----------- | -------- |
| module     | Required. <ul><li>`module = gis` indicates the GIS feature. </li><li>`module = timezone` indicates the timezone feature. </li></ul> |
| tenant     | Required. The tenant to which the feature is imported. |
| infile     | Optional. The path of the data file to be imported. You can specify an absolute path or a relative path to the OBServer working directory. If this parameter is not specified, the default file path and file name are used. |

## Examples

Import the GIS feature to a MySQL tenant:

```sql
ALTER SYSTEM LOAD MODULE DATA module=gis tenant=mysql;
```
