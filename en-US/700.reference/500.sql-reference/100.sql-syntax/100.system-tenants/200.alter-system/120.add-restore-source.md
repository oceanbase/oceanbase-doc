# ADD RESTORE SOURCE

## Purpose

This statement is used to load the path that needs to be restored.

## Privilege requirements

To execute this statement, the current user must have the `ALTER SYSTEM` privilege.

## Syntax

```sql
ALTER SYSTEM ADD RESTORE SOURCE 'restore_path';
```

## Parameters

|              **Parameter**       |                     **Description**                       |
|-----------------------------|----------------------------------------------------|
| restore_path                | The path of the data backup set (`backup_set`) or log archive (`archivelog_piece`) to be loaded. You can specify one or more paths. <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>If the <code>backup_set</code> or <code>archivelog_piece</code> to be loaded is stored in an object storage service, the <code>host</code>, <code>access_id</code>, and <code>access_key</code> parameters must be the same for each <code>backup_set</code> or <code>archivelog_piece</code> path. </li><li>This statement can be executed multiple times in the same session. When executed multiple times in the same session, the system will incrementally add to the restore source list. </li></ul></p></main>|

## Examples

1. Load the backup_set to be restored.

   ```shell
   obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'file:///ob_backup/data/backup_set_1_full';
   ```

2. Load the archivelog_piece to be restored.

   ```shell
   obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'file:///ob_backup/archive/piece_d1002r1p1,file:///ob_backup/archive/piece_d1002r1p2';
   ```

   ```shell
   obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'oss://test_bucket/archive/piece_1?host=***&access_id=x****&access_key=****';
   ```
