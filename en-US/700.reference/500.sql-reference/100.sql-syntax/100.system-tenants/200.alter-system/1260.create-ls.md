# CREATE LS

## Purpose

This statement is used to create a user log stream.

## Limitations and considerations

* Currently, only regular user log streams can be created, and broadcast log streams are not supported.

* In the current version, tenants can be configured in either homogeneous zone mode or heterogeneous zone mode:

  * In homogeneous zone mode, you must specify a unit group to create a log stream.

  * In heterogeneous zone mode, you must specify a list of units to create a log stream.

  For more information about the differences between homogeneous zone mode and heterogeneous zone mode, see [Data distribution](../../../../../600.manage/300.replica-management/400.data-distribution.md).

* The operation of creating a log stream can only be performed on the primary tenant. Additionally, the `STATUS` and `SWITCHOVER_STATUS` of the tenant to be operated on must be `NORMAL`.

* When creating a log stream:

  * In homogeneous zone mode, the target `UNIT_GROUP` must be in the `ACTIVE` state, and the value of the target `UNIT_GROUP_ID` in the `DBA_OB_UNITS` view must not be 0.

  * In heterogeneous zone mode, the target `UNIT_LIST` must be in the `ACTIVE` state, and the specified target `UNIT_LIST` must not be empty.

* When specifying the `PRIMARY_ZONE` for the log stream to be created, ensure that the specified zone is present in the `ZONE_LIST` of the tenant. For a log stream, setting the `PRIMARY_ZONE` is slightly different from setting the `PRIMARY_ZONE` for a tenant. A log stream can only have one zone specified, such as `z1` or `z2`, unlike a tenant which can have multiple zones specified, such as `z1,z2`, `z1; z2`, or `RANDOM`.

* Load balancing-related configuration items are recommended to be disabled, i.e., set to `False`. Otherwise:

  * If the tenant-level configuration item [enable_rebalance](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2800.enable_rebalance.md) is enabled, i.e., set to `True`, the created log stream will be migrated from the target `UNIT_GROUP` to other `UNIT_GROUP`s by the system.

  * If the tenant-level configuration item [enable_transfer](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3000.enable_transfer.md) is enabled, i.e., set to `True`, the created log stream may be deleted.

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase Database privileges, see [Privilege types in MySQL mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege types in Oracle mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM CREATE LS
    {UNIT_GROUP [=] unit_group_id} | {UNIT_LIST [=] (unit_id_list)}
    [,PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

|     **Parameter**      |             **Description**               |
|-------------------|------------------------------------|
| unit_group_id     | The ID of the target `UNIT_GROUP` for the log stream to be created. This parameter is applicable only in homogeneous zone mode.|
| unit_id_list      | The list of units where the log stream to be created is distributed. Multiple unit IDs are separated by commas (,). This parameter is applicable only in heterogeneous zone mode.|
| zone_name         | The primary zone for the log stream to be created. If you do not specify `PRIMARY_ZONE`, the system will automatically select a zone to assign.|
| tenant_name       | Optional. The name of the tenant to be operated on.<main id="notice" type='notice'><h4>Notice</h4><p>Only the sys tenant can specify other tenants. A user tenant can only specify itself. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all meta tenants. </p></main>|

## Examples

:::tab
tab Homogeneous zone mode

* The sys tenant

  The sys tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001 TENANT = obtenant;
  ```

  The sys tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* A user tenant

  A user tenant creates a log stream for itself on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001;
  ```

  A user tenant creates a log stream for itself on the `UNIT_GROUP` with ID 1001 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1';
  ```

tab Heterogeneous zone mode

* The sys tenant

  The sys tenant creates a log stream for the `obtenant` tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003) TENANT = obtenant;
  ```

  The sys tenant creates a log stream for the `obtenant` tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* A user tenant

  A user tenant creates a log stream for itself on the `UNIT_LIST` with IDs 1001, 1002, and 1003.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003);
  ```

  A user tenant creates a log stream for itself on the `UNIT_LIST` with IDs 1001, 1002, and 1003 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1';
  ```

:::
