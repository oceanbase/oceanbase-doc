# CREATE LS

## Description

This statement is used to create a user log stream.

## Limitations and considerations

* At present, only ordinary user log streams can be created.
* You can create a log stream only in the primary tenant. The `STATUS` and `SWITCHOVER_STATUS` of the tenant for which a log stream is to be created must be `NORMAL`.
* When you create a log stream, the target `UNIT_GROUP` must be in the `ACTIVE` state, and the value of `UNIT_GROUP_ID` cannot be 0.
* If you specify a `PRIMARY_ZONE` for the log stream to be created, make sure that the zone is included in the `ZONE_LIST` of the tenant. A log stream can have only one primary zone, such as `z1` or `z2`. You cannot set `z1,z2`, `z1; z2`, or `RANDOM` for a log stream, as you can for a tenant.
* We recommend that you set load balancing-related parameters to `False`. Otherwise:

  * If the tenant-level parameter [enable_rebalance](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2800.enable_rebalance.md) is set to `True`, the log stream is migrated from the target `UNIT_GROUP` to another `UNIT_GROUP`.

  * If the tenant-level parameter [enable_transfer](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3000.enable_transfer.md) is set to `True`, the log stream may be deleted.

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about the privileges of OceanBase Database, see [Privilege types in MySQL mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege types in Oracle mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM CREATE LS
    UNIT_GROUP [=] unit_group_id,
    [PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

|     **Parameter**      |             **Description**               |
|-------------------|------------------------------------|
| unit_group_id     | The ID of the target `UNIT_GROUP`. |
| zone_name         | The primary zone of the log stream to be created. If you do not specify `PRIMARY_ZONE`, the system automatically selects a zone for allocation. |
| tenant_name       | The name of the tenant for which a log stream is to be created. <main id="notice" type='notice'><h4>Notice</h4><p>You can specify other tenants only in the sys tenant. A user tenant can specify only its own tenant. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, and all Meta tenants. </p></main>|

## Examples

* System tenant

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001 TENANT = obtenant;
  ```

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1' TENANT = mq_t1;
  ```

* User tenant

  The user tenant creates a log stream for the current tenant on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001;
  ```

  The user tenant creates a log stream for the current tenant on the `UNIT_GROUP` with ID 1001 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1';
  ```
