# CREATE LS

## Purpose

This statement is used to create a user log stream.

## Limitations and considerations

* At present, only regular user log streams can be created. Broadcast log streams are not supported.

* The current version supports both homogeneous and heterogeneous zone modes for tenants:

  * In homogeneous zone mode, log streams must be created by specifying a unit group.

  * In heterogeneous zone mode, log streams must be created by specifying a unit list.

  For more information about the differences between homogeneous and heterogeneous zone modes, see [Data distribution](../../../../../600.manage/300.replica-management/400.data-distribution.md).

* Log stream creation is only supported on the primary tenant. Additionally, the tenant of the log stream to be created must have both `STATUS` and `SWITCHOVER_STATUS` set to `NORMAL`.

* When creating a log stream:

  * In homogeneous zone mode, ensure that the target `UNIT_GROUP` is in the `ACTIVE` state, and the value of the target `UNIT_GROUP_ID` in the `DBA_OB_UNITS` view is not 0.

  * In heterogeneous zone mode, ensure that the target `UNIT_LIST` is in the `ACTIVE` state, and the specified target `UNIT_LIST` is not empty.

* When specifying the `PRIMARY_ZONE` for the log stream to be created, ensure that the specified zone is included in the tenant's `ZONE_LIST`. For log streams, setting the `PRIMARY_ZONE` is slightly different from setting it for tenants: only a single zone (such as `z1` or `z2`) can be set, whereas tenants can use multiple zones (for example, `z1,z2`, `z1; z2`) or `RANDOM`.

* It is recommended to disable load balancing-related parameters, that is, set their values to `False`. Otherwise:

  * If the tenant-level parameter [enable_rebalance](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2800.enable_rebalance.md) is enabled (`True`), the created log stream may be migrated by the system from the target `UNIT_GROUP` to another `UNIT_GROUP`.

  * If the tenant-level parameter [enable_transfer](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3000.enable_transfer.md) is enabled (`True`), the created log stream may be deleted.

## Privilege requirements

To execute this statement, you must have the `ALTER SYSTEM` privilege. For more information about the privileges of OceanBase Database, see [Privilege types in MySQL-compatible mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege types in Oracle-compatible mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM CREATE LS
    {UNIT_GROUP [=] unit_group_id} | {UNIT_LIST [=] (unit_id_list)}
    [,PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

|     **Parameter**      |             **Description**               |
|-------------------|------------------------------------|
| unit_group_id     | The ID of the target `UNIT_GROUP`. Applies only to homogeneous zones. |
| unit_id_list      | The list of units where the log stream is to be distributed. Separate multiple unit IDs with commas (,). Applies only to heterogeneous zones. |
| zone_name         | The primary zone of the log stream to be created. If you do not specify `PRIMARY_ZONE`, the system automatically selects a zone for allocation. |
| tenant_name       |Optional. The name of the tenant for which a log stream is to be created. <main id="notice" type='notice'><h4>Notice</h4><p>You can specify other tenants only in the sys tenant. A user tenant can specify only its own tenant. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, and all Meta tenants. </p></main>|

## Examples

:::tab
tab Homogeneous zone mode

* System tenant

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001 TENANT = obtenant;
  ```

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1' TENANT = mq_t1;
  ```

* User tenant

  The user tenant creates a log stream for the current tenant on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001;
  ```

  The user tenant creates a log stream for the current tenant on the `UNIT_GROUP` with ID 1001 and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1';
  ```

tab Heterogeneous Zone mode

* System tenant

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003) TENANT = obtenant;
  ```

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003, and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* User tenant

  The user tenant creates a log stream for this tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003);
  ```

  The user tenant creates a log stream for this tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003, and sets the `PRIMARY_ZONE` of the log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1';
  ```

:::
