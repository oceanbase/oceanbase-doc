# REMOVE REPLICA

## Purpose

This statement is used to remove a replica from a log stream.

## Limitations and considerations

* Ensure that the log stream can still form a majority after the replica is removed, otherwise an error will be returned when executing maintenance commands.

* This statement can only remove one replica at a time.

* For the same log stream of a tenant, except for replica migration tasks, only one disaster recovery task (including adding a replica, removing a replica, changing the replica type, and modifying the quorum size of the log stream) can be executed at a time.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>For the sys tenant, you can query the <code>CDB_OB_LS_REPLICA_TASKS</code> view to check whether a disaster recovery task is in progress. For a user tenant, you can query the <code>DBA_OB_LS_REPLICA_TASKS</code> view to check whether a disaster recovery task is in progress.</p>
    </main>

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase Database privileges, see [Privilege types in MySQL mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege types in Oracle mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM REMOVE REPLICA
    LS [=] ls_id
    SERVER [=] 'svr_ip:svr_port'
    [PAXOS_REPLICA_NUM [=] paxos_replica_num]
    [TENANT [=] 'tenant_name'];
```

## Parameters

|     **Parameter**      |             **Description**               |
|-------------------|------------------------------------|
| ls_id             | The ID of the log stream from which a replica is to be removed.|
| svr_ip:svr_port   | The IP address and port number of the server where the replica to be removed is located. Example: `xxx.xx.xxx.001:2882`.|
| paxos_replica_num | Optional. The number of required members for the leader of the log stream. If this parameter is not specified, the current default value of `paxos_replica_num` will be used. The maximum number of F replicas for a log stream is 7.<main id="notice" type='notice'><h4>Notice</h4><p>When you specify this parameter, the following conditions must be met: <ol><li>After the modification, <code>paxos_replica_num</code> must satisfy the majority requirement. </li><li>The value of <code>paxos_replica_num</code> must be greater than or equal to the number of members in the <code>MEMBER_LIST</code> of the current leader replica. For the sys tenant, you can query the <code>CDB_OB_LS_LOCATIONS</code> view to confirm this. For a user tenant, you can query the <code>DBA_OB_LS_LOCATIONS</code> view to confirm this. </li><li>The absolute value of the change in <code>paxos_replica_num</code> must not exceed 1. For example, if the current value of <code>paxos_replica_num</code> is 3, you can only change it to 2. </li></ul> If any of the above conditions are not met, an error will be returned. </p></main>|
| tenant_name       | Optional. The name of the tenant to operate on. If not specified, the current tenant will be used as the default. <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>The sys tenant can specify other tenants, while a user tenant can only specify itself. </li><li>This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants. </li></ul></p></main>|

## Examples

Execute the following statement in the sys tenant to remove a replica from the log stream of the `mysql001` tenant.

```sql
ALTER SYSTEM REMOVE REPLICA
    LS = 1001
    SERVER = 'xxx.xxx.xxx.001:2882'
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```

For more examples of removing log stream replicas, see [Reduce replicas](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/400.reduce-replica.md).
