# FLUSH SS_LOCAL_CACHE

<main id="notice" >
<h4>Applicability</h4>
<p>This statement is applicable only in the Shared-Storage (SS) mode. </p>
</main>

## Purpose

The `ALTER SYSTEM FLUSH SS_LOCAL_CACHE` statement is used to clear the local cache data of a specified type for a specified user tenant in the Shared-Storage (SS) mode.

## Privilege requirements

This statement must be executed by the `root` user of the `sys` tenant. User tenants do not support this statement.

## Syntax

```sql
ALTER SYSTEM FLUSH SS_LOCAL_CACHE TENANT [=] tenant_name [CACHE [=] cache_type];

cache_type:
    micro_cache
  | macro_cache
  | mem_macro_cache
  | hot_macro_cache
```

## Parameters

|       Parameter        |               Description                                   |
|-------------------|------------------------------------------------------|
| tenant_name       | Specifies the user tenant whose local cache data is to be cleared. Only one tenant can be specified in a statement.|
| cache_type        | Specifies the type of local cache data to be cleared. Only one type can be specified in a statement. The supported types are as follows:<ul><li>`micro_cache`: local persistent microblock cache</li> <li>`macro_cache`: local persistent macroblock cache</li> <li>`mem_macro_cache`: local memory macroblock cache</li> <li>`hot_macro_cache`: local persistent user hot data cache</li></ul><p>If the `CACHE [=] cache_type` clause is not used to specify the type of local cache data to be cleared, all types of local cache data will be cleared by default.</p> |

## Examples

* In the `sys` tenant, clear all types of local cache data for the `mysql_tenant` tenant.

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH SS_LOCAL_CACHE TENANT = 'mysql_tenant';
  ```

* In the `sys` tenant, clear the local memory macroblock cache data for the `mysql_tenant` tenant.

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH SS_LOCAL_CACHE TENANT = 'mysql_tenant' CACHE = 'mem_macro_cache';
  ```
