# FLUSH SS_LOCAL_CACHE

<main id="notice" >
<h4>Applicability</h4>
<p>This statement is only applicable to the Shared-Storage (SS) mode. </p>
</main>

## Purpose

The `ALTER SYSTEM FLUSH SS_LOCAL_CACHE` statement is used to clear the local cache data of a specified type for a specified user tenant in the Shared-Storage (SS) mode.

## Privilege requirements

This statement must be executed by the `root` user of the `sys` tenant. User tenants do not support this statement.

## Syntax

```sql
ALTER SYSTEM FLUSH SS_LOCAL_CACHE TENANT [=] tenant_name [CACHE [=] cache_type];

cache_type:
    micro_cache
  | macro_cache
  | mem_macro_cache
  | hot_macro_cache
```

## Parameters

|       Parameter        |               Description                                   |
|-------------------|------------------------------------------------------|
| tenant_name       | The user tenant whose local cache data is to be cleared. A statement supports specifying only one tenant.|
| cache_type        | The type of the local cache data to be cleared. A statement supports specifying only one type. The supported types are as follows:<ul><li>`micro_cache`: local persistent microblock cache</li> <li>`macro_cache`: local persistent macroblock cache</li> <li>`mem_macro_cache`: local memory macroblock cache</li> <li>`hot_macro_cache`: local persistent user hot data cache</li></ul><p>If you do not specify the local cache type to be cleared by using `CACHE [=] cache_type`, all types of local cache data are cleared by default. </p> |

## Examples

* In the `sys` tenant, clear all types of local cache data of the `mysql_tenant` tenant.

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH SS_LOCAL_CACHE TENANT = 'mysql_tenant';
  ```

* In the `sys` tenant, clear the local memory macroblock cache data of the `mysql_tenant` tenant.

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH SS_LOCAL_CACHE TENANT = 'mysql_tenant' CACHE = 'mem_macro_cache';
  ```
