# TRIGGER TTL

## Purpose

The `ALTER SYSTEM TRIGGER TTL` statement is used to manually trigger a tenant-level Time-To-Live (TTL) task. Expired data will be deleted during subsequent Compaction tasks.

## Privilege requirements

To execute the `ALTER SYSTEM TRIGGER TTL` statement, the current user must have the `ALTER SYSTEM` privilege. For more information about OceanBase Database privileges, see [Privilege classification in MySQL mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) and [Privilege classification in Oracle mode](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md).

## Syntax

```sql
ALTER SYSTEM TRIGGER TTL [TENANT [=] all | all_user | tenant_list];

tenant_list:
  tenant_name[,tenant_name ...]
```

## Parameters

|    Parameter        |        Description          |
|---------------|------------------------|
| TENANT        | Specifies the user tenant to initiate the TTL task in the sys tenant. When executed in the sys tenant, the user tenant must be specified. Multiple tenant names can be specified, separated by commas (,).<main id="notice" type='notice'> <h4>Notice</h4><p>Only the sys tenant needs to specify the target tenant using the <code>TENANT</code> clause. User tenants can only execute this command for themselves and cannot specify the <code>TENANT</code> clause.</p></main>       |

## Examples

* The sys tenant triggers a TTL task for the user tenant `tenant1`.

  1. Enable the TTL feature for the tenant `tenant1`.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM SET enable_ttl = True TENANT = tenant1;
     ```

  2. Manually trigger a TTL task for the user tenant `tenant1`.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM TRIGGER TTL TENANT = tenant1;
     ```

* A user tenant triggers a TTL task for itself.

  1. Enable the TTL feature.

     ```shell
     obclient(root@mysql001)[(none)]> ALTER SYSTEM SET enable_ttl = True;
     ```

  2. Manually trigger a TTL task.

     ```shell
     obclient(root@mysql001)[(none)]> ALTER SYSTEM TRIGGER TTL;
     ```
