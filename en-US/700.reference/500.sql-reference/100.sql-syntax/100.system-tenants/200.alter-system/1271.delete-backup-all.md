# DELETE BACKUP ALL

The `DELETE BACKUP ALL` statement is used to clear the backup sets or log archive pieces in the specified path (data backup path or archive path).

## Limitations and considerations

When using the `DELETE BACKUP ALL` statement to clear the backup sets or log archive pieces in the specified path:

* Only replaced backup or archive paths can be cleared. Current backup or archive paths cannot be cleared.
* The old path being cleared cannot be set as the backup or archive path again.
* After the data backup path or archive path is cleared, the corresponding path information will be deleted from the views [CDB_OB_BACKUP_STORAGE_INFO(sys tenant)](../../../../700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7300.o-cdb_ob_backup_storage_info-of-sys-tenant.md) and [DBA_OB_BACKUP_STORAGE_INFO(user tenant)](../../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/7300.o-dba_ob_backup_storage_info-of-mysql-mode.md).

## Privilege requirements

The statement must be executed by the `root` user of the `sys` tenant (`root@sys`) or the administrator of each tenant. Specifically:

* The default administrator in MySQL mode is the `root` user.
* The default administrator in Oracle mode is the `SYS` user.

## Syntax

```sql
ALTER SYSTEM DELETE BACKUP ALL delete_backup_action [TENANT [=] tenant_name];

delete_backup_action:
  DATA_BACKUP_DEST [=] 'data_backup_path'
| LOG_ARCHIVE_DEST [=] 'log_archive_path'
```

## Parameters

| Parameter      | Description                                                     |
|----------------|---------------------------------------------------------|
| data_backup_path | Specifies the data backup path to be cleared. |
| log_archive_path | Specifies the archive path to be cleared. |
| tenant_name     | Specifies the name of the user tenant for the path to be cleared. This parameter is optional and is required only when executed in the sys tenant.   |

## Examples

* For the sys tenant

  * Clear the data backup path.

    :::tab
    tab OSS

    The sys tenant clears the OSS backup path `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com` for the tenant `mysql001`.

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com' TENANT = mysql001;
    ```

    tab NFS

    The sys tenant clears the NFS backup path `file:///data/nfs/backup/data` for the tenant `mysql001`.

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='file:///data/nfs/backup/data' TENANT = mysql001;
    ```

    :::

  * Clear the archive path.

    :::tab
    tab OSS

    The sys tenant clears the OSS archive path `oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com` for the tenant `mysql001`.

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com' TENANT = mysql001;
    ```

    tab NFS

    The sys tenant clears the NFS archive path `file:///data/nfs/backup/archive` for the tenant `mysql001`.

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='file:///data/nfs/backup/archive' TENANT = mysql001;
    ```

    :::

* For a user tenant

  * Clear the data backup path.

    :::tab
    tab OSS

    The user tenant clears the OSS backup path `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com` for itself.

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com';
    ```

    tab NFS

    The user tenant clears the NFS backup path `file:///data/nfs/backup/data` for itself.

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='file:///data/nfs/backup/data';
    ```

    :::

  * Clear the archive path.

    :::tab
    tab OSS

    The user tenant clears the OSS archive path `oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com` for itself.

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com';
    ```

    tab NFS

    The user tenant clears the NFS archive path `file:///data/nfs/backup/archive` for itself.

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='file:///data/nfs/backup/archive';
    ```

    :::
