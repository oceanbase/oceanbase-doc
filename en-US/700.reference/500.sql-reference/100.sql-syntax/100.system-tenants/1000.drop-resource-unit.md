# DROP RESOURCE UNIT

## Purpose

You can use this statement to drop a resource unit.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Before you drop a resource unit, make sure that the resource unit is not in use. To drop a resource unit that is in use, remove it from the resource pool first. </p>
  </main>

## Syntax

```sql
DROP RESOURCE UNIT unit_name;
```

## Parameters

| **Parameter** | **Description** |
|-----------|----------------|
| unit_name | The name of the resource unit to be dropped.  |

## Examples

* If a resource unit is not allocated to a resource pool, you can directly drop it.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  Query OK, 0 rows affected
  ```

* If a resource unit is allocated to a resource pool, you cannot directly drop it. You must first remove the resource unit from the resource pool.

  For example, in the following example, resource unit `unit1` is allocated to resource pool `pool1`.

  ```shell
  obclient> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone2');
  ```

  If you directly drop resource unit `unit1`, an error is returned.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  ERROR 4634 (HY000): resource unit 'UNIT1' is referenced by some resource pool
  ```

  If you still want to remove `unit1` from `pool1`, you can first create a new resource unit named `unit2` and allocate `unit2` to `pool1`, and then drop `unit1`. Here is an example.

  1. Create a new resource unit named `unit2`.

     ```shell
     obclient> CREATE RESOURCE UNIT unit2 MAX_CPU 4, MEMORY_SIZE '5G', MAX_IOPS 1280,LOG_DISK_SIZE '10G', MIN_CPU=4, MIN_IOPS=1024;
     ```

  2. Remove `unit1` from `pool1`.

     ```shell
     obclient> ALTER RESOURCE POOL pool1 UNIT='';
     ```

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>The <code>ALTER RESOURCE POOL</code> statement can add or remove only one resource unit to or from a resource pool at a time. Therefore, you must remove <code>unit1</code> from the resource pool and then add <code>unit2</code> to it. </p>
     </main>

  3. Allocate `unit2` to `pool1`.

     ```shell
     obclient> ALTER RESOURCE POOL pool1 UNIT='unit2';
     ```

  4. Drop `unit1`. The drop operation is successful.

     ```shell
     obclient> DROP RESOURCE UNIT unit1;
     Query OK, 0 rows affected
     ```

* If a resource unit is allocated to a resource pool, you must drop the resource pool and the resource unit.

  For example, in the following example, resource unit `unit1` is allocated to resource pool `pool1`.

  ```shell
  obclient> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone2');
  ```

  If you directly drop resource unit `unit1`, an error is returned.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  ERROR 4634 (HY000): resource unit 'UNIT1' is referenced by some resource pool
  ```

  Drop resource pool `pool1` and then drop resource unit `unit1`. The drop operations are successful.

  ```shell
  obclient> DROP RESOURCE POOL pool1;
  Query OK, 0 rows affected
  ```

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  Query OK, 0 rows affected
  ```
