# DROP RESOURCE UNIT

## Purpose

This statement is used to drop a resource unit.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Before dropping a resource unit, make sure that the resource unit is not in use. If the resource unit is in use, you need to remove it from the resource pool before dropping it. </p>
  </main>

## Syntax

```sql
DROP RESOURCE UNIT unit_name;
```

## Parameters

|  **Parameter**   |     **Description**     |
|-----------|----------------|
| unit_name | The name of the resource unit to be dropped. |

## Examples

* If a resource unit has not been assigned to a resource pool, you can directly drop it.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  Query OK, 0 rows affected
  ```

* If a resource unit has been assigned to a resource pool, you cannot directly drop it. You need to remove it from the resource pool before dropping it.

  For example, in the following example, the resource unit `unit1` has been assigned to the resource pool `pool1`.

  ```shell
  obclient> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone2');
  ```

  If you directly drop the resource unit `unit1`, an error is returned.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  ERROR 4634 (HY000): resource unit 'UNIT1' is referenced by some resource pool
  ```

  If you still want to remove the resource unit `unit1` from the resource pool `pool1`, you can create a new resource unit `unit2` and assign it to the resource pool `pool1` before dropping the resource unit `unit1`. Here is an example:

  1. Create a new resource unit `unit2`.

     ```shell
     obclient> CREATE RESOURCE UNIT unit2 MAX_CPU 4, MEMORY_SIZE '5G', MAX_IOPS 1280,LOG_DISK_SIZE '10G', MIN_CPU=4, MIN_IOPS=1024;
     ```

  2. Remove the resource unit `unit1` from the resource pool `pool1`.

     ```shell
     obclient> ALTER RESOURCE POOL pool1 UNIT='';
     ```

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>Each time you execute the <code>ALTER RESOURCE POOL</code> command, you can only add or remove one resource unit from the resource pool. Therefore, you need to remove <code>unit1</code> first and then add <code>unit2</code>. </p>
     </main>

  3. Assign the resource unit `unit2` to the resource pool `pool1`.

     ```shell
     obclient> ALTER RESOURCE POOL pool1 UNIT='unit2';
     ```

  4. Drop the resource unit `unit1`. The operation is successful.

     ```shell
     obclient> DROP RESOURCE UNIT unit1;
     Query OK, 0 rows affected
     ```

* If you want to drop a resource unit that has been assigned to a resource pool, you need to drop the resource pool first and then drop the resource unit.

  For example, in the following example, the resource unit `unit1` has been assigned to the resource pool `pool1`.

  ```shell
  obclient> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone2');
  ```

  If you directly drop the resource unit `unit1`, an error is returned.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  ERROR 4634 (HY000): resource unit 'UNIT1' is referenced by some resource pool
  ```

  Drop the resource pool `pool1` first and then drop the resource unit `unit1`. The operation is successful.

  ```shell
  obclient> DROP RESOURCE POOL pool1;
  Query OK, 0 rows affected
  ```

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  Query OK, 0 rows affected
  ```
