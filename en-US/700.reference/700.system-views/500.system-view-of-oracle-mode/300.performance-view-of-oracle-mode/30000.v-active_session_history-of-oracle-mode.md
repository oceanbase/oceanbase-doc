# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view was renamed to <a href="31200.v-ob_active_session_history-of-oracle-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> starting from V4.2.2. </li><li>This view is available starting with V4.0.0. </li></ul>
</main>

## Purpose

This view displays the history of active sessions.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server to which the sample belongs. |
| SVR_PORT | NUMBER | NO | The port number of the server to which the sample belongs. |
| SAMPLE_ID | NUMBER | NO | The unique ID of the sample. |
| SAMPLE_TIME | TIMESTAMP(6) | NO | The time when the sample was taken. |
| CON_ID | NUMBER | NO | The tenant ID. |
| USER_ID | NUMBER | NO | The user ID of the session being sampled. |
| SESSION_ID | NUMBER | NO | The ID of the session being sampled. |
| SESSION_TYPE | VARCHAR2(10) | NO | The session type. Valid values: <li>FOREGROUND: a foreground session, which is a user session<li>BACKGROUND: a background session. This value is not supported. |
| SESSION_STATE | VARCHAR2(7) | NO | The session state. Valid values: <li>ON CPU: the session is not waiting and is executing SQL logic<li>WAITING: the session is waiting. For more information, see the `EVENT` column. |
| SQL_ID | VARCHAR2(32) | NO | The SQL ID. |
| PLAN_ID |  bigint(20) |NO  |The plan ID of the sampled SQL in the plan cache. This ID is used to associate the sampling point with the plan. |
| TRACE_ID         | VARCHAR2(64)  | NO   | The trace ID of the operator. |
| EVENT | VARCHAR2(64) | NO | The description of the wait event. |

| IN_PARSE | VARCHAR2(1) | NO | Indicates whether the session is parsing an SQL statement at the time the sample was taken. |
| IN_PL_PARSE | VARCHAR2(1) | NO | Indicates whether the session is parsing an SQL PL statement at the time the sample was taken. |

| IN_STORAGE_WRITE | VARCHAR2(1) | NO | Indicates whether the sampling point is in the storage write phase.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1. </p></main> |
| IN_REMOTE_DAS_EXECUTION | VARCHAR2(1) | NO | Indicates whether the sampling point is in the DAS remote execution phase.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1. </p></main> |

| IN_RPC_DECODE               | VARCHAR2(1)                       | NO   | This column indicates the deserialization operation being performed by the current SQL statement.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.5 for V4.2.x. </p></main>     |
| IN_CONNECTION_MGR           | VARCHAR2(1)                       | NO   | This column indicates the connection operation being performed by the current SQL statement.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.5 for V4.2.x. </p></main>     |
| PROGRAM | VARCHAR2(64) | NO | The name of the program being executed at the sampling point:<ul><li>Background thread: the name of the thread, such as `observer` or `WrTimer`.  </li><li>Foreground thread:<ul><li>For a regular request, it is `user@client_ip (thread_name)`.  </li><li>For an `inner_sql` remote execution, it is `INNER SQL REMOTE EXEC (thread_name)`.  </li><li>For a DAS remote execution, it is `DAS REMOTE EXEC (thread_name)`.  </li></ul> </li></ul><main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.2. </p></main>|
| MODULE | VARCHAR2(64) | NO | The MODULE value recorded at the sampling point. This value is set by using the `DBMS_APPLICATION_INFO.SET_MODULE` package. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.3. </p></main> |
| ACTION | VARCHAR2(64) | NO | The ACTION value recorded at the sampling point. This value is set by using the `DBMS_APPLICATION_INFO.SET_ACTION` package. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.3. </p></main> |
| CLIENT_ID | VARCHAR2(64) | NO | The CLIENT_ID value recorded at the sampling point. This value is set by using the `DBMS_APPLICATION_INFO.set_identifier` package. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.3. </p></main> |
