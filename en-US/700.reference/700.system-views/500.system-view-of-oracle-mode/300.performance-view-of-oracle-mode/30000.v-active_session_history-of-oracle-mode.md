# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
    <ul><li>For V4.3.x versions, this view was renamed to <a href="31200.v-ob_active_session_history-of-oracle-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> starting with V4.3.5. For V4.2.x versions, this view was renamed to <a href="31200.v-ob_active_session_history-of-oracle-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> starting with V4.2.2. </li>
  <li>This view is available starting with V4.0.0. </li></ul>
</main>

## Purpose

This view displays the active session history of the current OBServer node in the current tenant.

## Sample query

Query the history of active sessions on the current OBServer node in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$ACTIVE_SESSION_HISTORY WHERE ROWNUM <= 1\G
```
