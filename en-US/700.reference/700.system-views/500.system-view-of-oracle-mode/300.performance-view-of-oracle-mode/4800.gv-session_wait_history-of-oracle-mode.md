# GV$SESSION_WAIT_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `GV$SESSION_WAIT_HISTORY` view displays the information of the most recent 10 wait events for all sessions on all nodes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | NUMBER | NO | For V4.3.x versions:<ul><li> V4.3.5 BP2 and earlier versions:<br>This column indicates the server session ID in all connection modes (direct mode/ODP mode). </li><li> V4.3.5 BP2 and later versions:<ul><li> In direct mode:<br>This column indicates the server session ID. </li> <li> In ODP mode:<ul><li> If the <code>client_session_id_version</code> parameter is set to 2, this column indicates the client session ID. </li> <li> If the <code>client_session_id_version</code> parameter is set to 1, this column indicates the server session ID. </li></ul></li></ul></li></ul>  |
| CON_ID | NUMBER | NO | The tenant ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server. |
| SEQ# | NUMBER | NO | The sequence number of the wait event. |
| EVENT# | NUMBER | NO | The event number. |
| EVENT | VARCHAR2(64) | NO | The name of the wait event. |
| P1TEXT | VARCHAR2(64) | NO | The description of the first parameter of the wait event. |
| P1 | NUMBER | NO | The value of the first parameter of the wait event. |
| P2TEXT | VARCHAR2(64) | NO | The description of the second parameter of the wait event. |
| P2 | NUMBER | NO | The value of the second parameter of the wait event. |
| P3TEXT | VARCHAR2(64) | NO | The description of the third parameter of the wait event. |
| P3 | NUMBER | NO | The value of the third parameter of the wait event. |
| WAIT_TIME | NUMBER | NO | The wait time of the wait event, in hundredths of a second. |
| WAIT_TIME_MICRO | NUMBER | NO | The wait time of the wait event, in microseconds. |
| TIME_SINCE_LAST_WAIT_MICRO | NUMBER | NO | The time elapsed since the last wait ended, in microseconds. |

## Sample query

Query the information of the most recent 10 wait events for all sessions on all nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSION_WAIT_HISTORY WHERE ROWNUM =1\G
```
