# V$OB_PROCESSLIST

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_PROCESSLIST` view displays the session information on the current OBServer node.

## Sample query

Query the session information of the current OBServer node.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PROCESSLIST WHERE ROWNUM <= 1\G
```
