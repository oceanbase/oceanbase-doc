# GV$OB_PX_WORKER_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

In parallel execution scenarios, this view displays the execution information of each thread for the current tenant on all OBServer nodes.

## Columns

|    Column     |                Type                 | Nullable |      Description       |
|------------|-----------------------------------|------------|----------------|
| SESSION_ID | NUMBER(38)                        | NO         | For V4.3.x versions: <ul><li> For versions earlier than V4.3.5 BP2:<br>This field represents the server session ID in all connection modes (direct connection mode or ODP mode). </li><li> For V4.3.5 BP2 and later versions: <ul><li> In direct connection mode:<br>This field represents the server session ID. </li> <li> In ODP mode:</li><ul><li> If the value of the <code>client_session_id_version</code> parameter in ODP is <code>2</code>, this field represents the client session ID. </li> <li> If the value of the <code>client_session_id_version</code> parameter in ODP is <code>1</code>, this field represents the server session ID. </li></ul></ul></li></ul>      |
| TENANT_ID  | NUMBER(38)                        | NO         | The tenant ID          |
| SVR_IP     | VARCHAR2(46)                      | NO         | The IP address of the server     |
| SVR_PORT   | NUMBER(38)                        | NO         | The port of the server          |
| TRACE_ID   | VARCHAR2(128)                     | NO         | The trace_id of the SQL |
| QC_ID      | NUMBER(38)                        | NO         | The qc_id in PX    |
| SQC_ID     | NUMBER(38)                        | NO         | The sqc_id in PX   |
| WORKER_ID  | NUMBER(38)                        | NO         | The thread ID          |
| DFO_ID     | NUMBER(38)                        | NO         | The dfo_id in PX   |
| START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | The time when the thread starts running      |

## Sample query

Query all threads of the current user tenant in all OBServer nodes for the tenant in a parallel execution scenario.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_PX_WORKER_STAT\G
```
