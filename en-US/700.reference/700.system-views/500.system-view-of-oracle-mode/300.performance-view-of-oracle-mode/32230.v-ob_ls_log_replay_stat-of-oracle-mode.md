# V$OB_LS_LOG_REPLAY_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.2, this view is available starting from V4.4.2 BP2.</p>
</main>

## Overview

The `V$OB_LS_LOG_REPLAY_STAT` view displays the log replay progress for each log stream (LS) replica on the current node of a tenant. You must query this view on a standby database, or on the primary database by querying a follower replica.

Since logs are not replayed on the leader replica of the primary tenant (primary database), in query results, a row with `ROLE = LEADER` for the primary tenant is meaningless.

## Columns

| Column | Type | Nullable | Description |
| -------------------- | --------------------- | ---------------- | ------------- |
| TENANT_ID | NUMBER(38) | NO | Tenant ID |
| SVR_IP | VARCHAR2(46) | NO | Server IP address |
| SVR_PORT | NUMBER(38) | NO | Server port number |
| LS_ID | NUMBER(38) | NO | Log stream ID |
| ROLE | VARCHAR2(32) | NO | Log stream replica roles:<ul><li>`LEADER`: Primary replica</li> <li>`FOLLOWER`: Follower replica</li></ul> |
| ENABLED | NUMBER(38) | NO | Whether the log replay service is enabled. |
| END_LSN | NUMBER(38) | NO | LSN written by Palf (right boundary for log replay) |
| UNSUBMITTED_LSN | NUMBER(38) | NO | The LSN of the next log to be committed to the replay queue |
| UNSUBMITTED_SCN | NUMBER(38) | NO | SCN of the next log to be submitted to the replay queue |
| MIN_UNREPLAYED_LSN | NUMBER(38) | NO | LSN of the earliest unreplayed log in the replay queue |
| MIN_UNREPLAYED_SCN | NUMBER(38) | NO | SCN of the earliest unreplayed log in the replay queue |
| PENDING_CNT | NUMBER(38) | NO | Number of tasks pending replay in memory |

## Sample query

In a standby tenant, view the log replay progress of each log stream replica on the current node of the tenant.

```shell
obclient(root@standby_tenant)[SYS]> SELECT LS_ID, ROLE, ENABLED,
        END_LSN, UNSUBMITTED_LSN, MIN_UNREPLAYED_LSN, PENDING_CNT
        FROM SYS.V$OB_LS_LOG_REPLAY_STAT;
```

The query result is as follows:

```shell
+-------+----------+---------+-----------+-----------------+--------------------+-------------+
| LS_ID | ROLE     | ENABLED | END_LSN   | UNSUBMITTED_LSN | MIN_UNREPLAYED_LSN | PENDING_CNT |
+-------+----------+---------+-----------+-----------------+--------------------+-------------+
|     1 | FOLLOWER |       1 | 300636581 |       300299240 |          300299240 |           0 |
|  1001 | FOLLOWER |       1 | 197547054 |       197259486 |          197259486 |           0 |
+-------+----------+---------+-----------+-----------------+--------------------+-------------+
2 rows in set
```
