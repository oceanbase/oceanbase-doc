# GV$OB_TRANSACTION_PARTICIPANTS

## Features

Displays the participants of all active transactions on all OBServer nodes.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in MySQL V4.0.0. </p>
</main>

## Field descriptions

| **Column** | **Type** | **Nullable?** | **Description** |
|------------------|-----------------------------------|------------|-----------|
| TENANT_ID        | NUMBER(38)                        | NO         | Tenant ID.    |
| SVR_IP           | VARCHAR2(46)                      | NO         | Server IP address.  |
| SVR_PORT         | NUMBER(38)                        | NO         | Server port number.  |
| SESSION_ID       | NUMBER(38)                        | NO         | Session ID.  |
| SCHEDULER_ADDR   | VARCHAR2(64)                      | NO         | Address of the scheduling node.  |
| TX_TYPE          | VARCHAR2(11)                      | NO         | Transaction type.  |
| TX_ID            | NUMBER(38)                        | NO         | Transaction ID.  |
| LS_ID            | NUMBER(38)                        | NO         | Log stream ID to which the context belongs.  |
| PARTICIPANTS     | VARCHAR2(1024)                    | NO         | Participant list.  |
| CTX_CREATE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | Creation time of the context.  |
| TX_EXPIRED_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | Timeout time of the transaction.  |
| STATE            | VARCHAR2(9)                       | NO         | Commit status of the context.  |
| ACTION           | VARCHAR2(10)                      | NO         | Last executed action.  |
| PENDING_LOG_SIZE | NUMBER(38)                        | NO         | Size of the data to be persisted.  |
| FLUSHED_LOG_SIZE | NUMBER(38)                        | NO         | Size of the data that has been persisted.  |
| IS_EXITING       | VARCHAR2(3)                       | NO         | Whether the system is exiting.  |
| ROLE             | VARCHAR2(8)                       | NO         | Role of the context.  |
| COORD             | NUMBER(38)                        | NO   | ID of the corresponding coordinator (takes effect only after the transaction enters the commit phase).  |
| LAST_REQUEST_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | Time when the last external request was received.  |
| FORMATID          | NUMBER(38)                        | NO   | Format type of xid.  |
| GLOBALID          | VARCHAR2(256)                     | NO   | Global identifier of the XA transaction.  |
| BRANCHID          | VARCHAR2(256)                     | NO   | Branch qualifier of the XA transaction.  |
