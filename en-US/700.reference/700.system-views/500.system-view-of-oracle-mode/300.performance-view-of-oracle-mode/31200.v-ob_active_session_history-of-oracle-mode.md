# V$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.2. </p>
</main>

## Purpose

The `V$OB_ACTIVE_SESSION_HISTORY` view displays the history of active sessions.
