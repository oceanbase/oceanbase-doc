# V$OB_LS_LOG_RESTORE_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore status at the log stream level for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| LS_ID | NUMBER(38) | NO | The log stream ID. |
| SYNC_LSN | NUMBER(38) | NO | The maximum continuous majority LSN of the standby database or the maximum consumable LSN. |
| SYNC_SCN | NUMBER(38) | NO | The maximum continuous majority SCN of the standby database or the maximum consumable SCN. |
| SYNC_STATUS | VARCHAR2(128) | NO | The log stream restore status. <ul><li>NORMAL: Normal synchronization.  </li><li>SOURCE HAS A GAP: The log source has a gap. </li><li>STANDBY LOG NOT MATCH: The standby log is inconsistent with the log source. The logs at the same LSN are different.  </li><li>CHECK USER OR PASSWORD: The username or password of the replication account is incorrect. The log source cannot be accessed.  </li><li>CHECK NETWORK: The log source is unreachable. This may be due to an incorrect tenant access IP address or port.  </li><li>FETCH LOG TIMEOUT: Log fetching timed out.  </li><li>RESTORE SUSPEND: The log restore has reached the maximum synchronization point.  </li><li>STANDBY NEED UPGRADE: The standby database version is earlier than the primary database version. The standby database needs to be upgraded.  </li><li>CHECK PRIMARY ALIVE: The primary database cannot be accessed. Check whether the primary database has been deleted.  </li><li> NOT AVAILABLE: The log synchronization is unavailable due to other exceptions. </li></ul>|
| ERR_CODE | NUMBER(38) | NO | The error code. 0 indicates normal synchronization. |
| COMMENT | VARCHAR2(2048) | NO | The error details. This column is empty during normal synchronization. |

## Sample query

Query the log restore status at the log stream level for the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_LS_LOG_RESTORE_STATUS;
```
