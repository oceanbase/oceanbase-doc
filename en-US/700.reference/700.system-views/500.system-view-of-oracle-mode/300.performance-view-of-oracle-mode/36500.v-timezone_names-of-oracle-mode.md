# V$TIMEZONE_NAMES

## **Description**

Displays the names of valid time zones.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

| **Column** |    **Type**     | **Nullable?** |     **Description**     |
|----------|---------------|----------------|----------------|
| TZNAME   | varchar(64)   | NO             | Time zone region           |
| TZABBREV | varchar(8)    | NO             | Relative time abbreviation (for example, PDT) |
| CON_ID   | decimal(38,0) | NO             | Tenant ID          |
