# V$TIMEZONE_NAMES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays the names of valid time zones.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode. </p>
  </main>

## Columns

| **Column** |    **Type**     | **Nullable** |     **Description**     |
|----------|---------------|----------------|----------------|
| TZNAME   | varchar(64)   | NO             | The name of the time zone.           |
| TZABBREV | varchar(8)    | NO             | The abbreviation of the time zone (for example, PDT). |
| CON_ID   | decimal(38,0) | NO             | The tenant ID.          |
