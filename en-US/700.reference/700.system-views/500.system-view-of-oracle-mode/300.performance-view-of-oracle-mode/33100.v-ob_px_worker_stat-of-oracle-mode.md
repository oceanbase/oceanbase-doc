# V$OB_PX_WORKER_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

In parallel execution scenarios, this view displays the execution information of each thread for the current tenant on the current OBServer node.

## Columns

|    Column    |                Type                 | Nullable |       Description       |
|------------|-----------------------------------|------------|----------------|
| SESSION_ID | NUMBER(38)                        | NO         | For V4.2.x versions:<ul><li> V4.2.5 BP4 and earlier versions:<br>This field represents the server session ID in all connection modes (direct mode/ODP mode). </li><li> V4.2.5 BP4 and later versions:<ul><li> In direct mode:<br>This field represents the server session ID. </li> <li> In ODP mode:</li><ul><li> When the <code>client_session_id_version</code> parameter in ODP is set to 2, this field represents the client session ID. </li> <li> When <code>client_session_id_version</code> is set to 1, this field represents the server session ID. </li></ul></ul></li></ul>      |
| TENANT_ID  | NUMBER(38)                        | NO         | The tenant ID.          |
| SVR_IP     | VARCHAR2(46)                      | NO         | The IP address of the server.     |
| SVR_PORT   | NUMBER(38)                        | NO         | The port number of the server.          |
| TRACE_ID   | VARCHAR2(128)                     | NO         | The trace ID of the SQL statement. |
| QC_ID      | NUMBER(38)                        | NO         | The qc_id in PX.    |
| SQC_ID     | NUMBER(38)                        | NO         | The sqc_id in PX.   |
| WORKER_ID  | NUMBER(38)                        | NO         | The thread ID.          |
| DFO_ID     | NUMBER(38)                        | NO         | The dfo_id in PX.   |
| START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | The time when the thread started running.      |

## Sample query

In the user tenant, query the execution information of all threads for the current tenant on the current OBServer node in a parallel execution scenario.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PX_WORKER_STAT\G
```
