# V$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Introduced in V4.0.0. </p>
</main>

## Description

Displays the progress of a tablet-level major compaction.

## Field descriptions
