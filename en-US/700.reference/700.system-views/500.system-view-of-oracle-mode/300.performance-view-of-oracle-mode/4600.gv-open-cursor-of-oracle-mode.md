# GV$OPEN_CURSOR

## Purpose

Displays information about the open cursors in the current session.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

| Column | Type | Nullable? | Description |
|------|------|---------|-------------|
| SVR_IP | VARCHAR2(46) | NO | IP address of the server. |
| SVR_PORT | NUMBER(38) | NO | Port number of the server. |
| SADDR | VARCHAR2(8) | NO | Memory address of the session. |
| SID | NUMBER | NO | Session ID. |
| USER_NAME | VARCHAR2(30) | NO | Username. |
| ADDRESS | VARCHAR2(8) | NO | SQL address. The SQL address, together with the SQL hash value, uniquely identifies an SQL statement. Currently, this field is NULL. |
| HASH_VALUE | NUMBER | NO | SQL hash value. Currently, this field is NULL. |
| SQL_ID | VARCHAR2(32) | NO | SQL ID. |
| SQL_TEXT | VARCHAR2(60) | NO | The first 60 characters of the SQL statement. |
| LAST_SQL_ACTIVE_TIME | DATE | NO | Time when the SQL statement was last executed. |
| SQL_EXEC_ID | NUMBER | NO | Currently, this field is NULL. |
| CURSOR_TYPE | VARCHAR2(30) | NO | Cursor type. Currently, it can be in one of the following states:<ul><li>OPEN: indicates all open SQL statements in the current session. </li><li>SESSION CURSOR: indicates all session cursors in the current session. </li></ul>|
| CHILD_ADDRESS | VARCHAR2(30) | NO | Not supported. |
| CON_ID | NUMBER | NO | ID of the container to which the data belongs. The current value is `0`. |
