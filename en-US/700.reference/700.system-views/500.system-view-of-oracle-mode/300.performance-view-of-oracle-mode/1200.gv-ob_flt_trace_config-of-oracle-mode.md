# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the diagnostic information of full-link tracing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID.  </li><li>Other values: the ID of a user tenant or a Meta tenant. </li></ul> |
| TYPE | VARCHAR2(16) | NO | The monitoring level of the diagnostic information.  </li><li>Module/action level: diagnostic information is monitored at the module and action levels. </li><li>Client identifier level: diagnostic information is monitored at the client identifier level. </li></ul> |
| TENANT_NAME | VARCHAR2(128) | NO | The name of the tenant. |
| MODULE_NAME | VARCHAR2(4096) | NO | The name of the module. |
| ACTION_NAME | VARCHAR2(4096) | NO | The name of the action. |
| CLIENT_IDENTIFIER | VARCHAR2(65) | NO | The name of the client identifier. |
| LEVEL | NUMBER(38) | NO | The tracing monitoring level of the session. For example, 1 indicates that diagnostic information of level 1 is collected. |
| SAMPLE_PERCENTAGE | NUMBER(38) | NO | The sampling frequency of the session. For example, 50 indicates that diagnostic information is sampled with a 50% probability. |
| RECORD_POLICY | VARCHAR2(32) | NO | The tracing recording policy of the session. The following three policies are supported: <ul><li>ALL: all trace points that are sampled and enabled are printed to the log file. The trace points are printed to the log file when each span ends. </li><li>ONLY_SLOW_QUERY: only trace points that are sampled and enabled and belong to slow queries are printed to the log file. Other trace points are discarded. The trace points are printed to the log file after the request is determined to be a slow query. In the Proxy, for the root span, which is at the transaction level, the root span is printed only when a slow query is detected. </li><li>SAMPLE_AND_SLOW_QUERY: trace points that are sampled and enabled and meet the following conditions are printed to the log file: <ol><li>When the hidden parameter <code>_print_sample_ppm</code> is used for sampling with a 0.0001 probability, the trace point is printed to the log file only when the sampling result is selected. </li><li>The trace point meets the conditions for printing in the ONLY_SLOW_QUERY mode. </li></ol> In this mode, the trace points are not printed when the span ends. If condition 1 is met, the trace point is marked for forced printing at the client end and the information is passed to the subsequent link components. If condition 2 is met, the trace point is printed at the same time as in the ONLY_SLOW_QUERY mode. </li></ul> |

## Sample query

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_FLT_TRACE_CONFIG  WHERE ROWNUM < 10;
```
