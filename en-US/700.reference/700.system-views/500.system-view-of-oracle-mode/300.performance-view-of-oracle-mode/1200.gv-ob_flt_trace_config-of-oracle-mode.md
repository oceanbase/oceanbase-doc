# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the diagnostic information of full-link tracing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. Other values: the user tenant ID or the Meta tenant ID. |
| TYPE | VARCHAR2(16) | NO | The monitoring level of the diagnostic information.  </li><li>Module/action level: diagnostic information is monitored at the module and action levels. </li><li>Client identifier level: diagnostic information is monitored at the client identifier level. </li></ul> |
| TENANT_NAME | VARCHAR2(128) | NO | The tenant name. |
| MODULE_NAME | VARCHAR2(4096) | NO | The module name. |
| ACTION_NAME | VARCHAR2(4096) | NO | The action name. |
| CLIENT_IDENTIFIER | VARCHAR2(65) | NO | The client identifier name. |
| LEVEL | NUMBER(38) | NO | The full-link tracing monitoring level of the session. For example, 1 indicates diagnostic information of level 1. |
| SAMPLE_PERCENTAGE | NUMBER(38) | NO | The full-link tracing sampling frequency of the session. For example, 50 indicates that diagnostic information is sampled with a 50% probability. |
| RECORD_POLICY | VARCHAR2(32) | NO | The full-link tracing recording policy of the session. The following three policies are supported:<ul><li>ALL: all trace points that are sampled and enabled are printed to the log file. The trace points are printed to the log file at the end of each span.  </li><li>ONLY_SLOW_QUERY: all trace points that are sampled and enabled are printed to the log file, but only those that belong to slow queries are printed. Other trace points are discarded. For this recording policy, trace logs are printed only after a request is determined to be a slow query. In the Proxy, for the root span, which is at the transaction level, the root span is printed only when a slow query is detected.  </li><li>SAMPLE_AND_SLOW_QUERY: all trace points that are sampled and enabled are printed to the log file if the following conditions are met:<ol><li>When the hidden parameter <code>_print_sample_ppm</code> is used for sampling at a 0.0001 probability, the trace point is printed to the log only if it is selected for sampling.</li><li>The trace point meets the printing conditions of the ONLY_SLOW_QUERY mode.</li></ol>For this mode, the trace logs are not printed at the end of the span. If condition 1 is met, the trace log is forcibly printed at the client and the information is passed to the subsequent components in the chain. If condition 2 is met, the trace log is printed at the same time as in the ONLY_SLOW_QUERY mode.</li></ul> |

## Sample query

Query the diagnostic information of full-link tracing and display the first 10 records.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_FLT_TRACE_CONFIG  WHERE ROWNUM < 10;
```
