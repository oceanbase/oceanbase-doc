# GV$OB_TRANSACTION_PARTICIPANTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_TRANSACTION_PARTICIPANTS` view displays information about participants of active transactions on all OBServer nodes.

## Columns

|       Column       |                Type                 | Nullable |    Description     |
|------------------|-----------------------------------|------------|-----------|
| TENANT_ID        | NUMBER(38)                        | NO         | The tenant ID.     |
| SVR_IP           | VARCHAR2(46)                      | NO         | The IP address of the server. |
| SVR_PORT         | NUMBER(38)                        | NO         | The port number of the server.    |
| SESSION_ID       | NUMBER(38)                        | NO         | For V4.3.x versions:<ul><li> V4.3.5 BP2 and earlier versions:<br>This field indicates the server session ID in all connection modes (direct mode and ODP mode). </li><li> V4.3.5 BP2 and later versions:<ul><li> In direct mode:<br>This field indicates the server session ID. </li> <li> In ODP mode:</li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this field indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this field indicates the server session ID. </li></ul></ul></li></ul>      |
| SCHEDULER_ADDR   | VARCHAR2(64)                      | NO         | The address of the node where the scheduler resides. |
| TX_TYPE          | VARCHAR2(11)                      | NO         | The transaction type.      |
| TX_ID            | NUMBER(38)                        | NO         | The transaction ID.      |
| LS_ID            | NUMBER(38)                        | NO         | The ID of the log stream to which the transaction belongs.   |
| PARTICIPANTS     | VARCHAR2(1024)                    | NO         | The list of participants.     |
| CTX_CREATE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | The time when the context was created.  |
| TX_EXPIRED_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | The time when the transaction expired.   |
| STATE            | VARCHAR2(9)                       | NO         | The context submission status.   |
| ACTION           | VARCHAR2(10)                      | NO         | The last executed action.  |
| PENDING_LOG_SIZE | NUMBER(38)                        | NO         | The size of the data to be persisted.  |
| FLUSHED_LOG_SIZE | NUMBER(38)                        | NO         | The size of the data that has been persisted.  |
| IS_EXITING       | VARCHAR2(3)                       | NO         | Indicates whether the context is exiting.    |
| ROLE             | VARCHAR2(8)                       | NO         | The role of the context.     |
| COORD             | NUMBER(38)                        | NO   | The ID of the corresponding coordinator (effective only after the transaction enters the commit phase). |
| LAST_REQUEST_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | The time when the last external request was received. |
| FORMATID          | NUMBER(38)                        | NO   | The type of the xid format.  |
| GLOBALID          | VARCHAR2(256)                     | NO   | The global identifier of the XA transaction. |
| BRANCHID          | VARCHAR2(256)                     | NO   | The qualifier of the XA transaction branch. |

## Sample query

Query information about participants of active transactions on all OBServer nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_TRANSACTION_PARTICIPANTS \G
```
