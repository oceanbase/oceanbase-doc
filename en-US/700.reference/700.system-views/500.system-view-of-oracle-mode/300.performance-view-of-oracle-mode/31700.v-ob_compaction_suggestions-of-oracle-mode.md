# V$OB_COMPACTION_SUGGESTIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays compaction suggestions on the current node.

## Columns

|    Column     |                Type                 | **Nullable** |                                            Description                                            |
|-------------|-----------------------------------|----------------|--------|
| SVR_IP      | VARCHAR2(46)                      | NO             | The IP address of the server.                                                                                |
| SVR_PORT    | NUMBER(38)                        | NO             | The port number of the server.|
| TENANT_ID   | NUMBER(38)                        | NO             | The tenant ID. |
| TYPE        | VARCHAR2(64)                      | NO             | The type of compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persists the system metadata in the SSTable format to the disk. </li> <li>`MAJOR_MERGE`: tenant-level major compaction. </li> <li>`MEDIUM_MERGE`: partition-level major compaction. </li> <li>`MINI_MERGE`: mini compaction. Converts a MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Merges multiple Mini SSTables into a new Mini SSTable or merges multiple Mini SSTables with one Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of compaction. Merges data from a specified time point into a Meta Major SSTable. The data format is the same as that of a Major SSTable, and the SSTable does not contain multi-version data or uncommitted transaction data. </li></ul>    |
| TABLE_ID    | NUMBER(38)                        | NO             | The ID of the main table. |
| LS_ID       | NUMBER(38)                        | NO             | The ID of the log stream.|
| TABLET_ID   | NUMBER(38)                        | NO             | The ID of the data tablet.                                                                                  |
| START_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO             | The start time.  |
| FINISH_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO             | The end time.  |
| SUGGESTION  | VARCHAR2(1024)                      | NO             | The suggestion.  |
