# V$OB_LS_LOG_RESTORE_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore status of the current tenant at the log stream level.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| LS_ID | NUMBER(38) | NO | The log stream ID. |
| SYNC_LSN | NUMBER(38) | NO | The LSN of the maximum continuous majority in the standby database or the maximum consumable LSN. |
| SYNC_SCN | NUMBER(38) | NO | The SCN of the maximum continuous majority in the standby database or the maximum consumable SCN. |
| SYNC_STATUS | VARCHAR2(128) | NO | The log stream restore status. Valid values: <ul><li>NORMAL: Normal synchronization is in progress.  </li><li>SOURCE HAS A GAP: The log source has a gap. </li><li>STANDBY LOG NOT MATCH: The log in the standby database conflicts with the log in the log source. The logs in the standby database and the log source have the same LSN but are different.  </li><li>CHECK USER OR PASSWORD: The username or password of the replication account is incorrect, and the log source cannot be accessed.  </li><li>CHECK NETWORK: The log source is unreachable. This may be due to an incorrect tenant access endpoint IP address or port.  </li><li>FETCH LOG TIMEOUT: The log fetch operation times out.  </li><li>RESTORE SUSPEND: The log restore has reached the maximum synchronization LSN set.  </li><li>STANDBY NEED UPGRADE: The standby database is running an older version than the primary database. The standby database needs to be upgraded.  </li><li>CHECK PRIMARY ALIVE: The primary database cannot be accessed. Check whether the primary database has been deleted.  </li><li> NOT AVAILABLE: The log synchronization is unavailable due to other exceptions. </li></ul>|
| ERR_CODE | NUMBER(38) | NO | The error code. This value is 0 during normal synchronization. |
| COMMENT | VARCHAR2(2048) | NO | The error details. This column is empty during normal synchronization. |

## Sample query

Query the log restore status of the current user tenant at the log stream level.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_LS_LOG_RESTORE_STATUS;
```
