# GV$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V4.0.0. </p>
</main>

## Purpose

The `GV$OB_SQL_AUDIT` view displays the source and execution status of each SQL request on all OBServer nodes. This view is tenant-scoped. Tenants other than the system tenant cannot query across tenants.
