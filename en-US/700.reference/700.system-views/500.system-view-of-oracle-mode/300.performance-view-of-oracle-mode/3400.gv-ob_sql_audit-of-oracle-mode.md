# GV$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_SQL_AUDIT` view displays the source, execution status, and other statistics for each SQL request on all OBServer nodes. This view is tenant-separated, and only the system tenant can query it. Other tenants cannot query it across tenants.
