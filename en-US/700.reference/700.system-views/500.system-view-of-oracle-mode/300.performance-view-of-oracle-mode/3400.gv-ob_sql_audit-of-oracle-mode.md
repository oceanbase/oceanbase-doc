# GV$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_SQL_AUDIT` view displays the source, execution status, and other statistical information for each SQL request on all OBServer nodes. This view is tenant-separated. Except for the sys tenant, other tenants cannot query across tenants.

## Sample query

Query the statistics such as the source and execution status of each SQL request on all OBServer nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_SQL_AUDIT WHERE ROWNUM <= 1\G
```
