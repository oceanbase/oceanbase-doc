# V$OB_PLAN_CACHE_PLAN_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was renamed from V$PLAN_CACHE_PLAN_STAT to V$OB_PLAN_CACHE_PLAN_STAT starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_PLAN_CACHE_PLAN_STAT` view displays the status of each cached object in the plan cache of the current OBServer node for the current tenant.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This view caches not only SQL plan objects but also PL objects such as anonymous blocks, PL packages, and PL functions. Some fields are only valid for specific object types. </p>
  </main>
