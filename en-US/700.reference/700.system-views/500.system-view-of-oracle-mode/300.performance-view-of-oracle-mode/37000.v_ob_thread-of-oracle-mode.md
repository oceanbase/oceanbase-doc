# V$OB_THREAD

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the status of all threads in the observer process on the current OBServer node. In a user tenant, it displays the relevant threads for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the observer process. |
| SVR_PORT | NUMBER(38) | NO | The port number of the observer process. |
| TENANT_ID | NUMBER(38) | NO | The ID of the tenant to which the thread belongs. 500 indicates a process-level thread. |
| TID | NUMBER(38) | NO | The thread ID. |
| TNAME | VARCHAR2(16) | NO | The thread name. |
| STATUS | VARCHAR2(32) | NO | The thread status. Valid values: <ul><li> Run indicates that the thread is running.  </li><li> Wait indicates that the thread is waiting. </li><li> Sleep indicates that the thread is sleeping. </li><li> Join indicates that the thread is waiting for another thread to end. </li></ul>|
| LATCH_WAIT | VARCHAR2(16) | NO | The address that the thread is waiting for a latch. |
| LATCH_HOLD | VARCHAR2(256) | NO | The address of the latch that the thread is holding. This field may contain multiple values. |
| TRACE_ID | VARCHAR2(40) | NO | The ID of the trace being executed by the thread. |
| CGROUP_PATH | VARCHAR2(256) | NO  | The path of the cgroup to which the thread belongs. This field is obtained from the CPU line in the `/proc/observer-pid/task/tid/cgroup` path. |

## Sample query

In a user tenant, query the status of all threads in the observer process on the current OBServer node and display the first two records.

```shell
obclient > SELECT * FROM SYS.V$OB_THREAD WHERE ROWNUM <= 2;
```
