# GV$SESSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays session-level statistics for the current tenant on the current OBServer node. In this view, `STATISTIC#` indicates the statistic item number. You can query the `V$STATNAME` view to obtain the name and description of the statistic item corresponding to the `STATISTIC#` value.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SID | NUMBER | NO | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> This field indicates the server session ID in all connection modes (direct mode and ODP mode). </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field indicates the server session ID. </li></ul></ul></li></ul>  |
| CON_ID | NUMBER | NO | The tenant ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server. |
| STATISTIC# | NUMBER | NO | The statistic item number. |
| VALUE | NUMBER | NO | The value of the statistic item. |

## Sample query

In the user tenant, query the session-level statistics of the tenant on all OBServer nodes and display the first 10 records.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSTAT WHERE ROWNUM <= 10;
```
