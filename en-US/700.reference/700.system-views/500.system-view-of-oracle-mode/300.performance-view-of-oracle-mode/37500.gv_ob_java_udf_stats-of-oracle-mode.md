# GV$OB_JAVA_UDF_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.2, this view is available starting with V4.4.2 BP4.</p>
</main>

## Overview

This view displays the execution statistics of Java UDFs for the current tenant across all OBServer nodes, including the number of calls, successes and failures, concurrency, time distribution, and time consumed in each execution phase. Each Java UDF is statistically analyzed separately by function type and execution mode.

The usage instructions are as follows:

* Statistical information is only stored in memory and is reset after an OBServer node restarts.
* Each tenant retains at most 1,024 statistics on each OBServer node. When this limit is exceeded, statistics for deleted Java UDFs are evicted first, followed by the least recently used statistics. The eviction or discarding of statistics does not affect the execution of Java UDFs.
* Only statistics for Java UDFs that exist in the current tenant and are accessible to the current user are displayed.

## Columns

| ---------------- | ------------- | ---------------- | ---------------- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the OBServer node. |
| SVR_PORT | NUMBER(38) | NO | The port number of the OBServer node. |
| TENANT_ID | NUMBER(38) | NO | Tenant ID. |
| PACKAGE_ID | NUMBER(38) | NO | The ID of the package to which the Java UDF belongs. |
| UDF_ID | NUMBER(38) | NO | The ID of the Java UDF. |
| DATABASE_ID | NUMBER(38) | YES | The ID of the database to which the Java UDF belongs. This parameter is NULL if the ID cannot be obtained. |
| UDF_NAME | VARCHAR2(128) | NO | The name of the Java UDF. |
| SCHEMA_STATUS | VARCHAR2(16) | NO | Schema status of Java UDF:<ul><li>`ACTIVE`: Java UDF exists</li></ul> |
| CLASS_NAME | VARCHAR2(1024) | YES | The Java class name corresponding to the Java UDF. This parameter is NULL if the class name cannot be obtained. |
| ROUTINE_TYPE | VARCHAR2(32) | NO | Function type:<ul><li>`UDF`:Java UDF</li><li>`UDAF`:Java UDAF</li><li>`UDTF`:Java UDTF</li><li>`UNKNOWN`: Unknown type</li></ul> |
| EXECUTION_MODE | VARCHAR2(16) | NO | Execution mode:<ul><li>`IN_PROCESS`: Execute within the OBServer process via JNI.</li><li>`SANDBOX`: Runs in a standalone sandbox process.</li></ul> |
| CALL_COUNT | NUMBER(38) | NO | Cumulative number of calls. A vectorized batch call counts as 1 call. |
| ROW_COUNT | NUMBER(38) | NO | Cumulative number of input rows processed. |
| SUCCESS_COUNT | NUMBER(38) | NO | Cumulative number of successful calls. |
| FAIL_COUNT | NUMBER(38) | NO | The cumulative number of failed calls, including those that timed out or were interrupted. |
| TIMEOUT_COUNT | NUMBER(38) | NO | Cumulative number of calls with timeouts, including in`FAIL_COUNT`. |
| INTERRUPT_COUNT | NUMBER(38) | NO | Cumulative number of interrupted (for example, killed or canceled) calls, including in`FAIL_COUNT`. |
| CURRENT_CONCURRENCY | NUMBER(38) | NO | The number of calls currently in progress. |
| PEAK_CONCURRENCY | NUMBER(38) | NO | The peak number of concurrent calls. |
| CALL_COUNT_1M | NUMBER(38) | NO | Number of calls within the last minute. |
| QPS_1M | NUMBER(38) | NO | Average number of calls per second in the last minute. |
| TOTAL_ELAPSED_US | NUMBER(38) | NO | The cumulative time consumed by the completed calls, in microseconds. |
| AVG_ELAPSED_US | NUMBER(38) | YES | The average time consumed for completed calls, in microseconds. NULL when no calls are completed. |
| MAX_ELAPSED_US | NUMBER(38) | NO | The maximum duration of a single request, in microseconds. |
| P95_ELAPSED_US_5M | NUMBER(38) | YES | The P95 value of the call duration in the last 5 minutes, in microseconds. NULL if not calculable. |
| P99_ELAPSED_US_5M | NUMBER(38) | YES | The P99 value of call duration in the last 5 minutes, in microseconds. NULL if cannot be calculated. |
| SERIALIZE_TIME_US | NUMBER(38) | NO | The cumulative time consumed in converting OceanBase parameters to Java parameters or making sandbox requests, in microseconds. |
| DISPATCH_TIME_US | NUMBER(38) | NO | The cumulative time from input preparation completion to receiving the Java execution result or sandbox response, in microseconds. |
| JAVA_TIME_US | NUMBER(38) | YES | The cumulative time consumed by Java code execution, in microseconds. NULL if unavailable. |
| DESERIALIZE_TIME_US | NUMBER(38) | NO | The cumulative time consumed in converting the Java execution result or sandbox response into an OceanBase result, in microseconds. |
| INPUT_BYTES | NUMBER(38) | YES | The cumulative amount of request data sent to the sandbox process, in bytes. Only counts`SANDBOX`Execution mode. NULL when statistics cannot be collected. |
| OUTPUT_BYTES | NUMBER(38) | YES | Cumulative response data volume received from the sandbox process, in bytes. Only counts the`SANDBOX`Execution mode. NULL when statistics cannot be collected. |
| LAST_CALL_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | Time of the last call. |
| LAST_ERROR_CODE | NUMBER(38) | YES | The error code of the most recent failed call. This parameter is NULL if no error has occurred. |
| LAST_ERROR_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | The time when the last call failed. This column is NULL if no error has occurred. |
| STAT_START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when this statistic started to be recorded. |

## Sample query

```shell
obclient> SELECT PACKAGE_ID, UDF_ID, UDF_NAME, ROUTINE_TYPE, EXECUTION_MODE, CALL_COUNT, SUCCESS_COUNT, FAIL_COUNT, QPS_1M, AVG_ELAPSED_US FROM SYS.GV$OB_JAVA_UDF_STATS;
```
