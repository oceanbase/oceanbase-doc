# V$OB_SESSION_PS_INFO

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in V4.2.3.</p>
</main>

## Overview

The `V$OB_SESSION_PS_INFO` view displays the PS information opened by all sessions in the current OBServer tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | -------- | ------------------- | -------- |
| SVR_IP | VARCHAR2(46) | NO | OBServer IP |
| SVR_PORT | NUMBER(38) | NO | OBServer PORT |
| TENANT_ID | NUMBER(38) | NO | Tenant ID |
| PROXY_SESSION_ID | NUMBER(38) | NO | Session ID in ODP |
| SESSION_ID | NUMBER(38) | NO | Server-side session ID |
| PS_CLIENT_STMT_ID | NUMBER(38) | NO | PS ID Returned to the Client After a Prepare Request Is Sent |
| PS_INNER_STMT_ID | NUMBER(38) | NO | Internal PS ID in OBServer (PS ID in PS Cache) |
| STMT_TYPE | VARCHAR2(256) | NO | Statement type of the prepared statement. Valid values:`T_SELECT`,`T_INSERT`,`T_REPLACE`,`T_DELETE`,`T_UPDATE`,`T_MERGE`,`T_EXPLAIN`,`T_CREATE_TABLE`,`T_DROP_TABLE`etc. |
| PARAM_COUNT | NUMBER(38) | NO | Number of PS parameters |
| PARAM_TYPES | CLOB | NO | List of parameter types. The list of types for all parameters in the prepared statement, where each type is represented by a number and different types are separated by commas. |
| REF_COUNT | NUMBER(38) | NO | `ps_session_info_`The reference count of the object,`ps_session_info_`is an attribute on a session. After a session prepares a statement, a`ps_session_info_`. |
| CHECKSUM | NUMBER(38) | NO | String checksum of parameterized SQL in PS cache |

## Sample query

Query the PS information opened by all sessions of the current OBServer tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SESSION_PS_INFO;
```
