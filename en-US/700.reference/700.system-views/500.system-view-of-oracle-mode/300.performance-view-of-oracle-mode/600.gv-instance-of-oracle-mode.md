GV$INSTANCE
================================

Purpose
-----------

The `GV$INSTANCE` view displays the status of the current database instance.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>

-------------

| INSTANCE_NUMBER  | NUMBER       | NO             | At present, this column is not supported and its value is `NULL` by default. |
