# GV$DBLINK

## Purpose

This view displays all database links (links with `IN_TRANSACTION=YES`) opened after a query session on this view is initiated. You must commit or roll back these database links before you close them.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|-----------------------|-----------------|----------------|--------------------------------|
| TENANT_ID             | NUMBER(38)      | NO             | Tenant ID                          |
| SVR_IP                | VARCHAR2(46)    | NO             | IP address of the remote database                      |
