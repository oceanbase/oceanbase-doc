# V$OB_CGROUP_CONFIG

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.0 for V4.3.x. </li>
<li>This view is available starting with V4.2.1 BP2 for V4.2.1 and V4.2.2 for other V4.2.x versions. </li></ul>
</main>

## Purpose

The `V$OB_CGROUP_CONFIG` view is used to quickly query the cgroup configuration of the current OBServer node. The view fields are sourced from the cgroup directory under the installation directory of the OBServer node (e.g., `/home/admin/oceanbase/cgroup`).

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the OBServer node. |
| SVR_PORT | NUMBER(38) | NO | The port number of the OBServer node. |
| CFS_QUOTA_US | NUMBER(38) | NO | The CPU time slice for the thread, in microseconds. This information is sourced from the `cpu.cfs_quota_us` file in the path directory. |
| CFS_PERIOD_US | NUMBER(38) | NO | The control cycle time for the cgroup, in microseconds. This is used in conjunction with Quota. This information is sourced from the `cpu.cfs_period_us` file in the path directory. |
| SHARES | NUMBER(38) | NO | The CPU usage ratio of the thread (only effective when the CPU is fully loaded). This information is sourced from the `cpu.shares` file in the path directory. |
| CGROUP_PATH | VARCHAR2(256) | NO | The path to the cgroup directory configured for the OBServer node. |

## Sample query

Query the cgroup configuration of the current OBServer node in the user tenant.

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.V$OB_CGROUP_CONFIG;
```
