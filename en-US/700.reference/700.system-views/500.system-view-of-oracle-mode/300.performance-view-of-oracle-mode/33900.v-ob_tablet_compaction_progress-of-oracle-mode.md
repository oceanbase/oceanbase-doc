# V$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced in V4.0.0. </p>
</main>

## Features

Displays the progress information of tablet-level compactions.

## Field description

|             Field name             |                Type                 | NULL? |                                            Description                                            |
|------------------------------|-----------------------------------|------|--------|
| SVR_IP                       | VARCHAR2(46)                      | NO   | The IP address of the server.                                                                                |
| SVR_PORT                     | NUMBER(38)                        | NO   | The port number of the server. |
| TENANT_ID                    | NUMBER(38)                        | NO   | The tenant ID. |
| TYPE                         | VARCHAR2(64)                      | NO   | The type of compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persists the system metadata in the format of an SSTable to the disk. </li> <li>`MAJOR_MERGE`: tenant-level major compaction. </li> <li>`MEDIUM_MERGE`: partition-level major compaction. </li> <li>`MINI_MERGE`: minor compaction. It converts the MemTables to Mini SSTables. </li> <li>`MINOR_MERGE`: micro compaction. It merges multiple Mini SSTables into a new Mini SSTable or multiple Mini SSTables and a Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of compaction that synthesizes data created before a specified point in time into a Meta Major SSTable. The data format of this SSTable is the same as that of a Major SSTable, but it does not contain multi-version data or uncommitted transaction data. </li></ul>    |
| LS_ID                        | NUMBER(38)                        | NO   | The log stream ID. |
