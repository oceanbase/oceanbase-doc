# V$OB_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <ul><li>For V4.3.x versions, this view is available starting with V4.3.5. </li> <li>For V4.2.x versions, this view is available starting with V4.2.5. </li></ul>
</main>

## Purpose

The `V$OB_RES_MGR_SYSSTAT` view displays the statistics of resource groups in the current OBServer node of the current tenant.

## Columns

| **Column** | **Type**  | **Nullable** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| CON_ID     | NUMBER       | NO   | The tenant ID. |
| GROUP_ID   | NUMBER       | NO   | The ID of the resource group. |
| SVR_IP     | VARCHAR2(46) | NO   | The IP address of the node. |
| SVR_PORT   | NUMBER(38)   | NO   | The port number of the node. |
| STATISTIC# | NUMBER       | NO   | The sequence number of the statistic. |
| NAME       | VARCHAR2(64) | NO   | The name of the statistic. |
| CLASS      | NUMBER       | NO   | The category of the statistic. |
| VALUE      | NUMBER       | NO   | The value of the statistic. |
| VALUE_TYPE | VARCHAR2(16) | NO   | The type of the value: cumulative or assigned. |
| STAT_ID    | NUMBER       | NO   | The ID of the statistic. |

## Sample query

Query the statistics of resource groups in the current OBServer node of the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_RES_MGR_SYSSTAT  WHERE ROWNUM < 10;
```
