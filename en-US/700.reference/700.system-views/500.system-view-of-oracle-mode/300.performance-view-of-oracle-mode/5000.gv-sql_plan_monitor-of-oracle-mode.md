# GV$SQL_PLAN_MONITOR

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `GV$SQL_PLAN_MONITOR` view displays the operation-level statistics of slow queries in the current tenant across all OBServer nodes. Each operation of a slow query is associated with statistics.

Query the statistics of slow queries at the Operation layer on the current OBServer node in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SQL_PLAN_MONITOR WHERE ROWNUM =1\G
```
