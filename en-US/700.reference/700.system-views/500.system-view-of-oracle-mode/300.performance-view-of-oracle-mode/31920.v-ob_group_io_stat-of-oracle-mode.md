# V$OB_GROUP_IO_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V4.3.3. </p>
</main>

## Purpose

This view displays the real-time status of each resource group on the current OBServer node in the current tenant.

## Columns

| Column |  Type  | Nullable? | Description |
|------------|----------|----------|------------|
| TENANT_ID  | NUMBER(38) | NO       | The ID of the tenant. |
| SVR_IP     | VARCHAR2(46) | NO       | The IP address of the server. |
| SVR_PORT   | NUMBER(38) | NO       | The port of the server. |
| GROUP_ID   | NUMBER(38) | NO       | The ID of the resource group. |
| GROUP_NAME | VARCHAR2(128)| NO       | The name of the resource group. |
| MODE       | VARCHAR2(128)| NO       | The read/write mode, which can be either `READ` for read mode or `WRITE` for write mode. |
| MIN_IOPS   | NUMBER(38) | NO       | The minimum IOPS of the resource group. |
| MAX_IOPS   | NUMBER(38) | NO       | The maximum IOPS of the resource group. |
| REAL_IOPS  | NUMBER(38) | NO       | The current IOPS of the resource group. |
| MAX_NET_BANDWIDTH | NUMBER(38) | NO       | The maximum network bandwidth of the resource group in bytes. |
| MAX_NET_BANDWIDTH_DISPLAY | VARCHAR2(128)| NO       | The maximum network bandwidth of the resource group after it is converted to a readable format, such as 10 GB/s or 10 MB/s. |
| REAL_NET_BANDWIDTH | NUMBER(38) | NO       | The current network bandwidth of the resource group in bytes. |
| REAL_NET_BANDWIDTH_DISPLAY | VARCHAR2(128)| NO       | The current network bandwidth of the resource group after it is converted to a readable format, such as 10 GB/s or 10 MB/s. |

## Sample query

The following example queries the real-time status of each resource group on the current OBServer node in the user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_GROUP_IO_STAT WHERE ROWNUM <= 2;
```

