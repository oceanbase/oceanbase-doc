# V$EVENT_NAME

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the definitions of various wait events in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | NUMBER | NO | The tenant ID. |
| EVENT_ID | NUMBER | NO | The wait event ID. |
| EVENT# | NUMBER | NO | The wait event number. |
| NAME | VARCHAR2(64) | NO | The wait event name. |
| DISPLAY_NAME | VARCHAR2(64) | NO | The display name of the wait event. |
| PARAMETER1 | VARCHAR2(64) | NO | The first parameter of the wait event. |
| PARAMETER2 | VARCHAR2(64) | NO | The second parameter of the wait event. |
| PARAMETER3 | VARCHAR2(64) | NO | The third parameter of the wait event. |
| WAIT_CLASS_ID | NUMBER | NO | The ID of the wait event type to which the wait event belongs. |
| WAIT_CLASS# | NUMBER | NO | The index of the wait event type to which the wait event belongs. |
| WAIT_CLASS | VARCHAR2(64) | NO | The name of the wait event type to which the wait event belongs. |

## Sample query

In the user tenant, query the definitions of all wait events in the tenant and display the first 10 records.

```shell
obclient [SYS]> SELECT * FROM SYS.V$EVENT_NAME WHERE ROWNUM <= 10;
```
