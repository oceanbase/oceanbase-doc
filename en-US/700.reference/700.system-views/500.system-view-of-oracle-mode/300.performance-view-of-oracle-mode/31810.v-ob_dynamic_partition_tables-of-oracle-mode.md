# V$OB_DYNAMIC_PARTITION_TABLES

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.3.5 BP2. </p>
</main>

## Purpose

This view displays information about dynamic partition tables in the current tenant. The view reads dynamic partition table attributes from memory, which provides better read performance.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Dynamic performance views, such as <code>V$OB_DYNAMIC_PARTITION_TABLES</code>, obtain information from the memory of the connected node. Therefore, the information in dynamic performance views may not be the latest compared to data dictionary views, such as <code>DBA/CDB_OB_DYNAMIC_PARTITION_TABLES</code>. You need to use <code>TENANT_SCHEMA_VERSION</code> to confirm the latest information. </p>
</main>

## Columns

|          Column         |       Type      | Nullable | Description |
|-----------------------|----------------|-------------|------|
| TENANT_ID             | NUMBER(38)     | NO          | The ID of the tenant where the dynamic partition table resides.|
| TENANT_SCHEMA_VERSION | NUMBER(38)     | NO          | The `schema_version` used to obtain the current attribute from memory.|
| DATABASE_NAME         | VARCHAR2(128)  | NO          | The name of the database where the dynamic partition table resides.|
| TABLE_NAME            | VARCHAR2(256)  | NO          | The name of the dynamic partition table.|
| TABLE_ID              | NUMBER(38)     | NO          | The ID of the dynamic partition table.|
| MAX_HIGH_BOUND_VAL    | VARCHAR2(4096) | NO          | The upper bound of the largest range partition.|
| ENABLE                | VARCHAR2(1024) | NO          | Indicates whether dynamic partition management is enabled.|
| TIME_UNIT             | VARCHAR2(1024) | NO          | The `time_unit` for dynamic partition management.|
| PRECREATE_TIME        | VARCHAR2(1024) | NO          | The `precreate_time` for dynamic partition management.|
| EXPIRE_TIME           | VARCHAR2(1024) | NO          | The `expire_time` for dynamic partition management.|
| TIME_ZONE             | VARCHAR2(1024) | NO          | The `time_zone` for dynamic partition management.|
| BIGINT_PRECISION      | VARCHAR2(1024) | NO          | The `bigint_precision` for dynamic partition management.|

## Sample query

Query information about dynamic partition tables in the current tenant.

```shell
obclient> SELECT * FROM sys.V$OB_DYNAMIC_PARTITION_TABLES\G
```

The query result is as follows:

