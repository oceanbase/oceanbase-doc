# GV$OB_PLAN_CACHE_PLAN_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. The view name was changed from GV$PLAN_CACHE_PLAN_STAT to GV$OB_PLAN_CACHE_PLAN_STAT. </p>
</main>

## Purpose

This view displays the status of each cached object in the plan cache of all OBServer nodes for the current tenant.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This view caches not only SQL plan objects but also PL objects such as anonymous blocks, PL packages, and PL functions. Some fields are only valid for specific objects. </p>
  </main>
