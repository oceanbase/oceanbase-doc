# V$OB_ARCHIVE_DEST_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays the status of archive destinations for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| DEST_ID | NUMBER(38) | NO | The archive destination ID. |
| PATH | VARCHAR2(4096) | NO | The archive path. |
| STATUS | VARCHAR2(64) | NO | The archive status. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The continuous point of the archived logs. |
| SYNCHRONIZED | VARCHAR2(32) | NO | Indicates whether the archive is synchronized with the tenant logs. <ul><li> `YES` indicates that the archive is synchronized with the tenant logs.  </li><li> `NO` indicates that the archive is not synchronized with the tenant logs. </li></ul>|
| COMMENT | VARCHAR2(262144) | NO | The error message. |

## Sample query

Query the status of archive destinations for the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_ARCHIVE_DEST_STATUS;
```

The query result is as follows:

```shell
+-----------+---------+----------------------------------------+--------+---------------------+--------------+---------+
| TENANT_ID | DEST_ID | PATH                                   | STATUS | CHECKPOINT_SCN      | SYNCHRONIZED | COMMENT |

+-----------+---------+----------------------------------------+--------+---------------------+--------------+---------+
1 row in set
```
