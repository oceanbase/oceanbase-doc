# V$INSTANCE

## Purpose

The view displays the status of the current database instance.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**   |   **Type**   | **Nullable?** |                        **Description**                        |
|------------------|--------------|----------------|-------------------------------------------------------------|
| INST_ID          | NUMBER       | NO             | The ID of the database instance.                                          |
| INSTANCE_NUMBER  | NUMBER       | NO             | Not supported. The field is NULL by default.      |
| INSTANCE_NAME    | VARCHAR2(16) | NO             | Not supported. The field is NULL by default.                        |
| HOST_NAME        | VARCHAR2(64) | NO             | The IP address of the server where the instance resides.                                      |
| VERSION          | VARCHAR2(17) | NO             | The version of the database instance.                                             |
| STARTUP_TIME     | DATE         | NO             | Not supported. The field is NULL by default.                      |
| STATUS           | VARCHAR2(12) | NO             | Not supported. The field is NULL by default.                        |
| PARALLEL         | VARCHAR2(3)  | NO             | Not supported. The field is NULL by default.                                                                     |
| THREAD#          | NUMBER       | NO             | Not supported. The field is NULL by default.                     |
| ARCHIVER         | VARCHAR2(7)  | NO             | Not supported. The field is NULL by default.   |
| LOG_SWITCH_WAIT  | VARCHAR2(15) | NO             | Not supported. The field is NULL by default.                   |
| LOGINS           | VARCHAR2(10) | NO             | Not supported. The field is NULL by default.                              |
| SHUTDOWN_PENDING | VARCHAR2(3)  | NO             | Not supported. The field is NULL by default.                              |
| DATABASE_STATUS  | VARCHAR2(17) | NO             | The status of the database.                                               |
