# GV$OB_PLAN_CACHE_PLAN_EXPLAIN

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_PLAN_CACHE_PLAN_EXPLAIN` view displays the physical execution plans cached in all OBServer nodes.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view only supports GET operations. You must specify the <code>PLAN_ID</code> field when you query this view. </p>
  </main>

## Columns

|   **Column**   |     **Type**     | **Nullable** |      **Description**      |
|--------------|----------------|----------------|------------------|
| TENANT_ID    | NUMBER(38)     | NO             | The tenant ID.            |
| SVR_IP       | VARCHAR2(46)   | NO             | The IP address of the server.        |
| SVR_PORT     | NUMBER(38)     | NO             | The port number of the server.           |
| PLAN_ID      | NUMBER(38)     | NO             | The ID of the plan.           |
| PLAN_DEPTH   | NUMBER(38)     | NO             | The depth of the operator when it is displayed. |
| PLAN_LINE_ID | NUMBER(38)     | NO             | The ID of the operator.     |
| OPERATOR     | VARCHAR2(128)  | NO             | The name of the operator.     |
| NAME         | VARCHAR2(256)  | NO             | The name of the table.             |
| ROWS         | NUMBER(38)     | NO             | The estimated number of rows.          |
| COST         | NUMBER(38)     | NO             | The estimated cost.            |
| PROPERTY     | VARCHAR2(4096) | NO             | The information about the operator.  |

## Sample query

1. Query the `PLAN_ID` of the current OBServer node from the [GV$OB_PLAN_CACHE_PLAN_STAT](2300.gv-ob_plan_cache_plan_stat-of-oracle-mode.md) view.

   ```shell
   obclient [SYS]> SELECT PLAN_ID FROM SYS.GV$OB_PLAN_CACHE_PLAN_STAT WHERE ROWNUM < 5;
   ```

   The query result is as follows:

   ```shell
   +---------+
   | PLAN_ID |
   +---------+
   |     800 |
   |     802 |
   |     803 |
   |     804 |
   +---------+
   4 rows in set (0.011 sec)
   ```

2. Query the physical execution plan in the plan cache from the `GV$OB_PLAN_CACHE_PLAN_EXPLAIN` view. For example, `PLAN_ID=800`.

   ```shell
   obclient [SYS]> SELECT * FROM SYS.GV$OB_PLAN_CACHE_PLAN_EXPLAIN WHERE PLAN_ID = 800\G
   ```

   The query result is as follows:

   ```shell
   *************************** 1. row ***************************
     TENANT_ID: 1004
         SVR_IP: xx.xx.xx.xx
       SVR_PORT: 2882
       PLAN_ID: 800
     PLAN_DEPTH: 0
   PLAN_LINE_ID: 0
       OPERATOR: PHY_TABLE_SCAN
           NAME: __all_transfer_task
           ROWS: 1
           COST: 2
       PROPERTY: table_rows:1, physical_range_rows:1, logical_range_rows:1, index_back_rows:0, output_rows:1, avaiable_index_name[__all_transfer_task]
   1 row in set (0.023 sec)
   ```
