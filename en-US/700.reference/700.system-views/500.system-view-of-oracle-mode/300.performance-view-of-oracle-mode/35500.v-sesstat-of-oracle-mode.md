# V$SESSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays some session-level statistics of the current tenant on the current OBServer node. `STATISTIC#` indicates the statistic item number. You can query the `V$STATNAME` view to obtain the name and description of the statistic item corresponding to the statistic item number.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SID | NUMBER | NO | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> This field indicates the server session ID in all connection modes (direct mode and ODP mode). </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the configuration parameter <code>client_session_id_version = 2</code> is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code> is set, this field indicates the server session ID. </li></ul></ul></li></ul>   |
| CON_ID | NUMBER | NO | Tenant ID |
| SVR_IP | VARCHAR2(46) | NO | Server IP address |
| SVR_PORT | NUMBER(38) | NO | Server port number |
| STATISTIC# | NUMBER | NO | Statistic item number |
| VALUE | NUMBER | NO | Statistic item value |

## Sample query

Query the session-level statistics of the current tenant on the current OBServer node in the user tenant, and display the first 10 records.

```shell
obclient [SYS]> SELECT * FROM SYS.V$SESSTAT WHERE ROWNUM <= 10;
```
