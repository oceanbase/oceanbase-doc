# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_SQL_AUDIT` view displays the source, execution status, and other statistics for each SQL request on the current OBServer node. This view is tenant-separated. Only the sys tenant can query the view. Other tenants cannot query the view across tenants.
