# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_SQL_AUDIT` view displays the source, execution status, and other statistical information for each SQL request on the current OBServer node. This view is tenant-separated. You can query this view only in the system tenant.

Query the source, execution status, and other statistics for each SQL request on the current OBServer node.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SQL_AUDIT WHERE ROWNUM <= 1\G
```
