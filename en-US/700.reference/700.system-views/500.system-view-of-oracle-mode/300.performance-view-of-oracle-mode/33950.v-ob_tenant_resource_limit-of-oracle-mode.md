# V$OB_TENANT_RESOURCE_LIMIT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.1 in V4.3.x. </li>
<li>This view is available starting with V4.2.4 in V4.2.x. </li></ul>
</main>

## Purpose

The `V$OB_TENANT_RESOURCE_LIMIT` view displays the logical resource usage, upper limits, effective constraints, and maximum usage after a server restart for the current tenant on the current OBServer.

## Columns

| Column | Type | Nullable | Description |
|----------|--------|-----------------|-------------|
| SVR_IP               | VARCHAR2(46)  | NO   | The IP address of the OBServer.    |
| SVR_PORT             | NUMBER(38)    | NO   | The RPC port of the OBServer.    |
| TENANT_ID            | NUMBER(38)    | NO   | The tenant ID.    |
| ZONE                 | VARCHAR2(128) | NO   | The name of the zone.    |
| RESOURCE_NAME        | VARCHAR2(128) | NO   | The name of the resource.    |
| CURRENT_UTILIZATION  | NUMBER(38)    | NO   | The current usage of the resource.    |
| MAX_UTILIZATION      | NUMBER(38)    | NO   | The maximum usage of the resource since the server was started.    |
| RESERVED_VALUE       | NUMBER(38)    | NO   | The pre-allocated amount, which is the minimum required for stable operation.    |
| LIMIT_VALUE          | NUMBER(38)    | NO   | The maximum allowed usage.    |
| EFFECTIVE_LIMIT_TYPE | VARCHAR2(128) | NO   | The type of the effective constraint, such as a configuration parameter, memory, CPU, or disk.    |

## Sample query

Query the logical resource usage, upper limits, effective constraints, and maximum usage after a server restart for the current tenant on the current OBServer.

```shell
obclient[SYS]> SELECT * FROM SYS.V$OB_TENANT_RESOURCE_LIMIT;
```
