# V$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the compaction progress information of the current tenant on the current node.

## Columns

|          Column           |                Type                 | Nullable |                                            Description                                            |
|-------------------------|-----------------------------------|------------|--------|
| SVR_IP                  | VARCHAR2(46)                      | NO         | The IP address of the server.                                                                                |
| SVR_PORT                | NUMBER(38)                        | NO         | The port number of the server. |
| TENANT_ID               | NUMBER(38)                        | NO         | The tenant ID. |
| TYPE                    | VARCHAR2(64)                      | NO         | The type of compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persist system metadata in SSTable format to disk. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: minor compaction. Convert MemTable to Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Merge multiple Mini SSTables into a new Mini SSTable, or merge multiple Mini SSTables with one Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: major compaction. Merge data before a specified time point into a Meta Major SSTable. This type of SSTable has the same data format as Major SSTable and does not contain multi-version data and uncommitted transaction data. </li> </ul>  |
| ZONE                    | VARCHAR2(128)                     | NO         | The zone information.                                                                                  |
| COMPACTION_SCN          | NUMBER(38)                        | NO         | The compaction version information. |
| STATUS                  | VARCHAR2(15)                      | NO         | The status.  |
| TOTAL_TABLET_COUNT      | NUMBER(38)                        | NO         | The total number of tablets.                                                                                |
| UNFINISHED_TABLET_COUNT | NUMBER(38)                        | NO         | The number of tablets that have not been compacted.                                                                           |
| DATA_SIZE               | NUMBER(38)                        | NO         | The total data size to be compacted, in bytes. |
| UNFINISHED_DATA_SIZE    | NUMBER(38)                        | NO         | The data size that has not been compacted, in bytes.  |
| COMPRESSION_RATIO       | NUMBER(38)                        | NO         | The compression ratio of new data. This value indicates the compression ratio of data written after the last major version point.                                                |
| START_TIME              | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | The start time.  |
| ESTIMATED_FINISH_TIME   | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | The estimated finish time. If the compaction progress reaches 100%, the finish time is displayed.                                               |
| COMMENTS                | VARCHAR2(1024)                     | NO         | The comments. During the compaction, this column records the latest compaction event. After the compaction is completed, this column records the overall time consumed.    |

## Sample query

Query the compaction progress of the current tenant on the current OBServer node.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_COMPACTION_PROGRESS;
```
