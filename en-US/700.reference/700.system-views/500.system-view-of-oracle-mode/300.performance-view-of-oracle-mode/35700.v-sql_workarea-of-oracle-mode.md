# V$SQL_WORKAREA

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays the workarea statistics of all operators executed by the SQL automatic memory management feature.

## Columns

|        **Column**        |    **Type**    | **Nullable** |                                                                **Description**                                                                 |
|------------------------|--------------|----------------| ----------|
| ADDRESS                | RAW(8)       | NO             | The handle address of the SQL statement. This field is not supported and is NULL by default.   |
| HASH_VALUE             | NUMBER       | NO             | The hash value of the statement. This field is not supported and is NULL by default.           |
| DB_ID                  | NUMBER(38)    | NO            | The ID of the database to which the SQL statement belongs.    <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.3.x, this field is available starting with V4.3.1. </li> <li>For V4.2.x, this field is available starting with V4.2.3. </li></ul></main>  |
| SQL_ID                 | VARCHAR2(32) | NO             | The unique identifier of the SQL statement.                                   |
| CHILD_NUMBER           | NUMBER       | NO             | The number of cursors. This field is not supported and is NULL by default.               |
| WORKAREA_ADDRESS       | RAW(8)       | NO             | The address of the workarea. This field is not supported and is NULL by default.                   |
| OPERATION_TYPE         | VARCHAR2(40) | NO             | The type of the workarea operator, such as Sort, Hash Join, and Group by.        |
| OPERATION_ID           | NUMBER(38)   | NO             | The unique identifier of the operator in the plan tree.                                     |
| POLICY                 | VARCHAR2(10) | NO             | The strategy of the workarea:<ul><li>MANUAL   </li><li> AUTO  </li></ul>  |
| ESTIMATED_OPTIMAL_SIZE | NUMBER(38)   | NO             | The estimated memory size required to execute the operator optimally, in bytes.                        |
| ESTIMATED_ONEPASS_SIZE | NUMBER(38)   | NO             | The estimated memory size required to execute the operator in one pass, in bytes.                  |
| LAST_MEMORY_USED       | NUMBER(38)   | NO             | The memory size used by the cursor in the last execution, in bytes.                            |
| LAST_EXECUTION         | VARCHAR2(10) | NO             | The execution mode used in the last execution: optimal, one pass, or multi passes.                                                                                  |
| LAST_DEGREE            | NUMBER(38)   | NO             | The degree of parallelism in the last execution.                                            |
| TOTAL_EXECUTIONS       | NUMBER(38)   | NO             | The total number of times the workarea was used.                                |
| OPTIMAL_EXECUTIONS     | NUMBER(38)   | NO             | The number of times the workarea was used in optimal mode.                                         |
| ONEPASS_EXECUTIONS     | NUMBER(38)   | NO             | The number of times the workarea was used in one pass mode.                                   |
| MULTIPASSES_EXECUTIONS | NUMBER(38)   | NO             | The number of times the workarea was used in multi passes mode.                               |
| ACTIVE_TIME            | NUMBER(38)   | NO             | The average active time of the workarea, in seconds.                             |
| MAX_TEMPSEG_SIZE       | NUMBER(38)   | NO             | The maximum temporary disk space used by the workarea, in bytes. If this field is NULL, no temporary space was used. |
| LAST_TEMPSEG_SIZE      | NUMBER(38)   | NO             | The temporary disk space used by the workarea in the last execution. If this field is NULL, no temporary space was used.        |
| CON_ID                 | NUMBER(38)   | NO             | The tenant ID.                                              |
| SVR_IP                 | VARCHAR2(46)  | NO            | The IP address of the server.  |
| SVR_PORT               | NUMBER(38)    | NO            | The port number of the server.  |

## Sample query

Query the workarea statistics of all operators executed by the SQL automatic memory management feature on the current OBServer node.

```shell
obclient [SYS]> SELECT * FROM SYS.V$SQL_WORKAREA WHERE ROWNUM <= 1\G
```
