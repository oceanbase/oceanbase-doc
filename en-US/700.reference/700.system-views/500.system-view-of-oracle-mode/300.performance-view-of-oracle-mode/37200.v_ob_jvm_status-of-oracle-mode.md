# V$OB_JVM_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.2, this view is available starting with V4.4.2 BP4.</p>
</main>

## Overview

This view displays the runtime status and resource usage of the JVM in the OBServer process on the current OBServer node, including information such as the JVM status, heap memory, metaspace, GC, number of threads, and number of file descriptors. Each OBServer node corresponds to a row of records.

The usage instructions are as follows:

* The JVM is started only when the `ob_enable_java_env` parameter is enabled. When it is not enabled, the `STATUS` is `DISABLED`.
* After the JVM is started, the system collects JVM status data by default every 60 seconds. A query on this view returns the result from the most recent collection and does not trigger JVM startup or another collection.
* Metrics that have not been successfully collected or cannot be obtained are displayed as NULL, to distinguish them from metrics whose actual value is `0`.
* For the status of the sandbox JVM when Java UDFs are executed in a sandbox process, see [V$OB_JAVA_SANDBOX_STATUS](37400.v_ob_java_sandbox_status-of-oracle-mode.md).

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------- | ------------- | ---------------- | ---------------- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the OBServer node. |
| SVR_PORT | NUMBER(38) | NO | The port number of the OBServer node. |
| PROCESS_PID | NUMBER(38) | YES |
| STATUS | VARCHAR2(32) | NO | Status of the JVM in the OBServer process: <ul><li>`DISABLED`: The Java environment is not enabled (parameter configuration`ob_enable_java_env`is`False`)</li><li>`NOT_STARTED`: JVM has not been started yet.</li><li>`STARTING`: The JVM is starting, or has started but has not completed its first collection.</li><li>`UP`: The JVM is running, and the last collection was successful.</li><li>`INIT_FAILED`: JVM initialization failed.</li><li>`COLLECT_ERROR`: JVM status collection failed.</li><li>`DOWN`: The OBServer process is exiting, or JVM monitoring has stopped.</li></ul> |
| INIT_ATTEMPT_COUNT | NUMBER(38) | YES |
| INIT_FAILURE_COUNT | NUMBER(38) | YES |
| LAST_INIT_ERROR_CODE | NUMBER(38) | YES |

## Sample query

```shell
obclient> SELECT SVR_IP, SVR_PORT, STATUS, HEAP_USED_BYTES, HEAP_MAX_BYTES, GC_COUNT, THREAD_COUNT, SNAPSHOT_TIME FROM SYS.V$OB_JVM_STATUS;
```
