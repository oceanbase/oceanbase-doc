# GV$OB_PLAN_CACHE_PLAN_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The name of this view was changed from GV$PLAN_CACHE_PLAN_STAT to GV$OB_PLAN_CACHE_PLAN_STAT in V4.0.0. </p>
</main>

## Purpose

Displays the status of each cached object in the plan cache of all OBServer nodes in the current tenant.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The view caches SQL plan objects as well as PL objects (such as anonymous blocks, PL packages, and PL functions). Some fields are valid only for specific objects. </p>
  </main>
