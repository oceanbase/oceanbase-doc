# V$OB_TRANSACTION_SCHEDULERS

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

`V$OB_TRANSACTION_SCHEDULERS` is used to query the transaction scheduler information of all servers.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server where the replica resides. |
| SVR_PORT | NUMBER(38) | NO | The port of the server where the replica resides. |
| SESSION_ID | NUMBER(38) | NO | For V4.3.x: <ul><li> V4.3.5 BP2 and earlier: <br> In all connection modes (direct mode and ODP mode), this field indicates the server session ID. </li><li> V4.3.5 BP2 and later: <ul><li> In ODP mode: <ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field indicates the server session ID. </li></ul></ul></li></ul> |
| TX_ID | NUMBER(38) | NO | The transaction ID. |
| STATE | VARCHAR2(18) | NO | The transaction state. |
| CLUSTER_ID | NUMBER(38) | NO | The unique ID of the cluster. |
| COORDINATOR | NUMBER(38) | NO | The log stream ID of the coordinator. |
| PARTICIPANTS | VARCHAR2(1024) | NO | The information about the participants of the transaction. |
| ISOLATION_LEVEL | VARCHAR2(16) | NO | The isolation level. |
| SNAPSHOT_VERSION | NUMBER(38)  | NO | The snapshot version when the RR or SERIAL isolation level is enabled. If the isolation level is not enabled, the value is -1. |
| ACCESS_MODE | VARCHAR2(10) | NO | The access mode (read-only or read/write). |
| TX_OP_SN | NUMBER(38)  | NO | The operation sequence number of the transaction. |
| ACTIVE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The timestamp when the transaction is explicitly or implicitly started. |
| EXPIRE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The transaction expiration timestamp. |
| CAN_EARLY_LOCK_RELEASE | VARCHAR2(7) | NO | Indicates whether the transaction can release the row lock early. |
| FORMATID               | NUMBER(38)          | NO   | The format identifier of the global transaction. |
| GLOBALID               | VARCHAR2(256)        | NO  | The unique identifier of the global transaction. |
| BRANCHID               | VARCHAR2(256)        | NO  | The unique identifier of the branch transaction. |

## Sample query

```sql
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TRANSACTION_SCHEDULERS;
```
