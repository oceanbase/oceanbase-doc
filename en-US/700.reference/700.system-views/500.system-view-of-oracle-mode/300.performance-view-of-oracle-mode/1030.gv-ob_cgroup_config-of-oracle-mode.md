# GV$OB_CGROUP_CONFIG

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.3.x, this view is available starting with V4.3.0. </li>
<li>For V4.2.1, this view is available starting with V4.2.1 BP2. For other V4.2.x versions, this view is available starting with V4.2.2. </li></ul>
</main>

## Purpose

The `GV$OB_CGROUP_CONFIG` view is used to quickly query the cgroup configurations of all OBServer nodes. The field information of this view comes from the cgroup directory under the installation directory of the OBServer node (for example, `/home/admin/oceanbase/cgroup`).

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the OBServer node. |
| SVR_PORT | NUMBER(38) | NO | The port number of the OBServer node. |
| CFS_QUOTA_US | NUMBER(38) | NO | The CPU time slice of the thread, in microseconds. This field information comes from the `cpu.cfs_quota_us` file under the path directory. |
| CFS_PERIOD_US | NUMBER(38) | NO | The control cycle time of the cgroup, in microseconds. This field is used in conjunction with Quota. This field information comes from the `cpu.cfs_period_us` file under the path directory. |
| SHARES | NUMBER(38) | NO | The CPU usage ratio of the thread (only effective when the CPU is fully loaded). This field information comes from the `cpu.shares` file under the path directory. |
| CGROUP_PATH | VARCHAR2(256) | NO | The path of the cgroup directory configured for the OBServer node. |

## Sample query

Query the cgroup configurations of all OBServer nodes in the user tenant.

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.GV$OB_CGROUP_CONFIG;
```
