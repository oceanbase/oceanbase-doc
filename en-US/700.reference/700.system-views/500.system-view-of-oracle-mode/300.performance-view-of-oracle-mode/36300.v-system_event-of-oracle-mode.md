# V$SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays some wait events of the current tenant on the current OBServer node, including the number of occurrences, wait time, and timeout count of each type of wait event.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | NUMBER | NO | The tenant ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server where the information is stored. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server where the information is stored. |
| EVENT_ID | NUMBER | NO | The ID of the wait event. |
| EVENT | VARCHAR2(64) | NO | The description of the wait event. |
| WAIT_CLASS_ID | NUMBER | NO | The class ID of the wait event. |
| WAIT_CLASS# | NUMBER | NO | The index of the wait event's class. |
| WAIT_CLASS | VARCHAR2(64) | NO | The class of the wait event. |
| TOTAL_WAITS | NUMBER | NO | The total number of wait events. |
| TOTAL_TIMEOUTS | NUMBER | NO | The total number of timeouts. |
| TIME_WAITED | NUMBER | NO | The total wait time of the wait event, in 10 ms. |
| AVERAGE_WAIT | NUMBER | NO | The average wait time of the wait event, in 10 ms. |
| TIME_WAITED_MICRO | NUMBER | NO | The total wait time of the wait event, in microseconds. |

## Sample query

Query all wait events of the current tenant on the current node and display the first 10 records.

```shell
obclient [SYS]> SELECT * FROM SYS.V$SYSTEM_EVENT WHERE ROWNUM <= 10;
```
