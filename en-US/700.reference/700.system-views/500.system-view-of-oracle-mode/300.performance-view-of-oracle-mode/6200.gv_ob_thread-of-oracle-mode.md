# GV$OB_THREAD

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Overview

Displays the status information of all threads in the observer process on each OBServer node. For user tenants, it displays the relevant threads of the current tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | IP Address of the Observer Process |
| SVR_PORT | NUMBER(38) | NO | Port number of the observer process |
| TENANT_ID | NUMBER(38) | NO | Tenant to which the thread belongs. For process-level threads, this is 500. |
| TID | NUMBER(38) | NO | Thread ID |
| TNAME | VARCHAR2(16) | NO | Thread Name |
| STATUS | VARCHAR2(32) | NO | Thread status:<ul><li> Run: the thread is in the running state.  </li><li> Wait: the thread is in the waiting state. </li><li> Sleep: the thread is in the sleep state. </li><li> Join: the thread is waiting for another thread to end. </li></ul> |
| LATCH_WAIT | VARCHAR2(16) | NO | Address Waiting for Latch |
| LATCH_HOLD | VARCHAR2(256) | NO | Addresses Holding Latches (May Contain Multiple) |
| TRACE_ID | VARCHAR2(40) | NO | ID of the trace being executed on the thread |
| CGROUP_PATH | VARCHAR2(256) | NO | The path of the cgroup to which the thread belongs. This field is obtained from the`/proc/observer-pid/task/tid/cgroup`CPU Usage Under Path<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.2. </p></main> |

## Sample query

In the user tenant, view the status information of all threads in the observer process on each OBServer node, displaying the first two records.

```shell
obclient > SELECT * FROM SYS.GV$OB_THREAD WHERE ROWNUM <= 2;
```
