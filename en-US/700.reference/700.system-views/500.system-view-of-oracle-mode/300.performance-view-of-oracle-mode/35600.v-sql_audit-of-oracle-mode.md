# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in OceanBase Database V4.0.0. </p>
</main>

## Purpose

The `V$OB_SQL_AUDIT` view displays the statistics about each SQL request on the current OBServer node, such as the source and execution status. This view is tenant-specific, and you can query this view of other tenants only from the `sys` tenant.

Query the statistics about each SQL request on the current OBServer node, such as the source and execution status.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SQL_AUDIT WHERE ROWNUM <= 1\G
```
