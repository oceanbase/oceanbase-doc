# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_SQL_AUDIT` view displays the source, execution status, and other statistics for each SQL request on the current OBServer node. This view is tenant-separated, and only the system tenant can query it. Other tenants cannot cross-tenant query it.

## Sample query

Query the statistics of each SQL request on the current OBServer node, such as the source and execution status.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SQL_AUDIT WHERE ROWNUM <= 1\G
```
