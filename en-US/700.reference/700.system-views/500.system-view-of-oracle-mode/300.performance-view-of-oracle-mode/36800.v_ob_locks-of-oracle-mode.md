# V$OB_LOCKS

## Description

Displays the locks held or requested by the current user on tables.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced in V4.2.0. </p>
</main>

## Columns

| **Column** | **Type** | **NULLable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the OBServer node that holds or requests the lock. |
| SVR_PORT | NUMBER(38) | NO | The port number of the OBServer node that holds or requests the lock. |
| TENANT_ID | NUMBER(38) | NO | The ID of the tenant that holds or requests the lock. |
| TRANS_ID | NUMBER(38) | NO | The ID of the transaction that holds or requests the lock. |
| SESSION_ID | NUMBER(38) | NO   | The session ID of the transaction that holds or requests the lock. <main id="notice" type='explain'><h4>Note</h4><p><ul><li>This column is introduced in V4.3.2 of the V4.3.x version. </li><li>This column is introduced in V4.2.5 of the V4.2.x version. </li></ul></p></main>|
| TYPE | VARCHAR2(9) | NO | The lock type. <ul><li>TM: table lock</li><li>TX: transaction lock</li><li>TR: row lock</li></ul> |
| ID1 | NUMBER | NO | Lock identifier 1. <ul><li>Table lock: TABLE_ID or TABLET_ID</li><li>Transaction lock: TX_ID</li><li>Row lock: TABLET_ID</li></ul> |
| ID2 | VARCHAR2(553) | NO | Lock identifier 2. <ul><li>Table lock: NULL</li><li>Transaction lock: NULL</li><li>Row lock: TX_ID + row rowkey</li></ul> |
| ID3 | varchar(512) | NO | Lock identifier 3. <ul><li>TM: TABLE_ID / TABLET_ID</li><li>TX: NULL</li><li>TR: TABLET_ID + row rowkey</li></ul> <main id="notice" type='explain'><h4>Note</h4><p><ul><li>This column is introduced in V4.3.2 of the V4.3.x version. </li><li>This column is introduced in V4.2.5 of the V4.2.x version. </li></ul></p></main>|
| LMODE | VARCHAR2(8) | NO | The mode in which the lock is held. <ul><li>NONE: no lock is requested. </li><li>RS: row share. </li><li>RX: row exclusive. </li><li>S: share. </li><li>SRX: share row exclusive. </li><li>X: exclusive. </li></ul> |
| REQUEST | VARCHAR2(8) | NO | The mode in which the lock is requested. <ul><li>NONE: no lock is requested. </li><li>RS: row share. </li><li>RX: row exclusive. </li><li>S: share. </li><li>SRX: share row exclusive. </li><li>X: exclusive. </li></ul> |
| CTIME | NUMBER(38) | NO | The time in microseconds for which the lock is held or waited for. |
| BLOCK | NUMBER | NO | Indicates whether a lock requested by the current transaction is held by another transaction. <ul><li>0: the requested lock is not held by another transaction, which means that the transaction holds the lock. </li><li>1: the requested lock is held by another transaction, which means that the transaction is blocked. </li></ul>|
