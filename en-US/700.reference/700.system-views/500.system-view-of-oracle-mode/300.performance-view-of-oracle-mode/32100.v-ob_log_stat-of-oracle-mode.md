# V$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of a log stream in Oracle mode. Common use cases include:

* Checking whether a leader exists in the log stream.
* Querying the list of members (number of Paxos replicas) in the log stream.
* Checking the synchronization status of replicas.
* Checking the recyclable point of the log stream.
* Checking the range of log consumption services allowed for the log stream (including LSN/SCN).
* Checking the access mode of the log stream.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| LS_ID | NUMBER(38) | NO | The log stream ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server. |
| ROLE | VARCHAR2(32) | NO | The role of the replica. Valid values: <ul><li>LEADER</li><li>FOLLOWER </li></ul>|
| PROPOSAL_ID | NUMBER(38) | NO | The Paxos proposal ID. |
| CONFIG_VERSION | VARCHAR2(128) | NO | The version number of the configuration change (for example, the modification of the member list, the number of replicas, or the access mode). |
| ACCESS_MODE | VARCHAR2(32) | NO | The access mode. Valid values: <ul><li>APPEND</li><li>RAW_WRITE</li></ul> |
| PAXOS_MEMBER_LIST | VARCHAR2(1024) | NO | The list of Paxos members. |
| PAXOS_REPLICA_NUM | NUMBER(38) | NO | The number of Paxos replicas. |
| IN_SYNC           | VARCHAR2(3)    | NO   |  Whether the replica is in sync.|
| BASE_LSN | NUMBER(38) | NO | The maximum recyclable point. |
| BEGIN_LSN | NUMBER(38) | NO | The minimum consumable point (LSN). |
| BEGIN_SCN | NUMBER(38) | NO | The minimum consumable point (SCN). |
| END_LSN | NUMBER(38) | NO | The maximum continuous majority point or the maximum consumable point (LSN). |
| END_SCN | NUMBER(38) | NO | The maximum continuous majority point or the maximum consumable point (SCN). |
| MAX_LSN | NUMBER(38) | NO | The maximum write point (LSN). |
| MAX_SCN | NUMBER(38) | NO | The maximum write point (SCN). |
| ARBITRATION_MEMBER | VARCHAR2(128)    | NO | The server address of the arbitration member <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| DEGRADED_LIST |VARCHAR2(1024) | NO | The list of full-featured replicas that are downgraded in arbitration mode <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| LEARNER_LIST | CLOB| NO | The list of read-only replicas in the log stream <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
