# GV$OB_UNITS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the information about the units of the OBServer node where the tenant is located. The system tenant can view the information about the units of all OBServer nodes in the cluster.

## Columns

|       Column       |      Type      | Nullable |                         Description            |
|------------------|--------------|------------|-------------------------------------------------------------------------|
| SVR_IP           | VARCHAR2(46)  | NO         | The IP address of the server.                                                              |
| SVR_PORT         | NUMBER(38)   | NO         | The port number of the server.                                                                 |
| Unit_ID          | NUMBER(38)   | NO         | The ID of the unit.                                                                |
| TENANT_ID        | NUMBER(38)   | NO         | The ID of the tenant to which the unit belongs.                                                          |
| ZONE             | VARCHAR2(128) | NO         | The name of the zone.                                                                |
| ZONE_TYPE        | VARCHAR2(128) | NO         | The type of the zone where the unit is located. Valid values: <ul><li>`NULL`: This value is invalid. It appears temporarily when the OBServer node restarts. </li> <li>`ReadWrite`: Read/Write Zone</li> <li>`Encryption`: Encrypted Zone</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| REGION           | VARCHAR2(128) | NO         | The name of the region to which the zone where the unit is located belongs. If this value is not set, the default value is `default_region`. If this value is `NULL`, it indicates that the value is invalid, which appears temporarily when the OBServer node restarts. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main>  |
| MIN_CPU          | NUMBER(38)       | NO         | The minimum CPU specification.                                                               |
| MAX_CPU          | NUMBER(38)       | NO         | The maximum CPU specification.                                                               |
| MEMORY_SIZE       | NUMBER(38)   | NO         | The size of memory, in bytes.                                                           |
| MIN_IOPS         | NUMBER(38)   | NO         | The minimum IOPS specification.                                                           |
| MAX_IOPS         | NUMBER(38)   | NO         | The maximum IOPS specification.                                                           |
| IOPS_WEIGHT    | NUMBER(38)   | NO         | The IOPS weight.                          |
| LOG_DISK_SIZE  | NUMBER(38)   | NO         | The size of the log disk, in bytes.                |
| LOG_DISK_IN_USE | NUMBER(38)   | NO         | The size of the log disk that has been used, in bytes.                                                               |
| DATA_DISK_IN_USE | NUMBER(38)   | NO         | The size of the data disk that has been used, in bytes.                                                               |
| STATUS           | VARCHAR2(64)  | NO         | The status of the unit. Valid values: <li> `NORMAL`: Normal.   <li> `MIGRATING IN`: Migrating in.   <li> `MIGRATING OUT`: Migrating out.   <li> `MARK DELETING`: Marked for deletion. <li>`WAIT GC`: Waiting for garbage collection. <li>`DELETING`: Deleted after garbage collection. <li> `ERROR`: Error.  |
| CREATE_TIME      | NUMBER(38) | NO         | The time when the unit is created on the OBServer node.                                                 |

## Sample query

Query the information about the units of all OBServer nodes where the current tenant is located.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_UNITS\G
```
