# V$OB_LS_REPLICA_TASK_PLAN

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays all tasks that should be generated (including those that have been generated and those that have not yet been generated).

## Columns

| Column                 | Type           | Nullable | Description                             |
|-------------------------|----------------|-----------------|------------------------------------|
| LS_ID                   | NUMBER(38)     | NO              | The ID of the log stream.                          |
| TASK_TYPE               | VARCHAR2(64)   | NO              | The task type. Valid values:<ul><li>MIGRATE REPLICA: migrate a replica</li><li>ADD REPLICA: add a replica</li> <li>REMOVE PAXOS REPLICA: remove a replica</li> <li>MODIFY PAXOS REPLICA NUMBER: modify the number of required Paxos replicas</li></ul>|
| PRIORITY                | CHAR(5)        | NO              | The task priority. Valid values:<ul><li>LOW: low priority. Only migration tasks can have low priority.</li><li>HIGH: high priority.</li></ul>|
| TARGET_REPLICA_SVR_IP   | VARCHAR2(46)   | YES             | The IP address of the server where the target replica resides. |
| TARGET_REPLICA_SVR_PORT | NUMBER(38)     | YES             | The port number of the server where the target replica resides. |
| TARGET_PAXOS_REPLICA_NUMBER | NUMBER(38) | YES             | The number of required Paxos replicas for the log stream. |
| TARGET_REPLICA_TYPE     | VARCHAR2(16)   | YES             | The type of the target replica. |
| SOURCE_REPLICA_SVR_IP   | VARCHAR2(46)   | YES             | The IP address of the server where the source replica resides.</br>For tasks such as replica removal and modification of the number of required Paxos replicas, this field is invalid and is displayed as NULL. |
| SOURCE_REPLICA_SVR_PORT | NUMBER(38)     | YES             | The port number of the server where the source replica resides.</br>For tasks such as replica removal and modification of the number of required Paxos replicas, this field is invalid and is displayed as 0. |
| SOURCE_PAXOS_REPLICA_NUMBER | NUMBER(38) | YES             | The number of required Paxos replicas for the log stream. |
| SOURCE_REPLICA_TYPE     | VARCHAR2(16)   | YES             | The type of the source replica.</br>For tasks such as replica removal and modification of the number of required Paxos replicas, this field is invalid and is displayed as NULL. |
| TASK_EXEC_SVR_IP        | VARCHAR2(46)   | YES             | The IP address of the server where the task is executed. |
| TASK_EXEC_SVR_PORT      | NUMBER(38)     | YES             | The port number of the server where the task is executed. |
| COMMENT                 | VARCHAR2(2048) | YES             | The comment on the reason for task generation. |
