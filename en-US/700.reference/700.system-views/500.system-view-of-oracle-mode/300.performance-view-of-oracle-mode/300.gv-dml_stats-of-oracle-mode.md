# GV$DML_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the DML information of user tables in the current tenant on all OBServer nodes.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server. |
| SVR_PORT | NUMBER | NO | The port number of the server. |
| INST_ID | NUMBER | NO | The tenant ID. |
| OBJN | NUMBER | NO | The object ID. |
| INS | NUMBER | NO | The approximate number of insertions since the last statistics collection. |
| UPD | NUMBER | NO | The approximate number of updates since the last statistics collection. |
| DEL | NUMBER | NO | The approximate number of deletions since the last statistics collection. |
| DROPSEG | NUMBER | NO | This column is not supported and is NULL by default. |
| CURROWS | NUMBER | NO | This column is not supported and is NULL by default. |
| PAROBJN | NUMBER | NO | This column is not supported and is NULL by default. |
| LASTUSED | NUMBER | NO | This column is not supported and is NULL by default. |
| FLAGS | NUMBER | NO | This column is not supported and is NULL by default. |
| CON_ID | NUMBER | NO | This column is not supported and is NULL by default. |

## Sample query

Query the DML information of user tables in the current tenant on all OBServer nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$DML_STATS;
```
