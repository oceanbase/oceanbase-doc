# GV$OB_LS_SNAPSHOTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `GV$OB_LS_SNAPSHOTS` view displays information about log stream snapshots stored in all units.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| SNAPSHOT_ID | NUMBER(38) | NO | The snapshot ID. |
| LS_ID | NUMBER(38) | NO | The log stream ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server where the log stream is located. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server where the log stream is located. |
| META_EXISTED | VARCHAR2(3) | NO | Indicates whether the meta information of the snapshot is stored in the unit (YES/NO). |
| BUILD_STATUS | VARCHAR2(10) | NO | The creation status of the snapshot. |
| REBUILD_SEQ_START | NUMBER(38) | YES | The rebuild sequence number of the log stream when the snapshot creation started. |
| REBUILD_SEQ_END | NUMBER(38) | YES | The rebuild sequence number of the log stream when the snapshot creation ended. |
| END_INTERVAL_SCN | NUMBER(38) | YES | The SCN at which the replay was terminated. |
| LS_META_PACKAGE | CLOB | YES | The log stream metadata corresponding to the start replay SCN. |
| TSNAP_IS_RUNNING | VARCHAR2(3) | NO | Indicates whether the snapshot of the corresponding tenant is running (YES/NO). |
| TSNAP_HAS_UNFINISHED_CREATE_DAG | VARCHAR2(3) | NO | Indicates whether there are unfinished Create tasks for the snapshot of the corresponding tenant (YES/NO). |
| TSNAP_HAS_UNFINISHED_GC_DAG | VARCHAR2(3) | NO | Indicates whether there are unfinished GC tasks for the snapshot of the corresponding tenant (YES/NO). |
| TSNAP_CLONE_REF | NUMBER(38) | YES | The number of clone tasks for the snapshot of the corresponding tenant. |
| TSNAP_META_EXISTED | VARCHAR2(3) | NO | Indicates whether the meta information of the snapshot of the corresponding tenant is stored in the unit (YES/NO). |
