# GV$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in V4.0.0. </p>
</main>

## Description

Displays the progress of major compactions at the tablet level.

## Field description

|             Field name             |                Type                 | Nullable |                                            Description                                            |
|------------------------------|-----------------------------------|------------|--------|
| SVR_IP                       | VARCHAR2(46)                      | NO         | The IP address of the server.                                                                                |
| SVR_PORT                     | NUMBER(38)                        | NO         | The port number of the server.|
| TENANT_ID                    | NUMBER(38)                        | NO         | The ID of the tenant. |
| TYPE                         | VARCHAR2(64)                      | NO         | The type of compaction. <ul><li>`MDS_TABLE_MERGE`: The system metadata is persisted to the disk in the SSTable format. </li> <li>`MAJOR_MERGE`: A major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: A major compaction at the partition level. </li> <li>`MINI_MERGE`: A mini compaction that converts MemTables into a Mini SSTable. </li> <li>`MINOR_MERGE`: A minor compaction that merges multiple Mini SSTables into a new one or a minor compaction that merges a few Mini SSTables and a minor SSTable into a new one. </li> <li>`META_MAJOR_MERGE`: A special type of compaction that synthesizes data from the start time to a specified time point into a Meta Major SSTable.
