# V$OB_LOG_TRANSPORT_DEST_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in OceanBase Database V4.2.5. </p>
</main>

## Purpose

The `V$OB_LOG_TRANSPORT_DEST_STAT` view displays the information about downstream log synchronization links (OceanBase Change Data Capture, obcdc for short, or a standby tenant) of the current OBServer node in the current tenant.

## Columns

| Column | Type | Nullable? | Description |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID                   | NUMBER(38)                        | NO   | The ID of the tenant. |
| SVR_IP                      | VARCHAR2(46)                      | NO   | The IP address of the OBServer node. |
| SVR_PORT                    | NUMBER(38)                        | NO   | The remote procedure call (RPC) port number of the OBServer node. |
| LS_ID                       | NUMBER(38)                        | NO   | The log stream ID of the request. |
| CLIENT_IP                   | VARCHAR2(46)                      | NO   | The IP address of the OBServer node where the client process resides. |
| CLIENT_PID                  | NUMBER(38)                        | NO   | The ID of the client process. |
| CLIENT_TENANT_ID            | NUMBER(38)                        | NO   | The tenant ID of the client. |
| CLIENT_TYPE                 | VARCHAR2(7)                       | NO   | The type of the client. Valid values: <ul><li>`STANDBY`: indicates a standby tenant. </li><li>`CDC`: indicates obcdc. </li><li>`UNKNOWN`: indicates an unknown client type. </li></ul>    |
| START_SERVE_TIME            | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The time when the record was created. |
| LAST_SERVE_TIME             | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The time when the record was last modified. |
| LAST_READ_SOURCE            | VARCHAR2(7)          | NO   | The source where logs are read during the last request processing. Valid values: <ul><li>`ONLINE`: indicates online logs. </li><li>`ARCHIVE`: indicates archive logs. </li><li>`UNKNOWN`: indicates an unknown source. </li></ul>     |
| LAST_REQUEST_TYPE           | VARCHAR2(24)         | NO   | The RPC type of the last request. Valid values: <ul><li>`0`: SEQUENTIAL_READ_SERIAL, which indicates that logs were sequentially read through serial log transport. </li><li>`1`: SEQUENTIAL_READ_PARALLEL, which indicates that logs were sequentially read through parallel log transport. </li><li>`2`: SCATTERED_READ, which indicates that the last request read scattered logs. </li><li>Other values: indicates an unknown RPC type. </li></ul>     |
| LAST_REQUEST_LOG_LSN        | NUMBER(38)                        | NO   | The log sequence number (LSN) of the last request. |
| LAST_REQUEST_LOG_SCN        | NUMBER(38)                        | NO   | The log system change number (SCN) of the last request. |
| LAST_FAILED_REQUEST         | CLOB                              | NO   | The RPC information of the last failure, such as the sending time, trace ID, and error code. |
| AVG_REQUEST_PROCESS_TIME    | NUMBER(38)                        | NO   | The average RPC processing time. |
| AVG_REQUEST_QUEUE_TIME      | NUMBER(38)                        | NO   | The average RPC queuing time. |
| AVG_REQUEST_READ_LOG_TIME   | NUMBER(38)                        | NO   | The average RPC log read time. |
| AVG_REQUEST_READ_LOG_SIZE   | NUMBER(38)                        | NO   | The average RPC log read size. |
| AVG_LOG_TRANSPORT_BANDWIDTH | VARCHAR2(44)                      | NO   | The average log transport bandwidth. |

## Sample query

Query the information about downstream log synchronization links (obcdc or a standby tenant) of the current OBServer node in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_LOG_TRANSPORT_DEST_STAT;
```
