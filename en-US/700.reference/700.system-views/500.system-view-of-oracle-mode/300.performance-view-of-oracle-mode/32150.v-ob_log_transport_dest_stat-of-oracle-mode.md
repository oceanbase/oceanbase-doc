# V$OB_LOG_TRANSPORT_DEST_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>For V4.3.x, this view is available starting with V4.3.5. </li> <li>For V4.2.x, this view is available starting with V4.2.5. </li></ul>
</main>

## Purpose

The `V$OB_LOG_TRANSPORT_DEST_STAT` view displays information about downstream log synchronization links (OBCDC or network standby databases) under the current OBServer node of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID                   | NUMBER(38)                        | NO   | The tenant ID.     |
| SVR_IP                      | VARCHAR2(46)                      | NO   | The IP address of the server.     |
| SVR_PORT                    | NUMBER(38)                        | NO   | The RPC port of the server.     |
| LS_ID                       | NUMBER(38)                        | NO   | The ID of the log stream requested.     |
| CLIENT_IP                   | VARCHAR2(46)                      | NO   | The IP address of the machine where the client process is located.     |
| CLIENT_PID                  | NUMBER(38)                        | NO   | The process ID of the client.     |
| CLIENT_TENANT_ID            | NUMBER(38)                        | NO   | The tenant ID of the client.     |
| CLIENT_TYPE                 | VARCHAR2(7)                       | NO   | The type of the client. Valid values: <ul><li>STANDBY: network standby database </li><li>CDC: OBCDC </li><li>UNKNOWN: unknown client type </li></ul>    |
| START_SERVE_TIME            | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The time when the record was created.     |
| LAST_SERVE_TIME             | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The time when the record was last modified.     |
| LAST_READ_SOURCE            | VARCHAR2(7)          | NO   | The source of the log read during the last request. Valid values: <ul><li>ONLINE: online log </li><li>ARCHIVE: archived log </li><li>UNKNOWN: unknown source </li></ul>     |
| LAST_REQUEST_TYPE           | VARCHAR2(24)         | NO   | The type of the last RPC request. Valid values: <ul><li>0: SEQUENTIAL_READ_SERIAL, indicating that the serial log transport protocol is used to read logs sequentially. </li><li>1: SEQUENTIAL_READ_PARALLEL, indicating that the parallel log transport protocol is used to read logs sequentially. </li><li>2: SCATTERED_READ, indicating that the last request was to read scattered logs. </li><li>Other values: unknown RPC type. </li></ul>     |
| LAST_REQUEST_LOG_LSN        | NUMBER(38)                        | NO   | The LSN of the log in the last request.     |
| LAST_REQUEST_LOG_SCN        | NUMBER(38)                        | NO   | The SCN of the log in the last request.     |
| LAST_FAILED_REQUEST         | CLOB                              | NO   | The information about the last failed RPC request, including the send time, TRACE_ID, and error code.    |
| AVG_REQUEST_PROCESS_TIME    | NUMBER(38)                        | NO   | The average RPC processing time.     |
| AVG_REQUEST_QUEUE_TIME      | NUMBER(38)                        | NO   | The average RPC queueing time.     |
| AVG_REQUEST_READ_LOG_TIME   | NUMBER(38)                        | NO   | The average time taken to read logs for an RPC request.     |
| AVG_REQUEST_READ_LOG_SIZE   | NUMBER(38)                        | NO   | The average size of logs read for an RPC request.     |
| AVG_LOG_TRANSPORT_BANDWIDTH | VARCHAR2(44)                      | NO   | The average log transport bandwidth.     |

## Sample query

Query information about downstream log synchronization links (OBCDC or network standby databases) under the current OBServer node of the current tenant.
