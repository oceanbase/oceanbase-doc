# GV$OB_PL_CACHE_OBJECT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view is available starting with V4.3.1 in V4.3.x. </li><li>This view is available starting with V4.2.2 in V4.2.x. </li></ul>
</main>

## Purpose

The `GV$OB_PL_CACHE_OBJECT` view displays the basic information of all PL-related cached objects in all servers of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | NUMBER(38)         | NO   |  Tenant ID:<ul><li>1: system tenant ID.  </li><li>Other values: user tenant or Meta tenant ID.  </li></ul>   |
| SVR_IP            | VARCHAR2(46)       | NO   |  IP address of the node where the cache object is located.   |
