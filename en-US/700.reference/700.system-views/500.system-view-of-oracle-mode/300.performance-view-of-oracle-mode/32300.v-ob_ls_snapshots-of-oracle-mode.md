# V$OB_LS_SNAPSHOTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `V$OB_LS_SNAPSHOTS` view displays information about the log stream snapshots that are persistently stored in all units of the current OBServer.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| SNAPSHOT_ID | NUMBER(38) | NO | The snapshot ID. |
| LS_ID | NUMBER(38) | NO | The log stream ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server where the log stream is located. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server where the log stream is located. |
| META_EXISTED | VARCHAR2(3 CHAR) | NO | Indicates whether the meta information of the snapshot is stored in the unit (YES/NO). |
| BUILD_STATUS | VARCHAR2(10 CHAR) | NO | The creation status of the snapshot. |
| REBUILD_SEQ_START | NUMBER(38) | NO | The REBUILD SEQ of the log stream when the snapshot creation started. |
| REBUILD_SEQ_END | NUMBER(38) | NO | The REBUILD SEQ of the log stream when the snapshot creation ended. |
| END_INTERVAL_SCN | NUMBER(38) | NO | The SCN at which the replay ended. |
| LS_META_PACKAGE | CLOB | NO | The log stream metadata corresponding to the start replay point. |
| TSNAP_IS_RUNNING | VARCHAR2(3 CHAR) | NO | Indicates whether the corresponding tenant snapshot is running (YES/NO). |
| TSNAP_HAS_UNFINISHED_CREATE_DAG | VARCHAR2(3 CHAR) | NO | Indicates whether there are unfinished Create tasks for the corresponding tenant snapshot (YES/NO). |
| TSNAP_HAS_UNFINISHED_GC_DAG | VARCHAR2(3 CHAR) | NO | Indicates whether there are unfinished GC tasks for the corresponding tenant snapshot (YES/NO). |
| TSNAP_CLONE_REF | NUMBER(38) | NO | The number of clone tasks for the corresponding tenant snapshot. |
| TSNAP_META_EXISTED | VARCHAR2(3 CHAR) | NO | Indicates whether the meta information of the corresponding tenant snapshot is stored in the unit (YES/NO). |

## Sample query

Query information about the log stream snapshots that are persistently stored in all units of the current OBServer.

obclient [SYS]> SELECT * FROM SYS.V$OB_LS_SNAPSHOTS;
