# V$OB_TRANSACTION_PARTICIPANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the context information of active transactions in the current tenant on the current OBServer node.

## Columns

|       Column       |                Type                 | Nullable |    Description     |
|------------------|-----------------------------------|------------|-----------|
| TENANT_ID        | NUMBER(38)                        | NO         | The tenant ID.     |
| SVR_IP           | VARCHAR2(46)                      | NO         | The IP address of the server. |
| SVR_PORT         | NUMBER(38)                        | NO         | The port number of the server.    |
| SESSION_ID       | NUMBER(38)                        | NO         | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> In all connection modes (direct mode/ODP mode), this field indicates the server session ID. </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this field indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this field indicates the server session ID. </li></ul></ul></li></ul>       |
| SCHEDULER_ADDR   | VARCHAR2(64)                      | NO         | The IP address of the node where the scheduler is located. |
| TX_TYPE          | VARCHAR2(11)                      | NO         | The transaction type.      |
| TX_ID            | NUMBER(38)                        | NO         | The transaction ID.      |
| LS_ID            | NUMBER(38)                        | NO         | The ID of the log stream to which the transaction belongs.   |
| PARTICIPANTS     | VARCHAR2(1024)                    | NO         | The list of participants.     |
| CTX_CREATE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | The time when the context was created.  |
| TX_EXPIRED_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | The time when the transaction times out.   |
| STATE            | VARCHAR2(9)                       | NO         | The context submission status.   |
| ACTION           | VARCHAR2(10)                      | NO         | The last executed action.  |
| PENDING_LOG_SIZE | NUMBER(38)                        | NO         | The size of data to be persisted.  |
| FLUSHED_LOG_SIZE | NUMBER(38)                        | NO         | The size of data that has been persisted.  |
| IS_EXITING       | VARCHAR2(3)                       | NO         | Indicates whether the context is exiting.    |
| ROLE             | VARCHAR2(8)                       | NO         | The role of the context.     |

## Sample query

Query the participant information of active transactions in the current tenant on all nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_TRANSACTION_PARTICIPANTS\G
```
