# V$OB_LS_LOG_TRANSPORT_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.2, this view is available starting from V4.4.2 BP2.</p>
</main>

## Overview

The `V$OB_LS_LOG_TRANSPORT_STAT` view displays the transmission status of logs pushed from each log stream (LS) to a standby database in strong sync mode for the current node of a tenant. To query this view, you must log in as the primary tenant (or the `sys` tenant of the cluster where the primary tenant resides).

## Columns

| Column | Type | Nullable | Description |
| ----------------- | --------------------- | ---------------- | ------------- |
| TENANT_ID | NUMBER(38) | NO | Tenant ID |
| LS_ID | NUMBER(38) | NO | Log Stream ID |
| SVR_IP | VARCHAR2(46) | NO | Server IP Address |
| SVR_PORT | NUMBER(38) | NO | Server Port Number |
| ROLE | VARCHAR2(32) | NO | Log stream replica roles:<ul><li>`LEADER`: Primary replica</li> <li>`FOLLOWER`: Follower replica</li></ul> |
| ENABLED | NUMBER(38) | NO | Whether the log transport service is enabled. |
| END_LSN | NUMBER(38) | NO | LSN committed by the primary tenant (primary database) Palf |
| END_SCN | NUMBER(38) | NO | SCN committed by the primary tenant (primary database) Palf |
| LAST_SENT_LSN | NUMBER(38) | NO | Last LSN sent to the standby tenant (standby database) |
| LAST_SENT_SCN | NUMBER(38) | NO | Last SCN sent to the standby tenant (standby database) |
| STANDBY_END_LSN | NUMBER(38) | NO | Confirmed LSN written on the standby tenant (standby database) |
| STANDBY_END_SCN | NUMBER(38) | NO | Confirmed SCN written on the standby tenant (standby database) |
| STANDBY_ADDR | VARCHAR2(52) | NO | Address of the log stream leader on the standby tenant (standby database). If the value is `0.0.0.0:0`, the address is invalid. |

## Sample query

In the primary tenant, query the transmission status of logs pushed by each log stream on the current node to the standby tenant.

1. Check the synchronization mode of the primary tenant LS.

   ```shell
   obclient(root@oracle001)[SYS]> SELECT LS_ID, ROLE, SYNC_MODE FROM SYS.V$OB_LOG_STAT WHERE ROLE = 'LEADER';
   ```

   The query result is as follows:

   ```shell
   +-------+--------+-----------+
   | LS_ID | ROLE   | SYNC_MODE |
   +-------+--------+-----------+
   |     1 | LEADER | SYNC      |
   |  1001 | LEADER | SYNC      |
   +-------+--------+-----------+
   2 rows in set
   ```

   The result `SYNC` indicates that the current tenant's log stream synchronization mode is strong sync.

2. Query the transmission status of each log stream from all nodes of the primary tenant to the standby tenant.

   ```shell
   obclient(root@oracle001)[SYS]> SELECT LS_ID, ROLE, ENABLED,
       END_LSN, LAST_SENT_LSN, STANDBY_END_LSN, STANDBY_ADDR
       FROM SYS.V$OB_LS_LOG_TRANSPORT_STAT WHERE ROLE = 'LEADER';
   ```

   The query result is as follows:

   ```shell
   +-------+--------+---------+-----------+---------------+-----------------+-------------------+
   | LS_ID | ROLE   | ENABLED | END_LSN   | LAST_SENT_LSN | STANDBY_END_LSN | STANDBY_ADDR      |
   +-------+--------+---------+-----------+---------------+-----------------+-------------------+
   |     1 | LEADER |       1 | 305300441 |     305300441 |       305300441 | 6.xx.xxx.160:2882 |
   |  1001 | LEADER |       1 | 201421647 |     201421647 |       201421647 | 6.xx.xxx.160:2882 |
   +-------+--------+---------+-----------+---------------+-----------------+-------------------+
   2 rows in set
   ```
