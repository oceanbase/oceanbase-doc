# GV$OB_TABLET_COMPACTION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V4.0.0. </p>
</main>

## Purpose

The `GV$OB_TABLET_COMPACTION_HISTORY` view displays historical information about tablet-level compactions.

## Columns

| Column |  Type  | Nullable? | Description |
|--------------------------------------|---------------|------------|--------|
| SVR_IP                               | VARCHAR2(46)  | NO         | The IP address of the server.                                                                                |
| SVR_PORT                             | NUMBER(38)    | NO         | The port of the server.|
| TENANT_ID                            | NUMBER(38)    | NO         | The tenant ID. |
| LS_ID                                | NUMBER(38)    | NO         | The log stream ID.|
| TABLET_ID                            | NUMBER(38)    | NO         | The data tablet ID.                                                                                  |
| TYPE                                 | VARCHAR2(64)  | NO         | The type of compaction. Valid values include:<ul><li>`MDS_TABLE_MERGE`: persists the metadata of the system in the format of SSTable to the disk. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: minor compaction, which converts data in the MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction, which merges multiple Mini SSTables or multiple Mini SSTables and minor SSTables into one minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of compaction that compacts data before a specified time point to a Meta Major SSTable. The data format of a Meta Major SSTable is the same as that of a Major SSTable. It does not contain multi-version data or uncommitted transaction data. </li></ul>   |
| COMPACTION_SCN                              | NUMBER(38)    | NO         | The version of the compaction: snapshot_version for minor compaction.                                                            |
| START_TIME                           | TIMESTAMP(6) WITH LOCAL TIME ZONE    | NO         | The start time.  |
| FINISH_TIME                          | TIMESTAMP(6) WITH LOCAL TIME ZONE    | NO         | The end time.  |
| OCCUPY_SIZE                          | NUMBER(38)    | NO         | The data volume.   |
| MACRO_BLOCK_COUNT                    | NUMBER(38)    | NO         | The number of macro blocks.   |
| MULTIPLEXED_MACRO_BLOCK_COUNT        | NUMBER(38)    | NO         | The number of reused macro blocks. |
| NEW_MICRO_COUNT_IN_NEW_MACRO         | NUMBER(38)    | NO         | The number of new micro blocks in a new macro block.                                                                              |
| MULTIPLEXED_MICRO_COUNT_IN_NEW_MACRO | NUMBER(38)    | NO         | The number of reused micro blocks in a new macro block.                                                                             |
| TOTAL_ROW_COUNT                      | NUMBER(38)    | NO         | The total number of rows.   |
| INCREMENTAL_ROW_COUNT                | NUMBER(38)    | NO         | The number of new rows. |
| COMPRESSION_RATIO                    | NUMBER(38)    | NO         | The compression ratio of new data: the ratio of the compressed data volume to the original data volume.                                                                 |
| PROGRESSIVE_COMPACTION_ROUND         | NUMBER(38)    | NO         | The current round of progressive compaction. If the compaction is full compaction, the value of this column is -1.                                                                  |
| PROGRESSIVE_COMPACTION_NUM           | NUMBER(38)    | NO         | The total number of rounds of progressive compaction.                                                                                  |
| PARALLEL_DEGREE                      | NUMBER(38)    | NO         | The degree of parallelism.   |
| PARALLEL_INFO                        | VARCHAR2(512) | NO         | The information about the parallel task, which displays the statistics of the data scanned, runtime, and data output (minimum value, maximum value, and average value) of the parallel task.                                       |
| MACRO_ID_LIST    |varchar2(256)    |NO   |The list of macro blocks. If the macro block list is too long, it is not displayed.    |
|COMMENTS    |varchar2(256)    |NO   |The historical information of failed compactions and the collection information of the current compaction.    |
| START_CG_ID                     | NUMBER(38)   | NO   | The start ID of the column group. <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.0. </p></main>    |
| END_CG_ID                       | NUMBER(38)   | NO   | The end ID of the column group. <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.0. </p></main>   |
| KEPT_SNAPSHOT                   | VARCHAR2(128)| NO   | The information about the retained multi-version site for this compaction. <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.0. </p></main>    |
| MERGE_LEVEL                     | VARCHAR2(64) | NO   | Whether major compaction or microblock reuse is used for this compaction. <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.0. </p></main>    |
| EXEC_MODE                       | VARCHAR2(64) | NO   | The mode of this compaction trace:<ul><li>`EXEC_MODE_LOCAL`: local mode, which outputs macro blocks to the local disk. </li> <li>`EXEC_MODE_VALIDATE`: shared mode, which only calculates checksums and does not output macro blocks. This mode is not supported in the current version. </li> <li>`EXEC_MODE_OUTPUT`: shared mode, which outputs macro blocks to shared storage. This mode is not supported in the current version. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.3. </p></main> |
| IS_FULL_MERGE                   | VARCHAR2(5)  | NO   | Whether this compaction is full compaction. <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.3. </p></main> |
| IO_COST_TIME_PERCENTAGE         | NUMBER(38)   | NO   | The percentage of IO time in the compaction time. <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.3. </p></main> |
| MERGE_REASON                    | VARCHAR2(32) | NO   | The reason for initiating the compaction. Valid values include:<ul><li>`LOAD_DATA_SCENE`: data loading scenario</li> <li>`TOMBSTONE_SCENE`: tombstone scenario</li> <li>`INEFFICIENT_QUERY`: slow query scenario</li> <li>`FREQUENT_WRITE`: frequent write scenario</li> <li>`TENANT_MAJOR`: major compaction at the tenant level</li> <li>`USER_REQUEST`: user-initiated major compaction</li> <li>`REBUILD_COLUMN_GROUP`: row-to-column scenario</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.3. </p></main> |
| BASE_MAJOR_STATUS               | VARCHAR2(64) | NO   | The major SSTable type before the compaction:<ul><li>`COL_WITH_ALL`: hybrid row-column table defined at the time of table creation, with baseline data in hybrid row-column format. </li> <li>`COL_ONLY_ALL`: hybrid row-column table defined at the time of table creation, with baseline data in row format. </li> <li>`PURE_COL`: pure columnar table defined at the time of table creation, with baseline data in columnar format. </li> <li>`PURE_COL_ONLY_ALL`: pure columnar table defined at the time of table creation, with baseline data in row format. </li> <li>`ROW_STORE_MAJOR`: row store table. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.3. </p></main>|
| CO_MERGE_TYPE                   | VARCHAR2(64) | NO   | The columnar store merge type:<ul><li>`BUILD_COLUMN_STORE_MERGE`: columnar store merge. </li> <li>`BUILD_ROW_STORE_MERGE`: row store merge. </li> <li>`USE_RS_BUILD_SCHEMA_MATCH_MERGE`: merge to a storage type that matches the schema. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.3.3. </p></main> |

## Sample query

The user tenant queries the historical information of tablet-level compactions on all OBServer nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_TABLET_COMPACTION_HISTORY WHERE ROWNUM = 1\G
```
