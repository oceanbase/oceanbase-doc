# GV$SESSION_WAIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `GV$SESSION_WAIT` view displays information about the current or previous wait events of all sessions on all nodes, including the wait event name, wait time, and other parameters.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | NUMBER | NO | For V4.3.x: <ul><li> V4.3.5 BP2 and earlier: <br> This field represents the server session ID in all connection modes (direct mode/ODP mode). </li><li> V4.3.5 BP2 and later: <ul><li> In direct mode: <br> This field represents the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field represents the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field represents the server session ID. </li></ul></ul></li></ul>  |
| CON_ID | NUMBER | NO | Tenant ID |
| SVR_IP | VARCHAR2(46) | NO | Server IP address |
| SVR_PORT | NUMBER(38) | NO | Server port |
| EVENT | VARCHAR2(64) | NO | Name of the wait event |
| P1TEXT | VARCHAR2(64) | NO | Description of the first parameter of the wait event |
| P1 | NUMBER | NO | Value of the first parameter of the wait event |
| P2TEXT | VARCHAR2(64) | NO | Description of the second parameter of the wait event |
| P2 | NUMBER | NO | Value of the second parameter of the wait event |
| P3TEXT | VARCHAR2(64) | NO | Description of the third parameter of the wait event |
| P3 | NUMBER(38) | NO | Value of the third parameter of the wait event |
| WAIT_CLASS_ID | NUMBER | NO | ID of the wait event category |
| WAIT_CLASS# | NUMBER | NO | Sequence number of the wait event category |
| WAIT_CLASS | VARCHAR2(64) | NO | Name of the wait event category |
| STATE | VARCHAR2(19) | NO | Current state of the wait event. Valid values: <ul><li>Waiting: The session is waiting for this event. </li><li>Waited unknown time: Time information cannot be obtained because the value of the timed_statistics parameter is set to false. This indicates that the session has waited for a very short period. </li><li>Wait short time: The session has waited for a very short period that is less than one time unit, so the wait is not recorded. </li><li>Waited known time: The session has waited for the required resources. </li></ul> |
| WAIT_TIME_MICRO | NUMBER | NO | Wait time in microseconds. If the session is currently waiting, this field indicates the elapsed wait time. If the session is not waiting, this field indicates the total wait time of the last wait. |
| TIME_REMAINING_MICRO | NUMBER | NO |<ul><li> > 0: The last wait time in microseconds. The session is not waiting. </li><li> 0: The session is waiting for the current event. </li><li> -1: The last wait time is less than one time unit. The session is not waiting. </li><li> -2: Time statistics are not available. The session is not waiting. </li></ul> |
| TIME_SINCE_LAST_WAIT_MICRO | NUMBER | NO | Time elapsed since the last wait ended, in microseconds. If the session is currently waiting, this field is 0. |

## Sample query

Query information about the current or previous wait events of all sessions on all nodes.

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSION_WAIT WHERE ROWNUM =1\G
```
