# GV$OB_DTL_INTERM_RESULT_MONITOR

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.4. </p>
</main>

## Purpose

This view displays the monitoring information of the DTL intermediate result manager.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the server. |
| SVR_PORT | NUMBER(38) | NO | The port number of the server. |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| TRACE_ID | VARCHAR2(64) | NO | The TRACE ID of the statement. |
| OWNER | VARCHAR2(64) | NO | The user who uses the intermediate result. |
| START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the intermediate result is written. |
| EXPIRE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The timeout time of the intermediate result. |
| HOLD_MEMORY | NUMBER(38) | NO | The size of the memory occupied, in bytes. |
| DUMP_SIZE | NUMBER(38) | NO | The size of the dump, in bytes. |
| DUMP_COST | NUMBER(38) | NO | The time consumed for the dump. |
| DUMP_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | The time when the dump is performed. |
| DUMP_FD | NUMBER(38) | NO | The FD of the dump file. |
| DUMP_DIR_ID | NUMBER(38) | NO | The directory ID of the dump file. |
| CHANNEL_ID | NUMBER(38) | NO | The CHANNEL ID of DTL. |
| QC_ID | NUMBER(38) | NO | The QC ID of the sender. |
| DFO_ID | NUMBER(38) | NO | The DFO ID of the sender. |
| SQC_ID | NUMBER(38) | NO | The SQC ID of the sender. |
| BATCH_ID | NUMBER(38) | NO | The index of the batch in the px batch rescan scenario. |
| MAX_HOLD_MEMORY | NUMBER(38) | NO | The maximum size of the memory occupied, in bytes. |
