# DBA_WR_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.5 BP1. </p>
</main>

## Purpose

Displays sysstats at the resource group granularity.

## Columns

| Column | Type | Nullable? | Description |
| --- | --- | --- | --- |
| CLUSTER_ID | NUMBER(38) | NO | Cluster ID |
| TENANT_ID | NUMBER(38) | NO | Tenant ID |
| GROUP_ID | NUMBER(38) | NO | consumer_group_id |
| SNAP_ID | NUMBER(38) | NO | Snapshot ID |
| SVR_IP | VARCHAR2(46) | NO | Node IP |
| SVR_PORT | NUMBER(38) | NO | Node Port |
| STAT_ID | NUMBER(38) | NO | Statistics Item ID |
| VALUE | NUMBER(38) | YES | Statistical Item Value |

## Sample query

View sysstats at the resource group granularity.

```shell
obclient [sys]> SELECT * FROM DBA_WR_RES_MGR_SYSSTAT;
```

The query result is as follows:

```shell
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
| CLUSTER_ID | TENANT_ID | SNAP_ID | SVR_IP          | SVR_PORT | STAT_ID | VALUE  | group_id |
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
|          1 |         1 |       1 | xxx.xxx.xxx.198 |    49708 |   10000 | 460384 |        1 |
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
1 row in set
```
