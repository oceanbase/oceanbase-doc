# USER_AUDIT_SESSION

## Purpose

Displays the audit trail records of the current user's login and logout.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

DBA_AUDIT_SESSION
