# USER_PROFILES

## Purpose

Displays all profiles and their limitations.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_PROFILES

* ALL_PROFILES

## Columns

|   **Column**    |    **Type**    | **Nullable?** |              **Description**               |
|---------------|--------------|----------------|-----------------------------------|
| PROFILE       | VARCHAR2(30) | NO             | The name of the profile.                             |
| RESOURCE_NAME | VARCHAR2(32) | NO             | The name of the resource.                             |
| RESOURCE_TYPE | VARCHAR2(8)  | NO             | Indicates whether a profile resource is a kernel parameter or a password. |
| LIMIT         | VARCHAR2(40) | NO             | The limitations on the profile resource.                           |
