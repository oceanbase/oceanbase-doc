# DBA_TAB_PRIVS

## Purpose

Describes the privileges granted to users on objects in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TAB_PRIVS

* USER_TAB_PRIVS

## Columns

|  **Column**  |    **Type**     | **Nullable?** |            **Description**             |
|------------|---------------|----------------|-------------------------------|
| GRANTEE    | VARCHAR2(128) | NO             | The username granted access.                   |
| OWNER      | VARCHAR2(128) | NO             | The owner of the object.                        |
| TABLE_NAME | VARCHAR2(128) | NO             | The name of the object.                          |
| GRANTOR    | VARCHAR2(128) | NO             | The username that granted the privilege.                      |
| PRIVILEGE  | VARCHAR2(40)  | NO             | The privilege on the object.                         |
| GRANTABLE  | VARCHAR2(3)   | NO             | Indicates whether the privilege can be granted with the GRANT OPTION.     |
| HIERARCHY  | VARCHAR2(10)  | NO             | Indicates whether the privilege can be granted with the HIERARCHY OPTION. |
