# USER_TAB_PRIVS

## Purpose

Displays the object privileges granted to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TAB_PRIVS

* DBA_TAB_PRIVS

## Columns

|  **Column**  |    **Type**     | **Nullable?** |            **Description**             |
|------------|---------------|-----------|-------------------------------|
| GRANTEE    | VARCHAR2(128) | NO        | The username to which the access privilege is granted.                   |
| OWNER      | VARCHAR2(128) | NO        | The owner of the object.                        |
| TABLE_NAME | VARCHAR2(128) | NO        | The name of the object.                          |
| GRANTOR    | VARCHAR2(128) | NO        | The username that granted the privilege.                      |
| PRIVILEGE  | VARCHAR2(40)  | NO        | The privilege of the object.                         |
| GRANTABLE  | VARCHAR2(3)   | NO        | Indicates whether the privilege can be granted through the GRANT OPTION clause.     |
| HIERARCHY  | VARCHAR2(10)  | NO        | Indicates whether the privilege can be granted through the HIERARCHY OPTION clause. |
