# ALL_TAB_PARTITIONS

Purpose
-----------

The `ALL_TAB_PARTITIONS` view provides multi-level partitioning information, partition storage parameters, and partition statistics of all partitioned tables.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is only applicable to the Oracle mode of OceanBase Database. </p>
  </main>
