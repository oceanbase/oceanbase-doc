# DBA_OB_TABLEGROUP_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Starting from V4.2.0, table groups no longer support partitions. Therefore, this view is no longer used. You can query this view, but the query result is empty. </li>
<li>Starting from V4.2.0, you can query the <a href="15700.dba_ob_tablegroups-of-oracle-mode.md">DBA_OB_TABLEGROUPS</a> view to obtain information about table groups. For more information about table groups, see <a href="../../../300.database-object-management/200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md">Table groups</a>. </li>
</ul>
</main>

## Purpose

This view displays the partition information of a table group.

## Columns

|        Column        |       Type       | Nullable |             Description                          |
|--------------------|----------------|------------|---------------------------|
| TABLEGROUP_NAME    | VARCHAR2(128)  | NO         | The name of the table group.                                            |
| COMPOSITE          | VARCHAR2(3)    | NO         | Indicates whether the table group is a composite partition. Valid values: `YES` or `NO`.                             |
| PARTITION_NAME     | VARCHAR2(64)   | NO         | The name of the partition of the table group.                                              |
| SUBPARTITION_COUNT | NUMBER         | NO         | This column is reserved and will be `NULL`.                  |
| HIGH_VALUE         | VARCHAR2(4096) | NO         | This column is reserved and will be `NULL`.            |
| HIGH_VALUE_LENGTH  | NUMBER         | NO         | This column is reserved and will be `NULL`.                             |
| PARTITION_POSITION | NUMBER         | NO         | This column is reserved and will be `NULL`.   |
