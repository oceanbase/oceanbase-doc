# DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in V4.0.0. </p>
</main>

## Description

This view displays the status and restore progress of log streams in the current tenant.

## Fields

| Field name       | Type           | Not null | Description               |
|---------------|----------------|---------|--------------------|
| LS_ID         | NUMBER         | NO | Log stream ID |
| STATUS        | VARCHAR2(100)  | NO | The status of the log stream. It can take the following values: <li>`CREATING`: The log stream is being created. <li>`CREATED`: The log stream has been created. <li>`NORMAL`: The log stream is available for service. <li>`DROPPING`: The log stream is to be deleted. The tablets on the log stream need to be migrated. <li>`TENANT DROPPING`: The log stream is located in a tenant to be deleted. The log stream needs to be deleted. <li>`WAIT OFFLINE`: The data of the log stream has been deleted. It is waiting for garbage collection. <li>`CREATE ABORT`: The creation of the log stream has failed or is not needed. The log stream is to be deleted. |
| PRIMARY_ZONE  | CLOB           | YES | The primary zone of the log stream. |
| UNIT_GROUP_ID | NUMBER         | NO | Unit group ID |
| LS_GROUP_ID   | NUMBER         | NO | Log stream group ID |
| CREATE_SCN    | NUMBER         | NO | The SCN where the log stream starts writing logs. |
| DROP_SCN      | NUMBER         | NO | The SCN where the log stream is to be deleted. It is also the ending SCN of all user data. |
| SYNC_SCN      | NUMBER         | NO | The synchronization SCN of the log stream. |
| READABLE_SCN  | NUMBER         | NO | The readable SCN of the log stream. |
| FLAG          | VARCHAR2(2048) | YES| The log stream flag. It can take the following values: <ul><li>NULL: The log stream is normal. </li><li> DUPLICATE: The log stream is a broadcast log stream of a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: Tablets cannot be created on the log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: A broadcast log stream does not support tablet creation. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.2.0. </p></main>  |

## Examples

A user tenant queries the status and restore progress of its log streams.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS;
```
