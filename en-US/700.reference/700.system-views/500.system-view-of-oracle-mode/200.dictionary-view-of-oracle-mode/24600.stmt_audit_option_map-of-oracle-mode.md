# STMT_AUDIT_OPTION_MAP

## Purpose

The view records the ID, name, and priority of statement-level audit types.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

The DBA_STMT_AUDIT_OPTS view

## Columns

| **Column** |    **Type**     | **Nullable?** |               **Description**                |
|----------|---------------|----------------|-------------------------------------|
| OPTION#  | NUMBER(38)    | NO             | The ID of a statement-level audit type.                     |
| NAME     | VARCHAR2(128) | NO             | The name of a statement-level audit type.                  |
| PROPERTY | NUMBER        | NO             | The priority of a statement-level audit type. Currently, this field is not supported and defaults to NULL. |
