# ALL_TAB_COLUMNS

## Purpose

Displays all columns of tables and views accessible to the current user.
  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_TAB_COLUMNS

* USER_TAB_COLUMNS
