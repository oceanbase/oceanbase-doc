# USER_MVIEW_LOGS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `USER_MVIEW_LOGS` view displays information about materialized view logs.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| LOG_OWNER | VARCHAR2(128) | YES | The name of the owner of the materialized view log. |
| MASTER | VARCHAR2(128) | NO | The name of the master table to which the materialized view log belongs. |
| LOG_TABLE | VARCHAR2(128) | YES | The name of the materialized view log table. |
| LOG_TRIGGER | VARCHAR2(128) | YES | The row-level trigger on the master table that inserts rows into the materialized view log. <main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and its value is NULL by default. </p></main> |
| ROWIDS | VARCHAR2(3) | NO | Indicates whether to record rowid information. <ul><li> YES </li><li>NO </li></ul>|
| PRIMARY_KEY | VARCHAR2(3) | NO | Indicates whether to record primary key information. <ul><li> YES </li><li>NO </li></ul>|
| OBJECT_ID | VARCHAR2(3) | NO | Indicates whether to record object identifiers in the object table. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and its value is NO by default. </p></main> |
| FILTER_COLUMNS | VARCHAR2(3) | NO | Indicates whether to record filter column information. <ul><li> YES </li><li>NO </li></ul>|
| SEQUENCE | VARCHAR2(3) | NO | Indicates whether to record sequence values that provide additional sorting information. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| INCLUDE_NEW_VALUES | VARCHAR2(3) | NO | Indicates whether to record both old and new values. <ul><li>YES: Record both old and new values. </li><li>NO: Record only old values. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| PURGE_ASYNCHRONOUS | VARCHAR2(3) | NO | Indicates whether the materialized view log is asynchronously purged. <ul><li> YES </li><li>NO </li></ul>|
| PURGE_DEFERRED | VARCHAR2(3) | NO | Indicates whether to purge the materialized view log in a deferred manner. <ul><li> YES </li><li>NO </li></ul>|
| PURGE_START | DATE | YES | The start date of the deferred purge. |
| PURGE_INTERVAL | VARCHAR2(200) | YES | The time interval for the deferred purge. |
| LAST_PURGE_DATE | DATE | YES | The date when the materialized view log was last purged. |
| LAST_PURGE_STATUS | NUMBER | NO | The status of the last purge of the materialized view log. <ul><li>Error code  </li><li>0: Indicates success. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always 0. </p></main> |
| NUM_ROWS_PURGED | NUMBER | YES | The number of rows purged from the materialized view log in the last purge. |
| COMMIT_SCN_BASED | VARCHAR2(3) | NO | Indicates whether the materialized view log is based on commit SCN. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| STAGING_LOG | VARCHAR2(3) | NO | Indicates whether the materialized view log is a staging log for synchronous refresh. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and its value is NO by default. </p></main> |
| PURGE_DOP          | NUMBER(38)    | NO   | The parallelism for purging the materialized view log. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting with V4.3.5 BP2. </p></main>|
| LAST_PURGE_TIME    | NUMBER(38)    | YES  | The duration of the last materialized view log purge task, in seconds. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting with V4.3.5 BP2. </p></main>|
