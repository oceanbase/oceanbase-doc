# DBA_OB_BALANCE_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the history of load balancing tasks executed in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | The ID of the load balancing task. |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The start time of the task. |
| FINISH_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The end time of the task. This field indicates the time when the task is completed or canceled. |
| TASK_TYPE | VARCHAR2(64) | NO | The type of the task. Valid values: <ul><li>`LS_SPLIT`: Log stream splitting.  </li><li>`LS_ALTER`: Modifying the attributes of a log stream. </li><li>`LS_MERGE`: Log stream merging. </li><li>`LS_TRANSFER`: Log stream transfer. </li></ul>|
| SRC_LS | NUMBER(38) | NO | The source log stream. |
| DEST_LS | NUMBER(38) | NO | The destination log stream. |
| PART_LIST | CLOB | YES | The list of partitions, including user table partitions and global index partitions. |
| FINISHED_PART_LIST | CLOB | YES | The list of partitions that have completed load balancing. |
| PART_COUNT | NUMBER(38) | YES | The number of partitions in the partition list. |
| FINISHED_PART_COUNT | NUMBER(38) | YES | The number of partitions that have completed load balancing. |
| LS_GROUP_ID | NUMBER(38) | NO | The ID of the log stream group. |
| STATUS | VARCHAR2(64) | NO | The status of the task. Valid values: <ul><li>`COMPLETED`: The task is completed. </li><li>`CANCELED`: The task is canceled. </li></ul>|
| PARENT_LIST | VARCHAR2(1024) | YES | The list of parent tasks. |
| CHILD_LIST | VARCHAR2(1024) | YES | The list of child tasks. |
| CURRENT_TRANSFER_TASK_ID | NUMBER(38) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | NUMBER(38) | NO | The ID of the job to which the current task belongs. |
| COMMENT | CLOB | YES | The comment. |
| BALANCE_STRATEGY         | VARCHAR2(64)   | YES | The load balancing strategy corresponding to the balance task. Valid values: <ul><li>`LS balance by migrate`: Migration-based load balancing.  </li><li>`LS balance by alter`: Attribute modification-based load balancing. </li><li>`LS balance by expand`: Expansion-based load balancing. </li><li>`LS balance by shrink`: Shrinkage-based load balancing. </li><li>`partition balance`: Partition-based load balancing. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this field is available starting with V4.3.2. For V4.2.x, this field is available starting with V4.2.4. </p></main>   |
