# DBA_OB_BALANCE_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the history of load balancing tasks executed in the tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | The ID of the load balancing task. |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The start time of the task. |
| FINISH_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The end time of the task, including the time when the task is successfully completed or canceled. |
| TASK_TYPE | VARCHAR2(64) | NO | The task type. Valid values: <ul><li>`LS_SPLIT`: split a log stream.  </li><li>`LS_ALTER`: modify the attributes of a log stream. </li><li>`LS_MERGE`: merge log streams. </li><li>`LS_TRANSFER`: transfer a log stream. </li></ul>|
| SRC_LS | NUMBER(38) | NO | The source log stream (the log data stream generated from the data source). |
| DEST_LS | NUMBER(38) | NO | The destination log stream. |
| PART_LIST | CLOB | YES | The list of partitions, including user table partitions and global index partitions. |
| FINISHED_PART_LIST | CLOB | YES | The list of partitions that have been balanced. |
| PART_COUNT | NUMBER(38) | YES | The number of partitions in the partition list. |
| FINISHED_PART_COUNT | NUMBER(38) | YES | The number of partitions that have been balanced. |
| LS_GROUP_ID | NUMBER(38) | NO | The ID of the log stream group. |
| STATUS | VARCHAR2(64) | NO | The task status. Valid values: <ul><li>`INIT`: the task is created.  </li><li>`CREATE_LS`: a log stream is created. </li><li>`ALTER_LS`: the attributes of a log stream are modified. </li><li>`SET_LS_MERGING`: a log stream is merged. </li><li>`DROP_LS`: a log stream is dropped. </li><li>`COMPLETED`: the task is successfully executed. </li><li>`CANCELED`: the task is canceled. </li></ul>|
| PARENT_LIST | VARCHAR2(1024) | YES | The list of parent tasks. |
| CHILD_LIST | VARCHAR2(1024) | YES | The list of child tasks. |
| CURRENT_TRANSFER_TASK_ID | NUMBER(38) | NO | The ID of the Transfer task triggered by the current load balancing task. |
| JOB_ID | NUMBER(38) | NO | The ID of the job to which the current task belongs. |
| COMMENT | CLOB | YES | The comment. |
| BALANCE_STRATEGY         | VARCHAR2(64)   | YES | The balance strategy corresponding to the balance task. Valid values: <ul><li>`LS balance by migrate`: migrate-based load balancing.  </li><li>`LS balance by alter`: attribute modification-based load balancing. </li><li>`LS balance by expand`: expansion-based load balancing. </li><li>`LS balance by shrink`: reduction-based load balancing. </li><li>`partition balance`: partition-based load balancing. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this column is available starting with V4.3.2. For V4.2.x, this column is available starting with V4.2.4. </p></main>   |

obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_TASK_HISTORY\G
