# DBA_SYS_PRIVS

## Purpose

Describes the system privileges granted to users and roles. The `USERNAME` column is not displayed in this view.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_SYS_PRIVS

## Columns

|   **Column**   |    **Type**     | **Allowable Values** |      **Description**      |
|--------------|---------------|----------------|------------------|
| GRANTEE      | VARCHAR2(128) | NO             | The name of the grantee, user, or role to which the privilege is granted |
| PRIVILEGE    | VARCHAR2(40)  | NO             | The system privilege.             |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | Indicates whether the grantee has the privilege to grant the privilege to other users or roles. |
