# DBA_AUDIT_SESSION

Purpose
-----------

The `DBA_AUDIT_SESSION` view displays all audit trail entries concerning `CONNECT` and `DISCONNECT`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>
