# DBA_AUDIT_SESSION

## Purpose

This view displays all audit trail entries for `CONNECT` and `DISCONNECT` operations.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode of OceanBase Database. </p>
  </main>

## Columns

|      **Column**      |           **Type**            | **Nullable** |                         **Description**                         |
|--------------------|-----------------------------|----------------|--------------------------------------------------------|
| OS_USERNAME        | VARCHAR2(255)               | NO             | This column is not supported. It is NULL by default.             |
| USERNAME           | VARCHAR2(64)                | NO             | The name of the audited user.                                            |
| USERHOST           | VARCHAR2(32)                | NO             | The IP address of the host where the audited user is located.                       |
| TERMINAL           | VARCHAR2(255)               | NO             | This column is not supported. It is NULL by default.                       |
| TIMESTAMP          | DATE                        | NO             | The date and time when the audit trail entry was created in the local database session time zone.                              |
| ACTION_NAME        | VARCHAR2(128)               | NO             | The name of the operation type corresponding to the numeric code in the operation column of DBA_AUDIT_TRAIL.                 |
| LOGOFF_TIME        | DATE                        | NO             | The date and time when the user logged off.                                             |
| LOGOFF_LREAD       | NUMBER(38)                  | NO             | The number of logical reads in the session.                                                |
| LOGOFF_PREAD       | NUMBER                      | NO             | This column is not supported. It is NULL by default.                        |
| LOGOFF_LWRITE      | NUMBER                      | NO             | This column is not supported. It is NULL by default.                       |
| LOGOFF_DLOCK       | VARCHAR2(40)                | NO             | This column is not supported. It is NULL by default.                    |
| SESSIONID          | NUMBER(38)                  | NO             | The numeric ID of the session. <br>For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> In all connection modes (direct mode/ODP mode), this field indicates the server session ID. </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this field indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this field indicates the server session ID. </li></ul></ul></li></ul>                                               |
| RETURNCODE         | NUMBER(38)                  | NO             | The error code generated by the operation.                                              |
| CLIENT_ID          | VARCHAR2(40)                | NO             | The client identifier for each session.                                           |
| SESSION_CPU        | NUMBER(38)                  | NO             | The CPU time used by the session.                                           |
| EXTENDED_TIMESTAMP | TIMESTAMP(6) WITH TIME ZONE | NO             | The timestamp when the audit trail entry was created in the UTC time zone.                                  |
| PROXY_SESSIONID    | NUMBER(38)                  | NO             | The sequence number of the proxy session.                                                |
| GLOBAL_UID         | NUMBER(38)                  | NO             | The global user identifier of the user.                                             |
| INSTANCE_NUMBER    | VARCHAR2(40)                | NO             | This column is not supported. It is NULL by default. |
| OS_PROCESS         | VARCHAR2(40)                | NO             | This column is not supported. It is NULL by default.                   |
