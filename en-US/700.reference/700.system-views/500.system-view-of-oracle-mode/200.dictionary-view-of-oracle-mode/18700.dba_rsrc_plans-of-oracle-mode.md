# DBA_RSRC_PLANS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.1.2. </p>
</main>

## Purpose

This view displays all resource management plans defined in the system.

## Columns

|           Column            |       Type       | Nullable |                         Description                         |
|---------------------------|----------------|------------|----------------------------------------------------|
| PLAN_ID                   | NUMBER         | NO         | The ID of the resource management plan.                                          |
| PLAN                      | VARCHAR2(128)  | NO         | The name of the resource management plan.                                             |
| NUM_PLAN_DIRECTIVES       | NUMBER         | NO         | This column is reserved for compatibility. Its value is always `NULL`. |
| CPU_METHOD                | VARCHAR2(128)  | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| MGMT_METHOD               | VARCHAR2(128)  | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| ACTIVE_SESS_POOL_MTH      | VARCHAR2(128)  | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| PARALLEL_DEGREE_LIMIT_MTH | VARCHAR2(128)  | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| QUEUING_MTH               | VARCHAR2(128)  | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| SUB_PLAN                  | VARCHAR2(3)    | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| COMMENTS                  | VARCHAR2(2000) | YES        | The comments on the resource management plan.                                         |
| STATUS                    | VARCHAR2(128)  | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |
| MANDATORY                 | VARCHAR2(3)    | NO         | This column is reserved for compatibility. Its value is always `NULL`.                               |

## Sample query

Query all resource management plans defined in the system for a user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_RSRC_PLANS;
```

The query result is as follows:

```shell
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
| PLAN_ID | PLAN    | NUM_PLAN_DIRECTIVES | CPU_METHOD | MGMT_METHOD | ACTIVE_SESS_POOL_MTH | PARALLEL_DEGREE_LIMIT_MTH | QUEUING_MTH | SUB_PLAN | COMMENTS | STATUS | MANDATORY |
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
|    NULL | daytime |                NULL | NULL       | NULL        | NULL                 | NULL                      | NULL        | NULL     | TPFirst  | NULL   | NULL      |
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
1 row in set
```
