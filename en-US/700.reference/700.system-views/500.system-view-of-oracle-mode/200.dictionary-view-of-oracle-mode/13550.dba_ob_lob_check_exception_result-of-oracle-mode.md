# DBA_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.4.2. </p>
</main>

## Purpose

The `DBA_OB_LOB_CHECK_EXCEPTION_RESULT` view displays the tables and tablets with LOB consistency check exceptions, and the exception types, under the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------------- | ----------- | --------------------- | ----------- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| LS_ID | NUMBER(38) | NO | The log stream ID. |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the exception result was created. |
| UPDATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the exception result was last modified. |
| TABLE_NAME | VARCHAR2(256) | NO | The name of the abnormal table. |
| TABLE_ID | NUMBER(38) | NO | The ID of the abnormal table. |
| INCONSISTENCY_TYPE | VARCHAR2(16) | NO | Exception type. <ul><li>LOB_NOT_FOUND: The primary table points to a non-existent LOB.</li><li>LOB_LEN_MISMATCH: The metadata length does not match the actual length.</li><li>LOB_ORPHANED: The LOB exists, but the primary table has no locator.</li></ul> |
| TABLET_IDS | CLOB | NO | The IDs of the abnormal partitions. |
| TASK_SCOPE | VARCHAR2(6) | NO | Task type. Valid values:<ul><li>TENANT: tenant-level task.</li><li>LS: LS-level task.</li></ul> |

## Sample query

```shell
obclient> SELECT * FROM DBA_OB_LOB_CHECK_EXCEPTION_RESULT;
```
