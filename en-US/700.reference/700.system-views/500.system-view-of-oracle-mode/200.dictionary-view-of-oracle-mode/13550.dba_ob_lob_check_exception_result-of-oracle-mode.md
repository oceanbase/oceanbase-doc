# DBA_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.6.0. </p>
</main>

## Overview

The `DBA_OB_LOB_CHECK_EXCEPTION_RESULT` view displays the abnormal tables and tablets for LOB consistency check, along with the exception types, under the current tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------- | ----------- | --------------------- | ----------- |
| TENANT_ID | NUMBER(38) | NO | Tenant ID |
| LS_ID | NUMBER(38) | NO | Log Stream ID |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZON | NO | Exception Result Creation Time |
| UPDATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZON | NO | Modified Time of Abnormal Result |
| TABLE_NAME | VARCHAR2(256) | NO | Exceptional Table Name |
| TABLE_ID | NUMBER(38) | NO | ID of the abnormal table object |
| INCONSISTENCY_TYPE | VARCHAR2(16) | NO | Exception type. <ul><li>LOB_NOT_FOUND: The primary table points to a non-existent LOB.</li><li>LOB_LEN_MISMATCH: The metadata length does not match the actual length.</li><li>LOB_ORPHANED: The LOB exists, but the primary table has no locator.</li></ul> |
| TABLET_IDS | CLOB | NO | Exception Partition ID |
| TASK_SCOPE | VARCHAR2(6) | NO | Task type. Valid values:<ul><li>TENANT: tenant-level task.</li><li>LS: LS-level task.</li></ul> |

## Sample query

```shell
obclient > SELECT * FROM DBA_OB_LOB_CHECK_EXCEPTION_RESULT;
```
