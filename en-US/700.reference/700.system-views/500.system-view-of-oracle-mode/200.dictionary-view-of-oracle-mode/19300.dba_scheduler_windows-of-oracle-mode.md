# DBA_SCHEDULER_WINDOWS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all scheduler windows in the current tenant.

## Columns

| Column          | Type          | Nullable | Description              |
|------------------|---------------|----------------|-------------------|
| OWNER            | VARCHAR2(128)                  | NO   | The owner of the scheduler window.    |
| WINDOW_NAME      | VARCHAR2(128)                  | NO   | The name of the scheduler window.  |
| RESOURCE_PLAN    | VARCHAR2(128)                  | NO   | The resource plan associated with the window. This column is not currently used.   |
| SCHEDULE_OWNER   | VARCHAR2(4000)                 | NO   | The owner of the window's schedule. This column is not currently used.   |
| SCHEDULE_NAME    | VARCHAR2(4000)                 | NO   | The name of the window's schedule. This column is not currently used.   |
| SCHEDULE_TYPE    | VARCHAR2(8)                    | NO   | The type of the window's schedule:<ul><li>ONCE: The repeat interval is NULL.</li><li>NAMED: A named schedule.</li><li>CALENDAR: A calendar expression used as a schedule.</li></ul></br>This column is not currently used. |
| START_DATE       | TIMESTAMP(6) WITH TIME ZONE    | YES  | The start time of the window. |
| REPEAT_INTERVAL  | VARCHAR2(4000)                 | YES  | The repeat interval for the window.|
| END_DATE         | TIMESTAMP(6) WITH TIME ZONE    | YES  | The end time of the window.|
| DURATION         | INTERVAL DAY (3) TO SECOND (0) | YES  | The duration of the window.    |
| WINDOW_PRIORITY  | VARCHAR2(4)                    | NO   | The priority of the window relative to other windows:<ul><li>HIGH</li><li>LOW</li></ul> </br>This column is not currently used.|
| NEXT_RUN_DATE    | TIMESTAMP(6) WITH TIME ZONE    | NO   | The next start time of the window. |
| LAST_START_DATE  | TIMESTAMP(6) WITH TIME ZONE    | YES  | The last start time of the window.|
| ENABLED          | VARCHAR2(5)                    | YES  | Indicates whether the window is enabled (TRUE) or disabled (FALSE).    |
| ACTIVE           | VARCHAR2(5)                    | NO   | Indicates whether the window is open (TRUE) or not open (FALSE). This column is not currently used.      |
| MANUAL_OPEN_TIME | TIMESTAMP(6) WITH TIME ZONE    | NO   | The time when the window was manually opened. NULL if not manually opened. This column is not currently used.      |
| MANUAL_DURATION  | INTERVAL DAY (3) TO SECOND (0) | NO   | The duration of the manually opened window. NULL if not manually opened. This column is not currently used.    |
| COMMENTS         | VARCHAR2(4000)                 | YES  | A description of the window.   |
