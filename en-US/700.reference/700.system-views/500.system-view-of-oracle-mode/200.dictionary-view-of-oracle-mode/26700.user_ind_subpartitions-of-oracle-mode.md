# USER_IND_SUBPARTITIONS

## Purpose

Displays information about all index subpartitions owned by the user in the database. This view is similar to the `DBA_IND_SUBPARTITIONS` and `ALL_IND_SUBPARTITIONS` views, but does not contain the `INDEX_OWNER` column.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>
