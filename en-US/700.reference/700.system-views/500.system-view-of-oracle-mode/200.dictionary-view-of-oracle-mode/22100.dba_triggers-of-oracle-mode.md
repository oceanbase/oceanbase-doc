# DBA_TRIGGERS

## Purpose

Describes all triggers in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TRIGGERS

* USER_TRIGGERS

## Columns

|     **Column**      |     **Type**      | **Nullable?** |                                                                  **Description**                                                                  |
|-------------------|-----------------|----------------|------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER             | VARCHAR2(128)   | NO             | The owner of the trigger.                                             |
| TRIGGER_NAME      | VARCHAR2(128)   | NO             | The name of the trigger.                                                 |
| TRIGGER_TYPE      | VARCHAR2(16)    | NO             | The type of the trigger: * BEFORE/AFTER   * ROW/STMT    |
| TRIGGERING_EVENT  | VARCHAR2(246)   | NO             | The triggering event. The current OceanBase Database supports only INSERT, UPDATE, and DELETE.       |
| TABLE_OWNER       | VARCHAR2(128)   | NO             | The owner of the table. This field is valid when the trigger is defined on a table.                                  |
| BASE_OBJECT_TYPE  | VARCHAR2(18)    | NO             | The type of the trigger object. The current OceanBase Database supports only TABLE.                     |
| TABLE_NAME        | VARCHAR2(256)   | NO             | The name of the table. This field is valid when the trigger is defined on a table.                                       |
| COLUMN_NAME       | VARCHAR2(4000)  | YES            | The name of the column. This field is valid only when the trigger is defined on a nested table, and is NULL otherwise.                          |
| REFERENCING_NAMES | VARCHAR2(422)   | NO             | The REF name, which is an alias for OLD and NEW.                                |
| WHEN_CLAUSE       | VARCHAR2(4000)  | YES            | The triggering condition.                                                  |
| STATUS            | VARCHAR2(8)     | NO             | The status: * ENABLE   * DISABLE              |
| DESCRIPTION       | VARCHAR2(65536) | NO             | The description of the trigger, including the name, type, and event information.|
| ACTION_TYPE       | VARCHAR2(11)    | NO             | The type of the action. The current OceanBase Database supports only PL/SQL.                 |
| TRIGGER_BODY      | VARCHAR2(65536) | NO             | The trigger statement.|
| CROSSEDITION      | VARCHAR2(7)     | NO             | The cross-version information. This field is not supported.                                      |
| BEFORE_STATEMENT  | VARCHAR2(3)     | NO             | YES/NO. Indicates whether the specified section is included in the trigger statement before the statement.                  |
| BEFORE_ROW        | VARCHAR2(3)     | NO             | YES/NO. Indicates whether the specified section is included in the trigger statement before the row.                   |
| AFTER_ROW         | VARCHAR2(3)     | NO             | YES/NO. Indicates whether the specified section is included in the trigger statement after the row.                   |
| AFTER_STATEMENT   | VARCHAR2(3)     | NO             | YES/NO. Indicates whether the specified section is included in the trigger statement after the statement.                  |
| INSTEAD_OF_ROW    | VARCHAR2(3)     | NO             | YES/NO. Indicates whether the specified section is included in the trigger statement instead of the row.                   |
| FIRE_ONCE         | VARCHAR2(3)     | NO             | This field is not supported.                                            |
| APPLY_SERVER_ONLY | VARCHAR2(3)     | NO             | This field is not supported.                                            |
