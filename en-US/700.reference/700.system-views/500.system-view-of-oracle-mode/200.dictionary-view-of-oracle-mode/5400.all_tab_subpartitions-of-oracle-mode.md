# ALL_TAB_SUBPARTITIONS


Purpose
-----------

The `ALL_TAB_SUBPARTITIONS` view displays the partition-level partitioning information, partition storage parameters, and partition statistics generated by the `DBMS_STATS` package for the partitions accessible to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>
