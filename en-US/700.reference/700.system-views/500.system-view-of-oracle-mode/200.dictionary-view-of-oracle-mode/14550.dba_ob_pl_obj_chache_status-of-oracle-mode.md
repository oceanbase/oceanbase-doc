# DBA_OB_PL_OBJ_CACHE_STATUS

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>For V4.2.x versions, this view is available starting with V4.2.5 BP6.</p>
</main>

## Overview

The `DBA_OB_PL_OBJ_CACHE_STATUS` view displays the status information of PL cache objects.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------------- | --------------------- | ---------------------------------------- |
| OBJECT_NAME | VARCHAR2(128) | NO | PL Object Name |
| OBJECT_ID | NUMBER(38) | NO | PL Object ID |
| OBJECT_TYPE | VARCHAR2(12) | NO | PL Object Type |
| STATUS | VARCHAR2(7) | NO | PL Object Status |
| COMPILE_DB_ID | NUMBER(38) | NO | PL Compilation Period Corresponding to`db_id` |
| DISK_CACHE_STATUS | VARCHAR2(32767) | NO | The status of PL objects in the disk cache |
| PL_CACHE_STATUS | VARCHAR2(32767) | NO | Status of PL objects in the PL cache |

## Sample query

Query Description

```shell
obclient [SYS]> SELECT * FROM DBA_OB_PL_OBJ_CACHE_STATUS WHERE rownum < 2\G
```
