# USER_TAB_COLS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

The `USER_TAB_COLS` view displays all columns of tables and views accessible to the current user.

The `USER_TAB_COLS` view differs from [USER_TAB_COLUMNS](30500.user_tab_columns-of-oracle-mode.md) in that `USER_TAB_COLS` displays columns marked for quick drop, while `USER_TAB_COLUMNS` does not.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This view is available only in OceanBase Database in Oracle mode. </p>
</main>
