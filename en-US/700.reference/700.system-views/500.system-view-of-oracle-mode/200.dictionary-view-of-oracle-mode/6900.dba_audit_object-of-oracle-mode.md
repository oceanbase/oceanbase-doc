# DBA_AUDIT_OBJECT

## Purpose

Displays the audit records of all objects in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_AUDIT_OBJECT
