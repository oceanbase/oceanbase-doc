# DBA_PLSQL_TYPES

<main id="notice" >
    <h4>Note</h4>
    <p>This view is available starting with V4.3.5 for V4.3.x. <br> This view is available starting with V4.2.5 for V4.2.x. </p>
  </main>

## Purpose

The `DBA_PLSQL_TYPES` view displays general information about package types in the current tenant. The types in a package can be displayed in this view only if the package is successfully compiled.

<main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode. </p>
  </main>

## Columns

|         **Column**          |     **Type**     | **Nullable** |**Description**|
|---------------------------|---|---|--------------------------------------------|
| OWNER          | VARCHAR2(128) | YES  | The username of the owner of the PL/SQL type. |
| TYPE_NAME      | VARCHAR2(136) | NO   | The name of the PL/SQL type. |
| PACKAGE_NAME   | VARCHAR2(128) | YES  | The name of the package to which the PL/SQL type belongs. |
| TYPE_OID       | RAW(16)       | NO   | The object identifier of the PL/SQL type. |
| TYPECODE       | VARCHAR2(58)  | NO   | The code of the PL/SQL type. |
| ATTRIBUTES     | NUMBER(38)    | NO   | The number of attributes in the PL/SQL type. |
| CONTAINS_PLSQL | VARCHAR2(3)   | NO   | Indicates whether the PL/SQL type contains PL/SQL code. |

## Sample query

Query general information about package types in the current tenant.

```shell
obclient> SELECT * FROM DBA_PLSQL_TYPES;
```
