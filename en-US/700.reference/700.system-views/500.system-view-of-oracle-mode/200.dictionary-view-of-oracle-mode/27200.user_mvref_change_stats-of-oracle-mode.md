# USER_MVREF_CHANGE_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `USER_MVREF_CHANGE_STATS` view displays statistics related to materialized view refreshes. These statistics indicate the number of data changes in the base tables associated with each materialized view refresh and the information required to load these changes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TBL_OWNER | VARCHAR2(128) | YES | The name of the base table owner. |
| TBL_NAME | VARCHAR2(128) | YES | The name of the base table. |
| MV_OWNER | VARCHAR2(128) | YES | The name of the materialized view owner. |
| MV_NAME | VARCHAR2(128) | YES | The name of the materialized view. |
| REFRESH_ID | NUMBER | NO | The refresh ID. |
| NUM_ROWS_INS | NUMBER | YES | The number of rows inserted. |
| NUM_ROWS_UPD | NUMBER | YES | The number of rows updated. |
| NUM_ROWS_DEL | NUMBER | YES | The number of rows deleted. |
| NUM_ROWS_DL_INS | NUMBER | NO | The number of rows directly loaded. <main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and defaults to 0. </p></main> |
| PMOPS_OCCURRED | CHAR(1) | NO | Indicates whether a partition maintenance operation (PMOP) occurred. Valid values: <ul><li>Y  </li><li>N </li><li>NULL </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and defaults to N. </p></main> |
| PMOP_DETAILS | VARCHAR2(4000) | NO | The details of the PMOP, in the following format: <ul><li>TRUNCATE (low_bound, high_bound)  </li><li>EXECHANGE (low_bound, high_bound) </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and defaults to NULL. </p></main> |
| NUM_ROWS | NUMBER | YES | The number of rows in the base table at the start of the refresh. |

## Sample query

```shell
obclient [SYS]> SELECT * FROM SYS.USER_MVREF_CHANGE_STATS;
```

The query result is as follows:
