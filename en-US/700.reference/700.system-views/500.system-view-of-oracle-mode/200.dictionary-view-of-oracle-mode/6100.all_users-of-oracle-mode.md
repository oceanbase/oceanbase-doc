# ALL_USERS

## Purpose

This view displays all database users visible to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in OceanBase Database Enterprise Edition. </p>
  </main>

## Columns

| **Column** |    **Type**    | **Nullable** | **Description**  |
|----------|--------------|----------------|---------|
| USERNAME | VARCHAR2(30) | NO             | The username.     |
| USERID   | NUMBER(38)   | NO             | The user ID.   |
| CREATED  | DATE         | NO             | The time when the user was created. |
| COMMON            | VARCHAR2(3)   | NO   | Indicates whether the user is a common user. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| ORACLE_MAINTAINED | VARCHAR2(1)   | NO   | Indicates whether the user is created and maintained by scripts provided by the Oracle mode. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| INHERITED         | VARCHAR2(3)   | NO   | Indicates whether the user is inherited from another container. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| DEFAULT_COLLATION | VARCHAR2(100) | NO   | The default character set. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| IMPLICIT          | VARCHAR2(3)   | NO   | Indicates whether the user is created by an implicit application. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| ALL_SHARD         | VARCHAR2(3)   | NO   | Indicates whether the user is created under the shard-enabled mode. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|

## Sample query

Query all database users visible to the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_USERS\G
```
