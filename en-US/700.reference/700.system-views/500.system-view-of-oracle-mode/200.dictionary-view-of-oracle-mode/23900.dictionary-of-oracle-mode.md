# DICTIONARY

## Purpose

Displays the descriptions of data dictionary tables and views.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|  **Column**  |     **Type**     | **Nullable?** | **Description**  |
|------------|----------------|----------------|---------|
| TABLE_NAME | VARCHAR2(128)  | NO             | The name of the object.   |
| COMMENTS   | VARCHAR2(4000) | NO             | The text comments on the object. |
