# DBA_TAB_COMMENTS

## Purpose

The view displays the comments of all tables and views in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TAB_COMMENTS

* USER_TAB_COMMENTS

## Columns

|  **Column**  |     **Type**     | **Nullable?** |  **Description**  |
|------------|----------------|----------------|----------|
| OWNER      | VARCHAR2(128)  | NO             | The owner of the table or view. |
| TABLE_NAME | VARCHAR2(128)  | NO             | The name of the table or view.  |
| TABLE_TYPE | VARCHAR2(11)   | NO             | The type of the object.     |
| COMMENTS   | VARCHAR2(4000) | NO             | The comments of the object.     |
