# DBA_OB_TABLE_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the execution status of historical statistics collection for tables in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | YES | The username of the table. |
| TABLE_NAME | VARCHAR2(256) | NO | The name of the table. |
| TASK_ID | VARCHAR2(36) | NO | The task ID of the statistics collection. |
| STATUS | VARCHAR2(8) | NO | The status of the statistics collection task. Valid values: <ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| START_TIME | TIMESTAMP(6) | YES | The start time of the statistics collection. |
| END_TIME | TIMESTAMP(6) | YES | The end time of the statistics collection. |
| MEMORY_USED | NUMBER | YES | The memory used for the statistics collection. |
| STAT_REFRESH_FAILED_LIST | VARCHAR2(4096) | YES | The list of statistics cache refresh failures. |
| PROPERTIES | VARCHAR2(4096) | YES | The property settings for the statistics collection. |

## Sample query

Query the execution status of historical statistics collection for the `T2_M_LR` table in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLE_OPT_STAT_GATHER_HISTORY WHERE TABLE_NAME='T2_M_LR'\G
```
