# ALL_IND_SUBPARTITIONS

## Purpose

Displays information about all index subpartitions that the user can access in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>
