# DBA_MVIEWS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVIEWS` view is used to display information about all materialized views.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | YES | The name of the materialized view owner. |
| MVIEW_NAME | VARCHAR2(128) | YES | The name of the materialized view. |
| CONTAINER_NAME | VARCHAR2(128) | YES | The name of the container table of the materialized view. |
| QUERY | CLOB | NO | The query that defines the materialized view. |
| QUERY_LEN | NUMBER | NO | The length of the query, in bytes. |
| UPDATABLE | VARCHAR2(1) | NO | Indicates whether the materialized view is updatable.  <ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is N by default. </p></main> |
| UPDATE_LOG | VARCHAR2(128) | NO | The name of the update log for an updatable materialized view. <main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |
| MASTER_ROLLBACK_SEG | VARCHAR2(128) | NO | The rollback segment of the master site or the master materialized view site. <main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |
| MASTER_LINK | VARCHAR2(128) | NO | The database link of the master site or the master materialized view site. <main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |

If the materialized view meets the requirements, it must follow these rules:  <ul><li>NONE: The materialized view cannot be used for query rewrite because query rewrite is not allowed or is blocked.  </li><li>TEXTMATCH: The query of the materialized view has restrictions on query rewrite. </li><li>GENERAL: The query of the materialized view has no restrictions on query rewrite. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |
| REFRESH_MODE | VARCHAR2(6) | NO | The refresh mode of the materialized view.  <ul><li>DEMAND: The materialized view is refreshed when the refresh procedure is called.  </li><li>NEVER: The materialized view is never refreshed. </li></ul>|
| REFRESH_METHOD | VARCHAR2(8) | NO | The default method for refreshing the materialized view (which can be overridden by an API).  <ul><li>COMPLETE: A complete refresh is performed.  </li><li>FORCE: An incremental refresh is attempted. If an incremental refresh is not possible, a complete refresh is performed. </li><li>FAST: An incremental refresh is performed. </li><li>NEVER: The materialized view is never refreshed. </li></ul>|
| BUILD_MODE | VARCHAR2(9) | NO | How the materialized view is populated during creation.  <ul><li>IMMEDIATE: The materialized view is populated immediately during creation.  </li><li>DEFERRED: The materialized view is not populated during creation. </li><li>PREBUILT: The materialized view is populated with an existing table during creation. </li></ul>|
| FAST_REFRESHABLE | VARCHAR2(18) | NO | Indicates whether the materialized view is suitable for incremental (fast) refresh.  <ul><li>NO: The materialized view cannot be fast-refreshed, and is therefore complex.  </li><li>DML: Only DML operations support fast refresh. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |
| LAST_REFRESH_TYPE | VARCHAR2(8) | NO | The method used for the last refresh.  <ul><li>COMPLETE: A complete refresh was performed.  </li><li>FAST: An incremental refresh was performed. </li><li>NA: The materialized view has not been refreshed yet (for example, it was created with DEFERRED option). </li></ul>|
| LAST_REFRESH_DATE | DATE | YES | The date when the materialized view was last refreshed. |
| LAST_REFRESH_END_TIME | DATE | NO | The end time of the last refresh of the materialized view. |
| STALENESS | VARCHAR2(19) | NO | The relationship between the content of the materialized view and the content of the materialized view master.  <ul><li>FRESH: The materialized view is a read-consistent view of the current state of its master object.  </li><li>IMPORT: The materialized view was imported from another database (the value of the UNKNOWN_IMPORT column is Y). Therefore, it is unknown whether the materialized view is a read-consistent view of its master view at any point in time. After a complete refresh, the STALENESS value of this view becomes FRESH. </li><li>NEEDS_COMPILE: Some objects on which the materialized view depends have changed. You must execute the ALTER MATERIALIZED VIEW...COMPILE statement to verify the materialized view and calculate its staleness. </li><li>STALE: The materialized view is outdated because one or more of its master objects have changed. If the materialized view was FRESH before it became STALE, then it is a read-consistent view of the previous state of its master objects. </li><li>UNDEFINED: The materialized view has a remote master. The concept of staleness is not defined for such materialized views. </li><li>UNKNOWN: Whether the materialized view is a read-consistent view of its master view at any point in time. </li><li>UNUSABLE: The materialized view is not a read-consistent view of its master view at any point in time. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |
| AFTER_FAST_REFRESH | VARCHAR2(19) | NO | The STALENESS value that appears when the fast refresh is applied to this materialized view. Its value is the same as that of the STALENESS column. If the value is NA, it indicates that this value is used when fast refresh is not applicable to the materialized view. <main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is NULL by default. </p></main> |
| UNKNOWN_PREBUILT | VARCHAR2(1) | NO | Indicates whether the materialized view is prebuilt.  <ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is N by default. </p></main> |
| UNKNOWN_PLSQL_FUNC | VARCHAR2(1) | NO | Indicates whether the materialized view contains PL/SQL functions.  <ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is N by default. </p></main> |
| UNKNOWN_EXTERNAL_TABLE | VARCHAR2(1) | NO | Indicates whether the materialized view contains external tables.  <ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only, and its value is N by default. </p></main> |
| UNKNOWN_CONSIDER_FRESH | VARCHAR2(1) | NO | Indicates whether the materialized view is considered fresh.<ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is N. </p></main> |

The default value is Y. </p></main> |

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_MVIEWS WHERE ROWNUM < = 1\G
```
