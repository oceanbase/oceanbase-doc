# DBA_MVIEWS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in MySQL 4.3.0.</p>
</main>

## Description

The `DBA_MVIEWS` view displays information about all materialized views in the database.

## Field description

| **Field name** | **Type** | **NULLable** | **Description** |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | YES | The name of the owner of the materialized view. |
| MVIEW_NAME | VARCHAR2(128) | YES | The name of the materialized view. |
| CONTAINER_NAME | VARCHAR2(128) | YES | The name of the container table of the materialized view. |
| QUERY | CLOB | NO | The query that defines the materialized view. |
| QUERY_LEN | NUMBER | NO | The length of the query, in bytes. |
| UPDATABLE | VARCHAR2(1) | NO | Indicates whether the materialized view is updatable. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| UPDATE_LOG | VARCHAR2(128) | NO | The name of the file that records update logs for updatable materialized views.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| MASTER_ROLLBACK_SEG | VARCHAR2(128) | NO | The rollback segment of the primary site or the primary materialized view site.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| MASTER_LINK | VARCHAR2(128) | NO | The database link of the primary site or the primary materialized view site.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| REWRITE_ENABLED | VARCHAR2(1) | NO | Specifies whether query rewriting is enabled for the materialized view. The options are: <ul><li>Y</li><li>N</li></ul> |
| REWRITE_CAPABILITY | VARCHAR2(9) | NO | Specifies whether the materialized view is eligible for query rewriting. If yes, the materialized view must follow the following rules: <ul><li>NONE: The materialized view cannot be used for query rewriting because it does not support or allow query rewriting. </li><li>TEXTMATCH: The materialized view's query contains restrictions on query rewriting. </li><li>GENERAL: The materialized view's definition query does not contain restrictions on query rewriting. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| REFRESH_MODE | VARCHAR2(6) | NO | The refresh mode of the materialized view. <ul><li>DEMAND: The materialized view is refreshed when a refresh process is called.  </li><li>NEVER: The materialized view is never refreshed. </li></ul>|
| REFRESH_METHOD | VARCHAR2(8) | NO | The default refresh method for refreshing the materialized view (can be overridden through APIs). <ul><li>COMPLETE: The complete refresh method.  </li><li>FORCE: The prefer incremental refresh method. If an incremental refresh cannot be performed, the complete refresh method is used. </li><li>FAST: The incremental refresh method. </li><li>NEVER: The materialized view is never refreshed. </li></ul>|
| BUILD_MODE | VARCHAR2(9) | NO | Specifies how the materialized view is populated during creation. The options are: <ul><li>IMMEDIATE: The materialized view is immediately populated during creation.  </li><li>DEFERRED: The materialized view is not populated during creation. </li><li>PREBUILT: The materialized view is populated during creation using existing tables. </li></ul>|
| FAST_REFRESHABLE | VARCHAR2(18) | NO | Specifies whether the materialized view is suitable for incremental (fast) refreshes. The options are: <ul><li>NO: The materialized view cannot be fast refreshed. Therefore, it is complex.  </li><li>DML: Only DML operations support fast refreshing. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| LAST_REFRESH_TYPE | VARCHAR2(8) | NO | The method used in the last refresh. <ul><li>COMPLETE: The complete refresh method.  </li><li>FAST: The incremental refresh method. </li><li>NA: The materialized view has not been refreshed. For example, the materialized view is in a delayed creation state. </li></ul>|
| LAST_REFRESH_DATE | DATE | YES | The date when the materialized view was last refreshed. |
| LAST_REFRESH_END_TIME | DATE | NO | The end time of the last refresh of the materialized view. |
| STALENESS | VARCHAR2(19) | NO | The relationship between the content of the materialized view and that of its master. <ul><li>FRESH: The materialized view is a read-consistent view of the current status of its primary object.  </li><li>IMPORT: The materialized view is imported from another database (UNKNOWN_IMPORT is set to Y). Therefore, it is unknown whether the materialized view is in a read-consistent state with its primary view at any point in time. After a complete refresh, the STALENESS of the view will change to FRESH. </li><li>NEEDS_COMPILE: Some objects on which the materialized view depends have been changed. The ALTER MATERIALIZED VIEW...COMPILE statement is needed to verify the materialized view and calculate its staleness. </li><li>STALE: The materialized view is out-of-date because one or more of its primary objects have been changed. If the materialized view becomes STALE without being FRESH, it is a read-consistent view of the previous status of its primary objects. </li><li>UNDEFINED: The materialized view has a remote primary controller. The concept of staleness is not defined for such a materialized view. </li><li>UNKNOWN: It is unknown whether the materialized view is in a read-consistent state with its primary view at any point in time. </li><li>UNUSABLE: The materialized view is not a read-consistent view of the primary view at any point in time. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| AFTER_FAST_REFRESH | VARCHAR2(19) | NO | The value that the STALENESS field will take after a fast refresh is applied to the materialized view. The options are the same as those for the STALENESS field. If the value is NA, the STALENESS field will be set to this value when fast refreshes are not applicable to the materialized view. <main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| UNKNOWN_PREBUILT | VARCHAR2(1) | NO | Specifies whether the materialized view is prebuilt. The options are: <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| UNKNOWN_PLSQL_FUNC | VARCHAR2(1) | NO | Specifies whether the materialized view contains a PL/SQL function. The options are: <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| UNKNOWN_EXTERNAL_TABLE | VARCHAR2(1) | NO | Specifies whether the materialized view contains an external table. The options are: <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| UNKNOWN_CONSIDER_FRESH | VARCHAR2(1) | NO | Specifies whether the materialized view is considered the latest. The options are: <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| UNKNOWN_IMPORT | VARCHAR2(1) | NO | Specifies whether the materialized view is imported. The options are: <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| UNKNOWN_TRUSTED_FD | VARCHAR2(1) | NO | Specifies whether the materialized view uses trusted constraints for refreshes. The options are: <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is N. </p></main> |
| COMPILE_STATE | VARCHAR2(19) | NO | The validity of the materialized view relative to the objects on which it depends. <ul><li>VALID: The materialized view has been verified, contains no errors, and the objects on which it depends have not changed since the last verification.  </li><li>NEEDS_COMPILE: Some objects on which the materialized view depends have been changed. A verification statement such as ALTER MATERIALIZED VIEW...COMPILE is needed to verify the materialized view. </li><li>ERROR: The materialized view has been verified and contains one or more errors. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| USE_NO_INDEX | VARCHAR2(1) | NO | Specifies whether the materialized view was created using the USING NO INDEX clause (Y) or the default index (N). The USING NO INDEX clause prohibits the creation of a default index. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is Y. </p></main> |
| STALE_SINCE | DATE | NO | The start time when the materialized view became out-of-date.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| NUM_PCT_TABLES | NUMBER | NO | The number of PCT base tables.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| NUM_FRESH_PCT_REGIONS | NUMBER | NO | The number of latest PCT partition or subpartition regions.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| NUM_STALE_PCT_REGIONS | NUMBER | NO | The number of out-of-date PCT partition or subpartition regions.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| SEGMENT_CREATED | VARCHAR2(3) | NO | Specifies whether the materialized view was created using the SEGMENT CREATION DEFERRED clause. The options are: <ul><li>YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NO. </p></main> |
| EVALUATION_EDITION | VARCHAR2(128) | NO | The version name of the version object referenced in the expression column of the materialized view.<main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| UNUSABLE_BEFORE | VARCHAR2(128) | NO | The name of the oldest version where the storage results of the subquery of the materialized view can be used for query rewriting. The storage results of the materialized view in versions earlier than the specified version are considered unavailable for query rewriting. If no such version is specified, the value of this field is NULL. <main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| UNUSABLE_BEGINNING | VARCHAR2(128) | NO | The name of the oldest version where the storage results of the subquery of the materialized view cannot be used for query rewriting. In versions from the specified version to its descendants, the data is unavailable for query rewriting. If no such version is specified, the value of this field is NULL. <main id="notice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| DEFAULT_COLLATION | VARCHAR2(100) | NO | The default sorting rule of the materialized view.<main idnotice" type='explain'> <h4>Note</h4><p>The field is compatible only and its default value is NULL. </p></main> |
| ON_QUERY_COMPUTATION | VARCHAR2(1) | NO | Specifies whether the materialized view is a real-time materialized view. The options are: <ul><li>Y</li><li>N</li></ul>|
