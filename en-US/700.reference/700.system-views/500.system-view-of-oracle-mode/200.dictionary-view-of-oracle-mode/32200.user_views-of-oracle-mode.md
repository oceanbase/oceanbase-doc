# USER_VIEWS

## Purpose

The USER_VIEWS view displays views that the current user owns.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_VIEWS

* DBA_VIEWS

## Columns

|    **Column**     |     **Type**     | **Nullable?** |                           **Description**                           |
|-----------------|----------------|----------------|------------------------------------------------------------|
| VIEW_NAME       | VARCHAR2(128)  | NO             | The name of the view.                                                       |
| TEXT_LENGTH     | NUMBER         | NO             | The length of the view definition.                                                     |
| TEXT            | VARCHAR2(4000) | NO             | The view definition.                                                       |
| OID_TEXT_LENGTH | NUMBER         | NO             | The OID length. Currently, this field is not supported and has a default value of NULL.              |
| OID_TEXT        | VARCHAR2(4000) | NO             | The OID value. Currently, this field is not supported and has a default value of NULL.                 |
| VIEW_TYPE       | VARCHAR2(30)   | NO             | The view type. Currently, this field is not supported and has a default value of NULL. |
| SUPERVIEW_NAME  | VARCHAR2(30)   | NO             | The name of the superview. Currently, this field is not supported and has a default value of NULL.                           |
| EDITIONING_VIEW | VARCHAR2(1)    | NO             | Indicates whether the view is an editioning view. Currently, this field is not supported and has a default value of NULL.                          |
| READ_ONLY       | VARCHAR2(1)    | NO             | Indicates whether the view is read-only. Currently, this field is not supported and has a default value of NULL.                          |
