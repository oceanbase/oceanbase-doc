# DBA_OB_TABLE_LOCATIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the locations of tables and partitions, including system tables, user tables, and index tables.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DATABASE_NAME | VARCHAR2(128) | NO | The name of the database. |
| TABLE_NAME | VARCHAR2(256) | NO | The name of the table. |
| TABLE_ID | NUMBER(38) | NO | The ID of the table. |
| TABLE_TYPE | VARCHAR2(13) | NO | The type of the table. Valid values: <ul><li>USER TABLE: user table</li><li>SYSTEM TABLE: system table that is automatically created</li><li>INDEX: index table</li><li>LOB AUX TABLE: LOB auxiliary table that is automatically created to assist in implementing LOB columns</li></ul> |
| PARTITION_NAME | VARCHAR2(64) | NO | The name of the partition. For non-partitioned tables, this column is NULL. |
| SUBPARTITION_NAME | VARCHAR2(64) | NO | The name of the subpartition. If no subpartition exists, this column is NULL. |
| INDEX_NAME | VARCHAR2(1024) | NO | The name of the index table. If the table is not an index table, this column is NULL. |
| DATA_TABLE_ID | NUMBER | NO | The ID of the primary table to which the index table or LOB auxiliary table belongs. If the table is not an index table or LOB auxiliary table, this column is NULL. |
| TABLET_ID | NUMBER(38) | NO | The tablet ID. |
| LS_ID | NUMBER | NO | The ID of the log stream to which the object belongs. |
| ZONE | VARCHAR2(128) | NO | The zone where the replica is located. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the replica. |
| SVR_PORT | NUMBER | NO | The port of the replica. |
| ROLE | VARCHAR2(8) | NO | The role of the replica. |
| REPLICA_TYPE | VARCHAR2(18) | NO | The type of the log stream replica. Valid values: <ul><li>`FULL`: full-featured replica</li><li>READONLY: read-only replica</li><li>`COLUMNSTORE`: columnstore replica</li></ul>  |
| DUPLICATE_SCOPE | VARCHAR2(7) | NO | Indicates whether the table is a replicated table. Valid values: <ul><li>`CLUSTER`: replicated table</li><li>`NONE`: regular table</li></ul><main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| DUPLICATE_READ_CONSISTENCY | varchar(6) | NO | Indicates the read consistency constraint of the standby replica of a replicated table. Valid values: <ul><li>`NONE`: indicates that the table is not a replicated table. This value is meaningless for non-replicated tables.</li><li>`STRONG`: indicates that the standby replica of a replicated table supports strong-consistency reads.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>|
| OBJECT_ID | NUMBER(38) | NO | The ID of the partition. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| TABLEGROUP_NAME | VARCHAR2(128) | NO | The name of the table group corresponding to the table. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| TABLEGROUP_ID | NUMBER(38) | NO | The ID of the table group corresponding to the table. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| SHARDING | VARCHAR2(20) | NO | The sharding attribute (evenly distributed mode) of the table group corresponding to the table. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| INDEX_TYPE                 | VARCHAR2(6)   | NO   | The `GLOBAL`/`LOCAL` attribute of the index of an index table. Valid values: <ul><li>`NULL`: indicates that the table is not an index table.</li><li>`GLOBAL`: indicates a global index, including `INDEX_TYPE_NORMAL_GLOBAL`, INDEX_TYPE_UNIQUE_GLOBAL, and `INDEX_TYPE_SPATIAL_GLOBAL`.</li><li>`LOCAL`: indicates a local index, including `INDEX_TYPE_NORMAL_LOCAL`, `INDEX_TYPE_UNIQUE_LOCAL`, `INDEX_TYPE_PRIMARY`, `INDEX_TYPE_DOMAIN_CTXCAT`, `INDEX_TYPE_NORMAL_GLOBAL_LOCAL_STORAGE`, `INDEX_TYPE_UNIQUE_GLOBAL_LOCAL_STORAGE`, `INDEX_TYPE_SPATIAL_LOCAL`, and `INDEX_TYPE_SPATIAL_GLOBAL_LOCAL_STORAGE`.</li></ul> <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x versions, this column is available starting with V4.4.1. </li> <li>For V4.2.5 versions, this column is available starting with V4.2.5 BP2. </li></ul></main>     |

## Sample query

Query the location of the `TEST1_TBL1` table.

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_NAME='TEST1_TBL1'\G
```
