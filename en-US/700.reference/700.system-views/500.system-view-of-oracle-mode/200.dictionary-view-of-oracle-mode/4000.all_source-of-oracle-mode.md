# ALL_SOURCE

## Purpose

The view displays the text source of the storage objects that the current user can access.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_SOURCE

* USER_SOURCE

## Columns

|   **Column**    |    **Type**    | **Nullable?** |      **Description**       |
|---------------|--------------|----------------|-------------------|
| OWNER         | VARCHAR2(30) | NO             | The owner of the object.          |
| NAME          | VARCHAR2(30) | NO             | The name of the object.               |
| TYPE          | VARCHAR2(12) | NO             | The type of the object.              |
| LINE          | NUMBER       | NO             | The line number in the source code corresponding to the TEXT field. |
| TEXT          | CLOB         | NO             | The source code of the current line.           |
| ORIGIN_CON_ID | NUMBER(38)   | NO             | This field is not supported. The field is set to NULL by default. |
