# DBA_OB_ARCHIVELOG

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the log archiving status on each path for the current tenant.

## Columns

| Column | Type | Nullable | Description |
| ------ | ------ | ------ | ------ |
| DEST_ID | NUMBER(38) | NO | The path identifier. |
| ROUND_ID | NUMBER(38) | NO | The backup round number. |
| INCARNATION | NUMBER(38) | NO | The number of incarnations after Flashback Database. |
| DEST_NO | NUMBER(38) | NO | The log_archive_dest_n identifier. |
| STATUS | VARCHAR2(64) | NO | The archiving status. Valid values: <ul><li>`PREPARE`: The archiving starts at `START_SCN`. </li> <li>`BEGINNING`: The log archiving is being started.  </li> <li>`DOING`: The log archiving is in progress. </li><li> `INTERRUPTED`: The log archiving is interrupted and requires manual intervention. </li><li>`STOP`: The log archiving is stopped.  </li><li>`STOPPING`: The log archiving is being stopped.  </li><li>`SUSPENDING`: The log archiving is being suspended.  </li><li>`SUSPEND`: The log archiving is suspended.  </li></ul>  |
| START_SCN | NUMBER(38) | NO | The start backup SCN. |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | The start backup SCN converted to a timestamp. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The current archiving SCN. |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | The current archiving SCN converted to a timestamp. |
| COMPATIBLE | NUMBER(38) | NO | The compatibility version. |
| BASE_PIECE_ID | NUMBER(38) | NO | The first PIECE ID of the current backup round. |
| USED_PIECE_ID | NUMBER(38) | NO | The PIECE IDs used in the current backup round. |
| PIECE_SWITCH_INTERVAL | NUMBER(38) | NO | The piece switching cycle. |
| UNIT_SIZE   | NUMBER(38)     | NO   | The size of a single log block for compression or encryption. This field is not supported. |
| COMPRESSION | VARCHAR2(128)  | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used. </li></ul> This field is not supported. |
| INPUT_BYTES | NUMBER | NO | The size of the data read. This field is not supported. |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the data read, converted to MB, GB, TB, or PB. This field is not supported. |
| OUTPUT_BYTES | NUMBER | NO | The size of the data output. This field is not supported. |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the data output, converted to MB, GB, TB, or PB. This field is not supported. |
| COMPRESSION_RATIO | NUMBER | NO | The compression ratio. This field is not supported. |
| DELETED_INPUT_BYTES | NUMBER(38) | NO | The size of the original data deleted. |
| DELETED_INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the original data deleted. |
| DELETED_OUTPUT_BYTES | NUMBER(38) | NO | The size of the effective data deleted. |
| DELETED_OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the effective data deleted. |
| COMMENT | VARCHAR2(262144) | NO | The error message. |
| PATH | VARCHAR2(2048) | NO | The archiving path. |
