# DBA_TYPE_METHODS

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view is not supported by OceanBase Database. </p>
  </main>

## Purpose

This view displays the methods of object types in the current tenant.

## Columns

|   **Column**   |    **Type**    | **Nullable** |                                                                                 **Description**                                                                                  |
|--------------|--------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER        | VARCHAR2(30) | NO             | The owner of the type.                                                                               |
| TYPE_NAME    | VARCHAR2(30) | NO             | The name of the type.                                                                                |
| METHOD_NAME  | VARCHAR2(30) | NO             | The name of the method.                                                                                |
| METHOD_NO    | NUMBER       | NO             | The method number, which is used to distinguish overloaded methods.                                                                        |
| METHOD_TYPE  | VARCHAR2(6)  | NO             | The method type. Valid values: <ul><li>MAP   </li><li> ORDER   </li><li> PUBLIC</li></ul>    |
| PARAMETERS   | NUMBER       | NO             | The number of method parameters.          |
| RESULTS      | NUMBER       | NO             | The number of method return values.     |
| FINAL        | VARCHAR2(3)  | NO             | YES indicates that the method is a final method. <ul><li>YES</li><li>NO</li></ul>       |
| INSTANTIABLE | VARCHAR2(3)  | NO             | YES indicates that the method can be instantiated. <ul><li>YES</li><li>NO</li></ul>       |
| OVERRIDING   | VARCHAR2(3)  | NO             | YES indicates that the method overrides a method of a supertype. <ul><li>YES</li><li>NO</li></ul>     |
| INHERITED    | VARCHAR2(3)  | NO             | YES indicates that the method is inherited from a supertype. <ul><li>YES</li><li>NO</li></ul>     |
