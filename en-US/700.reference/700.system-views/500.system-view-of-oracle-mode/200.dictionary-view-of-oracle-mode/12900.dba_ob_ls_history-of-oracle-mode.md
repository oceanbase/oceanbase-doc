# DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log streams that existed in the current tenant in the past.

## Columns

| Column        | Type           | Nullable | Description                                       |
|-------------|---------------|-------------|-------------------------------------------|
| LS_ID       | NUMBER        | NO          |  The ID of the log stream.                                 |
| LS_GROUP_ID | NUMBER        | NO          |  The ID of the log stream group.                               |
| STATUS      | VARCHAR2(100) | NO          |  The status of the log stream:<ul><li>CREATING: The log stream is being created.</li><li>NORMAL: The log stream is in the normal state.</li><li>DROPPING: The log stream is being dropped.</li><li>PRE_TENANT_DROPPING: A special state of the system log stream, indicating that all log streams under the tenant are being dropped.</li><li>TENANT_DROPPING: The tenant is being dropped, and the log stream is being dropped.</li><li>DROPPED: The log stream has been dropped or is being dropped.</li><li>WAIT_OFFLINE: The log stream is waiting to be dropped.</li><li>CREATE_ABORT: The creation of the log stream has been aborted.</li></ul>        |
| FLAG        | VARCHAR2(2048)| NO          |  The flag of the log stream:<ul><li>Empty: The log stream is in the normal state.</li><li> DUPLICATE: The broadcast log stream of a user tenant. A replicated table is created in this log stream. </li><li>BLOCK_TABLET_IN: Indicates that a tablet cannot be created in this log stream. </li></ul>                        |
| CREATE_SCN  | NUMBER        | NO          |  The GTS of the log stream when it was created, in nanoseconds.              |

## Sample query

Query the log streams that existed in the current user tenant in the past.

```sshell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_HISTORY;
```

The query result is as follows:

```shell
+-------+-------------+--------+------+---------------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN          |
+-------+-------------+--------+------+---------------------+
|     1 |           0 | NORMAL | NULL |                   0 |
|  1001 |        1001 | NORMAL | NULL | 1736152507462028000 |
+-------+-------------+--------+------+---------------------+
2 rows in set
```
