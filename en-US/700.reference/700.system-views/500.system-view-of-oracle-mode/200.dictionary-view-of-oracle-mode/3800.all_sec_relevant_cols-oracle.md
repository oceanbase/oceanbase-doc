# ALL_SEC_RELEVANT_COLS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays information about all columns associated with policies in tables or views accessible to the current user. When a column is associated with a column-level policy, the corresponding policy is applied when the column is accessed.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | The owner of the object controlled by the policy. |
| OBJECT_NAME | VARCHAR2(128) | YES | The name of the object controlled by the policy. |
| POLICY_GROUP | VARCHAR2(128) | NO | The name of the policy group. |
| POLICY_NAME | VARCHAR2(128) | NO | The name of the policy. |
| SEC_REL_COLUMN | VARCHAR2(128) | YES | The name of the column associated with the column-level policy. |
| COLUMN_OPTION | VARCHAR2(8) | NO | The policy option:<ul><li> NONE </li><li> ALL_ROWS </li></ul>|
| COMMON | VARCHAR2(3) | NO | For compatibility only. The value is fixed to NO. |
| INHERITED | VARCHAR2(3) | NO | For compatibility only. The value is fixed to NO. |

## Sample query

Query information about all columns associated with policies in tables or views accessible to the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_SEC_RELEVANT_COLS;
```

The query result is as follows:

```shell
+--------------+----------------+--------------+----------------+----------------+---------------+--------+-----------+
| OBJECT_OWNER | OBJECT_NAME    | POLICY_GROUP | POLICY_NAME    | SEC_REL_COLUMN | COLUMN_OPTION | COMMON | INHERITED |
+--------------+----------------+--------------+----------------+----------------+---------------+--------+-----------+
| SYS          | V_SALES_SECURE | GROUP_SALES  | POLICY_REGION  | AMOUNT         | NONE          | NO     | NO        |
| SYS          | V_ORDERS_CTX   | GROUP_REGION | POLICY_DYNAMIC | AMOUNT         | NONE          | NO     | NO        |
+--------------+----------------+--------------+----------------+----------------+---------------+--------+-----------+
2 rows in set
```
