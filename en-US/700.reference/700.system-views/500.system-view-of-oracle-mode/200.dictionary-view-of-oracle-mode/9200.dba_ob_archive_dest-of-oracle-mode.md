# DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the archive path configuration of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_NO | NUMBER(38) | NO | Identifies log_archive_dest_n. |
| NAME | VARCHAR2(1024) | NO | The column name. |
| VALUE | VARCHAR2(4096) | NO | The column value. |

## Sample query

Query the archive path configuration of the current user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_ARCHIVE_DEST;
```

The query result is as follows:

```shell
+---------+-----------------------+----------------------------------------+
| DEST_NO | NAME                  | VALUE                                  |

5 rows in set
```
