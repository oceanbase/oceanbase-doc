# DBA_OB_ROUTINE_LOAD_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `DBA_OB_ROUTINE_LOAD_JOBS` view is used to retrieve information about Routine Load tasks in the current tenant.

## Columns

|    Column     |                Type               | Nullable |    Description     |
|----------------|-----------------------------------|------|-----------------------|
| JOB_ID         | NUMBER(38)                        | NO   | The job ID.|
| JOB_NAME       | VARCHAR2(128)                     | NO   | The job name.|
| CREATE_TIME    | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The job creation time.|
| PAUSE_TIME     | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | The job pause time.|
| END_TIME       | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | The job end time.|
| DATABASE_NAME  | VARCHAR2(128)                     | YES  | The name of the database corresponding to the target table.|
| DATABASE_ID    | NUMBER(38)                        | NO   | The ID of the database corresponding to the target table.|
| TABLE_NAME     | VARCHAR2(256)                     | YES  | The name of the target table.|
| TABLE_ID       | NUMBER(38)                        | NO   | The ID of the target table.|
| STATE          | VARCHAR2(16)                      | NO   | The job status. Valid values: <ul><li>`RUNNING`: The job is running.</li><li>`PAUSED`: The job is paused and can be resumed.</li><li>`STOPPED`: The job is stopped or has ended and cannot be resumed.</li><li>`CANCELLED`: The job is canceled (due to a failure). </li></ul>|
| JOB_PROPERTIES | VARBINARY(1048576)                | NO   | The job configuration attributes in JSON format.|
| PROGRESS       | VARBINARY(1048576)                | YES  | The consumption progress information in JSON format.|
| LAG            | VARBINARY(1048576)                | YES  | The consumption lag information in JSON format.|
| TMP_PROGRESS   | VARBINARY(1048576)                | YES  | The temporary progress information for the intermediate state before transaction commit.|
| TMP_LAG        | VARBINARY(1048576)                | YES  | The temporary lag information.|
| LAST_TRACE_ID  | VARCHAR2(64)                      | YES  | The trace ID of the last operation, used for troubleshooting.|
| LAST_RET_CODE  | NUMBER(38)                        | YES  | The error code of the last execution. 0 indicates success.|
| LAST_ERROR_MSG | VARCHAR2(512)                     | YES  | The detailed information about the job execution failure.|
