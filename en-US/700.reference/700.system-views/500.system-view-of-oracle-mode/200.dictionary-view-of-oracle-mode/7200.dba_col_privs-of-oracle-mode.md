# DBA_COL_PRIVS

## Purpose

This view describes the column privileges granted in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|  **Column**   |    **Type**     | **Nullable** |    **Description**     |
|-------------|---------------|----------------|---------------|
| GRANTEE     | VARCHAR2(128) | NO             | The name of the user who is granted the privilege. |
| OWNER       | VARCHAR2(128) | NO             | The owner of the object.        |
| TABLE_NAME  | VARCHAR2(256) | NO             | The name of the object.         |
| COLUMN_NAME | VARCHAR2(128) | NO             | The name of the column.          |
| GRANTOR     | VARCHAR2(128) | NO             | The name of the user who executes the grant operation.    |
| PRIVILEGE   | VARCHAR2(40)  | NO             | The privilege on the column.         |
| GRANTABLE   | VARCHAR2(3)   | NO             | Indicates whether the grant option is used.    |
