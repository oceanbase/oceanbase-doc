# USER_SOURCE

## Purpose

The view displays the text source of the stored objects owned by the user. The columns are the same as those in the `ALL_SOURCE` view, except for the `OWNER` column.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_SOURCE

* ALL_SOURCE

## Columns

|   **Column**    |    **Type**    | **Nullable?** |         **Description**          |
|---------------|--------------|----------------|-------------------------|
| NAME          | VARCHAR2(30) | NO             | Name of the object                     |
| TYPE          | VARCHAR2(12) | NO             | Type of the object                    |
| LINE          | NUMBER       | NO             | Line number in the source code of the TEXT field       |
| TEXT          | CLOB         | NO             | Source code of the current row                 |
| ORIGIN_CON_ID | NUMBER(38)   | NO             | This field is currently not supported and defaults to NULL |
