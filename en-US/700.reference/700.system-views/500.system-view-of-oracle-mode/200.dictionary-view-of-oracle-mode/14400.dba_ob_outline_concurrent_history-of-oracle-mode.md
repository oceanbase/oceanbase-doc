# DBA_OB_OUTLINE_CONCURRENT_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the outline history of the current tenant, including the execution plans and throttling rules.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| CREATE_TIME | TIMESTAMP(6) | NO | The timestamp when the outline was created. |
| MODIFY_TIME | TIMESTAMP(6) | NO | The timestamp when the outline was last modified. |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| DATABASE_ID | NUMBER(38) | YES | The database ID. |
| OUTLINE_ID | NUMBER(38) | NO | The outline ID. |
| OUTLINE_NAME | VARCHAR2(128) | YES | The outline name. |
| SQL_TEXT | CLOB | YES | The SQL statement specified in the ON clause when the outline was created. |
| OUTLINE_PARAMS | VARBINARY(65536) | YES | The throttling rule parameters specified when the outline was created. |
| OUTLINE_TARGET | CLOB | YES | The SQL statement specified in the TO clause when the outline was created. |
| SQL_ID | VARCHAR2(32) | YES | The SQL identifier. |
| OUTLINE_CONTENT | CLOB | YES | The complete outline information. |
| IS_DELETED | VARCHAR2(3) | NO | Indicates whether the outline is deleted. |
| ENABLED | VARCHAR2(3) | NO | Indicates whether the outline is enabled. |

## Sample query

Query the outline history of the current tenant, including the execution plans and throttling rules.

obclient [SYS]> SELECT * FROM SYS.DBA_OB_OUTLINE_CONCURRENT_HISTORY\G
