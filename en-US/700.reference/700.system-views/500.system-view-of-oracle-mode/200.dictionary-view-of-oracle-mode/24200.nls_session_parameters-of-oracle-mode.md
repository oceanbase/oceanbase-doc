# NLS_SESSION_PARAMETERS

## Purpose

The view displays the NLS parameters at the session level.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* NLS_INSTANCE_PARAMETERS

* NLS_DATABASE_PARAMETERS

* V$NLS_PARAMETERS

## Columns

| **Column**  |     **Type**      | **Nullable?** | **Description** |
|-----------|-----------------|----------------|--------|
| PARAMETER | VARCHAR2(128)   | NO             | The name of the parameter.   |
| VALUE     | VARCHAR2(65536) | YES            | The value of the parameter.   |

## Sample query

```sql
obclient> SELECT * FROM SYS.NLS_SESSION_PARAMETERS;
```
