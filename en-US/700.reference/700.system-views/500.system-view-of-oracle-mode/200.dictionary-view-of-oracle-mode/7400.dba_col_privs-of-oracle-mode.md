# DBA_COL_PRIVS

## Purpose

Describes all column objects granted in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_COL_PRIVS

## Columns

|  **Column**   |    **Type**     | **Nullable?** |    **Description**     |
|-------------|---------------|----------------|---------------|
| GRANTEE     | VARCHAR2(128) | NO             | The name of the user to whom access is granted. |
| OWNER       | VARCHAR2(128) | NO             | The owner of the object.        |
| TABLE_NAME  | VARCHAR2(256) | NO             | The name of the object.         |
| COLUMN_NAME | VARCHAR2(128) | NO             | The name of the column.          |
| GRANTOR     | VARCHAR2(128) | NO             | The name of the user who granted the privilege.    |
| PRIVILEGE   | VARCHAR2(40)  | NO             | The privilege granted on the column.         |
| GRANTABLE   | VARCHAR2(3)   | NO             | Indicates whether the GRANT OPTION is granted. |
