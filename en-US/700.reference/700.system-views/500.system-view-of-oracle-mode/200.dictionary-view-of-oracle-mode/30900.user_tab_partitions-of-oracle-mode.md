# USER_TAB_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays the partition information of all partitioned tables owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle-compatible mode. </p>
  </main>

## Sample query

Query the primary partition information of the `TBL2_F_RL` table in all partitioned tables owned by the current user.

```shell
obclient [SYS]> SELECT TABLE_NAME, COMPOSITE, PARTITION_NAME, SUBPARTITION_COUNT, HIGH_VALUE_LENGTH, PARTITION_POSITION
   FROM SYS.USER_TAB_PARTITIONS
   WHERE TABLE_NAME='TBL2_F_RL';
```

The query result is as follows:

```shell
+------------+-----------+----------------+--------------------+-------------------+--------------------+
| TABLE_NAME | COMPOSITE | PARTITION_NAME | SUBPARTITION_COUNT | HIGH_VALUE_LENGTH | PARTITION_POSITION |
+------------+-----------+----------------+--------------------+-------------------+--------------------+
| TBL2_F_RL  | YES       | P0             |                  3 |                 3 |                  1 |
| TBL2_F_RL  | YES       | P1             |                  3 |                 3 |                  2 |
+------------+-----------+----------------+--------------------+-------------------+--------------------+
2 rows in set
```
