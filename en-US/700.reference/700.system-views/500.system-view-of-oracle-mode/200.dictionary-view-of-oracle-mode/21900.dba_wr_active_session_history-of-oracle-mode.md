# DBA_WR_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the ASH data that is persisted for the current tenant.

## Columns

| --- | --- | --- | --- |
| CLUSTER_ID | NUMBER(38) | NO | The cluster ID. |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| SNAP_ID | NUMBER(38) | NO | The snapshot ID. |

| SVR_PORT | NUMBER(38) | NO | The port number of the node. |
| SAMPLE_ID | NUMBER(38) | NO | The sample ID. |

| IN_SEQUENCE_LOAD | VARCHAR2(1) | NO | Indicates whether the current session is retrieving values from an auto-increment column or a sequence at the time of sampling. |

| PROGRAM                     | VARCHAR2(64)                      | YES  | The name of the program being executed at the sampling point:<ul><li>Background thread: the name of the thread, such as `observer` or `WrTimer`.  </li><li>Foreground thread:<ul><li>For a regular request, the format is `user@client_ip (thread_name)`.  </li><li>For `inner_sql` remote execution, the format is `INNER SQL REMOTE EXEC (thread_name)`.  </li><li>For DAS remote execution, the format is `DAS REMOTE EXEC (thread_name)`.  </li></ul> </li></ul><main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.2. </p></main>  |
