# DBA_AUDIT_OBJECT

## Purpose

This view displays the audit tracking entries of all objects in the current tenant.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode of OceanBase Database. </p>
  </main>

## Sample query

Query the audit trail entries of all objects in the current tenant.

```shell
obclient [SYS]> SELECT USERNAME, USERHOST, TIMESTAMP, ACTION_NAME, SQL_TEXT FROM SYS.DBA_AUDIT_OBJECT;
```

The query result is as follows:

```shell

| USERNAME   | USERHOST       | TIMESTAMP | ACTION_NAME | SQL_TEXT                           |

| TEST2      | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
```
