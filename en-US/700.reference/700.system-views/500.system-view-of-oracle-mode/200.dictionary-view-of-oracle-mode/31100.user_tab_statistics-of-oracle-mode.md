# USER_TAB_STATISTICS

## Purpose

Displays optimizer statistics for all tables of the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TAB_STATISTICS

* DBA_TAB_STATISTICS
