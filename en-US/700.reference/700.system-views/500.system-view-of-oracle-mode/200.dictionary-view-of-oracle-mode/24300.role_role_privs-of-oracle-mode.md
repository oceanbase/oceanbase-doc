# ROLE_ROLE_PRIVS

## Purpose

Describes the roles granted to other roles. This view provides information about the roles that a user can access.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**   |    **Type**     | **Nullable?** |       **Description**       |
|--------------|---------------|------------|--------------------|
| ROLE         | VARCHAR2(128) | NO         | The name of the role.               |
| GRANTED_ROLE | VARCHAR2(128) | NO         | The name of the role granted.              |
| ADMIN_OPTION | VARCHAR2(3)   | NO         | Indicates whether the role has been granted the ADMIN option. |
