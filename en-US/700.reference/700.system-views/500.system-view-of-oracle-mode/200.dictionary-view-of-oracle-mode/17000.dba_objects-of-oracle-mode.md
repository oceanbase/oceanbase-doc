# DBA_OBJECTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

The `DBA_OBJECTS` view displays all database objects.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is applicable only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   Column  |    Type  | Nullable |     Description |
|-------------------|---------------|------------|-------------|
| OWNER             | VARCHAR2(128) | NO         | The owner of the object.                                     |
| OBJECT_NAME       | VARCHAR2(128) | NO         | The name of the object.                                         |
| SUBOBJECT_NAME    | VARCHAR2(128) | NO         | The name of the subobject (for example, partition).                          |
| OBJECT_ID         | NUMBER        | NO         | The dictionary ID value of the object.                                   |
| DATA_OBJECT_ID    | NUMBER        | NO         | The dictionary ID value of the segment that contains the object.                        |
| OBJECT_TYPE       | VARCHAR2(23)  | NO         | The type of the object. Valid values: TABLE, INDEX, PARTITION, PACKAGE, STORED PROCEDURE, SYNONYM, and SEQUENCE.                |
| CREATED           | DATE          | NO         | The creation time of the object.                                       |
| LAST_DDL_TIME     | DATE          | NO         | The last DDL time of the object.                                |
| TIMESTAMP         | VARCHAR2(19)  | NO         | The timestamp of the object, in character format.                             |
| STATUS            | VARCHAR2(7)   | NO         | The status of the object. Valid values: <ul><li>VALID: valid</li><li> INVALID: invalid </li></ul>   |
| TEMPORARY         | VARCHAR2(1)   | NO         | Indicates whether the object is a temporary object.                                 |
| GENERATED         | VARCHAR2(1)   | NO         | Indicates whether the name of the object is generated by the system.                             |
| SECONDARY         | VARCHAR2(1)   | NO         | This column is not currently used.                                    |
| NAMESPACE         | NUMBER        | NO         | The namespace of the object.                                      |
| EDITION_NAME      | VARCHAR2(128) | NO         | Reserved.                                         |
| SHARING           | VARCHAR2(18)  | NO         | `NULL` by default               |
| EDITIONABLE       | VARCHAR2(1)   | NO         | `NULL` by default  |
| ORACLE_MAINTAINED | VARCHAR2(1)   | NO         | `NULL` by default                            |
| APPLICATION       | VARCHAR2(1)   | NO         | `NULL` by default                        |
| DEFAULT_COLLATION | VARCHAR2(1)   | NO         | `NULL` by default            |
| DUPLICATED        | VARCHAR2(1)   | NO         | `NULL` by default        |
| SHARDED           | VARCHAR2(1)   | NO         | `NULL` by default                             |
| IMPORTED_OBJECT   | VARCHAR2(1)   | NO         | `NULL` by default                             |
| CREATED_APPID     | NUMBER    | NO         | `NULL` by default     |
| CREATED_VSNID     | NUMBER    | NO         | `NULL` by default            |
| MODIFIED_APPID    | NUMBER    | NO         | `NULL` by default      |
| MODIFIED_VSNID    | NUMBER    | NO          | `NULL` by default        |

## Sample query

Query all database objects in the current tenant and display the first two records.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OBJECTS WHERE ROWNUM <= 2;
```
