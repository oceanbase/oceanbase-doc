# ALL_LOCATIONS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.4.0.</p>
</main>

## Overview

`ALL_LOCATIONS` is used to view the External Location object information of the current tenant.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This view is applicable only to the Oracle-compatible mode of OceanBase Database. </p>
</main>

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------------- | ---------------- | ---------------- | -------------------------------------------------------------------- |
| OWNER | VARCHAR2(128) | NO | Owner |
| LOCATION_NAME | VARCHAR2(128) | YES | Name |
| LOCATION_URL | VARCHAR2(4000) | YES | Path |
| ORIGIN_CON_ID | NUMBER(38) | NO | Tenant ID |
| ACCESS_INFO | VARCHAR2(8000) | YES | Access Information |
| --------------- | ---------------- | ------ | ------ |

## Sample query

Query the External Location object information of the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_LOCATIONS ;
```
