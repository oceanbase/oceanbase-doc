# DBA_OB_BACKUP_STORAGE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about backup destinations used for backup and restore in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| PATH | VARCHAR2(1024) | NO | The root path for backup. |
| ENDPOINT | VARCHAR2(256) | NO | The host for accessing the object storage. |
| DEST_ID | NUMBER(38) | YES | The ID of the backup destination. |
| DEST_TYPE | VARCHAR2(64) | YES | The type of the backup destination. Valid values: <ul><li>`archive_log`: log archiving</li> <li>`backup_data`: data backup</li></ul> |
| AUTHORIZATION | VARCHAR2(1024) | NO | The authorization information for the object storage. |
| EXTENSION | VARCHAR2(512) | NO | The other parameters of the backup destination. |
| CHECK_FILE_NAME | VARCHAR2(256) | YES | The name of the file for checking connectivity. |
| LAST_CHECK_TIMESTAMP | VARCHAR2(256) | NO | The timestamp of the last successful connectivity check. |
| MAX_IOPS             | NUMBER(38)   | NO | The maximum IOPS allowed for the backup medium used for backup. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.5. </p></main>    |
| MAX_BANDWIDTH        | NUMBER(38)   | NO | The maximum bandwidth allowed for the backup medium used for backup, in bytes. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.5. </p></main>      |
| MAX_BANDWIDTH_DISPLAY| VARCHAR2(44) | NO | The display format of the maximum bandwidth. The format is similar to 10GB/s or 10MB/s. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.5. </p></main>      |
| STATUS               |  VARCHAR2(64)   | YES | <ul><li>`DELETING`: indicates that the path is being deleted.</li><li>`NORMAL`: indicates that the path is normal.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1 for V4.4.x. </p></main>   |

## Sample query

Query information about backup destinations used for backup and restore in the user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_STORAGE_INFO;
```
