# NLS_DATABASE_PARAMETERS

## Purpose

Displays the NLS parameters at the database level (tenant level in OceanBase Database).

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* NLS_INSTANCE_PARAMETERS

* NLS_SESSION_PARAMETERS

* V$NLS_PARAMETERS

## Columns

| **Column** |     **Type**      | **Nullable?** | **Description** |
|-----------|-----------------|----------------|--------|
| PARAMETER | VARCHAR2(128)   | NO             | Parameter name   |
| VALUE     | VARCHAR2(65536) | YES            | Parameter value   |
