# USER_IND_EXPRESSIONS

## Purpose

Displays information about function-based indexes that the user owns in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_IND_EXPRESSIONS

* ALL_IND_EXPRESSIONS

## Columns

|     **Column**      |     **Type**     | **Nullable?** |        **Description**        |
|-------------------|----------------|----------------|----------------------|
| INDEX_NAME        | VARCHAR2(128)  | NO             | The name of the index.                 |
| TABLE_NAME        | VARCHAR2(128)  | NO             | The name of the table where the index resides.             |
| COLUMN_EXPRESSION | VARCHAR2(1000) | NO             | The expression of the function-based index. |
| COLUMN_POSITION   | NUMBER(38)     | NO             | The position of the column in the index.             |
