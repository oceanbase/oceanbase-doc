# USER_TAB_COLUMNS

## Purpose

The view displays all columns of the tables and views that belong to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TAB_COLUMNS

* DBA_TAB_COLUMNS
