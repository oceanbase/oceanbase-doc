# DBA_OB_BACKUP_DELETE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the execution progress of the backup cleanup job for the current tenant.

## Columns

| Field Name | Type | Nullable | Description |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | Task ID, which is monotonically increasing. |
| INCARNATION | NUMBER(38) | NO | Avatar ID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | Tenant ID that initiated the job |
| INITIATOR_JOB_ID | NUMBER(38) | NO | The tenant ID of the job initiator.
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | List of Tenants for Which the Cleanup Task Is to Be Performed |
| TYPE | VARCHAR2(64) | NO | Cleanup type:<ul><li>`DELETE OBSOLETE BACKUP`: Purge expired data</li> <li>`DELETE BACKUP ALL`: Clear all backup or archive data in the path.</li> <li>`DELETE BACKUPSET`: Clean up the specified data backup set.</li> <li>`DELETE ARCHIVELOG_PIECE`: Clean up the specified log archive piece. </li> <li>`DELETE BACKED UP ARCHIVELOG PIECE`: with`DELETE INPUT`<li>Clean up source log archive pieces initiated by the archived log backup option.</li></ul></br>For V4.4.x versions,`DELETE BACKED UP ARCHIVELOG PIECE`Introduced in V4.4.2 BP3. |
| PARAMETER | VARCHAR2(1024) | NO | Cleanup parameters, describing the specific parameter information for different cleanup types |
| JOB_LEVEL | VARCHAR2(64) | NO | Task Initiation Level: <ul><li>`USER_TENANT`: User tenant initiated task</li><li>`SYS_TENANT`: Tasks initiated by the system tenant.</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | Current Tenant Time at Task Start |
| END_TIMESTAMP | VARCHAR2(256) | NO | Current Tenant Time at Task End |
| STATUS | VARCHAR2(64) | NO | Task status: <ul><li>`INIT`: Task initialization phase </li><li>`DOING`: Task execution phase </li><li>`CANCELING`: The task is canceled. </li><li>`COMPLETED`: Task executed successfully. </li><li>`FAILED`: Task execution failed. </li><li>`CANCELED`: The task has been successfully canceled. </li></ul> |
| TASK_COUNT | NUMBER(38) | YES | Number of backup_set/piece Tasks |
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | Number of Successful Tasks for backup_set/piece |
| RESULT | NUMBER(38) | NO | Error Code |
| COMMENT | VARCHAR2(4096) | YES | Task Execution Instructions |

## Sample query

You can query the execution progress of backup cleanup jobs for the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOBS\G
```
