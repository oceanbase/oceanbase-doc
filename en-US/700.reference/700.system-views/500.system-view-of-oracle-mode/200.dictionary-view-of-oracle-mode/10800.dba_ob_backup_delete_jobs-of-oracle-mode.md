# DBA_OB_BACKUP_DELETE_JOBS

<main id="notice" type='explain'>
<h4>NOTES</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the execution progress of backup cleanup jobs in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| Column | Type | Nullable | Description | | --- | --- | --- | --- | | JOB_ID | NUMBER(38) | NO | Task ID, which is incrementally generated. |
| INCARNATION | NUMBER(38) | NO | Split ID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | The ID of the initiator's tenant. |
| INITIATOR_JOB_ID | NUMBER(38) | NO | the tenant initiating the job | </think>  | INITIATOR_JOB_ID | NUMBER(38) | NO | the tenant initiating the job |
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | The list of tenants that execute cleanup tasks. |
| Column | Type | Nullable | Description | | --- | --- | --- | --- | | TYPE | VARCHAR2(64) | NO | Type of the backup set to be cleaned. Valid values: <ul><li>`DELETE OBSOLETE BACKUP`: Clean up expired backup sets.</li> <li>`DELETE BACKUP ALL`: Clean up all backups and archive logs in the specified path.</li> <li>`DELETE BACKUPSET`: Clean up the specified data backup set.</li> <li>`DELETE ARCHIVELOG_PIECE`: Clean up the specified archive log piece.</li></ul> |
| PARAMETER | VARCHAR2(1024) | NO | This column stores the parameter information of different cleaning types. |
| JOB_LEVEL | VARCHAR2(64) | NO | Task initiation level:<ul><li>`USER_TENANT`: a task initiated by a user tenant</li><li>`SYS_TENANT`: a task initiated by a system tenant</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | The current tenant time when the task starts. |
| END_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task is completed. |
| STATUS | VARCHAR2(64) | NO | The task status. Valid values: `INIT`, `DOING`, `CANCELING`, `COMPLETED`, `FAILED`, and `CANCELED`. <ul><li>`INIT`: the task is initializing. </li><li>`DOING`: the task is being executed. </li><li>`CANCELING`: the task is being canceled. </li><li>`COMPLETED`: the task is successfully executed. </li><li>`FAILED`: the task execution failed. </li><li>`CANCELED`: the task is successfully canceled. </li></ul>  |
|TASK_COUNT | NUMBER(38) | YES | the number of backup set/piece tasks|
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | backup_set/piece Successful tasks |
| RESULT | NUMBER(38) | NO | Error code |
| COMMENT | VARCHAR2(4096) | YES | Task execution description |

## Sample query

A user tenant can query the execution progress of a backup cleanup job task in its own user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOBS\G
```
