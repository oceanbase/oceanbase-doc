# ALL_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

This view displays all tables accessible to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Sample query

Query the information about the `TBL1` table in the tables accessible to the current user.

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, STATUS, PCT_FREE, TEMPORARY, NESTED, ROW_MOVEMENT, DROPPED, EXTERNAL FROM SYS.ALL_TABLES WHERE TABLE_NAME = 'TBL1';
```

The query result is as follows:

```shell
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
| OWNER | TABLE_NAME | STATUS | PCT_FREE | TEMPORARY | NESTED | ROW_MOVEMENT | DROPPED | EXTERNAL |
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
| SYS   | TBL1       | VALID  |        0 | N         | NO     | NO           | NO      | NO       |
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
1 row in set
```
