# ALL_TABLES

## Purpose

Displays all tables that the user can access.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_TABLES

* USER_TABLES
