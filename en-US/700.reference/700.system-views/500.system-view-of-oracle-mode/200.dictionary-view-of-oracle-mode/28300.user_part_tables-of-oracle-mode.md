# USER_PART_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays the partition information of all partitioned tables that the current user owns.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle-compatible mode. </p>
  </main>

## Columns
