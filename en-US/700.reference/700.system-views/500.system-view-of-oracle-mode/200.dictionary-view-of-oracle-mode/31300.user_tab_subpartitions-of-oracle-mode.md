# USER_TAB_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays the subpartition names, table names, partition names, and storage attributes of subpartitions for all tables accessible to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Sample query

Query the subpartition information of the `TBL2_F_RL` table in the partitioned tables owned by the current user.

```shell
obclient [SYS]> SELECT TABLE_NAME, PARTITION_NAME, SUBPARTITION_NAME, HIGH_VALUE, HIGH_VALUE_LENGTH, PARTITION_POSITION, SUBPARTITION_POSITION
   FROM SYS.USER_TAB_SUBPARTITIONS
   WHERE TABLE_NAME='TBL2_F_RL';
```
