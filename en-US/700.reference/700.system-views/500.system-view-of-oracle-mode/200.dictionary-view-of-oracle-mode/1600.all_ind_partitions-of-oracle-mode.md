# ALL_IND_PARTITIONS

## Purpose

This view displays information about index partitions in databases accessible to the user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>
