# TENANT_VIRTUAL_SESSION_VARIABLE

## Purpose

This view displays the session variables.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**    |     **Type**      | **Nullable?** |   **Description**    |
|---------------|-----------------|----------------|-------------|
| VARIABLE_NAME | VARCHAR2(128)   | NO             | Session variable name |
| VALUE         | VARCHAR2(65536) | YES            | Session variable value |
