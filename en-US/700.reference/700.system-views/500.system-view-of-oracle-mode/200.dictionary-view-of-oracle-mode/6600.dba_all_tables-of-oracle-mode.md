# DBA_ALL_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

This view displays all object tables and relational tables in the current tenant. The columns of this view are the same as those of `ALL_ALL_TABLES`.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Sample query

Query the `T_SUBPART` table.

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, STATUS, PCT_FREE, NUM_ROWS, PARTITIONED, TEMPORARY, ROW_MOVEMENT, DROPPED, EXTERNAL FROM SYS.DBA_ALL_TABLES WHERE TABLE_NAME='T_SUBPART';
```

The query result is as follows:

```shell
+-------+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
| OWNER | TABLE_NAME | STATUS | PCT_FREE | NUM_ROWS | PARTITIONED | TEMPORARY | ROW_MOVEMENT | DROPPED | EXTERNAL |
+-------+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
| SYS   | T_SUBPART  | VALID  |        0 |     1000 | YES         | N         | NO           | NO      | NO       |
+-------+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
1 row in set
```
