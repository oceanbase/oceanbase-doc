# DBA_DIRECTORIES

## Purpose

Displays all directories that the current user can access.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

ALL_DIRECTORIES

## Columns

|    **Column**    |     **Type**     | **Nullable?** |   **Description**    |
|----------------|----------------|----------------|-------------|
| OWNER          | VARCHAR2(128)  | NO             | The owner of the directory. |
| DIRECTORY_NAME | VARCHAR2(128)  | NO             | The name of the directory.        |
| DIRECTORY_PATH | VARCHAR2(4000) | NO             | The path of the directory.        |
| ORIGIN_CON_ID  | NUMBER(38)     | NO             | The tenant ID.       |
