# DBA_USERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30.</p>
</main>

## Overview

The `DBA_USERS` view is used to view all users in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is applicable only to OceanBase Database Enterprise Edition.</p>
  </main>

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ----------------------------- | ---------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| USERNAME | VARCHAR2(128) | NO | Username |
| USER_ID | NUMBER(38) | NO | User ID |
| PASSWORD | VARCHAR2(128) | NO | Hash of the user password. The plugin identifier at the beginning of the authentication string can be used to identify the authentication plugin used:<ul><li>`$S$`: indicates`ob_sm3_password`</li><li>`$A$`: indicates`caching_sha2_password`</li></ul> We recommend that you do not rely on this column to determine the authentication mechanism. Check the`PLUGIN`or`AUTHENTICATION_TYPE`Column. |
| ACCOUNT_STATUS | VARCHAR2(30) | NO | Account status:<ul><li>OPEN: The account has been activated.</li><li>OPEN & IN ROLLOVER: The account is normal and in the password rotation period. Both the old and new passwords are valid.</li><li>EXPIRED: The account password has expired.</li><li>EXPIRED(GRACE): The account password has expired, but the password change grace period has not yet ended.</li><li>LOCKED(TIMED): The account is locked because the number of consecutive login failures exceeds the limit.</li><li>LOCKED: The account is locked.</li><li>EXPIRED & LOCKED(TIMED): The account password has expired and the account is locked because the number of consecutive login failures exceeds the limit.</li><li>EXPIRED(GRACE) & LOCKED(TIMED): The account is locked because the password has expired but the password change grace period has not yet ended, and the number of consecutive login failures exceeds the limit.</li><li>EXPIRED & LOCKED: The account is in the password update period.</li><li>EXPIRED(GRACE) & LOCKED: The account is locked because the password has expired but the password change grace period has not yet ended.</li></ul><main id="notice" type='explain'><h4>Note</h4><p>The OPEN & IN ROLLOVER status is supported starting from V4.4.2 BP1.</p></main> |
| LOCK_DATE | DATE | NO | If the account status is locked, the date the account was locked. |
| EXPIRY_DATE | DATE | NO | Account Expiration Date |
| DEFAULT_TABLESPACE | VARCHAR2(30) | NO | Default Tablespace of Data |
| TEMPORARY_TABLESPACE | VARCHAR2(30) | NO | The default tablespace name or tablespace group name of the temporary table. |
| LOCAL_TEMP_TABLESPACE | VARCHAR2(30) | NO | Local Temporary Tablespace <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2. </p></main> |
| CREATED | DATE | NO | Creation Date |
| PROFILE | VARCHAR2(128) | NO | User resource configuration file name <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| INITIAL_RSRC_CONSUMER_GROUP | VARCHAR2(30) | NO | Initial User Resource User Group |
| EXTERNAL_NAME | VARCHAR2(4000) | NO | External Name |
| PASSWORD_VERSIONS | VARCHAR2(12) | NO | Hash algorithm version of the password.<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| EDITIONS_ENABLED | VARCHAR2(1) | NO | Whether to enable the version for users.<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| AUTHENTICATION_TYPE | VARCHAR2(8) | NO | User authentication mechanism.<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| PROXY_ONLY_CONNECT | VARCHAR2(1) | NO | Whether the connection can only be made through a proxy user.  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| COMMON | VARCHAR2(3) | NO | Whether it is a public user. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2. </p></main> |
| LAST_LOGIN | TIMESTAMP(9) WITH TIME ZONE | NO | Last login time <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2. </p></main> |
| ORACLE_MAINTAINED | VARCHAR2(1) | NO | Whether the script is created and maintained by Oracle mode.  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| INHERITED | VARCHAR2(3) | NO | Whether the user inherits from another container. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| DEFAULT_COLLATION | VARCHAR2(100) | NO | Default Character Set <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2. </p></main> |
| IMPLICIT | VARCHAR2(3) | NO | Whether the user is created by an implicit application. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| ALL_SHARD | VARCHAR2(3) | NO | Whether to create shards enabled.  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2. </p></main> |
| PASSWORD_CHANGE_DATE | DATE | YES | Last Password Change Time <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1 BP2.</p></main> |
| PLUGIN | VARCHAR2(64) | NO | Records the name of the plugin used for password hash calculation. Currently, only the following value is allowed:<ul><li>Empty string (default value, equivalent to`mysql_native_password`)</li><li>`ob_native_password`: The value in Oracle-compatible mode, which is equivalent to`mysql_native_password`</li><li>`caching_sha2_password`</li><li>`ob_sm3_password`</li></ul>This field indicates the authentication plugin actually used by the user.<main id="notice" type='explain'><h4>Note</h4><p><ul><li>This field is available starting with V4.4.2 BP2.</li><li>For V4.4.2,`caching_sha2_password`The value is available starting from V4.4.2 BP2. </li><li>For V4.4.2,`ob_sm3_password`The value is available starting from V4.4.2 BP3. </li></ul></p></main> |
