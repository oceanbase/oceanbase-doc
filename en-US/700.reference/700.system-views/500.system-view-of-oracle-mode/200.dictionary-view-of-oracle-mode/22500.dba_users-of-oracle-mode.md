# DBA_USERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

The `DBA_USERS` view displays information about all users in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available starting with OceanBase Database Enterprise Edition. </p>
  </main>

## Columns

|          **Column**           |     **Type**     | **Nullable** |         **Description**         |
|-----------------------------|----------------|----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME                    | VARCHAR2(128)  | NO             | The username.                   |
| USER_ID                     | NUMBER(38)     | NO             | The ID of the user.              |
| PASSWORD                    | VARCHAR2(128)  | NO             | This column is not recommended to be used with the AUTHENTICATION_TYPE column.    |
| ACCOUNT_STATUS              | VARCHAR2(30)   | NO             | The account status:<ul><li>OPEN: The account is enabled. </li><li>EXPIRED: The account password has expired. </li><li>EXPIRED(GRACE): The account password has expired, but the grace period for password change has not expired. </li><li>LOCKED(TIMED): The account is locked due to exceeding the maximum number of consecutive login failures. </li><li>LOCKED: The account is locked. </li><li>EXPIRED & LOCKED(TIMED): The account password has expired and the account is locked due to exceeding the maximum number of consecutive login failures. </li><li>EXPIRED(GRACE) & LOCKED(TIMED): The account is locked due to exceeding the maximum number of consecutive login failures, and the grace period for password change has not expired. </li><li>EXPIRED & LOCKED: The account is in the password update period. </li><li>EXPIRED(GRACE) & LOCKED: The account is locked due to exceeding the maximum number of consecutive login failures, and the grace period for password change has not expired. </li></ul>|
| LOCK_DATE                   | DATE           | NO             | The date when the account is locked.     |
| EXPIRY_DATE                 | DATE           | NO             | The account expiration date.                 |
| DEFAULT_TABLESPACE          | VARCHAR2(30)   | NO             | The default tablespace for data.               |
| TEMPORARY_TABLESPACE        | VARCHAR2(30)   | NO             | The name of the default temporary tablespace or the name of the temporary tablespace group.   |
| LOCAL_TEMP_TABLESPACE       | VARCHAR2(30)   | NO             | The local temporary tablespace <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main> |
| CREATED                     | DATE           | NO             | The date when the user was created.                 |
| PROFILE                     | VARCHAR2(128)  | NO             | The name of the user resource profile. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| INITIAL_RSRC_CONSUMER_GROUP | VARCHAR2(30)   | NO             | The initial resource consumer group of the user.            |
| EXTERNAL_NAME               | VARCHAR2(4000) | NO             | The external name of the user.                |
| PASSWORD_VERSIONS           | VARCHAR2(12)   | NO             | The hash algorithm version of the password <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| EDITIONS_ENABLED            | VARCHAR2(1)    | NO             | Indicates whether the editions are enabled for the user. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| AUTHENTICATION_TYPE         | VARCHAR2(8)    | NO             | The authentication mechanism of the user. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| PROXY_ONLY_CONNECT          | VARCHAR2(1)    | NO             | Indicates whether the user can only connect through a proxy user. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| COMMON                      | VARCHAR2(3)    | NO             | Indicates whether the user is a common user. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| LAST_LOGIN                  | TIMESTAMP(9) WITH TIME ZONE | NO   | The last login time of the user. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| ORACLE_MAINTAINED           | VARCHAR2(1)    | NO             | Indicates whether the script is created and maintained by the Oracle mode. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| INHERITED                   | VARCHAR2(3)    | NO             | Indicates whether the user is inherited from another container. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| DEFAULT_COLLATION           | VARCHAR2(100)  | NO             | Default character set <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| IMPLICIT                    | VARCHAR2(3)    | NO             | Indicates whether the user is created by an implicit application. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| ALL_SHARD                   | VARCHAR2(3)    | NO             | Indicates whether the user is created in shard mode. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
| PASSWORD_CHANGE_DATE        | DATE           | YES            | The last time the password was changed. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.1 BP2. </p></main>|
