# DBA_OB_BACKUP_VALIDATE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` view displays the execution history of task-level backup validation tasks initiated by the current tenant. Each task corresponds to a backup set or archive log piece validation task.

## Columns

| Column | Type | Nullable | Description |
| ----------------- | ------------- | -------------- | -------------- |
| TASK_ID | NUMBER(38) | NO | The task ID. |
| INCARNATION | NUMBER(38) | NO | The incarnation ID. |
| JOB_ID | NUMBER(38) | NO | The job ID. |
| TASK_TYPE | VARCHAR2(64) | NO | The validation task type. Valid values: <ul><li>`BACKUPSET`: validates a specified backup set. </li> <li>`ARCHIVELOG_PIECE`: validates a specified archive log piece. </li></ul>       |
| ID | NUMBER(38) | YES | The `backup_set_id` of the backup set to be validated or the `piece_id` of the archive log piece to be validated.       |
| PATH | CLOB | YES | The backup path or archive log path to be validated.      |
| PATH_TYPE | VARCHAR2(64) | YES | The path type to be validated. Valid values: <ul><li>`BACKUP_SET_DEST`: the data backup path. </li> <li>`ARCHIVELOG_PIECE_DEST`: the archive log path. </li></ul>  |
| DEST_ID | NUMBER(38) | YES | The ID of the backup path or archive log path to be validated.     |
| PLUS_ARCHIVELOG | VARCHAR2(64) | NO | Indicates whether to include compensating logs.      |
| INITIATOR_TASK_ID | NUMBER(38) | NO | The task ID of the compensating log validation task. If this value is 0, no compensating log validation task exists.     |
| VALIDATE_LEVEL | VARCHAR2(64) | NO | The validation level. Valid values: <ul><li>`basic`: only checks the completeness of the file list. </li> <li>`physical`: checks the correctness and logical consistency of the physical data. </li></ul>      |
| ROUND_ID | NUMBER(38) | NO | The Round ID of the archive log piece to be validated. If this value is 0, no archive log piece is to be validated. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The start time of the validation task.     |
| END_TIMESTAMP | VARCHAR2(256) | NO | The end time of the validation task.     |
| STATUS | VARCHAR2(64) | NO | The task status. Valid values: <ul><li>`COMPLETED`: the validation task has been completed. </li> <li>`FAILED`: the validation task has failed. </li> <li>`CANCELED`: the validation task has been canceled. </li></ul>       |
| TOTAL_LS_COUNT | NUMBER(38) | YES | The number of log streams in the task.     |
| FINISH_LS_COUNT | NUMBER(38) | YES | The number of log streams that have been validated.     |
| TOTAL_BYTES | NUMBER(38) | YES | The estimated size of the data to be validated, in bytes.     |
| VALIDATED_BYTES | NUMBER(38) | YES | The size of the data that has been validated, in bytes.     |
| RESULT | NUMBER(38) | NO | The error code of the validation result.     |
| COMMENT | VARCHAR2(4096)| YES | The reason for the failure of the validation task.      |

## Sample query

Query the execution history of task-level backup validation tasks initiated by the current user tenant.

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_TASK_HISTORY\G
```
