# DBA_OB_BACKUP_VALIDATE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.4.2, this view is available starting from V4.4.2 BP2.</li>
<li>For V4.6.x versions, this view is available starting from V4.6.0.</li></ul>
</main>

## Overview

The `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` view displays the execution history of backup validation tasks initiated by the current tenant. Each task corresponds to a validation task for a backup set or log archive piece.

## Columns

| Column | Type | Nullable | Description |
| ----------------- | ------------- | -------------- | -------------- |
| TASK_ID | NUMBER(38) | NO | The task ID. |
| INCARNATION | NUMBER(38) | NO | Incarnation ID |
| JOB_ID | NUMBER(38) | NO | Job ID of the task. |
| TASK_TYPE | VARCHAR2(64) | NO | Validation task type: <ul><li>`BACKUPSET`: Validate the specified backup set.</li> <li>`ARCHIVELOG_PIECE`: Validate the specified log archive piece.</li></ul> |
| ID | NUMBER(38) | YES | The `backup_set_id` of the backup set to be validated or the `piece_id` of the log archive piece |
| PATH | CLOB | YES | Backup path or log archive path to validate |
| PATH_TYPE | VARCHAR2(64) | YES | Valid path types:<ul><li>`BACKUP_SET_DEST`: Data backup path</li> <li>`ARCHIVELOG_PIECE_DEST`: Log archive path</li></ul> |
| DEST_ID | NUMBER(38) | YES | ID of the backup or archive path to be validated |
| PLUS_ARCHIVELOG | VARCHAR2(64) | NO | Whether compensation logs are included |
| INITIATOR_TASK_ID | NUMBER(38) | NO | Parent task ID of the compensation log validation task. 0 if not specified. |
| VALIDATE_LEVEL | VARCHAR2(64) | NO | Validation level: <ul><li>`basic`: Checks only the integrity of the file list. </li> <li>`physical`: Checks the correctness of physical data and logical consistency.</li></ul> |
| ROUND_ID | NUMBER(38) | NO | Round ID of the log archive piece, or 0 if not specified. |
| START_TIMESTAMP | VARCHAR2(256) | NO | Start time of the validation task |
| END_TIMESTAMP | VARCHAR2(256) | NO | End time of the validation task |
| STATUS | VARCHAR2(64) | NO | Task status: <ul><li>`COMPLETED`: The validation task has been completed.</li> <li>`FAILED`: Validation task execution failed.</li> <li>`CANCELED`: The validation task has been canceled.</li></ul> |
| TOTAL_LS_COUNT | NUMBER(38) | YES | Number of Log Streams Included in the Task |
| FINISH_LS_COUNT | NUMBER(38) | YES | Number of log streams validated |
| TOTAL_BYTES | NUMBER(38) | YES | Estimated data volume to be validated, in bytes |
| VALIDATED_BYTES | NUMBER(38) | YES | The amount of data that has been validated, in bytes |
| RESULT | NUMBER(38) | NO | Error code information of the validation result |
| COMMENT | VARCHAR2(4096) | YES | Reason description for the validation task failure |

## Sample query

You can view the execution history of task-level backup validation tasks initiated by the current tenant.

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_TASK_HISTORY\G
```
