# DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing jobs that are currently being executed by the tenant. Each tenant can have only one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks (TASK) to perform specific load balancing operations.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | The ID of the load balancing job. |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the job was created. |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the information was last updated. |
| BALANCE_STRATEGY | VARCHAR2(64) | NO | The name of the balancing strategy. Valid values: <ul><li>`LS balance by migrate`: migration-based balancing  </li><li>`LS balance by alter`: log stream attribute modification-based balancing </li><li>`LS balance by expand`: expansion-based balancing </li><li>`LS balance by shrink`: reduction-based balancing </li><li>`partition balance`: partition-based balancing </li></ul>|
| JOB_TYPE | VARCHAR2(64) | NO | The type of the task. Valid values:  <ul><li>`LS_BALANCE`: log stream balancing  </li><li>`PARTITION_BALACNE`: partition balancing </li></ul>|
| TARGET_UNIT_NUM | NUMBER(38) | NO | The number of units to be changed in each zone. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is always <code>NULL</code> starting from V4.4.2. </li> <li>For V4.2.5, this field is always <code>NULL</code> starting from V4.2.5 BP5. </li></ul></main>  |
| TARGET_PRIMARY_ZONE_NUM | NUMBER(38) | NO | The number of primary zones to be changed. |
| STATUS | VARCHAR2(64) | NO | The status of the task. Valid values: <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: The task was successfully executed. </li><li>`CANCELING`: The task is being canceled. </li><li>`CANCELED`: The task was canceled. </li> <li>`SUSPEND`: The task is suspended. </li></ul>|
| COMMENT | longtext | YES | The comment. |
| COMMENT | CLOB | YES | The comment. |
| MAX_END_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | The maximum end time of the load balancing task. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view is available starting with V4.3.4. For V4.2.x, this field is available starting with V4.2.4. </p></main>  |
| ZONE_UNIT_NUM_LIST      | VARCHAR2(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting with V4.4.2. </li> <li>For V4.2.5, this field is available starting with V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          | CLOB           | NO   | The parameters of the balancing-related configurations.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting with V4.4.2. </li> <li>For V4.2.5, this field is available starting with V4.2.5 BP5. </li></ul></main> |

## Sample query

Query the load balancing jobs that are currently being executed by the tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOBS;
```

The query result is as follows:

```shell
+--------+----------------------------+----------------------------+-------------------------+------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
| JOB_ID | CREATE_TIME                | MODIFY_TIME                | BALANCE_STRATEGY        | JOB_TYPE   | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS | COMMENT | MAX_END_TIME | ZONE_UNIT_NUM_LIST | PARAMETER_LIST                                                                               |
+--------+----------------------------+----------------------------+-------------------------+------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
| 120112 | 16-JAN-26 17:37:21.308318  | 16-JAN-26 17:37:21.308318  | alter LS group location | LS_BALANCE |            NULL |                       2 | DOING  | NULL    | NULL         | z1:1,z2:1          | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |
+--------+----------------------------+----------------------------+-------------------------+------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
1 row in set
```
