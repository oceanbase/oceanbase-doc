# DBA_ALL_TABLES

## Purpose

Query the object and relationship tables in the database. The fields are the same as those in the ALL_ALL_TABLES view.

  <main id="notice" >
    <h4>Applicability</h4>
    <p> This view applies only to the Oracle mode of OceanBase Database. </p>
  </main>

## Related views

* ALL_ALL_TABLES

* USER_ALL_TABLES
