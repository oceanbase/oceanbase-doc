# USER_SYS_PRIVS

## Purpose

Lists the system privileges granted to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

DBA_SYS_PRIVS

## Columns

|   **Column**   |    **Type**     | **Nullable?** |      **Description**      |
|--------------|---------------|----------------|------------------|
| GRANTEE      | VARCHAR2(128) | NO             | The name of the grantee, user, or role. |
| PRIVILEGE    | VARCHAR2(40)  | NO             | The system privilege.             |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | The option to grant the privilege to other users.           |
