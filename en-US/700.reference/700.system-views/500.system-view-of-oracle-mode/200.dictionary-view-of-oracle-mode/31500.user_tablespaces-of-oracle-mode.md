# USER_TABLESPACES

## Purpose

The view displays the tablespaces that the current user can access. The columns are the same as those in the `DBA_TABLESPACES` view, except for the `PLUGGED_IN` column.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views
