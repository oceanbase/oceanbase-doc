# ROLE_TAB_PRIVS

## Purpose

Describes the table privileges granted to roles. This view provides information about roles that users can access.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|  **Column**   |    **Type**     | **Nullable?** |       **Description**       |
|-------------|---------------|----------------|--------------------|
| ROLE        | VARCHAR2(128) | NO             | Role name               |
| OWNER       | VARCHAR2(128) | NO             | Owner of the object             |
| TABLE_NAME  | VARCHAR2(128) | NO             | Name of the object              |
| COLUMN_NAME | VARCHAR2(128) | NO             | Name of the column (if applicable)         |
| PRIVILEGE   | VARCHAR2(40)  | NO             | Object privilege granted to the role          |
| GRANTABLE   | VARCHAR2(3)   | NO             | Whether the role has the ADMIN OPTION |
