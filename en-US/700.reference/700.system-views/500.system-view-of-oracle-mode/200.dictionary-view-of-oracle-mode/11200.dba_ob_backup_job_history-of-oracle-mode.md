# DBA_OB_BACKUP_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the history of backup jobs of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | The ID of the backup job. Each backup operation corresponds to one job record. |
| INCARNATION | NUMBER(38) | NO | The incarnation number after a Flashback Database operation. |
| BACKUP_SET_ID | NUMBER(38) | YES | The backup set ID. For the sys tenant, it defaults to 0. For user tenants, it starts from 1 and increments sequentially. For records of archive log backup tasks (`BACKUP_TYPE` is `BACKUP_ARCHIVE` or `BACKUP_ARCHIVE_DELETE_INPUT`), this field has no practical meaning. |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | The tenant ID of the task initiator. This value indicates the tenant that initiated the task, which is the tenant that executed the backup SQL statement. |
| INITIATOR_JOB_ID | NUMBER(38) | NO | The job ID of the task initiator. |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | The ID of the tenant for which the job-level backup task is to be executed. |
| PLUS_ARCHIVELOG | VARCHAR2(4096) | NO | Specifies whether to enable log completion. Valid values:<ul><li>ON: Enable log completion.</li><li>OFF: Disable log completion.</li></ul>This parameter is meaningless for records of archive log backup tasks (`BACKUP_TYPE` is `BACKUP_ARCHIVE` or `BACKUP_ARCHIVE_DELETE_INPUT`). |
| BACKUP_TYPE | VARCHAR2(4096) | NO | The backup type. Valid values:<ul><li>`FULL`: indicates a full backup. </li> <li>`INC`: indicates an incremental backup.</li><li>`BACKUP_ARCHIVE`: indicates an archive log backup, initiated by executing the `ALTER SYSTEM BACKUP ARCHIVELOG ALL` statement.</li><li>`BACKUP_ARCHIVE_DELETE_INPUT`: indicates an archive log backup with `DELETE INPUT`, initiated by executing the `ALTER SYSTEM BACKUP ARCHIVELOG ALL DELETE INPUT` statement.</li></ul></br>For V4.4.x versions, `BACKUP_ARCHIVE` and `BACKUP_ARCHIVE_DELETE_INPUT` are available starting from V4.4.2 BP3. |
| JOB_LEVEL | VARCHAR2(4096) | NO | The job level. Valid values: <ul><li>CLUSTER: jobs initiated by the sys tenant to back up all tenants</li><li>SYS_TENANT: jobs initiated by the sys tenant to back up a specified tenant</li><li>USER_TENANT: jobs initiated by a user tenant to back up itself</li></ul> |
| ENCRYPTION_MODE | VARCHAR2(4096) | YES | The encryption mode. Valid values: <ul><li>None: no encryption.</li><li>Password: password-only protection.</li><li>Password Encryption: encryption and password-only protection.</li><li>Transparent Encryption: Transparent Data Encryption (TDE).</li><li>Dual mode Encryption: TDE and password-only protection.</li></ul> Only the None and Password modes are supported. |
| PASSWD | VARCHAR2(4096) | YES | Password. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The start time of the job-level backup task. |
| END_TIMESTAMP | VARCHAR2(256) | NO | The end time of the job-level backup task. |
| STATUS | VARCHAR2(4096) | NO | The backup status. |
| RESULT | NUMBER(38) | NO | The backup error code result. |
| COMMENT | VARCHAR2(4096) | YES | The description of the error code. |
| DESCRIPTION | VARCHAR2(4096) | YES | The user-specified backup description. |
| PATH | VARCHAR2(4096) | YES | The backup path. |
