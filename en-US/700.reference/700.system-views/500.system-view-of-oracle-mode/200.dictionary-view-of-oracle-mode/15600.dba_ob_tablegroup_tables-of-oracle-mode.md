# DBA_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the association between tables and table groups in the current tenant. It does not display tables that are not in any table group.

## Columns

|      Column       |      Type       | Nullable |      Description       |
|-----------------|---------------|------------|---------------|
| TableGROUP_NAME | VARCHAR2(128) | NO         | The name of the table group.           |
| OWNER           | VARCHAR2(128) | NO         | The name of the database to which the table belongs. |
| TABLE_NAME      | VARCHAR2(256) | NO         | The name of the table.       |
| SHARDING        | VARCHAR2(20)  | NO         | The SHARDING attribute of the table group. Valid values: <ul><li>`NONE`: All partitions of all tables in the table group are located on the same server. No restrictions are imposed on tables added to the table group.</li> <li>`PARTITION`: Data of each table in the table group is distributed across primary partitions. If the table is a composite partitioned table, all secondary partitions under each primary partition are located on the same server.</li> <li>`ADAPTIVE`: Data of each table in the table group is distributed in adaptive mode. That is, if the table is a primary partitioned table, data is distributed across primary partitions. If the table is a composite partitioned table, data is distributed across secondary partitions under each primary partition.</li></ul>  |

## Sample query

Query the association between tables and the table group named `TBLGROUP1` in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'TBLGROUP1';
```

The query result is as follows:

```shell
+-----------------+-------+------------+----------+
| TABLEGROUP_NAME | OWNER | TABLE_NAME | SHARDING |
+-----------------+-------+------------+----------+
| TBLGROUP1       | SYS   | TBL3       | NONE     |
+-----------------+-------+------------+----------+
1 row in set
```
