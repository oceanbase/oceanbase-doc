# DBA_OB_ARCHIVELOG_PIECE_FILES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of pieces in the backup set of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | The path ID. The system assigns a unique ID to each path. |
| ROUND_ID | NUMBER(38) | NO | The ID of the complete clog backup stream. |
| PIECE_ID | NUMBER(38) | NO | The ID of the backup log piece. |
| INCARNATION | NUMBER(38) | NO | The number of times the database has been flashed back. |
| DEST_NO | NUMBER(38) | NO | The ID of the log_archive_dest_n parameter. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| STATUS | VARCHAR2(64) | NO | The status of the piece. Valid values: <li>ACTIVE: The piece is active. <li>FREEZING: The piece is being frozen. <li>FROZEN: The piece is frozen. After this status is set, the piece status will no longer change. |
| START_SCN | NUMBER(38) | NO | The start SCN of the piece. |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | The time corresponding to the START_SCN value. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The current archive SCN. |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | The time corresponding to the CHECKPOINT_SCN value. |
| MAX_SCN | NUMBER(38) | NO | The maximum archive SCN. |
| END_SCN | NUMBER(38) | NO | The theoretical end SCN of the piece. |
| COMPATIBLE  | NUMBER(38) | NO | The compatible version of the log archive. |
| UNIT_SIZE   | NUMBER(38)     | NO   | The size of a single log block that is compressed or encrypted. This column is not supported. |
| COMPRESSION | VARCHAR2(128)  | NO   | The compression algorithm. Valid values: <ul><li> none: No compression. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used. </li></ul> This column is not supported.    |
| INPUT_BYTES | NUMBER(38) | NO | The size of the original data. |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the original data in the specified unit. |
| OUTPUT_BYTES | NUMBER(38) | NO | The size of the effective data after encryption and compression. |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the effective data in the specified unit. |
| COMPRESSION_RATIO | NUMBER | NO | The compression ratio. |
| FILE_STATUS | VARCHAR2(64) | NO | The file status of the backup log piece. Valid values: <li>AVAILABLE: The backup is valid and can be used for recovery. <li>COPYING: The log file is being backed up. <li>INCOMPELTE: The log file is partially copied. This status is applicable only to scheduled log backups. The checkpoint_ts of the copy is earlier than that of the original backup. The copy can be used for recovery before the checkpoint_ts of the original backup. <li>DELETING: The log file is being deleted. <li>EXPIRED: The backup file is invalid. <li>BROKEN: The backup file is incomplete and cannot be used. <li>DELETED: The log file has been deleted. |
| PATH | VARCHAR2(2048) | NO | The archive path. |
