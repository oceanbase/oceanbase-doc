# ALL_ALL_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

This view displays the objects and relationships of tables that the current user can access. Unlike the `ALL_TABLES` view, the `ALL_ALL_TABLES` view can query object tables.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode of OceanBase Database. </p>
  </main>

## Sample query

Query the information of the `T_SUBPART` table in the object tables and relationship tables that the user can access.

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, STATUS, PCT_FREE, NUM_ROWS, PARTITIONED, TEMPORARY, ROW_MOVEMENT, DROPPED, EXTERNAL FROM SYS.ALL_ALL_TABLES WHERE TABLE_NAME='T_SUBPART';
```

The query result is as follows:

```shell
+-------+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
| OWNER | TABLE_NAME | STATUS | PCT_FREE | NUM_ROWS | PARTITIONED | TEMPORARY | ROW_MOVEMENT | DROPPED | EXTERNAL |
+-------+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
| SYS   | T_SUBPART  | VALID  |        0 |     1000 | YES         | N         | NO           | NO      | NO       |
+-------+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
1 row in set
```
