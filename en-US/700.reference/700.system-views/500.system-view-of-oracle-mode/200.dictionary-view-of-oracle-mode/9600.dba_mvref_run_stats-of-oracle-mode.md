# DBA_MVREF_RUN_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVREF_RUN_STATS` view displays information about each refresh run of a materialized view. Each run is identified by a REFRESH_ID. The information includes timing statistics related to the run and the parameters specified for the run.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| RUN_OWNER | VARCHAR2(128) | NO | The owner of the refresh operation (the user who initiated the operation). |
| REFRESH_ID | NUMBER | NO | The ID of the refresh. |
| NUM_MVS | NUMBER | NO | The number of materialized views refreshed. |
| MVIEWS | VARCHAR2(4000) | NO | The MVIEW parameter specified by the API. |
| BASE_TABLES | VARCHAR2(4000) | YES | For internal use only. |
| METHOD | VARCHAR2(4000) | YES | The METHOD parameter specified by the API. |
| ROLLBACK_SEG | VARCHAR2(4000) | YES | The ROLLBACK_SEG parameter specified by the API. |
| PUSH_DEFERRED_RPC | CHAR(1) | NO | The PUSH_DEFERRED_RPC parameter specified by the API. |
| REFRESH_AFTER_ERRORS | CHAR(1) | NO | The REFRESH_AFTER_ERRORS parameter specified by the API. |
| PURGE_OPTION | NUMBER | NO | The PURGE_OPTION parameter specified by the API. |
| PARALLELISM | NUMBER | NO | The PARALLELISM parameter specified by the API. |
| HEAP_SIZE | NUMBER | NO | The HEAP_SIZE parameter specified by the API. |
| ATOMIC_REFRESH | CHAR(1) | NO | The ATOMIC_REFRESH parameter specified by the API. |
| NESTED | CHAR(1) | NO | The NESTED parameter specified by the API. |
| OUT_OF_PLACE | CHAR(1) | NO | The OUT_OF_PLACE parameter specified by the API. |
| NUMBER_OF_FAILURES | NUMBER | NO | The number of failures that occurred during API processing. |
| START_TIME | TIMESTAMP(6) | NO | The start time of the refresh run. |
| END_TIME | TIMESTAMP(6) | NO | The end time of the refresh run. |
| ELAPSED_TIME | NUMBER | NO | The duration of the refresh run, in seconds. |
| LOG_SETUP_TIME | NUMBER | NO | The time taken to set up the materialized view log, in seconds.<main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and defaults to 0. </p></main> |
| LOG_PURGE_TIME | NUMBER | NO | The time taken to purge the materialized view log, in seconds. |
| COMPLETE_STATS_AVAILABLE | CHAR(1) | NO | Indicates whether complete refresh statistics are available for this run<ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and defaults to Y. </p></main> |

## Sample query

Query information about each refresh run of a materialized view. Each run is identified by a REFRESH_ID.
