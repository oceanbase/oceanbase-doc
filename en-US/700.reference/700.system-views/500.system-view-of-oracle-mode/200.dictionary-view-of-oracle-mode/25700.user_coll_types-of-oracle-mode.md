# USER_COLL_TYPES

## Purpose

Lists the user-defined collection types available to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_COLL_TYPES

* ALL_COLL_TYPES

## Columns

|      **Column**      |    **Type**     | **Nullable?** |   **Description**    |
|--------------------|---------------|----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE_NAME          | VARCHAR2(64)  | NO             | Type name         |
| COLL_TYPE          | VARCHAR2(10)  | NO             | Collection type: <li> VARYING   <li> ARRAY   <li> NESTED TABLE    |
| UPPER_BOUND        | NUMBER(38)    | YES            | Maximum size of a collection for VARYING.                                                                           |
| ELEM_TYPE_MOD      | VARCHAR2(7)   | YES            | Not supported. The default value is NULL.                                                                        |
| ELEM_TYPE_OWNER    | VARCHAR2(128) | YES            | Owner of the collection element type  |
| ELEM_TYPE_NAME     | VARCHAR2(324) | YES            | Name of the collection element type     |
| LENGTH             | NUMBER(38)    | YES            | Length of the collection element type    |
| NUMBER_PRECISION   | NUMBER(38)    | YES            | Precision of the collection element type    |
| SCALE              | NUMBER(38)    | YES            | Length of the data to the right of the decimal point in the collection element type                                                                               |
| CHARACTER_SET_NAME | CHAR(7)       | YES            | Character set of the collection element type   |
| ELEM_STORAGE       | CHAR(7)       | YES            | Not supported. The default value is NULL.                                                                        |
| NULLS_STORED       | CHAR(7)       | YES            | Not supported. The default value is NULL.                                                                        |
