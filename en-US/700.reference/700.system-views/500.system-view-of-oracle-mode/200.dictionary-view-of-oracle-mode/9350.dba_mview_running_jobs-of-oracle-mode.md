# DBA_MVIEW_RUNNING_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.4.x, this view was introduced in V4.4.0.</li><li>For V4.3.5, this view was introduced in V4.3.5 BP2.</li></ul></p>
</main>

## ## Purpose

This view displays the materialized view-related tasks in progress in the current tenant, including refresh tasks and MLOG cleanup tasks.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
|----------------|----------|---------------------|---------|
| SVR_IP         | VARCHAR2(46)                      | NO   | The node address where the Leader of log stream 1 of the tenant is located. |
| SVR_PORT       | NUMBER(38)                        | NO   | The node PORT where the Leader of log stream 1 of the tenant is located. |
| TABLE_NAME     | VARCHAR2(256)                     | YES  | The name of the table associated with the task. <ul><li>Refresh task: the name of the materialized view.</li><li>MLOG cleanup task: the name of the MLOG table.</li></ul>|
| JOB_TYPE       | CHAR(64)                          | NO   | The task type. Valid values: <ul><li>INVALID</li><li>COMPLETE REFRESH</li><li>FAST REFRESH</li><li>PURGE MLOG</li></ul>|
| SESSION_ID     | NUMBER(38)                        | NO   | The Session ID that initiated the task. |
| READ_SNAPSHOT  | NUMBER(38)                        | NO   | The snapshot position used by the task. |
| PARALLEL       | NUMBER(38)                        | NO   | The parallelism of the task. |
| JOB_START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The start time of the task. |
| REFRESH_ID     | NUMBER(38)                        | NO   | The ID of the current refresh task. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.4.2 BP2. </p></main>|
