# DBA_ROLES

## Purpose

The DBA_ROLES view lists all roles in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|      **Column**       |    **Type**    | **Nullable?** |               **Description**               |
|---------------------|--------------|----------------|------------------------------------|
| ROLE                | VARCHAR2(30) | NO             | The name of the role.                               |
| PASSWORD_REQUIRED   | VARCHAR2(8)  | NO             | Indicates whether the role requires a password. The password feature is supported, but this field cannot correctly display the password status. |
| AUTHENTICATION_TYPE | VARCHAR2(11) | NO             | The authentication mechanism of the role. This field is not supported.             |
