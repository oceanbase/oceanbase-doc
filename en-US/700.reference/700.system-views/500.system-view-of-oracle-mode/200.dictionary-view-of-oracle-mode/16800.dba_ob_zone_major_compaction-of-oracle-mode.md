# DBA_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the compaction information of each zone in the current tenant.

## Columns

|       Column        |      Type      | Nullable |         Description         |
|-------------------|--------------|------------|----------------------------------------------|
| ZONE              | VARCHAR2(128) | NO         | The name of the zone.            |
| BROADCAST_SCN | NUMBER(38)   | NO         | The version number of the broadcast compaction.           |
| LAST_SCN      | NUMBER(38)   | NO         | The version number of the last compaction.          |
| LAST_FINISH_TIME  | NUMBER(38)   | NO         | The end time of the last compaction.          |
| START_TIME        | NUMBER(38)   | NO         | The start time of the compaction.             |
| STATUS            | VARCHAR2(10)  | NO         | <ul><li> `IDLE`: No compaction is in progress.  </li><li>`COMPACTING`: A compaction is in progress. </li></ul>    |

## Sample query

Query the compaction information of each zone in the current user tenant.

```shell
obclient> SELECT * FROM SYS.DBA_OB_ZONE_MAJOR_COMPACTION;
```

The query result is as follows:

```shell
+-------+---------------------+---------------------+------------------+------------------+--------+
| ZONE  | BROADCAST_SCN       | LAST_SCN            | LAST_FINISH_TIME | START_TIME       | STATUS |
+-------+---------------------+---------------------+------------------+------------------+--------+
| zone1 | 1748455200327759000 | 1748455200327759000 | 1748455572486949 | 1748455200370343 | IDLE   |
+-------+---------------------+---------------------+------------------+------------------+--------+
1 row in se
```
