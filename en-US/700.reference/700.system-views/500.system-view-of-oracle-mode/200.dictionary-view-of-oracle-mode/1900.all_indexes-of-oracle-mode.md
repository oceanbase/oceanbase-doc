# ALL_INDEXES

## Purpose

The ALL_INDEXES view displays the index column information of all tables accessible to the user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>
