# DBA_OB_RECOVER_TABLE_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays information about table-level restore tasks for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | The task ID. |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | The tenant ID of the parent task. |
| INITIATOR_JOB_ID | NUMBER(38) | NO | The job ID of the parent task. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task started. |
| FINISH_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task completed. |
| STATUS | VARCHAR2(64) | NO | The status of the task. Valid values: <ul><li>PREPARE: The task is being initialized.  </li><li>RECOVERING: The task is being restored. </li><li>RESTORE_AUX_TENANT: The auxiliary tenant is being restored. </li><li>PRECHECK_IMPORT: The import is being prechecked. </li><li>GEN_IMPORT_JOB: The import task is being initialized. </li><li>IMPORTING: The tables are being imported. </li><li> CANCELING: The task is being canceled.</li><li>COMPLETED: The task is completed. </li><li>FAILED: The task failed. </li></ul> |
| AUX_TENANT_NAME | VARCHAR2(64) | NO | The name of the auxiliary tenant. |
| TARGET_TENANT_NAME | VARCHAR2(64) | NO | The name of the target tenant. |
| IMPORT_ALL | NUMBER(38) | NO | Indicates whether to import all tables under the tenant. The value is 1 only when the user specifies `RECOVER TABLE *.*`. In other scenarios, the value is 0. |
| DB_LIST | CLOB | YES | The list of databases to be fully restored. |
| TABLE_LIST | CLOB | YES | The list of tables to be restored. |
| RESTORE_SCN | NUMBER(38) | NO | The restore point specified by the user. |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | The timestamp representation of the restore point specified by the user. |
| RESTORE_OPTION | VARCHAR2(4096) | NO | The restore_option parameter required by the auxiliary tenant. |
| BACKUP_DEST | VARCHAR2(4096) | NO | The path for backups and archives. |
| BACKUP_SET_LIST | CLOB | NO | The path for data backups. |
| BACKUP_PIECE_LIST | CLOB | NO | The path for log archives. |
| BACKUP_PASSWD | VARCHAR2(4096) | YES | The password of the backup set. |
| EXTERNAL_KMS_INFO | VARCHAR2(4096) | YES | If the source tenant has configured key management, configure this parameter in the session. |
| REMAP_DB_LIST | CLOB | YES | The list of renamed databases. The format is as follows: db1:new_db1, db2:newdb2 |
| REMAP_TABLE_LIST | CLOB | YES | The list of renamed tables. The format is as follows: db1.t1:new_t1, db1.t2:db2.new_t2 |
| REMAP_TABLEGROUP_LIST | CLOB | YES | The list of table groups to be remapped. You can remap tables from the original table group to the target table group. The format is as follows: tg1:new_tg1, tg2:new_tg2 |
| REMAP_TABLESPACE_LIST | CLOB | YES | The list of tablespaces to be remapped. You can remap tables from the original tablespace to the target tablespace. The format is as follows: ts1:new_ts1, ts2:new_ts2 |
| RESULT | VARCHAR2(64) | YES | The result of the table-level restore task. Valid values: <ul><li>SUCCESS  </li><li>FAIL </li></ul> |
| COMMENT | CLOB | YES | The remarks. |
| DESCRIPTION | CLOB | YES | The DESCRIPTION parameter specified in the restore command. |
