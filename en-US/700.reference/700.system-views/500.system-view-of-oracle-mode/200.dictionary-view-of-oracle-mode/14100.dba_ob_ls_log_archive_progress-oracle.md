# DBA_OB_LS_LOG_ARCHIVE_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays the log stream archiving progress of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | Description |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | The ID of the archiving destination. |
| LS_ID | NUMBER(38) | NO | The ID of the log stream. |
| ROUND_ID | NUMBER(38) | NO | The ID of the log stream round. |
| PIECE_ID | NUMBER(38) | NO | The ID of the latest piece. |
| INCARNATION | NUMBER(38) | NO | The ID of the incarnation. |
| START_SCN | NUMBER(38) | NO | The SCN at which archiving starts. |
| MIN_LSN | NUMBER(38) | NO | The minimum LSN of the current piece. |
| MAX_LSN | NUMBER(38) | NO | The maximum LSN of the current piece. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The maximum archiving progress of the current piece. |
| STATUS | VARCHAR2(64) | NO | The archiving status. |
| FILE_ID | NUMBER(38) | NO | The ID of the largest archiving file in the current piece. |
| FILE_OFFSET | NUMBER(38) | NO | The offset of the largest archiving file in the current piece. |
| INPUT_BYTES | NUMBER(38) | NO | The size of the log data read, in bytes. |
| OUTPUT_BYTES | NUMBER(38) | NO | The size of the archived log data, in bytes. |

## Sample query

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_LOG_ARCHIVE_PROGRESS\G
```
