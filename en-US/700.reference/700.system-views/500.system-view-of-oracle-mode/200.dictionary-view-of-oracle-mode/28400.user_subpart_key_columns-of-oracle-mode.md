# USER_SUBPART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays all columns in the subpartition keys of all partitioned objects owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode. </p>
  </main>

## Columns

|      **Column**      |     **Type**     | **Nullable** |                                                              **Description**                                                              |
|--------------------|----------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| NAME               | VARCHAR2(128)  | NO             | The name of the partitioned table or partitioned index.                                   |
| OBJECT_TYPE        | CHAR(5)        | NO             | The type of the partitioned object: <li> TABLE   <li> INDEX    |
| COLUMN_NAME        | VARCHAR2(4000) | NO             | The name of the column.                                          |
| COLUMN_POSITION    | NUMBER         | NO             | The position of the column in the partition key.                                     |
| COLLATED_COLUMN_ID | NUMBER         | NO             | This column is not supported. The value of this column is NULL by default.                       |

## Sample query

Query the columns in the subpartition key of the partitioned table `TBL2_F_RL` owned by the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_SUBPART_KEY_COLUMNS WHERE NAME='TBL2_F_RL';
```

The query result is as follows:

```shell
+-----------+-------------+-------------+-----------------+--------------------+
| NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-----------+-------------+-------------+-----------------+--------------------+
| TBL2_F_RL | TABLE       | COL2        |               1 |               NULL |
+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
