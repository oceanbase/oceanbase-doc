# DBA_SQL_MANAGEMENT_CONFIG

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the configuration parameters of SPM for the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| PARAMETER_NAME | VARCHAR2(128) | NO | The name of the configuration parameter. Valid values: <ul><li>SPACE_BUDGET_PERCENT</li><li>PLAN_RETENTION_WEEKS</li></ul> |
| PARAMETER_VALUE | text | YES | The value of the configuration parameter. |
| LAST_MODIFIED | TIMESTAMP(6) | NO | The time when the parameter value was last updated. |
| MODIFIED_BY | VARCHAR2(128) | NO | The object that last updated the parameter value. |

## Sample query

Query the configuration parameters of SPM for the current tenant.

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_SQL_MANAGEMENT_CONFIG;
```
