# DBA_TAB_STATISTICS

## Purpose

The `DBA_TAB_STATISTICS` view displays optimizer statistics for all tables in the database.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in V3.2.1. </p>
</main>

## Related views

* ALL_TAB_STATISTICS

* USER_TAB_STATISTICS

| OWNER                     | VARCHAR2(128) | NO             | The name of the user who owns the entity.                                     |
