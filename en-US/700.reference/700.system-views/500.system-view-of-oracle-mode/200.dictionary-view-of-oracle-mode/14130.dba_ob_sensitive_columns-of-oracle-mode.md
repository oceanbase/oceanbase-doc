# DBA_OB_SENSITIVE_COLUMNS

## Purpose

This view displays all columns that are protected by sensitive rules in the current tenant.

## Columns

|        Column         |      Type       | Nullable |                      Description                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| RULE_NAME         | varchar(256)    | NO         | The name of the sensitive rule.                                           |
| USER_NAME      | varchar(128)    | NO         | The name of the user.                                        |
| TABLE_NAME         | varchar(128)    | NO         | The name of the table.                                      |
| COLUMN_NAME        | varchar(128)    | NO         | The name of the column.                                                     |

## Sample query

Query all columns that are protected by sensitive rules in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_SENSITIVE_COLUMNS;
```

The query result is as follows:

```shell
+-----------+-----------+------------+-------------+
| RULE_NAME | USER_NAME | TABLE_NAME | COLUMN_NAME |
+-----------+-----------+------------+-------------+
| r1        | u1        | t2         | c           |
| r1        | u1        | t1         | a           |
+-----------+-----------+------------+-------------+
2 row in set
```
