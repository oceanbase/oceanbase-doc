# DICT

## Purpose

Displays descriptions of data dictionary tables and views. This view is the same as the `DICTIONARY` view.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|  **Column**  |     **Type**     | **Nullable?** | **Description**  |
|------------|----------------|----------|---------|
| TABLE_NAME | VARCHAR2(128)  | NO       | The name of the object.   |
| COMMENTS   | VARCHAR2(4000) | NO       | The text comment on the object. |
