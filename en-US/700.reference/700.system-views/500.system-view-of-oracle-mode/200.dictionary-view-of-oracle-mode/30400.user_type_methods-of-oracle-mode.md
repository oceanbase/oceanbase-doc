# USER_TYPE_METHODS

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Currently, no relevant functions are supported for this view in OceanBase Database.</p>
  </main>

## Purpose

## Purpose This view displays the methods of the object types owned by the current user, excluding the OWNER field. The column information is the same as that in the ALL_TYPE_METHODS view.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
|--------------|--------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE_NAME | VARCHAR2(30) | NO | Type |
| METHOD_NAME  | VARCHAR2(30) | NO             | Method name.                                                                              |
| METHOD_NO    | NUMBER       | NO             | Specifies the method number to distinguish overload methods.                                                              |
| METHOD_TYPE  | VARCHAR2(6)  | NO             | Method type: <li> MAP   <li> ORDER   <li> PUBLIC    |
| PARAMETERS   | NUMBER       | NO             | The number of method parameters.                                                              |
| RESULTS      | NUMBER       | NO             | The number of items returned by the method.                                                                            |
| FINAL       | VARCHAR2(3)  | NO             | Indicates whether this method is final:  <li>YES  <li>NO                                   |
| INSTANTIABLE | VARCHAR2(3)  | NO             | Indicates whether the method is instantiable:  <li>YES  <li>NO                                         |
| OVERRIDING | VARCHAR2(3) | NO | Indicates whether this method overrides a method from a supertype: <li> YES   <li> NO                                       |
| INHERITED    | VARCHAR2(3)  | NO             | Indicates whether this method is inherited from a supertype: <li> YES <li> NO                               |
