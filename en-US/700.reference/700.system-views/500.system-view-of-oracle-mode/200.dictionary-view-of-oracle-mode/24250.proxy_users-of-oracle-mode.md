# PROXY_USERS

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.2 in V4.3.x. </li><li>This view is available starting with V4.2.3 in V4.2.x. </li></ul>
</main>

## Purpose

The `PROXY_USERS` view displays information about proxy users.

## Columns

| **Column** | **Type**  | **Nullable** | **Description**      |
|--------------|-----------|---------------------|---------------|
| PROXY          | VARCHAR2(128) | NO   |The name of the proxy user. |
| CLIENT         | VARCHAR2(128) | NO   |The name of the client user. |
| AUTHENTICATION | VARCHAR2(3)   | NO   |Indicates whether the proxy user needs to provide the client user's credentials:<ul><li>YES: The proxy user needs to provide the client user's credentials.</li><li>NO: The proxy user does not need to provide the client user's credentials.</li></ul> |
| FLAGS          | VARCHAR2(35)  | NO   |Records additional information about the proxy:<ul><li>PROXY MAY ACTIVATE ALL CLIENT ROLES: The proxy user has the permission to activate all client roles.</li><li>NO CLIENT ROLES MAY BE ACTIVATED: The proxy user is prohibited from activating any client roles.</li><li>PROXY MAY ACTIVATE ROLE: The proxy user has the permission to activate specific client roles.</li><li>PROXY MAY NOT ACTIVATE ROLE: The proxy user does not have the permission to activate client roles.</li></ul>Currently, only PROXY MAY ACTIVATE ALL CLIENT ROLES is displayed. |

## Sample query

Query the proxy user information.

```shell
obclient [SYS]> SELECT * FROM SYS.PROXY_USERS WHERE ROWNUM = 1;
```

The query result is as follows:

```shell
+-------+--------+----------------+-------------------------------------+
| PROXY | CLIENT | AUTHENTICATION | FLAGS                               |
+-------+--------+----------------+-------------------------------------+
| U1    | U1     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U3    | U2     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U3    | U1     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U4    | U2     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U4    | U1     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
+-------+--------+----------------+-------------------------------------+
```
