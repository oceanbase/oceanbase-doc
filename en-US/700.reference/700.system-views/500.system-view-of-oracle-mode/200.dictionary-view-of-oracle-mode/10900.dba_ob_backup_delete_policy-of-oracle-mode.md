# DBA_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the cleanup policy for expired or automatic cleanup set for the tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| POLICY_NAME | VARCHAR2(256) | NO | The name of the cleanup policy.  <ul><li>`default`: specifies to automatically clean up backups stored in the `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` parameters of the tenant. </li> <li>`log_only`: specifies to automatically clean up logs stored in the `LOG_ARCHIVE_DEST` parameter of the tenant. </li></ul> |
| RECOVERY_WINDOW | VARCHAR2(64) | NO | The time window for data recovery. Default value: 0 |

## Sample query

Query the cleanup policy of the user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_POLICY;
```

The query result is as follows:

```shell
+-------------+-----------------+
| POLICY_NAME | RECOVERY_WINDOW |
+-------------+-----------------+
| default     | 7d              |
+-------------+-----------------+
1 row in set
```
