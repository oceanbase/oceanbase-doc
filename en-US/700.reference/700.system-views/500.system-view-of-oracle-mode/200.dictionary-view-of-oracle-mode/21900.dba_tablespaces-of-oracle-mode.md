# DBA_TABLESPACES

## Purpose

The `DBA_TABLESPACES` view displays all the tablespaces in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_TABLESPACES
