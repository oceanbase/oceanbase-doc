# DBA_SEGMENTS

## Purpose

Displays the storage information of all segments in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_SEGMENTS
