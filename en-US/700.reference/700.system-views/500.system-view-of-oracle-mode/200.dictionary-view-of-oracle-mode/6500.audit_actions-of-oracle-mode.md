# AUDIT_ACTIONS

## Purpose

The view records the action ID and the corresponding name in the audit records.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

| **Column** |    **Type**     | **Nullable?** |          **Description**          |
|----------|---------------|-----------|--------------------------|
| ACTION   | NUMBER(38)    | NO        | The Action ID in the audit record.         |
| NAME     | VARCHAR2(128) | NO        | The name corresponding to the Action ID in the audit record. |
