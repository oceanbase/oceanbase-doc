# DBA_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.5 for V4.3.x. </li> <li>This view is available starting with V4.2.2 for V4.2.x. </li></ul>
</main>

## Purpose

The `DBA_WR_SQLSTAT` view displays basic performance statistics of SQL statements executed in the current tenant. The statistics with `_DELTA` in the name indicate the incremental values from the last WR snapshot collection to the current time.
