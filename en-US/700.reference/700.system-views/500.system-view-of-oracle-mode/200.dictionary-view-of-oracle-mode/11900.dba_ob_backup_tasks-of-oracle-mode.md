# DBA_OB_BACKUP_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays task-level backup tasks of the current tenant.

## Columns

| Column | Type | Nullable | Description |
|-------------------------------|----------------|-----------------|----------------------------------|
| TASK_ID | NUMBER(38) | NO | The task ID, which corresponds to a backup set. |
| JOB_ID | NUMBER(38) | NO | The ID of the job to which the task belongs. |
| INCARNATION | NUMBER(38) | NO | The number of incarnations after a flashback database operation. |
| BACKUP_SET_ID | NUMBER(38) | NO | The ID of the backup set corresponding to the task. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The start time of the task. |
| END_TIMESTAMP | VARCHAR2(256) | NO | The end time of the task. |
| STATUS | VARCHAR2(4096) | NO | The status of the backup. |
| START_SCN | NUMBER(38)  | NO | The SCN at which the backup starts. |
| END_SCN | NUMBER(38)  | NO | The SCN at which the backup ends. |
| USER_LS_START_SCN | NUMBER(38)  | NO | The SCN of the backup log stream meta data. |
| ENCRYPTION_MODE | VARCHAR2(4096) | YES | The encryption mode. Valid values: <ul><li>None: no encryption is performed. </li><li>Password: only password protection is performed. </li><li>Password Encryption: encryption and password protection are performed. </li><li>Transparent Encryption: TDE is used for encryption. </li><li>Dual mode Encryption: TDE and password protection are used for encryption. </li></ul> </br>Only the None and Password modes are supported. |
| PASSWD | VARCHAR2(4096) | YES | The password. |
| INPUT_BYTES | NUMBER(38) | YES | The number of input bytes. |
| OUTPUT_BYTES | NUMBER(38) | YES | The number of output bytes. |
| OUTPUT_RATE_BYTES | NUMBER | NO | The number of output bytes per second. |
| EXTRA_META_BYTES | NUMBER(38) | YES | The number of extra bytes. |
| TABLET_COUNT | NUMBER(38) | YES | The total number of tablets. |
| FINISH_TABLET_COUNT | NUMBER(38) | YES | The total number of tablets that have been backed up. |
| MACRO_BLOCK_COUNT | NUMBER(38) | YES | The total number of macroblocks. |
| FINISH_MACRO_BLOCK_COUNT | NUMBER(38) | YES | The total number of macroblocks that have been backed up. |
| FILE_COUNT | NUMBER(38) | YES | The total number of backup files. |
| META_TURN_ID | NUMBER(38) | YES | The number of backup meta data rounds. |
| DATA_TURN_ID | NUMBER(38) | YES | The number of backup data rounds. |
| RESULT | NUMBER(38) | YES | The error code of the backup. |
| COMMENT | VARCHAR2(4096) | YES | The description of the error code. |
| PATH | VARCHAR2(4096) | YES | The backup path. |
| MINOR_TURN_ID                 | NUMBER(38)     | NO              | The number of rounds at which the minor data backup ends.      |
| MAJOR_TURN_ID                 | NUMBER(38)     | NO              | The number of rounds at which the major data backup ends.      |
| DATA_PROGRESS                 | NUMBER         | NO              | The backup progress of data. The value is calculated as `Number of macroblocks that have been backed up / Total number of macroblocks`, and is rounded to two decimal places. For example, 87.65 indicates that the backup progress is 87.65%.  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.1. </p></main>    |
| LOG_FILE_COUNT                | NUMBER(38)     | NO              | The total number of archived clog files.  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.1. </p></main>     |
| FINISH_LOG_FILE_COUNT         | NUMBER(38)     | NO              | The number of archived clog files that have been backed up.  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.1. </p></main>     |
| LOG_PROGRESS                  | NUMBER         | NO              | The backup progress of the archived clog files. The value is calculated as `Number of archived clog files that have been backed up / Total number of archived clog files`, and is rounded to two decimal places. For example, 87.65 indicates that the backup progress is 87.65%.    <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.1. </p></main>    |
