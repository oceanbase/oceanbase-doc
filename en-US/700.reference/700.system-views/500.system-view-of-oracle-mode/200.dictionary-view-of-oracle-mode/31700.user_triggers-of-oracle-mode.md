# USER_TRIGGERS

## Purpose

Describes the triggers of the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TRIGGERS

* DBA_TRIGGERS

## Columns

|     **Column**      |     **Type**      | **Nullable?** |                                                                  **Description**                                                                  |
|-------------------|-----------------|----------------|------------------------------------------------------------------------------------------------------------------------------------------|
| TRIGGER_NAME      | VARCHAR2(128)   | NO             | Name of the trigger.                                                 |
| TRIGGER_TYPE      | VARCHAR2(16)    | NO             | Type of the trigger: <li> BEFORE/AFTER   <li> ROW/STMT    |
| TRIGGERING_EVENT  | VARCHAR2(246)   | NO             | Triggering event. Currently, OceanBase Database supports only INSERT, UPDATE, and DELETE.       |
| TABLE_OWNER       | VARCHAR2(128)   | NO             | OWNER of the table, which is valid when the trigger is on a table.                                  |
| BASE_OBJECT_TYPE  | VARCHAR2(18)    | NO             | Type of the trigger object. Currently, OceanBase Database supports only TABLE.                     |
| TABLE_NAME        | VARCHAR2(256)   | NO             | Name of the table, which is valid when the trigger is on a table.                                       |
| COLUMN_NAME       | VARCHAR2(4000)  | NO             | Name of the column. This field is valid only when the trigger object is a nested table.                          |
| REFERENCING_NAMES | VARCHAR2(422)   | NO             | REF name, which is an alias for OLD and NEW.                                  |
| WHEN_CLAUSE       | VARCHAR2(4000)  | YES            | Trigger condition                                                  |
| STATUS            | VARCHAR2(8)     | NO             | Status: <li> ENABLE   <li> DISABLE              |
| DESCRIPTION       | VARCHAR2(65536) | NO             | Description of the trigger, including the name, type, and event information.|
| ACTION_TYPE       | VARCHAR2(11)    | NO             | Type of the action. Currently, OceanBase Database supports only PL/SQL.                 |
| TRIGGER_BODY      | VARCHAR2(65536) | NO             | Statement of the trigger.               |
| CROSSEDITION      | VARCHAR2(7)     | NO             | Cross-version information. This field is currently not supported.                                       |
| BEFORE_STATEMENT  | VARCHAR2(3)     | NO             | YES/NO, indicating whether the trigger contains a section of the specified type before the statement.                  |
| BEFORE_ROW        | VARCHAR2(3)     | NO             | YES/NO, indicating whether the trigger contains a section of the specified type before the row.                   |
| AFTER_ROW         | VARCHAR2(3)     | NO             | YES/NO, indicating whether the trigger contains a section of the specified type after the row.                   |
| AFTER_STATEMENT   | VARCHAR2(3)     | NO             | YES/NO, indicating whether the trigger contains a section of the specified type after the statement.                  |
| INSTEAD_OF_ROW    | VARCHAR2(3)     | NO             | YES/NO, indicating whether the trigger contains a section of the specified type instead of the row.                   |
| FIRE_ONCE         | VARCHAR2(3)     | NO             | This field is currently not supported.                                             |
| APPLY_SERVER_ONLY | VARCHAR2(3)     | NO             | This field is currently not supported.                                             |
