# TENANT_VIRTUAL_GLOBAL_VARIABLE

## Purpose

This view displays information about global variables.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**    |     **Type**      | **Nullable?** | **Description** |
|---------------|-----------------|----------------|--------|
| VARIABLE_NAME | VARCHAR2(128)   | NO             | Variable name    |
| VALUE         | VARCHAR2(65536) | YES            | Variable value    |
