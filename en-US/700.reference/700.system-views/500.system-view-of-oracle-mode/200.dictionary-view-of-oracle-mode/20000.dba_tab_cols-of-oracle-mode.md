# DBA_TAB_COLS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

The `DBA_TAB_COLS` view displays all columns of all tables and views in the database.

The `DBA_TAB_COLS` view differs from [DBA_TAB_COLUMNS](20100.dba_tab_columns-of-oracle-mode.md) in that `DBA_TAB_COLS` displays columns that are marked for quick drop, while `DBA_TAB_COLUMNS` does not.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This view is available only in OceanBase Database in Oracle mode. </p>
</main>

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_TAB_COLS WHERE ROWNUM =1\G
```
