# DBA_RSRC_CONSUMER_GROUPS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.4. </p>
</main>

## Purpose

This view displays information about all resource groups in the current tenant.

## Columns

|       Column        |       Type       | Nullable |                  Description                  |
|-------------------|----------------|------------|--------------------------------------|
| CONSUMER_GROUP_ID | NUMBER(38)     | NO         | The ID of the resource group.                              |
| CONSUMER_GROUP    | VARCHAR2(128)  | NO         | The name of the resource group to which the user is bound.                        |
| CPU_METHOD        | VARCHAR2(128)  | NO         | This parameter is for compatibility. Its value is always `NULL`.                 |
| MGMT_METHOD       | VARCHAR2(128)  | NO         | This parameter is for compatibility. Its value is always `NULL`.                 |
| INTERNAL_USE      | VARCHAR2(3)    | NO         | Indicates whether the resource group is for internal use only. This parameter is for compatibility. Its value is always `NULL`. |
| COMMENTS          | VARCHAR2(2000) | YES        | The remarks about the resource group.                           |
| CATEGORY          | VARCHAR2(128)  | NO         | The category of the resource group. This parameter is for compatibility. Its value is always `NULL`.          |
| STATUS            | VARCHAR2(128)  | NO         | The status of the resource group. This parameter is for compatibility. Its value is always `NULL`.          |
| MANDATORY         | VARCHAR2(3)    | NO         | Indicates whether the resource group is mandatory. This parameter is for compatibility. Its value is always `NULL`.     |

## Sample query

Query information about all resource groups in the user tenant.

```shell
obclient [SYS]> SELECT CONSUMER_GROUP_ID, CONSUMER_GROUP FROM SYS.DBA_RSRC_CONSUMER_GROUPS;
```

The query result is as follows:

```shell
+-------------------+----------------+
| CONSUMER_GROUP_ID | CONSUMER_GROUP |
+-------------------+----------------+
|             10000 | BIG_GROUP      |
|             10001 | SMALL_GROUP    |
+-------------------+----------------+
2 rows in set
```
