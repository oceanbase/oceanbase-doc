# USER_TYPE_ATTRS

## Purpose

Lists the attributes of user-defined types that are available to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_TYPE_ATTRS

* ALL_TYPE_ATTRS

## Columns

|      **Column**      |    **Type**     | **Nullable?** |          **Description**          |
|--------------------|---------------|----------------|--------------------------|
| TYPE_NAME          | VARCHAR2(64)  | NO             | Type name.                      |
| ATTR_NAME          | VARCHAR2(64)  | NO             | Attribute name.                    |
| ATTR_TYPE_MOD      | VARCHAR2(7)   | NO             | Reserved for future use.  |
| ATTR_TYPE_OWNER    | VARCHAR2(128) | NO             | Owner of the attribute type.                 |
| ATTR_TYPE_NAME     | VARCHAR2(324) | NO             | Name of the attribute type.                   |
| LENGTH             | NUMBER(38)    | NO             | Length of the attribute type.                   |
| NUMBER_PRECISION   | NUMBER(38)    | NO             | Length of the numeric attribute type.                |
| SCALE              | NUMBER(38)    | NO             | Number of digits to the right of the decimal point for the numeric attribute type.           |
| CHARACTER_SET_NAME | CHAR(7)       | NO             | Character set of the attribute type.                 |
| ATTR_NO            | NUMBER(38)    | NO             | Attribute number.                     |
| INHERITED          | CHAR(2)       | NO             | Indicates whether the attribute is inherited from a parent type.              |
| CHAR_USED          | CHAR(1)       | YES            | Reserved. The default value is NULL. |
