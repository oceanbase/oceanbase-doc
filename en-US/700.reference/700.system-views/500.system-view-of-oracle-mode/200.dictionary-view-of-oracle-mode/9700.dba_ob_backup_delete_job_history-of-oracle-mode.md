# DBA_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information about backup cleanup tasks executed in a tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| Column | Type | Nullable | Description | | --- | --- | --- | --- | | JOB_ID | NUMBER(38) | NO | The task ID, which is a monotonic increasing value. |
| Column | Type | Nullable | Description | | --- | --- | --- | --- | | INCARNATION | NUMBER(38) | NO | incarnation id. |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | The ID of the tenant that initiated the job. |
| INITIATOR_JOB_ID | NUMBER(38) | NO | ID of the job initiator tenant.
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | The list of tenants that execute cleanup tasks |
| TYPE | VARCHAR2(64) | NO | Cleanup type. Valid value: <ul><li>DELETE OBSOLETE BACKUP : obsolete backup cleanup</li></ul> |
| PARAMETER | VARCHAR2(1024) | NO | The value of the parameter contains the following elements: <li> Automatic cleanup/purge: policy_name = xxx; expired_time = xxx; redundancy:2; backup_copies:1; <li> Manual cleanup of backup set: backup_set_id = 1; dest_id = 1; dest = xxxxx; <li> Manual cleanup of backup piece: dest_round_id = 1; backup_piece_id = 1; dest_id = 1; dest = xxxx; <li> Manual cleanup of backup round: dest_round_id = 1; dest_id = 1; dest = xxxx; <li> Cleanup of all backup information on a destination: dest_id = 1; dest = xxx; |
| COLUMN | TYPE | NULLABLE | DESCRIPTION | | --- | --- | --- | --- | | JOB_LEVEL | VARCHAR2(64) | NO | The task initiator level, which can be USER_TENANT, CLUSTER, or SYS_TENANT. |
| START_TIMESTAMP | VARCHAR2(256) | NO | Current time for the tenant when the task starts |
| END_TIMESTAMP | VARCHAR2(256) | NO | The time on the tenant when the task ends. |
| STATUS | VARCHAR2(64) | NO | Task status: <li>INIT<li>DOING<li>CANCELING<li>CANCELED<li>COMPLETED<li>FAILED |
| TASK_COUNT | NUMBER(38) | YES | the number of backup_set/piece tasks |
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | The number of tasks that have been successfully executed by a backup set or backup piece. |
| RESULT | NUMBER(38) | NO | Error code |
| COMMENT | VARCHAR2(4096) | YES | The description of a task. |

## Sample query

The query result contains the first five records of the tenant backup cleanup tasks performed by the tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOB_HISTORY WHERE ROWNUM <= 5\G
```
