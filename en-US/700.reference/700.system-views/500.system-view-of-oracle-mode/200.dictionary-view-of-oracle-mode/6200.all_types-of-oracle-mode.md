# ALL_TYPES

## Purpose

The view lists the user-defined types available in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_TYPES

* USER_TYPES

## Columns

|     **Column**     |    **Type**     | **Nullable?** |          **Description**           |
|------------------|---------------|----------------|---------------------------|
| OWNER            | VARCHAR2(128) | NO             | The owner of the object.                  |
| TYPE_NAME        | VARCHAR2(64)  | NO             | The name of the type.                       |
| TYPE_OID         | NUMBER(38)    | NO             | The OID of the type.                    |
| TYPECODE         | VARCHAR2(10)  | NO             | The type of the object, such as OBJECT or COLL. |
| ATTRIBUTES       | NUMBER(38)    | NO             | The number of attributes in the type.                  |
| METHODS          | NUMBER(38)    | NO             | The number of methods in the type.                  |
| PREDEFINED       | CHAR(2)       | NO             | Whether the type is a system predefined type.                |
| INCOMPLETE       | CHAR(2)       | NO             | Whether the type is an incomplete type, which has only a name but no methods or attributes.     |
| FINAL            | CHAR(3)       | NO             | Whether the type is final.                   |
| INSTANTIABLE     | CHAR(3)       | NO             | Whether the type is instantiable.                    |
| SUPERTYPE_OWNER  | VARCHAR2(30)  | NO             | The owner of the parent type.                   |
| SUPERTYPE_NAME   | VARCHAR2(30)  | NO             | The name of the parent type.                      |
| LOCAL_ATTRIBUTES | NUMBER(38)    | NO             | The number of local attributes.                     |
| LOCAL_METHODS    | NUMBER(38)    | NO             | The number of local methods.                     |
| TYPEID           | NUMBER(38)    | YES            | The field is not supported. The default value is NULL.     |
