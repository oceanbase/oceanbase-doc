# DBA_AUDIT_SESSION

## Purpose

Displays all audit records for `CONNECT` and `DISCONNECT` operations.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_AUDIT_SESSION
