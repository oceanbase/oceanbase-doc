# DBA_AUDIT_SESSION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in V2.2.77. </p>
</main>

## Purpose

The `DBA_AUDIT_SESSION` view displays all audit records for `CONNECT` and `DISCONNECT` operations.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to the Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Columns

|      **Column**      |           **Type**            | **Nullable?** |                         **Description**                         |
|--------------------|-----------------------------|----------------|--------------------------------------------------------|
| OS_USERNAME        | VARCHAR2(255)               | NO             | This column is not supported. The default value is NULL.             |

## Sample query

Query all audit records related to `CONNECT` and `DISCONNECT`.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_AUDIT_SESSION WHERE ROWNUM =1\G
```
