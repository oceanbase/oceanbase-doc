# DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V4.0.0. </p>
</main>

## Purpose

The `DBA_OB_TENANTS` view displays the basic information of tenants.

* When you query this view from the `sys` tenant, the view displays the basic information of all tenants, including the `sys` tenant, user tenants, and meta tenants. You can determine the tenant type based on the `TENANT_TYPE` column.
* When you query this view from a user tenant, only the information of the current tenant is displayed.

## Columns

| Column | Type | Nullable? | Description |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The ID of the tenant. Valid values: <ul><li>`1`: indicates the ID of the `sys` tenant.</li><li>Other values: indicates the ID of a user tenant or meta tenant.</li></ul> |
| TENANT_NAME | VARCHAR2(128) | NO | The name of the tenant. |
| TENANT_TYPE | VARCHAR2(4) | NO | The type of the tenant. Valid values: <ul><li>`SYS`: indicates the `sys` tenant.</li><li>`USER`: indicates a user tenant.</li><li>`META`: indicates a meta tenant.</li></ul> |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the tenant was created. |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the tenant was last modified. |
| PRIMARY_ZONE | VARCHAR2(128) | YES | The primary zone of the tenant. |
| LOCALITY | VARCHAR2(4096) | YES | The locality of the tenant. |
| PREVIOUS_LOCALITY | VARCHAR2(4096) | YES | The locality before the change. <ul><li>If this column has a valid value, the locality change is not completed.</li><li>The value `NULL` indicates that no locality change was performed.</li></ul> |
| COMPATIBILITY_MODE | VARCHAR2(6) | NO | The compatibility mode. Valid values:<ul><li>`MYSQL` </li><li>`ORACLE` </li></ul> |
| STATUS | VARCHAR2(64) | NO | The current status of the tenant. Valid values: <ul><li>`NORMAL`: The tenant is normal.</li><li>`RESTORE`: The tenant is undergoing physical restore.</li><li>`CREATING`: The tenant is being created.</li><li> `DROPPING`: The tenant is being dropped.</li></ul> |
| IN_RECYCLEBIN | VARCHAR2(3) | NO | Indicates whether the tenant has been dropped and is in the recycle bin. Valid values: <ul><li>`YES`: The tenant is in the recycle bin.</li><li>`NO`: The tenant is not in the recycle bin.</li></ul> |
| LOCKED | VARCHAR2(3) | NO | Indicates whether the tenant is locked. Valid values: <ul><li>`YES`: The tenant is locked.</li><li>`NO`: The tenant is not locked.</li></ul>The value of this column is controlled by the `ALTER TENANT xxx LOCK|UNLOCK` command. |
| TENANT_ROLE | VARCHAR2(100) | NO | The role of the tenant in the cluster. Valid values: <ul><li>`PRIMARY`: indicates a primary tenant.</li><li>`STANDBY`: indicates a standby tenant.</li><li>`RESTORE`: indicates that the tenant is being restored.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| SWITCHOVER_STATUS | VARCHAR2(100) | NO | The switchover status. Valid values: <ul><li>`SWITCHING TO PRIMARY`: The current tenant is being switched to the primary tenant.</li><li>`PREPARE FLASHBACK`: The current tenant is preparing for flashback.</li><li> `FLASHBACK`: The current tenant is in the flashback state.</li><li>`PREPARE SWITCHING TO STANDBY`: The current tenant is preparing for a switchover to a standby tenant.</li><li>`SWITCHING TO STANDBY`: The current tenant is being switched to a standby tenant.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| SWITCHOVER_EPOCH | NUMBER | NO | The unique ID of the switchover or failover.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| SYNC_SCN | NUMBER | NO | The snapshot version that has been synchronized for the current tenant. The value is `NULL` for the `sys` tenant or a meta tenant.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| REPLAYABLE_SCN | NUMBER | NO | The snapshot version that can be replayed for the current tenant. The value is `NULL` for the `sys` tenant or a meta tenant.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| READABLE_SCN | NUMBER | NO | The snapshot version that can be read for the current tenant. The value is `NULL` for the `sys` tenant or a meta tenant.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| RECOVERY_UNTIL_SCN | NUMBER | NO | The maximum system change number (SCN) that can be restored for the current tenant. The value is `NULL` for the `sys` tenant or a meta tenant.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| LOG_MODE | VARCHAR2(100) | NO | The log archiving mode. Valid values: <ul><li>`ARCHIVELOG`: Log archiving is enabled.</li><li>`NOARCHIVELOG`: Log archiving is not enabled.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| ARBITRATION_SERVICE_STATUS | VARCHAR2(64) | NO | The arbitration service status of the tenant. Valid values: <ul><li>`ENABLING`: The arbitration service is being enabled for the tenant.</li><li>`ENABLED`: The arbitration service is enabled for the tenant.</li><li>`DISABLING`: The arbitration service is being disabled for the tenant.</li><li>`DISABLED`: The arbitration service is disabled for the tenant.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.1.0 and later. </p></main> |
| UNIT_NUM | NUMBER(38) | NO | The number of resource units in each zone.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.2.0 and later. </p></main> |
| COMPATIBLE | VARCHAR2(65536) | NO | The compatibility version.<main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.2.0 and later. </p></main> |
| MAX_LS_ID  | NUMBER          | NO | The maximum log stream ID of the tenant. The value is `1` for the `sys` tenant or a meta tenant. For a user tenant, the value varies based on the actual situation. <main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.2.0 and later. </p></main> |
| RESTORE_DATA_MODE  | varchar(128)     | NO | The data restore mode of the tenant. Valid values: <ul><li>`NORMAL`: The tenant is normally created or restored from full data. This is the default value. </li><li>`REMOTE`: The tenant is restored in quick restore mode, and the baseline data is referenced from a remote source.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available in OceanBase Database V4.3.3 and later. </p></main> |

Query the tenant information of a user tenant from the user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TENANTS\G
```
