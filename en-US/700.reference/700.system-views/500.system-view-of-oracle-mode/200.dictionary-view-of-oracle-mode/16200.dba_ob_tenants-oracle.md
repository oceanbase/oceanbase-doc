# DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the basic information of a tenant.

* When you query this view from the system tenant, the information of all tenants is displayed, including the system tenant, user-created tenant (user tenant), and Meta tenant. You can use the `TENANT_TYPE` column to distinguish the types of tenants.
* When you query this view from a user tenant, only the information of this tenant is displayed.

## Columns

| TENANT_NAME | VARCHAR2(128) | NO | Tenant name |

| RECOVERY_UNTIL_SCN | NUMBER | NO | Maximum recovery point for the current tenant. For system tenants and Meta tenants, this column is meaningless and displays as NULL <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| LOG_MODE | VARCHAR2(100) | NO | Archiving mode: <ul><li>  `ARCHIVELOG` : archiving mode is enabled </li><li> `NOARCHIVELOG` : archiving mode is not enabled </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| ARBITRATION_SERVICE_STATUS | VARCHAR2(64) | NO | Arbitration service status of the tenant. For V4.2.5 BP5 and later, this column indicates the minimum value of <code>UNIT_NUM</code> in each zone of the tenant. </li></ul></main>  |
| ZONE_UNIT_NUM_LIST | VARCHAR2(32767) | NO | This column displays the number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |

| MAX_LS_ID  | NUMBER          | NO | The largest log stream ID that has ever existed in the tenant. For the system tenant and Meta tenant, the value is 1. For a user tenant, the value is the actual size. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| RESTORE_DATA_MODE  | VARCHAR2(128)     | NO | The data restore mode of the tenant. Valid values: <ul><li>`NORMAL`: indicates that the tenant is normally created or restored by using full data. </li><li>`REMOTE`: indicates that the tenant is restored by using fast restore, and the data is in a remote reference state. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.2. </p></main> |
| FLASHBACK_LOG_SCN          | NUMBER                            | NO   | The latest log stream ID that has been truncated. | COMMENT                    | VARCHAR2(4096)                    | NO   | The comment. |
