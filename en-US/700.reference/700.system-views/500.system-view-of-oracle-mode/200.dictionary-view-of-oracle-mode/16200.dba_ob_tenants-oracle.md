# DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the basic information of a tenant.

* When you query this view as the system tenant, the information of all tenants, including the system tenant, user-created tenants (user tenants), and the Meta tenant, is displayed. You can use the `TENANT_TYPE` column to identify the type of each tenant.
* When you query this view as a user tenant, only the information of the user tenant is displayed.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID.  <ul><li> 1: the ID of the system tenant.  </li><li> Other values: the ID of a user tenant or a Meta tenant.  </li></ul> |
| TENANT_NAME | VARCHAR2(128) | NO | The tenant name. |
| TENANT_TYPE | VARCHAR2(4) | NO | <ul><li> `SYS`: the system tenant.  </li><li> `USER`: the user tenant.  </li><li> `META`: the Meta tenant.  </li></ul> |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the tenant was created. |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the information was updated. |
| PRIMARY_ZONE | VARCHAR2(128) | YES | The primary zone of the tenant. |
| LOCALITY | VARCHAR2(4096) | YES | The distribution information of tenant replicas. |
| PREVIOUS_LOCALITY | VARCHAR2(4096) | YES | The locality information before the change.  <ul><li> If this value is valid, it indicates that the locality change has not been completed.  </li><li> NULL indicates that no locality change has been performed.  </li></ul> |
| COMPATIBILITY_MODE | VARCHAR2(6) | NO |  <ul><li>`MYSQL`: MySQL compatibility mode.  </li><li>`ORACLE`: Oracle compatibility mode.  </li></ul> |
| STATUS | VARCHAR2(64) | NO | The current tenant status.  <ul><li>`NORMAL`: the normal state.  </li><li>`RESTORE`: the tenant is being physically restored.  </li><li>`CREATING`: the tenant is being created.  </li><li> `DROPPING`: the tenant is being dropped.  </li></ul> |
| IN_RECYCLEBIN | VARCHAR2(3) | NO | Indicates whether the tenant is in the recycle bin.  <ul><li>`YES`: the tenant is in the recycle bin.  </li><li> `NO`: the tenant is not in the recycle bin.  </li></ul> |
| LOCKED | VARCHAR2(3) | NO | Indicates whether the tenant is locked.  <ul><li>`YES`: the tenant is locked.  </li><li>`NO`: the tenant is not locked.  </li></ul> This field is affected by the `ALTER TENANT xxx LOCK|UNLOCK` statement. |
| TENANT_ROLE | VARCHAR2(100) | NO | The cluster role.  <ul><li>`PRIMARY`: the primary tenant.  </li><li>  `STANDBY`: the standby tenant.  </li><li> `RESTORE`: the tenant is being restored.  </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| SWITCHOVER_STATUS | VARCHAR2(100) | NO | The SWITCHOVER status.  <ul><li> `SWITCHING TO PRIMARY`: the standby tenant is switching to the primary tenant.  </li><li>`PREPARE FLASHBACK`: the preparation for Flashback is in progress.  </li><li>`FLASHBACK`: Flashback is in progress.  </li><li>`PREPARE SWITCHING TO STANDBY`: the preparation for switching from the primary tenant to the standby tenant is in progress.  </li><li> `SWITCHING TO STANDBY`: the primary tenant is switching to the standby tenant.  </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| SWITCHOVER_EPOCH | NUMBER | NO | The unique identifier of SWITCHOVER/FAILOVER. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| SYNC_SCN | NUMBER | NO | The snapshot version that is synchronized for the current tenant. For the system tenant and the Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| REPLAYABLE_SCN | NUMBER | NO | The snapshot version that can be replayed for the current tenant. For the system tenant and the Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| READABLE_SCN | NUMBER | NO | The snapshot version that can be read for the current tenant. For the system tenant and the Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| RECOVERY_UNTIL_SCN | NUMBER | NO | The maximum recovery point for the current tenant. For the system tenant and the Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| LOG_MODE | VARCHAR2(100) | NO | The archive mode.  <ul><li>  `ARCHIVELOG`: the archive mode is enabled.  </li><li> `NOARCHIVELOG`: the archive mode is not enabled.  </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| ARBITRATION_SERVICE_STATUS | VARCHAR2(64) | NO | The arbitration service status of the tenant. Valid values:  <ul><li>`ENABLING`: the arbitration service is being enabled.  </li><li>`ENABLED`: the arbitration service is enabled.  </li><li>`DISABLING`: the arbitration service is being disabled.  </li><li>`DISABLED`: the arbitration service is disabled.  </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0.  </p></main> |
| UNIT_NUM           | NUMBER(38) | NO | The minimum value of the `UNIT_NUM` of all zones of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>This column is available starting with V4.2.0. </li>  <li>For V4.6.x, this column is available starting with V4.6.0. The column value changes from the value of the `UNIT_NUM` of all zones of the tenant to the minimum value of the `UNIT_NUM` of all zones of the tenant. </li> <li>For V4.4.x, this column is available starting with V4.4.2. The column value changes from the value of the `UNIT_NUM` of all zones of the tenant to the minimum value of the `UNIT_NUM` of all zones of the tenant. </li> <li>In V4.2.5, for versions earlier than V4.2.5 BP5, this column indicates the value of the `UNIT_NUM` of all zones of the tenant. For V4.2.5 BP5 and later, this column indicates the minimum value of the `UNIT_NUM` of all zones of the tenant. </li></ul></main>  |
| ZONE_UNIT_NUM_LIST | VARCHAR2(32767) | NO | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column is available starting with V4.6.0. </li> <li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |
| COMPATIBLE | VARCHAR2(65536) | NO | The compatibility version. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| MAX_LS_ID  | NUMBER          | NO | The maximum log stream ID that has ever existed for the tenant. For the system tenant and the meta tenant, the value is 1. For a user tenant, the value is the actual size. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| RESTORE_DATA_MODE  | VARCHAR2(128)     | NO | The data restore mode of the tenant. Valid values: <ul><li>`NORMAL`: indicates that the tenant is created normally or restored by using full data. </li><li>`REMOTE`: indicates that the tenant is restored by using remote data. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.2. </p></main> |
| FLASHBACK_LOG_SCN |  NUMBER | NO | The latest log stream ID that has ever existed for the tenant. After a failover, you can execute an operation command to enable the standby tenant to be connected to the new primary tenant. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1. </p></main> |
| COMMENT                    | VARCHAR2(4096)  | NO   | The comment.     |
| PROTECTION_MODE            | VARCHAR2(128)       | NO   | The protection mode of the tenant. Only the `MAXIMUM PERFORMANCE` (maximum performance) protection mode is supported. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main> |
| PROTECTION_LEVEL           | VARCHAR2(128)       | NO   | The protection level of the tenant. Only the `MAXIMUM PERFORMANCE` (maximum performance) protection level is supported. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>  |
