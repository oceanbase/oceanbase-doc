# DBA_OB_SYNC_STANDBY_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.2 BP1. </p>
</main>

## Purpose

The `DBA_OB_SYNC_STANDBY_DEST` view displays the information about the strong synchronization standby tenants of the current tenant.

## Columns

| Column   | Type          | Nullable | Description                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | NUMBER(38)   | NO             | The tenant ID.     |
| DEST_ID   | NUMBER(38)   | NO             | The ID of the strong synchronization standby tenant. Only one strong synchronization standby tenant with ID 0 is allowed for each primary tenant.     |
| VALUE     | CLOB         | NO             | The information about the strong synchronization standby tenant, including the IP address list, username, password, and cluster ID.     |

## Sample query

Query the information about the strong synchronization standby tenants of the current user tenant.

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_SYNC_STANDBY_DEST\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
TENANT_ID: 1004
  DEST_ID: 0
    VALUE: IP_LIST=6.xx.xxx.xx:2881+2882,USER=rep_user@standby_tenant,PASSWORD=*****************************************************************,TENANT_ID=1002,CLUSTER_ID=10002,COMPATIBILITY_MODE=MYSQL,IS_ENCRYPTED=true,net_timeout=20000000,health_check_time=40000000
1 row in set
```
