# USER_PART_INDEXES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays partition information of the partition indexes of the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode of OceanBase Database. </p>
  </main>

## Columns

|         **Column**          |     **Type**     | **Nullable** |**Description**|
|---------------------------|----------------|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX_NAME                | VARCHAR2(128)   | NO             | The name of the partitioned index.                                                                                 |
| TABLE_NAME                | VARCHAR2(128)   | NO             | The name of the table to which the index belongs.                                                                               |
| PARTITIONING_TYPE         | VARCHAR2(9)    | NO             | The partitioning method. <ul><li> HASH  </li><li>RANGE </li><li> LIST </li></ul>  |
| SUBPARTITIONING_TYPE      | VARCHAR2(9)    | NO             | The subpartitioning method. <ul><li>HASH</li><li>RANGE </li><li>LIST</li></ul>    |
| PARTITION_COUNT           | NUMBER         | NO             | The number of partitions in the index.                                                                                 |
| DEF_SUBPARTITION_COUNT    | NUMBER         | NO             | For a composite partitioned index, the number of subpartitions.                                                                      |
| PARTITIONING_KEY_COUNT    | NUMBER         | NO             | The number of partitioning keys.                                                                                  |
| SUBPARTITIONING_KEY_COUNT | NUMBER         | NO             | For a composite partitioned index, the number of subpartitioning keys.                                                                      |
| LOCALITY                  | VARCHAR2(6)    | NO             | Indicates whether the partitioned index is LOCAL or GLOBAL.                                                             |
| ALIGNMENT                 | VARCHAR2(12)   | NO             | Indicates whether the partitioned index is PREFIXED or NON_PREFIXED.                                                  |
| DEF_TABLESPACE_NAME       | VARCHAR2(30)   | NO             | For a LOCAL index, the default tablespace when a table partition is added or split.                                                                |
| DEF_PCT_FREE              | NUMBER         | NO             | This column is not supported. The default value of this column is 0.          |
| DEF_INI_TRANS             | NUMBER         | NO             | This column is not supported. The default value of this column is 0.              |
| DEF_MAX_TRANS             | NUMBER         | NO             | This column is not supported. The default value of this column is 0.                |
| DEF_INITIAL_EXTENT        | VARCHAR2(40)   | NO             | This column is not supported. The default value of this column is NULL.             |
| DEF_NEXT_EXTENT           | VARCHAR2(40)   | NO             | This column is not supported. The default value of this column is NULL.          |
| DEF_MIN_EXTENTS           | VARCHAR2(40)   | NO             | This column is not supported. The default value of this column is NULL.            |
| DEF_MAX_EXTENTS           | VARCHAR2(40)   | NO             | This column is not supported. The default value of this column is NULL.       |
| DEF_MAX_SIZE              | VARCHAR2(40)   | NO             | This column is not supported. The default value of this column is NULL.       |
| DEF_PCT_INCREASE          | VARCHAR2(40)   | NO             | This column is not supported. The default value of this column is NULL.       |
| DEF_FREELISTS             | NUMBER         | NO             | This column is not supported. The default value of this column is 0.         |
| DEF_FREELIST_GROUPS       | NUMBER         | NO             | This column is not supported. The default value of this column is 0.            |
| DEF_LOGGING               | VARCHAR2(7)    | NO             | This column is not supported. The default value of this column is NULL.          |
| DEF_BUFFER_POOL           | VARCHAR2(7)    | NO             | This column is not supported. The default value of this column is NULL.           |
| DEF_FLASH_CACHE           | VARCHAR2(7)    | NO             | This column is not supported. The default value of this column is NULL.            |
| DEF_CELL_FLASH_CACHE      | VARCHAR2(7)    | NO             | This column is not supported. The default value of this column is NULL.             |
| DEF_PARAMETERS            | VARCHAR2(1000) | NO             | This column is not supported and is NULL by default. |
| INTERVAL                  | VARCHAR2(1000) | NO             | This column is not supported and is `NO` by default.  |
| AUTOLIST                  | VARCHAR2(3)    | NO         | Indicates whether the local index is automatically partitioned by list partitioning: <ul><li>YES</li><li>NO</li></ul>     |
| INTERVAL_SUBPARTITION     | VARCHAR2(1000) | NO         | This column is not supported and is NULL by default.  |
| AUTOLIST_SUBPARTITION     | VARCHAR2(1000) | NO         | This column is not supported and is NULL by default.  |

## Sample query

Query the partition information of the partitioned index `TBL1_H_IDX1` that belongs to the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_PART_INDEXES WHERE INDEX_NAME='TBL1_H_IDX1'\G
```
