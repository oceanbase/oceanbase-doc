# DBA_SCHEDULER_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.3. </p>
</main>

## Purpose

This view displays the information about the scheduler jobs that the current user can access.

## Columns

|      Column |    Type       | Nullable|    Description    |
|--------------|---------------|---------------|------------|
| OWNER | VARCHAR2(128) | NO | The owner of the job. |
| JOB_NAME | VARCHAR2(128) | NO | The name of the job. |
| JOB_SUBNAME | VARCHAR2(128) | NO | The subname of the job. |
| JOB_STYLE | VARCHAR2(17) | YES | Default value is NULL. |
| JOB_CREATOR | VARCHAR2(128) | NO | The creator of the job. |
| CLIENT_ID | VARCHAR2(65) | NO | The client identifier of the user who created the job. |
| GLOBAL_UID | VARCHAR2(33) | NO | The global user identifier of the user who created the job. |
| PROGRAM_OWNER | VARCHAR2(4000) | NO | The owner of the program associated with the job. |
| PROGRAM_NAME | VARCHAR2(4000) | YES | The name of the program associated with the job. |
| JOB_TYPE | VARCHAR2(16) | YES | The type of the job operation: <ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul> |
| JOB_ACTION | VARCHAR2(4000) | YES | The inline job operation. |
| NUMBER_OF_ARGUMENTS | NUMBER | YES | The number of inline parameters for the job. |
| SCHEDULE_OWNER | VARCHAR2(4000) | NO | The owner of the schedule used by the job. |
| SCHEDULE_NAME | VARCHAR2(4000) | NO | The name of the schedule used by the job. |
| SCHEDULE_TYPE | VARCHAR2(12) | NO | Default value is NULL. |
| START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | The original scheduled start date of the job. |
| REPEAT_INTERVAL | VARCHAR2(4000) | YES | The inline PL/SQL expression or calendar string for the schedule. |
| EVENT_QUEUE_OWNER | VARCHAR2(128) | NO | The owner of the source queue where events are triggered. |
| EVENT_QUEUE_NAME | VARCHAR2(128) | NO | The name of the source queue where events are triggered. |
| EVENT_QUEUE_AGENT | VARCHAR2(523) | NO | The name of the AQ agent used by the user on the event source queue. |
| EVENT_CONDITION | VARCHAR2(4000) | NO | The subscription rule for events on the source queue. |
| EVENT_RULE | VARCHAR2(261) | NO | The name of the rule used by the coordinator to trigger event-based jobs. |
| FILE_WATCHER_OWNER | VARCHAR2(261) | NO | The owner of the file watcher on which the job is based. |
| FILE_WATCHER_NAME | VARCHAR2(261) | NO | The name of the file watcher on which the job is based. |
| END_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | The date on which the job will no longer run. |
| JOB_CLASS | VARCHAR2(128) | YES | The name of the job category associated with the job. |
| ENABLED | VARCHAR2(5) | YES | Indicates whether the job is enabled: <ul><li>TRUE  </li><li>FALSE </li></ul> |
| AUTO_DROP | VARCHAR2(5) | YES | Indicates whether the job is deleted after it is completed: <ul><li>TRUE  </li><li>FALSE </li></ul>  |
| RESTART_ON_RECOVERY | VARCHAR2(5) | NO | Default value is NULL. |
| RESTART_ON_FAILURE | VARCHAR2(5) | NO | Default value is NULL. |
| STATE | VARCHAR2(15) | YES | The current state of the job: <ul><li>DISABLED</li><li>RETRY SCHEDULED</li><li>SCHEDULED</li><li>BLOCKED</li><li>RUNNING</li><li>COMPLETED</li><li>BROKEN</li><li>FAILED</li><li>REMOTE</li><li>RESOURCE_UNAVAILABLE</li><li>SUCCEEDED</li><li>CHAIN_STALLED </li></ul>|
| JOB_PRIORITY | NUMBER | NO | The priority of the job relative to other jobs of the same type. |
| RUN_COUNT | NUMBER | YES | The number of times the job has run. |
| MAX_RUNS | NUMBER | NO | The maximum number of times the job is scheduled to run. |
| FAILURE_COUNT | NUMBER | YES | The number of times the job has failed. |
| MAX_FAILURES | NUMBER | NO | The maximum number of times the job is allowed to fail before being marked as broken. |
| RETRY_COUNT | NUMBER | YES | The number of times the job has been retried. |
| LAST_START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | The last date on which the job started running. |
| LAST_RUN_DURATION | INTERVAL DAY (9) TO SECOND (6) | NO | The time spent completing the job during the last run. |
| NEXT_RUN_DATE | TIMESTAMP(6) WITH TIME ZONE | NO | The next date on which the job is scheduled to run. |
| SCHEDULE_LIMIT | INTERVAL DAY (3) TO SECOND (0) | NO | The time at which the job will be rescheduled if it has not run. |
| MAX_RUN_DURATION | INTERVAL DAY (3) TO SECOND (0) | NO | The maximum allowed duration for the job. |
| LOGGING_LEVEL | VARCHAR2(11) | NO | Default value is NULL. |
| STORE_OUTPUT | VARCHAR2(5) | NO | Default value is NULL. |
| STOP_ON_WINDOW_CLOSE | VARCHAR2(5) | NO | Default value is NULL. |
| INSTANCE_STICKINESS | VARCHAR2(5) | NO | Default value is NULL|
| RAISE_EVENTS | VARCHAR2(4000) | NO | Default value is NULL. |
| SYSTEM | VARCHAR2(5) | NO | Default value is NULL. |
| JOB_WEIGHT | NUMBER | NO | The weight of the job, used to specify the priority of the job during scheduling. |
| NLS_ENV | VARCHAR2(4000) | YES | The national language environment settings for the job. |
| SOURCE | VARCHAR2(128) | NO | The source code or script of the job. |
| NUMBER_OF_DESTINATIONS | NUMBER | NO | The number of destinations for the job. |
| DESTINATION_OWNER | VARCHAR2(261) | NO | The owner of the destination for the job. |
| DESTINATION | VARCHAR2(261) | NO | The destination for the job, which is the object or location where the job is executed. |
| CREDENTIAL_OWNER | VARCHAR2(128) | NO | The owner of the credential. |
| CREDENTIAL_NAME | VARCHAR2(128) | NO | The name of the credential. |
| INSTANCE_ID | NUMBER | YES | The ID of the instance on which the user requests the job to run. |
| DEFERRED_DROP | VARCHAR2(5) | NO | Indicates whether the job is to be dropped with delay. |
| ALLOW_RUNS_IN_RESTRICTED_MODE | VARCHAR2(5) | NO | Indicates whether the job is allowed to run in restricted mode. |
| COMMENTS | VARCHAR2(4000) | YES | The comments or description of the job. |
| FLAGS | NUMBER | NO | The flags of the job. |
| RESTARTABLE | VARCHAR2(5) | NO | Indicates whether the job is restartable. |
| CONNECT_CREDENTIAL_OWNER | VARCHAR2(128) | NO | The owner of the connection credential. |
| CONNECT_CREDENTIAL_NAME | VARCHAR2(128) | NO | The name of the connection credential. |
| THIS_DATE                     | DATETIME(6)  | YES  | The start time of the current scheduling. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>    |
| USER_ID                       | BIGINT(20)   | YES  | The `user_id` of the JOB. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>   |
| DATABASE_ID                   | BIGINT(20)   | YES  | The `database_id` of the JOB. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>    |
| THIS_EXEC_DATE                | DATETIME(6)  | YES  | The start time of the current execution. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>    |
| THIS_EXEC_ADDR                | VARCHAR(128) | YES  | The address of the OBServer node where the current execution is performed. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>   |
| THIS_EXEC_TRACE_ID            | VARCHAR(128) | YES  | The `trace_id` of the current execution. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>    |
