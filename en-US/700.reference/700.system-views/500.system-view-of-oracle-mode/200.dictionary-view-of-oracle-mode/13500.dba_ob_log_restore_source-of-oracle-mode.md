# DBA_OB_LOG_RESTORE_SOURCE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore sources of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| ID | NUMBER(38) | NO | The ID of the log restore source. |
| TYPE | VARCHAR2(32) | NO | The type of the log restore source. Valid values: <ul><li>`SERVICE`: a network log restore source.  </li><li>`LOCATION`: an archive log restore source. </li><li>`RAWPATH`: a user-defined log restore source. </li></ul> |
| VALUE | CLOB | NO | The entry address of the log restore source. <ul><li>For a SERVICE type: the entry address of the primary tenant, for example, "IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,COMPATIBILITY_MODE=ORACLE,IS_ENCRYPTED=true".  </li><li>For a LOCATION type: the log archive directory, for example, "file:///data/1/archive/". </li><li>For a RAWPATH type: the user-defined directory. </li></ul>|
| RECOVERY_UNTIL_SCN | NUMBER(38) | NO | The maximum log SCN. The value can be INT64_MAX or a positive integer. |

## Sample query

Query the log restore sources of the current tenant in the user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LOG_RESTORE_SOURCE;
```

The query result is as follows:

