# DBA_OB_BACKUP_DELETE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about the `backup_set`/`backup_piece` cleanup tasks that are being executed in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | The task group ID, used to identify a group of tasks. |
| INCARNATION | NUMBER(38) | NO | The incarnation ID. |
| JOB_ID | NUMBER(38) | NO | The task ID, corresponding to the JOB table. |
| TASK_TYPE | VARCHAR2(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: Clean up `backup_set`. </li><li>`BACKUP PIECE`: Clean up `backup_piece`. </li></ul> |
| ID | NUMBER(38) | NO | The task ID, including backup_set and piece. |
| ROUND_ID | NUMBER(38) | NO | The dest_round_id of the piece. For the cleanup of a backup_set, the ROUND_ID is 0. |
| DEST_ID | NUMBER(38) | NO | The destination ID of the backup destination. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The task start time. |
| END_TIMESTAMP | VARCHAR2(256) | NO | The task end time. |
| STATUS | VARCHAR2(64) | NO | The task status. Valid values: <ul><li>`INIT`: The task is being initialized. </li><li>`DOING`: The task is being executed. </li><li>`CANCELING`: The task is being canceled. </li><li>`COMPLETED`: The task is successfully executed. </li><li>`FAILED`: The task execution failed. </li><li>`CANCELED`: The task was successfully canceled. </li></ul> |
| TOTAL_TASK_COUNT  | NUMBER(38) | YES | The number of subtasks. <ul><li>In SN mode, this column indicates the total number of ls_task. </li><li>In SS mode, for a log archive piece, this column indicates the total number of ls_task. For a data backup set, this column indicates the total number of macro_task. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this column is available starting with V4.6.0. </p></main>|
| FINISH_TASK_COUNT | NUMBER(38) | YES | The number of successfully completed subtasks. <ul><li>In SN mode, this column indicates the number of completed ls_task. </li><li>In SS mode, for a log archive piece, this column indicates the number of completed ls_task. For a data backup set, this column indicates the number of completed macro_task. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this column is available starting with V4.6.0. </p></main> |
| RESULT | NUMBER(38) | YES | The error code. |
| COMMENT | VARCHAR2(4096) | YES | Comments. |
| PATH | VARCHAR2(1024) | NO | The backup destination of the backup_set or backup_piece. |

## Sample query

Query the information about the `backup_set` or `backup_piece` cleanup tasks that are being executed in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_TASKS\G
```
