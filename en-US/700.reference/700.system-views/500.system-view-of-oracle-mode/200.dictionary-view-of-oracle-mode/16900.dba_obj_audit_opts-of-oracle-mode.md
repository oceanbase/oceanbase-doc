# DBA_OBJ_AUDIT_OPTS

## Purpose

The view records the detailed configurations of object-level auditing.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views
