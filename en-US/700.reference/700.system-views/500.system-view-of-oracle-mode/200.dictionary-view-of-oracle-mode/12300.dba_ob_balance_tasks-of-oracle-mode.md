# DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing tasks that are currently being executed in the current tenant. A tenant can have multiple load balancing tasks running at the same time, and these tasks (TASK) belong to the same load balancing job (JOB).

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | The ID of the load balancing task. |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the task was created. |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the information was updated. |
| TASK_TYPE | VARCHAR2(64) | NO | The type of the task. Valid values: <ul><li>`LS_SPLIT`: Log stream split.  </li><li>`LS_ALTER`: Modify the log stream attributes. </li><li>`LS_MERGE`: Log stream merge. </li><li>`LS_TRANSFER`: Log stream transfer. </li></ul>|
| SRC_LS | NUMBER(38) | NO | The source log stream (the log data stream generated from the data source). |
| DEST_LS | NUMBER(38) | NO | The destination log stream. |
| PART_LIST | CLOB | YES | The list of partitions, including user table partitions and global index partitions. |
| FINISHED_PART_LIST | CLOB | YES | The list of partitions that have been balanced. |
| PART_COUNT | NUMBER(38) | YES | The number of partitions in the partition list. |
| FINISHED_PART_COUNT | NUMBER(38) | YES | The number of partitions that have been balanced. |
| LS_GROUP_ID | NUMBER(38) | NO | The ID of the log stream group. |
| STATUS | VARCHAR2(64) | NO | The status of the task. Valid values: <ul><li>`INIT`: Task creation.  </li><li>`CREATE_LS`: Create a log stream. </li><li>`ALTER_LS`: Modify the log stream attributes. </li> <li>`TRANSFER`: Transfer between log streams. </li><li>`SET_LS_MERGING`: Merge a log stream. </li><li>`DROP_LS`: Drop a log stream. </li><li>`COMPLETED`: The task was executed successfully. </li><li>`CANCELED`: The task was canceled. </li></ul>|
| PARENT_LIST | VARCHAR2(1024) | YES | The list of parent tasks. |
| CHILD_LIST | VARCHAR2(1024) | YES | The list of child tasks. |
| CURRENT_TRANSFER_TASK_ID | NUMBER(38) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | NUMBER(38) | NO | The ID of the job to which the current task belongs. |
| COMMENT | CLOB | YES | The comment. |
| BALANCE_STRATEGY         | VARCHAR2(64)   | YES | The balance strategy corresponding to the balance task. Valid values: <ul><li>`LS balance by migrate`: Migrate-based load balancing.  </li><li>`LS balance by alter`: Alter-based load balancing. </li><li>`LS balance by expand`: Expand-based load balancing. </li><li>`LS balance by shrink`: Shrink-based load balancing. </li><li>`partition balance`: Partition-based load balancing. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this column is available starting with V4.3.2. For V4.2.x, this column is available starting with V4.2.4. </p></main>   |

## Sample query

Query the load balancing tasks that are currently being executed in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_TASKS\G
```
