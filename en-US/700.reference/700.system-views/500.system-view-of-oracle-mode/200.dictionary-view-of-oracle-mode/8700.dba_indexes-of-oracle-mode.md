# DBA_INDEXES

Purpose
-----------

The `DBA_INDEXES` view displays the indexes on all tables in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>

References
-------------

* `USER_INDEXES`

* `ALL_INDEXES`
