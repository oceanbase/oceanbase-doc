# ALL_COLL_TYPES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

This view lists the user-defined collection types available in the database. It has the same columns as the `DBA_COLL_TYPES` view.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is applicable only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|      **Column**      |    **Type**     | **Nullable** |   **Description**    |
|--------------------|---------------|----------------|---------------------------------------------|
| OWNER              | VARCHAR2(128) | NO             | The owner of the object.    |
| TYPE_NAME          | VARCHAR2(64)  | NO             | The name of the type.         |
| COLL_TYPE          | VARCHAR2(10)  | NO             | The collection type. Valid values: <ul><li>VARYING   </li><li> ARRAY   </li><li> NESTED TABLE</li></ul>    |
| UPPER_BOUND        | NUMBER(38)    | YES            | The maximum size of the collection, for VARYING.                                                                           |
| ELEM_TYPE_MOD      | VARCHAR2(7)   | YES            | This column is not supported. The default value is NULL.                                                                         |
| ELEM_TYPE_OWNER    | VARCHAR2(128) | YES            | The owner of the element type.  |
| ELEM_TYPE_NAME     | VARCHAR2(324) | YES            | The name of the element type.     |
| LENGTH             | NUMBER(38)    | YES            | The length of the element type.    |
| NUMBER_PRECISION   | NUMBER(38)    | YES            | The precision of the element type.    |
| SCALE              | NUMBER(38)    | YES            | The length of the data to the right of the decimal point for the element type.                                                                               |
| CHARACTER_SET_NAME | CHAR(7)       | YES            | The character set of the element type.   |
| ELEM_STORAGE       | CHAR(3)       | YES            | This column is not supported. The default value is NULL.                                                                         |
| NULLS_STORED       | CHAR(1)       | YES            | This column is not supported. The default value is NULL.                                                                         |
