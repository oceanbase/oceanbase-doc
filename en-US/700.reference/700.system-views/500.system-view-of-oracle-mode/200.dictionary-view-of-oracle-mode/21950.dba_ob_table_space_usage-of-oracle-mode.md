# DBA_OB_TABLE_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view was introduced in OceanBase Database V4.3.5. </p>
</main>

## Purpose

The `DBA_OB_TABLE_SPACE_USAGE` view is used to view the logical size of tables in a tenant and the size of the leader replica in a multi-replica environment.

## Columns

| **Column** | **Type**  | **Nullable?** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| TABLE_ID      | bigint(20)    | NO   | The ID of the table.     |
| DATABASE_NAME | varchar(128)  | NO   | The name of the database.     |
| TABLE_NAME    | varchar(256)  | NO   | The name of the table.     |
| OCCUPY_SIZE   | decimal(42,0) | NO   | The size of the data that is compressed and written to disk, in bytes. For example, 2 GB of data is compressed to 1 MB, which occupies one macroblock. In this case, the value of `OCCUPY_SIZE` is 1 MB.     |
| REQUIRED_SIZE | decimal(42,0) | NO   | The size of the space occupied by the data that is compressed and written to disk, in bytes. For example, 2 GB of data is compressed to 1 MB, which occupies one macroblock. In this case, the value of `REQUIRED_SIZE` is 2 MB (the default size of a macroblock is 2 MB).     |

## Sample query

In SN mode, a user tenant queries the sizes of all user tables in the tenant.

```shell
obclient [test]> SELECT * FROM SYS.DBA_OB_TABLE_SPACE_USAGE WHERE ROWNUM <= 3;
```

The query result is as follows:

```shell
+----------+---------------+--------------------------------+-------------+---------------+
| TABLE_ID | DATABASE_NAME | TABLE_NAME                     | OCCUPY_SIZE | REQUIRED_SIZE |
+----------+---------------+--------------------------------+-------------+---------------+
|   500011 | test          | wide_table_row_storage2        |  4495925120 |    4613763072 |
|   500012 | test          | wide_table_column_storage2     |  3915023145 |    4195397632 |
|   500014 | test          | wide_table_row_column_storage2 |  8410964107 |    9805275136 |
+----------+---------------+--------------------------------+-------------+---------------+
3 rows in set
```
