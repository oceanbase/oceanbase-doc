# DBA_ROLE_PRIVS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view describes the roles granted to all users and the roles in the database.

<main id="notice" >
<h4>Applicability</h4>
<p>This view is applicable only to OceanBase Database in Oracle mode. </p>
</main>

## Columns

|   **Column**   |    **Type**    | **Nullable** |      **Description**       |
|--------------|--------------|----------------|-------------------|
| GRANTEE      | VARCHAR2(30) | NO             | The name of the user or role that receives the grant.     |
| GRANTED_ROLE | VARCHAR2(30) | NO             | The name of the granted role.             |
| ADMIN_OPTION | VARCHAR2(3)  | NO             | Indicates whether the grant includes the ADMIN option. |
| DEFAULT_ROLE | VARCHAR2(3)  | NO             | Indicates whether the role is specified as the default role for the user. |

## Sample query

* View the roles owned by the `USER2` user.

  ```shell
  obclient [SYS]> SELECT * FROM DBA_ROLE_PRIVS WHERE GRANTEE ='USER2';
  ```

  The query result is as follows:

  ```shell
  +---------+--------------+--------------+--------------+
  | GRANTEE | GRANTED_ROLE | ADMIN_OPTION | DEFAULT_ROLE |
  +---------+--------------+--------------+--------------+
  | USER2   | ROLE1        | NO           | YES          |
  +---------+--------------+--------------+--------------+
  1 row in set
  ```

* View the roles owned by the `ROLE1` role.

  ```shell
  obclient [SYS]> SELECT * FROM DBA_ROLE_PRIVS WHERE GRANTEE ='ROLE1';
  ```

  The query result is as follows:

  ```shell
  +---------+--------------+--------------+--------------+
  | GRANTEE | GRANTED_ROLE | ADMIN_OPTION | DEFAULT_ROLE |
  +---------+--------------+--------------+--------------+
  | ROLE1   | ROLE2        | NO           | YES          |
  +---------+--------------+--------------+--------------+
  1 row in set
  ```
