# DBA_ROLE_PRIVS

## Purpose

Describes the roles granted to all users and the roles granted to other roles.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

USER_ROLE_PRIVS

## Columns

|   **Column**   |    **Type**    | **Nullable?** |      **Description**       |
|--------------|--------------|----------------|-------------------|
| GRANTEE      | VARCHAR2(30) | NO             | The name of the user or role that receives the grant.     |
| GRANTED_ROLE | VARCHAR2(30) | NO             | The name of the granted role.             |
| ADMIN_OPTION | VARCHAR2(3)  | NO             | Indicates whether the grant is with ADMIN OPTION. |
| DEFAULT_ROLE | VARCHAR2(3)  | NO             | Indicates whether the role is specified as the default role for the user. |
