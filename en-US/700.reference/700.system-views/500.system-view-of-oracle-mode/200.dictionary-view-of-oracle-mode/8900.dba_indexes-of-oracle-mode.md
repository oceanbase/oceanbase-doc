# DBA_INDEXES

## Purpose

The `DBA_INDEXES` view displays information about indexes for all tables in a database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns
