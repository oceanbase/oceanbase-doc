# DBA_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1 BP2. </p>
</main>

## Purpose

The `DBA_OB_TRANSFER_PARTITION_TASK_HISTORY` view displays the history of executed Transfer Partition tasks for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID          | NUMBER(38)   | NO   | The unique identifier of the Transfer Partition task.   |
| CREATE_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The creation time.   |
| FINISH_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The task completion time, including successful and canceled tasks.   |
| TABLE_ID         | NUMBER(38)   | NO   | The ID of the table where the partition to be transferred is located.   |
| OBJECT_ID        | NUMBER(38)   | NO   | The `OBJECT_ID` of the partition to be transferred.   |
| DEST_LS          | NUMBER(38)   | NO   | The log stream of the destination.   |
| BALANCE_JOB_ID   | NUMBER(38)   | NO   | The ID of the load balancing job associated with the task.   |
| TRANSFER_TASK_ID | NUMBER(38)   | NO   | The ID of the Transfer task associated with the task.   |
| STATUS           | VARCHAR2(64) | NO   | The task status. Valid values: <ul><li>COMPLETED: The task is completed. </li><li>FAILED: The task failed. </li></ul>   |
| COMMENT          | CLOB         | YES  | The comment.   |

## Sample query

```shell
obclient> SELECT * FROM SYS.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY;
```
