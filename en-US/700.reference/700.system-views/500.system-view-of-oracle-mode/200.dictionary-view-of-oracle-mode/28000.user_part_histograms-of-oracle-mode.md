# USER_PART_HISTOGRAMS

## Purpose

The `USER_PART_HISTOGRAMS` view displays the histogram information of the primary partitions of the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_PART_HISTOGRAMS

* DBA_PART_HISTOGRAMS

## Columns

|           Column            |       Type       | Whether null |      Description       |
|---------------------------|----------------|------------|---------------|
| TABLE_NAME                | VARCHAR2(128)  | NO         | Name of the table that contains the histogram.       |
| PARTITION_NAME            | VARCHAR2(128)  | NO         | Name of the primary partition that contains the histogram.    |
| COLUMN_NAME               | VARCHAR2(128)  | NO         | Name of the column that contains the histogram.       |
| ENDPOINT_NUMBER           | NUMBER         | NO         | Cumulative frequency of the bucket.  |
| ENDPOINT_VALUE            | NUMBER         | NO         | Normalized value of the bucket endpoint. |
| ENDPOINT_ACTUAL_VALUE     | VARCHAR2(4000) | NO         | Value of the bucket endpoint.    |
| ENDPOINT_ACTUAL_VALUE_RAW | VARCHAR2(4000) | NO         | Binary value of the bucket endpoint. |
| ENDPOINT_REPEAT_COUNT     | NUMBER         | NO         | Frequency of the bucket endpoint value. |
