# DBA_VIEWS

## Purpose

Displays all views in the database.

## Related views

* ALL_VIEWS

* USER_VIEWS

## Columns

|    **Column**     |     **Type**     | **Nullable?** |        **Description**         |
|-----------------|----------------|----------------|-----------------------|
| OWNER           | VARCHAR2(128)  | NO             | The USER that owns the view.         |
| VIEW_NAME       | VARCHAR2(128)  | NO             | The name of the view.                  |
| TEXT_LENGTH     | NUMBER         | NO             | The length of the view definition.                |
| TEXT            | VARCHAR2(4000) | NO             | The view definition.                 |
| OID_TEXT_LENGTH | NUMBER         | NO             | Not supported. The default value is NULL. |
| OID_TEXT        | VARCHAR2(4000) | NO             | Not supported. The default value is NULL. |
| VIEW_TYPE       | VARCHAR2(30)   | NO             | Not supported. The default value is NULL. |
| SUPERVIEW_NAME  | VARCHAR2(30)   | NO             | Not supported. The default value is NULL. |
| EDITIONING_VIEW | VARCHAR2(1)    | NO             | Not supported. The default value is NULL. |
| READ_ONLY       | VARCHAR2(1)    | NO             | Not supported. The default value is NULL. |
