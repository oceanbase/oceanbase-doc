# DBA_AUDIT_EXISTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in OceanBase Database V2.2.77. </p>
</main>

## Purpose

The `DBA_AUDIT_EXISTS` view displays the audit trail entries generated by the `AUDIT EXISTS` and `AUDIT NOT EXISTS` statements.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to the Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Sample query

Query the audit entries generated by the `AUDIT EXISTS` and `AUDIT NOT EXISTS` statements.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_AUDIT_EXISTS WHERE ROWNUM =1\G
```
