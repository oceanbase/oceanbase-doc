# DBA_OB_LS_LOCATIONS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the distribution of log stream (LS) replicas in the current tenant.

## Columns

|     Column     |      Type       | Nullable |                                                                          Description                                                                           |
|--------------|---------------|------------|-------------------------------------|
| CREATE_TIME        | VARCHAR2(19)    | NO         | The creation time.                                                              |
| MODIFY_TIME        | VARCHAR2(19)    | NO         | The modification time.                                                              |
| SVR_IP       | varchar2(46)   | NO         | The IP address of the server.                                                          |
| SVR_PORT     | NUMBER    | NO         | The port number of the server.                                                             |
| SQL_PORT     | NUMBER    | NO         | The SQL port number.                                                            |
| ZONE         | varchar2(128)  | NO         | The zone name.                                                            |
| ROLE         | varchar2(8)    | NO         | The replica role:<ul><li>`LEADER`   </li><li> `FOLLOWER` </li></ul>    |
| MEMBER_LIST  | varchar2(4480) | NO         | The list of replicas separated by commas. When the role is `LEADER`, this field is valid. The format of a single replica is `svr_ip:svr_port:timestamp`. The fields in this format are described as follows:<ul><li>`svr_ip`: the IP address of the server where the replica is located. </li> <li>`svr_port`: the port number of the server where the replica is located. </li> <li>`timestamp`: the time when the replica joined the member list. The default value is `1`. This value changes when a replica is added or migrated. </li></ul></br> Example: 172.xx.xxx.xxx:2882:1</li> <li>When the role is not `LEADER`, this field is `NULL`. </li></ul>    |
| PAXOS_REPLICA_NUMBER       | NUMBER    | NO         | The number of Paxos quorum replicas. When the role is `LEADER`, this field is valid. Otherwise, it is `NULL`.                       |
| REPLICA_TYPE | varchar2(18)   | NO         | The replica type:<ul><li> `FULL`: a full-featured replica </li> <li> `READONLY`: a read-only replica </li>  <li>`COLUMNSTORE`: a columnstore replica</li></ul>    |
| LEARNER_LIST | CLOB           | YES  | The list of read-only replicas of the current log stream, separated by commas. The format of a single replica is `svr_ip:svr_port:timestamp:flag`. The fields in this format are described as follows:<ul><li>`svr_ip`: the IP address of the server where the replica is located. </li> <li>`svr_port`: the port number of the server where the replica is located. </li> <li>`timestamp`: the time when the replica joined. The default value is `1`. This value changes when a replica is added or migrated. </li> <li>`flag`: indicates whether the replica is being migrated. `0` indicates that the replica is not being migrated. `2` indicates that the replica is being migrated. </li></ul></br> Example: 172.xx.xxx.xxx:2882:1:0<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| REBUILD      | VARCHAR2(5)    | NO   | Indicates whether the replica is being rebuilt. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1. </p></main>|

Query the distribution of log stream replicas in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_LOCATIONS;
```
