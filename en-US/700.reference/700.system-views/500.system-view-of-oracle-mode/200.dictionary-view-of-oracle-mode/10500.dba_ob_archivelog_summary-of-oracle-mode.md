# DBA_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of all log archives in the current and historical logs of the tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | The path ID. The system assigns a unique ID to each path. |
| ROUND_ID | NUMBER(38) | NO | The ID of the round of full clog backup data. |
| INCARNATION | NUMBER(38) | NO | The number of incarnations after flashback database. |
| DEST_NO | NUMBER(38) | NO | The ID of the log_archive_dest_n parameter. For example, the dest_no of the log_archive_dest parameter is 0, and the dest_no of the log_archive_dest_1 parameter is 1. |
| STATUS | VARCHAR2(64) | NO | The status of the log archive. Valid values: <ul><li>`PREPARE`: The system is preparing to archive data starting from the `START_SCN` value. </li> <li>`BEGINNING`: The system is starting to archive data.  </li> <li>`DOING`: The system is archiving data. </li><li> `INTERRUPTED`: The log archive is interrupted and requires manual intervention. </li><li>`STOP`: The log archive is stopped.  </li><li>`STOPPING`: The system is stopping the log archive.  </li><li>`SUSPENDING`: The system is suspending the log archive.  </li><li>`SUSPEND`: The log archive is suspended.  </li></ul> |
| START_SCN | NUMBER(38) | NO | The start point of the backup. |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | The start point of the backup, converted into a time unit. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The current archive point. |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | The current archive point, converted into a time unit. |
| COMPATIBLE | NUMBER(38) | NO | The compatibility version. |
| BASE_PIECE_ID | NUMBER(38) | NO | The ID of the first piece in the current round. |
| USED_PIECE_ID | NUMBER(38) | NO | The IDs of the pieces used in the current round. |
| PIECE_SWITCH_INTERVAL | NUMBER(38) | NO | The interval for switching pieces. |
| UNIT_SIZE   | NUMBER(38)     | NO   | The size of a single log block that is compressed or encrypted in a log archive. This column is not supported. |
| COMPRESSION | VARCHAR2(128)  | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used. </li></ul> This column is not supported.  |
| INPUT_BYTES | NUMBER | NO | The size of the data read, in bytes. |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the data read, with a unit. For example: 798.01 M or 5.25 G. |
| OUTPUT_BYTES | NUMBER | NO | The size of the data output, in bytes. |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the data output, with a unit. For example: 798.01 M or 5.25 G. |
| COMPRESSION_RATIO | NUMBER | NO | The compression ratio. This column is not supported. |
| DELETED_INPUT_BYTES | NUMBER(38) | NO | The size of the original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the original data deleted, converted into a unit. Valid values: MB, GB, TB, and PB. |
| DELETED_OUTPUT_BYTES | NUMBER(38) | NO | The size of the effective data deleted, in bytes. |
| DELETED_OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the effective data deleted, converted into a unit. Valid values: MB, GB, TB, and PB. |
| PATH | VARCHAR2(2048) | NO | The archive path. |
| COMMENT | VARCHAR2(262144) | NO | The error message. |
