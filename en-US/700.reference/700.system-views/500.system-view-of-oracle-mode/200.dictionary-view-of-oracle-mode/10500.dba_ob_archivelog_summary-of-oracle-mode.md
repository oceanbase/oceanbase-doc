# DBA_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of all log archives in the current and historical logs of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | The path ID. The system assigns a unique ID to each path. |
| ROUND_ID | NUMBER(38) | NO | The identifier of the round of full clog backup data streams. |
| INCARNATION | NUMBER(38) | NO | The number of incarnations after a flashback database operation. |
| DEST_NO | NUMBER(38) | NO | The identifier of log_archive_dest_n. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| STATUS | VARCHAR2(64) | NO | The archive status. Valid values: <ul><li>`PREPARE`: The archive starts at `START_SCN`. </li> <li>`BEGINNING`: The log archive is being started.  </li> <li>`DOING`: The log archive is being performed. </li><li> `INTERRUPTED`: The log archive is interrupted and requires manual intervention. </li><li>`STOP`: The log archive is stopped.  </li><li>`STOPPING`: The log archive is being stopped.  </li><li>`SUSPENDING`: The log archive is being suspended.  </li><li>`SUSPEND`: The log archive is suspended.  </li></ul> |
| START_SCN | NUMBER(38) | NO | The start backup point. |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | The start backup point converted to a timestamp. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The current archive point. |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | The current archive point converted to a timestamp. |
| COMPATIBLE | NUMBER(38) | NO | The compatibility version. |
| BASE_PIECE_ID | NUMBER(38) | NO | The ID of the first PIECE in the current round. |
| USED_PIECE_ID | NUMBER(38) | NO | The ID of the PIECE used in the current round. |
| PIECE_SWITCH_INTERVAL | NUMBER(38) | NO | The piece switching cycle. |
| UNIT_SIZE   | NUMBER(38)     | NO   | The size of a single log block that is compressed or encrypted in a log archive. This field is not supported. |
| COMPRESSION | VARCHAR2(128)  | NO   | The compression algorithm. Valid values: <ul><li> none: no compression is performed. </li><li> lz4_1.0: the lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: the zstd_1.3.8 compression algorithm is used. </li></ul> This field is not supported.  |
| INPUT_BYTES | NUMBER | NO | The amount of data read, in bytes. |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The amount of data read, with the unit. For example: 798.01 M or 5.25 G. |
| OUTPUT_BYTES | NUMBER | NO | The amount of data output, in bytes. |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The amount of data output, with the unit. For example: 798.01 M or 5.25 G. |
| COMPRESSION_RATIO | NUMBER | NO | The compression ratio. This field is not supported. |
| DELETED_INPUT_BYTES | NUMBER(38) | NO | The amount of original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The amount of original data deleted, with the unit. Valid values: MB, GB, TB, and PB. |
| DELETED_OUTPUT_BYTES | NUMBER(38) | NO | The amount of effective data deleted, in bytes. |
| DELETED_OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The amount of effective data deleted, with the unit. Valid values: MB, GB, TB, and PB. |
| PATH | VARCHAR2(2048) | NO | The archive path. |
| COMMENT | VARCHAR2(262144) | NO | The error message. |
