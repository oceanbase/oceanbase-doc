# USER_SEGMENTS

## Purpose

The USER_SEGMENTS view displays the storage information of segments owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

DBA_SEGMENTS
