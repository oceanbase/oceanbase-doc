# DBA_POLICIES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays the access control policies of all tables or views in the current tenant. You can create multiple policies for a table.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | The owner of the object controlled by the policy. |
| OBJECT_NAME | VARCHAR2(128) | YES | The name of the object controlled by the policy. |
| POLICY_GROUP | VARCHAR2(128) | NO | The name of the policy group. |
| POLICY_NAME | VARCHAR2(128) | NO | The name of the policy. |
| PF_OWNER | VARCHAR2(128) | NO | The owner of the policy function. |
| PACKAGE | VARCHAR2(128) | NO | The name of the package where the policy function is located. |
| FUNCTION | VARCHAR2(128) | NO | The name of the policy function. |
| SEL | VARCHAR2(3) | NO | Whether the Select operation is affected: YES or NO. |
| INS | VARCHAR2(3) | NO | Whether the Insert operation is affected: YES or NO. |
| UPD | VARCHAR2(3) | NO | Whether the Update operation is affected: YES or NO. |
| DEL | VARCHAR2(3) | NO | Whether the Delete operation is affected: YES or NO. |
| IDX | VARCHAR2(3) | NO | Whether the Index operation is affected: YES or NO. |
| CHK_OPTION | VARCHAR2(3) | NO | Whether the value is checked after the Insert or Update operation: YES or NO. |
| ENABLE | VARCHAR2(3) | NO | Whether the policy is effective: YES or NO. |
| STATIC_POLICY | VARCHAR2(3) | NO | Whether the policy is static: YES or NO. |
| POLICY_TYPE | VARCHAR2(24) | NO | The type of the policy. Valid values:<ul><li> STATIC  </li><li> SHARED_STATIC </li><li>CONTEXT_SENSITIVE  </li><li> SHARED_CONTEXT_SENSITIVE</li><li>DYNAMIC </li></ul>|
| LONG_PREDICATE | VARCHAR2(3) | NO | Whether the predicate returned by the policy function exceeds 4000. |
| COMMON | VARCHAR2(3) | NO | This column is reserved for compatibility. Its value is fixed to NO. |
| INHERITED | VARCHAR2(3) | NO | This column is reserved for compatibility. Its value is fixed to NO. |

## Sample query

Query the access control policies of all tables or views in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_POLICIES;
```
