# DBA_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the history of load balancing tasks in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | The ID of the load balancing task. |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the task was created. |
| FINISH_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the task was completed, including the time when the task was canceled. |
| BALANCE_STRATEGY | VARCHAR2(64) | NO | The name of the load balancing strategy. Valid values: <ul><li>`LS balance by migrate`: migration-based load balancing  </li><li>`LS balance by alter`: log stream attribute modification-based load balancing </li><li>`LS balance by expand`: expansion-based load balancing </li><li>`LS balance by shrink`: reduction-based load balancing </li><li>`partition balance`: partition-based load balancing </li></ul>|
| JOB_TYPE | VARCHAR2(64) | NO | The type of the task. Valid values: <ul><li>`LS_BALANCE`: log stream-based load balancing  </li><li>`PARTITION_BALANCE`: partition-based load balancing </li></ul>|
| TARGET_UNIT_NUM | NUMBER(38) | NO | The number of units in each zone after the change. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is always <code>NULL</code> starting from V4.4.2. </li> <li>For V4.2.5, this column is always <code>NULL</code> starting from V4.2.5 BP5. </li></ul></main> |
| TARGET_PRIMARY_ZONE_NUM | NUMBER(38) | NO | The number of primary zones after the change. |
| STATUS | VARCHAR2(64) | NO | The status of the task. Valid values: <ul><li>`COMPLETED`: The task was executed successfully. </li><li>`CANCELED`: The task was canceled. </li></ul>|
| COMMENT | CLOB | YES | The comment. |
| MAX_END_TIME            | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | The maximum end time of the load balancing task. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view is available starting with V4.3.4. For V4.2.x, this column is available starting with V4.2.4. </p></main>     |
| ZONE_UNIT_NUM_LIST      | VARCHAR2(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          |  CLOB          | NO   | The parameters of the load balancing task.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |

## Sample query

Query the history of all load balancing tasks in the current tenant.

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOB_HISTORY;
```

The query result is as follows:

```shell
+--------+----------------------------+----------------------------+-------------------------+------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
| JOB_ID | CREATE_TIME                | FINISH_TIME                | BALANCE_STRATEGY        | JOB_TYPE   | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS    | COMMENT | MAX_END_TIME | ZONE_UNIT_NUM_LIST | PARAMETER_LIST                                                                               |
+--------+----------------------------+----------------------------+-------------------------+------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
| 120112 | 16-JAN-26 17:37:21.308318  | 16-JAN-26 17:37:53.423716  | alter LS group location | LS_BALANCE |            NULL |                       2 | COMPLETED | NULL    | NULL         | z1:1,z2:1          | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |
+--------+----------------------------+----------------------------+-------------------------+------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
1 row in set
```
