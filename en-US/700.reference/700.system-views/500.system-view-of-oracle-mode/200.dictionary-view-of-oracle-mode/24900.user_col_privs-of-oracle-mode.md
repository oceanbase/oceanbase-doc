# USER_COL_PRIVS

## Purpose

This view describes the column object grants for the current user as the owner, grantor, or grantee.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Column privileges are not supported. </p>
  </main>

## Columns

|  **Column**   |    **Type**     | **Nullable** |      **Description**      |
|-------------|---------------|----------------|------------------|
| GRANTEE     | VARCHAR2(128) | NO             | The name of the user who is granted access.    |
| OWNER       | VARCHAR2(128) | NO             | The owner of the object.           |
| TABLE_NAME  | VARCHAR2(256) | NO             | The name of the object.            |
| COLUMN_NAME | VARCHAR2(128) | NO             | The name of the column.             |
| GRANTOR     | VARCHAR2(128) | NO             | The name of the user who executes the grant.       |
| PRIVILEGE   | VARCHAR2(40)  | NO             | The privilege on the column.            |
| GRANTABLE   | VARCHAR2(3)   | NO             | Whether the GRANT statement can be used to grant privileges. |
