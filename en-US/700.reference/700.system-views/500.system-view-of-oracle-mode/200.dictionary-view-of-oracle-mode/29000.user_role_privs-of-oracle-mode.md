# USER_ROLE_PRIVS

## Purpose

Describes the roles granted to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**   |    **Type**    | **Nullable?** |           **Description**           |
|--------------|--------------|-------------|----------------------------|
| GRANTEE      | VARCHAR2(30) | NO          | The name of the user or PUBLIC.             |
| GRANTED_ROLE | VARCHAR2(30) | NO          | The name of the role granted to the user.                  |
| ADMIN_OPTION | VARCHAR2(3)  | NO          | Indicates whether the grant is with ADMIN OPTION.          |
| DEFAULT_ROLE | VARCHAR2(3)  | NO          | Indicates whether the role is set as the default role for the user. |
