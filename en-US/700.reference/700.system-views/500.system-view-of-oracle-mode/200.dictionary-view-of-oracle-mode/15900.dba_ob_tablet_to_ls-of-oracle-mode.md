# DBA_OB_TABLET_TO_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the list of all tablets in the current tenant and the log stream information of each tablet.

## Columns

|   Column    |   Type   | Nullable |        Description        |
|-----------|--------|------------|------------------|
| TABLET_ID | NUMBER | NO         | The ID of the tablet.        |
| LS_ID     | NUMBER | NO         | The ID of the log stream to which the tablet belongs. |

## Sample query

Query the list of tablets in log stream 1001 in the current user tenant and display the first five entries.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLET_TO_LS WHERE LS_ID=1001 AND ROWNUM <= 5;
```

The query result is as follows:

```shell
+-----------+-------+
| TABLET_ID | LS_ID |
+-----------+-------+
|    200004 |  1001 |
|    200005 |  1001 |
|    200006 |  1001 |
|    200007 |  1001 |
|    200008 |  1001 |
+-----------+-------+
5 rows in set
```
