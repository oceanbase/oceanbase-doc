# DBA_AUDIT_STATEMENT

## Purpose

The DBA_AUDIT_STATEMENT view displays the audit records of `GRANT`, `REVOKE`, `AUDIT`, `NOAUDIT`, and `ALTER SYSTEM` statements in the entire database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>
