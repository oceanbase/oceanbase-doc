# DBA_AUDIT_STATEMENT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in V2.2.77. </p>
</main>

## Purpose

The `DBA_AUDIT_STATEMENT` view displays the audit trail of `GRANT`, `REVOKE`, `AUDIT`, `NOAUDIT`, and `ALTER SYSTEM` statements in the entire database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is applicable only to the Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Sample query

Query the audit trail records of `GRANT`, `REVOKE`, `AUDIT`, `NOAUDIT`, and `ALTER SYSTEM` statements in the entire database.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_AUDIT_STATEMENT WHERE ROWNUM =1\G
```
