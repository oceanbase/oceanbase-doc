# DBA_METHOD_PARAMS

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Currently, OceanBase Database does not support this view. </p>
  </main>

## Purpose

The view displays the method parameters of object types in the database.

## Related views

* ALL_METHOD_PARAMS

* USER_METHOD_PARAMS

## Columns

|      **Column**      |    **Type**    | **Nullable?** |                           **Description**                            |
|--------------------|--------------|----------------|-------------------------------------------------------------|
| OWNER              | VARCHAR2(30) | NO             | The owner of the type.                                                      |
| TYPE_NAME          | VARCHAR2(30) | NO             | The name of the type.                                                        |
| METHOD_NAME        | VARCHAR2(30) | NO             | The name of the method.                                                        |
| METHOD_NO          | NUMBER       | NO             | The number that distinguishes overloaded methods with the same name. Do not confuse this number with the object ID.                      |
| PARAM_NAME         | VARCHAR2(30) | NO             | The name of the parameter.                                                       |
| PARAM_NO           | NUMBER       | NO             | The parameter number (positive).                                                    |
| PARAM_MODE         | VARCHAR2(6)  | NO             | The parameter mode (IN, OUT, IN OUT).                                       |
| PARAM_TYPE_MOD     | VARCHAR2(7)  | NO             | Whether the parameter references other objects.                                                 |
| PARAM_TYPE_OWNER   | VARCHAR2(30) | NO             | The owner of the parameter type.                                                    |
| PARAM_TYPE_NAME    | VARCHAR2(30) | NO             | The name of the parameter type.                                                     |
| CHARACTER_SET_NAME | VARCHAR2(44) | NO             | The default value is NULL.|
