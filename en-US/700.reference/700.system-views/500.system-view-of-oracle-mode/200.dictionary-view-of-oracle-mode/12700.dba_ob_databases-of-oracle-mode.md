# DBA_OB_DATABASES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the metadata of databases in the current tenant.

## Columns

|     Column      |       Type       | Nullable |             Description             |
|---------------|----------------|------------|----------------------------|
| DATABASE_NAME | VARCHAR2(128)  | NO         | The name of the database.                       |
| IN_RECYCLEBIN | VARCHAR2(3)    | NO         | Indicates whether the database is in the recycle bin:<ul><li>YES</li><li>NO</li></ul> |
| COLLATION     | VARCHAR2(128)  | NO         | The default collation of the database.            |
| READ_ONLY     | VARCHAR2(3)    | NO   | Indicates whether the database is read-only:<ul><li>YES: Read-only</li><li>NO: Read/write</li></ul> |
| COMMENT       | VARCHAR2(2048) | NO         | The description of the database.                     |
| TABLEGROUP_NAME | VARCHAR2(128)  | NO       | The name of the table group to which the database is bound. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1. </p></main>|

## Sample query

Query the metadata of databases in the current user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_DATABASES WHERE DATABASE_NAME = 'SYS'\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
  DATABASE_NAME: SYS
  IN_RECYCLEBIN: NO
      COLLATION: utf8mb4_bin
      READ_ONLY: NO
        COMMENT: oracle sys schema
TABLEGROUP_NAME: NULL
1 row in set
```
