# USER_TABLES

## Privilege

The user must have the SELECT ANY TABLE privilege.

## Purpose

The USER_TABLES view displays all tables owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_TABLES

* DBA_TABLES
