# DBA_SOURCE

## Purpose

Displays the text source of all stored objects in the database. The columns are the same as those in the `ALL_SOURCE` view.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_SOURCE

* USER_SOURCE

## Columns

|   **Column**    |    **Type**    | **Nullable?** |       **Description**       |
|---------------|--------------|----------------|--------------------|
| OWNER         | VARCHAR2(30) | NO             | The owner of the object.           |
| NAME          | VARCHAR2(30) | NO             | The name of the object.                |
| TYPE          | VARCHAR2(12) | NO             | The type of the object.               |
| LINE          | NUMBER       | NO             | The line number in the source code of the TEXT field.  |
| TEXT          | CLOB         | NO             | The source code of the current line.            |
| ORIGIN_CON_ID | NUMBER(38)   | NO             | Not supported. The default value is NULL. |
