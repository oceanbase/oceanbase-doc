# DBA_OB_ARCHIVELOG_PIECE_FILES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of pieces in the backup set of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | The path ID. The system assigns a unique ID to each configured path. |
| ROUND_ID | NUMBER(38) | NO | The ID of the round of complete clog backup data stream. |
| PIECE_ID | NUMBER(38) | NO | The ID of the backup log piece. |
| INCARNATION | NUMBER(38) | NO | The number of incarnations after Flashback Database. |
| DEST_NO | NUMBER(38) | NO | The ID of the log_archive_dest_n parameter. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| STATUS | VARCHAR2(64) | NO | The status of the piece. Valid values: <ul><li>ACTIVE: the piece is active. </li><li>FREEZING: the piece is being frozen. </li><li>FROZEN: the piece is frozen. After this status is set, the status of the piece will no longer change. </li></ul> |
| START_SCN | NUMBER(38) | NO | The start SCN of the piece. |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | The start SCN of the piece, converted to a timestamp. |
| CHECKPOINT_SCN | NUMBER(38) | NO | The current archive SCN. |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | The current archive SCN, converted to a timestamp. |
| MAX_SCN | NUMBER(38) | NO | The maximum archive SCN. |
| END_SCN | NUMBER(38) | NO | The theoretical end SCN of the piece. |
| COMPATIBLE  | NUMBER(38) | NO | The compatible version number of log archiving. |
| UNIT_SIZE   | NUMBER(38)     | NO   | The size of a single log block that is compressed or encrypted in one log archiving operation. This column is not supported. |
| COMPRESSION | VARCHAR2(128)  | NO   | The compression algorithm. Valid values: <ul><li> none: no compression is performed. </li><li> lz4_1.0: the lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: the zstd_1.3.8 compression algorithm is used. </li></ul> This column is not supported. |
| INPUT_BYTES | NUMBER(38) | NO | The size of the original data, in bytes. |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the original data, converted to a unit. |
| OUTPUT_BYTES | NUMBER(38) | NO | The size of the encrypted or compressed data, in bytes. |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | The size of the encrypted or compressed data, converted to a unit. |
| COMPRESSION_RATIO | NUMBER | NO | The compression ratio. This column is not supported. |
| FILE_STATUS | VARCHAR2(64) | NO | The file status of the backup log piece. Valid values: <ul><li>AVAILABLE: the backup is valid and can be used for recovery. </li><li>COPYING: the log file is being backed up. </li><li>INCOMPELTE: only part of the log file is copied. This status is applicable only to periodic backups. The checkpoint_ts of the copy is earlier than that of the original backup. The copy can be used for recovery before the checkpoint_ts of the original backup. </li><li>DELETING: the log file is being deleted. </li><li>EXPIRED: the backup file is invalid. </li><li>BROKEN: the backup file is incomplete and cannot be used. </li><li>DELETED: the log file is deleted. </li></ul> |
| PATH | VARCHAR2(2048) | NO | The archive path. |
