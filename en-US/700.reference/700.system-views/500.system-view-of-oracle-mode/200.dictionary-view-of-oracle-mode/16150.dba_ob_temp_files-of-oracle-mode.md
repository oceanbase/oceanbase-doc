# DBA_OB_TEMP_FILES

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.3.3. </p>
</main>

## Purpose

The `DBA_OB_TEMP_FILES` view displays information about temporary files.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------- | -------- | ------------------ | -------- |
| SVR_IP           | VARCHAR2(46)  | NO   | The IP address of the OBServer node.     |
| SVR_PORT         | NUMBER(38)   | NO   | The port number of the OBServer node.     |
| FILE_ID          | NUMBER(38)   | NO   | The file ID of the temporary file.     |
| TRACE_ID         | VARCHAR2(64)  | NO   | The TRACE ID of the current environment when the temporary file was opened.    |
| DIR_ID           | NUMBER(38)   | NO   | The directory ID corresponding to the temporary file.    |
| BYTES            | NUMBER(38)   | NO   | The size of the data in the temporary file, in bytes.     |
| START_OFFSET     | NUMBER(38)   | NO   | The starting byte offset of the temporary file, which is the position of the start of the current valid data.   |
| TOTAL_WRITES     | NUMBER(38)   | NO   | The total number of write requests for the temporary file.    |
| UNALIGNED_WRITES | NUMBER(38)   | NO   | The total number of unaligned write requests for the temporary file.    |
| TOTAL_READS      | NUMBER(38)   | NO   | The total number of read requests for the temporary file.     |
| UNALIGNED_READS  | NUMBER(38)   | NO   | The total number of unaligned read requests for the temporary file.    |
| TOTAL_READ_BYTES | NUMBER(38)   | NO   | The total size of the read requests for the temporary file, in bytes.    |
| LAST_ACCESS_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The last access time of the temporary file.    |
| LAST_MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The last modification time of the temporary file.    |
| BIRTH_TIME       | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | The creation time of the temporary file.    |

## Sample query

Query information about temporary files.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TEMP_FILES WHERE ROWNUM < 2\G
```
