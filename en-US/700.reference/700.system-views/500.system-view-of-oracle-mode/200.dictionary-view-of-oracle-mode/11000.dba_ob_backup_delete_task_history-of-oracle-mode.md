# DBA_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information of completed `backup_set`/`backup_piece` cleanup tasks in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | The task group ID, which identifies a group of tasks. |
| INCARNATION | NUMBER(38) | NO | The incarnation ID. |
| JOB_ID | NUMBER(38) | NO | The task ID, which corresponds to the ID in the jobs table. |
| TASK_TYPE | VARCHAR2(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: specifies the `backup_set` cleanup task. </li><li>`BACKUP PIECE`: specifies the `backup_piece` cleanup task. </li></ul> |
| ID | NUMBER(38) | NO | The task ID, which includes the IDs of backup_set and backup_piece. |
| ROUND_ID | NUMBER(38) | NO | The dest_round_id of the piece. For a backup_set cleanup task, the value of ROUND_ID is 0. |
| DEST_ID | NUMBER(38) | NO | The destination ID of the backup destination. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The start time of the task. |
| END_TIMESTAMP | VARCHAR2(256) | NO | The end time of the task. |
| STATUS | VARCHAR2(64) | NO | The task status. Valid values: <ul><li>`INIT`: the task is being initialized. </li><li>`DOING`: the task is being executed. </li><li>`CANCELING`: the task is being canceled. </li><li>`COMPLETED`: the task is successfully executed. </li><li>`FAILED`: the task failed. </li><li>`CANCELED`: the task is successfully canceled. </li></ul> |
| TOTAL_LS_COUNT | NUMBER(38) | YES | The total number of log stream tasks. |
| FINISH_LS_COUNT | NUMBER(38) | YES | The number of successfully executed log stream tasks. |
| RESULT | NUMBER(38) | YES | The error code. |
| COMMENT | VARCHAR2(4096) | YES | The comment. |
| PATH | VARCHAR2(1024) | NO | The backup destination of the backup_set or backup_piece. |

## Sample query

Query the historical information of completed `backup_set` or `backup_piece` cleanup tasks in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
```
