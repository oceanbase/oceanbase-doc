# DBA_PART_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays the partition information of all partitioned tables in the current tenant.

## Columns

|           Column            |       Type       | Nullable |  Description  |
|---------------------------|----------------|------------|--------------------------------|
| OWNER                     | VARCHAR2(128)  | NO         | The owner of the partitioned table.                                                                                 |
| TABLE_NAME                | VARCHAR2(128)  | NO         | The name of the partitioned table.                                                                                  |
| PARTITIONING_TYPE         | VARCHAR2(9)    | NO         | The partitioning method. <ul><li> HASH </li><li> RANGE </li><li> LIST  </li></ul>      |
| SUBPARTITIONING_TYPE      | VARCHAR2(9)    | NO         | The subpartitioning method. <ul><li>HASH </li><li>RANGE  </li><li>LIST </li></ul>   |
| PARTITION_COUNT           | NUMBER         | NO         | The number of partitions in the partitioned table.                                                                                |
| DEF_SUBPARTITION_COUNT    | NUMBER         | NO         | For a composite partitioned table, the number of subpartitions.                                                                        |
| PARTITIONING_KEY_COUNT    | NUMBER         | NO         | The number of partitioning keys.                                                                                  |
