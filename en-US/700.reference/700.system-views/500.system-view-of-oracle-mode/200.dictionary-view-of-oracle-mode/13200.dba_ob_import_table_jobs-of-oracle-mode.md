# DBA_OB_IMPORT_TABLE_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the information about the import tasks of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | The task ID. |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | The tenant ID of the parent task. |
| INITIATOR_JOB_ID | NUMBER(38) | NO | The job ID of the parent task. |
| START_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task started. |
| FINISH_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task completed. |
| SRC_TENANT_NAME | VARCHAR2(64) | NO | The name of the source tenant. |
| SRC_TENANT_ID | NUMBER(38) | NO | The ID of the source tenant. |
| STATUS | VARCHAR2(64) | NO | The task status. Valid values: <ul><li> INIT: the task is being initialized. </li><li>IMPORT_TABLE: importing tables. </li><li>RECONSTRUCT_REF_CONSTRAINT: reconstructing reference constraints.  </li><li>CANCELING: the task is being canceled. </li><li>IMPORT_FINISH: the task has been completed.  </li></ul> |
| IMPORT_ALL | NUMBER(38) | NO | Indicates whether to import all tables under the source tenant. This value is 1 only when the `RECOVER TABLE *.*` option is specified. In other cases, this value is 0. |
| DB_LIST | CLOB | YES | The list of databases to be fully recovered. |
| TABLE_LIST | CLOB | YES | The list of tables to be recovered. |
| REMAP_DB_LIST | CLOB | YES | The list of databases to be renamed. The format is as follows: db1:new_db1, db2:newdb2. |
| REMAP_TABLE_LIST | CLOB | YES | The list of tables to be renamed. The format is as follows: db1.t1:new_t1, db1.t2:db2.new_t2. |
| REMAP_TABLEGROUP_LIST | CLOB | YES | The list of table groups to be remapped. You can remap tables from the original table group to the target table group. The format is as follows: tg1:new_tg1, tg2:new_tg2. |
| REMAP_TABLESPACE_LIST | CLOB | YES | The list of tablespaces to be remapped. You can remap tables from the original tablespace to the target tablespace. The format is as follows: ts1:new_ts1, ts2:new_ts2. |
| TOTAL_TABLE_COUNT | NUMBER(38) | NO | The total number of tables to be imported. |
| FINISHED_TABLE_COUNT | NUMBER(38) | NO | The number of tables that have been imported. |
| FAILED_TABLE_COUNT | NUMBER(38) | NO | The number of tables that failed to be imported. |
| RESULT | VARCHAR2(64) | YES | The result of the table-level recovery task. Valid values: <ul><li>SUCCESS  </li><li>FAIL </li></ul> |
| COMMENT | CLOB | YES | The remarks. |
| DESCRIPTION | CLOB | YES | The DESCRIPTION parameter specified in the restore command. |
