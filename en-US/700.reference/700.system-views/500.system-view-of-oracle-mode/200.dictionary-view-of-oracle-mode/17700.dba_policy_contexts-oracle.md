# DBA_POLICY_CONTEXTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays the context information of all views in the current tenant. When accessing a view, the corresponding policy group is selected based on the value of the context.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | The owner of the object controlled by a policy. |
| OBJECT_NAME | VARCHAR2(128) | YES | The name of the object controlled by a policy. |
| NAMESPACE | VARCHAR2(128) | NO | The name of the associated context. |
| ATTRIBUTE | VARCHAR2(128) | NO | The attribute name in the associated context. |
| COMMON | VARCHAR2(3) | NO | For compatibility only. The value is always NO. |
| INHERITED | VARCHAR2(3) | NO | For compatibility only. The value is always NO. |

## Sample query

Query the context information of all views in the current tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_POLICY_CONTEXTS;
```

The query result is as follows:

```shell
+--------------+--------------+------------+----------------+--------+-----------+
| OBJECT_OWNER | OBJECT_NAME  | NAMESPACE  | ATTRIBUTE      | COMMON | INHERITED |
+--------------+--------------+------------+----------------+--------+-----------+
| SYS          | V_ORDERS_CTX | REGION_CTX | CURRENT_REGION | NO     | NO        |
| SYS          | V_ORDERS_CTX | DEPT_CTX   | CURRENT_DEPT   | NO     | NO        |
+--------------+--------------+------------+----------------+--------+-----------+
2 rows in set
```
