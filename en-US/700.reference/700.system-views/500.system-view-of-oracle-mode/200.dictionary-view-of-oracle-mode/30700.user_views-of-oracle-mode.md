# USER_VIEWS

## Purpose
-----------
Displays the views that the current user owns.
The `USER_VIEWS` view displays the views owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>

## Sample query

Get information about the view `VIEW1` owned by the current user.

```shell
obclient [SYS]> SELECT VIEW_NAME, TEXT_LENGTH, TEXT FROM SYS.USER_VIEWS WHERE VIEW_NAME='VIEW1';
```

The query result is as follows:

```shell
+-----------+-------------+-----------------------------+
| VIEW_NAME | TEXT_LENGTH | TEXT                        |
+-----------+-------------+-----------------------------+
| VIEW1     |          27 | SELECT col1, col2 FROM tbl1 |
+-----------+-------------+-----------------------------+
1 row in set
```
