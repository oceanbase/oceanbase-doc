# DBA_SEGMENTS

## Purpose

The `DBA_SEGMENTS` view displays the storage allocated for all segments in the database.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>

## References

USER_SEGMENTS
