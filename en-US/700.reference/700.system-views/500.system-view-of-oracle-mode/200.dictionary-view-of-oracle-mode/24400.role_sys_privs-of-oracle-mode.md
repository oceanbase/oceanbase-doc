# ROLE_SYS_PRIVS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

Describes the system privileges granted to a role.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is applicable only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**   |    **Type**     | **Nullable** |       **Description**       |
|--------------|---------------|----------------|--------------------|
| ROLE         | VARCHAR2(128) | NO             | The name of the role.               |
| PRIVILEGE    | VARCHAR2(40)  | NO             | The system privilege granted to the role.         |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | Indicates whether the role has been granted the ADMIN option. |

## Sample query

Query the system privileges granted to the `ROLE2` role.

```shell
obclient [SYS]> SELECT * FROM ROLE_SYS_PRIVS WHERE ROLE = 'ROLE2';
```

The query result is as follows:

```shell
+-------+-----------------+--------------+
| ROLE  | PRIVILEGE       | ADMIN_OPTION |
+-------+-----------------+--------------+
| ROLE2 | CREATE SEQUENCE | NO           |
+-------+-----------------+--------------+
1 row in set
```
