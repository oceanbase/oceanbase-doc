# ROLE_SYS_PRIVS

## Purpose

Describes the system privileges granted to roles.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Columns

|   **Column**   |    **Type**     | **Nullable?** |       **Description**       |
|--------------|---------------|-----------|--------------------|
| ROLE         | VARCHAR2(128) | NO        | The role name.               |
| PRIVILEGE    | VARCHAR2(40)  | NO        | The system privilege granted to the role.         |
| ADMIN_OPTION | VARCHAR2(3)   | NO        | Whether the role has the ADMIN option. |
