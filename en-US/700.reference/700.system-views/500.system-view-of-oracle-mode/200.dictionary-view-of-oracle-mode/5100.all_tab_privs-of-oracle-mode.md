# ALL_TAB_PRIVS

## Purpose

This view lists the object privileges that meet the following conditions:

* The current user is the owner of the object, the grantor of the object privilege, or the grantee of the object privilege.

* The grantee of the object privilege is an activated role or the PUBLIC role.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available starting with OceanBase Database. </p>
  </main>

## Columns

|   **Column**   |    **Type**     | **Nullable** |            **Description**             |
|--------------|---------------|----------------|-------------------------------|
| GRANTOR      | VARCHAR2(128) | NO             | The username of the grantor.                      |
| GRANTEE      | VARCHAR2(128) | NO             | The username of the grantee.                   |
| TABLE_SCHEMA | VARCHAR2(128) | NO             | The schema of the object.                         |
| TABLE_NAME   | VARCHAR2(128) | NO             | The name of the object.                          |
| PRIVILEGE    | VARCHAR2(40)  | NO             | The privilege of the object.                         |
| GRANTABLE    | VARCHAR2(3)   | NO             | Indicates whether the privilege can be granted with the GRANT OPTION.     |
| HIERARCHY    | VARCHAR2(10)  | NO             | Indicates whether the privilege can be granted with the HIERARCHY OPTION. |
