# USER_IND_PARTITIONS

## Purpose

-----------

The `USER_IND_PARTITIONS` view displays the information about the index partitions owned by the current user in the database. This view does not have the `INDEX_OWNER` column compared with the `ALL_IND_PARTITIONS` and `DBA_IND_PARTITIONS` views.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>
