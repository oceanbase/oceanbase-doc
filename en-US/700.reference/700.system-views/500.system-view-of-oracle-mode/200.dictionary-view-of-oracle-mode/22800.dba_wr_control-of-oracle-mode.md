# DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the configuration information related to WR.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or a meta tenant. </li></ul> |
| SNAP_INTERVAL | VARCHAR2(64) | NO | The interval between snapshots, in the `DD HH:mm:SS` format for easy reading. |
| RETENTION | VARCHAR2(64) | NO | The retention period of each snapshot, in the `DD HH:mm:SS` format for easy reading. |
| TOPNSQL | NUMBER(38) | NO | The topN SQL statements to be stored. |
