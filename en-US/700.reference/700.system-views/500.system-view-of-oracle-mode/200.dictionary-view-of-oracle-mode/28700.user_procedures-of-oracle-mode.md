# USER_PROCEDURES

## Purpose

The view displays all functions and procedures that the current user owns, along with their associated attributes. The columns are the same as those in the `ALL_PROCEDURES` view, except for the `OWNER` column.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_PROCEDURES

* ALL_PROCEDURES

## Columns

|    **Column**    |    **Type**     | **Nullable?** |                     **Description**                     |
|----------------|---------------|----------|------------------------------------------------|
| OBJECT_NAME    | VARCHAR2(128) | YES      | The name of the package.                                             |
| PROCEDURE_NAME | VARCHAR2(128) | NO       | The name of the procedure or function.                                        |
| OBJECT_ID      | NUMBER        | NO       | The ID of the object.                                          |
| SUBPROGRAM_ID  | NUMBER        | NO       | The order in which the procedure or function appears in the package. For an independent procedure or function, this value is 1.                     |
| OVERLOAD       | NUMBER        | NO       | The number of times the procedure or function is overloaded in the package source file.                                 |
| OBJECT_TYPE    | VARCHAR2(9)   | NO       | The type of the object.                                          |
| AGGREGATE      | VARCHAR2(3)   | NO       | Not supported. The default value is NO.             |
| PIPELINED      | VARCHAR2(3)   | NO       | Indicates whether the procedure is a pipelined table function.                                  |
| IMPLTYPEOWNER  | VARCHAR2(30)  | NO       | Not supported. The default value is NULL.             |
| IMPLTYPENAME   | VARCHAR2(30)  | NO       | Not supported. The default value is NULL.                |
| PARALLEL       | VARCHAR2(3)   | NO       | Indicates whether the procedure or function is enabled for parallel execution.                                |
| INTERFACE      | VARCHAR2(3)   | NO       | Not supported. The default value is NULL. |
| DETERMINISTIC  | VARCHAR2(3)   | NO       | Indicates whether the procedure or function is declared as deterministic.                                 |
| AUTHID         | VARCHAR2(12)  | NO       | INVOKER/DEFINER                                |
| ORIGIN_CON_ID  | NUMBER(38)    | NO       | Not supported. The default value is NULL.                        |
