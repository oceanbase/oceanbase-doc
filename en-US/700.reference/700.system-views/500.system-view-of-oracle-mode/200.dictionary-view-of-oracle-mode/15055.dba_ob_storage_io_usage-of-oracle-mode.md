# DBA_OB_STORAGE_IO_USAGE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

This view displays the I/O operations of object storage and cloud disks in the current tenant.

## Columns

| Column | Type | Nullable | Description |
|-----------|---------------|----------------|-------------------------------|
| PATH      | VARCHAR2(1024)| NO   | The path is in the `oss://`, `file://`, or `s3://` format.    |
| ENDPOINT  | VARCHAR2(256) | NO   | <ul><li>In Shared-Nothing (SN) mode, the endpoint of the object storage used for backup and restore, data import, and data export. </li> <li>In Shared-Storage (SS) mode, the endpoint of the log (clog) or data storage and the endpoint of the object storage used for backup and restore, data import, and data export. </li></ul> |
| TYPE      | VARCHAR2(128) | NO   | The operation type. Valid values: <ul><li>`READ`: read operations. </li> <li>`WRITE`: write operations. </li> <li>`READ_BYTES`: network traffic entering the object storage. </li> <li>`WRITE_BYTES`: network traffic exiting the object storage. </li> <li>`TAG`: tags in the object storage. This type is not displayed for local disks and cloud disks. </li></ul>     |
| TOTAL     | NUMBER(38)    | NO   | The cumulative value for each operation type (`TYPE`). <ul><li>`READ`: the number of read operations. </li> <li>`WRITE`: the number of write operations. </li> <li>`READ_BYTES`: the total network traffic entering the object storage, in bytes. </li> <li>`WRITE_BYTES`: the total network traffic exiting the object storage, in bytes. </li> <li>`TAG`: the cumulative value of tags in the object storage. This value is not displayed for local disks and cloud disks. </li></ul>      |
