# ALL_PROCEDURES

## Purpose

The view displays all the functions and procedures that the current user can access, along with their attributes.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_PROCEDURES

* USER_PROCEDURES

## Columns

|    **Column**    |    **Type**     | **Nullable?** |                     **Description**                     |
|----------------|---------------|----------------|------------------------------------------------|
| OWNER          | VARCHAR2(128) | NO             | The owner of the object.                                       |
| OBJECT_NAME    | VARCHAR2(128) | YES            | The name of the package.                                             |
| PROCEDURE_NAME | VARCHAR2(128) | NO             | The name of the procedure or function.                                        |
| OBJECT_ID      | NUMBER        | NO             | The ID of the object.                                          |
| SUBPROGRAM_ID  | NUMBER        | NO             | The order of the procedure or function in the package.  For standalone procedures or functions, the value is 1.                     |
| OVERLOAD       | NUMBER        | NO             | The number of overloads of the procedure or function in the package source file.                                 |
| OBJECT_TYPE    | VARCHAR2(9)   | NO             | The type of the object.                                          |
| AGGREGATE      | VARCHAR2(3)   | NO             | The value of this field is currently not supported. The default value is NO.             |
| PIPELINED      | VARCHAR2(3)   | NO             | Indicates whether the procedure is a pipelined table function.                                  |
| IMPLTYPEOWNER  | VARCHAR2(30)  | NO             | The value of this field is currently not supported. The default value is NULL.             |
| IMPLTYPENAME   | VARCHAR2(30)  | NO             | The value of this field is currently not supported. The default value is NULL.                |
| PARALLEL       | VARCHAR2(3)   | NO             | Indicates whether the procedure or function is enabled for parallel execution.                                |
| INTERFACE      | VARCHAR2(3)   | NO             | The value of this field is currently not supported. The default value is NULL. |
| DETERMINISTIC  | VARCHAR2(3)   | NO             | Indicates whether the procedure or function is declared as deterministic.                                 |
| AUTHID         | VARCHAR2(12)  | NO             | INVOKER/DEFINER                                |
| ORIGIN_CON_ID  | NUMBER(38)    | NO             | The value of this field is currently not supported. The default value is NULL.                        |
