# USER_INDEXES

## Purpose
-----------
The INDEXES of USER_SHOW view are used to display information on all indexes owned by the user.
The `USER_INDEXES` view displays indexes on all tables owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>

## Sample query

Query the index information of the `TBL2` table in the tables owned by the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_INDEXES WHERE table_name='TTBL2';
```
