# DBA_WR_SNAPSHOT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the `SNAPSHOT` information of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CLUSTER_ID | NUMBER(38) | NO | The cluster ID. |
| TENANT_ID | NUMBER(38) | NO | The tenant ID. |
| SNAP_ID | NUMBER(38) | NO | The snapshot ID. |
| SVR_IP | VARCHAR2(46) | NO | The IP address of the node. |
| SVR_PORT | NUMBER(38) | NO | The port of the node. |
| BEGIN_INTERVAL_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The start time of the snapshot, with millisecond precision. |
| END_INTERVAL_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The end time of the snapshot, with millisecond precision. |
| SNAP_FLAG | NUMBER(38) | YES | The reason for triggering the snapshot. |
| STARTUP_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | The startup time of the process, with millisecond precision. |

## Sample query

Query the `SNAPSHOT` information of the current tenant and display the first record.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_SNAPSHOT WHERE ROWNUM <= 1\G
```
