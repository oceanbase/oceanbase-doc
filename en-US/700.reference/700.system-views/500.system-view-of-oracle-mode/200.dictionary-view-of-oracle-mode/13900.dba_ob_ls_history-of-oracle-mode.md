# DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in V4.2.0. </p>
</main>

## Description

This view displays the log streams that existed in the tenant.

## Columns

| Column | Type | Nullable | Description                                       |
|-------------|---------------|-------------|-------------------------------------------|
| LS_ID       | NUMBER        | NO          |  Log stream ID                                 |
| LS_GROUP_ID | NUMBER        | NO          |  Log stream group ID                           |
| STATUS      | VARCHAR2(100) | NO          |  Current status of the log stream. The following values are possible: <ul><li>CREATING: The log stream is being created. </li><li>NORMAL: The log stream is in a normal state. </li><li>DROPPING: The log stream is being deleted. </li><li>PRE_TENANT_DROPPING: A special status of a system log stream. It indicates the start of the deletion of all log streams in the tenant. </li><li>TENANT_DROPPING: The tenant is being deleted. The log streams are being deleted. </li><li>DROPPED: The log streams have been recycled or are being recycled. </li><li>WAIT_OFFLINE: The log streams are waiting to be recycled. </li><li>CREATE_ABORT: The creation of the log stream is stopped. </li></ul>        |
| FLAG        | VARCHAR2(2048)| NO          |  Log stream flags. The following values are possible: <ul><li>NULL: A normal log stream. </li><li> DUPLICATE: A broadcast log stream of a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: You cannot create a tablet on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: You cannot create a tablet on this broadcast log stream. </li></ul>                        |
| CREATE_SCN  | NUMBER        | NO          |  Global timestamp (GTS) when the log stream is created. The unit is nanoseconds.              |

## Examples

Query the log streams that existed in the current tenant.

```sshell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_HISTORY;
```

The query result is as follows:

```shell
+-------+-------------+--------+------+---------------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN          |
+-------+-------------+--------+------+---------------------+
|     1 |           0 | NORMAL | NULL |                   0 |
|  1001 |        1001 | NORMAL | NULL | 1736152507462028000 |
+-------+-------------+--------+------+---------------------+
2 rows in set
```
