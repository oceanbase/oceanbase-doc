# USER_AUDIT_OBJECT

## Purpose

The `USER_AUDIT_OBJECT` view displays the audit records of objects that the user can access.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Sample query

Query the audit trails of all objects that the current user has access to.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_AUDIT_OBJECT WHERE ROWNUM =1\G
```
