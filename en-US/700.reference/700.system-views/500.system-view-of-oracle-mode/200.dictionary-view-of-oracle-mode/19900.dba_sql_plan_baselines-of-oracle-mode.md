# DBA_SQL_PLAN_BASELINES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the plan baselines of SQL statements in the SQL Plan Management (SPM) of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SIGNATURE | NUMBER | NO | The unique identifier of the SQL statement generated by the normalized SQL statement. |
| SQL_HANDLE | VARCHAR2(32) | NO | The unique text of the SQL statement. |
| SQL_TEXT | CLOB | NO | The unnormalized text of the SQL statement. |
| PLAN_NAME | VARCHAR2(128) | NO | The unique text of the plan identifier. |
| CREATOR | VARCHAR2(128) | NO | The user who created the plan baseline. |
| ORIGIN | VARCHAR2(29) | NO | The method used to create the plan baseline. Valid values: <ul><li>MANUAL-LOAD</li><li>AUTO-CAPTURE</li><li>MANUAL-SQLTUNE</li><li>AUTO-SQLTUNE</li></ul> |
| PARSING_SCHEMA_NAME | VARCHAR2(128) | NO | This column is not supported and is set to NULL by default. |
| DESCRIPTION | VARCHAR2(500) | YES | The description of the plan baseline. |
| VERSION | VARCHAR2(256) | NO | The database version when the plan baseline was created. |
| CREATED | TIMESTAMP(6) | NO | The creation time of the plan baseline. |
| LAST_MODIFIED | TIMESTAMP(6) | NO | The last modification time of the plan baseline. |
| LAST_EXECUTED | NUMBER | NO | The last execution time of the plan baseline. |
| LAST_VERIFIED | NUMBER | NO | The last verification time of the plan baseline. |
| ENABLED | VARCHAR2(3) | NO | Indicates whether the plan baseline is enabled. Valid values: <ul><li>YES</li><li>NO</li></ul>    |
| ACCEPTED | VARCHAR2(3) | NO | Indicates whether the plan baseline is accepted. Valid values: <ul><li>YES</li><li>NO</li></ul>    |
| FIXED | VARCHAR2(3) | NO | Indicates whether the plan baseline is fixed. Valid values: <ul><li>YES</li><li>NO</li></ul>   |
| REPRODUCED | VARCHAR2(3) | NO | Indicates whether the plan baseline is reproducible. Valid values: <ul><li>YES</li><li>NO</li></ul>   |
| AUTOPURGE | VARCHAR2(3) | NO | Indicates whether the plan baseline is automatically purged. Valid values: <ul><li>YES</li><li>NO</li></ul>    |
| ADAPTIVE | VARCHAR2(3) | NO | Indicates whether the plan baseline captured automatically by the SPM is adaptive. Valid values: <ul><li>YES</li><li>NO</li></ul>    |
| OPTIMIZER_COST | NUMBER | NO | The estimated plan cost calculated by the optimizer when the plan baseline was created. |
| MODULE | VARCHAR2(64) | NO | This column is not supported and is set to NULL by default. |
| ACTION | VARCHAR2(64) | NO | This column is not supported and is set to NULL by default. |
| EXECUTIONS | NUMBER | NO | The number of times the plan was executed when the plan baseline was created. |
| ELAPSED_TIME | NUMBER | NO | The total elapsed time of the plan when the plan baseline was created. |
| CPU_TIME | NUMBER | NO | The total CPU time of the plan when the plan baseline was created. |
| BUFFER_GETS | NUMBER | NO | This column is not supported and is set to NULL by default. |
| DISK_READS | NUMBER | NO | This column is not supported and is set to NULL by default. |
| DIRECT_WRITES | NUMBER | NO | This column is not supported and is set to NULL by default. |
| ROWS_PROCESSED | NUMBER | NO | This column is not supported and is set to NULL by default. |
| FETCHES | NUMBER | NO | This column is not supported and is set to NULL by default. |
| END_OF_FETCH_COUNT | NUMBER | NO | This column is not supported and is set to NULL by default. |
