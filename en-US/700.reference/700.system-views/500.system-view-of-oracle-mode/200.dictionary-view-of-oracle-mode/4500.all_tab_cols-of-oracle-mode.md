# ALL_TAB_COLS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

The `ALL_TAB_COLS` view displays all columns of tables and views accessible to the current user.

The `ALL_TAB_COLS` view differs from [ALL_TAB_COLUMNS](4600.all_tab_columns-of-oracle-mode.md) in that `ALL_TAB_COLS` displays columns marked for quick drop, while `ALL_TAB_COLUMNS` does not.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This view is available starting with OceanBase Database in Oracle mode. </p>
</main>

| HIDDEN_COLUMN        | VARCHAR2(3)    | NO             | Indicates whether the column is a hidden column: <li> YES   <li> NO    |
| VIRTUAL_COLUMN       | VARCHAR2(3)    | NO             | Indicates whether the column is a virtual column: <li> YES   <li> NO    |

| INTERNAL_COLUMN_ID   | NUMBER         | NO             | This column is not supported. The default value is NULL.                    |
| HISTOGRAM            | VARCHAR2(15)   | NO             | This column is not supported. The default value is NULL.                    |
| QUALIFIED_COL_NAME   | VARCHAR2(4000) | NO             | The qualified column name                                       |

| COLLATED_COLUMN_ID   | NUMBER         | NO             | This column is not supported. The default value is NULL |
