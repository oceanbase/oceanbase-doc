# USER_IND_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

This view displays information about the index partitions that the current user owns. It does not contain the `INDEX_OWNER` column, which is present in the `ALL_IND_PARTITIONS` and `DBA_IND_PARTITIONS` views.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode of OceanBase Database. </p>
  </main>
