# ALL_METHOD_PARAMS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is not supported by OceanBase Database. </p>
</main>

## Purpose

This view displays the method parameters for object types accessible to the current user.

  <main id="notice" >
    <h4>Purpose</h4>
    <p>This view is available only in OceanBase Database in Oracle mode. </p>
  </main>

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
|--------------------|--------------|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER | VARCHAR2(30) | NO | Type |
| TYPE_NAME          | VARCHAR2(30) | NO             | Column                                                                              |
| COLUMN              | VARCHAR2(30) | NO             | Column name                                                                           |
| METHOD_NO          | NUMBER       | NO             | For an overloaded method, this number differentiates another method with the same name. Do not confuse this with the object ID.                                          |
| PARAM_NAME         | VARCHAR2(30) | NO             | The parameter name.                                                                         |
|PARAM_NO|NUMBER|NO|Parameter ID (positive number). |
| PARAM_MODE         | VARCHAR2(6)  | NO             | Parameter Mode: <li> IN   <li> OUT   <li> IN OUT    |
| PARAM_TYPE_MOD     | VARCHAR2(7)  | NO             | Indicates whether the parameter refers to another object.                                                                   |
| PARAM_TYPE_OWNER   | VARCHAR2(30) | NO             | The owner of the parameter type.                                                            |
| PARAM_TYPE_NAME    | VARCHAR2(30) | NO             | The name of the parameter type.                                                             |
| CHARACTER_SET_NAME | VARCHAR2(44) | NO             | Default is NULL. |
