# DBA_OB_FREEZE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the version information generated by major_freeze operations in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| FROZEN_SCN | NUMBER(38) | NO | The major freeze version number. |
| CLUSTER_VERSION | NUMBER(38) | NO | The cluster version number at the time of the major freeze. |
| SCHEMA_VERSION | NUMBER(38) | NO | The schema version number at the time of the major freeze. |
| GMT_CREATE | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the record was created. |
| GMT_MODIFIED | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | The time when the record was last modified. |

## Sample query

Query the version information generated by major_freeze operations in the current user tenant.

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_FREEZE_INFO;
```
