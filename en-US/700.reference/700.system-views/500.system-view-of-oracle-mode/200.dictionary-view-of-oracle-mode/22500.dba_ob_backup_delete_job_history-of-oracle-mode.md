# DBA_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Introduced from version V4.0.0.</p>
</main>

## Feature description

Displays the history of backup cleanup tasks executed under the tenant.

## Field description

| Field | Type | Null | Description |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | The task ID that monotonically increases.
| INCARNATION | NUMBER(38) | NO | Avatar ID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | The ID of the tenant that initiated the job.
| INITIATOR_JOB_ID | NUMBER(38) | NO | The tenant ID that initiated the job.
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | A list of tenants that execute the cleanup task.
| TYPE | VARCHAR2(64) | NO | Cleanup type: <ul><li>DELETE OBSOLETE BACKUP: Obsolete cleanup</li></ul>
| PARAMETER | VARCHAR2(1024) | NO | The cleanup parameter records the expiration time.
| JOB_LEVEL | VARCHAR2(64) | NO | The task initiation level: <ul><li> `USER_TENANT`: task initiated by user tenant </li><li> `SYS_TENANT`: task initiated by system tenant </li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task starts.
| END_TIMESTAMP | VARCHAR2(256) | NO | The current time of the tenant when the task ends.
| STATUS | VARCHAR2(64) | NO | The task status: <li>INIT<li>DOING<li>CANCELING<li>CANCELED<li>COMPLETED<li>FAILED |
| TASK_COUNT | NUMBER(38) | YES | The number of backup_set or piece tasks.
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | The number of successful tasks executed in the backup set or piece.
| RESULT | NUMBER(38) | NO | Error code |
| COMMENT | VARCHAR2(4096) | YES | Description of the task execution.
