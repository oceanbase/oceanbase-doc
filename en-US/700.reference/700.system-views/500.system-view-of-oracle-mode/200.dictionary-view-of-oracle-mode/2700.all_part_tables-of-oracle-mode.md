# ALL_PART_TABLES

## Purpose

The `ALL_PART_TABLES` view displays the partitioning information of all partitioned tables accessible to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition provides only the MySQL mode. </p>
  </main>
