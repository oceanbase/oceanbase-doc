# USER_OBJECTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

The `USER_OBJECTS` view displays all database objects owned by the current user. This view is similar to the ALL_OBJECTS view, but it does not include the OWNER column because the owner is the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is applicable only to OceanBase Database in Oracle-compatible mode. </p>
  </main>

## Columns

|   Column  |    Type  | Nullable |     Description |
|-------------------|---------------|------------|-------------|
| OBJECT_NAME    | VARCHAR2(128) | NO             | The name of the object.                                         |
| SUBOBJECT_NAME | VARCHAR2(128) | NO             | The name of the subobject. For example, the name of a partition.                          |
| OBJECT_ID      | NUMBER        | NO             | The dictionary ID of the object.                                   |
| DATA_OBJECT_ID | NUMBER        | NO             | The dictionary ID of the segment that contains the object.                       |
| OBJECT_TYPE    | VARCHAR2(23)  | NO             | The type of the object. Valid values: TABLE, INDEX, PARTITION, PACKAGE, STORED PROCEDURE, SYNONYM, and SEQUENCE.                |
| CREATED        | DATE          | NO             | The time when the object was created.                                       |
| LAST_DDL_TIME  | DATE          | NO             | The time when the last DDL operation was performed on the object.                                |
| TIMESTAMP      | VARCHAR2(19)  | NO             | The timestamp of the object, in character format.                             |
| STATUS         | VARCHAR2(7)   | NO             | The status of the object. Valid values: <ul><li>VALID: valid</li><li> INVALID: invalid </li></ul>    |
| TEMPORARY      | VARCHAR2(1)   | NO             | Indicates whether the object is a temporary object.                                 |
| GENERATED      | VARCHAR2(1)   | NO             | Indicates whether the name of the object is generated by the system.                             |

| ORACLE_MAINTAINED | VARCHAR2(1)   | NO         | `NULL`                            |
| APPLICATION       | VARCHAR2(1)   | NO         | `NULL`                        |
| DEFAULT_COLLATION | VARCHAR2(1)   | NO         | `NULL`                            |
| DUPLICATED        | VARCHAR2(1)   | NO         | `NULL`         |
| SHARDED           | VARCHAR2(1)   | NO         | `NULL`                             |

| CREATED_APPID     | NUMBER    | NO         | `NULL`    |

| MODIFIED_APPID    | NUMBER    | NO         | `NULL`      |
| MODIFIED_VSNID    | NUMBER    | NO         | `NULL`        |

## Sample query

Query all database objects owned by the current user and display the first two records.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_OBJECTS WHERE ROWNUM <= 2;
```
