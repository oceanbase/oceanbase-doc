# DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the archive path and the backup destination configuration for archived logs of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_NO | NUMBER(38) | NO | The identifier of log_archive_dest_n. |
| NAME | VARCHAR2(1024) | NO | The name of the field, which contains the following fields:<ul><li>`binding`: the priority mode of archive and business. </li> <li>`dest_id`: the ID of the archive destination. </li> <li>`path`: the archive path information. </li> <li>`piece_switch_interval`: the cycle of piece switching. </li> <li>`state`: the state of the archive destination. </li><li>`backup_archive_dest_id`: the ID of the backup destination for archived logs. </li><li>`backup_archive_path`: the path of the backup destination for archived logs. </li><li>`backup_archive_state`: the state of the backup destination for archived logs. </li></ul></br>For V4.4.x versions, `backup_archive_dest_id`, `backup_archive_path`, and `backup_archive_state` are available starting with V4.4.2 BP3.  |
| VALUE | VARCHAR2(4096) | NO | The value corresponding to the `name` field. |

## Sample query

Query the archive path configuration of the user tenant.

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_OB_ARCHIVE_DEST;
```

The query result is as follows:

```shell
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
| DEST_NO | NAME                  | VALUE                                                                                                                         |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
|       0 | binding               | OPTIONAL                                                                                                                      |
|       0 | dest_id               | 1004                                                                                                                          |
|       0 | path                  | oss://example_patharchive?host=cn-******.aliyuncs.com&access_id=******&access_key=*****&checksum_type=md5&enable_worm=true    |
|       0 | piece_switch_interval | 1d                                                                                                                            |
|       0 | state                 | ENABLE                                                                                                                        |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
5 rows in set
```

You can view the backup destination configurations of the current tenant's archived logs.

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_OB_ARCHIVE_DEST WHERE name LIKE '%backup_archive%';
```

The query result is as follows:

```shell
+---------+------------------------+------------------------+
| DEST_NO | NAME                   | VALUE                  |
+---------+------------------------+------------------------+
|   10000 | backup_archive_dest_id | 1005                   |
|   10000 | backup_archive_path    | file:///data/backuparg |
|   10000 | backup_archive_state   | ENABLE                 |
+---------+------------------------+------------------------+
3 rows in set
```
