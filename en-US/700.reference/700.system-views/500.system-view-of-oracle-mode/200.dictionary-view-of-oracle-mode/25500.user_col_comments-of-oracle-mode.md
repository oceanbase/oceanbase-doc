# USER_COL_COMMENTS

## Purpose

The view displays all column comments of views and tables owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* ALL_COL_COMMENTS

* DBA_COL_COMMENTS

## Columns

|  **Column**   |     **Type**     | **Nullable?** | **Description** |
|-------------|----------------|----------------|--------|
| OBJECT_NAME | VARCHAR2(128)  | NO             | Name of the object.   |
| COLUMN_NAME | VARCHAR2(128)  | NO             | Name of the column.     |
| COMMENTS    | VARCHAR2(4000) | YES            | Column comment.    |
