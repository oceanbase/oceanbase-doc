# USER_COL_COMMENTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.30. </p>
</main>

## Purpose

This view displays the comments of all columns in the views and tables owned by the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view is available only in Oracle mode. </p>
  </main>

## Columns

|  **Column**   |     **Type**     | **Nullable** | **Description** |
|-------------|----------------|----------------|--------|
| TABLE_NAME  | VARCHAR2(128)  | NO             | The name of the object.   |
| COLUMN_NAME | VARCHAR2(128)  | NO             | The name of the column.     |
| COMMENTS    | VARCHAR2(4000) | YES            | The comment of the column.    |

## Sample query

Query the comments of all columns in the `T1` table owned by the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_COL_COMMENTS WHERE TABLE_NAME='T1';
```

The query result is as follows:

```shell
+------------+----------------+----------+
| TABLE_NAME | COLUMN_NAME    | COMMENTS |
+------------+----------------+----------+
| T1         | __pk_increment | NULL     |
| T1         | ID1            | score    |
| T1         | ID2            | NULL     |
+------------+----------------+----------+
3 rows in set
```
