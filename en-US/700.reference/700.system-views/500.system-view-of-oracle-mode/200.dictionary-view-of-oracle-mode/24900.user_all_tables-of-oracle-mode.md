# USER_ALL_TABLES

## Purpose

The view displays the tables and views that the current user can access. The view is similar to the ALL_ALL_TABLES view, except that the view does not contain the OWNER column.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to OceanBase Database in Oracle mode. </p>
  </main>

## Related views

* DBA_ALL_TABLES

* ALL_ALL_TABLES
