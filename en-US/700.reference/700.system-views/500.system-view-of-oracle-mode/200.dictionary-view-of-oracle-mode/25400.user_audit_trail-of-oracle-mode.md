## USER_AUDIT_TRAIL

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in V2.2.77. </p>
</main>

## Purpose

The `USER_AUDIT_TRAIL` view allows you to view standard audit trail entries related to the current user.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This view applies only to the Oracle-compatible mode of OceanBase Database. </p>
  </main>

## Sample query

Query the standard audit trail entries related to the current user.

```shell
obclient [SYS]> SELECT * FROM SYS.USER_AUDIT_TRAIL WHERE ROWNUM =1\G
```
