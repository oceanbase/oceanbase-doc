# oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVREF_STATS_SYS_DEFAULTS` view displays the system-level default values for the statistics attributes of the materialized view refresh history.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(16) | NO | The parameter name. Valid values: <ul><li>COLLECTION_LEVEL: the level or degree of detail for data collection.</li><li>RETENTION_PERIOD: the time period for data retention.</li></ul>|
| VALUE | varchar(40) | NO | The system-level default value of the parameter. |

## Sample query

Query the system-level default values for the statistics attributes of the materialized view refresh history.

```shell
obclient [test_db]> SELECT * FROM oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS;
```

The query result is as follows:

```shell
+------------------+---------+
| PARAMETER_NAME   | VALUE   |
+------------------+---------+
| COLLECTION_LEVEL | TYPICAL |
| RETENTION_PERIOD | 31      |
+------------------+---------+
2 rows in set
```
