# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the status and recovery progress of the log streams for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------- | --------------------- | ----------------------- | -------------------- |
| LS_ID | bigint(20) | NO | Log Stream ID |
| STATUS | varchar(100) | NO | The status of the log stream, including: <ul><li>`CREATING`: Log stream is being created.</li><li>`CREATED`: Log stream created.</li><li>`NORMAL`: Log streams can provide services.</li><li>`DROPPING`: The log stream is about to be deleted. You need to migrate the tablets on the log stream away.</li><li>`TENANT DROPPING`: The tenant where the log stream resides is being deleted, and the log stream needs to be deleted.</li><li>`WAIT OFFLINE`: Log stream data has been deleted and is waiting for GC.</li><li>`CREATE ABORT`: Log stream creation failed or not required, about to be deleted.</li></ul> |
| PRIMARY_ZONE | longtext | YES | Election Priority of Log Streams |
| UNIT_GROUP_ID | bigint(20) | NO | Unit group ID. For system log streams (log stream 1) and broadcast log streams, this field displays as 0, indicating that the log stream is not bound to any unit group. <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.5, starting from V4.2.5 BP5, the value of this field is always 0.</p></main> |
| LS_GROUP_ID | bigint(20) | NO | Log stream group ID. For system log streams (log stream 1) and broadcast log streams, this field displays as 0, indicating that the log stream does not belong to any log stream group. |
| CREATE_SCN | bigint(20) unsigned | NO | The log position at which the log stream starts writing logs. |
| DROP_SCN | bigint(20) unsigned | NO | The log stream deletion timestamp, which is also the end timestamp of all user data. If the log stream is deleted, this field records the SCN at the time of deletion; if not deleted, this field is empty. |
| SYNC_SCN | bigint(20) unsigned | NO | The synchronization timestamp of the log stream, indicating the SCN of the last successfully synchronized transaction. |
| READABLE_SCN | bigint(20) unsigned | NO | The readable point of a log stream, indicating the minimum SCN at which the log stream can be read. |
| FLAG | varchar(2048) | NO | Log stream tag:<ul><li>NULL: normal log stream</li><li>DUPLICATE: broadcast log stream of a user tenant. A replicated table is created on this log stream.</li><li>BLOCK_TABLET_IN: indicates that a tablet cannot be created on this log stream.</li><li>DUPLICATE\ | BLOCK_TABLET_IN: The current broadcast log stream does not allow creating tablets.</li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0.</p></main> |
| UNIT_LIST | varchar(1216) | NO | Unit list of user log stream distribution. The system log stream and broadcast log stream are empty if no specific location is specified.  <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.5, this field is available starting with V4.2.5 BP5.</p></main> |
