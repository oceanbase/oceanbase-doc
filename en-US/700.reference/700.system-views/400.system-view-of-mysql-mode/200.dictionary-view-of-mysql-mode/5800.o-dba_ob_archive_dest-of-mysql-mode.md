# oceanbase.DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the archive path configuration of the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| DEST_NO | bigint(20) | NO | Identifies log_archive_dest_n |
| NAME | varchar(1024) | NO | Field name, which includes the following fields:<ul><li>`binding`: Priority mode for archiving and business </li> <li>`dest_id`: The ID of the destination archive.</li> <li>`path`: Archive path information</li> <li>`piece_switch_interval`: The switching cycle of the Piece.</li> <li>`state`: The status of the destination for archiving.</li></ul> |
| VALUE | varchar(4096) | NO | `name`Field Value |

## Sample query

Users can view the archive path configuration of their own tenant.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_ARCHIVE_DEST;
```

The query result is as follows:

```shell
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
| DEST_NO | NAME                  | VALUE                                                                                                                         |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
|       0 | binding               | OPTIONAL                                                                                                                      |
|       0 | dest_id               | 1002                                                                                                                          |
|       0 | path                  | oss://example_patharchive?host=cn-******.aliyuncs.com&access_id=******&access_key=*****&checksum_type=md5&enable_worm=true    |
|       0 | piece_switch_interval | 1d                                                                                                                            |
|       0 | state                 | ENABLE                                                                                                                        |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
5 rows in set
```
