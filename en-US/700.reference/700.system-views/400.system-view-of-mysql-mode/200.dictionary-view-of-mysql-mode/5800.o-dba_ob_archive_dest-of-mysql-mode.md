# oceanbase.DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the archive path of the current tenant and the backup destination configuration for archived logs.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| DEST_NO | bigint(20) | NO | Identifies log_archive_dest_n |
| NAME | varchar(1024) | NO | The field name, which contains the following fields:<ul><li>`binding`: the priority mode for archiving and business operations.</li> <li>`dest_id`: the ID of the archive destination.</li> <li>`path`: the archive path information.</li> <li>`piece_switch_interval`: the switching cycle of pieces.</li> <li>`state`: the status of the archive destination.</li><li>`backup_archive_dest_id`: the ID of the backup archive destination.</li><li>`backup_archive_path`: the path of the backup archive destination.</li><li>`backup_archive_state`: the status of the backup archive destination.</li></ul></br>For V4.4.x versions, `backup_archive_dest_id`, `backup_archive_path`, and `backup_archive_state` are introduced starting from V4.4.2 BP3.  |
| VALUE | varchar(4096) | NO | `name`Field Value |

## Sample query

Users can view the archive path configuration of their own tenant.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_ARCHIVE_DEST;
```

The query result is as follows:

```shell
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
| DEST_NO | NAME                  | VALUE                                                                                                                         |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
|       0 | binding               | OPTIONAL                                                                                                                      |
|       0 | dest_id               | 1002                                                                                                                          |
|       0 | path                  | oss://example_patharchive?host=cn-******.aliyuncs.com&access_id=******&access_key=*****&checksum_type=md5&enable_worm=true    |
|       0 | piece_switch_interval | 1d                                                                                                                            |
|       0 | state                 | ENABLE                                                                                                                        |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
5 rows in set
```

You can view the backup destination configurations of the current tenant's archived logs.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_ARCHIVE_DEST WHERE name LIKE '%backup_archive%';
```

The query result is as follows:

```shell
+---------+------------------------+------------------------+
| DEST_NO | NAME                   | VALUE                  |
+---------+------------------------+------------------------+
|   10000 | backup_archive_dest_id | 1004                   |
|   10000 | backup_archive_path    | file:///data/backuparg |
|   10000 | backup_archive_state   | ENABLE                 |
+---------+------------------------+------------------------+
3 rows in set
```
