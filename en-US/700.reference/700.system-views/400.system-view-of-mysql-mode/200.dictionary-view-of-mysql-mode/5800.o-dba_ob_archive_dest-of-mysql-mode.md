# oceanbase.DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the archive path configuration of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_NO | bigint(20) | NO | The identifier of the log_archive_dest_n parameter. |
| NAME | varchar(1024) | NO | The name of the archive destination, which contains the following parameters: <ul><li>`binding`: the priority mode of archive and business. </li><li>`dest_id`: the ID of the archive destination. </li><li>`path`: the archive path. </li><li>`piece_switch_interval`: the switching cycle of a piece. </li><li>`state`: the status of the archive destination. </li></ul> |
| VALUE | varchar(4096) | NO | The value of the `name` parameter. |

## Sample query

Query the archive path configuration of the user tenant.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_ARCHIVE_DEST;
```

The query result is as follows:

```shell
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
```
