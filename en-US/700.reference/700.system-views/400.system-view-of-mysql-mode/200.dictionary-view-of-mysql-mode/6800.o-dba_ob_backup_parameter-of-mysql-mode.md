# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the data backup parameters of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | The parameter name. |
| VALUE | longtext | NO | The parameter value. |

## Sample query

Query the data backup parameters of the current user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_PARAMETER;
```

The query result is as follows:

```shell
+------------------+-----------------------------------------+
| NAME             | VALUE                                   |
+------------------+-----------------------------------------+
| data_backup_dest | file:///home/admin/oceanbase/backupdata |
+------------------+-----------------------------------------+
1 row in set
```
