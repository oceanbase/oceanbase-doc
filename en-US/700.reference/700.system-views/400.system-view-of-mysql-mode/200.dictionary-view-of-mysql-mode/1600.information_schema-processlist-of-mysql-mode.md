# information_schema.PROCESSLIST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view provides information about running threads.

## Columns

| **Column** |       **Type**        | **Nullable** |    **Description**    |
|----------|---------------------|----------------|--------------|
| ID       | bigint(20) unsigned | NO             | Connection identifier<br>For V4.2.x versions:<ul><li> For versions earlier than V4.2.5 BP3 Hotfix5:<br> In all connection modes (direct connect mode / ODP mode), this field represents the Server Session ID.</li><li> For V4.2.5 BP3 Hotfix5 and later versions:<ul><li> In direct connect mode:<br> This field represents the Server Session ID.</li> <li> In ODP mode:<ul><li> If the configuration item <code>client_session_id_version = 2</code> in the ODP is set, this field represents the Client Session ID. </li> <li> If <code>client_session_id_version = 1</code> is set, this field represents the Server Session ID. </li></ul></li></ul></li></ul>         |
| USER     | varchar(32)         | NO             | The username.          |
| HOST     | varchar(128)        | NO             | The name of the client host.      |
| DB       | varchar(128)        | YES            | The name of the database.        |
| COMMAND  | varchar(4096)       | NO             | The type of command executed by the thread.    |
| TIME     | bigint(20)          | NO             | The duration of the thread in the current state, in seconds. |
| STATE    | varchar(128)        | YES            | The identifier of the task being performed by the thread. |
| INFO     | varchar(262143)     | YES            | The statement being executed by the current thread.  |

## Sample query

Query the information about all running threads in a user tenant.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```

The query result is as follows:

```shell
+------------+------+----------------------+-----------+---------+------+--------+----------------------------------------------+
```
