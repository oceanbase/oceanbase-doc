# oceanbase.DBA_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of all historical and current log archives of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | The path ID. The system assigns a unique ID to each path. |
| ROUND_ID | bigint(20) | NO | The ID of the round of full clog backup data. |
| INCARNATION | bigint(20) | NO | The number of incarnations after a Flashback Database operation. |
| DEST_NO | bigint(20) | NO | The ID of the log_archive_dest_n parameter. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| STATUS | varchar(64) | NO | The status of the log archive. Valid values: <ul><li>`PREPARE`: The system is preparing to start the log archive at the `START_SCN` value. </li> <li>`BEGINNING`: The system is starting the log archive. </li> <li>`DOING`: The system is archiving logs. </li><li> `INTERRUPTED`: The log archive is interrupted and requires manual intervention. </li><li>`STOP`: The log archive has been stopped.  </li><li>`STOPPING`: The system is stopping the log archive.  </li><li>`SUSPENDING`: The system is suspending the log archive.  </li><li>`SUSPEND`: The log archive has been suspended.  </li></ul> |
| START_SCN | bigint(20) unsigned | NO | The start SCN of the backup. |
| START_SCN_DISPLAY | datetime(6) | NO | The start SCN converted to a time unit. |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | The current archive SCN. |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | The current archive SCN converted to a time unit. |
| COMPATIBLE | bigint(20) | NO | The compatibility version. |
| BASE_PIECE_ID | bigint(20) | NO | The ID of the first PIECE in the current round. |
| USED_PIECE_ID | bigint(20) | NO | The ID of the PIECE used in the current round. |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | The interval for switching PIECES. |
| UNIT_SIZE   | bigint(20)   | NO   | The size of a log block that is compressed or encrypted in a single log archive operation. This field is not supported in OceanBase Database.    |
| COMPRESSION | varchar(128) | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used. </li></ul> This field is not supported in OceanBase Database.    |
| INPUT_BYTES | bigint(20) | NO | The size of the data read. <li> This field is not supported in OceanBase Database. |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the data read, with a unit. For example: 798.01 M or 5.25 G. <li> This field is not supported in OceanBase Database. |
| OUTPUT_BYTES | bigint(20) | NO | The size of the data output. <li> This field is not supported in OceanBase Database. |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the data output, with a unit. For example: 798.01 M or 5.25 G. <li> This field is not supported in OceanBase Database. |
| COMPRESSION_RATIO | decimal(23,2) | NO | The compression ratio. <li> This field is not supported in OceanBase Database. |
| DELETED_INPUT_BYTES | bigint(20) | NO | The size of the original data deleted. |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the original data deleted, with a unit. Valid values: MB, GB, TB, and PB. |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | The size of the effective data deleted. |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the effective data deleted, with a unit. Valid values: MB, GB, TB, and PB. |
| PATH | varchar(2048) | NO | The archive path.  |
| COMMENT | varchar(262144) | NO | The error message. |
