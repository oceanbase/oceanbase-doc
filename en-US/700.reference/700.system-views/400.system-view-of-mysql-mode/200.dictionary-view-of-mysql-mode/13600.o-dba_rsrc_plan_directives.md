# oceanbase.DBA_RSRC_PLAN_DIRECTIVES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.1.2. </p>
</main>

## Purpose

This view displays the details of each resource plan instruction in the current tenant.

## Sample query

Query the information about resource plan directives in the current user tenant.

```shell
obclient [oceanbase]> SELECT PLAN, GROUP_OR_SUBPLAN FROM oceanbase.DBA_RSRC_PLAN_DIRECTIVES;
```

The query result is as follows:

```shell
+---------+-------------------+
| PLAN    | GROUP_OR_SUBPLAN  |
+---------+-------------------+
| daytime | batch_group       |
| daytime | interactive_group |
+---------+-------------------+
2 rows in set
```
