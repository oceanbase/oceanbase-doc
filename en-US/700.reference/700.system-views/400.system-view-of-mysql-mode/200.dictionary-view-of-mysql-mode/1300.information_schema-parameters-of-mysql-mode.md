# information_schema.PARAMETERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays information about stored procedure parameters and return values in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SPECIFIC_CATALOG | varchar(512) | NO | Fixed value (def) |
| SPECIFIC_SCHEMA | varchar(128) | NO | Database name |
| SPECIFIC_NAME | varchar(64) | NO | Stored procedure name |
| ORDINAL_POSITION | bigint(20) | NO | Parameter position (0 for return values) |
| PARAMETER_MODE | varchar(5) | NO | Parameter type: <ul><li>   IN</li><li>   OUT</li><li>   INOUT</li><li>    NULL</li></ul> |
| PARAMETER_NAME | varchar(64) | YES | Parameter name |
| DATA_TYPE | varchar(64) | NO | Parameter data type |
| CHARACTER_MAXIMUM_LENGTH | bigint(20) | NO | Maximum character length for string parameters |
| CHARACTER_OCTET_LENGTH | bigint(20) | NO | Maximum byte length for string parameters |
| NUMERIC_PRECISION | bigint(20) unsigned | NO | Precision for numeric parameters |
| NUMERIC_SCALE | bigint(20) | NO | Scale for numeric parameters |
| DATETIME_PRECISION | bigint(20) unsigned | NO | Precision for date parameters |
| CHARACTER_SET_NAME | varchar(64) | NO | Character set for string parameters |
| COLLATION_NAME | varchar(64) | NO | Collation for string parameters |
| DTD_IDENTIFIER | longtext | NO | Detailed data type information in character form |
| ROUTINE_TYPE | varchar(9) | NO | Stored procedure type (procedure/function) |
