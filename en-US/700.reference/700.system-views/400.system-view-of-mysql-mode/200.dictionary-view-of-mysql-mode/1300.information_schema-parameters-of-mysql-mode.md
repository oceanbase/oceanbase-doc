# information_schema.PARAMETERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays information about parameters and return values of stored procedures in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SPECIFIC_CATALOG | varchar(512) | NO | Fixed value (def). |
| SPECIFIC_SCHEMA | varchar(128) | NO | Database name. |
| SPECIFIC_NAME | varchar(64) | NO | Stored procedure name. |
| ORDINAL_POSITION | bigint(20) | NO | Parameter position. For the return value of a function, this value is 0. |
| PARAMETER_MODE | varchar(5) | NO | Parameter type:<ul><li>   IN</li><li>   OUT</li><li>   INOUT</li><li>    NULL</li></ul> |
| PARAMETER_NAME | varchar(64) | YES | Parameter name. |
| DATA_TYPE | varchar(64) | NO | Parameter data type. |
| CHARACTER_MAXIMUM_LENGTH | bigint(20) | NO | For string-type parameters, the maximum length of characters. |
| CHARACTER_OCTET_LENGTH | bigint(20) | NO | For string-type parameters, the maximum length of bytes. |
| NUMERIC_PRECISION | bigint(20) unsigned | NO | For numeric-type parameters, the precision. |
| NUMERIC_SCALE | bigint(20) | NO | For numeric-type parameters, the scale. |
| DATETIME_PRECISION | bigint(20) unsigned | NO | For date-type parameters, the precision. |
| CHARACTER_SET_NAME | varchar(64) | NO | For string-type parameters, the character set. |
| COLLATION_NAME | varchar(64) | NO | For string-type parameters, the collation. |
| DTD_IDENTIFIER | longtext | NO | The detailed information of the data type in character form. |
| ROUTINE_TYPE | varchar(9) | NO | The type of the stored procedure (procedure/function). |
