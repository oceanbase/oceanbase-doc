# mysql.default_roles

<main id="notice" type='explain'>
 <h4>Note</h4>
 <ul><li>This view is available starting with V4.3.1 in V4.3.x. </li><li>This view is available starting with V4.2.3 in V4.2.x. </li></ul>
</main>

## Purpose

The `mysql.default_roles` view displays information about the roles enabled by default for users.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------- | -------- | --------------- | -------- |
| HOST              | varchar(255) | NO   | The Host name of the account.     |
| USER              | varchar(128) | NO   | The account name.     |
| DEFAULT_ROLE_HOST | varchar(255) | NO   | The Host name of the role enabled by default.     |
| DEFAULT_ROLE_USER | varchar(128) | NO   | The account name of the role enabled by default.     |

## Sample query

Query the default roles enabled for the `user001` user.

1. Create a role named `role1`.

   ```shell
   obclient [oceanbase]> CREATE ROLE IF NOT EXISTS role1;
   Query OK, 0 rows affected, 1 warning
   ```

2. Grant the `ALTER SYSTEM` privilege to the `role1` role.

   ```shell
   obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
   ```

3. Create a user named `user001`.

   ```shell
   obclient [oceanbase]> CREATE USER 'user001'@'%' IDENTIFIED BY '******';
   ```

4. Grant the `role1` role to the newly created `user001` user.

   ```shell
   obclient [oceanbase]>GRANT role001 TO user001 WITH ADMIN OPTION;;
   ```

5. Specify that all roles granted to the `user001` user are activated by default upon login.

   ```shell
   obclient > SET DEFAULT ROLE ALL TO user001;
   ```

6. Query the default roles enabled for the `user001` user.

   ```shell
   obclient > SELECT * FROM mysql.default_roles;
   ```

   The query result is as follows:

   ```shell
   +------+---------+-------------------+-------------------+
   | HOST | USER    | DEFAULT_ROLE_HOST | DEFAULT_ROLE_USER |
   +------+---------+-------------------+-------------------+
   | %    | user001 | %                 | role001           |
   +------+---------+-------------------+-------------------+
   1 row in set (0.001 sec)
   ```
