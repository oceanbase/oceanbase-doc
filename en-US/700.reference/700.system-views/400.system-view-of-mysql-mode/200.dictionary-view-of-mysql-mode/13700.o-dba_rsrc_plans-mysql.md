# oceanbase.DBA_RSRC_PLANS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.1.2. </p>
</main>

## Purpose

This view displays all system-defined resource management plans.

## Columns

|           Column            |       Type       | Nullable |                         Description                         |
|---------------------------|----------------|------------|----------------------------------------------------|
| PLAN_ID                   | decimal(10,0)         | NO         | The ID of the resource plan.                                          |
| PLAN                      | varchar(128)  | NO         | The name of the resource plan.                                             |
| NUM_PLAN_DIRECTIVES       | decimal(10,0)         | NO         | The number of directives defined in the resource plan. This column is for compatibility only and is always `NULL`.  |
| CPU_METHOD                | varchar(128)  | NO         | This column is for compatibility only and is always `NULL`.                               |
| MGMT_METHOD               | varchar(128)  | NO         | This column is for compatibility only and is always `NULL`.                               |
| ACTIVE_SESS_POOL_MTH      | varchar(128)  | NO         | This column is for compatibility only and is always `NULL`.                               |
| PARALLEL_DEGREE_LIMIT_MTH | varchar(128)  | NO         | This column is for compatibility only and is always `NULL`.                               |
| QUEUING_MTH               | varchar(128)  | NO         | This column is for compatibility only and is always `NULL`.                               |
| SUB_PLAN                  | varchar(3)    | NO         | This column is for compatibility only and is always `NULL`.                               |
| COMMENTS                  | varchar(2000) | YES        | The remarks about the resource plan.                                         |
| STATUS                    | varchar(128)  | NO         | This column is for compatibility only and is always `NULL`.                               |
| MANDATORY                 | varchar(3)    | NO         | This column is for compatibility only and is always `NULL`.                               |

## Sample query

Query all system-defined resource management plans in the user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_PLANS;
```

The query result is as follows:

```shell

+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
|    NULL | daytime |                NULL | NULL       | NULL        | NULL                 | NULL                      | NULL        | NULL     | TPFirst  | NULL   | NULL      |

1 row in set
```
