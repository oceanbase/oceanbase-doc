# oceanbase.DBA_SUBPART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the columns of the subpartition keys in all partitioned objects of the current tenant.

## Columns

|      **Column**      |    **Type**     | **Nullable** |                                                              **Description**                                                              |
|--------------------|---------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | varchar(128)  | NO             | The owner of the partitioned table or partitioned index.                                  |
| NAME               | varchar(128)  | NO             | The name of the partitioned table or partitioned index.                                   |
| OBJECT_TYPE        | varchar(5)    | NO             | The type of the partitioned object. Valid values: <ul><li>TABLE   </li><li> INDEX </li></ul>   |
| COLUMN_NAME        | text | NO             | The name of the column.                                          |
| COLUMN_POSITION    | bigint(21)    | NO             | The position of the column in the partition key.                                     |
| COLLATED_COLUMN_ID | bigint(0)     | NO             | This column is not supported. The value of this column is NULL by default.                       |

## Sample query

Query the columns of the subpartition keys in the partitioned table `tbl2_f_rl` of the current user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPART_KEY_COLUMNS WHERE NAME='tbl2_f_rl';
```

The query result is as follows:

```shell
+----------+-----------+-------------+-------------+-----------------+--------------------+
| OWNER    | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+----------+-----------+-------------+-------------+-----------------+--------------------+
| infotest | tbl2_f_rl | TABLE       | col2        |               1 |               NULL |
+----------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
