# oceanbase.DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the configuration information of the write replay feature.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or the ID of the Meta tenant. </li></ul> |
| SNAP_INTERVAL | varchar(64) | NO | The interval between two snapshots, in the `DD HH:mm:SS` format for easy reading. |
| RETENTION | varchar(64) | NO | The retention time of each snapshot, in the `DD HH:mm:SS` format for easy reading. |
| TOPNSQL | bigint(20) | NO | The stored topN SQL. |
