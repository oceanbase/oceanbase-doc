# oceanbase.DBA_OB_ARCHIVELOG

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the log archiving status of each path in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | The identifier of the path. |
| ROUND_ID | bigint(20) | NO | The identifier of the backup round. |
| INCARNATION | bigint(20) | NO | The number of incarnations after a flashback database operation. |
| DEST_NO | bigint(20) | NO | The identifier of log_archive_dest_n. |
| STATUS | varchar(64) | NO | The archiving status. Valid values: <ul><li>`PREPARE`: The archiving starts at `START_SCN`. </li> <li>`BEGINNING`: The log archiving is being started.  </li> <li>`DOING`: The log archiving is being performed. </li><li> `INTERRUPTED`: The log archiving is interrupted and requires manual intervention. </li><li>`STOP`: The log archiving has been stopped.  </li><li>`STOPPING`: The log archiving is being stopped.  </li><li>`SUSPENDING`: The log archiving is being paused.  </li><li>`SUSPEND`: The log archiving has been paused.  </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | The starting backup SCN. |
| START_SCN_DISPLAY | datetime(6) | NO | The time corresponding to the START_SCN. |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | The current archiving SCN. |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | The time corresponding to the CHECKPOINT_SCN. |
| COMPATIBLE | bigint(20) | NO | The compatibility version. |
| BASE_PIECE_ID | bigint(20) | NO | The ID of the first PIECE in the current round. |
| USED_PIECE_ID | bigint(20) | NO | The ID of the last PIECE used in the current round. |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | The piece switching cycle. |
| UNIT_SIZE   | bigint(20)   | NO   | The size of a single log block that is compressed or encrypted in the log archiving. This field is not supported.    |
| COMPRESSION | varchar(128) | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used.</li></ul> This field is not supported.   |
| INPUT_BYTES | bigint(21) | NO | The size of the data read, in bytes. |
| INPUT_BYTES_DISPLAY | varchar(28) | NO | The size of the data read, in MB, GB, TB, or PB. |
| OUTPUT_BYTES | bigint(21) | NO | The size of the data output, in bytes. |
| OUTPUT_BYTES_DISPLAY | varchar(28) | NO | The size of the data output, in MB, GB, TB, or PB. |
| COMPRESSION_RATIO | decimal(24,2) | NO | The compression ratio. This field is not supported. |
| DELETED_INPUT_BYTES | bigint(20) | NO | The size of the original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the original data deleted, in MB, GB, TB, or PB. |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | The size of the effective data deleted, in bytes. |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the effective data deleted, in MB, GB, TB, or PB. |
| COMMENT | varchar(262144) | NO | The error message. |
| PATH | varchar(2048) | NO | The archiving path. |
