# mysql.audit_log_user

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view was introduced in OceanBase Database V4.2.4. </p>
</main>

## Purpose

The `mysql.audit_log_user` view displays the mappings between audit filters and users.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support security audit. </p>
</main>

## Columns

| Column | Type | Nullable? | Description |
|------------|-------------|---------------------|----------------------------------------|
| USER       | varchar(128) | NO | The username. |
| HOST       | varchar(128) | NO | The name of the host. |
| FILTERNAME | varchar(64) | NO | The name of the filter. |

## Sample query

```shell
obclient [mysql]> select * from mysql.audit_log_user;
```

The query result is as follows:

```shell
+---------+------+------------+
| USER    | HOST | FILTERNAME |
+---------+------+------------+
| user001 | %    | log_all    |
+---------+------+------------+
1 row in set (0.003 sec)
```
