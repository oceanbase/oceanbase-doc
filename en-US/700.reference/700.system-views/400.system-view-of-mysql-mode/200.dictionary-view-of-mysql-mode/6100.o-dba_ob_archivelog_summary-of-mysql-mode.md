# oceanbase.DBA_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of all log archives in the current and historical tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | The path ID. The system assigns a unique ID to each configured path. |
| ROUND_ID | bigint(20) | NO | The ID of a complete Clog backup data stream. |
| INCARNATION | bigint(20) | NO | The number of times the database has been flashbacked. |
| DEST_NO | bigint(20) | NO | The ID of the log_archive_dest_n parameter. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| STATUS | varchar(64) | NO | The status of the log archive. Valid values: <ul><li>`PREPARE`: The system is preparing to start archiving at the `START_SCN` point. </li><li>`BEGINNING`: The system is starting to archive logs. </li><li>`DOING`: The system is archiving logs. </li><li> `INTERRUPTED`: The log archive is interrupted and requires manual intervention. </li><li>`STOP`: The system has stopped archiving logs. </li><li>`STOPPING`: The system is stopping archiving logs. </li><li>`SUSPENDING`: The system is suspending archiving logs. </li><li>`SUSPEND`: The system has suspended archiving logs. </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | The starting backup point. |
| START_SCN_DISPLAY | datetime(6) | NO | The start time converted from the START_SCN value. |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | The current archive point. |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | The checkpoint time converted from the CHECKPOINT_SCN value. |
| COMPATIBLE | bigint(20) | NO | The compatibility version. |
| BASE_PIECE_ID | bigint(20) | NO | The ID of the first PIECE in the current round. |
| USED_PIECE_ID | bigint(20) | NO | The ID of the last PIECE used in the current round. |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | The interval for switching pieces. |
| UNIT_SIZE   | bigint(20)   | NO   | The size of a single log block for compression or encryption in the current round. This column is not supported.  |
| COMPRESSION | varchar(128) | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used. </li></ul> This column is not supported.   |
| INPUT_BYTES | bigint(20) | NO | The amount of data read, in bytes. |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of data read, in bytes, with a unit. For example: 798.01 M or 5.25 G. |
| OUTPUT_BYTES | bigint(20) | NO | The amount of data output, in bytes. |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of data output, in bytes, with a unit. For example: 798.01 M or 5.25 G. |
| COMPRESSION_RATIO | decimal(23,2) | NO | The compression ratio. This column is not supported. |
| DELETED_INPUT_BYTES | bigint(20) | NO | The amount of original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of original data deleted, in MB, GB, TB, or PB. |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | The amount of effective data deleted, in bytes. |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of effective data deleted, in MB, GB, TB, or PB. |
| PATH | varchar(2048) | NO | The archive path. |
| COMMENT | varchar(262144) | NO | The error message. |
