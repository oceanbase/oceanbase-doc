# oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS` view displays information about backup validation jobs initiated by the current tenant. Each job corresponds to a backup validation instruction.

## Columns

| Column             | Type           | Nullable | Description           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | bigint(20)     | NO   | The job ID.     |
| INCARNATION         | bigint(20)     | NO   | The incarnation ID.     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | The ID of the tenant that initiated the job.   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | The ID of the job that initiated the job. If the value is 0, the job was initiated by itself.     |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | The ID of the user tenant that needs to execute the validation task for this job. If the value is empty, the validation task is executed by the current tenant.     |
| TYPE                | varchar(64)    | NO   | The type of the validation task:<ul><li>`DATABASE`: Validates all backup sets and archive logs in the backup path and archive path. </li> <li>`BACKUPSET`: Validates the specified backup set. </li> <li>`ARCHIVELOG_PIECE`: Validates the specified archive log piece. </li></ul>     |
| PATH                | longtext       | YES  | The backup path or archive log path specified by the user for validation. If the value is empty, the task is for validating the entire backup path and archive path.     |
| PATH_TYPE           | varchar(64)    | YES  | The type of the specified path for validation (if the value is empty, the task is for validating the entire backup path and archive path):<ul><li>`BACKUPSET`: Validates the backup set in the specified path. </li> <li>`ARCHIVELOG_PIECE`: Validates the archive log piece in the specified path. </li></ul>     |
| ID                  | longtext       | YES  | <p>The `backup_set_id` of the backup set to be validated or the `piece_id` of the archive log piece to be validated.</p><p>By default, this value is empty, indicating that all backup sets and archive log pieces in the current backup path and archive path will be validated. When the user specifies the `backup_set_id` of a backup set or the `piece_id` of an archive log piece for validation, the value changes to the corresponding ID or ID list. </p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | The validation level:<ul><li>`basic`: Only checks the completeness of the file list. </li> <li>`physical`: Checks the correctness of physical data and logical consistency. </li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | The start time of the validation task.     |
| END_TIMESTAMP       | timestamp(6)   | NO   | The end time of the validation task.     |
| STATUS              | varchar(64)    | NO   | The status of the job:<ul><li>`INIT`: The validation task is being initialized. </li> <li>`DOING`: The validation task is being executed. </li> <li>`COMPLETED`: The validation task has been completed. </li> <li>`FAILED`: The validation task has failed. </li> <li>`CANCELED`: The validation task has been canceled. </li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | The number of retries.     |
| TASK_COUNT          | bigint(20)     | YES  | The total number of validation tasks for the backup set or archive log piece.     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | The number of successful validation tasks for the backup set or archive log piece.     |
| RESULT              | bigint(20)     | NO   | The error code of the validation result.    |
| DESCRIPTION         | varchar(4096)  | YES  | External information provided by OCP.    |
| COMMENT             | varchar(4096)  | YES  | The description of the reason for the failure of the validation task.      |

## Sample query

Query the information about backup validation jobs initiated by the current user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS\G
```
