# oceanbase.DBA_OB_LS_LOCATIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V4.0.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_LS_LOCATIONS` view displays the distribution of the log stream replicas in the current tenant.

## Columns

| Column | Type | Nullable? | Description |
|--------------|----------------|------------|----------------------------------------------------------------------|
| CREATE_TIME | datetime(6) | NO | The time when the log stream replica was created. |
| MODIFY_TIME | datetime(6) | NO | The time when the log stream replica was last modified. |
| LS_ID | bigint(20) | NO | The ID of the log stream replica. |
| SVR_IP | varchar(46) | NO | The IP address of the OBServer node. |
| SVR_PORT | bigint(20) | NO | The port number of the OBServer node. |
| SQL_PORT | bigint(20) | NO | The SQL port number. |
| ZONE | varchar(128) | NO | The name of the zone. |
| ROLE | varchar(8) | NO | The role of the replica. Valid values:<li>`LEADER`<li>`FOLLOWER` |
| MEMBER_LIST | varchar(4480) | NO         | The list of replica members. Multiple replicas are separated with commas (,). <ul><li>This column is valid when the value of `ROLE` is `LEADER`. A single replica is identified in the `svr_ip:svr_port:timestamp` format. The parameters are described as follows: <ul><li>`svr_ip`: the IP address of the OBServer node where the replica resides.</li> <li>`svr_port`: the port number of the OBServer node where the replica resides.</li> <li>`timestamp`: the time when the replica was added to the `MEMBER_LIST`. The default value is `1`, which changes after you add or migrate a replica.</li></ul></br> Here is an example: `172.xx.xxx.xxx:2882:1`.</li> <li>The value of this column is `NULL` when the value of `ROLE` is not `LEADER`. </li></ul> |
| PAXOS_REPLICA_NUMBER | bigint(20) | NO         | The quorum of a Paxos group. This column is valid when the value of `ROLE` is `LEADER`. In other cases, the value of this column is `NULL`. |
| REPLICA_TYPE | varchar(18) | NO         | The replica type. Valid values: <li> `FULL`: indicates a full-featured replica. <li> `READONLY`: indicates a read-only replica. |
| LEARNER_LIST | longtext      | YES        | The list of read-only replicas in the current log stream. Multiple replicas are separated with commas (,). A single replica is identified in the `svr_ip:svr_port:timestamp:flag` format. The parameters are described as follows: <ul><li>`svr_ip`: the IP address of the OBServer node where the replica resides.</li> <li>`svr_port`: the port number of the OBServer node where the replica resides.</li> <li>`timestamp`: the time when the replica was added to the `LEARNER_LIST`. The default value is `1`, which changes after you add or migrate a replica.</li> <li>`flag`: indicates whether the replica is being migrated. The value `0` indicates that the replica is not being migrated. The value `2` indicates that the replica is being migrated. </li></ul></br>Here is an example: `172.xx.xxx.xxx:2882:1:0`. <main id="notice" type='explain'><h4>Note</h4><p>This column was introduced in OceanBase Database V4.2.0. </p></main> |
| REBUILD      | varchar(5)    | NO         | Indicates whether the replica is being rebuilt.<main id="notice" type='explain'><h4>Note</h4><p>This column was introduced in OceanBase Database V4.2.1. </p></main>|
