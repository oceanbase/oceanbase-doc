# mysql.user

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.1. </p>
</main>

## Purpose

This view displays the global privileges of a user (VIRTUAL_TABLE).

## Columns

|        **Column**        |    **Type**     | **Nullable** |                      **Description**                       |
|------------------------|---------------|----------------|---------------------------------------------------|
| host                   | varchar(128)  | NO             | The host name.                                               |
| user                   | varchar(128)  | NO             | The username.                                               |
| password               | varchar(128)  | NO             | The password of the user.                                              |
| select_priv            | varchar(1)    | NO             | Indicates whether the user can execute SELECT statements.                                   |
| insert_priv            | varchar(1)    | NO             | Indicates whether the user can execute INSERT statements.                                   |
| update_priv            | varchar(1)    | NO             | Indicates whether the user can execute UPDATE statements.                                   |
| delete_priv            | varchar(1)    | NO             | Indicates whether the user can execute DELETE statements.                                   |
| create_priv            | varchar(1)    | NO             | Indicates whether the user can execute CREATE statements.                                   |
| drop_priv              | varchar(1)    | NO             | Indicates whether the user can execute DROP statements.                                     |
| reload_priv            | varchar(1)    | NO             | Indicates whether the user can execute FLUSH statements. This column is not currently used.                          |
| shutdown_priv          | varchar(1)    | NO             | Indicates whether the user can execute the SHUTDOWN command. This column is not currently used.                       |
| process_priv           | varchar(1)    | NO             | Indicates whether the user can query information about active threads.                                       |
| file_priv              | varchar(1)    | NO             | Indicates whether the user has file read/write permissions. This column is not currently used.                              |
| grant_priv             | varchar(1)    | NO             | Indicates whether the user can execute GRANT statements.                                         |
| reference_priv         | varchar(1)    | NO             | This column is not currently used.                                              |
| index_priv             | varchar(1)    | NO             | Indicates whether the user can create indexes.                                           |
| alter_priv             | varchar(1)    | NO             | Indicates whether the user can execute ALTER statements.                                    |
| show_db_priv           | varchar(1)    | NO             | Indicates whether the user can execute the `SHOW DATABASES` statement.                          |
| super_priv             | varchar(1)    | NO             | Indicates whether the user can execute superuser statements.                                       |
| create_tmp_table_priv  | varchar(1)    | NO             | Indicates whether the user can create temporary tables. This column is not currently used.                                     |
| lock_tables_priv       | varchar(1)    | NO             | Indicates whether the user can execute the `LOCK TABLES` statement. This column is not currently used. |
| execute_priv           | varchar(1)    | NO             | Indicates whether the user can execute stored procedures. This column is not currently used.                               |
| repl_slave_priv        | varchar(1)    | NO             | This column is not currently used.                                              |
| repl_client_priv       | varchar(1)    | NO             | This column is not currently used.                                              |
| create_view_priv       | varchar(1)    | NO             | Indicates whether the user can create views.                                           |
| show_view_priv         | varchar(1)    | NO             | Indicates whether the user can execute the `SHOW CREATE VIEW` statement.                       |
| create_routine_priv    | varchar(1)    | NO             | Indicates whether the user can create stored procedures. This column is not currently used.                               |
| alter_routine_priv     | varchar(1)    | NO             | Indicates whether the user can modify stored procedures. This column is not currently used.                               |
| create_user_priv       | varchar(1)    | NO             | Indicates whether the user can execute the `CREATE USER` statement.                            |
| event_priv             | varchar(1)    | NO             | Indicates whether the current user has the privilege to create, change, or delete events. This column is not currently used. |
| trigger_priv           | varchar(1)    | NO             | The privilege to operate a trigger. This column is currently not in use.    |
| create_tablespace_priv | varchar(1)    | NO             | This column indicates whether you can create a tablespace. This column is not in use.  |
| ssl_type               | varchar(10)   | NO             | This field is currently unused.                             |
| ssl_cipher             | varchar(1024) | NO             | This column is not used at the moment.                    |
| x509_issuer            | varchar(1024) | NO             | This column is not currently in use.                         |
| x509_subject | varchar(1024) | NO | This column is unused. |
| max_questions          | bigint(20)    | NO             | The maximum number of queries per hour for the user (not in use)                       |
| max_updates            | bigint(20)    | NO             | The maximum number of updates allowed per hour for a user. This field is not currently used.             |
| max_connections        | bigint(20)    | NO             | Displays the maximum number of connections allowed per hour for the user. This column is not in use at the current time.                        |
| max_user_connections | bigint(20)    | NO             | The maximum number of simultaneous connections requested. This field is currently not used.                             |
| plugin                 | varchar(1024) | NO             | This column is not currently used.                        |
| authentication_string | varchar(1024) | NO             | This field is not in use.                               |
| password_expired       | varchar(1)    | NO             | This column indicates whether the password has expired. It is not currently used.                                      |
| Column             | Type             | Nullable | Description          | |--------------------|------------------|----------|-----------------------| | account_locked     | varchar(1)       | NO       | Whether the user is locked.  |
| drop_database_link_priv   | varchar(1)    | NO   | Indicates whether a database link can be dropped. |
| create_database_link_priv | varchar(1)    | NO   | Whether a user can create a database link.      |
| create_role_priv          | varchar(1)    | NO   | Can you create a role?     |
| drop_role_priv            | varchar(1)    | NO   | Whether you can drop a role. |
