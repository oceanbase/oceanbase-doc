# mysql.user

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.1. </p>
</main>

## Purpose

This view displays the global permissions of a user (VIRTUAL_TABLE).

## Columns

|        **Column**        |    **Type**     | **Nullable** |                      **Description**                       |
|------------------------|---------------|----------------|---------------------------------------------------|
| host                   | varchar(128)  | NO             | The name of the host.                                               |
| user                   | varchar(128)  | NO             | The username.                                               |
| password               | varchar(128)  | NO             | The user password.                                              |
| select_priv            | varchar(1)    | NO             | Indicates whether the user has the SELECT privilege.                                   |
| insert_priv            | varchar(1)    | NO             | Indicates whether the user has the INSERT privilege.                                   |
| update_priv            | varchar(1)    | NO             | Indicates whether the user has the UPDATE privilege.                                   |
| delete_priv            | varchar(1)    | NO             | Indicates whether the user has the DELETE privilege.                                   |
| create_priv            | varchar(1)    | NO             | Indicates whether the user has the CREATE privilege.                                   |
| drop_priv              | varchar(1)    | NO             | Indicates whether the user has the DROP privilege.                                     |
| reload_priv            | varchar(1)    | NO             | Indicates whether the user has the FLUSH privilege. This privilege is not currently used.                          |
| shutdown_priv          | varchar(1)    | NO             | Indicates whether the user has the SHUTDOWN privilege. This privilege is not currently used.                       |
| process_priv           | varchar(1)    | NO             | Indicates whether the user has the privilege to query active thread information.                                       |
| file_priv              | varchar(1)    | NO             | Indicates whether the user has file read and write privileges. This privilege is not currently used.                              |
| grant_priv             | varchar(1)    | NO             | Indicates whether the user has the privilege to execute the GRANT statement.                                         |
| reference_priv         | varchar(1)    | NO             | This privilege is not currently used.                                              |
| index_priv             | varchar(1)    | NO             | Indicates whether the user has the privilege to create indexes.                                           |
| alter_priv             | varchar(1)    | NO             | Indicates whether the user has the privilege to execute the ALTER statement.                                    |
| show_db_priv           | varchar(1)    | NO             | Indicates whether the user has the privilege to execute the `show database` statement.                          |
| super_priv             | varchar(1)    | NO             | Indicates whether the user has the privilege to execute superuser statements.                                       |
| create_tmp_table_priv  | varchar(1)    | NO             | Indicates whether the user has the privilege to create temporary tables. This privilege is not currently used.                                     |
| lock_tables_priv       | varchar(1)    | NO             | Indicates whether the user has the privilege to execute the `lock tables` statement. This privilege is not currently used. |
| execute_priv           | varchar(1)    | NO             | Indicates whether the user has the privilege to execute stored procedures. This privilege is not currently used.                               |
| repl_slave_priv        | varchar(1)    | NO             | This privilege is not currently used.                                              |
| repl_client_priv       | varchar(1)    | NO             | This privilege is not currently used.                                              |
| create_view_priv       | varchar(1)    | NO             | Indicates whether the user has the privilege to create views.                                           |
| show_view_priv         | varchar(1)    | NO             | Indicates whether the user has the privilege to execute the `show create view` statement.                       |
| create_routine_priv    | varchar(1)    | NO             | Indicates whether the user has the privilege to create stored procedures. This privilege is not currently used.                               |
| alter_routine_priv     | varchar(1)    | NO             | Indicates whether the user has the privilege to modify stored procedures. This privilege is not currently used.                               |
| create_user_priv       | varchar(1)    | NO             | Indicates whether the user has the privilege to execute the `create user` statement.                            |
| event_priv             | varchar(1)    | NO             | Specifies whether you can create, modify, or drop an event. This field is unused for now.                         |
| trigger_priv           | varchar(1)    | NO             | Specifies whether you have the operation permissions of a trigger. This field is unused for now.                      |
| create_tablespace_priv | varchar(1)    | NO             | Specifies whether you can create a tablespace. This field is unused for now.                        |
| ssl_type               | varchar(10)   | NO             | This field is unused for now.                                         |
| ssl_cipher             | varchar(1024) | NO             | This field is unused for now.                                         |
| x509_issuer            | varchar(1024) | NO             | This field is unused for now.                                         |
| x509_subject           | varchar(1024) | NO             | This field is unused for now.                                         |
| max_questions          | bigint(20)    | NO             | The maximum number of queries that a user can perform per hour (unused).                               |
| max_updates            | bigint(20)    | NO             | The maximum number of updates that a user can perform per hour. This field is unused for now.                          |
| max_connections        | bigint(20)    | NO             | The maximum number of connections that a user can receive per hour. This field is unused for now.                          |
| max_user_connections   | bigint(20)    | NO             | The maximum number of concurrent connections. This field is unused for now.                              |
| plugin                 | varchar(1024) | NO             | This field is unused for now.                                         |
| authentication_string  | varchar(1024) | NO             | This field is unused for now.                                         |
| password_expired       | varchar(1)    | NO             | Specifies whether the user password has expired. This field is unused for now.                                |
| account_locked         | varchar(1)    | NO   | Whether the user account is locked    |
| drop_database_link_priv   | varchar(1)    | NO   | Whether you can delete a database link     |
| create_database_link_priv | varchar(1)    | NO   | Whether you can create a database link     |
| create_role_priv          | varchar(1)    | NO   | Whether you can create a role     |
| drop_role_priv            | varchar(1)    | NO   | Whether you can drop a role    |
| user_attributes          | longtext      | NO             | User-defined attributes stored in JSON format. Information about dual passwords is stored in the `additional_password` field.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.2 BP1. </p></main> |
