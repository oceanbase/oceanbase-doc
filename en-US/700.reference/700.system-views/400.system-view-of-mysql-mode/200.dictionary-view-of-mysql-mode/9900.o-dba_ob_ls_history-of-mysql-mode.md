# oceanbase.DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log streams that existed in the current tenant in the past.

## Columns

| Column | Type | Nullable | Description |
|-------------|---------------|-------------|-------------------------------------------|
| LS_ID       | bigint(20)    | NO          | The ID of the log stream.                                 |
| LS_GROUP_ID | bigint(20)    | NO          | The ID of the log stream group.                               |
| STATUS      | varchar(100)  | NO          | The current status of the log stream. Valid values: <ul><li>CREATING: The log stream is being created.</li><li>NORMAL: The log stream is in the normal state.</li><li>DROPPING: The log stream is being dropped.</li><li>PRE_TENANT_DROPPING: A special state of the system log stream. This state indicates that all log streams under the tenant are to be dropped. </li><li>TENANT_DROPPING: The tenant is being dropped, and the log stream is being dropped. </li><li>DROPPED: The log stream has been dropped or is being dropped. </li><li>WAIT_OFFLINE: The log stream is waiting to be dropped. </li><li>CREATE_ABORT: The creation of the log stream is aborted. </li></ul>        |
| FLAG        | varchar(2048) | NO          | The flag of the log stream. Valid values: <ul><li>Empty: The log stream is in the normal state. </li><li>DUPLICATE: The log stream is a broadcast log stream of a user tenant. The replicated tables are created on this log stream. </li> <li>BLOCK_TABLET_IN: The tablet cannot be created on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: The broadcast log stream does not allow the creation of a tablet. </li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          | The GTS when the log stream was created. Unit: nanoseconds.              |

## Sample query

Query the log streams that existed in the current user tenant in the past.

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```

The query result is as follows:

```shell
+-------+-------------+--------+------+---------------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN          |
+-------+-------------+--------+------+---------------------+
|     1 |           0 | NORMAL |      |                   0 |
|  1001 |        1001 | NORMAL |      | 1736152507462028000 |
+-------+-------------+--------+------+---------------------+
2 rows in set
```
