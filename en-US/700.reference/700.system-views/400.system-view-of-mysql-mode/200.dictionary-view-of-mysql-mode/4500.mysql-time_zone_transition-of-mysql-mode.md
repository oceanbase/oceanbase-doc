# mysql.time_zone_transition

## Purpose

The `mysql.time_zone_transition` view displays the information about time zone conversions. It is a system view.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in OceanBase Database V1.4. </p>
</main>

## Columns

| Column | Type | Nullable? | Description |
|--------------------|------------|----------------|-----------|
| Time_zone_id | bigint(20)  | NO         | The ID of the time zone. |
| Transition_time    | bigint(20) | NO             | The time after the time zone conversion. |
| Transition_type_id | bigint(20) | NO             | The ID of the time zone conversion type. |
