# oceanbase.DBA_OBJECTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0.</p>
</main>

## Overview

The `oceanbase.DBA_OBJECTS` view displays all database objects of the current tenant. Its definition is the same as that of the `ALL_OBJECTS` view.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------- | -------------- | ------------ | ------------------------------- |
| OWNER | varchar(128) | NO | Owner of the object |
| OBJECT_NAME | varchar(128) | NO | Object Name |
| SUBOBJECT_NAME | varchar(128) | NO | Subobject name (for example, partition) |
| OBJECT_ID | bigint(20) | NO | Dictionary ID of the object |
| DATA_OBJECT_ID | bigint(20) | NO | Dictionary ID of the segment containing this object |
| OBJECT_TYPE | varchar(23) | NO | Object types, including tables, indexes, partitions, packages, stored procedures, synonyms, sequences, etc. |
| CREATED | datetime | NO | Object creation time |
| LAST_DDL_TIME | datetime | NO | Last DDL Time of Object |
| TIMESTAMP | datetime | NO | The timestamp specified by the object, output as a character |
| STATUS | varchar(7) | NO | Object status: <ul><li>`VALID`: valid</li><li>`INVALID`: invalid </li></ul> |
| TEMPORARY | varchar(1) | NO | Whether this object is a temporary object. |
