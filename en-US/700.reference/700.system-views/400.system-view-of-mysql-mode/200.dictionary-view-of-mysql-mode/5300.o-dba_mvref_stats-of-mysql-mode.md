# oceanbase.DBA_MVREF_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVREF_STATS` view displays the basic timing statistics of materialized view refreshes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| MV_OWNER | varchar(128) | NO | The owner of the materialized view. |
| MV_NAME | varchar(128) | NO | The name of the materialized view. |
| REFRESH_ID | bigint(20) | NO | The ID of the refresh. |
| REFRESH_METHOD | varchar(30) | NO | The method used to refresh the materialized view. <ul><li>FAST: incremental refresh  </li><li>COMPLETE: complete refresh </li></ul>|
| REFRESH_OPTIMIZATIONS | text | NO | The refresh optimizations. For example, empty refresh or primary/foreign key operations applied during materialized view refreshes.<main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only. The value is NULL by default. </p></main> |
| ADDITIONAL_EXECUTIONS | text | NO | Additional executions. For example, index rebuilding or log operations involved during materialized view refreshes.<main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only. The value is NULL by default. </p></main> |
| START_TIME | datetime | NO | The start time of the refresh. |
| END_TIME | datetime | NO | The end time of the refresh. |
| ELAPSED_TIME | bigint(20) | NO | The duration of the refresh.<ul><li>For versions earlier than V4.4.2 BP2, the unit is seconds.</li><li>For V4.4.2, starting from V4.4.2 BP2, the unit is microseconds.</li></ul> |
| LOG_SETUP_TIME | bigint(1) | NO | The time taken to set up logs for the materialized view, in seconds<main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only. The value is 0 by default. </p></main> |
| LOG_PURGE_TIME | bigint(20) | NO | The time taken to purge logs for the materialized view.<ul><li>For versions earlier than V4.4.2 BP2, the unit is seconds.</li><li>For V4.4.2, starting from V4.4.2 BP2, the unit is microseconds.</li></ul> |
| INITIAL_NUM_ROWS | bigint(20) | NO | The initial number of rows in the materialized view (at the start of the refresh). |
| FINAL_NUM_ROWS | bigint(20) | NO | The final number of rows in the materialized view (at the end of the refresh). |
| NUM_STEPS             | bigint(20)          | NO   | The total number of steps in this refresh. <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this column is available starting from V4.4.2 BP2. </p></main>|
| RESULT                | bigint(20)          | NO   | The execution result code of this refresh task. 0 indicates success. <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this column is available starting from V4.4.2 BP2. </p></main>|
| REFRESH_SCN           | bigint(20) unsigned | YES  | The SCN at which the refresh started. <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this column is available starting from V4.4.2 BP2. </p></main>|
| SVR_IP                | varchar(64)         | YES  | The IP address of the OBServer node where the refresh is performed. <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this column is available starting from V4.4.2 BP2. </p></main>|
| SVR_PORT              | bigint(20)          | YES  | The port number of the OBServer node where the refresh is performed. <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this column is available starting from V4.4.2 BP2. </p></main>|

