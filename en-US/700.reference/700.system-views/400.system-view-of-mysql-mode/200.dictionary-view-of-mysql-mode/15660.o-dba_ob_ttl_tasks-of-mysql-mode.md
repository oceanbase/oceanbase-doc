# oceanbase.DBA_OB_TTL_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_TTL_TASKS` view displays the execution status of TTL tasks in the current user tenant in SQL mode.

## Columns

| Column | Type | Nullable | Description |
|---------------|--------------|-------------|-------------------------------------------|
| TABLE_NAME    | varchar(256) | NO   | The name of the table.     |
| TABLE_ID      | bigint(20)   | NO   | The ID of the table.     |
| TASK_ID       | bigint(20)   | NO   | The ID of the current batch task.     |
| START_TIME    | timestamp(6) | NO   | The start time of the task.     |
| MODIFIED_TIME | timestamp(6) | NO   | The update time of the row.   |
| TRIGGER_TYPE  | varchar(8)   | NO   | The type of task trigger:<ul><li>`PERIODIC`: The system triggers the task periodically. </li> <li>`USER`: The user manually triggers the task. </li></ul>       |
| STATUS        | varchar(10)  | NO   | The status of the task:<ul><li>`PENDING`: The task is waiting to reach an executable state. </li> <li>`CANCELED`: The task is canceled. </li> <li>`FINISHED`: The task is completed. </li> <li>`SKIP`: The task is skipped because it has not reached an executable state. </li> <li>`FAILED`: The task execution failed. </li> <li>`TRIGGERING`: The task is being executed on the RS node. </li> <li>`SUSPENDING`: The task is being suspended on the RS node. </li> <li>`CANCELING`: The task is being canceled on the RS node. </li> <li>`MOVING`: The task information is being moved to the task history table on the RS node. </li></ul>     |
| RET_CODE      | varchar(512) | NO   | The error code returned when the task is completed.    |
| TASK_TYPE     | varchar(10)  | NO   | The type of the TTL task:<ul><li>`NORMAL`: Displays tenant-level information. </li> <li>`COMPACTION`: A table-level task that deletes expired data by using compaction. </li></ul>     |

## Sample query

Query the execution status of TTL tasks in the current user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TTL_TASKS;
```

The query result is as follows:

```shell
+------------+----------+---------+----------------------------+----------------------------+--------------+------------+------------+------------+
| TABLE_NAME | TABLE_ID | TASK_ID | START_TIME                 | MODIFIED_TIME              | TRIGGER_TYPE | STATUS     | RET_CODE   | TASK_TYPE  |
+------------+----------+---------+----------------------------+----------------------------+--------------+------------+------------+------------+
| NULL       |       -1 |       3 | 2026-03-11 11:05:05.235833 | 2026-03-11 11:05:05.235833 | USER         | TRIGGERING | OB_SUCCESS | COMPACTION |
+------------+----------+---------+----------------------------+----------------------------+--------------+------------+------------+------------+
1 row in set
```
