# mysql.time_zone_transition_type

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the time zone transition types (SYSTEM_VIEW).

## Columns

|      **Column**      |   **Type**   | **Nullable** |  **Description**   |
|--------------------|------------|----------------|-----------|
| Time_zone_id       | bigint(20) | NO             | The time zone ID.     |
| Transition_type_id | bigint(20) | NO             | The ID of the time zone transition type. |
| Offset             | bigint(20) | NO             | The time zone offset.      |
| Is_DST             | bigint(20) | NO             | Indicates whether the time zone is in daylight saving time.    |
| Abbreviation       | varchar(8) | NO             | The abbreviation.        |
