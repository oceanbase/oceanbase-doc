# mysql.help_keyword

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view, together with the `mysql.help_relation`, `mysql.help_topic`, and `mysql.help_category` views, generates help commands.

## **Columns**

|    **Column**     |   **Type**    | **Nullable** | **Description** |
|-----------------|-------------|----------------|--------|
| help_keyword_id | bigint(20)  | NO             | The ID of the keyword. |
| name            | varchar(64) | NO             | The keyword.    |
