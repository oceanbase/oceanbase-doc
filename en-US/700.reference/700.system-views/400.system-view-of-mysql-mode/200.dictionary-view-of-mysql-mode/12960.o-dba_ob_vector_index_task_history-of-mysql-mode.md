# oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

The `DBA_OB_VECTOR_INDEX_TASK_HISTORY` view displays the historical information of all vector index partition rebuild tasks, segment merge tasks, and segment merge dump tasks in the current tenant. You can use the `TASK_TYPE` column to distinguish the task types.

## Columns

| Column                   | Type      | Nullable | Description |
|---------------------------|---------------|------|----|
| TABLE_ID	                | bigint(20)	| YES   | The ID of the table. |
| TABLET_ID	                | bigint(20)	| YES   | The ID of the partition. |
| TASK_ID	                | bigint(20)	| YES   | The ID of the task. |
| START_TIME	                | timestamp(6)	| YES   | The start time of the task. |
| MODIFY_TIME	                | timestamp(6)	| YES   | The end time of the task. |
| TRIGGER_TYPE	                | varchar(16)	| NO   | The type of the task trigger. Valid values: <ul><li><code>0</code>: automatic trigger</li><li><code>1</code>: manual trigger</li></ul> |
| STATUS	                | varchar(16)	| NO   | The status of the task. Valid values: <ul><li><code>0</code>: task is preparing</li><li><code>1</code>: task is in progress</li><li><code>2</code>: task is paused</li><li><code>3</code>: task is completed</li></ul> |
| TASK_TYPE	                | bigint(20)	| NO   | The type of the task. Valid values: <ul><li><code>0</code>: asynchronous build</li><li><code>1</code>: index partition rebuild</li><li><code>5</code>: freeze dump task</li><li><code>6</code>: segment merge task</li></ul>     | |
| TASK_SCN	                | bigint(20)	| NO   | The version number of the task. |
| RET_CODE	                | bigint(20)	| NO   | The status of the task when it is completed. Valid values: <ul><li><code>0</code>: successful</li><li><code>non-zero</code>: failed</li></ul> |
| TRACE_ID	                | varchar(512)	| NO   | The trace ID of the task. |
| TASK_INFO                  | long text    | NO   | The detailed progress of the task. The information is in JSON format and includes details about each segment in the segment merge task, such as the SCN, key range, index, and memory usage of each segment. This helps you understand the task execution process. |

## Sample query

In the sys tenant, query the historical information of vector index performance optimization tasks of all tenants.

```sql
SELECT * FROM oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY ORDER BY MODIFY_TIME DESC\G;
```

The following table describes the JSON string in the TASK_INFO field.

| Column | JSON field type | Description |
|---|---|---|
| merge_segments_cnt | string | The number of segments to be merged. |
| merge_segments | array | The information about the segments to be merged. The number of elements in this array is the same as that in the merge_segments_cnt field. |
| result_segments | array | The information about the merged segments. |
| scn | string | The internal timestamp. |
| start_key | string | The upper bound of the storage range of the segment. |
| end_key | string | The lower bound of the storage range of the segment. |
| index_type | string | The index type for processing vectors in the segment. Valid values: <ul><li>HNSW</li><li>HNSW_SQ</li><li>HNSW_BQ</li><li>HGRAPH</li><li>SINDI</li></ul> |
| mem_used | string | The memory used by the segment. |
| min_vid | string | The minimum vector ID in the segment. |
| max_vid | string | The maximum vector ID in the segment. |
