# oceanbase.DBA_OB_AI_MODELS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

This view displays the AI model information of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| MODEL_ID | int(20) | NO | The unique ID of the large model. |
| NAME | varchar(128) | NO | The unique name of the large model defined by the user. This name is used when calling an AI function or the `DBMS_AI_SERVICE` package. |
| TYPE | varchar(128) | NO | The type of the large model. Valid values: <ul><li><code>dense_embedding</code>: a dense vector model</li><li><code>sparse_embedding</code>: a sparse vector model</li><li><code>completion</code>: a text completion model</li><li><code>rerank</code>: a reranking model</li></ul><main id="notice" type='notice'><h4>Notice</h4><p>At present, sparse vector models are not supported. </p></main> |
| MODEL_NAME | varchar(128) | NO | The name of the large model. Example: `text-embedding-v2`. |

## Sample query

Query the AI model information of the current user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_MODELS;
```

The query result is as follows:

```shell
+----------+---------------+-----------------+-------------------+
| MODEL_ID | NAME          | TYPE            | MODEL_NAME        |
+----------+---------------+-----------------+-------------------+
|   500005 | my_ai_model_1 | DENSE_EMBEDDING | text-embedding-v1 |
+----------+---------------+-----------------+-------------------+
1 row in set
```
