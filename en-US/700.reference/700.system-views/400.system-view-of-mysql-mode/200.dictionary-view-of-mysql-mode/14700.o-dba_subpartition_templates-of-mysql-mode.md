# oceanbase.DBA_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the template-based subpartition information for the partitioned tables of the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------------- | ----------------- | ------------ | ----------- |
| USER_NAME | varchar(128) | NO | Owner of the partitioned table |
| TABLE_NAME | varchar(128) | NO | Partitioned Table Name |
| SUBPARTITION_NAME | varchar(132) | NO | Subpartition Name |
| SUBPARTITION_POSITION | bigint(21) | NO | Subpartition Location |
| TABLESPACE_NAME | varchar(30) | NO | Tablespace name of the partition |
| HIGH_BOUND | mediumtext | NO | Partition template expression |
| COMPRESSION | varchar(4) | NO | Specifies whether the data of each newly added composite partition in the subpartition template is stored in compressed format. Valid values: <ul><li>YES</li><li>(Default) NO <br>This value can be specified in the subpartition template. </li></ul> |
| INDEXING | varchar(4) | NO | Specifies whether the data of each newly added composite partition in the subpartition template is considered a partial index:<ul><li>ON</li><li>(Default) OFF<br>This value can be specified in the subpartition template. </li></ul> |
| READ_ONLY | varchar(4) | NO | Specifies whether the data of each newly added composite partition in the subpartition template is read-only:<ul><li>YES</li><li>(Default) NO<br>This value can be specified in the subpartition template. </li></ul> |

## Sample query

You can query the template-based subpartition information of a partitioned table in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPARTITION_TEMPLATES;
```

```shell
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+

| infotest  | t2_m_rch   | p0                |                     1 | NULL            | NULL       | NULL        | NULL     | NULL      |
| infotest  | t2_m_rch   | p1                |                     2 | NULL            | NULL       | NULL        | NULL     | NULL      |
```
