# mysql.help_category

<main id="notice" type='explain'>
<h4>Notes</h4>
<p>This view is supported in V1.4 and later versions.</p>
</main>

## Purpose

The `mysql.help_category` view is used to generate the HELP command in coordination with the following three tables: `mysql.help_relation`, `mysql.help_topic`, and `mysql.help_keyword`.

## Columns

| Column | Type | Nullable? | Description |
|--------------------|----------------|----------------|--------|
| help_category_id   | bigint(20)     | NO             | The ID of the category. |
| name               | varchar(64)    | NO             | The name of the category. |
| parent_category_id | bigint(20)     | YES            | The ID of the parent category. |
| url                | varchar(65535) | NO             | The URL. |
