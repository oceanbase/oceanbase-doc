# oceanbase.DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p> This view was introduced in version V4.2.0. </p>
</main>

## Description

This view displays the log streams that existed in the tenant.

## Fields

| Field        | Type           | Not null | Description                                       |
|-------------|---------------|---------|-------------------------------------------|
| LS_ID       | bigint(20)    | NO          |  Log stream ID                                 |
| LS_GROUP_ID | bigint(20)    | NO          |  Log stream group ID                           |
| STATUS      | varchar(100)  | NO          |  Current status of the log stream. The following values are possible: <ul><li>CREATING: The log stream is being created. </li><li>NORMAL: The log stream is in a normal state. </li><li>DROPPING: The log stream is being deleted. </li><li>PRE_TENANT_DROPPING: A special status of a system log stream. It indicates the start of the deletion of all log streams in the tenant. </li><li>TENANT_DROPPING: The tenant is being deleted. The log stream is in the process of being deleted. </li><li>DROPPED: The log stream has been recycled or is being recycled. </li><li>WAIT_OFFLINE: The log stream is waiting to be recycled. </li><li>CREATE_ABORT: The creation of the log stream is aborted. </li></ul>        |
| FLAG        | varchar(2048) | NO          |  Log stream flags. The following values are possible: <ul><li>Empty: A normal log stream. </li><li>DUPLICATE: A broadcast log stream for a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: You cannot create a tablet on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: You cannot create a tablet on this broadcast log stream. </li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          |  The GTS when the log stream is created. The value is in nanoseconds.              |

## Examples

Query the log streams that existed in the current tenant.

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```

The query result is as follows:

```shell
+-------+-------------+--------+------+---------------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN          |
+-------+-------------+--------+------+---------------------+
|     1 |           0 | NORMAL |      |                   0 |
|  1001 |        1001 | NORMAL |      | 1736152507462028000 |
+-------+-------------+--------+------+---------------------+
2 rows in set
```
