# oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information of completed `backup_set`/`backup_piece` cleanup tasks in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task group ID, which identifies a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, which corresponds to the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: indicates that the `backup_set` is to be cleaned up. </li><li>`BACKUP PIECE`: indicates that the `backup_piece` is to be cleaned up. </li></ul> |
| ID | bigint(20) | NO | The task ID, which includes backup_set and piece. |
| ROUND_ID | bigint(20) | NO | The dest_round_id of the piece. For the cleanup of a backup_set, the ROUND_ID is 0. |
| DEST_ID | bigint(20) | NO | The DEST_ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The time when the task was started. |
| END_TIMESTAMP | timestamp(6) | NO | The time when the task was completed. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`INIT`: indicates the task initialization stage. </li><li>`DOING`: indicates the task execution stage. </li><li>`CANCELING`: indicates the task cancellation stage. </li><li>`COMPLETED`: indicates that the task was successfully executed. </li><li>`FAILED`: indicates that the task execution failed. </li><li>`CANCELED`: indicates that the task was successfully canceled. </li></ul> |
| TOTAL_TASK_COUNT | bigint(20) | YES | The number of subtasks. <ul><li>In SN mode, it indicates the total number of ls_tasks. </li><li>In SS mode, for a log archive piece, it indicates the total number of ls_tasks. For a data backup set, it indicates the total number of macro_tasks. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>For V4.6.x, this column is available starting with V4.6.0. </p></main> |
| FINISH_TASK_COUNT | bigint(20) | YES | The number of completed subtasks. <ul><li>In SN mode, it indicates the number of completed ls_tasks. </li><li>In SS mode, for a log archive piece, it indicates the number of completed ls_tasks. For a data backup set, it indicates the number of completed macro_tasks. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>For V4.6.x, this column is available starting with V4.6.0. </p></main> |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set or backup_piece. |

## Sample query

Query the historical information of completed `backup_set` or `backup_piece` cleanup tasks in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
```
