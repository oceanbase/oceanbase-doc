# oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information of completed `backup_set`/`backup_piece` cleanup tasks in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task group ID, which is used to identify a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, which corresponds to the ID in the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: indicates the cleanup of a `backup_set`. </li><li>`BACKUP PIECE`: indicates the cleanup of a `backup_piece`. </li></ul> |
| ID | bigint(20) | NO | The task ID, which includes backup_set and piece. |
| ROUND_ID | bigint(20) | NO | The destination round ID to which the piece belongs. For the cleanup of a `backup_set`, the value of this column is 0. |
| DEST_ID | bigint(20) | NO | The destination ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the task. |
| END_TIMESTAMP | timestamp(6) | NO | The end time of the task. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`INIT`: indicates the initialization phase of the task. </li><li>`DOING`: indicates the execution phase of the task. </li><li>`CANCELING`: indicates the cancellation phase of the task. </li><li>`COMPLETED`: indicates that the task is completed. </li><li>`FAILED`: indicates that the task fails. </li><li>`CANCELED`: indicates that the task is successfully canceled. </li></ul> |
| TOTAL_TASK_COUNT | bigint(20) | YES | The number of subtasks. <ul><li>In SN mode, this column indicates the number of all ls_tasks. </li><li>In SS mode, this column indicates the number of all ls_tasks for a log archive piece and the number of all macro_tasks for a data backup set. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this column is available starting with V4.6.0. </p></main> |
| FINISH_TASK_COUNT | bigint(20) | YES | The number of completed subtasks. <ul><li>In SN mode, this column indicates the number of completed ls_tasks. </li><li>In SS mode, this column indicates the number of completed ls_tasks for a log archive piece and the number of completed macro_tasks for a data backup set. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this column is available starting with V4.6.0. </p></main> |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set or backup_piece. |

## Sample query

Query the historical information of completed `backup_set` or `backup_piece` cleanup tasks in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
```
