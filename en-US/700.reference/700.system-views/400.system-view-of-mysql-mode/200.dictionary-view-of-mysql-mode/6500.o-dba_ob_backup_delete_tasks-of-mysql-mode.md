# oceanbase.DBA_OB_BACKUP_DELETE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays information about the `backup_set` and `backup_piece` cleanup tasks being executed in the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | Task group ID, used to identify a group of tasks. |
| INCARNATION | bigint(20) | NO | Avatar ID |
| JOB_ID | bigint(20) | NO | Task ID, corresponding to the JOB table. |
| TASK_TYPE | varchar(64) | NO | Task type: <ul><li> BACKUP SET: cleanup.`backup_set`</li><li>BACKUP PIECE : Clean up`backup_piece`</li></ul> |
| ID | bigint(20) | NO | Task ID, including: backup_set and piece |
| ROUND_ID | bigint(20) | NO | The ID of the destination round to which the piece belongs. For cleanup of a backup set, ROUND_ID is 0. |
| DEST_ID | bigint(20) | NO | Backup Destination DEST_ID |
| START_TIMESTAMP | timestamp(6) | NO | Task Start Time |
| END_TIMESTAMP | timestamp(6) | NO | End Time |
| STATUS | varchar(64) | NO | Task status: <ul><li>`INIT`: Task initialization phase</li><li>`DOING`: Task execution phase.</li><li>`CANCELING`: The task is canceled.</li><li>`COMPLETED`: Task executed successfully. </li><li>`FAILED`: Task execution failed. </li><li>`CANCELED`: The task was successfully canceled.</li></ul> |
| TOTAL_LS_COUNT | bigint(20) | YES | Number of Log Streams under the Task |
| FINISH_LS_COUNT | bigint(20) | YES | Number of Successful Log Stream Tasks |
| RESULT | bigint(20) | YES | Error Code |
| COMMENT | varchar(4096) | YES | Comment |
| PATH | varchar(1024) | NO | Backup Destination of backup_set/backup_piece |

## Sample query

You can view the information about the `backup_set` or `backup_piece` cleanup tasks being executed by the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASKS\G
```
