# oceanbase.DBA_MVREF_RUN_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVREF_RUN_STATS` view displays information about each refresh run of a materialized view. Each run is identified by a REFRESH_ID. This information includes timing statistics related to the run and the parameters specified for the run.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| RUN_OWNER | varchar(128) | NO | The owner of the refresh operation (the user who initiated the operation). |
| REFRESH_ID | bigint(20) | NO | The ID of the refresh. |
| NUM_MVS | bigint(20) | NO | The number of materialized views refreshed. |
| MVIEWS | text | NO | The API-specified parameter for the materialized view name. |
| BASE_TABLES | text | YES | Reserved for internal use. |
| METHOD | text | YES | The API-specified METHOD parameter. |
| ROLLBACK_SEG | text | YES | The API-specified ROLLBACK_SEG parameter. |
| PUSH_DEFERRED_RPC | varchar(1) | NO | The API-specified PUSH_DEFERRED_RPC parameter. |
| REFRESH_AFTER_ERRORS | varchar(1) | NO | The API-specified REFRESH_AFTER_ERRORS parameter. |
| PURGE_OPTION | bigint(20) | NO | The API-specified PURGE_OPTION parameter. |
| PARALLELISM | bigint(20) | NO | The API-specified PARALLELISM parameter. |
| HEAP_SIZE | bigint(20) | NO | The API-specified HEAP_SIZE parameter. |
| ATOMIC_REFRESH | varchar(1) | NO | The API-specified ATOMIC_REFRESH parameter. |
| NESTED | varchar(1) | NO | The API-specified NESTED parameter. |
| OUT_OF_PLACE | varchar(1) | NO | The API-specified OUT_OF_PLACE parameter. |
| NUMBER_OF_FAILURES | bigint(20) | NO | The number of failures that occurred during API processing. |
| START_TIME | datetime | NO | The start time of the refresh run. |
| END_TIME | datetime | NO | The end time of the refresh run. |
| ELAPSED_TIME | bigint(20) | NO | The duration of the refresh run, in seconds. |
| LOG_SETUP_TIME | bigint(1) | NO | The log setup time of the materialized view, in seconds<main id="notice" type='explain'> <h4>Note</h4><p>This field is reserved and its value is 0 by default. </p></main> |
| LOG_PURGE_TIME | bigint(20) | NO | The log purge time of the materialized view, in seconds |
| COMPLETE_STATS_AVAILABLE | varchar(1) | NO | Indicates whether complete refresh statistics are available for this run<ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This field is reserved and its value is Y by default. </p></main> |
