# oceanbase.DBA_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.5 for V4.3.x. </li> <li>This view is available starting with V4.2.2 for V4.2.x. </li></ul>
</main>

## Purpose

The `DBA_WR_SQLSTAT` view displays basic performance statistics for SQL statements executed in the current tenant. Each row corresponds to a unique combination of `SQL_ID` and `Plan_Hash`. The columns with `_DELTA` in their names indicate the incremental statistics from the last WR snapshot collection to the current time.
