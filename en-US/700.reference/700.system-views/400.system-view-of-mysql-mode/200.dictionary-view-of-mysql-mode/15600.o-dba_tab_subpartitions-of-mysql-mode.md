# oceanbase.DBA_TAB_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the subpartition information of partitioned tables in the current tenant, including the subpartition name, table name, partition name, storage attributes, and statistics generated by the `DBMS_STATS` package.

## Sample query

```shell
obclient [oceanbase]> SELECT TABLE_OWNER, TABLE_NAME, PARTITION_NAME, SUBPARTITION_NAME, HIGH_VALUE, HIGH_VALUE_LENGTH, PARTITION_POSITION, SUBPARTITION_POSITION FROM oceanbase.DBA_TAB_SUBPARTITIONS WHERE TABLE_NAME='t_m_rclc';
```
