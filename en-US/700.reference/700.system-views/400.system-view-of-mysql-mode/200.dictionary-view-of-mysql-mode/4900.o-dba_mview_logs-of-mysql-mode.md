# oceanbase.DBA_MVIEW_LOGS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVIEW_LOGS` view displays information about materialized view logs.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| LOG_OWNER | varchar(128) | NO | The name of the owner of the materialized view log. |
| MASTER | varchar(128) | NO | The name of the primary table to which the materialized view log belongs. |
| LOG_TABLE | varchar(128) | NO | The name of the materialized view log table. |
| LOG_TRIGGER | varchar(128) | YES | The row-level trigger on the primary table that inserts rows into the materialized view log. <main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility and its value is NULL by default. </p></main> |
| ROWIDS | varchar(3) | NO | Indicates whether the Rowid information is recorded. <ul><li> YES </li><li>NO </li></ul>|
| PRIMARY_KEY | varchar(3) | NO | Indicates whether the primary key information is recorded. <ul><li> YES </li><li>NO </li></ul>|
| OBJECT_ID | varchar(3) | NO | Indicates whether the object identifier information is recorded in the object table. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility and its value is NO by default. </p></main> |
| FILTER_COLUMNS | varchar(3) | NO | Indicates whether the filter column information is recorded. <ul><li> YES </li><li>NO </li></ul>|
| SEQUENCE | varchar(3) | NO | Indicates whether the sequence value is recorded to provide additional sorting information. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| INCLUDE_NEW_VALUES | varchar(3) | NO | Indicates whether both the old and new values are recorded. <ul><li>YES: Both the old and new values are recorded. </li><li>NO: Only the old value is recorded. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| PURGE_ASYNCHRONOUS | varchar(3) | NO | Indicates whether the materialized view log is asynchronously purged. <ul><li> YES </li><li>NO </li></ul>|
| PURGE_DEFERRED | varchar(3) | NO | Indicates whether the materialized view log is purged in a deferred manner. <ul><li> YES </li><li>NO </li></ul>|
| PURGE_START | datetime | YES | The start date of the deferred purge. |
| PURGE_INTERVAL | varchar(200) | YES | The interval for the deferred purge. |
| LAST_PURGE_DATE | datetime | YES | The date when the materialized view log was last purged. |
| LAST_PURGE_STATUS | bigint(1) | NO | The status of the last purge of the materialized view log. <ul><li> Error code </li><li>0: The purge was successful. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always 0. </p></main> |
| NUM_ROWS_PURGED | bigint(20) | YES | The number of rows purged from the materialized view log in the last purge. |
| COMMIT_SCN_BASED | varchar(3) | NO | Indicates whether the materialized view log is based on the commit SCN. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| STAGING_LOG | varchar(3) | NO | Indicates whether the materialized view log is a staging log that is synchronously refreshed. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility and its value is NO by default. </p></main> |
| PURGE_DOP          | bigint(20)   | NO   | The parallelism for purging the materialized view log. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP2. </p></main>|
| LAST_PURGE_TIME    | bigint(20)   | YES  | The time consumed by the last materialized view log purge task, in seconds. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP2. </p></main>|
