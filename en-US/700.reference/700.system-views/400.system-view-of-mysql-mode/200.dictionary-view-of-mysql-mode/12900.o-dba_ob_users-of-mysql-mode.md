# oceanbase.DBA_OB_USERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about users and roles in the current tenant.

## Columns

| Column                   | Type      | Nullable | Description |
|---------------------------|---------------|------|----|
| USER_NAME                 | varchar(128)  | NO   |  Username or role name   |
| HOST                      | varchar(128)  | NO   |  Server name   |
| PASSWD                    | varchar(128)  | NO   |  User or role password   |
| INFO                      | varchar(4096) | NO   |  User or role information   |
| PRIV_ALTER                | varchar(3)    | NO   |  Whether the user or role has the permission to modify databases or tables   |
| PRIV_CREATE               | varchar(3)    | NO   |  Whether the user or role has the permission to create databases or tables   |
| PRIV_DELETE               | varchar(3)    | NO   |  Whether the user or role has the permission to delete records in databases or tables   |
| PRIV_DROP                 | varchar(3)    | NO   |  Whether the user or role has the permission to delete databases or tables   |
| PRIV_GRANT_OPTION         | varchar(3)    | NO   |  Whether the user or role has the permission to grant privileges   |
| PRIV_INSERT               | varchar(3)    | NO   |  Whether the user or role has the permission to insert records   |
| PRIV_UPDATE               | varchar(3)    | NO   |  Whether the user or role has the permission to update records   |
| PRIV_SELECT               | varchar(3)    | NO   |  Whether the user or role has the permission to query records   |
| PRIV_INDEX                | varchar(3)    | NO   |  Whether the user or role has the permission to set indexes   |
| PRIV_CREATE_VIEW          | varchar(3)    | NO   |  Whether the user or role has the permission to create views   |
| PRIV_SHOW_VIEW            | varchar(3)    | NO   |  Whether the user or role has the permission to view views   |
| PRIV_SHOW_DB              | varchar(3)    | NO   |  Whether the user or role has the permission to view all databases   |
| PRIV_CREATE_USER          | varchar(3)    | NO   |  Whether the user or role has the permission to create users   |
| PRIV_SUPER                | varchar(3)    | NO   |  Whether the user or role has the permission of a superuser   |
| IS_LOCKED                 | varchar(3)    | NO   |  Whether the user or role is locked   |
| PRIV_PROCESS              | varchar(3)    | NO   |  Whether the user or role has the permission to view all threads   |
| PRIV_CREATE_SYNONYM       | varchar(3)    | NO   |  Whether the user or role has the permission to create synonyms   |
| SSL_TYPE                  | bigint(20)    | NO   |  Supported SSL standard encryption security types   |
| SSL_CIPHER                | varchar(1024) | NO   |  Supported SSL standard encryption security passwords   |
| X509_ISSUER               | varchar(1024) | NO   |  X.509 issuer name   |
| X509_SUBJECT              | varchar(1024) | NO   |  X.509 certificate subject name   |
| TYPE                      | varchar(4)    | NO   |  Type:<ul><li>`USER`: User</li> <li>`ROLE`: Role</li></ul>   |
| PROFILE_ID                | bigint(20)    | NO   |  Profile ID   |
| PASSWORD_LAST_CHANGED     | timestamp(6)  | YES  |  The last time the password was changed.   |
| PRIV_FILE                 | varchar(3)    | NO   |  Whether the user or role has the permission to view files   |
| PRIV_ALTER_TENANT         | varchar(3)    | NO   |  Whether the user or role has the permission to modify tenant information   |
| PRIV_ALTER_SYSTEM         | varchar(3)    | NO   |  Whether the user or role has the permission to change server configuration parameters   |
| PRIV_CREATE_RESOURCE_POOL | varchar(3)    | NO   |  Whether the user or role has the permission to create, modify, and delete resource pools   |
| PRIV_CREATE_RESOURCE_UNIT | varchar(3)    | NO   |  Whether the user or role has the permission to create, modify, and delete resource units   |
| MAX_CONNECTIONS           | bigint(20)    | NO   |  Maximum number of connections   |
| MAX_USER_CONNECTIONS      | bigint(20)    | NO   |  Maximum number of tenant connections   |
| PRIV_REPL_SLAVE           | varchar(3)    | NO   |  From server management. A tenant can determine the locations of the replication slave and master servers.   |
| PRIV_REPL_CLIENT          | varchar(3)    | NO   |  Master server management. A tenant can read the binary log files used to maintain the replication database environment. This user is located in the master system, facilitating communication between the host and client.   |
| PRIV_DROP_DATABASE_LINK   | varchar(3)    | NO   | Whether the user or role has the permission to drop database links     |
| PRIV_CREATE_DATABASE_LINK | varchar(3)    | NO   | Whether the user or role has the permission to create database links     |
| PRIV_EXECUTE              | varchar(3)    | NO   | Whether the user or role has the permission to execute procedures and functions    |
| PRIV_ALTER_ROUTINE        | varchar(3)    | NO   | Whether the user or role has the permission to modify and drop procedures and functions      |
| PRIV_CREATE_ROUTINE       | varchar(3)    | NO   | Whether the user or role has the permission to create procedures and functions     |
| PRIV_CREATE_TABLESPACE    | varchar(3)    | NO   | Whether the user or role has the permission to create, modify, and drop tablespaces     |
| PRIV_SHUTDOWN             | varchar(3)    | NO   | Whether the user or role has the permission to execute the mysqladmin shutdown command     |
| PRIV_RELOAD               | varchar(3)    | NO   | Whether the user or role has the permission to execute flush operations     |
| PRIV_REFERENCES           | varchar(3)    | NO   | Whether the user has the privilege to create foreign keys.     |
| PRIV_CREATE_ROLE          | varchar(3)    | NO   | Whether the user has the privilege to create roles.     |
| PRIV_DROP_ROLE            | varchar(3)    | NO   | Whether the user has the privilege to drop roles.     |
| PRIV_TRIGGER              | varchar(3)    | NO   | Whether the user has the privilege to activate triggers.     |
| PRIV_ENCRYPT              | varchar(3)    | NO   | Whether the user can call the ENHANCED_AES_ENCRYPT function.     |
| PRIV_DECRYPT              | varchar(3)    | NO   | Whether the user can call the ENHANCED_AES_DECRYPT function.     |
