# oceanbase.DBA_IND_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all index subpartitions in the database.

## Sample query

A user tenant queries the subpartitions (secondary partitions) of indexes in the `tbl2_f_rl` table of its own tenant.

```shell
obclient [infotest]> SELECT INDEX_OWNER, INDEX_NAME, PARTITION_NAME, SUBPARTITION_NAME, HIGH_VALUE, HIGH_VALUE_LENGTH, PARTITION_POSITION, SUBPARTITION_POSITION FROM oceanbase.DBA_IND_SUBPARTITIONS WHERE TABLE_NAME='tbl2_f_rl';
```
