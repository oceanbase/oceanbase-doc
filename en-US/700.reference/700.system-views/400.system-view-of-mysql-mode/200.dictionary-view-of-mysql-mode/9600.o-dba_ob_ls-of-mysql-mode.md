# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status and restore progress of log streams in the current tenant.

## Columns

| Column       | Type                | Nullable        | Description               |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO   | The ID of the log stream. |
| STATUS        | varchar(100)        | NO   | The status of the log stream. Valid values: <ul><li>`CREATING`: The log stream is being created. </li><li>`CREATED`: The log stream is created. </li><li>`NORMAL`: The log stream is available. </li><li>`DROPPING`: The log stream is being dropped. You must migrate the tablets on the log stream. </li><li>`TENANT DROPPING`: The log stream is being dropped. You must drop the log stream. </li><li>`WAIT OFFLINE`: The data of the log stream is deleted. The log stream is waiting for garbage collection. </li><li>`CREATE ABORT`: The log stream is being dropped. </li></ul> |
| PRIMARY_ZONE  | longtext            | YES  | The election priority of the log stream. |
| UNIT_GROUP_ID | bigint(20)          | NO   | The ID of the unit group. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column is available starting with V4.6.0. The value of this column is always 0. </li><li>For V4.4.x, this column is available starting with V4.4.2. The value of this column is always 0. </li><li>For V4.2.5, this column is available starting with V4.2.5 BP5. The value of this column is always 0. </li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO   | The ID of the log stream group. For the system log stream (log stream 1) and broadcast log stream, this column displays 0, indicating that the log stream does not belong to any log stream group. |
| CREATE_SCN    | bigint(20) unsigned | NO   | The position at which the log stream starts to write logs. |
| DROP_SCN      | bigint(20) unsigned | NO   | The position at which the log stream is dropped. This position indicates the end of all user data. If the log stream is dropped, this column records the SCN at which the log stream is dropped. If the log stream is not dropped, this column is empty. |
| SYNC_SCN      | bigint(20) unsigned | NO   | The synchronization position of the log stream. This position indicates the SCN of the last transaction that is synchronized. |
| READABLE_SCN  | bigint(20) unsigned | NO   | The readable position of the log stream. This position indicates the minimum SCN at which the log stream can be read. |
| FLAG          | varchar(2048)       | NO   | The flag of the log stream. Valid values: <ul><li>Empty: normal log stream. </li><li>DUPLICATE: broadcast log stream of a user tenant. The replicated tables are created on this log stream. </li> <li>BLOCK_TABLET_IN: indicates that a tablet cannot be created on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: indicates that a tablet cannot be created on the broadcast log stream. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | The list of units where the user log stream is distributed. The value of this column is empty for the system log stream and broadcast log stream if no specific location is specified. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column is available starting with V4.6.0. </li> <li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main>  |

## Sample query

Query the status and restore progress of log streams in the current user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```
