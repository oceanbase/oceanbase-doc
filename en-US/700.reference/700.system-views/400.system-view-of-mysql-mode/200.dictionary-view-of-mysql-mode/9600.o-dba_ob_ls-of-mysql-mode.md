# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status and recovery progress of log streams in the current tenant.

## Columns

| Column | Type | Nullable | Description |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO   | The ID of the log stream. |
| STATUS        | varchar(100)        | NO   | The status of the log stream. Valid values: <ul><li>`CREATING`: the log stream is being created</li><li>`CREATED`: the log stream is created</li><li>`NORMAL`: the log stream is available for service</li><li>`DROPPING`: the log stream is being dropped, and the tablets on the log stream must be migrated away</li><li>`TENANT DROPPING`: the log stream is being dropped because its tenant is being dropped</li><li>`WAIT OFFLINE`: the data of the log stream has been deleted and is waiting for garbage collection</li><li>`CREATE ABORT`: the log stream creation failed or is not required, and the log stream is being dropped</li></ul> |
| PRIMARY_ZONE  | longtext            | YES  | The priority zone of the log stream. |
| UNIT_GROUP_ID | bigint(20)          | NO | The ID of the unit group. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting from V4.4.2. The value of this field is always 0. </li><li>For V4.2.5, this field is available starting from V4.2.5 BP5. The value of this field is always 0. </li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO   | The ID of the log stream group. For system log streams (log stream 1) and broadcast log streams, this field is 0, indicating that the log stream does not belong to any log stream group. |
| CREATE_SCN    | bigint(20) unsigned | NO   | The position at which the log stream starts to write logs. |
| DROP_SCN      | bigint(20) unsigned | NO   | The position at which the log stream is dropped. This position marks the end of all user data. If the log stream is dropped, this field records the SCN at which the log stream is dropped. If the log stream is not dropped, this field is empty. |
| SYNC_SCN      | bigint(20) unsigned | NO   | The synchronization position of the log stream. This position marks the SCN of the last transaction that is successfully synchronized. |
| READABLE_SCN  | bigint(20) unsigned | NO   | The readable position of the log stream. This position marks the minimum SCN that can be read from the log stream. |
| FLAG          | varchar(2048)       | NO   | The flag of the log stream. Valid values: <ul><li>Empty: normal log stream</li><li>DUPLICATE: broadcast log stream of a user tenant. A replicated table is created on this log stream. </li> <li>BLOCK_TABLET_IN: no tablet can be created on this log stream</li> <li>DUPLICATE\|BLOCK_TABLET_IN: no tablet can be created on this broadcast log stream</li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting from V4.2.0. </p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | The list of units where the user log stream is distributed. For system log streams and broadcast log streams, this field is empty if no specific location is specified. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting from V4.4.2. </li> <li>For V4.2.5, this field is available starting from V4.2.5 BP5. </li></ul></main>  |

## Sample query

Query the status and recovery progress of log streams in the current user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```
