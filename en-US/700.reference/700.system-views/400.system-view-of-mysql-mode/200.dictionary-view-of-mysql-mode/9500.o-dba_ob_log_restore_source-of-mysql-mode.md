# oceanbase.DBA_OB_LOG_RESTORE_SOURCE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore sources of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| ID | bigint(20) | NO | The ID of the log restore source. |
| TYPE | varchar(32) | NO | The type of the log restore source. Valid values: `SERVICE`, `LOCATION`, and `RAWPATH`. <ul><li>`SERVICE`: a direct network connection log restore source.  </li><li>`LOCATION`: an archive log restore source. </li><li>`RAWPATH`: a user-managed log restore source. </li></ul>|
| VALUE | longtext | NO | The entry address of the log restore source. <ul><li>For a `SERVICE` type log restore source: the entry address of the primary tenant, such as "IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,COMPATIBILITY_MODE=ORACLE,IS_ENCRYPTED=true".  </li><li>For a `LOCATION` type log restore source: the log archive directory, such as "file:///data/1/archive/". </li><li>For a `RAWPATH` type log restore source: a user-defined directory. </li></ul>|
| RECOVERY_UNTIL_SCN | bigint(20) unsigned | NO | The upper limit of the log to be retrieved. The value can be INT64_MAX or a positive value. |

## Sample query

Query the log restore sources of the current user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LOG_RESTORE_SOURCE;
```

The query result is as follows:

```shell
+-----------+------+----------+-------------------------------------+---------------------+
| TENANT_ID | ID   | TYPE     | VALUE                               | RECOVERY_UNTIL_SCN  |
+-----------+------+----------+-------------------------------------+---------------------+
|      1016 |    1 | LOCATION | file:///home/admin/oceanbase/arglog | 4611686018427387903 |
+-----------+------+----------+-------------------------------------+---------------------+
1 row in set
```
