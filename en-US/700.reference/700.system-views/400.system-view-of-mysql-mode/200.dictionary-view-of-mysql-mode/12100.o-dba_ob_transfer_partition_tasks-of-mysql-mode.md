# oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1 BP2. </p>
</main>

## Purpose

The `DBA_OB_TRANSFER_PARTITION_TASKS` view displays the Transfer Partition tasks being processed in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID          | bigint(20)   | NO   | The unique identifier of the Transfer Partition task.   |
| CREATE_TIME      | timestamp(6) | YES  | The time when the task was created.   |
| MODIFY_TIME      | timestamp(6) | YES  | The time when the information was last updated.   |
| TABLE_ID         | bigint(20)   | NO   | The ID of the table that contains the partition to be transferred.   |
| OBJECT_ID        | bigint(20)   | NO   | The `OBJECT_ID` of the partition to be transferred.   |
| DEST_LS          | bigint(20)   | NO   | The log stream ID of the destination.   |
| BALANCE_JOB_ID   | bigint(20)   | NO   | The ID of the load balancing job associated with the task.   |
| TRANSFER_TASK_ID | bigint(20)   | NO   | The ID of the Transfer task associated with the task.   |
| STATUS           | varchar(64)  | NO   | The status of the task. Valid values: <ul><li>WAITING: The task is waiting to start. </li><li>INIT: The task is being scheduled. </li><li>DOING: The task is being executed. </li></ul>   |
| COMMENT          | longtext     | YES  | The comment.   |

## Sample query

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS;
```

The query result is as follows:

