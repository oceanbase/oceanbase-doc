# mysql.audit_log_user

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>This view is available starting with V4.3.3 for V4.3.x. </li> <li>This view is available starting with V4.2.4 for V4.2.x. </li></ul></p>
</main>

## Purpose

The `mysql.audit_log_user` view displays the mapping between audit filters and users.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support the audit feature. </p>
</main>

## Columns

| **Column** | **Type**  | **Nullable** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| USER       | varchar(128) | NO | The username. |
| HOST       | varchar(128) | NO | The host name. |
| FILTERNAME | varchar(64)  | NO | The name of the audit filter. |

## Sample query

Query the mapping between audit filters and users.

```shell
obclient [mysql]> select * from mysql.audit_log_user;
```

The query result is as follows:

```shell
+---------+------+------------+
| USER    | HOST | FILTERNAME |
+---------+------+------------+
| user001 | %    | log_all    |
+---------+------+------------+
1 row in set (0.003 sec)
```
