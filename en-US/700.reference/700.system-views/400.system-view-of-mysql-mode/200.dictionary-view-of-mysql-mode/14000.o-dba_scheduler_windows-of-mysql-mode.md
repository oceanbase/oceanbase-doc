# oceanbase.DBA_SCHEDULER_WINDOWS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays information for all scheduler windows under the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------ | --------------- | ---------------- | ------------------- |
| OWNER | varchar(128) | NO | Owner of the scheduler window |
| WINDOW_NAME | varchar(128) | NO | Name of the scheduler window |
| RESOURCE_PLAN | varchar(128) | NO | Resource plan associated with the window. This field is currently unused. |
| SCHEDULE_OWNER | varchar(4000) | NO | Owner of the window schedule. This field is currently unused. |
| SCHEDULE_NAME | varchar(4000) | NO | The name of the time table in the window. This field is currently not used. |
| SCHEDULE_TYPE | varchar(8) | NO | Window plan type. Valid values:<ul><li>ONCE: The repetition interval is NULL.</li><li>NAMED: A named schedule.</li><li>CALENDAR: A calendar expression used as a schedule.</li></ul></br>This field is currently unused. |
| START_DATE | datetime(6) | YES | Date at which the window starts (for inline plans) |
| REPEAT_INTERVAL | varchar(4000) | YES | Window Cycle Interval |
| END_DATE | datetime(6) | YES | Window End Time |
| DURATION | bigint(20) | YES | Window Duration |
| WINDOW_PRIORITY | varchar(4) | NO | Priority of the job relative to other windows:<ul><li>HIGH</li><li>LOW</li></ul></br>This field is currently not used. |
| NEXT_RUN_DATE | datetime(6) | NO | Next Window Start Time |
| LAST_START_DATE | datetime(6) | YES | Last Window Start Time |
| ENABLED | varchar(5) | YES | Whether the indicator window is enabled (TRUE) or disabled (FALSE). |
| ACTIVE | varchar(5) | NO | Indicates whether the window is open (TRUE) or not open (FALSE). This field is currently unused. |
| MANUAL_OPEN_TIME | datetime(6) | NO | The time when the window was manually opened. If not, this field is set to NULL. This field is currently unused. |
| MANUAL_DURATION | bigint(0) | NO | Duration of the manually opened window, otherwise NULL. This field is currently unused. |
| COMMENTS | varchar(4000) | YES | Description of the window |

## Sample query

View information for all scheduler windows in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SCHEDULER_WINDOWS;
```
