# oceanbase.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` view displays the execution history of backup validation tasks initiated by the current tenant at the job level. Each job corresponds to a backup validation instruction.

## Columns

| Column             | Type           | Nullable | Description           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | bigint(20)     | NO   | The task ID.     |
| INCARNATION         | bigint(20)     | NO   | The incarnation ID.     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | The ID of the tenant that initiated the job.   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | The ID of the job that initiated the job. If the value is 0, the current job initiated the job.     |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | The ID of the user tenant that needs to execute the validation task. If the value is empty, the current tenant executes the validation task.     |
| TYPE                | varchar(64)    | NO   | The type of the validation task. Valid values: <ul><li>`DATABASE`: validates all backup sets and archive log pieces under the backup path and archive path.</li> <li>`BACKUPSET`: validates the specified backup set.</li> <li>`ARCHIVELOG_PIECE`: validates the specified archive log piece.</li></ul>     |
| PATH                | longtext       | YES  | The backup path or archive log path specified by the user for validation. If the value is empty, the task does not specify a path.     |
| PATH_TYPE           | varchar(64)    | YES  | The type of the path specified by the user for validation. If the value is empty, the task does not specify a path. Valid values: <ul><li>`BACKUPSET`: validates the backup set under the specified path.</li> <li>`ARCHIVELOG_PIECE`: validates the archive log piece under the specified path.</li></ul>     |
| ID                  | longtext       | YES  | <p>The `backup_set_id` of the backup set to be validated or the `piece_id` of the archive log piece to be validated.</p><p>If the value is empty, all backup sets and archive log pieces under the current backup path and archive path are validated. When the user specifies the `backup_set_id` of a backup set or the `piece_id` of an archive log piece for validation, the value changes to the corresponding ID or ID list.</p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | The validation level. Valid values: <ul><li>`basic`: checks only the completeness of the file list.</li> <li>`physical`: checks the correctness and logical consistency of the physical data.</li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | The start time of the validation task.     |
| END_TIMESTAMP       | timestamp(6)   | NO   | The end time of the validation task.     |
| STATUS              | varchar(64)    | NO   | The status of the job. Valid values: <ul><li>`COMPLETED`: the validation task has been completed.</li> <li>`FAILED`: the validation task has failed.</li> <li>`CANCELED`: the validation task has been canceled.</li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | The number of retries.     |
| TASK_COUNT          | bigint(20)     | YES  | The total number of validation tasks for the backup set or archive log piece.     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | The number of successful validation tasks for the backup set or archive log piece.     |
| RESULT              | bigint(20)     | NO   | The error code of the validation result.    |
| DESCRIPTION         | varchar(4096)  | YES  | The external information provided by OCP.    |
| COMMENT             | varchar(4096)  | YES  | The description of the reason for the failure of the validation task.      |

## Sample query

Query the execution history of backup validation tasks initiated by the current user tenant at the job level.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY\G
```
