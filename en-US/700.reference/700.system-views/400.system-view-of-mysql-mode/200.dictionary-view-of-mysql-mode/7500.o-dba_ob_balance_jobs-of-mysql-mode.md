# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.0. </p>
</main>

## Overview

The `DBA_OB_BALANCE_JOBS` view displays the load balancing jobs currently in progress for a tenant. A tenant can only have one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks to perform specific load balancing operations.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | ------- |
| JOB_ID | bigint(20) | NO | CLB Work ID |
| CREATE_TIME | timestamp(6) | YES | Created At |
| MODIFY_TIME | timestamp(6) | YES | Information Update Time |
| BALANCE_STRATEGY | varchar(64) | NO | Load balancing strategy name. Valid values: <ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing. </li><li>`LS balance by expand`: Scale-out balancing</li><li>`LS balance by shrink`: Scale-down balancing </li><li>`partition balance`: Partition balancing. </li></ul> |
| JOB_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>`LS_BALANCE`: Log stream balancing  </li><li>`PARTITION_BALACNE`: Partition balancing</li></ul> |
| TARGET_UNIT_NUM | bigint(20) | NO | Number of Units in Each Zone Where Target Changes <main id="notice" type='explain'><h4>Note</h4><p>For version V4.2.5, the value of this field has been changed to always be <code>NULL</code> starting from V4.2.5 BP5.</p></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | Number of Changed Primary Zones |
| STATUS | varchar(64) | NO | Task status. Valid values: <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELING`: Cancellation in progress. </li><li>`CANCELED`: Task canceled. </li> <li>`SUSPEND`: Task paused</li></ul> |
| COMMENT | longtext | YES | Comments |
| MAX_END_TIME | timestamp(6) | YES | Maximum End Time of Load Balancing Task <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.x, this field is available starting from V4.2.4. For V4.3.x, this view is available starting from V4.3.4.</p></main> |
| ZONE_UNIT_NUM_LIST | varchar(4096) | NO | Number of Units in Each Zone of Tenant <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.5, this field is available starting from V4.2.5 BP5.</p></main> |
| PARAMETER_LIST | longtext | NO | Balancing-related parameters <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.5, this field is available starting from V4.2.5 BP5.</p></main> |

## Sample query

View the current load balancing tasks being executed for this tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
```

The query result is as follows:

```shell

| 6083968 | 2025-06-16 17:23:18.070731 | 2025-06-16 17:23:18.070731 | LS group count balance | LS_BALANCE |            NULL |                       2 | DOING  | NULL    | NULL         | z1:2,z2:2,z3:3     | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |

1 row in set
```
