# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view `DBA_OB_BALANCE_JOBS` displays the load balancing jobs that are being executed for the current tenant. Each tenant can have only one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks, which are the specific operations for achieving load balancing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------- | -------- | --------------- | ------- |
| JOB_ID                  | bigint(20)   | NO  | The ID of the load balancing job. |
| CREATE_TIME             | timestamp(6) | YES | The time when the job was created. |
| MODIFY_TIME             | timestamp(6) | YES | The time when the information was last updated. |
| BALANCE_STRATEGY        | varchar(64)  | NO  | The name of the balancing strategy. <ul><li>`LS balance by migrate`: Migration-based balancing.  </li><li>`LS balance by alter`: Log stream attribute modification-based balancing. </li><li>`LS balance by expand`: Expansion-based balancing. </li><li>`LS balance by shrink`: Shrinkage-based balancing. </li><li>`partition balance`: Partition-based balancing. </li></ul>|
| JOB_TYPE                | varchar(64)  | NO  | The type of the task. <ul><li>`LS_BALANCE`: Log stream balancing.  </li><li>`PARTITION_BALACNE`: Partition balancing. </li></ul>|
| TARGET_UNIT_NUM         | bigint(20)   | NO  | The number of units to be changed in each zone. |
| TARGET_PRIMARY_ZONE_NUM | bigint(20)   | NO  | The number of primary zones to be changed. |
| STATUS                  | varchar(64)  | NO  | The status of the task. <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: The task was executed successfully. </li><li>`CANCELING`: The task is being canceled. </li><li>`CANCELED`: The task was canceled. </li> <li>`SUSPEND`: The task is suspended. </li></ul>|
| COMMENT                 | longtext     | YES | The comment. |
| MAX_END_TIME            | timestamp(6) | YES | The maximum end time of the load balancing tasks. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.4. </p></main>     |

## Sample query

Query the load balancing jobs that are being executed for the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
```

The query result is as follows:

```shell
+--------+----------------------------+----------------------------+---------------------------+--------------------+-----------------+-------------------------+--------+---------+--------------+
| JOB_ID | CREATE_TIME                | MODIFY_TIME                | BALANCE_STRATEGY          | JOB_TYPE           | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS | COMMENT | MAX_END_TIME |
+--------+----------------------------+----------------------------+---------------------------+--------------------+-----------------+-------------------------+--------+---------+--------------+
|  68699 | 2024-12-31 17:24:16.758260 | 2024-12-31 17:24:16.758260 | manual transfer partition | TRANSFER_PARTITION |               3 |                       1 | DOING  | NULL    | NULL         |
+--------+----------------------------+----------------------------+---------------------------+--------------------+-----------------+-------------------------+--------+---------+--------------+
1 row in set
```
