# oceanbase.DBA_WR_STATNAME

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the names of system statistics items of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | The cluster ID. |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| STAT_ID | bigint(20) | NO | The ID of the system statistics item. |
| STAT_NAME | varchar(64) | NO | The name of the system statistics item. |

## Sample query

Query the names of system statistics items of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_STATNAME limit 1;
```

The return result is as follows:

```shell
    +------------+-----------+---------+---------------+
    | CLUSTER_ID | TENANT_ID | STAT_ID | STAT_NAME     |
    +------------+-----------+---------+---------------+
    |       4000 |         1 |   10000 | rpc packet in |
    +------------+-----------+---------+---------------+
    1 row in set (0.004 sec)
```
