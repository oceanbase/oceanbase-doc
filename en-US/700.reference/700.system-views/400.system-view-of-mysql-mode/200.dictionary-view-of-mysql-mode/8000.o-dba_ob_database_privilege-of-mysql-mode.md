# oceanbase.DBA_OB_DATABASE_PRIVILEGE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the database privileges of users under the current tenant.

## Columns

| Field Name | Field type | Whether can be NULL | Description |
| ------------------- | -------------- | ------ | ----- |
| USER_ID | bigint(20) | NO | User ID |
| USERNAME | varchar(128) | NO | Username |
| DATABASE_NAME | varchar(128) | NO | Database Name |
| GMT_CREATE | timestamp(6) | NO | Created At |
| GMT_MODIFIED | timestamp(6) | NO | Modified At |
| PRIV_ALTER | varchar(3) | NO | Whether you have the privilege to modify the database or table. |
| PRIV_CREATE | varchar(3) | NO | Whether you have the privilege to create a database or table |
| PRIV_DELETE | varchar(3) | NO | Whether the user has the permission to delete database or table records. |
| PRIV_DROP | varchar(3) | NO | Whether you have the privilege to delete databases or tables. |
| PRIV_GRANT_OPTION | varchar(3) | NO | Whether Sub-authorization Is Allowed |
| PRIV_INSERT | varchar(3) | NO | Whether the user has the permission to insert records |
| PRIV_UPDATE | varchar(3) | NO | Whether to grant the permission to update records |
| PRIV_SELECT | varchar(3) | NO | Whether to grant the query record permission |
| PRIV_INDEX | varchar(3) | NO | Whether you have the privilege to create and drop indexes |
| PRIV_CREATE_VIEW | varchar(3) | NO | Whether the user has the privilege to create views |
| PRIV_SHOW_VIEW | varchar(3) | NO | Whether the user has the privilege to view the view. |
| PRIV_EXECUTE | varchar(3) | NO | Whether the user has the privilege to execute procedures and functions |
| PRIV_ALTER_ROUTINE | varchar(3) | NO | Whether you have the privilege to modify or drop procedures and functions |
| PRIV_CREATE_ROUTINE | varchar(3) | NO | Whether the user has the privilege to create procedures and functions |
| PRIV_REFERENCES | varchar(3) | NO | Whether the user has the privilege to create foreign keys |
| PRIV_TRIGGER | varchar(3) | NO | Whether the user has the privilege to activate trigger operations. |
| PRIV_LOCK_TABLE | varchar(3) | NO | Whether the user has the privilege to lock tables |
| PRIV_EVENT | varchar(3) | NO | Whether you have the permission to create and manage events. |

## Sample query

You can view the database privileges of users in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DATABASE_PRIVILEGE;
```
