# information_schema.PROCESSLIST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in OceanBase Database V1.4. </p>
</main>

## Purpose

This view provides information about running threads.

## Columns

| **Column** |       **Type**        | **Nullable?** |    **Description**    |
|----------|---------------------|----------------|--------------|
| ID       | bigint(20) unsigned | NO             | Connection identifier        |
| USER     | varchar(32)         | NO             | Username          |
| HOST     | varchar(128)        | NO             | Name of the client host      |
| DB       | varchar(128)        | YES            | Database name        |
| COMMAND  | varchar(4096)       | NO             | Type of the command executed by the thread    |
| TIME     | bigint(20)          | NO             | Duration of the thread in the current state, in seconds |
| STATE    | varchar(128)        | YES            | Identifier indicating the task the thread is performing |
| INFO     | varchar(262143)     | YES            | Statement being executed by the current thread  |

## Sample query

Query all running threads in a user tenant.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```

The query result is as follows:

