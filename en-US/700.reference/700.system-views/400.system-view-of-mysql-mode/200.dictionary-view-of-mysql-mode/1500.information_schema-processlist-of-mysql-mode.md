# information_schema.PROCESSLIST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view provides information about running threads.

## Columns

| **Column** |       **Type**        | **Nullable** |    **Description**    |
|----------|---------------------|----------------|--------------|
| ID       | bigint(20) unsigned | NO             | The connection identifier.<ul><li>In direct mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field indicates the client session ID. </li> <li>If <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul>        |
| USER     | varchar(32)         | NO             | The username.          |
| HOST     | varchar(128)        | NO             | The client host name.      |
| DB       | varchar(128)        | YES            | The database name.        |
| COMMAND  | varchar(4096)       | NO             | The type of command executed by the thread.    |
| TIME     | bigint(20)          | NO             | The duration of the thread in the current state, in seconds |
| STATE    | varchar(128)        | YES            | The identifier of the task being performed by the thread. |
| INFO     | varchar(262143)     | YES            | The statement being executed by the current thread.  |

## Sample query

Query the information about all running threads in the user tenant.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```

The query result is as follows:

```shell
+------------+------+----------------------+-----------+---------+------+--------+----------------------------------------------+
```
