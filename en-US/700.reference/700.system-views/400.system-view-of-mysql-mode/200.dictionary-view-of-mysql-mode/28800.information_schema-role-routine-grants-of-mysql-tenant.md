# information_schema.role_routine_grants

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V4.2.4. </p>
</main>

## Purpose

The `information_schema.role_routine_grants` view displays the routine privileges of activated roles granted to the user in the current session, and the routine privileges of other roles granted to these roles.

## Columns

| Column | Type | Nullable? | Description |
|----------------|--------------|----------------------|-----------------|
| GRANTOR        | varchar(97)  | YES  | The username of the account that grants privileges to the role.    |
| GRANTOR_HOST   | varchar(256) | YES  | The host name of the account that grants privileges to the role.      |
| GRANTEE        | varchar(32)  | NO   | The username of the account corresponding to the role.      |
| GRANTEE_HOST   | varchar(255) | NO   | The host name of the account corresponding to the role.    |
| SPECIFIC_CATALOG | varchar(3) | NO   | The name of the catalog containing the routine on which the role is granted privileges. The value of this column is always `def`.   |
| SPECIFIC_SCHEMA  | varchar(64)| NO   | The name of the database containing the routine on which the role is granted privileges.   |
| SPECIFIC_NAME    | varchar(64)| NO   | The name of the routine on which the role is granted privileges.         |
| ROUTINE_CATALOG  | varchar(3) | NO   | The name of the catalog containing the routine on which the role is granted privileges. The value of this column is always `def`.         |
| ROUTINE_SCHEMA   | varchar(64)| NO   | The name of the database containing the routine on which the role is granted privileges.          |
| ROUTINE_NAME     | varchar(64)| NO   | The name of the routine on which the role is granted privileges.         |
| PRIVILEGE_TYPE   | varchar(90)| NO   | The privileges granted. The value can be any privileges at the routine level.         |
| IS_GRANTABLE     | varchar(3) | NO   | Indicates whether the privileges of the role can be granted to other users.         |

## Sample query

1. Create a role and a function.

   Create a role named `employee`.

   ```shell
   obclient [test]> CREATE ROLE employee;
   ```

   Create a function named `add_numbers`.

   ```shell
   obclient [test]> DELIMITER //
   ```

   ```shell
   obclient [test]> CREATE FUNCTION test.add_numbers(a INT, b INT)
   RETURNS INT
   BEGIN
         RETURN a + b;
   END;//
   ```

   ```shell
   obclient [test]> DELIMITER ;
   ```

2. Grant routine privileges to the role.

   ```shell
   obclient [test]> GRANT EXECUTE,ALTER ROUTINE ON test.add_numbers TO employee;
   ```

3. Assign the role to the `user1` user.

   ```shell
   obclient [test]> GRANT employee TO user1;
   ```

4. Connect to the database as the `user1` user.

5. Activate the `employee` role in the current session.

   ```shell
   obclient [test]> SET ROLE employee;
   ```

6. Query the routine privileges of the activated role assigned to the user in the current session.

    ```shell
    obclient [test]> USE information_schema;
    ```

    ```shell
    obclient [information_schema]> SELECT * FROM information_schema.role_routine_grants;
    ```

    The query result is as follows:

    ```shell
    +---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
    | GRANTOR | GRANTOR_HOST | GRANTEE   | GRANTEE_HOST | SPECIFIC_CATALOG | SPECIFIC_SCHEMA | SPECIFIC_NAME | ROUTINE_CATALOG | ROUTINE_SCHEMA | ROUTINE_NAME | PRIVILEGE_TYPE        | IS_GRANTABLE |
    +---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
    | root    | %            | employee  | %            | def              | test            | add_numbers   | def             | test           | add_numbers  | Execute,Alter Routine | NO           |
    +---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
    1 row in set
    ```
