# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in V4.0.0. </p>
</main>

## Description

Displays the status and restore progress of log streams in the current tenant.

## Fields

| Field name       | Type                | Not null | Description               |
|---------------|---------------------|---------|--------------------|
| LS_ID         | bigint(20)          | NO   | The ID of the log stream. |
| STATUS        | varchar(100)        | NO   | The status of the log stream. Valid values are: <li>`CREATING`: The log stream is being created. <li>`CREATED`: The log stream has been created. <li>`NORMAL`: The log stream is available for service. <li>`DROPPING`: The log stream is to be deleted. Tablets must be migrated from the log stream. <li>`TENANT DROPPING`: The log stream is in the tenant to be deleted. The log stream must be deleted. <li>`WAIT OFFLINE`: The data of the log stream has been deleted. The log stream is waiting for garbage collection. <li>`CREATE ABORT`: The log stream creation failed or is no longer needed. The log stream is to be deleted.  |
| PRIMARY_ZONE  | longtext            | YES  | The primary zone of the log stream. |
| UNIT_GROUP_ID | bigint(20)          | NO   | The ID of the unit group. |
| LS_GROUP_ID   | bigint(20)          | NO   | The ID of the log stream group. |
| CREATE_SCN    | bigint(20) unsigned | NO   | The SCN where the log stream starts writing logs. |
| DROP_SCN      | bigint(20) unsigned | NO   | The SCN where the log stream is to be deleted. It is also the SCN where all user data ends. |
| SYNC_SCN      | bigint(20) unsigned | NO   | The synchronization SCN of the log stream. |
| READABLE_SCN  | bigint(20) unsigned | NO   | The readable SCN of the log stream. |
| FLAG          | varchar(2048)       | NO   | The flags of the log stream. These flags are defined: <ul><li>None: A normal log stream. </li><li>DUPLICATE: A broadcast log stream for a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: You cannot create a tablet on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: You cannot create a tablet on the broadcast log stream. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.2.0. </p></main>  |

## Examples

A user tenant queries the status and restore progress of its log streams.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```
