# mysql.time_zone_name

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V1.4. </p>
</main>

## Purpose

The `mysql.time_zone_name` view displays the names of time zones. It is a system view.

## Columns

| Column | Type | Nullable? | Description |
|--------------|-------------|------------|-------|
| Name         | varchar(64) | NO         | The name of the time zone. |
| Time_zone_id | bigint(20)  | NO         | The ID of the time zone. |
