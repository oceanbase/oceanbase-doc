# oceanbase.DBA_OB_BACKUP_STORAGE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays information about the backup destinations used for backup and restore operations in the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| PATH | varchar(1024) | NO | Root Path of Backup |
| ENDPOINT | varchar(256) | NO | Host for object storage access |
| DEST_ID | bigint(20) | YES | Backup Destination ID |
| DEST_TYPE | varchar(64) | YES | Type of the backup destination: <ul><li>`archive_log`: Log Archiving</li> <li>`backup_data`: Data Backup</li></ul> |
| AUTHORIZATION | varchar(1024) | NO | Object Storage Authorization Information |
| EXTENSION | varchar(512) | NO | Other parameters of the backup destination |
| CHECK_FILE_NAME | varchar(256) | YES | Verification File Name for Connectivity |
| LAST_CHECK_TIMESTAMP | timestamp(6) | YES | Time of Last Connectivity Check Pass |

## Sample query

View the backup destination information used for backup and restore operations in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO;
```
