# oceanbase.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1 BP2. </p>
</main>

## Purpose

The `DBA_OB_TRANSFER_PARTITION_TASK_HISTORY` view displays the history of Transfer Partition tasks that have been executed in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID          | bigint(20)   | NO   | The unique identifier of the Transfer Partition task.   |
| CREATE_TIME      | timestamp(6) | NO   | The creation time.   |
| FINISH_TIME      | timestamp(6) | NO   | The completion time of the task, including successful and canceled tasks.   |
| TABLE_ID         | bigint(20)   | NO   | The ID of the table containing the partition to be transferred.   |
| OBJECT_ID        | bigint(20)   | NO   | The `OBJECT_ID` of the partition to be transferred.   |
| DEST_LS          | bigint(20)   | NO   | The log stream ID of the destination.   |
| BALANCE_JOB_ID   | bigint(20)   | NO   | The ID of the load balancing job associated with the task.   |
| TRANSFER_TASK_ID | bigint(20)   | NO   | The ID of the Transfer task associated with the task.   |
| STATUS           | varchar(64)  | NO   | The task status. Valid values: <ul><li>COMPLETED: the task was executed successfully.</li><li>FAILED: the task failed.</li></ul>   |
| COMMENT          | longtext     | YES  | The comment.   |

## Sample query

Query the history of Transfer Partition tasks executed in the current tenant.

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY;
```
