# oceanbase.DBA_OB_TABLET_REPLICAS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the information about all tablets in the current tenant. Each tablet replica is uniquely identified by the joint key: `<TABLET_ID, SVR_IP, SVR_PORT, LS_ID>`.

## Columns

|     Column      |     Type      | Nullable |              Description              |
|---------------|-------------|------------|------------------------------------------------------------|
| CREATE_TIME     | timestamp(6)  | NO         | The time when the tablet replica was created.    |
| MODIFY_TIME     | timestamp(6)  | NO         | The time when the tablet replica was last modified.     |
| TABLET_ID     | bigint(20)  | NO         | The ID of the tablet replica.     |
| SVR_IP        | varchar(46) | NO         | The IP address of the server.     |
| SVR_PORT      | bigint(20)  | NO         | The port number of the server.        |
| LS_ID         | bigint(20)  | NO         | The ID of the log stream to which the tablet replica belongs.             |
| COMPACTION_SCN  | bigint(20) unsigned  | NO         | The snapshot version number of the data.         |
| DATA_SIZE     | bigint(20)  | NO         | The actual size of the data, in bytes.        |
| REQUIRED_SIZE | bigint(20)  | NO         | The size of the space allocated for the data, in bytes. The data is stored in macroblocks (2 MB), so `REQUIRED_SIZE >= DATA_SIZE` |

## Sample query

Query the information about all tablet replicas in the current tenant and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLET_REPLICAS LIMIT 10;
```
