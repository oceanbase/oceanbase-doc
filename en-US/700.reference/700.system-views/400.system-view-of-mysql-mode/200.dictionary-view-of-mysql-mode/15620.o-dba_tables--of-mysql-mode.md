# oceanbase.DBA_TABLES

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>The view was introduced in V4.4.x in V4.4.2. </li><li>The view was introduced in V4.5.x in V4.5.0. </li></ul></p>
</main>

## Purpose

The following view displays information about all tables of the current tenant:
