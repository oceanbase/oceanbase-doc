# mysql.help_relation

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V1.4. </p>
</main>

## Purpose

The `mysql.help_relation` view is used to generate the HELP command in coordination with the following three tables: `mysql.help_category`, `mysql.help_topic`, and `mysql.help_keyword`.

## Columns

| Column | Type | Nullable? | Description |
|-----------------|------------|----------------|--------|
| help_topic_id   | bigint(20) | NO             | The ID of the topic. |
| help_keyword_id | bigint(20) | NO             | The ID of the keyword. |
