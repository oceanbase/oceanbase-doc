# information_schema.CHECK_CONSTRAINTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.3. </p>
</main>

## Purpose

This view records constraint information about tables and columns during the `CREATE TABLE` operation.

## Columns

|        Column        |      Type       | Nullable |          Description           |
|--------------------|---------------|------------|-----------------------|
| CONSTRAINT_CATALOG | varchar(64) | NO         | The name of the directory to which the constraint belongs. This value is always `def`. |
| CONSTRAINT_SCHEMA  | varchar(128)  | NO         | The name of the `SCHEMA` to which the constraint belongs.     |
| CONSTRAINT_NAME    | varchar(64)  | NO         | The name of the constraint.                 |
| CHECK_CLAUSE       | text  | NO         | The expression that specifies the constraint condition.            |

## Sample query

Query the constraint information about tables and columns in the current tenant.

```shell
obclient [infotest]> SELECT * FROM information_schema.CHECK_CONSTRAINTS;
```

The query result is as follows:

```shell
+--------------------+-------------------+-------------------------------+--------------+
| CONSTRAINT_CATALOG | CONSTRAINT_SCHEMA | CONSTRAINT_NAME               | CHECK_CLAUSE |
+--------------------+-------------------+-------------------------------+--------------+
| def                | infotest          | tbl8_OBCHECK_1736909793670468 | (`col1` > 0) |
+--------------------+-------------------+-------------------------------+--------------+
1 row in set
```
