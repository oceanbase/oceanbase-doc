# oceanbase.DBA_OB_KV_REDIS_TABLE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.5. </p>
</main>

## Overview

The `oceanbase.DBA_OB_KV_REDIS_TABLE` view is used to store the specific commands for various Redis data structures in the current tenant and their corresponding storage table names.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | -------------- | ---------------------- | ----------------- |
| COMMAND_NAME | varchar(1024) | NO | Redis commands, such as get, set, and hgetall. |
| TABLE_NAME | varchar(OB_MAX_TABLE_NAME_LENGTH) | NO | The name of the data table. |
| GMT_CREATE   | timestamp(6) | NO   | The time when the table was created.    |
| GMT_MODIFIED | timestamp(6) | NO   | The time when the record was last modified. This field is updated during a REPLACE operation.   |

## Sample query

Query the specific commands for various data structures in Redis of the current tenant and their corresponding storage table names.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_KV_REDIS_TABLE LIMIT 10;
```
