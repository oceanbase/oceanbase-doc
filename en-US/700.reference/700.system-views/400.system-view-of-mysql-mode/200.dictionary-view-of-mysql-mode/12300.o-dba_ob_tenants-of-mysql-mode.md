# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the basic information of a tenant.

* When you query this view as the system tenant, the information of all tenants, including the system tenant, user-created tenants (user tenants), and the Meta tenant, is displayed. You can use the `TENANT_TYPE` column to distinguish the types of tenants.
* When you query this view as a user tenant, only the information of the current user tenant is displayed.
