# information_schema.SCHEMATA

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V1.4. </p>
</main>

## Purpose

The `information_schema.SCHEMATA` view displays the database metadata.

## Columns

| Column | Type | Nullable? | Description |
|----------------------------|--------------|----------------|---------|
| CATALOG_NAME               | varchar(3)   | NO             | The catalog. The value of this column is always `def`. |
| SCHEMA_NAME                | varchar(128) | NO             | The name of the database. |
| DEFAULT_CHARACTER_SET_NAME | varchar(7)   | NO             | The default character set. |
| DEFAULT_COLLATION_NAME     | varchar(18)  | NO             | The default collation. |
| SQL_PATH                   | null         | NO             | The value of this column is `NULL`. |
| DEFAULT_ENCRYPTION         | varchar(2)   | NO   | Indicates whether encryption is enabled by default. |

## Sample query

Query the metadata of all databases in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SCHEMATA;
```

The query result is as follows:

```shell
+--------------+--------------------+----------------------------+------------------------+----------+--------------------+
```
