# oceanbase.DBA_MVIEWS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVIEWS` view displays information about all materialized views.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | The name of the owner of the materialized view. |
| MVIEW_NAME | varchar(128) | NO | The name of the materialized view. |
| CONTAINER_NAME | varchar(128) | NO | The name of the container table of the materialized view. |
| QUERY | longtext | NO | The query that defines the materialized view. |
| QUERY_LEN | bigint(20) | NO | The length of the query in bytes. |
| UPDATABLE | varchar(1) | NO | Indicates whether the materialized view is updatable. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is N. </p></main> |
| UPDATE_LOG | varchar(128) | NO | The name of the update log file for an updatable materialized view. <main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |
| MASTER_ROLLBACK_SEG | varchar(128) | NO | The rollback segment of the master site or master materialized view site. <main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |
| MASTER_LINK | varchar(128) | NO | The database link of the master site or master materialized view site. <main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |

If the materialized view meets the rewrite conditions, it must follow the rules below: <ul><li>NONE: The materialized view cannot be used for rewrite because rewrite is not allowed or is blocked.  </li><li>TEXTMATCH: The query of the materialized view has restrictions on query rewrite. </li><li>GENERAL: The query of the materialized view has no restrictions on query rewrite. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |
| REFRESH_MODE | varchar(6) | NO | The refresh mode of the materialized view. <ul><li>DEMAND: The materialized view is refreshed when the refresh process is called.  </li><li>NEVER: The materialized view is never refreshed. </li></ul>|
| REFRESH_METHOD | varchar(8) | NO | The default method used to refresh the materialized view (can be overridden by API). <ul><li>COMPLETE: A full refresh.  </li><li>FORCE: An incremental refresh is attempted first. If an incremental refresh is not possible, a full refresh is performed. </li><li>FAST: An incremental refresh. </li><li>NEVER: The materialized view is never refreshed. </li></ul>|
| BUILD_MODE | varchar(9) | NO | The method used to populate the materialized view during creation. <ul><li>IMMEDIATE: The materialized view is populated immediately during creation.  </li><li>DEFERRED: The materialized view is not populated during creation. </li><li>PREBUILT: The materialized view is populated with an existing table during creation. </li></ul>|
| FAST_REFRESHABLE | varchar(18) | NO | Indicates whether the materialized view is suitable for incremental (fast) refresh. <ul><li>NO: The materialized view cannot be fast-refreshed and is therefore complex.  </li><li>DML: Only DML operations support fast refresh. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |
| LAST_REFRESH_TYPE | varchar(8) | NO | The method used for the last refresh. <ul><li>COMPLETE: A full refresh.  </li><li>FAST: An incremental refresh. </li><li>NA: The materialized view has not been refreshed yet (for example, when it is created with a delay). </li></ul>|
| LAST_REFRESH_DATE | datetime | YES | The date when the materialized view was last refreshed. |
| LAST_REFRESH_END_TIME | datetime | NO | The end time of the last refresh of the materialized view. |
| STALENESS | varchar(19) | NO | The relationship between the content of the materialized view and the content of the materialized view master. <ul><li>FRESH: The materialized view is a read-consistent view of the current state of its master object.  </li><li>IMPORT: The materialized view is imported from another database (the value of the UNKNOWN_IMPORT column is Y). Therefore, it is unknown whether the materialized view is a read-consistent view of the master view at any point in time. After a full refresh, the STALENESS value of this view will change to FRESH. </li><li>NEEDS_COMPILE: Some objects that the materialized view depends on have changed. You need to execute the ALTER MATERIALIZED VIEW...COMPILE statement to verify the materialized view and calculate the staleness. </li><li>STALE: The materialized view is outdated because one or more of its master objects have changed. If the materialized view was previously FRESH and then became STALE, it is a read-consistent view of the previous state of the master object. </li><li>UNDEFINED: The materialized view has a remote master. The concept of staleness is not defined for such materialized views. </li><li>UNKNOWN: Whether the materialized view is a read-consistent view of the master view at any point in time. </li><li>UNUSABLE: The materialized view is not a read-consistent view of the master view at any point in time. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |
| AFTER_FAST_REFRESH | varchar(19) | NO | The STALENESS value that will appear after a fast refresh is applied to this materialized view. The value of this column is the same as that of the STALENESS column. If the value is NA, it indicates that this value is used when a fast refresh is not applicable to the materialized view. <main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |

| UNKNOWN_PLSQL_FUNC | varchar(1) | NO | Indicates whether the materialized view contains PL/SQL functions. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is N. </p></main> |
| UNKNOWN_EXTERNAL_TABLE | varchar(1) | NO | Indicates whether the materialized view contains external tables. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is N. </p></main> |
| UNKNOWN_CONSIDER_FRESH | varchar(1) | NO | Indicates whether a materialized view is considered fresh. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and the default value is N. </p></main> |
| UNKNOWN_IMPORT | varchar(1) | NO | Indicates whether a materialized view is imported. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and the default value is N. </p></main> |
| UNKNOWN_TRUSTED_FD | varchar(1) | NO | Indicates whether a materialized view is refreshed by using trusted constraints. <ul><li>Y</li><li>N</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is compatible only and the default value is N. </p></main> |

| DATA_SYNC_DELAY        | varchar(128)        | NO   | The data synchronization delay of a materialized view, in seconds. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP2. </p></main>|
