# oceanbase.DBA_OB_TABLET_TO_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the list of all tablets in the current tenant and the log stream information to which each tablet belongs.

## Columns

|   Column    |     Type     | Nullable |        Description        |
|-----------|------------|------------|------------------|
| TABLET_ID | bigint(20) | NO         | The ID of the tablet.        |
| LS_ID     | bigint(1)  | NO         | The ID of the log stream to which the tablet belongs. |

## Sample query

Query the list of tablets in the current user tenant for log stream 1001, and display the first five rows.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLET_TO_LS WHERE LS_ID=1001 LIMIT 5;
```

The query result is as follows:

```shell
+-----------+-------+
| TABLET_ID | LS_ID |
+-----------+-------+
|    200004 |  1001 |
|    200005 |  1001 |
|    200007 |  1001 |
|    200008 |  1001 |
|    200009 |  1001 |
+-----------+-------+
5 rows in set
```
