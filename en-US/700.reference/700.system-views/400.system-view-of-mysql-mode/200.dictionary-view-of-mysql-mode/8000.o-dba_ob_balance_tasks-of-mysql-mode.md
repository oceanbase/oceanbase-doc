# oceanbase.DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing tasks that are being executed for the current tenant. A tenant can have multiple load balancing tasks running at the same time, and all these tasks belong to the same load balancing job.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The ID of the load balancing task. |
| CREATE_TIME | timestamp(6) | YES | The time when the task was created. |
| MODIFY_TIME | timestamp(6) | YES | The time when the information was last updated. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li>`LS_SPLIT`: log stream splitting.  </li><li>`LS_ALTER`: modifying log stream attributes. </li><li>`LS_MERGE`: log stream merging. </li><li>`LS_TRANSFER`: log stream transfer. </li></ul>|
| SRC_LS | bigint(20) | NO | The source log stream (the log data stream generated from the data source). |
| DEST_LS | bigint(20) | NO | The destination log stream. |
| PART_LIST | longtext | YES | The list of partitions, including user table partitions and global index partitions. |
| FINISHED_PART_LIST | longtext | YES | The list of partitions that have been balanced. |
| PART_COUNT | bigint(20) | YES | The number of partitions in the partition list. |
| FINISHED_PART_COUNT | bigint(20) | YES | The number of partitions that have been balanced. |
| LS_GROUP_ID | bigint(20) | NO | The ID of the log stream group. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`INIT`: the task was created.  </li><li>`CREATE_LS`: the log stream was created. </li><li>`ALTER_LS`: the log stream attributes were modified. </li> <li>`TRANSFER`: the transfer between log streams was performed. </li> <li>`SET_LS_MERGING`: the log stream was merged. </li><li>`DROP_LS`: the log stream was dropped. </li><li>`COMPLETED`: the task was successfully executed. </li><li>`CANCELED`: the task was canceled. </li></ul>|
| PARENT_LIST | varchar(1024) | YES | The list of parent tasks. |
| CHILD_LIST | varchar(1024) | YES | The list of child tasks. |
| CURRENT_TRANSFER_TASK_ID | bigint(20) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | bigint(20) | NO | The ID of the job to which the current task belongs. |
| COMMENT | longtext | YES | The comment. |
| BALANCE_STRATEGY         | varchar(64)   | YES | The balance strategy corresponding to the balance task. Valid values: <ul><li>`LS balance by migrate`: migration-based load balancing.  </li><li>`LS balance by alter`: attribute modification-based load balancing. </li><li>`LS balance by expand`: expansion-based load balancing. </li><li>`LS balance by shrink`: reduction-based load balancing. </li><li>`partition balance`: partition-based load balancing. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this column is available starting with V4.3.2. For V4.2.x, this column is available starting with V4.2.4. </p></main>   |

## Sample query

Query the load balancing tasks that are being executed for the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_TASKS\G
```
