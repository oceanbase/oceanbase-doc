# information_schema.GLOBAL_VARIABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

Records information about all global variables, including hidden variables that start with an underscore.

## Columns

|    **Column**    |     **Type**     | **Nullable** | **Description** |
|----------------|----------------|----------------|--------|
| VARIABLE_NAME  | varchar(128)   | NO             | The variable name.    |
| VARIABLE_VALUE | varchar(65536) | YES            | The variable value.    |

## Sample query

Query the value of the global variable `ob_trx_timeout`.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.GLOBAL_VARIABLES WHERE VARIABLE_NAME='ob_trx_timeout';
```

The query result is as follows:

```shell
+----------------+----------------+
| VARIABLE_NAME  | VARIABLE_VALUE |
+----------------+----------------+
| ob_trx_timeout | 86400000000    |
+----------------+----------------+
1 row in set
```
