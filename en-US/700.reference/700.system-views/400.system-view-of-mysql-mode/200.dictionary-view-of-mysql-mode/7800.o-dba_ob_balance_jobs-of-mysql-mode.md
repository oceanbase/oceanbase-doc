# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing jobs that are currently being executed in the current tenant. Each tenant can have only one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks to perform the specific load balancing operations.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | The ID of the load balancing job. |
| CREATE_TIME | timestamp(6) | YES | The time when the job was created. |
| MODIFY_TIME | timestamp(6) | YES | The time when the information was last updated. |
| BALANCE_STRATEGY | varchar(64) | NO | The name of the balancing strategy. Valid values: <ul><li>`LS balance by migrate` indicates migration-based load balancing.  </li><li>`LS balance by alter` indicates log stream attribute modification-based load balancing. </li><li>`LS balance by expand` indicates expansion-based load balancing. </li><li>`LS balance by shrink` indicates reduction-based load balancing. </li><li>`partition balance` indicates partition-based load balancing. </li></ul>|
| JOB_TYPE | varchar(64) | NO | The type of the task. Valid values: <ul><li>`LS_BALANCE` indicates log stream-based load balancing.  </li><li>`PARTITION_BALACNE` indicates partition-based load balancing. </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | The number of units to be changed in each zone. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column was introduced in V4.6.0 and always returns <code>NULL</code>. </li> <li>For V4.4.x, this column was introduced in V4.4.2 and always returns <code>NULL</code>. </li> <li>For V4.2.5, this column was introduced in V4.2.5 BP5 and always returns <code>NULL</code>. </li></ul></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | The number of primary zones to be changed. |
| STATUS | varchar(64) | NO | The status of the task. Valid values: <ul><li>`DOING` indicates that the job is being executed.  </li><li>`COMPLETED` indicates that the task was successfully executed. </li><li>`CANCELING` indicates that the task is being canceled. </li><li>`CANCELED` indicates that the task was canceled. </li> <li>`SUSPEND` indicates that the task is suspended. </li></ul>|
| COMMENT | longtext | YES | The comment. |
| MAX_END_TIME | timestamp(6) | YES | The maximum end time of the load balancing tasks. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view was introduced in V4.3.4. For V4.2.x, this column was introduced in V4.2.4. </p></main>  |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column was introduced in V4.6.0. </li> <li>For V4.4.x, this column was introduced in V4.4.2. </li> <li>For V4.2.5, this column was introduced in V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | The parameters of the balancing-related configurations.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column was introduced in V4.6.0. </li> <li>For V4.4.x, this column was introduced in V4.4.2. </li> <li>For V4.2.5, this column was introduced in V4.2.5 BP5. </li></ul></main> |

## Sample query

Query the load balancing jobs that are currently being executed in the current tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
```

The query result is as follows:

```shell
+---------+----------------------------+----------------------------+------------------------+------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+

+---------+----------------------------+----------------------------+------------------------+------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
| 6083968 | 2026-01-16 17:23:18.070731 | 2026-01-16 17:23:18.070731 | LS group count balance | LS_BALANCE |            NULL |                       2 | DOING  | NULL    | NULL         | z1:2,z2:2,z3:3     | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |
+---------+----------------------------+----------------------------+------------------------+------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
1 row in set
```
