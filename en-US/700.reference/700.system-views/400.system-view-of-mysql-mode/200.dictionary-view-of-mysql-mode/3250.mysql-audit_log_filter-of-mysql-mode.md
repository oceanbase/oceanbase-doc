# mysql.audit_log_filter

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view was introduced in OceanBase Database V4.2.4. </p>
</main>

## Purpose

The  `mysql.audit_log_filter` displays the definitions of audit filters.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This view applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support security audit. </p>
</main>

## Columns

| Column | Type | Nullable? | Description |
|------------|-------------|---------------------|----------------------------------------|
| NAME   | varchar(64) | NO | The name of the filter. |
| FILTER | longtext	   | NO | The definition of the filter. |

## Sample query

```shell
obclient [mysql]> select * from mysql.audit_log_filter;
```

The query result is as follows:

```shell
+---------+-------------------------------+
| NAME    | FILTER                        |
+---------+-------------------------------+
| log_all | { "filter": { "log": true } } |
+---------+-------------------------------+
1 row in set (0.003 sec)
```
