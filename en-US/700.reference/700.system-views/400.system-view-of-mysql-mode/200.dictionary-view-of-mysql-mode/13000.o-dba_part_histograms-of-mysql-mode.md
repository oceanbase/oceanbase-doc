# oceanbase.DBA_PART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the histogram data (endpoints of each histogram) for the partitions of all partitioned tables in the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | Owner of the table |
| TABLE_NAME | varchar(128) | NO | Table name |
| PARTITION_NAME | varchar(128) | NO | Partitioned table name |
| COLUMN_NAME | varchar(128) | NO | Column name |
| ENDPOINT_NUMBER | decimal(10,0) | NO | Bin number of histogram |
| ENDPOINT_VALUE | decimal(10,0) | NO | Standardized Endpoint Value of the Bucket |
| ENDPOINT_ACTUAL_VALUE | text | NO | The actual string value of the bucket endpoint (non-standardized). |
| ENDPOINT_ACTUAL_VALUE_RAW | text | NO | Actual value of the endpoint in the original format |
| ENDPOINT_REPEAT_COUNT | decimal(10,0) | NO | Endpoint Frequency (Only for hybrid histograms; set to 0 for other histogram types.) |

## Sample query

Query the histogram information of partitions in the `test_part_hist` partitioned table in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_PART_HISTOGRAMS WHERE TABLE_NAME ='test_part_hist';
```
