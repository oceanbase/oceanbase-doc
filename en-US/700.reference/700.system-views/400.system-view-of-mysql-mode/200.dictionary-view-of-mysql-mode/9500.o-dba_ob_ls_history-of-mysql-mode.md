# oceanbase.DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log streams that have existed in the current tenant in the past.

## Columns

| Column        | Type           | Nullable | Description                                       |
|-------------|---------------|-------------|-------------------------------------------|
| LS_ID       | bigint(20)    | NO          |  The ID of the log stream.                                 |
| LS_GROUP_ID | bigint(20)    | NO          |  The ID of the log stream group.                               |
| STATUS      | varchar(100)  | NO          |  The status of the log stream:<ul><li>CREATING: The log stream is being created.</li><li>NORMAL: The log stream is in the normal state.</li><li>DROPPING: The log stream is being dropped.</li><li>PRE_TENANT_DROPPING: The special state of the system log stream. This state indicates that all log streams under the tenant are being dropped. </li><li>TENANT_DROPPING: The log stream is being dropped because the tenant is being dropped. </li><li>DROPPED: The log stream has been dropped or is being dropped. </li><li>WAIT_OFFLINE: The log stream is waiting to be dropped. </li><li>CREATE_ABORT: The creation of the log stream has been aborted. </li></ul>        |
| FLAG        | varchar(2048) | NO          |  The flag of the log stream:<ul><li>Empty: The log stream is in the normal state. </li><li>DUPLICATE: The broadcast log stream of the user tenant. The replicated tables are created on this log stream. </li><li>BLOCK_TABLET_IN: The tablet cannot be created on this log stream. </li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          |  The GTS when the log stream was created, in nanoseconds.              |

## Sample query

Query the log streams that have existed in the current user tenant in the past.

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```

The query result is as follows:

```shell
+-------+-------------+--------+------+---------------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN          |
+-------+-------------+--------+------+---------------------+
|     1 |           0 | NORMAL | NULL |                   0 |
|  1001 |        1001 | NORMAL | NULL | 1736152507462028000 |
+-------+-------------+--------+------+---------------------+
2 rows in set
```
