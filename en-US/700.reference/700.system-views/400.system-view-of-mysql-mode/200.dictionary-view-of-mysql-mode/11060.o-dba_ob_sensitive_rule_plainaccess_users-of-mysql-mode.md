# oceanbase.DBA_OB_SENSITIVE_RULE_PLAINACCESS_USERS

## Purpose

This view displays all users and roles in the current tenant that have plaintext access permissions for a specific sensitive rule.

## Columns

|        Column         |      Type       | Nullable |                      Description                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| RULE_NAME         | varchar(256)    | NO         | The name of the sensitive rule.                                           |
| USER_NAME      | varchar(128)    | NO         | The name of the user.                                        |
| USER_TYPE        | varchar(4)    | NO         | The type of the user. Valid values: `USER` and `ROLE`. `USER` indicates a user, and `ROLE` indicates a role.                                      |

## Sample query

Query all users and roles in the current tenant that have plaintext access permissions for a specific sensitive rule.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SENSITIVE_RULE_PLAINACCESS_USERS;
```

The query result is as follows:

```shell
+-----------+-----------+-----------+
| RULE_NAME | USER_NAME | USER_TYPE |
+-----------+-----------+-----------+
| r1        | root      | USER      |
+-----------+-----------+-----------+
1 row in set
```
