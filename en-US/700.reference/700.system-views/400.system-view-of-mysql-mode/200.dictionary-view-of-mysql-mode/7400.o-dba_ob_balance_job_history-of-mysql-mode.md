# oceanbase.DBA_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.0. </p>
</main>

## Overview

The `DBA_OB_BALANCE_JOB_HISTORY` view displays the history of all load balancing jobs executed for a tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | ------- |
| JOB_ID | bigint(20) | NO | CLB Work ID |
| CREATE_TIME | timestamp(6) | NO | Job Creation Time |
| FINISH_TIME | timestamp(6) | NO | Job completion time, including success and cancellation times |
| BALANCE_STRATEGY | varchar(64) | NO | Load balancing strategy name. Valid values: <ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing. </li><li>`LS balance by expand`: Expansion balancing </li><li>`LS balance by shrink`: Scale-down balancing </li><li>`partition balance`: Partition balancing </li></ul> |
| JOB_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>`LS_BALANCE`: Log stream balancing  </li><li>`PARTITION_BALACNE`: Partition balancing. </li></ul> |
| TARGET_UNIT_NUM | bigint(20) | NO | Number of Units in Each Zone Where Target Changes <main id="notice" type='explain'><h4>Note</h4><p>For version V4.2.5, the value of this field has been changed to always be <code>NULL</code> starting from V4.2.5 BP5.</p></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | Number of Changed Primary Zones |
| STATUS | varchar(64) | NO | Task Status  <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELING`: Canceled </li><li>`CANCELED`: Task canceled. </li></ul> |
| COMMENT | longtext | YES | Comments |
| MAX_END_TIME | timestamp(6) | YES | Maximum End Time of Load Balancing Tasks<main id="notice" type='explain'><h4>Note</h4><p>For V4.2.x, this field is available starting from V4.2.4. For V4.3.x, this view is available starting from V4.3.4.</p></main> |
| ZONE_UNIT_NUM_LIST | varchar(4096) | NO | Number of Units in Each Zone of Tenant <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting from V4.2.5 BP5 for version V4.2.5.</p></main> |
| PARAMETER_LIST | longtext | NO | Load balancing related parameters <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.5, this field is available starting from V4.2.5 BP5.</p></main> |

## Sample query

View the history of all load balancing tasks executed for the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOB_HISTORY;
```
