# oceanbase.DBA_WR_EVENT_NAME

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.5 for V4.3.x. </li> <li>This view is available starting with V4.2.2 for V4.2.x. </li></ul>
</main>

## Purpose

The `DBA_WR_EVENT_NAME` view displays the names of tenant-level wait events after they are persisted.

## Columns

| **Column**  | **Type**    | **Nullable** | **Description**                               |
|---------------|-------------|---------------------|----------------------------------------|
| EVENT_ID      | bigint(20)  | NO   |  The ID of the wait event.   |
| EVENT_NAME    | varchar(64) | YES  |  The name of the wait event.    |
| PARAMETER1    | varchar(64) | YES  |  The name of parameter 1 of the wait event.   |
| PARAMETER2    | varchar(64) | YES  |  The name of parameter 2 of the wait event.   |
| PARAMETER3    | varchar(64) | YES  |  The name of parameter 3 of the wait event.   |
| WAIT_CLASS_ID | bigint(20)  | YES  |  The ID of the class to which the wait event belongs.     |
| WAIT_CLASS    | varchar(64) | YES  |  The name of the class to which the wait event belongs.   |

The `WAIT_CLASS` column in the view contains the names of wait event classes and their corresponding IDs. The following table describes the wait event classes and their IDs.

| Class Name | ID | Description |
|------|----|------|
| OTHER | 100 | A wait event that does not belong to any other class. |
| APPLICATION | 101 | A wait event caused by client-side code. |
| CONFIGURATION | 102 | A wait event caused by insufficient database or instance resources. |
| ADMINISTRATIVE | 103 | A wait event caused by a database administrator's command. |
| CONCURRENCY | 104 | A wait event for internal database resources. |
| COMMIT | 105 | A wait event related to log submission. |
| IDLE | 106 | A wait event for an inactive session. |
| NETWORK | 107 | A wait event related to network communication. |
| USER_IO | 108 | A wait event for user I/O. |
| SYSTEM_IO | 109 | A wait event for background process I/O. |
| CLUSTER | 111 | A wait event related to the cluster. |

## Sample query
