# oceanbase.DBA_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the global information of major compactions of the current tenant.

## Columns

|           Column           |     Type      | Nullable |        Description         |
|--------------------------|-------------|------------|---------------------------------------------|
| FROZEN_SCN           | bigint(20) unsigned  | NO         | The version number of the last major compaction.           |
| FROZEN_TIME              | timestamp(6)  | NO         | The time when the last major compaction was initiated. (FROZEN_SCN is displayed in a readable format.)          |
| GLOBAL_BROADCAST_SCN | bigint(20) unsigned  | NO         | The version number of the global broadcast major compaction.         |
| LAST_SCN             | bigint(20) unsigned  | NO         | The version number of the last major compaction that was completed.      |
| LAST_FINISH_TIME         | timestamp(6)  | NO         | The time when the last major compaction was completed.         |
| START_TIME               | timestamp(6)  | NO         | The time when the major compaction was initiated.            |
| STATUS                   | varchar(10) | NO         | <ul><li>`IDLE`: No major compaction is in progress. </li><li> `COMPACTING`: A major compaction is in progress. </li><li>`CHECKSUM`: The checksum is being verified. </li></ul>   |
| IS_ERROR                 | varchar(3)  | NO         | <ul><li>`YES`: An error occurred during the major compaction. </li><li> `NO`: No error occurred during the major compaction. </li></ul>   |
| IS_SUSPENDED             | varchar(3)  | NO         | <ul><li>`YES`: The major compaction is suspended. </li><li>`NO`: The major compaction is not suspended.   </li></ul>   |
| INFO                     | varchar(14) | NO         | The information about the major compaction. For example, the reason for the failure.  |
| MODE                     | varchar(7)  | NO         | The type of daily major compaction:<ul><li>`TENANT`: Tenant-level major compaction</li> <li>`WINDOW`: Window-based major compaction</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>|

## Sample query

Query the global information of major compactions of the current tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_MAJOR_COMPACTION;
```

The query result is as follows:

```shell
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+--------+
| FROZEN_SCN          | FROZEN_TIME                | GLOBAL_BROADCAST_SCN | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS | IS_ERROR | IS_SUSPENDED | INFO | MODE   |
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+--------+
| 1772992801519693000 | 2026-03-09 02:00:01.519693 |  1772992801519693000 | 1772992801519693000 | 2026-03-09 02:05:42.538179 | 2026-03-09 16:15:11.214954 | IDLE   | NO       | NO           |      | WINDOW |
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+--------+
1 row in set
```
