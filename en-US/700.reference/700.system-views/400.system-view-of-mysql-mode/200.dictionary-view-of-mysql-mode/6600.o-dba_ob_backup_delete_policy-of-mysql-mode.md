# oceanbase.DBA_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the cleanup strategy set for the tenant for expired backup cleanup or automatic backup cleanup.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| POLICY_NAME | varchar(256) | NO | The name of the cleanup strategy. <ul><li>`default`: indicates that automatic cleanup is performed for backups stored in the `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` parameters of the tenant. </li> <li>`log_only`: indicates that automatic cleanup is performed for logs stored in the `LOG_ARCHIVE_DEST` parameter of the tenant. </li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | The time window for recovery. Default value: 0 |

## Sample query

Query the cleanup strategy of the user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_POLICY;
```

The query result is as follows:

```shell
+-------------+-----------------+
| POLICY_NAME | RECOVERY_WINDOW |
+-------------+-----------------+
| default     | 7d              |
+-------------+-----------------+
1 row in set
```
