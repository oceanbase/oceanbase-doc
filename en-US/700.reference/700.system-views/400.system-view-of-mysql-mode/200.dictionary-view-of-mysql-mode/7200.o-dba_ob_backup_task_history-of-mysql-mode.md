# oceanbase.DBA_OB_BACKUP_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays Task-level backup history for a specific user tenant.

## Columns

| Column | Column | Column | Column |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task ID for a backup task at the TASK level. A backup task corresponds to a backup set. |
| JOB_ID | bigint(20) | NO | The ID of the task. The task is part of a job.
JOB_ID |
| Column | Type | Nullable | Description | | --- | --- | --- | --- | | INCARNATION | bigint(20) | NO | The number of incarnations after the Flashback Database operation. |
| BACKUP_SET_ID | bigint(20) | NO | The ID of the backup set corresponding to the task. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the task. |
| END_TIMESTAMP | timestamp(6) | NO | The end time of the task. |
| STATUS | varchar(4096) | NO | The status of the backup. |
| START_SCN | bigint(20) unsigned | NO | The SCN when the backup started. |
| END_SCN | bigint(20) unsigned | NO | SCN where the backup ends |
| USER_LS_START_SCN | bigint(20) unsigned | NO | The SCN in the log stream meta-data. |
| ENCRYPTION_MODE | varchar(4096) | YES | The encryption mode. Valid values: None, Password, Password Encryption, Transparent Encryption, and Dual mode Encryption. None indicates no encryption. Password indicates that only password protection is used. Password Encryption indicates that encryption and password protection are used. Transparent Encryption indicates that Transparent Data Encryption (TDE) is used. Dual mode Encryption indicates that TDE encryption and password protection are used. |
| PASSWD | varchar(4096) | YES | Password |
| INPUT_BYTES | bigint(20) | YES | The number of input bytes. |
| OUTPUT_BYTES | bigint(20) | YES | The number of output bytes |
|OUTPUT_RATE_BYTES | decimal(28,4) | NO | Output rate in bytes per second. |
| EXTRA_META_BYTES | bigint(20) | YES | The extra number of bytes |
| TABLET_COUNT | bigint(20) | YES | Tablet total number |
| FINISH_TABLET_COUNT | bigint(20) | YES | The total number of TABLETs that have been backed up. |
| MACRO_BLOCK_COUNT | bigint(20) | YES | Number of macroblocks. |
| FINISH_MACRO_BLOCK_COUNT | bigint(20) | YES | The number of macroblocks completed during the backup. |
| FILE_COUNT | bigint(20) | YES | Number of backup files |
| Column | Type | Nullable | Description | | --- | --- | --- | --- | | META_TURN_ID | bigint(20) | YES | The backup rounds of the meta data. |
| DATA_TURN_ID | bigint(20) | YES | Backup round for data |
| RESULT | bigint(20) | YES | Backup error code |
| COMMENT | varchar(4096) | YES | Error code description |
| PATH | varchar(4096) | YES | Backup path |
| MINOR_TURN_ID                 | bigint(20)     | NO              | The minor compaction end turn.      |
| MAJOR_TURN_ID                 | bigint(20)     | NO              | The backup round.         |
