# information_schema.ENGINES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view records information about storage engines.

## Columns

|   **Column**   |    **Type**     | **Nullable** |     **Description**      |
|--------------|---------------|----------------|-----------------|
| ENGINE       | varchar(64)   | NO             | The engine type.            |
| SUPPORT      | varchar(8)    | NO             | Indicates whether the current storage engine is supported.      |
| COMMENT      | varchar(80)   | NO             | The comment.              |
| TRANSACTIONS | varchar(3)    | NO             | Transaction-related information.          |
| XA           | varchar(3)    | NO             | XA-related information for distributed transactions.   |
| SAVEPOINTS   | varchar(3)    | NO             | Savepoints-related information. |

## Sample query

Query information about storage engines.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.ENGINES;
```

The query result is as follows:

```shell
+--------+---------+-----------------------+--------------+------+------------+
| ENGINE | SUPPORT | COMMENT               | TRANSACTIONS | XA   | SAVEPOINTS |
+--------+---------+-----------------------+--------------+------+------------+
| InnoDB | YES     | Supports transactions | YES          | NO   | YES        |
+--------+---------+-----------------------+--------------+------+------------+
1 row in set
```
