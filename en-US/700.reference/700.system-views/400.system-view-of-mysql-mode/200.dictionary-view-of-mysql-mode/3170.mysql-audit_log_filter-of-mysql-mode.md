# mysql.audit_log_filter

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>This view is available starting with V4.3.3 for V4.3.x. </li> <li>This view is available starting with V4.2.4 for V4.2.x. </li></ul></p>
</main>

## Purpose

The `mysql.audit_log_filter` view displays the definitions of audit filters.

<main id="notice" >
  <h4>Applicability</h4>
  <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support the audit feature. </p>
</main>

## Columns

| **Column** | **Type**  | **Nullable** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| NAME   | varchar(64) | NO | The name of the filter. |
| FILTER | longtext	   | NO | The definition of the filter. |

## Sample query

Query the definitions of audit filters.

```shell
obclient [mysql]> select * from mysql.audit_log_filter;
```

The query result is as follows:

```shell
+---------+-------------------------------+
| NAME    | FILTER                        |
+---------+-------------------------------+
| log_all | { "filter": { "log": true } } |
+---------+-------------------------------+
1 row in set (0.003 sec)
```
