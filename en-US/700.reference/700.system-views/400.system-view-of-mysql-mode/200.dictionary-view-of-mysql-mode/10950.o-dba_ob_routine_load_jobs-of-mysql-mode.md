# oceanbase.DBA_OB_ROUTINE_LOAD_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_ROUTINE_LOAD_JOBS` view is used to obtain information about Routine Load tasks in the current tenant.

## Columns

|    Column     |        Type        | Nullable |    Description     |
|----------------|--------------------|------|-----------------------|
| JOB_ID         | bigint(20)         | NO   | The ID of the job.|
| JOB_NAME       | varchar(128)       | NO   | The name of the job.|
| CREATE_TIME    | timestamp(6)       | NO   | The time when the job was created.|
| PAUSE_TIME     | timestamp(6)       | YES  | The time when the job was paused.|
| END_TIME       | timestamp(6)       | YES  | The time when the job was stopped or completed.|
| DATABASE_NAME  | varchar(128)       | NO   | The name of the database corresponding to the target table.|
| DATABASE_ID    | bigint(20)         | NO   | The ID of the database corresponding to the target table.|
| TABLE_NAME     | varchar(256)       | NO   | The name of the target table.|
| TABLE_ID       | bigint(20)         | NO   | The ID of the target table.|
| STATE          | varchar(16)        | NO   | The status of the job. Valid values: <ul><li>`RUNNING`: The job is running.</li><li>`PAUSED`: The job is paused and can be resumed.</li><li>`STOPPED`: The job has been stopped or completed and cannot be resumed.</li><li>`CANCELLED`: The job was canceled due to a failure.</li></ul>|
| JOB_PROPERTIES | varbinary(1048576) | NO   | The configuration attributes of the job in JSON format.|
| PROGRESS       | varbinary(1048576) | YES  | The consumption progress information in JSON format.|
| LAG            | varbinary(1048576) | YES  | The consumption lag information in JSON format.|
| TMP_PROGRESS   | varbinary(1048576) | YES  | The temporary progress information, used for intermediate states before transaction commit.|
| TMP_LAG        | varbinary(1048576) | YES  | The temporary lag information.|
| LAST_TRACE_ID  | varchar(64)        | YES  | The trace ID of the last operation, used for issue tracking.|
| LAST_RET_CODE  | bigint(20)         | YES  | The error code of the last execution. 0 indicates success.|
| LAST_ERROR_MSG | varchar(512)       | YES  | The detailed information about the job execution failure.|

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ROUTINE_LOAD_JOBS LIMIT 1\G
```
