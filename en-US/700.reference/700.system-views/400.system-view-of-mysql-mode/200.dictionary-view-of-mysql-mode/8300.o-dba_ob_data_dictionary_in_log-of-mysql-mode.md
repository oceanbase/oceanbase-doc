# oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view records the location range of the data dictionary in the system log stream, which facilitates the consumption of the data dictionary by Change Data Capture (CDC).

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | The SNAPSHOT SCN of the corresponding tenant when the data dictionary was generated. |
| REPORT_TIME | timestamp(6) | YES | The time when the data dictionary was generated and reported to the internal table. (The unit is microseconds.) |
| START_LSN | bigint(20) unsigned | NO | The LSN of the first log in the tenant's primary log stream where the data dictionary was persisted. |
| END_LSN | bigint(20) unsigned | NO | The LSN of the last log in the tenant's primary log stream where the data dictionary was persisted. |

## Sample query

Query the location range of the data dictionaries of all user tenants in the system log stream in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_DATA_DICTIONARY_IN_LOG;
```
