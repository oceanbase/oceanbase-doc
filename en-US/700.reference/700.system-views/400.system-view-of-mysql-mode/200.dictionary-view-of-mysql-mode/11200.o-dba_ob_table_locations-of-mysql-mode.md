# oceanbase.DBA_OB_TABLE_LOCATIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the location of tables or partitions, including system tables, user tables, index tables, etc.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| DATABASE_NAME | varchar(128) | NO | Database Name |
| TABLE_NAME | varchar(256) | NO | Table name |
| TABLE_ID | bigint(20) | NO | Table ID |
| TABLE_TYPE | varchar(13) | NO | Table type:<ul><li>USER TABLE: a user table. </li><li>SYSTEM TABLE: a system table, which is a table created by the system. </li><li>INDEX: an index table. </li><li>LOB AUX TABLE: a LOB auxiliary table, which is a system-created table used to assist in implementing LOB columns.</li></ul> |
| PARTITION_NAME | varchar(64) | NO | The name of the partition. For a non-partitioned table, this parameter is NULL by default. |
| SUBPARTITION_NAME | varchar(64) | NO | Subpartition name. NULL if no subpartitions exist. |
| INDEX_NAME | varchar(256) | NO | Displays the index table name if it is an index table; otherwise, displays NULL. |
| DATA_TABLE_ID | bigint(20) | NO | Displays the ID of the primary table to which an index or LOB auxiliary table belongs. If no primary table is associated, NULL is displayed. |
| TABLET_ID | bigint(20) | NO | TABLET ID |
| LS_ID | bigint(20) | NO | Log stream where the object is located |
| ZONE | varchar(128) | NO | ZONE of the Replica |
| SVR_IP | varchar(46) | NO | IP address of the replica location |
| SVR_PORT | bigint(20) | NO | Port information of the replica location |
| ROLE | varchar(8) | NO | Replica Role |
| REPLICA_TYPE | varchar(18) | NO | Log stream replica type:<ul><li>`FULL`: Full-featured replica</li> <li>READONLY: Read-only replica</li> <li>`COLUMNSTORE`: Columnstore replica</li></ul> |
| DUPLICATE_SCOPE | varchar(7) | NO | Indicates whether this table is a replicated table. Valid values: <ul><li>`CLUSTER`: Copy table  </li><li>`NONE`: normal table </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0.</p></main> |
| DUPLICATE_READ_CONSISTENCY | varchar(6) | NO | Displays the read-consistency constraints for standby replicas of replicated tables. Valid values: <ul><li>`NONE`: Indicates a non-replicated table. This attribute is meaningless.</li><li>`STRONG`: Indicates that the standby replica of the replicated table supports strong-consistency reads.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.3.4.</p></main> |
| OBJECT_ID | bigint(20) | NO | Object ID Corresponding to Partition<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| TABLEGROUP_NAME | varchar(128) | NO | The name of the table group to which the table belongs.<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| TABLEGROUP_ID | bigint(20) | NO | Table corresponding to the table group ID<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| SHARDING | varchar(20) | NO | Sharding attribute (balanced mode) of the table corresponding to the table group.<main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0.</p></main> |
| SCOPE | varchar(20) | NO | Table group`SCOPE`Attribute. Valid values: <ul><li>`SERVER`: Indicates that the leaders of all partition groups are distributed on the same node.  </li><li>`ZONE`: Indicates that the leaders of all partition groups are distributed within the same zone and are scattered across nodes within that zone.  </li><li>`CLUSTER`: Indicates that the leaders of all partition groups are scattered across nodes in the cluster.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For version V4.4.2, this field is available starting from V4.4.2 BP1.</p></main> |
| INDEX_TYPE | varchar(6) | NO | Displays indexes of the index table.`GLOBAL`/`LOCAL`The attribute information can have the following three values:<ul><li>`NULL`: indicates a non-index table. </li><li>`GLOBAL`: Indicates a global index, which contains`INDEX_TYPE_NORMAL_GLOBAL`、INDEX_TYPE_UNIQUE_GLOBAL、`INDEX_TYPE_SPATIAL_GLOBAL`.</li><li>`LOCAL`: Local index, contains`INDEX_TYPE_NORMAL_LOCAL`、`INDEX_TYPE_UNIQUE_LOCAL`、`INDEX_TYPE_PRIMARY`、`INDEX_TYPE_DOMAIN_CTXCAT`、`INDEX_TYPE_NORMAL_GLOBAL_LOCAL_STORAGE`、`INDEX_TYPE_UNIQUE_GLOBAL_LOCAL_STORAGE`、`INDEX_TYPE_SPATIAL_LOCAL`、`INDEX_TYPE_SPATIAL_GLOBAL_LOCAL_STORAGE`</li></ul> <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting with V4.4.1.</li> <li>For V4.2.5, this field is available starting with V4.2.5 BP2.</li></ul></main> |
