# oceanbase.DBA_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p> This view is introduced in V4.0.0. </p>
</main>

## Purpose

Displays the association relationships between table groups and tables in the current tenant. Tables not in a table group are not displayed.

## Columns

| Column | Type | Nullable? | Description |
|-----------------|--------------|------------|---------------|
| TABLEGROUP_NAME | varchar(128) | NO         | The name of the table group.           |
| OWNER           | varchar(128) | NO         | The name of the database to which the table belongs. |
| TABLE_NAME      | varchar(256) | NO         | The name of the table.       |
| SHARDING        | varchar(10)   | NO         | The SHARDING attribute of the table group. The value can be one of the following: <ul><li>`NONE`: All partitions of all tables in the table group are aggregated on the same server, and no restrictions are imposed on tables to be added to the table group. </li> <li>`PARTITION`: The data of each table in the table group is scattered by partition; all subpartitions in a partition are aggregated together. </li> <li>`ADAPTIVE`: The data of each table in the table group is scattered adaptively. Specifically, tables partitioned by partition in the table group are scattered by partition; subpartitions in each partition are scattered adaptively. </li></ul>    |

## Examples

A user tenant queries the association relationships of the table group named `tblgroup1` in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'tblgroup1';
```

The query result is as follows:

```shell
+-----------------+-----------+------------+----------+
| TABLEGROUP_NAME | OWNER     | TABLE_NAME | SHARDING |
+-----------------+-----------+------------+----------+
| tblgroup1       | test      | tbl3       | ADAPTIVE |
+-----------------+-----------+------------+----------+
1 row in set
```
