# oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN` view displays information about each log truncation operation for the current tenant.

## Columns

| Column               | Type                | Nullable | Description                                       |
|---------------------|---------------------|----------|--------------------------------------------------|
| TENANT_ID           | bigint(20)          | NO       | The tenant ID.                                   |
| TIMESTAMP           | timestamp(6)        | NO       | The creation time, in microseconds.              |
| SWITCHOVER_EPOCH    | bigint(20)          | NO       | The `SWITCHOVER_EPOCH` value when the tenant role was switched to `NORMAL`. `SWITCHOVER_EPOCH` is a unique identifier for tenant role switching (Switchover/Failover) operations. |
| OP_TYPE              | varchar(64)         | NO       | The operation type. Valid values: <ul><li>`FAILOVER_TO_PRIMARY`: This is the type of a failover operation. It is used to switch a standby tenant to a primary tenant when the primary tenant is unavailable. </li><li>`FLASHBACK_STANDBY_LOG`: This is the type of a standby log truncation operation. It is used to truncate the logs of a standby tenant to a specified SCN. </li></ul> |
| FLASHBACK_LOG_SCN   | bigint(20) unsigned | NO       | The endpoint of the log truncation for the tenant. |

## Sample query

Query information about each log truncation operation for the current tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```

The query result is as follows:

```shell
+-----------+----------------------------+------------------+---------------------+---------------------+
| TENANT_ID | TIMESTAMP                  | SWITCHOVER_EPOCH | OP_TYPE             | FLASHBACK_LOG_SCN   |
+-----------+----------------------------+------------------+---------------------+---------------------+
|      1002 | 2025-05-21 16:48:53.583749 | 1747817333380437 | FAILOVER TO PRIMARY | 1747817331313513000 |
+-----------+----------------------------+------------------+---------------------+---------------------+
1 row in set
```
