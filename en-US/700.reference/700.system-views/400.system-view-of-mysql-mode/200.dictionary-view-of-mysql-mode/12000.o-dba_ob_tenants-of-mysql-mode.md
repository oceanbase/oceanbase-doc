# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the basic information of a tenant.

* When querying this view through the system tenant, it displays information for all tenants, including the system tenant, user-created tenants (user tenants), and the Meta tenant. You can distinguish between tenant types based on the `TENANT_TYPE` column.
* When you query this view from a user tenant, only information of the current tenant is displayed.
