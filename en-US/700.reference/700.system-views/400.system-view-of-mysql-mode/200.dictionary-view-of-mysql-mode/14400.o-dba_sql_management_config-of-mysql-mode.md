# oceanbase.DBA_SQL_MANAGEMENT_CONFIG

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the configuration parameters of the SPM of the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(128) | NO | The name of the configuration parameter. Valid values: <ul><li>SPACE_BUDGET_PERCENT</li><li>PLAN_RETENTION_WEEKS</li></ul> |
| PARAMETER_VALUE | text | YES | The value of the configuration parameter. |
| LAST_MODIFIED | timestamp(6) | YES | The time when the parameter value was last updated. |
| MODIFIED_BY | varchar(128) | NO | The user who last updated the parameter value. |

## Sample query

Query the configuration parameters of the SPM of the current tenant.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_SQL_MANAGEMENT_CONFIG;
```
