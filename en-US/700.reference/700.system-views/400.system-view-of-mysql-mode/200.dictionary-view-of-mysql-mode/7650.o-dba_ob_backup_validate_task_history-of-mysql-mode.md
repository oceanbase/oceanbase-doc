# oceanbase.DBA_OB_BACKUP_VALIDATE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.4.2, this view is available starting with V4.4.2 BP2.</li>
<li>For V4.6.x versions, this view is available starting from V4.6.0.</li></ul>
</main>

## Overview

The `oceanbase.DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` view displays the execution history of backup validation tasks initiated by the current tenant. Each task corresponds to a validation job for a backup set or log archive piece.

## Columns

| Column | Type | Nullable | Description |
| ----------------- | ------------- | -------------- | -------------- |
| TASK_ID | bigint(20) | NO | The task ID. |
| INCARNATION | bigint(20) | NO | Avatar ID |
| JOB_ID | bigint(20) | NO | Job ID of the task. |
| TASK_TYPE | varchar(64) | NO | Verification task type: <ul><li>`BACKUPSET`: Verify the specified backup set.</li> <li>`ARCHIVELOG_PIECE`: Verify the specified log archive piece.</li></ul> |
| ID | bigint(20) | YES | The verified backup set's`backup_set_id`or archived pieces`piece_id` |
| PATH | longtext | YES | Backup Path or Log Archiving Path to Verify |
| PATH_TYPE | varchar(64) | YES | Valid path types:<ul><li>`BACKUP_SET_DEST`: Data backup path</li> <li>`ARCHIVELOG_PIECE_DEST`: Log archive path</li></ul> |
| DEST_ID | bigint(20) | YES | ID of the backup or archive path to be verified |
| PLUS_ARCHIVELOG | varchar(64) | NO | Whether to Include Compensation Logs |
| INITIATOR_TASK_ID | bigint(20) | NO | Parent task ID of the compensation log verification task. 0 if not specified. |
| VALIDATE_LEVEL | varchar(64) | NO | Verification level: <ul><li>`basic`: Checks only the integrity of the file list. </li> <li>`physical`: Checks the correctness of physical data and logical consistency.</li></ul> |
| ROUND_ID | bigint(20) | NO | Round ID of the log archive piece, or 0 if not specified. |
| START_TIMESTAMP | timestamp(6) | NO | Start Time of Verification Task |
| END_TIMESTAMP | timestamp(6) | NO | End time of the verification task |
| STATUS | varchar(64) | NO | Task status: <ul><li>`COMPLETED`: The verification task has been completed.</li> <li>`FAILED`: Verification task execution failed.</li> <li>`CANCELED`: The verification task has been canceled.</li></ul> |
| TOTAL_LS_COUNT | bigint(20) | YES | Number of Log Streams Included in the Task |
| FINISH_LS_COUNT | bigint(20) | YES | Number of Log Streams Verified |
| TOTAL_BYTES | bigint(20) | YES | Estimated data volume to be verified, in bytes |
| VALIDATED_BYTES | bigint(20) | YES | The amount of data that has been verified, in bytes |
| RESULT | bigint(20) | NO | Error code information of the verification result |
| COMMENT | varchar(4096) | YES | Reason description for the verification task failure |

## Sample query

Users can view the execution history of task-level backup verification tasks initiated by the current tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_TASK_HISTORY\G
```
