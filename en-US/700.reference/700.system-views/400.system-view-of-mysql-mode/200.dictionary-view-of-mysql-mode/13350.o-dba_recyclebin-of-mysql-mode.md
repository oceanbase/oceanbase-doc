# oceanbase.DBA_RECYCLEBIN

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays information about all recycle bin objects under the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------- | --------------- | ------------ | -------------------- |
| OWNER | varchar(128) | NO | The name of the original object owner. |
| OBJECT_NAME | varchar(128) | NO | New name of the object |
| ORIGINAL_NAME | varchar(128) | NO | Original name of the object |
| OPERATION | varchar(9) | NO | This field is not supported. The default value is NULL. |
| TYPE | varchar(25) | NO | Object type |
| TS_NAME | varchar(30) | NO | The name of the tablespace to which the object belongs. |
| CREATETIME | date | YES | Time of object creation |
| DROPTIME | date | YES | Time when the object was moved to the recycle bin |
| DROPSCN | bigint(0) | NO | This field is not supported. The default value is NULL. |
| PARTITION_NAME | varchar(128) | NO | This field is not supported. The default value is NULL. |
| CAN_UNDROP | varchar(3) | NO | Whether the object can be restored from the recycle bin:<ul><li>YES </li><li>NO </li></ul> |
| CAN_PURGE | varchar(3) | NO | Whether to clear the object: <ul><li>YES </li><li>NO </li></ul> |
| RELATED | bigint(0) | NO | This field is not supported. The default value is NULL. |
| BASE_OBJECT | bigint(0) | NO | This field is not supported. The default value is NULL. |
| PURGE_OBJECT | bigint(0) | NO | This field is not supported. The default value is NULL. |
| SPACE | bigint(0) | NO | This field is not supported. The default value is NULL. |

## Sample query

Query information about all recycle bin objects in the database.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RECYCLEBIN;
```
