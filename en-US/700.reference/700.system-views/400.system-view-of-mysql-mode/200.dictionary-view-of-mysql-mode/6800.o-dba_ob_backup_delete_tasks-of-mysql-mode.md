# oceanbase.DBA_OB_BACKUP_DELETE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the information about the `backup_set`/`backup_piece` cleanup tasks being executed in the current tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task group ID, used to identify a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, corresponding to the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li> BACKUP SET: specifies the `backup_set` cleanup task. </li><li>BACKUP PIECE: specifies the `backup_piece` cleanup task. </li></ul> |
| ID | bigint(20) | NO | The task ID, including backup_set and piece. |
| ROUND_ID | bigint(20) | NO | The dest_round_id of the piece. For the cleanup of a backup_set, the value of this column is 0. |
| DEST_ID | bigint(20) | NO | The DEST_ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the task. |
| END_TIMESTAMP | timestamp(6) | NO | The end time of the task. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`INIT`: the task is being initialized. </li><li>`DOING`: the task is being executed. </li><li>`CANCELING`: the task is being canceled. </li><li>`COMPLETED`: the task is executed successfully. </li><li>`FAILED`: the task fails. </li><li>`CANCELED`: the task is canceled successfully. </li></ul> |
| TOTAL_TASK_COUNT | bigint(20) | YES | The number of subtasks. <ul><li>In SN mode, this column indicates the number of all ls_task. </li><li>In SS mode, for a log archive piece, this column indicates the number of all ls_task. For a data backup set, this column indicates the number of all macro_task. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>For V4.6.x, this column is available starting with V4.6.0. </p></main> |
| FINISH_TASK_COUNT | bigint(20) | YES | The number of completed subtasks. <ul><li>In SN mode, this column indicates the number of completed ls_task. </li><li>In SS mode, for a log archive piece, this column indicates the number of completed ls_task. For a data backup set, this column indicates the number of completed macro_task. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>For V4.6.x, this column is available starting with V4.6.0. </p></main> |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set/backup_piece. |
