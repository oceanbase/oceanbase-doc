# oceanbase.DBA_SCHEDULER_WINDOWS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all scheduler windows in the current tenant.

## Columns

| Column          | Type          | Nullable | Description              |
|------------------|---------------|----------------|-------------------|
| OWNER            | varchar(128)  | NO   | The owner of the scheduler window    |
| WINDOW_NAME      | varchar(128)  | NO   | The name of the scheduler window  |
| RESOURCE_PLAN    | varchar(128)  | NO   | The resource plan associated with the window. This column is not currently used.   |
| SCHEDULE_OWNER   | varchar(4000) | NO   | The owner of the window's schedule. This column is not currently used.   |
| SCHEDULE_NAME    | varchar(4000) | NO   | The name of the window's schedule. This column is not currently used.   |
| SCHEDULE_TYPE    | varchar(8)    | NO   | The type of the window's schedule:<ul><li>ONCE: The repeat interval is NULL.</li><li>NAMED: A named schedule.</li><li>CALENDAR: A calendar expression used as a schedule.</li></ul></br>This column is not currently used. |
| START_DATE       | datetime(6)   | YES  | The start date of the window (for inline schedules)   |
| REPEAT_INTERVAL  | varchar(4000) | YES  | The repeat interval for the window|
| END_DATE         | datetime(6)   | YES  | The end date of the window   |
| DURATION         | bigint(20)    | YES  | The duration of the window    |
| WINDOW_PRIORITY  | varchar(4)    | NO   | The priority of the window relative to other windows:<ul><li>HIGH</li><li>LOW</li></ul> </br>This column is not currently used.|
| NEXT_RUN_DATE    | datetime(6)   | NO   | The next start date of the window   |
| LAST_START_DATE  | datetime(6)   | YES  | The last start date of the window   |
| ENABLED          | varchar(5)    | YES  | Indicates whether the window is enabled (TRUE) or disabled (FALSE)    |
| ACTIVE           | varchar(5)    | NO   | Indicates whether the window is open (TRUE) or closed (FALSE). This column is not currently used.      |
| MANUAL_OPEN_TIME | datetime(6)   | NO   | The time when the window was manually opened, or NULL if it was not manually opened. This column is not currently used.      |
| MANUAL_DURATION  | bigint(0)     | NO   | The duration of the manually opened window, or NULL if it was not manually opened. This column is not currently used.    |
| COMMENTS         | varchar(4000) | YES  | The description of the window   |

obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SCHEDULER_WINDOWS;
