# oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.4.1 for V4.4.x. </li>
<li>This view is available starting with V4.2.5 BP2 for V4.2.5. </li></ul>
</main>

## Purpose

The `DBA_OB_OBJECT_BALANCE_WEIGHT` view displays all partitions with special weights in the current user tenant.

## Columns

|       Column     |      Type    | Nullable |         Description                                 |
|-------------------|--------------|----------------|----------------------------------------------|
| TABLE_ID          | bigint(20)   | NO             | The ID of the table.     |
| PARTITION_ID      | bigint(20)   | NO             | The ID of the partition. If no weight is specified for the partition, the value is `NULL`.     |
| SUBPARTITION_ID   | bigint(20)   | NO             | The ID of the subpartition. If no weight is specified for the subpartition, the value is `NULL`. Currently, you cannot specify a weight for a subpartition.     |
| WEIGHT            | bigint(20)   | NO             | The weight of the partition.     |
| DATABASE_NAME     | varchar(128) | NO             | The name of the database to which the table belongs.     |
| TABLE_NAME        | varchar(256) | NO             | The name of the table.     |
| PARTITION_NAME    | varchar(64)  | NO             | The name of the partition.     |
| SUBPARTITION_NAME | varchar(64)  | NO             | The name of the subpartition.     |
| TABLEGROUP_NAME   | varchar(128) | NO             | The name of the table group to which the table belongs.     |
| DATABASE_ID       | bigint(20)   | NO             | The ID of the database to which the table belongs.     |
| TABLEGROUP_ID     | bigint(20)   | NO             | The ID of the table group to which the table belongs.     |
| OBJECT_ID         | bigint(20)   | NO             | The ID of the object to which the table belongs.     |

## Sample query

Query the partitions with special weights in the current user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
```
