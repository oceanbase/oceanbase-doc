# GV$OB_SHARED_STORAGE_QUOTA

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

This view displays IO access resource information on all OBServer nodes.

## Columns

| Column | Type | Nullable | Description |
|-------------|---------------|----------------|-------------------------------------------------------------|
| SVR_IP      | varchar(46)   | NO   | The IP address of the OBServer node.    |
| SVR_PORT    | bigint(20)    | NO   | The port number of the OBServer node.     |
| ENDPOINT    | varchar(256)  | NO   | The endpoint of the shared storage. In Shared-Nothing (SN) mode, this field is empty.     |
| PATH        | varchar(1024) | NO   | The path of the object storage. In SN mode, it displays as the local path.</br>Typical path types include: `local://`, `oss://`, `file://`, and `s3://`.   |
| CLASS_ID    | bigint(20)    | NO   | The ID for labeling. The meaning of this field varies based on the purpose of the object storage bucket:<ul><li>If the bucket is used for clog storage or data storage, this field is meaningless and its value is `0`.</li> <li>If the bucket is used for backup and restore, data import, and export tasks, this field represents the tenant ID.</li></ul>      |
| TYPE        | varchar(32)   | NO   | The type of the metric. Valid values: <ul><li>`IPS`: instructions per second</li> <li>`OPS`: operations per second</li> <li>`IOPS`: input/output operations per second</li> <li>`IBW`: input bandwidth</li> <li>`OBW`: output bandwidth</li> <li>`IOBW`: input/output bandwidth</li> <li>`TAG`: user-defined tags</li></ul>     |
| REQUIREMENT | bigint(20)    | NO   | The required resources for the server.    |
| ASSIGN      | bigint(20)    | NO   | The upper limit of the resources specified by the throttling algorithm.     |

## Sample query

In a user tenant, query the requested and limited quotas of object storage metrics on all OBServer nodes for scenarios such as clog storage and data storage. For scenarios such as backup and restore, data import, and export, query the requested and limited quotas of object storage metrics on all OBServer nodes for the tenant.

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SHARED_STORAGE_QUOTA;
```
