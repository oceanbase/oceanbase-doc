# V$OB_SS_LOCAL_CACHE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

This view displays the metrics of various types of cached data in the local cache of the current tenant on the current OBServer node in shared-storage (SS) mode.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view applies only to shared-storage (SS) mode. In shared-nothing (SN) mode, the query result of this view is empty. </p>
</main>

## Columns

|      Column    |         Type          | Nullable |                       Description      |
|----------------|-----------------------|----------------|---------------------------------|
| SVR_IP          | varchar(46)           | NO             |  The IP address of the OBServer node.    |
| SVR_PORT        | bigint(20)            | NO             |  The port number of the OBServer node.      |
| TENANT_ID       | bigint(20)            | NO             |  The tenant ID.                   |
| CACHE_NAME      | varchar(128)          | NO             |  The name of the cache for a type of data in the local cache. The following types of data are supported:<ul><li>`ss_micro_cache`: microblock cache</li> <li>`ss_local_cache_tmpfile`: temporary file cache</li> <li>`ss_local_cache_major_macro`: baseline macroblock cache</li></ul>    |
| PRIORITY        | bigint(20)            | NO             |  The cache priority. The higher the value, the higher the priority. This field is not used at present, and the default value is `0`     |
| HIT_RATIO       | decimal(38,3)         | NO             |  The cache hit ratio.                    |
| TOTAL_HIT_CNT   | bigint(20)            | NO             |  The total number of cache hits.               |
| TOTAL_MISS_CNT  | bigint(20)            | NO             |  The total number of cache misses.             |
| HOLD_SIZE       | bigint(20)            | NO             |  The total size of objects stored in the cache, in bytes.    |
| ALLOC_DISK_SIZE | bigint(20)            | NO             |  The allocated disk space, in bytes.    |
| USED_DISK_SIZE  | bigint(20)            | NO             |  The used disk space (the disk space may be allocated but not used). In bytes.    |
| USED_MEM_SIZE   | bigint(20)            | NO             |  The used memory space, in bytes.                |
