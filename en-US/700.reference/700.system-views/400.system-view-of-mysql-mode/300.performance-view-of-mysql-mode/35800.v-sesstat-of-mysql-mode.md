# V$SESSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the session-level statistics of the current tenant on the current OBServer node. In this view, `STATISTIC#` indicates the index of the statistic item. You can query the `V$STATNAME` view to obtain the name and description of the statistic item corresponding to the index.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> In all connection modes (direct mode and ODP mode), this column indicates the server session ID. </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This column indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this column indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this column indicates the server session ID. </li></ul></ul></li></ul> |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server where the information is stored. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the information is stored. |
| STATISTICS# | bigint(20) | NO | The index of the statistic item. |
| VALUE | bigint(20) | NO | The number of times the statistic item occurs. |

## Sample query

Query the session-level statistics of the current tenant on the current OBServer node in the user tenant, and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSTAT LIMIT 10;
```
