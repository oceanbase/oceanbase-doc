# GV$OB_JAVA_SANDBOX_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.2, this view is available starting from V4.4.2 BP4.</p>
</main>

## Overview

This view displays the Java UDF sandbox status of the current tenant across all OBServer nodes, including information such as the lifecycle of sandbox generations, communication channel pools, sandbox process resources, and sandbox JVM resources.

The usage instructions are as follows:

* When the parameter `ob_enable_java_udf_sandbox` is enabled, Java UDFs are executed in independent sandbox processes. Each row corresponds to a generation (Generation) sandbox, and each generation sandbox corresponds to a sandbox JVM process.
* This view only displays existing sandboxes. Querying this view does not trigger sandbox creation.
* `INSTANCE_COUNT` to `LAST_FORCE_KILL_REASON` are tenant-level summary information. The values for each column are the same across rows belonging to the same tenant.
* Metrics that have not been successfully collected or cannot be obtained are displayed as NULL, to distinguish them from metrics whose actual value is `0`.

## Sample query

Query the status and memory usage of Java UDF sandboxes for the current tenant across all OBServer nodes.

```shell
obclient> SELECT SVR_IP, TENANT_ID, GENERATION_ID, GENERATION_STATE, STATUS, PROCESS_PID, PROCESS_RSS_BYTES, HEAP_USED_BYTES, MONITOR_STATUS FROM oceanbase.GV$OB_JAVA_SANDBOX_STATUS;
```
