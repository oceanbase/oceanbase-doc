# V$OB_RPC_OUTGOING

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the statistics of RPC requests sent by the current tenant on the current OBServer node.

## Columns

|    **Column**    |    **Type**    | **Nullable** |        **Description**         |
|----------------|--------------|----------------|-----------------------|
| TENANT_ID      | bigint(20)   | NO             | The tenant ID.                 |
| SVR_IP         | varchar(46)  | NO             | The IP address of the server.              |
| SVR_PORT       | bigint(20)   | NO             | The port number of the server.                |
| PCODE          | bigint(20)   | NO             | The RPC packet code.       |
| PCODE_NAME     | varchar(256) | NO             | The name corresponding to the RPC packet code. |
| COUNT          | bigint(20)   | NO             | The number of times the RPC request is used.                  |
| TOTAL_TIME     | bigint(20)   | NO             | The total time spent, in microseconds.                |
| TOTAL_SIZE     | bigint(20)   | NO             | The total size of data sent, in bytes.            |
| FAILURE        | bigint(20)   | NO             | The number of failed sends.                |
| TIMEOUT        | bigint(20)   | NO             | The number of timeouts.                |
| SYNC           | bigint(20)   | NO             | The number of synchronous RPC requests.         |
| ASYNC          | bigint(20)   | NO             | The number of asynchronous RPC requests.         |
| LAST_TIMESTAMP | timestamp(6) | NO             | The last update time of the statistics.            |

## Sample query

obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RPC_OUTGOING LIMIT 10;
