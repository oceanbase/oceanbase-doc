# V$SQL_PLAN_MONITOR

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `V$SQL_PLAN_MONITOR` view displays operation-level statistics for slow queries on the current OBServer node in the current tenant. Each operation has one corresponding statistic.
