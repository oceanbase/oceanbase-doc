# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view was renamed to <a href="30900.v-ob_active_session_history-of-mysql-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> starting from V4.2.2. </li>
  <li>This view is available starting with V4.0.0. </li></ul>
</main>

## Purpose

This view displays the history of active sessions.

## Columns

| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the server to which the sample belongs. |
