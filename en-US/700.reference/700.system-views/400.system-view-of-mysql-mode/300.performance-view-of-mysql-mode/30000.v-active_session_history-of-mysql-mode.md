# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
    <ul><li>For V4.3.x versions, this view was renamed to <a href="30400.v-ob_active_session_history-of-mysql-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> starting from V4.3.5. For V4.2.x versions, this view was renamed to <a href="30400.v-ob_active_session_history-of-mysql-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> starting from V4.2.2. </li>
  <li>This view is available starting with V4.0.0. </li></ul>
</main>

## Purpose

The `V$ACTIVE_SESSION_HISTORY` view displays the active session history of the current OBServer node in the current tenant.
