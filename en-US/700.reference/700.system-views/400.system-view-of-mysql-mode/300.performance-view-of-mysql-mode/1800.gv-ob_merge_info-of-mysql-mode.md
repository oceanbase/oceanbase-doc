# GV$OB_MERGE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The view <code>GV$MERGE_INFO</code> was renamed to <code>GV$OB_MERGE_INFO</code> starting from OceanBase Database V4.0.0. In V4.0.0 and later, you must use the new view name <code>GV$OB_MERGE_INFO</code> to query the view. Otherwise, an error will be returned. </p>
</main>

## Purpose

This view displays the statistics of completed major compactions in the OceanBase cluster.

## Columns

|       Column        |      Type       | Nullable |                                 Description                                  |
|-------------------|---------------|------------|-----------------------------------------------------------------------------------------------------|
| SVR_IP            | varchar(46)   | NO         | The IP address of the server.                                                           |
| SVR_PORT          | bigint(20)    | NO         | The port number of the server.                                                              |
| TENANT_ID         | bigint(20)    | NO         | The ID of the tenant.                                                               |
| LS_ID             | bigint(20)    | NO         | The ID of the log stream.                                                              |
| TABLET_ID         | bigint(20)    | NO         | The ID of the data tablet.                                                             |
| ACTION            | varchar(64)   | NO         | The type of the major compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persist the system metadata in SSTable format to disk. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: minor compaction. Converts a MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Combines multiple Mini SSTables into a new Mini SSTable or combines multiple Mini SSTables with a Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of major compaction. Combines data before a specified time into a Meta Major SSTable. The data format is the same as that of a Major SSTable. The Meta Major SSTable does not contain multi-version data or uncommitted transaction data. </li></ul>   |
| COMPACTION_SCN    | bigint(20) unsigned    | NO         | The version number of the major compaction.                                                      |
| START_TIME        | timestamp(6)  | NO         | The start time of the major compaction.                                                     |
| END_TIME          | timestamp(6)  | NO         | The end time of the major compaction.                                                     |
| MACRO_BLOCK_COUNT | bigint(20)    | NO         | The total number of macro blocks in the major compaction.                                                     |
| REUSE_PCT         | decimal(26,2) | NO         | The reuse rate of macro blocks in the major compaction.                                                    |
| PARALLEL_DEGREE   | bigint(20)    | NO         | The parallelism of the major compaction.                                                      |

## Sample query

Query the statistics of completed minor compactions (`MINI_MERGE`) in the MySQL user tenant and return the first five records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MERGE_INFO WHERE ACTION='MINI_MERGE' LIMIT 5;
```
