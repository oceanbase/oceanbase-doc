# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_SQL_AUDIT` view displays the source, execution status, and other statistical information for each SQL request on the current OBServer node. This view is tenant-separated. Except for the sys tenant, other tenants cannot query across tenants.
