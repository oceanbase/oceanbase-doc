# GV$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V4.0.0. </p>
</main>

## Purpose

The `GV$ACTIVE_SESSION_HISTORY` view displays the active session history records of all OBServer nodes in the tenant.
