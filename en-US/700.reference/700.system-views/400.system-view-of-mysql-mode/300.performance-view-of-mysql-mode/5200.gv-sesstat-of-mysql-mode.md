# GV$SESSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays session-level statistical events for the current tenant across all OBServer nodes. Here, `STATISTIC#` indicates the statistical item number, which can be queried from the `V$STATNAME` view to obtain the corresponding statistical item name and its meaning.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | For V4.2.x: <ul><li> For versions earlier than V4.2.5 BP4: <br> In all connection modes (direct mode/ODP mode), this field represents the Server Session ID. </li><li> For V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field represents the Server Session ID. </li> <li> In ODP mode: </li><ul><li> If the configuration parameter <code>client_session_id_version = 2</code> is set in ODP, this field represents the Client Session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field represents the Server Session ID. </li></ul></ul></li></ul> |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP address of the server where the information is located |
| SVR_PORT | bigint(20) | NO | Port number of the server where the information is located |
| STATISTICS# | bigint(20) | NO | Index of the statistical event |
| VALUE | bigint(20) | NO | Number of times the statistical event occurred |

## Sample query

Query session-level statistical events for the current tenant across all OBServer nodes, and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSTAT LIMIT 10;
```
