# GV$OB_UNITS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the unit information of the OBServer node where the tenant is located. The system tenant can view the unit information of all OBServer nodes in the cluster.

## Columns

|       Column    |    Type      | Nullable |                           Description                                 |
|------------------|--------------|------------|-------------------------------------------------------------------------|
| SVR_IP           | varchar(46)  | NO         | The IP address of the server.                                                              |
| SVR_PORT         | bigint(20)   | NO         | The port number of the server.                                                                 |
| UNIT_ID          | bigint(20)   | NO         | The ID of the unit.                                                                |
| TENANT_ID        | bigint(20)   | NO         | The ID of the tenant to which the unit belongs.                                                          |
| ZONE             | varchar(128) | NO         | The name of the zone.                                                                |
| ZONE_TYPE | varchar(128) | NO | The type of the zone where the unit is located. Valid values: <ul><li>`NULL`: This value is invalid. This value is temporarily displayed when the OBServer node restarts. </li> <li>`ReadWrite`: Read/write zone</li> <li>`Encryption`: Encrypted zone</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| REGION | varchar(128) | NO | The name of the region to which the zone where the unit is located belongs. If this column is not set, the default value is `default_region`. If the value is `NULL`, this value is invalid. This value is temporarily displayed when the OBServer node restarts.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| MAX_CPU          | double       | NO         | The upper limit of the CPU specification.                                                               |
| MIN_CPU          | double       | NO         | The lower limit of the CPU specification.                                                               |
| MEMORY_SIZE       | bigint(20)   | NO         | The size of memory, in bytes.                                                           |
| MAX_IOPS         | bigint(20)   | NO         | The upper limit of the disk IOPS specification.                                                           |
| MIN_IOPS         | bigint(20)   | NO         | The lower limit of the disk IOPS specification.                                                           |
| IOPS_WEIGHT    | bigint(20)   | NO         | The IOPS weight. |
| LOG_DISK_SIZE  | bigint(20)   | NO         | The size of the log disk, in bytes.  |
| LOG_DISK_IN_USE | bigint(20)   | NO         | The size of the log disk that has been used, in bytes.                                                               |
| DATA_DISK_IN_USE | bigint(20)   | NO         | The size of the data disk that has been used, in bytes.                                                               |
| STATUS           | varchar(64)  | NO         | The status of the unit. Valid values: <li> `NORMAL`: Normal.   <li> `MIGRATING IN`: Migrating in.   <li> `MIGRATING OUT`: Migrating out.   <li> `MARK DELETING`: Marked for deletion. <li>`WAIT GC`: Waiting for garbage collection. <li>`DELETING`: Deleted after garbage collection. <li> `ERROR`: Error.  |
| CREATE_TIME      | timestamp(6) | NO         | The time when the unit is created on the OBServer node.                                                 |

## Sample query

Query the unit information of all OBServer nodes where the tenant is located.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_UNITS\G
```
