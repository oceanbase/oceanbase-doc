# GV$OB_MEMSTORE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The view <code>GV$SERVER_MEMSTORE</code> was renamed to <code>GV$OB_MEMSTORE</code> starting from V4.0.0. In V4.0.0 and later, you must use the new view name <code>GV$OB_MEMSTORE</code> to query. Using the old view name <code>GV$SERVER_MEMSTORE</code> will result in an error. </p>
</main>

## Purpose

This view displays the memory usage of MemTables for the current tenant on all servers.

## Columns

|    **Column**    |   **Type**    | **Nullable** |              **Description**              |
|----------------|-------------|----------------|----------------------------------|
| SVR_IP         | varchar(46) | NO             | The IP address of the server.                          |
| SVR_PORT       | bigint(20)  | NO             | The port number of the server.                            |
| TENANT_ID      | bigint(20)  | NO             | The tenant ID.                            |
| ACTIVE_SPAN    | bigint(20)  | NO             | The estimated memory usage of active MemTables (may be larger than the actual value), in bytes. |
| FREEZE_TRIGGER | bigint(20)  | NO             | The memory size at which MemTable freezing is triggered, in bytes.        |
| FREEZE_CNT     | bigint(20)  | NO             | The number of times MemTable has been frozen.                   |
| MEMSTORE_USED  | bigint(20)  | NO             | The total memory size currently used by MemTables, in bytes.        |
| MEMSTORE_LIMIT      | bigint(20)  | NO             | The memory size limit for MemTables, in bytes.           |

## Sample query

Query the memory usage of MemTables for the current tenant on all servers.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MEMSTORE;
```

The query result is as follows:

```shell
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| SVR_IP         | SVR_PORT | TENANT_ID | ACTIVE_SPAN | FREEZE_TRIGGER | FREEZE_CNT | MEMSTORE_USED | MEMSTORE_LIMIT |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| 172.xx.xxx.xxx |     2882 |      1002 |    62914560 |      603982068 |          0 |      62914560 |     2684354550 |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
1 row in set
```
