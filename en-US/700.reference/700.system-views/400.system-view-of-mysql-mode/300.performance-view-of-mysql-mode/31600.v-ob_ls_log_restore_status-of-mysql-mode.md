# V$OB_LS_LOG_RESTORE_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore status of the log stream at the tenant level.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| LS_ID | bigint(20) | NO | The log stream ID. |
| SYNC_LSN | bigint(20) unsigned | NO | The maximum LSN of the majority of the standby database or the maximum LSN that can be consumed. |
| SYNC_SCN | bigint(20) unsigned | NO | The maximum SCN of the majority of the standby database or the maximum SCN that can be consumed. |
| SYNC_STATUS | varchar(128) | NO | The restore status of the log stream. Valid values: <ul><li>NORMAL: The log stream is being synchronized normally.  </li><li>SOURCE HAS A GAP: The log source has gaps. </li><li>STANDBY LOG NOT MATCH: The log stream is being synchronized, but the logs on the standby database conflict with those on the log source. The logs on the standby database and the logs on the log source have the same LSN.  </li><li>CHECK USER OR PASSWORD: The username or password of the replication account is incorrect, and the log source cannot be accessed.  </li><li>CHECK NETWORK: The log source is unreachable. This may be due to an incorrect tenant access IP address or port.  </li><li>FETCH LOG TIMEOUT: The log fetch operation times out.  </li><li>RESTORE SUSPEND: The log restore has reached the maximum synchronization LSN that is set.  </li><li>STANDBY NEED UPGRADE: The standby database is running an earlier version than the primary database.  </li><li>CHECK PRIMARY ALIVE: The primary database cannot be accessed. Check whether the primary database has been deleted.  </li><li> NOT AVAILABLE: The log synchronization is unavailable due to other exceptions. </li></ul>|
| ERR_CODE | bigint(20) | NO | The error code. 0 indicates that the log stream is being synchronized normally. |
| COMMENT | varchar(2048) | NO | The error details. This column is empty when the log stream is being synchronized normally. |

## Sample query

Query the log restore status of the log stream at the tenant level for the user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_LS_LOG_RESTORE_STATUS;
```
