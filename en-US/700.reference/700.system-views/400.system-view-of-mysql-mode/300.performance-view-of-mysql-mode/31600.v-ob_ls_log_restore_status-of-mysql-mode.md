# V$OB_LS_LOG_RESTORE_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore status at the log stream level for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| LS_ID | bigint(20) | NO | The log stream ID. |
| SYNC_LSN | bigint(20) unsigned | NO | The LSN of the latest continuous majority in the standby database or the latest consumable LSN. |
| SYNC_SCN | bigint(20) unsigned | NO | The SCN of the latest continuous majority in the standby database or the latest consumable SCN. |
| SYNC_STATUS | varchar(128) | NO | The restore status of the log stream. Valid values: <ul><li>NORMAL: Normal synchronization.  </li><li>SOURCE HAS A GAP: The log source has a gap. </li><li>STANDBY LOG NOT MATCH: The logs in the standby database and the log source are inconsistent at the same LSN.  </li><li>CHECK USER OR PASSWORD: The username or password of the replication account is incorrect, and the log source cannot be accessed.  </li><li>CHECK NETWORK: The log source is unreachable. This may be due to an incorrect tenant access IP address or port.  </li><li>FETCH LOG TIMEOUT: Log fetching timed out.  </li><li>RESTORE SUSPEND: The log restore has reached the maximum synchronization LSN.  </li><li>STANDBY NEED UPGRADE: The standby database is outdated.  </li><li>CHECK PRIMARY ALIVE: The primary database cannot be accessed. Check whether the primary database has been deleted.  </li><li> NOT AVAILABLE: Other exceptions have caused the log synchronization to be unavailable. </li></ul>|
| ERR_CODE | bigint(20) | NO | The error code. 0 indicates normal synchronization. |
| COMMENT | varchar(2048) | NO | The error details. This column is empty during normal synchronization. |

## Sample query

Query the log restore status at the log stream level for the current user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_LS_LOG_RESTORE_STATUS;
```
