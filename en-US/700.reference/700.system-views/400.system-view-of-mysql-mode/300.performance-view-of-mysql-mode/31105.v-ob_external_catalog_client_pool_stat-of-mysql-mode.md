# V$OB_EXTERNAL_CATALOG_CLIENT_POOL_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For V4.6.x, this view is available starting with V4.6.0.</p>
</main>

## Overview

The `V$OB_EXTERNAL_CATALOG_CLIENT_POOL_STAT` view is used to obtain the catalog pooling information of the OBServer node that executed the SQL statement.

## Columns

| **Field** | **Type** | **Is NULL** | **Description** |
| ---------------- | --------------- | ----------------- | ---------- |
| SVR_IP | varchar(46) | NO | The IP address of the node where the replica is located. |
| SVR_PORT | bigint(20) | NO | The port of the node where the replica is located. |
| TENANT_ID | bigint(20) | NO | Tenant ID: <ul><li>1: the ID of the system tenant.</li><li>Other values: the ID of a user tenant or meta tenant.</li></ul> |
| CLIENT_TYPE | varchar(128) | NO | Client type. |
| CATALOG_ID | bigint(20) | NO | The ID of a catalog under the tenant. |
| URI | varchar(4096) | NO | The IP address of the server to which the client connects. |
| TOTAL_CLIENTS | bigint(20) | NO | `TENANT_ID`In the corresponding tenant, under the corresponding`CATALOG_ID`The total number of clients created by the catalog. |
| IN_USE_CLIENTS | bigint(20) | NO | `TENANT_ID`Under the corresponding tenant`CATALOG_ID`The number of clients currently using the catalog. |
| IDLE_CLIENTS | bigint(20) | NO | `TENANT_ID`In the corresponding tenant`CATALOG_ID`The number of idle clients in the catalog. |

## Sample query

Query the catalog pooling information of the OBServer node where this SQL statement is executed.

```shell
obclient> SELECT * FROM oceanbase.V$OB_EXTERNAL_CATALOG_CLIENT_POOL_STAT;
```

The query result is as follows:

```shell
+-------------+----------+-----------+-------------+------------+-------------------------------+---------------+----------------+--------------+
| SVR_IP      | SVR_PORT | TENANT_ID | CLIENT_TYPE | CATALOG_ID | URI                           | TOTAL_CLIENTS | IN_USE_CLIENTS | IDLE_CLIENTS |
+-------------+----------+-----------+-------------+------------+-------------------------------+---------------+----------------+--------------+
| xx.xx.xx.xx |    10203 |      1004 | rest        |     500005 | http://localhost:9001/iceberg |             1 |              0 |            1 |
+-------------+----------+-----------+-------------+------------+-------------------------------+---------------+----------------+--------------+
1 row in set
```
