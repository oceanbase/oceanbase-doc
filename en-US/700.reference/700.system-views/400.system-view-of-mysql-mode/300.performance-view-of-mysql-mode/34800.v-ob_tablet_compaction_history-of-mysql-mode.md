# V$OB_TABLET_COMPACTION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_TABLET_COMPACTION_HISTORY` view displays the history of tablet-level compactions.

## Columns

|   Column     |      Type      | **Nullable** |   Description     |
|--------------------------------------|--------------|----------------|--------|
|SVR_IP    |varchar(46)    |NO   |Server IP address    |
|SVR_PORT    |bigint(20)    |NO   |Server port number    |

Converts the MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: Minor compaction. Combines multiple Mini SSTables into a new Mini SSTable or combines multiple Mini SSTables with one Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: A special type of compaction. Combines data before a specified time point into a Meta Major SSTable. The data format is the same as that of a Major SSTable, and it does not contain multi-version data or uncommitted transaction data. </li></ul>    |

Valid values: <ul><li>`BUILD_COLUMN_STORE_MERGE`</li> <li>`BUILD_ROW_STORE_MERGE`</li> <li>`USE_RS_BUILD_SCHEMA_MATCH_MERGE`</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.3. </p></main> |

## Sample query

Query the tablet-level compaction history on the current OBServer node of the user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.V$OB_TABLET_COMPACTION_HISTORY LIMIT 1\G
```
