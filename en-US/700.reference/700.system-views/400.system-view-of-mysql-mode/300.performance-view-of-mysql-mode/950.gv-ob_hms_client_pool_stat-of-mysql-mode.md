# GV$OB_HMS_CLIENT_POOL_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

This view displays the usage of HMS Catalog clients for the current tenant.

## Columns

|     Column    |     Type    | Nullable |      Description      |
|----------------|-------------|----------------|----------------|
| SVR_IP         | varchar(46) | NO             | The IP address of the node where the replica is located.|
| SVR_PORT       | bigint(20)  | NO             | The port of the node where the replica is located.|
| TENANT_ID      | bigint(20)  | NO             | The ID of the tenant. Valid values: <ul><li>1: the ID of the sys tenant. </li><li>Other values: the ID of the user tenant or the Meta tenant.</li></ul>|
| CATALOG_ID     | bigint(20)  | NO             | The ID of a catalog under the current tenant.|
| TOTAL_CLIENTS  | bigint(20)  | NO             | The total number of clients created for the corresponding catalog under the current tenant.|
| IN_USE_CLIENTS | bigint(20)  | NO             | The number of clients being used for the corresponding catalog under the current tenant.|
| IDLE_CLIENTS   | bigint(20)  | NO             | The number of clients not being used (idle) for the corresponding catalog under the current tenant.|

## Sample query

obclient> SELECT * FROM oceanbase.GV$OB_HMS_CLIENT_POOL_STAT;
