# V$OB_THREAD

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the status information of all threads in the observer process on the current OBServer node. For user tenants, it also displays the relevant threads of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the observer process. |
| SVR_PORT | bigint(20) | NO | The port number of the observer process. |
| TENANT_ID | bigint(20) | NO | The ID of the tenant to which the thread belongs. For process-level threads, this value is 500. |
| TID | bigint(20) | NO | The thread ID. |
| TNAME | varchar(16) | NO | The name of the thread. |
| STATUS | varchar(32) | NO | The status of the thread. Valid values: <ul><li> Run: The thread is running.  </li><li> Wait: The thread is waiting. </li><li> Sleep: The thread is sleeping. </li><li> Join: The thread is waiting for another thread to end. </li></ul>|
| LATCH_WAIT | varchar(16) | NO | The address of the latch that the thread is waiting for. |
| LATCH_HOLD | varchar(256) | NO | The address of the latch that the thread is holding. This field may contain multiple values. |
| TRACE_ID | varchar(40) | NO | The ID of the trace being executed by the thread. |
| CGROUP_PATH | varchar(256) | NO  | The path of the cgroup to which the thread belongs. This field is obtained from the CPU line in the `/proc/observer-pid/task/tid/cgroup` path.  |

## Sample query

For a user tenant, query the status information of all threads in the observer process on the current OBServer node and display the first two records.

```shell
obclient > SELECT * FROM oceanbase.V$OB_THREAD LIMIT 2;
```
