# GV$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_SQL_AUDIT` view displays the statistics of each SQL request on all OBServer nodes, including the source and execution status. This view is tenant-separated. You can query only the statistics of the current tenant. You cannot query the statistics of other tenants.
