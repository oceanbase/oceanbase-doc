# V$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

In a MySQL-compatible tenant, the `V$OB_KV_GROUP_COMMIT_STATUS` view can access the group commit status information of the OBKV tenant client connection on the current node.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the node where the group commit group is located. |
| SVR_PORT | bigint(20) | NO | The port number of the node where the group commit group is located. |
| TENANT_ID | bigint(20) | NO | The tenant ID:<ul><li>1: the ID of the system tenant </li><li>Other values: the ID of a user tenant or a Meta tenant</li></ul> |
| TABLE_ID | bigint(20) | NO | The ID of the table to which the group commit group belongs. |
| LS_ID | bigint(20) | NO | The ID of the LS to which the group commit group belongs. |
| SCHEMA_VERSION | bigint(20) | NO | The schema version of the table to which the group commit group belongs. |
| GROUP_TYPE | varchar(32) | NO | The type of the group commit group. The supported types are as follows:<ul><li>get: the get request queue </li><li>put: the put request queue </li><li>del: the delete request queue </li><li>replace: the replace request queue </li><li>insert: the insert request queue </li><li>hybird: the hybrid operation request queue </li><li>fail: the queue for failed batch operations </li></ul>  |
| QUEUE_SIZE | bigint(20) | NO | The size of the request queue in the group commit group, representing the number of unprocessed requests. |
| BATCH_SIZE | bigint(20) | NO | The size of the batch in the group commit group. |
| CREATE_TIME | timestamp(6) | NO  | The time when the group was created in the group commit.  |
| UPDATE_TIME | timestamp(6) | NO  | The time when the status information of the group was refreshed in the group commit.  |

## Sample query

Query the group commit status information of the OBKV tenant client connection on the current node and display the records of the first day.

```shell
obclient > SELECT * FROM oceanbase.V$OB_KV_GROUP_COMMIT_STATUS limit 1;
```
