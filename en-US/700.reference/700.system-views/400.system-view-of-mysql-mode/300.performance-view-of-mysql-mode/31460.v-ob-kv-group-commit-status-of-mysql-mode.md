# V$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in MySQL 4.3.4. </p>
</main>

## Purpose

In a MySQL tenant, the `V$OB_KV_GROUP_COMMIT_STATUS` view can be used to query the group commit status of the current node in the OBKV tenant where the client is connected.

## Columns

| **Column** | **Type** | **Nullable?** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the node where the group commit group resides. |
| SVR_PORT | bigint(20) | NO | The port number of the node where the group commit group resides. |
| TENANT_ID | bigint(20) | NO | The tenant ID: <li> 1: the ID of the system tenant <li> Other values: the ID of a user tenant or meta tenant |
| TABLE_ID | bigint(20) | NO | The ID of the table to which the group commit group belongs. |
| LS_ID | bigint(20) | NO | The ID of the ls to which the group commit group belongs. |
| SCHEMA_VERSION | bigint(20) | NO | The schema version of the table to which the group commit group belongs. |
| GROUP_TYPE | varchar(32) | NO | The type of the group commit group. Valid values: <ul><li> get: the get request queue <li> put: the put request queue <li> del: the delete request queue <li> replace: the replace request queue <li> insert: the insert request queue <li> hybrid: the hybrid operation request queue <li> fail: the queue of batch operations that failed to execute </li></ul>  |
| QUEUE_SIZE | bigint(20) | NO | The size of the request queue in the group commit group, which indicates the number of unprocessed requests. |
| BATCH_SIZE | bigint(20) | NO | The size of the batch in the group commit group. |
| CREATE_TIME | timestamp(6) | NO  | The time when the group commit group was created.  |
| UPDATE_TIME | timestamp(6) | NO  | The time when the status information of the group commit group was last refreshed.  |

## Sample query

```shell
obclient > SELECT * FROM oceanbase.V$OB_KV_GROUP_COMMIT_STATUS limit 1;
```
