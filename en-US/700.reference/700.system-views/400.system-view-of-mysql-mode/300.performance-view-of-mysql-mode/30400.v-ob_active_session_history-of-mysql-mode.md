# V$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.3.x versions, this view is available starting with V4.3.5. </li> <li>For V4.2.x versions, this view is available starting with V4.2.2. </li></ul>
</main>

## Purpose

The `V$OB_ACTIVE_SESSION_HISTORY` view displays the active session history of the current OBServer node in the current tenant.

## Columns
