# V$OB_RPC_OUTGOING

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the RPC sending statistics for the current tenant on the current OBServer node.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | -------------- | ---------------- | ----------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| PCODE | bigint(20) | NO | RPC Packet Code |
| PCODE_NAME | varchar(256) | NO | Name Corresponding to RPC Packet Code |
| COUNT | bigint(20) | NO | Number of RPCs Sent |
| TOTAL_TIME | bigint(20) | NO | Total Time Spent, in Microseconds |
| TOTAL_SIZE | bigint(20) | NO | Total data sent, in bytes |
| FAILURE | bigint(20) | NO | Number of Sending Failures |
| TIMEOUT | bigint(20) | NO | Number of Send Timeout |
| SYNC | bigint(20) | NO | Number of Synchronous Waiting RPC Requests |
| ASYNC | bigint(20) | NO | Number of Asynchronous Callback RPC Requests |
| LAST_TIMESTAMP | timestamp(6) | NO | Last Update Statistics Time |

## Sample query

In the user tenant, view the RPC requests sent by this tenant from the current node, displaying the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RPC_OUTGOING LIMIT 10;
```
