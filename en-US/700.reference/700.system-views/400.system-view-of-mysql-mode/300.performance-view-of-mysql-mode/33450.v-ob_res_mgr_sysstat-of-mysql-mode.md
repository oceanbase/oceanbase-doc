# V$OB_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <ul><li>For V4.3.x, this view is available starting with V4.3.5. </li> <li>For V4.2.x, this view is available starting with V4.2.5. </li></ul>
</main>

## Purpose

The `V$OB_RES_MGR_SYSSTAT` view displays the statistics of resource groups in the current OBServer node of the current tenant.

## Columns

| **Column** | **Type**  | **Nullable** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| CON_ID     | bigint(20)  | NO   | The tenant ID.     |
| GROUP_ID   | bigint(20)  | NO   | The ID of the resource group to which the resource group belongs.     |
| SVR_IP     | varchar(46) | NO   | The IP address of the node.     |
| SVR_PORT   | bigint(20)  | NO   | The port number of the node.    |
| STATISTIC# | bigint(20)  | NO   | The serial number of the statistic.     |
| NAME       | varchar(64) | NO   | The name of the statistic.    |
| CLASS      | bigint(20)  | NO   | The category of the statistic.     |
| VALUE      | bigint(20)  | NO   | The value of the statistic.     |
| VALUE_TYPE | varchar(16) | NO   | The value type: incremental or assigned.     |
| STAT_ID    | bigint(20)  | NO   | The ID of the statistic.     |

## Sample query

Query the statistics of resource groups in the current OBServer node of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RES_MGR_SYSSTAT LIMIT 10;
```
