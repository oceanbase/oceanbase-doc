# V$OB_COMPACTION_DIAGNOSE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the diagnostic information of the current node about major compactions.

## Columns

|     Column      |      Type       | Nullable |                                            Description                                            |
|---------------|---------------|------------|----------|
| SVR_IP        | varchar(46)   | NO         | The IP address of the server.                                                                                |
| SVR_PORT      | bigint(20)    | NO         | The port number of the server.|
| TENANT_ID     | bigint(20)    | NO         | The tenant ID. |
| TYPE          | varchar(64)   | NO         | The type of the compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: The metadata of the system is persisted to the disk in the SSTable format. </li> <li>`MAJOR_MERGE`: The major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: The major compaction at the partition level. </li> <li>`MINI_MERGE`: The minor compaction. The MemTable is converted to a Mini SSTable. </li> <li>`MINOR_MERGE`: The minor compaction. Multiple Mini SSTables are combined into a new Mini SSTable. A Mini SSTable and multiple Minor SSTables are combined into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: The meta major compaction. The data before a specified time point is combined into a Meta Major SSTable. The data format is the same as that of a Major SSTable. The Meta Major SSTable does not contain multi-version data and uncommitted transaction data. </li></ul>   |
| LS_ID         | bigint(20)    | NO         | The log stream ID.|
| TABLET_ID     | bigint(20)    | NO         | The data tablet ID.                                                                                  |
| STATUS        | varchar(15)   | NO         | The task status.  |
| CREATE_TIME | timestamp(6) | NO         | The creation time.  |
| DIAGNOSE_INFO | varchar(1024) | NO         | The diagnostic information.  |
