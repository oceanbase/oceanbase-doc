# V$OB_SESSION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `V$OB_SESSION` view records session information created in the current server.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| ID | bigint(20) unsigned | NO |  For V4.3.x versions:<ul><li> For versions earlier than V4.3.5 BP2:<br>This column indicates the server session ID in all connection modes (direct mode and ODP mode). </li><li> For V4.3.5 BP2 and later versions:<ul><li> In direct mode:<br>This column indicates the server session ID. </li> <li> In ODP mode:</li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this column indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this column indicates the server session ID. </li></ul></ul></li></ul>   |
| USER | varchar(32) | NO |  Indicates the user to which the session belongs. |
| TENANT | varchar(128) | NO |  Indicates the name of the tenant being accessed.   |
| HOST | varchar(128) | NO | Indicates the IP address and port number of the client that initiated the session. If the database is connected through ODP, this column indicates the IP address and port number of the ODP.   |
| DB | varchar(128) | NO | Indicates the name of the database to which the session is currently connected.   |
| COMMAND | varchar(4096) | NO | Indicates the command being executed by the session.  |
| SQL_ID | varchar(32) | NO |  Indicates the SQL ID.   |
| TIME | bigint(21) | NO | Indicates the time when the current command is executed, in seconds. If the command is retried, this column is reset to zero.   |
| STATE | varchar(128) | NO | Indicates the current state of the session.   |
| INFO | varchar(262143) | NO | Indicates the statement being executed by the session.   |
| SVR_IP | varchar(46) | NO |  Indicates the IP address of the server. |
| SVR_PORT | bigint(20) | NO |  Indicates the RPC port number of the server.   |
| SQL_PORT | bigint(20) | NO |  Indicates the SQL port number of the server.   |
| PROXY_SESSID | bigint(20) unsigned | NO | If the current client is ODP, this column indicates the session ID of the ODP.   |
| USER_CLIENT_IP | varchar(46) | NO |  Indicates the IP address of the user client.   |
| USER_HOST | varchar(128) | NO |  Indicates the host name of the user client.   |
| TRANS_ID | bigint(20) unsigned | NO |  Indicates the transaction ID.   |
| THREAD_ID | bigint(20) unsigned | NO |  Indicates the thread ID.   |
| TRACE_ID | varchar(64) | NO |  Indicates the trace ID.   |
| REF_COUNT | bigint(20) | NO | Indicates the connection reference count. |
| BACKTRACE | varchar(16384) | NO | Indicates the connection reference call stack. |
| TRANS_STATE | varchar(32) | NO |  Indicates the transaction state (empty if no transaction exists on the session):<ul><li>`IDLE`: idle state, indicating that the transaction has not started. </li> <li>`ACTIVE`: the transaction is explicitly started. It is explicitly started by using statements such as `START TRANSACTION` and `BEGIN`. </li> <li>`IMPLICIT_ACTIVE`: the transaction is implicitly started. In `autocommit = on` mode, the transaction is started after a DML statement is executed. </li> <li>`ROLLBACK_SAVEPOINT`: the transaction is being rolled back to a savepoint. </li> <li>`IN_TERMINATE`: the transaction is being ended, including internal reasons and user-initiated transaction end (for example, by executing `COMMIT` or `ROLLBACK` statements). </li> <li>`ABORTED`: the transaction is internally aborted or rolled back due to an exception. </li> <li>`ROLLED_BACK`: the transaction has been rolled back. </li> <li>`COMMIT_TIMEOUT`: the transaction commit times out. </li> <li>`COMMIT_UNKNOWN`: the transaction commit result is unknown. </li> <li>`COMMITTED`: the transaction has been successfully committed. </li></ul>    |
| USER_CLIENT_PORT | bigint(20)          | NO   | Indicates the port number of the user client <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.x versions, this column is available starting with V4.4.0. </p></main>  |
| TOTAL_CPU_TIME | bigint(21) | NO | Indicates the CPU time used to execute the current command, in seconds. |

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_SESSION limit 1\G
```
