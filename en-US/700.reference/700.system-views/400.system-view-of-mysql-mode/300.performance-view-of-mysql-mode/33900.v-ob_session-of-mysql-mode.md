# V$OB_SESSION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `V$OB_SESSION` view records session information created in the current server.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| ID | bigint(20) unsigned | NO |  For V4.3.x versions:<ul><li> V4.3.5 BP2 and earlier versions:<br>This column represents the server session ID in all connection modes (direct mode and ODP mode). </li><li> V4.3.5 BP2 and later versions:<ul><li> In direct mode:<br>This column represents the server session ID. </li> <li> In ODP mode:</li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this column represents the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this column represents the server session ID. </li></ul></ul></li></ul>   |
| USER | varchar(32) | NO |  The user to which the session belongs. |
| TENANT | varchar(128) | NO |  The name of the tenant being accessed.   |
| HOST | varchar(128) | NO | The IP address and port number of the client that initiated the session. If the database is connected through ODP, this column represents the IP address and port number of ODP.   |
| DB | varchar(128) | NO | The name of the database to which the session is currently connected.   |
| COMMAND | varchar(4096) | NO | The command being executed by the session.  |
| SQL_ID | varchar(32) | NO |  The SQL ID.   |
| TIME | bigint(21) | NO | The time in seconds when the current command is executed. If the command is retried, this column is reset to zero and recalculated.   |
| STATE | varchar(128) | NO | The current state of the session.   |
| INFO | varchar(262143) | NO | The statement being executed by the session.   |
| SVR_IP | varchar(46) | NO |  The IP address of the server. |
| SVR_PORT | bigint(20) | NO |  The RPC port number of the server.   |
| SQL_PORT | bigint(20) | NO |  The SQL port number of the server.   |
| PROXY_SESSID | bigint(20) unsigned | NO | If the current client is ODP, this column displays the session ID of ODP.   |
| USER_CLIENT_IP | varchar(46) | NO |  The IP address of the user client.   |
| USER_HOST | varchar(128) | NO |  The hostname of the user client.   |
| TRANS_ID | bigint(20) unsigned | NO |  The transaction ID.   |
| THREAD_ID | bigint(20) unsigned | NO |  The thread ID.   |
| TRACE_ID | varchar(64) | NO |  The trace ID.   |
| REF_COUNT | bigint(20) | NO | The connection reference count. |
| BACKTRACE | varchar(16384) | NO | The connection reference call stack. |
| TRANS_STATE | varchar(32) | NO |  The transaction state. If no transaction is associated with the session, this column is empty:<ul><li>`IDLE`: The transaction is idle, indicating that the transaction has not started. </li> <li>`ACTIVE`: The transaction is explicitly started. It is started by using statements such as `START TRANSACTION` and `BEGIN`. </li> <li>`IMPLICIT_ACTIVE`: The transaction is implicitly started. In `autocommit = on` mode, the transaction is started after a DML statement that modifies data is executed. </li> <li>`ROLLBACK_SAVEPOINT`: The transaction is being rolled back to a savepoint. </li> <li>`IN_TERMINATE`: The transaction is being terminated. The termination can be caused by internal reasons or initiated by the user (for example, by executing `COMMIT` or `ROLLBACK` statements). </li> <li>`ABORTED`: The transaction is internally terminated or rolled back due to an exception. </li> <li>`ROLLED_BACK`: The transaction has been rolled back. </li> <li>`COMMIT_TIMEOUT`: The transaction commit times out. </li> <li>`COMMIT_UNKNOWN`: The transaction commit result is unknown. </li> <li>`COMMITTED`: The transaction has been successfully committed. </li></ul>    |
| USER_CLIENT_PORT | bigint(20)          | NO   | The port number of the user client <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.x versions, this column is available starting with V4.4.0. </p></main>  |
| TOTAL_CPU_TIME | bigint(21) | NO | The CPU usage time in seconds for the current command. |

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_SESSION limit 1\G
```
