# GV$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the progress of Tablet-level compactions for the current tenant on all nodes.

## Columns

|             Column             |      Type      | Nullable |                                            Description                                            |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | The IP address of the server.                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | The port number of the server.|
| TENANT_ID                    | bigint(20)   | NO         | The tenant ID. |
| TYPE                         | varchar(64)  | NO         | The type of compaction:<ul><li>`MDS_TABLE_MERGE`: Persist the system metadata in the SSTable format to disk. </li> <li>`MAJOR_MERGE`: Tenant-level compaction. </li> <li>`MEDIUM_MERGE`: Partition-level compaction. </li> <li>`MINI_MERGE`: Mini compaction. Converts a MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: Minor compaction. Combines multiple Mini SSTables into a new Mini SSTable or combines multiple Mini SSTables with a Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: A special type of compaction. Combines data from before a specified time point into a Meta Major SSTable. The data format is the same as that of a Major SSTable, and it does not contain multi-version data or uncommitted transaction data. </li> </ul>    |
| LS_ID                        | bigint(20)   | NO         | The log stream ID.|
| TABLET_ID                    | bigint(20)   | NO         | The data tablet ID.                                                                                  |
| COMPACTION_SCN                      | bigint(20) unsigned   | NO         | The compaction version information.|
| TASK_ID                      | varchar(64)  | NO         | The trace of the executed task.                                                                                |
| STATUS                       | varchar(15)  | NO         | The task status.  |
| DATA_SIZE                    | bigint(20)   | NO         | The total data volume to be compacted, in bytes. |
| UNFINISHED_DATA_SIZE         | bigint(20)   | NO         | The data volume that has not been compacted, in bytes.    |
| PROGRESSIVE_COMPACTION_ROUND | bigint(20)   | NO         | The number of progressive compaction rounds.|
| CREATE_TIME                  | timestamp(6) | NO         | The time when the task was created.|
| START_TIME                   | timestamp(6) | NO         | The start time.  |
| ESTIMATED_FINISH_TIME        | timestamp(6) | NO         | The estimated completion time.|
| START_CG_ID                  | bigint(20)   | NO         | The start ID of the column group. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.0. </p></main>  |
| END_CG_ID                    | bigint(20)   | NO         | The end ID of the column group. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.0. </p></main>   |
