# GV$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in MySQL 4.0.0. </p>
</main>

## Description

Displays the progress of major compactions at the tablet level.

## Field descriptions

|             Field              |      Type      | Nullable | Description |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | The IP address of the server.                                                                                |

| TENANT_ID                    | bigint(20)   | NO         | The tenant ID. |
| TYPE                         | varchar(64)  | NO         | The type of compaction: <ul><li>`MDS_TABLE_MERGE`: the system metadata is persisted to the disk in the SSTable format. </li> <li>`MAJOR_MERGE`: a major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: a major compaction at the partition level. </li> <li>`MINI_MERGE`: a minor compaction, which converts MemTables into a Mini SSTable. </li> <li>`MINOR_MERGE`: a minor compaction, which merges multiple Mini SSTables into a new one or a minor compaction, which merges a few Mini SSTables and a minor SSTable into a new one. </li> <li>`META_MAJOR_MERGE`: a special type of compaction that synthesizes data existing before a specified time point into a Meta Major SSTable.
