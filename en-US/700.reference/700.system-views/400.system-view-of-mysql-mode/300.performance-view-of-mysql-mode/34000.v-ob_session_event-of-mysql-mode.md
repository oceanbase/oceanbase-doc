# V$SESSION_EVENT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `V$SESSION_EVENT` view displays the waiting events of each session.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ------ | ------ | ------ | ------- |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server. |
| SVR_PORT | bigint(20) | NO | The port number of the server. |
| SID | bigint(20) | NO | For V4.3.x: <ul><li> V4.3.5 BP2 and earlier: <br> In all connection modes (direct mode/ODP mode), this field indicates the server session ID. </li><li> V4.3.5 BP2 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the configuration parameter <code>client_session_id_version = 2</code> is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code> is set, this field indicates the server session ID. </li></ul></ul></li></ul>  |
| EVENT | varchar(64) | NO | The description of the waiting event. |
| TOTAL_WAITS | bigint(20) | NO | The total number of waits for the waiting event. |
| TOTAL_TIMEOUTS | bigint(20) | NO | The total number of timeouts for the waiting event. |
| TIME_WAITED | double | NO | The total waiting time of the waiting event, in hundredths of a second. |
| AVERAGE_WAIT | double | NO | The average waiting time of the waiting event, in hundredths of a second. |
| MAX_WAIT | double | NO | The maximum waiting time of the waiting event, in hundredths of a second. |
| TIME_WAITED_MICRO | bigint(20) | NO | The total waiting time of the waiting event, in microseconds.  |
| CPU | null | NO | An invalid column. |
| EVENT_ID | bigint(20) | NO | The ID of the waiting event. |
| WAIT_CLASS_ID | bigint(20) | NO | The ID of the type to which the waiting event belongs. |
| WAIT_CLASS# | bigint(20) | NO | The index of the type to which the waiting event belongs. |
| WAIT_CLASS | varchar(64) | NO | The name of the type to which the waiting event belongs. |

## Sample query

Query the waiting events of each session.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSION_EVENT LIMIT 1\G
```
