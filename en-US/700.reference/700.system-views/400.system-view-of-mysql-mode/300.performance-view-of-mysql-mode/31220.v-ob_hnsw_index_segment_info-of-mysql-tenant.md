# V$OB_HNSW_INDEX_SEGMENT_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

This view displays the basic information and real-time status of each data segment (Segment) in the single partition of HNSW index tables for all tenants on the current OBServer node.

## Columns

|             Column          |      Data type    | Nullable |            Description                                            |  Information type |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | The IP address of the node where the replica resides.                                              | Basic information |
| SVR_PORT                     | bigint(20)   | NO             | The RPC_PORT of the node where the replica resides.                                              | Basic information |
| TENANT_ID                    | bigint(20)   | NO             | The tenant ID<ul><li>1: the ID of the system tenant</li> <li>Other values: the ID of a user tenant or a meta tenant</li></ul>                                                    | Basic information |
| DATA_TABLE_ID                | bigint(20)   | NO             | The ID of the data table.                                                    | Basic information |
| DATA_TABLET_ID               | bigint(20)   | NO             | The ID of the partition.                                                    | Basic information |
| VBITMAP_TABLET_ID             | bigint(20)   | NO             | The ID of the partition corresponding to the auxiliary table (index_id).         | Basic information |
| INC_INDEX_TABLET_ID           | bigint(20)   | NO             | The ID of the partition of the delta_buffer table that stores incremental data.        | Basic information |
| SNAPSHOT_INDEX_TABLET_ID      | bigint(20)   | NO             | The ID of the partition of the index_snapshot_data table that stores data snapshots. | Basic information |
| BLOCK_COUNT                   | bigint(20)   | NO             | The number of data blocks in the snapshot Segment in the index_snapshot_data table. | Basic information |
| SEGMENT_TYPE                  | varchar(20)  | NO             | The type of the Segment:<ul><li>INVALID: default or uninitialized</li> <li>IN_MEMORY: a non-persisted Segment, that is, a Segment that exists only in memory</li> <li>PERSISTED_INCR: a persisted Segment, that is, a Segment that has been persisted to disk</li> <li>MERGED_INCR: an incremental Segment that has been merged</li> <li>PERSISTED_BASE: a persisted baseline Segment</li></ul> | Basic information |
| INDEX_TYPE                    | varchar(20)  | NO             | The type of the vector index:<ul><li>HNSW</li> <li>HNSW_SQ</li> <li>HNSW_BQ</li> <li>HGRAPH</li></ul> | Basic information |
| MEM_USED                      | bigint(20)   | NO             | The size of memory occupied by the current Segment (in bytes).           | Basic information |
| MIN_VID                       | bigint(20)   | NO             | The minimum vector ID (vid) in the Segment.           | Basic information |
| MAX_VID                       | bigint(20)   | NO             | The maximum vector ID (vid) in the Segment.           | Basic information |
| VECTOR_CNT                    | bigint(20)   | NO             | The number of vectors (data) in the Segment.                 | Basic information |
| REF_CNT                       | bigint(20)   | NO             | The reference count of the Segment. Usually, it represents the number of times the Segment is referenced by an index or a query. | Basic information |
| SEGMENT_STATE                 | varchar(20)  | NO             | The state of the current Segment:<ul><li>DEFAULT: uninitialized or default state</li> <li>ACTIVE: an active Segment that is being written to</li> <li>FROZEN: a frozen Segment that has stopped writing</li> <li>FLUSHING: a Segment that is being persisted to disk</li> <li>PERSISTED: a persisted Segment that is available for queries</li></ul> | Basic information |
| PERSISTENCE_TIMESTAMP         | timestamp    | NO             | The timestamp when the Segment is persisted (converted from the SCN of the Segment). | Basic information |

## Sample query

Query the real-time status of HNSW vector indexes for all tenants on the current OBServer node.

```sql
SELECT * FROM oceanbase.V$OB_HNSW_INDEX_SEGMENT_INFO ORDER BY PERSISTENCE_TIME DESC\G;
```
