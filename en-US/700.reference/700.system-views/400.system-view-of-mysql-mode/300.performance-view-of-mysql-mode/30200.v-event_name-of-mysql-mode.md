# V$EVENT_NAME

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the definitions of all wait events in the current tenant.

## Columns

|   **Column**    |   **Type**    | **Nullable** |    **Description**    |
|---------------|-------------|----------------|--------------|
| CON_ID        | bigint(20)  | NO             | The tenant ID.       |
| EVENT_ID      | bigint(20)  | NO             | The ID of the wait event.     |
| EVENT#        | bigint(20)  | NO             | The index of the wait event.      |
| NAME          | varchar(64) | NO             | The name of the wait event.      |
| DISPLAY_NAME  | varchar(64) | NO             | The alias of the wait event.      |
| PARAMETER1    | varchar(64) | NO             | The first parameter of the wait event.    |
| PARAMETER2    | varchar(64) | NO             | The second parameter of the wait event.    |
| PARAMETER3    | varchar(64) | NO             | The third parameter of the wait event.    |
| WAIT_CLASS_ID | bigint(20)  | NO             | The ID of the wait class to which the wait event belongs. |
| WAIT_CALSS#   | bigint(20)  | NO             | The index of the wait class to which the wait event belongs.  |
| WAIT_CLASS    | varchar(64) | NO             | The name of the wait class to which the wait event belongs.  |

## Sample query

Query the definitions of all wait events in the current tenant and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$EVENT_NAME limit 10;
```
