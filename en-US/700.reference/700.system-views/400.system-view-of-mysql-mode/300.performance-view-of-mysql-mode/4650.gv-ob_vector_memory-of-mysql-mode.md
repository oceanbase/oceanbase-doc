# GV$OB_VECTOR_MEMORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view is available starting with V4.4.1. </li></ul>
</main>

## Purpose

This view displays detailed statistics about the memory usage of vector index data for the current tenant across all OBServer nodes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)          | NO   |  The tenant ID:<ul><li>1: the system tenant ID.  </li><li>Other values: the ID of a user tenant or a Meta tenant. </li></ul>   |
| SVR_IP            | varchar(46)         | NO   |  The IP address of the node.   |
| SVR_PORT          | bigint(20)          | NO   |  The port number of the node.   |
| VECTOR_MEM_HOLD   | bigint(20)          | NO   |  The size of memory occupied by vector index data, in bytes.   |
| VECTOR_MEM_LIMIT  | bigint(20)          | NO   |  The maximum size of memory allocated to vector index data, in bytes.   |
| VECTOR_MEM_USED   | bigint(20)          | NO   |  The size of memory actually used by vector index data, in bytes.   |

## Sample query

Query the detailed statistics about the memory usage of vector index data for the current tenant across all OBServer nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_VECTOR_MEMORY  \G
```

The query result is as follows:

```shell
*************************** 1. row ***************************

              svr_port: 46002
             tenant_id: 1004
       vector_mem_hold: 82231296
       vector_mem_used: 77876328

1 row in set
```
