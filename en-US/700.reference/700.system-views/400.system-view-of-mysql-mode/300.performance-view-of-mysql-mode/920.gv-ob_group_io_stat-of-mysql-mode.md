# GV$OB_GROUP_IO_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in OceanBase Database V4.3.3. </p>
</main>

## Purpose

The view displays the real-time status of each resource group on all OBServer nodes of the current tenant.

## Columns

|             Column              |      Type    | Nullable? |            Description                                            |
|------------------------------|--------------|----------------|------------------------------------------------------------|
| TENANT_ID                    | bigint(20)   | NO             | ID of the tenant.                                            |
| SVR_IP                       | varchar(46)  | NO             | IP address of the server.                                    |
| SVR_PORT                     | bigint(20)   | NO             | Port number of the server.                                   |
| GROUP_ID                     | bigint(20)   | NO             | ID of the resource group.                                    |
| GROUP_NAME                   | varchar(128) | NO             | Name of the resource group.                                  |
| MODE                         | varchar(128) | NO             | Read/write mode, which can be either `READ` or `WRITE`.     |
| MIN_IOPS                     | bigint(20)   | NO             | Minimum IOPS of the resource group.                          |
| MAX_IOPS                     | bigint(20)   | NO             | Maximum IOPS of the resource group.                          |
| REAL_IOPS                    | bigint(20)   | NO             | Current IOPS.                                               |
| MAX_NET_BANDWIDTH            | bigint(20)   | NO             | Maximum network bandwidth of the resource group, in bytes.     |
| MAX_NET_BANDWIDTH_DISPLAY    | varchar(128) | NO             | Maximum network bandwidth of the resource group after the format is converted, in the format of 10 GB/s or 10 MB/s.     |
| REAL_NET_BANDWIDTH           | bigint(20)   | NO             | Current network bandwidth, in bytes.    |
| REAL_NET_BANDWIDTH_DISPLAY   | varchar(128) | NO             | Current network bandwidth after the format is converted, in the format of 10 GB/s or 10 MB/s.     |

## Sample query

The following example shows how to query the real-time status of each resource group on all OBServer nodes of the current tenant for a user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_GROUP_IO_STAT LIMIT 1;
```

The query result is as follows:

```shell

+-----------+----------------+----------+----------+-------------+------+----------+----------+-----------+-------------------+---------------------------+--------------------+----------------------------+
|      1002 | 172.xx.xxx.xxx |     2882 |        0 | OTHER_GROUP | READ |      307 |    20000 |         0 |          50000000 | 47.684MB/s                |                  0 | 0B/s                       |

1 row in set
```
