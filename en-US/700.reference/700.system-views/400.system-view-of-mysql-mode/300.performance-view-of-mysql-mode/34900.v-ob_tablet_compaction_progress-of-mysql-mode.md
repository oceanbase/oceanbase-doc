# V$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the progress of tablet-level compactions for the current tenant on the current node.

## Columns

|             Column             |      Type      | Nullable |                                            Description                                            |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | The IP address of the server.                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | The port number of the server.|
| TENANT_ID                    | bigint(20)   | NO         | The tenant ID. |
| TYPE                         | varchar(64)  | NO         | The type of compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persists the system metadata in the SSTable format to the disk.</li> <li>`MAJOR_MERGE`: tenant-level compaction</li> <li>`MEDIUM_MERGE`: partition-level compaction</li> <li>`MINI_MERGE`: Mini Compaction, which converts a MemTable to a Mini SSTable.</li> <li>`MINOR_MERGE`: Minor Compaction, which synthesizes multiple Mini SSTables into a new Mini SSTable or synthesizes multiple Mini SSTables with one Minor SSTable into a new Minor SSTable.</li> <li>`META_MAJOR_MERGE`: a special type of compaction. This type of compaction synthesizes data before a specified time point into a Meta Major SSTable. The data format of the Meta Major SSTable is the same as that of a Major SSTable. The Meta Major SSTable does not contain multi-version data or uncommitted transaction data. </li></ul>    |
| TABLE_ID                     | bigint(20)   | NO         | The ID of the primary table. |
| LS_ID                        | bigint(20)   | NO         | The ID of the log stream.|
| TABLET_ID                    | bigint(20)   | NO         | The ID of the data tablet.                                                                                  |
| COMPACTION_SCN                      | bigint(20) unsigned   | NO         | The compaction version.|
| TASK_ID                      | varchar(64)  | NO         | The trace of the executed task.                                                                                |
| STATUS                       | varchar(15)  | NO         | The task status.  |
| DATA_SIZE                    | bigint(20)   | NO         | The total data size to be compacted, in bytes. |
| UNFINISHED_DATA_SIZE         | bigint(20)   | NO         | The data size that has not been compacted, in bytes. |
| PROGRESSIVE_COMPACTION_ROUND | bigint(20)   | NO         | The number of progressive compaction rounds.|
| CREATE_TIME                  | timestamp(6) | NO         | The time when the task was created.|
| START_TIME                   | timestamp(6) | NO         | The start time.  |
| ESTIMATED_FINISH_TIME        | timestamp(6) | NO         | The estimated time when the task will be completed.|
| START_CG_ID                  | bigint(20)   | NO         | The start ID of the column group.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.0. </p></main>  |
| END_CG_ID                    | bigint(20)   | NO         | The end ID of the column group.<main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.0. </p></main>   |

obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TABLET_COMPACTION_PROGRESS WHERE TYPE='MAJOR_MERGE'\G
