# V$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Available as of V4.0.0.
</main>

## Features

Displays the progress information of tablet-level compaction.

## Field description

|             Field name             |      Type      | Nullable? |                                            Description                                            |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | The IP address of the server.                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | The port number of the server. |
| TENANT_ID                    | bigint(20)   | NO         | The tenant ID. |
| TYPE                         | varchar(64)  | NO         | The type of compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persists the system metadata to disk in the format of an SSTable. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: mini compaction. It converts the MemTables into Mini SSTables. </li> <li>`MINOR_MERGE`: minor compaction. It combines multiple Mini SSTables into one or combines multiple Mini SSTables and one Minor SSTable into one. </li> <li>`META_MAJOR_MERGE`: a special type of compaction. It synthesizes data created before a specified point in time into one Meta Major SSTable. The data format of this table is the same as that of a Major SSTable, but it does not contain multi-version data or uncommitted transaction data. </li></ul>    |
| TABLE_ID                     | bigint(20)   | NO         | The ID of the primary table. |
