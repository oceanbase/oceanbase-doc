# V$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in MySQL 4.0.0. </p>
</main>

## Description

Displays the progress of major compactions at the tablet level.

## Field descriptions

|             Field              |      Type      | Nullable | Description |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | The IP address of the server.                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | The port number of the server. |
| TENANT_ID                    | bigint(20)   | NO         | The ID of the tenant. |
| TYPE                         | varchar(64)  | NO         | The type of compaction. Valid values are: <ul><li>`MDS_TABLE_MERGE`: the system metadata is persisted to disk in the SSTable format. </li> <li>`MAJOR_MERGE`: a major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: a major compaction at the partition level. </li> <li>`MINI_MERGE`: a minor compaction that converts MemTables into a SSTable. </li> <li>`MINOR_MERGE`: a minor compaction that merges multiple SSTables. </li> <li>`META_MAJOR_MERGE`: a special type of compaction that synthesizes data from the start time to a specified point in time into a Meta Major SSTable. The data format of this SSTable is the same as that of a Major SSTable, but it does not contain multi-version data or uncommitted transactions. </li></ul>     |
