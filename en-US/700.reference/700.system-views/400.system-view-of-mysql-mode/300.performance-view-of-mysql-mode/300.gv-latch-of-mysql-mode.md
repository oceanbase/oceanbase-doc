# GV$LATCH

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view no longer records data due to feature adjustments. You can query the <a href="../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/5700.gv-system_event-of-mysql-mode.md">GV$SYSTEM_EVENT</a> view and <a href="../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/400.gv-ob_active_session_history-of-mysql-mode.md">GV$OB_ACTIVE_SESSION_HISTORY</a> view for lock diagnostic data. </p>
</main>

## Purpose

This view displays the latch information of all OBServer nodes in the cluster.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address. |
| SVR_PORT | bigint(20) | NO | The port number. |
| ADDR | varchar(256) | NO | This column is currently NULL. |
| LATCH# | bigint(20) | NO | The index of the latch class to which the latch belongs. |
| LEVEL# | bigint(20) | NO | The index of the latch level to which the latch belongs. |
| NAME | varchar(256) | NO | The name of the latch. |
| HASH | bigint(20) | NO | This column is currently 0. |
| GETS | bigint(20) | NO | The number of times the lock is successfully acquired. |
| MISSES | bigint(20) | NO | The number of times the lock enters the waiting state. |
| SLEEPS | bigint(20) | NO | The total number of times the thread yields. |
| IMMEDIATE_GETS | bigint(20) | NO | The number of times try_lock is successfully acquired. |
| IMMEDIATE_MISSES | bigint(20) | NO | The number of times try_lock fails. |
| SPIN_GETS | bigint(20) | NO | The total number of spins. |
| WAIT_TIME | bigint(20) | NO | The total waiting time for sleep. |
