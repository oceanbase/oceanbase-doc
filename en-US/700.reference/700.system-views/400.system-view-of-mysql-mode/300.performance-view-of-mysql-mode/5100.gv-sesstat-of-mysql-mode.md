# GV$SESSTAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `GV$SESSTAT` view displays session-level statistics on all OBServer nodes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | For V4.3.x: <ul><li> V4.3.5 BP2 and earlier: <br> In all connection modes (direct mode/ODP mode), this column indicates the server session ID. </li><li> V4.3.5 BP2 and later: <ul><li> In direct mode: <br> This column indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> When the <code>client_session_id_version = 2</code> parameter is set in ODP, this column indicates the client session ID. </li> <li> When <code>client_session_id_version = 1</code>, this column indicates the server session ID. </li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server where the information is located. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the information is located. |
| STATISTICS# | bigint(20) | NO | The index of the statistics. |
| VALUE | bigint(20) | NO | The number of times the statistics event occurred. |

## Sample query

Query session-level statistics on all OBServer nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSTAT LIMIT 1\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
       SID: 1152921504606863376
    CON_ID: 1002
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
