# GV$DML_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the DML information of user tables in the current tenant on all OBServer nodes.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the server. |
| SVR_PORT | bigint(20) | NO | The port number of the server. |
| INST_ID | bigint(20) | NO | The tenant ID. |
| OBJN | bigint(20) | NO | The object ID. |
| INS | bigint(20) | NO | The approximate number of insertions since the last statistics collection. |
| UPD | bigint(20) | NO | The approximate number of updates since the last statistics collection. |
| DEL | bigint(20) | NO | The approximate number of deletions since the last statistics collection. |
| DROPSEG | bigint(0) | NO | This column is not supported and is currently set to NULL by default. |
| CURROWS | bigint(0) | NO | This column is not supported and is currently set to NULL by default. |
| PAROBJN | bigint(20) | NO | This column is not supported and is currently set to NULL by default. |
| LASTUSED | bigint(0) | NO | This column is not supported and is currently set to NULL by default. |
| FLAGS | bigint(0) | NO | This column is not supported and is currently set to NULL by default. |
| CON_ID | bigint(0) | NO | This column is not supported and is currently set to NULL by default. |

## Sample query

obclient [oceanbase]> SELECT * FROM oceanbase.GV$DML_STATS;
