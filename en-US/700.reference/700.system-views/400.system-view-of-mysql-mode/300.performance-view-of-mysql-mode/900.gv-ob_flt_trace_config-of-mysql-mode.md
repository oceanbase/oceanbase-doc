# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the diagnostic information of full-link tracing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. Other values: the user tenant ID or the Meta tenant ID. |
| TYPE | varchar(16) | NO | The monitoring level of the diagnostic information.  </li><li>Module/action level: diagnostic information is monitored at the module and action levels. </li><li>Client identifier level: diagnostic information is monitored at the client identifier level. </li></ul> |
| TENANT_NAME | varchar(128) | NO | The tenant name. |
| MODULE_NAME | varchar(4096) | NO | The module name. |
| ACTION_NAME | varchar(4096) | NO | The action name. |
| CLIENT_IDENTIFIER | varchar(65) | NO | The client identifier name. |
| LEVEL | bigint(20) | NO | The monitoring level of full-link tracing for the session. For example, 1 indicates the diagnostic information of level 1. |
| SAMPLE_PERCENTAGE | bigint(20) | NO | The sampling frequency of full-link tracing for the session. For example, 50 indicates that diagnostic information is sampled with a 50% probability. |
| RECORD_POLICY | varchar(32) | NO | The recording policy of full-link tracing for the session. The following three policies are supported: <ul><li>ALL: All trace points of the trace that are sampled and enabled are printed to the log file. The trace points are printed to the log file at the end of each span. </li><li>ONLY_SLOW_QUERY: Only the trace points of the trace that are sampled and enabled and belong to slow queries are printed to the log file. Other trace points are discarded. For this printing policy, the trace log is printed only after the request is determined to be a slow query. In the Proxy, the root span, which is at the transaction level, is printed only when a slow query is detected. </li><li>SAMPLE_AND_SLOW_QUERY: The trace points of the trace that are sampled and enabled and meet the following conditions are printed to the log file: <ol><li>When the hidden parameter <code>_print_sample_ppm</code> is used for sampling at a 0.01% probability, the trace point is printed to the log file only when the sampling result is selected. </li><li>The trace point meets the printing conditions of the ONLY_SLOW_QUERY mode. </li></ol> For this mode, the trace log is not printed at the end of the span. If condition 1 is met, the trace log is forcibly printed at the client and the information is passed to the subsequent link components. If condition 2 is met, the printing timing is the same as that of the ONLY_SLOW_QUERY mode. </li></ul> |
