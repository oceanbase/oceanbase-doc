# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays diagnostic information of full-link tracing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. Other values: the ID of a user tenant or a Meta tenant. |
| TYPE | varchar(16) | NO | The monitoring level of the diagnostic information.  </li><li>Module/action level: diagnostic information is monitored at the module and action levels. </li><li>Client identifier level: diagnostic information is monitored at the client identifier level. </li></ul> |
| TENANT_NAME | varchar(128) | NO | The tenant name. |
| MODULE_NAME | varchar(4096) | NO | The module name. |
| ACTION_NAME | varchar(4096) | NO | The action name. |
| CLIENT_IDENTIFIER | varchar(65) | NO | The client identifier name. |
| LEVEL | bigint(20) | NO | The monitoring level of full-link tracing for the session. For example, 1 indicates diagnostic information of level 1. |
| SAMPLE_PERCENTAGE | bigint(20) | NO | The sampling frequency of full-link tracing for the session. For example, 50 indicates that diagnostic information is sampled with a 50% probability. |
| RECORD_POLICY | varchar(32) | NO | The recording strategy of full-link tracing for the session. The following three strategies are supported:<ul><li>ALL: all trace points that are sampled and enabled for tracing are printed to the log file. The trace points are printed to the log file at the end of each span.  </li><li>ONLY_SLOW_QUERY: only trace points that are sampled and enabled for tracing and belong to slow queries are printed to the log file. Other trace points are discarded. For this strategy, trace logs are printed to the log file only after a request is determined to be a slow query. In the Proxy, for the root span, which is at the transaction level, the root span is printed only when a slow query is detected.  </li><li>SAMPLE_AND_SLOW_QUERY: trace points that are sampled and enabled for tracing are printed to the log file if they meet the following conditions:<ol><li>When the hidden parameter <code>_print_sample_ppm</code> is used for sampling at a 0.01% probability, the trace point is printed to the log file only if the sampling result is selected. </li><li>The trace point meets the conditions for printing under the ONLY_SLOW_QUERY mode. </li></ol>For this strategy, trace logs are not printed at the end of a span. If condition 1 is met, the trace log is forcibly printed at the client and the information is passed to subsequent components in the chain. If condition 2 is met, the trace log is printed at the same time as in the ONLY_SLOW_QUERY mode. </li></ul> |
