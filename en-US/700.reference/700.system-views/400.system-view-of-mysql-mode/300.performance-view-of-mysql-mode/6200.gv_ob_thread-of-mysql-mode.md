# GV$OB_THREAD

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the status information of all threads in the observer process on each OBServer node. For user tenants, it shows the relevant threads of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the observer process. |
| SVR_PORT | bigint(20) | NO | The port number of the observer process. |
| TENANT_ID | bigint(20) | NO | The tenant ID to which the thread belongs. For process-level threads, the value is 500. |
| TID | bigint(20) | NO | The thread ID. |
| TNAME | varchar(16) | NO | The thread name. |
| STATUS | varchar(32) | NO | The thread status: <ul><li> Run indicates that the thread is running.  </li><li> Wait indicates that the thread is waiting. </li><li> Sleep indicates that the thread is sleeping. </li><li> Join indicates that the thread is waiting for another thread to end. </li></ul>|
| LATCH_WAIT | varchar(16) | NO | The address being waited for by the latch. |
| LATCH_HOLD | varchar(256) | NO | The address holding the latch (may contain multiple addresses). |
| TRACE_ID | varchar(40) | NO | The ID of the trace being executed on the thread. |
| CGROUP_PATH | varchar(256) | NO  | The path of the cgroup to which the thread belongs. This field information is obtained from the CPU line under the `/proc/observer-pid/task/tid/cgroup` path.  |

## Sample query

For a user tenant, query the status information of all threads in the observer process on each OBServer node and display the first two records.

```shell
obclient > SELECT * FROM oceanbase.GV$OB_THREAD LIMIT 2;
```
