# oceanbase.DBA_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the association between tables and table groups in the current tenant. Tables not in a table group are not displayed.

## Columns

|      Column       |      Type      | Nullable |      Description       |
|-----------------|--------------|------------|---------------|
| TABLEGROUP_NAME | varchar(128) | NO         | The name of the table group.           |
| OWNER           | varchar(128) | NO         | The name of the database to which the table belongs. |
| TABLE_NAME      | varchar(256) | NO         | The name of the table.       |
| SHARDING        | varchar(20)   | NO         | The SHARDING attribute of the table group. Valid values: <ul><li>`NONE`: All partitions of all tables in the table group are aggregated on the same server. No restrictions are imposed on tables added to the table group.</li> <li>`PARTITION`: Data of each table in the table group is scattered by partition. If the table is a subpartitioned table, all subpartitions under each partition are aggregated together.</li> <li>`ADAPTIVE`: Data of each table in the table group is scattered based on the adaptive method. If the table is a partitioned table, data is scattered by partition. If the table is a subpartitioned table, data is scattered by subpartition under each partition.</li></ul>    |

## Sample query

In the sys tenant, query the association between tables and the `tblgroup1` table group.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'tblgroup1';
```

The query result is as follows:

```shell
+-----------------+-----------+------------+----------+
| TABLEGROUP_NAME | OWNER     | TABLE_NAME | SHARDING |
+-----------------+-----------+------------+----------+
| tblgroup1       | infotest  | tbl1       | ADAPTIVE |
+-----------------+-----------+------------+----------+
1 row in set
```
