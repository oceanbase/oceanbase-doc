# oceanbase.DBA_OB_BACKUP_VALIDATE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_BACKUP_VALIDATE_TASKS` view displays information about backup validation tasks initiated by the current tenant. Each task corresponds to a backup set or log archive piece validation task.

## Columns

| Column | Type | Nullable | Description |
| ----------------- | ------------- | -------------- | -------------- |
| TASK_ID | bigint(20) | NO | The task ID. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The job ID. |
| TASK_TYPE | varchar(64) | NO | The type of the validation task. Valid values: <ul><li>`BACKUPSET`: validates a specified backup set. </li> <li>`ARCHIVELOG_PIECE`: validates a specified log archive piece. </li></ul>       |
| ID | bigint(20) | YES | The `backup_set_id` of the validated backup set or the `piece_id` of the validated log archive piece.       |
| PATH | longtext | YES | The backup path or log archive path to be validated.      |
| PATH_TYPE | varchar(64) | YES | The type of the path to be validated. Valid values: <ul><li>`BACKUP_SET_DEST`: the data backup path. </li> <li>`ARCHIVELOG_PIECE_DEST`: the log archive path. </li></ul>    |
| DEST_ID | bigint(20) | YES | The ID of the validated backup path or log archive path.   |
| PLUS_ARCHIVELOG | varchar(64) | NO | Indicates whether to include compensating logs.     |
| INITIATOR_TASK_ID | bigint(20) | NO | The parent task ID of the compensating log validation task. 0 if this column is not applicable.     |
| VALIDATE_LEVEL | varchar(64) | NO | The validation level. Valid values: <ul><li>`basic`: checks only the completeness of the file list. </li> <li>`physical`: checks the correctness and logical consistency of the physical data. </li></ul>      |
| ROUND_ID | bigint(20) | NO | The round ID of the log archive piece to be validated. 0 if this column is not applicable. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the validation task.     |
| END_TIMESTAMP | timestamp(6) | NO | The end time of the validation task.     |
| STATUS | varchar(64) | NO | The status of the task. Valid values: <ul><li>`INIT`: the validation task is being initialized. </li> <li>`DOING`: the validation task is being executed. </li> <li>`COMPLETED`: the validation task has been completed. </li> <li>`FAILED`: the validation task has failed. </li> <li>`CANCELED`: the validation task has been canceled. </li></ul>       |
| TOTAL_LS_COUNT | bigint(20) | YES | The number of log streams in the task.     |
| FINISH_LS_COUNT | bigint(20) | YES | The number of log streams that have been validated.     |
| TOTAL_BYTES | bigint(20) | YES | The estimated size of data to be validated, in bytes.     |
| VALIDATED_BYTES | bigint(20) | YES | The size of data that has been validated, in bytes.     |
| RESULT | bigint(20) | NO | The error code of the validation result.     |
| COMMENT | varchar(4096) | YES | The reason for the failure of the validation task.      |
