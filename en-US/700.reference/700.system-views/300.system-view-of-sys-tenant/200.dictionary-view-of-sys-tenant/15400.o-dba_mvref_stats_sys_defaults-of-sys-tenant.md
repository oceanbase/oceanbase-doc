# oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `DBA_MVREF_STATS_SYS_DEFAULTS` view displays the system-wide default values for the statistics attributes of the history of materialized view refreshes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(16) | NO | The name of the parameter. Valid values: <ul><li>COLLECTION_LEVEL: the level of detail for data collection.</li><li>RETENTION_PERIOD: the period for which data is retained.</li></ul>|
| VALUE | varchar(40) | NO | The system-wide default value of the parameter. |

## Sample query

Query the system-wide default values for the statistics attributes of the history of materialized view refreshes.

```shell
obclient [test_db]> SELECT * FROM oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS;
```

The query result is as follows:

```shell
+------------------+---------+
| PARAMETER_NAME   | VALUE   |
+------------------+---------+
| COLLECTION_LEVEL | TYPICAL |
| RETENTION_PERIOD | 31      |
+------------------+---------+
2 rows in set (0.007 sec)
```
