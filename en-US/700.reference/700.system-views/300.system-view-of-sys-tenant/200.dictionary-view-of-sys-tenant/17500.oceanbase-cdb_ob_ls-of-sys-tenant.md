# oceanbase.CDB_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in V4.0.0. </p>
</main>

## Description

This view displays the status and restore progress of all log streams of all tenants.

## Columns

| Column name   | Type                | NULL | Description               |
|---------------|---------------------|------|--------------------|
| TENANT_ID     | bigint(20)          | NO | Tenant ID |
| LS_ID         | bigint(20)          | NO | Log stream ID |
| STATUS        | varchar(100)        | NO | The status of the log stream. Valid values: <li>`CREATING`: The log stream is being created. <li>`CREATED`: The log stream has been created. <li>`NORMAL`: The log stream is available for service. <li>`DROPPING`: The log stream is to be deleted. The tablets on the log stream need to be migrated. <li>`TENANT DROPPING`: The tenant to which the log stream belongs is to be deleted. The log stream needs to be deleted. <li>`WAIT OFFLINE`: The data of the log stream has been deleted. It is waiting for garbage collection. <li>`CREATE ABORT`: The log stream creation failed or is no longer needed. The log stream is to be deleted. |
| PRIMARY_ZONE  | longtext            | YES| The primary zone of the log stream. |
| UNIT_GROUP_ID | bigint(20)          | NO | Unit group ID |
| LS_GROUP_ID   | bigint(20)          | NO | Log stream group ID |
| CREATE_SCN    | bigint(20) unsigned | NO | The SCN where the log stream starts writing logs. |
| DROP_SCN      | bigint(20) unsigned | NO | The SCN where the log stream is to be deleted. It is also the SCN where all user data ends. |
| SYNC_SCN      | bigint(20) unsigned | NO | The synchronization SCN of the log stream. |
| READABLE_SCN  | bigint(20) unsigned | NO | The readable SCN of the log stream. |
| FLAG          | varchar(2048)       | NO | The log stream flag. The following values are supported: <ul><li>None: The log stream is normal. </li><li>DUPLICATE: The log stream is a broadcast log stream of a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: Tablets cannot be created on the log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: A broadcast log stream does not support tablet creation. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field was introduced in V4.2.0. </p></main>  |
