# oceanbase.CDB_TAB_COLS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays column information of tables and views of all tenants. This view is consistent with the `CDB_TAB_COLS_V$` view, except that it does not contain the `NOTES` column, which is not currently used.

## Columns

|         Column         |       Type        | Nullable |                                                               Description                                                                |
|----------------------|-----------------|------------|---------------|
| CON_ID               | bigint(20)      | NO         | Tenant ID                                        |
| OWNER                | varchar(128)    | NO         | The owner of the table, view, or cluster.                                  |

| AVG_COL_LEN          | bigint(21)      | NO         | The average length of the column, in bytes.                               |

| CHAR_USED            | varchar(1)      | NO         | Indicates the length semantics used for the column: `BYTE` (`B`) or `CHAR` (`C`). If the column is not of the following data types, the value is `NULL`: <ul><li>`CHAR`   </li><li> `VARCHAR2`   </li><li> `NCHAR`   </li><li> `NVARCHAR2`   </li></ul>   |
| V80_FMT_IMAGE        | varchar(3)      | NO         | Default value is `NULL`   |
| DATA_UPGRADED        | varchar(3)      | NO         | Default value is `NULL`         |
| HIDDEN_COLUMN        | varchar(3)      | NO         | Indicates whether the column is a hidden column ( `YES`) or not ( `NO`)              |
| VIRTUAL_COLUMN       | varchar(3)      | NO         | Indicates whether the column is a virtual column ( `YES`) or not ( `NO`)               |
| SEGMENT_COLUMN_ID    | bigint(0)       | NO         | Default value is `NULL`                                       |
| INTERNAL_COLUMN_ID   | bigint(0)       | NO         | Default value is `NULL`                                      |
| HISTOGRAM            | varchar(15)     | NO         | Indicates the existence or type of histogram: <ul><li>`NONE`   </li><li> `FREQUENCY`   </li><li> `TOP-FREQUENCY`   </li><li> `HEIGHT BALANCED`   </li><li> `HYBRID` </li></ul>   |
| QUALIFIED_COL_NAME   | text            | NO         | The qualified column name                                         |
| USER_GENERATED       | varchar(3)      | NO         | Indicates the generation attribute of the column. Valid values: <ul><li>`YES`: Indicates that the column is a user-generated column. </li><li>`NO`: Indicates that the column is a system-generated column, that is, a column that is logically deleted but not deleted at the storage layer. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP1. </p></main>|
| DEFAULT_ON_NULL      | varchar(3)      | NO         | Default value is `NULL`                                          |
| IDENTITY_COLUMN      | varchar(3)      | NO         | Default value is `NULL`              |
| EVALUATION_EDITION   | varchar(128)    | NO         | Default value is `NULL`                        |
| UNUSABLE_BEFORE      | varchar(128)    | NO         | Default value is `NULL`                       |
| UNUSABLE_BEGINNING   | varchar(128)    | NO         | Default value is `NULL`             |
| COLLATION            | varchar(100)    | NO         | Default value is `NULL`                       |
| COLLATED_COLUMN_ID   | bigint(0)       | NO         | Default value is `NULL`                |
