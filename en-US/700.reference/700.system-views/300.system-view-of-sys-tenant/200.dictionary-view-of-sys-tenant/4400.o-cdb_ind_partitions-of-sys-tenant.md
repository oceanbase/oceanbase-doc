# oceanbase.CDB_IND_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the partition information of the primary partition of the index table for all tenants.

## Columns

|          Column           |       Type        | Nullable |                                                                        Description                                                                         |
|-------------------------|-----------------|------------|-------|
| CON_ID                  | bigint(20)      | NO         | The tenant ID.                                                          |
| INDEX_OWNER             | varchar(128)    | NO         | The owner of the index.                                                       |
| TABLE_NAME              | varchar(128)    | NO         | The name of the table to which the index belongs. |
| INDEX_NAME              | varchar(128)    | NO         | The name of the index.                                                           |
| COMPOSITE               | varchar(3)      | NO         | Indicates whether the partition is a local index of a composite-partitioned table:<ul><li>YES</li><li>NO</li></ul>   |

| SUBPARTITION_COUNT      | bigint(20)      | NO         | The number of subpartitions.                                                          |
