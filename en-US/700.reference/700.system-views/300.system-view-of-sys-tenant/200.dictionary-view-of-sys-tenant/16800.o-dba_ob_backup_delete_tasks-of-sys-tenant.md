# oceanbase.DBA_OB_BACKUP_DELETE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the information about `backup_set`/`backup_piece` cleanup tasks that are being executed in the current tenant. The `sys` tenant and the Meta tenant do not support backup cleanup.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task group ID, which identifies a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, which corresponds to the ID in the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li> BACKUP SET: specifies the `backup_set` cleanup task. </li><li>BACKUP PIECE: specifies the `backup_piece` cleanup task. </li></ul> |
| ID | bigint(20) | NO | The task ID, which includes backup_set and piece. |
| ROUND_ID | bigint(20) | NO | The destination round ID of the piece. For a `backup_set` cleanup task, the ROUND_ID is 0. |
| DEST_ID | bigint(20) | NO | The destination ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The time when the task started. |
| END_TIMESTAMP | timestamp(6) | NO | The time when the task ended. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`INIT`: the task is being initialized. </li><li>`DOING`: the task is being executed. </li><li>`CANCELING`: the task is being canceled. </li><li>`COMPLETED`: the task is executed successfully. </li><li>`FAILED`: the task failed. </li><li>`CANCELED`: the task is canceled. </li></ul> |
| TOTAL_LS_COUNT | bigint(20) | YES | The number of log streams in the task. |
| FINISH_LS_COUNT | bigint(20) | YES | The number of log stream tasks that are executed successfully. |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set or backup_piece. |
