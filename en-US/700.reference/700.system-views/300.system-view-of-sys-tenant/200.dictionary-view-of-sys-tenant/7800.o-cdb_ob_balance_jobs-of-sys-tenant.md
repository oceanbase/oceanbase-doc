# oceanbase.CDB_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing jobs that are being executed for all tenants. Each tenant can have only one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks (TASK) to perform the specific operations of load balancing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or the ID of the Meta tenant. </li></ul>|
| JOB_ID | bigint(20) | NO | The ID of the load balancing job. |
| CREATE_TIME | timestamp(6) | NO | The creation time. |
| MODIFY_TIME | timestamp(6) | NO | The time when the information was last updated. |
| BALANCE_STRATEGY | varchar(64) | NO | The name of the balancing strategy. <ul><li>`LS balance by migrate`: migration-based balancing  </li><li>`LS balance by alter`: log stream attribute modification-based balancing </li><li>`LS balance by expand`: expansion-based balancing </li><li>`LS balance by shrink`: reduction-based balancing </li><li>`partition balance`: partition-based balancing </li></ul>|
| JOB_TYPE | varchar(64) | NO | The type of the task. <ul><li>`LS_BALANCE`: log stream balancing  </li><li>`PARTITION_BALANCE`: partition balancing </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | The number of units in each zone that are to be changed. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column was changed to always return <code>NULL</code> starting with V4.4.2. </li> <li>For V4.2.5, this column was changed to always return <code>NULL</code> starting with V4.2.5 BP5. </li></ul></main>  |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | The number of primary zones that are to be changed. |
| STATUS | varchar(64) | NO | The status of the task. <ul><li>`DOING`: the job is being executed.  </li><li>`COMPLETED`: the task was executed successfully. </li><li>`CANCELING`: the task is being canceled. </li><li>`CANCELED`: the task was canceled.</li> <li>`SUSPEND`: the task is suspended.</li></ul>|
| COMMENT | longtext | YES | The comment. |
| MAX_END_TIME | timestamp(6) | YES | The maximum end time of the load balancing task. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view was introduced starting with V4.3.4. For V4.2.x, this column was introduced starting with V4.2.4. </p></main>  |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column was introduced starting with V4.4.2. </li> <li>For V4.2.5, this column was introduced starting with V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | The parameters of the balancing-related configurations.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column was introduced starting with V4.4.2. </li> <li>For V4.2.5, this column was introduced starting with V4.2.5 BP5. </li></ul></main> |

## Sample query

Query the load balancing jobs that are being executed for all tenants.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_JOBS;
```
