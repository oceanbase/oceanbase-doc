# oceanbase.CDB_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.0. </p>
</main>

## Overview

The `CDB_OB_BALANCE_JOB_HISTORY` view displays the history of all load balancing jobs performed by a tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | ------- |
| TENANT_ID | bigint(20) | NO | Tenant ID <ul><li>1: system tenant ID</li><li>Other values: user tenant or meta tenant ID</li></ul> |
| JOB_ID | bigint(20) | NO | CLB Work ID |
| CREATE_TIME | timestamp(6) | NO | Job Creation Time |
| FINISH_TIME | timestamp(6) | NO | Job completion time, including success and cancellation times |
| BALANCE_STRATEGY | varchar(64) | NO | Load balancing strategy name  <ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing </li><li>`LS balance by expand`: Scale-out balancing </li><li>`LS balance by shrink`: Scale-down balancing </li><li>`partition balance`: Partition balancing</li></ul> |
| JOB_TYPE                | varchar(64)  | NO  | The task type.  <ul><li>`LS_BALANCE`: log stream balancing.  </li><li>`PARTITION_BALANCE`: partition balancing. </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | Number of Units in Each Zone Where Target Changes <main id="notice" type='explain'><h4>Note</h4><p>For version V4.2.5, the value of this field has been changed to always be <code>NULL</code> starting from V4.2.5 BP5.</p></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | Number of Changed Primary Zones |
| STATUS | varchar(64) | NO | Task status. Valid values: <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELING`: Cancellation in progress. </li><li>`CANCELED`: Cancel the task. </li></ul> |
| COMMENT | longtext | YES | Comments |
| MAX_END_TIME | timestamp(6) | YES | Maximum End Time of Load Balancing Task <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.x, this field is available starting from V4.2.4. For V4.3.x, this view is available starting from V4.3.4.</p></main> |
| ZONE_UNIT_NUM_LIST | varchar(4096) | NO | Number of Units in Each Zone of Tenant <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting from V4.2.5 BP5 for version V4.2.5.</p></main> |
| PARAMETER_LIST | longtext | NO | Load balancing related parameters <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.5, this field is available starting from V4.2.5 BP5.</p></main> |
