# oceanbase.DBA_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the global compaction information of the current tenant.

## Columns

|           Column           |     Type      | Nullable |        Description         |
|--------------------------|-------------|------------|---------------------------------------------|
| FROZEN_SCN           | bigint(20) unsigned  | NO         | The version number of the last major compaction.           |
| FROZEN_TIME              | timestamp(6)  | NO         | The time when the last major compaction was initiated (FROZEN_SCN is displayed in a readable format).          |
| GLOBAL_BROADCAST_SCN | bigint(20) unsigned  | NO         | The global broadcast version of the major compaction.         |
| LAST_SCN             | bigint(20) unsigned  | NO         | The version number of the last major compaction that was completed.      |
| LAST_FINISH_TIME         | timestamp(6)  | NO         | The end time of the last major compaction.         |
| START_TIME               | timestamp(6)  | NO         | The start time of the major compaction.            |
| STATUS                   | varchar(10) | NO         | <ul><li>`IDLE`: No major compaction is in progress. </li><li>`COMPACTING`: A major compaction is in progress.</li><li>`CHECKSUM`: Checksum verification is in progress.</li></ul>    |
| IS_ERROR                 | varchar(3)  | NO         | <ul><li>`YES`: An error occurred during the major compaction. </li><li>`NO`: No error occurred during the major compaction.  </li></ul> |
| IS_SUSPENDED             | varchar(3)  | NO         | <ul><li>`YES`: The major compaction is suspended. </li><li>`NO`: The major compaction is not suspended. </li></ul>  |
| INFO                     | varchar(14) | NO         | The information about the major compaction. For example, the reason why the major compaction failed.  |

## Sample query

Query the global compaction information of the current tenant in the sys tenant.

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_MAJOR_COMPACTION;
```

The query result is as follows:

```shell
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+

+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+

+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+
1 row in set
```
