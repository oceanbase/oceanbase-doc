# oceanbase.DBA_OB_SERVERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all OBServer nodes.

## Columns

|         Column          |      Type      | Nullable |                        Description                        |
|-----------------------|--------------|------------|----------------------------------------------------------------------------|
| SVR_IP                | varchar(46)  | NO         | The IP address of the server.                                        |
| SVR_PORT              | bigint(20)   | NO         | The port number of the server.                                           |
| ID                    | bigint(20)   | NO         | The unique ID assigned to the cluster.                                     |
| ZONE                  | varchar(128) | NO         | The zone to which the OBServer node belongs.                                |
| SQL_PORT              | bigint(20)   | NO         | The port used by the OBServer node to service SQL requests.                          |
| WITH_ROOTSERVER       | varchar(3)   | NO         | <li> `YES`: The Root Service is available.   <li> `NO`: The Root Service is unavailable.                                                                                |
| STATUS                | varchar(64)  | NO         | <li> `ACTIVE`: The OBServer node is in communication with the RS.   <li> `INACTIVE`: The OBServer node has lost communication with the RS.   <li> `DELETING`: The OBServer node is being deleted.    |
| START_SERVICE_TIME    | timestamp(6) | NO         | The time when the node can start to provide services after the node process is started.<li> `NULL`: The node process has not been started or the node is unavailable.   <li> Valid value: The time when the node can start to provide services after the node process is started |
| STOP_TIME             | timestamp(6) | NO         | The time when the node service is stopped by the user.<li> `NULL`: The node is not stopped.   <li> Valid value: The time when the OBServer node is stopped.   |
| BLOCK_MIGRATE_IN_TIME | timestamp(6) | NO         | The time when data migration in is prohibited for the OBServer node <li> `NULL`: Data migration in is not prohibited.   <li> Valid value: The time when data migration in is prohibited for the OBServer node                                                          |
| LAST_OFFLINE_TIME     | timestamp(6) | NO         | The last time when the OBServer node was offline <li> `NULL`: The OBServer node has never been offline.   <li> Valid value: The last time when the OBServer node was offline <br> Added in V4.2.0.                                                 |
|CREATE_TIME            | timestamp(6) | YES        |The time when the table was created.|
|MODIFY_TIME            | timestamp(6) | YES        |The time when the task was last modified.|
| BUILD_VERSION         | varchar(256) | NO         | The binary build version of the OBServer node.      |

## Sample query

Query the information about all OBServer nodes in the cluster as the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SERVERS\G
```
