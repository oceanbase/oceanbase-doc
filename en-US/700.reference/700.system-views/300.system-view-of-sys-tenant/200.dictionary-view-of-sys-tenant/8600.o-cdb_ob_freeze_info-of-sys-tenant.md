# oceanbase.CDB_OB_FREEZE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the version information generated by major_freeze operations across all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| FROZEN_SCN | bigint(20) unsigned | NO | The major freeze-generated merge version number. |
| CLUSTER_VERSION | bigint(20) | NO | The cluster version number at the time of major freeze. |
| SCHEMA_VERSION | bigint(20) | NO | The schema version number at the time of major freeze. |
| GMT_CREATE | timestamp(6) | NO | The record creation time. |
| GMT_MODIFIED | timestamp(6) | NO | The record's last modification time. |

## Sample query

Query the version information generated by major_freeze operations for all tenants, and display the first five records.

obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_FREEZE_INFO LIMIT 5;
