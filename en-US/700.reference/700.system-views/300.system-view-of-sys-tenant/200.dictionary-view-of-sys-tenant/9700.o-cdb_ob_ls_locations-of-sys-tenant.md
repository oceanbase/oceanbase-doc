# oceanbase.CDB_OB_LS_LOCATIONS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the distribution information of log streams (LS) replicas for all tenants.

## Columns

|     Column     |      Type       | Nullable |       Description        |
|--------------|---------------|------------|-------------------------------------|
| CREATE_TIME  | datetime(6)   | NO         |   The creation time of the log stream.  |
| MODIFY_TIME  | datetime(6)   | NO         |   The modification time of the log stream.  |
| TENANT_ID    | bigint(20)    | NO         | The tenant ID.           |
| LS_ID        | bigint(20)    | NO         | The log stream ID.          |
| SVR_IP       | varchar(46)   | NO         | The IP address of the server.       |
| SVR_PORT     | bigint(20)    | NO         | The port number of the server.          |
| SQL_PORT     | bigint(20)    | NO         | The SQL port number.         |
| ZONE         | varchar(128)  | NO         | The name of the zone.         |
| ROLE         | varchar(8)    | NO         | The role of the replica:<ul><li>`LEADER`   </li><li> `FOLLOWER` </li></ul>      |
| MEMBER_LIST  | varchar(4480) | NO         | The list of replicas, separated by commas. The format of a single replica is `svr_ip:svr_port:timestamp`. The format of the `svr_ip`, `svr_port`, and `timestamp` fields is as follows:<ul><li>`svr_ip`: the IP address of the server where the replica is located</li> <li>`svr_port`: the port number of the server where the replica is located</li> <li>`timestamp`: the time when the replica was added to the list. The default value is `1`. If a replica was added or migrated, the value changes.</li></ul></br> Example: 172.xx.xxx.xxx:2882:1</li> <li>When the role is not `LEADER`, this field is `NULL`.</li></ul>    |
| PAXOS_REPLICA_NUMBER       | bigint(20)    | NO         | The number of Paxos replicas: this field is valid only when the role is `LEADER`. Otherwise, it is `NULL`.  |
| REPLICA_TYPE | varchar(18)   | NO         | The type of the replica:<ul><li>`FULL`: a full-featured replica</li>  <li>`READONLY`: a read-only replica</li> <li>`COLUMNSTORE`: a columnstore replica</li></ul>   |
| LEARNER_LIST | longtext      | YES        | The list of read-only replicas of the log stream, separated by commas. The format of a single replica is `svr_ip:svr_port:timestamp:flag`. The format of the `svr_ip`, `svr_port`, and `timestamp` fields is as follows:<ul><li>`svr_ip`: the IP address of the server where the replica is located</li> <li>`svr_port`: the port number of the server where the replica is located</li> <li>`timestamp`: the time when the replica was added. The default value is `1`. If a replica was added or migrated, the value changes.</li> <li>`flag`: indicates whether the replica is being migrated. `0` indicates that the replica is not being migrated. `2` indicates that the replica is being migrated.</li></ul></br> Example: 172.xx.xxx.xxx:2882:1:0  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| REBUILD      | varchar(5)    | NO         | Indicates whether the replica is being rebuilt. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1. </p></main>|
