# oceanbase.CDB_OB_BALANCE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Overview

Displays the history of load balancing tasks executed by all tenants.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID.<ul><li>1: the ID of the system tenant.  </li><li>Other values: the ID of a user tenant or Meta tenant. </li></ul> |
| TASK_ID | bigint(20) | NO | Load balancing task ID |
| CREATE_TIME | timestamp(6) | NO | Task Start Time |
| FINISH_TIME | timestamp(6) | NO | Task completion time, including success and cancellation times |
| TASK_TYPE | varchar(64) | NO | The task type. <ul><li>`LS_SPLIT`: splits a log stream.  </li><li>`LS_ALTER`: modifies log stream attributes. </li><li>`LS_MERGE`: merges log streams. </li><li>`LS_TRANSFER`: performs log stream transfer. </li></ul>|
| SRC_LS | bigint(20) | NO | Source log stream (the log data stream generated by the data source) |
| DEST_LS | bigint(20) | NO | Destination log stream |
| PART_LIST | longtext | YES | Partition list, including: user table partitions and global index partitions |
| FINISHED_PART_LIST | longtext | YES | List of Partitions That Have Completed Load Balancing |
| PART_COUNT | bigint(20) | YES | Number of Partitions in the Partition List |
| FINISHED_PART_COUNT | bigint(20) | YES | Number of Partitions with Balancing Completed |
| LS_GROUP_ID | bigint(20) | NO | Log Stream Group ID |
| STATUS | varchar(64) | NO | Task Status <ul><li>`INIT`: Task creation  </li><li>`CREATE_LS`: Create log stream</li><li>`ALTER_LS`: Modify log stream attributes</li><li>`SET_LS_MERGING`: Log stream major compaction</li><li>`DROP_LS`: Delete log stream </li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELED`: Cancel the task. </li></ul> |
| PARENT_LIST | varchar(1024) | YES | Parent Task List |
| CHILD_LIST | varchar(1024) | YES | Subtask List |
| CURRENT_TRANSFER_TASK_ID | bigint(20) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | bigint(20) | NO | Job ID of the current task |
| COMMENT | longtext | YES | Comments |
| BALANCE_STRATEGY | varchar(64) | YES | The balancing strategy corresponding to the balance task:<ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing.</li><li>`LS balance by expand`: Expansion balancing </li><li>`LS balance by shrink`: Scale-in balancing </li><li>`partition balance`: Partition balancing </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.2.x, this field is available starting from V4.2.4; for V4.3.x, it is available starting from V4.3.2.</p></main> |
