# oceanbase.CDB_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the history of backup cleanup tasks that have been executed in all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| JOB_ID | bigint(20) | NO | The task ID, which is a monotonic increasing number. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| INITIATOR_TENANT_ID | bigint(20) | NO | The tenant ID of the initiator of the task. |
| INITIATOR_JOB_ID | bigint(20) | NO | The job ID of the initiator of the task. |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | The list of tenants that executed the cleanup task. |
| TYPE | varchar(64) | NO | The cleanup type. Valid value: <ul><li>DELETE OBSOLETE BACKUP: obsolete backup cleanup. </li></ul> |
| PARAMETER | timestamp(6) | NO | The content of the parameter is as follows: <li>For automatic cleanup/obsolete backup cleanup: policy_name = xxx; expired_time = xxx; redundancy:2; backup_copies:1; <li>For manual backup set cleanup: backup_set_id = 1; dest_id = 1; dest = xxxxx; <li>For manual backup piece cleanup: dest_round_id = 1; backup_piece_id = 1; dest_id = 1; dest = xxxx; <li>For manual backup round cleanup: dest_round_id = 1; dest_id = 1; dest = xxxx; <li>For cleanup of all backups in a destination: dest_id = 1; dest = xxx; |
| JOB_LEVEL | varchar(64) | NO | The task initiation level. Valid values: USER_TENANT, CLUSTER, and SYS_TENANT. |
| START_TIMESTAMP | timestamp(6) | NO | The current time of the tenant when the task started. |
| END_TIMESTAMP | timestamp(6) | NO | The current time of the tenant when the task ended. |
| STATUS | varchar(64) | NO | The task status. Valid values: <li>INIT<li>DOING<li>CANCELING<li>CANCELED<li>COMPLETED<li>FAILED |
| TASK_COUNT | bigint(20) | YES | The number of backup_set or backup_piece tasks. |
| SUCCESS_TASK_COUNT | bigint(20) | YES | The number of backup_set or backup_piece tasks that were executed successfully. |
| RESULT | bigint(20) | NO | The error code. |
| COMMENT | varchar(4096) | YES | The task execution description. |
