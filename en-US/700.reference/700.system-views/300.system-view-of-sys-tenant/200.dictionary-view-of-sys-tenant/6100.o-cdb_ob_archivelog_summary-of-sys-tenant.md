# oceanbase.CDB_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of all historical and current log archives for all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| DEST_ID | bigint(20) | NO | The path ID. The system assigns a unique ID to each path. |
| ROUND_ID | bigint(20) | NO | The ID of the round of complete Clog backup data stream. |
| INCARNATION | bigint(20) | NO | The number of incarnations after Flashback Database. |
| DEST_NO | bigint(20) | NO | The ID of log_archive_dest_n. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| STATUS | varchar(64) | NO | The archive status. Valid values: <ul><li>`PREPARE`: The system is preparing to start archiving from the `START_SCN` point. </li> <li>`BEGINNING`: The system is starting to archive logs.  </li> <li>`DOING`: The system is archiving logs. </li><li> `INTERRUPTED`: The log archiving is interrupted and requires manual intervention. </li><li>`STOP`: The log archiving has been stopped.  </li><li>`STOPPING`: The system is stopping log archiving.  </li><li>`SUSPENDING`: The system is suspending log archiving.  </li><li>`SUSPEND`: The log archiving has been suspended.  </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | The starting backup point. |
| START_SCN_DISPLAY | datetime(6) | NO | The converted value of START_SCN in time units. |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | The current archive point. |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | The converted value of CHECKPOINT_SCN in time units. |
| COMPATIBLE | bigint(20) | NO | The compatibility version. |
| BASE_PIECE_ID | bigint(20) | NO | The ID of the first PIECE in this round. |
| USED_PIECE_ID | bigint(20) | NO | The ID of the PIECE used in this round. |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | The piece switching cycle. |
| UNIT_SIZE   | bigint(20)   | NO   | The size of a single log block for compression or encryption in this round. This field is not supported.   |
| COMPRESSION | varchar(128) | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used.</li></ul> This field is not supported.  |
| INPUT_BYTES | bigint(20) | NO | The amount of data read, in bytes. |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of data read with the unit, for example: 798.01 M or 5.25 G. |
| OUTPUT_BYTES | bigint(20) | NO | The amount of data output, in bytes. |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of data output with the unit, for example: 798.01 M or 5.25 G. |
| COMPRESSION_RATIO | decimal(23,2) | NO | The compression ratio. This field is not supported.  |
| DELETED_INPUT_BYTES | bigint(20) | NO | The amount of original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | The converted value of DELETED_INPUT_BYTES. The unit is MB, GB, TB, or PB. |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | The amount of effective data deleted, in bytes. |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The converted value of DELETED_OUTPUT_BYTES. The unit is MB, GB, TB, or PB. |
| PATH | varchar(2048) | NO | The archive path. |
| COMMENT | varchar(262144) | NO | The error message. |
