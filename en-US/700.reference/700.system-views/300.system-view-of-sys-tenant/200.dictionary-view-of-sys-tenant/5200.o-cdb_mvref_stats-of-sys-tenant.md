# CDB_MVREF_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `CDB_MVREF_STATS` view displays the basic timing statistics of materialized view refreshes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| MV_OWNER | varchar(128) | NO | The owner of the materialized view. |
| MV_NAME | varchar(128) | NO | The name of the materialized view. |
| REFRESH_ID | bigint(20) | NO | The ID of the refresh. |
| REFRESH_METHOD | varchar(30) | NO | The method used to refresh the materialized view.<ul><li>FAST: Incremental refresh.  </li><li>COMPLETE: Full refresh. </li></ul>|
| REFRESH_OPTIMIZATIONS | text | NO | The refresh optimizations. For example, the primary key or foreign key applied during a materialized view refresh or an empty refresh.<main id="notice" type='explain'> <h4>Note</h4><p>This field is reserved and its value is NULL by default. </p></main> |
| ADDITIONAL_EXECUTIONS | text | NO | Additional executions. For example, index rebuilds or log operations involved in a materialized view refresh.<main id="notice" type='explain'> <h4>Note</h4><p>This field is reserved and its value is NULL by default. </p></main> |
| START_TIME | datetime | NO | The start time of the refresh. |
| END_TIME | datetime | NO | The end time of the refresh. |
| ELAPSED_TIME | bigint(20) | NO | The duration of the refresh, in seconds. |
| LOG_SETUP_TIME | bigint(1) | NO | The time taken to set up the logs for the materialized view, in seconds<main id="notice" type='explain'> <h4>Note</h4><p>This field is reserved and its value is 0 by default. </p></main> |
| LOG_PURGE_TIME | bigint(20) | NO | The time taken to purge the logs for the materialized view, in seconds. |
| INITIAL_NUM_ROWS | bigint(20) | NO | The number of rows in the materialized view at the start of the refresh. |
| FINAL_NUM_ROWS | bigint(20) | NO | The number of rows in the materialized view at the end of the refresh. |

## Sample query

Query the basic timing statistics of a materialized view refresh.

```shell
obclient [test_db]> SELECT * FROM oceanbase.CDB_MVREF_STATS;
```
