# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the basic information of a tenant.

* When you query this view as a system tenant, the view displays the information of all tenants, including the system tenant, user-created tenants (user tenants), and the Meta tenant. You can use the `TENANT_TYPE` column to distinguish the types of tenants.
* When you query this view as a user tenant, the view displays only the information of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)| NO | The tenant ID.  <ul><li> 1: the ID of the system tenant.  </li><li> Other values: the ID of a user tenant or a Meta tenant.  </li></ul>|
| TENANT_NAME| varchar(128)| NO | The tenant name. |
| TENANT_TYPE| varchar(4)| NO | <ul><li> `SYS`: the system tenant.  </li><li> `USER`: the user tenant. </li><li>`META`: the Meta tenant. </li></ul> |
| CREATE_TIME| timestamp(6)| YES | The time when the tenant was created.|
| MODIFY_TIME| timestamp(6)| YES | The time when the information was last updated.|
| PRIMARY_ZONE| varchar(128)| YES | The primary zone of the tenant.|
| LOCALITY| varchar(4096)| NO | The distribution information of the tenant's replicas.|
| PREVIOUS_LOCALITY| varchar(4096)| NO | The locality information before the change.  <ul><li> If this value is valid, it indicates that the locality change is not yet complete.  </li><li>NULL indicates that no locality change has been performed.  </li></ul> |
| COMPATIBILITY_MODE| varchar(6)| NO | <ul><li>`MYSQL`: MySQL compatibility mode. </li><li>`ORACLE`: Oracle compatibility mode. </li></ul> |
| STATUS| varchar(64)| NO | The status of the tenant.  <ul><li>`NORMAL`: normal status. </li><li>`RESTORE`: tenant is being physically restored.  </li><li>`CREATING`: tenant is being created. </li><li> `DROPPING`: tenant is being dropped. </li></ul>|
| IN_RECYCLEBIN| varchar(3)| NO | Indicates whether the tenant is in the recycle bin.  <ul><li>  `YES`: the tenant is in the recycle bin. </li><li> `NO`: the tenant is not in the recycle bin. </li></ul>|
| LOCKED| varchar(3)| NO | Indicates whether the tenant is locked.  <ul><li>  `YES`: the tenant is locked. </li><li>`NO`: the tenant is not locked.  </li></ul> The value of this column is affected by the `ALTER TENANT xxx LOCK|UNLOCK` statement. |
| TENANT_ROLE| varchar(100) | NO | The role of the cluster.  <ul><li>`PRIMARY`: the primary tenant.   </li><li>  `STANDBY`: the standby tenant.  </li><li> `RESTORE`: the tenant is being restored. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| SWITCHOVER_STATUS| varchar(100)| NO | The SWITCHOVER status.  <ul><li>`NORMAL`: normal status, not in the process of switching.   </li><li>`PREPARE SWITCHING TO PRIMARY`: preparing for switching from standby to primary. </li><li> `SWITCHING TO PRIMARY`: switching from standby to primary. </li><li>`PREPARE FLASHBACK`: preparing for Flashback. </li><li> `FLASHBACK`: Flashback. </li><li>`PREPARE SWITCHING TO STANDBY`: preparing for switching from primary to standby. </li><li> `SWITCHING TO STANDBY`: switching from primary to standby. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| SWITCHOVER_EPOCH| bigint(20)| NO | The unique identifier for SWITCHOVER/FAILOVER. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| SYNC_SCN| bigint(20) unsigned| NO | The snapshot version that has been synchronized for the tenant. This column is meaningless for the system tenant and the Meta tenant, and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| REPLAYABLE_SCN| bigint(20) unsigned| NO | The snapshot version that can be replayed for the tenant. This column is meaningless for the system tenant and the Meta tenant, and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| READABLE_SCN| bigint(20) unsigned| NO | The snapshot version that can be read for the tenant. This column is meaningless for the system tenant and the Meta tenant, and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| RECOVERY_UNTIL_SCN| bigint(20) unsigned| NO | The maximum recovery point for the tenant. This column is meaningless for the system tenant and the Meta tenant, and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| LOG_MODE| varchar(100)| NO | The archiving mode.  <ul><li>  `ARCHIVELOG`: the archiving mode is enabled. </li><li> `NOARCHIVELOG`: the archiving mode is not enabled. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| ARBITRATION_SERVICE_STATUS |  varchar(64)   | NO | The arbitration service status of the tenant. Valid values:  <ul><li>`ENABLING`: enabling.   </li><li> `ENABLED`: enabled. </li><li> `DISABLING`: disabling. </li><li>`DISABLED`: disabled. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.1.0. </p></main> |
| UNIT_NUM | bigint(20) | NO | The number of units in the zone. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| COMPATIBLE | varchar(65536) | NO | The compatibility version. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| MAX_LS_ID  | bigint(20)     | NO | The largest log stream ID that ever existed for the tenant. For the system tenant and the Meta tenant, this value is 1. For a user tenant, this value is the actual size.  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| RESTORE_DATA_MODE  | varchar(128)     | NO | The data restore mode of the tenant. Valid values: <ul><li>`NORMAL`: indicates that the tenant is normally created or restored from full data.</li><li>`REMOTE`: indicates that the tenant is restored from a remote source, and the data is in a remote reference state.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.2. </p></main> |
| FLASHBACK_LOG_SCN | bigint(20) | NO | The point in time of the last log truncation operation for the tenant. After a failover, you can use the standby tenant to perform log truncation operations to a specified point in time and connect the original primary tenant's standby tenant to the new primary tenant. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1. </p></main> |
| COMMENT                    | varchar(4096)       | NO   | Comments     |
