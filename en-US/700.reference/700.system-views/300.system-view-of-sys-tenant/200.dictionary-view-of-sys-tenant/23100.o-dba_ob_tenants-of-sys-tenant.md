# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the basic information of a tenant.

* When you query this view from the system tenant, the information of all tenants, including the system tenant, user-created tenants (user tenants), and Meta tenant, is displayed. You can use the `TENANT_TYPE` column to identify the tenant type.
* When you query this view from a user tenant, only the information of the current tenant is displayed.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)| NO | Tenant ID: <ul><li> 1: system tenant ID  </li><li> Other values: user tenant or Meta tenant ID </li></ul>|
| TENANT_NAME| varchar(128)| NO | Tenant name |
| TENANT_TYPE| varchar(4)| NO | <ul><li> `SYS`: system tenant  </li><li> `USER`: user tenant </li><li>`META`: Meta tenant </li></ul> |
| CREATE_TIME| timestamp(6)| YES | Tenant creation time|
| MODIFY_TIME| timestamp(6)| YES | Information update time|
| PRIMARY_ZONE| varchar(128)| YES | Tenant Primary Zone|
| LOCALITY| varchar(4096)| NO | Tenant replica distribution information|
| PREVIOUS_LOCALITY| varchar(4096)| NO | Locality information before the change: <ul><li> If this value is valid, it indicates that the Locality change is not completed.  </li><li>NULL indicates that no Locality change has been performed.  </li></ul> |
| COMPATIBILITY_MODE| varchar(6)| NO | <ul><li>`MYSQL`: MySQL compatibility mode </li><li>`ORACLE`: Oracle compatibility mode</li></ul> |
| STATUS| varchar(64)| NO | Current tenant status: <ul><li>`NORMAL`: normal state tenant</li><li>`RESTORE`: tenant being physically restored  </li><li>`CREATING`: tenant being created </li><li> `DROPPING`: tenant being dropped </li></ul>|
| IN_RECYCLEBIN| varchar(3)| NO | Whether the tenant is in the recycle bin: <ul><li>  `YES`: in the recycle bin </li><li> `NO`: not in the recycle bin </li></ul>|
| LOCKED| varchar(3)| NO | Whether the tenant is locked: <ul><li>  `YES`: locked </li><li>`NO`: not locked  </li></ul> This field is affected by the `ALTER TENANT xxx LOCK|UNLOCK` command. |
| TENANT_ROLE| varchar(100) | NO | Cluster role: <ul><li>`PRIMARY`: primary tenant   </li><li>  `STANDBY`: standby tenant  </li><li> `RESTORE`: tenant being restored </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| SWITCHOVER_STATUS| varchar(100)| NO | SWITCHOVER status: <ul><li>`NORMAL`: normal status, not in switching   </li><li>`PREPARE SWITCHING TO PRIMARY`: preparing for standby-to-primary switch </li><li> `SWITCHING TO PRIMARY`: standby-to-primary switch</li><li>`PREPARE FLASHBACK`: preparing for Flashback  </li><li> `FLASHBACK`: Flashback </li><li>`PREPARE SWITCHING TO STANDBY`: preparing for primary-to-standby switch </li><li> `SWITCHING TO STANDBY`: primary-to-standby switch </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| SWITCHOVER_EPOCH| bigint(20)| NO | Unique identifier for SWITCHOVER/FAILOVER <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| SYNC_SCN| bigint(20) unsigned| NO | Snapshot version synchronized by the current tenant. For system tenants and Meta tenants, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| REPLAYABLE_SCN| bigint(20) unsigned| NO | Snapshot version that can be replayed by the current tenant. For system tenants and Meta tenants, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| READABLE_SCN| bigint(20) unsigned| NO | Snapshot version that can be read by the current tenant. For system tenants and Meta tenants, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| RECOVERY_UNTIL_SCN| bigint(20) unsigned| NO | Maximum recovery point of the current tenant. For system tenants and Meta tenants, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| LOG_MODE| varchar(100)| NO | Archive mode: <ul><li>  `ARCHIVELOG`: archive mode is enabled </li><li> `NOARCHIVELOG`: archive mode is not enabled </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| ARBITRATION_SERVICE_STATUS |  varchar(64)   | NO | Arbitration service status of the tenant. Valid values: <ul><li>`ENABLING`: enabling   </li><li> `ENABLED`: enabled</li><li> `DISABLING`: disabling</li><li>`DISABLED`: disabled </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| UNIT_NUM | bigint(20) | NO | Number of units in the zone <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| COMPATIBLE | varchar(65536) | NO | Compatibility version <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| MAX_LS_ID  | bigint(20)     | NO | Maximum log stream ID that has ever existed for the tenant. For system tenants and Meta tenants, this value is 1. For user tenants, this value is the actual size. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| RESTORE_DATA_MODE  | varchar(128)     | NO | The data restore mode of the tenant. Valid values: <ul><li>`NORMAL`: indicates that the tenant is normally created or restored by using full data. </li><li>`REMOTE`: indicates that the tenant is restored by using quick restore and the data is in a remote reference state. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.2. </p></main> |
| FLASHBACK_LOG_SCN | bigint(20) | NO | The SCN of the latest log pruning operation performed on the tenant. After a failover, you can use the log pruning command to prune the logs of the original primary tenant to a specified SCN and then add the standby tenant to the new primary tenant. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1. </p></main> |
| COMMENT                    | varchar(4096)       | NO   | The comment.     |
