# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the basic information of a tenant.

* When you query this view as a system tenant, the information of all tenants is displayed, including system tenants, user-created tenants (user tenants), and the Meta tenant. You can distinguish the types of tenants based on the `TENANT_TYPE` column.
* When you query this view as a user tenant, only the information of the current tenant is displayed.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)| NO | The tenant ID.  <ul><li> 1: the ID of the system tenant.  </li><li> Other values: the ID of a user tenant or a Meta tenant. </li></ul>|
| TENANT_NAME| varchar(128)| NO | The tenant name. |
| TENANT_TYPE| varchar(4)| NO | <ul><li> `SYS`: the system tenant.  </li><li> `USER`: the user tenant. </li><li>`META`: the Meta tenant. </li></ul> |
| CREATE_TIME| timestamp(6)| YES | The time when the tenant was created.|
| MODIFY_TIME| timestamp(6)| YES | The time when the information was last updated.|
| PRIMARY_ZONE| varchar(128)| YES | The primary zone of the tenant.|
| LOCALITY| varchar(4096)| NO | The replica distribution information of the tenant.|
| PREVIOUS_LOCALITY| varchar(4096)| NO | The locality information before the change.  <ul><li> If this value is valid, it indicates that the locality change is not yet complete.  </li><li>NULL indicates that no locality change has been performed.  </li></ul> |
| COMPATIBILITY_MODE| varchar(6)| NO | <ul><li>`MYSQL`: MySQL compatibility mode. </li><li>`ORACLE`: Oracle compatibility mode. </li></ul> |
| STATUS| varchar(64)| NO | The current status of the tenant.  <ul><li>`NORMAL`: the tenant is in the normal state. </li><li>`RESTORE`: the tenant is being physically restored.  </li><li>`CREATING`: the tenant is being created. </li><li> `DROPPING`: the tenant is being dropped. </li></ul>|
| IN_RECYCLEBIN| varchar(3)| NO | Indicates whether the tenant is in the recycle bin.  <ul><li>  `YES`: the tenant is in the recycle bin. </li><li> `NO`: the tenant is not in the recycle bin. </li></ul>|
| LOCKED| varchar(3)| NO | Indicates whether the tenant is locked.  <ul><li>  `YES`: the tenant is locked. </li><li>`NO`: the tenant is not locked.  </li></ul> This field is affected by the `ALTER TENANT xxx LOCK|UNLOCK` statement.|
| TENANT_ROLE| varchar(100) | NO | The cluster role.  <ul><li>`PRIMARY`: the primary tenant.   </li><li>  `STANDBY`: the standby tenant.  </li><li> `RESTORE`: the tenant is being restored. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| SWITCHOVER_STATUS| varchar(100)| NO | The SWITCHOVER status.  <ul><li>`NORMAL`: the tenant is in the normal state and not in the process of switching.   </li><li>`PREPARE SWITCHING TO PRIMARY`: the tenant is preparing to switch to the primary. </li><li> `SWITCHING TO PRIMARY`: the tenant is switching to the primary. </li><li>`PREPARE FLASHBACK`: the tenant is preparing to perform a Flashback. </li><li> `FLASHBACK`: the tenant is performing a Flashback. </li><li>`PREPARE SWITCHING TO STANDBY`: the tenant is preparing to switch to the standby. </li><li> `SWITCHING TO STANDBY`: the tenant is switching to the standby. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| SWITCHOVER_EPOCH| bigint(20)| NO | The unique identifier of the SWITCHOVER/FAILOVER. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| SYNC_SCN| bigint(20) unsigned| NO | The snapshot version that has been synchronized for the current tenant. For the system tenant and Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| REPLAYABLE_SCN| bigint(20) unsigned| NO | The snapshot version that can be replayed for the current tenant. For the system tenant and Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| READABLE_SCN| bigint(20) unsigned| NO | The snapshot version that can be read for the current tenant. For the system tenant and Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| RECOVERY_UNTIL_SCN| bigint(20) unsigned| NO | The maximum recovery point for the current tenant. For the system tenant and Meta tenant, this field is meaningless and is displayed as NULL. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| LOG_MODE| varchar(100)| NO | The archive mode.  <ul><li>  `ARCHIVELOG`: the archive mode is enabled. </li><li> `NOARCHIVELOG`: the archive mode is disabled. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| ARBITRATION_SERVICE_STATUS |  varchar(64)   | NO | The arbitration service status of the tenant. Valid values:  <ul><li>`ENABLING`: the arbitration service is being enabled.   </li><li> `ENABLED`: the arbitration service is enabled. </li><li> `DISABLING`: the arbitration service is being disabled. </li><li>`DISABLED`: the arbitration service is disabled. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.1.0. </p></main> |
| UNIT_NUM | bigint(20) | NO | The minimum `UNIT_NUM` of all zones in the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>This column is available starting with V4.2.0. </li> <li>For V4.6.x, this column is available starting with V4.6.0. The column value indicates the minimum `UNIT_NUM` of all zones in the tenant. </li> <li>For V4.4.x, this column is available starting with V4.4.2. The column value indicates the minimum `UNIT_NUM` of all zones in the tenant. </li> <li>In V4.2.5, this column indicates the `UNIT_NUM` of all zones in the tenant in versions earlier than V4.2.5 BP5, and the minimum `UNIT_NUM` of all zones in the tenant in V4.2.5 BP5 and later. </li></ul></main> |
| ZONE_UNIT_NUM_LIST | varchar(65536) | NO | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column is available starting with V4.6.0. </li> <li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |
| COMPATIBLE | varchar(65536) | NO | The compatible version. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| MAX_LS_ID  | bigint(20)     | NO | The largest log stream ID that ever existed in the tenant. For the system tenant and the meta tenant, the value is 1. For a user tenant, the value is the actual size. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| RESTORE_DATA_MODE  | varchar(128)     | NO | The data restore mode of the tenant. Valid values: <ul><li>`NORMAL`: indicates that the tenant was created normally or restored from full data. </li><li>`REMOTE`: indicates that the tenant was restored quickly, and the data is in a remote reference state. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.2. </p></main> |
| FLASHBACK_LOG_SCN | bigint(20) | NO | The latest log stream ID that was pruned from the tenant. After a failover, you can use the log stream pruning command to prune the logs of the original primary tenant to the specified log stream ID and then add the standby tenant to the new primary tenant. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1. </p></main> |
| COMMENT                    | varchar(4096)       | NO   | The comment.     |
| PROTECTION_MODE            | varchar(128)        | NO   | The protection mode of the current tenant. Only `MAXIMUM PERFORMANCE` is supported. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main> |
| PROTECTION_LEVEL           | varchar(128)        | NO   | The protection level of the current tenant. Only `MAXIMUM PERFORMANCE` is supported. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main>  |
