# mysql.user

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.1. </p>
</main>

## Purpose

This view displays the global permissions of a user (VIRTUAL_TABLE).

## Columns

|        **Column**        |    **Type**     | **Nullable** |                      **Description**                       |
|------------------------|---------------|----------------|---------------------------------------------------|
| host                   | varchar(128)  | NO             | The host name.                                               |
| user                   | varchar(128)  | NO             | The username.                                               |
| password               | varchar(128)  | NO             | The user password.                                              |
| select_priv            | varchar(1)    | NO             | Indicates whether the user has the SELECT privilege.                                   |
| insert_priv            | varchar(1)    | NO             | Indicates whether the user has the INSERT privilege.                                   |
| update_priv            | varchar(1)    | NO             | Indicates whether the user has the UPDATE privilege.                                   |
| delete_priv            | varchar(1)    | NO             | Indicates whether the user has the DELETE privilege.                                   |
| create_priv            | varchar(1)    | NO             | Indicates whether the user has the CREATE privilege.                                   |
| drop_priv              | varchar(1)    | NO             | Indicates whether the user has the DROP privilege.                                     |
| reload_priv            | varchar(1)    | NO             | Indicates whether the user has the FLUSH privilege. This privilege is not used currently.                          |
| shutdown_priv          | varchar(1)    | NO             | Indicates whether the user has the SHUTDOWN privilege. This privilege is not used currently.                       |
| process_priv           | varchar(1)    | NO             | Indicates whether the user can query active threads.                                       |
| file_priv              | varchar(1)    | NO             | Indicates whether the user has file read/write privileges. This privilege is not used currently.                              |
| grant_priv             | varchar(1)    | NO             | Indicates whether the user has the GRANT privilege.                                         |
| reference_priv         | varchar(1)    | NO             | This privilege is not used.                                              |
| index_priv             | varchar(1)    | NO             | Indicates whether the user can create indexes.                                           |
| alter_priv             | varchar(1)    | NO             | Indicates whether the user has the ALTER privilege.                                    |
| show_db_priv           | varchar(1)    | NO             | Indicates whether the user can execute the `show database` statement.                          |
| super_priv             | varchar(1)    | NO             | Indicates whether the user has the SUPER privilege.                                       |
| create_tmp_table_priv  | varchar(1)    | NO             | Indicates whether the user can create temporary tables. This privilege is not used.                                     |
| lock_tables_priv       | varchar(1)    | NO             | Indicates whether the user can execute the `lock tables` statement. This privilege is not used currently. |
| execute_priv           | varchar(1)    | NO             | Indicates whether the user can execute stored procedures. This privilege is not used currently.                               |
| repl_slave_priv        | varchar(1)    | NO             | This privilege is not used.                                              |
| repl_client_priv       | varchar(1)    | NO             | This privilege is not used.                                              |
| create_view_priv       | varchar(1)    | NO             | Indicates whether the user can create views.                                           |
| show_view_priv         | varchar(1)    | NO             | Indicates whether the user can execute the `show create view` statement.                       |
| create_routine_priv    | varchar(1)    | NO             | Indicates whether the user can create stored procedures. This privilege is not used currently.                               |
| alter_routine_priv     | varchar(1)    | NO             | Indicates whether the user can modify stored procedures. This privilege is not used currently.                               |
| create_user_priv       | varchar(1)    | NO             | Indicates whether the user can execute the `create user` statement.                            |
| event_priv             | varchar(1)    | NO             | Whether to allow creation, modification, and deletion of events. This column is not used. |
| Column        | Type       | Nullable    | Description                         | |----------------|---------------------|--------------------|-------------------------------------| | trigger_priv  | varchar(1)    | NO             | Indicates whether a privilege to manipulate triggers is available. This column is unused for now. |
| create_tablespace_priv | varchar(1)    | NO             | Whether the user is allowed to create a tablespace. This column is currently not used.       |
| ssl_type               | varchar(10)   | NO             | This column is not used at present.                        |
| ssl_cipher             | varchar(1024) | NO             | This column is not used at present.                                   |
| x509_issuer            | varchar(1024) | NO             | This field is not used currently.                                         |
| x509_subject           | varchar(1024) | NO             | The value of this column is not currently used.        |
| max_questions          | bigint(20)    | NO             | The maximum number of queries per hour for a user (not used)                               |
| max_updates            | bigint(20)    | NO             | The maximum number of updates that can be performed per hour. This column is currently not in use.                 |
| max_connections        | bigint(20)    | NO             | The maximum number of connections that can be accepted by a user per hour. This column is currently not in use. |
| max_user_connections   | bigint(20)    | NO             | The maximum number of requests. This field is not in use currently.                              |
| Column      | Type       | Nullable | Description   | | --- | --- | --- | --- | | plugin              | varchar(1024) | NO             | This column is temporarily not in use.                                          |
| authentication_string  | varchar(1024) | NO             | This column is not in use currently.                    |
| password_expired       | varchar(1)    | NO             | Whether the user password has expired. This column is not in use currently. |
| account_locked | varchar(1)    | NO   | Whether the user is locked out.    |
| drop_database_link_priv   | varchar(1)    | NO   | Whether to allow deleting database links     |
| create_database_link_priv | varchar(1)    | NO   | Whether to allow creating database links.     |
| create_role_priv          | varchar(1)    | NO   | Whether the user has the CREATE ROLE privilege. |
| drop_role_priv           | varchar(1)    | NO   | Whether the role can be dropped     |
