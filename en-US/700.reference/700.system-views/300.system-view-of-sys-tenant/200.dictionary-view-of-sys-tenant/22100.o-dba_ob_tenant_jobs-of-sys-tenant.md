# oceanbase.DBA_OB_TENANT_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about tenant-level tasks.

## Columns

|    Column     |      Type      | Nullable |                                                              Description                                                               |
|-------------|--------------|------------|-------------|
| JOB_ID      | bigint(20)   | NO         | The task ID.                                      |
| JOB_TYPE    | varchar(128) | NO         | The task type. Valid values: <ul><li> `ALTER_TENANT_LOCALITY`: modify the locality of a tenant. </li> <li>`ROLLBACK_ALTER_TENANT_LOCALITY`: roll back the locality of a tenant. </li> <li>`SHRINK_RESOURCE_TENANT_UNIT_NUM`: reduce the number of resource units of a tenant. </li> <li>`ALTER_TENANT_PRIMARY_ZONE`: modify the `PRIMARY_ZONE` of a tenant. </li>  <li>`ALTER_RESOURCE_TENANT_UNIT_NUM`: modify the `UNIT_NUM` of a tenant resource pool. </li> <li>`UPGRADE_POST_ACTION`: perform the pre-upgrade actions. </li> <li>`UPGRADE_SYSTEM_VARIABLE`: upgrade system variables. </li> <li>`UPGRADE_SYSTEM_TABLE`: upgrade system tables. </li> <li>`UPGRADE_BEGIN`: start an upgrade. </li> <li>`UPGRADE_VIRTUAL_SCHEMA`: upgrade schemas. </li> <li>`UPGRADE_SYSTEM_PACKAGE`: upgrade system packages. </li> <li>`UPGRADE_ALL_POST_ACTION`: perform the post-upgrade actions. </li> <li>`UPGRADE_INSPECTION`: perform an upgrade inspection. </li> <li>`UPGRADE_END`: end an upgrade. </li> <li>`UPGRADE_ALL`: upgrade all tenants. </li></ul>   |
| JOB_STATUS  | varchar(128) | NO         | The task status. Valid values: <li> `INPROGRESS`: in progress.   <li> `SUCCESS`: succeeded.   <li> `FAILED`: failed.                     |
| RESULT_CODE | bigint(20)   | YES        | The task exit code.                                      |
| PROGRESS    | bigint(20)   | NO         | The task progress, in percentage. Value range: \[0, 100\].                     |
| START_TIME  | timestamp(6) | YES        | The task start time.                                     |
| MODIFY_TIME | timestamp(6) | YES        | The last task modification time.                                 |
| TENANT_ID   | bigint(20)   | YES        | The tenant ID.                                      |
| SQL_TEXT    | longtext     | YES        | The related SQL statement.                                 |
| EXTRA_INFO  | varchar(512) | YES        | Additional information.                                      |
| RS_SVR_IP   | varchar(46)  | NO         | The IP address of the Root Service server.                      |
| RS_SVR_PORT | bigint(20)   | NO         | The port number of the Root Service server.                         |

## Sample query

Query the tenant tasks of all tenants in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_JOBS\G
```
