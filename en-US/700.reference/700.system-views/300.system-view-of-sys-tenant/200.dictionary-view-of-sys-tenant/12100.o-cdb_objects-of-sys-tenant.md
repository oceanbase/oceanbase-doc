# oceanbase.CDB_OBJECTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `CDB_OBJECTS` view displays the object information of all tenants.

## Columns

|       Column        |      Type      | Nullable |              Description               |
|-------------------|--------------|------------|-------------------------------|
| CON_ID            | bigint(20)   | NO         | The tenant ID.  |
| OWNER             | varchar(128) | NO         | The owner of the object.                      |
| OBJECT_NAME       | varchar(128) | NO         | The name of the object.                          |
| SUBOBJECT_NAME    | varchar(128) | NO         | The name of the subobject. For example, partition.           |
| OBJECT_ID         | bigint(20)   | NO         | The dictionary ID of the object.                    |
| DATA_OBJECT_ID    | bigint(20)   | NO         | The dictionary ID of the segment that contains the object.         |
| OBJECT_TYPE       | varchar(23)  | NO         | The type of the object. Valid values: TABLE, INDEX, PARTITION, PACKAGE, STORED PROCEDURE, SYNONYM, and SEQUENCE. |
| CREATED           | datetime     | NO         | The time when the object was created.                        |
| LAST_DDL_TIME     | datetime     | NO         | The time when the last DDL operation was performed on the object.                 |
| TIMESTAMP         | datetime     | NO         | The timestamp of the object, in character format.              |
| STATUS            | varchar(7)   | NO         | The status of the object: VALID or INVALID.           |
| TEMPORARY         | varchar(1)   | NO         | Indicates whether the object is a temporary object.                  |
| GENERATED         | varchar(1)   | NO         | Indicates whether the name of the object is generated by the system.              |
| SECONDARY         | varchar(1)   | NO         | This column is currently unused.                     |
| NAMESPACE         | bigint(20)   | NO         | The namespace of the object.                       |
| EDITION_NAME      | varchar(128) | NO         | Reserved.                          |
| SHARING           | varchar(18)  | NO         | NULL by default.                              |
| EDITIONABLE       | varchar(1)   | NO         | NULL by default.         |
| ORACLE_MAINTAINED | varchar(1)   | NO         | NULL by default.      |
| APPLICATION       | varchar(1)   | NO         | NULL by default.            |
| DEFAULT_COLLATION | varchar(1)   | NO         | NULL by default.                              |
| DUPLICATED        | varchar(1)   | NO         | NULL by default.         |
| SHARDED           | varchar(1)   | NO         | NULL by default.                            |
| IMPORTED_OBJECT   | varchar(1)   | NO         | NULL by default.                              |
| CREATED_APPID     | bigint(0)    | NO         | NULL by default.       |
| CREATED_VSNID     | bigint(0)    | NO         | NULL by default.          |
| MODIFIED_APPID    | bigint(0)    | NO         | NULL by default.       |
| MODIFIED_VSNID    | bigint(0)    | NO         | NULL by default.      |
