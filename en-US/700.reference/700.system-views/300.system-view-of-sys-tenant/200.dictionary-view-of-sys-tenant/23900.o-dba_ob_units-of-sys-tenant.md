# oceanbase.DBA_OB_UNITS
<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>

</main>

## Purpose

This view displays the information about units of all tenants.

## Columns
|         Column          |      Type      | Nullable |   Description   |
|-----------------------|--------------|------------|--------------------|
| UNIT_ID| bigint(20)   | NO         | The ID of the unit.|
| TENANT_ID             | bigint(20)   | NO         | The ID of the tenant to which the unit belongs. <ul><li>`NULL`: The unit does not belong to any tenant.   </li><li> Valid value: the ID of the target tenant. </li></ul>   |
| STATUS | varchar(128) | NO         | <ul><li>`ACTIVE`: The unit is in the active state.   </li> <li>`ADDING`: The unit is being added. </li> <li> `DELETING`: The unit is being deleted. </li></ul>       |
| RESOURCE_POOL_ID      | bigint(20)   | NO         | The ID of the resource pool to which the unit belongs.        |
| UNIT_GROUP_ID         | bigint(20)   | NO         | The ID of the unit group to which the unit belongs. |
| CREATE_TIME           | timestamp(6) | YES        | The time when the unit was created.             |
| MODIFY_TIME           | timestamp(6) | YES        | The time when the unit was last modified.     |
| ZONE   | varchar(128) | NO         | The name of the zone. |
| SVR_IP | varchar(46)  | NO         | The IP address of the OBServer to which the unit belongs.  |
| SVR_PORT              | bigint(20)   | NO         | The port number of the OBServer to which the unit belongs. |
| MIGRATE_FROM_SVR_IP   | varchar(46)  | NO         | <ul><li>`NULL`: The unit is not being migrated. </li><li> Valid value: the IP address of the source server from which the unit is being migrated. </li></ul>  |
| MIGRATE_FROM_SVR_PORT | bigint(20)   | NO         | <ul><li> `NULL`: The unit is not being migrated. </li><li> Valid value: the port number of the source server from which the unit is being migrated. </li></ul>     |
| MANUAL_MIGRATE        | varchar(3)   | NO         | <ul><li>`NULL`: The unit is not being migrated. </li><li>`YES`: The unit is being manually migrated. </li><li>`NO`: The unit is being automatically migrated. </li></ul>   |
| UNIT_CONFIG_ID        | bigint(20)   | NO         |  The ID of the unit specification.   |
| MAX_CPU               | double       | NO         |  The upper limit of the CPU specification.   |
| MIN_CPU               | double       | NO         |  The lower limit of the CPU specification.   |
| MEMORY_SIZE           | bigint(20)   | NO         |  The size of the memory, in bytes.   |
| LOG_DISK_SIZE         | bigint(20)   | NO         |  The size of the log disk, in bytes.   |
| DATA_DISK_SIZE        | bigint(20)   | NO         |  The size of the local cache available to the unit, in bytes. This parameter is valid only in the Shared-Storage (SS) mode. In the Shared-Nothing (SN) mode, this parameter is `NULL`, indicating that the disk space of other tenants can be used. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is available starting with V4.3.4. </p></main>   |
| MAX_IOPS              | bigint(20)   | NO         |  The upper limit of the disk IOPS specification.   |
| MIN_IOPS              | bigint(20)   | NO         |  The lower limit of the disk IOPS specification.   |
| IOPS_WEIGHT           | bigint(20)   | NO         |  The IOPS weight.   |
| MAX_NET_BANDWIDTH     | bigint(20)   | NO         |  The maximum network bandwidth of the unit, in bytes.  <main id="notice" type='explain'><h4>Note</h4><p>This parameter is available starting with V4.3.4. </p></main>    |
| NET_BANDWIDTH_WEIGHT  | bigint(20)   | NO         |  The weight of the network bandwidth of the unit. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is available starting with V4.3.4. </p></main>     |
| REPLICA_TYPE          | varchar(7)   | NO         |  The type of replica. The default value is `FULL`. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.5.x, the <code>REPLICA_TYPE</code> column is available starting with V4.5.0. </li><li>For V4.4.x, the <code>REPLICA_TYPE</code> column is available starting with V4.4.0 BP1. </li><li>For V4.2.5, the <code>REPLICA_TYPE</code> column is available starting with V4.2.5 BP7. </li></ul></main>   |
