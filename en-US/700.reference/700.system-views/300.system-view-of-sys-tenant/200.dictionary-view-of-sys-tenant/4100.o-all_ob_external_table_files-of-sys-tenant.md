# oceanbase.ALL_OB_EXTERNAL_TABLE_FILES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the list of files of external tables that the current user has access privileges to.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TABLE_NAME | varchar(256) | NO | The name of the external table. |
| TABLE_SCHEMA | varchar(128) | NO | The name of the database where the external table is located. |
| PARTITION_NAME | varchar(2) | NO | The name of the partition of the external table. |
| FILE_URL | varbinary(16384) | NO | The URL of the file of the external table. |
| FILE_SIZE | bigint(20) | NO | The size of the file, in bytes. |

## Sample query

Query the list of files of external tables that the current user has access privileges to.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.ALL_OB_EXTERNAL_TABLE_FILES;
```

The query result is as follows:

```shell
+-------------------------------+------------------+----------------+-------------------------------+-----------+
| TABLE_NAME                    | TABLE_SCHEMA     | PARTITION_NAME | FILE_URL                      | FILE_SIZE |
+-------------------------------+------------------+----------------+-------------------------------+-----------+
| __all_external_alert_log_info | sys_external_tbs | P0             | 172.xx.xxx.xxx:2882%alert.log |      6473 |
+-------------------------------+------------------+----------------+-------------------------------+-----------+
1 row in set
```
