# mysql.time_zone_transition

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the system view that contains the time zone transition information.

## Columns

|      **Column**      |   **Type**   | **Nullable** |  **Description**   |
|--------------------|------------|----------------|-----------|
| Time_zone_id       | bigint(20) | NO             | The time zone ID.     |
| Transition_time    | bigint(20) | NO             | The time zone transition time.    |
| Transition_type_id | bigint(20) | NO             | The time zone transition type ID. |
