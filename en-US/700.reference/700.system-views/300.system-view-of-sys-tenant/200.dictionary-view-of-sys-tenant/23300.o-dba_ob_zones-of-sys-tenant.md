# oceanbase.DBA_OB_ZONES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all zones.

## Columns

|  Column  |      Type       | Nullable |        Description         |
|--------|---------------|------------|-----------------------------|
| ZONE   | varchar(128)  | NO         | The name of the zone.           |
| CREATE_TIME | timestamp(6)  | NO    | The time when the zone was created.     |
| MODIFY_TIME | timestamp(6)  | NO    | The time when the zone was last modified.    |
| STATUS | varchar(4096) | NO         | The status of the zone. <li> `ACTIVE`: The zone is active and provides services.   <li> `INACTIVE`: The zone is stopped.    |
| IDC    | varchar(4096) | NO         | The IDC information of the zone.   |
| REGION | varchar(4096) | NO         | The region information of the zone.|
| TYPE   | varchar(4096) | NO         | The type of the zone. <li> `ReadWrite`: A read/write zone.   <li> `Encryption`: An encryption zone.              |

## Sample query

Query all zones in the cluster as the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONES;
```

The query result is as follows:

```shell
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC  | REGION  | TYPE      |

| zone1 | 2025-01-06 16:31:31.733840 | 2025-01-07 13:53:45.645465 | ACTIVE |      | region1 | ReadWrite |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
1 row in set
```
