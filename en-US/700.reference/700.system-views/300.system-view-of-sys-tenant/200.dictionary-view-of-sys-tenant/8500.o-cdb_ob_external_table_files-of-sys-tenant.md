# oceanbase.CDB_OB_EXTERNAL_TABLE_FILES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the list of files for all external tables created by all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| TABLE_NAME | varchar(256) | NO | The name of the external table. |
| TABLE_SCHEMA | varchar(128) | NO | The name of the database where the external table is located. |
| PARTITION_NAME | varchar(2) | NO | The name of the partition of the external table. |
| FILE_URL | varbinary(16384) | NO | The URL of the file of the external table. |
| FILE_SIZE | bigint(20) | NO | The size of the file. |

## Sample query

In the sys tenant, query the information about the external tables of the tenant with the tenant ID of 1002.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_EXTERNAL_TABLE_FILES WHERE TENANT_ID = 1002;
```

The query result is as follows:

```shell
+------------+--------------+----------------+------------------------------+-----------+
| TABLE_NAME | TABLE_SCHEMA | PARTITION_NAME | FILE_URL                     | FILE_SIZE |
+------------+--------------+----------------+------------------------------+-----------+
| ext_t3     | test         | P0             | xx.xx.xx.208:2882%data.csv   |        34 |
| ext_t2     | test         | P0             | xx.xx.xx.208:2882%data.csv   |        34 |
| ext_t1     | test         | P0             | xx.xx.xx.208:2882%data.csv   |        34 |
+------------+--------------+----------------+------------------------------+-----------+
3 rows in set
```
