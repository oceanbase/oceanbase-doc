# oceanbase.CDB_OB_TENANT_FLASHBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.5 BP4. </p>
</main>

## Overview

The `CDB_OB_TENANT_flashBACK_LOG_SCN` view displays information about each log trim operation for all tenants in the cluster.

## Columns

| field | Type | Is NULL | Description |
| ------------ | -------------- | ------------- | ------------------------------------------ |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TIMESTAMP | timestamp(6) | NO | Creation time, in microseconds |
| OP_TYPE | varchar(64) | NO | Operation type. Valid values: <ul><li>`FAILOVER_TO_PRIMARY`: The type of failover operation. When the primary tenant is unavailable, this operation switches the standby tenant to the primary tenant.</li><li>`FLASHBACK_STANDBY_LOG`: The type of log trimming operation for the standby tenant, used to trim the standby tenant's logs to a specified SCN position.</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20) | YES | End point for log trimming from the tail |
| SWITCHOVER_EPOCH | bigint(20) | YES | Tenant role switched to`NORMAL`When the status is`SWITCHOVER_EPOCH`.`SWITCHOVER_EPOCH`A unique identifier used to identify a tenant role switchover/failover operation. |

## Sample query

Query information about each log compaction in all tenants of the current cluster.

```shell
obclient [oceanbase]> SELECT * FROM CDB_OB_TENANT_FLASHBACK_LOG_SCN;
```
