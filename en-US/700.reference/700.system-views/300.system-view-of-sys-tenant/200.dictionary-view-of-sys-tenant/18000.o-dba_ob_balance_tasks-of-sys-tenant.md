# oceanbase.DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing tasks that are being executed for the current tenant. A tenant can have multiple load balancing tasks running at the same time, and these tasks belong to the same load balancing job (JOB).

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The ID of the load balancing task. |
| CREATE_TIME | timestamp(6) | YES | The time when the task was created. |
| MODIFY_TIME | timestamp(6) | YES | The time when the information was last updated. |
| TASK_TYPE | varchar(64) | NO | The type of the task. Valid values: <ul><li>`LS_SPLIT`: log stream split.  </li><li>`LS_ALTER`: modify log stream attributes. </li><li>`LS_MERGE`: log stream merge. </li><li>`LS_TRANSFER`: log stream transfer. </li></ul>|
| SRC_LS | bigint(20) | NO | The source log stream (the log data stream generated by the data source). |
| DEST_LS | bigint(20) | NO | The destination log stream. |
| PART_LIST | longtext | YES | The list of partitions, including user table partitions and global index partitions. |
| FINISHED_PART_LIST | longtext | YES | The list of partitions that have completed load balancing. |
| PART_COUNT | bigint(20) | YES | The number of partitions in the partition list. |
| FINISHED_PART_COUNT | bigint(20) | YES | The number of partitions that have completed load balancing. |
| LS_GROUP_ID | bigint(20) | NO | The ID of the log stream group. |
| STATUS | varchar(64) | NO | The status of the task. Valid values: <ul><li>`INIT`: task creation.  </li><li>`CREATE_LS`: create log stream. </li><li>`ALTER_LS`: modify log stream attributes. </li> <li>`TRANSFER`: log stream transfer. </li><li>`SET_LS_MERGING`: log stream merge. </li><li>`DROP_LS`: drop log stream. </li><li>`COMPLETED`: task execution succeeded. </li><li>`CANCELED`: task canceled. </li></ul>|
| PARENT_LIST | varchar(1024) | YES | The list of parent tasks. |
| CHILD_LIST | varchar(1024) | YES | The list of child tasks. |
| CURRENT_TRANSFER_TASK_ID | bigint(20) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | bigint(20) | NO | The ID of the job to which the current task belongs. |
| COMMENT | longtext | YES | The comment. |
| BALANCE_STRATEGY         | varchar(64)   | YES | The load balancing strategy corresponding to the balance task. Valid values: <ul><li>`LS balance by migrate`: migration-based load balancing.  </li><li>`LS balance by alter`: attribute modification-based load balancing. </li><li>`LS balance by expand`: expansion-based load balancing. </li><li>`LS balance by shrink`: reduction-based load balancing. </li><li>`partition balance`: partition-based load balancing. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this column is available starting with V4.3.2. For V4.2.x, this column is available starting with V4.2.4. </p></main>   |
