# oceanbase.CDB_TAB_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the partition information of all tenants' partitioned tables.

## Sample query

In the sys tenant, query the partition information of the partitioned table `tbl2_f_rl` for the tenant with ID 1002.

```shell
obclient [oceanbase]> SELECT CON_ID, TABLE_OWNER, TABLE_NAME, COMPOSITE, PARTITION_NAME, SUBPARTITION_COUNT, HIGH_VALUE_LENGTH, PARTITION_POSITION
   FROM oceanbase.CDB_TAB_PARTITIONS
   WHERE CON_ID=1002 AND TABLE_NAME='tbl2_f_rl';
```

The query result is as follows:

```shell
+--------+-------------+------------+-----------+----------------+--------------------+-------------------+--------------------+
| CON_ID | TABLE_OWNER | TABLE_NAME | COMPOSITE | PARTITION_NAME | SUBPARTITION_COUNT | HIGH_VALUE_LENGTH | PARTITION_POSITION |
+--------+-------------+------------+-----------+----------------+--------------------+-------------------+--------------------+
|   1002 | infotest    | tbl2_f_rl  | YES       | p0             |                  3 |                 3 |                  1 |
|   1002 | infotest    | tbl2_f_rl  | YES       | p1             |                  3 |                 3 |                  2 |
+--------+-------------+------------+-----------+----------------+--------------------+-------------------+--------------------+
2 rows in set
```
