# oceanbase.CDB_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the backup deletion policies set for tenants for expired and automatic deletion.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| POLICY_NAME | varchar(256) | NO | The name of the backup deletion policy. |
| RECOVERY_WINDOW | varchar(64) | NO | The time window for data recovery. Default value: 0. |

## Sample query

The system tenant queries the backup deletion policies of all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_POLICY;
```

The query result is as follows:

```shell
+-----------+-------------+-----------------+
| TENANT_ID | POLICY_NAME | RECOVERY_WINDOW |
+-----------+-------------+-----------------+
|      1002 | default     | 7d              |
+-----------+-------------+-----------------+
1 row in set
```
