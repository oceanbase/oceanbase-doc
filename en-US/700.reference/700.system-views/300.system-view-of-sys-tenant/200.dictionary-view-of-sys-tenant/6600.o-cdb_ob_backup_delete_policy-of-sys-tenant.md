# oceanbase.CDB_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the backup cleanup policies set for tenants for expired backup cleanup and automatic backup cleanup.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| POLICY_NAME | varchar(256) | NO | The name of the backup cleanup policy. Valid values: <ul><li>`default`: specifies to automatically clean up backups stored in the `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` parameters of the tenant. </li> <li>`log_only`: specifies to automatically clean up logs stored in the `LOG_ARCHIVE_DEST` parameter of the tenant. </li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | The time window for data recovery. Default value: 0 |

## Sample query

Query the backup cleanup policies of all tenants as the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_POLICY;
```

The query result is as follows:

```shell
+-----------+-------------+-----------------+
| TENANT_ID | POLICY_NAME | RECOVERY_WINDOW |
+-----------+-------------+-----------------+
|      1002 | default     | 7d              |
+-----------+-------------+-----------------+
1 row in set
```
