# oceanbase.CDB_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the cleanup policies for expired or automatic cleanup set for each tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| POLICY_NAME | varchar(256) | NO | The name of the cleanup policy. <ul><li>`default`: indicates that automatic cleanup is performed for the current `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` parameters of the tenant. </li> <li>`log_only`: indicates that automatic cleanup is performed for the archive path specified by the `LOG_ARCHIVE_DEST` parameter of the tenant. </li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | The recovery window. Default value: 0. |

## Sample query

Query the cleanup policies of all tenants in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_POLICY;
```

The query result is as follows:

```shell
+-----------+-------------+-----------------+
| TENANT_ID | POLICY_NAME | RECOVERY_WINDOW |
+-----------+-------------+-----------------+
|      1002 | default     | 7d              |
+-----------+-------------+-----------------+
1 row in set
```
