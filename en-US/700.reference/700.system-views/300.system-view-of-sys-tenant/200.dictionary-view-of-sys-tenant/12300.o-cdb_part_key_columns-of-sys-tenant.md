# oceanbase.CDB_PART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the columns of the primary partitioning key for partitioned tables and partitioned indexes in all tenants.

## Columns

|      **Column**      |    **Type**     | **Nullable** |                                                              **Description**                                                              |
|--------------------|---------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| CON_ID             | bigint(20)    | NO             | The tenant ID.                                         |
| OWNER              | varchar(128)  | NO             | The owner of the partitioned table or partitioned index.                                  |
| NAME               | varchar(128)  | NO             | The name of the partitioned table or partitioned index.                                   |
| OBJECT_TYPE        | varchar(5)    | NO             | The type of the partitioned object. <ul><li>TABLE   </li><li> INDEX </li></ul>   |
| COLUMN_NAME        | text          | NO             | The name of the column.                                          |
| COLUMN_POSITION    | bigint(20)    | NO             | The position of the column in the partitioning key.                                     |
| COLLATED_COLUMN_ID | bigint(0)    | NO             | This column is not supported. It is set to NULL by default.                       |

## Sample query

In the sys tenant, query the columns of the primary partitioning key for the partitioned table `tbl2_f_rl` in the tenant with ID 1002.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_PART_KEY_COLUMNS WHERE CON_ID=1002 AND NAME='tbl2_f_rl';
```

The query result is as follows:

```shell
+--------+----------+-----------+-------------+-------------+-----------------+--------------------+
| CON_ID | OWNER    | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+--------+----------+-----------+-------------+-------------+-----------------+--------------------+
|   1002 | infotest | tbl2_f_rl | TABLE       | col1        |               1 |               NULL |
+--------+----------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
