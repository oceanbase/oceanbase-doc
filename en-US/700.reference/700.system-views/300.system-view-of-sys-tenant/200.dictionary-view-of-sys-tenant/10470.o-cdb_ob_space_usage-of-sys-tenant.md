# oceanbase.CDB_OB_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

* In Shared-Storage (SS) mode, the `CDB_OB_SPACE_USAGE` view records the space occupied by different types of data for each tenant across various Endpoints and Paths.

* In Shared-Nothing (SN) mode, the `CDB_OB_SPACE_USAGE` view records the total storage space occupied by each tenant across all nodes.

## Columns

| **Column** | **Type**  | **Nullable** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| TENANT_ID   | varchar(128)  | NO   | The tenant ID.     |
| TENANT_NAME | varchar(128)  | NO   | The tenant name.     |
| ENDPOINT    | varchar(1024) | NO   | The Endpoint of the shared storage, applicable only in SS mode. In SN mode, this field is `NULL`, indicating it is undefined.      |
| PATH        | varchar(1024) | NO   | The Path of the shared storage, applicable only in SS mode. In SN mode, this field is `NULL`, indicating it is undefined.      |
| SPACE_TYPE  | varchar(11)   | NO   | <ul><li>Local Data: All macroblocks in local deployment mode. In SS mode, this includes all private data, metadata, and temporary files across all replicas of the tenant. In SN mode, this includes all data, metadata, and temporary files across all replicas of the tenant. </li><li>clog Data: clogs in local deployment mode. In SS mode, this includes all private clogs across all replicas of the tenant. In SN mode, this includes all clogs across all replicas of the tenant. </li><li>PRIVATE: Total of multi-replica and multi-version data, plus temporary files </li><li>Shared Data: The shared multi-version baseline of the tenant, applicable only in SS mode. In SN mode, this field is always `0`, indicating no shared data. </li></ul>    |
| USAGE_BYTES | decimal(42,0) | NO   | The actual disk space occupied by the data, measured in bytes.   |

## Sample query

In SN mode, query the `CDB_OB_SPACE_USAGE` view to view the total disk space occupied by each tenant across all nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SPACE_USAGE LIMIT 10;
```
