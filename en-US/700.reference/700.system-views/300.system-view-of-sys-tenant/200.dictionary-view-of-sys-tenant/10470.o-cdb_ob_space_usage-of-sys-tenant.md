# oceanbase.CDB_OB_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view was introduced in version V4.3.4. </p>
</main>

## Purpose

The `CDB_OB_SPACE_USAGE` view records the details of the storage space occupied by each tenant on all nodes.

## Columns

| **Column** | **Type**  | **Nullable?** | **Description**                               |
|------------|-------------|---------------------|----------------------------------------|
| TENANT_ID   | varchar(128)  | NO   | The tenant ID.     |
| TENANT_NAME | varchar(128)  | NO   | The tenant name.     |
| ENDPOINT    | varchar(1024) | NO   | The value of this field is `NULL`, indicating that it is undefined.      |
| PATH        | varchar(1024) | NO   | The value of this field is `NULL`, indicating that it is undefined.      |
| SPACE_TYPE  | varchar(11)   | NO   | <ul><li>Local Data: all macroblocks in the local deployment mode, including all data, all metadata, and all temporary files of all replica nodes of the tenant. </li><li>clog Data: clogs in the local deployment mode, including all clogs of all replica nodes of the tenant. </li><li>PRIVATE: the sum of multi-version baselines and temporary files. </li><li>Shared Data: the multi-version baseline shared by the tenant. The value of this field is always `0`, indicating that no data is shared. </li></ul>    |
| USAGE_BYTES | decimal(42,0) | NO   | The actual disk usage required_size of data, in bytes.   |

## Sample query

The sys tenant can view detailed information about the total disk space occupied by each tenant across all nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SPACE_USAGE LIMIT 10;
```
