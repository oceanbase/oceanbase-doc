# mysql.proc

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays information about stored procedures.

## Columns

|       **Column**       |      **Type**      | **Nullable** |                                                                                  **Description**|
|----------------------|------------------|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| db                   | varchar(128)     | NO             | The name of the database.|
| name                 | varchar(128)     | NO             | The name of the stored procedure.                                                                                |
| type                 | varchar(10)      | NO             | The type of the stored procedure. Valid values: <li> PROCEDURE: stored procedure   <li> FUNCTION: stored function                            |
| specific_name        | varchar(128)      | NO             | The same as the name column.                                                                                |
| language             | varchar(4)       | NO             | Reserved. The value is fixed to SQL.                                                                          |
| sql_data_access      | varchar(32)      | NO             | Reserved. The value is fixed to CONTAINS_SQL.                                                                 |
| is_deterministic     | varchar(4)       | NO             | Reserved. Indicates whether the stored procedure is defined with the `DETERMINISTIC` characteristic. Valid values: <li> YES  <li> NO   |
| security_type        | varchar(10)      | NO             | Reserved. Indicates the access attribute of the SQL statement. Valid values: <li> DEFINER   <li> INVOKER                                |
| param_list           | longblob | NO             | The list of parameters of the stored procedure.                                                                            |
| returns              | longblob | NO             | The return value of the stored procedure.                                                                             |
| body                 | longblob | NO             | The text of the stored procedure definition.                                                                            |
| definer              | varchar(77)      | NO             | The user who created the stored procedure.                                                                              |
| created              | timestamp(6)     | NO             | The date and time when the stored procedure was created.                                                                           |
| modified             | timestamp(6)     | NO             | The last modified date and time of the stored procedure.                                                                         |
| sql_mode             | text      | NO             | The SQL mode that is effective when the stored procedure is created or modified. The stored procedure is executed in this mode.                                                       |
| comment              | varchar(4096) | NO             | The comment text.|
| character_set_client | varchar(128)     | NO             | The session value of the character_set_client system variable when the stored procedure is created or modified.                                             |
| collation_connection | varchar(128)     | NO             | The session value of the collation_connection system variable when the stored procedure is created or modified.                                               |
| collation_database   | varchar(128)     | NO             | The session value of the collation_database system variable when the stored procedure is created or modified.                                                 |
| body_utf8            | longblob | NO             | The definition of the stored procedure. The value is the same as that of the body column.                                                                       |
