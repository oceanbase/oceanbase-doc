# oceanbase.DBA_WR_SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.3.x, this view is available starting with V4.3.5. </li> <li>For V4.2.x, this view is available starting with V4.2.2. </li></ul>
</main>

## Purpose

The `DBA_WR_SYSTEM_EVENT` view displays the persistent tenant-level wait event information of the current tenant.

## Columns

| **Column**      | **Type**    | **Nullable** | **Description**                               |
|-------------------|-------------|---------------------|----------------------------------------|
| SNAP_ID           | bigint(20)  | NO   |  Snapshot ID   |
| SVR_IP            | varchar(46) | NO   |  Node IP   |
| SVR_PORT          | bigint(20)  | NO   |  Node port number    |
| EVENT_ID          | bigint(20)  | NO   |  Wait event ID   |
| EVENT_NAME        | varchar(64) | YES  |  Wait event name    |
| WAIT_CLASS_ID     | bigint(20)  | YES  |  Wait event classification ID      |
| WAIT_CLASS        | varchar(64) | YES  |  Wait event classification name       |
| TOTAL_WAITS       | bigint(20)  | YES  |  Total number of wait events       |
| TOTAL_TIMEOUTS    | bigint(20)  | YES  |  Total number of timeouts for wait events        |
| TIME_WAITED_MICRO | bigint(20)  | YES  |  Total wait time for wait events       |

The values of the `WAIT_CLASS` column in the view indicate the wait event classification name and the corresponding wait event ID, as shown in the table below.

| Wait event classification name | Wait event ID | Description |
|------|----|------|
| OTHER | 100 | A wait event that does not belong to other classifications |
| APPLICATION | 101 | A wait event caused by client code |
| CONFIGURATION | 102 | A wait event caused by insufficient database or instance resource configuration |
| ADMINISTRATIVE | 103 | A wait event caused by a database administrator command |
| CONCURRENCY | 104 | A wait event for internal database resources |
| COMMIT | 105 | A wait event related to log commit |
| IDLE | 106 | A wait event for an inactive session |
| NETWORK | 107 | A wait event related to network communication |
| USER_IO | 108 | A wait event for user I/O |
| SYSTEM_IO | 109 | A wait event for background process I/O |
| CLUSTER | 111 | A wait event related to the cluster |
