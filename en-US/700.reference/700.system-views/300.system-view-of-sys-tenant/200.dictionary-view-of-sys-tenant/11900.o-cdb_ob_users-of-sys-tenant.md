# oceanbase.CDB_OB_USERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the user or role information under all tenants in the cluster.

## Columns

| Field Name | Field type | Whether can be NULL | Description |
| --------------------------- | --------------- | ------ | ----- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| USER_NAME | varchar(128) | NO | Username or Role Name |
| HOST | varchar(128) | NO | Server name |
| PASSWD | varchar(128) | NO | User or role password |
| INFO | varchar(4096) | NO | User or Role Information |
| PRIV_ALTER | varchar(3) | NO | Whether the user has the privilege to modify the database or table. |

| PRIV_DELETE | varchar(3) | NO | Whether the user has the permission to delete database or table records. |
| PRIV_DROP | varchar(3) | NO | Whether the user has the privilege to drop databases or tables. |

| PRIV_RELOAD | varchar(3) | NO | Whether the user has the privilege to perform a flush operation. |
| PRIV_REFERENCES | varchar(3) | NO | Whether the user has the privilege to create foreign keys. |
| PRIV_CREATE_ROLE | varchar(3) | NO | Whether the role creation permission is granted |

| PRIV_DECRYPT | varchar(3) | NO | Whether the ENHANCED_AES_DECRYPT function can be called |

| PRIV_PLAINACCESS | varchar(3) | NO | Whether plaintext access permissions exist for all sensitive rules |

| PLUGIN | varchar(64) | NO | Records the name of the plugin used for password hash calculation. Currently, only the following value is allowed: <ul><li>Empty string (equal to`mysql_native_password`(equivalent)</li><li>`ob_native_password`: Equivalent to  in Oracle-compatible mode.`mysql_native_password`</li><li>`mysql_native_password`</li><li>`caching_sha2_password`</li></ul><main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.4.2 BP2. </p></main> |
