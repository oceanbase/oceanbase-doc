# oceanbase.CDB_OB_LS_LOG_ARCHIVE_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays the log stream archive progress of all tenants for the system tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)   | NO | The tenant ID. |
| DEST_ID | bigint(20)   | NO | The archive destination ID. |
| LS_ID | bigint(20)   | NO | The log stream ID. |
| ROUND_ID | bigint(20)   | NO | The log stream round ID. |
| PIECE_ID | bigint(20)  | NO | The latest piece ID. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| START_SCN | bigint(20) unsigned | NO | The archive start SCN. |
| MIN_LSN | bigint(20) unsigned | NO | The minimum LSN of the current piece log stream. |
| MAX_LSN | bigint(20) unsigned | NO | The maximum LSN of the current piece log stream. |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | The maximum archive progress of the current piece log stream. |
| STATUS | varchar(64)  | NO | The archive status of the tenant. Valid values: <ul><li> PREPARE: the initial status when archive is enabled. </li><li>BEGINNING: the status after the basic checks for enabling archive are completed. </li><li> DOING: the normal archive status. </li><li> INTERRUPTED: the status when the archive is interrupted and cannot be resumed. </li><li> STOPPING: the status when archive is being disabled. </li><li>STOP: the status when archive is disabled. </li><li> SUSPENDING: the status when archive is being paused. </li><li> SUSPEND: the status when archive is paused. </li></ul>|
| FILE_ID  | bigint(20)  | NO | The maximum archive file ID of the current piece. |
| FILE_OFFSET  | bigint(20)  | NO | The maximum archive file offset of the current piece. |
| INPUT_BYTES  | bigint(20)  | NO | The amount of log data read. |
| OUTPUT_BYTES   | bigint(20)  | NO | The amount of archived log data. |
