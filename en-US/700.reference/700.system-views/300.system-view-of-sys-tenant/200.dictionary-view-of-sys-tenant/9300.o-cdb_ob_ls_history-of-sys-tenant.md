# oceanbase.CDB_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

Only the sys tenant can access this view, which displays all log streams that have existed in all tenants.

## Columns

| Column        | Type           | Nullable | Description                                       |
|-------------|---------------|-------------|-------------------------------------------|
| TENANT_ID   | bigint(20)    | NO          |  The tenant ID.                                   |
| LS_ID       | bigint(20)    | NO          |  The log stream ID.                                 |
| LS_GROUP_ID | bigint(20)    | NO          |  The log stream group ID.                               |
| STATUS      | varchar(100)  | NO          |  The current status of the log stream:<ul><li>CREATING: The log stream is being created.</li><li>NORMAL: The log stream is in the normal state.</li><li>DROPPING: The log stream is being dropped.</li><li>PRE_TENANT_DROPPING: A special state of the system log stream, indicating that all log streams under the tenant are being dropped.</li><li>TENANT_DROPPING: The tenant is being dropped, and the log stream is being dropped.</li><li>DROPPED: The log stream has been recycled or is being recycled.</li><li>WAIT_OFFLINE: The log stream is waiting to be recycled.</li><li>CREATE_ABORT: The log stream creation has been aborted.</li></ul>        |
| FLAG        | varchar(2048) | NO          |  The flag of the log stream:<ul><li>Empty: The log stream is in the normal state.</li><li> DUPLICATE: A broadcast log stream of a user tenant. A replicated table is created on this log stream. </li><li>BLOCK_TABLET_IN: Indicates that a tablet cannot be created on this log stream.</li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          |  The GTS when the log stream was created, in nanoseconds.              |
