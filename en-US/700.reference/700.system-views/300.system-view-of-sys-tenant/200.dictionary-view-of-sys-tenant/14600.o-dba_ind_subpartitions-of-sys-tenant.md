# oceanbase.DBA_IND_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all index subpartitions in the database.

## Columns

|          Column           |       Type        | Nullable |                    Description                    |
|-------------------------|-----------------|------------|------------------------------------------------|
| INDEX_OWNER             | varchar(128)    | NO         | The owner of the index.      |

## Sample query

```shell
obclient [infotest]> SELECT INDEX_OWNER, INDEX_NAME, PARTITION_NAME, SUBPARTITION_NAME, HIGH_VALUE, HIGH_VALUE_LENGTH, PARTITION_POSITION, SUBPARTITION_POSITION FROM oceanbase.DBA_IND_SUBPARTITIONS;
```
