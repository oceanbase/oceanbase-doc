# oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

The `DBA_OB_VECTOR_INDEX_TASK_HISTORY` view displays the historical information of vector index partition rebuild tasks in the current tenant.

## Columns

| Column | Type | Nullable | Description |
|---------------------------|---------------|------|----|
| TABLE_ID	                | bigint(20)	| YES   | The table ID. |
| TABLET_ID	                | bigint(20)	| YES   | The partition ID. |
| TASK_ID	                | bigint(20)	| YES   | The task ID. |
| START_TIME	                | timestamp(6)	| YES   | The task start time. |
| MODIFY_TIME	                | timestamp(6)	| YES   | The task end time. |
| TRIGGER_TYPE	                | varchar(16)	| NO   | The task trigger type. <ul><li><code>0</code>: automatically triggered. </li><li><code>1</code>: manually triggered. </li></ul> |
| STATUS	                | varchar(16)	| NO   | The task status. <ul><li><code>0</code>: the task is being prepared. </li><li><code>1</code>: the task is being executed. </li><li><code>2</code>: the task is paused. </li><li><code>3</code>: the task is completed. </li></ul> |
| TASK_TYPE	                | bigint(20)	| NO   | The task type. <ul><li><code>0</code>: asynchronous build. </li><li><code>1</code>: index partition rebuild. </li><li><code>5</code>: freeze dump task. </li><li><code>6</code>: major compaction task. </li></ul>     |
| TASK_SCN	                | bigint(20)	| NO   | The task version number. |
| RET_CODE	                | bigint(20)	| NO   | The task status when the task is completed. <ul><li><code>0</code>: the task is completed. </li><li><code>Non-zero</code>: the task failed. </li></ul> |
| TRACE_ID	                | varchar(512)	| NO   | The task execution trace ID. |
| TASK_INFO                  | long text    | NO   | The detailed progress information of the task. The information is in JSON format and includes details of each segment for major compaction tasks, such as the SCN, key range, index, and memory usage of each segment. This helps you understand the execution process of the task. |

## Sample query

In the sys tenant, query the historical information of vector index performance optimization tasks for all tenants.

```sql
SELECT * FROM oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY ORDER BY MODIFY_TIME DESC\G;
```

The following table describes the JSON string in the TASK_INFO field.

| Field | JSON Field Type | Description |
|---|---|---|
| merge_segments_cnt | string | The number of segments to be merged. |
| merge_segments | array | The information of the segments to be merged. The number of segments is the same as that in the merge_segments_cnt field. |
| result_segments | array | The information of the merged segments. |
| scn | string | The internal timestamp. |
| start_key | string | The upper bound of the storage range of a segment. |
| end_key | string | The lower bound of the storage range of a segment. |
| index_type | string | The index type used to process vectors in the segment. Valid values: <ul><li>HNSW</li><li>HNSW_SQ</li><li>HNSW_BQ</li><li>HGRAPH</li><li>SINDI</li></ul> |
| mem_used | string | The memory used by the segment. |
| min_vid | string | The minimum vector ID in the segment. |
| max_vid | string | The maximum vector ID in the segment. |
