# oceanbase.CDB_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status and recovery progress of all log streams of all tenants.

## Columns

| Column       | Type                | Nullable        | Description               |
|---------------|---------------------|-----------------------|--------------------|
| TENANT_ID     | bigint(20)          | NO | The ID of the tenant. |
| LS_ID         | bigint(20)          | NO | The ID of the log stream. |
| STATUS        | varchar(100)        | NO | The status of the log stream. Valid values: <ul><li>`CREATING`: The log stream is being created.</li><li>`CREATED`: The log stream has been created.</li><li>`NORMAL`: The log stream is ready to provide services.</li><li>`DROPPING`: The log stream is to be dropped. You must migrate the tablets on the log stream before it is dropped.</li><li>`TENANT DROPPING`: The log stream is to be dropped because its tenant is being dropped.</li><li>`WAIT OFFLINE`: The data of the log stream has been dropped. The log stream is waiting for garbage collection (GC).</li><li>`CREATE ABORT`: The log stream creation has failed or is not required. The log stream is to be dropped.</li></ul> |
| PRIMARY_ZONE  | longtext            | YES| The priority of the log stream for leader election. |
| UNIT_GROUP_ID | bigint(20)          | NO | The ID of the unit group. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column is available starting with V4.6.0. The value of this column is always 0. </li><li>For V4.4.x, this column is available starting with V4.4.2. The value of this column is always 0. </li><li>For V4.2.5, this column is available starting with V4.2.5 BP5. The value of this column is always 0. </li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO | The ID of the log stream group. For the system log stream (log stream 1) and broadcast log stream, this column displays 0, indicating that the log stream does not belong to any log stream group. |
| CREATE_SCN    | bigint(20) unsigned | NO | The position at which the log stream starts to write logs. |
| DROP_SCN      | bigint(20) unsigned | NO | The position at which the log stream is dropped. This position marks the end of all user data. If the log stream is dropped, this column records the SCN when the log stream is dropped. If the log stream is not dropped, this column is empty. |
| SYNC_SCN      | bigint(20) unsigned | NO | The synchronization position of the log stream. This position marks the SCN of the last transaction that is synchronized to the log stream. |
| READABLE_SCN  | bigint(20) unsigned | NO | The readable position of the log stream. This position marks the minimum SCN of the log stream that can be read. |
| FLAG          | varchar(2048)       | NO | The flag of the log stream. Valid values: <ul><li>Empty: normal log stream</li><li>DUPLICATE: the broadcast log stream of a user tenant. A duplicated table is created on this log stream. </li> <li>BLOCK_TABLET_IN: a tablet cannot be created on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: no tablet can be created on the broadcast log stream. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | The list of units where the user log stream is distributed. For the system log stream and broadcast log stream, this column is empty if no specific location is specified. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this column is available starting with V4.6.0. </li> <li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main>  |
