# mysql.db

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays database-level privileges.

## Columns

|       **Column**        |    **Type**    | **Nullable** |                                 **Description**       |
|-----------------------|--------------|----------------|------------------------------------------------------------------------|
| host                  | varchar(128) | NO             | The host name.                                                                    |
| db                    | varchar(128) | NO             | The database name.                                                                   |
| user                  | varchar(128) | NO             | The username.                                                                    |
| select_priv           | varchar(1)   | NO             | Whether the user can execute the SELECT statement.                                                        |
| insert_priv           | varchar(1)   | NO             | Whether the user can execute the INSERT statement.                                                        |
| update_priv           | varchar(1)   | NO             | Whether the user can execute the UPDATE statement.                                                        |
| delete_priv           | varchar(1)   | NO             | Whether the user can execute the DELETE statement.                                                        |
| create_priv           | varchar(1)   | NO             | Whether the user can execute the CREATE statement.                                                        |
| drop_priv             | varchar(1)   | NO             | Whether the user can execute the DROP statement.                                                          |
| grant_priv            | varchar(1)   | NO             | Whether the user can grant privileges.                                                              |
| reference_priv        | varchar(1)   | NO             | This column is not in use.                                                                   |
| index_priv            | varchar(1)   | NO             | Whether the user can create an index.                                                            |
| alter_priv            | varchar(1)   | NO             | Whether the user can execute the `ALTER TABLE` statement.                                                 |
| create_tmp_table_priv | varchar(1)   | NO             | Whether the user can create a temporary table. This column is not in use.                |
| lock_tables_priv      | varchar(1)   | NO             | Whether the user can execute the `LOCK TABLES` statement. The user must also have SELECT privileges on the table. This column is not in use. |
| create_view_priv      | varchar(1)   | NO             | Whether the user can execute the `CREATE VIEW` statement.                                                 |
| show_view_priv        | varchar(1)   | NO             | Whether the user can execute the `SHOW CREATE VIEW` statement.                                            |
| create_routine_priv   | varchar(1)   | NO             | Whether the user can create stored procedures. This column is not in use.   |
| alter_routine_priv    | varchar(1)   | NO             | Whether the user can execute the `ALTER FUNCTION` statement. This column is not in use.                         |
| execute_priv          | varchar(1)   | NO             | Whether the user can execute stored procedures. This column is not in use.      |
| event_priv            | varchar(1)   | NO             | Whether the user can create, delete, or modify events. This column is not in use.    |
| trigger_priv          | varchar(1)   | NO             | Whether the user can execute the `CREATE TRIGGER` or `DROP TRIGGER` statement. This column is not in use.   |

## Sample query

Query the database-level privileges of the `test2` user.

```shell
obclient [oceanbase]> SELECT * FROM mysql.db WHERE user='test2' \G
```
