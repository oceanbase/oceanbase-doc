# oceanbase.CDB_OB_LOB_CHECK_TASKS

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.4.2. </p>
</main>

## Purpose

The `oceanbase.CDB_OB_LOB_CHECK_TASKS` view records the progress of LOB consistency check and recovery task scans under the sys tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------------- | ----------- | --------------------- | ----------- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| LS_ID | bigint(20) | NO | The log stream ID. |
| TABLE_NAME | varchar(256) | NO | The name of the table. |
| TABLE_ID | bigint(20) | NO | The ID of the table. |
| TABLET_ID | bigint(20) | NO | The partition ID. |
| TASK_ID | bigint(20) | NO | The ID of the current batch task. |
| START_TIME | timestamp(6) | NO | The time when the task started. |
| END_TIME | timestamp(6) | NO | The time when the task ended. |
| TRIGGER_TYPE | varchar(8) | NO | The type of the task trigger. Valid values: `SYSTEM` and `USER`. |
| STATUS | varchar(10) | NO | Task status. <ul><li>LS-level task status:<ul><li>PREPARED: The task is ready and has not started scanning data.</li><li>RUNNING: The task is running and scanning data in the primary or auxiliary table.</li><li>PENDING: The task is suspended and can be resumed by using the appropriate command.</li><li>CANCELED: The task is canceled and cannot be resumed.</li><li>FINISHED: The task is completed.</li></ul></li><li>Tenant-level task status:<ul><li>TRIGGERING: Indicates that the tenant's LOB consistency verification or restore task is being triggered.</li><li>SUSPENDING: Indicates that the tenant's LOB consistency verification or restore task is being suspended.</li><li>CANCELING: Indicates that the tenant's LOB consistency verification or restore task is being canceled.</li><li>CLEANING: Indicates that the records of the LOB consistency verification or restore task are being cleaned up.</li><li>INVALID: The task is in an invalid state.</li></ul></li></ul> |
| MISS_CNT | bigint(20) | NO | The number of missing records in the auxiliary table found by the consistency check. |
| MISMATCH_LEN_CNT | bigint(20) | NO | The number of records whose `byte_len` is not equal between the primary table and the auxiliary table, as found by the consistency check. |
| ORPHAN_CNT | bigint(20) | NO | The number of residual records in the auxiliary table found by the consistency check. |
| CORRECT_CNT | bigint(20) | NO | The number of exceptions in the auxiliary table that were deleted by consistency recovery. |
| RET_CODE | varchar(512) | NO | The status when the task ends. |
| TASK_TYPE | varchar(10) | NO | The task type. Valid values: `LOB_CHECK` and `LOB_CORRECT`. |
| TASK_SCOPE | varchar(6) | NO | Task type. Valid values:<ul><li>TENANT: tenant-level task.</li><li>LS: LS-level task.</li></ul> |

## Sample query

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_LOB_CHECK_TASKS;
```
