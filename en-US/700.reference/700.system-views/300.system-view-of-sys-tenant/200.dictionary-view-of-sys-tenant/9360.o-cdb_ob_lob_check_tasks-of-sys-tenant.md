# oceanbase.CDB_OB_LOB_CHECK_TASKS

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.6.0.</p>
</main>

## Overview

The `oceanbase.CDB_OB_LOB_CHECK_TASKS` view is used to record the progress of task scans for LOB consistency verification and recovery in the sys tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------- | ----------- | --------------------- | ----------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLE_NAME | varchar(256) | NO | Table name |
| TABLE_ID | bigint(20) | NO | Table ID |
| TABLET_ID | bigint(20) | NO | Partition ID |
| TASK_ID | bigint(20) | NO | ID of the current batch task |
| START_TIME | timestamp(6) | NO | Task Start Time |
| END_TIME | timestamp(6) | NO | End Time |
| TRIGGER_TYPE | varchar(8) | NO | Task trigger type. Valid values: SYSTEM and USER. |
| STATUS | varchar(10) | NO | Task status. <ul><li>LS-level task status:<ul><li>PREPARED: The task is ready and has not started scanning data.</li><li>RUNNING: The task is running and is scanning data from the primary or auxiliary table.</li><li>PENDING: The task is suspended and can be resumed by using a command.</li><li>CANCELED: The task is canceled and cannot be resumed.</li><li>FINISHED: The task is completed.</li></ul></li><li>Tenant-level task status:<ul><li>TRIGGERING: Indicates that the tenant LOB consistency verification or restore task is being triggered.</li><li>SUSPENDING: Indicates that the tenant LOB consistency verification or restore task is being suspended.</li><li>CANCELING: Indicates that the tenant LOB consistency verification or restore task is being canceled.</li><li>CLEANING: Indicates that the LOB consistency verification or restore task records are being cleaned up.</li><li>INVALID: The task is in an invalid state.</li></ul></li></ul> |
| MISS_CNT | bigint(20) | NO | Number of Missing Data Records in the Auxiliary Table Scanned by Consistency Verification |
| MISMATCH_LEN_CNT | bigint(20) | NO | Number of Data Records with Unequal Byte Lengths Scanned in Primary and Secondary Tables during Consistency Verification |
| ORPHAN_CNT | bigint(20) | NO | Number of Residual Data in Auxiliary Tables Scanned by Consistency Verification |
| CORRECT_CNT | bigint(20) | NO | Number of Abnormalities Restored for Deleted Auxiliary Tables in Consistency Recovery |
| RET_CODE | varchar(512) | NO | Status at Task Completion |
| TASK_TYPE | varchar(10) | NO | TTL Task Type ("LOB_CHECK" or "LOB_CORRECT") |
| TASK_SCOPE | varchar(6) | NO | Task type. Valid values:<ul><li>TENANT: tenant-level task.</li><li>LS: LS-level task.</li></ul> |
