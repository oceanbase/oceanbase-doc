# oceanbase.CDB_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in V4.2.0. </p>
</main>

## Description

You can access this view only in a sys tenant. It displays all the log streams that have existed in all tenants.

## Fields

| Field        | Type           | Not null | Description                                       |
|-------------|---------------|---------|-------------------------------------------|
| TENANT_ID   | bigint(20)    | NO      | The tenant ID.                                   |
| LS_ID       | bigint(20)    | NO      | The log stream ID.                               |
| LS_GROUP_ID | bigint(20)    | NO      | The log stream group ID.                         |
| STATUS      | varchar(100)  | NO      | The current status of the log stream. The following statuses are possible: <ul><li>CREATING: The log stream is being created. </li><li>NORMAL: The log stream is in a normal state. </li><li>DROPPING: The log stream is being deleted. </li><li>PRE_TENANT_DROPPING: A special status of a system log stream, indicating the start of the deletion of all log streams in the tenant. </li><li>TENANT_DROPPING: The tenant is being deleted. The log stream is in the process of being deleted. </li><li>DROPPED: The log stream has been recycled or is being recycled. </li><li>WAIT_OFFLINE: The log stream is waiting to be recycled. </li><li>CREATE_ABORT: The log stream creation is stopped. </li></ul>        |
| FLAG        | varchar(2048) | NO      | The log stream flags. The following flags are possible: <ul><li>None: The log stream is a normal log stream. </li><li>DUPLICATE: The log stream is a broadcast log stream of a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: You cannot create a tablet on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: You cannot create a tablet on this broadcast log stream. </li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO      | The GTS when the log stream is created. The unit is nanoseconds.              |
