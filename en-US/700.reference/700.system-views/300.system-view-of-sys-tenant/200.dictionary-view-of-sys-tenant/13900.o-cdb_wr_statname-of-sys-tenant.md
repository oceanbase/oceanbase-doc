# oceanbase.CDB_WR_STATNAME

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the names of system statistics for all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | The cluster ID. |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| STAT_ID | bigint(20) | NO | The ID of the statistics. |
| STAT_NAME | varchar(64) | NO | The name of the statistics. |

## Sample query

Query the names of system statistics for all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_WR_STATNAME limit 1;
```

The result set is as follows:

```shell
+------------+-----------+---------+---------------+
| CLUSTER_ID | TENANT_ID | STAT_ID | STAT_NAME     |
+------------+-----------+---------+---------------+
|       4000 |         1 |   10000 | rpc packet in |
+------------+-----------+---------+---------------+
1 row in set (0.001 sec)
```
