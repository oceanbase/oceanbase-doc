# oceanbase.DBA_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the backup deletion policies set for tenants for expired or automatic deletion. Physical backups are not supported for the `sys` tenant and Meta tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| POLICY_NAME | varchar(256) | NO | The name of the backup deletion policy. Valid values: <ul><li>`default`: automatically deletes backups in the `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` parameters of the tenant. </li> <li>`log_only`: automatically deletes logs in the `LOG_ARCHIVE_DEST` parameter of the tenant. </li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | The time window for recovery. Default value: 0. |
