# oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information of completed `backup_set`/`backup_piece` cleanup tasks in the current tenant. The `sys` tenant and Meta tenant do not support physical backups.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task group ID, which identifies a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, which corresponds to the ID in the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: indicates that the task is to clean up a `backup_set`. </li><li>`BACKUP PIECE`: indicates that the task is to clean up a `backup_piece`. </li></ul>|
| ID | bigint(20) | NO | The task ID, which includes the IDs of a backup_set and a piece. |
| ROUND_ID | bigint(20) | NO | The destination round ID to which the piece belongs. For a backup_set cleanup task, the ROUND_ID is 0. |
| DEST_ID | bigint(20) | NO | The destination ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The time when the task started. |
| END_TIMESTAMP | timestamp(6) | NO | The time when the task ended. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`COMPLETED`: indicates that the task was executed successfully. </li><li>`FAILED`: indicates that the task failed. </li><li>`CANCELED`: indicates that the task was canceled. </li></ul> |
| TOTAL_TASK_COUNT | bigint(20) | YES | The number of subtasks. <ul><li>In SN mode, this value indicates the total number of ls_tasks. </li><li>In SS mode, this value indicates the total number of ls_tasks for a log archive piece and the total number of macro_tasks for a data backup set. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this field is available starting with V4.6.0. </p></main> |
| FINISH_TASK_COUNT | bigint(20) | YES | The number of successfully completed subtasks. <ul><li>In SN mode, this value indicates the number of completed ls_tasks. </li><li>In SS mode, this value indicates the number of completed ls_tasks for a log archive piece and the number of completed macro_tasks for a data backup set. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this field is available starting with V4.6.0. </p></main> |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set or backup_piece. |
