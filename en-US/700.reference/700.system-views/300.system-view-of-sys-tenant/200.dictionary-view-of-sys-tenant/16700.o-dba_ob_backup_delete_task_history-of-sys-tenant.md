# oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information of completed `backup_set`/`backup_piece` cleanup tasks in the current tenant. The `sys` tenant and Meta tenant do not support physical backup.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | The task group ID, which identifies a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, which corresponds to the ID in the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: clean up a `backup_set`.</li><li>`BACKUP PIECE`: clean up a `backup_piece`.</li></ul>|
| ID | bigint(20) | NO | The task ID, which includes the IDs of backup_set and piece. |
| ROUND_ID | bigint(20) | NO | The dest_round_id of the piece. For the cleanup of a backup_set, the value of ROUND_ID is 0. |
| DEST_ID | bigint(20) | NO | The destination ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the task. |
| END_TIMESTAMP | timestamp(6) | NO | The end time of the task. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`INIT`: the task is initializing. </li><li>`DOING`: the task is being executed. </li><li>`CANCELING`: the task is being canceled. </li><li>`COMPLETED`: the task is executed successfully. </li><li>`FAILED`: the task failed. </li><li>`CANCELED`: the task is canceled. </li></ul> |
| TOTAL_TASK_COUNT | bigint(20) | YES | The number of subtasks. <ul><li>In SN mode, this column indicates the number of all ls_task instances. </li><li>In SS mode, this column indicates the number of all ls_task instances for a log archive piece or the number of all macro_task instances for a data backup set. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main> |
| FINISH_TASK_COUNT | bigint(20) | YES | The number of successful subtasks. <ul><li>In SN mode, this column indicates the number of completed ls_task instances. </li><li>In SS mode, this column indicates the number of completed ls_task instances for a log archive piece or the number of completed macro_task instances for a data backup set. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.6.0. </p></main> |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set or backup_piece. |
