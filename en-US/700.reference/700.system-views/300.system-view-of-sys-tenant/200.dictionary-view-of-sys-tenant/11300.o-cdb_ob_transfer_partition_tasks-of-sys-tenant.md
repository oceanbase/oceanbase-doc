# oceanbase.CDB_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1 BP2.</p>
</main>

## Overview

The `CDB_OB_TRANSFER_PARTITION_TASKS` view displays the partition transfer tasks currently being processed by all tenants.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | User Tenant ID |
| TASK_ID | bigint(20) | NO | Unique identifier of the transfer partition task. |
| CREATE_TIME | timestamp(6) | NO | Created At |
| MODIFY_TIME | timestamp(6) | NO | Information Update Time |
| TABLE_ID | bigint(20) | NO | Table ID of the partition for which data is being transferred |
| OBJECT_ID | bigint(20) | NO | Partition of Transfer`OBJECT_ID` |
| DEST_LS | bigint(20) | NO | Destination log stream |
| BALANCE_JOB_ID | bigint(20) | NO | The associated CLB job ID during task execution. |
| TRANSFER_TASK_ID | bigint(20) | NO | Transfer task ID associated with the task during execution |
| STATUS | varchar(64) | NO | Task status:<ul><li>WAITING: The task is waiting and has not started execution.</li><li>INIT: The task has started scheduling.</li><li>DOING: The task has started executing the transfer.</li></ul> |
| COMMENT | longtext | YES | Comments |

## Sample query

Query the partition transfer tasks currently in progress for tenant 1006.

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TRANSFER_PARTITION_TASKS WHERE TENANT_ID = 1006;
```

The query result is as follows:

```shell
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TENANT_ID | TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|      1006 |       3 | 2023-12-01 11:26:43.757677 | 2023-12-01 11:27:11.192958 |   500003 |    500009 |    1001 |         760894 |             2954 | DOING  | NULL    |
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set
```
