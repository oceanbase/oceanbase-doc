# oceanbase.DBA_OB_LS_LOCATIONS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the distribution of log streams (LS) replicas of the current tenant.

## Columns

|     Column     |       Type       | Nullable |       Description        |
|--------------|----------------|------------|----------------------------------------------------------------------|
| CREATE_TIME  | datetime(6)         | NO         |   The time when the log stream was created.       |
| MODIFY_TIME  | datetime(6)         | NO         |   The time when the log stream was last modified.      |
| LS_ID        | bigint(20)          | NO         |   The ID of the log stream.       |
| SVR_IP       | varchar(46)        | NO         | The IP address of the server.       |
| SVR_PORT     | bigint(20)   | NO         | The port number of the server.          |
| SQL_PORT     | bigint(20)   | NO         | The SQL port number.         |
| ZONE         | varchar(128)  | NO         | The name of the zone.         |
| ROLE         | varchar(8)    | NO         | The role of the replica:<ul><li>`LEADER` </li><li>`FOLLOWER` </li></ul>  |
| MEMBER_LIST  | varchar(4480) | NO         | The list of replicas, separated by commas. The format of a single replica is as follows: `svr_ip:svr_port:timestamp`. The fields are described as follows:<ul><li>`svr_ip`: the IP address of the server where the replica is located</li> <li>`svr_port`: the port number of the server where the replica is located</li> <li>`timestamp`: the time when the replica joined the member list. The default value is `1`. If a replica was added or migrated, this value changes.</li></ul></br> Example: 172.xx.xxx.xxx:2882:1</li> <li>When the role is not `LEADER`, this field is `NULL`.</li></ul>   |
| PAXOS_REPLICA_NUMBER       | bigint(20)    | NO         | The number of Paxos replicas: when the role is `LEADER`, this field is valid; otherwise, it is `NULL`. |
| REPLICA_TYPE | varchar(18)   | NO         | The type of the replica:<ul><li> `FULL`: a full-featured replica </li><li> `READONLY`: a read-only replica </li></ul>  |
| LEARNER_LIST | longtext      | YES        | The list of read-only replicas of the current log stream, separated by commas. The format of a single replica is `svr_ip:svr_port:timestamp:flag`. The fields are described as follows:<ul><li>`svr_ip`: the IP address of the server where the replica is located</li> <li>`svr_port`: the port number of the server where the replica is located</li> <li>`timestamp`: the time when the replica joined. The default value is `1`. If a replica was added or migrated, this value changes.</li> <li>`flag`: indicates whether the replica is being migrated. `0` indicates that the replica is not being migrated. `2` indicates that the replica is being migrated.</li></ul></br> Example: 172.xx.xxx.xxx:2882:1:0  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| REBUILD      | varchar(5)    | NO         | Indicates whether the replica is being rebuilt. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.1. </p></main>|

## Sample query

Query the distribution of log stream replicas of the current tenant. The system tenant has only one log stream, log stream 1.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_LOCATIONS;
```
