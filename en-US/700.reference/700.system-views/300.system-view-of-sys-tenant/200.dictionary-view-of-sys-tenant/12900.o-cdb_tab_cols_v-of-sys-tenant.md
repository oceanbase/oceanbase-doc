# oceanbase.CDB_TAB_COLS_V$

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays column information for tables and views of all tenants. It is consistent with the `CDB_TAB_COLS` view, but it also includes a `NOTES` column that is not currently used.

## Columns

|         Column         |       Type        | Nullable |                                                               Description                                                                |
|----------------------|-----------------|------------|---------------|
| CON_ID               | bigint(20)      | NO         | The tenant ID.                                        |
| OWNER                | varchar(128)    | NO         | The owner of the table, view, or cluster.                                  |
| TABLE_NAME           | varchar(128)    | NO         | The name of the table, view, or cluster.                                   |
| COLUMN_NAME          | varchar(128)    | NO         | The column name.                                           |
| DATA_TYPE            | varchar(128)    | NO         | The data type of the column.                                       |
| DATA_TYPE_MOD        | varchar(3)      | NO         | `NULL` by default                                    |
| DATA_TYPE_OWNER      | varchar(128)    | NO         | `NULL` by default                                    |
| DATA_LENGTH          | bigint(21)      | NO         | The length of the column, in bytes.                                 |
| DATA_PRECISION       | bigint(20)      | NO         | The decimal precision of the `NUMBER` data type; the binary precision of the `FLOAT` data type; `NULL` for all other data types.                                                                            |
| DATA_SCALE           | bigint(20)      | NO         | The number of digits to the right of the decimal point.                                  |
| NULLABLE             | varchar(1)      | NO         | Indicates whether the column allows NULL values. This value indicates whether the column has a `NOT NULL` constraint or whether the column is part of the `PRIMARY KEY`.                                                                    |
| COLUMN_ID            | bigint(20)      | NO         | The sequence number of the created column.                                     |
| DEFAULT_LENGTH       | bigint(20)      | NO         | The length of the default value of the column.                                     |
| DATA_DEFAULT         | mediumtext | NO         | The default value of the column.                                        |
| NUM_DISTINCT         | bigint(20)      | NO         | The number of distinct values in the column.                                     |
| LOW_VALUE            | varchar(128)    | NO         | The minimum value in the column.                                         |

| DENSITY              | bigint(21)      | NO         | The density of the column.        |
| NUM_NULLS            | bigint(20)      | NO         | The number of NULL values in the column.                                   |
| NUM_BUCKETS          | bigint(20)      | NO         | The number of buckets in the histogram of the column.                                    |
| LAST_ANALYZED        | date            | NO         | The date when the column was last analyzed.                                    |
| SAMPLE_SIZE          | bigint(20)      | NO         | The sample size used for analyzing the column.                                   |
| CHARACTER_SET_NAME   | varchar(44)     | NO         | The character set name:<ul><li> `CHAR_CS`   </li><li> `NCHAR_CS` </li></ul>      |
| CHAR_COL_DECL_LENGTH | bigint(0)       | NO         | `NULL` by default                                   |
| GLOBAL_STATS         | varchar(3)      | NO         | `YES` if statistics are collected or incrementally maintained, otherwise `NO`.                                                                                  |
| USER_STATS           | varchar(3)      | NO         | Indicates whether the statistics were directly input by the user ( `YES`) or not ( `NO`).         |
| NOTES                | varchar(80)     | NO         | Records some additional attributes.                                            |
| AVG_COL_LEN          | bigint(21)      | NO         | The average length of the column, in bytes.                               |
| CHAR_LENGTH          | bigint(20)      | NO         | The length of the column displayed as characters. This value is applicable only to the following data types: <ul><li> `CHAR`   </li><li> `VARCHAR2`   </li><li> `NCHAR`   </li><li> `NVARCHAR2`  </li></ul> |
| CHAR_USED            | varchar(1)      | NO         | Indicates whether the column uses `BYTE` length semantics (`B`) or `CHAR` length semantics (`C`). If the data type is not one of the following, the value is NULL: <ul><li> `CHAR`   </li><li> `VARCHAR2`   </li><li> `NCHAR`   </li><li> `NVARCHAR2` </li></ul> |
| V80_FMT_IMAGE        | varchar(3)      | NO         | The default value is `NULL`   |
| DATA_UPGRADED        | varchar(3)      | NO         | The default value is `NULL`         |
| HIDDEN_COLUMN        | varchar(3)      | NO         | Indicates whether the column is a hidden column ( `YES`) or not ( `NO`)              |
| VIRTUAL_COLUMN       | varchar(3)      | NO         | Indicates whether the column is a virtual column ( `YES`) or not ( `NO`)               |
| SEGMENT_COLUMN_ID    | bigint(0)       | NO         | The default value is `NULL`                                       |
| INTERNAL_COLUMN_ID   | bigint(0)       | NO         | The default value is `NULL`                                      |
| HISTOGRAM            | varchar(15)     | NO         | Indicates the presence or type of histogram: <ul><li>`NONE`   </li><li> `FREQUENCY`   </li><li> `TOP-FREQUENCY`   </li><li> `HEIGHT BALANCED`   </li><li> `HYBRID` </li></ul>   |
| QUALIFIED_COL_NAME   | text            | NO         | The qualified column name                                         |
| USER_GENERATED       | varchar(3)      | NO         | Indicates the generation attribute of the column. Valid values: <ul><li>`YES`: Indicates that the column is a user-generated column. </li><li>`NO`: Indicates that the column is a system-generated column, that is, a column deleted logically but not physically. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP1. </p></main>|
| DEFAULT_ON_NULL      | varchar(3)      | NO         | The default value is `NULL`                                                                                 |
| IDENTITY_COLUMN      | varchar(3)      | NO         | The default value is `NULL`               |
| EVALUATION_EDITION   | varchar(128)    | NO         | The default value is `NULL`                         |
| UNUSABLE_BEFORE      | varchar(128)    | NO         | The default value is `NULL`                         |
| UNUSABLE_BEGINNING   | varchar(128)    | NO         | The default value is `NULL`              |
| COLLATION            | varchar(100)    | NO         | The default value is `NULL`                       |
| COLLATED_COLUMN_ID   | bigint(0)       | NO         | The default value is `NULL`                        |
