# oceanbase.CDB_OB_STORAGE_IO_USAGE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

This view displays the I/O operations of object storage and cloud disks for all tenants.

## Columns

| Column | Type | Nullable | Description |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | bigint(20)    | NO   | The ID of the tenant.     |
| PATH      | varchar(1024) | NO   | The path, for example, `oss://`, `file://`, or `s3://`.    |
| ENDPOINT  | varchar(256)  | NO   | <ul><li>In Shared-Nothing (SN) mode, the endpoint of the object storage used for backup and restore, data import, and data export. </li> <li>In Shared-Storage (SS) mode, the endpoint of the object storage used for log (clog) or data storage, backup and restore, data import, and data export. </li></ul> |
| TYPE      | varchar(128)  | NO   | The operation type. Valid values: <ul><li>`READ`: read operation</li> <li>`WRITE`: write operation</li> <li>`READ_BYTES`: the amount of network traffic entering the object storage</li> <li>`WRITE_BYTES`: the amount of network traffic leaving the object storage</li> <li>`TAG`: the tag type of the object storage. This type is not displayed for local disks and cloud disks. </li></ul>     |
| TOTAL     | bigint(20)    | NO   | The total value for each operation type (`TYPE`). <ul><li>`READ`: the number of read operations. </li> <li>`WRITE`: the number of write operations. </li> <li>`READ_BYTES`: the total amount of network traffic entering the object storage, in bytes. </li> <li>`WRITE_BYTES`: the total amount of network traffic leaving the object storage, in bytes. </li> <li>`TAG`: the total value of the tag type of the object storage. This type is not displayed for local disks and cloud disks. </li></ul>      |

## References

To query the I/O operations of object storage and cloud disks for the current tenant, query [DBA_OB_STORAGE_IO_USAGE](21820.o-dba_ob_storage_io_usage-of-sys-tenant.md).
