# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing jobs that are being executed for the current tenant. Each tenant can have only one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks (TASK) to perform the specific load balancing operations.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | The ID of the load balancing job. |
| CREATE_TIME | timestamp(6) | YES | The time when the job was created. |
| MODIFY_TIME | timestamp(6) | YES | The time when the information was last updated. |
| BALANCE_STRATEGY | varchar(64) | NO | The name of the balancing strategy. <ul><li>`LS balance by migrate`: Migration-based balancing.  </li><li>`LS balance by alter`: Alteration-based balancing. </li><li>`LS balance by expand`: Expansion-based balancing. </li><li>`LS balance by shrink`: Reduction-based balancing. </li><li>`partition balance`: Partition-based balancing. </li></ul>|
| JOB_TYPE | varchar(64) | NO | The type of the task. <ul><li>`LS_BALANCE`: Log stream balancing.  </li><li>`PARTITION_BALACNE`: Partition balancing. </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | The number of units to be changed in each zone. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field was changed to always be <code>NULL</code> starting from V4.6.0. </li> <li>For V4.4.x, this field was changed to always be <code>NULL</code> starting from V4.4.2. </li> <li>For V4.2.5, the value of this field was changed to always be <code>NULL</code> starting from V4.2.5 BP5. </li></ul></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | The number of primary zones to be changed. |
| STATUS | varchar(64) | NO | The status of the task. <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: The task was executed successfully. </li><li>`CANCELING`: The task is being canceled. </li><li>`CANCELED`: The task was canceled. </li> <li>`SUSPEND`: The task is suspended. </li></ul>|
| COMMENT | longtext | YES | The comment. |
| MAX_END_TIME | timestamp(6) | YES | The maximum end time of the load balancing task. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view was introduced starting from V4.3.4. For V4.2.x, this field was introduced starting from V4.2.4. </p></main>  |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field was introduced starting from V4.6.0. </li> <li>For V4.4.x, this field was introduced starting from V4.4.2. </li> <li>For V4.2.5, this field was introduced starting from V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | The parameters of the balancing-related configurations.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field was introduced starting from V4.6.0. </li> <li>For V4.4.x, this field was introduced starting from V4.4.2. </li> <li>For V4.2.5, this field was introduced starting from V4.2.5 BP5. </li></ul></main> |
