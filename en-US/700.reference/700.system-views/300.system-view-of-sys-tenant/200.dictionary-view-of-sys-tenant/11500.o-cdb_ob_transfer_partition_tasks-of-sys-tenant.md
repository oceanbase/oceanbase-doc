# oceanbase.CDB_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1 BP2. </p>
</main>

## Purpose

The `CDB_OB_TRANSFER_PARTITION_TASKS` view displays the current partition transfer tasks for all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID        | bigint(20)   | NO   |  The ID of the user tenant.   |
| TASK_ID          | bigint(20)   | NO   |  The unique identifier of the partition transfer task.   |
| CREATE_TIME      | timestamp(6) | NO   |  The time when the task was created.   |
| MODIFY_TIME      | timestamp(6) | NO   |  The time when the information was updated.   |
| TABLE_ID         | bigint(20)   | NO   |  The ID of the table where the partition to be transferred resides.   |
| OBJECT_ID        | bigint(20)   | NO   |  The `OBJECT_ID` of the partition to be transferred.   |
| DEST_LS          | bigint(20)   | NO   |  The log stream on the destination.   |
| BALANCE_JOB_ID   | bigint(20)   | NO   |  The ID of the load balancing job associated with the task.   |
| TRANSFER_TASK_ID | bigint(20)   | NO   |  The ID of the partition transfer task associated with the task.   |
| STATUS           | varchar(64)  | NO   |  The status of the task:<ul><li>WAITING: The task is waiting to be executed. </li><li>INIT: The task is being scheduled. </li><li>DOING: The task is being executed. </li></ul>   |
| COMMENT          | longtext     | YES  |  The comment.   |

## Sample query

Query the partition transfer tasks for tenant 1006.

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TRANSFER_PARTITION_TASKS WHERE TENANT_ID = 1006;
```

The query result is as follows:

```shell
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TENANT_ID | TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|      1006 |       3 | 2023-12-01 11:26:43.757677 | 2023-12-01 11:27:11.192958 |   500003 |    500009 |    1001 |         760894 |             2954 | DOING  | NULL    |
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set
```
