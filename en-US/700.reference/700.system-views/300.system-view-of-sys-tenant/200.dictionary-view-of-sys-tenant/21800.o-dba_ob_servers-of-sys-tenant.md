# oceanbase.DBA_OB_SERVERS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about all OBServer nodes.

## Columns

|         Column          |      Type      | Nullable |                        Description                        |
|-----------------------|--------------|------------|----------------------------------------------------------------------------|
| SVR_IP                | varchar(46)  | NO         | The IP address of the server.                                        |
| SVR_PORT              | bigint(20)   | NO         | The port number of the server.                                           |
| ID                    | bigint(20)   | NO         | The unique ID assigned to the cluster.                                     |
| ZONE                  | varchar(128) | NO         | The zone to which the OBServer node belongs.                                |
| SQL_PORT              | bigint(20)   | NO         | The port used by the OBServer node to service SQL requests.                          |
| WITH_ROOTSERVER       | varchar(3)   | NO         | <ul><li>`YES`: The Root Service is available. </li><li>`NO`: The Root Service is unavailable.</li></ul>  |
| STATUS                | varchar(64)  | NO         | <ul><li>`ACTIVE`: The OBServer node is in normal communication with the Root Service. </li><li>`INACTIVE`: The OBServer node has lost communication with the Root Service. </li><li>`DELETING`: The OBServer node is being deleted.</li></ul>    |
| START_SERVICE_TIME    | timestamp(6) | NO         | The time when the node can start to provide services after the node process is started:<ul><li>`NULL`: The node process is not started or the node status is unavailable.   </li><li> Valid value: The time when the node can start to provide services after the node process is started.</li></ul>  |
| STOP_TIME             | timestamp(6) | NO         | The time when the user manually stops the node service:<ul><li>`NULL`: The node has not been stopped.   </li><li> Valid value: The time when the OBServer node is stopped.</li></ul>  |
| BLOCK_MIGRATE_IN_TIME | timestamp(6) | NO         | The time when the OBServer node is prohibited from migrating in data:<ul><li>`NULL`: Data migration in is not prohibited.   </li><li> Valid value: The time when data migration in is prohibited.</li></ul>  |
|CREATE_TIME            | timestamp(6) | YES        |The creation time of the table.|
|MODIFY_TIME            | timestamp(6) | YES        |The last modification time of the task.|
| BUILD_VERSION         | varchar(256) | NO         | The binary build version of the OBServer node.      |
| LAST_OFFLINE_TIME     | timestamp(6) | NO         | The last offline time of the OBServer node:<ul><li> `NULL`: The OBServer node has never been offline.   </li><li> Valid value: The last offline time of the OBServer node.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main>      |

Query the information about all OBServer nodes in the cluster as the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SERVERS\G
```
