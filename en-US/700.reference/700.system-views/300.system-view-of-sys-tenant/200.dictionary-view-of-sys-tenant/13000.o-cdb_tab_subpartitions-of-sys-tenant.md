# oceanbase.CDB_TAB_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the subpartition information for all tenant partitioned tables, including the subpartition name, table and partition name, storage attributes, and statistics generated by the `DBMS_STATS` package.

## Sample query

