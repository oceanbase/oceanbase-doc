# oceanbase.DBA_OB_TABLE_LOCATIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the locations of tables and partitions, including system tables, user tables, and index tables.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DATABASE_NAME | varchar(128) | NO | The name of the database. |
| TABLE_NAME | varchar(256) | NO | The name of the table. |
| TABLE_ID | bigint(20) | NO | The ID of the table. |
| TABLE_TYPE | varchar(13) | NO | The type of the table. Valid values: <ul><li>USER TABLE: a user table. </li><li>SYSTEM TABLE: a system table. </li><li>INDEX: an index table. </li><li>LOB AUX TABLE: a LOB auxiliary table. </li></ul> |
| PARTITION_NAME | varchar(64) | NO | The name of the partition. If the table is not partitioned, this column is NULL. |
| SUBPARTITION_NAME | varchar(64) | NO | The name of the subpartition. If the table has no subpartitions, this column is NULL. |
| INDEX_NAME | varchar(256) | NO | The name of the index table. If the table is not an index table, this column is NULL. |
| DATA_TABLE_ID | bigint(20) | NO | The ID of the table to which the index table or LOB auxiliary table belongs. If the table is not an index table or LOB auxiliary table, this column is NULL. |
| TABLET_ID | bigint(20) | NO | The ID of the tablet. |
| LS_ID | bigint(20) | NO | The ID of the log stream to which the object belongs. |
| ZONE | varchar(128) | NO | The zone where the replica is located. |
| SVR_IP | varchar(46) | NO | The IP address of the server where the replica is located. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the replica is located. |
| ROLE | varchar(8) | NO | The role of the replica. |
| REPLICA_TYPE | varchar(18) | NO | The type of the log stream replica. Valid values: <ul><li>`FULL`: a full-featured replica. </li><li>`READONLY`: a read-only replica. </li><li>`COLUMNSTORE`: a columnstore replica. </li></ul>  |
| DUPLICATE_SCOPE | varchar(7) | NO | The value indicates whether the table is a replicated table. Valid values: <ul><li>`CLUSTER`: a replicated table.  </li><li>`NONE`: a regular table. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| DUPLICATE_READ_CONSISTENCY | varchar(6) | NO | The value indicates the read consistency constraint of the standby replica of a replicated table. Valid values: <ul><li>`NONE`: indicates that the table is not a replicated table. This value is meaningless. </li><li>`STRONG`: indicates that the standby replica of a replicated table supports strong consistency reads. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>|
| OBJECT_ID | bigint(20) | NO | The ID of the partition. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| TABLEGROUP_NAME | varchar(128) | NO | The name of the table group to which the table belongs. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| TABLEGROUP_ID | bigint(20) | NO | The ID of the table group to which the table belongs. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| SHARDING | varchar(20) | NO | The sharding attribute (balance mode) of the table group to which the table belongs. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main> |
| INDEX_TYPE                 | varchar(6)   | NO   | The value indicates the `GLOBAL`/`LOCAL` attribute of the index of an index table. Valid values: <ul><li>`NULL`: indicates that the table is not an index table. </li><li>`GLOBAL`: indicates that the index is a global index. Valid values: `INDEX_TYPE_NORMAL_GLOBAL`, `INDEX_TYPE_UNIQUE_GLOBAL`, and `INDEX_TYPE_SPATIAL_GLOBAL`. </li><li>`LOCAL`: indicates that the index is a local index. Valid values: `INDEX_TYPE_NORMAL_LOCAL`, `INDEX_TYPE_UNIQUE_LOCAL`, `INDEX_TYPE_PRIMARY`, `INDEX_TYPE_DOMAIN_CTXCAT`, `INDEX_TYPE_NORMAL_GLOBAL_LOCAL_STORAGE`, `INDEX_TYPE_UNIQUE_GLOBAL_LOCAL_STORAGE`, `INDEX_TYPE_SPATIAL_LOCAL`, and `INDEX_TYPE_SPATIAL_GLOBAL_LOCAL_STORAGE`. </li></ul> <main id="notice" type='explain'><h4>Note</h4><ul><li>For OceanBase Database V4.4.x, this column is available starting with V4.4.1. </li> <li>For OceanBase Database V4.2.5, this column is available starting with V4.2.5 BP2. </li></ul></main>     |

Query the location of the `t1` table.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLE_LOCATIONS WHERE TABLE_NAME='t1'\G
```
