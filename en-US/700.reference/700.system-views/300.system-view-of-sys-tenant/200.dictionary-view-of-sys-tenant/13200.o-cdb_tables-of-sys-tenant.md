# oceanbase.CDB_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the TABLE information for all tenants.

## Sample query

In the sys tenant, query the information about the table `tbl1` in the tenant with ID 1002.

```shell
obclient [oceanbase]> SELECT CON_ID, OWNER, TABLE_NAME, STATUS, PCT_FREE, TEMPORARY, NESTED, ROW_MOVEMENT, DROPPED, EXTERNAL FROM oceanbase.CDB_TABLES WHERE CON_ID=1002 AND TABLE_NAME = 'tbl1';
```
