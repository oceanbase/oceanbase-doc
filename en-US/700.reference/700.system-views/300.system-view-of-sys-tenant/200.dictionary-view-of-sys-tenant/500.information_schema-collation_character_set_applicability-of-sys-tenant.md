# information_schema.COLLATION_CHARACTER_SET_APPLICABILITY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view records the correspondence between Character and Collation.

## Columns

|      **Column**      |    **Type**    | **Nullable** | **Description** |
|--------------------|--------------|----------------|--------|
| COLLATION_NAME     | varchar(128) | NO             | The name of the collation method. |
| CHARACTER_SET_NAME | varchar(128) | NO             | The name of the character set.  |

## Sample query

Query the correspondence between Character and Collation in the database and display the first 10 records.

```shell
obclient [infotest]> SELECT * FROM information_schema.COLLATION_CHARACTER_SET_APPLICABILITY LIMIT 10;
```
