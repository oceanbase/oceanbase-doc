# mysql.help_category

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view, along with the `mysql.help_relation`, `mysql.help_topic`, and `mysql.help_keyword` views, generates help commands.

## Columns

|      **Column**      |     **Type**     | **Nullable** | **Description** |
|--------------------|----------------|----------------|--------|
| help_category_id   | bigint(20)     | NO             | The category ID.  |
| name               | varchar(64)    | NO             | The category name.    |
| parent_category_id | bigint(20)     | YES            | The parent category ID. |
| url                | varchar(65535) | NO             | The URL address. |
