# mysql.time_zone

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays information about time zones.

## Columns

|     **Column**     |   **Type**   | **Nullable** | **Description** |
|------------------|------------|-----------------|--------|
| Time_zone_id     | bigint(20) | NO              | The time zone ID.  |
| Use_leap_seconds | varchar(8) | NO              | Indicates whether to use leap seconds. |
