# CDB_MVIEW_LOGS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.0. </p>
</main>

## Purpose

The `CDB_MVIEW_LOGS` view displays information about all materialized view logs.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| LOG_OWNER | varchar(128) | NO | The name of the materialized view log owner. |
| MASTER | varchar(128) | NO | The name of the master table to which the materialized view log belongs. |
| LOG_TABLE | varchar(128) | NO | The name of the materialized view log table. |
| LOG_TRIGGER | varchar(128) | YES | The row-level trigger on the master table that inserts rows into the materialized view log. <main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NULL. </p></main> |
| ROWIDS | varchar(3) | NO | Indicates whether to record rowid information. <ul><li> YES </li><li>NO </li></ul>|
| PRIMARY_KEY | varchar(3) | NO | Indicates whether to record primary key information. <ul><li> YES </li><li>NO </li></ul>|
| OBJECT_ID | varchar(3) | NO | Indicates whether to record object identifier information in the object table. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NO. </p></main> |
| FILTER_COLUMNS | varchar(3) | NO | Indicates whether to record filter column information. <ul><li> YES </li><li>NO </li></ul>|
| SEQUENCE | varchar(3) | NO | Indicates whether to record sequence values that provide additional sorting information. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| INCLUDE_NEW_VALUES | varchar(3) | NO | Indicates whether to record both the old and new values. <ul><li>YES: Record both the old and new values.  </li><li>NO: Record only the old values. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| PURGE_ASYNCHRONOUS | varchar(3) | NO | Indicates whether the materialized view log is asynchronously purged. <ul><li> YES </li><li>NO </li></ul>|
| PURGE_DEFERRED | varchar(3) | NO | Indicates whether to purge the materialized view log in a deferred manner. <ul><li> YES </li><li>NO </li></ul>|
| PURGE_START | datetime | YES | The start date of the deferred purge. |
| PURGE_INTERVAL | varchar(200) | YES | The interval between deferred purges. |
| LAST_PURGE_DATE | datetime | YES | The date when the materialized view log was last purged. |
| LAST_PURGE_STATUS | bigint(1) | NO | The status of the last purge of the materialized view log. <ul><li> Error code  </li><li>0: The purge was successful. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always 0. </p></main> |
| NUM_ROWS_PURGED | bigint(20) | YES | The number of rows purged in the last purge of the materialized view log. |
| COMMIT_SCN_BASED | varchar(3) | NO | Indicates whether the materialized view log is based on commit SCN. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this column is always YES. </p></main> |
| STAGING_LOG | varchar(3) | NO | Indicates whether the materialized view log is a staging log for synchronous refresh. <ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This column is for compatibility only. The default value is NO. </p></main> |
| PURGE_DOP          | bigint(20)   | NO   | The parallelism for purging the materialized view log.<main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP2. </p></main>|
| LAST_PURGE_TIME    | bigint(20)   | YES  | The duration of the last materialized view log purge task, in seconds.<main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this column is available starting from V4.3.5 BP2. </p></main>|
| LAST_PURGE_METHOD  | varchar(16)  | NO   | The method used in the last materialized view log purge task. Valid values: <ul><li>SQL </li><li>COMPACTION</li></ul> If no materialized view log purge task has been performed, this column displays NULL. <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.6.x, this column is available starting from V4.6.0. </p></main>|

## Sample query

Query all materialized view logs and display the first record.

```shell
obclient [(none)]> SELECT * FROM oceanbase.CDB_MVIEW_LOGS LIMIT 1\G
```
