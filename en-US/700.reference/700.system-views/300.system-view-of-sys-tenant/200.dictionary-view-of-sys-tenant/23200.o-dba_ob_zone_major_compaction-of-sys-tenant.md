# oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the major compaction information of each zone in the current tenant.

## Columns

|       Column        |      Type      | Nullable |         Description         |
|-------------------|--------------|------------|------------------|
| ZONE              | varchar(128) | NO         | The name of the zone.            |
| BROADCAST_SCN | bigint(20) unsigned   | NO         | The version number of the broadcast major compaction.           |
| LAST_SCN      | bigint(20) unsigned   | NO         | The version number of the last major compaction.          |
| LAST_FINISH_TIME  | timestamp(6)   | NO         | The end time of the last major compaction.          |
| START_TIME        | timestamp(6)   | NO         | The start time of the major compaction.             |
| STATUS            | varchar(10)  | NO         | <ul><li> `IDLE`: no major compaction is in progress.  </li><li>`COMPACTING`: a major compaction is in progress. </li></ul>  |

## Sample query

Query the major compaction information of each zone in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION;
```

The query result is as follows:

```shell
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| ZONE  | BROADCAST_SCN       | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| zone1 | 1736445603362416000 | 1736445603362416000 | 2025-01-10 02:02:17.252947 | 2025-01-10 02:00:03.403496 | IDLE   |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
1 row in set
```
