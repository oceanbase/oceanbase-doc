# oceanbase.DBA_OB_UNITS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the unit information for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------------- | -------------- | ------------ | -------------------- |
| UNIT_ID | bigint(20) | NO | Unit ID |
| TENANT_ID | bigint(20) | NO | Tenant ID of the unit: <ul><li>`NULL`: The current unit does not belong to any tenant.   </li><li> Valid value: target tenant ID. </li></ul> |
| STATUS | varchar(128) | NO | <ul><li> `ACTIVE`: Normal status.   </li> <li>`ADDING`: Adding status</li> <li>`DELETING`: Deleting</li></ul> |
| RESOURCE_POOL_ID | bigint(20) | NO | ID of the resource pool to which the unit belongs. |
| UNIT_GROUP_ID | bigint(20) | NO | Unit Group ID of the unit |
| CREATE_TIME | timestamp(6) | YES | Unit creation time |
| MODIFY_TIME | timestamp(6) | YES | Unit Modified At |
| ZONE | varchar(128) | NO | Zone Name |
| SVR_IP | varchar(46) | NO | IP Address of the OBServer Where the Unit Belongs |
| SVR_PORT | bigint(20) | NO | OBServer Port Number of the Unit |
| MIGRATE_FROM_SVR_IP | varchar(46) | NO | <ul><li> `NULL`: The unit is not being migrated. </li><li> Valid value: The unit is being migrated, indicating the IP address of the source server for migration. </li></ul> |
| MIGRATE_FROM_SVR_PORT | bigint(20) | NO | <ul><li> `NULL`: The unit is not being migrated.  </li><li>Valid values: The unit is being migrated, indicating the port number of the source server for migration.  </li></ul> |
| MANUAL_MIGRATE | varchar(3) | NO | <ul><li> `NULL`: Unit not involved in migration. </li><li>`YES`: Manually initiated unit migration   </li><li>`NO`: Automatically initiated unit migration. </li></ul> |
| UNIT_CONFIG_ID | bigint(20) | NO | Unit Specification ID |
| MAX_CPU | double | NO | Maximum CPU Specification |
| MIN_CPU | double | NO | Minimum CPU Specification |
| MEMORY_SIZE | bigint(20) | NO | Memory specification, in bytes |
| LOG_DISK_SIZE | bigint(20) | NO | Log disk specification, in bytes |
| MAX_IOPS | bigint(20) | NO | Maximum Disk IOPS Specification |
| MIN_IOPS | bigint(20) | NO | Minimum Disk IOPS Specification |
| IOPS_WEIGHT | bigint(20) | NO | IOPS Weight |
| REPLICA_TYPE | varchar(7) | NO | Replica type. Default value:`FULL`<main id="notice" type='explain'><h4>Note</h4><p>The <code>REPLICA_TYPE</code> field is available starting with V4.2.5 BP7.</p></main> |
