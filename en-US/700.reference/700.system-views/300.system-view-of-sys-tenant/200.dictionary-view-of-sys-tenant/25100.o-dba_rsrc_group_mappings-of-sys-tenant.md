# oceanbase.DBA_RSRC_GROUP_MAPPINGS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.4. </p>
</main>

## Purpose

This view displays the binding relationships between users and resource groups in the current tenant.

## Columns

|      Column      |       Type       | Nullable |                Description                 |
|----------------|----------------|------------|-----------------------------------|
| ATTRIBUTE      | varchar(128)  | NO         | The category. Valid value: `ORACLE_USER`.         |
| VALUE          | varbinary(128) | NO         | The value. If the category is `ORACLE_USER`, the value is the login username. |
| CONSUMER_GROUP | varchar(128)  | YES        | The name of the resource group to which the user is bound.                     |
| STATUS         | varchar(128)  | NO         | The status of the resource group. This column is reserved for compatibility. The value is fixed to `NULL`.       |

## Sample query

Query the binding relationships between users and resource groups in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_GROUP_MAPPINGS;
```

The query result is as follows:

```shell
+-----------+-------+-------------------+--------+
| ATTRIBUTE | VALUE | CONSUMER_GROUP    | STATUS |
+-----------+-------+-------------------+--------+
| user      | root  | interactive_group | NULL   |
+-----------+-------+-------------------+--------+
1 row in set
```
