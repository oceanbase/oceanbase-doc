# oceanbase.CDB_OB_BACKUP_STORAGE_INFO_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information about the backup destinations used for backup and restore operations for all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| PATH | varchar(1024) | NO | The root path for backup. |
| ENDPOINT | varchar(256) | NO | The HOST for accessing the object storage service. |
| DEST_ID | bigint(20) | YES | The ID of the backup destination. |
| DEST_TYPE | varchar(64) | YES | The type of the backup destination. Valid values: <ul><li>`archive_log`: log archiving</li> <li>`backup_data`: data backup</li></ul>|
| AUTHORIZATION | varchar(1024) | NO | The authorization information for the object storage service. |
| EXTENSION | varchar(512) | NO | The additional parameters of the backup destination. |
| CHECK_FILE_NAME | varchar(256) | YES | The name of the file for checking connectivity. |
| LAST_CHECK_TIMESTAMP | timestamp(6) | YES | The time when the last connectivity check was successful. |
| MAX_IOPS             | bigint(20)   | NO | The maximum IOPS allowed for the backup medium used for backup. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>    |
| MAX_BANDWIDTH        | bigint(20)   | NO | The maximum bandwidth allowed for the backup medium used for backup, in bytes. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>      |
| MAX_BANDWIDTH_DISPLAY| varchar(29)  | NO | The maximum bandwidth after conversion. The format is similar to 10GB/s or 10MB/s. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>      |
