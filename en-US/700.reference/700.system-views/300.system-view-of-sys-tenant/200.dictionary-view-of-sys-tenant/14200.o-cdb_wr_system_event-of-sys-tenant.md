# oceanbase.CDB_WR_SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.3.x, this view is available starting with V4.3.5. </li> <li>For V4.2.x, this view is available starting with V4.2.2. </li></ul>
</main>

## Purpose

The `CDB_WR_SYSTEM_EVENT` view displays the persistent tenant-level waiting events of all tenants.

## Columns

| **Column**      | **Type**    | **Nullable** | **Description**                               |
|-------------------|-------------|---------------------|----------------------------------------|
| TENANT_ID         | bigint(20)  | NO   |  The tenant ID. |
| CLUSTER_ID        | bigint(20)  | NO   |  The cluster ID.  |
| SNAP_ID           | bigint(20)  | NO   |  The snapshot ID.   |
| SVR_IP            | varchar(46) | NO   |  The IP address of the node.   |
| SVR_PORT          | bigint(20)  | NO   |  The port number of the node.    |
| EVENT_ID          | bigint(20)  | NO   |  The waiting event ID.   |
| EVENT_NAME        | varchar(64) | YES  |  The name of the waiting event.    |
| WAIT_CLASS_ID     | bigint(20)  | YES  |  The ID of the waiting event category.      |
| WAIT_CLASS        | varchar(64) | YES  |  The name of the waiting event category.       |
| TOTAL_WAITS       | bigint(20)  | YES  |  The total number of waits for the waiting event.       |
| TOTAL_TIMEOUTS    | bigint(20)  | YES  |  The total number of timeouts for the waiting event.        |
| TIME_WAITED_MICRO | bigint(20)  | YES  |  The total waiting time for the waiting event.       |

The `WAIT_CLASS` column in the view lists the waiting event categories. The following table describes the waiting event categories and their corresponding IDs.

| Waiting event category | Waiting event ID | Description |
|------|----|------|
| OTHER | 100 | A waiting event that does not belong to any other category. |
| APPLICATION | 101 | A waiting event caused by client code. |
| CONFIGURATION | 102 | A waiting event caused by insufficient database or instance resources. |
| ADMINISTRATIVE | 103 | A waiting event caused by a database administrator command. |
| CONCURRENCY | 104 | A waiting event for internal database resources. |
| COMMIT | 105 | A waiting event related to log submission. |
| IDLE | 106 | A waiting event for a session that is not active. |
| NETWORK | 107 | A waiting event related to network communication. |
| USER_IO | 108 | A waiting event for user I/O. |
| SYSTEM_IO | 109 | A waiting event for background process I/O. |
| CLUSTER | 111 | A waiting event related to a cluster. |

## Sample query

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_WR_SYSTEM_EVENT WHERE TENANT_ID= 1004 LIMIT 10;
```
