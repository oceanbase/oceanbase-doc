# oceanbase.DBA_PART_TABLES

## Purpose

The `oceanbase.DBA_PART_TABLES` view provides information about a partitioned table.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V4.0.0. </p>
</main>

## Columns

| **Column**           | **Type**       | **Nullable?** | **Description**                                                                 |
|---------------------------|----------------|--------------|---------------------------------------------------------------------------------|
| OWNER                    | varchar(128)   | NO           | The owner of the partitioned table.                                            |
| TABLE_NAME               | varchar(128)   | NO           | The name of the partitioned table.                                             |
| PARTITIONING_TYPE        | varchar(13)    | NO           | The partitioning type: <li>HASH</li><li>RANGE</li><li>LIST</li>                    |
| SUBPARTITIONING_TYPE     | varchar(13)    | NO           | The subpartitioning type: <li>HASH</li><li>RANGE</li><li>LIST</li>                 |
| PARTITION_COUNT          | bigint(20)     | NO           | The number of partitions in the table.                                         |
| DEF_SUBPARTITION_COUNT   | bigint(20)     | NO           | For composite partitions, this column indicates the number of subpartitions.          |
| PARTITIONING_KEY_COUNT   | bigint(21)     | NO           | The number of partitioning keys.                                               |
| SUBPARTITIONING_KEY_COUNT| bigint(21)     | NO           | For composite partitions, this column indicates the number of subpartitioning keys.   |
| STATUS                   | varchar(8)     | NO           | This column is currently not supported and defaults to `NULL`.                 |
| DEF_TABLESPACE_NAME      | varchar(30)    | NO           | The name of the tablespace for the partitioned table.                          |
| DEF_PCT_FREE             | bigint(0)      | NO           | This column is currently not supported and defaults to `NULL`.                 |
| DEF_PCT_USED             | bigint(0)      | NO           | This column is currently not supported and defaults to `NULL`.                 |

| DEF_NEXT_EXTENT          | varchar(40)    | NO           | This column is currently not supported and defaults to `NULL`.                 |

| DEF_MAX_EXTENTS          | varchar(40)    | NO           | This column is currently not supported and defaults to `NULL`.                 |

| DEF_PCT_INCREASE         | varchar(40)    | NO           | This column is currently not supported and defaults to `NULL`.                 |
| DEF_FREELISTS            | bigint(0)      | NO           | This column is currently not supported and defaults to `NULL`.                 |

| DEF_BUFFER_POOL          | varchar(7)     | NO           | This column is currently not supported and defaults to `NULL`.                 |
