# oceanbase.DBA_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the history of load balancing jobs executed in the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | The ID of the load balancing job. |
| CREATE_TIME | timestamp(6) | NO | The time when the job was created. |
| FINISH_TIME | timestamp(6) | NO | The time when the job was completed, including the time when it was successfully completed or canceled. |
| BALANCE_STRATEGY | varchar(64) | NO | The name of the balancing strategy. <ul><li>`LS balance by migrate`: migration-based balancing.  </li><li>`LS balance by alter`: log stream attribute modification-based balancing. </li><li>`LS balance by expand`: expansion-based balancing. </li><li>`LS balance by shrink`: reduction-based balancing. </li><li>`partition balance`: partition-based balancing. </li></ul>|
| JOB_TYPE | varchar(64) | NO | The type of the task. <ul><li>`LS_BALANCE`: log stream balancing.  </li><li>`PARTITION_BALANCE`: partition balancing. </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | The number of units in each zone that is changed. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is always <code>NULL</code> starting with V4.4.2. </li> <li>For V4.2.5, this column is always <code>NULL</code> starting with V4.2.5 BP5. </li></ul></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | The number of primary zones that are changed. |
| STATUS | varchar(64) | NO | The status of the task. <ul><li>`COMPLETED`: The task is successfully executed. </li><li>`CANCELED`: The task is canceled. </li></ul>|
| COMMENT | longtext | YES | The comment. |
| MAX_END_TIME            | timestamp(6) | YES | The maximum end time of the load balancing task. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view is available starting with V4.3.4. For V4.2.x, this column is available starting with V4.2.4. </p></main>     |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | The parameters of the balancing-related configurations.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this column is available starting with V4.4.2. </li> <li>For V4.2.5, this column is available starting with V4.2.5 BP5. </li></ul></main> |
