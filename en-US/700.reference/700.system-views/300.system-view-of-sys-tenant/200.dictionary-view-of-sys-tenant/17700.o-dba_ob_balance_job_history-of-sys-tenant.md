# oceanbase.DBA_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the history of load balancing jobs executed on all nodes under the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | The ID of the load balancing job. |
| CREATE_TIME | timestamp(6) | NO | The time when the job was created. |
| FINISH_TIME | timestamp(6) | NO | The time when the job was completed. This field includes both the successful completion time and the cancellation time. |
| BALANCE_STRATEGY | varchar(64) | NO | The name of the balancing strategy. <ul><li>`LS balance by migrate`: Migration-based balancing.  </li><li>`LS balance by alter`: Log stream attribute modification-based balancing. </li><li>`LS balance by expand`: Expansion-based balancing. </li><li>`LS balance by shrink`: Reduction-based balancing. </li><li>`partition balance`: Partition-based balancing. </li></ul>|
| JOB_TYPE | varchar(64) | NO | The type of the task. <ul><li>`LS_BALANCE`: Log stream balancing.  </li><li>`PARTITION_BALACNE`: Partition balancing. </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | The number of units in each zone that are to be changed. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field is always <code>NULL</code> starting from V4.6.0. </li><li>For V4.4.x, this field is always <code>NULL</code> starting from V4.4.2. </li> <li>For V4.2.5, this field is always <code>NULL</code> starting from V4.2.5 BP5. </li></ul></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | The number of primary zones to be changed. |
| STATUS | varchar(64) | NO | The status of the task.  <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: The job was successfully executed. </li><li>`CANCELING`: The job is being canceled. </li><li>`CANCELED`: The job was canceled. </li></ul>|
| COMMENT | longtext | YES | The comment. |
| MAX_END_TIME            | timestamp(6) | YES | The maximum end time of the load balancing task. <main id="notice" type='explain'><h4>Note</h4><p>For V4.3.x, this view is available starting from V4.3.4. For V4.2.x, this field is available starting from V4.2.4. </p></main>     |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | The number of units in each zone of the tenant. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field is available starting from V4.6.0. </li> <li>For V4.4.x, this field is available starting from V4.4.2. </li> <li>For V4.2.5, this field is available starting from V4.2.5 BP5. </li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | The parameters of the balancing-related configurations.  <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field is available starting from V4.6.0. </li> <li>For V4.4.x, this field is available starting from V4.4.2. </li> <li>For V4.2.5, this field is available starting from V4.2.5 BP5. </li></ul></main> |
