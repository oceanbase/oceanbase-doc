# oceanbase.CDB_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.2. </p>
</main>

## Overview

The `CDB_WR_SQLSTAT` view displays basic performance statistics for all SQL statements executed by tenants. Each SQL statement is represented as a row (i.e., each unique combination of `SQL_ID` and `Plan_Hash` corresponds to one row). A column containing `_DELTA` indicates the incremental value of the statistic from the time the last WR snapshot was collected until the current time.
