# oceanbase.CDB_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.2.</p>
</main>

## Purpose

The `CDB_WR_SQLSTAT` view displays basic performance statistics of SQL statements executed by all tenants, with each SQL statement in one row (that is, each unique value of `SQL_ID` + `Plan_Hash` in one row). Columns that contain `_DELTA` indicate the increment of the statistical values from the last collected WR snapshot to the current time.
