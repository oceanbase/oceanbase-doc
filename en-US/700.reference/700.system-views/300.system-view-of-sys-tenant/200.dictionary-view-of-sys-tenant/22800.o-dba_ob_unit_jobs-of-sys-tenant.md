# oceanbase.DBA_OB_UNIT_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays all unit-related tasks.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ------------- | -------------- | ----- | ----------------------------------------------------- |
| JOB_ID | bigint(20) | NO | Task ID |
| JOB_TYPE | varchar(128) | NO | Task type.`MIGRATE_UNIT`Represents a migration unit task. |
| JOB_STATUS | varchar(128) | NO | Task status: <ul><li>`INPROGRESS`: In progress </li><li>`SUCCESS`: Success </li><li>`FAILED`: Failed. </li></ul> |
| RESULT_CODE | bigint(20) | YES | Task End Code |
| PROGRESS | bigint(20) | NO | Task progress percentage, which ranges from 0 to 100. |
| START_TIME | timestamp(6) | YES | Task Start Time |
| MODIFY_TIME | timestamp(6) | YES | Last Modified Time |
| TENANT_ID | bigint(20) | YES | Tenant ID: <ul><li>`NULL`: The unit does not belong to any tenant.  </li><li> Valid value: the tenant ID to which the unit belongs.  </li></ul> |
| UNIT_ID | bigint(20) | YES | Unit ID |
| SQL_TEXT | longtext | YES | Related SQL strings |
| EXTRA_INFO | varchar(512) | YES | Additional information |
| RS_SVR_IP | varchar(46) | NO | Root Service Server IP Address |
| RS_SVR_PORT | bigint(20) | NO | Root Service Server Port Number |

## Sample query

Query all unit-related task information in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_JOBS;
```
