# oceanbase.DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the archive path configuration of the current tenant. Physical backup is not supported for the `sys` tenant and Meta tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| DEST_NO | bigint(20) | NO | The identifier of log_archive_dest_n. |
| NAME | varchar(1024) | NO | The name of the column. |
| VALUE | varchar(4096) | NO | The value of the column. |
