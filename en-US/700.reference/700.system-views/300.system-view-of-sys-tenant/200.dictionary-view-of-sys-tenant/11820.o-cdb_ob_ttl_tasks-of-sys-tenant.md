# oceanbase.CDB_OB_TTL_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.CDB_OB_TTL_TASKS` view displays the execution status of all tenant-level TTL tasks in SQL mode.

## Columns

| Column           | Type         | Nullable | Description                                       |
|---------------|--------------|-------------|-------------------------------------------|
| TENANT_ID     | bigint(20)   | NO   | The tenant ID.      |
| TABLE_NAME    | varchar(256) | NO   | The table name.     |
| TABLE_ID      | bigint(20)   | NO   | The table ID.     |
| TASK_ID       | bigint(20)   | NO   | The ID of the current batch task.     |
| START_TIME    | timestamp(6) | NO   | The start time of the task.     |
| MODIFIED_TIME | timestamp(6) | NO   | The update time of the row.   |
| TRIGGER_TYPE  | varchar(8)   | NO   | The type of the task trigger:<ul><li>`PERIODIC`: The system triggers the task periodically. </li> <li>`USER`: The user manually triggers the task. </li></ul>       |
| STATUS        | varchar(10)  | NO   | The status of the task:<ul><li>`PENDING`: The task is waiting to reach an executable state. </li> <li>`CANCELED`: The task is canceled. </li> <li>`FINISHED`: The task has been completed. </li> <li>`SKIP`: The task did not reach an executable state and is skipped for this cycle. </li> <li>`FAILED`: The task failed. </li> <li>`TRIGGERING`: The task is being executed on the RS node. </li> <li>`SUSPENDING`: The task is being suspended on the RS node. </li> <li>`CANCELING`: The task is being canceled on the RS node. </li> <li>`MOVING`: The task is being moved to the task history table on the RS node. </li></ul>     |
| RET_CODE      | varchar(512) | NO   | The error code returned when the task ends.    |
| TASK_TYPE     | varchar(10)  | NO   | The type of the TTL task:<ul><li>`NORMAL`: Displays tenant-level information. </li> <li>`COMPACTION`: A table-level task that deletes expired data through compaction. </li></ul>     |

## Sample query

Query the execution status of all tenant-level TTL tasks in the sys tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_TTL_TASKS;
```

The query result is as follows:

```shell
+-----------+------------+----------+---------+----------------------------+----------------------------+--------------+------------+------------+------------+
| TENANT_ID | TABLE_NAME | TABLE_ID | TASK_ID | START_TIME                 | MODIFIED_TIME              | TRIGGER_TYPE | STATUS     | RET_CODE   | TASK_TYPE  |
+-----------+------------+----------+---------+----------------------------+----------------------------+--------------+------------+------------+------------+
|      1002 | NULL       |       -1 |       2 | 2026-03-11 10:41:13.700826 | 2026-03-11 10:41:13.700826 | USER         | TRIGGERING | OB_SUCCESS | COMPACTION |
+-----------+------------+----------+---------+----------------------------+----------------------------+--------------+------------+------------+------------+
1 row in set
```
