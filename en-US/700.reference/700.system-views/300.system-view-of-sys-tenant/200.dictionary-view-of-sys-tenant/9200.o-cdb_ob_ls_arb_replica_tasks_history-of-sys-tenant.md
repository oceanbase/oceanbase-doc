# oceanbase.CDB_OB_LS_ARB_REPLICA_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.1.0. </p>
</main>

## Overview

Accessible only to the system tenant, this view displays the history of arbitration service tasks executed by all tenants.

## Columns

| field | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TASK_ID | bigint(20) | NO | Task ID |
| EXECUTE_RESULT | varchar(2048) | NO | Task execution result and duration, in the format of "[ret:0; elapsed:72160;]" |
| CREATE_TIME | datetime | NO | Task Generation Time |
| FINISH_TIME | datetime | NO | Task completion time |
| TRACE_ID | varchar(200) | NO | The trace ID of this task execution in the log |
| TASK_TYPE | varchar(32) | NO | Task type: <ul><li>`ADD REPLICA`Refers to the add replica task.  </li><li>`REMOVE REPLICA`<li>delete_replicas: Delete replica tasks.</li></ul> |
| ARBITRATION_SERVICE | varchar(512) | NO | Arbitration service address |
| ARBITRATION_SERVICE_TYPE | varchar(64) | NO | Arbitration service type. Currently, only the following value is supported:`ADDR` |
| COMMENT | varchar(2048) | YES | Task description |
