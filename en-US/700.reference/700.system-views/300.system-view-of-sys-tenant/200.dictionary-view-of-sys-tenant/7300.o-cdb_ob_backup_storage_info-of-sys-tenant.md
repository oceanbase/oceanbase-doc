# oceanbase.CDB_OB_BACKUP_STORAGE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays information about backup destinations used for backup and restore operations across all tenants.

## Columns

| Column              | Type         | Nullable | Description            |
|----------------------|--------------|----------------|-----------------|
| TENANT_ID            | bigint(20)   | NO | The tenant ID. |
| PATH                 | varchar(1024)| NO | The root path for backups. |
| ENDPOINT             | varchar(256) | NO | The host for accessing the object storage. |
| DEST_ID              | bigint(20)   | YES| The ID of the backup destination. |
| DEST_TYPE            | varchar(64)  | YES| The type of the backup destination. Valid values: <ul><li>`archive_log`: log archiving</li> <li>`backup_data`: data backup</li></ul> |
| AUTHORIZATION        | varchar(1024)| NO | The authorization information for object storage. |
| EXTENSION            | varchar(512) | NO | Additional parameters for the backup destination. |
| CHECK_FILE_NAME      | varchar(256) | YES| The name of the connectivity verification file. |
| LAST_CHECK_TIMESTAMP | timestamp(6) | YES| The timestamp of the last successful connectivity check. |
| MAX_IOPS             | bigint(20)   | NO | The maximum IOPS allowed for the backup media used for backup. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>    |
| MAX_BANDWIDTH        | bigint(20)   | NO | The maximum bandwidth allowed for the backup media used for backup, in bytes. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>      |
| MAX_BANDWIDTH_DISPLAY| varchar(29)  | NO | The formatted display of the maximum bandwidth, such as 10GB/s or 10MB/s. <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.3.4. </p></main>      |
| STATUS               |  varchar(64)   | YES | <ul><li>`DELETING`: indicates that the path is being deleted.</li><li>`NORMAL`: indicates that the path is normal.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.4.1 in V4.4.x. </p></main>   |

obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_STORAGE_INFO WHERE TENANT_ID=1002;
