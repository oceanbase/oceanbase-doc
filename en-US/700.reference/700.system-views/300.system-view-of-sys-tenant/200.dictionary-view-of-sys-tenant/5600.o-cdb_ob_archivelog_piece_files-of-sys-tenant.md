# oceanbase.CDB_OB_ARCHIVELOG_PIECE_FILES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status of pieces in backup sets of all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| DEST_ID | bigint(20) | NO | The path ID. The system assigns a unique ID to each path. |
| ROUND_ID | bigint(20) | NO | The ID of the round of full clog backup data. |
| PIECE_ID | bigint(20) | NO | The ID of the backup log piece. |
| INCARNATION | bigint(20) | NO | The number of incarnations after Flashback Database. |
| DEST_NO | bigint(20) | NO | The ID of the log_archive_dest_n parameter. For example, the dest_no of log_archive_dest is 0, and the dest_no of log_archive_dest_1 is 1. |
| CREATE_TIMESTAMP | bigint(20) | NO | The time when the piece was created. |
| STATUS | varchar(64) | NO | The status of the piece. Valid values: <br>ACTIVE: The piece is active. <br>FREEZING: The piece is being frozen. <br>FROZEN: The piece is frozen. The status of a frozen piece will no longer be modified. |
| START_SCN | bigint(20) unsigned | NO | The start SCN of the piece. |
| START_SCN_DISPLAY | varchar(26) | NO | The start SCN of the piece, converted into a time unit. |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | The current archive SCN. |
| CHECKPOINT_SCN_DISPLAY | varchar(26) | NO | The current archive SCN, converted into a time unit. |
| MAX_SCN | bigint(20) unsigned | NO | The maximum archive SCN. |
| END_SCN | bigint(20) unsigned | NO | The theoretical end SCN of the piece. |
| COMPATIBLE | bigint(20) | NO | The compatible version number of log archiving. |
| UNIT_SIZE   | bigint(20)   | NO   | The size of a single log block for compression or encryption. This column is not supported.    |
| COMPRESSION | varchar(128) | NO   | The compression algorithm. Valid values: <ul><li> none: No compression is performed. </li><li> lz4_1.0: The lz4_1.0 compression algorithm is used. </li><li>zstd_1.3.8: The zstd_1.3.8 compression algorithm is used.</li> This column is not supported.    |
| INPUT_BYTES | bigint(20) | NO | The size of the original data. |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the original data, converted into a unit. |
| OUTPUT_BYTES | bigint(20) | NO | The size of the effective data after encryption and compression. |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The size of the effective data after encryption and compression, converted into a unit. |
| COMPRESSION_RATIO | decimal(23,2) | NO | The compression ratio. |
| FILE_STATUS | varchar(64) | NO | The file status of the backup log piece. Valid values: <li>AVAILABLE: The backup is valid and can be used for recovery. <li>COPYING: The log file is being backed up. <li>INCOMPELTE: The logs in the piece are incomplete. Some log streams are missing. <li>DELETING: The log file is being deleted. <li>EXPIRED: The backup file is invalid. <li>BROKEN: The backup file is incomplete and cannot be used. <li>DELETED: The log file has been deleted. |
| PATH | varchar(2048) | NO | The archive path. |
