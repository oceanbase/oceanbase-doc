# oceanbase.CDB_TAB_COLS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays column information for tables and views of all tenants. It is consistent with the `CDB_TAB_COLS_V$` view, but without the `NOTES` column, which is not currently used.

## Columns

|         Column         |       Type        | Nullable |                                                               Description                                                                |
|----------------------|-----------------|------------|---------------|
| CON_ID               | bigint(20)      | NO         | The tenant ID                                        |
| OWNER                | varchar(128)    | NO         | The owner of the table, view, or cluster                                  |
| TABLE_NAME           | varchar(128)    | NO         | The name of the table, view, or cluster                                   |
| COLUMN_NAME          | varchar(128)    | NO         | The column name                                           |
| DATA_TYPE            | varchar(128)    | NO         | The data type of the column                                       |
| DATA_TYPE_MOD        | varchar(3)      | NO         | This column is NULL by default               |
| DATA_TYPE_OWNER      | varchar(128)    | NO         | This column is NULL by default        |
| DATA_LENGTH          | bigint(21)      | NO         | The length of the column, in bytes                                 |
| DATA_PRECISION       | bigint(20)      | NO         | The decimal precision of the `NUMBER` data type; the binary precision of the `FLOAT` data type; NULL for all other data types                                                                            |
| DATA_SCALE           | bigint(20)      | NO         | The number of digits to the right of the decimal point                                  |
| NULLABLE             | varchar(1)      | NO         | Indicates whether the column allows NULL values. The value indicates whether the column has a `NOT NULL` constraint or whether the column is part of a `PRIMARY KEY`                                                                    |
| COLUMN_ID            | bigint(20)      | NO         | The sequence number of the created column                                     |
| DEFAULT_LENGTH       | bigint(20)      | NO         | The length of the default value of the column                                     |
| DATA_DEFAULT         | mediumtext | NO         | The default value of the column                                        |
| NUM_DISTINCT         | bigint(20)      | NO         | The number of distinct values in the column                                     |
| LOW_VALUE            | varchar(128)    | NO         | The minimum value of the column                                       |
| HIGH_VALUE           | varchar(128)    | NO         | The maximum value of the column                                        |
| DENSITY              | bigint(21)      | NO         | The density of the column                                                                       |
| NUM_NULLS            | bigint(20)      | NO         | The number of `NULL` values in the column                                 |
| NUM_BUCKETS          | bigint(20)      | NO         | The number of buckets in the column histogram                                    |
| LAST_ANALYZED        | date            | NO         | The time when the column was last analyzed                                    |
| SAMPLE_SIZE          | bigint(20)      | NO         | The sampling size when the column was analyzed                                   |
| CHARACTER_SET_NAME   | varchar(44)     | NO         | The character set name: <li> `CHAR_CS`   <li> `NCHAR_CS`                                                                               |
| CHAR_COL_DECL_LENGTH | bigint(0)       | NO         | This column is NULL by default                                  |
| GLOBAL_STATS         | varchar(3)      | NO         | `YES` if statistics are collected or incrementally maintained, otherwise `NO`                                                                                  |
| USER_STATS           | varchar(3)      | NO         | Indicates whether the statistics are directly input by a user ( `YES`) or not ( `NO`)         |
| AVG_COL_LEN          | bigint(21)      | NO         | The average length of the column, in bytes                              |
| CHAR_LENGTH          | bigint(20)      | NO         | The length of the column, displayed in characters. This value applies only to the following data types: <li> `CHAR`   <li> `VARCHAR2`   <li> `NCHAR`   <li> `NVARCHAR2`                                                      |
| CHAR_USED           | varchar(1)       | NO       | Indicates whether the column uses the `BYTE` length semantics (`B`) or the `CHAR` length semantics (`C`).  NULL indicates that the column is not of the following data types: <li> `CHAR`   <li> `VARCHAR2`   <li> `NCHAR`   <li> `NVARCHAR2`                |
| V80_FMT_IMAGE        | varchar(3)      | NO         | This column defaults to NULL.  |
| DATA_UPGRADED        | varchar(3)      | NO         | This field is NULL by default.     |
| HIDDEN_COLUMN        | varchar(3)      | NO         | Indicates whether the column is hidden ( `YES`) or not ( `NO`)              |
| VIRTUAL_COLUMN       | varchar(3)      | NO         | Indicates whether the column is a virtual column (`YES`) or not (`NO`).               |
| SEGMENT_COLUMN_ID    | bigint(0)       | NO         | This column defaults to NULL.                                  |
| INTERNAL_COLUMN_ID |  |  | This column is NULL by default. |
| HISTOGRAM            | varchar(15)     | NO         | Indicates the type of the histogram: <li> `NONE`   <li> `FREQUENCY`   <li> `TOP-FREQUENCY`   <li> `HEIGHT BALANCED`   <li> `HYBRID`    |
| QUALIFIED_COL_NAME   | text            | NO         | The qualified name of a column.                          |
| USER_GENERATED       | varchar(3)      | NO         | Indicates whether the column is user-generated (`YES`) or system-generated (`NO`).        |
| DEFAULT_ON_NULL      | varchar(3)      | NO         | This column defaults to NULL.         |
| IDENTITY_COLUMN      | varchar(3)      | NO         | The value is null by default. |
| EVALUATION_EDITION   | varchar(128)    | NO         | The value is NULL by default.            |
| UNUSABLE_BEFORE      | varchar(128)    | NO         | This field is default NULL.                         |
| UNUSABLE_BEGINNING   | varchar(128)    | NO         | This field defaults to NULL.           |
| COLLATION            | varchar(100)    | NO         | The default value is NULL.           |
| COLLATED_COLUMN_ID | bigint(0) | NO | NULL by default |
