# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Purpose

This view displays the data backup parameters configured for the current tenant. Because the `sys` tenant is a cluster management tenant and does not contain user data, it does not support backup and restore. Therefore, no backup parameters are configured for the `sys` tenant. When you query this view in the `sys` tenant, the result is always empty.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | Parameter name |
| VALUE | longtext | NO | Parameter value |
