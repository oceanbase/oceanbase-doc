# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the data backup parameters of the current tenant. Physical backup is not supported for the `sys` tenant and Meta tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | The parameter name. |
| VALUE | longtext | NO | The parameter value. |
