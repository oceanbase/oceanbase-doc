# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status and restore progress of log streams in the current tenant.

## Columns

| Column | Type | Nullable | Description |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID | bigint(20) | NO | The ID of the log stream. |
| STATUS | varchar(100) | NO | The status of the log stream. Valid values: <ul><li>`CREATING`: The log stream is being created.</li><li>`CREATED`: The log stream has been created.</li><li>`NORMAL`: The log stream is available for services.</li><li>`DROPPING`: The log stream is to be dropped. You must migrate the tablets on the log stream before it is dropped. </li><li>`TENANT DROPPING`: The tenant of the log stream is being dropped. You must drop the log stream before the tenant is dropped. </li><li>`WAIT OFFLINE`: The data of the log stream has been dropped. The log stream is waiting for garbage collection. </li><li>`CREATE ABORT`: The creation of the log stream has failed or is not required. The log stream is to be dropped. </li></ul> |
| PRIMARY_ZONE | longtext | YES | The priority zone for the log stream. |
| UNIT_GROUP_ID | bigint(20) | NO | The ID of the unit group. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field is available starting with V4.6.0. The value of this field is always 0. </li><li>For V4.4.x, this field is available starting with V4.4.2. The value of this field is always 0. </li><li>For V4.2.5, this field is available starting with V4.2.5 BP5. The value of this field is always 0. </li></ul></main>  |
| LS_GROUP_ID | bigint(20) | NO | The ID of the log stream group. For the system log stream (log stream 1) and broadcast log stream, the value of this field is 0, indicating that the log stream does not belong to a log stream group. |
| CREATE_SCN | bigint(20) unsigned | NO | The starting point of the log stream. |
| DROP_SCN | bigint(20) unsigned | NO | The point at which the log stream is dropped. This point marks the end of all user data. If the log stream is dropped, this field records the SCN when the log stream is dropped. If the log stream is not dropped, this field is empty. |
| SYNC_SCN | bigint(20) unsigned | NO | The synchronization point of the log stream. This point marks the SCN of the last transaction that is successfully synchronized. |
| READABLE_SCN | bigint(20) unsigned | NO | The readable point of the log stream. This point marks the minimum SCN of the log stream that can be read. |
| FLAG | varchar(2048) | NO | The flag of the log stream. Valid values: <ul><li>Empty: normal log stream. </li><li>`DUPLICATE`: broadcast log stream of a user tenant. A duplicated table is created on this log stream. </li><li>`BLOCK_TABLET_IN`: a tablet cannot be created on this log stream. </li><li>`DUPLICATE\|BLOCK_TABLET_IN`: a tablet cannot be created on this broadcast log stream. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main>  |
| UNIT_LIST | varchar(1216) | NO | The list of units for the user log stream. The value of this field is empty for the system log stream and broadcast log stream if no specific location is specified. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.6.x, this field is available starting with V4.6.0. </li> <li>For V4.4.x, this field is available starting with V4.4.2. </li> <li>For V4.2.5, this field is available starting with V4.2.5 BP5. </li></ul></main>  |

## Sample query

Query the status and restore progress of log streams in the sys tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```

The query result is as follows:

```shell
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
| LS_ID | STATUS | PRIMARY_ZONE | UNIT_GROUP_ID | LS_GROUP_ID | CREATE_SCN | DROP_SCN | SYNC_SCN | READABLE_SCN | FLAG | UNIT_LIST |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
|     1 | NORMAL | zone1        |             0 |           0 |       NULL |     NULL |     NULL |         NULL |      |           |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
1 row in set
```
