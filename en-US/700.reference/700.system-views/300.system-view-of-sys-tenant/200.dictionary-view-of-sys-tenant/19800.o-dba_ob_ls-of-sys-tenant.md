# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status and recovery progress of log streams in the current tenant.

## Columns

| Column       | Type                | Nullable        | Description               |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO | The ID of the log stream. |
| STATUS        | varchar(100)        | NO | The status of the log stream. Valid values: <ul><li>`CREATING`: The log stream is being created.</li><li>`CREATED`: The log stream is created.</li><li>`NORMAL`: The log stream is available for service.</li><li>`DROPPING`: The log stream is being dropped. You must migrate the tablets on the log stream. </li><li>`TENANT DROPPING`: The log stream is being dropped because its tenant is being dropped. </li><li>`WAIT OFFLINE`: The data of the log stream is deleted and the log stream is waiting for garbage collection. </li><li>`CREATE ABORT`: The log stream is being dropped because the log stream creation failed or is not needed. </li></ul> |
| PRIMARY_ZONE  | longtext            | YES| The priority zone for log stream election. |
| UNIT_GROUP_ID | bigint(20)          | NO | The ID of the unit group. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting with V4.4.2. The value of this field is always 0. </li><li>For V4.2.5, this field is available starting with V4.2.5 BP5. The value of this field is always 0. </li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO | The ID of the log stream group. For system log streams (log stream 1) and broadcast log streams, this field is 0, indicating that the log stream does not belong to a log stream group. |
| CREATE_SCN    | bigint(20) unsigned | NO | The SCN at which the log stream starts to write logs. |
| DROP_SCN      | bigint(20) unsigned | NO | The SCN at which the log stream is dropped. This is also the SCN at which all user data ends. If the log stream is dropped, this field records the SCN at which the log stream is dropped. If the log stream is not dropped, this field is empty. |
| SYNC_SCN      | bigint(20) unsigned | NO | The SCN of the last successful synchronization transaction of the log stream. |
| READABLE_SCN  | bigint(20) unsigned | NO | The minimum SCN of the log stream that can be read. |
| FLAG          | varchar(2048)       | NO | The flag of the log stream. Valid values: <ul><li>Empty: normal log stream. </li><li>`DUPLICATE`: broadcast log stream of a user tenant. A replicated table is created on this log stream. </li> <li>`BLOCK_TABLET_IN`: a tablet cannot be created on this log stream. </li> <li>`DUPLICATE\|BLOCK_TABLET_IN`: tablet creation is not allowed on this broadcast log stream. </li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | The list of units where the user log stream is distributed. This field is empty for system log streams and broadcast log streams if no specific location is specified. <main id="notice" type='explain'><h4>Note</h4><ul><li>For V4.4.x, this field is available starting with V4.4.2. </li> <li>For V4.2.5, this field is available starting with V4.2.5 BP5. </li></ul></main>  |

## Sample query

Query the status and recovery progress of log streams in the sys tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```

The query result is as follows:

```shell
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
| LS_ID | STATUS | PRIMARY_ZONE | UNIT_GROUP_ID | LS_GROUP_ID | CREATE_SCN | DROP_SCN | SYNC_SCN | READABLE_SCN | FLAG | UNIT_LIST |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
|     1 | NORMAL | zone1        |             0 |           0 |       NULL |     NULL |     NULL |         NULL |      |           |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
1 row in set
```
