# oceanbase.CDB_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in V4.0.0. </p>
</main>

## Purpose

This view in the sys tenant displays the associations between all tables and table groups in the database. Tables not in any table group are not displayed.

## Columns

| Column | Type | Nullable? | Description |
|-----------------|---------------|------------|---------------|
| TENANT_ID       | bigint(20)    | NO         | Tenant ID         |
| TABLEGROUP_NAME | VARCHAR2(128) | NO         | Table group name           |
| OWNER           | VARCHAR2(128) | NO         | Database name to which the table belongs |
| TABLE_NAME      | VARCHAR2(256) | NO         | Table name       |
| SHARDING        | varchar(10)   | NO         | SHARDING attribute of the table group: <ul><li>`NONE`: All partitions of all tables in the table group are aggregated on the same server, and no restrictions are imposed on tables to be added to the table group. </li> <li>`PARTITION`: The data of each table in the table group is scattered by partition; all subpartitions in a partition are aggregated together. </li> <li>`ADAPTIVE`: The data of each table in the table group is scattered adaptively. Specifically, tables in the table group that are partitioned by partition are scattered by partition; tables in the table group that are subpartitioned are subpartitioned in each partition. </li></ul>    |

## Examples

Query the associations of the `tblgroup1` table group in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'tblgroup1';
```

The query result is as follows:

```shell
+-----------+-----------------+-------+------------+----------+
| TENANT_ID | TABLEGROUP_NAME | OWNER | TABLE_NAME | SHARDING |
+-----------+-----------------+-------+------------+----------+
|      1002 | tblgroup1       | test  | tbl3       | ADAPTIVE |
|      1004 | TBLGROUP1       | SYS   | TBL3       | NONE     |
+-----------+-----------------+-------+------------+----------+
2 rows in set
```
