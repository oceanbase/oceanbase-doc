# oceanbase.CDB_OB_ACCESS_POINT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the list of Server nodes for a tenant. In a network-based physical standby database scenario, it is mainly used to obtain the IP address and SQL port number of the OBServer node of the primary tenant's replica.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)   | NO | The tenant ID.  <ul><li>1: the sys tenant.  </li><li>Other values: user tenants. </li></ul>|
| TENANT_NAME | varchar(128) | NO | The tenant name. |
| SVR_IP | varchar(46) | NO | The IP address of the server node of the system log stream replica. |
| SQL_PORT | bigint(20) | NO | The SQL port number of the server node of the system log stream replica. |

## Sample query

Query the list of Server nodes for the `primary_tenant1` tenant in the sys tenant.

```shell
obclient [oceanbase]> SELECT SVR_IP, SQL_PORT FROM oceanbase.CDB_OB_ACCESS_POINT WHERE TENANT_NAME = 'primary_tenant1';
```

The query result is as follows:

```shell
+----------------+----------+
| SVR_IP         | SQL_PORT |
+----------------+----------+
| xxx.xxx.xxx.20 |    17860 |
+----------------+----------+
1 row in set
```
