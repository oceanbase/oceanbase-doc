# mysql.time_zone_name

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the timezone name information (SYSTEM_VIEW).

## Columns

|     Column     |     Type      | Nullable |  Description   |
|--------------|-------------|------------|-------|
| Name         | varchar(64) | NO         | The name of the timezone.  |
| Time_zone_id | bigint(20)  | NO         | The ID of the timezone. |
