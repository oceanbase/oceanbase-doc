# oceanbase.DBA_OB_LICENSE

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view is only applicable to centralized deployment. In distributed deployment, the query result for this view is empty.</li>
  <li>This view is available starting with V4.4.2 BP1.</li></ul>
</main>

## Overview

Displays the information about the license currently loaded by the user.

## Columns

| **Field** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| END_USER | varchar(512) | NO | Authorized username. |
| LICENSE_ID | varchar(128) | NO | The ID of the license. |
| LICENSE_CODE | varchar(128) | NO | Contract number. |
| LICENSE_TYPE | varchar(128) | NO | License type. <ul><li>Commercial: The commercial edition.</li><li>Trial: The trial edition.</li></ul> |
| PRODUCT_TYPE | varchar(128) | NO | Product type. <ul><li>SE: short for Standalone Enterprise Edition, indicating the standalone enterprise edition.</li><li>DE: short for Distributed Enterprise Edition, indicating the distributed enterprise edition.</li></ul> |
| ISSUANCE_DATE | timestamp(6) | NO | The license issuance date. |
| ACTIVATION_TIME | timestamp(6) | NO | License activation time. |
| EXPIRED_TIME | timestamp(6) | NO | License expiration time. |
| OPTIONS | varchar(1024) | NO | The feature options included in the license. <ul><li>EE: short for Enterprise Edition, representing the basic features of OceanBase Database Enterprise Edition for standalone deployment.</li><li>PS: short for Primary-Standby, representing the inter-cluster replication option for OceanBase Database Standalone Edition.</li><li>MT: short for Multitenant, representing the multi-tenant option for OceanBase Database Standalone Edition.</li><li>AP: short for OLAP, representing the OLAP option for OceanBase Database Standalone Edition.</li></ul> |
| CORE_NUM | bigint(20) unsigned | NO | The number of CPU cores authorized for use. |
| NODE_NUM | bigint(20) unsigned | NO | Number of authorized nodes. For the standalone edition, it is fixed as 1. |
| CLUSTER_ULID | varchar(30) | NO | It is automatically generated when the cluster starts. |

## Sample query

The system tenant displays the information about the loaded license.

```shell
obclient [oceanbase]> select * from oceanbase.DBA_OB_LICENSE;
```
