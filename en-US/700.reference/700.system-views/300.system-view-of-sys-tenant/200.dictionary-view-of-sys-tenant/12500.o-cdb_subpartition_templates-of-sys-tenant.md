# oceanbase.CDB_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the template-based subpartition information for partitioned tables of all tenants (excluding the Meta tenant).

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------------- | ----------------- | ------------ | ----------- |
| CON_ID | decimal(10,0) | NO | Tenant ID |
| USER_NAME | varchar(128) | NO | Owner of the partitioned table |
| TABLE_NAME | varchar(128) | NO | Partitioned Table Name |
| SUBPARTITION_NAME | varchar(132) | NO | Subpartition Name |
| SUBPARTITION_POSITION | bigint(21) | NO | Subpartition Location |
| TABLESPACE_NAME | varchar(30) | NO | Tablespace name of the partition |
| HIGH_BOUND | varchar(262144) | NO | Partition template expression |
| COMPRESSION | varchar(4) | NO | Specifies whether the data of each newly added composite partition in the subpartition template is stored in compressed format:<ul><li>YES</li><li>(Default) NO </li></ul> <br>This value can be specified in the subpartition template. |
| INDEXING | varchar(4) | NO | Specifies whether the data of each newly added composite partition in the subpartition template is considered a partial index:<ul><li>ON</li><li>(Default) OFF</li></ul><br>This value can be specified in the subpartition template. |
| READ_ONLY | varchar(4) | NO | Specifies whether the data of each newly added composite partition in the subpartition template is read-only:<ul><li>YES</li><li>(Default) NO</li></ul><br>This value can be specified in the subpartition template. |

## Sample query
