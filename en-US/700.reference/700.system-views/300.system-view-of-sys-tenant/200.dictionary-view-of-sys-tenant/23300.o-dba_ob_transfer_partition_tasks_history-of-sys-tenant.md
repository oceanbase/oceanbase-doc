# oceanbase.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1 BP2. </p>
</main>

## Purpose

The `DBA_OB_TRANSFER_PARTITION_TASK_HISTORY` view displays the history of executed Transfer Partition tasks for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID          | bigint(20)   | NO   | The unique identifier of the Transfer Partition task.   |
| CREATE_TIME      | timestamp(6) | NO   | The creation time.   |
| FINISH_TIME      | timestamp(6) | NO   | The task completion time, including successful and canceled tasks.   |
| TABLE_ID         | bigint(20)   | NO   | The table ID where the Transfer Partition is located.   |
| OBJECT_ID        | bigint(20)   | NO   | The `OBJECT_ID` of the Transfer Partition.   |
| DEST_LS          | bigint(20)   | NO   | The destination log stream.   |
| BALANCE_JOB_ID   | bigint(20)   | NO   | The load balancing job ID associated with the task execution.   |
| TRANSFER_TASK_ID | bigint(20)   | NO   | The Transfer task ID associated with the task execution.   |
| STATUS           | varchar(64)  | NO   | The task status. Valid values: <ul><li>COMPLETED: The task was executed successfully. </li><li>FAILED: The task failed. </li></ul>   |
| COMMENT          | longtext     | YES  | The comment.   |

## Sample query

Query the history of executed Transfer Partition tasks for the current tenant.

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY;
```
