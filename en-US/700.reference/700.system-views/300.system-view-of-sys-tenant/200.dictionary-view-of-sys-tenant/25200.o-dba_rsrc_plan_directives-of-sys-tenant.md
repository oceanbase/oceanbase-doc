# oceanbase.DBA_RSRC_PLAN_DIRECTIVES

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V3.1.2. </li>
<li>For the current version, we recommend that you use the <a href="21420.o-dba_ob_rsrc_directives-of-sys-tenant.md">DBA_OB_RSRC_DIRECTIVES</a> view to view the resource configuration parameters of a tenant in the Resource Manager. </li></ul>
</main>

## Purpose

This view displays detailed information about each group of resource plan instructions in the database.
