# oceanbase.DBA_OB_SS_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

The `DBA_OB_SS_SPACE_USAGE` view records the storage space usage on the object storage of the current tenant.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available only in Shared-Storage (SS) mode. In Shared-Nothing (SN) mode, the query result is empty. </p>
</main>

## Columns

| Column       | Type          | Nullable      | Description                                        |
|---------------|---------------|---------------------|----------------------------------------|
| ENDPOINT      | varchar(128)  | NO   | The endpoint of the shared storage.      |
| PATH          | varchar(128)  | NO   | The path of the shared storage.      |
| STORAGE_TYPE  | varchar(32)   | NO   | The storage type. Valid values: <ul><li>`Local All Bytes`: all data in the local directory on the object storage</li> <li>`Shared Data Bytes`: data in the public directory on the object storage</li> <li>`Shared Meta Bytes`: all metadata on the object storage</li></ul>     |
| VALUE         | bigint(20)    | NO   | The size of the storage space corresponding to `STORAGE_TYPE`, in bytes.   |
