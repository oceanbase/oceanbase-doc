# oceanbase.CDB_OB_TABLET_REPLICAS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays information for all tablet replicas of all tenants. Each tablet replica is uniquely identified by the composite key: `<TENANT_ID, TABLET_ID, SVR_IP, SVR_PORT, LS_ID>`.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------- | ------------- | ------------ | ------------------------------------------------------------ |
| CREATE_TIME | timestamp(6) | NO | Creation Time of TABLET ID |
| MODIFY_TIME | timestamp(6) | NO | Modification Time of Tablet ID |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TABLET_ID | bigint(20) | NO | TABLET ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| LS_ID | bigint(20) | NO | Log stream ID of the tablet |
| COMPACTION_SCN | bigint(20) unsigned | NO | Data Snapshot Version Number |
| DATA_SIZE | bigint(20) | NO | Actual data size, in bytes |
| REQUIRED_SIZE | bigint(20) | NO | The size of the data allocation space, in bytes. Data is stored in units of macroblocks (2 MB). Therefore,`REQUIRED_SIZE >= DATA_SIZE` |

## Sample query

The system tenant queries the tablet replica information of the tenant with ID 1002 and displays the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLET_REPLICAS WHERE TENANT_ID = 1002 LIMIT 10;
```
