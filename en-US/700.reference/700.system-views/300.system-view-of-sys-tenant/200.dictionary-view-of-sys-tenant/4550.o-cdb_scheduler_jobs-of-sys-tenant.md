# oceanbase.CDB_SCHEDULER_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.4.2. </p>
</main>

## Purpose

This view displays all jobs under all tenants.

## Columns

|          Column           |       Type        | Nullable |     Description     |
|-------------------------|-----------------|------------|--------------------------------------|
| TENANT_ID                     | bigint(20)   | NO         | The tenant ID.|
| OWNER                         | varchar(128) | NO         | The owner of the scheduler job.|
| JOB_NAME                      | varchar(128) | NO         | The name of the scheduler job.|
| JOB_SUBNAME                   | varchar(128) | NO         | The subname of the scheduler job.        |
| JOB_STYLE                     | varchar(17)  | YES        | The default value is NULL.|
| JOB_CREATOR                   | varchar(128) | NO         | The creator of the scheduler job.        |
| CLIENT_ID                     | varchar(65)  | NO         | The client identifier of the user who created the job.        |
| GLOBAL_UID                    | varchar(33)  | NO         | The global user identifier of the user who created the job.        |
| PROGRAM_OWNER                 | text         | NO         | The owner of the program associated with the job.|
| PROGRAM_NAME                  | text         | YES        | The name of the program associated with the job.|
| JOB_TYPE                      | varchar(16)  | YES        | The operation type of the job. Valid values: <ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul>|
| JOB_ACTION                    | text         | YES        | The inline operation of the job.|
| NUMBER_OF_ARGUMENTS           | bigint(20)   | YES        | The number of inline parameters of the job.|
| SCHEDULE_OWNER                | text         | NO         | The owner of the schedule used by the job.       |
| SCHEDULE_NAME                 | text         | NO         | The name of the schedule used by the job.      |
| SCHEDULE_TYPE                 | varchar(12)  | NO         | The type of the schedule used by the job.     |
| START_DATE                    | datetime(6)  | YES        | The original start date of the job's schedule.|
| REPEAT_INTERVAL               | text         | YES        | The inline PL/SQL expression or calendar string of the schedule.|
| EVENT_QUEUE_OWNER             | varchar(128) | NO         | The owner of the source queue where events are triggered.       |
| EVENT_QUEUE_NAME              | varchar(128) | NO         | The name of the source queue where events are triggered.       |
| EVENT_QUEUE_AGENT             | text         | NO         | The name of the AQ agent used by the user on the event source queue.        |

| FILE_WATCHER_OWNER            | varchar(261) | NO         | The owner of the file watcher on which the job is based.       |
| FILE_WATCHER_NAME             | varchar(261) | NO         | The name of the file watcher on which the job is based.       |

| JOB_CLASS                     | varchar(128) | YES        | The name of the job category associated with the job.|
| ENABLED                       | varchar(5)   | YES        | Indicates whether the job is enabled: <ul><li>TRUE  </li><li>FALSE </li></ul>|

| RESTART_ON_RECOVERY           | varchar(5)   | NO         | The default value is NULL        |
| RESTART_ON_FAILURE            | varchar(5)   | NO         | The default value is NULL       |
| STATE                         | varchar(15)  | YES        | The current state of the job: <ul><li>DISABLED</li><li>RETRY SCHEDULED</li><li>SCHEDULED</li><li>BLOCKED</li><li>RUNNING</li><li>COMPLETED</li><li>BROKEN</li><li>FAILED</li><li>REMOTE</li><li>RESOURCE_UNAVAILABLE</li><li>SUCCEEDED</li><li>CHAIN_STALLED </li></ul>|
| JOB_PRIORITY                  | bigint(0)    | NO         |  The priority of the job relative to other jobs of the same type.       |
| RUN_COUNT                     | bigint(20)   | YES        | The number of times the job has run.|
| MAX_RUNS                      | bigint(0)    | NO         | The maximum number of times the job is scheduled to run.        |
| FAILURE_COUNT                 | bigint(20)   | YES        | The number of times the job has failed.        |
| MAX_FAILURES                  | bigint(0)    | NO         | The maximum number of allowed job failures before the job is marked as failed.       |
| RETRY_COUNT                   | bigint(20)   | YES        | The number of job retries. |
| LAST_START_DATE               | datetime(6)  | YES        | The date the job started to run|
| LAST_RUN_DURATION             | bigint(20)   | YES        | The duration of the last job run, in seconds. |
| NEXT_RUN_DATE                 | datetime(6)  | NO         | The next run date of a job schedule|
| SCHEDULE_LIMIT                | bigint(0)    | NO         | The time by which unscheduled jobs will be rescheduled.       |
| MAX_RUN_DURATION              | bigint(20)   | YES        | The maximum time allowed for the job to run |
| LOGGING_LEVEL                 | varchar(11)  | NO         | Default value is NULL.     |
| STORE_OUTPUT                  | varchar(5)   | NO         | NULL is default        |
| STOP_ON_WINDOW_CLOSE          | varchar(5)   | NO         | NULL                 |
| INSTANCE_STICKINESS           | varchar(5)   | NO         | NULL                 |
| RAISE_EVENTS                  | text         | NO         | Default value is NULL |
| SYSTEM                       | varchar(5)   | NO         | NULL value          |
| JOB_WEIGHT                    | bigint(0)    | NO         |Job weight, which specifies the priority of the job during scheduling.       |
| NLS_ENV                       | text         | YES        |The job's national language environment setting |
| SOURCE                        | varchar(128) | NO         |The source code or script of the job      |
| NUMBER_OF_DESTINATIONS        | bigint(0)    | NO         | The number of job destinations    |
| DESTINATION_OWNER           | varchar(261) | NO      | Owner of the destination job  |
| DESTINATION                   | varchar(261) | NO         |Job target, which indicates the object or location where the job is to be executed.       |
| CREDENTIAL_OWNER              | varchar(128) | NO         |The owner of the credential.        |
| CREDENTIAL_NAME               | varchar(128) | NO         |The name of the credential.         |
| INSTANCE_ID                   | varchar(128) | YES        |This column describes the instance of the instance where the user requests to run the job. |
| DEFERRED_DROP                 | varchar(5)   | NO         |Whether to drop the job in a deferred manner    |
| ALLOW_RUNS_IN_RESTRICTED_MODE | varchar(5)   | NO         | Whether the job is allowed to run in restricted mode        |
| COMMENTS                      | text         | YES        | The comment or description for the job. |
| FLAGS                         | bigint(20)   | NO         | The flags of the job. |
| RESTARTABLE                   | varchar(5)   | NO         | Whether the job is restartable. |
| CONNECT_CREDENTIAL_OWNER      | varchar(128) | NO         |Owner of the connection credential         |
| CONNECT_CREDENTIAL_NAME       | varchar(128) | NO         |The name of the connection credential.        |
