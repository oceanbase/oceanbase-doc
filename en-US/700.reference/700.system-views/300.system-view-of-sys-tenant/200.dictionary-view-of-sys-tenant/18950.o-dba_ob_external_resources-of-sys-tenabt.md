# oceanbase.DBA_OB_EXTERNAL_RESOURCES

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.4.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_EXTERNAL_RESOURCES` view displays the uploaded resource files.

## Columns

| **Column** | **Type**  | **Nullable** | **Description**               |
|------------|-------------|---------------------|----------------------------------------|
|RESOURCE_ID|bigint(20)|NO|The resource ID, which uniquely identifies the resource.|
|DATABASE_ID|bigint(20)|NO|The ID of the database to which the resource belongs.|
| NAME        | varchar(256)  | NO   |   The name of the resource.   |
| TYPE        | varchar(12)   | NO   |   The type of the resource. Valid values: 'JAVA_JAR' and 'PYTHON_PY'.  |
| CONTENT     | longblob      | NO   |   The binary content of the resource.   |
| COMMENT     | varchar(4096) | NO   |   The comment added when the resource is uploaded.   |

## Sample query

Execute the following SQL statement to query the uploaded resource files in the current tenant.

```shell
obclient > SELECT * FROM oceanbase.DBA_OB_EXTERNAL_RESOURCES;
```
