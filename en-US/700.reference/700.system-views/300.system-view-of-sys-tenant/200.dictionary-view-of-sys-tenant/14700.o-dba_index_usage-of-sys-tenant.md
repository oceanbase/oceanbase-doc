# oceanbase.DBA_INDEX_USAGE

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>For V4.3.x, this view is available starting with V4.3.0. </li> <li>For V4.2.x, this view is available starting with V4.2.3. </li></ul></p>
</main>

## Purpose

The `DBA_INDEX_USAGE` view displays the usage data of indexes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| OBJECT_ID | bigint(20) | NO | The ID of the index table. |
| NAME | varchar(128) | NO | The name of the index table. |
| OWNER | varchar(128) | NO | The name of the database. |
| TOTAL_ACCESS_COUNT | bigint(20) | NO | The total number of accesses. |
| TOTAL_EXEC_COUNT | bigint(20) | NO | The total number of executions. |
| TOTAL_ROWS_RETURNED | bigint(20) | NO | This column is not supported. |
| BUCKET_0_ACCESS_COUNT | bigint(20) | NO | This column is not supported. |
| BUCKET_1_ACCESS_COUNT | bigint(20) | NO | This column is not supported. |
| BUCKET_2_10_ACCESS_COUNT | bigint(20) | NO | This column is not supported. |
| BUCKET_2_10_ROWS_RETURNED | bigint(20) | NO | This column is not supported. |
| BUCKET_11_100_ACCESS_COUNT | bigint(20) | NO | This column is not supported. |
| BUCKET_11_100_ROWS_RETURNED | bigint(20) | NO | This column is not supported. |
| BUCKET_101_1000_ACCESS_COUNT | bigint(20) | NO | This column is not supported. |
| BUCKET_101_1000_ROWS_RETURNED | bigint(20) | NO | This column is not supported. |
| BUCKET_1000_PLUS_ACCESS_COUNT | bigint(20) | NO | This column is not supported. |
| BUCKET_1000_PLUS_ROWS_RETURNED | bigint(20) | NO | This column is not supported. |
| LAST_USED | varchar(128) | NO | The last time when the index table was used. |

## Sample query

Query the usage data of indexes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_INDEX_USAGE;
```
