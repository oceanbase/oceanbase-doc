# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the status and restore progress of log streams in the current tenant.

## Columns

| Column       | Type                | Nullable        | Description               |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO | The ID of the log stream. |
| STATUS        | varchar(100)        | NO | The status of the log stream. Valid values: <li>`CREATING`: the log stream is being created<li>`CREATED`: the log stream is created<li>`NORMAL`: the log stream is ready to provide services<li>`DROPPING`: the log stream is being dropped. You must migrate the tablets on the log stream<li>`TENANT DROPPING`: the log stream is being dropped because its tenant is being dropped<li>`WAIT OFFLINE`: the data of the log stream has been dropped and is waiting for garbage collection<li>`CREATE ABORT`: the log stream creation failed or is not required. The log stream is being dropped. |
| PRIMARY_ZONE  | longtext            | YES| The priority zone of the log stream. |
| UNIT_GROUP_ID | bigint(20)          | NO | The ID of the unit group. |
| LS_GROUP_ID   | bigint(20)          | NO | The ID of the log stream group. |
| CREATE_SCN    | bigint(20) unsigned | NO | The start point of the log stream. |
| DROP_SCN      | bigint(20) unsigned | NO | The end point of the log stream. |
| SYNC_SCN      | bigint(20) unsigned | NO | The synchronization point of the log stream. |
| READABLE_SCN  | bigint(20) unsigned | NO | The readable point of the log stream. |
| FLAG          | varchar(2048)       | NO | The flag of the log stream. Valid values: <ul><li>Empty: normal log stream</li><li> DUPLICATE: the broadcast log stream of a user tenant. A replicated table is created on this log stream </li> <li>BLOCK_TABLET_IN: a tablet cannot be created on this log stream</li> <li>DUPLICATE\|BLOCK_TABLET_IN: a tablet cannot be created on this broadcast log stream</li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This column is available starting with V4.2.0. </p></main>  |

## Sample query

Query the log stream status and restore progress in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```

The query result is as follows:

```shell
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+
| LS_ID | STATUS | PRIMARY_ZONE | UNIT_GROUP_ID | LS_GROUP_ID | CREATE_SCN | DROP_SCN | SYNC_SCN | READABLE_SCN | FLAG |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+
|     1 | NORMAL | zone1        |             0 |           0 |       NULL |     NULL |     NULL |         NULL |      |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+
1 row in set
```
