# oceanbase.CDB_INDEXES

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the INDEX information for all tenants.

## Columns

|          Column           |      Type       | Nullable |                       Description                       |
|-------------------------|---------------|------------|------------------------------------------------|
| CON_ID                  | bigint(20)    | NO         | The tenant ID.                                          |
| OWNER                   | varchar(128)  | NO         | The owner of the index.                                       |
| INDEX_NAME              | varchar(128)  | NO         | The name of the index.                                           |
| INDEX_TYPE              | varchar(27)   | NO         | The type of the index.                                          |
| TABLE_OWNER             | varchar(128)  | NO         | The owner of the object being indexed.                                      |
| TABLE_NAME              | varchar(128)  | NO         | The name of the object being indexed.                                       |
| TABLE_TYPE              | varchar(5)    | NO         | The type of the object being indexed.                                       |
| UNIQUENESS              | varchar(9)    | NO         | Indicates whether the index is unique (UNIQUE) or non-unique.                        |
| COMPRESSION             | varchar(13)   | NO         | Indicates whether the index is compressed.                                    |
| PREFIX_LENGTH           | decimal(10,0) | NO         | This column is not supported. The default value is NULL.         |
