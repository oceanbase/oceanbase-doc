# oceanbase.DBA_OB_TTL_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_TTL_TASK_HISTORY` view displays the execution history of TTL tasks in the current tenant in SQL mode.

## Columns

| Column           | Type         | Nullable | Description                                       |
|---------------|--------------|-------------|-------------------------------------------|
| TABLE_NAME    | varchar(256) | NO   | The name of the table.     |
| TABLE_ID      | bigint(20)   | NO   | The ID of the table.     |
| TASK_ID       | bigint(20)   | NO   | The ID of the current batch task.     |
| START_TIME    | timestamp(6) | NO   | The start time of the task.     |
| MODIFIED_TIME | timestamp(6) | NO   | The update time of the row.   |
| TRIGGER_TYPE  | varchar(8)   | NO   | The type of task trigger. Valid values: <ul><li>`PERIODIC`: the system triggers the task periodically. </li> <li>`USER`: the user manually triggers the task. </li></ul>       |
| STATUS        | varchar(10)  | NO   | The status of the task. Valid values: <ul><li>`CANCELED`: the task is canceled. </li> <li>`FINISHED`: the task is completed. </li> <li>`SKIP`: the task is skipped because it does not meet the execution conditions. </li> <li>`FAILED`: the task fails. </li></ul>     |
| RET_CODE      | varchar(512) | NO   | The error code returned when the task ends.    |
| TASK_TYPE     | varchar(10)  | NO   | The type of the TTL task. Valid values: <ul><li>`NORMAL`: displays tenant-level information. </li> <li>`COMPACTION`: a table-level task that deletes expired data by using compaction. </li></ul>     |
