# oceanbase.CDB_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the history of executed backup cleanup tasks across all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| JOB_ID | bigint(20) | NO | The task ID, which is a monotonic increasing number. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| INITIATOR_TENANT_ID | bigint(20) | NO | The tenant ID that initiated the task. |
| INITIATOR_JOB_ID | bigint(20) | NO | The job ID of the tenant that initiated the task. |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | The list of tenants that executed the cleanup task. |
| TYPE | varchar(64) | NO | The cleanup type. Valid values: <ul><li>`DELETE OBSOLETE BACKUP` : obsolete backup cleanup</li> <li>`DELETE BACKUP ALL` : clear all backups or archived data in the path</li> <li>`DELETE BACKUPSET` : clear the specified data backup set</li> <li>`DELETE ARCHIVELOG_PIECE` : clear the specified log archive piece</li></ul> |
| PARAMETER | timestamp(6) | NO | The cleanup parameters. This column describes the specific parameters for different cleanup types. |
| JOB_LEVEL | varchar(64) | NO | The task initiation level. Valid values: <ul><li> `USER_TENANT` : a task initiated by a user tenant</li><li> `SYS_TENANT` : a task initiated by a system tenant</li></ul> |
| START_TIMESTAMP | timestamp(6) | NO | The current time of the tenant when the task started. |
| END_TIMESTAMP | timestamp(6) | NO | The current time of the tenant when the task ended. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`COMPLETED` : the task execution succeeded </li><li>`FAILED` : the task execution failed </li><li>`CANCELED` : the task was successfully canceled </li></ul> |
| TASK_COUNT | bigint(20) | YES | The number of backup_set/piece tasks. |
| SUCCESS_TASK_COUNT | bigint(20) | YES | The number of backup_set/piece tasks that executed successfully. |
| RESULT | bigint(20) | NO | The error code. |
| COMMENT | varchar(4096) | YES | The task execution description. |

## Sample query

Query the history of completed backup cleanup tasks across all tenants and display the first 5 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_JOB_HISTORY LIMIT 5\G
```
