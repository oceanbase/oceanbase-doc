# oceanbase.DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p> This view was introduced in version V4.2.0. </p>
</main>

## Description

This view displays the log streams that existed in the tenant.

## Fields

| Field        | Type           | Not null | Description                                       |
|-------------|---------------|---------|-------------------------------------------|
| LS_ID       | bigint(20)    | NO      | The ID of the log stream.                                 |
| LS_GROUP_ID | bigint(20)    | NO      | The ID of the log stream group.                               |
| STATUS      | varchar(100)  | NO      | The status of the log stream. The possible values are as follows: <ul><li>CREATING: The log stream is being created. </li><li>NORMAL: The log stream is in the normal state. </li><li>DROPPING: The log stream is being deleted. </li><li>PRE_TENANT_DROPPING: A special status of a system log stream, indicating the start of deleting all log streams in the tenant. </li><li>TENANT_DROPPING: The tenant is being deleted, and the log stream is being deleted. </li><li>DROPPED: The log stream has been recycled or is being recycled. </li><li>WAIT_OFFLINE: The log stream is waiting to be recycled. </li><li>CREATE_ABORT: The creation of the log stream is stopped. </li></ul>        |
| FLAG        | varchar(2048) | NO      | The flags of the log stream. The possible values are as follows: <ul><li>None: The log stream is in the normal state. </li><li>DUPLICATE: The log stream is a broadcast log stream of a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: You cannot create a tablet on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: You cannot create a tablet on the broadcast log stream. </li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO      | The GTS when the log stream is created. The unit is nanoseconds.              |

## Examples

Query the log streams that existed in the current tenant from the sys tenant.

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```

The query result is as follows:

```shell
+-------+-------------+--------+------+------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN |
+-------+-------------+--------+------+------------+
|     1 |           0 | NORMAL |      |          0 |
+-------+-------------+--------+------+------------+
1 row in set
```
