# oceanbase.CDB_OB_LOG_RESTORE_SOURCE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore sources of all physical restore tenants and standby tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| ID | bigint(20) | NO | The ID of the log restore source. |
| TYPE | varchar(32) | NO | The type of the log restore source. Valid values: `SERVICE`, `LOCATION`, and `RAWPATH`. <ul><li>`SERVICE`: indicates a network direct log restore source.  </li><li>`LOCATION`: indicates an archive log restore source. </li><li>`RAWPATH`: indicates a user-managed log restore source. </li></ul>|
| VALUE | longtext | NO | The endpoint address of the log restore source. <ul><li>For the `SERVICE` type: the endpoint of the primary tenant, for example, "IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,COMPATIBILITY_MODE=ORACLE,IS_ENCRYPTED=true".  </li><li>For the `LOCATION` type: the archive log directory, for example, "file:///data/1/archive/". </li><li>For the `RAWPATH` type: the user-defined directory. </li></ul>|
| RECOVERY_UNTIL_SCN | bigint(20) unsigned | NO | The maximum SCN of logs to be obtained. The value can be INT64_MAX or a positive finite value. |
| RECOVERY_DELAY      | bigint(20) | NO | The synchronization delay of the tenant, in microseconds. Default value: 0, indicating no delay. <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.4.2 BP2. </p></main> |

## Sample query

Query the log restore sources of a physical restore tenant and a standby tenant as the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_LOG_RESTORE_SOURCE\G
```
