# oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS` view displays information about backup validation tasks initiated by the current tenant. Each job corresponds to a backup validation instruction.

## Columns

| Column             | Type           | Nullable | Description           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | bigint(20)     | NO   | The task ID.     |
| INCARNATION         | bigint(20)     | NO   | The incarnation ID.     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | The ID of the tenant that initiated the job.   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | The job ID of the job that initiated the job. If the value is 0, the current job initiated the job.     |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | The tenant ID of the user tenant that needs to execute the validation task. If the value is empty, the current tenant executes the validation task.     |
| TYPE                | varchar(64)    | NO   | The type of the validation task:<ul><li>`DATABASE`: Validates all backup sets and archive log pieces under the backup path and archive path.</li> <li>`BACKUPSET`: Validates the specified backup set.</li> <li>`ARCHIVELOG_PIECE`: Validates the specified archive log piece.</li></ul>     |
| PATH                | longtext       | YES  | The backup path or archive log path specified by the user for validation. If the value is empty, the task does not specify a path.     |
| PATH_TYPE           | varchar(64)    | YES  | The type of validation on the specified path (if the value is empty, the task does not specify a path):<ul><li>`BACKUPSET`: Validates the backup set under the specified path.</li> <li>`ARCHIVELOG_PIECE`: Validates the archive log piece under the specified path.</li></ul>     |
| ID                  | longtext       | YES  | <p>The `backup_set_id` of the backup set to be validated or the `piece_id` of the archive log piece to be validated.</p><p>By default, the value is empty, indicating that all backup sets and archive log pieces under the current backup path and archive path are to be validated. When the user specifies the `backup_set_id` of the backup set or the `piece_id` of the archive log piece to be validated, the value changes to the corresponding ID or ID list.</p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | The validation level:<ul><li>`basic`: Only checks the completeness of the file list.</li> <li>`physical`: Checks the correctness and logical consistency of the physical data.</li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | The start time of the validation task.     |
| END_TIMESTAMP       | timestamp(6)   | NO   | The end time of the validation task.     |
| STATUS              | varchar(64)    | NO   | The job status:<ul><li>`INIT`: The validation task is being initialized.</li> <li>`DOING`: The validation task is in progress.</li> <li>`COMPLETED`: The validation task has been completed.</li> <li>`FAILED`: The validation task has failed.</li> <li>`CANCELED`: The validation task has been canceled.</li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | The number of retries.     |
| TASK_COUNT          | bigint(20)     | YES  | The total number of validation tasks for the backup set or archive log piece.     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | The number of successful validation tasks for the backup set or archive log piece.     |
| RESULT              | bigint(20)     | NO   | The error code information of the validation result.    |
| DESCRIPTION         | varchar(4096)  | YES  | The external information provided by OCP.    |
| COMMENT             | varchar(4096)  | YES  | The description of the reason for the validation task failure.      |

## Sample query

Query information about backup validation tasks initiated by the current tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS\G
```
