# oceanbase.CDB_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the major compaction information of each zone for all tenants under the sys tenant.

## Columns

|       Column        |      Type      | Nullable |         Description         |
|-------------------|--------------|------------|----------------------------------------------|
| TENANT_ID              | bigint(20) | NO         | The ID of the tenant.            |
| ZONE              | varchar(128) | NO         | The name of the zone.            |
| BROADCAST_SCN | bigint(20) unsigned   | NO         | The version number of the major compaction broadcast.           |
| LAST_SCN      | bigint(20) unsigned   | NO         | The version number of the last major compaction.          |
| LAST_FINISH_TIME  | timestamp(6)   | NO         | The end time of the last major compaction.          |
| START_TIME        | timestamp(6)   | NO         | The start time of the major compaction.             |
| STATUS            | varchar(10)  | NO         | <ul><li> `IDLE`: No major compaction is in progress.  </li><li>`COMPACTING`: A major compaction is in progress. </li></ul>    |

## Sample query

Query the major compaction information of each zone for all tenants under the sys tenant.

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_ZONE_MAJOR_COMPACTION;
```
