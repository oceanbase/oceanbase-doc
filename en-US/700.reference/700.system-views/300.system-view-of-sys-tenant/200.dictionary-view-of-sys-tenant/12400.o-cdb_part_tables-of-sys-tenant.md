# oceanbase.CDB_PART_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays partition information for all tenants' partitioned tables.

## Columns

|           Column            |      Type       | Nullable |  Description  |
|---------------------------|---------------|------------|--------------------------------|
| CON_ID                    | bigint(20)    | NO         | The tenant ID.|
| OWNER                     | varchar(128)  | NO         | The owner of the partitioned table.                                                                                 |
| TABLE_NAME                | varchar(128)  | NO         | The name of the partitioned table.                                                                                  |
| PARTITIONING_TYPE         | varchar(13)   | NO         | The partitioning method. Valid values: <ul><li> HASH </li><li> RANGE </li><li> LIST  </li></ul>      |
| SUBPARTITIONING_TYPE      | varchar(13)   | NO         | The subpartitioning method. Valid values: <ul><li> HASH  </li><li> RANGE   </li><li> LIST </li></ul>   |
| PARTITION_COUNT           | bigint(20)    | NO         | The number of partitions in the partitioned table.                                                                                |
| DEF_SUBPARTITION_COUNT    | bigint(20)    | NO         | The number of subpartitions in a composite partitioned table.                                                                        |
| PARTITIONING_KEY_COUNT    | bigint(21)    | NO         | The number of partitioning keys.                                                                                  |
| SUBPARTITIONING_KEY_COUNT | bigint(21)    | NO         | The number of subpartitioning keys in a composite partitioned table.                                                                       |
| STATUS                    | varchar(8)    | NO         | This column is not supported. It is set to NULL by default.                                                                 |

| DEF_PCT_INCREASE          | varchar(40)   | NO         | This column is not supported. It is set to NULL by default.                                                                 |

| DEF_FREELIST_GROUPS       | bigint(0)     | NO         | This column is not supported. It is set to NULL by default.                                                                 |
| DEF_LOGGING               | varchar(7)    | NO         | This column is not supported. It is NULL by default.                                                                 |
| DEF_COMPRESSION           | varchar(8)    | NO         | Indicates whether compression is enabled.                                                                                  |
| DEF_COMPRESS_FOR          | varchar(12)   | NO         | The compression method. |
| DEF_BUFFER_POOL           | varchar(7)    | NO         | This column is not supported. It is NULL by default.                                                                 |
| DEF_FLASH_CACHE           | varchar(7)    | NO         | This column is not supported. It is NULL by default.                                                                 |

| INTERVAL                  | text          | YES        | This column is not supported. It is NULL by default.                                                                 |

| INTERVAL_SUBPARTITION     | text          | NO         | The string that specifies the subpartition interval.     |

| DEF_INDEXING              | varchar(3)    | NO         | Indicates the index attribute specified for the table. Valid values:<ul><li>ON-INDEXING: ON is explicitly specified, or no index attribute is specified. </li><li>OFF-INDEXING: OFF is specified. </li></ul>    |

| DEF_INMEMORY_SERVICE      | varchar(12)   | NO         | This column is not supported. It is NULL by default.                       |
| DEF_INMEMORY_SERVICE_NAME | text          | NO         | This column is not supported. It is NULL by default.           |
| AUTO                      | varchar(3)    | NO         | Indicates whether the table is automatically partitioned:<ul><li>YES</li><li>NO</li></ul>                       |
