# DBA_OB_TRUSTED_ROOT_CERTIFICATE

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The view was introduced in V4.3.0. </p>
</main>

## Description

The `DBA_OB_TRUSTED_ROOT_CERTIFICATE` view displays the list of CA root certificates trusted by the OBServer cluster and other related information, such as the certificate expiration time.

## Field description

| **Field** | **Type** | **NULL?** | **Description** |
| ------------ | -------- | ------------------ | -------- |
| COMMON_NAME       | varchar(256) | NO   |  The common name of the certificate.    |
| DESCRIPTION       | varchar(256) | NO   |  A description of the certificate source and purpose.    |
| CERT_EXPIRED_TIME | timestamp(6) | NO   |  The expiration time of the certificate.    |

## Examples

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TRUSTED_ROOT_CERTIFICATE;
```
