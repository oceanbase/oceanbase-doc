# oceanbase.CDB_OB_TENANT_FLASHBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

The `CDB_OB_TENANT_FLASHBACK_LOG_SCN` view displays information about each log truncation in all tenants of the current cluster.

## Columns

| Column              | Type         | Nullable | Description                                       |
|---------------------|--------------|----------|------------------------------------------|
| TENANT_ID           | bigint(20)   | NO       | The tenant ID.                            |
| TIMESTAMP           | timestamp(6) | NO       | The time when the log was truncated. The unit is microseconds.                   |
| SWITCHOVER_EPOCH    | bigint(20)   | NO       | The `SWITCHOVER_EPOCH` when the tenant role was switched to `NORMAL`. `SWITCHOVER_EPOCH` is a unique identifier for a switchover or failover operation. |
| OP_TYPE              | varchar(64)  | NO       | The operation type. Valid values: <ul><li>`FAILOVER_TO_PRIMARY`: This operation type indicates a failover operation. This operation switches the standby tenant to the primary tenant when the primary tenant is unavailable. </li><li>`FLASHBACK_STANDBY_LOG`: This operation type indicates a log truncation operation. This operation truncates the logs of the standby tenant to the specified SCN. </li></ul> |
| FLASHBACK_LOG_SCN | bigint(20) unsigned | NO         | The end SCN of the log truncation.             |

## Sample query

Query information about each log truncation in all tenants of the current cluster.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_TENANT_FLASHBACK_LOG_SCN;
```
