# oceanbase.DBA_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the meta information of a table group, mainly its partition information.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Starting from V4.2.0, the partition attribute fields in this view will no longer have meaning and are uniformly displayed as <code>NONE</code> or </code>NULL</code>.</p>
</main>

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | -------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| TABLEGROUP_NAME | varchar(128) | NO | Table group name |
| PARTITIONING_TYPE | varchar(13) | NO | Partition type of a partitioned table group's partition:<ul><li>`NONE`: Non-partitioned table group   </li><li>`HASH`: HASH partitioning (single partitioning key)   </li><li>`KEY`: KEY partitioning   </li><li>`RANGE`: RANGE partitioning (single partitioning key)   </li><li>`RANGE COLUMNS`: RANGE COLUMNS partitioning   </li><li>`LIST`: LIST partitioning (single partitioning key)   </li><li>`LIST COLUMNS`: LIST COLUMNS partition   </li><li>`UNKNOWN`: exception type</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is <code>NULL</code> starting from V4.2.0.</p></main> |
| SUBPARTITIONING_TYPE | varchar(13) | NO | Partition type of a subpartition of a partitioned table group:<ul><li>`NONE`: Non-partitioned table groups, partitioned table groups   </li><li>`HASH`: HASH partitioning (single partitioning key)   </li><li>`KEY`: KEY partitioning   </li><li>`RANGE`: RANGE partitioning (single partitioning key)   </li><li>`RANGE COLUMNS`: RANGE COLUMNS partitioning   </li><li>`LIST`: LIST partitioning (single partitioning key)   </li><li>`LIST COLUMNS`: LIST COLUMNS partition   </li><li>`UNKNOWN`: Exception type.</li></ul><main id="notice" type='explain'><h4>Note</h4><p>Starting from V4.2.0, the value of this field is <code>NULL</code>.</p></main> |
| PARTITION_COUNT | bigint(0) | NO | The value is`NULL` |
| DEF_SUBPARTITION_COUNT | bigint(0) | NO | The value is`NULL` |
| PARTITIONING_KEY_COUNT | bigint(0) | NO | The value is`NULL` |
| SUBPARTITIONING_KEY_COUNT | bigint(0) | NO | The value is`NULL` |
| SHARDING | varchar(20) | NO | The SHARDING attribute of the table group. Valid values: <ul><li>`NONE`: For tables in this table group, all partitions of all tables within the table group are placed on the same server, and there are no restrictions on the tables that can be added to the table group. </li> <li>`PARTITION`: For tables in the table group with this attribute, the data of each table is scattered by its partition. For a subpartitioned table, all subpartitions under a partition are aggregated together.</li> <li>`ADAPTIVE`: For the tables in the table group with this attribute, the data of each table is scattered in an adaptive manner. That is, if a table in the table group is a partitioned table, its data is scattered by partitions; if a table in the table group is a subpartitioned table, its data is scattered by subpartitions within each partition.</li></ul>  <main id="notice" type='explain'><h4>Note</h4><p>This field is available starting with V4.2.0. </p></main> |
| SCOPE | varchar(20) | NO | Table group's`SCOPE`Attribute. Valid values: <ul><li>`SERVER`: Indicates that the leaders of all partition groups are distributed on the same node.  </li><li>`ZONE`: Indicates that the leaders of all partition groups are distributed within the same zone and are scattered across nodes within that zone. </li><li>`CLUSTER`: Indicates that the leaders of all partition groups are scattered across nodes in the cluster.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this field is available starting with V4.4.2 BP1.</p></main> |
