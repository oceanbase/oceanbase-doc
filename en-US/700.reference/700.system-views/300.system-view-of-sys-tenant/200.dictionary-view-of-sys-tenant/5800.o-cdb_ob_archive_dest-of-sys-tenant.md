# oceanbase.CDB_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the archive path configuration information of all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| DEST_NO | bigint(20) | NO | The identifier of log_archive_dest_n. |
| NAME | varchar(1024) | NO | The name of the field, which contains the following fields: <ul><li>`binding`: the priority mode of archiving and business. </li> <li>`dest_id`: the ID of the archive destination. </li> <li>`path`: the archive path. </li> <li>`piece_switch_interval`: the piece switching cycle. </li> <li>`state`: the state of the archive destination. </li></ul> |
| VALUE | varchar(4096) | NO | The value of the `name` field. |

## Sample query

In the sys tenant, query the archive path configuration information of all tenants.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_ARCHIVE_DEST;
```
