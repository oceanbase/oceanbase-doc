# oceanbase.CDB_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the archive path configuration information for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| DEST_NO | bigint(20) | NO | Identifies log_archive_dest_n |
| NAME | varchar(1024) | NO | Field name, containing the following fields:<ul><li>`binding`: Priority mode for archiving and business </li> <li>`dest_id`: The ID of the destination archive.</li> <li>`path`: Archive path information</li> <li>`piece_switch_interval`: The switching cycle of the piece.</li> <li>`state`: The status of the destination archive.</li></ul> |
| VALUE | varchar(4096) | NO | `name`Field Value |

## Sample query

In the sys tenant, view the archive path configuration information for all tenants.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_ARCHIVE_DEST;
```
