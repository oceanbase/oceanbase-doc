# oceanbase.DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the configuration information related to the WR feature.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or a meta tenant. </li></ul> |
| SNAP_INTERVAL | varchar(64) | NO | The interval between snapshots. The value is in the `DD HH:mm:SS` format for easy reading. |
| RETENTION | varchar(64) | NO | The retention period of each snapshot. The value is in the `DD HH:mm:SS` format for easy reading. |
| TOPNSQL | bigint(20) | NO | The topN SQL statements stored. |

## Sample query

Query the configuration information related to the WR feature.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_CONTROL LIMIT 1\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
    TENANT_ID: 1
SNAP_INTERVAL: +0 01:00:00
    RETENTION: +7 00:00:00
      TOPNSQL: 30
1 row in set (0.008 sec)
```
