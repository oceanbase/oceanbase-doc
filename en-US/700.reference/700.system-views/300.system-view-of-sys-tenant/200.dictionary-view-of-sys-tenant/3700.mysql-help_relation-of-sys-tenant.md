# mysql.help_relation

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view collaborates with the `mysql.help_category`, `mysql.help_topic`, and `mysql.help_keyword` views to generate help commands.

## Columns

|    **Column**     |   **Type**   | **Nullable** | **Description** |
|-----------------|------------|----------------|--------|
| help_topic_id   | bigint(20) | NO             | The ID of the topic. |
| help_keyword_id | bigint(20) | NO             | The ID of the keyword. |
