# oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view records the position range of the data dictionary in the system log stream, which facilitates the consumption of the data dictionary by Change Data Capture (CDC).

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | The SNAPSHOT SCN of the tenant when the data dictionary was generated. |
| REPORT_TIME | timestamp(6) | YES | The time when the data dictionary was generated and reported to the internal table. (Unit: microseconds) |
| START_LSN | bigint(20) unsigned | NO | The LSN of the first log in the system log stream where the data dictionary was persisted. |
| END_LSN | bigint(20) unsigned | NO | The LSN of the last log in the system log stream where the data dictionary was persisted. |

## Sample query

Query the position range of the data dictionary in the system log stream of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG;
```

The query result is as follows:

```shell
+---------------------+----------------------------+-----------+-----------+
| SNAPSHOT_SCN        | REPORT_TIME                | START_LSN | END_LSN   |
+---------------------+----------------------------+-----------+-----------+
| 1723084121964378000 | 2024-08-08 10:28:42.014127 |  10713062 |  10713062 |
| 1723170522400303000 | 2024-08-09 10:28:42.439283 | 139661239 | 139661239 |
+---------------------+----------------------------+-----------+-----------+
2 rows in set
```
