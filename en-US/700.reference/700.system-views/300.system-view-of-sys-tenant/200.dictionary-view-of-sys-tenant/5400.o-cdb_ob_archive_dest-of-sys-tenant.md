# oceanbase.CDB_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Purpose

This view displays the archive path configuration of all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| DEST_NO | bigint(20) | NO | Identifies `log_archive_dest_n` |
| NAME | varchar(1024) | NO | Field name. The field contains the following items:<ul><li>`binding`: priority mode between archiving and business operations</li> <li>`dest_id`: archive destination ID</li> <li>`path`: archive path information</li> <li>`piece_switch_interval`: piece switch interval</li> <li>`state`: archive destination status</li></ul> |
| VALUE | varchar(4096) | NO | Value of the field specified by `name` |

## Sample query

The sys tenant views the archive path configuration of the tenant with tenant ID `1002`.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_ARCHIVE_DEST WHERE TENANT_ID = 1002;
```
