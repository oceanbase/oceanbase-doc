# oceanbase.DBA_OB_UNIT_CONFIGS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the unit specifications of all tenants.

## Columns

|      Column       |      Type      | Nullable |        Description        |
|-----------------|--------------|------------|------------------|
| UNIT_CONFIG_ID  | bigint(20)   | NO         | The ID of the unit specification.       |
| NAME            | varchar(128) | NO         | The name of the unit specification.        |
| CREATE_TIME         | timestamp(6)       | YES         | The time when the unit specification was created.         |
| MODIFY_TIME         | timestamp(6)       | YES         | The time when the information was updated.         |
| MAX_CPU         | double       | NO         | The upper limit of the CPU specification.         |
| MIN_CPU         | double       | NO         | The lower limit of the CPU specification.         |
| MEMORY_SIZE      | bigint(20)   | NO         | The memory specification, in bytes.     |
| LOG_DISK_SIZE      | bigint(20)   | NO         | The log disk specification, in bytes.     |
| DATA_DISK_SIZE        | bigint(20)   | NO         | The size of the local cache that can be used by the unit, in bytes. This parameter is valid only in Shared-Storage (SS) mode. In Shared-Nothing (SN) mode, the value of this parameter is `NULL`, indicating that the disk space of other tenants can be used. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is available starting with V4.3.4. </p></main>   |
| MAX_IOPS        | bigint(20)   | NO         | The upper limit of the IOPS specification.     |
| MIN_IOPS        | bigint(20)   | NO         | The lower limit of the IOPS specification.     |
| IOPS_WEIGHT   | bigint(20)   | NO         | The IOPS weight.   |
| MAX_NET_BANDWIDTH     | bigint(20)   | NO         | The maximum network bandwidth of the unit, in bytes.  <main id="notice" type='explain'><h4>Note</h4><p>This parameter is available starting with V4.3.4. </p></main>    |
| NET_BANDWIDTH_WEIGHT  | bigint(20)   | NO         | The weight of the network bandwidth of the unit. <main id="notice" type='explain'><h4>Note</h4><p>This parameter is available starting with V4.3.4. </p></main>     |
