# oceanbase.CDB_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.4.2. </p>
</main>

## Purpose

The `oceanbase.CDB_OB_LOB_CHECK_EXCEPTION_RESULT` view displays the tables and tablets with LOB consistency check exceptions, and the exception types, under the sys tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------------- | ----------- | --------------------- | ----------- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| LS_ID | bigint(20) | NO | The log stream ID. |
| CREATE_TIME | timestamp(6) | NO | The time when the exception result was created. |
| UPDATE_TIME | timestamp(6) | NO | The time when the exception result was last modified. |
| TABLE_NAME | varchar(256) | NO | The name of the abnormal table. |
| TABLE_ID | bigint(20) | NO | The ID of the abnormal table. |
| INCONSISTENCY_TYPE | varchar(16) | NO | Exception type. <ul><li>LOB_NOT_FOUND: The primary table points to a non-existent LOB.</li><li>LOB_LEN_MISMATCH: The metadata length does not match the actual length.</li><li>LOB_ORPHANED: The LOB exists, but the primary table has no locator.</li></ul> |
| TABLET_IDS | longtext | YES | The IDs of the abnormal partitions. |

## Sample query

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_LOB_CHECK_EXCEPTION_RESULT;
```
