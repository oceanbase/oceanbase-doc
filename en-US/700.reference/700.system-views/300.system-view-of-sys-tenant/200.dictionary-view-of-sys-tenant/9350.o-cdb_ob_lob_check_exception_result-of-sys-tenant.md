# oceanbase.CDB_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view is available starting with V4.6.0. </p>
</main>

## Overview

The `oceanbase.CDB_OB_LOB_CHECK_EXCEPTION_RESULT` view is used to display the abnormal tables and tablets that have undergone LOB consistency verification, as well as the exception types, in the sys tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------- | ----------- | --------------------- | ----------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| CREATE_TIME | timestamp(6) | NO | Exception Result Creation Time |
| UPDATE_TIME | timestamp(6) | NO | Modified Time of Abnormal Result |
| TABLE_NAME | varchar(256) | NO | Exceptional Table Name |
| TABLE_ID | bigint(20) | NO | ID of the abnormal table object |
| INCONSISTENCY_TYPE | varchar(16) | NO | Exception type. <ul><li>LOB_NOT_FOUND: The primary table points to a non-existent LOB.</li><li>LOB_LEN_MISMATCH: The metadata length does not match the actual length.</li><li>LOB_ORPHANED: The LOB exists, but the primary table has no locator.</li></ul> |
| TABLET_IDS | longtext | YES | Exception Partition ID |

## Sample query

```shell
obclient > SELECT * FROM oceanbase.CDB_OB_EXTERNAL_RESOURCES;
```
