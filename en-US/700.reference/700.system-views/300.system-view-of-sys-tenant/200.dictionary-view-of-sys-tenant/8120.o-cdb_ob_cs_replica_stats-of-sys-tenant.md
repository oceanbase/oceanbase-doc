# oceanbase.CDB_OB_CS_REPLICA_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.5 BP1. </p>
</main>

## Purpose

This view displays the progress of converting tablets to columnar storage in the log streams of C replicas on all OBServer nodes for all tenants.

## Columns

| Column                   | Type          | Nullable      | Description                                |
|---------------------------|---------------|---------------------|-------------------------------------|
| TENANT_ID                 | bigint(20)    | NO   | The tenant ID. |
| SVR_IP                    | varchar(46)   | NO   | The IP address of the server where the C replica is located. |
| SVR_PORT                  | bigint(20)    | NO   | The port number of the server where the C replica is located.  |
| LS_ID                     | bigint(20)    | NO   | The log stream ID.  |
| TOTAL_TABLET_CNT          | bigint(20)    | NO   | The number of partitions to be converted to columnar storage.  |
| AVAILABLE_TABLET_CNT      | decimal(42,0) | NO   | The number of available partitions.    |
| TOTAL_MACRO_BLOCK_CNT     | decimal(42,0) | NO   | The total number of baseline macroblocks (ignoring multi-versioning).  |
| AVAILABLE_MACRO_BLOCK_CNT | decimal(42,0) | NO   | The number of available baseline macroblocks (ignoring multi-versioning).   |
| AVAILABLE                 | varchar(5)    | NO   | Indicates whether the log stream is fully available:<ul><li>`TRUE`: Available. A log stream is considered fully available when all tablets on it are available.</li> <li>`FALSE`: Not available</li></ul>  |

## Sample query

Query the progress of converting tablets to columnar storage in the log streams of C replicas on all OBServer nodes for the tenant with ID 1004 in the sys tenant.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_CS_REPLICA_STATS WHERE TENANT_ID=1004;
```

The query result is as follows:

```shell
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
| TENANT_ID | SVR_IP         | SVR_PORT | LS_ID | TOTAL_TABLET_CNT | AVAILABLE_TABLET_CNT | TOTAL_MACRO_BLOCK_CNT | AVAILABLE_MACRO_BLOCK_CNT | AVAILABLE |
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
|      1004 | xx.xxx.xxx.212 |    63000 |  1001 |             1019 |                 1019 |                 10706 |                     10706 | TRUE      |
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
1 row in set
```

To estimate the progress of converting rowstore to columnar storage, calculate the value of `AVAILABLE_TABLET_CNT / TOTAL_TABLET_CNT` or `AVAILABLE_MACRO_BLOCK_CNT / TOTAL_MACRO_BLOCK_CNT`.
