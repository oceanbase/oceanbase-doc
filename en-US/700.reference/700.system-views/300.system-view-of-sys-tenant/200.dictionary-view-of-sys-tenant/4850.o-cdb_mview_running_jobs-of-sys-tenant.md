# oceanbase.CDB_MVIEW_RUNNING_JOBS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>This view is available starting with V4.4.0 for V4.4.x. </li><li>This view is available starting with V4.3.5 BP2 for V4.3.5. </li></ul></p>
</main>

## Purpose

This view is accessible only to the sys tenant. It displays all current materialized view-related tasks across all tenants, including refresh tasks and MLOG cleanup tasks.

## Columns

|  **Column**  | **Type** | **Nullable** | **Description** |
|----------------|----------|---------------------|---------|
| SVR_IP         | varchar(46)         | NO   | The IP address of the node where the leader of log stream 1 of the tenant resides.|
| SVR_PORT       | bigint(20)          | NO   | The port of the node where the leader of log stream 1 of the tenant resides.|
| TENANT_ID      | bigint(20)          | NO   | The tenant ID.|
| TABLE_NAME     | varchar(256)        | NO   | The name of the table associated with the task.<ul><li>For a refresh task: the name of the materialized view table.</li><li>For an MLOG cleanup task: the name of the MLOG table.</li></ul>|
| JOB_TYPE       | varchar(64)         | NO   | The type of the task. Valid values:<ul><li>INVALID</li><li>COMPLETE REFRESH</li><li>FAST REFRESH</li><li>PURGE MLOG</li></ul>|
| SESSION_ID     | bigint(20) unsigned | NO   | The session ID that initiated the task.|
| READ_SNAPSHOT  | bigint(20)          | NO   | The snapshot point used by the task.|
| PARALLEL       | bigint(20)          | NO   | The parallelism of the task.|
| JOB_START_TIME | timestamp(6)        | NO   | The start time of the task.|
