# oceanbase.DBA_OB_TABLET_REPLICAS

## Purpose

Displays information about all tablet replicas in the tenant, including the unique identifier of each tablet replica, which is composed of the joint key: `<TABLET_ID, SVR_IP, SVR_PORT, LS_ID>`.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V4.0.0. </p>
</main>

## Columns

| Column | Type | Nullable? | Description |
|---------------|-------------|------------|------------------------------------------------------------|
| CREATE_TIME     | timestamp(6)  | NO         | Creation time    |
| MODIFY_TIME     | timestamp(6)  | NO         | Modification time     |
| TABLET_ID     | bigint(20)  | NO         | Tablet ID     |
| SVR_IP        | varchar(46) | NO         | Server IP address     |
| SVR_PORT      | bigint(20)  | NO         | Server port number        |
| LS_ID         | bigint(20)  | NO         | ID of the log stream to which the tablet belongs             |
| COMPACTION_SCN  | bigint(20) unsigned  | NO         | Version number of the data snapshot         |
| DATA_SIZE     | bigint(20)  | NO         | Actual data size        |
| REQUIRED_SIZE | bigint(20)  | NO         | Size of the allocated space. Data is stored in macroblocks (2 MB each), so `REQUIRED_SIZE >= DATA_SIZE`. |
