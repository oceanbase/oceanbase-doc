# oceanbase.DBA_OB_LOG_RESTORE_SOURCE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the log restore sources of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| ID | bigint(20) | NO | The ID of the log restore source. |
| TYPE | varchar(32) | NO | The type of the log restore source. Valid values: <ul><li>SERVICE: a log restore source that directly connects to the network.  </li><li>LOCATION: an archived log restore source. </li><li>RAWPATH: a user-managed log restore source. </li></ul>|
| VALUE | longtext | NO | The entry address of the log restore source. <ul><li>For a SERVICE type log restore source: the entry address of the primary tenant, for example, "IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,COMPATIBILITY_MODE=ORACLE,IS_ENCRYPTED=true".  </li><li>For a LOCATION type log restore source: the log archive directory, for example, "file:///data/1/archive/". </li><li>For a RAWPATH type log restore source: the user-defined directory. </li></ul>|
| RECOVERY_UNTIL_SCN | bigint(20) unsigned | NO | The upper limit of the log. It can be INT64_MAX or a finite value greater than 0. |
