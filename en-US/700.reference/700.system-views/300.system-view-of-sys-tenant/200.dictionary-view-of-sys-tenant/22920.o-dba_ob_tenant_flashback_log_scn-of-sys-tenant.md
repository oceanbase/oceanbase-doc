# oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

The `DBA_OB_TENANT_FLASHBACK_LOG_SCN` view displays information about each log truncation for the current tenant.

## Columns

| Column               | Type         | Nullable | Description                                       |
|---------------------|--------------|----------|------------------------------------------|
| TENANT_ID           | bigint(20)          | NO       | The tenant ID. |
| TIMESTAMP           | timestamp(6)        | NO       | The creation time, in microseconds.                   |
| SWITCHOVER_EPOCH    | bigint(20)          | NO      | The `SWITCHOVER_EPOCH` value when the tenant role is switched to `NORMAL`. `SWITCHOVER_EPOCH` is a unique identifier for tenant role switching (Switchover/Failover) operations. |
| OP_TYPE              | varchar(64)         | NO       | The operation type. Valid values: <ul><li>`FAILOVER_TO_PRIMARY`: This is the operation type for a failover. When the primary tenant is unavailable, the standby tenant is switched to the primary tenant. </li><li>`FLASHBACK_STANDBY_LOG`: This is the operation type for log truncation of a standby tenant. It truncates the logs of the standby tenant to the specified SCN. </li></ul> |
| FLASHBACK_LOG_SCN   | bigint(20) unsigned | NO      | The endpoint of the log truncation for the tenant.             |

## Sample query

Query information about each log truncation for the current tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```
