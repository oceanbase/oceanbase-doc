# oceanbase.DBA_OB_TASK_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the execution status of the historical statistics collection tasks of the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The ID of the tenant to which the statistics collection task belongs. |
| TASK_ID | varchar(36) | NO | The ID of the statistics collection task. This ID is a UUID and is globally unique. |
| TYPE | varchar(16) | NO | The type of the statistics collection task. |
| STATUS | varchar(8) | NO | The status of the statistics collection task. Valid values: SUCCESS and FAILED. |
| TABLE_COUNT | bigint(20) | YES | The number of tables to be collected by the statistics collection task. |
| FAILED_COUNT | bigint(20) | YES | The number of tables that failed to be collected by the statistics collection task. |
| START_TIME | datetime(6) | NO | The time when the statistics collection task started. |
| END_TIME | datetime(6) | NO | The time when the statistics collection task ended. |

## Sample query

Query the historical execution status of the manual statistics collection task of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TASK_OPT_STAT_GATHER_HISTORY WHERE TYPE='MANUAL GATHER';
```
