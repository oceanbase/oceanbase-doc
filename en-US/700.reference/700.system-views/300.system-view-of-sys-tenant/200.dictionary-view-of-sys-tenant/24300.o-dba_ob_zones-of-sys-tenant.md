# oceanbase.DBA_OB_ZONES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the information of all zones.

## Columns

|  Column  |      Type       | Nullable |        Description         |
|--------|---------------|------------|-----------------------------|
| ZONE   | varchar(128)  | NO         | The name of the zone.           |
| CREATE_TIME | timestamp(6)  | NO    | The time when the zone was created.     |
| MODIFY_TIME | timestamp(6)  | NO    | The time when the zone was last modified.    |
| STATUS | varchar(4096) | NO         | The status of the zone. Valid values: <ul><li>`ACTIVE`: The zone is active and provides services. </li><li>`INACTIVE`: The zone is stopped. </li></ul>    |
| IDC    | varchar(4096) | NO         | The information about the IDC to which the zone belongs.   |
| REGION | varchar(4096) | NO         | The information about the region to which the zone belongs.|
| TYPE   | varchar(4096) | NO         | The type of the zone. Valid values: <ul><li>`ReadWrite`: Read/write zone. </li><li>`Encryption`: Encrypted zone. </li></ul>   |

## Sample query

Query the information about all zones in the cluster as the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONES;
```

The query result is as follows:

```shell
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC  | REGION  | TYPE      |

| zone1 | 2025-01-06 16:31:31.733840 | 2025-01-07 13:53:45.645465 | ACTIVE |      | region1 | ReadWrite |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
1 row in set
```
