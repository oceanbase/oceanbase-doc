# oceanbase.CDB_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the association between tables and table groups in all tenants under the sys tenant. Tables not in a table group are not displayed.

## Columns

|      Column       |      Type       | Nullable |      Description       |
|-----------------|---------------|------------|---------------|
| TENANT_ID       | bigint(20)    | NO         | The tenant ID.         |
| TABLEGROUP_NAME | VARCHAR2(128) | NO         | The name of the table group.           |
| OWNER           | VARCHAR2(128) | NO         | The name of the database to which the table belongs. |
| TABLE_NAME      | VARCHAR2(256) | NO         | The name of the table.       |
| SHARDING        | varchar(20)   | NO         | The SHARDING attribute of the table group. <ul><li>`NONE`: All partitions of all tables in the table group are located on the same server. No restrictions are imposed on tables added to the table group. </li> <li>`PARTITION`: Data of each table in the table group is scattered across primary partitions. If the table is a secondary partitioned table, all secondary partitions under each primary partition are located on the same server. </li> <li>`ADAPTIVE`: Data of each table in the table group is scattered in an adaptive manner. Specifically, if the table is a primary partitioned table, data is scattered across primary partitions. If the table is a secondary partitioned table, data is scattered across secondary partitions under each primary partition. </li></ul>    |

## Sample query

In the sys tenant, query the association of the table group named `tblgroup1`.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'tblgroup1';
```

The query result is as follows:

```shell
+-----------+-----------------+-------+------------+----------+
| TENANT_ID | TABLEGROUP_NAME | OWNER | TABLE_NAME | SHARDING |
+-----------+-----------------+-------+------------+----------+
|      1002 | tblgroup1       | test  | tbl3       | ADAPTIVE |
|      1004 | TBLGROUP1       | SYS   | TBL3       | NONE     |
+-----------+-----------------+-------+------------+----------+
2 rows in set
```
