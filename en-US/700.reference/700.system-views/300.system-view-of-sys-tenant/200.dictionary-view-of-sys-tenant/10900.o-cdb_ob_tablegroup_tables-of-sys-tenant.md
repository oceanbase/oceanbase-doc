# oceanbase.CDB_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

The system tenant displays the table and table group relationships for all tenants. Tables that are not part of a table group are not displayed.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------- | --------------- | ------------ | --------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TABLEGROUP_NAME | VARCHAR2(128) | NO | Table group name |
| OWNER | VARCHAR2(128) | NO | The name of the database to which the table belongs. |
| TABLE_NAME | VARCHAR2(256) | NO | Table name |
| SHARDING | varchar(20) | NO | The SHARDING attribute of the table group:<ul><li>`NONE`: All partitions of all tables in the table group are placed on the same server, and there are no restrictions on which tables can be added to the table group. </li> <li>`PARTITION`: The data of each table in the table group is scattered by its partition. For a subpartitioned table, all subpartitions under a partition are aggregated together.</li> <li>`ADAPTIVE`: The data of each table in the table group is scattered in an adaptive manner. That is, if the tables in the table group are partitioned tables, they are scattered by partitions; if the tables in the table group are subpartitioned tables, they are scattered by subpartitions within each partition.</li></ul> |
| SCOPE | varchar(20) | NO | Table group's`SCOPE`Attribute. Valid values: <ul><li>`SERVER`: Indicates that the leaders of all partition groups are distributed on the same node.  </li><li>`ZONE`: Indicates that the leaders of all partition groups are distributed within the same zone and are scattered across nodes within that zone.  </li><li>`CLUSTER`: Indicates that the leaders of all partition groups are scattered across nodes in the cluster.</li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For V4.4.2, this field is available starting with V4.4.2 BP1.</p></main> |

## Sample query

In the sys tenant, query the association relationships of the table group named `tblgroup2`.

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TABLEGROUP_TABLES
    WHERE tablegroup_name = 'tblgroup2'
    AND TENANT_ID = '1002';
```

The return result is as follows:

```shell
+-----------+-----------------+---------+------------+----------+--------+
| TENANT_ID | TABLEGROUP_NAME | OWNER   | TABLE_NAME | SHARDING | SCOPE  |
+-----------+-----------------+---------+------------+----------+--------+
|      1002 | tblgroup2       | test_db | test_tbl3  | NONE     | SERVER |
|      1002 | tblgroup2       | test_db | test_tbl4  | NONE     | SERVER |
+-----------+-----------------+---------+------------+----------+--------+
2 rows in set
```
