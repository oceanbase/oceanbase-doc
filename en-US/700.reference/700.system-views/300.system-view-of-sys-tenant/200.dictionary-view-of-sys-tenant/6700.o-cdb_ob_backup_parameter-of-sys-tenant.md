# oceanbase.CDB_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the data backup parameters of all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| NAME | varchar(1024) | NO | The parameter name. |
| VALUE | longtext | NO | The parameter value. |

## Sample query

In the sys tenant, query the data backup parameters of the tenant whose tenant ID is 1002.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_PARAMETER WHERE TENANT_ID = 1002;
```

The query result is as follows:

```shell
+-----------+------------------+-----------------------------------------+
| TENANT_ID | NAME             | VALUE                                   |
+-----------+------------------+-----------------------------------------+
|      1002 | data_backup_dest | file:///home/admin/oceanbase/backupdata |
+-----------+------------------+-----------------------------------------+
1 row in set
```
