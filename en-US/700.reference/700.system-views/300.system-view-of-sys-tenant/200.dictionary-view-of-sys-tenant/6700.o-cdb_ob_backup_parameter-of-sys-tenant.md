# oceanbase.CDB_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Purpose

This view displays the data backup parameters configured for all tenants.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| NAME | varchar(1024) | NO | Parameter name |
| VALUE | longtext | NO | Parameter value |

## Sample query

The sys tenant views the data backup parameter information of the tenant with tenant ID `1002`.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_PARAMETER WHERE TENANT_ID = 1002;
```

The query result is as follows:

```shell
+-----------+------------------+---------------------------------------------------------------------------------------------------------------------------+
| TENANT_ID | NAME             | VALUE                                                                                                                     |
+-----------+------------------+---------------------------------------------------------------------------------------------------------------------------+
|      1002 | data_backup_dest | oss://example_path/data?host=cn-heyuan.aliyuncs.com&access_id=******&access_key=******&checksum_type=md5&enable_worm=true |
+-----------+------------------+---------------------------------------------------------------------------------------------------------------------------+
1 row in set
```
