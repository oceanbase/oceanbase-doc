# oceanbase.DBA_OB_TTL_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.0. </p>
</main>

## Purpose

The `oceanbase.DBA_OB_TTL_TASKS` view displays the execution status of TTL tasks in the SQL mode for the current tenant.

## Columns

| Column         | Type         | Nullable | Description                                       |
|---------------|--------------|-------------|-------------------------------------------|
| TABLE_NAME    | varchar(256) | NO   | The name of the table.     |
| TABLE_ID      | bigint(20)   | NO   | The ID of the table.     |
| TASK_ID       | bigint(20)   | NO   | The ID of the current batch task.     |
| START_TIME    | timestamp(6) | NO   | The start time of the task.     |
| MODIFIED_TIME | timestamp(6) | NO   | The update time of the row.   |
| TRIGGER_TYPE  | varchar(8)   | NO   | The type of the task trigger. Valid values: <ul><li>`PERIODIC`: the system triggers the task periodically. </li> <li>`USER`: the user manually triggers the task. </li></ul>       |
| STATUS        | varchar(10)  | NO   | The status of the task. Valid values: <ul><li>`PENDING`: the task is waiting to reach an executable state. </li> <li>`CANCELED`: the task is canceled. </li> <li>`FINISHED`: the task has ended. </li> <li>`SKIP`: the task did not reach an executable state and is skipped in this round. </li> <li>`FAILED`: the task execution failed. </li> <li>`TRIGGERING`: the task is being executed on the RS node. </li> <li>`SUSPENDING`: the task is being suspended on the RS node. </li> <li>`CANCELING`: the task is being canceled on the RS node. </li> <li>`MOVING`: the RS node is transferring the task execution information to the task history table. </li></ul>     |
| RET_CODE      | varchar(512) | NO   | The error code returned when the task ends.    |
| TASK_TYPE     | varchar(10)  | NO   | The type of the TTL task. Valid values: <ul><li>`NORMAL`: displays tenant-level information. </li> <li>`COMPACTION`: a table-level task that deletes expired data by using compaction. </li></ul>     |
