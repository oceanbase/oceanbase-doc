# oceanbase.CDB_OB_BALANCE_TASKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the load balancing tasks that are being executed by all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or the ID of the meta tenant. </li></ul>|
| TASK_ID | bigint(20) | NO | The ID of the load balancing task. |
| CREATE_TIME | timestamp(6) | YES | The time when the task was created. |
| MODIFY_TIME | timestamp(6) | YES | The time when the information was updated. |
| TASK_TYPE | varchar(64) | NO | The type of the task. <ul><li>`LS_SPLIT`: log stream splitting.  </li><li>`LS_ALTER`: modifying the attributes of a log stream. </li><li>`LS_MERGE`: log stream merging. </li><li>`LS_TRANSFER`: log stream transfer. </li></ul>|
| SRC_LS | bigint(20) | NO | The source log stream (the log data stream generated from the data source). |
| DEST_LS | bigint(20) | NO | The destination log stream. |
| PART_LIST | longtext | YES | The list of partitions, including user table partitions and global index partitions. |
| FINISHED_PART_LIST | longtext | YES | The list of partitions that have completed load balancing. |
| PART_COUNT | bigint(20) | YES | The number of partitions in the partition list. |
| FINISHED_PART_COUNT | bigint(20) | YES | The number of partitions that have completed load balancing. |
| LS_GROUP_ID | bigint(20) | NO | The ID of the log stream group. |
| STATUS | varchar(64) | NO | The status of the task. <ul><li>`INIT`: task creation.  </li><li>`CREATE_LS`: creating a log stream. </li><li>`ALTER_LS`: modifying the attributes of a log stream. </li> <li>`SET_LS_MERGING`: log stream merging. </li> <li>`TRANSFER`: log stream transfer</li> <li>`DROP_LS`: dropping a log stream. </li><li>`COMPLETED`: task execution succeeded. </li><li>`CANCELED`: task canceled. </li></ul>|
| PARENT_LIST | varchar(1024) | YES | The list of parent tasks. |
| CHILD_LIST | varchar(1024) | YES | The list of child tasks. |
| CURRENT_TRANSFER_TASK_ID | bigint(20) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | bigint(20) | NO | The ID of the job to which the current task belongs. |
| COMMENT | longtext | YES | The comment. |

