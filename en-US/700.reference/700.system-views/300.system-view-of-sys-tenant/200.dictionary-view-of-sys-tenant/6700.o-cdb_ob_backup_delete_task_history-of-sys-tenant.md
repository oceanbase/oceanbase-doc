# oceanbase.CDB_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the historical information of completed `backup_set`/`backup_piece` cleanup tasks for each tenant.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| TASK_ID | bigint(20) | NO | The task group ID, used to identify a group of tasks. |
| INCARNATION | bigint(20) | NO | The incarnation ID. |
| JOB_ID | bigint(20) | NO | The task ID, corresponding to the JOB table. |
| TASK_TYPE | varchar(64) | NO | The task type. Valid values: <ul><li>`BACKUP SET`: clean up `backup_set`. </li><li>`BACKUP PIECE`: clean up `backup_piece`. </li></ul> |
| ID | bigint(20) | NO | The task ID, including backup_set and piece. |
| ROUND_ID | bigint(20) | NO | The dest_round_id of the piece. For the cleanup of a backup_set, the ROUND_ID is 0. |
| DEST_ID | bigint(20) | NO | The DEST_ID of the backup destination. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the task. |
| END_TIMESTAMP | timestamp(6) | NO | The end time of the task. |
| STATUS | varchar(64) | NO | The task status. Valid values: <ul><li>`COMPLETED`: the task is successfully executed. </li><li>`FAILED`: the task failed. </li><li>`CANCELED`: the task is successfully canceled. </li></ul> |
| TOTAL_TASK_COUNT | bigint(20) | YES | The number of subtasks. <ul><li>In SN mode, this column indicates the total number of ls_task. </li><li>In SS mode, this column indicates the total number of ls_task for log archive pieces and the total number of macro_task for data backup sets. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this column is available starting with V4.6.0. </p></main> |
| FINISH_TASK_COUNT | bigint(20) | YES | The number of completed subtasks. <ul><li>In SN mode, this column indicates the number of completed ls_task. </li><li>In SS mode, this column indicates the number of completed ls_task for log archive pieces and the number of completed macro_task for data backup sets. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>In V4.6.x, this column is available starting with V4.6.0. </p></main> |
| RESULT | bigint(20) | YES | The error code. |
| COMMENT | varchar(4096) | YES | The comment. |
| PATH | varchar(1024) | NO | The backup destination of the backup_set or backup_piece. |

## Sample query

Query the historical information of completed `backup_set` or `backup_piece` cleanup tasks for all tenants in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_TASK_HISTORY\G
```
