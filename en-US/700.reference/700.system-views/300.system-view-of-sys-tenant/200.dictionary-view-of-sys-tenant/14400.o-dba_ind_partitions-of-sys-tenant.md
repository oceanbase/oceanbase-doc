# oceanbase.DBA_IND_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the primary partition information of all indexes in the current tenant.

## Columns

|          Column           |       Type        | Nullable |                                                                        Description                                                                         |
|-------------------------|-----------------|------------|---------|
| INDEX_OWNER             | varchar(128)    | NO         | The owner of the index.|
| INDEX_NAME              | varchar(128)    | NO         | The name of the index.  |
| TABLE_NAME              | varchar(128)    | NO         | The name of the table to which the index belongs.|
| COMPOSITE               | varchar(3)      | NO         | Indicates whether the partition belongs to a local index of a composited-partition table:<ul><li>YES</li><li>NO</li></ul>       |
| PARTITION_NAME          | varchar(128)    | NO         | The name of the partition.   |
| SUBPARTITION_COUNT      | bigint(20)      | NO         | The number of subpartitions.   |
| HIGH_VALUE              | mediumtext      | NO         | The expression that binds the partition value.   |
| HIGH_VALUE_LENGTH       | bigint(20)      | NO         | The length of the expression that binds the partition value.      |
| PARTITION_POSITION      | bigint(20)      | NO         | The position of the partition in the index.             |
| STATUS                  | varchar(8)      | NO         | Indicates whether the index partition is available.              |
| TABLESPACE_NAME         | varchar(30)     | NO         | The name of the tablespace that contains the partition.                 |
| PCT_FREE                | bigint(0)       | NO         | This column is not supported. The default value is NULL.               |

| INITIAL_EXTENT          | bigint(0)       | NO         | This column is not supported. The default value is NULL.      |
| NEXT_EXTENT             | bigint(0)       | NO         | This column is not supported. The default value is NULL.      |
| MIN_EXTENT              | bigint(0)       | NO         | This column is not supported. The default value is NULL.    |
| MAX_EXTENT              | bigint(0)       | NO         | This column is not supported. The default value is NULL.           |

| FREELISTS               | bigint(0)       | NO         | This column is not supported. The default value is NULL.             |

| LOGGING                 | varchar(7)      | NO         | This column is not supported. The default value is NULL.               |
| COMPRESSION             | varchar(13)     | NO         | Indicates whether the partition index is compressed:<ul><li> Enabled (ENABLE)   </li><li> Disabled (DISABLE) </li></ul>   |
| BLEVEL                  | bigint(0)       | NO         | This column is not supported. The default value is NULL |

| DISTINCT_KEYS           | bigint(0)       | NO         | This column is not supported. The default value is NULL.                |

| AVG_DATA_BLOCKS_PER_KEY | bigint(0)       | NO         | This column is not supported. The default value is  NULL.                           |
| CLUSTERING_FACTOR       | bigint(0)       | NO         | This column is not supported. The default value is NULL.             |
| NUM_ROWS                | bigint(0)       | NO         | This column is not supported. The default value is NULL.            |
| SAMPLE_SIZE             | bigint(0)       | NO         | This column is not supported. The default value is NULL.               |
| LAST_ANALYZED           | date            | NO         | This column is not supported. The default value is NULL.              |
| BUFFER_POOL             | varchar(7)      | NO         | This column is not supported. The default value is NULL.                   |
| FLASH_CACHE             | varchar(7)      | NO         | This column is currently not supported and defaults to NULL.         |
| CELL_FLASH_CACHE        | varchar(7)      | NO         | This column is currently not supported and defaults to NULL.              |
| USER_STATS              | varchar(3)      | NO         | This column is currently not supported and defaults to NULL.            |
| PCT_DIRECT_ACCESS       | bigint(0)       | NO         | This column is currently not supported and defaults to NULL.       |
| GLOBAL_STATS            | varchar(3)      | NO         | This column is currently not supported and defaults to NULL. |
| DOMIDX_OPSTATUS         | varchar(6)      | NO         | This column is currently not supported and defaults to NULL.                  |

| INTERVAL                | varchar(3)      | NO         | This column is currently not supported and defaults to `NO`.          |
