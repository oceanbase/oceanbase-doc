# oceanbase.CDB_PART_TABLES

## Purpose
The `oceanbase.CDB_PART_TABLES` view displays the partitioning information of the partitioned tables of all tenants.
<main id="notice" type='explain'>
<h4>Note</h4>

<p>This view was introduced in OceanBase Database V4.0.0. </p>

</main>
