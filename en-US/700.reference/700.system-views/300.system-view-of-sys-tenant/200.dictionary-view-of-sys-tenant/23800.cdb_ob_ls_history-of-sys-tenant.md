# oceanbase.CDB_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view was introduced in V4.2.0. </p>
</main>

## Description

This view is accessible only in the sys tenant and displays all the log streams that have existed in any tenants.

## Columns

| Column    | Type           | NULL | Description                                       |
|-------------|---------------|-------------|-------------------------------------------|
| TENANT_ID   | bigint(20)    | NO          |  Tenant ID                                   |
| LS_ID       | bigint(20)    | NO          |  Log stream ID                                 |
| LS_GROUP_ID | bigint(20)    | NO          |  Log stream group ID                           |
| STATUS      | varchar(100)  | NO          |  The current status of the log stream. The following statuses are defined: <ul><li>CREATING: The log stream is being created. </li><li>NORMAL: The status of a normal log stream. </li><li>DROPPING: The log stream is being deleted. </li><li>PRE_TENANT_DROPPING: A special status of a system log stream, indicating the start of deleting all log streams in the tenant. </li><li>TENANT_DROPPING: The tenant is being deleted, and the log stream is in the process of being deleted. </li><li>DROPPED: The log stream has been recycled or is being recycled. </li><li>WAIT_OFFLINE: The log stream is waiting to be recycled. </li><li>CREATE_ABORT: The creation of the log stream is stopped. </li></ul>        |
| FLAG        | varchar(2048) | NO          |  Log stream flags. The following flags are defined: <ul><li>None: A normal log stream. </li><li>DUPLICATE: A broadcast log stream in a user tenant. A replica table is created on this log stream. </li> <li>BLOCK_TABLET_IN: You cannot create a tablet on this log stream. </li> <li>DUPLICATE\|BLOCK_TABLET_IN: You cannot create a tablet on a broadcast log stream. </li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          |  The GTS when the log stream is created. The value is in nanoseconds.              |
