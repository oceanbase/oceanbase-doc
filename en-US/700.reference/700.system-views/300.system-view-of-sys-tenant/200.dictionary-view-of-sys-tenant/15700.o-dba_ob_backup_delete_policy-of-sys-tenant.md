# oceanbase.DBA_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0.</p>
</main>

## Overview

Displays the backup cleanup strategies set for expiration cleanup or automatic cleanup under a tenant. The `sys` tenant and Meta tenant do not support physical backup.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| POLICY_NAME | varchar(256) | NO | Cleanup Policy Name |
| RECOVERY_WINDOW | varchar(64) | NO | Recoverable Time Window. Default value: 0. |
