# information_schema.TABLES

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in V1.4. </p>
</main>

## Description

The `information_schema.TABLES` view displays information about tables.

## Field descriptions

|      Field name    |         Type       | Nullable |    Description     |
|-----------------|--------------------|----------------|-------------|
| TABLE_CATALOG   | varchar(512)        | NO | The table catalog. |
| TABLE_SCHEMA    | varchar(64)         | NO | The database name. |
| TABLE_NAME      | varchar(64)         | NO | The table name. |
| TABLE_TYPE      | varchar(64)         | NO | The table type. |
| ENGINE          | varchar(64)         | NO | The storage engine type. |
| VERSION         | bigint(0) unsigned  | NO | The version. |
| ROW_FORMAT      | varchar(10)         | NO | The row format. |
| TABLE_ROWS      | bigint(21) unsigned | NO | The number of rows in the table. |
| AVG_ROW_LENGTH  | bigint(21) unsigned | NO | The average row length. |
| DATA_LENGTH     | bigint(21) unsigned | NO | The data length, which is the size of storage space occupied by the table, measured in bytes, calculated based on macroblocks. <main id="notice" type='explain'><h4>Note</h4><p>In V4.3.x, the `NULL` value is displayed for this field only in V4.3.5 and later. </p></main> |
| MAX_DATA_LENGTH | bigint(0) unsigned  | NO | The maximum data length. |
| INDEX_LENGTH    | bigint(0) unsigned  | NO | The index length, which is the size of storage space occupied by non-primary key indexes, measured in bytes, calculated based on macroblocks. <main id="notice" type='explain'><h4>Note</h4><p>In V4.3.x, the `NULL` value is displayed for this field only in V4.3.5 and later. </p></main> |
| DATA_FREE       | bigint(0) unsigned  | NO | The size of free space. |
| AUTO_INCREMENT  | bigint(0) unsigned  | NO | The current auto-increment value. |
| CREATE_TIME     | datetime            | NO | The creation time of the table. |
| UPDATE_TIME     | datetime            | NO | The last update time of the table. |
| CHECK_TIME      | datetime            | NO | The last check time of the table. |
| TABLE_COLLATION | varchar(32)         | NO | The collation method of the table character set. |
| CHECKSUM        | bigint(0) unsigned  | NO | The checksum. |
| CREATE_OPTIONS  | varchar(255)        | NO | The creation options. |
| TABLE_COMMENT   | text                | NO | The comment on the table. |
| AUTO_SPLIT    | varchar(16) | NO | Specifies whether automatic partitioning is enabled for the table. Valid values are as follows: <ul><li>`FALSE` (default value): Automatic partitioning is disabled. </li><li>`TRUE`: Automatic partitioning is enabled. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is introduced in V4.3.4. </p></main>|
| AUTO_SPLIT_TABLET_SIZE | bigint(20) unsigned | NO | The threshold for automatic partition splitting. If `AUTO_SPLIT` is set to `FALSE`, the value of `AUTO_SPLIT_TABLET_SIZE` is 0. <main id="notice" type='explain'><h4>Note</h4><p>This field is introduced in V4.3.4. </p></main>|
| ORGANIZATION    | varchar(12)         | NO | The table organization mode. Valid values are as follows: <ul><li>`HEAP`: The table is organized in heap mode. </li><li>`INDEX`: The table is organized in index mode. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For OceanBase Database V4.3.5, this field is supported starting from V4.3.5 BP1. </p></main>|

Query the details of the `t1` table.

```sql
SELECT * FROM information_schema.tables WHERE table_name = 't1'\G
```
