# information_schema.TABLES

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V1.4. </p>
</main>

## Purpose

The `information_schema.TABLES` view displays information about tables.

## Columns

| Column |  Type  | Nullable? | Description |
|------------|----------|------------------------|-------------|
| TABLE_CATALOG | varchar(512) | NO | The catalog of the table. |
| TABLE_SCHEMA | varchar(64) | NO | The name of the database. |
| TABLE_NAME | varchar(64) | NO | The name of the table. |
| TABLE_TYPE | varchar(64) | NO | The type of the table. |
| ENGINE | varchar(64) | NO | The storage engine type used. |
| VERSION | bigint(0) unsigned | NO | The version. |
| ROW_FORMAT | varchar(10) | NO | The row format. |
| TABLE_ROWS | bigint(21) unsigned | NO | The number of rows in the table. |
| AVG_ROW_LENGTH | bigint(21) unsigned | NO | The average row length. |
| DATA_LENGTH | bigint(21) unsigned | NO | The data length, which is the storage space occupied by the table, in bytes, calculated based on macroblocks. <main id="notice" type='explain'><h4>Note</h4><p>This field is effective starting from V4.3.5 in V4.3.x. </p></main> |
| MAX_DATA_LENGTH | bigint(0) unsigned | NO | The maximum data length. |
| INDEX_LENGTH | bigint(0) unsigned | NO | The index length, which is the storage space occupied by non-primary key indexes, in bytes, calculated based on macroblocks. <main id="notice" type='explain'><h4>Note</h4><p>This field is effective starting from V4.3.5 in V4.3.x. </p></main> |
| DATA_FREE | bigint(0) unsigned | NO | The remaining space. |
| AUTO_INCREMENT | bigint(0) unsigned | NO | The current auto-increment value. |
| CREATE_TIME | datetime | NO | The creation time of the table. |
| UPDATE_TIME | datetime | NO | The last update time of the table. |
| CHECK_TIME | datetime | NO | The last check time of the table. |
| TABLE_COLLATION | varchar(32) | NO | The collation method of the table. |
| CHECKSUM | bigint(0) unsigned | NO | The checksum. |
| CREATE_OPTIONS | varchar(255) | NO | The creation options. |
| TABLE_COMMENT | text | NO | The remarks of the table. |
| AUTO_SPLIT | varchar(16) | NO | Indicates whether automatic table splitting is enabled for the table. Valid values: <ul><li>`FALSE` (default): Automatic table splitting is disabled for the table. </li><li>`TRUE`: Automatic table splitting is enabled for the table. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>This field is introduced in V4.3.4. </p></main>|
| AUTO_SPLIT_TABLET_SIZE | bigint(20) unsigned | NO | The threshold for automatic table splitting. If the value of the `AUTO_SPLIT` field is `FALSE`, the value of the `AUTO_SPLIT_TABLET_SIZE` field is 0. <main id="notice" type='explain'><h4>Note</h4><p>This field is introduced in V4.3.4. </p></main>|

## Sample query

Query the details of the `t1` table.

```shell
obclient> select * from information_schema.tables where table_name = 't1'\G
```
