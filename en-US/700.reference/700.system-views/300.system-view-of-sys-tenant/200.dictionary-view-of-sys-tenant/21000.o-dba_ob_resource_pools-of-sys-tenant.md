# oceanbase.DBA_OB_RESOURCE_POOLS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.1.0. </p>
</main>

## Purpose

This view displays the information about resource pools of all tenants.

## Columns

|     Column     |       Type       | Nullable |                                                                          Description                                                                           |
|--------------|----------------|------------|-------------------------------------|
| RESOURCE_POOL_ID | bigint(20)    | NO  | The unique ID of the resource pool.                                                                              |
| NAME             | varchar(128)  | NO  | The name of the resource pool.                                                                                 |
| TENANT_ID        | bigint(20)    | NO  | The ID of the tenant.  <ul><li>`NULL`: indicates that the resource pool does not belong to any tenant. </li><li>Valid value: indicates the ID of the tenant to which the resource pool belongs. </li></ul>   |
| CREATE_TIME      | timestamp(6)  | YES | The time when the resource pool was created.          |
| MODIFY_TIME      | timestamp(6)  | YES | The time when the resource pool was last modified.        |
| UNIT_COUNT       | bigint(20)    | NO  | The number of resource units.       |
| UNIT_CONFIG_ID   | bigint(20)    | NO  | The ID of the resource specification of the resource pool.   |
| ZONE_LIST        | varchar(8192) | NO  | The list of zones of the resource pool.  |
| REPLICA_TYPE     | varchar(18)   | NO  | The type of replica supported by the resource pool.  <ul><li> `FULL`: supports all replica types, including full-featured replicas. </li> <li>`READONLY`: supports only read-only replicas. </li> <li> `COLUMNSTORE`: supports only columnstore replicas. </li></ul>   |

obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS;
