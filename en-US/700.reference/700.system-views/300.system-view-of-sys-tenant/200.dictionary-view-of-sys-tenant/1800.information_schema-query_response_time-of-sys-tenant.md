# information_schema.QUERY_RESPONSE_TIME

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays histogram data such as the response time for Prometheus monitoring.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| RESPONSE_TIME | bigint(14) | NO | Response time. |
| COUNT | bigint(14) | NO | Number of requests in the response time. |
| TOTAL | bigint(14) | NO | Total response time of the requests. |
