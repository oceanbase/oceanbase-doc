# information_schema.SCHEMATA

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays database metadata.

## Columns

|          **Column**          |    **Type**    | **Nullable** | **Description**  |
|----------------------------|--------------|----------------|---------|
| CATALOG_NAME               | varchar(3)   | NO             | Fixed value def |
| SCHEMA_NAME                | varchar(128) | NO             | The name of the database.    |
| DEFAULT_CHARACTER_SET_NAME | varchar(7)   | NO             | The default character set.   |
| DEFAULT_COLLATION_NAME     | varchar(18)  | NO             | The default collation.  |
| SQL_PATH                   | null         | NO             | NULL    |
| DEFAULT_ENCRYPTION         | varchar(2)   | NO   | The default encryption setting.    |

## Sample query

Query the metadata of all databases in the cluster.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SCHEMATA;
```
