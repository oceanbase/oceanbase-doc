# V$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the major compaction progress of all tenants on the current node.

## Columns

|          Column           |      Type      | Nullable |                                            Description                                            |
|-------------------------|--------------|------------|--------|
|SVR_IP    |varchar(46)    |NO   |The IP address of the server.    |
|SVR_PORT    |bigint(20)    |NO   |The port number of the server.    |
|TENANT_ID    |bigint(20)    |NO   |The ID of the tenant.    |
|TYPE    |varchar(64)    |NO   |The type of the major compaction. <ul><li> MINI: the type of minor compaction, which is used to convert a MemTable to an SSTable. </li><li>MAJOR: the type of major compaction. </li><li>MINOR: the type of minor compaction, which is used to convert multiple Mini SSTables to one SSTable. </li></ul>    |
|ZONE    |varchar(128)    |NO   |The zone information.    |
|COMPACTION_SCN    |bigint(20) unsigned    |NO   |The compaction version.    |
|STATUS    |varchar(10)    |NO   |The status.    |
|TOTAL_TABLET_CNT    |bigint(20)    |NO   |The total number of tablets.    |
|UNFINISHED_TABLET_CNT    |bigint(20)    |NO   |The number of tablets that have not been compacted.    |
|DATA_SIZE    |bigint(20)    |NO   |The total size of data to be compacted, in bytes. |
|UNFINISHED_DATA_SIZE    |bigint(20)    |NO   |The size of data that has not been compacted, in bytes.  |
|COMPRESSION_RATIO    |bigint(20)    |NO   |The compression ratio of the new data (the compression ratio of data written after the last major version point).    |
|START_TIME    |timestamp(6)    |NO   |The start time.    |
|ESTIMATED_FINISH_TIME    |timestamp(6)    |NO   |The estimated finish time. If    |
|    |    |NO   |compaction_progress is 100, the end time is displayed.    |
|COMMENTS    |varchar(1024)    |NO   |The comments. During the major compaction, the latest major compaction event is recorded. If the major compaction is completed, the overall time consumption is recorded.    |

## Sample query

Query the major compaction progress of all tenants on the current node as the sys tenant, and display the first five records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_COMPACTION_PROGRESS LIMIT 5;
```
