# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays the diagnostic information of full-link tracing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or the ID of the Meta tenant. </li></ul> |
| TYPE | varchar(16) | NO | The monitoring level of the diagnostic information. <ul><li>Tenant level: the diagnostic information is monitored at the tenant level.  </li><li>Module/action level: the diagnostic information is monitored at the module and action levels. </li><li>Client identifier level: the diagnostic information is monitored at the client identifier level. </li></ul> |
| TENANT_NAME | varchar(128) | NO | The name of the tenant. |
| MODULE_NAME | varchar(4096) | NO | The name of the module. |
| ACTION_NAME | varchar(4096) | NO | The name of the action. |
| CLIENT_IDENTIFIER | varchar(65) | NO | The name of the client identifier. |
| LEVEL | bigint(20) | NO | The monitoring level of the full-link tracing of the current session. For example, 1 indicates that the diagnostic information of level 1 is monitored. |
| SAMPLE_PERCENTAGE | bigint(20) | NO | The sampling frequency of the full-link tracing of the current session.  For example, 50 indicates that the diagnostic information is sampled with a probability of 50%. |
| RECORD_POLICY | varchar(32) | NO | The record strategy of the full-link tracing of the current session. The following three strategies are supported: <ul><li>ALL: All trace information that is sampled and enabled is printed to the log file. The trace information is printed to the log file when each span ends.  </li><li>ONLY_SLOW_QUERY: All trace information that is sampled and enabled is printed to the log file. Only the trace information of slow queries is printed to the log file. The trace information is printed to the log file when the request is determined to be a slow query. In the Proxy, for the root span, which is the span at the transaction level, the root span is printed only when a slow query is detected. </li><li>SAMPLE_AND_SLOW_QUERY: All trace information that is sampled and enabled is printed to the log file if the following conditions are met: <ol><li>The trace information is sampled with a probability of 0.0001 by using the hidden parameter <code>_print_sample_ppm</code>, and the trace information is printed to the log file only when the sampling result is selected. </li><li>The trace information meets the conditions for printing in the ONLY_SLOW_QUERY mode. </li></ol> In this mode, the trace information is not printed to the log file when the span ends. If condition 1 is met, the trace information is forcibly printed to the log file at the client end and the information is passed to the subsequent link components. If condition 2 is met, the trace information is printed to the log file at the same time as in the ONLY_SLOW_QUERY mode. </li></ul> |
