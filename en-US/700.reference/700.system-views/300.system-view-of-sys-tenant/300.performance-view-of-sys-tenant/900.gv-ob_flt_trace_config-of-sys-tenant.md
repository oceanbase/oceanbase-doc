# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.2.1. </p>
</main>

## Purpose

This view displays diagnostic information for full-link tracing.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the system tenant ID.  </li><li>Other values: the user tenant ID or the Meta tenant ID. </li></ul> |
| TYPE | varchar(16) | NO | The monitoring level of diagnostic information. <ul><li>Tenant level: diagnostic information is monitored at the tenant level.  </li><li>Module/action level: diagnostic information is monitored at the module and action levels. </li><li>Client identifier level: diagnostic information is monitored at the client identifier level. </li></ul> |
| TENANT_NAME | varchar(128) | NO | The tenant name. |
| MODULE_NAME | varchar(4096) | NO | The module name. |
| ACTION_NAME | varchar(4096) | NO | The action name. |
| CLIENT_IDENTIFIER | varchar(65) | NO | The client identifier name. |
| LEVEL | bigint(20) | NO | The full-link tracing monitoring level of the session. For example, 1 indicates that diagnostic information of level 1 is collected. |
| SAMPLE_PERCENTAGE | bigint(20) | NO | The full-link tracing sampling frequency of the session.  For example, 50 indicates that diagnostic information is sampled with a 50% probability. |
| RECORD_POLICY | varchar(32) | NO | The full-link tracing recording policy of the session. The following three policies are supported: <ul><li>ALL: All trace points that are sampled and opened are printed to the log file. The trace points are printed to the log file when each span ends. </li><li>ONLY_SLOW_QUERY: Only trace points that are sampled and opened and belong to slow queries are printed to the log file. Other trace points are discarded. The trace log is printed only after the request is determined to be a slow query. In the Proxy, the root span (transaction-level span) is printed only when a slow query is detected. </li><li>SAMPLE_AND_SLOW_QUERY: Trace points that are sampled and opened are printed to the log file if the following conditions are met: <ol><li>When the hidden parameter <code>_print_sample_ppm</code> is used for sampling at a 0.0001 probability, the trace point is printed to the log only if the sampling result is selected. </li><li>The trace point meets the conditions for printing in the ONLY_SLOW_QUERY mode. </li></ol> In this mode, the trace log is not printed when the span ends. If condition 1 is met, the trace log is forcibly printed at the client and the information is passed to the subsequent link components. If condition 2 is met, the trace log is printed at the same time as in the ONLY_SLOW_QUERY mode. </li></ul> |
