# V$OB_QUERY_RESPONSE_TIME_HISTOGRAM

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For OceanBase Database V4.2.1, this view was introduced in OceanBase Database V4.2.1 BP7. For other versions of OceanBase Database V4.2.x, this view was introduced in OceanBase Database V4.2.5. </p>
</main>

## Purpose

The `V$OB_QUERY_RESPONSE_TIME_HISTOGRAM` view displays the histograms of query response time on the current OBServer node in all tenants.

## Columns

| Column | Type | Nullable? | Description |
| ------------ | -------- | ------------------ | -------- |
| SVR_IP        | varchar(46)   | NO   | The IP address of the OBServer node. |
| SVR_PORT      | bigint(20)    | NO   | The port number of the OBServer node. |
| TENANT_ID     | bigint(20)    | NO   | The ID of the tenant. |
| SQL_TYPE      | varchar(128)  | NO   | The type of the query statement. Valid values: <ul><li>SELECT</li><li>INSERT</li><li>UPDATE</li><li>DELETE</li><li>REPLACE</li><li>COMMIT</li><li>OTHER</li><li>INNER SQL</li><li>TABLEAPI SELECT</li><li>TABLEAPI INSERT</li><li>TABLEAPI DELETE</li><li>TABLEAPI UPDATE</li><li>TABLEAPI REPLACE</li><li>TABLEAPI QUERY AND MUTATE</li><li>TABLEAPI OTHER</li><li>HBASE SCAN</li><li>HBASE PUT</li><li>HBASE DELETE</li><li>HBASE APPEND</li><li>HBASE INCREMENT</li><li>HBASE CHECK AND PUT</li><li>HBASE CHECK AND DELETE</li><li>HBASE HYBRID BATCH</li></ul>     |
| RESPONSE_TIME | decimal(24,6) | NO   | The range of response time, in seconds. |
| COUNT         | bigint(20)    | NO   | The count for the range. |
| TOTAL         | decimal(24,6) | NO   | The total time within the range, in seconds. |

## Sample query

Query the histograms of query response time on the current OBServer node in all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_QUERY_RESPONSE_TIME_HISTOGRAM LIMIT 2\G;
```

The query result is as follows:

```shell

        COUNT: 0

     SVR_PORT: 2882
    TENANT_ID: 1
     SQL_TYPE: SELECT

```

Query the histograms of response time for `TABLEAPI SELECT` queries on the current OBServer node in all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_QUERY_RESPONSE_TIME_HISTOGRAM WHERE SQL_TYPE = "TABLEAPI SELECT" LIMIT 2\G;
```
