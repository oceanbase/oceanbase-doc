# V$OB_PL_CACHE_OBJECT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view is available starting with V4.3.1 in V4.3.x. </li><li>This view is available starting with V4.2.2 in V4.2.x. </li></ul>
</main>

## Purpose

The `V$OB_PL_CACHE_OBJECT` view displays the basic information about PL-related cache objects in the local server of all tenants.

## Columns
