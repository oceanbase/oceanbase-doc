# V$OB_PL_CACHE_OBJECT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view is available starting with V4.3.1 in V4.3.x. </li><li>This view is available starting with V4.2.2 in V4.2.x. </li></ul>
</main>

## Purpose

The `V$OB_PL_CACHE_OBJECT` view displays the basic information of PL-related cached objects in the local Server of all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)          | NO   |  Tenant ID:<ul><li>1: system tenant ID.  </li><li>Other values: user tenant ID or Meta tenant ID. </li></ul>   |
| SVR_IP            | varchar(46)         | NO   |  IP address of the node where the cache object is stored.   |
