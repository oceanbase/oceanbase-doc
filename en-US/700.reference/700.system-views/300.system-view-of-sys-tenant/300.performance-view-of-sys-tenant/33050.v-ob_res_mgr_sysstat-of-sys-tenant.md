# V$OB_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This view was introduced in OceanBase Database V4.2.5. </p>
</main>

## Purpose

The `V$OB_RES_MGR_SYSSTAT` view displays the statistical items of resource groups on the current OBServer node in all tenants.

## Columns

| Column | Type | Nullable? | Description |
|------------|-------------|---------------------|----------------------------------------|
| CON_ID     | bigint(20)  | NO   | The ID of the tenant. |
| GROUP_ID   | bigint(20)  | NO   | The ID of the consumer group. |
| SVR_IP     | varchar(46) | NO   | The IP address of the OBServer node. |
| SVR_PORT   | bigint(20)  | NO   | The port number of the OBServer node. |
| STATISTIC# | bigint(20)  | NO   | The sequence number of the statistical item. |
| NAME       | varchar(64) | NO   | The name of the statistical item. |
| CLASS      | bigint(20)  | NO   | The class of the statistical item. |
| VALUE      | bigint(20)  | NO   | The value of the statistical item. |
| VALUE_TYPE | varchar(16) | NO   | The type of the value, which can be a cumulative or assigned value.|
| STAT_ID    | bigint(20)  | NO   | The ID of the statistical item. |

## Sample query

Query the statistical items of resource groups on the current OBServer node in all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RES_MGR_SYSSTAT LIMIT 10;
```
