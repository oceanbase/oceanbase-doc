# GV$OB_SQL_CCL_STATUS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with OceanBase Database V4.3.5 BP3 for V4.3.x versions. <br>For V4.4.x versions, this view is available starting with OceanBase Database V4.4.1. </p>
  </main>

## Purpose

This view records the number of SQL statements that hit the throttling rules across all tenants and nodes at the current moment. It is used to observe the impact of the throttling rules set in the system.

## Columns

| Column | Type | Nullable | Description |
|---------|-------|-------------|--------|
| CON_ID              | bigint(20)  | NO   | The tenant ID.      |
| SVR_IP              | varchar(46) | NO   | The IP address of the OBServer node.     |
| SVR_PORT            | bigint(20)  | NO   | The port number of the BServer node.      |
| CCL_RULE_ID         | bigint(20)  | NO   | The ID of the active throttling rule.     |
| FORMAT_SQLID        | varchar(32) | NO   | The throttling granularity:<li>Rule level: 0 </li><li>Format SQLID level:1</li>      |
| CURRENT_CONCURRENCY | bigint(20)  | NO   | The number of SQL statements that are currently executing and hit the throttling rule.     |
| MAX_CONCURRENCY     | bigint(20)  | NO   | The maximum concurrency level of the throttling rule.    |

## Sample query

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SQL_CCL_STATUS;
```
