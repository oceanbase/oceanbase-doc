# GV$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

In the sys tenant, the `GV$OB_KV_GROUP_COMMIT_STATUS` view can be used to query the group commit status of all client connections in an OBKV tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the node where the group commit group is located. |
| SVR_PORT | bigint(20) | NO | The port number of the node where the group commit group is located. |
| TENANT_ID | bigint(20) | NO | The tenant ID. <ul><li>1: the sys tenant ID. </li><li>Other values: the ID of a user tenant or a meta tenant. </li></ul> |
| TABLE_ID | bigint(20) | NO | The ID of the table to which the group commit group belongs. |
| LS_ID | bigint(20) | NO | The ID of the leader server to which the group commit group belongs. |
| SCHEMA_VERSION | bigint(20) | NO | The schema version of the table to which the group commit group belongs. |
| GROUP_TYPE | varchar(32) | NO | The type of the group commit group. Valid values: <ul><li>get: a get request queue. </li><li>put: a put request queue. </li><li>del: a delete request queue. </li><li>replace: a replace request queue. </li><li>insert: an insert request queue. </li><li>hybird: a hybrid operation request queue. </li><li>fail: a batch execution failure queue. </li></ul> |
| QUEUE_SIZE | bigint(20) | NO | The size of the request queue in the group commit group. This value indicates the number of unprocessed requests. |
| BATCH_SIZE | bigint(20) | NO | The size of the batch in the group commit group. |
| CREATE_TIME | timestamp(6) | NO  | The time when the group was created in the group commit.  |
| UPDATE_TIME | timestamp(6) | NO  | The time when the status information of the group was last updated in the group commit.  |

## Sample query

Query the group commit status of all client connections in the OBKV tenant on all nodes and display the records of the first day.

```shell
obclient > SELECT * FROM oceanbase.GV$OB_KV_GROUP_COMMIT_STATUS limit 2;
```
