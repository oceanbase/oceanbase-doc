# GV$OB_PROCESSLIST

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_PROCESSLIST` view displays session information for all OBServer nodes where the tenant is located.

