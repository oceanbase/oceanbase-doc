# GV$OB_FUNCTION_IO_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

This view displays the I/O statistics at the Function level for all tenants on all OBServer nodes. When the resource group corresponding to the background task at the Function level has not enabled the resource management plan, the displayed I/O information is only for statistical reference, and the corresponding resources cannot be limited.

## Columns

|             Column           |      Type    | Nullable |            Description                                            |
|------------------------------|--------------|----------------|------------------------------------------------------------|
| SVR_IP                       | varchar(46)  | NO             | The IP address of the server.     |
| SVR_PORT                     | bigint(20)   | NO             | The port number of the server.       |
| TENANT_ID                    | bigint(20)   | NO             | The ID of the tenant.            |
| FUNCTION_NAME                | varchar(32)  | NO             | The name of the background task corresponding to the Function:<ul><li>`COMPACTION_HIGH`: Mini Merge and DDL KV Merge tasks</li> <li>`HA_HIGH`: High-priority, high-reliability tasks such as replication, rebuild, and restore</li> <li>`COMPACTION_MID`: Minor Merge tasks</li> <li>`HA_MID`: Medium-priority, high-reliability tasks, such as migration tasks</li> <li>`COMPACTION_LOW`: Major Merge tasks</li> <li>`HA_LOW`: Low-priority, high-reliability tasks such as backup and cleanup</li> <li>`DDL`: Tasks in scenarios such as unique index verification and data supplementation</li> <li>`DDL_HIGH`: DDL MemTable dump tasks</li> <li>`CLOG_LOW`: Physical standby and CDC read tasks</li> <li>`CLOG_MID`<: Follower replica read shared storage, log archive read local disk, and other tasks</li> <li>`CLOG_HIGH`: Clog write to local disk, clog file upload to shared storage, Follower replica read local disk, and other tasks</li> <li>`GC_MACRO_BLOCK`: Macroblock recycling and reuse tasks</li> <li>`OPT_STATS`: Statistics collection tasks</li> <li>`IMPORT`: Import tasks</li> <li>`SQL_AUDIT`: SQL audit log write to disk tasks</li> <li>`DEFAULT_FUNCTION`: All background tasks other than those already defined</li></ul>    |
| MODE                         | varchar(32)  | NO             | The read/write mode corresponding to the I/O operation. Shared storage requests are remote requests, and other types of requests are local requests:<ul><li>`LOCAL READ`: Local read</li> <li>`LOCAL WRITE`: Local write</li> <li>`REMOTE READ`: Remote read</li> <li>`REMOTE WRITE`: Remote write</li></ul>    |
| SIZE                         | bigint(20)   | NO             | The average I/O size.     |
| REAL_IOPS                    | bigint(20)   | NO             | The actual IOPS.     |
| REAL_MBPS                    | bigint(20)   | NO             | The actual bandwidth, in MB/s.     |
| SCHEDULE_US                  | bigint(20)   | NO             | The average I/O scheduling time, in microseconds.     |
| IO_DELAY_US                  | bigint(20)   | NO             | The average disk I/O execution time, in microseconds.     |
| TOTAL_US                     | bigint(20)   | NO             | The overall average I/O execution time, in microseconds.     |

## Sample query

Query the I/O statistics at the Function level for all tenants on all OBServer nodes in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_FUNCTION_IO_STAT LIMIT 5;
```
