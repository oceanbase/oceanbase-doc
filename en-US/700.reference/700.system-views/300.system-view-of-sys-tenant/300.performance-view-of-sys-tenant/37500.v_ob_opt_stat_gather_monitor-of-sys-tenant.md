# V$OB_OPT_STAT_GATHER_MONITOR

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the real-time status of statistical information collection tasks for all tenants on the current OBServer node.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The ID of the tenant to which the collection task belongs. |
| SVR_IP | varchar(46) | NO | The IP address of the node to which the collection task belongs. |
| SVR_PORT | bigint(20) | NO | The port of the node to which the collection task belongs. |
| SESSION_ID | bigint(20) | NO | The session ID of the collection task. <br>For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> In all connection modes (direct mode and ODP mode), this field indicates the server session ID. </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the configuration parameter <code>client_session_id_version = 2</code> is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code> is set, this field indicates the server session ID. </li></ul></ul></li></ul> |
| TRACE_ID | varchar(64) | NO | The TRACE ID of the collection task. |
| TASK_ID | varchar(36) | NO | The ID of the collection task (UUID, globally unique). |
| TYPE | varchar(16) | NO | The type of the collection task. |
| TASK_START_TIME | datetime(6) | NO | The start time of the collection task. |
| TASK_DURATION_TIME | bigint(20) | NO | The duration of the collection task, in microseconds. |
| TASK_TABLE_COUNT | bigint(20) | NO | The number of tables to be collected by the collection task. |
| COMPLETED_TABLE_COUNT | bigint(20) | NO | The number of tables that have been completed by the collection task. |
| RUNNING_TABLE_OWNER | varchar(128) | NO | The username of the table being collected by the collection task. |
| RUNNING_TABLE_NAME | varchar(256) | NO | The name of the table being collected by the collection task. |
| RUNNING_TABLE_DURATION_TIME | bigint(20) | NO | The duration of the table being collected by the collection task. |

## Sample query

In the sys tenant, query the real-time status of the statistical information collection task for tenant 1006 on the current node.

```shell
obclient> SELECT * FROM oceanbase.V$OB_OPT_STAT_GATHER_MONITOR WHERE TENANT_ID = 1006;
```
