# GV$OB_PLAN_CACHE_PLAN_STAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was renamed from GV$PLAN_CACHE_PLAN_STAT to GV$OB_PLAN_CACHE_PLAN_STAT starting from V4.0.0. </p>
</main>

## Purpose

The `GV$OB_PLAN_CACHE_PLAN_STAT` view displays the status of each cached object in the plan cache of all tenants on all OBServer nodes.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This view caches not only SQL plan objects but also PL objects, such as anonymous blocks, PL packages, and PL functions. Some fields are only valid for specific object types. </p>
  </main>
