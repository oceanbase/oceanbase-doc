# V$OB_LOCKS

## Description

Displays the locks held or requested by the current user on tables.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced in V4.2.0. </p>
</main>

## Columns

| **Column** | **Type** | **NULL?** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the OBServer node that holds or requests the lock. |
| SVR_PORT | bigint(20) | NO | The port number of the OBServer node that holds or requests the lock. |
| TENANT_ID | bigint(20) | NO | The ID of the tenant that holds or requests the lock. |
| TRANS_ID | bigint(20) | NO | The transaction ID of the transaction that holds or requests the lock. |
| SESSION_ID | bigint(20)   | NO   | The session ID of the transaction that holds or requests the lock. <main id="notice" type='explain'><h4>Note</h4><p><ul><li>This column is introduced in V4.3.2 of the V4.3.x version. </li><li>This column is introduced in V4.2.5 of the V4.2.x version. </li></ul></p></main>|
| TYPE | varchar(9) | NO | The lock type. <ul><li>TM: table lock </li><li>TX: transaction lock</li><li>TR: row lock</li></ul> |
| ID1 | bigint(20) | NO | Lock identifier 1. <ul><li>For table locks, this identifier is either TABLE_ID or TABLET_ID. </li><li>For transaction locks, this identifier is TX_ID. </li><li>For row locks, this identifier is TABLET_ID. </li></ul> |
| ID2 | varchar(533) | NO | Lock identifier 2. <ul><li>For table locks, this identifier is NULL. </li><li>For transaction locks, this identifier is NULL. </li><li>For row locks, this identifier is TX_ID + row rowkey. </li></ul> |
| ID3 | varchar(512) | NO | Lock identifier 3. <ul><li>For table locks, this identifier is TABLE_ID or TABLET_ID. </li><li>For transaction locks, this identifier is NULL. </li><li>For row locks, this identifier is TABLET_ID + row rowkey. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p><ul><li>This column is introduced in V4.3.2 of the V4.3.x version. </li><li>This column is introduced in V4.2.5 of the V4.2.x version. </li></ul></p></main>|
| LMODE | varchar(8) | NO | The mode of the lock held by the current transaction. <ul><li>NONE: indicates that no lock is held. </li><li>RS: ROW SHARE</li><li>RX: ROW EXCLUSIVE</li><li>S: SHARE</li><li>SRX: SHARE ROW EXCLUSIVE</li><li>X: EXCLUSIVE</li></ul> |
| REQUEST | varchar(8) | NO | The mode of the lock requested by the current transaction. <ul><li>NONE: indicates that no lock is requested. </li><li>RS: ROW SHARE</li><li>RX: ROW EXCLUSIVE</li><li>S: SHARE</li><li>SRX: SHARE ROW EXCLUSIVE</li><li>X: EXCLUSIVE</li></ul> |
| CTIME | bigint(20) | NO | The time when the lock was held or requested, in microseconds. |
| BLOCK | bigint(1) | NO | Indicates whether a lock requested by the transaction is held by another transaction. <ul><li>0: The requested lock is not held by another transaction, which means that the transaction holds the lock. </li><li>1: The requested lock is held by another transaction, which means that the transaction is blocked. </li></ul>|
