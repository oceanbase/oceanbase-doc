# V$SYSSTAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in V1.4. </p>
</main>

## Purpose

Displays the tenant-level statistical events on the current server.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>To use this view, enable monitoring by setting the <code>enable_perf_event</code> parameter to True. </p>
</main>

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP address of the server where the data for this view resides |
| SVR_PORT | bigint(20) | NO | Port number of the server where the data for this view resides |
| STATISTIC# | bigint(20) | NO | Index of the statistical event |
| NAME | varchar(64) | NO | Name of the statistical event |
| CLASS | bigint(20) | NO | Type to which the statistical event belongs |
| VALUE | bigint(20) | NO | Result value of the statistical event |
| VALUE_TYPE | varchar(16) | NO | Type of the statistical value: <li>ADD: Accumulated<li>SET: Updated |
| STAT_ID | bigint(20) | NO | ID of the statistical event |
