# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_SQL_AUDIT` view displays the statistics of each SQL request on the current OBServer node, including the source and execution status. This view is tenant-separated. Only the sys tenant can query the view. Other tenants cannot query the view across tenants.
