# GV$OB_IO_CALIBRATION_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the execution status of I/O calibration tasks on all nodes.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the server. |
| SVR_PORT | bigint(20) | NO | The port number of the server. |
| STORAGE_NAME | varchar(1024) | NO | The name of the storage, for example, DATA or REDO. |
| STATUS | varchar(256) | NO | The I/O calibration status. Valid values: <ul><li>NOT AVAILABLE</li><li>IN PROGRESS</li><li>READY</li></ul> |
| START_TIME | timestamp(6) | NO | The start time of the last I/O calibration. |
| FINISH_TIME | timestamp(6) | NO | The end time of the last I/O calibration. |

## Sample query

Query the execution status of I/O calibration tasks on all nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_IO_CALIBRATION_STATUS;
```

