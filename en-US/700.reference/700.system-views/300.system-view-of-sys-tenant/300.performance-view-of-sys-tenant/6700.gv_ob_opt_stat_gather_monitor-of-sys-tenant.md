# GV$OB_OPT_STAT_GATHER_MONITOR

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the real-time status of statistics collection tasks for all tenants on all OBServer nodes.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The ID of the tenant where the statistics collection task resides. |
| SVR_IP | varchar(46) | NO | The IP address of the node where the statistics collection task resides. |
| SVR_PORT | bigint(20) | NO | The port of the node where the statistics collection task resides. |
| SESSION_ID | bigint(20) | NO | The session ID where the statistics collection task resides. <br>For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> In all connection modes (direct mode or ODP mode), this field indicates the server session ID. </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this field indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this field indicates the server session ID. </li></ul></ul></li></ul> |
| TRACE_ID | varchar(64) | NO | The TRACE ID where the statistics collection task resides. |
| TASK_ID | varchar(36) | NO | The ID of the statistics collection task (UUID, globally unique). |
| TYPE | varchar(16) | NO | The type of the statistics collection task. |
| TASK_START_TIME | datetime(6) | NO | The start time of the statistics collection task. |
| TASK_DURATION_TIME | bigint(20) | NO | The duration of the statistics collection task, in microseconds. |
| TASK_TABLE_COUNT | bigint(20) | NO | The number of tables to be collected by the statistics collection task. |
| COMPLETED_TABLE_COUNT | bigint(20) | NO | The number of tables that have been collected by the statistics collection task. |
| RUNNING_TABLE_OWNER | varchar(128) | NO | The username of the user who owns the table being collected by the statistics collection task. |
| RUNNING_TABLE_NAME | varchar(256) | NO | The name of the table being collected by the statistics collection task. |
| RUNNING_TABLE_DURATION_TIME | bigint(20) | NO | The duration of the table being collected by the statistics collection task. |

## Sample query

```shell
obclient> SELECT * FROM oceanbase.GV$OB_OPT_STAT_GATHER_MONITOR WHERE TENANT_ID = 1006;
```
