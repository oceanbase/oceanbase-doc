# GV$LATCH

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view no longer records data due to feature adjustments. Lock diagnostic data can be viewed in the <a href="../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/5800.gv-system_event-of-sys-tenant.md">GV$SYSTEM_EVENT</a> view and the <a href="../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/400.gv-ob_active_session_history-of-sys-tenant.md">GV$OB_ACTIVE_SESSION_HISTORY</a> view. </p>
</main>

## Purpose

This view displays the latch information of all OBServer nodes in the cluster.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address. |
| SVR_PORT | bigint(20) | NO | The port number. |
| ADDR | varchar(256) | NO | This column is currently NULL. |
| LATCH# | bigint(20) | NO | The index of the latch class. |
| LEVEL# | bigint(20) | NO | The index of the latch level. |
| NAME | varchar(256) | NO | The name of the latch. |
| HASH | bigint(20) | NO | This column is currently 0. |
| GETS | bigint(20) | NO | The number of successful lock operations. |
| MISSES | bigint(20) | NO | The number of times a lock operation entered a wait state. |
| SLEEPS | bigint(20) | NO | The total number of yields. |
| IMMEDIATE_GETS | bigint(20) | NO | The number of successful try_lock operations. |
| IMMEDIATE_MISSES | bigint(20) | NO | The number of failed try_lock operations. |
| SPIN_GETS | bigint(20) | NO | The total number of spins. |
| WAIT_TIME | bigint(20) | NO | The total wait time for sleep. |
