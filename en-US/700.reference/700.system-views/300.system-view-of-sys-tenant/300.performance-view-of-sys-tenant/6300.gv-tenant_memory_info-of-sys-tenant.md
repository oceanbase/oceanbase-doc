# GV$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the memory usage of all tenants across all nodes in the cluster.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------- | ------------- | ------------ | --------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of the Server |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| HOLD | bigint(20) | NO | Tenant Used Memory, in bytes |
| FREE | bigint(21) | NO | Remaining memory of the tenant, in bytes |

## Sample query

The system tenant queries the memory usage of the tenant with ID 1002 across all nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_MEMORY WHERE TENANT_ID = 1002;
```

The query result is as follows:

