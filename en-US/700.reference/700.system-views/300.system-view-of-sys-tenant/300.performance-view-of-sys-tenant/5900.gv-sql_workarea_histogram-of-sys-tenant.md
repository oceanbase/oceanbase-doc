# GV$SQL_WORKAREA_HISTOGRAM

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V2.2.77. </p>
</main>

## Purpose

This view displays statistics for all previous workarea executions, such as the number of times full in-memory processing occurred between 1 MB and 2 MB, and the number of one-pass executions.

## Columns

|        **Column**        |   **Type**   | **Nullable** |                  **Description**                  |
|------------------------|------------|----------------|------------------------------------------|
| LOW_OPTIMAL_SIZE       | bigint(20) | NO             | The minimum memory size for the workarea in optimal mode.             |
| HIGH_OPTIMAL_SIZE      | bigint(20) | NO             | The maximum memory size for the workarea in optimal mode.             |
| OPTIMAL_EXECUTIONS     | bigint(20) | NO             | The number of executions in optimal mode within the lowest and highest intervals.             |
| ONEPASS_EXECUTIONS     | bigint(20) | NO             | The number of one-pass executions within the lowest and highest intervals.     |
| MULTIPASSES_EXECUTIONS | bigint(20) | NO             | The number of multi-pass executions within the lowest and highest intervals. |
| TOTAL_EXECUTIONS       | bigint(20) | NO             | The total number of executions for the workarea.                         |
| CON_ID                 | bigint(20) | NO             | The tenant ID.                                    |
| SVR_IP                 | varchar(46)   | NO             | The server IP address.                   |
| SVR_PORT                 | bigint(20)   | NO             | The server port number.                   |

## Sample query

Query the statistics for all previous workarea executions for tenant `1002` across all nodes, and display the first 10 records.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.GV$SQL_WORKAREA_HISTOGRAM WHERE CON_ID=1002 LIMIT 10;
```
