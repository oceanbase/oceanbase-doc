# GV$OB_TABLET_COMPACTION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_TABLET_COMPACTION_HISTORY` view displays the history of tablet-level compactions.

## Columns

Convert the MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Merge multiple Mini SSTables into one Mini SSTable, or merge multiple Mini SSTables with one Minor SSTable into one Minor SSTable. </li> <li>`META_MAJOR_MERGE`: special compaction type. ## Sample query

Query the V$OB_TABLET_COMPACTION_HISTORY view in the sys tenant to view the historical information about tablet-level major compactions on all OBServer nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_TABLET_COMPACTION_HISTORY LIMIT 1\G
```
