# GV$OB_PX_WORKER_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

In parallel execution scenarios, this view displays the execution information of each thread for all tenants on all OBServer nodes.

## Columns

|  **Column**  |    **Type**    | **Nullable** |   **Description**    |
|------------|--------------|----------------|----------------|
| SESSION_ID | bigint(20)   | NO             | For V4.3.x: <ul><li> V4.3.5 BP2 and earlier: <br> This field indicates the server session ID in all connection modes (direct mode/ODP mode). </li><li> V4.3.5 BP2 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field indicates the server session ID. </li></ul></ul></li></ul>     |
| TENANT_ID  | bigint(20)   | NO             | The tenant ID.          |
| SVR_IP     | varchar(46)  | NO             | The IP address of the server.     |
| SVR_PORT   | bigint(20)   | NO             | The port number of the server.          |
| TRACE_ID   | varchar(128) | NO             | The trace ID of the SQL statement. |
| QC_ID      | bigint(20)   | NO             | The qc_id in px.    |
| SQC_ID     | bigint(20)   | NO             | The sqc_id in px.   |
| WORKER_ID  | bigint(20)   | NO             | The thread ID.          |
| DFO_ID     | bigint(20)   | NO             | The dfo_id in px.   |
| START_TIME | timestamp(6) | NO             | The time when the thread started running.      |

## Sample query

In the sys tenant, query the execution information of all threads for all tenants on all OBServer nodes in parallel execution scenarios.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PX_WORKER_STAT\G
```
