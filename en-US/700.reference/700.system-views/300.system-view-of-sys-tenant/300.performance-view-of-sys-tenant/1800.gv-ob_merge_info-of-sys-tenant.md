# GV$OB_MERGE_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The view <code>GV$MERGE_INFO</code> was renamed to <code>GV$OB_MERGE_INFO</code> starting from V4.0.0. In V4.0.0 and later, you must use the new view name <code>GV$OB_MERGE_INFO</code> to query. Using the original view name <code>GV$MERGE_INFO</code> will result in an error. </p>
</main>

## Purpose

This view displays the statistics of completed major compactions in the OceanBase cluster.

## Columns

|       Column        |      Type       | Nullable |                                 Description                                  |
|-------------------|---------------|------------|-----------------------------------------------------------------------------------------------------|
| SVR_IP            | varchar(46)   | NO         | The IP address of the server.                                                           |
| SVR_PORT          | bigint(20)    | NO         | The port number of the server.                                                              |
| TENANT_ID         | bigint(20)    | NO         | The tenant ID.                                                               |
| LS_ID             | bigint(20)    | NO         | The log stream ID.                                                              |
| TABLET_ID         | bigint(20)    | NO         | The data tablet ID.                                                             |
| ACTION            | varchar(64)   | NO         | The action of the major compaction. <ul><li>`MDS_TABLE_MERGE`: persists the system metadata in the SSTable format to the disk. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: mini compaction. Converts the MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Combines multiple Mini SSTables into a new Mini SSTable or combines multiple Mini SSTables with one Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of major compaction. Combines the data before a specified time point into a Meta Major SSTable. The data format is the same as that of a Major SSTable, and the data does not contain multi-version data or uncommitted transaction data. </li> </ul>     |
| COMPACTION_SCN    | bigint(20) unsigned    | NO         | The version number of the major compaction.                                                      |
| START_TIME        | timestamp(6)  | NO         | The start time of the major compaction.                                                     |
| END_TIME          | timestamp(6)  | NO         | The end time of the major compaction.                                                     |
| MACRO_BLOCK_COUNT | bigint(20)    | NO         | The total number of macroblocks in the major compaction.                                                     |
| REUSE_PCT         | decimal(26,2) | NO         | The macroblock reuse rate of the major compaction.                                                    |
| PARALLEL_DEGREE   | bigint(20)    | NO         | The parallelism of the major compaction.                                                      |

## Sample query

Query the statistics of completed minor compactions (`MINI_MERGE`) in the cluster as the sys tenant and return the first five records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MERGE_INFO WHERE ACTION='MINI_MERGE' LIMIT 5;
```
