# GV$OB_VECTOR_MEMORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view is available starting with V4.4.1. </li></ul>
</main>

## Purpose

This view displays the detailed statistics of the memory usage of vector index data for all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)          | NO   |  The tenant ID. <ul><li>1: the ID of the sys tenant.  </li><li>Other values: the ID of a user tenant or a meta tenant. </li></ul>   |
| SVR_IP            | varchar(46)         | NO   |  The IP address of the node.   |
| SVR_PORT          | bigint(20)          | NO   |  The port number of the node.   |
| VECTOR_MEM_HOLD   | bigint(20)          | NO   |  The size of the memory occupied by vector index data, in bytes.   |
| VECTOR_MEM_LIMIT  | bigint(20)          | NO   |  The upper limit of the memory allocated to vector index data, in bytes.   |
| VECTOR_MEM_USED   | bigint(20)          | NO   |  The size of the memory actually used by vector index data, in bytes.   |

## Sample query

Query the detailed statistics of the memory usage of vector index data for all tenants.

```shell
OceanBase(root@test)>SELECT * FROM oceanbase.GV$OB_VECTOR_MEMORY  \G
```
