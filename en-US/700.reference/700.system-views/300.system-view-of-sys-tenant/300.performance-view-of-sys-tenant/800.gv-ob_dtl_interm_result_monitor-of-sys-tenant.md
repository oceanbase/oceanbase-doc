# GV$OB_DTL_INTERM_RESULT_MONITOR

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V3.2.4. </p>
</main>

## Purpose

This view displays the monitoring information of the DTL intermediate result manager.

## Columns

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the server. |
| SVR_PORT | bigint(20) | NO | The port number of the server. |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| TRACE_ID | varchar(64) | NO | The TRACE ID of the statement. |
| OWNER | varchar(64) | NO | The user who uses the intermediate result. |
| START_TIME | timestamp(6) | NO | The time when the intermediate result is written. |
| EXPIRE_TIME | timestamp(6) | NO | The time when the intermediate result expires. |
| HOLD_MEMORY | bigint(20) | NO | The size of the memory occupied, in bytes. |
| DUMP_SIZE | bigint(20) | NO | The size of the dump, in bytes. |
| DUMP_COST | bigint(20) | NO | The time spent on the dump. |
| DUMP_TIME | timestamp(6) | YES | The time when the dump is performed. |
| DUMP_FD | bigint(20) | NO | The file descriptor of the dump file. |
| DUMP_DIR_ID | bigint(20) | NO | The directory ID of the dump file. |
| CHANNEL_ID | bigint(20) | NO | The CHANNEL ID of DTL. |
| QC_ID | bigint(20) | NO | The QC ID of the sender. |
| DFO_ID | bigint(20) | NO | The DFO ID of the sender. |
| SQC_ID | bigint(20) | NO | The SQC ID of the sender. |
| BATCH_ID | bigint(20) | NO | The batch number in the px batch rescan scenario. |
| MAX_HOLD_MEMORY | bigint(20) | NO | The maximum size of the memory occupied, in bytes. |
