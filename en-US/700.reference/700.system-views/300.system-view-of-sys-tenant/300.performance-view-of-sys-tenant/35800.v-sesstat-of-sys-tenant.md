# V$SESSTAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V1.4. </p>
</main>

## Purpose

The `V$SESSTAT` view displays session-level statistics.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | For V4.3.x: <ul><li> V4.3.5 BP2 and earlier: <br> In all connection modes (direct mode/ODP mode), this field represents the server session ID. </li><li> V4.3.5 BP2 and later: <ul><li> In direct mode: <br> This field represents the server session ID. </li> <li> In ODP mode: </li><ul><li> If the ODP parameter <code>client_session_id_version = 2</code>, this field represents the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field represents the server session ID. </li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server where the information is located. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the information is located. |
| STATISTICS# | bigint(20) | NO | The index of the statistics. |
| VALUE | bigint(20) | NO | The number of times the statistics occurred. |

## Sample query

Query the session-level statistics.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSTAT LIMIT 1\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
       SID: 3221696264
    CON_ID: 1
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
