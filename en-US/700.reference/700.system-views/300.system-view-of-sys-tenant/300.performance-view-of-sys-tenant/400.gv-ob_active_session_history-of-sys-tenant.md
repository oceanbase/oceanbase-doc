# GV$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>In V4.3.x, this view was introduced in V4.3.5. </li> <li>In V4.2.x, this view was introduced in V4.2.2. </li></ul>
</main>

## Purpose

The `GV$OB_ACTIVE_SESSION_HISTORY` view displays the active session history of all OBServer nodes in all tenants.

## Columns

| **Column** | **Type** | **Nullable?** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the server where the sample is located. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the sample is located. |
| SAMPLE_ID | bigint(20) | NO | The unique ID of the sample on the local server. |
| SAMPLE_TIME | timestamp(6) | NO | The sampling time. |
| CON_ID | bigint(20) | NO | The tenant ID. |
| USER_ID | bigint(20) | NO | The user ID of the sampled session. |
| SESSION_ID | bigint(20) | NO | The ID of the sampled session. |
| SESSION_TYPE | varchar(10) | NO | The session type. Valid values include:<ul><li>FOREGROUND: foreground session, that is, user session.  </li><li>(Not supported) BACKGROUND: background session. </li></ul> |
| SESSION_STATE | varchar(7) | NO | The session state. Valid values include:<ul><li>ON CPU: no wait, executing SQL logic.  </li><li>WAITING: waiting. The wait event is described in the EVENT field. </li></ul> |
| SQL_ID | varchar(32) | NO | The SQL ID. |
| PLAN_ID | bigint(20) | NO | The plan ID of the sampled SQL statement in the plan cache, which is used to associate the sampling point with the plan. |
| TRACE_ID | varchar(64) | NO | The trace ID of the operator. |
| EVENT | varchar(64) | NO | The description of the wait event. |
| EVENT_NO | bigint(20) | NO | The internal ID of the wait event, which is used for join queries with other tables. |
| EVENT_ID | bigint(20) | YES | The ID of the current wait event. |
| P1TEXT | varchar(64) | NO | The name of the parameter 1 of the wait event. The name varies depending on the wait event. |
| P1 | bigint(20) | NO | The value of parameter 1 of the wait event. |
| P2TEXT | varchar(64) | NO | The name of the parameter 2 of the wait event. The name varies depending on the wait event. |
| P2 | bigint(20) | NO | The value of parameter 2 of the wait event. |
| P3TEXT | varchar(64) | NO | The name of the parameter 3 of the wait event. The name varies depending on the wait event. |
| P3 | bigint(20) | NO | The value of parameter 3 of the wait event. |
| WAIT_CLASS | varchar(64) | NO | The type of the wait event. |
| WAIT_CLASS_ID | bigint(20) | NO | The ID of the wait event type, which is used for join queries with other tables. |
| TIME_WAITED | bigint(20) | NO | The total wait time of the wait event, in microseconds (us). |
| SQL_PLAN_LINE_ID | bigint(20) | YES | The ID of the SQL operator in the SQL plan when the session was sampled. |
| GROUP_ID         | bigint(20) | YES  | The ID of the resource group to which the session belongs.     |
| PLAN_HASH                   | bigint(20) unsigned | YES  | The plan hash value of the current SQL statement.     |
| THREAD_ID                   | bigint(20)          | YES  | The ID of the thread where the active session resides.    |
| STMT_TYPE                   | bigint(20)          | YES  | The SQL type of the active session.     |
| TIME_MODEL                  | bigint(20)          | NO   | The time model information, which is a collection of IN_XXX fields (such as IN_PARSE and IN_PL_PARSE).     |
| IN_PARSE | varchar(1) | NO | Whether the session is parsing an SQL statement when it is sampled. |
| IN_PL_PARSE | varchar(1) | NO | Whether the session is parsing an PL/SQL statement when it is sampled. |
| IN_PLAN_CACHE | varchar(1) | NO | Whether the session is matching a plan in the plan cache when it is sampled. |
| IN_SQL_OPTIMIZE | varchar(1) | NO | Whether the session is optimizing an SQL statement when it is sampled. |
| IN_SQL_EXECUTION | varchar(1) | NO | Whether the session is executing an SQL statement when it is sampled. |
| IN_PX_EXECUTION | varchar(1) | NO | Whether the session is executing an SQL statement in parallel when it is sampled. When the session is in this state, it is also in the IN_SQL_EXECUTION state. |
| IN_SEQUENCE_LOAD | varchar(1) | NO | Whether the session is fetching values from an auto-increment column or a sequence when it is sampled. |
| IN_COMMITTING | varchar(1) | NO | Whether the sampling point is in the transaction commit phase. |
| IN_STORAGE_READ | varchar(1) | NO | Whether the sampling point is in the storage read phase. |
| IN_STORAGE_WRITE | varchar(1) | NO | Whether the sampling point is in the storage write phase. |
| IN_REMOTE_DAS_EXECUTION | varchar(1) | NO | Whether the sampling point is in the DAS remote execution phase. |
| IN_FILTER_ROWS | varchar(1) | NO | Whether the sampling point is in the storage down-press execution phase. |
| PROGRAM | varchar(64) | YES | The name of the program being executed at the sampling point:<ul><li>Background thread: the thread name, such as `observer` and `WrTimer`.  </li><li>Foreground thread:<ul><li>For a normal request, the value is `user@client_ip (thread_name)`.  </li><li>For an `inner_sql` remote execution request, the value is `INNER SQL REMOTE EXEC (thread_name)`.  </li><li>For a DAS remote execution request, the value is `DAS REMOTE EXEC (thread_name)`.  </li></ul> </li></ul>|
| MODULE | varchar(64) | YES | The MODULE value recorded when the session is sampled, which is set by using the `DBMS_APPLICATION_INFO.SET_MODULE` procedure. |
| ACTION | varchar(64) | YES | The ACTION value recorded when the session is sampled, which is set by using the `DBMS_APPLICATION_INFO.SET_ACTION` procedure. |
| CLIENT_ID | varchar(64) | YES | The CLIENT_ID value recorded when the session is sampled, which is set by using the `DBMS_SESSION.set_identifier` procedure. |
| BACKTRACE | varchar(512) | YES | The code call stack at the time of the event. The value of this field is always NULL. |
| TM_DELTA_TIME | bigint(20) | YES | The time interval for calculating the time model, in microseconds. |
| TM_DELTA_CPU_TIME | bigint(20) | YES | The CPU time spent in the past `TM_DELTA_TIME` time period. |
| TM_DELTA_DB_TIME | bigint(20) | YES | The database call time spent in the past `TM_DELTA_TIME` time period. |
| TOP_LEVEL_SQL_ID | varchar(32) | YES | The ID of the top-level SQL statement. |
| IN_PLSQL_COMPILATION | varchar(1) | NO | The PL compilation status: Y/N |
| IN_PLSQL_EXECUTION | varchar(1) | NO | The PL execution status: Y/N |
| PLSQL_ENTRY_OBJECT_ID | bigint(20) | YES | The OBJECT ID of the top-level PL. |
| PLSQL_ENTRY_SUBPROGRAM_ID | bigint(20) | YES | The subprogram ID of the top-level PL. |
| PLSQL_ENTRY_SUBPROGRAM_NAME | varchar(32) | YES | The subprogram name of the top-level PL. |
| PLSQL_OBJECT_ID | bigint(20) | YES | The ID of the PL being executed. |
| PLSQL_SUBPROGRAM_ID | bigint(20) | YES | The ID of the subprogram being executed. |
| PLSQL_SUBPROGRAM_NAME | varchar(32) | YES | The name of the subprogram being executed. |
| TX_ID                       | bigint(20)          | YES  | The ID of the current transaction.     |
| BLOCKING_SESSION_ID         | bigint(20)          | YES  | The ID of the session that blocks the current session. The field is effective only in lock conflict scenarios, and displays the ID of the session that holds the lock.      |
| TABLET_ID                   | bigint(20)          | YES  | The ID of the tablet being processed by the current SQL statement.     |
| PROXY_SID                   | bigint(20)          | YES  | The ID of the proxy session.     |
