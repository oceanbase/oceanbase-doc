# V$OB_JAVA_UDF_STATS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For V4.4.2, this view is available starting from V4.4.2 BP4.</p>
</main>

## Overview

This view displays the execution statistics of Java UDFs for all tenants on the current OBServer node, including the number of calls, successes and failures, concurrency, time distribution, and time consumed in each execution phase. Each Java UDF is statistically analyzed by function type and execution mode.

The usage instructions are as follows:

* Statistical information is only stored in memory and is reset after an OBServer node restarts.
* Each tenant retains at most 1,024 statistics on each OBServer node. When this limit is exceeded, statistics for deleted Java UDFs are evicted first, followed by the least recently used statistics. The eviction or discarding of statistics does not affect the execution of Java UDFs.
* The system tenant can view statistics for all tenants, including those of deleted Java UDFs.

## Sample query

Query the execution statistics of the top 10 Java UDFs called most frequently by all tenants on the current OBServer node.

```shell
obclient> SELECT SVR_IP, TENANT_ID, UDF_NAME, ROUTINE_TYPE, EXECUTION_MODE, CALL_COUNT, FAIL_COUNT, AVG_ELAPSED_US, P99_ELAPSED_US_5M FROM oceanbase.V$OB_JAVA_UDF_STATS ORDER BY CALL_COUNT DESC LIMIT 10;
```
