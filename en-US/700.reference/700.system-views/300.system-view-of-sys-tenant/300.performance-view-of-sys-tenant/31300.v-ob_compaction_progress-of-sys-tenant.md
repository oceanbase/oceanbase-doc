# V$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the major compaction progress of all tenants on the current node.

## Columns

|          Column           |      Type      | Nullable |                                            Description                                            |
|-------------------------|--------------|------------|--------|
|SVR_IP    |varchar(46)    |NO   |The IP address of the server.    |
|SVR_PORT    |bigint(20)    |NO   |The port number of the server.    |
|TENANT_ID    |bigint(20)    |NO   |The ID of the tenant.    |
|TYPE    |varchar(64)    |NO   |The type of major compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persist the system metadata in the SSTable format to the disk. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: mini compaction. Converts the MemTable to a mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Combines multiple mini SSTables or multiple mini SSTables and minor SSTables into one minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of major compaction. Combines all data before a specified time point into one Meta Major SSTable. The data format is the same as that of a Major SSTable, which does not contain multi-version data and uncommitted transaction data. </li></ul>   |
|ZONE    |varchar(128)    |NO   |The information about the zone.    |
|COMPACTION_SCN    |bigint(20) unsigned    |NO   |The compaction version.    |
|STATUS    |varchar(10)    |NO   |The status.    |
|TOTAL_TABLET_CNT    |bigint(20)    |NO   |The total number of tablets.    |
|UNFINISHED_TABLET_CNT    |bigint(20)    |NO   |The number of tablets that have not been processed.    |
|DATA_SIZE    |bigint(20)    |NO   |The total data size to be scanned.    |
|UNFINISHED_DATA_SIZE    |bigint(20)    |NO   |The data size that has not been scanned.    |
|COMPRESSION_RATIO    |bigint(20)    |NO   |The compression ratio of new data. This ratio is recorded only for data written after the last major version point.    |
|START_TIME    |timestamp(6)    |NO   |The start time.    |
|ESTIMATED_FINISH_TIME    |timestamp(6)    |NO   |The estimated end time. If the value of compaction_progress is 100, the end time is displayed.    |
|COMMENTS    |varchar(256)    |NO   |The comment. During the major compaction, the latest major compaction event is recorded. If the major compaction is completed, the overall time consumption is recorded.    |

## Sample query

Query the major compaction progress of all tenants on the current node as the sys tenant, and display the first five records.

obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_COMPACTION_PROGRESS LIMIT 5;
