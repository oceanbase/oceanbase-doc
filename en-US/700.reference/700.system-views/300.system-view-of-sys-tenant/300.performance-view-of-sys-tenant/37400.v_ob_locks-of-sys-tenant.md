# V$OB_LOCKS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the lock status of tables for the current user.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the OBServer node that holds or requests the lock. |
| SVR_PORT | bigint(20) | NO | The port number of the OBServer node that holds or requests the lock. |
| TENANT_ID | bigint(20) | NO | The ID of the tenant that holds or requests the lock. |
| TRANS_ID | bigint(20) | NO | The transaction ID that holds or requests the lock. |
| SESSION_ID | bigint(20)   | NO   | The session ID that holds or requests the lock. <ul><li>For V4.3.x, this field is available starting with V4.3.2. <ul><li>For versions earlier than V4.3.5 BP2: <br> In all connection modes (direct mode/ODP mode), this field indicates the server session ID. </li><li>For V4.3.5 BP2 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this field indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this field indicates the server session ID. </li></ul></ul></li></ul> </li><li>For V4.2.x, this field is available starting with V4.2.5. <ul><li>For versions earlier than V4.2.5 BP4: <br> In all connection modes (direct mode/ODP mode), this field indicates the server session ID. </li><li>For V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version</code> parameter in ODP is set to 2, this field indicates the client session ID. </li> <li> If <code>client_session_id_version</code> is set to 1, this field indicates the server session ID. </li></ul></ul></li></ul></li></ul>|
| TYPE | varchar(9) | NO | The lock type: <ul><li>TM: table lock</li><li>TX: transaction lock</li><li>TR: row lock</li></ul> |
| ID1 | bigint(20) | NO | Lock identifier 1: <ul><li>Table lock: may be the TABLE_ID or the TABLET_ID</li><li>Transaction lock: TX_ID</li><li>Row lock: TABLET_ID</li></ul> |
| ID2 | varchar(533) | NO | Lock identifier 2: <ul><li>Table lock: NULL</li><li>Transaction lock: NULL</li><li>Row lock: TX_ID + rowkey</li></ul> |
| ID3 | varchar(512) | NO | Lock identifier 3: <ul><li>TM: TABLE_ID / TABLET_ID</li><li>TX: NULL</li><li>TR: TABLET_ID + rowkey</li></ul> <main id="notice" type='explain'><h4>Note</h4><p><ul><li>For V4.3.x, this field is available starting with V4.3.2.</li><li>For V4.2.x, this field is available starting with V4.2.5.</li></ul></p></main>|
| LMODE | varchar(8) | NO | The mode of the lock currently held: <ul><li>NONE: indicates that no lock is held </li><li>RS: ROW SHARE</li><li>RX: ROW EXCLUSIVE</li><li>S: SHARE</li><li>SRX: SHARE ROW EXCLUSIVE</li><li>X: EXCLUSIVE</li></ul> |
| REQUEST | varchar(8) | NO | The mode of the lock currently requested: <ul><li>NONE: indicates that no lock is requested </li><li>RS: ROW SHARE</li><li>RX: ROW EXCLUSIVE</li><li>S: SHARE</li><li>SRX: SHARE ROW EXCLUSIVE</li><li>X: EXCLUSIVE</li></ul> |
| CTIME | bigint(20) | NO | The time for which the lock is held or the time for which the lock is being waited for, in microseconds. |
| BLOCK | bigint(1) | NO | Indicates whether the lock requested by the current transaction is held by another transaction: <ul><li>0: indicates that the lock requested by the transaction is not held by another transaction, that is, the transaction holds the lock.  </li><li>1: indicates that the lock requested by the transaction is held by another transaction, that is, the transaction is blocked. </li></ul>|

## Sample query

Query the lock status of tables for the current user on the current OBServer node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_LOCKS;
```

The query result is as follows:

```shell

+----------------+----------+-----------+----------+------------+------+---------+------------+------+-------+---------+---------+-------+
| 11.xxx.xxx.xxx |    28825 |         1 |  9720694 | 3221516966 | TM   | 9720177 | 4294967295 | NULL | NONE  | N       | 3120758 |     1 |

1 row in set
```
