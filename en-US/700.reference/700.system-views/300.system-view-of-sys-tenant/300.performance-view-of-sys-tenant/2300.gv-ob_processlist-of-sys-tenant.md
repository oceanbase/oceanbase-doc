# GV$OB_PROCESSLIST

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_PROCESSLIST` view displays session information for all OBServer nodes of the current tenant.

## Sample query

Query the session information of all OBServer nodes where the tenant is located.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PROCESSLIST LIMIT 1\G
```
