# V$OB_TRANSACTION_PARTICIPANTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `V$OB_TRANSACTION_PARTICIPANTS` view displays information about transaction participants on all OBServer nodes.

## Columns

|       Column       |      Type       | Nullable |    Description     |
|------------------|---------------|------------|-----------|
| TENANT_ID        | bigint(20)    | NO         | The tenant ID.     |
| SVR_IP           | varchar(46)   | NO         | The IP address of the server. |
| SVR_PORT         | bigint(20)    | NO         | The port number of the server.    |
| SESSION_ID       | bigint(20)    | NO         | For V4.3.x versions:<ul><li> V4.3.5 BP2 and earlier versions:<br>This field represents the server session ID in all connection modes (direct mode/ODP mode). </li><li> V4.3.5 BP2 and later versions:<ul><li> In direct mode:<br>This field represents the server session ID. </li> <li> In ODP mode:</li><ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field represents the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field represents the server session ID. </li></ul></ul></li></ul>      |
| SCHEDULER_ADDR   | varchar(64)   | NO         | The IP address of the node where the scheduler is located. |
| TX_TYPE          | varchar(11)   | NO         | The transaction type.      |
| TX_ID            | bigint(20)    | NO         | The transaction ID.      |
| LS_ID            | bigint(20)    | NO         | The ID of the log stream to which the transaction belongs.   |
| PARTICIPANTS     | varchar(1024) | NO         | The list of participants.     |
| CTX_CREATE_TIME  | timestamp(6)  | NO        | The time when the context was created.  |
| TX_EXPIRED_TIME  | timestamp(6)  | NO        | The time when the transaction expired.   |
| STATE            | varchar(13)   | NO         | The context submission status.   |
| ACTION           | varchar(10)   | NO         | The last executed action.  |
| PENDING_LOG_SIZE | bigint(20)    | NO         | The size of data to be persisted, in bytes.  |
| FLUSHED_LOG_SIZE | bigint(20)    | NO         | The size of data that has been persisted, in bytes.  |
| ROLE             | varchar(8)    | NO         | The context role.     |
| COORD             | bigint(20)    | NO   | The ID of the corresponding coordinator (effective only after the transaction enters the commit phase).    |
| LAST_REQUEST_TIME | timestamp(6)  | NO  | The time when the last external request was received.    |
| FORMATID          | bigint(20)    | NO   | The type of the xid format.    |
| GLOBALID          | varchar(257)  | NO   | The global identifier of the XA transaction.    |
| BRANCHID          | varchar(257)  | NO   | The qualifier of the XA transaction branch.    |

## Sample query

Query information about transaction participants on all OBServer nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TRANSACTION_PARTICIPANTS LIMIT 1\G
```
