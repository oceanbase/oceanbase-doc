# V$OB_PX_WORKER_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

In parallel execution scenarios, this view displays the execution information of all tenants on each thread of the current OBServer node.

## Columns

|  **Column**  |      Type      | **Nullable** |       Description       |
|------------|--------------|----------------|----------------|
| SESSION_ID | bigint(20)   | NO             | For V4.2.x versions:<ul><li> V4.2.5 BP4 and earlier versions:<br>This field represents the Server Session ID in all connection modes (direct mode/ODP mode). </li><li> V4.2.5 BP4 and later versions:<ul><li> In direct mode:<br>This field represents the Server Session ID. </li> <li> In ODP mode: </li><ul><li> When the <code>client_session_id_version = 2</code> parameter is set in ODP, this field represents the Client Session ID. </li> <li> When <code>client_session_id_version = 1</code>, this field represents the Server Session ID. </li></ul></ul></li></ul>      |
| TENANT_ID  | bigint(20)   | NO             | The tenant ID.          |
| SVR_IP     | varchar(46)  | NO             | The IP address of the server.     |
| SVR_PORT   | bigint(20)   | NO             | The port of the server.          |
| TRACE_ID   | varchar(128) | NO             | The trace ID of the SQL statement. |
| QC_ID      | bigint(20)   | NO             | The qc_id in px.    |
| SQC_ID     | bigint(20)   | NO             | The sqc_id in px.   |
| WORKER_ID  | bigint(20)   | NO             | The thread ID.          |
| DFO_ID     | bigint(20)   | NO             | The dfo_id in px.   |
| START_TIME | timestamp(6) | NO             | The time when the thread started running.      |

## Sample query

In the sys tenant, query the execution information of all threads of all tenants on the current OBServer node in parallel execution scenarios.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PX_WORKER_STAT\G
```
