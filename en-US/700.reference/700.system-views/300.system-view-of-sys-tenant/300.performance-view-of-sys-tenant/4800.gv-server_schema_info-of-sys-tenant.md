# GV$OB_SERVER_SCHEMA_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the schema information of all tenants on all OBServer nodes.

## Columns

|          **Column**          |   **Type**    | **Nullable** |              **Description**              |
|----------------------------|-------------|----------------|----------------------------------|
| SVR_IP                     | varchar(46) | NO             | The IP address of the server.                        |
| SVR_PORT                   | bigint(20)  | NO             | The port number of the server.                           |
| TENANT_ID                  | bigint(20)  | NO             | The tenant ID.                            |
| REFRESHED_SCHEMA_VERSION   | bigint(20)  | NO             | The schema version that has been refreshed for the tenant.                 |
| RECEIVED_SCHEMA_VERSION    | bigint(20)  | NO             | The schema version that is to be refreshed for the tenant.               |
| SCHEMA_COUNT               | bigint(20)  | NO             | The number of schemas of the tenant.                    |
| SCHEMA_SIZE                | bigint(20)  | NO             | The size of schemas of the tenant.                    |
| MIN_SSTABLE_SCHEMA_VERSION | bigint(20)  | NO             | The minimum schema_version recorded in the SSTable of the tenant. |

## Sample query

Query the schema information of all tenants on all OBServer nodes in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_SERVER_SCHEMA_INFO;
```
