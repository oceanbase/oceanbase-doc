# GV$OB_IVF_INDEX_INFO

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

This view displays the basic information and real-time status of IVF vector indexes for all tenants on all OBServer nodes.

## Columns

|             Column          |      Data type    | Nullable |            Description                                            |  Information type |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | The IP address of the node where the replica is located.                                              | Basic information |
| SVR_PORT                     | bigint(20)   | NO             | The RPC_PORT of the node where the replica is located.                                              | Basic information |
| TENANT_ID                    | bigint(20)   | NO             | The tenant ID. <ul><li>1: the ID of the sys tenant</li> <li>Other values: the ID of a user tenant or the ID of the meta tenant</li></ul>                                                    | Basic information |
| DATA_TABLE_ID                | bigint(20)   | NO             | The ID of the data table.                                                    | Basic information |
| TABLE_NAME                   | varchar(256) | NO             | The name of the table.                                                    | Basic information |
| INDEX_NAME                   | varchar(256) | NO             | The name of the index.                                                    | Index information |
| INDEX_TABLE_ID               | bigint(20)   | NO             | The ID of the index table.                                                    | Index information |
| INDEX_TABLET_ID              | bigint(20)   | NO             | The ID of the index table partition.                                                    | Index information |
| INDEX_PARAM                  | varchar(1024)     | NO             | The index parameters.                                                    | Index information |
| CACHE_TYPE                   | varchar(29)   | NO             | The cache type of the IVF index. <ul><li>IVF_CENTROID_CACHE: the centroid cache of the IVF index</li> <li>IVF_PQ_CENTROID_CACHE: the centroid cache of the IVF_PQ index</li> <li>IVF_PQ_PRECOMPUTE_TABLE_CACHE: the precomputed table cache of the IVF_PQ index</li></ul>                                                    | Cache information |
| IS_INIT                      | varchar(5)   | NO             | Indicates whether the cache is initialized. <ul><li>TRUE: the cache is initialized</li> <li>FALSE: the cache is not initialized</li></ul>                                                    | Cache information |
| MEMORY_USED                  | bigint(20)   | NO             | The memory used.                                                    | Index information |
| MEMORY_HOLD                  | bigint(20)   | NO             | The memory occupied.                                                    | Index information |
| CACHE_INFO                   | varchar(512)     | NO             | The cache attribute information in JSON format.                                                    | Cache information |

SELECT * FROM oceanbase.GV$OB_IVF_INDEX_INFO;
