# V$OB_SESSION_PS_INFO

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in OceanBase Database V4.2.3. </p>
</main>

## Purpose

The `V$OB_SESSION_PS_INFO` view displays the information about prepared statements opened in all sessions on the current OBServer node.

## Columns

| Column | Type | Nullable? | Description |
| ------------ | -------- | ------------------- | -------- |
| SVR_IP             | varchar(46) | NO | The IP address of the OBServer node. |
| SVR_PORT           | bigint(20)  | NO | The port number of the OBServer node. |
| TENANT_ID          | bigint(20)  | NO |  The ID of the tenant. |
| PROXY_SESSION_ID   | bigint(20) unsigned | NO | The session ID in OceanBase Database Proxy (ODP). |
| SESSION_ID         | bigint(20) unsigned | NO | The session ID on the OBServer node. |
| PS_CLIENT_STMT_ID  | bigint(20)  | NO | The prepared statement ID returned to the client after the client sends a PREPARE request. |
| PS_INNER_STMT_ID   | bigint(20)  | NO | The internal prepared statement ID on the OBServer node, namely the prepared statement ID in the prepared statement cache. |
| STMT_TYPE          | varchar(256)| NO | The type of the prepared statement. Here are some of the valid values: `T_SELECT`, `T_INSERT`, `T_REPLACE`, `T_DELETE`, `T_UPDATE`, `T_MERGE`, `T_EXPLAIN`, `T_CREATE_TABLE`, and `T_DROP_TABLE`. |
| PARAM_COUNT        | bigint(20)  | NO | The number of parameters in the prepared statement. |
| PARAM_TYPES        | longtext    | NO | A list of parameter types. It contains the types of all parameters in the prepared statement. Each parameter type is represented by a number. Different parameter types are separated with commas (,). |
| REF_COUNT          | bigint(20)  | NO | The reference count of the `ps_session_info_` attribute in the session. After a statement is prepared in a session, a `ps_session_info_` attribute is generated in the session. |
| CHECKSUM           | bigint(20)  | NO | The string checksum of the parameterized SQL statement in the prepared statement cache. |

## Sample query

Query the information about prepared statements opened in all sessions on the current OBServer node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_SESSION_PS_INFO;
```

The query result is as follows:

```shell

| xx.xx.xx.xx   |    17119 |      1010 |                0 | 3221625481 |                 1 |                3 | T_SELECT  |           3 | 3, 15, 5    |         1 | 1817423648 |
+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+
```
