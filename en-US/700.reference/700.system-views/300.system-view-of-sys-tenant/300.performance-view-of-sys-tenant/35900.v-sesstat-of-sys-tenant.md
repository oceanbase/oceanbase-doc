# V$SESSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays the session-level statistics of each tenant on the current OBServer node. In this view, `STATISTIC#` indicates the index of the statistics. You can query the `V$STATNAME` view to obtain the name and description of the statistics corresponding to the `STATISTIC#` index.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br>This field indicates the server session ID in all connection modes (direct mode and ODP mode). </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br>This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field indicates the server session ID. </li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server where the information is stored. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the information is stored. |
| STATISTICS# | bigint(20) | NO | The index of the statistics. |
| VALUE | bigint(20) | NO | The number of times the statistics event occurs. |

## Sample query

In the sys tenant, query the session-level statistics of tenant 1002 on the current OBServer node, and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSTAT WHERE CON_ID=1002 LIMIT 10;
```
