# V$OB_COMPACTION_SUGGESTIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

This view displays the compaction suggestions on the current node.

## Columns

|    Column     |      Type       | Nullable |                                            Description                                            |
|-------------|---------------|------------|--------|
| SVR_IP      | varchar(46)   | NO         | The IP address of the server.                                                                                |
| SVR_PORT    | bigint(20)    | NO         | The port number of the server.|
| TENANT_ID   | bigint(20)    | NO         | The tenant ID. |
| TYPE        | varchar(64)   | NO         | The type of compaction. Valid values: <ul><li>`MDS_TABLE_MERGE`: persist the system metadata in SSTable format to disk. </li> <li>`MAJOR_MERGE`: major compaction at the tenant level. </li> <li>`MEDIUM_MERGE`: major compaction at the partition level. </li> <li>`MINI_MERGE`: minor compaction. Converts a MemTable to a Mini SSTable. </li> <li>`MINOR_MERGE`: minor compaction. Combines multiple Mini SSTables into a new Mini SSTable, or combines multiple Mini SSTables with one Minor SSTable into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: a special type of compaction. Combines all data before a specified time point into a Meta Major SSTable. The data format of a Meta Major SSTable is the same as that of a Major SSTable, and it does not contain multi-version data or uncommitted transaction data. </li></ul>    |
| LS_ID       | bigint(20)    | NO         | The log stream ID.|
| TABLET_ID   | bigint(20)    | NO         | The data tablet ID.                                                                                  |
| START_TIME  | timestamp(6)  | NO         | The start time.  |
| FINISH_TIME | timestamp(6)  | NO         | The end time.  |
| SUGGESTION  | varchar(1024) | NO         | The suggestion.  |
