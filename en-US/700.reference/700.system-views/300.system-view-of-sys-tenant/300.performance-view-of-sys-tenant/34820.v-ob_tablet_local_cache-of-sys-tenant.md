# V$OB_TABLET_LOCAL_CACHE

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>For V4.4.x versions, this view is available starting with V4.4.0. </li>
<li>For V4.3.5, this view is available starting with V4.3.5 BP2. </li></ul>
</main>

## Purpose

This view displays the overall cache status of each tenant on the current OBServer node.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available only in Shared-Storage (SS) mode. In Shared-Nothing (SN) mode, the query result of this view is empty. </p>
</main>

## Columns

|      Column         |         Type  | Nullable |                       Description      |
|----------------------|---------------|----------------|---------------------------------|
| SVR_IP               | varchar(46)   | NO   |  The IP address of the OBServer node.    |
| SVR_PORT             | bigint(20)    | NO   |  The port number of the OBServer node.      |
| TENANT_ID            | bigint(20)    | NO   |  The tenant ID.    |
| TABLET_ID            | bigint(20)    | NO   |  The tablet ID.    |
| STORAGE_CACHE_POLICY | varchar(64)   | NO   |  The cache status of the tablet:<ul><li>`AUTO`: Automatic hot/cold data identification</li> <li>`HOT`: Hot data</li></ul>   |
| CACHED_DATA_SIZE     | bigint(20)    | NO   |  The size of data cached to the tablet, in bytes.    |
| CACHE_HIT_COUNT      | bigint(20)    | NO   |  The number of cache hits. This column is not enabled yet and its value is `-1`.    |
| CACHE_MISS_COUNT     | bigint(20)    | NO   |  The number of cache misses. This column is not enabled yet and its value is `-1`.    |
| CACHE_HIT_SIZE       | bigint(20)    | NO   |  The size of data cached to the tablet, in bytes. This column is not enabled yet and its value is `-1`.   |
| CACHE_MISS_SIZE      | bigint(20)    | NO   |  The size of data cached to the tablet, in bytes. This column is not enabled yet and its value is `-1`.   |
| INFO                 | varchar(4096) | NO   |  Other information.    |

## Sample query

In SS mode, the system tenant queries the overall cache status of tenant `1002` on the current OBServer node.

```shell
obclient> SELECT SVR_IP, SVR_PORT, TENANT_ID, TABLET_ID, STORAGE_CACHE_POLICY, INFO FROM oceanbase.V$OB_TABLET_LOCAL_CACHE WHERE TENANT_ID = 1002;
```
