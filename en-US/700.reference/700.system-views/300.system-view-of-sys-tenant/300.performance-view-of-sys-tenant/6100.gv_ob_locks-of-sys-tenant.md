# GV$OB_LOCKS

## Description

Displays the locks held or requested by the current user on each table.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced in V4.2.0. </p>
</main>

## Description of fields

| **Field** | **Type** | **NULL?** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the OBServer node that holds or requests the lock. |
| SVR_PORT | bigint(20) | NO | The port number of the OBServer node that holds or requests the lock. |
| TENANT_ID | bigint(20) | NO | The ID of the tenant that holds or requests the lock. |
| TRANS_ID | bigint(20) | NO | The transaction ID of the transaction that holds or requests the lock. |
| SESSION_ID | bigint(20)   | NO   | The session ID of the session that holds or requests the lock. <main id="notice" type='explain'><h4>Note</h4><p><ul><li>This field is introduced in V4.3.2 of the V4.3.x series. </li><li>This field is introduced in V4.2.5 of the V4.2.x series. </li></ul></p></main>|
| TYPE | varchar(9) | NO | The lock type. <ul><li>TM: table lock</li><li>TX: transaction lock</li><li>TR: row lock</li></ul> |
| ID1 | bigint(20) | NO | Lock identifier 1. <ul><li>TM: transaction ID</li><li>TX: transaction ID</li><li>TR: transaction ID</li></ul> |
| ID2 | bigint(20) | NO | Lock identifier 2. <ul><li>TM: session ID (NULL for external table locks of transactions)</li><li>TX: session ID</li><li>TR: session ID</li></ul> |
| ID3 | varchar(512) | NO | Lock identifier 3. <ul><li>TM: TABLE_ID / TABLET_ID</li><li>TX: NULL</li><li>TR: TABLET_ID + row rowkey</li></ul> <main id="notice" type='explain'><h4>Note</h4><p><ul><li>This field is introduced in V4.3.2 of the V4.3.x series. </li><li>This field is introduced in V4.2.5 of the V4.2.x series. </li></ul></p></main>|
| LMODE | varchar(4) | NO | The mode in which the lock is held. <ul><li>NONE: no lock is held. </li><li>RS: row share.</li><li>RX: row exclusive.</li><li>S: share.</li><li>SRX: share row exclusive.</li><li>X: exclusive.</li></ul> |
| REQUEST | varchar(8) | NO | The mode in which the lock is requested. <ul><li>NONE: no lock is requested. </li><li>RS: row share.</li><li>RX: row exclusive.</li><li>S: share.</li><li>SRX: share row exclusive.</li><li>X: exclusive.</li></ul> |
| CTIME | bigint(20) | NO | The time when the lock was held or requested, in microseconds. |
| BLOCK | bigint(1) | NO | Indicates whether the lock requested by the current transaction is held by another transaction. <ul><li>0: the requested lock is not held by another transaction, which means that the transaction holds the lock. </li><li>1: the requested lock is held by another transaction, which means that the transaction is blocked. </li></ul>|
