# V$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

In the sys tenant, the `V$OB_KV_GROUP_COMMIT_STATUS` view displays the group commit status of all OBKV tenant client connections on the current node.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the node where the group commit group is located. |
| SVR_PORT | bigint(20) | NO | The port number of the node where the group commit group is located. |
| TENANT_ID | bigint(20) | NO | The tenant ID: <ul><li>1: the ID of the sys tenant. </li><li>Other values: the ID of a user tenant or the ID of the meta tenant. </li></ul> |
| TABLE_ID | bigint(20) | NO | The ID of the table to which the group commit group belongs. |
| LS_ID | bigint(20) | NO | The ID of the leader server to which the group commit group belongs. |
| SCHEMA_VERSION | bigint(20) | NO | The schema version of the table to which the group commit group belongs. |
| GROUP_TYPE | varchar(32) | NO | The type of the group commit group. Supported types: <ul><li>get: get request queue. </li><li>put: put request queue. </li><li>del: delete request queue. </li><li>replace: replace request queue. </li><li>insert: insert request queue. </li><li>hybird: hybrid operation request queue. </li><li>fail: batch failure queue. </li></ul>  |
| QUEUE_SIZE | bigint(20) | NO | The size of the request queue in the group commit group. This value indicates the number of unprocessed requests. |
| BATCH_SIZE | bigint(20) | NO | The size of the batch in the group commit group. |
| CREATE_TIME | timestamp(6) | NO  | The time when the group was created in the group commit group.  |
| UPDATE_TIME | timestamp(6) | NO  | The time when the status information of the group was refreshed in the group commit group.  |

## Sample query

Query the group commit status of the current node's OBKV tenant client connections and display the first day's records.

```shell
obclient > SELECT * FROM oceanbase.V$OB_KV_GROUP_COMMIT_STATUS limit 2;
```
