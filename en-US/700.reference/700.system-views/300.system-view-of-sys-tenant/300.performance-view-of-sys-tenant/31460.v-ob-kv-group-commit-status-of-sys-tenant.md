# V$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view was introduced in OceanBase Database V4.3.4. </p>
</main>

## Purpose

In a system tenant, the `V$OB_KV_GROUP_COMMIT_STATUS` view can be used to query the group commit status of all OBKV tenant clients connected to the current node.

## Columns

| **Column** | **Type** | **Nullable?** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | IP address of the node where the group commit group is located. |
| SVR_PORT | bigint(20) | NO | Port number of the node where the group commit group is located. |
| TENANT_ID | bigint(20) | NO | Tenant ID: <li> 1: ID of the system tenant <li> Other values: ID of a user tenant or a meta tenant |
| TABLE_ID | bigint(20) | NO | ID of the table to which the group commit group belongs. |
| LS_ID | bigint(20) | NO | ID of the ls to which the group commit group belongs. |
| SCHEMA_VERSION | bigint(20) | NO | Schema version of the table to which the group commit group belongs. |
| GROUP_TYPE | varchar(32) | NO | Type of the group commit group. Valid values include: <ul><li> get: get request queue </li><li>put: put request queue </li><li>del: delete request queue </li><li>replace: replace request queue </li><li>insert: insert request queue </li><li>hybird: hybrid operation request queue </li><li>fail: batch execution failure queue </li></ul>  |
| QUEUE_SIZE | bigint(20) | NO | Size of the request queue in the group commit group, representing the number of unprocessed requests. |
| BATCH_SIZE | bigint(20) | NO | Size of the batch in the group commit group. |
| CREATE_TIME | timestamp(6) | NO  | Time when the group commit group was created.  |
| UPDATE_TIME | timestamp(6) | NO  | Time when the status information of the group commit group was last refreshed.  |

## Sample query

```shell
obclient > SELECT * FROM oceanbase.V$OB_KV_GROUP_COMMIT_STATUS limit 2;
```
