# V$SESSION_EVENT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays session-level wait events for all tenants on the current node.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server. |
| SVR_PORT | bigint(20) | NO | The port number of the server. |
| SID | bigint(20) | NO | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> This field indicates the server session ID in all connection modes (direct mode/ODP mode). </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field indicates the server session ID. </li> <li> In ODP mode: </li><ul><li> If the <code>client_session_id_version = 2</code> parameter is set in ODP, this field indicates the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field indicates the server session ID. </li></ul></ul></li></ul>  |
| EVENT | varchar(64) | NO | The description of the wait event. |
| TOTAL_WAITS | bigint(20) | NO | The total number of wait events. |
| TOTAL_TIMEOUTS | bigint(20) | NO | The total number of wait event timeouts. |
| TIME_WAITED | double | NO | The total wait time of the wait event, in hundredths of a second. |
| AVERAGE_WAIT | double | NO | The average wait time of the wait event, in hundredths of a second. |
| MAX_WAIT | double | NO | The maximum wait time of the wait event, in hundredths of a second. |
| TIME_WAITED_MICRO | bigint(20) | NO | The total wait time of the wait event, in microseconds.  |
| CPU | null | NO | An invalid column. |
| EVENT_ID | bigint(20) | NO | The ID of the wait event. |
| WAIT_CLASS_ID | bigint(20) | NO | The ID of the wait event type. |
| WAIT_CLASS# | bigint(20) | NO | The index of the wait event type. |
| WAIT_CLASS | varchar(64) | NO | The name of the wait event type. |

## Sample query

In the sys tenant, query all `sql`-related session-level wait events for all tenants on the current node and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSION_EVENT WHERE EVENT LIKE '%sql%' LIMIT 10;
```
