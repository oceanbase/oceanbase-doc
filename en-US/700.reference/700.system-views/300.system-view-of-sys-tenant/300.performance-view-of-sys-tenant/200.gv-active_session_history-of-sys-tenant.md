# GV$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>This view was renamed to <a href="800.gv-ob_active_session_history-of-sys-tenant.md">GV$OB_ACTIVE_SESSION_HISTORY</a> starting with V4.2.2. </li>
  <li>This view is available starting with V4.0.0. </li></ul>
</main>

## Purpose

The `GV$ACTIVE_SESSION_HISTORY` view displays the active session history of all OBServer nodes across all tenants.
