# GV$OB_ARBITRATION_SERVICE_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the communication status between nodes and the arbitration service in the cluster.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the node. |
| SVR_PORT | bigint(20) | NO | The RPC port of the node. |
| ARBITRATION_SERVICE_ADDRESS | varchar(512) | NO | The address of the arbitration service. |
| STATUS | varchar(46) | NO | The communication status between the node and the arbitration service. Valid values: <ul><li>  `ACTIVE`: indicates that the arbitration service is communicating with the node. </li><li> `INACTIVE`: indicates that the arbitration service is not communicating with the node. </li></ul>|

## Sample query

Query the communication status between nodes and the arbitration service in the cluster.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.GV$OB_ARBITRATION_SERVICE_STATUS;
```

The query result is as follows:

```shell
+----------------+----------+-----------------------------+--------+
| SVR_IP         | SVR_PORT | ARBITRATION_SERVICE_ADDRESS | STATUS |
+----------------+----------+-----------------------------+--------+
| xxx.xx.xxx.207 |     2882 | xxx.xx.xxx.224:2882         | ACTIVE |
| xxx.xx.xxx.218 |     2882 | xxx.xx.xxx.224:2882         | ACTIVE |
+----------------+----------+-----------------------------+--------+
2 rows in set
```
