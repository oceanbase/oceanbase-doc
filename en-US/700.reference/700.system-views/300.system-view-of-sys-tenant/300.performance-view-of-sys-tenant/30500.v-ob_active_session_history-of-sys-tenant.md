# V$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.5 for V4.3.x. </li> <li>This view is available starting with V4.2.2 for V4.2.x. </li></ul>
</main>

## Purpose

The `V$OB_ACTIVE_SESSION_HISTORY` view displays the active session history of the current OBServer node for all tenants.

## Columns
