# V$OB_LS_LOG_RESTORE_STATUS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.2.0. </p>
</main>

## Purpose

This view displays the restore status of log streams at the user tenant level.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | The tenant ID. |
| LS_ID | bigint(20) | NO | The log stream ID. |
| SYNC_LSN | bigint(20) unsigned | NO | The LSN of the maximum continuous majority in the standby database, or the maximum consumable LSN. |
| SYNC_SCN | bigint(20) unsigned | NO | The SCN of the maximum continuous majority in the standby database, or the maximum consumable SCN. |
| SYNC_STATUS | varchar(128) | NO | The restore status of the log stream. Valid values: <ul><li>NORMAL: Normal synchronization is in progress.  </li><li>SOURCE HAS A GAP: The log source has a gap. </li><li>STANDBY LOG NOT MATCH: The restore log conflicts with the standby database. The logs with the same LSN are different between the standby database and the log source.  </li><li>CHECK USER OR PASSWORD: The username or password of the replication account is incorrect. The log source cannot be accessed.  </li><li>CHECK NETWORK: The log source is unreachable. This may be caused by an incorrect tenant access IP address or port.  </li><li>FETCH LOG TIMEOUT: The log fetch operation times out.  </li><li>RESTORE SUSPEND: The log restore has reached the maximum synchronization LSN.  </li><li>STANDBY NEED UPGRADE: The standby database version is earlier than the primary database version. The standby database needs to be upgraded.  </li><li>CHECK PRIMARY ALIVE: The primary database cannot be accessed. Check whether the primary database has been deleted.  </li><li> NOT AVAILABLE: The log synchronization is unavailable for other reasons. </li></ul>|
| ERR_CODE | bigint(20) | NO | The error code. 0 indicates normal synchronization. |
| COMMENT | varchar(2048) | NO | The error details. This column is empty during normal synchronization. |

## Sample query

Query the restore status of log streams at the user tenant level in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_LS_LOG_RESTORE_STATUS;
```
