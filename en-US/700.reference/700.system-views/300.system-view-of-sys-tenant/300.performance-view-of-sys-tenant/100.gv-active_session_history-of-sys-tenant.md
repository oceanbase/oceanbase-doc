# GV$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>For V4.3.x, this view was renamed to <a href="400.gv-ob_active_session_history-of-sys-tenant.md">GV$OB_ACTIVE_SESSION_HISTORY</a> starting with V4.3.5. For V4.2.x, this view was renamed to <a href="400.gv-ob_active_session_history-of-sys-tenant.md">GV$OB_ACTIVE_SESSION_HISTORY</a> starting with V4.2.2. </li>
  <li>This view is available starting with V4.0.0. </li></ul>
</main>

## Purpose

The `GV$ACTIVE_SESSION_HISTORY` view displays the active session history of all OBServer nodes in all tenants.
