# GV$SESSTAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V1.4. </p>
</main>

## Purpose

This view displays session-level statistics for all tenants across all OBServer nodes. The `STATISTIC#` column indicates the statistic index, which can be mapped to the corresponding statistic name and description using the `V$STATNAME` view.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | For V4.2.x: <ul><li> V4.2.5 BP4 and earlier: <br> This field represents the server session ID in all connection modes (direct mode and ODP mode). </li><li> V4.2.5 BP4 and later: <ul><li> In direct mode: <br> This field represents the server session ID. </li> <li> In ODP mode: </li><ul><li> If the ODP parameter <code>client_session_id_version = 2</code>, this field represents the client session ID. </li> <li> If <code>client_session_id_version = 1</code>, this field represents the server session ID. </li></ul></ul></li></ul> |
| CON_ID | bigint(20) | NO | The tenant ID. |
| SVR_IP | varchar(46) | NO | The IP address of the server where the information is stored. |
| SVR_PORT | bigint(20) | NO | The port number of the server where the information is stored. |
| STATISTICS# | bigint(20) | NO | The index of the statistic. |
| VALUE | bigint(20) | NO | The number of times the statistic has occurred. |

## Sample query

Query the session-level statistics for tenant 1002 across all OBServer nodes in the sys tenant, and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSTAT WHERE CON_ID=1002 LIMIT 10;
```
