# V$OB_TENANT_RESOURCE_LIMIT

<main id="notice" type='explain'>
<h4>Note</h4>
<ul><li>This view is available starting with V4.3.1 in V4.3.x. </li>
<li>This view is available starting with V4.2.4 in V4.2.x. </li></ul>
</main>

## Purpose

The `V$OB_TENANT_RESOURCE_LIMIT` view displays the logical resource usage, upper limits, effective restrictions, and maximum usage after a reboot for all tenants on the current OBServer.

## Columns

| Column | Type | Nullable | Description |
|----------|--------|-----------------|-------------|
| SVR_IP               | varchar(46)  | NO   |  The IP address of the OBServer.    |
| SVR_PORT             | bigint(20)   | NO   |  The RPC port of the OBServer.    |
| TENANT_ID            | bigint(20)   | NO   |  The tenant ID.    |
| ZONE                 | varchar(128) | NO   |  The name of the zone.    |
| RESOURCE_NAME        | varchar(128) | NO   |  The name of the resource.    |
| CURRENT_UTILIZATION  | bigint(20)   | NO   |  The current usage of the resource.    |
| MAX_UTILIZATION      | bigint(20)   | NO   |  The maximum usage of the resource since the last boot.    |
| RESERVED_VALUE       | bigint(20)   | NO   |  The amount pre-allocated to ensure stable operation.    |
| LIMIT_VALUE          | bigint(20)   | NO   |  The maximum allowed usage.    |
| EFFECTIVE_LIMIT_TYPE | varchar(128) | NO   |  The type of the effective restriction, such as: configuration parameter, memory, CPU, or disk.    |

## Sample query

Query the logical resource usage, upper limits, effective restrictions, and maximum usage after a reboot for all tenants on the current OBServer.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_RESOURCE_LIMIT;
```
