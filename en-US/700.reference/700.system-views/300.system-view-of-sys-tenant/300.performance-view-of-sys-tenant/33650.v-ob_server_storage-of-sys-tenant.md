# V$OB_SERVER_STORAGE

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.3.4. </p>
</main>

## Purpose

This view displays information about the object storage of the shared storage cluster configured on the current OBServer node.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is applicable only to the Shared-Storage (SS) mode. In the Shared-Nothing (SN) mode, the query result of this view is empty. </p>
</main>

## Columns

| Column              | Type          | Nullable | Description                          |
|----------------------|---------------|----------------|-------------------------------|
| SVR_IP               | varchar(46)   | NO   | The IP address of the OBServer node.    |
| SVR_PORT             | bigint(20)    | NO   | The port number of the OBServer node.     |
| PATH                 | varchar(1024) | NO   | The root path of the object storage. The path is usually in the format of `oss://` or `s3://`.     |
| ENDPOINT             | varchar(1024) | NO   | The endpoint of the object storage.     |
| USED_FOR             | varchar(256)  | NO   | The user of the object storage. Currently, only `ALL` is supported, which indicates that the object storage is used for clog and data.    |
| ZONE                 | varchar(128)  | NO   | The zone name.    |
| STORAGE_ID           | bigint(20)    | NO   | The ID of the object storage path. The same path has the same STORAGE_ID.     |
| MAX_IOPS             | bigint(20)    | NO   | The maximum IOPS of the object storage.      |
| MAX_BANDWIDTH        | bigint(20)    | NO   | The maximum bandwidth of the object storage, in bytes.     |
| CREATE_TIME          | timestamp(6)  | NO   | The creation time of the object storage.     |
| AUTHORIZATION        | varchar(1024) | NO   | The authorization information of the object storage.     |
| STATE                | varchar(256)  | NO   | The state of the object storage:<ul><li>`ADDING`: The object storage is being added. </li> <li>`ADDED`: The object storage has been added successfully.</li> <li>`DROPPING`: The object storage is being dropped.</li> <li>`ROTATING`: The AK/SK is being rotated.</li> <li>`ROTATED`: The AK/SK rotation is completed.</li></ul>      |
| STATE_INFO           | varchar(1024) | NO   | The state information of the object storage.     |
| LAST_CHECK_TIMESTAMP | timestamp(6)  | NO   | The last check time.     |
| EXTENSION            | varchar(4096) | NO   | Other information about the object storage.     |
