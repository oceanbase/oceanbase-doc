# GV$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is introduced in OceanBase Database V4.0.0. </p>
</main>

## Description

Displays the memory usage of all tenants on all nodes in the cluster.

## Fields

|   Field    |     Type      | Nullable |   Description    |
|-----------|-------------|------------|---------|
| TENANT_ID | bigint(20)  | NO         | Tenant ID   |
| SVR_IP    | varchar(46) | NO         | IP address of the server   |
| SVR_PORT  | bigint(20)  | NO         | Port number of the server   |
| HOLD      | bigint(20)  | NO         | Memory used by the tenant, in bytes |
| FREE      | bigint(21)  | NO         | Free memory of the tenant, in bytes  |

## Examples

Query the memory usage of tenant 1002 on all nodes in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_MEMORY WHERE TENANT_ID = 1002;
```

The query result is as follows:

```shell
+-----------+----------------+----------+------------+------------+
| TENANT_ID | SVR_IP         | SVR_PORT | HOLD       | FREE       |

|      1002 | 172.xx.xxx.xxx |     2882 |  718929920 | 4649779200 |
|      1002 | 172.xx.xxx.xxx |     2882 | 1165156352 | 4203552768 |
|      1002 | 172.xx.xxx.xxx |     2882 |  714735616 | 4653973504 |
+-----------+----------------+----------+------------+------------+
3 rows in set
```
