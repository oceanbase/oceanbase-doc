# GV$SYSSTAT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is introduced since OceanBase Database V1.4. </p>
</main>

## Purpose

Displays tenant-level statistics information on all servers.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>To query this view, you must enable monitoring by setting the <code>enable_perf_event</code> parameter to True. </p>
</main>

## Columns

| **Column** | **Type** | **Nullable?** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP address of the server where the information resides |
| SVR_PORT | bigint(20) | NO | Port number of the server where the information resides |
| STATISTIC# | bigint(20) | NO | Index of the statistics |
| NAME | varchar(64) | NO | Name of the statistics |
| CLASS | bigint(20) | NO | Type of the statistics |
| VALUE | bigint(20) | NO | Result value of the statistics |
| VALUE_TYPE | varchar(16) | NO | Statistics value type:<li>ADD: accumulated<li>SET: updated |
| STAT_ID | bigint(20) | NO | ID of the statistics |
