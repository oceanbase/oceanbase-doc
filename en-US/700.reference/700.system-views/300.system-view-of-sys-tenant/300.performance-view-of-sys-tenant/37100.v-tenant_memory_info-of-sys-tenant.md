# V$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.0.0. </p>
</main>

## Overview

Displays the memory usage of each tenant on the current OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------- | ------------- | ------------ | ----------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| HOLD | bigint(20) | NO | Tenant Used Memory, in bytes |
| FREE | bigint(21) | NO | Remaining memory of the tenant, in bytes |

## Sample query

Query the memory usage of the tenant with ID 1002 on the current node in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_MEMORY WHERE TENANT_ID = 1002;
```

The query result is as follows:

```shell
+-----------+----------------+----------+-----------+------------+
| TENANT_ID | SVR_IP         | SVR_PORT | HOLD      | FREE       |
+-----------+----------------+----------+-----------+------------+
|      1002 | 172.xx.xxx.xxx |     2882 | 723124224 | 4645584896 |
+-----------+----------------+----------+-----------+------------+
1 row in set
```
