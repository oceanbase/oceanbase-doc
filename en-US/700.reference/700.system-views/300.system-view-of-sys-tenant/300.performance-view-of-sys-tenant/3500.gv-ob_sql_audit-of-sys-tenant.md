# GV$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view is available starting with V4.0.0. </p>
</main>

## Purpose

The `GV$OB_SQL_AUDIT` view displays statistics such as the source and execution status of each SQL request on all OBServer nodes. This view is tenant-separated. The system tenant can query the view, but other tenants cannot cross-tenant query it.
