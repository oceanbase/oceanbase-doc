# GV$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Introduced in MySQL 4.0.0. </p>
</main>

## Description

The `GV$OB_SQL_AUDIT` view displays the source and execution status of each SQL request on all OBServer nodes. This view is tenant-splitted. Tenants other than the sys tenant cannot perform cross-tenant queries.
