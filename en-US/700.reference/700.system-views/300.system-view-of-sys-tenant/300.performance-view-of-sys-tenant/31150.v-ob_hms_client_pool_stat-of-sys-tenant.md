# V$OB_HMS_CLIENT_POOL_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.4.1. </p>
</main>

## Purpose

This view displays the usage of HMS Catalog clients for all tenants.

## Columns

|     Column    |     Type    | Nullable |      Description      |
|----------------|-------------|----------------|----------------|
| SVR_IP         | varchar(46) | NO             | The IP address of the node where the replica resides.|
| SVR_PORT       | bigint(20)  | NO             | The port of the node where the replica resides.|
| TENANT_ID      | bigint(20)  | NO             | The ID of the tenant. Valid values: <ul><li>1: the ID of the sys tenant. </li><li>Other values: the ID of a user tenant or a meta tenant.</li></ul>|
| CATALOG_ID     | bigint(20)  | NO             | The ID of a catalog in the current tenant.|
| TOTAL_CLIENTS  | bigint(20)  | NO             | The total number of clients created for the catalog in the current tenant.|
| IN_USE_CLIENTS | bigint(20)  | NO             | The number of clients currently in use for the catalog in the current tenant.|
| IDLE_CLIENTS   | bigint(20)  | NO             | The number of clients not in use (idle) for the catalog in the current tenant.|

## Sample query

Query the usage of HMS Catalog clients for all tenants in the sys tenant.

```shell
obclient> SELECT * FROM oceanbase.V$OB_HMS_CLIENT_POOL_STAT;
```
