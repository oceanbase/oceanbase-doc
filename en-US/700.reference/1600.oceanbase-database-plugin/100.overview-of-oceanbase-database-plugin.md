# Overview

Starting from OceanBase Database V4.3.5 BP1, OceanBase has introduced the plugin mechanism as a lightweight, flexible, and efficient way to expand database features. With the plugin mechanism, users can customize and enhance OceanBase Database to suit their specific needs.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p><ul><li>The plugin mechanism is supported in OceanBase Database V4.3.5 starting from V4.3.5 BP1. </li><li>The plugin mechanism is currently an experimental feature. It is not recommended for production environments. </li></ul></p>
</main>

## How to develop and use plugins

OceanBase Database allows you to develop plugins using C/C++, and provides a complete plugin development kit (PDK). If your development environment has installed the C/C++ development toolchain and configured the OceanBase PDK, you can get started with plugin development.

## Scenarios

The OceanBase plugin mechanism supports the following scenarios at present:

* Tokenizer plugins: These plugins are used to expand the full-text search capability of the database and allow users to customize their own tokenization logic to meet diverse text processing requirements.
