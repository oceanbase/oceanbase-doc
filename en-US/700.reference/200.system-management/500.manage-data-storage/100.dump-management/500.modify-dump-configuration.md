# Modify minor compaction parameters

This topic describes how to modify minor compaction parameters.

## Minor compaction parameters

|             Parameter             |                          Description                           | Default value |     Value range     |
|-----------------------------|-------------------------------------------------------|-----|--------------|
| minor_compact_trigger       | The threshold for the number of SSTables at the tenant level. A minor compaction is triggered when the threshold is reached.       | 2   | \[0, 16\]    |
| freeze_trigger_percentage   | The threshold for the memory usage of MemStores as a percentage of the tenant memory at the tenant level. A freeze is triggered when the threshold is reached.                | 20  | (0, 100)    |
| memstore_limit_percentage   | Cluster-level configuration item, the percentage of tenant MemStore occupying the total memory of the tenant. <main id="notice" type='explain'><h4>Note</h4><p>Starting from version V4.3.0 in the V4.3.x series, it also supports configuring the percentage of tenant MemStore occupying the total memory of the tenant through the tenant-level hidden configuration item <code>_memstore_limit_percentage</code>. Except for the different effective scopes, its function and default value are the same as the cluster-level configuration item <code>memstore_limit_percentage</code>. When configuring these two configuration items, note the following:</p><ul><li>If only one of the values of <code>_memstore_limit_percentage</code> or <code>memstore_limit_percentage</code> is configured (non-default value), the configured value (non-default value) shall prevail.</li> <li>If both the tenant-level hidden configuration item <code>_memstore_limit_percentage</code> (non-default value) and the cluster-level configuration item <code>memstore_limit_percentage</code> (non-default value) are configured simultaneously, the value configured by <code>_memstore_limit_percentage</code> shall prevail.</li> <li>If neither is configured, or both are set to the default value, the system will adopt the following adaptive strategy:<ul><li>For tenants with 8G (actual Memory) or lower specifications, the configuration ratio of tenant Memstore is 40%.</li><li>For tenants with specifications above 8G, the configuration ratio of tenant Memstore is 50%.</li></ul></li></ul></main>   | 0  | [0, 100)   |

## Modify minor compaction parameters by using an SQL statement

1. Log in to the database as the tenant administrator.

2. Execute the following statements to modify the minor compaction parameters.

   Here is an example:

   ```sql
   obclient> ALTER SYSTEM SET minor_compact_trigger=2;

   obclient> ALTER SYSTEM SET freeze_trigger_percentage=20;

   obclient> ALTER SYSTEM SET memstore_limit_percentage=50;
   ```

3. After the parameters are modified, you can execute the `SHOW PARAMETERS` statement to verify whether the modification is successful.

   Here is an example:

   ```sql
    obclient> SHOW PARAMETERS LIKE 'minor_compact_trigger';

   obclient> SHOW PARAMETERS LIKE 'freeze_trigger_percentage';

   obclient> SHOW PARAMETERS LIKE 'memstore_limit_percentage';
   ```
