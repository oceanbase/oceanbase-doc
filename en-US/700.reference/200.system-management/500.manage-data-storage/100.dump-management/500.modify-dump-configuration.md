# Modify major compaction parameters

This topic describes how to modify major compaction parameters.

## Major compaction parameters

|             Parameter             |                          Description                           | Default value |     Value range     |
|-----------------------------|-------------------------------------------------------|-----|--------------|
| minor_compact_trigger       | The threshold of the number of SSTables at the tenant level. A major compaction is triggered when the threshold is reached.      | 2   | \[0, 16\]    |
| freeze_trigger_percentage   | The threshold of the percentage of memory occupied by tenant MemStores. A freeze is triggered when the threshold is reached.                | 20  | (0, 100)    |
| memstore_limit_percentage   | The threshold of the percentage of total memory occupied by tenant MemStores. <main id="notice" type='explain'><h4>Note</h4><p>In V4.3.x, the <code>_memstore_limit_percentage</code> tenant-level hidden parameter is supported from V4.3.0. It specifies the threshold of the percentage of total memory occupied by tenant MemStores. The functionality and default value of this parameter are the same as those of the cluster-level parameter <code>memstore_limit_percentage</code>, but the effective range is different. When you set both parameters, note the following points:</p><ul><li>If the value (non-default value) of <code>_memstore_limit_percentage</code> or <code>memstore_limit_percentage</code> is set, the value of the set parameter takes effect. </li> <li>If both <code>_memstore_limit_percentage</code> (non-default value) and <code>memstore_limit_percentage</code> (non-default value) are set, the value of <code>_memstore_limit_percentage</code> takes effect. </li> <li>If both parameters are not set, or are set to default values, the system adopts an adaptive strategy based on the memory size of the tenant. Specifically:</li></ul><ul><li>If the memory size is 8 GB (inclusive) or smaller, the percentage of MemStores is 40%. </li><li>If the memory size is larger than 8 GB, the percentage of MemStores is 50%. </li></ul></main>   | 0  | [0, 100)   |

## Modify major compaction parameters using an SQL statement

1. Log in to the database as the tenant administrator.

2. Execute the following statements to modify the major compaction parameters.

   Here is an example:

   ```sql
   obclient> ALTER SYSTEM SET minor_compact_trigger=2;

   obclient> ALTER SYSTEM SET freeze_trigger_percentage=20;

   obclient> ALTER SYSTEM SET memstore_limit_percentage=50;
   ```

3. After the parameters are modified, you can execute the `SHOW PARAMETERS` statement to verify whether the modifications are successful.

   Here is an example:

   ```sql
    obclient> SHOW PARAMETERS LIKE 'minor_compact_trigger';

   obclient> SHOW PARAMETERS LIKE 'freeze_trigger_percentage';

   obclient> SHOW PARAMETERS LIKE 'memstore_limit_percentage';
   ```
