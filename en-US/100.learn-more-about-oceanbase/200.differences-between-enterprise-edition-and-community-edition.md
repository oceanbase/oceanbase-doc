# Feature differences between the Enterprise Edition and Community Edition

OceanBase Database provides the Enterprise Edition and the Community Edition.

* OceanBase Database Enterprise Edition: OceanBase Database Enterprise Edition is a fully self-developed enterprise-level native distributed database that achieves financial-grade high availability on ordinary hardware. It sets a new standard for automatic lossless disaster recovery across five IDCs in three regions, and sets a new benchmark in TPC-C benchmark tests with a single cluster scale exceeding 1,500 nodes. It is cloud-native, highly consistent, and highly compatible with Oracle and MySQL.

* OceanBase Database Community Edition: OceanBase Database Community Edition is a single-machine distributed integrated database that is compatible with MySQL. It has a native distributed architecture and supports financial-grade high availability, transparent horizontal scaling, distributed transactions, multi-tenancy, and syntax compatibility. The OceanBase Database Community Edition kernel is open source and compatible with MySQL. It can be integrated with virtualization and big data technologies and products. It supports various graphical development, O&M, and data migration tools. The Community Edition also provides open interfaces and a rich ecosystem to help enterprises and individuals better meet their customized business needs.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>In this topic, a distributed transaction refers to a transaction within an OceanBase cluster. The data accessed by the transaction involves multiple participants but is limited to a single tenant. The XA protocol can ensure the atomicity of cross-database transaction commits. When an application's global transaction accesses data from multiple databases, the distributed transaction manager (an external service independent of OceanBase Database) can use the XA transaction interface to ensure the atomicity of the global transaction commit. This global transaction is also known as an XA transaction. </p>
