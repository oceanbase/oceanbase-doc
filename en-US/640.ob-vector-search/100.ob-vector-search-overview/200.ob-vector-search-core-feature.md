# Core features of vector search

OceanBase provides the ability to store, index, and search Embedding vector data. The main capabilities are:

| **Core feature** | **Description** |
|---|---|
| Vector data types | <ul><li>Dense float vectors with up to 16,000 dimensions.</li><li>Sparse vector storage.</li></ul> |
| Vector index | <ul><li>Exact search and approximate nearest neighbor (ANN) search.</li><li>L2 distance, inner product, and cosine similarity.</li><li>HNSW, HNSW_SQ, and HNSW_BQ indexes; maximum dimension 4096. HNSW_BQ is supported from V4.4.0.</li><li>IVF and IVF_PQ indexes; maximum dimension 4096.</li></ul> |
| Vector search SQL operators | Addition, subtraction, multiplication, comparison, aggregation, and other basic vector operators. |
| Vector hybrid search | <ul><li>Hybrid search over full-text index and vector index.</li><li>Hybrid search over vector data and scalar data.</li></ul> |

## Limitations and considerations

* OceanBase uses NULLS FIRST by default, so NULL values are sorted first. We recommend adding a `NOT NULL` condition in your queries.
