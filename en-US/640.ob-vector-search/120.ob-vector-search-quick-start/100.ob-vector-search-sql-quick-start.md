# Perform a vector search by using an SQL statement

OceanBase Database allows you to perform a vector search by using an SQL statement. This topic describes how to do so.

## Considerations

* At present, vector search is an experimental feature.

* Vector search is supported only in MySQL mode.

## Quick start

### Enable vector search

```sql
ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
```

You need to specify the value of the `ob_vector_memory_limit_percentage` parameter based on the memory usage. For more information, see [ob_vector_memory_limit_percentage](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/6150.ob_vector_memory_limit_percentage.md).

### Create a vector column and a vector index

Create a vector column named `c2` and set the dimensionality of vector data to `3`. To create a vector index, you must specify at least the `type` and `distance` parameters.

```sql
CREATE TABLE t1(
    c1 INT, 
    c2 VECTOR(3), 
    PRIMARY KEY(c1), 
    VECTOR INDEX idx1(c2) WITH (distance=L2, type=hnsw)
    );
```

### Write vector data

```sql
INSERT INTO t1 VALUES(1, '[0.203846, 0.205289, 0.880265]');
INSERT INTO t1 VALUES(2, '[0.735541, 0.670776, 0.903237]');
INSERT INTO t1 VALUES(3, '[0.327936, 0.048756, 0.084670]');
```

### Perform a vector search

Here is an example of using approximate nearest neighbor search (ANNS).

```sql
SELECT * FROM t1 ORDER BY l2_distance(c2, [0.712338, 0.603321, 0.133444]) APPROXIMATE LIMIT 1;
```
