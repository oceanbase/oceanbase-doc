# Vector data type

OceanBase Database provides the vector data type for applications that use AI-powered vector search. With the vector data type, you can store and query a floating-point array, for example, `[0.1, 0.3, -0.9, ...]`. When you use vector data, take note of the following considerations:

* The data elements supported by the vector data type are single-precision floating-point numbers.

* Element values in vector data must not be `NaN` or `Inf`. Otherwise, a runtime error will be thrown.

* A vector dimensionality must be specified when you create a vector column. For example, you can specify `VECTOR(3)`.

* Vector indexes can be created on vector columns. For more information, see [Vector indexes](300.ob-vector-index.md).

* In OceanBase Database, vector data is stored as arrays.

## Syntax

A vector value contains any number of floating-point numbers. The syntax is as follows:

```sql
'[<float>, <float>, ...]'
```

Here is an example of creating an index on a vector column:

```sql
CREATE TABLE t1(
    c1 INT, 
    c2 VECTOR(3), 
    PRIMARY KEY(c1), 
    VECTOR INDEX idx1(c2) WITH (distance=L2, type=hnsw)
    );
```
