# Overview of vector data types

OceanBase Database provides vector data types to support AI vector search applications. You can store and query a floating-point array, for example, `[0.1, 0.3, -0.9, ...]`. Before you use vector data types, you must be aware of the following information:

* Dense and sparse vectors are supported. The elements in the vectors are single-precision floating-point numbers.

* The values of the elements in the vectors cannot be NaN or Inf. Otherwise, a runtime error is thrown.

* When you create a vector column, you must specify the vector dimension, for example, `VECTOR(3)`.

* Dense and memory-based sparse indexes (hereinafter referred to as memory sparse indexes) are supported. For more information, see [Vector indexes](../200.ob-vector-index/200.ob-vector-index.md).

* Vector data in OceanBase Database is stored in arrays.

* Both dense and sparse vectors support [hybrid search](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002325135#92-title-混合搜索（Active%20Transaction）).

## Syntax

A dense vector value can contain any number of floating-point numbers up to 16,000. The syntax is as follows:

```sql
-- Dense vector
'[<float>, <float>, ...]'
```

A sparse vector is based on the MAP data type and contains unordered key-value pairs. The syntax is as follows:

```sql
-- Sparse vector
'{<uint:float>, <uint:float>...}'
```

Here are examples of creating vector columns and indexes:

```sql
-- Create a dense vector column and index
CREATE TABLE t1(
    c1 INT,
    c2 VECTOR(3),
    PRIMARY KEY(c1),
    VECTOR INDEX idx1(c2) WITH (distance=L2, type=hnsw)
    );
```

```sql
-- Create a sparse vector column and memory sparse index
CREATE TABLE t2 (
    c1 INT,
    c2 SPARSEVECTOR
    VECTOR INDEX idx2(c2) WITH (distance=inner_product, type=sindi)
    );
```
