# Vector functions

This topic describes the vector functions supported by OceanBase Database and the considerations in using the functions.

## Considerations

* You cannot execute the functions mentioned in this topic on vector data with different dimensionalities. Otherwise, the following error will be returned: `different vector dimensions %d and %d`.

* When the result of a function exceeds the floating-point value range, the following error will be returned: `value out of range: overflow / underflow`.

## Distance functions

A distance function calculates the distance between two vectors. The calculation method varies based on the distance algorithm.

### l2_distance

The L2 distance, also known as the Euclidean distance, is a measure of the distance between the coordinates of two compared vectors, which is basically the straight-line distance between the two vectors. The Pythagorean theorem is applied to the vector coordinates to calculate the distance.

```sql
[ D = \sqrt{\sum_{i=1}^{n} (x_{2,i} - x_{1,i})^2} ]
```

The syntax is as follows:

```sql
l2_distance(vector v1, vector v2)
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t1(c1 vector(3));
SELECT l2_distance(c1, [1,2,3]), l2_distance([1,2,3],[1,1,1]), l2_distance('[1,1,1]','[1,2,3]') FROM t1;
```

### l1_distance

The L1 distance, also known as the Manhattan distance, is a measure of the absolute distance between two points in a standard coordinate system. The formula for calculating the Manhattan distance is as follows: `$[ D = \sum_{i=1}^{n} |x_{1,i} - x_{2,i}| ]$`.

The syntax is as follows:

```sql
l1_distance(vector v1, vector v2)
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t2(c1 vector(3));
SELECT l1_distance(c1, [1,2,3]) FROM t2;
```

### cosine_distance

Cosine similarity is a measure of the angular difference between two vectors. It reflects the similarity of the two vectors in direction and has nothing to do with the lengths (magnitudes) of the vectors. The value range of cosine similarity is `[-1, 1]`, where `1` indicates that the two vectors are in the same direction, `0` indicates that they are orthogonal, and `-1` indicates that they are in opposite directions.

The formula for calculating the cosine similarity is as follows:

```sql
[ \text{Cosine Similarity} = \frac{\mathbf{A} \cdot \mathbf{B}}{|\mathbf{A}| |\mathbf{B}|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}} ]
```

The closer to 1 the cosine similarity is, the more similar the vectors are. Therefore, the cosine distance (or cosine dissimilarity) is sometimes used as a measure of the distance between vectors. The cosine distance can be calculated by subtracting the cosine similarity from 1.

```sql
[ \text{Cosine Distance} = 1 - \text{Cosine Similarity} ]
```

The value range of the cosine distance is `[0, 2]`, where `0` indicates that the vectors are in the same direction (without distance), and `2` indicates that they are in opposite directions.

The syntax is as follows:

```sql
cosine_distance(vector v1, vector v2)
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t3(c1 vector(3));
SELECT cosine_distance(c1, [1,2,3]) FROM t3;
```

### inner_product

The inner product, also known as the dot product or scalar product, is the product of two vectors. In a geometric sense, the inner product represents the direction and magnitude relationships between two vectors. The formula for calculating the inner product is as follows:

```sql
[ \mathbf{A} \cdot \mathbf{B} = a_1 b_1 + a_2 b_2 + ... + a_n b_n = \sum_{i=1}^{n} a_i b_i ]
```

The syntax is as follows:

```sql
inner_product(vector v1, vector v2)
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t4(c1 vector(3));
SELECT inner_product(c1, [1,2,3]) FROM t4;
```

### vector_distance

`vector_distance` calculates the distance between two vectors. You can specify a distance algorithm.

The syntax is as follows:

```sql
vector_distance(vector v1, vector v2 [, string metric])
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The `metric` parameter specifies the distance algorithm and is optional.

* If you do not specify this parameter, the default algorithm `euclidean` is used.

* Valid values are as follows:

  * `euclidean`: specifies to calculate the Euclidean distance, which means the same as `L2_distance`.

  * `manhattan`: specifies to calculate the Manhattan distance, which means the same as `L1_distance`.

  * `cosine`: specifies to calculate the cosine distance, which means the same as `Cosine_distance`.

  * `dot`: specifies to calculate the dot product, which means the same as `Inner_product`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t5(c1 vector(3));
SELECT vector_distance(c1, [1,2,3], euclidean) FROM t5;
```

## Arithmetic functions

Arithmetic functions perform arithmetic calculations such as addition (+), subtraction (-), and multiplication (*) between a vector and another vector, a flat array, or a special string, or between a flat array and another flat array or a special string. The calculation method is element-by-element calculation. Here is an example of addition:

```sql
[x_1,x_2,...,x_n]+[y_1,y_2,...,y_n]=[x_1+y_1,x_2+y_2,...,x_n+y_n]
```

The syntax is as follows:

```sql
v1 + v2
v1 - v2
v1 * v2
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`. **Notice:** The two parameters cannot both be of the string type. At least one of them must be of the vector or flat array type.

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* If at least one of the two parameters is of the vector type, the return value is of the vector type.

* If both parameters are of the flat array type, the return value is of the `array(float)` type.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t6(c1 vector(3));
SELECT [1,2,3] + '[1.12,1000.0001, -1.2222]', c1 - [1,2,3] FROM t6;
```

## Comparison functions

Comparison functions perform comparison calculations between a vector and another vector, a flat array, or a special string. The following comparison operations are supported: `=`, `!=`, `>`, `<`, `>=`, and `<=`. The calculation method is lexicographic comparison of each element.

The syntax is as follows:

```sql
v1 = v2
v1 != v2
v1 > v2
v1 < v2
v1 >= v2
v1 <= v2
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>At least one of the two parameters must be of a vector type. </p>
  </main>

* The dimensionality of the two parameters must be the same.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is of the Boolean type.

* If the value of either parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t7(c1 vector(3));
SELECT c1 = '[1,2,3]' FROM t7;
```

### sum

The `sum` function calculates the sum of a vector column in a table. It uses element-by-element accumulation to obtain the vector sum.

The syntax is as follows:

```sql
sum(vector v1)
```

The parameters are described as follows:

* Only the vector type is supported.

The return value is described as follows:

* A `sum (vector)` value is returned.

* `NULL` values in a column are excluded from the calculation.

Here is an example:

```sql
CREATE TABLE t8(c1 vector(3));
SELECT sum(c1) FROM t8;
```

### avg

The `avg` function calculates the average value of a vector column in a table.

The syntax is as follows:

```sql
 avg(vector v1)
```

The parameters are described as follows:

* Only the vector type is supported.

The return value is described as follows:

* An `avg (vector)` value is returned.

* `NULL` values in a column are excluded from the summation and counting processes.

* If the input is empty, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t9(c1 vector(3));
SELECT avg(c1) FROM t9;
```

## Other common vector functions

### vector_norm

`vector_norm` calculates the Euclidean norm (magnitude) of a vector, which represents the Euclidean distance between the vector and the origin. The formula is as follows:

```sql
[ D = \sqrt{\sum_{i=1}^{n} (x_i)^2} ]
```

The syntax is as follows:

```sql
vector_norm(vector v1)
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

* If a flat array is input as a parameter, the elements of this parameter cannot contain `NULL`.

The return value is described as follows:

* A `norm(double)` value is returned.

* If the value of the parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t10(c1 vector(3));
SELECT vector_norm(c1),vector_norm([1,2,3]) FROM t10;
```

### vector_dims

`vector_dims` returns the dimensionality of a vector.

The syntax is as follows:

```sql
vector_dims(vector v1)
```

The parameters are described as follows:

* In addition to the vector data type, data types that can be forcibly converted into the vector type are also supported, including flat arrays such as `[1,2,3,..]`, and the string type such as `'[1,2,3]'`.

The return value is described as follows:

* A `dims(int64)` dimensionality value is returned.

* If the value of the parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t11(c1 vector(3));
SELECT vector_dims(c1),vector_dims('[1,2,3]'),vector_dims([1,null,3]) FROM t11;
```
