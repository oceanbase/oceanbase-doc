# Vector functions

This topic describes the vector functions supported by OceanBase Database and provides usage notes.

## Considerations

* Vectors of different dimensions cannot be used in the following operations. Instead, an error of the type `different vector dimensions %d and %d` is returned.

* If the result of the operation is out of the floating-point value range, an error of the type `value out of range: overflow / underflow` is returned.

* The supported index distance algorithms are L2, inner product (IP), and cosine distance. For more information, see [Vector indexes](300.ob-vector-index.md).

## Prerequisites

Before you can use vector indexes, enable the vector feature by setting [ob_vector_memory_limit_percentage](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/6150.ob_vector_memory_limit_percentage.md).

```sql
ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
```

## Distance functions

A distance function calculates the distance between two vectors based on the specified distance algorithm.

### L2_distance

The Euclidean distance measures the distance between two vectors based on the sum of the squares of the differences between the coordinates of the two vectors. It is the length of the line segment connecting the two vectors. The formula is as follows:

$$
[ D = \sqrt{\sum_{i=1}^{n} (x_{2,i} - x_{1,i})^2} ]
$$

The function syntax is as follows:

```sql
l2_distance(vector v1, vector v2)
```

The parameters are described as follows:

* Apart from the vector type, a parameter of any other type that can be forcibly converted into a vector type, such as a one-dimensional array type (e.g., `[1,2,3,..]`) and a string type (e.g., `'[1,2,3]'`), is also accepted.

* The dimensions of the two parameters must be the same.

* If a one-dimensional array type is present among the parameters, `NULL` is not allowed in the elements of the parameter.

The return value is described as follows:

* The return value is the `distance(double)` value.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t1(c1 vector(3));
INSERT INTO t1 VALUES('[1,2,3]');
SELECT l2_distance(c1, [1,2,3]), l2_distance([1,2,3],[1,1,1]), l2_distance('[1,1,1]','[1,2,3]') FROM t1;
```

The return result is as follows:

```shell
+--------------------------+------------------------------+----------------------------------+
| l2_distance(c1, [1,2,3]) | l2_distance([1,2,3],[1,1,1]) | l2_distance('[1,1,1]','[1,2,3]') |
+--------------------------+------------------------------+----------------------------------+
|                        0 |             2.23606797749979 |                 2.23606797749979 |
+--------------------------+------------------------------+----------------------------------+
1 row in set
```

### L1_distance

The Manhattan distance measures the sum of the absolute differences of the coordinates of two points in a standard coordinate system. The formula is as follows:

$$
[ D = \sum_{i=1}^{n} |x_{1,i} - x_{2,i}| ]
$$

The function syntax is as follows:

```sql
l1_distance(vector v1, vector v2)
```

The parameters are described as follows:

* Apart from the vector type, a parameter of any other type that can be forcibly converted into a vector type, such as a one-dimensional array type (e.g., `[1,2,3,..]`) and a string type (e.g., `'[1,2,3]'`), is also accepted.

* The dimensions of the two parameters must be the same.

* If a one-dimensional array type is present among the parameters, `NULL` is not allowed in the elements of the parameter.

The return value is described as follows:

* The return value is the `distance(double)` value.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t2(c1 vector(3));
INSERT INTO t2 VALUES('[1,2,3]');
INSERT INTO t2 VALUES('[1,1,1]');
SELECT l1_distance(c1, [1,2,3]) FROM t2;
```

The return result is as follows:

```shell
+--------------------------+
| l1_distance(c1, [1,2,3]) |
+--------------------------+
|                        0 |
|                        3 |
+--------------------------+
2 rows in set
```

### Cosine_distance

The cosine similarity measures the angle between two vectors and reflects the direction similarity between the two vectors, which is independent of the size (magnitude) of the vectors. The value range of the cosine similarity is `[-1, 1]`, where `1` indicates that the two vectors have the same direction, `0` indicates that the two vectors are orthogonal, and `-1` indicates that the two vectors have opposite directions.

The cosine similarity can also be used to measure the distance between vectors. Since a higher cosine similarity indicates a higher degree of similarity, a lower cosine similarity indicates a greater distance between vectors. The cosine distance is calculated by subtracting the cosine similarity from 1:

$$
[ \text{Cosine Distance} = 1 - \text{Cosine Similarity} ]
$$

The value range of the cosine distance is `[0, 2]`, where `0` indicates that the two vectors have the same direction (no distance), and `2` indicates that the two vectors have opposite directions.

The formula for calculating the cosine similarity is as follows:
$$
[ \text{Cosine Similarity} = \frac{\mathbf{A} \cdot \mathbf{B}}{|\mathbf{A}| |\mathbf{B}|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}} ]

$$

The function syntax is as follows:

```sql
cosine_distance(vector v1, vector v2)
```

The parameters are described as follows:

* Apart from the vector type, a parameter of any other type that can be forcibly converted into a vector type, such as a one-dimensional array type (e.g., `[1,2,3,..]`) and a string type (e.g., `'[1,2,3]'`), is also accepted.

* The dimensions of the two parameters must be the same.

* If a one-dimensional array type is present among the parameters, `NULL` is not allowed in the elements of the parameter.

The return value is described as follows:

* The return value is the `distance(double)` value.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t3(c1 vector(3));
INSERT INTO t3 VALUES('[1,2,3]');
INSERT INTO t3 VALUES('[1,2,1]');
SELECT cosine_distance(c1, [1,2,3]) FROM t3;
```

```shell
+------------------------------+
| cosine_distance(c1, [1,2,3]) |
+------------------------------+
|                            0 |
|          0.12712843905603044 |
+------------------------------+
2 rows in set
```

### Inner_product

The inner product, also known as the dot product or scalar product, is a type of multiplication between two vectors. Geometrically, the inner product represents the directional and magnitude relationships between two vectors. The inner product is calculated as follows:

$$
[ \mathbf{A} \cdot \mathbf{B} = a_1 b_1 + a_2 b_2 + ... + a_n b_n = \sum_{i=1}^{n} a_i b_i ]
$$

The syntax is as follows:

```sql
inner_product(vector v1, vector v2)
```

The parameters are described as follows:

* Apart from vector types, the parameters can be of any type that can be converted into a vector, such as a one-dimensional array type (e.g., `[1,2,3,..]`) and a string type (e.g., `'[1,2,3]'`).

* The dimensions of the two parameters must be the same.

* If any element of a one-dimensional array is `NULL`, the element is not allowed in the parameter.

The return value is described as follows:

* The return value is the `distance(double)` distance value.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t4(c1 vector(3));
INSERT INTO t4 VALUES('[1,2,3]');
INSERT INTO t4 VALUES('[1,2,1]');
SELECT inner_product(c1, [1,2,3]) FROM t4;
```

The return result is as follows:

```shell
+----------------------------+
| inner_product(c1, [1,2,3]) |
+----------------------------+
|                         14 |
|                          8 |
+----------------------------+
2 rows in set
```

### Vector_distance

The vector_distance function calculates the distance between two vectors by using different distance algorithms specified by parameters.

The syntax is as follows:

```sql
vector_distance(vector v1, vector v2 [, string metric])
```

The parameters are described as follows:

* Apart from vector types, the parameters can be of any type that can be converted into a vector, such as a one-dimensional array type (e.g., `[1,2,3,..]`) and a string type (e.g., `'[1,2,3]'`).

* The dimensions of the two parameters must be the same.

* If any element of a one-dimensional array is `NULL`, the element is not allowed in the parameter.

The `metric` parameter specifies the distance algorithm. Valid values include:

* If the `metric` parameter is not specified, the default value `euclidean` is used.

* If the `metric` parameter is specified, it can only be one of the following:

  * `euclidean`. The Euclidean distance, which is the same as the L2_distance.

  * `manhattan`. The Manhattan distance, which is the same as the L1_distance.

  * `cosine`. The cosine distance, which is the same as the Cosine_distance.

  * `dot`. The inner product, which is the same as the Inner_product.

The return value is described as follows:

* The return value is the `distance(double)` distance value.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t5(c1 vector(3));
INSERT INTO t5 VALUES('[1,2,3]');
INSERT INTO t5 VALUES('[1,2,1]');
SELECT vector_distance(c1, [1,2,3], euclidean) FROM t5;
```

The return result is as follows:

```shell
+-----------------------------------------+
| vector_distance(c1, [1,2,3], euclidean) |
+-----------------------------------------+
|                                       0 |
|                                       2 |
+-----------------------------------------+
2 rows in set
```

## Arithmetic functions

Arithmetic functions enable you to perform element-wise addition (+), subtraction (-), and multiplication (*) operations between vector types, between single-level array types, between special string types, between vector and single-level array types, and between vector and special string types.

$$
[x_1,x_2,...,x_n]+[y_1,y_2,...,y_n]=[x_1+y_1,x_2+y_2,...,x_n+y_n]
$$

The syntax is as follows:

```sql
v1 + v2
v1 - v2
v1 * v2
```

The parameters are described as follows:

* Apart from vector types, parameters can be of any type that can be forcibly converted to a vector type, such as a one-dimensional array type (`[1,2,3,..]`) and a string type (`'[1,2,3]'`). **Notice:** If both parameters are of the string type, the system will return an error.

* The dimensions of the two parameters must be the same.

* If a parameter of a single-level array type is present, `NULL` cannot be used for its elements.

The return value is described as follows:

* If at least one of the parameters is a vector, the return value has the same vector type as the vector parameter.

* If only one of the two parameters is of the single-level array type, the return value is of the `array(float)` type.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t6(c1 vector(3));
INSERT INTO t6 VALUES('[1,2,3]');
SELECT [1,2,3] + '[1.12,1000.0001, -1.2222]', c1 - [1,2,3] FROM t6;
```

The return result is as follows:

```shell
+---------------------------------------+--------------+
| [1,2,3] + '[1.12,1000.0001, -1.2222]' | c1 - [1,2,3] |
+---------------------------------------+--------------+
| [2.12,1002,1.7778]                    | [0,0,0]      |
+---------------------------------------+--------------+
1 row in set
```

## Comparison functions

Comparison functions provide comparison capabilities for vector types, vector types, one-dimensional array types, and special string types. The comparison operators are =, !=, >, <, >=, and <=. These functions compare elements in a lexicographical order.

The syntax is as follows:

```sql
v1 = v2
v1 != v2
v1 > v2
v1 < v2
v1 >= v2
v1 <= v2
```

The parameters are described as follows:

* Parameters of a vector type or that can be converted into a vector type are acceptable. For example, you can compare a single-level array like `[1,2,3,..]` or a string like `'[1,2,3]'` with a vector.

  <main id="notice" type='notice'>

    <p>At least one of the two parameters must be of a vector type. </p>

* The two parameters must have the same dimension.

* If a single-level array is present, it must not contain `NULL` elements.

The return value is described as follows:

* The return value is of the bool type.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t7(c1 vector(3));
INSERT INTO t7 VALUES('[1,2,3]');
SELECT c1 = '[1,2,3]' FROM t7;
```

The return result is as follows:

```shell
+----------------+
| c1 = '[1,2,3]' |
+----------------+
|              1 |
+----------------+
1 row in set
```

## Other common vector functions

### Vector_norm

The Vector_norm function calculates the Euclidean norm (or modulus) of a vector, which is the Euclidean distance between the vector and the origin. The calculation formula is as follows:

$$
[ D = \sqrt{\sum_{i=1}^{n} (x_i)^2} ]
$$

The syntax is as follows:

```sql
vector_norm(vector v1)
```

The parameters are described as follows:

* Apart from the vector type, the parameters can be of any type that can be forcibly converted into a vector type. The single-level array type (e.g., `[1,2,3,..]`) and the string type (e.g., `'[1,2,3]'`) are also supported.

* If the parameter of the single-level array type, the elements of the array cannot be `NULL`.

The return value is described as follows:

* The return value is of the `norm(double)` type.

* If the parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t10(c1 vector(3));
INSERT INTO t10 VALUES('[1,2,3]');
SELECT vector_norm(c1),vector_norm([1,2,3]) FROM t10;
```

The return result is as follows:

```shell
+--------------------+----------------------+
| vector_norm(c1)    | vector_norm([1,2,3]) |
+--------------------+----------------------+
| 3.7416573867739413 |   3.7416573867739413 |
+--------------------+----------------------+
1 row in set
```

```sql
vector_dims(vector v1)
```

The parameters are described as follows:
