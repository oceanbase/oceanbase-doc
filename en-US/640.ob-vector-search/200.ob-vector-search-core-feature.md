# Core features

OceanBase Database can store, index, and retrieve vector data. The following table describes the core features.

|**Feature**|**Description**|
|---|---|
| Vector data type | Supports storing floating-point vector data with a maximum dimension of 16,000. |
| Vector indexes | <ul><li>Supports both exact search and approximate nearest neighbor search (ANNS).</li><li>Supports L2 distance, inner product, and cosine similarity calculations.</li><li>Supports HNSW index/HNSW SQ index, with a maximum index column dimension of 4096.</li><li>Supports IVF index/IVF SQ index/IVF PQ index (experimental feature), with a maximum index column dimension of 4096.</li></ul>| Operators for vector search | Basic operators, such as addition, subtraction, multiplication, comparison, and aggregation operators, are supported. |

## Limitations

* By default, OceanBase Database uses the nullsFirst comparison mode, in which NULL values are placed first during sorting. We recommend that you add a `NOT NULL` condition in queries.
