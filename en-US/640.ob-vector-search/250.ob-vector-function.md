# Use SQL functions

This topic describes the vector functions supported by OceanBase Database and their usage notes.

## Considerations

* The following operations will fail with the error `different vector dimensions %d and %d` if the vectors have different dimensions.
* If the result exceeds the floating-point value range, the error `value out of range: overflow / underflow` will be returned.
* Dense vector indexes support L2, inner product, and cosine distance as index distance algorithms; sparse vector indexes support inner product and negative inner product as index distance algorithms. For details, see [Dense vector indexes](200.ob-vector-index/200.ob-vector-index.md). The distance algorithms for sparse vector indexes are supported starting from V4.3.5 BP2.
* You can call the `L2_distance`, `Cosine_distance`, `Inner_product`, and `Negative_inner_product` distance functions in this topic to search for vectors.

## Configure the memory for vector indexes

OceanBase Database allows you to configure the memory for vector indexes by setting the [ob_vector_memory_limit_percentage](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/6150.ob_vector_memory_limit_percentage.md) parameter:

* **Before you create an HNSW/HNSW_SQ/HNSW_BQ vector index in a version earlier than V4.4.1**, you must manually set the `ob_vector_memory_limit_percentage` parameter to enable vector search. We recommend that you set the parameter to `30` for the best search performance. If you do not set the parameter, no memory is allocated for vector indexes, and an error is returned when you create an index. The IVF/IVF_SQ/IVF_PQ indexes do not need to be kept in memory. Therefore, you do not need to pay attention to this parameter. Here is a sample configuration:
    ```sql
    ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
    ```

* **Starting from V4.4.1**, vector search is enabled by default. The default value of `0` indicates adaptive mode, in which the system automatically adjusts the memory usage ratio of vector index data in a tenant. You do not need to manually adjust this parameter:
  * If the actual memory of the tenant is 8 GB or less, the value is automatically adjusted to `40`.
  * If the actual memory of the tenant is more than 8 GB, the value is automatically adjusted to `50`.

## Distance function

A distance function is used to calculate the distance between two vectors. The calculation method varies depending on the distance algorithm.

### L2_distance

The Euclidean distance reflects the distance between the coordinates of the compared vectors, which is essentially the straight-line distance between the two vectors. It is calculated by applying the Pythagorean theorem to the vector coordinates:

![Pythagorean theorem](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E5%8B%BE%E8%82%A1%E5%AE%9A%E7%90%86.jpg)

The function syntax is as follows:

```sql
l2_distance(vector v1, vector v2)
```

The parameters are described as follows:

* In addition to the vector type, the parameters can accept any type that can be explicitly converted to a vector, including one-dimensional array types (e.g., `[1,2,3,..]`) and string types (e.g., `'[1,2,3]'`).

* The dimensions of the two parameters must be the same.

* When a one-dimensional array type parameter is present, the elements of the parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If any parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t1(c1 vector(3));
INSERT INTO t1 VALUES('[1,2,3]');
SELECT l2_distance(c1, [1,2,3]), l2_distance([1,2,3],[1,1,1]), l2_distance('[1,1,1]','[1,2,3]') FROM t1;
```

The result is as follows:

```shell
+--------------------------+------------------------------+----------------------------------+
| l2_distance(c1, [1,2,3]) | l2_distance([1,2,3],[1,1,1]) | l2_distance('[1,1,1]','[1,2,3]') |
+--------------------------+------------------------------+----------------------------------+
|                        0 |             2.23606797749979 |                 2.23606797749979 |
+--------------------------+------------------------------+----------------------------------+
1 row in set
```

### Cosine_distance

Cosine similarity measures the angular difference between two vectors, reflecting their directional similarity regardless of their magnitudes. The range of cosine similarity is `[-1, 1]`, where `1` indicates the vectors are in the same direction, `0` indicates orthogonality, and `-1` indicates opposite directions.

The calculation method for cosine similarity is as follows:

![Cosine similarity](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E4%BD%99%E5%BC%A6%E7%9B%B8%E4%BC%BC%E5%BA%A6.jpg)

Since a higher cosine similarity indicates greater similarity, cosine distance (or cosine dissimilarity) is sometimes used as a measure of distance between vectors. Cosine distance can be calculated by subtracting cosine similarity from 1:

![Cosine distance](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E4%BD%99%E5%BC%A6%E8%B7%9D%E7%A6%BB.jpg)

The range of cosine distance is `[0, 2]`, where `0` indicates the same direction (no distance), and `2` indicates the opposite direction.

The function syntax is as follows:


The parameters are described as follows:

* In addition to the vector type, the parameters can accept any type that can be explicitly converted to a vector, including one-dimensional array types (e.g., `[1,2,3,..]`) and string types (e.g., `'[1,2,3]'`).

* The dimensions of the two parameters must be the same.

* When a one-dimensional array type parameter is present, the elements of the parameter cannot contain `NULL`.

The return value is described as follows:

* The return value is a `distance(double)` value.

* If any parameter is `NULL`, `NULL` is returned.

Here is an example:

### Vector_distance

vector_distance is used to calculate the distance between two vectors, and different distance algorithms can be selected by specifying parameters.

## Similarity functions

Similarity functions are used to measure the degree of similarity between two vectors—the larger the value, the more similar the vectors are. Similarity and distance functions are opposite concepts: higher similarity means smaller distance. In vector search, you can filter results that meet the criteria by setting a similarity threshold.

### inner_product_similarity

`inner_product_similarity` is used to calculate the inner product similarity between two vectors. The calculation method for the function’s return value is the same as the inner product distance function `inner_product`, but the return value represents similarity rather than distance. The conversion between them is: `inner_product_similarity(v1, v2) = (1 + inner_product(v1, v2) / (vector_norm(v1) * vector_norm(v2))) / 2`. The `vector_norm` function calculates the Euclidean norm (magnitude) of a vector, which is the Euclidean distance between the vector and the origin. For a vector `v = [v1, v2, v3, ..., vn]`, the norm is calculated as: `vector_norm(v) = √(v1² + v2² + v3² + ... + vn²)`.

Syntax:

```sql
inner_product_similarity(vector v1, vector v2)
```

Parameter description:

* In addition to vector type, the parameters can accept any other type that can be forcibly converted to a vector type, including single-level array types (such as `[1,2,3,..]`) and string types (such as `'[1,2,3]'`).
* The dimensions of both parameters must be the same.
* If a single-level array type is used as a parameter, its elements cannot be `NULL`.

Return value description:

* The return type is double, and the result is the similarity value between the two vectors. The larger the value, the more similar they are.
* If any parameter is `NULL`, the function returns `NULL`.

Examples:

```sql
CREATE TABLE t12(c1 vector(3));
INSERT INTO t12 VALUES('[1,2,3]');
INSERT INTO t12 VALUES('[1,2,1]');
SELECT inner_product_similarity(c1, [1,2,3]) FROM t12;
```

Return result:

```shell
+---------------------------------------+
| inner_product_similarity(c1, [1,2,3]) |
+---------------------------------------+
|                    0.9999999552965164 |
|                    0.9364357516169548 |
+---------------------------------------+
2 rows in set
```

Or a simpler example:

```sql
SELECT inner_product_similarity([1,0,0], [0,1,0]);
```

Return result:

```shell
+--------------------------------------------+
| inner_product_similarity([1,0,0], [0,1,0]) |
+--------------------------------------------+
|                                        0.5 |
+--------------------------------------------+
1 row in set
```

### cosine_similarity

`cosine_similarity` is used to calculate the cosine similarity between two vectors, reflecting the similarity in direction between the vectors, regardless of their length (magnitude). The calculation method is: `cosine_similarity(v1, v2) = 1 - (cosine_distance(v1, v2) / 2)`.

Parameter description:

* In addition to vector type, the parameters can accept any other type that can be forcibly converted to a vector type, including single-level array types (such as `[1,2,3,..]`) and string types (such as `'[1,2,3]'`).

* If a single-level array type is used as a parameter, its elements cannot be `NULL`.

Return value description:

* The return type is double, and the result is the similarity value between the two vectors. The value range is `[-1, 1]`, where `1` indicates the vectors have exactly the same direction, `0` indicates they are orthogonal, and `-1` indicates they have completely opposite directions. The larger the value, the more similar the vectors.
* If any parameter is `NULL`, the function returns `NULL`.

Examples:

## Arithmetic functions

Arithmetic functions support addition, subtraction, and multiplication between vector types and vector types, single-level array types, and special string types, as well as between single-level array types and special string types. The calculation is performed element-wise. For example, in addition, each element of the first vector is added to the corresponding element of the second vector.

![Addition](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E5%8A%A0%E6%B3%95.jpg)

The syntax is as follows:

```sql
v1 + v2
v1 - v2
v1 * v2
```

The parameters are described as follows:

* In addition to vector types, the parameters can accept any other type that can be forcibly converted to a vector type, including single-level array types (such as `[1,2,3,..]`) and string types (such as `'[1,2,3]'`). **Note:** The two parameters cannot both be string types. At least one of the parameters must be a vector or single-level array type.

* The dimensions of the two parameters must be the same.

* If a single-level array type parameter is provided, the elements of the array cannot contain `NULL`.

The return value is described as follows:

* If at least one of the two parameters is a vector type, the return value is a vector type with the same dimension as the vector parameter.

* If both parameters are single-level array types, the return value is of the `array(float)` type.

* If any parameter is `NULL`, the return value is `NULL`.

Here is an example:

```sql
CREATE TABLE t6(c1 vector(3));
INSERT INTO t6 VALUES('[1,2,3]');
SELECT [1,2,3] + '[1.12,1000.0001, -1.2222]', c1 - [1,2,3] FROM t6;
```

The return value is as follows:

```shell
+---------------------------------------+--------------+
| [1,2,3] + '[1.12,1000.0001, -1.2222]' | c1 - [1,2,3] |

| [2.12,1002,1.7778]                    | [0,0,0]      |
+---------------------------------------+--------------+
1 row in set
```

## Other common vector functions

### Vector_norm

The Vector_norm function calculates the Euclidean norm (magnitude) of a vector, which represents the Euclidean distance from the vector to the origin. The calculation method is:

![Euclidean norm](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E6%AC%A7%E5%87%A0%E9%87%8C%E5%BE%B7.jpg)

The syntax is as follows:

```sql
vector_norm(vector v1)
```

The parameters are described as follows:

* In addition to vector types, other types that can be explicitly converted to vector types are also supported, including single-level array types (such as `[1,2,3,..]`) and string types (such as `'[1,2,3]'`).

* If the parameter is a single-level array type, the elements cannot contain `NULL`.

The return value is described as follows:

* The `norm(double)` value is returned.

* If the parameter is `NULL`, `NULL` is returned.

Here is an example:

```sql
CREATE TABLE t10(c1 vector(3));
INSERT INTO t10 VALUES('[1,2,3]');
SELECT vector_norm(c1),vector_norm([1,2,3]) FROM t10;
```

The result is as follows:

```shell
+--------------------+----------------------+
| vector_norm(c1)    | vector_norm([1,2,3]) |
+--------------------+----------------------+
| 3.7416573867739413 |   3.7416573867739413 |
+--------------------+----------------------+
1 row in set
```

**Vector normalization**

Vector normalization refers to the process of standardizing the length (magnitude) of a vector to 1. The `vector_norm` function is commonly used for vector normalization.

For vector indexes that use the `l2_distance` distance type, it is recommended to normalize the vectors to improve the accuracy of similarity searches. After normalization, the vector’s magnitude is 1, and the L2 distance range is limited to `[0, 2]`, thus avoiding precision issues caused by excessively small similarity values.

For example, for the vector `[3, 4]`:
* The magnitude of the vector: `vector_norm([3, 4]) = √(3² + 4²) = 5`
* After normalization: `[3, 4] / 5 = [0.6, 0.8]`

The normalized vector has a magnitude of 1. To verify:

```sql
SELECT vector_norm([0.6, 0.8]);
```
Return result:

```shell
+-------------------------+
| vector_norm([0.6, 0.8]) |
+-------------------------+
|       1.000000029802322 |
+-------------------------+
1 row in set
```

### Vector_dims

The vector_dims function returns the dimension of a vector.

Syntax:

```sql
vector_dims(vector v1)
```

Parameters:

* In addition to vector types, other types that can be explicitly converted to vector types are also supported, including single-level array types (such as `[1,2,3,..]`) and string types (such as `'[1,2,3]'`).

The return value is described as follows:

* The `dims(int64)` value is returned.

* An error is returned if the parameter is `NULL`.

Here is an example:

```sql
CREATE TABLE t11(c1 vector(3));
INSERT INTO t11 VALUES('[1,2,3]');
INSERT INTO t11 VALUES('[1,1,1]');
SELECT vector_dims(c1), vector_dims('[1,2,3]') FROM t11;
```

The result is as follows:

```shell
+-----------------+------------------------+
| vector_dims(c1) | vector_dims('[1,2,3]') |
+-----------------+------------------------+
|               3 |                      3 |
|               3 |                      3 |
+-----------------+------------------------+
2 rows in set
```

## Vector search functions for semantic indexes

In addition to the general vector search functions, OceanBase Database provides the following vector search functions for semantic indexes (vector indexes created on text columns):

* `semantic_distance(column_name, 'query_text')`: This function performs vector search based on the original text. The system automatically calls the embedding model to convert the text into a vector.
* `semantic_vector_distance(column_name, query_vector)`: This function performs vector search based on the vector. It supports index search (with the `APPROXIMATE` or `APPROX` clause) and full-table scan (without the `APPROXIMATE` or `APPROX` clause).

For more information about these functions, see [Semantic indexes](200.ob-vector-index/300.ob-semantic-index.md).
