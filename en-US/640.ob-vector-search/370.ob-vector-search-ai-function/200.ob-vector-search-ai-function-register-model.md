# Register AI models

This topic describes how to register AI models and their endpoints by using the `DBMS_AI_SERVICE` package so that you can use the AI function service in OceanBase Database.

<main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You do not need to register models and endpoints when you use the <code>AI_SPLIT_DOCUMENT</code> function. </p>
</main>

## Prerequisites

* You have the required permissions for AI models. For more information, see [AI function service permissions](150.ob-vector-search-ai-function-permission.md).
* You have obtained an API key for a third-party model service.

## Register models and endpoints

Use `CREATE_AI_MODEL` to register models and `CREATE_AI_MODEL_ENDPOINT` to register the endpoints for the models. The following example registers three model keys: `ob_complete`, `ob_embed`, and `ob_rerank`, which are used for text generation (AI_COMPLETE), vector embedding (AI_EMBED), and re-ranking (AI_RERANK), respectively. Replace `access_key` with your actual API key.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>If you only need to use a specific type of AI function, you can register only the corresponding model and endpoint. For example, if you only need to use <code>AI_COMPLETE</code>, you can complete only the <code>Register the text generation model and endpoint</code> step below.</p>
</main>

### Register an embedding model and endpoint

This example uses the `AI_EMBED` model type.

:::tab
tab Alibaba Cloud

The following example shows how to register an embedding model and endpoint for Alibaba Cloud (OpenAI-compatible format).

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('ob_embed');
CALL DBMS_AI_SERVICE.DROP_AI_MODEL_ENDPOINT ('ob_embed_endpoint');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL(
'ob_embed', '{
    "type": "dense_embedding",
    "model_name": "BAAI/bge-m3"
}');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
'ob_embed_endpoint', '{
    "ai_model_name": "ob_embed",
    "url": "https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings",
    -- Replace with your actual access key.
    "access_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "provider": "aliyun-openAI"
}');
```
