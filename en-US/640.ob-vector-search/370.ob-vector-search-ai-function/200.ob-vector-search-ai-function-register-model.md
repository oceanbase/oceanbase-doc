# AI model registration

This topic describes how to register AI models and their access endpoints using the `DBMS_AI_SERVICE` package so you can use AI functions such as `AI_COMPLETE`, `AI_EMBED`, and `AI_RERANK` in OceanBase.

## Prerequisites

* You have the permissions required for AI models. For details, see [AI function service permissions](150.ob-vector-search-ai-function-permission.md).
* You have an API key from a third-party model service.

## Model and endpoint registration templates

Use `CREATE_AI_MODEL` to register a model, then use `CREATE_AI_MODEL_ENDPOINT` to register that model's access endpoint. The examples below register three model keys, `ob_complete`, `ob_embed`, and `ob_rerank`, for text generation (AI_COMPLETE), vector embedding (AI_EMBED), and reranking (AI_RERANK). Replace `access_key` with your actual API key.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>If you only need a subset of AI functions, register only the corresponding models and endpoints. For example, to use only <code>AI_COMPLETE</code>, complete the <code>Register a text generation model and endpoint</code> section below.</p>
</main>

### Register an embedding model and endpoint

Used by `AI_EMBED`.

:::tab
tab Alibaba Cloud

This example registers an embedding model and endpoint for Alibaba Cloud (OpenAI-compatible API).

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('ob_embed');
CALL DBMS_AI_SERVICE.DROP_AI_MODEL_ENDPOINT ('ob_embed_endpoint');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL(
'ob_embed', '{
    "type": "dense_embedding",
    "model_name": "BAAI/bge-m3"
}');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
'ob_embed_endpoint', '{
    "ai_model_name": "ob_embed",
    "url": "https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings",
    -- Replace with your actual access_key
    "access_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "provider": "aliyun-openAI"
}');
```
