# Quick start with AI Function Service

This topic is for users who are new to AI Function Service. It guides you through the process of registering a model and running a sample function with minimal steps.

This topic only covers the `AI_COMPLETE` function. For information about other functions, see [AI Function Service syntax and examples](300.ob-vector-search-ai-function.md).

## Prerequisites

* You have deployed an OceanBase cluster and created a MySQL tenant, and connected to the database.
* You have the required permissions for AI functions. For more information, see [AI function service permissions](150.ob-vector-search-ai-function-permission.md).

## Quick start

### Step 1: Register the AI model and endpoint

Before you use the AI model for the first time, you need to register the AI model and its endpoint. You can refer to the template provided in [Register an AI model](200.ob-vector-search-ai-function-register-model.md) and copy the example for the corresponding AI model provider. You just need to replace the API Key with your actual API Key. Here is an example of registering the `AI_COMPLETE` sentiment analysis model (Alibaba Cloud, compatible with OpenAI format):

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('ob_complete');
CALL DBMS_AI_SERVICE.DROP_AI_MODEL_ENDPOINT ('ob_complete_endpoint');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL(
'ob_complete', '{
    "type": "completion",
    "model_name": "THUDM/GLM-4-9B-0414"
}');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
'ob_complete_endpoint', '{
    "ai_model_name": "ob_complete",
    "url": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
    -- Replace the following value with your actual access key.
    "access_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "provider": "aliyun-openAI"
}');
```

### Step 2: Run an example

Here is an example of using the `AI_COMPLETE` sentiment analysis model to determine the sentiment of a piece of text:

```sql
SELECT AI_COMPLETE("ob_complete", AI_PROMPT('Your task is to perform sentiment analysis on the provided text and determine whether it expresses a positive or negative sentiment.
    The text to be analyzed is as follows:
    <text>
    {0}
    </text>
    The judgment criteria are as follows:
    If the text expresses a positive sentiment, output 1. If the text expresses a negative sentiment, output -1. Do not output anything else.', 'The weather is really nice today')) AS sentiment;
```

The expected result is that the `sentiment` column returns `1`, indicating a positive sentiment.

### Step 3: Comprehensive application (optional)

You can combine three AI functions to build a simple intelligent question-answering system in three steps.

1. Register all required models and endpoints (optional)

    This example requires the use of an embedding model, a text generation model, and a reranking model. Make sure you have registered the corresponding models and endpoints. For more information, see Step 1.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If you have already registered the corresponding models in the previous steps, you can skip the registration steps and proceed to the next step. </p>
    </main>

2. Prepare data and generate vectors

    ```sql
    CREATE TABLE knowledge_base (
        id INT AUTO_INCREMENT PRIMARY KEY,
        title VARCHAR(255),
        content TEXT,
        embedding TEXT
    );

    INSERT INTO knowledge_base (title, content) VALUES
        ('OceanBase Database', 'OceanBase Database is a powerful database system that supports vector search and AI functions.'),
        ('Vector search', 'Vector search can be used for semantic search to find similar content.'),
        ('AI functions', 'AI functions can be directly called in SQL to use AI models.');

    UPDATE knowledge_base
    SET embedding = AI_EMBED("ob_embed", content);
    ```

3. Perform vector search and reranking

    ```sql
    SET @query = "What is vector search?";
    SET @query_vector = AI_EMBED("ob_embed", @query);

    -- Directly construct a string array of documents
    SET @candidate_docs = '["OceanBase Database is a powerful database system that supports vector search and AI functions.", "Vector search can be used for semantic search to find similar content."]';

    SELECT AI_RERANK("ob_rerank", @query, @candidate_docs) AS ranked_results;
    ```

    The returned result is as follows, where `index` is the document index and `relevance_score` is the relevance score:

    ```sql
    +-------------------------------------------------------------------------------------------------------------+
    | ranked_results                                                                                              |
    +-------------------------------------------------------------------------------------------------------------+
    | [{"index": 1, "relevance_score": 0.9904329776763916}, {"index": 0, "relevance_score": 0.16993996500968933}] |
    +-------------------------------------------------------------------------------------------------------------+
    1 row in set
    ```

4. Generate an answer

    Based on the search results from Step 1 and the reranking results from Step 2, generate an answer:

    ```sql
    SELECT AI_COMPLETE("ob_complete",
        AI_PROMPT('Based on the following document content, answer the user's question.
        User question: {0}

        Relevant documents: {1}

        Please provide a concise and accurate answer based on the above documents.', @query, CAST(JSON_EXTRACT(@candidate_docs, '$[1]') AS CHAR))) AS answer;
    ```

    The returned result is as follows:

    ```sql
    +--------------------------------------------------------------------------------------------------------------------------------------------+
    | answer                                                                                                                                     |
    +--------------------------------------------------------------------------------------------------------------------------------------------+
    | Based on the provided document content, vector search is a technique used for semantic search to find similar content by comparing vector data. |
    +--------------------------------------------------------------------------------------------------------------------------------------------+
    1 row in set
    ```

    By following these three steps, you can quickly complete the entire AI application process in OceanBase Database: vectorization, search, reranking, and answer generation.
