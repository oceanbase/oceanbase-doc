# Create a Java application

This topic describes how to create a Java application to connect to and use OceanBase Database by using OceanBase Connector/J.

  <main id="notice" >
    <h4>Applicability</h4>
    <p>This topic applies only to OceanBase Database Enterprise Edition. OceanBase Database Community Edition does not support this feature. </p>
  </main>

## Prerequisites

* You have set up the basic database development environment.

* You have installed the Java Development Kit (JDK) 8 on your computer.

* You have obtained the OceanBase Connector/J installation package. To do so, visit **Resources > Download Center > Enterprise Edition > Drivers and Middleware** on the OceanBase website and click the corresponding [OceanBase JDBC Driver](https://en.oceanbase.com/softwarecenter-enterprise) link. Fill in the required information and download OceanBase Connector/J.

## Create a Java application

### Step 1: Obtain a database connection string

Contact your OceanBase deployment engineer or administrator to obtain a database connection string. For example:

```sql
obclient  -h100.88.xx.xx -usys@oracle -p****** -P2883
```

The database connection string contains all the parameters required for accessing the database. Before you create the application, you can verify whether you can connect to the database by using the database connection string to ensure that the parameters in the connection string are correct.

Parameter description:

* **-h**: the IP address of the OceanBase Database. This IP address is usually an ODP IP address.

* **-u**: the tenant user name in the format of **username@tenant name#cluster name**, which you can obtain from the administrator. In Oracle mode, the default administrator username is `sys`. If you connect directly to the database, do not specify the cluster name. If you connect to the database by using an ODP, you must specify the cluster name.

* **-p**: the username.

* **-P**: the port of the OceanBase Database, which is also the listening port of the ODP.

### Step 2: Install OceanBase Connector/J

Decompress the OceanBase Connector/J installation package and move the JAR package to the `/usr/share/java` directory. Then, set the temporary environment variable.

```shell
mv ./oceanbase-client-{version}.jar /usr/share/java
export CLASSPATH=/usr/share/java/oceanbase-client-{version}.jar:$CLASSPATH
```

### Step 3: Write the application

Write a sample Java file named `Test.java`.

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;
import java.sql.ResultSet;
import java.sql.Statement;

public class Test {
    public static void main(String[] args) {
        try {

            Class.forName("com.oceanbase.jdbc.Driver");
            Connection connection = DriverManager.getConnection("jdbc:oceanbase://172.30.xx.xx:2881/?pool=false&user=s**@oracle&password=******");
            System.out.println(connection.getAutoCommit());
            Statement sm = connection.createStatement();
            //Create a table named t_meta_form.
            sm.executeUpdate("CREATE TABLE t_meta_form (name varchar(36) , id int)");
            //Insert some data.
            sm.executeUpdate("insert into t_meta_form values ('an','1')");
            //Query the data and output the result.
            ResultSet rs = sm.executeQuery("select * from t_meta_form");
            while (rs.next()) {
                String name = rs.getString("name");
                String id = rs.getString("id");
                System.out.println(name + ','+ id);
            }
            //Drop the table.
            sm.executeUpdate("drop table t_meta_form");
        }catch (SQLException ex) {
            System.out.println("error!");
            ex.printStackTrace() ;
        }catch (ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

Set the database connection parameters in the sample code. The following table describes the parameters that you need to configure. The values are taken from the database connection string obtained in Step 1.

* **url**: The value of this parameter is obtained by combining the value of the `-h` parameter and the value of the `-P` parameter in the format of `jdbc:oceanbase://IP:port/?pool=false`. The value of the `-h` parameter is the IP address of the OceanBase Database, which is usually an ODP IP address. The value of the `-P` parameter is the port number of the OceanBase Database.

* **user**: The value of this parameter is the value of the `-u` parameter. This value is the tenant user name in the format of **username@tenant name#cluster name**. In Oracle mode, the default administrator username is `sys`. If you connect directly to the database, you do not specify the cluster name. If you connect to the database by using an ODP, you must specify the cluster name.

* **password**: The value of this parameter is the value of the `-p` parameter.

### Step 4: Run the application

Run the following command to compile the sample code:

```bash
javac Test.java
```

After the code is compiled, execute it to obtain the following result, which indicates that the database connection is successful and the sample statements are executed correctly:

```bash
java Test

true
an,1
```
