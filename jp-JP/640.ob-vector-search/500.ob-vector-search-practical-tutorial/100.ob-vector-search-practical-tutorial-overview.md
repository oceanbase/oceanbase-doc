# ベクトル検索実践ガイド概要

本記事では、OceanBase を基盤としてベクトル検索を構築する典型的な適用シナリオを紹介します。

# ベクトル検索実践ガイド

### OceanBase を基盤としてスマート QA ボットが構築されます

ドキュメントスマートアシスタントは、OceanBase データベースを基盤とするアプリケーションで、ドキュメントをベクトル形式で大量に保存します。ユーザーは UI インターフェースを通じて質問することができ、BGE-M3 モデルを使用して質問の内容をベクトルに埋め込み、データベースにおいて相似のベクトルを検索します。相似のベクトルに対応するドキュメント内容が見つかると、ユーザーの質問と一緒に LLM に送られ、LLM は提供されたドキュメントに基づいてより正確な回答を生成します。

# OceanBase を基盤とした画像検索アプリケーション

画像検索アプリケーションは、OceanBase データベースを基盤とするアプリケーションで、画像ライブラリをベクトル形式でデータベースに保存します。ユーザーは対応する UI インターフェースでクエリする画像をアップロードできます。アップロードされた画像はアプリケーションによってベクトルに変換され、データベース内で類似ベクトルがクエリされます。最終的に、類似画像は UI ページに画像形式で表示されます。
