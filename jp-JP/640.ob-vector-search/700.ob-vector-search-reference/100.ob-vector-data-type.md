# ベクトルデータ型の概要

OceanBase は、AI ベクトル検索関連アプリケーションをサポートするために、ベクトルデータ型を提供しています。ベクトルデータ型を使用することで、`[0.1, 0.3, -0.9, ...]` のような浮動小数点数の配列を格納し、クエリを実行できます。ベクトルデータを使用する前に、以下の点にご注意ください：

* ベクトルデータ型でサポートされるデータ要素は、単精度浮動小数点数です。

* ベクトルデータの要素値は、非数値 (NaN) または無限大 (Inf) を許容しません。これらの値が含まれる場合、実行時エラーが発生します。

* ベクトル列を作成する際には、`VECTOR(3)` のようにベクトル次元を指定する必要があります。

* ベクトルインデックスの作成をサポートします。詳細については、[ベクトルインデックス](../200.ob-vector-index.md) を参照してください。

* OceanBase では、ベクトルデータは配列として格納されます。

## 構文

ベクトル値は、任意の数の浮動小数点数を含むことができます。構文は以下のとおりです：

```sql
'[<float>, <float>, ...]'
```

ベクトル列とインデックスの作成例を以下のとおりです：

```sql
CREATE TABLE t1(
    c1 INT, 
    c2 VECTOR(3), 
    PRIMARY KEY(c1), 
    VECTOR INDEX idx1(c2) WITH (distance=L2, type=hnsw)
    );
```
