# SQL 関数の使用

本記事では、OceanBase でサポートされているベクトル関数とその使用上の注意点を紹介します。

## 使用上の注意点

* 次元の異なるベクトルデータに対して、以下の演算は許可されていません。 `different vector dimensions %d and %d` エラーが発生します。

* 結果が浮動小数点数の範囲を超えた場合、`value out of range : overflow / underflow` エラーが発生します。

* インデックス距離アルゴリズムとして、L2、内積 (IP)、コサイン距離をサポートします。詳細については、[ベクトルインデックス](200.ob-vector-index.md) を参照してください。

## 準備作業

ベクトルインデックスを使用する前に、[ob_vector_memory_limit_percentage](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001976671) を設定してベクトル機能を有効にする必要があります。

```sql
ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
```

## 距離関数

距離関数は、2 つのベクトルの間の距離を計算するために使用され、具体的な計算方法は、距離アルゴリズムによって異なります。

### L2_distance

ユークリッド距離は、比較されるベクトルの座標間の距離、つまり 2 つのベクトル間の直線距離を表します。ピタゴラスの定理をベクトル座標に適用して計算します：

![ピタゴラスの定理](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E5%8B%BE%E8%82%A1%E5%AE%9A%E7%90%86.jpg)

関数構文は以下のとおりです：

```sql
l2_distance(vector v1, vector v2)
```

パラメーターの説明は以下のとおりです：

* ベクトルタイプに加えて、パラメーターはベクトルタイプに変換可能な他のすべてのタイプを受け入れます。これには、単一レベルの配列タイプ (例：`[1,2,3,..]`) と文字列タイプ (例：`'[1,2,3]'`) が含まれます。

* 2 つのパラメーターの次元は同じでなければなりません。

* 単一レベルの配列タイプパラメーターが存在する場合、そのパラメーター要素に `NULL` は許可されません。

戻り値の説明は以下のとおりです：

* 戻り値は `distance(double)` で表される距離値です。

* いずれかのパラメーターが `NULL` の場合、`NULL` を返します。

例：

```sql
CREATE TABLE t1(c1 vector(3));
INSERT INTO t1 VALUES('[1,2,3]');
SELECT l2_distance(c1, [1,2,3]), l2_distance([1,2,3],[1,1,1]), l2_distance('[1,1,1]','[1,2,3]') FROM t1;
```

結果は次のとおりです：

```shell
+--------------------------+------------------------------+----------------------------------+
| l2_distance(c1, [1,2,3]) | l2_distance([1,2,3],[1,1,1]) | l2_distance('[1,1,1]','[1,2,3]') |
+--------------------------+------------------------------+----------------------------------+
|                        0 |             2.23606797749979 |                 2.23606797749979 |
+--------------------------+------------------------------+----------------------------------+
1 row in set
```

### Cosine_distance

コサイン類似度 (cosine similarity) は 2 つのベクトルの角度の差異を測るもので、2 つのベクトルの方向上の類似度を示し、ベクトルの長さ (サイズ) とは無関係となります。コサイン類似度の値の範囲は `[-1, 1]` であり、`1` はベクトルが完全に同じ方向であることを示し、`0` は直交を示し、`-1` は完全に反対の方向を示します。

コサイン類似度の計算方法は次のとおりです：

![コサイン類似度](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E4%BD%99%E5%BC%A6%E7%9B%B8%E4%BC%BC%E5%BA%A6.jpg)

コサイン類似度の度量が 1 に近づくとより類似していることを示すことから、コサイン距離 (またはコサイン非類似度) をベクトル間の距離の測定方式として使用することがあります。コサイン距離は 1 からコサイン類似度を引くことで計算することができます。

![コサイン距離](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E4%BD%99%E5%BC%A6%E8%B7%9D%E7%A6%BB.jpg)

コサイン距離の値の範囲は `[0, 2]` であり、`0` は完全に同じ方向 (距離なし)、`2` は完全に反対方向を表します。

関数構文は以下のとおりです：

```sql
cosine_distance(vector v1, vector v2)
```

パラメーターの説明は以下のとおりです：

* ベクトルタイプに加えて、パラメーターはベクトルタイプに変換可能な他のすべてのタイプを受け入れます。これには、単一レベルの配列タイプ (例：`[1,2,3,..]`) と文字列タイプ (例：`'[1,2,3]'`) が含まれます。

* 2 つのパラメーターの次元は同じでなければなりません。

* 単一レベルの配列タイプパラメーターが存在する場合、そのパラメーター要素に `NULL` は許可されません。

戻り値の説明は以下のとおりです：

* 戻り値は `distance(double)` で表される距離値です。

* いずれかのパラメーターが `NULL` の場合、`NULL` を返します。

例：

```sql
CREATE TABLE t3(c1 vector(3));
INSERT INTO t3 VALUES('[1,2,3]');
INSERT INTO t3 VALUES('[1,2,1]');
SELECT cosine_distance(c1, [1,2,3]) FROM t3;
```

```shell
+------------------------------+
| cosine_distance(c1, [1,2,3]) |
+------------------------------+
|                            0 |
|          0.12712843905603044 |
+------------------------------+
2 rows in set
```

### Vector_distance

vector_distance は、2 つのベクトル間の距離を計算するために使用され、指定されたパラメーターによって異なる距離アルゴリズムを選択します。

構文については以下のとおりです：

```sql
vector_distance(vector v1, vector v2 [, string metric])
```

`vector v1/v2` パラメーターの説明は以下のとおりです：

* ベクトルタイプに加えて、パラメーターはベクトルタイプに変換可能な他のすべてのタイプを受け入れます。これには、単一レベルの配列タイプ (例：`[1,2,3,..]`) と文字列タイプ (例：`'[1,2,3]'`) が含まれます。

* 2 つのパラメーターの次元は同じでなければなりません。

* 単一レベルの配列タイプパラメーターが存在する場合、そのパラメーター要素に `NULL` は許可されません。

`metric` パラメーターは、距離アルゴリズムを指定するために使用されます。オプションです。

* 指定されていない場合、デフォルトのアルゴリズムは `euclidean` です。

* 指定されている場合、選択可能な値は以下に限られます。

  * `euclidean`。ユークリッド距離を示し、L2_distance と同じ意味です。

  * `manhattan`。マンハッタン距離を示し、L1_distance と同じ意味です。

  * `cosine`。余弦距離を表し、Cosine_distance と同じ意味です。

  * `dot`。内積を表し、Inner_product と同じ意味です。

戻り値の説明は以下のとおりです：

* 戻り値は `distance(double)` で表される距離値です。

* いずれかのパラメーターが `NULL` の場合、`NULL` を返します。

例：

```sql
CREATE TABLE t5(c1 vector(3));
INSERT INTO t5 VALUES('[1,2,3]');
INSERT INTO t5 VALUES('[1,2,1]');
SELECT vector_distance(c1, [1,2,3], euclidean) FROM t5;
```

結果は次のとおりです：

```shell
+-----------------------------------------+
| vector_distance(c1, [1,2,3], euclidean) |
+-----------------------------------------+
|                                       0 |
|                                       2 |
+-----------------------------------------+
2 rows in set
```

## 算術関数

算術関数は、ベクトルタイプとベクトタイプル、単一レベル配列タイプ、特殊文字列タイプ、および単一レベル配列タイプと単一レベル配列タイプ、特殊文字列タイプの加算 (+) 、減算 (-)、および乗算 (*) の算術演算を提供します。計算方法は要素ごとの計算であり、例えば加法の計算は次のとおりです：

![加法](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.5/vector_search/%E5%8A%A0%E6%B3%95.jpg)

構文については以下のとおりです：

```sql
v1 + v2
v1 - v2
v1 * v2
```

パラメーターの説明は以下のとおりです：

* ベクトルタイプに加えて、パラメーターはベクトルタイプに変換可能な他のすべてのタイプを受け入れます。これには、単一レベルの配列タイプ (例：`[1,2,3,..]`) と文字列タイプ (例：`'[1,2,3]'`) が含まれます。**注意：** 2 つのパラメーターは同時に文字列タイプにすることはできません。少なくとも 1 つのパラメーターはベクトルまたは単一レベルの配列タイプでなければなりません。

* 2 つのパラメーターの次元は同じでなければなりません。

* 単一レベルの配列タイプパラメーターが存在する場合、そのパラメーター要素に `NULL` は許可されません。

戻り値の説明は以下のとおりです：

* 2 つのパラメーターのうち少なくとも 1 つがベクトルタイプの場合、戻り値はベクトルパラメーターと同じベクトルタイプになります。

* 2 つのパラメーターのうち、単一レベルの配列タイプしかない場合、戻り値は `array (float)` タイプになります。

* いずれかのパラメーターが `NULL` の場合、`NULL` を返します。

例：

```sql

INSERT INTO t6 VALUES('[1,2,3]');
SELECT [1,2,3] + '[1.12,1000.0001, -1.2222]', c1 - [1,2,3] FROM t6;
```

結果は次のとおりです：

```shell
+---------------------------------------+--------------+
| [1,2,3] + '[1.12,1000.0001, -1.2222]' | c1 - [1,2,3] |
+---------------------------------------+--------------+
| [2.12,1002,1.7778]                    | [0,0,0]      |
+---------------------------------------+--------------+
1 row in set
```
