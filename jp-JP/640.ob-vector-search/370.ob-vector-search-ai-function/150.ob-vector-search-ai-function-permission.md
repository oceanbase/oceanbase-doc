# AI関数サービスの権限

このドキュメントでは、AI関数サービスの権限について説明します。これには、AIモデルを管理するための`AI MODEL`権限と、AI関数を呼び出すための`ACCESS AI MODEL`権限が含まれます。

## AI MODEL

AI MODEL関連の権限は、AIモデルを管理するために使用され、`CREATE AI MODEL`、`ALTER AI MODEL`、`DROP AI MODEL`の3つの権限が含まれます。

### 構文

権限付与の構文は以下のとおりです：

```sql
-- AIモデルの作成権限を付与
GRANT CREATE AI MODEL ON *.* TO 'username'@'host';

-- AIモデルの変更権限を付与
GRANT ALTER AI MODEL ON *.* TO 'username'@'host';

-- AIモデルの削除権限を付与
GRANT DROP AI MODEL ON *.* TO 'username'@'host';

GRANT CREATE AI MODEL, ALTER AI MODEL, DROP AI MODEL ON *.* TO 'username'@'host';
```

権限の取り消し構文は以下のとおりです：

```sql
-- AIモデルの作成権限を取り消す
REVOKE CREATE AI MODEL ON *.* FROM 'username'@'host';

-- AIモデルの変更権限を取り消す
REVOKE ALTER AI MODEL ON *.* FROM 'username'@'host';

-- AIモデルの削除権限を取り消す
REVOKE DROP AI MODEL ON *.* FROM 'username'@'host';

-- 権限を確認する
SHOW GRANTS FOR 'username'@'host';
```

### 例

1. ユーザーの作成

    ```sql
    CREATE USER test_ai_user@'%' IDENTIFIED BY '123456';
    ```

2. test_ai_userユーザーにログインします。

    ```sql
    obclient -h 127.0.0.1 -P 2881 -u test_ai_user@'%' -p *** -A -D test;
    ```

3. `CREATE_AI_MODEL_ENDPOINT` プログラムを呼び出します。

    ```sql
    CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
           'user_ai_model_endpoint_1', '{
             "ai_model_name": "my_model1",
             "url": "https://api.deepseek.com",
             "access_key": "sk-xxxxxxxxxxxx",
             "request_model_name": "deepseek-chat",
             "provider": "deepseek"
           }');
    ```

    `CREATE AI MODEL` 権限がないため、エラーが発生します。

    ```shell
    ERROR 42501: Access denied; you need (at least one of) the create ai model endpoint privilege(s) for this operation
    ```

4. `test_ai_user` ユーザーに `CREATE AI MODEL` 権限を付与します。

    ```sql
    GRANT CREATE AI MODEL ON *.* TO test_ai_user@'%';
    ```

5. 権限を確認します。

    ```sql
    CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
           'user_ai_model_endpoint_1', '{
             "ai_model_name": "my_model1",
             "url": "https://api.deepseek.com",
             "access_key": "sk-xxxxxxxxxxxx",
             "request_model_name": "deepseek-caht",
             "provider": "deepseek"
           }');
    ```

    実行は成功しました。

## ACCESS AI MODEL

`ACCESS AI MODEL` 権限は、AI関数を呼び出すために使用されます。これには `AI_COMPLETE`、`AI_EMBED`、`AI_RERANK` の3つの関数が含まれます。

### 構文

権限を付与する構文は次のとおりです：

```sql
GRANT ACCESS AI MODEL ON *.* TO 'username'@'host';
```

権限を取り消す構文は次のとおりです：

```sql
REVOKE ACCESS AI MODEL ON *.* FROM 'username'@'host';
```

### 例

1. `AI_COMPLETE` 関数を呼び出します。

    ```sql
    SELECT AI_COMPLETE("ob_complete","あなたは翻訳の達人です。以下のテキストを英語に翻訳してください：{{Hello World.}}。出力は翻訳結果のみを含めてください") as ans;
    ```

    `ACCESS AI MODEL` 権限がないため、エラーが発生します。

    ```shell
    ERROR 42501: Access denied; you need (at least one of) the access ai model endpoint privilege(s) for this operation
    ```

2. `test_ai_user` ユーザーに `ACCESS AI MODEL` 権限を付与します。

    ```sql
    GRANT ACCESS AI MODEL ON *.* TO test_ai_user@'%';
    ```

3. 権限を検証します。

    ```sql
    SELECT AI_COMPLETE("ob_complete","あなたは翻訳の達人です。以下のテキストを英語に翻訳してください：{{Hello world.}}。出力は翻訳結果のみを含めてください") as ans;
    ```

    実行が成功しました。

    ```sql
    ```shell
    +----------------+
    | ans            |
    +----------------+
    | "Hello world." |
    +----------------+
    1 row in set
    ```
