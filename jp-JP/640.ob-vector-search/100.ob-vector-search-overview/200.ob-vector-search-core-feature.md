# ベクトル検索のコア機能

OceanBaseは、Embeddingベクトルデータの格納、インデックス作成、検索機能を提供します。具体的には以下のとおりです。

|**コア機能**|**説明**|
|---|---|
| ベクトルデータ型 | <ul><li>最大16,000次元のfloat型密ベクトルデータの格納をサポートします。</li><li>疎ベクトルデータの格納をサポートします。</li></ul> |
| ベクトルインデックス | <ul><li>厳密検索と近似最近傍探索をサポートします。</li><li>L2距離、内積、コサイン類似度の計算をサポートします。</li><li>HNSW/HNSW_SQ/HNSW_BQインデックスをサポートし、インデックス列の最大次元は4096です。HNSW_BQインデックスはV4.4.0バージョンからサポートされます。</li><li>IVF/IVF_PQインデックスをサポートし、インデックス列の最大次元は4096です。</li></ul> |
| ベクトル検索SQL演算子 | ベクトルの加算、減算、乗算、比較、集約などの基本的な演算子をサポートします。 |
| ベクトルと全文のハイブリッド検索 | <ul><li>全文インデックスとベクトルインデックスのハイブリッド検索をサポートします。</li><li>ベクトルデータとスカラーデータのハイブリッド検索をサポートします。</li></ul> |

## 使用上の制限と注意事項

* OceanBaseはデフォルトでNULL first比較モードを採用しているため、NULL値を含む列をソートするとNULL値が先頭に配置されます。クエリ実行時には`NOT NULL`条件を追加することを推奨します。
