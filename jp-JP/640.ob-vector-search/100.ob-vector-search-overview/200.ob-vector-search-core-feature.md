# ベクトル検索コア機能

OceanBase は、Embedding ベクトルデータのストレージ、インデックス、検索機能を提供します。具体的には以下を含みます：

|**コア機能**|**説明**|
|---|---|
| ベクトルデータ型 | 最大 16,000 次元の float ベクトルデータストレージをサポートします。 |
| ベクトルインデックス | <ul><li>正確な検索と近似近傍検索をサポートします。</li><li>L2 距離、内積、コサイン類似度の計算をサポートします。</li><li>HNSW インデックス / HNSW_SQ インデックスをサポートし、インデックス列の最大次元は 4,096 です。</li><li>IVF インデックス / IVF_SQ インデックス / IVF_PQ インデックス (実験機能) をサポートし、インデックス列の最大次元は 4,096 です。</li></ul> |
| ベクトル検索 SQL 演算子 | ベクトルの加算、減算、比較、集約などの基礎的計算の演算子をサポートします。 |

## 使用制限

* OceanBase はデフォルトで NULL first の比較モードを採用しているため、NULL 値をソートするときは、NULL 値が先頭に置かれます。クエリを実行する際は、`NOT NULL` 条件を追加することを推奨します。
