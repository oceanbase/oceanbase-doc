# OceanBase TPC-H性能テストレポート

## テスト環境 (Alibaba Cloud ECS)

* 3ノードのハードウェア構成

    | サービスタイプ | ECSタイプ | インスタンス数 | マシンコア数 | メモリ |
    | --- | --- | --- | --- | --- |
    | OceanBaseデータベース | ecs.g7.8xlarge | 3 | 32C | 128G <br>各マシンのシステムディスクは300G、さらに2枚の400GクラウドディスクをclogディスクとDataディスクとしてマウントし、パフォーマンスレベルはPL1です。|
    | TPC-H | ecs.g7.8xlarge | 1 | 32C | 128G |

* 3ノードのテナント仕様

    ```sql
    CREATE RESOURCE UNIT tpch_unit max_cpu 26, memory_size '100g'
    CREATE RESOURCE POOL tpch_pool unit = 'tpch_unit', unit_num = 1, zone_list=('zone1','zone2','zone3');
    CREATE TENANT tpch_mysql resource_pool_list=('tpch_pool'),  zone_list('zone1', 'zone2', 'zone3'), primary_zone=RANDOM, locality='F@zone1,F@zone2,F@zone3' set variables ob_compatibility_mode='mysql', ob_tcp_invited_nodes='%';
    ```

* ソフトウェアバージョン

    | サービスタイプ | ソフトウェアバージョン |
    | --- | --- |
    | OceanBaseデータベース |  <ul><li>Enterprise Edition：OceanBase 4.2.2.0</li> <li>Community Edition：OceanBase_CE 4.2.2.0 </li></ul>|
    | TPC-H | V3.0.0 |
    | OS | CentOS Linux release 7.9.2009 (Core) |

## テストプラン

* obdを使用してOceanBaseデータベースクラスタをデプロイします。TPC-Hクライアントは1台のマシンにデプロイし、クライアントの負荷マシンとして使用します。ODPのデプロイは不要であり、テスト時には任意のマシンに直接接続するだけで済みます。

* 3ノードのOceanBaseクラスタのデプロイ規模は1：1：1です。デプロイが成功したら、まずTPCHテスト用の新しいテナントとユーザーを作成します（sysテナントはクラスタを管理するための組み込みシステムテナントであり、直接sysテナントを使用してテストを行わないでください）。テナントの`primary_zone`をRANDOMに設定します。

* テストデータ量：100G。

* テスト手順の詳細については、[OceanBaseデータベースTPC-Hテスト](../1100.performance-test/100.run-the-tpc-h-benchmark-on-oceanbase-database.md)を参照してください。
