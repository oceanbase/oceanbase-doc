# OceanBase Sysbench性能テストレポート

## テスト環境 (Alibaba Cloud ECS)

* ハードウェア構成

    | サービスタイプ | ECSタイプ | インスタンス数 | マシンコア数 | メモリ |
    | --- | --- | --- | --- | --- |
    | OceanBaseデータベース | ecs.g7.8xlarge | 3 | 32C | 128G <br>各マシンのシステムディスクは300G、さらに2枚の400GクラウドディスクをマウントしてclogディスクとDataディスクとして使用。パフォーマンスレベルはPL1です。|
    | Sysbench | ecs.c7.4xlarge | 1 | 16c | 32g |
    | ODP | ecs.c7.16xlarge | 1 | 64C | 128G |

* テナント仕様

    ```sql
    CREATE RESOURCE UNIT sysbench_unit max_cpu 26, memory_size '100g'
    CREATE RESOURCE POOL sysbench_pool unit = 'sysbench_unit', unit_num = 1, zone_list=('zone1','zone2','zone3');
    CREATE TENANT sysbench_tenant resource_pool_list=('sysbench_pool'),  zone_list('zone1', 'zone2', 'zone3'), primary_zone=RANDOM, locality='F@zone1,F@zone2,F@zone3' set variables ob_compatibility_mode='mysql', ob_tcp_invited_nodes='%';
    ```

* ソフトウェアバージョン

    | サービスタイプ | ソフトウェアバージョン |
    | --- | --- |
    | OceanBaseデータベース | <ul><li>Enterprise Edition：OceanBase 4.2.2.0</li><li>Community Edition：OceanBase_CE 4.2.2.0 </li></ul> |
    | ODP | OceanBase 4.2.1 |
    | Sysbench | 1.0.20 |

## テストプラン

1. obdを使用してOceanBaseクラスタをデプロイし、ODPは別のマシンに単独でデプロイします。

2. OceanBaseクラスタの規模は1：1：1とし、デプロイが成功したら、まずSysbenchテスト用の新しいテナントとユーザーを作成します（sysテナントはクラスタを管理するための組み込みシステムテナントであり、直接sysテナントを使用してテストを行わないでください）。テナントの`primary_zone`をRANDOMに設定します。RANDOMとは、新しく作成されるテーブルパーティションのリーダーがこの3台のマシンにランダムに割り当てられることを意味します。

3. Sysbenchクライアントを起動し、`point_select`、`read_write`、`read_only`、`write_only`の各テストを実行します。

4. 各ラウンドのテストでは`--time`を60秒に設定し、スレッド数は`32/64/128/256/512/1024`から選択できます。

### テスト仕様

```shell
--mysql-db=test
--table_size=1000000
--tables=30
--threads=32/64/128/256/512/1024
--report-interval=10
--time=60
--db-ps-mode=disable
--rand-type=uniform
```
