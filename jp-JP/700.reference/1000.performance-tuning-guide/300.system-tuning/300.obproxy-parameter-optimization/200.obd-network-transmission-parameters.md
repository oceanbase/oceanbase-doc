# ネットワーク転送関連パラメータ

|             パラメータ              |                                                                    説明                                                                    |  建議   |
|------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|-------|
| server_tcp_user_timeout      | OBProxyとOBServerを接続するTCPユーザータイムアウト。デフォルト値は0秒                                                                                         | デフォルト値のまま |
| client_tcp_user_timeout      | OBProxyとClientを接続するTCPユーザータイムアウト。デフォルト値は0秒                                                                                           | デフォルト値のまま |
| client_max_connections       | OBProxyが許可するクライアントの最大接続数。デフォルト値は8192                                                                                                          | デフォルト値のまま |
| connect_observer_max_retries | OBProxyがOBServerに再接続する最大試行回数。デフォルト値は3                                                                                                         | デフォルト値のまま |
| observer_query_timeout_delta | ネットワーク転送遅延によるOBServerの`ob_query_timeout`設定値の増分。デフォルト値は20秒、取り得る範囲は[1, 39]秒   | デフォルト値のまま |
| sock_option_flag_out         | OBProxyとOBServer間のTCPパラメータで、2進数ビットで表されます。<ul><li>bit 0：2進数の最初のビット。1の場合、<code>no_delay</code>を有効にします。</li><li>bit 1：2進数の2番目のビット。1の場合、<code>keepalive</code>を有効にします。</li><li>bit 2：2進数の3番目のビット。1の場合、<code>linger_on</code>を有効にします。</li></ul>ソフトウェアのバージョンによって、このパラメータのデフォルト値は異なります。<ul><li>ODP 1.8.x系では、デフォルト値は1、すなわちbit 0が1で、<code>no_delay</code>が有効であることを意味します。 </li><li>ODP 3.x系では、デフォルト値は3、すなわちbit 0とbit 1が共に1で、<code>no_delay</code>と<code>linger_on</code>が同時に有効であることを意味します。</li></ul>| <ul><li>ODP 1.8.x系では、デフォルト値3を推奨します。 </li><li>ODP 3.x系では、デフォルト値のままにしてください。 </li></ul>|
| server_tcp_keepidle          | OBProxyとOBServer間のTCP接続で、keepaliveプローブが開始されるまでのアイドル時間。デフォルト値は5秒                                                                                | デフォルト値のまま |
| server_tcp_keepintvl         | OBProxyとOBServer間のTCP keepaliveプローブパケット間の時間間隔。デフォルト値は5秒。                                                                                  | デフォルト値を維持 |
| server_tcp_keepcnt           | OBProxyとOBServer間でTCP keepaliveパケットを最大で送信する数。デフォルト値は5                                                                                      | デフォルト値を維持 |
| client_sock_option_flag_out  | クライアントとOBProxy間のTCPパラメータで、2進数ビットで表されます。<ul><li>bit 0：2進数の最初のビットが1の場合、<code>no_delay</code>を有効にします。</li><li>bit 1：2進数の2番目のビットが1の場合、<code>keepalive</code>を有効にします。</li><li>bit 2：2進数の3番目のビットが1の場合、<code>linger_on</code>を有効にします。</li></ul>ソフトウェアのバージョンによって、このパラメータのデフォルト値は異なります。<ul><li>ODP V1.8.x系では、デフォルト値は0で、いずれの機能も有効になっていないことを意味します。 </li><li>ODP V3.x系では、デフォルト値は2で、bit 0が0、bit 1が1の場合、<code>keepalive</code>が有効になります。</li></ul>| <code>no_delay</code>と<code>linger_on</code>を同時に有効にするため、bit 0とbit 1の両方が1である3に設定することを推奨します。 |
| client_tcp_keepidle          | クライアントとOBProxy間のTCP接続で、keepaliveプローブを開始するまでのアイドル時間。デフォルト値は5秒。                                                                                      | デフォルト値を維持 |
| client_tcp_keepintvl         | クライアントとOBProxy間のTCP keepaliveプローブパケット間の時間間隔。デフォルト値は5秒。                                                                                        | デフォルト値を維持 |
| client_tcp_keepcnt           | クライアントとOBProxy間でTCP keepaliveパケットを最大で送信する数。デフォルト値は5                                                                                            | デフォルト値を維持 |
