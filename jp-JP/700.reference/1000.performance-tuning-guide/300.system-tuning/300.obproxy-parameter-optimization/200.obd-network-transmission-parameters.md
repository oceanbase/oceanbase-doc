# ネットワーク転送関連パラメータ

|             パラメータ              |                                                                    説明                                                                    |  建議   |
|------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|-------|
| server_tcp_user_timeout      | OBProxyとOBServerの接続におけるTCPユーザー時間アウト。デフォルト値は0秒です                                                                                         | デフォルト値を維持 |
| client_tcp_user_timeout      | OBProxyとClientの接続におけるTCPユーザー時間アウト。デフォルト値は0秒です                                                                                           | デフォルト値を維持 |
| client_max_connections       | OBProxyが許容できるクライアントの最大接続数。デフォルト値は8192です                                                                                                          | デフォルト値を維持 |
| connect.Observer_max_retries | OBProxyがOBServerに再接続する際の最大リトライ回数。デフォルト値は3です                                                                                                         | デフォルト値を維持 |
| observer_query_timeout_delta | ネットワーク転送遅延。OBServerの`ob_query_timeout`に設定される増分値。デフォルト値は20秒で、値の範囲は[1, 39]秒です。」 | デフォルト値を維持 |
| sock_option_flag_out         | OBProxyとOBServer間のTCPパラメータ。バイナリビットで表されます。<ul><li>bit 0：バイナリの最初のビット。1の場合、<code>no_delay</code>を有効にします。</li><li>bit 1：バイナリの2番目のビット。1の場合、<code>keepalive</code>を有効にします。</li><li>bit 2：バイナリの3番目のビット。1の場合、<code>linger_on</code>を有効にします。</li></ul>異なるソフトウェアバージョンによって、このパラメータのデフォルト値は以下のとおりです。<ul><li>ODP V1.8.xバージョンでは、デフォルト値は1、つまりbit 0が1であり、<code>no_delay</code>を有効にすることを意味します。 </li><li>ODP V3.xバージョンでは、デフォルト値は3、つまりbit 0とbit 1が共に1であり、<code>no_delay</code>と<code>linger_on</code>を同時に有効にすることを意味します。 </li></ul>| <ul><li>ODP V1.8.xバージョンでは、3に設定することを推奨します。 </li><li>ODP V3.xバージョンでは、デフォルト値を維持することを推奨します。 </li></ul>|
| server_tcp_keepidle          | OBProxyとOBServerのTCPでkeepaliveプローブを開始する前のアイドル時間。デフォルト値は5秒です。</p> | デフォルト値を維持 |
| server_tcp_keepintvl         | OBProxyとOBServer間のTCP keepaliveパケット間隔。デフォルト値は5秒です。（単位：秒）                                                                                  | デフォルト値を維持 |
| server_tcp_keepcnt           | OBProxyとOBServer間で送信する最大keepaliveパケット数。デフォルト値は5です。</li> | デフォルト値を維持 |
| client_sock_option_flag_out  | クライアントとOBProxy間のTCPパラメータ。バイナリビットで表されます。<ul><li>bit 0：バイナリの最初のビット。1の場合、<code>no_delay</code>が有効になります。</li><li>bit 1：バイナリの2番目のビット。1の場合、<code>keepalive</code>が有効になります。</li><li>bit 2：バイナリの3番目のビット。1の場合、<code>linger_on</code>が有効になります。</li></ul>異なるソフトウェアバージョンによって、このパラメータのデフォルト値は以下のとおりです。<ul><li>ODP V1.8.x系では、デフォルト値は0であり、いずれの機能も有効になっていないことを意味します。</li><li>ODP V3.x系では、デフォルト値は2であり、bit 0が0、bit 1が1の場合、<code>keepalive</code>が有効になります。</li></ul>| デフォルト値の3を推奨します。これは、bit 0とbit 1が共に1であり、<code>no_delay</code>と<code>linger_on</code>が同時に有効になることを意味します。 |
| client_tcp_keepidle          | クライアントとOBProxy間のTCP keepaliveパケット送信開始前のidle時間。デフォルト値は5秒です。</li> | デフォルト値を維持 |
| client_tcp_keepintvl         | クライアントとOBProxy間のTCP keepaliveパケット間隔。デフォルト値は5秒です。</li> | デフォルト値を維持 |
| client_tcp_keepcnt           | クライアントとOBProxy間で送信する最大keepaliveパケット数。デフォルト値は5です。</li> | デフォルト値を維持 |
