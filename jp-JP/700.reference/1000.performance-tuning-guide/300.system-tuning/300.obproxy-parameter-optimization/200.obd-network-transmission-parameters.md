# ネットワーク転送関連パラメータ

|             パラメータ              |                                                                    説明                                                                    |  建議   |
|------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|-------|
| server_tcp_user_timeout      | OBProxyとOBServerを接続するTCPユーザータイムアウト。デフォルト値は0秒                                                                                         | デフォルト値のまま |
| client_tcp_user_timeout      | OBProxyとClientを接続するTCPユーザータイムアウト。デフォルト値は0秒                                                                                           | デフォルト値のまま |
| client_max_connections       | OBProxyが許容するクライアントの最大接続数。デフォルト値は8192                                                                                                          | デフォルト値のまま |
| connect_observer_max_retries | OBProxyがOBServerに再接続する最大試行回数。デフォルト値は3                                                                                                         | デフォルト値のまま |
| observer_query_timeout_delta | ネットワーク転送遅延。OBServerの`ob_query_timeout`に設定される増分。デフォルト値は20秒、範囲は[1, 39]秒   | デフォルト値のまま |
| sock_option_flag_out         | OBProxyとOBServer間のTCPパラメータで、ビットで表現：<ul><li>bit 0：ビットの最初のビット。1の場合、<code>no_delay</code>を有効にします。</li><li>bit 1：ビットの2番目のビット。1の場合、<code>keepalive</code>を有効にします。</li><li>bit 2：ビットの3番目のビット。1の場合、<code>linger_on</code>を有効にします。</li></ul>ソフトウェアのバージョンによって、このパラメータのデフォルト値は異なります：<ul><li>ODP 1.8.x系では、デフォルト値は1、つまりbit 0が1で、<code>no_delay</code>が有効になります。 </li><li>ODP 3.x系では、デフォルト値は3、つまりbit 0とbit 1が共に1で、<code>no_delay</code>と<code>linger_on</code>が同時に有効になります。</li></ul>| <ul><li>ODP 1.8.x系では、デフォルト値3を推奨します。 </li><li>ODP 3.x系では、デフォルト値のままにしてください。 </li></ul>|
| server_tcp_keepidle          | OBProxyとOBServer間のTCP接続で、keepaliveプローブを送信する前のアイドル時間。デフォルト値は5秒                                                                                   | デフォルト値のまま |
| server_tcp_keepintvl         | OBProxyとOBServer間のTCP接続で、2つのkeepaliveプローブパケットを送信する間隔時間。デフォルト値は5秒                                                                                   | デフォルト値のまま |
| server_tcp_keepcnt           | OBProxyとOBServer間のTCP接続で、送信可能なkeepaliveパケットの最大数。デフォルト値は5                                                                                   | デフォルト値のまま |
| client_sock_option_flag_out  | クライアントとOBProxy間のTCP接続で、ビットで表現：<ul><li>bit 0：ビットの最初のビット。1の場合、<code>no_delay</code>を有効にします。</li><li>bit 1：ビットの2番目のビット。1の場合、<code>keepalive</code>を有効にします。</li><li>bit 2：ビットの3番目のビット。1の場合、<code>linger_on</code>を有効にします。</li></ul>ソフトウェアのバージョンによって、このパラメータのデフォルト値は異なります：<ul><li>ODP V1.8.x系では、デフォルト値は0で、いずれの機能も有効になりません。 </li><li>ODP V3.x系では、デフォルト値は2で、bit 0が0、bit 1が1の場合、<code>keepalive</code>が有効になります。</li></ul>| デフォルト値3を推奨します。これはbit 0とbit 1が共に1で、<code>no_delay</code>と<code>linger_on</code>が同時に有効になることを意味します。 |
| client_tcp_keepidle          | クライアントとOBProxy間のTCP接続で、keepaliveプローブを送信する前のアイドル時間。デフォルト値は5秒                                                                                   | デフォルト値のまま |
| client_tcp_keepintvl         | クライアントとOBProxy間のTCP接続で、2つのkeepaliveプローブパケットを送信する間隔時間。デフォルト値は5秒                                                                                   | デフォルト値のまま |
| client_tcp_keepcnt           | クライアントとOBProxy間のTCP接続で、送信可能なkeepaliveパケットの最大数。デフォルト値は5                                                                                   | デフォルト値のまま |
