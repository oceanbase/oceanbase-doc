# CPU関連パラメータ

|             パラメータ             |                                                   説明                                                   |                             推奨                              |
|-----------------------------|--------------------------------------------------------------------------------------------------------|-------------------------------------------------------------|
| work_thread_num             | OBProxyのワーカースレッド数。CPU使用率に大きな影響を与えます。デフォルト値は128です。変更後はOBProxyを再起動する必要があります                                                    | 環境に応じて動的に調整できます。OBProxyのCPU使用量の上限は`work_thread_num`の値となります          |
| task_thread_num             | ブロックやRSリスト情報の取得などを行うバックグラウンドスレッドの数です。デフォルト値は2です。変更後はOBProxyを再起動する必要があります                                                        | デフォルト値を維持します                                                       |
| block_thread_num            | ブロックスレッド数です。デフォルト値は1です。変更後はOBProxyを再起動する必要があります                                                                       | デフォルト値を維持します                                                       |
| grpc_thread_num             | gRPCスレッド数です。デフォルト値は8です。変更後はOBProxyを再起動する必要があります                                                                        | デフォルト値を維持します                                                       |
| net_accept_threads          | accept処理を実行するスレッド数です。デフォルト値は2です。変更後はOBProxyを再起動する必要があります                                                                  | デフォルト値を維持します                                                       |
| automatic_match_work_thread | 指定された`work_thread_num`を無視し、CPU数に応じてスレッド数を自動的に調整します。このオプションがtrueの場合、上限は`work_thread_num`の値となります。デフォルト値はtrueです。変更後はOBProxyを再起動する必要があります | <ul><li><code>automatic_match_work_thread=false</code> の場合、構成パラメータ <code>work_thread_num</code> の値を使用します；</li><li><code>automatic_match_work_thread=true</code> の場合、<code>MIN(マシンCPU、work_thread_num)</code> の値を使用します。</li></ul>例えば、構成パラメータ <code>work_thread_num</code> の値を大きく設定した場合。<ul><li>ハイブリッドデプロイメントでは、<code>automatic_match_work_thread=true</code> を推奨します；</li><li>単独デプロイメントでは、<code>automatic_match_work_thread=false</code> を設定することで、ODPがマシン全体を占有できます。</li></ul> |
| enable_compression_protocol | 圧縮を無効にして、OBProxyのCPU使用率を削減します。有効にするには、OBProxyマシンを再起動する必要があります                                                          | Falseに設定することを推奨します                                                 |

`sys`テナント内で、OBProxyのポート2883を介してOceanBaseクラスタに接続し、`ALTER PROXYCONFIG SET`および`SHOW PROXYCONFIG LIKE`ステートメントを使用して上記のパラメータを変更および確認できます。

例：

```shell
obclient> ALTER PROXYCONFIG SET automatic_match_work_thread = False;
```

```shell
obclient> SHOW PROXYCONFIG LIKE 'work_thread_num';
```
