# ノードルーティング関連パラメータ

|             パラメータ              |                                                                                                                  説明                                                                                                                  |     推奨値      |
|------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------|
| enable_index_route           | OBProxyがグローバルインデックスキーに基づくグローバルインデックステーブルのルーティングを有効にするかどうかを設定します。<li>True：有効<li>（デフォルト）False：無効    | デフォルト値を維持       |
| enable_pl_route              | OBProxyがPLルーティングを有効にするかどうかを設定します。<li>（デフォルト）True：有効<li>False：無効  | Falseに設定することを推奨 |
| enable_reroute               | OBProxyが再ルーティングを有効にするかどうかを設定します。初回ルーティングでヒットしない場合、リクエストを対応するOBServerに再転送します。<li>True：有効<li>（デフォルト）False：無効<blockquote>**説明**<br >enable_ob_protocol_v2パラメータでOBProxyとOBServer間でOceanBase 2.0プロトコルを有効にした後、再ルーティング機能が有効になります。</blockquote> | デフォルト値を維持       |
| enable_partition_table_route | OBProxyがパーティションテーブルのルーティングを有効にするかどうかを設定します。<li>（デフォルト）True：有効<li>False：無効 | デフォルト値を維持 |
| server_routing_mode          | OBProxyのルーティングモードです。以下が含まれます：<li>（デフォルト）oceanbase：OceanBaseモード<li>random：ランダムモード。リクエストを送信するOBServerをランダムに選択<li>mock：mockモード。OBProxyのtest_server_addrパラメータでIPルーティングを指定できます。"ip1:sql_port1;ip2:sql_port2"の形式で指定します。<li>mysql：MySQLモード。MySQLクラスタへの接続に使用されます   | デフォルト値を維持       |
| enable_ob_protocol_v2        | OBProxyとOBServer間でOceanBase 2.0プロトコル（OceanBaseが独自開発したMySQL圧縮プロトコルベースの伝送プロトコル）を有効にするかどうかを設定します。<li>True：OceanBase 2.0プロトコルを有効にする<li>（デフォルト）False：無効  | デフォルト値を維持       |
| routing_cache_mem_limited    | OBProxyルーティングcacheのメモリ上限を設定します。例えば、テーブルキャッシュやアドレスキャッシュなどです。値の範囲は[1KB, 100G]で、デフォルト値は128MBです。 | デフォルト値を維持       |
| enable_bad_route_reject      | ルーティングできないリクエストを拒否するかどうかを設定します。<li>True：拒否<li>（デフォルト）False：拒否しない  | デフォルト値を維持       |

`sys`テナントで`ALTER PROXYCONFIG SET`および`SHOW PROXYCONFIG LIKE`ステートメントを使用して、上記のパラメータを変更および確認できます。

例：

```shell
obclient>ALTER PROXYCONFIG SET enable_pl_route = False;
```

```shell
obclient> SHOW PROXYCONFIG LIKE 'enable_pl_route';
```
