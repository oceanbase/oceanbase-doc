# ノードルーティング関連パラメータ

|             パラメータ              |                                                                                                                  説明                                                                                                                  |     推奨値      |
|------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------|
| enable_index_route           | OBProxyがグローバルインデックスキーに基づくグローバルインデックステーブルルーティングを有効にするかどうかを設定します。<li>True：有効<li>（デフォルト）False：無効    | デフォルト値のまま       |
| enable_pl_route              | OBProxyがPLルーティングを有効にするかどうかを設定します。<li>（デフォルト）True：有効<li>False：無効  | Falseを推奨 |
| enable_reroute               | OBProxyが再ルーティングを有効にするかどうかを設定します。最初のルーティングでヒットしない場合、リクエストを対応するOBServerに再転送します。<li>True：有効<li>（デフォルト）False：無効<blockquote>**説明**<br >enable_ob_protocol_v2パラメータを使用して、OBProxyとOBServer間でOceanBase 2.0プロトコルを有効にした後にのみ、再ルーティング機能が有効になります。</blockquote> | デフォルト値のまま       |
| enable_partition_table_route | OBProxyがパーティションテーブルルーティングを有効にするかどうかを設定します。<li>（デフォルト）True：有効<li>False：無効 | デフォルト値のまま |
| server_routing_mode          | OBProxyのルーティングモード。以下が含まれます：<li>（デフォルト）oceanbase：OceanBaseモード<li>random：ランダムモード。ランダムにOBServerを選択してリクエストを送信<li>mock：mockモード。OBProxyのtest_server_addrパラメータを使用してIPルーティングを指定できます。形式は「ip1:sql_port1;ip2:sql_port2」です。<li>mysql：MySQLモード。MySQLクラスタへの接続に使用されます   | デフォルト値のまま       |
| enable_ob_protocol_v2        | OBProxyとOBServer間でOceanBase 2.0プロトコル（OceanBase独自のMySQL圧縮プロトコルベースの転送プロトコル）を有効にするかどうかを設定します。<li>（デフォルト）True：OceanBase 2.0プロトコルを有効にする<li>False：無効  | デフォルト値のまま       |
| routing_cache_mem_limited    | OBProxyルーティングキャッシュのメモリ上限を設定します。例えば、テーブルキャッシュ、アドレスキャッシュなどです。値の範囲は[1KB, 100G]で、デフォルト値は128MBです。 | デフォルト値のまま       |
| enable_bad_route_reject      | ルーティング不可能なリクエストを拒否するかどうかを設定します。<li>True：拒否<li>（デフォルト）False：拒否しない  | デフォルト値のまま       |

`sys`テナント内で、`ALTER PROXYCONFIG SET`および`SHOW PROXYCONFIG LIKE`ステートメントを使用して上記の構成パラメータを変更および確認できます。

例：

```unknow
obclient>ALTER PROXYCONFIG SET enable_pl_route = False;
```

```unknow
obclient> SHOW PROXYCONFIG LIKE 'enable_pl_route';
```
