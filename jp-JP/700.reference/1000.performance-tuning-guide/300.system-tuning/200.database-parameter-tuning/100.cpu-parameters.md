# CPU関連パラメータ

|                パラメータ          |    説明     |            推奨値         |
|------------------------------------|----------------------------------|----------------------------------------------------------------------------------------------------|
| workers_per_cpu_quota              | workers_per_cpu_quota \* tenant max_cpu = テナントに割り当て可能な最大スレッド数  | ここでの最大スレッド数は割り当てられる、使用可能な数であり、同時実行可能な最大スレッド数ではありません。このパラメータは通常調整不要です。                                                      |
| net_thread_count                   | クライアントリクエストを受信するネットワークスレッド数                    | 即時に反映されます。top -HでMySQLIOスレッドの使用効率を確認します。使用率が90%を超える場合、リクエスト受信スレッドがボトルネックとなっている可能性があるため、このパラメータを引き上げることを推奨します。すべてのスレッドが50%未満の場合は、スレッドスイッチングのオーバヘッドを低減するため、このパラメータを引き下げることを推奨します |
| auto_leader_switch_interval        | 自動リーダー切り替えバックグラウンドスレッドの実行間隔時間の設定                 | 大きく設定することを推奨します                                                                                               |
| enable_early_lock_release          | 早期ロック解放を有効にする                          | ヒートスポット行のシナリオでは有効にすることを推奨します                                                                                          |
| enable_monotonic_weak_read         | 単調読み取りを有効にする                            | パフォーマンスシナリオでは無効にすることを推奨します                                                                                           |
| weak_read_version_refresh_interval | 弱い一貫性読み取りのバージョン番号のリフレッシュ間隔                    | パフォーマンスシナリオでは無効にすることを推奨します                                                            |
| enable_sql_audit                   | SQL Audit機能を有効にする                  | 本番環境では必ず有効にしてください。パフォーマンステストシナリオでは、必要に応じて無効にすることもできます                                                                              |
| enable_perf_event                  | 情報収集を有効にする                           | 本番環境では必ず有効にしてください。パフォーマンステストシナリオでは、必要に応じて無効にすることもできます                                                                              |
| enable_record_trace_log            | Trace Log機能を有効にする                  | 本番環境では、Perf EventとSQL Audit機能を有効にした場合、このパラメータは無効にできます                                                      |
| _trace_control_info                | 全リンク追跡機能を有効にする | パフォーマンステストシナリオでは、必要に応じてこの機能を無効にすることができます。 |
