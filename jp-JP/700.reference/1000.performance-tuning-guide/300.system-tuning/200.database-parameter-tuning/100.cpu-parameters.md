# CPU関連パラメータ

|                パラメータ                 |                説明                |                                                 推奨                                                 |
|------------------------------------|----------------------------------|----------------------------------------------------------------------------------------------------|
| workers_per_cpu_quota              | このパラメータは、テナントのmax_cpuに等しい。テナントが割り当てることができる最大スレッド数を示す。 | ここでの最大スレッド数は割り当てられたものであり、実際に使用可能な数ではなく、同時に実行される最大スレッド数ではない。このパラメータは通常調整しない。                                                      |
| net_thread_count                   | クライアントリクエストを受信するネットワークスレッド数                    | リスタート後に有効になる。top -HコマンドでMySQL I/Oスレッドの使用効率を確認する。使用率が90％を超える場合、リクエスト受信スレッドがボトルネックとなっている可能性があるため、このパラメータを増やすことを推奨する。すべてのスレッドの使用率が50％未満の場合、スレッド切り替えのオーバーヘッドを軽減するために、このパラメータを減らすことを推奨する |
| auto_leader_switch_interval        | 自動リーダー切り替えバックグラウンドスレッドの作業間隔時間を設定                 | 大きく設定することを推奨する                                                                                               |
| enable_early_lock_release          | 早期ロック解放機能を有効にする                          | ヒートスポット行のシナリオでは有効にすることを推奨する                                                                                          |
| enable_monotonic_weak_read         | 単調読み取り機能を有効にする                            | パフォーマンスシナリオでは無効にすることを推奨する                                                                                           |
| weak_read_version_refresh_interval | 弱い一貫性読み取りのバージョン番号のリフレッシュ周期                    | パフォーマンスシナリオでは無効にすることを推奨します                                                            |
| enable_sql_audit                   | SQL監査機能を有効にする                  | 本番環境では必須であり、パフォーマンステストシナリオでは必要に応じて無効にすることができる。                                                                              |
| enable_perf_event                  | 情報収集機能を有効にする                           | 本番環境では必須であり、パフォーマンステストシナリオでは必要に応じて無効にすることができる。                                                                              |
| enable_record_trace_log            | Trace Log機能を有効にする                  | 本番環境では、Perf EventおよびSQL Audit機能を有効にした場合、このパラメータを無効にすることができる。                                                      |
| _trace_control_info | 全リンクトレース機能を有効にする | パフォーマンステストシナリオでは、必要に応じてこの機能を無効にすることができます。 |
