# ネットワーク転送関連パラメータ

|                     パラメータ                      |               説明                |                        推奨値                        |
|----------------------------------------------|---------------------------------|--------------------------------------------------|
| __easy_memory_limit                          | 単一observer宛のRPCパケットのメモリ上限 | デフォルトは4G。大規模クエリでは値を引き上げることを推奨します                                   |
| ob_proxy_readonly_transaction_routing_policy | Proxyによるトランザクションのルーティングが読み取り専用ステートメントの影響を受けるかどうかを制御します      | 値をFalseに変更することを推奨します。これは、Proxyによるトランザクションのルーティングが、実際に最初にトランザクションを開始したステートメントに基づくことを意味します   |
|
