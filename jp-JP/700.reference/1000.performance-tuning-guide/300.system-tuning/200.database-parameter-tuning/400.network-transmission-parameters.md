# ネットワーク転送関連パラメータ

|                     パラメータ                      |               説明                |                        推奨値                        |
|----------------------------------------------|---------------------------------|--------------------------------------------------|
| __easy_memory_limit                          | 単一observerへのRPCパケットのメモリ上限 | デフォルトは4GBです。大規模クエリの場合は、この値を引き上げることを推奨します                                   |
| ob_proxy_readonly_transaction_routing_policy | Proxyによるトランザクションのルーティングが読み取り専用ステートメントに影響されるかどうかを制御する | Proxyによるトランザクションのルーティングは、実際に最初にトランザクションを開始したステートメントに基づくように、値をFalseに変更することを推奨します   |
