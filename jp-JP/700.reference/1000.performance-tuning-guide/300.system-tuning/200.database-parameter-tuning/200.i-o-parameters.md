# I/O関連パラメータ

|               パラメータ                  |                                                                                              説明                                                                                               |                    推奨値                    |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------|
| syslog_io_bandwidth_limit        | プリンターログの帯域幅を制限します                                                                                                                                                                                   | デフォルトは30MBですが、10MBに調整することを推奨します                    |
| syslog_level                     | システムログのログレベル                                                                                                                                                                                     | パフォーマンスシナリオではPERFに調整します                             |
| clog_sync_time_warn_threshold    | ログ同期時間が一定のしきい値を超えた場合に警告ログを出力します。しきい値はこのパラメータで調整可能です                                                                                                                                                              | 大きく設定することを推奨しますが、clog同期遅延問題の調査に影響を与える可能性があるため注意してください        |
| trace_log_slow_query_watermark   | トランザクション実行時間が一定のしきい値を超えた場合にslow transログを出力します。しきい値はこのパラメータで調整可能です                                                                                                                                                   | 大きく設定することを推奨します。これにより、Slow QueryのTraceログの出力を回避できます      |
| max_syslog_file_count            | observer.logの最大許容数です。上限を超えると自動的に回収されます                                                                                                                                                                   | ディスク容量に応じて調整します                               |
| enable_sql_operator_dump         | SQL層の操作（例：hash join）が中間結果をダンプすることを許可し、メモリサイズの上限を超えた場合のエラーを回避します                                                                                                                                           | APテストでは有効にすることを推奨します                                |
| _temporary_file_io_area_size     | SQL中間結果（例：hash join）がストレージ層で使用できる総サイズ                                                                                                                                                           | APテストでは大きく設定することを推奨します                                |
| builtin_db_data_verify_cycle     | マクロブロック巡回検査周期パラメータです。0に設定すると巡回検査を無効にします                                                                                                                                                                           | パフォーマンス関連シナリオでは0に設定することを推奨します                            |
| disk_io_thread_count             | ディスクI/Oスレッド数は偶数である必要があります                                                                                                                                                                               | I/O負荷に応じて適切に調整してください                            |
| enable_async_syslog              | 非同期ログを有効にします                                                                                                                                                                                        | パフォーマンスシナリオではTrueに設定することを推奨します                           |
| fuse_row_cache_priority          | 統合行キャッシュのKVキャッシュ内での優先順位です。統合キャッシュとは、OceanBaseデータベースのマルチレベルストレージアーキテクチャにおいて、行の複数の列がmemstore、mini sstable、minor sstable、sstableに存在する場合、その行をクエリする際に複数の列を統合（fuse）する必要があります。このとき、fuse row cacheを使用してその行をキャッシュし、次回のクエリ時に再度統合操作を行うことを回避します。パフォーマンスに一定の影響があります | 1より大きく設定することを推奨します。これにより、このキャッシュが早期に廃棄されるのを回避できます            |
| micro_block_merge_verify_level   | マクロブロック検証レベルです。0は検証を行わないことを表します                                                                                                                                                                             | パフォーマンスシナリオでは0に設定できますが、本番システムでは変更を推奨しません                   |
| compaction_low_thread_score   | 低優先順位Compactionの並列スレッド数です。低優先順位とは、Major SSTableに対してCompaction操作を行うことを指します  | デフォルトは0で、デフォルトで6個の並列を意味します。並列数を向上させる必要がある場合は、このパラメータを適宜大きく調整できます。 |
| compaction_mid_thread_score   | 中優先順位Compactionの並列スレッド数です。中優先順位とは、Minor SSTableに対してCompaction操作を行うことを指します  | デフォルトは0で、デフォルトで6個の並列を意味します。並列数を向上させる必要がある場合は、このパラメータを適宜大きく調整できます。 |
| compaction_high_thread_score   | 高優先順位Compactionの並列スレッド数です。高優先順位とは、Mini SSTableに対してCompaction操作を行うことを指します  | デフォルトは0で、デフォルトで6個の並列を意味します。並列数を向上させる必要がある場合は、このパラメータを適宜大きく調整できます。 |
