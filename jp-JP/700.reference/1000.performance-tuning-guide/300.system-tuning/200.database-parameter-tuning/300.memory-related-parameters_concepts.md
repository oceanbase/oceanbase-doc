# メモリ関連パラメータ

|                  パラメータ                   |             説明              |                                                               推奨                                                                |
|----------------------------------------|-----------------------------|---------------------------------------------------------------------------------------------------------------------------------|
| memory_chunk_cache_size                | Observer cache 2 M 内存块的大小   | デフォルト値は0です。デフォルト値のままにしておくことを推奨します                                                                                                                  |
| memory_limit_percentage                | OceanBaseデータベースがシステムメモリ全体に占める割合      | OceanBaseデータベースで利用可能なメモリ量を増やします                                                                                                          |
| memstore_limit_percentage              | MemStoreがテナントメモリに占める割合（このメモリは専有ではない）     | MemStoreの容量をできるだけ大きく設定してください。値が大きすぎると、フラッシュ処理の速度が書き込み速度に追いつかず、メモリ上限を超えるリスクが生じる可能性があります。                                                                    |
| freeze_trigger_percentage              | ダンプをトリガーするタイミング                     | デフォルト値のままにしておくことを推奨します                 |
| system_memory                          | 500テナント用予約メモリサイズ                | デフォルト値のままにしておくことを推奨します                                                                                                                         |
| use_large_pages                        | メモリ大ページを有効にする                      | この機能を有効にするには、OS側でメモリ大ページ機能を有効にする必要があります。有効にすると、メモリページテーブルのクエリ効率が向上します                                                                                       |
| writing_throttling_trigger_percentage | 書き込み負荷が高い場合に書き込みを制限する | デフォルト値は60です。パフォーマンスシナリオでは必要に応じてこの機能を無効にできます。無効にした場合、書き込みの同時実行量が非常に多いときにメモリ不足のリスクが生じる可能性があります。|
