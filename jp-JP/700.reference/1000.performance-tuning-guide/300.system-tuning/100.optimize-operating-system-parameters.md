# オペレーティングシステムパラメータのチューニング

|   カテゴリ   |                パラメータ                 |                          説明                          |                   推奨値                   |
|--------|------------------------------------|------------------------------------------------------|----------------------------------------|
| ネットワークパラメータ   | net.core.somaxconn                 | ソケットリスニングキューの最大長。頻繁に接続を確立する場合は、この値を大きく設定する必要があります                        | デフォルトは128、推奨値は2048                     |
| ネットワークパラメータ   | net.core.netdev_max_backlog        | プロトコルスタックが処理するバッファキューの長さです。設定が小さすぎると、パケット損失が発生する可能性があります                            | 推奨値は10000                            |
| ネットワークパラメータ   | net.core.rmem_default              | 受信バッファキューのデフォルト長                                         | 推奨値は16777216                         |
| ネットワークパラメータ   | net.core.wmem_default              | 送信バッファキューのデフォルト長                                         | 推奨値は16777216                         |
| ネットワークパラメータ   | net.core.rmem_max                  | 受信バッファキューの最大長                                         | 推奨値は16777216                         |
| ネットワークパラメータ   | net.core.wmem_max                  | 送信バッファキューの最大長                                         | 推奨値は16777216                         |
| ネットワークパラメータ   | net.ipv4.ip_local_port_range       | ローカルTCP/UDPのポート範囲です。ローカルはこの範囲内のポートを使用してリモートと接続を開始します                  | 推奨されるポート範囲は【3500、65535】                   |
| ネットワークパラメータ   | net.ipv4.tcp_rmem                  | ソケット受信バッファのサイズで、それぞれ最小値、デフォルト値、最大値                       | 推奨される最小値、デフォルト値、最大値はそれぞれ4096、87380、16777216 |
| ネットワークパラメータ   | net.ipv4.tcp_wmem                  | ソケット送信バッファのサイズで、それぞれ最小値、デフォルト値、最大値                       | 推奨される最小値、デフォルト値、最大値はそれぞれ4096、65536、16777216 |
| ネットワークパラメータ   | net.ipv4.tcp_max_syn_backlog       | SYN_RECVD状態の接続数                                  | 推奨値は16384                            |
| ネットワークパラメータ   | net.ipv4.tcp_fin_timeout           | ソケットがアクティブに切断された後のFIN-WAIT-2状態の持続時間                     | 推奨値は15                               |
| ネットワークパラメータ   | net.ipv4.tcp_tw_reuse              | TIME WAIT状態のソケットの再利用を許可します                          | 推奨値は1                                |
| ネットワークパラメータ   | net.ipv4.tcp_slow_start_after_idle | TCP接続のIdle状態からのスロースタートを禁止し、特定の状況下でのネットワーク遅延を低減します                   | 推奨値は0                                |
| 仮想メモリ設定 | vm.swappiness                      | 物理メモリの優先使用                                             | 推奨値は0                                |
| 仮想メモリ設定 | vm.max_map_count                   | プロセスが所有できる仮想メモリ領域の数                                      | 推奨値は655360                           |
| AIO設定 | fs.aio-max-nr                      | 非同期I/Oのリクエスト数                                         | 推奨値は1048576                          |
