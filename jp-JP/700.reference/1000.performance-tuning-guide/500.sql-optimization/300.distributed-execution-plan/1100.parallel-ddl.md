# パラレルDDL

OceanBaseデータベースは、DDL実行時のパフォーマンス向上を図るために、パラレルDDL操作をサポートしています。

## パラレルDDLの設定

OceanBaseデータベースでは、構成パラメータを設定することで、パラレルDDL機能を柔軟に制御できます：

* `_enable_parallel_table_creation`：パラレル `CREATE TABLE` 操作を制御します。
* `_parallel_ddl_control`：以下のパラレル操作を制御します：

  * `TRUNCATE TABLE`
  * `DROP TABLE`
  * `CREATE INDEX`
  * `CREATE VIEW`
  * `COMMENT`

### _enable_parallel_table_creation

`_enable_parallel_table_creation`は、テナントレベルでテーブルの同時作成(`CREATE TABLE`)機能を有効にするかどうかを制御します。

|  **プロパティ** |    **説明**    |
|-----------|----------------|
| パラメータタイプ  | ブール型         |
| デフォルト値    | True、テーブルの同時作成機能が有効であることを示します。            |
| 値の範囲  | <ul><li> False   </li><li> True  </li></ul>|
| 反映タイミング  | 即時に反映されます        |

#### 例

* `sys`テナントで以下のステートメントを実行し、ユーザーテナント`mysql001`でテーブルの同時作成機能を無効に設定します。

    ```sql
    ALTER SYSTEM SET _enable_parallel_table_creation = false tenant=mysql001;
    ```

* ユーザーテナントで以下のステートメントを実行し、テーブルの同時作成機能を無効に設定します。

    **MySQLモード：**

    ```sql
    ALTER SYSTEM SET _enable_parallel_table_creation = false;
    ```

    **Oracleモード：**

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Oracleモードでは、隠し構成パラメータ名を二重引用符で囲む必要があります。</p>
    </main>

    ```sql
    ALTER SYSTEM SET "_enable_parallel_table_creation" = false;
    ```

### _parallel_ddl_control

`_parallel_ddl_control`は、テナントレベルで各種パラレルDDL機能を有効にするかどうかを制御します。OceanBaseデータベースの現在のバージョンでは、`_parallel_ddl_control`は`TRUNCATE TABLE`、`CREATE INDEX`、`CREATE VIEW`、`DROP TABLE`、および`COMMENT`のパラレル実行機能の有効・無効を制御します。

|  **プロパティ** |    **説明**    |
|-----------|----------------|
| パラメータタイプ  | STRING         |
| デフォルト値    | 空文字列。意味は以下のとおりです。<ul><li>`TRUNCATE TABLE`はデフォルトで`ON`であり、パラレル実行機能がデフォルトで有効であることを示します。</li><li>その他のDDLタイプ(`TRUNCATE TABLE`以外)はデフォルトで`OFF`であり、パラレル実行機能がデフォルトで無効であることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>特定のDDLタイプに対してパラレル実行を設定する場合、指定しなかったDDLタイプは、<code>TRUNCATE TABLE</code>がデフォルトで<code>ON</code>である以外、残りのDDLタイプはすべてデフォルトで<code>OFF</code>です。</p></main>|
| 値の範囲  | 空文字列、または <code>DDL:{ON \| OFF} [, DDL:{ON \| OFF}] [, ...]</code>。DDLタイプの詳細は下表を参照してください。 |
| 反映タイミング  | 即時に反映されます        |

DDLタイプの情報：

| **DDLタイプ** | **値** |
|-------------|----------|
| TRUNCATE_TABLE | TRUNCATE_TABLE:{ON \| OFF} |
| SET_COMMENT    | SET_COMMENT:{ON \| OFF} |
| CREATE_INDEX   | CREATE_INDEX:{ON \| OFF} |
| CREATE_VIEW    | CREATE_VIEW:{ON \| OFF}  |
| DROP_TABLE     | DROP_TABLE:{ON \| OFF}|

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>OceanBaseデータベースの現在のバージョンは、全文インデックス、複数値インデックス、およびベクトルインデックスの同時実行をサポートしていません。</p>
</main>

#### 例

* `sys`テナントで以下のステートメントを実行し、ユーザーテナント`mysql001`のパラレル`TRUNCATE TABLE`を無効にし、パラレル`CREATE INDEX`を有効に設定します。

    ```sql
    ALTER SYSTEM SET _parallel_ddl_control = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF' tenant = 'mysql001';
    ```

* ユーザーテナントで以下のステートメントを実行し、パラレル`TRUNCATE TABLE`を無効にし、パラレル`CREATE INDEX`を有効に設定します。

    **MySQLモード：**

    ```sql
    ALTER SYSTEM SET _parallel_ddl_control = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF';
    ```

    **Oracleモード：**

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Oracleモードでは、隠し構成パラメータ名を二重引用符で囲む必要があります。</p>
    </main>

    ```sql
    ALTER SYSTEM SET "_parallel_ddl_control" = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF';
    ```

## DDLのデフォルト並列度

OceanBaseデータベースでは、セッションレベルパラメータ `_force_parallel_ddl_dop` を使用して、DDL操作のパラレル実行におけるデフォルトの並列度を指定できます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>PARALLEL</code> ヒントで並列度を明示的に指定しない場合、DDLは <code>_force_parallel_ddl_dop</code> の設定値を並列度として使用します。</p>
</main>

パラレルDDL機能を使用する際、`_force_parallel_ddl_dop` を使用して、事前にDDLのパラレル実行の並列度を設定できます。

### 例

ユーザーテナントで以下のステートメントを実行し、セッションレベルのDDL操作のパラレル実行のデフォルト並列度を16に設定します。

**MySQLモード：**

```sql
SET _FORCE_PARALLEL_DDL_DOP = 16;
```

**Oracleモード：**

```sql
SET "_FORCE_PARALLEL_DDL_DOP" = 16;
```
