# パラレルDDL

OceanBaseデータベースはパラレルDDL操作をサポートしており、複数のDDL操作を同時に実行することで、データベースの並列性能を向上させることができます。OceanBaseデータベースでは、構成パラメータ`_enable_parallel_table_creation`と`_parallel_ddl_control`を使用して、`CREATE TABLE`、`CREATE VIEW`、`TRUNCATE TABLE`、`COMMENT`、`DROP TABLE`、`CREATE INDEX`操作を含むパラレルDDL機能を柔軟に制御できます。

## _enable_parallel_table_creation

`_enable_parallel_table_creation`は、テナントレベルでの並行テーブル作成(`CREATE TABLE`)機能を有効にするかどうかを制御します。

|  **プロパティ** |    **説明**    |
|-----------|----------------|
| パラメータタイプ  | ブール型         |
| デフォルト値    | True。並行テーブル作成機能を有効にすることを示します。            |
| 値の範囲  | <ul><li> False   </li><li> True  </li></ul>|
| 発効モード  | 即時発効        |

### 例

* `sys`テナントで以下のステートメントを実行して、ユーザーテナント`mysql001`での並行テーブル作成機能を無効に設定します。

    ```sql
    ALTER SYSTEM SET _enable_parallel_table_creation = false tenant=mysql001;
    ```

* ユーザーテナントで以下のステートメントを実行して、並行テーブル作成機能を無効に設定します。

    **MySQLモード：**

    ```sql
    ALTER SYSTEM SET _enable_parallel_table_creation = false;
    ```

    **Oracleモード：**

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Oracleモードでは、構文上、構成パラメータに二重引用符を付ける必要があります。</p>
    </main>

    ```sql
    ALTER SYSTEM SET "_enable_parallel_table_creation" = false;
    ```

## _parallel_ddl_control

`_parallel_ddl_control`は、テナントレベルで各種並列DDL機能を有効にするかどうかを制御します。OceanBaseデータベースの現行バージョンでは、`_parallel_ddl_control`は`TRUNCATE TABLE`、`CREATE INDEX`、`CREATE VIEW`、`DROP TABLE`、および`COMMENT`の並列機能のスイッチを制御します。

|  **プロパティ** |    **説明**    |
|-----------|----------------|
| パラメータタイプ  | STRING         |
| デフォルト値    | 空文字列。意味は以下のとおりです。<ul><li>`TRUNCATE TABLE` のデフォルトは `ON` であり、パラレル処理機能がデフォルトで有効になっていることを示します。</li><li>その他のDDL（`TRUNCATE TABLE` を除く）のデフォルトは `OFF` であり、パラレル処理機能がデフォルトで無効であることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>個別の並列DDLに対して操作を行う場合、関与しないDDLタイプについては、<code>TRUNCATE TABLE</code> のデフォルトが <code>ON</code> である以外、その他のDDLタイプのデフォルトはすべて <code>OFF</code> となります。</p></main>|
| 値の範囲  | 空文字列、または <code>DDL:{ON \| OFF} [, DDL:{ON \| OFF}] [, ...]</code>。DDLタイプの詳細は下表を参照してください。 |
| 効力発生日  | 即時に有効になります        |

DDLタイプ情報：

| **DDLタイプ** | **値** |
|-------------|----------|
| TRUNCATE_TABLE | TRUNCATE_TABLE:{ON \| OFF} |
| SET_COMMENT    | SET_COMMENT:{ON \| OFF} |
| CREATE_INDEX   | CREATE_INDEX:{ON \| OFF} |
| CREATE_VIEW    | CREATE_VIEW:{ON \| OFF}  |
| DROP_TABLE     | DROP_TABLE:{ON \| OFF}|

### 例

* `sys`テナントで以下のステートメントを実行し、ユーザーテナント`mysql001`の並列`TRUNCATE TABLE`を無効にし、並列`CREATE INDEX`を有効に設定します。

    ```sql
    ALTER SYSTEM SET _parallel_ddl_control = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF' tenant = 'mysql001';
    ```

* ユーザーテナントで以下のステートメントを実行し、並列`TRUNCATE TABLE`を無効にし、並列`CREATE INDEX`を有効に設定します。

    **MySQLモード：**

    ```sql
    ALTER SYSTEM SET _parallel_ddl_control = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF';
    ```

    **Oracleモード：**

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Oracleモードでは、構文上隠れた構成パラメータには二重引用符を付ける必要があります。</p>
    </main>

    ```sql
    ALTER SYSTEM SET "_parallel_ddl_control" = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF';
    ```

## DDLのデフォルト並列度

OceanBaseデータベースでは、セッション（Session）レベルのパラメータ`_force_parallel_ddl_dop`を使用して、DDL操作の並列実行のデフォルト並列度を指定できます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>PARALLEL</code>ヒントを使用して並列度を明示的に指定しない場合、DDLは<code>_force_parallel_ddl_dop</code>で設定された値を並列度として使用します。</p>
</main>

並列DDL機能を使用する際、事前に`_force_parallel_ddl_dop`でDDLの並列実行の並列度を設定できます。

### 例

ユーザー・テナントで以下のステートメントを実行して、セッションレベルのDDL操作の並列実行のデフォルト並列度を16に設定します。

**MySQLモード：**

```sql
SET _FORCE_PARALLEL_DDL_DOP = 16;
```

**Oracleモード：**

```sql
SET "_FORCE_PARALLEL_DDL_DOP" = 16;
```
