# デプロイド実行計画のスケジューリング

OceanBaseデータベースは、シンプルなスケジューリングモデルに基づいてクエリ計画をスケジュールします。

実行計画の生成の最終段階で、`EXCHANGE`ノードを境に複数のサブ計画に分割され、各サブ計画はDFOとしてカプセル化されます。並列度が1より大きい場合、一度に2つのDFOがスケジュールされ、順次DFOツリーのトラバース実行が完了します。並列度が1の場合、各DFOは生成されたデータを中間結果マネージャーに格納し、後続のトラバース形式でDFOツリー全体のトラバース実行を完了します。
