# 分散実行計画のスケジューリング

OceanBaseデータベースは、単純なスケジューリングモデルに基づいてクエリ計画をスケジュールします。

実行計画生成の最終段階で、`EXCHANGE`ノードを境に複数のサブ計画に分割され、各サブ計画はDFOとしてカプセル化されます。並列度が1より大きい場合は、2つのDFOを一度にスケジュールし、DFOツリーの走査実行を順次完了します。並列度が1の場合、各DFOは生成されたデータを中間結果マネージャーに格納し、後続走査の形式でDFOツリー全体の走査実行を完了します。

## 単一DFOスケジューリング

例：並列度が1のシナリオで、クエリプランの実行に単一DFOスケジューリングを適用します。
