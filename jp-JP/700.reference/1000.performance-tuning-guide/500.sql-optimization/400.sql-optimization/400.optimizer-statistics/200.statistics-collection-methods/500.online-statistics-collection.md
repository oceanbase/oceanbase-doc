# オンライン統計情報収集

オンライン統計情報収集とは、`INSERT` 操作の実行時にデータベースオプティマイザーが統計情報を収集できる機能であり、システムパッケージを手動で呼び出す必要はありません。データの一括インポートプロセス中にリアルタイムで統計情報を収集できるため、追加の収集タスクを開始する必要がなく、運用保守作業が削減され、統計情報収集のパフォーマンスが向上します。

OceanBaseデータベースは、`GATHER_OPTIMIZER_STATISTICS`/`NO_GATHER_OPTIMIZER_STATISTICS` ヒントとシステム変数 `_optimizer_gather_stats_on_load`（デフォルトで有効）を使用してオンライン統計情報収集を行います。また、ダイレクトロード機能の `APPEND` ヒントを使用してオンライン統計情報収集を有効にすることもできます。

<main id="notice" type='explain'>
<h4>説明</h4>
  <p> <code>_optimizer_gather_stats_on_load</code> は内部システム変数で、デフォルトで有効です。</p>
</main>

オンライン統計情報収集が主にトリガーされるシナリオは以下のとおりです：

- `CREATE TABLE...AS SELECT`（CTAS）

  システム変数 `_optimizer_gather_stats_on_load` が True の場合、CTAS はデフォルトでオンライン統計情報収集機能を有効にします。この機能を無効にするには、`NO_GATHER_OPTIMIZER_STATISTICS` ヒントを使用できます。例：

  ```sql
  CREATE TABLE table_name AS SELECT /*+NO_GATHER_OPTIMIZER_STATISTICS*/* FROM...
  ```

- `INSERT INTO SELECT`

  システム変数 `_optimizer_gather_stats_on_load` が True の場合、`GATHER_OPTIMIZER_STATISTICS` ヒントまたは `APPEND` ヒントを使用してオンライン統計情報収集機能を有効にします。
  例：

  ```sql
  INSERT /*+GATHER_OPTIMIZER_STATISTICS*/ INTO table_name SELECT * FROM table_name
  ```

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>OceanBaseデータベースは、<code>INSERT /*+GATHER_OPTIMIZER_STATISTICS*/ INTO table_name VALUES()...</code> ステートメントを使用したオンライン統計情報収集を現在サポートしていません。</p>
  </main>

- PDML

  `ENABLE_PARALLEL_DML` ヒント、または `ALTER SESSION ENABLE PARALLEL DML;` でシステムの並列モードを設定することで、挿入操作を並列的に実行します。

  例：

  ```shell
  CREATE TABLE t2(c1 INT) PARTITION BY HASH(c1) PARTITIONS 4;
  INSERT INTO t1 VALUES (1),(2),(3),(4);
  ```

ユーザーがオンラインで収集した統計情報は、対応するビューで確認できます。ビューの詳細については、[統計情報収集方法の概要](../200.statistics-collection-methods/100.overview-of-statistics-collection-methods.md)を参照してください。

例：

```shell
CREATE TABLE t1(c1 INT) PARTITION BY HASH(c1) PARTITIONS 4;
CREATE TABLE t2(c1 INT) PARTITION BY HASH(c1) PARTITIONS 4;
INSERT INTO t1 VALUES (1),(2),(3),(4);
INSERT /*+ENABLE_PARALLEL_DML PARALLEL(4)*/ INTO t2 SELECT * FROM t1;
```
