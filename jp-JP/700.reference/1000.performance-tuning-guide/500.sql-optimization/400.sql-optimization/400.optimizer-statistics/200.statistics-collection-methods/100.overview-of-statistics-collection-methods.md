# 統計情報収集方法の概要

現在、OceanBaseデータベースのオプティマイザーは、以下の統計情報収集方法をサポートしており、収集された統計情報を照会するための対応するビューも提供しています：

* **手動による統計情報収集**：ユーザーは `DBMS_STATS` システムパッケージまたは `ANALYZE` ステートメントを使用して統計情報を収集します。詳細については、[手動による統計情報の収集](300.collect-statistics-manually.md)を参照してください。

* **自動統計情報収集**：メンテナンスウィンドウを通じて、欠落または期限切れの統計情報を定期的に収集します。詳細については、[統計情報の自動収集](400.collect-statistics-automatically.md)を参照してください。

* **オンライン統計情報収集**：データの一括インポートと同時に統計情報を収集します。詳細については、[オンライン統計情報収集](500.online-statistics-collection.md)を参照してください。

* **非同期統計情報収集**：テーブルやパーティションのデータ変更を定期的にチェックし、データ量が大きく変化したテーブルやパーティションを適時処理します。詳細については、[非同期統計情報収集](450.collect-statistics-asynchronously.md)を参照してください。

OceanBaseデータベースは、Oracleデータベースと互換性のあるビューを提供しており、Oracleモードで統計情報の収集状況を照会するために使用できます。関連するビューは以下の表のとおりです。

|          ビュー名                     |                        説明                       |
|--------------------------------------|---------------------------------------------------|
| ALL_TAB_STATISTICS、DBA_TAB_STATISTICS、USER_TAB_STATISTICS                         |  テーブルレベルの統計情報を照会するために使用します。                     |
| ALL_TAB_COL_STATISTICS、DBA_TAB_COL_STATISTICS、USER_TAB_COL_STATISTICS             |  `GLOBAL` レベルの列レベル統計情報を照会するために使用します。         |
| ALL_PART_COL_STATISTICS、DBA_PART_COL_STATISTICS、USER_PART_COL_STATISTICS          |  `PARTITION` レベルの列レベル統計情報を照会するために使用します。       |
| ALL_SUBPART_COL_STATISTICS、DBA_SUBPART_COL_STATISTICS、USER_SUBPART_COL_STATISTICS |  `SUBPARTITION` レベルの列レベル統計情報を照会するために使用します。    |
| ALL_TAB_HISTOGRAMS、DBA_TAB_HISTOGRAMS、USER_TAB_HISTOGRAMS                         |  `GLOBAL` レベルの列レベルヒストグラム統計情報を照会するために使用します。      |
| ALL_PART_HISTOGRAMS、DBA_PART_HISTOGRAMS、USER_PART_HISTOGRAMS                      |  `PARTITION` レベルの列レベルヒストグラム統計情報を照会するために使用します。    |
| ALL_SUBPART_HISTOGRAMS、DBA_SUBPART_HISTOGRAMS、USER_SUBPART_HISTOGRAMS             |  `SUBPARTITION` レベルの列レベルヒストグラム統計情報を照会するために使用します。 |
| ALL_IND_STATISTICS、DBA_IND_STATISTICS、USER_IND_STATISTICS                         |  インデックス統計情報を照会するために使用します。 |
| sys.ALL_VIRTUAL_TABLE_STAT_REAL_AGENT                               | テーブルレベルの統計情報を照会するためのエージェントテーブル。                                   |
| sys.ALL_VIRTUAL_COLUMN_STAT_REAL_AGENT                              | 列レベルの基本統計情報を照会するためのエージェントテーブル。                                 |
| sys.ALL_VIRTUAL_HISTOGRAM_STAT_REAL_AGENT                           | 列レベルのヒストグラム情報を照会するためのエージェントテーブル。                                  |

OceanBaseデータベースのMySQLモードで関連する統計情報を照会するために使用するビューは以下の表のとおりです。

|          ビュー名                     |                        説明                       |
|--------------------------------------|---------------------------------------------------|
| oceanbase.DBA_TAB_STATISTICS         |  テーブルレベルの統計情報を照会するために使用します。                      |
| oceanbase.DBA_TAB_COL_STATISTICS     |  `GLOBAL` レベルの列レベル統計情報を照会するために使用します。         |
| oceanbase.DBA_PART_COL_STATISTICS    |  `PARTITION` レベルの列レベル統計情報を照会するために使用します。       |
| oceanbase.DBA_SUBPART_COL_STATISTICS |  `SUBPARTITION` レベルの列レベル統計情報を照会するために使用します。    |
| oceanbase.DBA_TAB_HISTOGRAMS         |  `GLOBAL` レベルの列レベルヒストグラム統計情報を照会するために使用します。   |
| oceanbase.DBA_PART_HISTOGRAMS        |  `PARTITION` レベルの列レベルヒストグラム統計情報を照会するために使用します。    |
| oceanbase.DBA_SUBPART_HISTOGRAMS     |  `SUBPARTITION` レベルの列レベルヒストグラム統計情報を照会するために使用します。 |
| oceanbase.DBA_IND_STATISTICS         |  インデックス統計情報を照会するために使用します。 |
