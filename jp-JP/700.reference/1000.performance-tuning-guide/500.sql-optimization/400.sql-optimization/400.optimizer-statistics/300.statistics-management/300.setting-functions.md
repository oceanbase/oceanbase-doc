# 統計情報の設定

統計情報の設定機能とは、テーブルレベルおよび列レベルの基本統計情報を明示的に設定することを指します。
  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>現在、列レベルのヒストグラム情報の設定はサポートされていません。</p>
  </main>

OceanBaseデータベースでは、現在以下の3つの方法で統計情報を設定できます：

* ストアドプロシージャ `set_table_stats` を使用して、テーブルレベルの基本統計情報を設定します。
* ストアドプロシージャ `set_column_stats` を使用して、列レベルの基本統計情報を設定します。
* ストアドプロシージャ `set_index_stats` を使用して、インデックス統計情報を設定します。

各ストアドプロシージャの定義は以下のとおりです：

```sql
PROCEDURE set_table_stats (
  ownname            VARCHAR2,
  tabname            VARCHAR2,
  partname           VARCHAR2 DEFAULT NULL,
  stattab            VARCHAR2 DEFAULT NULL,
  statid             VARCHAR2 DEFAULT NULL,
  numrows            NUMBER DEFAULT NULL,
  numblks            NUMBER DEFAULT NULL,
  avgrlen            NUMBER DEFAULT NULL,
  flags              NUMBER DEFAULT NULL,
  statown            VARCHAR2 DEFAULT NULL,
  no_invalidate      BOOLEAN DEFAULT FALSE,
  cachedblk          NUMBER DEFAULT NULL,
  cachehit           NUMBER DEFAULT NULL,
  force              BOOLEAN DEFAULT FALSE
);

PROCEDURE set_column_stats (
  ownname            VARCHAR2,
  tabname            VARCHAR2,
  colname            VARCHAR2,
  partname           VARCHAR2 DEFAULT NULL,
  stattab            VARCHAR2 DEFAULT NULL,
  statid             VARCHAR2 DEFAULT NULL,
  distcnt            NUMBER   DEFAULT NULL,
  density            NUMBER   DEFAULT NULL,
  nullcnt            NUMBER   DEFAULT NULL,
  epc                NUMBER   DEFAULT NULL,
  minval             RAW      DEFAULT NULL,
  maxval             RAW      DEFAULT NULL,
  bkvals             NUMARRAY  DEFAULT NULL,
  novals             NUMARRAY  DEFAULT NULL,
  chvals             CHARARRAY DEFAULT NULL,
  eavals             RAWARRAY  DEFAULT NULL,
  rpcnts             NUMARRAY  DEFAULT NULL,
  eavs               NUMBER   DEFAULT NULL,
  avgclen            NUMBER   DEFAULT NULL,
  flags              NUMBER   DEFAULT NULL,
  statown            VARCHAR2 DEFAULT NULL,
  no_invalidate      BOOLEAN DEFAULT FALSE,
  force              BOOLEAN DEFAULT FALSE
);

PROCEDURE SET_INDEX_STATS (
  ownname            VARCHAR2,
  indname            VARCHAR2,
  partname           VARCHAR2  DEFAULT NULL,
  stattab            VARCHAR2  DEFAULT NULL,
  statid             VARCHAR2  DEFAULT NULL,
  numrows            NUMBER    DEFAULT NULL,
  numlblks           NUMBER    DEFAULT NULL,
  numdist            NUMBER    DEFAULT NULL,
  avglblk            NUMBER    DEFAULT NULL,
  avgdblk            NUMBER    DEFAULT NULL,
  clstfct            NUMBER    DEFAULT NULL,
  indlevel           NUMBER    DEFAULT NULL,
  flags              NUMBER    DEFAULT NULL,
  statown            VARCHAR2  DEFAULT NULL,
  no_invalidate      BOOLEAN   DEFAULT FALSE,
  guessq             NUMBER    DEFAULT NULL,
  cachedblk          NUMBER    DEFAULT NULL,
  cachehit           NUMBER    DEFAULT NULL,
  force              BOOLEAN   DEFAULT FALSE,
  avgrlen            NUMBER    DEFAULT NULL,
  nummacroblks       NUMBER    DEFAULT NULL,
  nummicroblks       NUMBER    DEFAULT NULL
);
```

パラメータの説明は以下の表のとおりです。

|    パラメータ    |                説明                 |
|----------|-----------------------------------|
| ownname  | <ul><li>Oracleモード：ユーザー名。`NULL`に設定した場合、現在ログインしているユーザー名がデフォルトで使用されます。</li><li>MySQLモード：テーブルが存在するデータベースの名前。 |
| tabname  | テーブル名。                               |
| tabname  | インデックス名。                               |
| partname | パーティション名。                              |
| colname  | 列名。                               |
| numrows  | テーブルレベルの総行数。                           |
| avgrlen  | テーブルレベルの平均行数。                           |
| distcnt  | 列レベルのNDV値。                        |
| density  | 列レベルの密度。                           |
| nullcnt  | 列レベルの`NULL`値の数。                   |
| avgclen  | 列レベルの平均長さ。                          |
| force    | ロックの状態を無視して強制的に削除するかどうか。デフォルトは`FALSE`です。       |

統計情報設定機能の例を以下に示します：

* ユーザー `user1` のテーブル `tbl1` の総行数を1万行に設定します。

  ```sql
  CALL dbms_stats.set_table_stats('user1', 'tbl1', numrows=>10000);
  ```

* ユーザー `user1` のテーブル `tbl1` の `col1` 列のNDVを10、`NULL` 値の数を10に設定します。

  ```sql
  CALL dbms_stats.set_column_stats('user1', 'tbl1', 'col1', distcnt=>10, nullcnt=>10);
  ```

* ユーザー `user1` のインデックス `idx1` の関連情報を設定します。

  ```sql
  CALL DBMS_STATS.SET_INDEX_STATS('user1', 'idx1', numrows=>10, avgrlen=>10);
  ```
