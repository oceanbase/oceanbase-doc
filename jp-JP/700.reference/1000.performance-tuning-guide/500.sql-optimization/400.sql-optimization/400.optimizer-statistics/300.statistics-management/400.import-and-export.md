# 統計情報のインポートとエクスポート

統計情報のエクスポート機能は、主にテーブルの統計情報を指定されたユーザーテーブルにエクスポートして保存するために使用されます。一方、インポート機能は、指定されたユーザーテーブルの統計情報を現在の統計情報内部テーブルにインポートし、再収集のプロセスを省略する役割を果たします。

例えば、データベース移行時には、大規模なテーブルの統計情報を指定ユーザーテーブルにエクスポートし、そのテーブルも一緒に移行することができます。データ移行が完了した後は、以前保存された統計情報を含むユーザーテーブルのデータを、新しいデータベースの対応する統計情報内部テーブルに直接インポートできます。

## 統計情報ユーザーテーブル

DBMS_STATSパッケージは、統計情報ユーザーテーブルを作成および削除するためのストアドプロシージャ`create_stat_table`と`drop_stat_table`を提供しています。定義は以下のとおりです：

```sql
PROCEDURE create_stat_table(
  ownname          VARCHAR2,
  stattab          VARCHAR2,
  tblspace         VARCHAR2 DEFAULT NULL,
  global_temporary BOOLEAN DEFAULT FALSE
);

PROCEDURE drop_stat_table(
  ownname VARCHAR2,
  stattab VARCHAR2
);
```



|        パラメータ        |                説明                 |
|------------------|-----------------------------------|
| ownname          | <ul><li>Oracleモード：ユーザー名。`NULL`に設定した場合、現在ログインしているユーザー名がデフォルトで使用されます。</li><li>MySQLモード：テーブルが存在するデータベース名。</li></ul> |
| stattab          | 作成する統計情報ユーザーテーブルの名前を指定します。                   |
| tblspace         | テーブルグループ名。                             |
| global_temporary | このパラメータは現在実装されていません。使用できません。                      |

## エクスポート機能
現在、統計情報をエクスポートする方法は以下の3種類がサポートされています：

* ストアドプロシージャ `export_table_stats` を使用してテーブルレベルの統計情報をエクスポートします。

* ストアドプロシージャ `export_column_stats` を使用して列レベルの統計情報をエクスポートします。

* ストアドプロシージャ `export_schema_stats` を使用して、Schema内のすべてのテーブルの統計情報をエクスポートします。

* ストアドプロシージャ `export_index_stats` を使用してインデックス統計情報をエクスポートします。

各ストアドプロシージャの定義は以下のとおりです：



```sql
PROCEDURE export_table_stats (
  ownname          VARCHAR2,
  tabname          VARCHAR2,
  partname         VARCHAR2 DEFAULT NULL,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  cascade          BOOLEAN DEFAULT TRUE,
  statown          VARCHAR2 DEFAULT NULL,
  stat_category    VARCHAR2 DEFAULT DEFAULT_STAT_CATEGORY
);

PROCEDURE export_column_stats (
  ownname          VARCHAR2,
  tabname          VARCHAR2,
  colname          VARCHAR2,
  partname         VARCHAR2 DEFAULT NULL,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  statown          VARCHAR2 DEFAULT NULL
);

PROCEDURE export_schema_stats (
  ownname          VARCHAR2,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  statown          VARCHAR2 DEFAULT NULL
);

PROCEDURE export_index_stats (
  ownname           VARCHAR2,
  indname           VARCHAR2,
  partname          VARCHAR2 DEFAULT NULL,
  stattab           VARCHAR2,
  statid            VARCHAR2 DEFAULT NULL,
  statown           VARCHAR2 DEFAULT NULL,
  tabname            VARCHAR2  DEFAULT NULL
);
```


|      パラメータ       |                 説明                 |
|---------------|------------------------------------|
| ownname       | <ul><li>Oracleモード：ユーザー名。`NULL` に設定した場合、現在ログインしているユーザー名がデフォルトで使用されます。</li><li>MySQLモード：テーブルが存在するデータベース名。</li></ul> |
| tabname       | テーブル名。                                |
| indname       | インデックス名。                                |
| partname      | パーティション名。                               |
| colname       | 列名。                                |
| cascade       | 列レベルの統計情報も一緒にエクスポートするかどうかを示します。デフォルトは `TRUE` です。          |
| stattab       | エクスポートする統計情報のユーザーテーブル名を指定します。                    |
| statid        | このパラメータは現在実装されていません。使用できません。                       |
| statown       | 統計情報のエクスポート先ユーザーテーブルの所有者名を指定します。                   |
| stat_category | このパラメータは現在実装されていません。使用できません。                       |
## インポート機能

現在、統計情報をインポートする方法は以下の3種類をサポートしています：
* ストアドプロシージャ `import_table_stats` を使用して、テーブルレベルの統計情報をインポートします。

* ストアドプロシージャ `import_column_stats` を使用して、列レベルの統計情報をインポートします。

* ストアドプロシージャ `import_schema_stats` を使用して、Schema内のすべてのテーブルの統計情報をインポートします。

* ストアドプロシージャ `import_index_stats` を使用して、インデックスの統計情報をインポートします。

各ストアドプロシージャの定義は以下のとおりです：





```sql
PROCEDURE import_table_stats (
  ownname          VARCHAR2,
  tabname          VARCHAR2,
  partname         VARCHAR2 DEFAULT NULL,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  cascade          BOOLEAN DEFAULT TRUE,
  statown          VARCHAR2 DEFAULT NULL,
  no_invalidate    BOOLEAN DEFAULT FALSE,
  force            BOOLEAN DEFAULT FALSE,
  stat_category    VARCHAR2 DEFAULT DEFAULT_STAT_CATEGORY
);

PROCEDURE import_column_stats (
  ownname          VARCHAR2,
  tabname          VARCHAR2,
  colname          VARCHAR2,
  partname         VARCHAR2 DEFAULT NULL,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  statown          VARCHAR2 DEFAULT NULL,
  no_invalidate    BOOLEAN DEFAULT FALSE,
  force            BOOLEAN DEFAULT FALSE
);

PROCEDURE import_schema_stats (
  ownname          VARCHAR2,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  statown          VARCHAR2 DEFAULT NULL,
  no_invalidate    BOOLEAN DEFAULT FALSE,
  force            BOOLEAN DEFAULT FALSE
);

PROCEDURE import_index_stats (
  ownname          VARCHAR2,
  indname          VARCHAR2,
  partname         VARCHAR2 DEFAULT NULL,
  stattab          VARCHAR2,
  statid           VARCHAR2 DEFAULT NULL,
  statown          VARCHAR2 DEFAULT NULL,
  no_invalidate    BOOLEAN DEFAULT FALSE,
  force            BOOLEAN DEFAULT FALSE,
  tabname          VARCHAR2  DEFAULT NULL
);
```

| パラメータ | 説明 |
|---------------|------------------------------------|
| ownname       | <ul><li>Oracleモード：ユーザー名。`NULL` に設定した場合、現在ログインしているユーザー名がデフォルトで使用されます。 </li><li>MySQLモード：テーブルが存在するデータベース名。</li></ul>|
| tabname       | テーブル名。                                |
| indname       | インデックス名。                                |
| partname      | パーティション名。                               |
| colname       | 列名。                                |
| cascade       | 列レベルの統計情報も一緒にエクスポートするかどうか。デフォルトは `TRUE` です。          |
| stattab       | 統計情報をエクスポートするユーザーテーブルの名前を指定します。                    |
| statid        | このパラメータは現在実装されておらず、使用できません。                       |
| statown       | 統計情報をエクスポートするユーザーテーブルの所有者名を指定します。                   |
| stat_category | このパラメータは現在実装されておらず、使用できません。                       |
| no_invalidate | このパラメータは現在実装されておらず、使用できません。                       |
| force         | ロックの状態を無視して強制的に削除するかどうか。デフォルトは `FALSE` です。        |





## 例
1. ユーザー `test` の統計情報ユーザーテーブル `test_stat` を作成します。

   ```sql
   CALL dbms_stats.create_stat_table('test', 'test_stat');
   ```

2. ユーザー `test` の `tbl1` テーブルの統計情報を `test_stat` にエクスポートします。

   ```sql
   CALL dbms_stats.export_table_stats('test', 'tbl1', stattab=>'test_stat', statown=>'test');
   ```

3. ユーザー `test` の `test_stat` から、同じユーザーのテーブル `tbl1` の統計情報をインポートします。

   ```sql
   CALL dbms_stats.import_table_stats('test', 'tbl1', stattab=>'test_stat', statown=>'test');
   ```

4. ユーザー `test` の統計情報テーブル `test_stat` を削除します。

   ```sql
   CALL dbms_stats.drop_stat_table('test', 'test_stat');
   ```
