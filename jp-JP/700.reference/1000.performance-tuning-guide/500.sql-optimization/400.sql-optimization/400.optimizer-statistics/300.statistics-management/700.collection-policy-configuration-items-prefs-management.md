# 統計情報収集ポリシー(PREFS)の管理

統計情報PREFSは主に、統計情報収集プロセス中の収集ポリシーのデフォルト値を設定するために使用されます。例えば、granularityやmethod_optなどのデフォルト値です。

## 統計情報収集ポリシーPREFS構成パラメータ

Oracleモードでは、現在設定されているPREFSを照会するための以下の仮想テーブルが提供されています：

* `SYS.ALL_VIRTUAL_OPTSTAT_GLOBAL_PREFS_REAL_AGENT`は`GLOBAL`レベルのPREFS設定を照会するために使用されます。

* `SYS.ALL_VIRTUAL_OPTSTAT_USER_PREFS_REAL_AGENT`はテーブルレベルのPREFS設定を照会するために使用されます。

設定可能な統計情報収集ポリシーPREFSは以下の表のとおりです。

|     PREFS名      |                   PREFS値                   |                               説明                               |
|-------------------|-------------------------------------------------|----------------------------------------------------------------|
| APPROXIMATE_NDV   | 値の範囲： <ul><li> "TRUE"（デフォルト値）</li>   <li> "FALSE" </li>  </ul>        | NDVの計算に推定方法を使用するかどうかを示します。このPREFSは`__all_optstat_user_prefs`に挿入できません。 |
| CASCADE           | 値の範囲： <ul><li> "TRUE" </li>  <li> "FALSE" </li>  <li> "DBMS_STATS_AUTO_CASCADE"（デフォルト値）</li>  </ul>     | このパラメータは現在使用されていません。       |
| DEGREE            | デフォルト値：NULL       | 収集の並列度を示します。                                                         |
| ESTIMATE_PERCENT  | 値の範囲：\[0.000001, 100\] デフォルト値："DBMS_STATS_AUTO_SAMPLE_SIZE"。        | 比率を採用します。        |
| BLOCK_SAMPLE      | デフォルト値は "FALSE" です。        | サンプリングにブロックサンプリングを使用するかどうかを指定します。     |
| GRANULARITY       | デフォルト値は"AUTO" です。                                                         | 収集パーティションの粒度を示します。構文は`granularity`と同じです。  |
| INCREMENTAL       | 値の範囲： <ul><li> "TRUE"</li>   <li> "FALSE" （デフォルト値）</li> </ul>         | 増分収集ポリシーを採用するかどうかを示します。     |
| INCREMENTAL_LEVEL | 値の範囲： <ul><li> "PARTITION"</li>   <li> "TABLE"（デフォルト値） </li> </ul>                                                               | 増分収集レベル。現在はテーブルレベルのみサポートしています。    |
| METHOD_OPT        | デフォルト値： "FOR ALL COLUMNS SIZE AUTO"   | 列レベルの統計情報収集方法を設定します。構文は`method_opt`と同じです。                            |
| NO_INVALIDATE     | 値の範囲： <ul><li> "TRUE" </li>  <li> "FALSE" </li>  <li> "DBMS_STATS_AUTO_INVALIDATE"（デフォルト値）</li></ul>    | このパラメータは現在使用されていません。   |
| OPTIONS           | 値の範囲： <ul><li> "GATHER"（デフォルト値）</li>   <li>  "GATHER AUTO"  </li> </ul>                                                          | このパラメータは現在使用されていません。    |
| STALE_PERCENT     | デフォルト値：10     | 統計情報の有効期限切れのしきい値を示す割合です。                                                    |
| STATS_RETENTION   | 値の範囲：\[0-365000\] デフォルト値：31     | 統計情報の履歴保持間隔時間を示します。                                                 |

## 統計情報ポリシーPREFSの設定と取得

### グローバル統計情報ポリシーPREFSの設定と取得

グローバル統計情報ポリシーPREFSは、以下のストアドプロシージャを使用して設定および取得します：

* `reset_global_pref_defaults`

* `reset_param_defaults`

* `set_global_prefs`

* `set_param`

* `get_param`

具体的な定義は以下のとおりです：

```sql
PROCEDURE reset_global_pref_defaults;

PROCEDURE reset_param_defaults;

PROCEDURE set_global_prefs(
  pname         VARCHAR2,
  pvalue        VARCHAR2
);

PROCEDURE set_param(
  pname          VARCHAR2,
  pval           VARCHAR2
);

FUNCTION get_param (
  pname           VARCHAR2
)RETURN VARCHAR2;
```

パラメータの説明は以下のとおりです：

* `pname`：Prefsの名前。

* `pvalue`：Prefsの値。

### テーブルレベルの統計情報戦略Prefsの設定と取得

テーブルレベルの統計情報戦略Prefsは、以下のストアドプロシージャを使用して設定および取得します：

* `set_schema_prefs`

* `set_table_prefs`

* `delete_schema_prefs`

* `delete_table_prefs`

* `get_prefs`

具体的な定義は以下のとおりです：

```sql
PROCEDURE set_schema_prefs(
  ownname        VARCHAR2,
  pname          VARCHAR2,
  pvalue         VARCHAR2
);

PROCEDURE set_table_prefs(
  ownname        VARCHAR2,
  tabname        VARCHAR2,
  pname          VARCHAR2,
  pvalue         VARCHAR2
);

PROCEDURE delete_schema_prefs(
  ownname        VARCHAR2,
  pname          VARCHAR2
);

PROCEDURE delete_table_prefs (
  ownname        VARCHAR2,
  tabname        VARCHAR2,
  pname          VARCHAR2
);

FUNCTION get_prefs (
  pname           VARCHAR2,
  ownname         VARCHAR2 DEFAULT NULL,
  tabname         VARCHAR2 DEFAULT NULL
) RETURN VARCHAR2;
```

パラメータの説明は以下の表のとおりです。

|   パラメータ    |                説明                 |
|---------|-----------------------------------|
| ownname | <ul><li>Oracleモード：ユーザー名。ユーザー名が`NULL`に設定されている場合、デフォルトで現在ログインしているユーザー名が使用されます。</li><li>MySQLモード：テーブルが存在するデータベース名。  |
| tabname | テーブル名。                               |
| pname   | Prefsの名前。                        |
| pvalue  | Prefsの値。                         |

## 例
* グローバルレベルの`APPROXIMATE_NDV`値を`FALSE`に設定します。



  ```sql
  CALL dbms_stats.set_global_prefs('APPROXIMATE_NDV', 'FALSE');
  ```



  ```sql
  CALL reset_global_pref_defaults();
  ```



  ```sql
  CALL dbms_stats.set_table_prefs('test', 'tbl1', 'DEGREE', '128');
  ```



  ```sql
  CALL dbms_stats.delete_table_prefs('test', 'tbl1', 'DEGREE');
  ```
