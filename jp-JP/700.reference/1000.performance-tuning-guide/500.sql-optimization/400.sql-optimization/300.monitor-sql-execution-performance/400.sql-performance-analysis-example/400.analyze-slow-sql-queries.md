# スローSQLクエリの分析

特定のSQLクエリが常に遅いことが分かっている場合、以下の方法で分析することができます：

* SQL Auditを使用して統計データを確認し、そのSQLの実行計画を分析します。詳細な手順については、例を参照してください。

  [RTの急激なジッターを分析するSQL](../400.sql-performance-analysis-example/200.sql-statement-that-analyzes-sudden-jitter-of-rt.md)。

* 実行計画が正しいかどうかを分析します。詳細な手順については、例[実行計画の形状を確認して分析する](../400.sql-performance-analysis-example/300.view-and-analyze-the-execution-plan.md)を参照してください。
