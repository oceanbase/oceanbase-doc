# システム全体または特定のSQLの実行において、過剰な不合理なリモート実行リクエストが発生していないか分析する

以下のSQLステートメントを実行することで、一定期間における異なるタイプの実行計画の実行回数を分析できます。

```javascript
obclient> SELECT COUNT(*),plan_type FROM oceanbase.GV$OB_SQL_AUDIT WHERE tenant_id = 1001
   AND  IS_EXECUTOR_RPC = 0
   AND  request_time > (time_to_usec(now()) - 10000000)
   AND  request_time < time_to_usec(now())
   GROUP BY plan_type;
+----------+-----------+
| COUNT(*) | plan_type |
+----------+-----------+
|     2054 |         1 |
|      138 |         0 |
+----------+-----------+
2 rows in set
```

一般的に、リモート実行リクエストが多く発生する場合、プライマリ切り替えやProxyクライアントのルーティングが不正確である可能性があります。
