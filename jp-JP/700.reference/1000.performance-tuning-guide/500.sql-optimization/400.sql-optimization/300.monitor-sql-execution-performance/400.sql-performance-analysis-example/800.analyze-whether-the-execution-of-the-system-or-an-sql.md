# システムまたは特定のSQLの実行において、大量の不合理なリモート実行リクエストが発生しているかどうかを分析する

以下のSQL文を実行することで、一定期間内に異なるタイプの計画の実行回数を分析できます。

```javascript
obclient> SELECT COUNT(*),plan_type FROM oceanbase.GV$OB_SQL_AUDIT WHERE tenant_id = 1001
   AND  IS_EXECUTOR_RPC = 0
   AND  request_time > (time_to_usec(now()) - 10000000)
   AND  request_time < time_to_usec(now())
   GROUP BY plan_type;
+----------+-----------+
| COUNT(*) | plan_type |
+----------+-----------+
|     2054 |         1 |
|      138 |         0 |
+----------+-----------+
2 rows in set
```

一般的に、リモート実行リクエストが多く発生する場合、これはプライマリサーバーの切り替えやProxyクライアントのルーティングが不正確であることが原因である可能性があります。
