# ディストリビューション計画に関連するクエリの問題の分析

ディストリビューション計画は、以下の手順でクエリの問題を分析します：

1. `(G)V$OB_PLAN_CACHE_PLAN_STAT`ビューおよび`(G)V$OB_SQL_AUDIT`の実行計画タイプのレコードを確認して、ディストリビューション計画であるかどうかを判断します。

2. その実行計画が正しいかどうかを分析します。

3. `trace_id`を使用してクエリ`(G)V$OB_SQL_AUDIT`に関連付け、実行されたすべてのサブプランの時間消費状況を確認します。各サブプランのRPC実行には1つのSQL Auditレコードが対応しており、このSQL Auditレコードを分析して問題を特定します。

以下の例のように、`is_executor_rpc = 1`はサブプランの実行がSQL Auditに記録されていることを示し、主に実行関連情報を記録します。`is_executor_rpc = 0`は、SQLリクエストを受け取ったスレッドのSQL Auditにおける記録を示します。この記録には、SQL実行プロセスの情報が含まれており、SQL情報や実行計画情報の取得などが含まれます。

```sql
obclient> SELECT/*+ PARALLEL(15)*/sql_id, is_executor_rpc, elapsed_time
           FROM oceanbase.GV$OB_SQL_AUDIT WHERE trace_id = 'YB420AB74FC6-00056349D323483A';

+----------------------------------+-----------------+--------------+
| sql_id                           | is_executor_rpc | elapsed_time |

|                                  |               1 |          124 |
|                                  |               1 |          191 |
|                                  |               1 |       123447 |
|                                  |               1 |          125 |
| 20172B18BC9EE3F806D4149895754CE0 |               0 |       125192 |
|                                  |               1 |          148 |
|                                  |               1 |          149 |
|                                  |               1 |          140 |
+----------------------------------+-----------------+--------------+
```
