# 実行計画の形状を確認し分析する

以下の手順に従って実行計画の形状を確認し、分析します：

1. `EXPLAIN` コマンドを使用して実行計画の形状を確認するか、リアルタイム実行計画表示を通じてキャッシュされた実行計画を確認します。詳細については、[SQL実行計画の概要](../../../200.sql-execution-plan/100.introduction-to-sql-execution-plans.md)および[リアルタイム実行計画表示](../../../200.sql-execution-plan/500.real-time-execution-plan-display.md)を参照してください。

2. 実行計画の形状を取得した後、インデックス、結合順序、結合アルゴリズムなどが適切かつ正確に選択されているかどうかを分析できます。詳細については、[アクセスパス](../../600.query-optimization/100.access-path/100.access-path-overview.md)、[結合順序](../../600.query-optimization/200.join-algorithm/400.join-order.md)および[結合アルゴリズム](../../600.query-optimization/200.join-algorithm/200.join-algorithm.md)を参照してください。
