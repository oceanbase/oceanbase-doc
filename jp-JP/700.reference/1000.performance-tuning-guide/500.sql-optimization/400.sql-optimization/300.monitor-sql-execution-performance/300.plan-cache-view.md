# プランキャッシュビュー

プランキャッシュビューには、実行計画のキャッシュ状態、実行統計に関する情報、および計画情報が含まれます。

## (G)V$OB_PLAN_CACHE_STATビュー

`(G)V$OB_PLAN_CACHE_STAT`ビューは、現在のテナントにおける現在の（すべての）OBServerノード上での計画キャッシュ全体の状態を表示します。フィールド情報は以下の表のとおりです。

|   **フィールド名**   | **タイプ（MySQLモード）**    |    **タイプ（Oracleモード）**    |               **説明**                |
|--------------|-------------|--------------|-------------------------------------|
| TENANT_ID    | BIGINT(20)   | このフィールドはサポートされていません。   | テナントID                                 |
| SVR_IP       | VARCHAR2(32) | VARCHAR2(32) | サーバーのIPアドレス                          |
| SVR_PORT     | BIGINT(38)   | NUMBER(38)   | ポート番号                                 |
| SQL_NUM      | BIGINT(38)   | NUMBER(38)   | `plan_cache`に関連するSQL数              |
| MEM_USED     | BIGINT(38)   | NUMBER(38)   | `plan_cache`で使用済みのメモリ                |
| MEM_HOLD     | BIGINT(38)   | NUMBER(38)   | `plan_cache`が保持するメモリ                  |
| ACCESS_COUNT | BIGINT(38)   | NUMBER(38)   | `plan_cache`へのクエリアクセス回数                 |
| HIT_COUNT    | BIGINT(38)   | NUMBER(38)   | `plan_cache`へのヒット回数                 |
| HIT_RATE     | BIGINT(38)   | NUMBER(38)   | `plan_cache`のヒット率                   |
| PLAN_NUM     | BIGINT(38)   | NUMBER(38)   | プランの数                            |
| MEM_LIMIT    | BIGINT(38)   | NUMBER(38)   | `plan_cache`のメモリ上限                  |
| HASH_BUCKET  | BIGINT(38)   | NUMBER(38)   | `plan_cache` Hash Map内のBucket数 |
| STMTKEY_NUM  | BIGINT(38)   | NUMBER(38)   | `plan_cache`内の`stmt_key`の数       |

## (G)V$OB_PLAN_CACHE_PLAN_STATビュー

`(G)V$OB_PLAN_CACHE_PLAN_STAT`ビューは、現在のテナントが現在の（すべての）OBServerノード上の計画キャッシュにキャッシュされている各キャッシュオブジェクトの状態を表示します。フィールド情報は以下の表のとおりです。

|       **フィールド名**        | **タイプ（MySQLモード）**  | **タイプ（Oracleモード）**  |           **説明**    |
|-----------------------|-----------------------|----------------------|------------------------|
| TENANT_ID             | BIGINT(20)   |  NUMBER(38)       | テナントID      |
| SVR_IP                | VARCHAR2(46) |  VARCHAR2(46)     | サーバーのIPアドレス      |
| SVR_PORT              | BIGINT(20)   |  NUMBER(38)       | サーバーのポート番号    |
| PLAN_ID               | BIGINT(20)   |  NUMBER(38)       | 実行計画のID     |
| SQL_ID                | VARCHAR2(32) |  VARCHAR2(32)     | このSQLのID   |
| TYPE                  | BIGINT(20)   |  NUMBER(38)       | SQL計画のキャッシュにおいて、このフィールドは計画のタイプを表します：  <ul><li> 1：ローカル計画Local Planを表します  </li><li> 2：リモート計画Remote Planを表します </li><li>3：分散計画Distribute Planを表します  </li></ul>PLオブジェクトのキャッシュにおいて、このフィールドはPLオブジェクトのタイプを表します：<ul><li> 1：プロシージャProcedureを表します    </li><li> 2：関数Functionを表します </li><li>3：パッケージPackageを表します  </li><li> 4：匿名ブロックAnonymous Blockを表します   </li></ul>   |
| DB_ID                 | BIGINT(20) UNSIGNED  |  NUMBER(38)| データベースのID      |
| IS_BIND_SENSITIVE     | BIGINT(20)   |  NUMBER(38)        | この計画でACSを有効にする必要があるかどうか     |
| IS_BIND_AWARE         | BIGINT(20)   |  NUMBER(38)        | この計画でACSが有効になっているかどうか     |
| STATEMENT             | LONGTEXT     |  CLOB   | パラメータ化されたSQL文   |
| QUERY_SQL             | LONGTEXT     |  CLOB   | 最初に計画が読み込まれた際に実行された元のSQL文    |
| SPECIAL_PARAMS        | VARCHAR2(4096)|  VARCHAR2(4096)   | パラメータ化できないパラメータ値を表します    |
| PARAM_INFOS           | LONGTEXT      |  CLOB  | パラメータ化情報を表します  |
| SYS_VARS              | VARCHAR2(4096)| VARCHAR2(4096)   | キャッシュ対象オブジェクトに影響を与えるシステム変数の値   |
| CONFIGS               | VARCHAR(4096)       | このフィールドはサポートされていません  |    実行計画に影響を与える構成パラメータ情報を表します    |
| PLAN_HASH             | BIGINT(20) UNSIGNED   |  NUMBER(38) | SQL実行計画のハッシュ値   |
| FIRST_LOAD_TIME       | TIMESTAMP(6) |  TIMESTAMP(6) WITH LOCAL TIME ZONE | 最初に読み込まれた時間   |
| SCHEMA_VERSION        | BIGINT(20)   |  NUMBER(38)                        | Schemaバージョン番号   |
| LAST_ACTIVE_TIME      | TIMESTAMP(6) |  TIMESTAMP(6) WITH LOCAL TIME ZONE | 前回実行された時間     |
| AVG_EXE_USEC          | BIGINT(20)   |  NUMBER(38)                        | 平均実行時間   |
| SLOWEST_EXE_TIME      | TIMESTAMP(6) |  TIMESTAMP(6) WITH LOCAL TIME ZONE | 最も遅い実行のタイムスタンプ     |
| SLOWEST_EXE_USEC      | BIGINT(20)   |  NUMBER(38)                        | 最も遅い実行にかかった時間    |
| SLOW_COUNT            | BIGINT(20)   |  NUMBER(38)                        | 現在のSQL計画がスロークエリとなった回数    |
| HIT_COUNT             | BIGINT(20)   |  NUMBER(38)                        | ヒットした回数   |
| PLAN_SIZE             | BIGINT(20)   |  NUMBER(38)                        | キャッシュオブジェクトが占有するメモリサイズ     |
| EXECUTIONS            | BIGINT(20)   |  NUMBER(38)                        | 実行回数       |
| DISK_READS            | BIGINT(20)   |  NUMBER(38)                        | すべての実行における物理読み取り回数  |
| DIRECT_WRITES         | BIGINT(20)   |  NUMBER(38)                        | すべての実行におけるディスクへの書き込み回数    |
| BUFFERS_GETS          | BIGINT(20)   |  NUMBER(38)                        | すべての実行における論理読み取り回数    |
| APPLICATION_WAIT_TIME | BIGINT(20) UNSIGNED   |  NUMBER(38)  | このリクエストの実行中、すべてのApplication系イベントの合計時間     |
| CONCURRENCY_WAIT_TIME | BIGINT(20) UNSIGNED  |  NUMBER(38)   | このリクエストの実行中、すべてのConcurrency系イベントの合計時間     |
| USER_IO_WAIT_TIME     | BIGINT(20)  UNSIGNED |  NUMBER(38)   | このリクエストの実行中、すべての`USER_IO`系イベントの合計時間   |
| ROWS_PROCESSED        | BIGINT(20)   |  NUMBER(38)   | すべての実行における選択結果の行数または変更対象テーブルの行数    |
| ELAPSED_TIME          | BIGINT(20) UNSIGNED   |  NUMBER(38)  | すべての実行におけるリクエスト受信から実行終了までの経過時間    |
| CPU_TIME              | BIGINT(20) UNSIGNED   |  NUMBER(38)  | すべての実行におけるCPU時間     |
| LARGE_QUERYS          | BIGINT(20)   |  NUMBER(38)  | 大規模クエリと判断された回数    |
| DELAYED_LARGE_QUERYS  | BIGINT(20)   |  NUMBER(38)  | 大規模クエリと判断され、かつ大規模クエリキューに投入された回数      |
| DELAYED_PX_QUERYS     | BIGINT(20)   |  NUMBER(38)  | パラレルクエリがキューに再試行された回数        |
| OUTLINE_VERSION       | BIGINT(20)   |  NUMBER(38)  | アウトラインバージョン番号          |
| OUTLINE_ID            | BIGINT(20)   |  NUMBER(38)  | アウトラインのID。-1の場合、アウトラインにバインドされていない計画を表します      |
| OUTLINE_DATA          | LONGTEXT     |  CLOB   | 計画に対応するアウトライン情報   |
| ACS_SEL_INFO          | LONGTEXT     |  CLOB      | 現在のACS計画に対応する選択率空間         |
| TABLE_SCAN            | TINYINT(4)   |  NUMBER(38)   | このクエリが主キー スキャンであるかどうかを示します       |
| EVOLUTION             | TINYINT(4)   |  NUMBER(38)   | この実行計画が進化中であるかどうかを示します           |
| EVO_EXECUTIONS        | BIGINT(20) UNSIGNED  |  NUMBER(38)  | 進化回数        |
| EVO_CPU_TIME          | BIGINT(20)   |  NUMBER(38)  | 進化中の合計実行CPU時間         |
| TIMEOUT_COUNT         | BIGINT(20)   |  NUMBER(38)  | タイムアウト回数            |
| PS_STMT_ID            | BIGINT(20)   |  NUMBER(38)  | Prepare StatementのID      |
| SESSID                | BIGINT(20) UNSIGNED  |  NUMBER(38)  | キャッシュ オブジェクトが存在するセッションID         |
| TEMP_TABLES           | LONGTEXT     |  CLOB    | SQL計画に含まれる一時テーブルの名前。一時テーブルがない場合、フィールドは空です。            |
| IS_USE_JIT            | TINYINT(4)   |  NUMBER(38)   | SQL計画で式のコンパイル実行が有効になっているかどうか              |
| OBJECT_TYPE           | LONGTEXT     |  CLOB    | キャッシュ オブジェクトのタイプ：<ul><li> SQL_PLAN</li>   <li> PROCEDURE</li>   <li> FUNCTION </li>  <li> PACKAGE</li>   <li> ANONYMOUS   </li> </ul>         |
| HINTS_INFO            | LONGTEXT     |  CLOB   | SQL計画のヒント情報     |
| HINTS_ALL_WORKED      | TINYINT(4)  |  NUMBER(38)    | SQL計画内のヒントがすべて有効になっているかどうか      |
| PL_SCHEMA_ID          | BIGINT(20) UNSIGNED  |  NUMBER(38)    | 匿名ブロック以外のPLオブジェクトについては、このフィールドはキャッシュ オブジェクトのスキーマIDです。匿名ブロックの場合、このフィールドは`PS_STMT_ID`と同じです。SQL計画については、このフィールドは意味がありません。       |
| IS_BATCHED_MULTI_STMT | TINYINT(4)   |  NUMBER(38)    | Batched MultiStmt最適化された計画であるかどうかを示します        |
| RULE_NAME             | VARCHAR(256)        | このフィールドはサポートされていません   |  ユーザー定義の書き換えルールにヒットしたかどうかを示します。         |

## (G)V$OB_PLAN_CACHE_PLAN_EXPLAIN

`(G)V$OB_PLAN_CACHE_PLAN_EXPLAIN`は、現在の（すべての）OBServerノードにキャッシュされている計画キャッシュ内の物理実行計画を表示します。フィールド情報は以下の表のとおりです。

|   **フィールド名**   | **タイプ（MySQLモード）**  |  **タイプ（Oracleモード）**    |      **説明**      |
|--------------|----------------|----------------|------------------|
| TENANT_ID    |  BIGINT(20)   | NUMBER(38)     | テナントID            |
| SVR_IP       | VARCHAR2(46)  | VARCHAR2(46)   | サーバーIPアドレス        |
| SVR_PORT     | BIGINT(20)   | NUMBER(38)     | サーバーのポート番号           |
| PLAN_ID      | BIGINT(20)   | NUMBER(38)     | 実行計画のID         |
| PLAN_DEPTH   | BIGINT(20)   | NUMBER(38)     | Operator表示時の深さ |
| PLAN_LINE_ID | BIGINT(20)   | NUMBER(38)   |Operatorの番号     |
| OPERATOR     | VARCHAR2(128)  | VARCHAR2(128)  |演算子の名前            |
| NAME         | VARCHAR2(256)  | VARCHAR2(256)  |テーブル名             |
| ROWS         | BIGINT(20)   | NUMBER(38)     | 予想される結果行数          |
| COST         | BIGINT(20)   | NUMBER(38)     | 予想されるコスト            |
| PROPERTY     | VARCHAR2(4096) | VARCHAR2(4096) |対応する演算子の情報          |
