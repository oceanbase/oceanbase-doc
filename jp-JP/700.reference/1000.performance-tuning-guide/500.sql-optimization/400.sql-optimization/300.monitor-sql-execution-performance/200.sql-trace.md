# SQLトレース

SQLトレース（`SHOW TRACE`）は、OceanBase データベースが提供するパフォーマンス分析ツールであり、直前に実行されたSQLリクエストの実行プロセスにおける呼び出しチェーンと、チェーン内の各段階での所要時間をインタラクティブに提供し、パフォーマンス分析やチューニングに役立ちます。

## SQLトレースの役割

### パフォーマンスチューニングのニーズ

* 複雑なクエリの最適化：SQLの実行が遅い場合、トレースにより問題を迅速に特定できます（例：テーブル全体のスキャン、`JOIN`の順序が不適切など）。
* リソース競合分析：ロック待ち、同時実行の競合など、遅延を引き起こす問題を特定します。
* インデックスの有効性検証：クエリがインデックスにヒットしているか、冗長なインデックスが存在するかを判断します。

### 問題診断のシナリオ

* スロークエリの特定：`ELAPSE_TIME`を使用して、最も時間を要したサブタスクを特定します。
* インデックスの欠落：`inner_execute_read`の時間が異常にかかる場合、インデックスが使用されていない可能性があります。
* 分散タスクの異常：`do_local_das_task`の時間が均等にかかっているか確認し、単一点でのパフォーマンスボトルネックを回避します。

### システム安定性の保証

* 予防保守：定期的に重要なSQLをトレースすることで、潜在的なパフォーマンスリスクを早期に発見します。
* 障害発生後の振り返り：本番環境で異常が発生した場合、Traceログを組み合わせて問題を迅速に再現します。

## SQLトレースの使用

`SHOW TRACE`機能はデフォルトで無効になっています。セッション変数[ob_enable_show_trace](../../../../800.configuration-items-and-system-variables/200.system-variable/400.session-system-variable/500.ob_enable_show_trace-session.md)を使用して有効または無効にできます。

### 手順

#### ステップ１：現在のセッションのSQLトレース機能を有効にする

**例：**

```sql
SET ob_enable_show_trace = 1;
```

#### ステップ２：対象SQLを実行する

**例：**

1. テーブル`t1`を作成します。

   ```sql
   CREATE TABLE t1(c1 INT, c2 INT, c3 INT);
   ```

2. テーブルにデータを挿入します。

   ```sql
   INSERT INTO t1 VALUES(1,1,1),(2,2,2);
   ```

3. テーブル`t1`のデータを確認します。

   ```sql
   SELECT/*+PARALLEL(2)*/ COUNT(*) FROM t1;
   ```

   実行結果は次のとおりです：

   ```shell
   +----------+
   | COUNT(*) |
   +----------+
   |        2 |
   +----------+
   1 row in set
   ```

#### ステップ３：Trace情報を確認する

`SHOW TRACE;`ステートメントを使用して、直前のSQLのトレース結果を表示します。

**例：**

```sql
SHOW TRACE;
```
