# 概要

データベースにおけるクエリリライト（Query Rewrite）とは、あるSQL文をより最適化しやすい別のSQL文に変換することを指します。

OceanBaseデータベースがサポートするクエリリライトルールには、ルールベースのクエリリライトとコストベースのクエリリライトがあります。

ルールベースのクエリリライトは常にSQL文を「より良い」方向へと変換し、その結果、そのSQL文の最適化可能性を高めます。典型的なルールベースのリライト例として、サブクエリを結合に変換することが挙げられます。リライトしない場合、サブクエリの実行方法はネステッドループ結合（Nested Loop Join）しかありませんが、リライト後はオプティマイザーがハッシュ結合（Hash Join）やマージ結合（Merge Join）といった実行方法も検討できるようになります。

一方、コストベースのクエリリライトは必ずしもSQL文を「より良い」方向へと変換するわけではなく、コストモデルを用いて判断する必要があります。典型的なコストベースのリライト例として、OR展開（OR-Expansion）が挙げられます。

データベースにおいて、一つのリライトルールが実現されるためには通常特定の条件を満たす必要があり、また多くのルールのリライトは相互に作用し合うことがあります（あるルールのリライトが別のルールのリライトを引き起こす）。OceanBaseデータベースでは、ルールベースのクエリリライトをいくつかのルールセットに分類しています。各ルールセットに対して、OceanBaseデータベースは反復的な手法を用いてリライトを行い、SQL文が変換不可能になるか、あるいは反復回数が事前に設定されたしきい値に達するまで続けます。同様に、コストベースのリライトルールについてもこの手法を採用しています。

ここで注意すべき点として、コストベースのリライト後に再びルールベースのリライトがトリガーされる可能性があるため、全体としてのコストベースおよびルールベースのリライトもこのような反復的な手法で行われるということです。
