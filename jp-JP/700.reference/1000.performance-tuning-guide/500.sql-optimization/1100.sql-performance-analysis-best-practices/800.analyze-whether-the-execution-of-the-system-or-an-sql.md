# システム全体または特定のSQLの実行で、不適切なリモート実行リクエストが大量に発生していないか分析する

以下のSQLステートメントを実行することで、一定期間における異なるタイプのプランの実行回数を分析できます。

```javascript
obclient> SELECT COUNT(*),plan_type FROM oceanbase.GV$OB_SQL_AUDIT WHERE tenant_id = 1001
   AND  IS_EXECUTOR_RPC = 0
   AND  request_time > (time_to_usec(now()) - 10000000)
   AND  request_time < time_to_usec(now())
   GROUP BY plan_type;
+----------+-----------+
| COUNT(*) | plan_type |
+----------+-----------+
|     2054 |         1 |
|      138 |         0 |
+----------+-----------+
2 rows in set
```

通常、リモート実行リクエストが多く発生する場合、マスター切り替えやProxyクライアントのルーティングが不正確である可能性があります。
