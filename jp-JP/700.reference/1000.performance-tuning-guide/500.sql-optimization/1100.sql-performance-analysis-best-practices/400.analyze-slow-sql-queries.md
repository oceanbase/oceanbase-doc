# スロークエリの分析

特定のSQLクエリが常に遅いことが分かっている場合、以下の方法で分析できます：

* SQL Auditを使用して統計データを確認し、そのSQLの実行計画を分析します。詳細な手順については、以下の例を参照してください。

  [RTが急激に変動するSQLの分析](200.sql-statement-that-analyzes-sudden-jitter-of-rt.md)。

* 実行計画が正しいかどうかを分析します。詳細な手順については、例[実行計画の構造を確認し、分析する](300.view-and-analyze-the-execution-plan.md)を参照してください。
