# メモリツール

## free

`free` コマンドは、マシン全体のメモリ使用状況を確認するために使用します。

コマンドライン形式：

```shell
free [<options>]
```

パラメータ説明：

options の取り得る値は以下のとおりです：

* -m：メモリ値をMB単位で換算します。デフォルトはKBです。

* -g：メモリ値をGB単位で換算します。デフォルトはKBです。

マシン全体のメモリ使用状況を確認する例：

```shell
$free
              total        used        free      shared  buff/cache   available
Mem:      791791184    80578952   528945156       68244   182267076   702805628
Swap:             0           0           0
```

フィールド説明：

* total：物理メモリの合計サイズを表します。物理メモリの合計サイズ = 空き物理メモリ + キャッシュメモリ + 使用済み物理メモリ。

* used：使用済み物理メモリの合計サイズを表します。

* free：空き物理メモリの合計サイズを表します。

* shared：共有メモリの合計サイズを表します。

* buff/cache：キャッシュメモリの合計サイズを表します。

* available：利用可能な物理メモリの合計サイズを表します。利用可能な物理メモリの合計サイズ = 空き物理メモリ + キャッシュメモリ。
