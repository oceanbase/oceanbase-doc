# メモリツール

## free

`free` コマンドは、マシン全体のメモリ使用状況を確認するために使用されます。

コマンドライン形式：

```unknow
free [<options>]
```

パラメータの説明：

options の値は以下のとおりです：

* -m：メモリ値をMB単位で換算します。デフォルトはKBです。

* -g：メモリ値をGB単位で換算します。デフォルトはKBです。

マシン全体のメモリ使用状況を確認する例：

```unknow
$free
              total        used        free      shared  buff/cache   available
Mem:      791791184    80578952   528945156       68244   182267076   702805628
Swap:             0           0           0
```

フィールドの説明：

* total：物理メモリの合計を表します。物理メモリの合計 = 空き物理メモリの合計 + キャッシュメモリの合計 + 使用済み物理メモリの合計。

* used：使用済み物理メモリの合計を表します。

* free：空き物理メモリの合計を表します。

* shared：共有メモリの合計を表します。

* buff/cache：キャッシュメモリの合計を表します。

* available：利用可能な物理メモリの合計を表します。利用可能な物理メモリの合計 = 空き物理メモリの合計 + キャッシュメモリの合計。
