# ASHの概要

## ASHとは

ASH（Active Session History）は、データベース内のすべてのアクティブセッション情報を記録する診断ツールです。
ASHレポート（OceanBase Active Session History Report）は、一時的な性能異常の原因を特定するための分析レポートです。一般的なパフォーマンスレポートは時間単位のスナップショットを扱うため、短時間の性能変動が起きた際に、個々のセッションで何が実行されていたかまでは把握できません。ASHレポートでは、セッション単位の診断情報から実行状況を詳しく調べられます。

## 適用シナリオ

ASHレポートは、瞬時に発生する異常の診断に使用されます。通常、以下のシナリオでの問題特定に役立ちます：

* 数分間だけ続く一時的な性能問題。
* 時間、セッション、モジュール、操作、またはSQL文など、さまざまな観点からのパフォーマンス問題。

このレポートにより、過去の診断期間内にデータベースリソースを多く消費したSQLや、OceanBaseクラスタの履歴セッションの実行詳細などの情報を把握できます。これらの情報を基にSQLを最適化することで、SQLの実行効率を向上させることができます。
