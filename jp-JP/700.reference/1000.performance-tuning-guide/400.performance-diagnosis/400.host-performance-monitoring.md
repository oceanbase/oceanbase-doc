# ホスト性能監視

本記事では、OceanBaseクラスタのホストの性能監視を確認する方法について説明します。

## 手順

1. OCPにログインし、左側のナビゲーションバーで **ホスト** をクリックします。

2. **ホスト概要** ページの **ホスト一覧** エリアで、操作対象のホストを選択し、そのマシンIPアドレスをクリックします。

3. 表示されたページのナビゲーションバーで、**モニタリング** をクリックします。

4. **モニタリング** タブで、モニタリングウィンドウを設定し、モニタリングデータを確認できます。
     <!-- ![1129](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/host1.png) -->
   * **自動更新** をオフにした場合：**過去1時間** をクリックすると、実際の使用状況に応じて、過去1時間、過去1日、過去1週間、およびカスタム時間内のモニタリング状況を確認できます。
   * **自動更新** をオンにした場合：システムはそのホストのモニタリングデータをリアルタイムで表示します。
5. **ホスト性能** および **ホストリソース** タブで、それぞれホストのモニタリングデータを確認します。
   ここで、すべてのモニタリング項目の具体的な意味と値の出所については、[モニタリング指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001540061)を参照してください。
   以下の機能を使用すると、トレンドグラフでのパフォーマンスモニタリングデータの表示と分析がより容易になります。画像と以下の説明を組み合わせて理解することができます。
   <!-- ![1129](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8901044461/p360505.png) -->
   * 特定の期間における特定の指標の詳細な傾向を確認するには、その領域をマウスでドラッグして選択します。システムはその領域の傾向情報を拡大表示し、そのトレンドグラフをダブルクリックすると元に戻ります。

   * 他のサブ指標のデータを非表示にするには、他のサブ指標のアイコンをクリックしてグレーアウトし、トレンドグラフにはその指標情報が表示されなくなります。

   * 特定の時点の詳細データを確認するには、トレンドグラフの特定の時点にマウスをポインターを移動します。

   * あるトレンドグラフを拡大するには、トレンドグラフの右上隅にある拡大アイコンをクリックします。上記の①、②、③の機能は、拡大されたトレンドグラフでも同様に適用されます。
    パフォーマンス指標の詳細については、[モニタリング指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001540061)を参照してください。

   <!-- ![ob11](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8729721461/p347740.png) -->
