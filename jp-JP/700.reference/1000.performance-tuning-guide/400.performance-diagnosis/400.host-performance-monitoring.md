# ホスト性能監視

本記事では、OceanBaseクラスタのホストの性能監視方法について説明します。

## 手順

1. OCPにログインし、左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.component.ArchitectureAndVpcAlert.Host">ホスト</UI-TERM>**をクリックします。

2. **ホスト概要**ページの**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">ホスト一覧</UI-TERM>**エリアで、操作対象のホストを選択し、そのマシンのIPアドレスをクリックします。

3. 表示されたページのナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>**をクリックします。

4. **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>**タブでは、監視ウィンドウを設定し、監視データを確認できます。
     <!-- ![1129](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/host1.png) -->
   * **<UI-TERM key="src.page.WorkBench.components.MaterializedViewPage.MvViewPageBaseInfoForm.0E601450">自動更新</UI-TERM>**をオフの場合：**<UI-TERM key="ocp-v2.src.component.RangeTimeDropdown.LastHour">最近1時間</UI-TERM>**をクリックすると、実際の使用ニーズに応じて、過去1時間、過去1日、過去1週間、およびカスタム時間内の監視状況を確認できます。
   * **<UI-TERM key="src.page.WorkBench.components.DDLResultSet.Sync.584F1D7B">自動更新</UI-TERM>**をオンの場合：システムがそのホストの監視データをリアルタイムで表示します。
5. **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostPerformance">ホストパフォーマンス</UI-TERM>**および**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostResources">ホストリソース</UI-TERM>**タブで、それぞれホストの監視データを確認します。
   ここでのすべての監視項目の具体的な意味と値の出典については、[監視指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001540061)を参照してください。
   以下の機能は、トレンドグラフでの性能監視データの表示と分析をより効果的に行うのに役立ちます。画像と以下の説明を組み合わせて理解してください。
   <!-- ![1129](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8901044461/p360505.png) -->
   * 特定の指標の特定の期間の詳細なトレンドを見る：マウスでその範囲をドラッグして選択すると、システムはその範囲のトレンド情報を拡大表示します。このトレンドグラフをダブルクリックすると元に戻ります。

   * 他のサブ指標のデータを非表示にする：他のサブ指標のアイコンをクリックして灰色にすると、その指標情報はトレンドグラフに表示されません。

   * 特定の時刻の詳細データを見る：トレンドグラフ上の特定の時刻にマウスカーソルを合わせます。

   * 特定のトレンドグラフを拡大する：トレンドグラフの右上隅にある拡大アイコンをクリックします。上記の①、②、③の機能は、拡大したトレンドグラフでも同様に適用されます。
    より詳細な性能指標については、[監視指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001540061)を参照してください。
