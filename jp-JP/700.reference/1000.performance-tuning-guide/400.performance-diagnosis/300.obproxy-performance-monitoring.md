# OBProxyのパフォーマンス監視

本記事では、OBProxyのパフォーマンス監視の確認方法について説明します。

## OBProxyのパフォーマンス監視

1. OCPにログインし、左側のナビゲーションバーで **OBProxy** をクリックします。

2. **OBProxyページ** の **OBProxyクラスターリスト** エリアで、操作対象のOBProxyクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**パフォーマンス監視** をクリックします。

4. **パフォーマンス監視** ページでリアルタイムパフォーマンススイッチをオンにすると、パフォーマンスのリアルタイム変化を確認できます。

   <!-- ![monitor](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2729721461/p347751.png) -->

   **監視データのフィルタリングに関する説明**

   | 絞り込み対象 |                  説明                   |
   |------|---------------------------------------|
   | 選択時間 | モニタリングの表示期間です。過去30日間のデータを確認できます。               |
   | 統計周期 | 収集したモニタリング指標について、分単位および10秒単位で平均値を集計・表示できます。デフォルトは分単位です。 |
