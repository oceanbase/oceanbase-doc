# OBProxyのパフォーマンスモニタリング

本記事では、OBProxyのパフォーマンスモニタリングを確認する方法について説明します。

## OBProxyのパフォーマンスモニタリング

1. OCPにログインし、左側のナビゲーションバーで **OBProxy** をクリックします。

2. **OBProxyページ** の **OBProxyクラスタリスト** エリアで、操作対象のOBProxyクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**パフォーマンスモニタリング** をクリックします。

4. **パフォーマンスモニタリング** ページでリアルタイムパフォーマンススイッチをオンにすると、パフォーマンスのリアルタイム変化を確認できます。

   <!-- ![monitor](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2729721461/p347751.png) -->

   **モニタリングデータのフィルタリングに関する説明**

   | 篩選対象 |                  説明                   |
   |------|---------------------------------------|
   | 選択時間 | モニタリング表示の時間範囲で、過去30日間のデータを確認できます。               |
   | 統計周期 | 収集したモニタリング指標について、分単位および10秒単位で平均値を統計し表示することができます。デフォルトは分単位です。 |

   OBProxyのパフォーマンスモニタリングの詳細については、[パフォーマンスモニタリング](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001542119)を参照してください。
