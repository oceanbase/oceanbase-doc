# OBProxyパフォーマンス監視

本記事では、OBProxyのパフォーマンス監視の確認方法について説明します。

## OBProxyパフォーマンス監視

1. OCPにログインし、左側のナビゲーションバーで**OBProxy**をクリックします。

2. **OBProxyページ**の**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ObproxyClusterList">OBProxy クラスターリスト</UI-TERM>**エリアで、操作対象のOBProxyクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**をクリックします。

4. **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**ページでリアルタイムパフォーマンススイッチをオンにすると、パフォーマンスのリアルタイム変化を確認できます。

   <!-- ![monitor](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2729721461/p347751.png) -->

   **監視データのフィルタリングについて**

   | フィルタリング対象 |                  説明                   |
   |------|---------------------------------------|
   | 選択時間 | 監視データを表示する期間です。過去30日間のデータを確認できます。               |
   | 統計周期 | 収集した監視指標を1分または10秒ごとに集計し、平均値を表示できます。デフォルトは分単位です。 |

   OBProxyのパフォーマンス監視の詳細については、[パフォーマンス監視](https://docs.oceanbase.com/ocp/V4.2.2-view-service-monitoring)を参照してください。
