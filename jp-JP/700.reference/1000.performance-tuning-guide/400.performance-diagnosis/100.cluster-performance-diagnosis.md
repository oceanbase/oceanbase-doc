# クラスタ性能診断

本記事では、OceanBaseクラスタの性能監視と性能診断の方法について説明します。

## クラスタ性能監視

### 手順

1. OCPにログインし、左側のナビゲーションバーで、**<UI-TERM key="oceanbase-intl-console.HomeWorkspace.OperationEvent.utils.Cluster">クラスタ</UI-TERM>**をクリックします。

2. **<UI-TERM key="ocp-v2.Alarm.LogFilter.Cluster">クラスター</UI-TERM>**ページの**<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスター一覧</UI-TERM>**エリアで、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**をクリックします。

4. リアルタイム性能スイッチをオンにすると、性能のリアルタイム変化を確認できます。

<!-- ![クラスタパフォーマンス監視](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%95%B0%E6%8D%AE%E5%BA%93%E6%80%A7%E8%83%BD1.png) -->

監視データのフィルタリングについては以下のとおりです。

|   フィルタ対象   |                                           説明                                            |
|----------|-----------------------------------------------------------------------------------------|
|  選択時間（別名：監視ウィンドウ） | 自動更新モードでは表示されません。特定の期間を選択すると、その期間内のデータが返されます。  |
|自動更新  |デフォルトでオフです。オンにすると、5秒ごとに更新されます。|
| Zone     | OceanBaseは分散データベースであり、クラスタ監視は複数のZoneから収集・集計されたものです。集計方法は指標タイプによって決まります。単一のZoneを選択すると、そのZoneの監視データが表示されます。             |
| OBServer | OceanBaseは分散データベースであり、クラスタ監視は複数のOBServerから収集・集計されたものです。集計方法は指標タイプによって決まります。単一のOBServerを選択すると、そのOBServerの監視データが表示されます。 |

性能指標はデータベース性能とホスト性能に分かれています。詳細な性能指標については、[監視指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001538863)を参照してください。

## クラスタ性能レポート

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>現在、コミュニティ版OCPは性能レポートの生成をサポートしていません。</p>
  </main>

### 手順

1. OCPにログインし、左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">クラスター</UI-TERM>**をクリックします。

2. **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Cluster">クラスター</UI-TERM>**ページの**<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスター一覧</UI-TERM>**エリアで、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Report.PerformanceReport">性能レポート</UI-TERM>**をクリックします。

4. **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.GeneratePerformanceReports">パフォーマンスレポートを生成する</UI-TERM>**をクリックし、開始と終了のスナップショットポイントを選択して、クラスタのレポートを生成します。

5. **<UI-TERM key="odc.component.RecordPopover.components.View">見る</UI-TERM>**をクリックすると、パフォーマンスレポートの表示が完了します。システムは過去90日間のレポートを保持します。

6. **<UI-TERM key="src.page.Workspace.Worksheets.List.Explore.BC958743">ダウンロード</UI-TERM>**をクリックすると、パフォーマンスレポートのダウンロードが完了します。

<!-- ![クラスタパフォーマンスレポート](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1329721461/p347156.png) -->

パフォーマンスレポートに含まれる内容は以下のとおりです。

|  モジュール  |                 説明                  |
|------|-------------------------------------|
| 基本情報 | バージョン、ノードリソース、テナントリソース、データパーティションなどの情報が含まれます。             |
| ワークロード | クラスタのワークロード情報。                           |
| SQL  | 応答時間、待機イベント、CPUなどの指標で集計したTopSQL情報。 |
| ロック    | 行ロックリクエスト、待機、タイムアウトなどの情報が含まれます。                    |

クラスタのパフォーマンスレポートに関する詳細は、[パフォーマンスレポート](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001542084)を参照してください。
