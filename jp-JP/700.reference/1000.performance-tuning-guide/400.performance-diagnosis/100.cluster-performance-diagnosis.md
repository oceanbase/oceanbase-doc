# クラスタパフォーマンス診断

本記事では、OceanBaseクラスタのパフォーマンス監視とパフォーマンス診断の方法について説明します。

## クラスタパフォーマンス監視

### 手順

1. OCPにログインし、左側のナビゲーションバーで **クラスタ** をクリックします。

2. **クラスタ** ページの **クラスタリスト** エリアで、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**パフォーマンス監視** をクリックします。

4. リアルタイムパフォーマンススイッチをオンにすると、パフォーマンスのリアルタイム変化を確認できます。

<!-- ![クラスタパフォーマンス監視](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%95%B0%E6%8D%AE%E5%BA%93%E6%80%A7%E8%83%BD1.png) -->

監視データのフィルタリングについては以下のとおりです。

|   絞り込み対象   |                                           説明                                            |
|----------|-----------------------------------------------------------------------------------------|
|  選択時間（別名：監視ウィンドウ） | 自動更新モードでは表示されません。特定の期間を選択すると、その期間内のデータが返されます。  |
|自動更新  |デフォルトはオフです。オンにすると、5秒ごとに更新されます。|
| Zone     | OceanBaseは分散データベースであり、クラスタ監視は複数のZoneから収集・集計されたものです。集計方法はメトリックの種類によって決まります。単一のZoneを選択すると、そのZoneの監視データが表示されます。             |
| OBServer | OceanBaseは分散データベースであり、クラスタ監視は複数のOBServerから収集・集計されたものです。集計方法はメトリックの種類によって決まります。単一のOBServerを選択すると、そのOBServerの監視データが表示されます。 |

パフォーマンス指標はデータベースパフォーマンスとホストパフォーマンスに分かれています。<!-- 詳細なパフォーマンス指標については、[監視指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001538863)を参照してください。 -->

## クラスタパフォーマンスレポート

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>現在、コミュニティ版OCPはパフォーマンスレポートの生成をサポートしていません。</p>
  </main>

### 手順

1. OCPにログインし、左側のナビゲーションバーで **クラスタ** をクリックします。

2. **クラスタ** ページの **クラスタリスト** エリアで、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**パフォーマンスレポート** をクリックします。

4. **パフォーマンスレポートの生成** をクリックし、開始と終了のスナップショットポイントを選択して、クラスタのレポートを生成します。

5. **表示** をクリックすると、パフォーマンスレポートの閲覧が完了します。システムは過去90日間のレポートを保持します。

6. **ダウンロード** をクリックすると、パフォーマンスレポートのダウンロードが完了します。

<!-- ![クラスタパフォーマンスレポート](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1329721461/p347156.png) -->

パフォーマンスレポートに含まれる内容は以下のとおりです。

|  モジュール  |                 説明                  |
|------|-------------------------------------|
| 基本情報 | バージョン、ノードリソース、テナントリソース、データパーティションなどの情報が含まれます。             |
| ワークロード | クラスタのワークロード情報。                           |
| SQL  | 応答時間、待機イベント、CPUなどの指標に基づいて集計されたTopSQL情報。 |
| ロック    | 行ロックのリクエスト、待機、タイムアウトなどの情報が含まれます。                    |
