# テナントのパフォーマンス診断

本記事では、OceanBaseテナントのパフォーマンス監視と診断の方法について説明します。

## テナントのパフォーマンス監視

1. OCPにログインし、左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Cluster.Arbitration.Tenant">テナント</UI-TERM>**をクリックします。

2. **テナント概要**ページの**<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>**エリアで、操作対象のテナントを選択し、そのテナント名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**をクリックします。

4. リアルタイムパフォーマンススイッチをオンにすると、パフォーマンスのリアルタイム変化を確認できます。

<!-- ![テナントのパフォーマンス監視](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/tenent-performance.png) -->

|   絞り込み対象   |                                                           説明                                                            |
|----------|-------------------------------------------------------------------------------------------------------------------------|
| 選択時間     | 監視表示の時間範囲。過去30日間のデータを確認できます。                                                                                                 |
|自動更新  |デフォルトはオフです。オンにすると、5秒ごとに更新されます。|
| Zone     | OceanBaseは分散データベースであり、テナントのデータレプリカは複数のZoneに配置されています。テナントの監視データは、複数のZoneにあるレプリカから収集・集計されます。集計方法は指標の種類によって決まります。単一のZoneを選択すると、そのZoneが存在するテナントのレプリカの監視データのみが表示されます。                 |
| OBServer | OceanBaseは分散データベースであり、テナントのデータレプリカは複数のOBServerに配置されています。テナントの監視データは、複数のOBServerにあるレプリカから収集・集計されます。集計方法は指標の種類によって決まります。単一のOBServerを選択すると、そのOBServerが存在するテナントのレプリカの監視データのみが表示されます。 |

パフォーマンス指標は、パフォーマンス、SQL、トランザクション、ストレージとキャッシュに分かれています。詳細については、[監視指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001538876)を参照してください。

## テナントSQL診断

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>現在、コミュニティ版OCPは疑わしいSQL診断機能をサポートしていません。</p>
  </main>

1. OCPにログインし、左側のナビゲーションバーで、**テナント**をクリックします。

2. テナント概要ページのテナントリストエリアで、操作対象のテナントを選択し、そのテナント名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**SQL診断**をクリックします。

<!-- ![SQL診断](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7232489461/p429724.png) -->

SQLは4種類の診断機能を提供します。以下では、パフォーマンス異常、全体把握、スロークエリの観点から分析します。

|   機能    |                                         説明                                         |
|---------|------------------------------------------------------------------------------------|
| サスペクトSQL  | OCPのSQL診断エンジンは、パフォーマンス異常なSQLを識別し、診断結果を提供します。実行計画の変更、パフォーマンスの低下、実行スパイクなどのシナリオを識別できます。まずサスペクトSQLの結果に基づいてSQLを最適化する必要があります。 |
| TopSQL  | TopSQLはフルSQLとも呼ばれ、応答時間でソートされ、上位2000件の表示をサポートしています。TopSQLを通じて、実行中のSQLを全体として把握できます。              |
| SlowSQL | OCPのSQL診断エンジンは、単一実行で100msを超えるSQLを抽出します。スロークエリの観点からSQLを最適化することをサポートしています。                     |
|ParallelSQL |ParallelSQLとは、テナント内で並列スケジューリングメカニズムを使用して実行されるSQLを指します。ParallelSQL診断を通じて、APクエリのパフォーマンスが期待に達していないSQLを確認できます。|

SQL実行計画で最適なインデックスが選択されていない場合、SQL詳細ページでインデックスのオンラインバインドをサポートしています。インデックスをバインドすると、新しいリクエストは新しい実行計画を経由します。

<!-- ![インデックスのバインド](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5629721461/p347420.png) -->

## セッション監視と診断

1. OCPにログインし、左側のナビゲーションバーで、**<UI-TERM key="odc.Connecion.ConnectionList.ParamContext.Tenant">テナント</UI-TERM>**をクリックします。

2. **テナント概要**ページの**<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**エリアで、操作対象のテナントを選択し、そのテナント名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">会話管理</UI-TERM>**をクリックします。

<!-- ![aa](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5629721461/p374560.png) -->

セッション管理機能モジュールの説明

|    モジュール    |                                                             説明                                                              |
|----------|-----------------------------------------------------------------------------------------------------------------------------|
| テナントセッション     | 現在のセッション情報を表示します。アクティブおよび非アクティブセッションが含まれます。指定したセッションに対してKill操作を実行できます。                                                                                    |
| セッション統計     | ユーザー、アクセス元、データベース、アクティブかどうかで分析をサポートします。                                                                                                    |
| デッドロック分析     | 現在のテナント、指定したセッションに対するデッドロック診断をサポートします。                                                                                                         |
| アクティブセッション履歴レポート | 一定期間内のアクティブセッション履歴レポートで、履歴セッションの分析や問題の調査に役立ちます。時間範囲は60分以内に限定され、分析可能なのは直近8日間のセッションのみです。 レポートはオンラインでの閲覧とダウンロードをサポートしており、OCPは過去90日間に生成されたアクティブセッション履歴レポートを保持します。 |

テナントのパフォーマンス診断情報については、[パフォーマンス診断](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001542137)を参照してください。
