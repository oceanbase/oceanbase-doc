# テナントのパフォーマンス診断

本記事では、OceanBaseテナントのパフォーマンス監視と診断の方法について説明します。

## テナントのパフォーマンス監視

1. OCPにログインし、左側のナビゲーションバーで **テナント** をクリックします。

2. **テナント概要** ページの **テナント一覧** エリアで、操作対象のテナントを選択し、そのテナント名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**パフォーマンス監視** をクリックします。

4. リアルタイムパフォーマンススイッチをオンにすると、パフォーマンスのリアルタイム変化を確認できます。

<!-- ![テナントパフォーマンス監視](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/tenent-performance.png) -->

|   篩選対象   |                                                           説明                                                            |
|----------|-------------------------------------------------------------------------------------------------------------------------|
| 選択時間     | モニタリング表示の時間範囲で、過去30日間のデータを確認できます。                                                                                                 |
|自動リフレッシュ  |デフォルトはオフです。オンにすると、5秒ごとにリフレッシュが行われます。|
| Zone     | OceanBaseは分散型データベースであり、テナントは複数のZone上にデータレプリカを持っています。テナントのモニタリングは、複数のZoneのレプリカから収集・集計されています。集計方法はメトリックの種類によって決まります。単一のZoneを選択すると、そのZoneにあるテナントレプリカのモニタリングデータのみが表示されます。                 |
| OBServer | OceanBaseは分散型データベースであり、テナントは複数のOBServer上にデータレプリカを持っています。テナントのモニタリングは、複数のOBServerのレプリカから収集・集計されています。集計方法はメトリックの種類によって決まります。単一のOBServerを選択すると、そのOBServerにあるテナントレプリカのモニタリングデータのみが表示されます。 |

パフォーマンス指標は、パフォーマンス、SQL、トランザクション、ストレージおよびキャッシュに分類されます。詳細については、[監視指標](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001538876)を参照してください。

## テナントSQL診断

  <main id="notice" >
    <h4>適用対象</h4>
    <p>現在、Community EditionのOCPは疑わしいSQL診断機能をサポートしていません。</p>
  </main>

1. OCPにログインし、左側のナビゲーションバーで **テナント** をクリックします。

2. テナント概要ページのテナント一覧エリアで、操作対象のテナントを選択し、そのテナント名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**SQL診断** をクリックします。

<!-- ![SQL診断](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7232489461/p429724.png) -->

SQLは4種類の診断機能を提供しており、以下ではそれぞれパフォーマンス異常、グローバル管理、スロークエリの観点から分析します。

|   機能    |                                         説明                                         |
|---------|------------------------------------------------------------------------------------|
| 疑わしいSQL  | OCPのSQL診断エンジンは、パフォーマンス異常なSQLを識別し、診断結果を提供します。実行計画の変更、パフォーマンスの低下、実行の急増などのシナリオを識別できます。疑わしいSQLの結果に基づいて、SQLのチューニングを優先的に行う必要があります。 |
| TopSQL  | TopSQLはフルSQLとも呼ばれ、応答時間に基づいてソートされ、Top 2000の表示をサポートしています。TopSQLを使用すると、実行中のSQLを全体的に把握できます。              |
| SlowSQL | OCPのSQL診断エンジンは、単一実行に100ms以上かかるSQLを抽出します。遅延クエリの観点から、SQLのチューニングをサポートしています。                     |
|ParallelSQL |ParallelSQLとは、テナント内で並列スケジューリングメカニズムを使用して実行されるSQLを指します。ParallelSQL診断を通じて、APクエリのパフォーマンスが予想に達していないSQLを確認できます。|

SQL実行計画で最適なインデックスが選択されていない場合、SQL詳細ページでオンラインインデックスバインディングをサポートしています。インデックスをバインドすると、新しいリクエストは新しい実行計画を使用します。

<!-- ![インデックスバインディング](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5629721461/p347420.png) -->

## セッションの監視と診断

1. OCPにログインし、左側のナビゲーションバーで **テナント** をクリックします。

2. **テナント概要** ページの **テナント一覧** 項目で、操作対象のテナントを選択し、そのテナント名をクリックします。

3. 表示されたページの左側のナビゲーションバーで、**セッション管理** をクリックします。

<!-- ![aa](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5629721461/p374560.png) -->

セッション管理機能モジュールの説明

|    モジュール    |                                                             説明                                                              |
|----------|-----------------------------------------------------------------------------------------------------------------------------|
| テナントセッション     | 現在のセッション情報を表示します。アクティブおよび非アクティブなセッションが含まれます。指定されたセッションに対してKill操作を実行できます。                                                                                    |
| セッション統計     | ユーザー、アクセス元、データベース、アクティブかどうかに基づいて分析をサポートします。                                                                                                    |
| デッドロック分析     | 現在のテナント、指定されたセッションに対するデッドロック診断をサポートします。                                                                                                         |
| アクティブセッション履歴レポート | 一定期間内のアクティブセッション履歴レポートであり、履歴セッションの分析や問題のトラブルシューティングに役立ちます。時間範囲は60分以内に制限され、分析対象となるのは過去8日間のセッションのみです。 レポートはオンライン閲覧およびダウンロードに対応しており、OCPは過去90日以内に生成されたアクティブセッション履歴レポートを保持します。 |

テナントのパフォーマンス診断情報の詳細については、[パフォーマンス診断](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001542137)を参照してください。
