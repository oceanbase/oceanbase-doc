# OceanBase移行サービス（OMS）

OceanBase移行サービス（OceanBase Migration Service、OMS）は、OceanBaseデータベースが提供するサービスであり、同一構造または異なる構造のデータソースとOceanBaseデータベース間でのデータ交換をサポートします。既存データのオンライン移行および増分データのリアルタイム同期機能を備えています。

OMSは可視化された集中管理プラットフォームを提供しており、簡単な設定だけでリアルタイムにデータを移行できます。OMSは、同一構造または異なる構造のデータベースからOceanBaseへのリアルタイムデータ移行とデータ同期を、低リスク、低コスト、かつ高効率で実現できるよう支援することを目的としています。

## 特徴と利点

* 複数のデータソースをサポート

  OMSはMySQLやKafkaなど、さまざまなタイプのデータソースとOceanBaseデータベース間でリアルタイムのデータ転送をサポートしています。具体的な機能は、ソース側のデータベースの種類やターゲット側の下流端末の種類によって異なります。

* オフラインでの移行なし、業務アプリケーションへの影響なし

  サービスを停止することなく、OMSを使用してOceanBaseへのデータ移行をシームレスに実現できます。アプリケーションがOceanBaseデータベースに切り替わると、OceanBaseデータベース上のすべての変更データが、切り替え前のソース側データベースにリアルタイムで同期されます。

  OMSは、業務移行のリスクを低減し、企業ユーザーが高可用性・高信頼性のデータアーキテクチャを構築するのに役立ちます。

* 高パフォーマンスなデータ移行、安全かつ信頼性が高い

  OMSは、異種ITインフラ間で大量のデータを準リアルタイムで秒単位の遅延で複製できます。そのため、データ移行、都市間または地域間のデータ災害復旧、緊急システム、リアルタイムデータ同期、ディザスタリカバリ、データベースのアップグレードおよび移植など、多様なシナリオで利用できます。

  OMSは、業務アプリケーションへの影響や中断を一切発生させることなく、データ移行およびデータ同期タスクを実行し、データの完全性とトランザクションの一貫性を保証します。フル移行のパフォーマンスは100MB/s、20万TPSに達し、データ同期のパフォーマンスは50,000RPSに達します。同時に、OMSは高可用性のデプロイメントアーキテクチャを提供し、データ移行とリアルタイム同期に安定した信頼性の高い転送プロジェクトを提供します。

* ワンストップの対話

  データ移行のライフサイクル全体の管理をサポートします。管理コンソール画面で、データ移行タスクの作成、設定、監視を操作でき、操作が簡単です。

* リアルタイムデータ同期による業務の疎結合化

  OMSは、OceanBaseの2種類のテナントと自社構築のKafka、RocketMQ間でのデータのリアルタイム同期をサポートしており、リアルタイムデータウェアハウスの構築、データクエリ、レポートの分散などの業務シナリオで活用できます。

* 複数のデータ検証

  様々なデータ整合性検証方法を提供し、より包括的かつ時間と労力を節約しながら、データ品質を効率的に保証します。同時に差分データを表示し、迅速な訂正版の提供を可能にします。

* OceanBaseの簡単な移行を支援

  OceanBaseデータベースの各バージョンの特性に完全に適応し、データベースオブジェクトの収集と変換をインテリジェントに処理し、ソース側のサービス停止なしでの移行をサポートします。

## 適用シナリオ

本記事では、OceanBase Migration Service（OMS）のエンタープライズ向けデータベース移行およびデータ同期機能の適用シナリオについて説明します。

### データベースの無停止移行

![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/EN_US/700.reference/1400.oceanbase-tools/In-service-data-migration.png)

従来のデータベース移行ソリューションでは、移行タスクの安定性とデータの一貫性を確保するため、通常は停止移行方式でデータ移行が行われます。停止期間中は、ソース側データベースへの書き込みを一時的に停止し、移行完了後にデータの一貫性を確認してから、業務データベースに切り替えます。

停止移行の所要時間は、業務データ量やネットワーク状況に関連しており、業務量が非常に多い場合、データベースの停止移行には数日かかる可能性があり、業務への影響も大きくなります。

OMSが提供する無停止データ移行機能は、移行プロセス中もソースデータベースが継続的に外部にサービスを提供できるため、データ移行による業務への影響を最小限に抑えることができます。構造移行、フルデータ移行、増分データ移行が完了し、データ検証に合格した後、業務はソース側からターゲット側に切り替えることができます。

### リアルタイムデータ同期

OMSのデータ同期機能は、OceanBaseなどのデータベースの増分データを、自社構築のKafkaやRocketMQなどのメッセージキューにリアルタイムで同期することをサポートしており、メッセージ処理能力を向上させ、モニタリングデータ集計、ストリーミングデータ処理、オンラインおよびオフライン分析など、ビッグデータ分野における業務の全方位的な応用を拡張します。

OMSは、OceanBaseの物理テーブルと自社構築のKafkaなどのデータソース間のデータリアルタイム同期をサポートしており、クラウドBI、リアルタイムデータウェアハウスの構築、データクエリ、レポート分散など、多様な業務シナリオで利用できます。

### 高可用性、柔軟なデプロイ

* ストア(Store)および増分同期(Incr-Sync)コンポーネントは、単一ノードでもHA機能をサポートしています。StoreまたはIncr-Syncコンポーネントに障害が発生した場合、異常なプロセスを再起動します。

  ![HA1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/EN_US/700.reference/1400.oceanbase-tools/HA1.png)

* ラックマウントレベルの災害復旧をサポートしています。

  ![HA2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/EN_US/700.reference/1400.oceanbase-tools/HA2.png)

  * マシンがダウンした場合、そのマシン上のすべてのコンポーネントを適切なマシンに移行します。

  * マシンのリソース指標が異常な場合、一部のコンポーネントに対してロードバランシングを試みます。

  * Storeに障害が発生した場合、マシンのリソースが十分な場合は再起動を試みます。マシンのリソースが不足している場合は、ロードバランシングを行うか、冗長Storeを削除します。

  * Incr-Syncに障害が発生した場合、異常なプロセスを再起動します。

* リージョンデータセンターレベルの災害復旧をサポートしています。

  OMSは、増分ログの読み取りと増分同期書き込みを分離してデプロイすることをサポートしており、複数のトランスポート制御プロトコル(Transmission Control Protocol, TCP)接続による並列転送、データ圧縮、データ暗号化などの最適化手法を通じて、長距離、劣悪なネットワーク条件、データの安全性などの課題を克服しています(現在はリージョン間のスケジューリングはサポートされていません)。

  ![HA3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/EN_US/700.reference/1400.oceanbase-tools/HA3.png)

## プロダクト機能

OMSはデータ移行およびデータ同期機能をサポートしています：

* データ移行：データ移行は一回限りのタスクであり、移行完了後にプロジェクトリソースを解放できます。データ移行機能を使用することで、同一構造または異なる構造のデータソース間でのデータ移行を実現でき、データベースのアップグレード、インスタンス間のデータ移行、データベースのスケーリング、拡張などのビジネスシナリオに適しています。

  データ移行プロジェクトは、OMSのデータ移行機能の基本単位です。移行プロジェクトを作成する際、指定可能な最大移行範囲はデータベースレベル、最小移行範囲はテーブルレベルです。データ移行がサポートするプロジェクトタイプや移行タイプなどの詳細については、[データ移行](../../500.data-migration/100.data-migration-overview.md)モジュールのドキュメントを参照してください。

* データ同期：データ同期は継続的な動作であり、プロジェクト作成後も常にデータを同期し、ソース側とターゲット側のデータの一貫性を保ち、重要な業務のデータをリアルタイムで流動させます。データ同期機能を使用することで、データソース間のリアルタイム同期を実現でき、データのリージョン別アクティブアクティブ構成、リージョン別災害復旧、データ集計、リアルタイムデータウェアハウスなど、多様なビジネスシナリオに適しています。詳細については、[データ同期](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000000095)モジュールのドキュメントを参照してください。
