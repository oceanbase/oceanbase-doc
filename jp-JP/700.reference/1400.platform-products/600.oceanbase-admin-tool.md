# OceanBase管理者ツール(OAT)

OceanBase管理者ツール(OceanBase Admin Toolkit、OAT)は、OceanBaseエコシステム製品とコンポーネントのインストールおよび管理を行うための可視化プラットフォームです。OceanBaseエコシステム製品には、OceanBaseクラウドプラットフォーム(OceanBase Cloud Platform、OCP)、OceanBase開発者センター(OceanBase Development Center、ODC)、OceanBaseアクセスプロキシ(OB Sharding)、およびOceanBase移行サービス(OceanBase Migration Service、OMS)が含まれます。OceanBaseコンポーネントには、MetaDB、OBDNS、InfluxDB、NLBが含まれます。

OATの機能は以下のとおりです：

* OceanBaseサーバーの管理と運用。

* OceanBaseエコシステム製品のインストール、運用、およびアンインストール。

* OceanBaseコンポーネントのインストール、運用、およびアンインストール。
