# OceanBase管理者ツール(OAT)

OceanBase管理者ツール(OceanBase Admin Toolkit、OAT)は、OceanBaseエコシステムのプロダクトおよびコンポーネントをインストールおよび管理するための可視化プラットフォームです。OceanBaseエコシステムのプロダクトには、OceanBaseクラウドプラットフォーム(OceanBase Cloud Platform、OCP)、OceanBase開発者センター(OceanBase Development Center、ODC)、OceanBaseアクセスプロキシ(OB Sharding)、およびOceanBase移行サービス(OceanBase Migration Service、OMS)が含まれます。OceanBaseコンポーネントには、MetaDB、OBDNS、InfluxDB、NLBが含まれます。

OATの機能は以下のとおりです：

* OceanBaseサーバーの管理および運用保守。

* OceanBaseエコシステムのプロダクトのインストール、運用保守、およびアンインストール。

* OceanBaseコンポーネントのインストール、運用保守、およびアンインストール。
