# OceanBaseクラウドプラットフォーム(OCP)

OceanBaseクラウドプラットフォーム(OceanBase Cloud Platform、OCP)は、OceanBaseデータベースと共に生まれた、OceanBaseを核とするエンタープライズ向けデータベース管理プラットフォームです。

OCPは、OceanBaseクラスタやテナントなどのコンポーネントに対するライフサイクル全体の管理サービスを提供するだけでなく、OceanBase関連のリソース(ホスト、ネットワーク、ソフトウェアパッケージなど)の管理サービスも提供します。これにより、OceanBaseクラスタをより効率的に管理し、企業のIT運用コストを削減できます。

OceanBaseを核とするエンタープライズ向けデータベース管理プラットフォームとして、OCPは豊富な製品機能を備えています：

* **効率的なOceanBaseクラスタ管理**

  * 高可用性をサポートします。

  * 応答速度は秒単位に達します。

* **わかりやすい情報フレームワーク**

  * 全新のオブジェクト指向アーキテクチャ設計により、単一クラスタや単一テナントの没入型管理視点を提供し、ユーザーの心理により合致します。

  * DBAの作業シナリオに基づき、没入型ナビゲーションの機能モジュールを分割しており、機能へのアクセスがより明確です。

* **スムーズで効率的なユーザーパス**

  * コアなJobのタスクを連携設計し、プロセスが明確で途切れることがありません。

  * 運用タスクへのクイックアクセスを提供し、すべてのページからタスクに素早く切り替えられます。

* **視覚化された体験**

  * タスク詳細では、フローチャートと自然で柔軟なキャンバスインタラクションを提供し、タスク進捗の管理がより直感的かつ効率的です。

  * 新規クラスタとテナントのトポロジーマップを追加し、分散型のビジネスロジックを透視し、稼働状態や重要データを表示します。

* **専門的な機能**

  * OceanBaseクラスタのライフサイクル全体の管理を提供します。

  * OceanBaseの特性に合わせて設計された管理機能です。

  * クラスタからセッションへの段階的な管理機能です。

  * 精心設計されたトポロジーマップ機能です。
