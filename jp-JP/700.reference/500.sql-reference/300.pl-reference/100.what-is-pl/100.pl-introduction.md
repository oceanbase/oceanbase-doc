# PLの概要

PLとは、手続き型言語(Procedural Language、PL)のことです。これはSQLを拡張したものであり、通常のSQL文にプログラミング言語の特性を加えたものです。データ操作やクエリ文をPLコード内の手続き型コードに組織し、論理判断やループなどの操作を通じて複雑な機能を実現します。

PLを使用することで、多くの高度な機能を備えたプログラムを作成できます。業務ロジックをデータベース内部にカプセル化することで、より高い抽象性と安全性を提供すると同時に、ネットワークのやり取りを削減し、呼び出し速度を向上させることで、全体的なパフォーマンスを向上させます。

PLの主な利点は以下のとおりです：

* 高パフォーマンス

  PLを使用してデータベースとやり取りする際、処理ロジックはすべてデータベースサーバー上で行われ、必要な結果のみがクライアントに返されます。これにより、アプリケーションサーバーとデータベースサーバー間のデータ交換が大幅に削減され、ネットワークリソースと処理時間が節約されます。

  PLオブジェクトはデータベース内にプリコンパイルされた形式で保存されます。通常のSQLと比較して、オプティマイザーによるPLの最適化度が高く、実行効率も優れています。

* 開発が容易

  PLの多くの特性により、開発者は設計やエラー調査にかかる時間を省略できます。開発者はOceanBaseデータベース独自の開発者センター(OceanBase Developer Center、ODC)を使用して効率的に開発できます。

  詳細については、OceanBase公式WebサイトのODC関連ドキュメントを参照してください。

* 移植性

  データベース開発者にとって、PLは汎用的な標準言語です。PLアプリケーションは、任意のOceanBaseデータベース上で実行可能です。

* 管理が容易

  PLオブジェクトはデータベース内に保存されます。アプリケーションの変更やバージョンのイテレーションを行う際、データベース内のPLオブジェクトを変更するだけで、すべてのアプリケーションに即座に反映され、異なるクライアントコードの更新による差異問題を心配する必要はありません。
