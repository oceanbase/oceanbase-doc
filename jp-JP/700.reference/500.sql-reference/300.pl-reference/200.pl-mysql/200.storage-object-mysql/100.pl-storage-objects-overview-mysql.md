# ステートメントの概要

OceanBaseデータベースのMySQLモードにおけるPLステートメントには、ストアドプロシージャ、ストアド関数、トリガー、およびイベント（EVENT）が含まれます。

OceanBaseデータベースのMySQLモードにおけるPLステートメントオブジェクトには、以下のオブジェクトタイプが含まれます：

* ストアドプロシージャ：このオブジェクトは`CREATE PROCEDURE`で作成され、`CALL`ステートメントで呼び出されます。ストアドプロシージャには戻り値はありませんが、出力パラメータを持つことができ、結果セットを生成してクライアントプログラムに返すこともできます。

* ストアド関数：このオブジェクトは`CREATE FUNCTION`で作成され、組み込み関数と似た使い方をします。ユーザーは式の中でストアド関数を呼び出し、式の評価時に値を返すことができます。

* トリガー：このオブジェクトは`CREATE TRIGGER`で作成され、テーブルに関連付けられます。テーブルへの挿入や更新などの操作によってトリガーが起動されます。

* イベント（EVENT）：このオブジェクトは`CREATE EVENT`で作成されます。イベント（Event）は、特定の時間点または指定された時間間隔で自動的に実行される事前定義されたSQLタスクです。各イベントは、トリガー条件（つまりスケジュール計画）、実行されるSQL文、またはストアドプロシージャで構成されています。イベントの定義はデータベースに保存され、データベースとともに保守されるため、サーバー再起動後でもイベントは計画通りに実行されます。

そのうち、ストアドプロシージャと関数はストアドルーチンに属し、ストアドルーチンとトリガーはステートメントに属します。

各ステートメントには、複数のSQL文からなる本体が含まれており、各SQL文はセミコロン（;）で区切ることができます。ストアドプロシージャの本体は`BEGIN`キーワードで始まり、`END;`キーワードで終わります。
