# CREATE_SNAPSHOT

`CREATE_SNAPSHOT`プロシージャは、クラスタのスナップショット生成をトリガーするために使用され、SYSテナントでのみ利用可能です。

## 構文

```sql
DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT(
    flush_level  VARCHAR(64) DEFAULT 'TYPICAL'
);
```

## パラメータの説明

| **パラメータ** | **説明** |
| --- | --- |
| flush_level | スナップショットタイプを指定します。現在、定期的なスナップショットTYPICALのみがサポートされており、ほとんどの統計データを収集するために使用されます。 |

## 使用方法

ユーザーが手動でスナップショットを作成すると、タイマーが再開始されます。例えば、デフォルトのINTERVALが1時間の場合：

```shell
12:21 タイマーがスナップショットの作成をトリガー
13:21 タイマーが次のスナップショットの作成をトリガー
13:45 ユーザーが手動でスナップショットを作成
14:45 タイマーが次のスナップショットの作成をトリガー
```

## 例

```shell
obclient> CALL DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT(flush_level => 'TYPICAL');
Query OK, 0 rows affected
```
