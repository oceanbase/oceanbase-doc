# DROP_SNAPSHOT_RANGE

`DROP_SNAPSHOT_RANGE`プロシージャは、範囲内のスナップショットを削除するために使用され、SYSテナントでのみ利用可能です。

## 構文

```sql
DBMS_WORKLOAD_REPOSITORY.DROP_SNAPSHOT_RANGE(
    low_snap_id    INT,
    high_snap_id   INT
);
```

## パラメータの説明

| **パラメータ** | **説明** |
| --- | --- |
| low_snap_id | 削除する低スナップショットのID。 |
| high_snap_id | 削除する高スナップショットのID。 |

## 例

```shell
obclient> CALL DBMS_WORKLOAD_REPOSITORY.DROP_SNAPSHOT_RANGE('123','456');
Query OK, 0 rows affected
```
