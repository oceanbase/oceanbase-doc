# MODIFY_SNAPSHOT_SETTINGS

`MODIFY_SNAPSHOT_SETTINGS`プロシージャは、WORKLOAD_REPOSITORY構成を変更するために使用され、SYSテナントでのみ利用可能です。

## 構文

```sql
DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS(
   retention          INT    DEFAULT  NULL,
   interval           INT    DEFAULT  NULL);
```

## パラメータの説明

| **パラメータ** | **説明** |
| --- | --- |
| retention | スナップショットの保持時間で、この時間を超えるスナップショットは自動的に削除されます。単位は分です。[1440分（1日）、52560000分（100年）]の範囲で指定します。<ul><li>値が0の場合、永続的に保持することを意味し、保持時間は57816000分（110年）に設定されます。</li><li>値がNULLの場合、元の保持時間を維持します。</li></ul>|
| interval | 各スナップショット間の間隔を分単位で設定します。[10分、525600分（1年）]の範囲で指定します。<ul><li>値が0の場合、自動および手動スナップショットが無効になり、より大きなシステム定義値（110年）が保持時間として使用されます。</li><li>値がNULLの場合、現在の間隔設定を維持します。</li></ul>|

## 例

```shell
obclient> CALL DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS('2265','16');
Query OK, 0 rows affected
```
