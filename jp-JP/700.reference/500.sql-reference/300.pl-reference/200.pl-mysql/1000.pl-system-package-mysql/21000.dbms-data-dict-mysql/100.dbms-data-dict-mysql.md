# DBMS_DATA_DICT

`DBMS_DATA_DICT`は、データディクショナリのスケジューリングを制御するために使用されます。

## 構文

### データディクショナリのスケジューリングを禁止する

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>実行時にディクショナリ構成パラメータ<a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2300.dump_data_dictionary_to_log_interval.md">dump_data_dictionary_to_log_interval</a>が<code>0</code>以外の場合、実行は失敗し、ユーザーに対してこの構成パラメータを<code>0</code>に設定するよう求められます。</p>
</main>

### データディクショナリのスケジューリングを許可する

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
```

### ディクショナリの生成を手動でトリガーする

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(DICT_ITEM_RETENTION_BY_DAY);
```

### ディクショナリの定期的なDUMP周期を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL(INTERVAL_EXPR);
```

ディクショナリの生成をスケジュールするシナリオ：

* テナント作成後、即座にデータディクショナリの自動生成がトリガーされます。

* アーカイブ機能が有効になると、即座にデータディクショナリの自動生成がトリガーされます。

<main id="notice" >
  <h4>注意</h4>
  <p>実行時には、ディクショナリDUMPサービスが有効状態である必要があります(つまり、<code>ALL DBMS_DATA_DICT.ENABLE_DUMP()</code>を先に実行する)。そうでない場合、実行は失敗します。</p>
</main>

### ディクショナリ履歴の回収間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(DICT_ITEM_RETENTION_BY_DAY)
```

## パラメータの説明

| **パラメータ**           | **説明**                       |**データ型**   |
|------------------|---------------------------------|-------|
|DICT_ITEM_RETENTION_BY_DAY|<ul>トリガー実行により辞書が生成された後、辞書の履歴DUMPレコードを回収するかどうかを示します：<li>パラメータを指定する場合、値の範囲は `0` 以上です。</li><li>パラメータを指定しない場合、またはパラメータが `0` の場合、今回のDUMPでは辞書を回収しません。</li></ul>| INT |
|INTERVAL_expr|期待されるスケジューリング間隔を表します。このパラメータは `DBMS_SCHEDULER` の `REPEAT_INTERVAL` の記述形式に従い、一重引用符で囲む必要があります。例：`'FREQ=MINUTELY; INTERVAL=120'`。その中で：<ul><li>`FREQ` には `SECONDLY`/`DAILY`/`HOURLY`/`WEEKLY`/`YEARLY` を指定できます。</li><li>`INTERVAL` は実行間隔であり、希望する実行間隔の対応する数値を入力します。</li></ul>これら二つを組み合わせると `INTERVAL_expr` となります。 | TEXT |
|DICT_ITEM_RETENTION_BY_DAY|期待される辞書履歴レコードの回収時間を日単位で表します。<br/>`DBMS_DATA_DICT.TRIGGER_DUMP` でパラメータ付きで呼び出す場合と比較して、このストアドプロシージャが実行されると、以降の辞書DUMPでは、今回指定した時間に従って辞書履歴レコードが回収されるようになります（手動でパラメータ付きの `DBMS_DATA_DICT.TRIGGER_DUMP` ストアドプロシージャを実行しない限り）。| INT |

## 例

### データディクショナリのスケジューリングを禁止する

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
Query OK, 0 rows affected
```

### データディクショナリのスケジューリングを許可する

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
Query OK, 0 rows affected
```

### ディクショナリの生成を手動でトリガーする

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(7);
Query OK, 0 rows affected
```

### ディクショナリの定時DUMP周期を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL('FREQ=MINUTELY; INTERVAL=120');
Query OK, 0 rows affected
```

### ディクショナリ履歴の回収間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(7);
Query OK, 0 rows affected
```
