# SET_BALANCE_WEIGHT

`SET_BALANCE_WEIGHT`はパーティションの重みを設定するために使用されます。レベルによって、テーブルレベルとパーティションレベルのパーティション重みを設定できます。

## 制限事項と注意点

* V4.2.5バージョンでは、V4.2.5 BP2以降のバージョンからパーティション重みを手動で設定できるようになりました。

* パーティション重みの手動設定はユーザーテナントのみがサポートしており、システムテナントでは設定できません。

* 現在、パーティションテーブル以外およびパーティションテーブルのパーティションに対してのみパーティション重みの設定が可能です。サブパーティションへの重み設定は現在サポートされていません。

* 既存のエンティティパーティションに対してのみ重みを設定でき、テーブル作成時に重みを指定することはできません。つまり、まずテーブルを作成した後に、そのテーブルに対してパーティション重みを設定する必要があります。

* パーティション重みは整数のみをサポートし、値の範囲は[1, +∞)です。デフォルトでは、パーティションには重みが付けられていません。

* パーティション重みを設定する際は、重みの段階をできるだけ少なくすることを推奨します。最大でも3段階に分けることを推奨します：

  * 大重み = 100% × パーティション数

  * 中重み = 50% × パーティション数

  * 小重み = 1

* 重み均等化に参加する必要がないパーティションテーブルについては、パーティション重みを設定しないことを推奨します。

* パーティション重みを設定する際、下位のパーティションは上位のパーティションの重みをデフォルトで継承します。複数のレベルに同時にパーティション重みを設定した場合、下位の重みが上位の重みを上書きします。

* パーティション重みを設定した後、ユーザーがOffline DDL操作（例えば、Truncate Table、Truncate Partitionなどの操作）を実行してパーティションエンティティに変更が生じた場合、元のパーティション重みも無効になり、ユーザーが再度パーティション重みを設定する必要があります。パーティション重みを無効にする可能性のあるOffline DDLについては、[Online DDLとOffline DDL操作（MySQLモード）](../../../../100.sql-syntax/200.common-tenant-of-mysql-mode/700.ddl-function-of-mysql-mode/150.online-and-offline-ddl-list-of-mysql-mode.md)を参照してください。

## 構文

```sql
DBMS_BALANCE.SET_BALANCE_WEIGHT(
    weight              INT,
    database_name       VARCHAR(65535),
    table_name          VARCHAR(65535),
    partition_name      VARCHAR(65535) DEFAULT NULL,
    subpartition_name   VARCHAR(65535) DEFAULT NULL);
```

## パラメータの説明

| **パラメータ**         | **説明**                                            |
|------------------|-----------------------------------------------------|
| weight           | パーティションの重み。つまり、パーティション間で使用するCPU、メモリ、ディスクなどのリソースの相対的な割合を示します。整数のみをサポートし、値の範囲は[1, +∞)です。 |
| database_name    | テーブルが属するデータベース名  |
| table_name       | テーブル名             |
| partition_name   | パーティション名        |
| subpartition_name| サブパーティション名。構文上はサポートされていますが、現在サブパーティションの重み設定はサポートされていません。      |

## 例

1. ユーザーが`test`データベースにHashパーティションテーブル`tbl1_h`を作成したとします。

    ```shell
    obclient[test]> CREATE TABLE tbl1_h(col1 INT,col2 VARCHAR(50)) PARTITION BY HASH(col1) PARTITIONS 5;
    ```

2. このテーブルのパーティション情報を確認します。

    ```shell
    obclient[test]> SELECT TABLE_NAME, PARTITION_NAME FROM information_schema.PARTITIONS WHERE TABLE_NAME ='tbl1_h';
    ```

    実際のパーティション情報は以下のとおりです：

    ```shell
    +------------+----------------+
    | TABLE_NAME | PARTITION_NAME |
    +------------+----------------+
    | tbl1_h     | p0             |
    | tbl1_h     | p3             |
    | tbl1_h     | p2             |
    | tbl1_h     | p4             |
    | tbl1_h     | p1             |
    +------------+----------------+
    5 rows in set
    ```

3. テーブル`tbl1_h`のテーブルレベルのパーティション重みを1に設定します。

    ```shell
    obclient[test]> CALL DBMS_BALANCE.SET_BALANCE_WEIGHT(1,'test','tbl1_h');
    ```

4. テーブル`tbl1_h`のテーブルレベルのパーティション重みのみを設定した後、テーブルに設定されたパーティション重み情報をクエリします。

    ```shell
    obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    結果は次のとおりです：

    ```shell
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    |   500002 |         NULL |            NULL |      1 | test          | tbl1_h     | NULL           | NULL              | NULL            |      500001 |          NULL |    500002 |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    1 row in set
    ```

5. テーブル`tbl1_h`内のパーティション`p0`のパーティション重みを2に再設定します。

    ```shell
    obclient[test]> CALL DBMS_BALANCE.SET_BALANCE_WEIGHT(2,'test','tbl1_h','p0');
    ```

6. 再びテーブルに設定されたパーティション重み情報をクエリします。

    ```shell
    obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    結果は次のとおりです：

    ```shell
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    |   500002 |         NULL |            NULL |      1 | test          | tbl1_h     | NULL           | NULL              | NULL            |      500001 |          NULL |    500002 |
    |   500002 |       500003 |            NULL |      2 | test          | tbl1_h     | p0             | NULL              | NULL            |      500001 |          NULL |    500003 |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    2 rows in set
    ```
