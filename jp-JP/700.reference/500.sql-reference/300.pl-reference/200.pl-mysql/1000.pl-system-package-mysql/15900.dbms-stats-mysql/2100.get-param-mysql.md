# GET_PARAM

`GET_PARAM`関数は、`DBMS_STATS`システムパッケージ内のプロシージャのパラメータのデフォルト値を取得するために使用されます。

## 構文

```sql
DBMS_STATS.GET_PARAM (
   pname     IN   VARCHAR2)
 RETURN VARCHAR2;
```

## パラメータの説明

`pname`パラメータは、デフォルト値を取得するパラメータ名を指定します。

## 例外

エラーコード`ORA-20001`は、無効な入力値を示します。

## 例

パラメータ`METHOD_OPT`のデフォルト値を取得します。

```sql
obclient> SELECT DBMS_STATS.GET_PARAM ('METHOD_OPT') FROM DUAL;
+-------------------------------------+
| DBMS_STATS.GET_PARAM ('METHOD_OPT') |
+-------------------------------------+
| FOR ALL COLUMNS SIZE AUTO           |
+-------------------------------------+
1 row in set
```
