# DBMS_STATSの概要


`DBMS_STATS`システムパッケージは、オプティマイザーがデータベースオブジェクトに対して収集した統計情報を確認および変更するために使用されます。

## DBMS_STATSの使用方法

OceanBaseデータベースの現行バージョンでサポートされている`DBMS_STATS`システムパッケージは、主に以下の一般的な操作をサポートしています：

* オプティマイザー統計情報の収集

* 列、テーブル、インデックスに関する情報の設定

* 統計情報の削除

* 統計情報のロックとアンロック
