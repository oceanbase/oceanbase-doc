# SET_TABLE_PREFS

`SET_TABLE_PREFS` プロシージャは、指定されたユーザーが所有するテーブルの統計情報の設定を変更します。

## 構文

```sql
DBMS_STATS.SET_TABLE_PREFS (
  ownname    IN  VARCHAR2,
  tabname    IN  VARCHAR2,
  pname      IN  VARCHAR2,
  pvalue     IN  VARCHAR2);
```

## パラメータ

|   パラメータ    |                説明                 |
|---------|-----------------------------------|
| ownname | ユーザー名。ユーザー名を `NULL` に設定した場合、デフォルトで現在のログインユーザー名が使用されます。 |
| tabname | テーブル名。                               |
| pname   | Prefsの名前。                        |
| pvalue  | Prefsの値。                         |

## 例外

|    エラーコード    |      説明      |
|-----------|--------------|
| ORA-20000 | 対象が存在しないか、権限が不足しています。 |
| ORA-20001 | 無効な値または不正な入力値です。  |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続しているか、`SYSDBA` 権限を持っている必要があります。

* このプロシージャのパラメータはすべて `VARCHAR2` タイプであり、その値は引用符で囲む必要があります。

## 例

ユーザー `testUser01` の `tbl1` の収集戦略の `DEGREE` デフォルト値を128に設定します。

```sql
obclient> CALL DBMS_STATS.SET_TABLE_PREFS('testUser01', 'tbl1', 'DEGREE', '128');
Query OK, 0 rows affected
```
