# SET_PARAM

`SET_PARAM` プロシージャは、`DBMS_STATS` システムパッケージ内のプロシージャのパラメータにデフォルト値を設定できます。ユーザーは `GET_PARAM` 関数を使用してパラメータのデフォルト値を取得できます。

## 構文

```sql
DBMS_STATS.SET_PARAM (
  pname      IN    VARCHAR2,
  pval       IN    VARCHAR2);
```

## パラメータの説明

|   パラメータ   |   説明   |
|--------|--------|
| pname  | パラメータの名前。 |
| pvalue | パラメータの値。  |

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| ORA-20000 | 対象が存在しないか、権限が不足しています。 |
| ORA-20001 | 無効な値または不正な入力値です。  |

## 使用方法

* このプロシージャを実行するには、`SYSDBA` 権限が必要です。

* このプロシージャの2つのパラメータはどちらも `VARCHAR2` 型であり、その値は引用符で囲む必要があります。

* `NULL` と `'NULL'` は異なります。`NULL` に引用符を付けない場合、パラメータは推奨値に設定されます。一方、`'NULL'` の場合、パラメータの値は `NULL` に設定されます。

## 例

パラメータ `DEGREE` のデフォルト値を設定します。

```sql
obclient> CALL DBMS_STATS.SET_PARAM('DEGREE','20');
Query OK, 0 rows affected
```
