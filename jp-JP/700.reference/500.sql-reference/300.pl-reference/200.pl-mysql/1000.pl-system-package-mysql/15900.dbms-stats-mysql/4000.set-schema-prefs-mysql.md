# SET_SCHEMA_PREFS

`SET_SCHEMA_PREFS` プロシージャは、指定されたスキーマの統計プリファレンスを設定します。

## 構文

```sql
DBMS_STATS.SET_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2,
  pvalue    IN   VARCHAR2);
```

## パラメータの説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | スキーマ名。 |
| pname   | Prefs名。  |
| pvalue  | Prefs値。   |

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| ORA-20000 | 対象が存在しないか、権限が不足しています。 |
| ORA-20001 | 無効な値または不正な入力値です。  |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続しているか、`SYSDBA` 権限を持っている必要があります。

* このプロシージャのパラメータはすべて `VARCHAR2` タイプであり、その値は引用符で囲む必要があります。

## 例

```sql
obclient> CALL DBMS_STATS.SET_SCHEMA_PREFS('hr', 'DEGREE','10');
Query OK, 0 rows affected
```
