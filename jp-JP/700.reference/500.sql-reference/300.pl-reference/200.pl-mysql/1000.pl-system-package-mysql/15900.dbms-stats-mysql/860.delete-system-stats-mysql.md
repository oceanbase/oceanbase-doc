# DELETE_SYSTEM_STATS

`DELETE_SYSTEM_STATS` プロシージャは、システム統計情報を削除するために使用されます。

## 構文

```sql
DBMS_STATS.DELETE_SYSTEM_STATS();
```

## 例外

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000     | 入力したシステム統計情報の名前が間違っています。 |

## 使用方法

このプロシージャを実行するには、ユーザーに `SUPER` 権限または `root` ユーザーである必要があります。

## 例

`DBMS_STATS_DELETE_SYSTEM_STATS` ストアドプロシージャを使用してすべてのシステム統計情報を削除するのは非常に簡単です。これは、パラメータを一切必要としないためです。

```sql
BEGIN
    -- すべてのシステム統計情報を削除
    DBMS_STATS_DELETE_SYSTEM_STATS();
END;
/
```
