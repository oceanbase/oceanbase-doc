# FLUSH_DATABASE_MONITORING_INFO

`FLUSH_DATABASE_MONITORING_INFO` プロシージャは、データベースの辞書に記録されているすべてのテーブルのメモリ監視情報をフラッシュします。

## 構文

```sql
DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
```

## 異常

エラーコード `ORA-20000` は権限不足を示します。

## 使用方法

`FLUSH_DATABASE_MONITORING_INFO` は、定期的なデータベースのフラッシュを待たずに、`*_TAB_STATISTICS` および `*_IND_STATISTICS` ビュー内の対応する情報を即座に更新します。`GATHER_*_STATS` プロシージャは内部で監視情報をフラッシュするため、統計情報を収集する前にこのストアドプロシージャを実行する必要はありません。

## 例

```sql
obclient> CALL DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
Query OK, 0 rows affected
```
