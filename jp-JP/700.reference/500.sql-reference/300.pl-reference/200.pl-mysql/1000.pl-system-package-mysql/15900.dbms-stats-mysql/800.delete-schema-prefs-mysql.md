# DELETE_SCHEMA_PREFS

`DELETE_SCHEMA_PREFS` プロシージャは、指定されたスキーマのすべてのテーブルに対する統計情報の優先順位を削除します。

## 構文

```sql
DBMS_STATS.DELETE_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2);
```

## パラメータの説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | スキーマ名。 |
| pname   | Prefsの名前。 |

## 例外

|    エラーコード    |        説明     |
|-----------|------------------|
| ORA-20000 | スキーマが存在しない、または権限が不足しています。 |
| ORA-20001 | 無効な値または不正な入力値です。      |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとしてデータベースに接続しているか、`SYSDBA` 権限を持っている必要があります。

* このプロシージャのパラメータはすべて `VARCHAR2` タイプであり、その値は引用符で囲む必要があります。

## 例

`hr` スキーマの優先順位 `DEGREE` を削除します。

```sql
obclient> CALL DBMS_STATS.DELETE_SCHEMA_PREFS('hr', 'DEGREE');
Query OK, 0 rows affected
```
