# GATHER_SYSTEM_STATS

`GATHER_SYSTEM_STATS` プロシージャは、システム統計情報を収集するために使用されます。

## 構文

```sql
DBMS_STATS.GATHER_SYSTEM_STATS();
```

## 異常

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000    | 入力したシステム統計情報名が誤っています。 |

## 使用方法

このプロシージャを実行するには、ユーザーに `SUPER` 権限または `root` ユーザーである必要があります。

## 例

CPU速度、ディスクI/Oパフォーマンス、ネットワークスループットなどのシステム統計情報を収集するには、`DBMS_STATS.GATHER_SYSTEM_STATS` プロシージャを実行します。

```sql
BEGIN
    -- システム統計情報を収集
    DBMS_STATS.GATHER_SYSTEM_STATS();
END;
/
```
