# システムパッケージの概要

OceanBaseデータベースは、データベース機能を拡張し、SQL機能へのPLアクセスを提供するために、PLシステムパッケージをサポートしています。

アプリケーションを作成する際、または独自のストアドプロシージャを作成する際に、提供されているシステムパッケージを使用できます。このマニュアルでは、OceanBaseデータベースサーバーの現行バージョンがサポートするシステムパッケージについて説明します。

システムパッケージとは、データベース内に格納される関連するプログラムオブジェクトのカプセル化された集合です。プログラムオブジェクトには、ストアドプロシージャ、関数、変数、定数、カーソル、例外が含まれます。

対応する権限がある場合、`oceanbase` スキーマで以下のステートメントを実行して、現在サポートされているシステムパッケージとその関連情報を照会できます。

```sql
SELECT * FROM __all_package;
```

## PLシステムパッケージの構成

PLシステムパッケージには、パッケージヘッダー（`SPECIFICATION`）とパッケージボディ（`BODY`）の2つの部分があります。パッケージヘッダーはアプリケーションのインターフェースであり、アプリケーションから可視可能な共通宣言を含み、使用可能な型、変数、定数、例外、カーソル、サブルーチンを宣言しています。パッケージボディには、実装の詳細とアプリケーションから隠されたプライベート宣言が含まれ、カーソルとサブルーチンを完全に定義し、パッケージヘッダーの実装をサポートします。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースの現行バージョンでは、ユーザーによるシステムパッケージの変更はサポートされていません。</p>
  </main>

## PLシステムパッケージの使用

データベースを作成すると、OceanBaseデータベースが提供するシステムパッケージが自動的にインストールされます。

## PLシステムパッケージの概要

次の表は、OceanBaseデータベースの現行バージョンがサポートするPLシステムパッケージとその簡潔な説明を示しています。

|                      システムパッケージ                      |            説明                    |
|-------------------------------------------------|------------------------------------|
| [DBMS_RESOURCE_MANAGER](13300.dbms-resource-manager-mysql/100.dbms-resource-manager-overview-mysql.md)| リソース使用計画、リソース使用グループ、およびリソース計画指示を維持するために使用されます。|
| [DBMS_STATS](15900.dbms-stats-mysql/100.dbms-stats-overview-mysql.md)        | オプティマイザーがデータベースオブジェクトから収集した統計情報を表示および変更します。                        |
| [DBMS_UDR](17800.dbms-udr-mysql/100.dbms-udr-overview-mysql.md)| 書き換えバインディング機能を提供し、SQLの実行開始前にマッチングルールに基づいてデータベースが受信したSQL文を書き換えることができます。|
| [DBMS_WORKLOAD_REPOSITORY](17900.dbms-workload-repository-mysql/100.dbms-workload-repository-overview-mysql.md)|  自動ワークロードリポジトリ(WR)を管理するために使用されます。 |
| [DBMS_XPLAN](20700.dbms-xplan-mysql/100.dbms-xplan-overview-mysql.md)|  ロジックプランの最適化追跡など、ロジックプラン管理関連の機能を提供します。 |
|[DBMS_OB_LIMIT_CALCULATOR](20900.dbms-limit-calculator-mysql/100.dbms-limit-calculator-overview-mysql.md)|クラスタの現在のリソース使用状況を取得し、これらの情報に基づいてスケーリング、ノード交換、スタンバイテナントの作成などの操作を計画するために使用されます。|
|[DBMS_DATA.Dict](21000.dbms-data-dict-mysql/100.dbms-data-dict-mysql.md)|データディクショナリのスケジューリングを制御するために使用されます。|
