# DISPLAY_CURSOR

`DISPLAY_CURSOR`関数は、実行済みのクエリ計画の詳細を表示するために使用されます。

  <main id="notice">
   <h4>適用対象</h4>
   <p>OceanBaseデータベースCommunity Editionは、バージョンV4.2.5以降でこの機能をサポートしています。</p>
  </main>

## 構文

```sql
DBMS_XPLAN.DISPLAY_CURSOR(plan_id      DECIMAL          DEFAULT    0,         -- default value: last plan
                          format       VARCHAR(32)      DEFAULT    'TYPICAL',
                          svr_ip       VARCHAR(64)      DEFAULT    null,   -- default value: server connected by client
                          svr_port     DECIMAL          DEFAULT    0,     -- default value: server connected by client
                          tenant_id    DECIMAL          DEFAULT    0,     -- default value: current tenant
                          sql_handle   VARCHAR(32)      DEFAULT    NULL,
                          plan_name    VARCHAR(32)      DEFAULT    NULL
                        )
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## パラメータの説明

| パラメータ | 説明 |
| ---- | ---- |
| plan_id   | 実行計画のID。指定されない場合は、前回実行された計画が使用されます。 |
| format    | 計画形式情報を指定します。オプションパラメータは以下のとおりです：<ul><li>`'BASIC'`：演算子ID、演算子名、演算子備考情報、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報など、基本情報を表示します。この計画が実行されたことがある場合、実際のフィードバック情報も表示されます。例えば、実際の行数、コストなどです。</li><li> `'ALL'`：演算子ID、演算子名、演算子備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブル最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富な計画情報を表示します。</li><li> `'ADVANCED'`：豊富な計画情報を表示します。計画情報は'ALL'パラメータと同じですが、さらに複雑な計画についてはツリー構造情報も表示されます。</li></ul> |
| svr_ip    | 計画が存在するノードのIPアドレス。デフォルトはセッション接続先のノードのIPアドレスです。|
| svr_port  | 計画が存在するノードのポート番号。デフォルトはセッション接続先のノードのポート番号です。|
| tenant_id | 計画が属するテナントID。デフォルトはセッションが現在接続しているテナントです。|
| sql_handle  | 実行計画を識別するためのSQL文のハンドル（Handle）。特定のSQL文の実行計画を照会する際、複数の類似したSQL文が存在する場合でも、sql_handleを使用してターゲット文を正確に指定できます。|
| plan_name   | 実行計画の名前。|

## 例

MySQLテナントはFunction Table機能を持たないため、`SELECT` ステートメント内で直接 `DISPLAY_CURSOR` 関数を使用して計画情報を出力できます。

1. テーブルを作成します。

    ```shell
    obclient [test]> CREATE TABLE t1(c1 INT);
    ```

2. クエリを実行します。

    ```shell
    obclient [test]> SELECT * FROM t1;
    ```

3. `DBMS_XPLAN` パッケージを使用して履歴計画を表示します。

   * パラメータなしのクエリ。

      ```shell
      obclient [test]> SELECT DBMS_XPLAN.DISPLAY_CURSOR() ;
      ```

      クエリ結果は次のとおりです：
