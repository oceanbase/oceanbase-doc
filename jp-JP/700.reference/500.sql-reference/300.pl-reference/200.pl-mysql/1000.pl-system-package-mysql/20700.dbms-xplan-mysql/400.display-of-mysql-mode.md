# DISPLAY

`DISPLAY`関数は、履歴の`EXPLAIN`計画を照会してフォーマットするために使用されます。

## 構文

```sql
TYPE DBMS_XPLAN_TYPE_TABLE IS TABLE OF VARCHAR2(4000);

DBMS_XPLAN.DISPLAY(format VARCHAR2 DEFAULT 'TYPICAL',
                  statement_id VARCHAR2 DEFAULT null,
                  table_name   VARCHAR2 DEFAULT 'PLAN_TABLE',
                  filter_preds VARCHAR2 DEFAULT null)
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## パラメータの説明

| パラメータ | 説明 |
| --- | --- |
| format | プランの形式情報を指定します。オプションパラメータは以下のとおりです：<ul><li>`'BASIC'`：演算子ID、演算子名、演算子の備考情報、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子の備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報など、基本情報を表示します。このプランが実行された場合、実際のフィードバック情報も表示されます。例えば、実際の行数やコストなどです。</li><li> `'ALL'`：演算子ID、演算子名、演算子の備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブルの最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富なプラン情報を表示します。</li><li> `'ADVANCED'`：豊富なプラン情報を表示します。プラン情報は 'ALL' パラメータと同じですが、さらに複雑なプランについてはツリー構造情報も表示されます。</li></ul>|
| statement_id | `EXPLAIN` クエリのマーカー情報であり、コマンド `EXPLAIN SET STATEMENT_ID='XXX'` を使用してクエリのマーカー情報を設定できます。 |
| table_name | `EXPLAIN` プランを保存するターゲットテーブルで、現在のデフォルト値は `PLAN_TABLE` です。 |
| filter_preds | 追加の `PLAN_TABLE` フィルター条件であり、特定の演算子またはプランをフィルタリングするために使用されます。 |
