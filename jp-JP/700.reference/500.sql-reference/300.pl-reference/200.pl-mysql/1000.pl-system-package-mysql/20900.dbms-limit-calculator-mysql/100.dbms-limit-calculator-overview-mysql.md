# DBMS_OB_LIMIT_CALCULATORの概要

`DBMS_OB_LIMIT_CALCULATOR`システムパッケージは、クラスタの現在のリソース使用状況を取得し、これらの情報に基づいてスケーリング、ノード交換、スタンバイテナントの作成などの操作を計画するために使用されます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>このシステムパッケージはSYSテナントでのみ使用できます。</p>
</main>

## DBMS_OB_LIMIT_CALCULATORサブルーチンの概要

次の表は、OceanBaseデータベースの現行バージョンでサポートされている`DBMS_OB_LIMIT_CALCULATOR`サブルーチンとその簡潔な説明を示しています。

| サブルーチン                   | 説明                  |
| ----------------------- | --------------------- |
|[CALCULATE_MIN PHY RES NEEDED BY UNIT](200.calculate-min-phy-res-needed-by-unit-mysql.md)|テナントおよびノードを指定して、特定のノードで必要な最小物理リソースを計算できます。|
|[CALCULATE_MIN PHY RES NEEDED BY LOGIC RES](300.calculate-min-phy-res-needed-by-loglc-res-mysql.md)|テナントの論理リソースタイプと必要な数を指定して、これらの論理リソースを収容するために必要な物理リソース量を計算できます。|
|[CALCULATE_MIN PHY RES NEEDED BY STANDBY TENANT](400.calculate-min-phy-res-needed-by-standby-tenant-mysql.md)|プライマリテナントを指定し、作成するスタンバイテナントのユニット数を入力することで、各ユニットに必要な物理リソース量を計算できます。|
