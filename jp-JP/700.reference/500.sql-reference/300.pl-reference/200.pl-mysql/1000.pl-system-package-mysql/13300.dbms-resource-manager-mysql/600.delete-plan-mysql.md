# DELETE_PLAN

`DELETE_PLAN`プロシージャは、指定された計画とそれが参照するすべての計画指示子を削除します。

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_PLAN (
    plan IN VARCHAR2);
```

## パラメータの説明

`plan`は、削除するリソース計画の名前を指定します。

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN('NIGHT');
Query OK, 0 rows affected
```
