# DBMS_RESOURCE_MANAGERの概要


`DBMS_RESOURCE_MANAGER`システムパッケージは、リソース使用計画、リソース使用グループ、およびリソース計画命令を維持するために使用されます。


## 権限の説明

呼び出し元は、`DBMS_RESOURCE_MANAGER`システムパッケージ内のプロシージャを実行するために`ADMINISTER_RESOURCE_MANAGER`システム権限を持っていなければなりません。

## サブルーチンの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_RESOURCE_MANAGER`サブルーチンとその簡潔な説明を示しています。

|                                   サブルーチン                                 |           説明           |
|--------------------------------------------------------------------------|------------------------|
| [CREATE_CONSUMER_GROUP](../13300.dbms-resource-manager-mysql/200.create-consumer-group-mysql.md)      | リソース使用グループを定義して作成します。             |
| [CREATE_PLAN](../13300.dbms-resource-manager-mysql/300.create-plan-mysql.md)                | リソース計画を作成します。                |
| [CREATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-mysql/400.create-plan-directive-mysql.md)      | リソース計画指示子を作成します。              |
| [DELETE_CONSUMER_GROUP](../13300.dbms-resource-manager-mysql/500.delete-consume-group-mysql.md)      | リソース使用グループを削除します。               |
| [DELETE_PLAN](../13300.dbms-resource-manager-mysql/600.delete-plan-mysql.md)                | 指定された計画およびそれが参照するすべての計画指示子を削除します。  |
| [DELETE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-mysql/700.delete-plan-directive-mysql.md)      | リソース計画指示子を削除します。              |

| [UPDATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-mysql/900.update-plan-directive-mysql.md)      | リソース計画指示子を更新します。              |
