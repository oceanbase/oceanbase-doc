# CREATE_CONSUMER_GROUP

`CREATE_CONSUMER_GROUP`プロシージャは、リソースユーザーグループを定義して作成するために使用されます。

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP (
    consumer_group  IN VARCHAR2,
    comment         IN VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

|       パラメータ      |    説明     |
|----------------|-----------|
| consumer_group | リソースユーザーグループの名前。 |
| comment        | ユーザーコメント。     |

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group1','トランザクション処理グループ');
Query OK, 0 rows affected

obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group2','日常運用グループ');
Query OK, 0 rows affected
```
