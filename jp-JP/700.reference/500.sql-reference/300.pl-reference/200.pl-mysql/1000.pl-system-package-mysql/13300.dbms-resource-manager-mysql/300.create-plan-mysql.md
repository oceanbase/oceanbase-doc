# CREATE_PLAN

`CREATE_PLAN`プロシージャは、リソース計画を作成するために使用されます。

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN (
    plan          IN   VARCHAR2,
    comment       IN   VARCHAR2 DEFAULT'');
```

## パラメータの説明

|   パラメータ    |    説明    |
|---------|----------|
| plan    | リソース計画の名前。 |
| comment | ユーザーコメント。    |

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('DAY','このリソース計画はトランザクション処理用です');
Query OK, 0 rows affected

obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('NIGHT','このリソース計画は日常的な運用保守用です');
Query OK, 0 rows affected
```
