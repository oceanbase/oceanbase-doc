# カーソルの概要

PLストアドプロシージャではカーソルがサポートされており、その構文は組み込みSQLと同じです。

カーソル宣言は、処理手続き宣言の前、変数および条件宣言の後に記述する必要があります。カーソルには以下のプロパティがあります：

* 不感応性：サーバーは結果テーブルをコピーする場合もあれば、コピーしない場合もあります。

* 読み取り専用：更新できません。

* ロールバック不可：1方向のみをイテレーションでき、ジャンプはできません。
