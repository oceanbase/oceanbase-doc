# DO

`DO` ステートメントは、SQL式を実行しますが、結果を返しません。

`DO` ステートメントの構文は次のとおりです：

```sql
DO expr [, expr ...]
```

一部のシナリオでは、`DO` ステートメントは結果を返さずに迅速な応答を実現するために `SELECT expr` と同等です。例：

```sql
obclient> SELECT SLEEP(5);
+----------+
| SLEEP(5) |
+----------+
|        0 |
+----------+
1 row in set (5.001 sec)

obclient> DO SLEEP(5);
Query OK, 0 rows affected (5.011 sec)
```
