# ITERATE

`ITERATE` ステートメントは、ループステートメントを再度開始するために使用されます。

`ITERATE` ステートメントの構文は次のとおりです：

```sql
ITERATE label
```

`ITERATE` は `LOOP`、`REPEAT`、および `WHILE` ステートメントにのみ記述できます。
