# LEAVE

`LEAVE` ステートメントは、指定されたラベルを持つプロセス制御文から抜け出すために使用されます。ラベルが最も外側のストアドプログラムブロックに使用されている場合、LEAVEを使用してそのプログラムから抜け出します。

`LEAVE` ステートメントの構文は次のとおりです：

```sql
LEAVE label
```

`LEAVE` ステートメントは、`BEGIN ... END` ブロック、および `LOOP`、`REPEAT`、`WHILE` ループステートメントで使用できます。
