# エラー報告関数

PLは、PLの例外処理コードで使用できる2つのエラー報告関数`SQLCODE`と`SQLERRM`をサポートしています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。
  </main>

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>SQLCODE</code>および<code>SQLERRM</code>関数は、SQLステートメント内で使用することはできません。</p>
  </main>

## SQLCODE関数

例外ハンドラー内で、`SQLCODE`関数は現在処理中の例外に対応するエラーコードを返します。(例外ハンドラー外では、`SQLCODE`は常に0を返します)。

内部で定義された例外については、数値コードはデータベースエラーの番号に関連付けられます。

ユーザー定義の例外については、数値コードは`+1`(デフォルト値)または`EXCEPTION_INIT`コンパイル指示に関連付けられた例外のエラーコードです。

構文は以下のとおりです：

```sql
SQLCODE
```

## SQLERRM関数

`SQLERRM`関数は、エラーコードに関連付けられたエラーメッセージを返します。

構文は以下のとおりです：

```sql
SQLERRM [ ( error_code ) ]
```

ここで、パラメータ`error_code`はオプションであり、パラメータがない場合、この関数は現在の`SQLCODE`のエラー情報を返します。
