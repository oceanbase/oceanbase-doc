# インポート識別子

インポート識別子を使用する場合は、シンプル名、限定名、リモート名、または限定名とリモート名を使用できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

命名されたPLユニット内で宣言された識別子については、その限定名を使用して参照することができます（場合によっては必須です）。構文は以下のとおりです：

```sql
unit_name.simple_identifier_name
```

たとえば、プログラムパッケージ`ob`が識別子`c`を宣言した場合、限定名`ob.c`を使用してその識別子を参照できます。ユニット名も（場合によっては必須です）限定されている必要があります。識別子が非表示の場合は、限定する必要があります([識別子のスコープと可視性](../100.pl-language-basics-oracle/500.range-and-visibility-of-identifiers-oracle.md)参照)。

識別子がリモートデータベース上のオブジェクトに名前を付ける場合は、そのリモート名を使用してそのオブジェクトを参照する必要があります。構文は以下のとおりです：

```sql
simple_identifier_name@link_to_remote_database
```

リモートデータベースのPLユニット内で宣言された識別子については、その限定されたリモート名を使用して参照する必要があります。構文は以下のとおりです。

```sql
unit_name.simple_identifier_name@link_to_remote_database
```
