# SA_SESSIONの概要

`SA_SESSION`パッケージは、ユーザー権限によるセッション動作を管理するために使用されます。セッション中、ユーザーは管理者が設定した権限範囲内でラベルを変更できます。

このPLパッケージを使用するには特別な権限は不要です。

次の表は、OceanBaseデータベースの現行バージョンでサポートされている`SA_SESSION`パッケージの内容を示しています。

|                                       ステートメント                                       |           説明           |
|----------------------------------------------------------------------------------|------------------------|
| [SA_SESSION.LABEL](../700.sa-session-session-management-pack-oracle/200.sa-session-label-oracle.md)                  | 指定されたラベルセキュリティポリシーに関連付けられたラベルを返します。    |
| [SA_SESSION.RESTORE_DEFAULT_LABELS](../700.sa-session-session-management-pack-oracle/300.sa-session-restore-default-labels-oracle.md) | 現在のセッションのラベルと行ラベルを保存されているデフォルト設定にリセットします。 |
| [SA_SESSION.ROW_LABEL](../700.sa-session-session-management-pack-oracle/400.sa-session-row-label-oracle.md)              | 現在のセッションのポリシーに関連付けられた行ラベルの名前を返します。   |
| [SA_SESSION.SET_LABEL](../700.sa-session-session-management-pack-oracle/500.sa-session-set-label-oracle.md)              | 他者が読み取り権限を持つ新しいレベルを設定します。        |
| [SA_SESSION.SET_ROW_LABEL](../700.sa-session-session-management-pack-oracle/600.sa-session-set-row-label-oracle.md)          | 新しい行に適用されるデフォルトの行ラベルを設定します。        |
