# SA_SESSION.RESTORE_DEFAULT_LABELS

`SA_SESSION.RESTORE_DEFAULT_LABELS`は、セッションラベルと行ラベルをデータディクショナリに格納されているラベルに復元するために使用されます。

`SA_SESSION.SET_LABEL`コマンドを実行した後、このコマンドは値をリセットします。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_SESSION.RESTORE_DEFAULT_LABELS (
policy_name in VARCHAR);
```

## パラメータの説明

|   **パラメータ**    |                          **説明**                           |
|-------------|-----------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを照会するには、`ALL_SA_POLICIES`データディクショナリビューの`POLICY_NAME`列を照会してください。 |

## 例

次の例は、`shield_agent_policy`ポリシーのデフォルトラベルを復元する方法です。

```sql
BEGIN
    SA_SESSION.RESTORE_DEFAULT_LABELS (
          policy_name         => 'shield_agent_policy');
END;
/
```
