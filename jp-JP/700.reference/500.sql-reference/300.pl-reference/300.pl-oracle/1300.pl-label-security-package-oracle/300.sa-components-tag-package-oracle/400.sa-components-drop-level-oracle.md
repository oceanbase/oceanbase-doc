# SA_COMPONENTS.DROP_LEVEL

`SA_COMPONENTS.DROP_LEVEL`は、レベルを削除するために使用されます。

既存のタグでこのレベルが使用されている場合、そのレベルを削除することはできません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_COMPONENTS.DROP_LEVEL (
      policy_name IN VARCHAR,
      level_num   IN NUMBER
 );
```

## パラメータの説明

|   **パラメータ**    |                           **説明**                           |
|-------------|------------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを検索するには、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列を照会してください。     |
| level_num   | ポリシーの既存レベル番号を指定します。既存のレベル番号を検索するには、`ALL_SA_LEVEL`ビューの`LEVEL_NUM`列を照会してください。 |

## 例

次の例は、`shield_agent_policy`ポリシーのレベル番号500を削除する方法です。

```sql
BEGIN
   SA_COMPONENTS.DROP_LEVEL (
     policy_name     => 'shield_agent_policy',
     level_num       => 500);
END;
/
```
