# SA_COMPONENTS.CREATE_LEVEL

`SA_COMPONENTS.CREATE_LEVEL`は、レベルを作成し、そのショートネームとロングネームを指定するために使用されます。

`level_num`パラメータに割り当てられる値は、感度レベルを決定するために使用されます（つまり、数値が小さいほど感度が低いことを示します）。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
SA_COMPONENTS.CREATE_LEVEL (
policy_name       IN VARCHAR,
level_num         IN NUMBER,
short_name        IN VARCHAR,
long_name         IN VARCHAR );
```

## パラメータの説明

|   **パラメータ**    |                         **説明**                         |
|-------------|--------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを検索するには、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列を照会してください。 |
| level_num   | レベル番号(0～9999)を指定します。                                       |
| short_name  | レベルの短い名前(最大30文字)を指定します。                                   |
| long_name   | レベルの長い名前(最大80文字)を指定します。                                   |

## 例

次の例は、`shield_agent_policy`ポリシーにレベルを作成するためのものです。

```sql
BEGIN
   SA_COMPONENTS.CREATE_LEVEL (
    policy_name     => 'shield_agent_policy',
    level_num       => 500,
    short_name      => 'L5',
    long_name       => 'Level 5');
END;
/
```
