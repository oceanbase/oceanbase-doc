# PLラベルセキュリティパッケージの概要

ラベルセキュリティ（Label Security）は、単一のテーブル行に対する細かい粒度でのアクセスを提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

ラベルセキュリティポリシーには、標準的なコンポーネントが含まれています。これらの構成要素は以下のとおりです：

* ラベル

  データとユーザーのラベル、およびユーザーとプログラムユニットの権限制御により、指定された保護対象オブジェクトへのアクセスを管理します。現在のバージョンでは、ラベルにはレベルのみが含まれます。レベルとは、行に割り当てる機密性タイプを示し、例えば`SENSITIVE`または`HIGHLY SENSITIVE`などがあります。

* ポリシー

  ポリシーとは、これらのラベル、ルール、権限、および保護されたテーブルに関連付けられる名前です。

次の表は、OceanBaseデータベースの現在のバージョンで利用可能なラベルセキュリティ管理パッケージとその説明です。

|                             パッケージ名                              |              説明              |
|----------------------------------------------------------------|------------------------------|
| [SA_SYSDBA](200.sa-sysdba-policy-management-package-oracle/100.sa-sysdba-overview-oracle.md)       | タグセキュリティポリシーの作成、変更、および削除を行います。              |
| [SA_COMPONENTS](300.sa-components-tag-package-oracle/100.sa-components-overview-oracle.md)   | ポリシーのレベルを定義します。                     |
| [SA_LABEL_ADMIN](400.sa-label-admin-tag-management-pack-oracle/100.sa-label-admin-overview-oracle.md)  | タグの作成など、標準的なタグポリシー管理機能を実行します。         |
| [SA_POLICY_ADMIN](500.sa-policy-admin-policy-management-packs-oracle/100.sa-policy-admin-overview-oracle.md) | アーキテクチャとテーブルにポリシーを適用します。                  |
| [SA_USER_ADMIN](600.sa-user-admin-user-tag-management-pack-oracle/100.sa-user-admin-overview-oracle.md)   | レベルのユーザー権限とプログラムユニット権限を管理し、ユーザー権限も管理できます。 |
| [SA_SESSION](700.sa-session-session-management-pack-oracle/100.sa-session-overview-oracle.md)      | 管理者が設定した権限範囲内でセッション中にタグを変更します。       |
