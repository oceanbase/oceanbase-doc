# SA_SYSDBAの概要

`SA_SYSDBA`パッケージは、ラベルセキュリティポリシーの作成、変更、削除などを管理するために使用されます。

このPLパッケージを使用するには、`EXECUTE`権限が付与されている必要があります。`SA_SYSDBA`パッケージはコールプログラマー権限パッケージであり、このパッケージを使用する前に、`SYS`ユーザーに対して以下の`INHERIT PRIVILEGES`を付与する必要があります：



```sql
GRANT INHERIT PRIVILEGES ON USER SYS TO LBACSYS;
```



この権限はSYSユーザーにのみ付与し、他のユーザーに付与する必要はありません。

|------------------------------------------------------------------------|-----------|
