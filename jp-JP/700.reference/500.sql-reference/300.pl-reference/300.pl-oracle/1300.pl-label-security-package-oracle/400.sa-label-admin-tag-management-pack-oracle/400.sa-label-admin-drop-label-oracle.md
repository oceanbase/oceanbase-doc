# SA_LABEL_ADMIN.DROP_LABEL

`SA_LABEL_ADMIN.DROP_LABEL`は、指定されたポリシーラベルを削除するために使用されます。

ラベルへの以降の参照（データ行内、またはユーザーまたはプログラムユニットのラベル内）はすべて、無効なラベルのエラーを引き起こします。

このストアドプロシージャは、ラベルを設定する場合にのみ使用します。使用中のラベルが誤って削除された場合は、ポリシーを無効にしてから再有効化することで、そのラベルを復元できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_LABEL_ADMIN.DROP_LABEL (
policy_name       IN VARCHAR,
label_tag         IN BINARY_INTEGER);
```

## パラメータの説明

|   **パラメータ**    |                            **説明**                             |
|-------------|---------------------------------------------------------------|
| policy_name | 既存のポリシーの名前を指定します。既存のポリシーを検索するには、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列を照会してください。    |
| label_tag   | 削除するタグに割り当てる整数識別子を指定します。既存のタグを検索するには、`ALL_SA_LABELS`ビューの`LABEL_TAG`列を照会してください。 |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>データベース内で使用中のラベルを削除しないでください。</p>
  </main>

## 例

次の例は、`label_tag`に基づいて`shield_agent_policy`ポリシーラベルを削除する方法です。

```sql
BEGIN
   SA_LABEL_ADMIN.DROP_LABEL (
     policy_name     => 'shield_agent_policy',
     label_tag       => 50000);
END;
/
```
