# SA_LABEL_ADMINの概要

`SA_LABEL_ADMIN`パッケージは、ポリシーで使用されるラベルを管理するための管理インターフェースを提供します。

このPLパッケージを使用するには、`SA_LABEL_ADMIN`パッケージに対する`EXECUTE`権限が付与されていなければなりません。

次の表は、OceanBaseデータベースの現行バージョンでサポートされている`SA_LABEL_ADMIN`パッケージの内容を示しています。

|                                  **ストアドプロシージャ**                                  | **説明**  |
|----------------------------------------------------------------------------|---------|
| [SA_LABEL_ADMIN.ALTER_LABEL](../400.sa-label-admin-tag-management-pack-oracle/200.sa-label-admin-alter-label-oracle.md)  | 既存のラベルを変更します。 |
| [SA_LABEL_ADMIN.CREATE_LABEL](../400.sa-label-admin-tag-management-pack-oracle/300.sa-label-admin-create-label-oracle.md) | データラベルを作成します。 |
| [SA_LABEL_ADMIN.DROP_LABEL](../400.sa-label-admin-tag-management-pack-oracle/400.sa-label-admin-drop-label-oracle.md)   | ラベルを削除します。   |
