# 権限管理

デフォルトでは、関数とストアドプロシージャは作成者本人のみが実行できます。しかし、`GRANT` を使用して他のユーザーに実行権限を付与することができます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

`GRANT` 権限付与構文は以下のとおりです：

```javascript
GRANT system_privilege | role
TO user | role | PUBLIC [WITH ADMIN OPTION]

GRANT object_privilege | ALL ON schema.object
TO user | role | PUBLIC [WITH GRANT OPTION]
```

例：`hr.log_message` ストアドプロシージャの実行権限をすべての人に付与します。

```javascript
obclient> GRANT EXECUTE ON log_message TO PUBLIC;
Query OK, 0 rows affected
```

よく使われるシステム権限コマンドは以下のとおりです：

* `CREATE ANY PROCEDURE`：すべてのストアドプロシージャを作成する権限。

* `DROP ANY PROCEDURE`：すべてのストアドプロシージャを削除する権限。

* `EXECUTE ANY PROCEDURE`：すべてのストアドプロシージャを実行する権限。
