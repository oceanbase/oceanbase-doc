# パイプライン関数の概要

パイプライン関数（Pipelined Table Function）とは、行セット（ネストされたテーブルまたは配列を含む可能性があります）を返すことができる関数です。この関数は、物理テーブルをクエリするのと同じようにクエリしたり、集合変数に代入したりできます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionでは、MySQLモードのみが提供されています。</p>
  </main>

パイプライン関数は、`SELECT` ステートメントの `TABLE` 句で呼び出します。例：

```sql
SELECT * FROM TABLE(table_function_name(parameter_list))
```

キーワード `PIPELINED` はパイプライン関数を識別するために使用されます。パイプライン関数の戻り値型は集合でなければならず、`PIPE ROW` ステートメントはその集合の個々の要素を返すために使用され、実行完了を示す空の `RETURN` ステートメントで終了します。
