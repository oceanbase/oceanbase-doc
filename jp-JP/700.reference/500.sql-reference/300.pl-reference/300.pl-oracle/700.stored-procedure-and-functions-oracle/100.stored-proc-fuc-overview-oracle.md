# 概要

ストアドプロシージャと関数は、PLプログラムと総称され、PLブロックと命名され、入出力パラメータを通じて呼び出し元と情報を交換します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

ストアドプロシージャと関数の唯一の違いは、関数が常に呼び出し元にデータを返すのに対し、ストアドプロシージャは自動的にデータを返さない点ですが、`OUT`パラメータを使用して出力を実現できます。

OceanBaseデータベースでは、PLプログラムをデータベース内に保存でき、権限を付与することで、OceanBaseデータベースに接続されている任意のセッションが実行できます。
