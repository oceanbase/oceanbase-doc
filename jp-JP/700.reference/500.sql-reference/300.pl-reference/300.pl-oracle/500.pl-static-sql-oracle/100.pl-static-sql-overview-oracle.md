# 概要

PL静的SQLは、PLステートメント内で直接SQL構文を使用することをサポートしています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

一般的に、PL静的SQLステートメントは、以下の対応するSQLステートメントと同じ構文を持っています：

* `SELECT`（このステートメントはクエリとも呼ばれます）

* データ操作言語（DML）ステートメント：`INSERT`、`UPDATE`、`DELETE`、および`MERGE`。

* トランザクション制御言語（TCL）ステートメント：`COMMIT`、`ROLLBACK`、`SAVEPOINT`、`SET TRANSACTION`、および`LOCK TABLE`。

擬似列はテーブル列と同様に動作しますが、テーブルには格納されません。静的SQLには、以下のSQL擬似列が含まれます：

* `CURRVAL` と `NEXTVAL`

* `LEVEL`

* `OBJECT_VALUE`

* `ROWID`

* `ROWNUM`

OceanBaseデータベースのPL静的SQLは、次のシナリオでSQLによる複雑なデータ型の返却をサポートしています：

* `​SELECT INTO`/`BULK INTO​`
* DMLステートメント内の `RETURING INTO`/`BULK INTO`
* `​FETCH INTO`/`BULK INTO`

<main id="notice" type='notice'>
  <h4>説明</h4>
  <p>V4.2.0以降、OceanBaseデータベースでは、複数の列データをRECORD型変数にインポート（`INTO`）したり、複数の列データを一括してOBJECT型変数にインポート（`BULK INTO`）したりできるようになりました。</p>
</main>

OceanBaseデータベースは、Oracleテキストプロトコルの複雑な型のシリアライゼーション機能と互換性があります。SQLクエリ結果に複雑なデータ型が存在する場合、その複雑なデータ型をOracle互換のテキスト出力にシリアライズできます。

たとえば、データベースでクエリを実行し、そのクエリが複雑なデータ型を返す場合、複数のフィールドを含む複雑な型などです：

```sql
{
  "id": 1001,
  "name": "Alice",
  "phoneNumbers": ["123-456-7890", "098-765-4321"]
}
```

現在、複雑なデータ型をOracle互換のテキスト出力にシリアライズすることがサポートされており、それは次のように変換されます：

```
ID: 1001, Name: Alice, PhoneNumbers: (123-456-7890, 098-765-4321)
```
