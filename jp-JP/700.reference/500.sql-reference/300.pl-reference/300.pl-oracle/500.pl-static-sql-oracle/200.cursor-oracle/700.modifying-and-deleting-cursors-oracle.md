# カーソルの変更と削除

カーソルの変更および削除とは、カーソルが指している位置に基づいて、テーブル内の特定のデータ行を変更または削除することを指します。

カーソルクエリ文では、カーソルを開く際にカーソル結果セットに対応するテーブル内のすべての列または一部の列をロックするために、`FOR UPDATE`オプションを使用する必要があります。

`FOR UPDATE`句は、カーソル結果セットで選択された行をロックし、他のセッションによるデータの変更を防ぎます。これらの行データに対する他のセッションからのロックは、トランザクション処理がコミットまたはロールバックされるまで実行できません。

構文は次のとおりです：

```javascript
SELECT . . . FROM ... FOR UPDATE [OF column[, column]...] [NOWAIT]
```

別のセッションがアクティブセット内の行にロックをかけている場合、`SELECT FOR UPDATE`操作はその他のセッションがこれらのロックを解除するまで待機し続けます。このような状況において、`NOWAIT`句を追加した場合、これらの行が別のセッションによってロックされている場合は、`OPEN`操作は直ちに終了し、エラー`ORA-30006: resource busy; acquire with WAIT timeout expired`が報告されます。

`FOR UPDATE`を使用してカーソルを宣言した場合、`DELETE`および`UPDATE`ステートメントで`WHERE CURRENT OF cursor_name`句を使用して、カーソル結果セットの現在行に対応するデータベーステーブル内のデータ行を変更または削除できます。

例：

```javascript
obclient> SELECT empname, salary FROM emp WHERE deptno=4;
+---------+--------+
| EMPNAME | SALARY |
+---------+--------+
| Karen   |  10000 |
| Guy     |  10000 |
+---------+--------+
2 rows in set

obclient>DECLARE
         V_deptno emp.deptno%TYPE :=4;
     CURSOR c_emp IS SELECT empname, salary
             FROM emp WHERE deptno=V_deptno FOR UPDATE NOWAIT;
     BEGIN
     FOR emp_record IN c_emp LOOP
             IF emp_record.salary < 12000 THEN
                 UPDATE emp SET salary=12000 WHERE CURRENT OF c_emp;
             END IF;
     END LOOP;
     END;
     /
Query OK, 0 rows affected

obclient> SELECT empname, salary FROM emp WHERE deptno=4;
+---------+--------+
| EMPNAME | SALARY |
+---------+--------+
| Karen   |  12000 |
| Guy     |  12000 |
+---------+--------+
2 rows in set
```
