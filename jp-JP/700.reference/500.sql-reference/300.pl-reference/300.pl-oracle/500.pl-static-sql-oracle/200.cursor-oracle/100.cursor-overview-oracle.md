# カーソルの概要

OceanBaseデータベースがSQL文を実行すると、結果セットと処理情報を名前のないプライベートメモリ領域に保存し、そのメモリ領域の開始位置を示すポインタを設定します。このポインタこそがカーソルです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

カーソルを使用すると、一度に1行のレコードを取得できます。カーソルのプロパティはカーソルの状態情報を返します。カーソルには明示的カーソルと暗黙的カーソルがあります。
