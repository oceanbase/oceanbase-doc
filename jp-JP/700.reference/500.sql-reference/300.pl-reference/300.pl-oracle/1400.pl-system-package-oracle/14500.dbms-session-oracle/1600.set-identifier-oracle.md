# SET_IDENTIFIER

`SET_IDENTIFIER`プロシージャは、セッション内でクライアントIDを設定するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SESSION.SET_IDENTIFIER (
client_id VARCHAR2);
```

## パラメータの説明

`client_id`は、現在のデータベースセッションのアプリケーション識別子(大文字と小文字が区別されます)を指定します。このパラメータの最大バイト数は64バイトです。入力値が64バイトを超える場合、超過分のバイトは切り捨てられます。

## 使用方法

`SET_IDENTIFIER`プロシージャは、セッションのクライアントIDを指定された値に設定します。また、関数`SYS_CONTEXT('USERENV','CLIENT_IDENTIFIER')`を使用してセッションを識別するためにも使用できます。

`SET_IDENTIFIER`プロシージャは`PUBLIC`で実行できます。

## 例

```sql
BEGIN
  DBMS_SESSION.SET_IDENTIFIER('1234');
END;
```
