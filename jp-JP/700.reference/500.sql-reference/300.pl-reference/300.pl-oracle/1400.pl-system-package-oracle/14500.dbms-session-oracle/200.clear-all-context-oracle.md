# CLEAR_ALL_CONTEXT

`CLEAR_ALL_CONTEXT` プロシージャは、指定されたネームスペース内のアプリケーションコンテキスト情報をクリアするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SESSION.CLEAR_ALL_CONTEXT
    (namespace         VARCHAR2);
```

## パラメータの説明

`namespace` クリアするアプリケーションコンテキスト情報のネームスペースを指定します。

## 使用方法

`CLEAR_ALL_CONTEXT` プロシージャは、信頼できるパッケージによって直接または間接的に呼び出されなければなりません。

`CLEAR_ALL_CONTEXT` プロシージャによるコンテキスト値の変更は即時に反映され、その後 `SYS_CONTEXT` を使用して同じ値を呼び出すと最新の値が返されます。

## 例

```sql
BEGIN
  DBMS_SESSION.CLEAR_ALL_CONTEXT('emp_context');
END;
```
