# DBMS_SESSIONの概要

`DBMS_SESSION`システムパッケージは、PLから`ALTER SESSION`SQL文およびその他のセッション情報にアクセスするための機能を提供します。`DBMS_SESSION`を使用して、設定やセキュリティレベルを設定できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_SESSION権限の説明

`DBMS_SESSION`システムパッケージはユーザーの権限を呼び出すため、`SYS`権限は不要です。

## DBMS_SESSIONサブルーチンの概要

次の表は、OceanBaseデータベースの現行バージョンでサポートされているDBMS_SESSIONサブルーチンとその簡潔な説明を示しています。


|        サブルーチン            |      説明       |
|--------------------------|---------------|
| [CLEAR_ALL_CONTEXT](../14500.dbms-session-oracle/200.clear-all-context-oracle.md) | すべてのコンテキスト情報をクリアします。    |
| [CLEAR_CONTEXT](../14500.dbms-session-oracle/300.clear-context-oracle.md)     | 指定されたコンテキスト情報をクリアします。   |
| [CLEAR_IDENTIFIER](../14500.dbms-session-oracle/400.clear-identifier-oracle.md)  | 指定子をクリアします。        |
| [RESET_PACKAGE](../14500.dbms-session-oracle/1300.reset-package-of-oracle-mode.md) | Session上のすべてのPackage変数をクリアします。 |
| [SET_CONTEXT](../14500.dbms-session-oracle/1400.set-context-oracle.md)       | コンテキストプロパティの値を設定またはリセットします。 |
| [SET_IDENTIFIER](../14500.dbms-session-oracle/1600.set-identifier-oracle.md)    | 指定子を設定します。        |
