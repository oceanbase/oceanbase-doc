# DECRYPT

DECRYPT関数は、ストリーム暗号またはブロック暗号を使用してRAWデータを復号化します。この暗号は、ユーザーが提供する鍵とオプションのIV（初期化ベクトル）を使用します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_CRYPTO.DECRYPT(
   src IN RAW,
   typ IN PLS_INTEGER,
   key IN RAW,
   iv  IN RAW DEFAULT NULL)
 RETURN RAW;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
| src    | 解読するRAWデータ。           |
| typ    | 使用するパスワードストリームとパスワードブロック連結アルゴリズム。       |
| key    | 解読に使用する鍵。               |
| iv     | パスワードブロックのオプションの初期化ベクトル。デフォルト値はNULLです。 |

## 使用方法

* 生の平文データを照会するには、`DECRYPT` を呼び出す際に、データを暗号化するために最初に使用したものと同じパスワード、アルゴリズム、鍵、およびIVを使用する必要があります。

* `VARCHAR2` データが暗号化される前に生データに変換された場合、UTL_I18Nパッケージを使用して適切なデータベース文字セットに変換する必要があります。
