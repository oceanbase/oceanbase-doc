# DROP_PROGRAM

`DROP_PROGRAM`プロシージャは、プログラムを削除するために使用されます。プログラムが削除されると、プログラムに関連付けられたパラメータも削除されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SCHEDULER.DROP_PROGRAM (
program_name            IN VARCHAR2,
force                   IN BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

|      パラメータ     |         説明         |
|--------------|----------------------|
| program_name | 削除するプログラムの名前。名前はカンマで区切られたリストにすることができます。     |
| force        | `force` が `FALSE` に設定されている場合、どのジョブもそのプログラムを参照してはなりません。そうしないとエラーが発生します。 `force` が `TRUE` に設定されている場合、プログラムを削除する前に、そのプログラムを参照しているすべてのジョブが無効になります。 そのプログラムを参照して実行中のジョブは、`DROP_PROGRAM` コールの影響を受けずに実行を続けることができます。 |

## 例

```sql
BEGIN
  DBMS_SCHEDULER.DROP_PROGRAM(program_name => 'program_test');
END;
```
