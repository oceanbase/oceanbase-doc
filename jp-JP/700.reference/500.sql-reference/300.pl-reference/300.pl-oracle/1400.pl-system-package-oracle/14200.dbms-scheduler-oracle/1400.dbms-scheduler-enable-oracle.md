# ENABLE

`ENABLE`は、スケジュールされたパーティションのバランシング機能を有効にするために使用されます。

## 構文

```sql
DBMS_SCHEDULER.ENABLE('SCHEDULED_TRIGGER_PARTITION_BALANCE');
```

## 注意事項

スケジュールされたパーティションのバランシングタスク`SCHEDULED_TRIGGER_PARTITION_BALANCE`を有効にする場合、テナントレベルの構成パラメータ`partition_balance_schedule_interval = 0`が必要です。そうでない場合、`OB_OP_NOT_ALLOW`エラーが報告されます。構成パラメータトリガーとスケジュールタスクトリガーは同時に有効にすることはできません。

## 例

```shell
obclient> CALL DBMS_SCHEDULER.ENABLE('SCHEDULED_TRIGGER_PARTITION_BALANCE');
Query OK, 0 rows affected (0.010 sec)
```
