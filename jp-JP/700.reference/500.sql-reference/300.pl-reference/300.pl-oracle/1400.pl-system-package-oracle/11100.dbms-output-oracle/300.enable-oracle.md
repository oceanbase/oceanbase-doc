# ENABLE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/ENABLE
ENABLEストアドプロシージャは、PUT、PUT_LINE、NEW_LINE、およびGET_LINEの呼び出しを許可するために使用されます。

DBMS_OUTPUTパッケージが有効になっていない場合、これらのプログラムへの呼び出しは無視されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.ENABLE (
buffer_size IN INTEGER DEFAULT 20000);
```

## パラメータの説明

|     パラメータ      |                        説明                         |
|-------------|---------------------------------------------------|
| buffer_size | バッファ情報量の上限（バイト単位）。`buffer_size` をNULLに設定すると、制限がないことを意味します。 |

## 使用方法

* OBClientの`SET SERVEROUTPUT`オプションを使用する場合、このプログラムを呼び出す必要はありません。

* 複数のENABLEが同時に呼び出される場合、`buffer_size`は最後に指定された値を使用します。ユーザーが`buffer_size`(NOT NULL)を指定した場合、最大値は1,000,000、最小値は2,000です。

* 通常はNULLに設定します。デフォルト値は20,000であり、無限バッファをサポートしていない早期のデータベースバージョンとの互換性を保つためです。
