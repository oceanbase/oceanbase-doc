# GET_LINE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/GET_LINE
GET_LINEストアドプロシージャは、単一行のバッファ情報を検索するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.GET_LINE (
line    OUT VARCHAR2,
status  OUT INTEGER);
```

## パラメータの説明

| **パラメータ** |                                  **説明**                                   |
|--------|---------------------------------------------------------------------------|
| line   | 最後の改行文字を除いた1行分のバッファ情報を返します。このパラメータはVARCHAR2型であり、エラーを回避するためにVARCHAR2のサイズは32767以上である必要があります。 |
| status | 呼び出しが正常に完了した場合、ステータスの戻り値は0です。バッファ内に他の行がない場合、ステータスは1となります。                                    |

## 使用方法

* バッファから単一行または行配列を検索することができます。 単一行のバッファ情報を検索するには、GET_LINEプログラムを呼び出します。 サーバーへの呼び出し回数を減らすために、バッファから行配列を取得するには、GET_LINESプログラムを呼び出してください。

* OBClientを使用している場合は、特別な`SET SERVEROUTPUT ON`コマンドを使用してこの情報を自動表示することができます。

* GET_LINEを呼び出した後、検索されなかった行データは、次回のPUT、PUT_LINE、またはNEW_LINEの呼び出しの前に破棄されます。

  これは、後続の情報と混同されるのを防ぐためです。
