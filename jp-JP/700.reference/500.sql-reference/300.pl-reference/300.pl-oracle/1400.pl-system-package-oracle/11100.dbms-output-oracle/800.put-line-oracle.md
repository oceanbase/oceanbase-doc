# PUT_LINE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/PUT_LINE
`PUT_LINE`ストアドプロシージャは、単一行データをバッファに格納するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.PUT_LINE (
item IN VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|--------|--------|
| item   | バッファに格納する行。 |

## 使用方法

* `PUT`を複数回呼び出すことで、情報行を段階的に構築することができます。また、`PUT_LINE`を呼び出して、1行分の情報をバッファに一度に格納することもできます。

* `PUT_LINE`を呼び出すと、自動的に行末マークが付加されます。`PUT`を呼び出して行を作成した場合は、`NEW_LINE`を呼び出して行末マークを追加する必要があります。`GET_LINE`および`GET_LINES`は、改行文字で終了しない行を返しません。

* 行数が制限を超えると、エラーメッセージが表示されます。

* `PUT`または`PUT_LINE`を使用して作成された出力はバッファリングされます。PLユニットが出力をバッファリングした状態で、呼び出し元に返されるまで、その出力を取得することはできません。

  例えば、PLユニットが完了するまで、OBClientは`DBMS_OUTPUT`メッセージを表示しません。PLユニット内で`DBMS_OUTPUT`バッファをリフレッシュする仕組みはありません。

  ```sql
  obclient> SET SERVEROUTPUT ON；
  obclient> BEGIN
      DBMS_OUTPUT.PUT_LINE ('hello');
      DBMS_LOCK.SLEEP (10);
      END;
  ```
