# BASE64_DECODE

`BASE64_DECODE`関数は、Base64エンコードされた`RAW`入力文字列を読み取り、元の`RAW`値にデコードするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_ENCODE.BASE64_DECODE (
   r  IN RAW)
RETURN RAW;
```

## パラメータの説明

| パラメータ |                  説明                   |
|----|---------------------------------------|
| r  | Base64エンコードされたデータを含む`RAW`文字列です。デフォルト値やオプションパラメータはありません。 |

## 戻り値

| 戻り値 |    説明     |
|-----|-----------|
| RAW | デコード後の文字列を含みます |
