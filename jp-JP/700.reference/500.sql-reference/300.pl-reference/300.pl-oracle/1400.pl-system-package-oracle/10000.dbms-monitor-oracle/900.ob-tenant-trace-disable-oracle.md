# OB_TENANT_TRACE_DISABLE

`OB_TENANT_TRACE_DISABLE`は、現在のテナントのフルトレース機能を無効にするために使用されます。

<main id="notice" >
  <h4>注意</h4>
  <p>他のテナントのフルトレースを無効にすることは許可されていません。</p>
</main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_TENANT_TRACE_DISABLE(tenant_name  IN VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ**        | **説明**                                      |
|------------------|----------------------------------------------|
| tenant_name      | フルトレースを無効にする`tenant_name`。デフォルトは`null`で、現在のテナントを表します。 |
