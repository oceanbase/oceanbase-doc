# OB_MOD_ACT_TRACE_ENABLE

`OB_MOD_ACT_TRACE_ENABLE`は、module/actionレベルのフルリンクトレースを有効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_MOD_ACT_TRACE_ENABLE(
  module_name     IN VARCHAR2,
  action_name     IN VARCHAR2,
  level        IN  INT,
  sample_pct   IN  NUMBER,
  record_policy IN VARCHAR2);
```

## パラメータの説明

| **パラメータ**        | **説明**                                     |
|------------------|----------------------------------------------|
| module_name      | フルトレースを有効にする `module_name`。             |
| action_name      | フルトレースを有効にする `action_name`。             |
| level            | Span内部データの収集粒度を制御します。Level 1、Level 2、Level 3の3つのレベルがあります。   |
| sample_pct       | サンプリング率。値の範囲は[0, 1]です。                 |
| record_policy    | 出力ポリシー：<ul><li>`ALL`（サンプリングされたすべてのクエリのトレースを出力）。</li></ul>  <ul><li>`ONLY_SLOW_QUERY`（スロークエリのみを出力）。</li></ul> <ul><li> `SAMPLE_AND_SLOW_QUERY`（スロークエリを出力し、他のリクエストは `_print_sample_percentage` の確率に基づいて出力）。</li></ul> |
