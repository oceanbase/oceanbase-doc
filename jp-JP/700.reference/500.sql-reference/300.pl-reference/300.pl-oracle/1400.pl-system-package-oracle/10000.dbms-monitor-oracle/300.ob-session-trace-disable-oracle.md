# OB_SESSION_TRACE_DISABLE

`OB_SESSION_TRACE_DISABLE`は、セッションレベルのフルトレースを無効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_SESSION_TRACE_DISABLE(session_id   IN  BINARY_INTEGER);
```

## パラメータの説明

| **パラメータ**      | **説明**                                              |
|--------------|-------------------------------------------------------|
| session_id   | フルトレースを無効にする`session_id`。空の場合は、現在のセッションの`session_id`を表します。 |
