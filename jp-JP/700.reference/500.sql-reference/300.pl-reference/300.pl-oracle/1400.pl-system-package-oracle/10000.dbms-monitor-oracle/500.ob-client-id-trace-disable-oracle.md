# OB_CLIENT_ID_TRACE_DISABLE

`OB_CLIENT_ID_TRACE_DISABLE`は、client_identifierレベルのフルトレースを無効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_CLIENT_ID_TRACE_DISABLE(client_id IN  VARCHAR2);
```

## パラメータの説明

| **パラメータ**      | **説明**                            |
|--------------|-------------------------------------|
| client_id    | フルトレースを無効にする`client_id`です。       |
