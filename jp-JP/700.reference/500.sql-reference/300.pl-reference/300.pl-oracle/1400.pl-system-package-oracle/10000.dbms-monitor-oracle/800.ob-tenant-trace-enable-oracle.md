# OB_TENANT_TRACE_ENABLE

`OB_TENANT_TRACE_ENABLE`は、現在のテナントのフルトレースを有効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_TRACE_ENABLE(
  level        IN  INT,
  sample_pct   IN  NUMBER,
  record_policy IN VARCHAR2);
```

## パラメータの説明

| **パラメータ**       | **説明**                   |
| -------------- | -------------------------- |
| level:         | スパン内部データの収集粒度を制御します。Level 1、Level 2、Level 3 の3つのレベルがあります。                   |
| sample_pct:    | サンプリング率で、値の範囲は[0,1]です。                     |
| record_policy    | プリントのポリシーで、以下のオプションが含まれます：<ul><li>`ALL`：サンプリングされたすべてのクエリのトレースを出力します。</li></ul>        <ul><li>`ONLY_SLOW_QUERY`：スロークエリのみを出力します。</li></ul>   <ul><li>`SAMPLE_AND_SLOW_QUERY`：スロークエリを出力し、他のリクエストは `_print_sample_percentage` の確率に基づいて出力します。   </li></ul>          |
