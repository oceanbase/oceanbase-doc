# OB_MOD_ACT_TRACE_DISABLE

`OB_MOD_ACT_TRACE_DISABLE`は、module/actionレベルのフルリンクトレースを無効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_MOD_ACT_TRACE_DISABLE(
 module_name     IN  VARCHAR2,
 action_name     IN  VARCHAR2)
```

## パラメータの説明

| **パラメータ**        | **説明**                                       |
|------------------|----------------------------------------------|
| module_name      | フルトレースを無効にする `module_name`。             |
| action_name      | フルトレースを無効にする `action_name`。             |
