# DBMS_WORKLOAD_REPOSITORYの概要

`DBMS_WORKLOAD_REPOSITORY`システムパッケージは、自動ワークロードリポジトリ(AWR)を管理するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_WORKLOAD_REPOSITORY権限の説明

すべての`DBMS_WORKLOAD_REPOSITORY`システムパッケージのサブルーチンでは、ユーザーが`EXECUTE`権限を持っている必要があります。
