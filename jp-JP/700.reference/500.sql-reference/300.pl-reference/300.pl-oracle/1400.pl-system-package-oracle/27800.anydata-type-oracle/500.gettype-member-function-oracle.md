# GETTYPEメンバ関数

`GETTYPE` メンバ関数は、`ANYDATA` の型コードを取得するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
MEMBER FUNCTION GetType(
         self IN AnyData,
         typ OUT NOCOPY AnyType)
RETURN PLS_INTEGER；
```

## パラメータの説明

| パラメータ |             説明             |
|------|----------------------------|
| self | 1つの `ANYDATA`。              |
| typ  | `ANYDATA` に対応する `AnyType`。 |

## 戻り値

`ANYDATA` 型に対応する型。
