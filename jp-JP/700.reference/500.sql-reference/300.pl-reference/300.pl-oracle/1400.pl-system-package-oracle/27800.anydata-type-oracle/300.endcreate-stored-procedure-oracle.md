# ENDCREATEメンバーストアドプロシージャ

`ENDCREATE` メンバーストアドプロシージャは、`ANYDATA` の作成を終了するために使用されます。

この呼び出しを使用した後、他の作成関数を呼び出すことはできません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
MEMBER PROCEDURE EndCreate(
self IN OUT NOCOPY AnyData)；
```

## パラメータの説明

| パラメータ | 説明 |
|------|---------------|
| self | `ANYDATA` の1つ。 |
