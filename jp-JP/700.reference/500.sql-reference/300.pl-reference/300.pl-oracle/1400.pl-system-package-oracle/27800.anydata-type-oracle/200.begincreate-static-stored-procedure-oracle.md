# BEGINCREATE静的ストアドプロシージャ

`BEGINCREATE`静的ストアドプロシージャは、新しい`ANYDATA`の作成を開始するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
STATIC PROCEDURE BeginCreate(
dtype IN OUT NOCOPY AnyType,
adata OUT NOCOPY AnyData)；
```

## パラメータの説明

| パラメータ | 説明 |
|-------|---------------------|
| dtype | `ANYDATA`の型。      |
| adata | 現在構築中の`ANYDATA`を返します。 |

## 異常時

`DBMS_TYPES_INVALID_PARAMETERS`：`dtype`が無効です（`ANYTYPE`が不完全または類似の欠陥がある場合）。

## 使用方法

この呼び出しの直後に`PIECEWISE`を呼び出す必要はありません。`ANYDATA`プロセスの構築は、自動的に逐次的に開始されます。
