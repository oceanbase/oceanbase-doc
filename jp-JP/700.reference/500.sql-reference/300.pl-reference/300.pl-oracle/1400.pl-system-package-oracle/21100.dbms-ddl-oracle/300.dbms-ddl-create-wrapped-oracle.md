# CREATE_WRAPPED

`CREATE_WRAPPED`は、PLオブジェクト定義文字列を`CREATE WRAPPED`ステートメント文字列に暗号化し、このステートメントを実行して`WRAPPED`オブジェクトを作成するために使用されます。

## 構文

```sql
DBMS_DDL.CREATE_WRAPPED (DDL VARCHAR2);
DBMS_DDL.CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2A,
                        LB  PLS_INTEGER,
                        UB  PLS_INTEGER);
DBMS_DDL.CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2S,
                        LB  PLS_INTEGER,
                        UB  PLS_INTEGER);
```

## パラメータの説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|CREATE_WRAPPED (DDL VARCHAR2)|<ur><li>DDL: VARCHAR2型の文字列で、変換対象のPL/SQLソースコードを含みます。</li><li>RETURN: 戻り値はVARCHAR2型の文字列で、変換後のPL/SQLコードを含みます。|
|CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2A， LB  PLS_INTEGER, UB  PLS_INTEGER)|<ur><li>DDL: DBMS_SQL.VARCHAR2A型の配列で、変換対象のPL/SQLソースコードを含みます。</li><li>LB: PLS_INTEGER型の下限インデックス。</li><li>UB: PLS_INTEGER型の上限インデックス。|
|CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2S,LB  PLS_INTEGER,UB  PLS_INTEGER)|<ur><li>DDL: DBMS_SQL.VARCHAR2S型の配列で、変換対象のPL/SQLソースコードを含みます。</li><li>LB: PLS_INTEGER型の下限インデックス。</li><li>UB: PLS_INTEGER型の上限インデックス。</li>|

## 例

DBMS_DDLパッケージの`CREATE_WRAPPED`プロシージャを使用して、ラップされたPL/SQLパッケージを作成します。これは、元のPL/SQLコードを読み取りにくい形式に変換し、直接の閲覧や変更を防ぐために使用されます。

```shell
CALL dbms_ddl.create_wrapped(
  '-- this is a comment'                                                   || chr(10) ||
  'create or replace package arithmetic as'                                || chr(10) ||
  '  function add(a number, b number) return number; -- this is a comment' || chr(10) ||
  '  function sub(a number, b number) return number; /* comment */'        || chr(10) ||
  '  function /* comment */ mul(a number, b number) return number;'        || chr(10) ||
  '  /* comment1'                                                          || chr(10) ||
  '     comment2'                                                          || chr(10) ||
  '     comment3 */'                                                       || chr(10) ||
  '  function div(a number, b number) return number;'                      || chr(10) ||
  'end arithmetic;'                                                        || chr(10) ||
  '-- comment'                                                             || chr(10) ||
  '/* comment */'
);
Query OK, 0 rows affected (0.612 sec)
```

ここで：

* `create or replace package arithmetic as`：arithmeticという名前のパッケージを定義します。
* `function add(a number, b number) return number`：2つのnumber型のパラメータを受け取り、number型の結果を返す`add`関数を定義します。
* `function div(a number, b number) return number`：2つのnumber型のパラメータを受け取り、number型の結果を返す`div`関数を定義します。
* `end arithmetic`：パッケージの定義を終了します。
* `-- comment`：単一行コメント。
* `/* comment */`：複数行コメント。

ラップ後のコードは、読み取れない文字列になります。形式は以下のようになります（具体的な出力はバージョンや環境によって異なります）：

```sql
BEGIN
  DBMS_DDL.CREATE_WRAPPED('package body "SCHEMA_NAME"."ARITHMETIC" is
  function "ADD"(a in number, b in number) return number is
  begin
    return a + b;
  end;
  function "SUB"(a in number, b in number) return number is
  begin
    return a - b;
  end;
  function "MUL"(a in number, b in number) return number is
  begin
    return a * b;
  end;
  function "DIV"(a in number, b in number) return number is
  begin
    if b = 0 then
      raise value_error;
    else
      return a / b;
    end if;
  end;
end "ARITHMETIC";');
END;
/
```
