# WRAP

`WRAP`は、PLオブジェクト定義文字列を`CREATE WRAPPED`ステートメント文字列に暗号化するために使用されます。

## 構文

```sql
DBMS_DDL.WRAP(DDL VARCHAR2) RETURN VARCHAR2;
DBMS_DDL.WRAP(DDL DBMS_SQL.VARCHAR2S,
              LB  PLS_INTEGER,
              UB  PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2S;
DBMS_DDL.WRAP(DDL DBMS_SQL.VARCHAR2A,
              LB  PLS_INTEGER,
              UB  PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2A;
```

## パラメータの説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|WRAP(DDL VARCHAR2) RETURN VARCHAR2|<ur><li>DDL: VARCHAR2型の文字列で、コンパイルされるPL/SQLソースコードを含みます。</li><li>RETURN: 返される値は、コンパイルされたPL/SQLコードを含むVARCHAR2型の文字列です。|
|WRAP(DDL DBMS_SQL.VARCHAR2S, LB PLS_INTEGER, UB PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2S|<ur><li>DDL: DBMS_SQL.VARCHAR2S型の配列で、コンパイルされるPL/SQLソースコードを含みます。</li><li>LB: PLS_INTEGER型の下界インデックス。</li><li>UB: PLS_INTEGER型の上界インデックス。</li><li>RETURN: 返される値は、コンパイルされたPL/SQLコードを含むDBMS_SQL.VARCHAR2S型の配列です。|
|WRAP(DDL DBMS_SQL.VARCHAR2A, LB PLS_INTEGER, UB PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2A|<ur><li>DDL: DBMS_SQL.VARCHAR2A型の配列で、コンパイルされるPL/SQLソースコードを含みます。</li><li>LB: PLS_INTEGER型の下界インデックス。</li><li>UB: PLS_INTEGER型の上界インデックス。</li><li>RETURN: 返される値は、コンパイルされたPL/SQLコードを含むDBMS_SQL.VARCHAR2A型の配列です。|

## 例

PL/SQLとDBMS_DDLパッケージを使用してオブジェクト型を作成し、さまざまな方法でこれらの操作を実行します。
以下の3つの例はそれぞれ異なる方法でSQL文を実行しています。

**例1：**

`DBMS_DDL_WRAP`パッケージを使用して単一行のSQL文をラップし、DBMS_SQLパッケージを使用して解析および実行します。

```sql
declare
wrapped varchar2(32767);
c number;
r number;
begin
wrapped := dbms_ddl.wrap('create or replace type typ0 as object (a number);');
c := dbms_sql.open_cursor;
dbms_sql.parse(c, wrapped, dbms_sql.native);
r := dbms_sql.execute(c);
dbms_sql.close_cursor(c);
end;
/
 ```

その中で：

* `wrapped`：DBMS_DDL_WRAP処理後のSQL文を格納するために使用されます。
* `c`：カーソル識別子を指し、`dbms_sql.open_cursor`は新しいカーソルを開くことを意味し、`dbms_sql.close_cursor(c)`はカーソルを閉じることを意味します。
* `r`：実行結果を指し、`r := dbms_sql.execute(c)`は解析後のSQL文を実行することを意味します。

**例2：**

`DBMS_DDL_WRAP`パッケージを使用して単一行のSQL文をラップし、`EXECUTE IMMEDIATE`で直接実行します。

```sql
declare
  wrapped varchar2(32767);
begin
  wrapped := dbms_ddl.wrap('create or replace type typ1 as object (a number);');
  execute immediate wrapped;
end;
/
```

その中で：

* `dbms_ddl.wrap('create or replace type typ1 as object (a number);')`：オブジェクト型を作成するSQL文をラップすることを意味します。
* `execute immediate wrapped`：ラップしたSQL文を直接実行することを意味します。

**例3：**

`DBMS_DDL_WRAP`パッケージを使用して複数行のSQL文配列をラップし、DBMS_SQLパッケージを使用して解析および実行します。

```sql
declare
  sqls dbms_sql.varchar2a;
  c number;
  r number;
begin
  sqls(1) := 'create or replace type typ2 as object (';
  sqls(2) := '  a number';
  sqls(3) := ';';
  sqls := dbms_ddl.wrap(sqls, 1, sqls.count);
  c := dbms_sql.open_cursor;
  dbms_output.put_line(sqls.count);
  dbms_sql.parse(c, sqls, 1, sqls.count, false, dbms_sql_native);-- dbms_sql.parse linefeed flagパラメータはfalseに設定する必要があります。そうしないと、余分な改行文字がcreate wrapped文の構文解析に失敗を引き起こします。
  r := dbms_sql.execute(c);
  dbms_sql.close_cursor(c);
end;
/
```

その中で：

* `sqls := dbms_ddl.wrap(sqls, 1, sqls.count)`：複数行のSQL文配列をラップすることを意味します。
* `dbms_output.put_line(sqls.count)`：ラップしたSQL文配列の長さを出力することを意味します。
* `dbms_sql.parse(c, sqls, 1, sqls.count, false, dbms_sql_native)`：ラップしたSQL文配列を解析することを意味します。
