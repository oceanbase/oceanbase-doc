# GET_DDL

`GET_DDL`関数は、単一のオブジェクトのメタデータをDDLとして返すために使用されます。

`GET_xxx`関数は、1回の呼び出しでオブジェクトのメタデータを取得するために使用されます。現在、OceanBaseデータベースの現行バージョンでは`GET_DDL`のみがサポートされています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
FUNCTION  GET_DDL (
    object_type     VARCHAR,
    name            VARCHAR,
    ob_schema       VARCHAR DEFAULT NULL,
    version         VARCHAR DEFAULT 'COMPATIBLE',
    model           VARCHAR DEFAULT 'ORACLE',
    transform       VARCHAR DEFAULT 'DDL')
RETURN CLOB;
```

## パラメータの説明

|   **パラメータ**    |            **説明**             |
|-------------|-------------------------------|
| object_type | 検索対象のオブジェクトのタイプ。オブジェクトタイプのプロパティは、名前付けられたオブジェクトでなければなりません。 |
| name        | オブジェクトの名前。                        |
| ob_schema   | そのオブジェクトを含むスキーマ。デフォルトは呼び出し元のスキーマです。 |
| version     | オブジェクトのmetadataバージョン。              |
| model       | metadataのオブジェクトモデル。               |
| transform   | XSL-T変換を適用して出力結果を変換します。              |
