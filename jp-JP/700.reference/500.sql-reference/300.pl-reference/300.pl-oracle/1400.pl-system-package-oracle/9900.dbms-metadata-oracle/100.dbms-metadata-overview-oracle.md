# DBMS_METADATAの概要

`DBMS_METADATA` システムパッケージは、DDLを作成したり、XMLドキュメントをコミットしてDDLを実行したりするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_METADATA権限の説明

このシステムパッケージは `SYS` ユーザーに属し、`PUBLIC` に実行アクセス権限を付与します。`DBMS_METADATA` は呼び出し元の権限（つまり、呼び出し元のセキュリティ設定ファイル）に基づいて実行されます。

## DBMS_METADATAサブルーチンの概要

次の表は、OceanBaseデータベースの現行バージョンでサポートされている `DBMS_METADATA` サブルーチンとその簡潔な説明を示しています。

 サブルーチン | 説明 |
| --- | --- |
|[GET_DDL](200.get-ddl-oracle.md)|単一オブジェクトのメタデータをDDLとして返すために使用されます。|
|[GET_TABLE_INDEX_DDL](300.get-table-index-ddl-oracle.md)|主表(TABLE)のインデックスDDL文を一括で抽出するために使用されます。|
