# DBMS_PLAN_CACHEの概要

`DBMS_PLAN_CACHE`システムパッケージはOceanBaseデータベース固有であり、SQL実行計画キャッシュ（Plan Cache）に対する細かい粒度の操作を提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_PLAN_CACHE権限の説明

このシステムパッケージは`SYS`下に作成する必要があります。このシステムパッケージを使用するには、`SYS.DBMS_PLAN_CACHE`に対する`EXECUTE`権限が必要です。

## DBMS_PLAN_CACHEサブルーチンの概要

以下の表は、OceanBaseデータベースの現行バージョンでサポートされている`DBMS_PLAN_CACHE`サブルーチンとその簡潔な説明を示しています。


|                       **サブルーチン**                        |         **説明**          |
|------------------------------------------------------|-------------------------|
| [PURGE](../12500.dbms-plan-cache-oracle/200.purge-oracle.md) | Plan Cacheから指定されたSQLを削除します。 |
