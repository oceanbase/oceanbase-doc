# PURGE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/PURGE
`PURGE` ステートメントは、指定されたSQL文をPlan Cacheから削除します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_PLAN_CACHE.PURGE (
sql_id           VARCHAR2 NOT NULL,
schema        VARCHAR2 DEFAULT NULL
global          BOOLEAN  DEFAULT FALSE);
```

## パラメータの説明

|   パラメータ   |                                      説明                                       |
|--------|-------------------------------------------------------------------------------|
| sql_id | SQL識別子で、長さは32バイトです。SQLが削除されると、そのすべての実行計画も同時に無効になります。                                    |
| schema | 特定のスキーマによって生成された実行計画を指定します。`NULL` はスキーマを指定しないことを意味し、すべてのスキーマの実行計画が無効になります。 |
| global | パラメータ値が `FALSE` の場合、このマシン上の計画キャッシュをクリアすることを意味します。パラメータ値が `TRUE` の場合、そのテナントが存在するすべてのサーバー上の計画キャッシュをクリアすることを意味します。                   |
