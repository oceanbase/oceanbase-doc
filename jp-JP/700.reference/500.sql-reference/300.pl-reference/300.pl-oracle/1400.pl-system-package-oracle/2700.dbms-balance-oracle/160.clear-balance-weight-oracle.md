# CLEAR_BALANCE_WEIGHT

`CLEAR_BALANCE_WEIGHT`は、パーティションの重みをクリアするために使用されます。

## 制限事項と注意点

* V4.2.5バージョンでは、V4.2.5 BP2以降でパーティションの重みをクリアする機能がサポートされています。

* ユーザーテナントのみが`CLEAR_BALANCE_WEIGHT`サブルーチンを呼び出してパーティションの重みをクリアできます。システムテナントはパーティションの重みをクリアすることができません。

* テーブルレベルのパーティションの重みをクリアすると、すべてのパーティションに設定されたテーブルレベルの重みが削除されます。そのテーブルにパーティションレベルの重みが設定されている場合、システムはパーティションレベルの重みを保持します。

## 構文

```sql
DBMS_BALANCE.CLEAR_BALANCE_WEIGHT(
    schema_name         IN VARCHAR2,
    table_name          IN VARCHAR2,
    partition_name      IN VARCHAR2 DEFAULT NULL,
    subpartition_name   IN VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ**         | **説明**                                            |
|------------------|-----------------------------------------------------|
| schema_name      | テーブルが属するスキーマ名  |
| table_name       | テーブル名             |
| partition_name   | パーティション名        |
| subpartition_name| サブパーティション名。構文上はサポートされていますが、現在のところサブパーティションの重み付け設定はサポートされていません。        |

## 例

1. ユーザー `USR2`（Oracleモードではスキーマ名とユーザー名が同じ）に、パーティション重みを設定したテーブル `TBL1_H` があるとします。

    パーティションの重み情報を照会するステートメントは以下のとおりです：

    ```shell
    obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    照会結果は次のとおりです：

    ```shell
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    |   500002 |         NULL |            NULL |      1 | USR2          | TBL1_H     | NULL           | NULL              | NULL            |      201006 |          NULL |    500002 |
    |   500002 |       500003 |            NULL |      2 | USR2          | TBL1_H     | P0             | NULL              | NULL            |      201006 |          NULL |    500003 |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    2 rows in set
    ```

2. テーブル `TBL1_H` のテーブルレベルのパーティション重みをクリアします。

    ```shell
    obclient [USR2]> delimiter //
    ```

    ```shell
    obclient[USR2]> BEGIN
              DBMS_BALANCE.CLEAR_BALANCE_WEIGHT('USR2','TBL1_H');
              END;//
    ```

    ```shell
    obclient [USR2]> delimiter ;
    ```

3. クリア後、テーブルに設定されたパーティションの重み情報を照会します。

    ```shell
    obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    結果は次のとおりです：

    ```shell
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    |   500002 |       500003 |            NULL |      2 | USR2          | TBL1_H     | P0             | NULL              | NULL            |      201006 |          NULL |    500003 |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    1 row in set
    ```

4. テーブル `TBL1_H` 内のパーティション `P0` のパーティション重みをクリアします。

    ```shell
    obclient [USR2]> delimiter //
    ```

    ```shell
    obclient[USR2]> BEGIN
            DBMS_BALANCE.CLEAR_BALANCE_WEIGHT('USR2','TBL1_H','P0');
            END;//
    ```

    ```shell
    obclient [USR2]> delimiter ;
    ```

5. クリア後、再度テーブルに設定されたパーティションの重み情報を照会します。

    ```shell
    obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    照会結果は空です。
