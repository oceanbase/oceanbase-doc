# TRIGGER_PARTITION_BALANCE

`TRIGGER_PARTITION_BALANCE`は、パーティションの再バランスを手動でトリガーするために使用されます。

## 構文

```sql
DBMS_BALANCE.TRIGGER_PARTITION_BALANCE(balance_timeout BINARY_INTEGER DEFAULT NULL);
```

## パラメータの説明

パラメータ`balance_timeout`は秒単位で、バックグラウンドの再バランスタスクのタイムアウト時間を制御します。

## 注意事項

* このシステムパッケージは、ユーザーテナントでのみ呼び出すことができます。sysテナントからの呼び出しでは、<code>OB_OP_NOT_ALLOW</code>エラーが報告されます。
* テナントレベルの構成パラメータ<code>enable_rebalance</code>または<code>enable_transfer</code>が無効になっている場合、<code>OB_OP_NOT_ALLOW</code>エラーが報告され、手動でのパーティション再バランスのトリガーは許可されません。
* 他の再バランスタスクが実行中の場合、<code>OB_OP_NOT_ALLOW</code>エラーが報告され、現在の再バランスタスクが完了するまで待機する必要があります。
* 現在のテナントで既にパーティションの再バランスが実行されている場合、<code>OB_PARTITION_ALREADY_BALANCED</code>エラーが報告されます。

## 例

* パーティションの再バランスを1回トリガーし、バックグラウンドの再バランスタスクにタイムアウト時間を設定せず、完了するまで続けます。

    ```shell
    obclient> BEGIN
              DBMS_BALANCE.TRIGGER_PARTITION_BALANCE();
              END;
    ```

* パーティションの再バランスをトリガーした後、バックグラウンドの再バランスタスクは最大2時間実行され、完了しない場合はタイムアウトしてキャンセルされます。

    ```shell
    obclient> BEGIN
              DBMS_BALANCE.TRIGGER_PARTITION_BALANCE(7200);
              END;
    ```
