# DBMS_BALANCEの概要

`DBMS_BALANCE`システムパッケージは、パーティションの均衡に関するメソッドを提供するために使用されます。

## DBMS_BALANCE権限の説明

PL/SQL実行権限を持つユーザーテナントはこの機能を使用できます。sysテナントが呼び出すと、エラー`OB_OP_NOT_ALLOW`が返されます。

## DBMS_BALANCEサブルーチンの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_BALANCE`サブルーチンとその説明を示しています。

| サブルーチン | 説明 |
| --- | --- |
|[SET_BALANCE_WEIGHT](../2700.dbms-balance-oracle/150.set-balance-weight-oracle.md)              |パーティションの重みを手動で設定します。|
|[CLEAR_BALANCE_WEIGHT](../2700.dbms-balance-oracle/160.clear-balance-weight-oracle.md)          |パーティションの重みを手動でクリアします。|
|[TRIGGER_PARTITION_BALANCE](../2700.dbms-balance-oracle/200.trigger-paptition-balance-oracle.md)|パーティションの均衡を手動でトリガーします。|
