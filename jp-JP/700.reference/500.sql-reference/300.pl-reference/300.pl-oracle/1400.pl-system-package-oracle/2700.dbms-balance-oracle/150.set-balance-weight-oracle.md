# SET_BALANCE_WEIGHT

`SET_BALANCE_WEIGHT`はパーティションの重みを設定するために使用されます。レベルによって、テーブルレベルとパーティションレベルのパーティション重みを設定できます。

## 制限事項と注意点

* V4.2.5バージョンでは、V4.2.5 BP2以降のバージョンからパーティション重みを手動で設定できるようになりました。

* パーティション重みの手動設定はユーザーテナントのみサポートしており、システムテナントでは設定できません。

* 現在、パーティションテーブルおよびパーティションテーブルのパーティションに対するパーティション重みの設定のみがサポートされており、サブパーティションへの重み設定は現在サポートされていません。

* 既存のエンティティパーティションに対してのみ重みを設定でき、テーブル作成時に重みを指定することはサポートされていません。つまり、まずテーブルを作成し、その後にパーティション重みを設定する必要があります。

* パーティション重みは整数のみサポートしており、値の範囲は[1, +∞)です。デフォルトでは、パーティションには重みが付けられていません。

* パーティション重みを設定する際は、できるだけ少ない段階で設定することを推奨します。最大でも3段階に分けることを推奨します：

  * 大重み = 100% × パーティション数

  * 中重み = 50% × パーティション数

  * 小重み = 1

* 重み均等化に参加する必要がないパーティションテーブルについては、パーティション重みを設定しないことを推奨します。

* パーティション重みを設定する際、下位のパーティションは上位のパーティションの重みをデフォルトで継承します。複数のレベルに同時にパーティション重みを設定した場合、下位の重みが上位の重みを上書きします。

* パーティション重みを設定した後、ユーザーがOffline DDL操作（例えば、Truncate Table、Truncate Partitionなどの操作）を実行してパーティションエンティティに変更が生じた場合、元のパーティション重みも無効になり、ユーザーが再度パーティション重みを設定する必要があります。パーティション重みが無効になる可能性のあるOffline DDLについては、[Online DDLとOffline DDL操作（Oracleモード）](../../../../100.sql-syntax/300.common-tenant-of-oracle-mode/1000.ddl-function-of-oracle-mode/150.online-and-offline-ddl-list-of-oracle-mode.md)を参照してください。

## 構文

```sql
DBMS_BALANCE.SET_BALANCE_WEIGHT(
    weight              IN BINARY_INTEGER,
    schema_name         IN VARCHAR2,
    table_name          IN VARCHAR2,
    partition_name      IN VARCHAR2 DEFAULT NULL,
    subpartition_name   IN VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ**         | **説明**                                            |
|------------------|-----------------------------------------------------|
| weight           | パーティションの重み。つまり、パーティション間でリソース（CPU、メモリ、ディスクなど）を占める相対的な割合です。値の範囲は[1, +∞)です。 |
| schema_name      | テーブルが属するスキーマ名  |
| table_name       | テーブル名             |
| partition_name   | パーティション名        |
| subpartition_name| サブパーティション名。構文上はサポートされていますが、現在サブパーティションの重み設定はサポートされていません。         |

## 例

1. ユーザー `USR2` がHashパーティションテーブル `TBL1_H` を作成したとします。

    ```shell
    obclient[USR2]> CREATE TABLE TBL1_H(col1 INT,col2 VARCHAR(50)) PARTITION BY HASH(col1) PARTITIONS 5;
    ```

2. このテーブルのパーティション情報を確認するステートメントは以下のとおりです。

    ```shell
    obclient[USR2]> SELECT TABLE_NAME, PARTITION_NAME FROM USER_TAB_PARTITIONS WHERE TABLE_NAME = 'TBL1_H';
    ```

    実際に得られるパーティション情報は以下のとおりです：

    ```shell
    +------------+----------------+
    | TABLE_NAME | PARTITION_NAME |
    +------------+----------------+
    | TBL1_H     | P4             |
    | TBL1_H     | P3             |
    | TBL1_H     | P2             |
    | TBL1_H     | P1             |
    | TBL1_H     | P0             |
    +------------+----------------+
    5 rows in set
    ```

3. テーブル `TBL1_H` のテーブルレベルのパーティション重みを1に設定します。

    ```shell
    obclient [USR2]> delimiter //
    ```

    ```shell
    obclient[USR2]> BEGIN
                  DBMS_BALANCE.SET_BALANCE_WEIGHT(1,'USR2','TBL1_H');
                  END;//
    ```

    ```shell
    obclient [USR2]> delimiter ;
    ```

4. テーブル `TBL1_H` のテーブルレベルのパーティション重みを設定した後、設定されたパーティション重み情報を照会します。

    ```shell
    obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    結果は次のとおりです：

    ```shell
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    |   500002 |         NULL |            NULL |      1 | USR2          | TBL1_H     | NULL           | NULL              | NULL            |      201006 |          NULL |    500002 |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    1 row in set
    ```

5. さらに、テーブル `TBL1_H` 内のパーティション `P0` のパーティション重みを2に設定します。

    ```shell
    obclient [USR2]> delimiter //
    ```

    ```shell
    obclient[USR2]> BEGIN
                  DBMS_BALANCE.SET_BALANCE_WEIGHT(2,'USR2','TBL1_H','P0');
                  END;//
    ```

    ```shell
    obclient [USR2]> delimiter ;
    ```

6. 再び、設定されたパーティション重み情報を照会します。

    ```shell
    obclient[USR2]> obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
    ```

    照会結果は次のとおりです：

    ```shell
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    |   500002 |         NULL |            NULL |      1 | USR2          | TBL1_H     | NULL           | NULL              | NULL            |      201006 |          NULL |    500002 |
    |   500002 |       500003 |            NULL |      2 | USR2          | TBL1_H     | P0             | NULL              | NULL            |      201006 |          NULL |    500003 |
    +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
    2 rows in set
    ```
