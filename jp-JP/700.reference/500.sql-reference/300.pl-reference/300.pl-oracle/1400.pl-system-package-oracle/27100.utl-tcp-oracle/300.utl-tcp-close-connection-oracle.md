# CLOSE_CONNECTION

`CLOSE_CONNECTION`は、開いているTCP/IP接続を閉じるために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_TCP.CLOSE_CONNECTION (
   c IN OUT NOCOPY connection);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|閉じるTCP/IP接続。|

## 使用方法

* `open_connection`で既に開いた接続である必要があります。接続を閉じると、`remote_host`、`remote_port`、`local_host`、`local_port`、`charset`、`private_sd`フィールドがリセットされます。
* 開いている接続は明示的に閉じる必要があります。`connection`変数のライフサイクルが終了しても、接続は自動的に閉じられません。
* セッションが閉じられるまで、以前に閉じられなかった接続は自動的に閉じられます。
