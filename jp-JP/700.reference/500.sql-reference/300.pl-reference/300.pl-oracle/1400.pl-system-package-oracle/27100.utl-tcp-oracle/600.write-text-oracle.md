# WRITE_TEXT

`WRITE_TEXT`は、開いた接続を持つサービスにテキストメッセージを転送するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_TCP.WRITE_TEXT (
   c    IN OUT NOCOPY connection,
   data IN            VARCHAR2 CHARACTER SET ANY_CS,
   len  IN            PLS_INTEGER DEFAULT NULL)
 RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c| TCP/IP接続。|
|data|送信するデータを含むバッファ。|
|len|転送するデータの文字数。`NULL` の場合、すべてのデータが転送されます。ネットワーク状況により、実際に書き込まれるデータは少なくなる場合があります。|

## 戻り値

転送されたデータの実際の文字数を返します。

## 使用方法

* `open_connection`で既に開いた接続である必要があります。
* 転送前に、テキスト文字セットを指定されたオンライン文字セットに変換します。
* `len`が`data`の文字数より大きい場合、`bad argument`例外がスローされます。
