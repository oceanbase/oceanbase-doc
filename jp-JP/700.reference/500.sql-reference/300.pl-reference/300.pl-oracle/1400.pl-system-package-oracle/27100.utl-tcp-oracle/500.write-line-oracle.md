# WRITE_LINE

`WRITE_LINE`は、テキスト行を開いた接続先のサービスに転送するために使用されます。メッセージの末尾に`newline`文字列が追加されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_TCP.WRITE_LINE (
   c    IN OUT NOCOPY connection,
   data IN            VARCHAR2 DEFAULT NULL CHARACTER SET ANY_CS)
  RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c| TCP/IP接続。|
|data|送信するデータを含むバッファ。|

## 戻り値

転送したデータの実際の文字数を返します。

## 使用方法

* `open_connection`で既に開いた接続である必要があります。
* 転送前に、テキスト文字セットを指定されたオンライン文字セットに変換します。
