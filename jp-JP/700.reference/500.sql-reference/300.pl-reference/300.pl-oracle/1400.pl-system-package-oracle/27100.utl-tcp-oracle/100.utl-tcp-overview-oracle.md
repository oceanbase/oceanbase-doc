# UTL_TCPの概要

`UTL_TCP`は、TCP/IPプロトコルを使用して外部サーバーと通信するためのシステムパッケージです。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## UTL_TCPサブルーチンの概要

以下の表は、OceanBaseデータベースの現行バージョンでサポートされている`UTL_TCP`サブルーチンとその簡潔な説明を示しています。

|                       **サブルーチン**             |                **説明**                       |
|----------------------------------------------|-----------------------------------------------|
|[OPEN_CONNECTION](200.open-connection-oracle.md)|指定されたサービスとのTCP/IP接続を開きます。|
|[CLOSE_CONNECTION](300.utl-tcp-close-connection-oracle.md)|開いているTCP/IP接続を閉じます。|
|[CLOSE_ALL_connections](400.close-all-connections-oracle.md)|開いているTCP/IP接続を閉じます。|
|[WRITE_LINE](500.write-line-oracle.md)|テキスト行を開いた接続先のサービスに転送します。|
|[WRITE_TEXT](600.write-text-oracle.md)|テキストメッセージを開いた接続先のサービスに転送します。|
|[WRITE_RAW](700.write-raw-oracle.md)|バイナリを開いた接続先のサービスに転送します。|
|[GET_LINE](800.get-line-of-oracle.md)|行末または入力終了時まで読み取ったテキスト行データを返します。|
|[GET_TEXT](900.get-text-oracle.md)|読み取ったテキストデータを返します。|
