# PURGE_STATS

`PURGE_STATS`は、指定された時刻より前の履歴統計情報を削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.PURGE_STATS(
  before_timestamp       TIMESTAMP WITH TIME ZONE);
```

## パラメータの説明

`before_timestamp`パラメータは、このタイムスタンプより前に保存された統計情報がクリーンアップされることを指定します。`NULL`の場合、自動クリーンアップポリシーが使用されます。

## 異常ケース

|    エラーコード    |      説明      |
|-----------|--------------|
| ORA-20000 | 対象が存在しないか、権限が不足しています。 |
| ORA-20001 | 無効な値または矛盾する値です。   |

## 例

指定された時刻の履歴統計情報を手動でクリーンアップします。

```sql
obclient> CALL DBMS_STATS.PURGE_STATS (TO_TIMESTAMP('2021-09-26 19:02:12.675729', 'YYYY-MM-DD HH24:MI:SS.FF'));
Query OK, 0 rows affected
```
