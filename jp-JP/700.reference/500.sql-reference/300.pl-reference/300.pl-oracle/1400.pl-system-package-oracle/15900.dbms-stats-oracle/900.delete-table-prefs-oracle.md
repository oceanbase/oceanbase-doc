# DELETE_TABLE_PREFS

`DELETE_TABLE_PREFS` プロシージャは、指定されたユーザーが所有するテーブルの統計情報の設定を削除します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.DELETE_TABLE_PREFS (
  ownname    IN  VARCHAR2,
  tabname    IN  VARCHAR2,
  pname      IN  VARCHAR2);
```

## パラメータの説明

|   パラメータ    |                説明              |
|---------|-----------------------------------|
| ownname | ユーザー名。ユーザー名を `NULL` に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| tabname | テーブル名。                               |
| pname   | Prefsの名前。                       |

## 異常時の動作

|    エラーコード   |     説明     |
|-----------|-------------|
| ORA-20000 | 権限が不足しています。       |
| ORA-20001 | 無効な値または不正な入力値です。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとしてデータベースに接続しているか、`SYSDBA` 権限を持っている必要があります。

* このプロシージャのパラメータはすべて `VARCHAR2` タイプであり、その値は引用符で囲む必要があります。

## 例

`testUser01` ユーザーの `tbl1` テーブルの設定 `DEGREE` を削除します。

```sql
obclient> CALL DBMS_STATS.DELETE_TABLE_PREFS('testUser01', 'tbl1', 'DEGREE');
Query OK, 0 rows affected
```
