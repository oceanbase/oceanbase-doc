# DELETE_SCHEMA_PREFS

`DELETE_SCHEMA_PREFS` プロシージャは、指定されたユーザーの下にあるすべてのテーブルの統計情報の設定を削除します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.DELETE_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2);
```

## パラメータの説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | ユーザー名。ユーザー名を `NULL` に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| pname   | Prefsの名前。 |

## 異常時

|    エラーコード    |        説明     |
|-----------|------------------|
| ORA-20000 | ユーザーが存在しないか、権限が不足しています。 |
| ORA-20001 | 無効な値または不正な入力値です。      |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとしてデータベースに接続しているか、`SYSDBA` 権限を持っている必要があります。

* このプロシージャのパラメータはすべて `VARCHAR2` タイプであり、その値は引用符で囲む必要があります。

## 例

`hr` の下の設定 `DEGREE` を削除します。

```sql
obclient> CALL DBMS_STATS.DELETE_SCHEMA_PREFS('hr', 'DEGREE');
Query OK, 0 rows affected
```
