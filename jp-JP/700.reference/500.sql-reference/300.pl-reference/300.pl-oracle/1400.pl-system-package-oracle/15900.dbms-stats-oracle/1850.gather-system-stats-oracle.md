# GATHER_SYSTEM_STATS

`GATHER_SYSTEM_STATS` プロシージャは、システム統計情報を収集するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.GATHER_SYSTEM_STATS();
```

## 異常時

|    エラーコード    |        説明     |
|-----------|------------------|
| ORA-20001 | 入力したシステム統計情報名が誤っています。 |

## 使用方法

このプロシージャを実行するには、ユーザーに `SYSDBA` 権限または `SYS` ユーザーである必要があります。

## 例

`DBMS_STATS.GATHER_SYSTEM_STATS` プロシージャを実行して、CPU速度、ディスクI/Oパフォーマンス、ネットワークスループットなどのシステム統計情報を収集します。

```sql
BEGIN
    -- システム統計情報の収集
    DBMS_STATS.GATHER_SYSTEM_STATS();
END;
/
```
