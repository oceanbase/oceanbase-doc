# DELETE_SYSTEM_STATS

`DELETE_SYSTEM_STATS` プロシージャは、システム統計情報を削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.DELETE_SYSTEM_STATS();
```

## 異常時

|    エラーコード    |        説明     |
|-----------|------------------|
| ORA-20001 | 入力したシステム統計情報名が誤っています。 |

## 使用方法

このプロシージャを実行するには、ユーザーに `SYSDBA` 権限または `SYS` ユーザーである必要があります。

## 例

`DBMS_STATS.DELETE_SYSTEM_STATS` ストアドプロシージャを使用してすべてのシステム統計情報を削除するのは非常に簡単です。パラメータは不要だからです。

```sql
BEGIN
    -- すべてのシステム統計情報を削除
    DBMS_STATS_DELETE_SYSTEM_STATS();
END;
/
```
