# DROP_STAT_TABLE

`DROP_STAT_TABLE` プロシージャは、ユーザーの統計テーブルを削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.DROP_STAT_TABLE (
  ownname VARCHAR2,
  stattab VARCHAR2);
```

## パラメータの説明

|   パラメータ    |                説明                 |
|---------|-----------------------------------|
| ownname | ユーザー名。ユーザー名を `NULL` に設定した場合、現在ログインしているユーザー名がデフォルトで使用されます。 |
| stattab | 削除するユーザー統計情報テーブルの名前。                   |

## 異常時の処理

エラーコード `ORA-20000` は、テーブルが存在しないか、権限が不足していることを示します。

## 使用方法

このプロシージャを呼び出すには、指定されたユーザーからそのテーブルを削除する権限が必要です。

## 例

ユーザー `testUser01` の統計情報テーブル `test_stat` を削除します。

```sql
obclient> CALL DBMS_STATS.DROP_STAT_TABLE('testUser01', 'test_stat');
Query OK, 0 rows affected
```
