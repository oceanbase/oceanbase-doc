# PAUSE_PROFILER

`PAUSE_PROFILER`は、パフォーマンスプロファイラーを一時停止するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_PROFILER.PAUSE_PROFILER
  RETURN BINARY_INTEGER;

DBMS_PROFILER.PAUSE_PROFILER;
```

 <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>RETURN BINARY_INTEGER</code>は、返すデータ型をバイナリ整数として指定するために使用されます。実際の使用では、通常は個別に <code>RETURN BINARY_INTEGER</code> を宣言する必要はなく、直接 <code>PAUSE_PROFILER</code> プロシージャを呼び出します。</p>
  </main>

## 例

以下のコマンドを実行して、パフォーマンスプロファイラーを一時停止します。

```shell
obclient> call DBMS_PROFILER.pause_profiler();
Query OK, 0 rows affected (0.012 sec)
```
