# INTERNAL_VERSION_CHECK

`INTERNAL_VERSION_CHECK`は、データベースのバージョンと`DBMS_PROFILER`バージョンが一致しているかどうかを検証するために使用されます。
OBServerと一緒に配布されるadminパッケージが意図しなく変更された場合、`dbms_profiler`システムパッケージが正常に動作しなくなり、システムの安定性に影響を与える可能性があります。このような場合は、ユーザーにデータのバックアップを行い、再インストールメディアを使用してOBServerを再デプロイすることを推奨します。標準的なデプロイアップグレードプロセスを使用すれば、通常バージョンの不一致は発生しません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_PROFILER.INTERNAL_VERSION_CHECK
  RETURN BINARY_INTEGER;
```

## 例

```shell
obclient> select dbms_profiler.INTERNAL_VERSION_CHECK() from dual;
+----------------------------------------+
| DBMS_PROFILER.INTERNAL_VERSION_CHECK() |
+----------------------------------------+
|                                      0 |
+----------------------------------------+
1 row in set (0.063 sec)
```
