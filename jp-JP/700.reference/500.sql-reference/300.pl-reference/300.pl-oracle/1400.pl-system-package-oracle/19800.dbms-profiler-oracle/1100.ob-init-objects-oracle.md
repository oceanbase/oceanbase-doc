# OB_INIT_OBJECTS

ユーザーの`schema`下にデータ統計テーブルを作成します。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
PROCEDURE OB_INIT_OBJECTS(force_create IN boolean :=FALSE);
```

## パラメータの説明

|       パラメータ       |               説明                |
|----------------|---------------------------------|
| force_create IN boolean :=FALSE | <li><code>FALSE</code> の場合、統計テーブルと同名のテーブルが存在するとエラーが発生し終了します。<li><code>TRUE</code> の場合、統計テーブルと同名のテーブルが存在する場合、まず <code>DROP</code> してから作成します。デフォルトは <code>FALSE</code> です。|

```shell
obclient> call dbms_profiler.ob_init_objects();
Query OK, 0 rows affected (0.06 sec)
```
