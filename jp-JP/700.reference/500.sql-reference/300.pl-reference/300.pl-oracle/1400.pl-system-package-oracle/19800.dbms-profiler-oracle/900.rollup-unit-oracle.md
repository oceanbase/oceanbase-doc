# ROLLUP_UNIT

`ROLLUP_UNIT`は、特定の実行におけるあるユニットの実行時間を計算するために使用されます。

 <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
PROCEDURE ROLLUP_UNIT(run_number IN number,unit IN number);
```

## パラメータの説明

|       パラメータ       |               説明                |
|----------------|---------------------------------|
| run_number | 実行データを保存および後で呼び出すために使用される実行番号。<code>run_number</code> のINパラメータの値はすべて、<code>start_profiler</code> の <code>run_number OUT</code> パラメータから取得します。|
| unit | オブジェクトID。データ統計テーブルの <code>unit_number</code> 列を指します。|

## 例

```shell
obclient> call dbms_profiler.rollup_unit(1,501810);
Query OK, 0 rows affected (0.08 sec)
```
