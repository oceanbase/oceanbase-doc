# XMLTYPE

`XMLTYPE` はXMLType構築関数です。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
CONSTRUCTOR FUNCTION XMLType(
   xmlData IN CLOB)
RETURN SELF AS RESULT；

CONSTRUCTOR FUNCTION XMLType(
   xmlData IN VARCHAR2)
RETURN SELF AS RESULT；
```

## パラメータの説明

|   パラメータ    |                   説明                   |
|---------|----------------------------------------|
| xmlData | パラメータのデータ型は `CLOB` および `VARCHAR2` です。入力データが合法的なXML `DOCUMENT` テキストである場合、このテキストから構成されるXMLType型のデータを返します。 |

## 例

以下の例では、変数 `b` は合法的なXMLテキストであり、`a` はXMLType型の変数です。5行目の `a:=xmltype(b)` は、`b` を使用してXMLType型の値を構築し、変数 `a` に代入します。

```sql
obclient> DECLARE
        a XMLType;
        b VARCHAR2(200):='<?xml version="1.0" encoding="ISO-8859-1"?><note><heading>Reminder</heading></note>';
      BEGIN
        a:=XMLType(b);
      END;
      /
Query OK, 0 rows affected
```

入力データが合法的なXML `DOCUMENT` テキストでない場合、構築関数を実行するとエラーが報告されます。

```sql

        a XMLType;

        a:=XMLType(b);
      END;
```
