# CAST_TO_RAW

`CAST_TO_RAW`関数は、特定のバイト数で表される`VARCHAR2`値を、同じバイト数を持つRAW値に変換します。

データ自体は一切変更されませんが、そのデータ型は`RAW`データ型に変換されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.CAST_TO_RAW (
   c  IN VARCHAR2)
RETURN RAW;
```

## パラメータの説明

| **パラメータ** |         **説明**          |
|--------|-------------------------|
| c      | `RAW`に変更される`VARCHAR2`データ。 |

## 戻り値

| **戻り値** |                  **説明**                  |
|---------|------------------------------------------|
| RAW     | 入力された`VARCHAR2`と同じデータを含み、バイト長が等しく、先頭の長さフィールドがないもの。 |
| NULL    | `c`の入力パラメータが`NULL`である場合。                         |
