# CAST_TO_NUMBER

`CAST_TO_NUMBER`関数は、`RAW`バイナリ形式で表される`NUMBER`値を`NUMBER`に変換するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>NUMBER</code>型について、OceanBaseデータベースとOracleの実装方法は異なります。入力される<code>RAW</code>バイナリ形式は、OceanBaseデータベース内部で表される<code>NUMBER</code>形式である必要があります。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
UTL_RAW.CAST_TO_NUMBER (
   r  IN RAW)
 RETURN NUMBER;
```

## パラメータの説明

パラメータ`n`は`NUMBER`のバイナリ表現です。

## 戻り値

`NUMBER`値を返します。

## 例

```sql
obclient> SELECT UTL_RAW.CAST_TO_NUMBER('020000C07B00000000022E1B') FROM DUAL;
+----------------------------------------------------+
| UTL_RAW.CAST_TO_NUMBER('020000C07B00000000022E1B') |
+----------------------------------------------------+
|                                            123.456 |
+----------------------------------------------------+
1 row in set

obclient> SELECT UTL_RAW.CAST_TO_NUMBER('020000407B00000000022E1B') FROM DUAL;
+----------------------------------------------------+
| UTL_RAW.CAST_TO_NUMBER('020000407B00000000022E1B') |
+----------------------------------------------------+
|                                           -123.456 |
+----------------------------------------------------+
1 row in set
```
