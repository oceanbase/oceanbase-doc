# UTL_RAWの概要

`UTL_RAW` システムパッケージは、`RAW` データ型を操作するためのSQL関数を提供します。

通常のSQL関数は `RAW` データに対して操作できず、PLは `RAW` と `CHAR` データ型間でのオーバーロードを許可しないため、`UTL_RAW` システムパッケージは不可欠です。

`UTL_RAW` はデータベース環境でのみ使用されるわけではないため、このシステムパッケージには `DBMS` ではなくプレフィックス `UTL` が付けられています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## UTL_RAWの使用方法

`UTL_RAW`は、複数の要素で構成される`RAW`「レコード」を許可します。`RAW`データ型を使用することで、文字セット変換が実行されず、リモート呼び出し時に`RAW`の元の形式が維持されます。

| [CAST_FROM_BINARY_DOUBLE](../27000.utl-raw-oracle/600.cast-from-binary-double-oracle.md) | `BINARY_DOUBLE` 値を `RAW` のバイナリ形式で返します。 |

| [CAST_TO_BINARY_FLOAT](../27000.utl-raw-oracle/1100.cast-to-binary-float-oracle.md)      | `RAW` バイナリ形式で表される `BINARY_FLOAT` 値を `BINARY_FLOAT` に変換します。    |
