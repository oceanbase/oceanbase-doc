# COPIES

`COPIES`関数は、連結されたn個の`r`のコピーを返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.COPIES (
     r IN RAW,
     n IN NUMBER)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |       **説明**       |
|--------|--------------------|
| r      | コピー対象の `RAW`。         |
| n      | `RAW` のコピー回数（正の数でなければなりません）。 |

## 戻り値

n回コピーされた`RAW`を返します。

## 例外

|   **例外**    |        **説明**      |
|-------------|------------------------|
| VALUE_ERROR | 以下の状況が発生する可能性があります： <ul><li> rが失われたり、`NULL`であったり、長さが0であったりします。</li>   <li> n \< 1。</li>   <li> 結果の長さがRAWの最大長を超えています。</li></ul>    |
