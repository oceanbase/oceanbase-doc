# BIT_XOR

`BIT_XOR`関数は、`RAW r1`と`RAW r2`の値に対してビット単位の論理「排他的論理和」演算を実行し、排他的論理和の結果`RAW`返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.BIT_XOR (
    r1 IN RAW,
    r2 IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |         **説明**          |
|--------|-------------------------|
| r1     | `r2` と「排他的論理和」演算を行うRAW値。 |
| r2     | `r1` と「排他的論理和」演算を行うRAW値。 |

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
| RAW     | `r1`と`r2`に含まれる「排他的論理和」です。     |

## 使用方法

`r1`と`r2`の長さが異なる場合、「排他的論理和」演算は短い`RAW`の最後のバイトで終了し、長い`RAW`の未処理部分は部分結果に追加されます。結果の長さは、2つの入力`RAW`のうち長い方と同じになります。
