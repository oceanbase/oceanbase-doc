# BIT_COMPLEMENT

`BIT_COMPLEMENT`関数は、`RAW r`の値に対してビット単位の論理「補数」を実行し、補数結果`RAW`を返します。結果の長さは入力された`RAW r`の長さと同じです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.BIT_COMPLEMENT (
   r IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |    **説明**     |
|--------|---------------|
| r      | RAWに対して「補数」演算を実行します。 |

## 戻り値

| **戻り値** |    **説明**      |
|---------|------------------|
| RAW     | `r`の「補数」です。       |
