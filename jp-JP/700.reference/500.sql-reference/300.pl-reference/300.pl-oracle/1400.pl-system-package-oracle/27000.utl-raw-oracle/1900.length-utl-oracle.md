# LENGTH

`LENGTH`関数は、`RAW r`のバイト長を返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.LENGTH (
     r  IN RAW)
RETURN NUMBER;
```

## パラメータの説明

| **パラメータ** |    **説明**     |
|--------|---------------|
| r      | バイト長を測定する`RAW`。 |

## 戻り値

| **戻り値** |  **説明**   |
|---------|-----------|
| NUMBER  | `RAW`の現在の長さ |
