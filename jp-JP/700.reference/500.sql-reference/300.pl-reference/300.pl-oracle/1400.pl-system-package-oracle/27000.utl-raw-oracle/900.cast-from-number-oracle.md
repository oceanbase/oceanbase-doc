# CAST_FROM_NUMBER

`CAST_FROM_NUMBER`関数は、`RAW`のバイナリ形式で`NUMBER`値を返すために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>NUMBER</code>型について、OceanBaseデータベースとOracleの実装方法は異なり、返される<code>RAW</code>はOceanBaseデータベース内部で表現される<code>NUMBER</code>形式です。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
UTL_RAW.CAST_FROM_NUMBER (
   n  IN NUMBER)
 RETURN RAW;
```

## パラメータの説明

パラメータ`n`は`NUMBER`値です。

## 戻り値

`NUMBER`値のバイナリ表現（RAW）を返します。

## 例

```sql
obclient> SELECT UTL_RAW.CAST_FROM_NUMBER(123.456) FROM DUAL;
+-----------------------------------+
| UTL_RAW.CAST_FROM_NUMBER(123.456) |
+-----------------------------------+
| 020000C07B00000000022E1B          |
+-----------------------------------+
1 row in set

obclient> SELECT UTL_RAW.CAST_FROM_NUMBER(-123.456) FROM DUAL;
+------------------------------------+
| UTL_RAW.CAST_FROM_NUMBER(-123.456) |
+------------------------------------+
| 020000407B00000000022E1B           |
+------------------------------------+
1 row in set
```
