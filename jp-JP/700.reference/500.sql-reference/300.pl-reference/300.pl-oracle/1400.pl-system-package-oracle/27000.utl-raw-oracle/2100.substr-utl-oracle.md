# SUBSTR

`SUBSTR`関数は、`raw r`の`pos`ビットから計算して`len`バイトを返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.SUBSTR (
   r   IN RAW,
   pos IN BINARY_INTEGER,
   len IN BINARY_INTEGER DEFAULT NULL)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |                  **説明**                  |
|--------|------------------------------------------|
| r      | RAWから抽出される部分バイトの文字列。                   |
| pos    | `r`からバイトを抽出する開始位置。                          |
| len    | `r`から抽出されるバイト数。`RAW r`の`pos`ビットから計算します（オプション）。 |

## デフォルト値とオプションパラメータ

| **オプションパラメータ** |        **説明**        |
|----------|----------------------|
| len      | `pos`から`r`の末尾までの長さ。 |

## 戻り値

|   **戻り値**    |           **説明**            |
|--------------|-----------------------------|
| portion of r | `pos` ビットから計算して、長さが `len` バイトの部分を返します。 |
| NULL         | `r` の入力パラメータが `NULL` の場合。            |

## 使用方法

* `pos`が正の場合、`SUBSTR`は`r`の先頭からカウントして最初のバイトを見つけます。`pos`が負の場合、SUBSTRは`r`の末尾から逆算します。`pos`の値は0にすることはできません。

* `len`が省略されている場合、`SUBSTR`は`r`の末尾までのすべてのバイトを返します。`len`の値は1未満にすることはできません。

## 例外

|   **例外**   |        **説明**           |
|-------------|-----------------------------|
| VALUE_ERROR | 以下の場合に`VALUE_ERROR`が返される可能性があります： <ul><li> `pos`が0または`r`の長さより大きい場合 </li> <li> `len`が1未満または`r - (pos - 1)`の値より大きい場合。</li></ul>    |
