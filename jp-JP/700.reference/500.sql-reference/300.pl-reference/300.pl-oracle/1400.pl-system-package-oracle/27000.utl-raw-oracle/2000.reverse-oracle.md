# REVERSE

`REVERSE`関数は、`RAW r`のバイトシーケンスを先頭から末尾まで逆にするために使用されます。

たとえば、'nba'は'abn'に逆転されます。結果の長さは`RAW`の入力長と同じです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.REVERSE (
     r IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |  **説明**   |
|--------|-----------|
| r      | 逆転する`RAW`。 |

## 戻り値

| **戻り値** |     **説明**     |
|---------|----------------|
| RAW     | `r`の「逆」値を含みます。 |

## 例外

|   **例外**    |       **説明**        |
|-------------|---------------------|
| VALUE_ERROR | `r`が`NULL`または長さが0です。 |
