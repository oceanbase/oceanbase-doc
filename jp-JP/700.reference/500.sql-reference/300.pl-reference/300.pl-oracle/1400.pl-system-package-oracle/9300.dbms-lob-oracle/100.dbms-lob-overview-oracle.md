# DBMS_LOBの概要

`DBMS_LOB`システムパッケージは、`BLOB`および`CLOB`を読み取り、変更するために使用され、ほとんどの`LOB`操作を提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_LOB権限の説明

このシステムパッケージは、`SYS` データベース内に作成する必要があります。ただし、このシステムパッケージで提供される操作は、`SYS` データベースではなく、現在の呼び出しユーザーの権限で実行されます。

匿名PLブロックから呼び出されるすべての `DBMS_LOB` サブルーチンは、現在のユーザー権限を使用して実行されます。ストアドサブルーチンから呼び出されるすべての `DBMS_LOB` サブルーチンは、ストアドサブルーチンの所有者権限を使用して実行されます。

サブルーチンを作成する際、ユーザーは `AUTHID` を設定して、定義者の権限と呼び出し者の権限のどちらを使用するかを指定できます。例：

```sql
CREATE PROCEDURE proc1 AUTHID DEFINER ...
```

または

```sql
CREATE PROCEDURE proc1 AUTHID CURRENT_USER ...
```

## DBMS_LOBで使用されるデータ型

| **データ型** |               **説明**                |
|----------|-------------------------------------|
| BLOB     | ソースまたはターゲットのバイナリ `LOB`。                      |
| RAW      | ソースまたはターゲットの `RAW` バッファー（`BLOB` と一緒に使用）。      |
| CLOB     | ソースまたはターゲットの文字列 `LOB`。                       |
| VARCHAR2 | ソースまたはターゲットの文字列バッファー（`CLOB` と一緒に使用）。           |
| INTEGER  | 指定されたバッファーまたは `LOB` のサイズ、`LOB` のオフセット、またはアクセスする数。 |

## DBMS_LOBの使用方法

すべての `DBMS_LOB` サブルーチンは `LOB` ロケーターに基づいて動作します。`DBMS_LOB` サブルーチンの操作を正常に完了するためには、データベースのテーブル領域または外部ファイルシステムに既に存在する `LOB` を表す入力ロケーターを提供する必要があります。

すべての `DBMS_LOB` API は、リモート `LOB` ロケーターに対する操作をサポートします。2つのロケーターを使用するAPIは、2つの `LOB` を同一のデータベース内に配置する必要があります。

## DBMS_LOBサブルーチンの概要

次の表は、OceanBaseデータベースの現行バージョンでサポートされているDBMS_LOBサブルーチンとその簡潔な説明を示しています。

|                            **サブルーチン**                             |                  **説明**                  |
|----------------------------------------------------------------|------------------------------------------|
| [APPEND](../9300.dbms-lob-oracle/200.append-oracle.md)          | ソース `LOB` の内容をターゲット `LOB` に追加します。                 |
| [CLOSE](../9300.dbms-lob-oracle/300.close-oracle.md)           | 以前に開いた内部または外部の `LOB` を閉じます。                      |
| [COPY](../9300.dbms-lob-oracle/500.copy-oracle.md)            | ソース内部 `LOB` の全部または一部をターゲット内部 `LOB` にコピーします。         |
| [CREATETEMPORARY](../9300.dbms-lob-oracle/600.createtemporary-oracle.md) | デフォルトの一時テーブルスペースに一時 `BLOB` または `CLOB` および対応するインデックスを作成します。 |
| [ERASE](../9300.dbms-lob-oracle/700.eraese-oracle.md)           | 全部または一部の `LOB` を消去します。                           |
| [FREETEMPORARY](../9300.dbms-lob-oracle/800.freetemporary-oracle.md)   | デフォルトの一時テーブルスペース内の一時 `BLOB` または `CLOB` を解放します。          |
| [GETLENGTH](../9300.dbms-lob-oracle/900.getlength-oracle.md)       | `LOB` 値の長さを取得します。                           |
| [ISOPEN](../9300.dbms-lob-oracle/1000.isopen-oracle.md)          | 入力ロケーターを使用して `LOB` が既に開かれているかどうかを確認します。                  |
| [INSTR](../9300.dbms-lob-oracle/1100.instr-oracle.md)           | `LOB` モードで `n` 番目にマッチした位置を返します。              |
| [ISTEMPORARY](1150.istemporary-of-oracle-mode.md)| ロケーターが一時LOBを指しているかどうかを確認します。|
| [OPEN](../9300.dbms-lob-oracle/1200.open-oracle.md)            | 指定されたモードで `LOB` (内部、外部、または一時) を開きます。               |
| [READ](../9300.dbms-lob-oracle/1300.read-oracle.md)            | 指定されたオフセットから `LOB` のデータを読み取ります。                    |
| [SUBSTR](../9300.dbms-lob-oracle/1400.substr-oracle.md)          | 指定されたオフセットから一部の `LOB` 値を返します。                   |
| [TRIM](../9300.dbms-lob-oracle/1500.trim-oracle.md)            | `LOB` 値を指定された短い長さにトリムします。                     |
| [WRITE](../9300.dbms-lob-oracle/1600.write-oracle.md)           | 指定されたオフセットからデータを `LOB` に書き込みます。                    |
| [WRITEAPPEND](../9300.dbms-lob-oracle/1700.writeappend-oracle.md)     | バッファを `LOB` の末尾に書き込みます。                        |
