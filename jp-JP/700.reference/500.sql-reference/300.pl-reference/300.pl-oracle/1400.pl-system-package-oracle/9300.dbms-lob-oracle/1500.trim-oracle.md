# TRIM

`TRIM` ステートメントは、内部 `LOB` 値を `newlen` パラメータで指定された長さにトリムします。

`TRIM` ステートメントは、`BLOB` にバイト単位の長さを指定し、`CLOB` に文字単位の長さを指定します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>TRIM</code> ステートメントは、<code>LOB</code> の長さを <code>newlen</code> パラメータで指定された値に短縮します。</p>
  </main>

空の `LOB` に対して `TRIM` を実行しようとすると、結果はなく、`TRIM` はエラーを返しません。`newlen` で新しく指定された長さが `LOB` のサイズを超える場合、例外が発生します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.TRIM (
lob_loc        IN OUT  NOCOPY BLOB,
newlen         IN             INTEGER);

DBMS_LOB.TRIM (
lob_loc        IN OUT  NOCOPY CLOB CHARACTER SET ANY_CS,
newlen         IN             INTEGER);
```

## パラメータの説明

| **パラメータ** | **説明** |
|---------|---------------------------------------------------------------------------------------|
| lob_loc | 内部 `LOB` のロケーターであり、その長さを調整します。詳細については、[DBMS_LOB使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。 |
| newlen | トリミング後の新しい `LOB` の長さ値（`BLOB` の場合はバイト、`CLOB` の場合は文字）。                                      |

## 異常時の対応

|      **例外**       |                                                                              **説明**                                                                              |
|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VALUE_ERROR       | `lob_loc` の値が `NULL` です。                                                                                                                                             |
| INVALID_ARGVAL    | 次のいずれかの状況が考えられます： <ul><li> `new_len` の値が 0 より小さい   </li><li> `new_len` が `LOBMAXSIZE` より大きい </li></ul>   |
| QUERY_WRITE       | クエリまたはPDMLパラレル実行サーバー内で `LOB` 書き込みを実行できません。                                                                                                                                 |
| BUFFERING_ENABLED | `LOB` にバッファリングが有効になっている場合、`LOB` バッファリングを有効にした状態で操作を実行することはできません。                                                                                                                        |

## 使用方法

* `LOB` 操作をOpen/Closeインターフェースでラップすることは必須ではありません。操作実行前に `LOB` を開いていない場合、呼び出しの過程で `LOB` 列上の機能インデックスとドメインインデックスが更新されます。操作実行前に `LOB` を開いている場合は、トランザクションをコミットする前に閉じる必要があります。内部 `LOB` を閉じる際に、`LOB` 列上の機能インデックスとドメインインデックスが更新されます。

* `LOB` 操作をOpen/Close API内でラップしない場合、`LOB` への書き込みごとに機能インデックスとドメインインデックスが更新されます。パフォーマンスへの悪影響を避けるため、`LOB` への書き込み操作は `OPEN` または `CLOSE` ステートメント内に含めることを推奨します。

* 必要に応じて、指定された新しい長さが0でない限り、`TRIM` は `LOB` の長さを変更する前に `LOB` を取得します。
