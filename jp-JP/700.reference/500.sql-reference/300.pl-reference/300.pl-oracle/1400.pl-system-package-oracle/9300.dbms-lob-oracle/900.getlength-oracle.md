# GETLENGTH

`GETLENGTH`関数は、指定された`LOB`の長さを取得するために使用されます。返される長さはバイトまたは文字単位です。

長さのカウントには、以前の`WRITE`などの操作によって生成された`LOB`内の0バイトまたはスペースも含まれます。空の内部`LOB`の長さは0です。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.GETLENGTH (
lob_loc              IN BLOB
)
RETURN NUMBER;

DBMS_LOB.GETLENGTH (
lob_loc              IN CLOB CHARACTER SET ANY_CS
)
RETURN NUMBER;
```

## パラメータの説明

| **パラメータ**  |                                  **説明**                                  |
|---------|--------------------------------------------------------------------------|
| lob_loc | `LOB`のロケーター。詳細については、[DBMS_LOB使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)参照してください。 |

## 戻り値

`LOB`の長さ（バイトまたは文字）は整数（`INTEGER`）です。入力`LOB`が`NULL`であるか、入力`lob_loc`が`NULL`の場合、`NULL`返します。

## 例外

|      **例外**       |                  **説明**                   |
|-------------------|-------------------------------------------|
| BUFFERING_ENABLED | `LOB`上でバッファリングが有効になっている場合、`LOB`バッファリングが有効な状態で操作を実行することはできません。 |
