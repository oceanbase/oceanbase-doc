# CREATETEMPORARY

`CREATETEMPORARY` ステートメントは、デフォルトの一時テーブルスペースに一時的な `BLOB` または `CLOB` および対応するインデックスを作成します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_LOB.CREATETEMPORARY (
lob_loc IN OUT NOCOPY BLOB,
cache   IN            BOOLEAN,
dur     IN            PLS_INTEGER := 10);

DBMS_LOB.CREATETEMPORARY (
lob_loc IN OUT NOCOPY CLOB CHARACTER SET ANY_CS,
cache   IN            BOOLEAN,
dur     IN            PLS_INTEGER := 10);
```

## パラメータの説明

|   パラメータ    |                                             説明                                             |
|---------|--------------------------------------------------------------------------------------------|
| lob_loc | `LOB` のロケーター。詳細については、[DBMS_LOBの使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。                   |
| cache   | `LOB` をバッファキャッシュに読み込むかどうかを指定します。                                                                      |
| dur     | 2つの事前定義された持続時間値（`SESSION`または`CALL`）のいずれかを使用して、セッションまたはコール終了時に一時的な`LOB`のヒントをクリアするかどうかを指定します。`dur`が省略された場合は、セッションの持続時間が使用されます。 |
