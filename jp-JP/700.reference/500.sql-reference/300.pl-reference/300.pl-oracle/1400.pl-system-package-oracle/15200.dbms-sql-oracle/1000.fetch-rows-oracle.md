# FETCH_ROWS

`FETCH_ROWS`関数は、指定されたカーソルから1行のデータを取得するために使用されます。

`FETCH_ROWS`は、すべての行が抽出されるまで繰り返し呼び出すことができます。これらの行データはバッファに格納され、`FETCH_ROWS`を呼び出すたびに、各列に対して`COLUMN_VALUE`を呼び出して読み取る必要があります。

`FETCH_ROWS`関数は、取得するカーソルID番号を受け取り、実際に取得した行数を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SQL.FETCH_ROWS (c IN INTEGER)
RETURN INTEGER;
```

## パラメータの説明

| **パラメータ** | **説明** |
|--------|--------|
| c      | ID番号。  |

## 戻り値

指定されたカーソルから1行を返します。
