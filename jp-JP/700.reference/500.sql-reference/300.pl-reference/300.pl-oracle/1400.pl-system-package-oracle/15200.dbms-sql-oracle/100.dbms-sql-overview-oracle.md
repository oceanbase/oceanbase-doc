# DBMS_SQLの概要


`DBMS_SQL`システムパッケージは、動的ステートメントを実行するための仕組みを提供し、さまざまなステートメントをサポートしています：システムコマンド（例えば`ALTER SESSION`）、DDL、DML（`SELECT`を含む）などです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

使用上の注意点は以下のとおりです：

* パラメータを指定できるのはDMLステートメントのみです。

* DMLステートメントのうち、結果セットを返すステートメントのみ取得可能です。

* DMLステートメントは`dbms_sql.execute`などのインターフェースで実行され、その他のステートメントは`dbms_sql.parse`インターフェースで実行されます。

* `DBMS_SQL`で作成されたカーソルは現在のセッションでのみ利用可能であり、他のセッションからはアクセスできません。


## DBMS_SQL権限の説明

`DBMS_SQL`は`SYS`ユーザーが所有しており、`AUTHID CURRENT_USER`でコンパイルされたシステムパッケージです。匿名PLブロックから呼び出される任意の`DBMS_SQL`サブルーチンは、現在のユーザー権限で実行されます。

## DBMS_SQL定数

次の表は、`DBMS_SQL`の`PARSE`ストアドプロシージャの`language_flag`パラメータで使用される定数を示しています。


|   名前   |   タイプ    | 値 |    説明     |
|--------|---------|---|-----------|
| NATIVE | INTEGER | 1 | プログラムがデータベースに正常に接続されている |



## 使用方法

以下の使用方法は、クエリ、更新、挿入、削除の処理方法を説明しています。

動的SQLを使用してクエリを処理する場合は、次の手順を実行する必要があります：

1. `DEFINE_COLUMN`サブルーチンを呼び出して、`SELECT`ステートメントが返す値の変数を指定します。

2. `EXECUTE`関数を呼び出して`SELECT`ステートメントを実行します。

3. `FETCH_ROWS`関数を呼び出して、クエリに一致する行を取得します。

4. `COLUMN_VALUE`サブルーチンを呼び出して、`FETCH_ROWS`関数が返すクエリ検索の列値を決定します。


動的SQLを使用して`INSERT`、`UPDATE`、または`DELETE`を処理する場合は、`EXECUTE`関数を呼び出して`INSERT`、`UPDATE`、または`DELETE`ステートメントを実行する必要があります。

## DBMS_SQLの実行プロセス

`DBMS_SQL`の実行プロセスは次のとおりです：

1. `OPEN_CURSOR`

2. `PARSE`

3. `BIND_VARIABLE`

4. `DEFINE_COLUMN`、`DEFINE_COLUMN_LONG`、または`DEFINE_ARRAY`

5. `EXECUTE`

6. `FETCH_ROWS`または`EXECUTE_AND FETCH`

7. `COLUMN_VALUE`

8. `CLOSE_CURSOR`


## DBMS_SQLサブルーチンの概要

以下の表は、OceanBaseデータベースの現行バージョンでサポートされている`DBMS_SQL`サブルーチンとその簡潔な説明を示しています。


|                             **サブルーチン**                              |             **説明**              |
|------------------------------------------------------------------|---------------------------------|
| [BIND_VARIABLE](../15200.dbms-sql-oracle/200.bind-variable-oracle.md)     | 指定された値を指定された変数にバインドします。                    |
| [COLUMN_VALUE](../15200.dbms-sql-oracle/400.column-value-oracle.md)      | カーソル内の指定された要素の値を返します。                    |
| [CLOSE_CURSOR](../15200.dbms-sql-oracle/300.close-cursor-oracle.md)      | 指定されたカーソルを閉じてメモリを解放します。                   |
| [DEFINE_COLUMN](../15200.dbms-sql-oracle/500.define-column-oracle.md)     | 指定されたカーソルで選択される列を定義します。`SELECT` ステートメントでのみ使用されます。   |
| [DEFINE_ARRAY](../15200.dbms-sql-oracle/600.define-array-oracle.md)      | 指定されたカーソルから選択するコレクションを定義します。`SELECT` ステートメントでのみ使用されます。 |
| [DESCRIBE_COLUMNS](../15200.dbms-sql-oracle/700.describe-columns-oracle.md)  | カーソルのすべてのフィールド名、型などのプロパティを取得します。              |
| [EXECUTE](../15200.dbms-sql-oracle/800.execute-oracle.md)           | 指定されたカーソルを実行します。                        |
| [EXECUTE_AND FETCH](../15200.dbms-sql-oracle/900.execute-and-fetch-oracle.md) | 指定されたカーソルを実行して行を取得します。                    |
| [FETCH_ROWS](../15200.dbms-sql-oracle/1000.fetch-rows-oracle.md)        | 指定されたカーソルから特定の行データを取得します。                   |
| [IS_OPEN](../15200.dbms-sql-oracle/1100.is-open-oracle.md)           | 指定されたカーソルのステータスが `OPEN` の場合、`TRUE` を返します。 |
| [LAST_ERROR_POSITION](../15200.dbms-sql-oracle/1200.last-error-position-of-oracle-mode.md)| 最後に `DBMS_SQL.PARSE` を呼び出した際の構文エラーの位置を取得します。|
| [OPEN_CURSOR](../15200.dbms-sql-oracle/1500.open-cursor-oracle.md)       | 新しいカーソルのIDを返します。                      |
| [PARSE](../15200.dbms-sql-oracle/2000.parse-oracle.md)             | 指定されたステートメントを解析します。                        |
| [VARIABLE_VALUE](../15200.dbms-sql-oracle/2100.variable-value-oracle.md) |動的SQLステートメントの実行後、出力変数の値を取得するために使用されます。|
