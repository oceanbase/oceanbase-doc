# EXECUTE

`EXECUTE`関数は、指定されたカーソルを実行するために使用されます。この関数はカーソルのID番号を受け取り、処理された行数を返します。

この戻り値はINSERT、UPDATE、DELETEステートメントに対してのみ有効です。DDLを含む他のタイプのステートメントについては、戻り値は不確定であり、無視する必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SQL.EXECUTE(cursor_id   IN INTEGER)
RETURN INTEGER;
```

## パラメータの説明

|  **パラメータ**   |    **説明**     |
|-----------|---------------|
| cursor_id | 実行するカーソルのID番号。 |

## 戻り値

処理された行数を返します。
