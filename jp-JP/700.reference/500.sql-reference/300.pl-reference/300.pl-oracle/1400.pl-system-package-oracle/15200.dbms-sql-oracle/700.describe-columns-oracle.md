# DESCRIBE_COLUMNS

`DESCRIBE_COLUMNS` ステートメントは、カーソルのすべてのフィールド名と型などのプロパティを取得するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SQL.DESCRIBE_COLUMNS (
    c              IN  INTEGER,
    col_cnt        OUT INTEGER,
    desc_t         OUT DESC_TAB);

DBMS_SQL.DESCRIBE_COLUMNS (
    c              IN  INTEGER,
    col_cnt        OUT INTEGER,
    desc_t         OUT DESC_TAB2);

DBMS_SQL.DESCRIBE_COLUMNS (
    c              IN  INTEGER,
    col_cnt        OUT INTEGER,
    desc_t         OUT DESC_TAB3);
```

## パラメータの説明

|   パラメータ    |    説明     |
|---------|-----------|
| c       | カーソルID。    |
| col_cnt | クエリで選択された列数。 |
| desc_t  | テーブルの各列を説明します。  |
