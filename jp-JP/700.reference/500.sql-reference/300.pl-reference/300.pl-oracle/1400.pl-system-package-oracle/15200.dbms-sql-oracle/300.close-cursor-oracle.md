# CLOSE_CURSOR

`CLOSE_CURSOR` ステートメントは、指定されたカーソルを閉じるために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SQL.CLOSE_CURSOR(cursor_id    IN INTEGER);
```

## パラメータ

|  **パラメータ**   |    **説明**    |
|-----------|--------------|
| cursor_id | 閉じるカーソルのID番号。 |
