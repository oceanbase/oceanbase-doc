# PARALLEL_SLAVE

`PARALLEL_SLAVE`は、<code>recomp_parallel</code>プロセス内で実際のコンパイル作業を実行するためのプライベートサブルーチンです。通常、ユーザーが直接呼び出すことは推奨されません。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RECOMP.PARALLEL_SLAVE(
    flags IN BINARY_INTEGER
);
```

## パラメータの説明

|                       パラメータ            |                説明                       |
|--------------------------------------------|---------------------------------------------------|
|flags|同名のテーブルが存在する場合に有効になります。値512は、SYSテナント内に同名のテーブルが既に存在する場合、そのテーブルを直接使用することを意味し、1024は同名のテーブルが既に存在する場合、DROPして自動的に再作成することを意味します。デフォルト値は0（省略可能）であり、特別な意味はありません。|
