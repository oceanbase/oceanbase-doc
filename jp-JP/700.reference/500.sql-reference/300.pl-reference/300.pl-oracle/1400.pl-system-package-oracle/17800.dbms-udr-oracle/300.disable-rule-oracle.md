# DISABLE_RULE

`DISABLE_RULE`プロシージャは、カスタムルールを無効にし、カスタムルールを無効化するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
PROCEDURE DISABLE_RULE (
    rule_name          VARCHAR(256));
```

## パラメータの説明

| パラメータ名 | 説明 |
| --- | --- |
| rule_name | ルール名。 |

## 例

```shell
obclient> CALL DBMS_UDR.DISABLE_RULE('rule1');
Query OK, 0 rows affected

obclient> SELECT 1 FROM DUAL;
+---+
| 1 |
+---+
| 1 |
+---+
1 row in set
```
