# DROP_PURGE_JOB

`DROP_PURGE_JOB` プロシージャは、`CREATE_PURGE_JOB` プロシージャを使用して作成されたクリーンアップジョブを削除するために使用されます。クリーンアップジョブの名前はパラメータとして渡されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_AUDIT_MGMT.DROP_PURGE_JOB(
audit_trail_purge_name    IN VARCHAR2) ;
```

## パラメータの説明

`audit_trail_purge_name` は、削除対象のクリーンアップジョブの名前を指定します。これは、`CREATE_PURGE_JOB` プロシージャで指定されたクリーンアップジョブの名前です。

## 例

次の例では、`DROP_PURGE_JOB` プロシージャを呼び出して、`MYCLEANUP` という名前のクリーンアップジョブを削除します。

```sql
BEGIN
  DBMS_AUDIT_MGMT.DROP_PURGE_JOB(
     AUDIT_TRAIL_PURGE_NAME  => 'MyCLEANUP');
END;
```
