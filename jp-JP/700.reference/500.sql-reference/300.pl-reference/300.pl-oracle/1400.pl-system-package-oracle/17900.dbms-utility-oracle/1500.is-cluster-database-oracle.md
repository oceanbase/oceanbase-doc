# IS_CLUSTER_DATABASE

`IS_CLUSTER_DATABASE`関数は、データベースがクラスタデータベースモードで実行されているかどうかを判断するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.IS_CLUSTER_DATABASE
RETURN BOOLEAN;
```

## 戻り値

このインスタンスがクラスタデータベースモードで起動されている場合、この関数は`TRUE`返します。そうでない場合は`FALSE`返します。
