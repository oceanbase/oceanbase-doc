# CURRENT_INSTANCE

`CURRENT_INSTANCE`関数は、現在接続しているインスタンスの番号を返します。接続しているインスタンスが閉じられた場合、`NULL`返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.CURRENT_INSTANCE
RETURN NUMBER;
```
