# FORMAT_ERROR_BACKTRACE

`FORMAT_ERROR_BACKTRACE`関数は、例外を引き起こした呼び出しスタックのバックトレースをフォーマットするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.FORMAT_ERROR_BACKTRACE
RETURN VARCHAR2;
```

## 戻り値

バックトレース文字列。現在エラーが処理されていない場合は`NULL`返します。
