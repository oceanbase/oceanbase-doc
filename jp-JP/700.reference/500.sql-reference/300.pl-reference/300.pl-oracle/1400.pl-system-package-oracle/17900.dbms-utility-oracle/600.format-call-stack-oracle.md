# FORMAT_CALL_STACK

`FORMAT_CALL_STACK`関数は、現在の呼び出しスタックをフォーマットするために使用されます。

`FORMAT_CALL_STACK`呼び出しスタックにアクセスするストアドプロシージャやトリガーに適用され、デバッグに使用できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.FORMAT_CALL_STACK
RETURN VARCHAR2;
```

## 戻り値

最大2000バイトまでの呼び出しスタックを返します。
