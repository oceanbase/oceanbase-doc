# GET_HASH_VALUE

`GET_HASH_VALUE`関数は、指定された文字列のハッシュ値を計算するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.GET_HASH_VALUE (
    name        VARCHAR2,
    base          NUMBER,
    hash_size   NUMBER)
  RETURN NUMBER;
```

## パラメータの説明

|    パラメータ     |      説明      |
|-----------|--------------|
| name      | ハッシュ計算を行う文字列。 |
| base      | 返されるハッシュ値の開始値。 |
| hash_size | 必要なハッシュテーブルのサイズ。    |

## 戻り値

入力文字列に基づくハッシュ値です。例えば、ハッシュ値が1000から3047の間にある文字列のハッシュ値を取得するには、基数として1000を使用し、`hash_size`値として2048を使用できます。`hash_size`パラメータ値には、2のべき乗を使用することを推奨します。
