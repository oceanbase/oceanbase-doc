# NAME_TOKENIZE

`NAME_TOKENIZE` ステートメントは、指定された名前を `a [. b [. c ]][@ dblink ]` にパーサーを使用して解析するために使用されます。

`NAME_TOKENIZE` はダブルクォーテーションマークを削除し、引用符がない場合は大文字に変換します。また、意味解析は行いません。欠損値は `NULL` のまま保持されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースの現行バージョンでは、<code>DBMS_UTILITY</code> システムパッケージはUTF16エンコーディングの文字セットを一時的にサポートしていません。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_UTILITY.NAME_TOKENIZE (
name          IN  VARCHAR2,
a             OUT VARCHAR2,
b             OUT VARCHAR2,
c             OUT VARCHAR2,
dblink        OUT VARCHAR2,
nextpos       OUT BINARY_INTEGER);
```

## パラメータの説明

|   パラメータ    |                   説明                   |
|---------|----------------------------------------|
| name    | 入力名。SQL識別子で構成されます（例：`adam.ob@dblink`）。 |
| a       | 出力名の最初のトークン。                            |
| b       | 出力名の2番目のトークン（該当する場合）。                      |
| c       | 出力名の3番目のトークン（該当する場合）。                      |
| dblink  | `dblink`の出力名。                       |
| nextpos | 入力名の解析後の次の位置。                         |
