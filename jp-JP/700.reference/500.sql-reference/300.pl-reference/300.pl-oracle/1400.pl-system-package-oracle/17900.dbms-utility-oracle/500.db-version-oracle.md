# DB_VERSION

`DB_VERSION`ストアドプロシージャは、データベースのバージョン情報を返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.DB_VERSION (
version           OUT VARCHAR2,
compatibility  OUT VARCHAR2);
```

## パラメータの説明

|      パラメータ       |                                       説明                                        |
|---------------|---------------------------------------------------------------------------------|
| version       | データベース内部ソフトウェアバージョンを表す文字列（例：2.3.0）。この文字列の長さは変動可能で、データベースのバージョンによって決まります。                 |
| compatibility | `init.ora` パラメータによって決定されるデータベースの互換性設定。`init.ora` ファイルでこのパラメータが指定されていない場合、`NULL` を返します。 |
