# GETEndianNESS

`GET_ENDIANNESS`関数は、データベースプラットフォームのバイトストレージ順序を取得するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.GET_ENDIANNESS
RETURN NUMBER;
```

## 戻り値

`NUMBER`型の値で、データベースプラットフォームのバイトストレージ順序を表します。1はリトルエンディアン、2はビッグエンディアンを表します。
