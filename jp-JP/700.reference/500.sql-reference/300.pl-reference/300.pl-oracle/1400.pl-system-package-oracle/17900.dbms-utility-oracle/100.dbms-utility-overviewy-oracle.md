# DBMS_UTILITYの概要

`DBMS_UTILITY`システムパッケージは、ユーティリティ関数を提供します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>OceanBaseデータベースの現行バージョンでは、<code>DBMS_UTILITY</code>システムパッケージはUTF16エンコーディングでのパラメータ渡しをサポートしていません。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## DBMS_UTILITYデータ構造

`DBMS_UTILITY`システムパッケージは、以下の`RECORD`型と`TABLE`型を定義しています。

```sql
/* RECORD型 */
TYPE INSTANCE_RECORD IS RECORD (
INST_NUMBER   NUMBER,
INST_NAME     VARCHAR2(60));

/* TABLE型 */
TYPE UNCL_ARRAY IS TABLE OF VARCHAR2(32767) INDEX BY BINARY_INTEGER;
TYPE NAME_ARRAY IS TABLE OF VARCHAR2(128) INDEX BY BINARY_INTEGER;
TYPE QUOTED_NAME_ARRAY IS TABLE OF VARCHAR2(130) INDEX BY BINARY_INTEGER;
TYPE LNAME_ARRAY IS TABLE OF VARCHAR2(4000) INDEX BY BINARY_INTEGER;
TYPE MAXNAME_ARRAY IS TABLE OF VARCHAR2(32767) INDEX BY BINARY_INTEGER;
TYPE DBLINK_ARRAY IS TABLE OF VARCHAR2(128) INDEX BY BINARY_INTEGER;
TYPE INDEX_TABLE_TYPE IS TABLE OF BINARY_INTEGER INDEX BY BINARY_INTEGER;
TYPE NUMBER_ARRAY IS TABLE OF NUMBER INDEX BY BINARY_INTEGER;

TYPE INSTANCE_TABLE IS TABLE OF INSTANCE_RECORD INDEX BY BINARY_INTEGER;
```
