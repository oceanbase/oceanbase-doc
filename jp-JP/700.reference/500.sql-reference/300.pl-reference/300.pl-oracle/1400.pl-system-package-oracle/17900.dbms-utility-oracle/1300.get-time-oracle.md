# GET_TIME

`GET_TIME`関数は、現在の時間を100分の1秒（つまり0.01秒）単位で返すために使用されます。

`GET_TIME`関数は主に経過時間を決定するために使用されます。サブルーチンは、あるプロセスの開始時と終了時にそれぞれ2回呼び出され、その後、2番目（後方）の数値から1番目（前方）の数値を引くことで経過時間が決定されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.GET_TIME
RETURN NUMBER;
```

## 戻り値

時間はサブルーチンが呼び出された時点から、100分の1秒（つまり0.01秒）単位で計算されます。

## 使用方法

戻り値の範囲は-2147483648から2147483647までの数値であり、アプリケーションは間隔を決定する際に数値の符号を考慮する必要があります。例えば、2つの負の数の場合、アプリケーションのロジックでは、最初の（より早い）数値がゼロに近い2番目の（より遅い）数値よりも大きいことを許可しなければなりません。同様に、アプリケーションは最初の（より早い）数値が負の数で、2番目の（より遅い）数値が正の数であることも許可する必要があります。
