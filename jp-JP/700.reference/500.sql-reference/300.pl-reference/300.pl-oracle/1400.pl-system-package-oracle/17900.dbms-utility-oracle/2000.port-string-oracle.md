# PORT_STRING

`PORT_STRING`関数は、OSとデータベースの`TWO TASK PROTOCOL`バージョンを識別するための文字列を返すために使用されます。

文字列の最大長はポート設定によって決まります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.PORT_STRING
RETURN VARCHAR2;
```
