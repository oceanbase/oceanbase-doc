# VALUE

`VALUE`関数は、0以上1未満で、小数点以下に38桁の数字（つまり38桁の精度）を持つランダムコードを取得するために使用されます。

または、OceanBaseのランダムコードxを取得できます。ここで、xは`low`値以上`high`値未満です。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.VALUE
  RETURN NUMBER;

DBMS_RANDOM.VALUE(
  low  IN  NUMBER,
  high IN  NUMBER)
RETURN NUMBER;
```

## パラメータの説明

| **パラメータ** |            **説明**             |
|--------|-------------------------------|
| low    | 範囲内で生成される最小のランダムコード。生成される数値はlow値と等しい場合があります。 |
| high   | 範囲内で生成される最大のランダムコード。生成される数値はhigh値より小さいです。  |

## 戻り値

| **戻り値** |      **説明**      |
|---------|------------------|
| NUMBER  | OceanBaseの番号を返します。 |
