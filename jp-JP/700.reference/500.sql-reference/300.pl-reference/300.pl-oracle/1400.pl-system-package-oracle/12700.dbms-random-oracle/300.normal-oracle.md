# NORMAL

`NORMAL`関数は、標準正規分布のランダムコードを返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.NORMAL
RETURN NUMBER;
```

## 戻り値

| **パラメータ** |  **説明**  |
|--------|----------|
| number | ランダムコードを返します。 |
