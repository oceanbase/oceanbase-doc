# RANDOM

`RANDOM` ステートメントは、ランダムな数値を生成するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.RANDOM
RETURN binary_integer;
```

## 戻り値

|    **戻り値**     |              **説明**              |
|----------------|----------------------------------|
| binary_integer | \[-2\^31、2\^31)の範囲内のランダムな整数を返します。 |

## 使用方法

このプロシージャは廃止されており、現行バージョンではサポートされていますが、使用は推奨されません。
