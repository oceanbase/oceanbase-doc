# PRINT_BACKTRACE

`PRINT_BACKTRACE`関数は、現在実行されているスタックのバックトレースリストを出力するために使用されます。この関数は、プログラムが実行中である場合にのみ呼び出す必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.PRINT_BACKTRACE (
listing IN OUT VARCHAR);
```

## パラメータの説明

| **パラメータ**  |     **説明**      |
|---------|-----------------|
| listing | 縦書きのフォーマット文字バッファ。 |
