# DETACH_SESSION

`DETACH_SESSION` ステートメントは、デバッグ対象のプログラムを停止するために使用されます。

このステートメントはいつでも呼び出すことができますが、対象セッションに対してデバッグセッションが切断されていることを通知したり、対象セッションの実行を終了したりすることはありません。そのため、対象セッションがスタンドアロン状態にならないよう注意する必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionでは、MySQLモードのみが提供されています。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DETACH_SESSION;
```
