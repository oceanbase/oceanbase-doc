# DISABLE_BREAKPOINT

`DISABLE_BREAKPOINT`関数は、既存のブレークポイントを非アクティブにしますが、元の場所に保持します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DISABLE_BREAKPOINT (
   breakpoint IN BINARY_INTEGER)
  RETURN BINARY_INTEGER;
```

## パラメータの説明

|   **パラメータ**   |           **説明**           |
|------------|----------------------------|
| breakpoint | `SET_BREAKPOINT`で取得したブレークポイント番号。 |

## 戻り値

|        **戻り値**        |   **説明**    |
|-----------------------|-------------|
| success               | 完了しました。       |
| error_no_such_breakpt | ブレークポイントが存在しません。     |
| error_idle_breakpt    | 使用されていないブレークポイントを無効にできません。 |
