# ENABLE_BREAKPOINT

`ENABLE_BREAKPOINT`関数は、以前に無効にしたブレークポイントを有効にするための逆無効化機能です。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.ENABLE_BREAKPOINT (
   breakpoint IN BINARY_INTEGER)
  RETURN BINARY_INTEGER;
```

## パラメータの説明

|   **パラメータ**   |           **説明**           |
|------------|----------------------------|
| breakpoint | `SET_BREAKPOINT`で取得したブレークポイント番号。 |

## 戻り値

|        **パラメータ**         |   **説明**    |
|-----------------------|-------------|
| success               | 完了しました。       |
| error_no_such_breakpt | ブレークポイントが存在しません。     |
| error_idle_breakpt    | 使用されていないブレークポイントを有効にできません。 |
