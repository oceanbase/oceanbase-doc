# GET_VALUES

`GET_VALUES`関数は、現在のスタックフレームのすべての変数情報を返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.GET_VALUES(
scalar_values OUT VARCHAR2)
RETURN binary_integer;
```

## パラメータの説明

|    **パラメータ**    | **説明** |
|--------------|--------|
| scalar_value | 値。     |
