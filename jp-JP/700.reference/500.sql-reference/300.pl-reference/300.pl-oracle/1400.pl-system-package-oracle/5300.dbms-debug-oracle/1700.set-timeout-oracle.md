# SET_TIMEOUT

`SET_TIMEOUT`関数は、タイムアウト時間を設定し、新しいタイムアウト値を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.SET_TIMEOUT (
   timeout BINARY_INTEGER)
  RETURN BINARY_INTEGER;
```

## パラメータの説明

| **パラメータ**  |       **説明**        |
|---------|---------------------|
| timeout | ターゲットセッションとデバッグセッション間の通信のタイムアウト時間。 |
