# SHOW_BREAKPOINTS

`SHOW_BREAKPOINTS` ステートメントは、現在のブレークポイントの一覧を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.SHOW_BREAKPOINTS (
listing    IN OUT VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|---------|------------------------------------------------------------------------------|
| listing | ブレークポイントのフォーマットバッファ（改行文字を含む）。ブレークポイントエントリのインデックステーブルです。ブレークポイント番号はテーブル内のインデックスで示されます。ブレークポイント番号は1から始まり、削除後に再利用可能です。 |
