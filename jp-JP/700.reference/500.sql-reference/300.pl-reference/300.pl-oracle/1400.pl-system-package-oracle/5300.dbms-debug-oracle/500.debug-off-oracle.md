# DEBUG_OFF

`DEBUG_OFF`ストアドプロシージャは、ターゲットセッションにデバッグを停止するよう通知します。この関数は、セッションが終了するまで呼び出す必要はありません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DEBUG_OFF;
```
