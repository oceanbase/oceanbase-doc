# ATTACH_SESSION

`ATTACH_SESSION` ステートメントは、デバッグセッションに対象プログラムを通知するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.ATTACH_SESSION (
debug_session_id  IN VARCHAR2,
diagnostics       IN BINARY_INTEGER := 0);
```

## パラメータの説明

|      **パラメータ**      |         **説明**          |
|------------------|-------------------------|
| debug_session_id | ターゲットセッションで初期化呼び出しを行うDebugID。 |
| diagnostics      | 非ゼロの場合、診断出力を生成します。1と等しい値はサポートされていません。      |
