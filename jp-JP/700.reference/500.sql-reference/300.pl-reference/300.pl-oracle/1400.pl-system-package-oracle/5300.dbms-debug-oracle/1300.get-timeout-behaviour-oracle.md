# GET_TIMEOUT_BEHAVIOUR

`GET_TIMEOUT_BEHAVIOUR`関数は、現在のタイムアウト動作を返します。この呼び出しは、ターゲットセッション内で行われます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.GET_TIMEOUT_BEHAVIOUR
RETURN BINARY_INTEGER;
```
