# GET_VALUE

`GET_VALUE`関数は、現在実行中のプログラムから値を取得するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.GET_VALUE (
   variable_name  IN  VARCHAR2,
   frame#         IN  BINARY_INTEGER,
   scalar_value   OUT VARCHAR2,
   format         IN  VARCHAR2 := NULL)
RETURN BINARY_INTEGER;
```

## パラメータの説明

|    **パラメータ**     |                             **説明**                              |
|---------------|-----------------------------------------------------------------|
| variable_name | 変数またはパラメータの名前。                                                       |
| frame#        | 所在するフレーム。0は現在のサブルーチンを表します。                                                 |
| scalar_value  | 値。                                                              |
| format        | 使用できる日付形式。<br>**説明**  現在のバージョンではこのパラメータはサポートされていません。 |

## 戻り値

|       **戻り値**        |            **説明**            |
|----------------------|------------------------------|
| success              | 完了しました。                        |
| error_bogus_frame    | このフレームは存在しません。                       |
| error_no_debug_info  | 入口ポイントにデバッグ情報がありません。                   |
| error_no_such_object | `frame#` 内に `variable_name` が存在しません。 |
| error_unknown_type   | デバッグ情報内の型情報を識別できません。              |
| error_nullvalue      | 値がNULLです。                     |
| error_indexed_table  | オブジェクトはテーブルですが、インデックスが提供されていません。                 |
