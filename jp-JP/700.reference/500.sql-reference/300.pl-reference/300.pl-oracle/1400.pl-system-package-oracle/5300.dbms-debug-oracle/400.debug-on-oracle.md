# DEBUG_ON

`DEBUG_ON`ストアドプロシージャは、デバッグモードで実行されるすべてのPLを対象セッションにマークするために使用されます。この操作は、デバッグの実行開始前に完了していなければなりません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DEBUG_ON (
no_client_side_plsql_engine BOOLEAN := TRUE,
immediate                   BOOLEAN := FALSE);
```

## パラメータの説明

|           **パラメータ**            |                    **説明**                    |
|-----------------------------|----------------------------------------------|
| no_client_side_plsql_engine | デバッグセッションがクライアントPLエンジンから実行される場合を除き、デフォルト値を保持する必要があります。              |
| immediate                   | 値が`TRUE`の場合、呼び出し中にインタプリタは通常モードからデバッグモードに即座に切り替わります。 |
