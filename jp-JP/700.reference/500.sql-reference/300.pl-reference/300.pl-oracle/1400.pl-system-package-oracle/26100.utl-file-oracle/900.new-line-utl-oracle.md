# NEW_LINE

`NEW_LINE`ストアドプロシージャは、ファイルに指定された数の改行文字を入力するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_FILE.NEW_LINE (
file      IN FILE_TYPE,
lines    IN BINARY_INTEGER := 1);
```

## パラメータの説明

| パラメータ | 説明 |
|-------|----------------------------------------|
| file | `FOPEN`または`FOPEN_NCHAR`呼び出しによって返されるアクティブなファイルハンドル。 |
| lines | ファイルに書き込む改行文字の数。                           |

## 異常時

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`
