# FCLOSE

`FCLOSE` ステートメントは、入力されたファイルハンドルに基づいてファイルを閉じるために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_FILE.FCLOSE (
file IN OUT FILE_TYPE);
```

## パラメータの説明

| パラメータ | 説明 |
|------|----------------------------------------|
| file | `FOPEN`または`FOPEN_NCHAR`呼び出しによって返されたアクティブなファイルハンドル。 |

## 使用方法

`FCLOSE`実行時にまだ書き込まれていないバッファデータがある場合、バッファデータはファイルに書き込もうとしますが、`WRITE_ERROR`例外がスローされる可能性があります。

```sql
WRITE_ERROR
INVALID_FILEHANDLE
```
