# PUT

`PUT` ステートメントは、入力パラメータのバッファ内の情報を指定されたファイルに書き込むために使用されます。

`PUT` 書き込みはキャッシュ領域にのみ書き込まれ、ファイルシステムには直接フラッシュされません。ユーザーは手動で `UTL_FILE.FFLUSH` を呼び出して完了させる必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT (
file         IN FILE_TYPE,
buffer       IN VARCHAR2);
```

## パラメータの説明

|   パラメータ   |                                      説明                                      |
|--------|------------------------------------------------------------------------------|
| file   | 書き込み先ファイルのファイルハンドル。このファイルは、`w`または`a`モードで開く必要があります。                                          |
| buffer | 書き込むデータを格納するための入力パラメータです。ユーザーがファイルを`w`モードで開いた場合、書き込みはファイルの現在のオフセット位置に行われます。`a`モードで開いた場合、書き込みはファイルの末尾に行われます。 |

## 異常時

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`

## 使用方法

`FOPEN` で最大バイト数が指定されていない場合、バッファのパラメータは最大32767バイトになります。デフォルト値は1024です。すべての連続する `PUT` の合計は32767を超えてはならず、中間のバッファリフレッシュは行われません。
