# PUT_LINE

`PUT_LINE` ステートメントは、指定された長さの文字をファイルに書き込み、改行するために使用されます。

`PUT_LINE` と `PUT` の機能は基本的に同じですが、データ書き込み後に改行文字が追加される点と、`autoflush` パラメータで書き込み後に直ちにファイルシステムに情報をフラッシュするかどうかを指定できる点が異なります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT_LINE (
file            IN  FILE_TYPE,
buffer          IN  VARCHAR2,
autoflush       IN  BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| file      | `FOPEN` の呼び出しによって返されるアクティブなファイルハンドル。  |
| buffer    | テキストバッファーで、ファイルに書き込む行を含みます。        |
| autoflush | TRUEの場合のみ、バッファデータをディスクに書き込みます。 |

## 異常ケース

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`

## 使用方法

* `FOPEN` で最大バイト数が指定されていない場合、バッファのパラメータは最大32767バイトになります。デフォルト値は1024です。すべての連続した `PUT` の合計は32767を超えてはならず、中間のバッファリングフラッシュはありません。

* ファイルをバイトモードで開くと、`INVALID_OPERATION` 例外が発生します。
