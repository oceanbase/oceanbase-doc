# FREMOVE

`F_REMOVE` ステートメントは、指定されたファイルを削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_FILE.FREMOVE (
location IN VARCHAR2,
filename IN VARCHAR2);
```

## パラメータの説明

|    パラメータ    |       説明        |
|----------|-----------------|
| location | ファイルのパス（大文字と小文字は区別されます）。 |
| filename | 削除するファイル名。      |

## 異常時

* `ACCESS_DENIED`

* `DELETE_FAILED`

* `INVALID_FILENAME`

* `INVALID_OPERATION`

* `INVALID_PATH`

## 使用方法

`F_REMOVE` ステートメントは、ファイルを削除する前に権限を検証しません。ただし、オペレーティングシステムはファイルとディレクトリの権限を検証します。
