# DIST_TXN_SYNC

このサブルーチンは、データベースインスタンスのいずれかに障害が発生した場合に、不確定トランザクションを同期するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_XA.DIST_TXN_SYNC;
```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースはこのプロシージャを互換性のためにのみサポートしており、実質的な操作はありません。</p>
  </main>
