# XA_GETLASTOER

以前のXA呼び出しが失敗した場合、XA_GETLASTOERは最後のOceanBaseデータベースエラーコードを取得します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_GETLASTOER
RETURN PLS_INTEGER;
```

## 戻り値

返り値は、最後のOceanBaseデータベースエラーコードです。
