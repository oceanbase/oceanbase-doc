# XA_FORGET

XA_FORGET関数は、リソースマネージャーRMに対し、コミットまたはロールバックされたトランザクション分岐を破棄するよう要求します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_FORGET (
   xid       IN  DBMS_XA_XID)
RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |                                  **説明**                                   |
|--------|---------------------------------------------------------------------------|
| xid    | [DBMS_XA_XIDオブジェクトタイプ](../18500.dbms-xa-oracle/300.the-type-of-the-dbms-xa-xid-object-oracle.md)を参照してください。 |

## 戻り値

[DBMS_XAの可能な定数返り値](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md)を参照してください。

返り値として、`XA_OK`、`XAER_RMERR`、`XAER_RMFAIL`、`XAER_NOTA`、`XAER_INVAL`、または`XAERPROTO`が返される可能性があります。
