# XA_ROLLBACK

XA_ROLLBACK関数は、リソースマネージャーRMにトランザクション分岐のロールバックを要求するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_ROLLBACK (
   xid       IN  DBMS_XA_XID)
 RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |                                **説明**                                |
|--------|----------------------------------------------------------------------|
| xid    | [DBMS_XA_XIDオブジェクトタイプ](../18500.dbms-xa-oracle/300.the-type-of-the-dbms-xa-xid-object-oracle.md)を参照してください。 |

## 戻り値

[DBMS_XAの可能な定数返り値](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md)を参照してください。

返り値として`XA_OK`、`XA_RB\*`、`XA_HEURHAZ`、`XA_HEURCOM`、`XA_HEURRB`または`XA_HEURMIX`が返される可能性があります。
