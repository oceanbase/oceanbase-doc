# XA_SETTIMEOUT

XA_SETTIMEOUT関数は、現在のセッションのトランザクションタイムアウト間隔（秒単位）を設定します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_SETTIMEOUT (
   seconds  IN  PLS_INTEGER)
RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ**  |                         **説明**                         |
|---------|--------------------------------------------------------|
| seconds | タイムアウト時間とは、システムが自動的にトランザクションを中止する前に、トランザクション分岐がセッションから切断される可能性がある最長時間（秒単位）を指します。 デフォルト値は60秒です。 |

## 戻り値

[DBMS_XAの可能な定数返り値](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md)を参照してください。

返される値は次のとおりです：`XA_OK`、`XAER_RMERR`、`XAER_RMFAIL`、または`XAER_INVAL`。

## 使用方法

タイムアウト値の設定が成功したことを示すのは、返り値が`XA_OK`の場合のみです。
