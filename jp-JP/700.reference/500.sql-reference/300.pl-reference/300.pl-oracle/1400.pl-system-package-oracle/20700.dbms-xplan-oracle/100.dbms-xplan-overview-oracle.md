# DBMS_XPLANの概要

`DBMS_XPLAN`システムパッケージは、ロジックプランの最適化追跡など、ロジックプラン管理に関連する機能を提供します。

  <main id="notice">
  <h4>適用対象</h4>
  <p>Community EditionはV4.2.5バージョンからこの機能をサポートしています。</p>
  </main>

## DBMS_XPLAN権限の説明

PL/SQL実行権限を持つユーザーはこの機能を使用できます。

## DBMS_XPLANサブルーチンの概要

以下の表は、OceanBaseデータベースの現行バージョンがサポートする`DBMS_XPLAN`サブルーチンとその簡潔な説明を示しています。

| サブルーチン | 説明 |
| --- | --- |
| [DISPLAY_ACTIVE_SESSION_PLAN](../20700.dbms-xplan-oracle/200.display-active-session-plan-of-oracle-mode.md) | 指定されたセッションのリアルタイム計画の詳細を表示します。 |
| [DISPLAY_CURSOR](../20700.dbms-xplan-oracle/300.display-cursor-of-oracle-mode.md) | 実行済みのクエリ計画の詳細を表示します。 |
| [DISPLAY](../20700.dbms-xplan-oracle/400.display-of-oracle-mode.md) | 過去の`EXPLAIN`計画を照会してフォーマットします。 |
| [DISABLE_OPT_TRACE](../20700.dbms-xplan-oracle/500.disable-opt-trace-oracle.md) | 現在のセッションのオプティマイザー全リンクトレース機能を無効にします。 |
| [DISPLAY_SQL_PLAN_BASELINE](../20700.dbms-xplan-oracle/600.display-sql-plan-baseline-of-oracle-mode.md) | SPMのベースライン計画を確認します。 |
| [ENABLE_OPT_TRACE](../20700.dbms-xplan-oracle/800.enable-opt-trace-oracle.md) | 現在のセッションのオプティマイザー全リンクトレースを有効にします。 |
| [SET_OPT_TRACE_PARAMETER](../20700.dbms-xplan-oracle/1000.set-opt-trace-parameter-oracle.md) | 現在のセッションのオプティマイザー全リンクトレースのパラメータを変更します。 |
