# DISPLAY_SQL_PLAN_BASELINE

`DISPLAY_SQL_PLAN_BASELINE`関数は、SPMのベースライン計画を表示するために使用されます。

  <main id="notice">
  <h4>適用対象</h4>
  <p>Community Editionでは、V4.2.5バージョンからこの機能がサポートされています。</p>
  </main>

## 構文

```sql
DBMS_XPLAN.DISPLAY_SQL_PLAN_BASELINE(
           sql_handle   VARCHAR2  DEFAULT  NULL,
           plan_name    VARCHAR2  DEFAULT  NULL,
           format       VARCHAR2  DEFAULT  'TYPICAL',
           svr_ip       VARCHAR2 DEFAULT null,   -- default value: server connected by client
           svr_port     INTEGER DEFAULT 0,     -- default value: server connected by client
           tenant_id    INTEGER DEFAULT 0     -- default value: current tenant)
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## パラメータの説明

| パラメータ | 説明 |
| --- | --- |
| sql_handle | Baseline計画のSQLハンドルであり、SPM関連ビューから取得可能です。 |
| plan_name | Baseline計画の名前。 |
| format | プランの形式情報を指定します。オプションパラメータは以下のとおりです：<ul><li>`'BASIC'`：演算子ID、演算子名、演算子の備考情報、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子の備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報など、基本情報を表示します。この計画が実行された場合、実際のフィードバック情報も表示されます。例えば、実際の行数やコストなどです。</li><li> `'ALL'`：演算子ID、演算子名、演算子の備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブルの最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富な計画情報を表示します。</li><li> `'ADVANCED'`：豊富な計画情報を表示します。計画情報は'ALL'パラメータと同じですが、さらに複雑な計画についてはツリー構造情報も表示されます。</li></ul>|
| svr_ip | プランが存在するノードのIPアドレスです。デフォルトはSession接続先のノードのIPアドレスです。|
| svr_port | プランが存在するノードのポート番号です。デフォルトはSession接続先のノードのポート番号です。|
| tenant_id | プランが属するテナントIDです。デフォルトはSessionが現在接続しているテナントです。|
