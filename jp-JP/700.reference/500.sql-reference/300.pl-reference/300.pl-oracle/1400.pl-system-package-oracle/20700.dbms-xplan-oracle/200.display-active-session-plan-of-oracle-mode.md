# DISPLAY_ACTIVE_SESSION_PLAN

`DISPLAY_ACTIVE_SESSION_PLAN`関数は、指定されたセッションのリアルタイム計画の詳細を表示するために使用されます。

  <main id="notice">
  <h4>適用対象</h4>
  <p>Community Editionでは、V4.2.5バージョンからこの機能がサポートされています。</p>
  </main>

## 関数定義

```sql
DBMS_XPLAN.DISPLAY_ACTIVE_SESSION_PLAN(
           session_id   INTEGER DEFAULT 0,
           format       VARCHAR2  DEFAULT  'TYPICAL',
           svr_ip       VARCHAR2  DEFAULT  NULL,      -- default value: server connected by client
           svr_port     INTEGER DEFAULT 0           -- default value: server connected by client
           )
return DISPLAY_ACTIVE_SESSION_PLAN;
```

## パラメータの説明

| パラメータ | 説明 |
| --- | --- |
| session_id | ユーザーが接続しているセッションのIDです。プロキシセッションIDではなく、サーバーのセッションIDです。 |
| format | プランの形式情報を指定します。オプションパラメータは以下のとおりです：<ul><li>`'BASIC'`：演算子ID、演算子名、演算子の備考情報、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子の備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報など、基本情報を表示します。このプランが実行されたことがある場合、実際のフィードバック情報も表示されます。例えば、実際の行数やコストなどです。</li><li> `'ALL'`：演算子ID、演算子名、演算子の備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブルの最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富なプラン情報を表示します。</li><li> `'ADVANCED'`：豊富なプラン情報を表示します。プラン情報は'ALL'パラメータと同じですが、さらに複雑なプランについてはツリー構造情報も表示されます。</li></ul> |
| svr_ip | プランが存在するノードのIPアドレスです。デフォルトはセッション接続ノードのIPアドレスです。|
| svr_port | プランが存在するノードのポート番号です。デフォルトはセッション接続ノードのポート番号です。|
