# SET_CLIENT_INFO

`SET_CLIENT_INFO` プロシージャは、クライアントアプリケーションの追加情報を設定するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_APPLICATION_INFO.SET_CLIENT_INFO (
client_info IN VARCHAR2);
```

## パラメータの説明

`client_info` パラメータは、クライアントアプリケーションに関する追加情報を格納します。この情報は `__all_virtual_processlist` テーブルに保存され、情報の長さが64バイトを超える場合は切り捨てられます。

## 例

```sql
DECLARE
    myclient VARCHAR2(100);
      ...
   BEGIN
      ...

      DBMS_APPLICATION_INFO.SET_CLIENT_INFO('myclient');
      DBMS_OUTPUT.PUT_LINE ('client='||myclient);
   END;
```
