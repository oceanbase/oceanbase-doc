# DBMS_APPLICATION_INFOの概要

`DBMS_APPLICATION_INFO`システムパッケージは、監査やパフォーマンス追跡を行うためにアプリケーション名をデータベースに登録するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_APPLICATION_INFO権限の説明

`DBMS_APPLICATION_INFO`システムパッケージを使用するには特別な権限は不要です。アプリケーションがデータベースに登録されると、その名前と操作は`GV$OB_PROCESSLIST`ビューに記録されます。

## サブルーチンの概要

次の表は、OceanBaseデータベースの現行バージョンでサポートされている`DBMS_APPLICATION_INFO`サブルーチンとその簡潔な説明を示しています。

|     サブルーチン     |       説明     |
|---------------|---------------|
| [READ_CLIENT_INFO](../1900.dbms-application-info-oracle/200.read-client-info-oracle.md)     | 現在のセッションのclient_infoフィールドの値を読み取ります。         |
| [READ_MODULE](../1900.dbms-application-info-oracle/300.read-module-oracle.md)               | 現在のセッションのモジュールと操作フィールドの値を読み取ります。          |
| [SET_ACTION](../1900.dbms-application-info-oracle/400.set-action-oracle.md)                 | 現在のモジュール内で現在の操作の名前を設定します。                |
| [SET_CLIENT_INFO](../1900.dbms-application-info-oracle/500.set-client-info-oracle.md) | クライアントアプリケーションの追加情報を設定します。 |
| [SET_MODULE](../1900.dbms-application-info-oracle/600.set-module-oracle.md)                 | 現在実行中のモジュールの名前を新しいモジュールに設定します。       |
