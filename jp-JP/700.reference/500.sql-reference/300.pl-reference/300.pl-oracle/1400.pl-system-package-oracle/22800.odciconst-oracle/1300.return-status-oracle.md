# Return Status

`Return Status`定数とその説明。

|    定数名     |  定数タイプ   | デフォルト値 |                   説明                   |
|-------------|---------|-----|----------------------------------------|
| Success     | INTEGER | 0   | 操作が成功したことを示します                                 |
| Error       | INTEGER | 1   | エラーが発生したことを示します                                 |
| Warning     | INTEGER | 2   | 警告が表示されたことを示します                                   |
| ErrContinue | INTEGER | 3   | インデックスパーティションにエラーがあるものの、次のパーティションでの処理を続行することを示します                |
| Fatal       | INTEGER | 4   | インデックスのすべての辞書エントリがクリーンアップされ、`CREATE INDEX` 操作がロールバックされたことを示します |
