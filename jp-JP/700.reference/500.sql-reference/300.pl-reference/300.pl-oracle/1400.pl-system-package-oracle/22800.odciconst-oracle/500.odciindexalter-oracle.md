# ODCIIndexAlter

`ODCIIndexAlter`定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>

|          定数名           |  定数タイプ   | デフォルト値 |          説明          |
|-------------------------|---------|-----|----------------------|

| AlterIndexRename        | INTEGER | 1   | パーティションのリネームオプション              |
| AlterIndexRebuild       | INTEGER | 2   | インデックスの再構築オプション               |
| AlterIndexRebuildOnline | INTEGER | 3   | オンラインでのインデックス再構築             |
| AlterIndexModifyCol     | INTEGER | 4   | インデックス列の変更                |
| AlterIndexUpdBlockRefs  | INTEGER | 5   | IOT更新ブロック参照            |
| AlterIndexRenameCol     | INTEGER | 6   | ドメインインデックスの基づく列をリネーム        |
| AlterIndexRenameTab     | INTEGER | 7   | ドメインインデックスの基づくテーブルをリネーム        |
| AlterIndexMigrate       | INTEGER | 8   | ユーザー管理のドメインインデックスをシステム管理のドメインインデックスに移行 |
