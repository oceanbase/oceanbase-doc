# ODCIEnv.CallProperty

`ODCIEnv.CallProperty`定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|          定数名           |  定数タイプ   | デフォルト値 |         説明         |
|-------------------------|---------|-----|--------------------|
| None                    | INTEGER | 0   | デフォルトのオプション               |
| FirstCall               | INTEGER | 1   | 最初のパーティション呼び出し            |
| Intermediate Call       | INTEGER | 2   | 中間パーティション呼び出し             |
| FinalCall               | INTEGER | 3   | 最後のパーティション以降の最終呼び出し        |
| RebuildIndex            | INTEGER | 4   | インデックスの再構築               |
| RebuildPMO              | INTEGER | 5   | PMOの再構築             |
| StatsGlobal             | INTEGER | 6   | グローバル統計情報収集を指定するために使用されます       |
| StatsGlobalAndPartition | INTEGER | 7   | グローバルおよびパーティションレベルの統計情報収集を指定するために使用されます |
| StatsPartition          | INTEGER | 8   | パーティションレベルの統計情報収集を指定するために使用されます    |
