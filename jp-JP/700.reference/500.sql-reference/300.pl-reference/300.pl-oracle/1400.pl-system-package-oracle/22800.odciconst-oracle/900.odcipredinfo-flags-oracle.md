# ODCIPredInfo.Flags

`ODCIPredInfo.Flags`定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|       定数名       |  定数タイプ   | デフォルト値 |      説明       |
|------------------|---------|-----|---------------|
| PredExactMatch   | INTEGER | 1   | 等価述語          |
| PredPrefixMatch  | INTEGER | 2   | `LIKE` 述語     |
| PredIncludeStart | INTEGER | 4   | インデックス範囲スキャンに開始値を含める |
| PredIncludeStop  | INTEGER | 8   | インデックス範囲スキャンに終了値を含める |
| PredObjectFunc   | INTEGER | 16  | 述語の左側は独立した関数    |
| PredObjectPkg    | INTEGER | 32  | 述語の左側はパッケージ関数     |
| PredObjectType   | INTEGER | 64  | 述語の左側は型指定方式  |
| PredMultiTable   | INTEGER | 128 | 述語が複数のテーブルからの列を含む   |
| PredNotEqual     | INTEGER | 256 | 不等号述語         |
