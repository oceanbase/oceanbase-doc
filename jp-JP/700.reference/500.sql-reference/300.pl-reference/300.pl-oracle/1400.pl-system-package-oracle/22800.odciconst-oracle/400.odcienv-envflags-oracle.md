# ODCIEnv.Envflags

`ODCIEnv.Envflags`定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|      定数名       |  定数タイプ   | デフォルト値 |    説明     |
|-----------------|---------|-----|-----------|
| DebuggingOn     | INTEGER | 1   | デバッグを示します      |
| NoData          | INTEGER | 2   | データなしを示します     |
| UserParamString | INTEGER | 4   | ユーザーパラメータ文字列を示します |
| RowMigration    | INTEGER | 8   | 行移行を示します     |
| IndexKeyChanged | INTEGER | 16  | インデックスキーが変更されたことを示します  |
