# ODCIArgDesc.ArgType

`ODCIArgDesc.ArgType`定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|   定数名    |  定数タイプ   | デフォルト値 |         説明          |
|-----------|---------|-----|---------------------|
| ArgOther  | INTEGER | 1   | 実際のパラメータが他の式である場合          |
| ArgCol    | INTEGER | 2   | 実際のパラメータが列名の場合             |
| ArgLit    | INTEGER | 3   | 実際のパラメータがリテラル値の場合            |
| ArgAttr   | INTEGER | 4   | 実際のパラメータがADT `attr` 列の場合 |
| ArgNull   | INTEGER | 5   | 実際のパラメータがNULLの場合          |
| ArgCursor | INTEGER | 6   | 実際のパラメータが`CURSOR` 式の場合 |
