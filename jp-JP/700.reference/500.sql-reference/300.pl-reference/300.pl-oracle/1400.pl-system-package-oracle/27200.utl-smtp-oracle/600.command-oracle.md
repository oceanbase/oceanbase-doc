# コマンド

`COMMAND`は、汎用的なSMTPコマンドを実行するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.COMMAND (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL)
RETURN reply;

UTL_SMTP.COMMAND (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|cmd|サーバーに送信する`command`コマンド。|
|arg| `cmd`コマンドに関連する追加情報またはパラメータを渡すために使用されます。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|commandの応答です。複数の応答がある場合は、最後の応答を返します。|

## 使用方法

この関数は1行の応答のみを返します(複数行の応答がある場合は、最後の1行のみを返します)。複数の応答行を返す必要がある場合は、`command_replies`を使用してください。
