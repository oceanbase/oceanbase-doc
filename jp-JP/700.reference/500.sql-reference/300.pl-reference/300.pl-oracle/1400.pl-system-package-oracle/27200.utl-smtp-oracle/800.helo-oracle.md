# HELO

`HELO` コマンドは、SMTPサービスとの初期ハンドシェイクを実行するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.HELO (
   c       IN OUT NOCOPY   connection,
   domain  IN              VARCHAR2)
RETURN reply;

UTL_SMTP.HELO (
   c       IN OUT NOCOPY   connection,
   domain  IN              VARCHAR2);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|domain|送信ホストのドメイン名で、識別に使用されます。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|コマンドへの応答です。複数の応答がある場合は、最後の応答が返されます。|

## 使用方法

期待される `250` で始まる応答メッセージを返します。これは、SMTPサーバーが通信の確立に準備ができていることを示します。
