# CLOSE_CONNECTION

`CLOSE_CONNECTION`はSMTP接続を閉じるために使用され、その結果SMTP操作が終了します。これはデータセッション中に電子メールをキャンセルする場合にのみ使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.CLOSE_CONNECTION (
   c     IN OUT NOCOPY connection);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
