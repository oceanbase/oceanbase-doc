# AUTH

`AUTH`は、SMTPサーバーに認証コマンドを送信するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.AUTH (
   c          IN OUT NOCOPY connection,
   username   IN            VARCHAR2,
   password   IN            VARCHAR2,
   schemes    IN            VARCHAR2 DEFAULT NON_CLEARTEXT_PASSWORD_SCHEMES)
 RETURN reply;

UTL_SMTP.AUTH (
   c          IN OUT NOCOPY connection,
   username   IN            VARCHAR2,
   password   IN            VARCHAR2,
   schemes    IN            VARCHAR2 DEFAULT NON_CLEARTEXT_PASSWORD_SCHEMES);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|username|ユーザー名。|
|password|パスワード。|
|schemes|優先順位に従って使用できる認証方式。現在、PLAINとLOGINの認証方式をサポートしています。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|commandのレスポンス。複数のレスポンスがある場合は、最後のレスポンスが返されます。|
