# COMMAND_REPLIES

`COMMAND_REPLIES`は、汎用的なSMTPコマンドを実行し、複数のレスポンス行を受信するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.COMMAND_REPLIES (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL)
RETURN replies;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|cmd|サーバーに送信する`command`コマンド。|
|arg|SMTPコマンドの引数で、実際の送信時には`cmd`と`arg`の間にスペースを挿入して連結します。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|replies|コマンドのレスポンス。|

## 使用方法

この関数は複数のレスポンス行を返します。
