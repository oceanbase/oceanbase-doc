# CREATE_PLAN

`CREATE_PLAN`プロシージャは、リソース計画を作成するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN (
    plan          IN   VARCHAR2,
    comment       IN   VARCHAR2 DEFAULT'');
```

## パラメータの説明

|   パラメータ    |    説明    |
|---------|----------|
| plan    | リソース計画の名前。 |
| comment | ユーザーコメント。    |

## 例

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.CREATE_PLAN('DAY','このリソース計画はトランザクション処理に使用されます');
END ;
```

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.CREATE_PLAN('NIGHT','このリソース計画は日常的な運用保守に使用されます');
END ;
```
