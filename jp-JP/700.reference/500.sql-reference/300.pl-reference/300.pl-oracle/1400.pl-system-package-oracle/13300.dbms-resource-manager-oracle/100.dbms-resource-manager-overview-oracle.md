# DBMS_RESOURCE_MANAGERの概要

`DBMS_RESOURCE_MANAGER`システムパッケージは、リソース使用計画、リソース使用グループ、およびリソース計画命令を維持するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 権限の説明

コールサイドは、`DBMS_RESOURCE_MANAGER`システムパッケージ内のプロシージャを実行するために`ADMINISTER_RESOURCE_MANAGER`システム権限を持っている必要があります。

## サブルーチンの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_RESOURCE_MANAGER`サブルーチンとその簡潔な説明を示しています。

|                                   サブルーチン                                 |           説明           |
|--------------------------------------------------------------------------|------------------------|
| [CREATE_CONSUMER_GROUP](../13300.dbms-resource-manager-oracle/200.create-consumer-group-oracle.md)      | リソース使用グループを定義して作成します。             |
| [CREATE_PLAN](../13300.dbms-resource-manager-oracle/300.create-plan-oracle.md)                | リソース計画を作成します。                |
| [CREATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-oracle/400.create-plan-directive-oracle.md)      | リソース計画指示子を作成します。              |
| [DELETE_CONSUMER_GROUP](../13300.dbms-resource-manager-oracle/500.delete-consume-group-oracle.md)      | リソース使用グループを削除します。               |
| [DELETE_PLAN](../13300.dbms-resource-manager-oracle/600.delete-plan-oracle.md)                | 指定された計画およびそれが参照するすべての計画指示子を削除します。  |
| [DELETE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-oracle/700.delete-plan-directive-oracle.md)      | リソース計画指示子を削除します。              |
| [SET_CONSUMER_GROUP_MAPPING](../13300.dbms-resource-manager-oracle/800.set-consumer-group-mappingn-directive-oracle.md) | ログインおよび実行時プロパティマッピングのエントリを追加、削除、または変更します。 |
| [UPDATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-oracle/900.update-plan-directive-oracle.md)      | リソース計画指示子を更新します。              |
