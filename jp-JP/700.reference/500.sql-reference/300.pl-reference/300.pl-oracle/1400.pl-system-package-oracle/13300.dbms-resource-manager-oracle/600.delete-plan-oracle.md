# DELETE_PLAN

`DELETE_PLAN`プロシージャは、指定された計画と、それが参照するすべての計画指示子を削除します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_PLAN (
    plan IN VARCHAR2);
```

## パラメータの説明

`plan`は、削除するリソース計画の名前を指定します。

## 例

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.DELETE_PLAN('NIGHT');
END ;
```
