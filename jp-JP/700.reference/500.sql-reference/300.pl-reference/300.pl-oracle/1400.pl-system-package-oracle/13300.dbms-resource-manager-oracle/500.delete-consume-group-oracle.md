# DELETE_CONSUMER_GROUP

`DELETE_CONSUMER_GROUP`プロシージャは、リソース使用グループを削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_CONSUMER_GROUP (
    consumer_group IN VARCHAR2);
```

## パラメータの説明

`consumer_group`は、削除する使用グループ名を指定します。

## 例

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.DELETE_CONSUMER_GROUP ('group1');
END ;
```
