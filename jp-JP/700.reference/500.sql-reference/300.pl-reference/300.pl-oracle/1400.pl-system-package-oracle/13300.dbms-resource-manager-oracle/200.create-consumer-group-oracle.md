# CREATE_CONSUMER_GROUP

`CREATE_CONSUMER_GROUP`プロシージャは、リソースユーザーグループを定義して作成するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP (
    consumer_group  IN VARCHAR2,
    comment         IN VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

|       パラメータ      |    説明     |
|----------------|-----------|
| consumer_group | リソースユーザーグループの名前。 |
| comment        | ユーザーコメント。     |

## 例

```shell
obclient> BEGIN
  DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group1','Transaction Processing Group');
END ;
```

```shell
obclient> BEGIN DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group2','Daily O&M Group');
END ;
```
