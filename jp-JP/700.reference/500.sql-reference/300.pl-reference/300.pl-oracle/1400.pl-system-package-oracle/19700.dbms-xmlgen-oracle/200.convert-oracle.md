# CONVERT

`CONVERT`関数は、XMLデータをエスケープされたまたはエスケープされていないXMLの等価物に変換し、`CLOB`または`VARCHAR2`データとしてエンコードまたはデコードされた形式で返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

OceanBaseデータベースの現行バージョンでは、文字列および`CLOB`形式のXMLデータを使用できます。構文は以下のとおりです：

```sql
DBMS_XMLGEN.CONVERT (
   xmlData IN VARCHAR2,
   flag    IN NUMBER := ENTITY_ENCODE)
RETURN VARCHAR2;

DBMS_XMLGEN.CONVERT (
   xmlData IN CLOB,
   flag    IN NUMBER := ENTITY_ENCODE)
 RETURN CLOB;
```

## パラメータの説明

|   パラメータ    |               説明            |
|---------|-----------------------------------------------------------------|
| xmlData | エンコードまたはデコードするXML `CLOB` データ。    |
| flag    | フラグを設定します。  <ul><li> `ENTITY_ENCODE` エンコードに使用されます(デフォルト)。   </li> <li> `ENTITY_DECODE` デコードに使用されます。</li></ul>    |

## 使用方法

パラメータ`flag`に`ENTITY_ENCODE`が指定されている場合、この関数はXMLデータをエスケープします。

たとえば、文字`>`のエスケープ形式は`&gt`です。

エスケープされていないことは、逆変換を意味します。
