# ブール型データ型

ブール型（`BOOLEAN`）は、論理演算の結果を格納します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

ブール型データ型は`TRUE`、`FALSE`、または`NULL`となります。`NULL`は結果が不明であることを示します。

代入構文は以下のとおりです：

```javascript
variable_name BOOLEAN
```

ブール型は合法的なSQL型ではないため、使用時には以下の制限があります：

* テーブル内の列にブール型を代入することはできません。

* テーブル内のデータをブール型変数に代入することはできません。

* どのSQL関数でもブール型変数を使用することはできません。

* PL関数を通じて渡されない限り、SQLステートメント内でブール型を使用することはできません。

例：

```sql
obclient> CREATE OR REPLACE PROCEDURE output_bool (b BOOLEAN)
AUTHID DEFINER IS
BEGIN
  DBMS_OUTPUT.PUT_LINE (
    CASE
      WHEN b IS NULL THEN 'NA'
      WHEN b THEN 'Y'
      WHEN NOT b THEN 'N'
    END
  );
END;
/
obclient> BEGIN
  output_bool(TRUE);
  output_bool(FALSE);
  output_bool(NULL);
END;
 /
Query OK, 0 rows affected

Y
N
NA
```
