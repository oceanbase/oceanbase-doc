# DROP TRIGGER

`DROP TRIGGER` ステートメントは、データベースからトリガーを削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 前提条件

このトリガーは現在のユーザーのスキーマ内に存在するか、ユーザーが `ALTER ANY TRIGGER` のシステム権限を持っている必要があります。

他のユーザーのスキーマ内の `DATABASE` からトリガーを削除するには、`ADMINISTER DATABASE TRIGGER` のシステム権限が必要です。

## 構文

`drop_trigger` の構文は次のとおりです：

```sql
DROP TRIGGER [ schema. ] trigger ;
```

## セマンティクス

|      構文      | キーワードまたは構文ノード |                 説明                  |
|--------------|----------|-------------------------------------|
| drop_trigger | schema   | このトリガーが属するスキーマ名。デフォルト値は現在のユーザーのスキーマです。 |
| drop_trigger | trigger  | 削除するトリガーの名前。                          |

## 例

トリガー `del_new_region` を削除します。

```sql
DROP TRIGGER del_new_region;
```
