# DROP TYPE BODY

`DROP TYPE BODY` ステートメントは、ユーザー定義の抽象データ型(ADT)、変動配列(VARRAY)、またはネストテーブル(Nested Table)の本体を削除するために使用されます。

タイプ本体が削除されても、タイプ仕様は依然として存在し、タイプ本体を再作成できます。メンバ関数を呼び出すことはできませんが、本体を再作成するまで、そのタイプを引き続き使用できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 前提条件

このタイプ本体は現在のユーザーのスキーマ内に存在するか、ユーザーには `ALTER ANY TYPE` のシステム権限が付与されている必要があります。

## 構文

`drop_type_body` の構文は次のとおりです：

```sql
DROP TYPE BODY [ schema. ] type_name ;
```

## セマンティクス

|       構文       | キーワードまたは構文ノード  |                         説明                         |
|----------------|-----------|----------------------------------------------------|
| drop_type_body | schema    | この型が属するスキーマ名。デフォルト値は現在のユーザーのスキーマです。                 |
| drop_type_body | type_name | 削除する型本体。型本体に型やテーブルへの依存関係がない場合にのみ、削除できます。 |

## 例

タイプ本体 `demo_typ2` を削除します。

```sql
DROP TYPE BODY demo_typ2;
```
