# 概要

この章では、PLストアドユニットに対するDDL操作、つまり作成、変更、削除について説明します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

## CREATE \[OR REPLACE\]

`CREATE [OR REPLACE]`は、PLユニットを作成するために使用されます。

使用可能なSQLステートメントには、`CREATE FUNCTION`、
`CREATE PACKAGE`、
`CREATE PACKAGE BODY`
、`CREATE PROCEDURE`、`CREATE TRIGGER` 、
`CREATE TYPE` および
`CREATE TYPE BODY`が含まれます。

各`CREATE`ステートメントには、オプションの`OR REPLACE`句があります。`OR REPLACE`を指定すると、既存のPLユニットに基づいて再作成できます。つまり、削除せずに宣言または定義を変更し、以前にそのPLユニットに付与されたオブジェクト権限を再取得します。PLユニットが再定義された場合、データベースはそれを再コンパイルします。
  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>上記の<code>CREATE</code>ステートメントは、PLブロック内に記述することはできません。</p>
  </main>

## ALTER

`ALTER`は、PLユニットを再コンパイルするために使用され、再作成する必要はありません(その宣言や定義を変更することはありません)。

使用可能なSQLステートメントには、`ALTER FUNCTION`、
`ALTER PACKAGE`、`ALTER PROCEDURE`、`ALTER TRIGGER` および
`ALTER TYPE`が含まれます。

次の理由に基づいて`ALTER`ステートメントを使用できます：

* 無効になったストレージユニットを明示的に再コンパイルすることで、暗黙的なランタイム再コンパイル、ランタイムのコンパイルエラー、およびパフォーマンスオーバーヘッドを回避します。

* 異なるコンパイルパラメータでストレージされたユニットを再コンパイルします。

* トリガーを有効または無効にします。

## DROP

`DROP`は、既存のPLユニットを削除するために使用されます。

使用可能なSQLステートメントには、`DROP FUNCTION`、
`DROP PACKAGE`、`DROP PROCEDURE`、`DROP TRIGGER` 、
`DROP TYPE` および
`DROP TYPE BODY`が含まれます。
