# DROP TYPE

`DROP TYPE` ステートメントは、ユーザー定義の抽象データ型(ADT)、`VARRAY` タイプ、またはネストテーブルタイプのスキーマと本体を削除するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 前提条件

該当するADT、`VARRAY` タイプ、またはネストテーブルタイプは現在のユーザーのスキーマ内に存在するか、ユーザーが `ALTER ANY TYPE` のシステム権限を持っている必要があります。

## 構文

`drop_type` の構文は次のとおりです：

```sql
DROP TYPE [ schema. ] type_name [ FORCE | VALIDATE ] ;
```

## 意味

|    構文     | キーワードまたは構文ノード  |         説明   |
|-----------|-----------|---------------------------------|
| drop_type | schema    | この型が属するスキーマ名。デフォルト値は現在のユーザーのスキーマです。   |
| drop_type | type_name | 削除対象のオブジェクト、`VARRAY`、またはネストテーブルタイプの名前。型またはテーブルに依存しない型のみを削除できます。 `type_name`がスーパータイプの場合、このステートメントの実行は失敗します。 `type_name`が統計情報タイプの場合、このステートメントの実行は失敗します。 `type_name`が統計情報タイプに関連付けられたADTの場合、データベースは最初に`type_name`で設定されたADTを統計情報タイプから解除し、次に`type_name`を削除します。ただし、統計情報タイプを使用して統計情報が収集されている場合、データベースは`type_name`で設定されたADTを統計情報タイプから解除できず、ステートメントの実行は失敗します。 `type_name`がインデックスタイプの場合、インデックスタイプは`INVALID`としてマークされます。 `type_name`に共通シノニムが定義されている場合、データベースはそのシノニムも削除します。 |

## 例

`demo_typ2` タイプを削除します。

```sql
DROP TYPE demo_typ2 FORCE;
```
