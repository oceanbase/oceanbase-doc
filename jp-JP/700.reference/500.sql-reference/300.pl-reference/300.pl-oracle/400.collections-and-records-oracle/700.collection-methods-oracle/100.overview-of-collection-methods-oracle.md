# コレクションメソッドの概要

コレクションメソッドはPLサブルーチンに属し、コレクション情報を返す関数またはコレクションを操作するプロシージャである可能性があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

コレクションメソッドにより、コレクションの使用と保守が容易になります。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>空のコレクションに対して、<code>EXISTS</code> は定義済み例外 <code>COLLECTION_IS_NULL</code> を発生させない唯一のコレクションメソッドです。</p>
  </main>

OceanBaseデータベースがサポートするコレクションメソッドは以下の表のとおりです。

| **メソッド** | **タイプ** |              **説明**               |
|--------|--------|-----------------------------------|
| DELETE | ステートメント | コレクションの要素を削除します。                         |
| TRIM   | ステートメント | 変数配列またはネストテーブルの末尾から要素を削除します。                 |
| EXTEND | ステートメント | 要素を変数配列またはネストテーブルの末尾に追加します。                |
| EXISTS | 関数     | 指定された変数配列またはネストテーブルの要素が存在する場合にのみ、`TRUE` を返します。 |
| FIRST  | 関数     | コレクション内の最初のインデックスを返します。                      |
| LAST   | 関数     | コレクション内の最後のインデックスを返します。                     |
| COUNT  | 関数     | コレクション内の要素数を返します。                       |
| LIMIT  | 関数     | コレクションが収容できる最大要素数を返します。                  |
| PRIOR  | 関数     | 指定されたインデックスより前のインデックスを返します。                      |
| NEXT   | 関数     | 指定されたインデックスより後のインデックスを返します。                     |

コレクションメソッドを呼び出すための基本構文は次のとおりです：

```javascript
collection_name.method
```

コレクションメソッドは、そのタイプ（関数またはプロシージャ）のPLサブルーチン内から呼び出すことができますが、SQLステートメント内から直接呼び出すことはできません。

サブルーチン内では、コレクションパラメータはバインドされたパラメータのプロパティを継承します。このようなパラメータにコレクションメソッドを適用できます。可変配列パラメータの場合、パラメータモードに関係なく、`LIMIT` の値は常にパラメータ型の定義から得られます。
