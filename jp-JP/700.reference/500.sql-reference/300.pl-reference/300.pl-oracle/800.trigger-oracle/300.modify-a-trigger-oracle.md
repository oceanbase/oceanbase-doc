# トリガーの変更と削除

PLはトリガーの変更と削除をサポートしています。

## トリガーの変更

現在、トリガーを変更するにはDDLステートメント内の`REPLACE TRIGGER`ステートメントを使用するしかありません。

通常、トリガーの作成と変更は以下のステートメントで記述されます：

```javascript
CREATE OR REPLACE TRIGGER trigger_name ...
```

`trigger_name`が存在しない場合はトリガーが作成され、`trigger_name`が既に存在する場合はトリガーが変更されます。

## トリガーの削除

`DROP TRIGGER`を使用してトリガーを削除できます。構文は次のとおりです：

```javascript
DROP TRIGGER trigger_name;
```

さらに、テーブルを削除すると、そのオブジェクト上に作成されたトリガーも同時に削除されます。
