# 概要

PLはSQLの拡張として導入された制御文であり、プログラム内のステートメント実行順序をより柔軟に制御できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

OceanBaseデータベースのPLプロセス制御文には、主に以下の3種類が含まれます：

* 条件選択

  ランタイム時の異なる条件に基づいて、異なるステートメントを実行するかどうかを制御します。条件選択ステートメントのキーワードには`IF`と`CASE`があります。

* ループ制御

  条件に基づいて一連のステートメントを繰り返し実行します。ループステートメントには`FOR LOOP`、`WHILE LOOP`、および基本的な`LOOP`があります。

* シーケンス制御

  シーケンス制御ステートメントは、指定されたマーカー文にジャンプするか、何も処理しないことを許可します。`GOTO`と`NULL`が含まれます。
