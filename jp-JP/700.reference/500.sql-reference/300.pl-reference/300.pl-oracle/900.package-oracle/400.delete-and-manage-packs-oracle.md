# マネージャーパッケージ

PLは、パッケージの削除操作をサポートしており、パッケージ情報を確認して管理することができます。

    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## プログラムパッケージの削除

不要なプログラムパッケージを削除するには、`DROP PACKAGE` コマンドを使用します。構文は以下のとおりです：

```javascript
DROP PACKAGE [BODY] [user.]package_name;
```

例：

```javascript
obclient>DROP PACKAGE obdemo_pack1;
Query OK, 0 rows affected
```

## プログラムパッケージの管理

以下のプログラムパッケージ関連ビューを使用して、プログラムパッケージの情報を確認できます：

* `USER_OBJECTS`：データベースオブジェクトを確認し、パッケージの名前、現在の状態、作成時間などの情報を一覧表示するために使用できます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>パッケージ（<code>PACKAGE</code>）とパッケージ本体（<code>PACKAGE BODY</code>）は異なるタイプのオブジェクトです。</p>
  </main>

* `USER_SOURCE`：パッケージとパッケージ本体の内容を確認します。

* `USER_ERRORS`：前回パッケージまたはパッケージ本体をコンパイルした際のエラーメッセージを確認します。

**例1：現在のユーザーのすべてのプログラムパッケージのステータスと作成時間を確認します。**

```javascript
obclient> SELECT OBJECT_NAME,OBJECT_TYPE,CREATED,STATUS
           FROM USER_OBJECTS WHERE OBJECT_TYPE LIKE 'PACKAGE%';
+-------------+-------------+-----------+---------+
| OBJECT_NAME | OBJECT_TYPE | CREATED   | STATUS  |
+-------------+-------------+-----------+---------+
| DEMO_PACK   | PACKAGE     | 17-DEC-20 | INVALID |
+-------------+-------------+-----------+---------+
1 row in set
```

**例2：** **`OBDEMO_PACK`** **という名前のパッケージ本体の内容を確認します。**

```javascript
obclient> SELECT TEXT FROM USER_SOURCE
WHERE TYPE='PACKAGE BODY'
            AND NAME='OBDEMO_PACK'\G

        IS
    FUNCTION add_obdept(dept_no NUMBER, dept_name VARCHAR2, location VARCHAR2)

        IS
        deptno_remaining EXCEPTION;
           PRAGMA EXCEPTION_INIT(deptno_remaining, -1);
    BEGIN
        INSERT INTO obdept VALUES(dept_no, dept_name, location);
        IF SQL%FOUND THEN
            RETURN 1;
        END IF;
    EXCEPTION
           WHEN deptno_remaining THEN
            RETURN 0;
        WHEN OTHERS THEN
            RETURN -1;
    END add_obdept;

    FUNCTION remove_obdept(dept_no NUMBER)
        RETURN NUMBER
        IS
    BEGIN
    DELETE FROM obdept WHERE deptno=dept_no;
       IF SQL%FOUND THEN
            RETURN 1;
        ELSE
            RETURN 0;
       END IF;
    EXCEPTION
    WHEN OTHERS THEN
        RETURN -1;
    END remove_obdept;

    PROCEDURE query_obdept (dept_no IN NUMBER)
        IS
    BEGIN
    SELECT * INTO obDeptRec FROM obdept WHERE deptno=dept_no;
    EXCEPTION
           WHEN NO_DATA_FOUND THEN
              DBMS_OUTPUT.PUT_LINE('データベースには、部門が'||dept_no||'としてエンコードされていません');
           WHEN TOO_MANY_ROWS THEN
              DBMS_OUTPUT.PUT_LINE('プログラム実行エラー!');
           WHEN OTHERS THEN
               DBMS_OUTPUT.PUT_LINE(SQLCODE||'----'||SQLERRM);
    END query_obdept;
     BEGIN
             Null;
     END obdemo_pack
1 row in set
```
