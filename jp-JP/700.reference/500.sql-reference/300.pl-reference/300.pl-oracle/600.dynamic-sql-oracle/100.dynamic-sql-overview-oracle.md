# 概要

動的SQLは、PLが提供するプログラミング機能の一つであり、PLプログラムの実行中にSQLを生成・実行することができるため、プログラミングにおいて大きな柔軟性をもたらします。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。</p>
  </main>

動的SQLの適用シナリオは以下の通りです：

* プログラム作成時点では完全なSQL文が決定できない場合。

* PLの静的SQLではサポートされない操作、例えばDDLなど。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>一般的に静的SQLはより高いセキュリティと効率を提供するため、可能な限り動的SQLは使用しないようにしてください。</p>
  </main>

OceanBaseデータベースのPL動的SQLは、以下のシナリオで複雑なデータ型を返すSQLをサポートしています：

* 動的SQLによる`SELECT`ステートメントの実行
* 動的SQLによるDMLステートメントの実行
* `USING`句の`OUT`属性を使用した`EXECUTE IMMEDIATE`による代入
