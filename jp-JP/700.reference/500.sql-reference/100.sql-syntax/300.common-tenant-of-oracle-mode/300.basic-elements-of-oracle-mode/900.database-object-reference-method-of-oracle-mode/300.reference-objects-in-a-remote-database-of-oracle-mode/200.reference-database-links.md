# データベースリンクの参照

データベースリンクを含むSQLステートメントを実行する場合は、データディクショナリに格納されている完全なデータベースリンク名を使用する必要があります。

OceanBaseデータベースは、リモートデータベースに接続する際に、データベース接続文字列を使用してアクセスします。データベース文字列、ユーザー名、パスワードを使用して接続に成功した後、OceanBaseデータベースは参照スキーマオブジェクト内のルールを使用して、リモートデータベース上の指定されたオブジェクトにアクセスします。ただし、他のスキーマに属するテーブルオブジェクトにアクセスする場合は、データベース名を明示的に指定する必要がある点に注意してください。例：`test.t1@my_link`。
