# データベースリンクの作成

ローカルデータベース以外の他のデータベース内のオブジェクトを参照するには、オブジェクト名の後にそのデータベースへのデータベースリンク名を付加する必要があります。データベースリンクとは、OceanBaseデータベースがリモートデータベースに接続して内部のオブジェクトにアクセスできるようにするためのSchemaオブジェクトです。

`CREATE DATABASE LINK` ステートメントを使用してデータベースリンクを作成できます。このステートメントを使用する際には、以下のデータベースリンク情報を指定する必要があります：

* テナント名、ユーザー名、パスワード。

* ネットワークアドレス、ポート番号。

OceanBaseデータベースは上記の情報をデータディクショナリに格納します。

リンクの作成には以下の制限があります：

* OceanBaseデータベース内のOracleモードのテナントから、別のOracleモードのテナントへのデータベースリンクのみをサポートしています。現在、OceanBaseデータベースでは外部のOracleデータベースに接続するデータベースリンクの作成はサポートされていません。

* 1つのテナントはデータベースリンクを繰り返し作成・削除できますが、同時に存在できるデータベースリンクは最大15個までです。
