# データベースリンクの作成

ローカルデータベース以外のデータベース内のオブジェクトを参照するには、オブジェクト名の後に、そのデータベースへのデータベースリンク名を付加する必要があります。データベースリンクとはSchemaオブジェクトであり、OceanBaseデータベースがリモートデータベースに接続して内部のオブジェクトにアクセスできるようにします。

`CREATE DATABASE LINK` ステートメントを使用してデータベースリンクを作成できます。このステートメントを使用する際には、以下のデータベースリンク情報を指定する必要があります：

* テナント名、ユーザー名、パスワード。

* ネットワークアドレス、ポート番号。

OceanBaseデータベースは上記の情報をデータディクショナリに格納します。

リンクの作成には以下の制限があります：

* OceanBaseデータベース内のOracleモードのテナントから別のOracleモードのテナントへのデータベースリンクの作成のみをサポートしています。OceanBaseデータベースは現在、外部Oracleデータベースへの接続を提供するデータベースリンクの作成をサポートしていません。

* 1つのテナントはデータベースリンクを繰り返し作成および削除できますが、同時に存在できるデータベースリンクは最大15個です。
