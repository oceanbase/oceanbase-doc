# Optimized HintタイプのDistributed DML Hint

OracleモードのOceanBaseデータベースでは、分散DMLヒントを使用して、DML操作が分散方式で実行されるかどうかを制御できます。以下の2つの重要な概念を区別することが重要です：

- 分散DML：複数のノード間で実行されるDML操作を指し、単一ノード上でローカルまたはpartition-wiseに実行される非分散DML操作とは本質的に異なります。
- 並列DML：単一ノード内で複数のスレッドが並列して1つのDML操作を実行する場合を強調します。

また、このようなヒントは実行計画を固定するために使用できますが、ユーザーによる使用は推奨されません。通常はOUTLINE DATAでのみ有効にします。

| ヒント名                              | 説明       |
|---------------------------------------|------------|
| `USE_DISTRIBUTED_DML`     | 分散DML操作を有効にします。逆操作は`NO_USE_DISTRIBUTED_DML`です。  |
| `NO_USE_DISTRIBUTED_DML`  | 分散DML操作を無効にします。逆操作は`USE_DISTRIBUTED_DML`です。    |

## `USE_DISTRIBUTED_DML` ヒント

`USE_DISTRIBUTED_DML` ヒントは、分散DML操作を有効にします。このヒントを有効にすると、DML操作は分散実行されます。その逆操作は `NO_USE_DISTRIBUTED_DML` ヒントです。

### 構文

```sql
/*+ USE_DISTRIBUTED_DML [ ( [ @ qb_name ] ) ] */
```

### 例

```sql
-- ハッシュパーティションのテーブルtp1を作成し、10個のパーティションを含める
CREATE TABLE tp1(c1 INT, c2 INT, c3 INT) PARTITION BY HASH(c1) PARTITIONS 10;

-- USE_DISTRIBUTED_DMLヒントを使用してtp1テーブルを更新し、c1列の値が4未満の場合にc2列の値を4に設定する
-- この更新操作は分散実行される
```

## `NO_USE_DISTRIBUTED_DML` ヒント

`NO_USE_DISTRIBUTED_DML` ヒントは、DML操作における分散実行を禁止します。その逆操作は `USE_DISTRIBUTED_DML` ヒントです。

### 構文

```sql
/*+ NO_USE_DISTRIBUTED_DML [ ( [ @ qb_name ] ) ] */
```

### 例

```sql
-- NO_USE_DISTRIBUTED_DMLヒントを使用して、更新操作が分散実行ではなく単一ノードでローカル実行されるように制限する
```
