# コメントの概要

OceanBaseデータベースはコメント機能をサポートしており、SQL文の可読性を向上させるだけでなく、SQL文の機能を豊かにすることができます。

OceanBaseデータベースのユーザーは、以下の3種類のコメントを作成できます：

* SQL文のコメント

  SQL文を実行するアプリケーションコードの一部として格納されます。

* スキーマおよび非スキーマオブジェクトのコメント

  オブジェクト自体のメタデータとともにデータディクショナリに格納されます。

* ヒント

  SQL文内でOceanBaseデータベースのオプティマイザーに指示を伝えるためのコメントです。
