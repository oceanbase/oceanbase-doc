# コメントの概要

OceanBaseデータベースはコメント機能をサポートしており、SQLステートメントの可読性を向上させるだけでなく、SQLステートメントの機能を豊かにすることもできます。

OceanBaseデータベースのユーザーは、以下の3種類のコメントを作成できます：

* SQLステートメントのコメント

  SQLステートメントを実行するアプリケーションコードの一部として格納されます。

* スキーマおよび非スキーマオブジェクトのコメント

  オブジェクト自体のメタデータと共にデータディクショナリに格納されます。

* ヒント

  SQLステートメント内でOceanBaseデータベースのオプティマイザーに指示を伝えるためのコメントです。
