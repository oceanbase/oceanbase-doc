# スキーマオブジェクトと非スキーマオブジェクトのコメント

OceanBaseデータベースのユーザーは、COMMENTステートメントを使用して、コメントをスキーマオブジェクト（テーブル、演算子、インデックスタイプ）または非スキーマオブジェクト（Edition）に関連付けることができます。スキーマおよび非スキーマオブジェクトに関連付けられたコメントは、データディクショナリに格納されます。

スキーマオブジェクトおよび非スキーマオブジェクトのコメントを作成する構文は以下のとおりです：

```sql
COMMENT ON {TABLE table | COLUMN column | INDEXTYPE indextype
| OPERATOR operator} IS string
```

例：

* ユーザーテーブルのコメントを作成する

  ```sql
  COMMENT ON TABLE test.user is "これはユーザー情報を記録するテーブルです";
  ```

* user_name列のコメントを作成する

  ```sql
  COMMENT ON COLUMN test.user.user_name is "ここにユーザーの氏名が記録されています";
  ```
