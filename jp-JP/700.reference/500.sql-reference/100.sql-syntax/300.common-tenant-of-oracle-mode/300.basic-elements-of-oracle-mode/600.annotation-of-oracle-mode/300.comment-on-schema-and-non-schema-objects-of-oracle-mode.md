# スキーマオブジェクトと非スキーマオブジェクトのコメント

OceanBaseデータベースのユーザーは、COMMENTステートメントを使用して、スキーマオブジェクト（テーブル、演算子、インデックスタイプ）または非スキーマオブジェクト（エディション）にコメントを関連付けることができます。スキーマオブジェクトおよび非スキーマオブジェクトに関連付けられたコメントは、データディクショナリに格納されます。

スキーマオブジェクトと非スキーマオブジェクトのコメントを作成する構文は以下のとおりです：

```sql
COMMENT ON {TABLE table | COLUMN column | INDEXTYPE indextype
| OPERATOR operator} IS string
```

例：

* ユーザーテーブルのコメントを作成する

  ```sql
  COMMENT ON TABLE test.user is "これはユーザー情報を記録するテーブルです";
  ```

* user_name列のコメントを作成する

  ```sql
  COMMENT ON COLUMN test.user.user_name is "ここにユーザーの名前が記録されています";
  ```
