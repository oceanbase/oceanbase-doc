# 文字列から日付への変換ルール

文字列値を日付値に変換する際は、特定の変換ルールに従う必要があります。

変換ルールは以下のとおりです：

* 数値フォーマットモデル要素のすべての数値（先頭のゼロを含む）を指定した場合、日付文字列からフォーマット文字列に含まれる句読点を省略できます。例えば、2桁の書式要素（`MM`、`DD`、`YY`など）には、2ではなく02を指定します。

* フォーマット文字列の末尾にある時間フィールドは、日付文字列から省略できます。

* 日付文字列では、任意の非英字数字文字を使用して、フォーマット文字列内の句読点に一致させることができます。
