# 文字列から日付への変換ルール

文字列値を日付値に変換する際は、一定の変換ルールに従う必要があります。

変換ルールは以下のとおりです：

* 数値を表す各書式要素に、先頭のゼロを含めて必要な桁数をすべて指定した場合、日付文字列から書式文字列に含まれる句読点を省略できます。例えば、2桁の書式要素（`MM`、`DD`、`YY`など）には、2ではなく02を指定します。

* 書式文字列の末尾にある時間フィールドは、日付文字列から省略できます。

* 日付文字列では、書式文字列内の句読点に一致させるために、英数字以外の任意の文字を使用できます。
