# 文字列から日付への変換ルール

文字列値を日付値に変換する際には、一定の変換ルールに従う必要があります。

変換ルールは以下のとおりです：

* 数値フォーマットモデル要素のすべての数値（先頭のゼロを含む）が指定されている場合、日付文字列からフォーマット文字列に含まれる句読点を省略できます。例えば、2桁の書式要素（`MM`、`DD`、`YY`など）に対して、2ではなく02を指定します。

* フォーマット文字列の末尾に見つかる時間フィールドは、日付文字列から省略できます。

* 日付文字列では、フォーマット文字列内の句読点にマッチさせるために、アルファベット以外の任意の数字や記号を使用できます。
