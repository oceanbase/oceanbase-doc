# フォーマットモデルの概要

OceanBaseデータベースのOracleモードでは、フォーマットモデルを使用して、データベースに格納される日付時刻データや数値データの形式を指定できます。

フォーマットモデルは、データベース内の値の内部表現を変更するものではありません。データベースが文字列を日付または数値に変換する際、フォーマットモデルがその変換方法および文字列の格納方法を決定します。

SQLステートメントでは、フォーマットモデルを `TO_CHAR`、`TO_NUMBER`、`TO_DATE` などの関数のパラメータとして使用し、以下の形式を指定できます：

* データベースが返す値の形式

* データベースに格納される値の形式

OceanBaseデータベースは、以下の2種類のデータフォーマットモデルをサポートしています：

* [数値フォーマットモデル](../400.format-of-oracle-mode/200.format-of-oracle-mode.md)

* [日付時刻フォーマットモデル](../400.format-of-oracle-mode/300.date-and-time-formatting-of-oracle-mode.md)
