# 数値比較規則

数値データには、固定小数点数、浮動小数点数、およびゼロが含まれます。このセクションでは、主に数値データの比較規則について説明します。

OceanBaseデータベースの数値データ比較規則は以下のとおりです：

* 大きな値は小さな値より大きいです。例：`5.5 > 2.1`。

* 負の数はすべてゼロより小さいです。例：`-3 < 0;-200 < -1`。

* 正の数はすべてゼロより大きいです。例：`20 > 0;100 > 1`。

数値データの比較規則の詳細については、[数値型の優先順位](../100.built-in-data-types-of-oracle-mode/300.numeric-data-type-of-oracle-mode/500.numeric-priority-of-oracle-mode.md)を参照してください。
