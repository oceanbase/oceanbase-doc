# 数値比較ルール

数値データには固定小数点数、浮動小数点数、およびゼロが含まれます。このセクションでは、主に数値データの比較ルールについて説明します。

OceanBaseデータベースの数値データ比較ルールは以下のとおりです：

* 大きな値は小さな値よりも大きいです。例：`5.5 > 2.1`。

* 負の数はすべてゼロより小さいです。例：`-3 < 0；-200 < -1`。

* 正の数はすべてゼロより大きいです。例： `20 > 0；100 > 1`。

数値データの比較ルールの詳細については、[数値型の優先順位](../100.built-in-data-types-of-oracle-mode/300.numeric-data-type-of-oracle-mode/500.numeric-priority-of-oracle-mode.md)を参照してください。
