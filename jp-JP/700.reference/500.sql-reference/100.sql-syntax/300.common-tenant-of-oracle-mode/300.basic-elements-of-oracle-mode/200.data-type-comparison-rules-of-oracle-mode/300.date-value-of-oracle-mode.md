# 日付値の比較規則

DATEデータ型は、日付と時刻の情報を格納するために使用されます。このセクションでは、主に日付データの比較規則について説明します。

OceanBaseデータベースは、各`DATE`値に年、月、日、時、分、秒の情報を格納することをサポートしていますが、タイムゾーン情報は含まれません。

日付データの比較規則は以下のとおりです：

* 現在の時間は過去の時間より大きいです。例えば、2018年5月1日の日付値は2012年5月1日の日付値より大きいです。

* 午後の時間は午前の時間より大きいです。例えば、2019年2月2日午後3:30の日付時刻値は2019年2月2日午前10:30の日付時刻値より大きいです。

* 午前の時間は昨日の時間より大きいです。例えば、2019年3月5日午前2:30の日付時刻値は2019年3月4日午後23:30の日付時刻値より大きいです。
