# データ型比較ルールの概要

データ型比較ルールは、OceanBaseデータベースが各データ型の値を比較する方法を定義しています。この章では、主に数値、日付値、文字列値の比較ルール、およびデータ型の優先順位と変換ルールについて説明します。

OceanBaseデータベースは、以下のデータ型比較ルールをサポートしています：

* [数値比較ルール](../200.data-type-comparison-rules-of-oracle-mode/200.numeric-value-of-oracle-mode.md)

* [日付値比較ルール](../200.data-type-comparison-rules-of-oracle-mode/300.date-value-of-oracle-mode.md)

* [文字列値比較ルール](../200.data-type-comparison-rules-of-oracle-mode/400.character-value-of-oracle-mode.md)

データ型比較ルールの詳細については、以下のセクションを参照してください：

* [データ型の優先順位](../200.data-type-comparison-rules-of-oracle-mode/500.data-type-priority-of-oracle-mode.md)

* [データ型の変換](../200.data-type-comparison-rules-of-oracle-mode/600.data-type-conversion-of-oracle-mode.md)
