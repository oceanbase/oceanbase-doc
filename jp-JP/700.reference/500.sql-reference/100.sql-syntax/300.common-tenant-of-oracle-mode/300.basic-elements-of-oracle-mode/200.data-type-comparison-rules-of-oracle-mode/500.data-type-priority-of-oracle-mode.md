# データ型の優先順位

OceanBaseはデータ型の優先順位を使用して、暗黙的なデータ型変換の順序を決定します。この記事では主にデータ型の変換優先順位について説明します。

OceanBaseデータベースのデータ型の変換優先順位は以下のとおりです（高い順から低い順へ）：

1. 日付時刻および間隔データ型

2. `BINARY_DOUBLE` データ型

3. `BINARY_FLOAT` データ型

4. `NUMBER` データ型

5. 文字データ型

6. その他すべての組み込みデータ型
