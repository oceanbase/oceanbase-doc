# 条件判断式におけるNULL値

条件式で NULL 値を等号や不等号で比較すると、結果は UNKNOWN となり、その条件に一致する行は返されません。

条件判断式には `= NULL`、`!= NULL`、`NULL =`、`NULL !=` が含まれます。

OceanBaseデータベースでは、NULL値をテストするには比較演算子 `IS NULL` を使用し、結果は `TRUE` または `FALSE` になります。しかし、条件判断式におけるNULL値の判断結果 `UNKNOWN` は `FALSE` とは異なります。`NOT FALSE` の判断結果は `TRUE`、`NOT UNKNOWN` の判断結果は依然として `UNKNOWN` です。

以下の表の例は、A値に基づいて判断した条件判断式の結果を示しています。

|    条件     | A 値  |   結果    |
|-----------|------|---------|
| A = NULL  | 10   | UNKNOWN |
| A != NULL | 10   | UNKNOWN |
| A = NULL  | NULL | UNKNOWN |
| A != NULL | NULL | UNKNOWN |
| A = 10    | NULL | UNKNOWN |
| A != 10   | NULL | UNKNOWN |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>SELECT</code> ステートメントの <code>WHERE</code> 句で、判断結果が <code>UNKNOWN</code> の条件を使用した場合、そのクエリはいずれの行も返しません。</p>
