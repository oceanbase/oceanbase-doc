# 比較条件におけるNULL値

比較条件におけるNULL値とは、他の任意の条件と比較されるNULLを指します。

NULL値のテストには、比較演算子`IS NULL`および`IS NOT NULL`のみが使用できます。これは、`NULL`がデータの欠落を表すため、`NULL`は他の値と比較不可能であり、等号、不等号、大なり、小なりなどの比較演算子を使用して他の数値と比較することはできません。もちろん、NULL値そのものと比較することもできません。

また、OceanBaseデータベースでは、`DECODE`関数の計算において、2つのNULL値は等しいと見なされます。複合キーに2つのNULL値が含まれている場合、それらも等しいと見なされます。つまり、複合キーのすべての非NULLフィールドが等しい場合、OceanBaseデータベースは2つのNULLを含む複合キーを使用するかどうか検討します。

以下の表は、Aの値に基づいて得られる比較条件の結果を示しています。

|      条件       | A値  |  結果   |
|---------------|------|-------|
| A IS NULL     | 10   | FALSE |
| A IS NOT NULL | 10   | TRUE  |
| A IS NULL     | NULL | TRUE  |
| A IS NOT NULL | NULL | FALSE |
