# 非スキーマオブジェクト

非スキーマオブジェクトとは、特定のスキーマに属さないデータベースオブジェクトを指します。

非スキーマオブジェクトには一般的に以下が含まれます：

* ユーザー（User）

* ロール（Role）

* ディレクトリ（Directory）
