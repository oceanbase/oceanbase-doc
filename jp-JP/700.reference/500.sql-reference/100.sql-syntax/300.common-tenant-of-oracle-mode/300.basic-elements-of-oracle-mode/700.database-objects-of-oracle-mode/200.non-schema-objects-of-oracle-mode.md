# スキーマ対象外のオブジェクト

スキーマ対象外のオブジェクトとは、特定のスキーマに属さないデータベースオブジェクトを指します。

スキーマ対象外のオブジェクトには一般的に以下が含まれます：

* ユーザー（User）

* ロール（Role）

* ディレクトリ（Directory）
