# スペース列の作成

`SDO_GEOMETRY` 列の作成および関連するDDL操作をサポートします。

## 空間列を持つテーブルの作成

**例：**

`test_tbl1` という名前のテーブルを作成します。このテーブルには、以下の3列が含まれます：

* `id`：`NUMBER` 型の列で、主キーとして使用されます。
* `name`：`VARCHAR2(32)` 型の列で、最大長32文字の文字列を格納するために使用されます。
* `shape`：`SDO_GEOMETRY` 型の列で、空間幾何図形のデータを格納するために使用されます。

```sql
CREATE TABLE test_tbl1 (id NUMBER PRIMARY KEY, name VARCHAR2(32), shape SDO_GEOMETRY);
```

### 空間データの挿入

SDO_GEOMETRY コンストラクタを使用して、空間オブジェクトのインスタンスを作成できます。

**例：**

以下のステートメントを使用して、テーブル `test_tbl1` に1行のデータを挿入します。具体的な挿入データは以下のとおりです：

1. `id` 列の値は1です。

2. `name` 列の値は `name1` です。

3. `shape` 列の値は、多角形を記述する `SDO_GEOMETRY` オブジェクトです。`SDO_GEOMETRY` のコンストラクタパラメータは以下のとおりです：

   1. `2003`：多角形タイプを表します。
   2. `NULL`：空間参照識別子が指定されていないことを表します。
   3. `NULL`：点座標が与えられていないことを表します。
   4. `SDO_ELEM_INFO_ARRAY(1,1003,1)`：幾何図形の幾何要素情報を表します。最初のパラメータの1は `SDO_ORDINATE_ARRAY` の最初の要素から始まることを意味し、2番目のパラメータの1003は多角形の外輪を意味し、3番目のパラメータの1は直線接続を意味します。
   5. `SDO_ORDINATE_ARRAY(10,105, 15,105, 20,110, 10,110, 10,105)`：幾何図形の具体的な座標値を表し、多角形の頂点座標を示します。頂点座標は順に (10,105), (15,105), (20,110), (10,110), (10,105) です。

```sql
INSERT INTO test_tbl1 VALUES(1, 'name1',
  SDO_GEOMETRY(2003, NULL, NULL, SDO_ELEM_INFO_ARRAY(1,1003,1), SDO_ORDINATE_ARRAY(10,105, 15,105, 20,110, 10,110, 10,105))
);
```

### 空間データフィールド情報のクエリ

**例：**

以下のステートメントを使用して、テーブル `test_tbl1` から `shape` 列の情報を選択します。

```sql
obclient [SYS]> SELECT shape FROM test_tbl1;
```

実行結果は次のとおりです：

```shell
+----------------------------------------------------------------------------------------------------------------------------------+
| SHAPE                                                                                                                            |
+----------------------------------------------------------------------------------------------------------------------------------+
| SDO_GEOMETRY(2003, NULL, NULL, SDO_ELEM_INFO_ARRAY(1, 1003, 1), SDO_ORDINATE_ARRAY(10, 105, 15, 105, 20, 110, 10, 110, 10, 105)) |
+----------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```

## スペース列の追加・削除

`ALTER TABLE`ステートメントを使用して、既存のテーブルにスペース列を追加したり、スペース列を削除したりすることもできます。

**例：**

* スペース列の追加。

  ```sql
  ALTER TABLE test_tbl2 ADD shape SDO_GEOMETRY;
  ```

* スペース列の削除。

  ```sql
  ALTER TABLE test_tbl2 DROP COLUMN shape;
  ```
