# 組み込みデータ型の概要

OceanBase データベースは多くの組み込みデータ型を提供しており、これらの組み込みデータ型は OceanBase データベースの基本データ型とも呼ばれます。この章では、OceanBase データベースの現在のバージョンでサポートされているデータ型の構文、パラメータ、使用方法などについて説明します。

OceanBase データベースで操作される各値にはデータ型があります。値のデータ型は、その値に一連の固定属性を関連付けます。これらの属性により、OceanBase データベースはあるデータ型の値と別のデータ型の値を区別して扱うことができます。

OceanBase データベースの現在のバージョンで主にサポートされている組み込みデータ型は以下の通りです：

* [文字データ型](200.character-data-type-of-oracle-mode/100.overview-of-character-data-types-of-oracle-mode.md)

* [数値データ型](300.numeric-data-type-of-oracle-mode/100.overview-of-numeric-data-types-of-oracle-mode.md)

* [日付・時刻・間隔データ型](400.date-time-and-interval-data-types-of-oracle-mode/100.overview-of-date-time-and-interval-data-types-of-oracle-mode.md)

* [RAW データ型](../100.built-in-data-types-of-oracle-mode/500.raw-data-type-of-oracle-mode.md)

* [BLOB データ型](600.large-object-data-type-of-oracle-mode/100.data-types-of-large-objects-of-oracle-mode.md)

* [Rowid データ型](../100.built-in-data-types-of-oracle-mode/700.rowid-datatype-of-oracle-mode.md)
