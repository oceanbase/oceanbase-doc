# ビルトインデータ型の概要

OceanBaseデータベースは多くのビルトインデータ型を提供しており、これらのビルトインデータ型はOceanBaseデータベースの基本データ型とも呼ばれます。この章では、OceanBaseデータベースの現行バージョンでサポートされているデータ型の構文、パラメータ、使用方法などについて説明します。

OceanBaseデータベースで操作される各値にはデータ型があります。値のデータ型は、値に一連の固定されたプロパティを関連付け、これらのプロパティによってOceanBaseデータベースはあるデータ型の値と別のデータ型の値を区別して扱います。

OceanBaseデータベースの現行バージョンでは、主に以下のビルトインデータ型がサポートされています：

* [文字データ型](200.character-data-type-of-oracle-mode/100.overview-of-character-data-types-of-oracle-mode.md)

* [数値データ型](300.numeric-data-type-of-oracle-mode/100.overview-of-numeric-data-types-of-oracle-mode.md)

* [日付時刻および間隔データ型](400.date-time-and-interval-data-types-of-oracle-mode/100.overview-of-date-time-and-interval-data-types-of-oracle-mode.md)

* [RAWデータ型](../100.built-in-data-types-of-oracle-mode/500.raw-data-type-of-oracle-mode.md)

* [BLOBデータ型](600.large-object-data-type-of-oracle-mode/100.data-types-of-large-objects-of-oracle-mode.md)

* [ROWIDデータ型](../100.built-in-data-types-of-oracle-mode/700.rowid-datatype-of-oracle-mode.md)

* [JSONデータ型](1000.json-formatted-data-type-oracle-mode/100.json-data-type-overview-of-oracle-mode.md)
