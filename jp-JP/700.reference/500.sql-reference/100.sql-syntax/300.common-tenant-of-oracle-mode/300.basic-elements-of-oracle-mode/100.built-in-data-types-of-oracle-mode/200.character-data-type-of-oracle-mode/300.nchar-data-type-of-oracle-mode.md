# NCHARデータ型

NCHARは固定長のUNICODE文字データ型です。本記事では、主にNCHARデータ型の構文、パラメータ、使用方法について説明します。

## 構文

```sql
NCHAR[(size)]
```

## パラメータ

|   パラメータ   |                                        説明                                        |
|--------|----------------------------------------------------------------------------------|
| `size` | 固定長文字データの長さを表します。最大サイズは国別文字セットの定義によって決まり、上限は2000バイトです。デフォルトで固定長文字データの長さは最小1文字です。 |

## 使用方法

データベース作成時に、列の最大長は国別文字セットの定義によって決まります。`NCHAR` データ型の列を含むテーブルを作成する際は、文字単位で列の長さを定義します。文字データ型 `NCHAR` の幅の仕様は文字数を指します。許容される最大列サイズは2000バイトです。

中国語をより少ないスペースで保存したい場合は、`NCHAR` 型を選択できます。

`NCHAR` を使用してデータを保存する場合、保存されたデータが指定された長さに達していない場合、データベースは自動的にスペースを埋めます。指定長は `CHAR` を計量単位とし、他の単位を手動で指定することはできません。
