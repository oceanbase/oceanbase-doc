# NCHARデータ型

NCHARはUNICODE文字データ型であり、長さは固定されています。本記事では主にNCHARデータ型の構文、パラメータ、および使用方法について説明します。

## 構文

```sql
NCHAR[(size)]
```

## パラメータ

|   パラメータ   |                                        説明                                        |
|--------|----------------------------------------------------------------------------------|
| `size` | 固定長文字データの長さを表します。最大サイズは国別文字セットによって決定され、上限は2000バイトです。デフォルトでは固定長文字データの長さは最小でも1文字です。 |

## 使用方法

データベースを作成する際、列の最大長は国別文字セットによって決定されます。`NCHAR`データ型の列を含むテーブルを作成する場合、文字で列の長さを定義します。文字データ型`NCHAR`の幅の仕様とは、文字数を指します。許容される最大列サイズは2000バイトです。

中国語をより少ないスペースで保存したい場合は、`NCHAR`タイプを選択できます。

`NCHAR`を使用してデータを保存する場合、保存されたデータが指定された長さに達していない場合、データベースは自動的にスペースを補います。指定された長さは`CHAR`を単位とし、他の単位を手動で指定することはできません。
