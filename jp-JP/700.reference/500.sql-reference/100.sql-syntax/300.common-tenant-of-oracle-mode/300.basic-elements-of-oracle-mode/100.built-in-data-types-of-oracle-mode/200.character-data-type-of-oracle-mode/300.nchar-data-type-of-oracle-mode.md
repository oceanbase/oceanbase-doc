# NCHARデータ型

NCHARは固定長のUNICODE文字データ型です。本記事では、主にNCHARデータ型の構文、パラメータ、使用方法について説明します。

## 構文

```sql
NCHAR[(size)]
```

## パラメータ

|   パラメータ   |                                        説明                                        |
|--------|----------------------------------------------------------------------------------|
| `size` | 固定長文字データの長さを表します。最大サイズは各国語文字セットの定義によって決まり、上限は2000バイトです。デフォルトの長さは1文字で、これが最小値です。 |

## 使用方法

データベース作成時に、列の最大長は各国語文字セットの定義によって決まります。`NCHAR` データ型の列を含むテーブルを作成する際は、文字単位で列の長さを定義します。`NCHAR` の幅は文字数で表します。許容される最大列サイズは2000バイトです。

中国語の文字列をより少ない記憶領域で格納したい場合は、`NCHAR` 型を選択できます。

`NCHAR` の列に格納するデータが指定した長さより短い場合、データベースは不足分を自動的に空白で埋めます。長さの単位は文字（`CHAR`）で、他の単位は指定できません。
