# NVARCHAR2データ型

NVARCHAR2はUNICODE文字データ型です。本記事では主にNVARCHAR2データ型の構文、パラメータ、使用方法について説明します。

## 構文

```sql
NVARCHAR2(size)
```

## パラメータ

|  パラメータ  |                                                              説明                                                              |
|------|------------------------------------------------------------------------------------------------------------------------------|
| size | 列の長さを表し、可変長です。`size` は文字数であり、`size` 文字の合計サイズは32767バイトを超えてはなりません。`NVARCHAR2` にはサイズを指定する必要があります。AL16UTF16エンコーディングでは最大で文字数の2倍、UTF8エンコーディングでは最大で文字数の3倍のバイト数となります。バイト数の上限は32767バイトで、これは国別文字セットによって定義されます。 |

## 使用方法

`NVARCHAR2` データ型の列の長さは可変で、最大ストレージ長は32767バイト、最小値は1バイトです。`NVARCHAR2` データ型の列を含むテーブルを作成する際には、`NVARCHAR2` が収容できる最大文字数を指定する必要があります。デフォルトでは `CHAR` が測定単位として使用され、他の単位を手動で指定することはできません。

格納するデータの長さが不確定で、中国語を含む可能性がある場合は、`NVARCHAR2` 型を選択できます。
