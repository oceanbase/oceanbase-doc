# NVARCHAR2 データ型

NVARCHAR2 は UNICODE 文字データ型です。本記事では主に NVARCHAR2 データ型の構文、パラメータ、使用方法について説明します。

## 構文

```sql
NVARCHAR2(size)
```

## パラメータ

| パラメータ |                                                              説明                                                              |
|------|------------------------------------------------------------------------------------------------------------------------------|
| size | 列の長さを表します。可変長です。`size` は文字数であり、`size` 文字の合計サイズは32,767バイトを超えてはなりません。`NVARCHAR2` にはサイズを指定する必要があります。AL16UTF16エンコーディングでは、バイト数の上限はその2倍となり、UTF8エンコーディングでは最大3倍となります。バイト数の上限は国別文字セットによって定義され、最大で32,767バイトです。 |

## 使用方法

`NVARCHAR2` データ型の列の長さは可変で、最大ストレージ長は 32,767 バイト、最小値は 1 バイトです。`NVARCHAR2` データ型の列を含むテーブルを作成する際には、`NVARCHAR2` が収容できる最大文字数を指定する必要があります。デフォルトでは `CHAR` を計量単位として使用し、他の単位を手動で指定することはできません。

保存するデータの長さが不確定で、マルチバイト文字を含む可能性がある場合は、`NVARCHAR2` 型を選択できます。
