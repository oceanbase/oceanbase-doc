# NVARCHAR2データ型

NVARCHAR2はUNICODE文字データ型です。本記事では主にNVARCHAR2データ型の構文、パラメータ、使用方法について説明します。

## 構文

```sql
NVARCHAR2(size)
```

## パラメータ

| パラメータ |                                                              説明                                                              |
|------|------------------------------------------------------------------------------------------------------------------------------|
| size | 列の長さを表し、可変長です。`size` は文字数であり、`size` 文字の合計サイズは32767バイトを超えてはなりません。`NVARCHAR2` にはサイズを指定する必要があります。AL16UTF16エンコーディングの場合、最大バイト数は2倍、UTF8エンコーディングの場合は最大バイト数は3倍となります。バイト数の上限は32767バイトです。 |

## 使用方法

`NVARCHAR2` データ型の列の長さは可変で、最大ストレージ長は32767バイト、最小値は1バイトです。`NVARCHAR2` データ型の列を含むテーブルを作成する際には、`NVARCHAR2` に収容可能な最大文字数を指定する必要があります。デフォルトでは `CHAR` を単位として使用され、他の単位を手動で指定することはできません。

保存するデータの長さが不明であり、中国語を含む可能性がある場合は、`NVARCHAR2` タイプを選択できます。
