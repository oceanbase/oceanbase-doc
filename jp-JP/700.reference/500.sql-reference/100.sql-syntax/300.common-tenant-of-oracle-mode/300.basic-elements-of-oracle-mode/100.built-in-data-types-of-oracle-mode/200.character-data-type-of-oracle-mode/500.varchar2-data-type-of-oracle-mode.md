# VARCHAR2データ型

VARCHAR2データ型は、可変長の文字列を格納します。この記事では、主にVARCHAR2データ型の構文、パラメータ、使用方法について説明します。

## 構文

```sql
VARCHAR2(size [BYTE | CHAR])
```

## パラメータ説明

|  パラメータ  |         説明         |
|------|--------------------|
| size | グループ内で格納されるバイト数または文字数の長さを表します。 |
| BYTE | バイト単位で列の長さを指定します。`VARCHAR2` のデフォルトタイプは `BYTE` です。 |
| CHAR | 文字単位で列の長さを指定します。    |

## 使用方法

`VARCHAR2` データ型の最大長は32,767です。`VARCHAR2` 列を作成する際には、その列の最大長を指定する必要があります。実際に格納可能な文字列は長さゼロの文字列（''）でもかまいませんが、この最大値は少なくとも1バイトである必要があります。OceanBaseデータベースは、各文字値を指定された方法で`VARCHAR2`列に完全に格納します。

`VARCHAR2` データ型では、`CHAR` 指定子を使用して文字単位での最大長を指定することができます。例：`VARCHAR2(10 CHAR)`。`VARCHAR2` データ型では、`BYTE` 指定子を使用してバイト単位で最大長を明示的に指定することもできます。例：`VARCHAR2(10 BYTE)`。
