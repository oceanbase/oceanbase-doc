# BLOBデータ型

BLOBとはBinary Large Objectの略です。本記事では主にBLOBの使用方法について説明します。

## BLOBの使用方法

`BLOB`は、データベース内の大規模なバイナリオブジェクトを格納するために使用されます。`BLOB`オブジェクトは、文字セットの意味を持たないビットストリームと見なすことができます。`BLOB`に格納されるバイナリデータの最大長は536870910バイトであり、文字セットは`BINARY`です。

データベースでは、通常、画像、ファイル、音楽などの大きなファイル情報は`BLOB`フィールドを使用して格納されます。これは、まず大きなファイルをバイナリ形式に変換してから格納します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>格納されるバイナリファイルが大きすぎると、データベースのパフォーマンスが低下します。</p>
  </main>

`BLOB`オブジェクトは完全なトランザクションサポートを備えています。SQLやDBMS_LOBシステムパッケージを使用した変更はトランザクションに含まれ、`BLOB`値のコミットおよびロールバック操作がサポートされます。ただし、あるトランザクションでBLOB LocatorをPLに保存し、別のトランザクションまたはセッションでそれを使用することはできません。

## 例

テーブル`blob_tbl`を作成し、`blob_col`列を`BLOB`データ型に設定します。

```sql
obclient> CREATE TABLE blob_tbl (blob_col BLOB);
Query OK, 0 rows affected
```
