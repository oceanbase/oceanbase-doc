# 浮動小数点数

浮動小数点数（FLOAT-Point Numbers）には小数点をどの桁に置くことも、省略することもできます。この記事では、主に浮動小数点数の構文、パラメータ、使用方法について説明します。

## 構文

OceanBaseデータベースでは、浮動小数点数に対して2種類の数値データ型を提供しています：

* `BINARY_FLOAT`は、32ビット単精度浮動小数点数データ型です。各`BINARY_FLOAT`値は4バイトを必要とします。

* `BINARY_DOUBLE`は、64ビット倍精度浮動小数点数データ型です。各`BINARY_DOUBLE`値は8バイトを必要とします。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>NUMBER</code>列では、浮動小数点数は10進精度を持ちます。</li>
    <li><code>BINARY_FLOAT</code>または<code>BINARY_DOUBLE</code>列では、浮動小数点数は2進精度を持ちます。</li>
    </ul>
  </main>

## 値の範囲

次の表に示す範囲で、浮動小数点数を指定できます。

| 値               | BINARY_FLOAT  |    BINARY_DOUBLE     |
|------------------|---------------|----------------------|
| 最大正有限値      | 3.40282E+38F  | 1.79769313486231E+308|
| 最小正有限値      | 1.17549E-38F  | 2.22507485850720E-308|

## 使用方法

浮動小数点数では、数値の後に指数を付けることで表現範囲を広げることができます。例：1.666 e-20。小数点以下の桁数は浮動小数点数には適用されません。これは、小数点以下の桁数が固定されていないためです。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>2進浮動小数点数とNUMBERの違いは、値の格納方法にあります。OceanBaseデータベース内部では、2進浮動小数点数は2進精度（0と1のみ）で格納されます。一方、NUMBERデータ型は10進精度で格納され、保存されるデータはすべて正確に保持されます。2進浮動小数点数（FLOAT-Point Numbers）は、10進精度で表現できるすべての値を正確に表現することはできません。</p>
  </main>

## IEEE754準拠

* IEEE標準754-1985（IEEE754）

  OceanBaseデータベースの浮動小数点データ型の実装は、基本的に電気・電子技術者協会（IEEE）の二進浮動小数点アルゴリズム標準に準拠しています。

* 浮動小数点データ型は、以下の点でIEEE754に準拠しています：

  * SQL 関数 SQRT は平方根を求めます。
  * SQL 関数 REMAINDER は剰余を求めます。
  * 算術演算子が一致しています。
  * 比較演算子が要件を満たしています。
  * 変換演算子が一致しています。
  * デフォルトの丸めモードをサポートしています。
  * デフォルトの例外処理モードをサポートしています。
  * OceanBaseデータベースは、現在INF、-INF、NaN、BINARY_FLOAT_NAN、BINARY_DOUBLE_NANなどの特殊定数をサポートしていません。
  * SQL関数ROUND、TRUNC、CEIL、FLOORは、二進浮動小数点数BINARY_FLOAT、BINARY_DOUBLEを、それぞれの型を保ったまま整数値に丸めます。
  * SQL関数TO_CHAR、TO_NUMBER、TO_NCHAR、TO_BINARY_FLOAT、TO_BINARY_DOUBLE、CASTは、二進浮動小数点数BINARY_FLOAT、BINARY_DOUBLEと10進数の間で、丸めを伴う変換を行います。

* 浮動小数点データ型は、以下の点でIEEE754に準拠していません：

  * -0は+0に強制的に変換されます。
  * NaNとの比較はサポートされていません。
  * デフォルト以外の丸めモードはサポートされていません。
  * デフォルト以外の例外処理モードはサポートされていません。
