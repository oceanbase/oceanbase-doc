# 数値データ型の概要

数値型は、固定小数点数、浮動小数点数、およびゼロを格納するために使用されます。OceanBaseデータベースは、NUMBER、FLOAT、BINARY_FLOAT、BINARY_DOUBLEの4種類の数値データ型をサポートしています。このドキュメントでは、OceanBaseデータベースの現在のバージョンでサポートされているデータ型の概要を説明します。

数値計算において、数値型には異なる優先順位があります。詳細については、[数値型の優先順位](../300.numeric-data-type-of-oracle-mode/500.numeric-priority-of-oracle-mode.md)を参照してください。

OceanBaseデータベースの現在のバージョンでサポートされている数値データ型の関連情報は、次の表のとおりです。

|   **データ型**    | 長さタイプ | **長さ(バイト)** |                       **使用上の注意**                       |
|---------------|------|------------|------------------------------------------------------|
| NUMBER(p,s)   | 可変長 | \[4,40\]   | 可変長の10進数精度の固定小数点数を格納します。浮動小数点数も格納できますが、この場合 `NUMBER` には `p` および `s` パラメータがありません。 |
| FLOAT(p)      | 可変長 | \[4,40\]   | `NUMBER` データ型のサブタイプです。2進数精度の範囲は \[1,126\] です。`FLOAT` は浮動小数点数ではありません。  |
| BINARY_FLOAT  | 固定長 | 4          | 2進数精度の浮動小数点数であり、32ビット単精度浮動小数点数データ型です。                         |
| BINARY_DOUBLE | 固定長 | 8          | 2進数精度の浮動小数点数であり、64ビット倍精度浮動小数点数データ型です。                         |
