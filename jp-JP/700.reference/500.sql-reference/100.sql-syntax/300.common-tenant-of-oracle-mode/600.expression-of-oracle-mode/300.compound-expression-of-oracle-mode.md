# 複合式

複合式（Compound Expression）とは、さまざまな種類の式を組み合わせた式です。

複合式の構文は以下のとおりです：

```sql
{ (expr)
| { + | - | PRIOR } expr
| expr { * | / | + | - | || } expr
}
```

ここで、`PRIOR` 演算子は階層クエリの `CONNECT BY` 句で使用されます。

任意の組み込み関数を式として使用できます。ただし、複合式において、一部の関数の組み合わせは不適切とされ、非推奨となっています。例えば、`LENGTH()` 関数は集約関数としては使用できません。

以下は有効な複合式の例です：

* `('WELL' || 'SMITH')`

* `LENGTH('OCEAN1BASE') * 17`

* `SORT(221) + 32`

* `my_func(TO_CHAR(sysdate, 'DD-MMM-YY'))`
