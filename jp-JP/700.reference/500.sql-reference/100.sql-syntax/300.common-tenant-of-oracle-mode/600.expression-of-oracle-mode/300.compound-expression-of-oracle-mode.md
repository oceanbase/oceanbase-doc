# 複合式

複合式（Compound Expression）とは、複数の種類の式を組み合わせて作成される式です。

複合式の構文は以下のとおりです：

```sql
{ (expr)
| { + | - | PRIOR } expr
| expr { * | / | + | - | || } expr
}
```

ここで、`PRIOR` 演算子は階層クエリの `CONNECT BY` 句で使用されます。

任意の組み込み関数を式として使用できます。ただし、複合式においては、一部の関数の組み合わせが不適切であるため、使用が禁止されています。例えば、`LENGTH()` 関数は集計関数としては適していません。

以下は有効な複合式の例です：

* `('WELL' || 'SMITH')`

* `LENGTH('OCEAN1BASE') * 17`

* `SORT(221) + 32`

* `my_func(TO_CHAR(sysdate, 'DD-MMM-YY'))`
