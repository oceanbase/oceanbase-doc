# SQL式の概要

式はデータの値を計算するために使用され、1つまたは複数の数値、演算子、およびSQL関数などで構成されます。

式は通常、そのコンポーネントのデータ型を採用します。例えば、`2*2` は単純な式であり、計算結果は4で、データ型は `NUMBER` です（コンポーネントのデータ型と一致しています）。

以下は、関数と演算子を使用した複雑な式です。この式は、現在の日付に7日を加え、時間部分を削除し、最後に結果を `CHAR` データ型に変換することを示します。

```sql
TO_CHAR(TRUNC(SYSDATE+7))
```

式の一般的な使用シナリオは以下のとおりです：

* `SELECT` ステートメントの選択列。

* `WHERE` 句と `HAVING` 句。

* `CONNECT BY`、`START WITH` および `ORDER BY` 句。

* `INSERT` ステートメントの `VALUES` 句。

* `UPDATE` ステートメントの `SET` 句。

例えば、次の `UPDATE` ステートメントの `SET` 句では、文字列 `Smith` を式で置き換えることができます：

```sql
SET last_name = 'Smith';
```

`SET` 句で式 `INITCAP(last_name)` を使用して、文字列 `Smith` を置き換えます：

```sql
SET last_name = INITCAP(last_name);
```
