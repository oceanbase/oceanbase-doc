# 簡単な式

単純な式（Simple Expressions）は、列、仮列、定数、シーケンス番号、またはNULL値です。

単純な式の構文は次のとおりです：

```sql
{ [ query_name.
  | [schema.]
    { table. | view. | materialized view. }
  ] { column | ROWID }
| ROWNUM
| string
| number
| sequence. { CURRVAL | NEXTVAL }
| NULL
}
```

ユーザースキーマに加えて、`schema` は二重引用符で囲んだ `"PUBLIC"` も指定でき、これはテーブルやビューなどを指すために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li><strong>PUBLIC</strong> はデータ操作言語（DML）ステートメントでのみパブリックシノニムとして使用でき、データ定義言語（DDL）ステートメントではサポートされません。</li>
    <li><code>NCHAR</code> と <code>NVARCHAR2</code> は有効な仮列データ型ではありません。</li>
    </ul>
  </main>

以下は有効な単純な式の例です：

* `employees.first_name`

* `'welcome to OceanBase'`

* `10`

* `3*3`
