# シンプルな式

シンプルな式（Simple Expressions）とは、列、擬似列、定数、シーケンス番号、またはNULL値を指します。

シンプルな式の構文は以下のとおりです：

```sql
{ [ query_name.
  | [schema.]
    { table. | view. | materialized view. }
  ] { column | ROWID }
| ROWNUM
| string
| number
| sequence. { CURRVAL | NEXTVAL }
| NULL
}
```

ユーザースキーマに加えて、`schema` は「"PUBLIC"`（ダブルクォーテーションマークが必要）である場合もあり、テーブルやビューなどを指定するために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li><strong>PUBLIC</strong> を共通語として使用できるのは、データ操作言語（DML）ステートメントのみであり、データ定義言語（DDL）ステートメントではサポートされていません。</li>
    <li><code>NCHAR</code> と <code>NVARCHAR2</code> は有効な擬似列データ型ではありません。</li>
    </ul>
  </main>

以下は有効なシンプルな式の例です：

* `employees.first_name`

* `'welcome to OceanBase'`

* `10`

* `3*3`
