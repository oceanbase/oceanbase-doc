# INSERT

## 説明

このステートメントは、テーブルに1つまたは複数のレコードを追加するために使用されます。

## 権限要件

`INSERT` ステートメントを実行するには、現在のユーザーが `INSERT` のシステム権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
INSERT [hint_options] { single_table_insert | multi_table_insert }

single_table_insert:
    { INTO insert_table_clause { NOLOGGING | /*EMPTY*/ } '(' column_list ')' values_clause [{ RETURNING | RETURN } returning_exprs [into_clause]]
    | INTO insert_table_clause { NOLOGGING | /*EMPTY*/ } '(' ')' values_clause [{ RETURNING | RETURN } returning_exprs [into_clause]]
    | INTO insert_table_clause { NOLOGGING | /*EMPTY*/ } values_clause [{ RETURNING | RETURN } returning_exprs [into_clause]]
    }

hint_options:
    [/*+ [APPEND | DIRECT(bool, int, load_mode)] enable_parallel_dml PARALLEL(N) | NO_DIRECT */]
    [INTO] table_name [PARTITION(PARTITION_OPTION)]

column_list:
      column_definition_ref [, column_definition_ref...]

returning_exprs:
    projection_col_name [,projection_col_name ...]

insert_into_clause:
    { INTO into_var_list | BULK COLLECT INTO into_var_list}

into_var_list:
    { USER_VARIABLE | ref_name } [, { USER_VARIABLE | ref_name }...]

values_clause:
    VALUES ({ expr | DEFAULT } [, { expr | DEFAULT } ]...  )

returning_exprs:
      projection [, projection...]

multi_table_insert:
    { ALL { insert_into_clause [ values_clause ] [error_logging_clause] }
    | conditional_insert_clause
    } subquery

conditional_insert_clause:
    [ ALL | FIRST ]
    WHEN condition
    THEN insert_into_clause
    [ values_clause ]
    [ error_logging_clause ]
    [ insert_into_clause [ values_clause ] [ error_logging_clause ] ]...
    [ WHEN condition
        THEN insert_into_clause
        [ values_clause ]
        [ error_logging_clause ]
        [ insert_into_clause [ values_clause ] [ error_logging_clause ] ]...
    ]...
    [ ELSE insert_into_clause
        [ values_clause ]
        [ error_logging_clause ]
        [ insert_into_clause [ values_clause ] [ error_logging_clause ] ]...
    ]

error_logging_clause:
    LOG ERRORS [ INTO [schema.] table_name ] [ (simple_expression) ] [ REJECT LIMIT { integer | UNLIMITED } ]
```

## パラメータの説明

## パラメータの説明

|            パラメータ             |                                                                                                        説明                                                                                                         |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| hint_options              | オプションのHintオプションを指定します。クエリの実行計画を最適化するために使用されます。                                                                                                                                                                                                  |
| single_table_insert       | 単一テーブルへの挿入。主にデータを1つのテーブルに挿入するために使用されます。                                                                                                                                                                                                         |
| multi_table_insert        | 複数テーブルへの挿入。複数のテーブルにデータを挿入でき、条件付き挿入の柔軟性をサポートします。                                                                                                                                                                                            |
| insert_table_clause       | データを挿入するターゲットテーブルを指定します。ベーステーブル、更新可能なビュー、または特殊なサブクエリを指定できます。  <main id="notice" type='notice'><h4>注意</h4><p>特殊なサブクエリとは、更新可能なビューに対応するサブクエリのようなものです。このようなサブクエリには、複雑な演算子（<code>GROUP BY</code>、<code>DISTINCT</code>、<code>WINDOW FUNCTION</code>など）を含めないでください。</p></main>                                                                                                                                                                                      |
| opt_nologging             | オプションパラメータ。挿入時のログレコードを削減してパフォーマンスを向上させることができますが、障害復旧時にデータが失われる可能性があります。                                                                                                                                                                               |
| column_list               | 指定する列名のリストで、挿入操作が依存する具体的な列を定義します。                                                                                                                                                                                                         |
| values_clause             | 挿入する具体的な値を定義し、式やデフォルト値を使用して列を埋めることができます。                                                                                                                                                                                                  |
| returning_exprs           | 挿入後に返す列を指定するために使用され、挿入操作で新しく挿入された行の情報を取得できます。                                                                                                                                                                                             |
| insert_into_clause        | 挿入する列値を指定するために使用され、具体的な列名と対応する値のセットにすることができます。                                                                                                                                                                                          |
| into_var_list             | 挿入結果を受け取る変数のリストを指定します。ユーザー定義の変数または参照名にすることができます。                                                                                                                                                                                              |
| conditional_insert_clause | 条件付きの複数テーブルへの挿入で、設定した条件に基づいてデータをどのターゲットテーブルに挿入するかを動的に決定できます。<ul><li> `ALL`: 一致するすべての条件のブランチをイテレーションし、条件を満たすデータを対応するテーブルに挿入します。</li><li> `FIRST`: 条件を満たす最初のブランチを見つけた後、そのテーブルにデータを挿入し、以降の条件を確認しません。</li></ul>    |
| error_logging_clause      | 挿入処理中のエラーをどのように処理するかを定義し、SQLエラーと影響を受けた行の情報をエラーレコードテーブルに記録します。<ul><li> `LOG ERRORS`: エラー記録を有効にします。</li><li> `INTO` : エラーレコードテーブル名を指定します。</li><li> `(simple_expression)`: オプションの式で、エラー記録の詳細情報を示します。</li><li> `REJECT LIMIT`: 許容されるエラー数の制限を設定します。</li></ul> |
| NOLOGGING	   |   挿入性能を最適化し、ログレコードを削減することで挿入速度を向上させます。通常は大量データの挿入に使用されます。|

## 例

サンプルテーブルとデータは以下の定義に基づいています：

```shell
obclient> CREATE TABLE tbl(col1 INT PRIMARY KEY, col2 INT,col3 INT);
Query OK, 0 rows affected

obclient> CREATE TABLE tbl2(col1 INT PRIMARY KEY, col2 INT,col3 INT);
Query OK, 0 rows affected

obclient> CREATE TABLE tbl3(col1 INT PRIMARY KEY, col2 INT,col3 INT);
Query OK, 0 rows affected
```

* 単一テーブルへの挿入：テーブル `tbl1` に2行のデータを挿入します。

  ```shell
  obclient> INSERT INTO tbl1 (col1, col2, col3) VALUES (1, 10, 100), (2, 20, 200);
  Query OK, 2 row affected

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  +------+------+------+
  2 rows in set
  ```

* 単一テーブルへの挿入：直接サブクエリにデータを挿入します。

  ```shell
  obclient>INSERT INTO tbl1 (col1, col2, col3) SELECT col1 + 2, col2 + 5, col3 + 10 FROM tbl1;
  Query OK, 2 row affected

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  +------+------+------+
  4 rows in set
  ```

* 単一テーブルへの挿入：`RETURNING` 句を含みます。

  ```shell
  obclient> INSERT INTO tbl1 (col1, col2, col3) VALUES (5, 50, 500), (6, 60, 600) RETURNING col1;
  +------+
  | COL1 |
  +------+
  |    5 |
  |    6 |
  +------+
  2 rows in set

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  +------+------+------+
  6 rows in set
  ```

* 通常の複数テーブルへの挿入：テーブル `tbl3` に少なくとも1行のデータがある場合、テーブル `tbl1` に1行のデータ (7,8,9) を挿入し、テーブル `tbl2` に1行のデータ (10,11,12) を挿入します。

  ```shell
  obclient> INSERT ALL INTO tbl1 VALUES(7,8,9)
                                      INTO tbl2 VALUES(10,11,12)
                  SELECT * FROM tbl3 WHERE ROWNUM< 2;
  Query OK, 2 rows affected
  Records: 2  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  |    7 |    8 |    9 |
  +------+------+------+
  7 rows in set

  obclient> SELECT * FROM tbl2;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |   10 |   11 |   12 |
  +------+------+------+
  1 row in set
  ```

* 条件付きの複数テーブルへの挿入：`INSERT ALL` を使用して、テーブル `tbl` の `col2` の値が `1` より大きい場合、テーブル `tbl1` にデータ (10,11,12) を挿入します。テーブル `tbl` の `col3` の値が `1` より大きい場合、テーブル `tbl2` にデータ (22,23,24) を挿入します。どちらの条件も満たされない場合は、テーブル `tbl1` にデータ (33,34,35) を挿入します。

  ```shell
  obclient> INSERT INTO tbl VALUES(1,2,3);
  Query OK, 1 row affected

  obclient>INSERT ALL
                WHEN col2 > 1 THEN INTO tbl1 VALUES(10,11,12)
                WHEN col3 > 1 THEN INTO tbl2 VALUES(22,23,24)
                ELSE INTO tbl1 VALUES(33,34,35) SELECT col2,col3 FROM tbl;
  Query OK, 2 rows affected
  Records: 2  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  |    7 |    8 |    9 |
  |   10 |   11 |   12 |
  +------+------+------+
  8 rows in set

  obclient> SELECT * FROM tbl2;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |   10 |   11 |   12 |
  |   22 |   23 |   24 |
  +------+------+------+
  2 rows in set
  ```

* 条件付きの複数テーブルへの挿入：`INSERT FIRST` を使用して、テーブル `tbl` の `col2` の値が `1` より大きい場合、テーブル `tbl1` にデータ (14,15,16) を挿入し、テーブル `tbl2` にデータ (40,41,42) を挿入します。テーブル `tbl` の `col3` の値が `1` より大きい場合、テーブル `tbl2` にデータ (25,26,27) を挿入します。どちらの条件も満たされない場合は、テーブル `tbl1` にデータ (35,36,37) を挿入します。

  ```shell
  obclient>INSERT ALL
                WHEN col2 > 1 THEN INTO tbl1 VALUES(14,15,16) INTO tbl2 VALUES(40,41,42)
                WHEN col3 > 1 THEN INTO tbl2 VALUES(25,26,27)
                ELSE INTO tbl1 VALUES(35,36,37) SELECT col2,col3 FROM tbl;
  Query OK, 3 rows affected
  Records: 3  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  |    7 |    8 |    9 |
  |   10 |   11 |   12 |
  |   14 |   15 |   16 |
  +------+------+------+
  9 rows in set

  obclient> SELECT * FROM tbl2;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |   10 |   11 |   12 |
  |   22 |   23 |   24 |
  |   25 |   26 |   27 |
  |   40 |   41 |   42 |
  +------+------+------+
  4 rows in set
  ```
