# INSERT

## 説明

このステートメントは、テーブルに1つまたは複数のレコードを追加するために使用されます。

## 権限要件

`INSERT` ステートメントを実行するには、現在のユーザーが `INSERT` システム権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
INSERT [hint_options] { single_table_insert | multi_table_insert | overwrite_table_insert};

single_table_insert:
    { INTO insert_table_clause { NOLOGGING | /*EMPTY*/ } '(' column_list ')' values_clause [{ RETURNING | RETURN } returning_exprs [into_clause]]
    | INTO insert_table_clause { NOLOGGING | /*EMPTY*/ } '(' ')' values_clause [{ RETURNING | RETURN } returning_exprs [into_clause]]
    | INTO insert_table_clause { NOLOGGING | /*EMPTY*/ } values_clause [{ RETURNING | RETURN } returning_exprs [into_clause]]
    }

hint_options:
    [/*+ [APPEND | DIRECT(bool, int, load_mode)] enable_parallel_dml PARALLEL(N) | NO_DIRECT */]
    [INTO] table_name [PARTITION(PARTITION_OPTION)]

column_list:
      column_definition_ref [, column_definition_ref...]

returning_exprs:
    projection_col_name [,projection_col_name ...]

insert_into_clause:
    { INTO into_var_list | BULK COLLECT INTO into_var_list}

into_var_list:
    { USER_VARIABLE | ref_name } [, { USER_VARIABLE | ref_name }...]

values_clause:
    VALUES ({ expr | DEFAULT } [, { expr | DEFAULT } ]...  )

returning_exprs:
    projection_col_name [,projection_col_name ...]

multi_table_insert:
    { ALL { insert_into_clause [ values_clause ] [error_logging_clause] }
    | conditional_insert_clause
    } subquery

conditional_insert_clause:
    [ ALL | FIRST ]
    WHEN condition
    THEN insert_into_clause
    [ values_clause ]
    [ error_logging_clause ]
    [ insert_into_clause [ values_clause ] [ error_logging_clause ] ]...
    [ WHEN condition
        THEN insert_into_clause
        [ values_clause ]
        [ error_logging_clause ]
        [ insert_into_clause [ values_clause ] [ error_logging_clause ] ]...
    ]...
    [ ELSE insert_into_clause
        [ values_clause ]
        [ error_logging_clause ]
        [ insert_into_clause [ values_clause ] [ error_logging_clause ] ]...
    ]

error_logging_clause:
    LOG ERRORS [ INTO [schema.] table_name] [ (simple_expression) ] [ REJECT LIMIT { integer | UNLIMITED } ]

overwrite_table_insert:
    [/*+PARALLEL(N)*/] OVERWRITE table_name [(list_of_columns)] [PARTITION (partition_name, ...)] select_stmt
```

## パラメータの説明

|            パラメータ           |                            説明                                      |
|---------------------------|---------------------------------------------------------------------|
| hint_options              | Hintを使用してダイレクトロード機能を有効にします。オプションです。Hintの詳細については、[Hintの概要](../../300.basic-elements-of-oracle-mode/600.annotation-of-oracle-mode/400.hint-of-oracle-mode/100.hint-overview-of-oracle-mode.md)を参照してください。<main id="notice" type='notice'><h4>注意</h4><p>ダイレクトロードタスクの実行中は、OceanBaseデータベースのアップグレード操作を同時に行うことは推奨されません。これにより、ダイレクトロードタスクが失敗する可能性があります。</p></main> `INSERT INTO SELECT` ステートメントは、`APPEND \| DIRECT()\| NO_DIRECT` Hintを使用してデータのインポート方法を制御できます。形式は `/*+ [APPEND \| DIRECT(bool, int, load_mode)] enable_parallel_dml PARALLEL(N) \| NO_DIRECT */` です。Hint内の各パラメータの説明は以下の通りです：<ul><li><code>APPEND</code>：デフォルトでは <code>DIRECT(true, 0)</code> と同等ですが、オンライン統計情報収集（</code>GATHER_OPTIMIZER_STATISTICS</code> Hint）の機能も実現します。</li><li><code>DIRECT()</code>：<ul><li><code>bool</code>：書き込むデータのソートが必要かどうかを示します。<code>true</code> はソートが必要、<code>false</code> はソート不要を意味します。</li><li><code>int</code>：許容される最大誤り行数を示します。</li><li><code>load_mode</code>：オプションパラメータで、ダイレクトロードのモードを示します。値は英字のシングルクォートで囲む必要があります。取り得る値は以下の通りです：<ul><li><code>full</code>：デフォルト値で、全量インポートを示します。</li><li><code>inc</code>：増分インポートを示し、<code>INSERT</code> および <code>IGNORE</code> のセマンティクスをサポートします。</li><li><code>inc_replace</code>：増分インポートを示しますが、主キーの重複チェックは行いません。<code>REPLACE</code> のセマンティクスに相当する増分インポートです。</li></ul> </li><li><code>enable_parallel_dml parallel(N)</code>：データロードの並列度で、<code>N</code> のデフォルト値は4です。<main id="notice" type='explain'><h4>説明</h4><p>通常、<code>enable_parallel_dml</code> Hintと<code>parallel</code> Hintは併用して並列DMLを有効にする必要があります。ただし、対象テーブルのスキーマでテーブルレベルの並列度が指定されている場合は、<code>enable_parallel_dml</code> Hintのみを指定する必要があります。</p></main></li></ul><li><code>NO_DIRECT</code>：単一のSQLに対してダイレクトロードを強制的に無視させます。入力されたSQLにこのHintが含まれている場合、そのステートメント全体が他のダイレクトロードHintを無視し、通常のインポートが実行されます。</li></ul>`INSERT INTO SELECT` ダイレクトロードの詳細については、[INSERT INTO SELECTステートメントを使用したデータのダイレクトロード](../../../../../../620.obap/300.obap-data-transfer/300.data-import/200.load-data-import.md)を参照してください。|
| table_name                       | データをインポートするテーブル名。任意の数の列を指定できます。  |
| PARTITION_OPTION                   | パーティションダイレクトロード時のパーティション名を指定します：<ul><li>partition_option_list：パーティションリスト。複数のパーティションを一度に挿入する場合は、カンマ（,）で区切ります。 </ li> <li>subpartition_option_list：サブパーティションリスト。複数のサブパーティションを一度に挿入する場合は、カンマ（,）で区切ります。</li></ul>|
| single_table_insert       | 単一テーブルへの挿入。                                                                                                                                                                                                             |
| insert_table_clause       | 指定する挿入テーブル。ベーステーブル、更新可能なビュー、特殊なサブクエリが可能です。   <main id="notice" type='notice'><h4>注意</h4><p>特殊なサブクエリとは、更新可能なビューに対応するサブクエリのようなものを指します。この種のサブクエリには、複雑な演算子（例えば <code>GROUP BY</code>、<code>DISTINCT</code>、<code>WINDOW FUNCTION</code> など）を含めないでください。                                                                                                                                                                                      |
| opt_nologging             | 挿入時のログ情報を可能な限り削減します。                                                                                                                                                                                                     |
| column_list               | 指定する列名を挿入します。                                                                                                                                                                                                         |
| returning_exprs           | データ挿入後の投影列を返します。                                                                                                                                                                                                     |
| insert_into_clause        | データ挿入後の列値を指定されたリストに挿入します。                                                                                                                                                                                               |
| multi_table_insert        | 複数テーブルへの挿入。                                                                                                                                                                                                             |
| conditional_insert_clause | 条件付きの複数テーブルへの挿入。 <ul><li> `ALL`：すべての条件に一致するブランチを走査し、条件を満たせば対応するテーブルにデータを挿入します。   </li><li> `FIRST`：最初に条件を満たすブランチを見つけたら、そのブランチに対応するテーブルにデータを挿入し、残りのブランチの条件をチェックすることはありません。</li></ul>    |
| error_logging_clause      | SQLエラーと影響を受けた行数の列の値をエラーレコードテーブルに保存します。                                                                                                                                                                                    |
| overwrite_table_insert  | クエリ結果でテーブルまたはパーティション内の既存データを上書きします。`INSERT OVERWRITE SELECT` ステートメントの使用方法の詳細については、[データの挿入](../../../../../../300.develop/200.application-development-of-oracle-mode/400.write-data-of-oracle-mode/100.insert-data-of-oracle-mode-in-develop.md)の **INSERT OVERWRITE SELECTステートメントを使用したデータの挿入** セクションを参照してください。|
| list_of_columns   | データを挿入するテーブルの列を指定します。                     |
| select_stmt             | `SELECT` 句を指定します。クエリステートメントの詳細については、[SIMPLE SELECT](500.select-of-oracle-mode/100.simple-select-of-oracle-mode.md)を参照してください。|

## 例

サンプルテーブルとデータは以下の定義に基づいています：

```shell
obclient> CREATE TABLE tbl(col1 INT PRIMARY KEY, col2 INT,col3 INT);
Query OK, 0 rows affected

obclient> CREATE TABLE tbl2(col1 INT PRIMARY KEY, col2 INT,col3 INT);
Query OK, 0 rows affected

obclient> CREATE TABLE tbl3(col1 INT PRIMARY KEY, col2 INT,col3 INT);
Query OK, 0 rows affected
```

* 単一テーブルへの挿入：テーブル `tbl1` に2行のデータを挿入します。

  ```shell
  obclient> INSERT INTO tbl1 (col1, col2, col3) VALUES (1, 10, 100), (2, 20, 200);
  Query OK, 2 row affected

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  +------+------+------+
  2 rows in set
  ```

* 単一テーブルへの挿入：サブクエリに直接データを挿入します。

  ```shell
  obclient>INSERT INTO tbl1 (col1, col2, col3) SELECT col1 + 2, col2 + 5, col3 + 10 FROM tbl1;
  Query OK, 2 row affected

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  +------+------+------+
  4 rows in set
  ```

* 単一テーブルへの挿入：`RETURNING` 句を含みます。

  ```shell
  obclient> INSERT INTO tbl1 (col1, col2, col3) VALUES (5, 50, 500), (6, 60, 600) RETURNING col1;
  +------+
  | COL1 |
  +------+
  |    5 |
  |    6 |
  +------+
  2 rows in set

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  +------+------+------+
  6 rows in set
  ```

* 通常の複数テーブルへの挿入：テーブル `tbl3` に少なくとも1行のデータがある場合、テーブル `tbl1` に1行のデータ (7,8,9) を挿入し、テーブル `tbl2` に1行のデータ (10,11,12) を挿入します。

  ```shell
  obclient> INSERT ALL INTO tbl1 VALUES(7,8,9)
                                      INTO tbl2 VALUES(10,11,12)
                  SELECT * FROM tbl3 WHERE ROWNUM< 2;
  Query OK, 2 rows affected
  Records: 2  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  |    7 |    8 |    9 |
  +------+------+------+
  7 rows in set

  obclient> SELECT * FROM tbl2;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |   10 |   11 |   12 |
  +------+------+------+
  1 row in set
  ```

* 条件付きの複数テーブルへの挿入：`INSERT ALL` を使用し、テーブル `tbl` の `col2` の値が `1` より大きい場合、テーブル `tbl1` にデータ (10,11,12) を挿入します。テーブル `tbl` の `col3` の値が `1` より大きい場合、テーブル `tbl2` にデータ (22,23,24) を挿入します。どちらの条件も満たさない場合、テーブル `tbl1` にデータ (33,34,35) を挿入します。

  ```shell
  obclient> INSERT INTO tbl VALUES(1,2,3);
  Query OK, 1 row affected

  obclient>INSERT ALL
                WHEN col2 > 1 THEN INTO tbl1 VALUES(10,11,12)
                WHEN col3 > 1 THEN INTO tbl2 VALUES(22,23,24)
                ELSE INTO tbl1 VALUES(33,34,35) SELECT col2,col3 FROM tbl;
  Query OK, 2 rows affected
  Records: 2  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  |    7 |    8 |    9 |
  |   10 |   11 |   12 |
  +------+------+------+
  8 rows in set

  obclient> SELECT * FROM tbl2;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |   10 |   11 |   12 |
  |   22 |   23 |   24 |
  +------+------+------+
  2 rows in set
  ```

* 条件付きの複数テーブルへの挿入：`INSERT FIRST` を使用し、テーブル `tbl` の `col2` の値が `1` より大きい場合、テーブル `tbl1` にデータ (14,15,16) を挿入し、テーブル `tbl2` にデータ (40,41,42) を挿入します。テーブル `tbl` の `col3` の値が `1` より大きい場合、テーブル `tbl2` にデータ (25,26,27) を挿入します。どちらの条件も満たさない場合、テーブル `tbl1` にデータ (35,36,37) を挿入します。

  ```shell
  obclient>INSERT ALL
                WHEN col2 > 1 THEN INTO tbl1 VALUES(14,15,16) INTO tbl2 VALUES(40,41,42)
                WHEN col3 > 1 THEN INTO tbl2 VALUES(25,26,27)
                ELSE INTO tbl1 VALUES(35,36,37) SELECT col2,col3 FROM tbl;
  Query OK, 3 rows affected
  Records: 3  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM tbl1;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |    1 |   10 |  100 |
  |    2 |   20 |  200 |
  |    3 |   15 |  110 |
  |    4 |   25 |  210 |
  |    5 |   50 |  500 |
  |    6 |   60 |  600 |
  |    7 |    8 |    9 |
  |   10 |   11 |   12 |
  |   14 |   15 |   16 |
  +------+------+------+
  9 rows in set

  obclient> SELECT * FROM tbl2;
  +------+------+------+
  | COL1 | COL2 | COL3 |
  +------+------+------+
  |   10 |   11 |   12 |
  |   22 |   23 |   24 |
  |   25 |   26 |   27 |
  |   40 |   41 |   42 |
  +------+------+------+
  4 rows in set
  ```

* `direct` ヒントの load_mode パラメータを使用して、増分ダイレクトロードを指定します。

  ```sql
  obclient [SYS]> INSERT /*+ direct(true, 0, 'inc_replace') enable_parallel_dml parallel(2) */ INTO tbl2 SELECT * FROM tbl1;
  ```

  実行結果は次のとおりです：

  ```sql
  Query OK, 8 rows affected
  Records: 8  Duplicates: 0  Warnings: 0
  ```

* 指定パーティションのダイレクトロード
  テーブル `tbl1` とテーブル `tbl2` のパーティションルールは以下のとおりです：

  ```sql
  partition p0 values less than (10)
      subpartition p0_1 values less than (5)
      subpartition p0_2 values less than (10)
  partition p1 values less than (20)
      subpartition p1_1 values less than (15)
      subpartition p1_2 values less than (20)
  ```

  * 指定パーティションのダイレクトロード

    ```sql
    insert /*+ enable_parallel_dml parallel(3) append */
    into tbl2 partition(p0, p1)
    select * from tbl1 partition(p0, p1);
    ```

  * 指定サブパーティションのダイレクトロード

    ```sql
    insert /*+ enable_parallel_dml parallel(3) append */
    into tbl2 partition(p0sp0_1, p1sp1_1)
    select * from tbl1 partition(p0sp0_1, p1sp1_1);
    ```
