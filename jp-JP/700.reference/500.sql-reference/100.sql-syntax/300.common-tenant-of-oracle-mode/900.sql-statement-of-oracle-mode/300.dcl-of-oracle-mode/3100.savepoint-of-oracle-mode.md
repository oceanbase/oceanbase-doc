# SAVEPOINT

## 説明

このステートメントは、トランザクションをコミットする前にセーブポイントを作成し、トランザクションの一部をロールバックできるようにするために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>セーブポイント名は同一トランザクション内では一意であり、後から作成したセーブポイントは、同名の既存のセーブポイントを上書きします。</li>
    <li>セーブポイントを作成した後、処理を続けたり、作業をコミットしたり、トランザクション全体をロールバックしたり、指定したセーブポイントまでロールバックしたりできます。トランザクションのロールバックの詳細については、<a href="../300.dcl-of-oracle-mode/3000.rollback-of-oracle-mode.md">ROLLBACK</a>を参照してください。</li>
    </ul>
  </main>

## 構文

```sql
SAVEPOINT savepoint_name
```

## パラメータ説明

|       パラメータ       |    説明     |
|----------------|-----------|
| savepoint_name | セーブポイント名を指定します。 |

## 例

サンプルテーブル `employee` を作成します。

```sql
obclient> CREATE TABLE employee (id INT, name VARCHAR(10), salary INT);

obclient> INSERT INTO employee VALUES (1, 'Alice', 1000), (2, 'Bob', 2000), (3, 'Alice', 3000);
```

```sql
obclient> SELECT * FROM employee;
```

```sql
+------+-------+--------+
| ID   | NAME  | SALARY |
+------+-------+--------+
|    1 | Alice |   1000 |
|    2 | Bob   |   2000 |
|    3 | Alice |   3000 |
+------+-------+--------+
3 rows in set
```

1. テーブル `employee` を更新し、`id = 3` の `name` を 'Carol' に変更して、`point_after_update` を作成します。

   ```sql
   obclient> UPDATE employee SET name = 'Carol' WHERE id = 3;
   obclient> SAVEPOINT point_after_update;
   ```

2. テーブル `employee` に1行のデータを挿入し、テーブルをクエリします。

   ```sql
   obclient> INSERT INTO employee VALUES (4, 'David', 4000);
   obclient> SELECT * FROM employee;
   ```

   ```sql
   Query OK, 1 row affected

   +------+-------+--------+
   | ID   | NAME  | SALARY |
   +------+-------+--------+
   |    1 | Alice |   1000 |
   |    2 | Bob   |   2000 |
   |    3 | Carol |   3000 |
   |    4 | David |   4000 |
   +------+-------+--------+
   4 rows in set
   ```

3. `point_after_update` までロールバックし、テーブルをクエリします。

   ```sql
   obclient> ROLLBACK TO SAVEPOINT point_after_update;
   obclient> SELECT * FROM employee;
   ```

   ```sql
   Query OK, 0 rows affected

   +------+-------+--------+
   | ID   | NAME  | SALARY |
   +------+-------+--------+
   |    1 | Alice |   1000 |
   |    2 | Bob   |   2000 |
   |    3 | Carol |   3000 |
   +------+-------+--------+
   3 rows in set
   ```

   ```sql
   obclient> COMMIT;
   ```
