# SET NAMES

## 説明

このステートメントは、現在のセッションの文字セットと照合順序を設定します。

## 構文

```sql
SET NAMES 'charset_name' [COLLATE 'collation_name']
```

## パラメータの説明

|       パラメータ       |                説明                |
|----------------|----------------------------------|
| charset_name   | 文字セットを指定します。                           |
| collation_name | 文字セットの照合順序を指定します。指定しない場合、文字セットのデフォルトの照合順序が使用されます。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>SHOW CHARSET;</code> を実行することで、システムがサポートする文字セットを確認できます。<code>SHOW COLLATION;</code> を実行することで、システムがサポートする照合順序を確認できます。</p>
  </main>

## 例

* 現在のセッションの文字セットを `gbk`、デフォルトの照合順序に設定します。

  ```sql
  obclient> SET NAMES 'gbk';

  obclient> SHOW VARIABLES LIKE 'character_set_c%';

  obclient> SHOW VARIABLES LIKE 'collation_connection';
  ```

* 現在のセッションの文字セットを `utf8mb4`、照合順序を `utf8mb4_general_ci` に設定します。

  ```sql
  obclient> SET NAMES 'utf8mb4' COLLATE 'utf8mb4_general_ci';

  obclient> SHOW VARIABLES LIKE 'character_set_c%';

  obclient> SHOW VARIABLES LIKE 'collation_connection';
  ```
