# SHRINK

## 説明

このステートメントは、テーブルのデータを書き換えます。

## 構文

```sql
ALTER TABLE table_name SHRINK SPACE;
```

## パラメータの説明

|     パラメータ     | 説明  |
|------------|-----|
| table_name | テーブル名。 |

## 例

テーブル `tbl1` のデータを書き換えます。

```sql
obclient> ALTER TABLE tbl1 SHRINK SPACE;
Query OK, 0 rows affected
```
