# SET VARIABLE

## 説明

このステートメントは、ユーザー定義変数（@）とシステム定義のセッション変数（@@）を設定するために使用されます。

## 構文

```sql
SET variable_name = variable_value[,variable_name = variable_value...]
```

## パラメータの説明

|       パラメータ       |                           説明                            |
|----------------|---------------------------------------------------------|
| variable_name  | 設定する変数を指定します。ユーザー定義変数またはシステム変数にすることができます。複数の変数を設定する場合は、半角カンマ `,` で区切ります。 |
| variable_value | 変数に設定する値を指定します。                                              |

## 例

```sql
obclient> SET @a = 1, @b = 2, @c = 3;

obclient> SET @@tx_isolation = 'read-committed';

obclient> SELECT @a,@b,@c,@@tx_isolation FROM DUAL;
```
