# SET ROLE

## 説明

このステートメントは、現在のセッションに付与されたロールを有効または無効にします。

## 構文

```sql
SET ROLE
{ role_name [ IDENTIFIED BY password ][, role_name [ IDENTIFIED BY password ] ]...
| ALL [ EXCEPT role_name [, role_name ]... ]
| NONE
} ;
```

## パラメータの説明

|           パラメータ           |                                               説明                                               |
|------------------------|------------------------------------------------------------------------------------------------|
| role_name              | このセッションで有効にするロール名を指定します。                                                                               |
| IDENTIFIED BY password | ロールのパスワードを指定します。ロールにパスワードが設定されている場合、そのロールを有効にするにはパスワードを指定する必要があります。                                                               |
| ALL                    | このセッションに付与されたすべてのロールを有効にします。 `EXCEPT` 句は、リストされたロールを除くことを示します。オプションです。パスワード付きのロールが直接付与されている場合は、この句を指定できません。そうしないとエラーが発生します。 |
| NONE                   | このセッションのすべてのロールを無効にします。                                                                                   |

## 例

* 現在のセッションで、パスワード `**1***` で識別されるロール `role1` を有効にします。

  ```sql
  obclient> SET ROLE role1 IDENTIFIED BY **1***;
  Query OK, 0 rows affected
  ```

* 現在のセッションに付与されたすべてのロールを有効にします。付与されたロールにパスワードを持つロールが含まれている場合、エラーが報告されます。

  ```sql
  obclient> SET ROLE ALL;
  ORA-01979: missing or invalid password for role 'ROLE2'
  ```

* 現在のセッションに付与されたロール `role2` を除くすべてのロールを有効にします。

  ```sql
  obclient> SET ROLE ALL EXCEPT role2;
  Query OK, 0 rows affected
  ```

* 現在のセッションに付与されたすべてのロールを無効にします。

  ```sql
  obclient> SET ROLE NONE;
  Query OK, 0 rows affected
  ```
