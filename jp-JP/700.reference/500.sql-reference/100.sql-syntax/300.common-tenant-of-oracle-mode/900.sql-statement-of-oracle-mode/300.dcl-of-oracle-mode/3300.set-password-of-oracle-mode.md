# SET PASSWORD

## 説明

このステートメントは、OceanBaseデータベースの現在ログインしているユーザーまたは他のユーザーのパスワードを変更するために使用されます。

その他のユーザーのパスワードを変更する方法については、[ALTER USER](../100.ddl-of-oracle-mode/1200.alter-user-of-oracle-mode.md)を参照してください。

## 構文

```sql
SET PASSWORD [FOR user_name] = PASSWORD(password);

password:
  STR_VALUE
```

## パラメータの説明

|    パラメータ     |                                                            説明                                                             |
|-----------|---------------------------------------------------------------------------------------------------------------------------|
| FOR       | 指定されたユーザーのパスワードを変更することを示します。オプションです。指定されたユーザーのパスワードを変更するには、`ALTER USER` のシステム権限が付与されている必要があります。`FOR` 句が指定されていない場合、現在のユーザーのパスワードを変更することを意味します。ログインに成功した任意のユーザーは、現在のユーザーのパスワードを変更できます。 |
| user_name | ユーザー名。                                                                                                                     |
| password  | ユーザーの新しいパスワード。                                                                                                                   |

## 例

ユーザー`user1`のパスワードを`**1***`に変更します。

```sql
obclient> SET PASSWORD FOR user1 = PASSWORD(**1***);
Query OK, 0 rows affected
```
