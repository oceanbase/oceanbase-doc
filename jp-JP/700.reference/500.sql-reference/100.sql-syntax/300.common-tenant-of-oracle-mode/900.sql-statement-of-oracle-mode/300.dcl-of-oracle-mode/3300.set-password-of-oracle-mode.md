# SET PASSWORD

## 説明

このステートメントは、OceanBaseデータベースの現在ログインしているユーザーまたは他のユーザーのパスワードを変更するために使用されます。

その他のユーザーパスワードの変更方法については、[ALTER USER](../100.ddl-of-oracle-mode/1200.alter-user-of-oracle-mode.md)を参照してください。

## 構文

```sql
SET PASSWORD [FOR user_name] = PASSWORD(password);

password:
  STR_VALUE
```

## パラメータの説明

|    パラメータ     |                                                            説明                                                             |
|-----------|---------------------------------------------------------------------------------------------------------------------------|
| FOR       | 指定ユーザーのパスワードを変更することを示します。この句はオプションです。指定ユーザーのパスワードを変更するには、`ALTER USER` システム権限が必要です。`FOR` 句を指定しない場合、現在ユーザーのパスワードを変更します。ログインに成功しているすべてのユーザーは、現在ユーザーのパスワードを変更できます。 |
| user_name | ユーザー名。                                                                                                                     |
| password  | ユーザーの新しいパスワード。                                                                                                                   |

## 例

ユーザー`user1`のパスワードを`**1***`に変更します。

```sql
obclient> SET PASSWORD FOR user1 = PASSWORD(**1***);
Query OK, 0 rows affected
```
