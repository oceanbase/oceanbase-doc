# SHOW

## 説明

このステートメントは、データベースオブジェクトの情報を表示するために使用されます。

## 構文

```sql
SHOW {
  | TABLE STATUS
  | [FULL] PROCESSLIST
  | RECYCLEBIN
  | VARIABLES [LIKE 'pattern']
  | PARAMETERS
  | CHARSET | CHARACTER SET
  | COLLATION
  | CREATE TABLEGROUP tablegroup_name
  | CREATE TABLE table_name
  | CREATE VIEW view_name
  | GRANTS
  | PRIVILEGES
  | ERRORS
  | TRACE [FORMAT='JSON']
  | FILES IN LOCATION @location_name['/path'] [PATTERN = 'regex_pattern']
};
```

## パラメータの説明

|    パラメータ |    説明     |
|-----------|------------|
| TABLE STATUS                       | 現在のユーザーのすべてのテーブルの詳細情報を表示します。  |
| VARIABLES \[like 'variable_name'\] | 変数情報を表示します。`like 'variable_name'` を指定しない場合、すべてのシステム変数情報が表示されます。`variable_name` は変数名です。 |
| CHARSET \| CHARACTER SET           | サポートされている文字セットを表示します。 |
| COLLATION                          | サポートされている照合順序を表示します。  |
| PARAMETERS                         | すべてのシステムパラメータを表示します。  |
| TABLEGROUPS                        | テーブルグループ情報を表示します。   |
| CREATE TABLEGROUP tablegroup_name  | テーブルグループ作成ステートメントを確認します。`tablegroup_name` はテーブルグループ名です。      |
| CREATE TABLE table_name            | テーブル作成ステートメントを確認します。`table_name` はテーブル名です。|
| CREATE VIEW view_name              | ビュー作成ステートメントを確認します。`view_name` はビュー名です。  |
| ERRORS                             | エラー情報を確認します。 |
| GRANTS                             | 現在ユーザーの権限を確認します。 |
| PRIVILEGES                         | 各権限の説明を確認します。|
| RECYCLEBIN                         | ごみ箱を確認します。 |
| \[FULL\] PROCESSLIST                 | 現在のテナントプロセスリストを確認します。具体的には以下のとおりです：<ul><li><code>SHOW PROCESSLIST</code> は簡略化されたプロセスリストを表示します。具体的には以下のとおりです：  <ul><li><code>ID</code>：プロセスのID、すなわち現在のセッションのClient Session ID。このIDはクライアント内でのセッションの一意の識別子です。</li><li><code>USER</code>：接続されているユーザー名。</li><li><code>HOST</code>：クライアントのIPアドレスとポート（ODP経由で接続する場合はODPのIPアドレスとポート）。</li><li><code>DB</code>：アクセスするデータベースの名前。</li><li><code>COMMAND</code>：現在実行中のコマンドタイプ。<code>Query</code>、<code>Sleep</code> などの値が取り得ます。</li><li><code>TIME</code>：現在のコマンド実行時間、単位は秒です。コマンドが再試行された場合、ゼロリセットして再計算されます。</li><li><code>STATE</code>：現在のセッション状態。<code>SLEEP</code>、<code>ACTIVE</code> などの値が取り得ます。</li><li><code>INFO</code>：現在実行中のコマンドを表示します。長さは100文字に制限され、それを超える部分は切り捨てられます。</li></ul>  </li><li><code>SHOW FULL PROCESSLIST</code>：完全なプロセスリストを表示します。各プロセスの詳細情報を含みます。具体的には以下のとおりです：  <ul><li><code>ID</code>：プロセスのID、すなわち現在のセッションのClient Session ID。このIDはクライアント内でのセッションの一意の識別子です。</li><li><code>USER</code>：接続されているユーザー名。</li><li><code>TENANT</code>：接続されているテナント。</li><li><code>HOST</code>：クライアントのIPアドレスとポート（ODP経由で接続する場合はODPのIPアドレスとポート）。</li><li><code>DB</code>：アクセスするデータベースの名前。</li><li><code>COMMAND</code>：現在実行中のコマンドタイプ。<code>Query</code>、<code>Sleep</code> などの値が取り得ます。</li><li><code>TIME</code>：現在のコマンド実行時間、単位は秒です。コマンドが再試行された場合、ゼロリセットして再計算されます。</li><li><code>STATE</code>：現在のセッション状態。<code>SLEEP</code>、<code>ACTIVE</code> などの値が取り得ます。</li><li><code>INFO</code>：現在実行中のコマンドを表示します。</li><li><code>IP</code>：サーバーのIPアドレス。</li><li><code>PORT</code>：SQLポート番号。</li></ul>  </li></ul>  <main id="notice" type='explain'><h4>説明</h4><p><code>SHOW PROCESSLIST</code> ステートメントを使用して、現在のデータベース内のセッション数とセッションIDの詳細情報を確認するには、<a href="../../../../../1200.database-proxy/1500.view-tenant-sessions.md">テナントセッションの確認</a>を参照してください。</p></main>|
| TRACE [FORMAT='JSON']              | SQLステートメントの実行状況を表示します。JSON形式で出力することも選択できます。|
| FILES IN LOCATION @location_name['/path'] [PATTERN = 'regex_pattern'] | Locationに存在するファイルを確認するために使用されます。<ul><li>`['/path']` はオプションで、サブディレクトリを示します。</li><li>`PATTERN = 'regex_pattern'` はオプションで、Locationディレクトリ内のファイルをフィルタリングするための正規表現を指定するために使用されます。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p><ul><li><code>SHOW FILES IN LOCATION</code> ステートメントを実行するには、現在のユーザーがLocationオブジェクトに対する <code>READ</code> 権限を持っている必要があります。</li><li>OceanBaseデータベースV4.4.xバージョンでは、V4.4.1バージョンからこの構文がサポートされています。</li></ul></p></main>|

## 例

* テーブル `tbl1` の作成情報を確認します。

  ```sql
    obclient> CREATE TABLE employees (
      emp_id INT PRIMARY KEY,
      emp_name VARCHAR(50) NOT NULL,
      hire_date DATE,
      salary NUMBER(10,2),
      department VARCHAR(30)
    );
    obclient> SHOW CREATE TABLE employees;
  ```

* ごみ箱が有効かどうかを確認します。

  ```sql
  obclient> SHOW VARIABLES LIKE 'recyclebin';
  ```

* ゴミ箱内の内容を確認します。

  ```sql
  obclient> SHOW RECYCLEBIN;
  ```

* `SHOW TRACE` を使用して特定のSQLの実行情報を確認し、JSON形式で出力します。

  ```shell
  obclient> SET ob_enable_show_trace = 1;

  obclient> CREATE TABLE space_travelers (
      astronaut_id INT PRIMARY KEY,
      mission_code VARCHAR(50) NOT NULL,
      launch_date DATE,
      flight_hours NUMBER(10,2),
      space_station VARCHAR(30)
  );

  obclient> INSERT INTO space_travelers VALUES(1, 'APOLLO-11', TO_DATE('1969-07-16', 'YYYY-MM-DD'), 195.5, 'MOON');

  obclient> INSERT INTO space_travelers VALUES(2, 'ISS-EXP-1', TO_DATE('2000-11-02', 'YYYY-MM-DD'), 4320.8, 'ISS');

  obclient> SELECT/*+PARALLEL(2)*/ COUNT(*) FROM space_travelers;

  obclient> SHOW TRACE FORMAT='JSON'\G
  ```
