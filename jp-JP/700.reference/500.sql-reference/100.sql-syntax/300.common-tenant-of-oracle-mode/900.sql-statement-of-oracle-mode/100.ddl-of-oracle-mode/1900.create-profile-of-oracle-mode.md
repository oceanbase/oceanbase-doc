# CREATE PROFILE

## 説明

このステートメントは、構成ファイルを作成するために使用されます。構成ファイルとは、データベースリソースに対する一連の制限であり、ユーザーに構成ファイルが割り当てられると、そのユーザーはこれらの使用制限を超えることができません。

## 構文

```sql
CREATE PROFILE "profile_name" LIMIT
  { FAILED_LOGIN_ATTEMPTS
    | PASSWORD_LOCK_TIME
    | PASSWORD_LIFE_TIME
    | PASSWORD_VERIFY_FUNCTION
    | PASSWORD_GRACE_TIME
    }
    { integer | UNLIMITED | DEFAULT };
```

## パラメータの説明

|          パラメータ           |               説明                |
|-----------------------|---------------------------------|
| profile_name          | 作成するプロファイルの名前を指定します。                  |
| FAILED_LOGIN_ATTEMPTS | 継続的にユーザーアカウントへのログインに失敗した回数を指定します。                |
| PASSWORD_LOCK_TIME    | アカウントが制限回数内で連続してログインに失敗した場合、アカウントがロックされる日数を指定します。 |
| PASSWORD_LIFE_TIME    | 同一パスワードを認証に使用できる有効な日数を指定します。             |
| PASSWORD_VERIFY_FUNCTION |PLパスワード複雑性検証スクリプトを`CREATE PROFILE`ステートメントのパラメータとして渡すことを許可します。<br>関数の場合、パスワード複雑性検証ルーチンの名前を指定する必要があります。この関数はSYSスキーマに存在していなければならず、ユーザーはその関数に対して`EXECUTE`権限を持っていなければなりません。<br>このパラメータを`NULL`と指定した場合、パスワード検証は実行されません。パスワードパラメータに`expr`を指定した場合、式は標準量クエリ式以外の任意の形式である可能性があります。|
| PASSWORD_GRACE_TIME   | 警告を解除し、アカウントのログインを許可するための猶予期間の日数を指定します。          |
| integer               | このパラメータに設定された制限タイプの形式が整数であることを示します。             |
| UNLIMITED             | このパラメータに制限が設定されていないことを示します。                   |
| DEFAULT               | このパラメータのデフォルト制限を使用することを示します。                   |

## 例

パスワード制限の構成ファイル`profile1`を作成し、`FAILED_LOGIN_ATTEMPTS`を`3`回、`PASSWORD_LOCK_TIME`を`1`日、`PASSWORD_LIFE_TIME`を`60`日に設定し、`PASSWORD_GRACE_TIME`はデフォルトの制限を使用します。

```sql
obclient> CREATE PROFILE "profile1" LIMIT
   FAILED_LOGIN_ATTEMPTS 5
   PASSWORD_LOCK_TIME 1
   PASSWORD_LIFE_TIME 60
   PASSWORD_VERIFY_FUNCTION verify_function
   PASSWORD_GRACE_TIME DEFAULT;
Query OK, 0 rows affected
```
