# CREATE PROFILE

## 説明

このステートメントは、プロファイルを作成するために使用します。プロファイルとはデータベースリソースに対する一連の制限であり、ユーザーにプロファイルを割り当てると、そのユーザーはこれらの使用制限を超えることができなくなります。制限項目には、リソース制限パラメータ（セッションの最大アイドル時間 `IDLE_TIME` など）やパスワード管理パラメータが含まれます。

## 構文

```sql
CREATE [WITH HINT] PROFILE [profile_name | DEFAULT] LIMIT
  { FAILED_LOGIN_ATTEMPTS { integer | UNLIMITED | DEFAULT }
  | IDLE_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_LOCK_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_LIFE_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_VERIFY_FUNCTION { function_name | NULL }
  | PASSWORD_GRACE_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_ROLLOVER_TIME { bigint(20) | UNLIMITED | DEFAULT }
  }
  [, ...]
```

## パラメータの説明

|          パラメータ           |               説明                |
|-----------------------|---------------------------------|
| WITH HINT             | オプションです。クエリオプティマイザーが使用するヒント情報を指定します。                  |
| profile_name          | 作成するプロファイル名を指定します。通常の識別子、予約語ではないキーワード、または `DEFAULT` が指定可能です。                  |
| FAILED_LOGIN_ATTEMPTS | アカウントがロックされるまでに許容される連続したログイン失敗試行回数を指定します。                |
| IDLE_TIME | セッションの最大アイドル時間を分単位で指定します。正の整数を指定すると、セッションのアイドル時間がこの値を超えた場合に、データベースが自動的に接続を切断します。この設定は `wait_timeout` および `interactive_timeout` より優先して適用されます。`0` はこのパラメータが無効であり、アイドルタイムアウトは `wait_timeout`（対話型接続の場合は `interactive_timeout`）によって制御されることを意味します。`UNLIMITED` はアイドル時間を無制限にすることを意味します。`DEFAULT` は `DEFAULT` プロファイルの値を継承することを意味します。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このパラメータはV4.4.2 BP4バージョンからサポートされています。</li><li>Oracleでは、<code>IDLE_TIME</code>が<code>0</code>の場合、アイドル時間を無制限にすることを意味しますが、OceanBaseでは<code>0</code>はこのパラメータが無効であることを意味します。アイドル時間を無制限にする必要がある場合は、<code>UNLIMITED</code>に設定してください。</li></ul></main> |
| PASSWORD_LOCK_TIME    | ログイン失敗によりアカウントがロックされる日数を指定します。 |
| PASSWORD_LIFE_TIME    | パスワードの有効期間（日）を指定します。             |
| PASSWORD_VERIFY_FUNCTION | パスワード検証に使用する関数を指定します。 |
| PASSWORD_GRACE_TIME   | パスワード期限切れ後の猶予期間（日）を指定します。この期間中は古いパスワードでログインできますが、警告が表示されます。          |
| PASSWORD_ROLLOVER_TIME | パスワードローテーションの有効期間を指定します。単位は日です。ローテーションの有効期間内は、古いパスワードと新しいパスワードの両方を認証に使用できます。値 `0` は古いパスワードによる認証を無効にします。<main id="notice" type="explain"><h4>説明</h4><p>このパラメータはV4.4.2 BP1バージョンからサポートされています。V4.4.2 BP4バージョン以降は、パラメータの値を検証します。0以外の場合、値の範囲は10秒～60日でなければならず、<code>PASSWORD_LIFE_TIME</code> や、0でも<code>UNLIMITED</code> でもない場合の <code>PASSWORD_GRACE_TIME</code> より大きくしてはなりません。違反した場合はエラーが発生します。</p></main> |
| integer               | パラメータの具体的な整数値を指定します。             |
| UNLIMITED             | パラメータに制限がないことを指定します。                   |
| DEFAULT               | システムのデフォルト値を使用します。                   |
| NULL                  | パラメータをNULLに設定します。                  |
| function_name         | 検証関数の名前を指定します。                  |

## 制限と注意点

* `IDLE_TIME` は OceanBase データベースの Oracle モードでのみ適用され、MySQL モードでは無効です。

* `IDLE_TIME` はセッションのアイドル時間のみを制限します。セッションが SQL を実行している間はアイドル時間には含まれず、長時間実行されているクエリはこのパラメータの制約を受けません。

* `IDLE_TIME` は接続確立時に一度読み込まれ、変更後は新規に作成されるセッションにのみ有効になり、既に確立されたセッションには影響しません。

* 実際に接続が切断されるのは、`IDLE_TIME` で指定した時間が経過してから最大5秒後です。

* 負の数値を指定するとエラーが発生します。また、`IDLE_TIME 1.5` のような非整数値もエラーとなります。

* `DEFAULT` プロファイル自体に `IDLE_TIME DEFAULT` を指定することはできません。指定すると、無効なリソース制限エラーが発生します。

## 例

パスワード制限のプロファイル `profile1` を作成し、`FAILED_LOGIN_ATTEMPTS` を `5` 回、`PASSWORD_LOCK_TIME` を `1` 日、`PASSWORD_LIFE_TIME` を `60` 日、`PASSWORD_VERIFY_FUNCTION` を `NULL`、`PASSWORD_GRACE_TIME` をデフォルトの制限、`PASSWORD_ROLLOVER_TIME` を `5` 日（例としての値）に設定します。

```sql
obclient> CREATE PROFILE profile1 LIMIT
   FAILED_LOGIN_ATTEMPTS 5
   PASSWORD_LOCK_TIME 1
   PASSWORD_LIFE_TIME 60
   PASSWORD_VERIFY_FUNCTION NULL
   PASSWORD_GRACE_TIME DEFAULT
   PASSWORD_ROLLOVER_TIME 5;
```

<main id="notice" type='explain'>
<h4>説明</h4>
<p><code>PASSWORD_VERIFY_FUNCTION</code> でユーザー定義関数を使用する場合は、その関数を事前に作成する必要があります。パスワード検証機能が不要な場合は、<code>NULL</code> に設定できます。</p>
</main>

セッションの最大アイドル時間制限を含むプロファイル `profile2` を作成すると、セッションのアイドル時間が30分を超えた場合、データベースが自動的に接続を切断します。

```sql
obclient> CREATE PROFILE profile2 LIMIT IDLE_TIME 30;
```
