# DROP USER

## 説明

このステートメントは、OceanBaseデータベースのユーザーを削除するために使用します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>DROP USER</code> コマンドを使用するには、<code>CREATE USER</code> のシステム権限が必要です。</li>
    <li><code>CASCADE</code> を指定すると、ユーザーを削除する前に、そのユーザーが所有するすべてのオブジェクト（権限、データベース、テーブルなど）を削除します。</li>
    </ul>
  </main>

## 構文

```sql
DROP USER user_name [, user_name ...] [CASCADE]
```

## パラメータの説明

| パラメータ | 説明 |
|------|------|
| user_name | 削除するユーザー名を指定します。<ul><li>`username`または`username@hostname`の形式で指定できます。</li><li>複数のユーザーを指定する場合は、カンマで区切ります。</li></ul> |
| CASCADE | オプションパラメータ。ユーザーが所有するすべてのオブジェクトを削除するかどうかを指定します。<ul><li>指定した場合、ユーザーが所有するすべてのオブジェクト（テーブル、ビューなど）が削除されます。</li><li>指定しない場合、ユーザーがオブジェクトを所有しているとエラーが発生します。</li></ul> |

## 例

1. 単一ユーザーの削除：

   ```sql
   obclient> DROP USER user1;
   ```

2. 指定ホストのユーザーの削除：

   ```sql
   obclient> DROP USER 'user1'@'localhost';
   ```

3. 複数ユーザーの削除：

   ```sql
   obclient> DROP USER user1, user2@'%', 'user3'@'localhost';
   ```

4. ユーザーを削除し、そのオブジェクトを連鎖的に削除する：

   ```sql
   obclient> DROP USER user1 CASCADE;
   ```
