# DROP USER

## 説明

このステートメントは、OceanBaseデータベースのユーザーを削除します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>DROP USER</code> コマンドを使用するには、<code>CREATE USER</code> のシステム権限が付与されている必要があります。</li>
    <li><code>CASCADE</code> を指定すると、ユーザーを削除する前に、そのユーザーが持つすべてのオブジェクト（権限、データベース、テーブルなど）も削除されます。</li>
    </ul>
  </main>

## 構文

```sql
DROP USER user_name CASCADE;
```

## パラメータの説明

|    パラメータ     |       説明       |
|-----------|----------------|
| user_name | ユーザー名。単一のユーザーのみを削除できます。 |

## 例

`user1` という名前のユーザーを削除します。

```sql
obclient> DROP USER user1 CASCADE;
Query OK, 0 rows affected
```
