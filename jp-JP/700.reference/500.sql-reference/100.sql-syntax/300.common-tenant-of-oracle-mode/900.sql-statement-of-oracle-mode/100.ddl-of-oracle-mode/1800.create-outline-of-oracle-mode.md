# CREATE OUTLINE

## 説明

このステートメントは、アウトラインを作成するために使用されます。アウトラインの作成方法は2種類あります。1つは`SQL_TEXT`（ユーザーが実行したパラメータ付きの元のステートメント）を使用して作成する方法、もう1つは`SQL_ID`を使用して作成する方法です。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>アウトラインを作成するには、対応するユーザー権限で実行する必要があります。</p>
  </main>

## 構文

```sql
/* SQL_TEXTを使用してアウトラインを作成 */
CREATE [OR REPLACE] OUTLINE outline_name ON stmt [ TO target_stmt ]

/* SQL_IDを使用してアウトラインを作成 */
CREATE OUTLINE outline_name ON sql_id USING HINT  hint;
```

## パラメータの説明

|       パラメータ       |                                                                                                                                                      説明                                                                                                                                                       |
|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| outline_name   | 作成するアウトラインの名前を指定します。                                                                                                                                                                                                                                                                                            |
| OR REPLACE     | `OR REPLACE` を指定した場合、作成しようとしているアウトラインが既に存在する場合は、既存のアウトラインを置き換えます。                                                                                                                                                                                                                                                        |
| stmt           | 通常は `hint` と元のパラメータを含むDMLステートメントです。                                                                                                                                                                                                                                                                                 |
| TO target_stmt | `TO target_stmt` を指定しない場合、データベースが受け入れるSQLがパラメータ化された後、`stmt` から `hint` のパラメータ化テキストを除いたものと同じである場合、そのSQLは `stmt` 内の `hint` にバインドされ、実行計画が生成されます。`hint` を含むステートメントに対して固定計画を期待する場合は、元のSQLを指定するために `TO target_stmt` が必要です。  <br>**注意**  `target_stmt` を使用する際は、`stmt` と `target_stmt` が `hint` を除いた後に完全に一致することが厳密に求められます。 |
| sql_id         | `sql_id` に対応するSQL文にすでに `hint` が設定されている場合、Outlineで指定された `hint` は元の文のすべての `hint` を上書きします。                                                                                                                                                                                                                                    |
| hint           | 形式は /\*+ xxx \*/ です。Hint構文の詳細については、『OceanBaseデータベースSQLチューニングガイド』の **Optimizer Hint** 章を参照してください。<main id="notice" ><h4>説明</h4><p><ul><li>クエリの制限を実現するために `SQL_TEXT` を使用してOutlineを作成する場合、特別なパラメータを指定する必要はありません。例えば、次のようにOutlineを作成できます：`create outline otl2 on select /*+ max_concurrent(1) */ * from t where c1=?`。ここでは、具体的な値を指定する代わりに、パラメータ化されたプレースホルダー（例えば `?`）を使用しています。</li></ul><ul><li>バインド実行計画を作成する場合は、対応するパラメータを指定する必要があります。例えば、バインド実行計画のOutlineを作成するには、次のようなステートメントを使用できます：`create outline otl2 on select /*+ norewrite */ * from t where c1=1`。ここでは、`c1` に具体的な値を指定する必要があります。 </li></ul></p></main>|

## 例

* `SQL_TEXT` を使用して `outline1` を作成します。

  ```sql
  obclient> CREATE OUTLINE outline1
  ON SELECT/*+ index(tbl1 idx_col2)*/ * FROM tbl1 WHERE col2 = 1;
  ```

* `SQL_ID` を使用して `outline2` を作成します。

  ```sql
  obclient> CREATE OUTLINE outline2
  ON 'ED570339F2C856BA96008A29EDF04C74'
  USING HINT /*+ index(tbl1 idx_col2)*/ ;
  ```

* `SQL_TEXT` を使用して `outline1` を作成し、`HINT` で同時にレートリミットと実行計画を指定します：

  ```sql
  obclient> CREATE OUTLINE outline1
  ON SELECT/*+ index(tbl1 idx_col2) max_concurrent(1)*/ * FROM tbl1 WHERE col2 = 1;
  ```

## 注意事項

`SQL_ID` が同一の場合、`SQL_TEXT` を使用して作成されたアウトラインは `SQL_ID` を使用して作成されたアウトラインを上書きします。`SQL_TEXT` を使用した作成の優先順位が高いためです。

さらに、OceanBaseデータベースでは `SQL_ID` によって異なるSQLを区別しますが、`SQL_ID` は `SQL_TEXT` から `MD5` 加算して得られます。同一のSQLテキストであっても、改行やタブが1つ増えただけで、`MD5` によって得られる `SQL_ID` は異なります。実際の本番システムでは、`SQL_ID` を使用したアウトラインのバインドを推奨します。
