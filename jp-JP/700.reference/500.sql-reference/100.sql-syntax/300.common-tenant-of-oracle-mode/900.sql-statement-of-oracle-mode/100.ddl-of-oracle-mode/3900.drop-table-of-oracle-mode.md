# DROP TABLE

## 説明

このステートメントは、データベース内のテーブルを削除するために使用します。

## 権限要件

`DROP TABLE` ステートメントを実行するには、現在のユーザーが `DROP` システム権限を持っている必要があります。OceanBase データベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP TABLE table_name [CASCADE CONSTRAINTS] [PURGE];
```

## パラメータの説明

|         パラメータ          |            説明             |
|---------------------|---------------------------|
| table_name          | 削除するテーブル名を指定します。                 |
| CASCADE CONSTRAINTS | `table_name` に関連付けられた制約を連鎖的に削除します。 |
| PURGE               | テーブルを完全に削除します(ゴミ箱には入りません)。            |

## 例

テーブル `tbl1` を削除します。

```sql
obclient> DROP TABLE tbl1;
Query OK, 0 rows affected
```
