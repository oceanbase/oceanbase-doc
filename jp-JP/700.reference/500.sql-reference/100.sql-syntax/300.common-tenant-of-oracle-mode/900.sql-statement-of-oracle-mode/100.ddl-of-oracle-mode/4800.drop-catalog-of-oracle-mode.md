# DROP CATALOG

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このステートメントはV4.3.5 BP2バージョンからサポートされています。</p>
</main>

## 説明

このステートメントは、外部データカタログ(External Catalog)を削除するために使用します。

## 使用上の制限と注意事項

* Internal Catalog(`INTERNAL`)は削除できません。
* MySQLモードとは異なり、Oracleモードの`DROP CATALOG`ステートメントは`IF EXISTS`句をサポートしていません。削除対象のカタログが存在しない場合、エラーが発生し、エラーコードは`-11080`、エラーメッセージは`Catalog 'xxx' doesn't exist`となります。
* カタログ名は大文字小文字を区別せず、二重引用符で囲まれていないカタログ名はすべて大文字に変換されてマッチングされます。
* カタログを削除すると、他のユーザーがそのカタログに対して持つ`USE CATALOG`オブジェクト権限も同時に取り消されます。

## 権限要件

`DROP CATALOG`ステートメントを実行するには、現在のユーザーが`CREATE CATALOG`システム権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP CATALOG external_catalog_name
```

## パラメータ説明

|    **パラメータ**     | **説明** |
|-----------------|----------|
| external_catalog_name | 削除する外部データカタログの名前。大文字小文字を区別せず、二重引用符で囲まれていない場合はすべて大文字に変換されてマッチングされます。|

## 例

`tmp_catalog`という名前のExternal Catalogを作成して削除します。

```sql
obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

obclient> DROP CATALOG tmp_catalog;
```

削除対象のカタログが存在しない場合、エラーが発生します：

```sql
obclient> DROP CATALOG tmp_catalog;
```

実行結果は次のとおりです：

```sql
OBE-00600: internal error code, arguments: -11080, Catalog 'TMP_CATALOG' doesn't exist
```
