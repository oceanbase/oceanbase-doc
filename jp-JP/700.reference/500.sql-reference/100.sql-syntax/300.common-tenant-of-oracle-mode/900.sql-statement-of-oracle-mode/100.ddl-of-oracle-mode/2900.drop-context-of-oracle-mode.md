# DROP CONTEXT

## 説明

`DROP CONTEXT` ステートメントは、データベースからコンテキストネームスペースを削除するために使用されます。

コンテキストネームスペースを削除しても、そのネームスペース内でユーザーセッションに設定されたコンテキストが無効になることはありません。ただし、ユーザーが次回そのコンテキストを設定しようとした場合、そのコンテキストは無効になります。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DROP ANY CONTEXT</code> システム権限が付与されている必要があります。</p>
  </main>

## 構文

```sql
DROP CONTEXT namespace;
```

## パラメータの説明

`namespace` は、削除するコンテキストネームスペースの名前を指定します。組み込みネームスペース `USERENV` を削除することはできません。

`USERENV` ネームスペースの詳細については、関数 [SYS_CONTEXT](../../500.functions-of-oracle-mode/200.single-row-functions-of-oracle-mode/900.environment-and-identifier-functions-of-oracle-mode/100.lnnvl-of-oracle-mode.md)を参照してください。

## 例

`CREATE CONTEXT` で作成されたコンテキスト `dev_context` を削除します。

```sql
obclient> DROP CONTEXT dev_context;
Query OK, 0 rows affected
```
