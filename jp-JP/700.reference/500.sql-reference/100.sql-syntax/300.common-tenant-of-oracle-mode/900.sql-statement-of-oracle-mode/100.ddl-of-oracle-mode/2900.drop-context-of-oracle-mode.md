# DROP CONTEXT

## 説明

`DROP CONTEXT` 文は、データベースからコンテキスト名前空間を削除するために使用します。

コンテキスト名前空間を削除しても、現在のセッションで設定されているコンテキスト値は保持されます。ただし、その後同じコンテキストを設定しようとすると、名前空間が存在しないため失敗します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DROP ANY CONTEXT</code> システム権限が必要です。</p>
  </main>

## 構文

```sql
DROP CONTEXT context_name
```

## パラメータ説明

`context_name` は削除するコンテキスト名を指定します。組み込み名前空間 `USERENV` は削除できません。

`USERENV` コンテキストの詳細については、関数 [SYS_CONTEXT](../../500.functions-of-oracle-mode/200.single-row-functions-of-oracle-mode/900.environment-and-identifier-functions-of-oracle-mode/100.lnnvl-of-oracle-mode.md)を参照してください。

## 例

`CREATE CONTEXT` で作成したコンテキスト `dev_context` を削除します。

```sql
obclient> DROP CONTEXT dev_context;
```
