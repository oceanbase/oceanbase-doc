# ALTER VIEW COMPILE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このステートメントは、V4.4.2 BP1バージョンから導入されました。</p>
</main>

## 説明

このステートメントは、無効なビューを明示的に再コンパイルしたり、ビューの制約を変更したりするために使用します。

## 権限要件

このステートメントを実行するには、`ALTER ANY TABLE` システム権限が必要です。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER VIEW [schema_name.]view_name COMPILE;
```

## パラメータの説明

|      パラメータ      |         説明       |
|---------------|--------------------|
|schema_name|ビューが属するスキーマ名（オプション）。|
|view_name|再コンパイルが必要なビュー名。|
|COMPILE|キーワードで、データベースに再コンパイル操作を実行するよう指示します。|

## 例

以下のコマンドを実行して、`customer_ro` という名前のビューをコンパイルします。

```shell
obclient> ALTER VIEW customer_ro COMPILE;
```
