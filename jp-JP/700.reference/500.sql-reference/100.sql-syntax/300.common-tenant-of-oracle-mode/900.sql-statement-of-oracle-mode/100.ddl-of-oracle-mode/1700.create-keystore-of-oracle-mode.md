# CREATE KEYSTORE

## 説明

このステートメントは、キーを格納するために使用されるKeystoreオブジェクトを作成します。透過的データ暗号化のシナリオでは、Keystoreオブジェクトを作成する必要があります。各テナントは最大1つのKeystoreオブジェクトしか作成できません。

## 構文

```sql
ADMINISTER KEY MANAGEMENT CREATE KEYSTORE [keystore_name] IDENTIFIED BY [password] ;
```

## パラメータの説明

|      パラメータ       |          説明          |
|---------------|----------------------|
| keystore_name | Keystore名を指定します。      |
| password      | Keystoreへのアクセス制御パスワードを指定します。 |

## 例

Keystoreオブジェクト `keystore1` を作成します。

```sql
obclient> ADMINISTER KEY MANAGEMENT CREATE KEYSTORE keystore1 IDENTIFIED BY **1***;
```
