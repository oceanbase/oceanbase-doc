# CREATE KEYSTORE

## 説明

このステートメントは、キーストアオブジェクトを作成するために使用されます。このオブジェクトは秘密鍵の格納に使用されます。透過的データ暗号化のシナリオでは、Keystoreオブジェクトを作成する必要があり、各テナントは最大1つのKeystoreオブジェクトしか作成できません。

## 構文

```sql
ADMINISTER KEY MANAGEMENT CREATE KEYSTORE [keystore_name] IDENTIFIED BY [password] ;
```

## パラメータの説明

|      パラメータ       |          説明          |
|---------------|----------------------|
| keystore_name | Keystoreの名前を指定します。      |
| password      | アクセス制御用Keystoreのパスワードを指定します。 |

## 例

Keystoreオブジェクト `keystore1` を作成します。

```sql
obclient> ADMINISTER KEY MANAGEMENT CREATE KEYSTORE keystore1 IDENTIFIED BY **1***;
```
