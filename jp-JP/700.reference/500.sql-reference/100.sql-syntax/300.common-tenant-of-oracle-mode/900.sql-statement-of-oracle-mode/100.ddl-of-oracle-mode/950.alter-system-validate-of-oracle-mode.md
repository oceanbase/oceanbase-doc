# VALIDATE

## 説明

`ALTER SYSTEM VALIDATE` ステートメントは、物理バックアップの検証を実行するために使用されます。

## 使用上の制限と注意事項

* V4.4.2バージョンでは、V4.4.2 BP2バージョンから `ALTER SYSTEM VALIDATE` ステートメントがサポートされています。

* 検証タスクは頻繁にバックアップメディアにアクセスしてデータを読み取るため、バックアップタスクのネットワークリソースを占有します。そのため、ユーザーテナントでバックアップタスクが実行されておらず、負荷が低い時に検証タスクを実行することを推奨します。

* バックアップ検証のレベルを指定する場合：

  * V4.4.2バージョンでは、V4.4.2 BP2バージョン（V4.4.2 BP2バージョンを除く）以前のバックアップセットおよびログアーカイブピースについては、Basic検証、すなわちファイルの整合性検証はサポートされていません。

  * V4.3.4バージョン（V4.3.4バージョンを除く）以前のバックアップセットについては、Physical検証、すなわち物理データの正確性および論理的一貫性検証はサポートされていません。

## 権限要件

各テナントの管理者ユーザーによって実行する必要があります。具体的には：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。

* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM VALIDATE { BACKUP | BACKUPSET [= 'backup_set_id_list'] | ARCHIVELOG_PIECE [= 'piece_id_list'] }
    [ DATA_BACKUP_DEST = 'data_backup_path' ]
    [ LOG_ARCHIVE_DEST = 'log_archive_path' ]
    [ LEVEL = { 'basic' | 'physical' } ];

backup_set_id_list:
    backup_set_id[,backup_set_id,...]

piece_id_list:
    piece_id[,piece_id,...]
```

## パラメータ説明

|      パラメータ        |        説明                                             |
|------------------|---------------------------------------------------------|
| BACKUP           | 現在のユーザーテナント配下の、バックアップパスとアーカイブパスにあるすべてのバックアップセットとログアーカイブピースを検証します。検証パス（`DATA_BACKUP_DEST` または `LOG_ARCHIVE_DEST`）の指定はサポートされていないため、クラスタ間やコールドスタンバイデータシナリオは対応していません。|
| BACKUPSET        | 指定したバックアップセットを検証します。バックアップセットの `backup_set_id` を指定しない場合、現在のバックアップパス配下のすべてのバックアップセットを検証します。<main id="notice" type='notice'><h4>注意</h4><p><code>backup_set_id</code> を指定しない場合、システムは現在設定されているバックアップパス配下のすべてのバックアップセットを取得して検証するため、多数の検証タスクが生成され、時間がかかります。すべてのバックアップセットを検証する必要がない場合は、検証コマンドで <code>backup_set_id</code> を指定することを推奨します。</p></main> |
| ARCHIVELOG_PIECE | 指定したログアーカイブピースを検証します。アーカイブピースの `piece_id` を指定しない場合、現在のアーカイブパス配下のすべてのログアーカイブピースを検証します。 <main id="notice" type='notice'><h4>注意</h4><p><code>piece_id</code> を指定しない場合、システムは現在設定されているアーカイブパス配下のすべてのアーカイブピースを取得して検証するため、多数の検証タスクが生成され、時間がかかります。すべてのアーカイブピースを検証する必要がない場合は、検証コマンドで <code>piece_id</code> を指定することを推奨します。</p></main>|
| DATA_BACKUP_DEST | 検証対象のデータバックアップパスを指定するオプションパラメータです。このパラメータを指定しない場合、デフォルトでテナントの現在のバックアップ設定のバックアップパスが検証されます。 <main id="notice" type='notice'><h4>注意</h4><p>OceanBaseデータベースは、単一のコマンドで複数のパスを指定することは現在サポートされていません。そのため、<code>backup_set_id</code> を指定してパス内の増分バックアップセットを検証しようとした際、その増分バックアップセットが依存する他のバックアップセット情報を読み取れないため、エラー9120が発生する可能性があります。</p></main> |
| LOG_ARCHIVE_DEST | 検証対象のログアーカイブパスを指定するオプションパラメータです。このパラメータを指定しない場合、デフォルトでテナントの現在のアーカイブ設定のアーカイブパスが検証されます。 |
| LEVEL            | 検証レベルを指定するオプションパラメータです。<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一致性を同時にチェックします。</li></ul><p>このパラメータを指定しない場合、デフォルトは `physical` です。</p>|

## 例

### バックアップパスとアーカイブパス全体のすべてのバックアップセットとログアーカイブピースの検証

ユーザーテナントは、現在のバックアップおよびアーカイブパスにある自身のテナントのすべてのバックアップセットとアーカイブピースに対してBasic検証を実行します。

```shell
obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE BACKUP LEVEL = 'basic';
```

### 指定されたバックアップセットまたはログアーカイブピースの検証

**バックアップセットの検証**

* ユーザーテナントは、自身のテナントの現在のバックアップパスにあるすべてのバックアップセットに対してBasic検証を実行します。

  ```shell
  obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE BACKUPSET LEVEL = 'basic';
  ```

* ユーザーテナントは、自身のテナントの現在のバックアップパスにある `backup_set_id` が1および2のバックアップセットに対してPhysical検証を実行します。

  ```shell
  obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE BACKUPSET = '1,2' LEVEL = 'physical';
  ```

**ログアーカイブピースの検証**

* ユーザーテナントは、自身のテナントの現在のアーカイブパスにあるすべてのアーカイブピースに対してBasic検証を実行します。

  ```shell
  obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE LEVEL = 'basic';
  ```

* ユーザーテナントは、自身のテナントの現在のアーカイブパスにある `piece_id` が1および2のログアーカイブピースに対してPhysical検証を実行します。

  ```shell
  obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE = '1,2' LEVEL = 'physical';
  ```

### 指定パス下のバックアップセットまたはログアーカイブピースの検証

**バックアップセットの検証**

* ユーザーテナントは、自身のテナントで指定したバックアップパスにあるすべてのバックアップセットに対してBasic検証を実行します。

  ```shell
  obclient> ALTER SYSTEM VALIDATE BACKUPSET DATA_BACKUP_DEST = 'file:///data/nfs/backup/data' LEVEL = 'basic';
  ```

* ユーザーテナントは、自身のテナントで指定したバックアップパスにある `backup_set_id` が1および2のバックアップセットに対してPhysical検証を実行します。

  ```shell
  obclient> ALTER SYSTEM VALIDATE BACKUPSET = '1,2' DATA_BACKUP_DEST = 'file:///data/nfs/backup/data' LEVEL = 'physical';
  ```

**ログアーカイブピースの検証**

* ユーザーテナントは、自身のテナントで指定したアーカイブパスにあるすべてのアーカイブピースに対してBasic検証を実行します。

  ```shell
  obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE LOG_ARCHIVE_DEST = 'LOCATION=file:///data/nfs/backup/archive' LEVEL = 'basic';
  ```

* ユーザーテナントは、自身のテナントで指定したアーカイブパスにある `piece_id` が1および2のログアーカイブピースに対してPhysical検証を実行します。

  ```shell
  obclient(sys@oracletenant)[SYS]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE = '1,2' LOG_ARCHIVE_DEST = 'LOCATION=file:///data/nfs/backup/archive' LEVEL = 'physical';
  ```
