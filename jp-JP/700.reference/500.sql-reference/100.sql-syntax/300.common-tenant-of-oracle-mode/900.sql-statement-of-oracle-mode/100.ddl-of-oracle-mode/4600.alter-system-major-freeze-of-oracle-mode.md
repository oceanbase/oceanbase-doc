# MAJORとMINOR

## 説明

このステートメントは、通常のテナントが自身のストレージ層のメジャーコンパクションまたはダンプを開始するために使用されます。手動でのコンパクションとダンプは、テナントレベルでのみサポートされています。

## 構文

```shell
ALTER SYSTEM merge_action;

merge_action:
      MAJOR FREEZE
    | MINOR FREEZE
    | {SUSPEND | RESUME} MERGE
    | CLEAR MERGE ERROR
```

## パラメータの説明

|          **パラメータ**           |      **説明**      |
|---------------------------|------------------|
| MAJOR FREEZE              | 毎日のコンパクションを開始します。<br>**説明** ユーザーテナントは自身のコンパクションのみを開始できます。       |
| MINOR FREEZE              | ダンプを開始します。 <br>**説明** ユーザーテナントは自身のダンプのみを開始できます。           |
| {SUSPEND \| RESUME} MERGE | 毎日のコンパクションを一時停止または再開します。<br>**説明** ユーザーテナントは自身の毎日のコンパクションのみを一時停止または再開できます。       |
| CLEAR MERGE ERROR         | コンパクションエラーのマーカーをクリアします。<br>**説明** ユーザーテナントは自身のコンパクションのエラーマーカーのみをクリアできます。       |

## 例

### ストレージ層のメジャーコンパクション関連の例

* 通常のテナントが自身の日次コンパクションを開始します。

  ```shell
  obclient> ALTER SYSTEM MAJOR FREEZE;
  Query OK, 0 rows affected
  ```

* 通常のテナント自身の日次コンパクションを一時停止します。

  ```shell
  obclient> ALTER SYSTEM SUSPEND MERGE;
  Query OK, 0 rows affected
  ```

* 通常のテナント自身の日次コンパクションを再開します。

  ```shell
  obclient> ALTER SYSTEM RESUME MERGE;
  Query OK, 0 rows affected
  ```

* 通常のテナント自身のコンパクションエラーマークをクリアします。

  ```shell
  obclient> ALTER SYSTEM CLEAR MERGE ERROR;
  Query OK, 0 rows affected
  ```

### ストレージ層のダンプの例

* 通常のテナントが自身のダンプを開始します。

  ```shell
  obclient> ALTER SYSTEM MINOR FREEZE;
  Query OK, 0 rows affected
  ```
