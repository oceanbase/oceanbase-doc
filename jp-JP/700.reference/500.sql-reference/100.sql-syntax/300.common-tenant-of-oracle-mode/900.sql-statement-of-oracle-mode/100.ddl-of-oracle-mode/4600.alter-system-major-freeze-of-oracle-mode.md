# MAJORとMINOR

## 説明

このステートメントは、ユーザーテナントが自身のストレージ層のメジャーコンパクションまたはダンプを開始するために使用します。手動でのメジャーコンパクションとダンプは、テナントレベルおよびパーティションレベルをサポートしています。

## 構文

```shell
ALTER SYSTEM merge_action;

merge_action:
      MAJOR FREEZE [TABLET_ID = tablet_id]
    | MINOR FREEZE [TABLET_ID = tablet_id]
    | {SUSPEND | RESUME} MERGE
    | CLEAR MERGE ERROR
```

## パラメータの説明

|          **パラメータ**           |      **説明**      |
|---------------------------|------------------|
| MAJOR FREEZE              | メジャーコンパクションを開始します。<main id="notice" type='explain'><h4>説明</h4><p>ユーザーテナントは自身のメジャーコンパクションのみを開始できます。</p></main>      |
| MINOR FREEZE              | ダンプを開始します。 <main id="notice" type='explain'><h4>説明</h4><p>ユーザーテナントは自身のダンプのみを開始できます。</p></main>         |
| {SUSPEND \| RESUME} MERGE | メジャーコンパクションを一時停止または再開します。<main id="notice" type='explain'><h4>説明</h4><p>ユーザーテナントは自身のメジャーコンパクションのみを一時停止または再開できます。</p></main>   |
| CLEAR MERGE ERROR         | メジャーコンパクションエラーのマーカーをクリアします。<main id="notice" type='explain'><h4>説明</h4><p>ユーザーテナントは自身のメジャーコンパクションのエラーマーカーのみをクリアできます。</p></main>       |
| TABLET_ID                 | パーティションのメジャーコンパクションまたはダンプを指定します。          |

## 例

### ストレージ層のメジャーコンパクションに関連する例

* ユーザーテナントが自身のメジャーコンパクションを開始します。

  ```shell
  obclient> ALTER SYSTEM MAJOR FREEZE;
  Query OK, 0 rows affected
  ```

* ユーザーテナントがパーティションレベルのメジャーコンパクションを開始します。

  ```shell
  obclient> ALTER SYSTEM MAJOR FREEZE TABLET_ID = 5;
  Query OK, 0 rows affected
  ```

* ユーザーテナント自身のメジャーコンパクションを一時停止します。

  ```shell
  obclient> ALTER SYSTEM SUSPEND MERGE;
  Query OK, 0 rows affected
  ```

* ユーザーテナント自身のメジャーコンパクションを再開します。

  ```shell
  obclient> ALTER SYSTEM RESUME MERGE;
  Query OK, 0 rows affected
  ```

* ユーザーテナント自身のメジャーコンパクションのエラーマークをクリアします。

  ```shell
  obclient> ALTER SYSTEM CLEAR MERGE ERROR;
  Query OK, 0 rows affected
  ```

### ストレージ層のダンプに関連する例

* ユーザーテナントが自身のダンプを開始します。

  ```shell
  obclient> ALTER SYSTEM MINOR FREEZE;
  Query OK, 0 rows affected
  ```

* ユーザーテナントがパーティションレベルのダンプを開始します。

  ```shell
  obclient> ALTER SYSTEM MINOR FREEZE TABLET_ID = 5;
  Query OK, 0 rows affected
  ```
