# RENAME

## 説明

このステートメントは、テーブル、ビュー、マテリアライズドビュー、プライベートシノニム、またはシーケンスの名前を変更するために使用します。

## 構文

```sql
RENAME object_name TO new_object_name;
```

## パラメータの説明

| パラメータ | 説明 |
|------|------|
| object_name | 名前を変更する対象の名前。テーブル、ビュー、マテリアライズドビュー、プライベートシノニム、またはシーケンスが指定できます。 |
| new_object_name | 対象の新しい名前。新しい名前は既存の対象と重複してはなりません。 |

## 例

1. テーブル `tbl1` を作成します。

    ```shell
    obclient> CREATE TABLE tbl1(col1 INT, col2 INT);
    ```

2. テーブル `tbl1` の名前を `tbl2` に変更します。

    ```shell
    obclient> RENAME tbl1 TO tbl2;
    ```
