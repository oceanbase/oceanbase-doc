# RENAME

## 説明

このステートメントは、テーブル、ビュー、プライベートシノニム、またはシーケンスの名前を変更するために使用されます。

## 構文

```sql
RENAME obj_name TO new_obj_name;
```

## パラメータの説明

|      パラメータ      |            説明            |
|--------------|--------------------------|
| obj_name     | 元のオブジェクト名。                    |
| new_obj_name | 新しいオブジェクト名。新しいオブジェクト名は、既存のオブジェクトが使用している名前と同じにすることはできません。 |

## 例

テーブル `tbl1` を作成し、テーブル `tbl1` の名前を `tbl2` に変更します。

```sql
obclient> CREATE TABLE tbl1(col1 INT,col2 INT);
Query OK, 0 rows affected

obclient> RENAME tbl1 TO tbl2;
Query OK, 0 rows affected
```
