# DROP MATERIALIZED VIEW

## 説明

このステートメントは、マテリアライズドビューを削除するために使用します。

## 権限要件

マテリアライズドビューのログを削除するには、`DROP TABLE` 権限が必要です。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP MATERIALIZED VIEW [ schema. ] materialized_view;
```

## パラメータ説明

|       **パラメータ**    |       **説明**           |
|-------------------|--------------------------|
| schema.           | オプションです。マテリアライズドビューが存在するスキーマを指定します。`schema.` を省略した場合、デフォルトで現在のスキーマが使用されます。|
| materialized_view | マテリアライズドビューの名前を指定します。|

## 例

`mv_test_tbl1` という名前のマテリアライズドビューを削除します。

```sql
DROP MATERIALIZED VIEW mv_test_tbl1;
```

実行結果は次のとおりです：

```shell
Query OK, 0 rows affected
```
