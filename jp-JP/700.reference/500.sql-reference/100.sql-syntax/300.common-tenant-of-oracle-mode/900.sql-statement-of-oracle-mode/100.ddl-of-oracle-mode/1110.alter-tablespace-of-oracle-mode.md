# ALTER TABLESPACE

## 説明

このステートメントは、テーブル領域の属性を変更するために使用します。

## 構文

```sql
ALTER TABLESPACE tablespace_name
  [ ENCRYPTION USING 'algorithm' ]

algorithm:
  'AES-256' | 'AES-128' | 'AES-192' | 'SM4-CBC'
```

## パラメータの説明

| **パラメータ**        | **説明**                                           |
|---------------|--------------------------------------------------|
| tablespace_name | 変更対象のテーブル領域名                                  |
| algorithm     | 暗号化アルゴリズムの名前。'AES-256'、'AES-128'、'AES-192'、および'SM4-CBC'をサポートします |

## 例

```sql
-- テーブル領域usersを作成
obclient> CREATE TABLESPACE users;

-- テーブル領域の暗号化アルゴリズムを変更
obclient> ALTER TABLESPACE users ENCRYPTION USING 'AES-256';
```
