# CREATE SYNONYM

## 説明

このステートメントは、シノニムを作成するために使用されます。

## 構文

```sql
CREATE [ OR REPLACE ] [ PUBLIC ] SYNONYM [ synonym_schema. ]synonym_name
FOR [ object_schema. ]object_name;
```

## パラメータの説明

|       パラメータ       |                                                                                               説明                                                                                                |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OR REPLACE     | 既存の同義語名が存在する場合、新しい定義で再作成することを示します。                                                                                                                                                                |
| PUBLIC         | `PUBLIC` を指定してパブリック同義語を作成します。すべてのユーザーが使用できます。ユーザーは、その同義語を使用するために基礎オブジェクトに対する適切な権限を持っている必要があります。オブジェクトの参照を解決する際、オブジェクトにスキーマが指定されていない場合にのみ、パブリック同義語が使用されます。 `PUBLIC` を指定しない場合、同義語はプライベートであり、現在のスキーマからのみアクセス可能であり、同義語名は現在のスキーマ内で一意である必要があります。 |
| synonym_schema | 同義語が属するスキーマを指定します。 `schema.` を省略した場合、デフォルトでは同義語は自身のスキーマ内に存在します。 `PUBLIC` が指定されている場合、同義語に対して `schema` を指定する必要はありません。                                                                                                         |
| synonym_name   | 同義語の名前を指定します。                                                                                                                                                                                       |
| object_schema  | 同義語を作成するオブジェクトが属するスキーマを指定します。 `schema.` を省略した場合、デフォルトでは同義語を作成するオブジェクトは自身のスキーマ内に存在します。                                                                                                                                  |
| object_name    | 同義語が対応するオブジェクトの名前を指定します。                                                                                                                                                                                   |

## 例

* テーブルのシノニムを作成します。

  ```sql
  obclient> CREATE TABLE tbl1(col1 INT,col2 INT);
  Query OK, 0 rows affected

  obclient> CREATE SYNONYM syn1 FOR tbl1;
  Query OK, 0 rows affected

  obclient> INSERT INTO syn1 values(1,1);
  Query OK, 1 row affected

  obclient> SELECT * FROM syn1;
  +------+------+
  | COL1 | COL2 |
  +------+------+
  |    1 |    1 |
  +------+------+
  1 row in set
  ```

* `PUBLIC` シノニムを作成します。

  ```sql
  obclient> CREATE PUBLIC SYNONYM syn2 FOR tbl1;
  Query OK, 0 rows affected
  ```

## 注意事項

シノニムを作成する際には、以下の権限要件を満たす必要があります：

* 現在のスキーマでプライベートなシノニムを作成するには、`CREATE SYNONYM` 権限が必要です。

* 現在のスキーマ以外でプライベートなシノニムを作成するには、`CREATE ANY SYNONYM` 権限が必要です。

* `PUBLIC` のシノニムを作成するには、`CREATE PUBLIC SYNONYM` 権限が必要です。

* シノニムを作成する対象となるオブジェクトは存在しなくても構いませんし、アクセス権限を持っていなくても構いません。

```sql
/*ユーザー synonym_user を作成*/
obclient> CREATE USER synonym_user IDENTIFIED BY synonym_user;
Query OK, 0 rows affected

obclient> GRANT CREATE ON *.* TO synonym_user;
Query OK, 0 rows affected

obclient> GRANT SELECT ON *.* TO synonym_user;
Query OK, 0 rows affected

/*ユーザー synonym_user に接続*/
obclient> CREATE OR REPLACE SYNONYM syn1 FOR tbl1;
ERROR-00600: internal error code, arguments: -5036, Access denied; you need (at least one of) the CREATE SYNONYM privilege(s) for this operation

/*ユーザー synonym_user に CREATE SYNONYM 権限を付与*/
obclient> GRANT CREATE SYNONYM TO synonym_user;
Query OK, 0 rows affected

obclient> CREATE OR REPLACE SYNONYM syn1 FOR tbl1;
Query OK, 0 rows affected
```
