# CREATE CONCURRENT_LIMITING_RULE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このステートメントはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このステートメントはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>

## 説明

このステートメントは、レート制限ルールを作成し、特定のSQLの並列度を制限するためのレート制限範囲を指定します。

## 注意事項

OceanBaseデータベースのOracleモードで`CREATE CONCURRENT_LIMITING_RULE`ステートメントを実行するには、専用権限`create any concurrent_limiting_rule`が必要です。

## 構文

```sql
CREATE CONCURRENT_LIMITING_RULE ccl_rule_name
ON `database`.`table`
TO '<usename>'@'ip'
FOR { ALL | UPDATE | SELECT | INSERT | DELETE }
filter_options:
    [ FILTER BY KEYWORD('KEYWORD1', 'KEYWORD2',…) ]
 with_options:
    WITH MAX_CONCURRENCY = value1 [per sql]
```

## パラメータの説明

| パラメータ             |       説明        |
|----------------------------|----------|
|`ccl_rule_name`|必須。レート制限ルールの名前を表します。|
|`database`.`table`|必須。データベースとテーブルの名前を表します。アスタリスク（*）を使用して任意の文字列に一致させることができます。<main id="notice" type='explain'><h4>説明</h4><p>名前がSQLキーワードと競合するのを避けるため、ルール名の前後にバッククォート（`）を付けることを推奨します。</p></main>|
|`<usename>@<host>`|必須。アカウント名を表します。Host部分では、パーセント記号（%）を使用して任意の文字列に一致させることができます。|
|`ALL`\|`UPDATE \| SELECT \| INSERT\| DELETE`|必須。SQL文のタイプを表します。現在、`ALL`、`UPDATE`、`SELECT`、`INSERT`、`DELETE`タイプをサポートしています。<main id="notice" type='explain'><h4>説明</h4><p>各レート制限ルールは、1種類のSQL文タイプのみを指定できます。</p></main>|
|`[ filter_options ]`|オプション。レート制限のキーワードを表します。<main id="notice" type='explain'><h4>説明</h4><p><ul><li>キーワード間はワイルドカード<code>%</code>で結合されます。例えば、3つのキーワード<code>"asdasd", "c2 = 123", "xxyyzz"</code>を指定すると、<code>"%asdasd%c2 = 123%xxyyzz%"</code>という文字列が作成され、以降のSQLテキストのワイルドカード検索ではこの文字列が使用されます。</li><li>キーワードに<code>'_'</code>が含まれる場合、エスケープされます。例えば、<code>"table_t1"</code>は<code>"%table\_t1%"</code>として記録されます。</li><li>レート制限のキーワードに数の制限はありませんが、組み合わせた文字列の長さは <code>OB_MAX_VARCHAR_LENGTH=1048576</code>を超えてはなりません。</li></ul></p></main>|
|`with_options`|必須。レート制限の並列度を制御し、レート制限の統計粒度がルールレベルか、Format SQLID文レベルかを指定します。現在、`MAX_CONCURRENCY`パラメータのみをサポートしており、このレート制限ルールにマッチするSQL文の最大並列度を表します。|

## 例

以下のコマンドを実行して、キーワードのレート制限を行います：

```shell
obclient> CREATE CONCURRENT_LIMITING_RULE   sql1_keywords_ccl_rule
ON *.* TO '%'@'%' FOR SELECT
FILTER BY KEYWORD('table1', 'table2', 'c1') WITH MAX_CONCURRENCY 100;
```
