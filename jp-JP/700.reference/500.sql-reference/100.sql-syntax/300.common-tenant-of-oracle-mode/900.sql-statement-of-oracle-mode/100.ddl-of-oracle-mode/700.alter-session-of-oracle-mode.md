# ALTER SESSION

## 説明

このステートメントは、セッションの状態などの情報を設定または変更するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>ALTER SESSION</code> は複数の機能を持つステートメントに対応しており、OceanBaseデータベースでは現在以下の4種類がサポートされています：</p>
    <ul>
    <li>現在のセッションが接続しているデータベースを切り替えます。</li>
    <li>現在のセッションの分離レベルを変更します。</li>
    <li>セッション変数を設定します。同一ステートメントで複数の変数を設定できます。</li>
    <li><code>QUERY</code> または <code>DML</code> のパラレル実行機能を設定します。</li>
    </ul>
  </main>

## 構文

```sql
ALTER SESSION {
  alter_session_set_clause
| { ENABLE | DISABLE | FORCE } PARALLEL { DML | QUERY } [ PARALLEL integer ]
};

alter_session_set_clause：
SET {
  CURRENT_SCHEMA = current_schema_name
| ISOLATION_LEVEL = [ READ UNCOMMITTED
                                   | READ COMMITTED
                                   | REPEATABLE READ
                                   | SERIALIZABLE];
| variable_name = variable_value[,variable_name = variable_value...]
}
```

## パラメータの説明

|                                               パラメータ                                               |                                                                                                                                                                                                                      説明                                                                                                                                                                                                                       |
|------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CURRENT_SCHEMA                                                                                 | Session接続が切り替えるスキーマ名を指定します。                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ISOLATION_LEVEL                                                                                | Sessionの分離レベルを指定します。                                                                                                                                                                                                                                                                                                                                                                                                                             |
| variable_name = variable_value\[,variable_name = variable_value...\];                          | 設定するSession変数の名前と値を指定します。複数の変数を設定する場合、変数間にカンマで区切る必要はありません。                                                                                                                                                                                                                                                                                                                                                                                                    |
| * { ENABLE \| DISABLE \| FORCE } PARALLEL    | `QUERY`または`DML`のパラレル実行機能を設定します： * `ENABLE`：デフォルトでは、Session上の並列度の値はテーブルのDOP値に基づいて決定されます   <ul><li> `DISABLE`：デフォルトでは、Session上の並列度の値は1です。    </li><li> `FORCE`：`QUERY`または`DML`の並列度の値を指定します。この場合、パラメータ`PARALLEL integer`を指定する必要があります。</li></ul>    **注記** 並列度を指定する際の優先順位は以下の通りです：  ヒントによって指定された並列度 \> `ALTER SESSION`によって指定された並列度 \> テーブルレベルの並列度。 |

## 例

* ユーザーを`user1`モードに切り替えます。

  ```sql
  obclient> ALTER SESSION SET CURRENT_SCHEMA = user1;
  Query OK, 0 rows affected
  ```

* Sessionの変数値`recyclebin`、`sqlwarnings`、`tx_isolation`を変更します。

  ```sql
  obclient> ALTER SESSION SET recyclebin = 'on'
                             sql_warnings = 'on'
                             tx_isolation = 'read-committed';
  Query OK, 0 rows affected
  ```

* Session上で`QUERY`と`DML`のパラレル実行を設定します。

  ```sql
  /*並列度3でパラレル実行*/
  obclient> ALTER SESSION FORCE PARALLEL QUERY PARALLEL 3;
  Query OK, 0 rows affected

  obclient> SELECT * FROM tbl1;
  +------+------+
  | COL1 | COL2 |
  +------+------+
  |    1 |    1 |
  +------+------+
  1 row in set

  /*直列実行*/
  obclient> ALTER SESSION FORCE PARALLEL QUERY PARALLEL 1;
  Query OK, 0 rows affected

  obclient> SELECT * FROM tbl1;
  +------+------+
  | COL1 | COL2 |
  +------+------+
  |    1 |    1 |
  +------+------+
  1 row in set

  /*PDMLパスを有効化し、並列度3でパラレル実行*/
  obclient> ALTER SESSION FORCE PARALLEL DML PARALLEL 3;
  Query OK, 0 rows affected

  obclient> INSERT INTO tbl2 SELECT * FROM tbl1;
  Query OK, 1 row affected

  /*直列実行*/
  obclient> ALTER SESSION FORCE PARALLEL DML PARALLEL 1;
  Query OK, 0 rows affected

  obclient> INSERT INTO tbl2 SELECT * FROM tbl1;
  Query OK, 1 row affected
  ```
