# CREATE ROLE

## 説明

このステートメントは、ロールを作成するために使用されます。ロールを使用してデータベース権限を管理できます。

ロールに権限を追加し、そのロールをユーザーに付与することができます。ユーザーはそのロールを有効化して、ロールから付与された権限を行使できます。

## 構文

```sql
CREATE ROLE role_name
[ NOT IDENTIFIED
| IDENTIFIED BY password
] ;
```

## パラメータの説明

|           パラメータ           |                                                               説明                                                                |
|------------------------|---------------------------------------------------------------------------------------------------------------------------------|
| role_name              | 作成するロールの名前を指定します。                                                                                                                    |
| NOT IDENTIFIED         | 作成されるロールを有効にする際に、いかなる検証方法も使用しないことを指定します。<br> **説明**  `NOT IDENTIFIED` 句と `IDENTIFIED` 句が省略された場合、ロールはデフォルトで `NOT IDENTIFIED` に設定されます。 |
| IDENTIFIED BY password | 有効化されるロールのパスワードを設定します。<br> **説明**  このロールを付与されたユーザーは、`SET ROLE` ステートメントを使用してこのロールを有効にするには、パスワードを指定する必要があります。                                      |

## 例

* ロール `role1` を作成します。

  ```sql
  obclient> CREATE ROLE role1;
  Query OK, 0 rows affected
  ```

* ロール `role2` を作成し、パスワードを `**1***` と指定します。

  ```sql
  obclient> CREATE ROLE role2 IDENTIFIED BY **1***;
  Query OK, 0 rows affected
  ```
