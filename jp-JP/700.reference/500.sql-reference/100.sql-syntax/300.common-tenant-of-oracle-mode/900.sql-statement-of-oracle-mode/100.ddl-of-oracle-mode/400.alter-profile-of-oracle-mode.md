# ALTER PROFILE

## 説明

このステートメントは、プロファイルにパスワード管理パラメータを追加、変更、または削除するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>ALTER PROFILE</code> ステートメントで設定ファイルに加えられた変更は、その後のセッションのユーザーにのみ影響を及ぼし、現在のセッションのユーザーには影響しません。</p>
  </main>

## 構文

```sql
ALTER PROFILE "profile_name"
   LIMIT
   {
     FAILED_LOGIN_ATTEMPTS integer | UNLIMITED | DEFAULT
   | PASSWORD_LIFE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_LOCK_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_VERIFY_FUNCTION function_name | NULL | DEFAULT
   | PASSWORD_GRACE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_ROLLOVER_TIME bigint(20) | UNLIMITED | DEFAULT
   };
```

## パラメータの説明

|          パラメータ           |               説明                |
|-----------------------|---------------------------------|
| profile_name          | 変更するプロファイル名を指定します。                  |
| FAILED_LOGIN_ATTEMPTS | ユーザーアカウントの連続ログイン失敗回数を指定します。                |
| PASSWORD_LOCK_TIME    | アカウントが制限回数内に連続してログインに失敗した後、アカウントがロックされる日数を指定します。 |
| PASSWORD_LIFE_TIME    | 同一パスワードを認証に使用できる有効日数を指定します。             |
| PASSWORD_GRACE_TIME   | 警告が解除され、アカウントのログインが許可される猶予期間の日数を指定します。          |
| PASSWORD_VERIFY_FUNCTION | パスワードの検証に使用する関数名を指定します。                |
| PASSWORD_ROLLOVER_TIME | パスワードローテーションの有効期間を指定します。単位はマイクロ秒です。ローテーション有効期間中は、古いパスワードと新しいパスワードを同時に認証に使用できます。<main id="notice" type="explain"><h4>説明</h4><p>このパラメータはV4.4.2 BP1バージョンからサポートされています。</p></main> |
| integer               | このパラメータに設定された制限タイプが整数であることを示します。             |
| UNLIMITED             | このパラメータに制限が設定されていないことを示します。                   |
| DEFAULT               | このパラメータのデフォルト制限を使用することを示します。                   |
| function_name         | パスワードの検証に使用する関数名を示します。                   |
| NULL                  | いかなる検証関数も使用しないことを示します。                     |

## 例

* ログイン試行回数とパスワードロック時間の制限を変更する：プロファイル `profile1` の `FAILED_LOGIN_ATTEMPTS` を `5` 回、`PASSWORD_LOCK_TIME` を `1` 日に設定します。

  ```sql
  obclient> ALTER PROFILE "profile1" LIMIT FAILED_LOGIN_ATTEMPTS 5 PASSWORD_LOCK_TIME 1;
  ```

* パスワードの有効期間と猶予期間を変更する：プロファイル `profile2` の `PASSWORD_LIFE_TIME` を `90` 日、`PASSWORD_GRACE_TIME` を `5` 日に設定します。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT PASSWORD_LIFE_TIME 90 PASSWORD_GRACE_TIME 5;
  ```

* パスワードローテーションの有効期間の変更：設定ファイル `profile3` の `PASSWORD_ROLLOVER_TIME` を `86400000000` マイクロ秒（例値）に設定します。

  ```sql
  obclient> ALTER PROFILE "profile3" LIMIT PASSWORD_ROLLOVER_TIME 86400000000;
  ```
