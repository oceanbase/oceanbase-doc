# ALTER PROFILE

## 説明

このステートメントは、プロファイルにリソース制限パラメータとパスワード管理パラメータを追加、変更、または削除するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>ALTER PROFILE</code> ステートメントでプロファイルに加えられた変更は、その後のセッションのユーザーにのみ影響を及ぼし、現在のセッションのユーザーには影響しません。</p>
  </main>

## 構文

```sql
ALTER PROFILE "profile_name"
   LIMIT
   {
     FAILED_LOGIN_ATTEMPTS integer | UNLIMITED | DEFAULT
   | IDLE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_LIFE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_LOCK_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_VERIFY_FUNCTION function_name | NULL | DEFAULT
   | PASSWORD_GRACE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_ROLLOVER_TIME bigint(20) | UNLIMITED | DEFAULT
   };
```

## パラメータの説明

|          パラメータ           |               説明                |
|-----------------------|---------------------------------|
| profile_name          | 変更するプロファイル名を指定します。                  |
| FAILED_LOGIN_ATTEMPTS | ユーザーアカウントの連続ログイン失敗回数を指定します。                |
| IDLE_TIME | セッションの最大アイドル時間を分単位で指定します。正の整数を指定すると、セッションのアイドル時間がこの値を超えた場合に、データベースが自動的に接続を切断します。この設定は `wait_timeout` および `interactive_timeout` より優先して適用されます。`0` はこのパラメータが無効であり、アイドルタイムアウトは `wait_timeout` によって制御されることを意味します（インタラクティブ接続の場合は `interactive_timeout`）。`UNLIMITED` はアイドル時間を無制限にすることを意味します。`DEFAULT` は `DEFAULT` プロファイルの値を継承することを意味します。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このパラメータはV4.4.2 BP4バージョンからサポートされています。</li><li>Oracleでは、<code>IDLE_TIME</code>が<code>0</code>の場合、アイドル時間は無制限であることを意味します。OceanBaseでは、<code>0</code>はこのパラメータが無効であることを意味します。アイドル時間を無制限にする必要がある場合は、<code>UNLIMITED</code>に設定してください。</li></ul></main> |
| PASSWORD_LOCK_TIME    | アカウントが制限回数内に連続してログインに失敗した後、アカウントがロックされる日数を指定します。 |
| PASSWORD_LIFE_TIME    | 同一パスワードを認証に使用できる有効日数を指定します。             |
| PASSWORD_GRACE_TIME   | 警告が解除され、アカウントのログインが許可される猶予期間の日数を指定します。          |
| PASSWORD_VERIFY_FUNCTION | パスワードの検証に使用する関数名を指定します。                |
| PASSWORD_ROLLOVER_TIME | パスワードローテーションの有効期間を指定します。単位は日です。ローテーション有効期間中は、古いパスワードと新しいパスワードを同時に認証に使用できます。値 `0` は古いパスワードによる認証を無効にすることを意味します。<main id="notice" type="explain"><h4>説明</h4><p>このパラメータはV4.4.2 BP1バージョンからサポートされています。V4.4.2 BP4バージョン以降は、パラメータの値を検証します。0以外の場合、値の範囲は10秒～60日でなければならず、<code>PASSWORD_LIFE_TIME</code> や、0でも<code>UNLIMITED</code> でもない場合の <code>PASSWORD_GRACE_TIME</code> より大きくしてはなりません。そうでない場合はエラーが発生します。</p></main> |
| integer               | このパラメータの制限値を整数で指定することを示します。             |
| UNLIMITED             | このパラメータに制限が設定されていないことを示します。                   |
| DEFAULT               | このパラメータのデフォルト制限を使用することを示します。                   |
| function_name         | パスワードの検証に使用する関数名を示します。                   |
| NULL                  | いかなる検証関数も使用しないことを示します。                     |

## 使用上の制限と注意事項

* 変更時はステートメントで指定されたパラメータのみが更新され、指定されていないパラメータ（設定済みの `IDLE_TIME` を含む）は元の値のまま維持されます。

* 変更は新規作成されたセッションにのみ適用され、既に確立されたセッションには影響しません。

## 例

* ログイン試行回数とパスワードロック時間の制限を変更する：プロファイル `profile1` の `FAILED_LOGIN_ATTEMPTS` を `5` 回、`PASSWORD_LOCK_TIME` を `1` 日に設定します。

  ```sql
  obclient> ALTER PROFILE "profile1" LIMIT FAILED_LOGIN_ATTEMPTS 5 PASSWORD_LOCK_TIME 1;
  ```

* パスワードの有効期間と猶予期間を変更する：プロファイル `profile2` の `PASSWORD_LIFE_TIME` を `90` 日、`PASSWORD_GRACE_TIME` を `5` 日に設定します。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT PASSWORD_LIFE_TIME 90 PASSWORD_GRACE_TIME 5;
  ```

* パスワードローテーションの有効期間の変更：プロファイル `profile3` の `PASSWORD_ROLLOVER_TIME` を `5` 日（例としての値）に設定します。

  ```sql
  obclient> ALTER PROFILE "profile3" LIMIT PASSWORD_ROLLOVER_TIME 5;
  ```

* セッションの最大アイドル時間を変更する：プロファイル `profile2` の `IDLE_TIME` を `30` 分に設定します。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT IDLE_TIME 30;
  ```

* セッションの最大アイドル時間制限を解除する：プロファイル `profile2` の `IDLE_TIME` を `UNLIMITED` に設定します。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT IDLE_TIME UNLIMITED;
  ```

* セッションの最大アイドル時間を `DEFAULT` プロファイルの値に戻す：プロファイル `profile2` の `IDLE_TIME` を `DEFAULT` に設定します。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT IDLE_TIME DEFAULT;
  ```
