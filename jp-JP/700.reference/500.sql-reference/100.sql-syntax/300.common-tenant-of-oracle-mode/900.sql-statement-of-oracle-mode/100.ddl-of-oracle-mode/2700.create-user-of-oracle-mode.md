# CREATE USER

## 説明

`CREATE USER` ステートメントは、新しいOceanBaseデータベースユーザーを作成するために使用します。新しいユーザーを作成後、そのユーザーでOceanBaseデータベースに接続できます。

## 権限要件

`CREATE USER` ステートメントを実行してユーザーを作成するには、現在のユーザーが `CREATE USER` システム権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
CREATE USER user_name
    IDENTIFIED BY [VALUES] password
    [REQUIRE {NONE | SSL | X509 | tls_option}]
    [PROFILE profile_name]
    [DEFAULT TABLESPACE tablespace_name];

tls_option:
      CIPHER cipher_name
    | ISSUER issuer_name
    | SUBJECT subject_name
```

## パラメータ説明

| パラメータ   | 説明     |
|-------|-----------|
| user_name | ユーザー名です。新規ユーザー作成後、`dba_users` テーブルにそのユーザーのレコードが追加されます。同名のユーザーが既に存在する場合はエラーが発生します。 |
| IDENTIFIED BY | 作成予定のユーザーのパスワードを設定します。ここではパスワードは平文で、`dba_users` テーブルに格納された後、サーバー側で暗号化されます。パスワードに特殊文字 <code>~!@#%^&*_-+=`\|(){}[]:;',.?/</code> を含める場合は、英字の二重引用符（<code>"</code>）で囲む必要があります。 |
| IDENTIFIED BY VALUES | 作成予定のユーザーのパスワードを設定します。ここではパスワードは暗号文で、直接 `dba_users` テーブルに格納されます。 |
| REQUIRE | ユーザーのパスワード認証要件を指定します。以下の値があります。<ul><li>`NONE`：ユーザーにパスワード認証要件がないことを示し、ユーザーは任意のパスワードを使用するか、パスワードを設定しなくてもよいことを意味します。</li><li>`SSL`：ユーザーはSSL接続を使用して認証を行う必要があることを示します。</li><li>`X509`：ユーザーはX509証書を使用して認証を行う必要があることを示します。</li><li>`tls_option`：ユーザーは指定されたTLS（Transport Layer Security）要件を満たす必要があることを示します。</li></ul> |
| tls_option | TLS要件の具体的なオプションを指定します。<ul><li>`CIPHER`：TLS接続で使用する暗号アルゴリズムまたは暗号スイートを指定します。</li><li>`ISSUER`：TLS証書の発行者（Issuer）を指定します。</li><li>`SUBJECT`：TLS証書の主体（Subject）を指定します。</li></ul> |
| PROFILE | ユーザープロファイルを指定します。ユーザープロファイルは、作成するユーザーに適用可能な一連の事前定義された権限と制限です。 |
| DEFAULT TABLESPACE | ユーザーのデフォルトテーブル領域を指定します。テーブル領域はユーザーデータを格納するための論理構造です。 |

## 例

* ユーザー `test1` を作成し、平文パスワードを指定します。

  ```sql
  obclient [SYS]> CREATE USER test1 IDENTIFIED BY "********";
  ```

* ユーザー `test2` を作成し、暗号化されたパスワードを指定すると同時に、SSL接続を使用した認証を必須とします。

  ```sql
  obclient [SYS]> CREATE USER test2 IDENTIFIED BY VALUES "********" REQUIRE SSL;
  ```
