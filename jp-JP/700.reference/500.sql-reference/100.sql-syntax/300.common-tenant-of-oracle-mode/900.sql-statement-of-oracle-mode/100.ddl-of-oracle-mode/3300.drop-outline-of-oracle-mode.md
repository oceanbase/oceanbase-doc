# DROP OUTLINE

## 説明

このステートメントは、OceanBaseデータベース内のアウトラインを削除するために使用されます。

## 構文

```sql
DROP [FORMAT] OUTLINE outline_name;
```

## パラメータの説明

|   **パラメータ**   | **説明** |
|--------------|----------|
| FORMAT       | オプションです。`FORMAT OUTLINE`（あいまいアウトライン）を削除します。|
| outline_name | 削除するアウトライン名を指定します。|

## 例

テストテーブルと関連するアウトラインを作成し、その後削除します。

1. テーブル `employees` を作成します。

    ```shell
    obclient> CREATE TABLE employees (emp_id INT, emp_name VARCHAR(20));
    ```

2. テーブル `employees` にテストデータを挿入します。

    ```shell
    obclient> INSERT INTO employees VALUES (1, 'John'), (2, 'Alice');
    ```

3. アウトラインを作成します。

    ```shell
    obclient> CREATE OUTLINE emp_query_outline
        ON SELECT * FROM employees WHERE emp_id=1;
    ```

4. アウトラインを削除します。

    ```shell
    obclient> DROP OUTLINE emp_query_outline;
    ```

5. テストテーブルを削除します。

    ```shell
    obclient> DROP TABLE employees;
    ```
