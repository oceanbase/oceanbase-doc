# DROP OUTLINE

## 説明

このステートメントは、OceanBaseデータベース内のアウトラインを削除するために使用します。

## 構文

```sql
DROP [FORMAT] OUTLINE outline_name
    [BINDING_RULE (binding_item)];

binding_item:
    SCOPE = {DATABASE | TENANT}
```

## パラメータの説明

|   **パラメータ**   | **説明** |
|--------------|----------|
| FORMAT       | オプションです。`FORMAT OUTLINE`（あいまいアウトライン）を削除することを示します。Formatテンプレートアウトラインを含みます。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.x系では、V4.4.2 BP4バージョンからFormatテンプレートアウトラインの削除がサポートされています。</p></main>|
| outline_name | 削除するアウトライン名を指定します。|
| BINDING_RULE (binding_item) | オプションです。削除するアウトラインの範囲を指定します。<ul><li>`BINDING_RULE (SCOPE = DATABASE)`：デフォルト値です。現在のデータベースレベルのアウトラインを削除します。`BINDING_RULE` パラメータを明示的に指定しない場合と同じです。</li><li>`BINDING_RULE (SCOPE = TENANT)`：指定した名前の、データベースをまたぐテナントレベルのアウトラインを削除します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.x系では、V4.4.2 BP3以降で <code>BINDING_RULE</code> 句が導入されています。</p></main>|

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul><li>Formatアウトライン（Formatテンプレートアウトラインを含む）を削除する場合は、<code>FORMAT</code> キーワードを指定する必要があります。<code>FORMAT</code> を指定しない場合、システムは通常のアウトラインとして検索し、同名の通常アウトラインが見つからないため <code>doesn't exist</code> エラーが発生します。</li><li>Formatアウトラインと通常アウトラインは相互に独立しており、同名だがタイプが異なる2つのアウトラインは同時に存在できます。<code>FORMAT</code> を指定して個別に削除する必要があります。</li></ul>
</main>

## 例

テストテーブルと関連するアウトラインを作成し、その後削除します。

1. テーブル `employees` を作成します。

    ```shell
    obclient> CREATE TABLE employees (emp_id INT, emp_name VARCHAR(20));
    ```

2. テーブル `employees` にテストデータを挿入します。

    ```shell
    obclient> INSERT INTO employees VALUES (1, 'John'), (2, 'Alice');
    ```

3. アウトラインを作成します。

    ```shell
    obclient> CREATE OUTLINE emp_query_outline
        ON SELECT * FROM employees WHERE emp_id=1;
    ```

4. アウトラインを削除します。

    ```shell
    obclient> DROP OUTLINE emp_query_outline;
    ```

5. テストテーブルを削除します。

    ```shell
    obclient> DROP TABLE employees;
    ```

FormatテンプレートOutlineを削除します。

```shell
obclient> DROP FORMAT OUTLINE emp_format_outline;
```
