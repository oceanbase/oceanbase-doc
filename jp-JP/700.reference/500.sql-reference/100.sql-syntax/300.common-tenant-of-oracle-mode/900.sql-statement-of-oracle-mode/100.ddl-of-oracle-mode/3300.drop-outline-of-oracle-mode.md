# DROP OUTLINE

## 説明

このステートメントは、OceanBaseデータベース内のアウトラインを削除するために使用されます。

## 構文

```sql
DROP OUTLINE outline_name；
```

## パラメータの説明

|      パラメータ      |         説明         |
|--------------|--------------------|
| outline_name | 削除するアウトライン名を指定します。 |

## 例

アウトライン`outline1`を削除します。

```sql
obclient> DROP OUTLINE outline1;
Query OK, 0 rows affected
```
