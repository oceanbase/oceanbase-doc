# DROP ROLE

## 説明

このステートメントは、ロールを削除するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>削除されたロールは、そのロールが付与されていたすべてのユーザーおよびロールから取り消され、データベースからも削除されます。このロールが有効化されていたユーザーセッションには影響しません。ただし、ロールが削除された後は、新しいユーザーセッションでこのロールを有効化することはできません。</p>
  </main>

## 構文

```sql
DROP ROLE role_name ;
```

## パラメータの説明

|    パラメータ     |      説明      |
|-----------|--------------|
| role_name | 削除するロールの名前を指定します。 |

## 例

ロール`role1`を削除します。

```sql
obclient> DROP ROLE role1;
Query OK, 0 rows affected
```
