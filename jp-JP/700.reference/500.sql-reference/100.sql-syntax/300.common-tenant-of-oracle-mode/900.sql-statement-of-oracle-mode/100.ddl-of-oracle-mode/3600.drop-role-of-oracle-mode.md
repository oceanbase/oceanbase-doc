# DROP ROLE

## 説明

このステートメントは、ロールを削除するために使用します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
      <p>ロールを削除した後：</p>
      <ul>
      <li>そのロールは、このロールを付与されているすべてのユーザーおよびロールから解除されます。</li>
      <li>そのロールはデータベースから削除されます。</li>
      <li>そのロールが有効なユーザーセッションは影響を受けません。</li>
      <li>新しいユーザーセッションでは、そのロールを有効にできません。</li>
      </ul>
  </main>

## 構文

```sql
DROP ROLE role_name
```

## パラメータの説明

|    パラメータ     |      説明      |
|-----------|--------------|
| role_name | 削除するロール名を指定します。 |

## 例

まず、ロール `sales_manager` を作成し、次にそのロールを削除します。

```sql
obclient> CREATE ROLE sales_manager;
obclient> DROP ROLE sales_manager;
```
