# ALTER SYSTEM FLUSH CACHE

## 説明

キャッシュを削除します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>Oracleテナントの場合、テナント内の特定のSQLまたはスキーマのプランキャッシュをクリアするには、<a href="../../../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/12500.dbms-plan-cache-oracle/100.dbms-plan-cache-overview-oracle.md">DBMS_PLAN_CACHE</a> システムパッケージを使用する必要があります。</p>
  </main>

## 構文

```sql
ALTER SYSTEM FLUSH {PLAN
                  | LIB } CACHE [GLOBAL]
```

## パラメータの説明

| パラメータ | 説明 |
|---------|------|
| PLAN | 実行計画キャッシュをクリアします |
| LIB | Lib Cacheをクリアします |

## 例

```sql
obclient> ALTER SYSTEM FLUSH PLAN CACHE GLOBAL;
```
