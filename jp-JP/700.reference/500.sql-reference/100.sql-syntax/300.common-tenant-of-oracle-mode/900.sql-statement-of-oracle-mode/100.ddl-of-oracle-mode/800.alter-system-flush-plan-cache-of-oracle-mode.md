# ALTER SYSTEM FLUSH PLAN CACHE

## 説明

計画キャッシュを削除します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>Oracleテナントの場合、特定のSQLまたはスキーマの計画キャッシュをクリアするには、<a href="../../../../300.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/12500.dbms-plan-cache-oracle/100.dbms-plan-cache-overview-oracle.md">DBMS_PLAN_CACHE</a>システムパッケージを使用する必要があります。</p>
  </main>

## 構文

```unknow
ALTER SYSTEM FLUSH PLAN CACHE [GLOBAL]；
```

## パラメータの説明

|   パラメータ   |                                   説明                                   |
|--------|------------------------------------------------------------------------|
| GLOBAL | オプションのフィールドです。このパラメータを指定しない場合、現在のマシン上の計画キャッシュがクリアされます。指定した場合、そのテナントが存在するすべてのサーバー上の計画キャッシュがクリアされます。 |

## 例

```sql
obclient> ALTER SYSTEM FLUSH PLAN CACHE GLOBAL;
Query OK, 0 rows affected
```
