# ALTER EXTERNAL TABLE

## 説明

このステートメントは、外部テーブルのファイルを手動で更新するために使用します。単一ファイルのテーブルデータは自動的に更新できますが、外部テーブルデータがファイルリストから取得している場合は自動更新できず、手動でリフレッシュする必要があります。

## 構文

```sql
ALTER EXTERNAL TABLE table_name
    ( REFRESH
    | alter_table_action_list
    | ADD PARTITION ('partition_spec') LOCATION 'path'
    | DROP PARTITION LOCATION 'path'
    | exclude_alter_table_action)

alter_table_action_list:
    alter_table_action [, alter_table_action ...]

exclude_alter_table_action:
alter_partition_option
modify_partition_info
auto_split_range_partition_option
```

`alter_table_action_list` および `exclude_alter_table_action` の詳細については、[ALTER TABLE](1000.alter-table-of-oracle-mode.md)を参照してください。

## パラメータ説明

`table_name` は、リフレッシュする外部テーブル名を指定します。

## 例

```shell
obclient> ALTER EXTERNAL TABLE lineitem REFRESH;
```
