# ALTER ROLE

## 説明

ロールの認証方式を変更するために使用します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>既にロールが付与されているユーザーのセッションは影響を受けません。</p>
  </main>

## 構文

```sql
ALTER ROLE role_name
{ NOT IDENTIFIED
| IDENTIFIED BY password
} ;
```

## パラメータの説明

| パラメータ    | 説明     |
|-----------|------------|
| `role_name`            | 変更対象のロール名を指定します。STRING_VALUE、NAME_OB、または事前定義済みのロール名(DBA、RESOURCE、CONNECT、PUBLIC)が指定できます。 |
| `NOT IDENTIFIED`       | ロールを有効化する際に認証方式を使用しないことを指定します。  |
| `IDENTIFIED BY password` | ロールを有効化するための認証パスワードを指定します。**説明** このロールを付与されたユーザーは、`SET ROLE` ステートメントでこのロールを有効化するには、パスワードを指定する必要があります。       |

## 例

* ロール `role1` を作成し、ロール `role1` の認証方式をパスワード認証に変更します。パスワードは `password1` です。

  ```sql
  obclient> CREATE ROLE role1;

  obclient> ALTER ROLE role1 IDENTIFIED BY password1;
  ```

* ロール `role1` の認証パスワードを `password2` に変更します。

  ```sql
  obclient> ALTER ROLE role1 IDENTIFIED BY password2;
  ```

* ロール `role1` を無認証で有効化可能に変更します。

  ```sql
  obclient> ALTER ROLE role1 NOT IDENTIFIED;
  ```
