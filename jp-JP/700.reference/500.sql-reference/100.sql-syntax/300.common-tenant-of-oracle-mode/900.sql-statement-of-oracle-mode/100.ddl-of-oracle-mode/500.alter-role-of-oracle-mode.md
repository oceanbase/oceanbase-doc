# ALTER ROLE

## 説明

このステートメントは、ロールを有効にするために必要な認証方式を変更します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>このロールが有効になっているユーザーセッションには影響しません。</p>
  </main>

## 構文

```sql
ALTER ROLE role_name
{ NOT IDENTIFIED
| IDENTIFIED BY password
} ;
```

## パラメータの説明

|           パラメータ           |                                              説明                                              |
|------------------------|----------------------------------------------------------------------------------------------|
| role_name              | 変更対象のロール名を指定します。                                                                                 |
| NOT IDENTIFIED         | ロールを有効にする際に、いかなる認証方式も使用しないように指定します。                                                                            |
| IDENTIFIED BY password | ロールを有効にするためのパスワードを指定します。<br> **説明** このロールが付与されたユーザーは、`SET ROLE` ステートメントでこのロールを有効にするには、パスワードを指定する必要があります。 |

## 例

* ロール `role1` を作成し、ロール `role1` の認証方式をパスワード認証に変更します。パスワードは `**1***` です。

  ```sql
  obclient> CREATE ROLE role1;
  Query OK, 0 rows affected

  obclient> ALTER ROLE role1 IDENTIFIED BY **1***;
  Query OK, 0 rows affected
  ```

* ロール `role1` の認証パスワードを `**2***` に変更します。

  ```sql
  obclient> ALTER ROLE role1 IDENTIFIED BY **2***;
  Query OK, 0 rows affected
  ```

* ロール `role1` を、いかなる認証方式も使用せずに有効化できるように変更します。

  ```sql
  obclient> ALTER ROLE role1 NOT IDENTIFIED;
  Query OK, 0 rows affected
  ```
