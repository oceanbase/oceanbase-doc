# COMMENT

## 説明

このステートメントは、テーブルまたはテーブル列、ビューまたはビュー列に関するコメントをデータディクショナリに追加します。

データベースからコメントを削除するには、空の文字列`''`に設定します。

## 構文

```sql
/*列にコメントを追加*/
COMMENT ON COLUMN
    [ schema. ] { table_name.| view_name. } column_name IS 'string';

/*テーブルまたはビューにコメントを追加*/
COMMENT ON TABLE
    [ schema. ]  {table_name | view_name } IS 'string';
```

## パラメータの説明

|     パラメータ      |                                  説明                                   |
|-------------|-----------------------------------------------------------------------|
| schema      | スキーマを指定します。`schema.` を省略した場合、OceanBaseデータベースは、コメントを追加する対象であるテーブルなどが現在のスキーマに存在すると仮定します。 |
| column_name | 列名。                                                                   |
| table_name  | テーブル名。                                                                   |
| view_name   | ビュー名。                                                                  |
| string      | コメントテキストを指定します。`string` を空文字列に設定すると、データベースからコメントが削除されます。           |

## 例

* テーブル `tbl1` にコメントを追加します。テーブルのコメントは `all_tab_comments` 、 `dba_tab_comments` 、または `user_tab_comments` テーブルを使用して照会できます。

  ```sql
  obclient> COMMENT ON TABLE tbl1 IS 'Comment of the tbl1';
  Query OK, 0 rows affected
  ```

* テーブル `tbl1` の `name` 列にコメントを追加します。テーブル列のコメントは `all_col_comments` 、 `dba_col_comments` 、または `user_col_comments` テーブルを使用して照会できます。

  ```sql
  obclient> COMMENT ON COLUMN tbl1.name IS 'Name of person in table tbl1';
  Query OK, 0 rows affected
  ```

* データベースからテーブル `tbl1` の `name` 列のコメントを削除します。

  ```sql
  obclient> COMMENT ON COLUMN tbl1.name IS '';
  Query OK, 0 rows affected
  ```

* ビュー `view1` にコメントを追加します。ビューのコメントは `all_tab_comments` 、 `dba_tab_comments` 、または `user_tab_comments` テーブルを使用して照会できます。

  ```sql
  obclient> CREATE VIEW view1 AS SELECT * FROM tbl1;
  Query OK, 0 rows affected

  obclient> COMMENT ON TABLE view1 IS 'Comment of the view1';
  Query OK, 0 rows affected
  ```

* ビュー `view1` の `name` 列にコメントを追加します。ビュー列のコメントは `all_col_comments` 、 `dba_col_comments` 、または `user_col_comments` テーブルを使用して照会できます。

  ```sql
  obclient> COMMENT ON COLUMN view1.name IS 'Name of person in view view1';
  Query OK, 0 rows affected
  ```

* データベースからビュー `view1` の `name` 列のコメントを削除します。

  ```sql
  obclient> COMMENT ON COLUMN view1.name IS '';
  Query OK, 0 rows affected
  ```
