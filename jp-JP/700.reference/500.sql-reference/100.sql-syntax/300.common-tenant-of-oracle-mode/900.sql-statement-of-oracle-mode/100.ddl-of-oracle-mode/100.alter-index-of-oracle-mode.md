# ALTER INDEX

## 説明

`AlTER INDEX` ステートメントは、既存のインデックスの名前、並列度、またはインデックスが格納されるテーブルスペースを変更するために使用されます。

## 権限要件

`AlTER INDEX` ステートメントを実行するには、現在のユーザーがALTER ANY INDEXシステム権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER INDEX [ schema.]index_name
    {  RENAME TO new_name
    | parallel_option
    | TABLESPACE tablespace_name
    };

parallel_option:
      PARALLEL [COMP_EQ] integer
    | NOPARALLEL
```

## パラメータの説明

| パラメータ | 説明 |
|-------|--------|
| schema. | インデックスが存在するスキーマを指定します。`schema.` を省略した場合、デフォルトでインデックスは自身のスキーマに存在します。 |
| index_name | 変更対象のインデックス名を指定します。 |
| new_name | インデックスの新しい名前を指定します。 |
| parallel_option | インデックス上のクエリの並列度を変更します。 <ul><li>`NOPARALLEL` : シリアル実行を指定し、並列度は1です。これがデフォルト設定です。</li><li>`PARALLEL [COMP_EQ] integer` : 並列度、つまり並列操作で使用される並列スレッド数を指定します。`PARALLEL` キーワードはインデックスのパラレル処理を有効にすることを示します。`COMP_EQ` はオプションのキーワードで、並列度の制限条件を指定するために使用されます。`integer` は値が1以上の整数であり、並列度レベルを表します。</li></ul> |
| tablespace_name | インデックスの格納先となるTableSpaceオブジェクトの名前を指定します。|

## 例

* データベースにインデックスindex1が存在すると仮定し、それをindex2にリネームします。実行例は以下のとおりです：

  ```shell
  obclient> ALTER INDEX index1 RENAME TO index2;
  ```

* データベースにインデックスindex3が存在し、そのインデックス上でのクエリの並列度が3であると仮定します。インデックスindex3の並列度を1に変更します。実行例は以下のとおりです：

  ```shell
  obclient> ALTER INDEX index3 NOPARALLEL;
  ```
