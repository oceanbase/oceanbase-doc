# DROP DIRECTORY

## 説明

このステートメントは、パスオブジェクトを削除するために使用されます。

## 権限要件

`DROP DIRECTORY` ステートメントを実行するには、現在のユーザーが `DROP ANY DIRECTORY` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP DIRECTORY directory_name
```

## パラメータの説明

|       パラメータ       |                            説明                            |
|----------------|----------------------------------------------------------|
| directory_name | 削除するパスオブジェクトを指定します。パスオブジェクトを削除しても、システム内の関連する共有ファイルシステムパスは削除されません。 |

## 例

以下の例では、まずパスオブジェクト `sql_file_dir` を作成し、その後削除します：

```sql
obclient> CREATE DIRECTORY sql_file_dir AS '/home/admin/sql_files';

obclient> DROP DIRECTORY sql_file_dir;
```

`DBA_DIRECTORIES` ビューをクエリすることで、パスオブジェクトが削除されたかどうかを確認できます：

```sql
obclient> SELECT * FROM DBA_DIRECTORIES WHERE DIRECTORY_NAME = 'SQL_FILE_DIR';
```
