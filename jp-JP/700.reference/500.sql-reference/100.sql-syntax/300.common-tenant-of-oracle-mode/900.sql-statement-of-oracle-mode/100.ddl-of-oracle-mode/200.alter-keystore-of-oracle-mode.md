# ALTER KEYSTORE

## 説明

このステートメントは、Keystoreのプロパティを変更するために使用されます。これには、Keystoreの開閉、Keystoreパスワードの変更、およびKeystoreキーの生成が含まれます。

## 構文

```sql
/* Keystoreの開閉 */
ADMINISTER KEY MANAGEMENT SET KEYSTORE [OPEN | CLOSE] IDENTIFIED BY [password];

/* キーの設定 */
ADMINISTER KEY MANAGEMENT SET KEY IDENTIFIED BY [password]
```

## パラメータの説明

|    パラメータ    |          説明          |
|----------|----------------------|
| OPEN     | Keystoreを開きます。         |
| CLOSE    | Keystoreを閉じます。         |
| password | アクセス制御用Keystoreにアクセスするためのパスワードを指定します。 |

## 例

* Keystoreを開きます。Keystoreが`open`状態である場合にのみ、暗号化テーブルにアクセスし、`SET KEY`操作を実行できます。

  ```sql
  obclient> ADMINISTER KEY MANAGEMENT SET KEYSTORE OPEN IDENTIFIED BY **1***;
  ```

* Keystoreに格納されているマスターキーを更新します。

  ```sql
  obclient> ADMINISTER KEY MANAGEMENT SET KEY IDENTIFIED BY **1***;
  ```
