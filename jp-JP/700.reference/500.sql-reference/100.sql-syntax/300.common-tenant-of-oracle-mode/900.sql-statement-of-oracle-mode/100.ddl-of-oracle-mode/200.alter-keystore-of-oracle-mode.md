# ALTER KEYSTORE

## 説明

このステートメントは、Keystoreのプロパティを変更するために使用されます。Keystoreの開閉、Keystoreパスワードの変更、Keystoreキーの生成などが含まれます。

## 構文

```sql
/* Keystoreの開閉 */
ADMINISTER KEY MANAGEMENT SET KEYSTORE [OPEN | CLOSE] IDENTIFIED BY [password];

/* Keystoreの変更 */
ADMINISTER KEY MANAGEMENT ALTER KEYSTORE PASSWORD IDENTIFIED BY password SET new_password;

/* プライマリキーの設定 */
ADMINISTER KEY MANAGEMENT SET KEY IDENTIFIED BY [password]
```

## パラメータの説明

|    パラメータ    |          説明          |
|----------|----------------------|
| OPEN     | Keystoreを開きます。         |
| CLOSE    | Keystoreを閉じます。         |
| password | Keystoreへのアクセス制御パスワードを指定します。Keystoreのパスワード長は128文字を超えてはならず、英字で始まる必要があります。 |

## 例

* Keystoreを開きます。Keystoreが`open`状態の場合にのみ、暗号化されたテーブルにアクセスし、`SET KEY`操作を実行できます。

  ```sql
  obclient> ADMINISTER KEY MANAGEMENT SET KEYSTORE OPEN IDENTIFIED BY **1***;
  ```

* Keystoreに格納されているプライマリキーを更新します。

  ```sql
  obclient> ADMINISTER KEY MANAGEMENT SET KEY IDENTIFIED BY **1***;
  ```
