# DROP CONCURRENT_LIMITING_RULE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このステートメントはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このステートメントはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>>

## 説明

このステートメントは、レート制限ルールを削除するために使用します。

## 注意事項

OceanBaseデータベースのOracleモードで`DROP CONCURRENT_LIMITING_RULE`ステートメントを実行するには、専用権限`drop any concurrent_limiting_rule`が必要です。

## 構文

```sql
DROP CONCURRENT_LIMITING_RULE [ IF EXISTS ] "ccl_rule_name1" [, "ccl_rule_name2", ...]
```

ここで、`ccl_rule_name`はレート制限ルールの名前を表します。

## 例

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>削除されたレート制限ルールは即時に無効となり、そのルールの待機キューにあるSQLステートメントはすべて正常に実行されます。</p>
</main>

以下のコマンドを実行して、レート制限ルール`sql1_keywords_ccl_rule`、`sql2_keywords_ccl_rule`を削除します。

```shell
obclient> DROP CONCURRENT_LIMITING_RULE "sql1_keywords_ccl_rule"，"sql2_keywords_ccl_rule";
```
