# DROP PROFILE

## 説明

このステートメントは、設定ファイルを削除するために使用されます。

## 構文

```sql
DROP PROFILE "profile_name";
```

## パラメータの説明

|      パラメータ      |       説明       |
|--------------|----------------|
| profile_name | 削除する設定ファイルの名前を指定します。 |

## 例

設定ファイル`profile1`を削除します。

```sql
obclient> DROP PROFILE "profile1";
Query OK, 0 rows affected
```
