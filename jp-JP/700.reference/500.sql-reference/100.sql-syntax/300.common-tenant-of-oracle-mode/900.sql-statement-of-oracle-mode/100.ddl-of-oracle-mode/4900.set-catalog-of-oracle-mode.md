# SET CATALOG

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このステートメントはV4.3.5 BP2バージョンからサポートされています。</p>
</main>

## 説明

このステートメントは、現在のセッションのCatalog（データカタログ）を切り替えるために使用します。切り替えが成功すると、現在のセッションはCatalogプレフィックスなしで、`schema_name.object_name` の形式で対象Catalog下のオブジェクトに直接アクセスできるようになります。

各セッションのデフォルトCatalogは `INTERNAL` です。`CURRENT_CATALOG()` または `CATALOG()` 関数を使用して、現在のセッションがどのCatalogにあるかを確認できます。

## 使用上の制限と注意事項

* Catalog名は大文字小文字を区別せず、二重引用符で囲まれていないCatalog名はすべて大文字に変換されてマッチングされます。
* 対象Catalogが存在しない場合、または現在のユーザーが対象Catalogに対する `USE CATALOG` オブジェクト権限を持っていない場合、エラーが発生し、エラーコードは `-11080` または `-11083` になります。

## 権限要件

指定したExternal Catalogに切り替えるには、現在のユーザーがそのCatalogに対する `USE CATALOG` オブジェクト権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
SET CATALOG catalog_name
```

## パラメータ説明

|    **パラメータ**     | **説明** |
|-----------------|----------|
| catalog_name | 対象Catalogの名前。`INTERNAL` または作成済みのExternal Catalogの名前を指定できます。大文字小文字を区別せず、二重引用符で囲まれていない場合はすべて大文字に変換されてマッチングされます。|

## 例

* システム内部Catalog `INTERNAL` に切り替えます。

  ```sql
  obclient> SET CATALOG internal;
  ```

* External Catalogを作成し、そのCatalogに切り替えます。`CURRENT_CATALOG()` 関数で現在のCatalogを確認し、最後にそのCatalogを削除します。

  ```sql
  obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

  obclient> SET CATALOG tmp_catalog;

  obclient> SELECT CURRENT_CATALOG() FROM dual;
  ```

  クエリ結果は次のとおりです：

  ```sql
  +-------------------+
  | CURRENT_CATALOG() |
  +-------------------+
  | TMP_CATALOG       |
  +-------------------+
  1 row in set
  ```

  ```sql
  obclient> SET CATALOG internal;

  obclient> DROP CATALOG tmp_catalog;
  ```
