# DROP LOCATION

## 説明

このステートメントは、Locationオブジェクトを削除するために使用します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.4.xでは、V4.4.1バージョンから <code>DROP LOCATION</code> ステートメントがサポートされています。</p>
</main>

## 権限要件

`DROP LOCATION` ステートメントを実行するには、現在のユーザーが `CREATE LOCATION` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP LOCATION location_name;
```

## パラメータ説明

|   **パラメータ**    | **説明** |
|---------------|----------|
| location_name | 削除するLocationオブジェクトの名前を表します。|

## 例

Locationオブジェクト `test_location_local` を削除します。

```shell
obclient> DROP LOCATION test_location_local;
```

## 関連ドキュメント

現在のテナント内のLocationオブジェクト情報を確認する方法については、[SHOW](../300.dcl-of-oracle-mode/3600.show-of-oracle-mode.md)を参照してください。
