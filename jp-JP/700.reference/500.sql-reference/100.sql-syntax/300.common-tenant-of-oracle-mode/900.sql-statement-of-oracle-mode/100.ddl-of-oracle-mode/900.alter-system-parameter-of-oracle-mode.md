# ALTER SYSTEM SET PARAMETER

## 説明

このステートメントは、現在のテナントのパラメータ情報を変更するために使用されます。

## 構文

```sql
ALTER SYSTEM SET parameter_name = expression;
```

## パラメータの説明

|     **パラメータ**     |    **説明**    |
|----------------|--------------|
| parameter_name | 変更対象の構成パラメータ名を指定します。 |
| expression     | 変更後の構成パラメータ値を指定します。 |

## 例

パラメータ `log_disk_utilization_threshold` の情報を変更します。

obclient> SHOW PARAMETERS LIKE 'log_disk_utilization_threshold';
