# ALTER SYSTEM PARAMETER

## 説明

このステートメントは、現在のテナントの構成パラメータ情報を変更するために使用されます。

## 構文

```sql
ALTER SYSTEM SET parameter_name = expression;
```

## パラメータの説明

|     **パラメータ**     |    **説明**    |
|----------------|--------------|
| parameter_name | 変更する構成パラメータの名前を指定します。 |
| expression     | 変更後の構成パラメータの値を指定します。 |
