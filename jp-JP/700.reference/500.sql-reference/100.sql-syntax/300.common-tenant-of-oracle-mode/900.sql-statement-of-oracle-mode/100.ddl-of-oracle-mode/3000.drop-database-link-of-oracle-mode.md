# DROP DATABASE LINK

## 説明

作成されたデータベースリンク（つまり`dblink`）を削除します。
>**説明**
>
>既に作成されたデータベースリンクを削除するには、`DROP DATABASE LINK`システム権限が必要です。

## 構文

```sql
DROP DATABASE LINK dblink_name;
```

## パラメータの説明

`dblink_name`は削除するデータベースリンクの名前です。

## 例

```sql
obclient> DROP DATABASE LINK ob_dblink;
Query OK, 1 row affected
```
