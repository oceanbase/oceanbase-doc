# DROP DATABASE LINK

## 説明

作成済みのデータベースリンク（`dblink`）を削除します。

>**説明**
>
>作成済みのデータベースリンクを削除するには、`DROP DATABASE LINK` システム権限が必要です。

## 構文

```sql
DROP DATABASE LINK dblink_name
```

## パラメータ説明

`dblink_name` は削除するデータベースリンクの名前です。

## 例

```sql
obclient> DROP DATABASE LINK ob_dblink;
```
