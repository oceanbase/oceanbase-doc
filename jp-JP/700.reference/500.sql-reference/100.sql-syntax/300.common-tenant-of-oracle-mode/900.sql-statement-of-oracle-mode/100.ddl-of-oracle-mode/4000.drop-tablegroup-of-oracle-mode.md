# DROP TABLEGROUP

## 説明

このステートメントは、テーブルグループを削除するために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>いずれかのテーブルの <code>TABLEGROUP</code> プロパティがターゲットのテーブルグループを参照している場合、そのテーブルグループは削除できません。</p>
  </main>

## 構文

```sql
DROP TABLEGROUP tablegroup_name;
```

## パラメータの説明

|       パラメータ        |     説明      |
|-----------------|-------------|
| tablegroup_name | 削除するテーブルグループ名を指定します。 |

## 例

テーブルの `TABLEGROUP` プロパティによって参照されているテーブルグループ `tblgroup1` を削除します。

1. テーブルグループ `tblgroup1` を直接削除しようとするとエラーが発生します。

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ORA-00600: internal error code, arguments: -4615, tablegroup is not empty
   ```

2. テーブルグループの情報を確認し、テーブル `tbl1` をテーブルグループ `tblgroup1` から移動します。

   ```sql
   obclient> SHOW TABLEGROUPS;
   +-----------------------+---------------+---------------------+
   | TABLEGROUP_NAME | TABLE_NAME | DATABASE_NAME |
   +-----------------------+---------------+---------------------+
   | TBLGROUP1               | TBL1               | SYS                         |

   +-----------------------+---------------+---------------------+
   1 rows in set

   obclient> ALTER TABLE tbl1 SET TABLEGROUP '';
   Query OK, 0 rows affected
   ```

3. テーブルグループ `tblgroup1` を削除します。

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   Query OK, 0 rows affected
   ```
