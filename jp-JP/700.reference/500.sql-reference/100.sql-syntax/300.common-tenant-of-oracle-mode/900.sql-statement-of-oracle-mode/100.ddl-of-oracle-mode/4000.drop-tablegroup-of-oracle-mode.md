# DROP TABLEGROUP

## 説明

このステートメントは、テーブルグループを削除するために使用します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>対象のテーブルグループを参照しているテーブルがある場合、そのテーブルグループは削除できません。</p>
  </main>

## 権限要件

`DROP TABLEGROUP` を実行するには、以下の権限が必要です：

- テーブルグループを削除するには `DROP` 権限が必要です。
- テーブルグループ内にテーブルが含まれている場合、それらのテーブルのテーブルグループ属性を変更するには `ALTER` 権限が必要です。

## 注意事項

- テーブルグループを削除しても、その中のテーブルは削除されませんが、テーブルとテーブルグループ間の関連性は解除されます。
- テーブルグループを削除する前に、業務上そのテーブルグループに依存していないことを確認してください。

## 構文

```sql
DROP TABLEGROUP tablegroup_name
```

## パラメータ説明

|       パラメータ        |     説明      |
|-----------------|-------------|
| tablegroup_name | 削除するテーブルグループ名を指定します。 |

## 例

### 例1：参照されているテーブルグループを削除する

テーブルグループが `TABLEGROUP` 属性でテーブルによって参照されている場合、テーブルグループを削除する前に、これらの参照関係を解除する必要があります。

1. 空でないテーブルグループを直接削除するとエラーが発生します：

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ```

   期待される実行結果：

   ```sql
   OBE-00600: internal error code, arguments: -4615, tablegroup is not empty
   ```

2. テーブルグループ `tblgroup1` 内のテーブルを確認する：

   ```sql
   obclient> SHOW TABLEGROUPS;
   obclient> SHOW TABLES IN tblgroup1;
   ```

3. テーブル `tbl1` をテーブルグループ `tblgroup1` から移動する：

   ```sql
   obclient> ALTER TABLE tbl1 SET TABLEGROUP = '';
   ```

4. 再度テーブルグループ `tblgroup1` を削除する：

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ```

### 例2：完全なテーブルグループの使用プロセス

1. テーブルグループを作成する：

   ```sql
   obclient> CREATE TABLEGROUP tg1;
   ```

2. テーブルを作成し、テーブルグループを指定する：

   ```sql
   obclient> CREATE TABLE t1 (id INT) TABLEGROUP = tg1;
   ```

3. テーブルグループ情報を確認する：

   ```sql
   obclient> SHOW TABLEGROUPS;
   ```

4. テーブル `t1` をテーブルグループ `tg1` から移動する：

   ```sql
   obclient> ALTER TABLE t1 SET TABLEGROUP = '';
   ```

5. テーブルグループ `tg1` を削除する：

   ```sql
   obclient> DROP TABLEGROUP tg1;
   ```
