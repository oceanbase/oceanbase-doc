# CREATE DIRECTORY

## 説明

このステートメントは、パスオブジェクトを作成するために使用します。

## 権限要件

* パスオブジェクトを作成するには、`CREATE ANY DIRECTORY` システム権限が必要です。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

* ファイル操作のセキュリティを確保するため、ファイルパスオブジェクトを作成する際には、システム変数 `secure_file_priv` を指定されたセキュリティディレクトリに設定する必要があります。詳細については、[secure_file_priv](../../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/12000.secure_file_priv-global.md)を参照してください。

## 構文

```sql
CREATE [ OR REPLACE ] DIRECTORY directory AS 'path_name';
```

## パラメータの説明

|     パラメータ   |                                        説明                                         |
|------------|------------------------------------------------------------------------------------|
| OR REPLACE | `OR REPLACE` を指定すると、対応するパスオブジェクトが既に存在する場合、新しいファイルシステムパスで既存のパス定義を置き換えます。|
| directory  | 作成するパスオブジェクトの名前を指定します。最大長は30バイトです。|
| path_name  | ファイルシステムパスを指定します。これは、共有ファイルシステムが配置される絶対パス名を定義します。パス名は大文字小文字を区別します。<main id="notice" type='notice'><h4>注意</h4><p>OceanBaseデータベースは、ユーザーのためにファイルシステム上にパスを作成しません。ユーザーが <code>path_name</code> を指定する際には、そのパスが実際に存在していることを保証する必要があります。</p></main>|

## 例

以下の手順を参照して、パスオブジェクトを作成します。

1. グローバルセキュリティパスを設定します。

   <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>セキュリティ上の理由から、システム変数 <code>secure_file_priv</code> を設定する際は、ローカルソケット接続を介してデータベースに接続し、このグローバル変数を変更するSQLステートメントを実行する必要があります。詳細については、<a href="../../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/12000.secure_file_priv-global.md">secure_file_priv</a>を参照してください。</p>
   </main>

   1. ローカルUnixソケット接続を介してOceanBaseデータベースに接続します。例：

      ```shell
      obclient -S /home/admin/test421/oceanbase/run/sql.sock -usys@oracle001 -p******
      ```

   2. グローバルセキュリティパスを設定します。

      ```shell
      obclient [SYS]> SET GLOBAL secure_file_priv = "/usr/sqldump";
      ```

2. ログアウトします。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><code>secure_file_priv</code>は<code>GLOBAL</code>変数であるため、<code>\q</code>を実行してログアウトする必要があります。</p>
   </main>

   ```shell
   obclient [SYS]> \q
   ```

3. データベースに再接続します。

   ```shell
   obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@oracle001 -p******
   ```

4. パスオブジェクト`sql_file_dir`を作成します。

   ```sql
   obclient [TEST_USER001]> CREATE OR REPLACE DIRECTORY sql_file_dir AS '/usr/sqldump';
   ```
