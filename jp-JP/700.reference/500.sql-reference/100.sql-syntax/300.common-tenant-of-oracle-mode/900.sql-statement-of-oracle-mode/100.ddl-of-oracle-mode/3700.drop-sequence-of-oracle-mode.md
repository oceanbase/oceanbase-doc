# DROP SEQUENCE

## 説明

このステートメントは、シーケンスを削除するために使用します。

## 構文

```sql
DROP SEQUENCE [schema. ] sequence_name
```

## パラメータの説明

|      パラメータ       |                            説明                             |
|---------------|-----------------------------------------------------------|
| schema.       | シーケンスを含むユーザーを指定します。`Schema` を指定しない場合、デフォルトで現在ログインしているユーザーのシーケンスが対象になります。 |
| sequence_name | 削除するシーケンス名を指定します。                                               |

## 例

シーケンスの作成と削除の例。

```sql
obclient> CREATE SEQUENCE employee_id_seq
    START WITH 1000
    INCREMENT BY 1;

obclient> DROP SEQUENCE employee_id_seq;
```
