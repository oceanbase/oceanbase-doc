# DROP SEQUENCE

## 説明

このステートメントは、シーケンスを削除するために使用されます。

## 構文

```sql
DROP SEQUENCE [schema. ] sequence_name；
```

## パラメータの説明

|      パラメータ       |                            説明                             |
|---------------|-----------------------------------------------------------|
| schema.       | シーケンスを含むユーザーを指定します。 `Schema` を指定しない場合、デフォルトで現在ログインしているユーザーのシーケンスが使用されます。 |
| sequence_name | 削除するシーケンス名を指定します。                                               |

## 例

シーケンス`seq1`を削除します。

```sql
obclient> DROP SEQUENCE seq1;
Query OK, 0 rows affected
```
