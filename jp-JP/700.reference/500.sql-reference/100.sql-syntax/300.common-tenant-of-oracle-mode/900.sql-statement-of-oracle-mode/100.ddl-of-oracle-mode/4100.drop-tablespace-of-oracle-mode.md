# DROP TABLESPACE

## 説明

このステートメントは、TableSpaceの論理オブジェクトを削除するために使用されます。TableSpaceにテーブルが存在しない場合にのみ、削除が成功します。

## 構文

```sql
DROP TABLESPACE tablespace_name;
```

## パラメータの説明

|       パラメータ        |          説明           |
|-----------------|-----------------------|
| tablespace_name | 削除するTableSpaceの名前を指定します。 |

## 例

TableSpaceオブジェクト`tblspace1`を削除します。

```sql
obclient>  DROP TABLESPACE tblspace1;
Query OK, 0 rows affected
```
