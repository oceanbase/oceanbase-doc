# DROP TABLESPACE

## 説明

このステートメントは、TableSpaceの論理オブジェクトを削除するために使用されます。

## 使用制限と注意事項

TableSpaceにテーブルが存在しない場合にのみ、削除は成功します。

## 権限要件

`DROP TABLESPACE` ステートメントを実行するには、現在のユーザーが `DROP TABLESPACE` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP TABLESPACE tablespace_name;
```

## パラメータの説明

|       パラメータ        |          説明           |
|-----------------|-----------------------|
| tablespace_name | 削除するTableSpaceの名前を指定します。 |

## 例

TableSpaceオブジェクト `tblspace1` を削除します。

```sql
obclient>  DROP TABLESPACE tblspace1;
```
