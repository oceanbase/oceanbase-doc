# DROP INDEX

## 説明

このステートメントは、インデックスを削除するために使用します。インデックスが多すぎるとメンテナンスコストが増加するため、不要なインデックスを削除する必要があります。

## 使用上の制限と注意事項

インデックスを削除しても、完全に削除されるまでにはしばらく時間がかかります。

## 権限要件

`DROP INDEX` ステートメントを実行するには、現在のユーザーが `DROP` システム権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP INDEX [schema.] index_name;
```

## パラメータの説明

|     パラメータ     |      説明       |
|------------|---------------|
| schema     | スキーマ名を指定します。 |
| index_name | インデックス名を指定します。       |

## 例

インデックス `tbl1_idx1` を削除します。

```sql
obclient> DROP INDEX tbl1_idx1;
Query OK, 0 rows affected
```
