# DROP VIEW

## 説明

このステートメントは、ビューを削除するために使用されます。

## 制限事項と注意点

ビューを削除する際には、現在のユーザーが各ビューに対して `DROP` 権限を持っている必要があります。

## 権限要件

`DROP VIEW` ステートメントを実行するには、現在のユーザーが `DROP` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
DROP VIEW [schema.] view_name [CASCADE | RESTRICT];
```

## パラメータの説明

|       **パラメータ**      |                    **説明**                           |
|---------------------|-------------------------------------------------------|
| schema.             | ビューが属するスキーマを指定します。`schema.` を省略した場合、デフォルトでビューは自身のモードに存在します。                                                                                                        |
| view_name           | 削除するビューの名前。                                                                                                                                              |
| CASCADE \| RESTRICT | `CASCADE` はカスケード削除であり、このビューに依存するオブジェクトを自動的に削除します。 `RESTRICT` は制約付き削除であり、依存オブジェクトが存在する場合、このビューの削除を拒否します。 <br>**注記**  現在のバージョンではこのパラメータはサポートされていません。指定された場合、解析されて無視されます。 |

## 例

* ビュー `v1` を削除します。

  ```sql
  obclient> DROP VIEW v1;
  Query OK, 0 rows affected
  ```

* `DROP ANY VIEW` 権限がない場合、ビューを削除しようとすると権限不足のエラーが表示されます。

  ```sql
  obclient> DROP VIEW user1.v2;
  ORA-01031: insufficient privileges
  ```
