# CREATE VIEW

## 説明

このステートメントは、ビューを作成するために使用されます。

## 制限事項と注意点

* `OR REPLACE` 句が指定されている場合、このステートメントは既存のビューを置き換えることができます。

* ビューはデータベース内に実際にはテーブルとして存在するわけではなく、`CREATE VIEW` ステートメントで指定された `SELECT` ステートメントの結果として派生します。使用するたびにビューが再生成されます。

* `FROM` 句で2つ以上のテーブルまたはビューが参照されている場合、そのビューは結合ビュー（Join View）と呼ばれます。更新可能な結合ビュー、または変更可能な結合ビューとは、2つ以上の基底テーブルまたはビューに関連し、DML操作を許可するものです。更新可能なビューは `WITH READ ONLY` 句の制限を受けません。

* 更新可能性を実現するためには、ビューが複数の条件を満たす必要があります。例えば、一般的なルールの一つとして、結合ビューに対する `INSERT`、`UPDATE`、または `DELETE` 操作では一度に1つの基底テーブルしか変更できないというものがあります。

## 権限要件

`CREATE VIEW` ステートメントを実行するには、現在のユーザーが `CREATE VIEW` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
CREATE [OR REPLACE] [{NO FORCE} | FORCE] VIEW view_name [(column_name_list)]
    AS select_stmt
    [view_check_option];

column_name_list:
    column_name [, column_name ...]

view_check_option:
    WITH READ ONLY
    | WITH CHECK OPTION
```

## パラメータの説明

|        パラメータ       |              説明              |
|-------------------|--------------------------------|
| OR REPLACE        | オプション。作成しようとしているビューの名前が既に存在する場合、新しい定義を使用してビューを再作成します。|
| {NO FORCE} \| FORCE | オプション。ビューの作成を強制的に実行するかどうかを制御します。<ul><li>`NO FORCE`：デフォルト値。ベーステーブルが存在し、ビューが属するスキーマの所有者が権限を持つ場合にのみビューを作成します。</li><li>`FORCE`：ビューに対応するベーステーブルや参照されるオブジェクトの種類、およびビューが属するスキーマの所有者の権限を考慮せず、ビューを強制的に作成します。</li></ul>|
| view_name         | ビューの名前。|
| column_name_list  | オプション。ビューの列名リストを指定します。列名リストを指定しない場合、`SELECT` ステートメントで取得した列名がビューの列名として使用されます。`SELECT` ステートメントで取得した列は、テーブル列への単純な参照である場合もあれば、関数、定数値、演算子などを使用した式である場合もあります。ビューの列名には以下の制限があります：<ul><li>一意の列名でなければならず、重複してはなりません。</li><li>`column_name_list` の数は、`SELECT` ステートメントで取得した列数と等しくなければなりません。</li></ul>|
| select_stmt       | ビューを定義するためのクエリ（`SELECT`）ステートメントです。これにより、ベーステーブルまたは他のビューから選択できるビューの定義が提供されます。クエリステートメントの具体的な構造とオプションの詳細については、[SELECTステートメント](../200.dml-of-oracle-mode/500.select-of-oracle-mode/100.simple-select-of-oracle-mode.md)を参照してください。|
| view_check_option | オプション。ビューの追加プロパティを指定するために使用されます。詳細については、以下の [view_check_option](#view_check_option)を参照してください。|

### view_check_option

* `WITH READ ONLY`：ビューを作成または置き換える際のオプションであり、そのビューがデータの読み取り専用として使用され、DML操作（`INSERT`、`UPDATE`、`DELETE`）には使用できないことを指定します。つまり、ビューを介した挿入、更新、削除操作を禁止します。

* `WITH CHECK OPTION`：ビューを作成するための構文であり、挿入または更新されるデータがビューの定義条件を満たすことを保証するために使用されます。つまり、ビューを介したDML操作は許可されますが、操作後のデータはビューの定義条件を満たさなければなりません。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Oracleモードでは、<code>WITH CHECK OPTION</code> 構文は <code>LOCAL</code> または <code>CASCADED</code> として指定することはサポートされておらず、デフォルトは <code>CASCADED</code> です。</p>
    </main>

    V4.2.5バージョンでは、V4.2.5 BP7バージョンから、ビューのフィルタ条件（`where_clause`）にサブクエリを含む場合に `WITH CHECK OPTION` 句を指定することがサポートされています。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>フィルタ条件で <code>WITH CHECK OPTION</code> 句を使用する場合、ビュー定義内で <code>JOIN</code> 操作を使用することは現在サポートされていません。</p>
    </main>

## 例

テストテーブル `tbl1` と `tbl2` を作成します。

```shell
obclient> CREATE TABLE tbl1 (col1 INT, col2 VARCHAR(50));
```

```shell
obclient> CREATE TABLE tbl2 (col1 INT, col2 INT);
```

* テーブル `tbl1` の `col1` および `col2` 列を選択して、ビュー `v1_t1` を作成します。

    ```shell
    obclient> CREATE OR REPLACE FORCE VIEW v1_t1(vcol1, vcol2)
        AS SELECT col1, col2
           FROM tbl1;
    ```

* テーブル `tbl2` の `col1` および `col2` 列に基づいて、ビュー `v2_t2` を作成します。`v2_t2` には `tbl2.col2 > 1` を満たすすべてのデータが含まれます。

    ```shell
    obclient> CREATE VIEW v2_t2
        AS SELECT *
           FROM tbl2
           WHERE tbl2.col2 > 1 WITH CHECK OPTION;
    ```

* テーブル `tbl2` の `col1` および `col2` 列に基づいて、ビュー `v3_t3` を作成し、同時にビュー `v3_t3` にコメントを追加します。

  1. ビュー `v3_t3` を作成します。

      ```shell
      obclient> CREATE VIEW v3_t3
          AS SELECT
              col1,   --test.col1
              col2    --test.col2
          FROM tbl2;
      ```

  2. `SHOW CREATE VIEW` または `DBMS_METADATA.GET_DDL` を使用して、ビューのコメントを照会します。

     * `SHOW CREATE VIEW` を使用して、ビューのコメントを照会します。

         ```shell
         obclient> SHOW CREATE VIEW v3_t3;
         ```

        実行結果は次のとおりです：

        ```shell
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | VIEW  | CREATE VIEW                                                                                                                              | CHARACTER_SET_CLIENT | COLLATION_CONNECTION |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | V3_T3 | CREATE VIEW "V3_T3" ("COL1", "COL2")  AS SELECT
                    col1,   --test.col1
                    col2    --test.col2
                FROM tbl2 | utf8mb4              | utf8mb4_bin          |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        1 row in set
        ```

     * `DBMS_METADATA.GET_DDL` を使用して、ビューのコメントを照会します。

         ```shell
         obclient> SELECT DBMS_METADATA.GET_DDL('VIEW', 'V3_T3', 'SYS') FROM DUAL;
         ```

        実行結果は次のとおりです：

        ```shell
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | VIEW  | CREATE VIEW                                                                                                                              | CHARACTER_SET_CLIENT | COLLATION_CONNECTION |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | V3_T3 | CREATE VIEW "V3_T3" ("COL1", "COL2")  AS SELECT
                    col1,   --test.col1
                    col2    --test.col2
                FROM tbl2 | utf8mb4              | utf8mb4_bin          |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        1 row in set (0.028 sec)

        obclient(SYS@oracle001)[SYS]> SELECT DBMS_METADATA.GET_DDL('VIEW', 'V3_T3', 'SYS') FROM DUAL;
        +------------------------------------------------------------------------------------------------------------------------------------------+
        | DBMS_METADATA.GET_DDL('VIEW','V3_T3','SYS')                                                                                              |
        +------------------------------------------------------------------------------------------------------------------------------------------+
        | CREATE VIEW "V3_T3" ("COL1", "COL2")  AS SELECT
                    col1,   --test.col1
                    col2    --test.col2
                FROM tbl2 |
        +------------------------------------------------------------------------------------------------------------------------------------------+
        1 row in set
        ```

* フィルター条件のサブクエリの後に `WITH CHECK OPTION` 句を指定します。

    ```shell
    obclient> CREATE OR REPLACE VIEW v4_t1
        AS SELECT *
        FROM tbl1 t1
        WHERE EXISTS (SELECT 1 FROM tbl2 t2 WHERE t2.col1 = t1.col1) WITH CHECK OPTION;
    ```
