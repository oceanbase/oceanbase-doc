# CREATE VIEW

## 説明

このステートメントは、ビューを作成するために使用します。

## 使用上の制限と注意事項

`OR REPLACE` 句を指定した場合、このステートメントは既存のビューを置き換えることができます。

ビューはデータベース内では実際にはテーブルの形では存在せず、`CREATE VIEW` ステートメントで指定された `SELECT` ステートメントの結果として派生されます。使用するたびにビューは再生成されます。

`FROM` 句で2つ以上のテーブルまたはビューを参照する場合、そのビューは結合ビュー（Join View）と呼ばれます。更新可能な結合ビュー、または変更可能な結合ビューは、2つ以上のベーステーブルまたはビューに関連し、DML操作を許可します。更新可能なビューは `WITH READ ONLY` 句の制限を受けません。

更新可能性を実現するためには、ビューが満たす必要がある複数の条件があります。例えば、一般的なルールの1つとして、結合ビューに対する `INSERT`、`UPDATE`、または `DELETE` 操作では、一度に1つのベーステーブルしか変更できないというものがあります。

## 権限要件

`CREATE VIEW` ステートメントを実行するには、現在のユーザーが `CREATE VIEW` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
CREATE [OR REPLACE] [[NO] FORCE] VIEW view_name [(column_name_list)]
    AS select_stmt
    [view_check_option];

select_stmt:
    SELECT column_name, [--string]
        [, column_name, [--string] ...]
    FROM from_list
    [WHERE condition]

column_name_list:
    column_name [, column_name ...]

view_check_option:
    WITH READ ONLY
    | WITH CHECK OPTION
```

## パラメータの説明

|        パラメータ      |                                             説明                                                |
|------------------|------------------------------------------------------------------------------------------------|
| OR REPLACE       | 作成しようとするビュー名が既に存在する場合、新しい定義でビューを再作成することを示します。|
| \[NO\] FORCE     | ビューの作成時に、そのビューにベーステーブルが存在するか、参照されているオブジェクトのタイプ、およびビューが配置されているスキーマの所有者が権限を持っているかどうかを考慮しない場合は、`FORCE` を指定してください。ベーステーブルが存在し、かつビューが配置されているスキーマの所有者が権限を持っている場合にのみビューを作成する場合は、`NOFORCE` を指定してください。`NOFORCE` がデフォルト設定です。|
| view_name        | ビュー名。|
| column_name_list | ビューは一意の列名を持たなければならず、ベーステーブルと同様に重複してはなりません。デフォルトでは、`SELECT` ステートメントで取得した列名がビューの列名として使用されます。ビューの列に明確な名前を定義するには、オプションの `column_name_list` 句を使用できます。IDはカンマで区切ります。`column_name_list` の名前の数は、`SELECT` ステートメントで取得した列数と同じでなければなりません。`SELECT` ステートメントで取得した列は、テーブル列への単純な参照でも、関数、定数値、演算子などを使用した式でもかまいません。|
| select_stmt      | `SELECT` ステートメントの一種です。これによりビューの定義が与えられます。このステートメントは、ベーステーブルや他のビューから選択を行います。`SELECT` ステートメントの詳細については、[SIMPLE SELECT](../200.dml-of-oracle-mode/500.select-of-oracle-mode/100.simple-select-of-oracle-mode.md)を参照してください。|
| --string         | オプションです。ビューにコメントを追加するために使用します。コメントはビュー定義に保存されます。<main id="notice" type='notice'><h4>説明</h4><p><code>--string</code> は <code>select_stmt</code> の任意の位置にコメントできます。</p></main>|
| view_check_option | オプションです。ビューの追加属性を指定するために使用します。詳細については、後述の [view_check_option](#view_check_option) を参照してください。|

### view_check_option

* `WITH READ ONLY`：ビューの作成または置き換え時のオプションで、ビューを読み取り専用として使用し、DML操作（`INSERT`、`UPDATE`、`DELETE`）を禁止することを指定します。つまり、ビューを通じた挿入、更新、削除操作を禁止します。
* `WITH CHECK OPTION`：ビューを作成するための構文の一種で、挿入または更新されるデータがビューの定義条件を満たすことを保証します。つまり、ビューを通じたDML操作を許可しますが、操作後のデータがビューの定義条件を満たしている必要があります。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Oracleモードでは、<code>WITH CHECK OPTION</code>構文は<code>LOCAL</code>または<code>CASCADED</code>を指定することはサポートされておらず、デフォルトは<code>CASCADED</code>です。</p>
    </main>

    OceanBaseデータベースは、ビューのフィルタリング条件(`where_clause`)にサブクエリを含める場合に`WITH CHECK OPTION`句を指定することもサポートしています。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>フィルタリング条件で<code>WITH CHECK OPTION</code>句を使用する場合、ビュー定義で<code>JOIN</code>操作を使用することは現在サポートされていません。</p>
    </main>

## 例

テストテーブル`tbl1`と`tbl2`を作成します。

```shell
obclient> CREATE TABLE tbl1 (col1 INT, col2 VARCHAR(50));
```

```shell
obclient> CREATE TABLE tbl2 (col1 INT, col2 INT);
```

* テーブル`tbl1`の`col1`、`col2`列を選択してビュー`v1_t1`を作成します。

    ```shell
    obclient> CREATE OR REPLACE FORCE VIEW v1_t1(vcol1, vcol2)
        AS SELECT col1, col2
           FROM tbl1;
    ```

* テーブル`tbl2`の`col1`、`col2`列に基づいてビュー`v2_t2`を作成します。`v2_t2`には`tbl2.col2 > 1`を満たすすべてのデータが含まれます。

    ```shell
    obclient> CREATE VIEW v2_t2
        AS SELECT *
           FROM tbl2
           WHERE tbl2.col2 > 1 WITH CHECK OPTION;
    ```

* テーブル`tbl2`の`col1`、`col2`列に基づいてビュー`v3_t3`を作成し、同時にビュー`v3_t3`にコメントを追加します。

  1. ビュー`v3_t3`を作成します。

      ```shell
      obclient> CREATE VIEW v3_t3
          AS SELECT
              col1,   --test.col1
              col2    --test.col2
          FROM tbl2;
      ```

  2. `SHOW CREATE VIEW`または`DBMS_METADATA.GET_DDL`を使用してビューのコメントを確認します。

     * `SHOW CREATE VIEW`を使用してビューのコメントを確認します。

         ```shell
         obclient> SHOW CREATE VIEW v3_t3;
         ```

        実行結果は次のとおりです：

        ```shell
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | VIEW  | CREATE VIEW                                                                                                                              | CHARACTER_SET_CLIENT | COLLATION_CONNECTION |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | V3_T3 | CREATE VIEW "V3_T3" ("COL1", "COL2")  AS SELECT
                    col1,   --test.col1
                    col2    --test.col2
                FROM tbl2 | utf8mb4              | utf8mb4_bin          |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        1 row in set
        ```

     * `DBMS_METADATA.GET_DDL`を使用してビューのコメントを確認します。

         ```shell
         obclient> SELECT DBMS_METADATA.GET_DDL('VIEW', 'V3_T3', 'SYS') FROM DUAL;
         ```

        実行結果は次のとおりです：

        ```shell
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | VIEW  | CREATE VIEW                                                                                                                              | CHARACTER_SET_CLIENT | COLLATION_CONNECTION |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        | V3_T3 | CREATE VIEW "V3_T3" ("COL1", "COL2")  AS SELECT
                    col1,   --test.col1
                    col2    --test.col2
                FROM tbl2 | utf8mb4              | utf8mb4_bin          |
        +-------+------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
        1 row in set (0.028 sec)

        obclient(SYS@oracle001)[SYS]> SELECT DBMS_METADATA.GET_DDL('VIEW', 'V3_T3', 'SYS') FROM DUAL;
        +------------------------------------------------------------------------------------------------------------------------------------------+
        | DBMS_METADATA.GET_DDL('VIEW','V3_T3','SYS')                                                                                              |
        +------------------------------------------------------------------------------------------------------------------------------------------+
        | CREATE VIEW "V3_T3" ("COL1", "COL2")  AS SELECT
                    col1,   --test.col1
                    col2    --test.col2
                FROM tbl2 |
        +------------------------------------------------------------------------------------------------------------------------------------------+
        1 row in set
        ```

* フィルター条件のサブクエリの後に `WITH CHECK OPTION` 句を指定します。

    ```shell
    obclient> CREATE OR REPLACE VIEW v4_t1
        AS SELECT *
        FROM tbl1 t1
        WHERE EXISTS (SELECT 1 FROM tbl2 t2 WHERE t2.col1 = t1.col1) WITH CHECK OPTION;
    ```
