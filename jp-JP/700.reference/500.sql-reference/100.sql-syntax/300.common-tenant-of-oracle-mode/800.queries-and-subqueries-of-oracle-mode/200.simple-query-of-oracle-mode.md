# シンプルクエリ

シンプルクエリとは、OceanBaseデータベースの1つまたは複数のSELECTリストまたはビューから、1つまたは複数の列データを取得するものです。列の数、データ型、長さはSELECTリストの要素によって決定されます。SELECTリストとは、SELECTキーワードの後、FROM句の前に記述される式のリストを指します。

2つ以上のテーブルが共通の列名を持つ場合は、テーブル名で列名を限定する必要があります。SELECTリストの直前にある式には、列のエイリアス `col_alias` を使用できます。エイリアスは `ORDER BY` 句で使用できますが、クエリ内の他の句では使用できません。

## 構文

単純クエリの `SELECT` 構文は次のとおりです：

```sql
SELECT 列名1,列名2,列名3,... FROM テーブル;
```

ここで、テーブル名、フィールド名、キーワード `SELECT` および `FROM` は大文字小文字を区別しません。クエリの最後にはセミコロン（;）を付けることができ、複数のSQLを同時に実行することもできます。`SELECT` ステートメント内でコメントを使用して、OceanBaseデータベースのオプティマイザーに指示やヒントを伝えることができます。オプティマイザーはヒントを使用してステートメントの実行計画を選択します。ヒントの詳細については、[Hint](../300.basic-elements-of-oracle-mode/600.annotation-of-oracle-mode/400.hint-of-oracle-mode/100.hint-overview-of-oracle-mode.md)を参照してください。

## 例

従業員テーブル `employee` を作成し、列 `employee_id`、`first_name`、`last_name`、`manager_id`、`salary` にデータを挿入します。

```sql
CREATE TABLE employee (
employee_id INT,
first_name VARCHAR(50),
last_name VARCHAR(50),
manager_id INT,
salary NUMERIC
);
INSERT INTO employee VALUES(111, 'DEL', 'FA BEN', 1, 1500);
INSERT INTO employee VALUES(112, 'AXEL', 'BELL', 1, 1000);
INSERT INTO employee VALUES(113, 'CRIS',  'RACHAR', 1, 1000);
INSERT INTO employee VALUES(114, 'BlAIR',  'WALDORF', 1, 800);
```

* テーブルの一部の列を照会する

  ```sql
  obclient> SELECT first_name, last_name, salary FROM employee;
  +------------+-----------+--------+
  | FIRST_NAME | LAST_NAME | SALARY |
  +------------+-----------+--------+
  | DEL        | FA BEN    |   1500 |
  | AXEL       | BELL      |   1000 |
  | CRIS       | RACHAR    |   1000 |
  | BlAIR      | WALDORF   |    800 |
  +------------+-----------+--------+
  4 rows in set
  ```

* テーブルのすべての列を照会する

  ```sql
  obclient> SELECT * FROM employee;
  +-------------+------------+-----------+------------+--------+
  | EMPLOYEE_ID | FIRST_NAME | LAST_NAME | MANAGER_ID | SALARY |
  +-------------+------------+-----------+------------+--------+
  |         111 | DEL        | FA BEN    |          1 |   1500 |
  |         112 | AXEL       | BELL      |          1 |   1000 |
  |         113 | CRIS       | RACHAR    |          1 |   1000 |
  |         114 | BlAIR      | WALDORF   |          1 |    800 |
  +-------------+------------+-----------+------------+--------+
  4 rows in set
  ```

* テーブルの列に対して数学的演算を行う

  ```sql
  obclient> SELECT salary+100 FROM employee;
  +------------+
  | SALARY+100 |
  +------------+
  |       1600 |
  |       1100 |
  |       1100 |
  |        900 |
  +------------+
  4 rows in set
  ```

* テーブルの列にエイリアスを付ける

  ```sql
  obclient> SELECT salary*12 年薪 FROM employee;
  +--------+
  | 年薪   |
  +--------+
  |  18000 |
  |  12000 |
  |  12000 |
  |   9600 |
  +--------+
  4 rows in set
  ```

* テーブル内のデータを文字列として連結する

  ```sql
  obclient> SELECT first_name || '-' || last_name  AS 姓名 FROM employee;
  +---------------+
  | 姓名          |
  +---------------+
  | DEL-FA BEN    |
  | AXEL-BELL     |
  | CRIS-RACHAR   |
  | BlAIR-WALDORF |
  +---------------+
  4 rows in set
  ```

* テーブル内のデータを重複なくする

  ```sql
  obclient> SELECT DISTINCT MANAGER_ID FROM employee;
  +------------+
  | MANAGER_ID |
  +------------+
  |          1 |
  +------------+
  1 row in set
  ```

* `CASE WHEN` ステートメントを使用してテーブル内のデータを照会する

  ```sql
  obclient> SELECT salary, CASE WHEN salary >= 1200 then '高薪' WHEN salary >= 1000 THEN '一般'
       ELSE '继续努力' END AS type FROM employee;
  +--------+--------------+
  | SALARY | TYPE         |
  +--------+--------------+
  |   1500 | 高薪         |
  |   1000 | 一般         |
  |   1000 | 一般         |
  |    800 | 继续努力     |
  +--------+--------------+
  4 rows in set
  ```
