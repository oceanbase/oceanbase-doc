# フルテキストクエリ

フルテキストクエリとは、テキストデータに対して全文検索または検索を行う操作です。フルテキストクエリは、テキスト全体をより包括的に検索し、検索条件に一致する結果を返します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.4.2バージョンでは、OracleモードはV4.4.2 BP2バージョンからフルテキストインデックスの作成をサポートしています。</p>
</main>

## 構文

以下のステートメントを使用してフルテキストインデックスクエリを実行します。フルテキストインデックス列を指定し、`search_query` との一致度を調べます。結果は、行と `search_query` の関連度を表す非負の `DOUBLE` 値として返され、0は関連性がないことを意味します。

```sql
CONTAINS(indexed_column, 'search_query' [, score_label])

SCORE(score_label)
```

**パラメータ説明：**

* `indexed_column`：フルテキストインデックスの列名を表します。
* `search_query`：`VARCHAR2` 型または `CLOB` 型で、検索するキーワードまたはフレーズを表します。サポートされている検索演算子は以下のとおりです：

  * `空白`：連続するフレーズのマッチングを表し、隣接して現れる単語を順序通りにマッチングします。例：`'word1 word2'`。二重引用符 `""` または大括弧 `{}` を使用したエスケープがサポートされています。例えば、連続するフレーズ "law and order" を検索する場合、`'law and order'` と直接書くと `law AND order`（論理積）と解釈されます。解決策：

    * 大括弧を使用する：`'{law and order}'`。
    * 二重引用符を使用する：`'"law and order"'`。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>search_query</code> パラメータのクエリ内容が対応するトークナイザーで生成される分詞数が多すぎると、システムリソースの消費が増加し、応答速度が低下し、クエリのパフォーマンスに影響を与える可能性があります。最適な実行効率を得るために、クエリを簡潔かつ適切に保つことを推奨します。</p>
  </main>

* `score_label`：オプションパラメータで、`NUMBER` 型です。返される結果のマッチング番号を表します。
* `SCORE()`：オプションパラメータで、`NUMBER` 型です。`score_label` と組み合わせて使用し、`score_label` は `CONTAINS` で指定された `score_label` である必要があります。`CONTAINS` のマッチングスコア（関連性が高いほど高い）を出力するために使用されます。

## 使用上の制限と注意事項

* `indexed_column` が存在しない場合、エラーが発生します。
* `indexed_column` にフルテキストインデックスが作成されていない場合、エラーが発生します。
* `search_query` が `NULL` の場合、エラーが発生します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, NULL, 1) > 0;`。
* `search_query` が空文字列の場合、空を返します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, '', 1) > 0;`。
* `search_query` がすべて空白の場合、空を返します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, ' ', 1) > 0;`。
* `score_label` が負の数値の場合、エラーが発生します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, 'OceanBase', -1) > 0;`。
* `SCORE` タグが定義されていない場合、エラーが発生します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, 'OceanBase', 1) > 0 ORDER BY SCORE(999);`。
* `CONTAINS` の文脈がない場合に `SCORE` が使用されると、エラーが発生します。例：`SELECT SCORE(1) FROM tbl1;`。
* `GROUP BY` 句や `HAVING` 句での `SCORE` の使用はサポートされていません。
* `CONTAINS` が比較されていない場合、エラーが発生します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, 'OceanBase', 1);`。
* `CONTAINS` で小さい、等しい、または小さい・等しい比較を使用すると、エラーが発生します。例：`SELECT col1 FROM tbl1 WHERE CONTAINS(col2, 'OceanBase', 1) <= 0;`。
* フルテキストフィルターを使用した連結クエリやテーブル名の変更を行うと、エラーが発生します。例：`SELECT SCORE(1) FROM tbl2 t1 WHERE CONTAINS(t1.col2, 'OceanBase', 1) >0;`。

## 例

1. テーブル `tbl1` を作成します。

    ```shell
    obclient> CREATE TABLE tbl1(
        col1 INT,
        col2 CHAR(50),
        col3 VARCHAR2(500));
    ```

2. フルテキストインデックス `ft_idx1_tbl1` を作成します。

    ```shell
    obclient> CREATE INDEX ft_idx1_tbl1 ON tbl1(col2)
        INDEXTYPE IS CTXSYS.CONTEXT
        PARAMETERS('LEXER SPACE')
        LOCAL;
    ```

3. フルテキストインデックス `ft_idx2_tbl1` を作成します。

    ```shell
    obclient> CREATE INDEX ft_idx2_tbl1 ON tbl1(col3)
        INDEXTYPE IS CTXSYS.CONTEXT
        PARAMETERS('LEXER SPACE')
        LOCAL;
    ```

4. テーブル `tbl1` にテストデータを追加します。

    ```sql
    obclient> INSERT INTO tbl1 (col1, col2, col3) VALUES
        (1, 'Hello World', 'This is a test'),
        (2, 'OceanBase', 'OceanBase Database is a native, enterprise-level distributed database developed independently by the OceanBase team'),
        (3, 'Database Management', 'Learn about SQL and database administration'),
        (4, 'Full Text Searching', 'Master the art of full text searching');
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 4 rows affected
    Records: 4  Duplicates: 0  Warnings: 0
    ```

5. `CONTAINS` を使用してクエリを実行します。

    ```shell
    obclient> SELECT *
        FROM tbl1
        WHERE CONTAINS(col2, 'OceanBase', 1) > 0;
    ```

    実行結果は次のとおりです：

    ```shell
    +------+----------------------------------------------------+---------------------------------------------------------------------------------------------------------------------+
    | COL1 | COL2                                               | COL3                                                                                                                |
    +------+----------------------------------------------------+---------------------------------------------------------------------------------------------------------------------+
    |    2 | OceanBase                                          | OceanBase Database is a native, enterprise-level distributed database developed independently by the OceanBase team |
    +------+----------------------------------------------------+---------------------------------------------------------------------------------------------------------------------+
    1 row in set
    ```

6. `CONTAINS` を使用してクエリを実行し、`SCORE` でソートします。

    ```shell
    obclient> SELECT col1, col2, col3, SCORE(1)
        FROM tbl1
        WHERE CONTAINS(col2, 'Database', 1) > 0
        AND col1 >= 2
        ORDER BY SCORE(1) DESC;
    ```

    実行結果は次のとおりです：

    ```shell
    +------+----------------------------------------------------+---------------------------------------------+------------------------+
    | COL1 | COL2                                               | COL3                                        | SCORE(1)               |
    +------+----------------------------------------------------+---------------------------------------------+------------------------+
    |    3 | Database Management                                | Learn about SQL and database administration | 1.259496819494492E+000 |
    +------+----------------------------------------------------+---------------------------------------------+------------------------+
    1 row in set
    ```

7. 複数のクエリを実行し、`score_label` を使用して `SCORE` の結果を出力します。

    ```shell
    obclient> SELECT col1, col2, col3, SCORE(10), SCORE(20)
        FROM tbl1
        WHERE CONTAINS (col2, 'Database', 10) > 0
        OR CONTAINS (col3, 'OceanBase', 20) > 0
        ORDER BY SCORE(10), SCORE(20);
    ```

    実行結果は次のとおりです：

    ```shell
    +------+----------------------------------------------------+---------------------------------------------------------------------------------------------------------------------+------------------------+-------------------------+
    | COL1 | COL2                                               | COL3                                                                                                                | SCORE(10)              | SCORE(20)               |
    +------+----------------------------------------------------+---------------------------------------------------------------------------------------------------------------------+------------------------+-------------------------+
    |    2 | OceanBase                                          | OceanBase Database is a native, enterprise-level distributed database developed independently by the OceanBase team |                      0 | 1.1331643117640413E+000 |
    |    3 | Database Management                                | Learn about SQL and database administration                                                                         | 1.259496819494492E+000 |                       0 |
    +------+----------------------------------------------------+---------------------------------------------------------------------------------------------------------------------+------------------------+-------------------------+
    2 rows in set
    ```
