# クエリとサブクエリの概要

クエリとは、データベースからデータを取得するための方法であり、WHERE句やORDER BY句などの条件制限句や並べ替え句を組み合わせて、クエリ結果を取得します。

サブクエリとは、上位のクエリ内にネストされたクエリのことです。上位のクエリは一般的に親クエリまたは外部クエリと呼ばれます。サブクエリの結果は入力として親クエリまたは外部クエリに渡され、親クエリはこの値を計算に組み込んで最終的な出力を決定します。

SQL言語は多重ネストされたクエリを許容しており、あるサブクエリの中にさらに他のサブクエリをネストすることが可能です。また、サブクエリはSQL文の様々な句、例えば`SELECT`句、`FROM`句、`WHERE`句などに記述できます。
