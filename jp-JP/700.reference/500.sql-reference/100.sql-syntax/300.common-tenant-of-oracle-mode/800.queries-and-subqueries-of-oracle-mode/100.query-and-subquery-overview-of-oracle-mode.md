# クエリとサブクエリの概要

クエリとは、データベースからデータを取得するための方法であり、WHERE句やORDER BY句などの条件制限句を組み合わせてクエリ結果を取得します。

サブクエリとは、上位のクエリ内にネストされるクエリを指します。上位のクエリは一般的に親クエリまたは外部クエリと呼ばれます。サブクエリの結果は入力として親クエリまたは外部クエリに渡されます。親クエリはこの値を計算に組み込み、最終的な出力を決定します。

SQL言語では、複数層のネストクエリが許可されており、つまり一つのサブクエリ内にさらに他のサブクエリをネストすることが可能です。同時に、サブクエリはSQL文の様々な句、例えば`SELECT`句、`FROM`句、`WHERE`句などに現れることができます。
