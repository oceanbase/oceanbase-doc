# DUALテーブルのクエリ

DUALは、OceanBaseデータベースがデータディクショナリと共に自動的に作成するテーブルです。DUALテーブルはユーザーSYSのスキーマ内にありますが、すべてのユーザーが名前DUALでこのテーブルにアクセスできます。

`DUAL` テーブルには `DUMMY` という列が1つあり、`VARCHAR2(1)` として定義され、値が `X` の行が含まれています。`SELECT` ステートメントを使用して定数式を評価する際、`DUAL` テーブルからデータを選択する方が使いやすいです。`DUAL` には1行しかないため、定数は1回だけ返されます。または、任意のテーブルから定数、疑似列、または式を選択することもできますが、その値はテーブル内の行数に応じて返される値になります。
