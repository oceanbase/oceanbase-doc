# DUALテーブルクエリ

DUALは、OceanBaseデータベースがデータディクショナリと共に自動的に作成するテーブルです。DUALテーブルはユーザーSYSのスキーマ内にありますが、すべてのユーザーが名前DUALを使用してこのテーブルにアクセスできます。

`DUAL` テーブルには、`VARCHAR2(1)` として定義された `DUMMY` という列があり、値が `X` の行が含まれています。`SELECT` ステートメントを使用して定数式を計算する場合、`DUAL` テーブルからデータを選択する方が便利です。`DUAL` には1行しかないため、定数は1回だけ返されます。または、任意のテーブルから定数、擬似列、または式を選択できますが、その値はテーブル内の行数に応じて返される値になります。
