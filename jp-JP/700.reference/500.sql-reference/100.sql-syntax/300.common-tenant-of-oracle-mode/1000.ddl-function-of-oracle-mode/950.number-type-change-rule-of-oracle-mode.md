# NUMBER型の変換ルール

OceanBaseデータベースにおける`NUMBER`型のストレージ形式はすべて同じですが、値域の定義に基づいて以下の表に示す4種類の形式に分類できます。

| ストレージタイプ | MySQLモードにおける構文のデフォルトストレージルール | Oracleモードにおける構文のデフォルトストレージルール | 説明 |
| --- | --- | --- | --- |
| 固定小数点数 DECIMAL(M,D) = {10^{-D}*i &#124; i = 0,1,...,10^M-1} ここで、Mは自然数、Dは整数 | <ul><li> DECIMAL = DECIMAL(10, 0)</li> <li>DECIMAL(M) = DECIMAL(M, 0)</li> <li>DECIMAL(M, D) におけるMとDの値の範囲は、0 <=D<=M<=65 です </li></ul> | <ul><li> DECIMAL = NUMBER(38)</li> <li> NUMBER(M) = NUMBER(38,0)</li> <li> NUMBER(M,D) におけるMの値の範囲は[1, 38]、Dの値の範囲は[-84,127]です。</li></ul>| 固定小数点数`(M1,D1)`が固定小数点数`(M2,D2)`の部分集合であるためには、`D1 <= D2`かつ`M1-D1 <= M2-D2`でなければなりません。 |
| 置換えられない固定小数点数 DECIMAL(M,D) | <ul><li> DECIMAL</li> <li> DECIMAL(M)</li> <li> DECIMAL(M,D) </li> <li> UNSIGNEDプロパティをサポートします</li></ul>| サポートされていません| 置換えられない固定小数点数は、固定小数点数`DECIMAL(M,D)`の非負数に相当します |
| 浮動小数点数 NUMBER | サポートされていません | NUMBER | Oracleモードの浮動小数点数`NUMBER`は、合計精度が38ビットの浮動小数点数であり、決して`NUMBER(M, D)`の部分集合ではありません。また、`M-D <= 38`である場合に限り、`NUMBER(M, D)`はその部分集合となります。 |
| Oracle FLOAT(P) | サポートされていません | <ul><li>REAL = FLOAT(63) </li> <li>FLOAT = FLOAT(126)</li> <li>FLOAT(P)におけるPは[1, 126]に属します</li></ul> | 現在なし |

OceanBaseデータベースV4.2.0以降のバージョンでは、すべての`NUMBER`型間の変換ルールは以下の表のとおりです。表内の「-」は互換モードをまたいでいる場合を指します。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul><li><p>浮動小数点数の <code>NUMBER</code> とOracleの <code>FLOAT</code> はOracleモードにのみ存在し、符号なし固定小数点数はMySQLモードにのみ存在します。</p></li>
  <li><p>Oracleモードでは、Instant変換（スキーマのみを変更し、データの変換は行わない）が許可されないことは、空でないテーブルは変換できないことを意味します。MySQLモードでは、Instant変換が許可されないことは、データの書き換えが必要であることを意味します。たとえInstant変換が許可されていても、すべてのソース型のデータを損失なくターゲット型に挿入できるとは限らず、例えば固定小数点数をOracleの <code>FLOAT</code> に変換する場合などです。</p></li></ul>
</main>

| --- | --- | --- | --- | --- |
| 固定小数点数(M1,D1)| 変換条件：D1 <= D2 かつ M1-D1 <= M2-D2| サポートされていません| 変換条件：M-D <= 38| 変換条件：M1-D1 <=ceil(P*0.30103)|
| 置換え符号なし固定小数点数(M1,D1) UNSIGNED| 変換条件：D1 <= D2 かつ M1-D1 <= M2-D2| 変換条件：D1 <= D2 かつ M1-D1 <= M2-D2| -| -|
| 浮動小数点数 NUMBER| サポートされていません| -| サポートされています| サポートされていません|
| Oracle `FLOAT`(P1)| サポートされていません| -| サポートされています| 変換条件：P1 <= P2|
