# 主キーの操作

本記事では、OceanBaseデータベースのOracleモードにおける主キーの基本的な操作について説明します。主キーの追加、変更、削除を含みます。

## 主キーの追加

主キーを追加する構文は次のとおりです：

```sql
ALTER TABLE table_name ADD [CONSTRAINT constraint_name] PRIMARY KEY (column_name);
```

関連パラメータの説明は以下のとおりです：

* `table_name`：主キーを追加するテーブルの名前を指定します。

* `constraint_name`：追加する制約の名前を指定します。

* `column_name`：テーブルの列を指定します。

詳細については、[ALTER TABLE](../900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1000.alter-table-of-oracle-mode.md)を参照してください。

ここでは、データベースにテーブルtbl1が既に存在することを前提とし、tbl1 テーブルの c1 列を主キーとして定義する例を以下に示します：

```shell
obclient> ALTER TABLE tbl1 ADD PRIMARY KEY (c1);
```

## 主キーの変更

主キーを変更する構文は次のとおりです：

```sql
ALTER TABLE table_name MODIFY PRIMARY KEY (column_name);
```

ここで、`table_name` は主キーを変更する対象のテーブル名を指定し、`column_name` は変更後の主キーが存在する列を指定します。詳細については、[ALTER TABLE](../900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1000.alter-table-of-oracle-mode.md)を参照してください。

ここでは、データベースにテーブル tbl1 が既に存在し、tbl1 テーブルに主キーが存在することを前提とし、tbl1 テーブルの主キーを変更して c2 列に適用する例を以下に示します：

```shell
obclient> ALTER TABLE tbl1 MODIFY PRIMARY KEY (c2);
```

## 主キーの削除

主キーを削除する構文は次のとおりです：

```sql
ALTER TABLE table_name DROP PRIMARY KEY;
```

ここで、`table_name` は削除対象の主キーが存在するテーブル名を指定します。詳細については、[ALTER TABLE](../900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1000.alter-table-of-oracle-mode.md)を参照してください。

ここでは、データベースに tbl1 テーブルが存在し、そのテーブルに主キーが存在することを前提とします。tbl1 テーブルの主キーを削除する実行例は以下のとおりです：

```shell
obclient> ALTER TABLE tbl1 DROP PRIMARY KEY;
```
