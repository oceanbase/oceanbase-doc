# 集合演算子

集合演算子は、2つのクエリ結果を1つの結果に統合します。集合演算子を含むクエリは複合クエリと呼ばれます。

OceanBaseデータベースの現行バージョンでサポートされている集合演算子の詳細は、以下の表に示されています。

|    演算子    |                戻り値                 |
|-----------|------------------------------------|
| UNION     | 任意のクエリで選択されたすべての異なる行を返します。                    |
| UNION ALL | 任意のクエリで選択されたすべての行を返し、重複する行もすべて含みます。             |
| INTERSECT | 2つのクエリで選択されたすべての異なる行を返します。                   |
| MINUS     | 最初のクエリで選択されたすべての異なる行を返しますが、2番目のクエリに含まれる行は除外されます。 |

集合演算子の詳細情報と例については、[複合クエリ](../800.queries-and-subqueries-of-oracle-mode/400.collection-of-oracle-mode.md)を参照してください。
