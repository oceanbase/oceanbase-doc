# 集合演算子

集合演算子は、2つのクエリ結果を1つの結果に結合します。集合演算子を含むクエリは複合クエリと呼ばれます。

OceanBaseデータベースの現在のバージョンでサポートされている集合演算子の詳細は、次の表のとおりです。

|    演算子    |                戻り値                 |
|-----------|------------------------------------|
| UNION     | 任意のクエリで選択されたすべての異なる行を返します。                    |
| UNION ALL | 任意のクエリで選択されたすべての行を返し、重複する行も含みます。             |
| INTERSECT | 2つのクエリで選択されたすべての異なる行を返します。                   |
| MINUS     | 最初のクエリで選択されたすべての異なる行を返しますが、2番目のクエリにも現れる行は含まれません。 |

集合演算子の詳細および例については、[複合クエリ](../800.queries-and-subqueries-of-oracle-mode/400.collection-of-oracle-mode.md)を参照してください。
