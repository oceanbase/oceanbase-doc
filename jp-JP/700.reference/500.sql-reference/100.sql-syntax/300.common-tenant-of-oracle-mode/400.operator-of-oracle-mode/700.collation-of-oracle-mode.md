# COLLATE演算子

COLLATE演算子は照合順序を指定するために使用され、文字型の照合順序を再設定したり、単一の式に照合順序を指定したりできます。

`COLLATE` は後置一元演算子であり、他の一元演算子と同じ優先順位を持ちますが、すべての前置一元演算子の後に実行されます。`COLLATE` 演算子は `VARCHAR2`、`CHAR`、`NVARCHAR` または `NCHAR` 型の式に適用できます。

`COLLATE` 演算子の後にはパラメータ `collation_name` を続けて記述し、設定または使用する照合順序を示します。照合順序名にスペースが含まれる場合は、名前の両側に二重引用符を付ける必要があります。

例：

```sql
obclient>  CREATE TABLE t1(c1 VARCHAR(20));
Query OK, 0 rows affected

obclient> INSERT INTO t1 VALUES('a'),('b'),(1);
Query OK, 3 rows affected
Records: 3  Duplicates: 0  Warnings: 0

obclient> SELECT * FROM t1 ORDER BY c1 COLLATE utf8mb4_general_ci;
+------+
| C1   |
+------+
| 1    |
| a    |
| b    |
+------+
3 rows in set
```
