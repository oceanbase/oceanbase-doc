# 演算子の概要

演算子は一般的に、演算子またはパラメータなどの単一データ項目を結合して結果を返すために使用されます。構文上、演算子は演算子の前、演算子の後、または2つの演算子の間に記述することができます。

演算子は通常、特殊文字またはキーワードで表されます。例えば、除算演算子はスラッシュ（/）で表されます。

一般的な演算子は、一元演算子と二項演算子に分類することもできます：

* 一元演算子

  一元演算子は、1つの演算子に対してのみ演算を行います。一元演算子の一般的な書式は次のとおりです：

  ```sql
  演算子 演算子
  ```

* 二項演算子

  二項演算子とは、その名前が示すとおり、2つの演算子に対して演算を行うものです。二項演算子の一般的な書式は次のとおりです：

  ```sql
  演算子1 演算子 演算子2
  ```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>特別な形式を持つ他の演算子は、2つ以上の演算子を受け入れることができます。</li>
    <li>演算子に空の演算子（NULL）を提供した場合、結果は常に空になります。このルールに従わない唯一の例外は連結演算子（||）です。</li>
    </ul>
  </main>
