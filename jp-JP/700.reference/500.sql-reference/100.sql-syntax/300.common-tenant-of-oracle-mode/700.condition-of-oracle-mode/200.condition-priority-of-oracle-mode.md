# 条件優先順位

条件優先順位とは、OceanBaseデータベースにおいて同一の式内で異なる条件を評価する順序を指します。

複数の条件を含む式を計算する際は、まず高い優先順位の条件を評価し、最後に低い優先順位の条件を評価します。優先順位が同じ条件については、左から右へと順番に評価します。ただし、`AND` および `OR` で結合された複数の条件については、左から右への順序で評価することはできず、代わりにまず `AND` を計算してから `OR` を計算する順序となります。

SQL条件の優先順位は、最高から最低まで以下の表のとおりです。同一行に記載されている条件はすべて同じ優先順位を持ちます。

|                             条件タイプ                             |                               機能                               |
|--------------------------------------------------------------|----------------------------------------------------------------|
| SQL演算子はSQL条件の前に評価されます                                        | 詳細については、[演算子の優先順位](../400.operator-of-oracle-mode/200.operator-precedence-of-oracle-mode.md)を参照してください。 |
| =、!=、\<、\>、\<=、\>=                                           | 比較。                                                            |
| IS \[NOT\] NULL、LIKE、\[NOT\] BETWEEN、\[NOT\] IN、EXISTS、IS OF | 比較。                                                            |
| NOT                                                          | ロジックの否定。                                                          |
| AND                                                          | 接続。                                                            |
| OR                                                           | 分離。                                                            |
