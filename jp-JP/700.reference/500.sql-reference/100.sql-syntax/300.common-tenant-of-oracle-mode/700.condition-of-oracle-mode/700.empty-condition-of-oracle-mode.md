# NULL条件

NULL条件はNULL値を検出でき、NULLを検出するための唯一の条件です。

## NULL条件構文

NULL条件の構文は以下のとおりです：

```sql
expr IS [ NOT ] NULL
```

NULL値の詳細については、[NULL値](../300.basic-elements-of-oracle-mode/500.null-of-oracle-mode/100.empty-value-overview-of-oracle-mode.md)を参照してください。

## 例

```sql
SELECT last_name FROM emp WHERE comm_pct IS NULL ORDER BY last_name;
```
