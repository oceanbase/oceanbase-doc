# SQL条件の概要

条件はデータの値を判断するために使用され、1つ以上の式と論理（ブール）演算子などを組み合わせて構成され、TRUE、FALSE、またはUNKNOWNを返します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>パラメータ <code>NLS_COMP</code> と <code>NLS_SORT</code> は、文字のソートと比較に共同で影響します。データベースの <code>NLS_COMP</code> を <code>LINGUISTIC</code> に設定した場合、この開発ガイドで言及されているすべてのエンティティは、パラメータ <code>NLS_SORT</code> で指定されたルールに従います。<code>NLS_COMP</code> の値が <code>LINGUISTIC</code> に指定されていない場合、関数は <code>NLS_SORT</code> の影響を受けません。<code>NLS_SORT</code> の値は直接指定できますが、指定されていない場合は <code>NLS_LANGUAGE</code> の値を継承します。</p>
  </main>

以下のSQLステートメントの `WHERE` 句で条件を使用できます：

* `DELETE`

* `SELECT`

* `UPDATE`

`SELECT` ステートメントの以下の句でも条件を使用できます：

* `WHERE`

* `START WITH`

* `CONNECT BY`

* `HAVING`

条件は論理データ型と呼ばれることがあります。例えば、単純条件 `1 = 1` の判断結果は `TRUE` です。また、次の例では、`salary` の値に `comm_pct` の値を加算し（関数 `NVL()` は `salary` のNULL値を0に置き換えます）、その合計が2500より大きいかどうかを判断します。

```sql
NVL(salary, 0) + NVL(salary + (salary * comm_pct, 0) > 2500)
```

論理条件は複数の条件を1つの条件に組み合わせることができます。例えば、論理条件 `AND` は複数の条件を1つの条件に組み合わせることができます。

```sql
(1 = 1) AND (5 < 7)
```

SQLステートメントにおける有効な条件の例は以下のとおりです：

```sql
name = 'ALICE'
emp.deptno = dept.deptno
hire_date > '01-JAN-22'
job_id IN ('SA_MAN', 'SA_REP')
salary BETWEEN 5000 AND 8000
comm_pct IS NULL AND salary = 10000
```
