# 比較条件

比較条件（Comparison Condition）は、ある式と別の式を比較し、TRUE、FALSE、またはUNKNOWNのいずれかの結果を返します。比較条件は、単純比較条件と組み合わせ比較条件に分類されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>比較条件は、BLOBデータ型をサポートしていません。ただし、PLプログラムを使用して <code>CLOB</code> データを比較することはできます。</p>
  </main>

数値式を比較する場合、OceanBaseデータベースは数値の優先順位に基づいて、条件内の数値の比較順序を決定します。`BINARY_DOUBLE` の優先順位が最も高く、次いで `BINARY_FLOAT`、`NUMBER` が最も低い優先順位です。

文字列を比較する場合、OceanBaseデータベースは、文字データ型の比較ルールに従います。これには、比較前に式の文字セットがどのように統一されているか、バイナリおよび言語比較を使用するか、空白埋め込みおよび非空白埋め込みの比較セマンティクスを使用するかなどが含まれます。

比較条件を使用して文字値を言語的に比較する場合、まずそれらをソートキーに変換し、その後比較を行います。この比較プロセスは `RAW` データ型に似ています。ソートキーは関数 `NLSSORT` が返す値です。2つの式が生成するソートキーのプレフィックスが同じ場合、値の残りの部分が異なっていても、言語的に等しいと見なされます。

2つの非スカラータイプのオブジェクトが同じ名前タイプを持ち、かつその要素間に一対一の対応関係が存在する場合、それらは比較可能です。ユーザー定義のオブジェクト型であるネスト表を、等号または `IN` 条件で使用する場合は、`MAP` メソッドを定義する必要があります。ネスト表の要素は互いに比較できます。

比較条件の詳細は以下の表のとおりです。

|                    条件タイプ                     |                                                         機能                                                         |                                                                例                                                                |
|---------------------------------------------|--------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| =                                           | 等しい                                                                                                                 | `SELECT * FROM emp WHERE   salary = 2000 ORDER BY empno;`                                                                        |
| != \^= \<\> | 等しくない                                                                                                                | `SELECT * FROM emp WHERE salary != 2000 ORDER BY empno;`                                                                         |
| \> \<                       | 大于 小于                                                                                              | `SELECT * FROM emp WHERE salary > 2000 ORDER BY empno;` `SELECT * FROM emp WHERE salary < 2000 ORDER BY empno;`  |
| \>= \<=                     | 大于等于 小于等于                                                                                          | `SELECT * FROM emp WHERE salary >= 2000 ORDER BY empno;` `SELECT * FROM emp WHERE salary <=2000 ORDER BY empno;` |
| ANY SOME                    | 値をリスト内の各値、またはクエリが返す値と比較します。必ず =、!=、\>、\<、\<=、\>= で始める必要があります。後ろには、1つ以上の値を返す式またはサブクエリを続けることができます。クエリが行を返さない場合、計算結果は FALSE になります。 | `SELECT * FROM emp WHERE`           `salary = ANY (SELECT salary FROM emp     WHERE deptno = 30) ORDER BY empno;`               |
| ALL                                         | 値をリスト内の各値、またはクエリが返す値と比較します。必ず =、!=、\>、\<、\<=、\>= で始める必要があります。後ろには、1つ以上の値を返す式またはサブクエリを続けることができます。クエリが行を返さない場合、計算結果は TRUE になります。  | `SELECT * FROM emp WHERE salary >=ALL (1900, 3000) ORDER BY empno;`                                                              |

## 単純比較条件

単純比較条件は、単一の式と式のリストを比較する場合、または単一の式とサブクエリの結果を比較する場合があります。

単純比較条件の構文は以下のとおりです：

```sql
expr {= | != | ^= | <> | < | >= |} ( expression_list | subquery )
```

単純比較条件では、単一の式と式のリストを比較する場合、式のリスト内の式は、演算子の左側の式と数とデータ型が一致している必要があります。単一の式とサブクエリの値を比較する場合、サブクエリが返す値は、演算子の左側の式と数とデータ型が一致している必要があります。

## 組み合わせ比較条件

組み合わせ比較条件は、単一の式と式のリストまたはサブクエリの結果の任意またはすべてのメンバーを比較する場合、または複数の式と式のリストまたはサブクエリの結果の任意またはすべてのメンバーを比較する場合があります。

グループ比較条件では、単一の式または複数の式のリストが、式のリストの任意またはすべてのメンバーと比較される場合、各式のリスト内の式は、演算子の左側にある式と数とデータ型が一致している必要があります。単一の式または複数の式が、サブクエリ結果の任意またはすべてのメンバーと比較される場合、サブクエリが返す値は、演算子の左側にある式と数とデータ型が一致している必要があります。

グループ比較条件には、以下の2つの構文があります：

```sql
expr  {= | != | ^= | <> | < | >= | ANY | SOME | ALL } ({ expression_list | subquery})
```

```sql
(expr [, expr ]...){= | != | ^= | ANY | SOME | ALL} ({expression_list  [, expression_list ]... |subquery})
```
