# 浮動小数点条件

浮動小数点条件（Floating-Point Condition）は、式が無限または定義されていない結果の演算（数値またはNaNではない）であるかどうかを判断するために使用します。

浮動小数点条件の構文は次のとおりです：

```sql
expr IS [ NOT ] { NAN | INFINITE }
```

`{ NAN | INFINITE }` の2種類の形式の浮動小数点条件では、`expr` は数値データ型、または数値データ型へ暗黙的に変換可能な任意のデータ型に解析されなければなりません。

浮動小数点条件の詳細は以下の表のとおりです。

|        条件タイプ         |                                                         演算                                                         |                            例                             |
|---------------------|--------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------|
| IS \[NOT\] NAN      | `NOT` を指定しない場合、`expr` が特殊値 NaN の場合は TRUE を返します。`NOT` を指定した場合、`expr` が特殊値 NaN 以外の場合は TRUE を返します。                               | `SELECT COUNT(*) FROM emp WHERE comm_pct IS NOT NAN;`     |
| IS \[NOT\] INFINITE | NOT を指定しない場合、`expr` が特殊値 +INF または -INF の場合は TRUE を返します。`NOT` を指定した場合、`expr` が +INF でも -INF でもない場合は TRUE を返します。 | `SELECT last_name FROM emp WHERE salary IS NOT INFINITE;` |
