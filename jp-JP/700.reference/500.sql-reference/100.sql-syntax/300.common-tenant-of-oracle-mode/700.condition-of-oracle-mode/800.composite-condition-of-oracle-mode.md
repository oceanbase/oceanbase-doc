# 複合条件

複合条件（Compound Conditions）とは、複数の他の条件を組み合わせたものです。

複合条件の構文は以下のとおりです：

```sql
{ (condition) | NOT condition | condition { AND | OR } condition }
```

条件`NOT`、`AND`、`OR`の詳細については、[論理条件](../700.condition-of-oracle-mode/500.logical-conditions-of-oracle-mode.md)を参照してください。
