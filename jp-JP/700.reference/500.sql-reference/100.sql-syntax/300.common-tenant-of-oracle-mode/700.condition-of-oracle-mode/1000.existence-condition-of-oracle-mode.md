# EXISTS 条件

EXISTS 条件（EXISTS Condition）は、サブクエリ内に指定された行が存在するかどうかをテストするために使用されます。

## EXISTS 条件の構文

EXISTS 条件の構文は以下のとおりです：

```sql
EXISTS (subquery)
```

サブクエリが少なくとも1行を返す場合、必要なデータが存在することを意味します。

## 例

```sql
SELECT dept_id FROM dept d WHERE EXISTS (SELECT * FROM emp e
WHERE d.dept_id = e.dept_id) ORDER BY dept_id;
```
