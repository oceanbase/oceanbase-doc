# INITCAP

## 説明

この関数は文字列を返し、その文字列内の各単語の先頭文字を大文字に、他の文字を小文字に変換します。単語はスペースまたは英数字以外の文字で区切られます。

## 構文

```sql
INITCAP(char)
```

## パラメータの説明

`char` は文字列を表します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` です。

## 戻り値のタイプ

`CHAR` 型データを返します。

## 例

文字列 `ABC def,gHI` の各単語の先頭文字を大文字にします。

```sql
obclient> SELECT INITCAP('ABC def,gHI') STR FROM DUAL;
+-------------+
| STR         |
+-------------+
| Abc Def,Ghi |
+-------------+
1 row in set
```
