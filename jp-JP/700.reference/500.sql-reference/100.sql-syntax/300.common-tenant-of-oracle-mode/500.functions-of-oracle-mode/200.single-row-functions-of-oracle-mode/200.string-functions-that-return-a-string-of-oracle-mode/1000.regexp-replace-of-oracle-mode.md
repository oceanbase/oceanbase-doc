# REGEXP_REPLACE

## 説明

この関数は、文字列 `source_char` 内で正規表現と一致する文字を `replace_string` 内の文字に置き換えます。

## 構文

```sql
REGEXP_REPLACE(source_char, pattern
                 [, replace_string
                    [, position
                      [, occurrence
                        [, match_param ]
                      ]
                    ]
                 ]
               )
```

## パラメータの説明

|       パラメータ       |                                                                                                                                                                                   説明                                                                                                                                                                                   |
|----------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| source_char    | サーチ値として使用する文字式を指定します。通常は文字列です。データ型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。                                                                                                                                                                                                                                                                                       |
| pattern        | 正規表現を指定します。通常はテキスト文字で、データ型は `CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` が可能です。                                                                                                                                                                                                                                                                                                    |
| replace_string | 置き換える文字です。`CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` 型が可能です。                                                                                                                                                                                                                                                                                                         |
| position       | 正規表現のマッチング開始位置を指定します。正の整数で、オプションです。デフォルト値は `1` で、`source_char` の最初の文字から検索を開始することを意味します。                                                                                                                                                                                                                                                                                                    |
| occurrence     | 置き換え操作のマッチ項目の番号を指定します。非負の整数です。 <ul><li> `0` を指定した場合、OceanBaseデータベースはすべてのマッチ項目を置き換えます。   </li><li> 正の整数 `n` を指定した場合、OceanBaseデータベースは `n` 番目に現れるマッチ項目を置き換えます。 </li></ul>                                                                                                                                                        |
| match_param    | データ型 `VARCHAR2` または `CHAR` の文字式で、関数のデフォルトのマッチ動作を変更できます。 <ul><li> `i` は大文字小文字を区別しないことを意味します。   </li><li> `c` は大文字小文字を区別することを意味します。   </li><li> `n` はドット `.` が改行文字と一致できることを意味します。   </li><li> `m` は複数行モードを意味します。   </li><li> `x` はスペース文字を無視することを意味します。デフォルトでは、スペース文字は互いに一致します。</li></ul>     |

## 戻り値の型

戻り値のデータ型は `source_char` と同じです。

## 例

文字列 `OCEANBASE database` 内のすべての文字を `(A|B){1}` と一致する文字に置き換えて `*` にします。

```sql
obclient> SELECT REGEXP_REPLACE('OCEANBASE database', '(A|B){1}', '*',1,0) AS "REGEXP_REPLACE" FROM DUAL;
+--------------------+
| REGEXP_REPLACE     |
+--------------------+
| OCE*N**SE database |
+--------------------+
1 row in set
```
