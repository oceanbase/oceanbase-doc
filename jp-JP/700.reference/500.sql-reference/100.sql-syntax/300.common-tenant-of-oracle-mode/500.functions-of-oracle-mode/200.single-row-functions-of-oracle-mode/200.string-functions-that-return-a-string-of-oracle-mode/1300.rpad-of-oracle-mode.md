# RPAD

## 説明

この関数は、文字列 `char1` の右側を文字列 `char2` で埋めて、長さが `n` になるまで拡張します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>char1</code> の長さが <code>n</code> より大きい場合、<code>char1</code> の左側の <code>n</code> 文字を返します。</li>
    <li><code>char1</code> の長さが <code>n</code> より小さく、<code>char1</code> と <code>char2</code> を連結した長さが <code>n</code> より大きい場合、連結後の左側の <code>n</code> 文字を返します。</li>
    <li><code>char1</code> の長さが <code>n</code> より小さく、<code>char1</code> と <code>char2</code> を連結した長さが <code>n</code> より小さい場合、<code>char1</code> と複数の繰り返し <code>char2</code> を連結した（全長が <code>n</code> 以上）左側の <code>n</code> 文字を返します。</li>
    </ul>
  </main>

## 構文

```sql
RPAD(char1,n[,char2])
```

## パラメータの説明

| パラメータ | 説明 |
|-------|--------------------------------------------------------------------------------------------------------------|
| char1 | 文字列を表します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。                                                |
| n     | 追加後の文字の総長であり、`NUMBER` 型または `NUMBER` 型へ暗黙的に変換可能な値である必要があります。<br>**説明** 整数以外の値の場合、小数部分は切り捨てられて整数に変換されます。 |
| char2 | 追加する文字列を表します。デフォルトはスペースです。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。                                       |

## 戻り値のタイプ

* `char1` が文字データ型の場合、`VARCHAR2` タイプを返します。

* `char1` が国家文字データ型の場合、`NVARCHAR2` タイプを返します。

* `char1` が `LOB` データ型の場合、`LOB` タイプを返します。

## 例

アスタリスク `*` を使用して、文字列 `ABCDE` の右側を10文字まで埋めます。

```sql
obclient> SELECT  RPAD('ABCDE',10,'*') "RPAD" FROM DUAL;
+------------+
| RPAD       |
+------------+
| ABCDE***** |
+------------+
1 row in set
```
