# SOUNDEX

## 説明

この関数は、文字列の音声表現を返します。これにより、綴りは異なるものの発音が近い英単語を比較することができます。

## 構文

```sql
SOUNDEX(char)
```

## パラメータ説明

`char` は変換対象の文字列を指定します。

## 戻り値タイプ

文字列型を返します。

## 例

文字列 `OceanBase` の音声表現を返します。

```sql
obclient> SELECT SOUNDEX('OceanBase') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
| O251   |
+--------+
1 row in set
```
