# TRANSLATE ... USING

## 説明

この関数は、文字を指定されたデータベース文字セットまたは言語文字セットに変換する役割を果たします。

## 構文

```sql
TRANSLATE(char USING{ CHAR_CS | NCHAR_CS })
```

## パラメータの説明

|    パラメータ    |                               説明                                |
|----------|-----------------------------------------------------------------|
| char     | 変換する文字列。データ型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。 |
| CHAR_CS  | データベース文字セットへの変換を指定します。                                                    |
| NCHAR_CS | 言語文字セットへの変換を指定します。                                                     |

## 戻り値の型

* `CHAR_CS` を指定した場合、`VARCHAR2` 型を返します。

* `NCHAR_CS` を指定した場合、`NVARCHAR2` 型を返します。

## 例

文字列 `OceanBase` を指定すると、出力タイプは `VARCHAR2` 型と `NVARCHAR2` 型であり、文字列のバイト長も出力されます。

```sql
obclient> SELECT LENGTHB(TRANSLATE('OceanBase' USING CHAR_CS)) "VARCHAR2",
                 LENGTHB(TRANSLATE('OceanBase' USING NCHAR_CS)) "NVARCHAR2"
          FROM DUAL;
+----------+-----------+
| VARCHAR2 | NVARCHAR2 |
+----------+-----------+
|        9 |        18 |
+----------+-----------+
1 row in set
```
