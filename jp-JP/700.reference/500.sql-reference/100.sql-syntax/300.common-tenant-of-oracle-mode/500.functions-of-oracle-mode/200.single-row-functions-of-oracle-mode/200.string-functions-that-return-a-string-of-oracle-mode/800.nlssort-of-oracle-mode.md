# NLSSORT

## 説明

この関数は、明示または暗黙のパラメータで指定されたソート規則に基づいて、文字ソートキー値（Sortkey）を返します。

`NLSSORT()` 関数は、指定されたソート規則に基づいてソートキー値を生成します。ソートキーはバイト文字列であり、指定されたソート規則に従って文字をソートするために使用されます。

ソート規則キーの長さは、パラメータ `MAX_STRING_SIZE` の影響を受けます。`MAX_STRING_SIZE=EXTENDED` の場合、戻り値の最大長は 32767 バイトです。ソート規則キーがこの制限を超えると、関数は実行失敗し、「unable to create the collation key」というエラーが表示されます。

## 構文

```sql
NLSSORT(char [, 'nlsparam' ])
```

## パラメータの説明

|    パラメータ    |                                                                                                                                                                                                                                                                                                                                                           説明                                                                                                                                                                                                                                                                                                                                                           |
|----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| char     | このパラメータはリテラルと式（列名を含む）の両方をサポートします。 データ型は `CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` が可能です。入力データ型が `CLOB` の場合、暗黙的に変換されます。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| nlsparam | ソート規則を指定します。 `nlsparam` の固定形式は `NLS_SORT = collation` です。`collation` は言語ソート規則名を指します。 OceanBase データベースは V4.2 以降、簡体字中国語のソートで GB18030_2022 文字セットに基づくソート方式を新たにサポートしています。中国語文字セットでは、現在以下の 3 種類の簡体字中国語のソート方式をサポートしています： <ul><li>`SCHINESE_PINYIN2_M`：ピンイン順にソートします。   </li><li> `SCHINESE_STROKE2_M`：筆順順にソートします。   </li><li> `SCHINESE_RADICAL2_M`：部首順にソートします。</li></ul>     Unicode については、現在以下の 3 種類の簡体字中国語のソート方式をサポートしています： <ul><li> `UCA0900_SCHINESE_PINYIN`: ピンイン順にソートします。   </li><li> `UCA0900_SCHINESE_STROKE`：筆順順にソートします  </li><li> `UCA0900_SCHINESE_RADICAL`：まず部首でソートし、次に筆順でソートします。 </li></ul>    `nlsparam` を省略した場合、この関数は文字セットのデフォルトソート規則を使用します。 |

## 例

```sql
obclient> CREATE TABLE tbl1(PK INT, name VARCHAR(25));
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES(1,'Fox'),(2,'Police'),(3,'Taxi'),(4,'Lincoln'),(5,'Arizona'),(6,'Washington'),
      (7,'Dell'),(10,'Lucent');

Records: 8  Duplicates: 0  Warnings: 0

obclient> SELECT * FROM tbl1;

obclient> SELECT * FROM tbl1 ORDER BY NLSSORT(name,'NLS_SORT = SCHINESE_PINYIN2_M');

8 rows in set
```
