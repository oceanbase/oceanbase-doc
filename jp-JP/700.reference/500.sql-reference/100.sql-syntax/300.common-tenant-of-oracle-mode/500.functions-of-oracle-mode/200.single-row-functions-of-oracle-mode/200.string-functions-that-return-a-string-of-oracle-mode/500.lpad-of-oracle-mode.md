# LPAD

## 説明

この関数は、文字列 `char1` の左側を文字列 `char2` で埋めて、長さが `n` になるようにする機能です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>char1</code> の長さが <code>n</code> より大きい場合、<code>char1</code> の左側の最初の <code>n</code> 文字を返します。</li>
    <li><code>char1</code> の長さが <code>n</code> より短く、<code>char2</code> と <code>char1</code> を連結した長さが <code>n</code> より大きい場合、連結後の文字列の右側から <code>n</code> 文字目までを返します。</li>
    </ul>
  </main>

## 構文

```sql
LPAD(char1,n[,char2])
```

## パラメータの説明

|  パラメータ   |                                                      説明                                                      |
|-------|--------------------------------------------------------------------------------------------------------------|
| char1 | 文字列を表します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。                                               |
| n     | 結果としての文字列の総長で、`NUMBER` 型または `NUMBER` 型へ暗黙的に変換できる値である必要があります。 <br>**説明**  整数以外の値は小数部を切り捨てて整数に変換されます。 |
| char2 | 追加する文字列を表します。デフォルトはスペースです。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。                                      |

## 戻り値の型

* `char1` が文字データ型の場合、`VARCHAR2` 型を返します。

* `char1` が国際化文字データ型の場合、`NVARCHAR2` 型を返します。

* `char1` が `LOB` データ型の場合、`LOB` 型を返します。

## 例

アスタリスク `*` を使用して、文字列 `ABCDE` の左側を埋めます。

```sql
obclient> SELECT  LPAD('ABCDE',10,'*') FROM DUAL;
+----------------------+
| LPAD('ABCDE',10,'*') |
+----------------------+
| *****ABCDE           |
+----------------------+
1 row in set
```
