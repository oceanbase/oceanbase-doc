# CONCAT

## 説明

この関数は、2つの文字列を連結します。

## 構文

```sql
CONCAT(char1,char2)
```

## パラメータの説明

| パラメータ |                             説明                              |
|-------|-------------------------------------------------------------|
| char1 | 文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` とすることができます。 |
| char2 | 文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` とすることができます。 |

## 戻り値の型

`char1`と同じデータ型を返します。

## 例

文字列`Hello`と文字列`, world!`を連結します。

```sql
obclient> SELECT CONCAT('Hello',', world!') FROM DUAL;
+---------------------------+
| CONCAT('HELLO',',WORLD!') |
+---------------------------+
| Hello, world!             |
+---------------------------+
1 row in set
```
