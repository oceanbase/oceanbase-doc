# CONCAT

## 説明

この関数は、2つの文字列を結合します。

## 構文

```sql
CONCAT(char1,char2)
```

## パラメータの説明

| パラメータ   |                             説明                              |
|-------|-------------------------------------------------------------|
| char1 | 文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が指定できます。 |
| char2 | 文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が指定できます。 |

## 戻り値の型

`char1` と同じデータ型を返します。

## 例

文字列 `Hello` と文字列 `, world!` を結合します。

```sql
obclient> SELECT CONCAT('Hello',', world!') FROM DUAL;
+---------------------------+
| CONCAT('HELLO',',WORLD!') |
+---------------------------+
| Hello, world!             |
+---------------------------+
1 row in set
```
