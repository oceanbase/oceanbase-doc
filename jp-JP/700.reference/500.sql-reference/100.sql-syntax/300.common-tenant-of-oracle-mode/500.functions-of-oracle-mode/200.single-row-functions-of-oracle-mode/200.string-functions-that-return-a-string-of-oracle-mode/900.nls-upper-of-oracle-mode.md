# NLS_UPPER

## 説明

この関数は、文字列内の英字をすべて大文字に変換します。

## 構文

```sql
NLS_UPPER(char [, 'nlsparam' ])
```

## パラメータの説明

|    パラメータ    |                                          説明                                          |
|----------|--------------------------------------------------------------------------------------|
| char     | 変換する文字列を指定します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。                    |
| nlsparam | 返される文字列のソート方式を指定します。オプションです。 <br>**説明**  OceanBaseデータベースの現行バージョンでは、このパラメータはサポートされていません。 |

## 戻り値の型

`char`と同じデータ型を返します。

## 例

文字列`OceanBase`をすべて大文字に変換します。

```sql
obclient> SELECT NLS_UPPER('OceanBase') "UPPER" FROM DUAL;
+-----------+
| UPPER     |
+-----------+
| OCEANBASE |
+-----------+
1 row in set
```
