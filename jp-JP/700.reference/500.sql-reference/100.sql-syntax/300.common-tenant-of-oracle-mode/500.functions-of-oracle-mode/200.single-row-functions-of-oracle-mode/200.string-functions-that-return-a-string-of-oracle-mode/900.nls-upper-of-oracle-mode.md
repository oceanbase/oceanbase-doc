# NLS_UPPER

## 説明

この関数は、文字列内のすべての英字を大文字に変換します。

## 構文

```sql
NLS_UPPER(char [, 'nlsparam' ])
```

## パラメータの説明

|    パラメータ    |                                          説明                                          |
|----------|--------------------------------------------------------------------------------------|
| char     | 変換対象の文字列を指定します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。                    |
| nlsparam | 戻り値の文字列のソート方法を指定するオプションです。 <br>**注意**  OceanBaseデータベースの現在のバージョンでは、このパラメータはサポートされていません。 |

## 戻り値の型

`char` と同じデータ型を返します。

## 例

文字列 `OceanBase` のすべての文字を大文字に変換します。

```sql
obclient> SELECT NLS_UPPER('OceanBase') "UPPER" FROM DUAL;
+-----------+
| UPPER     |
+-----------+
| OCEANBASE |
+-----------+
1 row in set
```
