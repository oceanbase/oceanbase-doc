# LOWER

## 説明

この関数は、文字列内の英字をすべて小文字に変換します。

## 構文

```sql
LOWER(char)
```

## パラメータの説明

`char` は文字列を表します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。

## 戻り値の型

`char` と同じデータ型を返します。

## 例

文字列 `AaBbCcDd` 内の英字をすべて小文字に変換します。

```sql
obclient> SELECT  LOWER('AaBbCcDd') Lowercase FROM DUAL;
+-----------+
| LOWERCASE |
+-----------+
| aabbccdd  |
+-----------+
1 row in set
```
