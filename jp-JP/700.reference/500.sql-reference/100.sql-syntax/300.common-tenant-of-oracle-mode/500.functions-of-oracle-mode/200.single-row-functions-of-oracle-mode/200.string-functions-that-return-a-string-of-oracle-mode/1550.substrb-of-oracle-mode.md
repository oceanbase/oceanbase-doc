# SUBSTRB

## 説明

この関数は、バイト単位で文字列から部分文字列を切り出します。

## 構文

```sql
SUBSTRB(char, position [, substring_length])
```

## パラメータの説明

| パラメータ | 説明 |
|------|------|
| char | 切り出す文字列を指定します。 |
| position | 切り出し始めるバイト位置を指定します。値が `0` の場合は `1` として扱われます。値が負の場合は、文字列の終端から逆算して開始位置を求めます。 |
| substring_length | オプションです。切り出すバイト数を指定します。省略した場合、文字列の終端まで切り出されます。 |

## 戻り値の型

文字列型を返します。

## 例

文字列 `中OceanBase` の漢字 `中` は3バイトです。以下の例では、4番目のバイトから5バイトを切り出します。

```sql
obclient> SELECT SUBSTRB('中OceanBase', 4, 5) AS result FROM DUAL;
+--------+
| RESULT |
+--------+
| Ocean  |
+--------+
1 row in set
```
