# CHR

## 説明

この関数は、数値パラメータに基づいて文字を返します。また、返される値は現在のシステムの文字セットに関連しています。

## 構文

```sql
CHR(n)
```

## パラメータの説明

パラメータ `n` は、対応する文字の `NUMBER` コードを照会するために使用されます。これは整数値であり、範囲は \[0，4294967295\] です。

## 戻り値のタイプ

返される値は現在のシステムの文字セットに関連しています。OceanBaseデータベースがサポートする文字セットは `binary、utf8mb4、gbk、utf16、gb18030` です。

## 例

10進数 `25700` を対応する文字に変換します。文字セットは `UTF-8` です。

```sql
obclient> SELECT CHR(25700) AS str FROM DUAL;
+------+
| STR  |
+------+
| dd   |
+------+
1 row in set
```
