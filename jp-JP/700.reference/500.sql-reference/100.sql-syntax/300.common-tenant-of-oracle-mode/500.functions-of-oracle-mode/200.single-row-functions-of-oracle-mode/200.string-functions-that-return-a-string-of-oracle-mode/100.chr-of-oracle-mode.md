# CHR

## 説明

この関数は、数値パラメータに基づいて文字を返し、戻り値は現在のシステムの文字セットによって異なります。

## 構文

```sql
CHR(n)
```

## パラメータの説明

パラメータ `n` は、対応する文字を取得するために使用する `NUMBER` 型のコードです。これは整数値で、範囲は \[0，4294967295\] です。

## 戻り値の型

戻り値は現在のシステムの文字セットによって異なります。OceanBaseデータベースがサポートする文字セットは `binary、utf8mb4、gbk、utf16、gb18030` です。

## 例

10進数 `25700` を対応する文字に変換します。文字セットは `UTF-8` です。

```sql
obclient> SELECT CHR(25700) AS str FROM DUAL;
+------+
| STR  |
+------+
| dd   |
+------+
1 row in set
```
