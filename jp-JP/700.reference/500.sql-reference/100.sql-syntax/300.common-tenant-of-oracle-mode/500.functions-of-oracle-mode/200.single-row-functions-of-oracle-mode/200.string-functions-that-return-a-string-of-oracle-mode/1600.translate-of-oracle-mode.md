# 翻訳

## 説明

この関数は、`char1` 内の `char2` とマッチする文字を `char2` と `char3` の対応する順序の文字に置き換えます。

## 構文

```sql
TRANSLATE(char1,char2,char3)
```

## パラメータの説明

| パラメータ | 説明 |
|-------|-------------------------|
| char1 | 文字式または変数を指定します。             |
| char2 | `char1` 内で置き換える文字の集合を指定します。 |
| char3 | `char2` を置き換えるために使用する文字の集合を指定します。   |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>char1</code>、<code>char2</code>、および <code>char3</code> のデータ型は <code>CHAR</code>、<code>VARCHAR2</code>、<code>NCHAR</code>、<code>NVARCHAR2</code>、または <code>CLOB</code> です。</li>
    <li><code>char3</code> の長さが <code>char2</code> より長い場合、<code>char3</code> の後ろの余分な文字は無効です。</li>
    <li><code>char3</code> の長さが <code>char2</code> より短い場合、<code>char2</code> の後ろの余分な文字はすべて空（削除）に置き換えられます。</li>
    <li><code>char3</code> の長さが <code>0</code> の場合、<code>NULL</code> を返します。</li>
    <li><code>char2</code> 内に重複する文字がある場合、置き換えの基準として重複する文字が最初に現れた位置を使用します。例えば、<code>char2</code> が <code>aab</code> で <code>char3</code> が <code>123</code> の場合、置き換えの基準として <code>char1</code> 内のすべての <code>a</code> を <code>1</code> に、すべての <code>b</code> を <code>3</code> に置き換えます。</li>
    </ul>
  </main>

## 戻り値のタイプ

`char1` と同じデータ型を返します。

## 例

文字列 `OceanBase` 内の `a` と `e` を `A` と `E` に置き換えます。

```sql
obclient> SELECT TRANSLATE('OceanBase','ae','AE') "TRANSLATE" FROM DUAL;
+-----------+
| TRANSLATE |
+-----------+
| OcEAnBAsE |
+-----------+
1 row in set
```
