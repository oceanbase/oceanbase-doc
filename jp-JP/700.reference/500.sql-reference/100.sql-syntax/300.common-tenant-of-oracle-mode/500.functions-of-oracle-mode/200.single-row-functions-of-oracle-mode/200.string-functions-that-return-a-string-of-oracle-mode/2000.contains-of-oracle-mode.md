# CONTAINS

## 説明

この関数は、主にデータベースのフィールドで文字列マッチングまたは全文検索を行うために使用されます。

## 構文

```sql
CONTAINS(indexed_column, 'search_query' [, score_label])
```

## パラメータの説明

* `indexed_column`：全文インデックスの列名を表します。
* `search_query`：`VARCHAR2` 型または `CLOB` 型で、検索するキーワードまたはフレーズを表します。
* `score_label`：オプションのパラメータで、`NUMBER` 型です。返される結果のマッチング番号を表します。

## 例

以下のコマンドを実行して、`test` テーブルから `c1` 列の内容に文字列 `city` を含むデータ行をフィルタリングします。

```sql
obclient> SELECT id, c1 FROM test WHERE CONTAINS(c1, 'city') > 0;
```
