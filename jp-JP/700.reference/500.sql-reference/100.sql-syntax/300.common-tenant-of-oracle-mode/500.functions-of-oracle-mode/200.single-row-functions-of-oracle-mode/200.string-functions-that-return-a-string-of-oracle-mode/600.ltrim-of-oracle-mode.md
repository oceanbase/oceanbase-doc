# LTRIM

## 説明

この関数は、`char1` の左端から `char2` に含まれるすべての文字を削除し、`char1` の左端で `char2` に存在しない文字が現れるまで続け、その結果を返します。

## 構文

```sql
LTRIM(char1 [,char2])
```

## パラメータの説明

| パラメータ |                                                    説明                                                      |
|-------|-------------------------------------------------------------------------------------------------------------|
| char1 | 文字列を表します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。                             |
| char2 | 削除する文字の集合を表します。`char2` を指定しない場合、デフォルトで1つのスペースが使用されます。 文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。 |

## 戻り値の型

* `char1` が `CHAR` または `VARCHAR2` データ型の場合、関数は `VARCHAR2` データ型を返します。

* `char1` が `NCHAR` または `NVARCHAR2` データ型の場合、関数は `NVARCHAR2` データ型を返します。

* `char1` が `LOB` データ型の場合、返される文字列は `LOB` データ型となります。

## 例

文字列 `#a￥！aa￥ Hello World!` の `Hello World!` の前の余分な文字を削除します。

```sql
obclient> SELECT LTRIM('#a￥!aa￥  Hello World!','#a￥! ') text FROM DUAL;
+--------------+
| TEXT         |
+--------------+
| Hello World! |
+--------------+
1 row in set
```
