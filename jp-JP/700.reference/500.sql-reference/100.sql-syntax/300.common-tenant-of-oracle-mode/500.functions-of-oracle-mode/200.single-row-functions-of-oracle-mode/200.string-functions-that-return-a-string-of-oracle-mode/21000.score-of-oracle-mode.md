# SCORE

## 説明

この関数は、主にデータベースフィールドでの文字列マッチングや全文検索に使用されます。

## 構文

```sql
SCORE(score_label)
```

## パラメータの説明

* `score_label`：オプションパラメータ。`NUMBER` 型で、戻り値となる結果のマッチング番号を表します。

## 例

以下のコマンドを実行し、`CONTAINS` と `SCORE` を使用して全文検索のソートクエリを実現します。

```sql
obclient> SELECT column1, column2, ...
FROM table_name
WHERE CONTAINS(indexed_column, 'search_query'[, score_label]) > 0
ORDER BY SCORE(score_label) DESC;
```
