# UPPER

## 説明

この関数は、文字列内の英字をすべて大文字に変換します。

## 構文

```sql
UPPER(char)
```

## パラメータの説明

`char` は変換対象の文字列であり、データ型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` です。

## 戻り値の型

`char` と同じデータ型を返します。

## 例

文字列 `OceanBase` のすべての文字を大文字に変換します。

```sql
obclient> SELECT UPPER('OceanBase') "UPPER" FROM DUAL;
+-----------+
| UPPER     |
+-----------+
| OCEANBASE |
+-----------+
1 row in set
```
