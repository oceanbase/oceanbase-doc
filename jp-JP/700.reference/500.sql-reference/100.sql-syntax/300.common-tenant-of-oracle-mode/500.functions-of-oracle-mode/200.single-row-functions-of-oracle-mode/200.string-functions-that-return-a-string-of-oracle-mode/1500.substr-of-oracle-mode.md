# SUBSTR

## 説明

この関数は、文字列から部分文字列を切り出す機能を持っています。複数バイトの文字（漢字、全角記号など）は1文字としてカウントされます。

## 構文

```sql
SUBSTR(char1,n1[,n2])
```

## パラメータの説明

| パラメータ |                                                                                                                                                                                                                                                                  説明                                                                                                                                                                                                                   |
|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| char1 | 切り出す文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` とすることができます。                                                                                                                                                                                                                                                                                                                                        |
| n1    | 文字列の切り出し始めの位置。データ型は `NUMBER` です。<br>**説明**<ul><li> `n1` が `0` の場合、`1` と見なされ、`char1` の最初の文字から切り出します。</li><li> `n1` が正の数の場合、`char1` の `n1` 番目の文字から切り出しを開始します。</li><li> `n1` が負の数の場合、`char1` の末尾から `n1` 番目の文字まで逆算して、その後にある文字列を切り出します。</li></ul>    |
| n2    | 切り出す文字列の長さ。データ型は `NUMBER` で、オプションです。<br>**説明**<ul><li> `n2` を指定しない場合、`n1` 番目の文字から `char1` の終わりまでの文字列を切り出します。</li><li> `n2` が `0` より小さい場合、`NULL` を返します。</li></ul>                                                                                                                                                                |

## 戻り値のタイプ

`char1` のデータ型と同じデータ型を返します。

## 例

文字列 `OceanBase` の最初の `1` 文字目から `5` 文字、および最後から `-3` 文字目から `2.1` 文字を切り出す。

```sql
obclient> SELECT SUBSTR('OceanBase',1,5) "SUBSTR1",SUBSTR('OceanBase',-3,2.1) "SUBSTR2" FROM DUAL;
+---------+---------+
| SUBSTR1 | SUBSTR2 |
+---------+---------+
| Ocean   | as      |
+---------+---------+
1 row in set
```
