# SUBSTR

## 説明

この関数は、文字列からサブ文字列を切り出す機能を持ちます。複数バイト文字（全角文字など）は `1` 文字として計算されます。

## 構文

```sql
SUBSTR(char1,n1[,n2])
```

## パラメータの説明

|  パラメータ   |                                                                                                                                                                                                   説明                                                                                                                                                                                                    |
|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| char1 | 切り出す文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。                                                                                                                                                                                                                                                                                                                                        |
| n1    | 文字列の開始位置。データ型は `NUMBER` です。 <br>**説明**  <ul><li> `n1` が `0` の場合、`1` と見なされ、`char1` の最初の文字から切り出し始めます。   </li><li> `n1` が正の場合、`char1` の `n1` 番目の文字から切り出し始めます。   </li><li> `n1` が負の場合、`char1` の終端から `n1` 文字目まで逆算して、そこから切り出し始めます。  </li></ul>    |
| n2    | 切り出す文字列の長さ。データ型は `NUMBER` で、オプションです。 <br>**説明**  <ul><li> `n2` を指定しない場合、`n1` 番目の文字から `char1` の終端までの文字列を切り出します。  </li><li> `n2` が `0` より小さい場合、`NULL` を返します。 </li></ul>                                                                                                                                                                |

## 戻り値の型

`char1` と同じデータ型を返します。

## 例

文字列 `OceanBase` の最初の `1` 文字から `5` 文字を切り出し、`-3` 番目の文字から `2.1` 文字を切り出します。

```sql
obclient> SELECT SUBSTR('OceanBase',1,5) "SUBSTR1",SUBSTR('OceanBase',-3,2.1) "SUBSTR2" FROM DUAL;
+---------+---------+
| SUBSTR1 | SUBSTR2 |
+---------+---------+
| Ocean   | as      |
+---------+---------+
1 row in set
```
