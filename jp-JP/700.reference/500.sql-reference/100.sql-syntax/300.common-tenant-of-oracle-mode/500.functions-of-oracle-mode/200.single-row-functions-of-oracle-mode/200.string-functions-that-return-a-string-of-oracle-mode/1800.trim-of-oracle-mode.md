# TRIM

## 説明

この関数は、文字列の先頭または末尾（またはその両方）の文字を削除するために使用されます。

## 構文

```sql
TRIM([{{ LEADING | TRAILING | BOTH }[ trim_character ]|trim_character }FROM] trim_source)
```

## パラメータの説明

|             パラメータ              |                                                                                                                                                                                説明                                                                                                                                                                                 |
|-----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LEADING \| TRAILING \| BOTH | 削除する文字の位置を指定します。 <ul><li> `LEADING` は先頭文字です。`LEADING` を指定すると、すべての先頭文字と等しい `trim_character` が削除されます。  </li><li> `TRAILING` は末尾文字です。`TRAILING` を指定すると、すべての末尾文字と等しい `trim_character` が削除されます。   </li><li> `BOTH` は先頭と末尾の文字です。`BOTH` を指定するか、いずれも指定しない場合、先頭と末尾の文字と等しい `trim_character` が削除されます。</li></ul>    |
| trim_character              | 削除する文字で、単一の文字のみ指定可能です。`trim_character` が指定されていない場合、デフォルト値はスペースです。                                                                                                                                                                                                                                                                                                    |
| trim_source                 | 文字を削除する文字列です。`trim_source` のみを指定した場合、先頭と末尾のスペースが削除されます。                                                                                                                                                                                                                                                                                                      |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>trim_character</code> と <code>trim_source</code> は、どちらも <code>VARCHAR2</code> または <code>VARCHAR2</code> へ暗黙的に型変換できるデータ型を指定できます。関数の戻り値のデータ型が <code>VARCHAR2</code> の場合、その値の最大長は <code>trim_source</code> となります。</p>
  </main>

## 戻り値の型

* `trim_source` が `CHAR` または `VARCHAR2` 型の場合、この関数は `VARCHAR2` 型を返します。

* `trim_source` が `NCHAR` または `NVARCHAR2` 型の場合、この関数は `NVARCHAR2` 型を返します。

* `trim_source` が `CLOB` 型の場合、この関数は `CLOB` 型を返します。

* `trim_source` または `trim_character` が `NULL` の場合、`TRIM` 関数は `NULL` を返します。

## 例

文字列 `XXOceanBaseXX` の先頭と末尾の `XX` を削除します。

```sql
obclient> SELECT TRIM('X' FROM 'XXOceanBaseXX') "TRIM" FROM DUAL;
+-----------+
| TRIM      |
+-----------+
| OceanBase |
+-----------+
1 row in set
```
