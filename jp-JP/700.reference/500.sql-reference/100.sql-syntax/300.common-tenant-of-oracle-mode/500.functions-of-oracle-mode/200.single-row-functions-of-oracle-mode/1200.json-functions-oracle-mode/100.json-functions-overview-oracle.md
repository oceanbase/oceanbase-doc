# JSON関数の概要

OceanBaseデータベースの現行バージョンでサポートされているJSON関数は、以下の表に示されています。

| **関数名** | **説明** |
| --- | --- |
| [JSON_ARRAY](../1200.json-functions-oracle-mode/200.create-json-text-function-oracle/100.json-array-oracle-mode.md) | JSON配列を作成します。 |
| [JSON_OBJECT](../1200.json-functions-oracle-mode/200.create-json-text-function-oracle/200.json-object-oracle-mode.md)| JSONオブジェクトを作成します。 |
| [JSON_ARRAYAGG](../1200.json-functions-oracle-mode/200.create-json-text-function-oracle/300.json-arrayagg-oracle-mode.md) | JSON配列の集計関数を作成します。 |
| [JSON_OBJECTAGG](../1200.json-functions-oracle-mode/200.create-json-text-function-oracle/400.json-objectagg-oracle-mode.md) | JSONオブジェクトの集計関数を作成します。 |
| [JSON_VALUE](../1200.json-functions-oracle-mode/300.query-json-text-function-oracle/100.json-value-oracle-mode.md) | 指定されたパスのJSONテキストから値を抽出します。通常はスカラーを返します。デフォルトの戻り値は`VARCHAR2(4000)`またはユーザーが指定した値です。 |
| [JSON_QUERY](../1200.json-functions-oracle-mode/300.query-json-text-function-oracle/200.json-query-oracle-mode.md) | 指定されたパスのJSONテキストから値を抽出します。配列またはオブジェクトを返すことができます。デフォルトの戻り値の型は入力データの型によって異なります。入力が`VARCHAR`の場合、デフォルトの出力は`VARCHAR`です。入力データの型がJSONの場合、デフォルトの戻り値の型はJSONです。 |
| [JSON_EXISTS](../1200.json-functions-oracle-mode/300.query-json-text-function-oracle/300.json-exists-oracle-mode.md) | JSONテキストが指定されたパスのフィールドに存在するか、または特定の条件を満たしているかどうかを確認します。 |
| [JSON_TABLE](../1200.json-functions-oracle-mode/300.query-json-text-function-oracle/400.json-table-oracle-mode.md) | JSONデータを2次元テーブルに変換します。 |
| [JSON_EQUAL](../1200.json-functions-oracle-mode/400.validate-json-text-function-oracle/100.json-equal-oracle-mode.md) | 2つのJSONテキストが内容上同一であるかどうかを確認します。 |
| [JSON_MERGEPATCH](../1200.json-functions-oracle-mode/500.modify-json-text-function-oracle/100.json-mergepatch-oracle-mode.md) | 2つのJSONテキストをマージし、重複するキーと値を置き換えます。 |
