# JSON_EQUAL

## 説明

`JSON_EQUAL()` 関数は、2つのJSON値を比較し、等しい場合はTrueを返します。値が等しくない場合はFalseを返します。入力値は有効なJSONデータである必要があります。比較ではスペースとオブジェクトメンバーの順序は無視されます。例えば、JSONオブジェクトが同じメンバーを持っている場合、それらの順序に関係なく等しいと見なされます。

また、`IS JSON` および `IS NOT JSON` はSQLステートメント内のSQL条件としても使用され、式の結果が有効なJSONデータ形式であるかどうかを検証します。詳細については、[JSONデータ型列の作成](../../../../300.basic-elements-of-oracle-mode/100.built-in-data-types-of-oracle-mode/1000.json-formatted-data-type-oracle-mode/200.create-json-data-type-columns-of-oracle-mode.md)を参照してください。

## 構文

```sql
json_equal(expr,
           expr
          [TRUE|FALSE|ERROR ON ERROR]);
```

## 構文の説明

`ERROR` 句のデフォルトは `FALSE ON ERROR` です。典型的なエラーは、入力された2つのJSONが有効なJSONデータではないことです。

## 例

```shell
# WHEN CASEでSQL条件としてJSON_EQUAL()関数を使用する
obclient> SELECT CASE
               WHEN JSON_EQUAL (
       '{"comparesAttributes":"and values"}', '{"inTwoJSONDocuments": "for equality"}'
               ) THEN 'THE SAME' ELSE 'DIFFERENT'
             END JSON_compare
      FROM   DUAL;
+--------------+
| JSON_COMPARE |
+--------------+
|  DIFFERENT   |
+--------------+
1 row in set

# 同じ入力
obclient> SELECT 1 FROM DUAL WHERE JSON_EQUAL('[1,]', '[1]' FALSE ON ERROR);
+---+
| 1 |
+---+
| 1 |
+---+
1 row in set

obclient> SELECT 1 FROM DUAL WHERE JSON_EQUAL('[1,]', '[1' TRUE ON ERROR);
+---+
| 1 |
+---+
| 1 |
+---+
1 row in set

# ERROR句でFALSE ON ERRORを使用する
obclient> SELECT 1 FROM DUAL WHERE JSON_EQUAL('[1,]', '[1' FALSE ON ERROR);
Empty set

# ERROR句でERROR ON ERRORを使用する
obclient> SELECT 1 FROM DUAL WHERE JSON_EQUAL('[1,]', '[1' error on error);
OBE-40441: JSON syntax error
```
