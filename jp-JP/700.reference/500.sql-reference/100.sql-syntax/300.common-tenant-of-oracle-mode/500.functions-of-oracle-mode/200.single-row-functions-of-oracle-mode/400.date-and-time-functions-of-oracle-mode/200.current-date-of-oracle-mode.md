# CURRENT_DATE

## 説明

この関数は、現在のセッションのタイムゾーンにおける現在の日付を返します。

## 構文

```sql
CURRENT_DATE
```

## 戻り値の型

`DATE` データ型を返します。

## 例

`CURRENT_DATE` 関数を使用して、現在のタイムゾーンの日付を返します。

```sql
obclient> SELECT CURRENT_DATE FROM DUAL;
+--------------+
| CURRENT_DATE |
+--------------+
| 17-NOV-21    |
+--------------+
1 row in set
```
