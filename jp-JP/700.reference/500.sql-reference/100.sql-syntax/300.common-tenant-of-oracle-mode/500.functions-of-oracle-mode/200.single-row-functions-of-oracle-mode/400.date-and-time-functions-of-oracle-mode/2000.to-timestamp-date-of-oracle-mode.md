# TO_TIMESTAMP

## 説明

この関数は、文字列を `TIMESTAMP` データ型に変換します。

## 構文

```sql
TO_TIMESTAMP (char，[fmt],['nlsparam'])
```

## パラメータの説明

|    パラメータ    |                                 説明                                 |
|----------|--------------------------------------------------------------------|
| char     | `CHAR`、`VARCHAR2`、`NCHAR`、または`NVARCHAR2`データ型に属する文字列。               |
| fmt      | `char`のフォーマットを指定します。オプションです。`fmt`が省略された場合、`char`は`TIMESTAMP`データ型のデフォルトフォーマットを使用する必要があります。 |
| nlsparam | `nlsparam`パラメータを指定することで、TO_TIMESTAMP関数内で日付、時間、数値のフォーマットおよび解析ルールをカスタマイズできます。OceanBaseデータベースが現在サポートしている`nlsparam`は`nls_date_language`で、返される月と日付に使用する言語を制御します。デフォルト値はAMERICAで、変更はサポートされていません。                                           |

## 戻り値のタイプ

`TIMESTAMP` データ型を返します。

## 例

文字列 `2021-11-11 11:11:11.11` を `TIMESTAMP` データ型に変換します。

```sql
obclient> SELECT TO_TIMESTAMP ('2021-11-11 11:11:11.11', 'YYYY-MM-DD HH24:MI:SS.FF')
    FROM DUAL;
+-----------------------------------------------------------------+
| TO_TIMESTAMP('2021-11-1111:11:11.11','YYYY-MM-DDHH24:MI:SS.FF') |
+-----------------------------------------------------------------+
| 11-NOV-21 11.11.11.110000000 AM                                 |
+-----------------------------------------------------------------+
1 row in set
```
