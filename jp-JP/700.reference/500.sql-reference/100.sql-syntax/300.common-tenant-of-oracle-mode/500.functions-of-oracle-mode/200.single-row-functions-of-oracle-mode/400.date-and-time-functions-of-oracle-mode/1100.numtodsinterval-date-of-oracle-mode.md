# NUMTODSINTERVAL

## 説明

この関数は、パラメータ `n` をパラメータ `interval_unit` 単位の `INTERVAL DAY TO SECOND` データ型の値に変換します。

## 構文

```sql
NUMTODSINTERVAL (n,interval_unit)
```

## パラメータの説明

|      パラメータ       |                              説明                              |
|---------------|--------------------------------------------------------------|
| n             | `NUMBER`データ型、または`NUMBER`データ型に変換できる式。                       |
| interval_unit | 単位値。値は`DAY`(日) `HOUR`(時間) `MINUTE`(分) `SECOND`(秒)となり、大文字と小文字は区別されません。 |

## 戻り値のタイプ

`INTERVAL DAY TO SECOND` データ型を返します。

## 例

現在の日付から `3` 日後の日付を返します。

```sql
obclient> SELECT SYSDATE,SYSDATE+NUMTODSINTERVAL(3,'DAY') AS "DAY" FROM DUAL;
+-----------+-----------+
| SYSDATE   | DAY       |
+-----------+-----------+
| 18-NOV-21 | 21-NOV-21 |
+-----------+-----------+
1 row in set
```
