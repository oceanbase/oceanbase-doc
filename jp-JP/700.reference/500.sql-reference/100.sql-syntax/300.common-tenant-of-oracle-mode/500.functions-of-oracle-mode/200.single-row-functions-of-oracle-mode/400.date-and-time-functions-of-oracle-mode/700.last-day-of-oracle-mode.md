# LAST_DAY

## 説明

この関数は、日付 `date` が含まれる月の最終日の日付を返します。

## 構文

```sql
LAST_DAY (date)
```

## パラメータの説明

| パラメータ |                                                説明                                                |
|------|--------------------------------------------------------------------------------------------------|
| date | 日付情報を含むすべてのデータ型（`DATE`、`TIMESTAMP`、`TIMESTAMP WITH TIME ZONE`、`TIMESTAMP WITH LOCAL TIME ZONE`）の値。 |

## 戻り値の型

`DATE` データ型を返します。

## 例

現在の日付と今月の最終日の日付、および今月の残りの日数を表示します。

```sql
obclient> SELECT SYSDATE,LAST_DAY(SYSDATE) "Last",LAST_DAY(SYSDATE)-SYSDATE FROM DUAL;
+-----------+-----------+---------------------------+
| SYSDATE   | Last      | LAST_DAY(SYSDATE)-SYSDATE |
+-----------+-----------+---------------------------+
| 17-NOV-21 | 30-NOV-21 |                        13 |
+-----------+-----------+---------------------------+
1 row in set
```
