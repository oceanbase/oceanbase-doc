# DBTIMEZONE

## 説明

この関数は、現在のデータベースインスタンスのタイムゾーンを返します。OceanBaseデータベースのタイムゾーンは常に+00:00であり、変更することはできません。

## 構文

```sql
DBTIMEZONE
```

## 戻り値型

`VARCHAR2`データ型を返します。

## 例

現在のデータベースインスタンスのタイムゾーンを返します。

```sql
obclient> SELECT DBTIMEZONE FROM DUAL;
+------------+
| DBTIMEZONE |
+------------+
| +00:00     |
+------------+
1 row in set
```
