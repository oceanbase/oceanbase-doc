# SYSTIMESTAMP

## 説明

この関数は、システムの現在日時を返します。戻り値の秒の小数部には `6` 桁の精度が含まれ、現在のタイムゾーン情報も含まれます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>この関数は現在セッションのタイムゾーンに依存せず、現在のデータベースサーバーが存在するOSのタイムゾーンに依存します。</p>
  </main>

## 構文

```sql
SYSTIMESTAMP
```

## 戻り値の型

`TIMESTAMP WITH TIME ZONE` データ型を返します。

## 例

システムの現在日付と現在のタイムゾーン情報を返します。

```sql
obclient> SELECT SYSTIMESTAMP FROM DUAL;
+-------------------------------------+
| SYSTIMESTAMP                        |
+-------------------------------------+
| 18-NOV-21 10.32.27.176575 AM +08:00 |
+-------------------------------------+
1 row in set
```
