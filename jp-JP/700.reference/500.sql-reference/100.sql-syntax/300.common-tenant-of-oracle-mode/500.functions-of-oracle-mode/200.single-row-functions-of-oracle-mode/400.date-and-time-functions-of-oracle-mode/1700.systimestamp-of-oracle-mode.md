# SYSTIMESTAMP

## 説明

この関数は、システムの現在日時を返します。戻り値の秒の小数部は `6` 桁の精度を持ち、現在のタイムゾーン情報が含まれます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>この関数は現在のセッションのタイムゾーンに依存せず、現在のデータベースサーバーが稼働するオペレーティングシステムのタイムゾーンに依存します。</p>
  </main>

## 構文

```sql
SYSTIMESTAMP
```

## 戻り値の型

`TIMESTAMP WITH TIME ZONE` データ型を返します。

## 例

システムの現在日付を返し、現在のタイムゾーン情報を含みます。

```sql
obclient> SELECT SYSTIMESTAMP FROM DUAL;
+-------------------------------------+
| SYSTIMESTAMP                        |
+-------------------------------------+
| 18-NOV-21 10.32.27.176575 AM +08:00 |
+-------------------------------------+
1 row in set
```
