# LOCALTIMESTAMP

## 説明

この関数は、現在のセッションのタイムゾーンにおける現在の日付を返し、`TIMESTAMP` データ型の値を返します。

関数 `CURRENT_TIMESTAMP` との違いは、`CURRENT_TIMESTAMP` 関数が `TIMESTAMP WITH TIME ZONE` データ型の値を返す点です。

## 構文

```sql
LOCALTIMESTAMP [(timestamp_precision)]
```

## パラメータの説明

`timestamp_precision` は秒の小数部の精度を表し、整数値を取ります。範囲は \[0,9\] で、オプションです。デフォルト値は `6` です。

## 戻り値の型

`TIMESTAMP` データ型を返します。

## 例

* 現在のタイムゾーンをGMT-5に設定し、`LOCALTIMESTAMP` 関数を使用して現在の日付を返します。

  ```javascript
  obclient> ALTER SESSION SET TIME_ZONE = '-05:00';
  Query OK, 0 rows affected

  obclient> SELECT LOCALTIMESTAMP FROM DUAL;
  +------------------------------+
  | LOCALTIMESTAMP               |
  +------------------------------+
  | 17-NOV-21 04.36.28.557316 AM |
  +------------------------------+
  1 row in set
  ```

* 現在のタイムゾーンをGMT+8に設定し、秒の小数部の精度を `3` に調整します。`LOCALTIMESTAMP` 関数を使用して現在の日付を返します。

  ```javascript
  obclient> ALTER SESSION SET TIME_ZONE = '+08:00';
  Query OK, 0 rows affected

  obclient> SELECT LOCALTIMESTAMP(3) FROM DUAL;
  +---------------------------+
  | LOCALTIMESTAMP(3)         |
  +---------------------------+
  | 17-NOV-21 05.38.12.839 PM |
  +---------------------------+
  1 row in set
  ```
