# LOCALTIMESTAMP

## 説明

この関数は、現在のセッションのタイムゾーンに基づく現在日付を返し、`TIMESTAMP` データ型の値を返します。

`CURRENT_TIMESTAMP` 関数との違いは、`CURRENT_TIMESTAMP` 関数が `TIMESTAMP WITH TIME ZONE` データ型の値を返す点です。

## 構文

```sql
LOCALTIMESTAMP [(timestamp_precision)]
```

## パラメータの説明

`timestamp_precision` は、秒の小数点以下の精度を表します。整数値で、範囲は \[0,9\] です。オプションです。デフォルト値は `6` です。

## 戻り値の型

`TIMESTAMP` データ型を返します。

## 例

* 現在のタイムゾーンをGMT-5に設定し、`LOCALTIMESTAMP` 関数を使用して現在日付を返します。

  ```javascript
  obclient> ALTER SESSION SET TIME_ZONE = '-05:00';
  Query OK, 0 rows affected

  obclient> SELECT LOCALTIMESTAMP FROM DUAL;
  +------------------------------+
  | LOCALTIMESTAMP               |
  +------------------------------+
  | 17-NOV-21 04.36.28.557316 AM |
  +------------------------------+
  1 row in set
  ```

* 現在のタイムゾーンをGMT+8に設定し、秒の小数点以下の精度を `3` に調整します。`LOCALTIMESTAMP` 関数を使用して現在日付を返します。

  ```javascript
  obclient> ALTER SESSION SET TIME_ZONE = '+08:00';
  Query OK, 0 rows affected

  obclient> SELECT LOCALTIMESTAMP(3) FROM DUAL;
  +---------------------------+
  | LOCALTIMESTAMP(3)         |
  +---------------------------+
  | 17-NOV-21 05.38.12.839 PM |
  +---------------------------+
  1 row in set
  ```
