# TZ_OFFSET

## 説明

この関数は、現在のセッションのタイムゾーン `SESSIONTIMEZONE` またはデータベースのタイムゾーン `DBTIMEZONE` のタイムゾーンオフセットを返します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>タイムゾーンオフセットとは、グリニッジ標準時(GMT)との差(計算単位は時間と分)を指します。</p>
  </main>

## 構文

```sql
TZ_OFFSET({ SESSIONTIMEZONE | DBTIMEZONE})
```

## パラメータの説明

|       パラメータ        |   説明    |
|-----------------|---------|
| SESSIONTIMEZONE | 現在のセッションのタイムゾーン。 |
| DBTIMEZONE      | データベースのタイムゾーン。  |

## 戻り値の型

`VARCHAR2` データ型を返します。

## 例

現在のセッションのタイムゾーン `SESSIONTIMEZONE` とデータベースのタイムゾーン `DBTIMEZONE` のタイムゾーンオフセットを返します。

```sql
obclient> SELECT TZ_OFFSET(SESSIONTIMEZONE),TZ_OFFSET(DBTIMEZONE) FROM DUAL;
+----------------------------+-----------------------+
| TZ_OFFSET(SESSIONTIMEZONE) | TZ_OFFSET(DBTIMEZONE) |
+----------------------------+-----------------------+
| +08:00                     | +00:00                |
+----------------------------+-----------------------+
1 row in set
```
