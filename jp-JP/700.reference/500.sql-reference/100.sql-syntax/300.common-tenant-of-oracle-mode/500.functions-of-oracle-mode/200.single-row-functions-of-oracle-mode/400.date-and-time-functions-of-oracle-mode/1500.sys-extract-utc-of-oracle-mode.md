# SYS_EXTRACT_UTC

## 説明

この関数は、タイムゾーンオフセットを持つ日付時刻値から、指定された時間に対応する標準UTC時間を返します。タイムゾーンが指定されていない場合、指定された日付時刻は現在のセッションのタイムゾーンに関連付けられます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>UTC（Universal Time Coordinated）とは、世界協定時のことです。UTCはグリニッジ標準時（GMT, Greenwich Mean Time）と同様に、イギリスのロンドンの現地時間と同じです。</p>
  </main>

## 構文

```sql
SYS_EXTRACT_UTC (datetime_with_timezone)
```

## パラメータの説明

`datetime_with_timezone` は `TIMESTAMP WITH TIME ZONE` または `TIMESTAMP WITH LOCAL TIME ZONE` データ型の値です。

## 戻り値の型

`TIMESTAMP` データ型を返します。

## 例

`2021-11-18 10:08:08.18 +08:00` の標準UTC時間を返します。

```sql
obclient> SELECT SYS_EXTRACT_UTC(TIMESTAMP '2021-11-18 10:08:08.18 +08:00') "SYS_EXTRACT_UTC" FROM DUAL;
+---------------------------------+
| SYS_EXTRACT_UTC                 |
+---------------------------------+
| 18-NOV-21 02.08.08.180000000 AM |
+---------------------------------+
1 row in set
```
