# SYSDATE

## 説明

この関数は、現在のデータベースサーバーが存在するOSの日付を返します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>この関数は現在のセッションのタイムゾーンに依存せず、現在のデータベースサーバーが存在するOSのタイムゾーンに依存します。</p>
  </main>

## 構文

```sql
SYSDATE
```

## 戻り値型

`DATE`データ型を返します。

## 例

次の例では、現在の時間を指定された形式で出力します。

```sql
obclient> SELECT SYSDATE,TO_CHAR (SYSDATE, 'MM-DD-YYYY HH24:MI:SS') "NOW" FROM DUAL;
+-----------+---------------------+
| SYSDATE   | NOW                 |
+-----------+---------------------+
| 18-NOV-21 | 11-18-2021 10:23:00 |
+-----------+---------------------+
1 row in set
```
