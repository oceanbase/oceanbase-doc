# SYSDATE

## 説明

この関数は、現在のデータベースサーバーが稼働しているオペレーティングシステムの日付を返します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>この関数は、現在のセッションのタイムゾーンに依存せず、現在のデータベースサーバーが稼働しているオペレーティングシステムのタイムゾーンに依存します。</p>
  </main>

## 構文

```sql
SYSDATE
```

## 戻り値の型

`DATE` データ型を返します。

## 例

以下の例では、現在時刻を指定された形式で出力します。

```sql
obclient> SELECT SYSDATE,TO_CHAR (SYSDATE, 'MM-DD-YYYY HH24:MI:SS') "NOW" FROM DUAL;
+-----------+---------------------+
| SYSDATE   | NOW                 |
+-----------+---------------------+
| 18-NOV-21 | 11-18-2021 10:23:00 |
+-----------+---------------------+
1 row in set
```
