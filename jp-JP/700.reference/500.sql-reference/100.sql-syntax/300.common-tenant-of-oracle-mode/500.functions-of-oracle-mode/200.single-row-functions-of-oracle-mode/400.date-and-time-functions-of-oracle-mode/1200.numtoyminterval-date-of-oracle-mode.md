# NUMTOYMINTERVAL

## 説明

この関数は、パラメータ `n` を `interval_unit` 単位の `INTERVAL YEAR TO MONTH` データ型の値に変換します。

## 構文

```sql
NUMTOYMINTERVAL (n,interval_unit)
```

## パラメータの説明

|      パラメータ       |                   説明                   |
|---------------|----------------------------------------|
| n             | `NUMBER`データ型、または`NUMBER`データ型に変換できる式。 |
| interval_unit | 単位値。値は`YEAR`(年)または`MONTH`(月)であり、大文字と小文字は区別されません。  |

## 戻り値のタイプ

`INTERVAL YEAR TO MONTH` データ型を返します。

## 例

現在の日付から3年後の日付時刻値を返します。

```sql
obclient> SELECT SYSDATE,SYSDATE+NUMTOYMINTERVAL(3,'YEAR') AS RES FROM DUAL;
+-----------+-----------+
| SYSDATE   | RES       |
+-----------+-----------+
| 18-NOV-21 | 18-NOV-24 |
+-----------+-----------+
1 row in set
```
