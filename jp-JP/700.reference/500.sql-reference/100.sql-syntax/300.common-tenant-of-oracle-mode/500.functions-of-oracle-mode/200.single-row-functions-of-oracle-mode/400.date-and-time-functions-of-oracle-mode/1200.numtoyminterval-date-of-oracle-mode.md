# NUMTOYMINTERVAL

## 説明

この関数は、パラメータ `n` を `interval_unit` 単位の `INTERVAL YEAR TO MONTH` 型の値に変換します。

## 構文

```sql
NUMTOYMINTERVAL (n,interval_unit)
```

## パラメータの説明

|      パラメータ       |                   説明                   |
|---------------|----------------------------------------|
| n             | `NUMBER` 型データ型、または `NUMBER` 型データ型に変換可能な式。 |
| interval_unit | 単位値。`YEAR`(年)または`MONTH`(月)を指定できます。大文字と小文字は区別されません。  |

## 戻り値の型

`INTERVAL YEAR TO MONTH` 型を返します。

## 例

現在の日付から3年後の日時値を返します。

```sql
obclient> SELECT SYSDATE,SYSDATE+NUMTOYMINTERVAL(3,'YEAR') AS RES FROM DUAL;
+-----------+-----------+
| SYSDATE   | RES       |
+-----------+-----------+
| 18-NOV-21 | 18-NOV-24 |
+-----------+-----------+
1 row in set
```
