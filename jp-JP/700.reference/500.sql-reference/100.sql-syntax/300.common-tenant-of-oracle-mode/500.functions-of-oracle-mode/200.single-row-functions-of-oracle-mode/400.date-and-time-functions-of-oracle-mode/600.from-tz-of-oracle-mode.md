# FROM_TZ

## 説明

この関数は、`TIMESTAMP` データ型の値とタイムゾーン情報を組み合わせて、`TIMESTAMP WITH TIME ZONE` データ型の時刻値を作成します。

## 構文

```sql
FROM_TZ (timestamp_value,time_zone_value)
```

## パラメータの説明

|     **パラメータ**      |        **説明**        |
|-----------------|----------------------|
| timestamp_value | `TIMESTAMP` データ型の時刻値。 |
| time_zone_value | タイムゾーン情報。                |

## 戻り値の型

`TIMESTAMP WITH TIME ZONE` データ型を返します。

## 例

タイムスタンプ値 `2021-03-28 08:00:00` とタイムゾーン `+08:00` を組み合わせて `TIMESTAMP WITH TIME ZONE` 型のデータに変換し、返します。

```sql
obclient> SELECT FROM_TZ(TIMESTAMP '2021-03-28 08:00:00', '+08:00') FROM DUAL;
+-------------------------------------------------+
| FROM_TZ(TIMESTAMP'2021-03-2808:00:00','+08:00') |
+-------------------------------------------------+
| 28-MAR-21 08.00.00.000000000 AM +08:00          |
+-------------------------------------------------+
1 row in set
```
