# ADD_MONTHS

## 説明

この関数は、日付 `date` に `n` ヶ月を加えた日付値を返します。
  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>各月の日数が異なるため、<code>date</code> が月の最終日の場合、関数は計算後の月の最終日を返します。例えば、<code>ADD_MONTHS</code> を使用して2020年3月31日から1か月前の日付を計算すると、2020年2月29日が返されます。</p>
  </main>

## 構文

```sql
ADD_MONTHS(date, n)
```

## パラメータの説明

| パラメータ |                                                                                                                説明                                                                                                                 |
|------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| date | 日付を指定します。このパラメータは`DATE`データ型です。                                                                                                                                                                                                            |
| n    | 整数、または整数に変換できる任意の値。`NUMBER`データ型。<ul><li> `n`の値が負の場合、日付`date`から`n`か月前の日付を返します。   </li><li> `n`の値が正の場合、日付`date`から`n`か月後の日付を返します。</li></ul>    |

## 戻り値のタイプ

`DATE` データ型を返します。

## 例

現在の日付から3か月前と3か月後の日付を返します。

```sql
obclient> SELECT ADD_MONTHS(SYSDATE,-3),SYSDATE, ADD_MONTHS(SYSDATE,3) FROM DUAL;
+------------------------+-----------+-----------------------+
| ADD_MONTHS(SYSDATE,-3) | SYSDATE   | ADD_MONTHS(SYSDATE,3) |
+------------------------+-----------+-----------------------+
| 17-AUG-21              | 17-NOV-21 | 17-FEB-22             |
+------------------------+-----------+-----------------------+
1 row in set
```
