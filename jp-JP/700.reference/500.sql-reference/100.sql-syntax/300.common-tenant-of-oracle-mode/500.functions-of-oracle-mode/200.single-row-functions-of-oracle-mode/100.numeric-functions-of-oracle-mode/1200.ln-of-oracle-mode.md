# LN

## 説明

この関数は、`e` を底とする `numeric_expression` の対数を返します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>e</code> は数学定数で、2.71828183... に等しいです。</p>
  </main>

## 構文

```sql
LN (numeric_expression)
```

## パラメータの説明

`numeric_expression` は、`0` より大きい数値データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）であるか、数値データ型へ暗黙的に変換できるパラメータです。

## 戻り値の型

パラメータが `BINARY_FLOAT` データ型の場合、戻り値の型は `BINARY_DOUBLE` です。その他の場合、戻り値の型はパラメータ `numeric_expression` のデータ型と同じです。

## 例

`9` の自然対数を返します。

```sql
obclient> SELECT LN(9) FROM DUAL;
+------------------------------------------+
| LN(9)                                    |
+------------------------------------------+
| 2.19722457733621938279049047384505140929 |
+------------------------------------------+
1 row in set
```
