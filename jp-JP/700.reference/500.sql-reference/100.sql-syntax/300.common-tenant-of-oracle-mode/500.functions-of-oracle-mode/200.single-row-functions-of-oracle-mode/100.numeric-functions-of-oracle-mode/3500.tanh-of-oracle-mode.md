# TANH

## 説明

この関数は双曲正切関数であり、数値パラメータの双曲正切値を返します。戻り値の範囲は (-1,1) です。

## 構文

```sql
TANH(number)
```

## パラメータの説明

`number` は数値データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

パラメータ `number` が `BINARY_FLOAT` 型の場合、戻り値の型は `BINARY_DOUBLE` です。それ以外の場合、パラメータ `number` と同じ数値データ型を返します。

## 例

`1` の双曲正切値を返します。

```sql
obclient> SELECT TANH(1) FROM DUAL;
+-------------------------------------------+
| TANH(1)                                   |
+-------------------------------------------+
| .7615941559557648881194582826047935904128 |
+-------------------------------------------+
1 row in set
```
