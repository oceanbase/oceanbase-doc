# TAN

## 説明

この関数はタンジェント関数であり、角度のタンジェント値を返します。

## 構文

```sql
TAN(x)
```

## パラメータの説明

`x` は、任意の実数（ラジアン単位の角度）を取る数値データ型、または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

パラメータ `x` のデータ型が `BINARY_FLOAT` の場合、この関数は `BINARY_DOUBLE` データ型を返します。それ以外の場合、この関数はパラメータ `x` と同じ数値データ型を返します。

## 例

`0` 度と `135` 度のタンジェント値を計算します。

```sql
obclient> SELECT TAN(0),TAN(135*3.1415926/180) FROM DUAL;
+--------+-------------------------------------------+
| TAN(0) | TAN(135*3.1415926/180)                    |
+--------+-------------------------------------------+
|      0 | -1.00000008038469308854331997429109563738 |
+--------+-------------------------------------------+
1 row in set
```
