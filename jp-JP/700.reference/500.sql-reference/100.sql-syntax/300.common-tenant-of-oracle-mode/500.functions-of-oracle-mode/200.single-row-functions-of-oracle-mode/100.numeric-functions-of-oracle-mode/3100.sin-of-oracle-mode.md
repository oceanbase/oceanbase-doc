# SIN

## 説明

この関数はサイン関数であり、引数となる角度のサイン値を返します。戻り値の範囲は \[-1,1\] です。

## 構文

```sql
SIN(x)
```

## パラメータの説明

`x` は、任意の実数（ラジアン単位の角度）を取る数値データ型、または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

パラメータ `x` のデータ型が `BINARY_FLOAT` の場合、この関数は `BINARY_DOUBLE` データ型を返します。それ以外の場合、この関数はパラメータ `x` と同じ数値データ型を返します。

## 例

`0` 度と `30` 度の角度のサイン値を返します。

```sql
obclient> SELECT SIN(0),SIN(30*3.14159265/180) FROM DUAL;
+--------+-------------------------------------------+
| SIN(0) | SIN(30*3.14159265/180)                    |
+--------+-------------------------------------------+
|      0 | .4999999994818579767701332168843926496529 |
+--------+-------------------------------------------+
1 row in set
```
