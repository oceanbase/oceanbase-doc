# TRUNC

## 説明

この関数は、パラメータ `numeric` を精度 `precision` で切り捨てた値を返します。

## 構文

```sql
TRUNC (numeric[,precision])
```

## パラメータの説明

|    パラメータ     |                                                                                                                                                                                                                                                  説明                                                                                                                                                                                                                                                  |
|-----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| numeric   | 截断される数値を表し、数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式に属します。                                                                                                                                                                                                                                                                                                                                                                                                                               |
| precision | 精度を表し、オプションです。デフォルト値は `0` です。数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式に属します。 <ul><li> `precision` が整数でない場合、`precision` の整数部分に基づいて `numeric` を精度で切り捨てます。 </li> <li> `precision` が `0` より大きい場合、`numeric` を `precision` 桁小数まで切り捨てます。 </li> <li> `precision` が `0` より小さい場合、`numeric` の小数点から左へ `precision` 桁目まで切り捨てます。 </li> <li> `precision` が `0` と等しい場合、`numeric` の整数部分を切り捨て、小数部分は切り捨てます。 </li></ul>   |

## 戻り値の型

`precision` を指定しない場合、返り値の型はパラメータ `numeric` のデータ型と同じになります。`precision` を指定した場合、返り値の型は `NUMBER` になります。

## 例

`precision` の値が `2.2`、`-2` の場合、または `precision` を省略した場合、数値 555.666 は切り捨てられます。

```sql
obclient> SELECT TRUNC(555.666,2.2),TRUNC(555.666,-2),TRUNC(555.666) FROM DUAL;
+--------------------+-------------------+----------------+
| TRUNC(555.666,2.2) | TRUNC(555.666,-2) | TRUNC(555.666) |
+--------------------+-------------------+----------------+
|             555.66 |               500 |            555 |
+--------------------+-------------------+----------------+
1 row in set
```
