# TRUNC

## 説明

この関数は、パラメータ `numeric` を精度 `precision` で切り捨てた値を返します。

## 構文

```sql
TRUNC (numeric[,precision])
```

## パラメータの説明

|    パラメータ     |                                                                                                                                                                                                                                                  説明                                                                                                                                                                                                                                                  |
|-----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| numeric   | 切り捨てる数値で、数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式です。                                                                                                                                                                                                                                                                                                                                                                                                                               |
| precision | 精度を表し、オプションです。デフォルト値は `0` です。数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式です。 <ul><li> `precision` が整数でない場合、`precision` の整数部に基づいて `numeric` を精度切り捨てします。 </li> <li> `precision` が `0` より大きい場合、`numeric` を小数点以下 `precision` 桁まで切り捨てます。 </li> <li>`precision` が `0` より小さい場合、`numeric` の小数点から左側の `precision` 桁目まで切り捨てます。 </li> <li>`precision` が `0` の場合、`numeric` の整数部を返し、小数部は切り捨てます。 </li></ul>   |

## 戻り値の型

`precision` を指定しない場合、戻り値の型はパラメータ `numeric` のデータ型と同じです。`precision` を指定した場合、戻り値の型は `NUMBER` です。

## 例

`precision` の値を `2.2`、`-2` に設定し、`precision` を省略した場合における、数値 555.666 の切り捨て処理を示します。

```sql
obclient> SELECT TRUNC(555.666,2.2),TRUNC(555.666,-2),TRUNC(555.666) FROM DUAL;
+--------------------+-------------------+----------------+
| TRUNC(555.666,2.2) | TRUNC(555.666,-2) | TRUNC(555.666) |
+--------------------+-------------------+----------------+
|             555.66 |               500 |            555 |
+--------------------+-------------------+----------------+
1 row in set
```
