# POWER

## 説明

この関数は、指定された数値のべき乗を返します。

## 構文

```sql
POWER (x, y)
```

## パラメータの説明

| パラメータ |                                            説明                                             |
|----|-------------------------------------------------------------------------------------------|
| x  | 基数を表し、数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式に属します。                        |
| y  | 指数を表し、数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式に属します。`x` が負の数の場合、`y` は整数でなければなりません。 |

## 戻り値の型

パラメータが `BINARY_FLOAT` および `BINARY_DOUBLE` データ型の場合、戻り値の型は `BINARY_DOUBLE` です。それ以外の場合、戻り値の型は `NUMBER` です。

## 例

`3` の2乗、`-3` の3乗、`4` の `-2` 乗を返します。

```sql
obclient> SELECT POWER(3,2),POWER(-3,3),POWER(4,-2) FROM DUAL;
+------------+-------------+-------------+
| POWER(3,2) | POWER(-3,3) | POWER(4,-2) |
+------------+-------------+-------------+
|          9 |         -27 |       .0625 |
+------------+-------------+-------------+
1 row in set
```
