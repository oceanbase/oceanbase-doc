# POWER

## 説明

この関数は、指定された数のべき乗を返します。

## 構文

```sql
POWER (x, y)
```

## パラメータの説明

| パラメータ |                                            説明                                             |
|----|-------------------------------------------------------------------------------------------|
| x  | 基底となる数値を表します。数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式に使用されます。                        |
| y  | 指数を表します。数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式に使用されます。`x`が負の数の場合、`y`は整数である必要があります。 |

## 戻り値の型

パラメータが `BINARY_FLOAT` または `BINARY_DOUBLE` 型の場合、戻り値の型は `BINARY_DOUBLE` です。それ以外の場合、戻り値の型は `NUMBER` です。

## 例

`3` の二乗、`-3` の三乗、`4` の `-2` 乗を返します。

```sql
obclient> SELECT POWER(3,2),POWER(-3,3),POWER(4,-2) FROM DUAL;
+------------+-------------+-------------+
| POWER(3,2) | POWER(-3,3) | POWER(4,-2) |
+------------+-------------+-------------+
|          9 |         -27 |       .0625 |
+------------+-------------+-------------+
1 row in set
```
