# BITAND

## 説明

この関数は、引数をビット単位でAND演算します。

## 構文

```sql
BITAND (expr1,expr2)
```

## パラメータの説明

|  パラメータ   |                 説明                 |
|-------|------------------------------------|
| expr1 | ビット単位でAND演算を行う最初の値を指定します。`NUMBER` 型の式です。 |
| expr2 | ビット単位でAND演算を行う2番目の値を指定します。`NUMBER` 型の式です。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>expr1</code> と <code>expr2</code> のいずれか一方が <code>NULL</code> の場合、戻り値は <code>NULL</code> になります。</li>
    <li>パラメータが整数でない場合、演算前に整数に変換されます。</li>
    </ul>
  </main>

## 戻り値の型

`NUMBER` データ型または `NULL` を返します。

## 例

仮に `a=2`、`b=3` とします。`a` の2進数は `0100`、`b` の2進数は `0110` です。これらの2進数をビットごとに比較し、対応する位置がどちらも `1` の場合、そのビットの値は `1` となり、そうでない場合は `0` となります。

```sql
obclient> SELECT BITAND(2,3) FROM DUAL;
+-------------+
| BITAND(2,3) |
+-------------+
|           2 |
+-------------+
1 row in set
```
