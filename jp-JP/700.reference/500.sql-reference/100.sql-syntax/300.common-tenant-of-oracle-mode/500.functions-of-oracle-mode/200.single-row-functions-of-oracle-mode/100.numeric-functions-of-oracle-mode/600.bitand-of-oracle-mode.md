# BITAND

## 説明

この関数は、入力パラメータに対して2進数のビット単位でAND演算を実行します。

## 構文

```sql
BITAND (expr1,expr2)
```

## パラメータの説明

| パラメータ | 説明 |
|-------|------------------------------------|
| expr1 | ビット単位のAND演算を行う最初の値を指定します。これは`NUMBER`型の式です。 |
| expr2 | ビット単位のAND演算を行う2番目の値を指定します。これは`NUMBER`型の式です。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><code>expr1</code> または <code>expr2</code> のいずれかが <code>NULL</code> の場合、結果は <code>NULL</code> を返します。</li>
    <li>パラメータが整数でない場合、演算を実行する前に整数に変換されます。</li>
    </ul>
  </main>

## 戻り値のタイプ

`NUMBER` データ型または `NULL` を返します。

## 例

`a=2`、`b=3` とします。`a` の2進数表現は `0100`、`b` の2進数表現は `0110` です。これらの2進数をビットごとに比較し、対応する位置がすべて `1` の場合、そのビットの値は `1` となり、そうでない場合は `0` となります。

```sql
obclient> SELECT BITAND(2,3) FROM DUAL;
+-------------+
| BITAND(2,3) |
+-------------+
|           2 |
+-------------+
1 row in set
```
