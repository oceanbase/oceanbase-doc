# ATAN

## 説明

この関数は、アルカタン値を求めるために使用されます。アルカタン値とは、タンジェント値が`number`である角度を指し、返される角度はラジアン単位で表され、その範囲は (-π/2，π/2) です。

## 構文

```sql
ATAN(number)
```

## パラメータの説明

`number` は、数値データ型、または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

`NUMBER` データ型を返します。

## 例

`0.5` のアルカタン値を返します。

```sql
obclient> SELECT ATAN(0.5) FROM DUAL;
+-------------------------------------------+
| ATAN(0.5)                                 |
+-------------------------------------------+
| .4636476090008061162142562314612144020285 |
+-------------------------------------------+
1 row in set
```
