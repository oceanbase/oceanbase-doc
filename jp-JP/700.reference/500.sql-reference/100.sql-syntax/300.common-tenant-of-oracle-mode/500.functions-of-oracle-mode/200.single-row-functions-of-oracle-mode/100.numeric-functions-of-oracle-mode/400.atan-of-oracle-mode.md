# ATAN

## 説明

この関数は、反正切値を求めるために使用されます。反正切値とは、タンジェント値が`number`の角度を指し、返される角度はラジアンで表され、ラジアン値の範囲は(-π/2, π/2)です。

## 構文

```sql
ATAN(number)
```

## パラメータの説明

`number`は数値データ型、または暗黙的に数値データ型に変換できるパラメータです。

## 戻り値の型

`NUMBER`データ型を返します。

## 例

`0.5`の反正切値を返します。

```sql
obclient> SELECT ATAN(0.5) FROM DUAL;
+-------------------------------------------+
| ATAN(0.5)                                 |
+-------------------------------------------+
| .4636476090008061162142562314612144020285 |
+-------------------------------------------+
1 row in set
```
