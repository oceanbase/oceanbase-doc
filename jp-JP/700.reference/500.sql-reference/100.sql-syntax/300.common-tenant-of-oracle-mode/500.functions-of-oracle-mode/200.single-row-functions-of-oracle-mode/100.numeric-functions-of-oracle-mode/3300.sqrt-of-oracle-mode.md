# SQRT

## 説明

この関数は、パラメータ `numeric_expression` の平方根を返します。

## 構文

```sql
SQRT(numeric_expression)
```

## パラメータの説明

`numeric_expression` は、数値データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）であるか、暗黙的に数値データ型へ変換可能でゼロ以上の値です。

## 戻り値の型

パラメータ `numeric_expression` と同じデータ型を返します。

## 例

`64` と `50+50` の平方根を計算します。

```sql
obclient> SELECT SQRT(64),SQRT(50+50) FROM DUAL;
+----------+-------------+
| SQRT(64) | SQRT(50+50) |
+----------+-------------+
|        8 |          10 |
+----------+-------------+
1 row in set
```
