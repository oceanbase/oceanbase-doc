# LOG

## 説明

この関数は、底が `x` である `y` の対数を返します。

## 構文

```sql
LOG (x,y)
```

## パラメータの説明

| パラメータ |                                                    説明                                                    |
|----|--------------------------------------------------------------------------------------------------------|
| x  | 対数の底を表す数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）式。 `x` は `0` より大きく、かつ `1` と等しくない値である必要があります。 |
| y  | 真数を表す数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）式。 `y` は `0` より大きい値である必要があります。            |

## 戻り値の型

パラメータが `BINARY_FLOAT` および `BINARY_DOUBLE` データ型の場合、戻り値の型は `BINARY_DOUBLE` です。それ以外の場合、戻り値の型は `NUMBER` です。

## 例

底が `2` である `8` の対数を返します。

```sql
obclient> SELECT LOG(2,8) FROM DUAL;
+----------+
| LOG(2,8) |
+----------+
|        3 |
+----------+
1 row in set
```
