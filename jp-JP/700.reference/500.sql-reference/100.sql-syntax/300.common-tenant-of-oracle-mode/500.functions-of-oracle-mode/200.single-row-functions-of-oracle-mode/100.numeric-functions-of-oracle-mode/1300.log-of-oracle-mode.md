# LOG

## 説明

この関数は、`x` を底とする `y` の対数を返します。

## 構文

```sql
LOG (x,y)
```

## パラメータの説明

| パラメータ |                                                   説明                                                   |
|----|--------------------------------------------------------------------------------------------------------|
| x  | 対数の底を表す数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式です。 `x` は `0` より大きく、`1` と等しくない必要があります。 |
| y  | 真数を表す数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式です。 `y` は `0` より大きい必要があります。            |

## 戻り値の型

パラメータが `BINARY_FLOAT` または `BINARY_DOUBLE` 型の場合、戻り値の型は `BINARY_DOUBLE` となります。それ以外の場合、戻り値の型は `NUMBER` となります。

## 例

`2` を底とする `8` の対数を返します。

```sql
obclient> SELECT LOG(2,8) FROM DUAL;
+----------+
| LOG(2,8) |
+----------+
|        3 |
+----------+
1 row in set
```
