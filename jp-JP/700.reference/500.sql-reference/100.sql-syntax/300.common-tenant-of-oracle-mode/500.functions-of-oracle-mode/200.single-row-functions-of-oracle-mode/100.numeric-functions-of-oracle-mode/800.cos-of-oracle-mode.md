# COS

## 説明

この関数はコサイン関数であり、引数となる角度のコサイン値を計算します。戻り値の範囲は \[-1,1\] です。

## 構文

```sql
COS(x)
```

## パラメータの説明

`x` は、任意の実数（ラジアン単位の角度）を取る数値データ型、または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

引数 `x` のデータ型が `BINARY_FLOAT` の場合、この関数は `BINARY_DOUBLE` データ型を返します。それ以外の場合、この関数は引数 `x` と同じ数値データ型を返します。

## 例

`0` 度の角度のコサイン値を返します。

```sql
obclient> SELECT COS(0) FROM DUAL;
+--------+
| COS(0) |
+--------+
|      1 |
+--------+
1 row in set
```
