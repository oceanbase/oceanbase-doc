# CEIL

## 説明

この関数は、`numeric_expression` 以上の最小の整数を返します。

## 構文

```sql
CEIL (numeric_expression)
```

## パラメータの説明

|         パラメータ         |                                  説明                                   |
|--------------------|-----------------------------------------------------------------------|
| numeric_expression | 厳密数または近似数データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式。 |

## 戻り値のタイプ

戻り値のタイプは、パラメータ `numeric_expression` のデータ型と同じです。

## 例

`-1.5`、`1.5`、`2`、および `6-9.5` 以上の最小の整数を返します。

```sql
obclient> SELECT CEIL(-1.5),CEIL(1.5),CEIL(2),CEIL(6-9.5) FROM DUAL;
+------------+-----------+---------+-------------+
| CEIL(-1.5) | CEIL(1.5) | CEIL(2) | CEIL(6-9.5) |
+------------+-----------+---------+-------------+
|         -1 |         2 |       2 |          -3 |
+------------+-----------+---------+-------------+
1 row in set
```
