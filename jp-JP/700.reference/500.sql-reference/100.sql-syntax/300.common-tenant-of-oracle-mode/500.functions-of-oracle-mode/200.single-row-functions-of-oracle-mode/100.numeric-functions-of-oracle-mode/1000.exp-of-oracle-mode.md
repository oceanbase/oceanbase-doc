# EXP

## 説明

この関数は、自然定数 `e` を底とする指数関数であり、`e` の `numeric_expression` 回目の値を返します。ここで、`e` = 2.71828183... です。

## 構文

```sql
EXP (numeric_expression)
```

## パラメータの説明

`numeric_expression` は数値データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）または暗黙的に数値データ型に変換可能なパラメータです。

## 戻り値のタイプ

パラメータが `BINARY_FLOAT` データ型の場合、戻り値のタイプは `BINARY_DOUBLE` です。それ以外の場合、戻り値のタイプはパラメータ `numeric_expression` のデータ型と同じです。

## 例

`e` の `4` 回目の値と `e` の `3+2.5` 回目の値を返します。

```sql
obclient> SELECT EXP(4),EXP(3+2.5) FROM DUAL;
+-------------------------------------------+------------------------------------------+
| EXP(4)                                    | EXP(3+2.5)                               |
+-------------------------------------------+------------------------------------------+
| 54.59815003314423907811026120286087840279 | 244.691932264220387915188949511839350184 |
+-------------------------------------------+------------------------------------------+
1 row in set
```
