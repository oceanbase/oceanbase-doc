# ROUND

## 説明

この関数は、引数 `numeric` の四捨五入後の値を返します。

## 構文

```sql
ROUND (numeric[,decimal])
```

## パラメータの説明

|   パラメータ    |                                                                                                                                                                           説明                                                                                                                                                                            |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| numeric | 数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）の式。                                                                                                                                                                                                                                                                                            |
| decimal | <ul><li> `decimal` が `0` 以上の場合、`numeric` を小数点以下 `decimal` 桁に四捨五入します。   </li><li> `decimal` が `0` より小さい場合、小数点から左へ `decimal` 桁目まで四捨五入します。   </li><li> `decimal` が整数でない場合、`decimal` の整数部分を切り捨てます。   </li><li> `decimal` を指定しない場合、`numeric` を整数部に四捨五入します。</li></ul>    |

## 戻り値の型

* `decimal` を指定しない場合、戻り値の型は引数 `numeric` の型と同じです。

* `decimal` を指定した場合、戻り値の型は `NUMBER` データ型になります。

## 例

`decimal` の値が `1`、`-1`、`2.1` の場合、または `decimal` を省略した場合、四捨五入の結果として `666.666` を返します。

```sql
obclient> SELECT ROUND(666.666,1),ROUND(666.666,-1),ROUND(666.666,2.1),ROUND(666.666) FROM DUAL;
+------------------+-------------------+--------------------+----------------+
| ROUND(666.666,1) | ROUND(666.666,-1) | ROUND(666.666,2.1) | ROUND(666.666) |
+------------------+-------------------+--------------------+----------------+
|            666.7 |               670 |             666.67 |            667 |
+------------------+-------------------+--------------------+----------------+
1 row in set
```
