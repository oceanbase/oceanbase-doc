# SINH

## 説明

この関数は双曲正弦関数であり、数値パラメータの双曲正弦値を返します。戻り値の範囲は (-∞,+∞) です。

## 構文

```sql
SINH(number)
```

## パラメータの説明

`number` は数値データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）または暗黙的に数値データ型に変換できるパラメータです。

## 戻り値の型

パラメータ `number` が `BINARY_FLOAT` タイプの場合、戻り値の型は `BINARY_DOUBLE` です。それ以外の場合、パラメータ `number` と同じ数値データ型を返します。

## 例

`0` の双曲正弦値を返します。

```sql
obclient> SELECT SINH(0) FROM DUAL;
+---------+
| SINH(0) |
+---------+
|       0 |
+---------+
1 row in set
```
