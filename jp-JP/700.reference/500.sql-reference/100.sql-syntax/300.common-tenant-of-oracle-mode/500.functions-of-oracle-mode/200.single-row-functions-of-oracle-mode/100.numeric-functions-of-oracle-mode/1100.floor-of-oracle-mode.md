# FLOOR

## 説明

この関数は、数値 `numeric_expression` 以下の最大の整数を返します。

## 構文

```sql
FLOOR (numeric_expression)
```

## パラメータの説明

`numeric_expression` は、数値データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

戻り値の型は、パラメータ `numeric_expression` のデータ型と同じです。

## 例

それぞれ `-1.5`、`1.5`、`2`、`6-9.5` 以下の最大の整数を返します。

```sql
obclient> SELECT FLOOR(-1.5),FLOOR(1.5),FLOOR(2),FLOOR(6-9.5) FROM DUAL;
+-------------+------------+----------+--------------+
| FLOOR(-1.5) | FLOOR(1.5) | FLOOR(2) | FLOOR(6-9.5) |
+-------------+------------+----------+--------------+
|          -2 |          1 |        2 |           -4 |
+-------------+------------+----------+--------------+
1 row in set
```
