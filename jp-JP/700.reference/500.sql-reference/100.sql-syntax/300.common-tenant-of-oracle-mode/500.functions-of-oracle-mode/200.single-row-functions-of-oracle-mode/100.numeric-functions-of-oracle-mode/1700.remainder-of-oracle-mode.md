# REMAINDER

## 説明

この関数は、`x` を `y` で割ったときの余りを返します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>REMAINDER (x,y)</code> と <code>MOD (x,y)</code> の両関数は、計算時に <code>result=x-y*(x/y)</code> という同じ公式を使用しますが、<code>x/y</code> の計算方法が異なります。<code>REMAINDER (x,y)</code> 関数では <code>ROUND(x/y)</code> を使用し、<code>MOD (x,y)</code> 関数では <code>FLOOR(x/y)</code> を使用します。</p>
    <p><code>REMAINDER</code> 関数では、<code>ROUND(x/y)</code> の引数 <code>x/y</code> の小数部分がちょうど <code>0.5</code> の場合、<code>x/y</code> の整数部分が偶数の場合は切り捨て、奇数の場合は切り上げます。例えば、<code>ROUND(1.5)=2</code>、<code>ROUND(2.5)=2</code>、<code>ROUND(3.5)=4</code>、<code>ROUND(4.5)=4</code> となります。</p>
  </main>

## 構文

```sql
REMAINDER (x, y)
```

## パラメータの説明

| **パラメータ** |                                                 **説明**                                                  |
|--------|---------------------------------------------------------------------------------------------------------|
| x      | 被除数であり、数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式です。                                        |
| y      | 除数であり、数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式です。 <br>**注意**  パラメータ `y` は `0` にすることはできません。 |

## 戻り値の型

戻り値の型は、数値優先順位が高いパラメータのデータ型と同じです。

## 例

`MOD` および `REMAINDER` 関数を使用して、`1.5` を `1` で割ったときの余りを返します。

```sql
obclient> SELECT MOD(1.5,1),REMAINDER(1.5,1) FROM DUAL;
+------------+------------------+
| MOD(1.5,1) | REMAINDER(1.5,1) |
+------------+------------------+
|         .5 |              -.5 |
+------------+------------------+
1 row in set
```
