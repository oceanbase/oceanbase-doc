# ASIN

## 説明

この関数は、アークサインの値を求めるものです。アークサインとは、正弦値が `number` になる角度を指し、返される角度はラジアン単位で表されます。ラジアンの範囲は \[-π/2，π/2\] です。

## 構文

```sql
ASIN(number)
```

## パラメータの説明

`number` は、\[-1,1\] の範囲を取る数値データ型、または暗黙的に数値データ型へ変換可能なパラメータです。

## 戻り値の型

`NUMBER` データ型を返します。

## 例

`0.5` のアークサイン値を返します。

```sql
obclient> SELECT ASIN(0.5) FROM DUAL;
+-------------------------------------------+
| ASIN(0.5)                                 |
+-------------------------------------------+
| .5235987755982988730771072305465838140329 |
+-------------------------------------------+
1 row in set
```
