# ASIN

## 説明

この関数は、反正弦値を求める機能を持っています。反正弦値とは、正弦値が`number`の角度を指し、返される角度はラジアンで表され、ラジアンの範囲は\[-π/2，π/2\]です。

## 構文

```sql
ASIN(number)
```

## パラメータの説明

`number`は、\[-1,1\]の範囲の数値データ型、または暗黙的に数値データ型に変換可能なパラメータです。

## 戻り値のタイプ

`NUMBER`データ型を返します。

## 例

`0.5`の反正弦値を返します。

```sql
obclient> SELECT ASIN(0.5) FROM DUAL;
+-------------------------------------------+
| ASIN(0.5)                                 |
+-------------------------------------------+
| .5235987755982988730771072305465838140329 |
+-------------------------------------------+
1 row in set
```
