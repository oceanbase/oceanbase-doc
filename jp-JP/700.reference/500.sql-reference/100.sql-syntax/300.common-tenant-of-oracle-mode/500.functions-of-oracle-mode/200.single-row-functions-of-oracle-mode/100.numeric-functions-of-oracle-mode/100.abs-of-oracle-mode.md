# ABS

## 説明

この関数は、`numeric_expression` の絶対値を返します。`ABS` は負の値を正の値に変更しますが、ゼロや正の値には影響しません。

## 構文

```sql
ABS(numeric_expression)
```

## パラメータの説明

|         パラメータ         |                                  説明                                   |
|--------------------|-----------------------------------------------------------------------|
| numeric_expression | 厳密数または近似数データ型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、および `BINARY_DOUBLE`）の式。 |

## 戻り値のタイプ

`numeric_expression` と同じデータ型を返します。

## 例

`-1.0`、`0.0`、`6.66`、および `(3-6)` の絶対値を返します。

```sql
obclient> SELECT ABS(-1.0), ABS(0), ABS(6.66), ABS(3-6) FROM DUAL;
+-----------+--------+-----------+----------+
| ABS(-1.0) | ABS(0) | ABS(6.66) | ABS(3-6) |
+-----------+--------+-----------+----------+
|         1 |      0 |      6.66 |        3 |
+-----------+--------+-----------+----------+
1 row in set
```
