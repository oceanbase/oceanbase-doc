# ACOS

## 説明

この関数はアークコサイン関数であり、\[-1,1\] の範囲内の値をラジアン単位で返します。

## 構文

```sql
ACOS(num_expression)
```

## パラメータの説明

|       パラメータ       |                          説明                          |
|----------------|------------------------------------------------------|
| num_expression | `NUMBER` 型または `NUMBER` 型へ暗黙的に型変換できる式。値は \[-1,1\] の範囲内です。 |

## 戻り値のタイプ

`NUMBER` データ型を返します。

## 例

`0.3` を返す `ACOS` の値。

```sql
obclient> SELECT ACOS(0.3) "acos_test" FROM DUAL;
+------------------------------------------+
| acos_test                                |
+------------------------------------------+
| 1.26610367277949911125931873041222227514 |
+------------------------------------------+
1 row in set
```
