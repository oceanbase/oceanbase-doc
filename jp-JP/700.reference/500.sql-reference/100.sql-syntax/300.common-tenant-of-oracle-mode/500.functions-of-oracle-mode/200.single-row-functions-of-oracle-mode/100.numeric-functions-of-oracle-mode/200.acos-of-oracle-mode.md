# ACOS

## 説明

この関数は反コサイン関数であり、弧度単位の値を \[0,π\] の範囲で返します。

## 構文

```sql
ACOS(num_expression)
```

## パラメータの説明

|       パラメータ       |                          説明                          |
|----------------|------------------------------------------------------|
| num_expression | `NUMBER` 型、または `NUMBER` 型へ暗黙的に変換可能な式。値は \[-1,1\] の範囲です。 |

## 戻り値の型

`NUMBER` データ型を返します。

## 例

`0.3` の `ACOS` の値を返します。

```sql
obclient> SELECT ACOS(0.3) "acos_test" FROM DUAL;
+------------------------------------------+
| acos_test                                |
+------------------------------------------+
| 1.26610367277949911125931873041222227514 |
+------------------------------------------+
1 row in set
```
