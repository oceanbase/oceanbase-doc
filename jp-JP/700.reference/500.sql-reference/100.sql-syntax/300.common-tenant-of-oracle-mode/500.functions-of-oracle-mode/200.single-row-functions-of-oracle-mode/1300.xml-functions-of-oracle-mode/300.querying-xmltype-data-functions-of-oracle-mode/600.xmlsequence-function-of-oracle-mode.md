# XMLSEQUENCE

## 説明

この関数は、XMLドキュメントの内容をXML要素を含むVARRAYに変換します。XMLドキュメント内の各要素を行として返し、XML要素の集合を形成します。

## 構文

```sql
XMLSEQUENCE( XMLType_instance)
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>XMLSEQUENCE</code> 関数は <code>SELECT</code> 句での使用をサポートしていません。</p>
</main>

## パラメータの説明

| **項目** | **説明** |
| -------- | -------- |
| XMLType_instance | このパラメータはXML型のインスタンスで、関数の入力として使用されます。|

## 戻り値の型

XMLTypeコレクションを返します。

## 例

`XMLSEQUENCE` 関数と `EXTRACT` 関数を使用して、対象XMLから指定されたノードを抽出します。対象のXMLフラグメントは `<Videogame>` ノードとその子ノードです。XPath式は `/Videogame/*` で、`<Videogame>` ノードの下のすべての子ノードを抽出することを指示します。`XMLSEQUENCE` 関数は抽出されたノードをテーブルの一部として返し、`TABLE` 関数を使用してクエリ可能なテーブルに変換します。クエリの結果では、`ROWNUM` を行番号として使用し、抽出されたノードの値を `column_value` 列の値として返します。

```shell
SELECT rownum, column_value
FROM TABLE(
    XMLSEQUENCE(
        extract(
            XMLtype('<Videogame>
                <Type>Racing</Type>
                <Name>NFS Most Wanted</Name>
                <Version>2.0</Version>
                <Size>5.5 GB</Size>
            </Videogame>'),
            '/Videogame/*'
        )
    )
);
```

実行結果は次のとおりです：

```shell
+--------+-------------------------------+
| ROWNUM | COLUMN_VALUE                  |
+--------+-------------------------------+
|      1 | <Type>Racing</Type>           |
|      2 | <Name>NFS Most Wanted</Name>  |
|      3 | <Version>2.0</Version>        |
|      4 | <Size>5.5 GB</Size>           |
+--------+-------------------------------+
4 rows in set
```
