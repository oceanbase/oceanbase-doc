# XMLTABLE

## 説明

この関数は、XPathで返された結果をリレーショナルテーブルの行と列にマッピングするために使用されます。SQLクエリ関数が返す結果を仮想リレーショナルテーブルとして使用できます。

`XMLTABLE`機能の主な特徴は以下のとおりです：

* データ抽出機能：`XMLTABLE`で適切なXPath式を指定することで、複雑なXMLドキュメントから必要なデータ部分を正確に抽出できます。

* データの構造化：`XMLTABLE`は、XMLデータの特定部分をリレーショナルテーブルの行と列にマッピングし、半構造化されたXMLデータを構造化されたテーブル形式に変換します。これにより、SQLクエリや分析が容易になります。

* テーブル変換：`XMLTABLE`によって生成された構造化データを使用して仮想テーブルを作成でき、これらのテーブルデータを使用して新しいテーブルやビューを生成し、データベース内に保存したり、さらに処理したりできます。

## 構文

```sql
XMLTABLE( [ XMLnamespaces_clause , ] XQuery_string XMLTABLE_options )

XMLnamespaces_clause：
 XMLNAMESPACES( { string AS identifier } | { DEFAULT string } [, { string AS identifier } | { DEFAULT string } ]...)

XMLTABLE_options：
  [ XML_passing_clause ]
  [ COLUMNS XML_table_column [, XML_table_column]...]

XML_passing_clause：
  PASSING [ BY VALUE ] expr [ AS identifier ]

XML_table_column：
  column { FOR ORDINALITY
          | { datatype | XMLTYPE } [ PATH string ] [ DEFAULT expr ]
  }
```

## パラメータの説明

| **フィールド** | **説明** |
| -------- | -------- |
| XMLnamespaces_clause | XMLクエリ内でネームスペースを持つ要素や属性を参照するために、ネームスペースのプレフィックスとURIを定義します。この句には一連のXMLネームスペース宣言が含まれており、これらの宣言は`XML_table_column`の`PATH`句内のXPath式によって参照されます。この式は、XMLTable関数全体の列を計算します。`COLUMNS`句の`PATH`式で限定名を使用したい場合は、この句を指定する必要があります。|
| XQuery_string | XMLデータから変換する必要があるデータを選択するために使用されるXQuery式を指定します。XQueryは、XMLドキュメントからデータを抽出し、複雑なクエリ操作を実現するために使用されるXMLクエリ言語です。このパラメータを使用すると、XQuery構文を使用して、XMLデータから抽出する要素または属性を定義する指示を作成できます。<main id="notice" type='notice'><h4>注意</h4><p>OceanBaseデータベースの現行バージョンでは、XQueryはサポートされていません。</p></main>|
| XML_passing_clause | PASSINGキーワードを使用して、XQueryに渡すXMLデータを指定します。値渡しとデータ渡しのエイリアスを指定できます。具体的には以下のとおりです：<ul><li>PASSING: XML_passing_clauseの開始を示します。PASSING句の内容はXMLTABLEの入力です。</li><li>BY VALUE: オプションのキーワードで、渡されるデータが参照渡しではなく値渡しであることを示します。ほとんどの場合、このオプションは省略できます。値渡しはデフォルトの動作だからです。</li><li>expr: XMLTypeまたはSQLスカラー型データ型のインスタンスを返す式であり、その結果はXQueryに渡されるXMLデータです。この式は通常、XML型データを返す列名、変数、またはより複雑な式です。`PASSING`句は現在、現行バージョンでは`expr`を1つのみ指定できます。</li><li>AS identifier: オプションで、exprパラメータの結果にエイリアス（つまり識別子）を指定します。XQuery式内で、このエイリアスを使用して渡されたデータを参照できます。|
| COLUMNS | オプションのCOLUMNS句は、XMLTableによって作成される仮想テーブルの列を定義します。COLUMNS句を省略した場合、XMLTableはCOLUMN_VALUEという名前の単一のXMLType偽列を含む行を返します。|
| XML_table_column | 生成するテーブル列を定義します。通常のデータ型列またはXMLTYPE列にすることができます。また、列値のXPathパスとデフォルト値を指定することもできます。FOR ORDINALITYは行番号を生成するために使用されます。具体的には以下のとおりです： <ul><li>FOR ORDINALITY：この列が生成される行番号列になることを指定します。FOR ORDINALITY句は最大1つしかありません。これはNUMBER型の列として作成されます。</li><li> datatypeまたはXMLTYPE：FOR ORDINALITY列に加えて、各結果列について列のデータ型を指定する必要があります。XMLTypeまたは他の任意のデータ型にすることができます。列のデータ型がXMLTypeの場合は、XMLTYPE句を指定する必要があります。XMLTypeデータを参照して返すことで、ソースデータ内で列のPATH式が位置するノードよりも外側にある他の列のパスを指定できます。列のデータ型が他の任意のデータ型の場合は、データ型を指定する必要があります。<ul><li>PATH string：オプション。XQuery式文字列によって処理されるXQuery結果の部分を列の内容として使用します。PATHを省略した場合、XQuery式列と仮定されます。例：<code>XMLTable(... COLUMNS xyz)</code>。</li><li>DEFAULT expr：オプション。PATH式の結果が空シーケンスの場合に使用する値を指定します。そのexprは、デフォルト値を生成するためのXQuery式です。</li></ul></li></ul>

## 戻り値のタイプ

返されるデータ型は、XMLTable関数で指定された列のデータ型によって決まります。

## 例

`XMLTABLE`関数を使用して、従業員のID、氏名、職位、給与を含むSQLテーブルにXMLデータを変換します。具体的には以下のとおりです：

1. デフォルトネームスペースを`http://www.example.com/employees`と定義して、XMLデータ内のネームスペースとマッチングします。
2. XQuery式を`'/employees/employee'`と定義して、すべての従業員(`employee`)要素を選択します。
3. `PASSING`句を使用して、XQuery式に渡すXMLドキュメントを指定します。この例では、XMLドキュメント全体がXMLTYPEコンストラクタでカプセル化されています。XMLTYPEは、文字列形式のXMLデータをデータベースが処理できるXMLタイプに変換します。
4. `COLUMNS`句では、XMLから抽出されたデータをマッピングするために4つの列を定義しています。対応関係は以下のとおりです：

   * `employee_id`列は、各`employee`要素の`emp_id`にマッピングされます。
   * `employee_name`列は、各`employee`要素の`name`にマッピングされます。
   * `position`列は、各`employee`要素の`position`にマッピングされます。
   * `salary`列は、各`employee`要素の`salary`にマッピングされます。

   各列の後のPATH句は、対応する値をどこから抽出するかを定義しています。

```shell
SELECT *
FROM XMLTABLE(
       XMLNAMESPACES(DEFAULT 'http://www.example.com/employees'),
       '/employees/employee'
       PASSING XMLTYPE('
          <employees xmlns="http://www.example.com/employees">
               <employee>
                    <emp_id>1</emp_id>
                    <name>John Doe</name>
                    <position>Developer</position>
                    <salary>5000</salary>
               </employee>
               <employee>
                    <emp_id>2</emp_id>
                    <name>Jane Smith</name>
                    <position>Manager</position>
                    <salary>6500</salary>
               </employee>
          </employees>'
     )
     COLUMNS
          employee_id    INT           PATH 'emp_id',
          employee_name  VARCHAR2(100) PATH 'name',
          position       VARCHAR2(50)  PATH 'position',
          salary         NUMBER        PATH 'salary'
) AS emp_tab;
```

実行結果は次のとおりです：

```shell
+-------------+---------------+-----------+--------+
| EMPLOYEE_ID | EMPLOYEE_NAME | POSITION  | SALARY |
+-------------+---------------+-----------+--------+
|           1 | John Doe      | Developer |   5000 |
|           2 | Jane Smith    | Manager   |   6500 |
+-------------+---------------+-----------+--------+
2 rows in set
```
