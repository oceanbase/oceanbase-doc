# XMLELEMENT

## 説明

この関数は、指定された名前、属性、および内容を持つXML要素を生成します。

## 構文

```sql
XMLELEMENT ( [ ENTITYESCAPING | NOENTITYESCAPING ]
   { ( [ NAME ] identifier ) | ( EVALNAME value_expr ) }
   [ , XML_attributes_clause ]
   [ , value_expr [ [ AS ] c_alias ]]...
 )
```

## パラメータの説明

| フィールド | 説明 |
| --- | --- |
| ENTITYESCAPING &#124; NOENTITYESCAPING | オプション。要素の名前と内容に強制的にエスケープが必要かどうかを指定するキーワードです。式のデフォルト動作である `ENTITYESCAPING` を直接使用することを推奨します。 |
| NAME | ルート要素名を文字識別子として指定するキーワードです。`NAME` は、後続の値が識別子であることを意味し、オプションです。 |
| EVALNAME | ルート要素名が文字列として評価される結果であることを指定するキーワードです。`EVALNAME` は、後続の値を計算して結果を取得する必要があることを意味します。 |
| identifier | 文字列タイプのラベル名を指定します。 |
| value_expr | 要素値の式です。このパラメータは他の要素またはテキストにすることができます。他の要素の場合、XMLType列、または `XMLELEMENT`、`XMLAGG` など、XMLTypeを生成する式にすることができます。 |
| XML_attributes_clause | オプション。要素の属性を指定する式を指定します。詳細については [XMLATTRIBUTES](200.xmlattributes-function-of-oracle-mode.md) を参照してください。 |
| c_alias | 内容のエイリアスとなる文字列タイプを指定します。 |

## 戻り値のタイプ

XMLTypeデータ型を返します。

## 例

以下の例では、要素名が`Emp`、要素内容が`value`のXML要素を構築します。

```shell
obclient> SELECT XMLELEMENT(NAME "Emp", 'value') FROM DUAL;
+-------------------------------+
| XMLELEMENT(NAME"EMP",'VALUE') |
+-------------------------------+
| <Emp>value</Emp>
             |
+-------------------------------+
1 row in set
```
