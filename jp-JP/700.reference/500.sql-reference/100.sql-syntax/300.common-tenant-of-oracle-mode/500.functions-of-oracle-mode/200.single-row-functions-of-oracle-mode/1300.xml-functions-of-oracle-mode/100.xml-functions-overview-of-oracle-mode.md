# XML関数の概要

OceanBaseデータベースの現在のバージョンでサポートされているXML関数は、次の表のとおりです。

| **関数名** | **説明** |
| --- | --- |
| [XMLAGG](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/100.xmlagg-function-of-oracle-mode.md) | 一連のXMLフラグメントを取得し、集約されたXMLドキュメントを返します。 |
| [XMLATTRIBUTES](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/200.xmlattributes-function-of-oracle-mode.md) | XML要素内の属性セットを指定します。 |
| [XMLELEMENT](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/300.xmlelement-function-of-oracle-mode.md) | 指定された名前、属性、内容を持つXML要素を生成します。 |
| [XMLPARSE](../1300.xml-functions-of-oracle-mode/200.construct-xmltype-data-functions-of-oracle-mode/400.xmlparse-function-of-oracle-mode.md)  | 入力された文字列を解析し、XMLTypeデータ型を生成します。 |
| [EXTRACT](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/100.extract-function-of-oracle-mode.md) | Xpathに基づいてXMLフラグメントを抽出し、その結果はXpathがマッチしたすべてのノードの連結です。 |
| [EXTRACTVALUE](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/200.extract-value-function-of-oracle-mode.md) | Xpathに基づいてXMLフラグメントを抽出し、スカラー値を返します。 |
| [XMLSERIALIZE](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/300.xmlserialize-function-of-oracle-mode.md) | XMLTypeデータを`VARCHAR2`または`CLOB`型にシリアライズします。 |
| [XMLCAST](../1300.xml-functions-of-oracle-mode/300.querying-xmltype-data-functions-of-oracle-mode/400.xmlcast-function-of-oracle-mode.md) | XMLドキュメントの内容（要素名を除く）を抽出し、他のデータ型に変換します。 |
| [XMLTABLE](300.querying-xmltype-data-functions-of-oracle-mode/500.xmltable-function-of-oracle-mode.md) | Xpathが返す結果をリレーショナルテーブルの行と列にマッピングするために使用されます。|
| [XMLSEQUENCE](300.querying-xmltype-data-functions-of-oracle-mode/600.xmlsequence-function-of-oracle-mode.md) | XMLドキュメントの内容を、XML要素を含むVARRAYに変換するために使用されます。|
| [UPDATEXML](../1300.xml-functions-of-oracle-mode/400.modify-xmltype-data-functions-of-oracle-mode/100.updatexml-function-of-oracle-mode.md) | XMLTypeデータの式を変更・更新するために使用されます。 |
| [INSERTCHILDXML](400.modify-xmltype-data-functions-of-oracle-mode/200.insertchildxml-function-of-oracle-mode.md) | 指定されたXMLフラグメントをターゲットXMLに挿入するために使用されます。|
| [DELETEXML](400.modify-xmltype-data-functions-of-oracle-mode/300.deletexml-function-of-oracle-mode.md) | XPath式がXML内でマッチする1つまたは複数のノードを削除するために使用されます。|

OceanBaseデータベースの現在のバージョンで現在サポートされていないXML関数は、次の表のとおりです。

| **関数名**   | **説明**                                       |
|------------|--------------------------------------------|
| `XMLEXIST` | 指定されたXPathパスがXMLデータに存在するかどうかを確認します。  |
| `XMLISVALID` | XMLドキュメントがそのXML Schema定義に準拠しているかどうかを検証します。   |
| `XMLQUERY` | XQuery式を実行してXMLデータをクエリします。           |
