# XMLATTRIBUTES

## 説明

`XMLATTRIBUTES`は`XMLELEMENT`のサブ式であり、XML要素内の属性セットを指定するために使用されます。

## 構文

```sql
XMLATTRIBUTES
  ( [ ENTITYESCAPING | NOENTITYESCAPING ]
    [ SCHEMACHECK | NOSCHEMACHECK ]
    value_expr [ { AS c_alias } | { AS EVALNAME value_expr } ]
      [, value_expr [ { AS c_alias } | { AS EVALNAME value_expr } ] ]...
  )
```

## パラメータの説明

| パラメータ | 説明 |
| --- | --- |
| ENTITYESCAPING&#124;NOENTITYESCAPING | オプションです。エスケープ処理が必要かどうかを指定します。指定しない場合、デフォルトでエスケープ処理が実行されます(`ENTITYESCAPING`)。 |
| SCHEMACHECK&#124;NOSCHEMACHECK | オプションです。ランタイムチェックを実行するかどうかを指定します。指定しない場合、デフォルトで実行されません(`NOSCHEMACHECK`)。現在、ランタイムチェックの実行はサポートされていません。 |
| value_expr | 評価結果が文字列リテラルとなる式を指定し、その結果を属性値として使用します。 |
| c_alias | 生成する属性名を文字列で指定します。 |
| EVALNAME | このキーワードの後に、評価結果が文字列リテラルとなる式を指定します。 |

## 戻り値の型

`XMLATTRIBUTES`は`XMLELEMENT`句として使用されるものであり、単独で使用することはできません。戻り値の型はありません。

## 例

```shell
# テーブルt1を作成し、データを1件挿入します。
obclient> CREATE TABLE t1(col1 varchar(10));
Query OK, 0 rows affected

obclient> INSERT INTO t1 VALUES('a');
Query OK, 1 row affected

# col1の内容を持つkeyという名前の属性を生成します。
obclient> SELECT XMLELEMENT(emp, XMLATTRIBUTES(col1 as "key")) FROM t1;
+--------------------------------------------+
| XMLELEMENT(EMP,XMLATTRIBUTES(COL1AS"KEY")) |
+--------------------------------------------+
| <EMP key="a"/>
                            |
+--------------------------------------------+
1 row in set
```
