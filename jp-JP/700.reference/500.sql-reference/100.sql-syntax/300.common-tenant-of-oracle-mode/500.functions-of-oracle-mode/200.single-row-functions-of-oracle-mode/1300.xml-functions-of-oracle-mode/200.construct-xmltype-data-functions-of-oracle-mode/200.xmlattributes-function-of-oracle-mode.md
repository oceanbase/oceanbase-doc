# XMLATTRIBUTES

## 説明

`XMLATTRIBUTES` は `XMLELEMENT` のサブ式であり、XML要素内の属性セットを指定するために使用されます。

## 構文

```sql
XMLATTRIBUTES
  ( [ ENTITYESCAPING | NOENTITYESCAPING ]
    [ SCHEMACHECK | NOSCHEMACHECK ]
    value_expr [ { AS c_alias } | { AS EVALNAME value_expr } ]
      [, value_expr [ { AS c_alias } | { AS EVALNAME value_expr } ] ]...
  )
```

## パラメータの説明

| フィールド | 説明 |
| --- | --- |
| ENTITYESCAPING&#124;NOENTITYESCAPING | オプション。強制的なエスケープが必要かどうかを指定します。指定されていない場合は、デフォルトで強制的なエスケープが行われます（`ENTITYESCAPING`）。 |
| SCHEMACHECK&#124;NOSCHEMACCHECK | オプション。実行時のチェックを実行するかどうかを指定します。指定されていない場合は、デフォルトで実行されません（`NOSCHEMACCHECK`）。現在、実行時のチェックはサポートされていません。 |
| value_expr | 計算結果が文字列として生成されるプロパティ値を指定します。 |
| c_alias | 生成されるプロパティ名を文字列タイプで指定します。 |
| EVALNAME | このキーワードが続くと、計算結果が文字列となる式を表すことを指定します。 |

## 戻り値タイプ

`XMLATTRIBUTES` は `XMLELEMENT` 句として使用されるため、単独では使用できず、戻り値タイプもありません。

## 例

```shell
# テーブルt1を作成し、データを1件挿入します。
obclient> CREATE TABLE t1(col1 varchar(10));
Query OK, 0 rows affected

obclient> INSERT INTO t1 VALUES('a');
Query OK, 1 row affected

# col1を属性として、keyという名前の属性を生成します。
obclient> SELECT XMLELEMENT(emp, XMLATTRIBUTES(col1 as "key")) FROM t1;
+--------------------------------------------+
| XMLELEMENT(EMP,XMLATTRIBUTES(COL1AS"KEY")) |
+--------------------------------------------+
| <EMP key="a"/>
                            |
+--------------------------------------------+
1 row in set
```
