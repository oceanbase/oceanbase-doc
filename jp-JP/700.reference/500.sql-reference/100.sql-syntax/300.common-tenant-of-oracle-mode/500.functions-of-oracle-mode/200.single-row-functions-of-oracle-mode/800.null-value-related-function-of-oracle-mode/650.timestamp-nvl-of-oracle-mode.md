# TIMESTAMP_NVL

## 説明

この関数は、タイムスタンプ式が `NULL` かどうかを判断します。最初の式が `NULL` でない場合は、最初の式を返します。そうでない場合は、2番目の式を返します。

## 構文

```sql
TIMESTAMP_NVL(expr1, expr2)
```

## パラメータの説明

| パラメータ | 説明 |
|------|------|
| expr1 | 最初のタイムスタンプ式を指定します。 |
| expr2 | `expr1` が `NULL` の場合に返すタイムスタンプ式を指定します。 |

## 戻り値の型

タイムスタンプデータ型を返します。両方の式がともに `NULL` の場合は、`NULL` を返します。

## 例

最初の式が `NULL` の場合、2番目のタイムスタンプ式を返します。

```sql
obclient> SELECT TIMESTAMP_NVL(
            CAST(NULL AS TIMESTAMP),
            TIMESTAMP '2026-10-09 10:00:00'
          ) AS result
          FROM DUAL;
+------------------------------+
| RESULT                       |
+------------------------------+
| 09-OCT-26 10.00.00.000000 AM |
+------------------------------+
1 row in set
```
