# NVL

## 説明

この関数は、2つの式から非NULL値を返します。`expr1` と `expr2` の両方の結果がNULL値の場合、`NVL` 関数は `NULL` を返します。

## 構文

```sql
NVL(expr1, expr2)
```

## パラメータの説明

| パラメータ |                説明                 |
|-------|-----------------------------------|
| expr1 | 最初のパラメータを指定します。データ型は、データベースの組み込みデータ型のいずれかにすることができます。 |
| expr2 | 2番目のパラメータを指定します。データ型は、データベースの組み込みデータ型のいずれかにすることができます。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>expr1</code> と <code>expr2</code> は同じ型であるか、暗黙的に同じ型に変換できなければなりません。暗黙的に変換できない場合、データベースはエラーを返します。暗黙的変換のルールは以下のとおりです：</p>
    <ul>
    <li><code>expr1</code> が <code>CHAR</code>、<code>NCHAR</code>、<code>NVARCHAR</code>、<code>VARCHAR2</code> または <code>VARCHAR</code> 文字データ型の場合、データベースは <code>expr1</code> を比較する前に <code>expr2</code> を <code>expr1</code> のデータ型に変換し、<code>expr1</code> 文字セットの <code>VARCHAR2</code> を返します。</li>
    <li><code>expr1</code> が <code>NUMBER</code>、<code>FLOAT</code>、<code>BINARY_FLOAT</code> または <code>BINARY_DOUBLE</code> 数値データ型の場合、データベースはどちらのパラメータが最も高い数値優先順位を持つかを判断し、もう一方のパラメータをそのデータ型に暗黙的に変換して返します。</li>
    </ul>
  </main>

## 戻り値の型

* `expr1` と `expr2` が `NULL` の場合、`NULL` を返します。

* `expr1` が文字データ型 `CHAR`、`NCHAR`、`NVARCHAR`、`VARCHAR2` または `VARCHAR` に属する場合、`expr1` 文字セットの `VARCHAR2` を返します。

* `expr1` が数値データ型 `NUMBER`、`FLOAT`、`BINARY_FLOAT` または `BINARY_DOUBLE` に属する場合、`expr1` の中で最も優先順位の高いデータ型を返します。

## 例

テーブル `tbl1` を作成し、5件のデータを挿入します。そして、列 `col2` のNULL値を `100` で置き換えます。

```sql
obclient> CREATE TABLE tbl1 (col1 INT,col2 INT);
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES (1,30),(2,null),(3,50),(4,80),(5,10);
Query OK, 5 rows affected
Records: 5  Duplicates: 0  Warnings: 0

obclient> SELECT col1,NVL(col2,100) FROM tbl1;
+------+---------------+
| COL1 | NVL(COL2,100) |
+------+---------------+
|    1 |            30 |
|    2 |           100 |
|    3 |            50 |
|    4 |            80 |
|    5 |            10 |
+------+---------------+
5 rows in set
```
