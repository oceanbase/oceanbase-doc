# LENGTHB

## 説明

この関数は、文字列のバイト長を返します。

## 構文

```sql
LENGTHB(char)
```

## パラメータ説明

`char` は、バイト長を計算する文字列を指定します。

## 戻り値の型

`NUMBER` データ型を返します。

## 例

文字列 `中OceanBase` には、3バイトの漢字と9つの1バイト文字が含まれているため、バイト長は12です。

```sql
obclient> SELECT LENGTHB('中OceanBase') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|     12 |
+--------+
1 row in set
```
