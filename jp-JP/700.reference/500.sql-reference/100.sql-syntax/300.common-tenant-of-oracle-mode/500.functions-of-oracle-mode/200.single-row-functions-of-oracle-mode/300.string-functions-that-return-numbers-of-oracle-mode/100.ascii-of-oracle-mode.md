# ASCII

## 説明

この関数は、文字式の左端の文字のASCIIコード値を返します。

## 構文

```sql
ASCII(char)
```

## パラメータの説明

| パラメータ |                        説明                         |
|------|---------------------------------------------------|
| char | `CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` データ型の式。 |

## 戻り値のタイプ

`NUMBER` データ型を返します。

## 例

`ASCII` 関数を使用して、**A**、**a**、およびスペースのASCIIコード値を返します。

```sql
obclient> SELECT ASCII('A') A, ASCII('a') a, ASCII(' ') space FROM DUAL;
+------+------+-------+
| A    | A    | SPACE |
+------+------+-------+
|   65 |   97 |    32 |
+------+------+-------+
1 row in set
```

`ASCII` 関数を使用して、**A**、**a**、**中**、およびスペースのASCIIコード値を返します。

```sql
obclient> SELECT ASCII('A') A, ASCII('a') a, ASCII(' ') space, ASCII('中') hz FROM DUAL;
+------+------+-------+----------+
| A    | A    | SPACE | HZ       |
+------+------+-------+----------+
|   65 |   97 |    32 | 14989485 |
+------+------+-------+----------+
1 row in set
```
