# POSITION

## 説明

この関数は、文字列内で指定されたサブ文字列を検索し、そのサブ文字列が最初に現れる文字の位置を返します。

## 構文

```sql
POSITION(substring IN string)
```

## パラメータ説明

| パラメータ | 説明 |
|------|------|
| substring | 検索するサブ文字列を指定します。 |
| string | 検索対象の文字列を指定します。 |

## 戻り値タイプ

`NUMBER` データ型を返します。指定されたサブ文字列が見つからない場合は `0` を返します。

## 例

文字列 `中OceanBase` 内で `Base` が最初に現れる文字位置を返します。

```sql
obclient> SELECT POSITION('Base' IN '中OceanBase') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|      7 |
+--------+
1 row in set
```
