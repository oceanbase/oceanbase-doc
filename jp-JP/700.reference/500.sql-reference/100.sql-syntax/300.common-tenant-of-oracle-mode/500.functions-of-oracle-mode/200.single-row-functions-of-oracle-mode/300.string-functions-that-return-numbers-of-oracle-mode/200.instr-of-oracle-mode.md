# INSTR

## 説明

この関数は、文字列内で指定された文字を検索し、指定された文字が見つかった場所を返します。複数バイト文字（漢字、全角文字など）は1文字として計算されます。

## 構文

```sql
INSTR(char1,char2[,i[,j]])
```

## パラメータの説明

|  パラメータ   |                                 説明                                 |
|-------|--------------------------------------------------------------------|
| char1 | 検索する文字列。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。   |
| char2 | 検索する文字列を指定します。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` が可能です。 |
| i     | 検索の開始位置。デフォルト値は `1` です。値が `0` より小さい場合、検索は逆方向から開始されますが、検出された文字の正の位置は返されます。            |
| j     | `char2` の `j` 番目の出現位置です。オプションです。デフォルト値は `1` です。                                |

## 戻り値の型

`NUMBER` データ型を返します。

## 例

文字列 `OceanBase` 内で `a` の2番目の出現位置を前方から検索します。

```sql
obclient> SELECT INSTR('OceanBase','a',1,2) "INSTR" FROM DUAL;
+-------+
| INSTR |
+-------+
|     7 |
+-------+
1 row in set
```
