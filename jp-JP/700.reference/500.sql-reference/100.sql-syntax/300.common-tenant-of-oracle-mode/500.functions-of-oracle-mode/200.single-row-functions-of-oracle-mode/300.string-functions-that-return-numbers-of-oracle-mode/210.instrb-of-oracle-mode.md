# INSTRB

## 説明

この関数は、バイト単位で文字列内を検索し、指定されたサブ文字列の開始バイト位置を返します。

## 構文

```sql
INSTRB(string, substring [, position [, occurrence]])
```

## パラメータ説明

| パラメータ | 説明 |
|------|------|
| string | 検索する文字列を指定します。 |
| substring | 検索するサブ文字列を指定します。 |
| position | オプションです。検索の開始位置を指定します。デフォルト値は `1` です。値が負の場合、文字列の末尾から逆方向に検索します。 |
| occurrence | オプションです。何回目に出現するサブ文字列の位置を返すかを指定します。デフォルト値は `1` です。 |

## 戻り値の型

`NUMBER` データ型を返します。指定されたサブ文字列が見つからない場合は `0` を返します。

## 例

文字列 `中OceanBase` の漢字 `中` は3バイトです。したがって、`Base` は9番目のバイトから始まります。

```sql
obclient> SELECT INSTRB('中OceanBase', 'Base') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|      9 |
+--------+
1 row in set
```
