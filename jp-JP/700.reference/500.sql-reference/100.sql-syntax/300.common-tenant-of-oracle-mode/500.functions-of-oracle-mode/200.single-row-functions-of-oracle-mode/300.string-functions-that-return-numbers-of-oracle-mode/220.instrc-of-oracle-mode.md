# INSTRC

## 説明

この関数は、Unicode完全文字単位で、文字列内から指定されたサブ文字列を検索し、そのサブ文字列の開始文字位置を返します。

## 構文

```sql
INSTRC(string, substring [, position [, occurrence]])
```

## パラメータの説明

| パラメータ | 説明 |
|------|------|
| string | 検索対象の文字列を指定します。 |
| substring | 検索するサブ文字列を指定します。 |
| position | オプションです。検索の開始位置を指定します。デフォルト値は `1` です。値が負数の場合、文字列の末尾から逆方向に検索します。 |
| occurrence | オプションです。何回目に出現するサブ文字列の位置を返すかを指定します。デフォルト値は `1` です。 |

## 戻り値の型

`NUMBER` データ型を返します。指定されたサブ文字列が見つからない場合は `0` を返します。

## 例

文字列 `中OceanBase` の `Base` は、7番目のUnicode完全文字から始まります。

```sql
obclient> SELECT INSTRC('中OceanBase', 'Base') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|      7 |
+--------+
1 row in set
```
