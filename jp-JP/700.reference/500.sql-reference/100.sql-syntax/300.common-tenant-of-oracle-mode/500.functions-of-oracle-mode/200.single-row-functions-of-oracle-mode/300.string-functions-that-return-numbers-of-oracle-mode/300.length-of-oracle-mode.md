# LENGTH

## 説明

この関数は文字列の長さを返します。複数バイトの文字（漢字、全角記号など）は1文字としてカウントされます。

## 構文

```sql
LENGTH(char)
```

## パラメータの説明

`char` は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` データ型の文字列です。

## 戻り値のタイプ

`NUMBER` データ型を返します。

## 例

文字列 `OceanBase` の長さを返します。

```sql
obclient> SELECT LENGTH('OceanBase') "LENGTH" FROM DUAL;
+--------+
| LENGTH |
+--------+
|      9 |
+--------+
1 row in set
```
