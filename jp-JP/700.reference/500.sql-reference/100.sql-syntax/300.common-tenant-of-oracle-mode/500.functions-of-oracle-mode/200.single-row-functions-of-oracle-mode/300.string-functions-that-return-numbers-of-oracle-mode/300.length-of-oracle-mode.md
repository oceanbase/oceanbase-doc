# LENGTH

## 説明

この関数は、文字列の長さを返します。複数バイト文字（全角文字など）は1文字として計算されます。

## 構文

```sql
LENGTH(char)
```

## パラメータの説明

`char` は `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` データ型の文字列です。

## 戻り値の型

`NUMBER` データ型を返します。

## 例

文字列 `OceanBase` の長さを返します。

```sql
obclient> SELECT LENGTH('OceanBase') "LENGTH" FROM DUAL;
+--------+
| LENGTH |
+--------+
|      9 |
+--------+
1 row in set
```
