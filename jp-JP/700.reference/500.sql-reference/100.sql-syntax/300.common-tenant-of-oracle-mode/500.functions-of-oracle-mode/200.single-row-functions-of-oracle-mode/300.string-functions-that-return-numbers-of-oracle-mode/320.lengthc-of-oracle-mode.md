# LENGTHC

## 説明

この関数は、Unicode完全文字単位で文字列の長さを返します。

## 構文

```sql
LENGTHC(char)
```

## パラメータ説明

`char` は、長さを計算する文字列を指定します。

## 戻り値の型

`NUMBER` データ型を返します。

## 例

文字列 `中OceanBase` には10個のUnicode完全文字が含まれています。

```sql
obclient> SELECT LENGTHC('中OceanBase') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|     10 |
+--------+
1 row in set
```
