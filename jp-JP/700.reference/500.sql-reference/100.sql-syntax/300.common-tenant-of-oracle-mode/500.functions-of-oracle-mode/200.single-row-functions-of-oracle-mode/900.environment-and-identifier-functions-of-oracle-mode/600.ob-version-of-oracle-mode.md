# OB_VERSION

## 宣言

```sql
OB_VERSION()
```

## 説明

現在のOceanBaseデータベースのバージョン情報を返します。文字セットはutf8mb4です。

## 例

```sql
obclient> SELECT OB_VERSION() FROM DUAL;
+--------------+
| OB_VERSION() |
+--------------+
| 4.0.0.0      |
+--------------+
1 row in set
```
