# USERENV

## 説明

この関数は、現在のセッションに関する情報を返します。この関数は `CHECK` 制約の条件下では使用できません。

## 構文

```sql
USERENV('parameter')
```

## パラメータの説明

`parameter` 変数の取り得る値は以下のとおりです：

| **値** | **説明** |
| -------- | -------- |
| CLIENT_INFO | ユーザーセッション情報を返します（最大64バイト）。アプリケーションは `DBMS_APPLICATION_INFO` システムパッケージを使用してこの情報を格納できます。 |
| INSTANCE | 現在のインスタンスの識別子です。 |
| LANG | 言語の略称名で、LANGUAGEパラメータよりも短い形式です。 |
| LANGUAGE | 現在のセッションで使用されている言語と地域、およびデータベースの文字セットです。形式は `language_territory.characterset` です。 |
| SCHEMAID | スキーマIDです。 |
| SID \| SESSIONID | 現在のセッションのクライアントセッションIDを返します。このIDは、クライアント内でのセッションの一意の識別子です。|

## 戻り値

`SESSIONID` と `SID` パラメータを指定して呼び出した場合は `NUMBER` を返し、その他のパラメータを指定して呼び出した場合は `VARCHAR2` データ型を返します。

## 例

* 現在のセッションで使用されている言語とロケール、およびデータベースの文字セットを取得します。

  ```sql
  obclient [SYS]> SELECT USERENV('LANGUAGE') "Language" FROM DUAL;
  ```

  実行結果は次のとおりです：

  ```shell
  +---------------------------+
  | Language                  |
  +---------------------------+
  | AMERICAN_AMERICA.AL32UTF8 |
  +---------------------------+
  1 row in set
  ```

* 現在のセッションのスキーマIDを取得します。

  ```sql
  obclient [SYS]> SELECT USERENV('SCHEMAID') FROM DUAL;
  ```

  実行結果は次のとおりです：

  ```shell
  +---------------------+
  | USERENV('SCHEMAID') |
  +---------------------+
  |              201006 |
  +---------------------+
  1 row in set
  ```

* 現在のセッションのクライアントセッションIDを取得します。

  ```sql
  obclient [SYS]> SELECT USERENV('SESSIONID') AS Client_Session_ID FROM DUAL;
  ```

  または

  ```sql
  obclient [SYS]> SELECT USERENV('SID') AS Client_Session_ID FROM DUAL;
  ```

  実行結果は次のとおりです：

  ```shell
  +-------------------+
  | CLIENT_SESSION_ID |
  +-------------------+
  |        3221488033 |
  +-------------------+
  1 row in set
  ```
