# SYS_CONTEXT

## 説明

この関数は、現在の時刻においてコンテキスト名前空間に関連付けられたパラメータの値を返します。

## 構文

```sql
SYS_CONTEXT('namespace', 'parameter' [, length ])
```

## パラメータの説明

|    パラメータ     |                              説明                              |
|-----------|--------------------------------------------------------------|
| namespace | 名前空間を指定します。任意の `USERENV` をサポートします。                                      |
| parameter | 名前空間に関連付けられたパラメータを指定します。現在サポートされているパラメータは、次の表 **名前空間** `USERENV` **の定義済みパラメータ** のとおりです。 |
| length    | 戻り値の長さをバイト単位で指定します。オプションです。値の範囲は \[1, 4000\] で、デフォルトの長さは 256 バイトです。          |

**名前空間** `USERENV` **の定義済みパラメータ**

|       パラメータ名        |                           戻り値                           |
|------------------|---------------------------------------------------------|
| CON_ID           | CDB（Container DataBase）に接続してクエリを実行した場合、現在のコンテナIDを返します。CDBに接続していない場合は、`0` を返します。 |
| CON_NAME         | CDBに接続してクエリを実行した場合、現在のコンテナ名を返します。CDBに接続していない場合は、`DB_NAME` パラメータで指定されたデータベース名を返します。  |
| CURRENT_SCHEMA   | 現在アクティブなデフォルトスキーマ名です。                                      |
| CURRENT_SCHEMAID | 現在アクティブなデフォルトスキーマIDです。                                      |
| CURRENT_USER     | 現在権限が有効なデータベースユーザー名です。                                      |
| CURRENT_USERID   | 現在権限が有効なデータベースユーザーIDです。                                    |
| DB_NAME          | データベース名です。                                                  |
| INSTANCE         | 現在のインスタンス識別子です。                                               |
| INSTANCE_NAME    | 現在のインスタンス名です。                                                 |
| IP_ADDRESS       | クライアントマシンのIPアドレスです。                                           |
| LANG             | 言語の略称名で、`LANGUAGE` パラメータよりも短い形式です。                           |
| LANGUAGE         | 現在のセッションで使用されている言語と地域、およびデータベースの文字セットです。                                  |
| SESSION_USER     | ログインしたデータベースユーザー名で、この値はセッション全体を通じて変更されません。                                |
| SESSION_USERID   | ログインしたデータベースユーザーIDです。                                            |
| SID \| SESSIONID | 現在のセッションのクライアントセッションIDを取得します。このIDは、クライアント上のセッションを一意に識別するものです。|

## 戻り値の型

`VARCHAR2` データ型を返します。

## 例

名前空間 `USERENV` 内のセッションのクライアントセッションIDを確認します。

```sql
obclient [SYS]> SELECT SYS_CONTEXT ('USERENV', 'SESSIONID') AS Client_Session_ID FROM DUAL;
```

または

```sql
obclient [SYS]> SELECT SYS_CONTEXT ('USERENV', 'SID') AS Client_Session_ID FROM DUAL;
```

実行結果は次のとおりです：

```shell
+-------------------+
| CLIENT_SESSION_ID |
+-------------------+
| 3221488043        |
+-------------------+
1 row in set
```
