# USER

## 説明

この関数は、現在ログインしているユーザーの名前を返します。

## 構文

```sql
USER
```

## 戻り値型

`VARCHAR2`データ型を返します。

## 例

現在のユーザーの名前を返します。

```sql
obclient> SELECT USER FROM DUAL;
+------+
| USER |
+------+
| SYS  |
+------+
1 row in set
```
