# TO_CHAR (character)

## 説明

この関数は、`NCHAR`、`NVARCHAR2`、または `CLOB` タイプのデータを `VARCHAR2` データ型に変換します。
  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>関数が文字 <code>LOB</code> をデータベース文字セットに変換する場合、変換対象の <code>LOB</code> 値がターゲット型より大きい場合、データベースはエラーを返します。</p>
  </main>

## 構文

```sql
TO_CHAR(character)
```

## パラメータの説明

パラメータ `character` は、`VARCHAR2` データ型に変換する式を指定します。データ型は `NCHAR`、`NVARCHAR2`、または `CLOB` です。

## 戻り値の型

`VARCHAR2` データ型を返します。

## 例

文字列 `010101` を文字データに変換します。

```sql
obclient> SELECT TO_CHAR('010101') FROM DUAL;
+-------------------+
| TO_CHAR('010101') |
+-------------------+
| 010101            |
+-------------------+
1 row in set
```
