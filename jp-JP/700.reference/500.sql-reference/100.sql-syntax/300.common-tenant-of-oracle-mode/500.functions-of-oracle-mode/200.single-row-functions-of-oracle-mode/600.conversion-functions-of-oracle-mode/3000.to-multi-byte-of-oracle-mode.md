# TO_MULTI_BYTE

## 説明

この関数は、すべての1バイト文字を対応する複数バイト文字に変換します。データベースの文字セットに1バイト文字と複数バイト文字の両方が含まれている場合にのみ、この関数は有効です。

## 構文

```sql
TO_MULTI_BYTE(char)
```

## パラメータの説明

`char` は、データ型 `CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` であることができます。`char` 内のいずれかの1バイト文字に複数バイトの等価文字がない場合、出力文字列では1バイト文字として表示されます。

## 戻り値の型

戻り値は `char` のデータ型と同じです。

## 例

* 1バイト文字 `B` をUTF-8の複数バイト文字 `B` に変換します。

  ```sql
  obclient> SELECT dump(TO_MULTI_BYTE( 'B')) FROM DUAL;
  +---------------------------+
  | DUMP(TO_MULTI_BYTE('B'))  |
  +---------------------------+
  | Typ=22 Len=3: 239,188,162 |
  +---------------------------+
  1 row in set
  ```

* 文字列内の半角文字を全角文字に変換します。

  ```sql
  obclient> SELECT TO_MULTI_BYTE('中国A') text FROM DUAL;
  +-----------+
  | TEXT      |
  +-----------+
  | 中国Ａ    |
  +-----------+
  ```
