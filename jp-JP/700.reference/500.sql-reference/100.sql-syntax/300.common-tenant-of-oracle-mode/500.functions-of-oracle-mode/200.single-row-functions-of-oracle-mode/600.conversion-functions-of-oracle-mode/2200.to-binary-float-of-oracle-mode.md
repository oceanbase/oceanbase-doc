# TO_BINARY_FLOAT

## 説明

この関数は、単精度浮動小数点数を返します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>文字列または <code>NUMBER</code> を <code>BINARY_FLOAT</code> に変換すると、正確さが損なわれる可能性があります。これは、<code>NUMBER</code> と文字列型が10進精度で数値を表現するのに対し、<code>BINARY_FLOAT</code> は2進精度を使用するためです。また、<code>BINARY_DOUBLE</code> 値が <code>BINARY_FLOAT</code> よりも高い精度を使用している場合、<code>BINARY_DOUBLE</code> から <code>BINARY_FLOAT</code> への変換は不正確になります。</p>
  </main>

## 構文

```sql
TO_BINARY_FLOAT(expr [, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                 説明                                 |
|----------|--------------------------------------------------------------------|
| expr     | 文字列または`NUMBER`、`BINARY_FLOAT`、または`BINARY_DOUBLE`型のデータ。              |
| expr     | 出力形式パラメータで、オプションです。`fmt`が省略された場合、`n`は`VARCHAR2`値に変換されます。値の詳細については、`fmt`パラメータのリストを参照してください。 |
| nlsparam | 十進数文字、部門区切り文字、現地通貨記号、および国際通貨記号を定義します。オプションです。                                   |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>expr</code> が文字列の場合、オプションの <code>fmt</code> および <code>nlsparam</code> パラメータが有効になります。これらのパラメータの役割は <code>TO_CHAR (number)</code> 関数と同じです。<code>expr</code> が <code>BINARY_FLOAT</code> の場合、関数は <code>expr</code> を返します。</p>
  </main>

## 戻り値のタイプ

`BINARY_FLOAT` タイプのデータを返します。

## 例

文字列 `123.123` を単精度浮動小数点数に変換します。

```sql
obclient> SELECT TO_BINARY_FLOAT('123.123') FROM DUAL;
+----------------------------+
| TO_BINARY_FLOAT('123.123') |
+----------------------------+
|            1.23123001E+002 |
+----------------------------+
1 row in set
```
