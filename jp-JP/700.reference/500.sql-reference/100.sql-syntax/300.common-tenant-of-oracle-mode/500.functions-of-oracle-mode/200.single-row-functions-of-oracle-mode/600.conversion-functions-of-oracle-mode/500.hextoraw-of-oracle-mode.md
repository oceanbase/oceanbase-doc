# HEXTORAW

## 説明

この関数は、16進数文字列を `RAW` 型に変換します。

## 構文

```sql
HEXTORAW (char)
```

## パラメータの説明

パラメータ `char` は16進数の文字列です。文字列型は `CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` が可能です。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>char</code> に <code>F</code> より大きい文字が含まれる場合（<code>A</code> が最小、<code>Z</code> が最大）、エラーが発生します。</p>
  </main>

## 戻り値の型

`RAW` 型のデータを返します。

## 例

16進数文字列 `AAA` を `RAW` 型に変換します。

```sql
obclient> SELECT HEXTORAW('AAA') FROM DUAL;
+-----------------+
| HEXTORAW('AAA') |
+-----------------+
| 0AAA            |
+-----------------+
1 row in set
```
