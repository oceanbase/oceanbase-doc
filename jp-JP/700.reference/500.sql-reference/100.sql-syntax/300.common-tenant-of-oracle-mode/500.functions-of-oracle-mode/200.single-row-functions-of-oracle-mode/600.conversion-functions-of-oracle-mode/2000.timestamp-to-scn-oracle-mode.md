# TIMESTAMP_TO_SCN

## 説明

`TIMESTAMP_TO_SCN()`関数は、タイムスタンプ型のパラメータを入力として受け取り、対応するSCN（System Change Number）を返します。この関数の入力パラメータの型は`TIMESTAMP`であり、戻り値のデータ型は`NUMBER`です。

## 構文

```sql
TIMESTAMP_TO_SCN(timestamp)
```

## 例

```sql
obclient> SELECT TIMESTAMP_TO_SCN('2022-06-16 11:50:30.123451234') FROM DUAL;
+--------------------------------------------------+
| TIMESTAMP_TO_SCN('2022-06-1611:50:30.123451234') |
+--------------------------------------------------+
|                              1655351430123451234 |
+--------------------------------------------------+
1 row in set
```
