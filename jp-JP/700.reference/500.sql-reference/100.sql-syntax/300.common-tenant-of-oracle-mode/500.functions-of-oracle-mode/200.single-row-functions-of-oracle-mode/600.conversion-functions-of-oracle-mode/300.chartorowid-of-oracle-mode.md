# CHARTOROWID

## 説明

この関数は、`CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` 型の文字列を `ROWID` データ型に変換します。

## 構文

```sql
CHARTOROWID(char)
```

## パラメータの説明

パラメータ `char` は、`ROWID` 書式に従う文字列であり、例えば "`*AAIKAQAAAAAAAAA="` などです。

## 戻り値のタイプ

`ROWID` データ型を返します。

## 例

文字列 `*AAIKAQAAAAAAAA/=` を `ROWID` データ型の値に変換します。

```sql
obclient> SELECT CHARTOROWID('*AAIKAQAAAAAAAA/=') FROM DUAL;
+----------------------------------+
| CHARTOROWID('*AAIKAQAAAAAAAA/=') |
+----------------------------------+
| *AAIKAQAAAAAAAA8=                |
+----------------------------------+
1 row in set
```
