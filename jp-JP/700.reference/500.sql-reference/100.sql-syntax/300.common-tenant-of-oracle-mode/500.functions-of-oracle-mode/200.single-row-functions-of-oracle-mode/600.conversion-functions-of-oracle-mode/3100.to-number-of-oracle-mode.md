# TO_NUMBER

## 説明

この関数は、`CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、`BINARY_FLOAT`、または `BINARY_DOUBLE` 型の文字列を `NUMBER` 値データ型に変換します。

## 構文

```sql
TO_NUMBER(expr [, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                                               説明                                                               |
|----------|--------------------------------------------------------------------------------------------------------------------------------|
| expr     | `CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、`BINARY_FLOAT`、または `BINARY_DOUBLE` データ型の値。                                             |
| fmt      | `expr` のフォーマットモデルであり、オプションです。 **説明**  `expr` は `fmt` の範囲内でなければなりません。例：`TO_NUMBER('$123456.78','$999999999.999')`。 |
| nlsparam | 返されるデータで使用する言語を制御します。オプションです。                                                                                                          |

## 戻り値のタイプ

`NUMBER` 型のデータを返します。

## 例

* 文字列 `0123456` を数値に変換します。

  ```sql
  obclient> SELECT TO_NUMBER('0123456') FROM DUAL;
  +----------------------+
  | TO_NUMBER('0123456') |
  +----------------------+
  |               123456 |
  +----------------------+
  1 row in set
  ```

* 16進数 `16f` を10進数に変換します。

  ```sql
  obclient> SELECT TO_NUMBER('16f','xxx') FROM DUAL;
  +------------------------+
  | TO_NUMBER('16F','XXX') |
  +------------------------+
  |                    367 |
  +------------------------+
  1 row in set
  ```
