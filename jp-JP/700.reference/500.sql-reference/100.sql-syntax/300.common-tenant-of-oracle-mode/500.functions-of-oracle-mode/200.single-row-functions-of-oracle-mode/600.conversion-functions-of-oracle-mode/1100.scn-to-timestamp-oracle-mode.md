# SCN_TO_TIMESTAMP

## 説明

`SCN_TO_TIMESTAMP()`関数は、SCNをパラメータとして受け取り、そのSCNに関連付けられたタイムスタンプを返します。戻り値は`TIMESTAMP`データ型です。

## 構文

```sql
SCN_TO_TIMESTAMP(number)
```

## 例

```sql
obclient> SELECT MAX_SCN, SCN_TO_TIMESTAMP(MAX_SCN) FROM gv$ob_log_stat;
+---------------------+---------------------------------+
| MAX_SCN             | SCN_TO_TIMESTAMP(MAX_SCN)       |
+---------------------+---------------------------------+
| 1676966094432030402 | 21-FEB-23 03.54.54.432030402 PM |
| 1676966094299077583 | 21-FEB-23 03.54.54.299077583 PM |
+---------------------+---------------------------------+
2 rows in set
```

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>gv$ob_log_stat</code>ログストリームの同期状態を示す内部テーブルであり、その<code>max_scn</code>フィールドはSCN型です。<code>SCN_TO_TIMESTAMP()</code>関数を使用してSCNをタイムスタンプに変換します。</p>
</main>
