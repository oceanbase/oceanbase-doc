# CONVERT

## 説明

この関数は、文字列をある文字セットから別の文字セットに変換するために使用します。

## 構文

```sql
CONVERT(char, dest_char_set[, source_char_set])
```

## パラメータの説明

|       パラメータ        |                                  説明                                  |
|-----------------|----------------------------------------------------------------------|
| char            | 変換する文字列。`CHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2`、または `CLOB` など、任意のデータ型を指定できます。 |
| dest_char_set   | 文字列が変換先の文字セット名です。                                                       |
| source_char_set | データベース内に格納されている文字列の文字セット名です。指定しない場合、データベースの文字セットがデフォルト値となります。                                   |

## 戻り値の型

* `char` のデータ型が `CHAR` または `VARCHAR2` の場合、`VARCHAR2` 型を返します。

* `char` のデータ型が `NCHAR` または `NVARCHAR2` の場合、`NVARCHAR2` 型を返します。

* `char` のデータ型が `CLOB` の場合、`CLOB` 型を返します。

## 例

文字列 `Ä Ê Í a b c d` を ZHS16GBK 文字セットに変換します。

```sql
obclient> SELECT CONVERT('Ä Ê Í a b c d', 'ZHS16GBK') FROM DUAL;
+----------------------------------+
| CONVERT('ÄÊÍABCD','ZHS16GBK')    |
+----------------------------------+
| ? ? ? a b c d                    |
+----------------------------------+
1 row in set
```
