# NLS CHARSET_ID

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.4.2では、この関数はV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 説明

`NLS CHARSET_ID` 関数は、文字セット名に対応する文字セットID番号を返します。

## 構文

```sql
NLS_CHARSET_ID(string)
```

## パラメータの説明

パラメータ `string` は任意の文字セットの文字列です。

* `CHAR_CS` を指定した場合：現在のデータベースのデフォルト文字セットのIDを返します。
* `NCHAR_CS` を指定した場合：現在のデータベースの国別文字セットのIDを返します。
* 指定された名前が無効な場合、`NULL` を返します。

## 例

```shell
obclient> SELECT NLS_CHARSET_ID('ja16euc')
  FROM DUAL;
```

実行結果は次のとおりです：

```sql
+---------------------------+
| NLS_CHARSET_ID('JA16EUC') |
+---------------------------+
|                      803  |
+---------------------------+
1 row in set (0.001 sec)
```
