# TO_NCHAR (character)

## 説明

この関数は、`CHAR`、`VARCHAR2`、`CLOB`、または `NCLOB` 型のデータを国際文字セットに変換し、`NVARCHAR2` データ型を返します。

## 構文

```sql
TO_NCHAR(character)
```

## パラメータの説明

`character` は `CHAR`、`VARCHAR2`、`CLOB`、または `NCLOB` 型のデータです。

## 戻り値の型

`NVARCHAR2` データ型を返します。

## 例

テーブル `tbl1` を作成してデータを挿入し、テーブル `tbl1` の `VARCHAR2` データを国際文字セットに変換します。

```sql
obclient> CREATE TABLE tbl1(col1 INT,col2 VARCHAR2(20));
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES(1,'OceanBase');
Query OK, 1 row affected

obclient> SELECT TO_NCHAR(col2) FROM tbl1;
+----------------+
| TO_NCHAR(COL2) |
+----------------+
| OceanBase      |
+----------------+
1 row in set
```
