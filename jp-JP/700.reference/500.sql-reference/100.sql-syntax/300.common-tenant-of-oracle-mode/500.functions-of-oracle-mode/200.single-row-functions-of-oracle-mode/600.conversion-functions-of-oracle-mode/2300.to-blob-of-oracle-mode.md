# TO_BLOB

## 説明

この関数は、`LONG RAW` 値と `RAW` 値を `BLOB` 値に変換します。

## 構文

```sql
TO_BLOB( raw_value )
```

## パラメータの説明

パラメータ `raw_value` は `LONG RAW` または `RAW` タイプの値です。

## 戻り値のタイプ

`BLOB` のタイプを返します。

## 例

次の例では、`tbl_raw` テーブルを作成し、`COL_RAW` という名前の列を追加して、列タイプをRAW、長さを16バイトとして定義し、データを挿入します。

```sql
CREATE TABLE tbl_raw (COL_RAW RAW(16));

-- テーブルに1行のデータを挿入します。COL_RAW列の値は0ABCです。
-- RAWタイプでは、文字列は16進数データとして解釈されます。
-- そのため、ここでの'0ABC'は2バイトのバイナリ形式で保存されます：0A（16進）とBC（16進）
INSERT INTO tbl_raw (COL_RAW) VALUES ('0ABC');

-- さらに1行のデータを挿入します。COL_RAW列の値は0123456789ABCDEFであり、8バイトのバイナリデータに変換されて保存されます。
-- 01、23、45、67、89、AB、CD、EFは対応するバイナリバイトです。
INSERT INTO tbl_raw (COL_RAW) VALUES ('0123456789ABCDEF');
```

以下のSQLを実行すると、テーブル `tbl_raw` の `RAW` タイプの値を `BLOB` 値に変換して、対応するバイト長を返します。

```shell
obclient> SELECT COL_RAW,LENGTHB(COL_RAW) "LENGTHB_RAW",LENGTHB(TO_BLOB(COL_RAW)) "LENGTHB_BLOB"
          FROM tbl_raw;
+------------------+-------------+--------------+
| COL_RAW          | LENGTHB_RAW | LENGTHB_BLOB |
+------------------+-------------+--------------+
| 0ABC             |           4 |            2 |
| 0123456789ABCDEF |          16 |            8 |
+------------------+-------------+--------------+
2 rows in set
```
