# TO_BLOB

## 説明

この関数は、`LONG RAW` 値と `RAW` 値を `BLOB` 値に変換します。

## 構文

```sql
TO_BLOB( raw_value )
```

## パラメータの説明

パラメータ `raw_value` は `LONG RAW` または `RAW` 型の値です。

## 戻り値の型

`BLOB` 型を返します。

## 例

既に作成されたテーブル `tbl_raw` がある場合、`RAW` 型の値を `BLOB` 値に変換し、対応するバイト長を返します。

```sql
obclient> SELECT COL_RAW,LENGTHB(COL_RAW) "LENGTHB_RAW",LENGTHB(TO_BLOB(COL_RAW)) "LENGTHB_BLOB"
          FROM tbl_raw;
+------------------+-------------+--------------+
| COL_RAW          | LENGTHB_RAW | LENGTHB_BLOB |
+------------------+-------------+--------------+
| 0ABC             |           4 |            2 |
| 0123456789ABCDEF |          16 |            8 |
+------------------+-------------+--------------+
2 rows in set
```
