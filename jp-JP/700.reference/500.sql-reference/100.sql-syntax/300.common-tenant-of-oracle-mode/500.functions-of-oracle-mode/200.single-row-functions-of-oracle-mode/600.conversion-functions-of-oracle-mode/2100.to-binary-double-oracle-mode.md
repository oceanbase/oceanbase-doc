# TO_BINARY_DOUBLE

## 説明

この関数は、倍精度浮動小数点数を返します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>文字列または <code>NUMBER</code> を <code>BINARY_DOUBLE</code> に変換すると、正確さが損なわれる可能性があります。これは、<code>NUMBER</code> と文字列型が10進精度で数値を表現するのに対し、<code>BINARY_DOUBLE</code> は2進精度を使用するためです。一方、<code>BINARY_FLOAT</code> から <code>BINARY_DOUBLE</code> への変換は正確です。</p>
  </main>

## 構文

```sql
TO_BINARY_DOUBLE(expr [, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                 説明                                 |
|----------|--------------------------------------------------------------------|
| expr     | 文字列、または`NUMBER`、`BINARY_FLOAT`、または`BINARY_DOUBLE`型の数値。              |
| fmt      | 出力形式パラメータで、オプションです。`fmt`が省略された場合、`n`は`VARCHAR2`値に変換されます。値の詳細については、`fmt`パラメータのリストを参照してください。 |
| nlsparam | 十進文字、部門区切り文字、現地通貨記号、および国際通貨記号を定義します。オプションです。                                   |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>expr</code> が文字列の場合、オプションの <code>fmt</code> および <code>nlsparam</code> パラメータが有効になります。これらのパラメータの役割は <code>TO_CHAR (number)</code> 関数と同じです。<code>expr</code> が <code>BINARY_DOUBLE</code> の場合、この関数は <code>expr</code> を返します。</p>
  </main>

## 戻り値のタイプ

`BINARY_DOUBLE` タイプのデータを返します。

## 例

文字列 `123.123` を倍精度浮動小数点数に変換します。

```sql
obclient> SELECT TO_BINARY_DOUBLE('123.123') FROM DUAL;
+-----------------------------+
| TO_BINARY_DOUBLE('123.123') |
+-----------------------------+
|                1.23123E+002 |
+-----------------------------+
1 row in set
```
