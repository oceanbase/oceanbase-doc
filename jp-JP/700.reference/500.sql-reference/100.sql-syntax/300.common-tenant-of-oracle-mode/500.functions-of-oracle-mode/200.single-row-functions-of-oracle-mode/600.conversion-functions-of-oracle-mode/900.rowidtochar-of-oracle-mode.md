# ROWIDTOCHAR

## 説明

この関数は、`rowid` 値を `VARCHAR2` データ型の値に変換します。

## 構文

```sql
ROWIDTOCHAR(rowid)
```

## パラメータの説明

パラメータ `rowid` は `ROWID` 形式の値です。

## 戻り値のタイプ

`VARCHAR2` データ型を返します。

## 例

テーブル `tbl1` の列 `ROWID` に `AAIKA` を含むデータを照会します。

```sql
obclient> SELECT LENGTHB(ROWIDTOCHAR(ROWID)),ROWIDTOCHAR(ROWID)
          FROM tbl1
          WHERE ROWIDTOCHAR(ROWID) LIKE '%AAIKA%';
+-----------------------------+--------------------+
| LENGTHB(ROWIDTOCHAR(ROWID)) | ROWIDTOCHAR(ROWID) |
+-----------------------------+--------------------+
|                          17 | *AAIKAQAAAAAAAAA=  |
|                          17 | *AAIKAgAAAAAAAAA=  |
|                          17 | *AAIKAwAAAAAAAAA=  |
+-----------------------------+--------------------+
3 rows in set
```
