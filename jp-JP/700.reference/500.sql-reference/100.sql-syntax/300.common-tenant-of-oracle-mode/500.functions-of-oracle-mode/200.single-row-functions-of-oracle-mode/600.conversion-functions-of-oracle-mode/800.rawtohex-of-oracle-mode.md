# RAWTOHEX

## 説明

この関数は、バイナリ形式の文字列を対応する16進数表現の文字列に変換します。

## 構文

```sql
RAWTOHEX (raw)
```

## パラメータの説明

| パラメータ  |    説明    |
|-----|----------|
| raw | バイナリ文字列。 |

## 戻り値の型

16進数表現の文字列。

## 例

バイナリ `AB` を対応する16進数文字列に変換します。

```sql
obclient> SELECT RAWTOHEX('AB')  FROM DUAL;
+----------------+
| RAWTOHEX('AB') |
+----------------+
| 4142           |
+----------------+
1 row in set
```
