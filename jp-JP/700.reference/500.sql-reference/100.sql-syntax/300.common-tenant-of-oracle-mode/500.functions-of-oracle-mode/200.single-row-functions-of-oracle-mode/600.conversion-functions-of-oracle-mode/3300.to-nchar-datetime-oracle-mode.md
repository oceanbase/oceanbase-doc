# TO_NCHAR (datetime)

## 説明

この関数は、`DATE`、`TIMESTAMP`、`TIMESTAMP WITH TIME ZONE`、`TIMESTAMP WITH LOCAL TIME ZONE`、`INTERVAL YEAR TO MONTH`、または `INTERVAL DAY TO SECOND`などのデータ型の値を、データベースの文字セットから国家文字セットのデータ型に変換します。

## 構文

```sql
TO_NCHAR({ datetime | interval }[, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                                                                                                                                                                                                 説明                                                                                                                                                                                                                 |
|----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| datetime | `DATE`、`TIMESTAMP`、`TIMESTAMP WITH TIME ZONE`、`TIMESTAMP WITH LOCAL TIME ZONE`、`INTERVAL DAY TO SECOND`、および `INTERVAL YEAR TO MONTH`データ型の値。                                                                                                                                                                                                                                                                                        |
| interval | `INTERVAL DAY TO SECOND`および`INTERVAL YEAR TO MONTH`データ型の値。 間隔単位は以下のとおりです： <ul><li> `YEAR`年を表します。   </li><li> `MONTH`月を表します。   </li><li> `DAY`日を表します。   </li><li> `HOUR`時間を表します。   </li><li> `MINUTE`分を表します。   </li><li> `SECOND`秒数を表します。 </li></ul>   |
| fmt      | 出力形式を指定します。省略可能です。 パラメータ`fmt`を指定しない場合、パラメータ`datetime`の値は次の形式で`VARCHAR2`データ型に変換されます： <ul><li> `DATE`、`TIMESTAMP`、`TIMESTAMP WITH TIME ZONE`、および`TIMESTAMP WITH LOCAL TIME ZONE`の値は、データベース内の日付時刻値のデフォルト形式に変換されます。各日付時刻型のデフォルト形式については、「日付時刻および間隔データ型」セクションを参照してください。   </li><li> `INTERVAL DAY TO SECOND`および`INTERVAL YEAR TO MONTH`データ型の値は、数値形式の間隔値に変換されます。 </li></ul>               |
| nlsparam | 返される月と日付で使用する言語を制御します。オプションです。                                                                                                                                                                                                                                                                                                                                                                                                           |

## 戻り値の型

国別文字セットを返すデータ型。

## 例

* `TO_NCHAR`関数を使用して、現在の日付をそれぞれ`YYYY/MM/DD`と`DSDL`形式で返します。

  ```sql
  obclient> SELECT TO_NCHAR(SYSDATE,'yyyy/mm/dd'),TO_NCHAR(SYSDATE,'DSDL') FROM DUAL;
  +--------------------------------+----------------------------------------+
  | TO_NCHAR(SYSDATE,'YYYY/MM/DD') | TO_NCHAR(SYSDATE,'DSDL')               |
  +--------------------------------+----------------------------------------+
  | 2021/12/09                     | 12/09/2021 Thursday, December 09, 2021 |
  +--------------------------------+----------------------------------------+
  1 row in set
  ```

* 時間間隔値を数値形式の間隔値に変換し、返却言語を`AMERICAN`に設定します。

  ```sql
  obclient> SELECT TO_NCHAR(interval'90' MINUTE, 'SS-MI-HH', 'nls_language = AMERICAN') FROM DUAL;
  +-----------------------------------------------------------------+
  | TO_NCHAR(INTERVAL'90'MINUTE,'SS-MI-HH','NLS_LANGUAGE=AMERICAN') |
  +-----------------------------------------------------------------+
  | +00 01:30:00                                                    |
  +-----------------------------------------------------------------+
  1 row in set
  ```
