# TO_CHAR (number)

## 説明

この関数は、`NUMBER`、`BINARY_FLOAT`、または `BINARY_DOUBLE` 型の数値を指定された数値形式に従って `varchar2` データ型の値に変換します。

## 構文

```sql
TO_CHAR(n [, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                                                               説明                                                                                |
|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| n        | `NUMBER`、`BINARY_FLOAT`、または `BINARY_DOUBLE` データ型の数値。<br>**説明**  `n` が負の値の場合、出力値の左端にマイナス記号が表示されます。例えば、`TO_CHAR(-1,'$9')` は `$-1` ではなく `-1` を返します。 |
| fmt      | 出力形式パラメータで、オプションです。`fmt` を省略した場合、`n` は `VARCHAR2` 値に変換されます。値の詳細については、`fmt` パラメータのリストを参照してください。                                                                                              |
| nlsparam | 十進文字、小数点区切り文字、現地通貨記号、および国際通貨記号を定義します。オプションです。                                                                                                                                |

**`fmt`** **パラメータリスト**

| fmtパラメータ値 |                                            説明                                            |
|----------|------------------------------------------------------------------------------------------|
| 9        | 指定された桁の値を返します。                                                                                |
| 0        | 前導0を返します。                                                                         |
| ,（カンマ）    | 指定された位置のカンマを返します。数値フォーマットモデルでは複数のカンマを指定できます。<br>**制限条件**：フォーマットモデルの数値はカンマで始まることができず、カンマは小数点またはピリオドの右側に配置することができません。 |
| .（小数点）   | 小数点を指定された位置に含む小数を返します。<br>**制限条件**：数値フォーマットモデルでは、小数点は1つしか指定できません。                         |

## 戻り値のタイプ

`VARCHAR2` データ型を返します。

## 例

`123456789.123` を `999,999,999` 形式の値に変換します。

```sql
obclient> SELECT TO_CHAR(123456789.123,'999,999,999') FROM DUAL;
+--------------------------------------+
| TO_CHAR(123456789.123,'999,999,999') |
+--------------------------------------+
|  123,456,789                         |
+--------------------------------------+
1 row in set
```
