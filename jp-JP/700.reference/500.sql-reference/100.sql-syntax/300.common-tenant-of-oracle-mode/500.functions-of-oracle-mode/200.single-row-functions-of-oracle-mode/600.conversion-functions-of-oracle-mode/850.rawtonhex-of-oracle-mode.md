# RAWTONHEX

## 説明

この関数は、`RAW` 値を対応する16進数文字列に変換します。

## 構文

```sql
RAWTONHEX(raw)
```

## パラメータの説明

`raw` は、変換する `RAW` 値を指定します。

## 戻り値の型

`NVARCHAR2` データ型を返します。

## 例

16進数で表された `RAW` 値を対応する16進数文字列に変換します。

```sql
obclient> SELECT RAWTONHEX(HEXTORAW('4F6365616E42617365')) AS result FROM DUAL;
+--------------------+
| RESULT             |
+--------------------+
| 4F6365616E42617365 |
+--------------------+
1 row in set
```
