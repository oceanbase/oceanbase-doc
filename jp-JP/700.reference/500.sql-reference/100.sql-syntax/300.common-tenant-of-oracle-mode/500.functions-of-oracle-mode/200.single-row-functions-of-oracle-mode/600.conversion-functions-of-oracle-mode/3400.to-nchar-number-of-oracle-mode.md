# TO_NCHAR (number)

## 説明

この関数は、`NUMBER`、`BINARY_FLOAT`、または `BINARY_DOUBLE` 型の数値を国家文字セットの文字列に変換します。

## 構文

```sql
TO_NCHAR(n [, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                               説明                                                |
|----------|-------------------------------------------------------------------------------------------------|
| n        | `NUMBER`、`BINARY_FLOAT`、または `BINARY_DOUBLE` データ型に属する数値。                                           |
| fmt      | 出力形式パラメータで、オプションです。`fmt` を省略した場合、`n` は `NVARCHAR2` 値に変換されて返されます。 値の詳細については、`fmt` **パラメータリスト**を参照してください。 |
| nlsparam | 10進文字、部門区切り文字、現地通貨記号、および国際通貨記号を定義します。オプションです。                                                                |

**`fmt`** **パラメータリスト**

| fmtパラメータ値 |                                            説明                                            |
|----------|------------------------------------------------------------------------------------------|
| 9        | 指定された桁数の値を返します。                                                                                |
| 0        | 指定された先頭と末尾の`0`を返します。                                                                           |
| （カンマ）    | 指定された位置のカンマを返します。数値フォーマットモデルでは複数のカンマを指定できます。 <br>**制限事項**：フォーマットモデルの数値はカンマで始まることができず、カンマは小数点またはピリオドの右側に表示されてはなりません。 |
| （小数点）   | 小数点を指定された位置に含む小数を返します。 <br>**制限事項**：数値フォーマットモデルでは、小数点は1つしか指定できません。                         |

## 戻り値の型

`NVARCHAR2` データ型を返します。

## 例

`123456789.123` を `999,999,999` 形式の値に変換します。

```sql
obclient> SELECT TO_NCHAR(123456789.123,'999,999,999') FROM DUAL;
+---------------------------------------+
| TO_NCHAR(123456789.123,'999,999,999') |
+---------------------------------------+
|  123,456,789                          |
+---------------------------------------+
1 row in set
```
