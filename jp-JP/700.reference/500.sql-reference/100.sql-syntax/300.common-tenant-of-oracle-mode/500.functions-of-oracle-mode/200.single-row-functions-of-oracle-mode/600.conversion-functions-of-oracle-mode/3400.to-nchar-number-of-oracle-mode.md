# TO_NCHAR (number)

## 説明

この関数は、`NUMBER`、`BINARY_FLOAT`、または `BINARY_DOUBLE` 型の数値を国際文字セットの文字列に変換します。

## 構文

```sql
TO_NCHAR(n [, fmt [, 'nlsparam' ] ])
```

## パラメータの説明

|    パラメータ    |                                               説明                                                |
|----------|-------------------------------------------------------------------------------------------------|
| n        | `NUMBER`、`BINARY_FLOAT` または `BINARY_DOUBLE` 型の数値。                                           |
| fmt      | 出力フォーマットパラメータで、オプションです。`fmt` を省略した場合、`n` は `NVARCHAR2` 値に変換されて返されます。 値の詳細については、`fmt` **パラメータリスト**を参照してください。 |
| nlsparam | 十進数文字、部品区切り文字、現地通貨記号、国際通貨記号を定義します。オプションです。                                                                |

**`fmt`** **パラメータリスト**

| fmtパラメータの値 |                                            説明                                            |
|----------|------------------------------------------------------------------------------------------|
| 9        | 指定された桁数の値を返します。                                                                                |
| 0        | 指定された数の先頭と末尾に`0`を付加して返します。                                                                           |
| ,（カンマ）    | 指定された位置にカンマを返します。数値書式モデルで複数のカンマを指定できます。 <br>**制限条件** ：書式モデルの数値はカンマで始まってはならず、カンマは小数文字やピリオドの右側には来てはなりません。 |
| .（小数点）   | 小数を返し、小数点は指定された位置に配置されます。 <br>**制限条件** ：数値書式モデルでは、小数点は1つしか指定できません。                         |

## 戻り値の型

`NVARCHAR2` データ型を返します。

## 例

`123456789.123` を `999,999,999` 形式の値に変換します。

```sql
obclient> SELECT TO_NCHAR(123456789.123,'999,999,999') FROM DUAL;
+---------------------------------------+
| TO_NCHAR(123456789.123,'999,999,999') |
+---------------------------------------+
|  123,456,789                          |
+---------------------------------------+
1 row in set
```
