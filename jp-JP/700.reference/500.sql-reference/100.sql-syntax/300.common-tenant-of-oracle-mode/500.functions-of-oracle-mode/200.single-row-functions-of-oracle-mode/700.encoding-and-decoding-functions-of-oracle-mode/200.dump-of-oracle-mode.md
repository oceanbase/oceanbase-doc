# DUMP

## 説明

この関数は、指定された式のデータ型コード、バイト長、および式の内部表現を返します。

## 構文

```sql
DUMP(expr[, return_fmt [, start_position [, length ] ] ])
```

## パラメータの説明

|       パラメータ       |                                                                                                                                                                                      説明                                                                                                                                                                                       |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr           | 分析する式を指定します。各種データ型の値を指定できます。                                                                                                                                                                                                                                                                                                                                                         |
| return_fmt     | 返される値の形式を指定します。オプションです。以下のように使用します： <ul><li> `8` は、結果値を8進数で返すことを意味します。   </li><li> `10` は、結果値を10進数で返すことを意味し、デフォルト値です。   </li><li> `16` は、結果値を16進数で返すことを意味します。   </li><li> `17` は、結果値を単一の文字として返すことを意味します。この文字はコンパイラの文字セットに含まれる出力可能な文字として解釈され、通常はASCII文字セットまたはEBCDIC文字エンコーディングです。それ以外の場合、文字は16進数表記で出力されます。すべてのNLSパラメータは無視されます。 </li></ul>     |
| start_position | 返される文字の開始位置を指定します。オプションです。デフォルト値は `1` です。                                                                                                                                                                                                                                                                                                                                                  |
| length         | 返す文字列の長さを指定します。省略可能です。デフォルトでは、すべての文字が返されます。                                                                                                                                                                                                                                                                                                                                                    |

## 返り値のタイプ

`expr` が `NULL` の場合、`NULL` を返します。それ以外の場合は、`VARCHAR2` データ型を返します。

## 例

文字列 `OceanBase` のデータ型コード、バイト長、および関連する文字に対応する8進数値を返します。

```sql
obclient> SELECT DUMP('OceanBase',8) FROM DUAL;
+---------------------------------------------------+
| DUMP('OCEANBASE',8)                               |
+---------------------------------------------------+
| Typ=23 Len=9: 117,143,145,141,156,102,141,163,145 |
+---------------------------------------------------+
1 row in set
```
