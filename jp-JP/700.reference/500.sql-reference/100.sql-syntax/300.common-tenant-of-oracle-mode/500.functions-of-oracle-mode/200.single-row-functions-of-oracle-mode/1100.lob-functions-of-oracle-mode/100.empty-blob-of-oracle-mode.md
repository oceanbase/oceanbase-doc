# EMPTY_BLOB

## 説明

この関数は、空の `BLOB` ロケーターを返します。このロケーターは `NULL` ではなく、LOBの長さは0です。

## 構文

```sql
EMPTY_BLOB()
```

## 戻り値

`BLOB` データ型を返します。

## 例

空の `BLOB` ロケーターを返し、そのロケーターが `NULL` かどうかおよびLOBの長さを確認します。

```sql
obclient> SELECT CASE WHEN EMPTY_BLOB() IS NULL THEN 'NULL' ELSE 'NOT NULL' END AS blob_is_null,
          DBMS_LOB.GETLENGTH(EMPTY_BLOB()) AS blob_len
          FROM DUAL;
+--------------+----------+
| BLOB_IS_NULL | BLOB_LEN |
+--------------+----------+
| NOT NULL     |        0 |
+--------------+----------+
1 row in set
```
