# EMPTY_CLOB

## 説明

この関数は、空の `CLOB` ロケーターを返します。このロケーターは `NULL` ではなく、LOB長は0です。

## 構文

```sql
EMPTY_CLOB()
```

## 戻り値

`CLOB` データ型を返します。

## 例

空の `CLOB` ロケーターを返し、そのロケーターが `NULL` かどうかおよびLOB長を確認します。

```sql
obclient> SELECT CASE WHEN EMPTY_CLOB() IS NULL THEN 'NULL' ELSE 'NOT NULL' END AS clob_is_null,
          DBMS_LOB.GETLENGTH(EMPTY_CLOB()) AS clob_len
          FROM DUAL;
+--------------+----------+
| CLOB_IS_NULL | CLOB_LEN |
+--------------+----------+
| NOT NULL     |        0 |
+--------------+----------+
1 row in set
```
