# SYS_CONNECT_BY_PATH

## 説明

この関数は、ルートからノードへの列値のパスを返します。`CONNECT BY` 条件で返される各行の列値は、指定された区切り文字で区切られます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この関数は階層クエリでのみ有効です。</p>
  </main>

## 構文

```sql
SYS_CONNECT_BY_PATH(column,'char')
```

## パラメータの説明

|   パラメータ   |                             説明                              |
|--------|-------------------------------------------------------------|
| column | 戻すデータの列名を指定します。`CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` データ型が可能です。 |
| char   | 区切り文字を指定します。`CHAR`、`VARCHAR2`、`NCHAR`、または `NVARCHAR2` データ型が可能です。    |

## 戻り値の型

`VARCHAR2` データ型を返します。

## 例
