# STDDEV_POP

## 説明

この関数は、数値データをパラメータとして全体の標準偏差を計算します。全体の標準偏差とは、全体分散の算術平均の平方根です。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行う必要があります。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果として1つの値しか返せません。この場合、<code>OVER</code> 句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
STDDEV_POP( [ALL] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

| パラメータ |                                           説明                                            |
|------|-----------------------------------------------------------------------------------------|
| ALL  | すべての数値列を指定します。オプションです。デフォルト値は `ALL` です。                                                                |
| expr | 数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT`、`BINARY_DOUBLE`）または数値型に変換できる式。                 |
| OVER | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。 |

## 返り値の型

返り値の型は、パラメータ`expr`のデータ型と同じです。

### 集計関数の例

列 `salary` の全標準偏差を求めます。

```sql
obclient> SELECT STDDEV_POP(salary) FROM employees;
+-------------------------------------------+
| STDDEV_POP(SALARY)                        |
+-------------------------------------------+
| 5637.250548804798333699350384281939588505 |
+-------------------------------------------+
1 row in set
```

### 分析関数の例

列 `department_id` でグループ化し、列 `salary` の全標準偏差を求めます。

```sql

          ORDER BY department_id,last_name,salary;
```
