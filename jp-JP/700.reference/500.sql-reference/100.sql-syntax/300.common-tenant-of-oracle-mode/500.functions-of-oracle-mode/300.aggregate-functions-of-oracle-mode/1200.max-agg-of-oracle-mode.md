# MAX

## 説明

この関数は、引数で指定された列の最大値を返します。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code>句を使用してウィンドウを定義し、計算を行う必要があります。これは一連の行に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行に対して集計計算を行い、結果として1つの値しか返せません。この場合、<code>OVER</code>句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
MAX ([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                                           説明                                                                                                                                            |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時に重複を除外するかどうか。オプションであり、デフォルト値は `ALL` です。 <ul><li> `ALL`：重複行を含むすべての値を返し、値が `NULL` の行は無視します。   </li><li> `DISTINCT`：返される行から重複行を除外し、値が `NULL` の行は無視します。   </li><li> `UNIQUE`：返される行から重複行を除外し、値が `NULL` の行は無視します。 </li></ul>   |
| expr                      | 数値、文字、日付、またはその他のデータ型の列または式を指定できます。                                                                                                                                                                                                                                                               |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を実行します。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                                 |

## 戻り値の型

`expr`と同じデータ型の値を返します。

## 例

既に作成されたテーブル `employees` があります。

```sql
obclient> SELECT * FROM employees;
+---------------+------------+-----------+------------+--------+
| DEPARTMENT_ID | MANAGER_ID | LAST_NAME | HIREDATE   | SALARY |
+---------------+------------+-----------+------------+--------+
|            30 |        100 | Raphaely  | 2017-07-01 |   1700 |
|            30 |        100 | De Haan   | 2018-05-01 |  11000 |
|            40 |        100 | Errazuriz | 2017-07-21 |   1400 |
|            50 |        100 | Hartstein | 2019-10-05 |  14000 |
|            50 |        100 | Raphaely  | 2017-07-22 |   1700 |
```

### 集約関数の例

`salary` 列の最大値を照会します。

```sql
obclient> SELECT MAX(salary) FROM employees;
+-------------+
| MAX(SALARY) |
+-------------+
|       14000 |
+-------------+
1 row in set
```

### 分析関数の例

`department_id` でグループ化し、`salary` 列の最大値を照会します。

```sql
obclient> SELECT department_id,last_name,salary,
                 MAX(salary) OVER (PARTITION BY department_id) AS rmax_sal
          FROM employees;
+---------------+-----------+--------+----------+
| DEPARTMENT_ID | LAST_NAME | SALARY | RMAX_SAL |
+---------------+-----------+--------+----------+
|            30 | Raphaely  |   1700 |    11000 |
|            30 | De Haan   |  11000 |    11000 |
|            40 | Errazuriz |   1400 |     1400 |
|            50 | Hartstein |  14000 |    14000 |
|            50 | Raphaely  |   1700 |    14000 |
|            50 | Weiss     |  13500 |    14000 |
|            90 | Russell   |  13000 |    14000 |
|            90 | Partners  |  14000 |    14000 |
+---------------+-----------+--------+----------+
8 rows in set
```
