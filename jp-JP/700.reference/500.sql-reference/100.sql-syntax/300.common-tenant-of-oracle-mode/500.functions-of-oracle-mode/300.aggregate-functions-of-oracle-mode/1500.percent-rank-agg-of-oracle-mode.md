# PERCENT_RANK

## 説明

この関数は、一連の値における特定の値の累積分布を計算します。<code>CUME_DIST</code> 関数と類似しています。この関数は集約関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>集約関数として、<code>PERCENT_RANK</code> はある数が集合内で占める割合の順位を計算し、戻り値の範囲は (0, 1] です。<code>N</code> 行のデータがあり、<code>expr</code> の値が2番目の行の値より大きく3番目の行の値より小さい場合、その位置の割合は <code>2/N</code> に等しくなります。定数パラメータ式と <code>ORDER BY</code> 集約句内の式は位置が一致する必要があります。したがって、パラメータの数は同じでなければならず、型も互換性がなければなりません。指定した値がグループ化されたシーケンス内の他の値と重複する場合、2つの同一の値は1つの値として処理されます。</li>
    <li>分析関数として、<code>PERCENT_RANK</code> は、特定の列または列の組み合わせに対する各行の割合順位を計算し、戻り値の範囲は [0, 1] です。同じ順位値が存在する場合、同じランキングが付与され、値が同じ行数は次のランキングに記録されます。任意の集合における最初の行の <code>PERCENT_RANK</code> 関数は <code>0</code> です。位置の割合の計算式は、位置の割合 = 序号 / 最大序号 です。具体的な例は以下の表を参照してください：</li>
    </ul>
  </main>

| N | # | 割合 |
|---|----|-------|
| A | 0  | 0     |
| B | 1  | 0.25  |
| C | 2  | 0.5   |
| D | 3  | 0.75  |
| E | 4  | 1     |

## 構文

```sql
/*集計構文*/
PERCENT_RANK(expr [, expr ...]) WITHIN GROUP
               ( ORDER BY expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
                          [,expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
               )

/*分析構文*/
PERCENT_RANK( ) OVER ([query_partition_clause] order_by_clause)
```

## パラメータの説明

|           パラメータ            |                                                                                                            説明                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | クエリ対象の値を指定します。                                                                                                                                                                                                                 |
| expr_col                | クエリ対象の値に対応する列名を指定します。                                                                                                                                                                                                            |
| DESC \| ASC             | リストのソート方法を指定します（オプション）。 <ul><li> `ASC` は昇順で、デフォルト値です。   </li><li> `DESC` は降順です。 </li></ul>                                                                |
| NULLS { FIRST \| LAST } | ソート後の `expr_col` 内の `NULL` 値の位置を指定します（オプション）。 <ul><li> `NULLS FIRST` は、`NULL` 値を非NULL値の前に配置します。   </li><li> `NULLS LAST` は、`NULL` 値を非NULL値の後に配置します。これがデフォルト値です。</li></ul>    |
| OVER                    | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                  |

## 戻り値の型

`NUMBER` データ型を返します。

### 集計関数の例

列 `sal` 内で `3300` の位置の割合を返します。

```sql
obclient> SELECT PERCENT_RANK(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+-------------------------------------------+
| PERCENT_RANK(3300)WITHINGROUP(ORDERBYSAL) |
+-------------------------------------------+
|                                        .8 |
+-------------------------------------------+
1 row in set
```
