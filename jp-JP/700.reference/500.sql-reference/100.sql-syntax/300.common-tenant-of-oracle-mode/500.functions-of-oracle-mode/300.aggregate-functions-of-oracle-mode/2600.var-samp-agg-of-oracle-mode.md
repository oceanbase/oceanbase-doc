# VAR_SAMP

## 説明

この関数は、一連の数値の集合における標本分散を返します（`NULL` 値は無視されます）。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
VAR_SAMP(expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

| パラメータ |                                           説明                                            |
|------|-----------------------------------------------------------------------------------------|
| expr | 計算に使用する数値式を指定します。数値データ型、または暗黙的に数値データ型へ変換できる値が必要です。                                                  |
| OVER | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この関数を空集合に適用すると、<code>NULL</code> を返します。戻り値の計算式は次のとおりです：<code>(SUM(expr - (SUM(expr) / COUNT(expr)))²) /(COUNT(expr) - 1)</code>。</p>
  </main>

## 戻り値の型

パラメータ `expr` と同じデータ型、または `NULL` を返します。

|    2 | B4   |   11 |   16 |

|    3 | C2   |    9 |   16 |

### 集計関数の例

列 `col4` の標本分散を計算します。

```sql
obclient> SELECT VAR_SAMP(col4) FROM tbl1;
+----------------+
| VAR_SAMP(COL4) |
+----------------+
|              6 |
+----------------+
1 row in set
```
