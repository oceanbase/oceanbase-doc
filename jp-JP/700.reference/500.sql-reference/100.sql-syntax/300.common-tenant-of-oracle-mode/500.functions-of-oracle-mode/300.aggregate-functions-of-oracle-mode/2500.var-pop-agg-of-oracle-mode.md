# VAR_POP

## 説明

この関数は、一連の数値集合の全分散（`NULL` を無視）を返します。この関数は集計関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行う必要があります。これは、一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果として1つの値しか返せません。この場合、<code>OVER</code> 句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
VAR_POP(expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

| パラメータ |                                           説明                                            |
|------|-----------------------------------------------------------------------------------------|
| expr | 計算に参加する数値式を指定します。数値データ型または暗黙的に数値データ型に変換できる値に該当します。                                                  |
| OVER | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この関数が空集合に適用される場合、<code>NULL</code> を返します。結果の計算式は次のとおりです：<code>SUM((expr - (SUM(expr) / COUNT(expr)))²)/ COUNT(expr)</code>。</p>
  </main>

## 返り値の型

引数 `expr` と同じデータ型、または `NULL` を返します。

### 集計関数の例

列 `col4` の全分散を計算します。

```sql
obclient> SELECT VAR_POP(col4) FROM tbl1;
+------------------------------------------+
| VAR_POP(COL4)                            |
+------------------------------------------+
| 5.53846153846153846153846153846153846154 |
+------------------------------------------+
1 row in set
```
