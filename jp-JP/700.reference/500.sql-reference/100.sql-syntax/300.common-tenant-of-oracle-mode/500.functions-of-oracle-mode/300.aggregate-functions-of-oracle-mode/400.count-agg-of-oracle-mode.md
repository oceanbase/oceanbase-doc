# COUNT

## 説明

この関数は、`expr` の行数を返します。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
COUNT({ * | [ DISTINCT | UNIQUE | ALL ] expr }) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                            説明                                                                                                                             |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \*                        | 条件を満たすすべての行を返し、重複行とNULL行を含みます。                                                                                                                                                                                                                                   |
| DISTINCT \| UNIQUE \| ALL | クエリ時の重複除去の有無。オプションで、デフォルト値は `ALL` です。 <ul><li> `ALL`：重複行を含むすべての値を返し、NULL行は無視します。   </li><li> `DISTINCT`：重複行を除去し、NULL行を無視して行を返します。   </li><li> `UNIQUE`：重複行を除去し、NULL行を無視して行を返します。</li></ul>    |
| expr                      | 計算に参加する列名を指定します。                                                                                                                                                                                                                                                |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                   |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li><code>COUNT</code> 関数は、<code>NULL</code> を返すことはありません。<code>expr</code> を指定した場合、<code>expr</code> が <code>NULL</code> ではない統計数を返します。<code>COUNT(*)</code> を指定した場合、すべての行の統計数を返します。パラメータ <code>DISTINCT</code>、<code>UNIQUE</code> または <code>ALL</code> を使用する場合は、<code>expr</code> とスペースで区切る必要があります。</li>
    <li><code>DISTINCT</code> または <code>UNIQUE</code> キーワードを指定した場合、<code>analytic_clause</code> 内に <code>order_by_clause</code> および <code>windowing_clause</code> を含めることはできません。</li>
    </ul>
  </main>

## 戻り値の型

自然数を返します。

## 例

テーブル `tbl1` を作成し、テストデータを挿入します。

```sql
obclient> CREATE TABLE tbl1 (col1 INT,col2 varchar(10),col3 INT);
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES
    (1,'aa',10),(2,'bb',12),(3,'cc',15),(4,'dd',18),(5,'ee',20),
    (6,'ff',23),(7,'gg',25),(8,'hh',30),(9,'ii',40),(10,'jj',15),
    (11,'kk',NULL),(12,'oo',NULL);
Query OK, 12 rows affected
Records: 12  Duplicates: 0  Warnings: 0

obclient> SELECT * FROM tbl1;
+------+------+------+
| COL1 | COL2 | COL3 |
+------+------+------+
|    1 | aa   |   10 |
|    2 | bb   |   12 |
|    3 | cc   |   15 |
|    4 | dd   |   18 |
|    5 | ee   |   20 |
|    6 | ff   |   23 |
|    7 | gg   |   25 |

12 rows in set
```

### 集計関数の例

テーブル `tbl1` の列 `col3` のNULL以外の行数とテーブル `tbl1` の総行数を求めます。

```sql
obclient> SELECT COUNT(col3),COUNT(*) FROM tbl1;
+-------------+----------+
| COUNT(COL3) | COUNT(*) |
+-------------+----------+
|          10 |       12 |
+-------------+----------+
1 row in set
```

### 分析関数の例

テーブル `tbl1` 内で、`col3` の値でソートされた後、オフセットが `1` から `3` の範囲内にある行の数を求めます。

```sql
obclient> SELECT col1,col2,
                 COUNT(*) OVER (ORDER BY col3 RANGE BETWEEN 1 PRECEDING AND 3 FOLLOWING) AS mov_count
          FROM tbl1;
+------+------+-----------+
| COL1 | COL2 | MOV_COUNT |
+------+------+-----------+
|    1 | aa   |         2 |
|    2 | bb   |         3 |
|    3 | cc   |         3 |
|   10 | jj   |         3 |
|    4 | dd   |         2 |
|    5 | ee   |         2 |
|    6 | ff   |         2 |
|    7 | gg   |         1 |
|    8 | hh   |         1 |
|    9 | ii   |         1 |
|   11 | kk   |         2 |
|   12 | oo   |         2 |
+------+------+-----------+
12 rows in set
```
