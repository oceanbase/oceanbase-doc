# STDDEV_SAMP

## 説明

この関数は、数値データをパラメータとして受け取り、標本標準偏差を計算します。標本標準偏差とは、標本分散の算術平方根です。`STDDEV_SAMP` と関数 `STDDEV` の違いは、`STDDEV` が入力データが1行のみの場合に `0` を返すのに対し、`STDDEV_SAMP` は `NULL` を返す点です。集約または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集約関数として使用する場合、この関数は一連の行の集合に対して集約計算を行い、結果は1つの値のみを返すため、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
STDDEV_SAMP([ALL] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|  パラメータ  |                                           説明                                            |
|------|-----------------------------------------------------------------------------------------|
| ALL  | すべての数値列。オプションです。デフォルト値は `ALL` です。                                                                   |
| expr | 数値型（`NUMBER`、`FLOAT`、`BINARY_FLOAT` および `BINARY_DOUBLE`）または数値型に変換可能な式。                 |
| OVER | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。 |

## 戻り値の型

戻り値の型は、パラメータ `expr` のデータ型と同じです。

### 集約関数の例

列 `salary` の標準偏差を求めます。

```sql
obclient> SELECT STDDEV_SAMP(salary) FROM employees;
+-------------------------------------------+
| STDDEV_SAMP(SALARY)                       |
+-------------------------------------------+
| 6026.474330580265330900400184969999384459 |
+-------------------------------------------+
1 row in set
```

### 分析関数の例

`department_id` 列でグループ化し、`hiredate` 列で昇順に並べ替えた上で、`salary` 列の標準偏差を求めます。

```sql
obclient> SELECT department_id, last_name, hiredate, salary,
                 STDDEV_SAMP(salary) OVER (PARTITION BY department_id
                  ORDER BY hiredate ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS s_samp
          FROM employees;
+---------------+-----------+------------+--------+-------------------------------------------+
| DEPARTMENT_ID | LAST_NAME | HIREDATE   | SALARY | S_SAMP                                    |
+---------------+-----------+------------+--------+-------------------------------------------+
|            30 | Raphaely  | 2017-07-01 |   1700 |                                      NULL |
|            30 | De Haan   | 2018-05-01 |  11000 | 6576.093065034891976927852567575096065349 |
|            40 | Errazuriz | 2017-07-21 |   1400 |                                      NULL |
|            50 | Raphaely  | 2017-07-22 |   1700 |                                      NULL |
|            50 | Hartstein | 2019-10-05 |  14000 | 8697.413408594534550130385653889643183203 |
|            50 | Weiss     | 2019-10-05 |  13500 | 6961.561127601576503543602300090640831831 |
```
