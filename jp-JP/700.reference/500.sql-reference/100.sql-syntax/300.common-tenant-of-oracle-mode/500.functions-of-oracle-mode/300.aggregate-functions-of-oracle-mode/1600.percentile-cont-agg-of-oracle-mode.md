# PERCENTILE_CONT

## 説明

この関数は、連続分布モデルを仮定した逆分布関数です。指定されたパーセンタイル値とソート規範に基づき、そのソート規範の指定されたパーセンタイル値に対応する内挿値を返します。計算ではNULL値は無視されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集約関数として使用する場合、この関数は一連の行の集合に対して集約計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
PERCENTILE_CONT(percentile) WITHIN GROUP (ORDER BY expr [ DESC | ASC ])
[ OVER (query_partition_clause) ]
```

## パラメータの説明

|     パラメータ      |                                                                             説明                                                                              |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| percentile  | 指定するパーセンタイル値で、数値データ型の定数です。値の範囲は \[0,1\] です。 <br>**説明**  `MEDIAN` 関数は、`percentile` が `0.5` の特別な場合に相当します。                                     |
| expr        | ソート規範を指定する式で、データ型は数値型または日付時刻型である必要があります。 <br>**注意**  `expr` は列参照を含む単一の式でなければならず、複数の式の使用は許可されません。                                                     |
| DESC \| ASC | リストのソート方法を指定するオプションです。 <ul><li> `ASC` は昇順ソートで、デフォルト値です。    </li><li> `DESC` は降順ソートです。</li> </ul>   |
| OVER        | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                     |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この関数は、ソート規範に従って行をソートした後、指定されたパーセンタイル値 <code>(P)</code> と非NULL行数 <code>(N)</code> を用いて行番号を計算します。行番号の計算式は <code>RN = (1+ (P*(N-1))</code> です。最終的な結果は、行番号 <code>CRN = CEILING(RN)</code> と <code>FRN = FLOOR(RN)</code> の行の値に対して線形内挿により計算されます。最終的な結果は次のとおりになります：</p>
  </main>

もし `(CRN = FRN = RN)` ならば、結果は `(value of expression from row at RN)` となります。それ以外の場合、結果は次のとおりです：

`(CRN - RN) * (value of expression for row at FRN) + (RN - FRN) * (value of expression for row at CRN)`。

## 戻り値の型

パラメータ `expr` と同じデータ型を返します。

## 例

既に作成済みのテーブル `tbl1` があります。

```sql
obclient> SELECT * FROM tbl1;
+------+------+------+------+
| COL1 | COL2 | COL3 | COL4 |
+------+------+------+------+
|    1 | A1   |    8 |   12 |
|    1 | A2   |   10 |   15 |
|    1 | A3   |   11 |   16 |
|    2 | B1   |    9 |   14 |
|    2 | B2   |   10 |   15 |
|    2 | B3   |    8 |   13 |
|    2 | B4   |   11 |   16 |
|    3 | C1   |    8 |   18 |
|    3 | C2   |    9 |   16 |
|    3 | C3   |   10 |   15 |
|    3 | C4   |   11 |   12 |
|    3 | C5   |   12 |   10 |

12 rows in set
```

### 集計関数の例

列 `col4` の10パーセンタイル値を計算します。

```sql
obclient> SELECT PERCENTILE_CONT(0.1) WITHIN GROUP (ORDER BY col4) FROM tbl1;
+----------------------------------------------+
| PERCENTILE_CONT(0.1)WITHINGROUP(ORDERBYCOL4) |
+----------------------------------------------+
|                                           12 |
+----------------------------------------------+
1 row in set
```

### 分析関数の例
