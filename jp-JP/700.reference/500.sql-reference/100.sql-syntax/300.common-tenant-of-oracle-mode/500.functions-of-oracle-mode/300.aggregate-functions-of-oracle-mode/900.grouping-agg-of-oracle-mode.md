# GROUPING

## 説明

この関数は、`GROUP BY` 句の拡張（例：`ROLLUP`）によって生成されたスーパーグループ化行内の `NULL` 値と通常行内の `NULL` 値を区別します。この関数は、スーパーグループ化行内の `NULL` 値に対して `1` を返し、通常行内の値に対して `0` を返します。

## 構文

```sql
GROUPING(expr)
```

## パラメータの説明

パラメータ `expr` は `GROUP BY` 句内の式です。

## 戻り値の型

`NUMBER` データ型を返します。

## 例

テーブル `tbl1` を作成し、データを挿入します。列 `col2` と列 `col3` でグループ化し、`ROLLUP` 句を使用して生成される集計行と通常のレコードをクエリします。
