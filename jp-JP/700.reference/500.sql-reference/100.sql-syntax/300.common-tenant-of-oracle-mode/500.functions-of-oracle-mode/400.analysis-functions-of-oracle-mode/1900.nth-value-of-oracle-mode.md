# NTH_VALUE

## 説明

この関数は、`analytic_clause` で定義されたウィンドウ内の `n` 行目の `measure_expr` の値を返します。

## 構文

```sql
NTH_VALUE (measure_expr, n)
  [ FROM { FIRST | LAST } ][ { RESPECT | IGNORE } NULLS ]
OVER (analytic_clause)
```

## パラメータの説明

|            パラメータ             |                                                                                                           説明                                                                                                            |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| measure_expr              | 戻り値として返すフィールドを指定します。                                                                                                                                                                                                              |
| n                         | 測定値のうち、`n` 番目の行を返します。`n` は正の整数です。 **注意**  <ul><li> `n` が `NULL` の場合、関数はエラーを返します。   </li><li> `n` がウィンドウ内の行数より大きい場合、関数は `NULL` を返します。</li></ul>    |
| FROM { FIRST \| LAST }    | 計算の開始行を指定します。オプションで、デフォルトは `FROM FIRST` です。 <ul><li> `FROM FIRST` は、ウィンドウの最初の行から計算を開始することを意味します。   </li><li> `FROM LAST` は、最後の行から計算を開始することを意味します。</li></ul>                             |
| {RESPECT \| IGNORE} NULLS | `NULL` 値を無視するかどうかを指定します。オプションで、デフォルトは `RESPECT NULLS` です。 <ul><li> `RESPECT NULLS` は、`NULL` 値を無視しないことを意味します。   </li><li> `IGNORE NULLS` は、`NULL` 値を無視することを意味します。</li></ul>      |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                 |

## 戻り値の型

戻り値の型は、パラメータ `measure_expr` のデータ型と同じです。
