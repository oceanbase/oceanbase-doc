# COVAR_POP

## 説明

この関数は、一連の数値ペアの全体的な共分散を計算するために使用されます。この関数は集約または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code>句を使用してウィンドウを定義し、計算を行う必要があります。これは、行の集合に対して計算を実行し、複数の値を返します。</li>
    <li>集約関数として使用する場合、この関数は行の集合に対して集約計算を実行し、結果として1つの値しか返せません。この場合、<code>OVER</code>句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
COVAR_POP(expr1, expr2)[ OVER (analytic_clause) ]
```

## パラメータの説明

| パラメータ |                                           説明                                            |
|-------|-----------------------------------------------------------------------------------------|
| expr1 | 最初の数値式を指定します。数値データ型に属するか、暗黙的に数値データ型に変換できる値です。                                                    |
| expr2 | 2 番目の数値式を指定します。数値データ型に属するか、暗黙的に数値データ型に変換できる値です。                                                    |
| OVER  | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>データベースは、最も高い数値優先順位を持つパラメータを特定し、他のパラメータをそのデータ型に暗黙的に変換して返します。</li>
    <li>パラメータ <code>expr1</code> と <code>expr2</code> の位置は、返される結果に影響しません。つまり、<code>COVAR_POP(expr1, expr2)</code> は <code>COVAR_POP(expr2, expr1)</code> と等しくなります。</li>
    <li>返される結果の計算式は次のとおりです：<code>(SUM(expr1 * expr2) - SUM(expr2) * SUM(expr1) / n) / n</code> ここで、<code>n</code> は(<code>expr1</code>,<code>expr2</code>)式ペアの数であり、<code>expr1</code> と <code>expr2</code> はどちらも空ではありません。</li>
    </ul>
  </main>

## 返り値の型

いずれかのパラメータが空の場合、`NULL` を返します。それ以外の場合は、`NUMBER` 型の値を返します。

## 例

既に作成されたテーブル `tbl1` があります。

```sql
obclient> SELECT * FROM tbl1;
+------+------+------+------+
| COL1 | COL2 | COL3 | COL4 |
+------+------+------+------+
|    1 | A1   |    8 |   12 |
|    1 | A2   |   10 |   15 |
|    1 | A3   |   11 |   16 |
|    2 | B1   |    9 |   14 |
|    2 | B2   |   10 |   15 |
|    2 | B3   |    8 |   13 |
|    2 | B4   |   11 |   16 |
|    3 | C1   |    8 |   18 |
|    3 | C2   |    9 |   16 |
|    3 | C3   |   10 |   15 |
|    3 | C4   |   11 |   12 |
|    3 | C5   |   12 |   10 |
+------+------+------+------+
12 rows in set
```

### 集約関数の例

数値型の `col3` 列と `col4` 列の全体的な共分散を計算します。

```sql
obclient> SELECT COVAR_POP(col3,col4) FROM tbl1;
+----------------------+
| COVAR_POP(COL3,COL4) |
+----------------------+
|                 -.75 |
+----------------------+
1 row in set
```

### 分析関数の例

`col1` 列でグループ化し、`col2` 列でソートして、数値型の `col3` 列のデータと `col4` 列の累積全体的な共分散を計算します。

```sql
obclient> SELECT col1,col3,col4,
            COVAR_POP(col3,col4) OVER(PARTITION BY col1 ORDER BY col2) "COVAR_POP"
          FROM tbl1;
+------+------+------+-------------------------------------------+
| COL1 | COL3 | COL4 | COVAR_POP                                 |
+------+------+------+-------------------------------------------+
|    1 |    8 |   12 |                                         0 |
|    1 |   10 |   15 |                                       1.5 |
|    1 |   11 |   16 |    2.111111111111111111111111111111111111 |
|    2 |    9 |   14 |                                         0 |
|    2 |   10 |   15 |                                       .25 |
|    2 |    8 |   13 | .6666666666666666666666666666666666666667 |
|    2 |   11 |   16 |                                      1.25 |
|    3 |    8 |   18 |                                         0 |
|    3 |    9 |   16 |                                       -.5 |
|    3 |   10 |   15 |                                        -1 |
|    3 |   11 |   12 |                                    -2.375 |
|    3 |   12 |   10 |                                        -4 |
+------+------+------+-------------------------------------------+
12 rows in set
```
