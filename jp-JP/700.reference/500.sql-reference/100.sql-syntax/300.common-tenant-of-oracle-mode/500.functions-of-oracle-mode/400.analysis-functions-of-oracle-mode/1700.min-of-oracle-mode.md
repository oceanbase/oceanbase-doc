# MIN

## 説明

この関数は、パラメータで指定された列の最小値を返します。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
MIN([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|          **パラメータ**           |                                                                                                                                         **説明**                                                                                                                                          |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時の重複除去を指定します。オプションです。デフォルト値は `ALL` です。 <ul><li> `ALL`：重複行を含むすべての値を返し、`NULL` 値の行は無視します。   </li><li> `DISTINCT`：返される行から重複行を除外し、`NULL` 値の行は無視します。   </li><li> `UNIQUE`：返される行から重複行を除外し、`NULL` 値の行は無視します。</li></ul>    |
| expr                      | 数値、文字、日付、その他のデータ型の列または式です。                                                                                                                                                                                                                                                               |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                                 |

## 戻り値の型

`expr` と同じデータ型の値を返します。

既に作成済みのテーブル `employees` があります。

```sql
obclient> SELECT * FROM employees;
+---------------+------------+-----------+------------+--------+
| DEPARTMENT_ID | MANAGER_ID | LAST_NAME | HIREDATE   | SALARY |

|            30 |        100 | Raphaely  | 2017-07-01 |   1700 |
|            30 |        100 | De Haan   | 2018-05-01 |  11000 |
|            40 |        100 | Errazuriz | 2017-07-21 |   1400 |
```

### 集計関数の例

`salary` 列の最小値を照会します。

```sql
obclient> SELECT MIN(salary)  FROM employees;
+-------------+
| MIN(SALARY) |
+-------------+
|        1400 |
+-------------+
1 row in set
```

### 分析関数の例

`department_id` 列でグループ化し、`salary` 列の最小値を照会します。

```sql
obclient> SELECT department_id,last_name,hiredate,salary,
                 MIN(salary) OVER(PARTITION BY department_id) AS p_cmin
          FROM employees;
+---------------+-----------+------------+--------+--------+
| DEPARTMENT_ID | LAST_NAME | HIREDATE   | SALARY | P_CMIN |
+---------------+-----------+------------+--------+--------+
|            30 | Raphaely  | 2017-07-01 |   1700 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |   1700 |
|            40 | Errazuriz | 2017-07-21 |   1400 |   1400 |
|            50 | Hartstein | 2019-10-05 |  14000 |   1700 |
|            50 | Raphaely  | 2017-07-22 |   1700 |   1700 |
|            50 | Weiss     | 2019-10-05 |  13500 |   1700 |
|            90 | Russell   | 2019-07-11 |  13000 |  13000 |
```
