# SUM

## 説明

この関数は、指定されたパラメータの合計を返します。集約関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集約関数として使用する場合、この関数は一連の行の集合に対して集約計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
SUM([ DISTINCT | UNQIUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                                      説明                                                                                                                                       |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNQIUE \| ALL | 計算時に重複を除外するかどうかを指定します。オプションで、デフォルト値は `ALL` です。 <ul><li> `ALL`：重複行を含むすべての値を計算し、`NULL` 値の行は無視します。   </li><li> `DISTINCT`：重複行を除外し、`NULL` 値の行は無視します。   </li><li> `UNIQUE`：重複行を除外し、`NULL` 値の行は無視します。 </li></ul>   |
| expr                      | 数値データ型、または数値データ型へ暗黙的に変換可能な式。                                                                                                                                                                                                                                                   |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                       |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DISTINCT</code> または <code>UNIQUE</code> キーワードを指定した場合、<code>analytic_clause</code> には <code>order_by_clause</code> および <code>windowing_clause</code> パラメータを指定できません。</p>
  </main>

## 戻り値の型

`expr` と同じデータ型の値を返します。

### 集計関数の例

テーブル `employees` の列 `salary` の合計を求めます。

```sql
obclient> SELECT SUM(salary) FROM employees;
+-------------+
| SUM(SALARY) |
+-------------+
|       70300 |
+-------------+
1 row in set
```

### 分析関数の例

列 `department_id` でグループ化し、列 `salary` の昇順でソートして、列 `salary` の累積合計を返します。

```sql
obclient> SELECT department_id, last_name, salary,
              SUM(salary) OVER
                  (PARTITION BY department_id ORDER BY salary RANGE UNBOUNDED PRECEDING) s_sum
    FROM employees
    ORDER BY department_id,s_sum;
+---------------+-----------+--------+-------+
| DEPARTMENT_ID | LAST_NAME | SALARY | S_SUM |
+---------------+-----------+--------+-------+
|            30 | Raphaely  |   1700 |  1700 |
|            30 | De Haan   |  11000 | 12700 |
|            40 | Errazuriz |   1400 |  1400 |
|            50 | Raphaely  |   1700 |  1700 |
|            50 | Weiss     |  13500 | 15200 |
|            50 | Hartstein |  14000 | 29200 |
|            90 | Russell   |  13000 | 13000 |
|            90 | Partners  |  14000 | 27000 |
+---------------+-----------+--------+-------+
8 rows in set
```
