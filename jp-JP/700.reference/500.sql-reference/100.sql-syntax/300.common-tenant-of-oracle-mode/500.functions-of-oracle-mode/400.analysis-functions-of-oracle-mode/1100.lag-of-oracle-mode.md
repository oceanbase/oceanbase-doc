# LAG

## 説明

この関数は分析関数であり、クエリ内で同一フィールドの最初の `offset` 行のデータを独立した列としてテーブルに格納します。この操作は、テーブルの自己結合に代わるものとなります。

## 構文

```sql
LAG { (value_expr [,offset [,default]]) [{ RESPECT|IGNORE } NULLS ]
    | (value_expr [{ RESPECT|IGNORE } NULLS ] [,offset [,default] ])
    }
OVER([query_partition_clause] order_by_clause)
```

## パラメータの説明

|            パラメータ             |                                                                                                          説明                                                                                                           |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| value_expr                | クエリ対象のフィールドを指定します。 <br>**注意**  `LAG` 関数や他の分析関数を `value_expr` 内にネストすることはできません。                                                                                                                              |
| offset                    | `value_expr` のオフセット量を指定します。0より大きい整数で、オプションです。デフォルト値は `1` です。                                                                                                                                                                        |
| default                   | 条件に合致しない場合のデフォルト値を指定します。オフセットがウィンドウの範囲を超えた場合、`default` の値を返します。オプションです。デフォルト値は `NULL` です。                                                                                                                                                          |
| {RESPECT \| IGNORE} NULLS | `NULL` 値を無視するかどうかを示します。オプションです。デフォルト値は `RESPECT NULLS` です。 <ul><li> `RESPECT NULLS` は `NULL` 値を無視しないことを意味します。   </li><li> `IGNORE NULLS` は `NULL` 値を無視することを意味します。</li></ul>    |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                               |

## 戻り値の型

戻り値のデータ型は制限されません。
