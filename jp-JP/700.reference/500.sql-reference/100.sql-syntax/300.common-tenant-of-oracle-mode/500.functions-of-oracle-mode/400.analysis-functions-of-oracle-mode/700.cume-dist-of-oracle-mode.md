# CUME_DIST

## 説明

この関数は、一連の値の中で特定の値の累積分布を計算し、(0,1]の範囲の値を返します。この関数は集約関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として、この関数は指定された値が一連の値の中でどの程度の相対的な位置にあるかを計算します。行<code>row</code>について、昇順に並べ替えた場合、<code>row</code>の<code>cume_dist</code>は、<code>row</code>の値以下の値を持つ行数を、計算対象の行数（クエリ結果セット全体またはパーティション）で割ったものです。</li>
    <li>集約関数として、この関数のパラメータは各集約グループ内の仮想的な単一行を識別します。したがって、それらはすべて各集約グループ内の定数式として計算されなければなりません。定数パラメータ式と<code>ORDER BY</code>集約句内の式は位置が一致します。そのため、パラメータの数は同じでなければならず、型も互換性が必要です。指定された値がグループ化シーケンス内の他の値と重複する場合、2つの重複する値は1つの値として処理されます。</li>
    </ul>
  </main>

## 構文

```sql
/*集約構文*/
CUME_DIST( expr[,expr]...)
  WITHIN GROUP (ORDER BY expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
                       [,expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
          )

/*分析構文*/
CUME_DIST() OVER ([ query_partition_clause ] order_by_clause)
```

## パラメータの説明

|           パラメータ            |                                                                                                            説明                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | クエリ対象の値を指定します。                                                                                                                                                                                                                 |
| expr_col                | クエリ対象の値に対応する列名を指定します。                                                                                                                                                                                                            |
| DESC \| ASC             | 列のソート方法を指定します。オプションです。 <ul><li> `ASC` は昇順ソートで、デフォルト値です。   </li><li> `DESC` は降順ソートです。</li></ul>                                                                 |
| NULLS { FIRST \| LAST } | ソート後の `expr_col` 内の `NULL` 値の位置を指定します。オプションです。 <ul><li> `NULLS FIRST` は `NULL` 値を非NULL値の前に配置します。   </li><li> `NULLS LAST` は `NULL` 値を非NULL値の後ろに配置します。デフォルト値です。</li></ul>    |
| OVER                    | `OVER` 句を使用してウィンドウを定義し、計算を行います。[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                  |

## 戻り値の型

戻り値の型は `NUMBER` です。

### 集計関数の例

列 `sal` 内で `3300` の位置を返します。

```sql
obclient> SELECT CUME_DIST(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+----------------------------------------+
| CUME_DIST(3300)WITHINGROUP(ORDERBYSAL) |
+----------------------------------------+
|                                  .9375 |
+----------------------------------------+
1 row in set
```
