# STDDEV

## 説明

この関数は、一連の数値データの標準偏差を計算するために使用されます。関数 `STDDEV_SAMP` との違いは、`STDDEV` が入力データが1行の場合に `0` を返すのに対し、`STDDEV_SAMP` は NULL を返すことです。OceanBaseデータベースにおける標準偏差の値は、関数 `VARIANCE` によって計算された分散の算術的平方根です。集計または分析関数として使用できます。
  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義して計算する必要があります。これは、一連の行の集合に対して計算を実行し、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を実行し、結果として1つの値しか返せません。この場合、<code>OVER</code> 句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
STDDEV([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                         説明                                                                                                                          |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時に重複を除外するかどうか。オプションで、デフォルト値は `ALL` です。 <ul><li> `ALL`：すべての数値型列。   </li><li> `DISTINCT`：重複を除外するキーワードで、一意な値の全体的な標準偏差を計算します。   </li><li> `UNIQUE`：重複を除外するキーワードで、一意な値の全体的な標準偏差を計算します。</li></ul>    |
| expr                      | 数値型または数値型に変換可能な値。                                                                                                                                                                                                                                  |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                             |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DISTINCT</code>または<code>UNIQUE</code>キーワードを指定した場合、<code>analytic_clause</code>には<code>order_by_clause</code>と<code>windowing_clause</code>を含めることはできません。</p>
  </main>

## 返り値の型

`NUMBER` 型のデータを返します。

既に作成されたテーブル`employees`があります。

```sql
obclient> SELECT * FROM employees;

|            30 | Raphaely  | 2017-07-01 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |
|            40 | Errazuriz | 2017-07-21 |   1400 |
|            50 | Hartstein | 2019-10-05 |  14000 |
|            50 | Raphaely  | 2017-07-22 |   1700 |
```

### 集計関数の例

列 `salary` の標準偏差を計算します。

```sql
obclient> SELECT STDDEV(salary) FROM employees;
+-------------------------------------------+
| STDDEV(SALARY)                            |
+-------------------------------------------+
| 6026.474330580265330900400184969999384459 |
+-------------------------------------------+
1 row in set
```

### 分析関数の例

列 `hiredate` で昇順にソートし、列 `salary` の累積標準偏差を計算します。
