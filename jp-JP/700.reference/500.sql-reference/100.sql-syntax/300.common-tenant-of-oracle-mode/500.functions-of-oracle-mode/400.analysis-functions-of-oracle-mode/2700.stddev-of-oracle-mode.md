# STDDEV

## 説明

この関数は、一連の数値データの標準偏差を計算します。`STDDEV_SAMP` 関数との違いは、`STDDEV` が入力データが1行のみの場合に `0` を返すのに対し、`STDDEV_SAMP` は NULL を返す点です。OceanBase データベースでは、標準偏差の値は関数 `VARIANCE` で計算された分散の算術平方根です。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を実行する必要があります。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返すため、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
STDDEV([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                         説明                                                                                                                          |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時の重複除去を指定します。オプションで、デフォルト値は `ALL` です。 <ul><li> `ALL`：すべての数値列。</li><li> `DISTINCT`：重複除去キーワード。一意の値の全体の標準偏差を計算することを示します。</li><li> `UNIQUE`：重複除去キーワード。一意の値の全体の標準偏差を計算することを示します。</li></ul>    |
| expr                      | 数値型または数値型に変換可能な値。</p> |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                             |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DISTINCT</code> または <code>UNIQUE</code> キーワードを指定した場合、<code>analytic_clause</code> 内に <code>order_by_clause</code> および <code>windowing_clause</code> を記述することはできません。</p>
  </main>

## 戻り値の型

`NUMBER` 型のデータを返します。

既に作成済みのテーブル`employees`があります。

```sql
obclient> SELECT * FROM employees;

|            30 | Raphaely  | 2017-07-01 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |
|            40 | Errazuriz | 2017-07-21 |   1400 |
```

### 集計関数の例

列 `salary` の標準偏差を計算します。

```sql
obclient> SELECT STDDEV(salary) FROM employees;
+-------------------------------------------+
| STDDEV(SALARY)                            |
+-------------------------------------------+
| 6026.474330580265330900400184969999384459 |
+-------------------------------------------+
1 row in set
```

### 分析関数の例

列 `hiredate` の昇順でソートし、列 `salary` の累積標準偏差を計算します。
