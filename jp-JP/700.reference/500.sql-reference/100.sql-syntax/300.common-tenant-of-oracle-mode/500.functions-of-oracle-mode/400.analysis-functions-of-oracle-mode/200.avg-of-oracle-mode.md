# AVG

## 説明

この関数は、数値型または数値型に変換可能な式をパラメータとして平均値を求めます。集計関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code>句を使用してウィンドウを定義し、計算を行う必要があります。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果として1つの値しか返せません。この場合、<code>OVER</code>句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
AVG([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                                                説明                                                                                                                                                |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時に重複を除外するかどうか。オプションであり、デフォルト値は `ALL` です。 <ul><li> `ALL`：クエリ時にデータ内の重複値を削除せず、データ内の `NULL` 値を無視します。   </li><li> `DISTINCT`：クエリ時にデータ内の重複値を削除し、データ内の `NULL` 値を無視します。   </li><li> `UNIQUE`：クエリ時にデータ内の重複値を削除し、データ内の `NULL` 値を無視します。</li></ul>    |
| expr                      | 計算対象の列名を指定します。列のデータ型は数値型、または数値型に変換可能な式です。数値型としては `NUMBER`、`FLOAT`、`BINARY_FLOAT`、または `BINARY_DOUBLE` が使用できます。                                                                                                                                                                                                   |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                                          |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DISTINCT</code>または<code>UNIQUE</code>キーワードを指定した場合、<code>analytic_clause</code>に<code>order_by_clause</code>および<code>windowing_clause</code>を含めることはできません。</p>
  </main>

## 返り値

返り値は、パラメータ `expr` のデータ型と同じです。

## 例

テーブル `tbl1` を作成し、テストデータを挿入します。

```sql
obclient> CREATE TABLE tbl1 (col1 INT,col2 varchar(10),col3 INT);
Query OK, 0 rows affected

obclient> INSERT INTO tbl1 VALUES (1,'a',5),(1,'b',10),(1,'c',15),
    (2,'d',20),(2,'e',18),(2,'f',12),(3,'a',10),
    (3,'b',15),(4,'c',15),(4,'a',8);
Query OK, 10 rows affected
Records: 10  Duplicates: 0  Warnings: 0

obclient> SELECT * FROM tbl1;
+------+------+------+
| COL1 | COL2 | COL3 |
+------+------+------+
|    1 | a    |    5 |
|    1 | b    |   10 |
|    1 | c    |   15 |
|    2 | d    |   20 |
|    2 | e    |   18 |
|    2 | f    |   12 |
|    3 | a    |   10 |
|    3 | b    |   15 |
|    4 | c    |   15 |
|    4 | a    |    8 |
+------+------+------+
10 rows in set
```

### 集計関数の例

`col3` の平均値を計算します。

```sql
obclient> SELECT AVG(col3) FROM tbl1;
+-----------+
| AVG(COL3) |
+-----------+
|      12.8 |
+-----------+
1 row in set
```

### 分析関数の例

`col1` でグループ化し、`col2` 列を昇順にソートして、`col3` 列の値の前後の範囲の平均値を計算します。

```sql
obclient> SELECT col1,col2,col3, AVG(col3)
              OVER (PARTITION BY col1 ORDER BY col2 ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING) AS over_col2
          FROM tbl1
          ORDER BY col1,col2,col3;
+------+------+------+-------------------------------------------+
| COL1 | COL2 | COL3 | OVER_COL2                                 |
+------+------+------+-------------------------------------------+
|    1 | a    |    5 |                                       7.5 |
|    1 | b    |   10 |                                        10 |
|    1 | c    |   15 |                                      12.5 |
|    2 | d    |   20 |                                        19 |
|    2 | e    |   18 | 16.66666666666666666666666666666666666667 |
|    2 | f    |   12 |                                        15 |
|    3 | a    |   10 |                                      12.5 |
|    3 | b    |   15 |                                      12.5 |
|    4 | a    |    8 |                                      11.5 |
|    4 | c    |   15 |                                      11.5 |
+------+------+------+-------------------------------------------+
10 rows in set
```
