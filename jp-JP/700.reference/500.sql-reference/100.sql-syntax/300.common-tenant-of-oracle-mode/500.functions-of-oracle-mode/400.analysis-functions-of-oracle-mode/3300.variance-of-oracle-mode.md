# VARIANCE

## 説明

この関数は、指定された列の分散を返します。集計または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を実行します。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
VARIANCE([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                                                説明                                                                                                                                                |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時の重複除去の有無。オプションで、デフォルト値は `ALL` です。 <ul><li> `ALL`：クエリ時にデータ中の重複値を削除せず、`NULL` 値も無視します。    </li><li> `DISTINCT`：クエリ時にデータ中の重複値を削除し、`NULL` 値も無視します。    </li><li> `UNIQUE`：クエリ時にデータ中の重複値を削除し、`NULL` 値も無視します。</li></ul>    |
| expr                      | 数値データ型、または暗黙的に数値データ型に変換可能な式。                                                                                                                                                                                                                                                                      |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を実行します。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                                          |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DISTINCT</code> または <code>UNIQUE</code> キーワードを指定した場合、<code>analytic_clause</code> 内に <code>order_by_clause</code> および <code>windowing_clause</code> を記述することはできません。</p>
  </main>

## 戻り値の型

パラメータ `expr` と同じデータ型を返します。

既に作成済みのテーブル `employees` があります。

```sql
obclient> SELECT * FROM employees;
+---------------+-----------+------------+--------+

|            30 | Raphaely  | 2017-07-01 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |
|            40 | Errazuriz | 2017-07-21 |   1400 |
```

### 集計関数の例

列 `salary` のすべての値の分散を求めます。

```sql
obclient> SELECT SUM(salary) FROM employees;
+-------------+
| SUM(SALARY) |
+-------------+
|       70300 |
+-------------+
1 row in set
```

### 分析関数の例

列 `hiredate` の昇順でソートし、列 `salary` の累積分散を求めます。
