# 分散

## 説明

この関数は、指定された列の分散を返します。集計または分析関数として使用できます。
  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行う必要があります。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値しか返せません。この場合、<code>OVER</code> 句を追加する必要はありません。</li>
    </ul>
  </main>

## 構文

```sql
VARIANCE([ DISTINCT | UNIQUE | ALL ] expr) [ OVER (analytic_clause) ]
```

## パラメータの説明

|            パラメータ             |                                                                                                                                                説明                                                                                                                                                |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DISTINCT \| UNIQUE \| ALL | クエリ時に重複を除外するかどうか。オプションで、デフォルト値は `ALL` です。 <ul><li> `ALL`：クエリ時にデータ内の重複値を削除せず、データ内の `NULL` 値を無視します。    </li><li> `DISTINCT`：クエリ時にデータ内の重複値を削除し、データ内の `NULL` 値を無視します。    </li><li> `UNIQUE`：クエリ時にデータ内の重複値を削除し、データ内の `NULL` 値を無視します。</li></ul>    |
| expr                      | 数値データ型、または数値データ型へ暗黙的に型変換できる式。                                                                                                                                                                                                                                                                      |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                                          |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>DISTINCT</code>または<code>UNIQUE</code>キーワードを指定した場合、<code>analytic_clause</code>に<code>order_by_clause</code>および<code>windowing_clause</code>を含めることはできません。</p>
  </main>

## 返り値の型

引数 `expr` と同じデータ型を返します。

## 例

既に作成されたテーブル `employees` があります。

```sql
obclient> SELECT * FROM employees;
+---------------+-----------+------------+--------+
| DEPARTMENT_ID | LAST_NAME | HIREDATE   | SALARY |
+---------------+-----------+------------+--------+
|            30 | Raphaely  | 2017-07-01 |   1700 |
|            30 | De Haan   | 2018-05-01 |  11000 |
|            40 | Errazuriz | 2017-07-21 |   1400 |
|            50 | Hartstein | 2019-10-05 |  14000 |
|            50 | Raphaely  | 2017-07-22 |   1700 |
|            50 | Weiss     | 2019-10-05 |  13500 |
|            90 | Russell   | 2019-07-11 |  13000 |
|            90 | Partners  | 2018-12-01 |  14000 |
+---------------+-----------+------------+--------+
8 rows in set
```

### 集計関数の例

列 `salary` のすべての値の分散を求めます。

```sql
obclient [SYS]> SELECT VARIANCE(salary) FROM employees;
+-------------------------------------------+
| VARIANCE(SALARY)                          |
+-------------------------------------------+
| 36318392.85714285714285714285714285714286 |
+-------------------------------------------+
1 row in set
```

### 分析関数の例

列 `hiredate` を昇順にソートし、列 `salary` の累積分散を求めます。

```sql
obclient> SELECT last_name,hiredate,salary,VARIANCE(salary) OVER (ORDER BY hiredate) "Variance"
```
