# RATIO_TO_REPORT

## 説明

この関数は分析関数であり、ある値と一連の値の合計との比率を計算する機能を持っています。

## 構文

```sql
RATIO_TO_REPORT(expr) OVER ([query_partition_clause])
```

## パラメータの説明

| パラメータ |                                               説明                                               |
|------|------------------------------------------------------------------------------------------------|
| expr | クエリ対象のフィールドを指定します。<br>**注意**  `RATIO_TO_REPORT`関数やその他の分析関数を使用して`expr`をネストすることはできません。 |
| OVER | `OVER`句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)参照してください。        |

## 戻り値の型

`expr` が `NULL` の場合、結果は `NULL` を返します。それ以外の場合は、数値型データを返します。
