# ARG_MAX

## 宣言

```sql
ARG_MAX([DISTINCT] maximize_col, return_col)
```

## 説明

`ARG_MAX` 関数は、データセット内で目的の式を最大化する行を検索し、その行に対応する指定された列の値または完全なレコードを返します。

ここで：

* `maximize_col` は最大化する列を指します。
* `return_col` は戻り値に対応する列を指します。`NULL` 値がある場合はスキップします。

## 例

```shell
obclient> SELECT * FROM test;
+------+------+
| a    | b    |
+------+------+
| a    |    1 |
| b    |    2 |
| c    |    2 |
| NULL |    3 |
| NULL | NULL |
| d    | NULL |
+------+------+
6 rows in set (0.000 sec)
```

```shell
obclient> SELECT arg_max(a, b), max(b) FROM test;
+---------------+--------+
| arg_max(a, b) | max(b) |
+---------------+--------+
| b             |      3 |
+---------------+--------+
1 row in set (0.002 sec)
```
