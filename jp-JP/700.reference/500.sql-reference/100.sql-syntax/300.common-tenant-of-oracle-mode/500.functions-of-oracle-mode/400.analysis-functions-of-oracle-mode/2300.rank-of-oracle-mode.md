# RANK

## 説明

この関数は、値の集合における1つの値のランクを計算します。同じソート値が存在する場合、その値には同じランクが付与され、値が同じ行数は次のランクに記録されます。この関数は集約または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>集約関数として、<code>RANK</code> パラメータ <code>expr</code> で識別される仮想行の、指定されたソート規範に対するランクを計算します。パラメータ式 <code>expr</code> と <code>ORDER BY</code> 集約句内の式は位置に基づいてマッチします。したがって、パラメータの数は同じでなければならず、データ型も互換性がある必要があります。</li>
    <li>解析関数として、<code>RANK</code> クエリが <code>order_by_clause</code> 内の <code>value_exprs</code> の値に基づいて、クエリから返される他の各行に対して、クエリから返される各行のランクを計算します。</li>
    </ul>
  </main>

## 構文

```sql
/*集約構文*/
RANK(expr [, expr ]...) WITHIN GROUP
  ( ORDER BY
            expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
            [, expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
  )

/*分析構文*/
RANK() OVER ([ query_partition_clause ] order_by_clause)
```

## パラメータの説明

|           パラメータ            |                                                                                                            説明                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | クエリ対象の値を指定します。                                                                                                                                                                                                                 |
| expr_col                | クエリ対象の値に対応する列名を指定します。                                                                                                                                                                                                            |
| DESC \| ASC             | 列のソート方法を指定します。オプションです。 <ul><li> `ASC` は昇順ソートで、デフォルト値です。   </li><li> `DESC` は降順ソートです。</li></ul>                                                                  |
| NULLS { FIRST \| LAST } | ソート後の `expr_col` 内の `NULL` 値の位置を指定します。オプションです。 <ul><li> `NULLS FIRST` は、`NULL` 値が非NULL値の前に配置されることを意味します。   </li><li> `NULLS LAST` は、`NULL` 値が非NULL値の後ろに配置されることを意味し、デフォルト値です。</li></ul>    |
| OVER                    | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                  |

## 戻り値のタイプ

`NUMBER`データ型を返します。

### 集約関数の例

列 `sal` 内の `3300` のランキングを返します。

```sql
obclient> SELECT RANK(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+-----------------------------------+
| RANK(3300)WITHINGROUP(ORDERBYSAL) |
+-----------------------------------+
|                                13 |
+-----------------------------------+
1 row in set
```

### 分析関数の例
