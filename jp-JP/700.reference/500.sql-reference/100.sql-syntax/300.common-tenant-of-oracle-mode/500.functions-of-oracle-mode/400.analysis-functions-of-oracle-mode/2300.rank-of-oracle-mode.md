# RANK

## 説明

この関数は、一連の値の中で特定の値の順位を計算します。同じソート値が存在する場合、それらは同じ順位を持ち、値が同じ行数は次の順位に記録されます。この関数は集約関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>集約関数として、<code>RANK</code>はパラメータ<code>expr</code>で識別された仮定行が指定されたソート規範に対する順位を計算します。パラメータ式<code>expr</code>と<code>ORDER BY</code>の集約句内の式は位置が一致します。したがって、パラメータの数は同じでなければならず、データ型も互換性が必要です。</li>
    <li>解析関数として、<code>RANK</code>はクエリが返す他の行に対する各行の順位を計算し、その値は<code>order_by_clause</code>で指定された<code>value_exprs</code>に基づきます。</li>
    </ul>
  </main>

## 構文

```sql
/*集約構文*/
RANK(expr [, expr ]...) WITHIN GROUP
  ( ORDER BY
            expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]
            [, expr_col [ DESC | ASC ][ NULLS { FIRST | LAST } ]]...
  )

/*分析構文*/
RANK() OVER ([ query_partition_clause ] order_by_clause)
```

## パラメータの説明

|           パラメータ            |                                                                                                            説明                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                    | クエリ対象の値を指定します。                                                                                                                                                                                                                 |
| expr_col                | クエリ対象の値に対応する列名を指定します。                                                                                                                                                                                                            |
| DESC \| ASC             | リストのソート方法を指定します。オプションです。 <ul><li> `ASC` は昇順ソートで、デフォルト値です。   </li><li> `DESC` は降順ソートです。</li></ul>                                                                  |
| NULLS { FIRST \| LAST } | ソート後の `expr_col` 内の `NULL` 値の位置を指定します。オプションです。 <ul><li> `NULLS FIRST` は `NULL` 値を非NULL値の前に配置します。   </li><li> `NULLS LAST` は `NULL` 値を非NULL値の後ろに配置します。デフォルト値です。</li></ul>    |
| OVER                    | `OVER` 句を使用してウィンドウを定義し、計算を行います。[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                  |

## 戻り値の型

`NUMBER` データ型を返します。

### 集計関数の例

列 `sal` 内で `3300` のランキングを返します。

```sql
obclient> SELECT RANK(3300) WITHIN GROUP (ORDER BY sal) FROM emp_msg;
+-----------------------------------+
| RANK(3300)WITHINGROUP(ORDERBYSAL) |
+-----------------------------------+
|                                13 |
+-----------------------------------+
1 row in set
```

### 分析関数の例
