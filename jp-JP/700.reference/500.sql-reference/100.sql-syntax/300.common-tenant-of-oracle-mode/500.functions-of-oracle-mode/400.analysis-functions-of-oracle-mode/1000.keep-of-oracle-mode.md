# KEEP

## 説明

この関数は、一連の行の値に対して操作を行い、指定されたソート規則で並べ替えた後、最初または最後の値を返します。集計や分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。この関数は、<code>query_partition_clause</code> 内の1つ以上の式に基づいて、クエリ結果セットを複数のグループに分割します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返す必要があります。この場合、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
aggregate_function KEEP ( DENSE_RANK { FIRST | LAST }
                ORDER BY expr [ DESC | ASC ] [ NULLS { FIRST | LAST } ]
                      [, expr [ DESC | ASC ] [ NULLS { FIRST | LAST } ]]...
                        )
[ OVER ( [query_partition_clause] ) ]

aggregate_function:
  MIN
 |MAX
 |SUM
 |AVG
 |COUNT
 |VARIANCE
 |STDDEV
```

## パラメータの説明

|           パラメータ            |                                                                                                          説明                                                                                                          |
|-------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| aggregate_function      | 集計関数の種類を指定します。                                                                                                                                                                                                           |
| expr                    | 任意の式を指定できます。                                                                                                                                                                                                            |
| FIRST \| LAST           | `expr` でソートした後のその位置の値を返すことを指定します。 <ul><li> `FIRST` は最初の値を返します。   </li><li> `LAST` は最後の値を返します。</li></ul>                                               |
| DESC \| ASC             | リストのソート方法を指定します。オプションです。 <ul><li> `ASC` は昇順ソートで、デフォルト値です。   </li><li> `DESC` は降順ソートです。</li></ul>                                                              |
| NULLS { FIRST \| LAST } | ソート後の `expr` 内の `NULL` 値の位置を指定します。オプションです。 <ul><li> `NULLS FIRST` は `NULL` 値を非NULL値の前に配置します。   </li><li> `NULLS LAST` は `NULL` 値を非NULL値の後ろに配置します。デフォルト値です。 </li></ul>   |
| OVER                    | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                              |

## 戻り値の型

`aggregate_function` で指定された列と同じデータ型を返します。

### 集計関数の例

給与でソートし、1番目の従業員の給与の合計を求めます。採用日でソートし、最後尾の従業員の給与の合計を求めます。

```sql
obclient> SELECT SUM(salary) KEEP (DENSE_RANK FIRST ORDER BY salary) "Worst",
    SUM(salary) KEEP (DENSE_RANK LAST ORDER BY HIREDATE) "Best"
    FROM employees;
+-------+-------+
| Worst | Best  |
+-------+-------+
|  1400 | 27500 |
+-------+-------+
1 row in set
```

### 分析関数の例

各部門ごとに給与でソートし、1番目の従業員の給与の合計を求めます。採用日でソートし、最後尾の従業員の給与の合計を求めます。

```sql
obclient> SELECT last_name,department_id,salary,
    SUM(salary) KEEP (DENSE_RANK FIRST ORDER BY salary)
        OVER (PARTITION BY department_id) "Worst",
    SUM(salary) KEEP (DENSE_RANK LAST ORDER BY HIREDATE)
        OVER (PARTITION BY department_id) "Best"
    FROM employees
    ORDER BY department_id, salary, last_name;
```
