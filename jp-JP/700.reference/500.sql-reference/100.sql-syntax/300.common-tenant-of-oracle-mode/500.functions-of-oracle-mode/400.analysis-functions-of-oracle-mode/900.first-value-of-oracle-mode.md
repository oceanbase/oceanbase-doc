# FIRST_VALUE

## 説明

この関数は分析関数であり、順序付けられた値のうち最初の値を返します。セットの最初の値が `NULL` の場合、関数は `NULL` を返します。ただし、`IGNORE NULLS` を指定した場合はこの限りではありません。この設定はデータの圧縮に役立ちます。`expr` 列の `NULL` 値の行に対応する戻り値は `NULL` です。

## 構文

```sql
FIRST_VALUE { (expr) [{RESPECT | IGNORE} NULLS ]
            | (expr [{RESPECT | IGNORE} NULLS ])
            }
OVER (analytic_clause)
```

## パラメータの説明

|            パラメータ             |                                                                                                          説明                                                                                                           |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                      | 戻り値として返す列名を指定します。 <br>**注意**  `expr` に `FIRST_VALUE` またはその他の分析関数を使用して、ネストされた分析関数を記述することはできません。                                                                                                                        |
| {RESPECT \| IGNORE} NULLS | `NULL` 値を無視するかどうかを示します。オプションです。デフォルト値は `RESPECT NULLS` です。 <ul><li>  `RESPECT  NULLS` は `NULL` 値を無視しないことを意味します。   </li><li>`IGNORE NULLS` は `NULL` 値を無視することを意味します。</li></ul>     |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                               |

## 戻り値の型

戻り値はパラメータ `expr` のデータ型と同じ、または `NULL` を返します。

## 例
