# NTILE

## 説明

この関数は分析関数であり、順序付きデータセットをいくつかのグループに分割し、各行に適切なグループ番号を割り当てる機能を持っています。グループ番号は `1` から `expr` までです。

## 構文

```sql
NTILE (expr) OVER ([ query_partition_clause ] order_by_clause)
```

## パラメータの説明

| パラメータ |                                                                                                                                                    説明                                                                                                                                                    |
|------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr | 分割するグループ数を指定します。<ul><li>`expr` の値は、`1` 以上の正の数として解釈されなければなりません。`expr` が非整数定数の場合、データベースはその値を整数に切り捨てます。</li><li>`expr` が行数より大きい場合、行数と同じ数の複数のグループが追加され、残りのグループは空になります。</li></ul>    **注記**   `NTILE` または他の分析関数を使用して、分析関数をネストすることはできません。ただし、`expr` 内で他の組み込み関数式を使用できます。 |
| OVER | `OVER` 句を使用してウィンドウを定義し、計算を実行します。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                                                                                                                  |

## 戻り値のタイプ

`NUMERIC` 型のデータを返します。
