# CORR

## 説明

この関数は、一連の数値ペアの相関係数を計算します。相関係数は数値ペアの関連強度を表し、範囲は \[-1,1\] です。ここで、`0` は無相関、`0` より小さい値は負の相関、`0` より大きい値は正の相関を示します。この関数は集計関数または分析関数として使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>分析関数として使用する場合は、<code>OVER</code> 句を使用してウィンドウを定義し、計算を行います。これは一連の行の集合に対して計算を行い、複数の値を返します。</li>
    <li>集計関数として使用する場合、この関数は一連の行の集合に対して集計計算を行い、結果は1つの値のみを返すため、<code>OVER</code> 句は不要です。</li>
    </ul>
  </main>

## 構文

```sql
CORR(expr1, expr2) [ OVER (analytic_clause) ]
```

## パラメータの説明

|  パラメータ   |                                           説明                                            |
|-------|-----------------------------------------------------------------------------------------|
| expr1 | 最初のパラメータを指定します。数値データ型、または数値データ型へ暗黙的に変換可能な値である必要があります。                                                       |
| expr2 | 2番目のパラメータを指定します。数値データ型、または数値データ型へ暗黙的に変換可能な値である必要があります。                                                       |
| OVER  | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>データベースは、数値的に最も高い優先順位を持つパラメータを特定し、残りのパラメータをそのデータ型に暗黙的に変換して返します。</li>
    <li>パラメータ <code>expr1</code> と <code>expr2</code> の位置は、返される結果に影響しません。</li>
    <li>戻り値の計算式は次のとおりです：<code>COVAR_POP(expr1, expr2) / (STDDEV_POP(expr1) * STDDEV_POP(expr2))</code>。</li>
    </ul>
  </main>

## 戻り値の型

いずれかのパラメータがNULLであるか、データが1行しかない場合は、`NULL` を返します。それ以外の場合は、`NUMBER` 型の値を返します。

### 集計関数の例

列 `col3` のデータと列 `col4` のデータの相関係数を計算します。

```sql
obclient> SELECT CORR(col3,col4) FROM tbl1;
+--------------------------------------------+
| CORR(COL3,COL4)                            |
+--------------------------------------------+
| -.2705008904002296868793073195758520224002 |
+--------------------------------------------+
1 row in set
```
