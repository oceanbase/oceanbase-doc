# LAST_VALUE

## 説明

この関数は分析関数であり、順序付けられた値の集合の中から最後の値を返します。集合の最後の値が `NULL` の場合、この関数は `NULL` を返します。ただし、`IGNORE NULLS` を指定した場合は例外です。この設定はデータの密度化に役立ちます。

## 構文

```sql
LAST_VALUE { (expr) [{RESPECT | IGNORE} NULLS ]
            | (expr [{RESPECT | IGNORE} NULLS ])
            }
OVER (analytic_clause)
```

## パラメータの説明

|            パラメータ             |                                                                                                          説明                                                                                                           |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr                      | シーケンスを指定します。 <br>**注意**  `LAST_VALUE` または他の分析関数を `expr` に使用して、分析関数をネストすることはできません。                                                                                                                              |
| {RESPECT \| IGNORE} NULLS | `NULL` 値を無視するかどうかを示します。オプションです。デフォルト値は `RESPECT NULLS` です。 <ul><li> `RESPECT  NULLS` は `NULL` 値を無視しないことを意味します。   </li><li> `IGNORE NULLS` は `NULL` 値を無視することを意味します。</li></ul>    |
| OVER                      | `OVER` 句を使用してウィンドウを定義し、計算を行います。詳細については、[分析関数の説明](../400.analysis-functions-of-oracle-mode/100.window-function-description-of-oracle-mode.md)を参照してください。                                                                                                                               |

## 戻り値の型

戻り値は `expr` のデータ型と同じになるか、`NULL` を返します。

## 例

既に作成されたテーブル `emp_msg` があります。`emp_msg` テーブルのデータを列 `sal` の昇順でソートし、列 `MGR` の最後の非NULL値を `last_MGR` 列として返します。
