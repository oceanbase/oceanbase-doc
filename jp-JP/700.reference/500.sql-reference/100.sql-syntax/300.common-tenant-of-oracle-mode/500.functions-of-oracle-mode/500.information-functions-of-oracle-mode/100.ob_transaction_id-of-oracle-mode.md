# OB_TRANSACTION_ID

## 宣言

```sql
OB_TRANSACTION_ID()
```

## 説明

* 現在のセッションがアクティブトランザクション中である場合、そのトランザクションIDの整数値（0より大きい）を返します。
* 現在のセッションがアクティブトランザクションにない場合、0を返します。

## 例

1. トランザクションを開始します。

   ```shell
   obclient [SYS]> START TRANSACTION;
   ```

2. 現在アクティブなトランザクションのIDを照会します。

   ```shell
   obclient [SYS]> SELECT OB_TRANSACTION_ID() FROM DUAL;
   ```

   実行結果は次のとおりです：

   ```shell
   +---------------------+
   | OB_TRANSACTION_ID() |
   +---------------------+
   |            11003721 |
   +---------------------+
   1 row in set
   ```

3. トランザクションをコミットします。

   ```shell
   obclient [SYS]> COMMIT;
   ```

4. 現在アクティブなトランザクションにないトランザクションIDを照会します。

   ```shell
   obclient [SYS]> SELECT OB_TRANSACTION_ID() FROM DUAL;
   ```

   実行結果は次のとおりです：

   ```shell
   +---------------------+
   | OB_TRANSACTION_ID() |
   +---------------------+
   |                   0 |
   +---------------------+
   1 row in set
   ```
