# テーブル関数

テーブル関数（Table Function）とは、行の集合を生成する関数であり、その集合はデータベースのテーブルと同様にクエリできます。`FROM` クエリ句でテーブル関数を使用できます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースはV4.2.5 BP5バージョンから、複雑なデータ型をサポートしています。</p>
</main>

## 例

```sql
CREATE FUNCTION func_normal RETURN table_type AS
  v_result table_type := table_type();
BEGIN
  v_result.EXTEND;
  v_result(1) := obj_type(1, 'A');
  RETURN v_result;
END;
```

### パラメータの説明

|      パラメータ    |                 説明                         |
|--------------|---------------------------------------------|
|CREATE FUNCTION func_normal|`func_normal` という名前の関数を作成することを宣言します。|
|RETURN table_type|関数の戻り値型をカスタムテーブル型 `table_type` と指定します。|
|v_result|ローカル変数で、型は `table_type` (ネストテーブルまたは配列型)。|
|table_type()|コンストラクタのように、空のテーブルインスタンスを初期化します。|
|v_result.EXTEND|テーブル容量を拡張します。|
|v_result(1) := obj_type(1, 'A')|カスタムオブジェクト型 `obj_type` のインスタンスを作成します。|
|RETURN v_result|宣言と一致する型で、埋め込み後のテーブル変数を返します。|

完全な使用プロセスの例は以下のとおりです：

1. オブジェクトタイプを定義します。

    ```shell
    obclient> CREATE OR REPLACE TYPE obj_type AS OBJECT (
    id   NUMBER,
    name VARCHAR2(50)
    );
    ```

2. テーブルタイプを定義します。

    ```shell
    obclient> CREATE OR REPLACE TYPE table_type IS TABLE OF obj_type;
    ```

3. テーブル関数を呼び出します。

    ```shell
    obclient> SELECT * FROM TABLE(func_normal());
    ```
