# 仮想列の概要

仮想列（Pseudocolumn）は、テーブル内の列と同じように動作しますが、具体的な値は格納されません。そのため、仮想列には読み取り専用の属性しかなく、挿入、更新、削除などの操作はできません。この章では、OceanBaseデータベースの現在のバージョンでサポートされている仮想列とその使用方法について説明します。

OceanBaseデータベースの現在のバージョンでサポートされている仮想列のタイプは以下のとおりです：

* [階層クエリ仮想列](../200.pseudo-column-of-oracle-mode/200.hierarchical-query-pseudo-columns-of-oracle-mode.md)

* [シーケンス仮想列](../200.pseudo-column-of-oracle-mode/300.sequence-pseudo-column-of-oracle-mode.md)

* [ORA_ROWSCN 仮想列](../200.pseudo-column-of-oracle-mode/400.ora_rowscn-pseudo-column-of-oracle-mode.md)

* [ROWNUM 仮想列](../200.pseudo-column-of-oracle-mode/500.rownum-pseudo-column-of-oracle-mode.md)

* [ROWID 仮想列](../200.pseudo-column-of-oracle-mode/600.rowid-pseudo-column-of-oracle-mode.md)

* [PARTITIONID 仮想列](../200.pseudo-column-of-oracle-mode/700.partitionid-pseudo-column-of-oracle-mode.md)
