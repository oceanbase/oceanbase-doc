# プセウドカラムの概要

プセウドカラム（Pseudocolumn）は、テーブル内の列と同様に動作しますが、具体的な値は格納されません。そのため、プセウドカラムは読み取り専用であり、挿入、更新、削除などの操作を行うことはできません。この章では、OceanBaseデータベースの現行バージョンでサポートされているプセウドカラムとその使用方法について説明します。

OceanBaseデータベースの現行バージョンでは、以下のプセウドカラムタイプがサポートされています：

* [階層クエリ用プセウドカラム](../200.pseudo-column-of-oracle-mode/200.hierarchical-query-pseudo-columns-of-oracle-mode.md)

* [シーケンス用プセウドカラム](../200.pseudo-column-of-oracle-mode/300.sequence-pseudo-column-of-oracle-mode.md)

* [ORA_ROWSCNプセウドカラム](../200.pseudo-column-of-oracle-mode/400.ora_rowscn-pseudo-column-of-oracle-mode.md)

* [ROWNUMプセウドカラム](../200.pseudo-column-of-oracle-mode/500.rownum-pseudo-column-of-oracle-mode.md)

* [ROWIDプセウドカラム](../200.pseudo-column-of-oracle-mode/600.rowid-pseudo-column-of-oracle-mode.md)
