# 疑似列の概要

疑似列（Pseudocolumn）は、テーブル内の列と同じように動作しますが、具体的な値は格納されません。そのため、疑似列には読み取り専用の属性しかなく、挿入、更新、削除などの操作はできません。この章では、OceanBaseデータベースの現在のバージョンでサポートされている疑似列とその使用方法について説明します。

OceanBaseデータベースの現在のバージョンでサポートされている疑似列のタイプは以下のとおりです：

* [階層クエリ疑似列](../200.pseudo-column-of-oracle-mode/200.hierarchical-query-pseudo-columns-of-oracle-mode.md)

* [シーケンス疑似列](../200.pseudo-column-of-oracle-mode/300.sequence-pseudo-column-of-oracle-mode.md)

* [ORA_ROWSCN 疑似列](../200.pseudo-column-of-oracle-mode/400.ora_rowscn-pseudo-column-of-oracle-mode.md)

* [ROWNUM 疑似列](../200.pseudo-column-of-oracle-mode/500.rownum-pseudo-column-of-oracle-mode.md)

* [ROWID 疑似列](../200.pseudo-column-of-oracle-mode/600.rowid-pseudo-column-of-oracle-mode.md)

* [PARTITIONID 疑似列](../200.pseudo-column-of-oracle-mode/700.partitionid-pseudo-column-of-oracle-mode.md)
