# 空間構造関数

空間構造関数は、新しい空間データ型や幾何図形を作成するための関数です。

OceanBaseデータベースで現在サポートされている空間構造関数には、`_ST_MakeEnvelope` が含まれます。

## _ST_MakeEnvelope

`_ST_MakeEnvelope` 関数は、左下隅の座標と右上隅の座標を入力することで、長方形を作成します。この長方形は、空間クエリの境界ボックス（bounding box）としてよく使用されます。

構文は以下のとおりです：

```sql
_ST_MakeEnvelope(float xmin, float ymin, float xmax, float ymax, integer srid=unknown)
```

パラメータの説明：

- `float xmin`：長方形の左下隅の x 座標（通常は経度）を表します。
- `float ymin`：長方形の左下隅の y 座標（通常は緯度）を表します。
- `float xmax`：長方形の右上隅の x 座標（通常は経度）を表します。
- `float ymax`：長方形の右上隅の y 座標（通常は緯度）を表します。
- `integer srid`：空間参照系の識別子（Spatial Reference System Identifier）であり、有効な識別子を指定することで、座標が使用する空間参照系を指定します。デフォルト値の unknown は、空間参照系を指定しないことを意味します。

制限事項：

- 座標値は有効でなければなりません。`xmin` は `xmax` より小さく、`ymin` は `ymax` より小さい必要があります。これにより、有効な長方形が形成されます。

例1は以下のとおりです：

```sql
obclient> SELECT ST_AsText(_ST_MakeEnvelope(10, 10, 11, 11, 4326));
```

この例では、左下隅の座標が (10, 10)、右上隅の座標が (11, 11) の長方形を作成します。

戻り値は以下のとおりです：

```shell
+-----------------------------------------------------+
| ST_AsText( _ST_MakeEnvelope(10, 10, 11, 11, 4326) ) |
+-----------------------------------------------------+
| POLYGON((10 10,11 10,11 11,10 11,10 10))            |
+-----------------------------------------------------+
1 row in set
```

例2は以下のとおりです：

```sql
obclient> SELECT ST_ASTEXT(_ST_ClipByBox2D(ST_GEOMFROMTEXT('POLYGON((-2 -2, -2 11, 11 11, 11 -2, -2 -2))'), _ST_MakeEnvelope(0,0,10,10)));
```

この例では、まず、左下隅の座標が (0, 0)、右上隅の座標が (10, 10) の長方形をクリッピング範囲として作成します。次に、`_ST_ClipByBox2D` 関数を使用して、元の多角形 `POLYGON((-2 -2, -2 11, 11 11, 11 -2, -2 -2))` を長方形でクリッピングします。

実行結果は次のとおりです：

```shell
+--------------------------------------------------------------------------------------------------------------------------+
| ST_ASTEXT(_ST_ClipByBox2D(ST_GEOMFROMTEXT('POLYGON((-2 -2, -2 11, 11 11, 11 -2, -2 -2))'), _ST_MakeEnvelope(0,0,10,10))) |
+--------------------------------------------------------------------------------------------------------------------------+
| POLYGON((0 0,0 10,10 10,10 0,0 0))                                                                                       |
+--------------------------------------------------------------------------------------------------------------------------+
1 row in set
```
