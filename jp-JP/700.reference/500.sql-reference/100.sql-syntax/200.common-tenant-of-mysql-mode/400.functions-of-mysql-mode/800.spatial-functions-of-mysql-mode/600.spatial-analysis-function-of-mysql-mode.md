# 空間分析関数

空間分析関数は、バッファ分析、結合、クリッピングなどの複雑な空間処理と分析を実行するために使用される関数です。

OceanBaseデータベースで現在サポートされている空間分析関数には、`ST_Length()`、`ST_Centroid()`、および `_ST_PointOnSurface()` が含まれます。

## ST_Length

`ST_Length(ls[,unit])` 関数は、線形幾何体（線分、折れ線、または曲線など）の長さを計算します。この関数は通常、`LINESTRING` および `MULTILINESTRING` 型の幾何オブジェクトに適用されます。

単位変換を有効にするには、幾何体 ls に対応する空間参照システムID（SRID）が関連付けられており、その SRID が 0 でない必要があります（SRID = 0 は通常、空間参照がないことを意味します）。

使用する単位はデータベースでサポートされている有効な単位でなければならず、データベースはその単位に対応する変換係数を認識できなければなりません。

```sql

```

パラメータの説明：

- `ls`：入力パラメータで、長さを計算する線形幾何体を表します。
- `unit`：（オプションのパラメータ）長さの単位を指定します。指定しない場合、長さはデフォルトでメートル（metre）単位です。関数の実装と空間データベースシステムによっては、このパラメータは 'foot'（フィート）、'centimetre'（センチメートル）など、さまざまな長さ単位を受け入れることができます。

例：

```sql
obclient> SET @ls = ST_GeomFromText('LineString(1 1,2 2,3 3)', 4326);
Query OK, 0 rows affected

obclient> SELECT ST_Length(@ls, "foot");

| ST_Length(@ls, "foot") |
+------------------------+
|     1029205.9131247795 |
+------------------------+
1 row in set

obclient> SELECT ST_Length(@ls);
+-------------------+
| ST_Length(@ls)    |
+-------------------+
| 313701.9623204328 |
+-------------------+
1 row in set
```

この例では、まず `ST_GeomFromText` 関数を使用して、3つの点 (1,1)、(2,2)、(3,3) からなる線形幾何体（LineString）を作成します。

次に、`ST_Length` 関数を使用してこの LineString の長さを計算します。まず、長さの単位をフィートに指定すると、得られた長さは 1029205.9131247795 フィートです。その後、再度 `ST_Length` 関数を呼び出しますが、今回は単位を指定しません。そのため、デフォルトの単位であるメートルが使用され、得られた長さは 313701.9623204328 メートルです。

## ST_Centroid

`ST_Centroid(geometry A)` は、与えられた幾何体 `A` の重心（幾何的中心）を計算するための空間関数です。重心は幾何体の各部分の平衡点であり、幾何体の中心位置と見なすことができます。二次元幾何体、例えば多角形の場合、重心はすべての点の平均位置です。

- `A` が空の幾何体（点がない場合）の場合、関数は `NULL` または無効な結果を返す可能性があります。
- `A` が複雑な幾何体の場合、特に幾何体が多数の頂点や内部の穴を持つ場合、重心の計算は複雑で計算負荷が高くなる可能性があります。
- 計算された重心は、特に幾何体自体の形状が不規則であったり凹みがあったりする場合、元の幾何体上に位置しない可能性があります。例えば、「U」字型の多角形では、重心が凹んだ外部空間に位置することがあります。
- 線形幾何体（線分や折れ線など）の場合、重心はその線上のすべての点の平均位置ですが、複雑な線形（自己交差している、または湾曲した折れ線など）の場合、重心の位置は直感的に理解しにくいことがあります。

構文は以下のとおりです：

```sql
ST_Centroid(geometry A)
```

例：

```sql
obclient> SELECT ST_AsText(_ST_PointOnSurface(geom)) AS pt_on_surf, ST_AsText(ST_Centroid(geom)) AS centroid FROM (SELECT ST_GeomFromText('POLYGON ((0 0, 0 10, 10 10, 10 8, 2 8, 2 2, 10 2, 10 0, 0 0))') AS geom) AS t;
```

この例では、複雑な形状を持つ多角形幾何体を定義し、2種類の空間分析操作を行っています：

`_ST_PointOnSurface` 関数は、多角形の表面上に位置する点を取得するために使用されます。この点は通常、全体の幾何体の位置を表すために使用され、多角形の内部に位置することが保証されます。
`ST_Centroid` 関数は、多角形の重心を計算するために使用されます。重心は多角形の各部分のバランス点ですが、多角形の内部に位置することは保証されません。
結果は2列に表示されます。1列目の `pt_onsurf` は多角形表面上の点の座標で、2列目の `centroid` は計算された多角形の重心の座標です。クエリ結果から、多角形表面上の点は (1, 5) に位置し、重心の座標は (4.076923076923077, 5) であることが確認できます。

戻り値は次のとおりです：

```shell
+------------+----------------------------+
| pt_on_surf | centroid                   |
+------------+----------------------------+
| POINT(1 5) | POINT(4.076923076923077 5) |
+------------+----------------------------+
1 row in set
```

## _ST_PointOnSurface

`_ST_PointOnSurface(geometry a)` 関数は、入力された幾何体 `a` から、その幾何体の表面上に位置する点を返すために使用されます。これにより、幾何体の内部に正確に位置する点（多角形やその他の面状幾何体の場合）を返すことができ、単なる幾何的中心や算術的中心にとどまりません。

`_ST_PointOnSurface` 関数は通常、面状幾何体（多角形など）に対してのみ意味があります。線状や点状の幾何体の場合、内部点の概念が明確でないか適用できない場合があるためです。

この関数は、複数の内部点のうちいずれも返さない場合があり、代わりに全体の幾何体を代表する特定の点（例えば、多角形の角点や辺上の点など）を返すことがあります。

構文は以下のとおりです：

```sql
_ST_PointOnSurface(geometry g1)
```

例：

```sql
obclient> SELECT ST_AsText(_ST_PointOnSurface(geom)) AS pt_on_surf, ST_AsText(ST_Centroid(geom)) AS centroid FROM (SELECT ST_GeomFromText('POLYGON ((0 0, 0 10, 10 10, 10 8, 2 8, 2 2, 10 2, 10 0, 0 0))') AS geom) AS t;
```

この例では、まずWell-Known Text (WKT) 形式の文字列から、特定の形状を持つ多角形幾何体を作成します。次に、この多角形に対して2つの関数を使用します：`_ST_PointOnSurface` と `ST_Centroid`。

`_ST_PointOnSurface` 関数は、多角形の表面上に位置する点を返します。これは、その点が多角形の境界上または内部にあることを意味します。一方、`ST_Centroid` 関数は、多角形の幾何的中心を計算して返します。

最後に、クエリ結果は2列を使用してこれら2つの点の座標を表示します。`pt_onsurf` は表面上の点、`centroid` は重心の座標です。提供された例では、`pt_onsurf` は座標 (1, 5) の点を返し、`centroid` は座標 (4.076923076923077, 5) の点を返します。

戻り値は次のとおりです：

```shell
+------------+----------------------------+
| pt_on_surf | centroid                   |
+------------+----------------------------+
| POINT(1 5) | POINT(4.076923076923077 5) |
+------------+----------------------------+
1 row in set
```
