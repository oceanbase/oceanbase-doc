# 空間関数の概要

空間関数とは、OceanBaseデータベースシステムが提供する地理空間データを処理するための専門的な関数群です。これらの関数により、ユーザーはデータベースレベルで複雑な空間クエリや分析を実行できるようになり、地理情報システム（GIS）やその他の空間データ依存アプリケーションが空間データを効率的に保存、検索、操作できるようになります。

以下は、OceanBaseの空間関数の種類とその用途の概要です：

## 空間関数の種類

| スペース関数タイプ                             | 説明                                                               |
|------------------------------------------|--------------------------------------------------------------------|
| [幾何値関数の作成](150.create-a-geometry-function-of-mysql-mode.md) | ポイント、ライン、面などのジオメトリデータ型のインスタンスを生成するために使用されます。                     |
| [空間演算関数](200.spatial-operation-functions-of-mysql-mode.md) | 加算、減算、乗算など、ジオメトリオブジェクト間の基本的な演算を提供する関数です。                   |
| [空間関係関数](300.spatial-relation-functions-of-mysql-mode.md)  | 交差、包含、隣接など、2つのジオメトリオブジェクト間の空間関係を決定する関数です。       |
| [幾何属性関数](400.geometry-attribute-functions-of-mysql-mode.md) | 面積、長さ、境界など、ジオメトリオブジェクトの属性を取得するための関数です。           |
| [幾何形式変換関数](500.geometry-conversion-function-of-mysql-mode.md) | WKBからWKTへの変換など、ジオメトリデータ形式間で相互に変換するための関数です。             |
| [空間分析関数](600.spatial-analysis-function-of-mysql-mode.md)                           | バッファ分析、結合、クリッピングなど、複雑な空間処理と分析を実行するための関数です。   |
| [空間構築関数](700.spatial-constructor-function-of-mysql-mode.md)                           | 新しい空間データ型やジオメトリ図形を構築するための関数です。                   |
| [空間アクセサ関数](800.spatial-accessor-function-of-mysql-mode.md)                         | 多角形の頂点や線の始点へのアクセスなど、空間データ要素へのアクセスを提供する関数です。   |
| [空間形式変換関数](900.spatial-format-conversion-function-of-mysql-mode.md)                       | ジオメトリオブジェクトをテキストやバイナリ形式に変換するなど、異なる空間データ表現形式間で変換するための関数です。 |
|[幾何処理関数](1000.spatial-processing-function-of-mysql-mode.md)|形状の変更、幾何関係の計算、空間クエリ、その他の種類の空間分析を含む、空間ジオメトリオブジェクトに対するさまざまな操作と変換を行うために使用されます。|
