# RELEASE_LOCK

## 説明

この関数は、現在のセッションが `GET_LOCK()` 関数を使用して取得した名前付きロック（`str` という名前のロック）を解除するために使用されます。

## 構文

```sql
RELEASE_LOCK('str')
```

## 説明

### パラメータの説明

`str`: 解除するロックの名前を指定します。文字列型です。

### 戻り値

* 1を返す：現在のセッションがそのロックを保持しており、ロックが正常に解除されたことを示します。
* 0を返す：現在のセッションがそのロックの所有者ではないか、またはロックが現在のセッションによって解除されていないことを示します。
* `NULL` を返す：ロックが存在しないことを示します。つまり、`GET_LOCK()` でロックを取得していないか、ロックが以前に解除されている可能性があります。

## 例

`my_lock` という名前のロックを解除します。

```shell
obclient [(none)]> SELECT RELEASE_LOCK('my_lock');
```

戻り結果は次のとおりです：

```shell
+-------------------------+
| RELEASE_LOCK('my_lock') |
+-------------------------+
|                       0 |
+-------------------------+
1 row in set
```

戻り結果が0であることは、現在のセッションがロック `my_lock` の所有者ではなく、ロックが現在のセッションによって解除されていないことを示します。
