# ロック関数の概要

OceanBaseデータベースのMySQLモードは、ロックを操作するための関数をサポートしており、以下の表に示されています。

| **関数名** | **説明** |
|--------------|----------|
| [GET_LOCK](200.get-lock-of-mysql-mode.md) | 命名ロックを取得します。|
| [IS_FREE_LOCK](300.is-free-lock-of-mysql-mode.md) | 指定されたロックがアイドル状態かどうかを確認します。|
| [IS_USED_LOCK](400.is-used-lock-of-mysql-mode.md) | 指定されたロックが使用中かどうかを確認します。|
| [RELEASE_ALL_LOCKS](500.release-all-locks-of-mysql-mode.md) | 現在のセッションが保持しているすべてのロックを解放します。|
| [RELEASE_LOCK](600.release-lock-of-mysql-mode.md) | 指定されたロックを解放します。|
