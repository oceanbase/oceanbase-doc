# ロック関数の概要

OceanBaseデータベースのMySQLモードは、ロックを操作するための関数をサポートしています。以下の表に示します。

| **関数名** | **説明** |
|--------------|----------|
| [GET_LOCK](200.get-lock-of-mysql-mode.md) | 名前付きロックを取得します。|
| [IS_FREE_LOCK](300.is-free-lock-of-mysql-mode.md) | 指定されたロックが空いているかどうかを確認します。|
| [IS_USED_LOCK](400.is-used-lock-of-mysql-mode.md) | 指定されたロックが使用中かどうかを確認します。|
| [RELEASE_ALL_LOCKS](500.release-all-locks-of-mysql-mode.md) | 現在のセッションが保持するすべてのロックを解放します。|
| [RELEASE_LOCK](600.release-lock-of-mysql-mode.md) | 指定されたロックを解放します。|

## 前提条件

プロキシを使用してクラスタに接続する場合は、プロキシの以下の設定も有効にする必要があります：

```sql
ALTER PROXYCONFIG SET proxy_id = 1;
ALTER PROXYCONFIG SET client_session_id_version = 2;
ALTER PROXYCONFIG SET enable_single_leader_node_routing = false;
```

上記のプロキシ設定の詳細については、[proxy_id](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000001409988)、[client_session_id_version](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000001410074)、および [enable_single_leader_node_routing](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000001410098)を参照してください。
