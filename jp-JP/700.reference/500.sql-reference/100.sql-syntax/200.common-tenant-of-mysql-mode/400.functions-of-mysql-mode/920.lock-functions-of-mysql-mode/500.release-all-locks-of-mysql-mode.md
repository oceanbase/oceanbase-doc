# RELEASE_ALL_LOCKS()

## 説明

この関数は、現在のセッションが保持しているすべてのネーム付きロックを解放し、正常に解放されたロックの数を返します。

## 構文

```sql
RELEASE_ALL_LOCKS()
```

## 説明

### パラメータの説明

パラメータはありません。

### 戻り値

正常に解放されたロックの数を返します。現在のセッションがロックを保持していない場合、戻り値は0です。

## 例

現在のセッションが保持するすべてのネーム付きロックを解放します。

```shell
obclient [(none)]> SELECT RELEASE_ALL_LOCKS();
```

実行結果は次のとおりです：

```shell
+---------------------+
| RELEASE_ALL_LOCKS() |
+---------------------+
|                   1 |
+---------------------+
1 row in set
```

実行結果は1であり、現在のセッションが保持している1つのネーム付きロックが正常に解放されたことを示します。
