# マップ構築関数

マップ構築関数/演算子は、新しいマップデータ型を構築するために使用されます。OceanBaseデータベースで現在サポートされているマップ構築関数には `map()` があり、演算子には `{}` があります。

## map

`map()` 関数は、マップデータを構築するために使用されます。構文は以下のとおりです：

```sql
map(key1, value1, key2, value2, ..., keyN, valueN)
```

入力パラメータの説明は以下のとおりです：

* 入力パラメータの数は偶数である必要があります。奇数番目のパラメータはキー配列を形成し、偶数番目のパラメータは値配列を形成します。
* key1～keyN と value1～valueN の各要素のデータ型については、[マップデータ型の概要](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/1300.map-data-type-of-mysql-mode/100.map-data-type-overview-of-mysql-mode.md)を参照してください。
* 入力されたキーと値のペアのキーは重複してはなりません。重複するキーがある場合、後から入力された値が優先され、前の値は上書きされます。

戻り値はマップデータ型（MAP）です。

例：

```sql
-- 構築されたマップデータには1つのキーと値のペアがあり、keyは1、valueは2です
SELECT map(1,2);
+----------+
| map(1,2) |
+----------+
| {1:2}    |
+----------+
1 row in set
```

```sql
-- 構築されたマップデータには3つのキーと値のペアがあります
SELECT map(1,"a",2,"b",3,"c");
+------------------------+
| map(1,"a",2,"b",3,"c") |
+------------------------+
| {1:"a",2:"b",3:"c"}    |
+------------------------+
1 row in set
```

```sql
-- キー配列のデータ型は奇数番号のパラメータによって、値配列のデータ型は偶数番号のパラメータによって決定されます。
SELECT map(1,"a","b",1.8,"ccc",3);
+-------------------------------+
| map(1,"a","b",1.8,"ccc",3)    |
+-------------------------------+
| {"1":"a","b":"1.8","ccc":"3"} |
+-------------------------------+
```

## {}

`{}` は、文字列形式でマップデータを構築するために使用します。マップデータを `{key1:value1, key2:value2, ..., keyN:valueN}` の形式の文字列として記述すると、OceanBase データベースはそれをマップデータ型に変換します。そのため、マップ型の列にデータを挿入する際には、このような文字列を直接使用できます。

入力パラメータの説明は以下のとおりです：

* 各キーと値のペアは `,` で区切り、キー と 値 の間は `:` で区切ります。
* キー には引用符を付けなくてもかまいません。例：`{1:1,2:2,3:3}`。
* 入力されるキーと値のペアの キー は重複してはなりません。重複する キー がある場合、後から入力された 値 が優先され、前の 値 は上書きされます。

例：

```sql
CREATE TABLE t1 (
  id INT NOT NULL AUTO_INCREMENT,
  m MAP(INT, INT)
);

INSERT INTO t1 (m) VALUES ('{1:1,2:2,3:3}');

SELECT m FROM t1;
+---------------+
| m             |
+---------------+
| {1:1,2:2,3:3} |
+---------------+
1 row in set
```
