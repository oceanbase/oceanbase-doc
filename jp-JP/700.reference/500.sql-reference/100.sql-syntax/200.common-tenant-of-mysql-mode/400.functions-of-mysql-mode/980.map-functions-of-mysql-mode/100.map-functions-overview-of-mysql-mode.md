# マッピング関数の概要

マッピング関数は、OceanBaseデータベースシステムで提供される、マッピングデータを処理するために特化した関数群です。これらの関数により、ユーザーは複雑なマッピングクエリや分析を実行できます。

以下は、OceanBaseのマッピング関数とその用途の概要です：

## マッピング関数の種類

| マッピング関数の種類                               | 説明                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [マッピング構築関数](200.map-constructor-functions-of-mysql-mode.md) | 新しいマッピングデータ型を構築するために使用される関数。 |
| [マッピング判断関数](300.map-decision-functions-of-mysql-mode.md) | 入力されたマッピングデータに対して論理判断を行い、ブール値を返す関数。 |
| [マッピング操作関数](600.map-manipulation-functions-of-mysql-mode.md)  | 入力されたマッピングデータに対して、Keyの抽出やValueの抽出などの基本操作を行い、操作後のマッピングデータを返す。 |

## マッピング関数一覧

OceanBaseデータベースが現在サポートしているすべてのマッピング関数は以下のとおりです：

| 関数タイプ | 関数名 | 説明 |
|---------|---------|------|
| [マッピング構築関数](200.map-constructor-functions-of-mysql-mode.md) | map | マッピングデータを構築するために使用される。 |
| [演算子](200.map-constructor-functions-of-mysql-mode.md)  | {} | マッピングデータを構築するために使用される。 |
| [演算子](300.map-decision-functions-of-mysql-mode.md)  | =/!= | 二つのマッピングデータが等しいかどうかを判断するために使用される。 |
| [マッピング操作関数](600.map-manipulation-functions-of-mysql-mode.md) | map_keys | マッピングデータからKeyのリストを取得する。 |
| [マッピング操作関数](600.map-manipulation-functions-of-mysql-mode.md) | map_values | マッピングデータからValueのリストを取得する。 |
