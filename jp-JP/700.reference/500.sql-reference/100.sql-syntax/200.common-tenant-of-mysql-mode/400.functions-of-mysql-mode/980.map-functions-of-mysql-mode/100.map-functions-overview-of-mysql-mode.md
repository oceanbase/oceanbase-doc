# マッピング関数の概要

マッピング関数は、OceanBaseデータベースシステムで提供される、マッピングデータを処理するために特化した関数群です。これらの関数により、ユーザーは複雑なマッピングクエリや分析を実行できます。

以下は、OceanBaseのマッピング関数とその用途の概要です：

## マッピング関数の種類

| マッピング関数タイプ                               | 説明                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [マッピングコンストラクタ](200.map-constructor-functions-of-mysql-mode.md) | 新しいマッピングデータ型を構築するために使用される関数。 |
| [マッピング判定関数](300.map-decision-functions-of-mysql-mode.md) | 入力されたマッピングデータに対して論理的な判断を行い、ブール値を返す関数。 |
| [マッピング操作関数](600.map-manipulation-functions-of-mysql-mode.md)  | キーの抽出や値の抽出など、入力されたマッピングデータに対して基本的な操作を行い、操作後のマッピングデータを返す関数。 |

## マッピング関数一覧

OceanBaseデータベースが現在サポートしているすべてのマッピング関数は以下のとおりです：

| 関数タイプ | 関数名 | 説明 |
|---------|---------|------|
| [マッピング構築関数](200.map-constructor-functions-of-mysql-mode.md) | map | マッピングデータを構築するために使用されます。 |
| [演算子](200.map-constructor-functions-of-mysql-mode.md)  | {} | マッピングデータを構築するために使用されます。 |
| [演算子](300.map-decision-functions-of-mysql-mode.md)  | =/!= | 2つのマッピングデータが等しいかどうかを判断します。 |
| [マッピング操作関数](600.map-manipulation-functions-of-mysql-mode.md) | map_keys | マッピングデータのKeyリストを取得します。 |
| [マッピング操作関数](600.map-manipulation-functions-of-mysql-mode.md) | map_values | マッピングデータのValueリストを取得します。 |
