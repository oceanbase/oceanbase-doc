# マップ関数の概要

マップ関数は、OceanBaseデータベースシステムで提供される、マップデータを処理するために特化した関数群です。これらの関数により、ユーザーは複雑なマップクエリや分析を実行できます。

以下は、OceanBaseのマップ関数とその用途の概要です：

## マップ関数の種類

| マップ関数の種類                               | 説明                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [マップ構築関数](200.map-constructor-functions-of-mysql-mode.md) | 新しいマップデータ型を構築するために使用される関数。 |
| [マップ判定関数](300.map-decision-functions-of-mysql-mode.md) | 入力されたマップデータに対して論理判断を行い、ブール値を返す関数。 |
| [マップ操作関数](600.map-manipulation-functions-of-mysql-mode.md)  | 入力されたマップデータに対して、キーの抽出や値の抽出などの基本操作を行い、操作後のマップデータを返す。 |

## マップ関数一覧

OceanBaseデータベースが現在サポートしているすべてのマップ関数は以下のとおりです：

| 関数タイプ | 関数名 | 説明 |
|---------|---------|------|
| [マップ構築関数](200.map-constructor-functions-of-mysql-mode.md) | map | マップデータを構築するために使用される。 |
| [演算子](200.map-constructor-functions-of-mysql-mode.md)  | {} | マップデータを構築するために使用される。 |
| [演算子](300.map-decision-functions-of-mysql-mode.md)  | =/!= | 二つのマップデータが等しいかどうかを判断するために使用される。 |
| [マップ操作関数](600.map-manipulation-functions-of-mysql-mode.md) | map_keys | マップデータからキーのリストを取得する。 |
| [マップ操作関数](600.map-manipulation-functions-of-mysql-mode.md) | map_values | マップデータから値のリストを取得する。 |
