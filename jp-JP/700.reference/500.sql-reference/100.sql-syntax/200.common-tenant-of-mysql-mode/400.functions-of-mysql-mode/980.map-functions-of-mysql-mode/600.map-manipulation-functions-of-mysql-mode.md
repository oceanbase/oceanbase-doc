# マッピング関数

マッピング関数は、入力されたマップデータに対してキーまたは値の要素を抽出するなどの基本的な操作を行い、操作後のマップデータを返します。OceanBaseデータベースで現在サポートされているマッピング関数は、`map_keys()`と`map_values()`です。

## map_keys

`map_keys()` 関数は、ターゲットマップのキーリストを返します。構文は次のとおりです：

```sql
map_keys(map)
```

入力パラメータはマップデータである必要があります。

戻り値は配列型です。

例：

```sql
SELECT map_keys(map(1,"apple",2,"banana"));
+-------------------------------------+
| map_keys(map(1,"apple",2,"banana")) |
+-------------------------------------+
| [1,2]                               |
+-------------------------------------+
1 row in set
```

```sql
CREATE TABLE t1 (
  id INT NOT NULL AUTO_INCREMENT,
  m MAP(INT, INT)
);

INSERT INTO t1 (m) VALUES ('{1:1,2:2,3:3}');
INSERT INTO t1 (m) VALUES ('{"1":1,  2  : 2 , "3 " : 3}');
INSERT INTO t1 (m) VALUES ('{1.5:2, 1.6:"3"}');

SELECT m, map_keys(m) FROM t1;
+---------------+-------------+
| m             | map_keys(m) |
+---------------+-------------+
| {1:1,2:2,3:3} | [1,2,3]     |
| {1:1,2:2,3:3} | [1,2,3]     |
| {2:3}         | [2]         |
+---------------+-------------+
3 rows in set
```

## map_values

`map_values()` 関数は、ターゲットマップの値リストを返します。構文は次のとおりです：

```sql
map_values(map)
```

入力パラメータはマップデータである必要があります。

戻り値は配列型です。

例：

```sql
SELECT map_values(map(1,"apple",2,"banana"));
+-------------------------------------+
| map_values(map(1,"apple",2,"banana")) |
+-------------------------------------+
| ["apple","banana"]                  |
+-------------------------------------+
1 row in set
```

```sql
-- t1のテーブル作成と挿入ステートメントは、map_keysの例を参照してください。
SELECT m, map_values(m) FROM t1;
+---------------+---------------+
| m             | map_values(m) |
+---------------+---------------+
| {1:1,2:2,3:3} | [1,2,3]       |
| {1:1,2:2,3:3} | [1,2,3]       |
| {2:3}         | [3]           |
+---------------+---------------+
3 rows in set
```
