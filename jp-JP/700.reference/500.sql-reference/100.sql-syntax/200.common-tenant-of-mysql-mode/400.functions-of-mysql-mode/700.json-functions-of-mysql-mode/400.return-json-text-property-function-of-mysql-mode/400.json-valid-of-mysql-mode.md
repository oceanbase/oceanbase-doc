# JSON_VALID

## 説明

この関数は、入力値が有効なJSONであるかどうかを判断します。有効なJSONであれば1を返し、そうでない場合は0を返します。

## 構文

```sql
JSON_VALID(val)
```

## 説明

パラメータ `val` は入力値です。パラメータが `NULL` の場合、`NULL` を返します。

## 例

```sql
obclient> SELECT JSON_VALID('{"a": 1}');
+------------------------+
| JSON_VALID('{"a": 1}') |
+------------------------+
|                      1 |
+------------------------+
1 row in set

obclient> SELECT JSON_VALID('oceanbase'), JSON_VALID('"oceanbase"');
+-------------------------+---------------------------+
| JSON_VALID('oceanbase') | JSON_VALID('"oceanbase"') |
+-------------------------+---------------------------+
|                       0 |                         1 |
+-------------------------+---------------------------+
1 row in set
```
