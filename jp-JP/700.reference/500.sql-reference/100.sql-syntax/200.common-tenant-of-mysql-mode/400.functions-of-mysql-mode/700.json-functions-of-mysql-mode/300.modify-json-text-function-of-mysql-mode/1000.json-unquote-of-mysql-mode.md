# JSON_UNQUOTE

## 説明

この関数は、JSON値の参照を解除し、結果をutf8mb4文字列として返します。

## 構文

```sql
JSON_UNQUOTE(json_val)
```

## 説明

パラメータ `json_val` は参照されるJSON値です。パラメータが `NULL` の場合、`NULL` を返します。

値が二重引用符で始まり終わるものの、有効なJSON文字列リテラルではない場合、エラーが発生します。

## 例

```sql
obclient> SET @jn = '"abcd"';
Query OK, 0 rows affected

obclient> SELECT @jn, JSON_UNQUOTE(@jn);
+--------+-------------------+
| @jn    | JSON_UNQUOTE(@jn) |
+--------+-------------------+
| "abcd" | abcd              |
+--------+-------------------+
1 row in set

obclient> SET @jn = '[1, 2, 3, 4]';
Query OK, 0 rows affected

obclient> SELECT @jn, JSON_UNQUOTE(@jn);
+--------------+-------------------+
| @jn          | JSON_UNQUOTE(@jn) |
+--------------+-------------------+
| [1, 2, 3, 4] | [1, 2, 3, 4]      |
+--------------+-------------------+
1 row in set
```
