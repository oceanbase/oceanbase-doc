# JSON関数の概要

OceanBaseデータベースのMySQLモードでサポートされているJSON関数は、次の表のとおりです。

| **関数名** | **説明** |
| --- | --- |
| [JSON_ARRAY](100.create-json-text-function-of-mysql-mode/100.json-array-of-mysql-mode.md) | JSON配列を作成します。 |
| [JSON_ARRAYAGG](600.json-aggregate-function-of-mysql-mode/100.json-arrayagg-of-mysql-mode.md) | 結果を集約して単一のJSON配列にします。|
| [JSON_ARRAY_APPEND](300.modify-json-text-function-of-mysql-mode/100.json-array-append-of-mysql-mode.md)| 指定された値をJSONドキュメントに追加します。|
| [JSON_APPEND](300.modify-json-text-function-of-mysql-mode/120.json-append-of-mysql-mode.md) | 指定された値をJSONドキュメントに追加します。|
| [JSON_ARRAY_INSERT](300.modify-json-text-function-of-mysql-mode/200.json-array-insert-of-mysql-mode.md) | 配列をJSONドキュメントに挿入します。|
| [JSON_CONTAINS](200.search-json-text-function-of-mysql-mode/100.json-contains-of-mysql-mode.md) | 指定されたJSONドキュメントが、ターゲットのJSONドキュメントに含まれているかどうかを確認します。 |
| [JSON_CONTAINS_PATH](200.search-json-text-function-of-mysql-mode/200.json-contains-path-of-mysql-mode.md)| 指定されたパス内のデータが、ターゲットのJSONドキュメントに含まれているかどうかを確認します。|
| [JSON_DEPTH](400.return-json-text-property-function-of-mysql-mode/100.json-depth-of-mysql-mode.md)| JSONドキュメントの最大深さを返します。|
| [JSON_EXTRACT](200.search-json-text-function-of-mysql-mode/300.json-extract-of-mysql-mode.md) | JSONドキュメントからデータを返します。|
| [JSON_INSERT](300.modify-json-text-function-of-mysql-mode/300.json-insert-of-mysql-mode.md) | データをJSONドキュメントに挿入します。|
| [JSON_KEYS](200.search-json-text-function-of-mysql-mode/400.json-keys-of-mysql-mode.md) | JSONドキュメントから、指定されたパスに対応するKeyの配列を返します。|
| [JSON_LENGTH](400.return-json-text-property-function-of-mysql-mode/200.json-length-of-mysql-mode.md) | JSONドキュメントの長さを返します。|
| [JSON_MERGE](300.modify-json-text-function-of-mysql-mode/400.json-merge-of-mysql-mode.md) | 複数のJSONドキュメントをマージします。|
| [JSON_MERGE_PATCH](300.modify-json-text-function-of-mysql-mode/500.json-merge-patch-of-mysql-mode.md) | 複数のJSONドキュメントをマージします。結果では重複するKeyを持つメンバーは保持されません。|
| [JSON_MERGE_PRESERVE](300.modify-json-text-function-of-mysql-mode/600.json-merge-preserve-of-mysql-mode.md) | 複数のJSONドキュメントをマージします。|
| [JSON_OBJECT](100.create-json-text-function-of-mysql-mode/200.json-object-of-mysql-mode.md)| JSONオブジェクトを作成します。 |
| [JSON_OVERLAPS](200.search-json-text-function-of-mysql-mode/500.json-overlaps-of-mysql-mode.md) | 二つのJSONドキュメントを比較します。|
| [JSON_PRETTY](500.json-utility-function-of-mysql-mode/100.json-pretty-of-mysql-mode.md)| フォーマットに従ってJSONドキュメントを出力します。|
| [JSON_QUOTE](100.create-json-text-function-of-mysql-mode/300.json-quote-of-mysql-mode.md)| JSONドキュメントを引用します。|
| [JSON_REMOVE](300.modify-json-text-function-of-mysql-mode/700.json-remove-of-mysql-mode.md) | JSONドキュメントからデータを削除します。|
| [JSON_REPLACE](300.modify-json-text-function-of-mysql-mode/800.json-replace-of-mysql-mode.md)| JSONドキュメント内の値を置き換えます。|
| [JSON_SEARCH](200.search-json-text-function-of-mysql-mode/600.json-search-of-mysql-mode.md) | JSONドキュメント内の値のパスを返します。|
| [JSON_SET](300.modify-json-text-function-of-mysql-mode/900.json-set-of-mysql-mode.md) | JSONドキュメントにデータを挿入します。|
| [JSON_STORAGE_SIZE](500.json-utility-function-of-mysql-mode/200.json-storage-size-of-mysql-mode.md) | JSONドキュメントのバイナリバイトサイズを格納します。|
| [JSON_TABLE](450.json-table-functions-of-mysql-mode.md)| JSONドキュメントからデータを抽出し、指定された列を持つリレーショナルテーブルを返します。|
| [JSON_TYPE](400.return-json-text-property-function-of-mysql-mode/300.json-type-of-mysql-mode.md) | JSON値の型を返します。|
| [JSON_UNQUOTE](300.modify-json-text-function-of-mysql-mode/1000.json-unquote-of-mysql-mode.md) | JSON値の引用を解除します。|
| [JSON_VALUE](200.search-json-text-function-of-mysql-mode/700.json-value-of-mysql-mode.md) | 指定されたパスからJSONドキュメント内の値を抽出して返します。|
| [JSON_VALID](400.return-json-text-property-function-of-mysql-mode/400.json-valid-of-mysql-mode.md) | JSON値が有効かどうかを判断します。|
| [JSON_OBJECTAGG](600.json-aggregate-function-of-mysql-mode/200.json-objectagg-of-mysql-mode.md)| キーと値のペアを含むJSONオブジェクトを返します。|
| [MEMBER OF](200.search-json-text-function-of-mysql-mode/800.member-of-of-mysql-mode.md)| 検索された要素がJSON配列のいずれかの要素と同じ場合、この関数は1を返し、そうでない場合は0を返します。|
| [JSON_SCHEMA_VALIDATION_REPORT](700.json-schema-function-of-mysql-mode/200.json-schema-validation-report-of-mysql-mode.md) | JSONドキュメントがJSON Schemaに準拠している場合は1を返し、準拠していない場合は0を返します。|
| [JSON_SCHEMA_VALID](700.json-schema-function-of-mysql-mode/100.json-schema-valid-of-mysql-mode.md) | JSON Schemaの検証レポートを返します。検証レポートはJSON形式です。|
