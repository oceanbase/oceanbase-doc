# SM3

## 宣言

```javascript
SM3(str)
```

## 説明

SM3は、中国国家暗号管理局が発表したハッシュ値計算方式であり、戻り値は32ビットの16進数文字列となります。

## 例

```javascript
obclient> SELECT SM3(1);
+------------------------------------------------------------------+
| sm3(1)                                                           |
+------------------------------------------------------------------+
| cbdddb8e8421b23498480570d7d75330538a6882f5dfdc3b64115c647f3328c4 |
+------------------------------------------------------------------+
1 row in set
```
