# RANDOM_BYTES

## 宣言

```sql
RANDOM_BYTES(len)
```

## 説明

lenバイトのランダムなバイナリ文字列を返します。lenの有効な範囲は[1～1024]です。

## 例

```sql
obclient [test]> select RANDOM_BYTES(2);
+-----------------+
| RANDOM_BYTES(2) |
+-----------------+
| H              |
+-----------------+
1 row in set
```
