# RANDOM_BYTES

## 宣言

```sql
RANDOM_BYTES(len)
```

## 説明

lenバイトの長さを持つランダムなバイナリ文字列を返します。lenの値は[1～1024]の範囲で有効です。

## 例

```sql
obclient [test]> select RANDOM_BYTES(2);
+-----------------+
| RANDOM_BYTES(2) |
+-----------------+
| H              |
+-----------------+
1 row in set
```
