# VALIDATE_PASSWORD_STRENGTH

## 宣言

```sql
VALIDATE_PASSWORD_STRENGTH(str)
```

## 説明

指定されたパスワード文字列に対して、その強度を示す整数を返します。戻り値の範囲は0（弱い）から100（強い）です。パスワード評価に関連するシステム変数は、`SHOW VARIABLES LIKE 'validate_password%';` で確認できます。

## 例

```sql
obclient [test]> SELECT VALIDATE_PASSWORD_STRENGTH('ob$_@123');
+----------------------------------------------+
| VALIDATE_PASSWORD_STRENGTH('ob$_@123') |
+----------------------------------------------+
|                                          100 |
+----------------------------------------------+
1 row in set
```
