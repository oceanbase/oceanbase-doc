# SHA

## 宣言

```sql
SHA(str)
```

## 説明

指定された文字列のSHA-1 160ビットのチェックサムを計算して返します。この値は、40桁の16進数で表されます。これは`SHA1()`関数と同等です。

## 例

```sql
obclient [test]> SELECT SHA('OB');
+------------------------------------------+
| SHA('OB')                                |
+------------------------------------------+
| 29a6de2fd8618f31afb281a608c57995b7eb105d |
+------------------------------------------+
1 row in set
```
