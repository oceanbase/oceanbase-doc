# UNCOMPRESS

## 宣言

```sql
UNCOMPRESS(str)
```

## 説明

[COMPRESS()](../500.encryption-and-compression-functions-of-mysql-mode/300.compress-of-mysql-mode.md)関数によって圧縮された文字列を解凍します。

## 例

```sql
obclient [test]> SELECT UNCOMPRESS(COMPRESS('abc'));
+-----------------------------+
| UNCOMPRESS(COMPRESS('abc')) |
+-----------------------------+
| abc                         |
+-----------------------------+
1 row in set
```
