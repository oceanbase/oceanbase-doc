# SM4_DECRYPT

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>Community Editionは現在、`sm4_decrypt`システム関数をサポートしていません。</p>
</main>

## 宣言

```sql
SM4_DECRYPT(str,key_str[,init_vector])
```

## 説明

キー`key_str`に基づいて、SM4で復号化された平文の暗号文`str`を返します。

`init_vector`パラメータの詳細については、[SM4_ENCRYPT](1900.sm4-encrypt-of-mysql-mode.md)を参照してください。

## 例

1. `sm4-ecb`モードでは、`SM4_DECRYPT`は2つのパラメータ`{str, key_str}`を受け取ります。3つの値が渡された場合、3番目の値は無視されます。例えば：

```javascript
SET block_encryption_mode = 'sm4-ecb';

SELECT hex(sm4_decrypt('asdasdasdasd', '12312313123'))  FROM dual;
+-------------------------------------------------+
| hex(sm4_decrypt('asdasdasdasd', '12312313123')) |
+-------------------------------------------------+
| NULL                                            |
+-------------------------------------------------+
1 row in set
```

2. `sm4-cbc`、`sm4-cfb`、`sm4-ofb`モードでは、`SM4_DECRYPT`は3つのパラメータのみを受け取ります。例えば：

```javascript
SET block_encryption_mode= 'sm4-cbc';

SELECT hex(sm4_decrypt('asdasdasdasd', '12312313123', 'asdasdkljasdkljalskdjaklsdjaklsjdaklsdjlaksdj'))  FROM dual;
+--------------------------------------------------------------------------------------------------+
| hex(sm4_decrypt('asdasdasdasd', '12312313123', 'asdasdkljasdkljalskdjaklsdjaklsjdaklsdjlaksdj')) |
+--------------------------------------------------------------------------------------------------+
| NULL                                                                                             |
+--------------------------------------------------------------------------------------------------+
1 row in set
```
