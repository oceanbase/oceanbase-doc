# UNCOMPRESSED_LENGTH

## 宣言

```sql
UNCOMPRESSED_LENGTH(str)
```

## 説明

[COMPRESS()](../500.encryption-and-compression-functions-of-mysql-mode/300.compress-of-mysql-mode.md) 関数で圧縮する前の圧縮文字列の長さを返します。

## 例

```sql
obclient [test]> SELECT UNCOMPRESSED_LENGTH(COMPRESS('abc'));
+--------------------------------------+
| UNCOMPRESSED_LENGTH(COMPRESS('abc')) |
+--------------------------------------+
|                                    3 |
+--------------------------------------+
1 row in set
```
