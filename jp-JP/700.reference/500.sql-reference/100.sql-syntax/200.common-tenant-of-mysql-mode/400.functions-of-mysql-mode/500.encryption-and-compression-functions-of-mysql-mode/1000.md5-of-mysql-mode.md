# MD5

## 宣言

```javascript
MD5(str)
```

## 説明

文字列のMD5 128ビットチェックサムを返します。

戻り値は32ビットの16進数で構成される文字列です。`str`が`NULL`場合、`NULL`返します。

## 例

```javascript
obclient> SELECT MD5(1);
+----------------------------------+
| MD5(1)                           |
+----------------------------------+
| c4ca4238a0b923820dcc509a6f75849b |
+----------------------------------+
1 row in set
```
