# PASSWORD

## 宣言

```sql
PASSWORD(str)
```

## 説明

文字列を暗号化するために使用されます。明文の文字列をパラメータとして受け取り、その文字列の暗号化バージョンを返します。

## 例

```sql
obclient [test]> SELECT PASSWORD('***1***');
```

実行結果は次のとおりです：

```shell
+--------------------------------------------+
| PASSWORD('***1***')                        |
+--------------------------------------------+
| *BA10AFC5C8D9F9D1A5704E9C274C1A63EE9CB94B  |
+--------------------------------------------+
1 row in set, 1 warning
```
