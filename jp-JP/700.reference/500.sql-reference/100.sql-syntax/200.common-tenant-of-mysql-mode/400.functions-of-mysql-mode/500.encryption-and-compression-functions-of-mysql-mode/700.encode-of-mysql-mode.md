# ENCODE

## 宣言

```sql
ENCODE(str,pass_str)
```

## 説明

`ENCODE()`は、パスワードとして`pass_str`を使用して文字列を暗号化します。結果として返されるのは、`str`と同じ長さのバイナリ文字列です。この結果を復号するには、`DECODE()`を使用してください。

## 例

`ENCODE()`を使用する場合は、リスクを軽減するためにシャドー値を使用する必要があります。

```sql
obclient> SELECT ENCODE('text', CONCAT('ob_random_salt','ob_secret_password'))
+---------------------------------------------------------------+
| ENCODE('text', CONCAT('ob_random_salt','ob_secret_password')) |
+---------------------------------------------------------------+
5+                                                          |
+---------------------------------------------------------------+
1 row in set
```
