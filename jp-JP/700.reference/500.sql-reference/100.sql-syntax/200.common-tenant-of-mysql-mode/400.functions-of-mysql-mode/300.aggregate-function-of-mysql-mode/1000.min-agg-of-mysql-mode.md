# MIN

## 宣言

```sql
MIN([DISTINCT | ALL] expr)
```

## 説明

指定されたデータの中で最小値を返します。

`MIN()` の値は文字列パラメータであり、結果として最小の文字列値が返されます。`DISTINCT` キーワードは異なる値のみを計算することを示し、デフォルトは `ALL` です。

## 例

テーブル `a` に `id=1,num=10`、`id=2,num=20`、`id=3,num=30` の3行のデータがあるとします。そのうち `num` の最小値を取得します：

```sql
obclient> SELECT MIN(num) FROM a;
+----------------+
| MIN(num)       |
+----------------+
|             10 |
+----------------+
1 row in set
```
