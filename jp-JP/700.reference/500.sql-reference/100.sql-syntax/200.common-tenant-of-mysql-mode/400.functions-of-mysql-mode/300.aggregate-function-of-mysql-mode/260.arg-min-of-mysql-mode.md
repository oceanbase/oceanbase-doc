# ARG_MIN

## 宣言

```sql
ARG_MAX([DISTINCT] minimize_col, return_col)
```

## 説明

`ARG_MAX` 関数は、データセット内で目的の式を最大化する行を検索し、その行に対応する指定された列の値または完全なレコードを返します。

ここで：

* `minimize_col` は最小化する列を指します。
* `return_col` は戻り値の対応する列を指します。最小値の行のその列の値を返しますが、`NULL` の場合はその行を無視します。

## 例

```shell
obclient> SELECT * FROM test;
+------+------+
| a    | b    |
+------+------+
| a    |    1 |
| b    |    2 |
| c    |    2 |
| NULL |    3 |
| NULL | NULL |
| d    | NULL |
+------+------+
6 rows in set (0.000 sec)
```

```sql
obclient> SELECT arg_min(a, b), min(b) FROM test;
+---------------+--------+
| arg_min(a, b) | min(b) |
+---------------+--------+
| a             |      1 |
+---------------+--------+
1 row in set (0.006 sec)
```
