# OB_TRANSACTION_ID

## 宣言

```sql
OB_TRANSACTION_ID()
```

## 説明

* 現在のセッションがアクティブトランザクション中である場合、そのトランザクションIDの整数値（0より大きい）を返します。
* 現在のセッションがアクティブトランザクション中でない場合、0を返します。

## 例

現在のセッションがアクティブトランザクション中のトランザクションIDを照会します。

1. トランザクションを開始します。

   ```shell
   obclient [test]> BEGIN;
   ```

2. 現在のトランザクションIDを照会します。

   ```shell
   obclient [test]> SELECT OB_TRANSACTION_ID();
   ```

   実行結果は次のとおりです：

   ```shell
   +---------------------+
   | OB_TRANSACTION_ID() |
   +---------------------+
   |            14565563 |
   +---------------------+
   1 row in set
   ```

3. トランザクションをコミットします。

   ```shell
   obclient [test]> COMMIT;
   ```

4. 現在アクティブトランザクションに含まれていないトランザクションIDを照会します。

   ```shell
   obclient [test]> SELECT OB_TRANSACTION_ID();
   ```

   実行結果は次のとおりです：

   ```shell
   +---------------------+
   | OB_TRANSACTION_ID() |
   +---------------------+
   |                   0 |
   +---------------------+
   1 row in set
   ```
