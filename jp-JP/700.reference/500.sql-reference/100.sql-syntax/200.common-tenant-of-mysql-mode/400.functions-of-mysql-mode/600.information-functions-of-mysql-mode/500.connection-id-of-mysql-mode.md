# CONNECTION_ID

## 宣言

```sql
CONNECTION_ID()
```

## 説明

この関数は、現在のセッションのクライアントセッションIDを返します。このIDは、クライアント内でのセッションの一意の識別子です。

## 例

現在のセッションのクライアントセッションIDを取得します。

```sql
obclient [(none)]> SELECT CONNECTION_ID() AS Client_Session_ID;
```

戻り値は次のとおりです：

```shell
+-------------------+
| Client_Session_ID |
+-------------------+
|        3221488032 |
+-------------------+
1 row in set
```

## 関連ドキュメント

`SHOW PROCESSLIST` ステートメントを使用して、現在のデータベース内のセッション数とセッションIDを確認することもできます。詳細については、[テナントセッションの表示](../../../../../1200.database-proxy/1500.view-tenant-sessions.md)を参照してください。
