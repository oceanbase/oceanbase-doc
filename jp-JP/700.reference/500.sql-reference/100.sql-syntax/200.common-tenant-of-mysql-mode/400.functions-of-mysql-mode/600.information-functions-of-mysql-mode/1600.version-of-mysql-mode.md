# VERSION

## 宣言

```sql
VERSION()
```

## 説明

現在のOceanBaseデータベースのMySQL互換バージョン番号を返します。文字セットはutf8mb4です。

## 例

```sql
obclient> SELECT VERSION();
+---------------------------+
| VERSION()                 |
+---------------------------+
| 5.7.25-OceanBase-v4.1.0.0 |
+---------------------------+
1 row in set
```
