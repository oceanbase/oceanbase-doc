# CURRENT_ROLE

## 宣言

```sql
CURRENT_ROLE()
```

## 説明

この関数は、現在のセッションで現在のユーザーがアクティブなロールを確認するために使用されます。クエリ結果が`NONE`場合、現在のユーザーにはアクティブなロールがないことを意味し、ユーザーが使用できる権限はアクティブなロールの権限のみです。

## 例

```sql
obclient [(none)]> SELECT CURRENT_ROLE();
```

実行結果は次のとおりです：

```shell
+-----------------------------+
| CURRENT_ROLE()              |
+-----------------------------+
| `role002`@`%`,`role001`@`%` |
+-----------------------------+
1 row in set
```
