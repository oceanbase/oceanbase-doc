# CURRENT_ROLE

## 宣言

```sql
CURRENT_ROLE()
```

## 説明

この関数は、現在のセッションにおいて、現在のユーザーがアクティブなロールを確認するために使用されます。クエリ結果が `NONE` の場合、現在のユーザーにはアクティブなロールがなく、ユーザーが使用できるのはアクティブなロールの権限のみです。

## 例

```sql
obclient [(none)]> SELECT CURRENT_ROLE();
```

実行結果は次のとおりです：

```shell
+-----------------------------+
| CURRENT_ROLE()              |
+-----------------------------+
| `role002`@`%`,`role001`@`%` |
+-----------------------------+
1 row in set
```
