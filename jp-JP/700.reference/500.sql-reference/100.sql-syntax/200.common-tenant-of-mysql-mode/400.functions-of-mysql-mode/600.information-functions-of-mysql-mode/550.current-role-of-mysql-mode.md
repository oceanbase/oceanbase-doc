# CURRENT_ROLE

## 宣言

```sql
CURRENT_ROLE()
```

## 説明

この関数は、現在のセッションで現在のユーザーが有効なロールを確認するために使用されます。クエリ結果が `NONE` の場合、現在のユーザーに有効なロールがないことを意味し、ユーザーが使用できるのは有効なロールの権限のみです。

## 例

```sql
obclient [(none)]> SELECT CURRENT_ROLE();
```

戻り値は次のとおりです：

```shell
+-----------------------------+
| CURRENT_ROLE()              |
+-----------------------------+
| `role002`@`%`,`role001`@`%` |
+-----------------------------+
1 row in set
```
