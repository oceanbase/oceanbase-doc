# USER

## 宣言

```sql
USER()
```

## 説明

現在のユーザー名とホスト名を返します。返される値の文字セットはutf8mb4です。

## 例

```sql
obclient> SELECT USER();
+---------------------+
| USER()              |
+---------------------+
| root@xxx.xx.xxx.xxx |
+---------------------+
1 row in set
```
