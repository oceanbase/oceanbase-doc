# CHARSET

## 宣言

```sql
CHARSET(str)
```

## 説明

文字列 `str` で使用される文字セットを返します。

## 例

```sql
obclient> SELECT CHARSET("oceanbaase");
+-----------------------+
| CHARSET("oceanbaase") |
+-----------------------+
| utf8mb4               |
+-----------------------+
1 row in set

obclient> SELECT CHARSET(CONVERT("oceanbase" USING binary));
+--------------------------------------------+
| CHARSET(CONVERT("oceanbase" USING binary)) |
+--------------------------------------------+
| binary                                     |
+--------------------------------------------+
1 row in set
```
