# BENCHMARK

## 構文

```sql
BENCHMARK(count,expr)
```

## 説明

`BENCHMARK()`関数は、式`expr`を`count`回繰り返し実行し、結果として0を返します。不適切なパラメータに対しては、`NULL`値や`count`が負の数の場合など、`NULL`を返します。

`expr`はスカラー式である必要があります。`BENCHMARK()`はスカラー式の実行性能を測定するために使用できます。実行後のレポート時間はサーバーのCPU時間ではなく、クライアントの実行時間です。

## 例

```sql
obclient> SELECT BENCHMARK(100,AES_ENCRYPT('hello','world'));
+---------------------------------------------+
| BENCHMARK(100,AES_ENCRYPT('hello','world')) |
+---------------------------------------------+
|                                           0 |
+---------------------------------------------+
```
