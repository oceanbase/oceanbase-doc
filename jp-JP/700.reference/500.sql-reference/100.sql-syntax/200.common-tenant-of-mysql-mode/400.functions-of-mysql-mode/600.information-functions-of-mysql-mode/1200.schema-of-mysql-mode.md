# SCHEMA

## 宣言

```sql
SCHEMA()
```

## 説明

現在のスキーマ名を返します。この関数は`DATABASE()`のシノニムです。

## 例

次の例は、現在のスキーマ名を照会するものです。

```sql
obclient> SELECT SCHEMA();
+----------+
| SCHEMA() |
+----------+
| test     |
+----------+
1 row in set
```
