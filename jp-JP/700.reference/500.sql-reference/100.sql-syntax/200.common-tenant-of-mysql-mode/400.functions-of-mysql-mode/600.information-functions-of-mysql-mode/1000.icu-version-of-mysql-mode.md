# ICU_VERSION

## 宣言

```sql
ICU_VERSION()
```

## 説明

この関数は、正規表現操作をサポートするICUライブラリのバージョンを返します。
OceanBaseデータベースは、International Components for Unicode (ICU) を使用して正規表現をサポートしています。ICUは完全なUnicodeサポートを提供し、マルチバイトセーフです。

## 例

```sql
obclient> SELECT ICU_VERSION();
+---------------+
| ICU_VERSION() |
+---------------+
| 69.1          |
+---------------+
1 row in set
```
