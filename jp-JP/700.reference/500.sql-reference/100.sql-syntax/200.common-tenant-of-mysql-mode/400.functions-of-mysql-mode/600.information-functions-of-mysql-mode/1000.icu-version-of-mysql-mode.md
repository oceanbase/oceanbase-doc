# ICU_VERSION

## 宣言

```sql
ICU_VERSION()
```

## 説明

この関数は、正規表現操作をサポートする ICU ライブラリのバージョンを返します。
OceanBase データベースは、International Components for Unicode (ICU) を使用して正規表現をサポートしています。ICU は完全な Unicode サポートを提供し、マルチバイトセーフです。

## 例

```sql
obclient> SELECT ICU_VERSION();
+---------------+
| ICU_VERSION() |
+---------------+
| 69.1          |
+---------------+
1 row in set
```
