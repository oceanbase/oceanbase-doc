# SESSION_USER

## 宣言

```sql
SESSION_USER()
```

## 説明

現在のユーザー名とホスト名を返します。返される値の文字セットはutf8mb4です。

この関数は`USER()`のシノニムです。

## 例

```sql
obclient> SELECT SESSION_USER();
+---------------------+
| SESSION_USER()      |
+---------------------+
| root@100.0.0.1 |
+---------------------+
1 row in set
```
