# SYSTEM_USER

## 宣言

```sql
SYSTEM_USER()
```

## 説明

現在のユーザー名とホスト名を返します。この関数は`USER()`のシノニムです。

## 例

```sql
obclient> SELECT SYSTEM_USER();
+---------------------+
| SYSTEM_USER()       |
+---------------------+
| root@xxx.xx.xxx.xxx |
+---------------------+
1 row in set
```
