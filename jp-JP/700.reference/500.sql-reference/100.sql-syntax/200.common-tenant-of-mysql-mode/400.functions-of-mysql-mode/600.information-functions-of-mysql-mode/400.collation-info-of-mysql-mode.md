# COLLATION

## 宣言

```sql
COLLATION(str)
```

## 説明

文字列 `str` の照合順序を返します。

`SHOW COLLATION` ステートメントを使用して、OceanBaseデータベースがサポートする照合順序を確認できます。

## 例

```sql
obclient> SELECT COLLATION("oceanbase");
+------------------------+
| COLLATION("oceanbase") |
+------------------------+
| utf8mb4_general_ci     |
+------------------------+
1 row in set

obclient> SELECT COLLATION("oceanbase" COLLATE utf8mb4_bin);
+--------------------------------------------+
| COLLATION("oceanbase" COLLATE utf8mb4_bin) |
+--------------------------------------------+
| utf8mb4_bin                                |
+--------------------------------------------+
1 row in set
```
