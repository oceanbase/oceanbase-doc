# GTID_SUBSET()

## 説明

この関数は、あるGTID集合が別のGTID集合の部分集合であるかどうかを検証し、そうであれば`true`を返し、そうでなければ`false`を返します。

## 構文

```sql
GTID_SUBSET(set1,set2)
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このキーワード構文のみサポートされており、機能は有効ではありません。</p>
</main>
