# IF

## 宣言

```sql
IF(expr1,expr2,expr3)
```

## 説明

`expr1` の値が `TRUE` (つまり、`expr1` \> 0 かつ `expr1` <> NULL) の場合、結果は `expr2` を返します。そうでない場合、結果は `expr3` を返します。

`IF()` の戻り値は数値または文字列のいずれかになります。これは使用する内容によって決まります。

`expr2` と `expr3` のうち明示的に `NULL` であるものが1つだけの場合、`IF()` 関数の結果型は、`NULL` 以外の式の結果型になります。

## 例

```sql
obclient> SELECT IF(5>6, 'T','F'), IF (5>6, 1, 0), IF(NULL, 'TRUE', 'FALSE'), IF(0, 'TRUE', 'FALSE')\G
*************************** 1. row ***************************
         IF(5>6, 'T','F'): F
           IF (5>6, 1, 0): 0
IF(NULL, 'TRUE', 'FALSE'): FALSE
   IF(0, 'TRUE', 'FALSE'): FALSE
1 row in set
```
