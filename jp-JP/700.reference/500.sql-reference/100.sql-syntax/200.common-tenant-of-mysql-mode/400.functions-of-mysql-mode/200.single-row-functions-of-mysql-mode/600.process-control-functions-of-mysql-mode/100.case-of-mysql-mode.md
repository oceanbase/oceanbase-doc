# CASE

## 宣言

```sql
CASE value WHEN compare-value THEN result [WHEN [compare-value] THEN result ...] [ELSE result] END
CASE WHEN condition THEN result [WHEN [condition] THEN result ...] [ELSE result] END
```

## 説明

最初の宣言による戻り値では、`value` = `compare-value` となります。一方、2番目の宣言による戻り値は、最初の条件が真である場合です。一致する結果値がない場合、`ELSE` の後の結果が返されます。`ELSE` 部分がない場合、戻り値は `NULL` となります。

## 例

```sql
obclient> SELECT CASE 'B' WHEN 'A' THEN 1 WHEN 'B' THEN 2 END;
+----------------------------------------------+
| CASE 'B' WHEN 'A' THEN 1 WHEN 'B' THEN 2 END |
+----------------------------------------------+
|                                            2 |
+----------------------------------------------+
1 row in set

obclient> SELECT CASE CONCAT('A','B') WHEN CONCAT('AB','') THEN 'A' WHEN 'B' THEN 'B' END;
+--------------------------------------------------------------------------+
| CASE CONCAT('A','B') WHEN CONCAT('AB','') THEN 'A' WHEN 'B' THEN 'B' END |
+--------------------------------------------------------------------------+
| A                                                                        |
+--------------------------------------------------------------------------+
1 row in set

obclient> SELECT CASE WHEN 1>0 THEN 'TRUE' ELSE 'FALSE' END;
+--------------------------------------------+
| CASE WHEN 1>0 THEN 'TRUE' ELSE 'FALSE' END |
+--------------------------------------------+
| TRUE                                       |
+--------------------------------------------+
1 row in set
```
