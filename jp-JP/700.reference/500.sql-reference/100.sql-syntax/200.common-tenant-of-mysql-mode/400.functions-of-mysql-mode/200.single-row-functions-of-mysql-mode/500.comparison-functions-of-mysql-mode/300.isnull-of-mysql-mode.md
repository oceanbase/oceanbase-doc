# ISNULL

## 宣言

```sql
ISNULL(expr)
```

## 説明

パラメータ `expr` が `NULL` の場合、`ISNULL()` の戻り値は `1` となり、それ以外の場合は `0` となります。

`ISNULL()` 関数は、等号（=）に代えて値が `NULL` であるかどうかを判断するために使用できます。（値と `NULL` を等号で比較すると常に `NULL` が返されます）`ISNULL()` 関数は、`IS NULL` 比較演算子といくつかの共通点があります。比較演算子の詳細については、[比較演算子](../../../200.operator-of-mysql-mode/500.comparison-operators-of-mysql-mode.md)を参照してください。

## 例

```sql
obclient> SELECT ISNULL(null), ISNULL('test'), ISNULL(123.456), ISNULL('10:00');
+--------------+----------------+-----------------+-----------------+
| ISNULL(null) | ISNULL('test') | ISNULL(123.456) | ISNULL('10:00') |
+--------------+----------------+-----------------+-----------------+
|            1 |              0 |               0 |               0 |
+--------------+----------------+-----------------+-----------------+
1 row in set

obclient> SELECT ISNULL(null+1);
+----------------+
| ISNULL(null+1) |
+----------------+
|              1 |
+----------------+
1 row in set
```
