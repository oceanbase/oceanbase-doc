# TO_CHAR(character)

## 説明

この関数は、文字データを `VARCHAR` 型の文字列に変換します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBase データベース V4.3.5 では、この関数は V4.3.5 BP1 からサポートされています。</p>
</main>

## 構文宣言

```sql
TO_CHAR(character)
```

## パラメータの説明

`character`：変換する文字データを表します。

## 戻り値のタイプ

* `VARCHAR` 型のデータを返します。
* `character` の値が `NULL` の場合、`NULL` を返します。

## 例

```sql
SELECT TO_CHAR('Hello, World!'), TO_CHAR(NULL);
```

結果は次のとおりです：

```shell
+--------------------------+---------------+
| TO_CHAR('Hello, World!') | TO_CHAR(NULL) |
+--------------------------+---------------+
| Hello, World!            |          NULL |
+--------------------------+---------------+
1 row in set
```
