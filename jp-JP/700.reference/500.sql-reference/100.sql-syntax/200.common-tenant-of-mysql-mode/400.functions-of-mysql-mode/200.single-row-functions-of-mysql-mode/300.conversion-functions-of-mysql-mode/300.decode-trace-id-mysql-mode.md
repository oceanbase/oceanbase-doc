# DECODE_TRACE_ID

## 宣言

```sql
DECODE_TRACE_ID()
```

## 説明

`DECODE_TRACE_ID()`関数は、trace_idを解析し、SQLリクエストの送信元サーバーのIPアドレスとポート番号を返します。また、ビュー[GV$OB_SQL_AUDIT](../../../../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/5300.gv-sql_audit-of-mysql-mode.md)から関連情報を確認することもできます。

## 例

```sql
obclient [(none)]> SELECT DECODE_TRACE_ID(LAST_TRACE_ID());
```

実行結果は次のとおりです：

```shell
+----------------------------------+
| DECODE_TRACE_ID(LAST_TRACE_ID()) |
+----------------------------------+
| xxx.xx.xxx.xx1:2882              |
+----------------------------------+
1 row in set
```
