# TIMESTAMP_TO_SCN

## 構文

```sql
TIMESTAMP_TO_SCN(timestamp)
```

## 説明

`TIMESTAMP_TO_SCN()`関数は、タイムスタンプ型のパラメータを入力として受け取り、対応するSCN（System Change Number）を返します。この関数の入力パラメータの型は`DATETIME`であり、返されるデータ型は`UINT64_T`です。

## 例

```sql
obclient> SELECT TIMESTAMP_TO_SCN("2023-02-21 00:00:01");
+-----------------------------------------+
| timestamp_to_scn("2023-02-21 00:00:01") |
+-----------------------------------------+
|                     1676908801000000000 |
+-----------------------------------------+
1 row in set
```
