# SCN_TO_TIMESTAMP

## 構文

```sql
SCN_TO_TIMESTAMP(number)
```

## 説明

`SCN_TO_TIMESTAMP()` 関数は、SCNをパラメータとして受け取り、そのSCNに関連付けられたタイムスタンプを返します。戻り値は `DATETIME` 型です。

## 例

```sql
obclient [oceanbase]> SELECT MAX_SCN, SCN_TO_TIMESTAMP(MAX_SCN) FROM gv$ob_log_stat;
+---------------------+----------------------------+
| MAX_SCN             | SCN_TO_TIMESTAMP(MAX_SCN)  |
+---------------------+----------------------------+
| 1676966395664862550 | 2023-02-21 15:59:55.664862 |
| 1676966395664862550 | 2023-02-21 15:59:55.664862 |
+---------------------+----------------------------+
2 rows in set
```

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>gv$ob_log_stat</code> はログストリームのログ同期状態を表示する内部テーブルであり、その <code>max_scn</code> フィールドはSCN型です。<code>SCN_TO_TIMESTAMP()</code> 関数を使用してSCNをタイムスタンプに変換します。</p>
</main>
