# TO_PINYIN

## 宣言

```sql
TO_PINYIN('chinese_string','option')
```

### パラメータの説明

`option` はオプションを表します。「データベース」を例に、シナリオごとにオプション名と出力結果を紹介します。

|オプション|すべて小文字|頭文字大文字|すべて大文字|
|-----------|------|--------|-------|
|頭文字|INITIAL<br>(sjk)|CAP_INITIAL<br>(Sjk)|ALL_CAP_INITIAL<br>(SJK)|
|フルスペル|FULL（指定されない場合のデフォルトモード）<br>(shujuku)|CAP(ShuJuKu)<br>FIRST_CAP(Shujuku)|ALL_CAP<br>(SHUJUKU)|

## 説明

この関数は、中国語をピンイン文字列に変換するために使用されます。

入力として中国語の文字列を受け取り、対応するピンイン文字を含む文字列を返します。

## 例

**例1：**

以下のコマンドを実行して、文字列を対応するピンイン文字列に変換します。

```sql
SELECT TO_PINYIN('データベース') FROM DUAL;
```

実行結果は次のとおりです：

```shell
+------------------------+
| TO_PINYIN('数据库')    |
+------------------------+
| shùjùkù                |
+------------------------+
1 row in set
```

**例2：**

以下のコマンドを実行して、中国語の文字列を対応するピンイン文字列に変換し、先頭の文字を大文字にします。

```sql
SELECT TO_PINYIN('データベース','CAP') FROM DUAL;
```

実行結果は次のとおりです：

```shell
+------------------------------+
| TO_PINYIN('数据库','CAP')    |
+------------------------------+
| ShùJùKù                      |
+------------------------------+
1 row in set (0.000 sec)
```
