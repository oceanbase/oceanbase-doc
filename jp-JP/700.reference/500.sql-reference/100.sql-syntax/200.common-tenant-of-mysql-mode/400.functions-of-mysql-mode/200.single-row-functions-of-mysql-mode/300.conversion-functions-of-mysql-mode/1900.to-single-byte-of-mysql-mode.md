# TO_SINGLE_BYTE

## 説明

この関数は、文字列内の複数バイト文字を対応する1バイト文字に変換します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2バージョンでは、この関数はV4.4.2 BP2バージョンから導入されました。</p>
</main>

## 構文

```sql
TO_SINGLE_BYTE(str)
```

## パラメータの説明

`str`：変換する文字列。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>str</code> 内のいずれかの複数バイト文字に1バイト文字の等価項目がない場合、出力文字列では複数バイト文字として表示されます。</p>
</main>

## 戻り値の型

戻り値は `str` のデータ型と同じです。

## 例

文字列内の全角文字を半角文字に変換します。

```shell
obclient> SELECT TO_SINGLE_BYTE('中国Ａ')
```

結果は次のとおりです：

```shell
+-----------------------------+
| TO_SINGLE_BYTE('中国Ａ')    |
+-----------------------------+
| 中国A                       |
+-----------------------------+
1 row in set
```
