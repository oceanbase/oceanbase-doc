# MID

## 宣言

```sql
MID(str,pos,len)
```

## 説明

`str` の部分文字列を返します。開始位置は `pos`、長さは `len` です。パラメータに `NULL` が含まれる場合、`NULL` を返します。

* `len` を指定しない場合、返される部分文字列は `pos` の位置から `str` の終端までです。

* `pos` の値が負の場合、`str` の末尾から頭部に向かって逆順に開始位置を決定します。

* `len` が 0 以下、または `pos` が指定する開始位置が無効な場合、空文字列を返します。

この関数は `SUBSTRING(str,pos,len)` のエイリアスです。

## 例

```sql
obclient> SELECT MID('OceanBase',6);
+--------------------+
| MID('OceanBase',6) |
+--------------------+
| Base               |
+--------------------+
1 row in set
```
