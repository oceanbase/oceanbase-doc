# LPAD

## 宣言

```sql
LPAD(str,len,padstr)
```

## 説明

文字列 `padstr` を使って、文字列 `str` の左側を埋めて、長さが `len` になるまで調整します。

`str` の長さが `len` より長い場合は、`str` の最初の `len` 文字を返します。`str` の長さが `len` より短く、かつ `padstr` と `str` を連結した長さが `len` より長い場合は、連結後の文字列の最後から `len` 文字目以降を返します。

## 例

```sql
obclient> SELECT LPAD('Base',9,'Ocean');
+------------------------+
| LPAD('Base',9,'Ocean') |
+------------------------+
| OceanBase              |
+------------------------+
1 row in set

obclient> SELECT LPAD('Base',1,'Ocean');
+------------------------+
| LPAD('Base',1,'Ocean') |
+------------------------+
| B                      |
+------------------------+
1 row in set
```
