# LPAD

## 宣言

```sql
LPAD(str,len,padstr)
```

## 説明

文字列 `padstr` を使用して、文字列 `str` の左側を `len` まで埋めます。

`str` の長さが `len` より大きい場合は、`str` の左から `len` 文字目まで返します。`str` の長さが `len` より小さく、かつ `padstr` と `str` を連結した長さが `len` より大きい場合は、連結後の右側から `len` 文字目まで返します。

## 例

```sql
obclient> SELECT LPAD('Base',9,'Ocean');
+------------------------+
| LPAD('Base',9,'Ocean') |
+------------------------+
| OceanBase              |
+------------------------+
1 row in set

obclient> SELECT LPAD('Base',1,'Ocean');
+------------------------+
| LPAD('Base',1,'Ocean') |
+------------------------+
| B                      |
+------------------------+
1 row in set
```
