# BIT_LENGTH

## 宣言

```sql
BIT_LENGTH(str)
```

## 説明

文字列 `str` のビット長を返します。

## 例

```sql
obclient> SELECT BIT_LENGTH('oceanbase');
+-------------------------+
| BIT_LENGTH('oceanbase') |
+-------------------------+
|                      72 |
+-------------------------+
1 row in set
```
