# REGEXP

## 宣言

```sql
str [NOT] REGEXP | RLIKE pat
```

## 説明

正規表現によるマッチング。パラメータに `NULL` が含まれている場合、`NULL` を返します。

## 例

```sql
obclient> SELECT
     1234 REGEXP 1,
     'hello' RLIKE 'h%'
     \G
*************************** 1. row ***************************
     1234 REGEXP 1: 1
'hello' RLIKE 'h%': 0
1 row in set
```
