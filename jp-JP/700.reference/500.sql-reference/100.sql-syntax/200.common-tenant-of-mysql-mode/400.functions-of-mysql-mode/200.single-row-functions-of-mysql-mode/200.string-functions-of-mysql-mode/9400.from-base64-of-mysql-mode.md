# FROM_BASE64

## 宣言

```sql
FROM_BASE64(str)
```

## 説明

base-64でエンコードされた文字列をデコードし、バイナリ文字列として返します。通常は`TO_BASE64()`でエンコードされた文字列をデコードするために使用されます。詳細については、[TO_BASE64()](../200.string-functions-of-mysql-mode/9300.to-base64-mysql-mode.md)を参照してください。

## 例

```sql
obclient> SELECT FROM_BASE64('T0I=');
+---------------------+
| FROM_BASE64('T0I=') |
+---------------------+
| OB                  |
+---------------------+
1 row in set
```
