# INSTR

## 宣言

```sql
INSTR(str,substr)
```

## 説明

文字列 `str` 内の部分文字列が最初に現れる位置を返します。これは、パラメータの順序が逆になっている場合を除き、`LOCATE()` の2引数形式と同じです。

## 例

```sql
obclient> SELECT INSTR('foobarbar', 'bar'), INSTR('xbar', 'foobar');
+---------------------------+-------------------------+
| INSTR('foobarbar', 'bar') | INSTR('xbar', 'foobar') |
+---------------------------+-------------------------+
|                         4 |                       0 |
+---------------------------+-------------------------+
1 row in set
```
