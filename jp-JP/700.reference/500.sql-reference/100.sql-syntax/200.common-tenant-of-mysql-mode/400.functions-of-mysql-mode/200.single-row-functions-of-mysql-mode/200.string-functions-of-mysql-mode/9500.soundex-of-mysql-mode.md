# SOUNDEX

## 宣言

```sql
SOUNDEX(str)
```

## 説明

入力された文字列を、その文字列の発音を表すためのエンコードに変換します。この関数は、データベース内であいまいクエリを実行したり、発音が似ている文字列をマッチングしたりするためによく使用されます。

## 例

```sql
obclient> SELECT SOUNDEX('a');
+--------------+
| SOUNDEX('a') |
+--------------+
| A000         |
+--------------+
1 row in set
```
