# SOUNDEX

## 宣言

```sql
SOUNDEX(str)
```

## 説明

入力された文字列を、その文字列の発音を表すコードに変換します。この関数は、データベースであいまい検索を行ったり、発音が似ている文字列を照合したりする際によく使用されます。

## 例

```sql
obclient> SELECT SOUNDEX('a');
+--------------+
| SOUNDEX('a') |
+--------------+
| A000         |
+--------------+
1 row in set
```
