# RTRIM

## 宣言

```sql
RTRIM(str)
```

## 説明

文字列 `str` の右側の空白を削除します。

## 例

```sql
obclient> SELECT RTRIM('    obclient    ') AS rtrim;
+--------------+
| rtrim        |
+--------------+
|     obclient |
+--------------+
1 row in set
```
