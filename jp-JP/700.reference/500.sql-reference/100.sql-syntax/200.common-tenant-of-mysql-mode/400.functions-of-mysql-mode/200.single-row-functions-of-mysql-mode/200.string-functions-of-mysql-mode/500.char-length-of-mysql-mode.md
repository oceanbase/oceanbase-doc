# CHAR_LENGTH

## 宣言

```sql
CHAR_LENGTH(str)
```

## 説明

文字列 `str` が含む文字数を返します。

複数バイトの文字は1文字として数えられます。例えば、5つの2バイト文字を入力した場合、`LENGTH()` は `10` を返しますが、`CHAR_LENGTH()` は `5` を返します。

## 例

```sql
obclient> SELECT CHAR_LENGTH('中国'), LENGTH('中国'),CHAR_LENGTH('hello');
+-----------------------+------------------+----------------------+
| CHAR_LENGTH('中国')   | LENGTH('中国')   | CHAR_LENGTH('hello') |
+-----------------------+------------------+----------------------+
|                     2 |                6 |                    5 |
+-----------------------+------------------+----------------------+
1 row in set
```
