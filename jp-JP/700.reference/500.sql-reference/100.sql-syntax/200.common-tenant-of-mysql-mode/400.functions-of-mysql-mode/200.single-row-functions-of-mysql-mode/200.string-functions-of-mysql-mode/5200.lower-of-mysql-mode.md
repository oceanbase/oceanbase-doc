# LOWER

## 宣言

```sql
LOWER(str)
```

## 説明

文字列内の大文字を小文字に変換します。

この関数は `LCASE()` のシノニムです。

## 例

```sql
obclient> SELECT LOWER('OBCLIENTこんにちは！');
+-----------------------------+
| LOWER('OBCLIENTこんにちは！') |
+-----------------------------+
| obclientこんにちは！          |
+-----------------------------+
1 row in set
```
