# UCASE

## 宣言

```sql
UCASE(str)
```

## 説明

文字列 `str` の小文字を大文字に変換します。この関数は `UPPER()` 関数の同義語です。

## 例

```sql
obclient> SELECT UCASE('obclientこんにちは！');
+----------------------------+
| UCASE('obclientこんにちは！')    |
+----------------------------+
| OBCLIENTこんにちは！             |
+----------------------------+
1 row in set
```
