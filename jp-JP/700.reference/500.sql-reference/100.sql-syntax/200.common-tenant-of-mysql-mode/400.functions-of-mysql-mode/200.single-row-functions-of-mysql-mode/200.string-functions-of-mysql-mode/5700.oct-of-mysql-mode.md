# OCT

## 宣言

```sql
OCT(N)
```

## 説明

この関数は、`N` の8進数値を返します。これは `CONV(N,10,8)` と同じです。

`N` が `NULL` の場合、この関数は `NULL` を返します。

## 例

```sql
obclient> SELECT OCT(12);
+---------+
| OCT(12) |
+---------+
| 14      |
+---------+
1 row in set
```
