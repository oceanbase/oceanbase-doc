# URL_encode

## 説明

この関数は、文字列内の非ASCII文字をURLエンコードして、純粋なASCII文字に変換するために使用されます。`expr` のアルファベット数字以外の文字を、`%` とその後に続く16進数2文字の形式に変換します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.3.5では、この関数はV4.3.5 BP1バージョンからサポートされています。</p>
</main>

## 注意事項

* この関数は現在、`utf8` 照合順序のみをサポートしています。
* 入力がstring型の場合、出力の照合順序は入力と一致します。inputがstring型でない場合、現在のセッションのデフォルトの照合順序が適用されます。

## 構文宣言

```sql
URL_ENCODE(expr)
```

## パラメータ説明

`expr`：URLエンコードが必要な文字列。

## 戻り値タイプ

* URLエンコードされた文字列（`VARCHAR` 型）を返します。
* `expr` の値が `NULL` の場合、`NULL` を返します。

## 例

```sql
SELECT URL_ENCODE('https://example.com/path?name=John Doe&age=25'), URL_ENCODE(NULL);
```

結果は次のとおりです：

```shell
+-----------------------------------------------------------------+------------------+
| URL_ENCODE('https://example.com/path?name=John Doe&age=25')     | URL_ENCODE(NULL) |
+-----------------------------------------------------------------+------------------+
| https%3A%2F%2Fexample.com%2Fpath%3Fname%3DJohn%20Doe%26age%3D25 | NULL             |
+-----------------------------------------------------------------+------------------+
1 row in set
```
