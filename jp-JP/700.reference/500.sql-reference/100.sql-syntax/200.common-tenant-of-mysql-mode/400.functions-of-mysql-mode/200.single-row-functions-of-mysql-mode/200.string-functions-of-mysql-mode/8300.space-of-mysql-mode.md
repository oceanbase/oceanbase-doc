# SPACE

## 宣言

```sql
SPACE(N)
```

## 説明

`N`個のスペースを含む文字列を返します。

## 例

5つのスペースを含む文字列を返します。

```sql
obclient> SELECT SPACE(5);
+----------+
| SPACE(5) |
+----------+
|          |
+----------+
1 row in set
```
