# TO_BASE64

## 宣言

```sql
TO_BASE64(str)
```

## 説明

文字列パラメータをbase-64エンコード形式に変換します。`FROM_BASE64`関数を使用してBase-64エンコードされた文字列をデコードできます。詳細については、[FROM_BASE64()](../200.string-functions-of-mysql-mode/9400.from-base64-of-mysql-mode.md)参照してください。

## 例

```sql
obclient> SELECT TO_BASE64('OB');
+-----------------+
| TO_BASE64('OB')
+-----------------+
| T0I=            |
+-----------------+
1 row in set
```
