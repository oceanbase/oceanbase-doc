# REPEAT

## 宣言

```sql
REPEAT(str, count)
```

## 説明

`str` を `count` 回繰り返して構成される文字列を返します。`count` が 0 以上の場合は、`str` そのものを返します。パラメータに `NULL` が含まれる場合は、`NULL` を返します。

## 例

```javascript
obclient> SELECT
     REPEAT('1', -1),
     REPEAT(null, null),
     REPEAT('Abc', 4)
     \G
*************************** 1. row ***************************
   REPEAT('1', -1):
REPEAT(null, null): NULL
  REPEAT('Abc', 4): AbcAbcAbcAbc
1 row in set
```
