# REPEAT

## 宣言

```sql
REPEAT(str, count)
```

## 説明

`str` を `count` 回繰り返して構成される文字列を返します。`count` が0以下の場合、空の文字列を返します。パラメータに `NULL` が含まれている場合、`NULL` を返します。

## 例

```javascript
obclient> SELECT
     REPEAT('1', -1),
     REPEAT(null, null),
     REPEAT('Abc', 4)
     \G
*************************** 1. row ***************************
   REPEAT('1', -1):
REPEAT(null, null): NULL
  REPEAT('Abc', 4): AbcAbcAbcAbc
1 row in set
```
