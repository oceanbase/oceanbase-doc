# UPPER

## 宣言

```sql
UPPER(str)
```

## 説明

文字列 `str` 内の小文字を大文字に変換します。

## 例

```sql
obclient> obclient> SELECT UPPER('obclientこんにちは！');
+----------------------------+
| UPPER('obclient您好！')    |
+----------------------------+
| OBCLIENT您好！             |
+----------------------------+
1 row in set
```
