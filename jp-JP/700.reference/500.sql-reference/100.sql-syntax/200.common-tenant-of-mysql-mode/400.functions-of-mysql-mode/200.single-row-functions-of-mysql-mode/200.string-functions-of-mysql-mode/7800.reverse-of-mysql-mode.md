# REVERSE

## 宣言

```sql
REVERSE(str)
```

## 説明

文字列 `str` の逆順の配列を返します。

この関数はマルチバイトセーフです。

## 例

```sql
obclient> SELECT REVERSE('oceanbase');
+----------------------+
| REVERSE('oceanbase') |
+----------------------+
| esabnaeco            |
+----------------------+
1 row in set

obclient> SELECT REVERSE(1000);
+---------------+
| REVERSE(1000) |
+---------------+
| 0001          |
+---------------+
1 row in set
```
