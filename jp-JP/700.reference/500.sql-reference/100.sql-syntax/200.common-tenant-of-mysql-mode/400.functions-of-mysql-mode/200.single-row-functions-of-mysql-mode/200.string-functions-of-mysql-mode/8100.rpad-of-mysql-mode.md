# RPAD

## 宣言

```sql
RPAD(str,len,padstr)
```

## 説明

文字列 `padstr` を使用して、文字列 `str` の右側を埋め、長さを `len` にします。

* `str` の長さが `len` より長い場合は、`str` の最初の `len` 文字を返します。

* `str` の長さが `len` より短く、`str` と `padstr` を連結した長さが `len` より長い場合は、連結後の最初の `len` 文字を返します。

* `str` の長さが `len` より短く、`str` と `padstr` を連結した長さが `len` より短い場合は、`str` と複数の `padstr` を繋げた文字列（合計長が `len` 以上）の最初の `len` 文字を返します。

## 例

```sql
obclient> SELECT RPAD('hi',5,'?');
+------------------+
| RPAD('hi',5,'?') |
+------------------+
| hi???            |
+------------------+
1 row in set

obclient> SELECT RPAD('hi',1,'?');
+------------------+
| RPAD('hi',1,'?') |
+------------------+
| h                |
+------------------+
1 row in set
```
