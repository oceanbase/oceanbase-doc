# RPAD

## 宣言

```sql
RPAD(str,len,padstr)
```

## 説明

文字列 `padstr` を使用して、文字列 `str` の右側を `len` の長さになるまで埋めます。

* `str` の長さが `len` より大きい場合は、`str` の左側から `len` 文字目まで返します。

* `str` の長さが `len` より小さく、`str` と `padstr` を連結した長さが `len` より大きい場合は、連結後の左側から `len` 文字目まで返します。

* `str` の長さが `len` より小さく、`str` と `padstr` を連結した長さが `len` より小さい場合は、`str` に複数の `padstr` を繰り返し連結した（全長が `len` 以上）左側から `len` 文字目まで返します。

## 例

```sql
obclient> SELECT RPAD('hi',5,'?');
+------------------+
| RPAD('hi',5,'?') |
+------------------+
| hi???            |
+------------------+
1 row in set

obclient> SELECT RPAD('hi',1,'?');
+------------------+
| RPAD('hi',1,'?') |
+------------------+
| h                |
+------------------+
1 row in set
```
