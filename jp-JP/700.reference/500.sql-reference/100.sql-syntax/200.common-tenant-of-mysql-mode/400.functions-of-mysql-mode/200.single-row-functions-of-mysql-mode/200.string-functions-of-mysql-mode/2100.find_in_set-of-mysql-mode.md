# FIND_IN_SET

## 宣言

```sql
FIND_IN_SET(str,strlist)
```

## 説明

文字列集合 `strlist` 内で指定された文字列 `str` の位置を返します。位置は `1` から始まります。`str` が `strlist` に存在しない場合、`0` を返します。`str` または `strlist` が `NULL` の場合、`NULL` を返します。

`str` 文字列にはカンマ（,）を含めることはできません。

## 例

```sql
obclient> SELECT FIND_IN_SET('b','a,b,c,d');
+----------------------------+
| FIND_IN_SET('b','a,b,c,d') |
+----------------------------+
|                          2 |
+----------------------------+
1 row in set
```
