# QUOTE

## 宣言

```sql
quote(str)
```

## 説明

文字列を引用して、SQL文でデータ値を正しくエスケープするための結果を生成します。

一般的に、返される文字列は元の文字列の前後にシングルクォート（`'`）が付きます。

各バックスラッシュ（`\`）、シングルクォート（`'`）、ASCIIエンコードされた`NUL`値、および`Control+Z`の前には、バックスラッシュ（`\`）が付きます。

パラメータが`NULL`の場合、戻り値はシングルクォートを含まない`'NULL'`文字列となります。

## 例

```sql
obclient> SELECT QUOTE('Don\'t!');
+------------------+
| QUOTE('Don\'t!') |
+------------------+
| 'Don\'t!'        |
+------------------+
1 row in set

obclient> SELECT QUOTE(NULL);
+-------------+
| QUOTE(NULL) |
+-------------+
| NULL        |
+-------------+
1 row in set

obclient> SELECT LENGTH(QUOTE(NULL));
+---------------------+
| LENGth(QUOTE(NULL)) |
+---------------------+
|                   4 |
+---------------------+
1 row in set
```
