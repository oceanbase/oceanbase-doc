# HEX

## 宣言

```sql
HEX(str)
```

## 説明

数値または文字列 `str` を16進数文字列に変換します。ここで、`str` の各文字の各バイトは2桁の16進数に変換されます。

数値型パラメータ `N` の場合、`UNHEX(N)` は `HEX(N)` の逆演算ではありません。このような場合は、`CONV(HEX(N),16,10)` を使用して代替することができます。

## 例

```sql
obclient> SELECT HEX(255), HEX('abc');
+----------+------------+
| HEX(255) | HEX('abc') |
+----------+------------+
| FF       | 616263     |
+----------+------------+
1 row in set
```
