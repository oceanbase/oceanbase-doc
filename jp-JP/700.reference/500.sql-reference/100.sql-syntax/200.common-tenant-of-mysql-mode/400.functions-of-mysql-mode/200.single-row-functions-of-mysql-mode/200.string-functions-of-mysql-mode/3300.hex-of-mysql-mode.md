# HEX

## 宣言

```sql
HEX(str)
```

## 説明

数値または文字列 `str` を16進数文字列に変換します。ここで、`str` の各文字の各バイトが2つの16進数に変換されます。

数値型のパラメータ `N` について、`UNHEX(N)` は `HEX(N)` の逆演算ではありません。この場合、`CONV(HEX(N),16,10)` を使用することができます。

## 例

```sql
obclient> SELECT HEX(255), HEX('abc');
+----------+------------+
| HEX(255) | HEX('abc') |
+----------+------------+
| FF       | 616263     |
+----------+------------+
1 row in set
```
