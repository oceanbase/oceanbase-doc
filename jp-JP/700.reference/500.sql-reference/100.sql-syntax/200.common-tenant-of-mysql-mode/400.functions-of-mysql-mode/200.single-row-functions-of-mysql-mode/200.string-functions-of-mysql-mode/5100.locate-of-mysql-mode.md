# LOCATE

## 宣言

```sql
LOCATE(substr,str)
LOCATE(substr,str,pos)
```

## 説明

最初の構文は、文字列 `str` 内で部分文字列 `substr` が最初に現れる位置を返します。2番目の構文は、文字列 `str` の位置 `pos` から検索を開始し、部分文字列 `substr` が最初に現れる位置を返します。`substr` が `str` 内に存在しない場合、戻り値は `0` です。

## 例

```sql
obclient> SELECT LOCATE('bar', 'foobarbar'), LOCATE('xbar', 'foobar'), LOCATE('bar', 'foobarbar',5);
+----------------------------+--------------------------+------------------------------+
| LOCATE('bar', 'foobarbar') | LOCATE('xbar', 'foobar') | LOCATE('bar', 'foobarbar',5) |
+----------------------------+--------------------------+------------------------------+
|                          4 |                        0 |                            7 |
+----------------------------+--------------------------+------------------------------+
1 row in set
```
