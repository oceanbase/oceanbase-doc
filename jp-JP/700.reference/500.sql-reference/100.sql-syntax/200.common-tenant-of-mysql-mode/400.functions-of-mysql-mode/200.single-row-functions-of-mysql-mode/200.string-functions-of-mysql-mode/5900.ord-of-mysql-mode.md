# ORD

## 宣言

```sql
ORD(str)
```

## 説明

文字列の左端の文字の文字コードを返します。単一バイトエンコーディングの場合、左端の文字がマルチバイトエンコーディング文字である場合、戻り値の計算ルールは以下のとおりです：

```sql
(1st byte code)
+ (2nd byte code * 256)
+ (3rd byte code * 256^2) ...
```

左端の文字がマルチバイト文字でない場合、`ORD()`関数は`ASCII()`関数と同じ値を返します。

## 例

```sql
obclient> SELECT ORD('中国');
+---------------+
| ORD('中国') |
+---------------+
|      14989485 |
+---------------+
1 row in set
```
