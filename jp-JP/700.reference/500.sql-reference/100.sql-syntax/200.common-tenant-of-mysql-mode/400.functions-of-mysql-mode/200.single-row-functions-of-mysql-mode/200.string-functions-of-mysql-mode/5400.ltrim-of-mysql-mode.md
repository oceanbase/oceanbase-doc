# LTRIM

## 宣言

```sql
LTRIM(str)
```

## 説明

文字列の左側のスペースを削除します。

## 例

```sql
obclient> SELECT LTRIM('    obclient    ') AS ltrim;
+--------------+
| ltrim        |
+--------------+
| obclient     |
+--------------+
1 row in set
```
