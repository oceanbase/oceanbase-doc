# BIN

## 宣言

```sql
bin(N)
```

## 説明

数値 `N` の2進形式を返します。この関数は `CONV(N,10,2)` と同じです。

`N` が `NULL` の場合、`NULL` を返します。

## 例

```sql
obclient> SELECT BIN(12);
+---------+
| BIN(12) |
+---------+
| 1100    |
+---------+
1 row in set
```
