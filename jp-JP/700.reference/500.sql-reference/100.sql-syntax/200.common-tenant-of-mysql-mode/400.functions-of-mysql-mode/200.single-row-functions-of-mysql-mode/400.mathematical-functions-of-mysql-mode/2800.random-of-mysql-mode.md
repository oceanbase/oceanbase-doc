# RANDOM

## 宣言

```sql
RANDOM(seed)
```

## 説明

この関数は、64ビットの整数型疑似乱数値を生成します。

* `seed` は整数型であり、異なる `seed` によって異なる乱数列が生成されます。
* `RANDOM()` はMT19937疑似乱数生成アルゴリズムを使用しており、その乱数空間は非常に大きく、2<sup>19937</sup> - 1 個のランダム要素を生成した後に初めて同じシーケンスが繰り返し生成されます。

## 例

以下の例は、`RANDOM()` を使用して乱数を生成する方法です。

```shell
obclient> SELECT RANDOM(4) FROM TABLE(GENERATOR(3));
+---------------------+
| RANDOM(4)           |
+---------------------+
| 5267436225003336391 |
| -851690886662571060 |
| 1738617244330437274 |
+---------------------+
3 rows in set
```

以下の例では、`RANDOM()` の結果を分布関数のランダム入力として使用しています。

```shell
obclient> SELECT UNIFORM(1, 100, RANDOM()) FROM TABLE(GENERATOR(4));
+---------------------------+
| UNIFORM(1, 100, RANDOM()) |
+---------------------------+
|                        66 |
|                        71 |
|                        52 |
|                        14 |
+---------------------------+
4 rows in set
```

以下の例は特殊なケースであり、`RANDOM()` のパラメータに変数を指定すると、毎回 `seed` が再計算されます。

```shell
obclient> SELECT * FROM t1;
+------+
| c1   |
+------+
|    3 |
|    4 |
|    5 |
|    1 |
|    1 |
+------+
5 rows in set

obclient> SELECT t1.c1, RAND(t1.c1), RANDOM(t1.c1) FROM TABLE(GENERATOR(1)), t1;
+------+---------------------+----------------------+
| c1   | RAND(t1.c1)         | RANDOM(t1.c1)        |
+------+---------------------+----------------------+
|    3 |  0.9057697559760601 |  1084041170817055659 |
|    4 | 0.15595286540310166 |  5267436225003336391 |
|    5 | 0.40613597483014313 |  3192483991702052534 |
|    1 | 0.40540353712197724 | -6753783847308464280 |
|    1 | 0.40540353712197724 | -6753783847308464280 |
+------+---------------------+----------------------+
5 rows in set
```
