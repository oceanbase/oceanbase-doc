# DEGREES

## 構文

```sql
DEGREES(x)
```

## 説明

`DEGREES()`関数は、引数`x`をラジアンから度に変換して返します。

## 例

以下の例では、それぞれ`PI()`の値と`PI()/2`の値を対応する度に変換します。

```sql
obclient> SELECT DEGREES(PI());
+---------------+
| DEGREES(PI()) |
+---------------+
|           180 |
+---------------+
1 row in set

obclient> SELECT DEGREES(PI()/2);
+-------------------+
| DEGREES(PI()/2) |
+-------------------+
|                90 |
+-------------------+
1 row in set
```
