# POW

## 宣言

```sql
POW(X,Y)
```

## 説明

`X` の `Y`乗を返します。

`X` または `Y` のいずれかの引数が `NULL` の場合、戻り値は `NULL` になります。

## 例

```sql
obclient> SELECT POW(4,2), POW(4,-2), POW(1,NULL);
+----------+-----------+-------------+
| POW(4,2) | POW(4,-2) | POW(1,NULL) |
+----------+-----------+-------------+
|       16 |    0.0625 |        NULL |
+----------+-----------+-------------+
1 row in set
```
