# LOG10

## 宣言

```sql
LOG10(X)
```

## 説明

10を底とする `X` の対数を返します。`X` は正の実数であり、10を底とする対数を計算したい値です。

## 例

```sql
obclient> SELECT LOG10(1000);
+-------------+
| LOG10(1000) |
+-------------+
|           3 |
+-------------+
1 row in set

obclient> SELECT LOG10(-1000);
+--------------+
| LOG10(-1000) |
+--------------+
|         NULL |
+--------------+
1 row in set, 1 warning
```
