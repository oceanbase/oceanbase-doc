# COS

## 宣言

```sql
COS(X)
```

## 説明

指定されたラジアン `X` のコサイン値を返します。

## 例

```sql
obclient> SELECT COS(PI());
+-----------+
| COS(PI()) |
+-----------+
|        -1 |
+-----------+
1 row in set
```
