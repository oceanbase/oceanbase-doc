# TAN

## 宣言

```sql
TAN(X)
```

## 説明

指定された弧度Xのタンジェント値を返します。

## 例

```sql
obclient> SELECT TAN(PI());
+-------------------------+
| TAN(PI())               |
+-------------------------+
| -1.2246467991473532e-16 |
+-------------------------+
1 row in set
```
