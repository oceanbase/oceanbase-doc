# CRC32

## 宣言

```sql
CRC32(expr)
```

## 説明

ループ冗長性チェック値を計算し、32ビットの符号なし値を返します。

パラメータ`expr`は文字列である必要があります。そうでない場合、文字列と見なされる可能性があります。

パラメータが`NULL`の場合、結果は`NULL`です。

## 例

```sql
obclient>SELECT CRC32('hello-world');
+-----------------------+
| COS32('hello-world') |
+-----------------------+
|               2983461467|
+-----------------------+
1 row in set
```
