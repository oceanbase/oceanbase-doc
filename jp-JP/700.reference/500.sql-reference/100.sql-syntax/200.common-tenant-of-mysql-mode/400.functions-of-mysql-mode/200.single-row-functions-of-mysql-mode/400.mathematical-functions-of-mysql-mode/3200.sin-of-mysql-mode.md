# SIN

## 宣言

```sql
SIN(X)
```

## 説明

指定されたラジアン `X` のサイン値を返します。

## 例

```sql
obclient> SELECT SIN(PI());
+------------------------+
| SIN(PI())              |
+------------------------+
| 1.2246467991473532e-16 |
+------------------------+
1 row in set
```
