# LOG2

## 宣言

```sql
LOG2(X)
```

## 説明

2を底とする `X` の対数を返します。`X` は正の実数であり、2を底とする対数を計算したい値です。

## 例

```sql
obclient> SELECT LOG2(65536);
+-------------+
| LOG2(65536) |
+-------------+
|          16 |
+-------------+
1 row in set

obclient> SELECT LOG2(-65536);
+--------------+
| LOG2(-65536) |
+--------------+
|         NULL |
+--------------+
1 row in set, 1 warning
```
