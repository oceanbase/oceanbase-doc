# CEIL

## 宣言

```sql
CEIL(expr)
```

## 説明

`expr` 以上の最小の整数を返します。

比較演算がサポートされており、結果はBOOL値となります。これは数値型に変換されて処理され、結果は `1` (`TRUE`) または `0` (`FALSE`) となります。

入力が `NULL` の場合、戻り値も `NULL` となります。

純粋な数字の文字列を入力した場合、自動的に数値型に変換されます。

戻り値はBIGINT型に変換されます。

## 例

```sql
obclient> SELECT CEIL(1.2), CEIL(-1.2), CEIL(1+1.5), CEIL(1=1),CEIL(1<1),CEIL(null);
+-----------+------------+-------------+-----------+-----------+------------+
| CEIL(1.2) | CEIL(-1.2) | CEIL(1+1.5) | CEIL(1=1) | CEIL(1<1) | CEIL(null) |
+-----------+------------+-------------+-----------+-----------+------------+
|         2 |         -1 |           3 |         1 |         0 |       NULL |
+-----------+------------+-------------+-----------+-----------+------------+
1 row in set

obclient> SELECT CEIL(name);
ERROR 1054 (42S22): Unknown column 'name' in 'field list'

obclient> SELECT CEIL('2');
+-----------+
| CEIL('2') |
+-----------+
|         2 |
+-----------+
1 row in set
```
