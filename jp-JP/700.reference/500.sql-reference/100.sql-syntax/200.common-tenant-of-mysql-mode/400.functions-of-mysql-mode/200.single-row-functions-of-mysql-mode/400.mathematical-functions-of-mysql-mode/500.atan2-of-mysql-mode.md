# ATAN2

## 宣言

```sql
ATAN2(X,Y)
```

## 説明

`X` と `Y` のアーケタンジュアントを返します。これは、`Y/X` のアーケタンジュアントを計算するのに似ており、2つの引数の符号によって結果がどの象限に属するかが決定されます。

この関数は `ATAN(X,Y)` としても記述できます。詳細については、[ATAN](../400.mathematical-functions-of-mysql-mode/400.atan-of-mysql-mode.md)参照してください。

## 例

```sql
obclient> SELECT ATAN(PI(),0);
+--------------------+
| ATAN(PI(),0)       |
+--------------------+
| 1.5707963267948966 |
+--------------------+
1 row in set
```
