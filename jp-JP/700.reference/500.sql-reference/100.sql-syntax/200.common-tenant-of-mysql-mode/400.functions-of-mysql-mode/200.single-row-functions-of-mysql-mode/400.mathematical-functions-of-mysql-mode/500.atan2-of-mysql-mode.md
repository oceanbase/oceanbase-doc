# ATAN2

## 宣言

```sql
ATAN2(X,Y)
```

## 説明

`X` と `Y` のアルティジャンクションを返します。これは `Y/X` のアルティジャンクションを計算することに似ており、2つのパラメータの符号によって結果がどの象限にあるかが決定されます。

この関数は `ATAN(X,Y)` としても記述できます。詳細については [ATAN](../400.mathematical-functions-of-mysql-mode/400.atan-of-mysql-mode.md) を参照してください。

## 例

```sql
obclient> SELECT ATAN(PI(),0);
+--------------------+
| ATAN(PI(),0)       |
+--------------------+
| 1.5707963267948966 |
+--------------------+
1 row in set
```
