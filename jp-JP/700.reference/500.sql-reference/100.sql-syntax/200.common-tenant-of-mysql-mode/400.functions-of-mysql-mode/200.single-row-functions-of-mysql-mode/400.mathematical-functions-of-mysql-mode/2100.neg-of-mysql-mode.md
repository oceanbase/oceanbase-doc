# NEG

## 宣言

```sql
NEG(expr)
```

## 説明

補集合を求める関数です。演算子に対して補集合演算を実行し、すなわちゼロから演算子を引いた後、その結果を演算子に返します。

比較演算をサポートしており、結果はBOOL値となります。このBOOL値は数値型に変換されて処理され、`1` (`TRUE`) または `0` (`FALSE`) が生成されます。その後、この結果の補集合が求められます。

## 例

```sql
obclient> SELECT NEG(1), NEG(1+1), NEG(2*3), NEG(1=1), NEG(5<1);
+--------+----------+----------+----------+----------+
| NEG(1) | NEG(1+1) | NEG(2*3) | NEG(1=1) | NEG(5<1) |
+--------+----------+----------+----------+----------+
|     -1 |       -2 |       -6 |       -1 |        0 |
+--------+----------+----------+----------+----------+
1 row in set
```
