# NEG

## 宣言

```sql
NEG(expr)
```

## 説明

補集合を求める関数であり、演算子に対して補集合演算を実行します。つまり、ゼロから演算子を引いた値を結果として返します。

比較演算をサポートしており、結果はBOOL型の値となり、数値型に変換されて処理されます。生成される結果は`1`(`TRUE`)または`0`(`FALSE`)となり、その後その結果に対して補集合演算が行われます。

## 例

```sql
obclient> SELECT NEG(1), NEG(1+1), NEG(2*3), NEG(1=1), NEG(5<1);
+--------+----------+----------+----------+----------+
| NEG(1) | NEG(1+1) | NEG(2*3) | NEG(1=1) | NEG(5<1) |
+--------+----------+----------+----------+----------+
|     -1 |       -2 |       -6 |       -1 |        0 |
+--------+----------+----------+----------+----------+
1 row in set
```
