# NEG

## 宣言

```sql
NEG(expr)
```

## 説明

符号を反転する関数です。ゼロからオペランドを引き、その結果を返します。

比較演算をサポートしており、結果はBOOL値となります。このBOOL値は数値型に変換されて処理され、`1` (`TRUE`) または `0` (`FALSE`) が生成されます。その後、この結果の符号を反転します。

## 例

```sql
obclient> SELECT NEG(1), NEG(1+1), NEG(2*3), NEG(1=1), NEG(5<1);
+--------+----------+----------+----------+----------+
| NEG(1) | NEG(1+1) | NEG(2*3) | NEG(1=1) | NEG(5<1) |
+--------+----------+----------+----------+----------+
|     -1 |       -2 |       -6 |       -1 |        0 |
+--------+----------+----------+----------+----------+
1 row in set
```
