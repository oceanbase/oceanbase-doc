# EXP

## 宣言

```sql
EXP(X)
```

## 説明

自然対数の底eの`X`乗を返します。

## 例

```sql
obclient> SELECT EXP(2);
+------------------+
| EXP(2)           |
+------------------+
| 7.38905609893065 |
+------------------+
1 row in set

obclient> SELECT EXP(0);
+--------+
| EXP(0) |
+--------+
|      1 |
+--------+
1 row in set

obclient> SELECT EXP(-2);
+--------------------+
| EXP(-2)            |
+--------------------+
| 0.1353352832366127 |
+--------------------+
1 row in set
```
