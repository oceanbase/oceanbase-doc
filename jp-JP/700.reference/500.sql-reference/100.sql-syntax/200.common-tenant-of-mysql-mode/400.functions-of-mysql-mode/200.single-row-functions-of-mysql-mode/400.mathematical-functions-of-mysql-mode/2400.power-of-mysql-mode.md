# POWER

## 宣言

```sql
POWER(X,Y)
```

## 説明

`X` の `Y`乗を返します。この関数は `POW()` のエイリアスです。

`X` または `Y` のいずれかの引数が `NULL` の場合、戻り値は `NULL` になります。

## 例

```sql
obclient> SELECT POWER(2,8);
+------------+
| POWER(2,8) |
+------------+
|        256 |
+------------+
1 row in set
```
