# PI

## 宣言

```sql
PI()
```

## 説明

`π` の値（円周率）を返します。

## 例

```sql
obclient> SELECT PI();
+----------+
| PI()     |
+----------+
| 3.141593 |
+----------+
1 row in set

obclient> SELECT ROUND(2*PI(),2);
+----------------+
| ROUND(2*PI(),2)|
+----------------+
| 6.28           |
+----------------+
1 row in set
```
