# CURRENT_TIMESTAMP

## 宣言

```javascript
CURRENT_TIMESTAMP([scale])
```

## 説明

現在のタイムゾーンの日付時刻を返します。

`scale` はマイクロ秒部分の精度を表し、有効な値は `0` から `6` の整数で、デフォルト値は `0` です。

## 例

```javascript
obclient> SELECT CURRENT_TIMESTAMP(6);
+----------------------------+
| CURRENT_TIMESTAMP(6)       |
+----------------------------+
| 2018-05-05 11:35:39.177764 |
+----------------------------+
1 row in set
```
