# YEARWEEK

## 宣言

```sql
YEARWEEK(date[,mode])
```

## 説明

日付または日付時刻型の `date` の年と、その年における週の位置を返します。

`mode` パラメータは、週数計算のロジックを決定するもので、その取り得る範囲と意味は次の表のとおりです。

| 値 | 週の初日 |  範囲   |        意味        |
|----|-------|-------|------------------|
| 0  | 日曜日   | 0\~53 | 最初の日曜日の週がその年の第1週となります |
| 1  | 月曜日   | 0\~53 | 4日以上ある週がその年の第1週となります |
| 2  | 日曜日   | 1\~53 | 最初の日曜日の週がその年の第1週となります |
| 3  | 月曜日   | 1\~53 | 4日以上ある週がその年の第1週となります |
| 4  | 日曜日   | 0\~53 | 4日以上ある週がその年の第1週となります |
| 5  | 月曜日   | 0\~53 | 最初の月曜日の週がその年の第1週となります |
| 6  | 日曜日   | 1\~53 | 4日以上ある週がその年の第1週となります |
| 7  | 月曜日   | 1\~53 | 最初の月曜日の週がその年の第1週となります |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>指定された日付がその年の最初の日付の場合、この関数は前年の最終週を返す可能性があります。</p>
  </main>

## 例

```sql
obclient> SELECT YEARWEEK('2021-01-01');
+------------------------+
| YEARWEEK('2021-01-01') |
+------------------------+
|                 202052 |
+------------------------+
1 row in set
```
