# MONTHNAME

## 宣言

```sql
MONTHNAME(date)
```

## 説明

指定された日付 `date` の月のフルネームを返します。

## 例

```sql
obclient> SELECT MONTHNAME('2008-02-03');
+-------------------------+
| MONTHNAME('2008-02-03') |
+-------------------------+
| February                |
+-------------------------+
1 row in set
```
