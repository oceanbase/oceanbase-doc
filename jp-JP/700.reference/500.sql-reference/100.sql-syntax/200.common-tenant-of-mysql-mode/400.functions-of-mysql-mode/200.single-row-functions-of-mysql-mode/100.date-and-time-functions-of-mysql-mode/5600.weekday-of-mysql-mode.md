# WEEKDAY

## 宣言

```sql
WEEKDAY(date)
```

## 説明

日付または日付時刻型の `date` が週のいずれの位置にあるかを返します。

## 例

```sql
obclient> SELECT WEEKDAY('2021-07-16 00:00:00');
+--------------------------------+
| WEEKDAY('2020-07-16 00:00:00') |
+--------------------------------+
|                              5 |
+--------------------------------+
1 row in set
```
