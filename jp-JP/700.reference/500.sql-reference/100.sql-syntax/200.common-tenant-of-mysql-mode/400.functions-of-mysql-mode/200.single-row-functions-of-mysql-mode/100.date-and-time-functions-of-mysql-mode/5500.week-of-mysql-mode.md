# WEEK

## 宣言

```sql
WEEK(date[,mode])
```

## 説明

日付または日付時刻型の `date` が属する週の、その年における週番号を返します。

`mode` パラメータは、週数計算のロジックを決定し、その取り得る範囲と意味は次の表のとおりです。

| 値 | 週の初日 |  範囲   |        意味        |
|----|-------|-------|------------------|
| 0  | 日曜日   | 0\~53 | その年の最初の日曜日を含む週がその年の第1週となります |
| 1  | 月曜日   | 0\~53 | 4日以上を含む週がその年の第1週となります |
| 2  | 日曜日   | 1\~53 | その年の最初の日曜日を含む週がその年の第1週となります |
| 3  | 月曜日   | 1\~53 | 4日以上を含む週がその年の第1週となります |
| 4  | 日曜日   | 0\~53 | 4日以上を含む週がその年の第1週となります |
| 5  | 月曜日   | 0\~53 | その年の最初の月曜日を含む週がその年の第1週となります |
| 6  | 日曜日   | 1\~53 | 4日以上を含む週がその年の第1週となります |
| 7  | 月曜日   | 1\~53 | その年の最初の月曜日を含む週がその年の第1週となります |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>指定された日付がその年の最初の日付の場合、この関数は前年の最終週を返す可能性があります。</p>
  </main>

## 例

```sql
obclient> SELECT WEEK('2021-01-01',0);
+----------------------+
| WEEK('2021-01-01',0) |
+----------------------+
|                    0 |
+----------------------+
1 row in set
```
