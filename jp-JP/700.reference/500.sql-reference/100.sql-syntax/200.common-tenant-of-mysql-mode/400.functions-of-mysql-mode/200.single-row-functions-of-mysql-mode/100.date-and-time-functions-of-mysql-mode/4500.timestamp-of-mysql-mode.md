# TIMESTAMP

## 宣言

```sql
TIMESTAMP(expr)
TIMESTAMP(expr1,expr2)
```

## 説明

最初の宣言は、日付時刻式 `expr` の日付時刻値を返します。

2 番目の宣言は、日付時刻式 `expr1` と時刻式 `expr2` を加算した日付時刻式を返します。ただし、`expr2` に日付が含まれる場合は、そのうちの時刻値のみを取ります。

いずれかの引数が `NULL` の場合、この関数は `NULL` を返します。

## 例

```sql
obclient> SELECT TIMESTAMP('2020-12-31');
+----------------------------+
| TIMESTAMP('2020-12-31')    |
+----------------------------+
| 2020-12-31 00:00:00.000000 |
+----------------------------+
1 row in set

obclient> SELECT TIMESTAMP('2020-12-31 12:00:00','12:00:00');
+---------------------------------------------+
| TIMESTAMP('2020-12-31 12:00:00','12:00:00') |
+---------------------------------------------+
| 2021-01-01 00:00:00.000000                  |
+---------------------------------------------+
1 row in set
```
