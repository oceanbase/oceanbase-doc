# DATE

## 宣言

```sql
DATE(expr)
```

## 説明

時間または日付時刻式 `expr` の日付を返します。

## 例

```sql
obclient> SELECT DATE('2021-07-14 19:12:03');
+-----------------------------+
| DATE('2021-07-14 19:12:03') |
+-----------------------------+
| 2021-07-14                  |
+-----------------------------+
1 row in set
```
