# CURRENT_DATE

## 宣言

```sql
CURRENT_DATE()
CURRENT_DATE
```

## 説明

現在の日付を返します。時刻部分は含まれません。この関数は [CURDATE](../100.date-and-time-functions-of-mysql-mode/300.curdate-of-mysql-mode.md) のエイリアスです。

## 例

```javascript
obclient> SELECT CURRENT_DATE;
+--------------+
| CURRENT_DATE |
+--------------+
| 2021-08-23   |
+--------------+
1 row in set

obclient> SELECT CURRENT_DATE();
+----------------+
| CURRENT_DATE() |
+----------------+
| 2021-08-23     |
+----------------+
1 row in set
```
