# TIME_TO_USEC

## 宣言

```javascript
TIME_TO_USEC(date)
```

## 説明

`date` 値を `1970-01-01 00:00:00.000000` からのミリ秒数に変換し、タイムゾーン情報を考慮します。

`date` は日付または日付時刻を表すことができます。

## 例

```javascript
obclient> SELECT TIME_TO_USEC('2014-03-25'), TIME_TO_USEC(NOW());
+----------------------------+---------------------+
| TIME_TO_USEC('2014-03-25') | TIME_TO_USEC(NOW()) |
+----------------------------+---------------------+
|           1395676800000000 |    1525528100000000 |
+----------------------------+---------------------+
1 row in set
```
