# PERIOD_ADD

## 宣言

```sql
PERIOD_ADD(P,N)
```

## 説明

時間帯 `P` に `N` ヶ月を追加します。ここで、`P` の形式は `YYMM` または `YYYYMM` です。

戻り値の形式は `YYYYMM` です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>パラメータ <code>P</code> は <code>DATE</code> タイプ、つまり日付以外の値ではありません。</p>
  </main>

## 例

```sql
obclient> SELECT PERIOD_ADD(200801,2);
+----------------------+
| PERIOD_ADD(200801,2) |
+----------------------+
|               200803 |
+----------------------+
1 row in set
```
