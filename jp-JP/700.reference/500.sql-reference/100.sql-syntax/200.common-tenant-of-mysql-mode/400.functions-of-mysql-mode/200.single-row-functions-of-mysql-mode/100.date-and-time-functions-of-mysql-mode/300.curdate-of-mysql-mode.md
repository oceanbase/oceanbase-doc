# CURDATE

## 宣言

```javascript
CURDATE()
```

## 説明

現在の日付を返します。時刻部分は含まれません。

## 例

```javascript
obclient> SELECT CURDATE();
+------------+
| CURDATE()  |
+------------+
| 2018-05-05 |
+------------+
1 row in set
```
