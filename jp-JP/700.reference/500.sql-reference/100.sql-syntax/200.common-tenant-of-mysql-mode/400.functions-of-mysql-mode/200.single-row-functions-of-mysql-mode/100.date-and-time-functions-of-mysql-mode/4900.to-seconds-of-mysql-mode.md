# TO_SECONDS

## 宣言

```sql
TO_SECONDS(expr)
```

## 説明

日付または時刻の式 `expr` が西暦0年から経過した秒数を返します。`expr` が `NULL` の場合、`NULL` を返します。

## 例

```sql
obclient> SELECT TO_SECONDS(950501);
+--------------------+
| TO_SECONDS(950501) |
+--------------------+
|        62966505600 |
+--------------------+
1 row in set

obclient> SELECT TO_SECONDS('2021-07-15');
+--------------------------+
| TO_SECONDS('2021-07-15') |
+--------------------------+
|              63793526400 |
+--------------------------+
1 row in set
```
