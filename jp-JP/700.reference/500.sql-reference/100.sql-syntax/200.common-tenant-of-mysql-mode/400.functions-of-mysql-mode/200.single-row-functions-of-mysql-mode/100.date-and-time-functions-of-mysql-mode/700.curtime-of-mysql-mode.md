# CURTIME

## 宣言

```javascript
CURTIME(scale)
```

## 説明

現在時刻を日付部分なしで返します。この関数は `CURRENT_TIME()` のエイリアスです。

`scale` はマイクロ秒の精度を表し、有効な値は `0` から `6` の整数で、デフォルト値は `0` です。

## 例

```sql
obclient> SELECT CURTIME(0);
+------------+
| CURTIME(0) |
+------------+
| 16:17:11   |
+------------+
1 row in set
```
