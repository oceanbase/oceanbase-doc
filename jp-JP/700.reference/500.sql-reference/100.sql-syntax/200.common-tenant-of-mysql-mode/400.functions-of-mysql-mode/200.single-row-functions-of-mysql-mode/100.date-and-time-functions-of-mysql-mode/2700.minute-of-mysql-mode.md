# MINUTE

## 宣言

```sql
MINUTE(time)
```

## 説明

時間 `time` の分を返します。

## 例

```sql
obclient> SELECT MINUTE('18:20:17');
+--------------------+
| MINUTE('18:20:17') |
+--------------------+
|                 20 |
+--------------------+
1 row in set
```
