# MONTH

## 宣言

```sql
MONTH(date)
```

## 説明

`date` の月情報を返します。

## 例

```sql
obclient> SELECT MONTH('2008-02-03');
+---------------------+
| MONTH('2008-02-03') |
+---------------------+
|                   2 |
+---------------------+
1 row in set
```
