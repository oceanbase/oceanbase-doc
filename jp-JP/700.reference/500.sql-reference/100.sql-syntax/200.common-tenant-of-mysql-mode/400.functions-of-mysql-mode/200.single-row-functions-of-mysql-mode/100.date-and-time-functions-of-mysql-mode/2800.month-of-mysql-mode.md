# MONTH

## 宣言

```javascript
MONTH(date)
```

## 説明

`date` の月の情報を返します。

## 例

```javascript
obclient> SELECT MONTH('2008-02-03');
+---------------------+
| MONTH('2008-02-03') |
+---------------------+
|                   2 |
+---------------------+
1 row in set
```
