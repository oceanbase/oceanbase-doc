# WEEKOFYEAR

## 宣言

```sql
WEEKOFYEAR(date)
```

## 説明

日付または日付時刻型の `date` が属する週の、その年における週番号を返します。

## 例

```sql
obclient> SELECT WEEKOFYEAR('2020-07-16');
+--------------------------+
| WEEKOFYEAR('2020-07-16') |
+--------------------------+
|                       29 |
+--------------------------+
1 row in set
```
