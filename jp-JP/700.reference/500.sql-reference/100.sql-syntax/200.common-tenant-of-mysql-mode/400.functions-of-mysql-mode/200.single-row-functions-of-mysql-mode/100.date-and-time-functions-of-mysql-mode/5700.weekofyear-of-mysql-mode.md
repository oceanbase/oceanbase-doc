# WEEKOFYEAR

## 宣言

```sql
WEEKOFYEAR(date)
```

## 説明

日付または日時の日付型`date`で指定された週が年間における位置を返します。

## 例

```sql
obclient> SELECT WEEKOFYEAR('2020-07-16');
+--------------------------+
| WEEKOFYEAR('2020-07-16') |
+--------------------------+
|                       29 |
+--------------------------+
1 row in set
```
