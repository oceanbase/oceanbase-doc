# DAYNAME

## 宣言

```sql
DAYNAME(date)
```

## 説明

日付に対応する営業日の名前を返します。

## 例

```sql
obclient> SELECT DAYNAME('2022-09-08');
+-----------------------+
| DAYNAME('2022-09-08') |
+-----------------------+
| Thursday              |
+-----------------------+
1 row in set
```
