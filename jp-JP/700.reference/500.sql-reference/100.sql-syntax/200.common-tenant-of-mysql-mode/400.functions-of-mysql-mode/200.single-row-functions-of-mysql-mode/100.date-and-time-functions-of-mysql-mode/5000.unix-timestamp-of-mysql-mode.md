# UNIX_TIMESTAMP

## 宣言

```sql
UNIX_TIMESTAMP()
UNIX_TIMESTAMP(date)
```

## 説明

* `date` パラメータを指定しない場合、現在時刻から `'1970-01-01 00:00:00'` までの秒数を返します。タイムゾーン情報を考慮する必要があります。

* `date` パラメータを指定した場合、指定された日付時刻から `'1970-01-01 00:00:00'` までの秒数を返します。タイムゾーン情報を考慮する必要があります。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この関数のパラメータは、<code>DATE</code>、<code>DATETIME</code>、<code>TIMESTAMP</code> 型の日付または時刻です。</p>
</main>
