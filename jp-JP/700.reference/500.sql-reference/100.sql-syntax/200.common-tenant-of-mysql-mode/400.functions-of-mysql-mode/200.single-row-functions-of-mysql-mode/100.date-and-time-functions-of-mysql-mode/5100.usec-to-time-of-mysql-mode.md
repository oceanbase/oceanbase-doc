# USEC_TO_TIME

`USEC_TO_TIME` 関数は、マイクロ秒（usec）を TIMESTAMP 型の値に変換するために使用されます。OceanBase データベースが使用するタイムゾーンは UTC（協定世界時）です。そのため、マイクロ秒を TIMESTAMP に変換する際、システムはタイムゾーン情報を考慮し、UTC タイムゾーンを基準とします。

## 関数構文

```sql
USEC_TO_TIME(usec)
```

## パラメータ説明

|パラメータ    | 説明  |
|-------|------|
|`usec` | `TIMESTAMP` 型の値に変換する必要があるマイクロ秒数を表します。`usec` は `1970-01-01 00:00:00.000000` からのマイクロ秒数を示します。|

## 例

```sql
obclient> SELECT USEC_TO_TIME(1);
+----------------------------+
| USEC_TO_TIME(1)            |
+----------------------------+
| 1970-01-01 08:00:00.000001 |
+----------------------------+
1 row in set
```
