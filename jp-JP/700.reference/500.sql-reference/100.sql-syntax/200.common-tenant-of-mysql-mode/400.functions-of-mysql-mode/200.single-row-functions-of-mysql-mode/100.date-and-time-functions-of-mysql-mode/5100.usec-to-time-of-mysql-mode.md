# USEC_TO_TIME

`USEC_TO_TIME`関数は、マイクロ秒数（usec）をTIMESTAMP型の値に変換するために使用されます。OceanBaseデータベースが使用するタイムゾーンはUTC（協定世界時）です。したがって、マイクロ秒数をTIMESTAMPに変換する際、システムはタイムゾーン情報を考慮し、UTCタイムゾーンを基準とします。

## 関数構文

```sql
USEC_TO_TIME(usec)
```

## パラメータの説明

|パラメータ | 説明 |
|-------|------|
|`usec` | `TIMESTAMP`型の値に変換する必要があります。`usec`は`1970-01-01 00:00:00.000000`からのマイクロ秒数を表します。|

## 例

```sql
obclient> SELECT USEC_TO_TIME(1);
+----------------------------+
| USEC_TO_TIME(1)            |
+----------------------------+
| 1970-01-01 08:00:00.000001 |
+----------------------------+
1 row in set
```
