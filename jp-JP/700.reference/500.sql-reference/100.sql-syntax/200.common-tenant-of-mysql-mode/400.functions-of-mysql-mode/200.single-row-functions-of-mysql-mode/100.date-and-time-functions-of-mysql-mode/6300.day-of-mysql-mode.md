# DAY

## 宣言

```sql
DAY(date)
```

## 説明

`date` の月の日付を返します。範囲は1から31です。`DAY()` は `DAYOFMONTH()` の同義語です。

## 例

```sql
obclient> SELECT DAY('2008-12-31');
+--------------------------+
| DAY('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
```
