# CURRENT_TIME

## 宣言

```javascript
CURRENT_TIME([scale])
```

## 説明

日付部分を除いた現在の時間を返します。

`scale` はマイクロ秒部分の精度を表し、有効な値は `0` から `6` の整数で、デフォルト値は `0` です。

## 例

```javascript
obclient> SELECT CURRENT_TIME(6);
+-----------------+
| CURRENT_TIME(6) |
+-----------------+
| 11:11:45.215311 |
+-----------------+
1 row in set
```
