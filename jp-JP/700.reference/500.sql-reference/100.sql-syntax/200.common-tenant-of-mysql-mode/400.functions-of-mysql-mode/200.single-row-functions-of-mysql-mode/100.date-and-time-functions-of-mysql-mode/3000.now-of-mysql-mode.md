# NOW

## 宣言

```javascript
NOW([scale])
```

## 説明

現在の日付時刻を返します。タイムゾーン設定が考慮されます。この関数は `CURRENT_TIMESTAMP()` のエイリアスです。

`scale` はマイクロ秒部分の精度を表し、有効な値は `0` から `6` の整数で、デフォルト値は `0` です。

## 例

```sql
obclient> SELECT NOW(6);
+----------------------------+
| NOW(6)                     |
+----------------------------+
| 2021-07-20 16:30:54.816317 |
+----------------------------+
1 row in set
```
