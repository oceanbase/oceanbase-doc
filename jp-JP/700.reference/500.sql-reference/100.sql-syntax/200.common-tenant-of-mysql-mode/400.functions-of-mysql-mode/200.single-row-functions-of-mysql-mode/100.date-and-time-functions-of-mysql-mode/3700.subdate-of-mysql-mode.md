# SUBDATE

## 宣言

```sql
SUBDATE(date,INTERVAL expr unit)

SUBDATE(expr,days)
```

## 説明

SUBDATE()関数が2番目の引数として`INTERVAL`を使用して呼び出される場合、この関数はDATE_SUB()のシノニムであり、日付時刻`date`から`expr`を減じた値を返すために使用されます。

`INTERVAL`および`unit`パラメータの詳細については、[DATE_ADD](../100.date-and-time-functions-of-mysql-mode/900.date-add-of-mysql-mode.md)を参照してください。

`SUBDATE(expr,days)`では、`days`の整数値を使用できます。この場合、日付または日付時刻式`expr`から引く日数として解釈されます。

## 例

```sql
obclient> SELECT DATE_SUB('2022-01-02', INTERVAL 31 DAY);
+-----------------------------------------+
| DATE_SUB('2022-01-02', INTERVAL 31 DAY) |
+-----------------------------------------+
| 2021-12-02                              |
+-----------------------------------------+
1 row in set

obclient> SELECT SUBDATE('2022-01-02', INTERVAL 31 DAY);
+----------------------------------------+
| SUBDATE('2022-01-02', INTERVAL 31 DAY) |
+----------------------------------------+
| 2021-12-02                             |
+----------------------------------------+
1 row in set

obclient> SELECT SUBDATE('2022-01-02 12:00:00', 31);
+------------------------------------+
| SUBDATE('2022-01-02 12:00:00', 31) |
+------------------------------------+
| 2021-12-02 12:00:00                |
+------------------------------------+
1 row in set
```
