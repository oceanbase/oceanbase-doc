# DAYOFMONTH

## 宣言

```sql
DAYOFMONTH(date)
```

## 説明

日付または時刻の日付 `date` が月内で占める位置を返します。

## 例

```sql
obclient> SELECT DAYOFMONTH('2008-12-31');
+--------------------------+
| DAYOFMONTH('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
```
