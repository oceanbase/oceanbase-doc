# DAYOFMONTH

## 宣言

```sql
DAYOFMONTH(date)
```

## 説明

日付または日付時刻 `date` が、その月の何日目に当たるかを返します。

## 例

```sql
obclient> SELECT DAYOFMONTH('2008-12-31');
+--------------------------+
| DAYOFMONTH('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
```
