# DAYOFWEEK

## 宣言

```sql
DAYOFWEEK(date)
```

## 説明

日付または日付時刻 `date` が、その週の何日目に当たるかを返します。日曜日を週の最初の日として数えます。

## 例

```sql
obclient> SELECT DAYOFWEEK('2021-07-15');
+-------------------------+
| DAYOFWEEK('2021-07-15') |
+-------------------------+
|                       5 |
+-------------------------+
1 row in set
```
