# DAYOFWEEK

## 宣言

```sql
DAYOFWEEK(date)
```

## 説明

日付または日時の日付 `date` を、日曜日から数えて1週間のうちの位置を返します。

## 例

```sql
obclient> SELECT DAYOFWEEK('2021-07-15');
+-------------------------+
| DAYOFWEEK('2021-07-15') |
+-------------------------+
|                       5 |
+-------------------------+
1 row in set
```
