# TIME_FORMAT

## 宣言

```sql
TIME_FORMAT(time,format)
```

## 説明

使用方法は `DATE_FORMAT` 関数と似ていますが、`format` は時、分、秒、マイクロ秒のフォーマット指定子のみをサポートしています。

時間値 `time` に23より大きい時間部分が含まれる場合、`%H` および `%k` 時間フォーマット指定子は0から23より大きい値を生成し、他の時間フォーマット指定子は時間値（12を法とする剰余）を生成します。

## 例

```sql
obclient> SELECT TIME_FORMAT('100:00:00', '%H %k %h %I %l');
+--------------------------------------------+
| TIME_FORMAT('100:00:00', '%H %k %h %I %l') |
+--------------------------------------------+
| 100 100 04 04 4                            |
+--------------------------------------------+
1 row in set
```
