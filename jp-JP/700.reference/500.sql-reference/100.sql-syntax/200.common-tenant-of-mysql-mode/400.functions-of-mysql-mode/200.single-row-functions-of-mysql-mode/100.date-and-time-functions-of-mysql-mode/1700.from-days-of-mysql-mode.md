# FROM_DAYS

## 宣言

```javascript
FROM_DAYS(N)
```

## 説明

指定された日数 `N` に対応する `DATE` 値を返します。日数は `0000-01-01` からの日数を指します。

## 例

```javascript
obclient> SELECT FROM_DAYS(736271), FROM_DAYS(700000);
+-------------------+-------------------+
| FROM_DAYS(736271) | FROM_DAYS(700000) |
+-------------------+-------------------+
| 2015-11-04        | 1916-07-15        |
+-------------------+-------------------+
1 row in set
```
