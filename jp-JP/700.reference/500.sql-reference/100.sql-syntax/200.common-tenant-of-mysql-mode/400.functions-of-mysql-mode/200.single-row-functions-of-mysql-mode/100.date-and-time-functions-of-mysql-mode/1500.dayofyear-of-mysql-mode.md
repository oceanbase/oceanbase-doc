# DAYOFYEAR

## 宣言

```sql
DAYOFYEAR(date)
```

## 説明

日付または日付時刻 `date` が、その年の何日目に当たるかを返します。

## 例

```sql
obclient> SELECT DAYOFYEAR('2021-07-15');
+-------------------------+
| DAYOFYEAR('2021-07-15') |
+-------------------------+
|                     196 |
+-------------------------+
1 row in set
```
