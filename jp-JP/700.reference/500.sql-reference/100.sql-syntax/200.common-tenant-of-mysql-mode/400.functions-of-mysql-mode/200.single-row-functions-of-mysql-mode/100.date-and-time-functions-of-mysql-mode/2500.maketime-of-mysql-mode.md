# MAKETIME

## 宣言

```sql
MAKETIME(hour,minute,second)
```

## 説明

`hour:minute:second` で指定された時刻値を返します。ここで、`second` には小数部を指定できます。

## 例

```sql
obclient> SELECT MAKETIME(12,15,30);
+--------------------+
| MAKETIME(12,15,30) |
+--------------------+
| 12:15:30.000000    |
+--------------------+
1 row in set
```
