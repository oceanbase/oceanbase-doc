# MAKETIME

## 宣言

```sql
MAKETIME(hour,minute,second)
```

## 説明

`hour:minute:second` で指定された時間値を返します。ここで、`second` には小数部分を含めることができます。

## 例

```sql
obclient> SELECT MAKETIME(12,15,30);
+--------------------+
| MAKETIME(12,15,30) |
+--------------------+
| 12:15:30.000000    |
+--------------------+
1 row in set
```
