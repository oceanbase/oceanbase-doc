# LOCALTIME

## 宣言

```sql
LOCALTIME
LOCALTIME([scale])
```

## 説明

現在の日付時刻を返します。`LOCALTIME` と `LOCALTIME()` は `NOW()` のシノニムです。

`scale` はマイクロ秒部分の精度を表し、有効な値は `0` から `6` の整数で、デフォルト値は `0` です。

## 例

```sql
obclient> SELECT LOCALTIME(0);
+---------------------+
| LOCALTIME(0)        |
+---------------------+
| 2021-08-25 17:20:31 |
+---------------------+
1 row in set

obclient> SELECT LOCALTIME(6);
+----------------------------+
| LOCALTIME(6)               |
+----------------------------+
| 2021-08-25 17:20:41.358574 |
+----------------------------+
1 row in set
```
