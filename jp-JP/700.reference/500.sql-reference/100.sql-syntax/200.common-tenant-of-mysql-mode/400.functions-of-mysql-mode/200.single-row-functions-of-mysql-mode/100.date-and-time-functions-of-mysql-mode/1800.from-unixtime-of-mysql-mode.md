# FROM_UNIXTIME

## 宣言

```javascript
FROM_UNIXTIME(unix_timestamp)
FROM_UNIXTIME(unix_timestamp, format)
```

## 説明

`FROM_UNIXTIME()` の戻り値は、以下のルールに従います：

* `format` パラメータを指定しない場合、タイムゾーンを考慮せずに `DATETIME` タイプの値を返します。

* `format` パラメータを指定した場合、指定された形式の日付時刻文字列を返します。

`unix_timestamp` とは、UNIXタイムスタンプのことであり、`1970-01-01 00:00:00` からの秒数を指します。

`format` がサポートする形式の詳細については、[DATE_FORMAT](../100.date-and-time-functions-of-mysql-mode/1000.date-format-of-mysql-mode.md)を参照してください。

## 例

```javascript
obclient> SELECT FROM_UNIXTIME(UNIX_TIMESTAMP(), '%Y %D %M %h:%i:%s %x');
+---------------------------------------------------------+
| FROM_UNIXTIME(UNIX_TIMESTAMP(), '%Y %D %M %h:%i:%s %x') |
+---------------------------------------------------------+
| 2018 5th May 08:41:26 2018                              |
+---------------------------------------------------------+
1 row in set
```
