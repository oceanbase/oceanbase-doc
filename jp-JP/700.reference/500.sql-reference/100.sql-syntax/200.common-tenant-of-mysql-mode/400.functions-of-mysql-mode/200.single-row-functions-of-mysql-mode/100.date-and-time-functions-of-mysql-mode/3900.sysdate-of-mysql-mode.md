# SYSDATE

## 宣言

```sql
SYSDATE(fsp)
```

## 説明

現在の日付と時刻を返します。形式は `%Y-%m-%d %H.%i.%s` です。

`fsp` は秒の精度を表します。つまり、戻り値の小数点以下の秒の部分に含まれる数字の位数です。有効な値は 0 から 6 の整数で、デフォルト値は 0 です。

## 例

```sql
obclient> SELECT SYSDATE();
+---------------------+
| SYSDATE()           |
+---------------------+
| 2021-07-15 14:10:06 |
+---------------------+
1 row in set
```
