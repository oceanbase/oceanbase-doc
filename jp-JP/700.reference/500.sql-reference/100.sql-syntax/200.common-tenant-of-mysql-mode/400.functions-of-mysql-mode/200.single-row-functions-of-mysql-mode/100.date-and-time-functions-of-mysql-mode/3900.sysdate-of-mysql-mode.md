# SYSDATE

## 宣言

```sql
SYSDATE(fsp)
```

## 説明

現在の日付と時刻を返します。フォーマットは `%Y-%m-%d %H.%i.%s` です。

`fsp` は秒の精度を表します。つまり、返される値の小数点以下の秒の部分に含まれる桁数を示します。有効な値は0から6の整数で、デフォルト値は0です。

## 例

```sql
obclient> SELECT SYSDATE();
+---------------------+
| SYSDATE()           |
+---------------------+
| 2021-07-15 14:10:06 |
+---------------------+
1 row in set
```
