# TO_DAYS

## 宣言

```javascript
TO_DAYS(date)
```

## 説明

指定された `date` 値に対応する日数を返します。日数は `0000-01-01` からの日数を指します。

## 例

```javascript
obclient> SELECT TO_DAYS('2015-11-04'), TO_DAYS('20151104');
+-----------------------+---------------------+
| TO_DAYS('2015-11-04') | TO_DAYS('20151104') |
+-----------------------+---------------------+
|                736271 |              736271 |
+-----------------------+---------------------+
1 row in set
```
