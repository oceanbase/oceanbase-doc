# YEAR

## 宣言

```sql
YEAR(date)
```

## 説明

`date`値の年の情報を返します。

## 例

```sql
obclient> SELECT YEAR('1987-01-01');
+--------------------+
| YEAR('1987-01-01') |
+--------------------+
|               1987 |
+--------------------+
1 row in set
```
