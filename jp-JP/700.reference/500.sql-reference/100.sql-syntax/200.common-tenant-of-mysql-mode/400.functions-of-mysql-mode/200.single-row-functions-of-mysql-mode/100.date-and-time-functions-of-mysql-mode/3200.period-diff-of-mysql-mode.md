# PERIOD_DIFF

## 宣言

```javascript
PERIOD_DIFF(p1, p2)
```

## 説明

2つの日付間の期間を月単位で返します。日付には年月情報のみを含めることができ、形式は`YYYYMM`または`YYMM`のいずれかです。

## 例

```javascript
obclient> SELECT PERIOD_DIFF(200802, 200703);
+----------------------------+
| PERIOD_DIFF(200802,200703) |
+----------------------------+
|                         11 |
+----------------------------+
1 row in set
```
