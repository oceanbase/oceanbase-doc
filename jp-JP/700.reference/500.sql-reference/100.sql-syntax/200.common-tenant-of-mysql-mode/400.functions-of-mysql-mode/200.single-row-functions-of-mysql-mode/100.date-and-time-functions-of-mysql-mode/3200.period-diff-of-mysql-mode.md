# PERIOD_DIFF

## 宣言

```javascript
PERIOD_DIFF(p1, p2)
```

## 説明

月単位で2つの日付間の期間を返します。日付には年と月の情報のみ含まれている必要があり、形式は `YYYYMM` または `YYMM` のみとなります。

## 例

```javascript
obclient> SELECT PERIOD_DIFF(200802, 200703);
+----------------------------+
| PERIOD_DIFF(200802,200703) |
+----------------------------+
|                         11 |
+----------------------------+
1 row in set
```
