# SECOND

## 宣言

```sql
SECOND(time)
```

## 説明

時間 `time` の秒数を返します。

## 例

```sql
obclient> SELECT SECOND('18:20:17');
+--------------------+
| SECOND('18:20:17') |
+--------------------+
|                 17 |
+--------------------+
1 row in set
```
