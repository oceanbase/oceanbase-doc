# QUARTER

## 宣言

```sql
QUARTER(date)
```

## 説明

指定された日付の四半期値を返します。取り得る範囲は \[1,4\] です。

## 例

```sql
obclient> SELECT QUARTER(NOW()), NOW();
+----------------+---------------------+
| QUARTER(NOW()) | NOW()               |
+----------------+---------------------+
|              3 | 2021-07-12 19:45:01 |
+----------------+---------------------+
1 row in set
```
