# UPDATEXML

## 説明

この関数は、XML文字列内で指定されたパスのノード内容を更新するために使用します。

## 構文

```sql
UPDATEXML(xml_target, xpath_expr, new_xml)
```

## パラメータの説明

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>xml_target</code> のうち、<code>xpath_expr</code> で指定された部分を <code>new_xml</code> に置き換えます。<code>xpath_expr</code> が結果と一致しない場合、または複数の結果と一致する場合は、<code>xml_target</code> の元の結果を返します。</p>
</main>

| **フィールド** | **説明** |
| -------- | -------- |
| xml_target | 指定されたXML文字列。XMLドキュメントまたは断片です。|
| xpath_expr | 更新対象ノードのパス(XPath)式を指定します。|
| new_xml | 置き換えるノードの新しいXML断片を指定します。|

## 戻り値の型

戻り値の型は `LONGTEXT` です。

## 例

* `UPDATEXML` 関数を使用して、XML文字列内の `</a>` ノードを `<x>carrot</x>` ノードに置き換え、更新後のXML文字列を返します。`<a/><b/>` は、`<a>` と `<b>` の2つのノードを含むルートノードを表します。

  ```shell
  obclient [test_db]> SELECT UPDATEXML('<a/><b/>', '/a', '<x>carrot</x>');
  ```

  実行結果は次のとおりです：

  ```shell
  +----------------------------------------------+
  | UPDATEXML('<a/><b/>', '/a', '<x>carrot</x>') |
  +----------------------------------------------+
  | <x>carrot</x><b></b>                         |
  +----------------------------------------------+
  1 row in set
  ```

* `UPDATEXML` 関数を使用して、XML文字列内の `root` ノードの下の `a` ノードを `<b>bbb</b>` ノードに置き換え、更新後のXML文字列を返します。

  ```shell
  obclient [test_db]> SELECT UPDATEXML('<root><a>aaa</a></root>', '/root/a', '<b>bbb</b>');
  ```

  実行結果は次のとおりです：

  ```shell
  +---------------------------------------------------------------+
  | UPDATEXML('<root><a>aaa</a></root>', '/root/a', '<b>bbb</b>') |
  +---------------------------------------------------------------+
  | <root><b>bbb</b></root>                                       |
  +---------------------------------------------------------------+
  1 row in set
  ```
