# NVL

## 宣言

```sql
NVL(str1,replace_with)
```

## 説明

`NULL` 値を指定値に置き換えます。`str1` が `NULL` の場合、`replace_with` で指定された値を返します。ここで、`str1` は通常、列名です。`replace_with` は、直接指定する値（ハードコード）、他の列への参照、または式にすることができます。

このような `NULL` 値を自動的に置き換える機能により、出力内容をより充実させることができます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2 BP4バージョン以降、<code>NVL</code> は短絡評価を採用しています。<code>str1</code> が <code>NULL</code> の場合にのみ <code>replace_with</code> が評価されます。例えば、<code>NVL(1, 1/0)</code> は <code>1</code> を返し、<code>1/0</code> によるエラーは発生しません。</p>
</main>

## 例

```sql
obclient> SELECT NVL(NULL, 0), NVL(NULL, 'a');
+--------------+----------------+
| NVL(NULL, 0) | NVL(NULL, 'a') |
+--------------+----------------+
|            0 | a              |
+--------------+----------------+
1 row in set
```
