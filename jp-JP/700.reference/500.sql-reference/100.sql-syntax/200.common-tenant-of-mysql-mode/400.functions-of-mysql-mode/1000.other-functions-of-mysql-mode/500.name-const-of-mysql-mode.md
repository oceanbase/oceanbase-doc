# NAME_CONST

## 宣言

```sql
NAME_CONST(name,value)
```

## 説明

この関数は、指定された値を返します。パラメータ `value` は定数である必要があります。

`NAME_CONST()` は、生成される結果セットの列に指定された名前を付けます。

## 例

```sql
obclient> SELECT NAME_CONST('my_id', 101);
+-------+
| my_id |
+-------+
|   101 |
+-------+
1 row in set
```

上記の例とまったく同じ結果を得るには、簡単なエイリアスを設定することもできます。以下に示します：

```sql
SELECT 101 AS my_id;
```
