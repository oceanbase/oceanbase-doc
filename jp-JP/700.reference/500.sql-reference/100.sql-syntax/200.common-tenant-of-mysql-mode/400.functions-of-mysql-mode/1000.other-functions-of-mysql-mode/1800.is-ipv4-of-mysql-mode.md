# ISIpv4

## 宣言

```sql
IS_IPV4(expr)
```

## 説明

パラメータ `expr` が有効なIPv4アドレス文字列である場合は1を返し、そうでない場合は0を返します。

指定されたパラメータについて、`IS_IPV4()` が1を返す場合、`INET_ATON()` と `INET6_ATON()` は `NULL` 以外を返します。逆は必ずしも正しくありません。場合によっては、`IS_IPV4()` が0を返すときに `INET_ATON()` が `NULL` 以外を返すことがあります。`IS_IPV4()` はIPv4アドレスに対して `INET_ATON()` よりも厳格な要件を持ちます。`INET6_ATON()` はIPv4アドレスのチェックにおいて `IS_IPV4()` と同等の強力さを備えています。

## 例

```sql
obclient> SELECT IS_IPV4('10.x.x.9'), IS_IPV4('10.x.x.256');
+---------------------+-----------------------+
| IS_IPV4('10.x.x.9') | IS_IPV4('10.x.x.256') |
+---------------------+-----------------------+
|                   1 |                     0 |
+---------------------+-----------------------+
1 row in set
```
