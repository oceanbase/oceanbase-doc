# INET_ATON

## 宣言

```sql
INET_ATON(expr)
```

## 説明

IPv4ネットワークアドレスを文字列として表現し、ネットワークバイト順序（ビッグエンディアン）でアドレス値を表す整数を返します。パラメータが無効な場合は、`NULL` を返します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>INET_ATON()</code> によって生成された値は、<code>INT UNSIGNED</code> 列に格納してください。符号付きの <code>INT</code> 列を使用することはできません。符号付きの列を使用すると、IPアドレスの最初の8ビットが127より大きい場合、対応する値を正しく格納できなくなります。</p>
  </main>

## 例

```sql
obclient> SELECT INET_ATON('1.1.1.1');
+----------------------+
|  INET_ATON('1.1.1.1') |
+----------------------+
|             16843009 |
+----------------------+
1 row in set
```
