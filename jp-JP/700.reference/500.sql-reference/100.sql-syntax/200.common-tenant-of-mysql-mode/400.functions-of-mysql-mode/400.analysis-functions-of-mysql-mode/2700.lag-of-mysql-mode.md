# LAG

## 宣言

```sql
LAG { ( value_expr [, offset [, default]]) [ { RESPECT | IGNORE } NULLS ] | ( value_expr [ { RESPECT | IGNORE } NULLS ] [, offset [, default]] )} OVER ([ query_partition_clause ] order_by_clause)
```

## 説明

1回のクエリで、現在の行の同一フィールドの後ろから`offset`行目のデータを取得する操作は、同一テーブルの自己結合を使用して実現できますが、`LAG()`ウィンドウ関数の方がより高い効率を発揮します。

## パラメータ

各パラメータの意味は以下の表のとおりです。

|                パラメータ                |                                      意味                                       |
|----------------------------------|-------------------------------------------------------------------------------|
| `value_expr`                     | 比較対象のフィールドを表します                                                                    |
| `offset`                         | `value_expr` のオフセット量を表します                                                          |
| `default`                        | デフォルトの返り値を表します。 省略値は `NULL` であり、明示的に `default` 値が設定されていない場合、返り値は `NULL` となることを意味します。 |
| `[ { RESPECT | IGNORE } NULLS ]` | `NULL` 値を考慮するかどうかを表します。 省略値は `RESPECT NULLS` であり、`NULL` 値を考慮することを意味します。          |
| `order_by_clause`                | データが特定の列でソートされた後に、先頭の何行目から末尾の何行目までを取得するかを指定します。                                                |
| `query_partition_clause`         | クエリのパーティションを指定します。省略されている場合、グローバルデータを使用することを意味します。                                                     |

## 例

```sql
obclient> CREATE TABLE employees(LAST_NAME CHAR(10), SALARY DECIMAL, JOB_ID CHAR(32));
Query OK, 0 rows affected

obclient> INSERT INTO employees VALUES('JIM', 2000, 'CLEANER');
Query OK, 1 row affected

obclient> INSERT INTO employees VALUES('MIKE', 12000, 'ENGINEERING');
Query OK, 1 row affected

obclient> INSERT INTO employees VALUES('LILY', 13000, 'ENGINEERING');
Query OK, 1 row affected

obclient> INSERT INTO employees VALUES('TOM', 11000, 'ENGINEERING');
Query OK, 1 row affected

obclient> SELECT LAST_NAME, LEAD(SALARY) OVER(ORDER BY SALARY) LEAD, LAG(SALARY) OVER(ORDER BY SALARY) LAG FROM employees;
+-----------+-------+-------+
| LAST_NAME | LEAD  | LAG   |
+-----------+-------+-------+
| JIM       | 11000 |  NULL |
| TOM       | 12000 |  2000 |
| MIKE      | 13000 | 11000 |
| LILY      |  NULL | 12000 |
+-----------+-------+-------+
4 rows in set
```
