# PERCENTILE_CONT

## 説明

この関数は、指定された列の正確なパーセンタイルを計算するために使用されます。この関数は入力列を昇順にソートし、指定されたパーセンタイル値（`percentile`）に基づいて対応する補間結果を返します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.2.5では、この関数はV4.2.5 BP4バージョンからサポートされています。</p>
</main>

## 制限

現在のバージョンの`PERCENTILE_CONT`は`DATETIME`型をサポートしていません。

## 構文宣言

```sql
PERCENTILE_CONT(expr, percentile)
```

## パラメータの説明

* `expr`：パーセンタイルを計算する対象の列で、現在は数値型である必要があります。サポートされている具体的な型については[サポートされている型](#サポートされている型)を参照してください。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><code>PERCENTILE_CONT</code>は、入力列内の<code>NULL</code>値を自動的に無視します。</p>
    </main>

* `percentile`：指定されたパーセンタイル値で、データ分布における目標値の位置を示します。値の範囲は[0, 1]の浮動小数点定数です。

### サポートされている型

* 整数型：`TINYINT`、`SMALLINT`、`MEDIUMINT`、`INT`/`INTEGER`、`BIGINT`。
* 固定小数点型：`DECIMAL`と`NUMERIC`。
* 浮動小数点型：`FLOAT`と`DOUBLE`。
* Bit-Value型：`BIT`。

## 戻り値の型

戻り値の型は`expr`と一致します。

指定されたパーセンタイルにある値を返します。入力値のうち、必要なパーセンタイルに正確に位置する値がない場合は、最も近い2つの入力値の線形補間を使用して結果を計算します。

## 例

1. 列`col1`と`col2`を含むテストテーブル`test_tbl1`を作成します。

    ```sql
    CREATE TABLE test_tbl1(col1 VARCHAR(10), col2 INT);
    ```

2. テーブル`test_tbl1`にテストデータを挿入します。

    ```sql
    INSERT INTO test_tbl1 VALUES
        ('A1', 80), ('A1', 100), ('A1', NULL),
        ('B1', 60), ('B1', 70), ('B1', 85),
        ('C1', 75), ('C1', 80), ('C1', 85), ('C1', 99);
    ```

3. `PERCENTILE_CONT`を使用して、列`col1`の各カテゴリの中央値（すなわち50パーセンタイル）を計算します。

    ```sql
    SELECT col1, PERCENTILE_CONT(col2, 0.5)
    FROM test_tbl1
    GROUP BY col1;
    ```

    実行結果は次のとおりです：

    ```shell
    +------+----------------------------+
    | col1 | PERCENTILE_CONT(col2, 0.5) |
    +------+----------------------------+
    | A1   |                         90 |
    | B1   |                         70 |
    | C1   |                       82.5 |
    +------+----------------------------+
    3 rows in set
    ```
