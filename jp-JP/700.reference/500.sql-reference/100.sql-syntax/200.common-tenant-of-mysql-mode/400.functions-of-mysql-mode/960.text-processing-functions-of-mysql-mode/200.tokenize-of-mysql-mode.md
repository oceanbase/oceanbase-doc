# TOKENIZE

## 説明

この関数は、指定されたトークナイザーとJSON形式のパラメータに基づいて、テキストを分かち書きした結果を出力します。

## 構文

```sql
TOKENIZE('text', ['parser'], ['behavior_ctrl'])
```

## パラメータの説明

|    **パラメータ**   | **説明** |
|---------------|----------|
| text          | テキストを表します。`TEXT`、`CHAR`、`VARCHAR` 型のデータをサポートします。|
| parser        | トークナイザーの名前を表します。`BENG`（基本英語）、`NGRAM`（中国語）、`SPACE`（スペース）、`IK`（中国語）などのトークナイザーをサポートします。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、V4.3.5 BP1バージョンから <code>IK</code> トークナイザーがサポートされています。</p></main> |
| behavior_ctrl | JSON形式のパラメータで指定します。オプションは以下のとおりです：<ul><li>`stopwords`：ストップワードリストです。設定しない場合は、グローバルデフォルト設定に従い、グローバルストップワードを適用します。空に設定した場合は、ストップワードリストは空になります。</li><li>`case`：設定しない場合は、システムのデフォルト動作で処理します。設定されている場合は、upper/lowerに従って大文字または小文字に変換します。</li><li>`output`：以下の形式があります：<ul><li>`default`：トークンのみを含む `json array, ["hello", "world", "english"]` を出力します。</li><li>`all`：`doc_len` と単語の出現頻度を含む `json object` を出力します。例：`{"doc_len":3, "tokens":["i":1, "love":1, "china":1]}`。</li><li>`additional-args`：`ngram`などの特定のトークナイザーのパラメータを指定します。例：`["token_size:2"]`。</li></ul></li></ul>|

## 例

`TOKENIZE` 関数を使用して、文字列 `I Love China` を単語に分解し、`beng` を区切り文字として使用します。次に、`JSON` 形式のパラメータを使用して出力オプションを設定します。

```sql
SELECT TOKENIZE('I Love China','beng', '[{"output": "all"}]');
```

実行結果は次のとおりです：

```shell
+--------------------------------------------------------+
| TOKENIZE('I Love China','beng', '[{"output": "all"}]') |
+--------------------------------------------------------+
| {"tokens": [{"love": 1}, {"china": 1}], "doc_len": 2}  |
+--------------------------------------------------------+
1 row in set
```
