# ビットマップ判定関数

ビットマップ判定関数は、入力されたビットマップデータに対して一定の判定を行い、ブール値を返します。OceanBaseデータベースで現在サポートされているビットマップ判定関数には、`rb_is_empty()` と `rb_contains()` があります。

## rb_is_empty

`rb_is_empty()` 関数は、入力されたビットマップデータが空かどうかを判定します。構文は以下のとおりです：

```sql
rb_is_empty(rb)
```

戻り値 `1` は空を表し、`0` は空ではないことを表します。

例：

```sql
SELECT rb_is_empty(rb_from_string(''));
+---------------------------------+
| rb_is_empty(rb_from_string('')) |
+---------------------------------+
|                               1 |
+---------------------------------+
1 row in set
```

```sql
SELECT rb_is_empty(rb_from_string('1,2,3'));
+--------------------------------------+
| rb_is_empty(rb_from_string('1,2,3')) |
+--------------------------------------+
|                                    0 |
+--------------------------------------+
1 row in set
```

## rb_contains

`rb_contains()` 関数には2つの使い方があります：

* 入力された最初のビットマップデータ（`rb1`）が、2番目のビットマップデータ（`rb2`）を完全に含んでいるかどうかを判定するために使用します。
* 入力されたビットマップデータに特定のオフセット（`offset`）が含まれているかどうかを判定するために使用します。

2つの使い方は、異なる構文で実装されています。詳細は以下のとおりです。

### 使い方1

`rb_contains()` 関数は、入力された最初のビットマップデータ（`rb1`）が、2番目のビットマップデータ（`rb2`）を完全に含んでいるかどうかを判定するために使用できます。構文は以下のとおりです：

```sql
rb_contains(rb1, rb2)
```

詳細は以下のとおりです：

* 入力パラメータ `rb1` が計算の基準となり、入力パラメータ `rb2` が計算対象のビットマップデータとなります。つまり、`rb2` の各要素がすべて `rb1` に含まれているかどうかをチェックします。
* パラメータ `rb1` と `rb2` の順序は結果に影響します。
* 戻り値 `1` は完全に含まれていることを表し、`0` は完全には含まれていないことを表します。

例：

```sql
SELECT rb_contains(rb_from_string('1,2,3,4,5'), rb_from_string('1,2,3,4'));
+---------------------------------------------------------------------+
| rb_contains(rb_from_string('1,2,3,4,5'), rb_from_string('1,2,3,4')) |
+---------------------------------------------------------------------+
|                                                                   1 |
+---------------------------------------------------------------------+
1 row in set
```

### 用法二

`rb_contains()` 関数は、入力されたビットマップデータに特定のオフセット（`offset`）が含まれているかどうかを判断するために使用できます。構文は以下のとおりです：

```sql
rb_contains(rb, offset)
```

詳細は以下のとおりです：

* 入力パラメータ `rb` は計算の基礎となるビットマップデータです。
* `offset` は整数でなければならず、この整数がビットマップデータ `rb` に存在するかどうかを判断するために使用されます。
* 戻り値 `1` は含まれていることを表し、`0` は含まれていないことを表します。

例：

```sql
SELECT rb_contains(rb_from_string('1,2,3,4,5'), 1);
+---------------------------------------------+
| rb_contains(rb_from_string('1,2,3,4,5'), 1) |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set
```

```sql
SELECT rb_contains(rb_from_string('1,2,3,4,6'), 5);
+---------------------------------------------+
| rb_contains(rb_from_string('1,2,3,4,6'), 5) |
+---------------------------------------------+
|                                           0 |
+---------------------------------------------+
1 row in set
```
