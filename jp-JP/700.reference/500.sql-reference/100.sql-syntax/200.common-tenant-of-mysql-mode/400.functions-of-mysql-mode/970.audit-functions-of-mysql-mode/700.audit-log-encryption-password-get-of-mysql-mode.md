# AUDIT_LOG_ENCRYPTION_PASSWORD_GET

## 説明

この関数は、アーカイブされた監査ログファイル名に含まれる `pwd_id`（暗号化キー識別子）に基づいて、対応するアーカイブファイルの暗号化パスワードを返します。これは、制御環境下でのオフライン復号、証拠収集、または外部ツールとの連携に利用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは、現在監査機能をサポートしていません。</p>
</main>

## 構文

```sql
AUDIT_LOG_ENCRYPTION_PASSWORD_GET(pwd_id);
```

## 権限要件

この関数を使用するには、`SUPER`権限が必要です。

## 説明

### パラメータの説明

* `pwd_id`：Int型。暗号化されたアーカイブファイル名の `.enc.` セグメント以降のフィールドに対応するキー識別子です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この関数は<strong>機密情報</strong>を返します。呼び出し権限を厳格に制限し、操作の監査と結果のマスキングを適切に行ってください。アーカイブファイル名の形式については、<a href="../../../../../../600.manage/500.security-and-permissions/600.security-audit/200.security-audit-of-mysql-mode/300.set-up-audit-rules-of-mysql-mode.md">監査ルールの設定</a>のログ暗号化におけるアーカイブファイル名形式表を参照してください。</p>
</main>

### 使用上の制限

他の監査関数（式）と同様に、直接かつ一意に `SELECT` ステートメントの出力列として使用する必要があり、サブクエリ内には使用できません。[監査関数の概要](100.audit-functions-overview-of-mysql-mode.md) の「使用上の制限と注意事項」を参照してください。

### 戻り値

式の出力は文字列型です。

* クエリが成功した場合、`pwd_id` に対応するパスワードを返します。
* クエリが失敗した場合、`SELECT` ステートメントは実行される可能性がありますが、式の出力結果はエラーメッセージとなります。

## 例

アーカイブファイルの名前が `audit.log.20231031080646317.enc.1001` である場合、`1001` を `pwd_id` として渡すことができます（実際のファイル名から解析された識別子に置き換えてください）。

```sql
SELECT AUDIT_LOG_ENCRYPTION_PASSWORD_GET(1001);
```

戻り値の例は以下のとおりです（実際のキー内容は省略）：

```shell
+-------------------------------------------+
| AUDIT_LOG_ENCRYPTION_PASSWORD_GET(1001)   |
+-------------------------------------------+
| <パスワード>                                |
+-------------------------------------------+
1 row in set
```
