# AUDIT_LOG_FILTER_REMOVE_FILTER

## 説明

この関数（式）は、フィルターを削除するために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは、現在監査機能をサポートしていません。</p>
</main>

## 構文

```sql
AUDIT_LOG_FILTER_REMOVE_FILTER('filter_name');
```

## 説明

### パラメータの説明

`filter_name`：フィルター名を指定するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>AUDIT_LOG_FILTER_REMOVE_FILTER</code> は <code>DROP IF EXISTS</code> のセマンティクスを持ち、存在しないオブジェクトを削除してもエラーは報告されません。</p>
</main>

### 戻り値

式の入力は文字列定数でなければならず、出力は文字列型です。

* DDLが正常に実行された場合、式は `OK` を返します。
* DDLの実行に失敗した場合、`SELECT` ステートメントはそれでも正常に実行され、式の出力結果はエラーメッセージとなります。

## 例

フィルター `log_all` を削除します。

```sql
SELECT AUDIT_LOG_FILTER_REMOVE_FILTER('log_all');
```

戻り結果は次のとおりです：

```shell
+-------------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_FILTER('log_all') |
+-------------------------------------------+
| OK                                        |
+-------------------------------------------+
1 row in set
```
