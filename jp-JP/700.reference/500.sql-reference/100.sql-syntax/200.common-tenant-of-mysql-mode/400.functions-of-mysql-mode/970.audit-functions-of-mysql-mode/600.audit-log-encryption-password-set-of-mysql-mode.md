# AUDIT_LOG_ENCRYPTION_PASSWORD_SET

## 説明

この関数は、監査ログの暗号化が有効な場合に、現在書き込み中の監査ログファイルをアーカイブし、新しい暗号鍵を生成するために使用されます。その後、新しく生成されたアーカイブファイルは新しい鍵で暗号化されます。典型的な用途はキーのローテーションやセキュリティポリシーの変更に伴うものです。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは、現在監査機能をサポートしていません。</p>
</main>

## 構文

```sql
AUDIT_LOG_ENCRYPTION_PASSWORD_SET();
```

## 権限要件

この関数を使用するには、`SUPER`権限が必要です。

## 説明

### パラメータの説明

この関数にはパラメータはありません。

### 使用上の制限

他の監査関数（式）と同様に、直接かつ一意に`SELECT`ステートメントの出力列として使用する必要があり、サブクエリ内には使用できません。[監査関数の概要](100.audit-functions-overview-of-mysql-mode.md)の使用上の制限と注意事項を参照してください。

### 戻り値

式の入力にパラメータはなく、出力は文字列型です。

* 操作が正常に実行された場合、式は`OK`を返します。
* 操作が失敗した場合、`SELECT`ステートメント自体は成功する可能性がありますが、式の出力結果はエラーメッセージとなります。

## 例

キーをローテーションし、現在の監査ログをアーカイブします。

```sql
SELECT AUDIT_LOG_ENCRYPTION_PASSWORD_SET();
```

実行結果は次のとおりです：

```shell
+-----------------------------------------+
| AUDIT_LOG_ENCRYPTION_PASSWORD_SET()     |
+-----------------------------------------+
| OK                                      |
+-----------------------------------------+
1 row in set
```
