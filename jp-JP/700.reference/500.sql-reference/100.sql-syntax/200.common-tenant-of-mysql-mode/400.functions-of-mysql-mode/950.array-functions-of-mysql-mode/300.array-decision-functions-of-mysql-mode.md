# 配列判定関数

配列判定関数は、入力された配列データに対して一定の判定を行い、ブール値を返します。OceanBaseデータベースで現在サポートされている配列判定関数には、`array_contains()`、`array_contains_all()`、`array_overlaps()`があり、サポートされている演算子には `ANY()` が含まれます。

## array_contains

`array_contains()` 関数は、配列に特定の要素が含まれているかどうかを判定します。構文は以下のとおりです：

```sql
array_contains(arr1, element)
```

入力パラメータの説明は以下のとおりです：

* `arr1` は配列型である必要があります。
* `element` は任意の型の要素を指定できます。

戻り値 `1` は含まれていることを表し、`0` は含まれていないことを表します。

例：

```sql
SELECT array_contains([1,2,3], 2);
+----------------------------+
| array_contains([1,2,3], 2) |
+----------------------------+
|                          1 |
+----------------------------+
1 row in set
```

```sql
SELECT array_contains([1,2,3], 6);
+----------------------------+
| array_contains([1,2,3], 6) |
+----------------------------+
|                          0 |
+----------------------------+
1 row in set
```

```sql
SELECT array_contains(["hello", "hi"], "hel");
+----------------------------------------+
| array_contains(["hello", "hi"], "hel") |
+----------------------------------------+
|                                      0 |
+----------------------------------------+
1 row in set
```

```sql
SELECT array_contains(["hello", "hi"], "hi");
+---------------------------------------+
| array_contains(["hello", "hi"], "hi") |
+---------------------------------------+
|                                     1 |
+---------------------------------------+
1 row in set
```

```sql
SELECT array_contains([[1,2],[3,4]], [3.0,4.0]);
+------------------------------------------+
| array_contains([[1,2],[3,4]], [3.0,4.0]) |
+------------------------------------------+
|                                        1 |
+------------------------------------------+
1 row in set
```

## array_contains_all

`array_contains_all()` 関数は、入力された配列に別の配列のすべての要素が含まれているかどうかを判定します。構文は以下のとおりです：

```sql
array_contains_all(arr1, arr2)
```

入力パラメータの説明は以下のとおりです：

* `arr1` は配列型である必要があります。
* `arr2` は配列型である必要があります。

戻り値 `1` は含まれていることを表し、`0` は含まれていないことを表します。

入力パラメータ `arr1` と `arr2` は、同じ（または変換可能な）要素型である必要があります。そうでない場合、処理は失敗します。

例：

```sql
SELECT array_contains_all([1,2,3], [2]);
+----------------------------------+
| array_contains_all([1,2,3], [2]) |
+----------------------------------+
|                                1 |
+----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([2], [1,2,3]);
+----------------------------------+
| array_contains_all([2], [1,2,3]) |
+----------------------------------+
|                                0 |
+----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([1,2,3], null);
+-----------------------------------+
| array_contains_all([1,2,3], null) |
+-----------------------------------+
|                              NULL |
+-----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([1,2,3], [2.0]);
+------------------------------------+
| array_contains_all([1,2,3], [2.0]) |
+------------------------------------+
|                                  1 |
+------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all(["hello", "hi"], ["hi"]);
+---------------------------------------------+
| array_contains_all(["hello", "hi"], ["hi"]) |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([[1,2],[3,4]], [[3.0,4.0]]);
+------------------------------------------------+
| array_contains_all([[1,2],[3,4]], [[3.0,4.0]]) |
+------------------------------------------------+
|                                              1 |
+------------------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([["hello", "world"], ["hi", "what"], ["are you?"]], [["are you?"]]);
+----------------------------------------------------------------------------------------+
| array_contains_all([["hello", "world"], ["hi", "what"], ["are you?"]], [["are you?"]]) |
+----------------------------------------------------------------------------------------+
|                                                                                      1 |
+----------------------------------------------------------------------------------------+
1 row in set
```

## array_overlaps

`array_overlaps()` 関数は、2つの配列に重複する要素が存在するかどうかを判断します。構文は以下のとおりです：

```sql
array_overlaps(arr1, arr2)
```

入力パラメータの説明は以下のとおりです：

* `arr1` は配列型である必要があります。
* `arr2` は配列型である必要があります。

戻り値 `1` は重複する要素が存在することを示し、`0` は存在しないことを示します。

入力パラメータ `arr1` と `arr2` は、同じ（または変換可能な）要素型である必要があります。そうでない場合、処理は失敗します。

例：

```sql
SELECT array_overlaps([1,2,3], [2]);
+------------------------------+
| array_overlaps([1,2,3], [2]) |
+------------------------------+
|                            1 |
+------------------------------+
1 row in set
```

```sql
SELECT array_overlaps([1,2,3], null);
+-------------------------------+
```

## ANY

`ANY()` 演算子と `array_contains()` 関数は、機能、入力パラメータ、戻り値がすべて同じですが、構文が異なります。

```sql
element = ANY(arr1)
```

例：

```sql
SELECT 2 = ANY([1,2,3]);
SELECT 6 = ANY([1,2,3]);
SELECT "hel" = ANY(["hello", "hi"]);
SELECT "hi" = ANY(["hello", "hi"]);
SELECT [3.0,4.0] = ANY([[1,2],[3,4]]);
```
