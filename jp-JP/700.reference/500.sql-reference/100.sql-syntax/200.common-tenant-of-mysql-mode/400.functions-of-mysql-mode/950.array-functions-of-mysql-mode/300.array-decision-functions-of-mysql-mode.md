# 配列判定関数

配列判定関数は、入力された配列データに対して各種判定を行い、ブール値を返します。現在、OceanBase データベースでサポートされている配列判定関数には、`array_contains()`、`array_contains_all()`、`array_overlaps()` があり、サポートされている演算子には `ANY()` があります。

## array_contains

`array_contains()` 関数は、配列に特定の要素が含まれているかどうかを判定します。構文は次のとおりです。

```sql
array_contains(arr1, element)
```

入力パラメーターの説明：

* `arr1` は配列型である必要があります。
* `element` は判定対象の要素で、任意の型を指定できます。

戻り値は、要素が含まれている場合は `1`、含まれていない場合は `0` です。

例：

```sql
SELECT array_contains([1,2,3], 2);
+----------------------------+
| array_contains([1,2,3], 2) |
+----------------------------+
|                          1 |
+----------------------------+
1 row in set
```

```sql
SELECT array_contains([1,2,3], 6);
+----------------------------+
| array_contains([1,2,3], 6) |
+----------------------------+
|                          0 |
+----------------------------+
1 row in set
```

```sql
SELECT array_contains(["hello", "hi"], "hel");
+----------------------------------------+
| array_contains(["hello", "hi"], "hel") |
+----------------------------------------+
|                                      0 |
+----------------------------------------+
1 row in set
```

```sql
SELECT array_contains(["hello", "hi"], "hi");
+---------------------------------------+
| array_contains(["hello", "hi"], "hi") |
+---------------------------------------+
|                                     1 |
+---------------------------------------+
1 row in set
```

```sql
SELECT array_contains([[1,2],[3,4]], [3.0,4.0]);
+------------------------------------------+
| array_contains([[1,2],[3,4]], [3.0,4.0]) |
+------------------------------------------+
|                                        1 |
+------------------------------------------+
1 row in set
```

## array_contains_all

`array_contains_all()` 関数は、入力配列が別の配列のすべての要素を含んでいるかどうかを判定します。構文は次のとおりです。

```sql
array_contains_all(arr1, arr2)
```

入力パラメーターの説明：

* `arr1` は配列型である必要があります。
* `arr2` は配列型である必要があります。

戻り値は、すべての要素を含んでいる場合は `1`、含んでいない場合は `0` です。

`arr1` と `arr2` の要素型は同一、または相互変換可能である必要があります。そうでない場合はエラーとなります。

例：

```sql
SELECT array_contains_all([1,2,3], [2]);
+----------------------------------+
| array_contains_all([1,2,3], [2]) |
+----------------------------------+
|                                1 |
+----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([2], [1,2,3]);
+----------------------------------+
| array_contains_all([2], [1,2,3]) |
+----------------------------------+
|                                0 |
+----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([1,2,3], null);
+-----------------------------------+
| array_contains_all([1,2,3], null) |
+-----------------------------------+
|                              NULL |
+-----------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([1,2,3], [2.0]);
+------------------------------------+
| array_contains_all([1,2,3], [2.0]) |
+------------------------------------+
|                                  1 |
+------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all(["hello", "hi"], ["hi"]);
+---------------------------------------------+
| array_contains_all(["hello", "hi"], ["hi"]) |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([[1,2],[3,4]], [[3.0,4.0]]);
+------------------------------------------------+
| array_contains_all([[1,2],[3,4]], [[3.0,4.0]]) |
+------------------------------------------------+
|                                              1 |
+------------------------------------------------+
1 row in set
```

```sql
SELECT array_contains_all([["hello", "world"], ["hi", "what"], ["are you?"]], [["are you?"]]);
+----------------------------------------------------------------------------------------+
| array_contains_all([["hello", "world"], ["hi", "what"], ["are you?"]], [["are you?"]]) |
+----------------------------------------------------------------------------------------+
|                                                                                      1 |
+----------------------------------------------------------------------------------------+
1 row in set
```

## array_overlaps

`array_overlaps()` 関数は、2 つの配列に共通要素（積集合）が存在するかどうかを判定します。構文は次のとおりです。

```sql
array_overlaps(arr1, arr2)
```

入力パラメーターの説明：

* `arr1` は配列型である必要があります。
* `arr2` は配列型である必要があります。

戻り値は、共通要素が存在する場合は `1`、存在しない場合は `0` です。

`arr1` と `arr2` の要素型は同一、または相互変換可能である必要があります。そうでない場合はエラーとなります。

例：

```sql
SELECT array_overlaps([1,2,3], [2]);
+------------------------------+
| array_overlaps([1,2,3], [2]) |
+------------------------------+
|                            1 |
+------------------------------+
1 row in set
```

SELECT array_overlaps([1,2,3], null);

## ANY

`ANY()` 演算子は、機能、入力パラメーター、および戻り値の点で `array_contains()` 関数と同等ですが、構文が異なります。

```sql
element = ANY(arr1)
```

例：

```sql
SELECT 2 = ANY([1,2,3]);
SELECT 6 = ANY([1,2,3]);
SELECT "hel" = ANY(["hello", "hi"]);
SELECT "hi" = ANY(["hello", "hi"]);
SELECT [3.0,4.0] = ANY([[1,2],[3,4]]);
```
