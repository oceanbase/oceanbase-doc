# 配列コンストラクタ

配列コンストラクタは、新しい配列データ型を作成するために使用されます。OceanBaseデータベースで現在サポートされている配列コンストラクタには `array()` と `rb_build()` があり、サポートされている演算子には `[]` が含まれます。

## array

`array()` 関数は、配列データを構築するために使用されます。構文は以下のとおりです：

```sql
array(elem1, elem2, elem3, ..., elemN)
[elem1, elem2, elem3, ..., elemN]
```

elem1～elmenN：入力パラメータはすべて同じデータ型である必要があります。現在サポートされている配列データ型については、[配列データ型の概要](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/1200.array-data-type-of-mysql-mode/100.array-data-type-overview-of-mysql-mode.md)を参照してください。

例：

```sql
SELECT array(1, 2, 3);
+----------------+
| array(1, 2, 3) |
+----------------+
| [1,2,3]        |
+----------------+
1 row in set
```

## rb_build

`rb_build()` 関数は、整数型の基本データ型を持つ配列データを効率的に圧縮されたビットマップデータ（RoaringBitmap）に変換するために使用されます。構文は以下のとおりです：

```sql
rb_build(arr)
```

入力パラメータの説明は以下のとおりです：

* `arr` に渡す型は配列型でなければなりません。

戻り値は、配列のすべての要素を含むRoaringBitmapです。

制約事項は以下のとおりです：

* 配列には空要素を含めることはできません。
* ネスト配列の場合、各サブ配列の基本要素を再帰的に取り出し、Roaringbitmapに挿入します。
* Roaringbitmapは符号なし64ビット整数（uint64）と符号付き32ビット整数（int32）データの挿入をサポートしています。[rb_from_string](../940.roaring-bitmap-functions-of-mysql-mode/200.roaring-bitmap-constructor-functions-of-mysql-mode.md) の動作と一致しており、入力された符号付き32ビット整数の負数は、まず符号なし32ビット整数に変換された後、RoaringBitmapに挿入されます。したがって、許容される整数の範囲は、符号付き32ビット整数の最小値から符号なし64ビット整数の最大値、すなわち `[INT32_MIN, UINT64_MAX]` です。

例：

```sql
SELECT rb_to_string(rb_build([1.2]));
ERROR 5083 (22000): Invalid data type for the operation
```

```sql
SELECT rb_to_string(rb_build([0,1,2]));
+---------------------------------+
| rb_to_string(rb_build([0,1,2])) |
+---------------------------------+
| 0,1,2                           |
+---------------------------------+
1 row in set
```

```sql
SELECT rb_to_string(rb_build([[0,1],[2],[2,3]]));
+-------------------------------------------+
| rb_to_string(rb_build([[0,1],[2],[2,3]])) |
+-------------------------------------------+
| 0,1,2,3                                   |
+-------------------------------------------+
1 row in set
```

## []

演算子 `[]` は配列データの構築にも使用できます。例：

```sql
SELECT [1, 2, 3];
+-----------+
| [1, 2, 3] |
+-----------+
| [1,2,3]   |
+-----------+
1 row in set
```
