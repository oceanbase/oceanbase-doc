# 式の概要

式は広義の概念であり、通常は複数の入力パラメータを含み、1つの出力結果を返します。入力パラメータは、定数や単一行データだけでなく、複数行データからも取得できます。式は組み合わせることができ、ある式の入力が別の式の出力になることもあります。

式の出典と形式に基づいて、以下のカテゴリに分類できます：

* 列参照

* 定数

* 演算子

* 関数

式はSQL文の複数の場所で使用できます。例えば、`SELECT` 文の `ORDER BY` 句や `HAVING` 句、`SELECT`、`DELETE`、または `UPDATE` 文の `WHERE` 句、あるいは `SET` 文などです。式には、文字列、列値、`NULL`、変数、組み込み関数と演算子、ロード可能な関数、ストアド関数（一種の格納オブジェクト）など、複数のソースからの値を使用できます。

例：

```javascript
SELECT ABS(a + 1)
  FROM t1
 WHERE a > 0;
```

上記の例において、各パラメータの説明は以下の通りです：

* `a` は列参照です。

* 0 と 1 は定数です。

* `>` と `+` は演算子で、0、1、`a` の式を入力として取ります。

* `ABS` は関数で、`+` の式を入力として取ります。
