# 式の概要

式とは広義の概念であり、通常は複数の入力パラメータを含み、1つの出力結果を返します。入力パラメータは定数や単一行データから得られる場合もあれば、複数行データから得られる場合もあります。また、式は組み合わせることができ、ある式の入力が別の式の出力になることもあります。

式の出所と形式によって、以下のように分類することができます：

* 列参照

* 定数

* 演算子

* 関数

式はSQL文の複数の箇所で使用できます。例えば、`SELECT` 文の `ORDER BY` または `HAVING` 句、`SELECT`、`DELETE` または `UPDATE` 文の `WHERE` 句、または `SET` 文などです。式は、リテラル、列値、`NULL`、変数、組み込み関数と演算子、読み込み可能な関数およびストレージ関数（ストレージオブジェクトの一種）など、複数のソースの値を使用して記述できます。

例：

```javascript
SELECT ABS(a + 1)
  FROM t1
 WHERE a > 0;
```

上記の例では、各パラメータの説明は以下の通りです：

* `a` は列参照です。

* 0と1は定数です。

* `>` と `+` は演算子であり、0、1、`a` の式を入力として使用します。

* `ABS` は関数であり、`+` の式を入力として使用します。
