# マップデータ型の概要

OceanBaseデータベースは、マップデータ型（MAP）をサポートしています。マップ型は、順序のないキー・バリュー・ペア（Key-value Pair）を格納するために使用されます。マップデータ型（MAP）は、キー（Key）と対応する値（Value）で構成されています。このデータ型により、`{a:1, b:2, c:3}` のような順序のないキー・バリュー・ペアを簡単に管理でき、設定オプション、ユーザープロパティ、製品情報などのシナリオで非常に便利です。

現在、MAPは主にマップデータの定義（DDL）と操作（DML）を実装しています。マップは、マップ式または文字列を使用して作成できます。さらに、マップ内のキーまたは値の配列を抽出するための `map_keys` および `map_values` という2つの式が提供されており、データ処理や分析を容易にします。

OceanBaseデータベースの現在のバージョンでは、キーに使用できるマップ要素型は以下のとおりです：

* 整数型：`TINYINT`、`SMALLINT`、`INT`/`INTEGER`、`BIGINT`。`UNSIGNED` 修飾子をサポートします。
* 浮動小数点型：`FLOAT` および `DOUBLE`。
* 文字列型：`VARCHAR`。

値に使用できる要素型は以下のとおりです：

* 整数型：`TINYINT`、`SMALLINT`、`INT`/`INTEGER`、`BIGINT`。`UNSIGNED` 修飾子をサポートします。
* 浮動小数点型：`FLOAT` および `DOUBLE`。
* 文字列型：`VARCHAR`。
* 配列型：`ARRAY`。

説明および制限事項は以下のとおりです：

* `<`、`>`、`>=`、`<=` の比較演算子はサポートされていません。
* `ORDER BY`、`GROUP BY`、`MIN`、`MAX`、`AVG`、`SUM` の集約操作はサポートされていません。
* 値のネスト配列の最大深さは6層です。

マップデータ型に加えて、マップデータに使用できる関数も提供されています。詳細については、[マップ関数](../../../400.functions-of-mysql-mode/980.map-functions-of-mysql-mode/100.map-functions-overview-of-mysql-mode.md)を参照してください。
