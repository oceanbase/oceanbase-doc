# ボールトとテキスト型の概要

OceanBaseデータベースは、大きなオブジェクトデータ型の`BLOB`とテキスト型の`TEXT`をサポートしています。

OceanBaseデータベースの現行バージョンがサポートするボールトとテキスト型および関連情報は、次の表に示されています。

|      タイプ      | 長さ |   ストレージ長の上限（バイト）   |    文字セット    |
|--------------|----|----------------|-----------|
| `TINYBLOB`   | 変長 | 255          | `BINARY`  |
| `BLOB`       | 変長 | 65535        | `BINARY`  |
| `MEDIUMBLOB` | 変長 | 16777215     | `BINARY`  |
| `LONGBLOB`   | 変長 | 536870910    | `BINARY`  |
| `TINYTEXT`   | 変長 | 256          | `UTF8MB4` |
| `TEXT`       | 変長 | 65535        | `UTF8MB4` |
| `MEDIUMTEXT` | 変長 | 16777215     | `UTF8MB4` |
| `LONGTEXT`   | 変長 | 536870910    | `UTF8MB4` |

ほとんどの場合、`BLOB`列は`VARBINARY`列と見なし、`TEXT`列は`VARCHAR`列と見なすことができます。`BLOB`と`TEXT`は、以下の点で`VARBINARY`と`VARCHAR`とは異なります。

* `BLOB`および`TEXT`列上のインデックスのプレフィックス長を指定する必要があります。`CHAR`および`VARCHAR`では、プレフィックス長はオプションです。

* `BLOB`および`TEXT`列には`DEFAULT`値を設定できません。
