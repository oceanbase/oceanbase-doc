# 文字列型の概要

OceanBaseデータベースがサポートする文字データ型は、`CHAR`、`VARCHAR`、`BINARY`、および `VARBINARY` です。

OceanBaseデータベースの現行バージョンでサポートされている一般的な文字列型とその関連情報は、以下の表に示されています。

|     タイプ      | 長さタイプ |   最大長   |    文字セット    |
|-------------|------|----------|-----------|
| `CHAR`      | 固定長   | 256文字   | `UTF8MB4` |
| `VARCHAR`   | 可変長   | 262144文字 | `UTF8MB4` |
| `BINARY`    | 固定長   | 256バイト   | `BINARY`  |
| `VARBINARY` | 可変長   | 1048576バイト | `BINARY`  |

`CHAR` および `VARCHAR` タイプでは、長さの単位は文字です。バイナリ文字列の `BINARY` および `VARBINARY` タイプでは、長さの単位はバイトです。
