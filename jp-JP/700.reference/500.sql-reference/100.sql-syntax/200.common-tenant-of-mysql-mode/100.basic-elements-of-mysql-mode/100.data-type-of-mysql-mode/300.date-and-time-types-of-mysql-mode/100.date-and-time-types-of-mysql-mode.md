# 日付時刻型の概要

OceanBaseデータベースは、時間値を表すための日付および時刻データ型をサポートしており、`DATE`、`TIME`、`DATETIME`、`TIMESTAMP`、`YEAR` が含まれます。各型には有効な値の範囲と「ゼロ」値があり、表現できない無効な値を指定することができます。

OceanBaseデータベースの現行バージョンでサポートされている日付および時刻型とその関連情報は、以下の表に示されています。

|     タイプ      |                フォーマット                |             下界             |             上界             |     意味      |
|-------------|----------------------------------|----------------------------|----------------------------|-------------|
| `DATETIME`  | YYYY-MM-DD HH:MM:SS\[.fraction\] | 0000-00-00 00:00:00.000000 | 9999-12-31 23:59:59.999999 | 日時（タイムゾーンを考慮しない） |
| `TIMESTAMP` | YYYY-MM-DD HH:MM:SS\[.fraction\] | 0000-00-00 00:00:00.000000 | 9999-12-31 23:59:59.999999 | 日時（タイムゾーンを考慮する）  |
| `DATE`      | YYYY-MM-DD                       | 0000-00-00                 | 9999-12-31                 | 日付          |
| `TIME`      | HH:MM:SS\[.fraction\]            | -838:59:59.000000          | 838:59:59.000000           | 時間          |
| `YEAR`      | YYYY                             | 1901                       | 2155                       | 年号          |

`DATETIME`、`TIMESTAMP`、`TIME` の値の範囲と精度はスケールによって異なります。スケール属性は小数部の最大有効桁数を表し、最大値は6、デフォルト値は0です。
