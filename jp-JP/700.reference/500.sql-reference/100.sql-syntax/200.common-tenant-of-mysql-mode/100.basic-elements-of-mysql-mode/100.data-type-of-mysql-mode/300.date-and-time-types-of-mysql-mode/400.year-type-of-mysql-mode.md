# YEAR型

`YEAR`型は、4桁の数字形式で年を表すために使用されます。

`YEAR`値の検索と表示形式は`YYYY`で、範囲は1901から2155、および0000です。

`YEAR`の構文は以下のとおりです：

```sql
YEAR[(4)]
```

OceanBaseデータベースでは、文字列または数字を使用して`YEAR`列に値を代入できます。

`YEAR`は以下の入力値形式をサポートします：

* '1901'から'2155'の範囲内の4文字列。

* 1901から2155の範囲内の4桁の数字

* '0'から'99'の範囲内の1文字または2文字の文字列。OceanBaseデータベースは、「0」から「69」と「70」から「99」の範囲の値をそれぞれ2000から2069および1970から1999の範囲の`YEAR`値に変換します。

* 0から99の範囲内の1桁または2桁の数字。OceanBaseデータベースは、1から69および70から99の範囲の値をそれぞれ2001から2069および1970から1999の範囲の`YEAR`値に変換します。

  数字0を挿入した場合、表示値は0000、内部値も0000になります。2000に変換したい場合は、文字列として"0"または"00"を指定します。

* `NOW()`など、`YEAR`型に変換可能な式。
