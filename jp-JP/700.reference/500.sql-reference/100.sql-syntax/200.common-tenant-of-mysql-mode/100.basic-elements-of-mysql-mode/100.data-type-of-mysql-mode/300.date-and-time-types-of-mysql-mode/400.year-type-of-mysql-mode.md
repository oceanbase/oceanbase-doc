# YEAR型

`YEAR`型は、4桁の数字形式で年を表すために使用されます。

`YEAR`値の検索および表示形式は`YYYY`であり、範囲は1901から2155、および0000です。

`YEAR`の構文は次のとおりです：

```sql
YEAR[(4)]
```

OceanBaseデータベースでは、文字列または数値を使用して`YEAR`列に値を割り当てることができます。

`YEAR`は、以下の入力値形式をサポートします：

* '1901'から'2155'の範囲内の4桁の文字列。

* 1901から2155の範囲内の4桁の数字

* '0'から'99'の範囲内の1桁または2桁の文字列。OceanBaseデータベースは、「0」から「69」と「70」から「99」の範囲内の値をそれぞれ2000から2069および1970から1999の範囲内の`YEAR`値に変換します。

* 0から99の範囲内の1桁または2桁の数字。OceanBaseデータベースは、1から69および70から99の範囲内の値をそれぞれ2001から2069および1970から1999の範囲内の`YEAR`値に変換します。

  数字0を挿入した結果の表示値は0000であり、内部値も0000です。2000に変換したい場合は、文字列として「0」または「00」を指定します。

* 返される値は`YEAR`型の式に変換できます。例えば、`NOW()`などです。
