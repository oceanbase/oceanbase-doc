# TIME型

`TIME`型は、1日の特定の時間を表すことができるほか、経過した時間や2つのイベント間の時間間隔（24時間を大幅に超える場合もあります）を表すこともできます。

OceanBaseデータベースでは、文字列または数値を使用して`TIME`列に値を割り当てることができます。

`TIME`値の検索および表示形式は`'hh:mm:ss'`で、範囲は`'-838:59:59'`から`'838:59:59'`です。

`TIME`値の表示形式には、秒の小数部を含む形式`'hh:mm:ss[.fraction]'`も使用でき、精度はマイクロ秒（6桁）まで可能です。範囲は`'-838:59:59.000000'`から`'838:59:59.000000'`です。小数部は常に他の時間部分と小数点で区切られる必要があり、他の区切り文字は認識されません。

`TIME`構文は以下のとおりです：

```sql
TIME[(fsp)]
```

オプションの`fsp`値は、小数部の秒の精度を指定するために使用され、範囲は\ [0,6\]です。0値は小数部分がないことを示します。省略された場合、デフォルトの精度は0です。
