# データ型の概要

この章では、OceanBaseデータベースの現在のバージョンでサポートされているMySQLデータ型とそのプロパティ、ストレージ要件などについて説明します。

OceanBaseデータベースの現在のバージョンでサポートされているMySQLデータ型は以下のとおりです：

* [数値型](200.numeric-of-mysql-mode/100.numeric-type-of-mysql-mode.md)

* [日付時刻型](300.date-and-time-types-of-mysql-mode/100.date-and-time-types-of-mysql-mode.md)

* [文字列型](400.string-of-mysql-mode/100.string-type-overview-of-mysql-mode.md)

* [BLOB型](500.large-object-of-mysql-mode/100.large-object-and-text-type-overview-of-mysql-mode.md)

* [テキスト型](500.large-object-of-mysql-mode/100.large-object-and-text-type-overview-of-mysql-mode.md)

* [列挙型](../100.data-type-of-mysql-mode/600.enum-type-of-mysql-mode.md)

* [集合型](../100.data-type-of-mysql-mode/700.set-type-of-mysql-mode.md)

* [JSONデータ型](800.json-formatted-data-type-of-mysql-mode/100.json-formatted-data-types-of-mysql-mode.md)

* [空間データ型](900.spatial-data-type-of-mysql-mode/100.spatial-data-type-overview-of-mysql-mode.md)

* [高効率圧縮ビットマップデータ型](1000.roaring-bitmap-data-type-of-mysql-mode/100.roaring-bitmap-data-type-overview-of-mysql-mode.md)

* [配列データ型](1200.array-data-type-of-mysql-mode/100.array-data-type-overview-of-mysql-mode.md)

* [マッピングデータ型](1300.map-data-type-of-mysql-mode/100.map-data-type-overview-of-mysql-mode.md)

OceanBaseデータベースでは、任意の2つ以上の任意のデータ型を比較することができます。比較結果は以下のいずれかになります：

* 非0 / `TRUE`

* 0 / `FALSE`

* `NULL`

比較に使用されるデータ型が一致しない場合、OceanBaseデータベースは関連するルールに基づいて比較用のデータ型を決定します。論理的には、比較に参加するすべてのデータは、比較操作を行う前にこのデータ型に変換する必要があります。比較対象がテキスト型の場合は、比較に使用する照合順序も決定する必要があります。

比較演算の変換ルールについては、[式評価における型変換](../200.expression-of-mysql-mode/300.type-conversion-of-expression-evaluation-of-mysql-mode.md)を参照してください。
