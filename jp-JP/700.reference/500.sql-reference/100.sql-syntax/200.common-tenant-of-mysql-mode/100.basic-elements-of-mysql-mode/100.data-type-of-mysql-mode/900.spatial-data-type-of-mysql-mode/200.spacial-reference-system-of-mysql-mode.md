# 空間参照系 (SRS)

空間データの空間参照系 (Spatial Reference System、SRS) は、座標に基づく地理的位置システムです。OceanBaseデータベースの現行バージョンでは、システムがデフォルトでサポートするSRSのみが利用可能です。

一般的なSRSには以下の種類があります：

* 投影SRS。投影SRSとは、地球を平面上に投影したものであり、つまり平面地図です。この平面上の座標系はデカルト座標系であり、経度や緯度ではなく長さ単位（メートル、フィートなど）を使用します。

* 地理SRS。地理SRSは非投影SRSであり、任意の角度単位で楕円体上の経緯度（または緯度-経度）座標を表します。

さらに、`SRID 0` を使用して表される無限に平坦なデカルト平面もあります。この平面の軸には単位が割り当てられていません。投影SRSとは異なり、これは抽象的な平面であり、地理的な参照を持たず、必ずしも地球を表すわけではありません。`SRID 0` は空間データのデフォルトの `SRID` です。

SRSの内容は、次の例のように `INFORMATION_SCHEMA ST_SPATIAL_REFERENCE_SYSTEMS` テーブルから取得できます：

```sql
obclient> SELECT *  FROM INFORMATION_SCHEMA.ST_SPATIAL_REFERENCE_SYSTEMS
     WHERE SRS_ID = 4326\G
*************************** 1. row ***************************
                SRS_NAME: WGS 84
                  SRS_ID: 4326
            ORGANIZATION: EPSG
ORGANIZATION_COORDSYS_ID: 4326
              DEFINITION: GEOGCS["WGS 84",DATUM["World Geodetic System 1984",SPHEROID["WGS 84",6378137,298.257223563,AUTHORITY["EPSG","7030"]],AUTHORITY["EPSG","6326"]],PRIMEM["Greenwich",0,AUTHORITY["EPSG","8901"]],UNIT["degree",0.017453292519943278,AUTHORITY["EPSG","9122"]],AXIS["Lat",NORTH],AXIS["Lon",EAST],AUTHORITY["EPSG","4326"]]
             DESCRIPTION: NULL
1 row in set
```

上記の例は、GPSシステム用のSRSを説明しており、その名前 (SRS_NAME) はWGS 84、ID (SRS_ID) は4326です。

`DEFINITION` 列のSRS定義は `WKT` 値です。WKTはEBNF（Extended Backus Naur Form）に基づいて定義されています。WKTはデータ形式（本記事ではWKT-Dataと呼ばれる）として使用できるほか、GISにおいてSRSの定義にも使用されます。

`SRS_ID` 値は、幾何値の `SRID` と同じタイプの値を表すか、あるいは空間関数に `SRID` パラメータとして渡されます。`SRID 0`（単位のないデカルト平面）は特殊で合法的な空間参照系IDであり、`SRID` 値に依存するすべての空間データ計算で使用できます。

複数の幾何値に対する計算では、すべての値が同一のSRIDを持っていなければならず、そうでない場合はエラーが発生します。
