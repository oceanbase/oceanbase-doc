# 空間データ型の概要

OceanBaseデータベースの地理情報システム(Geographic Information System、GIS)機能は、以下の空間データ型をサポートしています：

* `GEOMETRY`

* `POINT`

* `LINESTRING`

* `POLYGON`

* `MULTIPOINT`

* `MULTILINESTRING`

* `MULTIPOLYGON`

* `GEOMETRYCOLLECTION`

その中で `POINT`、`LINESTRING`、`POLYGON` は最も基本的な3つの型であり、単一の空間データを格納するために使用されます。これらはそれぞれ `MULTIPOINT`、`MULTILINESTRING`、`MULTIPOLYGON` の3つの集合型を拡張し、空間データの集合を格納するために使用されますが、指定された基本型の集合しか表現できません。`GEOMETRY` は仮想型であり、任意の基本型を表すことができ、`GEOMETRYCOLLECTION` は任意の `GEOMETRY` 型の集合です。
