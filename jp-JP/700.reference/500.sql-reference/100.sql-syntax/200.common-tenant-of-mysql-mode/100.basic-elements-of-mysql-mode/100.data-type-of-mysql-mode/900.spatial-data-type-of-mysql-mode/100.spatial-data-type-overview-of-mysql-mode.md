# 空間データ型の概要

OceanBaseデータベースの地理情報システム(GIS)機能には、以下の空間データ型が含まれます：

* `GEOMETRY`

* `POINT`

* `LINESTRING`

* `POLYGON`

* `MULTIPOINT`

* `MULTILINESTRING`

* `MULTIPOLYGON`

* `GEOMETRYCOLLECTION`

その中で、`POINT`、`LINESTRING`、`POLYGON` の3つは最も基本的なタイプであり、単一の空間データを格納するために使用されます。また、それぞれが `MULTIPOINT`、`MULTILINESTRING`、`MULTIPOLYGON` の3つの集合タイプを拡張し、空間データの集合を格納するために使用されますが、指定された基本タイプの集合しか表現できません。`GEOMETRY` は仮想タイプであり、任意の基本タイプを表すことができ、`GEOMETRYCOLLECTION` は任意の `GEOMETRY` タイプの集合である可能性があります。
