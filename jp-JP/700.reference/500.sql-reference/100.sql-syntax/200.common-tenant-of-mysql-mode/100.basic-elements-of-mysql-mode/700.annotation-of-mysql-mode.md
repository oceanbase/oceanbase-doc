# コメント

SQLステートメントとデータベースオブジェクトのコメント方法は異なります。

## SQLステートメントのコメント

通常のSQLステートメントについて、OceanBaseデータベースは以下の3種類のコメント方法をサポートしています：

* `#` から行末までを記述することで、1行をコメントできます。

* `--` から行末までを記述することで、1行をコメントできます。

* `/*` から `*/` までを記述することで、複数行をコメントできます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>SQLステートメントではネストされたコメントはサポートされていません。</p>
  </main>

特に、OceanBaseデータベースは `/*！*/` 内のステートメントをSQLとして処理し、コメント内のステートメントを実行することをサポートしています。`/*！*/` 内に構文エラーが発生した場合、データベースはデフォルトでコメントとして扱います。

コメントの書式は次のとおりです：

```sql
/*![バージョン番号を表す連続する数字文字] <スペース> <任意のSQLステートメント >*/
```

* 例1：テーブル `t1` にHashパーティションを作成し、パーティション数を `8` に設定します。

  ```sql
  obclient> CREATE TABLE t1 (c1 INT PRIMARY KEY, c2 INT) /*!50100
      PARTITION BY HASH(c1) PARTITIONS 8*/;
  Query OK, 0 rows affected
  ```

* 例2：`ENABLE KEYS` を使用して非一意インデックスを更新します。一括挿入時には、`DISABLE KEYS` を使用して最初は更新せず、すべてのインデックスの挿入が完了した後にインデックスを更新します。

  ```sql
  obclient> /*!ALTER TABLE t1 DISABLE KEYS */;
  Query OK, 0 rows affected

  obclient> /*!ALTER TABLE t1 ENABLE KEYS */;
  Query OK, 0 rows affected
  ```

* 例3：PLの `DROP IF EXISTS` 構文の実行をサポートします。

  ```sql
  obclient> /*!50003 DROP PROCEDURE IF EXISTS */;
  Query OK, 0 rows affected
  ```

## データベースオブジェクトのコメント

DDLステートメント内で `COMMENT` 句を使用して、データベースオブジェクトにコメントを指定できます。例：

```sql
obclient> CREATE TABLE tbl1(pk INT PRIMARY KEY COMMENT '主キー');
Query OK, 0 rows affected
```
