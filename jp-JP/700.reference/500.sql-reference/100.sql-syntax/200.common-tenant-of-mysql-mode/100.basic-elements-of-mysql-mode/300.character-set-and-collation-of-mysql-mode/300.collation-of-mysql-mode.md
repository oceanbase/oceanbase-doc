照合順序には、一般的に以下の特徴があります：

* 2つの異なる文字セットが同じ照合順序を持つことはできません。

* 各文字セットにはデフォルトの照合順序があります。<code>SHOW CHARACTER SET</code>ステートメントは各文字セットのデフォルトの照合順序を示します。<code>SHOW COLLATION</code>ステートメントには、各照合順序がその文字セットのデフォルト値であるかどうかを示す列があります(そうであればYes、そうでなければ空欄)。

* 照合順序名は、それらに関連付けられた文字セットの名前で始まり、通常は他の照合順序の特徴を示す1つ以上の接尾辞が続きます。
