# 文字列テキスト

文字列テキストとは、シングルクォート（'）またはダブルクォート（"）で囲まれた文字の連続です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>ANSI_QUOTES</code> モードが有効になっている場合、文字列を引用するにはシングルクォート <code>'</code> のみを使用できます。設定とクエリステートメントは次のとおりです：</p>
  </main>

```sql
obclient> SET sql_mode = 'ANSI_QUOTES';
obclient> SELECT @@sql_mode;
```

文字列テキストには、以下の2種類があります：

* バイナリ文字列。単位はバイトであり、比較時にはバイトを使用します。文字セットと照合順序は `binary` です。

* バイナリ以外の文字列。単位は文字であり、比較時には文字を使用します（一部の文字セットではマルチバイト文字をサポートしています）。これは `binary` 以外のさまざまな文字セットと、その文字セットと互換性のある照合順序を持っています。

文字列テキストに対して、次の `COLLATE` 句を使用して文字セットと照合順序を指定します：

```sql
[_charset_name]'string' [COLLATE collation_name]
```

文字列内で、エスケープ文字とは、特定のシーケンスの前にスラッシュ `\` を追加して構成され、特殊な意味を表すために使用されます。エスケープ文字は大文字と小文字を区別します。例えば、`\b` はバックスペースを表し、`\B` は `B` を表します。

以下はすべてのエスケープシンボルのリストです：

| エスケープシンボル | 意味 |
|------|-------------------------------------|
| `\b` | バックスペース |
| `\f` | フォームフィールドの改行 |
| `\n` | 行末 |
| `\r` | キャリッジリターン |
| `\t` | タブ文字 |
| `\\` | 反斜線文字 |
| `\'` | 単一引用符 |
| `\"` | 双重引用符 |
| `_` | アンダースコア |
| `%` | パーセント記号 |
| `\0` | NULL |
| `\Z` | ASCII 26 コントロール文字 Ctrl+Z |
