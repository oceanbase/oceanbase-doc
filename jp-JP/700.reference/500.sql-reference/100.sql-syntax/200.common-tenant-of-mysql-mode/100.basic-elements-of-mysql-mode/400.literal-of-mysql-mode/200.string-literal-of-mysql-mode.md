# 文字列リテラル

文字列リテラルは、シングルクォート `'` またはダブルクォート `"` で囲まれた文字の連なりです。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>ANSI_QUOTES</code> モードを有効にすると、文字列を引用する際にシングルクォート <code>'</code> のみを使用できます。設定とクエリステートメントは以下のとおりです：</p>
  </main>

```sql
obclient> SET sql_mode = 'ANSI_QUOTES';
obclient> SELECT @@sql_mode;
```

文字列リテラルには、以下の2種類があります：

* バイナリ文字列。単位はバイトで、比較時もバイト単位です。文字セットと照合順序は `binary` です。

* 非バイナリ文字列。単位は文字で、比較時も文字単位です（一部の文字セットはマルチバイト文字をサポートします）。`binary` 以外のさまざまな文字セットと、それらの文字セットと互換性のある照合順序を持ちます。

以下の `COLLATE` 句を使用して、文字列リテラルに文字セットと照合順序を指定します：

```sql
[_charset_name]'string' [COLLATE collation_name]
```

文字列では、エスケープシーケンスは特定のシーケンスの前にバックスラッシュ `\` を付加して構成され、特殊な意味を表します。エスケープシーケンスは大文字と小文字を区別します。例えば、`\b` はバックスペースを表しますが、`\B` は `B` を表します。

以下はすべてのエスケープシーケンスのリストです：

| エスケープシーケンス  |                 意味                  |
|------|-------------------------------------|
| `\b` | バックスペース文字                                 |
| `\f` | 改ページ文字                                 |
| `\n` | 改行文字                                 |
| `\r` | キャリッジリターン文字                                 |
| `\t` | Tab文字                              |
| `\\` | バックスラッシュ文字                               |
| `\'` | シングルクォート文字                                 |
| `\"` | ダブルクォート文字                                 |
| `\_` | アンダースコア文字                                 |
| `\%` | パーセント記号                                 |
| `\0` | NULL                                |
| `\Z` | ASCII 26 コントロール文字 Ctrl+Z |
