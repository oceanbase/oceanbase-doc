# NULL値

`NULL` 値は「データなし」を表します。

`NULL` は大文字小文字を区別しません。同義語は `\N`（大文字小文字を区別する）です。`NULL` 値は、数値の0や空文字列 `''` とは異なることに注意してください。

`ORDER BY` を使用してソートする場合、昇順ソートでは `NULL` 値は他の値より前に来ます。降順ソートでは、`NULL` 値は他の値より後に来ます。

`LOAD DATA` または `SELECT ... INTO OUTFILE` では、\N を使用して NULL を表すことができます。

**例：**

```sql
obclient [test]> SELECT 1, NULL, \N FROM dual;
```

結果は次のとおりです：

```shell
+------+------+------+
| 1    | NULL | NULL |
+------+------+------+
|    1 | NULL | NULL |
+------+------+------+
1 row in set
```
