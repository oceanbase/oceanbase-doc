# ブール値

ブール値には、定数 `TRUE` と `FALSE` が含まれます。

定数 `TRUE` と `FALSE` の計算結果はそれぞれ1と0です。定数名には任意の文字を使用でき、大文字と小文字は区別されません。

```sql
obclient> SELECT TRUE, true, FALSE, false;
+------+------+-------+-------+
| TRUE | true | FALSE | false |
+------+------+-------+-------+
|    1 |    1 |     0 |     0 |
+------+------+-------+-------+
1 row in set
```
