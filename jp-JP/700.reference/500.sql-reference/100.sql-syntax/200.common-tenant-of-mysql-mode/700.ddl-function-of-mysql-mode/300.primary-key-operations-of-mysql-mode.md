# 主キーの操作

本記事では、OceanBaseデータベースのMySQLモードにおける簡単な主キー操作について説明します。主キーの追加、変更、削除を含みます。

## 主キーの追加

主キーを追加する構文は次のとおりです：

```sql
ALTER TABLE table_name ADD PRIMARY KEY (column_name);
```

ここで、`table_name` は主キーを追加する対象のテーブル名を指定します。`column_name` は主キーが存在する列を指定します。詳細については [ALTER TABLE](../600.sql-statement-of-mysql-mode/1600.alter-table-of-mysql-mode.md) を参照してください。

ここでは、データベースにテーブル tbl1 が既に存在することを前提とします。tbl1 テーブルに主キーインデックスを追加し、そのインデックスを c1 列に適用する例を以下に示します：

```shell
obclient> ALTER TABLE tbl1 ADD PRIMARY KEY(c1);
```

## 主キーの変更

主キーを変更する構文は次のとおりです：

```sql
ALTER TABLE table_name DROP PRIMARY KEY, ADD PRIMARY KEY (column_name);
```

ここで、`table_name` は主キーを変更する対象のテーブル名を指定します。`column_name` は変更後の主キーが存在する列を指定します。詳細については [ALTER TABLE](../600.sql-statement-of-mysql-mode/1600.alter-table-of-mysql-mode.md) を参照してください。

ここでは、データベースにテーブル tbl1 が既に存在し、tbl1 テーブルに主キーが存在することを前提とします。tbl1 テーブルの主キーを変更し、それを c2 列に適用する例を以下に示します：

```shell
obclient> ALTER TABLE tbl1 DROP PRIMARY KEY, ADD PRIMARY KEY(c2);
```

## 主キーの削除

主キーを削除する構文は次のとおりです：

```sql
ALTER TABLE table_name DROP PRIMARY KEY;
```

ここで、`table_name` は主キーを削除する対象のテーブル名を指定します。詳細については [ALTER TABLE](../600.sql-statement-of-mysql-mode/1600.alter-table-of-mysql-mode.md) を参照してください。

ここでは、データベースにテーブル tbl1 が存在し、tbl1 テーブルに主キーが存在することを前提とします。tbl1 テーブルの主キーを削除する例を以下に示します：

```shell
obclient> ALTER TABLE tbl1 DROP PRIMARY KEY;
```
