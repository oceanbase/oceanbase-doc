# DDL機能の概要

OceanBaseデータベースのDDL機能は、データベースオブジェクトの変更に使用されます。

OceanBaseデータベースのMySQLモードでサポートされているDDL機能は以下のとおりです：

* インデックス操作
* 主キー操作
* 列操作
* 生成列操作
* 外部キー操作
* テーブル操作
* パーティション操作
