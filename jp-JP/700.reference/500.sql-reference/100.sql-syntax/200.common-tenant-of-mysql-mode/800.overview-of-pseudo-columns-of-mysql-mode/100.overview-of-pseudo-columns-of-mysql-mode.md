# 疑似列の概要

疑似列（Pseudocolumn）は、テーブル内の列と同じように動作しますが、具体的な値は格納されません。そのため、疑似列には読み取り専用の属性しかなく、挿入、更新、削除などの操作はできません。この章では、OceanBaseデータベースの現在のバージョンでサポートされている疑似列とその使用方法について説明します。

OceanBaseデータベースのMySQLモードの現在のバージョンでは、以下の疑似列タイプをサポートしています：

* [PARTITIONID疑似列](200.partititionid-pseudo-column-of-mysql-mode.md)
* [シーケンス疑似列](300.sequence-pseudo-column-of-mysql-mode.md)
