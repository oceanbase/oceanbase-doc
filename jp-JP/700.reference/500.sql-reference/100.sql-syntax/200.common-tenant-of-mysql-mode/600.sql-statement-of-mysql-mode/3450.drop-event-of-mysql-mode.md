# DROP EVENT

このステートメントは、イベントを削除するために使用されます。

## 構文

```sql
DROP EVENT [IF EXISTS] event_name
```

## パラメータの説明

| パラメータ | 説明 |
|-------|-----------|
|event_name|削除するイベントの名前を指定します。|

## 例

```shell
obclient> DROP EVENT myevent;
```
