# GRANT

## 説明

このステートメントは、指定されたユーザーまたはロールに対して権限を付与するか、ロールをユーザーまたは別のロールに付与するために使用します。

## 使用制限と注意事項

`GRANT` 操作の連鎖はサポートされていません。例えば、ロールAがロールBに権限を付与し、ロールBがロールCに権限を付与した後、ロールCがロールAに権限を付与しようとするとエラーが発生します。

## 権限要件

### オブジェクト権限をユーザー権限に付与する要件

* `GRANT` ステートメントを実行する際、現在のユーザーは付与される権限を持っていなければなりません。例えば、ユーザー `user1` がユーザー `user2` にテーブル `tbl1` の `SELECT` 権限を付与する場合、ユーザー `user1` はテーブル `tbl1` の `SELECT` 権限を持っている必要があります。

* `GRANT` ステートメントを実行する際、現在のユーザーは `GRANT OPTION` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>ユーザーに権限を付与した後、そのユーザーはOceanBaseデータベースに再接続する必要があり、権限が有効になります。</p>
</main>

### ロールをユーザーまたは別のロールに付与する要件

* 現在のユーザーが `SUPER` 権限を持っている場合、すべてのロールを `GRANT` できます。
* ロールを他のユーザーまたはロールに付与する場合、現在のユーザーは付与するロールを所有している必要があり、`ADMIN OPTION` 権限も持っている必要があります。現在のユーザーが持つ権限を確認する操作については、[ユーザー権限の確認](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。

## 構文

### オブジェクト権限をユーザーまたはロールに付与する

```sql
GRANT priv_type[(column_name_list)] [, priv_type[(column_name_list)] ...]
    ON [object_type] priv_level
    TO {user [, user...]}
    [WITH GRANT OPTION];

priv_type:
    READ
    | WRITE

column_name_list:
    column_name [, column_name ...]

object_type:
    TABLE
    | FUNCTION
    | PROCEDURE
    | CATALOG
    | LOCATION

user:
    user_or_role
    | user_name IDENTIFIED [WITH auth_plugin] BY password
    | user_name IDENTIFIED [WITH auth_plugin] BY PASSWORD password

user_or_role:
    user_name | role_name
```

### ロールをユーザーまたは別のロールに付与する

```sql
GRANT role_name [, role_name ...]
    TO user_or_role [, user_or_role ...]
    [WITH ADMIN OPTION];

user_or_role:
    user_name | role_name
```

## パラメータの説明

|                 **パラメータ**   |          **説明**        |
|----------------------------------------|--------------------------------------|
| priv_type                              | 付与する権限タイプを指定します。複数の権限を付与することができ、複数の権限は半角カンマ（`,`）で区切ります。具体的な権限タイプとその説明については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。注意：PROXYパラメータは現在のバージョンでは構文のみ記録されており、機能は有効ではありません。|
| column_name_list | オプションです。列レベルの権限を付与する列のリストを指定します。付与される権限は、リストアップされた列にのみ適用されます。指定しない場合、権限はテーブル全体またはオブジェクト全体に適用されます。詳細については、[直接権限の付与](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。|
| object_type                            | オプションです。権限が適用されるオブジェクトタイプ（つまり、権限の対象タイプ）を示します。詳細については、以下の [object_type](#object_type) を参照してください。|
| priv_level                             | 権限を付与するレベルを指定します。形式は以下のとおりです：<ul><li>すべてのデータベースとすべてのテーブルに適用する場合（`*.*`）を指定できます。</li><li>特定のデータベースまたは特定のテーブルに適用する場合（`db_name.*`、`*.table_name`）</li><li>特定のデータベース内の特定のテーブルに適用する場合（`db_name.table_name`）</li><li>権限の対象タイプがCatalogの場合、外部データカタログの名前（`external_catalog_name`）を指定する必要があります。</li></ul>|
| user | 権限を付与するユーザーを指定します。1人または複数のユーザーを指定でき、複数のユーザーは半角カンマ（`,`）で区切ります。ユーザーが存在しない場合、このステートメントはそのユーザーを直接作成します。  |
| auth_plugin | ユーザー認証方式を指定するために使用します。現在、`mysql_native_password` と `caching_sha2_password` 認証プラグインをサポートしています。<main id="notice" type='notice'><h4>注意</h4><p><code>caching_sha2_password</code> のサポートはV4.4.2 BP2から開始されました。</p></main> |
| BY password | 権限を付与されるユーザーにパスワードを指定します。ここでのパスワードは平文で、`mysql.user` テーブルに格納された後、サーバー側で暗号化されます。パスワードに特殊文字 <code>~!@#%^&*_-+=`\|(){}[]:;',.?/</code> が含まれる場合は、半角引用符（<code>''</code> または <code>""</code>）で囲む必要があります。 |
| BY PASSWORD password | 権限を付与されるユーザーにパスワードを指定します。ここでのパスワードは暗号文で、直接 `mysql.user` テーブルに格納されます。 |
| WITH GRANT OPTION  | 権限の再付与を許可するかどうかを指定します。権限剥奪時の連鎖を防ぎます。 |
| role_name          | ロールの名前を指定します。|
| WITH ADMIN OPTION  | 指定したロール権限の再付与を許可するかどうかを指定します。権限を取り消す際には、カスケードされません。|

### object_type

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>object_type</code> 句を使用する場合、指定したオブジェクトが対応するタイプであることを確認する必要があります。そうでない場合、構文エラーが発生します。</p>
</main>

* `TABLE`：権限の適用対象がテーブルであることを示します。
* `FUNCTION`：権限の適用対象が関数であることを示します。
* `PROCEDURE`：権限の適用対象がストアドプロシージャであることを示します。
* `CATALOG`：権限の適用対象がCatalogであることを示します。
* `LOCATION`：権限の適用対象がLocationであることを示します。ユーザーにLocationオブジェクトに対する権限を付与できるものは以下のとおりです：

  * `READ`：Locationオブジェクトの読み取り権限を示します。
  * `WRITE`：Locationオブジェクトの書き込み権限を示します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースV4.4.x系では、<code>GRANT</code> ステートメントはV4.4.1バージョンから <code>LOCATION</code> パラメータおよび対応する <code>READ</code> と <code>WRITE</code> 権限をサポートしています。</p>
  </main>

**例：**

* `user001` に `test` データベース内のすべてのオブジェクトに対する `SELECT` 権限を付与します。指定したオブジェクトが指定されたタイプではないため、エラーが発生します。

  ```sql
  GRANT SELECT ON TABLE test.* TO user001;
  ```

  実行結果は次のとおりです：

  ```shell
  ERROR 1144 (42000): Illegal GRANT/REVOKE command; please consult the manual to see which privileges can be used
  ```

* `user001` に `test` データベース内のテーブル `tbl1` に対する `SELECT` 権限を付与します。

  ```sql
  GRANT SELECT ON TABLE test.tbl1 TO user001;
  ```

* `user002` に `test` データベース内の関数 `calculate_salary` の実行権限を付与します。

  ```sql
  GRANT EXECUTE ON FUNCTION test.calculate_salary TO user002;
  ```

* `user003` に `test` データベース内のストアドプロシージャ `pro_generate_data` の実行権限を付与します。

  ```sql
  GRANT EXECUTE ON PROCEDURE test.pro_generate_data TO user003;
  ```

* `user004` に Catalogオブジェクト `test_odps_catalog` に対する `SELECT` および `USE CATALOG` 権限を付与します。

  ```sql
  GRANT SELECT, USE CATALOG ON CATALOG test_odps_catalog TO user004 WITH GRANT OPTION;
  ```

* `user005` に Locationオブジェクト `test_location_local` の読み取り権限を付与します。

  ```sql
  GRANT READ ON LOCATION test_location_local TO user005 WITH GRANT OPTION;
  ```

## 例

### 例1：オブジェクトに権限を付与する

* 既存のユーザー `user1` にデータベース `db1` の `CREATE VIEW` 権限を付与し、他のユーザーへの同権限の再付与を許可します。

  ```sql
  GRANT CREATE VIEW ON db1.* TO user1 WITH GRANT OPTION;
  ```

* 既存のユーザー `user1` にデータベース `db1` の `CREATE` 権限を付与し、`user1` のパスワードを変更します。

  ```sql
  GRANT CREATE ON db1.* TO user1 IDENTIFIED by '********';
  ```

  実行後に `mysql.user` テーブルで `user1` ユーザーのパスワードを確認すると、最新に設定したパスワードに更新されていることが確認できます。

* 不存在のユーザー `user2` にデータベース `db1` の `CREATE` 権限を付与し、`user2` にパスワードを設定します。

  ```sql
  GRANT CREATE ON db1.* TO user2 IDENTIFIED by '********';
  ```

* 既存のユーザー `user001` にデータベース `test` 内のテーブル `tbl1` の列 `col1` に対する `SELECT` 権限を付与します。

  ```sql
  GRANT SELECT(col1) ON test.tbl1 TO user001;
  ```

* ユーザー `user005` にグローバルレベルの `CREATE CATALOG` および `USE CATALOG` 権限を付与します。

  ```sql
  GRANT CREATE CATALOG, USE CATALOG ON *.* TO user004 WITH GRANT OPTION;
  ```

### 例2：ロールをユーザーまたは別のロールに付与する

* ロール `role001` の権限をロール `role002` に付与し、再付与を許可します。

  ```sql
  GRANT role001 TO role002 WITH ADMIN OPTION;
  ```

* ロール `role001` の権限をユーザー `user001` に付与し、再付与を許可します。

  ```sql
  GRANT role001 TO user001 WITH ADMIN OPTION;
  ```
