# STORAGE_CACHE_POLICY_EXECUTOR

## 説明

共有ストレージモードでは、このステートメントはホットデータキャッシュタスクを手動で1回トリガーするために使用されます。

## 構文

```sql
ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```

## パラメータの説明

|          **パラメータ**           |      **説明**      |
|---------------------------|------------------|
|TRIGGER|ホットデータキャッシュタスクの実行を手動で即座に1回トリガーします。|

## 例

以下のコマンドを実行すると、ホットキャッシュタスクが即座に1回トリガーされます。

```shell
obclient> ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```
