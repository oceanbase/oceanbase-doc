# REVOKE

## 概要

このステートメントは、ユーザーまたはロールに以前に付与された権限を取り消すために使用されます。また、ユーザーまたはロール内のロールも取り消すことができます。

## 制限事項と注意点

* `ALL PRIVILEGES` および `GRANT OPTION` 権限を取り消すには、現在のユーザーがグローバル `GRANT OPTION` 権限を持っているか、権限テーブルに対する `UPDATE` および `DELETE` 権限を持っている必要があります。
* 権限の取り消し操作は連鎖しません。例えば、ユーザー `user1` が `user2` に特定の権限を付与した場合、`user1` の権限を取り消しても同時に `user2` の対応する権限は取り消されません。
* `REVOKE` ステートメントの実行は、現在ログインしているユーザーに即座に反映されます。
* システム変数 `mandatory_roles` 内のロールは取り消すことができません。

## 権限要件

### ユーザーまたはロール内のオブジェクト権限を取り消す権限要件

ユーザーは取り消される権限（例えば、`user1` が `user2` に対し、テーブル `t1` に対する `SELECT` 権限を取り消す場合、`user1` はテーブル `t1` に対する `SELECT` 権限を持っている必要があります）を持ち、さらに `GRANT OPTION` 権限も必要です。

### ユーザーまたはロール内のロール権限要件

ロールを取り消すには、現在のユーザーが取り消されるロールを持っていること、および `ADMIN OPTION` 権限を持っていることが必要です。

## 構文

### ユーザーまたはロールのオブジェクト権限を取り消す

```sql
REVOKE priv_type[(column_name_list)] [, priv_type[(column_name_list)] ...]
     ON database.table_name
     FROM 'user_or_role';

priv_type:
      ALTER
    | CREATE
    | CREATE USER
    | CREATE VIEW
    | DELETE
    | DROP
    | GRANT OPTION
    | INDEX
    | INSERT
    | PROCESS
    | SELECT
    | SHOW DATABASES
    | SHOW VIEW
    | SUPER
    | UPDATE
    | USAGE

column_name_list:
    column_name [, column_name ...]

user_or_role:
    user_name | role_name
```

### ユーザーまたはロール内のロールを取り消す

```sql
REVOKE [IF EXISTS] role_name [, role_name ...]
    FROM user_or_role [, user_or_role ...]
    [IGNORE UNKNOWN USER];

user_or_role:
    user_name | role_name
```

## パラメータの説明

|       **パラメータ**        |                                          **説明**                                           |
|---------------------|-------------------------------------------------------------------------------------------|
| priv_type           | 撤回する権限タイプを指定します。具体的な権限タイプとその説明については、以下の権限タイプの説明表を参照してください。同時に特定のユーザーから複数の権限を撤回する場合、権限タイプは","で区切ります。注意：PROXY パラメータは現在のバージョンではこのキーワード構文のみが記録され、機能は有効になりません。             |
| column_name_list    | オプションです。テーブル内のカラムレベル権限のリストを撤回します。指定しない場合は、テーブル全体またはオブジェクトの権限をすべて撤回します。|
| database.table_name | データベース内のテーブルを指定します。`database` または `table_name` を "*" に置き換えると、グローバル権限を撤回することになります。つまり、データベース内のすべてのテーブルに対する操作権限を撤回します。 |
| user_name           | 権限を撤回するユーザーを指定します。同時に複数のユーザーの権限を撤回する場合、ユーザー名は","で区切ります。                                                         |
| IF EXISTS \| IGNORE UNKNOWN USER | オプションです。指定されたロールまたは権限者が存在しない場合、`IF EXISTS` および `IGNORE UNKNOWN USER` オプションを使用した場合は、システムが警告メッセージを発行し、エラー メッセージではなく警告メッセージを出力します。|
| role_name           | ロールの名前を指定します。|
| proxy  | 現在のバージョンではこのキーワード構文のみが記録され、機能は有効になりません。|

取り消し可能な権限タイプは以下の表のとおりです。

|      **権限**       |                                 **説明**                                 |
|-------------------|------------------------------------------------------------------------|
| ALL PRIVILEGES    | `GRANT OPTION` を除くすべての権限。                                               |
| ALTER             | `ALTER TABLE` の権限。                                                     |
| CREATE            | `CREATE TABLE` の権限。                                                    |
| CREATE USER       | `CREATE USER`、`DROP USER`、`RENAME USER`、および `REVOKE ALL PRIVILEGES` の権限。 |
| CREATE TABLEGROUP | グローバル `CREATE TABLEGROUP` の権限。                                            |
| DELETE            | `DELETE` の権限。                                                          |
| DROP              | `DROP` の権限。                                                            |
| GRANT OPTION      | `GRANT OPTION` の権限。                                                    |
| INSERT            | `INSERT` の権限。                                                          |
| SELECT            | `SELECT` の権限。                                                          |
| UPDATE            | `UPDATE` の権限。                                                          |
| SUPER             | `SET GLOBAL` でグローバルシステムパラメータを変更する権限。                                              |
| SHOW DATABASES    | グローバル `SHOW DATABASES` の権限。                                               |
| INDEX             | `CREATE INDEX` と `DROP INDEX` の権限。                                     |
| CREATE VIEW       | `CREATE VIEW` と `DROP VIEW` の権限。                                       |
| SHOW VIEW         | `SHOW CREATE VIEW` 権限。                                                 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>現在、Change Effective Tenant の権限制御はありません。そのため、sysテナント内のユーザーはすべて権限を取り消すことができます。</p>
  </main>

## 例

### 例1：オブジェクト権限を回収する

`u1` ユーザーの `SELECT` 権限を回収し、`ALL PRIVILEGES` で付与された権限を確認します。

```sql
obclient> GRANT ALL PRIVILEGES ON *.* TO u1;
Query OK, 0 rows affected

obclient> SHOW GRANTS FOR u1;
+-------------------------------------+
| Grants for u1@%                     |
+-------------------------------------+
| GRANT ALL PRIVILEGES ON *.* TO 'u1' |
+-------------------------------------+
1 row in set

obclient> REVOKE SELECT ON *.* FROM u1;
Query OK, 0 rows affected

obclient> SHOW GRANTS FOR u1;
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Grants for u1@%
                        |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| GRANT ALTER, CREATE, CREATE USER, DELETE, DROP, INSERT, UPDATE, INDEX, CREATE VIEW, SHOW VIEW, SHOW DB, SUPER, PROCESS, FILE, ALTER TENANT, ALTER SYSTEM, CREATE RESOURCE POOL, CREATE RESOURCE UNIT ON *.* TO 'u1' |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```

### 例2：ユーザーまたはロール内のロールを回収する

* ロール `role002` 内のロール `role001` を回収します。

  ```sql
  obclient [test]> REVOKE role001 FROM role002;
  ```

* ユーザー `user001` 内のロール `role001` を回収します。

  ```sql
  obclient [test]> REVOKE role001 FROM user001;
  ```
