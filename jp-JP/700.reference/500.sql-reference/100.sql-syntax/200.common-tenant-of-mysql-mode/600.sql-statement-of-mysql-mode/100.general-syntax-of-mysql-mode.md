# 汎用構文

このセクションでは、SQLステートメントの汎用構文について説明します。これには、定数、文字セット、データ型、SQLプロパティ、分散プロパティ、ストレージプロパティが含まれます。

## 定数

* `INT_VALUE`：整数型定数に一致します。例：`123`。

* `DECIMAL_VALUE`：固定小数点型定数に一致します。例：`123.456`。

* `STR_VALUE`：文字列定数に一致します。例：`abc`。

* `NULL`：`NULL` 定数に一致します。

* `STORAGE_SIZE`：ストレージ長定数に一致します。整数形式のデフォルト単位はバイトですが、文字列形式では M または G を指定できます。例：`1024` または `'500M'`。

```sql
const_value:
      INT_VALUE
    | DECIMAL_VALUE
    | STR_VALUE
    | NULL
    | STORAGE_SIZE

STORAGE_SIZE:
      INT_VALUE
    | 'INT_VALUE[M|G]'
```

## 文字セット

```sql
charset:
      default_charset
    | column_charset

default_charset:
    [DEFAULT] {CHARSET | CHARACTER SET} [=] charset_name

column_charset:
    {CHARSET | CHARACTER SET} charset_name

charset_name:
    STR_VALUE
```

`charset_name` は任意の有効な文字セット名を指定できます。詳細な文字セット情報については、[MySQLとの互換性比較](../../../../../100.learn-more-about-oceanbase/500.compatibility-with-mysql.md)を参照してください。

## 照合順序

```sql
collate:
      default_collate
    | column_collate

default_collate:
    [DEFAULT] COLLATE [=] collation_name

column_collate:
    COLLATE collation_name

collation_name:
    STR_VALUE
```

`collation_name` は任意の有効な照合順序名を指定できます。詳細な照合順序情報については、[MySQLとの互換性比較](../../../../../100.learn-more-about-oceanbase/500.compatibility-with-mysql.md)を参照してください。

## SQLプロパティ

* オブジェクト名

  ```sql
  tenant_name | pool_name | unit_name | zone_name | region_name:
      STR_VALUE

  database_name | table_name | table_alias_name | column_name| column_alias_name  | partition_name | subpartition_name:
      STR_VALUE

  index_name | view_name | object_name | constraint_name | tablegroup_name:
      STR_VALUE

  outline_name | user_name:
      STR_VALUE

  table_factor:
      [[database_name].] table_name

  column_factor:
      [table_factor.] column_name
  ```

* 式

  ```sql
  expression:
        const_value
      | column_factor
      | operator_expression
      | function_expression
  ```

* コメント

  ```sql
  comment:
      COMMENT 'comment_text'

  comment_text:
      STR_VALUE
  ```

## 分散パラメータ

* `PRIMARY_ZONE`：データのプライマリレプリカ分散ポリシーを指定します。

  ```sql
  primary_zone:
  PRIMARY_ZONE [=] zone_name
  ```

* `ZONE_LIST`：テナントのリソース分散ポリシーを指定します。

  ```sql
  zone_list:
  ZONE_LIST [=] (zone_name [, zone_name ...])
  ```

* `REPLICA_NUM`：データのレプリカ数を指定します。

  ```sql
  replica_num:
  REPLICA_NUM [=] INT_VALUE
  ```

* `TABLEGROUP`：複数データのプライマリレプリカ分散ポリシーを指定します。

  ```sql
  tablegroup:
        default_tablegroup
      | table_tablegroup

  default_tablegroup:
      DEFAULT TABLEGROUP [=] {tablegroup_name | NULL}

  table_tablegroup:
      TABLEGROUP [=] {tablegroup_name | NULL}
  ```

## ストレージパラメータ

* `BLOCK_SIZE`：オブジェクトストレージのマイクロブロックサイズを指定します。

  ```sql
  block_size:
  BLOCK_SIZE [=] INT_VALUE
  ```

* `COMPRESSION`：オブジェクトストレージの圧縮アルゴリズムを指定します。

  ```sql
  compression:
  COMPRESSION [=] {NONE | LZ4_1.0 | LZ0_1.0 | SNAPPY_1.0}
  ```

* `PCTFREE`：オブジェクトストレージのマクロブロック予約割合を指定します。

  ```sql
  pctfree:
  PCTFREE [=] INT_VALUE
  ```

* `TABLET_SIZE`：並列マージ時の単一タスクの最小シャーディングサイズを指定します。

  ```sql
  tablet_size:
  TABLET_SIZE [=] INT_VALUE
  ```
