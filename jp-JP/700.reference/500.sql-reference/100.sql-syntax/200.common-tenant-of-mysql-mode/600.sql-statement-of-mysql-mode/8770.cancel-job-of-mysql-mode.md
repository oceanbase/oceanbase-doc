# CANCEL JOB

非同期タスクをキャンセルするために使用します。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><ul><li><code>CANCEL JOB</code> を実行するには、<code>job_id</code> を指定する必要があります。</li><li>実行中のタスクは終了し、まだ開始されていないタスクは実行されません。</li>既に終了したタスクに対して <code>cancel job</code> を実行すると、<code> ERROR 4018 (HY000): Entry not exist</code> エラーが発生します。</li>タスクをキャンセルしても、ジョブのステータスは確認できます。</li></ul></p>
</main>

## 構文

```sql
CANCEL JOB 'job_id';
```

## 例

```shel
obclient> CANCEL JOB '2010011125899906847397';
3 rows in set (0.00 sec)
```
