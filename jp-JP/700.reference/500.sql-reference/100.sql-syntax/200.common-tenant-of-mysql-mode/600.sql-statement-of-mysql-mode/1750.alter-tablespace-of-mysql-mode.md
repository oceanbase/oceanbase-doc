# ALTER TABLESPACE

## 説明

このステートメントは、TableSpace（テーブルスペース）の暗号化方式を変更するために使用されます。

## 権限要件

`ALTER TABLESPACE` ステートメントを実行するには、現在のユーザーが `CREATE TABLESPACE` の管理権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

* 暗号化されたテーブルスペースを変更する

  ```sql
  ALTER TABLESPACE tablespace_name ENCRYPTION [=] 'tablespace_encryption_option';

  tablespace_encryption_option:
      N
      | Y
      | AES-256
      | AES-256-GCM
      | AES-128
      | AES-128-GCM
      | AES-192
      | AES-192-GCM
      | SM4-CBC
      | SM4-GCM
  ```

* テーブルスペースを変更する。

  ```sql
  ALTER TABLESPACE tablespace_name
    {ADD | DROP} DATAFILE 'file_name'
    [INITIAL_SIZE [=] size]
    [WAIT]
    ENGINE [=] engine_name
  ```

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>このキーワード構文のみサポートされており、機能は有効ではありません。この構文のキーワードは <code>ENCRYPTION</code> と同時に実行することはできず、そうした場合は構文エラーが発生します。</p>
  </main>

## パラメータの説明

|              パラメータ             |          説明           |
|------------------------------|-------------------------|
| tablespace_name              | 変更対象のTableSpaceオブジェクト名を指定します。|
| tablespace_encryption_option | 変更対象のTableSpaceオブジェクトの暗号化に使用する暗号化アルゴリズムを指定します。暗号化アルゴリズムの詳細については、以下の[tbspace_encryption_option](#tablespace_encryption_option)を参照してください。|

### tablespace_encryption_option

* `N`：暗号化しないことを示します。
* `Y`：`Y` を使用する場合、デフォルトで `AES-256` を使用することを示します。
* `AES-256`：256ビットの鍵を使用して暗号化と復号化を行います。
* `AES-256-GCM`：256ビットの鍵を使用したGCMモードです。
* `AES-128`：128ビットの鍵を使用して暗号化と復号化を行います。
* `AES-128-GCM`：128ビットの鍵を使用したGCMモードです。
* `AES-192`：192ビットの鍵を使用して暗号化と復号化を行います。
* `AES-192-GCM`：192ビットの鍵を使用したGCMモードです。
* `SM4-CBC`：SM4アルゴリズムはCBCモードを採用しており、各データブロックは前のブロックの暗号化後の出力と異なる値をXOR演算した上で再び暗号化されます。
* `SM4-GCM`：SM4アルゴリズムはGCMモードを採用しており、このモードではSM4がデータの暗号化と認証機能を同時に提供します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>AES (Advanced Encryption Standard) は対称暗号化アルゴリズムであり、同じ鍵を使用してデータの暗号化と復号化を行うことを意味します。AESアルゴリズム自体はブロック暗号化に基づいており、通常は128ビットのブロックでデータを暗号化します。</li><li>AES-GCM (Galois/Counter Mode) は、ブロック暗号化アルゴリズム（例えばAES）を処理し、暗号化とデータ認証（メッセージ認証コードとも呼ばれる）を提供するための操作モードです。</li><li>SM4アルゴリズムのブロック長は128ビット、鍵長も128ビットです。</li></ul></p>
</main>

## 例

暗号化されていないTableSpaceオブジェクト`tablespace001`を`SM4-GCM`暗号アルゴリズムを使用するように変更します。

```shell
ALTER TABLESPACE tablespace001 ENCRYPTION = 'SM4-GCM';
```
