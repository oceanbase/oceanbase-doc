# CHECKSUM TABLE

このステートメントは、テーブルのチェックサム（checksum）を取得するために使用されます。テーブルの内容を計算して一意の数値を生成し、この値を使用してテーブル内容の整合性を検証できます。つまり、異なるデータベース間で同一のテーブルが一致しているかどうか、または時間の経過とともにテーブルが変更されていないかどうかを確認するために使用できます。

## 構文

```sql
CHECKSUM TABLE tbl_name [, tbl_name] ... [QUICK | EXTENDED]
```
