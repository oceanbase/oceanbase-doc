# DROP LOCATION

## 説明

このステートメントは、Locationオブジェクトを削除するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.4.x系では、V4.4.1バージョンから <code>DROP LOCATION</code> ステートメントがサポートされています。</p>
</main>

## 権限要件

`DROP LOCATION` ステートメントを実行するには、現在のユーザーが `CREATE LOCATION` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
DROP LOCATION location_name;
```

## パラメータ説明

|   **パラメータ**    | **説明** |
|---------------|----------|
| location_name | 削除するLocationオブジェクトの名前を表します。|

## 例

Locationオブジェクト `test_location_local` を削除します。

```shell
obclient> DROP LOCATION test_location_local;
```

## 関連ドキュメント

現在のテナント内のLocationオブジェクト情報の確認方法については、[SHOW](8700.show-of-mysql-mode.md)を参照してください。
