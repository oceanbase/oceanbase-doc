# VALUES

## 説明

このステートメントは、テーブルとして一連の単一行または複数行データを返します。

`VALUES` はテーブル値コンストラクタであり、独立した SQL ステートメントとして、あるいは `UNION`、`EXCEPT`、`INTERSECT` などと組み合わせて使用することもできます。

## 構文

```sql
VALUES row_constructor_list [ORDER BY column_designator] [LIMIT number]

row_constructor_list:
    ROW(value_list)[, ROW(value_list)][, ...]

value_list:
    value[, value][, ...]

column_designator:
    column_index
```

## パラメータ

|      パラメータ       |    説明     |
|---------------|-----------|
|row_constructor_list| `ROW()` 行構築子句で構成される行構築関数のリストで、コンマで区切られます。`ROW()` は空にできませんが、括弧内に含まれるスカラーデータは `NULL` にすることができます。|
|value_list|1つまたは複数のスカラーデータのリストです。スカラーデータはリテラルまたはスカラーデータに評価される式です。同じ `VALUES` ステートメント内の各 `ROW()` に含まれる `value_list` には、同じ数の値が含まれている必要があります。|
|column_designator|列を指定します。列の命名規則は `column_0`、`column_1`、... です。オプションの `ORDER BY` 句を使用して、指定された列で行を並べ替えることができます。|

## 例

* `VALUES` は、出力がテーブル形式であり、指定された列 `column_0` でソートされている場合に使用されます。

  ```shell
  obclient> VALUES ROW(4,6,8), ROW(5,7,9), ROW(1,-2,3) ORDER BY column_0;
  ```

  例の出力結果は次のとおりです。

  ```shell
  +----------+----------+----------+
  | column_0 | column_1 | column_2 |
  +----------+----------+----------+
  |        1 |       -2 |        3 |
  |        4 |        6 |        8 |
  |        5 |        7 |        9 |
  +----------+----------+----------+
  3 rows in set
  ```

* `VALUES` ステートメントは、同じ列内のデータが混合データ型であることをサポートしています。

  ```shell
  obclient> VALUES ROW("q", 23, '2022-12-18'),  ROW(87, "x+z", 92.6), ROW(25.0009, "Well Smith", '{"a": 11, "b": 55}');
  ```

  例の出力結果は次のとおりです。

  ```shell
  +----------+------------+--------------------+
  | column_0 | column_1   | column_2           |
  +----------+------------+--------------------+
  | q        | 23         | 2022-12-18         |
  | 87       | x+z        | 92.6               |
  | 25.0009  | Well Smith | {"a": 11, "b": 55} |
  +----------+------------+--------------------+
  ```

* `VALUES` と `UNION` を一緒に使用すると、`SELECT` と同等の機能になります。

  ```shell
  obclient> SELECT 11,22 UNION SELECT 33,44;
  +------+------++
  | 11   | 22   |
  +------+------++
  |   11 |   22 |
  |   33 |   44 |
  +------+------++
  2 rows in set

  obclient> VALUES ROW(11,22) UNION VALUES ROW(33,44);
  ```

  例の出力結果は次のとおりです。

  ```shell
  +----------+----------+
  | column_0 | column_1 |
  +----------+----------+
  |       11 |       22 |
  |       33 |       44 |
  +----------+----------+
  2 rows in set
  ```
