# DEALLOCATE PREPARE

## 説明

このステートメントは、プリペアドステートメントを削除するために使用します。

## 構文

```sql
{DEALLOCATE | DROP} PREPARE stmt_name
```

## パラメータの説明

|    パラメータ     |    説明    |
|-----------|----------|
| stmt_name | ステートメントの名前です。 |

## 例

プリペアドステートメントを削除します。

```sql
obclient> PREPARE stmt1 FROM 'PURGE RECYCLEBIN';
Query OK, 0 rows affected

obclient> DROP PREPARE stmt1;
Query OK, 0 rows affected
```
