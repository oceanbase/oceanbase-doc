# DESCRIBE

## 説明

このステートメントは、テーブルまたは列のスキーマ情報を取得するために使用されます。

`EXPLAIN` は `DESCRIBE`、`DESC` の同義語です。

## 構文

```sql
{EXPLAIN | DESCRIBE | DESC} table_name [column_name | wild];
```

## パラメータの説明

|   **パラメータ**    |   説明    |
|-------------|---------|
| table_name  | テーブル名を指定します。   |
| column_name | テーブルの列名を指定します。 |

## 例

* テーブル `t1` の定義を表示します。

  ```sql
  obclient> DESCRIBE t1;
  +-------+-------------+------+-----+---------+-------+
  | Field | Type        | Null | Key | Default | Extra |
  +-------+-------------+------+-----+---------+-------+
  | c1    | int(11)     | NO   | PRI | NULL    |       |
  | c2    | int(11)     | YES  |     | NULL    |       |
  | c3    | varchar(20) | YES  |     | NULL    |       |
  +-------+-------------+------+-----+---------+-------+
  3 rows in set
  ```

* テーブル `t1` の `c1` 列の定義を表示します。

  ```sql
  obclient> DESCRIBE t1 c1;
  +-------+---------+------+-----+---------+-------+
  | Field | Type    | Null | Key | Default | Extra |
  +-------+---------+------+-----+---------+-------+
  | c1    | int(11) | NO   | PRI | NULL    |       |
  +-------+---------+------+-----+---------+-------+
  1 row in set
  ```
