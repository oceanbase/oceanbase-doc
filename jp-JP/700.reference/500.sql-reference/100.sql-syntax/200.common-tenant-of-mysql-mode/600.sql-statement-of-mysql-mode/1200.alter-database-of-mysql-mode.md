# ALTER DATABASE

## 説明

このステートメントは、データベースのプロパティを変更するために使用します。

## 構文

```sql
ALTER {DATABASE|SCHEMA} [database_name] [SET] alter_specification [alter_specification ...];

alter_specification:
    [DEFAULT] {CHARACTER SET | CHARSET} [=] charset_name
  | [DEFAULT] COLLATE [=] collation_name
  | {READ ONLY | READ WRITE}
  | [DEFAULT] TABLEGROUP [=] {NULL | table_group_name}
```

## パラメータの説明

|                        **パラメータ**                         |                                                        **説明**                                                        |
|-------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------|
| database_name                                         | プロパティを変更するデータベース名を指定します。指定しない場合、現在のデータベースが変更されます。現在のデータベースが空の場合、エラーが返されます。                                                    |
| \[DEFAULT\] { CHARACTER SET \| CHARSET } charset_name | データベースのデフォルト文字セットを指定します。`CHARACTER SET` と `CHARSET` は同義です。`DEFAULT` キーワードはオプションであり、意味に影響しません。                              |
| \[DEFAULT\] COLLATE collation_name                    | データベースのデフォルト照合順序を指定します。`DEFAULT` キーワードはオプションであり、意味に影響しません。                                                                |
| READ ONLY \| READ WRITE                               | データベースレベルの読み取り専用または読み書き可能な属性を設定します。                                                                                                       |
| [DEFAULT] TABLEGROUP table_group_name                   | データベースのデフォルトテーブルグループ情報を設定します。`NULL` はデータベースのデフォルトテーブルグループを無効にすることを意味します。 <main id="notice" type='explain'><h4>説明</h4> <p>V4.4.x系では、V4.4.1バージョン以降、このコマンドを実行すると、データベース内のすべてのテーブルのTableGroupプロパティが実際に変更されます。データベース内のユーザーテーブルの集約に関する情報については、<a href="../../../../../600.manage/350.load-balancing-manage/430.tablegroup-weight-management/100.aggregation-of-user-tables-in-a-database.md">データベース内のユーザーテーブルの集約</a>を参照してください。 データベースのTableGroupプロパティを変更しても、システムはすぐにすべてのユーザーテーブルのパーティションを同じログストリームに整列させるわけではありません。ユーザーテーブルの集約を早急に行いたい場合は：<ul><li><code>DBMS_BALANCE.TRIGGER_PARTITION_BALANCE</code>サブルーチンを呼び出して、手動でパーティションの均衡を一度トリガーすることができます。手動でパーティションの均衡をトリガーする詳細な操作については、<a href="../../../../../600.manage/350.load-balancing-manage/600.partition-balance-management/200.manually-trigger-a-partition-balancing-task.md">手動でパーティションの均衡をトリガーする</a>を参照してください。 </li><li>または、スケジュールされたパーティション均衡タスクのトリガーを待つこともできます。スケジュールされたパーティション均衡タスクの詳細については、<a href="../../../../../600.manage/350.load-balancing-manage/600.partition-balance-management/100.configure-a-scheduled-partition-balancing-task.md">スケジュールされたパーティション均衡タスクの設定</a>を参照してください。</li></ul></p></main>|

## 例

データベース `test2` の文字セットを `UTF8MB4`、照合順序を `UTF8MB4_BIN` に変更し、読み書き可能な属性を設定します。

```sql
obclient> ALTER DATABASE test2 DEFAULT CHARACTER SET utf8mb4;

obclient> ALTER DATABASE test2 DEFAULT COLLATE utf8mb4_bin;

obclient> ALTER DATABASE test2 READ WRITE;
```
