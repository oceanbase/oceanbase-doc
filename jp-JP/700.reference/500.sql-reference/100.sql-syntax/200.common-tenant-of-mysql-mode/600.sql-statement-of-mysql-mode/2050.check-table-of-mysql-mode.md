# CHECK TABLE

## 説明

このステートメントは、データベース内のテーブルとビューが存在するかどうか、またはビューが参照するオブジェクトが有効であるかどうかを確認するために使用されます。

`CHECK TABLE` ステートメントは、次の列を含む結果セットを返します：

* `Table`：チェック対象のテーブル名をリストアップします。
* `Op`：常に `check` であり、チェック操作が実行されていることを示します。
* `Msg_type`：メッセージタイプを示し、通常は `status` であり、メッセージタイプがステータス情報であることを示します。値は以下のとおりです：

  * `status`：ステータスを示します。
  * `error`：エラーを示します。
  * `info`：情報を示します。
  * `note`：注釈を示します。
  * `warning`：警告を示します。

* `Msg_text`：チェック結果の詳細情報を提供し、通常は `OK` であり、チェック結果が正常であり、問題が見つからなかったことを示します。

## 権限要件

`CHECK TABLE` ステートメントを実行するには、現在のユーザーが対応するオブジェクトに対して少なくとも `SELECT` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
CHECK TABLE table_name_list [check_option_list];

table_name_list:
    table_name [, table_name ...]

check_option_list:
    check_option [check_option ...]

check_option:
    FOR UPGRADE
    | QUICK
    | FAST
    | MEDIUM
    | EXTENDED
    | CHANGED
```

## パラメータの説明

|    パラメータ    |    説明  |
|--------------|---------|
| table_name   | チェック対象のテーブル名を指定します。複数のテーブルを指定する場合は、英語のカンマ（`,`）で区切ります。|
| check_option_list | オプションパラメータで、さらなるチェックオプションを指定します。複数のチェックオプションを同時に指定する組み合わせチェックオプションを指定できます。<main id="notice" type='notice'><h4>注意</h4><p>現在のバージョンでは、チェックオプションの構文のみサポートされており、機能は有効ではありません。</p></main>

## 例

テーブル `test_tbl1` が存在するかどうかを確認します。

```sql
obclient [test]> CHECK TABLE test_tbl1;
```

実行結果は次のとおりです：

```shell
+----------------+-------+----------+----------+
| Table          | Op    | Msg_type | Msg_text |
+----------------+-------+----------+----------+
| test.test_tbl1 | check | status   | OK       |
+----------------+-------+----------+----------+
1 row in set
```
