# DROP CATALOG

## 説明

このステートメントは、外部データカタログ(External Catalog)を削除するために使用します。

## 権限要件

`DROP CATALOG` ステートメントを実行するには、現在のユーザーが `CREATE CATALOG` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
DROP CATALOG [IF EXISTS] external_catalog_name;
```

## パラメータ説明

|   **パラメータ**   | **説明** |
|--------------|----------|
| IF EXISTS    | オプションです。`IF EXISTS` を指定すると、削除対象の外部データカタログが存在しない場合でもエラーは報告されません。指定しない場合はエラーが報告されます。|
| external_catalog_name | 削除する外部データカタログの名前を指定します。|

## 例

```sql
DROP CATALOG test_odps_catalog;
```
