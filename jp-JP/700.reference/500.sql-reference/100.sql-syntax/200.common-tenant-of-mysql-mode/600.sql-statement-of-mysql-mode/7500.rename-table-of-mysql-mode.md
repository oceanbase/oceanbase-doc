# RENAME TABLE

## 説明

このステートメントは、1つまたは複数のテーブルをリネームするために使用されます。

## 制限事項と注意点

* テーブルのリネーム処理中、システムは自動的にこのプロセスをロックし、リネームが完了するまで他のスレッドによるこれらのテーブルへの読み取り操作をブロックします。
* ターゲットテーブルに継続的にアクティブなトランザクションが存在する場合、リネーム操作は待機します。すべてのアクティブなトランザクションがコミットまたはロールバックされるまで、テーブルのリネーム処理は進行できません。
* このステートメントが複数のテーブルのリネームに使用される場合、リネーム操作は左から右へと順次実行されます。
* `RENAME TABLE` を実行する際には、ロックされたテーブルやアクティブな状態のトランザクションが存在してはなりません。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>テナントレベルの構成パラメータ<a href="../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2750.enable_lock_priority.md">enable_lock_priority</a>が有効になっている場合、<code>RENAME TABLE</code>は最も高いロック優先順位を持ちます。</p>
   </main>

* `RENAME TABLE`はビューに対して使用できますが、他のデータベースへの移動はサポートされていません。
* `RENAME TABLE`操作中は、テーブルのロックや読み書き防御策が追加されるため、操作時間が長くなります。他のユーザーによるDDL操作への影響を避けるため、一括して`RENAME TABLE`操作を実行することは推奨されません。

## 権限要件

この操作を実行するには、元のテーブルに対する`ALTER`および`DROP`権限と、新しいテーブルに対する`CREATE`および`INSERT`権限が必要です。

## 構文

```sql
RENAME TABLE table_name TO [new_database_name.]new_table_name
   [, table_name2 TO [new_database_name.]new_table_name2 ...];
```

## パラメータの説明

|                               **パラメータ**                                |                                  **説明**                                   |
|---------------------------------------------------------------------|---------------------------------------------------------------------------|
| table_name                                                          | 元のテーブル名。                                                                      |
| new_table_name                                                      | 新しいテーブル名。                                                                      |
| table_name  TO \[new_database_name.\]new_table_name | 複数のテーブルをリネームする場合は、カンマ（,）で区切ります。 `new_database_name` を指定して、テーブルを他のデータベースに移動できます。 |

## 例

1. テーブル `t1` と `t2` を作成します。

   ```sql
   obclient> CREATE TABLE t1(c1 INT);
   obclient> CREATE TABLE t2(c1 INT);
   ```

2. テーブル `t1` を `t11` にリネームします。

   ```sql
   obclient> RENAME TABLE t1 TO t11;
   ```

3. テーブル `t11` を `t111` に、テーブル `t2` を `t22` にリネームします。

   ```sql
   obclient> RENAME TABLE t11 TO t111, t2 TO t22;
   ```

4. テーブル `t22` を `mysql` データベースに移動します。

   ```sql
   obclient> RENAME TABLE t22 TO mysql.t22;
   ```
