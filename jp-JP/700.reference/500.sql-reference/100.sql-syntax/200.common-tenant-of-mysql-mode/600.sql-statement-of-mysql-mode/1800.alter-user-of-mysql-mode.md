# ALTER USER

## 説明

このステートメントは主に以下の操作を実行するために使用されます：

* OceanBaseデータベースユーザーのパスワードを変更します。

* ユーザーをロックまたはアンロックし、ロックされたユーザーはデータベースへのログインを許可されません。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>現在のユーザーのパスワードを変更する以外に、<code>CREATE USER</code>権限も必要です。</p>
  </main>

* ユーザーがログイン時にデフォルトで有効になるロールを設定します。
* ユーザーのリソースオプションを変更します。

## 権限要件

`ALTER USER` ステートメントを実行するには、現在のユーザーが `CREATE USER` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

* ユーザーのパスワードを変更する：

  ```sql
  ALTER USER 'user_name' IDENTIFIED BY 'password';
  ```

* ユーザーをロックする：

  ```sql
  ALTER USER 'user_name' [ACCOUNT LOCK | ACCOUNT UNLOCK];
  ```

* ユーザーがログイン時にデフォルトで有効になるロールを設定する：

  ```sql
  ALTER USER user_name DEFAULT ROLE {NONE | ALL | role_name [, role_name ...]};
  ```

* ユーザーのリソースオプションを変更する：

  ```sql
  ALTER USER user_name WITH  resource_option [resource_option];

  resource_option:
      MAX_CONNECTIONS_PER_HOUR integer
      | MAX_USER_CONNECTIONS integer
  ```

## パラメータの説明

|     **パラメータ**   | **説明** |
|----------------|----------|
| user_name      | ユーザー名を指定します。|
| password       | 新しいパスワードを指定します。|
| ACCOUNT LOCK   | ユーザーのロックを指定します。|
| ACCOUNT UNLOCK | ユーザーのアンロックを指定します。|
| NONE           | ユーザーに付与されたすべてのロールを無効にすることを指定します。|
| ALL            | ユーザーのすべてのロールを有効にすることを指定します。|
| role_name      | ロール名を指定します。複数のロールを有効にする場合は、ロール名を英字のカンマ（`,`）で区切ります。|
| resource_option | ユーザーのリソースオプションを指定します。複数のリソースオプションを指定する場合は、英字のスペースで区切ります。<ul><li>`MAX_CONNECTIONS_PER_HOUR`：1時間あたりに許可される最大接続数を指定します。`integer` は整数であり、許可される最大接続数を表します。</li><li>`MAX_USER_connections`：各ユーザーに許可される最大接続数を指定します。`integer` は整数であり、許可される最大接続数を表します。</li></ul>|

## 例

* 以下のコマンドを実行して、ユーザー `sqluser01` のパスワードを `******` に変更します。

  ```sql
  obclient> ALTER USER 'sqluser01' IDENTIFIED BY '******';
  ```

* ユーザー `obsqluser01` をロックします。

  ```sql
  obclient> ALTER USER 'obsqluser01' ACCOUNT LOCK;
  ```

* ユーザー `obsqluser01` のロックを解除します。

  ```sql
  obclient> ALTER USER 'obsqluser01' ACCOUNT UNLOCK;
  ```

* ユーザー `user001` がログイン時に、ユーザーに付与された `role001` と `role002` のロールをデフォルトで有効にするよう指定します。

  ```sql
  ALTER USER user001 DEFAULT ROLE role001, role002;
  ```
