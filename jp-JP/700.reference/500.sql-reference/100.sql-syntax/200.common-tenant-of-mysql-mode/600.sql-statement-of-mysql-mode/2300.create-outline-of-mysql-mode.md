# CREATE OUTLINE

## 説明

このステートメントは、Outlineを作成するために使用されます。作成方法は2種類あります。1つは `SQL_TEXT`（ユーザーが実行したパラメータ付きの元のステートメント）を使用する方法、もう1つは `SQL_ID` を使用する方法です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>Outlineを作成するには、対応するデータベースに接続して実行する必要があります。</p>
  </main>

`SQL_ID` が同じ場合、`SQL_TEXT` 方式で作成されたOutlineは `SQL_ID` 方式で作成されたOutlineを上書きします。`SQL_TEXT` 方式の優先順位が高いためです。

さらに、OceanBaseデータベースは `SQL_ID` を使用して異なるSQLを区別します。`SQL_ID` は `SQL_TEXT` からMD5ハッシュを取得して生成されるため、同じSQLテキストであっても、改行やタブが1つ追加されただけでも、生成される `SQL_ID` は異なります。実際の本番システムでは、`SQL_ID` を使用してOutlineをバインドすることを推奨します。

## 権限要件

`CREATE OUTLINE` ステートメントを実行するには、現在のユーザーに `CREATE` 管理権限が必要です。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

* `SQL_TEXT` を使用してOutlineを作成します。

  ```sql
  CREATE [OR REPLACE] OUTLINE outline_name ON stmt [ TO target_stmt ];
  ```

* `SQL_ID` を使用してOutlineを作成します。

  ```sql
  CREATE OUTLINE outline_name ON sql_id USING HINT hint;
  ```

## パラメータの説明

|     **パラメータ**     |                                                                                                                                **説明**                                                                                                                                |
|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| outline_name   | 作成するOutlineの名前を指定します。                                                                                                                                                                                                                                                   |
| OR REPLACE     | `OR REPLACE` を指定すると、作成しようとしているOutlineが既に存在する場合、既存のOutlineを置き換えます。                                                                                                                                                                                                                |
| stmt           | 通常は、ヒントと元のパラメータを含むDMLステートメントです。                                                                                                                                                                                                                                          |
| TO target_stmt | `TO target_stmt` を指定しない場合、データベースが受け入れるSQLをパラメータ化した結果、`stmt` からヒントを除去したテキストと一致する場合、そのSQLを `stmt` のヒントに基づいて実行計画を生成してバインドします。ヒントを含むステートメントの固定計画を期待する場合は、 `TO target_stmt` を使用して元のSQLを指定する必要があります。<br>**注意**  `target_stmt` を使用する際は、 `stmt` と `target_stmt` のヒントを除去した後、完全に一致している必要があります。</br> |
| sql_id         | `sql_id` に対応するSQLステートメントに既にヒントが存在する場合、Outline作成時に指定されたヒントは元のステートメント内のすべてのヒントを上書きします。                                                                                                                                                                                                 |
| hint           | `/*+ xxx */`の形式。 <main id="notice" ><h4>説明</h4><p><ul><li><code>SQL_TEXT</code>を使用してクエリ制限のためのOutlineを作成する場合、追加のパラメータを明示的に指定する必要はありません。例えば、次のようにOutlineを作成できます：<code>create outline otl2 on select /*+ max_concurrent(1) */ * from t where c1=?</code>。この場合、<code>c1</code>は具体的な値を指定する必要はなく、パラメータ化されたプレースホルダー（例えば、<code>?</code>）を使用できます。</li></ul><ul><li>実行計画をバインドする際には、対応するパラメータを指定する必要があります。例えば、バインド実行計画のOutlineを作成するには、次のようないくつかの文を使用できます：<code>create outline otl2 on select /*+ norewrite */ * from t where c1=1</code>。この場合、<code>c1</code>に具体的な値を指定する必要があります。 </li></ul></p></main>   |


## 例

* `SQL_TEXT` を使用して Outline を作成します。

  ```sql
  obclient> CREATE OUTLINE otl_idx_c2
  ON SELECT/*+ index(t1 idx_c2)*/ * FROM t1 WHERE c2 = 1;
  ```

* `SQL_ID` を使用して Outline を作成します。

  ```sql
  obclient> CREATE OUTLINE otl_idx_c2
  ON 'ED570339F2C856BA96008A29EDF04C74'
  USING HINT /*+ index(t1 idx_c2)*/ ;
  ```

* `SQL_TEXT` を使用して Outline を作成し、ヒントで同時実行数の制限と実行計画を同時に指定します。

  ```sql
  obclient> CREATE OUTLINE otl_idx_c2 ON SELECT /*+ use_nl(tbl2) max_concurrent(1)*/ * FROM t WHERE c1=?;
  ```
