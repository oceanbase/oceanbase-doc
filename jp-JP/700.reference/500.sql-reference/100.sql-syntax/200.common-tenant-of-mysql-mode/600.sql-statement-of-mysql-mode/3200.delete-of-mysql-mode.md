# DELETE

## 説明

このステートメントは、単一のテーブルまたは複数のテーブルから条件に一致する行を削除するために使用されます。

複数のテーブルからの削除であっても単一のテーブルからの削除であっても、サブクエリ自体を直接削除することはサポートされていません。例えば、`DELETE FROM (SELECT * FROM t1);` のような書き方はできません。

## 構文

```sql
Single-Table-Delete Syntax:
    DELETE [hint_options] [LOW_PRIORITY] [QUICK] [IGNORE] FROM table_name
    [PARTITION (partition_name,...)]
    [WHERE where_condition]
    [ORDER BY order_expression_list]
    [LIMIT row_count]

Multiple-Table-Delete Syntax:
    DELETE [hint_options] [LOW_PRIORITY] [QUICK] table_name[.*] [, table_name[.*]] ...
    FROM table_references
    [WHERE where_condition]
Or:
    DELETE [hint_options] [LOW_PRIORITY] [QUICK] FROM table_name[.*] [, table_name[.*]] ...
    USING table_references
    [WHERE where_condition]

where_condition:
    expression

order_expression_list:
    order_expression [, order_expression ...]

order_expression:
    expression [ASC | DESC]

limit_row_count:
    INT_VALUE

table_references:
    {table_name | joined_table | table_subquery | select_with_parents} [, ...]

```

## パラメータの説明

|        **パラメータ**         |        **説明**         |
|-----------------------|-----------------------|
| hint_options          | `hint` オプションを指定します。         |
| LOW_PRIORITY          | オプションで、他のクライアントがテーブルからデータを読み取るまで `DELETE` ステートメントの実行を遅延させます。現在のバージョンではこのキーワード構文のみがサポートされており、機能は有効ではありません。|
| QUICK                 | オプションで、削除操作を高速化するために使用されます。現在のバージョンではこのキーワード構文のみがサポートされており、機能は有効ではありません。|
| IGNORE                | オプションで、行を削除する際に無視可能なエラーを無視します。現在のバージョンではこのキーワード構文のみがサポートされており、機能は有効ではありません。|
| table_name            | 削除対象のテーブル名を指定します。            |
| partition_name        | 削除対象のテーブルのパーティション名。          |
| where_condition       | 削除するテーブルが満たす必要があるフィルタリング条件。        |
| order_expression_list | 削除するテーブルのソートキーのリスト。           |
| row_count             | 削除対象のテーブルの行数を指定します。指定する値は整数のみです。 |
| table_references      | 複数のテーブルを削除する場合に、選択するテーブルのシーケンスを指定します。      |

## 例

サンプルテーブルとデータは、以下の定義に基づいています：

```sql
obclient> CREATE TABLE t1(c1 INT PRIMARY KEY, c2 INT);
Query OK, 0 rows affected
obclient> SELECT * FROM t1;
+----+------+
| c1 | c2   |
+----+------+
|  1 |    1 |
|  2 |    2 |
|  3 |    3 |
|  4 |    4 |
+----+------+
4 rows in set

obclient> CREATE TABLE t2(c1 INT PRIMARY KEY, c2 INT) PARTITION BY KEY(c1) PARTITIONS 4;
Query OK, 0 rows affected
obclient> SELECT * FROM t2;
+----+------+
| c1 | c2   |
+----+------+
|  5 |    5 |
|  1 |    1 |
|  2 |    2 |
|  3 |    3 |
+----+------+
4 rows in set
```

* 単一テーブルの削除：テーブル `t1` の `c1` 列が主キーであるため、`c1=2` の行を削除します。

  ```sql
  obclient> DELETE FROM t1 WHERE c1 = 2;
  Query OK, 1 row affected (0.02 sec)

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  1 |    1 |
  |  3 |    3 |
  |  4 |    4 |
  +----+------+
  3 rows in set
  ```

* 単一テーブルの削除：テーブル `t1` の `c2` 列でソートした後の最初の行データを削除します。

  ```sql
  obclient> DELETE FROM t1 ORDER BY c2 LIMIT 1;
  Query OK, 1 row affected

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  2 |    2 |
  |  3 |    3 |
  |  4 |    4 |
  +----+------+
  3 rows in set
  ```

* 単一テーブルの削除：テーブル `t2` の `p2` パーティションのデータを削除します。

  ```sql
  obclient> DELETE FROM t2 PARTITION(p2);
  Query OK, 3 rows affected

  obclient> SELECT * FROM t2;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  5 |    5 |
  +----+------+
  1 row in set
  ```

* 複数テーブルの削除：テーブル `t1` および `t2` から `t1.c1 = t2.c1` のデータを削除します。

  ```sql
  obclient> DELETE t1, t2 FROM t1, t2 WHERE t1.c1 = t2.c1;
  Query OK, 3 rows affected

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  4 |    4 |
  +----+------+
  1 row in set

  obclient> SELECT * FROM t2;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  5 |    5 |
  +----+------+
  1 row in set
  ```

* 複数テーブルの削除：テーブル `t1` および `t2` から `t1.c1 = t2.c1` のデータを削除します。

  ```sql
  obclient> DELETE FROM t1, t2 USING t1,t2 WHERE t1.c1 = t2.c1;
  Query OK, 6 rows affected

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  4 |    4 |
  +----+------+
  1 row in set

  obclient> SELECT * FROM t2;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  5 |    5 |
  +----+------+
  1 row in set
  ```

* 複数テーブルの削除：テーブル `t2` の `p2` パーティションおよびテーブル `t1` から `t1.c1 = t2.c1` を満たすデータを削除します。

  ```sql
  obclient> DELETE t2 FROM t1,t2 PARTITION(p2) WHERE t1.c1 = t2.c1;
  Query OK, 3 rows affected

  obclient> select * from t2;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  5 |    5 |
  +----+------+
  1 row in set
  ```

* 更新可能なビュー `v` に対して削除操作を実行します。

  ```sql
  obclient> CREATE VIEW v AS SELECT * FROM t1;
  Query OK, 0 rows affected

  obclient> DELETE FROM v WHERE v.c1 = 1;
  Query OK, 1 row affected

  obclient> SELECT * FROM v;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  2 |    2 |
  |  3 |    3 |
  |  4 |    4 |
  +----+------+
  3 rows in set
  ```
