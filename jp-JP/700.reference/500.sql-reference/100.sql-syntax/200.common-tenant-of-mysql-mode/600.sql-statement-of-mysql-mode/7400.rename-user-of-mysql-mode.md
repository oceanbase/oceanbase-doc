# RENAME USER

## 説明

このステートメントは、OceanBaseデータベースのログインユーザー名を変更するために使用します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>グローバルな <code>CREATE USER</code> 権限が付与されている必要があります。このコマンドを使用してユーザー名を変更できます。</p>
  </main>

## 構文

```sql
RENAME USER
    'old_user_name' TO 'new_user_name'
  [,'old_user_name' TO 'new_user_name'...];
```

## パラメータの説明

|               **パラメータ**               |                           **説明**                            |
|------------------------------------|-------------------------------------------------------------|
| old_user_name                      | 旧ユーザー名。                                                       |
| new_user_name                      | 新ユーザー名。ユーザー名は16バイト以下である必要があります。                                      |
| 'old_user_name' TO 'new_user_name' | ユーザー名を変更します。複数のユーザー名を同時に変更する場合は、カンマ（,）で区切ります。 変更前後で、新旧のユーザー権限は一致します。 |

## 例

1. 変更前に、以下のコマンドを実行してユーザーを確認します。

   結果は次のとおりです。

   ```sql
   obclient> SELECT user FROM mysql.user;
   +-----------+
   | user      |
   +-----------+
   | root      |
   | admin     |
   | sqluser01 |
   | sqluser02 |
   +-----------+
   4 rows in set
   ```

2. 以下のコマンドを実行して、`sqluser01` ユーザーのユーザー名を `obsqluser01` に変更します。

   ```sql
   obclient> RENAME USER 'sqluser01' TO 'obsqluser01';
   ```

3. 変更後に、以下のコマンドを実行してユーザーを確認します。結果は次のとおりです。

   `sqluser01` ユーザーのユーザー名が `obsqluser01` に変更されました。

   ```sql
   obclient> RENAME USER 'sqluser01' TO 'obsqluser01';
   Query OK, 0 rows affected

   obclient> SELECT user FROM mysql.user;
   +-------------+
   | user        |
   +-------------+
   | root        |
   | admin       |
   | obsqluser01 |
   | sqluser02   |
   +-------------+
   4 rows in set
   ```
