# DROP TABLESPACE

## 説明

このステートメントは、TableSpaceの論理オブジェクトを削除するために使用されます。TableSpaceにテーブルが存在しない場合にのみ、削除は成功します。

## 構文

```sql
DROP TABLESPACE tablespace_name
[ENGINE [=] engine_name];
```

## パラメータの説明

|       パラメータ      |          説明          |
|-----------------|-----------------------|
| tablespace_name | 削除するTableSpaceの名前を指定します。|
| ENGINE |TableSpaceで使用するストレージエンジンを指定します。現在のバージョンではこのキーワード構文のみがサポートされており、機能はまだ有効ではありません。|

## 例

TableSpaceオブジェクト `tablespace001` を削除します。

```shell
DROP TABLESPACE tablespace001;
```
