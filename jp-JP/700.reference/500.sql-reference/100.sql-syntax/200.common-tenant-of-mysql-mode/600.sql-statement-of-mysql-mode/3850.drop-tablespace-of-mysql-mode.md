# DROP TABLESPACE

## 説明

このステートメントは、TableSpaceの論理オブジェクトを削除するために使用されます。TableSpaceにテーブルが存在しない場合にのみ、削除は成功します。

## 権限要件

`DROP TABLESPACE` ステートメントを実行するには、現在のユーザーが `CREATE TABLESPACE` の管理権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
DROP TABLESPACE tablespace_name
[ENGINE [=] engine_name];
```

## パラメータの説明

|       パラメータ      |          説明          |
|-----------------|-----------------------|
| tablespace_name | 削除するTableSpaceの名前を指定します。|
| ENGINE | TableSpaceを使用するストレージエンジンを指定します。現在のバージョンではこのキーワード構文のみがサポートされており、機能はまだ有効ではありません。|

## 例

TableSpaceオブジェクト `tablespace001` を削除します。

```shell
DROP TABLESPACE tablespace001;
```
