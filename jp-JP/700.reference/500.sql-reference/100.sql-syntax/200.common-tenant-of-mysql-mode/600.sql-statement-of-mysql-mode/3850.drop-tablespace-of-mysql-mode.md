# DROP TABLESPACE

## 説明

このステートメントは、テーブルスペースという論理オブジェクトを削除します。対象のテーブルスペース内にテーブルがない場合にのみ削除できます。

## 構文

```sql
DROP TABLESPACE tablespace_name
[ENGINE [=] engine_name];
```

## パラメータの説明

|       パラメータ      |          説明          |
|-----------------|-----------------------|
| tablespace_name | 削除するテーブルスペースの名前を指定します。|
| ENGINE |テーブルスペースで使用するストレージエンジンを指定します。現在のバージョンではこのキーワード構文のみがサポートされており、機能はまだ有効ではありません。|

## 例

テーブルスペース `tablespace001`を削除します。

```shell
DROP TABLESPACE tablespace001;
```
