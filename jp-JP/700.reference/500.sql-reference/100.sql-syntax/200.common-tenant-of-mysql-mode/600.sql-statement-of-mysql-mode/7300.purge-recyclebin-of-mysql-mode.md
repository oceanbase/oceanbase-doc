# PURGE RECYCLEBIN

## 説明

このステートメントは、ごみ箱を空にするために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>PURGE RECYCLEBIN</code> はごみ箱内のすべてのデータベースオブジェクトを削除します。このステートメントを実行できるのはrootユーザーのみですので、操作には十分ご注意ください。</p>
  </main>

## 構文

```sql
 PURGE RECYCLEBIN;
```

## 例

ごみ箱を空にします。

```sql
obclient> PURGE RECYCLEBIN;
Query OK, 0 rows affected
```
