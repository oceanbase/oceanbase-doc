# CREATE CONCURRENT_LIMITING_RULE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このステートメントはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このステートメントはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>

## 説明

このステートメントは、レート制限ルールを作成し、特定のSQLの同時実行数を制限するためのレート制限範囲を指定します。

## 権限要件

`CREATE CONCURRENT_LIMITING_RULE` ステートメントを実行するには、現在のユーザーがCREATE権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
CREATE CONCURRENT_LIMITING_RULE [ IF NOT EXISTS ] `ccl_rule_name`
ON `database`.`table`
TO '<usename>'@'ip'
FOR { ALL | UPDATE | SELECT | INSERT | DELETE }
filter_options:
    [ FILTER BY KEYWORD('KEYWORD1', 'KEYWORD2',…) ]
 with_options:
    WITH MAX_CONCURRENCY = value1 [per sql]
```

## パラメータの説明

| パラメータ             |       説明        |
|----------------------------|----------|
|`ccl_rule_name`|必須。レート制限ルールの名前を表します。<main id="notice" type='explain'><h4>説明</h4><p>名前がSQLキーワードと競合するのを避けるため、ルール名の前後にアポストロフ(`)を付けることを推奨します。</p></main>|
|`database`.`table`|必須。データベースとテーブルの名前を表します。アスタリスク(*)を使用して任意の一致を表すことができます。<main id="notice" type='explain'><h4>説明</h4><p>名前がSQLキーワードと競合するのを避けるため、ルール名の前後にアポストロフ(`)を付けることを推奨します。</p></main>|
|`<usename>@<host>`|必須。アカウント名を表します。usernameでは*を使用してすべてのユーザーを表すことができ、Host部分ではパーセント記号(%)を使用して任意の一致を表すことができます。|
|`ALL`\|`UPDATE \| SELECT \| INSERT\| DELETE`|必須。SQLステートメントのタイプを表します。現在`ALL`、`UPDATE`、`SELECT`、`INSERT`、`DELETE`タイプをサポートしています。<main id="notice" type='explain'><h4>説明</h4><p>各レート制限ルールは、1種類のSQLステートメントタイプのみをサポートします。</p></main>|
|`[ filter_options ]`|オプション。レート制限のキーワードを表します。<main id="notice" type='explain'><h4>説明</h4><p><ul><li>キーワード間はワイルドカード<code>%</code>で結合されます。例えば、3つのキーワード<code>'asdasd', 'c2 = 123', 'xxyyzz'</code>が与えられた場合、<code>'%asdasd%c2 = 123%xxyyzz%'</code>という文字列に組み合わされ、その後この文字列に基づいてSQLテキストのワイルドマッチングが行われます。</li><li>キーワードに<code>'_</code>が含まれる場合、エスケープされます。例えば、<code>'table_t1'</code>は<code>'%table\_t1%'</code>として記録されます。</li><li> レート制限キーワードに数の制限はありませんが、組み合わせた後の文字列の長さは <code>OB_MAX_VARCHAR_LENGTH=1048576</code> を超えてはなりません。</li></ul></p></main>|
|`with_options`|必須。レート制限の同時実行数を制御し、レート制限統計の粒度がルールレベルかFormat SQLIDステートメントレベルかを指定します。現在、`MAX_CONCURRENCY`パラメータのみをサポートしており、このレート制限ルールに一致するSQLステートメントの最大同時実行数を表します。|

## 例

以下のコマンドを実行して、キーワードによるレート制限を行います：

```shell
obclient> CREATE CONCURRENT_LIMITING_RULE IF NOT EXISTS  `sql1_keywords_ccl_rule`
ON *.* TO '%'@'%' FOR SELECT
FILTER BY KEYWORD('table1', 'table2', 'c1') WITH MAX_CONCURRENCY 100;
```
