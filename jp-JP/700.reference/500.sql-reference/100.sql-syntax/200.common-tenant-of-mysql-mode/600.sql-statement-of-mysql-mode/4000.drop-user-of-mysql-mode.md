# DROP USER

## 説明

このステートメントは、1人または複数のデータベースユーザーを削除するために使用します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li><code>DROP USER</code> コマンドを使用するには、グローバルな <code>CREATE USER</code> 権限が必要です。</li>
    <li><code>mysql.user</code> テーブルは <code>DELETE</code> で削除できません。<code>DROP</code> コマンドでのみ削除できます。</li>
    <li>ユーザーの削除に成功すると、そのユーザーのすべての権限も同時に削除されます。</li>
    </ul>
  </main>

## 構文

```sql
DROP USER [IF EXISTS] user_name [, user_name...];
```

## パラメータ説明

|    パラメータ     |          説明           |
|-----------|-----------------------|
| IF EXISTS | オプションです。指定すると、存在しないユーザーを削除した場合にエラーではなく警告が発生します。この句を省略した場合、存在しないユーザーを削除するとエラーが発生します。|
| user_name | ユーザー名。複数のユーザーを同時に削除する場合は、「,」で区切ります。 |

## 例

`sqluser01` という名前のユーザーを削除します。

```sql
obclient> DROP USER sqluser01;
Query OK, 0 rows affected
```
