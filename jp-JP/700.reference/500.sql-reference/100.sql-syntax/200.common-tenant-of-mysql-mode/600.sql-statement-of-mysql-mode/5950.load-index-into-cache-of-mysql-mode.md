# LOAD INDEX INTO CACHE

## 説明

このステートメントは、クエリ性能を向上させるためにインデックスをキャッシュに読み込むために使用されます。各インデックスを個別に読み込む代わりに、一度に複数のインデックスをキャッシュに読み込むことができます。これにより、インデックスの読み込み時のシステムオーバーヘッドが削減され、全体的なパフォーマンスが向上します。

## 構文

```sql
LOAD INDEX INTO CACHE tbl_index_list [, tbl_index_list ...];

tbl_index_list:
    tbl_name [PARTITION (partition_list)] [{INDEX|KEY} (index_name[, index_name ...])] [IGNORE LEAVES]

partition_list:
    partition_name [, partition_name ...]
    | ALL
```
