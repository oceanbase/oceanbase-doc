# INSERT

## 説明

このステートメントは、テーブルに1つまたは複数のレコードを追加するために使用されます。

サブクエリに対して直接挿入操作を行うことはサポートされていません。例えば、`INSERT INTO (SELECT * FROM t1) VALUES(1, 1)` のような構文は使用できません。

## 構文

```sql
INSERT [LOW_PRIORITY | HIGH_PRIORITY] [IGNORE] [INTO]
       single_table_insert
       [ON DUPLICATE KEY UPDATE update_asgn_list]

single_table_insert:
    {dml_table_name values_clause
     | dml_table_name '(' ')' values_clause
     | dml_table_name '(' column_list ')' values_clause
     | dml_table_name SET update_asgn_list}

dml_table_name:
    table_name [PARTITION (partition_name,...)]

values_clause:
     {{VALUES | VALUE} ({expr | DEFAULT},...) [, ...]
      | select_stmt}

column_list
    column_name [, ...]

update_asgn_list:
     column_name = expr [, ...]
```

## パラメータの説明

|         **パラメータ**          |                                                              **説明**                                                               |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| LOW_PRIORITY \| HIGH_PRIORITY | オプション。具体的な意味は以下のとおりです。<ul><li><code>LOW_PRIORITY</code>：<code>INSERT</code> ステートメントの実行を遅延させ、他のクライアントがテーブルからデータを読み取らない限り実行しません。現在のバージョンではこのキーワード構文のみがサポートされており、機能は有効になりません。</li><li><code>HIGH_PRIORITY</code>：<code>INSERT</code> ステートメントの優先順位を高く指定します。現在のバージョンではこのキーワード構文のみがサポートされており、機能は有効になりません。</li></ul>|
| IGNORE                  | `INSERT` ステートメントの実行中に発生したエラーは無視されます。                                                                                                     |
| column_list             | 指定するデータを挿入する列。複数の列を同時に挿入する場合は、カンマ（,）で区切ります。                                                                                                       |
| table_name              | 挿入するテーブル名を指定します。                                                                                                                         |
| partition_name          | 指定するパーティション名を挿入します。                                                                                                                        |
| update_asgn_list        | 値代入ステートメント。例えば、`c1 = 2` のように記述します。                                                                                                                 |
| ON DUPLICATE KEY UPDATE | 重複する主キーまたは一意キーに対する処理を指定します。`ON DUPLICATE KEY UPDATE` を指定した場合、挿入しようとしている主キーまたは一意キーが重複している場合、設定値で置き換えられます。`ON DUPLICATE KEY UPDATE` を指定しない場合、挿入しようとしている主キーまたは一意キーが重複している場合、挿入エラーが発生します。 |

## 例

サンプルテーブルとデータは、以下の定義に基づいています：

```sql
obclient> CREATE TABLE t1(c1 INT PRIMARY KEY, c2 INT) PARTITION BY KEY(c1) PARTITIONS 4;
Query OK, 0 rows affected

obclient> CREATE TABLE t2(c1 INT PRIMARY KEY, c2 INT);
Query OK, 0 rows affected
obclient> SELECT * FROM t2;
+----+------+
| c1 | c2   |
+----+------+
|  1 |    1 |
|  2 |    2 |
|  3 |    3 |
|  4 |    4 |
+----+------+
4 rows in set
```

* テーブル `t1` に1行のデータを挿入します。

  ```javascript
  obclient>  INSERT INTO t1 VALUES(1,1);
  Query OK, 1 row affected

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  1 |    1 |
  +----+------+
  1 row in set
  ```

* テーブル `t1` に複数行のデータを挿入します。

  ```sql
  obclient> INSERT t1 VALUES(1,1),(2,DEFAULT),(2+2,3*4);
  Query OK, 3 rows affected
  Records: 3  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  1 |    1 |
  |  2 | NULL |
  |  4 |   12 |
  +----+------+
  3 rows in set
  ```

* テーブル `t1` の指定された `p0` パーティションに単一行のデータを挿入します。

  ```sql
  obclient> INSERT INTO t1 PARTITION(p0) (c1) VALUES(5);
  Query OK, 1 row affected
  obclient> SELECT * FROM t1 PARTITION(p0);
  +----+------+
  | c1 | c2   |
  +----+------+
  |  5 | NULL |
  +----+------+
  1 row in set
  ```

* テーブル `t1` に重複する主キー値を挿入する際に、`ON DUPLICATE KEY UPDATE` 機能を使用して値を更新します。

  ```sql
  obclient> INSERT INTO t1 VALUES(1,1),(1,2) ON DUPLICATE KEY UPDATE c1=100;
  Query OK, 3 rows affected
  Records: 2  Duplicates: 1  Warnings: 0

  obclient> SELECT * FROM t1;
  +-----+------+
  | c1  | c2   |
  +-----+------+
  | 100 |    1 |
  +-----+------+
  1 row in set
  ```

* 更新可能なビュー `v` に挿入値を挿入します。

  ```sql
  obclient> CREATE VIEW v AS SELECT * FROM t1;
  Query OK, 0 rows affected
  obclient> INSERT INTO v VALUES (1,1);
  Query OK, 1 row affected

  obclient> SELECT * FROM v;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  1 |    1 |
  +----+------+
  1 row in set
  ```

* `t2` テーブルに `t1` のクエリ結果を挿入します。

  ```sql
  obclient> INSERT INTO t1 SELECT * FROM t2 WHERE c1>2;
  Query OK, 2 rows affected
  Records: 2  Duplicates: 0  Warnings: 0

  obclient> SELECT * FROM t1;
  +----+------+
  | c1 | c2   |
  +----+------+
  |  3 |    3 |
  |  4 |    4 |
  +----+------+
  2 rows in set
  ```
