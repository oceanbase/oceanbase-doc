# ALTER LOGFILE GROUP

## 説明

このステートメントは、ログファイルグループを変更するために使用されます。

## 構文

```sql
ALTER LOGFILE GROUP logfile_group
    ADD UNDOFILE 'file_name'
    [INITIAL_SIZE [=] size]
    [WAIT]
    ENGINE [=] engine_name
```
