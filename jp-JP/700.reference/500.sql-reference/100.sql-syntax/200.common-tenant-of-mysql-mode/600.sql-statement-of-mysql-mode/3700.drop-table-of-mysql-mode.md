# DROP TABLE

## 説明

このステートメントは、OceanBaseデータベースからテーブルを削除するために使用します。

## 構文

```sql
DROP {TABLE | TABLES} [TEMPORARY] [IF EXISTS]
table_name [,table_name]...
[RESTRICT | CASCADE]
```

## パラメータの説明

|       **パラメータ**        |                                             **説明**                                             |
|---------------------|------------------------------------------------------------------------------------------------|
| table_name          | 削除するテーブル名を指定します。複数のテーブルを同時に削除する場合は、「,」で区切ります。                                                                      |
| TEMPORARY           | 一時テーブルを削除することを示します。<main id="notice" type='explain'><h4>説明</h4><p><ul><li>OceanBaseデータベースV4.1.0 BP4バージョン以降、MySQLモードでは一時テーブル機能が無効になっています。</li><li>OceanBaseデータベースV4.4.xバージョンでは、V4.4.2バージョンから一時テーブル機能をサポートしています。</li></p></main>|
| IF EXISTS           | `IF EXISTS`を指定した場合、削除対象のテーブルが存在しなくてもエラーは報告されません。指定しない場合はエラーが報告されます。                                                  |
| RESTRICT \| CASCADE | 他のデータベースからOceanBaseデータベースへの移行シナリオで使用されます。 <br>**説明**  現在のバージョンではこのパラメータはサポートされていないため、指定された場合は解析され無視されます。</br> |

## 例

* `IF EXISTS`を指定し、テーブル`test1`を削除します。

  ```sql
  obclient> DROP TABLE IF EXISTS test1;
  Query OK, 0 rows affected
  ```

* `IF EXISTS`を指定し、テーブル`test1`と`test2`を同時に削除します。

  ```sql
  obclient> DROP TABLES IF EXISTS test1,test2;
  Query OK, 0 rows affected
  ```

* `IF EXISTS`を指定せず、複数のテーブルを削除する際に、いずれか一つのテーブルが存在しない場合はエラーが発生します。

  ```sql
  obclient> DROP TABLES test1,test2;
  ERROR 1051 (42S02): Unknown table 'test.test2'
  ```

* 一時テーブル`tset3`を削除します。

  ```sql
  obclient> DROP TEMPORARY TABLE test3;
  ```
