# SET ROLE

## 説明

このステートメントは、現在ログインしているユーザーが現在のセッションで付与されているロールを有効にするために使用します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>SET ROLE</code> ステートメントで有効にしたロールは、現在のセッションにのみ影響し、後のセッションには影響しません。</p>
</main>

## 構文

```sql
SET ROLE {
    DEFAULT
    | NONE
    | ALL
    | ALL EXCEPT role_name [, role_name ...]
    | role_name [, role_name ...]
};
```

## パラメータの説明

|       **パラメータ**      | **説明** |
|---------------------|----------|
| DEFAULT             | デフォルトのロール設定を維持するよう指定します。システムは、変数 `activate_all_roles_on_login` の値および `SET DEFAULT ROLE` ステートメントまたは `ALTER USER` ステートメントで設定されたデフォルトの有効なロールに基づいてロールを有効にします。<ul><li>変数 <code>activate_all_roles_on_login</code> の値が <code>on</code> の場合、セッション内でユーザーに付与されたすべてのロールを有効にします。</li><li>変数 <code>activate_all_roles_on_login</code> の値が <code>off</code> の場合、セッション内で <code>SET DEFAULT ROLE</code> ステートメントまたは <code>ALTER USER</code> ステートメントで指定されたデフォルトの有効なロールを有効にします。</li></ul>|
| NONE                | ユーザーに付与されたすべてのロールを無効にするよう指定します。|
| ALL                 | ユーザーに付与されたすべてのロールを有効にするよう指定します。|
| ALL EXCEPT          | ユーザーに付与されたロールのうち、特定のロールを除くすべてのロールを無効にするよう指定します。|
| role_name           | ロール名を指定します。複数のロールを有効にする場合は、ロール名を半角カンマ（`,`）で区切ります。|

## 例

* 現在のセッション内で、ユーザーに付与されたロールのうち、`role001` を除くすべてのロールを有効にするよう指定します。

  ```shell
  obclient [(none)]> SET ROLE ALL EXCEPT role001;
  ```

* 現在のセッション内で、ユーザーの `role001` と `role002` ロールを有効にするよう指定します。

  ```shell
  obclient [(none)]> SET ROLE role001, role002;
  ```
