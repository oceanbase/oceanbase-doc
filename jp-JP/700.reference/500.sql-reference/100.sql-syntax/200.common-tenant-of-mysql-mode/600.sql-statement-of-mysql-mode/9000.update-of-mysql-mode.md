# UPDATE

## 説明

このステートメントは、テーブル内のフィールド値を変更するために使用されます。

## 構文

```sql
UPDATE [LOW_PRIORITY] [IGNORE] table_references
    SET update_asgn_list
    [WHERE where_condition]
    [ORDER BY order_list]
    [LIMIT row_count]
    ;

table_references:
    table_name [PARTITION (partition_name,...)] [, ...]

update_asgn_list:
    column_name = expr [, ...]

order_list:
    column_name [ASC|DESC] [, column_name [ASC|DESC]...]
```

## パラメータの説明

|      **パラメータ**      |            **説明**             |
|------------------|-------------------------------|
| LOW_PRIORITY        | オプション。`UPDATE` ステートメントの実行を遅延させ、他のクライアントがテーブルからデータを読み取ることがなくなるまで待機します。現在のバージョンではこのキーワード構文のみサポートされており、機能は有効ではありません。|
| IGNORE           | `INSERT` ステートメントの実行中に発生したエラーは無視されます。 |
| table_references | テーブル名の変更を指定します。複数のテーブルを変更する場合は、テーブル名をカンマ（,）で区切ります。      |
| where_condition  | フィルタ条件を指定します。                       |
| row_count        | 制限する行数。                         |
| table_name       | 挿入するテーブル名。                         |
| partition_name   | 挿入するテーブルの指定パーティション名。                    |
| column_name      | 列名。                           |
| ASC              | 列名に基づいて昇順に変更します。                      |
| DESC             | 列名に基づいて降順に変更します。                      |

## 説明

複数テーブルでも単一テーブルでも、サブクエリに対して直接値を更新することはサポートされておらず、そうした場合エラーが発生します。例：

```sql
obclient> UPDATE (SELECT * FROM T1) SET C1 = 100;
ERROR 1288 (HY000): The target table  of the UPDATE is not updatable
```

## 例

1. サンプルテーブル `t1` と `t2` を作成します。

   ```sql
   obclient> CREATE TABLE t1(c1 INT PRIMARY KEY, c2 INT);
   Query OK, 0 rows affected
   obclient> SELECT * FROM t1;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  1 |    1 |
   |  2 |    2 |
   |  3 |    3 |
   |  4 |    4 |
   +----+------+
   4 rows in set

   obclient> CREATE TABLE t2(c1 INT PRIMARY KEY, c2 INT) PARTITION BY KEY(c1) PARTITIONS 4;
   Query OK, 0 rows affected
   obclient> SELECT * FROM t2;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  5 |    5 |
   |  1 |    1 |
   |  2 |    2 |
   |  3 |    3 |
   +----+------+
   4 rows in set
   ```

2. テーブル `t1` 内の `t1.c1=1` に対応する行データの `c2` 列の値を `100` に変更します。

   ```sql
   obclient> UPDATE t1 SET t1.c2 = 100 WHERE t1.c1 = 1;
   Query OK, 1 row affected
   Rows matched: 1  Changed: 1  Warnings: 0

   obclient> SELECT * FROM t1;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  1 |  100 |
   |  2 |    2 |
   |  3 |    3 |
   |  4 |    4 |
   +----+------+
   4 rows in set
   ```

3. テーブル `t1` 内の `c2` 列でソートした上位2行のデータの `c2` 列の値を `100` に変更します。

   ```sql
   obclient> UPDATE t1 SET t1.c2 = 100 ORDER BY c2 LIMIT 2;
   Query OK, 2 rows affected
   Rows matched: 2  Changed: 2  Warnings: 0

   obclient> SELECT * FROM t1;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  1 |  100 |
   |  2 |  100 |
   |  3 |    3 |
   |  4 |    4 |
   +----+------+
   4 rows in set
   ```

4. テーブル `t2` 内の `p2` パーティションのデータにおいて、`t2.c1 > 2` に対応する行データの `c2` 列の値を `100` に変更します。

   ```sql
   obclient> UPDATE t2 PARTITION(p2) SET t2.c2 = 100 WHERE t2.c1 > 2;
   Query OK, 1 row affected
   Rows matched: 1  Changed: 1  Warnings: 0

   obclient> SELECT * FROM t2;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  5 |    5 |
   |  1 |    1 |
   |  2 |    2 |
   |  3 |  100 |
   +----+------+
   4 rows in set
   ```

5. 複数のテーブルを変更し、`t1` テーブルと `t2` テーブルのうち `t1.c1 = t2.c1` に対応する行データの `t1` テーブル内の `c2` 列の値を `100` に、`t2` テーブル内の `c2` 列の値を `200` に変更します。

   ```sql
   obclient> UPDATE t1,t2 SET t1.c2 = 100, t2.c2 = 200 WHERE t1.c2 = t2.c2;
   Query OK, 6 rows affected
   Rows matched: 6  Changed: 6  Warnings: 0

   obclient> SELECT * FROM t1;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  1 |  100 |
   |  2 |  100 |
   |  3 |  100 |
   |  4 |    4 |
   +----+------+
   4 rows in set

   obclient> SELECT * FROM t2;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  5 |    5 |
   |  1 |  200 |
   |  2 |  200 |
   |  3 |  200 |
   +----+------+
   4 rows in set
   ```

6. 複数のテーブルを変更します。`t1` テーブルと `t2` テーブルの `p2` パーティションにおいて、`t1.c1 = t2.c1` に対応する行データの `t1` テーブル内の `c2` 列の値を `100` に、`t2` テーブル内の `c2` 列の値を `200` に変更します。

   ```sql
   obclient> UPDATE t1,t2 PARTITION(p2) SET t1.c2 = 100, t2.c2 = 200 WHERE t1.c2 = t2.c2;
   Query OK, 6 rows affected
   Rows matched: 6  Changed: 6  Warnings: 0

   obclient> SELECT * FROM t1;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  1 |  100 |
   |  2 |  100 |
   |  3 |  100 |
   |  4 |    4 |
   +----+------+
   4 rows in set

   obclient> SELECT * FROM t2;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  5 |    5 |
   |  1 |  200 |
   |  2 |  200 |
   |  3 |  200 |
   +----+------+
   4 rows in set
   ```

7. 更新可能なビュー `v` に値を更新します。

   ```sql
   obclient> CREATE VIEW v AS SELECT * FROM t1;
   Query OK, 0 rows affected

   obclient> UPDATE v SET v.c2 = 100 WHERE v.c1 = 1;
   Query OK, 1 row affected
   Rows matched: 1  Changed: 1  Warnings: 0

   obclient> SELECT * FROM v;
   +----+------+
   | c1 | c2   |
   +----+------+
   |  1 |  100 |
   |  2 |    2 |
   |  3 |    3 |
   |  4 |    4 |
   +----+------+
   4 rows in set
   ```
