# DROP MATERIALIZED VIEW

## 説明

このステートメントは、マテリアライズドビューを削除するために使用します。

## 権限要件

マテリアライズドビューのログを削除するには、`DROP TABLE` 権限が必要です。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
DROP MATERIALIZED VIEW [IF EXISTS] materialized_view_list [opt_drop_behavior];

materialized_view_list:
    [ database. ]materialized_view [,[ database. ]materialized_view]...

opt_drop_behavior:
    RESTRICT | CASCADE
```

## パラメータ説明

|       **パラメータ**    |       **説明**           |
|-------------------|--------------------------|
| IF EXISTS         | オプションです。`IF EXISTS` を指定すると、削除対象のマテリアライズドビューが存在しない場合でもエラーは報告されません。指定しない場合、削除対象のマテリアライズドビューが存在しないとエラーが発生します。 |
| database.         | オプションです。マテリアライズドビューが存在するデータベースを指定します。`database.` を省略した場合、デフォルトで自身のデータベースが使用されます。|
| materialized_view | マテリアライズドビューの名前を指定します。|
| RESTRICT \| CASCADE | オプションです。削除操作の動作を示します。<ul><li>CASCADE がデフォルト値であり、マテリアライズドビューを削除すると同時に、それに依存している他のオブジェクトも削除します。</li><li>RESTRICT は、他のオブジェクトがそのマテリアライズドビューに依存している場合、マテリアライズドビューの削除を許可しません。</li></ul>|

## 例

`test_db` データベース内の `mv_test_tbl1` という名前のマテリアライズドビューを削除します。

```sql
obclient [test_db]> DROP MATERIALIZED VIEW mv_test_tbl1;
```

実行結果は次のとおりです：

```shell
Query OK, 0 rows affected
```
