# FLUSH TABLE

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>現在のバージョンではこのキーワード構文のみがサポートされており、機能は実際には有効になりません。</p>
</main>

## 説明

このステートメントは、特定の内部キャッシュ、ログ、およびテーブルをクリーンアップまたはフラッシュするために使用されます。

## 構文

```sql
FLUSH [NO_WRITE_TO_BINLOG | LOCAL] { tables_option }

tables_option: {
    table_synonym
  | table_synonym tbl_name [, tbl_name] ...
  | table_synonym WITH READ LOCK
  | table_synonym tbl_name [, tbl_name] ... WITH READ LOCK
  | table_synonym tbl_name [, tbl_name] ... FOR EXPORT
}

table_synonym: {
    TABLE
  | TABLES
}
```

## 使用方法

テナントレベルの隠れたパラメータ `_enable_mock_stmt_flush_table` を有効にすると、`FLUSH TABLE` 構文でエラーが発生しません。このパラメータを無効にすると、ステートメントは `NOT SUPPORT` エラーを返します。

以下のコマンドを実行してこのパラメータを有効にできます：

```sql
ALTER SYSTEM SET _enable_mock_stmt_flush_table = true;
```
