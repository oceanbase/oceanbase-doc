# SET PASSWORD

## 説明

このステートメントは、OceanBaseデータベースの現在ログインしているユーザーまたは他のユーザーのパスワードを変更するために使用します。

## 使用上の制限と注意事項

* `SET PASSWORD`/`ALTER USER` によるパスワード変更後、古いパスワードの高速認証キャッシュは無効となり、古いパスワードではログインできなくなります。
* 認証文字列の形式検証：`IDENTIFIED AS`/`BY PASSWORD` は `$S$` 形式を検証し、`$A$`（`sha2`）などの誤った形式を拒否します。

## 構文

```sql
SET PASSWORD [FOR user] = password_option [RETAIN CURRENT PASSWORD];

password_option: {
PASSWORD('authstring')
|'hashstring'
}
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>オプションの句 <code>RETAIN CURRENT PASSWORD</code> は、新しいパスワードを設定すると同時に古いパスワードを保持するために使用されます。これはデュアルパスワードのシナリオで使用され、V4.4.2 BP1バージョンからサポートされています。</p>
</main>

## パラメータの説明

|  **パラメータ**  |                                                                       **説明**                                                                        |
|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| FOR user | `FOR user` 句がない場合、現在のユーザーのパスワードを変更することを意味します。正常にログインしているすべてのユーザーは、現在のユーザーのパスワードを変更できます。`FOR user` 句がある場合、指定されたユーザーのパスワードを変更することを意味します。指定されたユーザーのパスワードを変更するには、グローバル（MySQLデータベース）の `CREATE USER` 権限が必要です。 |
|password|デフォルトでは `password` は平文で送信され、カーネルで一度エンコードされます。|
| RETAIN CURRENT PASSWORD | オプションです。`=` の右側、`password_option` の後に記述します：変更前の古いパスワードを保持し、今回設定する新しいパスワードと同時に有効にすることで、デュアルパスワードの状態にします。 |

## 例

* 現在のユーザーのパスワードを変更します。

  ```sql
  obclient> SET PASSWORD = PASSWORD('**1***');
  Query OK, 0 rows affected
  ```

* `sqluser01` ユーザーのパスワードを変更します。

  ```sql
  obclient> SET PASSWORD FOR sqluser01 = PASSWORD('**2***');
  Query OK, 0 rows affected
  ```
* `sqluser01` ユーザーのパスワードを変更し、古いパスワードを保持します（デュアルパスワード）。

  ```sql
  obclient> SET PASSWORD FOR sqluser01 = PASSWORD('**2***') RETAIN CURRENT PASSWORD;
  Query OK, 0 rows affected
  ```

* シリアライズされた認証文字列（`$S$...`）を直接書き込みます。

    ```shell
    SET PASSWORD FOR user001 = PASSWORD('$S$005$ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789.');
    ```
