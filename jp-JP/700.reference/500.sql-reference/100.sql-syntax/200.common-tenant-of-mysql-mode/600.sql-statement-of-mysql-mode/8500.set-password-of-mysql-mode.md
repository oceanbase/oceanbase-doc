# SET PASSWORD

## 説明

このステートメントは、OceanBaseデータベースの現在ログインしているユーザーまたは他のユーザーのパスワードを変更するために使用されます。

## 構文

```sql
SET PASSWORD [FOR user] = password_option;

password_option: {
PASSWORD('authstring')
|'hashstring'
}
```

## パラメータの説明

|  **パラメータ**  |                                                                       **説明**                                                                        |
|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| FOR user | `FOR user` 句がない場合、現在のユーザーのパスワードを変更します。ログインに成功したすべてのユーザーは、現在のユーザーのパスワードを変更できます。`FOR user` 句がある場合、指定されたユーザーのパスワードを変更します。指定されたユーザーのパスワードを変更するには、グローバル（MySQLデータベース）の `CREATE USER` 権限が必要です。 |
|password|デフォルトでは、`password` は平文で送信され、カーネルで一度エンコードされます。|

## 例

* 現在のユーザーのパスワードを変更します。

  ```sql
  obclient> SET PASSWORD = PASSWORD('**1***');
  Query OK, 0 rows affected
  ```

* `sqluser01` ユーザーのパスワードを変更します。

  ```sql
  obclient> SET PASSWORD FOR sqluser01 = PASSWORD('**2***');
  Query OK, 0 rows affected
  ```
