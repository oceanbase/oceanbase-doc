# DROP DATABASE LINK

## 説明

このステートメントは、作成されたデータベースリンク（つまり`dblink`）を削除するために使用されます。

<main id="notice" >
   <h4>適用対象</h4>
   <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在、<code>dblink</code>機能をサポートしていません。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>作成されたデータベースリンクを削除するには、<code>DROP DATABASE LINK</code>システム権限が必要です。 </p>
</main>

## 構文

```sql
DROP DATABASE LINK [IF EXISTS] dblink_name;
```

## パラメータの説明

`dblink_name`は、削除するデータベースリンクの名前です。

## 例

```sql
obclient> DROP DATABASE LINK IF EXISTS ob_dblink;
Query OK, 1 row affected
```
