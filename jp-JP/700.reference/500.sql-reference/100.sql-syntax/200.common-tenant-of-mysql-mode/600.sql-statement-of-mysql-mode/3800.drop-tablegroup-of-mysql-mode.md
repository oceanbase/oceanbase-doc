# DROP TABLEGROUP

## 説明

このステートメントは、テーブルグループを削除するために使用されます。ただし、対象のテーブルグループを参照しているテーブルの`TABLEGROUP`プロパティがある場合、そのテーブルグループは削除できません。

## 構文

```sql
DROP TABLEGROUP [IF EXISTS] tablegroup_name;
```

## パラメータの説明

|     **パラメータ**      |                    **説明**                     |
|-----------------|-----------------------------------------------|
| tablegroup_name | テーブルグループ名。削除するテーブルグループ名が存在しない場合、また`IF EXISTS`が指定されていない場合、エラーが発生します。 |

## 例

* `Table_Group1`という名前のテーブルグループを削除します。

  ```sql
  obclient> DROP TABLEGROUP Table_Group1;
  Query OK, 0 rows affected
  ```

* 存在しないテーブルグループ`Table_Group1`を削除します。

  ```sql
  obclient> DROP TABLEGROUP Table_Group1;
  ERROR 5151 (42P01): tablegroup not exist
  ```

* `IF EXISTS`を指定して、存在しないテーブルグループ`Table_Group1`を削除します。

  ```sql
  obclient> DROP TABLEGROUP IF EXISTS Table_Group1;
  Query OK, 0 rows affected, 1 warning
  ```
