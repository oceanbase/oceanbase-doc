# ALTER INSTANCE ROTATE INNODB MASTER KEY

## 説明

`ALTER INSTANCE ROTATE INNODB MASTER KEY` ステートメントは、透過的データ暗号化（Transparent Data Encryption, TDE）を使用する際に、メインテナントのマスター暗号鍵を交換またはローテーションするために使用されます。このステートメントはパラメータを受け付けず、単一の機能、すなわち鍵のローテーションを実行します。

`ALTER INSTANCE ROTATE INNODB MASTER KEY` を実行すると、現在のマスター暗号鍵に代わる新しいマスター暗号鍵が生成されます。新しいマスター暗号鍵は設定済みのキーライブラリに安全に格納され、古いマスター暗号鍵で暗号化されたすべてのテーブルスペースのテーブルスペースページ（またはデータ）は段階的に再暗号化され、新しいマスター暗号鍵に切り替えられます。

## 使用制限と注意事項

システムテナントはこのステートメントを使用できません

システムテナントは `ALTER INSTANCE ROTATE INNODB MASTER KEY` ステートメントを使用してメインテナントのマスター暗号鍵を交換またはローテーションすることはできません。

通常テナントであれば、`ALTER INSTANCE ROTATE INNODB MASTER KEY` ステートメントを使用してメインテナントのマスター暗号鍵を交換またはローテーションできます。

## 構文

```sql
ALTER INSTANCE ROTATE INNODB MASTER KEY;
```

## パラメータ説明

|フィールド              |説明                         |
|-----------------|-----------------------------|
|ROTATE           | 古い鍵に代わる新しい鍵を生成します。 |
|INNODB MASTER KEY| MySQLモードでInnoDBストレージエンジンが使用するマスター暗号鍵です。この鍵はデータベース内のテーブルスペースを暗号化するために使用されます。  |

## 例

```shell
/* 暗号化方式を組み込みの透過的暗号化に設定します。*/
obclient> ALTER SYSTEM SET tde_method='internal';
/* 現在の暗号化方式の設定を表示します。 */
obclient> SHOW PARAMETERS LIKE 'tde_method';
/* 新しいマスター暗号鍵を生成します。*/
obclient> ALTER INSTANCE ROTATE INNODB MASTER KEY;
```
