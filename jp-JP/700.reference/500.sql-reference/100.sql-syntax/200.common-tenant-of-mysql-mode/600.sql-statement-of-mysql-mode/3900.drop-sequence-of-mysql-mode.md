# DROP SEQUENCE

## 説明

このステートメントは、シーケンスを削除するために使用されます。

## 権限要件

`DROP SEQUENCE` ステートメントを実行するには、現在のユーザーが `DROP` 管理権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## フォーマット

```sql
DROP SEQUENCE [IF EXISTS] [schema. ] sequence_name;
```

## パラメータの説明

|      パラメータ       |                            説明                             |
|---------------|-----------------------------------------------------------|
| schema.       | シーケンスを含むユーザーを指定します。`Schema` を指定しない場合、デフォルトで現在ログインしているユーザーのシーケンスが使用されます。 |
| IF EXISTS     | シーケンスが存在しない場合、エラーを報告せず、情報プロンプトを表示します。|
| sequence_name | 削除するシーケンス名を指定します。                                               |

## 例

シーケンス `seq1` を削除します。

```sql
obclient> DROP SEQUENCE IF EXISTS seq1;
Query OK, 0 rows affected
```
