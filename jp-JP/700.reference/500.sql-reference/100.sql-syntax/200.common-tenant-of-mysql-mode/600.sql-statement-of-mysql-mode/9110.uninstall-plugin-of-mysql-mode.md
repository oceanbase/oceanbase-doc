# UNINSTALL PLUGIN

## 説明

このステートメントは、インストール済みのサーバープラグインを削除するために使用されます。

## 構文

```sql
UNINSTALL PLUGIN plugin_name
```

  <h4>注意</h4>
  <p>現在のバージョンではこのキーワード構文のみがサポートされており、機能は実際には有効になりません。</p>
