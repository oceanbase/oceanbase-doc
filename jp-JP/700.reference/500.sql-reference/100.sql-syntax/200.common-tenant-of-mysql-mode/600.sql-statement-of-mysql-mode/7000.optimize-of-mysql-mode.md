# OPTIMIZE

## 説明

このステートメントは、プログレッシブメジャーコンパクションを1ラウンド開始します。

プログレッシブメジャーコンパクションのラウンド数は、テーブルの `progressive_merge_num` によって決定されます。テーブルに `progressive_merge_num` が設定されていない場合は、テナントのデフォルト値が使用されます。

* テナントレベルのメジャーコンパクションでは、sysテナントのみが他の業務テナントに対してメジャーコンパクションを開始できます。

* テーブルレベルのメジャーコンパクションでは、業務テナントは自身のテナント内のテーブルに対してメジャーコンパクションを開始できます。

## 構文

```sql
OPTIMIZE {
     TABLE table_list
   | TENANT {ALL | tenant_list}
};

table_list:
   table_name [,table_name ...]

tenant_list:
    tenant_name [,tenant_name ...]
```

## パラメータの説明

|     パラメータ      |                    説明                     |
|-------------|-------------------------------------------|
| table_name  | プログレッシブメジャーコンパクションを実行するテーブル名。                                |
| tenant_name | プログレッシブメジャーコンパクションを実行するテナント名。`ALL` はすべてのテナントを意味します。 |

## 例

`t1` テーブルに対してプログレッシブメジャーコンパクションを実行します。

```sql
obclient> OPTIMIZE TABLE t1;
Query OK, 0 rows affected
```
