# UNLOCK TABLES

## 説明

このステートメントは、現在のセッション(Session)が保持しているすべてのテーブルロックを解除します。

## 制限事項と注意点

`UNLOCK TABLES` は、トランザクションを自動的にコミットしません。

## 構文

```sql
UNLOCK {TABLE | TABLES};
```

## 構文の説明

|       **フィールド名**       | **説明** |
|--------------------------|----------|
| UNLOCK {TABLE \| TABLES} | 現在のSessionが保持しているすべてのテーブルロックを解除することを示します。`UNLOCK TABLE` は `UNLOCK TABLES` のシノニムです。|

## 例

現在のSessionが保持しているすべてのテーブルロックを解除します。

```sql
UNLOCK TABLES;
```
