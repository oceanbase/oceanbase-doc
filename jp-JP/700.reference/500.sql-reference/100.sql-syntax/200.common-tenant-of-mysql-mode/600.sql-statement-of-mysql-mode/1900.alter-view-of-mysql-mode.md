# ALTER VIEW

## 説明

このステートメントは、ビューの定義を変更するために使用されます。

## 構文

```sql
ALTER VIEW view_name [(column_name_list)] AS select_stmt;

column_name_list:
    column_name [, column_name ...]
```

## パラメータの説明

|        パラメータ        |                                                                                                                        説明                                                                                                                         |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| select_stmt      | `SELECT` ステートメントの一種です。ビューの定義を示します。このステートメントは、ベーステーブルまたは他のビューから選択することができます。                                                                                                                                                                                                      |
| column_name_list | ビューには一意の列名を持たせる必要があり、ベーステーブルと同様に重複してはなりません。デフォルトでは、`SELECT` ステートメントで取得される列名がビューの列名として使用されます。 ビューの列に明確な名前を定義するには、オプションの `column_name_list` 句を使用して、カンマで区切られたIDをリストアップします。`column_name_list` の名前の数は、`SELECT` ステートメントで取得される列数と等しくなければなりません。 `SELECT` ステートメントで取得される列は、テーブル列への単純な参照である場合もあれば、関数、定数値、演算子などを使用した式である場合もあります。 |

## 例

ビュー `v1` の定義を変更して、`t2` 内のデータを選択するようにします。

```sql
obclient> SHOW CREATE VIEW v1;
+------+-----------------------------------------------------------------------------------------------+----------------------+----------------------+
| View | Create View                                                                                   | character_set_client | collation_connection |
+------+-----------------------------------------------------------------------------------------------+----------------------+----------------------+
| v1   | CREATE VIEW `v1` AS select `test`.`T1`.`c1` AS `d1`,`test`.`T1`.`c2` AS `d2` from `test`.`T1` | utf8mb4              | utf8mb4_general_ci   |
+------+-----------------------------------------------------------------------------------------------+----------------------+----------------------+
1 row in set

obclient> ALTER VIEW v1 AS SELECT * FROM t2;
Query OK, 0 rows affected
```
