# DROP FORMAT OUTLINE

## 説明

このステートメントは、OceanBaseデータベース内のファジィアウトラインを削除するために使用されます。ファジィアウトラインを削除すると、対応するSQLが再計画を行う際に、バインドされたファジィアウトラインに基づいて計画を生成しなくなります。

## 構文

```sql
DROP FORMAT OUTLINE outline_name;
```

## パラメータの説明

|      パラメータ      |         説明         |
|--------------|--------------------|
| outline_name | 削除するファジィアウトラインの名前を指定します。 |

## 例

アウトライン`outline1`を削除します。

```shell
obclient> DROP FORMAT OUTLINE outline1;
Query OK, 0 rows affected
```
