# ANALYZE

## 説明

このステートメントは、テーブルまたはテーブルパーティションの統計情報を収集するために使用されます。

## 構文

- テーブルの特定の列のヒストグラムを更新し、バケット数を指定するには、次の構文を使用します。

```sql
ANALYZE TABLE table_name UPDATE HISTOGRAM ON column_name_list WITH INT_NUM BUCKETS;
```

- テーブルの特定の列のヒストグラムを削除するには、次の構文を使用します。

```sql
ANALYZE TABLE table_name DROP HISTOGRAM ON column_name_list;
```

- 行数と列データを含むテーブルの統計情報を収集するには、次の構文を使用します。

```sql
ANALYZE TABLE table_name [use_partition] analyze_statistics_clause;
```

- 複数のテーブルの統計情報を収集するには、次の構文を使用します。

```sql
ANALYZE TABLE tbl_name1 [, tbl_name2]...
```

テナントレベルの構成パラメータ `enable_sql_extension` が `TRUE` の場合、Oracleモードの構文を使用できます。例：

```sql
ANALYZE TABLE table_name [use_partition] COMPUTE STATISTICS [ for_clause ];

use_partition:
    PARTITION (parition_name [,partition_name,....])
   | SUBPARTITION(subpartition_name, [,subpartition_name,...])

analyze_statistics_clause:
    COMPUTE STATISTICS [analyze_for_clause]
    | ESTIMATE STATISTICS [analyze_for_clause] [SAMPLE INTNUM {ROWS | PERCENTAGE}]

analyze_for_clause:
    FOR TABLE
    | FOR ALL [INDEXED | HIDDEN] COLUMNS [size_clause]
    | FOR COLUMNS [size clause] column [size_clause] [,column [size_clause]...]

size_clause:
    SIZE integer
    | SIZE REPEAT
    | SIZE AUTO
    | SIZE SKEWONLY

column:
    column_name
    | (column_name [, column_name])

```

## パラメータの説明

| パラメータ | 説明 |
|----------------------------|----------|
| table_name | ターゲットテーブルの名前。このテーブルに対して分析操作を実行し、統計情報を収集します。|
| tbl_name1 [, tbl_name2]... | バッチテーブル分析時の構文であり、複数のテーブルを同時に指定して分析することができます。テーブル名はカンマで区切ります。|
|UPDATE HISTOGRAM ON column_name_list| この句は、ヒストグラムを更新する列を指定するために使用されます。ヒストグラムは統計情報の一種であり、オプティマイザーがデータ分布の詳細を理解するのに役立ちます。|
|DROP HISTOGRAM ON column_name_list | この句は、指定された列からヒストグラムを削除するために使用されます。ヒストグラムがもはやデータの実際の分布を反映していない、またはヒストグラムが不要になった場合に使用できます。|
| INT_NUM | 整数、つまりバケットの数です。バケットの値については、[method_opt](../../../../1000.performance-tuning-guide/500.sql-optimization/400.sql-optimization/400.optimizer-statistics/200.statistics-collection-methods/300.collect-statistics-manually.md)を参照してください。|
|WITH INT_NUM BUCKETS|この句は、ヒストグラムに必要なバケット(buckets)の数を指定するために使用されます。バケットはヒストグラム内の区間であり、各バケットはデータの範囲を表します。|
| use_partition | オプションパラメータで、パーティション名を指定します。テーブルがパーティションテーブルの場合、このパラメータを使用して、分析操作が特定のパーティションまたはサブパーティションのみに対象を絞るように指定できます。指定されていない場合、分析操作はすべてのパーティションを対象とします。テーブル名として指定された場合、パーティション統計情報は収集されません。 |
| compute_statistics_clause  | `COMPUTE STATISTICS` を指定すると、分析対象の正確な統計情報を計算し、データディクショナリに格納できます。テーブルを分析する際には、テーブルと列の両方の統計情報が同時に集計されます。 |
| for_clause                 | テーブル全体を分析するか、特定の列のみを分析するかを指定します。 <ul><li> `FOR TABLE`：テーブルの統計情報のみを収集するように指定します。   <li> `FOR COLUMNS`：指定された列とスカラーオブジェクトのプロパティ列の統計情報のみを収集するように指定します。ここで、`attribute` はオブジェクト内の特定の列名を指定します。   <li> `FOR ALL COLUMNS`：すべての列とスカラーオブジェクトのプロパティ列の統計情報を収集するように指定します。   <li> `FOR ALL INDEXED COLUMNS`：すべてのインデックス列の列統計情報を収集するように指定します。列統計情報は完全な列に基づくことも、`SIZE` を指定してヒストグラムを使用することもできます。   <li> `FOR ALL HIDDEN COLUMNS`：すべての隠れた列の列統計情報を収集するように指定します。列統計情報は完全な列に基づくことも、`SIZE` を指定してヒストグラムを使用することもできます。   <li> `SIZE`：ヒストグラム内の最大バケット数を指定します。値の範囲は \[1,2048] で、デフォルト値は `256` です。 </ul>   |
| estimate_statistics_clause | `ESTIMATE STATISTICS` を指定すると、分析対象の統計情報を推定し、データディクショナリに格納できます。   |
| SAMPLE                     | 統計情報の推定に使用する分析対象内のサンプリングデータ量を指定します。このパラメータを省略した場合、データベースオプティマイザーが自動的に適切な比率でサンプリングを行います。 <ul><li> `ROWS`：テーブル内の `integer` 行をサンプリングします。   <li> `PERCENT`：テーブル内の行の `integer` パーセントをサンプリングします。</ul>   |

## 例

* `test`テーブルの統計情報を収集し、列のバケット数を30に設定します。

```sql
obclient> CREATE TABLE test (c1 NUMBER(30) PRIMARY KEY,c2 VARCHAR(50));
Query OK, 0 rows affected

obclient> ANALYZE TABLE test UPDATE HISTOGRAM ON c1,c2 with 30 buckets;
Query OK, 0 rows affected
```

* テナントレベルの構成パラメータ`enable_sql_extension`が`TRUE`の場合、Oracleモードでユーザー`user01`のテーブル`test`の統計情報を収集し、すべての列のバケット数を128に設定します。

```sql
obclient> ALTER SYSTEM SET enable_sql_extension = TRUE;
Query OK, 0 rows affected

obclient> ANALYZE TABLE test COMPUTE STATISTICS FOR ALL COLUMNS SIZE 128;
Query OK, 0 rows affected
```
