# DROP RESTORE POINT

## 説明

このステートメントは、復元ポイント（Restore Point）を削除するために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>V4.x系では、DROP RESTORE POINTステートメントは現在サポートされていません。</li><li>システムテナントは、復元ポイントの作成および削除をサポートしていません。</li></ul></p>
  </main>

## 構文

```sql
DROP RESTORE POINT restore_point;
```

## パラメータの説明

|      パラメータ       |    説明    |
|---------------|----------|
| restore_point | 復元ポイント名を指定します。 |

## 例

1. テナントの既存の復元ポイントを確認します。

   ```sql
   obclient> SELECT * FROM V$RESTORE_POINT;
   +-----------+------------------+----------------------------+------+
   | TENANT_ID | SNAPSHOT         | TIME                       | NAME |
   +-----------+------------------+----------------------------+------+
   |      1001 | 1630407064663511 | 2021-08-31 18:51:04.665692 | rp1  |
   +-----------+------------------+----------------------------+------+
   1 row in set
   ```

2. 復元ポイント`rp1`を削除します。

   ```sql
   obclient> DROP RESTORE POINT rp1;
   Query OK, 0 rows affected
   ```
