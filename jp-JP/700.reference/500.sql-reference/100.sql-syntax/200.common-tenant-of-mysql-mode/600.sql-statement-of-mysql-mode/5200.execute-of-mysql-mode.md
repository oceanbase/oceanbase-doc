# EXECUTE

## 説明

このステートメントは、プリペアドステートメントを実行するために使用されます。

## 構文

```sql
EXECUTE stmt_name
[USING @var_name [, @var_name] ...]
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| stmt_name | プリペアドステートメントの名前。                |
| @var_name | `stmt_name` で指定したプリペアドステートメントに順番に渡す変数です。 |

## 例

プリペアドステートメントを実行します。

```sql
obclient> PREPARE stmt1 FROM 'SELECT SQRT(POW(?,2) + POW(?,2)) AS hypotenuse';
Query OK, 0 rows affected

obclient> SET @a = 3;
Query OK, 0 rows affected

obclient> SET @b = 4;
Query OK, 0 rows affected

obclient> EXECUTE stmt1 USING @a, @b;
Query OK, 0 rows affected
```
