# EXECUTE

## 説明

このステートメントは、準備済みのステートメントを実行するために使用されます。

## 構文

```sql
EXECUTE stmt_name
[USING @var_name [, @var_name] ...]
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| stmt_name | ステートメントの名前です。                |
| @var_name | `stmt_name` に含まれる変数を順に挿入します。 |

## 例

準備済みのステートメントを実行します。

```sql
obclient> PREPARE stmt1 FROM 'SELECT SQRT(POW(?,2) + POW(?,2)) AS hypotenuse';
Query OK, 0 rows affected

obclient> SET @a = 3;
Query OK, 0 rows affected

obclient> SET @b = 4;
Query OK, 0 rows affected

obclient> EXECUTE stmt1 USING @a, @b;
Query OK, 0 rows affected
```
