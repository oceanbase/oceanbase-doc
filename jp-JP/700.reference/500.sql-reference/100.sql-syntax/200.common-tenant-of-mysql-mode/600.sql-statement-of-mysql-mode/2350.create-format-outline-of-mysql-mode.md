# CREATE FORMAT OUTLINE

## 説明

このステートメントは、あいまいアウトラインを作成するために使用されます。あいまいアウトラインの作成方法は2種類あります。一つは`FORMAT_SQL_TEXT`(ユーザーが実行するパラメータ付きの元のステートメント)を使用して作成する方法、もう一つは`FORMAT_SQL_ID`を使用して作成する方法です。

## 制限事項と注意点

* アウトラインを作成するには、対応するユーザー権限で実行する必要があります。
* `FORMAT_SQL_ID`が同じ場合、`FORMAT_SQL_TEXT`方式で作成されたアウトラインは`FORMAT_SQL_ID`方式で作成されたアウトラインを上書きします。`FORMAT_SQL_TEXT`方式の優先順位が高いためです。また、OceanBaseデータベースでは`FORMAT_SQL_ID`によって異なるSQLを区別しており、`FORMAT_SQL_ID`は`FORMAT_SQL_TEXT`から`MD5`暗号化されて生成されます。実際の本番システムでは、`FORMAT_SQL_ID`を使用したアウトラインバインディングを推奨します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><ul><li><code>FORMAT_SQL_TEXT</code>のマッチングルールは、パラメータ内容、大文字と小文字、スペースや改行などの構文上の違いを無視し、これらの処理後のテキスト内容のみを比較します。</li><li><code>FORMAT_SQL_ID</code>は、<code>FORMAT_SQL_TEXT</code>をフォーマットした結果(不要なスペースや改行を削除し、すべての文字を大文字または小文字に統一変換)に対して、<code>MD5</code>ハッシュ暗号化を適用して生成されます。</li></ul></p>
  </main>

## 構文

```sql
/* FORMAT_SQL_TEXTを使用してアウトラインを作成 */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_stmt [ TO format_target_stmt ]

/* FORMAT_SQL_IDを使用してアウトラインを作成 */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_sql_id USING HINT hint;
```

## パラメータの説明

|        パラメータ          |            説明             |
|----------------------|----------------------------|
| outline_name         | 作成するファジィアウトラインの名前を指定します。|
| OR REPLACE           | `OR REPLACE` を指定し、作成するアウトラインが既に存在する場合は、既存のアウトラインを置き換えます。|
| format_stmt          | SQLの生テキスト、つまりアウトラインを適用したいSQL文または操作を指定します。 <main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベース内部では、非フォーマットされたSQLテキストを自動的にフォーマットされたSQLテキストに変換します。</p></main>|
| TO format_target_stmt | オプションで、`format_stmt` を変換または適用するターゲットSQL文を指定します。これにより、アウトラインを他のSQL文にも適用できるようになります。TO format_target_stmtオプションを使用して、これらのSQL文を宣言できます。 <main id="notice" type='notice'><h4>注意</h4><p><ul><li>Hintを含む文に対して固定計画を期待する場合は、<code>format_target_stmt</code> を使用して元のSQLを指定する必要があります。</li><li><code>TO format_target_stmt</code> 句を使用する場合、元のSQL <code>format_stmt</code> と <code>format_target_stmt</code> は、Hintを削除し、フォーマット処理を行った後に一致する必要があります。</li></ul></p></main>|
| format_sql_id        | バインドするSQLに対応する一連のルールによって書き換えられた `format_stmt` から、`format_stmt` に基づいて計算された `MD5` 値によって得られる `format_sql_id` を指定します。|

## 例

* `FORMAT_SQL_TEXT` を使用してアウトラインを作成します。

  ```sql
  CREATE FORMAT OUTLINE my_outline ON SELECT * FROM employees WHERE department_id = ?;
  ```

* `FORMAT_SQL_ID` を使用してアウトラインを作成します。

  ```sql
  CREATE FORMAT OUTLINE my_sql_id_outline ON 'ED570339F2C856BA96008A29EDF04C74' USING HINT /*+ index(t1 idx_c2)*/;

  ```
