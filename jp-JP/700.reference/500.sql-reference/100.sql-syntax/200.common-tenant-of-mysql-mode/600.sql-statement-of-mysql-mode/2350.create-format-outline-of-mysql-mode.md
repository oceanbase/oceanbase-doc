# CREATE FORMAT OUTLINE

## 説明

このステートメントは、あいまいアウトラインを作成するために使用されます。あいまいアウトラインの作成方法は2つあります。1つは `FORMAT_SQL_TEXT` を使用する方法（ユーザーが実行したパラメータ付きの元のステートメント）で、もう1つは `FORMAT_SQL_ID` を使用する方法です。

## 使用上の制限と注意事項

* アウトラインを作成するには、対応するユーザーとして実行する必要があります。

* `FORMAT_SQL_ID` が同じ場合、`FORMAT_SQL_TEXT` 方式で作成されたアウトラインは、`FORMAT_SQL_ID` 方式で作成されたアウトラインを上書きします。`FORMAT_SQL_TEXT` 方式の方が優先順位が高いです。また、OceanBaseデータベースは `FORMAT_SQL_ID` で異なるSQLを区別しており、`FORMAT_SQL_ID` は `FORMAT_SQL_TEXT` に対して `MD5` ハッシュを適用して得られます。実際の本番システムでは、`FORMAT_SQL_ID` を使用したアウトラインのバインドを推奨します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><ul><li><code>FORMAT_SQL_TEXT</code> のマッチングルールは、パラメータの変更、大文字と小文字の違い、およびスペースや改行などの構文に影響しない記号の違いを無視します。`in` 式は正規化されます。これらの処理後のテキスト内容のみが比較されます。</li><li><code>FORMAT_SQL_ID</code> は、<code>FORMAT_SQL_TEXT</code> をフォーマットした後（余分なスペースと改行を削除し、すべての文字を大文字または小文字に統一変換）、そのフォーマット済み結果に <code>MD5</code> ハッシュを適用して生成されます。</li></ul></p>
  </main>

* V4.4.2バージョンでは、V4.4.2 BP3バージョンからFormat OutlineはテキストプロトコルとPSプロトコル（Prepared Statement Protocol）の両方のシナリオをサポートしています。

## 構文

```sql
/* FORMAT_SQL_TEXT を使用してアウトラインを作成 */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_stmt [ TO format_target_stmt ]

/* FORMAT_SQL_ID を使用してアウトラインを作成 */
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_sql_id USING HINT hint;
```

## パラメータの説明

|        パラメータ          |            説明             |
|----------------------|----------------------------|
| outline_name         | 作成するあいまいアウトライン名を指定します。|
| OR REPLACE           | `OR REPLACE` を指定し、かつ作成するアウトラインが既に存在する場合、既存のアウトラインを置き換えます。|
| format_stmt          | SQLの元のテキスト、つまりアウトラインを適用したいSQLステートメントまたは操作を指定します。 <main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースは、内部的に非フォーマットされたSQLテキストをフォーマットされたSQLテキストに自動的に変換します。</p></main>|
| TO format_target_stmt | オプションです。`format_stmt` を変換または適用するターゲットSQLステートメントを指定するために使用します。つまり、アウトラインを他のSQLステートメントにも適用させるには、TO format_target_stmtオプションを使用してこれらのSQLステートメントを宣言できます。 <main id="notice" type='notice'><h4>注意</h4><p><ul><li>Hintを含むステートメントに対して固定の実行計画を使用する場合は、<code>format_target_stmt</code> を使用して元のSQLを指定する必要があります。</li><li><code>TO format_target_stmt</code> 句を使用する場合、元のSQL <code>format_stmt</code> と <code>format_target_stmt</code> は、Hintを除去し、フォーマット処理を施した後で一致している必要があります。</li></ul></p></main>|
| format_sql_id        | バインド対象のSQLを一連のルールに従って書き換えた `format_stmt` に基づき、MD5値を計算して得られる `format_sql_id` を指定します。|

## 例

* `FORMAT_SQL_TEXT` を使用してアウトラインを作成します。

  ```sql
  CREATE FORMAT OUTLINE my_outline ON SELECT * FROM employees WHERE department_id = ?;
  ```

* `FORMAT_SQL_ID` を使用してアウトラインを作成します。

  ```sql
  CREATE FORMAT OUTLINE my_sql_id_outline ON 'ED570339F2C856BA96008A29EDF04C74' USING HINT /*+ index(t1 idx_c2)*/;

  ```
