# SHOW

## 説明

このステートメントは、データベースオブジェクトの情報を表示するために使用されます。

## 構文

```sql
SHOW {
    [EXTENDED] [FULL] TABLES [{FROM | IN} database_name] [like_or_where_clause]
   | {DATABASES | SCHEMAS} [STATUS] [like_or_where_clause]
   | [EXTENDED] [FULL] {COLUMNS | FIELDS} {FROM | IN} rel_name [{FROM | IN} database_name] [like_or_where_clause]
   | TABLE STATUS [{FROM | IN} database_name] [like_or_where_clause]
   | PROCEDURE STATUS [{FROM | IN} database_name] [like_or_where_clause]
   | FUNCTION STATUS [{FROM | IN} database_name] [like_or_where_clause]
   | {GLOBAL | SESSION | LOCAL} VARIABLES [like_or_where_clause]
   | {CHARSET | CHARACTER SET} [like_or_where_clause]
   | TRACE [FORMAT='JSON']
   | COLLATION [like_or_where_clause]
   | PARAMETERS [like_or_where_clause] tenant_name
   | [EXTENDED] {INDEX | INDEXES | KEYS} {FROM | IN} table_name [{FROM | IN} database_name] WHERE opt_hint_value expr
   | [FULL] PROCESSLIST
   | TABLEGROUPS [like_or_where_clause]
   | {GLOBAL | SESSION | LOCAL} STATUS [like_or_where_clause]
   | TENANT [STATUS]
   | CREATE TENANT tenant_name
   | CREATE TABLEGROUP tablegroup_name
   | CREATE {DATABASE | SCHEMA} [IF NOT EXISTS] database_name
   | CREATE TABLE table_name
   | CREATE VIEW view_name
   | CREATE PROCEDURE proc_name
   | CREATE FUNCTION func_name
   | WARNINGS [LIMIT N | LIMIT N,M]
   | ERRORS [LIMIT N | LIMIT N,M]
   | COUNT(*) WARNINGS
   | COUNT(*) ERRORS
   | GRANTS opt_for_grant_user
   | [STORAGE] ENGINES
   | PRIVILEGES
   | RECYCLEBIN
   | SEQUENCE [like_or_where_clause]
   | FUNCTION CODE func_name
   | PROCEDURE CODE proc_name
   | ENGIN engine_name {STATUS | MUTEX}
   | OPEN TABLES [{FROM | IN} db_name] [LIKE 'pattern' | WHERE expr]
   | CREATE CATALOG external_catalog_name
   | CATALOGS
   | CREATE LOCATION location_name
   | LOCATIONS
   | FILES IN LOCATION @location_name['/path'] [PATTERN = 'regex_pattern']
};

like_or_where_clause:
    LIKE like_str [ESCAPE] esc_str
  | WHERE expr

opt_for_grant_user:
    FOR CURRENT USER
  | FOR user_name
```

## パラメータの説明

|                                       パラメータ                           |                        説明         |
|--------------------------------------------------|-------------------------------------------------------------------|
|\[EXTENDED\] \[FULL\] TABLES \{FROM \| IN} database_name                                    | `database_name`データベース内のすべてのテーブルを表示します。 <ul><li>`EXTENDED` キーワードは隠れたテーブルを表示するために使用されます。OceanBaseデータベースの現在のバージョンでは隠れたテーブルは生成されないため、このパラメータには実際の効果はありません。</li><li>`FULL` キーワードはテーブルタイプを表示するために使用されます。</li></ul>|
| {DATABASES \| SCHEMAS} \[STATUS\]                                               | 現在のテナント内のすべてのデータベースを表示します。`STATUS` キーワードはデータベースの読み書き属性を表示するために使用されます。   |
|\[EXTENDED\] \[FULL\] {COLUMNS \| FIELDS} {FROM \| IN} rel_name                              | リレーション `rel_name` の列を表示します。 <ul><li>`EXTENDED` キーワードは、データベース内部で使用される隠れた列の情報を表示するために使用されます。</li><li>`FULL` キーワードは、列の照合順序、権限、コメントを表示するために使用されます。</li></ul>|
| TABLE STATUS \[{FROM \| IN} database_name\]                                     | `database_name` データベース内のすべてのテーブルの詳細情報を表示します。  |
| PROCEDURE STATUS \[{FROM \| IN} database_name\]                                 | `database_name` データベース内のすべてのストアドプロシージャの詳細情報を表示します。     |
| FUNCTION STATUS \[{FROM \| IN} database_name\]                                  | `database_name` データベース内のすべての関数の詳細情報を表示します。   |
| {GLOBAL \| SESSION \| LOCAL} VARIABLES                                          | システム変数を表示します。  |
| {CHARSET \| CHARACTER SET}                                                      | サポートされている文字セットを表示します。    |
| TRACE [FORMAT='JSON']                                                             | SQL文の実行状況を表示します。JSON形式で出力することも選択できます。|
| COLLATION                                                                       | サポートされている照合順序を表示します。 |
| PARAMETERS \[like_or_where_clause\] tenant_name                                 | システム構成パラメータを表示します。                   |
|\[EXTENDED\] {INDEX \| INDEXES \| KEYS} {FROM \| IN} rel_name \[{FROM \| IN} database_name\] | リレーション `rel_name` 上のインデックスまたはキーを表示します。 `EXTENDED` キーワードは、データベース内部で使用される隠れたインデックスの情報を表示するために使用されます。 |
