# USE

## 説明

このステートメントは、使用するデータベースを切り替えるために使用されます。

## 構文

```sql
USE database_name
```

## パラメータの説明

|      パラメータ       |    説明     |
|---------------|-----------|
| database_name | 使用するデータベース名。 |

## 例

現在のデータベースを切り替えます。

```sql
obclient> USE test
Database changed
```
