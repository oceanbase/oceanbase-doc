# DROP VIEW

## 説明

このステートメントは、1つまたは複数のビューを削除します。
  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>現在のユーザーには、各ビューに対する <code>DROP</code> 権限が付与されていなければなりません。</p>
  </main>

## 構文

```sql
drop_view_stmt:
    DROP VIEW [IF EXISTS] view_name_list [CASCADE | RESTRICT];

view_name_list:
    view_name [, view_name_list]
```

## パラメータの説明

|       **パラメータ**        |                                                                        **説明**                                                                        |
|---------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| IF EXISTS           | `IF EXISTS` キーワードを使用すると、ビューが存在しないことによるエラーを防ぐことができます。                                                                                                                    |
| view_name_list      | `view_name_list` に存在するビューと存在しないビューが混在している場合、実行時にエラーが発生する可能性がありますが、存在するビューは削除されます。                                                                                          |
| CASCADE \| RESTRICT | `CASCADE` はカスケード削除であり、このビューに依存するオブジェクトを自動的に削除します。 `RESTRICT` は制約付き削除であり、依存オブジェクトが存在する場合、このビューの削除を拒否します。 <br>**説明**  現在のバージョンではこのパラメータはサポートされていません。指定された場合、解析されて無視されます。</br> |

## 例

* 単一のビュー `v1` を削除します。

  ```sql
  obclient> DROP VIEW v1;
  Query OK, 0 rows affected (0.02 sec)
  ```

* 複数のビュー `v1` と `v2` を削除します。

  ```sql
  obclient> DROP VIEW IF EXISTS v1,v2;
  Query OK, 0 rows affected, 1 warning (0.01 sec)
  ```

* `IF EXISTS` を使用せずに複数のビューを削除する場合、いずれかのビューが存在しないとエラーが発生します。

  ```sql
  obclient> DROP VIEW v1,v2;
  ERROR 1051 (42S02): Unknown table 'test.v1'
  ```
