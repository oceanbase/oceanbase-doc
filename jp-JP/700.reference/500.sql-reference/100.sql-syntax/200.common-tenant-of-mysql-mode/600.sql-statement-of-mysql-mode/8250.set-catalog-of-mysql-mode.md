# SET CATALOG

## 説明

このステートメントは、カタログを切り替えるために使用されます。

## 権限要件

`SET CATALOG` ステートメントを実行するには、現在のユーザーが `USE CATALOG` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
SET CATALOG {INTERNAL | external_catalog_name};
```

## パラメータ説明

|        **パラメータ**       | **説明** |
|-----------------------|----------|
| INTERNAL              | システム内部のカタログに切り替えることを示します。|
| external_catalog_name | 外部データカタログに切り替える名前を指定します。|

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>use internal.test</code> または <code>use odps_catalog.default</code> を使用して、カタログとデータベースの切り替えを一度に完了できます。</p>
</main>

## 例

* 外部データカタログ `test_odps_catalog` に切り替えます。

  ```sql
  SET CATALOG test_odps_catalog;
  ```

* システム内部カタログに切り替えます。

  ```sql
  SET CATALOG INTERNAL;
  ```
