# UNION句句

## 説明

このステートメントは、複数の`SELECT`クエリの結果に対して`UNION`、`EXCEPT`、または`INTERSECT`操作を実行するために使用されます。

## 構文

```sql
select_clause_set:
    select_clause_set_left [ UNION | UNION ALL | MINUS | EXCEPT | INTERSECT] select_clause_set_right
  [sort_list_columns] [limit_clause]
```

## パラメータの説明

|           パラメータ            |                                             説明                                             |
|-------------------------|--------------------------------------------------------------------------------------------|
| select_clause_set_left  | `SELECT` ステートメントで、集合計算用の左側のセットを返します。                                                                  |
| select_clause_set_right | `SELECT` ステートメントで、集合計算用の右側のセットを返します。                                                                  |
| sort_list_columns       | 集合計算後のグループ化方法を指定します。                                                                              |
| limit_clause            | 集合計算後に返される行数を指定します。                                                                              |
| UNION ALL               | 2つのクエリの結果を結合します。                                                                                 |
| UNION                   | 2つのクエリの結果を結合し、重複を削除します。                                                                             |
| MINUS \| EXCEPT         | 左側のクエリ結果セットから、右側のクエリに含まれる重複する結果を削除します。<br> **注記**  `MINUS` は `EXCEPT` のシノニムです。 |
| INTERSECT               | 右側のクエリに含まれる結果を左側のクエリ結果セットに保持し、重複を削除します。                                                                   |

## 例

以下の2つのテーブルのデータを例にします：

```sql
obclient> CREATE TABLE t1 (c1 INT, c2 INT);
obclient> CREATE TABLE t2 (c1 INT, c2 INT);
obclient> INSERT INTO t1 VALUES (1, -1), (2, -2);
obclient> INSERT INTO t2 VALUES (1, 1), (2, -2), (3, 3);
```

* データセット `t1`∪`t2` のすべてのレコードを照会します。

  ```sql
  obclient> SELECT c1, c2 FROM t1 UNION ALL SELECT c1, c2 FROM t2;
  +------+------+
  | c1   | c2   |
  +------+------+
  |    1 |   -1 |
  |    2 |   -2 |
  |    1 |    1 |
  |    2 |   -2 |
  |    3 |    3 |
  +------+------+
  5 rows in set
  ```

* データセット `t1`∪`t2` の重複を除いたすべてのレコードを照会します。

  ```sql
  obclient> SELECT c1, c2 FROM t1 UNION SELECT c1, c2 FROM t2;
  +------+------+
  | c1   | c2   |
  +------+------+
  |    1 |   -1 |
  |    2 |   -2 |
  |    1 |    1 |
  |    3 |    3 |
  +------+------+
  4 rows in set
  ```

* `t1` と `t2` の共通部分を照会します。

  ```sql
  obclient> SELECT c1, c2 FROM t1 INTERSECT SELECT c1, c2 FROM t2;
  +------+------+
  | c1   | c2   |
  +------+------+
  |    2 |   -2 |
  +------+------+
  1 row in set
  ```

* `t1` と `t2` の差集合を照会します。

  ```sql
  obclient> SELECT c1, c2 FROM t1 EXCEPT SELECT c1, c2 FROM t2;
  +------+------+
  | c1   | c2   |
  +------+------+
  |    1 |   -1 |
  +------+------+
  1 row in set
  ```

* `t1` と `t2` の和集合から `c2` で降順にソートした上位2行を照会します。

  ```sql
  obclient> SELECT c1, c2 FROM t1 UNION SELECT c1, c2 FROM t2 ORDER BY c2 DESC LIMIT 2;
  +------+------+
  | c1   | c2   |
  +------+------+
  |    3 |    3 |
  |    1 |    1 |
  +------+------+
  2 rows in set
  ```
