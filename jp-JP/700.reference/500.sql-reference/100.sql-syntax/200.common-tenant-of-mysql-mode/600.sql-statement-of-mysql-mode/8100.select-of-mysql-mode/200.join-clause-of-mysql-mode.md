# JOIN句句

## 説明

`JOIN`句は、テーブルの結合に使用されます。

データベース内の結合ステートメントは、結合条件に基づいてデータベース内の2つ以上のテーブルを組み合わせるために使用されます。「結合」によって生成された集合は、テーブルとして保存したり、テーブルとして使用したりできます。結合ステートメントの意味は、2つのテーブルのプロパティをそれらの値を通じて組み合わせることです。

## 構文

```sql
table_references:
    table_reference [, table_reference ...]

table_reference:
    table_factor
  | joined_table

table_factor:
    table_name [partition_option]
 [[AS] alias] [index_hint_list]
  | table_subquery [AS] alias
  | ( table_references )

joined_table:
      table_reference [NATURAL] [[INNER] | CROSS] JOIN table_factor [join_condition]
    | table_reference outer_join_type JOIN table_factor join_condition

partition_option:
    PARTITION (partition_name_list)

join_condition:
     ON expression
   | USING (join_column_list)

join_column_list:
    column_name [, column_name ...]

outer_join_type:
    [NATURAL] {LEFT | RIGHT | FULL} [OUTER]

index_hint_list:
    index_hint [, index_hint ...]

index_hint:
    {USE | FORCE | IGNORE} {KEY | INDEX}
       [FOR {JOIN | ORDER BY | GROUP BY}] (index_list)

index_list:
    index_name [, index_name ...]
```

## パラメータの説明

|               パラメータ                |                                                                                                                                                                                                         説明                                                                                                                                                                                                          |
|---------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARTITION (partition_name_list) | 接続するテーブルのパーティションを指定します。                                                                                                                                                                                                                                                                                                                                                                                                         |
| NATURAL                         | 自然結合を実行します。 `NATURAL JOIN` は、同じ列を自動的に使用して結合します。                                                                                                                                                                                                                                                                                                                                                               |
| \[INNER\] JOIN                  | 内部結合を実行します。結合条件が指定されていない場合、`INNER JOIN` はカンマ（,）と同等であり、どちらも指定されたテーブルを用いてデカルト積を生成します。<br>**注意**  カンマ（,）は演算子として、`INNER JOIN`、`CROSS JOIN`、`LEFT JOIN` などよりも優先順位が低いため、カンマを他の結合キーワードと混在させて使用すると、`ON` 句の条件に誤りが生じる可能性があります。                                                                                                                                                                                              |
| CROSS JOIN                      | OceanBaseデータベースのMySQLモードでは、`CROSS JOIN` は `JOIN`、`INNER JOIN` と同等です。                                                                                                                                                                                                                                                                                                                                                    |
| LEFT \[OUTER\] JOIN             | 左外部結合を実行します。左側のテーブルの1行が右側のテーブルで見つからない場合、右側のテーブルに自動的に`NULL`が入力されます。                                                                                                                                                                                                                                                                                                                                                                             |
| RIGHT \[OUTER\] JOIN            | 右外部結合を実行します。右側のテーブルの1行が左側のテーブルで見つからない場合、左側のテーブルに自動的に`NULL`が入力されます。                                                                                                                                                                                                                                                                                                                                                                             |
| FULL \[OUTER\] JOIN             | 外部結合を実行します。左側または右側のテーブルでマッチする行が見つからない場合、自動的に`NULL`が補完されます。                                                                                                                                                                                                                                                                                                                                                                                  |
| column_name                     | 結合に使用する列名。                                                                                                                                                                                                                                                                                                                                                                                                            |
| index_hint                      | クエリで指定されたインデックスを使用するかどうかを示します。 <ul><li> `USE`：特定の操作でインデックスを使用するように指示します。</li> <li> `FORCE`：特定の操作でインデックスを強制的に使用するように指示します。</li> <li> `IGNORE`：特定の操作でインデックスを使用しないように指示します。</li> <li> `FOR JOIN`：結合に使用するインデックスを指定します。</li> <li> `FOR ORDER BY`：ソートに使用するインデックスを指定します。</li> <li> `FOR GROUP BY`：グループ化に使用するインデックスを指定します。</li></ul>    |
| ON expression                   | 重複する列の結合条件を返します。これは、異なる名前の列を結合条件として使用する場合に適用されます。                                                                                                                                                                                                                                                                                                                                                                                       |
| USING (join_column_list)        | 重複する列を返さない結合条件であり、結合されるテーブル間で同じ名前の列を結合条件として使用します。                                                                                                                                                                                                                                                                                                                                                                                  |

## 例

以下のテーブル `a` とテーブル `b` を例にします。

![Join](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1610958261/p303134.png)

* テーブル `a` とテーブル `b` に内部結合を実行します。

  ```sql
  obclient> SELECT * FROM a JOIN b ON a.ID=b.ID;
  +------+------+------+------+
  | id   | name | id   | num  |
  +------+------+------+------+
  |    1 | A    |    1 |  100 |
  |    3 | A    |    3 |   75 |
  +------+------+------+------+
  2 rows in set
  ```

* テーブル `a` とテーブル `b` に交差結合を実行します。

  ```sql
  obclient> SELECT * FROM a CROSS JOIN b ON a.id=b.id;
  +------+------+------+------+
  | id   | name | id   | num  |
  +------+------+------+------+
  |    1 | A    |    1 |  100 |
  |    3 | A    |    3 |   75 |
  +------+------+------+------+
  2 rows in set
  ```

* テーブル `a` とテーブル `b` に自然結合を実行します。

  ```sql
  obclient> SELECT * FROM a NATURAL JOIN b;
  Empty set
  ```

* テーブル `a` とテーブル `b` に左外部結合を実行します。

  ```sql
  obclient> SELECT * FROM a LEFT JOIN b USING(ID);
  +------+------+------+
  | id   | name | num  |
  +------+------+------+
  |    1 | A    |  100 |
  |    2 | B    | NULL |
  |    3 | A    |   75 |
  +------+------+------+
  3 rows in set
  ```

* テーブル `a` とテーブル `b` に右外部結合を実行します。

  ```sql
  obclient> SELECT * FROM a RIGHT JOIN b USING(ID);
  +------+------+------+
  | id   | num  | name |
  +------+------+------+
  |    1 |  100 | A    |
  |    3 |   75 | A    |
  |    4 |   50 | NULL |
  +------+------+------+
  3 rows in set
  ```

* テーブル `a` とテーブル `b` に完全結合を実行します。

  ```sql
  obclient> SELECT * FROM a FULL JOIN b USING(ID);
  +------+------+------+
  | id   | name | num  |
  +------+------+------+
  |    1 | A    |  100 |
  |    2 | B    | NULL |
  |    3 | A    |   75 |
  |    4 | NULL |   50 |
  +------+------+------+
  4 rows in set
  ```
