# SELECT INTO

## 説明

このステートメントは、クエリ結果を変数またはファイルに格納するために使用されます。その中で：

* `SELECT ... INTO OUTFILE` は、結果セットを外部ファイルに格納し、出力形式を指定できます。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><code>SELECT ... INTO OUTFILE</code> では、<code>\N</code> を使用して <code>NULL</code> を表すことができます。</p>
    </main>

* `SELECT ... INTO DUMPFILE` は、書式なしの単一行を外部ファイルに書き込むために使用されます。

* `SELECT ... INTO var_list` は、結果セットを変数に格納するために使用されます。

## 構文

```sql
select_stmt INTO
    OUTFILE string [ {CHARSET | CHARACTER SET} charset_name] [field_opt] [line_opt]
  | DUMPFILE string
  | into_var_list

field_opt:
   {COLUMNS | FIELDS} field_term_list

line_opt:
    LINES line_term_list

field_term_list:
  field_term [, field_term ...]

field_term:
  {[OPTIONALLY] ENCLOSED | TERMINATED | ESCAPED} BY string

line_term_list:
  line_term [line_term]

line_term:
  {STARTING | TERMINATED} BY string
```

## パラメータの説明

|                  パラメータ                   |                                                                                                                                  説明                                                                                                                                  |
|---------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OUTFILE \| DUMPFILE string            | クエリ結果を`string`で指定されたファイルに保存します。                                                                                                                                                                                                                                            |
| CHARSET \| CHARACTER SET charset_name | 外部ファイルへのエクスポートに使用する文字セットを指定します。                                                                                                                                                                                                                                                       |
| {COLUMNS \| FIELDS} field_term_list   | フィールドの形式を指定します。 <ul><li> `[OPTIONALLY] ENCLOSED`：エクスポート値の修飾子を設定します。`OPTIONALLY`は曖昧さが生じる可能性のある値のみを修飾することを意味します    </li><li> `TERMINATED`：エクスポート列の終了文字を設定します。   </li><li> `ESCAPED`：エクスポート値で無視する文字を設定します。</li></ul>    |
| LINES line_term_list                  | 行の形式を指定します。 <ul><li> `STARTING`：行の開始文字を設定します。    </li><li> `TERMINATED`：行の終了文字を設定します。 </li></ul>                                                                                                          |

## 例

* クエリ結果セットをCSV形式のファイルに出力します。

  ```sql
  obclient> SELECT a,b,a+b INTO OUTFILE '/tmp/result.txt'
  FIELDS TERMINATED BY ',' OPTIONALLY ENCLOSED BY '"'
  LINES TERMINATED BY '\n'
  FROM test_table;
  ```

* テーブル `A` と `B` の完全外部結合結果を外部ファイルにエクスポートします。

  ```sql
  obclient> SELECT distinct * FROM A FULL JOIN B USING(ID) INTO OUTFILE 'test.sql'
  FIELDS TERMINATED BY ',' ENCLOSED BY '"'
  LINES TERMINATED BY '\n';
  ```
