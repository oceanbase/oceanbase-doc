# DROP OUTLINE

## 説明

このステートメントは、OceanBaseデータベース内のアウトラインを削除するために使用します。

## 構文

```sql
DROP OUTLINE outline_name
    [BINDING_RULE (binding_item)];

binding_item:
    SCOPE = {DATABASE | TENANT}
```

## パラメータの説明

|    **パラメータ**  | **説明** |
|--------------|----------|
| outline_name | 削除するアウトライン名を指定します。|
| BINDING_RULE (binding_item) | オプションです。削除するアウトラインのスコープを指定します。<ul><li>`BINDING_RULE (SCOPE = DATABASE)`：デフォルト値です。現在のデータベースをスコープとするアウトラインを削除します。`BINDING_RULE` を省略した場合も同じです。</li><li>`BINDING_RULE (SCOPE = TENANT)`：指定した名前の、複数のデータベースにまたがるテナントレベルのアウトラインを削除します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 系では、<code>BINDING_RULE</code> 句は V4.4.2 BP3 で導入されました。</p></main>|

## 例

アウトライン `ol_1` を削除します。

```shell
obclient> DROP OUTLINE ol_1;
```
