# DROP OUTLINE

## 説明

このステートメントは、OceanBaseデータベース内のアウトラインを削除するために使用します。

## 構文

```sql
DROP [FORMAT] OUTLINE outline_name
    [BINDING_RULE (binding_item)];

binding_item:
    SCOPE = {DATABASE | TENANT}
```

## パラメータの説明

|    **パラメータ**  | **説明** |
|--------------|----------|
| FORMAT | オプションです。フォーマットアウトライン（あいまいアウトライン）を削除します。フォーマットテンプレートアウトラインも含みます。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.x 系では、V4.4.2 BP4 からフォーマットテンプレートアウトラインの削除がサポートされています。</p></main>|
| outline_name | 削除するアウトライン名を指定します。|
| BINDING_RULE (binding_item) | オプションです。削除するアウトラインのスコープを指定します。<ul><li>`BINDING_RULE (SCOPE = DATABASE)`：デフォルト値です。現在のデータベースをスコープとするアウトラインを削除します。`BINDING_RULE` を省略した場合も同じです。</li><li>`BINDING_RULE (SCOPE = TENANT)`：指定した名前の、複数のデータベースにまたがるテナントレベルのアウトラインを削除します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.x 系では、<code>BINDING_RULE</code> 句は V4.4.2 BP3 で導入されました。</p></main>|

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul><li>フォーマットアウトライン（フォーマットテンプレートアウトラインを含む）を削除する場合は、<code>FORMAT</code> キーワードを指定する必要があります。<code>FORMAT</code> を指定しない場合、システムは通常のアウトラインとして検索し、同名の通常アウトラインが見つからないため <code>doesn't exist</code> エラーが発生します。</li><li>フォーマットアウトラインと通常のアウトラインは相互に独立しており、同名だがタイプが異なる2つのアウトラインは同時に存在できます。<code>FORMAT</code> を指定して個別に削除する必要があります。</li></ul>
</main>

## 例

アウトライン `ol_1` を削除します。

```shell
obclient> DROP OUTLINE ol_1;
```

フォーマットアウトライン（フォーマットテンプレートアウトラインを含む）`ol_format_1` を削除します。

```shell
obclient> DROP FORMAT OUTLINE ol_format_1;
```
