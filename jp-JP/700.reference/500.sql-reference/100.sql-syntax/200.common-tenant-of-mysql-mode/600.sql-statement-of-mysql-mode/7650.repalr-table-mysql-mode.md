# REPAIR TABLE

このステートメントは、損傷した可能性のあるテーブルを修復するために使用されます。

## 構文

```sql
REPAIR [NO_WRITE_TO_BINLOG | LOCAL]
    TABLE tbl_name [, tbl_name] ...
    [QUICK] [EXTENDED] [USE_FRM]
```

  <h4>説明</h4>
  <p>現在のバージョンではこのキーワード構文のみがサポートされており、機能はまだ有効ではありません。</p>
