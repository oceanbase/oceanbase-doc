# ビット演算子

OceanBaseデータベースは、一般的なビット演算子をサポートしています。ビット演算は `BIGINT UNSIGNED` 型で計算され、符号ビットを考慮する必要はありません。

## ビット演算子の概要

OceanBaseデータベースの現在のバージョンでサポートされているビット演算子の詳細は、次の表のとおりです。

| 演算子  | 操作数タイプ |  意味  |
|------|-------|------|
| `&`  | 二項    | 比較的論理積  |
| `|`  | 二項    | 比較的論理和  |
| `~`  | 一項    | 比較的論理反転 |
| `^`  | 二項    | 比較的論理排他和 |
| `<<` | 二項    | 論理左シフト |
| `>>` | 二項    | 論理右シフト |

## 説明

### 比較的論理積 \&

2つの操作数の2進数ビットがどちらも1の場合にのみ、結果は1になります。結果は符号なしの64ビット整数です。

例：

```sql
obclient> SELECT 28 & 15;
+---------+
| 28 & 15 |
+---------+
|      12 |
+---------+
1 row in set
```

### 比較的論理和 \|

2つの操作数の2進数ビットがどちらも0の場合にのみ、結果は0になります。結果は符号なしの64ビット整数です。

例：

```sql
obclient>  SELECT 28 | 15;
+---------+
| 28 | 15 |
+---------+
|      31 |
+---------+
1 row in set
```

### 比較的論理反転 \~

2進数ビットの0が1に、1が0に変わります。結果は符号なしの64ビット整数です。

例：

```sql
obclient> SELECT 5 & ~1;
+--------+
| 5 & ~1 |
+--------+
|      4 |
+--------+
1 row in set
```

### ビット単位の排他的論理和 \^

2つのオペランドのビットが同じ場合は0、異なる場合は1となります。結果は符号なし64ビット整数です。

例：

```sql
obclient> SELECT 1 ^ 1;
+-------+
| 1 ^ 1 |
+-------+
|     0 |
+-------+
1 row in set

obclient> SELECT 1 ^ 0;
+-------+
| 1 ^ 0 |
+-------+
|     1 |
+-------+
1 row in set

obclient> SELECT 13 ^ 5;
+--------+
| 13 ^ 5 |
+--------+
|      8 |
+--------+
1 row in set
```

### 論理左シフト \<\<

2つのオペランドのビットをすべて所定の数だけ左にシフトします。上位ビットは破棄され、下位ビットは0で補完されます。結果は符号なし64ビット整数です。この値は64ビットで切り捨てられます。シフト回数が符号なし64ビット数の幅以上の場合、結果は0となります。

以下の例では、1 (00000001) を2ビット左シフトし、右側に0を補完することで、4(00000100) を得ます。

```sql
obclient> SELECT 1 << 2;
+--------+
| 1 << 2 |
+--------+
|      4 |
+--------+
1 row in set
```

### 論理右シフト \>\>

2つのオペランドのビットをすべて所定の数だけ右にシフトします。符号なし数の場合、上位ビットは0で補完されます。結果は符号なし64ビット整数です。この値は64ビットで切り捨てられます。シフト回数が符号なし64ビット数の幅以上の場合、結果は0となります。

以下の例では、4（00000100）を2ビット右シフトし、左側に0を補完することで、1 (00000001) を得ます。

```sql
obclient> SELECT 4 >> 2;
+--------+
| 4 >> 2 |
+--------+
|      1 |
+--------+
1 row in set
```
