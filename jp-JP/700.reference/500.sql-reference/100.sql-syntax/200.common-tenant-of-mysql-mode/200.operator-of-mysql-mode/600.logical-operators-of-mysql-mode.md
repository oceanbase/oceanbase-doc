# 論理演算子

OceanBaseデータベースは一般的な論理演算子をサポートしています。

## 論理演算子の概要

OceanBaseデータベースの現行バージョンでサポートされている論理演算子の詳細は、以下の表に示されています。

|    演算子     | 演算子 |  意味  |
|------------|-----|------|
| `NOT`/`!`  | 一元  | 論理非  |
| `AND`/`&&` | 二項  | 論理積  |
| `OR`/`||`  | 二項  | 論理和  |
| `XOR`      | 複数  | 論理排他的論理和 |

## 説明

SQLでは、すべての論理演算子の計算結果は`TRUE`、`FALSE`、または`NULL (UNKNOWN)`です。OceanBaseデータベースはそれらを1(`TRUE`)、0(`FALSE`)、および`NULL`として実装し、ゼロ以外かつ`NULL`以外の値をすべて`TRUE`と評価します。

### NOT/!

オペランドが0の場合、計算結果は1です。オペランドがゼロ以外の場合、計算結果は0であり、`NOT NULL`は`NULL`返します。

例：

```sql
obclient> SELECT NOT NULL;
+----------+
| NOT NULL |
+----------+
|     NULL |
+----------+
1 row in set

obclient> SELECT ! (1+1);
+---------+
| ! (1+1) |
+---------+
|       0 |
+---------+
1 row in set
```

### AND/\&\&

すべてのオペランドがゼロ以外かつ`NULL`でない場合、計算結果は1です。1つ以上のオペランドが0の場合、計算結果は0です。それ以外の場合は`NULL`返します。

例：

```sql
obclient> SELECT 1 AND NULL;
+------------+
| 1 AND NULL |
+------------+
|       NULL |
+------------+
1 row in set

obclient> SELECT 0 AND NULL;
+------------+
| 0 AND NULL |
+------------+
|          0 |
+------------+
1 row in set
```

### OR/\|\|

2つのオペランドがどちらも`NULL`でない場合、いずれかのオペランドがゼロ以外の場合、結果は1、そうでない場合は0です。`NULL`オペランドの場合、もう一方のオペランドがゼロ以外の場合、結果は1、そうでない場合は`NULL`です。2つのオペランドがどちらも`NULL`の場合、結果は`NULL`です。

例：

```sql
obclient> SELECT 0 OR NULL;
+-----------+
| 0 OR NULL |
+-----------+
|      NULL |
+-----------+
1 row in set

obclient> SELECT 1 OR NULL;
+-----------+
| 1 OR NULL |
+-----------+
|         1 |
+-----------+
1 row in set
```

### XOR

いずれかのオペランドが`NULL`の場合、`NULL`返します。`NULL`以外のオペランドの場合、奇数個のオペランドがゼロ以外の場合、計算結果は1、そうでない場合は0返します。

例：

```sql
obclient> SELECT 1 XOR NULL;
+------------+
| 1 XOR NULL |
+------------+
|       NULL |
+------------+
1 row in set

obclient> SELECT 1 XOR 1 XOR 1;
+---------------+
| 1 XOR 1 XOR 1 |
+---------------+
|             1 |
+---------------+
1 row in set
```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>a XOR b</code>は数学的には <code>(a AND (NOT b)) OR ((NOT a) and b)</code> に等しいです。</p>
  </main>
