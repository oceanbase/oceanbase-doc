# 日付時刻演算子

OceanBaseデータベースは日付時刻演算子をサポートしており、その機能は指定された日付時刻関数と同等です。

OceanBaseデータベースの現行バージョンでサポートされている日付時刻演算子の詳細は、以下の表に示されています。

| 演算子 | 引数 |                                                    意味                                                    |
|-----|-----|----------------------------------------------------------------------------------------------------------|
| `+` | 二項演算    | 日付と時間を足す。これは `DATE_ADD` 関数と同じです。  [DATE_ADD](../400.functions-of-mysql-mode/200.single-row-functions-of-mysql-mode/100.date-and-time-functions-of-mysql-mode/900.date-add-of-mysql-mode.md)を参照してください。 |
| `-` | 二項演算    | 日付と時間を引く。これは `DATE_SUB` 関数と同じです。  [DATE_SUB](../400.functions-of-mysql-mode/200.single-row-functions-of-mysql-mode/100.date-and-time-functions-of-mysql-mode/1100.date-sub-of-mysql-mode.md)を参照してください。 |

例：

```javascript
obclient> SELECT '2008-12-31 23:59:59' + INTERVAL 1 SECOND;
+-------------------------------------------+
| '2008-12-31 23:59:59' + INTERVAL 1 SECOND |
+-------------------------------------------+
| 2009-01-01 00:00:00                       |
+-------------------------------------------+
1 row in set
```
