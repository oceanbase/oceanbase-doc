# 演算子の概要

演算子は通常、オペランドやパラメータなどの単一のデータ項目を結合して結果を返します。構文的には、演算子はオペランドの前、オペランドの後、または2つのオペランドの間に配置できます。

一般的な演算子は、単項演算子と二項演算子に分類されます：

* 単項演算子

  単項演算子は、1つのオペランドに対してのみ演算を行います。単項演算子の一般的な書式は次のとおりです：

  ```sql
  演算子 オペランド
  ```

* 二項演算子

  二項演算子は、2つのオペランドに対して演算を行います。二項演算子の一般的な書式は次のとおりです：

  ```sql
  オペランド1 演算子 オペランド2
  ```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>その他の特殊な書式を持つ演算子は、2つ以上のオペランドを受け付けることがあります。</li>
    <li>演算子に空オペランド <code>NULL</code> を指定した場合、結果は常にNULLになります。このルールに従わない唯一の例外は、文字連結演算子（||）です。</li>
    </ul>
  </main>
