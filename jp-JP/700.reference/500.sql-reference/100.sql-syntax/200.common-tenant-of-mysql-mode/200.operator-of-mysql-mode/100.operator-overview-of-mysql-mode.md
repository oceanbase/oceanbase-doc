# 演算子の概要

演算子は一般的に、オペランドやパラメータなどの単一のデータ項目を結合して結果を返すために使用されます。構文上、演算子はオペランドの前、オペランドの後、または2つのオペランドの間に記述できます。

一般的な演算子は、一元演算子と二項演算子に分類することができます：

* 一元演算子

  一元演算子は、1つのオペランドに対してのみ演算を行います。一元演算子の一般的な書式は以下のとおりです：

  ```sql
  演算子 オペランド
  ```

* 二項演算子

  二項演算子は、2つのオペランドに対して演算を行います。二項演算子の一般的な書式は以下のとおりです：

  ```sql
  オペランド1 演算子 オペランド2
  ```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>特別な書式を持つ他の演算子は、2つ以上のオペランドを受け入れることができます。</li>
    <li>演算子に空のオペランド <code>NULL</code> を提供した場合、結果は常に空になります。このルールに従わない唯一の例外は、文字連結演算子（||）です。</li>
    </ul>
  </main>
