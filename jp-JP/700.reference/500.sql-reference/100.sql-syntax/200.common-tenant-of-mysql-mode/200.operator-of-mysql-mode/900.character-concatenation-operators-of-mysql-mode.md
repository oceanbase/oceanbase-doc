# 文字列結合演算子

OceanBaseデータベースは、文字列結合演算子をサポートしています。

OceanBaseデータベースの現在のバージョンでサポートされている文字列結合演算子の詳細は、次の表のとおりです。

| 演算子  | 操作数 |  意味   |
|------|-----|-------|
| `||` | 二項  | 文字列を結合します |

`||` は論理OR演算子としても使用でき、`sql_mode` によって制御されます：

* `sql_mode` に `PIPES_AS_CONCAT` が含まれている場合、`||` は文字列結合演算子となります。

* `sql_mode` に `PIPES_AS_CONCAT` が含まれていない場合、`||` は論理OR演算子となります。
