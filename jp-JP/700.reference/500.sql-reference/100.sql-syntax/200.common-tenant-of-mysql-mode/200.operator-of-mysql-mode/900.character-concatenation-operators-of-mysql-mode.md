# 文字列結合演算子

OceanBaseデータベースは文字列結合演算子をサポートしています。

OceanBaseデータベースの現行バージョンでサポートされている文字列結合演算子の詳細は、以下の表に示されています。

| 演算子 | 引数 | 意味 |
|------|-----|-------|
| `||` | 二項式 | 文字列を結合します |

`||` は論理OR演算子として使用でき、`sql_mode` によって制御されます：

* `sql_mode` に `PIPES_AS_CONCAT` が含まれている場合、`||` は文字列結合演算子です。

* `sql_mode` に `PIPES_AS_CONCAT` が含まれていない場合、`||` は論理OR演算子です。
