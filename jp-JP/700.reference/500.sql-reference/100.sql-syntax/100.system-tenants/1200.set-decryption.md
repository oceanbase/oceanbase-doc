# SET DECRYPTION

## 説明

このステートメントは、復元用のパスワードを設定します。パスワードがバックアップ時に追加された場合にのみ、復元用のパスワードを設定する必要があります。

このステートメントはsysテナントでの実行のみをサポートしています。

## 構文

```sql
SET DECRYPTION IDENTIFIED BY  ('password'[, 'password' ...]);
```

## パラメータの説明

|    パラメータ    |                                             説明                                              |
|----------|---------------------------------------------------------------------------------------------|
| password | バックアップ時に追加するパスワード。<main id="notice" type='explain'><h4>説明</h4><p> フルバックアップと増分バックアップで設定されたパスワードが異なる場合は、複数のパスワードを入力する必要があります。パスワードはカンマで区切ります。</p></main> |

## 例

* フルバックアップと増分バックアップに同じパスワードを設定します。

  ```sql
  obclient> SET DECRYPTION IDENTIFIED BY '***1***';
  ```

* フルバックアップと増分バックアップに異なるパスワードを設定します。最初がフルバックアップのパスワード、次が増分バックアップのパスワードです。

  ```sql
  obclient> SET DECRYPTION IDENTIFIED BY '***1***','***2***';
  ```
