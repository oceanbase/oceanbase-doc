# CREATE RESOURCE UNIT

## 説明

OceanBaseデータベースはUnitを使用して物理リソースを管理します。`sys`テナントは`CREATE RESOURCE UNIT`ステートメントを使用してUnitを作成し、Unitのリソース仕様を指定できます。Unitのリソース仕様には、CPU、メモリ、ログディスクストレージ容量、IOPSなどの一般的な物理リソースが定義されています。

Unitのリソース仕様とは、単一ゾーン内の単一OBServerノードに割り当て可能な総リソース量を指します。テナントが特定のノード上にUnitを持っている場合にのみ、そのノード上のリソースを使用してデータを保存できます。

テナントに割り当てられる全リソース量は、Unit仕様 × Unit数です。

## 制限事項および注意点

Unitのリソース仕様は、単一ノードの総割り当て可能リソースを超えてはなりません。

## 権限要件

Unitを作成できるのは`sys`テナントの`root`ユーザー(`root@sys`)のみであり、他のテナントではUnitの作成はサポートされていません。

## 構文

```sql
CREATE RESOURCE UNIT [IF NOT EXISTS] unit_name
MEMORY_SIZE [=] 'size_value',
MAX_CPU [=] cpu_num,
[MAX_IOPS [=] iops_num,]
[MIN_CPU [=] cpu_num,]
[MIN_IOPS [=] iops_num,]
[IOPS_WEIGHT [=]iopsweight,]
[LOG_DISK_SIZE [=] 'size_value'];
```

## パラメータの説明

| パラメータ | 説明 |
|-----------------|----------------------------------------------------------------------------------------------------------------------------------|
| IF NOT EXISTS | オプション。作成対象のUnitが既に存在し、`IF NOT EXISTS` が指定されていない場合、システムはエラーを報告します。                                                            |
| unit_name | Unitの名前を指定します。                                                                                                                |
| MEMORY_SIZE | メモリ仕様を指定します。最小値は隠れた構成パラメータ `__min_full_resource_pool_memory` によって制御され、デフォルトは5GBです。システムの安定性を確保するため、最小メモリ仕様は4GBを推奨します。  <main id="notice" type='notice'><h4>注意</h4><p>OceanBaseデータベースはV4.0.0.0以降、メモリオーバーコミットをサポートしていません。</p></main> |
| MAX_CPU | CPU仕様の上限を指定します。最小値は1で、1コアを表します。                                                                                                      |
| MIN_CPU | CPU仕様の下限を指定します。最小値は1で、1コアを表します。オプションです。</br>指定されていない場合、デフォルト値は `MAX_CPU` と等しくなります。<main id="notice" type='notice'><h4>注意</h4><p>すべてのテナントの <code>MIN_CPU</code> の合計は、そのノードのCPU総容量 <code>CPU_CAPACITY</code> を超えてはなりません。</p></main>  |
| MAX_IOPS | IOPSの上限を指定します。最小値は1024で、指定された値は `MAX_IOPS >= MIN_IOPS` を満たす必要があります。オプションです。</br>指定されていない場合、システムは以下のルールに基づいて `MAX_IOPS` の値を自動的に計算します：<ul><li> <code>MIN_IOPS</code> の値が指定されている場合、<code>MAX_IOPS</code> の値は <code>MIN_IOPS</code> の値と等しくなります。</li> <li><code>MIN_IOPS</code> も指定されていない場合、<code>MAX_IOPS</code> と <code>MIN_IOPS</code> の値はどちらも <code>INT64_MAX</code> となります。</li></ul>                                                                |
| MIN_IOPS | IOPSの下限を指定します。最小値は1024で、オプションです。 </br>指定されていない場合、システムは以下のルールに基づいて `MIN_IOPS` の値を自動的に計算します：<ul><li> <code>MAX_IOPS</code> の値が指定されている場合、<code>MIN_IOPS</code> の値は <code>MAX_IOPS</code> の値と等しくなります。</li> <li><code>MAX_IOPS</code> も指定されていない場合、<code>MIN_IOPS</code> と <code>MAX_IOPS</code> の値はどちらも <code>INT64_MAX</code> となります。</li></ul>                                                                                                 |
| IOPS_WEIGHT | IOPSの重み値を指定します。オプションです。</br>指定しない場合、システムは次のルールに基づいて`IOPS_WEIGHT`の値を自動的に計算します。<ul><li><code>MAX_IOPS</code>と<code>MIN_IOPS</code>の両方の値が指定されている場合、またはどちらか一方の値のみが指定されている場合、<code>IOPS_WEIGHT</code>の値は<code>0</code>となります。</li> <li><code>MAX_IOPS</code>と<code>MIN_IOPS</code>の両方が指定されていない場合、<code>IOPS_WEIGHT = MIN_CPU</code>となります。</li></ul>                                                                                                            |
| LOG_DISK_SIZE | テナントログディスク容量を指定します。オプションです。</br>指定しない場合、デフォルトではメモリ仕様の3倍のサイズとなり、最小値は2GBです。|

## 例

`unit1`という名前のユニットを作成します。そのリソース仕様は以下のとおりです：CPUは4コア、メモリは`5G`、ログディスク容量は`10G`、IOPSの上限は`1280`、下限は`1024`であり、同時にIOPSの重みは`1`です。

```sql
obclient [oceanbase]> CREATE RESOURCE UNIT unit1 MAX_CPU 4, MEMORY_SIZE '5G', MAX_IOPS 1280,LOG_DISK_SIZE '10G', MIN_IOPS=1024, IOPS_WEIGHT=1;
```

ユニットの作成が成功した後、ビューを使用して作成結果を確認できます。ステートメントは以下のとおりです：

```sql
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS WHERE NAME='unit1';
```

クエリ結果は次のとおりです：

```shell

| UNIT_CONFIG_ID | NAME  | CREATE_TIME                | MODIFY_TIME                | MAX_CPU | MIN_CPU | MEMORY_SIZE | LOG_DISK_SIZE | MAX_IOPS | MIN_IOPS | IOPS_WEIGHT |
+----------------+-------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------+----------+-------------+
|           1002 | unit1 | 2023-10-30 16:33:41.182430 | 2023-10-30 16:33:41.182430 |       4 |       4 |  5368709120 |   10737418240 |     1280 |     1024 |           1 |
+----------------+-------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------+----------+-------------+
```
