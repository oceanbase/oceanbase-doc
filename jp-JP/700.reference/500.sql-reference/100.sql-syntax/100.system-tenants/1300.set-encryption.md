# SET ENCRYPTION

## 説明

このステートメントは、バックアップの暗号化パスワードを設定します。

このステートメントはセッション単位で有効です。このパスワードはバックアップ開始後にクリアされるため、バックアップパスワードを設定する場合は、毎回バックアップ開始前に再設定する必要があります。

## 構文

```sql
SET ENCRYPTION ON IDENTIFIED BY 'password' ONLY;
```

## パラメータの説明

|    パラメータ    |    説明    |
|----------|----------|
| password | バックアップの暗号化パスワード。 |

## 例

バックアップパスワードを設定します。

```sql
obclient> SET ENCRYPTION ON IDENTIFIED BY  '***1***' ONLY;
```
