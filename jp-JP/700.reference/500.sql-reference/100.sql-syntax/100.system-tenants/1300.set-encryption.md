# SET ENCRYPTION

## 説明

このステートメントは、バックアップのパスワードを設定するために使用されます。

このステートメントはセッション単位でのみ有効です。このパスワードはバックアップ開始後にクリアされるため、バックアップパスワードを設定する場合は、毎回バックアップを開始する前に再度設定する必要があります。

## 構文

```sql
SET ENCRYPTION ON IDENTIFIED BY 'password' ONLY;
```

## パラメータの説明

|    パラメータ    |    説明    |
|----------|----------|
| password | バックアップの暗号化パスワード。 |

## 例

バックアップのパスワードを設定します。

```sql
obclient> SET ENCRYPTION ON IDENTIFIED BY  '***1***' ONLY;
```
