# DROP RESOURCE POOL

## 説明

このステートメントは、リソースプールを削除するために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>テナントに割り当て済みのリソースプールは削除できません。</p>
  </main>

## 構文

```sql
DROP RESOURCE POOL pool_name;
```

## パラメータの説明

|  **パラメータ**   |   **説明**   |
|-----------|------------|
| pool_name | 削除するリソースプールの名前。 |

## 例

リソースプール `pool1` を削除します。

```sql
obclient> DROP RESOURCE POOL pool1;
Query OK, 0 rows affected
```
