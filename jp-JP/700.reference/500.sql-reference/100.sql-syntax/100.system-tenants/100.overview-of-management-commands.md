# 管理コマンドの概要

この章では、OceanBaseデータベースの管理コマンドの使用方法について説明します。一部のコマンドはsysテナントでのみ実行が許可されています。

OceanBaseデータベースの管理コマンドは、主にクラスタの管理、テナントの管理、リソースの管理、データストレージの管理、メモリの管理などに関連しています。
