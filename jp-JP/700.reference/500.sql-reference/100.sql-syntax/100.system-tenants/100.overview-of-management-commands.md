# 管理コマンドの概要

この章では、OceanBaseデータベースの管理コマンドの使用方法について説明します。一部のコマンドはsysテナントでのみ実行が許可されます。

OceanBaseデータベースの管理コマンドは、主にクラスタ管理、テナント管理、リソース管理、データストレージ管理、メモリ管理などを対象としています。
