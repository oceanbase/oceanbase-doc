# BALANCE TASK

## 説明

このステートメントは、スケジュールされていないロードバランシングタスクを削除するために使用されます。

このステートメントはsysテナントでのみ実行がサポートされています。

## 構文

```sql
ALTER SYSTEM REMOVE BALANCE TASK opt_tenant_list opt_zone_list opt_balance_task_type;

opt_tenant_list
    TENANT [=] tenant_name,tenant_name_list

opt_zone_list
    ZONE [=] zone_name, zone_list

opt_balance_task_type
    ALL
    | MANUAL
    | AUTO
```

## パラメータの説明

|        **パラメータ**       |           **説明**         |
|-----------------------|----------------------------|
| opt_tenant_list       | テナントリスト。指定されない場合、すべてのテナントのタスクを削除します。    |
| opt_zone_list         | Zoneリスト。省略可能です。   |
| opt_balance_task_type | 削除対象のタスクタイプ：<ul><li> `ALL`: すべてのタスク。</li>   <li> `AUTO`: 自動生成されたタスク。</li>   <li> `MANUAL`: ユーザーが手動で開始したタスク。</li></ul>    |

## 例

すべてのテナントのスケジュールされていないタスクをすべて削除します。

```sql
obclient> ALTER SYSTEM REMOVE BALANCE TASK；
```
