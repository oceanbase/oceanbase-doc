# RESTORE PREVIEW

## 説明

このステートメントは、元のテナントレベルのアーカイブおよびバックアップパスと希望のリストア時刻を指定し、指定された時刻にリストアするために必要なデータバックアップセット(`backup_set`)とログアーカイブ(`archivelog_piece`)をプレビューします。

## 権限要件

このステートメントを実行するには、現在のユーザーが`ALTER SYSTEM`権限を持っている必要があります。

## 構文

```sql
ALTER SYSTEM RESTORE FROM 'uri' UNTIL { TIME='timestamp' | SCN=scn } PREVIEW;
```

## パラメータの説明

|              **パラメータ**       |                     **説明**                       |
|-----------------------------|----------------------------------------------------|
| uri                         | 元のデータバックアップパス `backup_data_dest` とログアーカイブパス `log_archive_dest` を指定します。この値には少なくとも1つのデータバックアップパスと1つのログアーカイブパスを含める必要があり、パスは半角カンマ（,）で区切ります。バックアップ中にアーカイブログバックアップが実行された場合（`BACKUP_ARCHIVE_DEST` が設定されている場合）、`uri` にアーカイブバックアップの出力先パス `backup_archive_dest` を追加する必要があります。形式は `backup_data_dest,log_archive_dest,backup_archive_dest` で、複数のパスはこの順序で並べる必要があります。`BACKUP_ARCHIVE_DEST` が設定されていれば、常に `uri` にアーカイブバックアップパスを含めることができます。システムは必要に応じて対応する Piece を読み取ります。<main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、V4.4.2 BP3 以降、<code>uri</code> でアーカイブバックアップの出力先パス <code>backup_archive_dest</code> を指定できます。</p></main>|
| TIME='timestamp' \| SCN=scn | リストアしたいタイムスタンプまたはSCNを指定します。このステートメントを実行する際には、時間を明示的に指定する必要があります。|

## 例

* OSS

  * 元のデータバックアップパスとログアーカイブパスを指定し、指定されたSCN `1712650554000909004` をリストアの終点として指定し、必要なバックアップデータをプレビューします。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM RESTORE FROM 'oss://test_bucket/data?host=***&access_id=****&access_key=****, oss://test_bucket/archive?host=***&access_id=****&access_key=****' UNTIL SCN = 1712650554000909004 PREVIEW;
    ```

  * 元のデータバックアップパスとログアーカイブパスを指定し、指定されたタイムスタンプ `2024-04-09 16:15:54` をリストアの終点として指定し、必要なバックアップデータをプレビューします。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM RESTORE FROM 'oss://test_bucket/data?host=***&access_id=****&access_key=****, oss://test_bucket/archive?host=***&access_id=****&access_key=****' UNTIL TIME = '2024-04-09 16:15:54' PREVIEW;
    ```

  * 元のデータバックアップパス、ログアーカイブパス、およびアーカイブバックアップの宛先パスを指定し、指定されたタイムスタンプ `2024-04-09 16:15:54` をリストアの終点として指定し、必要なバックアップデータをプレビューします。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM RESTORE FROM 'oss://test_bucket/data?host=***&access_id=****&access_key=****, oss://test_bucket/archive?host=***&access_id=****&access_key=****, oss://test_bucket/backup_archive?host=***&access_id=****&access_key=****' UNTIL TIME = '2024-04-09 16:15:54' PREVIEW;
    ```

* NFS

  * 元のデータバックアップパスとログアーカイブパスを指定し、指定されたSCN `1712650554000909004` をリストアの終点として指定し、必要なバックアップデータをプレビューします。

    ```shell
    ALTER SYSTEM RESTORE FROM 'file:///ob_backup/data, file:///ob_backup/archive' UNTIL SCN = 1712650554000909004 PREVIEW;
    ```

  * 元のデータバックアップパスとログアーカイブパスを指定し、指定されたタイムスタンプ `2024-04-09 16:15:54` をリストアの終点として指定し、必要なバックアップデータをプレビューします。

    ```shell
    ALTER SYSTEM RESTORE FROM 'file:///ob_backup/data, file:///ob_backup/archive' UNTIL TIME = '2024-04-09 16:15:54' PREVIEW;
    ```

  * 元のデータバックアップパス、ログアーカイブパス、およびアーカイブバックアップの宛先パスを指定し、指定されたタイムスタンプ `2024-04-09 16:15:54` をリストアの終点として指定し、必要なバックアップデータをプレビューします。

    ```shell
    ALTER SYSTEM RESTORE FROM 'file:///ob_backup/data, file:///ob_backup/archive, file:///ob_backup/backup_archive' UNTIL TIME = '2024-04-09 16:15:54' PREVIEW;
    ```
