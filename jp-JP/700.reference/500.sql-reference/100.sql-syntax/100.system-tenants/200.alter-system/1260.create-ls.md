# CREATE LS

## 説明

このステートメントは、ユーザーログストリームを作成するために使用されます。

## 制限事項と注意点

* V4.2.5バージョンでは、V4.2.5 BP2以降のバージョンでのみログストリームの作成がサポートされています。
* V4.x以前のバージョンでは、OceanBaseデータベースはテナントの同一構成ゾーンモードのみをサポートしています。V4.2.5バージョンでは、V4.2.5 BP5以降のバージョンから、テナントの異種ゾーンモードがサポートされるようになりました。その中で：

  * 同一構成ゾーンモードでは、Unit Groupを指定してログストリームを作成する必要があります。
  * 異種ゾーンモードでは、UNIT_LISTを指定してログストリームを作成する必要があります。

  同一構成ゾーンモードと異種ゾーンモードの詳細な違いについては、[データ分散](../../../../../600.manage/300.replica-management/400.data-distribution.md)を参照してください。

* 現在、通常のユーザーログストリームの作成のみがサポートされており、ブロードキャストログストリームの作成はサポートされていません。

* ログストリームの作成操作は、プライマリテナント上でのみ完了できます。また、ログストリームを作成するテナントの`STATUS`と`SWITCHOVER_STATUS`は`NORMAL`である必要があります。

* ログストリームを作成する際：

  * 同一構成ゾーンモードでは、ターゲット`UNIT_GROUP`の状態が`ACTIVE`であること、およびビュー`DBA_OB_UNITS`内のターゲット`UNIT_GROUP_ID`の値が0でないことが求められます。
  * 異種ゾーンモードでは、ターゲット`UNIT_LIST`の状態が`ACTIVE`であること、および指定されたターゲット`UNIT_LIST`が空でないことが求められます。

* 作成予定のログストリームに`PRIMARY_ZONE`を指定する場合、指定されたゾーンがテナントの`ZONE_LIST`内にあることを確認する必要があります。ログストリームにおける`PRIMARY_ZONE`の設定は、テナントの`PRIMARY_ZONE`の設定と若干異なります。ログストリームでは、`z1`や`z2`などの単一のゾーンのみを設定でき、テナントのように`z1,z2`、`z1; z2`、または`RANDOM`といった複数のゾーンを指定することはできません。
* ロードバランシング関連の構成パラメータは、値を`False`として無効にすることを推奨します。そうしない場合：

  * テナントレベルの構成パラメータ[enable_rebalance](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2900.enable_rebalance.md)が有効である場合、作成されたログストリームはシステムによってターゲット`UNIT_GROUP`から他の`UNIT_GROUP`へ移行されます。

  * テナントレベルの構成パラメータ[enable_transfer](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3100.enable_transfer.md)が有効である場合、作成されたログストリームは削除される可能性があります。

## 権限要件

このステートメントを実行するユーザーは`ALTER SYSTEM`権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM CREATE LS
    {UNIT_GROUP [=] unit_group_id} | {UNIT_LIST [=] (unit_id_list) }
    [,PRIMARY_ZONE [=] 'zone_name']
    [TENANT [=] 'tenant_name'];
```

## パラメータの説明

|     **パラメータ**      |             **説明**               |
|-------------------|------------------------------------|
| unit_group_id     | 作成するログストリームのターゲットとなる`UNIT_GROUP`のIDを指定します。同一構成ゾーンモードにのみ適用されます。|
| unit_id_list      | 作成するログストリームが配置されるUnitのリストを指定します。複数のunit_idは、英字のカンマ（,）で区切ります。異種構成ゾーンモードにのみ適用されます。<main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、このパラメータはV4.2.5BP5バージョンからサポートされています。</p></main>|
| zone_name         | 作成するログストリームのターゲットとなるプライマリゾーンを指定します。`PRIMARY_ZONE`を指定しない場合、システムが自動的にゾーンを選択して割り当てます。|
| tenant_name       | オプション。操作対象のテナントを指定します。<main id="notice" type='notice'><h4>注意</h4><p>他のテナントを指定できるのはシステムテナントのみです。ユーザーテナントは自身のテナントしか指定できません。このステートメントでは、<code>ALL</code>、<code>ALL_USER</code>、<code>ALL_META</code>などを使用してすべてのテナント、ユーザーテナント、およびすべてのMetaテナントを指定することはサポートされていません。</p></main>|

## 例

:::tab
tab 同構成ゾーンモード

* システムテナント

  システムテナントは、テナント`obtenant`のためにIDが1001の`UNIT_GROUP`上にログストリームを作成します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001 TENANT = obtenant;
  ```

  システムテナントは、テナント`obtenant`のためにIDが1001の`UNIT_GROUP`上にログストリームを作成し、そのログストリームの`PRIMARY_ZONE`を`z1`に設定します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* ユーザーテナント

  ユーザーテナントは、自身のためにIDが1001の`UNIT_GROUP`上にログストリームを作成します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001;
  ```

  ユーザーテナントは、自身のためにIDが1001の`UNIT_GROUP`上にログストリームを作成し、そのログストリームの`PRIMARY_ZONE`を`z1`に設定します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1';
  ```

tab 異種ゾーンモード

* システムテナント

  システムテナントは、テナント`obtenant`のIDが1001、1002、1003の`UNIT_LIST`にログストリームを作成します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003) TENANT = obtenant;
  ```

  システムテナントは、テナント`obtenant`のIDが1001、1002、1003の`UNIT_LIST`にログストリームを作成し、そのログストリームの`PRIMARY_ZONE`を`z1`に設定します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* ユーザーテナント

  ユーザーテナントは、自身のテナントのIDが1001、1002、1003の`UNIT_LIST`にログストリームを作成します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003);
  ```

  ユーザーテナントは、自身のテナントのIDが1001、1002、1003の`UNIT_LIST`にログストリームを作成し、そのログストリームの`PRIMARY_ZONE`を`z1`に設定します。

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1';
  ```

:::
