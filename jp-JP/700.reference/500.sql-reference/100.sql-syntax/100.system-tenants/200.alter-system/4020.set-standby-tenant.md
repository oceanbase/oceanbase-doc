# SET STANDBY TENANT

## 説明

`ALTER SYSTEM SET STANDBY TENANT` ステートメントは、プライマリテナントの保護モードを設定します。

## 使用制限と注意事項

* V4.4.2バージョンでは、OceanBaseデータベースはV4.4.2 BP1バージョンから保護モードの設定をサポートしています。

* 保護モードはプライマリテナントでのみ設定できます。

* 最大パフォーマンスモードにあるプライマリテナントの保護モードを最大可用モードまたは最大保護モードに変更する場合、そのプライマリテナントには強力同期のスタンバイテナントが設定されていなければなりません。プライマリテナントに強力同期のスタンバイテナントを設定するSQLステートメントについては、[SET SYNC_STANDBY_DEST](4000.set-sync-standby-dest.md)を参照してください。

  最大保護モードまたは最大可用モードにあるテナントの保護モードは、直接最大パフォーマンスモードに変更できます。

* 連鎖的にスタンバイテナントを強力同期モードに設定することはサポートされていません。

* テナントを最大パフォーマンスモードまたは最大可用モードから最大保護モードに設定する場合、強力同期のスタンバイテナントの同期時刻とプライマリテナントの同期時刻の差は5秒を超えてはなりません。

## 権限要件

`sys`テナントの`root`ユーザー(`root@sys`)または各テナントの管理者ユーザーが実行する必要があります。具体的には：

* MySQLモードのデフォルト管理者ユーザーは`root`ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは`SYS`ユーザーです。

## 構文

```sql
ALTER SYSTEM SET STANDBY TENANT TO {MAXIMIZE PERFORMANCE} | {MAXIMIZE AVAILABILITY} | {MAXIMIZE PROTECTION} [TENANT = tenant_name];
```

## パラメータ説明

| パラメータ                    | 説明                                                                                                   |
|-------------------------|--------------------------------------------------------------------------------------------------------|
| {MAXIMIZE PERFORMANCE} \| {MAXIMIZE AVAILABILITY} \| {MAXIMIZE PROTECTION}  | 保護モードを最大パフォーマンスモード(MAXIMIZE PERFORMANCE)、最大可用モード(MAXIMIZE AVAILABILITY)、または最大保護モード(MAXIMIZE PROTECTION)のいずれかに指定します。|
| tenant_name             | システムテナントがこの操作を実行するテナント名を指定します。<main id="notice" type='notice'><h4>注意</h4><p>このコマンドを実行する際は、システムテナントのみが<code>TENANT tenant_name</code> 句を使用して操作対象のテナントを指定する必要があります。ユーザーテナントは自身のテナントでのみこのコマンドを実行できるため、この句を指定する必要はありません。</p></main> |

## 例

* システムテナントがプライマリテナントmysqlの保護モードを最大可用モードに設定します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM SET STANDBY TENANT TO MAXIMIZE AVAILABILITY TENANT = mysql;
  ```

* ユーザーテナントが自身のテナントの保護モードを最大可用モードに設定します。

  ```shell
  obclient> ALTER SYSTEM SET STANDBY TENANT TO MAXIMIZE AVAILABILITY;
  ```
