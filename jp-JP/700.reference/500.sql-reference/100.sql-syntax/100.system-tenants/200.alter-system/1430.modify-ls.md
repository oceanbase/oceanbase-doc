# LSの変更

## 説明

このステートメントは、ログストリームを変更するために使用されます。これには、ログストリームの `UNIT_GROUP`（同一ゾーンモード）または `UNIT_LIST`（異種ゾーンモード）、およびログストリームの `PRIMARY_ZONE` の変更が含まれます。

## 制限事項と注意点

* V4.2.5バージョンでは、このステートメントはV4.2.5 BP1以降のバージョンで実行する必要があります。

* V4.x以前のバージョンでは、OceanBaseデータベースはテナントの同一ゾーンモードのみをサポートしています。V4.2.5バージョンでは、V4.2.5 BP5以降のバージョンからテナントの異種ゾーンモードがサポートされています。その中で：

  * 同一ゾーンモードでは、ログストリームの分散を変更する `UNIT_GROUP` およびログストリームの `PRIMARY_ZONE` を変更できます。
  * 異種ゾーンモードでは、ログストリームの分散を変更する `UNIT_LIST` およびログストリームの `PRIMARY_ZONE` を変更できます。

* ログストリームを変更する際、変更対象のログストリームは存在していなければならず、その状態は `NORMAL` である必要があります。
* ログストリームを変更する際、変更対象のログストリームのテナントの状態は `NORMAL` である必要があります。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>V4.2.5 BP1バージョンでは、変更対象のログストリームのテナントの状態が <code>CREATING</code> または <code>DROPPING</code> であってはなりません。</p>
   </main>

* プライマリテナント上でログストリームの分散を変更する `UNIT_GROUP`（同一ゾーンモード）/`UNIT_LIST`（異種ゾーンモード）の場合、テナントのすべてのログストリームに現在ロードバランシングタスクがないことが求められます。
* スタンバイテナント上でログストリームの分散を変更する `UNIT_GROUP`（同一ゾーンモード）/`UNIT_LIST`（異種ゾーンモード）のプロパティを変更することは推奨されません。スタンバイテナントはログストリームの `UNIT_GROUP`/`UNIT_LIST` プロパティを自動的に調整するため、手動でスタンバイテナントのログストリームの `UNIT_GROUP`/`UNIT_LIST` プロパティを変更しても反映されない可能性があります。
* ログストリームの分散を変更する `UNIT_GROUP`（同一ゾーンモード）/`UNIT_LIST`（異種ゾーンモード）の場合、ターゲット `UNIT_GROUP`/`UNIT_LIST` の状態は `ACTIVE` である必要があります。
* ログストリームの `PRIMARY_ZONE` を変更する際、変更後のゾーンがテナントの `ZONE_LIST` 内にあることを確認する必要があります。ログストリームについては、テナントの `PRIMARY_ZONE` とは若干異なり、ログストリームは `z1` または `z2` のように1つのゾーンのみを設定でき、テナントのように `z1,z2`、`z1; z2`、または `RANDOM` といった複数のゾーンを設定することはできません。
* ログストリームを変更する際、テナントレベルの構成パラメータ `enable_rebalance` が無効であること、つまり値が `False` であることが求められます。`enable_rebalance` が有効な場合、テナントのロードバランシングモジュールはログストリームの `PRIMARY_ZONE` および `UNIT_GROUP`/`UNIT_LIST` プロパティを自動的に調整する可能性があります。
* 同一ゾーンモードでは、ブロードキャストログストリームとシステムログストリーム（1番目のログストリーム）のみが `UNIT_GROUP` を0に指定することをサポートしています。
* 異種ゾーンモードでは、ユーザーログストリームが指定する `UNIT_LIST` は空であってはなりません。

## 権限要件

このステートメントを実行するユーザーは `ALTER SYSTEM` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM MODIFY LS
    LS [=] ls_id
    [UNIT_GROUP [=] unit_group_id] | [UNIT_LIST [=] (unit_id_list) ]
    [,PRIMARY_ZONE [=] 'zone_name']
    [TENANT [=] 'tenant_name'];
```

## パラメータの説明

|     **パラメータ**      |             **説明**               |
|-------------------|------------------------------------|
| ls_id             | 変更対象のログストリームのIDを指定します。|
| unit_group_id     | 変更対象のログストリームのターゲットUnitグループのIDを指定します。これは同一構成ゾーンモードにのみ適用されます。このステートメントを実行する際には、ログストリームの少なくとも1つのプロパティ`UNIT_GROUP`または`PRIMARY_ZONE`を変更する必要があります。|
| unit_id_list      | 変更対象のログストリームが配置されるUnitのリストを指定します。複数のunit_idは英語のカンマ（,）で区切ります。これは異種ゾーンモードにのみ適用されます。<main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、このパラメータはV4.2.5BP5バージョンからサポートされています。</p></main>|
| zone_name         | 変更対象のログストリームのターゲットプライマリゾーンを指定します。このステートメントを実行する際には、ログストリームの少なくとも1つのプロパティ`UNIT_GROUP`または`PRIMARY_ZONE`を変更する必要があります。|
| tenant_name       | オプション。操作対象のテナントを指定します。<main id="notice" type='notice'><h4>注意</h4><p>他のテナントを指定できるのはシステムテナントのみです。ユーザーテナントは自身のテナントのみを指定できます。このステートメントでは、<code>ALL</code>、<code>ALL_USER</code>、<code>ALL_META</code>などを使用してすべてのテナント、ユーザーテナント、およびすべてのMetaテナントを指定することはサポートされていません。</p></main>|

## 例

:::tab
tab 同構成ゾーンモード

* システムテナント

  * ログストリームの `UNIT_GROUP` のみを変更

    システムテナントは、テナント `obtenant` の1002番目のログストリームの位置を1002番目の `UNIT_GROUP` に変更します。

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002 TENANT = obtenant;
    ```

  * ログストリームの `PRIMARY_ZONE` のみを変更

    システムテナントは、テナント `obtenant` の1002番目のログストリームのリーダーの第一優先順位を `z1` に変更します。

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

  * ログストリームの `UNIT_GROUP` と `PRIMARY_ZONE` を同時に変更

    システムテナントは、テナント `obtenant` の1002番目のログストリームの位置を1002番目の `UNIT_GROUP` に変更し、ログストリームのリーダーの第一優先順位を `z1` に変更します。

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

* ユーザーテナント

  * ログストリームの `UNIT_GROUP` のみを変更
