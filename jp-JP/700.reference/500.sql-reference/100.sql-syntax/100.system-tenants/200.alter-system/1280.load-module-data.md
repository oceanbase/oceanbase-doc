# LOAD MODULE DATA

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このステートメントは、V4.4.0バージョンから導入されました。</p>
</main>

## 説明

このステートメントは、特定のテナントに指定された機能をインポートするために使用します。

## 構文

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>このコマンドはSYSテナントでのみ実行が許可されています。</p>
</main>

構文は以下のとおりです：

```sql
ALTER SYSTEM LOAD MODULE DATA
 module = {gis|timezone}
 tenant = <tenant_name>
 infile = <file_name>;
```

## 構文の説明

|   **フィールド**  | **説明** |
| ----------- | -------- |
| module     | 必須。<ul><li>`module = gis`：gis機能を操作します。</li><li>`module = timezone`：timezone機能を操作します。</li></ul> |
| tenant     | 必須。指定したテナントに対して操作を実行します。|
| infile     | オプション。データファイルのパス。絶対パスまたはOBServerの作業ディレクトリに対する相対パスを指定できます。指定しない場合、内部のデフォルトファイルパスとファイル名が使用されます。|

## 例

MysQLテナントに空間データモジュール機能をインポートします：

```sql
ALTER SYSTEM LOAD MODULE DATA module=gis tenant=mysql;
```
