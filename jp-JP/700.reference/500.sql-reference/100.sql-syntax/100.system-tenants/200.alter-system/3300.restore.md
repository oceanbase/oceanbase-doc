# RESTORE

## 説明

`ALTER SYSTEM RESTORE` ステートメントは、テナントのバックアップデータをリストアするために使用します。

## 使用上の制限と注意事項

* OceanBaseデータベースの物理リストアは、同一クラスタ内でのリストアだけでなく、異なるクラスタ間でのリストアもサポートしています。

* `ALTER SYSTEM RESTORE` ステートメントを使用して物理リストアを実行する前に、リストア対象のバックアップデータのバージョンを必ず確認してください。リストア可能なバージョンの制限については、[リストア前の準備](../../../../../600.manage/600.backup-and-recovery/600.restore-data/100.preparation-before-recovery.md)を参照してください。

* `ALTER SYSTEM RESTORE` ステートメントを使用して物理リストアを実行する前に、リストア対象のテナントに必要なリソースが作成されていることを確認してください。リストア対象のテナントに必要なリソースを作成する具体的な操作については、[リストア前の準備](../../../../../600.manage/600.backup-and-recovery/600.restore-data/100.preparation-before-recovery.md)を参照してください。

* `ALTER SYSTEM RESTORE` ステートメントでリストアされたテナントは、デフォルトでスタンバイテナントとなります。サービス提供のためにプライマリテナントに切り替える必要がある場合は、`ALTER SYSTEM ACTIVATE STANDBY` ステートメントを追加で実行する必要があります。`ALTER SYSTEM ACTIVATE STANDBY` ステートメントの詳細については、[ACTIVATE STANDBY](100.activate.md)を参照してください。

## 権限要件

`ALTER SYSTEM RESTORE` ステートメントは、`sys` テナントの `root` ユーザー(`root@sys`)のみが実行できます。

## 構文

```shell
ALTER SYSTEM
   RESTORE dest_tenant_name
   FROM uri
   [ UNTIL {TIME='timestamp' | SCN=scn} ]
   WITH 'restore_option'
   [WITH KEY FROM 'backup_key_path' ENCRYPTED BY 'password']
   [DESCRIPTION [=] 'description'];

restore_option:
  pool_list=pool_name[&locality=locality][&primary_zone=zone_name][&concurrency=int_num][&kms_encrypt={true | false}][&method={full | quick}]
```

## パラメータの説明

|        **パラメータ**      |       **説明**                                                                          |
|----------------------|-----------------------------------------------------------------------------------------|
| dest_tenant_name     | リストアするテナント名を指定します。 |
| uri                  | バックアップ時に設定されたデータバックアップパス `backup_data_dest` とログアーカイブパス `log_archive_dest` を指定します。この値には少なくとも1つのデータバックアップパスと1つのログアーカイブパスが含まれ、パスは半角カンマ（,）で区切られます。バックアッププロセス中にアーカイブログバックアップ（`BACKUP_ARCHIVE_DEST`が設定されている場合）が実行された場合は、`uri` にアーカイブバックアップ宛先パス `backup_archive_dest` を追加して指定する必要があります。形式は `backup_data_dest,log_archive_dest,backup_archive_dest` で、複数のパスはこの順序で配置する必要があります。`BACKUP_ARCHIVE_DEST` が設定されている限り、リストアを開始する際に常に `uri` にアーカイブバックアップパスを含めることができ、システムは必要に応じて対応する Piece を読み取ります。ログアーカイブ宛先とアーカイブバックアップ宛先の両方で必要な Piece が存在しない場合、リストアは失敗します。現在、OceanBaseデータベースでサポートされているアーカイブ宛先メディアは、NFS、Alibaba Cloud OSS、Azure Blob、AWS S3、およびS3プロトコルに互換性のあるオブジェクトストレージです。例：Huawei OBS、Google GCS、Tencent Cloud COS。`uri` パスの例については、[SET LOG_ARCHIVE_DEST](3800.set-log-archive-dest.md)または[SET DATA_BACKUP_DEST](3500.set-data-backup-dest.md)を参照してください。<main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、V4.4.2 BP3 以降、<code>uri</code> でアーカイブバックアップ宛先パス <code>backup_archive_dest</code> を指定できるようになりました。</p></main>|
| TIME='timestamp' \| SCN=scn | リストアの終点を指定し、そのポイントまでを含むようにリストアします。`TIME` または `SCN` にリストアする場合は、`=` で指定した値を結合する必要があります。`UNTIL` 句を指定しない場合、デフォルトでは最新のポイントまでリストアされます。timestampは `YYYY-MM-DD HH24:MI:SS.FF` の形式のみをサポートし、ナノ秒単位の精度に対応します。リストア時に `timestamp` と `scn` の値を選択する方法の詳細については、[物理リストア関連パラメータの紹介](../../../../../600.manage/600.backup-and-recovery/600.restore-data/800.parameters-of-the-restore.md)を参照してください。|
| restore_option       | `pool_list`、`locality`、`primary_zone`、`concurrency`、`kms_encrypt`、`method` などのパラメータをサポートしており、異なるパラメータ間は `&` で区切ります。locality と primary_zone を指定する際は、可能な限りソーステナントと同じ構成に保つことを推奨します。構成が異なる場合、テナントのリストア後にプライマリテナントとしてアクティブ化するとロードバランシング操作が発生し、パフォーマンスに影響を与える可能性があります。<ul><li>`pool_list`：必須。リストア対象の新しいテナントに作成されたリソースプールを入力します。複数のリソースプールは半角カンマ（,）で区切ります。</li>  <li>`locality`：オプション。新しいテナントのレプリカ配置の Locality 情報を指定します。新しいテナントが配置されるクラスタの pool_list のゾーン情報と一致させる必要があります。ソーステナントと同じ構成に保つ場合、新しいテナントとソーステナントの F レプリカ数が同じであることを推奨します。明示的に指定しない場合、デフォルトでは `resource_pool` の `zone_list` に従って、各ゾーンに 1 つの F レプリカが設定されます。</br>入力例: `locality='F@z1,F@z2,F@z3'`。 </li>  <li> `primary_zone`：オプション。新しいテナントのリーダーレプリカの優先位置を指定します。`pool_list` および `locality` と一致させる必要があります。つまり、ゾーン 情報の一致および `primary_region` 内に少なくとも 2 つの Paxos メンバーが存在するという制限を満たす必要があります。ソーステナントと同じ構成に保つ場合、新しいテナントとソーステナントの第一優先順位の Primary Zone の数が同じであることを推奨します。明示的に指定しない場合、システムは `locality` の `zone_list` に従って、これらのゾーンにリーダーをランダムに配置します。</br>入力例: `primary_zone='z1'`</li> <li>`concurrency`：オプション。データリストアの並列度を指定します。明示的に指定しない場合、デフォルトでそのテナントに割り当てられた MAX_CPU の値に等しくなります。例えば、システムテナントがリストア対象のテナントに割り当てた `MAX_CPU` が 16 の場合、`concurrency` の値は 16 になります。</br>入力例: `concurrency=50`</li> <li>`kms_encrypt`：オプション。`true` の場合、リストア時にリストア前に指定された `kms_encrypt_info` を使用する必要があります。</li> <li>`method`：オプション。データリストアの方式を指定します。大文字小文字を区別せず、取り得る値は以下のとおりです：<ul><li>`full`：フルリストアを指します。明示的に指定しない場合、デフォルトは `full` になります。</li><li>`quick`：クイックリストア。</li></ul></br>入力例: `method=quick`</li></ul>   |
| WITH KEY FROM 'backup_key_path' ENCRYPTED BY 'password' | 暗号化テナントのキーバックアップ情報を指定します。ソーステナントに透過的データ暗号化が設定されている場合にのみ、リストア時にキーバックアップ関連情報を指定する必要があります。ここで：<ul><li><code>backup_key_path</code>：キーのバックアップパス。</li> <li><code>password</code>：キーのバックアップ時に設定された暗号化パスワード。</li></ul> |
| description          | ユーザーが指定する説明情報です。オプションです。 |

## 例

* NFSデータバックアップパスとNFSログアーカイブパスから、テナント `mysql` を指定されたタイムスタンプ `2022-06-01 00:00:00` までリストアします。リソースプールを `restore_pool`、レプリカ Locality を `F@z1,F@z2,F@z3` に指定し、`primary_zone` を `z1` に指定して、フルリストアモードでリストアします。

  ```shell
  obclient [oceanbase]> ALTER SYSTEM RESTORE mysql FROM 'file:///data/nfs/backup/data,file:///data/nfs/backup/archive' UNTIL TIME='2022-06-01 00:00:00' WITH 'pool_list=restore_pool&locality=F@z1,F@z2,F@z3&primary_zone=z1';
  ```

* NFSデータバックアップパスとNFSログアーカイブパスから、テナント `mysql` を現在の最新のアーカイブポイントまでリストアします。リソースプールを `restore_pool` に指定し、データリストアの並列度 `concurrency` を 50 に指定して、フルリストアモードでリストアします。

  ```shell
  obclient [oceanbase]> ALTER SYSTEM RESTORE mysql FROM 'file:///data/nfs/backup/data,file:///data/nfs/backup/archive' WITH 'pool_list=restore_pool&concurrency=50';
  ```

* NFSデータバックアップパスとNFSログアーカイブパスから、テナント `mysql` を指定されたSCNまでリストアします。リソースプールを `restore_pool` に指定して、クイックリストアモードでリストアします。

  ```shell
  obclient [oceanbase]> ALTER SYSTEM RESTORE mysql FROM 'file:///data/nfs/backup/data,file:///data/nfs/backup/archive' UNTIL SCN=1658285759724047000 WITH 'pool_list=restore_pool&method=quick';
  ```

* NFSデータバックアップパス、NFSログアーカイブパス、およびNFSアーカイブバックアップ宛先パスから、テナント `mysql` を指定されたタイムスタンプ `2022-06-01 00:00:00` までリストアします。リソースプールを `restore_pool` に指定して、フルリストアモードでリストアします。

  ```shell
  obclient [oceanbase]> ALTER SYSTEM RESTORE mysql FROM 'file:///data/nfs/backup/data,file:///data/nfs/backup/archive,file:///data/nfs/backup/backup_archive' UNTIL TIME='2022-06-01 00:00:00' WITH 'pool_list=restore_pool';
  ```

* OSSバックアップパスとOSSログアーカイブパスから、テナント `mysql` を指定されたタイムスタンプ `2022-06-01 00:00:00` までリストアします。リソースプールを `restore_pool` に指定して、フルリストアモードでリストアします。

  ```shell
  obclient [oceanbase]> ALTER SYSTEM RESTORE mysql FROM 'oss://oceanbase-test-bucket/backup/data/?host=***.aliyun-inc.com&access_id=***&access_key=***,oss://oceanbase-test-bucket/backup/archive/?host=***.aliyun-inc.com&access_id=***&access_key=***' UNTIL TIME='2022-06-01 00:00:00' WITH 'pool_list=restore_pool';
  ```

* S3バックアップパスとS3ログアーカイブパスから、テナント`mysql`を指定タイムスタンプ`2024-01-15 00:00:00`までリストアし、リソースプールを`restore_pool`に指定します。

  ```shell
  obclient [oceanbase]> ALTER SYSTEM RESTORE mysql FROM 's3://oceanbase-test-bucket/backup/data?host=s3.<region>.amazonaws.com&access_id=***&access_key=***&s3_region=***, s3://oceanbase-test-bucket/backup/archive?host=s3.<region>.amazonaws.com&access_id=***&access_key=***&s3_region=***' UNTIL TIME='2024-01-15 00:00:00' WITH 'pool_list=restore_pool';
  ```

  + `s3_region`は、S3のバケットが配置されているリージョンを表します。

* OBSバックアップパスとログアーカイブパスから、テナント`mysql`を指定タイムスタンプ`2023-06-01 00:00:00`までリストアし、リソースプールを`restore_pool`に指定して、フルリストアモードでリストアします。

  ```shell
   obclient> ALTER SYSTEM RESTORE mysql FROM 's3://oceanbase-test-bucket/backup/data/?host=obs.***.myhuaweicloud.com&access_id=***&access_key=***,s3://oceanbase-test-bucket/backup/archive/?host=obs.***.myhuaweicloud.com&access_id=***&access_key=***' UNTIL TIME='2023-06-01 00:00:00' WITH 'pool_list=restore_pool';
  ```

* GCSバックアップパスとログアーカイブパスから、テナント`mysql`を指定タイムスタンプ`2023-06-01 00:00:00`までリストアし、リソースプールを`restore_pool`に指定して、フルリストアモードでリストアします。

  ```shell
  obclient> ALTER SYSTEM RESTORE mysql FROM 's3://oceanbase-test-bucket/backup/data/?host=https://storage.googleapis.com&access_id=***&access_key=***,s3://oceanbase-test-bucket/backup/archive/?host=https://storage.googleapis.com&access_id=***&access_key=***' UNTIL TIME='2023-06-01 00:00:00' WITH 'pool_list=restore_pool';
  ```

* COSバックアップパスとログアーカイブパスから、テナント`mysql`を指定タイムスタンプ`2023-06-01 00:00:00`までリストアし、リソースプールを`restore_pool`に指定して、フルリストアモードでリストアします。

  ```shell
  obclient> ALTER SYSTEM RESTORE mysql FROM 's3://oceanbase-test/backup/data?host=cos.ap-***x.myqcloud.com&access_id=***&access_key=***,s3://oceanbase-test/backup/archive?host=cos.ap-***x.myqcloud.com&access_id=***&access_key=***' UNTIL TIME='2023-06-01 00:00:00' WITH 'pool_list=restore_pool';
  ```
