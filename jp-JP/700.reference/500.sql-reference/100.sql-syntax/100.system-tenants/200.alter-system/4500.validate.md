# VALIDATE

## 説明

`ALTER SYSTEM VALIDATE` ステートメントは、物理バックアップの検証を実行するために使用されます。

## 使用上の制限と注意事項

* V4.4.2バージョンでは、V4.4.2 BP2バージョン以降で `ALTER SYSTEM VALIDATE` ステートメントがサポートされています。

* 検証タスクは頻繁にバックアップメディアにアクセスしてデータを読み取るため、バックアップタスクのネットワークリソースを占有します。そのため、ユーザーテナントがバックアップタスクを実行しておらず、負荷が低い時に検証タスクを実行することを推奨します。

* バックアップ検証の検証レベルを指定する場合：

  * V4.4.2バージョンでは、V4.4.2 BP2バージョン（V4.4.2 BP2バージョンを除く）以前のバックアップセットおよびログアーカイブピースについては、Basic検証、すなわちファイルの整合性検証はサポートされていません。

  * V4.3.4バージョン（V4.3.4バージョンを除く）以前のバックアップセットについては、Physical検証、すなわち物理データの正確性および論理的一致性検証はサポートされていません。

## 権限要件

`sys` テナントの `root` ユーザー（`root@sys`）が実行する必要があります。

## 構文

```sql
ALTER SYSTEM VALIDATE { BACKUP | BACKUPSET [= 'backup_set_id_list'] | ARCHIVELOG_PIECE [= 'piece_id_list'] }
    [ DATA_BACKUP_DEST = 'data_backup_path' ]
    [ LOG_ARCHIVE_DEST = 'log_archive_path' ]
    [ LEVEL = { 'basic' | 'physical' } ]
    [ TENANT = tenant_name ];

backup_set_id_list:
    backup_set_id[,backup_set_id,...]

piece_id_list:
    piece_id[,piece_id,...]
```

## パラメータ説明

|      パラメータ        |        説明                                             |
|------------------|---------------------------------------------------------|
| BACKUP           | 現在のクラスタ内のユーザーテナント配下の、すべてのバックアップパスおよびアーカイブパス下のすべてのバックアップセットとログアーカイブピースを検証します。検証パス（`DATA_BACKUP_DEST` または `LOG_ARCHIVE_DEST`）の指定はサポートされていないため、クラスタ間やコールドスタンバイデータシナリオはサポートされていません。|
| BACKUPSET        | 指定したバックアップセットを検証します。バックアップセットの `backup_set_id` を指定しない場合、現在のバックアップパス下のすべてのバックアップセットを検証します。<main id="notice" type='notice'><h4>注意</h4><p><code>backup_set_id</code> を指定しない場合、システムは現在設定されているバックアップパス下のすべてのバックアップセットを取得して検証するため、多数の検証タスクが生成され、時間がかかります。すべてのバックアップセットを検証する必要がない場合は、検証コマンドで <code>backup_set_id</code> を指定することを推奨します。</p></main> |
| ARCHIVELOG_PIECE | 指定したログアーカイブピースを検証します。アーカイブピースの `piece_id` を指定しない場合、現在のアーカイブパス下のすべてのログアーカイブピースを検証します。 <main id="notice" type='notice'><h4>注意</h4><p><code>piece_id</code> を指定しない場合、システムは現在設定されているアーカイブパス下のすべてのアーカイブピースを取得して検証するため、多数の検証タスクが生成され、時間がかかります。すべてのアーカイブピースを検証する必要がない場合は、検証コマンドで <code>piece_id</code> を指定することを推奨します。</p></main>|
| DATA_BACKUP_DEST | 検証対象のデータバックアップパスを指定するオプションパラメータです。このパラメータを指定しない場合、デフォルトでテナントの現在のバックアップ設定のバックアップパスが検証されます。 <main id="notice" type='notice'><h4>注意</h4><p>OceanBaseデータベースは、単一のコマンドで複数のパスを指定することを現在サポートしていません。そのため、<code>backup_set_id</code> を指定してパス内の増分バックアップセットを検証しようとした際、その増分バックアップセットが依存する他のバックアップセット情報を読み取れないため、エラー9120が発生する可能性があります。</p></main> |
| LOG_ARCHIVE_DEST | 検証対象のログアーカイブパスを指定するオプションパラメータです。このパラメータを指定しない場合、デフォルトでテナントの現在のアーカイブ設定のアーカイブパスが検証されます。 |
| LEVEL            | 検証レベルを指定するオプションパラメータです。<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一致性を同時にチェックします。</li></ul><p>このパラメータを指定しない場合、デフォルトは `physical` です。</p>|
| TENANT           | 検証タスクを実行するユーザーテナントを指定します。<ul><li>検証パス `DATA_BACKUP_DEST` または `LOG_ARCHIVE_DEST` が指定されていない場合、このパラメータはオプションです。検証対象のユーザーテナントを指定している場合は、指定されたユーザーテナントが検証されます。指定しない場合、デフォルトでクラスタ内のすべてのテナントが検証されます。</li> <li>検証パス `DATA_BACKUP_DEST` または `LOG_ARCHIVE_DEST` が指定されている場合、このパラメータは必須であり、検証タスクを実行するユーザーテナントを指定する必要があります。  |

## 例

### 全体のバックアップパスとアーカイブパス下のすべてのバックアップセットとログアーカイブピースを検証する

* システムテナントは、クラスタ内のすべてのユーザーテナントについて、現在のバックアップおよびアーカイブパス下のすべてのバックアップセットとアーカイブピースに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUP LEVEL = 'basic';
  ```

* システムテナントは、指定されたユーザーテナント`mysqltenant`の現在のバックアップおよびアーカイブパス下のすべてのバックアップセットとアーカイブピースに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUP LEVEL = 'physical' TENANT = mysqltenant;
  ```

### 指定されたバックアップセットまたはログアーカイブピースの検証

**バックアップセットの検証**

* システムテナントは、すべてのユーザーテナントの現在のバックアップパス下のすべてのバックアップセットに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUPSET LEVEL = 'basic';
  ```

* システムテナントは、ユーザーテナント`mysqltenant`の現在のバックアップパス下のすべてのバックアップセットに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUPSET LEVEL = 'basic' TENANT = mysqltenant;
  ```

* システムテナントは、ユーザーテナント`mysqltenant`の現在のバックアップパス下で`backup_set_id`が1および2のバックアップセットに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUPSET = '1,2' LEVEL = 'physical' TENANT = mysqltenant;
  ```

* システムテナントは、すべてのユーザーテナントの現在のバックアップパス下で`backup_set_id`が1および2のバックアップセットに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUPSET = '1,2' LEVEL = 'physical';
  ```

**ログアーカイブピースの検証**

* システムテナントは、すべてのユーザーテナントの現在のアーカイブパス下のすべてのアーカイブピースに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE LEVEL = 'basic';
  ```

* システムテナントは、ユーザーテナント`mysqltenant`の現在のアーカイブパス下のすべてのアーカイブピースに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE LEVEL = 'basic' TENANT = mysqltenant;
  ```

* システムテナントは、ユーザーテナント`mysqltenant`の現在のアーカイブパス下で`piece_id`が1および2のログアーカイブピースに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE = '1,2' LEVEL = 'physical' TENANT = mysqltenant;
  ```

* システムテナントは、すべてのユーザーテナントの現在のアーカイブパス下で`piece_id`が1および2のログアーカイブピースに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE = '1,2' LEVEL = 'physical';
  ```

### 指定パス下のバックアップセットまたはログアーカイブピースの検証

**バックアップセットの検証**

* システムテナントは、指定されたユーザーテナント`mysqltenant`の指定されたバックアップパス下にあるすべてのバックアップセットに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUPSET DATA_BACKUP_DEST = 'file:///data/nfs/backup/data' LEVEL = 'basic' TENANT = mysqltenant;
  ```

* システムテナントは、指定されたユーザーテナント`mysqltenant`の指定されたバックアップパス下で`backup_set_id`が1および2のバックアップセットに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUPSET = '1,2' DATA_BACKUP_DEST = 'file:///data/nfs/backup/data' LEVEL = 'physical' TENANT = mysqltenant;
  ```

**検証ログアーカイブPiece**

* システムテナントは、指定されたアーカイブパス下のすべてのアーカイブPieceに対してBasic検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE LOG_ARCHIVE_DEST = 'file:///data/nfs/backup/archive' LEVEL = 'basic' TENANT = tenant1;
  ```

* システムテナントは、指定されたアーカイブパス下で`piece_id`が1および2のログアーカイブPieceに対してPhysical検証を実行します。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE ARCHIVELOG_PIECE = '1,2' LOG_ARCHIVE_DEST = 'file:///data/nfs/backup/archive' LEVEL = 'physical' TENANT = tenant1;
  ```
