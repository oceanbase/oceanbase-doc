# SERVICE_NAME

## 説明

`ALTER SYSTEM {CREATE | DELETE | START | STOP} SERVICE ...` ステートメントは、`SERVICE_NAME`（サービス名）のメンテナンスを行い、`SERVICE_NAME` の作成、削除、起動、停止などの操作を制御します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OCPを使用してサービス名の管理とプライマリ/スタンバイ切り替え操作を行うには、<a href="https://www.oceanbase.com/docs/common-ocp-1000000001127007">プライマリ/スタンバイテナントの日常的な切り替え</a>を参照してください。</p>
</main>

## 制限事項と注意点

* `META`/`SYS` テナントは `SERVICE_NAME` 機能をサポートしていません。
* OceanBaseクラウドプラットフォーム(OceanBase Cloud Platform、OCP)は、管理するクラスタ内で一つの `SERVICE_NAME` に対してプライマリテナントが一つしか存在しないことを保証します。ユーザーがコマンドラインで `SERVICE_NAME` を設定する場合は、その設定を自ら確認する必要があります。
* `FAILOVER` 操作では、テナント内のすべての `SERVICE_NAME` が自動的に削除されます。
* 一つのテナントには最大一つの `SERVICE_NAME` しか存在できません。
* `SERVICE_NAME` によって確立された接続では、`SERVICE_NAME` およびテナントのプライマリ/スタンバイロール変換に関連する運用コマンドの実行は許可されておらず、実行しようとすると `OB_OP_NOT_ALLOW` エラーが報告されます。

## 権限要件

このステートメントを実行するユーザーは `ALTER SYSTEM` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM {CREATE | DELETE | START | STOP} SERVICE service_name [tenant = 'tenant_name'];
```

## パラメータの説明

|    **パラメータ**   |      **説明**      |
|---------------|--------------------|
| CREATE        | サービスを作成します。サービスの作成後、自動的にサービスが起動されます。|
| DELETE        | サービスを削除します。サービスを削除する前に、サービスは停止されている必要があります。|
| START         | サービスを起動します。サービスの起動後、この `SERVICE_NAME` を使用してセッションを確立したり、リクエストを許可したりできます。|
| STOP          | サービスを停止します。サービスの停止後、この `SERVICE_NAME` で起動されたセッションは存在せず、またこの `SERVICE_NAME` を使用して新しいセッションを確立することもできません。|
| service_name  | サービス名を指定します。|
| tenant_name   | オプションで、操作対象のテナントを指定します。操作対象のテナントを明示的に指定しない場合、デフォルトのテナント名は現在のテナント名になります。<main id="notice" type='notice'><h4>注意</h4><p>システムテナントでは <code>SERVICE_NAME</code> 機能はサポートされていないため、システムテナントでこのステートメントを実行する際には、<code>TENANT = tenant_name</code> 句を指定する必要があります。</p></main>|

## 例

テナント `mysql001` にサービス `service_mysql001` を作成します。

```sql
ALTER SYSTEM CREATE SERVICE service_mysql001 TENANT = 'mysql001';
```
