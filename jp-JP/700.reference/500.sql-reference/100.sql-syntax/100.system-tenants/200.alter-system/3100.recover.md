# RECOVER STANDBY

## 説明

物理復旧が完了した後、または物理スタンバイデータベースの作成に成功した後、`ALTER SYSTEM RECOVER STANDBY` ステートメントを使用してスタンバイテナントのログ復旧の終了点を指定し、スタンバイテナントでログをセグメントごとに再生するか、継続的に再生することができます。

## 権限要件

`sys` テナントの `root` ユーザー（`root@sys`）または各テナントの管理者ユーザーが実行する必要があります。その中で：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM RECOVER STANDBY
    [TENANT [=] tenant_name] UNTIL { TIME='timestamp' | SCN=scn_no | UNLIMITED };
```

## パラメータの説明

| パラメータ | 説明                                                                                                      |
|-----------|------------------------------------------------------------------------------------------------------------|
| tenant_name| システムテナントが復元するログのスタンバイテナントを指定します。一度に指定できるのは1つのスタンバイテナントのみです。複数のテナントを指定する必要がある場合は、このコマンドを再度実行する必要があります。<main id="notice" type='notice'> <h4>注意</h4> <p>このコマンドを実行する際は、システムテナントのみが <code>TENANT = tenant_name</code> 句を使用して操作対象のテナントを指定する必要があります。通常のテナントは自身のテナントに対してのみこのコマンドを実行できるため、<code>TENANT = tenant_name</code> 句を指定することはできません。</p></main>   |
| timestamp | スタンバイテナントのログを復元できるタイムスタンプを指定します。このタイムスタンプポイントを含みます。`TIME` を指定する場合は、必ず `=` を使用して指定値を結合する必要があります。                    |
| scn_no    | スタンバイテナントのログを復元できるSCN（System Change Number）を指定します。このSCNポイントを含みます。`SCN` を指定する場合は、必ず `=` を使用して指定値を結合する必要があります。 |
| UNLIMITED | 無限に復元することを意味し、スタンバイテナントはソース側テナントのアーカイブログを継続的に再生できます。物理スタンバイデータベースの場合、スタンバイテナントは継続的同期モードにあることを意味します。              |

## 例

* システムテナント

  * バックアップ復旧シナリオでは、システムテナントはスタンバイテナント `restore_oracle_tenant` を指定して、指定されたタイムスタンプ `'2023-06-01 00:00:00'` までログを再生します。

    ```sql
    obclient [oceanbase]> ALTER SYSTEM RECOVER STANDBY TENANT restore_oracle_tenant UNTIL TIME='2023-06-01 00:00:00';
    ```

  * 物理スタンバイデータベースシナリオでは、システムテナントはスタンバイテナント `restore_oracle_tenant` を指定して、継続同期モードに入ります。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM RECOVER STANDBY TENANT restore_oracle_tenant UNTIL UNLIMITED;
    ```

* ユーザーテナント

    * バックアップ復旧シナリオでは、スタンバイテナント `restore_oracle_tenant` は、指定されたタイムスタンプ `'2023-06-01 00:00:00'` まで、このテナントのログを再生します。

      ```sql
      obclient [oceanbase]> ALTER SYSTEM RECOVER STANDBY UNTIL TIME='2023-06-01 00:00:00';
      ```

  * 物理スタンバイデータベースシナリオでは、スタンバイテナント `restore_oracle_tenant` は、このテナントを継続同期モードに入れます。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM RECOVER STANDBY UNTIL UNLIMITED;
    ```
