# MODIFY REPLICA

## 説明

このステートメントは、ログストリームレプリカのタイプを変換するために使用されます。

## 制限事項と注意点

* レプリカタイプを変更した後もログストリームが過半数を維持できることを確認してください。そうでない場合、運用コマンドエラーが発生します。
* このステートメントは一度に1つのレプリカのタイプしか変更できません。
* テナント内の同一ログストリームについては、レプリカ移行タスクを複数並行実行できる以外、他の災害復旧タスク（レプリカの追加、削除、レプリカタイプの変更、ログストリームの法定メンバー数の変更など）は毎回1つしか実行できません。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>sysテナントはビュー <code>CDB_OB_LS_REPLICA_TASKS</code> を使用して実行中の災害復旧タスクがあるかどうかを確認できます。ユーザーテナントはビュー <code>DBA_OB_LS_REPLICA_TASKS</code> を使用して実行中の災害復旧タスクがあるかどうかを確認できます。</p>
    </main>

## 権限要件

このステートメントを実行するユーザーは `ALTER SYSTEM` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM MODIFY REPLICA
    LS [=] ls_id
    SERVER [=] 'svr_ip:svr_port'
    REPLICA_TYPE [=] 'replica_type'
    [PAXOS_REPLICA_NUM [=] paxos_replica_num]
    [TENANT [=] 'tenant_name'];
```

## パラメータの説明

|     **パラメータ**      |             **説明**               |
|-------------------|------------------------------------|
| ls_id             | 変換対象のレプリカタイプを示すログストリームID。|
| svr_ip:svr_port   | 変換対象のレプリカタイプのターゲットサーバーのIPアドレスとポート番号。例えば、`xxx.xx.xxx.001:2882`。|
| replica_type      | 変換後のターゲットレプリカタイプを指定します。現在、以下の2種類のレプリカタイプ間での相互変換がサポートされています（大文字と小文字は区別されません）：<ul><li>フル機能レプリカ：<code>FULL</code>または<code>F</code>を使用して表します。</li><li>読み取り専用レプリカ：<code>READONLY</code>または<code>R</code>を使用して表します。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p><code>F</code>レプリカはリーダー（プライマリレプリカ）に選出される可能性がありますが、<code>R</code>レプリカはリーダーに選出されることはありません。</p></main>|
| paxos_replica_num | オプション。ログストリームリーダーの法定メンバー数を指定します。この値を明示的に指定しない場合、システムは現在のデフォルトの`paxos_replica_num`を使用します。また、1つのログストリームにおけるFレプリカの最大数は7です。<main id="notice" type='notice'><h4>注意</h4><p>このパラメータの値を指定する際には、以下の点に注意する必要があります：<ol><li><code>F</code>レプリカを<code>R</code>レプリカに変換する場合、変換後はリーダーレプリカが1つ削除されることになるため、<code>paxos_replica_num</code>の値から1を引く必要があります。</li><li><code>R</code>レプリカを<code>F</code>レプリカに変換する場合、変換後はリーダーレプリカが1つ追加されることになるため、<code>paxos_replica_num</code>の値に1を加える必要があります。</li><li>変更後の<code>paxos_replica_num</code>は過半数を満たす必要があります。</li><li><code>paxos_replica_num</code>の値は、現在のリーダーレプリカの<code>MEMBER_LIST</code>メンバー数以上である必要があります。sysテナントはビュー<code>CDB_OB_LS_LOCATIONS</code>を照会することで確認できます。ユーザーテナントはビュー<code>DBA_OB_LS_LOCATIONS</code>を照会することで確認できます。</li><li><code>paxos_replica_num</code>値の変化の絶対値は1を超えてはなりません。例えば、現在の<code>paxos_replica_num</code>が3の場合、<code>paxos_replica_num</code>は2または4にしか変更できません。</li></ol>指定した値が上記のいずれかの条件を満たさない場合、システムはエラーを報告します。</p></main>|
| tenant_name       | オプション。操作対象のテナントを指定します。操作対象のテナントを明示的に指定しない場合、デフォルトのテナント名は現在のテナント名になります。<main id="notice" type='notice'><h4>注意</h4><p>システムテナントは他のテナントを指定できますが、ユーザーテナントは自身のテナントのみを指定できます。このステートメントでは、<code>ALL</code>、<code>ALL_USER</code>、<code>ALL_META</code>などを使用してすべてのテナント、ユーザーテナント、およびすべてのMetaテナントを指定することはサポートされていません。</p></main>|

## 例

sysテナントで以下のコマンドを実行し、テナント`mysql001`内の`F`タイプのログストリープレペリカを`R`タイプのログストリープレペリカに変換します。

```sql
ALTER SYSTEM MODIFY REPLICA
    LS = 1001
    SERVER = 'xxx.xxx.xxx.001:2882'
    REPLICA_TYPE = 'R'
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```

ログストリープレペリカのタイプを変換するその他の例については、[レプリカタイプの変換](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/450.change-the-replica-type.md)を参照してください。
