# CANCEL RESTORE

## 説明

`ALTER SYSTEM CANCEL RESTORE` ステートメントは、進行中のテナント復元をキャンセルし、復元状態にあるテナントを削除するために使用されます。

## 権限要件

`sys` テナントの `root` ユーザー (`root@sys`) のみが `ALTER SYSTEM CANCEL RESTORE` ステートメントを実行できます。

## 構文

```sql
ALTER SYSTEM CANCEL RESTORE dest_tenant_name;
```

## パラメータの説明

|        **パラメータ**      |       **説明**                                                                          |
|----------------------|-----------------------------------------------------------------------------------------|
| dest_tenant_name     | 復元をキャンセルするテナントの名前を指定します。 |

## 例

`mysql` テナントに対して進行中の復元操作をキャンセルします。

```shell
obclient [oceanbase]> ALTER SYSTEM CANCEL RESTORE mysql;
```
