# MODIFY PAXOS_REPLICA_NUM

## 説明

このステートメントは、ログストリームの `paxos_replica_num`、つまりログストリームのリーダーに必要な法定メンバー数を変更するために使用されます。

## 使用制限と注意事項

* このステートメントは、1回につき1つのログストリームの `paxos_replica_num` のみを変更できます。

* テナント内の同一ログストリームについて、レプリカ移行タスクは複数並列実行可能ですが、その他のディザスタリカバリタスク（レプリカの追加、削除、レプリカタイプの変換、ログストリームの法定メンバー数の変更など）は、1回につき1つしか実行できません。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>sysテナントはビュー <code>CDB_OB_LS_REPLICA_TASKS</code> を参照して実行中のディザスタリカバリタスクを確認できます。ユーザーテナントはビュー <code>DBA_OB_LS_REPLICA_TASKS</code> を参照して実行中のディザスタリカバリタスクを確認できます。</p>
    </main>

## 権限要件

このステートメントを実行するユーザーは `ALTER SYSTEM` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM MODIFY
    LS [=] ls_id
    PAXOS_REPLICA_NUM [=] paxos_replica_num
    [TENANT [=] 'tenant_name'];
```

## パラメータ説明

|     **パラメータ**      |             **説明**               |
|-------------------|------------------------------------|
| ls_id             | 変更対象のログストリームIDを指定します。|
| paxos_replica_num | 変更後のリーダーの法定メンバー数を指定します。<main id="notice" type='notice'><h4>注意</h4><p>このパラメータの値を指定する場合は、以下の点に注意してください：<ol><li>調整後も、<code>paxos_replica_num</code> およびリーダーレプリカ内の <code>MEMBER_LIST</code> のメンバー数が過半数を満たす必要があります。</li><li><code>paxos_replica_num</code> の値は、現在のリーダーレプリカ内の <code>MEMBER_LIST</code> のメンバー数以上である必要があります。sysテナントはビュー <code>CDB_OB_LS_LOCATIONS</code> を、ユーザーテナントはビュー <code>DBA_OB_LS_LOCATIONS</code> を参照して確認できます。</li><li><code>paxos_replica_num</code> は小さくすることは可能ですが、大きくすることはできません。また、値の変化幅は1を超えてはなりません。</li></ol>指定した値が上記のいずれかの条件を満たさない場合、システムはエラーを返します。</p></main>|
| tenant_name       | オプションです。操作対象のテナントを指定します。操作対象のテナントを明示的に指定しない場合、デフォルトのテナント名は現在のテナントになります。<main id="notice" type='notice'><h4>注意</h4><p>システムテナントは他のテナントを指定できますが、ユーザーテナントは自身のテナントのみを指定できます。このステートメントでは、<code>ALL</code>、<code>ALL_USER</code>、<code>ALL_META</code> などを使用してすべてのテナント、ユーザーテナント、およびすべてのMetaテナントを指定することはサポートされていません。</p></main>|

## 例

sysテナントで以下のコマンドを実行し、テナント`mysql001`のログストリーム(1002)の`PAXOS_REPLICA_NUM`を2に変更します。

```sql
ALTER SYSTEM MODIFY
    LS = 1002
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```

ログストリームの`paxos_replica_num`を変更するその他の例については、[ログストリームの法定メンバー数の変更](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/800.modify-paxos-replica-number.md)を参照してください。
