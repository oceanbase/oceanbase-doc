# CANCEL MIGRATE UNIT

## 説明

このステートメントは、Unitの移行をキャンセルするために使用します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>このステートメントはsysテナントでの実行のみをサポートします。</p>
  </main>

## 構文

```sql
ALTER SYSTEM CANCEL MIGRATE UNIT unit_id;
```

## パラメータ説明

| **パラメータ**  |      **説明**      |
|---------|------------------|
| unit_id | 移行するUnitのIDを指定します。 |

## 例

`unit_id` が `1001` のリソースUnitの移行をキャンセルします。

```sql
obclient> ALTER SYSTEM CANCEL MIGRATE UNIT 1001;
```
