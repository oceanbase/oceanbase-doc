# CANCEL MIGRATE UNIT

## 説明

このステートメントは、ユニットの移行をキャンセルするために使用されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>このステートメントはsysテナントでのみ実行できます。</p>
  </main>

## 構文

```sql
ALTER SYSTEM CANCEL MIGRATE UNIT unit_id;
```

## パラメータの説明

| **パラメータ**  |      **説明**      |
|---------|------------------|
| unit_id | 移行するユニットのIDを指定します。 |

## 例

`unit_id` が `1001` のリソースユニットの移行をキャンセルします。

```sql
obclient> ALTER SYSTEM CANCEL MIGRATE UNIT 1001;
```
