# CANCEL RECOVER TABLE

## 説明

`ALTER SYSTEM CANCEL RECOVER TABLE` ステートメントは、対象テナントで実行中のテーブルレベルのリカバリタスクをキャンセルするために使用されます。

## 制限事項と注意点

* このステートメントを実行すると、対応するテナント内のすべてのテーブルレベルのリカバリタスクがキャンセルされますが、補助テナント用に作成されたリソースプールは解放されません。

* このステートメントを実行する前に、一部のテーブルが既にリカバリ完了している場合、既にリカバリ済みのテーブルはリカバリをキャンセルできません。

## 権限要件

`ALTER SYSTEM RECOVER TABLE` ステートメントを実行できるのは、`sys` テナントの `root` ユーザー (`root@sys`) のみです。

## 構文

```sql
ALTER SYSTEM CANCEL RECOVER TABLE dest_tenant_name;
```

## パラメータの説明

|        **パラメータ**      |       **説明**               |
|----------------------|------------------------------|
| dest_tenant_name     | テーブルレベルのリカバリを実行中の対象テナントを指定します。|

## 例

`sys` テナント内で、対象テナント `obt` のテーブルレベルのリカバリタスクをキャンセルします。

```sql
obclient [oceanbase]> ALTER SYSTEM CANCEL RECOVER TABLE obt;
```
