# MIGRATE UNIT

## 説明

このステートメントは、ユニットの移行を担当します。

このステートメントはsysテナントでのみ実行がサポートされています。

クラスタの単一ゾーン内において複数のOBServerノード間でリソースの配分が偏っている場合、テナントが使用するリソースの配分を調整することで、クラスタ全体のリソース使用量を均等化できます。ユニット移行を実行する前に、負荷分散を無効にする必要があります。構文は以下のとおりです：

```sql
obclient> ALTER SYSTEM SET enable_rebalance = false;
```

上記パラメータの詳細については、《OceanBaseデータベース 参考ガイド》の**システムパラメータ**章を参照してください。

## 構文

```sql
alter_system_unit_stmt:
    ALTER SYSTEM MIGRATE
    UNIT [=] unit_id DESTINATION [=] ip_port

unit_id:
    INT_VALUE
```

## パラメータ説明

| **パラメータ**  |          **説明**          |
|---------|--------------------------|
| unit_id | ユニット番号。                 |
| ip_port | ユニットを移行先サーバーのIPアドレス。 |

## 例

`unit_id` が `1001` のリソースユニットを、IPアドレスが `xxx.xxx.xx.xx1` のOBServerに移行します。

```sql
obclient> ALTER SYSTEM MIGRATE UNIT = 1001 DESTINATION = 'xxx.xxx.xx.xx1:xxxx';
Query OK, 0 rows affected
```
