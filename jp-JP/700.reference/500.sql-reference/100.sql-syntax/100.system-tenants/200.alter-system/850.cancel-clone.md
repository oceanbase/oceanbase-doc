# CANCEL CLONE

## 説明

このステートメントは、クローンタスクをキャンセルするために使用します。

## 使用上の制限と注意事項

* このステートメントを実行して実行中のクローンタスクをキャンセルすると、対応するクローンタスクは明示的に `CANCELED` 状態に切り替えられます。また、クローンタスクがキャンセルされると、申請した各種リソースは自動的に解放されます。
* このステートメントを実行する前に、新しいクローンテナントのクローン操作が既に完了し、通常のサービス状態に切り替わっている場合、このステートメントは実行されません。

## 権限要件

クローンタスクをキャンセルできるのは、`sys` テナントの `root` ユーザー（`root@sys`）のみです。

## 構文

```sql
ALTER SYSTEM CANCEL CLONE new_tenant_name;
```

## パラメータ説明

|       パラメータ        |       説明       |
|-------------------|-----------------|
| new_tenant_name   | クローンする新しいテナント名。|

2. クローンタスクのキャンセルを有効にします。

   ```sql
   ALTER SYSTEM CANCEL CLONE clone_mysql001;
   ```

   ```sql
   SELECT * FROM oceanbase.DBA_OB_CLONE_PROGRESS\G
   ```

   実行結果は次のとおりです：

   ```shell
   Empty set
   ```
