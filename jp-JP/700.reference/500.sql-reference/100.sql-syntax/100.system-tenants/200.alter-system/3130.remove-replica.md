# REMOVE REPLICA

## 説明

このステートメントは、ログストリームのレプリカを削除するために使用されます。

## 使用上の制限と注意事項

* レプリカを削除した後もログストリームが過半数を維持できることを確認してください。そうでない場合、運用コマンドがエラーになります。

* このステートメントは一度に1つのレプリカしか削除できません。

* テナント内の同一ログストリームについて、レプリカ移行タスクは複数並列実行可能ですが、その他のディザスタリカバリタスク（レプリカ追加、レプリカ削除、レプリカタイプ変更、ログストリームの法定メンバー数変更など）は、1回につき1つしか実行できません。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>sysテナントはビュー<code>CDB_OB_LS_REPLICA_TASKS</code>で、ユーザーテナントはビュー<code>DBA_OB_LS_REPLICA_TASKS</code>で、実行中のディザスタリカバリタスクがあるかどうかを確認できます。</p>
    </main>

## 権限要件

このステートメントを実行するユーザーは`ALTER SYSTEM`権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM REMOVE REPLICA
    LS [=] ls_id
    SERVER [=] 'svr_ip:svr_port'
    [PAXOS_REPLICA_NUM [=] paxos_replica_num]
    [TENANT [=] 'tenant_name'];
```

## パラメータ説明

|     **パラメータ**      |             **説明**               |
|-------------------|------------------------------------|
| ls_id             | 削除対象レプリカのログストリームIDを指定します。|
| svr_ip:svr_port   | 削除対象レプリカが存在するサーバーのIPアドレスとポートを指定します。例：`xxx.xx.xxx.001:2882`。|
| paxos_replica_num | オプションです。ログストリームのリーダーレプリカの法定メンバー数を指定します。この値を明示的に指定しない場合、システムは現在のデフォルトの`paxos_replica_num`を使用します。また、同一ログストリームのFレプリカ数は最大7個です。<main id="notice" type='notice'><h4>注意</h4><p>このパラメータの値を指定する場合、以下の条件を満たす必要があります：<ol><li>変更後の<code>paxos_replica_num</code>が過半数を満たす必要があります。</li><li><code>paxos_replica_num</code>の値は、現在のリーダーレプリカの<code>MEMBER_LIST</code>のメンバー数以上である必要があります。sysテナントはビュー<code>CDB_OB_LS_LOCATIONS</code>を、ユーザーテナントはビュー<code>DBA_OB_LS_LOCATIONS</code>を参照して確認できます。</li><li><code>paxos_replica_num</code>の値の絶対変化量は1を超えてはなりません。例えば、現在の<code>paxos_replica_num</code>が3の場合、<code>paxos_replica_num</code>は2にしか変更できません。</li></ul> 指定した値が上記のいずれかの条件を満たさない場合、システムはエラーを返します。</p></main>|
| tenant_name       | オプションです。操作対象のテナントを指定します。操作対象のテナントを明示的に指定しない場合、デフォルトテナント名は現在のテナントになります。<main id="notice" type='notice'><h4>注意</h4><p><ul><li>システムテナントは他のテナントを指定できますが、ユーザーテナントは自身のテナントのみを指定できます。</li><li>このステートメントでは、<code>ALL</code>、<code>ALL_USER</code>、<code>ALL_META</code>などを使用して、すべてのテナント、ユーザーテナント、およびすべてのMetaテナントを指定することはサポートされていません。</li></ul></p></main>|

## 例

sysテナントで以下のコマンドを実行し、テナント`mysql001`のログストリームレプリカを1つ削除します。

```sql
ALTER SYSTEM REMOVE REPLICA
    LS = 1001
    SERVER = 'xxx.xxx.xxx.001:2882'
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```

ログストリームのレプリカを削除するその他の例については、[レプリカの削減](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/400.reduce-replica.md)を参照してください。
