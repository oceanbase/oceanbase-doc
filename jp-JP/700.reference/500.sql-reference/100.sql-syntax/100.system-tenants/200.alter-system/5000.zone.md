# ZONE

## 説明

このステートメントは、ゾーンの状態を管理するために使用されます。ゾーンの追加、削除、起動、停止、隔離などの操作が含まれます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>このステートメントはsysテナントでのみ実行できます。</p>
  </main>

## 構文

```sql
alter_system_zone_stmt:
    ALTER SYSTEM zone_action;

zone_action:
      ADD ZONE zone_name
      [zone_option_list]
    | {ALTER | CHANGE | MODIFY} ZONE zone_name
      [SET] zone_option_list
    | {DELETE | START | STOP | FORCE STOP} ZONE zone_name
    | ISOLATE ZONE '$zone_name';

zone_option_list:
    zone_option [, zone_option ...]

zone_option:
      region
    | idc
    | ZONE_TYPE {READWRITE | ENCRYPTION}

idc:
    STR_VALUE
```

## パラメータの説明

|          **パラメータ**      |          **説明**      |
|------------------------|------------------------|
| ADD ZONE                         | ゾーンを追加します。   |
| {ALTER \| CHANGE \| MODIFY} ZONE | ゾーンのリージョン属性を変更します。 <main id="notice" type='explain'><h4>説明</h4><p><code>ALTER</code>、<code>CHANGE</code>、<code>MODIFY</code> の3つの機能は同じであり、任意のコマンドを使用してゾーンのリージョン属性を変更できます。</p></main>       |
| DELETE ZONE                      | ゾーンを削除します。削除する前に、ゾーン内に利用可能なサーバーがないことを確認する必要があります。 |
| ISOLATE ZONE                     | 故障したゾーンを隔離します。故障したゾーン上のリーダーを他のマシンに切り替えることで、ユーザーの書き込みサービスを復旧し、同時にクラスタ内のログ同期状態も正常に戻ります。   |
| START \| STOP                    | ゾーンを手動でオンラインまたはオフラインにします。    |
| FORCE STOP                       | ゾーンを強制的にオフラインにします。     |
| zone_option                      | 対象ゾーンの属性を指定します。複数の属性を指定する場合は、各属性をカンマ（,）で区切ります： <ul><li> `region`：ゾーンが属するリージョンの名前。デフォルトは`default_region`です。</li>   <li> `idc`：ゾーンが配置されているデータセンターの名前。デフォルトは空です。</li>   <li> `ZONE_TYPE`：対象ゾーンを読み書きゾーン(`READWRITE`)または暗号化ゾーン(`ENCRYPTION`)として指定します。`ZONE_TYPE`を明示的に指定しない場合、デフォルトは読み書きゾーンです。</li></ul>    |

## 例

* ゾーンを削除します。ゾーン内にOBServerノードが存在する場合、削除は失敗します。

  ```sql
  obclient> ALTER SYSTEM DELETE ZONE 'z1';
  ERROR 4668 (HY000): The zone is not empty and can not be deleted. You should delete the servers of the zone. There are 1 servers alive and 0 not alive.
  ```

* 故障したゾーンを隔離します。

  ```sql
  obclient> ALTER SYSTEM ISOLATE ZONE 'zone1';
  ```
