# ZONE

## 説明

このステートメントは、ゾーンの追加、削除、起動、停止、隔離などの操作を含むゾーンの状態のメンテナンスを担当します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>このステートメントはsysテナントでのみ実行できます。</p>
  </main>

## 構文

```sql
alter_system_zone_stmt:
    ALTER SYSTEM zone_action;

zone_action:
      ADD ZONE zone_name
      [zone_option_list]
    | {ALTER | CHANGE | MODIFY} ZONE zone_name
      [SET] zone_option_list
    | {DELETE | START | STOP | FORCE STOP} ZONE zone_name
    | ISOLATE ZONE '$zone_name';

zone_option_list:
    zone_option [, zone_option ...]

zone_option:
      region
    | idc
    | ZONE_TYPE {READWRITE | ENCRYPTION}

idc:
    STR_VALUE
```

## パラメータの説明

|          **パラメータ**      |          **説明**      |
|------------------------|------------------------|
| ADD ZONE                         | Zoneを追加します。   |
| {ALTER \| CHANGE \| MODIFY} ZONE | ZoneのRegionプロパティを変更します。 <main id="notice" type='explain'><h4>説明</h4><p><code>ALTER</code>、<code>CHANGE</code>、<code>MODIFY</code> の3つは機能が同じであり、いずれかのコマンドを使用してZoneのRegionプロパティを変更できます。</p></main>       |
| DELETE ZONE                      | Zoneを削除します。削除する前に、Zone内に利用可能なServerがないことを確認する必要があります。 |
| ISOLATE ZONE                     | 故障したZoneを隔離します。故障したZone上のリーダーを他のマシンに切り替えることで、ユーザーの書き込みサービスを復旧し、クラスタ内のログ同期状態も正常に戻ります。   |
| START \| STOP                    | Zoneをアクティブまたは非アクティブにします。    |
| FORCE STOP                       | Zoneを強制的に非アクティブにします。     |
| zone_option                      | ターゲットZoneのプロパティを指定します。複数のプロパティを指定する場合は、各プロパティの前にカンマ（,）を付けて区切ります： <ul><li> `region`：Zoneが属するRegionの名前。デフォルトは`default_region`です。</li>   <li> `idc`：Zoneが属するデータセンターの名前。デフォルトは空です。</li>   <li> `ZONE_TYPE`：ターゲットZoneを読み書きZone（`READWRITE`）または暗号化Zone（`ENCRYPTION`）に指定します。`ZONE_TYPE`を明示的に指定しない場合、デフォルトは読み書きZoneになります。</li></ul>    |

## 例

* ゾーンを削除します。ゾーン内にOBServerノードが存在する場合、削除に失敗します。

  ```sql
  obclient> ALTER SYSTEM DELETE ZONE 'z1';
  ERROR 4668 (HY000): The zone is not empty and can not be deleted. You should delete the servers of the zone. There are 1 servers alive and 0 not alive.
  ```

* 故障したゾーンを隔離します。

  ```sql
  obclient> ALTER SYSTEM ISOLATE ZONE 'zone1';
  ```
