# ADD RESTORE SOURCE

## 説明

このステートメントは、復元するパスを読み込むために使用されます。

## 権限要件

このステートメントを実行するには、現在のユーザーが`ALTER SYSTEM`権限を持っている必要があります。

## 構文

```sql
ALTER SYSTEM ADD RESTORE SOURCE 'restore_path';
```

## パラメータの説明

|              **パラメータ**       |                     **説明**                       |
|-----------------------------|----------------------------------------------------|
| restore_path                | 読み込むデータバックアップセット(`backup_set`)またはログアーカイブ(`archivelog_piece`)のパスを入力します。1つのパスでも複数のパスでも構いません。 <main id="notice" type='notice'><h4>注意</h4><p><ul><li>読み込む <code>backup_set</code>または <code>archivelog_piece</code>がオブジェクトストレージに保存されている場合、各 <code>backup_set</code>または <code>archivelog_piece</code>パス内の <code>host</code>、<code>access_id</code>、および <code>access_key</code>などのパラメータ情報がすべて同一であることが求められます。</li><li>このステートメントは、同一セッション内で連続して複数回実行できます。同一セッション内で複数回実行された場合、システムは復元ソースリストに増分追加します。</li></ul></p></main>|

## 例

1. 復元するbackup_setを読み込みます。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'file:///ob_backup/data/backup_set_1_full';
    ```

2. 復元するarchivelog_pieceを読み込みます。

    ```shell
    obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'file:///ob_backup/archive/piece_d1002r1p1,file:///ob_backup/archive/piece_d1002r1p2';
    ```

    ```shell
    obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'oss://test_bucket/archive/piece_1?host=***&access_id=x****&access_key=****';
    ```
