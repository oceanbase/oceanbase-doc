# JOB

## 説明

このステートメントは、パラメータで指定されたバックグラウンドタスクをトリガーします。

このステートメントはsysテナントでのみ実行できます。

## 構文

```sql
alter_system_job_stmt:
ALTER SYSTEM RUN JOB job_name
[ZONE [=] 'zone' | SERVER [=] 'server'];
```

## パラメータの説明

|        **パラメータ**       |          **説明**         |
|-----------------------|-------------|
| job_name              | タスク名を指定します。特殊文字が含まれる場合はシングルクォートが必要です。その他の場合は、シングルクォートの有無は問いません。サポートされているJobは以下のとおりです： <ul><li> `check_partition_table`：OBServerノードでPartition Tableの整合性チェック削除タスクを実行します。</li>   <li> `root_inspection`：Root Serviceの自己検査をトリガーします。</li></ul>    |
| SERVER \[=\] 'server' | このタスクを特定のServerで実行します。このパラメータは`check_partition_table`タスクでのみサポートされています。    |
| ZONE \[=\] 'zone'     | このタスクを特定のZoneで実行します。このパラメータは`check_partition_table`タスクでのみサポートされています。   |

## 例

Root Serviceの自己検査タスクをトリガーします。

```sql
obclient> ALTER SYSTEM RUN JOB "root_inspection";
```
