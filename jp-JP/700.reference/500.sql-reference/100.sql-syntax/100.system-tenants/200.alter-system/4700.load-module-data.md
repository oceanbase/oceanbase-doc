# LOAD MODULE DATA

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このステートメントは、V4.2.5バージョンから導入されました。</p>
</main>

## 説明

このステートメントは、特定のテナントに指定された機能をインポートするために使用されます。

## 構文

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>このコマンドはSYSテナントのみが実行できます。</p>
</main>

構文は以下のとおりです：

```sql
ALTER SYSTEM LOAD MODULE DATA
 module = {redis|gis|timezone}
 tenant = <tenant_name>
 infile = <file_name>;
```

## 構文の説明

|   **フィールド**  | **説明** |
| ----------- | -------- |
| module     | 必須。<ul><li>`module = redis`：Redis機能を操作することを示します。</li><li>`module = gis`：GIS機能を操作することを示します。</li><li>`module = timezone`：Timezone機能を操作することを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.2.x系では、V4.2.5 BP2以降のバージョンから値の範囲が`redis`から`redis|gis|timezone`に変更されました。</p></main> |
| tenant     | 必須。指定されたテナントに対して操作を実行します。|
| infile     | オプション。データファイルをインポートするパスです。絶対パスまたはOBServerワーカディレクトリの相対パスを指定できます。指定しない場合は、内部デフォルトのファイルパスとファイル名が使用されます。|

## 例

MysQLテナントにOBKV-Redisモジュール機能をインポートします：

```sql
ALTER SYSTEM LOAD MODULE DATA module=redis tenant=mysql;
```

## 関連ドキュメント

特定のテナントの指定された機能またはすべての機能がインポートされているかどうかを確認するには、[CHECK MODULE DATA](4800.check-module-data.md)を参照してください。
