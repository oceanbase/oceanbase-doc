# RECOVER STANDBY CANCEL

## 説明

スタンバイテナントでログのセグメント再生または継続再生を行っている途中に、`ALTER SYSTEM RECOVER... CANCEL` ステートメントを使用して、そのスタンバイテナントのログ再生をキャンセルできます。

## 権限要件

このコマンドは、`sys` テナントの `root` ユーザー（`root@sys`）または各テナントの管理者ユーザーが実行する必要があります。具体的には：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM RECOVER STANDBY [TENANT [=] tenant_name] CANCEL;
```

## パラメータ説明

| パラメータ       | 説明                                                                                                   |
|------------|------------------------------------------------------------------------------------------------------------|
| tenant_name| キャンセル対象のスタンバイテナントを指定します。一度に指定できるのは1つのスタンバイテナントのみです。複数のテナントを指定する場合は、このコマンドを再度実行する必要があります。<main id="notice" type='notice'> <h4>注意</h4> <p>システムテナントがこのコマンドを実行する場合のみ、<code>TENANT = tenant_name</code> 句を使用して操作対象のテナントを指定する必要があります。通常のテナントは自身のテナントに対してのみこのコマンドを実行できるため、<code>TENANT = tenant_name</code> 句を指定することはできません。</p></main>   |

## 例

* スタンバイテナント `restore_oracle_tenant` が存在するクラスタのシステムテナントが、そのスタンバイテナントのログ再生をキャンセルします。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM RECOVER STANDBY TENANT restore_oracle_tenant CANCEL;
  ```

* スタンバイテナント `restore_oracle_tenant` が自身のテナントのログ再生をキャンセルします。

  ```shell
  obclient [SYS]> ALTER SYSTEM RECOVER STANDBY CANCEL;
  ```
