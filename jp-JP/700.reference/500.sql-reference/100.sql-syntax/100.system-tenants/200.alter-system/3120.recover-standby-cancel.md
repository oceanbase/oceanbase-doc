# RECOVER STANDBY CANCEL

## 説明

スタンバイテナントでログのセグメントリプレイまたは継続的なリプレイを行っている途中で、`ALTER SYSTEM RECOVER... CANCEL` ステートメントを使用して、スタンバイテナントのログリプレイをキャンセルできます。

## 権限要件

このコマンドは、`sys` テナントの `root` ユーザー (`root@sys`) または各テナントの管理者ユーザーによって実行する必要があります。その中で：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM RECOVER STANDBY [TENANT [=] tenant_name] CANCEL;
```

## パラメータの説明

| パラメータ | 説明                                                                                                   |
|------------|------------------------------------------------------------------------------------------------------------|
| tenant_name| ログリプレイをキャンセルするスタンバイテナントを指定します。一度に指定できるのは1つのスタンバイテナントのみです。複数のテナントを指定する場合は、このコマンドを再度実行する必要があります。<main id="notice" type='notice'> <h4>注意</h4> <p>このコマンドを実行する際、システムテナントのみが <code>TENANT = tenant_name</code> 句を使用して操作対象のテナントを指定する必要があります。通常のテナントは自身のテナントに対してのみこのコマンドを実行できるため、<code>TENANT = tenant_name</code> 句を指定することはできません。</p></main>   |

## 例

* スタンバイテナント `restore_oracle_tenant` が属するクラスタのシステムテナントが、スタンバイテナントのログリプレイをキャンセルします。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM RECOVER STANDBY TENANT restore_oracle_tenant CANCEL;
  ```

* スタンバイテナント `restore_oracle_tenant` が、自身のログリプレイをキャンセルします。

  ```shell
  obclient [SYS]> ALTER SYSTEM RECOVER STANDBY CANCEL;
  ```
