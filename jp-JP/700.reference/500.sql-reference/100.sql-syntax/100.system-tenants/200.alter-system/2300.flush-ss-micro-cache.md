# FLUSH ss_micro_cache

<main id="notice" >
<h4>機能の適用範囲</h4>
<p>このステートメントは、共有ストレージ（Shared-Storage、SS）モードでのみ適用されます。</p>
</main>

## 説明

`ALTER SYSTEM FLUSH ss_micro_cache` ステートメントは、共有ストレージ（Shared-Storage、SS）モードで指定されたテナントのマイクロブロックキャッシュデータをクリーンアップするために使用されます。

## 権限要件

`sys` テナントの `root` ユーザーが実行する必要があります。ユーザーテナントではこのステートメントはサポートされていません。

## 構文

```sql
ALTER SYSTEM FLUSH ss_micro_cache TENANT [=] tenant_name;
```

## パラメータ説明

|       パラメータ        |               説明                                   |
|-------------------|------------------------------------------------------|
| tenant_name       | クリーンアップ対象のマイクロブロックキャッシュを持つユーザーテナントを指定します。1文で指定できるテナントは1つのみです。|

## 例

`sys` テナント内で、テナント `mysql_tenant` のマイクロブロックキャッシュデータをクリーンアップします。

```shell
obclient> ALTER SYSTEM FLUSH ss_micro_cache TENANT = 'mysql_tenant';
```
