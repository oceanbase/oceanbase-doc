# CHECK MODULE DATA

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このステートメントは、V4.2.5バージョンから導入されました。</p>
</main>

## 説明

このステートメントは、特定のテナントの指定された機能またはすべての機能がインポートされているかどうかを確認するために使用されます。

## 構文

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>このコマンドはSYSテナントのみが実行できます。</p>
</main>

構文は次のとおりです：

```sql
ALTER SYSTEM CHECK MODULE DATA
 module = {redis}
 tenant = <tenant_name> ;
```

## 構文の説明

|   **フィールド**  | **説明** |
| ----------- | -------- |
| module     | 必須。module = 'redis'：redis機能を操作することを示します。現在はredisのみサポートしています。 |
| tenant     | 必須。指定されたテナントに対して操作を行います。|

## 例

MySQLテナントにインポートされたOBKV-Redisモジュール機能が正常にインポートされているかどうかを確認します：

```sql
ALTER SYSTEM CHECK MODULE DATA module=redis tenant=mysql;
```

インポートに失敗した場合、エラーが報告されます：

```shell
ERROR 4025 (HY000): redis module data is not complete，please retry loading
```

## 関連ドキュメント
