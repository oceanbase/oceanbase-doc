# BALANCE JOB

## 説明

このステートメントは、Balance Jobを一時停止(SUSPEND)、再開(RESUME)、またはキャンセル(CANCEL)するために使用されます。

テナントで実行中のBalance Jobがある場合、他の緊急変更を実行する必要がある場合、そのBalance Jobの実行が緊急変更に影響を与えないように、現在実行中のBalance Jobを一時停止し、緊急変更が完了した後に再開して実行を続けることができます。

現在進行中のBalance Jobがお客様の要件に合致しない場合は、そのタスクをキャンセルすることができます。また、Transfer Partitionを開始したものの、実行中のBalance Jobがあるためタスクの開始が遅延している場合でも、現在進行中のBalance Jobをキャンセルすることができます。

## 制限事項と注意点

* V4.2.5バージョンでは、V4.2.5 BP2バージョンからBalance Jobの一時停止と再開がサポートされています。

* Balance Jobのキャンセル、一時停止、または再開の操作は、プライマリデータベース（すなわちプライマリテナント）でのみ実行できます。

* Balance Jobを一時停止または再開する際、そのBalance Jobの状態が`CANCELING`であってはなりません。

## 権限要件

現在のユーザーに`ALTER SYSTEM`権限が付与されている必要があります。

## 構文

```sql
ALTER SYSTEM {SUSPEND | RESUME | CANCEL} BALANCE JOB [TENANT = 'tenant_name'];
```

## パラメータの説明

| パラメータ | 説明 |
|--------------|------------|
| tenant_name | キャンセルするタスクのテナント名を指定します。オプションですが、システムテナントで実行する場合は指定する必要があります。|

## 例

以下は、システムテナントでの操作を例に説明します。

1. 現在実行中のタスクとその状態を照会します。

    ```shell
    obclient> SELECT T.TENANT_NAME, J.TENANT_ID, J.JOB_ID, J.CREATE_TIME, J.MODIFY_TIME, J.BALANCE_STRATEGY, J.JOB_TYPE, j.STATUS
    FROM oceanbase.CDB_OB_BALANCE_JOBS J, oceanbase.DBA_OB_TENANTS T
    WHERE J.TENANT_ID = T.TENANT_ID;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------------+-----------+--------+----------------------------+----------------------------+---------------------------+--------------+--------+
    | TENANT_NAME | TENANT_ID | JOB_ID | CREATE_TIME                | MODIFY_TIME                | BALANCE_STRATEGY          | JOB_TYPE     | STATUS |
    +-------------+-----------+--------+----------------------------+----------------------------+---------------------------+--------------+--------+
    | oracle001   |      1004 | 300793 | 2024-02-29 16:45:12.864110 | 2024-02-29 16:45:12.864110 | LS balance by shrink      | LS_BALANCE   | DOING  |
    +-------------+-----------+--------+----------------------------+----------------------------+---------------------------+--------------+--------+
    1 row in set
    ```

2. ビジネスの状況に応じて、適切な操作を選択します：

   * 実行中のBalance Jobを一時停止します

        ```shell
        obclient> ALTER SYSTEM SUSPEND BALANCE JOB TENANT = 'oracle001';
        ```

   * 一時停止されたBalance Jobを再開します

        ```shell
        obclient> ALTER SYSTEM RESUME BALANCE JOB TENANT = 'oracle001';
        ```

   * 予想に合わないBalance Jobをキャンセルします

        ```shell
        obclient> ALTER SYSTEM CANCEL BALANCE JOB TENANT = 'oracle001';
        ```
