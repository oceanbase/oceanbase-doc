# ADD REPLICA

## 説明

このステートメントは、ログストリームのレプリカを手動で追加するために使用されます。

## 使用上の制限と注意事項

* レプリカの追加操作を実行する前に、ターゲットサーバー(Server)上にユーザーが利用可能なリソース(Unit)があり、そのUnit上に該当ログストリームのレプリカが存在しないことを確認してください。

* システムテナント(sysテナント)はすべてのテナントのログストリームに対してレプリカの追加操作を実行できますが、ユーザーテナントは自身のテナントのログストリームに対してのみレプリカの追加操作を実行できます。

* このステートメントは一度に1つのレプリカしか追加できません。複数のレプリカを追加する必要がある場合は、このステートメントを複数回実行する必要があります。

* テナント内の同一ログストリームについて、レプリカ移行タスクは並列実行可能ですが、その他のディザスタリカバリタスク(レプリカの追加、削除、レプリカタイプの変更、ログストリームの法定メンバー数の変更など)は、1回につき1つのみ実行可能です。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>sysテナントはビュー<code>CDB_OB_LS_REPLICA_TASKS</code>を参照することで、実行中のディザスタリカバリタスクを確認できます。ユーザーテナントはビュー<code>DBA_OB_LS_REPLICA_TASKS</code>を参照することで、実行中のディザスタリカバリタスクを確認できます。</p>
    </main>

## 権限要件

このステートメントを実行するユーザーは`ALTER SYSTEM`権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)および[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

```sql
ALTER SYSTEM ADD REPLICA
    LS [=] ls_id
    SERVER [=] 'svr_ip:svr_port'
    REPLICA_TYPE [=] 'replica_type'
    [DATA_SOURCE [=] 'data_source']
    [PAXOS_REPLICA_NUM [=] $paxos_replica_num]
    [TENANT [=] '$tenant_name'];
```

## パラメータ説明

|     **パラメータ**      |             **説明**               |
|-------------------|------------------------------------|
| ls_id             | 追加対象のログストリームIDを指定します。|
| svr_ip:svr_port   | 追加対象のレプリカを配置するターゲットサーバーのIPアドレスとポートを指定します。例：`xxx.xx.xxx.001:2882`。|
| replica_type      | 追加するレプリカタイプを指定します。現在、以下の2種類のレプリカタイプのみサポートしています(大文字小文字を区別しません)：<ul><li>フル機能レプリカ：<code>FULL</code>または<code>F</code>を使用して表します。</li><li>読み取り専用レプリカ：<code>READONLY</code>または<code>R</code>を使用して表します。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p><code>F</code>レプリカはリーダー(プライマリレプリカ)に選出される可能性がありますが、<code>R</code>レプリカはリーダーに選出されません。</p></main>|
| data_source       | オプションです。追加するレプリカのデータソースアドレスを指定します。形式は`svr_ip:svr_port`です。例：`xxx.xx.xxx.002:2882`。この値を明示的に指定しない場合、システムは利用可能なデータソースを自動的に選択します。<main id="notice" type='notice'><h4>注意</h4><p>指定したデータソースが利用不可の場合、システムはエラーを返します。</p></main>|
| paxos_replica_num | オプションです。ログストリームリーダーの法定メンバー数を指定します。この値を明示的に指定しない場合、システムは現在のデフォルト値である`paxos_replica_num`を使用します。また、同一ログストリームのFレプリカ数は最大7個です。<main id="notice" type='notice'><h4>注意</h4><p>このパラメータの値を指定する場合、以下の条件を満たす必要があります：<ol><li>変更後の<code>paxos_replica_num</code>は過半数である必要があります。</li><li><code>paxos_replica_num</code>の値は、現在のリーダーレプリカの<code>MEMBER_LIST</code>のメンバー数以上である必要があります。sysテナントはビュー<code>CDB_OB_LS_LOCATIONS</code>を、ユーザーテナントはビュー<code>DBA_OB_LS_LOCATIONS</code>を参照することで確認できます。</li><li><code>paxos_replica_num</code>値の変化量の絶対値は1を超えてはなりません。例えば、現在の<code>paxos_replica_num</code>が2の場合、<code>paxos_replica_num</code>を3に変更できます。</li></ul> 指定した値が上記いずれかの条件を満たさない場合、システムはエラーを返します。</p></main>|
| tenant_name       | オプションです。操作対象のテナントを指定します。操作対象のテナントを明示的に指定しない場合、デフォルトのテナント名は現在のテナント名となります。<main id="notice" type='notice'><h4>注意</h4><p>システムテナントは他のテナントを指定できますが、ユーザーテナントは自身のテナントのみを指定できます。このステートメントでは、<code>ALL</code>、<code>ALL_USER</code>、<code>ALL_META</code>などを使用して、すべてのテナント、ユーザーテナント、およびすべてのMetaテナントを指定することはできません。</p></main>|

## 例

sysテナントで以下のコマンドを実行し、テナント`mysql001`にログストリームレプリカを追加します。

```sql
ALTER SYSTEM ADD REPLICA
    LS = 1001
    SERVER = 'xxx.xxx.xxx.001:2882'
    REPLICA_TYPE = 'F'
    DATA_SOURCE = 'xxx.xxx.xxx.002:2882'
    PAXOS_REPLICA_NUM = 3
    TENANT = 'mysql001';
```

ログストリームレプリカの追加に関する詳細な例は、[レプリカの追加](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/300.add-replica.md)を参照してください。
