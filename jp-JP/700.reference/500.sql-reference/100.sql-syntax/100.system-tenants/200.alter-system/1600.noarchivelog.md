# NOARCHIVELOG

## 説明

ログアーカイブモードには、アーカイブ（ARCHIVELOG）モードと非アーカイブ（NOARCHIVELOG）モードの2種類があります。ログアーカイブモードを有効にした後、`ALTER SYSTEM NOARCHIVELOG` ステートメントを使用してユーザーテナントのアーカイブモードを無効にできます。

## 使用上の制限と注意事項

`ALTER SYSTEM NOARCHIVELOG` ステートメントでアーカイブモードを無効にする前に、現在のテナントで進行中または一時停止されているログアーカイブタスクがある場合、アーカイブモードを無効にすると、システムはこれらのアーカイブタスクを自動的に停止します。

## 権限要件

`sys` テナントの `root` ユーザー（`root@sys`）または各テナントの管理者ユーザーが実行する必要があります。具体的には：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM NOARCHIVELOG [TENANT = {all | tenant_name[, tenant_name...]}] [DESCRIPTION [=] 'description'];
```

## パラメータ説明

| パラメータ                    | 説明                                                                                                   |
|-------------------------|--------------------------------------------------------------------------------------------------------|
| all                     | システムテナントがクラスタ内のすべてのユーザーテナントのアーカイブモードを無効にします。                                                                  |
| tenant_name[, tenant_name...]    | システムテナントがアーカイブモードを無効にするテナント名を指定します。複数のテナントを同時に指定でき、異なるテナント間は半角カンマ（,）で区切ります。<main id="notice" type='notice'><h4>注意</h4><p>このコマンドを実行するのはシステムテナントのみであり、<code>TENANT tenant_name</code> 句で操作対象のテナントを指定する必要があります。ユーザーテナントは自身のテナントでのみこのコマンドを実行できるため、この句を指定する必要はありません。</p></main>  |
| description             | オプションです。この操作の説明情報を指定します。                                                                              |

## 例

現在のクラスタに `sys`、`mysql_tenant`、`oracle_tenant` の3つのテナントがあり、ユーザーテナント `mysql_tenant` と `oracle_tenant` の両方でアーカイブモードが有効になっていると仮定します。次のステートメントを使用して、テナントのアーカイブモードを無効にできます。

* システムテナントがテナント `mysql_tenant` のアーカイブモードを無効にします。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM NOARCHIVELOG TENANT = mysql_tenant;
  ```

* システムテナントがテナント `mysql_tenant` と `oracle_tenant` のアーカイブモードを無効にします。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM NOARCHIVELOG TENANT = mysql_tenant, oracle_tenant;
  ```

* システムテナントは、すべてのユーザーテナントのアーカイブモードを無効にします。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM NOARCHIVELOG TENANT = all;
  ```

* ユーザーテナント `mysql_tenant` および `oracle_tenant` は、自身のテナントのアーカイブモードを無効にします。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM NOARCHIVELOG;
  ```
