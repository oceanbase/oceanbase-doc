# MODULE DATA

## 概要

`MODULE DATA` ステートメントには、以下の2つの機能があります：

* `ALTER SYSTEM LOAD MODULE DATA ...`：このステートメントは、特定のテナントに指定された機能をインポートするために使用されます。
* `ALTER SYSTEM CHECK MODULE DATA ...`：このステートメントは、特定のテナントの指定された機能がインポートされているかどうかを確認するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.2.5では、V4.2.5 BP2以降のバージョンから<code>MODULE DATA</code>ステートメントがサポートされています。</p>
</main>

## 制限事項と注意点

* このステートメントは、`sys`（システム）テナントでのみ実行できます。
* 現在のバージョンでは、MySQLモードのテナントにのみ`REDIS`モジュール機能をインポートできます。
* 現在のバージョンでは、インポートされた`REDIS`モジュール機能のチェック(`CHECK MODULE DATA`)のみサポートされています。

## 権限要件

このステートメントを実行するユーザーは、`ALTER SYSTEM`権限が必要です。OceanBaseデータベースの権限の詳細については、[MySQLモードにおける権限の分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
ALTER SYSTEM {LOAD | CHECK} MODULE DATA
    MODULE = module_value
    TENANT = tenant_name
    [INFILE = file_path];

module_value:
    REDIS
    | GIS
    | TIMEZONE
```

## パラメータの説明

|      パラメータ     |            説明            |
|---------------|---------------------------|
| LOAD \| CHECK | インポートまたはチェックを指定します。詳細は以下のとおりです：<ul><li>`LOAD`：特定のテナントに指定された機能をインポートします。</li><li>`CHECK`：特定のテナントの指定された機能がインポートされているかどうかを確認します。</li><li>|
| tenant_name   | 操作対象となるテナント名を指定します。|
| module_value  | 操作対象となる機能を指定します。詳細については、以下の[module_value](#module_value)を参照してください。|
| file_path     | インポートするSQLファイルのパスを指定します。<main id="notice" type='notice'><h4>注意</h4><p><ul><li><code>TIMEZONE</code> および <code>GIS</code> には複数バージョンのデータが存在する可能性があるため、対応するバージョンのSQLファイルを指定する必要があります。現在、<code>TIMEZONE</code> および <code>GIS</code> には1つのバージョンのみが存在するため、デフォルトの <code>INFILE</code> パラメータをサポートしています。</li><li>現在のバージョンでは、<code>REDIS</code> モジュールの機能は <code>INFILE</code> パラメータをサポートしていません。このパラメータのパスを入力するとエラーが発生します。</li></ul></p></main>|

### module_value

* `REDIS`：`REDIS` モジュール機能を操作することを示します。
* `GIS`：`GIS` モジュール機能を操作することを示します。
* `TIMEZONE`：`TIMEZONE` モジュール機能を操作することを示します。

## 例

### LOAD MODULE DATAの例

1. テナント`mysql001`に`REDIS`モジュール機能をインポートします。現在、`REDIS`モジュール機能は`INFILE`パスを使用することができないため、エラーが発生します。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = REDIS
        TENANT = mysql001
        INFILE = '/home/admin/test.sql';
    ```

    実行結果は次のとおりです：

    ```shell
    ERROR 4025 (HY000): loading redis module does not need to specify infile
    ```

2. テナント`mysql001`に`REDIS`モジュール機能をインポートします。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = REDIS
        TENANT = mysql001;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

3. テナント`mysql001`に`GIS`モジュール機能をインポートします。ここで、`INFILE`パラメータは省略可能です。デフォルト値は`etc/`であり、対応するファイルはデプロイメントディレクトリの`etc`ディレクトリ内にあります。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = GIS
        TENANT = mysql001
        INFILE = 'etc/';
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

4. テナント`mysql001`に`TIMEZONE`モジュール機能をインポートします。ここで、`INFILE`パラメータは省略可能です。デフォルト値は`etc/`であり、対応するファイルはデプロイメントディレクトリの`etc`ディレクトリ内にあります。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = TIMEZONE
        TENANT = mysql001
        INFILE = 'etc/';
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

### CHECK MODULE DATAの例

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>現在のバージョンでは、チェック (<code>CHECK MODULE DATA</code>) はインポートされた <code>REDIS</code> モジュール機能のみをサポートしています。</p>
</main>

* テナントに機能がインポートされていない場合、`CHECK MODULE DATA` ステートメントの実行時にエラーが発生します。テナント `mysql002` に `REDIS` モジュール機能がインポートされているかどうかを確認します。

    ```sql
    ALTER SYSTEM CHECK MODULE DATA
        MODULE = REDIS
        TENANT = mysql002;
    ```

    実行結果は次のとおりです：

    ```shell
    ERROR 4025 (HY000): redis info is not complete，please retry loading
    ```

* テナントに機能をインポートした後で、インポートされた機能の状況を確認します。

    1. テナント `mysql002` に `REDIS` モジュール機能をインポートします。

        ```sql
        ALTER SYSTEM LOAD MODULE DATA
            MODULE = REDIS
            TENANT = 'mysql002';
        ```

        実行結果は次のとおりです：

        ```shell
        Query OK, 0 rows affected
        ```

    2. テナント `mysql002` に `REDIS` モジュール機能がインポートされているかどうかを確認します。

        ```sql
        ALTER SYSTEM CHECK MODULE DATA
            MODULE = REDIS
            TENANT = mysql002;
        ```

        実行結果は次のとおりです：

        ```shell
        Query OK, 0 rows affected
        ```
