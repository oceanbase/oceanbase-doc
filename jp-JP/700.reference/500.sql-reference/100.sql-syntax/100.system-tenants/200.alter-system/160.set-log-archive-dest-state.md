# SET LOG_ARCHIVE_DEST_STATE

## 説明

`SET LOG_ARCHIVE_DEST_STATE` ステートメントは、アーカイブ宛先の状態を設定します。

## 権限要件

`sys` テナントの `root` ユーザー（`root@sys`）または各テナントの管理者ユーザーによって実行する必要があります。その中で：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE={'ENABLE' | 'DEFER'} [TENANT = tenant_name];
```

## パラメータの説明

| パラメータ                    | 説明                                                                                                   |
|-------------------------|--------------------------------------------------------------------------------------------------------|
| 'ENABLE' \| 'DEFER'     | アーカイブ宛先の状態を指定します。<ul><li>`ENABLE`：有効な状態です。この状態でアーカイブモードが有効になっている場合、まだアーカイブされていないデータについても、システムはアーカイブタスクの実行を開始します。アーカイブ宛先の設定が成功すると、デフォルトでこの状態になります。</li> <li>`DEFER`：一時停止状態です。この状態でアーカイブモードが有効になっており、かつアーカイブタスクが存在する場合、システムはアーカイブタスクを一時停止します。</li></ul>                                                                   |
| tenant_name             | システムテナントが設定対象のアーカイブ宛先の状態を指定するテナント名です。各ステートメントでは、1つのテナントのアーカイブ宛先のみを設定できます。<main id="notice" type='notice'><h4>注意</h4><p>このコマンドを実行する際は、システムテナントのみが <code>TENANT tenant_name</code> 句を使用して操作対象のテナントを指定する必要があります。ユーザーテナントは自身のテナントに対してのみこのコマンドを実行できるため、この句を指定する必要はありません。</p></main>  |

## 例

テナント `mysql_tenant` がアーカイブ宛先の設定を完了したと仮定します。例：

* システムテナントは、テナント `mysql_tenant` の宛先上でのログアーカイブを一時停止します。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'DEFER' TENANT = mysql_tenant;
  ```

* テナント `mysql_tenant` は、自テナントの宛先上でのログアーカイブを開始します。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'ENABLE';
  ```
