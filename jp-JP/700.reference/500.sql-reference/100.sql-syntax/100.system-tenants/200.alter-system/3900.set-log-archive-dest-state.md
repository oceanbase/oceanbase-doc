# SET LOG_ARCHIVE_DEST_STATE

## 説明

`SET LOG_ARCHIVE_DEST_STATE` ステートメントは、アーカイブ宛先の状態を設定します。

## 権限要件

`sys` テナントの `root` ユーザー（`root@sys`）または各テナントの管理者ユーザーが実行する必要があります。具体的には：

* MySQLモードのデフォルト管理者ユーザーは `root` ユーザーです。
* Oracleモードのデフォルト管理者ユーザーは `SYS` ユーザーです。

## 構文

```sql
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE={'ENABLE' | 'DEFER'} [TENANT = tenant_name];
```

## パラメータ説明

| パラメータ                    | 説明                                                                                                   |
|-------------------------|--------------------------------------------------------------------------------------------------------|
| 'ENABLE' \| 'DEFER'     | アーカイブ宛先の状態を指定します。<ul><li>`ENABLE`：有効状態です。この状態でアーカイブモードが有効であり、まだアーカイブされていない場合、システムはアーカイブタスクの実行を開始します。アーカイブ宛先が正常に設定された後、デフォルトでこの状態になります。</li> <li>`DEFER`：一時停止状態です。この状態でアーカイブモードが有効であり、アーカイブタスクが存在する場合、システムはアーカイブタスクを一時停止します。</li></ul>                                                                   |
| tenant_name             | システムテナントが、アーカイブ宛先の状態を設定するテナント名を指定します。1文につき、1つのテナントのアーカイブ宛先のみを設定できます。<main id="notice" type='notice'><h4>注意</h4><p>このコマンドを実行する際は、システムテナントのみが <code>TENANT tenant_name</code> 句を使用して操作対象のテナントを指定する必要があります。ユーザーテナントは自身のテナントでのみこのコマンドを実行できるため、この句を指定する必要はありません。</p></main>  |

## 例

テナント `mysql_tenant` のアーカイブ宛先設定が完了していることを前提とした例です：

* システムテナントがテナント `mysql_tenant` の宛先でのログアーカイブを一時停止します。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'DEFER' TENANT = mysql_tenant;
  ```

* テナント `mysql_tenant` が自身の宛先でのログアーカイブを開始します。

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'ENABLE';
  ```
