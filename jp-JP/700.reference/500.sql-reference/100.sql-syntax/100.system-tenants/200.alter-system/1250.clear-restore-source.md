# CLEAR RESTORE SOURCE

## 説明

このステートメントは、`ADD RESTORE SOURCE` ステートメントでロードされたパスを取り消すために使用されます。

## 権限要件

このステートメントを実行するには、現在のユーザーが `ALTER SYSTEM` 権限を持っている必要があります。

## 構文

```sql
ALTER SYSTEM CLEAR RESTORE SOURCE;
```
