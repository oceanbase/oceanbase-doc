# BACKUP CLUSTER PARAMETERS

`ALTER SYSTEM BACKUP CLUSTER PARAMETERS` ステートメントは、クラスタレベルのパラメータをバックアップするために使用します。

## 使用上の制限と注意事項

* このステートメントは、`sys` テナントの `root` ユーザーのみが実行できます。

* このステートメントは、デフォルト設定ではないクラスタ範囲のパラメータのみをバックアップします。

  <main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>all_server_list</code>、<code>rootservice_list</code>、<code>debug_sync_timeout</code> などのパラメータは、値がデフォルト値であるかどうかにかかわらず、バックアップされません。</p>
  </main>

## 構文

```sql
ALTER SYSTEM BACKUP CLUSTER PARAMETERS TO 'parameters_backup_path';
```

## パラメータ説明

| パラメータ                   | 説明                                                                |
|------------------------|---------------------------------------------------------------------------|
| parameters_backup_path | クラスタレベル構成パラメータのバックアップファイルのターゲットパスで、ユーザーが指定する必要があります。このパス要件はデータバックアップのバックアップ宛先パス要件と一致している必要があります。データバックアップのバックアップ宛先要件については、[バックアップ前の準備](../../../../../600.manage/600.backup-and-recovery/400.data-backup/100.preparation-before-data-backup.md)を参照してください。|

## 例

クラスタレベルのパラメータを `oss://oceanbase-test-bucket/backup/cluster_parameters?host=***.aliyun-inc.com&access_id=***&access_key=***` ディレクトリにバックアップします。

```shell
obclient> ALTER SYSTEM BACKUP CLUSTER PARAMETERS TO 'oss://oceanbase-test-bucket/backup/cluster_parameters?host=***.aliyun-inc.com&access_id=***&access_key=***';
```
