# BACKUP CLUSTER PARAMETERS

`ALTER SYSTEM BACKUP CLUSTER PARAMETERS` ステートメントは、クラスタレベルの構成パラメータをバックアップするために使用されます。

## 制限事項と注意点

* このステートメントは、`sys` テナントの `root` ユーザーのみが実行できます。

* このステートメントは、デフォルト以外の値を持つクラスタ全体の構成パラメータのみをバックアップします。

  <main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>all_server_list</code>、<code>rootservice_list</code>、および <code>debug_sync_timeout</code> などの構成パラメータは、その値がデフォルト値であるかどうかに関係なく、バックアップされません。</p>
  </main>

## 構文

```sql
ALTER SYSTEM BACKUP CLUSTER PARAMETERS TO 'parameters_backup_path';
```

## パラメータの説明

| パラメータ | 説明 |
|------------------------|---------------------------------------------------------------------------|
| parameters_backup_path | クラスタレベルの構成パラメータバックアップファイルのターゲットパス。ユーザーが指定する必要があります。そのパス要件は、データバックアップのバックアップ宛先パス要件と一致している必要があります。データバックアップのバックアップ宛先要件については、[バックアップ前の準備](../../../../../600.manage/600.backup-and-recovery/400.data-backup/100.preparation-before-data-backup.md)を参照してください。|

## 例

クラスタレベルの構成パラメータを `oss://oceanbase-test-bucket/backup/cluster_parameters?host=***.aliyun-inc.com&access_id=***&access_key=***` ディレクトリにバックアップします。

```shell
obclient> ALTER SYSTEM BACKUP CLUSTER PARAMETERS TO 'oss://oceanbase-test-bucket/backup/cluster_parameters?host=***.aliyun-inc.com&access_id=***&access_key=***';
```
