# WASH MEMORY FRAGMENTATION

## 説明

通常、システムがメモリ断片化によりメモリ割り当てに失敗した場合、システムは自動的にメモリ断片をクリーンアップして再試行します。また、`ALTER SYSTEM WASH MEMORY FRAGMENTATION` ステートメントを使用して手動でメモリ断片をクリーンアップすることもできます。このステートメントは、サーバー上のすべての空きBlockを解放します。

## 権限要件

`ALTER SYSTEM WASH MEMORY FRAGMENTATION` ステートメントを実行できるのは、`sys` テナントの `root` ユーザー（`root@sys`）のみです。

## 構文

```sql
ALTER SYSTEM WASH MEMORY FRAGMENTATION server_or_zone;

server_or_zone：
    SERVER [=] 'ip:port'
  | ZONE [=] 'zone_name'
```

## パラメータ説明

|         **パラメータ**       |         **説明**                                                              |
|------------------------|-------------------------------------------------------------------------------|
| server_or_zone         | クリーンアップ範囲を指定します。OBServerノードまたはZoneを指定します。                                            |
| ip:port                | クリーンアップ対象のOBServerノードのIPアドレスとRPCポート番号を指定します。1回につき1つのOBServerノードのみ指定可能です。  |
| zone_name              | クリーンアップ対象のZoneを指定します。1回につき1つのZoneのみ指定可能です。                                     |

## 例

* `Zone1` 内のすべてのOBServerノード上のメモリ断片をクリーンアップします。

  ```sql
  obclient [(none)]> ALTER SYSTEM WASH MEMORY FRAGMENTATION ZONE = 'zone1';
  ```

* 指定されたOBServerノード上のメモリ断片をクリーンアップします。

  ```sql
  obclient [(none)]> ALTER SYSTEM WASH MEMORY FRAGMENTATION SERVER = '10.10.10.1:2882';
  ```
