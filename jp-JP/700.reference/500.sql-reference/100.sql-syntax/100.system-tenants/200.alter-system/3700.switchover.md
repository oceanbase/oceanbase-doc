# スイッチオーバー

## 説明

このステートメントは、テナントのプライマリとスタンバイの役割を切り替えるために使用されます。これにより、プライマリテナントを損失なくスタンバイテナントに切り替えることができ、またスタンバイテナントをプライマリテナントに切り替えることもできます。

## 構文

```sql
ALTER SYSTEM SWITCHOVER TO {STANDBY | PRIMARY}
  [TENANT tenant_name]
  [VERIFY];
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>システムテナントがこのコマンドを実行する場合は、<code>TENANT tenant_name</code>パラメータを指定する必要があります。</li><li>通常のテナントは、このコマンドを自身のテナントに対してのみ実行できます。</li></ul></p>
</main>

## 構文の詳細

|   **フィールド**  | **説明** |
| ----------- | -------- |
| STANDBY     | プライマリテナントを損失なくスタンバイテナントに切り替えます。|
| PRIMARY     | スタンバイテナントをプライマリテナントに切り替えます。|
| tenant_name | プライマリ/スタンバイテナントの名前を指定します。|
| VERIFY      | オプションです。このパラメータを使用する場合、`SWITCHOVER` コマンドを実行するために必要な前提条件がすでに整っているかどうかを事前に検証します。 <main id="notice" type='notice'><h4>注意</h4><p><ul><li>プライマリ/スタンバイテナントのロール変換の実行中には、一定の失敗リスクがあります。<code>VERIFY</code> コマンドは単に初期検証を行い、ロール変換の前提条件を満たしているかどうかを評価するものであり、この操作の失敗可能性を低減するのに役立ちますが、実際には <code>SWITCHOVER</code> 操作を実行しません。</li><li><code>VERIFY</code> コマンドが正常に実行されたとしても、その後の <code>SWITCHOVER</code> 操作が必ず成功するとは限りません。</li></ul></p></main> |

## 例

プライマリテナントに対してプライマリからスタンバイへの切り替えコマンドを実行し、テナントをスタンバイテナント`tenant1`に変更します。また、プライマリテナントがスタンバイテナントに切り替わったことを確認します。`TENANT_ROLE`は`STANDBY`に、`SWITCHOVER_STATUS`は`NORMAL`に変更されます。

```shell
obclient> ALTER SYSTEM SWITCHOVER TO STANDBY TENANT tenant1;
Query OK, 0 rows affected

obclient> SELECT TENANT_NAME,TENANT_TYPE,TENANT_ROLE,SWITCHOVER_STATUS FROM DBA_OB_TENANTS
    WHERE TENANT_NAME='tenant1';
+---------------------+-------------+-------------+-------------------+
| TENANT_NAME         | TENANT_TYPE | TENANT_ROLE | SWITCHOVER_STATUS |
+---------------------+-------------+-------------+-------------------+
| t1                  | USER        | STANDBY     | NORMAL            |
+---------------------+-------------+-------------+-------------------+
1 row in set
```
