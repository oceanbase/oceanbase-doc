# CREATE TENANT

## 概要

`CREATE TENANT` ステートメントは、ユーザーテナントを作成するために使用されます。OceanBaseデータベースでは、ユーザーテナントのみを作成でき、システムテナントはクラスタ作成時にシステムが自動的に作成されます。Metaテナントは、OceanBaseデータベース内部で自動的に管理されるテナントであり、ユーザーテナントが作成されるたびに対応するMetaテナントも作成され、そのライフサイクルはユーザーテナントと一致します。

`CREATE TENANT` ステートメントで作成されたテナントのデフォルトのテナントロールは `PRIMARY` です。

## 制限事項と注意事項

* OceanBaseデータベースは、MySQL互換モードとOracle互換モードの2種類のテナントをサポートしています。テナントを作成する際には、適切なテナントタイプを指定する必要があります。テナントのタイプは、作成後に変更することはできません。

* テナントを作成する際には、リソースプールを割り当てる必要があります。リソースプールの作成には事前のリソース計画が必要であり、リソースプールの作成に関する操作については、[テナントの作成](../../../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)を参照してください。

## 権限要件

`sys` テナントの `root` ユーザー（`root@sys`）のみがテナントを作成できます。他のテナントではテナントの作成はサポートされていません。

## 構文

テナントを作成する構文は次のとおりです。

```sql
CREATE TENANT [IF NOT EXISTS] tenant_name
     [tenant_option_list] [set_sys_var];

tenant_option_list:
  tenant_option [, tenant_option...]

tenant_option:
      LOCALITY [=] 'locality_description'
    | PRIMARY_ZONE [=] primary_zone_name
    | RESOURCE_POOL_LIST [=] (pool_name [, pool_name...])
    | ENABLE_ARBITRATION_SERVICE [=] {True | False}
    | {CHARACTER SET | CHARSET} [=] charset_name
    | COLLATE [=] collation_name
    | {READ ONLY | READ WRITE}
    | COMMENT [=] 'string'

set_sys_var:
       {SET | SET VARIABLES | VARIABLES} var_name {TO | =} var_value [,var_name {TO | =} var_value...]
```

## パラメータの説明

|          パラメータ            |                説明                                                                                                      |
|--------------------------|--------------------------------------------------------------------------------------------------------------------------|
| tenant_name              | テナント名を指定します。最大63バイトで、大文字と小文字を区別する英字、数字、アンダースコアのみ使用でき、かつ、アルファベットまたはアンダースコアで始まり、OceanBaseデータベースのキーワードとしては使用できません。 |
| IF NOT EXISTS            | 作成しようとしているテナント名が既に存在し、かつ `IF NOT EXISTS` を指定していない場合、エラーが返されます。    |
| LOCALITY                 | レプリカがゾーン間でどのように分散されているかを記述します。 例えば：`F@z1,F@z2,F@z3` は `z1`、`z2`、`z3` がフル機能のレプリカであることを示します。     |
| PRIMARY_ZONE             | テナントが存在するプライマリゾーンを指定します。主に以下の値をサポートしています：<ul><li>`RANDOM`：テナントのプライマリゾーンをテナントが存在するすべてのゾーンに指定します。これは、テナントが存在するすべてのゾーンが同じ優先順位を持つことを意味します。</li> <li>zone_name：テナントのプライマリゾーンを具体的なゾーンに指定します。</li></ul> </br>テナントを作成する際にプライマリゾーンを指定しない場合、デフォルト値は `RANDOM` です。 |
| RESOURCE_POOL_LIST       | テナントに割り当てるリソースプールのリストを指定します。テナントを作成する際にはこのパラメータを必ず指定する必要があります。</br>複数のリソースプールがある場合、各リソースプールの `UNIT_NUM` の数が一致している必要があります。<main id="notice" type='notice'><h4>注意</h4><p>同一テナントの複数のリソースプール間では、それぞれの `ZONE_LIST` に重複があってはなりません。</p></main> |
| ENABLE_ARBITRATION_SERVICE | テナントにアービトレーションサービスを有効にするかどうかを指定します。このパラメータを指定しない場合、デフォルト値は `False` です。クラスタにアービトレーションサービスが存在する場合、テナントを作成する際にアービトレーションサービスを有効にしないと、テナントの作成後にアービトレーションサービスを有効にすることができます。詳細な操作については、[テナントにアービトレーションサービスを有効にする](../../../../600.manage/400.high-availability/400.arbitration-high-availability/200.enable-the-arbitration-service.md)を参照してください。|
| CHARACTER SET \| CHARSET | テナントレベルの文字セットを指定します。文字セットの詳細については、[文字セット（MySQLモード）](../200.common-tenant-of-mysql-mode/100.basic-elements-of-mysql-mode/300.character-set-and-collation-of-mysql-mode/200.character-set-of-mysql-mode.md) および [文字セット（Oracleモード）](../300.common-tenant-of-oracle-mode/300.basic-elements-of-oracle-mode/1000.character-set-and-collation-of-oracle-mode.md) を参照してください。   |
| COLLATE                  | MySQL互換モードのテナントを作成する際、テナントレベルの文字列照合順序を指定します。MySQLモードにおける文字列照合順序の詳細については、[文字列照合順序（MySQLモード）](../200.common-tenant-of-mysql-mode/100.basic-elements-of-mysql-mode/300.character-set-and-collation-of-mysql-mode/300.collation-of-mysql-mode.md)を参照してください。<main id="notice" type='explain'><h4>説明</h4><p>Oracle互換モードのテナントを作成する際は、テナントレベルの文字列照合順序を設定することはサポートされていません。文字列照合順序を設定しても、構文上はエラーは発生しませんが、設定は無視され、システムはその代わりに文字セットに対応するデフォルトの文字列照合順序に置き換えます。</p></main> |
| READ ONLY \| READ WRITE  | テナントのプロパティを読み取り専用か読み取り/書き込みかを指定します。指定しない場合は、デフォルトで読み取り/書き込みプロパティになります。|
| set_sys_var              | テナントレベルのシステム変数の値を指定します。`var_name`の詳細については、以下の[var_name](#var_name)を参照してください。|
| COMMENT                  | コメントを入力します。オプションです。   |
### var_name

`var_name` の一般的な値は以下のとおりです：

* `ob_compatibility_mode`：テナントの互換モード（MySQLモードまたはOracleモード）を指定します。このパラメータはテナント作成時にのみ指定できます。`ob_compatibility_mode` を指定しない場合、デフォルトでMySQLモードが使用されます。
* `ob_tcp_invited_nodes`：テナントに接続できるクライアントIPアドレスの白リストを指定します。例の `%` はすべてのクライアントが接続できることを意味します。`ob_tcp_invited_nodes` を指定しない場合、デフォルトではローカルIPアドレスのみがテナントに接続できるようになります。
* `lower_case_table_names`：大文字と小文字を区別するかどうかを制御します。このパラメータは `CREATE TENANT` ステートメントを使用してテナントを作成する際にのみ指定でき、MySQLモードでのみ有効です。テナント作成後はSQLステートメントで変更することはできません。

* `ob_compatibility_control`：MySQL互換モードの動作が競合する機能に対して、どの動作を優先するかを制御します。現在の値は `MYSQL5.7` または `MYSQL8.0` です。`MYSQL5.7` の動作と `MYSQL8.0` の動作とどちらに合わせるかを指定します。MySQLモードのテナントを作成する際にはこの変数を指定する必要があります。この変数はテナント作成時にのみ指定でき、作成後に変更することはできません。`ob_compatibility_control` を明示的に指定しない場合、デフォルトではMySQL 5.7の動作に合わせます。

## 例

* MySQL互換モードの`test_tenant`という名前のテナントを作成し、Primary Zoneを`zone1;zone2,zone3`、リソースプールを`pool1`、文字セットを`utf8mb4`とし、すべてのクライアントIPアドレスからのデータベース接続を許可します。

  ```sql
  obclient [oceanbase]>  CREATE TENANT IF NOT EXISTS test_tenant PRIMARY_ZONE='zone1;zone2,zone3', RESOURCE_POOL_LIST=('pool1'), CHARSET='utf8mb4' SET ob_tcp_invited_nodes TO '%';
  ```

* Oracle互換モードの`tenant1`という名前のテナントを作成し、Primary Zoneを`zone1`、リソースプールを`pool1`とし、すべてのクライアントIPアドレスからのデータベース接続を許可します。

  ```sql
  obclient [oceanbase]>  CREATE TENANT tenant1 PRIMARY_ZONE='zone1', RESOURCE_POOL_LIST=('pool1') SET ob_compatibility_mode='oracle',  ob_tcp_invited_nodes='%';
  ```
