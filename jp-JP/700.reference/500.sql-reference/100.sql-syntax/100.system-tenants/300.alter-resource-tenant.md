# ALTER RESOURCE TENANT

## 説明

リソースプールがテナントに割り当てられた後、リソースプールの構成パラメータである `UNIT_NUM` を変更する場合は、`ALTER RESOURCE TENANT` ステートメントを使用する必要があります。

リソースプールの他のプロパティを変更する場合は、`ALTER RESOURCE POOL` ステートメントを使用する必要があります。`ALTER RESOURCE POOL` ステートメントの詳細については、[ALTER RESOURCE POOL](300.alter-resource-pool.md)を参照してください。

## 制限事項と注意点

* `ALTER RESOURCE TENANT` ステートメントは、テナント内のすべてのリソースプールのユニット数を変更します。

* `ALTER RESOURCE TENANT` ステートメントを使用してテナントのスケーリング操作を実行する前に、そのテナントにロードバランシングポリシーを設定する必要があります。そうしないと、スケーリングが失敗する可能性があります。テナントにロードバランシングポリシーを設定するための詳細な操作と説明については、[Unit Numberの調整によるテナントのスケーリング](../../../../600.manage/200.tenant-management/600.common-tenant-operations/800.tenant-scale-in-and-out/300.adjust-unit-number.md)を参照してください。

## 権限要件

テナントのリソースプール構成を変更できるのは、`sys` テナントの `root` ユーザー (`root@sys`) のみです。他のテナントでは、テナントのリソースプール構成を変更することはサポートされていません。

## 構文

```sql
ALTER RESOURCE TENANT tenant_name UNIT_NUM [=] unit_num [ DELETE UNIT_GROUP = ( unit_group_id_list ) ];
```

## パラメータの説明

|  **パラメータ**         |   **説明**                                                                                      |
|-------------------|-------------------------------------------------------------------------------------------------|
| tenant_name       | 変更対象のリソースプール設定を持つテナント名。                                                                       |
| unit_num          | テナント内のすべてのリソースプールのユニット数を変更します。`UNIT_NUM` を増やす場合、その値はターゲットゾーン内のノード数以下である必要があります。                              |
| unit_group_id_list | 同型ゾーンモードのスケーリングダウンシナリオにのみ使用されます。`unit_num` を減らす場合、`DELETE UNIT_GROUP` を使用して指定されたユニットグループを削除できます。`DELETE UNIT_GROUP` を指定しない場合、システムはランダムに該当する数のユニットグループを削除します。 |

## 例

* テナント`tenant1`のすべてのリソースプールのユニット数を3に変更します。

  ```sql
  obclient [oceanbase]> ALTER RESOURCE TENANT tenant1 UNIT_NUM = 3;
  ```

* 同型ゾーンモードのスケーリングダウンシナリオでは、テナント`tenant2`の`UNIT_GROUP_ID`が`1006`のユニットグループを削除します。

  1. 以下のコマンドを順番に実行して、ロードバランシングを有効にします。

     ```sql
     obclient [oceanbase]> ALTER SYSTEM SET enable_rebalance = true TENANT = 'tenant2';
     ```

     ```sql
     obclient [oceanbase]> ALTER SYSTEM SET enable_transfer = true TENANT = 'tenant2';
     ```

  2. テナントの`TENANT_ID`を取得します。

     ```sql
     obclient [oceanbase]> SELECT TENANT_ID,TENANT_NAME,TENANT_TYPE FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'tenant2';
     ```

     クエリ結果は次のとおりです：

     ```shell
     +-----------+-------------+-------------+
     | TENANT_ID | TENANT_NAME | TENANT_TYPE |
     +-----------+-------------+-------------+
     |      1006 | tenant2     | USER        |
     +-----------+-------------+-------------+
     1 row in set
     ```

  3. テナントが保有するユニットを確認し、削除対象の`UNIT_GROUP_ID`を取得します。

     ```sql
     obclient [oceanbase]> SELECT UNIT_ID, TENANT_ID, STATUS, RESOURCE_POOL_ID, UNIT_GROUP_ID, ZONE, SVR_IP, SVR_PORT FROM oceanbase.DBA_OB_UNITS WHERE TENANT_ID = 1006;
     ```

     クエリ結果は次のとおりです：

     ```shell
     +---------+-----------+--------+------------------+---------------+-------+----------------+----------+
     | UNIT_ID | TENANT_ID | STATUS | RESOURCE_POOL_ID | UNIT_GROUP_ID | ZONE  | SVR_IP         | SVR_PORT |
     +---------+-----------+--------+------------------+---------------+-------+----------------+----------+
     |    1016 |      1006 | ACTIVE |             1003 |          1006 | zone1 | xxx.xx.xxx.194 |     2882 |
     |    1017 |      1006 | ACTIVE |             1003 |          1007 | zone1 | xxx.xx.xxx.198 |     2882 |
     |    1018 |      1006 | ACTIVE |             1003 |          1006 | zone2 | xxx.xx.xxx.192 |     2882 |
     |    1019 |      1006 | ACTIVE |             1003 |          1007 | zone2 | xxx.xx.xxx.196 |     2882 |
     |    1020 |      1006 | ACTIVE |             1003 |          1006 | zone3 | xxx.xx.xxx.204 |     2882 |
     |    1021 |      1006 | ACTIVE |             1003 |          1007 | zone3 | xxx.xx.xxx.197 |     2882 |
     +---------+-----------+--------+------------------+---------------+-------+----------------+----------+
     6 rows in set
     ```

  4. 取得した`UNIT_GROUP_ID`に基づいて、スケーリングダウン操作を実行します。

     ```shell
     obclient [oceanbase]> ALTER RESOURCE TENANT tenant2 UNIT_NUM = 1 DELETE UNIT_GROUP = (1006);
     ```

  5. 実行が成功した後、ビュー`DBA_OB_TENANT_JOBS`を使用して、ユニット数を減らすタスクの実行状態を確認できます。

     ```sql
     obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_JOBS WHERE JOB_TYPE='ALTER_RESOURCE_TENANT_UNIT_NUM' AND TENANT_ID=1006;
     ```

     クエリ結果は次のとおりです：

     ```shell
     +--------+--------------------------------+------------+-------------+----------+----------------------------+----------------------------+-----------+-----------------------------------------------------------------------+--------------------+----------------+-------------+
     | JOB_ID | JOB_TYPE                       | JOB_STATUS | RESULT_CODE | PROGRESS | START_TIME                 | MODIFY_TIME                | TENANT_ID | SQL_TEXT                                                              | EXTRA_INFO         | RS_SVR_IP      | RS_SVR_PORT |
     +--------+--------------------------------+------------+-------------+----------+----------------------------+----------------------------+-----------+-----------------------------------------------------------------------+--------------------+----------------+-------------+
     |      6 | ALTER_RESOURCE_TENANT_UNIT_NUM | SUCCESS    |           0 |      100 | 2023-09-25 18:01:30.069506 | 2023-09-25 18:01:45.068740 |      1006 | ALTER RESOURCE TENANT tenant2 UNIT_NUM = 2                            | FROM: '1', TO: '2' | xxx.xx.xxx.196 |        2882 |
     |      7 | ALTER_RESOURCE_TENANT_UNIT_NUM | SUCCESS    |           0 |      100 | 2023-09-26 09:37:32.367076 | 2023-09-26 09:39:05.651200 |      1006 | ALTER RESOURCE TENANT tenant2 UNIT_NUM = 1 DELETE UNIT_GROUP = (1006) | FROM: '2', TO: '1' | xxx.xx.xxx.196 |        2882 |
     +--------+--------------------------------+------------+-------------+----------+----------------------------+----------------------------+-----------+-----------------------------------------------------------------------+--------------------+----------------+-------------+
     2 rows in set
     ```
