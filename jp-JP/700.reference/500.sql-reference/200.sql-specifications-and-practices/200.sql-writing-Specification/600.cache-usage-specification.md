# cacheの使用規範

本記事では、OceanBaseデータベースにおけるcacheの使用規範について説明します。

* 業務上、特定のフィールドへの頻繁な書き込みが発生する場合は、カウンターの書き込みなど、書き込みキャッシュメカニズムの使用を推奨します。

* ヒントを使用したプランキャッシュの制御

  * `/*+ USE_PLAN_CACHE(NONE)*/` は、プランキャッシュを使用しないことを意味します。

  * `/*+USE_PLAN_CACHE(DEFAULT)*/` は、プランキャッシュを使用することを意味します。

* SQLステートメントでの `force index`、`ignore index`、`straight_join`、`SQL_no_cache` などのヒントの使用は禁止されています。
