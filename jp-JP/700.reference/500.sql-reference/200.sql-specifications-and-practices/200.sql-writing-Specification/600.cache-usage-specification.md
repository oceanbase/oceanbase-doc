# cacheの使用規範

本記事では、OceanBaseデータベースにおけるcacheの使用規範について説明します。

* ビジネス上、特定のフィールドへの頻繁な重複書き込みが発生する場合は、カウンターの書き込みなど、書き込みキャッシュメカニズムを使用することを推奨します。

* ヒントを使用して計画キャッシュを制御する

  * `/*+ USE_PLAN_CACHE(NONE)*/` は、計画キャッシュを使用しないことを意味します。

  * `/*+USE_PLAN_CACHE(DEFAULT)*/` は、計画キャッシュを使用することを意味します。

* SQL文でのヒントの使用は禁止されています。例えば、`force index`、`ignore index`、`straight_join`、`SQL_no_cache` などです。
