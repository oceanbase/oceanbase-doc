# DDLステートメントの記述規範

本記事では、OceanBaseにおけるデータベースDDLステートメントの記述規範について説明します。

- フルテーブル削除には、`TRUNCATE TABLE` ステートメントの使用を推奨します。

- オンラインDDL操作は、システムへの影響を軽減するため、業務の閑散時間帯に実施することを推奨します。

* V3.x系以前では、DDL操作の並列度は40以下に制御する必要があります。
