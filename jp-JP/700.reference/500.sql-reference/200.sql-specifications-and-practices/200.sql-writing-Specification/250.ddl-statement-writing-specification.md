# DDLステートメントの作成規範

本記事では、OceanBaseにおけるデータベースDDLステートメントの作成規範について説明します。

- フルテーブル削除は、`TRUNCATE TABLE` ステートメントを使用することを推奨します。

- オンラインDDL操作は、システムへの影響を軽減するため、業務のオフピーク時に行うことを推奨します。

* V3.x系以前では、DDL操作の同時実行数（コンカレンス）は40以下に抑える必要がありました。
