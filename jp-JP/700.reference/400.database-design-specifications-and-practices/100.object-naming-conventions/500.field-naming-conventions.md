# フィールド命名規範

データベース内でテーブルを作成する際、フィールドの命名には関連する規範に従う必要があります。本記事は、開発者がデータベース内のフィールド命名を規範化するための支援を目的としています。

## フィールド命名

* フィールド名は、英字を使用し、大文字または小文字のいずれか一方のみを使用し、大文字と小文字を混在させないことを推奨します。

* フィールド名は、英字で始めることを推奨します。

* フィールド名は、そのまま意味が分かるようにすることを推奨します。例：「NAME」。

* フィールド名は、アンダースコアで始めることや、アンダースコアで終わらせることを推奨しません。

* フィールド名は、数字で始めることを推奨しません。

* フィールド名には、システム予約語やキーワードを使用しないことを推奨します。

* フィールド名には、アンダースコーの間に数字のみを含むことを推奨しません。

* フィールド名には、複数形の名詞を使用することを推奨しません。

* フィールド名は、フィールドが表す機能名または一般的な標準略称を使用し、「_」で区切ることを推奨します。最適な形式は「業務名_フィールドの役割」です。例：「TASK_NUM」、「CREATE_DATE」、「STATION_DESC」、「TASK_ID」。
