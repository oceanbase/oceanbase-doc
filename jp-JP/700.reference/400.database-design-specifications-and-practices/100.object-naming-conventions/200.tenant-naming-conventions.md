# テナントの命名規則

テナントはOceanBase独自のオブジェクトであり、アーキテクチャ上、インスタンスに似ています。本記事は、開発者がテナントの命名規則を統一するためのものです。

## テナント名の命名に関する推奨事項

* テナント名は64バイト以内に収める必要があり、すべて小文字で表記します。

* テナント名には、業務部門の名称またはその略称を使用することを推奨します。例：deposit業務部門のテナント名は「deposit」となります。

* 特定の業務システムのサブシステムが独立したテナントとして扱われる場合、業務システム名またはその略称を使用し、英字、数字、アンダースコアで命名することを推奨します。例：deposit業務部門のaccountサブシステムのテナント名は「deposit_account」となります。
