# テナントの命名規則

テナントはOceanBase独自のオブジェクトであり、アーキテクチャ上、インスタンスに類似しています。本記事では、テナント名を統一するための指針を紹介します。

## テナント名に関する推奨事項

* テナント名は64バイト以内に収める必要があり、すべて小文字で表記します。

* テナント名には、業務ラインの名称または略称を使用することを推奨します。例：deposit業務ラインのテナント名は "deposit" です。

* 特定の業務システムのサブシステムが独立したテナントとなる場合、業務システム名または略称に、英字、数字、アンダースコアを組み合わせて命名することを推奨します。例：deposit業務ラインのaccountサブシステムのテナント名は "deposit_account" です。
