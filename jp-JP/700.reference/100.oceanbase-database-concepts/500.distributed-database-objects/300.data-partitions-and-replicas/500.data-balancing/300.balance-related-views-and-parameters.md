# データロードバランスに関するビューとパラメータ

## よく使われるビュー

| ビュー名                                               | 説明                                          |
|-------------------------------------------------------|-----------------------------------------------|
| DBA_OB_TABLE_LOCATIONS/CDB_OB_TABLE_LOCATIONS          | パーティションレプリカの分布状況を表示し、パーティションの詳細情報も含まれます。最もよく使用されるビューの1つです。 |
| DBA_OB_LS_LOCATIONS /CDB_OB_LS_LOCATIONS              | ログストリームレプリカの分布状況を表示します。 |
| DBA_OB_BALANCE_JOBS/CDB_OB_BALANCE_JOBS               | 拡張、縮小、パーティションの均等化など、実行中のロードバランシングタスクを表示します。 |
| DBA_OB_BALANCE_JOB_HISTORY/CDB_OB_BALANCE_JOB_HISTORY| ロードバランシングタスクの履歴を表示します。 |
| DBA_OB_BALANCE_TASKS/CDB_OB_BALANCE_TASKS             | LS分割やLS統合など、実行中のLS均等化タスクを表示します。 |
| DBA_OB_BALANCE_TASK_HISTORY/CDB_OB_BALANCE_TASK_HISTORY  | LS均等化タスクの履歴を表示します。 |
| DBA_OB_TRANSFER_TASKS/CDB_OB_TRANSFER_TASKS           | 実行中のTransferタスクを表示します。 |
| DBA_OB_TRANSFER_TASK_HISTORY/CDB_OB_TRANSFER_TASK_HISTORY  | Transferタスクの履歴を表示します。 |
| GV$OB_UNITS                                           | 予想Unitの分布と永続化されたリソースを表示します。 |
| GV$OB_SERVERS                                         | 各マシン上の実際のUnitの分布とリソースを表示します。 |

## パラメータ

| パラメータ名        | レベル   | デフォルト値| 説明                                                                          | 対象のロードバランシングポリシー |
|------------------|--------|------|-------------------------------------------------------------------------------|--------------|
| enable_rebalance                         | テナントレベル  | true | ロードバランシングの総合スイッチです。システムテナントではUnitの均等化を、ユーザーテナントではLSの均等化およびパーティションの均等化を制御します。| テナント内バランス、テナント間バランス
| enable_transfer                          | テナントレベル  | true | Transferスイッチです。オフの場合、すべてのTransfer動作を禁止します。</br><code>enable_rebalance=true</code> かつ <code>enable_transfer=false</code> の場合、LS数を変更しない特殊なバランス戦略を採用します。| テナント内バランス |
| balancer_idle_time                       | テナントレベル | 10s | バックグラウンドロードバランシングのスキャン間隔 | テナント内バランス  |
| enable_ls_leader_balance                 | テナントレベル | true  | ログストリームLeaderのバランススイッチです。<code>enable_rebalance</code>が有効な場合、<code>enable_ls_leader_balance</code>を無効にすると、ログストリームLeaderの自動バランスを個別に制御できます。| LSバランス |
| partition_balance_schedule_interval      | テナントレベル | 0s | パーティションバランススケジューリング間隔。テナント作成/クラスタ再起動時から計測。<main id="notice" type='notice'><h4>注意</h4><p>V4.4.x系では、このパラメータのデフォルト値はV4.4.1以降で0sに変更されました。V4.4.1以降のバージョンでは、このパラメータを使用してパーティションの均衡を制御することは推奨されません。ユーザーは<code>DBMS_BALANCE.TRIGGER_PARTITION_BALANCE</code>サブプログラムを呼び出すことで、定期的または手動でパーティションの均衡をトリガーできます。</p></main>| パーティションバランス |
| balancer_tolerance_percentage            | クラスタレベル | 10 | LSレベルのパーティションディスク均衡の許容範囲です。均衡状態で各LS間のディスク使用率の差がこの割合を超えないようにします。| パーティションディスク均衡|
| server_balance_cpu_mem_tolerance_percent | クラスタレベル | 5  | Unit均衡をトリガーするしきい値の割合です。ノード間のUnit負荷と平均負荷の差がこの割合を超えた場合、Unit均衡を通じてUnit移行を試みます。| Unit均衡 |
| server_balance_critical_disk_waterlevel  | クラスタレベル | 80 | ディスク使用率の割合しきい値です。これを超えた場合、ディスク使用状況に応じてUnit均衡をトリガーします。 | Unit均衡 |
