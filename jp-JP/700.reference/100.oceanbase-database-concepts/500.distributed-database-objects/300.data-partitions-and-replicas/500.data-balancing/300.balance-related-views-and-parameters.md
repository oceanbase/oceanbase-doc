# データバランシング関連のビューとパラメータ

## 主要ビュー

| ビュー名                                               | 説明                                          |
|-------------------------------------------------------|-----------------------------------------------|
| DBA_OB_TABLE_LOCATIONS/CDB_OB_TABLE_LOCATIONS          | パーティションレプリカの分散状況を表示し、パーティションの詳細情報も含まれます。最もよく使われるビューの一つです。 |
| DBA_OB_LS_LOCATIONS /CDB_OB_LS_LOCATIONS              | ログストリームレプリカの分散状況を表示します。 |
| DBA_OB_BALANCE_JOBS/CDB_OB_BALANCE_JOBS               | 拡張、縮小、パーティションの均等化など、実行中のロードバランシングタスクを表示します。 |
| DBA_OB_BALANCE_JOB_HISTORY/CDB_OB_BALANCE_JOB_HISTORY| ロードバランシングタスクの履歴を表示します。 |
| DBA_OB_BALANCE_TASKS/CDB_OB_BALANCE_TASKS             | LSの均等化、LSの統合など、実行中のLS均等化タスクを表示します。 |
| DBA_OB_BALANCE_TASK_HISTORY/CDB_OB_BALANCE_TASK_HISTORY  | LS均等化タスクの履歴を表示します。 |
| DBA_OB_TRANSFER_TASKS/CDB_OB_TRANSFER_TASKS           | 実行中のTransferタスクを表示します。 |
| DBA_OB_TRANSFER_TASK_HISTORY/CDB_OB_TRANSFER_TASK_HISTORY  | Transferタスクの履歴を表示します。 |
| GV$OB_UNITS                                           | 期待ユニットの分布と永続化されたリソースを表示します。 |
| GV$OB_SERVERS                                         | 各マシン上の実際のユニットの分布とリソースを表示します。 |

## パラメータ

| パラメータ名        | レベル   | デフォルト値| 説明                                                                          | 影響を受ける均等化戦略 |
|------------------|--------|------|-------------------------------------------------------------------------------|--------------|
| enable_rebalance                         | テナントレベル  | true | ロードバランシングの総合スイッチです。システムテナントではこのパラメータがユニットの均等化を制御し、ユーザーテナントではLSの均等化およびパーティションの均等化を制御します。| テナント内均等化、テナント間均等化
| enable_transfer                          | テナントレベル  | true | Transferスイッチです。オフにするとすべてのTransfer動作を禁止します。</br><code>enable_rebalance=true</code>で<code>enable_transfer=false</code>の場合は、LS数を変更しない特殊な均等化戦略を採用します。| テナント内均等化 |
| balancer_idle_time                       | テナントレベル | 10s | バックグラウンドロードバランシングのスキャン間隔 | テナント内均等化  |
| enable_ls_leader_balance                 | テナントレベル | true  | ログストリームLeaderの均等化スイッチです。<code>enable_rebalance</code>が有効な場合、<code>enable_ls_leader_balance</code>を無効にすることで、ログストリームLeaderの自動均等化を個別に無効にできます。| LS均等化 |
| partition_balance_schedule_interval      | テナントレベル | 0s | パーティション均等化スケジュール間隔で、テナント作成/クラスタ再起動から計測します。<main id="notice" type='notice'><h4>注意</h4><p>V4.4.x系では、このパラメータのデフォルト値はV4.4.1以降で0秒に変更されました。V4.4.1以降のバージョンでは、このパラメータを使用してパーティションの均等化を制御することは推奨されません。ユーザーは<code>DBMS_BALANCE.TRIGGER_PARTITION_BALANCE</code>サブプログラムを呼び出すことで、定期的または手動でパーティションの均等化をトリガーできます。</p></main>| パーティション均等化 |
| zone_disk_balance_tolerance_percentage   | テナントレベル | 10 | Zone間のテーブルグループディスク均等化アルゴリズムの不均衡許容度を制御します。 | テーブルグループディスク均等化 |
| balancer_tolerance_percentage            | クラスタレベル | 10 | LSレベルのパーティションディスク均等化の許容率です。均等化状態で各LS間のディスク使用量の差がこの割合を超えないようにします。| パーティションディスク均等化|
| server_balance_cpu_mem_tolerance_percent | クラスタレベル | 5  | ユニット均等化をトリガーするしきい値の割合です。ノード間のユニット負荷が平均負荷との差がこの割合を超えた場合、ユニット均等化を通じてユニット移行を試みます。| ユニット均等化 |
| server_balance_critical_disk_waterlevel  | クラスタレベル | 80 | ディスク使用量の割合しきい値です。これを超えた場合、ディスク使用量に応じてユニット均等化をトリガーします。 | ユニット均等化 |
