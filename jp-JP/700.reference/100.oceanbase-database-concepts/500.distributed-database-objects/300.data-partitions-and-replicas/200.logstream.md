# ログストリーム

この記事では、ログストリーム、パーティション、およびレプリカ間の関係について説明します。

ログストリームとは、連続的に増加する一連のログデータであり、データベース内のすべての変更操作を記録しています。変更はすべてのデータ同期の基盤であり、レプリカ、プライマリデータベースとスタンバイデータベース、バックアップデータはすべてログに記録された変更情報に依存しています。

OceanBaseデータベースV4.xでは、物理的な変更レコードが整理された複数のログストリームに集約されています。これらには、1つのシステムログストリームと複数のユーザーログストリームが含まれます。システムのすべての物理的変更情報はこれらのログストリームに記録され、障害復旧、ログアーカイブ、スタンバイデータベース同期などはすべて同一の物理的変更情報を使用します。

1つのテナント内で、1つのログストリームには複数のレプリカを配置でき、複数のレプリカ間ではPaxosプロトコルに基づいてデータが同期されます。これにより、少数派のレプリカに障害が発生した場合でも、RPO = 0、RTO < 8秒を実現できます。

OceanBaseデータベースV4.xでは、パーティションはユーザーの論理的概念であり、テーブルデータを分割および管理するための仕組みです。
