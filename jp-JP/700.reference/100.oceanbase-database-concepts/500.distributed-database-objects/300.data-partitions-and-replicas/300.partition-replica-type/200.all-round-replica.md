# フル機能レプリカ

フル機能レプリカは現在最も広く使用されているレプリカタイプであり、トランザクションログ、MemTable、SSTableなど、すべての完全なデータと機能を備えています。

フル機能レプリカには以下の特徴があります：

* 現在最も広く使用されているレプリカタイプであり、トランザクションログ、MemTable、SSTableなど、すべての完全なデータと機能を備えています。

* いつでも迅速にリーダーに切り替えて外部へサービスを提供できます。

* Paxosメンバーグループを構成でき、Paxosメンバーグループの多数派はフル機能レプリカである必要があります。

* 読み取り専用レプリカに変換できます。

その他の機能と説明は以下の表のとおりです。

|      プロパティ       |             説明              |
|----------------|-----------------------------|
| レプリカ名および略称        | FULL(F)                     |
|ログの有無        | あり、投票に参加(SYNC_CLOG)           |
|MemTableの有無   | あり(WITH_MEMSTORE)            |
|SSTableの有無    | あり(WITH_SSSTORE)          |
| データセキュリティ           | 高                           |
| リーダーへの復旧時間 | 短                           |
| リソースコスト           | 高                           |
| サービス             | リーダーは読み書きを提供、フォロワーは非一貫性読み取り可能 |
| レプリカタイプ変換制限       | 読み取り専用レプリカに変換可能       |
