# フル機能レプリカ

フル機能レプリカは現在、最も広く使用されているレプリカタイプであり、トランザクションログ、MemTable、SSTableなど、すべての完全なデータと機能を備えています。

フル機能レプリカには以下の特徴があります：

* トランザクションログ、MemTable、SSTableなど、すべての完全なデータと機能を備えており、現在最も広く使用されているレプリカタイプです。

* リーダーに迅速に切り替えて外部にサービスを提供できます。

* Paxosメンバーグループを構成でき、その過半数がフル機能レプリカである必要があります。

* 読み取り専用レプリカに変換できます。

その他の機能と説明は以下の表を参照してください。

|      特性項       |             説明              |
|----------------|-----------------------------|
| フォロワーの名前と略称        | FULL(F)                     |
| Logの有無        | 有り、投票に参加(SYNC_CLOG)           |
| MemTableの有無   | 有り(WITH_MEMSTORE)            |
| SSTableの有無    | 有り(WITH_SSSTORE)             |
| データセキュリティ           | 高                           |
| リーダーへの復旧時間 | 短い                           |
| リソースコスト           | 高                           |
| サービス             | リーダーは読み書きを提供し、フォロワーは非一貫性読み取り可能 |
| フォロワーのタイプ変換制限       | 読み取り専用のフォロワーに変換可能       |
