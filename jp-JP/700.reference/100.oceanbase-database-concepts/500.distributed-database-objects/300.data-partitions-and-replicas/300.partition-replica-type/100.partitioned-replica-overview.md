# ログストリームレプリカの概要

データの安全性と高可用性を確保するために、各ログストリームのデータは物理的に複数のコピーが保存されます。これらのコピーをログストリームのレプリカと呼びます。各レプリカには、ディスク上に保存されるTabletの静的データ（SSTable）、メモリ上に保存されるTabletの増分データ（MemTable）、およびトランザクションを記録したログという3種類の主要なデータが含まれます。保存されるデータの種類に応じて、レプリカにはいくつかの異なるタイプがあり、それぞれがデータの安全性、パフォーマンスのスケーラビリティ、可用性、コストなどの観点から異なるビジネスニーズをサポートします。

OceanBaseデータベースV4.x系では、以下のタイプのレプリカがサポートされています：

* フル機能レプリカ（FULL/F）

* 読み取り専用レプリカ（READONLY/R）

  V4.x系では、OceanBaseデータベースはV4.2.0バージョンから読み取り専用レプリカをサポートしています。

フル機能レプリカはPaxosレプリカと呼ばれ、対応するレプリカはPaxosメンバーグループを構成し、選挙投票に参加できます。読み取り専用レプリカは非Paxosレプリカと呼ばれ、対応するレプリカはPaxosメンバーグループを構成できず、選挙投票にも参加できません。

## レプリカタイプのプロパティ

現在、レプリカタイプとロケーション分布を指定するためのLocalityの構文は以下のとおりです：

```sql
LOCALITY='F{1}@z1,F@z2,R{1}@z3,F@z4,F@z5'
```

上記の構文において、`F{1}@z1`や`R{1}@z3`という書き方は`F@z1`や`R@z3`と同じ意味であり、角括弧内の数字は1のみとなります。
