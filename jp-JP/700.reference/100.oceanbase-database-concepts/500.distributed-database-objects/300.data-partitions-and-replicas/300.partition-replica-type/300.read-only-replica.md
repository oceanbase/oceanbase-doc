# 読み取り専用レプリカ

読み取り専用レプリカには、完全なログ、MemTable、SSTableなどが含まれます。

読み取り専用レプリカの主な特徴は以下のとおりです：

* 完全なログ、MemTable、SSTableなどが含まれます。

* Paxosメンバーグループを構成することはできず、Paxosメンバーとしてログの投票に参加することはありません。代わりに、観察者としてPaxosメンバーのログをリアルタイムで追従し、ローカルで再生します。そのため、投票メンバーの増加によるトランザクションコミットの遅延が発生することはありません。

* ビジネス上、読み取りデータの一貫性要件がそれほど高くない場合には、読み取り専用サービスを提供できます。

* フル機能レプリカに変換できます。

その他の機能と説明は、以下の表に示されています。

|      特性項       |                      説明                       |
|----------------|-----------------------------------------------|
| フォロワー名および略称        | READONLY(R)                                   |
| ログの有無        | あり、非同期ログですが、Paxosグループには属さず、単なるリスナー(ASYNC_CLOG)です |
| MemTableの有無   | あり(WITH_MEMSTORE)                              |
| SSTableの有無    | あり(WITH_SSSTORE)                               |
| データセキュリティ           | 中                                             |
| リーダーへの復旧時間 | サポートされていません                                           |
| リソースコスト           | 高                                             |
| サービス             | 非一貫性読み取りが可能です                                        |
| フォロワー種類変換制限       | 全機能型フォロワーへの変換のみが可能です                                    |
