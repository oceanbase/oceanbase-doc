# 読み取り専用レプリカ

読み取り専用レプリカには、完全なログ、MemTable、SSTableなどが含まれます。

読み取り専用レプリカには、主に以下の特徴があります：

* 完全なログ、MemTable、SSTableなどが含まれます。

* Paxosメンバーグループを構成することはできません。Paxosメンバーとしてログの投票に参加するのではなく、観察者としてPaxosメンバーのログをリアルタイムで追従し、ローカルで再生します。そのため、投票メンバーの増加によるトランザクションコミットの遅延は発生しません。

* 業務上、データの読み取り一貫性に対する要求が高くない場合に、読み取り専用サービスを提供できます。

* 全機能レプリカに変換できます。

その他の特徴と説明は以下の表のとおりです。

|      機能項目       |                      説明                       |
|----------------|-----------------------------------------------|
| レプリカ名および略称        | READONLY(R)                                   |
| LOGの有無        | あり。非同期ログですが、Paxosグループには属さず、単なるリスナー(ASYNC_CLOG)です |
| MemTableの有無   | あり(WITH_MEMSTORE)                              |
| SSTableの有無    | あり(WITH_SSSTORE)                             |
| データセキュリティ           | 中                                             |
| リーダーへの復旧時間 | サポートされていません                                           |
| リソースコスト           | 高                                             |
| サービス             | 非一貫性読み取りが可能                                        |
| レプリカタイプ変換制限       | 全機能レプリカへの変換のみが可能                                    |
