# ステートメントプロシージャ

ステートメントプロシージャとは、SQL文とオプションの制御フロー文をプリコンパイルした集合であり、PLエンジンが一つの単位として処理します。一つのステートメントプロシージャは他のステートメントプロシージャを参照することができ、複数の変数を返すことも可能です。

## ステートメントプロシージャの構造

ステートメントプロシージャの構造は以下の通りです：

```sql
PROCEDURE name [ ( parameter_list ) ]
{ IS | AS }
[ declarative_part ]
BEGIN    -- 実行開始部分
statement; [ statement; ]...
[ EXCEPTION ]
exception_handler; [ exception_handler; ]... ]
END;
```

## ステートメントプロシージャの作成

`CREATE PROCEDURE` ステートメントを使用してステートメントプロシージャを作成できます。ステートメントプロシージャを作成する構文は以下の通りです：

```sql
CREATE [OR REPLACE] PROCEDURE Procedure_name
[ (argment [ { IN | IN OUT }] Type,
      argment [ { IN | OUT | IN OUT } ] Type ]
    [ AUTHID DEFINER | CURRENT_USER ]
{ IS | AS }
delarification_block
BEGIN
    procedure_body
EXCEPTION
  exception_handler
END;
```

パラメータなしのステートメントプロシージャの例は以下の通りです：

```sql
obclient> CREATE TABLE loghistory
      (userid VARCHAR2(20),
      logdate DATE DEFAULT SYSDATE);
Query OK, 0 rows affected
obclient> DELIMITER /
obclient> CREATE OR REPLACE PROCEDURE userlogin
      IS
  BEGIN
      INSERT INTO loghistory (userid) VALUES (USER);
  END;
  /
Query OK, 0 rows affected
```

## ステートメントプロシージャの呼び出し

ステートメントプロシージャの作成が完了すると、ユーザーは権限付与によりOBClient、OceanBase開発者センターODC、またはサードパーティの開発ツールから呼び出して実行できます。

例：

```sql
obclient> SELECT * FROM loghistory;
Empty set

obclient> BEGIN
     userlogin;
     END;
     /
Query OK, 0 rows affected

obclient> SELECT * FROM loghistory;
+--------+-----------+
| USERID | LOGDATE   |
+--------+-----------+
| HR     | 27-SEP-20 |
+--------+-----------+
1 row in set

obclient> COMMIT;
Query OK, 0 rows affected
```
