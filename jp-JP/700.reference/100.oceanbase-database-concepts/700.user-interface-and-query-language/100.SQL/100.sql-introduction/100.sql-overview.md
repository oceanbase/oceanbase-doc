# SQLの概要

構造化クエリ言語（Structured Query Language）の略称であるSQLは、特定の目的に特化したプログラミング言語であり、データベースのクエリやプログラミングに用いられる言語です。これにより、関係データベースシステムへのアクセス、およびデータの検索、更新、管理が可能になります。プログラムやユーザーは共に、SQL文を通じてデータにアクセスします。

SQLは、OceanBaseデータベースなどの関係データベースへのインターフェースを提供します。

汎用的かつ統一された言語として、SQLは以下のタスクを実行できます：

* オブジェクトの作成、置換、変更、削除

* テーブル行の挿入、更新、削除

* データのクエリ

* データベースおよびそのオブジェクトへのアクセスの制御

* データベースの整合性と完全性の保証

SQLは、対話型（ユーザーが直接OceanBaseデータベースにSQL文を送信する方式）で使用することも、CやJavaなどのさまざまな言語に組み込んで使用することもできます。
