# SQLの概要

構造化クエリ言語（Structured Query Language）は、SQLと略され、特定の目的のために使用されるプログラミング言語です。データベースのクエリやプログラミングに用いられ、関係データベースシステムへのデータアクセス、およびクエリ、更新、管理を行います。プログラムもユーザーもSQL文を通じてデータにアクセスします。

SQLは、関係データベース（例：OceanBaseデータベース）へのアクセスインターフェースを提供します。

SQLは汎用的な統一言語として、以下のタスクを実行できます：

* オブジェクトの作成、置換、変更、削除

* テーブル行の挿入、更新、削除

* データのクエリ

* データベース及びそのオブジェクトへのアクセス制御

* データベースの一貫性と完全性の保証

SQLは、対話型（ユーザーが直接SQL文をOceanBaseデータベースに送信する）で使用することも、CやJavaなどの異なる言語に組み込んで使用することもできます。
