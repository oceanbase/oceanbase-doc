# SQLの標準

OceanBaseデータベースは、業界で公認された標準に準拠しています。

現在、業界で認められている委員会は、アメリカ国家規格協会(ANSI)と国際標準化機構(ISO)です。ANSIとISO/IECはどちらも、リレーショナルデータベースの標準言語としてSQLを採用しています。

SQL標準は10の部分で構成されています。そのうちの1つの部分(SQL/RPR:2012)の最新版は2012年に改訂されました。5つの部分は2011年に改訂されました。他の4つの部分は、2008年に改訂されたバージョンが引き続き使用されています。

OceanBaseデータベースのSQLは、ANSI/ISO標準SQL言語を大幅に拡張しています。ツールOBClientおよびODCを使用することで、OceanBaseデータベースに基づくすべてのANSI/ISO標準SQLステートメント、および任意の拡張ステートメントや関数を実行できます。
