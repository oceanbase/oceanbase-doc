# SQLの標準

OceanBaseデータベースは業界で認められた標準に従います。

現在、業界で認められている委員会はアメリカ国家規格協会(ANSI)と国際標準化機構(ISO)です。ANSIとISO/IECはどちらも、関係データベースの標準言語としてSQLを採用しています。

SQL標準は10の部分から構成されています。そのうちの一部(SQL/RPR:2012)の最新バージョンは2012年に改訂されました。5つの部分は2011年に改訂されました。残りの4つの部分は、2008年に改訂されたバージョンが引き続き使用されています。

OceanBaseデータベースのSQLは、ANSI/ISO標準のSQL言語に多くの拡張を加えています。ツールOBClientおよびODCを使用することで、OceanBaseデータベースに基づくANSI/ISO標準のSQLステートメント、および任意の拡張ステートメントや関数を実行できます。
