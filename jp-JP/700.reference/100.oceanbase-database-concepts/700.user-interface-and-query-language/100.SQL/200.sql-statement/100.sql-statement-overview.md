# SQL文の概要

OceanBaseデータベースに対する運用保守タスクやデータ処理など、すべての操作にはSQL文が使用されます。

SQL文とは、コンピュータ言語または命令であり、識別子、パラメータ、変数、データ型、およびSQL予約語で構成されます。

​SQL文は完全なSQL句でなければなりません。例えば：

```sql
​SELECT last_name，department_id FROM employee;
```

​OceanBaseデータベースは完全なSQL文のみを実行します。以下の例のような断片はエラーを生成し、さらにテキストが必要であることを示します：

```sql
​SELECT last_name;
```

OceanBaseデータベースのSQL文は、以下の3つのカテゴリに分類されます：

* データ定義言語（DDL）文

* データ操作言語（DML）文

* データ制御文（DCL）文
