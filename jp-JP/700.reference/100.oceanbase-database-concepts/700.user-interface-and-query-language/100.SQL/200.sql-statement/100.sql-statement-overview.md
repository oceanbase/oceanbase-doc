# SQLステートメントの概要

OceanBaseデータベースの運用保守タスクやデータ処理など、すべての操作にはSQLステートメントを使用します。

SQLステートメントは、識別子、パラメータ、変数、データ型、およびSQL予約語で構成されるコンピュータ言語または命令です。

​SQLステートメントは完全なSQL句でなければなりません。例：

```sql
​SELECT last_name，department_id FROM employee;
```

​OceanBaseデータベースは完全なSQLステートメントのみを実行します。以下の例のような断片はエラーを生成し、より多くのテキストが必要であることを示します：

```sql
​SELECT last_name;
```

OceanBaseデータベースのSQLステートメントは、以下の3種類に分類されます：

* データ定義言語（DDL）ステートメント

* データ操作言語（DML）ステートメント

* データ制御言語（DCL）ステートメント
