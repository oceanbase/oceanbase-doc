# DCL

データ制御言語（DCL）ステートメントは、データアクセス権限を制御するためのコマンドであり、指定されたアカウントに対して指定されたデータベースリソースへのアクセス権限を制御できます。

一部のユーザーは、デフォルトで特定のデータへのアクセス権限を持っています。例えば、Oracleモードでは、データにはOwnerという概念があり、あるSchema内のデータのOwnerは同名のユーザーです。データのOwnerは、特別な権限付与なしでデータにアクセスできますが、非Ownerの場合は権限付与が必要です。一方、MySQLモードでは、データにOwnerという概念はなく、データへのアクセスには権限付与が必要です。

例1：Schema A内のテーブル`ta`に対するクエリ権限をユーザーBに付与します。

```sql
GRANT SELECT ON a.ta TO b;
```

例2：Schema A内のテーブル`ta`に対するユーザーBのクエリ権限を取り消します。

```sql
REVOKE SELECT ON a.ta FROM b;
```
