# メモリ管理の概要

OceanBaseデータベースはマルチテナント設計のデータベースであり、同一プロセスが複数のテナントのリクエストを実行します。テナントのリソース分類には3種類あります：500テナントメモリ、システムテナントメモリ、業務テナントメモリです。

* 500は特殊な仮想テナントであり、共有用途で使用されるメモリや、実体テナント以外で消費されるメモリは、OceanBaseデータベースによって500テナントの使用量に計上されます。

* システムテナントは、OceanBaseデータベースが自動的に作成する最初の実体テナントであり、クラスタ関連の内部テーブルを管理します。これらの内部テーブルに対するリクエストによって使用されるメモリは、sysテナントの使用量に計上されます。

* 業務テナントとは、クラスタのインストール後にDBAが作成し、業務リクエストを処理する実体テナントです。これらのテナントのリクエストによって使用されるメモリは、そのテナントの使用量に計上されます。
