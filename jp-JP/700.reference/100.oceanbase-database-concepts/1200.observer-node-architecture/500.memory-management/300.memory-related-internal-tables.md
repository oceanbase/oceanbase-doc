# メモリ関連ビュー

OceanBaseデータベースでは、ビューを通じてメモリ使用状況を確認できます。

|                  ビュー                  | 説明                                                                |
|---------------------------------------|----------------------------------------------------------------------|
| GV$OB_MEMORY                         | OBServerノードのメモリタグ統計情報。                                           |
| GV$OB_MEMSTORE                       | MemStore統計情報。                                                    |
| GV$OB_KVCACHE                        | Kvcache統計情報。                                                     |
