# メモリ関連のビュー

OceanBaseデータベースは、ビューを通じてメモリ使用状況を確認できます。

|                  ビュー                  | 説明                                                                |
|---------------------------------------|----------------------------------------------------------------------|
| GV$OB_MEMORY                         | OBServerノードのメモリタグに関する統計情報。                                           |
| GV$OB_MEMSTORE                       | MemStoreの統計情報。                                                    |
| GV$OB_KVCACHE                        | Kvcacheの統計情報。                                                     |
