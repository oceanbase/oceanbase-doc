# パーティションキー

パーティションキーは、1つまたは複数の列の集合であり、パーティションテーブル内の各行がどのパーティションに属するかを決定します。各行は明確に1つのパーティションに割り当てられます。

例えば、ユーザーテーブルにおいて、`user_id` 列をRangeパーティションのキーとして指定できます。データベースは、この列のユーザーIDが指定された範囲内にあるかどうかに基づいて、行をパーティションに割り当てます。

OceanBaseデータベースは、パーティションキーを使用して、挿入、更新、削除操作を自動的に対応するパーティションに定向します。
