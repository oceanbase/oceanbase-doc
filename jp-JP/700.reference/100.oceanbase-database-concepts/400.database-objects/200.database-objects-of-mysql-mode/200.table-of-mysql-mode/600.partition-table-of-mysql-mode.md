# パーティションテーブル

OceanBaseデータベースは、非パーティションテーブルとパーティションテーブルをサポートしています。

パーティション方式が定義されていないテーブルは非パーティションテーブルと呼ばれ、そうでない場合はパーティションテーブルと呼ばれます。

パーティションテーブルは1つ以上のパーティションで構成されており、これらのパーティションは個別に管理され、他のパーティションと独立して実行することができます。たとえパーティションテーブルが1つのパーティションのみで構成されている場合でも、それは非パーティションテーブルとは異なります。非パーティションテーブルにはパーティションを追加することはできません。

パーティションの概念については、[パーティションの概要](../400.partition-of-mysql-mode/100.partitions-overview-of-mysql-mode.md)を参照してください。
