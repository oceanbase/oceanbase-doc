# パーティションテーブル

OceanBaseデータベースは、パーティション化されていないテーブルとパーティションテーブルの両方をサポートしています。

パーティショニング方式が定義されていないテーブルを非パーティションテーブルと呼び、それ以外のものをパーティションテーブルと呼びます。

パーティションテーブルは1つまたは複数のパーティションで構成されており、これらのパーティションは個別に管理され、他のパーティションとは独立して動作できます。たとえパーティションテーブルが1つのパーティションのみで構成されている場合でも、そのテーブルは非パーティションテーブルとは異なります。非パーティションテーブルにはパーティションを追加することはできません。

パーティションの概念については、[パーティションの概要](../400.partition-of-mysql-mode/100.partitions-overview-of-mysql-mode.md)を参照してください。
