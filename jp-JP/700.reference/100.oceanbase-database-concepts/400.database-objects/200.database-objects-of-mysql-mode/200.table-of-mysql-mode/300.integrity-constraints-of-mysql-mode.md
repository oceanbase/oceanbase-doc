# 基一性制約

基一性制約（Integrity Constraint）は、データが業務ルールに従うことを保証し、ルールに適合しない不正なデータがデータテーブルに挿入されるのを防ぐために使用されます。本記事では、基一性制約を使用してデータベースのテーブルに不正なデータの挿入を防ぐ方法について説明します。

​OceanBase データベースの MySQL モードのテナントは、基一性制約を使用して、ユーザーがデータベースのテーブルに不正なデータを挿入するのを防ぐことができます。基一性制約の役割は、データベース内に保存される情報が一定の業務ルールに従うことを保証することです。DML ステートメントの実行結果が基一性制約に違反した場合、ステートメントはロールバックされ、エラーメッセージが返されます。

​例えば、ユーザーが `employees` テーブルの `salary` 列に基一性制約を定義したとします。この基一性制約は、`salary` 列の数値が 10,000 より大きいデータ行を `employees` テーブルに挿入できないように規定しています。特定の `INSERT` または `UPDATE` ステートメントがこの基一性制約に違反した場合、ステートメントはロールバックされ、エラーメッセージが返されます。

​基一性制約の詳細については、[データの整合性](../700.data-integrity-of-mysql-mode/100.data-integrity-overview-of-mysql-mode.md)を参照してください。
