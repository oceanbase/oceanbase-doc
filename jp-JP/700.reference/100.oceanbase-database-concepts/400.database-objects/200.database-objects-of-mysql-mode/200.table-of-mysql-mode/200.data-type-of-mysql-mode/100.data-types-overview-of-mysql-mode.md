# データ型の概要

OceanBaseデータベースでは、テーブル内の各列にはデータ型が設定されており、それぞれのデータ型には独自のストレージ形式、制約、値の範囲が対応しています。

OceanBaseデータベースがサポートするSQLデータ型には、以下のものが含まれます：

* 数値型

* 日付時刻型

* 文字列型

* ビッグオブジェクトデータ型

* テキスト型

* 列挙型

* コレクション型

* マルチモーダルデータ型

  * JSONデータ型
  * 空間データ型
