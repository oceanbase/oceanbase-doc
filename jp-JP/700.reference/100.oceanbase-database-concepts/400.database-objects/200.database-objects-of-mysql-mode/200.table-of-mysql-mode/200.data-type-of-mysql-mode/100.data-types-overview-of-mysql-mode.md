# データ型の概要

OceanBaseデータベースでは、テーブルの各列にはデータ型が割り当てられており、各データ型は独自の格納形式、制約、値の範囲に対応しています。

OceanBaseデータベースでサポートされているSQLデータ型は以下のとおりです：

* 数値型

* 日付時刻型

* 文字列型

* ラージオブジェクト型

* テキスト型

* 列挙型

* 集合型

* マルチモーダルデータ型

  * 空間型

  * JSONデータ型
