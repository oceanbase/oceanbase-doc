# インデックスの格納

OceanBaseデータベースでは、インデックステーブルの格納は通常のデータテーブルと同様であり、データもマクロブロックとマイクロブロックの構造に格納されます。OceanBaseデータベースは集約インデックステーブルモデルを採用しているため、インデックス行にはユーザーが指定したインデックス列に加えて、メインテーブルの主キー列も格納され、メインテーブルへの再アクセスを容易にします。
