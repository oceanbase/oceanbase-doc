# ビューによるデータアクセス

OceanBaseデータベースは、ビューに対応するクエリ文を内部のデータディクショナリに保存します。

ユーザーがビューを通じてデータを読み取ろうとした場合、OceanBaseデータベースは以下の手順を実行します：

1. ユーザーのクエリを解析し、解析中にビュー名に遭遇した場合は、データディクショナリからビューに対応するクエリ文を取得して解析します。

2. そのビューをユーザーのクエリと統合しようとします。統合後、より良い実行計画が生成される可能性があります。

3. 実行計画を生成し、そのステートメントを実行します。

## 例

1. `staff_dept_10` という名前のビューを作成します。このビューの定義は以下のとおりです。

   ```plsql
   CREATE VIEW staff_dept_10 AS
   SELECT employee_id, last_name, job_id, manager_id, department_id
   FROM   employees
   WHERE  department_id = 10
   ```

2. ユーザーは次のクエリを実行して `staff_dept_10` にアクセスします。

   ```plsql
   SELECT last_name FROM  staff_dept_10 WHERE  employee_id = 200;
   ```

3. OceanBaseデータベースはまず上記のクエリを次のようなクエリに解析します。

   ```plsql
   SELECT last_name
   FROM   (SELECT employee_id, last_name, job_id,
                          manager_id, department_id
                                   FROM   employees
                                   WHERE  department_id = 10) staff_dept_10
   WHERE  employee_id = 200;
   ```

4. クエリの書き換えでは、ビュー定義とメインクエリを統合しようとします。

   ```plsql
   SELECT last_name
   FROM  employees
   WHERE  employee_id = 200 and department_id = 10;
   ```

5. OceanBaseデータベースのSQLエンジンは、上記のSQLに対応する実行計画を生成して実行します。
