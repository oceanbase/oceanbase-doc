# MySQLテナントへのOracleビューの移植

MySQLテナントでは、一部のOracleデータベース関連ビューが互換性を持ちます。

## 保存場所

Oracle互換ビューは、MySQLテナントおよびシステムテナントに移植された場合、OceanBaseデータベース内に配置され、MySQLテナント（SYSテナントを含む）からのみアクセス可能です。

## ビューの特徴

MySQLテナントへのOracleビューの移植は、Oracle標準ビューと以下の点で共通点と相違点があります。

* 共通点：
  * ビュー名は、Oracleビューの`DBA_*`ビューと同名です。
  * 列名および実装は、Oracleビューの`DBA_*`ビューと一致しています。
* 相違点：

  同名のビューでも列の意味が異なります。Oracle標準ビューでは、`OWNER`列はUSERを表し、`CON_ID`列は`container_id`を表します。しかし、MySQLテナントではそれぞれ`Database`、`tenant_id`を表します。

## ビューの区別

移植後のビューには、データディクショナリビューと動的性能ビューが含まれます。

* データディクショナリビュー：`oceanbase.DBA_*`をプレフィックスとし、現在のテナントの一部のデータベースオブジェクトに関する情報を取得するために使用できます。
* 動的性能ビュー：`oceanbase.V$*`、`oceanbase.GV$*`をプレフィックスとし、各`oceanbase.V$*`ビューにはほぼ対応する`oceanbase.GV$*`ビューが存在します。OceanBaseクラスタでは、`oceanbase.GV$*`ビューを照会すると、条件に合致するすべての`oceanbase.V$*`ビュー情報が返されます。
