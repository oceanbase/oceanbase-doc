# MySQLテナントからOracleビューの移植

MySQLテナントでは、一部のOracleデータベース関連ビューと互換性があります。

## 保存場所

Oracle互換ビューは、MySQLテナントおよびシステムテナントに移植された場合、OceanBaseデータベース内に配置され、MySQLテナント（SYSテナントを含む）からのみアクセス可能です。

## ビューの特徴

MySQLテナントに移植されたOracleビューは、Oracle標準ビューと以下の点で共通点と相違点があります。

* 共通点：
  * ビュー名はOracleビューの`DBA_*`ビューと同じです。
  * 列名および実装はOracleビューの`DBA_*`ビューと一致しています。
* 相違点：

  同一名称のビューでも列の意味が異なります。Oracle標準ビューでは、`OWNER`列はUSERを表し、`CON_ID`列は`container_id`を表します。しかし、MySQLテナントではそれぞれ`Database`、`tenant_id`を表します。

## ビューの区別

移植後のビューには、データディクショナリビューと動的性能ビューが含まれます。

* データディクショナリビュー：`oceanbase.DBA_*`をプレフィックスとし、現在のテナントの一部のデータベースオブジェクトに関する情報を取得するために使用できます。
* 動的性能ビュー：`oceanbase.V$*`、`oceanbase.GV$*`をプレフィックスとします。各`oceanbase.V$*`ビューにはほぼ対応する`oceanbase.GV$*`ビューが存在します。OceanBaseクラスタでは、`oceanbase.GV$*`ビューをクエリすると、すべての条件に合致する`oceanbase.V$*`ビューの情報が返されます。
