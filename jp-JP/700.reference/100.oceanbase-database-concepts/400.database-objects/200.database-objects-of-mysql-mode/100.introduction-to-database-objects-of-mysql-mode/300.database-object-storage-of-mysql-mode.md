# データベースオブジェクトストレージ

OceanBaseデータベースは、一部のデータベースオブジェクトのデータを1つまたは複数のSSTableに格納します。1つのSSTableは1つ以上のマクロブロックを含み、各マクロブロックは1つ以上のマイクロブロックを含み、各マイクロブロックは1行または複数行を含みます。ビューや仮想テーブルなど、メタデータ情報のみを持つ一部のデータベースオブジェクトは、実際のデータは格納されません。
