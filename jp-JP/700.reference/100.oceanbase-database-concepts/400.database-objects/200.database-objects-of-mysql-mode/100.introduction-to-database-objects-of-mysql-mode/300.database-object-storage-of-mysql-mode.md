# データベースオブジェクトストレージ

OceanBaseデータベースは、一部のデータベースオブジェクトのデータを1つまたは複数のSSTableに格納します。1つのSSTableは1つ以上のマクロブロックを含み、各マクロブロックには1つ以上のマイクロブロックが含まれ、各マイクロブロックには1行または複数行が含まれます。ビュー、仮想テーブルなどの一部のデータベースオブジェクトは、メタデータ情報のみを持つため、実際のデータは格納されません。
