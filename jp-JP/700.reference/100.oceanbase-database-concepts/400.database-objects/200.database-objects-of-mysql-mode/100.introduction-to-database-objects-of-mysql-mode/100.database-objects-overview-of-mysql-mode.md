# データベースオブジェクトの概要

データベースオブジェクトはデータベースの構成要素であり、SQLを用いて操作や利用が可能な対象を指します。本章では、OceanBaseデータベースのMySQLモードでサポートされているデータベースオブジェクトの種類、格納方式、およびデータベースオブジェクト間の依存関係について説明します。

OceanBaseデータベースのMySQLモードにおけるデータベースオブジェクトには、主にテーブル（Table）、ビュー（View）、インデックス（Index）、パーティション（Partition）、シーケンス（Sequence）、トリガー（Trigger）、およびストアドプログラムなどが含まれます。

MySQLモードのユーザー（User）は、関連する権限を付与されると、データベースに接続し、データベースオブジェクトにアクセスまたは操作を実行できます。データベース（Database）はデータベースオブジェクトの集合であり、権限管理と名前空間の分離に使用されます。スキーマ（Schema）はデータベース（Database）の同義語であり、SQLでは `CREATE DATABASE` の代わりに `CREATE SCHEMA` など、Database キーワードの代わりに Schema キーワードを使用できます。
