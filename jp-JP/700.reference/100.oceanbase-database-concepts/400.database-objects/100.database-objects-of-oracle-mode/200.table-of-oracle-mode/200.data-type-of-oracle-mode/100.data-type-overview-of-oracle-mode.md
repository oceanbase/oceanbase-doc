# データ型の概要

OceanBaseデータベースでは、テーブルの各列にはデータ型が割り当てられており、各データ型は固有の格納形式、制約、値の範囲に対応しています。この章では、最も一般的に使用されるOceanBaseデータベースの組み込みデータ型について説明します。

OceanBaseデータベースはいくつかの組み込みデータ型を提供しており、その中で最も一般的に使用されるのは以下の5種類です：

* 文字データ型

* 数値データ型

* 日付時刻データ型

* Rowidデータ型

* マルチモーダルデータ型

  * JSONデータ型
  * XMLデータ型
  * 空間データ型

その他の重要なデータ型には、`RAW`、BLOBデータ型、コレクションデータ型が含まれます。PLでは、`BOOLEAN`、参照型、複合型（`COLLECTION`および`RECORD`型を含む）、およびユーザー定義型を含む他の型を定数や変数に指定することもできます。

データ型は、データに一連の固定属性を関連付け、これらの属性によりOceanBaseデータベースは異なるデータ型を区別して処理できます。例えば、`NUMBER`型のデータに対して乗算操作を行うことができますが、`RAW`型のデータに対してはこのような操作を行うことはできません。

ユーザーがテーブルを作成する際には、各列にデータ型を指定する必要があり、その後挿入する各行のデータは指定した型と一致している必要があります。
