# フォーマットモデルの概要

OceanBaseデータベースのOracleモードでは、フォーマットモデルを使用して、データベースに格納される日付時刻データまたは数値データの形式を指定できます。

フォーマットモデルは、データベース内の値の内部表現を変更しません。データベースが文字列を日付または数値に変換する場合、フォーマットモデルはその文字列をどのように変換および格納するかを決定します。

SQLステートメントでは、フォーマットモデルを`TO_CHAR`、`TO_NUMBER`、`TO_DATE`などの関数のパラメータとして使用して、次の形式を指定できます。

* データベースから返される値の形式

* データベースに格納される値の形式

OceanBaseデータベースは、次の2種類のデータフォーマットモデルをサポートしています。

* [数値フォーマットモデル](../700.format-model-of-oracle-mode/200.digital-format-model-of-oracle-mode.md)

* [日付時刻フォーマットモデル](../700.format-model-of-oracle-mode/200.digital-format-model-of-oracle-mode.md)

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースは、現在フォーマット修飾子 <code>FX</code> および <code>FM</code> をサポートしていません。</p>
