# フォーマットモデルの概要

OceanBaseデータベースのOracleモードでは、フォーマットモデルを使用して、データベースに保存される日付時刻データや数値データの書式を指定できます。

フォーマットモデルは、データベース内の値の内部表現を変更するものではありません。データベースが文字列を日付または数値に変換する際、フォーマットモデルがその変換方法および文字列の格納方法を決定します。

SQL文では、`TO_CHAR`、`TO_NUMBER`、`TO_DATE` などの関数のパラメータとしてフォーマットモデルを使用し、以下の書式を指定できます：

* データベースが返す値の書式

* データベースに保存される値の書式

OceanBaseデータベースは、以下の2種類のデータフォーマットモデルをサポートしています：

* [数値フォーマットモデル](../700.format-model-of-oracle-mode/200.digital-format-model-of-oracle-mode.md)

* [日付時刻フォーマットモデル](../700.format-model-of-oracle-mode/200.digital-format-model-of-oracle-mode.md)

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースは、現在フォーマット修飾子 <code>FX</code> と <code>FM</code> をサポートしていません。</p>
