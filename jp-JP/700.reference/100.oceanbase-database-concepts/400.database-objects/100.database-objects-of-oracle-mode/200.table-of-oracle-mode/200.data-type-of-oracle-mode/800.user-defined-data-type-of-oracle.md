# ユーザー定義データ型

UDTとはユーザー定義型のことで、ビジネス構造に合わせて適切なカスタム型を作成できます。以前はPL内でのみ使用が可能でしたが、OceanBaseデータベースV4.4.2 BP2バージョンからテーブル列型としての使用がサポートされるようになりました。これにより、より柔軟なテーブルデータモデルの構築が可能になります。

現在、以下の2種類のUDTがテーブル列としてサポートされています（複雑なネスト型をサポート）。

* OBJECT
* VARRAY

## 構文サポート

現在、以下の構文機能がサポートされています：

* `create` でUDT列型を含むテーブルを作成することをサポートします。
* `alter table add column`/`drop column`/`modify column` でUDT列の追加、削除、変更をサポートします。
* `insert` でUDT列データを挿入することをサポートします。
* `update` でUDT列配列を更新することをサポートします。
* UDT列データへのアクセスをサポートします。
* UDT列のプロパティまたはメンバー関数へのアクセスをサポートします。
* `table function` で `varray` 型のUDT列を使用することをサポートします。

## 使用例

* オブジェクト型の作成

    ```sql
    CREATE TYPE type_obj1 AS OBJECT (
        a int,
        b int
    );

    CREATE TYPE type_array AS VARRAY(10) of int;
    ```

* UDT列を持つテーブルの作成

    ```sql
    CREATE TABLE t_udt (c1 int, c2 type_obj1, c3 type_array);
    ```

* データの挿入

    ```sql
    INSERT INTO T_UDT VALUES(1, TYPE_OBJ1(1,2), TYPE_ARRAY(1,2,3));
    ```

* データのUPDATE

    ```sql
    UPDATE T_UDT SET C2 = TYPE_OBJ1(11,22);
    ```

* UDT列のクエリ

    ```sql
    SELECT C1, C2, C3 FROM T_UDT;
    ```

* UDT列のプロパティを照会する

    ```sql
    SELECT T.C2.A, T.C2.B FROM T_UDT T;
    ```

* `table function` を使用して `varray` 型UDT列にアクセスする

    ```sql
    SELECT tf.* from T_UDT, table(T_UDT.c3) tf;
    ```

## 機能制限

* テーブル列に依存するUDTは、`alter type` でプロパティを変更できません。
* テーブルに依存するUDTは、`drop force` をサポートしていません。
* 制約や `order by` では `object.addr` の使用はサポートされていません。
* updateではプロパティの更新をサポートしていません。
* 現在のOceanBaseバージョンでは、書き込まれたUDT COLUMN値は、CDCによってオンラインスキーマモードで処理される必要があります。
