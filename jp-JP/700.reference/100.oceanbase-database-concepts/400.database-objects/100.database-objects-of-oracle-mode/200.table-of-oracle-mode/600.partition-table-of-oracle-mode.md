# パーティションテーブル

OceanBaseデータベースは、パーティションテーブルとパーティション化されていないテーブルの両方をサポートしています。

パーティショニング方式が定義されていないテーブルはパーティション化されていないテーブルと呼ばれ、それ以外の場合はパーティションテーブルです。

パーティションテーブルは1つまたは複数のパーティションで構成されており、これらのパーティションは個別に管理され、他のパーティションとは独立して動作できます。たとえパーティションテーブルが1つのパーティションのみで構成されている場合でも、そのテーブルはパーティション化されていないテーブルとは異なります。パーティション化されていないテーブルにはパーティションを追加することはできません。

パーティションの概念については、[パーティションの概要](../400.partition-of-oracle-mode/100.the-partition-overview-of-oracle-mode.md)を参照してください。
