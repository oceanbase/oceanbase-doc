# パーティションテーブル

OceanBaseデータベースは、非パーティションテーブルとパーティションテーブルをサポートしています。

パーティション方式が定義されていないテーブルは非パーティションテーブルと呼ばれ、それ以外はパーティションテーブルです。

パーティションテーブルは1つ以上のパーティションで構成されており、これらのパーティションは個別に管理され、他のパーティションと独立して実行できます。パーティションテーブルが1つのパーティションのみで構成されている場合でも、非パーティションテーブルとは異なります。非パーティションテーブルにはパーティションを追加することはできません。

パーティションの概念については、[パーティションの概要](../400.partition-of-oracle-mode/100.the-partition-overview-of-oracle-mode.md)を参照してください。
