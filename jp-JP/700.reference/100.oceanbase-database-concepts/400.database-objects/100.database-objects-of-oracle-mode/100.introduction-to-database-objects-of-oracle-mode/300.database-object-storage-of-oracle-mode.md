# データベースオブジェクトストレージ

OceanBaseデータベースは、一部のデータベースオブジェクトのデータを1つまたは複数のSSTableに格納します。1つのSSTableは1つ以上のマクロブロックを含み、各マクロブロックは1つ以上のマイクロブロックを含み、各マイクロブロックは1行または複数行を含みます。一部のデータベースオブジェクト（例えばビュー）はメタデータ情報のみを持つため、実際のデータは格納されません。

​一部の従来のデータベースとは異なり、OceanBaseデータベースのテーブルスペースはシステムが自動的に管理します。ユーザーはテーブルスペースを明示的に作成したり管理したりする必要はありません。一部の機能ではテーブルスペースに関する構文がサポートされており（例えば透過的データ暗号化機能の使用時）、ユーザーはテーブルスペース関連のプロパティを設定できます。
