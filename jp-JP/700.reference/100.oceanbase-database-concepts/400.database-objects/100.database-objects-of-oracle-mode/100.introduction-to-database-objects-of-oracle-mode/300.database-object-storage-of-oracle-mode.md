# データベースオブジェクトストレージ

OceanBaseデータベースは、一部のデータベースオブジェクトのデータを1つまたは複数のSSTableに格納します。1つのSSTableには1つ以上のマクロブロックが含まれ、各マクロブロックには1つ以上のマイクロブロックが含まれ、各マイクロブロックには1行または複数行が含まれます。一部のデータベースオブジェクト（例えばビュー）はメタデータ情報のみを持つため、実際のデータは格納されません。

​従来の一部のデータベースとは異なり、OceanBaseデータベースのテーブルスペースはシステムが自動的に管理します。ユーザーは明示的にテーブルスペースを作成および管理する必要はありません。一部の機能では、テーブルスペースに関連する構文（例えば透過的暗号化機能を使用する場合）がサポートされており、ユーザーはテーブルスペース関連のプロパティを設定できます。
