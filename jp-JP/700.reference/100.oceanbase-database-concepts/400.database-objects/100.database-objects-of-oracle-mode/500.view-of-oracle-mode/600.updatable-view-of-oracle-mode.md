# 更新可能なビュー

ユーザーはビューを通じてデータを読み取るだけでなく、ビューを通じてデータを更新することもできます。これらの更新可能なビューを更新可能ビューと呼びます。

例えば、ビュー `staff_dept_10` に対して、ユーザーは以下のような削除操作を実行できます：

```plsql
DELETE staff_dept_10 WHERE employee_id = 200;
```

OceanBaseデータベースはこのリクエストを受信した後、次のような処理プロセスを実行します：

1. ステートメントを解析し、`staff_dept_10` をビューの定義に置き換えます。

2. そのビューが更新対象として、いくつかの必要な制約を満たしているかどうかを確認します。

3. そのビューをメインステートメントにマージしようとします。

4. プランを生成して実行します。

OceanBaseデータベース内部では、実際に実行される削除ステートメントは次のとおりです：

```plsql
DELETE employees WHERE employee_id = 200 and department_id = 10;
```

ビューが更新可能なステートメントによって変更できるかどうかは、以下のような必要条件を満たす必要があります：

* 一つの変更操作は、一つのエンティティテーブルのみを変更できます。

* 変更対象のテーブル内の各行について、ビューのクエリでは各行が一度しか現れません。多対多の結合クエリはこの性質を持ちません。

* 変更対象のビューに `WITH READ ONLY` のマークが付いていないこと。
