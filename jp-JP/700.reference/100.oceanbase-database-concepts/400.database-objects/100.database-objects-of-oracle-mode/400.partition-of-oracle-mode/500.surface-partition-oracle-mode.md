# 外部テーブルのパーティショニング

外部テーブルのパーティションでは、各パーティションが複数のファイルに対応します。パーティションプルーニングにより、読み取り対象のファイルを選別できます。これにより、外部テーブルのファイル管理の使いやすさとクエリ効率が向上します。データをパーティション化することで、クエリ操作は特定のパーティションのみに対して実行でき、テーブル全体のすべてのデータをスキャンする必要がなくなるため、クエリ効率が向上し、リソース消費が削減されます。
