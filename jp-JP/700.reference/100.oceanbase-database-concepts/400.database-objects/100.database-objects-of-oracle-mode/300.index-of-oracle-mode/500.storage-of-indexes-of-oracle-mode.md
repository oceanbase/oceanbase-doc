# インデックス付きストレージ

OceanBaseデータベースでは、インデックステーブルのストレージは通常のデータテーブルと同様であり、そのデータもマクロブロックとマイクロブロックの構造に格納されます。OceanBaseデータベースは集約インデックステーブルモデルを採用しているため、インデックス行にはユーザーが指定したインデックス列に加えて、主テーブルの主キー列も格納され、テーブルへのアクセスを容易にします。
