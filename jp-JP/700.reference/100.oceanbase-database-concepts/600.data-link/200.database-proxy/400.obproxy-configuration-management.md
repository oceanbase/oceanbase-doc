# ODPの設定管理

ODPの設定はODPの動作を制御します。ODPの設定の変更や確認などが可能です。

ODPは設定をローカルファイルに保存します。このファイルはobproxy起動ディレクトリの`etc`配下にあり、名前は`obproxy_config.bin`です。このファイルを確認することで簡単な設定内容を見ることができますが、このファイルは変更できません。変更すると設定が異常になる可能性があります。

現在、ODPの設定はすべてプロセスレベルであり、設定後はODPにアクセスするすべてのリクエストに影響します。テナント、クラスタ、ユーザーなどの細かい粒度での設定はできません。

## パラメータ説明

ODPパラメータは以下のカテゴリに分類できます：

* 動的に変更できるパラメータ。

  この種のパラメータは変更後すぐに反映されます。詳細については、[動的に変更できるパラメータ](https://en.oceanbase.com/docs/community-odp-en-10000000000864246)を参照してください。

* 動的に変更できないパラメータ。

  この種のパラメータは変更後、ODPを再起動しないと反映されません。詳細については、[動的に変更できないパラメータ](https://en.oceanbase.com/docs/community-odp-en-10000000000864247)を参照してください。

* メモリレベルのパラメータ。

  この種のパラメータの変更は1回限り有効になります。詳細については、[メモリレベルのパラメータ](https://en.oceanbase.com/docs/community-odp-en-10000000000864218)を参照してください。

## ODP設定の確認

ODPを実行する際、`root@proxysys` アカウントでODPにログインします。パスワードはユーザーがODPをインストールした際に自分で設定します。以下のコマンドを実行してODPの設定を取得します：

```sql
SHOW proxyconfig [LIKE '%var_name%'];
```

すべての設定を確認する必要がある場合は、直接 `show proxyconfig` と入力するだけで、結果は表形式で表示されます。以下の情報が含まれます：

* name：設定名。

* value：設定値。

* info：設定の紹介。この紹介から設定の用途を理解できます。

* need_reboot：再起動が必要かどうか。値がtrueの場合、変更後は再起動が必要であることを示します。

* visible_level：未使用

## 設定の変更

ODPの設定は以下の2つの方法で変更できます：

* 起動時に `-o` パラメータの後に設定内容を追加します。例：`-o <var_name>=<var_value>`。

* `root@proxysys` でログインし、`alter proxyconfig set <var_name>=<var_value>` で設定を変更します。need_reboot の設定は動的に反映されないため、必ず再起動する必要があります。

ODPには、一度だけ有効になる設定もあります。以下の表を参照してください：

|                   パラメータ                    |  デフォルト値  |                  説明                   |
|-----------------------------------------|-------|---------------------------------------|
| refresh_json_config                     | false | JSON設定をconfig serverから再取得するかどうかを設定します。   |
| refresh_rslist                          | false | RSリスト設定をconfig serverから再取得するかどうかを設定します。 |
| refresh_idc_list                        | false | IDC設定をconfig serverから再取得するかどうかを設定します。    |
| refresh_config                          | false | MetaDBからすべての設定を更新するかどうかを設定します。              |
| partition_location_expire_relative_time | 0     | n秒後にすべてのlocation cacheが無効になります。nは設定値です。    |

ODPのその他の設定については、`show proxyconfig` で確認するか、ODPのドキュメントを参照してください。

## ドライバーのサポート

ODPの `root@proxysys` 操作はMySQLプロトコルと完全に互換性があり、MySQLプロトコルの `COM_QUERY` フィールドを使用しています。ODPの設定管理もJavaなどのMySQLドライバーを通じて管理できます。
