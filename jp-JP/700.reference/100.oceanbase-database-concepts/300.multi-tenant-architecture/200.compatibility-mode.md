# 互換モード

OceanBaseデータベースは、1つのシステム内でMySQLモードとOracleモードの両方のモードをサポートするテナントを同時に持つことができます。ユーザーはテナント作成時に、MySQL互換モードまたはOracle互換モードのテナントを選択できます。テナントの互換モードは一度設定すると変更できません。そのため、すべてのデータ型、SQL機能、ビューなどは、それぞれMySQLデータベースまたはOracleデータベースと一致します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>OceanBaseデータベースCommunity Editionは、MySQLモードのみを提供しています。</p>
  </main>

## MySQLモード

MySQLモードは、MySQLデータベースからOceanBaseデータベースへの移行に伴う業務システムの改修コストを削減し、同時に業務データベースの設計者、開発者、管理者などが蓄積したMySQLデータベースの技術知識や経験を再利用し、OceanBaseデータベースを迅速に習得できるようにするためのテナントタイプ機能です。OceanBaseデータベースのMySQLモードは、MySQL 5.7のほとんどの機能と構文に互換性があり、MySQL 5.7バージョンの全機能および8.0バージョンの一部のJSON関数に対応しています。これにより、MySQLベースのアプリケーションはスムーズに移行できます。

## Oracleモード

OceanBaseデータベースはV2.x.xバージョンからOracle互換モードをサポートしています。Oracleモードは、OracleデータベースからOceanBaseデータベースへの移行に伴う業務システムの改修コストを削減し、同時に業務データベースの設計・開発者、管理者などが蓄積したOracleデータベースの技術知識や経験を再利用し、OceanBaseデータベースを迅速に習得できるようにするためのテナントタイプ機能です。Oracleモードは現在、ほとんどのOracle構文と手続き型言語機能をサポートしており、大部分のOracle業務をわずかに修正するだけで自動的に移行できます。
