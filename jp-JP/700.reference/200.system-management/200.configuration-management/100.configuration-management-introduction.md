# 設定管理の紹介

OceanBaseデータベースは、パラメータとシステム変数を設定することで、設定管理を実現します。

## 構成パラメータ

構成パラメータは主に運用保守に使用され、マシンやそれ以上のレベルのシステム動作を制御するために一般的です。ノード起動時のパラメータやテナント作成時のパラメータとして設定できるほか、ノードが稼働中にシステム動作を調整するために変更することもできます。
構成パラメータの詳細については、[パラメータの設定](../200.configuration-management/200.set-parameters.md)を参照してください。

## システム変数

システム変数は通常、ユーザーのセッションにバインドされ、セッションレベルのSQL動作を制御します。

グローバルレベルとセッションレベルの変数を設定できます。グローバルレベルのシステム変数を設定しても、現在のセッションでは有効にならず、新しく作成されるすべてのセッションが新しい変数値を読み取ります。セッションレベルのシステム変数を設定すると、その変更は現在のセッション内でのみ有効になります。

システム変数の詳細については、[変数の設定](../200.configuration-management/300.set-variables.md)を参照してください。

| 永続化  | 内部テーブルと設定ファイルに永続化され、この構成パラメータは `/home/admin/oceanbase/etc/observer.config.bin` および `/home/admin/oceanbase/etc/observer.config.bin.history` ファイルで確認できます。                                                                                                                                                                                                                                     | GLOBALレベルの変数のみが永続化され、SESSIONレベルの変数は永続化されません。                                                                                                                                                                                                                                                                                                                                                                                                                    |
