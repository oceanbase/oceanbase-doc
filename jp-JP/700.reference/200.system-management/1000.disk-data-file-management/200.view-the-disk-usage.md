# テーブルが使用するディスク容量の確認

OceanBaseデータベースでは、ビューを通じてテーブル内のデータが使用するディスク容量を確認できます。

## 制限

V4.2.5バージョンについては、V4.2.5 BP3バージョンから、ユーザーテナントが`DBA_OB_TABLE_SPACE_usage`ビューを使用してテーブルが使用するディスク容量を確認できるようになりました。

## 手順

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLテナントの管理者ユーザーは<code>root</code>ユーザー、Oracleテナントの管理者ユーザーは<code>SYS</code>ユーザーです。</p>
   </main>

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のステートメントを実行して、テーブルデータのディスク容量使用状況を確認します。

   :::tab
   tab MySQLモード

   MySQLテナントは、自身のテナント内の各テーブルのディスク容量使用状況を確認するために、以下のステートメントを使用します。

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLE_SPACE_USAGE;
   ```

   tab Oracleモード

   Oracleテナントは、自身のテナント内の各テーブルのディスク容量使用状況を確認するために、以下のステートメントを使用します。

   ```shell
   obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLE_SPACE_USAGE;
   ```

   :::

   クエリ結果の例は次のとおりです：

   ```shell
   +----------+---------------+--------------------------------+-------------+---------------+
   | TABLE_ID | DATABASE_NAME | TABLE_NAME                     | OCCUPY_SIZE | REQUIRED_SIZE |
   +----------+---------------+--------------------------------+-------------+---------------+
   |   500011 | test          | wide_table_row_storage2        |  4495925120 |    4613763072 |
   |   500012 | test          | wide_table_column_storage2     |  3915023145 |    4195397632 |
   |   500014 | test          | wide_table_row_column_storage2 |  8410964107 |    9805275136 |
   +----------+---------------+--------------------------------+-------------+---------------+
   3 rows in set
   ```

   実行結果には次の項目が含まれます：

   * `OCCUPY_SIZE`：テーブル圧縮後にディスクに書き込まれたデータ量、単位はバイトです。
   * `REQUIRED_SIZE`：テーブル圧縮後にディスクに書き込まれたデータ量が実際に使用したディスク容量、単位はバイトです。

   実行結果から`(OCCUPY_SIZE / REQUIRED_SIZE) * 100%`を計算することで、ディスク容量の利用率を求めることもできます。例えば、この例では、テーブル`wide_table_row_storage2`のディスク容量利用率は`(4495925120 / 4613763072) * 100% = 97.4%`です。
