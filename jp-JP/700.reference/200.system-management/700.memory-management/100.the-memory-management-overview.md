# メモリ管理の概要

OceanBaseデータベースは、マルチテナントアーキテクチャをサポートする準メモリ級の分散型データベースであり、大量のメモリの管理と利用に対して高い要求が課されます。OceanBaseデータベースでは、サーバーの大部分のメモリを占有し、統一的に管理する方式でメモリを管理します。

新しい業務が立ち上げられる際には、そのために新しいテナントを作成します。この際、メモリはテナントが割り当て可能なメモリからリソースを割り当てます。テナントのCPUおよびメモリのサイズは、業務規模によって決まります。割り当て可能なCPUおよびメモリリソースが不足した場合は、OceanBaseクラスタを水平スケールすることで、拡大し続ける業務規模に対して持続可能なサービス能力を提供する必要があります。
