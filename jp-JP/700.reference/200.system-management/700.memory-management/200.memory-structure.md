# メモリ構造

<!-- ![メモリ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/700.reference/200.system-management/memory-struc.jpg) -->

上図から分かるように、OceanBaseデータベースの1ノードが使用するメモリサイズは、サーバー全体の一定の割合（または絶対値）として設定できます。このメモリの一部はノード自身のシステム運用（ノード予約メモリ）に使用され、残りの部分は作成されたテナントに割り当てられます。各テナントは従来のデータベースのインスタンスに相当し、システムテナントを除く他のテナントではメモリ構成が同一です。システムテナントには対応するMetaテナントが存在せず、そのメモリは増分データを格納するMemStoreとKVCacheキャッシュに直接分割されます。一方、ユーザーテナントには対応するMetaテナントが存在するため、ユーザーテナントのメモリは、テナント自身のメモリと対応するMetaテナントのメモリに分かれます。そして、テナント自身のメモリと対応するMetaテナントのメモリは、それぞれ増分データを格納するMemStoreとKVCacheキャッシュに分割されます。
