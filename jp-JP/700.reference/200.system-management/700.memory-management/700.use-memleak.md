# 惯常化されたMemleakに基づくメモリリーク診断メカニズム

OceanBaseデータベースは、Memleakツールを使用してメモリリークを診断します。その仕組みは、追跡モジュールのメモリ割り当てスタックを記録することです。特定のスタックの累積回数が一定期間にわたって継続的に増加する場合、そのスタックに対応するメモリ割り当てコンテキストでメモリリークが発生している可能性があります。しかし、Memleakを有効にするタイミングは通常、メモリリークが発生した後です。Memleakを有効にした後にメモリリークが止まった場合、リークが発生したモジュールを追跡することはできず、再現を待つしかありません。そのため、常態化されたMemleakを使用し、メモリ割り当て情報のサンプルをリアルタイムで保存し、サンプリング結果に基づいてメモリリークが発生する可能性のあるモジュールを分析する必要があります。

常態化されたMemleakは、パラメータ `_min_malloc_sample_interval` と `_max_malloc_sample_interval` を使用してメモリ割り当て情報のサンプリングレートを制御します。

|           パラメータ             |     説明                        | 値の範囲     | デフォルト値  |
|-----------------------------|--------------------------------|-------------|--------|
| _min_malloc_sample_interval | 隣接する2回のサンプリング間のob_mallocの最小回数 | [1,10000]  | 16     |
| _max_malloc_sample_interval | 隣接する2回のサンプリング間のob_mallocの最大回数 | [1,10000]  | 256   |

パラメータを設定してメモリ割り当て情報のサンプリングレートを制御する方法は、以下の3つのモードがあります：

* ゼロサンプリングモード：このモードでは、システムはメモリ割り当て情報の記録を停止します。

    ```shell
    obclient> ALTER SYSTEM SET _min_malloc_sample_interval=10000;
    Query OK, 0 rows affected

    obclient> ALTER SYSTEM SET _max_malloc_sample_interval=10000;
    Query OK, 0 rows affected
    ```

* フルサンプリングモード：このモードでは、システムはすべてのメモリ割り当て情報を記録します。このモードでは、OceanBaseデータベースのパフォーマンスが大幅に低下します。

    ```shell
    obclient> ALTER SYSTEM SET _min_malloc_sample_interval=1;
    Query OK, 0 rows affected

    obclient> ALTER SYSTEM SET _max_malloc_sample_interval=1;
    Query OK, 0 rows affected
    ```

* 常態化モード：このモードでは、システムは設定されたサンプリング間隔に従って、メモリ割り当て情報のサンプルを記録します。

    ```shell
    obclient> ALTER SYSTEM SET _min_malloc_sample_interval=16;
    Query OK, 0 rows affected

    obclient> ALTER SYSTEM SET _max_malloc_sample_interval=256;
    Query OK, 0 rows affected
    ```

<main id="notice" type='notice'>
     <h4>注意</h4>
     <ul>
     <li>OceanBaseデータベースでは、名前が「_」で始まるパラメータは隠れたパラメータと呼ばれ、開発者が障害の調査や緊急な運用保守時にのみ使用します。</li>
     <li>パラメータの値を設定する際には、以下の要件を満たす必要があります：<code>_min_malloc_sample_interval <= _max_malloc_sample_interval</code>。</li>
     <li>パラメータ <code>_min_malloc_sample_interval</code> と <code>_max_malloc_sample_interval</code> は、ユーザーが勝手に変更することは推奨されません。不適切な変更はクラスタのパフォーマンスを低下させる可能性があります。</li>
     </ul>
</main>
