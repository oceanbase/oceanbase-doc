# メモリ制御

OceanBaseデータベースの現行バージョンでは、単一のSQLクエリ処理中のメモリ使用状況を追跡することができます。メモリ使用量が一定のしきい値を超えると、システムはエラーを報告し、SQLの実行を中断します。これにより、OOMを防ぐか、OOMの原因を特定することができます。

## 単一のSQL実行中のメモリ使用しきい値の調整

OceanBaseデータベースは、テナントレベルの構成パラメータ`query_memory_limit_percentage`を使用して、単一のSQLで使用可能なテナントメモリの割合を制御します。デフォルト値は`50`であり、単一のSQLで使用されるメモリがテナントメモリの50％を超えた場合、システムはエラーを報告し、そのSQLの実行を中断します。ユーザーは実際のシナリオに応じて、この構成パラメータの値を調整できます。

調整方法は以下のとおりです：

1. テナント管理者がクラスタのユーザーテナントにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードのデフォルト管理者ユーザーは<code>root</code>ユーザー、Oracleモードのデフォルト管理者ユーザーは<code>SYS</code>ユーザーです。</p>
   </main>

   接続例は次のとおりです：

    ```shell
    obclient -h172.30.xxx.xxx -P2883 -uroot@mysqltenant#obdemo -pxxxx -A
    ```

2. 現在の構成パラメータ`query_memory_limit_percentage`の値を確認します。

   ```shell
   obclient> SHOW PARAMETERS LIKE '%query_memory_limit_percentage%';
   ```

3. 構成パラメータ`query_memory_limit_percentage`の値を調整します。

   例：

   ```shell
   obclient> ALTER SYSTEM SET query_memory_limit_percentage = 50;
   ```
