# ダンプの自動トリガー

このセクションでは、自動ダンプのトリガーメカニズムについて説明します。

テナントのActive MemTableメモリ使用量が `freeze_trigger_percentage * memstore_limit`（ここで、`memstore_limit = テナントメモリ * memstore_limit_percentage`）に達すると、システムは自動的にフリーズ（ダンプの前段階の処理）をトリガーし、その後ダンプをスケジュールします。フリーズ（minor freeze）の回数が一定のしきい値に達すると、自動マージがトリガーされます。

パラメータ `memstore_limit_percentage` および `freeze_trigger_percentage` の詳細と設定方法については、[ダンプ設定の変更](../100.dump-management/500.modify-dump-configuration.md)を参照してください。
