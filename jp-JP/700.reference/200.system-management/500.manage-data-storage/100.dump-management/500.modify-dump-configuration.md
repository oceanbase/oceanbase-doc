# ダンプ設定の変更

この記事では、ダンプパラメータとその設定方法について説明します。

## ダンプパラメータ

|             パラメータ             |                          意味                           | デフォルト値 |     設定範囲     |
|-----------------------------|-------------------------------------------------------|-----|--------------|
| minor_compact_trigger       | テナントレベルのパラメータで、ダンプ（Minor Compaction）をトリガーするSSTable数のしきい値を設定します。                                  | 2   | \[0, 16\]    |
| freeze_trigger_percentage   | テナントレベルのパラメータで、テナントMemStoreが占用するメモリの割合のしきい値です。この値に達するとFreezeがトリガーされます。                | 20  | \[1, 99\]    |
| memstore_limit_percentage   | クラスタレベルのパラメータで、テナントMemStoreがテナント全体のメモリに占める割合。<main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、V4.3.0以降のバージョンから、テナントレベルの隠れパラメータ<code>_memstore_limit_percentage</code>を使用して、テナントMemStoreがテナント全体のメモリに占める割合を設定できるようになりました。有効範囲が異なる以外は、機能およびデフォルト値はクラスタレベルのパラメータ<code>memstore_limit_percentage</code>と同じです。これら2つのパラメータを設定する際には、以下の点に注意する必要があります：</p><ul><li><code>_memstore_limit_percentage</code>または<code>memstore_limit_percentage</code>のいずれか一方の値（デフォルト値以外）のみを設定した場合、設定した値（デフォルト値以外）を優先します。</li> <li>テナントレベルの隠れパラメータ<code>_memstore_limit_percentage</code>（デフォルト値以外）とクラスタレベルのパラメータ<code>memstore_limit_percentage</code>（デフォルト値以外）の両方の値を設定した場合、<code>_memstore_limit_percentage</code>で設定した値を優先します。</li> <li>両方とも設定されていない場合、または両方ともデフォルト値に設定されている場合、システムは以下の適応型ポリシーを採用します：<ul><li>メモリが8GB（実際のメモリ）以下のテナントでは、テナントMemstoreの設定割合は40%となります。</li><li>メモリが8GBを超えるテナントでは、テナントMemstoreの設定割合は50%となります。</li></ul></li></ul></main>   | 0  | \[1, 99\]    |

## SQLステートメントによるダンプ設定の変更

1. テナント管理者がデータベースにログインします。

2. それぞれ以下のステートメントを実行して、ダンプ設定を変更します。

   例：

   ```sql
   obclient> ALTER SYSTEM SET minor_compact_trigger=2;

   obclient> ALTER SYSTEM SET freeze_trigger_percentage=20;

   obclient> ALTER SYSTEM SET memstore_limit_percentage=50;
   ```

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>クラスタレベルの構成パラメータは、<code>sys</code>テナントで設定する必要があります。</p>
   </main>

3. 変更が成功した後、`SHOW PARAMETERS` ステートメントを使用して変更が成功したかどうかを確認できます。

   例：

   ```sql
    obclient> SHOW PARAMETERS LIKE 'minor_compact_trigger';

   obclient> SHOW PARAMETERS LIKE 'freeze_trigger_percentage';

   obclient> SHOW PARAMETERS LIKE 'memstore_limit_percentage';
   ```
