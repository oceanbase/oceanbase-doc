# ダンプ設定の変更

このセクションでは、ダンプパラメータとその設定方法について説明します。

## ダンプパラメータ

|             パラメータ             |                          意味                           | デフォルト値 |     設定範囲     |
|-----------------------------|-------------------------------------------------------|-----|--------------|
| minor_compact_trigger       | テナントレベルの構成パラメータで、ダンプ（Minor Compaction）をトリガーするSSTable数のしきい値を設定します。             | 2   | \[0, 16\]    |
| freeze_trigger_percentage   | テナントレベルの構成パラメータで、テナントMemStoreが占用するメモリの割合のしきい値です。この値に達するとFreezeがトリガーされます。                | 20  | (0, 100)    |
| memstore_limit_percentage   | クラスタレベルの構成パラメータで、テナントMemStoreがテナント総メモリに占める割合。<main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、V4.3.0バージョンから、テナントレベルの隠れた構成パラメータ<code>_memstore_limit_percentage</code>を使用して、テナントMemStoreがテナント総メモリに占める割合を設定することもできます。有効範囲が異なる点を除けば、その機能とデフォルト値はクラスタレベルの構成パラメータ<code>memstore_limit_percentage</code>と同じです。これら2つの構成パラメータを設定する際には、以下の点に注意してください：</p><ul><li><code>_memstore_limit_percentage</code>または<code>memstore_limit_percentage</code>のどちらか一方の値（デフォルト値以外）のみを設定した場合は、設定した値（デフォルト値以外）が優先されます。</li> <li>テナントレベルの隠れた構成パラメータ<code>_memstore_limit_percentage</code>（デフォルト値以外）とクラスタレベルの構成パラメータ<code>memstore_limit_percentage</code>（デフォルト値以外）の両方の値を設定した場合は、<code>_memstore_limit_percentage</code>で設定した値が優先されます。</li> <li>両方とも設定されていない場合、または両方ともデフォルト値に設定されている場合、システムは以下の適応型ポリシーを採用します：<ul><li>メモリが8GB（実メモリ）以下のテナントの場合、テナントMemStoreの設定比率は40%となります。</li><li>メモリが8GBを超えるテナントの場合、テナントMemStoreの設定比率は50%となります。</li></ul></li></ul></main>   | 0  | [0, 100)   |

## SQLステートメントによるダンプ設定の変更

1. テナント管理者がデータベースにログインします。

2. 以下のステートメントを実行して、ダンプ設定を変更します。

   例：

   ```sql
   obclient> ALTER SYSTEM SET minor_compact_trigger=2;

   obclient> ALTER SYSTEM SET freeze_trigger_percentage=20;

   obclient> ALTER SYSTEM SET memstore_limit_percentage=50;
   ```

3. 変更が成功した後、`SHOW PARAMETERS` ステートメントを使用して変更が正しく行われたかどうか確認できます。

   例：

   ```sql
    obclient> SHOW PARAMETERS LIKE 'minor_compact_trigger';

   obclient> SHOW PARAMETERS LIKE 'freeze_trigger_percentage';

   obclient> SHOW PARAMETERS LIKE 'memstore_limit_percentage';
   ```
