# 合併プロセスの確認

合併を開始した後、ビューを通じて合併プロセスを確認できます。

合併プロセスは内部テーブルを通じて確認でき、通常、合併にかかる時間は2回の合併間のデータ変更量によって決まります。2回の合併間のデータ変更が大きい場合、合併にかかる時間も長くなります。また、合併のスレッド数や合併時のクラスタ圧力なども合併時間に影響を与えます。

## システムテナントからすべてのテナントのメジャーコンパクションプロセスを確認する

システムテナントは、`oceanbase.CDB_OB_ZONE_MAJOR_COMPACTION` および `oceanbase.CDB_OB_MAJOR_COMPACTION` ビューを照会することで、すべてのテナントのメジャーコンパクション情報を確認できます。

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 以下のステートメントを実行して、コンパクションの進捗状況を確認します。

   * すべてのテナントの各ゾーンのメジャーコンパクションプロセスを確認します。

      ```shell
      obclient> SELECT * FROM oceanbase.CDB_OB_ZONE_MAJOR_COMPACTION;
      ```

      クエリ結果は次のとおりです：


      実行結果の `status` 列を確認します。一部のフィールドの説明は以下の表のとおりです。

      |フィールド|説明|

## ユーザーテナントが自身のテナントのメジャーコンパクションプロセスを確認する

ユーザーテナントは、`DBA_OB_ZONE_MAJOR_COMPACTION` および `DBA_OB_MAJOR_COMPACTION` を照会することで、自身のテナントのメジャーコンパクションプロセスを確認できます。

1. ユーザーテナントのテナント管理者がデータベースにログインします。

2. 以下のステートメントを実行して、コンパクションの進捗状況を確認します。

   タブ MySQLモード

      実行結果の`status`列を確認すると、一部のパラメータの説明は以下の表のとおりです。
