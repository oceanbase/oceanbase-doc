# メジャーコンパクション情報の確認

メジャーコンパクションを開始した後、ビューを通じてその情報を確認できます。

メジャーコンパクションの進捗状況はビューで確認できますが、通常、メジャーコンパクションにかかる時間は、前回のメジャーコンパクションと今回のメジャーコンパクションの間で発生したデータ変更量によって決まります。データの変更量が多い場合、メジャーコンパクションにかかる時間も長くなります。また、メジャーコンパクションを実行するスレッド数や、コンパクション時のクラスタ負荷なども、メジャーコンパクションの所要時間に影響します。

## システムテナントによるすべてのテナントのメジャーコンパクション情報の確認

1. `root`ユーザーでクラスタの`sys`テナントにログインします。
