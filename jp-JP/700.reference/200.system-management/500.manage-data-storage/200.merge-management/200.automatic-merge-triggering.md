# 自動マージのトリガー

マージは自動トリガーによって実行できます。

## 前提条件

マージをトリガーする前に、グローバルマージスイッチが有効になっていることを確認する必要があります。グローバルマージスイッチはクラスタレベル構成パラメータ `enable_major_freeze` によって制御され、デフォルト値は `True` で、マージスイッチが有効であることを示しています。

現在のクラスタでグローバルマージスイッチが有効になっていない場合は、以下の手順を参照してグローバルマージスイッチを有効にしてください。

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. グローバルマージスイッチが有効になっているか確認します。

   ```sql
   obclient> SHOW PARAMETERS LIKE 'enable_major_freeze';
   ```

3. 有効になっていない場合は、以下のステートメントを実行してマージスイッチを有効にします。

   ```sql
   obclient> ALTER SYSTEM SET enable_major_freeze='True';
   ```

   構成パラメータ `enable_major_freeze` の詳細については、[enable_major_freeze](../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/7000.enable_major_freeze.md)を参照してください。

## 自動マージのトリガー条件

フリーズ（minor freeze）の回数が一定のしきい値に達すると、自動的にマージがトリガーされます。
