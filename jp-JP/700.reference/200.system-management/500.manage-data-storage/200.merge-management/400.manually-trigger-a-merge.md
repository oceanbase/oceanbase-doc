# マニュアルでのメジャーコンパクションのトリガー

メジャーコンパクションは、手動でトリガーすることも可能です。

## 前提条件

メジャーコンパクションをトリガーする前に、グローバルコンパクションスイッチが有効になっていることを確認する必要があります。グローバルコンパクションスイッチは、クラスタレベルの構成パラメータ`enable_major_freeze`で制御され、デフォルト値は`True`であり、これはコンパクションスイッチが有効であることを示します。

現在のクラスタでグローバルコンパクションスイッチが有効になっていない場合は、以下の手順に従って有効にしてください。

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

2. グローバルコンパクションスイッチが有効になっているかどうかを確認します。

   ```sql
   obclient> SHOW PARAMETERS LIKE 'enable_major_freeze';
   ```

3. 有効になっていない場合は、以下のステートメントを実行してコンパクションスイッチを有効にします。

   ```sql
   obclient> ALTER SYSTEM SET enable_major_freeze='True';
   ```

   パラメータ`enable_major_freeze`の詳細については、[enable_major_freeze](../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/7300.enable_major_freeze.md)を参照してください。

## システムテナントによる手動メジャーコンパクション

システムテナントは、自身のテナント、すべてのテナント、または指定されたテナントに対してメジャーコンパクション操作を開始できます。

具体的な操作は以下のとおりです：

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

2. 以下のコマンドを実行して、メジャーコンパクションを開始します。

   SQLステートメントは次のとおりです：

   ```sql
   obclient> ALTER SYSTEM MAJOR FREEZE TENANT [=] all_user | all | all_meta | tenant_name [, tenant_name ...];
   ```

   ここで、`[=]`は等号(=)を意味し、省略可能です。

   例：

   * システムテナントが自身のテナントに対してメジャーコンパクションを開始する

      ```sql
      obclient> ALTER SYSTEM MAJOR FREEZE;
      ```

   * システムテナントがすべてのユーザーテナントに対してメジャーコンパクションを開始する

      ```sql
      obclient> ALTER SYSTEM MAJOR FREEZE TENANT = all_user;
      ```

      または

      ```sql
      obclient> ALTER SYSTEM MAJOR FREEZE TENANT = all;
      ```

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>OceanBaseデータベースはV4.2.1バージョンから、<code>TENANT = all_user</code>と<code>TENANT = all</code>は同じ意味を持ちます。すべてのユーザーテナントに適用範囲を設定する必要がある場合は、<code>TENANT = all_user</code>の使用を推奨します。<code>TENANT = all</code>は今後廃止され、使用されなくなります。</p>

   * システムテナントがすべてのMetaテナントに対してメジャーコンパクションを開始する

      ```sql
      obclient> ALTER SYSTEM MAJOR FREEZE TENANT = all_meta;
      ```

   * システムテナントが指定されたテナントに対してメジャーコンパクションを開始する

      ```sql
      obclient> ALTER SYSTEM MAJOR FREEZE TENANT = tenant1,tenant2;
      ```

## ユーザーテナントによる手動メジャーコンパクション

ユーザーテナントは、自身のテナントに対してのみメジャーコンパクション操作を開始できます。

1. ユーザーテナントのテナント管理者がデータベースにログインします。

2. 自身のテナントに対してメジャーコンパクションを開始します。

   ステートメントは次のとおりです：

   ```sql
   obclient> ALTER SYSTEM MAJOR FREEZE;
   ```
