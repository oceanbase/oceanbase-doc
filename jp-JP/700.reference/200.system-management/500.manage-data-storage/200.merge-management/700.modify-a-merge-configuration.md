# メジャーコンパクションの設定を変更する

このセクションでは、メジャーコンパクションに関連するパラメータとその変更方法について説明します。

## メジャーコンパクションパラメータ

メジャーコンパクションに関連するパラメータの説明は、次の表のとおりです。

|              パラメータ              |             説明             |  デフォルト値  |          値の範囲          |
|-------------------------------|----------------------------------------------------------------------------------------------------------|-------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| enable_major_freeze           | クラスタレベル構成パラメータで、メジャーコンパクションを有効にするかどうかを示します。                   | True  |  <ul><li>True </li><li>False  </li></ul>      |
| major_freeze_duty_time        | テナントレベル構成パラメータで、毎日の定期的なメジャーコンパクションの実行時間です。                 | 02:00 | \[00:00,24:00\]        |
| major_compact_trigger         | テナントレベル構成パラメータで、フリーズが何回発生した後にメジャーコンパクションをトリガーするかを示します。               | 0     | \[0,65535\]            |
| default_progressive_merge_num | テナントレベル構成パラメータで、テーブル作成時のデフォルトのメジャーコンパクション動作を示します。                | 0     | \[0, +∞)  </br>ここで： <ul><li>0 ：デフォルト値100を使用します </li><li>1：プログレッシブコンパクションを実行せず、必ずフルコンパクションを強制実行します。</li>   <li>1より大きい場合：スキーマ変更が発生した場合、指定されたラウンド数に従ってプログレッシブコンパクションを実行します。 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>テーブル作成後に、<code>ALTER TABLE table_name SET PROGRESSIVE_MERGE_NUM=0;</code> ステートメントを使用して、テーブルのメジャーコンパクション動作を変更することもできます。</p></main>  |
| merger_check_interval         | テナントレベル構成パラメータで、各ゾーンのメジャーコンパクション進捗チェック間隔を示します。         | 10m   | \[10s, 60m\]           |

## SQLステートメントによるメジャーコンパクション設定の変更

1. テナント管理者がデータベースにログインします。

2. 以下のSQLステートメントを使用してメジャーコンパクションの設定を変更します。

   例：

   ```sql
   obclient> ALTER SYSTEM SET major_freeze_duty_time='03:00';
   ```

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>クラスタレベルの構成パラメータは、<code>sys</code>テナントで設定する必要があります。</p>
   </main>

3. 変更が成功した後、`SHOW PARAMETERS`ステートメントを実行して変更が正しく行われたかどうか確認できます。

   例：

   ```sql
   obclient>SHOW PARAMETERS LIKE 'major_freeze_duty_time';
   ```
