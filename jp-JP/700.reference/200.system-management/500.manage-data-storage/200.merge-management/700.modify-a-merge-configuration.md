# マージ設定の変更

この記事では、主にマージ関連のパラメータとその変更方法について説明します。

## マージパラメータ

マージ関連のパラメータの説明は、以下の表のとおりです。

|              パラメータ              |             説明             |  デフォルト値  |          値の範囲          |
|-------------------------------|----------------------------------------------------------------------------------------------------------|-------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| enable_major_freeze           | クラスタレベルのパラメータで、メジャーコンパクションを有効にするかどうかを示します。                   | True  |  <ul><li>True </li><li>False  </li></ul>      |
| major_freeze_duty_time        | テナントレベルのパラメータで、毎日の定時メジャーコンパクションの時間です。                 | 02:00 | \[00:00,24:00\]        |
| major_compact_trigger         | テナントレベルのパラメータで、何回凍結したらメジャーコンパクションをトリガーするかを示します。               | 0     | \[0,65535\]            |
| default_progressive_merge_num | テナントレベルのパラメータで、テーブル作成時のデフォルトのメジャーコンパクション動作を示します。                | 0     | \[0, +∞)  </br>その中で： <ul><li>0 ：デフォルト値100を使用することを示します </li><li>1：プログレッシブコンパクションを実行せず、フルコンパクションを強制的に実行することを示します</li>   <li>1より大きい場合：スキーマ変更が発生した場合、指定されたラウンドでプログレッシブコンパクションを実行することを示します </li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>テーブル作成後に、<code>ALTER TABLE table_name SET PROGRESSIVE_MERGE_NUM=0;</code> ステートメントを使用して、テーブルのメジャーコンパクション動作を変更することもできます。</p></main> |
| merger_check_interval         | テナントレベルのパラメータで、各ゾーンのメジャーコンパクション進捗状況のチェック間隔を示します。         | 10m   | \[10s, 60m\]           |

## SQLステートメントによるマージ設定の変更

1. テナント管理者がデータベースにログインします。

2. 以下のSQLステートメントを使用してマージ設定を変更します。

   例：

   ```sql
   obclient> ALTER SYSTEM SET major_freeze_duty_time='03:00';
   ```

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>クラスタレベルの構成パラメータは、<code>sys</code>テナントで設定する必要があります。</p>
  </main>

3. 変更が成功した後、`SHOW PARAMETERS` ステートメントを使用して変更が成功したかどうかを確認できます。

   例：

   ```sql
   obclient>SHOW PARAMETERS LIKE 'major_freeze_duty_time';
   ```
