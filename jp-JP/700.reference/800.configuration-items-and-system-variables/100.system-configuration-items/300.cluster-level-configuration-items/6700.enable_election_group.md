# enable_election_group

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではシステムアーキテクチャが最適化されたため、選挙グループの概念はなくなりました。この構成パラメータはV4.0.0以降のバージョンから廃止されています。</p>
</main>

## 機能の概要

`enable_election_group`は、選挙グループポリシーを有効にするかどうかを設定します。

## プロパティの説明

|        プロパティ        |                        説明                    |
|------------------|--------------------------------------------------|
| パラメータタイプ             | Bool                                         |
| デフォルト値              | True                                           |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>    |
| OBServerノードの再起動が必要か | 不要です                                        |
