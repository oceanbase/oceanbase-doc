# flush_log_at_trx_commit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは導入後の利用率が低いため、総合的な評価を経て、V4.0.0バージョンから削除されました。</p>
</main>

## 機能の概要

`flush_log_at_trx_commit`は、トランザクションコミット時のトランザクションログ書き込みポリシーを設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値              | 1        |
| 値の範囲             | \[0, 2\] |
| OBServerノードの再起動が必要か | 不要です    |

## 使用方法

`flush_log_at_trx_commit`構成パラメータの値の意味は以下のとおりです：

* 値が0の場合、ログのバッファへの書き込みを待機しません。

* 値が1の場合、ログのディスクへの書き込みを待機します。

* 値が2の場合、ログのディスクへの書き込みを待機せず、バッファへの書き込みを待機します。
