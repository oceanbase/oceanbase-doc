# election_cpu_quota

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではシステムアーキテクチャが最適化されたため、選挙タイマーのスレッド数はログストリーム数に応じて変動し、1つのスレッドで十分となりました。そのため、CPUクォータの設定は不要となり、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`election_cpu_quota`は、レプリカ選挙関連のバックグラウンド処理に割り当てるCPUクォータを設定します。

## プロパティの説明

|      **プロパティ**     |  **説明**   |
|-------------------|-------------|
| パラメータタイプ            | Double    |
| デフォルト値              | 3         |
| 値の範囲            | [0, 10] |
| OBServerノードの再起動が必要か | 不要です       |
