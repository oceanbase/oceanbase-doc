# server_cpu_quota_min

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`server_cpu_quota_min`は、システムが使用できる最小CPUクォータを設定します。システムは自動的に予約します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## 使用方法

値が0の場合、Serverの`cpu_count`のサイズに応じて自動調整が行われます：

1. `cpu_count` < 8cの場合、`server_cpu_quota_min`は自動的に1cに調整されます。
2. 8c ≤ `cpu_count` < 16cの場合、`server_cpu_quota_min`は自動的に2cに調整されます。
3. 16c ≤ `cpu_count` < 32cの場合、`server_cpu_quota_min`は自動的に3cに調整されます。
4. 32c ≤ `cpu_count`の場合、`server_cpu_quota_min`は自動的に4cに調整されます。

## 設定例

システムが自動調整により最小CPUクォータを設定します。

```shell
obclient> ALTER SYSTEM SET server_cpu_quota_min=0;
```
