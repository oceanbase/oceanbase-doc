# enable_manual_merge

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではマニュアルでのメジャーコンパクションの実行順序を制御することができなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、<code>MAJOR FREEZE</code>コマンドでメジャーコンパクションをトリガーすると、システムが統一されたメジャーコンパクション戦略に従ってプロセスを実行し、ユーザーが各ゾーンのメジャーコンパクション順序を手動で制御する必要はありません。メジャーコンパクション中にエラーが発生した場合は、マニュアルでのメジャーコンパクション制御に関するドキュメントを参照して対処してください。詳細な操作については、<a href="../../../200.system-management/500.manage-data-storage/200.merge-management/500.manually-control-a-merge.md">マニュアルでのメジャーコンパクション制御</a>を参照してください。</li></ul>
</main>

## 機能の概要

`enable_manual_merge`は、手動でのメジャーコンパクションを有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |                  **説明**                                 |
|------------------|------------------------------------------------------------|
| パラメータタイプ             | Bool                                                |
| デフォルト値              | False                                                |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>   |
| OBServerノードの再起動が必要か | 不要です                                            |

## 使用方法

`enable_manual_merge`がTrueの場合、`alter system major freeze`は実際のメジャーコンパクションをトリガーせず、各ゾーンごとに手動で個別にメジャーコンパクションを実行する必要があります。
例えば、以下のコマンドでzone1とzone2を個別にメジャーコンパクションします。また、メジャーコンパクションの順序は必要に応じて調整できます。

```sql
alter system start merge zone='zone1';
alter system start merge zone='zone2';
```
