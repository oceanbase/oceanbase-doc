# minor_deferred_gc_time

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V2.2.3xバージョン以降の使用は推奨されなくなり、V4.0.0バージョン以降のリリースで削除されました。</p>
</main>

## 機能の概要

`minor_deferred_gc_time`は、マージ後のSSTableの遅延回収時間間隔を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**    |
|------------------|-------------|
| パラメータタイプ             | Time       |
| デフォルト値              | 0s          |
| 値の範囲             | \[0s, 24h] |
| OBServerノードの再起動が必要か | 不要です         |
