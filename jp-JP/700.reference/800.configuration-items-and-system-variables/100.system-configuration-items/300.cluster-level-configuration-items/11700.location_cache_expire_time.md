# location_cache_expire_time

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`location_cache_expire_time`は、パーティション位置キャッシュ内のパーティション位置情報の有効期限を設定します。変更は推奨されません。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Time      |
| デフォルト値              | 600s      |
| 値の範囲             | \[1s, +∞) |
| OBServerノードの再起動が必要か | 不要です       |
