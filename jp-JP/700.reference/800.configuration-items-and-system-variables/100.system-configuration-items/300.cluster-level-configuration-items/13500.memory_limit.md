# memory_limit

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`memory_limit`は、OBServerが利用可能なメモリサイズの合計を設定します。

OBServer上で`memory_limit`の設定が有効になるには、以下の2つの条件を満たす必要があります：

* 500テナントの予約メモリが実際の使用メモリ以上であること。
* `memory_limit`の値が`system_memory`とユニットに割り当てられたメモリの合計よりも高いこと。

上記の制限条件を満たさない場合、`memory_limit`の設定はエラーにならず、有効にもなりません。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Capacity      |
| デフォルト値              | 0、単位はMBです。        |
| 値の範囲             | [1G, +∞) <main id="notice" type='explain'><h4>説明</h4><ul><li>この構成パラメータは、V4.1.0バージョン以降、値の範囲が[4G, +∞)から[1G, +∞)に調整されました。  </li><li>アービトレーションサービスモードでは最小値は1G、非アービトレーションサービスモードでは最小値は4Gです。</li></ul></main>|
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。         |

## 使用方法

* `memory_limit`のデフォルト値は`0`です。この値が`0`以外の場合、システムは`memory_limit_percentage`の設定を無視し、`memory_limit`で設定された値を優先的に使用します。例えば、物理メモリが100GBのマシンにおいて、`memory_limit_percentage`を`80`に設定するとメモリの80%が使用されますが、`memory_limit`パラメータを`'90G'`に設定した場合、実際にOceanBaseデータベースが使用できるメモリは`memory_limit`の設定である90GBとなります。`memory_limit_percentage`の詳細については、[memory_limit_percentage](13600.memory_limit_percentage.md)を参照してください。

* `memory_limit` のデフォルト単位はMBです。例えば、`memory_limit='40G'` は、OceanBaseデータベースプロセスの使用メモリ上限を40GBに設定することを意味します。デフォルト単位がMBであるため、`memory_limit=40960` と `memory_limit='40G'` は同じ値に設定されます。

* `memory_limit` の値に現在上限はありません。

  * 設定したメモリの最大上限が実際の物理メモリの合計を超えると、システム内の他のメモリ値も実際より大きく表示される可能性があります。

  * 実行中のOceanBaseデータベースのメモリサイズを制限したい場合は、`memory_limit` の値を直接変更して適切な範囲に設定できます。設定後、バックグラウンドのReloadスレッドにより動的に反映されるため、再起動は不要です。ただし、設定時には `memory_limit` の値がシステム全体のメモリ容量を超えないようにしてください。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p><code>memory_limit</code> の値は、OBServerノードが実際に使用しているメモリ量より大きく設定する必要があります。</p>
    </main>

## 設定例

* 例えば、OBServerが使用可能なメモリの合計を32GBに設定するコマンドは次のとおりです：

  ```shell
  obclient> ALTER SYSTEM SET memory_limit='32G';
  ```

* 現在使用中のメモリ量（単位：GB）を確認する方法は次のとおりです：

  ```shell
  obclient> SELECT value/1024/1024/1024 used_gb FROM v$sysstat WHERE name LIKE '%observer memory%' AND con_id = 1 AND stat_id=140008 AND name='observer memory used size';
  ```
