# enable_auto_refresh_location_cache

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_auto_refresh_location_cache`は、位置キャッシュ情報の自動リフレッシュロジックを有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |          **説明**                               |
|------------------|---------------------------------------------------|
| パラメータタイプ             | Bool                             |
| デフォルト値              | True                                 |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>    |
| OBServerノードの再起動が必要か | 不要です                           |
