# user_iort_up_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>IOスケジューリングアルゴリズムの調整に伴い、対応する機能が廃止されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`user_iort_up_percentage`は、ユーザーディスクI/Oの遅延しきい値を設定します。ユーザーディスクI/Oの遅延がこのしきい値を超えると、システムのバックグラウンドI/Oタスクが制限されます。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値              | 100      |
| 値の範囲             | \[0, +∞) |
| OBServerノードの再起動が必要か | 不要です    |
