# clog_disk_utilization_threshold

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではログディスク容量の管理がテナントレベルに分割されたため、この構成パラメータは使用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、テナントレベルの構成パラメータ <code>log_disk_utilization_threshold</code> を使用して、ログディスク容量の再利用のしきい値を制御します。構成パラメータ <code>log_disk_utilization_threshold</code> の詳細については、<a href="../400.tenant-level-configuration-items/4900.log_disk_utilization_threshold.md">log_disk_utilization_threshold</a>を参照してください。</li></ul>
</main>

## 機能の概要

`clog_disk_utilization_threshold`は、clogまたはilogのディスク容量の再利用のしきい値を制御します。

## プロパティの説明

|        プロパティ        |     説明     |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値               | 80         |
| 値の範囲             | \[10, 100) |
| OBServerノードの再起動が必要か | 不要です      |

## 設定例

clogまたはilogのディスク容量の再利用のしきい値を80に設定します。

```shell
obclient> ALTER SYSTEM SET clog_disk_utilization_threshold=80;
```
