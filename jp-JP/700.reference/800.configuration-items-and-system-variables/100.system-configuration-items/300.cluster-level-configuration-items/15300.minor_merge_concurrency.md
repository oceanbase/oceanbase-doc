# minor_merge_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースには限りがあるため、V4.x系では具体的なタスクタイプごとにスレッドリソースを設定することができなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、テナントレベルの構成パラメータ <code>compaction_mid_thread_score</code> を使用して、優先度の高いCompactionのワーカースレッド数を設定できます。構成パラメータ <code>compaction_mid_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/1300.compaction_mid_thread_score.md">compaction_mid_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`minor_merge_concurrency`は、ダンプ時の並行スレッド数を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Int        |
| デフォルト値              | 0、これは並行スレッド数がmin[10, cpu_cnt]を表すことを意味します        |
| 値の範囲             | [0, 64] |
| OBServerノードの再起動が必要か | 不要です       |
