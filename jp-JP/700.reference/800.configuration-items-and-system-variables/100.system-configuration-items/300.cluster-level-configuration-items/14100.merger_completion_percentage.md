# merger_completion_percentage

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは導入後の利用率が低いため、総合的な評価を経て、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`merger_completion_percentage`は、メジャーコンパクション完了レプリカ数の割合しきい値を設定します。このしきい値に達した場合、当該ラウンドのメジャーコンパクションスケジューリングが完了したとみなします。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 100        |
| 値の範囲             | \[5, 100\] |
| OBServerノードの再起動が必要か | 不要です        |
