# observer_id

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

`observer_id`は、クラスタ内でRSがOBServerノードに割り当てる一意の識別子です。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できません。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int |
| デフォルト値               | 0、無効な`observer_id`を表します |
| 値の範囲             | [1, 18446744073709551615] |
| 変更は可能か           | 不可、読み取り専用です。 |
| OBServerノードの再起動が必要か | 不要です、読み取り専用です。 |

## クエリ例

クラスタ内でRSがOBServerノードに割り当てた一意の識別子を確認します。

```shell
obclient> SHOW PARAMETERS LIKE 'observer_id';
```
