# sys_bkgd_io_low_percentage

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でテナントのI/O分離が実装されたため、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`sys_bkgd_io_low_percentage`は、システムバックグラウンドI/Oが最低限占用する割合を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 0          |
| 値の範囲             | \[0, 100\] |
| OBServerノードの再起動が必要か | 不要です       |

## 使用方法

`sys_bkgd_io_low_percentage`の値が0の場合、システムは環境に応じて自動的に割合を設定します。
