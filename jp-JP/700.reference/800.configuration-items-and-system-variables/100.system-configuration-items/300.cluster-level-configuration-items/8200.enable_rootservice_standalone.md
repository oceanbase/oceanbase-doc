# enable_rootservice_standalone

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではストレージアーキテクチャが最適化され、システムテナント内にはクラスタのプライベートデータのみが格納され、ユーザーテナントのデータは格納されなくなりました。この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_rootservice_standalone`は、システムテナントとRootServiceがOBServerノードを専有するかどうかを設定します。

## プロパティの説明

|      **プロパティ**    |       **説明**      |
|------------------|---------------------|
| パラメータタイプ             | Bool                                                                                                  |
| デフォルト値               | False                                                                                                  |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>   |
| OBServerノードの再起動が必要か | 不要です                                                                                                   |
