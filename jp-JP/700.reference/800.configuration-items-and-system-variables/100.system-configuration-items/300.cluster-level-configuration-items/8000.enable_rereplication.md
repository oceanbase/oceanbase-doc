# enable_rereplication

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_rereplication`は、ログストリームレプリカの自動移行・複製を有効または無効にするためのトグルスイッチです。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**    |   **説明**   |
|------------------|--------------|
| パラメータタイプ             | Bool                |
| デフォルト値               | True                |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>    |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。    |

# 使用方法

構成パラメータ`enable_rereplication`を無効（値が`False`の場合）にした場合：

* 以下のシナリオで発生するログストリームの移行・複製を開始できなくなります：

  * Locality変更によるレプリカの追加または削除
  * Unit移行（送信元OBServerノードが`INACTIVE`状態の場合を除く）
  * `UNIT_NUM`変更によるログストリームの移行

* 以下のシナリオでは、ログストリームの移行レプリケーションを正常に開始できます：

  * ソース側OBServerノードが`INACTIVE`状態のUnitの移行

## 設定例

ログストリームレプリカの自動移行レプリケーションを有効にします。

```shell
obclient> ALTER SYSTEM SET enable_rereplication = True;
```
