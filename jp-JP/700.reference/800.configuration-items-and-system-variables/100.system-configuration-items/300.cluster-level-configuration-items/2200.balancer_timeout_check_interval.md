# balancer_timeout_check_interval

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でストレージアーキテクチャがアップグレードされたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`balancer_timeout_check_interval`は、ロードバランシングなどを行うバックグラウンドタスクのタイムアウトチェック間隔を設定します。

## プロパティの説明

|      **プロパティ**    |   **説明** |
|------------------|------------|
| パラメータタイプ            | Time      |
| デフォルト値              | 1m、1分を表す |
| 値の範囲            | [1s, +∞)  |
| OBServerノードの再起動が必要か | 不要です        |
