# auto_leader_switch_interval

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではシステムアーキテクチャが最適化されたため、選出によるリフレッシュ間隔の設定は不要となりました。この構成パラメータはV4.0.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`auto_leader_switch_interval`は、自動リーダー切り替えを行うバックグラウンドスレッドの実行間隔時間を設定します。

## プロパティの説明

|     **プロパティ**     |  **説明**  |
|----------------|----------|
| パラメータタイプ           |  Time     |
| デフォルト値             | 30s、30秒を意味します       |
| 値の範囲           | [1s，+∞) |
| OBServerの再起動が必要か | 不要です      |
