# enable_pg

<main id="notice" type='explain'>
  <h4>説明</h4>
    <p>V4.x系ではシステムアーキテクチャが最適化されたため、パーティションの概念がなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_pg`は、パーティショングループ機能を有効にするかどうかを設定します。

## プロパティの説明

|        プロパティ        |                                                   説明                                                   |
|------------------|--------------------------------------------------------------------------------------------------------|
| パラメータタイプ                     | Bool      |
| デフォルト値                       | False     |
| 値の範囲                     | <ul><li>True：有効</li><li>False：無効</li></ul>     |
| OBServerノードの再起動が必要か    | 不要です    |

## 設定例

パーティショングループ機能を有効にします。

```shell
obclient> ALTER SYSTEM SET enable_pg = True;
```
