# wait_leader_batch_count

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系から単一マシンのログストリームアーキテクチャへの移行に伴い、リーダー切り替えが単一のログストリームによって制御されるようになったため、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`wait_leader_batch_count`は、RootServiceが毎回リーダー切り替えコマンドを送信する際の最大パーティション数を設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**     |
|------------------|---------------|
| パラメータタイプ             | Int            |
| デフォルト値              | 1024          |
| 値の範囲             | \[128, 5000\] |
| OBServerノードの再起動が必要か | 不要です           |
