# local_ip

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

`local_ip`は、ObServerマシンのインストールIPアドレスを設定します。

## 権限要件

`sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

## プロパティの説明

| **プロパティ** | **説明** |
| --- | --- |
| パラメータタイプ | String |
| デフォルト値 | 空文字列 |
| 値の範囲 | 対象マシンの有効なIP |
| 変更は可能か | 不可です。この構成パラメータはクラスタデプロイ時にのみ設定可能で、クラスタが有効になった後は変更できません。|
| OBServerノードの再起動が必要か | 不要です。読み取り専用のみサポート |

## 使用方法

1. `alter system set`での変更はサポートされていません。
2. OBServer起動時に、コマンドラインでパラメータ`-I`または`--local_ip`を使用してIPアドレスを指定します。
3. `local_ip`と`devname`を同時に指定することは推奨されません。両方を指定した場合は`local_ip`が優先されます。
4. パラメータ`-o`を使用して`local_ip=xxx.xxx.xxx.xxx`の形式でIPアドレスを指定することも可能ですが、パラメータ`-I`または`--local_ip`を使用した指定を推奨します。IPアドレスが`-I/--local_ip`パラメータと`-o`パラメータの両方で指定されている場合、最終的には`-o`パラメータで指定されたIPが優先されます。

## 設定例

OBServerを指定IPで起動します。

```shell
./observer -I xxx.xxx.xxx.xxx -P 2882 -p 2881 -z zone1 -n demo1 -c 1 -d /home/user_name/path_to_store/store -l INFO -r 'xxx.xxx.xxx.xxx:2882:2881;xxx.xxx.xxx.xxx:2884:2883' -o "memory_limit=64G,system_memory=16G"
```
