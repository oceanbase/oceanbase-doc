# ignore_replica_checksum_error

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、レプリカのチェックサム検査を無視する可能性があり、重大な問題を引き起こすおそれがあるため、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ignore_replica_checksum_error`は、複数のレプリカ間でチェックサム検査にエラーが発生した場合に、そのエラーを無視するかどうかを設定します。

## プロパティの説明

|    **プロパティ**      |            **説明**   |
|------------------|-----------------------|
| パラメータタイプ             | Bool   |
| デフォルト値               | False      |
| 値の範囲             | <ul><li>True：分離ストレージ</li><li>False：非分離ストレージ</li></ul>    |
| OBServerノードの再起動が必要か    | 不要です   |
