# ob_startup_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_startup_mode`は、OBServerノードの起動モードを設定します。変更は初回起動時にのみ可能です。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  クラスタの初回起動時にのみ変更が可能です。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | String           |
| デフォルト値               | NORMAL |
| 値の範囲             |<ul><li> NORMAL：通常モードで起動することを示します  </li><li>ARBITRATION：アービトレーションモードで起動することを示します </li></ul>|
| 変更は可能か           | 不要です。`ALTER SYSTEM SET` ステートメントで変更することはサポートされていません。|
| OBServerノードの再起動が必要か | 不要です。読み取り専用のみサポートされます。            |
