# auto_broadcast_location_cache_rate_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`auto_broadcast_location_cache_rate_limit`は、各OBServerが1秒間にブロードキャストできる、位置情報が変更されたパーティションの最大数を設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**     |
|------------------|---------------|
| パラメータタイプ             | Int            |
| デフォルト値              | 1000          |
| 値の範囲             | \[1, 100000\] |
| OBServerノードの再起動が必要か | 不要です           |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>この構成パラメータは、位置キャッシュの自動リフレッシュ機能が有効な場合にのみ適用されます。</p>
</main>
