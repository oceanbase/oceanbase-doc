# backup_dest

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系では物理バックアップ・リカバリ機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、構成パラメータによるデータバックアップおよびログアーカイブの宛先設定はサポートされなくなりました。システムテナントおよびすべてのユーザーテナントは、<a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/150.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a> および <a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3500.set-data-backup-dest.md">ALTER SYSTEM SET DATA_BACKUP_DEST</a> ステートメントを使用して、それぞれアーカイブ宛先とデータバックアップ宛先を設定できます。</li>
</ul>
</main>

## 機能の概要

`backup_dest`は、ベースラインバックアップおよびログアーカイブのパスを設定します。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ             | String     |
| デフォルト値              | NULL値     |
| OBServerノードの再起動が必要か | 不要です   |
