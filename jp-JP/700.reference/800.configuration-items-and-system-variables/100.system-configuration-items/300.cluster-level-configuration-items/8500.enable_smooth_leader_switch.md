# enable_smooth_leader_switch

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではパーティションリーダーの切り替えがサポートされなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_smooth_leader_switch`はスムーズリーダー切り替え機能のスイッチです。

## プロパティの説明

|      **プロパティ**      |                  **説明**                                 |
|------------------|------------------------------------------------------------|
| パラメータタイプ             | Bool                                                |
| デフォルト値              | True                                                  |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>    |
| OBServerノードの再起動が必要か | 不要です                                               |
