# backup_log_archive_option

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、この構成パラメータに含まれていた各項目の仕様や設定方法は、以下のように変更されました。
<ul><li>構成パラメータによるバックアップモードの設定は、今後サポートされなくなりました。システムテナントおよびすべてのユーザーテナントは、<a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3800.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a> ステートメントの <code>BINDING</code>オプションを使用して、アーカイブとビジネスの優先モードを設定できます。</li>
<li>ログアーカイブの圧縮機能は現在対応していません。</li></ul>
</li></ul>
</main>

## 機能の概要

`backup_log_archive_option`は、バックアップログのアーカイブオプションを定義するために使用します。

## プロパティの説明

|**プロパティ**|   **説明**      |
|------------------|--------------------------|
| パラメータタイプ             | String                      |
| デフォルト値              | `OPTIONAL COMPRESSION=ENABLE`                    |
| 値の範囲             | <ul><li>`MANDATORY`：バックアップ優先を示します。ログアーカイブが遅延すると書き込みが停止する可能性があります。 </li><li>`OPTIONAL`：書き込み優先を示します。書き込み処理によりログアーカイブが途絶える可能性があります。 </li><li>`COMPRESSION`：`ENABLE`、`DISABLE`、`LZ4_1.0`、`ZSTD_1.3.8`をサポートします。デフォルトは`ENABLE`で、圧縮アルゴリズムはLZ4_1.0が使用されます。 </li></ul>     |
| OBServerノードの再起動が必要か |不要です |
