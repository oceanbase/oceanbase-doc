# zone_merge_order

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では、ゾーンごとのコンパクションやローテーションコンパクションがサポートされなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`zone_merge_order`は、ゾーンのローテーションコンパクションの順序を設定します。指定しない場合、システムが自動的に決定します。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|---------------------|
| パラメータタイプ                      | String  |
| デフォルト値              | NULL値     |
| OBServerノードの再起動が必要か | 不要です   |
