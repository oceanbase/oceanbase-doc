# schema_history_recycle_interval

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`schema_history_recycle_interval`は、システム内部で実行される`schema`マルチバージョンレコードリサイクルタスクの時間間隔を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Time      |
| デフォルト値               | 10m、つまり10分を表します       |
| 値の範囲             | [0s, +∞)<main id="notice" type='explain'><h4>説明</h4><ul><li>値が0の場合、<code>schema</code>マルチバージョンレコード回収タスク機能を無効にすることを意味します。</li> <li>値が0以外の場合、<code>schema</code>マルチバージョンレコード回収タスクを実行する時間間隔を意味します。</li></ul></main> |
| 変更は可能か           | はい。<code>ALTER SYSTEM SET</code> ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。         |

## 設定例

システム内部で実行される`schema`マルチバージョンレコードリサイクルタスクの時間間隔を10分に設定します。

```shell
obclient> ALTER SYSTEM SET schema_history_recycle_interval = '10m';
```
