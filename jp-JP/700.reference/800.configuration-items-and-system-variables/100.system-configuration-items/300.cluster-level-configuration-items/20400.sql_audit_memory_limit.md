# sql_audit_memory_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>OceanBaseデータベースはV2.xバージョンからSQL Auditシステムテーブルをテナントごとに分割したため、SQL Auditが占用するメモリはテナントレベルになりました。この構成パラメータで定義されていたサーバーレベルのメモリオフリット上限は適用されなくなり、V4.0.0バージョン以降は削除されました。</li>
<li>2.x系以降のバージョンでは、システム変数<code>ob_sql_audit_percentage</code>を使用して、SQL Auditメモリが現在のテナントメモリの割合を制御します。<code>ob_sql_audit_percentage</code>システム変数の詳細については、<a href="../../200.system-variable/300.global-system-variable/9000.ob_sql_audit_percentage-global.md">ob_sql_audit_percentage</a>を参照してください。</li></ul>
</main>

## 機能の概要

`sql_audit_memory_limit`は、SQL監査データが占用できる最大メモリを設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Capacity       |
| デフォルト値               | 3G         |
| 値の範囲             | \[64M, +∞) |
| OBServerノードの再起動が必要か | 不要です        |
