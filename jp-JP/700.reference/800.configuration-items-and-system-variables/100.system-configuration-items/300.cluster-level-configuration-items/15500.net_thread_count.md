# net_thread_count

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`net_thread_count`は、ネットワークI/Oスレッドの数を制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**    |   **説明**   |
|------------------|--------------|
| パラメータタイプ            | Int         |
| デフォルト値              | 0          |
| 値の範囲            | [0, 128] <main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.3.5 BP2バージョン以降、値の範囲が[0, 64]から[0, 128]に調整されました。</p></main>|
| 変更は可能か          | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.4.0バージョン以降、「再起動後に反映」モードから「即時反映」モードに調整されました。</p></main>          |

## 使用方法

* デフォルトでは、RPCおよびMySQLのLibeasyのI/Oスレッドは、それぞれCPUコア数の1/8に設定されます。

* `net_thread_count`の値がN（Nは0以上）の場合、RPCおよびMySQLのLibeasyのI/Oスレッドは、それぞれN個ずつ生成されます。

## 設定例

ネットワークI/Oスレッドの数を6に設定します。

```shell
obclient> ALTER SYSTEM SET net_thread_count = 6;
```
