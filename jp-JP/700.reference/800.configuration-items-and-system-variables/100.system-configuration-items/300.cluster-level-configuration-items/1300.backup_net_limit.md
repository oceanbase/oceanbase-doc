# backup_net_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<P>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、クラスタレベルのバックアップはサポートされなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</P>
</main>

## 機能の概要

`backup_net_limit`は、クラスタバックアップの総帯域幅を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Capacity     |
| デフォルト値              | 0M        |
| 値の範囲             | \[0M, +∞) |
| OBServerノードの再起動が必要か | 不要です       |
