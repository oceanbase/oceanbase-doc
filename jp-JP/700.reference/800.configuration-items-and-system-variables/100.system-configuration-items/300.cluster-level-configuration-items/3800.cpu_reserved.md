# cpu_reserved

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系でシステムアーキテクチャが調整されたことにより、対応する機能がサポートされなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`cpu_reserved`はシステムが予約するCPU数を設定します。残りのCPUはOceanBaseデータベースが専有使用します。

## プロパティの説明

|  **プロパティ**    |  **説明**   |
|----------------|-----------|
| パラメータタイプ            | Int        |
| デフォルト値              | 2         |
| 値の範囲            | [0, 15] |
| OBServerノードの再起動が必要か | 不要です       |
