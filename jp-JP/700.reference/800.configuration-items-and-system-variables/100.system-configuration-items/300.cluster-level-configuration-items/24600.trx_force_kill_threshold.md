# trx_force_kill_threshold

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系では対応するロジックが変更されたため、この機能は使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`trx_force_kill_threshold`は、フリーズまたはプライマリスレーブの切り替えによりトランザクションを強制終了する際の最大待機時間を設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Time         |
| デフォルト値              | 100ms        |
| 値の範囲             | \[1ms, 10s\] |
| OBServerノードの再起動が必要か | 不要です          |
