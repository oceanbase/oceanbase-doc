# clog_cache_priority

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、トランザクションログはキャッシュを使用しなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`clog_cache_priority`は、トランザクションログが占用するキャッシュの優先順位を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | 整数型       |
| デフォルト値              | 1        |
| 値の範囲             | \[1, +∞) |
| OBServerノードの再起動が必要か | 不要です      |
