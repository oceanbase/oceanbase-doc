# max_px_worker_count

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では対応する機能が廃止されたため、この構成パラメータはV4.2.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`max_px_worker_count`は、SQL並列クエリエンジンで使用する最大スレッド数を設定します。

## プロパティの説明

|  **プロパティ**    |    **説明**    |
|--------------|----------------|
| パラメータタイプ      | Int         |
| デフォルト値        | 64           |
| 値の範囲      | [0, 65535] |
| 変更は可能か    | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 設定例

SQL並列クエリエンジンで使用する最大スレッド数を64に設定します。

```shell
obclient> ALTER SYSTEM SET max_px_worker_count=64;
```
