# enable_separate_sys_clog

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータに対応する機能は有効化されたことがないため、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_separate_sys_clog`は、システムトランザクションログとユーザートランザクションログを分離して保存するかどうかを設定します。

## プロパティの説明

|      **プロパティ**    |       **説明**  |
|------------------|-----------------|
| パラメータタイプ             | Bool      |
| デフォルト値               | False     |
| 値の範囲             | <ul><li>True：分離ストレージ</li><li>False：非分離ストレージ</li></ul> |
| OBServerノードの再起動が必要か    | 不要です   |
