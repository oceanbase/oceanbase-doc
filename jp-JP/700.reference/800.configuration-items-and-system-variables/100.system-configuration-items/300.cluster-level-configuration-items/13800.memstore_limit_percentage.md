# memstore_limit_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`memstore_limit_percentage`は、テナントがMemStoreとして使用するメモリが、利用可能な総メモリに対する割合を設定します。

## プロパティの説明

|      **プロパティ**    |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | INT        |
| デフォルト値               | 0、適応型調整を行います。<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.3.0バージョンからデフォルト値が50から0に調整されました。</p></main> |
| 値の範囲             | [0, 100) <main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.3.0バージョンから値の範囲が(0, 100)から[0, 100)に調整されました。</p></main>|
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。        |

## 使用方法

* `memstore_limit_percentage`構成パラメータは、`memstore_limit`の値を計算するために使用されます。計算式は以下のとおりです：

  `memstore_limit_percentage` = `memstore_limit` / `memory_size`

  ここで、`memory_size`はテナント作成時に指定した値で、テナントが使用可能なメモリを表します。

* V4.3.x系では、V4.3.0バージョンから、テナントレベルの非表示構成パラメータ<code>_memstore_limit_percentage</code>を使用して、テナントのMemStoreがテナント総メモリに占める割合を設定することもできます。有効範囲が異なる点を除けば、その機能とデフォルト値はクラスタレベルの構成パラメータ<code>memstore_limit_percentage</code>と同じです。これら2つの構成パラメータを設定する際には、以下の点に注意してください：

  <ul><li><code>_memstore_limit_percentage</code>または<code>memstore_limit_percentage</code>のどちらか一方の値（デフォルト値以外）のみを設定した場合は、設定した値（デフォルト値以外）が優先されます。</li> <li>テナントレベルの非表示構成パラメータ<code>_memstore_limit_percentage</code>（デフォルト値以外）とクラスタレベルの構成パラメータ<code>memstore_limit_percentage</code>（デフォルト値以外）の両方の値を設定した場合は、<code>_memstore_limit_percentage</code>で設定した値が優先されます。</li> <li>両方とも設定されていない場合、または両方ともデフォルト値に設定されている場合、システムは以下の適応型ポリシーを採用します：<ul><li>メモリが8GB（実メモリ）以下の規格のテナントの場合、テナントMemStoreの設定比率は40%となります。</li><li>メモリが8GBを超える規格のテナントの場合、テナントMemStoreの設定比率は50%となります。</li></ul></li></ul>

## 設定例

テナントがMemStoreとして使用するメモリを、利用可能な総メモリの60%に設定します。

```shell
obclient> ALTER SYSTEM SET memstore_limit_percentage = 60;
```
