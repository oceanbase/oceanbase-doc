# enable_cgroup

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>この構成パラメータは、V3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_cgroup`は、OBServerノードでcgroup機能を有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  sysテナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータはsysテナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| ------ | ------ |
| パラメータタイプ | Bool |
| デフォルト値 | True |
| 値の範囲 |<ul><li>True：システムがcgroupディレクトリをマウント済みであることを検出した場合、cgroup機能を有効にします。検出されない場合は、警告を報告します。</li><li>False：cgroup機能を無効にします。</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、V4.2.5 BP2以降のバージョンから、この構成パラメータは動的に反映されるように変更されました。</p></main> |

## 設定例

cgroup機能を有効にします。

```shell
obclient> ALTER SYSTEM SET enable_cgroup = true;
```
