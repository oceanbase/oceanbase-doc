# devname

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`devname`は、サービスプロセスがバインドするNICデバイス名を確認するために使用されます。

## 権限要件

`sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを照会できます。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|------------|
| パラメータタイプ             | String    |
| デフォルト値               | bond0  |
| 変更は可能か           | 不可。読み取り専用です。<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.2.0バージョンから適用範囲が動的に有効になるのを読み取り専用に変更されました。</p></main>|
