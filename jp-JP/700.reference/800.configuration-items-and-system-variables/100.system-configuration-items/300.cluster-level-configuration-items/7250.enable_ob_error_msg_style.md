# enable_ob_error_msg_style

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V4.3.1バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_ob_error_msg_style`は、OBServerのエラーコード形式を選択します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**      |                          **説明**                            |
|------------------|------------------------------------------------------------------|
| パラメータタイプ             | Bool                                                         |
| デフォルト値              | True                                                            |
| 値の範囲             | <ul><li>True：OBE-xx形式のエラーコードを使用します。 </li><li>False：ORA-xx形式のエラーコードを使用します。 </li></ul>     |
| OBServerノードの再起動が必要か | 不要です                                                     |

## 設定例

OBE-xx形式のエラーコードを使用するように設定します。

```shell
obclient> ALTER SYSTEM SET enable_ob_error_msg_style = True;
```
