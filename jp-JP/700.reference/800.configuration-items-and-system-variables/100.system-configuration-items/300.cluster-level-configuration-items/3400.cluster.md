# cluster

<main id="notice" type='notice'>
<h4>注意</h4>
<p>この起動パラメータは、OceanBaseクラスタの作成時に設定することを推奨します。クラスタが有効になった後は変更できません。OceanBaseクラスタの作成に関する詳細は、<a href="../../../../400.deploy/300.deploy-oceanbase-enterprise-edition/300.deploy-through-a-graphical-interface/300.deploy-oceanbase-cluster-use-ocp/400.deploy-single-replica-oceanbase-cluster-use-ocp.md">OceanBaseクラスタの作成</a>を参照してください。</p>
</main>

## 機能の概要

`cluster`は、現在のOceanBaseクラスタの名前を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータはクラスタのデプロイ時にのみ設定され、クラスタ起動後は変更できません。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ                 | String       |
| デフォルト値                   | obcluster |
| 変更は可能か                | 不可。`ALTER SYSTEM SET`ステートメントによる変更はサポートされていません。  |
| OBServerノードの再起動が必要か | 不要です。読み取り専用モードのみサポートされます。         |
