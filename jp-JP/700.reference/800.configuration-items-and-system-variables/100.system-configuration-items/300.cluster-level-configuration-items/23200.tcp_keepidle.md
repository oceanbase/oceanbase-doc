# tcp_keepidle

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`tcp_keepidle`は、TCP接続がアイドル状態のときに生存確認プローブをトリガーする時間しきい値を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Time     |
| デフォルト値               | 7200s    |
| 値の範囲             | [1s,+∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

TCP接続がアイドル状態のときに生存確認プローブをトリガーする時間しきい値を7200秒に設定します。

```shell
obclient> ALTER SYSTEM SET tcp_keepidle = '7200s';
```
