# minor_merge_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースには限りがあるため、V4.x系では特定のタスクタイプごとにスレッドリソースを設定することはできなくなりました。この構成パラメータは、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、テナントレベルの構成パラメータ <code>compaction_mid_thread_score</code> を使用して、中優先順位Compactionのワーカースレッド数を設定できます。<code>compaction_mid_thread_score</code> パラメータの詳細については、<a href="../400.tenant-level-configuration-items/1200.compaction_mid_thread_score.md">compaction_mid_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`minor_merge_concurrency`は、ダンプ時の並列スレッド数を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Int        |
| デフォルト値              | 0、並列スレッド数は min[10, cpu_cnt] を表す        |
| 値の範囲             | [0, 64] |
| OBServerノードの再起動が必要か | 不要です       |
