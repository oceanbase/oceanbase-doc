# zone_merge_timeout

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではゾーン単位でのメジャーコンパクション制御がサポートされなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`zone_merge_timeout`は、単一ゾーンのメジャーコンパクションタイムアウト時間を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ                      | Time      |
| デフォルト値              | 3h        |
| 値の範囲             | \[1s, +∞) |
| OBServerノードの再起動が必要か | 不要です       |
