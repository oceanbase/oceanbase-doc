# use_large_pages

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`use_large_pages`は、データベースが使用するメモリのヒュージページ(Huge Pages)を管理します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | String      |
| デフォルト値               | false       |
| 値の範囲             | <ul><li>false：大ページの使用を禁止します。</li> <li>true：大ページと通常ページの混在を許可します。</li> <li>only：システムが大ページのみを使用するよう強制します。</li></ul>    |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | はい。ノードの再起動が必要です。 |

## 設定例

データベースでメモリのヒュージページの使用を禁止します。

```shell
obclient> ALTER SYSTEM SET use_large_pages = 'false';
```
