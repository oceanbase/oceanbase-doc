# ob_java_home

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_java_home`は、現在のOBServerが稼働しているノード上のJavaホームディレクトリを設定します。

## 権限要件

* 構成パラメータの確認

  sysテナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  この構成パラメータはsysテナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|プロパティ|説明|
|---|---|
|パラメータタイプ|STRING|
|デフォルト値|NULL|
|変更は可能か|はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
|OBServerノードの再起動が必要か|不要です。設定は即時に反映されます。|

## 設定例

現在のOBServerが稼働しているノード上のJavaホームディレクトリを`/home/admin/jdk8u422_05`に設定します。

```shell
obclient> ALTER SYSTEM SET ob_java_home="/home/admin/jdk8u422_05";
```
