# migrate_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースには限りがあるため、V4.x系では具体的なタスクタイプによるスレッドリソースの設定は行われなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、構成パラメータ <code>ha_mid_thread_score</code> を使用して、移行タスクなどの高可用性で優先度の高いスレッドのワーカースレッド数を設定できます。テナントレベルの構成パラメータ <code>ha_mid_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3600.ha_mid_thread_score.md">ha_mid_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`migrate_concurrency`は、内部データ移行の最大並列数を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Int        |
| デフォルト値              | 10          |
| 値の範囲             | \[0, 64\] |
| OBServerノードの再起動が必要か | 不要です       |
