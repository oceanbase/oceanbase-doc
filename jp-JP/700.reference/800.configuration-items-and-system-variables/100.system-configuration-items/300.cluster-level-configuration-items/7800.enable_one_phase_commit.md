# enable_one_phase_commit

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系では対応するロジックが変更されたため、この機能は使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_one_phase_commit`は、トランザクションコミットのワンフェーズ最適化機能を有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |                                                 **説明**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| パラメータタイプ                     | Bool                                                                                                   |
| デフォルト値                       | False                                                                                                  |
| 値の範囲                     | <ul><li>True：有効</li><li>False：無効</li></ul>     |
| OBServerノードの再起動が必要か    | 不要です   |

## 設定例

トランザクションコミットのワンフェーズ最適化機能を有効にします。

```shell
obclient> ALTER SYSTEM SET enable_one_phase_commit = True;
```
