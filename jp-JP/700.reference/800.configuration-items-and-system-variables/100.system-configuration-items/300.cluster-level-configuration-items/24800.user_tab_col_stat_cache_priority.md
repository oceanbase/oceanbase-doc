# user_tab_col_stat_cache_priority

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>統計情報のメンテナンス方法が調整されたことにより、対応する機能は使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`user_tab_col_stat_cache_priority`は、統計データキャッシュをキャッシュシステム内で保持する優先順位を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | 整数型       |
| デフォルト値              | 1        |
| 値の範囲             | \[1, +∞) |
| OBServerノードの再起動が必要か | 不要です      |
