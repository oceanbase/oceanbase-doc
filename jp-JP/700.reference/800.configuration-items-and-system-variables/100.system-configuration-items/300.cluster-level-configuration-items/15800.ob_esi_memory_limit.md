# ob_esi_memory_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータに対応する機能はV4.x系ではサポートされなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ob_esi_memory_limit`は、obesiプロセスのメモリ使用量の上限を設定します。

## プロパティの説明

| **プロパティ** | **説明** |
| --- | --- |
| パラメータタイプ | Capacity |
| デフォルト値 | 0M |
| 値の範囲 | [64M, +∞) |
| OBServerノードの再起動が必要か | 不要です |
