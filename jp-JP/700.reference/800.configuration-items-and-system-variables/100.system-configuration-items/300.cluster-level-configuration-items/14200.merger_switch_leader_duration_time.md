# merger_switch_leader_duration_time

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではゾーン単位のローテーションマージがサポートされなくなったため、メジャーコンパクション時の一括リーダー切り替え時間間隔を設定する必要はありません。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`merger_switch_leader_duration_time`は、日次メジャーコンパクション時の一括リーダー切り替え時間間隔を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ                       | Time       |
| デフォルト値                        | 3m、3分を意味します |
| 値の範囲             | \[0s, 30m\] |
| OBServerノードの再起動が必要か | 不要です        |
