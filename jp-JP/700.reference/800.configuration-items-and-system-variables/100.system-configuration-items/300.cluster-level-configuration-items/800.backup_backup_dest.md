# backup_backup_dest

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では、バックアップのバックアップ（二次バックアップ）機能がサポートされなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`backup_backup_dest`は、バックアップデータのバックアップ先を設定します。

## プロパティの説明

|        プロパティ        |  説明   |
|------------------|-------|
| パラメータタイプ             | String |
| デフォルト値              | 空文字列  |
| OBServerノードの再起動が必要か | 不要です   |
