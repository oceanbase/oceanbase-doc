# resource_soft_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャがアップグレードされたため、この構成パラメータの意味は適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ユニット移行のスイッチはテナントレベルの構成パラメータ <code>enable_rebalance</code> のみで制御されます。<code>enable_rebalance</code> パラメータの詳細については、<a href="../400.tenant-level-configuration-items/2900.enable_rebalance.md">enable_rebalance</a>を参照してください。</li></ul>
</main>

## 機能の概要

`resource_soft_limit`は、ユニット均衡を有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int           |
| デフォルト値              | 50           |
| 値の範囲             | \[1, 10000\] |
| OBServerノードの再起動が必要か | 不要です          |

## 使用方法

`resource_soft_limit`構成パラメータの値が`100`未満の場合、ユニット均衡スイッチがオンであることを示します。`resource_soft_limit`構成パラメータの値が`100`以上の場合、ユニット均衡スイッチがオフであることを示します。
