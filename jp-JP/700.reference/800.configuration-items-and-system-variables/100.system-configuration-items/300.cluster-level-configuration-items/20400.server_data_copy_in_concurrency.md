# server_data_copy_in_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースには限りがあるため、V4.x系では具体的なタスクタイプごとにスレッドリソースを設定することができなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、構成パラメータ <code>ha_mid_thread_score</code> を使用して、移行タスクなどの高可用性で優先度の高いスレッドのワーカースレッド数を設定できます。テナントレベルの構成パラメータ <code>ha_mid_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3700.ha_mid_thread_score.md">ha_mid_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`server_data_copy_in_concurrency`は、単一ノードへのデータコピーの最大並列数を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**    |
|------------------|-------------|
| パラメータタイプ             | Int         |
| デフォルト値               | 2           |
| 値の範囲             | [1, 1000\] |
| OBServerノードの再起動が必要か | 不要です       |
