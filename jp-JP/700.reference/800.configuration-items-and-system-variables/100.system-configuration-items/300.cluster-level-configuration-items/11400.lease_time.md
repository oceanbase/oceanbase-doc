# lease_time

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`lease_time`は、ハートビートリース期間を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ    | Time         |
| デフォルト値      | 10s          |
| 値の範囲    | [1s, 5min] |
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。 <main id="notice" type='explain'><h4>説明</h4><p>通常、この構成パラメータを変更することは推奨されません。</p></main>|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

Root Serviceは、ハートビートリース期間内にOBServerノードからハートビート情報を受信しない場合、そのOBServerノードをオフライン状態と見なします。

## 設定例

ハートビートリース期間を10秒に設定します。

```shell
obclient> ALTER SYSTEM SET lease_time ='10s';
```
