# ob_event_history_recycle_interval

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_event_history_recycle_interval`は、履歴イベントの回収間隔を制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Time         |
| デフォルト値               | 7d、7日を意味します    |
| 値の範囲             | [1d, 180d] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 設定例

履歴イベントの回収間隔を7日に設定します。

```shell
obclient> ALTER SYSTEM SET ob_event_history_recycle_interval = '7d';
```
