# default_row_format

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`default_row_format`は、MySQLモードでテーブル作成時に使用するデフォルトの行フォーマットを設定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この構成パラメータは、OceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|   **プロパティ**      |    **説明**   |
|-----------------|---------------|
| パラメータタイプ             | String                                 |
| デフォルト値               | DYNAMIC                             |
| 値の範囲             | <ul><li>REDUNDANT</li> <li>COMPACT</li><li>DYNAMIC</li><li>COMPRESSED</li></ul>   |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。            |

## 設定例

MySQLモードで、テーブル作成時に使用するデフォルトの行フォーマットを`DYNAMIC`に設定します。

```shell
obclient> ALTER SYSTEM SET default_row_format= 'DYNAMIC';
```
