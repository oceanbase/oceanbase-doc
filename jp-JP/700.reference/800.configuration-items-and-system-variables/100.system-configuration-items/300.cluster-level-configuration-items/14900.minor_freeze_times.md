# minor_freeze_times

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャがアップグレードされたことにより、この構成パラメータは <code>major_compact_trigger</code> パラメータと同じ意味を持つため、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、テナントのフリーズ回数を制御し、それに応じてメジャーコンパクションをトリガーするテナントレベルの構成パラメータ <code>major_compact_trigger</code> のみを使用できます。<code>major_compact_trigger</code> パラメータの詳細については、<a href="../400.tenant-level-configuration-items/5200.major_compact_trigger.md">major_compact_trigger</a> を参照してください。</li></ul>
</main>

## 機能の概要

`minor_freeze_times`は、フリーズが何回発生したら1回のメジャーコンパクションをトリガーするかを設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int           |
| デフォルト値              | 100          |
| 値の範囲             | \[0, 65535\] |
| OBServerノードの再起動が必要か | 不要です          |

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
  <li>この構成パラメータの値が0の場合、フリーズ回数に関係なく、自動的にメジャーコンパクションはトリガーされません。 </li>
  <li>この構成パラメータは <code>major_compact_trigger</code> パラメータと同じ機能を持ちます。 </li>
  </ul>
</main>
