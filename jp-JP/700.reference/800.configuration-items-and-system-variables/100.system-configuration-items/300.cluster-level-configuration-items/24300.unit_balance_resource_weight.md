# unit_balance_resource_weight

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系からシングルマシンログストリームアーキテクチャへの移行に伴い、レプリカはログストリーム単位で分散されるため、ロードバランシングモジュールではパーティションの均衡を直接制御できなくなりました。この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。  </p>
</main>

## 機能の概要

`unit_balance_resource_weight`は、UNIT均衡戦略で使用されるリソースの重みを設定します。通常は手動での設定は不要です。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ                      | String  |
| デフォルト値              | NULL値     |
| OBServerノードの再起動が必要か | 不要です    |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>デフォルトでは、重み値はNULLです。重み値を設定する場合、すべての重み値の合計は100である必要があります。  </li>
  <li><code>enable_unit_balance_resource_weight</code>が有効な場合にのみ、<code>unit_balance_resource_weight</code>の設定が有効になります。  </li>
  </ul>
</main>
