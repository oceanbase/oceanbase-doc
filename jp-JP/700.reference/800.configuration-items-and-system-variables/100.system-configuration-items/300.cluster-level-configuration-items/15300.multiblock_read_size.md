# multiblock_read_size

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でストレージアーキテクチャが変更されたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`multiblock_read_size`は、データ読み取り時のI/O集約サイズを設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Capacity         |
| デフォルト値              | 128k       |
| 値の範囲             | \[0K, 2M\] |
| OBServerノードの再起動が必要か | 不要です        |
