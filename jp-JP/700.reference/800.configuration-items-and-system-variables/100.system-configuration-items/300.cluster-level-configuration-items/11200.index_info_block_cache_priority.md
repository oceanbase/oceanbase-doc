# index_info_block_cache_priority

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではアーキテクチャが変更・アップグレードされたため、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、構成パラメータ <code>index_block_cache_priority</code> を使用してメタデータインデックスのマイクロブロックのキャッシュ優先順位を設定します。構成パラメータ <code>index_block_cache_priority</code> の詳細については、<a href="10900.index_block_cache_priority.md">index_block_cache_priority</a>を参照してください。</li></ul>
</main>

## 機能の概要

`index_info_block_cache_priority`は、ブロックインデックスのキャッシュシステム内での優先順位を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値              | 1        |
| 値の範囲             | \[1, +∞) |
| OBServerノードの再起動が必要か | 不要です    |
