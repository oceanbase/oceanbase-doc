# merger_warm_up_duration_time

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でストレージアーキテクチャがアップグレードされたことに伴い、この構成パラメータに対応する機能がサポートされなくなったため、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`merger_warm_up_duration_time`は、メジャーコンパクション時の新バージョンベースラインデータのウォームアップ時間を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**    |
|------------------|-------------|
| パラメータタイプ             | Time        |
| デフォルト値              | 0s          |
| 値の範囲             | \[0s, 60m\] |
| OBServerノードの再起動が必要か | 不要です         |
