# rootservice_memory_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではRSテナントの概念が存在しないため、対応する機能は使用されなくなりました。この構成パラメータはV4.2.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`rootservice_memory_limit`はRoot Serviceの最大メモリ容量制限を設定します。

## プロパティの説明

|  **プロパティ**   |  **説明**   |
|-------------|-------------|
| パラメータタイプ     | Capacity      |
| デフォルト値       | 2G        |
| 値の範囲     | [2G, +∞) |
| 変更は可能か   | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 設定例

Root Serviceの最大メモリ容量を2GBに設定します。

```shell
obclient> ALTER SYSTEM SET rootservice_memory_limit='2G';
```
