# default_transport_compress_func

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではアーキテクチャの最適化が行われたため、各モジュールで使用する圧縮アルゴリズムを個別に制御するようになり、統一されたデフォルトの圧縮アルゴリズムは使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では：
  <ul><li>V4.1.0以降、テナントレベルの構成パラメータ <code>log_transport_compress_func</code> を使用して、ログ転送プロセスで使用する圧縮アルゴリズムを制御します。<code>log_transport_compress_func</code> パラメータの詳細については、<a href="../400.tenant-level-configuration-items/5400.log_transport_compress_func.md">log_transport_compress_func</a>を参照してください。</li>
  <li>V4.2.1以降、テナントレベルの構成パラメータ <code>kv_transport_compress_func</code> を使用して、OBKV-Tableクエリ結果の転送で使用する圧縮アルゴリズムを制御します。<code>kv_transport_compress_func</code> パラメータの詳細については、<a href="../400.tenant-level-configuration-items/4000.kv_transport_compress_func.md">kv_transport_compress_func</a>を参照してください。</li></ul>
</li></ul>
</main>

## 機能の概要

`default_transport_compress_func`は、クラスタ全体のRPC圧縮アルゴリズムを設定します。

## プロパティの説明

| **プロパティ**                      |       **説明**                        |
|------------------------------|----------------------------------------|
| パラメータタイプ                      | String                                 |
| デフォルト値                        | none                                   |
| 値の範囲                      | <ul><li> none   </li><li> lz4_1.0   </li><li> snappy_1.0   </li><li> zlib_1.0   </li><li> zstd_1.0   </li><li> zstd_1.3.8 </li></ul>   |
| OBServerノードの再起動が必要か    | 不要です                    |

## 設定例

クラスタ全体のRPC転送の圧縮アルゴリズムをlz4_1.0に設定します。

```shell
obclient> ALTER SYSTEM SET default_transport_compress_func = 'lz4_1.0';
```
