# datafile_next

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.2.x系では、この構成パラメータはV4.2.0バージョンから導入されました。</li>
  <li>V3.x系では、この構成パラメータはV3.1.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`datafile_next`は、ディスクファイルの自動拡張における増分サイズを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| プロパティ | 説明 |
| ------ | ----- |
| パラメータタイプ | Capacity |
| デフォルト値 | 0。増加を有効にしないことを示します。 |
| 値の範囲 | [0M, +∞) |
| 変更は可能か | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

`datafile_next`のデフォルト値は0であり、ディスクファイルの自動増加を無効にすることを意味します。自動増加を有効にするには、新しい値を設定する必要があります。

* `datafile_next`が1GB未満に設定されている場合、値はmin(1GB, datafile_maxsize * 10%)となります。
* `datafile_next`が1GBより大きく設定されている場合、値はmin(datafile_next, ディスク残存容量)となります。

## 設定例

ディスクファイルの自動拡張における増分サイズを10GBに設定します。

```shell
obclient> ALTER SYSTEM SET datafile_next = '10G';
```
