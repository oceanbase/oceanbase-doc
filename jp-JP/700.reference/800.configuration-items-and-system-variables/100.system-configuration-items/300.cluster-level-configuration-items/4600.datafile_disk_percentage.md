# datafile_disk_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`datafile_disk_percentage`は、データファイルが占有するディスク容量の割合を設定します(`data_dir`が存在するディスクは、OceanBaseデータベースシステムによってデータストレージ用に初期化されます)。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**    |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値               | 0<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、バージョンV4.0.0以降でデフォルト値が90から0に変更されました。</p></main>       |
| 値の範囲             | [0，99]<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、バージョンV4.0.0以降で値の範囲が[5，99]から[0，99]に変更されました。</p></main> |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。    |

## 使用方法

* この構成パラメータと<code>datafile_size</code>を同時に設定した場合、[datafile_size](4900.datafile_size.md)で設定された値が優先されます。
* この構成パラメータの値が0の場合、システムはログとデータが同一ディスクを共有するかどうかに基づいて、データファイルが占有するディスク容量の割合を自動的に計算します。

  * 共有する場合、データファイルが占有するディスク容量の割合は60%です。
  * 専有する場合、データファイルが占有するディスク容量の割合は90%です。

## 設定例

データファイルが占有するディスク容量の割合を98に設定します。

```shell
obclient> ALTER SYSTEM SET datafile_disk_percentage = 98;
```
