# global_index_build_single_replica_timeout

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系で対応するロジックが最適化されたため、データ構築のタイムアウト時間を外部設定で指定する必要がなくなりました。この機能は廃止され、この構成パラメータはV4.0.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`global_index_build_single_replica_timeout`は、グローバルインデックスの構築時に、各レプリカの構築タイムアウト時間を設定します。

## プロパティの説明

| **プロパティ**  |  **説明**   |
|-----------|-------------|
| パラメータタイプ             | Time      |
| デフォルト値               | 48h       |
| 値の範囲             | [1h, +∞) |
| OBServerノードの再起動が必要か    | 不要です    |
