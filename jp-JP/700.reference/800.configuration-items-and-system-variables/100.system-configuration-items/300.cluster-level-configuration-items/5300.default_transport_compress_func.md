# default_transport_compress_func

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではアーキテクチャの最適化に伴い、各モジュールで使用する圧縮アルゴリズムが個別に制御されるようになり、統一されたデフォルトの圧縮アルゴリズムは使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では：
<ul><li>V4.1.0以降、ログ転送プロセスで使用する圧縮アルゴリズムは、テナントレベルの構成パラメータ <code>log_transport_compress_func</code> で制御します。<code>log_transport_compress_func</code> の詳細については、<a href="../400.tenant-level-configuration-items/5000.log_transport_compress_func.md">log_transport_compress_func</a>を参照してください。</li>
<li>V4.2.x系では、V4.2.1以降、OBKV-Tableクエリ結果の転送で使用する圧縮アルゴリズムは、テナントレベルの構成パラメータ <code>kv_transport_compress_func</code> で制御します。V4.3.x系では、クラスタレベルの構成パラメータ <code>tableapi_transport_compress_func</code> で制御します。<code>tableapi_transport_compress_func</code> の詳細については、<a href="22600.tableapi_transport_compress_func.md">tableapi_transport_compress_func</a>を参照してください。</li></ul></li></ul>
</main>

## 機能の概要

`default_transport_compress_func`は、クラスタ全体のRPC圧縮アルゴリズムを設定します。

## プロパティの説明

| **プロパティ**                      |       **説明**                        |
|------------------------------|----------------------------------------|
| パラメータタイプ                      | String                                 |
| デフォルト値                        | none                                   |
| 値の範囲                      | <ul><li>none </li><li>lz4_1.0    </li><li>snappy_1.0    </li><li>zlib_1.0    </li><li> zstd_1.0    </li><li>zstd_1.3.8    </li></ul>    |
| 変更は可能か                    | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か    | 不要です                   |

## 設定例

クラスタ全体のRPC転送の圧縮アルゴリズムを `lz4_1.0` に設定します。

```shell
obclient> ALTER SYSTEM SET default_transport_compress_func = 'lz4_1.0';
```
