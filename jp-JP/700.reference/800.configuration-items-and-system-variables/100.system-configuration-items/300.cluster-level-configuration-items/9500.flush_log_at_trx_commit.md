# flush_log_at_trx_commit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータの導入後の利用率が低いため、総合的な評価を経て、V4.0.0バージョン以降の削除が決定されました。</p>
</main>

## 機能の概要

`flush_log_at_trx_commit`は、トランザクションコミット時のトランザクションログ書き込みポリシーを設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値              | 1        |
| 値の範囲             | \[0, 2\] |
| OBServerノードの再起動が必要か | 不要です      |

## 使用方法

`flush_log_at_trx_commit`構成パラメータの値の意味は以下のとおりです：

* 値が0の場合、ログがバッファに書き込まれるのを待たずに、コミット処理を続行します。

* 値が1の場合、ログがディスクに書き込まれるのを待ちます。

* 値が2の場合、ログがディスクにフラッシュされるまで待たずに、バッファに書き込まれるのを待ちます。
