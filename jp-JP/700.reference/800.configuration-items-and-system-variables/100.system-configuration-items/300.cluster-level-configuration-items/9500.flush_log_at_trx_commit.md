# flush_log_at_trx_commit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータの導入後の利用率が低いことから、総合的な評価の結果、V4.0.0バージョン以降の削除が決定されました。</p>
</main>

## 機能の概要

`flush_log_at_trx_commit`は、トランザクションコミット時のトランザクションログの書き込みポリシーを設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値              | 1        |
| 値の範囲             | \[0, 2\] |
| OBServerノードの再起動が必要か | 不要です      |

## 使用方法

`flush_log_at_trx_commit`構成パラメータの値の意味は以下のとおりです：

* 値が0の場合、ログのバッファへの書き込みを待たないことを意味します。

* 値が1の場合、ログのディスクへの書き込みを待つことを意味します。

* 値が2の場合、ログの永続化を待たずにバッファへの書き込みを待つことを意味します。
