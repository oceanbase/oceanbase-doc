# log_disk_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`log_disk_percentage`は、Redoログが配置されるディスクの総容量に占める割合を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ    | Int |
| デフォルト値 | 0 |
| 値の範囲 | [0, 99] |
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

* <code>log_disk_size</code> の値が0の場合にのみ、この構成パラメータが有効になります。<code>log_disk_size</code> の値が0以外の場合、この構成パラメータは無効になります。<code>log_disk_size</code> の詳細については、<a href="12700.log_disk_size.md">log_disk_size</a>を参照してください。
* この構成パラメータの値が0の場合、システムはログとデータが同じディスクを共有するかどうかに基づいて、Redoログが配置されるディスクの総容量に占める割合を自動的に計算します。
  * 共有の場合、Redoログが配置されるディスクの総容量に占める割合は30%です。ディスク容量の30%がログファイルに割り当てられます。
  * 専用の場合、Redoログが配置されるディスクの総容量に占める割合は90%です。ディスク容量の90%がログファイルに割り当てられます。

## 設定例

Redoログが配置されるディスクの総容量の30%を設定します。

```shell
obclient> ALTER SYSTEM SET log_disk_percentage=30;
```
