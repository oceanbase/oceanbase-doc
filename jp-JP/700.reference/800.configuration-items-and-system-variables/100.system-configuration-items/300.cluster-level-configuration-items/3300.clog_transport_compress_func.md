# clog_transport_compress_func

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.0.0バージョンでは、トランザクションログの圧縮機能がサポートされていないため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.1.0バージョン以降、OceanBaseデータベースは再びトランザクションログの圧縮機能をサポートしています。V4.1.0以降のバージョンでは、テナントレベルの構成パラメータ <code>log_transport_compress_func</code> を使用して、トランザクションログの内部転送時に使用する圧縮アルゴリズムを設定します。<code>log_transport_compress_func</code> パラメータの詳細については、<a href="../400.tenant-level-configuration-items/5000.log_transport_compress_func.md">log_transport_compress_func</a>を参照してください。</li></ul>
</main>

## 機能の概要

`clog_transport_compress_func`は、トランザクションログの内部転送時に使用する圧縮アルゴリズムを設定します。

## プロパティの説明

|      **プロパティ**      |               **説明**                                    |
|------------------|-------------------------------------------------------------------------------------------------------------------------|
| パラメータタイプ             | String                 |
| デフォルト値              | lz4_1.0                                |
| 値の範囲             | <ul><li> none</li>   <li> lz4_1.0</li>   <li> snappy_1.0</li>   <li> zlib_1.0</li>   <li> zstd_1.0</li>   <li> zstd_1.3.8</li></ul>    |
| OBServerノードの再起動が必要か | 不要です              |
