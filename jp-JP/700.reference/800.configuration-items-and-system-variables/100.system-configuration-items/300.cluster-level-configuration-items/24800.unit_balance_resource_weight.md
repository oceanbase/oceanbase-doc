# unit_balance_resource_weight

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系が単一マシンのログストリームアーキテクチャにアップグレードされたことにより、レプリカはログストリームを単位として分散されるようになりました。ロードバランシングモジュールではパーティションの均衡を直接制御できなくなったため、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。  </p>
</main>

## 機能の概要

`unit_balance_resource_weight`は、UNIT均衡ポリシーで使用するリソースの重みを設定します。通常は手動での設定は不要です。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ                      | String  |
| デフォルト値              | NULL値     |
| OBServerノードの再起動が必要か | 不要です   |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>デフォルトでは、重み値は空です。重み値を設定した場合、すべての重み値の合計は100でなければなりません。  </li>
  <li><code>enable_unit_balance_resource_weight</code>が有効になっている場合に限り、<code>unit_balance_resource_weight</code>の設定が有効になります。  </li>
  </ul>
</main>
