# unit_gc_wait_time

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このパラメータはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このパラメータはV4.3.5 BP1バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`unit_gc_wait_time`はUnit GCの最大待機時間を指定します。この時間までにGCが行われない場合、強制的にGCを実行します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ**  | **説明** |
| ----------|----------------------------------|
| パラメータタイプ   | Time |
| デフォルト値     | 1m、1分を表す |
| 値の範囲   |[0, 30d]|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

構成パラメータの値を変更する際、数値の後に単位としてus（マイクロ秒）、ms（ミリ秒）、s（秒）、m（分）、h（時間）、またはd（日）を指定できます。

## 設定例

Unit GCの最大待機時間を1分に設定します。1分を超えた場合、システムは強制的にGCを実行します。

```shell
obclient> ALTER SYSTEM SET unit_gc_wait_time = '1m';
```
