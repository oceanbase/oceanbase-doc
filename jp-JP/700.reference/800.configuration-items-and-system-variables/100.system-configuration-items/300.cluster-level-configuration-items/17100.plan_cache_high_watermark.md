# plan_cache_high_watermark

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータに対応する機能は有効になったことがないため、V4.2.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`plan_cache_high_watermark`は、実行計画キャッシュが使用するメモリのしきい値を設定します。このしきい値を超えると、自動的なエリミネーションがトリガーされます。

## プロパティの説明

|      **プロパティ**             |  **説明**               |
|---------------------------|-------------------------|
| パラメータタイプ                   | Capacity   |
| デフォルト値                     | 2000M、デフォルト単位はMBです。設定時に単位を指定する必要があります。  |
| 値の範囲                   | [0, +∞)   |
| OBServerノードの再起動が必要か  | 不要です    |
