# merge_stat_sampling_ratio

<main id="notice" type='explain'>
<h4>説明</h4>
<p></p>
<ul><li>V4.x系では、統計情報収集の仕組みが全面的に見直されたことにより、メジャーコンパクション処理中は統計情報を収集しなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、主にDBMS_STATSシステムパッケージを呼び出して統計情報を収集します。</li></ul>
</main>

## 機能の概要

`merge_stat_sampling_ratio`は、メジャーコンパクション時のデータ列統計情報のサンプリング率を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 100        |
| 値の範囲             | \[0, 100\] |
| OBServerノードの再起動が必要か | 不要です        |
