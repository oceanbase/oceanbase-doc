# merge_stat_sampling_ratio

<main id="notice" type='explain'>
<h4>説明</h4>
<p></p>
<ul><li>V4.x系では統計情報収集の仕組みが全面的に見直されたため、メジャーコンパクション処理中は統計情報を収集しなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されています。</li>
<li>V4.x系では、主にDBMS_STATSシステムパッケージを呼び出して統計情報を収集します。統計情報収集の詳細な操作手順および説明については、<a href="../../../../600.manage/900.performance-tuning/400.sql-tuning/200.execution-plan-optimization/100.statistics-and-cost-based-optimization/200.statistic-information/200.collect-statistic-information/100.collect-statistic-information-overview.md">統計情報収集の概要</a>を参照してください。</li></ul>
</main>

## 機能の概要

`merge_stat_sampling_ratio`は、メジャーコンパクション時のデータ列統計情報のサンプリング率を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 100        |
| 値の範囲             | \[0, 100\] |
| OBServerノードの再起動が必要か | 不要です        |
