# backup_zone

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、Zoneを指定してバックアップを行うことは現在サポートされていません。</li></ul>
</main>

## 機能の概要

`backup_region`は、ユーザーがバックアップを実行するZoneを指定します。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ             | String  |
| デフォルト値              | 空文字列   |
| 値の範囲             | 対象外    |
| OBServerノードの再起動が必要か | 不要です    |
