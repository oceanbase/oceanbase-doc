# rootservice_async_task_queue_size

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`rootservice_async_task_queue_size`は、Root Service内部の非同期タスクキューのサイズを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int            |
| デフォルト値               | 16384         |
| 値の範囲             | [8, 131072] |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

Root Service内部の非同期タスクキューのサイズを16384に設定します。

```shell
obclient> ALTER SYSTEM SET rootservice_async_task_queue_size = 16384;
```
