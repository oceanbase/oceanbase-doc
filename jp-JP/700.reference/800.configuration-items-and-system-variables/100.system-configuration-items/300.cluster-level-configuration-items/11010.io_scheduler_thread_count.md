# io_scheduler_thread_count

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.5 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

`io_scheduler_thread_count`は、I/O分離スケジューリングロジックのスレッド数を調整するために使用します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---|---|
| パラメータタイプ    | Int |
| デフォルト値      | 4 |
| 値の範囲    | [1，16] |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | はい。変更を有効にするには、OBServerノードを再起動する必要があります。 |

## 使用方法

この構成パラメータは、I/O分離スケジューリングロジックのスレッド数を動的に調整するために使用します。この構成パラメータにより、システムは具体的なビジネスニーズに応じてリソース割り当てを柔軟に調整し、パフォーマンスを最適化できます。

通常、1つのスレッドは約10万IOPSをサポートできます。ディスクの性能が良好で40万IOPSに達する場合は、スレッド数を4に調整することを推奨します。実際の本番環境では、パフォーマンステストを通じて最適なスレッド数を決定することを推奨します。

## 設定例

I/O分離スケジューリングロジックのスレッド数を8に設定します。

```shell
obclient> ALTER SYSTEM SET io_scheduler_thread_count = 8;
```
