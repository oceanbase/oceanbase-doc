# data_dir

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`data_dir`は、SSTableなどのデータを格納するディレクトリを表示します。

## 権限要件

`sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

## プロパティの説明

| **プロパティ** | **説明** |
|--------|--------|
| パラメータタイプ   | String    |
| デフォルト値    | store  |
| 変更は可能か  | 不可。`ALTER SYSTEM SET`ステートメントでの変更はサポートされていません。      |
| OBServerノードの再起動が必要か | 不要です。読み取り専用モードのみサポートされます。  |
