# ob_java_connector_path

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_java_connector_path`は、JNI（Java Native Interface）が外部テーブル（HDFS外部テーブルなど）へのアクセスや外部テーブルに対する処理の実行に必要とするConnector Jarパッケージのルートパスを設定します。このパスは`ob_java_home`構成パラメータで指定されたパスと結合され、JVMのクラスロードパスを形成します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この構成パラメータはOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
</main>

## 権限要件

* 構成パラメータの確認
  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。
* 構成パラメータの変更
  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ**  | **説明** |
|---|---|
| パラメータタイプ | String |
| デフォルト値 | `""` (空文字列) |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。 |
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

* この構成パラメータは、HDFS外部テーブルなどのJNI機能をサポートするために、OceanBaseデータベースのJava環境を有効にする構成パラメータの一つです。通常は`ob_enable_java_env`、`ob_java_home`、`ob_java_opts`構成パラメータと併用する必要があります。
* **初期化にかかる時間**：Java環境の初回初期化には時間がかかり、関連する外部テーブルへの初回クエリがタイムアウトする可能性があります。クエリのタイムアウト時間を適切に調整することを推奨します。その後のクエリでは再度初期化されません。
* **デプロイの一貫性**：複数マシンのデプロイ環境では、機能が正常に動作するように、すべてのOBServerノードで同じパスを設定し、そのパスが指すディレクトリが各ノードに存在することを確認する必要があります。
* **パス要件**：設定するパスは、Connector Jarパッケージが保存されているディレクトリを指す必要があります。実際に配布されるパッケージディレクトリに`current`、`hadoop`、バージョンディレクトリ（例：`vX.X.X`、実際のバージョン番号はOceanBaseのバージョンによって異なる）などのエントリが含まれている場合、`ob_java_connector_path`を`current`ディレクトリのパスに設定することを推奨します。
* **環境依存性**：この機能を使用する前に、サーバーにJava環境（例：OpenJDK 8）を正しくインストールし、必要な環境変数を適切に設定しておく必要があります（例：`LD_LIBRARY_PATH`に`libhdfs.so`があるディレクトリを設定）。

## 設定例

Java Connectorのパスを`/home/admin/jni_packages/current`に設定します。

```shell
obclient> ALTER SYSTEM SET ob_java_connector_path = '/home/admin/jni_packages/current';
```
