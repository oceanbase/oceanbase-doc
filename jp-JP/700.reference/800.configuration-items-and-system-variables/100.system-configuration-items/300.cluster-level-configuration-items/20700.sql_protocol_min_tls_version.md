# sql_protocol_min_tls_version

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`sql_protocol_min_tls_version`は、SQLステートメントがSSL接続を実行する際に使用するSSL/TLSプロトコルの最小バージョン番号を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| --- | --- |
| パラメータタイプ             | String|
| デフォルト値               | none |
| 値の範囲             |<ul><li>none：接続で使用されるSSL/TLSバージョン番号に制限を設けない</li><li>TLSv1 / TLSv1.1 / TLSv1.2 / TLSv1.3：TLSv1 / TLSv1.1 / TLSv1.2 / TLSv1.3のいずれかのバージョン番号を指定した場合、接続がSSL暗号化の使用を選択した場合、指定されたバージョン番号以上のプロトコルバージョンが使用されます。</li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

この構成パラメータはSSLバージョン番号の選択を制御するためにのみ使用されます。SSLを有効にするには、[ssl_client_authentication](20800.ssl_client_authentication.md)も設定する必要があります。

## 設定例

SQLステートメントがSSL接続を実行する際に使用するSSL/TLSプロトコルの最小バージョン番号をNONEに設定します。

```shell
obclient> ALTER SYSTEM SET sql_protocol_min_tls_version = 'none';
```
