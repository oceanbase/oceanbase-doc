# global_major_freeze_residual_memory

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは導入後の利用率が低かったため、総合的な評価を経て、V4.0.0バージョンから削除されました。 </p>
</main>

## 機能の概要

`global_major_freeze_residual_memory`は、グローバルフリーズをトリガーする残存メモリのしきい値を設定します。つまり、残存メモリがこの割合を下回った場合にグローバルフリーズをトリガーします。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Int        |
| デフォルト値              | 40        |
| 値の範囲             | \[1, 99\] |
| OBServerノードの再起動が必要か | 不要です       |

## 使用方法

`global_major_freeze_residual_memory`構成パラメータは割合であり、その割合の基準となる値はmemory_limit - system_memory、すなわちOceanBaseデータベースの内部テナント500個が予約するメモリを差し引いた値です。フリーズされたMemStoreは、メジャーコンパクションが完了するとメモリが解放されるため、ここではフリーズされたMemStoreが占有するメモリもactive_memstoreが使用可能なメモリと見なされます。また、blockcacheが占有できるメモリのうち、それに割り当てられる部分もMemStoreが使用可能なメモリと見なされます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>global_major_freeze_residual_memory</code>構成パラメータの値は、<code>global_write_halt_residual_memory</code>より大きく設定する必要があります。そうでない場合、グローバルフリーズトリガーは実際には機能せず、テナント側でのグローバルフリーズのトリガーに依存することになります。  </p>
</main>
