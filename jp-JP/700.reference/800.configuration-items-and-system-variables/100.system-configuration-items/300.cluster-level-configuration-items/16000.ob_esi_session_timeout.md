# ob_esi_session_timeout

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータに対応する機能はV4.x系ではサポートされなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ob_esi_session_timeout`は、obesiプロセスがアクティブセッションのリソースを保持するタイムアウト時間を設定します。

## プロパティの説明

| **プロパティ** | **説明** |
| --- | --- |
| パラメータタイプ | Time |
| デフォルト値 | 1m |
| 値の範囲 | [10s, 30m] |
| OBServerノードの再起動が必要か | 不要です |
