# enable_global_freeze_trigger

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でテナント単位のフリーズに調整されたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。  </p>
</main>

## 機能の概要

`enable_global_freeze_trigger`は、グローバルフリーズを自動的にトリガーするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**                                 |
|------------------|-----------------------------------------------|
| パラメータタイプ             | Bool                                          |
| デフォルト値              | False                                           |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>    |
| OBServerノードの再起動が必要か | 不要です                                        |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>  この構成パラメータはデフォルト値のままにしておくことを推奨します。変更は不要です。  </p>
</main>
