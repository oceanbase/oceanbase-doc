# gc_wait_archive

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でストレージアーキテクチャがアップグレードされたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`gc_wait_archive`は、パーティションGC時にパーティション上のすべてのログアーカイブ完了を待機するかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |                                                 **説明**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| パラメータタイプ             | Bool                                                                                                   |
| デフォルト値              | True                                                                                                   |
| 値の範囲             | <ul><li> False   </li><li> True</li></ul>    |
| OBServerノードの再起動が必要か | 不要です                                                                                                      |
