# ob_storage_s3_url_encode_type

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、この構成パラメータはV4.3.3バージョンから導入されました。</li>
<li>V4.2.1系では、この構成パラメータはV4.2.1 BP9バージョンから導入されました。V4.2.x系のその他のバージョンでは、この構成パラメータはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`ob_storage_s3_url_encode_type`は、S3にリクエストを送信する際のURLエンコード方式がRFC 3986標準と互換性があるかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明**    |
|-----------|------------|
| パラメータタイプ | String |
| デフォルト値   | compliantRfc3986Encoding <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、V4.4.2 BP1バージョン以降、デフォルト値が<code>default</code>から<code>compliantRfc3986Encoding</code>に調整されました。</p></main> |
| 値の範囲 | <ul><li>compliantRfc3986Encoding</li> <li>default</li></ul> |
| 変更は可能か           | はい。<code>ALTER SYSTEM SET</code>ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

この構成パラメータは、S3プロトコルに部分的に対応しているものの、AWS S3 SDKのデフォルトのURLエンコード方式をサポートしないオブジェクトストレージに適用されます。関連する操作と例については、[ログアーカイブの準備作業](../../../../600.manage/600.backup-and-recovery/300.log-archive/200.preparation-before-log-archive.md)を参照してください。

## 設定例

S3にリクエストを送信する際のURLエンコード方式をRFC 3986標準と互換性があるように設定します。

```shell
obclient> ALTER SYSTEM SET ob_storage_s3_url_encode_type='compliantRfc3986Encoding';
```
