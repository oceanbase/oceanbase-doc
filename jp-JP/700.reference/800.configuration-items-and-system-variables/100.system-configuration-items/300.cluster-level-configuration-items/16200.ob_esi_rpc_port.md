# ob_esi_rpc_port

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では物理バックアップ・リカバリ機能のアーキテクチャが最適化されたため、この構成パラメータに対応する機能はV4.x系でサポートされなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ob_esi_rpc_port`は、obesiプロセスとobserverプロセス間の通信ポートを設定します。

## プロパティの説明

| **プロパティ**    | **説明**        |
|-------------|-----------------|
| パラメータタイプ | Int |
| デフォルト値 | 2501 |
| 値の範囲 | [1025, 65535] |
| OBServerノードの再起動が必要か | 不要です |
