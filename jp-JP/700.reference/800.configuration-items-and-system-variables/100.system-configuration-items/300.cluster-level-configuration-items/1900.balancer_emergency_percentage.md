# balancer_emergency_percentage

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でストレージアーキテクチャがアップグレードされたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`balancer_emergency_percentage`はUNIT負荷のしきい値を設定します。UNIT負荷がこのしきい値を超えると、レプリカを当該UNITの外へ移行することを許可し、メジャーコンパクション中でもロードバランシングを実行します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ                     | Int         |
| デフォルト値              | 80           |
| 値の範囲             | \[1, 100\] |
| OBServerノードの再起動が必要か | 不要です        |
