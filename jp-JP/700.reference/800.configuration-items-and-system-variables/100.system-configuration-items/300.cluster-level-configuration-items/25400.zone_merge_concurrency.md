# zone_merge_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではゾーン単位でのメジャーコンパクションの制御がサポートされなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`zone_merge_concurrency`は、メジャーコンパクション時に並列処理を許可するゾーン数を設定します。値が0の場合、システムがデプロイ状況に応じて最適な並列度を自動的に選択します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int      |
| デフォルト値              | 0        |
| 値の範囲             | \[0, +∞) |
| OBServerノードの再起動が必要か | 不要です     |
