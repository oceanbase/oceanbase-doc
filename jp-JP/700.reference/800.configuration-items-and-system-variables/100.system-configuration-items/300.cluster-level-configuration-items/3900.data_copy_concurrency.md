# data_copy_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースには限りがあるため、V4.x系では具体的なタスクタイプごとのスレッドリソース設定をサポートしていません。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、<code>ha_high_thread_score</code>構成パラメータを使用できます。これは、レプリケーション、Rebuild、復元などの高可用性・高優先順位スレッドのワーカースレッド数を制御します。テナントレベルの構成パラメータ <code>ha_high_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3400.ha_high_thread_score.md">ha_high_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`data_copy_concurrency`は、システム内で並列実行されるデータ移行レプリケーションタスクの最大並列数を設定します。

## プロパティの説明

| **プロパティ** |  **説明**  |
|--------|----------|
| パラメータタイプ   | Int       |
| デフォルト値    | 20       |
| 値の範囲   | \[1, +∞) |
| リスタートが必要か | 不要です      |
