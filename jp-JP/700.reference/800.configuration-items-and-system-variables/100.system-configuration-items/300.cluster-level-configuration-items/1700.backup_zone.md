# backup_zone

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系では物理バックアップ・リカバリ機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.2.5については、V4.2.5 BP2以降のバージョンから、<code>ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST</code>ステートメントを使用してバックアップ用ゾーンを指定できます。詳細な設定例については、<a href="../../../../600.manage/600.backup-and-recovery/1500.configuration-case-the-source-of-backup-dest-and-archive-dest.md">バックアップパスとアーカイブパスのソース側設定例</a>を参照してください。</li></ul>
</main>

## 機能の概要

`backup_zone`は、ユーザーがバックアップを実行するゾーンを指定するために使用されます。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ             | String  |
| デフォルト値              | 空文字列   |
| OBServerノードの再起動が必要か | 不要です    |
