# enable_syslog_recycle

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_syslog_recycle`は、OBServerノード起動前の古いログファイルを有効化するかどうかを設定します。`max_syslog_file_count`と組み合わせて使用し、回収ロジックが古いログファイルを対象とするかどうかを決定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**      |                                                 **説明**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| パラメータタイプ             | BOOL                |
| デフォルト値              | False               |
| 値の範囲             | <ul><li>True：有効  </li><li>False：無効 </li></ul>     |
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

この機能が有効になるには、<code>max_syslog_file_count</code>構成パラメータの値が0以外の正の数に設定されている必要があります。<code>max_syslog_file_count</code>構成パラメータの詳細については、<a href="13300.max_syslog_file_count.md">max_syslog_file_count</a>を参照してください。

## 設定例

OBServerノード起動前の古いログファイルを有効化します。

```shell
obclient> ALTER SYSTEM SET enable_syslog_recycle=True;
```
