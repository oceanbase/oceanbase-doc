# trace_log_sampling_interval

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では対応するロジックが変更されたため、この機能は使用されなくなりました。この構成パラメータはV4.2.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`trace_log_sampling_interval`は、Trace Logログ情報を定期的に出力する時間間隔を設定します。

## プロパティの説明

|   **プロパティ**   |   **説明** |
|--------------|------------|
| パラメータタイプ      | Time       |
| デフォルト値        | 10ms       |
| 値の範囲      | [0ms, +∞) |
| 変更は可能か    | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。          |

## 使用方法

[enable_record_trace_log](../300.cluster-level-configuration-items/7900.enable_record_trace_log.md)がFalseに設定されている場合、`trace_log_sampling_interval`によって低速クエリとホワイトリスト情報を出力する時間間隔が決定されます。

## 設定例

Trace Logログ情報を定期的に出力する時間間隔を10msに設定します。

```shell
obclient> ALTER SYSTEM SET trace_log_sampling_interval='10ms';
```
