# clog_cache_priority

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではアーキテクチャが変更・アップグレードされたため、トランザクションログはキャッシュを使用しなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`clog_cache_priority`は、トランザクションログがキャッシュを占有する優先順位を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値               | 1        |
| 値の範囲             | \[1, +∞) |
| OBServerノードの再起動が必要か | 不要です    |
