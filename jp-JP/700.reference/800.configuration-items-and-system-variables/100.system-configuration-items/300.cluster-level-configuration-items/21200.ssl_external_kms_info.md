# ssl_external_kms_info

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`ssl_external_kms_info`構成パラメータは、OceanBaseデータベースのSSL機能の実行に依存する情報を記録するために使用されます。JSON文字列形式で、異なるSSL使用方法における依存関係の設定を記録します。JSONには少なくとも`ssl_mode`フィールドが含まれている必要があります。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | String  |
| デフォルト値               | ""、空の文字列を表す |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

* この構成パラメータのデフォルト値は空の文字列です。SSLスイッチがオンになっている場合、SSL使用キーはデフォルトパスのデフォルトファイルから取得されます。

* この構成パラメータの値は有効なJSONでなければなりません。そうでない場合、構成パラメータの設定チェックに失敗します。

* 現在、この構成パラメータは`ssl_mode`を指定するために、fileとbkmiの2つの値のみをサポートしています。

  * fileと指定した場合、ローカルのデフォルトパスからSSL秘密鍵と証明書ファイルを読み取り、追加のJSONフィールドの設定は不要です。

  * bkmiと指定した場合、実行時にbkmiからSSLファイルを取得し、ローカルに永続的に保存しません。同時に、JSON文字列には完全なアプリケーション名、bkmi URL、bkmiルート証明書、アイデンティティ秘密鍵、アイデンティティ秘密鍵のパスワード、SSL秘密鍵の名前、SSL秘密鍵のバージョン番号、SSL証明書の名前などを提供する必要があります。これらの情報は有効で利用可能である必要があります。つまり、これらの情報を使用してbkmiから秘密鍵と証明書を取得できない場合、応答エラーコードが返されます。

  他の外部の証明書発行システムをサポートするために、`ssl_external_kms_info`は他の内容のJSON文字列にカスタマイズして拡張することもできます。

## 設定例

SSL証明書の設定をfileモードに設定します。

```shell
obclient> ALTER SYSTEM SET ssl_external_kms_info = '
          {
          "ssl_mode":"file"
          }';
```
