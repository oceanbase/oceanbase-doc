# backup_recovery_window

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系では物理バックアップ・リカバリ機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、構成パラメータによるバックアップデータの復元可能時間帯の設定はサポートされなくなりました。システムテナントおよびユーザーテナントは、SQL文<a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/1600.delete-backup.md">ALTER SYSTEM ADD DELETE BACKUP POLICY</a>の<code>RECOVERY_WINDOW</code>オプションを使用して設定できます。</li></ul>
</main>

## 機能の概要

`backup_recovery_window`は、バックアップデータを復元できる時間を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Time    |
| デフォルト値               | 0、自動クリーンアップを行わないことを示す        |
| 値の範囲             | \[0, +∞) |
| OBServerノードの再起動が必要か | 不要です        |
