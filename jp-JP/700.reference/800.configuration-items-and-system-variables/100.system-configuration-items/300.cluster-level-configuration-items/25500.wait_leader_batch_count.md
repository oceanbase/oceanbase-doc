# wait_leader_batch_count

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系が単一ログストリームアーキテクチャにアップグレードされ、リーダー切り替えが単一のログストリームによって制御されるようになったため、この構成パラメータは適用されなくなりました。V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`wait_leader_batch_count`は、RootServiceが一度に送信するリーダー切り替えコマンドの最大パーティション数を設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**     |
|------------------|---------------|
| パラメータタイプ             | Int            |
| デフォルト値              | 1024          |
| 値の範囲             | \[128, 5000\] |
| OBServerノードの再起動が必要か | 不要です         |
