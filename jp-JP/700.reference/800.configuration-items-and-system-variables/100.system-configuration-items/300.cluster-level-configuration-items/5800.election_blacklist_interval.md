# election_blacklist_interval

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではシステムアーキテクチャが最適化されたため、選挙におけるブラックリストは時間ではなくイベントに依存するようになりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`election_blacklist_interval`は、リーダーレプリカがその役割を解除された後、再びリーダーに選出されることを禁止する期間を設定します。

## プロパティの説明

|        プロパティ        |     説明      |
|------------------|-------------|
| パラメータタイプ                      | Time        |
| デフォルト値              | 1800s       |
| 値の範囲             | \[0s, 24h\] |
| OBServerノードの再起動が必要か | 不要です         |
