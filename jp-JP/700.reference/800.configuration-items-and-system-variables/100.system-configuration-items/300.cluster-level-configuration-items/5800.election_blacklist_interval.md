# election_blacklist_interval

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でシステムアーキテクチャが最適化されたことにより、選出のブラックリストは時間ではなくイベントに依存するようになりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`election_blacklist_interval`は、プライマリレプリカが廃棄された後、再度プライマリとして選出されることを許可しない時間間隔を設定します。

## プロパティの説明

|        プロパティ        |     説明      |
|------------------|-------------|
| パラメータタイプ                      | Time        |
| デフォルト値              | 1800s       |
| 値の範囲             | \[0s, 24h\] |
| OBServerノードの再起動が必要か | 不要です         |
