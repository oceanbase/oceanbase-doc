# sys_bkgd_io_high_percentage

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でテナントのI/O分離が実装されたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`sys_bkgd_io_high_percentage`は、システムのバックグラウンドI/Oの最大占有率を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 90           |
| 値の範囲             | \[1, 100\] |
| OBServerノードの再起動が必要か | 不要です        |

## 関連情報

テナントリソース分離の詳細については、[リソース分離の概要](../../../../600.manage/200.tenant-management/600.common-tenant-operations/300.resource-isolation/100.resource-isolation-overview.md)を参照してください。
