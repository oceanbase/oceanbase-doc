# data_storage_warning_tolerance_time

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`data_storage_warning_tolerance_time`は、データディスクの状態を`WARNING`に設定するまでの猶予時間を制御します。

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|        プロパティ        |      説明       |
|------------------|---------------|
| パラメータタイプ             | Time          |
| デフォルト値               | 5s<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.0.0バージョン以降、デフォルト値が30秒から5秒に調整されました。</p></main>           |
| 値の範囲             | [1s, 300s]<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.0.0バージョン以降、値の範囲が[10s、300s]から[1s、300s]に調整されました。</p></main> |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。    |

## 使用方法

予期しないI/O失敗が発生した場合、OceanBaseデータベースのI/Oマネージャーは検出スレッドを通じてデータディスクの状態を検出しようとします。この構成パラメータで指定された時間を超えても、検出スレッドがそのマシンのデータディスクの状態が正常に戻っていないことを判別した場合、データディスクの状態を`WARNING`に設定します。この状態はリーダー切り替えなどのイベントをトリガーし、業務リクエストへの正常なサービス提供を継続します。

## 設定例

データディスクの状態を`WARNING`に設定するまでの猶予時間を20秒に設定します。

```shell
obclient> ALTER SYSTEM SET data_storage_warning_tolerance_time = 20s;
```
