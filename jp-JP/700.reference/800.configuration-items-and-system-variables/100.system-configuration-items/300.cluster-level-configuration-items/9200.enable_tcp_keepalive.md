# enable_tcp_keepalive

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_tcp_keepalive`は、クライアント接続の生存確認メカニズムを有効または無効にするために使用します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**    |   **説明**   |
|------------------|--------------|
| パラメータタイプ             | Bool                |
| デフォルト値               | True                |
| 値の範囲             | <ul><li>True：有効</li> <li>False：無効</li></ul>     |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

クライアント接続の生存確認メカニズムは、クライアントの稼働状態をチェックするために使用できます。クライアントが異常終了した場合、システムはサーバー側のリソースを解放できます。さらに、ロードバランシング装置やゲートウェイなどのネットワーク機器は、通過する接続を維持し、接続の状態をチェックします。接続が長時間`Idle`状態にあることを検出すると、切断またはリリースされ、これによりアプリケーションのクライアントとサーバー間の接続が異常に切断されることがあります。クライアント接続の生存確認メカニズムは、このようなネットワーク機器によって引き起こされる接続の異常切断を回避することができます。

## 設定例

クライアント接続の生存確認メカニズムを有効に設定します。

```shell
obclient> ALTER SYSTEM SET enable_tcp_keepalive = True;
```
