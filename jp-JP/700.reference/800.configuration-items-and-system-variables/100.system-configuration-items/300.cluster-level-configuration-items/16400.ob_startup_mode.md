# ob_startup_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_startup_mode`はOBServerノードの起動モードを設定します。初回起動時にのみ変更が可能です。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  クラスタの初回起動時にのみ変更が可能です。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ | String |
| デフォルト値 | NORMAL |
| 値の範囲 |<ul><li>`NORMAL`：シェアードナッシング（Shared-Nothing、SN）モードで起動することを示します。 </li><li>`ARBITRATION`：アービトレーションモードで起動することを示します。 </li><li>`SHARED_STORAGE`：シェアードストレージ（Shared-Storage、SS）モードで起動することを示します。 </li></ul><main id="notice" type='explain'><h4>説明</h4><p>`SHARED_STORAGE`値はV4.3.4バージョンから導入されました。</p></main>|
| 変更は可能か | 不可です。`ALTER SYSTEM SET`ステートメントを使用した変更はサポートされません。|
| OBServerノードの再起動が必要か | 不要です。読み取り専用モードのみサポートされます。 |
