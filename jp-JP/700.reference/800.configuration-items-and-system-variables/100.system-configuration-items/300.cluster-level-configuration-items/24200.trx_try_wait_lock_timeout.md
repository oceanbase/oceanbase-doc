# trx_try_wait_lock_timeout

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>機能の調整により、この構成パラメータはV3.1.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`trx_try_wait_lock_timeout`は、ステートメント実行プロセスにおける行ロックの待機時間を設定します。

## プロパティの説明

|      **プロパティ**      |     **説明**     |
|------------------|----------------|
| パラメータタイプ             | Time           |
| デフォルト値               | 0ms            |
| 値の範囲             | [0ms, 100ms] |
| OBServerノードの再起動が必要か | 不要です           |
