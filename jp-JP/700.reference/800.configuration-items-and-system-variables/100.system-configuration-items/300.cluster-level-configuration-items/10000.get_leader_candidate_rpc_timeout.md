# get_leader_candidate_rpc_timeout

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`get_leader_candidate_rpc_timeout`は、自動リーダー切り替えポリシーにおけるリーダー候補者取得のための内部リクエストのタイムアウト時間を設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Time        |
| デフォルト値              | 9s           |
| 値の範囲             | \[2s, 180s\] |
| OBServerノードの再起動が必要か | 不要です          |
