# clog_expire_days

<main id="notice" type='explain'>
<h4>説明</h4>
<p>4.x系でアーキテクチャが変更・アップグレードされたことにより、この構成パラメータは適用されなくなりました。V4.0.0以降のバージョンから削除され、代替案もありません。</p>
</main>

## 機能の概要

`clog_expire_days`は、clogファイルの有効期限を制御します。clogファイルの最終更新時間から現在時刻までの期間が有効期限を超えると、そのファイルは削除されます。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Time      |
| デフォルト値               | 3、単位は日です。    |
| 値の範囲             | [1, 365] |
| 変更は可能か           | 不可 |
| OBServerノードの再起動が必要か | 不要です          |

## 使用方法

この構成パラメータは`clog_disk_usage_limit_percentage`構成パラメータと共同で動作しますが、優先順位は`clog_disk_usage_limit_percentage`より低いため、clogが占有するディスク使用率が80％を超えても、clogファイルの最終更新時間から現在時刻までの期間が`clog_expire_days`構成パラメータで設定された時間未満の場合、clogファイルは削除されます。
