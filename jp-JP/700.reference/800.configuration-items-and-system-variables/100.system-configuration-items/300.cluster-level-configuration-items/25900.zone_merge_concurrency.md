# zone_merge_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではゾーン単位でのメジャーコンパクションをサポートしなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`zone_merge_concurrency`は、メジャーコンパクション時に並行して処理できるゾーン数を設定します。値が0の場合、システムがデプロイメント状況に基づいて最適な並列度を自動的に選択します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int      |
| デフォルト値              | 1        |
| 値の範囲             | \[0, +∞) |
| OBServerノードの再起動が必要か | 不要です    |
