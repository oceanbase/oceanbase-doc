# enable_global_background_resource_isolation

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このパラメータはV4.3.2バージョンから導入されました。</li><li>V4.2.x系では、このパラメータはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`enable_global_background_resource_isolation`は、グローバルなフォアグラウンドとバックグラウンドのリソース分離機能を有効にするために使用します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。`sys`テナントは`information_schemaарамЕТРы`ビューを使用してこのパラメータを確認することもできます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | Bool |
| デフォルト値     | false |
| 値の範囲   |[true, false]<ul><li>true：バックグラウンドタスクはテナントの上位で単独で隔離されます。</li><li>false：バックグラウンドタスクとフォアグラウンドタスクはテナント内で隔離されます。</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | はい。変更が複数のOBServerノードに関わる場合、すべてのOBServerノードを再起動する必要があります。 |

## 設定例

テナント内でバックグラウンドとフォアグラウンドのタスクを分離します。

```shell
obclient> ALTER SYSTEM SET enable_global_background_resource_isolation=false;
```
