# user_iort_up_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>IOスケジューリングのアルゴリズムが調整されたことにより、対応する機能は使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`user_iort_up_percentage`はユーザーディスクI/O遅延のしきい値を設定します。ユーザーディスクI/O遅延がこのしきい値を超えると、システムのバックグラウンドI/Oタスクが制限されます。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | 整数型       |
| デフォルト値              | 100      |
| 値の範囲             | \[0, +∞) |
| OBServerノードの再起動が必要か | 不要です      |
