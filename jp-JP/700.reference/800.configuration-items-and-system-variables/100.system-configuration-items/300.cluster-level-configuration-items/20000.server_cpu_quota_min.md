# server_cpu_quota_min

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`server_cpu_quota_min`は、システムが使用できる最小CPUクォータを設定します。システムは自動的に予約します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## 使用方法

値が0の場合、サーバーの`cpu_count`のサイズに応じて適応的に調整されます：

1. `cpu_count` < 8cの場合、`server_cpu_quota_min`は1cに適応的に調整されます。
2. 8c ≤ `cpu_count` < 16cの場合、`server_cpu_quota_min`は2cに適応的に調整されます。
3. 16c ≤ `cpu_count` < 32cの場合、`server_cpu_quota_min`は3cに適応的に調整されます。
4. 32c ≤ `cpu_count`の場合、`server_cpu_quota_min`は4cに適応的に調整されます。

## 設定例

システムが最大CPUクォータを適応的に調整するように設定します。

```shell
obclient> ALTER SYSTEM SET server_cpu_quota_max=0;
```
