# row_purge_thread_count

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータに対応する機能は一度も有効になったことがないため、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`row_purge_thread_count`は、メモリ内の行データマージを実行するワーカースレッドの最大数を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Int        |
| デフォルト値              | 4           |
| 値の範囲             | \[1, 64\] |
| OBServerノードの再起動が必要か | 不要です       |
