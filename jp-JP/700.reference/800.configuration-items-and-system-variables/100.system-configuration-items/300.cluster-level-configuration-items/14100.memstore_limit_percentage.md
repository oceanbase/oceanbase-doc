# memstore_limit_percentage

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`memstore_limit_percentage`は、テナントがMemStoreを使用するメモリが、利用可能な総メモリに占める割合を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**    |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | INT        |
| デフォルト値               | 0、適応的調整を行うことを示します。<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.2.3バージョン以降、デフォルト値が50から0に変更されました。</p></main> |
| 値の範囲             | [0, 100) <main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.3.0バージョン以降、(0, 100)から[0, 100)に変更されました。</p></main>|
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。        |

## 使用方法

* `memstore_limit_percentage`構成パラメータは`memstore_limit`の値を計算するために使用され、計算式は次のとおりです：

  `memstore_limit_percentage` = `memstore_limit` / `memory_size`

  ここで`memory_size`はテナント作成時に指定された値であり、テナントが使用できるメモリを表します。`memstore_limit`の詳細については、[memory_limit](13800.memory_limit.md)を参照してください。

* V4.3.xバージョンでは、V4.3.0バージョンから、テナントレベルの非表示構成パラメータ<code>_memstore_limit_percentage</code>を使用して、テナントのMemStoreがテナントの総メモリに占める割合を設定することもサポートされています。有効範囲が異なる以外は、その機能とデフォルト値はクラスタレベルの構成パラメータ<code>memstore_limit_percentage</code>と同じです。これら2つの構成パラメータを設定する際には、以下の点に注意する必要があります：

  <ul><li><code>_memstore_limit_percentage</code>または<code>memstore_limit_percentage</code>のいずれか一方の値（デフォルト値以外）のみを設定した場合、設定した値（デフォルト値以外）が優先されます。</li> <li>テナントレベルの非表示構成パラメータ<code>_memstore_limit_percentage</code>（デフォルト値以外）とクラスタレベルの構成パラメータ<code>memstore_limit_percentage</code>（デフォルト値以外）の両方の値を同時に設定した場合、<code>_memstore_limit_percentage</code>で設定した値が優先されます。</li> <li>どちらも設定されていない場合、または両方ともデフォルト値に設定されている場合、システムは以下の適応型ポリシーを採用します：<ul><li>メモリが8GB（実際のメモリ）以下のテナントの場合、テナントMemstoreの設定比率は40%です。</li><li>メモリが8GBを超えるテナントの場合、テナントMemstoreの設定比率は50%です。</li></ul></li></ul>

## 設定例

クラスタ内の各テナントがMemStoreを使用するメモリが、利用可能な総メモリの60%に設定されます。

```shell
obclient> ALTER SYSTEM SET memstore_limit_percentage = 60;
```
