# stack_size

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`stack_size`は、プログラム関数呼び出しスタックのサイズを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Capacity        |
| デフォルト値               | 512K、デフォルト単位はMBです。設定時に単位を指定する必要があります。<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.0.0バージョン以降、デフォルト値が1MBから512KBに調整されました。</p></main>            |
| 値の範囲             | [512K, 20M] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | はい。変更を有効にするには、OBServerノードを再起動する必要があります。 |

## 設定例

プログラム関数呼び出しスタックのサイズを512KBに設定します。

```shell
obclient> ALTER SYSTEM SET stack_size = '512K';
```
