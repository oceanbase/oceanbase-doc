# ofs_list

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系では対応する機能が廃止されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ofs_list`は、各ゾーンのOFS(OceanBase File System、OceanBaseデータベース独自設計の分散ストレージシステム)接続URLを保存しており、主にOFSデプロイモードでRootServiceがゾーン間でファイルにアクセスする際に使用されます。

## プロパティの説明

|        プロパティ        |            説明            |
|------------------|--------------------------|
| パラメータタイプ             | String                    |
| デフォルト値              | デプロイ時のOFSリスト              |
| 値の範囲             | 構文：`[zone]@[ofs_url];` |
| OBServerノードの再起動が必要か | 不要です                        |
