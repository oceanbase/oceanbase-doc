# all_cluster_list

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V2.x系でクラスタ設定が最適化されたことにより、この構成パラメータはV2.2.50以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`all_cluster_list`は、同じ`config_url`にアクセスするサーバーリストを表示するために使用されます。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ             | String    |
| デフォルト値               | NULL値     |
| 値の範囲             | NULL   |
| OBServerノードの再起動が必要か | 不要です    |
