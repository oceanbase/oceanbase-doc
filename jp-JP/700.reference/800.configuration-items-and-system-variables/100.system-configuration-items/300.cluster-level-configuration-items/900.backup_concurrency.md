# backup_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>現在のバージョンでは、タスクの優先順位と重要度に基づき、高可用性に関連する以下の3つの構成パラメータに分かれており、各パラメータは異なるタスクタイプに対応しています：
<ul><li><code>ha_high_thread_score</code> ：レプリケーション、Rebuild、復元などの高可用性・高優先順位スレッドのワーカースレッド数を制御します。テナントレベル構成パラメータ <code>ha_high_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3400.ha_high_thread_score.md">ha_high_thread_score</a> を参照してください。</li>
<li><code>ha_mid_thread_score</code> ：移行タスクなどの高可用性・中優先順位スレッドのワーカースレッド数を制御します。テナントレベル構成パラメータ <code>ha_mid_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3600.ha_mid_thread_score.md">ha_mid_thread_score</a> を参照してください。</li>
<li><code>ha_low_thread_score</code> ：バックアップ、バックアップクリーンアップなどの高可用性・低優先順位スレッドのワーカースレッド数を制御します。テナントレベル構成パラメータ <code>ha_low_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3500.ha_low_thread_score.md">ha_low_thread_score</a> を参照してください。</li></ul>
</li></ul>
</main>

`backup_concurrency`は、バックアップ時のファイルシステムへの同時書き込み数を設定します。

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 0          |
| 値の範囲             | \[0, 100\] |
| OBServerノードの再起動が必要か | 不要です        |
