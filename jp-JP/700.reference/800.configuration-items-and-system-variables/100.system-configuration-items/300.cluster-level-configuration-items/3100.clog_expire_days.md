# clog_expire_days

<main id="notice" type='explain'>
<h4>説明</h4>
<p>4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなりました。V4.0.0以降のバージョンから削除され、代替案もありません。</p>
</main>

## 機能の概要

`clog_expire_days`は、Clogファイルの有効期限を制御します。Clogファイルの最終変更時刻が現在時刻から有効期限を超えた場合、そのファイルは削除されます。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | TIME       |
| デフォルト値              | 3、単位は日です。    |
| 値の範囲             | [1, 365] |
| 変更は可能か           | 不可 |
| OBServerノードの再起動が必要か | 不要です        |

## 使用方法

この構成パラメータは `clog_disk_usage_limit_percentage`と連携して動作しますが、優先順位は `clog_disk_usage_limit_percentage`より低いです。つまり、Clogが占用するディスクのウォーターマークが80%を超えても、Clogファイルの最終変更時刻が現在時刻から `clog_expire_days`で設定された時間より短い場合、Clogファイルは削除されます。
