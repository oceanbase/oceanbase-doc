# index_cache_priority

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`index_cache_priority`は、インデックスのキャッシュシステム内での優先順位を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**  |
|------------------|----------|
| パラメータタイプ             | Int       |
| デフォルト値              | 10       |
| 値の範囲             | \[1, +∞) |
| OBServerノードの再起動が必要か | 不要です      |
