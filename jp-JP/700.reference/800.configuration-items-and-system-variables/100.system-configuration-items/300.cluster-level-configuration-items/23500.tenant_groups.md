# tenant_groups

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではテナントグループ機能がサポートされなくなったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`tenant_groups`は、ロードバランシングポリシーで使用するテナントグループを設定します。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ                      | String  |
| デフォルト値              | NULL値     |
| OBServerノードの再起動が必要か | 不要です    |
