# cpu_count

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`cpu_count`は、システムのCPU総数を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|  **プロパティ**      |     **説明**        |
|------------------|------------------|
| パラメータタイプ             | Int                                                                                  |
| デフォルト値               | 0。システムがCPU数を自動的に検出します。 |
| 値の範囲             | [0, +∞)                                                                            |
| 変更は可能か          | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

クラスタ内の他の構成によって、この構成パラメータの有効化方法に影響を与える可能性があります。この構成パラメータを設定した後、`SELECT`ステートメントを使用して、[GV$OB_SERVERS](../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/2700.gv-ob_servers-of-sys-tenant.md)内部テーブル内の`CPU_CAPACITY`フィールドに実際に有効な値を確認することを推奨します。動的に有効にならない場合は、クラスタ全体を再起動する必要があります。

## 設定例

システムのCPU総数を16に設定します。

```shell
obclient> ALTER SYSTEM SET cpu_count=16;
```
