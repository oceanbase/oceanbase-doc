# backup_dest_option

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、この構成パラメータに含まれていた各項目の仕様や設定方法は、以下のように変更されました：
<ul><li>ログアーカイブの遅延時間間隔は、テナントレベルの構成パラメータ <a href="../400.tenant-level-configuration-items/200.archive_lag_target.md">archive_lag_target</a> で設定できます。</li>
<li>構成パラメータによるバックアップデータの復元可能時間窓の設定は、サポートされなくなりました。システムテナントおよびユーザーテナントは、SQLステートメント<a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/1270.delete-backup.md">ALTER SYSTEM ADD DELETE BACKUP POLICY</a> の <code>RECOVERY_WINDOW</code>オプションを使用して設定できます。</li>
<li>バックアップの自動および手動クリーンアップ機能がサポートされています。バックアップクリーンアップに関する操作については、<a href="../../../../600.manage/600.backup-and-recovery/500.clear-backup-data/50.automatic-backup-cleanup/100.cleaning-up-backed-up-data-automatically.md">バックアップデータのクリーンアップ</a>の章を参照してください。</li>
<li>Pieceの切り替え周期は、SQLステートメント<a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/3800.set-log-archive-dest.md">ALTER SYSTEM SET LOG_ARCHIVE_DEST</a>で設定できます。</li>
<li>バックアップデータのバックアップ(2次バックアップ)機能はサポートされなくなったため、バックアップセットの冗長度の指定もサポートされなくなりました。</li></ul>
</li></ul>
</main>

## 機能の概要

`backup_dest_option`は、バックアップに関するパラメータを制御します。

## プロパティの説明

|        プロパティ        |  説明   |
|------------------|-------|
| パラメータタイプ             | String |
| デフォルト値              | 空文字列  |
| OBServerノードの再起動が必要か | 不要です   |
