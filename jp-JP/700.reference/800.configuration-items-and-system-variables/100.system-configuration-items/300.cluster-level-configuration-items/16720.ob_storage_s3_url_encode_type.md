# ob_storage_s3_url_encode_type

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.2.1バージョンでは、この構成パラメータはV4.2.1 BP9バージョンから導入されました。V4.2.xの他のバージョンでは、この構成パラメータはV4.2.5バージョンから導入されました。</li>
<li>V4.3.xバージョンでは、この構成パラメータはV4.3.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`ob_storage_s3_url_encode_type`は、S3へのリクエスト送信時のURLエンコーディング方式がRFC3986規格と互換性があるかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントは変更できません。

## プロパティの説明

| **プロパティ** | **説明**    |
|-----------|------------|
| パラメータタイプ | String |
| デフォルト値   | default |
| 値の範囲 | <ul><li>compliantRfc3986Encoding</li> <li>default</li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

この構成パラメータは、一部のS3プロトコルに互換性がありますが、AWS S3 SDKのデフォルトのURLエンコーディング方式をサポートしていないオブジェクトストレージに適用されます。関連する操作と例については、[ログアーカイブの準備](../../../../600.manage/600.backup-and-recovery/300.log-archive/200.preparation-before-log-archive.md)を参照してください。

## 設定例

S3へのリクエスト送信時のURLエンコーディング方式をRFC3986規格と互換性があるように設定します。

```shell
obclient> ALTER SYSTEM SET ob_storage_s3_url_encode_type='compliantRfc3986Encoding';
```
