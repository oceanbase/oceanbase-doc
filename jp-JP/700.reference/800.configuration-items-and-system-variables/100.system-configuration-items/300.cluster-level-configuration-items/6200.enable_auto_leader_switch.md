# enable_auto_leader_switch

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではシステムアーキテクチャが最適化され、自動リーダー切り替えが単一ログストリームによって制御されるようになり、ロードバランシングが不要となったため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`enable_auto_leader_switch`は、自動リーダー切り替えを有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |                     **説明**                |
|------------------|---------------------------------------------------------|
| パラメータタイプ             | Bool                                                 |
| デフォルト値              | True                                                  |
| 値の範囲             | False：無効    |
| OBServerノードの再起動が必要か | 不要です                                               |
