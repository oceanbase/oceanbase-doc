# merge_thread_count

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースが限られているため、V4.x系では特定のタスクタイプごとにスレッドリソースを設定することはできなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、構成パラメータ <code>compaction_low_thread_score</code> を使用して低優先順位Compactionのワーカースレッド数を設定します。テナントレベルの構成パラメータ <code>compaction_low_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/1100.compaction_low_thread_score.md">compaction_low_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`merge_thread_count`は、日次マージ処理を実行するスレッド数を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値               | 0          |
| 値の範囲             | [0, 256] |
| OBServerノードの再起動が必要か | 不要です      |

## 使用方法

この構成パラメータの値が`0`の場合、マージを実行するワーカープロセス数は`min{10,cpu_cnt}`で計算されます。ここで、`cpu_cnt`はシステムのCPU数です。
