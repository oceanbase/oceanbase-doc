# tenant_cpu_variation_per_server

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V2.x系では対応するロジックが変更されたため、該当機能は使用されなくなりました。この構成パラメータはV2.2.77バージョンから削除されました。</p>
</main>

## 機能の概要

`tenant_cpu_variation_per_server`は、各OBServer上の任意のテナントにおけるCPUクォータ割り当ての変動率を設定します。

## プロパティの説明

|    プロパティ    |    説明     |
|------------|------------|
| パラメータタイプ    | Double     |
| デフォルト値      | 50         |
| 値の範囲    | [0, 100] |
| OBServerノードの再起動が必要か | 不要です       |

## 設定例

各OBServer上の任意のテナントにおけるCPUクォータ割り当ての変動率を50に設定します。

```shell
obclient> ALTER SYSTEM SET tenant_cpu_variation_per_server=50;
```
