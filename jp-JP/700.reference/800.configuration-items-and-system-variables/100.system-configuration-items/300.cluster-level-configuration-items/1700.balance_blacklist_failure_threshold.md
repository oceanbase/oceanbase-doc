# balance_blacklist_failure_threshold

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でストレージアーキテクチャがアップグレードされたことにより、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`balance_blacklist_failure_threshold`は、レプリカ移行などのバックグラウンドタスクの連続失敗回数のしきい値を設定します。レプリカ移行などのバックグラウンドタスクの連続失敗回数がこのしきい値を超えると、ブラックリストに追加されます。

## プロパティの説明

|      **プロパティ**      |   **説明**    |
|------------------|-------------|
| パラメータタイプ             | Int          |
| デフォルト値              | 5           |
| 値の範囲             | \[0, 1000\] |
| OBServerノードの再起動が必要か | 不要です         |
