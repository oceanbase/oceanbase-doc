# fast_recovery_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>スレッドリソースには限りがあるため、V4.x系では特定のタスクタイプごとにスレッドリソースを設定することはできなくなりました。この構成パラメータは、V4.0.0以降のバージョンから削除されています。</li>
<li>V4.x系では、構成パラメータ <code>ha_high_thread_score</code> を使用して、レプリケーション、Rebuild、復元などの高可用性・高優先順位スレッドのワーカースレッド数を制御できます。テナントレベル構成パラメータ <code>ha_high_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3400.ha_high_thread_score.md">ha_high_thread_score</a>を参照してください。</li></ul>
</main>

## 機能の概要

`fast_recovery_concurrency`は、RootServiceスケジューラーによってスケジュールされる高速復元タスクがOBServer上で実行される際の並列数を制御します。

## プロパティの説明

|        プロパティ        |     説明     |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値              | 10           |
| 値の範囲             | \[1,1000\] |
| OBServerノードの再起動が必要か | 不要です        |
