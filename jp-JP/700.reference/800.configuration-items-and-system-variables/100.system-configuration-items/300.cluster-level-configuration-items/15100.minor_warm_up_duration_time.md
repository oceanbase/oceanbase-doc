# minor_warm_up_duration_time

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V2.2.3xバージョン以降の使用は推奨されなくなり、V4.0.0バージョン以降は削除されました。</p>
</main>

## 機能の概要

`minor_warm_up_duration_time`は、ダンプによって生成された新しいダンプファイルのウォームアップ時間を設定します。

|      **プロパティ**      |   **説明**    |
|------------------|-------------|
| パラメータタイプ                      | Time       |
| デフォルト値              | 30s         |
| 値の範囲             | \[0s, 60m\] |
| OBServerノードの再起動が必要か | 不要です         |

## 使用方法

`minor_warm_up_duration_time`構成パラメータの値が0sの場合、ウォームアップは行われません。
