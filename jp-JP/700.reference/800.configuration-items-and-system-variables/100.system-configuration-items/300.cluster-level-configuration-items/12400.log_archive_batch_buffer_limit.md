# log_archive_batch_buffer_limit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系でのアーキテクチャ変更に伴い、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

物理バックアップが有効な場合、`log_archive_batch_buffer_limit`はログアーカイブの単一マシンにおける最大メモリ使用量を制御します。

## プロパティの説明

|        プロパティ        |    説明     |
|------------------|-----------|
| パラメータタイプ             | Capacity      |
| デフォルト値              | 1G        |
| 値の範囲             | \[2M, +∞) |
| OBServerノードの再起動が必要か | 不要です       |

## 設定例

```shell
obclient> ALTER SYSTEM SET log_archive_batch_buffer_limit = 1GB;
```
