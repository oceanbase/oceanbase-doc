# recyclebin_object_expire_time

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`recyclebin_object_expire_time`は、ごみ箱内の期限切れになったスキーマオブジェクトを自動的にクリーンアップするために使用します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Time      |
| デフォルト値               | 0秒、自動Purgeショッピングカート機能を無効にすることを示します。        |
| 値の範囲             | [0s, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 使用方法

値が0秒以外の場合、一定期間前にごみ箱に移動したスキーマオブジェクトを回収することを意味します。

## 設定例

* ゴミ箱の自動クリーンアップ機能を無効にします。

  ```shell
  obclient> ALTER SYSTEM SET recyclebin_object_expire_time = "0s";
  ```

* ゴミ箱の自動クリーンアップ機能を有効にし、7日前にごみ箱に移動したスキーマオブジェクトを回収します。

  ```shell
  obclient> ALTER SYSTEM SET recyclebin_object_expire_time = "7d";
  ```
