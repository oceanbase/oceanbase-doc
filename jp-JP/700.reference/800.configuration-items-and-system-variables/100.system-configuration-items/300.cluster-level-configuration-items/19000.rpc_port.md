# rpc_port

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`rpc_port`は、リモートアクセスのプロトコルポート番号を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  **この構成パラメータは、クラスタのデプロイ時にのみ設定できます。クラスタが有効になった後は、変更することはできません。**

## プロパティの説明

|      **プロパティ**      |     **説明**      |
|------------------|-----------------|
| パラメータタイプ             | Int              |
| デフォルト値               | 2882  <main id="notice" type='explain'><h4>説明</h4><p>V3.2.4バージョン以降、デフォルト値は2500から2882に調整されました。</p></main>          |
| 値の範囲             | [1025, 65535] |
| 変更は可能か                | 不可。`ALTER SYSTEM SET`ステートメントによる変更はサポートされていません。  |
| OBServerノードの再起動が必要か | 不要です。読み取り専用でのみサポートされます。               |
