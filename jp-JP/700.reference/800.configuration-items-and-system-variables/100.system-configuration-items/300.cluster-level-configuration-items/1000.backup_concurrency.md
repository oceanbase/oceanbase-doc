# backup_concurrency

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系では物理バックアップ・リカバリ機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>

<li><code>ha_low_thread_score</code> : バックアップ、バックアップクリーンアップなどの高可用性・低優先順位スレッドのワーカースレッド数を制御します。テナントレベルの構成パラメータ <code>ha_low_thread_score</code> の詳細については、<a href="../400.tenant-level-configuration-items/3600.ha_low_thread_score.md">ha_low_thread_score</a> を参照してください。</li></ul>

## 機能の概要

`backup_concurrency`は、バックアップ時のファイルシステムへの書き込み並列数を設定します。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|------------------|------------|
| パラメータタイプ             | Int         |
| デフォルト値               | 0          |
| 値の範囲             | \[0, 100\] |
| OBServerノードの再起動が必要か | 不要です       |
