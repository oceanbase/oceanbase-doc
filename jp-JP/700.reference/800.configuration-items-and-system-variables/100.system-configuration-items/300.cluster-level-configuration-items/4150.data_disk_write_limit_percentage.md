# data_disk_write_limit_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このパラメータはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このパラメータはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`data_disk_write_limit_percentage`は、データディスクの書き込み制限の割合を設定します。データディスクの使用量が設定された制限割合に近づくと、システムは業務リクエストの書き込み操作を制限し、データディスクの空き容量が枯渇するのを防ぎます。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  この構成パラメータは`sys`テナントのみが変更でき、ユーザーテナントでは変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | Int |
| デフォルト値     | 0、無効を表します。 |
| 値の範囲   |[0, 100)|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

* この構成パラメータは、データディスクが満杯になった場合に書き込みを停止し、問題を早期に発見するために使用されます。問題が発見された場合は、テーブルを削除することで緊急に容量を解放できます。そうしないと、クラスタの復旧が困難になる可能性があります。

* **設定時の値は、[data_disk_usage_limit_percentage](4100.data_disk_usage_limit_percentage.md)以上である必要があります。**

* **この構成パラメータの推奨値は、(1 - memstore_limit_size/data_disk_size) * 100%**です。ここで、

  * memstore_limit_size：`テナント memory_size * memstore_limit_percentage`を表します。
  * data_disk_size：ユーザーが設定したデータディスクのサイズを表します。

## 設定例

データディスクの書き込み制限割合を90に設定します。

```shell
obclient> ALTER SYSTEM SET data_disk_write_limit_percentage=90;
```
