# partition_table_check_interval

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系ではパーティションレプリカの概念が廃止されたため、この構成パラメータは適用されなくなり、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`partition_table_check_interval`は、OBServerがパーティションテーブルから存在しないレプリカを削除する時間間隔を設定します。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Time         |
| デフォルト値              | 30m、30分を意味します |
| 値の範囲             | \[1m, +∞)    |
| OBServerノードの再起動が必要か | 不要です          |
