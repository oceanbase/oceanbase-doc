# enable_log_archive

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系では物理バックアップ・リストア機能のアーキテクチャが最適化されたため、この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、システムテナントおよびすべてのユーザーテナントはSQLステートメント<a href="../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/200.archivelog.md">ALTER SYSTEM ARCHIVELOG</a>を使用してアーカイブモードを有効にできます。アーカイブモードの詳細な操作手順については、<a href="../../../../600.manage/600.backup-and-recovery/300.log-archive/300.open-the-log-archive-mode.md">アーカイブモードの開始</a>を参照してください。</li></ul>
</main>

## 機能の概要

`enable_log_archive`は、ログアーカイブ機能を有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      |             **説明**               |
|------------------|-------------------------------------|
| パラメータタイプ             | Bool                              |
| デフォルト値              | False                              |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul>     |
| OBServerノードの再起動が必要か | 不要です                             |
