# max_kept_major_version_number

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、古いベースラインバージョンを保持し、追加のストレージ容量を消費するため、ユーザー全体の利用率が低いことから、V4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`max_kept_major_version_number`は、データ保持の凍結バージョン数を設定します。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ             | Int        |
| デフォルト値              | 2         |
| 値の範囲             | \[1, 16\] |
| OBServerノードの再起動が必要か | 不要です    |
