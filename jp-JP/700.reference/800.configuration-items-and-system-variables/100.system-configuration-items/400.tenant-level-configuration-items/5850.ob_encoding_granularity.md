# ob_encoding_granularity

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_encoding_granularity`は、単一マイクロブロックEncodingの行数の上限を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |    Int              |
| デフォルト値      |  65536  |
| 値の範囲    |  [8192, 1048576]              |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

AP業務において更新処理が少ない場合でも、マイクロブロックの行数が多すぎてskip indexによるフィルタリングの高速化が難しい場合や、マイクロブロックの再利用が困難でマージ処理のパフォーマンスが低下している場合に、このパラメータを適切に引き下げることでパフォーマンスを向上させることができます。

## 設定例

単一マイクロブロックEncodingの行数の上限を8192行に設定します。

```shell
obclient> ALTER SYSTEM SET ob_encoding_granularity=8192;
```
