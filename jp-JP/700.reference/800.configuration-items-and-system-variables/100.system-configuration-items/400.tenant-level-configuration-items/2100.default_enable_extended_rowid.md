# default_enable_extended_rowid

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`default_enable_extended_rowid`は、テーブルをExtended ROWIDモードで作成するかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Bool |
| デフォルト値               | False |
| 値の範囲             | <ul><li>True：新しいテーブルを作成する際に、Extended ROWID形式を使用し、Tablet IDの割り当て範囲は(2<sup>60</sup>, 2<sup>61</sup> - 1)となります。</li> <li>False：新しいテーブルを作成する際に、10バイト互換性のあるROWID形式を使用し、Tablet IDの割り当て範囲は(200000, 2<sup>37</sup> - 1)となります。</li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

テーブル作成時にExtended ROWIDモードを使用しないように設定します。

```shell
obclient> ALTER SYSTEM SET default_enable_extended_rowid= false;
```
