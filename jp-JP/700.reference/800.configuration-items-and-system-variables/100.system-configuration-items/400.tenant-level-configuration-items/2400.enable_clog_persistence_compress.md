# enable_clog_persistence_compress

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系でストレージアーキテクチャが変更されたことにより、V4.0.0バージョンでは現在ログストレージ圧縮機能をサポートしていません。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>ビジネスニーズに基づき、OceanBaseデータベースはV4.2.1バージョンから再びログストレージ圧縮機能をサポートしています。V4.2.1以降のバージョン（V4.3.0バージョンを除く）では、テナントレベルの構成パラメータ <code>log_storage_compress_all</code> を使用してログストレージ圧縮機能を有効にするかどうかを制御できます。</li></ul>
</main>

## 機能の概要

`enable_clog_persistence_compress`は、トランザクションログ永続化圧縮を有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ             | Bool                     |
| デフォルト値              | False  |
| 値の範囲             | </li><li> True   </li><li> False   |
| OBServerノードの再起動が必要か | 不要です    |
