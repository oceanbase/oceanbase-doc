# enable_clog_persistence_compress

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが変更されたため、V4.0.0以降ではログのストレージ圧縮機能をサポートしていません。この構成パラメータはV4.0.0以降から削除されました。</li>
<li>業務上のニーズに基づき、OceanBaseデータベースはV4.2.1バージョンから再びログのストレージ圧縮機能をサポートしています。V4.2.1以降のバージョン(V4.3.0を除く)では、テナントレベルの構成パラメータ<code>log_storage_compress_all</code>を使用して、ログのストレージ圧縮機能を有効にするかどうかを制御できます。<code>log_storage_compress_all</code>構成パラメータの詳細については、<a href="5100.log_storage_compress_all.md">log_storage_compress_all</a>を参照してください。</li></ul>
</main>

## 機能の概要

`enable_clog_persistence_compress`は、トランザクションログの永続化圧縮を有効にするかどうかを設定します。

## プロパティの説明

|      **プロパティ**      | **説明** |
|------------------|--------|
| パラメータタイプ             | Bool                     |
| デフォルト値              | false  |
| OBServerノードの再起動が必要か | 不要です   |
