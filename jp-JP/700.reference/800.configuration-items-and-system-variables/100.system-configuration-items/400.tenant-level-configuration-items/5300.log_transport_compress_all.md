# log_transport_compress_all

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

`log_transport_compress_all`は、ログ転送に圧縮を使用するかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Bool |
| デフォルト値               | False |
| 値の範囲             |<ul><li>False：ログ転送に圧縮を使用しないことを示します。</li><li>True：ログ転送に圧縮を使用することを示します。</li></ul>|
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

ログ転送に圧縮を使用しないように設定します。

```shell
obclient> ALTER SYSTEM SET log_transport_compress_all= False;
```
