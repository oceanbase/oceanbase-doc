# enable_user_defined_rewrite_rules

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_user_defined_rewrite_rules`は、リライトバインディング機能を有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Bool |
| デフォルト値               | False |
| 値の範囲             |<ul><li> True：有効 </li><li>False：無効 </li></ul>|
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

[DBMS_UDR](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/100.dbms-udr-overview-mysql.md)システムパッケージは、リライトバインディング機能を提供します：

* カスタムリライトルールの作成：[CREATE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/200.create-rule-mysql.md)
* カスタムリライトルールの無効化：[DISABLE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/300.disable-rule-mysql.md)
* カスタムリライトルールの有効化：[ENABLE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/400.enable-rule-mysql.md)
* カスタムリライトルールの削除：[REMOVE_RULE](../../../../700.reference/600.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/17800.dbms-udr-mysql/500.remove-rule-mysql.md)

## 設定例

リライトバインディング機能を無効に設定します。

```shell
obclient> ALTER SYSTEM SET enable_user_defined_rewrite_rules = False;
```
