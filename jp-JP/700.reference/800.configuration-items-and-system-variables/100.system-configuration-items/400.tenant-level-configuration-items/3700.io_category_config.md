# io_category_config

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では対応するロジックが変更されたため、この機能は使用されなくなりました。この構成パラメータはV4.2.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`io_category_config`は、各カテゴリのI/Oリクエストの割合を設定します。

## プロパティの説明

|      **プロパティ**      |       **説明**       |
|------------------|--------------------|
| パラメータタイプ             | String             |
| デフォルト値              | other: 100,100,100 |
| OBServerノードの再起動が必要か | 不要です            |

## 使用方法

カテゴリI/O仕様は、テナントのI/O仕様比率を表すもので、形式は`category_name: min_percent, max_percent, weight_percent`です。複数のカテゴリ仕様はセミコロンで区切られ、個別に指定されていないカテゴリは`other`で表されます。

すべてのカテゴリ（`other`を含む）の`min_percent`の合計は`100`、`weight_percent`の合計は`100`となります。

## 設定例

テナントの各カテゴリI/Oリクエストの割合を設定する例：

```shell
obclient> ALTER SYSTEM SET io_category_config = 'user: 30, 90, 50; log: 30, 90, 30; sys: 10, 10, 10; other: 30, 100, 10;';
```
