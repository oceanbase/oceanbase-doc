# enable_ps_meta_response_optimize

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.4.2 BP3で導入されました。</p>
</main>

## 機能の概要

`enable_ps_meta_response_optimize`は、PS（Prepared Statement）プロトコルにおいて、observerとクライアント間でメタデータ応答の最適化を有効にするかどうかを制御します。この構成パラメータを有効にすると、observerがメタデータキャッシュ機能を備えたob-jdbcと通信する際、PSステートメントが初めて実行されるときにのみ結果セットのメタデータを返します。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>テナント作成時、システムはこの構成パラメータをデフォルトでTrueに設定します。つまり、新規テナントはデフォルトでこの機能が有効になっています。</p>
</main>

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Bool |
| デフォルト値               | False |
| 値の範囲             |<ul><li>True：有効 </li><li> False：無効 </li></ul>|
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

* PSプロトコルのメタデータ応答の最適化を有効にします。

    ```shell
    obclient> ALTER SYSTEM SET enable_ps_meta_response_optimize = TRUE;
    ```

* PSプロトコルのメタデータ応答の最適化を無効にします。

    ```shell
    obclient> ALTER SYSTEM SET enable_ps_meta_response_optimize = FALSE;
    ```
