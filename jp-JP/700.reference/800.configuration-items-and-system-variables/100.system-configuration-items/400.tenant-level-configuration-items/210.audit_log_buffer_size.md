# audit_log_buffer_size

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

`audit_log_buffer_size`は、非同期ログ書き込み時のバッファサイズを制御します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在監査機能をサポートしていません。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | Capacity |
| デフォルト値     | 16M |
| 値の範囲   | [16M, 256M]|
| 変更は可能か | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

非同期方式で監査ログを書き込む場合、ワーカースレッドはバッファからメモリを確保し、I/Oキューに格納する必要があります。この構成パラメータはそのバッファのサイズを制御します。

## 設定例

非同期ログ書き込み時のバッファサイズを16MBに設定します。

```shell
obclient> ALTER SYSTEM SET audit_log_buffer_size='16M';
```
