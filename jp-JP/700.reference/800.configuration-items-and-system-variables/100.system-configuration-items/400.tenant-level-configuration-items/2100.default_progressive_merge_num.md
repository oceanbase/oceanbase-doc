# default_progressive_merge_num

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`default_progressive_merge_num`は、テーブル作成時のデフォルトのプログレッシブマージ回数を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Int       |
| デフォルト値               | 0       |
| 値の範囲             | [0, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

OceanBaseデータベースはテーブルデータのプログレッシブマージをサポートしています。これは、テーブルに対してデータ書き換えを必要とするDDL操作を実行した後、テーブルデータの書き換えを複数回のマージに分散し、1回のマージで部分的なデータのみを書き換えることができる機能です。テーブルレベルのプロパティ`progressive_merge_num`でマージ動作を制御することも、`default_progressive_merge_num`構成パラメータで新規テーブル作成時のデフォルトのプログレッシブマージ回数を設定することもできます。

新規テーブルに`progressive_merge_num`プロパティを指定しなかった場合、システムはテーブルレベルのプロパティ`progressive_merge_num`の値を`default_progressive_merge_num`の値に設定します。

`progressive_merge_num`プロパティの値の意味は以下のとおりです：

* progressive_merge_num = 0 の場合、デフォルト値の100を使用します。
* progressive_merge_num = 1 の場合、フルコンパクションのみを強制的に実行し、増分マージやプログレッシブマージは実行しません。
* progressive_merge_num = X の場合、X ラウンドのメジャーコンパクションで全データが書き換えられることを意味し、各ラウンドで 1/X のデータが書き換えられます。

## 設定例

新規テーブル作成時のプログレッシブコンパクション回数のデフォルト値を 100 に設定します。

```shell
obclient> ALTER SYSTEM SET default_progressive_merge_num = 0;
```
