# log_storage_compress_func

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このパラメータはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このパラメータはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`log_storage_compress_func`は、clogストレージ圧縮の圧縮アルゴリズムを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | ------- |
| パラメータタイプ | string |
| デフォルト値 | lz4_1.0 |
| 値の範囲 |<ul><li>lz4_1.0  </li><li>zstd_1.0 </li><li>zstd_1.3.8 </ li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

* sysテナント内の`tenant_name`テナントのclogストレージ圧縮アルゴリズムを`lz4_1.0`に設定します。

  ```shell
  obclient> ALTER SYSTEM SET log_storage_compress_func='lz4_1.0'  tenant = 'tenant_name';
  ```

* すべてのテナントのclogストレージ圧縮アルゴリズムを`lz4_1.0`に設定します。

  ```shell
  obclient> ALTER SYSTEM SET log_storage_compress_func='lz4_1.0' tenant=all;
  ```

* 現在のテナントのclogストレージ圧縮アルゴリズムを`lz4_1.0`に設定します。

  ```shell
  obclient> ALTER SYSTEM SET log_storage_compress_func='lz4_1.0';
  ```
