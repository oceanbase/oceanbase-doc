# major_freeze_duty_time

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>この構成パラメータは、V1.4バージョンから導入されました。</li>
<li>この構成パラメータは、V4.0.0バージョンから適用範囲がクラスタレベルからテナントレベルに調整されました。</li></ul>
</main>

## 機能の概要

`major_freeze_duty_time`は、日次定時凍結およびマージのトリガー時刻を設定します。

## 権限要件

* パラメータの確認

  sysテナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  sysテナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |      **説明**      |
|------------------|------------------|
| パラメータタイプ             | Moment                |
| デフォルト値              | 02:00            |
| 値の範囲             | \[00:00, 23:59\] または disable |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

`major_freeze_duty_time`の値を`disable`に設定すると、日次マージ機能が無効になります。

## 設定例

日次マージのトリガー時間を`02:00`に設定します。

```shell
obclient> ALTER SYSTEM SET major_freeze_duty_time = '02:00';
```
