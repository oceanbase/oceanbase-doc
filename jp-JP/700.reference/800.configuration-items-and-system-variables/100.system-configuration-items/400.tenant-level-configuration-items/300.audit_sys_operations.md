# audit_sys_operations

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`audit_sys_operations`は、システムユーザーの操作行為を追跡するかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ           | Bool                |
| デフォルト値             | False               |
| 値の範囲           | <ul><li>False</li><li>True</li></ul>   |
| 変更は可能か         | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 設定例

システムユーザーの操作行為を追跡しないように設定します。

```shell
obclient> ALTER SYSTEM SET audit_sys_operations =False;
```
