# default_load_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

`default_load_mode`は、データインポート操作シナリオにおいて、データのインポート方式を制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ  | String|
| デフォルト値    | DISABLED |
| 値の範囲  | <ul><li>DISABLED：ダイレクトロードを使用しない </li><li>FULL_DIRECT_WRITE：SQLのセマンティクスを優先し、フルダイレクトロードを使用する </li><li>INC_DIRECT_WRITE：増分ダイレクトロードのINCモードを使用する </li><li>INC_REPLACE_DIRECT_WRITE：増分ダイレクトロードのINC_REPLACEモードを使用する </li></ul>|
| 変更は可能か| はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

`LOAD DATA INFILE`ステートメント、`INSERT INTO SELECT`ステートメント、および`CREATE TABLE AS SELECT`ステートメントを使用してデータをインポートする際に、ダイレクトロードに関するHintを指定しなかった場合、データのデフォルトのインポート方式は構成パラメータ`default_load_mode`によって制御されます。データインポート操作で`APPEND/DIRECT/NO_DIRECT`Hintが指定されている場合、データのインポート方式はHintによって制御されます。

## 設定例

* データインポート操作シナリオにおいて、データのインポート方式を`FULL_DIRECT_WRITE`モードに設定します。

  ```shell
  obclient [test]> ALTER SYSTEM SET default_load_mode ='FULL_DIRECT_WRITE';
  ```

* データインポート操作シナリオにおいて、データのインポート方式を`INC_DIRECT_WRITE`モードに設定します。

  ```shell
  obclient [test]> ALTER SYSTEM SET default_load_mode ='INC_DIRECT_WRITE';
  ```
