# storage_rowsets_size

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.2バージョンから導入されました。</p>
</main>

## 機能の概要

`storage_rowsets_size`は、カラムストアエンジンが一度にベクトル化してバッチ処理する行数を制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ                  | Int |
| デフォルト値                    | 8192|
| 値の範囲                  | (0，1048576]|
| 変更は可能か                | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

この構成パラメータはカラムストアエンジンにのみ適用され、カラムストアエンジンが一度にベクトル化してバッチ処理するサイズを規定します。マイクロブロックの行数に応じてこのパラメータを適切に調整することで、カラムストアエンジンの実行効率を向上させることができます。

## 設定例

カラムストアエンジンの1回のバッチ処理サイズを16384に設定します。

```shell
obclient> ALTER SYSTEM SET storage_rowsets_size=16384;
```
