# result_cache_max_result

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

`result_cache_max_result`は、単一のresult cacheキャッシュオブジェクトが使用できるメモリの、`result_cache_max_size`に対する最大割合を制御します。

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |    Int         |
| デフォルト値      |  5  |
| 値の範囲    |    [0,100]            |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

以下のコマンドを実行し、単一キャッシュオブジェクトが使用できる`result cache`の最大メモリ量に対する割合を10%に設定します。

```shell
obclient> ALTER SYSTEM SET result_cache_max_result=10;
```
