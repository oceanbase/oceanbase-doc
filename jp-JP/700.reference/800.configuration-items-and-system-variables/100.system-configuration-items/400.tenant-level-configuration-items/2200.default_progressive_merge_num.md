# default_progressive_merge_num

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`default_progressive_merge_num`は、新規テーブル作成時のデフォルトの段階的コンパクション回数を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Int       |
| デフォルト値               | 0       |
| 値の範囲             | [0, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

OceanBaseデータベースは、テーブルデータの段階的なコンパクションをサポートしています。つまり、テーブルに対してデータの書き換えが必要なDDL操作を実行した後、テーブルデータの書き換えを複数回のコンパクションに分散させることができ、1回のコンパクションでは一部のデータのみが書き換えられます。テーブルレベルのプロパティ`progressive_merge_num`を使用してコンパクション動作を制御することも、`default_progressive_merge_num`構成パラメータを使用して新規テーブル作成時のデフォルトの段階的コンパクション回数を設定することもできます。

新規テーブルに`progressive_merge_num`プロパティを指定しない場合、システムはテーブルレベルのプロパティ`progressive_merge_num`の値を`default_progressive_merge_num`の値に設定します。

`progressive_merge_num`プロパティの値の意味は以下のとおりです：

* progressive_merge_num = 0 の場合、デフォルト値の100を使用します。
* progressive_merge_num = 1 の場合、増分コンパクションや段階的コンパクションを実行せず、フルコンパクションを強制的に実行します。
* progressive_merge_num = X の場合、X回のコンパクションで全データが書き換えられ、各コンパクションで1/Xのデータが書き換えられます。

## 設定例

新規テーブル作成時のデフォルトの段階的コンパクション回数をデフォルト値の100に設定します。

```shell
obclient> ALTER SYSTEM SET default_progressive_merge_num = 0;
```
