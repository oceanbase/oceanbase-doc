# default_table_store_format

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

`default_table_store_format`は、ユーザーテナントがデフォルトで作成するテーブルの形式を指定します。形式には、行ストア、純粋なカラムストア、および冗長行ストア/カラムストアが含まれます。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ | String |
| デフォルト値 | row |
| 値の範囲 | ('row', 'column', 'compound')<main id="notice" type='explain'><h4>説明</h4><ul><li>row：ユーザーテナントがテーブルを作成するデフォルト形式は行ストアです。  </li><li>column：ユーザーテナントがテーブル作成ステートメントの後に <code>with column group</code> ステートメントを追加しなかった場合、システムは自動的に <code>with column group(each column)</code> ステートメントを追加し、デフォルト形式は純粋なカラムストアテーブルとなります。</li><li>compound：ユーザーテナントがテーブル作成ステートメントの後に <code>with column group</code> ステートメントを追加しなかった場合、システムは自動的に <code>with column group(all columns, each column)</code> ステートメントを追加し、デフォルト形式は冗長行ストア/カラムストアテーブルとなります。</li></ul></main>|
| 変更は可能か          | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

* この構成パラメータは、ユーザーテナントが作成するメインテーブルのデフォルト形式にのみ影響し、Metaテナントやsysテナントには影響しません。

* テナントがカラムストアテーブルを作成する際、元のテーブル作成ステートメントを変更することなく、作成するテーブルをデフォルトで行ストア、カラムストア、または冗長行ストアのカラムストアとして指定できます。

* この構成パラメータは、テーブル作成ステートメントの後に `with column group` が記述されていない場合にのみ適用されます。インデックステーブルには適用されません。

## 設定例

* ユーザーテナントがテーブルを作成する際、デフォルトで純粋なカラムストアテーブル形式が指定され、テーブル作成ステートメントの後に `with column group(each column)` が自動的に追加されます。

  ```shell
  obclient> ALTER SYSTEM SET default_table_store_format = 'column';
  ```

* ユーザーテナントがテーブルを作成する際、デフォルトで冗長行ストア/カラムストアテーブル形式が指定され、テーブル作成ステートメントの後に `with column group(all columns, each column)` が自動的に追加されます。

  ```shell
  obclient> ALTER SYSTEM SET default_table_store_format = 'compound';
  ```
