# enable_transfer

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_transfer`は、テナント内でのTransferを許可するかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Bool |
| デフォルト値               | True |
| 値の範囲             |<ul><li> True：有効 </li><li>False：無効 </li></ul>|
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

* ロードバランシングアルゴリズムに基づいてテナントログストリーム数を動的に調整し、テナント内のリーダーとパーティションの自動バランシングを行うコマンドは次のとおりです：

  ```shell
  obclient> ALTER SYSTEM SET enable_rebalance=true;

  obclient> ALTER SYSTEM SET enable_transfer=true;
  ```

* 既存のログストリームに基づいてのみログストリームのバランシングを行い、Transferやログストリーム数の動的変化を生じさせないコマンドは次のとおりです：

  ```shell
  obclient> ALTER SYSTEM SET enable_rebalance=true;

  obclient> ALTER SYSTEM SET enable_transfer=false;
  ```

* いかなるロードバランシング関連の運用コマンドや操作も許可しないコマンドは次のとおりです：

  ```shell
  obclient> ALTER SYSTEM SET enable_rebalance=false;
  ```

## 設定例

* すべてのテナントのTransfer機能を無効にする

  ```shell
  obclient> ALTER SYSTEM SET enable_transfer = false TENANT = all_user;
  ```

* 特定のテナント(MySQLテナント)のTransfer機能を有効にする

  ```shell
  obclient> ALTER SYSTEM SET enable_transfer = true TENANT='MySQL';
  ```
