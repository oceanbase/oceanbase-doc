# vector_index_memory_saving_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.4.1バージョンから導入されました。</p>
  <p></p>
</main>

# 機能の概要

`vector_index_memory_saving_mode`は、ベクトルインデックスのメモリ節約モードを有効にするかどうかを制御します。このモードを有効にすると、パーティションテーブルのベクトルインデックス再構築(rebuild)プロセスでのメモリ消費を大幅に削減できます。メモリリソースが限られている環境では、このモードにより少ないメモリでインデックスの再構築を正常に完了でき、メモリ不足による再構築失敗を回避できます。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Bool         |
| デフォルト値               | true       |
| 値の範囲             | true/false |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

この構成パラメータを`true`に設定することで、パーティションテーブルのベクトルインデックス再構築プロセスで必要なメモリを削減します。

```sql
ALTER SYSTEM SET vector_index_memory_saving_mode = true;
```
