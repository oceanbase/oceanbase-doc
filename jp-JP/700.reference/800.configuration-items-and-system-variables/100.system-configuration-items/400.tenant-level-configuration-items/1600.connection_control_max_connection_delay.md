# connection_control_max_connection_delay

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`connection_control_max_connection_delay`は、ログイン失敗回数のしきい値を超えた後の、ログイン失敗によるロックの最大時間を指定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この構成パラメータは、OceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ             | Int      |
| デフォルト値               | 2147483647、単位はミリ秒    |
| 値の範囲             | [1000, 2147483647] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

ログイン失敗回数のしきい値を超えた後の、ログイン失敗によるロックの最大時間を2147483647ミリ秒に設定します。

```shell
obclient> ALTER SYSTEM SET connection_control_max_connection_delay = 2147483647;
```
