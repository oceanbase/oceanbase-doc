# ob_proxy_readonly_transaction_routing_policy

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.1.x系では関連ロジックが変更されたため、この機能は使用されなくなりました。この構成パラメータはV4.1.0以降で廃止され、クエリと設定はサポートされていますが、設定してもエラーは報告されず、有効にもなりません。</p>
</main>

## 機能の概要

`ob_proxy_readonly_transaction_routing_policy`は、Proxyのトランザクションに対するルーティングが読み取り専用ステートメントの影響を受けるかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Bool |
| デフォルト値               | false<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータはV4.0.0以降、デフォルト値がtrueからfalseに調整されました。</p></main>|
| 値の範囲             | <ul><li>true：Proxyのトランザクションに対するルーティングは、最初の読み取り専用ステートメントのルーティングに基づきます。 </li><li>false：Proxyのトランザクションに対するルーティングは、実際にトランザクションを開始する最初のステートメントに基づきます。 </ li></ul>     |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

Proxyのトランザクションに対するルーティングを、実際にトランザクションを開始する最初のステートメントに基づいて設定します。

```shell
obclient> ALTER SYSTEM SET ob_proxy_readonly_transaction_routing_policy = false;
```
