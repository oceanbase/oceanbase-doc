# px_node_policy

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`px_node_policy`は、PX計算ノードのリソースを独立してスケーリングできるようにするために使用され、計算ノードの候補プールを表します。

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|プロパティ|説明|
|-----|----|
|パラメータタイプ              |String|
|デフォルト値                |DATA|
|値の範囲              |<ul><li>`DATA`：PX計算ノードとして、現在のSQLに関わるすべてのデータノードを選択できます。</li> <li>`ZONE`：PX計算ノードとして、現在のSQLに関わるゾーン内で、そのテナントに属するすべてのノードを選択できます。</li> <li>`CLUSTER`：PX計算ノードとして、クラスタ内で現在のテナントに関わるすべてのノードを選択できます。</li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
|OBServerノードの再起動が必要か|不要です。設定は即時に反映されます。|

## 設定例

`sys`テナントは、`mysql`テナントのPX計算ノードとして、現在のSQLに関わるすべてのデータノードを選択できるように設定します。

```shell
obclient> ALTER SYSTEM SET px_node_policy = "DATA" tenant = 'mysql';
```
