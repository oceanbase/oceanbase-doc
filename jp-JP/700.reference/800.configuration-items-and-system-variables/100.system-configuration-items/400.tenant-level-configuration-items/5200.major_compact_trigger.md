# major_compact_trigger

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li><p>OceanBaseデータベースV4.xバージョンは、適応型メジャーコンパクション機能を備えています(<code>_enable_adaptive_compaction</code>スイッチで制御)。適応型メジャーコンパクションが有効な場合、システムはユーザーのクエリや書き込みなどの情報をリアルタイムで収集・統計し、必要に応じてパーティションのメジャーコンパクションタスクをスケジュールします。適応型メジャーコンパクションがトリガーされるシナリオの一つは、特定のパーティションのダンプ頻度がしきい値に達した場合、そのパーティションに対してメジャーコンパクションタスクをスケジュールすることです。適応型メジャーコンパクション機能の詳細な操作手順および説明については、<a href="../../../200.system-management/500.manage-data-storage/200.merge-management/320.adaptive-compaction.md">適応型メジャーコンパクション</a>を参照してください。</p>
<p>構成パラメータ<code>major_compact_trigger</code>は、あるテナントのフリーズ回数がしきい値に達した場合、そのテナントに対してテナントレベルのメジャーコンパクションタスクを1回スケジュールすることを示します。<code>major_compact_trigger</code>の制御範囲はテナントレベルであり、適応型メジャーコンパクション機能と比較して、テナントレベルのメジャーコンパクションの粒度は粗く、関連するパーティションも多く、システムが消費するリソースも多くなります。そのため、適応型メジャーコンパクション機能が有効な場合は、テナントが<code>major_compact_trigger</code>構成パラメータを使用することは推奨されません。</p></li>
<li>この構成パラメータはV4.0.0バージョンから、適用範囲がクラスタレベルからテナントレベルに調整されました。</li></ul>
</main>

## 機能の概要

`major_compact_trigger`は、フリーズ（ダンプの前段階のアクション）が何回発生した後にメジャーコンパクションをトリガーするかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int           |
| デフォルト値               | 0、フリーズ回数に関係なくメジャーコンパクションは自動的にトリガーされないことを示します。 <main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータはV4.0.0バージョンからデフォルト値が5から0に調整されました。</p></main>           |
| 値の範囲             | \[0, 65535\] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。      |

## 設定例

フリーズが10回発生した後に、テナントレベルのメジャーコンパクションを1回トリガーするように設定します。

```shell
obclient> ALTER SYSTEM SET major_compact_trigger=10;
```
