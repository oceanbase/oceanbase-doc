# clog_max_unconfirmed_log_count

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系では対応するロジックが変更されたため、この機能は使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されています。</p>
</main>

## 機能の概要

`clog_max_unconfirmed_log_count`は、トランザクションモジュール内の未確認ログの最大数を設定します。

## プロパティの説明

|      **プロパティ**      |     **説明**     |
|------------------|----------------|
| パラメータタイプ             | 整数型             |
| デフォルト値              | 1500           |
| 値の範囲             | \[100, 50000\] |
| OBServerノードの再起動が必要か | 不要です            |
