# audit_log_query_sql

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

`audit_log_query_sql`は、監査レコード内のSQLステートメントをどのように記録するかを制御します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在、監査機能をサポートしていません。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | String |
| デフォルト値     | ALL |
| 値の範囲   | <ul><li>ALL：すべてのQuery SQLを記録します。</li><li>NONE：Query SQLを記録しません。</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

監査レコード内のSQLステートメントを記録し、Query SQLを記録しないように設定します。

```shell
obclient> ALTER SYSTEM SET audit_log_query_sql ='NONE';
```
