# mds_minor_compact_trigger

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

`mds_minor_compact_trigger`は、MDS Minor CompactionをトリガーするSSTableの数を制御します。MDS SSTableの合計数がこのしきい値以上になると、MDS Minor Compactionがトリガーされ、すべてのMDS SSTableが新しいMDS Minor SSTableに統合されます。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int      |
| デフォルト値               | 2        |
| 値の範囲             | [2,16] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 設定例

* ユーザーテナントが自身のテナントでトリガーされるMDS Minor CompactionのSSTable数を2に設定します。

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2;
  ```

* システムテナント(`sys`テナント)がテナント`mysql`でトリガーされるMDS Minor CompactionのSSTable数を2に設定します。

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2 TENANT = 'mysql';
  ```
