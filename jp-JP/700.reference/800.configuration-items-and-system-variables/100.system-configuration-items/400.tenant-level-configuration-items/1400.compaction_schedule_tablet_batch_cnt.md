# compaction_schedule_tablet_batch_cnt

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

 `compaction_schedule_tablet_batch_cnt`は、Compactionのバッチスケジューリング時に、各バッチでスケジュールされるパーティション数の上限値を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| --- | --- |
| パラメータタイプ             | Int  |
| デフォルト値               | 50000 |
| 値の範囲             | [10000，500000] <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、V4.2.5 BP5バージョン以降、値の範囲が[10000，200000]から[10000，500000]に変更されました。</p></main> |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

Compactionのバッチスケジューリング時に、各バッチでスケジュールされるパーティション数の上限値を50000に設定します。

```shell
obclient> ALTER SYSTEM SET compaction_schedule_tablet_batch_cnt = 50000;
```
