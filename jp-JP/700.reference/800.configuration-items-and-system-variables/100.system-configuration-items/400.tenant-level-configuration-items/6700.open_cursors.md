# open_cursors

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`open_cursors`は、単一のSessionが同時に開けるカーソルの数を制限するために使用されます。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できません。

## プロパティの説明

|        プロパティ        |     説明      |
|------------------|-------------|
| パラメータタイプ             | Int          |
| デフォルト値              | 50          |
| 値の範囲             | [0，65535] |
| 変更は可能か  | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

* 各Sessionが同時に開けるカーソルの上限数。Session上で同時に開かれるカーソルがこの制限を超えると、`ORA-01000: maximum open cursors exceeded.`エラーが報告されます。

* パラメータ`open_cursors`はカーソルの数を制限するだけでなく、PSハンドルの数も制限します。

## 設定例

単一のSessionが同時に開けるカーソルの数を`20`に設定します。例：

```shell
obclient> ALTER SYSTEM SET open_cursors = 20;
```
