# ob_enable_python_udf

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_enable_python_udf`は、Python UDF機能を有効または無効にするために使用します。

# 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |    Bool              |
| デフォルト値      |  FALSE  |
| 値の範囲    |  TRUE/FALSE              |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

Python UDF機能を有効にするかどうかは、`ob_python_home`構成パラメータと併用する必要があります。

## 使用例

* Python UDF機能を有効にする

    ```shell
    obclient> ALTER SYSTEM SET ob_enable_python_udf = TRUE tenant mysql;
    ```

* Python UDF機能を無効にする

  ```shell
  obclient> ALTER SYSTEM SET ob_enable_python_udf = FALSE tenant mysql;
  ```
