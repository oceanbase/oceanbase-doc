# compatible

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`compatible`は、テナント内の関連機能の互換動作を制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | ------- |
| パラメータタイプ             | String |
| デフォルト値               | 4.4.2.0 |
| 値の範囲             | 4.0.0.0以降の有効なバージョン   |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 設定例

テナント内の関連機能の互換バージョンを4.4.2に設定します。

```shell
obclient> ALTER SYSTEM SET compatible = '4.4.2.0';
```
