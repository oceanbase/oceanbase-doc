# io_category_config

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では対応するロジックが変更されたため、該当機能は使用されなくなりました。この構成パラメータはV4.2.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`io_category_config`は、各カテゴリのI/Oリクエストの割合を設定します。

## プロパティの説明

|      **プロパティ**      |       **説明**       |
|------------------|--------------------|
| パラメータタイプ             | String             |
| デフォルト値              | other: 100,100,100 |
| OBServerノードの再起動が必要か | 不要です               |

## 使用方法

カテゴリI/O仕様は、テナントのI/O仕様の割合を表すために使用されます。フォーマットは次のとおりです：`category_name: min_percent, max_percent, weight_percent`。複数のカテゴリ仕様間はセミコロンで区切り、個別に指定されていないカテゴリは`other`で表されます。

すべてのカテゴリ（`other`を含む）の`min_percent`の合計は`100`、`weight_percent`の合計は`100`です。

## 設定例

テナントの各カテゴリのI/Oリクエストの割合を設定する例は以下のとおりです：

```shell
obclient> ALTER SYSTEM SET io_category_config = 'user: 30, 90, 50; log: 30, 90, 30; sys: 10, 10, 10; other: 30, 100, 10;';
```
