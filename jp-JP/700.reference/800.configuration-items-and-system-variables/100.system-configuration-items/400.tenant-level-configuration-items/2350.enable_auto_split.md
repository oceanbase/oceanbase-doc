# enable_auto_split

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_auto_split`は、テナントで自動パーティション機能を有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

|  **プロパティ** | **説明** |
|-----------|----------|
| パラメータタイプ   | BOOL |
| デフォルト値     | FALSE |
| 値の範囲   | <ul><li>TRUE：自動パーティション機能を有効にすることを示します。</li><li>FALSE（デフォルト値）：自動パーティション機能を無効にすることを示します。</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

`ALTER SYSTEM SET`ステートメントを使用して構成パラメータの値を調整します。

`enable_auto_split`構成パラメータは、テーブル作成時に自動パーティション句を使用して明示的に自動パーティションを有効にしなかった場合、自動パーティションテーブルを作成するかどうかを決定します。テーブルに対して自動パーティション属性を明示的に設定した場合は、この構成パラメータの影響を受けません。

* `enable_auto_split`が`true`の場合、作成されるテーブルが自動パーティションの要件を満たす場合にのみ、実際に自動パーティションテーブルとして作成されます。
* `enable_auto_split`が`false`で、後から`true`に変更しても、既存の自動パーティション要件を満たすテーブルには反映されず、新規作成されるテーブルにのみ有効になります。

自動パーティションの詳細については、[自動パーティションの分割（MySQLモード）](../../../300.database-object-management/100.manage-object-of-mysql-mode/300.manage-partitions-of-mysql-mode/250.partition-splitting-of-mysql-mode/300.automatic-partition-splitting-of-mysql-mode.md)または[自動パーティションの分割（Oracleモード）](../../../300.database-object-management/200.manage-object-of-oracle-mode/200.manage-partitions-of-oracle-mode/250.partition-splitting-of-oracle-mode/300.automatic-partition-splitting-of-oracle-mode.md)を参照してください。

## 設定例

自動パーティション機能を有効にします。

```sql
ALTER SYSTEM SET enable_auto_split = TRUE;
```
