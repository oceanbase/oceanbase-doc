# query_response_time_stats

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`query_response_time_stats`は、`information_schema.QUERY_RESPONSE_TIME`ビューの統計情報収集を有効にするかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|        プロパティ      |  説明  |
|------------------|-------|
| パラメータタイプ             | Bool |
| デフォルト値               | False |
| 値の範囲             | <ul><li>True：有効 </li><li>False：無効 </li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

`information_schema.QUERY_RESPONSE_TIME`ビューの統計情報収集を無効に設定します。

```shell
obclient> ALTER SYSTEM SET query_response_time_stats=False;
```
