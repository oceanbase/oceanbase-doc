# kv_group_commit_batch_size

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

`kv_group_commit_batch_size`は、OBKVのグループコミットでbatch操作を実行するサイズを指定します。値が1の場合、グループコミット機能を無効にします。1より大きい場合、グループコミットが有効になり、この値が各コミットバッチのサイズとして使用されます。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**    |   **説明**   |
|------------------|--------------|
| パラメータタイプ             | Int     |
| デフォルト値               | 1<main id="notice" type='explain'><h4>説明</h4><p>V4.3.5バージョンでは、V4.3.5 BP1バージョンからデフォルト値が1から10に調整されました。</p></main>     |
| 値の範囲             | (0, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 設定例

グループコミットのbatch_sizeを10に設定します。

```shell
obclient> ALTER SYSTEM SET kv_group_commit_batch_size = 10;
```
