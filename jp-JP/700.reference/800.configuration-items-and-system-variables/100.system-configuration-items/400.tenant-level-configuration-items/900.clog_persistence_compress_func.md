# clog_persistence_compress_func

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが変更されたため、V4.0.0以降ではログのストレージ圧縮機能がサポートされなくなりました。この構成パラメータはV4.0.0以降から削除されました。</li>
<li>業務上のニーズに基づき、OceanBaseデータベースはV4.2.1以降で再びログのストレージ圧縮機能をサポートしています。V4.2.1以降のバージョン(V4.3.0を除く)では、テナントレベルの構成パラメータ<code>log_storage_compress_func</code>を使用してログストレージ圧縮の圧縮アルゴリズムを制御できます。<code>log_storage_compress_func</code>構成パラメータの詳細については、<a href="5200.log_storage_compress_func.md">log_storage_compress_func</a>を参照してください。</li></ul>
</main>

## 機能の概要

`clog_persistence_compress_func`は、トランザクションログの永続化時の圧縮アルゴリズムを設定します。

## プロパティの説明

|      **プロパティ**      |                                    **説明**                                              |
|------------------|----------------------------------------------------------------------------------------------------|
| パラメータタイプ             | String                              |
| デフォルト値              | lz4_1.0   |
| 値の範囲             | <ul><li> none   </li><li> lz4_1.0   </li><li> zstd_1.0   </li><li> zstd_1.3.8 </li></ul>   |
| OBServerノードの再起動が必要か | 不要です    |
