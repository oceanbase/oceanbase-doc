# log_disk_utilization_limit_threshold

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`log_disk_utilization_limit_threshold`は、テナントのログディスク利用率のしきい値を設定します。テナントのログディスク使用量が、テナントのログディスク容量の総量にこの値を乗算した値を超えた場合、ログの書き込みを許可しなくなります。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int          |
| デフォルト値               | 95          |
| 値の範囲             | [80, 100] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 使用方法

`log_disk_utilization_limit_threshold`の値は、[log_disk_utilization_threshold](../400.tenant-level-configuration-items/4700.log_disk_utilization_threshold.md)の値より大きく設定する必要があります。

## 設定例

テナントのログディスク利用率のしきい値を95に設定します。

```shell
obclient> ALTER SYSTEM SET log_disk_utilization_limit_threshold=95;
```
