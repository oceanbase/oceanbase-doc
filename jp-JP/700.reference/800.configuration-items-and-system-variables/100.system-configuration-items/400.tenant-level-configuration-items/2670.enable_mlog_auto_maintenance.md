# enable_mlog_auto_maintenance

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.4.x系では、このパラメータはV4.4.2バージョンから導入されました。</li><li>V4.3.5系では、このパラメータはV4.3.5 BP4バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

`enable_mlog_auto_maintenance`は、マテリアライズドビューのログ（mlog）の自動管理機能を有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ  | Bool |
| デフォルト値    | True <main id="notice" type='notice'><h4>注意</h4><p>OceanBaseデータベースV4.3.5 BP4バージョンでは：<ul><li>新規作成されたテナントの場合、このパラメータのデフォルト値は<code>True</code>です。</li><li>OceanBaseデータベースの旧バージョン（V4.3.5 BP4以前のバージョン）からアップグレードされたテナントの場合、このパラメータのデフォルト値は<code>False</code>です。</li></ul></p></main>|
| 値の範囲  | <ul><li>True：mlogの自動管理機能を有効にすることを示します。</li><li>False：mlogの自動管理機能を無効にすることを示します。</li></ul> |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

* mlogの自動管理を無効にします。

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = False;
    ```

* mlogの自動管理を有効にします。

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = True;
    ```
