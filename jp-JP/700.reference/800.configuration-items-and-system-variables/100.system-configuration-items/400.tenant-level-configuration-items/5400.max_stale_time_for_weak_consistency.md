# max_stale_time_for_weak_consistency

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`max_stale_time_for_weak_consistency`は、弱い一貫性読み取りでどの程度古いデータの読み取りを許可するかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Time      |
| デフォルト値               | 5s        |
| 値の範囲             | [5s, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 設定例

弱い一貫性読み取りモードで読み取るデータがリーダーレプリカ（Leader）に対して最大5秒遅れるように設定します。

```shell
obclient> ALTER SYSTEM SET max_stale_time_for_weak_consistency= '5s';
```
