# external_table_csv_max_buffer_size

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.4.2 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

`external_table_csv_max_buffer_size`は、CSV外部テーブルを解析するためのバッファサイズを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ | Int |
| デフォルト値 | 1G |
| 値の範囲 | [0B, +∞)|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

デフォルトのCSV外部テーブルバッファサイズを使用して`SIZE_OVERFLOW`エラーが発生する場合、ニーズに合わせてバッファサイズを設定できます。

## 使用例

CSV外部テーブルを解析するためのバッファサイズを2Gに設定します。

```shell
obclient> ALTER SYSTEM SET external_table_csv_max_buffer_size = "2G";
```
