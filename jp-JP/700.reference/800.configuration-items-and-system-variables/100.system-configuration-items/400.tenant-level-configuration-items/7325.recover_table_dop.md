# recover_table_dop

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このパラメータはV4.3.5バージョンから導入されました。</li>
<li>V4.2.x系では、このパラメータはV4.2.5バージョンから導入されました。</li>
</ul>
</main>

## 機能の概要

`recover_table_dop`は、テーブルレベル復元のテナント間データロード段階において、単一テーブルの並列復元を許可する最大テーブル数を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|--------------------|--------------|
| パラメータタイプ             | Int         |
| デフォルト値               | 0、デフォルトの並列度は1を意味します        |
| 値の範囲             | [0, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 使用方法

* このパラメータは、**テーブルレベル復元のテナント間データロード段階**の並列度を制御するためにのみ使用されます。テーブルレベル復元のプロセスについては、[復元プロセス](../../../100.oceanbase-database-concepts/1000.high-data-reliability-and-availability/500.backup-and-recovery/400.recovery-architecture.md)を参照してください。

* 並列復元機能の詳細については、[テーブル単位での復元の実行](../../../../600.manage/600.backup-and-recovery/700.recover-table/200.perform-table-recovery.md)を参照してください。

## 設定例

`mysql`テナントの単一テーブル復元の並列度を6に設定します。

```shell
obclient> ALTER SYSTEM SET recover_table_dop = 6 TENANT = 'mysql';
```
