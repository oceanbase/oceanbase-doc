# clog_persistence_compress_func

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系でストレージアーキテクチャが変更されたことにより、V4.0.0バージョンでは現在ログストレージ圧縮機能をサポートしていません。この構成パラメータはV4.0.0以降のバージョンから削除されました。</li>
<li>ビジネスニーズに基づき、OceanBaseデータベースはV4.2.1バージョン以降、再びログストレージ圧縮機能をサポートしています。V4.2.1以降のバージョン（V4.3.0バージョンを除く）では、テナントレベルの構成パラメータ <code>log_storage_compress_func</code> を使用してログストレージ圧縮の圧縮アルゴリズムを制御できます。</li></ul><p></p>
</main>

## 機能の概要

`clog_persistence_compress_func`は、トランザクションログ永続化圧縮アルゴリズムを設定します。

## プロパティの説明

|      **プロパティ**      |                                 **説明**                               |
|------------------|--------------------------------------------------------------------------|
| パラメータタイプ             | String      |
| デフォルト値              | lz4_1.0     |
| 値の範囲             | <ul><li> none   </li><li> lz4_1.0   </li><li> zstd_1.0   </li><li> zstd_1.3.8</li></ul>    |
| OBServerノードの再起動が必要か | 不要です        |
