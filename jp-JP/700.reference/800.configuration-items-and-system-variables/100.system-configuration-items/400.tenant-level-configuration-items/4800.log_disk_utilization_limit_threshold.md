# log_disk_utilization_limit_threshold

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`log_disk_utilization_limit_threshold`は、テナントログディスク利用率の制限しきい値を設定します。テナントログディスク使用量が、テナントログディスク容量の合計にこの値を乗じた値を超えると、ログ書き込みが許可されなくなります。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Int          |
| デフォルト値               | 95          |
| 値の範囲             | [80, 100] |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

`log_disk_utilization_limit_threshold`の値は、[log_disk_utilization_threshold](../400.tenant-level-configuration-items/4900.log_disk_utilization_threshold.md)の値より大きくする必要があります。

## 設定例

テナントログディスク利用率の制限しきい値を95に設定します。

```shell
obclient> ALTER SYSTEM SET log_disk_utilization_limit_threshold=95;
```
