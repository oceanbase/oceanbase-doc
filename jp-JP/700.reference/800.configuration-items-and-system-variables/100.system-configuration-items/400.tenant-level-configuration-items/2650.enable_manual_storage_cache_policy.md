# enable_manual_storage_cache_policy

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このパラメータはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このパラメータはV4.3.5 BP2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`enable_manual_storage_cache_policy`は、ユーザーが手動で指定するホットキャッシュポリシーを有効にするために使用されます。

<main id="notice">
<h4>適用対象</h4>
<p>この構成パラメータは、OceanBaseデータベースの共有ストレージ(Shared-Storage、SS)モードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

  <main id="notice" type='notice'>
  <h4>注意</h4>
  <p>手動でホットデータキャッシュポリシーを指定する機能は、MySQLモードのユーザーテナントでのみ有効です。Oracleモードのユーザーテナントでこの構成パラメータを変更した場合、または<code>sys</code>テナントがOracleモードのユーザーテナントやその他の非ユーザーテナント(<code>sys</code>テナントおよびMetaテナント)を指定してこの構成パラメータを変更した場合、構成パラメータの値は変更できますが、機能は有効になりません。</p>
  </main>

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ  | Bool  |
| デフォルト値    | True |
| 値の範囲   | <ul><li>`True`：すべてのユーザーが手動で指定するホットキャッシュポリシーを有効にし、システムはテーブル/パーティション/インデックスで指定された`storage_cache_policy`パラメータの値を採用します。</li> <li> `False`：すべてのユーザーが手動で指定するホットキャッシュポリシーを無効にし、システムはテーブル/パーティション/インデックスで指定された`storage_cache_policy`パラメータの値を使用せず、すべてのテーブル/パーティション/インデックスのホットキャッシュポリシーには構成パラメータ`default_storage_cache_policy`の値が使用されます。</li></ul> |
| 変更は可能か | はい。<ALTER SYSTEM SET》ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

* ユーザーテナント内で、ユーザーが手動で指定するホットキャッシュポリシーを有効にします。

  ```shell
  obclient> ALTER SYSTEM SET enable_manual_storage_cache_policy= True;
  ```

* システムテナント内で、テナント`mysqltenant`のためにユーザーが手動で指定するホットキャッシュポリシーを有効にします。

  ```shell
  obclient> ALTER SYSTEM SET enable_manual_storage_cache_policy= True TENANT = mysqltenant;
  ```
