# audit_log_compression

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.3.x系では、このパラメータはV4.3.3バージョンから導入されました。</li> <li>V4.2.x系では、このパラメータはV4.2.4バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

`audit_log_compression`は監査ログで使用する圧縮アルゴリズムを設定します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは、現在監査機能をサポートしていません。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこのパラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | String |
| デフォルト値     | NONE、圧縮が無効であることを示します。 |
| 値の範囲   | <ul><li>NONE</li> <li>ZSTD</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

ファイルが`audit_log_rotate_on_size`で指定されたサイズを超えるとアーカイブがトリガーされます。このパラメータは、アーカイブされたファイルを圧縮する必要があるかどうかを制御します。

## 設定例

監査ログで使用する圧縮アルゴリズムをZSTDに設定します。

```shell
obclient> ALTER SYSTEM SET audit_log_compression='ZSTD';
```
