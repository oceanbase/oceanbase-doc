# ob_enable_java_udf

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_enable_java_udf`は、Java UDF機能を有効または無効にするために使用します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |    Bool              |
| デフォルト値      |  FALSE  |
| 値の範囲    |  TRUE/FALSE              |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

OceanBaseクラウドデータベースは、現在Java UDF機能をサポートしていません。また、Java UDFはOceanBase内部のJVMに依存しているため、`ob_enable_java_udf`構成パラメータを有効にするだけでなく、[ob_enable_java_env](../300.cluster-level-configuration-items/16630.ob_enable_java_env.md)構成パラメータも有効にし、JVM環境を設定する必要があります。

Java UDF機能を有効にした後、必要に応じて[ob_enable_java_udf_sandbox](../300.cluster-level-configuration-items/16655.ob_enable_java_udf_sandbox.md)構成パラメータを有効にすることで、Java UDFのJVMをObserverメインプロセスから分離して実行し、実行の安全性と安定性を高めることができます。

## 設定例

* Java UDF機能を有効にする

  ```sql
  obclient> ALTER SYSTEM SET ob_enable_java_udf = TRUE;
  ```

* Java UDF機能を無効にする

  ```sql
  obclient> ALTER SYSTEM SET ob_enable_java_udf = FALSE;
  ```
