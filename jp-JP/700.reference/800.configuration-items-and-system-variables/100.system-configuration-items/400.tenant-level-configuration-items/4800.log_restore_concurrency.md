# log_restore_concurrency

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>この構成パラメータは、V4.1.0バージョン以降、テナントレベルでの適用範囲に調整されました。 </li><li>この構成パラメータは、V2.2.50バージョンから導入されました。 </li></ul>
</main>

## 機能の概要

`log_restore_concurrency`は、ログ復元の並列度を設定します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>復元ワーカースレッドは、テナントまたはスタンバイテナントの復元時にのみ作成されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| --- | --- |
| パラメータタイプ    | Int |
| デフォルト値      | 0、OceanBaseデータベースの適応型ログ復元並列度を使用します。<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.2.0バージョン以降、デフォルト値が1から0に調整されました。</p></main> |
| 値の範囲    | [0，100]<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータは、V4.2.0バージョン以降、値の範囲が[1,100]から[0,100]に調整されました。</p></main> |
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

OceanBaseデータベースの適応型ログ復元並列度を使用する場合、ログ復元ワーカースレッド数の適応値はテナントの`max_cpu`数になります。

## 設定例

ログ復元の並列数を5に設定します。

```shell
obclient> ALTER SYSTEM SET log_restore_concurrency = 5;
```
