# kv_ttl_history_recycle_interval

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V3.1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`kv_ttl_history_recycle_interval`は、TTLタスクの履歴記録を保持する期間を設定します。TTLタスクの履歴テーブルは、現在から遡って`kv_ttl_history_recycle_interval`の長さの期間分の履歴記録のみを保持します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| プロパティ | 説明 |
| --- | --- |
| パラメータタイプ      | Time |
| デフォルト値        | 7d |
| 値の範囲      | [1d, 180d] |
| 変更は可能か    | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 設定例

TTLタスクの履歴記録を保持する期間を7日に設定します。

```shell
obclient> ALTER SYSTEM SET kv_ttl_history_recycle_interval= '7d';
```
