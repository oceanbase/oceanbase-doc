# plsql_optimize_level

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.3 BP1バージョンから削除され、システム変数<a href="../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/10910.plsql_optimize_level-global.md">plsql_optimize_level (Global)</a>に調整されました。</p>
</main>

## 機能の概要

`plsql_optimize_level`は、PLコードのコンパイル時の最適化レベルを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|        プロパティ        |                 説明                 |
|------------------|------------------------------------|
| パラメータタイプ             | Int                               |
| デフォルト値               | 1                                  |
| 値の範囲             | <ul><li>0：オプティマイズを無効にする</li><li>1：オプティマイズを有効にする</li></ul>  |
| OBServerノードの再起動が必要か | 不要です                                  |

## 設定例

PLコードのコンパイル時に最適化を有効にします。
```shell
obclient> ALTER SYSTEM SET plsql_optimize_level=1;
```
