# attach_shared_sstable_thread_score

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

`attach_shared_sstable_thread_score`は、テナントが共有ストレージモードでコンピューティングノードの共有データ参照を実行するために使用できるスレッド数を設定します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この構成パラメータは、共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | Int |
| デフォルト値     | 0、デフォルトのスレッド数は6を意味します |
| 値の範囲   | [0, 100] |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

`inc_sstable_upload_thread_score`を設定することで、共有SSTableをローカルタスクに参照するために同時に使用できるスレッド数を設定できます。

## 設定例

ユーザーテナント内で、共有ストレージの増分データをローカルタスクに参照する処理を行うスレッド数を10に設定します。

```shell
obclient> ALTER SYSTEM SET attach_shared_sstable_thread_score = 10;
```

## 関連ドキュメント

共有ストレージモードでデータ共有関連タスクを処理するスレッド数を設定する必要がある場合は、[inc_sstable_upload_thread_score](3650.inc_sstable_upload_thread_score.md)を参照してください。
