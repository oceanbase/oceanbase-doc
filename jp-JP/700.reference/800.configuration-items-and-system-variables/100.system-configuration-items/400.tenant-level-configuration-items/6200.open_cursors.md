# open_cursors

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`open_cursors`は、単一のセッションが同時に開けるカーソルの数を制限します。

## 権限要件

* パラメータの確認

  `sys`テナントとMySQLユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとMySQLユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|        プロパティ        |     説明      |
|------------------|-------------|
| パラメータタイプ             | Int          |
| デフォルト値              | 50          |
| 値の範囲             | [0，65535] |
| 変更は可能か  | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 使用方法

* 各セッションが同時に開けるカーソルの上限数です。セッションで同時に開くカーソル数がこの制限を超えた場合、`ORA-01000: maximum open cursors exceeded.` エラーが発生します。

* 構成パラメータ `open_cursors` は、カーソルの数だけでなく、PSハンドルの数も制限します。

## 設定例

単一セッションが同時に開けるカーソル数を `20` に設定します。例：

```shell
obclient> ALTER SYSTEM SET open_cursors = 20;
```
