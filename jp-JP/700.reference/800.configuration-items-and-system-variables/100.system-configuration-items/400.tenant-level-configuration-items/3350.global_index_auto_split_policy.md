# global_index_auto_split_policy

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.5 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

`global_index_auto_split_policy`は、新規作成されるグローバルインデックスで自動パーティション機能を有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

|  **プロパティ** | **説明** |
|-----------|----------|
| パラメータタイプ   | STRING |
| デフォルト値     | DISTRIBUTED |
| 値の範囲   | <ul><li>`DISTRIBUTED`（デフォルト値）：テナント内に複数ノードのリソースが利用可能な場合（例：テナントのプライマリゾーンが1つを超える、またはテナントのユニットが1つを超える）、新規作成されるグローバルインデックスに対して、デフォルトで自動ゾーン分割が有効になります。</li><li>`ALL`：新規作成されるグローバルインデックスに対して、デフォルトで自動ゾーン分割が有効になります。</li><li>`OFF`：既存のグローバルインデックスを含む、すべてのグローバルインデックスの自動分割を禁止します。</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータの値を変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

`ALTER SYSTEM SET`ステートメントを使用して構成パラメータ`global_index_auto_split_policy`の値を調整します。親テーブルが自動パーティションテーブルであれば、グローバルインデックスも自動的にパーティション化されます。親テーブルが自動パーティションテーブルでない場合にのみ、`global_index_auto_split_policy`のポリシーに従って設定されます。

* `global_index_auto_split_policy`の設定値が`ALL`の場合、新規作成されるグローバルインデックスでは、デフォルトで自動分割が有効になります。

* `global_index_auto_split_policy`の設定値が`DISTRIBUTED`の場合、テナント内に複数ノードのリソースが利用可能であることが確認された場合（例：テナントのプライマリゾーンが1つを超える場合、またはテナントのユニットが1つを超える場合）、新規作成されるグローバルインデックスでは、デフォルトで自動分割が有効になります。

* `global_index_auto_split_policy`の設定値が`OFF`の場合、既存のグローバルインデックスを含む、すべてのグローバルインデックスの自動分割を無効にします。

自動パーティションの詳細については、[自動パーティションの分割（MySQLモード）](../../../300.database-object-management/100.manage-object-of-mysql-mode/300.manage-partitions-of-mysql-mode/250.partition-splitting-of-mysql-mode/300.automatic-partition-splitting-of-mysql-mode.md)または[自動パーティションの分割（Oracleモード）](../../../300.database-object-management/200.manage-object-of-oracle-mode/200.manage-partitions-of-oracle-mode/250.partition-splitting-of-oracle-mode/300.automatic-partition-splitting-of-oracle-mode.md)を参照してください。

## 設定例

新規作成されるグローバルインデックスで自動パーティション機能を有効にします。

```sql
obclient> ALTER SYSTEM SET global_index_auto_split_policy = 'ALL';
```
