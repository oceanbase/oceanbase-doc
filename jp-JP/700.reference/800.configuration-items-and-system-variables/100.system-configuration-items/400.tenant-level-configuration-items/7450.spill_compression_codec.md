# spill_compression_codec

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V4.3.1バージョンから導入されました。</p>
</main>

## 機能の概要

`spill_compression_codec`は、SQL実行中にデータをディスクに書き込む際の圧縮アルゴリズムの種類を指定します。

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |  **説明**   |
|------------------|-----------|
| パラメータタイプ                  | String   |
| デフォルト値                    | NONE、圧縮しないことを表します。      |
| 値の範囲                  | <ul><li>NONE</li><li>ZSTD</li><li>LZ4</li><li>SNAPPY</li></ul>       |
| 変更は可能か                | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

この構成パラメータで圧縮アルゴリズムを選択することで、演算子の実行中に一時データをディスクに書き込む際の使用容量を削減できます。

## 設定例

SQL実行中にデータをディスクに書き込む際の圧縮アルゴリズムを`LZ4`に指定します。

```shell
obclient> ALTER SYSTEM SET spill_compression_codec='LZ4';
```
