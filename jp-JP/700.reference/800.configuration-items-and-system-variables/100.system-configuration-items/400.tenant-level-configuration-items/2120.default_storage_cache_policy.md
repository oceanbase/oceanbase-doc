# default_storage_cache_policy

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このパラメータはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このパラメータはV4.3.5 BP2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`default_storage_cache_policy`はデフォルトのキャッシュポリシーを設定します。これはテナントレベルの`storage_cache_policy`のデフォルト値であり、新規作成されたテーブルにのみ適用されます。

<main id="notice">
<h4>適用対象</h4>
<p>この構成パラメータは、OceanBaseデータベースの共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

  <main id="notice" type='notice'>
  <h4>注意</h4>
  <p>ホットデータキャッシュポリシーを手動で指定する機能は、MySQLモードのユーザーテナントでのみ有効です。Oracleモードのユーザーテナントでこの構成パラメータを変更した場合、または<code>sys</code>テナントがOracleモードのユーザーテナントやその他の非ユーザーテナント(<code>sys</code>テナントおよびMetaテナント)を指定してこの構成パラメータを変更した場合、パラメータ値は変更できますが、機能は有効になりません。</p>
  </main>

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ  | String  |
| デフォルト値    | AUTO |
| 値の範囲   | <ul><li>`HOT`：テーブル内のすべてのデータをホットデータとしてローカルディスクにキャッシュします。</li> <li> `AUTO`：テーブル内のすべてのデータの自動冷熱識別を指定します。つまり、共有ストレージがテーブル内のデータの保存方法を自動的に決定します。</li></ul> |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

* 現在のテナントで、パラメータ `storage_cache_policy` によって明示的にキャッシュポリシーが指定されていないすべての新規テーブルは、デフォルトで `default_storage_cache_policy` で指定されたキャッシュポリシーを使用します。
* ユーザーテーブルとインデックスのみが構成パラメータ `default_storage_cache_policy` の影響を受けます。システムテーブルは構成パラメータ `default_storage_cache_policy` の影響を受けず、常に `AUTO` 設定となります。

## 設定例

* ユーザーテナントで、そのテナントのデフォルトキャッシュポリシーを `HOT` に設定します。

  ```shell
  obclient> ALTER SYSTEM SET default_storage_cache_policy='HOT';
  ```

* システムテナントで、テナント `mysqltenant` のデフォルトキャッシュポリシーを `HOT` に指定します。

  ```shell
  obclient> ALTER SYSTEM SET default_storage_cache_policy='HOT' TENANT = mysqltenant;
  ```
