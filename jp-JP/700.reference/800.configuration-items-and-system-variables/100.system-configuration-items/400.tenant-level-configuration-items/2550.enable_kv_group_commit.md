# enable_kv_group_commit

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.3.4バージョンでは、構成パラメータ <a href="4150.kv_group_commit_batch_size.md">kv_group_commit_batch_size</a> と <a href="4160.kv_group_commit_rw_mode.md">kv_group_commit_rw_mode</a> を使用して、グループコミット機能が有効かどうかを確認できます。</li>
</ul>
</ul>
</main>

## 機能の概要

`enable_kv_group_commit`は、グループコミット機能を有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | Bool |
| デフォルト値     | False |
| 値の範囲   | <ul><li>True：有効な場合、サーバーは操作を実行計画ごとにグループ化し、グループ単位で実行します。</li><li>False：無効な場合、サーバーは元のプロセスに従って操作を個別に実行します。</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

グループコミット機能を有効にします。

```shell
obclient> ALTER SYSTEM SET enable_kv_group_commit=True;
```
