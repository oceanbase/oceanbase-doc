# zone_deploy_mode

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このパラメータはV4.4.2バージョンから導入されました。</li>
<li>V4.2.5系では、このパラメータはV4.2.5 BP5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`zone_deploy_mode`は、テナントの各ゾーンにおける分散モードを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| プロパティ                | 説明      |
|---------------------|-----------|
| パラメータタイプ             | String |
| デフォルト値               | homo |
| 値の範囲             |<ul><li>`homo`：同種ゾーンモード </li><li>`hetero`：異種ゾーンモード</li></ul>|
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です |

## 使用方法

新規作成されたテナントやアップグレードされた既存のテナントは、デフォルトで同種ゾーンモードになります。同種ゾーンモードでは、各ゾーンのUnit数は同一でなければならず、ログストリームは各ゾーン内で対称的に分散され、ログストリームはUnit Groupに紐づけられます。

* 1つのUnit Groupは各ゾーンの1つのUnitで構成され、各Unitは1つのUnit Groupにのみ属します。

* 1つのログストリームは1つのUnit Groupにのみ属し、各ログストリームのレプリカはそのUnit Group内の各Unitに分散配置されます。

* Unitの拡張・縮小はUnit Group単位でのみ行え、各ゾーンのUNIT_NUMは同期して調整し、一致させる必要があります。

異種ゾーンモードを有効にする必要がある場合は、パラメータ `zone_deploy_mode` の値を `hetero` に変更する必要があります。変更後、パラメータ `zone_deploy_mode` の値を `homo` に戻すことはできません。

同種ゾーンモードと比較して、異種ゾーンモードの主な使用上の違いは以下のとおりです：

* ログストリームの分散にはUnit Groupの概念がなくなり、各ゾーンのログストリームレプリカは対称的なUnitに限定されなくなりました。

* テナント内の各リソースプールの `UNIT_NUM` は異なる場合がありますが、最大でも2種類の異なる `UNIT_NUM` しかサポートされません。

* テナント内の特定のリソースプールの `UNIT_NUM` を個別に変更し、リソースプール単位でのスケーリングを実現できます。

* `ALTER RESOURCE TENANT` ステートメントを使用して `UNIT_NUM` を減らしてスケールインする際、`UNIT_GROUP` を指定して削除することはサポートされていません。

* ログストリーム運用コマンド `ALTER SYSTEM CREATE LS` および `ALTER SYSTEM MODIFY LS` を使用する際、`UNIT_GROUP` パラメータを指定することはサポートされていません。

## 設定例

テナントの各ゾーンの分散モードを異種ゾーンモードに設定します。

```shell
obclient> ALTER SYSTEM SET zone_deploy_mode = 'hetero';
```
