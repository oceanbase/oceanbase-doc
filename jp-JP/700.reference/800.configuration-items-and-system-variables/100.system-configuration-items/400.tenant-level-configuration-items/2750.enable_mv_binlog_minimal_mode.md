# enable_mv_binlog_minimal_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.4.x系では、この構成パラメータはV4.4.2バージョンから導入されました。</li><li>V4.3.5系では、この構成パラメータはV4.3.5 BP5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`enable_mv_binlog_minimal_mode`は、マテリアライズドビューの増分更新時に`binlog minimal`モードを有効にするかどうかを制御します。

## 権限要件

* 構成パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこの構成パラメータを確認できます。

* 構成パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ  | Bool |
| デフォルト値    | False |
| 値の範囲  | <ul><li>True：マテリアライズドビューの増分更新シナリオにおける`binlog minimal`モードを有効にすることを示します。</li><li>False：マテリアライズドビューの増分更新シナリオにおける`binlog minimal`モードを無効にすることを示します。</li></ul> |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 使用方法

* 構成パラメータ`enable_mv_binlog_minimal_mode`はマテリアライズドビューのDML動作にのみ影響し、他のDMLには影響しません。
* 構成パラメータ`enable_mv_binlog_minimal_mode`は[binlog_row_image](../../200.system-variable/300.global-system-variable/500.binlog_row_image-global.md)の影響を受けません。この構成パラメータは、マテリアライズドビュー用の特別な処理経路を対象とします。

  * `enable_mv_binlog_minimal_mode`のスイッチをオンにすると、たとえ`binlog_row_image`が`full`モードに設定されていても、マテリアライズドビューのDMLは`minimal`モードを使用します。

* 構成パラメータ`enable_mv_binlog_minimal_mode`を有効にすると、マテリアライズドビューのリフレッシュ性能を向上させることができます。ただし、この設定により`CLOG`の内容が簡略化されます。下流の連携(例：CDC + OMS)がマテリアライズドビューの完全な`CLOG`に依存して移行や同期を行う場合、この設定を有効にすると同期リンクで異常が発生する可能性があります。そのため、マテリアライズドビューを利用した下流データの同期が必要な場合は、このスイッチをオンにすることは推奨されません。

## 設定例

1. マテリアライズドビューの増分更新シナリオで `binlog minimal` モードを有効にします。

    ```shell
    obclient> ALTER SYSTEM SET enable_mv_binlog_minimal_mode = True;
    ```

2. テーブル `test_tbl1` を作成します。

    ```shell
    obclient> CREATE TABLE test_tbl1(col1 INT, col2 INT, col3 INT);
    ```

3. マテリアライズドビュー `mv1_t1` を作成します。

    ```shell
    obclient> CREATE MATERIALIZED VIEW mv1_t1
        REFRESH FAST
        AS SELECT col2, COUNT(*) cnt
           FROM test_tbl1
           GROUP BY col2;
    ```

4. 増分更新時のDMLは `binlog minimal` モードを使用します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH('mv1_t1', 'f');
    ```

5. マテリアライズドビューの増分更新シナリオで `binlog minimal` モードを無効にします。

    ```shell
    obclient> ALTER SYSTEM SET enable_mv_binlog_minimal_mode = False;
    ```
