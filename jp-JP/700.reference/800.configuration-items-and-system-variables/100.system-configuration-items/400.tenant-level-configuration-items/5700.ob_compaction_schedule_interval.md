# ob_compaction_schedule_interval

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_compaction_schedule_interval`は、Compactionスケジューリングの時間間隔を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Time         |
| デフォルト値               | 120s |
| 値の範囲             | [3s, 5m] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 設定例

Compactionスケジューリングの時間間隔を120秒に設定します。

```shell
obclient> ALTER SYSTEM SET ob_compaction_schedule_interval= '120s';
```
