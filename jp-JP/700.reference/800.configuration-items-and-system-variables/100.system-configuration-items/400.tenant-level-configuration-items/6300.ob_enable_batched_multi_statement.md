# ob_enable_batched_multi_statement

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V2.2.50バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_enable_batched_multi_statement`は、バッチ処理機能によるグループ実行の最適化を有効にするかどうかを設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |    **説明**    |
|------------------|--------------|
| パラメータタイプ             | Bool                       |
| デフォルト値               | False                      |
| 値の範囲             | <ul><li>False：無効 </li><li>True：有効  </li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 設定例

バッチ処理機能によるグループ実行の最適化を無効に設定します。

```shell
obclient> ALTER SYSTEM SET ob_enable_batched_multi_statement= False;
```
