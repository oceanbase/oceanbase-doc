# dump_data_dictionary_to_log_interval

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

`dump_data_dictionary_to_log_interval`は、テナントデータディクショナリの永続化サイクルを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

<main id="notice" type='explain'>
  <h4>注意</h4>
  <p>低バージョンからV4.2.5 BP1バージョンにアップグレードする場合、この構成パラメータの値は低バージョンの値が維持されます。</p>
</main>

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ | Time |
| デフォルト値   | 0、デフォルト単位は秒<main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、V4.2.5 BP1バージョンからデフォルト値が24Hから0に変更されました。値が0の場合、この構成パラメータに基づいてデータディクショナリをスケジュールして生成しません。データディクショナリの生成を停止するには、`DBMS_DATA_DICT.DISABLE_DUMP()`コマンドと組み合わせて使用する必要があります。</p></main> |

## 使用方法

データディクショナリはユーザーテナントにのみサービスを提供し、PALFを介して通常のテナントのシステムログストリーム(SYS_LS)に永続化されます。ユーザーテナントが作成されると、データディクショナリサービスが自動的に有効になり、テナントSYS_LSのLEADERコピー上で実行されます。

ログアーカイブサービスが有効になると、非同期データディクショナリ生成タスクが自動的にトリガーされます。OceanBaseデータベースは、テナントレベルの構成パラメータ`dump_data_dictionary_to_log_interval`とDBMS_DATA_DICTシステムパッケージ(V4.2.5 BP1以降のサポート)を使用して、定期的にデータディクショナリを生成するスケジューリングをサポートしています。[DBMS_DATA_DICT](../../../../700.reference/500.sql-reference/300.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/21000.dbms-data-dict-mysql/100.dbms-data-dict-mysql.md)システムパッケージを使用したデータディクショナリの生成スケジューリングを推奨します。

OceanBaseデータベースは、V4.2.0バージョン以降、DBA/CDBビューを使用してデータディクショナリの生成履歴を記録することをサポートしています。システムテナントでは[CDB_OB_DATA_DICTIONARY_IN_LOG](../../../700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7800.o-cdb_ob_data_dictionary_in_log-of-sys-tenant.md)ビューを、通常のテナントでは[DBA_OB_DATA_DICTIONARY_IN_LOG](../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/7900.o-dba_ob_data_dictionary_in_log-of-mysql-mode.md)ビューを照会して、ディクショナリの位置情報を取得できます。

## 設定例

テナントデータディクショナリの永続化サイクルを24時間に設定します。

```shell
obclient> ALTER SYSTEM SET dump_data_dictionary_to_log_interval = '24H';
```
