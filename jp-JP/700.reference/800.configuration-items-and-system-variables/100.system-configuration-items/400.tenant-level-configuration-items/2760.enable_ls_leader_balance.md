# enable_ls_leader_balance

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.5バージョンでは、この構成パラメータはV4.2.5 BP6バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_ls_leader_balance`は、ログストリームリーダーの自動バランシングを有効にするかどうかを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

|  **プロパティ** | **説明** |
|-----------|----------|
| パラメータタイプ   | Bool |
| デフォルト値     | True |
| 値の範囲   | <ul><li>`True`：ログストリームリーダーの自動バランシングを有効にする</li><li>`False`：ログストリームリーダーの自動バランシングを無効にする</li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

* [enable_rebalance](2900.enable_rebalance.md)で有効にした場合（値は`True`）、`enable_ls_leader_balance`はログストリームリーダーの自動バランシングを個別に無効にできます。

* この構成パラメータが無効になっている場合（値は`False`）、ログストリームレベルでの自動リーダー切り替えは発生しませんが、パーティションレベルでは異なるリーダー間でのログストリームの転送によりリーダー切り替えが発生する可能性があります。

## 設定例

* ユーザーテナントが自身のログストリームリーダーの自動バランシングを無効にします。

  ```shell
  obclient> ALTER SYSTEM SET enable_ls_leader_balance = False;
  ```

* システムテナントが`mysql`テナントのログストリームリーダーの自動バランシングを無効にします。

  ```shell
  obclient> ALTER SYSTEM SET enable_ls_leader_balance = False TENANT = 'mysql';
  ```
