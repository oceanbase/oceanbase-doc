# suspend_storage_cache_task

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このパラメータはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このパラメータはV4.3.5 BP2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`suspend_storage_cache_task`は、バックグラウンドキャッシュタスクを一時停止するかどうかを設定します。

<main id="notice">
<h4>適用対象</h4>
<p>この構成パラメータは、OceanBaseデータベースの共有ストレージ(Shared-Storage、SS)モードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

  <main id="notice" type='notice'>
  <h4>注意</h4>
  <p>ホットデータキャッシュ戦略を手動で指定する機能は、MySQLモードのユーザーテナントでのみ有効です。Oracleモードのユーザーテナントでこの構成パラメータを変更したり、<code>sys</code>テナントがOracleモードのユーザーテナントやその他の非ユーザーテナント(<code>sys</code>テナントおよびMetaテナント)を指定してこの構成パラメータを変更した場合、パラメータ値は変更できますが、機能は有効になりません。</p>
  </main>

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ  | Bool  |
| デフォルト値    | False |
| 値の範囲   | <ul><li>`True`：現在実行中および新規に開始されるキャッシュタスクを一時停止します。</li> <li> `False`：バックグラウンドのキャッシュタスクを一時停止せず、通常通りキャッシュタスクを実行します。</li></ul> |
| 変更は可能か | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

* ユーザーテナント

  1. このテナント配下のキャッシュタスクを一時停止します。

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = True;
     ```

  2. このテナント配下のキャッシュタスクを通常進行に設定します。

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = False;
     ```

* システムテナント

  1. テナント `mysqltenant` 配下のキャッシュタスクを一時停止します。

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = True TENANT = mysqltenant;
     ```

  2. テナント `mysqltenant` 配下のキャッシュタスクを通常進行に設定します。

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = False TENANT = mysqltenant;
     ```
