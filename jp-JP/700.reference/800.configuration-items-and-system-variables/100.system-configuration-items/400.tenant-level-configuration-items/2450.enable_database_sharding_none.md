# enable_database_sharding_none

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この構成パラメータは、V4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

`enable_database_sharding_none`構成パラメータは、データベース作成時にユーザーテーブルの自動集約（テーブルグループへの自動バインド）を有効にするかどうかを制御するスイッチです。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この構成パラメータは、OceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**    |      **説明**      |
|------------------|--------------------|
| パラメータタイプ          | Bool                |
| デフォルト値            | False  |
| 値の範囲          | <ul><li>True：有効 </li><li>False：無効</li></ul>|
| 変更は可能か        | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。|

## 使用方法

* 構成パラメータ`enable_database_sharding_none`の値を`False`から`True`に設定する場合：

  * 新規に作成されたデータベースでは、デフォルトで`SHARDING = 'NONE'`のテーブルグループが1つバインドされ、そのデータベース内のすべてのユーザーテーブルは同一のログストリームにバインドされます。
  * 既に作成されたデータベースには影響しません。

* 構成パラメータ `enable_database_sharding_none` の値を `True` から `False` に設定します：

  * 既存のデータベースには変更を加えません。

## 設定例

データベース作成時にユーザーテーブルの自動集計を有効にします。

```shell
obclient> ALTER SYSTEM SET enable_database_sharding_none = True;
```
