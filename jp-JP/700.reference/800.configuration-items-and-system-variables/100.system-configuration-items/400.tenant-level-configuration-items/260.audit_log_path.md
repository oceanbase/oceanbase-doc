# audit_log_path

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

`audit_log_path`は監査ログの出力ディレクトリを設定します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在監査機能をサポートしていません。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントは`ALTER SYSTEM SET`ステートメントを使用してこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | String |
| デフォルト値     | ""、デフォルトは空文字列であり、デフォルトのパス `${WORK_DIR}/audit` を使用することを意味します。 |
| 値の範囲   |<ul><li>ローカルの出力ディレクトリを使用する場合、例えば <code>file:///path...</code></li><li>クラウドストレージの出力ディレクトリを使用する場合、例えば <code>oss://dest...</code></li></ul>|
| 変更は可能か | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。   |

## 使用方法

* ローカルストレージシナリオ

  同一テナント内では、異なるOBServerの監査ログが異なるディレクトリに出力されます。同一クラスタ内で、ユーザーが異なるテナントの出力パスを同一に設定した場合、ディレクトリ構造に`tenant_id`という階層が追加されます。ローカル出力ディレクトリ構造は以下の図のとおりです：

    ```shell
    - ${audit_log_path}
    - tenant_id_1
    - ip1:port1
        - audit.log.20231031080646317[.zst]
        - audit.log.20231031084835263[.zst]
        - audit.log
    - ip2:port2
        - audit.log.20231031072457838[.zst]
        - audit.log.20231031093023607[.zst]
        - audit.log.20231031101213751[.zst]
        - audit.log
    - tenant_id_2
    ```

* クラウドストレージシナリオ

   OceanBaseデータベースは、複数のOBServerから同一の`oss/nfs`ディレクトリに出力するシナリオをサポートしています。同時実行書き込みファイルのパフォーマンスおよびその後の圧縮・暗号化機能はすべてローカルファイルを操作する必要があるため、アーカイブ済みのファイルのみがクラウドストレージに保存され、追加書き込みはローカルの`audit`ディレクトリ下のファイルに行われます。クラウドストレージ内の監査ログを下流で消費する際、最新の一部のレコードはOBServerのローカルにのみ存在し、下流には可視されません。

## 設定例

* 監査ログの出力ディレクトリを`file:///logs/audit`に設定します。

   ```shell
   obclient> ALTER SYSTEM SET audit_log_path='file:///logs/audit';
   ```

* 監査ログの出力ディレクトリを`oss://$OSS_ACCESS_ID:$OSS......`に設定します。

   ```shell
   obclient> ALTER SYSTEM SET audit_log_path='oss://$OSS_ACCESS_ID:$OSS_ACCESS_KEY@$OSS_HOST/test/audit/';
   ```
