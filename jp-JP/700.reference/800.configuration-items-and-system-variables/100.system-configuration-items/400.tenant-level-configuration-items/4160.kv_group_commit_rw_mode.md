# kv_group_commit_rw_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>この構成パラメータは、V4.3.4バージョンから導入されました。</li>
  <li>この構成パラメータは、OBKV-Tableモードでのみ操作が有効です。</li></ul>
</main>

## 機能の概要

`kv_group_commit_rw_mode`は、グループコミットを実行するシナリオを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**    |   **説明**   |
|------------------|--------------|
| パラメータタイプ             | STRING      |
| デフォルト値               | ALL       |
| 値の範囲             | <ul><li>ALL：読み書き操作ともにグループコミットを実行 </li><li>WRITE：書き込み操作のみグループコミットを実行 </li><li>READ：読み取り操作のみグループコミットを実行 </li></ul>|
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。  |

## 設定例

読み取り操作のみをグループコミットで実行するように設定します。

```shell
obclient> ALTER SYSTEM SET kv_group_commit_rw_mode = 'READ' tenant=<tenant_name>;
```
