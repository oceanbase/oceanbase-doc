# temporary_file_max_disk_size

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.5バージョンにおいて、この構成パラメータはV4.2.5 BP3バージョンから導入されました。</p>
</main>

## 機能の概要

構成パラメータ `temporary_file_max_disk_size` は、テナントの単一ノード内で一時ファイルが占有できる最大ディスク容量を設定します。

## 権限要件

* パラメータの確認

  `sys` テナントとすべてのユーザーテナントは、`SHOW PARAMETERS` ステートメントまたは `GV$OB_PARAMETERS` ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys` テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|--------------------|--------------|
| パラメータタイプ             | Capacity         |
| デフォルト値               | 0M、一時ファイルが占有できるディスク容量の上限を制限しないことを示します      |
| 値の範囲             | \[0M, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## クエリ例

テナントの単一ノード内で、一時ファイルが占有できる最大ディスク容量を100GBに設定します。

```shell
obclient> ALTER SYSTEM SET temporary_file_max_disk_size = '100GB';
```
