# rpc_memory_limit_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

`rpc_memory_limit_percentage`は、テナント内のRPCがテナント総メモリのうち使用できる最大割合を設定します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|        プロパティ      |  説明  |
|------------------|-------|
| パラメータタイプ             | Int |
| デフォルト値               | 0、RPCメモリに制限がないことを示します。 |
| 値の範囲             | [0,100] |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

テナント内のRPCがテナント総メモリのうち使用できる最大割合を10%に設定します。

```shell
obclient> ALTER SYSTEM SET rpc_memory_limit_percentage=10;
```
