# plsql_optimize_level

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.3 BP1バージョン以降の削除対象となり、システム変数<a href="../../200.system-variable/300.global-system-variable/10910.plsql_optimize_level-global.md">plsql_optimize_level(Global)</a>に調整されました。</p>
</main>

## 機能の概要

`plsql_optimize_level`は、PLコードのコンパイル時の最適化レベルを制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|        プロパティ        |                 説明                 |
|------------------|------------------------------------|
| パラメータタイプ             | Int                               |
| デフォルト値               | 1                                  |
| 値の範囲             | [0,3]<ul><li>0:フロントエンドおよびバックエンドの最適化を無効にする。コンパイルのオーバーヘッドと時間が最も短いが、実行時間が増加する可能性がある。</li><li>1:フロントエンドの最適化を無効にし、バックエンドの最適化を有効にする。コンパイルのオーバーヘッドと時間を大幅に削減するが、実行時間がわずかに増加する可能性がある。</li><li>2:フロントエンドおよびバックエンドの最適化を有効にする。コンパイルと実行のパフォーマンスのバランスが取れている。デフォルトの最適化動作。</li><li>3:より多くの最適化戦略を有効にすることを試みる。追加のパフォーマンス向上が得られる可能性がある。  |
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。          |

## 設定例

PLコードのコンパイル時に最適化を有効にします。

```shell
obclient> ALTER SYSTEM SET plsql_optimize_level=1;
```
