# balancer_idle_time

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.2.0バージョン以降、クラスタレベルからテナントレベルに調整されました。</p>
</main>

## 機能の概要

`balancer_idle_time`は、ロードバランシングなどを行うバックグラウンドスレッドがアイドル状態のとき、次に起動するまでの待機間隔を設定します。

* システムテナントの場合：ディザスタリカバリスレッドやロードバランシングスレッドの実行間隔を制御します。
* 通常テナントの場合：テナント内のログストリームロードバランシングスレッドの実行間隔を制御します。

## 権限要件

* パラメータの確認

  `sys`テナントとすべてのユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ | Time |
| デフォルト値 | 10s、つまり10秒を意味します<main id="notice" type='explain'><h4>説明</h4><p>この構成パラメータはV4.2.0以降のバージョンからデフォルト値が5分から10秒に調整されました。</p></main> |
| 値の範囲 | [10s, +∞) |
| 変更は可能か           | はい。`ALTER SYSTEM SET`ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。 |

## 設定例

* `sys`テナント内で、すべてのテナントのディザスタリカバリスレッドおよびロードバランシングスレッドの制御時間間隔を10秒に設定します。

  ```shell
  obclient(root@sys)[oceanbase]> ALTER SYSTEM SET balancer_idle_time = '10s' tenant = ALL;
  ```

* `sys`テナント内で、tenant1の時間間隔を10分に設定します。

  ```shell
  obclient(root@sys)[oceanbase]> ALTER SYSTEM SET balancer_idle_time = '10m' tenant = 'tenant1';
  ```

* ユーザーテナント内で、時間間隔を10分に設定します。

  ```shell
  obclient> ALTER SYSTEM SET balancer_idle_time = '10m';
  ```
