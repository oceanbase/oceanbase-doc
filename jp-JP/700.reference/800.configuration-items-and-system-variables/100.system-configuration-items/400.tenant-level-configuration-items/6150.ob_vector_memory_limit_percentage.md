# ob_vector_memory_limit_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この構成パラメータは、V4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_vector_memory_limit_percentage`は、ベクトルインデックスモジュールのメモリリソース使用量のしきい値を設定します。

<main id="notice" type='notice'>
  <h4>適用対象</h4>
  <p>この構成パラメータは、OceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* パラメータの確認

  `sys`テナントとMySQLユーザーテナントは`SHOW PARAMETERS`ステートメント、または`GV$OB_PARAMETERS`ビューを使用してこのパラメータを確認できます。

* パラメータの変更

  `sys`テナントとMySQLユーザーテナントはこの構成パラメータを変更できます。

## プロパティの説明

|      **プロパティ**      |   **説明**   |
|--------------------|--------------|
| パラメータタイプ             | Int         |
| デフォルト値               | 0、単位は割合 <main id="notice" type='notice'><h4>説明</h4><p>V4.4.1以前のバージョンでは、この構成パラメータのデフォルト値はベクトルインデックスにメモリを割り当てないことを意味し、ベクトル検索機能が無効になっていました。<br>V4.4.1バージョン以降、この構成パラメータのデフォルト値は適応モードを意味するように変更されました。これにより、システムがテナント内のベクトルインデックスデータのメモリ使用率を自動的に調整します：<ul><li>テナントの実際のメモリが8GB以下の場合、この値は自動的に40に設定されます。</li><li>テナントの実際のメモリが8GBを超える場合、この値は自動的に50に設定されます。</li></ul></p></main>      |
| 値の範囲             | [0, 100)。実際の最大値は `85 - Memstore`（つまり `memstore_limit_percentage` の値）です。`memstore_limit_percentage` パラメータが `0`（デフォルト値）に設定されている場合、システムはMemStoreのメモリ割合を自動的に計算します。自動計算のルール：<ul><li>テナントメモリ > 8GBの場合：MemStoreはテナントメモリの50%を使用します。</li><li>テナントメモリ ≤ 8GBの場合：MemStoreはテナントメモリの40%を使用します。</li></ul> |
| 変更は可能か           | はい。`ALTER SYSTEM SET` ステートメントを使用して変更できます。|
| OBServerノードの再起動が必要か | 不要です。設定は即時に反映されます。     |

## 使用方法

### メモリの計算

このパラメータの具体的な値は、計算式とビジネスニーズに基づいて計画する必要があります。[メモリ計算表をダウンロード](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V4.3.3/%E5%86%85%E5%AD%98%E8%AE%A1%E7%AE%97.xlsx)して、パラメータの値を計算してください。

表の説明：

* テナント内で複数のベクトルインデックスを作成する場合、必要なメモリはすべてのメモリの合計です。

* ビジネスシナリオに応じて、表の1列目のデータ量と2列目のベクトル次元の値を入力する必要があります。

* 表の3列目のMはHNSWグラフインデックスの最大辺数を表し、`16`がデフォルト値です。通常は変更不要です。

* 表の5列目の最小メモリ構成は、後からインデックスを作成する場合で、新規データを追加しないシナリオにのみ適用されます。

### ベクトルインデックスのメモリ使用量の増量

ベクトルインデックスのメモリ使用量のしきい値を引き上げる必要がある場合、そのテナントのMemStoreメモリ割合をまず下げることを推奨します。これは、ユーザーテナントで`_memstore_limit_percentage`パラメータを変更することで実現できます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>MemStoreの割合を下げるとDMLパフォーマンスに影響を与える可能性があるため、DML負荷が高い環境では、必ず評価のうえで変更してください。</p>
</main>

## 設定例

ベクトルインデックスのメモリ使用量のしきい値を30%に設定します。

```shell
obclient> ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
```

ベクトルインデックスのメモリ使用量のしきい値を59%に引き上げます。

```shell
obclient> ALTER SYSTEM SET _memstore_limit_percentage = 25;
          ALTER SYSTEM SET ob_vector_memory_limit_percentage = 59;
```

現在のベクトルインデックスのメモリ設定を確認します。

```shell
obclient> SHOW PARAMETERS LIKE 'ob_vector_memory_limit_percentage';
```
