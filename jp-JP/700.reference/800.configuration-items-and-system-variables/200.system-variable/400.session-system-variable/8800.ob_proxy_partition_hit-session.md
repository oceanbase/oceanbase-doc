# ob_proxy_partition_hit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_proxy_partition_hit`は、obproxyがSQL文でリクエストされたデータを、そのデータの主パーティションが存在するOBServerノードに送信するかどうかを設定します。

## プロパティの説明

| **プロパティ** |                                               **説明**                                                |
|--------|-----------------------------------------------------------------------------------------------------|
| パラメータタイプ   | Bool             |
| デフォルト値    | 1                |
| 値の範囲   | <ul><li> 1：はい   </li><li> 0：いいえ </li></ul>    |
| 適用範囲   | Session          |
| 変更は可能か  | 不可。この変数はテナント作成時に指定する必要があり、テナント作成後はSQL文で変更できません               |

## 使用方法

ユーザーが`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー(Oracleモード)および`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してこの変数の値を照会することはサポートされていません。ユーザーは`SYS.DBA_OB_SYS_VARIABLES`ビュー(Oracleモード)または`oceanbase.DBA_OB_SYS_VARIABLES`ビュー(MySQLモード)を照会してこの変数の値を照会できます。

また、ユーザーは`SELECT`ステートメントを使用してこの変数の値を返すこともできます：

```shell
obclient> SELECT @@ob_proxy_partition_hit;
```

実行結果は次のとおりです：

```shell
+--------------------------+
| @@ob_proxy_partition_hit |
+--------------------------+
|                        1 |
+--------------------------+
1 row in set
```
