# enable_sql_plan_monitor

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この変数はV4.3.3 BP1バージョンから導入されました。</li><li>V4.2.x系では、この変数はV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`enable_sql_plan_monitor`は、現在のセッションのSQLをSQLプランモニターに記録するかどうかを設定します。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用して、セッションのシステム変数の値を確認できます。

* 変数の変更

  `sys`テナントとすべてのユーザーテナントは、自身のテナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |  Bool                |
| デフォルト値      |  False |
| 値の範囲    |  <ul><li>False：現在のセッションのSQLがSQL計画監視器に追加されるのは、以下のいずれかの条件を満たす場合のみです：<ul><li>特定のHintを使用して監視を有効にした場合。</li><li>SQLの実行時間が設定されたしきい値を超えた場合。</li><li>SQLの実行で並列処理が採用され、その並列度が1より大きい場合。</li></ul> </li><li>True：追加の条件なしで、現在のセッションで実行されるすべてのSQLが自動的にSQL計画監視器に記録されます。</li></ul>              |
| 適用範囲    |  Session |
| 変更は可能か  |  はい。`SET`ステートメントを使用して変更できます。 |

## 設定例

現在のセッションのSQLをSQLプランモニターに記録するようにします。

```shell
obclient> SET  enable_sql_plan_monitor =True;
```
