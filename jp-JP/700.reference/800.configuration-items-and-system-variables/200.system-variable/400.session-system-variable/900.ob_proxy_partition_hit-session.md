# ob_proxy_partition_hit

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_proxy_partition_hit`は、obproxyがSQL文で要求されたデータを、そのデータのリーダーパーティションが存在するOBServerノードに送信するかどうかを設定します。

## プロパティの説明

| **プロパティ** |                                               **説明**                                                |
|--------|-----------------------------------------------------------------------------------------------------|
| パラメータタイプ   | Bool             |
| デフォルト値    | 1                |
| 値の範囲   | <ul><li> 1：はい   </li><li> 0：いいえ </li></ul>    |
| 適用範囲   | セッション          |
| 変更は可能か  | 不可。この変数はテナント作成時にのみ指定可能で、テナント作成後はSQLステートメントで変更できません。                                                                    |

## 使用方法

ユーザーは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してこの変数の値を照会することはできません。ユーザーは`SYS.DBA_OB_SYS_VARIABLES`ビュー（Oracleモード）または`oceanbase.DBA_OB_SYS_VARIABLES`ビュー（MySQLモード）をクエリすることでこの変数の値を確認できます。

また、ユーザーは`SELECT`ステートメントを使用してこの変数の値を取得することもできます：

```shell
obclient> SELECT @@ob_proxy_partition_hit;
```

実行結果は次のとおりです：

```shell
+--------------------------+
| @@ob_proxy_partition_hit |
+--------------------------+
|                        1 |
+--------------------------+
1 row in set
```
