# ob_global_debug_sync

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_global_debug_sync`は、デバッグ時に同期ポイントを設定するために使用されます。この変数の設定はすべてのセッションに影響します。

## プロパティの説明

| **プロパティ** |   **説明**   |
|--------|------------|
| パラメータタイプ   | Varchar    |
| デフォルト値    | 空文字列       |
| 適用範囲   | Session     |
| 見えるか   | いいえ、すべてのテナントからは見えません |

## 使用方法

ユーザーが`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー(Oracleモード)および`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してこの変数の値を照会することはサポートされていません。ユーザーは`SYS.DBA_OB_SYS_VARIABLES`ビュー(Oracleモード)または`oceanbase.DBA_OB_SYS_VARIABLES`ビュー(MySQLモード)を照会してこの変数の値を照会できます。

この設定は、[debug_sync_timeout](../../100.system-configuration-items/300.cluster-level-configuration-items/5100.debug_sync_timeout.md)構成パラメータの値が0以外の場合にのみ有効です。
