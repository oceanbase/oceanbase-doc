# ob_trace_info

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数は V2.2.77 で導入されました。</p>
</main>

## 機能の概要

`ob_trace_info`は、トレース情報をそのまま転送するために使用します。この情報は最終的にRedoログに永続化できます。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用して、セッションのシステム変数の値を確認できます。

* 変数の変更

  `sys`テナントとすべてのユーザーテナントは、自身のテナント内のセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** |      **説明**       |
|--------|-------------------|
| パラメータタイプ   | Varchar           |
| デフォルト値    | 空文字列              |
| 値の範囲   | 文字列長は\[0, 4096\] |
| 適用範囲    | セッション |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。      |

## 設定例

トレースログにそのまま渡す情報として `my_trace_info` を指定します。

```shell
obclient> SET ob_trace_info='my_trace_info';
```
