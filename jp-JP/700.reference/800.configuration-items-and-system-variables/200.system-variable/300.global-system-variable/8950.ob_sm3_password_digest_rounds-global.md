# ob_sm3_password_digest_rounds

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.4.2 BP3バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_sm3_password_digest_rounds`は、`ob_sm3_password`認証プラグインがパスワード認証文字列を生成する際に実行するSM3反復回数を制御します。反復回数が多いほど、パスワードハッシュのブルートフォース攻撃耐性は強くなりますが、パスワードハッシュの生成および完全なパスワード認証時の計算負荷も大きくなります。ユーザーはセキュリティとパフォーマンスの要件に応じて設定できます。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * グローバルに適用

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

    * Oracleユーザーテナントは、グローバルシステム変数の値を変更するには`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ** | **説明** |
|----------|----------|
| パラメータタイプ | Int |
| デフォルト値 | 5000 |
| 値の範囲 | [5000, 4095000]、かつ1000の倍数であること |
| 適用範囲 | Global |
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます。 |

## 使用方法

* この変数はグローバル変数であり、変更は即時に反映されます。変数を変更すると、新規ユーザーの作成時、または `ALTER USER`、`SET PASSWORD` などの操作で `ob_sm3_password` パスワードハッシュを再生成する際に、新しい反復回数が使用されます。既に格納されているパスワード認証文字列は自動的に再計算されず、パスワードをリセットしてハッシュを再生成した場合にのみ新しい値が使用されます。
* この変数はパスワードハッシュの反復回数のみを制御し、デフォルトの認証プラグインを切り替えるものではありません。この変数の設定が有効になるのは、`ob_sm3_password` プラグインを使用してパスワードを生成または更新する場合のみです。

## 設定例

SM3パスワードハッシュの反復回数を10000に設定します。

```shell
obclient> SET GLOBAL ob_sm3_password_digest_rounds = 10000;
```
