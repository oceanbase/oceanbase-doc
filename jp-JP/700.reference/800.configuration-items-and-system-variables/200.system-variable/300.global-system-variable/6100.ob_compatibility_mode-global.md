# ob_compatibility_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_compatibility_mode`は、テナントの互換モードを指定するために使用します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  この変数は、テナント作成後はSQLステートメントでの変更をサポートしていません。

## プロパティの説明

| **プロパティ**  |      **説明**      |
|-----------|--------------------|
| パラメータタイプ    | Enum                                         |
| デフォルト値      | MYSQL                                        |
| 値の範囲    | <ul><li>MYSQL：MYSQL互換を表す </li><li>ORACLE：ORACLE互換を表す </li></ul>  |
| 適用範囲    | <ul><li>Global </li><li>Session </li></ul>                      |
| 変更は可能か   | 不可。この変数はテナント作成時にのみ指定可能で、テナント作成後はSQLステートメントで変更できません。   |

## 設定例

`CREATE TENANT`ステートメントでテナントを作成する際に、`ob_compatibility_mode`変数の値を`MYSQL`に指定する例は以下のとおりです：

```shell
obclient> CREATE TENANT IF NOT EXISTS t1 zone_list = ('zone1'), primary_zone = 'zone1', resource_pool_list = ('pool1') SET ob_compatibility_mode = 'MYSQL',lower_case_table_names = 0;
```
