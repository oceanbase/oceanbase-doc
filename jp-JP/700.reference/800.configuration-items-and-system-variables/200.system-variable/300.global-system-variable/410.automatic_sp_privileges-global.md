# automatic_sp_privileges

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この変数はV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、この変数はV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`automatic_sp_privileges`は、ストアドプロシージャ作成時に、そのストアドプロシージャに対するALTERおよびEXECUTE権限を自動的に付与するかどうかを設定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---------|---------------|
| パラメータタイプ    | int                 |
| デフォルト値     | 1   |
| 値の範囲    |  [0，1]                    |
| 適用範囲    |  Global       |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

ストアドプロシージャ作成時に、この変数の値が1の場合、作成者にはそのストアドプロシージャに対するALTERおよびEXECUTE権限が自動的に付与されます。変数の値が0の場合、これらの権限は自動的に付与されません。

## 設定例

ストアドプロシージャ内で自動的に付与されるALTERおよびEXECUTE権限を設定します。

```shell
obclient> SET GLOBAL automatic_sp_privileges = true;
```
