# div_precision_increment

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`div_precision_increment`は、除算結果の精度を被除数の精度に基づいて増分する量を設定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限が必要です。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナント内のセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ     | Int                     |
| デフォルト値       | 4                       |
| 値の範囲     | [0, 30]               |
| 適用範囲     | <ul><li>Global</li><li>Session</li></ul>    |
| 変更は可能か   | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

除算結果の精度を被除数の精度に基づいて4増分します。

* グローバル変更

  ```shell
  obclient> SET GLOBAL div_precision_increment =4;
  ```

* セッション変更

  ```shell
  obclient> SET div_precision_increment =4;
  ```
