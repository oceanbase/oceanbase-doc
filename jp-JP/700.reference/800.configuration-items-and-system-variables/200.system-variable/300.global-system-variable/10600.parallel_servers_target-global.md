# parallel_servers_target

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`parallel_servers_target`は、各サーバー上のパラレルクエリのキュー条件を設定します。

複数のパラレル実行（Parallel eXecution、PX）SQLが合計で消費するスレッド数がパラレルクエリのキュー条件を超えた場合、後続のパラレル実行SQLはキュー待ちとなります。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

  * Oracleユーザーテナントは、グローバルシステム変数の値を変更するには`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ** |           **説明**           |
|--------|----------------------------|
| パラメータタイプ   | Int                        |
| デフォルト値    | 0、特別な意味はありません。この値はテナント作成時に自動的に設定されます。  |
| 値の範囲   | \[0, 9223372036854775807\] |
| 適用範囲   | Global                     |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

`parallel_servers_target`はテナントレベルの変数です。テナント作成時に：

1. テナント作成ステートメントで `parallel_servers_target` の値が指定されている場合、そのテナントの `parallel_servers_target` は指定値に設定されます。

   テナント作成時に `parallel_servers_target` の値を指定するステートメントは以下のとおりです：

   ```shell
   obclient> CREATE TENANT IF NOT EXISTS <tenant_name> CHARSET='utf8mb4', ZONE_LIST=('zone1'), PRIMARY_ZONE='zone1', RESOURCE_POOL_LIST=('<pool_name>') set parallel_servers_target = 624;
   ```

2. テナント作成時に `parallel_servers_target` の値が指定されていない場合、OBServerノード内でテナントを作成する過程で、`min_cpu` に基づいて自動的に値が計算され、設定されます。

   テナントにログインし、以下のステートメントを実行してこの値を確認します：

   ```shell
   obclient> show variables like 'parallel_servers_target';
   ```

   自動計算された `parallel_servers_target` の値は通常小さく、単純な並列クエリの要件しか満たせません。そのテナントで並列処理を使用したい場合は、手動でこの値を大きな値に設定することを推奨します。推奨アルゴリズムは `parallel_servers_target = max_cpu * 10` です。

## 設定例

各サーバー上の並列クエリキューを624に設定します。

```shell
obclient> SET GLOBAL parallel_servers_target = 624;
```
