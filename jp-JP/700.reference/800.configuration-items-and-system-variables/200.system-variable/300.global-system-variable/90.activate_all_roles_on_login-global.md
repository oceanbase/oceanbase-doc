# activate_all_roles_on_login

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この変数はV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、この変数はV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`activate_all_roles_on_login`は、ログイン時にすべてのRoleをデフォルトで自動的に有効にするかどうかを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---------|---------------|
| パラメータタイプ    |    Bool              |
| デフォルト値     |  0  |
| 値の範囲    | <ul><li>ON：有効</li><li>OFF：無効</li></ul>                   |
| 適用範囲    |  Global |
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

ログイン時にすべてのRoleをデフォルトで自動的に有効にします。

```shell
obclient> SET GLOBAL activate_all_roles_on_login=ON;
```
