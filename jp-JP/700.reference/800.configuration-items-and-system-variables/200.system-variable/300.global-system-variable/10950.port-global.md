# port

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この変数はV4.3.5 BP1バージョンから導入されました。</li><li>V4.2.x系の他のバージョンでは、この変数はV4.2.5 BP1バージョンから導入されました。V4.2.1バージョンでは、この変数はV4.2.1 BP10バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`port`は、OBServerノードをデプロイする際に、サーバーがTCP/IP接続をリッスンするポート番号を設定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は変更できません。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |  Int             |
| デフォルト値      |  3306  |
| 適用範囲    |  Global  |
| 変更は可能か  | 不可。この変数はOBServerノードのデプロイ時にのみ指定でき、`SET`ステートメントでの変更はサポートされていません。|
| 読み取り専用    | はい       |

## クエリ例

サーバーがTCP/IP接続をリッスンするポート番号を確認します。

```shell
obclient> SHOW VARIABLES LIKE 'port';
```

クエリ結果は次のとおりです：

```shell
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| port          | 2881  |
+---------------+-------+
1 row in set (0.003 sec)
```
