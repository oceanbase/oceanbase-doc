# event_scheduler

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数は、バージョン4.2.4以降で有効になります。 </p>
</main>

## 機能の概要

`event_scheduler`は、サーバー上でイベントスケジューラーが有効になっているかどうかを決定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ** | **説明** |
| -------- | -------- |
| パラメータタイプ   | Bool |
| デフォルト値     | OFF |
| 値の範囲   | <ul><li> OFF：イベントスケジューラーが停止しています。 </li><li> ON：イベントスケジューラーが起動しており、イベントスケジューラースレッドが実行され、すべての計画されたイベントが実行されます。 </li></ul>|
| 適用範囲   | Global |
| 変更は可能か | はい。`SET` ステートメントを使用して変更できます。|

## 設定例

サーバー上でイベントスケジューラーを有効にして実行します。

```shell
obclient> SET GLOBAL event_scheduler = ON;
```
