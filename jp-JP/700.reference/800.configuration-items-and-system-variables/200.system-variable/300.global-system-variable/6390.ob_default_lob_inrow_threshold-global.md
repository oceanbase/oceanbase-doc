# ob_default_lob_inrow_threshold

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数は、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_default_lob_inrow_threshold`は、テーブル作成時に、テーブル内のLOBフィールドのデフォルトの行内ストレージしきい値を指定するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
  </main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要がありますグローバルシステム変数の値を変更するには。

## プロパティの説明

| プロパティ | 説明 |
| ----------| ----- |
| パラメータタイプ | Int |
| デフォルト値 | 8192、単位はバイト <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.x系では、この変数のデフォルト値はV4.2.3以降で4096から8192に調整されました。</li> <li>V4.3.x系では、この変数のデフォルト値はV4.3.2以降で4096から8192に調整されました。</li></ul></main> |
| 値の範囲 | [0, 0.75M] 値が0の場合、INROWを禁止することを意味します。|
| 適用範囲 | <ul><li>Global </li><li>Session </li></ul>|
| 変更は可能か | はい。`SET`または`ALTER SESSION SET`ステートメントを使用して変更できます。|

## 使用方法

* テーブル作成時に`LOB_INROW_THRESHOLD`が指定されていない場合、この変数の値がテーブルスキーマに書き込まれます。
* この変数の値を変更しても、既に作成されたテーブルのINROWしきい値には影響せず、`LOB_INROW_THRESHOLD`が指定されていない新規作成のテーブルにのみ影響します。

## 設定例

`LOB_INROW_THRESHOLD`が指定されていない場合の例は以下のとおりです：

1. `ob_default_lob_inrow_threshold`の値を40960バイトに設定します。

    * セッションレベルでの設定

        ```shell
        obclient> SET ob_default_lob_inrow_threshold = 40960;
        ```

    * グローバルレベルでの設定

        ```shell
        obclient> SET GLOBAL ob_default_lob_inrow_threshold = 40960;
        ```

2. テーブル`t`を作成します。このとき`LOB_INROW_THRESHOLD`は指定されていません。

   ```shell
   obclient> CREATE TABLE t(pk int, data text);
   ```

  その場合、システム変数`ob_default_lob_inrow_threshold`の値がしきい値として使用されます。つまり、テーブル`t`のINROWしきい値は40960バイトになります。
