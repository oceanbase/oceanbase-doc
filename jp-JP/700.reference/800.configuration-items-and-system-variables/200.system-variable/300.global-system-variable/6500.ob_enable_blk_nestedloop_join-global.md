# ob_enable_blk_nestedloop_join

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.x系では対応するロジックが変更されたため、この機能は使用されなくなりました。この変数はV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ob_enable_blk_nestedloop_join`は、block nested loop joinを許可するかどうかを設定します。

## プロパティの説明

|    **プロパティ**    |    **説明**       |
|----------------|-------------------|
| パラメータタイプ        | Bool                                      |
| デフォルト値          | 0                                         |
| 値の範囲        | <ul><li>0：許可されない</li><li>1：許可される</li></ul> |
| 適用範囲        | <ul><li>Global</li><li>SESSION</li></ul>   |
