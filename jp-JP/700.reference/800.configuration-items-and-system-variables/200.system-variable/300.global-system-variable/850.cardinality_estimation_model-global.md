# cardinality_estimation_model

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

`cardinality_estimation_model`は、オプティマイザーが基数推定を行う際に使用する相関仮説を設定します。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>このオプションを本番環境で使用する前に、十分なテストを行ってください。</p>
</main>

## 権限要件

* クエリ変数

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー(Oracleモード)および`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

  * Oracleユーザーテナントは、グローバルシステム変数の値を変更するには`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |   Enum              |
| デフォルト値      |  PARTIAL   |
| 値の範囲    |  <ul><li>INDEPENDENT：述語間が完全に独立していると仮定します。</li><li>PARTIAL: 述語間に一定の相関性があると仮定します。</li><li>FULL：述語間が完全に相関していると仮定します。</li></ul><main id="notice" type='explain'><h4>説明</h4><p>ほとんどのシナリオでは、3種類の相関性の推定結果は順に大きくなります：INDEPENDENT < PARTIAL < FULL。</p></main>              |
| 適用範囲    |  <ul><li>Global</li><li>Session</li></ul>  |
| 変更は可能か  |  はい。`SET` ステートメントを使用して変更できます。 |

## 設定例

3つの相関性仮説の下で、`t1`に対してベーステーブル述語によるフィルタリング後の結果を推定すると、それぞれの結果は `10`, `31`, `98` となります。

1. テーブル `t1` を作成します。

    ```shell
    obclient [test]> create table t1(c1 int, c2 int);
    Query OK, 0 rows affected (0.103 sec)
    ```

2. テーブル `t1` にデータを挿入します。

    ```shell
    obclient [test]> insert into t1 select row_number() over () % 10, row_number() over () % 100 from table(generator(10000));
    Query OK, 10000 rows affected (0.077 sec)
    Records: 10000  Duplicates: 0  Warnings: 0
    ```

3. テーブル `t1` を分析します。

    ```shell
    obclient [test]> analyze table t1;
    Query OK, 0 rows affected (0.073 sec)
    ```

4. 相関性仮説を `INDEPENDENT` に設定し、基数推定を実行します。

    ```shell
    obclient [test]> set cardinality_estimation_model = 'independent';
    Query OK, 0 rows affected (0.001 sec)
    ```

5. 基数推定の結果を照会します。

    ```shell
    obclient [test]> explain select * from t1 where c1 = 1 and c2 = 1;
    ```
