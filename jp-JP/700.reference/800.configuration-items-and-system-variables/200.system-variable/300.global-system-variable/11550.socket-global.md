# socket

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.2.5バージョンでは、この変数はV4.2.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`socket`は、ローカルクライアントが接続する`Socket`ファイルの名前を照会するために使用されます。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は変更をサポートしていません。

## プロパティの説明

| **プロパティ** | **説明** |
|-----------|---------------|
| パラメータタイプ | Varchar              |
| デフォルト値 | /run/sql.sock   |
| 適用範囲 | グローバル  |
| 変更は可能か | 不可。この変数は読み取り専用です。       |

## クエリ例

ローカルクライアントが接続する`socket`ファイルの名前を照会します。

```shell
obclient> SHOW VARIABLES LIKE 'socket';
```

クエリ結果は次のとおりです：

```shell
+---------------+------------------------------------+
| Variable_name | Value                              |
+---------------+------------------------------------+
| socket        | /home/admin/oceanbase/run/sql.sock |
+---------------+------------------------------------+
1 row in set (0.003 sec)
```
