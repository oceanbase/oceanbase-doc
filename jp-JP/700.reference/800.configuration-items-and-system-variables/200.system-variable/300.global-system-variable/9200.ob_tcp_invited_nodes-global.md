# ob_tcp_invited_nodes

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_tcp_invited_nodes`はテナントのIPアローリストを設定します。パーセント記号（%）、ハイフン（_）、IPアドレス（複数のIPアドレスはカンマで区切る）をサポートしており、IPリストマッチング、マスクマッチング、あいまいマッチングが可能です。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

  * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要があります。

## プロパティの説明

| **プロパティ** |        **説明**            |
|----------|----------------------------|
| パラメータタイプ    | Varchar       |
| デフォルト値      | 127.0.0.1,::1 |
| 値の範囲    | 文字列長が65536未満 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.1 BP1以降、値の範囲は「文字列長が4096未満」から「文字列長が65536未満」に調整されました。</p></main> |
| 適用範囲    | Global  |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

テナントのIPアローリストを127.0.0.1に設定します。

```shell
obclient> SET GLOBAL ob_tcp_invited_nodes='127.0.0.1';
```
