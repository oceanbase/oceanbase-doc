# query_cache_size

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`query_cache_size`は、履歴的なクエリ結果を格納するために割り当てるメモリのサイズを設定します。これは未使用のメモリであり、単位はByteです。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この変数は現在、有効ではありません。</p>
  </main>

## プロパティの説明

| **プロパティ** |           **説明**            |
|--------|-----------------------------|
| パラメータタイプ   | Uint                        |
| デフォルト値    | 0                     |
| 値の範囲   | \[0, 18446744073709551615\] |
| 適用範囲    | Global |
