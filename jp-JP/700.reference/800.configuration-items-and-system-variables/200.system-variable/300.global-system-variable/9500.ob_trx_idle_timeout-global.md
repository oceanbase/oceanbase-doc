# ob_trx_idle_timeout

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_trx_idle_timeout`は、トランザクションのアイドルタイムアウト時間を設定します。これは、トランザクション内の2つのステートメント間の実行間隔がこの値を超えた場合にタイムアウトするまでの時間です。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>分散トランザクションルーティングを有効にした後は、<code>ob_trx_idle_timeout</code>変数の設定は無効になります。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要があります。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  |      **説明**            |
|-----------|--------------------------|
| パラメータタイプ    | Int                     |
| デフォルト値      | 86400000000、単位はマイクロ秒です。 <main id="notice" type='explain'><h4>説明</h4><p>この変数はV4.0.0バージョン以降、デフォルト値が120000000から86400000000に調整されました。</p></main>    |
| 値の範囲    | [100000000，+∞)         |
| 適用範囲    | <ul><li>Global</li><li>Session</li></ul>     |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

トランザクションのアイドルタイムアウト時間を86400000000マイクロ秒に設定します。

* セッション変更

  ```shell
  obclient> SET ob_trx_idle_timeout =86400000000;
  ```

* グローバル変更

  ```shell
  obclient> SET GLOBAL ob_trx_idle_timeout =86400000000;
  ```
