# plugin_dir

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`plugin_dir`は、プラグインDLLが保存されているパスを確認するために使用します。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は変更できません。

## プロパティの説明

| **プロパティ** |    **説明**     |
|--------|---------------|
| パラメータタイプ   | Varchar       |
| デフォルト値    | ./plugin_dir/ |
| 適用範囲   | Global        |
| 変更は可能か  | 不可。`SET`ステートメントを使用した変更はサポートされていません。          |
| 読み取り専用か    | はい |
