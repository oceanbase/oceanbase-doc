# ob_compatibility_control

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この変数はV4.3.2バージョンから導入されました。</li><li>V4.2.x系では、この変数はV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`ob_compatibility_control`は、MYSQL5.7およびMYSQL8.0との互換性に衝突がある場合の動作パターンを制御します。`ob_compatibility_control`の値をMYSQL5.7に設定しても、動作上の衝突がないMYSQL8.0の機能の使用には影響しません。テナント作成時に互換モードを指定し、テナント作成後は変更できません。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は、テナント作成後はSQLステートメントでの変更をサポートしていません。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    |    Enum              |
| デフォルト値      |  MYSQL5.7  |
| 値の範囲    | ["MYSQL5.7"，"MYSQL8.0"]              |
| 適用範囲    |  Global |
| 変更は可能か  | 不可。この変数はテナント作成時にのみ指定でき、テナント作成後は`SET`または`ALTER SESSION SET`ステートメントで変更することはできません。|
| 読み取り専用か    | はい  |

## 使用方法

* この変数がないテナントを、この変数が制御するバージョンにアップグレードする場合、この変数はデフォルト値`MYSQL5.7`を取得します。新規テナントの場合は、互換モードを指定できます。

* 過去のバージョンで既にMySQL 8.0として実装されていた機能については、`ob_compatibility_version < 4.2.3`の場合、`ob_compatibility_control`の値に関係なく、MySQL 8.0と互換性があります。

## 設定例

テナント作成時に互換モードをMySQL 5.7に指定します。

```shell
obclient> create tenant tenant_m57 zone_list=('z1'),primary_zone='z1',resource_pool_list=('pool1') set ob_compatibility_mode='mysql',ob_compatibility_control='MYSQL5.7',ob_tcp_invited_nodes='%';
```
