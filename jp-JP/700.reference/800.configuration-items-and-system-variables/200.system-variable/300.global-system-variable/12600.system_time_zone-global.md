# system_time_zone

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`system_time_zone`は、サーバーのシステム時区を設定します。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー(Oracleモード)および`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は、テナントが作成された後、SQLステートメントを使用して変更することはサポートされていません。

## プロパティの説明

| **プロパティ** | **説明** |
|---------|-----------------------------------------------------------|
| パラメータタイプ | varchar |
| デフォルト値 | CST |
| 値の範囲 | <ul><li> 数値範囲：\[-12:59,+13:00\]。 </li> <li> CDT（中部夏時間）、CST（中国標準時）などのタイムゾーン地域。 </li> </ul> |
| 適用範囲 | グローバル |
| 変更は可能か | 不可。この変数はテナント作成時に指定する必要があり、テナント作成後はSQL文で変更できません。 |
