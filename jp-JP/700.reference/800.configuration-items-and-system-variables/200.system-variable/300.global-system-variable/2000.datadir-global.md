# datadir

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この変数は互換性のためにのみ使用され、OceanBaseデータベースでは現在この変数の機能は実装されていません。</p>
  </main>

## 機能の概要

`datadir`は、データが保存されているローカルディスクのパスを確認するために使用されます。

## 権限要件

`sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

## プロパティの説明

| **プロパティ** |         **説明**         |
|--------|------------------------|
| パラメータタイプ   | varchar                |
| デフォルト値    | /usr/local/mysql/data/ |
| 値の範囲   | N/A                    |
| 適用範囲   | Global                 |
| 変更は可能か  | 不可                      |
