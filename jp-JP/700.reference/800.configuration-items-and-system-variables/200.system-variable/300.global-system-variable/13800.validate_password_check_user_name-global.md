# validate_password_check_user_name

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`validate_password_check_user_name`は、ユーザーのパスワードがユーザー名と同じであってもよいかどうかを設定します。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

  * Oracleユーザーテナントは、グローバルシステム変数の値を変更するには`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ**  |                                                              **説明**                                                               |
|---------|-----------------------------------------------------------------------------------------------------------------------------------|
| パラメータタイプ    | Enum                                           |
| デフォルト値     | on                                            |
| 値の範囲    | <ul><li>on：ユーザーのパスワードはユーザー名と同じにできないことを示します </li><li>off：ユーザーのパスワードはユーザー名と同じにできることを示します </li></ul>    |
| 適用範囲    | Global                                         |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

この変数は [validate_password_policy](14200.validate_password_policy-global.md) 変数と組み合わせて使用する必要があります。[validate_password_policy](14200.validate_password_policy-global.md) の値が `MEDIUM` の場合にのみ、この変数が有効になります。

## 設定例

ユーザーのパスワードは、ユーザー名と同じに設定できません。

```shell
obclient> SET GLOBAL validate_password_check_user_name = on;
```
