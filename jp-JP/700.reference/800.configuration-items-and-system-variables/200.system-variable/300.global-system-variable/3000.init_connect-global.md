# init_connect

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はMySQL 5.7との互換性を確保するためにのみ使用され、関連機能はサポートされていません。クエリや設定は可能ですが、設定した内容はエラー報告はされませんが有効にはなりません。</p>
</main>

## 機能の概要

`init_connect`は、サーバーが各接続のクライアントに対して実行する文字列を設定します。この文字列は、複数のSQL文で構成され、セミコロンで区切られます。

## プロパティの説明

| **プロパティ** | **説明** |
|-----------|---------------|
| パラメータタイプ | Varchar |
| 適用範囲 | グローバル |
| 変更は可能か | はい。`SET` ステートメントを使用して変更できます。|
