# ob_enable_hash_group_by

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>V4.x系のシステムアーキテクチャ最適化に伴い、関連機能は使用されなくなりました。この構成パラメータはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ob_enable_hash_group_by`は、Hash Group byのパスを有効にするかどうかを設定します。

## プロパティの説明

|  **プロパティ**  |       **説明**       |
|------------|----------------------|
| パラメータタイプ     | Bool                 |
| デフォルト値       | 1                    |
| 値の範囲     | <ul><li>0：不可</li><li>1：可</li></ul>|
| 適用範囲     | <ul><li>Global </li><li>Session </li></ul>   |
