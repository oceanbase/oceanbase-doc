# log_row_value_options

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`log_row_value_options`は、LOBデータに対して部分更新を有効にするかどうかを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントがグローバルシステム変数の値を変更するには、`SUPER`または`ALTER SYSTEM`権限が必要です。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントにおけるセッションシステム変数の値を直接変更できます。

## プロパティの説明

|**プロパティ**| **説明**|
|--------|---------|
|パラメータタイプ |Varchar  |
|デフォルト値   | 空文字列 |
|値の範囲 |['', 'partial_json']<ul><li><code>''</code>：空文字列。部分更新機能を無効にすることを示します。</li><li>JSON部分更新機能を有効にすることを示します。</li></ul>|
|適用範囲 |<ul><li>Global</li><li>Session</li></ul>|
| 変更は可能か| はい。SETステートメントを使用して変更できます。|

## 使用方法

`partial_json`に設定すると、JSON部分更新機能が有効になります。`json_set/json_remove/json_replace`式を使用してJSON型データを更新する際、増分更新ではなく部分更新が実行され、大規模なJSONデータの更新パフォーマンスが向上します。

## 設定例

LOBデータに対して部分更新を有効にし、JSON部分更新機能を有効にします。

* セッション変更

  ```shell
  obclient> SET log_row_value_options="partial_json";
  ```

* グローバル変更

  ```shell
  obclient> SET GLOBAL log_row_value_options="partial_json";
  ```
