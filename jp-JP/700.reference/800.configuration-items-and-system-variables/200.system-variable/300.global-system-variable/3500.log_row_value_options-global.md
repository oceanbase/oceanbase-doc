# log_row_value_options

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この変数はV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、この変数はV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`log_row_value_options`は、LOBが部分的更新を使用するかどうかを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自身のテナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

|**プロパティ**| **説明**|
|--------|---------|
|パラメータタイプ |varchar  |
|デフォルト値   | 空文字列 |
|値の範囲 |['', 'partial_json']<ul><li><code>''</code>：空文字列で、部分的な更新機能を無効にすることを示します。</li><li>JSONパーシャルアップデート機能を有効にすることを示します。</li></ul>|
|適用範囲 |<ul><li>Global</li><li>Session</li></ul>|
| 変更は可能か | はい。SETステートメントを使用して変更できます。|

## 使用方法

`partial_json`に設定すると、JSONの部分的更新機能が有効になります。これにより、`json_set/json_remove/json_replace`式を使用してJSON型データを更新する際に、増分更新ではなく部分的更新が使用されるため、大規模なJSONデータの更新パフォーマンスが向上します。

## 設定例

LOBに部分的更新を使用し、JSONの部分的更新機能を有効にします。

* セッション有効

    ```shell
    obclient> SET log_row_value_options="partial_json";
    ```

* グローバル有効

    ```shell
    obclient> SET GLOBAL log_row_value_options="partial_json";
    ```
