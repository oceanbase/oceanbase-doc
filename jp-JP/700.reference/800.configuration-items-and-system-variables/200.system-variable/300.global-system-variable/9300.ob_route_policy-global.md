# ob_route_policy

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_route_policy`は、OBServerノード内でデータレプリカを選択するためのルーティングポリシーを設定します。

## プロパティの説明

|  **プロパティ**  |       **説明**      |
|------------|---------------------|
| パラメータタイプ     | Enum  |
| デフォルト値       | 1     |
| 値の範囲     | <ul><li> 1（`READONLY_ZONE_FIRST`）：読み取り専用レプリカが存在するゾーンを優先 </li>  <li> 2（`ONLY_READONLY_ZONE`）：読み取り専用レプリカが存在するゾーンにのみ送信  </li>  <li> 3（`UNMERGE_ZONE_FIRST`）：コンパクション状態にないレプリカが存在するゾーンを優先  </li> <li> 4（`UNMERGE_FOLLOWER_FIRST`）：コンパクション状態にないフォロワーレプリカを優先</li> <li>5（`FORCE_READONLY_ZONE`）：すべての読み取り専用リクエストは、読み取り専用でないレプリカに転送されません</li></ul>   |
| 適用範囲     |  <ul><li>Global </li><li>Session </li></ul>                                                                   |
| 変更は可能か   | はい。`SET` ステートメントを使用して変更できます。|

## 設定例

OBServerノード内でデータレプリカを選択するためのルーティングポリシーを、読み取り専用レプリカが存在するゾーンを優先するように設定します。

* セッション有効

  ```shell
  obclient> SET ob_route_policy = 'READONLY_ZONE_FIRST';
  ```

  または

  ```shell
  obclient> SET ob_route_policy = 1;
  ```

* グローバル有効

  ```shell
  obclient> SET GLOBAL ob_route_policy = 'READONLY_ZONE_FIRST';
  ```

  または

  ```shell
  obclient> SET GLOBAL ob_route_policy = 1;
  ```
