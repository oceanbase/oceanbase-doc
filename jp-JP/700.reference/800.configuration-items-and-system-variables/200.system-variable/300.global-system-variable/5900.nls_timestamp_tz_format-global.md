# nls_timestamp_tz_format

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`nls_timestamp_tz_format`は、timestamp tz型からstrへのフォーマット、およびstrからtimestamp tz型への暗黙的な変換のフォーマットを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限が必要です。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントに属するセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---------|---------------|
| パラメータタイプ    | varchar                 |
| デフォルト値     | DD-MON-RR HH.MI.SSXFF AM TZR    |
| 適用範囲    | <ul><li>Global </li><li>Session </li></ul>   |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

この変数は、`to_CHAR`および`to_timestamp_TZ`関数と共に使用するデフォルトのタイムゾーン形式のタイムスタンプを指定します。一般的な値は`YYYY-MM-DD HH24:MI:SS.FF TZR TZD`です。

## 設定例

* セッション有効

  ```shell
  obclient> SET nls_timestamp_tz_format='YYYY-MM-DD HH24:MI:SS.FF TZR TZD';
  ```

* グローバル有効

  ```shell
  obclient> SET GLOBAL nls_timestamp_tz_format='YYYY-MM-DD HH24:MI:SS.FF TZR TZD';
  ```
