# ob_enable_truncate_flashback

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数は、現在では使用されていません。V4.x系では、TRUNCATE TABLE操作による削除は、もはやゴミ箱に移動することはサポートされなくなりました。V4.x系でもこの変数はクエリや設定が可能ですが、関連する機能は有効になりません。</p>
</main>

## 機能の概要

`ob_enable_truncate_flashback`は、テーブルのトランケーションによるフラッシュバックを有効にするかどうかを設定します。

## プロパティの説明

| **プロパティ** |    **説明**      |
|----------|------------------|
| パラメータタイプ   | Bool                         |
| デフォルト値     | OFF                          |
| 値の範囲   | <ul><li>OFF（0）：無効</li><li>ON（1）：有効</li></ul>     |
| 適用範囲   | <ul><li>Global</li><li>Session</li></ul>          |
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます。|
