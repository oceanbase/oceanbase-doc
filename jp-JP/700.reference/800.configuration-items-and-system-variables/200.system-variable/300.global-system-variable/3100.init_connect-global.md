# init_connect

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はMySQL 5.7との互換性のためにのみ使用され、関連する機能はサポートされていません。クエリや設定は可能ですが、設定してもエラーは報告されず、実際には反映されません。</p>
</main>

## 機能の概要

`init_connect`は、サーバーが各接続のクライアントに対して実行する文字列を設定します。この文字列は、セミコロンで区切られた1つまたは複数のSQLステートメントで構成されます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ     | Varchar |
| 適用範囲     | Global   |
| 変更は可能か   | はい。`SET`ステートメントを使用して変更できます。|
