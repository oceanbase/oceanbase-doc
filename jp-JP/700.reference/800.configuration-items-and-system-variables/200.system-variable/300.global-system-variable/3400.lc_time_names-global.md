# lc_time_names

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

`lc_time_names`は、日付と月の名前および略称を表示する言語を制御します。

<main id="notice">
  <h4>適用対象</h4>
    <p>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自テナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
|---------|---------------|
| パラメータタイプ | Varchar |
| デフォルト値 | en_US |
| 値の範囲 | <ul><li>en_US：英語 </li><li>ja_JP：日本語 </li><li>ko_KR：韓国語 </li><li>zh_CN：中国語 </li><li>zh_TW：中国台湾 </li></ul> |
| 適用範囲 | <ul><li>Global </li><li>Session </li></ul> |
| 変更は可能か | はい。`SET` ステートメントを使用して変更できます。|

## 使用方法

この変数は`DATE_FORMAT()`、`DAYNAME()`、および`MONTHNAME()`関数の出力に影響しますが、`STR_TO_DATE()`または`GET_FORMAT()`関数の結果には影響しません。

* `DATE_FORMAT()`関数

  `lc_time_names`変数は、この関数において出力文字列で使用される月と曜日の名前の言語と形式に影響します。`en_US`モードでは、英語の命名規則に基づいて月と曜日の名前が出力されます。`zh_CN`モードでは、中国語の命名規則に基づいて名前が出力されます。

* `DAYNAME()`関数

  `lc_time_names`変数は、この関数において返される曜日の名前の言語と形式に影響します。`en_US`モードでは、英語の曜日の名前が返されます。`zh_CN`モードでは、中国語の曜日の名前が返されます。

* `MONTHNAME()`関数

  `lc_time_names`変数は、この関数において返される月の名前の言語と形式に影響します。`en_US`モードでは、英語の月の名前が返されます。`zh_CN`モードでは、中国語の月の名前が返されます。

## 設定例

ある日付関数の結果を中国語で表示する例を挙げます：

1. 日付と月の名称および略称を表示する言語を中国語に設定します。

    * セッション有効

      ```shell
      obclient> SET lc_time_names='zh_CN';
      ```

    * グローバル有効

      ```shell
      obclient> SET GLOBAL lc_time_names='zh_CN';
      ```

2. 現在の `lc_time_names` の値を確認します。

    ```sehll
    obclient> show variables like "lc_time_names";
    ```

    実行結果は次のとおりです：

    ```sehll
    +---------------+-------+
    | Variable_name | Value |
    +---------------+-------+
    | lc_time_names | zh_CN |
    +---------------+-------+
    1 row in set (0.015 sec)
    ```

3. 関数を使用して対応する日付を照会します。

   * `DATE_FORMAT()` 関数を使用して、入力された日付に対応するフォーマットで表示します。

       ```sehll
       obclient> select DATE_FORMAT('2023-01-06','%Y-%m-%d');
       ```

       実行結果は次のとおりです：

       ```sehll
      +--------------------------------------+
      | DATE_FORMAT('2023-01-06','%Y-%m-%d') |
      +--------------------------------------+
      | 2023-01-06                           |
      +--------------------------------------+
      1 row in set (0.001 sec)
       ```

   * `DAYNAME()` 関数を使用して、入力された日付に対応する曜日名を照会します。

       ```sehll
       obclient> select DAYNAME('2023-01-06');
       ```

       実行結果は次のとおりです：

       ```sehll
       +-----------------------+
       | DAYNAME('2023-01-06') |
       +-----------------------+
       | 金曜日                |
       +-----------------------+
       1 row in set (0.000 sec)
       ```

   * `MONTHNAME()` 関数を使用して、入力された日付に対応する月を照会します。

       ```sehll
       obclient> select MONTHNAME('2023-01-06');
       ```

       実行結果は次のとおりです：

       ```sehll
        +-------------------------+
        | MONTHNAME('2023-01-06') |
        +-------------------------+
        | 一月                    |
        +-------------------------+
        1 row in set (0.001 sec)
       ```
