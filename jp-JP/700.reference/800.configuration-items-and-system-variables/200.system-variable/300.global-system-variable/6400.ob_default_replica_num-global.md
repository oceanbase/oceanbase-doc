# ob_default_replica_num

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V3.x系のシステムアーキテクチャ最適化に伴い、関連機能は廃止されました。この構成パラメータはV3.2.1以降のバージョンから非推奨となっています。</p>
</main>

## 機能の概要

`ob_default_replica_num`は、各クラスタ内のテーブルのデフォルトレプリカ数を設定します。

## プロパティの説明

| **プロパティ**  |    **説明**     |
|-----------|-----------------|
| パラメータタイプ   | Int     |
| デフォルト値     | 1   |
| 値の範囲   | [1, 7] |
| 適用範囲   | <ul><li>Global </li><li>Session </li></ul>    |
