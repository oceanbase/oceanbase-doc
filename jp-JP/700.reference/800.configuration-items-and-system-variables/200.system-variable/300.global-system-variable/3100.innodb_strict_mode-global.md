# innodb_strict_mode

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`innodb_strict_mode`は、特定の構文に対するSQLチェックモードを設定します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー(Oracleモード)および`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー(Oracleモード)および`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要がありますグローバルシステム変数の値を変更するには。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要がありますグローバルシステム変数の値を変更するには。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自テナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
|-----------|---------------|
| パラメータタイプ | Bool |
| デフォルト値 | 1 |
| 値の範囲 | <ul><li>1：厳密モードを使用することを示します。`CREATE TABLE`、`ALTER TABLE`、および`CREATE INDEX`ステートメントを使用する際、特定のシナリオでのエラー（例えば`ROW_FORMAT`がサポートされていない場合など）に対して警告メッセージが表示されることなく、直接エラーが報告されます。</li><li>0：非厳密モードを使用することを示します。緩やかな構文チェックを行い、誤った構文に対してはデフォルトの構文を使用します。</li></ul> |
| 適用範囲 | <ul><li>Global</li><li>Session</li></ul> |
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます。 |
| NULL値は許容されるか | 不可 |

## 設定例

特定の構文に対するSQLチェックモードを1に設定します。

* グローバル有効

   ```shell
   obclient> SET GLOBAL innodb_strict_mode =1;
   ```

* セッション有効

   ```shell
   obclient> SET innodb_strict_mode =1;
   ```
