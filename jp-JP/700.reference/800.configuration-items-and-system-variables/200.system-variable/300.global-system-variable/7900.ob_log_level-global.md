# ob_log_level

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_log_level`はセッションレベルのログレベルを設定します。指定しない場合、システムのログレベルが使用されます。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要があります。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自身のテナントに属するセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** |        **説明**            |
|----------|----------------------------|
| パラメータタイプ    | Varchar               |
| デフォルト値      | disabled、セッションレベルのログを無効にすることを示します              |
| 値の範囲    | <ul><li>trace：最も詳細なログレベルで、イベントの詳細を記録します(開発デバッグによく使用されます) </li> <li>info：通常の情報レベルで、通常の実行状態を記録します(本番環境でよく使用されます) </li><li>warn：警告レベルで、システムの安定性に影響を与える可能性のある異常(設定問題など)を記録します </li><li>error：エラーレベルで、重大な障害(サービス利用不可など)のみを記録します </li></ul>       |
| 適用範囲    | <ul><li>Global</li> <li>Session </li></ul>    |
| 変更は可能か  | はい。`SET` ステートメントを使用して変更できます。|

## 使用方法

`ob_log_level` の値が `disabled` の場合、システム全体のログレベルが使用され、このログレベルはパラメータ [syslog_level](../../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22200.syslog_level.md) によって制御されます。

## 設定例

セッションレベルのログレベルを INFO に設定します。

* セッションにのみ適用

  ```shell
  obclient> SET ob_log_level ='INFO';
  ```

* グローバルに適用

  ```shell
  obclient> SET GLOBAL ob_log_level ='INFO';
  ```
