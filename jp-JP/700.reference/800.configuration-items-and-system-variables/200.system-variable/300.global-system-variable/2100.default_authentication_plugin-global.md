# default_authentication_plugin

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`default_authentication_plugin`は、新規ユーザーがデフォルトで使用する認証プラグインを設定します。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

  * Oracleユーザーテナントは、グローバルシステム変数の値を変更するには`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ**  |   **説明**    |
|---------|---------------|
| パラメータタイプ    |  Varchar(64)    |
| デフォルト値      | '' （または `DEFAULT`、''と同じ）  |
| 値の範囲    | パスワードのHASH計算に使用されるプラグイン名を記録します。現在、以下の4種類の設定のみが許可されています：<ul><li>空文字列 (<code>mysql_native_password</code>と同じ)</li><li><code>ob_native_password</code> (Oracleモード用、<code>mysql_native_password</code>と同等)</li><li><code>mysql_native_password</code> (MySQLモード用)</li><li><code>caching_sha2_password</code></li></ul><main id="notice" type='explain'><h4>説明</h4><p><code>caching_sha2_password</code> の値はV4.4.2 BP2バージョンから導入されました。</p></main>   |
| 適用範囲    | Global      |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

新規ユーザーのデフォルト認証プラグインを `caching_sha2_password` プラグインに設定します。

```shell
obclient> SET default_authentication_plugin = 'caching_sha2_password';
```
