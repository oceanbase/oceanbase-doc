# sql_safe_updates

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`sql_safe_updates`は、MySQLのSQLセーフモードを有効にするかどうかを設定します。デフォルトは無効です。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数は互換性のためにのみ使用されます。OceanBaseデータベースでは、現在この変数の機能は実装されていません。</p>
</main>

## プロパティの説明

| **プロパティ**  |               **説明**                 |
|---------|------------------------------------------|
| パラメータタイプ    | Bool                                  |
| デフォルト値     | 0                                     |
| 値の範囲    | <ul><li>0：FALSE、つまり無効を示します。 </li><li>1：TRUE、つまり有効を示します。 </li></ul>    |
| 適用範囲    | <ul><li>Global   </li><li>Session </li></ul>   |
