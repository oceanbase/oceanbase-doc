# read_only

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`read_only`は、テナントが読み取り専用モードかどうかを設定します。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

  * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要があります。

## プロパティの説明

| **プロパティ** |                                                     **説明**                                                      |
|--------|-----------------------------------------------------------------------------------------------------------------|
| パラメータタイプ   | Bool                         |
| デフォルト値     | OFF                            |
| 値の範囲   | <ul><li>`ON`：テナントは読み取り専用モード</li><li>`OFF`：テナントは読み書きモード</li></ul>   |
| 適用範囲      | Global                                    |
| 変更は可能か    | はい。`SET`ステートメントを使用して変更できます。               |

## 使用方法

この変数を設定すると、そのテナント内のすべての通常ユーザーに影響しますが、root権限を持つユーザーには影響しません。

## 設定例

テナントを読み書きモードに設定します。

```shell
obclient> SET GLOBAL read_only = OFF;
```
