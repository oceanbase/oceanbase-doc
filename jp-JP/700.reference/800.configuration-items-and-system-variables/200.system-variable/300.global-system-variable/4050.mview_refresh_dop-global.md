# mview_refresh_dop

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.3.5バージョンでは、この変数はV4.3.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`mview_refresh_dop`は、マテリアライズドビューのデフォルトのリフレッシュ並列度を制御します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限が必要です。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自身のテナントにおけるセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  | **説明** |
|-----------|----------|
| パラメータタイプ   | Int |
| デフォルト値     | 4 |
| 値の範囲   | [0, uint64_max] |
| 適用範囲   | <ul><li>Global</li><li>SESSION</li></ul>|
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます |

## 使用方法

1. セッションレベルの設定：

   現在のセッションで`mview_refresh_dop`を設定することで、そのセッション内のマテリアライズドビューのデフォルトのリフレッシュ並列度を制御します。その後、このセッションで発生するマテリアライズドビューの手動リフレッシュで、並列度が明示的に指定されていない場合は、この値が使用されます。

2. グローバルレベルの設定：

   グローバルな`mview_refresh_dop`を設定すると、手動および自動のマテリアライズドビューのリフレッシュを含む、すべてのセッションに影響します。今後、すべてのセッションがマテリアライズドビューのリフレッシュを開始する際、並列度が明示的に指定されていない場合は、この値が使用されます。

3. `mview_refresh_dop`を0または1に設定した場合、並列リフレッシュ機能は使用されません。

## 設定例

* 現在のセッションのデフォルトリフレッシュ並列度を設定します。

  ```shell
  obclient> SET mview_refresh_dop = 5;
  ```

* グローバルデフォルトリフレッシュ並列度を設定します。

  ```shell
  obclient> SET GLOBAL mview_refresh_dop = 5;
  ```
