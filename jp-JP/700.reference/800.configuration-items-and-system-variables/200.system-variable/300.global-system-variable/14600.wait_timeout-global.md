# wait_timeout

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`wait_timeout`は、サーバーが非対話型接続を閉じる前にアクティビティを待つ秒数を設定します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバルに適用

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントがグローバルシステム変数の値を変更するには、`SUPER`または`ALTER SYSTEM`権限が必要です。

    * Oracleユーザーテナントがグローバルシステム変数の値を変更するには、`ALTER SYSTEM`権限が必要です。

  * セッションに適用

    `sys`テナントとすべてのユーザーテナントは、自身のテナントに属するセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** |        **説明**            |
|--------|------------------------------|
| パラメータタイプ   | Int                     |
| デフォルト値    | 28800、単位は秒                   |
| 値の範囲   | \[1, 31536000\]         |
| 適用範囲   | <ul><li>Global</li> <li>Session </li></ul>    |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

セッション起動時、システムはグローバル `wait_timeout` の値またはグローバル `interactive_timeout` の値に基づいて、セッションの `wait_timeout` 値を初期化します。具体的にグローバル `wait_timeout` の値を使用するか、グローバル `interactive_timeout` の値を使用するかは、クライアントタイプによって決まります。クライアントタイプは `mysql_real_connect()` の接続オプション `CLIENT_INTERACTIVE` によって定義されます。`interactive_timeout` 変数の詳細については、[interactive_timeout](../300.global-system-variable/3300.interactive_timeout-global.md)を参照してください。

OceanBaseデータベースのOracleモードでは、セッションのアイドルタイムアウトは、ユーザーが属するプロファイル内の `IDLE_TIME` パラメータの影響も受け、`IDLE_TIME` の優先順位は `wait_timeout` より高いです。`IDLE_TIME` が正の整数（単位：分）の場合、セッションのアイドル時間がその時間を超えると、`wait_timeout` よりも優先して適用され、データベースが自動的に接続を切断します。`IDLE_TIME` が `0` または明示的に設定されていない場合、このパラメータは無効となり、アイドルタイムアウトは元の判定に戻ります。非対話型接続は `wait_timeout` が、対話型接続は `interactive_timeout` が制御します。`IDLE_TIME` が `UNLIMITED` の場合、セッションはアイドルタイムアウトで切断されません。

プロファイル内の `IDLE_TIME` パラメータの詳細については、[CREATE PROFILE](../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1900.create-profile-of-oracle-mode.md)および[DBA_PROFILES](../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/18000.dba_profiles-of-oracle-mode.md)を参照してください。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>プロファイルの <code>IDLE_TIME</code> パラメータは、OceanBaseデータベースのOracleモードでのみ有効です。V4.4.x系では、V4.4.2 BP4バージョンからサポートされています。このパラメータは接続確立時に一度読み込まれ、変更後は新規作成されるセッションにのみ反映されます。</p>
</main>

## 設定例

サーバーが非対話型接続を閉じる前にアクティビティを待つ時間を1800秒、すなわち30分に設定します。

* セッションに適用

  ```shell
  obclient> SET wait_timeout =1800;
  ```

* グローバルに適用

  ```shell
  obclient> SET GLOBAL wait_timeout =1800;
  ```
