# wait_timeout

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`wait_timeout`は、サーバーが非対話型接続を閉じる前にアクティブな接続を待機させる秒数を設定します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要があります。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントに属するセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** |        **説明**            |
|--------|------------------------------|
| パラメータタイプ   | Int                     |
| デフォルト値    | 28800、単位は秒                   |
| 値の範囲   | \[1, 31536000\]         |
| 適用範囲   | <ul><li>Global</li> <li>Session </li></ul>    |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

セッション起動時、システムはグローバル `wait_timeout` の値またはグローバル `interactive_timeout` の値に基づいて、セッションの `wait_timeout` 値を初期化します。具体的にグローバル `wait_timeout` の値を優先するか、グローバル `interactive_timeout` の値を優先するかは、クライアントタイプによって決まります。クライアントタイプは `mysql_real_connect()` の接続オプション `CLIENT_INTERACTIVE` によって定義されます。`interactive_timeout` 変数の詳細については、[interactive_timeout](../300.global-system-variable/3300.interactive_timeout-global.md)を参照してください。

## 設定例

サーバーが非対話型接続を閉じる前にアクティブな接続を待機させる時間を1800秒、すなわち30分に設定します。

* セッション適用

  ```shell
  obclient> SET wait_timeout =1800;
  ```

* グローバル適用

  ```shell
  obclient> SET GLOBAL wait_timeout =1800;
  ```
