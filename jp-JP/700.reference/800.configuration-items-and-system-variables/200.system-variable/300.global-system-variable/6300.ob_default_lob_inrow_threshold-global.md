# ob_default_lob_inrow_threshold

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_default_lob_inrow_threshold`は、テーブル作成時に、そのテーブルのLOBフィールドのデフォルトの行内ストレージしきい値を指定するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
  </main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントにおけるセッションシステム変数の値を直接変更できます。

## プロパティの説明

| プロパティ    | 説明 |
| ----------| ----- |

## 使用方法

`ob_default_lob_inrow_threshold`はグローバルレベルのシステム変数であり、実際に影響を受けるのは新規作成されるテーブル（既存のテーブルは影響を受けない）のテーブルレベルプロパティ`lob_inrow_threshold`の値です。システム変数`ob_default_lob_inrow_threshold`を変更すると、新規作成されるテーブルのLOB列のインライン/アウトラインストレージのしきい値に影響します。テーブルレベルプロパティ`lob_inrow_threshold`を変更すると、そのテーブルのインライン/アウトラインストレージに影響します。テーブル作成時に`lob_inrow_threshold`を指定しなかった場合、システム変数ob_default_lob_inrow_threshold`の値がそのテーブルのLOB列のインライン/アウトラインストレージのしきい値として使用されます。

## 設定例

`LOB_INROW_THRESHOLD`が指定されていない例を以下に示します：

1. `ob_default_lob_inrow_threshold`の値を40960バイトに設定します。

   * セッションレベルでの設定

     ```shell
     obclient> SET ob_default_lob_inrow_threshold = 40960;
     ```

   * グローバルレベルでの設定

     ```shell
     obclient> SET GLOBAL ob_default_lob_inrow_threshold = 40960;
     ```

2. テーブル`t`を作成します。この時点で`LOB_INROW_THRESHOLD`は指定されていません。

   ```shell
   obclient> CREATE TABLE t(pk int, data text);
   ```

   そのため、システム変数`ob_default_lob_inrow_threshold`の値がしきい値として使用され、テーブル`t`のINROWしきい値は40960バイトとなります。
