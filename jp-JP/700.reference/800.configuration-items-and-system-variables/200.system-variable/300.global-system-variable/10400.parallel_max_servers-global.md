# parallel_max_servers

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数は現在のバージョンでは使用されなくなりました。<a href="10600.parallel_servers_target-global.md">parallel_servers_target</a> 変数を使用して、パラレル実行のリソース使用量を制御してください。</p>
</main>

## 機能の概要

`parallel_max_servers`は、各サーバー上のパラレル実行(Parallel eXecution、PX)スレッドプール内の最大スレッド数を設定します。

## プロパティの説明

| **プロパティ**  |   **説明**    |
|---------|-------------|
| パラメータタイプ    | Int         |
| デフォルト値     | 0           |
| 値の範囲    | \[0, 1800\] |
| 適用範囲    | Global      |
