# ob_enable_parameter_anonymous_block

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_enable_parameter_anonymous_block`は、グローバルな匿名ブロックパラメータ化機能を有効にするかどうかを設定します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限が必要です。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントにおけるセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---------|---------------|
| パラメータタイプ    |    bool              |
| デフォルト値     |  ON  |
| 値の範囲    | <ul><li>ON：有効  </li><li>OFF：無効 </li></ul>                   |
| 適用範囲    |  <ul><li>Global  </li><li>Session </li></ul>|
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます。|

## 使用方法

`ob_enable_parameter_anonymous_block`システム変数を使用して、匿名ブロックのパラメータ化機能を有効にするかどうかを選択できます。

## 設定例

* セッション変更

  ```shell
  obclient> SET ob_enable_parameter_anonymous_block = off;
  ```

* グローバル変更

  ```shell
  obclient> SET GLOBAL ob_enable_parameter_anonymous_block = on;
  ```
