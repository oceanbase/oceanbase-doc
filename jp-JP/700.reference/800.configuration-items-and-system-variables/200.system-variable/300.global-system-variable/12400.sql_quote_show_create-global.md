# sql_quote_show_create

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`sql_quote_show_create`は、`SHOW CREATE TABLE`および`SHOW CREATE DATABASE`ステートメントで参照識別子を有効にするかどうかを設定します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、またはビュー`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`（Oracleモード）およびビュー`information_schema.GLOBAL_VARIABLES`（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、またはビュー`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`（Oracleモード）およびビュー`information_schema.SESSION_VARIABLES`（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限が必要です。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限が必要です。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自身のテナントに属するセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** |                                                    **説明**                                                     |
|--------|---------------------------------------------------------------------------------------------------------------|
| パラメータタイプ   | Bool                       |
| デフォルト値    | true                       |
| 値の範囲   | <ul><li>True：有効 </li><li>False：無効</li></ul>    |
| 適用範囲    | <ul><li>Global   </li><li>Session </li></ul>   |
| 変更は可能か  | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

`SHOW CREATE TABLE`および`SHOW CREATE DATABASE`ステートメントで参照識別子を有効にするように設定します。有効にすると、`SHOW CREATE TABLE`または`SHOW CREATE DATABASE`ステートメントを実行した際の出力結果であるテーブル作成・データベース作成ステートメントにおいて、テーブル名、データベース名、フィールド名などの識別子がバッククォート（`）で囲まれます。

* セッション有効

  ```shell
  obclient> SET sql_quote_show_create = ON;
  ```

* グローバル有効

  ```shell
  obclient> SET GLOBAL sql_quote_show_create = ON;
  ```
