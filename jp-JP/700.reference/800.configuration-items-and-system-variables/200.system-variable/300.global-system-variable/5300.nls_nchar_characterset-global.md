# nls_nchar_characterset

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`nls_nchar_characterset`は、データベースのデフォルト文字セットを表し、NCHAR、NVARCHAR2、NCLOBなどのデータ型で使用されます。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は変更できません。

## プロパティの説明

| **プロパティ**  | **説明**  |
|---------|---------|
| パラメータタイプ    | Varchar |
| デフォルト値      | AL16UTF16   |
| 適用範囲    | Global |
| 変更は可能か  | 不可。この変数は読み取り専用です。|
