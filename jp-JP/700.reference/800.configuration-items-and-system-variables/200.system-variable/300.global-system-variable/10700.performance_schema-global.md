# performance_schema

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はMySQL 8.0との互換性のためにのみ使用され、関連する機能はサポートされていません。クエリや設定は可能ですが、設定してもエラーは報告されず、反映されません。</p>
</main>

## 機能の概要

`performance_schema`は、クライアントに対してパフォーマンス情報のクエリをサポートするかどうかを宣言するために使用されます。

## プロパティの説明

|   プロパティ       |      説明                                             |
|--------------|-------------------------------------------------------|
| パラメータタイプ     | Bool                   |
| デフォルト値       | OFF                    |
| 値の範囲     | <ul><li>ON：サポート</li><li>OFF：サポートなし</li></ul>    |
| 適用範囲     | Global                |
| 変更は可能か   | はい。`SET`ステートメントを使用して変更できます。|
