# query_cache_type

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`query_cache_type`はクエリキャッシュのタイプを設定します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数は現在、有効ではありません。</p>
</main>

## プロパティの説明

| **プロパティ**  |                           **説明**                             |
|-----------|----------------------------------------------------------------|
| パラメータタイプ   | Varchar                                                     |
| デフォルト値     | OFF                                                         |
| 値の範囲   | <ul><li>OFF：結果をキャッシュまたは検索しません。 </li><li>ON：`SELECT SQL_NO_CACHE ...` クエリ以外のすべての結果をキャッシュします。 </li><li>DEMAND：`SELECT SQL_CACHE ...` クエリの結果のみをキャッシュします。 </ li></ul>    |
| 適用範囲    | Global |
| 変更は可能か  | 不可です。この変数はテナント作成時にのみ指定でき、テナント作成後はSQLステートメントで変更できません。 |
