# nls_nchar_conv_excp

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`nls_nchar_conv_excp`は、NCHAR/NVARCHAR2とCHAR/VARCHAR2間の変換でデータが失われた場合にエラーを報告するかどうかを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  この変数は変更できません。

## プロパティの説明

| **プロパティ**  | **説明**  |
|---------|---------|
| パラメータタイプ    | Bool |
| デフォルト値      | FALSE                    |
| 値の範囲    | <ul><li>TRUE：エラーを報告することを示します </li><li>FALSE：エラーを報告しないことを示します</li></ul>   |
| 適用範囲    | <ul><li>Global</li><li>Session</li></ul> |
| 変更は可能か  | 不可です。この変数は読み取り専用です。|
