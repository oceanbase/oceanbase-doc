# ob_temp_tablespace_size_percentage

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>システムアーキテクチャの調整により、この変数は使用されなくなりました。ディスクデータの書き込み割合は、<a href="../../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/4100.data_disk_usage_limit_percentage.md">data_disk_usage_limit_percentage</a>構成パラメータで制御されます。この変数はV2.1バージョン以降の削除対象となっています。</p>
</main>，

## 機能の概要

`ob_temp_tablespace_size_percentage`は、テナントディスク上の一時テーブルスペースサイズの割合制限に使用されます。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|-----------|---------------|
| パラメータタイプ    | Int                     |
| デフォルト値      | 0                       |
| 値の範囲    | [0, 100]              |
| 適用範囲    |  <ul><li>Global</li><li>Session</li></ul>  |
