# ob_timestamp_service

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.x系では、システム全体でGTSが統一的に使用されるため、グローバルタイムスタンプサービスを指定する必要はありません。この変数はV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

`ob_timestamp_service`は、使用するタイムスタンプサービスを指定します。

## プロパティの説明

| **プロパティ**  |           **説明**                         |
|---------|----------------------------------------------|
| パラメータタイプ    | Enum                         |
| デフォルト値     | GTS                            |
| 値の範囲    | <ul><li>LTS：トランザクションの実行中、サーバーのローカルタイムスタンプをトランザクションのスナップショットとして使用します。パーティション間のアクセスはサポートされません。 </li><li>GTS：トランザクションの実行中、GTSサービスからグローバルタイムスタンプを取得し、それをトランザクションのスナップショットおよびトランザクションのコミットバージョン番号として使用します。使用に制限はありません。 </li><li>（現在はサポートされていません）HA_GTS </li></ul>   |
| 適用範囲    | Global            |
