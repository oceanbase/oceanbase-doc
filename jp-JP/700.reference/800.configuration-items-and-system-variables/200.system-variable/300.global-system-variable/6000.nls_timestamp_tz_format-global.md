# nls_timestamp_tz_format

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`nls_timestamp_tz_format`は、timestamp tz型をstrに変換する際のフォーマット、およびstrを暗黙的にtimestamp tzに変換する際のフォーマットを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
</main>

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---------|---------------|
| パラメータタイプ    | varchar                 |
| デフォルト値     | DD-MON-RR HH.MI.SSXFF AM TZR    |
| 値の範囲    | N/A                     |
| 適用範囲    | <ul><li>Global</li><li> Session</li></ul>    |
| 変更は可能か  | はい。`SET` ステートメントを使用して変更できます。|

## 使用方法

この変数は、`to_char`および`to_timestamp_TZ`関数と一緒に使用するデフォルトのタイムゾーン形式のタイムスタンプを指定します。一般的な値は`YYYY-MM-DD HH24:MI:SS.FF TZR TZD`です。

## 設定例

* セッション有効

  ```shell
  obclient> SET nls_timestamp_tz_format='YYYY-MM-DD HH24:MI:SS.FF TZR TZD';
  ```

* グローバル有効

  ```shell
  obclient> SET GLOBAL nls_timestamp_tz_format='YYYY-MM-DD HH24:MI:SS.FF TZR TZD';
  ```
