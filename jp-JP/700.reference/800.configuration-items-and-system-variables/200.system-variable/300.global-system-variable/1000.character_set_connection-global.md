# character_set_connection

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`character_set_connection`は、受信したステートメントを変換する際に使用する文字セットを設定します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー(Oracleモード)および`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー(Oracleモード)および`information_schema.SESSION_VARIABLES`ビュー(MySQLモード)を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル有効

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

    * Oracleユーザーテナントは`ALTER SYSTEM`権限を持っている必要があります。

  * セッション有効

    `sys`テナントとすべてのユーザーテナントは、自身のテナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ** | **説明** |
|-----------|---------------|
| パラメータタイプ | String       |
| デフォルト値 | utf8mb4      |
| 値の範囲 | <ul><li>utf8mb4</li><li>binary</li><li>gbk</li></ul> |
| 適用範囲 | <ul><li>Global</li><li>Session</li></ul> |
| 変更は可能か | はい。`SET` ステートメントを使用して変更できます。|
| NULL値は許容されるか | はい          |

## 設定例

受信したステートメントを変換する際に使用する文字セットを`utf8mb4`に設定します。

* グローバル有効

   ```shell
   obclient> SET GLOBAL character_set_connection ='utf8mb4';
   ```

* セッション有効

   ```shell
   obclient> SET character_set_connection ='utf8mb4';
   ```
