# long_query_time

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.2.77バージョンから導入されました。この変数はMySQLとの互換性のためにのみ使用され、関連する機能はサポートされていません。クエリや設定は可能ですが、設定してもエラーは報告されませんし、反映されません。</p>
</main>

## 機能の概要

`long_query_time`はスロークエリのしきい値を設定します。実行時間がこの値を超えるクエリはスロークエリログに記録されます。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードでのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバル変更

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントは`SUPER`または`ALTER SYSTEM`権限を持っている必要があります。

  * セッション変更

    `sys`テナントとすべてのユーザーテナントは、自身のテナントのセッションシステム変数の値を直接変更できます。

## プロパティの説明

|**プロパティ**| **説明**|
|--------|---------|
|パラメータタイプ | Numeric |
|デフォルト値   | 10、単位は秒 |
|値の範囲 |[0, +∞)|
|適用範囲 |<ul><li>グローバル</li><li>セッション</li></ul>|
| 変更は可能か| はい。`SET`ステートメントを使用して変更できます。|

## 設定例

スロークエリのしきい値を10秒に設定します。

* グローバルに適用

  ```shell
  obclient> SET GLOBAL long_query_time=10;
  ```

* セッションに適用

  ```shell
  obclient> SET long_query_time=10;
  ```
