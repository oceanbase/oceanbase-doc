# nls_timestamp_format

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`nls_timestamp_format`は、timestampまたはtimestamp ltz型をstrに変換する際のフォーマット、およびstrをtimestampまたはtimestamp ltzに暗黙的に変換する際のフォーマットを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
</main>

## プロパティの説明

| **プロパティ** | **説明** |
|---------|---------------|
| パラメータタイプ | Varchar                 |
| デフォルト値 | DD-MON-RR HH.MI.SSXFF AM|
| 値の範囲 | N/A                     |
| 適用範囲 | <ul><li>Global</li><li>Session</li></ul>    |
| 変更は可能か | はい。`SET` ステートメントを使用して変更できます。|

## 使用方法

この変数は、`to_char`および`to_TIMESTAMP`関数と一緒に使用するデフォルトの日付形式を指定します。一般的な値は`YYYY-MM-DD HH24:MI:SS.FF`です。

## 設定例

* セッション有効

  ```shell
  obclient> SET nls_timestamp_format='YYYY-MM-DD HH24:MI:SS.FF';
  ```

* グローバル有効

  ```shell
  obclient> SET GLOBAL nls_timestamp_format='YYYY-MM-DD HH24:MI:SS.FF';
  ```
