# innodb_stats_persistent

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV4.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

`innodb_stats_persistent`は、InnoDBインデックス統計情報をディスクに永続化するかどうかを制御します。

<main id="notice">
  <h4>適用対象</h4>
  <ul><li>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</li>
  <li>この変数はエコシステムツールの互換性を保証するためにのみ使用され、OceanBaseデータベースの機能に影響を与えることはありません。</li></ul>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は互換性のためにのみ使用され、パラメータ設定に実際の効果はなく、有効にもされません。

## プロパティの説明

| **プロパティ**  |    **説明**  |
|---------|---------------|
| パラメータタイプ    |    Enum              |
| デフォルト値     |  1  |
| 値の範囲    | <ul><li>ON：有効化  </li><li>OFF：無効化 </li></ul>                   |
| 適用範囲    |  Global |
