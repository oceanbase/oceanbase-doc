# ob_create_table_strict_mode

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>V4.x系では、独立したパーティションが存在しないため、システムはログストリームを媒体として使用します。ログストリームにはデータベース内のすべての変更操作が記録されるため、パーティションの作成に厳密モードは不要となりました。この変数はV4.0.0以降のバージョンから削除されました。ログストリームとパーティションの関係については、<a href="../../../100.oceanbase-database-concepts/500.distributed-database-objects/300.data-partitions-and-replicas/200.logstream.md">ログストリーム</a>を参照してください。</p>
</main>

## 機能の概要

`ob_create_table_strict_mode`は動的変数であり、テーブル作成時の厳密モードを設定します。

## プロパティの説明

| **プロパティ** |    **説明**   |
|----------|---------------|
| パラメータタイプ   | Bool                         |
| デフォルト値     | 0                |
| 値の範囲   | <ul><li>1：ローカリティに厳密に従ってレプリカを構築し、いずれかのレプリカの構築に失敗した場合はテーブル作成も失敗することを示します。 </li><li>0：すべてのタイプのレプリカが少なくとも1つずつ存在し、Paxosメンバーグループのレプリカが過半数に達した場合、テーブル作成が成功することを示します。 </li></ul>     |
| 適用範囲   | <ul><li>Global </li><li>Session </li></ul>  |
