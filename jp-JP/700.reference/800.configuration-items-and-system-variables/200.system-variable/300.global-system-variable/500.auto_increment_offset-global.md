# auto_increment_offset

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この変数はV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`auto_increment_offset`は、`AUTO_INCREMENT`列の値の開始点を決定するために使用されます。

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー(MySQLモード)を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  * `sys`テナントはグローバルシステム変数の値を直接変更できます。

  * MySQLユーザーテナントは、グローバルシステム変数の値を変更するには`SUPER`または`ALTER SYSTEM`権限が必要です。

## プロパティの説明

| **プロパティ** | **説明** |
|---------|------------------|
| パラメータタイプ | Uint                    |
| デフォルト値 | 1                       |
| 値の範囲 | [1, 65535]            |
| 適用範囲 | <ul><li>Global </li><li>Session </li></ul>           |
| 変更は可能か | はい。`SET` ステートメントを使用して変更できます。|

## 設定例

`AUTO_INCREMENT`列の値の開始点を1に設定します。

* グローバル有効

   ```shell
   obclient> SET GLOBAL auto_increment_offset =1;
   ```

* セッション有効

  ```shell
  obclient> SET auto_increment_offset =1;
  ```
