# ob_table_access_policy

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この変数はV4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

`ob_table_access_policy`は、オプティマイザーがベーステーブル計画を生成する際に優先的に選択するストレージ形式を制御します。

## 権限要件

* 変数の確認

  * グローバルレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビュー（Oracleモード）および`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

  * セッションレベル

    `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビュー（Oracleモード）および`information_schema.SESSION_VARIABLES`ビュー（MySQLモード）を使用してセッションシステム変数の値を確認できます。

* 変数の変更

  * グローバルに適用

    * `sys`テナントはグローバルシステム変数の値を直接変更できます。

    * MySQLユーザーテナントがグローバルシステム変数の値を変更するには、`SUPER`または`ALTER SYSTEM`権限が必要です。

    * Oracleユーザーテナントがグローバルシステム変数の値を変更するには、`ALTER SYSTEM`権限が必要です。

  * セッションに適用

    `sys`テナントとすべてのユーザーテナントは、自身のテナントに属するセッションシステム変数の値を直接変更できます。

## プロパティの説明

| **プロパティ**  |    **説明**     |
|-----------|---------------|
| パラメータタイプ   | Enum       |
| デフォルト値     | AUTO |
| 値の範囲   | <ul><li>`ROW_STORE`：行ストア形式に優先的にアクセスする</li> <li>`COLUMN_STORE`：カラムストア形式に優先的にアクセスする</li> <li>`AUTO`：オプティマイザーがアクセス形式を自動的に決定する</li></ul> |
| 適用範囲   | <ul><li>Global</li> <li>Session</li></ul>       |
| 変更は可能か | はい。`SET`ステートメントを使用して変更できます。|

## 設定例

オプティマイザーがベーステーブル計画を生成する際、カラムストア形式を優先的に選択するように設定します。

* セッションに適用

  ```shell
  obclient> SET ob_table_access_policy='COLUMN_STORE';
  ```

* グローバルに適用

  ```shell
  obclient> SET GLOBAL ob_table_access_policy='COLUMN_STORE';
  ```
