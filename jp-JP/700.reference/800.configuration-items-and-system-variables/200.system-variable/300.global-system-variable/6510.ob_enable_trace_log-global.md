# ob_enable_trace_log

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
   <li>V4.x系ではシステムアーキテクチャが最適化されたため、この変数はV4.x系には適用されなくなり、V4.1.0以降のバージョンから削除されました。</li>
   <li>V4.x系では、変数<a href="../400.session-system-variable/7400.ob_enable_show_trace-session.md">ob_enable_show_trace</a>を使用してShow Traceログを有効にするかどうかを設定できます。 </li>
  </ul>
</main>

## 機能の概要

`ob_enable_trace_log`は、SQLトレースログを使用するかどうかを設定します。

## プロパティの説明

| **プロパティ**   |      **説明**    |
|------------|--------------------|
| パラメータタイプ    | Bool        |
| デフォルト値      | 0                           |
| 値の範囲    | <ul><li>0：使用しない</li>   <li> 1：使用する</li></ul>      |
| 適用範囲    | <ul><li> Global</li>   <li> Session</li></ul>  |
