# pid_file

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.2.5バージョンでは、この変数はV4.2.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

`pid_file`は、サーバーが自身のプロセスIDを書き込むファイルのパス名を照会するために使用されます。

<main id="notice">
  <h4>適用対象</h4>
  <p>この変数はOceanBaseデータベースのMySQLモードにのみ適用されます。</p>
</main>

## 権限要件

* 変数の確認

  `sys`テナントとすべてのユーザーテナントは`SHOW VARIABLES`ステートメント、または`information_schema.GLOBAL_VARIABLES`ビュー（MySQLモード）を使用してグローバルシステム変数の値を確認できます。

* 変数の変更

  この変数は変更できません。

## プロパティの説明

| **プロパティ** | **説明** |
|-----------|---------------|
| パラメータタイプ | Varchar |
| デフォルト値 | /run/observer.pid |
| 適用範囲 | グローバル |
| 変更は可能か | 不可。この変数は読み取り専用です。 |

## クエリ例

サーバーが自身のプロセスIDを書き込むファイルのパス名を照会します。

```shell
obclient> SHOW VARIABLES LIKE 'pid_file';
```

クエリ結果は次のとおりです：

```shell
+---------------+----------------------------------------+
| Variable_name | Value                                  |
+---------------+----------------------------------------+
| pid_file      | /home/admin/oceanbase/run/observer.pid |
+---------------+----------------------------------------+
1 row in set (0.004 sec)
```
