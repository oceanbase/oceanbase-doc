# V3.xとV4.xの構成パラメータおよびシステム変数の変更

OceanBaseデータベースは、V4.xバージョンでアーキテクチャの変更とアップグレード、そしてリファクタリングが行われたため、多くの構成パラメータや変数はすでに使用できなくなりました。V4.xでは、無効な構成パラメータや変数を削除し、変更を行っています。例えば、Major Freezeをトリガーするための構成パラメータ`minor_freeze_times`はすでに削除されています。同時に、いくつかの構成パラメータのデフォルト値も調整されました。例えば、V4.xバージョンでは、大規模トランザクションのサポートを基盤から強化したため、トランザクションはフリーズ操作の影響を受けなくなりました。そのため、`freeze_trigger_percentage`のデフォルト値を20%に調整しました。
