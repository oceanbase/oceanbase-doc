# 概要

PLにおいて、各定数、変数、パラメータ、関数の戻り値にはデータ型が割り当てられており、これによって格納形式、使用制限、有効値の範囲、および許可される操作などが定義されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

OceanBaseデータベースのPLでは、さまざまなデータ型が事前に定義されていますが、ユーザー定義のデータ型もサポートしています。

PLで事前に定義されたデータ型には以下のものが含まれます：

* SQLデータ型

* ブール型

* カーソルポインタ

* ユーザー定義型

* `PLS_INTEGER` と `BINARY_INTEGER`

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li><code>BOOLEAN</code>、<code>RECORD</code>、<code>REF CURSOR</code> および一部の事前定義されたサブタイプは、PL専用のデータ型です。</li>
    <li>Schemaレベルの独立したサブプログラムでは、PL専用のデータ型を使用できません。これらの型を使用する場合は、サブプログラムをパッケージ内に配置する必要があります。</li>
    </ul>
  </main>

さらに、OceanBaseデータベースではPLステートメント内で `JSON_OBJECT_T` および `JSON_ELEMENT_T` の2種類のJSONデータ型もサポートしています。
