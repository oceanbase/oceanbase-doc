# ユーザー定義サブタイプ

PLは、基本データ型に基づいてユーザー定義のサブタイプ`SUBTYPE`を作成することを許可し、ユーザー定義型に基づいてさらに定義することもできます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

ユーザー定義サブタイプ`SUBTYPE`の構文は以下のとおりです：

```javascript
SUBTYPE subtype_name IS base_type
{ precision [, scale ]  [ NOT NULL ]
```

ユーザー定義型では、精度を再定義したり、NOT NULL制約を設定したりできます。例：

```javascript
obclient> DECLARE
  SUBTYPE score IS NUMBER;
  amount score(6,2);

  SUBTYPE item IS score NOT NULL;
  item1 item := 1;

BEGIN
  amount := item1;
END;
/
```
