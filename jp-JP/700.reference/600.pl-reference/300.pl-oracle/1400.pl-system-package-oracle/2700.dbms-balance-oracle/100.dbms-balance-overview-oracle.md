# DBMS_BALANCEの概要

`DBMS_BALANCE` システムパッケージは、パーティションの均衡に関するメソッドを提供します。

## DBMS_BALANCE権限の説明

PL/SQL実行権限を持つユーザーテナントはこの機能を使用できます。sysテナントが呼び出すと `OB_OP_NOT_ALLOW` エラーが発生します。

## DBMS_BALANCEサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_BALANCE` サブプログラムと対応する説明を示しています。

| サブプログラム | 説明 |
| --- | --- |
|[TRIGGER_PARTITION_BALANCE](200.trigger-paptition-balance-oracle.md)|パーティションの均衡を手動でトリガーするために使用されます。|
|[SET_BALANCE_WEIGHT](../2700.dbms-balance-oracle/150.set-balance-weight-oracle.md)              |パーティションの重みを手動で設定するために使用されます。|
|[CLEAR_BALANCE_WEIGHT](../2700.dbms-balance-oracle/160.clear-balance-weight-oracle.md)          |パーティションの重みを手動でクリアするために使用されます。|
