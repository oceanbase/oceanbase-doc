# DETACH_SESSION

`DETACH_SESSION` ストアドプロシージャは、デバッグ対象のプログラムを停止するために使用されます。

このストアドプロシージャはいつでも呼び出すことができますが、対象セッションに対してデバッガーセッションが切断されていることを通知したり、対象セッションの実行を終了させたりすることはありません。そのため、対象セッションがスリープ状態にならないように注意する必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DETACH_SESSION;
```
