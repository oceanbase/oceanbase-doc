# DETACH_SESSION

`DETACH_SESSION` ストアドプロシージャは、デバッグ対象のプログラムを停止するために使用されます。

このストアドプロシージャはいつでも呼び出すことができますが、対象セッションに対してデバッガーセッションが切断されていることを通知したり、対象セッションの実行を終了させたりすることはありません。そのため、対象セッションが一時停止されないように注意する必要があります。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DETACH_SESSION;
```
