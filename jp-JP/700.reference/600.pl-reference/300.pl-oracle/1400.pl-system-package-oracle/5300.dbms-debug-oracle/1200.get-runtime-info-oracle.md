# GET_RUNTIME_INFO

`GET_RUNTIME_INFO` 関数は、現在のプログラムに関する情報を返します。

この関数は、`CONTINUE` 関数の `info_requested` パラメータが0に設定されている場合にのみ使用する必要があります。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>この関数は現在、クライアントPLでのみ使用されます。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_DEBUG.GET_RUNTIME_INFO (
   info_requested  IN  BINARY_INTEGER,
   run_info        OUT runtime_info)
  RETURN BINARY_INTEGER;
```

## パラメータの説明

|     **パラメータ**     |                                                 **説明**                                                 |
|----------------|--------------------------------------------------------------------------------------------------------|
| info_requested | プログラム停止時に `run_info` で返す情報。詳細は[Information Flags](../5300.dbms-debug-oracle/100.dbms-debug-overview-oracle.md)を参照してください。 |
| run_info       | プログラムの状態に関する情報。                                                                                             |
