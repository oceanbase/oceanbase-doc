# GET_VALUES

`GET_VALUES` 関数は、現在のスタックフレームにおけるすべての変数情報を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.GET_VALUES(
scalar_values OUT VARCHAR2)
RETURN binary_integer;
```

## パラメータ説明

|    **パラメータ**    | **説明** |
|--------------|--------|
| scalar_value | 値。     |
