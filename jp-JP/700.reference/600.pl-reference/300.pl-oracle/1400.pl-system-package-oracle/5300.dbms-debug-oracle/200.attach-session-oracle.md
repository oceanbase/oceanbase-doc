# ATTACH_SESSION

`ATTACH_SESSION` ストアドプロシージャは、デバッグセッションに対象プログラムを通知するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.ATTACH_SESSION (
debug_session_id  IN VARCHAR2,
diagnostics       IN BINARY_INTEGER := 0);
```

## パラメータの説明

|      **パラメータ**      |         **説明**          |
|------------------|-------------------------|
| debug_session_id | ターゲットセッション内で初期化呼び出しを行うDebugID。 |
| diagnostics      | 非ゼロの場合、診断出力を生成します。1と等しい値はサポートされていません。      |
