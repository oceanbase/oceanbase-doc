# SET_TIMEOUT_BEHAVIOUR

`SET_TIMEOUT_BEHAVIOUR` ステアリングプロシージャは、監視スレッドでタイムアウトが発生した場合のターゲットセッションの処理方法を指定します。

この呼び出しは、ターゲットセッション内で行われます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.SET_TIMEOUT_BEHAVIOUR (
behaviour IN PLS_INTEGER);
```

## パラメータの説明

`behaviour` パラメータは以下のように分類されます：

|       **パラメータ**        |                              **説明**                               |
|---------------------|-------------------------------------------------------------------|
| retry_on_timeout    | 再試行します。タイムアウトは無効です。これはタイムアウト時間を無限大に設定するのと同じです。                                          |
| continue_on_timeout | 同一のイベント識別子を使用して実行を続けます。                                                   |
| nodebug_on_timeout  | デバッグモードを無効にし(`debug_off` を呼び出す)、実行を続けます。このターゲットセッションは、`debug_on` を呼び出して再初期化するまで、イベントを生成しなくなります。 |
| abort_on_timeout    | `abort_execution` 識別子を使用して実行を続けます。これにより、プログラムは即座に終了します。セッションは引き続きデバッグモードにあります。                |

## 例外

`unimplemented` は、要求された動作が認識できないことを表します。

## 使用方法

デフォルトの動作（このサブルーチンを呼び出さない場合）は `continue_on_timeout` です。これはデバッガークライアントが次のイベントに対する制御を再確立できるようにするため、ターゲットセッションを無期限にハングさせることはありません。
