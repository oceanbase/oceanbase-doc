# GET_TIMEOUT_BEHAVIOUR

`GET_TIMEOUT_BEHAVIOUR` 関数は、現在のタイムアウト動作を返します。この呼び出しは、対象セッション内で行われます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.GET_TIMEOUT_BEHAVIOUR
RETURN BINARY_INTEGER;
```
