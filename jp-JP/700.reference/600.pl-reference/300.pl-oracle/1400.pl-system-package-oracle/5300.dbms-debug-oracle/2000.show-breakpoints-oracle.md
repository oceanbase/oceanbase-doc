# SHOW_BREAKPOINTS

`SHOW_BREAKPOINTS` ストアドプロシージャは、現在のブレークポイントのリストを返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.SHOW_BREAKPOINTS (
listing    IN OUT VARCHAR2);
```

## パラメータの説明

| **パラメータ**  |                                    **説明**                                    |
|---------|------------------------------------------------------------------------------|
| listing | ブレークポイントのフォーマットバッファ（改行文字を含む）。ブレークポイントエントリのインデックステーブル。ブレークポイント番号は、このテーブルのインデックスによって示される。ブレークポイント番号は1から始まり、削除後は再利用可能である。 |
