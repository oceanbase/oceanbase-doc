# PROBE_VERSION

`PROBE_VERSION` プログラムは、サーバー上の `DBMS_DEBUG` のバージョン番号を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.PROBE_VERSION (
major out BINARY_INTEGER,
minor out BINARY_INTEGER);
```

## パラメータの説明

| **パラメータ** |        **説明**        |
|--------|----------------------|
| major  | 主要なバージョン番号です。               |
| minor  | 次要なバージョン番号（機能の追加に伴うイテレーションバージョン）。 |
