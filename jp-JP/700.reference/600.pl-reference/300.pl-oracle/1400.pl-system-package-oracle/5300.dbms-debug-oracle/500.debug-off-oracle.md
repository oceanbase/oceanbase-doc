# DEBUG_OFF

`DEBUG_OFF` ストアドプロシージャは、対象セッションにデバッグを停止するよう通知するために使用されます。セッションを終了する前にこの関数を呼び出す必要はありません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DEBUG_OFF;
```
