# DEBUG_ON

`DEBUG_ON` ストアドプロシージャは、デバッグモードですべてのPLを実行するためのターゲットセッションにマークを付けるために使用されます。この操作は、デバッグの実行を開始する前に完了しておく必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DEBUG_ON (
no_client_side_plsql_engine BOOLEAN := TRUE,
immediate                   BOOLEAN := FALSE);
```

## パラメータ説明

|           **パラメータ**            |                    **説明**                    |
|-----------------------------|----------------------------------------------|
| no_client_side_plsql_engine | デバッグセッションがクライアントPLエンジンから実行される場合を除き、デフォルト値のままにしておいてください。              |
| immediate                   | 値が `TRUE` の場合、呼び出し中にInterpreterは通常モードからデバッグモードに即座に切り替わります。 |
