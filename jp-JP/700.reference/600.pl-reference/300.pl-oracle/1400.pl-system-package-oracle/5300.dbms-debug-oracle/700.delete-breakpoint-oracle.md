# DELETE_BREAKPOINT

`DELETE_BREAKPOINT` 関数は、ブレークポイントを削除するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_DEBUG.DELETE_BREAKPOINT (
   breakpoint IN BINARY_INTEGER)
  RETURN BINARY_INTEGER;
```

## パラメータの説明

|   **パラメータ**   |           **説明**           |
|------------|----------------------------|
| breakpoint | `SET_BREAKPOINT` で返されたブレークポイント番号。 |

## 戻り値

|        **パラメータ**         |     **説明**      |
|-----------------------|-----------------|
| success               | 完了しました。           |
| error_no_such_breakpt | ブレークポイントが存在しません。         |
| error_idle_breakpt    | 使用されていないブレークポイントは削除できません。     |
| error_stale_breakpt   | ブレークポイント設定後にプログラムユニットが再定義されました。 |
