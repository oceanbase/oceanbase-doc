# DBMS_DDLの概要

`DBMS_DDL`は、PLオブジェクト定義文字列を暗号化するために使用されます。

## DBMS_DDLサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_DDL`サブプログラムとその簡潔な説明を示しています。

| サブプログラム                   | 説明                  |
| ----------------------- | --------------------- |
|[WRAP](200.dbms-ddl-wrap-oracle.md)|PLオブジェクト定義文字列を`CREATE WRAPPED`ステートメント文字列に暗号化するために使用されます。|
|[CREATE_WRAPPED](300.dbms-ddl-create-wrapped-oracle.md)|PLオブジェクト定義文字列を`CREATE WRAPPED`ステートメント文字列に暗号化した後、このステートメントを実行して`WRAPPED`オブジェクトを作成します。|
