# WRAP

`WRAP`は、PLオブジェクト定義文字列を`CREATE WRAPPED`ステートメント文字列に暗号化するために使用されます。

## 構文

```sql
DBMS_DDL.WRAP(DDL VARCHAR2) RETURN VARCHAR2;
DBMS_DDL.WRAP(DDL DBMS_SQL.VARCHAR2S,
              LB  PLS_INTEGER,
              UB  PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2S;
DBMS_DDL.WRAP(DDL DBMS_SQL.VARCHAR2A,
              LB  PLS_INTEGER,
              UB  PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2A;
```

## パラメータ説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|WRAP(DDL VARCHAR2) RETURN VARCHAR2|<ur><li>DDL: VARCHAR2型の文字列で、曖昧にするPL/SQLソースコードが含まれます。</li><li>RETURN: 戻り値。曖昧化処理後のPL/SQLコードを含むVARCHAR2型の文字列を返します。|
|WRAP(DDL DBMS_SQL.VARCHAR2S, LB PLS_INTEGER, UB PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2S|<ur><li>DDL: DBMS_SQL.VARCHAR2S型の配列で、曖昧にするPL/SQLソースコードが含まれます。</li><li>LB: PLS_INTEGER型の下界インデックス。</li><li>UB: PLS_INTEGER型の上界インデックス。</li><li>RETURN: 戻り値。曖昧化処理後のPL/SQLコードを含むDBMS_SQL.VARCHAR2S型の配列を返します。|
|WRAP(DDL DBMS_SQL.VARCHAR2A, LB PLS_INTEGER, UB PLS_INTEGER) RETURN DBMS_SQL.VARCHAR2A|<ur><li>DDL: DBMS_SQL.VARCHAR2A型の配列で、曖昧にするPL/SQLソースコードが含まれます。</li><li>LB: PLS_INTEGER型の下界インデックス。</li><li>UB: PLS_INTEGER型の上界インデックス。</li><li>RETURN: 戻り値。曖昧化処理後のPL/SQLコードを含むDBMS_SQL.VARCHAR2A型の配列を返します。|

## 例

PL/SQLとDBMS_DDLパッケージを使用してオブジェクトタイプを作成し、異なる方法でこれらの操作を実行します。
以下の3つの例は、それぞれ異なる方法でSQLステートメントを実行しています。

**例1：**

`DBMS_DDL_WRAP`を使用して単一行のSQLステートメントを包装し、DBMS_SQLパッケージを使用して解析および実行します。

```sql
declare
wrapped varchar2(32767);
c number;
r number;
begin
wrapped := dbms_ddl.wrap('create or replace type typ0 as object (a number);');
c := dbms_sql.open_cursor;
dbms_sql.parse(c, wrapped, dbms_sql.native);
r := dbms_sql.execute(c);
dbms_sql.close_cursor(c);
end;
/
```

ここで：

* `wrapped`: DBMS_DDL_WRAP処理後のSQLステートメントを格納するために使用されます。
* `c`: カーソル識別子を指します。`dbms_sql.open_cursor`は新しいカーソルを開くことを表し、`dbms_sql.close_cursor(c)`はカーソルを閉じることを表します。
* `r`: 実行結果を指します。`r := dbms_sql.execute(c)`は解析後のSQLステートメントを実行することを表します。

**例2：**

`DBMS_DDL_WRAP`を使用して単一行のSQLステートメントを包装し、`EXECUTE IMMEDIATE`を使用して直接実行します。

```sql
declare
  wrapped varchar2(32767);
begin
  wrapped := dbms_ddl.wrap('create or replace type typ1 as object (a number);');
  execute immediate wrapped;
end;
/
```

ここで：

* `dbms_ddl.wrap('create or replace type typ1 as object (a number);')`: オブジェクト型を作成するSQLステートメントをラッピングします。
* `execute immediate wrapped`: ラッピングされたSQLステートメントを直接実行します。

**例3:**

`DBMS_DDL_WRAP` を使用して複数行のSQLステートメント配列をラッピングし、DBMS_SQLパッケージで解析して実行します。

```sql
declare
  sqls dbms_sql.varchar2a;
  c number;
  r number;
begin
  sqls(1) := 'create or replace type typ2 as object (';
  sqls(2) := '  a number';
  sqls(3) := ';';
  sqls := dbms_ddl.wrap(sqls, 1, sqls.count);
  c := dbms_sql.open_cursor;
  dbms_output.put_line(sqls.count);
  dbms_sql.parse(c, sqls, 1, sqls.count, false, dbms_sql_native);-- dbms_sql.parse のlinefeed flagパラメータはfalseに設定する必要があります。そうでない場合、余分な改行文字がcreate wrappedステートメントの構文解析に失敗させる原因となります。
  r := dbms_sql.execute(c);
  dbms_sql.close_cursor(c);
end;
/
```

ここで：

* `sqls := dbms_ddl.wrap(sqls, 1, sqls.count)`: 複数行のSQLステートメント配列をラッピングします。
* `dbms_output.put_line(sqls.count)`: ラッピング後のSQLステートメント配列の長さを出力します。
* `dbms_sql.parse(c, sqls, 1, sqls.count, false, dbms_sql_native)`: ラッピング後のSQLステートメント配列を解析します。
