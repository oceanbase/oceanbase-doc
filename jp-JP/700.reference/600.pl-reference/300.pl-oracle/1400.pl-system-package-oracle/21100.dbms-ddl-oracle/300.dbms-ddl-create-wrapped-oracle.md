# CREATE_WRAPPED

`CREATE_WRAPPED`は、PLオブジェクトの定義文字列を`CREATE WRAPPED`ステートメント文字列に暗号化し、このステートメントを実行して`WRAPPED`オブジェクトを作成します。

## 構文

```sql
DBMS_DDL.CREATE_WRAPPED (DDL VARCHAR2);
DBMS_DDL.CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2A,
                        LB  PLS_INTEGER,
                        UB  PLS_INTEGER);
DBMS_DDL.CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2S,
                        LB  PLS_INTEGER,
                        UB  PLS_INTEGER);
```

## パラメータの説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|CREATE_WRAPPED (DDL VARCHAR2)|<ur><li>DDL: VARCHAR2型の文字列で、難読化するPL/SQLソースコードが含まれます。</li><li>RETURN: 戻り値。難読化処理後のPL/SQLコードを含むVARCHAR2型の文字列を返します。|
|CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2A， LB  PLS_INTEGER, UB  PLS_INTEGER)|<ur><li>DDL: DBMS_SQL.VARCHAR2A型の配列で、難読化するPL/SQLソースコードが含まれます。</li><li>LB: PLS_INTEGER型の下界インデックス。</li><li>UB: PLS_INTEGER型の上界インデックス。|
|CREATE_WRAPPED(DDL DBMS_SQL.VARCHAR2S,LB  PLS_INTEGER,UB  PLS_INTEGER)|<ur><li>DDL: DBMS_SQL.VARCHAR2S型の配列で、難読化するPL/SQLソースコードが含まれます。</li><li>LB: PLS_INTEGER型の下界インデックス。</li><li>UB: PLS_INTEGER型の上界インデックス。</li>|

## 例

DBMS_DDLパッケージの`CREATE_WRAPPED`プロシージャを使用して、ラッピングされたPL/SQLパッケージを作成します。これにより、元のPL/SQLコードが読み取り不能な形式に変換され、直接の閲覧や変更を防ぎます。

```shell
CALL dbms_ddl.create_wrapped(
  '-- this is a comment'                                                   || chr(10) ||
  'create or replace package arithmetic as'                                || chr(10) ||
  '  function add(a number, b number) return number; -- this is a comment' || chr(10) ||
  '  function sub(a number, b number) return number; /* comment */'        || chr(10) ||
  '  function /* comment */ mul(a number, b number) return number;'        || chr(10) ||
  '  /* comment1'                                                          || chr(10) ||
  '     comment2'                                                          || chr(10) ||
  '     comment3 */'                                                       || chr(10) ||
  '  function div(a number, b number) return number;'                      || chr(10) ||
  'end arithmetic;'                                                        || chr(10) ||
  '-- comment'                                                             || chr(10) ||
  '/* comment */'
);
Query OK, 0 rows affected (0.612 sec)
```

ここでは、以下の内容を定義します：

* `create or replace package arithmetic as`：arithmeticという名前のパッケージを定義します。
* `function add(a number, b number) return number`：add関数を定義します。number型の引数2つを受け取り、number型の結果を返します。
* `function div(a number, b number) return number`：div関数を定義します。number型の引数2つを受け取り、number型の結果を返します。
* `end arithmetic`：パッケージ定義を終了します。
* `-- comment`：1行コメント。
* `/* comment */`：複数行コメント。

ラッピング後のコードは、以下のような読み取り不能な文字列になります（実際の出力はバージョンや環境によって異なる場合があります）：

```sql
BEGIN
  DBMS_DDL.CREATE_WRAPPED('package body "SCHEMA_NAME"."ARITHMETIC" is
  function "ADD"(a in number, b in number) return number is
  begin
    return a + b;
  end;
  function "SUB"(a in number, b in number) return number is
  begin
    return a - b;
  end;
  function "MUL"(a in number, b in number) return number is
  begin
    return a * b;
  end;
  function "DIV"(a in number, b in number) return number is
  begin
    if b = 0 then
      raise value_error;
    else
      return a / b;
    end if;
  end;
end "ARITHMETIC";');
END;
/
```
