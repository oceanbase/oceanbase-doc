# ENDCREATE メンバーストアドプロシージャ

`ENDCREATE` メンバーストアドプロシージャは、`ANYDATA` の作成を終了するために使用します。

この呼び出しを使用すると、他の作成関数を呼び出すことができなくなります。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
MEMBER PROCEDURE EndCreate(
self IN OUT NOCOPY AnyData);
```

## パラメータの説明

| パラメータ | 説明 |
|------|---------------|
| self | `ANYDATA`型の値です。 |
