# GETTYPENAME メンバー関数

`GETTYPENAME` メンバー関数は、`ANYDATA` の完全な型名を取得するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
MEMBER FUNCTION GetTypeName(
         self IN AnyData)
RETURN VARCHAR2 DETERMINISTIC;
```

## パラメータ説明

| パラメータ | 説明 |
|------|---------------|
| self | `ANYDATA`型の値です。 |

## 戻り値

`ANYDATA` の型名。

`ANYDATA` が組み込み型に基づいている場合、この関数は `SYS.NUMBER` のような組み込み型名を返します。ユーザー定義の型に基づいている場合、この関数は `schema_name.type_name` のような形式で返します（例：`ADAM.FOO`）。一時的な匿名型に基づいている場合、この関数は `NULL` を返します。
