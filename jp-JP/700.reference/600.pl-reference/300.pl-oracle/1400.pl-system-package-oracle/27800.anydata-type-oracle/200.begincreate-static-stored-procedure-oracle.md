# BEGINCREATE 静的ストアドプロシージャ

`BEGINCREATE` 静的ストアドプロシージャは、新しい `ANYDATA` の作成を開始するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
STATIC PROCEDURE BeginCreate(
dtype IN OUT NOCOPY AnyType,
adata OUT NOCOPY AnyData);
```

## パラメータの説明

| パラメータ | 説明 |
|-------|---------------------|
| dtype | `ANYDATA` の型。      |
| adata | 現在構築中の `ANYDATA` を返します。 |

## 例外

`DBMS_TYPES.INVALID_PARAMETERS`：`dtype` が無効です（`ANYTYPE` が不完全であるか、類似の欠陥が存在する場合）。

## 使用方法

この呼び出しの直後に `PIECEWISE` を呼び出す必要はありません。`ANYDATA` の構築プロセスは、自動的に段階的な方法で開始されます。
