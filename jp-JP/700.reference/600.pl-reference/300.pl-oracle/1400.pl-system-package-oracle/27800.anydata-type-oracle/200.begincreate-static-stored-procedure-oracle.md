# BEGINCREATE 静的ストアドプロシージャ

`BEGINCREATE` 静的ストアドプロシージャは、新しい `ANYDATA` の作成を開始するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供します。</p>
  </main>

## 構文

```sql
STATIC PROCEDURE BeginCreate(
dtype IN OUT NOCOPY AnyType,
adata OUT NOCOPY AnyData);
```

## パラメータの説明

| パラメータ | 解説 |
|-------|---------------------|
| dtype | `ANYDATA`の型。      |
| adata | 現在構築中の`ANYDATA`を返します。 |

## 例外状況

`DBMS_TYPES_INVALID_PARAMETERS`：`dtype`が無効です(`ANYTYPE`が不完全であるか、類似の欠陥が存在する場合)。

## 使用方法

この呼び出しの直後に `PIECEWISE` を呼び出す必要はありません。`ANYDATA` プロセスの構築は、自動的に区間ごとに開始されます。
