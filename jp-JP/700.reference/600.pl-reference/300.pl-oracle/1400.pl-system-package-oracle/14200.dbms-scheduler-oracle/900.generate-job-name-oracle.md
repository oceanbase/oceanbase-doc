# GENERATE_JOB_NAME

`GENERATE_JOB_NAME` 関数は、ジョブの一意の名前を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_SCHEDULER.GENERATE_JOB_NAME (
in_type_name        IN VARCHAR2 DEFAULT 'JOB$_') RETURN VARCHAR2;
```

## パラメータ説明

パラメータ `in_type_name` は、ジョブ名を生成する際に使用するプレフィックスを指定します。

## 使用方法

プレフィックスが `NULL` に明示的に設定されている場合、名前はシーケンス番号のみとなります。これらの数字の名前を正常に使用するには、`DBMS_SCHEDULER` の呼び出し全体で二重引用符で囲む必要があります。

プレフィックスは18文字を超えてはならず、数字で終わってはなりません。

`GENERATE_JOB_NAME` 関数は通常、重複するジョブ名を返すことはなく、既存のデータベースオブジェクトと名前が重複する可能性も非常に低いです。

`GENERATE_JOB_NAME` 関数を使用するためには、指定されたScheduler権限は不要です。
