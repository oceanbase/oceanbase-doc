# DROP_JOB_CLASS

`DROP_JOB_CLASS`はJOBクラスのログを削除するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise EditionのOracleテナントにのみ適用されます。OceanBaseデータベースCommunity Editionはサポートしていません。</p>
  </main>

## 構文

```sql
  DBMS_SCHEDULER.DROP_JOB_CLASS ( job_class_name          IN VARCHAR2,
                             force                   IN BOOLEAN DEFAULT FALSE);
```

## パラメータ説明

|        パラメータ       |      説明      |
|------------------|-----------------|
|job_class_name|ジョブクラスの名前。|
|force|このフィールドは`false`のみをサポートします。`job_class`に関連付けられたジョブが存在する場合、`drop class`はエラーとなり失敗します。|

## 例

```shell
obclient> BEGIN
    ->   DBMS_SCHEDULER.DROP_JOB_CLASS(
    ->     job_class_name => 'my_job_class'
    ->   );
    -> END;
    -> /
Query OK, 1 row affected (0.021 sec)
```
