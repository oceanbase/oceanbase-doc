# ENABLE

`ENABLE`は、スケジュールされたパーティションの均衡機能を有効にするために使用します。

## 構文

```sql
DBMS_SCHEDULER.ENABLE('SCHEDULED_TRIGGER_PARTITION_BALANCE');
```

## 注意事項

スケジュールされたパーティションの均衡タスク`SCHEDULED_TRIGGER_PARTITION_BALANCE`を有効にする場合、テナントレベルの構成パラメータ`partition_balance_schedule_interval = 0`が必要です。そうでない場合、`OB_OP_NOT_ALLOW`エラーが発生します。構成パラメータによるトリガーとスケジュールタスクによるトリガーは同時に有効にできません。

## 例

```shell
obclient> CALL DBMS_SCHEDULER.ENABLE('SCHEDULED_TRIGGER_PARTITION_BALANCE');
Query OK, 0 rows affected
```
