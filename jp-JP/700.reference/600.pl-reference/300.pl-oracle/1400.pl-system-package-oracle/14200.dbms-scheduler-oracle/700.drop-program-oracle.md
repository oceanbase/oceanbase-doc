# DROP_PROGRAM

`DROP_PROGRAM` プロシージャは、プログラムを削除するために使用します。プログラムが削除されると、プログラムに関連付けられたパラメータも削除されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_SCHEDULER.DROP_PROGRAM (
program_name            IN VARCHAR2,
force                   IN BOOLEAN DEFAULT FALSE);
```

## パラメータ説明

|      パラメータ     |         説明         |
|--------------|----------------------|
| program_name | 削除するプログラムの名前。名前はカンマ区切りのリストにすることができます。     |
| force        | `force` を `FALSE` に設定した場合、どのジョブもそのプログラムを参照してはならず、そうでない場合はエラーが発生します。`force` を `TRUE` に設定した場合、プログラムを削除する前に、そのプログラムを参照しているすべてのジョブが無効になります。そのプログラムを指して実行中のジョブは、`DROP_PROGRAM` 呼び出しの影響を受けずに実行を続けることができます。 |

## 例

```sql
BEGIN
  DBMS_SCHEDULER.DROP_PROGRAM(program_name => 'program_test');
END;
```
