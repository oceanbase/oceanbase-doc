# OB_INIT_OBJECTS

ユーザースキーマ内に統計テーブルを作成します。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
PROCEDURE OB_INIT_OBJECTS(force_create IN boolean :=FALSE);
```

## パラメータ説明

|       パラメータ       |               説明                |
|----------------|---------------------------------|
| force_create IN boolean :=FALSE | <ul><li><code>FALSE</code> の場合、統計テーブルと同名のテーブルが存在するとエラーを返して終了します。</li><li><code>TRUE</code> の場合、統計テーブルと同名のテーブルが存在すると、まず <code>DROP</code> を実行してから作成します。デフォルトは <code>FALSE</code> です。</li></ul>|

obclient> call dbms_profiler.ob_init_objects();
