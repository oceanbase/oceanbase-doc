# RESUME_PROFILER

`RESUME_PROFILER`は、パフォーマンスプロファイラーを復元するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_PROFILER.RESUME_PROFILER
  RETURN BINARY_INTEGER;

DBMS_PROFILER.RESUME_PROFILER;
```

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>RETURN BINARY_INTEGER</code>は、戻り値のデータ型をバイナリ整数として指定するために使用されます。実際の使用では、通常は<code>RETURN BINARY_INTEGER</code>を個別に宣言する必要はなく、<code>RESUME_PROFILER</code>プロシージャを直接呼び出します。</p>
  </main>

## 例

以下のコマンドを実行してパフォーマンスプロファイラーを復元します。

```shell
obclient> call DBMS_PROFILER.resume_profiler();
Query OK, 0 rows affected (0.001 sec)
```
