# ROLLUP_RUN

`ROLLUP_RUN`は、特定の実行における各ユニットの実行時間を計算するために使用されます。

 <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
PROCEDURE ROLLUP_RUN(run_number IN number);
```

## パラメータ説明

|       パラメータ       |               説明                |
|----------------|---------------------------------|
| run_number | 実行番号を格納し、後で実行データを保存および呼び出すために使用します。<code>run_number</code> のINパラメータの値はすべて、<code>start_profiler</code> の <code>run_number OUT</code> パラメータから取得されます。|

## 例

```shell
obclient> call dbms_profiler.rollup_run(1);
Query OK, 0 rows affected (0.06 sec)
```
