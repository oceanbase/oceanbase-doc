# FLUSH_DATA

`FLUSH_DATA`は、データを統計テーブルに集約するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_PROFILER.FLUSH_DATA
  RETURN BINARY_INTEGER;

DBMS_PROFILER.FLUSH_DATA;
```

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>RETURN BINARY_INTEGER</code>は、戻り値のデータ型をバイナリ整数として指定するために使用されます。実際の使用では、通常は<code>RETURN BINARY_INTEGER</code>を個別に宣言する必要はなく、<code>FLUSH_DATA</code>プロシージャを直接呼び出せばよいです。</p>
  </main>

## 例

```shell
obclient> call DBMS_PROFILER.flush_data();
Query OK, 0 rows affected (0.012 sec)
```
