# OB_DROP_OBJECTS

ユーザーの<code>スキーマ</code>配下からデータ統計テーブルを削除します。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```SQL
PROCEDURE OB_DROP_OBJECTS;
```

## 例

```shell
obclient> call dbms_profiler.ob_drop_objects();
Query OK, 0 rows affected (0.06 sec)
```
