# START_PROFILER

`START_PROFILER`は、パフォーマンスプロファイラーを起動するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_PROFILER.START_PROFILER(
   run_comment IN VARCHAR2 := sysdate,
   run_comment1 IN VARCHAR2 :='',
   run_number OUT BINARY_INTEGER)
 RETURN BINARY_INTEGER;
```

## パラメータ説明

|       パラメータ       |               説明                |
|----------------|---------------------------------|
| run_comment | 各プロファイラーの実行は、コメントと関連付けることができます。例えば、コメントにはデータ収集に使用するベンチマークの名前やバージョンを記述できます。 |
| run_comment1 | 実行に関するコメントを追加で入力できます。                  |
| run_number | 実行番号を保存し、後からその実行データを呼び出すことができます。|

## 例

以下のコマンドを実行してプロファイラーを起動します。

```shell
obclient> call DBMS_PROFILER.start_profiler(run_comment => 'do_something: ' || SYSDATE);
Query OK, 0 rows affected (0.916 sec)
```
