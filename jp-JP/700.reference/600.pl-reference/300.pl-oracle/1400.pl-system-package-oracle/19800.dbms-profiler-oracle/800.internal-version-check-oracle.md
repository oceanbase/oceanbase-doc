# INTERNAL_VERSION_CHECK

`INTERNAL_VERSION_CHECK`は、データベースのバージョンと`DBMS_PROFILER`のバージョンが一致しているかどうかを検証するために使用されます。
OBServerと共に配布されるadminパッケージが誤って変更された場合、`dbms_profiler`システムパッケージが正常に動作しなくなり、システムの安定性に影響を及ぼす可能性があります。その際は、ユーザーにデータのバックアップを行い、インストールメディアを使用してOBServerを再デプロイすることを推奨します。標準のデプロイおよびアップグレードプロセスを使用すれば、通常はバージョン不整合の問題は発生しません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_PROFILER.INTERNAL_VERSION_CHECK
  RETURN BINARY_INTEGER;
```

## 例

```shell
obclient> select dbms_profiler.INTERNAL_VERSION_CHECK() from dual;
+----------------------------------------+
| DBMS_PROFILER.INTERNAL_VERSION_CHECK() |
+----------------------------------------+
|                                      0 |
+----------------------------------------+
1 row in set (0.063 sec)
```
