# DECRYPT

DECRYPT 関数は、ストリーム暗号またはブロック暗号を使用して RAW データを復号化します。この暗号は、ユーザーが提供するキーとオプションの IV（初期化ベクトル）を使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容は OceanBase データベースEnterprise Edition にのみ適用されます。OceanBase データベースCommunity Edition は MySQL モードのみ提供されます。</p>
  </main>

## 構文

```sql
DBMS_CRYPTO.DECRYPT(
   src IN RAW,
   typ IN PLS_INTEGER,
   key IN RAW,
   iv  IN RAW DEFAULT NULL)
 RETURN RAW;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
| src    | 復号化する RAW データ。           |
| typ    | 使用するストリーム暗号とブロック暗号の連結アルゴリズム。       |
| key    | 復号化に使用するキー。               |
| iv     | ブロック暗号のオプションの初期化ベクトル。デフォルト値は NULL です。 |

## 使用方法

* 元の平文データを取得するには、`DECRYPT` を呼び出す際に、データを暗号化するために最初に使用したものと同じ暗号、アルゴリズム、キー、および IV を使用する必要があります。

* `VARCHAR2` データが暗号化前に元のデータに変換されている場合は、UTL_I18N パッケージを使用して適切なデータベース文字セットに戻す必要があります。
