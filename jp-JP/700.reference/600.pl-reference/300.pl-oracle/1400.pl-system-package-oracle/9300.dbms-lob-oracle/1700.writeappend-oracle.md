# WRITEAPPEND

`WRITEAPPEND` ステートメントは、内部 `LOB` の末尾に指定された量のデータを書き込みます。データは `buffer` パラメータによって書き込まれます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.WRITEAPPEND (
lob_loc IN OUT NOCOPY BLOB,
amount  IN            INTEGER,
buffer  IN            RAW);

DBMS_LOB.WRITEAPPEND (
lob_loc IN OUT NOCOPY CLOB CHARACTER SET ANY_CS,
amount  IN            INTEGER,
buffer  IN            VARCHAR2 CHARACTER SET ANY_CS);
```

## パラメータ説明

|   パラメータ    |                                       説明                                       |
|---------|--------------------------------------------------------------------------------|
| lob_loc | 内部 `LOB` に書き込む位置情報です。[DBMS_LOBの使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。 |
| amount  | 書き込むバイト数（`BLOB`の場合）または文字数（`CLOB`の場合）。                                              |
| buffer  | 書き込み用の入力バッファです。                                                                     |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>入力量がバッファ内のデータを上回るとエラーが発生します。入力量がバッファ内のデータを下回る場合、バッファ内のバイトまたは文字数だけが <code>LOB</code> の末尾に書き込まれます。</p>
  </main>

## 例外

|     Exception     |                                                                          Description                                                                           |
|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VALUE_ERROR       | `lob_loc`、`amount`、または `offset` パラメータのいずれかが `NULL`、範囲外、または無効です。                                                                                                       |
| INVALID_ARGVAL    | 以下のいずれかの場合：<ul><li> `amount` が1未満の場合   </li><li> `amount` が32767バイト（またはそれに相当する文字数）を超える場合</li></ul>    |
| QUERY_WRITE       | クエリまたはPDML並列実行サーバーで `LOB` 書き込みを実行できません。                                                                                                                               |
| BUFFERING_ENABLED | `LOB` でバッファリングが有効な場合、`LOB` バッファを有効にした状態で操作を実行できません。                                                                                                                      |

## 使用方法

* `VARCHAR` バッファの形式は `CLOB` パラメータの形式と一致している必要があります。`LOB` パラメータの型を `CLOB` に設定した場合、バッファには `CHAR` データを含める必要があります。

* クライアントから `DBMS_LOB.WRITEAPPEND` を呼び出す場合（例：OBClientの `BEGIN` / `END` ブロック内）、バッファにはクライアントの文字セットのデータを含める必要があります。バッファデータを `LOB` に書き込む前に、データベースはクライアントのバッファをサーバーの文字セットに変換します。

* `LOB` 操作をOpen/Closeインターフェースでラップする必要はありません。操作を実行する前に`LOB`を開いていない場合、呼び出しの過程で`LOB`列上の機能インデックスとドメインインデックスが更新されます。しかし、操作を実行する前に`LOB`を開いている場合は、トランザクションをコミットする前に必ず閉じる必要があります。内部`LOB`を閉じる際、`LOB`列上の機能インデックスとドメインインデックスが更新されます。

* `LOB`操作をOpen/Close APIでラップしない場合、`LOB`に書き込むたびに機能インデックスとドメインインデックスが更新されます。これはパフォーマンスに悪影響を及ぼします。そのため、`LOB`への書き込み操作は`OPEN`または`CLOSE`ステートメント内に含めることを推奨します。

* 必要に応じて、`LOB`に追加する前に、`WRITEAPPEND`で`LOB`を取得します。
