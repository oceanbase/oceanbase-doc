# ISTEMPORARY

`ISTEMPORARY` 関数は、一時的なLOBインスタンスをチェックするために使用されます。

   <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.ISTEMPORARY (
   lob_loc IN BLOB)
  RETURN INTEGER;
DBMS_LOB.ISTEMPORARY (
   lob_loc IN CLOB CHARACTER SET ANY_CS)
  RETURN INTEGER;
```

## パラメータ説明

`lob_loc`：指定されたLOB Locatorを表します。詳細については、[DBMS_LOBの使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。

## 戻り値

LOBが一時的で存在する場合、戻り値は1です。LOBが一時的ではない、または存在しない場合、戻り値は0です。指定されたLocatorが`NULL`の場合、`NULL`を返します。

## 使用上の注意

`FREETEMPORARY` を使用して一時LOBを解放すると、LOB Locatorは`NULL`に設定されません。LOB Locatorが解放された後、明示的に`NULL`にリセットされていない場合、`ITEMPORARY` は0を返します。

## 例

```shell
obclient> SELECT DBMS_LOB.ISTEMPORARY(TO_CLOB('asd')) FROM DUAL;
+--------------------------------------+
| DBMS_LOB.ISTEMPORARY(TO_CLOB('ASD')) |
+--------------------------------------+
|                                    1 |
+--------------------------------------+
1 row in set

obclient> SELECT DBMS_LOB.ISTEMPORARY(TO_CLOB('30303031')) FROM DUAL;
+-------------------------------------------+
| DBMS_LOB.ISTEMPORARY(TO_BLOB('30303031')) |
+-------------------------------------------+
|                                         1 |
+-------------------------------------------+
1 row in set

obclient> SET SERVEROUTPUT ON;
Query OK, 0 rows affected

obclient> DELIMITER /
obclient> DECLARE
       my_clob CLOB;
       BEGIN
          my_clob := to_clob('abcd');
          DBMS_LOB.FREETEMPORARY(my_clob);
          DBMS_OUTPUT.PUT_LINE('istemp: ' || DBMS_LOB.ISTEMPORARY(my_clob));
       END;
       /
Query OK, 1 row affected

istemp: 0
```
