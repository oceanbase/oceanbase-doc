# READ

`READ` ステートメントは、`LOB` で始まる指定されたオフセットからデータを読み取り、`buffer` パラメータに返すために使用されます。

`amount`パラメータには、実際に読み取られたバイト数または文字数が返されます。入力されたオフセットが `LOB` の終端を超えると、`amount` は0に設定され、`NO_DATA_FOUND` 例外が発生します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.READ (
lob_loc   IN             BLOB,
amount    IN OUT NOCOPY  INTEGER,
offset    IN             INTEGER,
buffer    OUT            RAW);

DBMS_LOB.READ (
lob_loc   IN             CLOB CHARACTER SET ANY_CS,
amount    IN OUT NOCOPY  INTEGER,
offset    IN             INTEGER,
buffer    OUT            VARCHAR2 CHARACTER SET ANY_CS);
```

## パラメータの説明

|  **パラメータ**  |                                    **説明**                                     |
|----------|-------------------------------------------------------------------------------|
| lob_loc  | 読み取る `LOB` のロケーターです。[DBMS_LOB 使用说明](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。 |
| file_loc | チェックする `LOB` のファイルロケーターです。                                                            |
| amount   | 読み取るバイト数（`BLOB`の場合）または文字数（`CLOB`の場合）、または既に読み取った文字数。                                    |
| offset   | `LOB` の読み取り開始オフセットです。                                                              |
| buffer   | 読み取り操作の出力バッファです。                                                                   |

## 例外

|     **例外**     |                                                                                                                                                                        **説明**                                                                                                                                                                        |
|----------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VALUE_ERROR    | `lob_loc`、`mount` または `offset` パラメータのいずれかが `NULL` の場合。                                                                                                                                                                                                                                                                                                       |
| INVALID_ARGVAL | 以下のいずれかの場合があります： <ul><li> `amount` が1未満の場合   </li><li> `amount` が32767バイト（または同等の文字数）を超える場合   </li><li> `offset` が1未満の場合   </li><li> `offset` が `LOBMAXSIZE` を超える場合   </li><li> バイトまたは文字単位の `amount` がバッファの容量を超える場合 </li></ul>    |
| NO_DATA_FOUND  | `LOB` の終端に到達し、`LOB` から読み取るバイトまたは文字がないこと、つまり `amount` の値が0であることを示します。                                                                                                                                                                                                                                                                                                |

## 使用方法

* `VARCHAR2` バッファの形式は、`CLOB` パラメータの形式と一致している必要があります。言い換えれば、`LOB` パラメータの型を `CLOB` として指定した場合、バッファには `CHAR` データを含める必要があります。

* クライアントから `DBMS_LOB.READ` を呼び出すと、返されるバッファの値にはクライアントの文字セットのデータが含まれます。データベースは、ユーザーにバッファの値を返す前に、サーバーの文字セットから `LOB` 値をクライアントの文字セットに変換します。

* 必要に応じて、`READ` に `LOB` の取得を読み取り前に行わせることができます。
