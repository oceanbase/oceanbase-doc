# CREATETEMPORARY

`CREATETEMPORARY` ストアドプロシージャは、デフォルトの一時テーブル領域に一時的な `BLOB` または `CLOB` および対応するインデックスを作成します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.CREATETEMPORARY (
lob_loc IN OUT NOCOPY BLOB,
cache   IN            BOOLEAN,
dur     IN            PLS_INTEGER := 10);

DBMS_LOB.CREATETEMPORARY (
lob_loc IN OUT NOCOPY CLOB CHARACTER SET ANY_CS,
cache   IN            BOOLEAN,
dur     IN            PLS_INTEGER := 10);
```

## パラメータの説明

|   パラメータ    |                                             説明                                             |
|---------|--------------------------------------------------------------------------------------------|
| lob_loc | `LOB` のロケーターです。[DBMS_LOBの使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。                   |
| cache   | `LOB` をバッファキャッシュに読み込むかどうかを指定します。                                                                      |
| dur     | 2つの事前定義された持続時間値（`SESSION` または `CALL`）のいずれかを指定し、セッション終了時またはコール終了時に一時 `LOB` のヒントをクリアするかどうかを指定します。`dur` を省略した場合は、セッションの持続時間が使用されます。 |
