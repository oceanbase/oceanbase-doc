# GETLENGTH

`GETLENGTH` 関数は、指定された `LOB` の長さを取得するために使用されます。返される長さはバイトまたは文字単位です。

長さのカウントには、以前の `WRITE` などの操作によって `LOB` 内に生成された0バイトやスペースも含まれます。空の内部 `LOB` の長さは0です。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_LOB.GETLENGTH (
lob_loc              IN BLOB
)
RETURN NUMBER;

DBMS_LOB.GETLENGTH (
lob_loc              IN CLOB CHARACTER SET ANY_CS
)
RETURN NUMBER;
```

## パラメータの説明

| **パラメータ**  |                                  **説明**                                  |
|---------|--------------------------------------------------------------------------|
| lob_loc | `LOB` のロケーターです。[DBMS_LOBの使用方法](../9300.dbms-lob-oracle/100.dbms-lob-overview-oracle.md)を参照してください。 |

## 戻り値

`LOB` の長さ（バイトまたは文字）は整数（`INTEGER`）です。入力 `LOB` が `NULL` または入力 `lob_loc` が `NULL` の場合、`NULL` を返します。

## 例外

|      **例外**       |                  **説明**                   |
|-------------------|-------------------------------------------|
| BUFFERING_ENABLED | `LOB` でバッファリングが有効になっている場合、その `LOB` バッファを有効にした状態では操作を実行できません。 |
