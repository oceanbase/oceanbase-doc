# DBMS_PLAN_CACHEの概要

`DBMS_PLAN_CACHE`システムパッケージは、OceanBaseデータベース固有のものであり、SQL実行計画キャッシュ(Plan Cache)に対するきめ細かい操作を提供します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供します。</p>
  </main>

## DBMS_PLAN_CACHE権限の説明

このシステムパッケージは`SYS`配下で作成する必要があります。このシステムパッケージを使用するには、`SYS.DBMS_PLAN_CACHE`の`EXECUTE`権限が必要です。
