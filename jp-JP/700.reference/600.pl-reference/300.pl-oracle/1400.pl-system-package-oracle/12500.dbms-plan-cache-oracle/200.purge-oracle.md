# PURGE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/PURGE
`PURGE` ストアドプロシージャは、Plan Cacheから指定されたSQLを削除するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_PLAN_CACHE.PURGE (
sql_id           VARCHAR2 NOT NULL,
schema        VARCHAR2 DEFAULT NULL
global          BOOLEAN  DEFAULT FALSE);
```

## パラメータの説明

|   パラメータ   |                                      説明                                       |
|--------|-------------------------------------------------------------------------------|
| sql_id | SQL識別子。長さは32バイトです。SQLが削除されると、そのすべての実行計画も同時に無効になります。                                    |
| schema | 特定のSchemaが生成する実行計画を指定します。`NULL` はSchemaを指定しないことを意味し、すべてのSchemaの実行計画が無効になります。 |
| global | パラメータ値が `FALSE` の場合、ローカルのプランキャッシュをクリアします。パラメータ値が `TRUE` の場合、そのテナントが存在するすべてのサーバー上のプランキャッシュをクリアします。                   |
