# DBMS_METADATAの概要

`DBMS_METADATA` システムパッケージは、DDLを作成したり、XMLドキュメントをコミットしてDDLを実行したりするために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_METADATA権限の説明

このシステムパッケージは `SYS` ユーザーに属し、`PUBLIC` への実行アクセス権限を付与できます。`DBMS_METADATA` は呼び出し元の権限（つまり、呼び出し元のセキュリティプロファイル）に基づいて実行されます。

## DBMS_METADATAサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_METADATA` サブプログラムとその簡単な説明を示しています。

 サブプログラム | 説明 |
| --- | --- |
|[GET_DDL](200.get-ddl-oracle.md)|単一オブジェクトのメタデータをDDLとして返すために使用されます。|
|[GET_TABLE_INDEX_DDL](300.get-table-index-ddl-oracle.md)|主表(TABLE)のインデックスDDLステートメントを一括抽出するために使用されます。|
