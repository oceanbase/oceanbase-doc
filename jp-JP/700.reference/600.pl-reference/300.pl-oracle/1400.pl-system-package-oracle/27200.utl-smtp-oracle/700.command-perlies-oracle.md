# COMMAND_REPLIES

`COMMAND_REPLIES`は汎用SMTPコマンドを実行し、複数の応答行を受信するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.COMMAND_REPLIES (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL)
RETURN replies;
```

## パラメータ説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|cmd|サーバーに送信する`command`コマンド。|
|arg|SMTPコマンドの引数です。実際に送信する際は、`cmd`と`arg`の間にスペースを挿入して連結します。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|replies|コマンドの応答。|

## 使用方法

この関数は複数の応答行を返します。
