# MAIL

`MAIL` コマンドは、SMTPサービスと連携してメールトランザクションを開始し、送信者のメールアドレスを宣言するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.MAIL (
   c           IN OUT NOCOPY   connection,
   sender      IN              VARCHAR2,
   parameters  IN              VARCHAR2 DEFAULT NULL)
RETURN reply;

UTL_SMTP.MAIL (
   c           IN OUT NOCOPY   connection,
   sender      IN              VARCHAR2,
   parameters  IN              VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|sender|送信者のメールアドレス。|
|parameters|RFC1869ではSMTPプロトコルの形式が定義されています。これは「XXX=XXX （XXX=XXX ....）」の形式に従わなければなりません。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|コマンドの応答です。複数の応答がある場合は、最後の応答を返します。|

## 使用方法

`mail` コマンドは、サーバーに新しいメールトランザクションを開始したことを通知するために使用されます。トランザクションを完了するには、その後 `rcpt` および `data` コマンドを呼び出す必要があります。SMTPサーバーへの接続は開いている状態でなければならず、`helo` または `ehlo` コマンドを実行済みである必要があります。
