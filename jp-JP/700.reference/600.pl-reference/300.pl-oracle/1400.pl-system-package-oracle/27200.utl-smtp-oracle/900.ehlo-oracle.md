# EHLO

`EHLO` コマンドは、SMTPサービスとの初期ハンドシェイクを実行するために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.EHLO (
   c       IN OUT NOCOPY connection,
   domain  IN)
RETURN replies;

UTL_SMTP.EHLO (
   c       IN OUT NOCOPY connection,
   domain  IN);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|domain|送信元ホストのドメイン名です。識別に使用されます。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|commandの応答です。複数の応答がある場合は、最後の応答が返されます。|

## 使用方法

`ehlo` コマンドは `helo` コマンドの拡張であり、サーバーが自身の設定情報に関する記述的情報を返すことを許可します。互換性のため、各行の情報はステータスコード `250` で始まります。
