# EHLO

`EHLO` は、`EHLO` コマンドを実行し、SMTPサービスとの初期ハンドシェイクを行います。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.EHLO (
   c       IN OUT NOCOPY connection,
   domain  IN)
RETURN replies;

UTL_SMTP.EHLO (
   c       IN OUT NOCOPY connection,
   domain  IN);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|domain|送信元ホストのドメイン名です。識別に使用されます。|

## 戻り値

| **データ型** |          **説明**          |
|---------|--------------------------|
|reply|コマンドへの応答です。複数の応答がある場合は、最後の応答が返されます。|

## 使用方法

`ehlo` コマンドは `helo` コマンドの拡張であり、サーバーが自身の設定に関する説明を返すことができます。互換性のため、各行の情報はステータスコード `250` で始まります。
