# NOOP

サーバーが依然として接続状態にあり、正しくリスニングしているかどうかを検証するために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.NOOP (
   c  IN OUT NOCOPY connection)
RETURN reply;

UTL_SMTP.NOOP (
   c  IN OUT NOCOPY connection);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|コマンドの応答です。複数の応答がある場合、最後の応答が返されます。|

## 使用方法

* サーバーから正常な応答を引き出すために使用します。`open_connect` の後、`noop` を実行することで、サーバーが依然として接続状態にあり、正しくリスニングしているかどうかを検証できます。
* 期待される戻り値は `250` で始まる応答メッセージであり、サーバーが接続状態にあり、正しくリスニングしていることを示します。
