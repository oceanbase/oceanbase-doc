# RCPT

`RCPT` コマンドは、電子メールの受信者を指定するために使用します。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.RCPT (
   c           IN OUT NOCOPY     connection,
   recipient   IN                VARCHAR2,
   parameters  IN                VARCHAR2 DEFAULT NULL)
RETURN reply;

UTL_SMTP.RCPT (
   c           IN OUT NOCOPY     connection,
   recipient   IN                VARCHAR2,
   parameters  IN                VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|recipient|受信者のメールアドレス。|
|parameters|RFC1869ではSMTPプロトコルの形式が定義されています。これは「XXX=XXX （XXX=XXX ....）」の形式に従う必要があります。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|コマンドへの応答です。複数の応答がある場合は、最後の応答が返されます。|

## 使用方法

* `RCPT` を呼び出すたびに、単一の受信者メールアドレスを指定します。複数の受信者を指定するには、`RCPT` を複数回呼び出します。
* `mail` の後に呼び出す必要があります。
* 期待される戻り値は `250` または `251` で始まる応答情報であり、SMTPサーバーが正常に応答し、指定された受信者アドレスを受け入れたことを示します。
