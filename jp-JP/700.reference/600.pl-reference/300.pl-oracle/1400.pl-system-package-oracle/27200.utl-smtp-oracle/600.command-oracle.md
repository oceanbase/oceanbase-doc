# COMMAND

`COMMAND`は汎用SMTPコマンドを実行するために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.COMMAND (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL)
RETURN reply;

UTL_SMTP.COMMAND (
   c     IN OUT NOCOPY    connection,
   cmd   IN               VARCHAR2,
   arg   IN               VARCHAR2 DEFAULT NULL);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|cmd|サーバーに送信する`command`コマンド。|
|arg|`cmd`コマンドに関連する追加情報やパラメータを渡すために使用されます。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|commandの応答です。複数の応答がある場合、最後の応答が返されます。|

## 使用方法

この関数は1つの応答行のみを返します（複数行の応答がある場合は最後の1行のみ返します）。複数の応答行を返す必要がある場合は、`command_replies`を使用してください。
