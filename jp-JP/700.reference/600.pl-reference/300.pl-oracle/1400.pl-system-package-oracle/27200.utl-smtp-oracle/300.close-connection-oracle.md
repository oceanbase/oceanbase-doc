# CLOSE_CONNECTION

`CLOSE_CONNECTION`はSMTP接続を閉じるために使用され、それによりSMTP操作が終了します。データセッション中に電子メールの送信をキャンセルする場合にのみ使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.CLOSE_CONNECTION (
   c     IN OUT NOCOPY connection);
```

## パラメータ説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
