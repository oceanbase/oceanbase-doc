# RSET

現在の電子メールトランザクションを終了するために、`RSET` コマンドを送信します。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.RSET (
   c  IN OUT NOCOPY connection)
RETURN reply;

UTL_SMTP.RSET (
   c  IN OUT NOCOPY connection);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|コマンドの応答です。複数の応答がある場合は、最後の応答を返します。|

## 使用方法

* `REST` コマンドは、書きかけている電子メールをキャンセルし、メールを送信しないようにします。`open_connection` と `data` または `open_data` の間に使用して、メールトランザクションをキャンセルできます。ただし、メールの送信が開始されると、電子メールの送信を止めることはできません。
* 期待される戻り値は `250` で始まる応答メッセージであり、現在の電子メールトランザクションが終了したことを示します。
