# HELO

`HELO` コマンドを実行し、SMTPサービスとの初期ハンドシェイクを行います。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_SMTP.HELO (
   c       IN OUT NOCOPY   connection,
   domain  IN              VARCHAR2)
RETURN reply;

UTL_SMTP.HELO (
   c       IN OUT NOCOPY   connection,
   domain  IN              VARCHAR2);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c|SMTP接続。|
|domain|送信元ホストのドメイン名です。識別に使用されます。|

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
|reply|commandの応答です。複数の応答がある場合、最後の応答が返されます。|

## 使用方法

期待される応答メッセージは `250` で始まるものであり、SMTPサーバーが通信の確立を準備完了したことを示します。
