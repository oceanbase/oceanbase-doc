# BASE64_ENCODE

`BASE64_encode` 関数は、`RAW` 値のバイナリ表現をBase64エレメントにエンコードし、`RAW` 文字列として返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
UTL_ENCODE.BASE64_ENCODE (
   r  IN RAW)
RETURN RAW;
```

## パラメータの説明

| パラメータ |           説明           |
|----|------------------------|
| r  | エンコードする`RAW`値。デフォルト値やオプションパラメータはありません。 |

## 戻り値

| 戻り値 |       説明        |
|-----|-----------------|
| RAW | エンコードされたBase64要素を含む |
