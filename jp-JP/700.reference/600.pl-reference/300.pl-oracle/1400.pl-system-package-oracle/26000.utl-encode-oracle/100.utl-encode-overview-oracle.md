# UTL_ENCODEの概要

`UTL_ENCODE` システムパッケージは、`RAW` データを標準形式にエンコードし、ホスト間でデータを転送できるようにする機能を提供します。

`UTL_ENCODE` 関数を使用して、電子メール本文をエンコードできます。このシステムパッケージには、エンコード機能に対応するデコード機能も含まれています。これらの機能は、送信側または受信側のアプリケーションとの互換性を確保するために、公開されているエンコード規格に準拠しています。
