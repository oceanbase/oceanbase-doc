# CLOSE_ALL_CONNECTIONS

`CLOSE_ALL_CONNECTIONS`は、セッション内で開いているすべてのTCP/IP接続を閉じるために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_TCP.CLOSE_ALL_CONNECTIONS;
```
