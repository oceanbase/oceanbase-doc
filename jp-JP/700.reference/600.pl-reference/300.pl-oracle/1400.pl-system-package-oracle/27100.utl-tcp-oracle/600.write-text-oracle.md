# WRITE_TEXT

`WRITE_TEXT`は、開いた接続を持つサービスにテキストメッセージを送信するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## 構文

```sql
UTL_TCP.WRITE_TEXT (
   c    IN OUT NOCOPY connection,
   data IN            VARCHAR2 CHARACTER SET ANY_CS,
   len  IN            PLS_INTEGER DEFAULT NULL)
 RETURN PLS_INTEGER;
```

## パラメータ説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|c| TCP/IP接続を指定します。|
|data|送信するデータを格納するバッファです。|
|len|転送するデータの文字数です。`NULL` の場合、すべてのデータを転送します。ネットワーク状況により、実際に書き込まれるデータ量は少なくなる場合があります。|

## 戻り値

転送データの実際の文字数を返します。

## 使用方法

* `open_connection`で既に開いている接続である必要があります。
* 送信前に、テキストの文字セットを指定されたオンライン文字セットに変換します。
* `len`が`data`の文字数より大きい場合、`bad argument`例外をスローします。
