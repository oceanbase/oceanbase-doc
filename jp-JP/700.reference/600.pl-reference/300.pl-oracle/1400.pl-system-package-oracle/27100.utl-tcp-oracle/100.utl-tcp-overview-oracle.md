# UTL_TCPの概要

`UTL_TCP`は、TCP/IPプロトコルを介して外部サーバーと通信するためのシステムパッケージです。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## UTL_TCPサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`UTL_TCP`サブプログラムとその簡単な説明を示しています。

|                       **サブルーチン**             |                **説明**                       |
|----------------------------------------------|-----------------------------------------------|
|[OPEN_CONNECTION](200.open-connection-oracle.md)|指定されたサービスとのTCP/IP接続を開きます。|
|[CLOSE_CONNECTION](300.utl-tcp-close-connection-oracle.md)|開いたTCP/IP接続を閉じます。|
|[CLOSE_ALL_CONNECTIONS](400.close-all-connections-oracle.md)|開いたTCP/IP接続を閉じます。|
|[WRITE_LINE](500.write-line-oracle.md)|テキスト行を接続されたサービスに送信します。|
|[WRITE_TEXT](600.write-text-oracle.md)|テキストメッセージを接続されたサービスに送信します。|
|[WRITE_RAW](700.write-raw-oracle.md)|バイナリを接続されたサービスに送信します。|
|[GET_LINE](800.get-line-of-oracle.md)|行末または入力終了まで読み取ったテキスト行データを返します。|
|[GET_TEXT](900.get-text-oracle.md)|読み取ったテキストデータを返します。|
