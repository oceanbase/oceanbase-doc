# OB_TENANT_TRACE_DISABLE

`OB_TENANT_TRACE_DISABLE`は、現在のテナントのフルリンクトレース機能を無効にするために使用されます。

<main id="notice" >
  <h4>注意</h4>
  <p>他のテナントのフルリンクトレースを無効にすることはできません。</p>
</main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_TENANT_TRACE_DISABLE(tenant_name  IN VARCHAR2 DEFAULT NULL);
```

## パラメータ説明

| **パラメータ**        | **説明**                                      |
|------------------|----------------------------------------------|
| tenant_name      | フルリンクトレースを無効にする`tenant_name`。デフォルトの`null`は現在のテナントを表します。 |
