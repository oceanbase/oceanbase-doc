# OB_CLIENT_ID_TRACE_DISABLE

`OB_CLIENT_ID_TRACE_DISABLE`は、client_identifierレベルのエンドツーエンドトレースを無効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_CLIENT_ID_TRACE_DISABLE(client_id IN  VARCHAR2);
```

## パラメータ説明

| **パラメータ**      | **説明**                            |
|--------------|-------------------------------------|
| client_id    | フルリンクトレースを無効にする`client_id`。       |
