# OB_SESSION_TRACE_ENABLE

`OB_SESSION_TRACE_ENABLE`は、セッションレベルのエンドツーエンド・トレースを有効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_SESSION_TRACE_ENABLE(
    session_id   IN  BINARY_INTEGER DEFAULT NULL,
    level        IN  INT,
    sample_pct   IN  NUMBER,
    record_policy IN VARCHAR2);
```

## パラメータ説明

| **パラメータ**           | **説明**                                                                                                                                              |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| session_id       | フルリンクトレースを有効にする `session_id`。空の場合は、現在のセッションの `session_id` を表します。                                                                         |
| level            | フルリンクトレース機能のデータ収集粒度で、Level 1、Level 2、Level 3 の3つのレベルがあります。                                                                                            |
| sample_pct       | サンプリング率で、値の範囲は [0,1] です。                                                                                                                           |
| record_policy    | 出力ポリシーで、以下のオプションが含まれます：<ul><li>`ALL`：サンプリングされたすべてのクエリのトレースを出力します。</li></ul>     <ul><li>`ONLY_SLOW_QUERY`：スロークエリのみを出力します。 </li></ul>  <ul><li>`SAMPLE_AND_SLOW_QUERY`：スロークエリを出力し、その他のリクエストは `_print_sample_percentage` の確率で出力します。   </li></ul>          |
