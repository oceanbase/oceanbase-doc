# OB_CLIENT_ID_TRACE_ENABLE

`OB_CLIENT_ID_TRACE_ENABLE`は、client_identifierレベルのエンドツーエンドトレースを有効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_CLIENT_ID_TRACE_ENABLE(
 client_id    IN  VARCHAR2,
  level        IN  INT,
  sample_pct   IN  NUMBER,
  record_policy IN VARCHAR2);
```

## パラメータ説明

| **パラメータ**        | **説明**                                                |
|----------------|---------------------------------------------------------|
| client_id      | フルリンクトレースを有効にする `client_id`。                           |
| level          | フルリンクトレース機能の `trace` 収集レベルで、整数です。             |
| sample_pct     | サンプリング率。値の範囲は [0,1] です。                               |
| record_policy  | 出力ポリシー： <ul><li> `ALL`：サンプリングされたすべてのクエリの `trace` を出力します。</li></ul>              <ul><li>`ONLY_SLOW_QUERY`：スロークエリのみを出力します。</li></ul>          <ul><li>- `SAMPLE_AND_SLOW_QUERY`：スロークエリを出力し、その他のリクエストは `_print_sample_percentage` の確率で出力します。</li></ul> |
