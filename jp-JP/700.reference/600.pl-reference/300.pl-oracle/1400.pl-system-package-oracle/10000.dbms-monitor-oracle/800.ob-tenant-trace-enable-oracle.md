# OB_TENANT_TRACE_ENABLE

`OB_TENANT_TRACE_ENABLE`は、現在のテナントのエンドツーエンド・トレースを有効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_TENANT_TRACE_ENABLE(
  level        IN  INT,
  sample_pct   IN  NUMBER,
  record_policy IN VARCHAR2);
```

## パラメータ説明

| **パラメータ**       | **説明**                   |
| -------------- | -------------------------- |
| level:         | フルリンクトレース機能のデータ収集粒度で、Level 1、Level 2、Level 3の3段階があります。               |
| sample_pct:    | サンプリング率で、値の範囲は[0,1]です。                     |
| record_policy    | 出力のポリシーで、以下のオプションが含まれます：<ul><li>`ALL`：サンプリングされたすべてのクエリのトレースを出力します。</li></ul>        <ul><li>`ONLY_SLOW_QUERY`：slow queryのみを出力します。</li></ul>   <ul><li>`SAMPLE_AND_SLOW_QUERY`：slow queryを出力し、その他のリクエストは `_print_sample_percentage` の確率で出力します。   </li></ul>          |
