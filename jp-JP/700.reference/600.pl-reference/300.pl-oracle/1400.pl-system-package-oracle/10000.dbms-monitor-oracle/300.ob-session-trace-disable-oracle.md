# OB_SESSION_TRACE_DISABLE

`OB_SESSION_TRACE_DISABLE`は、セッションレベルのエンドツーエンド・トレースを無効にするために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
</main>

## 構文

```sql
DBMS_MONITOR.OB_SESSION_TRACE_DISABLE(session_id   IN  BINARY_INTEGER);
```

## パラメータ説明

| **パラメータ**      | **説明**                                              |
|--------------|-------------------------------------------------------|
| session_id   | フルリンクトレースを無効にする`session_id`。空の場合、現在のセッションの`session_id`を表します。 |
