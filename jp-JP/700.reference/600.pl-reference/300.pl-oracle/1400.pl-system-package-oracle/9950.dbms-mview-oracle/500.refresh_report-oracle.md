# REFRESH_REPORT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2バージョンでは、V4.4.2 BP2バージョンから <code>REFRESH_REPORT</code>が導入されました。</p>
</main>

`REFRESH_REPORT`は、単一のマテリアライズドビュー更新タスクに関する階層型診断レポートを生成するために使用されます。

## 使用上の制限と注意事項

`refresh_id`と`mv_name`のうち、少なくとも一方を指定してください。

## 構文

```sql
DBMS_MVIEW.REFRESH_REPORT(
    {refresh_id | mv_name}
    [, format]
    [, tenant_id])
```

## パラメータの説明

|  **パラメータ**  | **説明** |
|------------|----------|
| refresh_id | マテリアライズドビュー更新バッチの一意の識別子で、新しいスケジューリングフレームワークによって割り当てられます。 <main id="notice" type='explain'><h4>説明</h4><p><code>refresh_id</code>情報は、ビュー<a href="../../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/9600.dba_mvref_run_stats-of-oracle-mode.md">DBA_MVREF_RUN_STATS</a>で確認できます。</p></main>|
| mv_name | マテリアライズドビューの名前（例：`SCHEMA.MV_NAME`）を指定します。|
| format | オプションです。レポートの出力形式を指定します。値は以下のとおりです：<ul><li>`XML`（デフォルト値）</li><li>`JSON`</li></ul>|
| tenant_id | 現在は`sys`テナントでのみ利用可能です。他のテナントのマテリアライズドビュー更新レポートを照会するために使用されます。|

## 戻り値の説明

* 戻り値の型：`CLOB`。
* 内容の形式：`format`パラメータに依存し、`XML`または`JSON`形式のテキスト内容となります。

## 例

* `refresh_id`を使用して`XML`形式の診断レポートを取得します。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023) FROM DUAL;
    ```

* JSON形式のレポートを取得します。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023, format => 'JSON') FROM DUAL;
    ```

* マテリアライズドビュー名から直近に更新されたレポートを取得します。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(mv_name=> 'TEST.MV_SALES_DAILY') FROM DUAL;
    ```

* `sys`テナントが他のテナントの更新レポートを照会します。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023, tenant_id=> 1002) FROM DUAL;
    ```
