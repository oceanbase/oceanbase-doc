# EXTRACT

`EXISTSNODE` と同様に、ノードが存在する場合はそのノードの集合を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
EXTRACT(XMLType_instance, XPath_string [, namespace_string ])
```

## パラメータの説明

|   パラメータ    |                   説明                   |
|---------|----------------------------------------|
| XML_Type_instance | 引数として渡すxmltype変数。|
| XPath_string | XPATHパス文字列。 |
| namespace_string | プレフィックスのデフォルトマッピングまたは名前空間マッピングを指定するために使用します(オプション)。|

## 例

以下の例では、`XML` 文字列を `c2` 変数に代入して `XML` データを作成し、`EXTRACT` メソッドを使用して `c2` から `XPath` 式 'a/b' を満たすノードを抽出し、抽出結果を `t1` 変数に代入します。次に、`getstringval()` メソッドを使用して、XMLデータ `t1` の文字列表現を取得します。

```sql
DECLARE
  t1 xmltype;
  c2 xmltype;
BEGIN
  c2 := xmltype('<a><b>aaa</b><b>bbb</b></a>');
  t1 := c2.extract('a/b');
  dbms_output.put_line(t1.getstringval());
end;
/
```
