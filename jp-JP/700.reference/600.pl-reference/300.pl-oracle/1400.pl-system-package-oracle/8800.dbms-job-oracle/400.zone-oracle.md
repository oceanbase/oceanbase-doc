# ZONE

`ZONE` ストアドプロシージャは、JobとZoneの従属関係を変更するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供します。</p>
  </main>

## 構文

```sql
DBMS_JOB.ZONE (
job        IN BINARY_INTEGER,
zone      IN BINARY_INTEGER,
force     IN BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

| パラメータ   |                                          説明                                          |
|-------|--------------------------------------------------------------------------------------|
| job   | 変更前のJobに対応する一意のIDです。このIDを確認するには、`USER_JOBS`または`DBA_JOBS`ビューの`JOB`列を照会してください。 |
| zone  | Jobをコミットする際、ユーザーはそのJobを実行できるZoneを指定できます。                                                    |
| force | `TRUE`の場合、指定されたZoneに対して合法性チェックが実行されます。`FALSE`の場合、Zoneの合法性チェックは実行されません。                                    |

## 使用方法

Jobをコミットする際、ユーザーはそのJobを実行できるZoneを指定できます。
