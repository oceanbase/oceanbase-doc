# USER_EXPORT

`USER_EXPORT`は、指定されたJobを再作成するためのコールテキストを生成するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_JOB.USER_EXPORT (
job        IN BINARY_INTEGER,
mycall   IN OUT VARCHAR2);
```

## パラメータの説明

|   パラメータ   |                                          説明                                          |
|--------|--------------------------------------------------------------------------------------|
| job    | 変更前のJobに対応する一意のIDです。このIDを検索するには、`USER_JOBS`または`DBA_JOBS`ビューの`JOB`列をクエリします。 |
| mycall | 指定されたJobのコールテキストを再作成します。                                                                    |
