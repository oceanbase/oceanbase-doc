# RUN

`RUN` ステートメントは、Jobを即座に実行するために使用します。
無効なJobでも実行できます。Jobを実行すると、`next_date`が再計算されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_JOB.RUN (
job        IN  BINARY_INTEGER,
force     IN  BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

| パラメータ   |                                          説明                                          |
|-------|--------------------------------------------------------------------------------------|
| job   | 変更前のJobに対応する一意のIDです。このIDを検索するには、`USER_JOBS`または`DBA_JOBS`ビューの`JOB`列をクエリします。 |
| force | `TRUE`の場合、Jobを強制的に実行します。`FALSE`の場合、Jobが実行中でない場合にのみ現在のJobを実行します。                                     |

## 例

```sql
CALL DBMS_JOB.RUN(10100);
```
