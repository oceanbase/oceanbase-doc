# DBMS_JOBの概要

`DBMS_JOB`システムパッケージは、Jobキュー内のJobのスケジューリングと管理に使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

  <main id="notice" >
    <h4>説明</h4>
    <p>OceanBaseデータベースV4.x系では、<code>DBMS_JOB</code>システムパッケージの使用は推奨されません。<code>DBMS_SCHEDULER</code>システムパッケージへの切り替えを推奨します。</p>
  </main>

## DBMS_JOB権限の説明

`DBMS_JOB`の使用と管理には特定のシステム権限は必要ありません。Jobの所有者またはDBA権限を付与されたユーザーのみがJobを変更または削除できます。

## DBMS_JOBの使用方法

`DBMS_JOB`はJobのマルチゾーン実行をサポートしています。デフォルトではJobは任意のゾーンで実行可能ですが、Jobは1つのゾーンのみを選択できます。ゾーン名を指定することで、Jobを特定のゾーンにバインドできます。

以下は、ゾーンに関連付けられたJobを作成、変更、または実行する手順です。関連付けを指定しない場合は、任意のゾーンでそのJobを実行できることを意味します。

1. `DBMS_JOB.SUBMIT`を呼び出して、JobをJobキューに投入します。

2. `DBMS_JOB.ZONE`を呼び出して、Jobの実行に指定ゾーンを割り当てます。

3. `DBMS_JOB.CHANGE`を呼び出して、Jobに関連付けられたユーザー定義パラメータを変更します。

4. `DBMS_JOB.RUN`を呼び出して、Jobを実行します。

5. Jobを停止します。

| [INTERVAL](../8800.dbms-job-oracle/500.interval-oracle.md)    | 指定したJobの実行間隔を変更します。      |
| [NEXT_DATE](../8800.dbms-job-oracle/600.next-date-oracle.md)   | 指定したJobの次回実行時間を変更します。   |
| [REMOVE](../8800.dbms-job-oracle/700.remove-oracle.md)      | Jobキューから指定したJobを削除します。  |
| [RUN](../8800.dbms-job-oracle/800.run-oracle.md)         | 指定したJobを強制的に実行します。         |
| [SUBMIT](../8800.dbms-job-oracle/900.submit-oracle.md)      | Jobキューに新しいJobを送信します。     |
