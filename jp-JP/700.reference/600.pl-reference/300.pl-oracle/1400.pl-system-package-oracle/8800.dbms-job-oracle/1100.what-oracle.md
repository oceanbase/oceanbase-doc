# WHAT

`WHAT` ステアリングプロシージャは、既存のジョブの機能を変更するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_JOB.WHAT (
job        IN  BINARY_INTEGER,
what      IN  VARCHAR2);
```

## パラメータ説明

| パラメータ |                                                            説明                                                            |
|------|--------------------------------------------------------------------------------------|
| job  | 変更前のJobに対応する一意のIDです。このIDを検索するには、`USER_JOBS`または`DBA_JOBS`ビューの`JOB`列をクエリします。 |
| what | 実行するPLストアドプロシージャ。                                                                        |

## 使用方法

* コミット前は、ジョブはバックグラウンドのジョブキューによって処理されません。

* `what`パラメータ（ステアリングプロシージャが既に存在する場合）の有効な値例：

  * `'myplproc(''12-FEB-21'', next_date, broken);'`

  * `'dbms_job.remove(job);'`
