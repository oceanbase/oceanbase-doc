# NEXT_DATE

`NEXT_DATE` ストアドプロシージャは、ジョブの次回実行時刻を変更するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_JOB.NEXT_DATE (
job             IN  BINARY_INTEGER,
next_date   IN  DATE);
```

## パラメータ説明

|    パラメータ     |                                          説明                                          |
|-----------|--------------------------------------------------------------------------------------|
| job       | 変更前のJobに対応する一意のIDです。このIDを確認するには、`USER_JOBS`または`DBA_JOBS`ビューの`JOB`列をクエリします。 |
| next_date | 次回の実行時刻。                                                                             |

## 使用方法

コミットするまで、ジョブはバックグラウンドのジョブキューによって処理されません。
