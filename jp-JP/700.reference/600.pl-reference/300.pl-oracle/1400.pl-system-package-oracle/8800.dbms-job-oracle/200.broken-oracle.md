# BROKEN

`BROKEN` ストアドプロシージャは、破損フラグを設定するために使用されます。破損状態のジョブはスケジュールされません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_JOB.BROKEN (
job            IN  BINARY_INTEGER,
broken      IN  BOOLEAN,
next_date  IN  DATE DEFAULT SYSDATE);
```

## パラメータ説明

|    パラメータ     |                                 説明                                  |
|-----------|---------------------------------------------------------------------|
| job       | 変更前のJOBに対応する一意のIDです。このIDを検索するには、`USER_JOBS` または `DBA_JOBS` ビューの `JOB` 列をクエリしてください。 |
| broken    | Jobを無効または有効に設定します。`TRUE` は無効に設定することを表し、`FALSE` は有効に設定することを表します。               |
| next_date | Jobが実行される次の日付です。                                                       |

## 使用方法

* コミット前は、ジョブはバックグラウンドのジョブキューによって処理されません。

* ジョブが連続して16回失敗すると、自動的に破損として設定され、実行が停止します。
