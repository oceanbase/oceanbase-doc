# REMOVE

`REMOVE` ストアドプロシージャは、ジョブキューから既存のジョブを削除しますが、実行中のジョブを停止することはありません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_JOB.REMOVE (
job       IN  BINARY_INTEGER );
```

## パラメータ説明

| パラメータ  |                                          説明                                          |
|-----|--------------------------------------------------------------------------------------|
| job | 変更前のJobに対応する一意のIDです。このIDを検索するには、`USER_JOBS`または`DBA_JOBS`ビューの`JOB`列をクエリします。 |

## 使用方法

コミット前は、ジョブはバックグラウンドのジョブキューによって処理されません。

## 例

```sql
BEGIN
   DBMS_JOB.REMOVE(10100);
   COMMIT;
END;
```
