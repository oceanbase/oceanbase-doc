# BEGIN_REQUEST

`BEGIN_REQUEST`はHTTPリクエストを初期化するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、V4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.BEGIN_REQUEST (
   url               IN  VARCHAR2,
   method            IN  VARCHAR2 DEFAULT 'GET',
   http_version      IN  VARCHAR2 DEFAULT NULL,
   request_context   IN  request_context_key DEFAULT NULL,
   https_host        IN  VARCHAR2 DEFAULT NULL)
RETURN req;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|url|HTTPリクエストのURL|
|method|リクエストメソッド。デフォルトはGET|
|http_version|リクエスト時に使用されるHTTPプロトコルバージョン。デフォルトは空で、最新バージョンを表す|
|request_context|リクエストボディ。walletとcookie情報を含む。デフォルトは空で、現在のデータベースセッション内の情報を表す|
|https_host|ホスト名。デフォルトは空で、指定されたURLがSNIによって見つけたホスト名を表す|
