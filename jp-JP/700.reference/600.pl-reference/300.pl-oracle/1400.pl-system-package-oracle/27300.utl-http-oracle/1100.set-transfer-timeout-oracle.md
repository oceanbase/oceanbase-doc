# SET_TRANSFER_TIMEOUT

`SET_TRANSFER_TIMEOUT`は、HTTPデータ転送のタイムアウト時間の上限を設定します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.SET_TRANSFER_TIMEOUT (
   timeout  IN PLS_INTEGER DEFAULT 60);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|timeout|設定するタイムアウト時間の上限。単位は秒です|
