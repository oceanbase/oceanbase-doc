# READ_RAW

`READ_RAW`は、HTTPレスポンスボディ内のバイナリデータを読み取るために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.READ_RAW(
   r     IN OUT NOCOPY resp,
   data  OUT NOCOPY RAW,
   len   IN PLS_INTEGER DEFAULT NULL);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|HTTPリクエスト|
|data|HTTPレスポンスボディから読み取ったバイナリ形式のデータ|
|len|読み取ったデータのバイト数。デフォルトは空で、dataに可能な限り多くの文字を読み取ることを意味します|
