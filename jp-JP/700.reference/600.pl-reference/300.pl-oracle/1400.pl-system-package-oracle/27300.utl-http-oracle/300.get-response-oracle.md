# GET_RESPONSE

`GET_RESPONSE`は、HTTPリクエストの応答を取得するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.GET_RESPONSE (
   r                       IN OUT NOCOPY req,
   return_info_response    IN BOOLEAN DEFAULT FALSE)
RETURN resp;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|HTTPリクエスト|
|return_info_response|サーバー側の100 informational responseを返すかどうか。デフォルトはノー|
