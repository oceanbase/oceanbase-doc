# END_REQUEST

`END_REQUEST`は、リクエストを強制的に終了させるために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.END_RESPONSE (
   r  IN OUT NOCOPY resp);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|終了させるリクエスト req|
