# READ_LINE

`READ_LINE`は、HTTP応答ボディから1行のテキスト形式データを読み取り、改行文字に遭遇すると終了します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、V4.4.1バージョンから導入されました。</p>
</main>

# 構文

```sql
UTL_HTTP.READ_LINE(
   r            IN OUT NOCOPY resp,
   data         OUT NOCOPY  VARCHAR2 CHARACTER SET ANY_CS,
   remove_crlf  IN  BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|HTTPリクエスト|
|data|テキスト形式のHTTP応答本文|
|remove_crlf|newline charactersを除去するかどうか。デフォルトは`False`|
