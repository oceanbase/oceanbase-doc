# GET_TRANSFER_TIMEOUT

`GET_TRANSFER_TIMEOUT`は、現在のHTTPデータ転送のタイムアウト時間の上限を取得するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、V4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.GET_TRANSFER_TIMEOUT (
   timeout  OUT PLS_INTEGER);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|timeout|取得した現在のタイムアウト時間の上限。単位は秒です|
