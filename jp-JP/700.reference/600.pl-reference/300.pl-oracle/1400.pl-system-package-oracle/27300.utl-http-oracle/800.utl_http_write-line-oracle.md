# WRITE_LINE

`WRITE_LINE`は、HTTPリクエストボディに一行のテキストデータを書き込むために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.WRITE_LINE(
   r     IN OUT NOCOPY req,
   data  IN VARCHAR2 CHARACTER SET ANY_CS);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|HTTPリクエスト|
|data|書き込むテキストデータ|
