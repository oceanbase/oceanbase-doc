# END_RESPONSE

`END_RESPONSE`は、HTTPリクエストの処理が完了した後に、その応答を終了させるために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.END_RESPONSE（
   r IN OUT NOCOPY resp）;
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|HTTPリクエスト|
