# WRITE_RAW

`WRITE_RAW`は、HTTPリクエストボディにバイナリデータを書き込むために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
UTL_HTTP.WRITE_RAW(
   r     IN OUT NOCOPY REQ,
   data  IN            RAW);
```

## パラメータの説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
|r|HTTPリクエスト|
|data|書き込むバイナリデータ|
