# TRUNCATE_UTL_RECOMP_SKIP_LIST

`TRUNCATE_UTL_RECOMP_SKIP_LIST`は、`UTL_RECOMP_SKIP_LIST`テーブルを削除するために使用されます。

 <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RECOMP.TRUNCATE_UTL_RECOMP_SKIP_LIST();
```

## 例

```shell
EXECUTE UTL_RECOMP.TRUNCATE_UTL_RECOMP_SKIP_LIST();
Query OK, 1 row affected (23.463 sec)
```
