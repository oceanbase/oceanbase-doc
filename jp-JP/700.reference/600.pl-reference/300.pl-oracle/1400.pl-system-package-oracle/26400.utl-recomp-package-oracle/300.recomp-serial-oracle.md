# RECOMP_SERIAL

`RECOMP_SERIAL`は、データベースオブジェクトを直列コンパイルすることを示します。

 <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RECOMP.RECOMP_SERIAL(
   schema   IN   VARCHAR2    DEFAULT NULL,
   flags    IN   PLS_INTEGER DEFAULT 0);
```

## パラメータ説明

|                       パラメータ            |                説明                       |
|--------------------------------------------|---------------------------------------------------|
|schema|コンパイル対象が該当ユーザーに属するオブジェクトであることを示します。NULLの場合はデータベース全体のオブジェクトをコンパイルし、NULL以外の場合は該当ユーザーのオブジェクトをコンパイルします。|
|flags|同名のテーブルが存在する場合に有効です。値512はSYSテナント内に同名のテーブルが既に存在する場合、そのテーブルを直接使用することを意味し、1024は同名のテーブルが存在する場合、DROPして自動的に再作成することを意味します。デフォルト値は0（必須ではない）で、特別な意味はありません。|

## 例

すべてのオブジェクトを順次再コンパイルします。

```shell
EXECUTE UTL_RECOMP.RECOMP_SERIAL();
Query OK, 1 row affected (23.463 sec)
```
