# PARALLEL_SLAVE

`PARALLEL_SLAVE`は、<code>recomp_parallel</code>プロセス内で実際のコンパイル作業を実行するためのプライベートサブルーチンです。通常、ユーザーが直接呼び出すことは推奨されません。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RECOMP.PARALLEL_SLAVE(
    flags IN BINARY_INTEGER
);
```

## パラメータ説明

|                       パラメータ            |                説明                       |
|--------------------------------------------|---------------------------------------------------|
|flags|同名のテーブルが存在する場合に有効になります。値512は、SYSテナント内に同名のテーブルが既に存在する場合、そのテーブルを直接使用することを意味します。値1024は、同名のテーブルが存在する場合、それをDROPして自動的に再作成することを意味します。デフォルト値は0（必須ではない）で、特別な意味はありません。|
