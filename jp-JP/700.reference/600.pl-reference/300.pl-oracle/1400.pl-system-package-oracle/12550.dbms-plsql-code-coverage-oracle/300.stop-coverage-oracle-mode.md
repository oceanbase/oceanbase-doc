# STOP_COVERAGE

`STOP_COVERAGE`は、カバレッジ統計の収集を終了するために使用されます。終了すると、結果はデータ統計テーブルに集約されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージのサブプログラムは、V4.4.1バージョンからサポートされています。</p>
</main>

## 構文

```sql
DBMS_PLSQL_CODE_COVERAGE.STOP_COVERAGE;
```

## 例

カバレッジ情報の収集を終了します:

```sql
call DBMS_PLSQL_CODE_COVERAGE.stop_coverage();
```
