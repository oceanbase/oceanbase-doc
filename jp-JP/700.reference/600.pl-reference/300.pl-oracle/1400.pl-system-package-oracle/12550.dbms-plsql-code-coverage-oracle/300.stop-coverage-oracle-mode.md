# STOP_COVERAGE

`STOP_COVERAGE`は、カバレッジ統計を無効にするために使用されます。無効にすると、結果はデータ統計テーブルに集約されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムサブプログラムは、V4.4.1バージョンからサポートされています。</code></p>
</main>

## 構文

```sql
DBMS_PLSQL_CODE_COVERAGE.STOP_COVERAGE;
```

## 例

カバレッジ情報統計を無効にする:

```sql
call DBMS_PLSQL_CODE_COVERAGE.stop_coverage();
```
