# START_COVERAGE

`START_COVERAGE`はカバレッジ統計の開始を指示します。開始後、現在のセッションにおけるPLのカバレッジ状況が記録されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムサブプログラムはV4.4.1バージョンからサポートされています。</code></p>
</main>

## 構文

```sql
DBMS_PLSQL_CODE_COVERAGE.START_COVERAGE (
   run_comment   IN VARCHAR2)
   RETURN NUMBER;
```

## パラメータの説明

|      パラメータ      |   説明     |
|----------------|-----------|
|run_comment|今回のコードカバレッジ実行タスクに関するコメントまたは説明情報を表します。|

## 例

カバレッジ情報の収集を開始します:

```sql
BEGIN
  l_run_id := DBMS_PLSQL_CODE_COVERAGE.start_coverage('TEST_RUN_1');
END;
/
```
