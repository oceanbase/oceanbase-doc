# START_COVERAGE

`START_COVERAGE`は、カバレッジ統計の開始に使用されます。起動後、現在のセッション上のPLのカバレッジ状況を記録します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムサブプログラムは、V4.4.1バージョンからサポートされています。</code></p>
</main>

## 構文

```sql
DBMS_PLSQL_CODE_COVERAGE.START_COVERAGE (
   run_comment   IN VARCHAR2)
   RETURN NUMBER;
```

## パラメータの説明

|      パラメータ      |   説明     |
|----------------|-----------|
|run_comment|今回のコードカバレッジ実行タスクのコメントまたは説明情報を表します。|

## 例

カバレッジ情報の収集を開始します:

```sql
BEGIN
  l_run_id := DBMS_PLSQL_CODE_COVERAGE.start_coverage('TEST_RUN_1');
END;
/
```
