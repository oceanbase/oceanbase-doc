# CREATE_COVERAGE_TABLES

`CREATE_COVERAGE_TABLES`は、`DBMSPCC_RUNS`、`DBMSPCC_UNITS`、および`DBMSPCC_BLOCKS`の3つのカバレッジ情報統計テーブルを作成するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムサブプログラムは、V4.4.1バージョンからサポートされています。</code></p>
</main>

## 構文

```sql
DBMS_PLSQL_CODE_COVERAGE.CREATE_COVERAGE_TABLES (
   FORCE_IT     IN BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

|      パラメータ      |   説明     |
|----------------|-----------|
|FORCE_IT|上書きするテーブルが既に存在する場合、デフォルトではエラーをスローします。`TRUE`に設定すると、テーブルが既に存在する場合、そのテーブルをサイレントで削除して新しいテーブルを作成します。|

## 例

カバレッジ情報テーブルを作成します：

```sql
BEGIN
  DBMS_PLSQL_CODE_COVERAGE.create_coverage_tables(true);
END;
/
```
