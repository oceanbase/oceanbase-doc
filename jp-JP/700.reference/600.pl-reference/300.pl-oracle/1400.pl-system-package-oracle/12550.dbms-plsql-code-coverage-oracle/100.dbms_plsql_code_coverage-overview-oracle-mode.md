# DBMS_PLSQL_CODE_COVERAGEの概要

`DBMS_PLSQL_CODE_COVERAGE` システムパッケージは、PL/SQLコードの実行時カバレッジを収集するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージはV4.4.1バージョンからサポートされています。</code>。</p>
</main>

## DBMS_PLSQL_CODE_COVERAGE権限の説明

このシステムパッケージの権限は `AUTHID CURRENT_USER` です。

## サブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_PLSQL_CODE_COVERAGE` サブプログラムとその簡単な説明を示しています。

|                                   サブプログラム                                 |           説明          |
|--------------------------------------------------------------------------|------------------------|
|[START_COVERAGE](200.start-coverage-oracle-mode.md)|カバレッジ統計の開始に使用されます。開始後、現在のセッション上のPLのカバレッジ状況を記録します。|
|[STOP_COVERAGE](300.stop-coverage-oracle-mode.md)|カバレッジ統計の終了に使用されます。終了後、結果はデータ統計テーブルに集約されます。|
|[CREATE_COVERAGE_TABLES](400.create-coverage-oracle-mode.md)|`DBMSPCC_RUNS`、`DBMSPCC_UNITS`、`DBMSPCC_BLOCKS` の3つのカバレッジ情報統計テーブルを作成するために使用されます。|
