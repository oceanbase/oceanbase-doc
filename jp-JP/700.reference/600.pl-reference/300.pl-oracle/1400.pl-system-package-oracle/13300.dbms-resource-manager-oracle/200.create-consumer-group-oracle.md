# CREATE_CONSUMER_GROUP

`CREATE_CONSUMER_GROUP` プロシージャは、リソースユーザーグループを定義するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP (
    consumer_group  IN VARCHAR2,
    comment         IN VARCHAR2 DEFAULT NULL);
```

## パラメータ説明

|       パラメータ      |    説明     |
|----------------|-----------|
| consumer_group | リソースユーザーグループの名前。 |
| comment        | ユーザーコメント。     |

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group1','トランザクション処理グループ');
Query OK, 0 rows affected

obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group2','日常運用保守グループ');
Query OK, 0 rows affected
```
