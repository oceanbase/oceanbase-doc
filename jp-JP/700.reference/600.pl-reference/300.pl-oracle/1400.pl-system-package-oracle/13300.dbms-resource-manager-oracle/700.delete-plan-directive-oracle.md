# DELETE_PLAN_DIRECTIVE

`DELETE_PLAN_DIRECTIVE` プロシージャは、リソース計画の指示を削除するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_PLAN_DIRECTIVE (
    plan              IN VARCHAR2,
    group_or_subplan  IN VARCHAR2);
```

## パラメータ説明

|        パラメータ       |     説明     |
|------------------|------------|
| plan             | リソース計画の名前。   |
| group_or_subplan | グループまたはサブプランの名前。 |

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN_DIRECTIVE('NIGHT','group2');
Query OK, 0 rows affected
```
