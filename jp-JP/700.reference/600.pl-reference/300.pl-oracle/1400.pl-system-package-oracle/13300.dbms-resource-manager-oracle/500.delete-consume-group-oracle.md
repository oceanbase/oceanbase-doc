# DELETE_CONSUMER_GROUP

`DELETE_CONSUMER_GROUP` プロシージャは、リソース使用グループを削除するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_CONSUMER_GROUP (
    consumer_group IN VARCHAR2);
```

## パラメータ説明

`consumer_group` は、削除する使用グループ名を指定するために使用されます。

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.DELETE_CONSUMER_GROUP ('group1');
Query OK, 0 rows affected
```
