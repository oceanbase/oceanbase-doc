# DELETE_PLAN

`DELETE_PLAN` プロシージャは、指定されたプランおよびそれが参照するすべてのプラン命令を削除します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_PLAN (
    plan IN VARCHAR2);
```

## パラメータ説明

`plan` は、削除するリソースプランの名前を指定するために使用されます。

## 例

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN('NIGHT');
Query OK, 0 rows affected
```
