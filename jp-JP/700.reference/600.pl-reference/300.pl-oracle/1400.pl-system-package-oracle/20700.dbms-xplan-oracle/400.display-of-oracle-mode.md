# DISPLAY

`DISPLAY` 関数は、履歴の `EXPLAIN` プランを照会し、フォーマットするために使用されます。

  <main id="notice">
  <h4>機能の適用範囲</h4>
  <p>コミュニティエディションはV4.2.5バージョンからこの機能をサポートしています。</p>
  </main>

## 構文

```sql
TYPE DBMS_XPLAN_TYPE_TABLE IS TABLE OF VARCHAR2(4000);

DBMS_XPLAN.DISPLAY(format VARCHAR2 DEFAULT 'TYPICAL',
                  statement_id VARCHAR2 DEFAULT null,
                  table_name   VARCHAR2 DEFAULT 'PLAN_TABLE',
                  filter_preds VARCHAR2 DEFAULT null)
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## パラメータ説明

| パラメータ | 説明 |
| --- | --- |
| format | プランのフォーマット情報を指定します。オプションは以下のとおりです。<ul><li>`'BASIC'`：演算子ID、演算子名、演算子の備考、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子の備考、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報などの基本情報を表示します。このプランが実行されている場合、実際のフィードバック情報（実行行数、コストなど）も初回実行時のものを表示します。</li><li> `'ALL'`：演算子ID、演算子名、演算子の備考、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブルの最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富なプラン情報を表示します。</li><li> `'ADVANCED'`：豊富なプラン情報を表示します。プラン情報は 'ALL' パラメータと同じですが、さらに複雑なプランについてはツリー構造情報も表示します。</li></ul>|
| statement_id | `EXPLAIN` クエリのマーカー情報であり、コマンド `EXPLAIN SET STATEMENT_ID='XXX'` を使用してクエリのマーカー情報を設定できます。 |
| table_name | `EXPLAIN` プランが保存される対象テーブルで、現在のデフォルト値は `PLAN_TABLE` です。 |
| filter_preds | 追加の `PLAN_TABLE` フィルター条件で、特定の演算子やプランをフィルタリングするために使用されます。 |
