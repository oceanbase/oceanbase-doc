# DISPLAY_CURSOR

`DISPLAY_CURSOR` 関数は、実行済みのクエリ計画の詳細を表示するために使用されます。

## 使用上の制限

V4.3.5バージョンでは、この機能はV4.3.5 BP2バージョンからサポートされています。

## 構文

```sql
DBMS_XPLAN.DISPLAY_CURSOR(plan_id      INTEGER          DEFAULT    0,         -- default value: last plan
                          format       VARCHAR2         DEFAULT    'TYPICAL',
                          svr_ip       VARCHAR2         DEFAULT    null,   -- default value: server connected by client
                          svr_port     INTEGER          DEFAULT    0,     -- default value: server connected by client
                          tenant_id    INTEGER          DEFAULT    0,     -- default value: current tenant
                          sql_handle   VARCHAR2         DEFAULT    NULL,
                          plan_name    VARCHAR2         DEFAULT    NULL
                        )
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## パラメータの説明

| パラメータ | 説明 |
| ---- | ---- |
| plan_id     | 実行計画のIDです。指定しない場合、前回実行された計画が使用されます。 |
| format      | 計画形式情報を指定します。オプションは以下のとおりです：<ul><li>`'BASIC'`：演算子ID、演算子名、演算子備考情報、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報などの基本情報を表示します。この計画が実行されたことがある場合、実際のフィードバック情報（実行行数、コストなど）も表示されます。</li><li> `'ALL'`：演算子ID、演算子名、演算子備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブル最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富な計画情報を表示します。</li><li> `'ADVANCED'`：豊富な計画情報を表示します。計画情報は'ALL'パラメータと同じですが、さらに複雑な計画についてはツリー構造情報も表示します。</li></ul> |
| svr_ip      | 計画が存在するノードのIPアドレスです。デフォルトはセッションが接続しているノードのIPアドレスです。|
| svr_port    | 計画が存在するノードのポート番号です。デフォルトはセッションが接続しているノードのポート番号です。|
| tenant_id   | 計画が属するテナントIDです。デフォルトはセッションが現在接続しているテナントです。|
| sql_handle  | 実行計画がSQL文を識別するために使用するハンドル（Handle）です。特定のSQL文の実行計画を照会する際、類似したSQLが複数存在する場合、sql_handleを使用して対象文を正確に指定できます。|
| plan_name   | 実行計画の名前です。|

1. テーブルを作成します。

   ```shell
   obclient [test]> CREATE TABLE t1(c1 INT);
   ```

2. クエリを実行します。

   ```shell
   obclient [SYS]> SELECT * FROM t1;
   ```
