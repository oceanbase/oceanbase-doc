# DBMS_XPLANの概要

`DBMS_XPLAN` システムパッケージは、論理計画の最適化追跡など、論理計画管理に関連する機能を提供します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## DBMS_XPLAN権限の説明

PL/SQLを実行する権限を持つユーザーはこの機能を使用できます。

## DBMS_XPLANサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_XPLAN` サブプログラムとその簡単な説明です。

| サブプログラム | 説明 |
| --- | --- |
| [DISPLAY_ACTIVE_SESSION_PLAN](../20700.dbms-xplan-oracle/200.display-active-session-plan-of-oracle-mode.md)|指定されたセッションのリアルタイム実行計画の詳細を表示します。|
| [DISPLAY_CURSOR](../20700.dbms-xplan-oracle/300.display-cursor-of-oracle-mode.md) | 実行済みのクエリ計画の詳細を表示します。 |
| [DISPLAY](../20700.dbms-xplan-oracle/400.display-of-oracle-mode.md) | 過去の `EXPLAIN` プランを照会してフォーマットします。 |
| [DISABLE_OPT_TRACE](../20700.dbms-xplan-oracle/500.disable-opt-trace-oracle.md) | 現在のセッションのオプティマイザー全リンクトレース機能を無効にします。 |
| [DISPLAY_SQL_PLAN_BASELINE](../20700.dbms-xplan-oracle/600.display-sql-plan-baseline-of-oracle-mode.md) | SPMのベースライン計画を確認します。 |
| [ENABLE_OPT_TRACE](../20700.dbms-xplan-oracle/800.enable-opt-trace-oracle.md) | 現在のセッションのオプティマイザー全リンクトレースを有効にします。 |
| [SET_OPT_TRACE_PARAMETER](../20700.dbms-xplan-oracle/1000.set-opt-trace-parameter-oracle.md) | 現在のセッションのオプティマイザー全リンクトレースのパラメータを変更します。 |
