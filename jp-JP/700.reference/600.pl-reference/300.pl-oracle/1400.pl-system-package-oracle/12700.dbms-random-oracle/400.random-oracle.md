# RANDOM

`RANDOM` ストアドプロシージャは、ランダムなコードを生成するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.RANDOM
RETURN binary_integer;
```

## 戻り値

|    **戻り値**     |              **説明**              |
|----------------|----------------------------------|
| binary_integer | \[-2\^31，2\^31)の範囲内の乱数の整数を返します。 |

## 使用上の注意

このプログラムは廃止されており、現在のバージョンではサポートされているものの、使用は推奨されません。
