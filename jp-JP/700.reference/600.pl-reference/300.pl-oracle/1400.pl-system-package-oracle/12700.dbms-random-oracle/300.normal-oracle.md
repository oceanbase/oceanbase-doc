# NORMAL

`NORMAL` 関数は、標準正規分布の乱数を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.NORMAL
RETURN NUMBER;
```

## 戻り値

| **戻り値の型** |  **説明**  |
|--------|----------|
| number | 乱数を返します。 |
