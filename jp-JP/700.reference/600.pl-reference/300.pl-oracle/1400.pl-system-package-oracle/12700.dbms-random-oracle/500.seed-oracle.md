# SEED

`SEED` ストアドプロシージャは、シードをリセットするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.SEED (
   seed  IN  BINARY_INTEGER);

DBMS_RANDOM.SEED (
   seed  IN  VARCHAR2)
```

## パラメータの説明

| **パラメータ** |      **説明**      |
|--------|------------------|
| seed   | ランダムコードを生成するためのシード数または文字列。 |

## 使用方法

シードは最大2000文字の文字列です。
