# TERMINATE

ユーザーは `TERMINATE` 関数を呼び出して、パッケージの使用を終了します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.TERMINATE
```

## 使用方法

このプログラムはいかなる機能も実行しません。現在はサポートされていますが、既に旧式となっており、使用は推奨されません。
