# TERMINATE

ユーザーは `TERMINATE` 関数を呼び出して、パッケージの使用を終了します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.TERMINATE
```

## 使用方法

このプログラムは機能を実行しません。現在はサポートされていますが、既に時代遅れとなっており、使用は推奨されません。
