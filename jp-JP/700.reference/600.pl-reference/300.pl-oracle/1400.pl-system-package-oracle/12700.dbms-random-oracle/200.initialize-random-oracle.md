# INITIALIZE

`INITIALIZE` ストアドプロシージャは、シード値を使用してパッケージを初期化するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.INITIALIZE (
val  IN  BINARY_INTEGER);
```

## パラメータの説明

| **パラメータ** |    **説明**    |
|--------|--------------|
| val    | ランダムコードを生成するためのシード数。 |

## 使用方法

このプログラムは機能を実行しません。現在はサポートされていますが、既に古くなっており、使用は推奨されません。
