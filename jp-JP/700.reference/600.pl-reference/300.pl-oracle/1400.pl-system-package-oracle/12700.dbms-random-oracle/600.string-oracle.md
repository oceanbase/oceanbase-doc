# STRING

`STRING` 関数は、ランダムな文字列を取得するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.STRING
   opt  IN  CHAR,
   len  IN  NUMBER)
  RETURN VARCHAR2;
```

## パラメータの説明

| **パラメータ** |          **説明**        |
|--------|-------------------------------------|
| opt    | 生成する文字列の種類を指定します。ルールは以下のとおりです： <ul><li> 'u'、'U'：大文字の文字列を返します   </li><li> 'l'、'L'：小文字の文字列を返します   </li><li> 'a'、'A'：大文字と小文字が混在する文字列を返します   </li><li> 'x'、'X'：大文字と数字の文字列を返します   </li><li> 'p'、'P'：任意の印字可能な文字からなる文字列を返します。</li></ul>    それ以外の場合、返される文字列は大文字です。 |
| len    | 返される文字列の長さ。      |

## 戻り値

|  **戻り値の型**  |   **説明**    |
|----------|-------------|
| VARCHAR2 | `VARCHAR2`を返します。 |
