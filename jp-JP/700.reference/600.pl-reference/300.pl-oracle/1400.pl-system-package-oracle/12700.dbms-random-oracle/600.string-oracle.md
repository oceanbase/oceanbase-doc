# STRING

`STRING` 関数は、ランダムな文字列を取得するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_RANDOM.STRING
   opt  IN  CHAR,
   len  IN  NUMBER)
  RETURN VARCHAR2;
```

## パラメータ説明

| **パラメータ** |          **説明**        |
|--------|-------------------------------------|
| opt    | 返される文字列のパラメータを指定します。ルールは以下のとおりです： <ul><li> 'u'、'U'：大文字の文字列を返します   </li><li> 'l'、'L'：小文字の文字列を返します   </li><li> 'a'、'A'：大文字と小文字が混在する文字列を返します   </li><li> 'x'、'X'：大文字と数字の文字列を返します   </li><li> 'p'、'P'：任意の出力可能な文字の文字列を返します。</li></ul>    それ以外の場合、返される文字列は大文字になります。 |
| len    | 文字列の長さを返します。      |

## 戻り値

|  **パラメータ**  |   **説明**    |
|----------|-------------|
| VARCHAR2 | `VARCHAR2`を返します。 |
