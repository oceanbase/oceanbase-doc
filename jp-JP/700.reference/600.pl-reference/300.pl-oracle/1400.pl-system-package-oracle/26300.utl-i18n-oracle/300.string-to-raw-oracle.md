# STRING_TO_RAW

`STRING_TO_RAW` 関数は、`VARCHAR` または `NVARCHAR` 文字列を別の有効な文字セットに変換し、結果を生データとして返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
 UTL_I18N.STRING_TO_RAW (
    data             IN VARCHAR,
    dst_charset      IN VARCHAR := NULL)
 RETURN RAW AS ret RAW(32767);
```

## パラメータの説明

|   **パラメータ**    |                            **説明**                             |
|-------------|---------------------------------------------------------------|
| data        | 変換対象の `VARCHAR` または `NVARCHAR` 文字列を指定します。                                |
| dst_charset | ターゲット文字セットを指定します。`dst_charset` が `NULL` の場合、データベース文字セットが文字データに、国家文字セットがNCHARデータに使用されます。 |

## 使用方法

ユーザーが無効な文字セット、`NULL` 文字列、または長さが0の文字列を指定した場合、関数は `NULL` 文字列を返します。
