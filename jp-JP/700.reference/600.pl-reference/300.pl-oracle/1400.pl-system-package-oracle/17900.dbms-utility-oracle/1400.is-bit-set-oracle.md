# IS_BIT_SET

`IS_BIT_SET` 関数は、指定された `RAW` 値の特定のビットが設定されているかどうかを確認するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.IS_BIT_SET (
   r     IN    RAW,
   n     IN    NUMBER)
 RETURN NUMBER;
```

## パラメータの説明

| パラメータ |      説明       |
|----|---------------|
| r  | `RAW` ソース。      |
| n  | `r`パラメータのビット数をチェックします。 |

## 戻り値

`r` の `n` 番目のビットが設定されている場合、この関数は1を返し、そうでない場合は0を返します。ビットは上位から下位に向かって番号が付けられ、最低位は1となります。
