# OLD_CURRENT_USER

`OLD_CURRENT_USER` この関数は、`sys_context` からセッション値（'`userenv`', '`current_user`'）を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.OLD_CURRENT_USER
RETURN VARCHAR2;
```
