# GET_ENDIANNESS

`GET_ENDIANNESS` 関数は、データベースプラットフォームのバイト順序を取得するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.GET_ENDIANNESS
RETURN NUMBER;
```

## 戻り値

`NUMBER` 型の値で、データベースプラットフォームのバイト順序を表します。1はビッグエンディアン、2はリトルエンディアンを表します。
