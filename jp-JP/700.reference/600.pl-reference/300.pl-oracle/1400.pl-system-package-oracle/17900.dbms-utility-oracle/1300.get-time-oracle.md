# GET_TIME

`GET_TIME` 関数は、現在時刻を100分の1秒（0.01秒）単位で返します。

`GET_TIME` 関数は主に経過時間の算出に使用されます。サブルーチンはプロセスの開始時と終了時の2回呼び出され、後からの値から最初の値を引くことで経過時間が算出されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されています。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.GET_TIME
RETURN NUMBER;
```

## 戻り値

時間はサブルーチンが呼び出された時点から、100分の1秒（0.01秒）単位で計算されます。

## 使用方法

戻り値の範囲は-2147483648から2147483647です。アプリケーションは時間間隔を算出する際に、この数値の符号を考慮する必要があります。例えば、2つの値が共に負の場合、アプリケーションのロジックでは、最初の（早い方の）値がゼロに近い2番目の（遅い方の）値より大きいことを許容する必要があります。同様に、最初の（早い方の）値が負の数で、2番目の（遅い方の）値が正の数である場合も許容する必要があります。
