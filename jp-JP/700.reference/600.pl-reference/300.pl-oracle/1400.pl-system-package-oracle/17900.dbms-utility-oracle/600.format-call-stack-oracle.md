# FORMAT_CALL_STACK

`FORMAT_CALL_STACK` 関数は、現在の呼び出しスタックをフォーマットするために使用されます。

`FORMAT_CALL_STACK` は、呼び出しスタックにアクセスするすべてのストアドプロシージャやトリガーで使用でき、デバッグに役立ちます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.FORMAT_CALL_STACK
RETURN VARCHAR2;
```

## 戻り値

最大2000バイトの呼び出しスタックを返します。
