# GET_PARAMETER_VALUE

`GET_PARAMETER_VALUE` 関数は、指定された `init.ora` パラメータの値を取得するために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.GET_PARAMETER_VALUE (
   parnam     IN             VARCHAR2,
   intval         IN OUT    BINARY_INTEGER,
   strval         IN OUT    VARCHAR2,
   listno         IN            BINARY_INTEGER DEFAULT 1)
  RETURN BINARY_INTEGER;
```

## パラメータの説明

|   パラメータ   |        説明        |
|--------|------------------|
| parnam | パラメータ名。            |
| intval | 整数パラメータ値または文字列パラメータ値の長さ。 |
| strval | 文字列パラメータ値。          |
| listno | リストアイテム番号。          |

## 戻り値

以下のパラメータタイプを返します：

* 0：`INTEGER`/`BOOLEAN` パラメータ

* 1：文字列/ファイルパラメータ

## 使用方法

* この関数を実行するには、`V$PARAMETER` 動的ビューに対する `SELECT` 権限が必要です。

* `DBMS_UTILITY.GET_PARAMETER_VALUE` を使用する場合、`init.ora` の設定が以下のような場合、`/dir1` 内の最初のパラメータ設定のみが返されます：

  ```sql
  utl_file_dir = /dir1
  utl_file_dir = /dir2
  ```

  次の設定を使用する場合、カンマ区切りの完全な文字列が返されます：

  ```sql
  utl_file_dir = /dir1, /dir2
  ```
