# CURRENT_INSTANCE

`CURRENT_INSTANCE` 関数は、現在の接続におけるインスタンス番号を返します。接続先のインスタンスが停止している場合は、`NULL` を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.CURRENT_INSTANCE
RETURN NUMBER;
```
