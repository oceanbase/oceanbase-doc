# CURRENT_INSTANCE

`CURRENT_INSTANCE` 関数は、現在の接続におけるインスタンス番号を返します。接続されているインスタンスが閉じられた場合は、`NULL` を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.CURRENT_INSTANCE
RETURN NUMBER;
```
