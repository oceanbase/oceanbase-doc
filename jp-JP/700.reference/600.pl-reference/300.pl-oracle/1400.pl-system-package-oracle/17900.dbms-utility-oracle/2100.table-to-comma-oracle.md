# TABLE_TO_COMMA

TABLE_TO_COMMAストアドプロシージャは、PLテーブルをカンマ区切りのテーブル名リストに変換するために使用されます。PLテーブルの値は `1..n` であり、`n+1` は終端値として `NULL` です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースの現在のバージョンでは、<code>DBMS_UTILITY</code> システムパッケージはUTF-16エンコードの文字セットの使用をサポートしていません。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_UTILITY.TABLE_TO_COMMA (
   tab        IN  UNCL_ARRAY,
   tablen   OUT BINARY_INTEGER,
   list        OUT VARCHAR2);

DBMS_UTILITY.TABLE_TO_COMMA (
   tab        IN  lname_array,
   tablen   OUT BINARY_INTEGER,
   list         OUT VARCHAR2);
```

## パラメータの説明

|   パラメータ   |      説明       |
|--------|---------------|
| tab    | テーブル名リストを含むPLテーブル。 |
| tablen | PLテーブル内のテーブル数。    |
| list   | カンマ区切りのテーブルリスト。    |

## 戻り値

カンマ区切りのリストと、その中の要素数。
