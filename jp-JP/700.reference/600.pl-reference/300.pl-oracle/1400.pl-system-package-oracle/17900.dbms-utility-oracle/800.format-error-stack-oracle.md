# FORMAT_ERROR_STACK

`FORMAT_ERROR_STACK` 関数は、現在のエラースタックをフォーマットするために使用されます。

例外ハンドラーは `FORMAT_ERROR_STACK` を使用して完全なエラースタックを確認できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.FORMAT_ERROR_STACK
RETURN VARCHAR2;
```

## 戻り値

最大2000バイトのエラースタックを返します。
