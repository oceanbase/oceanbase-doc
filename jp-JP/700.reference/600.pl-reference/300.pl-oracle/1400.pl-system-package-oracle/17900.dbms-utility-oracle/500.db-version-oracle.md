# DB_VERSION

`DB_VERSION` ストアドプロシージャは、データベースのバージョン情報を返すために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.DB_VERSION (
version           OUT VARCHAR2,
compatibility  OUT VARCHAR2);
```

## パラメータ説明

|      パラメータ       |                                       説明                                        |
|---------------|---------------------------------------------------------------------------------|
| version       | データベースの内部ソフトウェアバージョンを表す文字列（例：2.3.0）です。この文字列の長さは可変で、データベースのバージョンによって決まります。                 |
| compatibility | `init.ora`パラメータで設定されたデータベースの互換性設定です。`init.ora`ファイルでこのパラメータが指定されていない場合は、`NULL`を返します。 |
