# ACTIVE_INSTANCES

`ACTIVE_INSTANCES` ストアドプロシージャは、アクティブなインスタンスを返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.ACTIVE_INSTANCES (
instance_table   OUT INSTANCE_TABLE,
instance_count   OUT NUMBER);
```

## パラメータ説明

|       パラメータ       |               説明                |
|----------------|---------------------------------|
| instance_table | アクティブなインスタンスの番号と名前を含むリストです。現在インスタンスが起動していない場合、リストは空になります。 |
| instance_count | アクティブなインスタンスの数。                        |
