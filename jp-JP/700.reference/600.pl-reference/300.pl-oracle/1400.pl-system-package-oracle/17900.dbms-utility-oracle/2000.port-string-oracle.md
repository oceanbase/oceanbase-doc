# PORT_STRING

`PORT_STRING` 関数は、オペレーティングシステムとデータベースの `TWO TASK PROTOCOL` バージョンを識別する文字列を返します。

文字列の最大長はポート設定によって決まります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_UTILITY.PORT_STRING
RETURN VARCHAR2;
```
