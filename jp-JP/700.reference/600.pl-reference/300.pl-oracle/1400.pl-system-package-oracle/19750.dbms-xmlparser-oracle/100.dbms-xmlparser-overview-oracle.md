# DBMS_XMLPARSERの概要

`DBMS_XMLPARSER` システムパッケージは、`CLOB` または `VARCHAR2` からXMLテキストを解析し、`DBMS_XMLDOM` がアクセス可能なDOMツリーを構築するために使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このシステムパッケージはOceanBaseデータベースV4.4.2 BP2から導入されました。</p>
</main>

## DBMS_XMLPARSER権限の説明

`DBMS_XMLPARSER` システムパッケージの `EXECUTE` 権限は `PUBLIC` に付与されています。現在のユーザーは、このパッケージ内のサブプログラムを使用する権限を持っています。

## DBMS_XMLPARSERの使用方法

`DBMS_XMLPARSER` は、`CLOB` または `VARCHAR2` 内のXMLを読み取り、解析してDOMツリーを構築します。解析が成功した場合は、`GETDOCUMENT` を使用して `DOMDOCUMENT` ハンドルを取得し、その後 `DBMS_XMLDOM` のサブプログラムを使用してノードを走査し、要素とノード値を読み取ります。解析に失敗した場合は、アプリケーションエラーがスローされます。

一般的な処理の流れは次のとおりです。

1. `NEWPARSER` を呼び出してパーサー（`Parser` ハンドル）を作成します。
2. `PARSECLOB` を呼び出して `CLOB` 内のXMLテキストを解析するか、`PARSEBUFFER` を呼び出して `VARCHAR2` 内の短いXMLテキストを解析します。
3. `GETDOCUMENT` を呼び出して、`DBMS_XMLDOM.DOMDOCUMENT` ハンドルを取得します。
4. [DBMS_XMLDOM](../19500.dbms-xmldom-oracle/100.dbms-xmldom-overview-oracle.md) 関連のサブプログラムを使用して、解析結果にアクセスします。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>現在のバージョンでは、<code>PARSECLOB</code> を使用して <code>CLOB</code> 内のXMLを解析し、<code>PARSEBUFFER</code>（V4.4.2 BP3以降でサポート）を使用して <code>VARCHAR2</code> の短いXMLテキストを解析し、DOMインターフェースからアクセスできる解析ツリーを構築します。ファイルパスやURLからの解析、DTD検証、エラーログなどの機能は、現在のサポート範囲外です。</p>
</main>

`XMLType` の作成と変換については、[XMLTypeの概要](../29600.xmltype-oracle/100.xmltype-overview-oracle.md)を参照してください。
