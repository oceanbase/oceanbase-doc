# NEWPARSER

`NEWPARSER` 関数は、新しいXMLパーサーインスタンスを割り当てて初期化し、その後の `PARSECLOB`、`GETDOCUMENT` などのサブルーチンで使用するための `PARSER` ハンドルを返します。通常、XML解析プロセスの最初のステップとして呼び出されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2バージョンでは、このサブルーチンはOceanBaseデータベースV4.4.2 BP2バージョンから導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLPARSER.NEWPARSER;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| なし | なし。 |

## 戻り値

新しく作成された `DBMS_XMLPARSER.PARSER` 型のパーサーハンドル。

## 使用方法

各解析プロセスごとに `NEWPARSER` を1回ずつ呼び出す必要があります。使用後は `FREEPARSER` を呼び出してリソースを解放し、ハンドルのリークを防いでください。

## 例

この例では、`DBMS_XMLPARSER` システムパッケージを使用してXMLパーサーインスタンスを作成します：

```sql
-- パーサーハンドル変数を宣言
DECLARE
  p DBMS_XMLPARSER.PARSER;
BEGIN
  -- パーサーインスタンスの作成
  p := DBMS_XMLPARSER.NEWPARSER;
  -- パーサーハンドルの解放
  DBMS_XMLPARSER.FREEPARSER(p);
END;
/
```
