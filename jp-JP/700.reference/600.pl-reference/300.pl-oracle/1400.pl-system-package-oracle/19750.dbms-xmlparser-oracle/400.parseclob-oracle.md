# PARSECLOB

`PARSECLOB` プロシージャは、指定されたパーサインスタンス上で、渡された `CLOB` 文字列をXMLドキュメントに解析します。解析が成功すると、パーサー内部にDOMツリー構造が生成され、その後 `GETDOCUMENT` メソッドでこのDOMツリーを取得できます。

## 構文

```sql
DBMS_XMLPARSER.PARSE_CLOB (
   parser   IN DBMS_XMLPARSER.PARSER,
   xml_text IN CLOB);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| parser | `NEWPARSER` によって作成された `DBMS_XMLPARSER.PARSER` ハンドルです。 |
| xml_text | 解析対象のXMLテキストで、`CLOB` 形式で渡されます。`CLOB` へ暗黙的に変換可能な文字列リテラルも渡すことができます。 |

## 使用方法

解析処理中に不正なXMLや空文書などの異常が発生した場合、エラーが直接返されます。解析が成功した場合は、直ちに `GETDOCUMENT` を使用して `DBMS_XMLDOM.DOMDOCUMENT` ハンドルを取得し、`DBMS_XMLDOM` の関連サブプログラムを使用してDOMツリーの走査やノードの読み取り操作を行うことを推奨します。

## 例

この例では、`DBMS_XMLPARSER` システムパッケージを使用してパーサー上でXMLドキュメントを解析し、CLOB形式で渡し、最後にパーサーハンドルを解放します：

```sql
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  xml CLOB;
BEGIN
  -- パーサーインスタンスの作成
  p := DBMS_XMLPARSER.NEWPARSER;
  -- パーサー上でXMLドキュメントを解析
  xml := '<root/>';
  -- パーサーでXMLドキュメントを解析し、CLOB形式で渡す
  DBMS_XMLPARSER.PARSECLOB(p, xml);
  -- パーサーハンドルを解放する
  DBMS_XMLPARSER.FREEPARSER(p);
END;
/
```
