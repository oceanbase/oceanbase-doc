# PARSER

`PARSER`は、変数やパラメータ内でパーサーインスタンスを保持するためのパーサーハンドル型です。このインスタンスは`NEWPARSER`で作成し、`FREEPARSER`で解放します。また、`PARSECLOB`や`GETDOCUMENT`などのサブプログラム間でパーサーインスタンスを受け渡すためにも使用されます。このハンドル自体は不透明型です。

## 構文

```sql
parser DBMS_XMLPARSER.PARSER;
```

## 変数の説明

| **変数** | **説明** |
|----------|----------|
| parser | パーサーハンドル。 |

## 戻り値

パーサーハンドル。

## 使用方法

`DBMS_XMLPARSER.PARSER`はPL変数でパーサーハンドルを宣言するための専用の型であり、直接構築することはできません。`NEWPARSER`サブプログラムを使用して生成する必要があります。

## 関連サブプログラム

| **サブプログラム** | **説明** |
|------------|----------|
| [NEWPARSER](../19750.dbms-xmlparser-oracle/300.newparser-oracle.md) | パーサーインスタンスを作成します。このサブプログラムには、`DBMS_XMLPARSER.PARSER`型のパーサーハンドルを入力パラメータとして渡す必要があります。 |
| [PARSECLOB](../19750.dbms-xmlparser-oracle/400.parseclob-oracle.md) | パーサー上で`CLOB`を解析します。このサブプログラムには、`DBMS_XMLPARSER.PARSER`型のパーサーハンドルと`CLOB`型のXMLテキストを入力パラメータとして渡す必要があります。 |
| [GETDOCUMENT](../19750.dbms-xmlparser-oracle/500.getdocument-oracle.md) | DOMドキュメントハンドルを取得します。このサブプログラムには、`DBMS_XMLPARSER.PARSER`型のパーサーハンドルを入力パラメータとして渡す必要があります。 |
| [FREEPARSER](../19750.dbms-xmlparser-oracle/600.freeparser-oracle.md) | パーサーを解放します。このサブプログラムには、`DBMS_XMLPARSER.PARSER`型のパーサーハンドルを入力パラメータとして渡す必要があります。 |

## 例

この例では、`DBMS_XMLPARSER`システムパッケージを使用してXMLパーサーインスタンスを作成し、最後にパーサーハンドルを解放します。

```sql
-- パーサーハンドル変数の宣言
DECLARE
  p DBMS_XMLPARSER.PARSER;
BEGIN
  -- パーサーインスタンスの作成
  p := DBMS_XMLPARSER.NEWPARSER;
  -- パーサーハンドルの解放
  DBMS_XMLPARSER.FREEPARSER(p);
END;
/
```
