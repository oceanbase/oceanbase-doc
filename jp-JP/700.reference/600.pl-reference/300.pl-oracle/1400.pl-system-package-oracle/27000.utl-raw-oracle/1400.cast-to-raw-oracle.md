# CAST_TO_RAW

`CAST_TO_RAW` 関数は、特定のバイト数で表される `VARCHAR2` 値を、同じバイト数を持つ RAW 値に変換します。

データ自体は一切変更されませんが、データ型が `RAW` データ型に変換されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
UTL_RAW.CAST_TO_RAW (
   c  IN VARCHAR2)
RETURN RAW;
```

## パラメータの説明

| **パラメータ** |         **説明**          |
|--------|-------------------------|
| c      | `RAW` に変更された `VARCHAR2` データ。 |

## 戻り値

| **戻り値** |                  **説明**                  |
|---------|------------------------------------------|
| RAW     | 入力された `VARCHAR2` と同じデータと等しいバイト長を含み、先行する長さフィールドがないことを示します。 |
| NULL    | `c` の入力パラメータが `NULL` であることを示します。                         |
