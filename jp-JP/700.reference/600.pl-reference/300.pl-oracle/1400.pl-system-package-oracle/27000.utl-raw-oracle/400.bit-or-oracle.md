# BIT_OR

`BIT_OR` 関数は、`RAW r2` を使用して `RAW r1` の値に対してビット単位の論理「または」演算を実行し、結果として `RAW` 値を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.BIT_OR (
   r1 IN RAW,
   r2 IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |          **説明**          |
|--------|--------------------------|
| r1     | `r2` と「または」演算を行った `RAW` 値。 |
| r2     | `r1` と「または」演算を行った `RAW` 値。 |

## 戻り値

| **戻り値** |           **説明**           |
|---------|----------------------------|
| RAW     | `r1` と `r2` の「または」の結果。        |

## 使用方法

`r1` と `r2` の長さが異なる場合、「または」演算は短い `RAW` 値の最後のバイトで終了し、長い `RAW` 値の未処理部分が部分的な結果に追加されます。結果の長さは、2つの入力 `RAW` 値のうち長い方と同じになります。
