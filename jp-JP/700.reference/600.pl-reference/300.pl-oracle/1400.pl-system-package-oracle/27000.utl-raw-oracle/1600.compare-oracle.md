# COMPARE

`COMPARE` 関数は、2つの `RAW` 値を比較します。長さが異なる場合、オプションパラメータ `pad` に基づいて、短い方の `RAW` の長さを右側に拡張します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.COMPARE (
     r1  IN RAW,
     r2  IN RAW,
     pad IN RAW DEFAULT NULL)
  RETURN NUMBER;
```

## パラメータの説明

| **パラメータ** |                     **説明**                  |
|--------|-------------------------------------------------|
| r1     | 比較する最初の `RAW` 値。`NULL` または長さ0も指定可能です。                    |
| r2     | 比較する2番目の `RAW` 値。`NULL` または長さ0も指定可能です。                    |
| pad    | オプションパラメータです。`r1` または `r2` のどちらか一方の短い方を拡張します。デフォルト値は `x'00'` です。 |

## 戻り値

| **戻り値** |                           **説明**                       |
|---------|------------------------------------------------------------|
| NUMBER  | 両方の `RAW` バイト文字列がともに `NULL` または同じ場合は0を返します。それ以外の場合は、最初にマッチしないバイトの位置（1から始まる）を返します。 |
