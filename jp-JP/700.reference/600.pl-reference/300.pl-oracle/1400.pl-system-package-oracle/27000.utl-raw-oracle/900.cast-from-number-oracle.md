# CAST_FROM_NUMBER

`CAST_FROM_NUMBER` 関数は、`NUMBER` 値を `RAW` のバイナリ形式で返します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>NUMBER</code> 型について、OceanBaseデータベースとOracleの実装方法は異なります。返される <code>RAW</code> は、OceanBaseデータベース内部で表現される <code>NUMBER</code> フォーマットです。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
UTL_RAW.CAST_FROM_NUMBER (
   n  IN NUMBER)
 RETURN RAW;
```

## パラメータ説明

パラメータ `n` は `NUMBER` 値です。

## 戻り値

`NUMBER` 値のバイナリ表現形式（RAW）を返します。

## 例

```sql
obclient> SELECT UTL_RAW.CAST_FROM_NUMBER(123.456) FROM DUAL;
+-----------------------------------+
| UTL_RAW.CAST_FROM_NUMBER(123.456) |
+-----------------------------------+
| 020000C07B00000000022E1B          |
+-----------------------------------+
1 row in set

obclient> SELECT UTL_RAW.CAST_FROM_NUMBER(-123.456) FROM DUAL;
+------------------------------------+
| UTL_RAW.CAST_FROM_NUMBER(-123.456) |
+------------------------------------+
| 020000407B00000000022E1B           |
+------------------------------------+
1 row in set
```
