# BIT_COMPLEMENT

`BIT_COMPLEMENT` 関数は、`RAW r` の値のビット単位の補数を求め、結果を `RAW` として返します。結果の長さは入力された `RAW r` の長さと同じです。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.BIT_COMPLEMENT (
   r IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |    **説明**     |
|--------|---------------|
| r      | 補数を求めるRAW型の値。 |

## 戻り値

| **データ型** |    **説明**      |
|---------|------------------|
| RAW     | `r` の「補数」。       |
