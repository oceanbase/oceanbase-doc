# REVERSE

`REVERSE` 関数は、`RAW r` のバイト列を先頭から末尾まで逆順にします。

例えば、'nba' は 'abn' に反転されます。結果の長さは `RAW` の入力長と同じです。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.REVERSE (
     r IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |  **説明**   |
|--------|-----------|
| r      | 反転する `RAW`。 |

## 戻り値

| **データ型** |     **説明**     |
|---------|----------------|
| RAW     | `r` のバイト列を逆順にした値を含みます。 |

## 例外

|   **例外**    |       **説明**        |
|-------------|---------------------|
| VALUE_ERROR | `r` が `NULL` または長さが0の場合。 |
