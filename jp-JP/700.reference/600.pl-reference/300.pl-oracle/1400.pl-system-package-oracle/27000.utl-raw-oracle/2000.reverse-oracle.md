# REVERSE

`REVERSE` 関数は、`RAW r` のバイト列を先頭から末尾まで逆順にするために使用されます。

例えば、'nba' は 'abn' に逆転します。結果の長さは `RAW` の入力長と同じです。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.REVERSE (
     r IN RAW)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |  **説明**   |
|--------|-----------|
| r      | 逆転する `RAW` データ。 |

## 戻り値

| **戻り値** |     **説明**     |
|---------|----------------|
| RAW     | `r` の「逆」値を含みます。 |

## 例外状況

|   **例外**    |       **説明**        |
|-------------|---------------------|
| VALUE_ERROR | `r`が`NULL`または長さが0の場合。 |
