# BIT_AND

`BIT_AND` 関数は、`RAW r1` と `RAW r2` の値に対してビット単位の論理「AND」演算を実行し、「AND」結果の `RAW` 値を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
UTL_RAW.BIT_AND (
   r1 IN RAW,
   r2 IN RAW)
RETURN RAW;
```

## パラメータ説明

| **パラメータ** |         **説明**         |
|--------|------------------------|
| r1     | `r2` と「AND」演算を行うRAW値。 |
| r2     | `r1` と「AND」演算を行うRAW値。 |

## 戻り値

| **戻り値** |          **説明**          |
|---------|--------------------------|
| RAW     | `r1` と `r2` の「AND」結果。      |

## 使用方法

`r1` と `r2` の長さが異なる場合、「AND」演算は短い `RAW` の最後のバイトで終了し、長い `RAW` の未処理部分が部分結果に追加されます。結果の長さは、2つの `RAW` のうち長い方と同じになります。
