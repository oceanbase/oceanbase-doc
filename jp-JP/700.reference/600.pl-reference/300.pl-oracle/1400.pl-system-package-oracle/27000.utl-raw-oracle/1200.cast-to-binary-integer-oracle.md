# CAST_TO_BINARY_INTEGER

`CAST_TO_BINARY_INTEGER` 関数は、`RAW` バイナリ形式で表される `BINARY_INTEGER` 値を `BINARY_INTEGER` に変換するために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.CAST_TO_BINARY_INTEGER (
   r          IN RAW
   endianess  IN PLS_INTEGER DEFAULT BIG_ENDIAN)
RETURN BINARY_INTEGER;
```

## パラメータ説明

| **パラメータ** | **説明** |
| --- | --- |
| r | `BINARY_INTEGER` の2進数表現です。 |
| endianess | `big_endian`または`little-endian`を表す`BINARY_INTEGER`値です。デフォルト値は`big_endian`です。 |

## 戻り値

`BINARY_INTEGER` 値を返します。
