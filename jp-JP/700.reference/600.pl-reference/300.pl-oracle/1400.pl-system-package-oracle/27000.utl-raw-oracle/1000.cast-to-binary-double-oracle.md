# CAST_TO_BINARY_DOUBLE

`CAST_TO_BINARY_DOUBLE` 関数は、`RAW` バイナリ形式で表された `BINARY_DOUBLE` 値を `BINARY_DOUBLE` に変換するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
UTL_RAW.CAST_TO_BINARY_DOUBLE (
   r          IN RAW
   endianess  IN PLS_INTEGER DEFAULT 1)
RETURN BINARY_DOUBLE;
```

## パラメータ説明

| **パラメータ** | **説明** |
| --- | --- |
| r | `BINARY_DOUBLE` の2進数表現形式。 |
| endianess | `big_endian` または `little-endian` を表す `BINARY_INTEGER` 値。デフォルト値は `big_endian` です。 |

## 戻り値

`BINARY_DOUBLE` 値を返します。

## 使用方法

- `RAW` パラメータが8バイトを超える場合、最初の8バイトのみが使用され、残りのバイトは無視されます。結果が `-0` の場合、`+0` を返します。結果が `NaN` の場合、戻り値は `BINARY_DOUBLE_NAN` となります。

- `RAW` パラメータが8バイト未満の場合、`VALUE_ERROR` 例外が発生します。

- 以下の表は、8バイトの `BINARY_DOUBLE` 値とIEEE 754倍精度形式とのマッピング関係です。

  ```sql
  byte 0: bit 63 ~ bit 56
  byte 1: bit 55 ~ bit 48
  byte 2: bit 47 ~ bit 40
  byte 3: bit 39 ~ bit 32
  byte 4: bit 31 ~ bit 24
  byte 5: bit 23 ~ bit 16
  byte 6: bit 15 ~ bit  8
  byte 7: bit  7 ~ bit  0
  ```

- パラメータ `endianess` は、`BINARY_DOUBLE` のバイトが `RAW` のバイトにどのようにマッピングされるかを示します。以下の行列のようになります。ここで、`rb0 ~ rb7` は `RAW` 内のバイトを指し、`db0 ~ db7` は `BINARY_DOUBLE` 内のバイトを指します。

  | **endianess** | **rb0** | **rb1** | **rb2** | **rb3** | **rb4** | **rb5** | **rb6** | **rb7** |
  | --- | --- | --- | --- | --- | --- | --- | --- | --- |
  | **big_endian** | db0 | db1 | db2 | db3 | db4 | db5 | db6 | db7 |
  | **little_endian** | db7 | db6 | db5 | db4 | db3 | db2 | db1 | db0 |

- `machine-endian` の場合、`RAW` パラメータの8バイトが返り値の `BINARY_DOUBLE` に直接コピーされます。ユーザーがビッグエンディアンマシンで `big_endian` を渡した場合でも、リトルエンディアンマシンで `little_endian` を渡した場合でも、効果は同じです。
