# LENGTH

`LENGTH` 関数は、`RAW r` のバイト長を返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.LENGTH (
     r  IN RAW)
RETURN NUMBER;
```

## パラメータ説明

| **パラメータ** |    **説明**     |
|--------|---------------|
| r      | 測定対象のバイト長を持つ `RAW` データ型の値。 |

## 戻り値

| **戻り値** |  **説明**   |
|---------|-----------|
| NUMBER  | `RAW`の現在の長さ |
