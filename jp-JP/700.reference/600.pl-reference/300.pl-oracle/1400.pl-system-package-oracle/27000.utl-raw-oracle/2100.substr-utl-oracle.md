# SUBSTR

`SUBSTR` 関数は、`RAW r` の `pos` バイト目から `len` バイトを返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.SUBSTR (
   r   IN RAW,
   pos IN BINARY_INTEGER,
   len IN BINARY_INTEGER DEFAULT NULL)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |                  **説明**                  |
|--------|------------------------------------------|
| r      | RAWから抽出するバイト数の文字列。                   |
| pos    | `r` からバイトを抽出する位置。                          |
| len    | `r` から抽出するバイト数。`RAW r` の `pos` ビットから計算します(オプション)。 |

## デフォルト値とオプションパラメータ

| **オプションパラメータ** |        **説明**        |
|----------|----------------------|
| len      | `pos` から `r` の終端までの範囲を指定します。 |

## 戻り値

|   **戻り値**    |           **説明**            |
|--------------|-----------------------------|
| portion of r | `pos` ビットから `len` バイトの長さを取得します。 |
| NULL         | `r` の入力パラメータが `NULL` です。            |

## 使用方法

* `pos` が正の場合、`SUBSTR` は `r` の先頭から数えて最初のバイトを見つけます。`pos` が負の場合、`SUBSTR` は `r` の末尾から逆算します。`pos` の値は0にすることはできません。

* `len` を省略した場合、`SUBSTR` は `r` の末尾までのすべてのバイトを返します。`len` の値は1以上でなければなりません。

## 例外状況

|   **例外**   |        **説明**           |
|-------------|-----------------------------|
| VALUE_ERROR | 以下の場合に `VALUE_ERROR` が返される可能性があります： <ul><li> `pos` が0または `r` の長さ以上の場合 </li> <li> `len` が1未満、または `r - (pos - 1)` より大きい場合。</li></ul>    |
