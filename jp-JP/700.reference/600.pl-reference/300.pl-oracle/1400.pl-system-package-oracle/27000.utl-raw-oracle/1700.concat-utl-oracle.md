# CONCAT

`CONCAT` 関数は、最大12個の `RAW` を1つの `RAW` に連結するために使用されます。連結サイズが32767バイトを超える場合、エラーが返されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
UTL_RAW.CONCAT (
      r1  IN RAW DEFAULT NULL,
      r2  IN RAW DEFAULT NULL,
      r3  IN RAW DEFAULT NULL,
      r4  IN RAW DEFAULT NULL,
      r5  IN RAW DEFAULT NULL,
      r6  IN RAW DEFAULT NULL,
      r7  IN RAW DEFAULT NULL,
      r8  IN RAW DEFAULT NULL,
      r9  IN RAW DEFAULT NULL,
      r10 IN RAW DEFAULT NULL,
      r11 IN RAW DEFAULT NULL,
      r12 IN RAW DEFAULT NULL)
  RETURN RAW;
```

## パラメータの説明

`r1` .... `r12` は、連結する `RAW` の項目です。

## 戻り値

| **戻り値** |  **説明**   |
|---------|-----------|
| RAW     | 連結された項目を含みます。 |

## 例外

入力の長さの合計が `RAW` の最大許容長（32767バイト）を超えると、エラーが発生します。
