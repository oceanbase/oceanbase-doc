# CAST_TO_VARCHAR2

`CAST_TO_VARCHAR2` 関数は、一定のバイト数で表される `RAW` 値を、同じバイト数を持つ `VARCHAR2` 値に変換します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>VARCHAR2</code> に変換する場合、現在のグローバル化サポート文字セットがその <code>VARCHAR2</code> 内の文字に適用されます。</p>
  </main>

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
UTL_RAW.CAST_TO_VARCHAR2 (
    r IN RAW)
RETURN VARCHAR2;
```

## パラメータの説明

| **パラメータ** |         **説明**          |
|--------|-------------------------|
| r      | `RAW` 型データを `VARCHAR2` 型に変換したもの。 |

## 戻り値

| **戻り値** |      **説明**      |
|---------|------------------|
| RAW     | 入力された `RAW` と同じデータを含みます。 |
