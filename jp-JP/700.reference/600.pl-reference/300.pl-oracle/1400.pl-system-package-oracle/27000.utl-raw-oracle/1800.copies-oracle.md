# COPIES

`COPIES` 関数は、n 個の `r` を連結したものを返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
UTL_RAW.COPIES (
     r IN RAW,
     n IN NUMBER)
  RETURN RAW;
```

## パラメータの説明

| **パラメータ** |       **説明**       |
|--------|--------------------|
| r      | 複製する `RAW`。         |
| n      | `RAW` の複製回数（正の整数でなければなりません）。 |

## 戻り値

n 回複製された `RAW` を返します。

## 例外状況

|   **例外**    |        **説明**      |
|-------------|------------------------|
| VALUE_ERROR | 以下の場合が発生する可能性があります： <ul><li> r が欠落している、`NULL` である、または長さが0である。</li>   <li> n \< 1。</li>   <li> 結果の長さがRAWの最大長を超えている。</li></ul>    |
