# CREATEELEMENT

`CREATEELEMENT` 関数は、指定したDOMドキュメントに要素ノードを作成します。要素名は `tagname` で指定します。作成した要素は、`MAKENODE` で汎用ノードに変換し、`APPENDCHILD` でDOMツリーに追加できます。

  <h4>機能の適用範囲</h4>

## 構文

```sql
DBMS_XMLDOM.createElement (
   doc     IN DBMS_XMLDOM.DOMDOCUMENT,
   tagname IN VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | 対象の `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。 |
| tagname | 要素のタグ名。 |

## 戻り値

`DBMS_XMLDOM.DOMELEMENT` 要素ノードハンドル。

## 使用方法

作成した要素は、まだドキュメントツリーに追加されていません。`MAKENODE` で `DOMNODE` に変換してから、`APPENDCHILD` を使用して親ノードに追加する必要があります。

## 例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
