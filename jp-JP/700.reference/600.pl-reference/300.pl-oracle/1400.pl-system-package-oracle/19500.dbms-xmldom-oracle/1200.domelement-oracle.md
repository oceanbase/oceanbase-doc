# DOMELEMENT

`DOMELEMENT` は、XML要素を表すDOM要素ノードのハンドル型です。`CREATEELEMENT`、`GETDOCUMENTELEMENT`、`SETATTRIBUTE` などのインターフェースの戻り値や入力パラメータとして使用できます。このハンドルは不透明型であり、DOM関連APIへの入力または出力にのみ使用できます。内部構造に直接アクセスすることはできません。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、この型はOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
elem DBMS_XMLDOM.DOMELEMENT;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| elem | 要素ノードのハンドル。 |

## 戻り値

要素ノードのハンドル。

## 使用方法

`DOMELEMENT` は通常、[CREATEELEMENT](1600.createelement-oracle.md) または [GETDOCUMENTELEMENT](2300.getdocumentelement-oracle.md) によって返されます。[MAKENODE](1800.makenode-oracle.md) を使用すると、汎用の `DOMNODE` に変換できます。

## 例

```sql
DECLARE
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  NULL;
END;
/
```
