# SETCHARSET

`SETCHARSET` プロシージャは、DOMドキュメントのシリアライズ時に使用する文字エンコーディングを設定します。XML宣言内のencoding情報や、その後の出力動作に影響する場合があります。

  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.setCharset (
   doc     IN DBMS_XMLDOM.DOMDOCUMENT,
   charset IN VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | 対象の `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。 |
| charset | 文字セット名。例：`UTF-8`。 |

## 戻り値

戻り値はありません。

## 使用方法

通常は、`WRITETOBUFFER` または `WRITETOCLOB` を呼び出してシリアライズする前に設定します。

## 例

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.setCharset(doc, 'UTF-8');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
