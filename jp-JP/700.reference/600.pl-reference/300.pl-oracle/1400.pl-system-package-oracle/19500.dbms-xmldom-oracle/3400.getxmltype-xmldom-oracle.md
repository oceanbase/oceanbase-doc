# GETXMLTYPE

`GETXMLTYPE` 関数は、DOMドキュメントオブジェクトを `XMLTYPE` オブジェクトに変換します。これにより、SQL/XML、`XMLType` のメンバーメソッド、またはXMLからPL/SQLオブジェクトへの変換機能を引き続き使用できます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.getXmlType (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | 対象の `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。 |

## 戻り値

`XMLTYPE` インスタンス。

## 使用方法

`XMLTYPE.TOOBJECT` と組み合わせて使用できます。まずDOMでXMLを構築または解析し、次に `XMLType` に変換してから、最後にPL/SQLオブジェクトにマッピングします。

## 例

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
  x   XMLTYPE;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  x := DBMS_XMLDOM.getXmlType(doc);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
