# GETNODENAME

`GETNODENAME` 関数は、指定したDOMノードのノード名を取得します。要素ノードでは要素名、属性ノードでは属性名を返します。テキストノードなどでは、Oracle DOMのセマンティクスに従って対応するノード名を返します。

## 構文

```sql
DBMS_XMLDOM.getNodeName (
   n IN DBMS_XMLDOM.DOMNODE);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| n | 照会対象の `DBMS_XMLDOM.DOMNODE` ハンドル。 |

## 戻り値

ノード名。型は `VARCHAR2` です。

## 使用方法

名前空間プレフィックスを持つ要素では、戻り値にプレフィックスが含まれることがあります。ローカル名のみが必要な場合は、`GETLOCALNAME` を使用してください。

## 例

```sql
DECLARE
  n         DBMS_XMLDOM.DOMNODE;
  node_name VARCHAR2(32767);
BEGIN
  node_name := DBMS_XMLDOM.getNodeName(n);
END;
/
```
