# MAKENODE

`MAKENODE` 関数は、`DOMDOCUMENT`、`DOMELEMENT`、`DOMTEXT`、`DOMATTR`、`DOMCHARACTERDATA` などの具体的なDOMオブジェクトを、汎用の `DOMNODE` ハンドルに変換します。これにより、`APPENDCHILD`、`REMOVECHILD`、`GETNODENAME` などのノードレベルのインターフェースで統一的に扱えます。

## 構文

```sql
DBMS_XMLDOM.makeNode (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);

DBMS_XMLDOM.makeNode (
   elem IN DBMS_XMLDOM.DOMELEMENT);

DBMS_XMLDOM.makeNode (
   text IN DBMS_XMLDOM.DOMTEXT);

DBMS_XMLDOM.makeNode (
   attr IN DBMS_XMLDOM.DOMATTR);

DBMS_XMLDOM.makeNode (
   character_data IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc / elem / text / attr / character_data | 変換対象の具体的なDOMオブジェクトのハンドル。 |

## 戻り値

`DBMS_XMLDOM.DOMNODE` 汎用ノードハンドル。

## 使用方法

各オーバーロードは、ドキュメント、要素、テキスト、属性、または文字データのハンドルを受け取り、共通の `DOMNODE` を返します。これにより、後続のノードレベルの操作を行えます。

## 例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
  node DBMS_XMLDOM.DOMNODE;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  node := DBMS_XMLDOM.makeNode(elem);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
