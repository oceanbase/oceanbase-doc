# DOMATTR

`DOMATTR` は、DOM属性ノードのハンドル型です。XML要素の属性に関する操作の戻り値や入力パラメータとして使用します。このハンドルは不透明型であり、DOM関連APIへの入力または出力にのみ使用できます。内部構造に直接アクセスすることはできません。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、この型はOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
attr DBMS_XMLDOM.DOMATTR;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| attr | 属性ノードのハンドル。 |

## 戻り値

属性ノードのハンドル。

## 使用方法

`DOMATTR` は通常、属性関連インターフェースの戻り値や入力パラメータとして使用します。[MAKENODE](1800.makenode-oracle.md) を使用すると、汎用の `DOMNODE` に変換できます。

## 例

```sql
DECLARE
  attr DBMS_XMLDOM.DOMATTR;
BEGIN
  NULL;
END;
/
```
