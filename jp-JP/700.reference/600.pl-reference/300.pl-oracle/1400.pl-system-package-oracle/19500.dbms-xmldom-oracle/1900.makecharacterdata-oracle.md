# MAKECHARACTERDATA

`MAKECHARACTERDATA` 関数は、汎用DOMノードを文字データノードのハンドルに変換します。変換後は、`GETDATA` を使用してノード内の文字データの内容を取得できます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.makeCharacterData (
   node IN DBMS_XMLDOM.DOMNODE);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| node | 変換対象の `DBMS_XMLDOM.DOMNODE` ハンドル。 |

## 戻り値

`DBMS_XMLDOM.DOMCHARACTERDATA` 文字データノードハンドル。

## 使用方法

変換が意味を持つのは、ノード自体がテキストノードなどの文字データノードである場合のみです。変換後は `GETDATA` を呼び出して内容を読み取れます。

## 例

```sql
DECLARE
  doc            DBMS_XMLDOM.DOMDOCUMENT;
  text           DBMS_XMLDOM.DOMTEXT;
  node           DBMS_XMLDOM.DOMNODE;
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  text := DBMS_XMLDOM.createTextNode(doc, 'hello');
  node := DBMS_XMLDOM.makeNode(text);
  character_data := DBMS_XMLDOM.makeCharacterData(node);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
