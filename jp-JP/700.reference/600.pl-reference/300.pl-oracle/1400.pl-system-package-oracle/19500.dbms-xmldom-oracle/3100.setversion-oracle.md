# SETVERSION

`SETVERSION` プロシージャは、DOMドキュメントのXMLバージョン情報を設定します。一般的な値は `1.0` で、後続のドキュメントのシリアライズに使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.setVersion (
   doc     IN DBMS_XMLDOM.DOMDOCUMENT,
   version IN VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | 対象の `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。 |
| version | XMLバージョン番号。例：`1.0`。 |

## 戻り値

戻り値はありません。

## 使用方法

通常は、`WRITETOBUFFER` または `WRITETOCLOB` を呼び出してシリアライズする前に設定します。

## 例

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.setVersion(doc, '1.0');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
