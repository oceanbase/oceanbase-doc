# GETDOCUMENTELEMENT

`GETDOCUMENTELEMENT` 関数は、DOMドキュメントのルート要素ノードを返します。このインターフェースは、ドキュメントオブジェクトから要素ツリーの走査、属性の読み取り、子ノードの操作を開始する際によく使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

  <h4>説明</h4>

## 構文

```sql
DBMS_XMLDOM.getDocumentElement (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | 対象の `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。 |

## 戻り値

`DBMS_XMLDOM.DOMELEMENT` ルート要素ハンドル。

## 使用方法

ドキュメントにまだルート要素がない場合は、NULLハンドルを返します。`ISNULL` と組み合わせて、戻り値がNULLかどうかを確認できます。

## 例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.getDocumentElement(doc);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
