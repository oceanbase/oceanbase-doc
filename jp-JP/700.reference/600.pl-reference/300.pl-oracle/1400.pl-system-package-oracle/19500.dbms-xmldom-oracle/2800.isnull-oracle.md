# ISNULL

`ISNULL` 関数は、DOMハンドルがNULLかどうかを判定します。`GETFIRSTCHILD`、`GETDOCUMENTELEMENT`、`MAKENODE` などのインターフェースの戻り値に対するNULLチェックによく使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.isNull (
   n IN DBMS_XMLDOM.DOMNODE);

DBMS_XMLDOM.isNull (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);

DBMS_XMLDOM.isNull (
   elem IN DBMS_XMLDOM.DOMELEMENT);

DBMS_XMLDOM.isNull (
   text IN DBMS_XMLDOM.DOMTEXT);

DBMS_XMLDOM.isNull (
   attr IN DBMS_XMLDOM.DOMATTR);

DBMS_XMLDOM.isNull (
   character_data IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| n / doc / elem / text / attr / character_data | チェック対象のDOMハンドル。 |

## 戻り値

ハンドルがNULLの場合は `TRUE`、それ以外の場合は `FALSE` を返します。

## 使用方法

各オーバーロードは、それぞれの種類のDOMハンドルを受け取ります。ノードへのアクセスを続ける前に、本関数を呼び出してNULLかどうかを確認することを推奨します。

## 例

```sql
DECLARE
  n       DBMS_XMLDOM.DOMNODE;
  is_null BOOLEAN;
BEGIN
  is_null := DBMS_XMLDOM.isNull(n);
END;
/
```
