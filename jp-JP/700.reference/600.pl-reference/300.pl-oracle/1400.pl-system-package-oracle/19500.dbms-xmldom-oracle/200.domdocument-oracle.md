# DOMDOCUMENT

`DOMDOCUMENT` は、解析済みXMLドキュメントのツリー全体を表す不透明なハンドルです。`GETELEMENTSBYTAGNAME` や `FREEDOCUMENT` などのAPIに、ドキュメントレベルの入力パラメータとして渡します。不透明型は解析済みXMLドキュメントへの参照を表し、DOM関連APIへの入力または出力にのみ使用できます。内部構造に直接アクセスすることはできません。

## 構文

```sql
doc DBMS_XMLDOM.DOMDOCUMENT;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | ドキュメントハンドル。 |

## 戻り値

ドキュメントハンドル。

## 使用方法

`DBMS_XMLDOM.DOMDOCUMENT`は通常、[DBMS_XMLPARSER.GETDOCUMENT](../19750.dbms-xmlparser-oracle/500.getdocument-oracle.md)によって返されます。V4.4.2 BP3以降では、[NEWDOMDOCUMENT](1500.newdomdocument-oracle.md)を使用して空のドキュメントを作成することもできます。

## 関連サブプログラム

| **サブプログラム** | **説明** |
|------------|----------|
| [GETELEMENTSBYTAGNAME](../19500.dbms-xmldom-oracle/700.getelementbytagname-oracle.md) | タグ名に基づいて、XMLドキュメント全体から一致するすべての要素ノードを一括取得するために使用されます。このメソッドでは、`DOMDOCUMENT`型のドキュメントハンドルを入力パラメータとして渡す必要があります。|
| [FREEDOCUMENT](../19500.dbms-xmldom-oracle/500.freedocument-oracle.md) | `DOMDOCUMENT`型ハンドルが識別するXMLドキュメントリソースを解放し、リソースリークを防ぎます。使用時には、解放対象のドキュメントハンドルを入力パラメータとして渡します。 |

## 例

この例では、`DBMS_XMLPARSER`システムパッケージを使用してXMLドキュメントを解析し、`DOMDOCUMENT`ハンドルを取得します。最後に`DBMS_XMLDOM`システムパッケージを使用してドキュメントリソースを解放します。

```sql
-- パーサーとドキュメントハンドルの変数を宣言する
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  -- パーサーインスタンスを作成する
  p := DBMS_XMLPARSER.NEWPARSER;
  -- パーサーでXMLドキュメントを解析する
  DBMS_XMLPARSER.PARSECLOB(p, '<root/>');
  -- XMLドキュメントのDOMDOCUMENTハンドルを取得する
  doc := DBMS_XMLPARSER.GETDOCUMENT(p);
  -- パーサーインスタンスを解放する
  DBMS_XMLPARSER.FREEPARSER(p);
  -- XMLドキュメントリソースを解放する
  DBMS_XMLDOM.FREEDOCUMENT(doc);
END;
/
```
