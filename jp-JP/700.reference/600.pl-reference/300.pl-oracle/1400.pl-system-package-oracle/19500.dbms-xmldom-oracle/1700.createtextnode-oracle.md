# CREATETEXTNODE

`CREATETEXTNODE` 関数は、指定したDOMドキュメントにテキストノードを作成します。テキスト内容は `data` で指定します。このノードは、要素ノードの子ノードとしてDOMツリーに追加できます。

## 構文

```sql
DBMS_XMLDOM.createTextNode (
   doc  IN DBMS_XMLDOM.DOMDOCUMENT,
   data IN VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc | 対象の `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。 |
| data | テキストノードの内容。 |

## 戻り値

`DBMS_XMLDOM.DOMTEXT` テキストノードハンドル。

## 使用方法

作成したテキストノードは通常、`MAKENODE` で `DOMNODE` に変換してから、`APPENDCHILD` を使用して要素ノードの下に追加します。

## 例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  text DBMS_XMLDOM.DOMTEXT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  text := DBMS_XMLDOM.createTextNode(doc, 'hello');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
