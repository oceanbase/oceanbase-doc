# GETLOCALNAME

`GETLOCALNAME` 関数は、指定したノードのローカル名を取得します。名前空間プレフィックスを持つノードでは、プレフィックスを含まないローカル名を返します。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>

## 構文

```sql
DBMS_XMLDOM.getLocalName (
   n IN DBMS_XMLDOM.DOMNODE);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| n | 照会対象の `DBMS_XMLDOM.DOMNODE` ハンドル。 |

## 戻り値

ノードのローカル名。型は `VARCHAR2` です。

## 使用方法

本関数は、`GETNODENAME` とは異なり、名前空間プレフィックスを含まないローカル名を返します。

## 例

```sql
DECLARE
  n          DBMS_XMLDOM.DOMNODE;
  local_name VARCHAR2(32767);
BEGIN
  local_name := DBMS_XMLDOM.getLocalName(n);
END;
/
```
