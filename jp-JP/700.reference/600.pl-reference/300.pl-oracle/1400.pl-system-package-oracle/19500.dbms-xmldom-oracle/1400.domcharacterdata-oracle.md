# DOMCHARACTERDATA

`DOMCHARACTERDATA` は、DOM文字データノードのハンドル型です。テキストやCDATAなどの文字データノードを統一的に処理するために使用し、`GETDATA` と組み合わせて文字データの内容を取得できます。このハンドルは不透明型であり、DOM関連APIへの入力または出力にのみ使用できます。内部構造に直接アクセスすることはできません。

## 構文

```sql
character_data DBMS_XMLDOM.DOMCHARACTERDATA;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| character_data | 文字データノードのハンドル。 |

## 戻り値

文字データノードのハンドル。

## 使用方法

`DOMCHARACTERDATA` は通常、[MAKECHARACTERDATA](1900.makecharacterdata-oracle.md) を使用して汎用の `DOMNODE` から変換して取得します。[GETDATA](2700.getdata-oracle.md) を使用すると、テキスト内容を読み取れます。

## 例

```sql
DECLARE
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
BEGIN
  NULL;
END;
/
```
