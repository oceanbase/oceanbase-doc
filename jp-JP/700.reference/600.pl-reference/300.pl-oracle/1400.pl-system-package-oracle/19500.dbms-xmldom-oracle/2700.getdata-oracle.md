# GETDATA

`GETDATA` 関数は、DOM文字データノード内のテキスト内容を取得します。`DOMCHARACTERDATA`、`DOMTEXT` などの文字データノードからテキストを読み取れます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.getData (
   cd IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| cd | 文字データノードの `DBMS_XMLDOM.DOMCHARACTERDATA` ハンドル。 |

## 戻り値

文字データの内容。型は `VARCHAR2` です。

## 使用方法

汎用の `DOMNODE` を保持している場合は、先に `MAKECHARACTERDATA` で `DOMCHARACTERDATA` に変換してから、本関数を呼び出す必要があります。

## 例

```sql
DECLARE
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
  data           VARCHAR2(32767);
BEGIN
  data := DBMS_XMLDOM.getData(character_data);
END;
/
```
