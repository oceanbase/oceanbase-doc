# GETFIRSTCHILD

`GETFIRSTCHILD` 関数は、指定したDOMノードの最初の子ノードを返します。子ノードが存在しない場合はNULLノードハンドルを返します。`ISNULL` と組み合わせて、戻り値がNULLかどうかを確認できます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.getFirstChild (
   n IN DBMS_XMLDOM.DOMNODE);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| n | 照会対象の `DBMS_XMLDOM.DOMNODE` ハンドル。 |

## 戻り値

最初の子ノードのハンドル。子ノードが存在しない場合はNULLハンドルを返します。

## 使用方法

NULLハンドルに対する操作を避けるため、[ISNULL](2800.isnull-oracle.md) と組み合わせて戻り値がNULLかどうかを確認することを推奨します。

## 例

```sql
DECLARE
  n           DBMS_XMLDOM.DOMNODE;
  first_child DBMS_XMLDOM.DOMNODE;
BEGIN
  first_child := DBMS_XMLDOM.getFirstChild(n);
END;
/
```
