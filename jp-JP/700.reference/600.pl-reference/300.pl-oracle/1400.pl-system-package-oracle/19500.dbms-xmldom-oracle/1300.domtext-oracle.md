# DOMTEXT

`DOMTEXT` は、XMLテキストノードを表すDOMテキストノードのハンドル型です。`CREATETEXTNODE` で作成でき、`MAKENODE` を使用して汎用の `DOMNODE` に変換することもできます。このハンドルは不透明型であり、DOM関連APIへの入力または出力にのみ使用できます。内部構造に直接アクセスすることはできません。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、この型はOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
text DBMS_XMLDOM.DOMTEXT;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| text | テキストノードのハンドル。 |

## 戻り値

テキストノードのハンドル。

## 使用方法

`DOMTEXT` は通常、[CREATETEXTNODE](1700.createtextnode-oracle.md) で作成します。[MAKENODE](1800.makenode-oracle.md) で汎用の `DOMNODE` に変換すると、ノードレベルの操作に使用できます。

## 例

```sql
DECLARE
  text DBMS_XMLDOM.DOMTEXT;
BEGIN
  NULL;
END;
/
```
