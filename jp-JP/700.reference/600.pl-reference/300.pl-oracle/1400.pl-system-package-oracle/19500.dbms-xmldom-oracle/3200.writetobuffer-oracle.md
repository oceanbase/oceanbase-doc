# WRITETOBUFFER

`WRITETOBUFFER` プロシージャは、DOMドキュメントまたはDOMノードをシリアライズし、`VARCHAR2` バッファに書き込みます。これにより、PL/SQL内でXMLテキストを引き続き受け渡したり、戻り値として返したりできます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.writeToBuffer (
   doc    IN DBMS_XMLDOM.DOMDOCUMENT,
   buffer IN OUT VARCHAR2);

DBMS_XMLDOM.writeToBuffer (
   n      IN DBMS_XMLDOM.DOMNODE,
   buffer IN OUT VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc / n | シリアライズ対象の `DOMDOCUMENT` または `DOMNODE` ハンドル。 |
| buffer | シリアライズ結果を受け取る `VARCHAR2` バッファ（`IN OUT`）。 |

## 戻り値

戻り値はありません。結果は `buffer` に書き込まれます。

## 使用方法

XMLの内容が `VARCHAR2` の長さ制限を超える可能性がある場合は、`WRITETOCLOB` を使用してください。

## 例

```sql
DECLARE
  doc    DBMS_XMLDOM.DOMDOCUMENT;
  buffer VARCHAR2(32767);
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.writeToBuffer(doc, buffer);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
