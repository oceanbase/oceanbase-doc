# WRITETOCLOB

`WRITETOCLOB` プロシージャは、DOMドキュメントまたはDOMノードをシリアライズし、`CLOB` に書き込みます。XMLの内容が `VARCHAR2` の長さ制限を超える場合に適しています。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.writeToClob (
   doc  IN DBMS_XMLDOM.DOMDOCUMENT,
   clob IN OUT CLOB);

DBMS_XMLDOM.writeToClob (
   n    IN DBMS_XMLDOM.DOMNODE,
   clob IN OUT CLOB);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| doc / n | シリアライズ対象の `DOMDOCUMENT` または `DOMNODE` ハンドル。 |
| clob | シリアライズ結果を受け取る `CLOB`（`IN OUT`）。 |

## 戻り値

戻り値はありません。結果は `clob` に書き込まれます。

## 使用方法

通常は、呼び出す前に `DBMS_LOB.CREATETEMPORARY` を使用して一時 `CLOB` を作成する必要があります。使用後は必要に応じて解放してください。

## 例

```sql
DECLARE
  doc         DBMS_XMLDOM.DOMDOCUMENT;
  clob_buffer CLOB;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_LOB.createtemporary(clob_buffer, TRUE);
  DBMS_XMLDOM.writeToClob(doc, clob_buffer);
  DBMS_LOB.freetemporary(clob_buffer);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
