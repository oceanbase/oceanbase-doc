# SETATTRIBUTE

`SETATTRIBUTE` プロシージャは、DOM要素の属性を設定します。属性が存在しない場合は新しく追加し、既に存在する場合は属性値を更新します。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2系では、このサブプログラムはOceanBaseデータベースV4.4.2 BP3から導入されました。</p>
</main>

## 構文

```sql
DBMS_XMLDOM.setAttribute (
   elem  IN DBMS_XMLDOM.DOMELEMENT,
   name  IN VARCHAR2,
   value IN VARCHAR2);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| elem | 対象の `DBMS_XMLDOM.DOMELEMENT` ハンドル。 |
| name | 属性名。 |
| value | 属性値。 |

## 戻り値

戻り値はありません。

## 使用方法

同名の属性が既に存在する場合、本プロシージャを実行すると元の値が上書きされます。

## 例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  DBMS_XMLDOM.setAttribute(elem, 'id', '1001');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
