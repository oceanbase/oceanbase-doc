# DOMNODE

`DOMNODE` は、DOMツリー内の単一ノード（要素、テキスト、コメントなど）を表すハンドルであり、XML構造の操作やアクセスに使用されます。通常、`GETCHILDNODES`、`GETNODEVALUE`、`ITEM` などの関数のパラメータまたは戻り値として使用されます。このハンドル自体は不透明な型であり、解析済みのXMLドキュメントを参照するオブジェクトを表します。DOM関連APIへの入出力にのみ使用され、内部構造には直接アクセスできません。

## 構文

```sql
node DBMS_XMLDOM.DOMNODE;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| node | ノードハンドル。 |

## 戻り値

ノードハンドル。

## 使用方法

`DOMNODE` は通常、[ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) によってノードリストから取得されるか、[GETCHILDNODES](../19500.dbms-xmldom-oracle/600.getchildnodes-oracle.md) によって子ノードを走査する際に使用されます。

## 関連するサブプログラム

| **サブプログラム** | **説明** |
|------------|----------|
| [GETCHILDNODES](../19500.dbms-xmldom-oracle/600.getchildnodes-oracle.md) | 直接子ノードリストを取得します。このメソッドは、`DOMNODE` 型のノードハンドルを入力パラメータとして渡す必要があります。|
| [ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) | ノードリストから `DOMNODE` を取得します。|
| [GETNODEVALUE](../19500.dbms-xmldom-oracle/900.getnodevalue-oracle.md) | ノード値を読み取ります。このメソッドは、`DOMNODE` 型のノードハンドルを入力パラメータとして渡す必要があります。|

## 例

この例では、`DBMS_XMLPARSER` システムパッケージを使用してXMLドキュメントを解析し、`DOMDOCUMENT` ハンドルを取得します。次に、`DBMS_XMLDOM` システムパッケージを使用してXMLドキュメントの `DOMNODE` ハンドルを取得し、ノード値を読み取ります。

```sql
-- 解析エンジンとドキュメントハンドルの変数宣言
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  doc DBMS_XMLDOM.DOMDOCUMENT;
  nl  DBMS_XMLDOM.DOMNODELIST;
  n   DBMS_XMLDOM.DOMNODE;
BEGIN
  -- 解析エンジンインスタンスの作成
  p := DBMS_XMLPARSER.NEWPARSER;
  -- 解析エンジンでXMLドキュメントの解析
  DBMS_XMLPARSER.PARSECLOB(p, '<root><a/></root>');
  -- XMLドキュメントのDOMDOCUMENTハンドルの取得
  doc := DBMS_XMLPARSER.GETDOCUMENT(p);
  -- 解析エンジンインスタンスの解放
  DBMS_XMLPARSER.FREEPARSER(p);
  -- XMLドキュメント内のすべての "a" 要素のリストの取得
  nl := DBMS_XMLDOM.GETELEMENTSBYTAGNAME(doc, 'a');
  -- リストの最初の要素の取得
  n  := DBMS_XMLDOM.ITEM(nl, 0);
  -- XMLドキュメントリソースの解放
  DBMS_XMLDOM.FREEDOCUMENT(doc);
END;
/
```
