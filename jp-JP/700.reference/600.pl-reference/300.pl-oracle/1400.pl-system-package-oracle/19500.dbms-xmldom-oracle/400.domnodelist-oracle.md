# DOMNODELIST

`DOMNODELIST` は、順序付けられたノードの集合を表すハンドルであり、`GETCHILDNODES`、`GETELEMENTSBYTAGNAME` などのメソッドによって返されます。`GETLENGTH` を使用してノード数を取得し、`ITEM` を使用してインデックスで各ノードにアクセスできます。このハンドルは不透明な型であり、解析済みのXMLドキュメントを参照するオブジェクトを表します。DOM関連APIの入出力にのみ使用され、内部構造には直接アクセスできません。

## 構文

```sql
nodelist DBMS_XMLDOM.DOMNODELIST;
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| nodelist | ノードリストハンドル。 |

## 戻り値

ノードリストハンドル。

## 使用方法

`DOMNODELIST` は、順序付けられた一連の `DOMNODE` 参照を表します。イテレーション時には、まず [GETLENGTH](../19500.dbms-xmldom-oracle/800.getlength-xmldom-oracle.md) を呼び出して長さを取得し、その後 [ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) を使用してインデックスでアクセスすることで、範囲外アクセスを回避します。

## 関連するサブプログラム

| **サブプログラム** | **説明** |
|------------|----------|
| [GETCHILDNODES](../19500.dbms-xmldom-oracle/600.getchildnodes-oracle.md) | 子ノードリストを返します。このメソッドは、`DOMNODE` 型のノードハンドルを入力パラメータとして指定する必要があります。|
| [GETELEMENTSBYTAGNAME](../19500.dbms-xmldom-oracle/700.getelementbytagname-oracle.md) | 匹合する要素リストを返します。このメソッドは、`DOMNODE` 型のノードハンドルを入力パラメータとして指定する必要があります。|
| [GETLENGTH](../19500.dbms-xmldom-oracle/800.getlength-xmldom-oracle.md) | リストの長さを返します。このメソッドは、`DOMNODELIST` 型のノードリストハンドルを入力パラメータとして指定する必要があります。|
| [ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) | インデックスでノードを取得します。このメソッドは、`DOMNODELIST` 型のノードリストハンドルとインデックスを入力パラメータとして指定する必要があります。|

## 例

この例では、`DBMS_XMLPARSER` システムパッケージを使用してXMLドキュメントを解析し、`DOMDOCUMENT` ハンドルを取得します。次に、`DBMS_XMLDOM` システムパッケージを使用して、XMLドキュメントの `DOMNODELIST` ハンドルを取得します：

```sql
-- パーサーとドキュメントハンドル変数を宣言する
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  doc DBMS_XMLDOM.DOMDOCUMENT;
  nl  DBMS_XMLDOM.DOMNODELIST;
BEGIN
  -- パーサーインスタンスを作成する
  p := DBMS_XMLPARSER.NEWPARSER;
  -- パーサーでXMLドキュメントを解析する
  DBMS_XMLPARSER.PARSECLOB(p, '<root><x/><x/></root>');
  -- XMLドキュメントのDOMDOCUMENTハンドルを取得する
  doc := DBMS_XMLPARSER.GETDOCUMENT(p);
  -- パーサーインスタンスを解放する
  DBMS_XMLPARSER.FREEPARSER(p);
  -- XMLドキュメント内の名前が"x"であるすべての要素のリストを取得する
  nl := DBMS_XMLDOM.GETELEMENTSBYTAGNAME(doc, 'x');
  -- XMLドキュメントのリソースを解放する
  DBMS_XMLDOM.FREEDOCUMENT(doc);
END;
/
