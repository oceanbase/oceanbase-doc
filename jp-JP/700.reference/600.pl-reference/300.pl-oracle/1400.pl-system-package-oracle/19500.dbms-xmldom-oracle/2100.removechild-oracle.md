# REMOVECHILD

`REMOVECHILD` 関数は、親ノード `n` から指定した子ノード `oldchild` を取り除きます。DOMツリーの構造を変更するために使用し、取り除いたノードのハンドルを返します。

## 構文

```sql
DBMS_XMLDOM.removeChild (
   n        IN DBMS_XMLDOM.DOMNODE,
   oldchild IN DBMS_XMLDOM.DOMNODE);
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| n | 親ノードの `DBMS_XMLDOM.DOMNODE` ハンドル。 |
| oldchild | 取り除く子ノードの `DBMS_XMLDOM.DOMNODE` ハンドル。 |

## 戻り値

取り除かれた子ノードのハンドル（`DBMS_XMLDOM.DOMNODE`）。

## 使用方法

`oldchild` は `n` の直接の子ノードである必要があります。取り除いた後、その子ノードのハンドルが返されるため、後続の処理に使用できます。

## 例

```sql
DECLARE
  parent_node DBMS_XMLDOM.DOMNODE;
  old_child   DBMS_XMLDOM.DOMNODE;
  ret_node    DBMS_XMLDOM.DOMNODE;
BEGIN
  ret_node := DBMS_XMLDOM.removeChild(parent_node, old_child);
END;
/
```
