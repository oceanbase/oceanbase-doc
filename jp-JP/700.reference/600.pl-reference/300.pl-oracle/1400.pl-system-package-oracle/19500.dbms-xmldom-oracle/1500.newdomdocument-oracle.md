# NEWDOMDOCUMENT

`NEWDOMDOCUMENT` 関数は、新しい空のDOMドキュメントオブジェクトを作成します。作成後は、ドキュメントのバージョンや文字セットの設定、ルート要素の作成、子ノードの追加を行い、最後にシリアライズまたは `XMLType` への変換を実行できます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>

</main>

## 構文

```sql
DBMS_XMLDOM.newDOMDocument;
```

## 戻り値

新しく作成された `DBMS_XMLDOM.DOMDOCUMENT` ハンドル。

## 使用方法

ドキュメントの作成後は、通常、`SETVERSION`、`SETCHARSET`、`CREATEELEMENT`、`APPENDCHILD` などのインターフェースを組み合わせてDOMツリーを構築します。使用後は `FREEDOCUMENT` を呼び出してリソースを解放してください。

## 例

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
