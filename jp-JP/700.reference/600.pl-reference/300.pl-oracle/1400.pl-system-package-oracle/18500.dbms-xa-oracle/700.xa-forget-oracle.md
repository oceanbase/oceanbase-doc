# XA_FORGET

XA_FORGET 関数は、リソースマネージャー RM に対し、コミットまたはロールバックされたトランザクションの分岐を破棄するよう要求します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_FORGET (
   xid       IN  DBMS_XA_XID)
RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |                                  **説明**                                   |
|--------|---------------------------------------------------------------------------|
| xid    | [DBMS_XA_XID オブジェクトタイプ](../18500.dbms-xa-oracle/300.the-type-of-the-dbms-xa-xid-object-oracle.md)を参照してください。 |

## 戻り値

[DBMS_XA の戻り値として返される定数](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md)を参照してください。

返される可能性のある値は、`XA_OK`、`XAER_RMERR`、`XAER_RMFAIL`、`XAER_NOTA`、`XAER_INVAL`、および `XAERPROTO` です。
