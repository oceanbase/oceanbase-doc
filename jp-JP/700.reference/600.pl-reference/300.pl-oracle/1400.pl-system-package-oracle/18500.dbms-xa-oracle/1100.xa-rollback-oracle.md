# XA_ROLLBACK

XA_ROLLBACK 関数は、リソースマネージャー RM にトランザクション分岐のロールバックを要求します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容は OceanBase データベース Enterprise Edition にのみ適用されます。OceanBase データベース Community Edition は MySQL モードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_ROLLBACK (
   xid       IN  DBMS_XA_XID)
 RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |                                **説明**                                |
|--------|----------------------------------------------------------------------|
| xid    | [DBMS_XA_XIDオブジェクトタイプ](../18500.dbms-xa-oracle/300.the-type-of-the-dbms-xa-xid-object-oracle.md)を参照してください。 |

## 戻り値

[DBMS_XA の可能な定数戻り値](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md) を参照してください。

返される可能性のある値は、`XA_OK`、`XA_RB\*`、`XA_HEURHAZ`、`XA_HEURCOM`、`XA_HEURRB`、または `XA_HEURMIX` です。
