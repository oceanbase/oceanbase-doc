# XA_START

XA_START 関数は、現在のセッションを `xid` で指定されたトランザクションブランチに関連付けるために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_XA.XA_START (
   xid   IN  DBMS_XA_XID,
   flag  IN  PLS_INTEGER)
RETURN PLS_INTEGER;
```

## パラメータの説明

| **パラメータ** |                                  **説明**                                   |
|--------|---------------------------------------------------------------------------|
| xid    | [DBMS_XA_XIDオブジェクト型](../18500.dbms-xa-oracle/300.the-type-of-the-dbms-xa-xid-object-oracle.md)を参照してください。 |
| flag   | [DBMS_XA定数](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md)を参照してください。     |

## 戻り値

[DBMS_XAの可能な定数戻り値](../18500.dbms-xa-oracle/200.dbms-xa-constant-oracle.md)を参照してください。

## 使用方法

* フラグに `TMJOIN` または `TMRESUME` を指定した場合、`xid` で識別された既存のトランザクションブランチが開始されます。`TMSUCCESS` でトランザクションを分離した場合は `TMJOIN` フラグを使用し、`TMSUSPEND` でトランザクションブランチを分離した場合は `TMRESUME` フラグを使用します。どちらのフラグでも、XA_STARTを呼び出して既存のトランザクションブランチに参加できます。

* フラグに `TMNOFLAGS` が指定され、かつ `TMJOIN` と `TMRESUME` が指定されていない場合、新しいトランザクションブランチが開始されます。`xid` で指定されたトランザクションブランチが既に存在する場合、XA_STARTは `XAER_DUPID` エラーコードを返します。

* 考えられるエラー戻り値は以下の通りです：`XAER_RMERR`、`XAER_RMFAIL`、`XAER_DUPID`、`XAER_OUTSIDE`、`XAER_NOTA`、`XAER_INVAL`、および `XAER_PROTO`。

* XA_STARTが正常に実行された場合、`XA_OK` を返します。アプリケーションは戻り値をチェックし、エラー状況を処理する必要があります。PLアプリケーションは `XA_OK` が返された場合にのみ、他の操作を続行すべきです。トランザクションスタックはサポートされていません。現在のセッションに関連付けられたアクティブなトランザクションが存在する場合、この状態でXA_STARTを呼び出して別のトランザクションを開始したり、参加したりすることはできません。そのセッションに関連付けられたアクティブなグローバルトランザクションブランチが存在する状態でXA_STARTを呼び出した場合、`XAER_PROTO` が返されます。現在のセッションに関連付けられたローカルトランザクションが存在する状態で `XA_START` を呼び出した場合、`XAER_OUTSIDE` が返されます。
