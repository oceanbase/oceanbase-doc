# DBMS_XA定数

DBMS_XAシステムパッケージは、パラメータ値を指定するために使用できる定数を定義しています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## XA_START関数とXA_END関数のflagフィールドで使用される定数

次の表は、XA_START関数とXA_END関数のflagフィールドで使用される定数を示しています。

|  **名前**   |   **データ型**    |                   **値**                    |       **説明**       |
|-----------|-------------|---------------------------------------------|--------------------|
| TMNOFLAGS | PLS_INTEGER | 00000000                                    | フラグ値が選択されていないことを示します。          |
| TMSUCCESS | PLS_INTEGER | UTL_RAW.CAST_TO_BINARY_INTEGER ('04000000') | 呼び出し元とトランザクションブランチを分離します。        |
| TMJOIN    | PLS_INTEGER | UTL_RAW.CAST_TO_BINARY_INTEGER ('00200000') | 呼び出し元が現在のトランザクションブランチに参加しています。     |
| TMSUSPEND | PLS_INTEGER | UTL_RAW.CAST_TO_BINARY_INTEGER ('02000000') | 呼び出し元は一時停止されており、関連付けは終了していません。     |
| TMRESUME  | PLS_INTEGER | UTL_RAW.CAST_TO_BINARY_INTEGER ('08000000') | 呼び出し元が一時停止されたトランザクションブランチとの関連付けを復元しています。 |
