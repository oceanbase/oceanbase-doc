# CONVERT

`CONVERT` 関数は、XMLデータをエスケープ済みまたはエスケープされていないXMLの等価項に変換し、`CLOB` または `VARCHAR2` データとしてエンコードまたはデコード形式で返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

OceanBaseデータベースの現在のバージョンでは、文字列および `CLOB` 形式のXMLデータの使用がサポートされています。構文は以下のとおりです：

```sql
DBMS_XMLGEN.CONVERT (
   xmlData IN VARCHAR2,
   flag    IN NUMBER := ENTITY_ENCODE)
RETURN VARCHAR2;

DBMS_XMLGEN.CONVERT (
   xmlData IN CLOB,
   flag    IN NUMBER := ENTITY_ENCODE)
 RETURN CLOB;
```

## パラメータの説明

|   パラメータ    |               説明            |
|---------|-----------------------------------------------------------------|
| xmlData | エンコードまたはデコードするXML `CLOB` データ。    |
| flag    | 識別子を設定します。  <ul><li> `ENTITY_ENCODE` はエンコードに使用されます(デフォルト)。   </li> <li> `ENTITY_DECODE` はデコードに使用されます。</li></ul>    |

## 使用方法

パラメータ `flag` に `ENTITY_ENCODE` が指定されている場合、この関数はXMLデータをエスケープします。

例えば、文字 `>` のエスケープ形式は `&gt` です。

エスケープされていない場合は、逆変換を意味します。
