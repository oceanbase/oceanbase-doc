# SET_GLOBAL_PREFS

`SET_GLOBAL_PREFS` プロシージャは、グローバル統計のパラメータを設定します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_STATS.SET_GLOBAL_PREFS (
  pname     IN   VARCHAR2,
  pvalue    IN   VARCHAR2);
```

## パラメータ説明

|   パラメータ   |     説明     |
|--------|------------|
| pname  | Prefsの名前。 |
| pvalue | Prefsの値。  |

## 例外状況

|    エラーコード    |     説明      |
|-----------|-------------|
| OBE-20000 | 権限が不足しています。       |
| OBE-20001 | 無効な値または不正な入力値です。 |

## 使用方法

* このプロシージャを呼び出すには、`SYSDBA` 権限が必要です。

* このプロシージャの2つのパラメータはどちらも `VARCHAR2` 型であり、値は引用符で囲む必要があります。

## 例

グローバルレベルの `APPROXIMATE_NDV` のデフォルト値を `FALSE` に設定します。

```sql
obclient> CALL DBMS_STATS.SET_GLOBAL_PREFS ('APPROXIMATE_NDV', 'FALSE');
Query OK, 0 rows affected
```
