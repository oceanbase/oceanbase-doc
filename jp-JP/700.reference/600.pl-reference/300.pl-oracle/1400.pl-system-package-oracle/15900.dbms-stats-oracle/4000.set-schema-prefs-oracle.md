# SET_SCHEMA_PREFS

`SET_SCHEMA_PREFS` プロシージャは、指定されたユーザーの統計プリファレンスを設定します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.SET_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2,
  pvalue    IN   VARCHAR2);
```

## パラメータ説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | ユーザー名。ユーザー名を `NULL` に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| pname   | Prefs名。  |
| pvalue  | Prefs値。   |

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| OBE-20000 | 対象が存在しないか、権限が不足しています。 |
| OBE-20001 | 無効な値または不正な入力値です。  |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続しているか、`SYSDBA`権限を持っている必要があります。

* プロシージャ内のパラメータはすべて `VARCHAR2` 型であり、値は引用符で囲む必要があります。

## 例

```sql
obclient> CALL DBMS_STATS.SET_SCHEMA_PREFS('hr', 'DEGREE','10');
Query OK, 0 rows affected
```
