# PURGE_STATS

`PURGE_STATS`は、指定された時刻以前の履歴統計情報を削除するために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.PURGE_STATS(
  before_timestamp       TIMESTAMP WITH TIME ZONE);
```

## パラメータ説明

`before_timestamp`パラメータは、このタイムスタンプ以前に保存された統計情報がクリアされる時刻を指定します。`NULL`の場合は、自動クリアポリシーが使用されます。

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| OBE-20000 | 対象が存在しないか、権限が不足しています。 |
| OBE-20001 | 無効な値または不整合な値です。   |

## 例

指定した時刻の履歴統計情報を手動でクリーンアップします。

```sql
obclient> CALL DBMS_STATS.PURGE_STATS (TO_TIMESTAMP('2021-09-26 19:02:12.675729', 'YYYY-MM-DD HH24:MI:SS.FF'));
Query OK, 0 rows affected
```
