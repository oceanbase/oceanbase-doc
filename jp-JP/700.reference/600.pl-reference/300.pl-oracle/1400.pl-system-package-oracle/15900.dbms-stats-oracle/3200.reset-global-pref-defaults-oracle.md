# RESET_GLOBAL_PREF_DEFAULTS

`RESET_GLOBAL_PREF_DEFAULTS` プロシージャは、グローバルPrefをデフォルト値に設定します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
DBMS_STATS.RESET_GLOBAL_PREF_DEFAULTS;
```

## 例

グローバルレベルのすべてのPrefデフォルト値を復元します。

```sql
obclient> CALL DBMS_STATS.RESET_GLOBAL_PREF_DEFAULTS();
Query OK, 0 rows affected
```
