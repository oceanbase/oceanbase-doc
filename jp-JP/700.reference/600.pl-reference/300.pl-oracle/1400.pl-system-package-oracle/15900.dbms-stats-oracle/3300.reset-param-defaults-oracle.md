# RESET_PARAM_DEFAULTS

`RESET_PARAM_DEFAULTS` プロシージャは、すべてのパラメータのデフォルト値をデータベースが推奨する値にリセットします。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
DBMS_STATS.RESET_PARAM_DEFAULTS;
```

## 例

```sql
obclient> CALL DBMS_STATS.RESET_PARAM_DEFAULTS;
Query OK, 0 rows affected
```
