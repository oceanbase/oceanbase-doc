# SET_SYSTEM_STATS

`SET_SYSTEM_STATS` プロシージャは、システム統計情報を設定するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.SET_SYSTEM_STATS (
   pname          VARCHAR2,
   pvalue         NUMBER);
```

## パラメータ説明

|   パラメータ    |     説明     |
|---------|------------|
| pname   | パラメータ名。選択可能な値：`cpu_speed`、`disk_seq_read_speed`、`disk_rnd_read_speed`、`network_speed`。 |
| pvalue  | Prefs値。   |

## 例外状況

|    エラーコード    |        説明     |
|-----------|------------------|
| OBE-20001 | 入力されたシステム統計情報名が間違っています。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続しているか、`SYSDBA`権限を持っている必要があります。

## 例

`DBMS_STATS.SET_SYSTEM_STATS` ストアドプロシージャを使用してシステム統計情報を設定する例です。この例では、パラメータ名が `cpu_speed` のシステム統計パラメータを設定します。`pvalue`は5000に設定されており、この値は実際の測定または推定に基づいて決定されるべきで、現在のハードウェア環境で1秒間に実行できるCPUサイクル数を表します。

```sql
BEGIN
    -- CPU速度を5000に設定します。ここでの5000は示唆的な数字であり、ある種の測定単位におけるCPU速度を表します。
    DBMS_STATS.SET_SYSTEM_STATS('cpu_speed', 5000);
END;
/
```

ハードディスクのシーケンシャル読み取り速度(`disk_seq_read_speed`)などを設定したい場合は、以下のコールを実行できます：

```sql
BEGIN
    -- ハードディスクのシーケンシャル読み取り速度を200に設定します。ここでの200は示唆的な数値であり、ある種の測定単位におけるハードディスクの速度を表します。
    DBMS_STATS.SET_SYSTEM_STATS('disk_seq_read_speed', 200);
END;
/
```
