# GET_STATS_HISTORY_AVAILABILITY

`GET_STATS_HISTORY_AVAILABILITY` 関数は、現在利用可能な最も古い履歴統計情報の時刻を取得するために使用されます。この時刻より前の指定時間については、履歴統計情報を復元できません。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.GET_STATS_HISTORY_AVAILABILITY
  RETURN TIMESTAMP WITH TIMEZONE;
```

## 例

現在利用可能な最も古い履歴統計情報の時刻を取得します。

```sql
obclient> SELECT DBMS_STATS.GET_STATS_HISTORY_AVAILABILITY() FROM DUAL;
+---------------------------------------------+
| DBMS_STATS.GET_STATS_HISTORY_AVAILABILITY() |
+---------------------------------------------+
| 2022-12-06 22:00:01.007146                  |
+---------------------------------------------+
1 row in set
```
