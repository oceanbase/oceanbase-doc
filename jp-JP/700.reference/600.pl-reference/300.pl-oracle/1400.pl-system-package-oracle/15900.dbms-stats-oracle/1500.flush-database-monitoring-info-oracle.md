# FLUSH_DATABASE_MONITORING_INFO

`FLUSH_DATABASE_MONITORING_INFO` プロシージャは、すべてのテーブルのメモリ内の監視情報をディクショナリにフラッシュするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
```

## 例外

エラーコード `OBE-20000` は権限不足を示します。

## 使用方法

このプロシージャを実行するには `ANALYZE_ANY` システム権限が必要です。

`FLUSH_DATABASE_MONITORING_INFO` は、定期的なデータベースリフレッシュを待たずに、`*_TAB_STATISTICS` および `*_IND_STATISTICS` ビュー内の対応する情報を即座に更新します。`GATHER_*_STATS` プロシージャは内部で監視情報をフラッシュするため、統計情報を収集する前にこのストアドプロシージャを実行する必要はありません。

## 例

```sql
obclient> CALL DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
Query OK, 0 rows affected
```
