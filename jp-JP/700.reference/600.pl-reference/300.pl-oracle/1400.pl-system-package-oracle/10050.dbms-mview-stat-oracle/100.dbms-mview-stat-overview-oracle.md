# DBMS_MVIEW_STATSの概要

`DBMS_MVIEW_STATS` システムパッケージは、マテリアライズドビューのリフレッシュ操作に関する統計情報の収集と保持を管理するためのインターフェースをユーザーに提供します。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## DBMS_MVIEW_STATS権限の説明

すべての `DBMS_MVIEW_STATS` システムパッケージのサブプログラムでは、ユーザーが `EXECUTE` 権限を持っている必要があります。デフォルトでは、`SYSDBA` ロールはこのシステムパッケージに対して `EXECUTE` 権限を持っています。

## DBMS_MVIEW_STATSサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_MVIEW_STATS` サブプログラムとその簡単な説明を示しています。

| サブプログラム                   | 説明                  |
| ----------------------- | --------------------- |
| [PURGE_REFRESH_STATS](200.purge-refresh-stats-oracle.md) |指定された保持期間を超えたマテリアライズドビューの更新統計データを強制的に自動削除するために使用されます。   |
| [SET_MVREF_STATS_PARAMS](300.set-mvref-stats-params-oracle.md) |マテリアライズドビューの更新統計情報収集レベルとデータ保持期間を設定するパラメータです。|
| [SET_SYSTEM_DEFAULT](400.set-system-default-oracle.md)  |更新統計パラメータのシステムデフォルト値を設定します。|
