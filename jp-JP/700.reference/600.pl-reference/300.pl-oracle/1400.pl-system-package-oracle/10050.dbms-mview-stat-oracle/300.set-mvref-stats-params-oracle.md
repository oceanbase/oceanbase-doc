# SET_MVREF_STATS_PARAMS

`SET_MVREF_STATS_PARAMS`は、マテリアライズドビューのリフレッシュ統計情報の収集レベルとデータ保持期間を設定するパラメータです。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 使用上の制限と注意事項

V4.4.2バージョンでは、V4.4.2 BP2バージョン以降、`retention_period`パラメータは無効になります。

## 構文

```sql
DBMS_MVIEW_STATS.SET_MVREF_STATS_PARAMS (
		mv_list            IN    VARACHAR2,
		collection_level   IN    VARCHAR2 DEFAULT NULL,
		retention_period   IN    NUMBER DEFAULT NULL);
```

## パラメータの説明

| **パラメータ**           | **説明**                                                                                                                                          |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| mv_list          | マテリアライズドビュー名のリスト。カンマで区切ります。現在、単一のマテリアライズドビューの指定のみをサポートしています。<ul><li>NULLの場合、すべてのマテリアライズドビューに対して操作を実行します。 </ ul></li>                                              |
| collection_level | 統計情報の収集レベルです。システムのデフォルトレベルはTYPICALです。オプションは以下のとおりです：<ul><li>NONE：統計情報を収集しません。</ul></li><ul><li>TYPICAL：基本的なリフレッシュ統計情報を収集します。</ul></li><ul><li>ADVANCED：詳細なリフレッシュ統計情報を収集します。</ul></li><ul><li>NULL：システムのデフォルト値、すなわちTYPICALを使用します。</ul></li> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定された日数を超えると統計レコードは自動的に削除されます。システムのデフォルトは31日です。<ul><li>NULLの場合、システムのデフォルト設定が適用されます。</ul></li><ul><li>-1に設定した場合、統計情報は永続的に保持されます。</ul></li>                               |
