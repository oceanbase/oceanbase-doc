# PURGE_REFRESH_STATS

`PURGE_REFRESH_STATS`は、指定された保持期間を超えたマテリアライズドビューの更新統計データを強制的に自動削除するために使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MVIEW_STATS.PURGE_REFRESH_STATS (
		mv_list               IN     VARACHAR2,
		retention_period      IN     NUMBER);
```

## パラメータの説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
| mv_list          | マテリアライズドビュー名のリスト。カンマで区切ります。現在のバージョンでは、複数のマテリアライズドビューを同時に指定することはサポートされていません。<ul><li>値がNULLの場合、すべてのマテリアライズドビューに対して操作を実行します。</ul></li> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定された日数を超えると統計レコードは自動的に削除されます。システムのデフォルトは31日です。<ul><li>値がNULLの場合、自動統計情報クリーンアップメカニズムのデフォルトのクリーンアップポリシーを採用します。</ul></li><ul><li>-1に設定した場合、すべての関連統計情報レコードを削除します。</ul></li> |
