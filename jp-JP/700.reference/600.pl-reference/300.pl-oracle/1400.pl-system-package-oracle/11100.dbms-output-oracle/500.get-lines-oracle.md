# GET_LINES

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/GET_LINES
`GET_LINES` ストアドプロシージャは、バッファから一連の行データを取得するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.GET_LINES (
   lines           OUT     CHARARR,
   numlines    IN OUT  INTEGER);

DBMS_OUTPUT.GET_LINES (
   lines           OUT     DBMSOUTPUT_LINESARRAY,
   numlines    IN OUT INTEGER);
```

## パラメータの説明

|    パラメータ    |                                        説明                                         |
|----------|-----------------------------------------------------------------------------------|
| lines    | 複数行のバッファ情報を返します。各行の最大長は32,767バイトです。                                    |
| numlines | バッファから取得する行数です。指定された行数を取得した後、このストアドプロシージャは実際に取得した行数を返します。この数が要求された行数より少ない場合、バッファにはそれ以上の行がないことを意味します。 |

## 使用方法

* バッファから1行または1組の行を取得するかどうかを選択できます。`GET_LINE` ストアドプロシージャを呼び出して単一行のバッファ情報を取得します。`GET_LINES` ストアドプロシージャは、サーバーへの呼び出し回数を削減できます。

* `GET_LINE` または `GET_LINES` を呼び出した後、取得されなかった行データは、次回 `PUT`、`PUT_LINE`、または `NEW_LINE` を呼び出す前に破棄されます。これは、後の情報と混同されるのを防ぐためです。
