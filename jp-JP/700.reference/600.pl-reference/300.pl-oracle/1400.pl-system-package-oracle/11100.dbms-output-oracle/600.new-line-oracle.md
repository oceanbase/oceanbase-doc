# NEW_LINE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/NEW_LINE
NEW_LINEストアドプロシージャは、行末マーカーを配置するために使用されます。

`GET_LINE` は、「改行文字」で区切られた「行」を返します。`PUT_LINE` プログラムまたは `NEW_LINE` プログラムを呼び出すたびに、`GET_LINE` が返した行が1つ生成されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.NEW_LINE;
```
