# ENABLE

ENABLEストアドプロシージャは、PUT、PUT_LINE、NEW_LINE、およびGET_LINEの呼び出しを許可するために使用されます。

DBMS_OUTPUTパッケージが有効化されていない場合、これらのプログラムへの呼び出しは無視されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.ENABLE (
buffer_size IN INTEGER DEFAULT 20000);
```

## パラメータの説明

|     パラメータ      |                        説明                         |
|-------------|---------------------------------------------------|
| buffer_size | バッファー情報量の上限（単位はバイト）。<ul><li>`enable(null)`: 無制限を表します。</li><li>`enable()`: デフォルト値を使用します。デフォルト値は20000です。数値で`buffer_size`を設定する場合、範囲は[2000,1000000]となります。|

## 使用方法

* OBClientで`SET SERVEROUTPUT`オプションを使用している場合、このプログラムを呼び出す必要はありません。

* 複数のENABLEが同時に呼び出された場合、`buffer_size`には最後に指定された値が使用されます。ユーザーが`buffer_size`（NOT NULL）を指定した場合、最大値は1,000,000、最小値は2,000です。

* 通常はNULLに設定します。デフォルト値は20,000で、無限バッファをサポートしない古いデータベースバージョンとの後方互換性を保つためのものです。
