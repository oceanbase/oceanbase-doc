# DISABLE

#docslug#/oceanbase-database/oceanbase-database/V4.0.0/DISABLE
DISABLEストアドプロシージャは、PUT、PUT_LINE、NEW_LINE、およびGET_LINEの呼び出しを禁止し、バッファに残っているすべての情報をクリアします。

ENABLEプログラムと同様に、OBClientの`SERVEROUTPUT`オプションを使用している場合は、このプログラムを呼び出す必要はありません。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_OUTPUT.DISABLE;
```
