# SLEEP

`SLEEP` ストアドプロシージャは、現在のセッションを指定された時間までブロックします。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_LOCK.SLEEP (
seconds  IN NUMBER);
```

## パラメータの説明

| **パラメータ**  |                              **説明**                              |
|---------|------------------------------------------------------------------|
| seconds | セッションをブロックする持続時間（秒）。最小増分は1/100秒単位で入力できます。例えば、1.95は有効な時間値です。 |
