# DISABLE_RULE

`DISABLE_RULE` プロシージャは、カスタムリライトルールを無効にし、その影響を解除します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
PROCEDURE DISABLE_RULE (
    rule_name          VARCHAR(256));
```

## パラメータ説明

| パラメータ名 | 説明 |
| --- | --- |
| rule_name | ルール名。 |

## 例

```shell
obclient> CALL DBMS_UDR.DISABLE_RULE('rule1');
Query OK, 0 rows affected

obclient> SELECT 1 FROM DUAL;
+---+
| 1 |
+---+
| 1 |
+---+
1 row in set
```
