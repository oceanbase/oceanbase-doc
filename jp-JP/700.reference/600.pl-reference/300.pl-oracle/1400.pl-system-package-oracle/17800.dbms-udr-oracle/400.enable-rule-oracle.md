# ENABLE_RULE

`ENABLE_RULE` プロシージャは、カスタムリライトルールを有効にし、それらを実行するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
PROCEDURE ENABLE_RULE (
    rule_name          VARCHAR(256));
```

## パラメータ説明

| パラメータ | 説明 |
| --- | --- |
| rule_name | ルール名。 |

## 例

```shell
obclient> CALL DBMS_UDR.ENABLE_RULE('rule1');
Query OK, 0 rows affected

obclient> SELECT 1 FROM DUAL;
+-------+
| ? + 1 |
+-------+
|     2 |
+-------+
1 row in set
```
