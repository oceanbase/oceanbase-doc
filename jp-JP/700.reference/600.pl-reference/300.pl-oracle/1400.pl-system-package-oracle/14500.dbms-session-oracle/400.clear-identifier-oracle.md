# CLEAR_IDENTIFIER

`CLEAR_IDENTIFIER` プロシージャは、現在のセッション識別子を `NULL` に設定します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SESSION.CLEAR_IDENTIFIER;
```

## 使用方法

`CLEAR_IDENTIFIER` プロシージャは `PUBLIC` から実行できます。

## 例

```sql
BEGIN
  DBMS_SESSION.CLEAR_IDENTIFIER;
END;
```
