# DBMS_SESSIONの概要

`DBMS_SESSION` システムパッケージは、PLから `ALTER SESSION` SQLステートメントやその他のセッション情報にアクセスするための機能を提供します。`DBMS_SESSION` を使用して、設定やセキュリティレベルを設定できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## DBMS_SESSION権限の説明

`DBMS_SESSION` システムパッケージの呼び出しにはユーザー権限が必要であり、`SYS` 権限は不要です。
