# SET_CONTEXT

`SET_CONTEXT` プロシージャは、コンテキストを設定するために使用されます。セッションローカル、グローバル初期化、外部初期化、グローバルアクセスの4種類があります。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SESSION.SET_CONTEXT (
namespace VARCHAR2,
attribute VARCHAR2,
value     VARCHAR2,
username  VARCHAR2,
client_id VARCHAR2 );
```

## パラメータ説明

|    パラメータ    |                          説明                         |
|-----------|-------------------------------------------------------|
| namespace | 設定するアプリケーションコンテキストの名前空間名を指定します。長さは128バイトまでです。   |
| attribute | 設定するアプリケーションコンテキストの属性を指定します。長さは128バイトまでです。    |
| value     | 設定するアプリケーションコンテキストの値を指定します。長さは4KBまでです。    |
| username  | アプリケーションコンテキストのデータベースユーザー名属性を指定します。デフォルト値は`NULL`です。    |
| client_id | アプリケーションコンテキストのアプリケーションの`client_id`属性（最大64バイト）を指定します。デフォルト値は`NULL`です。 |

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>SET_CONTEXT</code> プロシージャの5つのパラメータのうち、最初の3つのパラメータのみが必須です。最後の2つのパラメータはオプションであり、グローバルアクセスのコンテキストでのみ使用されます。</p>
  </main>

## 使用方法

* `username` パラメータは有効なSQL識別子である必要があります。

* `client_id` パラメータは最大64バイトの文字列である必要があります。大文字と小文字は区別され、`set_identifier` で提供されたパラメータと一致している必要があります。

* `namespace` パラメータがグローバルコンテキスト名前空間の場合、`username` パラメータはセッション内の現在のデータベースユーザー名と、`client_id` パラメータはセッション内の現在の `client_id` と一致します。これらのパラメータが設定されていない場合、`NULL` と見なされ、その場合は任意のユーザーがコンテキスト値を参照できます。

* `SET_CONTEXT` プロシージャは、信頼できるパッケージから直接または間接的に呼び出されなければなりません。

* 名前空間内に既にパラメータ値が設定されている場合、`SET_CONTEXT` はその値を上書きします。

* `SET_CONTEXT` プロシージャによるコンテキスト値の変更は即時に反映されます。その後、`SYS_CONTEXT` を使用して同じ値を呼び出すと、最新の値が返されます。

## 例

```sql
CREATE PROCEDURE emp_attr(empname IN VARCHAR2, empno IN NUMBER) IS
BEGIN
   DBMS_SESSION.SET_CONTEXT('emp_context',empname, empno);
END;
```
