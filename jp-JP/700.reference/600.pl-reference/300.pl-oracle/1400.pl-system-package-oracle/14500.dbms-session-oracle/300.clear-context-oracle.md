# CLEAR_CONTEXT

`CLEAR_CONTEXT` プロシージャは、指定された名前空間内のアプリケーションコンテキストをクリアするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SESSION.CLEAR_CONTEXT(
namespace         VARCHAR2,
client_identifier VARCHAR2
attribute         VARCHAR2);
```

## パラメータ説明

|        パラメータ       |       説明         |
|-------------------|-----------------|
| namespace         | クリアするアプリケーションコンテキストの名前空間を指定します。必須です。 <ul><li> セッションローカルのコンテキストについては、`namespace` を指定する必要があります。`namespace` がセッションローカルのコンテキストとして定義されている場合、`client_identifier` はオプションです。これは、`client_identifier` がグローバルアクセスのコンテキストにのみ関連付けられるためです。   </li><li> グローバルアクセスのコンテキストについては、`namespace` を指定する必要があります。`NULL` は `client_identifier` の有効な値であり、`SET_CONTEXT` で設定された（名前空間、属性、値、ユーザー名、`NULL`）コンテキストと区別するために使用されます。    |
| client_identifier | クライアント識別子を指定します。オプションです。このパラメータはグローバルコンテキストに適用され、他のタイプのコンテキストではオプションです。識別子の最大長は64バイトです。`NULL` は `client_identifier` の有効な値であり、`SET_CONTEXT` で設定された（名前空間、属性、値、ユーザー名、`NULL`）コンテキストと区別するために使用されます。    |
| attribute         | クリアする名前空間内の属性を指定します。オプションです。デフォルト値は `NULL` です。`attribute` を `NULL` に指定した場合、その名前空間の（`namespace`, `attribute`, `value`）がセッションからクリアされます。`attribute` が指定されていない場合、`namespace` と `client_identifier` パラメータを持つすべてのコンテキスト情報がクリアされます。   |

## 使用方法

`CLEAR_CONTEXT` プロシージャは、信頼できるパッケージによって直接または間接的に呼び出す必要があります。

`CLEAR_CONTEXT` プロシージャによるコンテキスト値の変更は即時に反映されます。その後、`SYS_CONTEXT` を使用して同じ値を呼び出すと、最新の値が返されます。

## 例

```sql
BEGIN
  DBMS_SESSION.CLEAR_CONTEXT('emp_context');
END;
```
