# SET_IDENTIFIER

`SET_IDENTIFIER` プロシージャは、セッション内でクライアントIDを設定するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SESSION.SET_IDENTIFIER (
client_id VARCHAR2);
```

## パラメータ説明

`client_id` は、現在のデータベースセッションのアプリケーション識別子（大文字小文字を区別）を指定します。このパラメータの最大バイト数は64バイトです。入力値が64バイトを超える場合、余分なバイトは切り捨てられます。

## 使用方法

`SET_IDENTIFIER` プロシージャは、セッションのクライアントIDを指定値に設定します。また、`SYS_CONTEXT('USERENV','CLIENT_IDENTIFIER')` 関数でセッションを識別するためにも使用できます。

`SET_IDENTIFIER` プロシージャは `PUBLIC` で実行できます。

## 例

```sql
BEGIN
  DBMS_SESSION.SET_IDENTIFIER('1234');
END;
```
