# CLEAR_ALL_CONTEXT

`CLEAR_ALL_CONTEXT` プロシージャは、指定された名前空間内のアプリケーションコンテキスト情報をクリアするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_SESSION.CLEAR_ALL_CONTEXT
    (namespace         VARCHAR2);
```

## パラメータ説明

`namespace` は、クリアするアプリケーションコンテキスト情報の名前空間を指定します。

## 使用方法

`CLEAR_ALL_CONTEXT` プロシージャは、信頼できるパッケージから直接または間接的に呼び出す必要があります。

`CLEAR_ALL_CONTEXT` プロシージャによるコンテキスト値の変更は即時に反映されます。その後、`SYS_CONTEXT` を使用して同じ値を呼び出すと、最新の値が返されます。

## 例

```sql
BEGIN
  DBMS_SESSION.CLEAR_ALL_CONTEXT('emp_context');
END;
```
