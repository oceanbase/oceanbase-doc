# DROP_PURGE_JOB

`DROP_PURGE_JOB` プロシージャは、`CREATE_PURGE_JOB` プロシージャを使用して作成されたクリーンアップジョブを削除するために使用します。クリーンアップジョブの名前はパラメータとして渡されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_AUDIT_MGMT.DROP_PURGE_JOB(
audit_trail_purge_name    IN VARCHAR2) ;
```

## パラメータ説明

`audit_trail_purge_name` は、削除対象のクリーンアップジョブの名前、つまり `CREATE_PURGE_JOB` プロシージャで指定したクリーンアップジョブ名を指定します。

## 例

以下の例では、`DROP_PURGE_JOB` プロシージャを呼び出して、`MYCLEANUP` という名前のクリーンアップジョブを削除します。

```sql
BEGIN
  DBMS_AUDIT_MGMT.DROP_PURGE_JOB(
     AUDIT_TRAIL_PURGE_NAME  => 'MyCLEANUP');
END;
```
