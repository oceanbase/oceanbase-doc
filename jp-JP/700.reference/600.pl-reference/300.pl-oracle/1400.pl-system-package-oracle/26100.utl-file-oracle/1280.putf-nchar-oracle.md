# PUTF_NCHAR

`PUTF_NCHAR` ストアドプロシージャは、指定されたファイルに `NCHAR` 形式でフォーマットして書き込むために使用します。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUTF_NCHAR (
    file   IN FILE_TYPE,
    format IN VARCHAR2,
    arg1   IN VARCHAR2 DEFAULT NULL,
    arg2   IN VARCHAR2 DEFAULT NULL,
    arg3   IN VARCHAR2 DEFAULT NULL,
    arg4   IN VARCHAR2 DEFAULT NULL,
    arg5   IN VARCHAR2 DEFAULT NULL
);
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
|file|`FOPEN` の呼び出しによって返されるアクティブなファイルハンドル。|
|format|書式文字列。`%s` は文字列のプレースホルダー、`\n` は行終端文字を表します。|
|arg1 から arg5|最大5つのオプションパラメータを指定でき、`format` 内の `%s` と順次置き換えます。パラメータがプレースホルダーより少ない場合、置き換えられなかった `%s` はそのまま残るか無視されます。|
