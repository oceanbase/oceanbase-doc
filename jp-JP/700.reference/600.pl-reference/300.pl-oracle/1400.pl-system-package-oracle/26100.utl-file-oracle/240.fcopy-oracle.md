# FCOPY

`FCOPY`は、ソースファイルの`start_line`行目から`end_line`行目まで（`end_line`行を含む）をターゲットファイルにコピーします。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FCOPY (
    src_location   IN VARCHAR2,
    src_filename   IN VARCHAR2,
    dest_location  IN VARCHAR2,
    dest_filename  IN VARCHAR2,
    start_line     IN BINARY_INTEGER DEFAULT 1,
    end_line       IN BINARY_INTEGER DEFAULT NULL
);
```

## パラメータ説明

|  パラメータ  |                   説明                   |
|------|----------------------------------------|
|src_location|ソースファイルがあるディレクトリのエイリアス。|
|src_filename|コピーするソースファイルの名前。|
|dest_location|ターゲットファイルがあるディレクトリのエイリアス。|
|dest_filename|作成または上書きするターゲットファイルの名前。|
|start_line|ソースファイルの何行目からコピーを開始するかを指定します。デフォルトは`1`です。|
|end_line|ソースファイルの何行目でコピーを終了するかを指定します。|
