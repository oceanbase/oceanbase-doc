# GET_RAW

`GET_RAW`は、オペレーティングシステムのファイルから生のバイナリデータを読み取るために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.GET_RAW (
    fid   IN  UTL_FILE.FILE_TYPE,
    r     OUT RAW,
    len   IN  PLS_INTEGER DEFAULT NULL
);
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| fid      | `FOPEN` で開いたファイルハンドル。  |
| r        | ファイルから読み取ったバイナリデータを受け取る出力バッファ。        |
| len | オプションパラメータ。デフォルトは `FALSE` です。`TRUE` に設定すると、データが即座にディスクにフラッシュされ、書き込みのリアルタイム性が確保されます。 |
