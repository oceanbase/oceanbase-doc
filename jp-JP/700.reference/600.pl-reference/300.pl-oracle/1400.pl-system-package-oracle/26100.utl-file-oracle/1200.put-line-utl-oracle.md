# PUT_LINE

`PUT_LINE` ストアドプロシージャは、指定された長さの文字をファイルに書き込み、改行します。

`PUT_LINE` と `PUT` の機能は基本的に同じですが、データ書き込み後に改行文字を追加する点と、`autoflush` パラメータで書き込み後に情報を直ちにファイルシステムにフラッシュするかどうかを指定できる点が異なります。

    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT_LINE (
file            IN  FILE_TYPE,
buffer          IN  VARCHAR2,
autoflush       IN  BOOLEAN DEFAULT FALSE);
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| file      | `FOPEN` を呼び出して返されたアクティブなファイルハンドル。  |
| buffer    | テキストバッファーには、ファイルに書き込む行が含まれます。        |
| autoflush | TRUEの場合のみ、バッファーデータをディスクに書き込みます。 |

## 例外

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`

## 使用方法

* `FOPEN` で最大バイト数が指定されていない場合、バッファーの最大サイズは32767バイトです。デフォルト値は1024です。すべての連続する `PUT` の合計は32767を超えてはならず、中間バッファーのフラッシュはありません。

* バイトモードでファイルを開くと、`INVALID_OPERATION` 例外が発生します。
