# NEW_LINE

`NEW_LINE` ストアドプロシージャは、ファイルに指定された数の改行文字を挿入します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.NEW_LINE (
file      IN FILE_TYPE,
lines    IN BINARY_INTEGER := 1);
```

## パラメータ説明

| パラメータ |                   説明                   |
|-------|----------------------------------------|
| file  | `FOPEN`または`FOPEN_NCHAR`の呼び出しによって返されたアクティブなファイルハンドルです。 |
| lines | ファイルに書き込む改行文字の数です。                           |

## 例外

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`
