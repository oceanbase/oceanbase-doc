# PUT_LINE_NCHAR

`UT_LINE_NCHAR`は、Unicode文字をファイルに書き込むためのストアドプロシージャです。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT_LINE_NCHAR (
    file      IN FILE_TYPE,
    buffer    IN NVARCHAR2,
    autoflush IN BOOLEAN DEFAULT FALSE
);
```

## パラメータ説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| file      | `FOPEN` の呼び出しによって返されたアクティブなファイルハンドル。  |
| buffer    | テキストバッファ。ファイルに書き込む行が含まれます。        |
| autoflush | オプションです。デフォルトは `FALSE` です。`TRUE` に設定すると、データの書き込み後すぐにデータをディスクにフラッシュし、データの永続性を確保します。|
