# FFLUSH

`FFLUSH` ストアドプロシージャは、キャッシュ内のデータをファイルにフラッシュするために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FFLUSH (
file  IN FILE_TYPE);
```

## パラメータ説明

| パラメータ | 解説 |
|------|----------------------------------------|
| file | `FOPEN` または `FOPEN_NCHAR` の呼び出しによって返されたアクティブなファイルハンドル。 |

## 例外

* `INVALID_MAXILINESIZE`

* `INVALID_OPERATION`

* `INVALID_FILENAME`

* `WRITE_ERROR`

## 使用方法

`FFLUSH` は、行終端文字で終わるデータのみをファイルに書き込みます。行終端文字で終わらない場合、データはファイルに書き込まれず、バッファにそのまま残ります。

`FFLUSH` を実行するには、ファイルに対する `w` 権限が必要です。権限がない場合、`INVALID_OPERATION` 例外がスローされます。バッファ内のデータ長が `FOPEN` で指定された最大行長を超えた場合、`INVALID_MAXILINESIZE` 例外がスローされます。
