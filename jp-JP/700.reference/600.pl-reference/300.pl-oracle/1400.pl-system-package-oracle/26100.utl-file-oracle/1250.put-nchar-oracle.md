# PUT_NCHAR

`PUT_NCHAR` ステートメントは、現在の行バッファに `NCHAR` 方式でデータを追加するために使用されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT_NCHAR(
    file    IN FILE_TYPE,
    buffer  IN VARCHAR2
);
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
| file      | `FOPEN` の呼び出しによって返されたアクティブなファイルハンドル。  |
| buffer    | テキストバッファ。ファイルに書き込む行を格納します。        |
