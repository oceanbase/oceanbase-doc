# PUTF

`PUTF` ストアドプロシージャは、フォーマット文字列に従って指定されたファイルに書き込むために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版では現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUTF (
    file   IN FILE_TYPE,
    format IN VARCHAR2,
    arg1   IN VARCHAR2 DEFAULT NULL,
    arg2   IN VARCHAR2 DEFAULT NULL,
    arg3   IN VARCHAR2 DEFAULT NULL,
    arg4   IN VARCHAR2 DEFAULT NULL,
    arg5   IN VARCHAR2 DEFAULT NULL
);
```

## パラメータの説明

|    パラメータ     |           説明            |
|-----------|-------------------------|
|file|`FOPEN` を呼び出して返されたアクティブなファイルハンドル。|
|format|フォーマット文字列。以下を含むことができます：<ul><li><code>%s</code>：最大5つのプレースホルダーがあり、順にargNパラメータの値で置き換えられます。</li><li><code>\n</code>：改行文字です。文字列内で複数回使用できます。</li></ul>|
|arg1 から arg5|最大5つのオプションパラメータで、`format` 内の `%s` を順に置き換えます。パラメータがプレースホルダーより少ない場合、置き換えられなかった `%s` は元のまま残るか無視されます。|
