# FREMOVE

`F_REMOVE` ストアドプロシージャは、指定されたファイルを削除するために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FREMOVE (
location IN VARCHAR2,
filename IN VARCHAR2);
```

## パラメータの説明

|    パラメータ    |       説明        |
|----------|-----------------|
| location | ファイルが存在するパス（大文字小文字を区別します）。 |
| filename | 削除するファイル名。      |

## 例外

* `ACCESS_DENIED`

* `DELETE_FAILED`

* `INVALID_FILENAME`

* `INVALID_OPERATION`

* `INVALID_PATH`

## 使用方法

`F_REMOVE` はファイルを削除する前に権限を検証しません。ただし、オペレーティングシステムはファイルとディレクトリの権限を検証します。
