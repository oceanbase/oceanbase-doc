# PUT

`PUT` ストアドプロシージャは、バッファに格納された入力パラメータの情報を指定されたファイルに書き込むために使用されます。

`PUT` はバッファにのみデータを書き込み、ファイルシステムには直接フラッシュされません。ユーザーは手動で `UTL_FILE.FFLUSH` を呼び出してフラッシュする必要があります。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版では現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT (
file         IN FILE_TYPE,
buffer       IN VARCHAR2);
```

## パラメータの説明

|   パラメータ   |                                      説明                                      |
|--------|------------------------------------------------------------------------------|
| file   | 書き込み先ファイルのファイルハンドルです。このファイルは `w` または `a` モードで開く必要があります。                                          |
| buffer | 書き込むデータを格納するための入力パラメータです。ユーザーが `w` モードでファイルを開いた場合、ファイルの現在のオフセット位置に書き込まれます。`a` モードでファイルを開いた場合、ファイルの末尾に書き込まれます。 |

## 例外

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`

## 使用方法

`FOPEN` で最大バイト数が指定されていない場合、バッファのパラメータは最大32767バイトになります。デフォルト値は1024です。途中でバッファをフラッシュせずに `PUT` を連続して呼び出す場合、書き込むデータの合計は32767バイトを超えてはなりません。
