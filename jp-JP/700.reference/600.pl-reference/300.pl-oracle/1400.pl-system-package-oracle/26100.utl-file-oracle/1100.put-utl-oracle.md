# PUT

`PUT` ステートメントは、バッファに格納された入力パラメータの情報を指定されたファイルに書き込むために使用します。

`PUT` による書き込みはキャッシュ領域にのみ行われ、ファイルシステムには直接フラッシュされません。ユーザーは手動で `UTL_FILE.FFLUSH` を呼び出して完了させる必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.PUT (
file         IN FILE_TYPE,
buffer       IN VARCHAR2);
```

## パラメータ説明

|   パラメータ   |                                      説明                                      |
|--------|------------------------------------------------------------------------------|
| file   | 書き込み先ファイルのファイルハンドルです。このファイルは `w` または `a` モードで開く必要があります。                                          |
| buffer | 書き込むデータを格納するための入力パラメータです。ユーザーが `w` モードでファイルを開いた場合、書き込みはファイルの現在のオフセット位置に発生します。`a` モードでファイルを開いた場合、書き込みはファイルの末尾に発生します。 |

## 例外

* `INVALID_FILEHANDLE`

* `INVALID_OPERATION`

* `WRITE_ERROR`

## 使用方法

`FOPEN` で最大バイト数を指定しなかった場合、バッファのサイズは最大32767バイトになります。デフォルト値は1024です。連続して呼び出されるすべての `PUT` の合計が32767を超えることはできず、中間バッファのフラッシュは行われません。
