# FOPEN

`FOPEN` 関数は、ユーザーが指定した情報に基づいてファイルを開きます。システムは最大で50個のファイルを同時に開くことができます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FOPEN (
   location         IN VARCHAR2,
   filename         IN VARCHAR2,
   open_mode        IN VARCHAR2,
   max_linesize     IN BINARY_INTEGER DEFAULT 1024)
  RETURN FILE_TYPE;
```

## パラメータの説明

|      パラメータ      |                                                                                                                                                                                                                説明                                                                                                                                                                                                                 |
|--------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| location     | 開くファイルが存在するパスオブジェクト名。</p>
| filename     | 開くファイル名。ファイル名には「/」を含めることはできません。</p>
| open_mode    | ファイルの開き方を指定します。モードは以下のとおりです： <ul><li> `r`：テキスト読み取り。    </li><li> `w`：テキスト書き込み。    </li><li> `a`：テキスト追記書き込み。    </li><li> `rb`：バイト読み取り。    </li><li>`wb`：バイト書き込み。    </li><li> `ab`：バイト追記書き込み。</li></ul>   ファイルを開く際に `open_mode` に `a` または `ab` を指定しようとしたが、ファイルが存在しない場合、そのファイルは `write` モードで作成されます。 |
| max_linesize | このファイルの各行の最大バイト数です。改行文字も含まれます。範囲は \[1，32767\] です。デフォルト値は1024です。                                                                                                                                                                                                                                                                                                                                                                                      |

## 戻り値

`FOPEN` は `FILE_TYPE`、つまり開いたファイルのハンドルを返します。このハンドルは、そのファイルに対するすべての後続の操作プロセスに渡す必要があります。ファイルハンドルの具体的な内容は `UTL_FILE` のプライベートなものであるため、参照や変更はできません。

## 例外

* `INVALID_MAXILINESIZE`

* `INVALID_MODE`

* `INVALID_OPERATION`

* `INVALID_PATH`

* `INVALID_FILENAME`

## 使用方法

ファイルの場所とファイル名のパラメータは、`FOPEN` 関数に引用符付き文字列として提供する必要があります。これにより、`ALL_DIRECTORIES` ビューで指定されたアクセス可能なディレクトリリストに基づいてファイルの場所をチェックできます。

同時に開くファイルが50個を超えると、`INVALID_OPERATION` 例外が発生します。
