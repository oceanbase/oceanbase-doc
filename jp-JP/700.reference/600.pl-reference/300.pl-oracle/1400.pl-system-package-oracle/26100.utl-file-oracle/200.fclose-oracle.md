# FCLOSE

`FCLOSE` ストアドプロシージャは、入力されたファイルハンドルに基づいてファイルを閉じるために使用されます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FCLOSE (
file IN OUT FILE_TYPE);
```

## パラメータの説明

|  パラメータ  |                   説明                   |
|------|----------------------------------------|
| file | `FOPEN` または `FOPEN_NCHAR` の呼び出しで返されたアクティブなファイルハンドル。 |

## 使用方法

`FCLOSE` の実行時にバッファデータが残っており、それらのデータが書き込まれていない場合、バッファデータはファイルに書き込もうと試みられますが、`WRITE_ERROR` 例外が発生する可能性があります。

```sql
WRITE_ERROR
INVALID_FILEHANDLE
```
