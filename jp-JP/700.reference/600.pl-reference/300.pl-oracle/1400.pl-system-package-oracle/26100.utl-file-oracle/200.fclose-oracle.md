# FCLOSE

`FCLOSE` ストアドプロシージャは、入力されたファイルハンドルに基づいてファイルを閉じるために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FCLOSE (
file IN OUT FILE_TYPE);
```

## パラメータの説明

| パラメータ |                   説明                   |
|------|----------------------------------------|
| file | `FOPEN`または`FOPEN_NCHAR`の呼び出しによって返されたアクティブなファイルハンドルです。 |

## 使用方法

`FCLOSE` を実行する際にバッファデータが未書き込みの場合、そのバッファデータはファイルに書き込もうと試みられますが、`WRITE_ERROR` 例外が発生する可能性があります。

```sql
WRITE_ERROR
INVALID_FILEHANDLE
```
