# FGETATTR

`FGETATTR` ストアドプロシージャは、ディスク上のファイルの属性を読み取り、返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FGETATTR(
   location     IN VARCHAR2,
   filename     IN VARCHAR2,
   fexists      OUT BOOLEAN,
   file_length  OUT NUMBER,
   block_size   OUT BINARY_INTEGER);
```

## パラメータの説明

| パラメータ | 説明 |
|------|------|
| location | ソースファイルがあるディレクトリの場所、すなわち `ALL_DIRECTORIES` ビューの `DIRECTORY_NAME`（大文字小文字を区別します）。 |
| filename | チェックするファイル名。 |
| fexists | ファイルが存在するかどうか。 |
| file_length | ファイルの長さ、単位はバイトです。ファイルが存在しない場合は `NULL` を返します。 |
| block_size | ファイルシステムブロックサイズ、単位はバイトです。ファイルが存在しない場合は `NULL` を返します。 |

## 使用方法

`FGETATTR` は、ファイルを開くことなく、ファイルの存在、サイズ、ファイルシステムブロックサイズなどの情報を取得するために使用されます。`location` は、`CREATE DIRECTORY` で作成され、現在のユーザーがアクセス権限を持つディレクトリオブジェクト名である必要があります。
