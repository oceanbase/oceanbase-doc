# NEW_LINE_NCHAR

`NEW_LINE_NCHAR`は、ファイルに改行文字を挿入するために使用されます。

 <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.NEW_LINE (
file      IN FILE_TYPE,
lines    IN BINARY_INTEGER := 1);
```

## パラメータの説明

| パラメータ   |                   説明                   |
|-------|----------------------------------------|
| file  | 既に開いているファイルハンドルを表します。 |
| lines | 書き込む行終端文字列の数を指定するために使用されます。デフォルト値は`1`です。このパラメータにより、ファイル内に挿入する改行文字の数が決定されます。                           |
