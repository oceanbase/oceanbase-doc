# FCLOSE_ALL

`FCLOSE_ALL`は、現在のセッションで `UTL_FILE` によって開かれたすべてのファイルを閉じるために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版では現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FCLOSE_ALL;
```

## 使用方法

* パラメータのないプロシージャ：`FCLOSE_ALL`は入力パラメータを受け取らないプロシージャです。呼び出す際はプロシージャ名のみを記述します。
* バッチ処理：このプロシージャは、現在のセッションで `UTL_FILE` パッケージを使用して開かれたすべてのファイルを即座に閉じます。
* 安全な実行：現在開いているファイルがない場合でも、このプロシージャを呼び出すと正常に実行され、エラーは発生しません。
