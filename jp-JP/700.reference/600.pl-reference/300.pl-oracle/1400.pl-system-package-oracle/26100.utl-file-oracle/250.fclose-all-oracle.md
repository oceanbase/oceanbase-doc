# FCLOSE_ALL

`FCLOSE_ALL`は、現在のセッションで `UTL_FILE` によって開かれているすべてのファイルを閉じるために使用されます。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは現在サポートされていません。</p>
  </main>

## 構文

```sql
UTL_FILE.FCLOSE_ALL;
```

## 使用方法

* パラメータなしプロシージャ：`FCLOSE_ALL`は入力パラメータを受け取らないプロシージャです。呼び出す際は、プロシージャ名のみを記述します。
* バッチ処理：このプロシージャは、現在のセッションで `UTL_FILE` パッケージを使用して開いたすべてのファイルを即座に閉じます。
* 安全実行：現在開いているファイルがない場合でも、このプロシージャを呼び出すと正常に実行され、エラーは発生しません。
