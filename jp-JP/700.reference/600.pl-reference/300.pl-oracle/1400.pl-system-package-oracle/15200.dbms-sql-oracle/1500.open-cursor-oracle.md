# OPEN_CURSOR

`OPEN_CURSOR` 関数は、新しいカーソルを開くために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
DBMS_SQL.OPEN_CURSOR
RETURN INTEGER;
```

```sql
DBMS_SQL.OPEN_CURSOR
  RETURN INTEGER;

DBMS_SQL.OPEN_CURSOR(
   security_level   IN   INTEGER)
  RETURN INTEGER;
```

## パラメータの説明

|     **パラメータ**     |                                                                                                                                                                                       **説明**                                                                                                                                                                                        |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| security_level | カーソルの開放に対して強制するセキュリティ保護レベルを指定します。有効なセキュリティレベルの値は0、1、2です。セキュリティレベルの詳細は以下のとおりです： <ul><li> 0 ：セキュリティチェックなしで、カーソルに対するすべての `DBMS_SQL` 操作を許可します。   </li><li> 1 ：BindおよびExecute操作を実行する `effective_user_id` または参照・呼び出し元が、直前に解析操作を実行した `effective_user_id` と同じである必要があります。  </li><li>2 ：1と同じ意味ですが、制限される操作にDefine、Describe、Fetch操作が追加されます。</li></ul>    |

## 戻り値

新しいカーソルのIDを返します。

## 使用方法

* このカーソルが不要になった場合は、`CLOSE_CURSOR` を呼び出して閉じる必要があります。

* カーソルを使用して、同一のSQLステートメントを繰り返し実行するか、新しいSQLステートメントを実行することができます。カーソルを再利用して新しいSQLステートメントを解析する際、該当するカーソルのデータ領域の内容はリセットされます。カーソルを再利用する前に、閉じて再オープンする操作を実行する必要はありません。
