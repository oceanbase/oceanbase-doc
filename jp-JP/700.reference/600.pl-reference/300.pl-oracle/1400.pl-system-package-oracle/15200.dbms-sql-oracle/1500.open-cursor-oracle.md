# OPEN_CURSOR

`OPEN_CURSOR` 関数は、新しいカーソルを開くために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
DBMS_SQL.OPEN_CURSOR
RETURN INTEGER;
```

```sql
DBMS_SQL.OPEN_CURSOR
  RETURN INTEGER;

DBMS_SQL.OPEN_CURSOR(
   security_level   IN   INTEGER)
  RETURN INTEGER;
```

## パラメータ説明

|     **パラメータ**     |                                                                                                                                                                                       **説明**                                                                                                                                                                                        |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| security_level | オープンされたカーソルに強制適用するセキュリティ保護レベルを指定します。有効なセキュリティレベルの値は0、1、2です。セキュリティレベルの詳細は以下のとおりです： <ul><li> 0 ：カーソルに対してすべての `DBMS_SQL` 操作を、いかなるセキュリティチェックもなく実行できます。   </li><li> 1 ：BindおよびExecute操作を実行する `effective_user_id` または参照・呼び出し元が、直近に解析操作を実行した `effective_user_id` と同一である必要があります。  </li><li>2 ：意味は1と同じですが、制限される操作にDefine、Describe、Fetch操作が追加されます。</li></ul>    |

## 戻り値

新しいカーソルのIDを返します。

## 使用方法

* カーソルが不要になった場合は、`CLOSE_CURSOR` を呼び出して閉じる必要があります。

* カーソルを使用して、同じSQLステートメントを繰り返し実行したり、新しいSQLステートメントを実行したりできます。カーソルを再利用して新しいSQLステートメントを解析すると、該当するカーソルのデータ領域の内容はリセットされます。カーソルを再利用する前に、閉じて再オープンする操作を行う必要はありません。
