# DBMS_SQLの概要

`DBMS_SQL` システムパッケージは、動的ステートメントを実行するためのメカニズムを提供し、システムコマンド（例：`ALTER SESSION`）、DDL、DML（`SELECT` を含む）など、さまざまなステートメントをサポートしています。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

使用上の注意点は以下のとおりです：

* パラメータを指定できるのはDMLステートメントのみです。

* DMLステートメントのうち、結果セットを返すステートメントからのみデータを取得できます。

* DMLステートメントは `dbms_sql.execute` などのインターフェースで実行され、その他のステートメントは `dbms_sql.parse` インターフェースで実行されます。

* `DBMS_SQL` が作成するカーソルは現在のセッションでのみ利用可能で、他のセッションからはアクセスできません。

## DBMS_SQL権限の説明

`DBMS_SQL` は `SYS` ユーザーが所有し、`AUTHID CURRENT_USER` でコンパイルされたシステムパッケージです。匿名PLブロックから呼び出される任意の `DBMS_SQL` サブプログラムは、現在のユーザーの権限で実行されます。

## DBMS_SQL定数

次の表は、`DBMS_SQL` の `PARSE` ストアドプロシージャの `language_flag` パラメータで使用される定数です。

|   名前   |   型    | 値 |    説明     |
|--------|---------|---|-----------|
| NATIVE | INTEGER | 1 | プログラムが正常にデータベースに接続されていることを示します |

## 使用方法

以下の使用方法では、クエリ、更新、挿入、削除の処理方法について説明します。

動的SQLを使用してクエリを処理する場合は、以下の手順を実行する必要があります：

1. `DEFINE_COLUMN` サブプログラムを呼び出して、`SELECT` ステートメントが返す値の変数を指定します。

2. `EXECUTE` 関数を呼び出して `SELECT` ステートメントを実行します。

3. `FETCH_ROWS` 関数を呼び出して、クエリに一致する行を取得します。

4. `COLUMN_VALUE` サブプログラムを呼び出して、`FETCH_ROWS` 関数で取得した行の列値を取得します。

動的SQLを使用して `INSERT`、`UPDATE`、または `DELETE` を処理する場合は、`EXECUTE` 関数を呼び出して `INSERT`、`UPDATE`、または `DELETE` ステートメントを実行する必要があります。

V4.4.2 BP4以降では、`BIND_ARRAY` サブプログラムを使用してPL/SQLコレクションをプレースホルダーにバインドし、`INSERT`、`UPDATE`、または `DELETE` ステートメントを一括実行することで、SQLの実行回数を削減できます。詳細については、[BIND_ARRAY](250.bind-array-oracle.md)を参照してください。

## DBMS_SQL の実行プロセス

`DBMS_SQL` の実行プロセスは以下のとおりです：

1. `OPEN_CURSOR`

2. `PARSE`

3. `BIND_VARIABLE` または `BIND_ARRAY`

4. `DEFINE_COLUMN`、`DEFINE_COLUMN_LONG` または `DEFINE_ARRAY`

5. `EXECUTE`

6. `FETCH_ROWS` または `EXECUTE_AND_FETCH`

7. `COLUMN_VALUE`

8. `CLOSE_CURSOR`

## DBMS_SQL サブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_SQL` サブプログラムとその簡単な説明を示しています。

|                             **サブプログラム**                              |             **説明**              |
|------------------------------------------------------------------|---------------------------------|
| [BIND_VARIABLE](../15200.dbms-sql-oracle/200.bind-variable-oracle.md)     | 指定した値を指定した変数にバインドします。                    |
| [BIND_ARRAY](../15200.dbms-sql-oracle/250.bind-array-oracle.md)        | PL/SQLコレクションを指定したプレースホルダーにバインドし、ステートメントを一括実行します。 |
| [COLUMN_VALUE](../15200.dbms-sql-oracle/400.column-value-oracle.md)      | カーソル内で指定された要素の値を返します。                    |
| [CLOSE_CURSOR](../15200.dbms-sql-oracle/300.close-cursor-oracle.md)      | 指定されたカーソルを閉じ、メモリを解放します。                   |
| [DEFINE_COLUMN](../15200.dbms-sql-oracle/500.define-column-oracle.md)     | 指定されたカーソルで選択する列を定義します。`SELECT` ステートメントでのみ使用されます。   |
| [DEFINE_ARRAY](../15200.dbms-sql-oracle/600.define-array-oracle.md)      | 指定されたカーソルから選択するコレクションを定義します。`SELECT` ステートメントでのみ使用されます。 |
| [DESCRIBE_COLUMNS](../15200.dbms-sql-oracle/700.describe-columns-oracle.md)  | カーソルのすべてのフィールド名、型などの属性を取得します。              |
| [EXECUTE](../15200.dbms-sql-oracle/800.execute-oracle.md)           | 指定されたカーソルを実行します。                        |
| [EXECUTE_AND_FETCH](../15200.dbms-sql-oracle/900.execute-and-fetch-oracle.md) | 指定されたカーソルを実行し、行を取得します。                    |
| [FETCH_ROWS](../15200.dbms-sql-oracle/1000.fetch-rows-oracle.md)        | 指定されたカーソルから特定の行データを取得します。                   |
| [IS_OPEN](../15200.dbms-sql-oracle/1100.is-open-oracle.md)           | 指定されたカーソルの状態が `OPEN` の場合、`TRUE` を返します。 |
| [LAST_ERROR_POSITION](../15200.dbms-sql-oracle/1200.last-error-position-of-oracle-mode.md)| 最後に `DBMS_SQL.PARSE` を呼び出した際の構文エラーの位置を取得します。|
| [OPEN_CURSOR](../15200.dbms-sql-oracle/1500.open-cursor-oracle.md)       | 新しいカーソルのIDを返します。                      |
| [PARSE](../15200.dbms-sql-oracle/2000.parse-oracle.md)             | 指定されたステートメントを解析します。                        |
| [RETURN_RESULT](../15200.dbms-sql-oracle/1550.return-result-oracle.md)| 指定されたカーソルの結果セットをクライアントに直接返します。|
| [VARIABLE_VALUE](../15200.dbms-sql-oracle/2100.variable-value-oracle.md) | 動的SQLステートメントを実行した後、出力変数の値を取得するために使用されます。|
