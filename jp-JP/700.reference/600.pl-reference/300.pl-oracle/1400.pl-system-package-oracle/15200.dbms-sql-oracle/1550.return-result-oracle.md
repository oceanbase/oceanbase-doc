# RETURN_RESULT

`RETURN_RESULT` ストアドプロシージャは、指定されたカーソルの結果セットをクライアントに直接返すために使用されます。呼び出し元は、`FETCH_ROWS`、`COLUMN_VALUE` などのサブプログラムを使用してデータを1行ずつ取得する必要がありません。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2バージョンでは、V4.4.2.3 hotfix1バージョンから <code>RETURN_RESULT</code> サブプログラムがサポートされています。</p>
</main>

## 使用上の制限と注意事項

* このサブプログラムはOracleモードでのみサポートされています。
* `cursor_number` は `DBMS_SQL.OPEN_CURSOR` サブプログラムが返す整数型のカーソルID（セッションのDBMS_SQLカーソルテーブルに登録される）を指し、PL/SQLで宣言されたカーソル変数ではありません。`SYS_REFCURSOR` 型のカーソルには、2番目のオーバーロードを使用してください。
* パラメータ `cursor_number` と `rc` はどちらも `IN OUT` モードであり、呼び出し時には変数を渡す必要があります。リテラルやその他の定数を直接渡すことはできません。
* `to_client` パラメータは現在 `TRUE` のみをサポートしています。`FALSE` に指定すると、未サポートを示すエラー（エラーコード `-4007`）が発生し、`DBMS_SQL.RETURN_RESULT with to_client => FALSE` はサポートされていないと表示されます。
* 無効なカーソルID（`DBMS_SQL.OPEN_CURSOR` が返すカーソルIDではない場合）を渡すと、`ORA-29471` エラー（`DBMS_SQL access denied`）が発生します。
* `cursor_number` のオーバーロードを使用する場合、カーソルは `PARSE`（`SELECT` ステートメント）、`EXECUTE` を完了し、結果がまだすべて取得されていない状態である必要があります。そうでない場合、`ORA-01001` エラー（`invalid cursor`）が発生します。
* `SYS_REFCURSOR` のオーバーロードを使用する場合、`rc` は `OPEN` されたカーソルでなければなりません。そうでない場合、`ORA-01001` エラー（`invalid cursor`）が発生します。
* 1つのストアドプロシージャ内で `RETURN_RESULT` を複数回呼び出すことができます。複数の結果セットは、呼び出し順にクライアントに返されます。
* 結果セットの送信が完了すると、このサブプログラムはカーソルの結果セットを閉じますが、カーソルIDは解放しません。`DBMS_SQL.OPEN_CURSOR` で開いたカーソルIDは、引き続き `DBMS_SQL.CLOSE_CURSOR` を呼び出して解放する必要があります。

## 構文

```sql
DBMS_SQL.RETURN_RESULT(
    cursor_number  IN OUT INTEGER,
    to_client      IN     BOOLEAN DEFAULT TRUE);

DBMS_SQL.RETURN_RESULT(
    rc             IN OUT SYS_REFCURSOR,
    to_client      IN     BOOLEAN DEFAULT TRUE);
```

## パラメータの説明

|  **パラメータ**  | **説明** |
|------------|----------|
| cursor_number | `DBMS_SQL.OPEN_CURSOR` で開き、かつ `SELECT` ステートメントが実行済みのカーソルID。 |
| rc | `OPEN ... FOR` で開いた `SYS_REFCURSOR` 変数。 |
| to_client | 結果セットをクライアントに返すかどうか。デフォルト値は `TRUE` です。現在は `TRUE` のみサポートされています。 |

## 例

### 例1：cursor_numberを使用して結果セットを返す

テストテーブルを作成し、データを挿入します。

```sql
obclient> CREATE TABLE return_result_tbl (id NUMBER, name VARCHAR2(20));
obclient> INSERT INTO return_result_tbl VALUES (1, 'one');
obclient> INSERT INTO return_result_tbl VALUES (2, 'two');
obclient> INSERT INTO return_result_tbl VALUES (3, 'three');
```

ストアドプロシージャ `return_result_proc` を作成し、動的SQLカーソルで `RETURN_RESULT` を呼び出します。

```sql
obclient> CREATE OR REPLACE PROCEDURE return_result_proc IS
  cur_id  INTEGER;
  rows    INTEGER;
BEGIN
  cur_id := DBMS_SQL.OPEN_CURSOR;
  DBMS_SQL.PARSE(cur_id, 'SELECT id, name FROM return_result_tbl ORDER BY id', DBMS_SQL.NATIVE);
  rows := DBMS_SQL.EXECUTE(cur_id);
  DBMS_SQL.RETURN_RESULT(cur_id);
END;
/
```

ストアドプロシージャを呼び出すと、クライアントは結果セットを直接受信します。

```sql
obclient> CALL return_result_proc();
```

実行結果は次のとおりです：

```sql
+------+-------+
| ID   | NAME  |
+------+-------+
|    1 | one   |
|    2 | two   |
|    3 | three |
+------+-------+
3 rows in set
```

### 例2：SYS_REFCURSORを使用して結果セットを返す

ストアドプロシージャ `return_result_ref_proc` を作成し、`SYS_REFCURSOR` を使用して結果セットを返します。

```sql
obclient> CREATE OR REPLACE PROCEDURE return_result_ref_proc IS
  rc  SYS_REFCURSOR;
BEGIN
  OPEN rc FOR SELECT id FROM return_result_tbl WHERE id = 1;
  DBMS_SQL.RETURN_RESULT(rc);
END;
/
```

ストアドプロシージャを呼び出します。

```sql
obclient> CALL return_result_ref_proc();
```

クライアントが受信する結果セットは次のとおりです：

```sql
+------+
| ID   |
+------+
|    1 |
+------+
1 row in set
```

同一のストアドプロシージャ内で `RETURN_RESULT` を複数回呼び出すことができます。複数の結果セットは、呼び出し順にクライアントに返されます。
