# ODCIQueryInfo.Flags

`ODCIQueryInfo.Flags` 定数とその説明。

|      定数名      |  型        | デフォルト値 |         説明          |
|----------------|---------|-----|---------------------|
| QueryFirstRows | INTEGER | 1   | オプティマイザーモードが `FIRST_ROWS` の場合 |
| QueryAllRows   | INTEGER | 2   | オプティマイザーモードが `ALL_ROWS` の場合   |
| QuerySortAsc   | INTEGER | 4   | クエリを昇順でソートします             |
| QuerySortDesc  | INTEGER | 8   | クエリを降順でソートします             |
| QueryBlocking  | INTEGER | 16  | クエリのブロッキング                |
