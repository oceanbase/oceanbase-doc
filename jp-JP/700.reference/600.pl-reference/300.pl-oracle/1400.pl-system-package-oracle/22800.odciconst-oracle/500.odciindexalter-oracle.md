# ODCIIndexAlter

`ODCIIndexAlter`定数とその説明。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>

| AlterIndexModifyCol     | INTEGER | 4   | インデックス列の変更                |
| AlterIndexUpdBlockRefs  | INTEGER | 5   | IOT更新ブロック参照            |
| AlterIndexRenameCol     | INTEGER | 6   | ドメインインデックスの基となる列の名前変更        |
| AlterIndexRenameTab     | INTEGER | 7   | ドメインインデックスの基となるテーブルの名前変更        |
| AlterIndexMigrate       | INTEGER | 8   | ユーザー管理のドメインインデックスをシステム管理のドメインインデックスに移行 |
