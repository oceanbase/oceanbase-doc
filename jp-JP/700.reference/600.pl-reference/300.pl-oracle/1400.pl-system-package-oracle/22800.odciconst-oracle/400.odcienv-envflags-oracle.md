# ODCIEnv.Envflags

`ODCIEnv.Envflags` 定数とその説明です。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|      定数名       |  型        | デフォルト値 |    説明     |
|-----------------|---------|-----|-----------|
| DebuggingOn     | INTEGER | 1   | デバッグを表します      |
| NoData          | INTEGER | 2   | データなしを表します     |
| UserParamString | INTEGER | 4   | ユーザーパラメータ文字列を表します |
| RowMigration    | INTEGER | 8   | 行移行を表します     |
| IndexKeyChanged | INTEGER | 16  | インデックスキーが変更されたことを表します  |
