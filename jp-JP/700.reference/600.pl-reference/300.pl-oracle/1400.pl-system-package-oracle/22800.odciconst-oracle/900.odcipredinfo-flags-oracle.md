# ODCIPredInfo.Flags

`ODCIPredInfo.Flags` 定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|       定数名       |  常数タイプ   | デフォルト値 |      説明       |
|------------------|---------|-----|---------------|
| PredExactMatch   | INTEGER | 1   | 等価述語          |
| PredPrefixMatch  | INTEGER | 2   | `LIKE` 述語     |
| PredIncludeStart | INTEGER | 4   | インデックス範囲スキャンで開始値を含む |
| PredIncludeStop  | INTEGER | 8   | インデックス範囲スキャンで終了値を含む |
| PredObjectFunc   | INTEGER | 16  | 述語の左側が独立関数    |
| PredObjectPkg    | INTEGER | 32  | 述語の左側がパッケージ関数     |
| PredObjectType   | INTEGER | 64  | 述語の左側が型指定  |
| PredMultiTable   | INTEGER | 128 | 述語に複数テーブルの列が含まれる   |
| PredNotEqual     | INTEGER | 256 | 不等号述語         |
