# ODCIArgDesc.ArgType

`ODCIArgDesc.ArgType` 定数とその説明です。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|   定数名    |  定数タイプ   | デフォルト値 |         説明          |
|-----------|---------|-----|---------------------|
| ArgOther  | INTEGER | 1   | 実際の引数が他の式であることを示す          |
| ArgCol    | INTEGER | 2   | 実際の引数が列名であることを示す             |
| ArgLit    | INTEGER | 3   | 実際の引数がリテラル値であることを示す            |
| ArgAttr   | INTEGER | 4   | 実際の引数がADT `attr` 列であることを示す     |
| ArgNull   | INTEGER | 5   | 実際の引数がNULLであることを示す          |
| ArgCursor | INTEGER | 6   | 実際の引数が`CURSOR` 式であることを示す |
