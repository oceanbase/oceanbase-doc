# ODCIArgDesc.ArgType

`ODCIArgDesc.ArgType`定数とその説明。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

|   定数名    |  型        | デフォルト値 |         説明          |
|-----------|---------|-----|---------------------|
| ArgOther  | INTEGER | 1   | 実際のパラメータが他の式です          |
| ArgCol    | INTEGER | 2   | 実際のパラメータが列名です             |
| ArgLit    | INTEGER | 3   | 実際のパラメータがリテラル値です            |
| ArgAttr   | INTEGER | 4   | 実際のパラメータがADT `attr` 列  |
| ArgNull   | INTEGER | 5   | 実際のパラメータがNULLです          |
| ArgCursor | INTEGER | 6   | 実際のパラメータが`CURSOR` 式です |
