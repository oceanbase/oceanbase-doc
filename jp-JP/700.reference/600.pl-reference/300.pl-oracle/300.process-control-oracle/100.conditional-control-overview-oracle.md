# 概要

PLはSQLの拡張機能として制御文を導入し、プログラム内の文の実行順序をより柔軟に制御できるようにしました。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

OceanBaseデータベースのPLプロセス制御文には、主に以下の3種類があります：

* 条件選択

  実行時の異なる条件に基づいて、異なる文を実行するかどうかを制御します。条件選択文のキーワードは `IF` と `CASE` です。

* ループ制御

  条件に基づいて一連の文を繰り返し実行します。ループ文には `FOR LOOP`、`WHILE LOOP`、および基本的な `LOOP` があります。

* シーケンス制御

  シーケンス制御文は、指定されたマーカー文へのジャンプや、何も処理を行わないことを許可します。`GOTO` と `NULL` が含まれます。
