# プログラムパッケージ STANDARD による PL 環境の定義

プログラムパッケージ `STANDARD` は PL 環境を定義します。プログラムパッケージヘッダーでは、PL プログラムで使用できる公開型、変数、例外、およびサブルーチンを宣言します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容は OceanBase データベースEnterprise Edition にのみ適用されます。OceanBase データベースCommunity Edition は MySQL モードのみ提供します。</p>
  </main>

システムパッケージ `STANDARD` の内容はアプリケーションから直接参照でき、ユーザーはプログラムパッケージ名の前に接頭辞を付加する必要なく、データベーストリガー、格納されたサブルーチン、または OceanBase ツールから直接呼び出すことができます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBase データベースのシステム関数は <code>STANDARD</code> パッケージに登録されていません。現在のバージョンの <code>STANDARD</code> パッケージは、事前定義されたデータ型、定数、および例外のみをサポートしています。</p>
  </main>

## 事前定義データ型

次の表は、現在のバージョンの `STANDARD` パッケージでサポートされている事前定義データサブタイプです。

|         **事前定義サブタイプ**          |             **値の説明**              |
|-----------------------------|-----------------------------------|
| DOUBLE PRECISION            | FLOAT                             |
| DEC                         | DECIMAL                           |
| STRING                      | VARCHAR2(32760)                   |
| LONG                        | VARCHAR2(32760)                   |
| CHARACTER VARYING           | VARCHAR(32767)                    |
| CHAR VARYING                | VARCHAR(32767)                    |
| CHARACTER LARGE OBJECT      | CLOB                              |
| BINARY LARGE OBJECT         | BLOB                              |
| CHAR LARGE OBJECT           | CLOB                              |
| TIMESTAMP_UNCONSTRAINED     | TIMESTAMP(9)                      |
| TIMESTAMP_TZ_UNCONSTRAINED  | TIMESTAMP(9) WITH TIME ZONE       |
| YMINTERVAL_UNCONSTRAINED    | INTERVAL YEAR(9) TO MONTH         |
| DSINTERVAL_UNCONSTRAINED    | INTERVAL DAY(9) TO SECOND(9)      |
| TIMESTAMP_LTZ_UNCONSTRAINED | TIMESTAMP(9) WITH LOCAL TIME ZONE |

以下のデータ型はジェネリックであり、`STANDARD` パッケージおよび一部の他のパッケージ専用であり、他の用途には使用できません。なお、ジェネリックデータ型はまだ言語の一部となっていない点にご注意ください。

|    **ジェネリックデータ型**    |                 **値の説明**                 |
|------------------|------------------------------------------|
| \<ADT_1\>        | RECORD (DUMMY CHAR(1))                   |
| \<RECORD_1\>     | RECORD (DUMMY CHAR(1))                   |
| \<TUPLE_1\>      | RECORD (DUMMY CHAR(1))                   |
| \<VARRAY_1\>     | VARRAY(1) OF CHAR(1)                     |
| \<V2_TABLE_1\>   | TABLE OF CHAR(1) INDEX BY BINARY_INTEGER |
| \<TABLE_1\>      | TABLE OF CHAR(1)                         |
| \<COLLECTION_1\> | TABLE OF CHAR(1)                         |
| \<REF_CURSOR_1\> | REF CURSOR                               |
| \<TYPED_TABLE\>  | TABLE OF \<ADT_1\>                       |
| \<ADT_WITH_OID\> | \<TYPED_TABLE\>                          |

PLコンパイラは、以下のジェネリックインデックステーブルデータ型を使用して配列属性をインスタンス化します。

|   **ジェネリックインデックステーブルデータ型**   |          **値の説明**           |
|-------------------|-----------------------------|
| SYS $ INT_V2TABLE | `binary_integer` で表される整数インデックステーブル |

PLコンパイラは、以下のレコードタイプと対応するジェネリックインデックステーブルデータ型を使用して、テーブル実行中に `FORALL` バッチバインディングステートメントの実行によって発生した例外を記録します。

|       **レコードタイプ**        |                        **値の説明**                         |
|-----------------------|---------------------------------------------------------|
| SYS$BULK_ERROR_RECORD | RECORD (ERROR_INDEX PLS_INTEGER,ERROR_CODE PLS_INTEGER) |
| SYS$REC_V2TABLE       | TABLE OF CHAR(1)                                        |

以下の表は、すべての不透明ジェネリックデータ型です。

| **不透明** **ジェネリックデータ型** |               **値の説明**                |
|--------------------|---------------------------------------|
| \<ASSOC_ARRAY_1\>  | TABLE OF CHAR(1) INDEX BY VARCHAR2(1) |
