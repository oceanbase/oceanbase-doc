# パイプライン関数の概要

パイプラインテーブル関数（Pipelined Table Function）は、行のコレクションをネスト表または配列として返すことができる関数です。物理テーブルをクエリするようにこの関数の戻り値を照会したり、コレクション変数に代入したりできます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

`SELECT` ステートメントの `TABLE` 句でパイプライン関数を呼び出します。例：

```sql
SELECT * FROM TABLE(table_function_name(parameter_list))
```

キーワード `PIPELINED` はパイプライン関数を示すものです。パイプライン関数の戻り値の型は必ず集合でなければならず、`PIPE ROW` ステートメントを使用してその集合の個々の要素を返し、実行完了を示すために戻り値を指定しない `RETURN` ステートメントで終了します。
