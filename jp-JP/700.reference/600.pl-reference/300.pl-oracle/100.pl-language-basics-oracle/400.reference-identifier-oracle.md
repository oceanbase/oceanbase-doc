# 識別子の参照

識別子は、単純名、修飾名、リモート名、または修飾リモート名で参照できます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

命名されたPLユニット内で宣言された識別子は、その修飾名を使用して参照することができます（場合によっては必須です）。構文は次のとおりです：

```sql
unit_name.simple_identifier_name
```

例えば、パッケージ `ob` が識別子 `c` を宣言した場合、修飾名 `ob.c` を使用してその識別子を参照できます。ユニット名も修飾でき、場合によっては修飾が必須です。識別子が可視でない場合は、修飾する必要があります（[識別子のスコープと可視性](../100.pl-language-basics-oracle/500.range-and-visibility-of-identifiers-oracle.md)を参照してください）。

識別子がリモートデータベース上のオブジェクトに名前を付ける場合は、そのオブジェクトを参照するためにリモート名を使用する必要があります。構文は次のとおりです：

```sql
simple_identifier_name@link_to_remote_database
```

リモートデータベースのPLユニット内で宣言された識別子の場合は、その修飾リモート名を使用して参照する必要があります。構文は次のとおりです：

```sql
unit_name.simple_identifier_name@link_to_remote_database
```
