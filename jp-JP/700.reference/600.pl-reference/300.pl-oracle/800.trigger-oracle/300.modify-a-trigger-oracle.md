# トリガーの変更と削除

PLはトリガーの変更と削除をサポートしています。

## トリガーの変更

現在、トリガーを変更するには、DDLステートメント内の `REPLACE TRIGGER` ステートメントを使用する必要があります。

通常、トリガーの作成と変更は次のようなステートメントで記述されます：

```javascript
CREATE OR REPLACE TRIGGER trigger_name ...
```

`trigger_name` が存在しない場合、トリガーが作成されます。`trigger_name` が既に存在する場合、トリガーが変更されます。

## トリガーの削除

`DROP TRIGGER` を使用してトリガーを削除できます。構文は以下のとおりです：

```javascript
DROP TRIGGER trigger_name;
```

さらに、テーブルを削除すると、そのオブジェクト上に作成されたトリガーも自動的に削除されます。
