# SA_SESSION.RESTORE_DEFAULT_LABELS

`SA_SESSION.RESTORE_DEFAULT_LABELS`は、セッションラベルと行ラベルをデータディクショナリに保存されているラベルに復元するために使用します。

`SA_SESSION.SET_LABEL`コマンドを実行した後、このコマンドで値をリセットします。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
SA_SESSION.RESTORE_DEFAULT_LABELS (
policy_name in VARCHAR);
```

## パラメータ説明

|   **パラメータ**    |                          **説明**                           |
|-------------|-----------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを検索する場合は、`ALL_SA_POLICIES` データディクショナリビューの `POLICY_NAME` 列を照会してください。 |

## 例

以下の例は、`shield_agent_policy`ポリシーのデフォルトラベルを復元するものです。

```sql
BEGIN
    SA_SESSION.RESTORE_DEFAULT_LABELS (
          policy_name         => 'shield_agent_policy');
END;
/
```
