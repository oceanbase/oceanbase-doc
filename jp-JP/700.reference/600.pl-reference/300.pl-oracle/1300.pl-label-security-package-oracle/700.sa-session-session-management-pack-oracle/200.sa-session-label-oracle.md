# SA_SESSION.LABEL

`SA_SESSION.LABEL` 関数は、現在のセッションに関連付けられた指定されたポリシーのラベルを返します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_SESSION.LABEL (
      policy_name IN VARCHAR)
 RETURN VARCHAR AS
 ret VARCHAR (4000);
```

## パラメータ説明

|   **パラメータ**    |                           **説明**                           |
|-------------|------------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを検索するには、`ALL_SA_POLICIES` データディクショナリビューの `POLICY_NAME` 列を照会してください。 |

## 例

以下の例では、`shield_agent_policy` ポリシーに関連付けられたラベルを返します。

```sql
SELECT SA_SESSION.LABEL ('shield_agent_policy') FROM DUAL;
```
