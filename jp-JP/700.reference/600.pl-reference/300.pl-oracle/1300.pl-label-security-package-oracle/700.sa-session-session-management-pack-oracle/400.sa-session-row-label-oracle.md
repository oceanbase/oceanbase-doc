# SA_SESSION.ROW_LABEL

`SA_SESSION.ROW_LABEL`は、現在のセッションのポリシーに関連付けられた行ラベルの名前を返します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみ提供しています。</p>
  </main>

## 構文

```sql
SA_SESSION.ROW_LABEL (
      policy_name IN VARCHAR)
RETURN VARCHAR;
```

## パラメータの説明

|   **パラメータ**    |                          **説明**                           |
|-------------|-----------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを検索する場合は、`ALL_SA_POLICIES` データディクショナリビューの `POLICY_NAME` 列を照会してください。 |

## 例

以下の例は、`shield_agent_policy` ポリシーに関連付けられた行ラベルを返すものです。

```sql
SELECT SA_SESSION.ROW_LABEL ('shield_agent_policy') FROM DUAL;
```
