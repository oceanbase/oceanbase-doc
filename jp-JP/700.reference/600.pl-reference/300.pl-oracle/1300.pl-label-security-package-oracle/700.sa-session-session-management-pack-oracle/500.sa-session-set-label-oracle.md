# SA_SESSION.SET_LABEL

`SA_SESSION.SET_LABEL`は、現在のデータベースセッションのラベルを設定します。

セッションラベルは、最大値以下かつ最小値以上の任意のレベルに設定できます。

ただし、セッションラベルを変更すると、その変更がセッションの行ラベルの値に影響を与える可能性があります。また、セッションの行ラベルがセッションラベルと一致しない場合もあります。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
SA_SESSION.SET_LABEL (
policy_name IN VARCHAR,
label       IN VARCHAR);
```

## パラメータの説明

|   **パラメータ**    |                          **説明**                           |
|-------------|-----------------------------------------------------------|
| policy_name | ポリシーを指定します。既存のポリシーを検索する場合は、`ALL_SA_POLICIES` データディクショナリビューの `POLICY_NAME` 列を照会してください。 |
| label       | タグの値を設定します。                                                  |

## 例

以下の例は、`shield_agent_policy`ポリシーにラベルを設定する方法です。

```sql
BEGIN
 SA_SESSION.SET_LABEL (
      policy_name         => 'shield_agent_policy',
       label              => 'L6');
END;
/
```
