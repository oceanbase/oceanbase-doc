# SA_LABEL_ADMIN.DROP_LABEL

`SA_LABEL_ADMIN.DROP_LABEL`は、指定されたポリシーラベルを削除するために使用します。

削除後にそのラベルを参照すると（データ行内、ユーザーのラベル内、またはプログラムユニットのラベル内）、無効なラベルのエラーが発生します。

このストアドプロシージャは、ラベルを設定する際にのみ使用されます。使用中のラベルを誤って削除してしまった場合は、ポリシーを無効にしてから再度有効にすることで、そのラベルを復元できます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_LABEL_ADMIN.DROP_LABEL (
policy_name       IN VARCHAR,
label_tag         IN BINARY_INTEGER);
```

## パラメータの説明

|   **パラメータ**    |                            **説明**                             |
|-------------|---------------------------------------------------------------|
| policy_name | 既存のポリシーの名前を指定します。既存のポリシーを検索するには、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列を照会してください。    |
| label_tag   | 削除するラベルに割り当てられた整数タグを指定します。既存のラベルを検索するには、`ALL_SA_LABELS`ビューの`LABEL_TAG`列を照会してください。 |

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>データベース内で使用中のラベルは削除しないでください。</p>
  </main>

## 例

以下の例では、`label_tag`に基づいて`shield_agent_policy`ポリシーラベルを削除します。

```sql
BEGIN
   SA_LABEL_ADMIN.DROP_LABEL (
     policy_name     => 'shield_agent_policy',
     label_tag       => 50000);
END;
/
```
