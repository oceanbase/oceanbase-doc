# PLラベルセキュリティパッケージの概要

ラベルセキュリティ（Label Security）は、単一のテーブル行に対するきめ細かいアクセス制御を提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

ラベルセキュリティポリシーには、一連の標準コンポーネントがあります。これらの構成要素は以下のとおりです：

* ラベル

  データとユーザーのラベル、およびユーザーとプログラムユニットの権限制御により、指定された保護対象へのアクセスが管理されます。現在のバージョンでは、ラベルにはレベルのみが含まれます。レベルは行に割り当てる機密性タイプを示し、例えば`SENSITIVE`や`HIGHLY SENSITIVE`などが該当します。

* ポリシー

  ポリシーとは、これらのラベル、ルール、権限、および保護対象となるテーブルに関連付けられる名前です。

次の表は、OceanBaseデータベースの現在のバージョンで利用可能なラベルセキュリティ管理パッケージとその説明です。

|                             パッケージ名                              |              説明              |
|----------------------------------------------------------------|------------------------------|
| [SA_SYSDBA](200.sa-sysdba-policy-management-package-oracle/100.sa-sysdba-overview-oracle.md)       | ラベルセキュリティポリシーの作成、変更、削除を行います。              |
| [SA_COMPONENTS](300.sa-components-tag-package-oracle/100.sa-components-overview-oracle.md)   | ポリシーのレベルを定義します。                     |
| [SA_LABEL_ADMIN](400.sa-label-admin-tag-management-pack-oracle/100.sa-label-admin-overview-oracle.md)  | ラベルの作成など、標準的なラベルセキュリティポリシー管理機能を実行します。         |
| [SA_POLICY_ADMIN](500.sa-policy-admin-policy-management-packs-oracle/100.sa-policy-admin-overview-oracle.md) | アーキテクチャとテーブルにポリシーを適用します。                  |
| [SA_USER_ADMIN](600.sa-user-admin-user-tag-management-pack-oracle/100.sa-user-admin-overview-oracle.md)   | レベルのユーザー権限およびプログラムユニット権限を管理し、ユーザー権限も管理できます。 |
| [SA_SESSION](700.sa-session-session-management-pack-oracle/100.sa-session-overview-oracle.md)      | 管理者が設定した権限範囲内で、セッション中にラベルを変更します。       |
