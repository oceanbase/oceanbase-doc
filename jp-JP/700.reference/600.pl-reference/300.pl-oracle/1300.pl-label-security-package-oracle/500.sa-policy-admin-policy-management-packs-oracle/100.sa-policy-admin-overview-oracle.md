# SA_POLICY_ADMINの概要

`SA_POLICY_ADMIN` パッケージは、ラベルセキュリティポリシーを全体的に管理するために使用されます。

このPLパッケージを使用するには、`SA_POLICY_ADMIN` パッケージに対する `EXECUTE` 権限が付与されている必要があります。

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `SA_POLICY_ADMIN` パッケージの内容を示しています。

|                                      **ストアドプロシージャ**                                       |                     **説明**                     |
|-------------------------------------------------------------------------------------|------------------------------------------------|
| [SA_POLICY_ADMIN.APPLY_TABLE_POLICY](../500.sa-policy-admin-policy-management-packs-oracle/200.sa-policy-admin-apply-table-policy-oracle.md)   | 指定されたポリシーをテーブルに追加します。                                   |
| [SA_POLICY_ADMIN.DISABLE_TABLE_POLICY](../500.sa-policy-admin-policy-management-packs-oracle/300.sa-policy-admin-disable-table-policy-oracle.md) | デフォルトの強制実行オプション、ラベル機能、または述語値を変更することなく、指定されたテーブル内のすべてのデフォルト強制実行オプションを無効にします。       |
| [SA_POLICY_ADMIN.ENABLE_TABLE_POLICY](../500.sa-policy-admin-policy-management-packs-oracle/400.sa-policy-admin-enable-table-policy-oracle.md)  | RLS 述語と DML トリガーを再適用することで、指定されたテーブルの現在の強制オプション、ラベル機能、および述語を再有効にします。 |
| [SA_POLICY_ADMIN.REMOVE_TABLE_POLICY](../500.sa-policy-admin-policy-management-packs-oracle/500.sa-policy-admin-remove-table-policy-oracle.md)  | テーブルから指定されたポリシーを削除します。                                    |
