# SA_POLICY_ADMIN.APPLY_TABLE_POLICY

`SA_POLICY_ADMIN.APPLY_TABLE_POLICY`は、指定されたポリシーをテーブルに追加するために使用します。

ポリシーのラベル列が存在しない場合、テーブルに追加され、`NULL`に設定されます。ポリシーを適用すると、自動的に有効になります。テーブルオプション、ラベル機能、または述語を変更するには、まずそのポリシーを削除し、再度適用する必要があります。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_POLICY_ADMIN.APPLY_TABLE_POLICY (
policy_name       IN VARCHAR,
schema_name       IN VARCHAR,
table_name        IN VARCHAR,
table_options     IN VARCHAR := NULL,
label_function    IN VARCHAR := NULL,
predicate         IN VARCHAR := NULL);
```

## パラメータの説明

|     **パラメータ**     |                           **説明**                           |
|----------------|------------------------------------------------------------|
| policy_name    | 指定するポリシー。既存のポリシーを検索するには、`ALL_SA_POLICIES`データディクショナリビューの`POLICY_NAME`列を照会してください。 |
| schema_name    | ポリシーで保護されるテーブルがあるスキーマ。                                         |
| table_name     | ポリシーで保護されるテーブル。                                                   |
| table_options  | このテーブルで使用されるポリシー実行オプションのリスト（カンマ区切り）。                                    |
| label_function | デフォルト値として使用するラベル値を返す関数の呼び出しを表す文字列。                                      |
| predicate      | ラベルベースの述語と組み合わせて使用する追加の述語（`AND`または`OR`を使用）。                            |

## 例

以下のステートメントは、`shield_agent_policy`ポリシーをスキーマ `FURY`内の`MISSION_LIST`テーブルに適用します。

```sql
BEGIN
     SA_POLICY_ADMIN.APPLY_TABLE_POLICY(
     policy_name    => 'shield_agent_policy',
     schema_name    => 'FURY',
     table_name     => 'MISSION_LIST');
END;
/
```
