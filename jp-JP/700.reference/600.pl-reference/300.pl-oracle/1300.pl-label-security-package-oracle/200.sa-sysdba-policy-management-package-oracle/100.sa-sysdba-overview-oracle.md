# SA_SYSDBAの概要

`SA_SYSDBA` パッケージは、タグセキュリティポリシーの作成、変更、削除などを管理するために使用されます。

このPLパッケージを使用するには、`EXECUTE` 権限が必要です。`SA_SYSDBA` パッケージはコールプログラマー権限パッケージであるため、このパッケージを使用する前に、`SYS` ユーザーに以下の `INHERIT PRIVILEGES` を付与する必要があります：

```sql
GRANT INHERIT PRIVILEGES ON USER SYS TO LBACSYS;
```

この権限はSYSユーザーにのみ付与すればよく、他のユーザーに付与する必要はありません。

|------------------------------------------------------------------------|-----------|
| [SA_SYSDBA.ALTER_POLICY](../200.sa-sysdba-policy-management-package-oracle/200.sa-sysdba-alter-policy-oracle.md)  | タグセキュリティポリシーを変更します。 |
| [SA_SYSDBA.CREATE_POLICY](../200.sa-sysdba-policy-management-package-oracle/300.sa-sysdba-create-policy-oracle.md) | タグセキュリティポリシーを作成します。 |
