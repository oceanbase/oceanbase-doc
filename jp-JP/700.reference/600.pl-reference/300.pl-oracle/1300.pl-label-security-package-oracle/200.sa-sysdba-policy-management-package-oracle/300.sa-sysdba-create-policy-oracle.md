# SA_SYSDBA.CREATE_POLICY

`SA_SYSDBA.CREATE_POLICY`は、新しいラベルセキュリティポリシーを作成し、特定のポリシーに対する列名を定義し、デフォルトのポリシーオプションを指定します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_SYSDBA.CREATE_POLICY (
      policy_name       IN VARCHAR,
      column_name       IN VARCHAR := NULL,
      default_options   IN VARCHAR := NULL
  );
```

## パラメータの説明

|     **パラメータ**      |                                                                       **説明**                                                                       |
|-----------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| policy_name     | ポリシー名を指定します。この名前はデータベース内で一意である必要があります。ポリシー名は最大30文字ですが、有効なのは最初の26文字のみです。2つのポリシーの最初の26文字は異なる場合があります。既存のポリシーリストを確認するには、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列をクエリしてください。 |
| column_name     | ポリシー保護対象のテーブルに追加する列名を指定します。`NULL`の場合は`policy_name_COL`を使用します。2つのラベルセキュリティポリシーは同じ列名を共有できません。                                                                                 |
| default_options | デフォルトの強制オプションを指定します。ポリシーを適用したものの、そのポリシーが適用されるテーブルやスキーマを指定しなかった場合に使用されるデフォルトの強制オプション（強制オプションとラベル付き列を非表示にするオプションを含む）です。各オプションはカンマで区切ります。                                                                        |

## 例

以下の例では、セキュリティポリシー `shield_agent_policy` を作成します。

```sql
BEGIN
   SA_SYSDBA.CREATE_POLICY (
     policy_name      => 'shield_agent_policy',
     column_name      => 'secret_label');
END;
/
```
