# SA_COMPONENTS.ALTER_LEVEL

`SA_COMPONENTS.ALTER_LEVEL`は、レベルのショート名とロング名を変更するために使用されます。

一度定義したレベル番号は変更できません。既存のタグでレベルが使用されている場合、そのショート名は変更できませんが、ロング名は変更できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供します。</p>
  </main>

## 構文

```sql
SA_COMPONENTS.ALTER_LEVEL (
   policy_name     IN VARCHAR,
   level_num       IN NUMBER,
   new_short_name  IN VARCHAR := NULL,
   new_long_name   IN VARCHAR := NULL
);
```

## パラメータ説明

|     **パラメータ**     |                         **説明**                          |
|----------------|---------------------------------------------------------|
| policy_name    | ポリシーを指定します。既存のポリシーを検索する場合は、`ALL_SA_POLICIES` ビューの `POLICY_NAME` 列を参照してください。  |
| level_num      | 変更するレベル番号を指定します。既存のレベルを検索する場合は、`ALL_SA_LEVELS` ビューの `LEVEL_NUM` 列を参照してください。 |
| new_short_name | レベルの新しい短い名前（最大30文字）を指定します                                   |
| new_long_name  | レベルの新しい長い名前（最大80文字）を指定します                                   |

## 例

以下の例では、`shield_agent_policy`ポリシーレベルのロング名とショート名を変更します。

```sql
BEGIN
 SA_COMPONENTS.ALTER_LEVEL (
   policy_name     => 'shield_agent_policy',
   level_num       => 500,
   new_short_name  => 'M5',
   new_long_name   => 'MEDIUM_SECRET 5');
END;
/
```
