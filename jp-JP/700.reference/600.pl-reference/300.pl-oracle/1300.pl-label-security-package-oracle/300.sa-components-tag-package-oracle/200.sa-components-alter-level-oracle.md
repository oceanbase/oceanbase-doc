# SA_COMPONENTS.ALTER_LEVEL

`SA_COMPONENTS.ALTER_LEVEL`は、レベルの短名と長名を変更するために使用します。

一度定義されたレベル番号は変更できません。既存のタグでレベルが使用されている場合、その短名は変更できませんが、長名は変更できます。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_COMPONENTS.ALTER_LEVEL (
   policy_name     IN VARCHAR,
   level_num       IN NUMBER,
   new_short_name  IN VARCHAR := NULL,
   new_long_name   IN VARCHAR := NULL
);
```

## パラメータの説明

|     **パラメータ**     |                         **説明**                          |
|----------------|---------------------------------------------------------|
| policy_name    | ポリシーを指定します。既存のポリシーを検索する場合は、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列を照会してください。  |
| level_num      | 変更するレベル番号を指定します。既存のレベルを検索する場合は、`ALL_SA_LEVELS`ビューの`LEVEL_NUM`列を照会してください。 |
| new_short_name | レベルの新しい短名（最大30文字）を指定します                                    |
| new_long_name  | レベルの新しい長名（最大80文字）を指定します                                    |

## 例

以下の例では、`shield_agent_policy`ポリシーレベルの長名と短名を変更します。

```sql
BEGIN
 SA_COMPONENTS.ALTER_LEVEL (
   policy_name     => 'shield_agent_policy',
   level_num       => 500,
   new_short_name  => 'M5',
   new_long_name   => 'MEDIUM_SECRET 5');
END;
/
```
