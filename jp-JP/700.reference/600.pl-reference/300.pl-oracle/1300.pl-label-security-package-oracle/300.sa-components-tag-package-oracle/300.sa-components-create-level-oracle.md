# SA_COMPONENTS.CREATE_LEVEL

`SA_COMPONENTS.CREATE_LEVEL`は、レベルを作成し、そのショート名とロング名を指定するために使用されます。

`level_num`パラメータに割り当てられる数値は、センシティビティレベルを決定します（数値が小さいほどセンシティビティが低いことを意味します）。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## 構文

```sql
SA_COMPONENTS.CREATE_LEVEL (
policy_name       IN VARCHAR,
level_num         IN NUMBER,
short_name        IN VARCHAR,
long_name         IN VARCHAR );
```

## パラメータの説明

|   **パラメータ**    |                         **説明**                         |
|-------------|--------------------------------------------------------|
| policy_name | 指定するポリシー。既存のポリシーを検索する場合は、`ALL_SA_POLICIES`ビューの`POLICY_NAME`列を照会してください。 |
| level_num   | レベル番号(0-9999)を指定します。                                       |
| short_name  | レベルのショート名(最大30文字)を指定します。                                   |
| long_name   | レベルのロング名(最大80文字)を指定します。                                   |

## 例

以下の例は、`shield_agent_policy`ポリシーにレベルを作成するものです。

```sql
BEGIN
   SA_COMPONENTS.CREATE_LEVEL (
    policy_name     => 'shield_agent_policy',
    level_num       => 500,
    short_name      => 'L5',
    long_name       => 'Level 5');
END;
/
```
