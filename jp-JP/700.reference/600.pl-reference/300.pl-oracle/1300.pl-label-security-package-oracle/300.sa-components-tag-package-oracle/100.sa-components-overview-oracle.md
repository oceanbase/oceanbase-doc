# SA_COMPONENTSの概要

`SA_COMPONENTS` パッケージは、セグメンテーションタグのコンポーネント定義を管理するために使用されます。

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `SA_COMPONENTS` パッケージの内容を示しています。

|                                   ストアドプロシージャ                                    |      **説明**      |
|---------------------------------------------------------------------------|------------------|
| [SA_COMPONENTS.ALTER_LEVEL](../300.sa-components-tag-package-oracle/200.sa-components-alter-level-oracle.md)  | レベルの略称と正式名称を変更します。    |
| [SA_COMPONENTS.CREATE_LEVEL](../300.sa-components-tag-package-oracle/300.sa-components-create-level-oracle.md) | レベルを作成し、その略称と正式名称を指定します。 |
| [SA_COMPONENTS.DROP_LEVEL](../300.sa-components-tag-package-oracle/400.sa-components-drop-level-oracle.md)   | レベルを削除します。            |
