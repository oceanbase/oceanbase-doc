# ネスト表

ネスト表とは、PLプログラム内で配列のように参照および操作できる非永続的なテーブルです。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

ユーザーはテーブル型を定義し、その型の変数を宣言することができます。その後、ユーザーはPL表にレコードを追加し、配列の要素を参照するのとほぼ同じ方法でレコードを参照できます。

構文は以下のとおりです：

```javascript
TYPE type_name IS TABLE OF
{column_type | variable%TYPE | table.column%TYPE } [NOT NULL] | table%ROWTYPE
```

PLネスト表のテーブル型でサポートされている値の取得方法は、次の表のとおりです。

|    **メソッド**     |                                                                                                     **説明**                                                                                                     |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EXISTS(n)     | n 番目の行が存在する場合、True を返します。                                                                                                                                                                                           |
| COUNT         | PL テーブルの行数を返します。                                                                                                                                                                                                  |
| FIRST \| LAST | 最初の行と最後の行（最小値と最大値）の行番号を返します。PL テーブルにデータがない場合は、NULL を返します。                                                                                                                                                                        |
| PRIOR(n)      | PL テーブルの n 番目の行の前の行の行番号を返します。                                                                                                                                                                                      |
| NEXT(n)       | PL テーブルの n 番目の行の次の行の行番号を返します。                                                                                                                                                                                      |
| DELETE        | <ul><li> DELETE：テーブル内のすべてのレコードを削除します。   </li><li> DELETE(n)：テーブルの n 番目のレコードを削除します。   </li><li> DELETE(m,n)：行番号 m から n の間のすべてのレコードを削除します。</li></ul>    |

ネスト表の例は以下のとおりです。PL表のレコードを削除しても、他のレコードの行番号は移動しません。

```javascript

    TYPE t_dept_table IS TABLE OF departments%ROWTYPE INDEX BY BINARY_INTEGER;
    tab_department T_DEPT_TABLE;
    v_count number(2) :=6;
BEGIN
    -- テーブルに値を代入
    FOR int IN 1 .. v_count LOOP
    SELECT * INTO tab_department(int) FROM departments WHERE department_id=int*10;
    END LOOP;

    -- COUNTを使用して合計行数を出力
    DBMS_OUTPUT.PUT_LINE(tab_department.COUNT||' ROW(S): ');
    -- FIRSTとLASTを使用してすべての行を出力
    FOR int IN TAB_department.FIRST .. TAB_department.LAST LOOP
        DBMS_OUTPUT.PUT_LINE('Department number: '||tab_department(int).department_id);
        DBMS_OUTPUT.PUT_LINE('Department name: '|| tab_department(int).department_name);
    END LOOP;

    -- EXISTSを使用してレコードをチェック
    IF tab_department.EXISTS(5) THEN
       DBMS_OUTPUT.PUT_LINE('ROW 5 EXISTS');
    ELSE
       DBMS_OUTPUT.PUT_LINE('ROW 5 NOT EXISTS');

       DBMS_OUTPUT.PUT_LINE('Delete row 2-3');
         tab_department.DELETE(2,3);

    -- NEXTを使用して最初から順にレコードを出力
        DBMS_OUTPUT.PUT_LINE('Looping from first');
         v_count := 1;
         WHILE v_count IS NOT NULL
         LOOP
             DBMS_OUTPUT.PUT_LINE(tab_department(v_count).department_id);
             v_count := tab_department.next(v_count);

    -- PRIORを使用して最後から逆順に出力します。このときCOUNTは4になります。

          v_count := tab_department.COUNT;

         LOOP
             DBMS_OUTPUT.PUT_LINE(tab_department(v_count).department_id);
             v_count := tab_department.prior(v_count);
         END LOOP;
END;
```

## ネスト表と配列の主な違い

概念的には、ネスト表は要素数を任意に持つ1次元配列のようなものです。ネスト表と配列の主な違いは以下の通りです：

* 配列は要素数を宣言できますが、ネスト表はできません。ネスト表のサイズは動的に拡張可能です。

* 配列は常に密です。ネスト表は初期段階では密ですが、要素を削除することができるため疎になることもあります。

## ネスト表の適用シナリオ

ネスト表は以下のシナリオに適しています：

* 要素数が未定義の場合。

* インデックス値が連続していない場合。

* 特定の要素を削除または更新する必要があるが、すべての要素を一度に削除または更新することはできない場合。
