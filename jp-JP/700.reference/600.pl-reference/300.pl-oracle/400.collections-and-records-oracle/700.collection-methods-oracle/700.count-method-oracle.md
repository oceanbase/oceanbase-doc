# COUNTメソッド

`COUNT`は、コレクション内の要素数を返します（削除された要素は無視されます。`DELETE`操作でプレースホルダーが保持されている場合でも同様です）。

## 可変配列での使用

可変配列では、`COUNT`は常に`LAST`と等しくなります。`EXTEND`または`TRIM`メソッドを使用して可変配列のサイズを増減すると、`COUNT`の値が変更されます。

```javascript
obclient> DECLARE
  TYPE oblist IS VARRAY(10) OF INTEGER;
  t oblist := OBLIST(2,4,6,8,10);

  PROCEDURE print_count_and_last IS
  BEGIN
    DBMS_OUTPUT.PUT('t.COUNT = ' || t.COUNT || ', ');
    DBMS_OUTPUT.PUT_LINE('t.LAST = ' || t.LAST);
  END  print_count_and_last;

BEGIN
  print_count_and_last;

  t.EXTEND(2);
  print_count_and_last;

  t.TRIM(4);
  print_count_and_last;
END;
/
Query OK, 0 rows affected

t.COUNT = 5, t.LAST = 5
t.COUNT = 7, t.LAST = 7
t.COUNT = 3, t.LAST = 3
```

上記の例では、可変配列変数を宣言し、4つの要素を初期化して代入します。その後、`EXTEND(3)`と`TRIM(5)`を実行した後、可変配列の`COUNT`と`LAST`の値を出力します。

## ネスト表での使用

ネスト表では、`COUNT`は`LAST`と等しくなります。ただし、ネスト表の途中から要素を削除する場合は、`COUNT`は`LAST`より小さくなります。

```javascript
obclient> DECLARE
  TYPE oblist IS TABLE OF INTEGER;
  t oblist := OBLIST(2,4,6,8,10);

  PROCEDURE print_count_and_last IS
  BEGIN
    DBMS_OUTPUT.PUT('t.COUNT = ' || t.COUNT || ', ');
    DBMS_OUTPUT.PUT_LINE('t.LAST = ' || t.LAST);
  END  print_count_and_last;

BEGIN
  print_count_and_last;

  t.EXTEND(2);     --末尾に2つのNull要素を追加
  print_count_and_last;

  t.DELETE(3);     --3番目の要素を削除
  print_count_and_last;

  FOR i IN 1..8 LOOP
    IF t.EXISTS(i) THEN
      IF t(i) IS NOT NULL THEN
        DBMS_OUTPUT.PUT_LINE('t(' || i || ') = ' || t(i));
      ELSE
        DBMS_OUTPUT.PUT_LINE('t(' || i || ') = NULL');
      END IF;
    ELSE
      DBMS_OUTPUT.PUT_LINE('t(' || i || ') does not exist');
    END IF;
  END LOOP;
END;
/
Query OK, 0 rows affected

t.COUNT = 5, t.LAST = 5
t.COUNT = 7, t.LAST = 7
t.COUNT = 6, t.LAST = 7
t(1) = 2
t(2) = 4
t(3) does not exist
t(4) = 8
t(5) = 10
t(6) = NULL
t(7) = NULL
t(8) does not exist
```

上記の例では、ネストされたテーブル変数を宣言し、5つの要素に初期値を代入します。その後、末尾に2つのNULL要素を追加し、3番目の要素を削除します。そして、ネストされたテーブルの`COUNT`と`LAST`の値を出力します。最後に、例の中で1番から8番までの要素の状態を出力します。
