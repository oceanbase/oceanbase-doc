# PRIORとNEXTメソッド

`PRIOR` と `NEXT` は、コレクション内を前後に移動するために使用できます（削除された要素は無視されます。ただし、`DELETE` 操作でプレースホルダーが残されている場合はそのままです）。

`PRIOR` と `NEXT` の2つのメソッドは、疎なコレクションの走査に適しています。

インデックスを指定した後：

* `PRIOR` は、そのコレクション内で直前に存在した要素のインデックスを返します（存在する場合）。存在しない場合、`PRIOR` は `NULL` を返します。任意のコレクション `c` について、`c.PRIOR(c.FIRST)` は `NULL` を返します。

* `NEXT` は、そのコレクションの次に存在する要素のインデックスを返します（存在する場合）。存在しない場合、`NEXT` は `NULL` を返します。任意のコレクション `c` について、`c.NEXT(c.LAST)` は `NULL` を返します。

指定されたインデックスが存在する必要はありません。ただし、コレクション `c` が可変配列であり、かつインデックスが `c.LIMIT` を超える場合は：

* `c.PRIOR(index)` は `c.LAST` を返します。

* `c.NEXT(index)` は `NULL` を返します。

可変配列の例：

```javascript
obclient> DECLARE
  TYPE var_ty IS VARRAY(10) OF NUMBER;
  v_num var_ty := VAR_TY(11,22,33,44,55);
BEGIN

  DBMS_OUTPUT.PUT_LINE(NVL(v_num.prior (10), -1));
  DBMS_OUTPUT.PUT_LINE(NVL(v_num.next (10), -1));
END;
/
Query OK, 0 rows affected (0.04 sec)

5
-1
```

ネストされたテーブルの例：

```javascript
DECLARE
  TYPE oblist IS TABLE OF VARCHAR(10);
  nt OBLIST := oblist('A', 'B', NULL, NULL, 'E', NULL, 'F', 'G', 'H', NULL);
  idxt INTEGER;

BEGIN
  DBMS_OUTPUT.PUT_LINE('From First to Last Using Next:');
  idxt := nt.FIRST;
  WHILE idxt IS NOT NULL LOOP
    DBMS_OUTPUT.PUT('nt(' || idxt || ') = ');
    DBMS_OUTPUT.PUT_LINE(NVL(TO_CHAR(nt(idxt)), 'NULL'));
    idxt := nt.NEXT(idxt);
  END LOOP;

  DBMS_OUTPUT.PUT_LINE('--------------');

  DBMS_OUTPUT.PUT_LINE('From Last to First Using Prior:');
  idxt := nt.LAST;
  WHILE idxt IS NOT NULL LOOP
    DBMS_OUTPUT.PUT('nt(' || idxt || ') = ');
    DBMS_OUTPUT.PUT_LINE(NVL(TO_CHAR(nt(idxt)), 'NULL'));
    idxt := nt.PRIOR(idxt);
  END LOOP;
END;
/
```

上記の例ではそれぞれ `FIRST` と `NEXT`、`LAST` と `PRIOR` を使用して、疎なネストテーブル内のすべての要素を出力しています。
