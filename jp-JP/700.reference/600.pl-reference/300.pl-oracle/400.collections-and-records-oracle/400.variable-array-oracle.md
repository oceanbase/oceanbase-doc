# 変数配列

変数配列（Varrayとも呼ばれ、Variable Arrayの略）は、順序付き要素の集合であり、すべての要素が同じデータ型を持ち、各要素のインデックスがその要素の配列内での位置に対応します。

変数配列にはサイズの制限があります。変数配列を作成する際には、その最大長を指定する必要があります。

変数配列を作成する簡単な構文は以下のとおりです：

```javascript
TYPE varray_name IS VARRAY( size ) OF element_type [ NOT NULL ] ;
```

ここで、`varray_name` は変数配列のデータ型名です。`size` は正の整数で、収容可能な配列要素の最大数を表します。各要素のデータ型は `element_type` です。デフォルトでは、要素はNULL値を取ることができますが、そうでない場合は `NOT NULL` で制限する必要があります。

**例：変数配列の作成**

```javascript
obclient> DECLARE
  TYPE players IS VARRAY(5) OF VARCHAR2(20);
  team PLAYERS := players('Andrew', 'Barton', 'Conrad', 'Dick','Edward');
  PROCEDURE print_team (heading VARCHAR2) IS
  BEGIN
    DBMS_OUTPUT.PUT_LINE(heading);
    FOR i IN 1..5 LOOP
      DBMS_OUTPUT.PUT_LINE(i || '.' || team(i));
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('---');

  END;
BEGIN
  print_team('First Team:');
  team(2) := 'Albert';
  team(5) := 'George';
  print_team('Second Team:');
  team := players('Charles', 'Carl', 'James', 'Gary','Brian');
  print_team('Third Team:');
END;
/

```

変数配列は以下のシナリオに適しています：

* 要素の最大数が既知の場合。

* 要素へのアクセスが通常は順序良く行われる場合。

変数配列はすべての要素を同時に格納または取得する必要があるため、要素数が多いシナリオにはあまり適していません。
