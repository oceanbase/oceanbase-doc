# カーソルの概要

OceanBaseデータベースがSQLステートメントを実行すると、結果セットと処理情報を名前の付いていないプライベートなメモリ領域に格納し、そのメモリ領域の先頭を指すポインターを設定します。このポインターがカーソルです。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみ提供しています。</p>
  </main>

カーソルを使用すると、1回につき1行のレコードを取得できます。カーソル属性は、カーソルの状態情報を返します。カーソルには、明示的カーソルと暗黙的カーソルがあります。
