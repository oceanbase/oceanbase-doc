# カーソルの概要

OceanBaseデータベースがSQLステートメントを実行すると、結果セットと処理情報を未命名のプライベートメモリ領域に格納し、そのメモリ領域の開始値を指すポインタを設定します。このポインタがカーソルです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

カーソルを使用すると、1回につき1行のレコードを取得できます。カーソルのプロパティは、カーソルの状態情報を返します。カーソルには、明示的カーソルと暗黙的カーソルがあります。
