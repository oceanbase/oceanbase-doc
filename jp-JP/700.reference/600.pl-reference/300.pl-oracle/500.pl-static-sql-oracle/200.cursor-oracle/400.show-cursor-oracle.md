# 明示カーソル

明示カーソルは、主にクエリステートメントの処理に使用され、特にクエリ結果が複数のレコードの場合に有効です。

## 明示カーソルの呼び出し形式

明示カーソルを宣言した後、同一のサブプログラムまたはパッケージ内で定義するか、同時に宣言と定義を行うことができます。

明示カーソルを宣言するだけの構文は以下のとおりです：

```javascript
CURSOR cursor_name [ parameter_list ] RETURN return_type;
```

カーソルを定義する構文は以下のとおりです：

```javascript
CURSOR cursor_name [ parameter_list ] [ RETURN return_type ]
IS select_statement;
```

## 明示カーソルの処理手順

明示カーソルの処理には4つのステップがあります：

1. カーソルの定義

2. カーソルの開放

3. カーソルデータの取得

4. カーソルの閉鎖

#### カーソルの定義

カーソル名と、それに対応する `SELECT` ステートメントを定義します。

構文は以下のとおりです：

```javascript
CURSOR cursor_name[(parameter[, parameter]...)] IS select_statement;
```

カーソルパラメータは入力パラメータのみとなり、その構文は以下のとおりです：

```javascript
parameter_name [IN] datatype [{:= | DEFAULT} expression]
```

    <p>データ型を指定する際には、長さ制約を使用できません。<code>NUMBER(4)</code>や<code>CHAR(10)</code>などはすべて誤りです。</p>
  </main>

#### カーソルの開放

`OPEN` ステートメントは、カーソルを開き、対応する `SELECT` ステートメントを実行してその結果をワークエリアに格納し、ポインタをワークエリアの先頭に配置してカーソルの結果セットを識別するために使用されます。カーソルのクエリステートメントに `FOR UPDATE` オプションが含まれる場合、`OPEN` ステートメントはデータベーステーブル内のカーソルの結果セットに対応するデータ行もロックします。

構文は以下のとおりです：

```javascript
OPEN cursor_name[([parameter =>] value[, [parameter =>] value]...)];
```

カーソルにパラメータを渡す際には、関数パラメータと同じ値渡し方法、すなわち位置表示法と名前表示法を使用できます。PLプログラムでは、`OPEN` ステートメントを使用して同一のカーソルを繰り返し開くことはできません。

#### カーソルデータの取得

`FETCH` ステートメントを使用して結果セット内のデータ行を取得し、指定された出力変数に格納します。

構文は以下のとおりです：

```javascript
FETCH cursor_name INTO {variable_list | record_variable };

/* カーソルを使用してデータを一括取得することも可能 */
FETCH { cursor | cursor_variable | :host_cursor_variable }
  { into_clause | BULK COLLECT INTO { collection | :host_array }
  [, { collection | :host_array } ]... [ LIMIT numeric_expression ] } ;

```

通常、`FETCH` ステートメントは `LOOP` ステートメント内で使用され、アクティブな結果セット内のすべてのレコードを処理するまで、そのレコードに対して繰り返し処理を行います。`FETCH` ステートメントは、カーソル属性 `%NOTFOUND` を使用して終了条件を検出します。

#### カーソルの閉鎖

`CLOSE` ステートメントは、カーソルを閉じるために使用されます。

構文は以下のとおりです：

```javascript
CLOSE cursor_name;
```

カーソルの結果セットのデータを取得し処理した後は、カーソルが占有するシステムリソースを解放し、そのワークエリアを無効にするために、速やかにカーソルを閉じる必要があります。これにより、`FETCH` ステートメントでそのデータを取得することはできなくなります。閉じたカーソルは、`OPEN` ステートメントを使用して再び開くことができます。

## 明示カーソルを使用してループ処理でレコードセットの各行を取得する

以下の手順では、明示カーソルを使用してループ処理でレコードセットの各行を取得する方法を示します。

1. まず、宣言部でカーソルを宣言します。以下の2つの方法を参照してください。

   ```sql
   CURSOR cursor_name IS query;      -- 方法1
   CURSOR cursor_name(para_name data_type) IS query;     -- 方法2
   ```

2. 宣言部で、カーソルが返す行レコードを格納するためのレコードを宣言します。

   ```sql
   record_name cursor_name%ROWTYPE;
   ```

3. 実行部でカーソルを開きます。以下の2つの方法を参照してください。

   ```sql
   OPEN cursor_name;       -- 方法1
   OPEN cursor_name(para_name);      -- 方法2
   ```

4. 実行部で、カーソルのレコードセットから行データを取得します。一度に1行ずつですが、以下の形式の `LOOP` ステートメントと組み合わせて使用することで、複数行のデータを取得できます。

   ```sql
   LOOP
   FETCHcursor_name INTO record_name;
   EXIT WHEN cursor_name%NOTFOUND;
   statement;
   [ statement; ]...
   END LOOP;
   ```

5. カーソルを閉じます。

   ```sql
   CLOSE cursor_name;
   ```
