# SQLからの自治関数の呼び出し

SQLステートメントから呼び出される関数は、一定のルールに従わなければなりません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

定義上、自治プログラムはデータベースの状態を読み取ったり書き込んだりすることはありません。つまり、データベーステーブルをクエリしたり変更したりすることはありません。

以下の例では、パッケージ関数 `oblog_msg` は自治的です。したがって、この関数をSQLから呼び出すと、データベーステーブル `obdebug_output` にメッセージを挿入しますが、データベーステーブルを変更するルールに違反することはありません。

```sql
obclient> CREATE TABLE emp(
   empno          NUMBER(4,0),
   empname        VARCHAR(10),
   job            VARCHAR(10),
   deptno         NUMBER(2,0)
);
Query OK, 0 rows affected

obclient> INSERT INTO emp VALUES (200,'Jennifer','AD_ASST',1);
Query OK, 1 row affected

obclient> CREATE TABLE obdebug_output (msg VARCHAR2(200));
Query OK, 0 rows affected

obclient> CREATE OR REPLACE PACKAGE obdebugging AUTHID DEFINER AS
       FUNCTION oblog_msg (message VARCHAR2) RETURN VARCHAR2;
    END obdebugging;
    /
Query OK, 0 rows affected

obclient> CREATE OR REPLACE PACKAGE BODY obdebugging AS
      FUNCTION oblog_msg (message VARCHAR2) RETURN VARCHAR2 IS
        PRAGMA AUTONOMOUS_TRANSACTION;
      BEGIN
        INSERT INTO obdebug_output (msg) VALUES (message);
        COMMIT;
        RETURN message;
      END;
    END obdebugging;
    /
Query OK, 0 rows affected

-- パッケージ関数の呼び出し

obclient>DECLARE
      my_id       NUMBER(6);
      my_name     VARCHAR2(25);
      my_count     NUMBER;
    BEGIN
     my_id := 200;

      SELECT obdebugging.oblog_msg(empname)
      INTO my_name
      FROM emp
      WHERE empno = my_id;

      ROLLBACK;
    END;
    /
Query OK, 0 rows affected
```
