# 概要

PL静的SQLは、PL文の中で直接SQL構文を使用することをサポートします。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

通常、PL静的SQL文は、以下の対応するSQL文と同じ構文を持ちます：

* `SELECT`（この文はクエリとも呼ばれます）

* データ操作言語（DML）文：`INSERT`、`UPDATE`、`DELETE`、`MERGE`。

* トランザクション制御言語（TCL）文：`COMMIT`、`ROLLBACK`、`SAVEPOINT`、`SET TRANSACTION`、`LOCK TABLE`。

擬似列はテーブル列のように動作しますが、テーブルには格納されません。静的SQLには以下のSQL擬似列が含まれます：

* `CURRVAL` と `NEXTVAL`

* `LEVEL`

* `OBJECT_VALUE`

* `ROWID`

* `ROWNUM`

OceanBaseデータベースのPL静的SQLは、以下のシナリオでSQLが複雑なデータ型を返すことをサポートします：

* `​SELECT INTO`/`BULK INTO​`
* DML文内の `RETURING INTO`/`BULK INTO`
* `​FETCH INTO`/`BULK INTO`

<main id="notice" type='notice'>
<h4>注意</h4>
<p>V4.2.0以降、OceanBaseデータベースでは、複数列のデータをRECORD型の変数にインポート（`INTO`）したり、複数列のデータをBULKインポート（`BULK INTO`）して複数のOBJECT型変数に格納したりすることが可能になりました。</p>
</main
