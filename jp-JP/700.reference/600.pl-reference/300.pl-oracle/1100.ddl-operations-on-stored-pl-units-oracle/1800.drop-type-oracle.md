# DROP TYPE

`DROP TYPE` ステートメントは、ユーザー定義の抽象データ型（ADT）、`VARRAY` 型、またはネスト表型の仕様と本体を削除するために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供します。</p>
  </main>

## 前提条件

該当するADT、`VARRAY` 型、またはネスト表型が現在ユーザーのスキーマ内に存在しているか、またはユーザーが `ALTER ANY TYPE` システム権限を持っている必要があります。

## 構文

`drop_type` の構文は以下のとおりです：

```sql
DROP TYPE [ schema. ] type_name [ FORCE | VALIDATE ] ;
```

## セマンティクス

|    構文     | キーワードまたは構文ノード  |         説明   |
|-----------|-----------|---------------------------------|
| drop_type | schema    | この型が存在するスキーマ名。デフォルト値は現在ユーザーのスキーマです。   |
| drop_type | type_name | 削除対象の`VARRAY`またはネスト表タイプの名前。型や表に依存しない型のみを削除できます。`type_name`がスーパータイプの場合、このステートメントは実行失敗します。`type_name`が統計情報タイプの場合、このステートメントは実行失敗します。`type_name`が統計情報タイプに関連付けられたADTの場合、データベースはまず`type_name`で設定されたADTと統計情報タイプの関連付けを解除しようと試み、その後`type_name`を削除します。ただし、統計情報タイプを使用して統計情報が収集されている場合、データベースは`type_name`で設定されたADTと統計情報タイプの関連付けを解除できず、このステートメントの実行は失敗します。`type_name`がインデックスタイプの場合、インデックスタイプを`INVALID`としてマークします。`type_name`に公開シノニムが定義されている場合、データベースもそのシノニムを削除します。|

## 例

`demo_typ2` 型を削除します。

```sql
DROP TYPE demo_typ2 FORCE;
```
