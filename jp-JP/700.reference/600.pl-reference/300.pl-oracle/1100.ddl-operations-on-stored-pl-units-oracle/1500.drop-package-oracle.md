# DROP PACKAGE

`DROP PACKAGE` ステートメントは、データベースから格納されたプログラムパッケージを削除するために使用します。このステートメントは、パッケージのヘッダーとボディを削除します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。
  </main>

  <main id="notice" type='notice'>
    <h4>注意</h4>
      <p>このステートメントを使用してパッケージから個々のオブジェクトを削除しないでください。<code>OR REPLACE</code> 句を含む <code>CREATE PACKAGE</code> ステートメントと <code>CREATE PACKAGE BODY</code> ステートメントを使用して、そのオブジェクトなしでパッケージを再作成してください。</p>
  </main>

## 前提条件

該当するパッケージが現在ユーザーのスキーマ内に存在するか、またはユーザーが `ALTER ANY PACKAGE` システム権限を持っている必要があります。

## 構文

`drop_package` の構文は以下のとおりです：

```sql
DROP PACKAGE [ BODY ] [ schema. ] package ;
```

## セマンティクス

|      構文      | キーワードまたは構文ノード |                                                                                              説明                                                                                               |
|--------------|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| drop_package | BODY     | パッケージ本体のみを破棄します。この句を省略した場合、データベースはパッケージヘッダーとボディを削除します。パッケージヘッダーを破棄せずに本体のみを破棄する場合、データベースは依存オブジェクトを無効にしません。ただし、パッケージ本体を再作成するまで、パッケージヘッダーで宣言されたストアドプロシージャや関数を呼び出すことはできません。                                                                                   |
| drop_package | schema   | そのパッケージが存在するスキーマ名です。デフォルト値は現在ユーザーのスキーマです。                                                                                                                                                           |
| drop_package | package  | 削除するプログラムパッケージの名前です。データベースは、パッケージヘッダーに依存しているローカルオブジェクトをすべて無効にします。これらのオブジェクトを後から参照すると、データベースはそのオブジェクトの再コンパイルを試みます。削除されたプログラムパッケージが再作成されていない場合、エラーが返されます。パッケージに関連付けられた統計情報タイプがある場合、データベースはその統計情報タイプを `FORCE` 句から解除関連付けし、その統計情報タイプを使用して収集されたすべてのユーザー定義統計情報を削除します。 |

## 例

パッケージ `obdemo_pack` を削除します。

```sql
DROP PACKAGE obdemo_pack;
```
