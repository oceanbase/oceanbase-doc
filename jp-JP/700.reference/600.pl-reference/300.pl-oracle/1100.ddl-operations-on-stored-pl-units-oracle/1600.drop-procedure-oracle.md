# DROP PROCEDURE

`DROP PROCEDURE` ステートメントは、データベースから独立ストアドプロシージャを削除するために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。
  </main>

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>このステートメントを使用してパッケージ内のストアドプロシージャを削除しないでください。<code>DROP PACKAGE</code> ステートメントを使用してパッケージ全体を削除するか、<code>OR REPLACE</code> 句を含む <code>CREATE PACKAGE</code> ステートメントを使用して、当該ストアドプロシージャを含まないパッケージを再定義する必要があります。</p>
  </main>

## 前提条件

当該ストアドプロシージャは、現在のユーザーのスキーマ内に存在する必要があります。または、ユーザーは `ALTER ANY PROCEDURE` システム権限を持っている必要があります。

## 構文

`drop_procedure` の構文は次のとおりです：

```sql
DROP PROCEDURE [ schema. ] procedure ;
```

## セマンティクス

|       構文       |    キーワードまたは構文ノード    |                                                           説明                                                            |
|----------------|----------------|-------------------------------------------------------------------------------------------------------------------------|
| drop_procedure | schema         | このストアドプロシージャが存在するスキーマ名です。デフォルト値は現在ユーザーのスキーマです。                                                                                    |
| drop_procedure | procedure_name | 削除するストアドプロシージャの名前です。ストアドプロシージャを削除すると、データベースはそのストアドプロシージャに依存しているすべてのローカルオブジェクトを無効にします。その後これらのオブジェクトが参照された場合、データベースはそのオブジェクトの再コンパイルを試みますが、削除されたストアドプロシージャがまだ再作成されていない場合は、エラーメッセージが返されます。 |

## 例

ストアドプロシージャ `userlogin` を削除します。

```sql
DROP PROCEDURE userlogin;
```
