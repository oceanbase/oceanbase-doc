# DROP TYPE BODY

`DROP TYPE BODY` 文は、ユーザー定義の抽象データ型（ADT）、可変配列（VARRAY）型、またはネスト表（Nested Table）型の本体を削除するために使用します。

型本体を削除しても型仕様は残り、後から型本体を再作成できます。メンバー関数は呼び出せませんが、本体を再作成するまでの間もその型自体は使用できます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
  </main>

## 前提条件

この型本体が現在ユーザーのスキーマ内に存在するか、またはユーザーが `ALTER ANY TYPE` システム権限を持っている必要があります。

## 構文

`drop_type_body` の構文は以下のとおりです：

```sql
DROP TYPE BODY [ schema. ] type_name ;
```

## セマンティクス

|       構文       | キーワードまたは構文ノード  |                         説明                         |
|----------------|-----------|----------------------------------------------------|
| drop_type_body | schema    | この型が存在するスキーマ名。デフォルト値は現在ユーザーのスキーマです。                 |
| drop_type_body | type_name | 削除する型本体。型本体に型やテーブルの依存関係がない場合にのみ削除できます。 |

## 例

型本体 `demo_typ2` を削除します。

```sql
DROP TYPE BODY demo_typ2;
```
