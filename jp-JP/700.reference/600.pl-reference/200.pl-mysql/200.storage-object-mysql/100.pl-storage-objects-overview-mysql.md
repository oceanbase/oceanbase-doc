# ストアドプログラムの概要

OceanBaseデータベースのMySQLモードにおけるPLストアドプログラムには、ストアドプロシージャ、ストアド関数、トリガーが含まれます。

OceanBaseデータベースのMySQLモードにおけるPLストアオブジェクトには、以下のオブジェクトタイプが含まれます：

* ストアドプロシージャ：このオブジェクトは `CREATE PROCEDURE` で作成し、`CALL` ステートメントで呼び出します。ストアドプロシージャには戻り値はありませんが、出力パラメータを持たせたり、結果セットを生成してクライアントプログラムに返したりできます。

* ストアド関数：このオブジェクトは `CREATE FUNCTION` で作成し、使い方は組み込み関数と似ています。ユーザーは式の中でストアド関数を呼び出し、式の評価時に値を返すことができます。

* トリガー：このオブジェクトは `CREATE TRIGGER` で作成し、テーブルに関連付けます。テーブルへの挿入や更新などの操作がトリガーを活性化することができます。

その中で、ストアドプロシージャとストアド関数はストアドルーチンに属し、ストアドルーチンとトリガーはストアドプログラムに属します。

各ストアドプログラムには、複数のSQLステートメントで構成される本体が含まれており、各SQLステートメントはセミコロン（;）で区切ることができます。ストアドプロシージャの本体は `BEGIN` キーワードで始まり、`END;` キーワードで終わります。
