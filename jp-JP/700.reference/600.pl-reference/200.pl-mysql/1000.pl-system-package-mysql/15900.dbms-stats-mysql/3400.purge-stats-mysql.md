# PURGE_STATS

`PURGE_STATS`は、指定された時刻より前の履歴統計情報を削除するために使用されます。

## 構文

```sql
DBMS_STATS.PURGE_STATS(
  before_timestamp       TIMESTAMP WITH TIME ZONE);
```

## パラメータ説明

`before_timestamp`パラメータは、履歴統計情報を削除する際の境界時刻を指定します。この時刻より前に保存された統計情報が削除されます。`NULL`の場合、自動クリアポリシーが使用されます。

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| HY000     |  <ul><li>オブジェクトが存在しないか、権限が不足しています。</li><li>無効または不整合な値。</li></ul>     |

## 例

指定した時刻の履歴統計情報を手動でクリーンアップします。

```sql
obclient [testUser01]> CALL DBMS_STATS.PURGE_STATS ('2021-09-26 19:02:12.675729');
Query OK, 0 rows affected
```
