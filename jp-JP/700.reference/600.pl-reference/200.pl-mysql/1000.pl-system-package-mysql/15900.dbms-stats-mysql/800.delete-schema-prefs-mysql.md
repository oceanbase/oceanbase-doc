# DELETE_SCHEMA_PREFS

`DELETE_SCHEMA_PREFS` プロシージャは、指定されたスキーマのすべてのテーブルの統計情報の設定を削除します。

## 構文

```sql
DBMS_STATS.DELETE_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2);
```

## パラメータ説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | スキーマ名。 |
| pname   | Prefsの名前。 |

## 例外

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000     | スキーマが存在しないか、権限が不足しているか、または無効な値や不正な入力値です。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとしてデータベースに接続しているか、`SYSDBA` 権限を持っている必要があります。

* プロシージャ内のパラメータはすべて `VARCHAR2` 型であり、値は引用符で囲む必要があります。

## 例

`hr` スキーマの設定 `DEGREE` を削除します。

```sql
obclient> CALL DBMS_STATS.DELETE_SCHEMA_PREFS('hr', 'DEGREE');
Query OK, 0 rows affected
```
