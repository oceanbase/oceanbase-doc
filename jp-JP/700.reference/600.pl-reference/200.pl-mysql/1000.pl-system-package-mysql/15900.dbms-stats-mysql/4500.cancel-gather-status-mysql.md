# CANCEL_GATHER_STATS

`CANCEL_GATHER_STATS`は、統計情報収集コマンドをキャンセルするために使用します。

## 構文

```sql
DBMS_STATS.cancel_gather_stats (
      taskid         VARCHAR2
    );
```

## パラメータの説明

|    パラメータ    |        説明         |
|----------|-----------------------|
|taskid|収集中のタスクIDを表します。<main id="notice" type='explain'><h4>説明</h4><p><code>taskid</code>は、<code>GV$OB_OPT_STAT_GATHER_MONITOR</code>ビューを参照することで取得できます。このビューの詳細については、<a href="../../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/6100.gv_ob_opt_stat_gather_monitor-of-mysql-mode.md">GV\$OB_OPT_STAT_GATHER_MONITOR</a>を参照してください。</p></main>|

## 例

```sql
obclient> CALL DBMS_STATS.CANCEL_GATHER_STATS(taskid);
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>taskid</code>は実際の値に置き換えてください。</p>
</main>
