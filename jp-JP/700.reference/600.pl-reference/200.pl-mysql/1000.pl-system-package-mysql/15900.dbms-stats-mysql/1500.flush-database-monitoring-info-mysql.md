# FLUSH_DATABASE_MONITORING_INFO

`FLUSH_DATABASE_MONITORING_INFO` プロシージャは、データベース内のすべてのテーブルに関するメモリ監視情報をリフレッシュします。

## 構文

```sql
DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
```

## 例外

エラーコード `HY000` は権限不足を示します。

## 使用方法

`FLUSH_DATABASE_MONITORING_INFO` は、定期的なデータベースリフレッシュを待たずに、`*_TAB_STATISTICS` および `*_IND_STATISTICS` ビュー内の対応する情報を即座に更新します。`GATHER_*_STATS` プロシージャは内部で監視情報をリフレッシュするため、統計情報収集前にこのストアドプロシージャを実行する必要はありません。

## 例

```sql
obclient> CALL DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
Query OK, 0 rows affected
```
