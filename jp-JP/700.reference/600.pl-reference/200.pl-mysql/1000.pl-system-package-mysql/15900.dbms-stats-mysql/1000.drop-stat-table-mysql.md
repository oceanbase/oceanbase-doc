# DROP_STAT_TABLE

`DROP_STAT_TABLE` プロシージャは、ユーザーの統計テーブルを削除するために使用されます。

## 構文

```sql
DBMS_STATS.DROP_STAT_TABLE (
  ownname VARCHAR2,
  stattab VARCHAR2);
```

## パラメータ説明

|   パラメータ    |                説明                 |
|---------|-----------------------------------|
| ownname | ユーザー名。ユーザー名が `NULL` に設定されている場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| stattab | 削除するユーザー統計情報テーブルの名前。                   |

## 例外

エラーコード `HY000` は、テーブルが存在しないか権限が不足していることを示します。

## 使用方法

このプロシージャを呼び出すには、指定されたスキーマ内でそのテーブルを削除する権限が必要です。

## 例

ユーザー `testUser01` の統計情報テーブル `test_stat` を削除します。

```sql
obclient> CALL DBMS_STATS.DROP_STAT_TABLE('testUser01', 'test_stat');
Query OK, 0 rows affected
```
