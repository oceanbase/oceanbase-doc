# UNLOCK_PARTITION_STATS

`UNLOCK_PARTITION_STATS` プロシージャは、パーティションの統計情報のロックを解除するために使用されます。

## 構文

```sql
DBMS_STATS.UNLOCK_PARTITION_STATS (
  ownname      VARCHAR2,
  tabname      VARCHAR2,
  partname     VARCHAR2);
```

## パラメータの説明

|    パラメータ    |                説明                 |
|----------|-----------------------------------|
| ownname  | ユーザー名。ユーザー名を`NULL`に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| tabname  | テーブル名。                              |
| partname | (サブ)パーティション名。                         |

## 使用方法

このプロシージャを呼び出すには、テーブル所有者である必要があります。`SYS` が所有するオブジェクトについては、テーブル所有者または `SYSDBA` 権限が必要です。

## 例

ユーザー `testUser01` のテーブル `t1` の `p0` パーティションの統計情報のロックを解除します。

```sql
obclient> CALL DBMS_STATS.UNLOCK_PARTITION_STATS ('testUser01', 't1', 'p0');
Query OK, 0 rows affected
```
