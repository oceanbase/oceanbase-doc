# DELETE_SYSTEM_STATS

`DELETE_SYSTEM_STATS` プロシージャは、システム統計情報を削除するために使用されます。

## 構文

```sql
DBMS_STATS.DELETE_SYSTEM_STATS();
```

## 例外

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000     | 入力されたシステム統計情報名が誤っています。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続するか、`SYSDBA` 権限を持っている必要があります。

## 例

`DBMS_STATS>Delete_SYSTEM_STATS` ストアドプロシージャを使用してすべてのシステム統計情報を削除することは非常に簡単です。パラメータは不要だからです。

```sql
BEGIN
    -- すべてのシステム統計情報を削除する
    DBMS_STATS_DELETE_SYSTEM_STATS();
END;
/
```
