# DBMS_PARTITIONの概要

`DBMS_PARTITION` システムパッケージは、動的パーティション管理インターフェースを提供します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseデータベースV4.3.5では、V4.3.5 BP2バージョンからシステムパッケージ <code>DBMS_PARTITION</code> がサポートされています。</p>
</main>

## 権限について

ユーザーテナントでのみ操作がサポートされます。

## サブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_PARTITION` サブプログラムとその簡潔な説明を示しています。

|                                   サブプログラム                                 |           説明          |
|--------------------------------------------------------------------------|------------------------|
| [MANAGE_DYNAMIC_PARTITION](200.manage_dynamic_partition-of-mysql-mode.md)| 動的パーティション管理タスクを1回実行し、現在のテナント配下の動的パーティションテーブルに対して将来のパーティションを事前作成し、期限切れのパーティションを削除します。|
