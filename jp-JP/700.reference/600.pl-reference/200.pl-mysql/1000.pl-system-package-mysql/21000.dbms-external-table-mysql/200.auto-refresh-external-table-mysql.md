# AUTO_REFRESH_EXTERNAL_TABLE

`auto_refresh_external_table`は、外部テーブルのMETAを定期的にリフレッシュするために使用されます。

## 構文

```sql
DBMS_EXTERNAL_TABLE.auto_refresh_external_table(interval int)
```

## パラメータ説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
| interval int | リフレッシュタスクの時間間隔を指定します。値の範囲は[-1，∞]で、単位は秒です。<ul><li>-1を指定した場合、定期リフレッシュタスクは無効になります。</li><li>0を指定した場合、外部テーブルのMETAを即座に1回リフレッシュします。</li><li>正の数値を指定した場合、指定された秒数ごとに外部テーブルのMETAをリフレッシュします。</li></ul>|

## 例

以下のコマンドを実行して、定期リフレッシュタスクを無効にします。

```shell
obclient> CALL DBMS_EXTERNAL_TABLE.auto_refresh_external_table(-1);
Query OK, 0 rows affected (0.104 sec)
```
