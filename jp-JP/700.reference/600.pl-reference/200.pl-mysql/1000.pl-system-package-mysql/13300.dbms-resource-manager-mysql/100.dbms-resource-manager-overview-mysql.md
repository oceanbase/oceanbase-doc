# DBMS_RESOURCE_MANAGERの概要

`DBMS_RESOURCE_MANAGER`システムパッケージは、リソース使用計画、リソース使用グループ、およびリソース計画指示を管理するために使用されます。

## 権限の説明

コール者は、`DBMS_RESOURCE_MANAGER`システムパッケージ内のプロシージャを実行するために`ADMINISTER_RESOURCE_MANAGER`システム権限を持っている必要があります。

## サブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_RESOURCE_MANAGER`サブプログラムとその簡潔な説明を示しています。

| [CREATE_PLAN](../13300.dbms-resource-manager-mysql/300.create-plan-mysql.md)                | リソース計画を作成します。                |
| [CREATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager-mysql/400.create-plan-directive-mysql.md)      | リソース計画指示を作成します。              |
