# DBMS_RESOURCE_MANAGERの概要

`DBMS_RESOURCE_MANAGER`システムパッケージは、リソースプラン、リソースユーザーグループ、およびリソースプラン・ディレクティブを管理するために使用されます。

## 権限の説明

呼び出し元は、`DBMS_RESOURCE_MANAGER`システムパッケージ内のプロシージャを実行するために`ADMINISTER_RESOURCE_MANAGER`システム権限を持っている必要があります。

## サブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_RESOURCE_MANAGER`サブプログラムとその簡潔な説明を示しています。
