# DBMS_MVIEWの概要

`DBMS_MVIEW` システムパッケージは、マテリアライズドビューのリフレッシュとマテリアライズドビューのログのクリアに使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

## DBMS_MVIEWサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_MVIEW` サブプログラムとその簡単な説明です。

| サブプログラム     | 説明                                      |
| --------- | ----------------------------------------- |
| [PURGE_LOG](200.purge-log-mysql.md)	| マテリアライズドビューのログをクリアするために使用されます。マテリアライズドビューのログをクリアすると、そのテーブルに関連するすべてのログレコードが削除されます。  |
| [REFRESH](300.refresh-mysql.md)	    | 指定したマテリアライズドビューをリフレッシュします。                   |
| [KILL_REFRESH](400.kill_refresh-mysql.md)| 新しいスケジューリングフレームワークによって管理され、まだ実行中のマテリアライズドビューのリフレッシュバッチを強制的に終了させるために使用されます。|
| [REFRESH_REPORT](500.refresh_report-mysql.md)| 単一のマテリアライズドビューのリフレッシュタスクの階層診断レポートを生成するために使用されます。|
