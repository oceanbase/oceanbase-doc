# DBMS_MVIEWの概要

`DBMS_MVIEW` システムパッケージは、マテリアライズドビューのリフレッシュとマテリアライズドビューのログのクリアに使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## DBMS_MVIEWサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_MVIEW` サブプログラムとその簡単な説明です。

| サブプログラム     | 説明                                      |
| --------- | ----------------------------------------- |
| [PURGE_LOG](200.purge-log-mysql.md)	| マテリアライズドビューのログを削除するために使用します。マテリアライズドビューのログを削除すると、そのテーブルに関連するすべてのログレコードが削除されます。  |
| [REFRESH](300.refresh-mysql.md)	    | 指定した1つまたは複数のマテリアライズドビューを更新します。                   |
