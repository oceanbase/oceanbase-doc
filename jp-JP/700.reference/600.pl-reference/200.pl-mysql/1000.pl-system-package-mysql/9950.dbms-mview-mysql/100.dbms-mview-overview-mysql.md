# DBMS_MVIEWの概要

`DBMS_MVIEW` システムパッケージは、マテリアライズドビューの更新とマテリアライズドビューのログのクリアに使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## DBMS_MVIEWサブプログラムの概要

下表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_MVIEW` サブプログラムとその簡単な説明です。

| サブプログラム     | 説明                                      |
| --------- | ----------------------------------------- |
| [PURGE_LOG](200.purge-log-mysql.md)	| マテリアライズドビューのログをクリアするために使用されます。マテリアライズドビューのログをクリアすると、そのテーブルに関連するすべてのログレコードが削除されます。  |
| [REFRESH](300.refresh-mysql.md)	    | 指定したマテリアライズドビューを更新します。                   |
| [KILL_REFRESH](400.kill_refresh-mysql.md)| 新しいスケジューリングフレームワークによって管理され、まだ実行中のマテリアライズドビューの更新バッチを強制的に終了させるために使用されます。|
| [REFRESH_REPORT](500.refresh_report-mysql.md)| 単一のマテリアライズドビュー更新タスクの階層診断レポートを生成するために使用されます。|
