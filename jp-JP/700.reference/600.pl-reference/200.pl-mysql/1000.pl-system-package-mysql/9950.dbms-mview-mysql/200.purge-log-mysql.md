# PURGE_LOG

`PURGE_LOG`は、マテリアライズドビューのログをクリアし、ログファイルのサイズを縮小するために使用されます。マテリアライズドビューのログをクリアすると、そのテーブルに関連するすべてのログレコードが削除されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
PROCEDURE purge_log(
    IN     master_name            VARCHAR(65535));
```

## パラメータの説明

| **パラメータ**           | **説明**                                                                                                                                              |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| master      | データを消去するマテリアライズドビューのログに対応するメインテーブル名。形式は`schema.object or object`です。                                                                         |
