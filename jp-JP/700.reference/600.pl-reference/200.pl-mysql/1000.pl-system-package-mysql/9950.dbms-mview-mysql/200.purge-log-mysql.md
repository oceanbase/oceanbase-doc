# PURGE_LOG

`PURGE_LOG`は、マテリアライズドビューのログを削除し、ログファイルのサイズを縮小するために使用されます。マテリアライズドビューのログを削除すると、そのテーブルに関連するすべてのログレコードが削除されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
PROCEDURE purge_log(
    IN     master_name            VARCHAR(65535));
```

## パラメータの説明

| **パラメータ**           | **説明**                                                                                                                                              |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| master      | データを削除するマテリアライズドビューのログの親テーブル名
形式は`schema.object or object`です。                                                                         |
