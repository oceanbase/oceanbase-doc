# REFRESH

`REFRESH`は、指定されたマテリアライズドビューをリフレッシュするために使用します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_MVIEW.REFRESH (
    mv_name                IN    VARCHAR(65535)
    [, method              IN    VARCHAR(65535) DEFAULT NULL]
    [, refresh_parallel    IN    INT DEFAULT 0]
    [, nested              IN    BOOLEAN DEFAULT FALSE]
    [, nested_refresh_mode IN    VARCHAR DEFAULT NULL]
    [, async               IN    BOOLEAN DEFAULT FALSE]
);
```

## パラメータの説明

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>ネストされていないマテリアライズドビューにはカスケードリフレッシュの動作が存在しないため、<code>nested</code>および<code>nested_refresh_mode</code>パラメータを指定しても意味がありません。デフォルトでは独立リフレッシュされます。</p>
</main>

|       **パラメータ**      |       **説明**        |
|---------------------|-----------------------|
| mv_name             | リフレッシュするマテリアライズドビューの名前。|
| method              | マテリアライズドビューのリフレッシュポリシーを定義します。マテリアライズドビュー作成時にデフォルトのポリシーを指定できます。選択可能な方法は以下のとおりです：<ul><li>`F`または`f`：高速リフレッシュ。</li><li>`?`：強制リフレッシュ。</li><li>`C`または`c`：フル更新。</li><li>`A`または`a`：常にリフレッシュ。`C`と同じです。</li></ul>|
| refresh_parallel    | リフレッシュ操作の並列度、つまり同時に実行されるリフレッシュ操作のスレッド数。|
| nested              | ネストされたマテリアライズドビューのリフレッシュモードを指定します。取り得る値は以下のとおりです：<ul><li>`FALSE`：デフォルト値で、ネストされたマテリアライズドビューを独立してリフレッシュします。</li><li>`TRUE`：ネストされたマテリアライズドビューをカスケードリフレッシュします。</li></ul>|
| nested_refresh_mode | ネストされたマテリアライズドビューのカスケードリフレッシュを一貫性のあるリフレッシュとするか、一貫性のないリフレッシュとするかを指定します。取り得る値は以下のとおりです：<ul><li>パラメータ`nested`を`FALSE`に指定した場合、パラメータ`nested_refresh_mode`を指定するとエラーが発生します。</li><li>パラメータ`nested`を`TRUE`に指定した場合：<ul><li>パラメータ`nested_refresh_mode`の取り得る値は以下のとおりです：<ul><li>`inconsistent`：カスケード非一貫性リフレッシュを示します。</li><li>`consistent`：カスケード一貫性リフレッシュを示します。</li></ul> </li><li>パラメータ`nested_refresh_mode`を指定しない場合、デフォルトでカスケード非一貫性リフレッシュとなります。</li></ul> </li></ul>|
| async               | 非同期リフレッシュを行うかどうかを指定します。取り得る値は以下のとおりです：<ul><li>`FALSE`：デフォルト値で、リフレッシュタスク完了後に戻ります。</li><li>`TRUE`：`REFRESH`を呼び出した後、バックグラウンドでリフレッシュタスクを作成し、すぐに戻ります。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このパラメータはV4.4.2 BP2バージョンから導入されました。</p></main>|

## 例

* 独立リフレッシュモード：

  * パラメータ`mv_name`のみを指定します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH('mv1');
    ```

  * パラメータ `mv_name` を指定し、`nested` を `false` に設定します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false);
    ```

* カスケード非一貫性リフレッシュモード：

  * パラメータ `mv_name` を指定し、パラメータ `nested` の値を `true` に設定しますが、パラメータ `nested_refresh_mode` を指定しません。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true);
    ```

  * パラメータ `mv_name` を指定し、パラメータ `nested` の値を `true` に設定するとともに、パラメータ `nested_refresh_mode` の値を `inconsistent` に設定します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'inconsistent');
    ```

* カスケード一貫性リフレッシュモード：

  パラメータ `mv_name` を指定し、パラメータ `nested` の値を `true` に設定するとともに、パラメータ `nested_refresh_mode` の値を `consistent` に設定します。

  ```shell
  obclient> CALL DBMS_MVIEW.REFRESH(
      'mv1',
      nested=> true,
      nested_refresh_mode => 'consistent');
  ```

* 以下はエラーが発生するシナリオです：

  * パラメータ `nested` の値を `false` に設定し、かつパラメータ `nested_refresh_mode` の値を指定した場合、エラーが発生します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false,
        nested_refresh_mode => 'xxxx');
    ```

  * パラメータ `nested` の値を指定せず、パラメータ `nested_refresh_mode` のみの値を指定した場合、エラーが発生します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested_refresh_mode => 'xxxx');
    ```

  * パラメータ `nested` の値を `true` に設定し、パラメータ `nested_refresh_mode` の値を無効な文字列に設定した場合、エラーが発生します。

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => '無効な文字列');
    ```
