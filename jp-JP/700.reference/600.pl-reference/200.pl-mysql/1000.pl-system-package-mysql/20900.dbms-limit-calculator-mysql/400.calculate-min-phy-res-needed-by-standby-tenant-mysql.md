# CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT

`CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT`は、プライマリテナントを指定し、作成するスタンバイテナントのユニット数を入力することで、各ユニットに必要な最小物理リソースを計算します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
</main>

## 構文

```sql
DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT(primary_tenant_id           IN  INTEGER,
                                                                        standby_tenant_unit_num     IN  INTEGER);
```

## パラメータ説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|primary_tenant_id|プライマリテナントのテナントIDを指定します。|
|standby_tenant_unit_num|スタンバイテナントのユニット数を指定します。|

## 例

プライマリテナントとスタンバイテナントの予想ユニット数を指定し、以下のコマンドを使用して各ユニットに必要な物理リソース量を計算できます。

```shell
obclient> CALL DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT(PRIMARY_TENANT_ID => 1001, STANDBY_TENANT_UNIT_NUM => 2);
```
