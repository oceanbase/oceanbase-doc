# CALCULATE_MIN PHY RES NEEDED BY LOGIC RES

`CALCULATE_MIN PHY RES NEEDED BY LOGIC RES`は、テナントの論理リソースタイプと必要な数を指定することで、これらの論理リソースを収容するために必要な物理リソース量を計算できます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES(args IN VARCHAR);
```

## パラメータの説明

ここで、argsは以下の形式の文字列です：

```sql
'ls: 1, tablet: 20000';
'ls: 10';
'tablet: 20000'
```

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|ls|論理リソースlsが必要とする数を指定します。|
|tablet|論理リソースtabletが必要とする数を指定します。|

## 例

以下の方法で必要な物理リソース量を計算できます。

```shell
obclient> CALL DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES("LS: 15, TABLET:40000");
+------------------------+-------------+
| PHYSICAL_RESOURCE_NAME | MIN_VALUE   |

| MEMSTORE               |           0 |
| MEMORY                 |  4194304000 |
| DATA_DISK              |           0 |
| CLOG_DISK              | 10737418240 |
| CPU                    |           0 |
+------------------------+-------------+
5 rows in set (0.003 sec)
```
