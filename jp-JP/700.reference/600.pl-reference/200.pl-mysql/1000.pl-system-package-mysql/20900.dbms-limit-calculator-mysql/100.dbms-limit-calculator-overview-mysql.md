# DBMS_OB_LIMIT_CALCULATORの概要

`DBMS_OB_LIMIT_CALCULATOR` システムパッケージは、クラスタの現在のリソース使用状況を取得し、これらの情報に基づいてスケーリング、ノードの置換、スタンバイテナントの作成などの操作を計画するために使用されます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>このシステムパッケージはSYSテナントでのみ使用できます。</p>
</main>

## DBMS_OB_LIMIT_CALCULATORサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_OB_LIMIT_CALCULATOR` サブプログラムとその簡潔な説明を示しています。

| サブプログラム                   | 説明                  |
| ----------------------- | --------------------- |
|[CALCULATE_MINPHY_RES_NEEDED_BY_UNIT](200.calculate-min-phy-res-needed-by-unit-mysql.md)|テナントおよびノードを指定し、特定のノードで必要な最小物理リソースを計算できます。|
|[CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES](300.calculate-min-phy-res-needed-by-loglc-res-mysql.md)|テナントの論理リソースタイプと必要数を指定し、それらの論理リソースを収容するために必要な物理リソース量を計算できます。|
|[CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT](400.calculate-min-phy-res-needed-by-standby-tenant-mysql.md)|プライマリテナントを指定し、作成するスタンバイテナントのユニット数を入力することで、各ユニットに必要な物理リソース量を計算できます。|
