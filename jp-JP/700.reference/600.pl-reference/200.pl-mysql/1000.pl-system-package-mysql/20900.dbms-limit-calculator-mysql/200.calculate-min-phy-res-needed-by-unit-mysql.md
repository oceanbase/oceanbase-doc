# CALCULATE_MINPHY_RES_NEEDED_BY_UNIT

`CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT`は、テナントおよびノードを指定し、特定のノードで必要な最小物理リソースを計算するために使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT(tenant_id     IN INTEGER,
                                                              server        IN VARCHAR);
```

## パラメータの説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
|tenant_id|計算対象のテナントIDを指定します。|
|server|サーバーのIPアドレスとポートを指定します。|

## 例

以下のコマンドを使用して、各ユニットに必要な最小物理リソースを計算できます。

```shell
obclient> CALL DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT(TENANT_ID => 1001, SERVER => "1.1.1.1:12104");
```
