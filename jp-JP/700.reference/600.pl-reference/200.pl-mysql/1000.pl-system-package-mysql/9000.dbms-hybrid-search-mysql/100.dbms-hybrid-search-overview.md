# DBMS_HYBRID_SEARCHの概要

`DBMS_HYBRID_SEARCH` システムパッケージは、ハイブリッドベクトルインデックスを管理するために使用されます。

## DBMS_HYBRID_SEARCHサブ関数の概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_HYBRID_SEARCH` サブ関数とその簡潔な説明を示しています。

| **サブ関数** | **説明** |
| --- | --- |
| [SEARCH](200.search-mysql.md) | 検索結果をJSON形式で返します。返される結果は関連性に基づいてソートされます。 |
| [GET_SQL](300.get_sql-mysql.md) | 実際に実行されたSQLを文字列形式で返します。 |
