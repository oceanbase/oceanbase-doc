# MODIFY_SNAPSHOT_SETTINGS

`MODIFY_SNAPSHOT_SETTINGS` プロシージャは、WORKLOAD_REPOSITORY設定を変更するために使用します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>このシステムパッケージは、sysテナントでの実行のみをサポートします。</p>
  </main>

## 構文

```sql
DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS(
   retention          INT    DEFAULT  NULL,
   interval           INT    DEFAULT  NULL,
   topnsql            INT    DEFAULT  NULL,
   sqlstat_interval   INT    DEFAULT  NULL
   );
```

## パラメータ説明

| **パラメータ** | **説明** |
| --- | --- |
| retention | スナップショットの保持時間です。この時間を超えるとスナップショットは自動的に削除されます。単位は分です。[1440分（1日）、52560000分（100年）]の範囲です。<ul><li>値を0に指定した場合、永続的に保持され、保持時間は57816000分（110年）に設定されます。  </li><li>NULLを指定した場合、元の保持時間が維持されます。 </li></ul>|
| interval | 各スナップショット間の間隔設定です。単位は分です。[10分、525600分（1年）]の範囲です。<ul><li>値を0に指定した場合、自動および手動スナップショットが無効になり、保持時間としてより大きなシステム定義値（110年）が使用されます。</li><li>NULLを指定した場合、現在の間隔設定が維持されます。</li></ul>|
| topnsql | WRストレージ化時に記録するSQLSTATデータの数。 |
| sqlstat_interval|  SQLSTATスナップショットのストレージ化時間間隔です。単位は分です。|

## 例

各スナップショットの保持時間を2265分（約1日12時間）、各スナップショット間の間隔を16分に設定し、ストレージ化時に30件のSQLSTATデータを記録するようにします。また、SQLSTATスナップショットのストレージ化時間間隔を5分に設定します。

```shell
obclient(root@sys)[(none)]> CALL DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS('2265','16', 30, 5);
```
