# DROPPYTHON

`DBMS_PYTHON.DROPPYTHON`は、Python外部リソースを削除するために使用します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、OceanBaseデータベースV4.4.1バージョンから導入されました。</p>
</main>

## 構文

```sql
DBMS_PYTHON.DROPPYTHON(IN py_name VARCHAR(65535));
```

`py_name`は、アップロード時の`loadpython`の`python_name`です。

## 例

以下のコマンドを実行して、アップロードしたPython外部リソースを削除します：

```shell
obclient> CALL DBMS_PYTHON.DROPPYTHON('my_add_python');
```
