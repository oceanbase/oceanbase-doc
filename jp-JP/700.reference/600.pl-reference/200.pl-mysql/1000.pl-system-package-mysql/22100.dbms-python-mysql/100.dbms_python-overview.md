# DBMS_PYTHONの概要

`DBMS_PYTHON`は、データベース内でPythonプログラムを統合および管理するために使用され、Pythonストアドプロシージャ、関数、およびセキュリティポリシーの実装をサポートします。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、OceanBaseデータベースV4.4.1バージョンから導入されました。</p>
</main>

## DBMS_PYTHONサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_PYTHON`サブプログラムとその簡単な説明を示しています。

|                **サブプログラム**             |                 **説明**                       |
|-----------------------------------------|------------------------------------------------|
|[DROPPYTHON](200.dbms_python_droppython-mysql.md)|Python外部リソースを作成するために使用されます。|
|[LOADPYTHON](300.dbms_python_loadpython-mysql.md)|Python外部リソースを削除するために使用されます。|
