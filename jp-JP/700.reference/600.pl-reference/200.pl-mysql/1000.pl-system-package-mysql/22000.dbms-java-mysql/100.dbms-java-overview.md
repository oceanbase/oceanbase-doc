# DBMS_JAVAの概要

`DBMS_JAVA`は、データベース内でJavaプログラムを統合および管理するために使用され、Javaストアドプロシージャ、関数、およびセキュリティポリシーの実装をサポートします。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、OceanBaseデータベースV4.4.0バージョンから導入されました。</p>
</main>

## DBMS_JAVA権限の説明

Java UDFへのアクセスを禁止します。`DBMS_JAVA`パッケージは現在、ファイルやネットワークへのアクセスをサポートしていません。

## DBMS_JAVAサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_JAVA`サブプログラムとその簡単な説明を示しています。

|                **サブプログラム**             |                 **説明**                       |
|-----------------------------------------|------------------------------------------------|
| [LOADJAVA](200.loadjava-mysql.md) | Jarパッケージを外部リソースとしてOBServerにアップロードするために使用されます。 |
| [DROPJAVA](300.dropjava-mysql.md) | アップロードされた外部リソースJarパッケージを削除するために使用されます。|
