# DROPJAVA

`DBMS_JAVA.DROPJAVA`は、アップロードされた外部リソースのJARパッケージを削除するために使用します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このシステムパッケージは、OceanBaseデータベースV4.4.0で導入されました。</p>
</main>

## 構文

```sql
DBMS_JAVA.DROPJAVA(IN jar_name VARCHAR(65535));
```

`jar_name`は、アップロード時の`loadjava`の`jar_name`です。

## 例

以下のコマンドを実行して、アップロードされた外部リソースのJARパッケージを削除します：

```shell
obclient> CALL DBMS_JAVA.DROPJAVA('my_add_jar');
```
