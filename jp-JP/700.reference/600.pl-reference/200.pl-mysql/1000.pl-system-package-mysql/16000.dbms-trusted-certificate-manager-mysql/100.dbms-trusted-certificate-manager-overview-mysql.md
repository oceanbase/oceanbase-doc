# DBMS_TRUSTED_CERTIFICATE_MANAGERの概要

`DBMS_TRUSTED_CERTIFICATE_MANAGER` システムパッケージは、OBserverクラスタが信頼するCAルート証明書を追加、削除、変更するために使用され、RPCセキュリティ認証に利用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 権限の説明

システムパッケージを呼び出すには、呼び出し元がsysテナントである必要があります。

## DBMS_TRUSTED_CERTIFICATE_MANAGERサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_TRUSTED_CERTIFICATE_MANAGER` サブプログラムとその簡単な説明です。

| サブプログラム     | 説明                                      |
| --------- | ----------------------------------------- |
| [ADD_TRUSTED_CERTIFICATE](200.add-trusted-certificate-mysql.md) | CAルート証明書を追加します。これにより、当該証明書で署名されたデジタル証明書を使用するOBserverクラスタやOMSなどのコンポーネントが、RPC認証を経てクラスタに安全に接続できるようになります。 |
| [DELETE_TRUSTED_CERTIFICATE](300.delete-trusted-certificat-mysql.md) | CAルート証明書を削除します。これにより、当該証明書で署名されたデジタル証明書を使用するOBserverクラスタやOMSなどのコンポーネントが、クラスタに接続できなくなります。 |
| [UPDATE_TRUSTED_CERTIFICATE](400.update-trusted-certificat-mysql.md)	| OBserverクラスタが信頼するCAルート証明書情報を更新します。           |
