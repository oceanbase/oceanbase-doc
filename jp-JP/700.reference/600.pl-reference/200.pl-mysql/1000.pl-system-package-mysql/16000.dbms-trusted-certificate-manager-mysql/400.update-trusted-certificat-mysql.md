# UPDATE_TRUSTED_CERTIFICATE

`UPDATE_TRUSTED_CERTIFICATE`は、OBserverクラスタが信頼するCAルート証書情報を更新します。

<main id="notice" >
    <h4>適用対象</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
  </main>

## 構文

```sql
PROCEDURE UPDATE_TRUSTED_CERTIFICATE(
  common_name VARCHAR(256),
  description VARCHAR(256),
  content     LONGTEXT);
```

## パラメータの説明

| **パラメータ**     | **説明**                                  |
|------------|----------------------------------------|
| common_name | 証書の一意の識別子であり、異なる証書を区別するために使用されます。       |
| description | 証書の用途または関連するクラスタ情報を説明します。          |
| content     | 証書の詳細情報です。    |
