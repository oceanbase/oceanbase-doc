# DELETE_TRUSTED_CERTIFICATE

`DELETE_TRUSTED_CERTIFICATE`は、CAルート証明書を削除するために使用されます。これにより、その証明書で署名されたデジタル証明書を使用しているOBServerクラスタやOMSなどのコンポーネントは、クラスタへの接続を継続できなくなります。

<main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版は現在サポートされていません。</p>
  </main>

## 構文

```sql
PROCEDURE DELETE_TRUSTED_CERTIFICATE(common_name VARCHAR(256));
```

## パラメータの説明

| **パラメータ**     | **説明**                                  |
|------------|----------------------------------------|
| common_name | 証明書の一意の識別子であり、異なる証明書を区別するために使用されます。       |

## 例

```shell
obclient>CALL DBMS_TRUSTED_CERTIFICATE_MANAGER.DELETE_TRUSTED_CERTIFICATE('MySQL_Server_5.7.2_Auto_Geanrateed_C_Certificate');
Query OK, 0 rows affected
```
