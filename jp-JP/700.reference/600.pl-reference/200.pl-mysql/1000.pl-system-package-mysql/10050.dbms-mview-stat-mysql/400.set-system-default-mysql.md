# SET_SYSTEM_DEFAULT

`SET_SYSTEM_DEFAULT`は、統計パラメータのリフレッシュに関するシステムのデフォルト値を設定します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供しています。</p>
</main>

## 構文

```sql
PROCEDURE set_system_default(
    IN     parameter_name         VARCHAR(65535),
    IN     value                  VARCHAR(65535));
```

## パラメータ説明

| **パラメータ**         | **説明**                                                                                         |
|------------------|--------------------------------------------------------------------------------------------------|
| parameter_name   | パラメータ名。以下の2種類に設定できます：<ul><li>COLLECTION_LEVEL：統計情報収集レベル。システムデフォルトはTYPICALです。</ul></li><ul><li>RETENTION_PERIOD：統計情報の保持日数。システムデフォルトは31日です。</ul></li> |
| value | <p>parameter_nameがCOLLECTION_LEVELの場合：<ul><li>NONE：統計情報を収集しません。</ul></li><ul><li>TYPICAL：基本的な更新統計情報を収集します。</ul></li><ul><li>ADVANCED：詳細な更新統計情報を収集します。</ul></li><ul><li>NULL：システムのデフォルト値、すなわちTYPICALを使用します。</li></ul></p> <p>parameter_nameがRETENTION_PERIODの場合、パラメータ値は統計情報の保持日数です：1～365000。<ul><li>NULL：システムのデフォルト値を使用します。</ul></li><ul><li>-1：統計情報を永久に保持します。</ul></li></br> </p>|
