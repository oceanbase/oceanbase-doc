# SET_MVREF_STATS_PARAMS

`SET_MVREF_STATS_PARAMS`は、マテリアライズドビューのリフレッシュ統計情報の収集レベルとデータ保持期間を設定するプロシージャです。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise版にのみ適用されます。OceanBaseデータベースCommunity版はMySQLモードのみを提供します。</p>
</main>

## 使用上の制限と注意事項

V4.4.2バージョンでは、V4.4.2 BP2バージョン以降、`retention_period`パラメータは無効になります。

## 構文

```sql
PROCEDURE set_mvref_stats_params(
    IN     mv_name                VARCHAR(65535),
    IN     collection_level       VARCHAR(65535)     DEFAULT NULL,
    IN     retention_period       INT                DEFAULT NULL);
```

## パラメータの説明

| **パラメータ**           | **説明**                                                                                                                                          |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| mv_name         | マテリアライズドビュー名。<ul><li>NULLの場合、すべてのマテリアライズドビューに対して操作を実行します。</li></ul>                                              |
| collection_level | 統計情報の収集レベルです。システムのデフォルトレベルはTYPICALです。オプションは以下のとおりです：<ul><li>NONE：統計情報を収集しません。</li></ul><ul><li>TYPICAL：基本的なリフレッシュ統計情報を収集します。</li></ul><ul><li>ADVANCED：詳細なリフレッシュ統計情報を収集します。</li></ul><ul><li>NULL：システムのデフォルト値、つまりTYPICALを使用します。</li></ul> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定日数を超えると統計レコードは自動的に削除されます。システムのデフォルトは31日です。<ul><li>NULLの場合、システムのデフォルト設定が適用されます。</li></ul><ul><li>-1に設定した場合、統計情報は永久に保持されます。</li></ul>                               |
