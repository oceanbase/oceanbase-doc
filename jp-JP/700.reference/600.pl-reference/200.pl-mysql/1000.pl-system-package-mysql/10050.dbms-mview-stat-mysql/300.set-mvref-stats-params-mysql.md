# SET_MVREF_STATS_PARAMS

`SET_MVREF_STATS_PARAMS`は、マテリアライズドビューのリフレッシュ統計情報の収集レベルとデータ保持期間を設定するためのパラメータです。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみ提供されます。</p>
</main>

## 構文

```sql
PROCEDURE set_mvref_stats_params(
    IN     mv_name                VARCHAR(65535),
    IN     collection_level       VARCHAR(65535)     DEFAULT NULL,
    IN     retention_period       INT                DEFAULT NULL);
```

## パラメータ説明

| **パラメータ**           | **説明**                                                                                                                                          |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| mv_name         | マテリアライズドビューの名前。<ul><li>NULLの場合、すべてのマテリアライズドビューに対して操作を実行します。 </ ul></li>                                              |
| collection_level | 統計情報の収集レベルです。システムのデフォルトはTYPICALです。オプションは以下のとおりです：<ul><li>NONE：統計情報を収集しません。</ul></li><ul><li>TYPICAL：基本的な更新統計情報を収集します。</ul></li><ul><li>ADVANCED：詳細な更新統計情報を収集します。</ul></li><ul><li>NULL：システムのデフォルト値、つまりTYPICALを使用します。</ul></li> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定された日数を超えると統計レコードは自動的に削除されます。システムのデフォルトは31日です。<ul><li>NULLの場合、システムのデフォルト設定が適用されます。</ul></li><ul><li>-1に設定した場合、統計情報は永続的に保持されます。</ul></li>                               |
