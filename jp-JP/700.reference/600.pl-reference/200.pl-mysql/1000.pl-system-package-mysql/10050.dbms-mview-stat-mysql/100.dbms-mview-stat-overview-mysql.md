# DBMS_MVIEW_STATSの概要

`DBMS_MVIEW_STATS` システムパッケージは、マテリアライズドビューのリフレッシュ操作に関する統計情報の収集と保持を管理するためのインターフェースをユーザーに提供します。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## DBMS_MVIEW_STATSサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_MVIEW_STATS` サブプログラムとその簡単な説明を示しています。

| サブプログラム                   | 説明                  |
| ----------------------- | --------------------- |
| [PURGE_REFRESH_STATS](200.purge-refresh-stats-mysql.md) |指定された保持期間を超えたマテリアライズドビューのリフレッシュ統計データを強制的に自動削除するために使用されます。   |
| [SET_MVREF_STATS_PARAMS](300.set-mvref-stats-params-mysql.md) |マテリアライズドビューのリフレッシュ統計情報の収集レベルとデータ保持期間のパラメータを設定します。|
| [SET_SYSTEM_DEFAULT](400.set-system-default-mysql.md)  |リフレッシュ統計パラメータのシステムデフォルト値を設定します。|
