# PURGE_REFRESH_STATS

`PURGE_REFRESH_STATS`は、指定された保持期間を超えたマテリアライズドビューの更新統計データを強制的に自動削除するために使用されます。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
</main>

## 構文

```sql
PROCEDURE purge_refresh_stats(
    IN     mv_name                VARCHAR(65535),
    IN     retention_period       INT);
```

## パラメータの説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
| mv_name          | マテリアライズドビュー名。<ul><li>値がNULLの場合、すべてのマテリアライズドビューに対して操作を実行します。</ul></li> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定された日数を超えると統計レコードは自動的に削除され、システムのデフォルトは31日です。<ul><li>値がNULLの場合、自動統計情報クリーンアップメカニズムのデフォルトのクリーンアップポリシーが採用されます。</ul></li><ul><li>-1に設定した場合、すべての関連統計情報レコードを削除します。</ul></li> |
