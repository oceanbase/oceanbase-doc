# DBMS_DATA_DICT

`DBMS_DATA_DICT`はデータディクショナリのスケジューリングを制御します。

## 構文

### データディクショナリのスケジューリングを禁止する

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>実行時にディクショナリ構成パラメータ <a href="../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2300.dump_data_dictionary_to_log_interval.md">dump_data_dictionary_to_log_interval</a> が <code>0</code> 以外の場合、実行は失敗し、ユーザーに対してこのパラメータを <code>0</code> に設定するよう促されます。</p>
</main>

### データディクショナリのスケジューリングを許可する

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
```

### ディクショナリの生成を手動でトリガーする

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(DICT_ITEM_RETENTION_BY_DAY);
```

### ディクショナリの定期DUMP周期を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL(INTERVAL_EXPR);
```

ディクショナリの生成をスケジュールするシナリオ：

* テナント作成後、即座に自動的にデータディクショナリの生成がトリガーされます。

* アーカイブが有効な場合、即座に自動的にデータディクショナリの生成がトリガーされます。

<main id="notice" >
  <h4>注意</h4>
  <p>実行時にはディクショナリDUMPサービスが有効である必要があります（つまり、まず <code>ALL DBMS_DATA_DICT.ENABLE_DUMP()</code> を実行する必要があります）。そうでない場合、実行は失敗します。</p>
</main>

### ディクショナリ履歴レコードの回収間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(DICT_ITEM_RETENTION_BY_DAY)
```

## パラメータの説明

| **パラメータ**           | **説明**                       |**データ型**   |
|------------------|---------------------------------|-------|
|DICT_ITEM_RETENTION_BY_DAY|<ul>DUMPの実行時にデータディクショナリを生成した後、履歴DUMPレコードを回収するかどうかを指定します。<li>パラメータを指定する場合、値は`0`以上である必要があります。</li><li>パラメータを指定しない場合、またはパラメータが`0`の場合、このDUMPではデータディクショナリを回収しません。</li></ul>| INT |
|INTERVAL_expr|期待されるスケジューリング間隔を表します。このパラメータは`DBMS_SCHEDULER`の`REPEAT_INTERVAL`の書式に従い、シングルクォートで囲む必要があります。例：`'FREQ=MINUTELY; INTERVAL=120'`。ここで：<ul><li>`FREQ`は`SECONDLY`/`DAILY`/`HOURLY`/`WEEKLY`/`YEARLY`から選択できます。</li><li>`INTERVAL`は実行間隔で、希望する実行間隔の数値を入力します。</li></ul>これらを組み合わせたものが`INTERVAL_expr`となります。 | TEXT |
|DICT_ITEM_RETENTION_BY_DAY|データディクショナリの履歴レコードを回収する期待日数を表します。<br/>パラメータを指定して`DBMS_DATA_DICT.TRIGGER_DUMP`を呼び出す場合と比較して、このストアドプロシージャを実行すると、以降のデータディクショナリDUMPは、この指定時間に従って履歴レコードを回収するようになります（手動でパラメータを指定した`DBMS_DATA_DICT.TRIGGER_DUMP`ストアドプロシージャを実行しない限り）。| INT |

## 例

### データディクショナリのスケジューリングを禁止する

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
Query OK, 0 rows affected
```

### データディクショナリのスケジューリングを許可する

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
Query OK, 0 rows affected
```

### データディクショナリの生成を手動でトリガーする

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(7);
Query OK, 0 rows affected
```

### データディクショナリの定期DUMP間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL('FREQ=MINUTELY; INTERVAL=120');
Query OK, 0 rows affected
```

### データディクショナリ履歴レコードの回収間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(7);
Query OK, 0 rows affected
```
