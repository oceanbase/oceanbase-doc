# DBMS_DATA_DICT

`DBMS_DATA_DICT`はデータディクショナリのスケジューリングを制御します。

## 構文

### データディクショナリのスケジューリングを禁止する

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>実行時のディクショナリ構成パラメータ <a href="../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2300.dump_data_dictionary_to_log_interval.md">dump_data_dictionary_to_log_interval</a> が <code>0</code> 以外の場合、実行は失敗し、ユーザーに対してこの構成パラメータを <code>0</code> に設定するよう促されます。</p>
</main>

### データディクショナリのスケジューリングを許可する

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
```

### ディクショナリの生成を手動でトリガーする

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(DICT_ITEM_RETENTION_BY_DAY);
```

### ディクショナリの定期DUMP間隔の調整

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL(INTERVAL_EXPR);
```

ディクショナリのスケジュール生成がトリガーされるシナリオ：

* テナント作成後、即座に自動的にデータディクショナリの生成がトリガーされます。

* アーカイブが有効な場合、即座に自動的にデータディクショナリの生成がトリガーされます。

<main id="notice" >
  <h4>注意</h4>
  <p>実行時にはディクショナリDUMPサービスが有効状態である必要があります（つまり、まず <code>ALL DBMS_DATA_DICT.ENABLE_DUMP()</code> を実行すること）。そうでない場合、実行は失敗します。</p>
</main>

### ディクショナリ履歴レコードの回収間隔の調整

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(DICT_ITEM_RETENTION_BY_DAY)
```

## パラメータの説明

| **パラメータ**           | **説明**                       |**データ型**   |
|------------------|---------------------------------|-------|
|DICT_ITEM_RETENTION_BY_DAY|<ul>DICT Item Retention By Dayトリガーが実行され、辞書が生成された後、履歴のDUMPレコードを回収するかどうかを指定します。<li>パラメータを指定する場合、値は`0`以上である必要があります。</li><li>パラメータを指定しない場合、またはパラメータが`0`の場合、このDUMPでは辞書を回収しません。</li></ul>| INT |
|INTERVAL_expr|期待されるスケジューリング間隔を表します。このパラメータは`DBMS_SCHEDULER`の`REPEAT_INTERVAL`の記述形式に従い、シングルクォートで囲む必要があります。例：`'FREQ=MINUTELY; INTERVAL=120'`。ここで：<ul><li>`FREQ`は`SECONDLY`/`DAILY`/`HOURLY`/`WEEKLY`/`YEARLY`から選択できます。</li><li>`INTERVAL`は実行間隔で、希望する実行間隔の対応する数値を入力します。</li></ul>これら2つを組み合わせたものが`INTERVAL_expr`となります。 | TEXT |
|DICT_ITEM_RETENTION_BY_DAY|期待される辞書履歴レコードの回収日時を日単位で表します。<br/>`DBMS_DATA_DICT.TRIGGER_DUMP`でパラメータを指定して呼び出す場合と比較して、このストアドプロシージャを実行すると、その後のすべての辞書DUMPは、デフォルトで今回指定した時間に従って辞書履歴レコードを回収します（パラメータを指定した`DBMS_DATA_DICT.TRIGGER_DUMP`ストアドプロシージャを手動で実行する場合を除く）。| INT |

## 例

### データディクショナリのスケジューリングを禁止する

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
Query OK, 0 rows affected
```

### データディクショナリのスケジューリングを許可する

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
Query OK, 0 rows affected
```

### ディクショナリの生成を手動でトリガーする

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(7);
Query OK, 0 rows affected
```

### ディクショナリの定期DUMP間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL('FREQ=MINUTELY; INTERVAL=120');
Query OK, 0 rows affected
```

### ディクショナリ履歴レコードの回収間隔を調整する

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(7);
Query OK, 0 rows affected
```
