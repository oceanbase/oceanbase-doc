# DBMS_XPLANの概要

`DBMS_XPLAN`システムパッケージは、論理計画の最適化追跡などを含む論理計画管理関連の機能を提供します。

## DBMS_XPLAN権限の説明

PL/SQL実行権限を持つユーザーはこの機能を使用できます。

## DBMS_XPLANサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_XPLAN`サブプログラムとその簡潔な説明です。

| サブプログラム | 説明 |
| --- | --- |
| [DISPLAY_ACTIVE_SESSION_PLAN](../20700.dbms-xplan-mysql/200.display-active-session-plan-of-mysql-mode.md)| 指定されたセッションのリアルタイム計画の詳細を表示するために使用されます。|
| [DISPLAY_CURSOR](../20700.dbms-xplan-mysql/300.display-cursor-of-mysql-mode.md) | 実行済みのクエリ計画の詳細を表示するために使用されます。 |
| [DISPLAY](../20700.dbms-xplan-mysql/400.display-of-mysql-mode.md) | 過去の`EXPLAIN`計画を照会し、フォーマットします。 |
| [DISABLE_OPT_TRACE](../20700.dbms-xplan-mysql/500.disable-opt-trace-mysql.md) | 現在のセッションのオプティマイザー全リンク追跡機能を無効にします。 |
| [DISPLAY_SQL_PLAN_BASELINE](../20700.dbms-xplan-mysql/600.display-sql-plan-baseline-of-mysql-mode.md) | SPMのベースライン計画を確認します。 |
| [ENABLE_OPT_TRACE](../20700.dbms-xplan-mysql/800.enable-opt-trace-mysql.md) | 現在のセッションのオプティマイザー全リンク追跡を有効にします。 |
| [SET_OPT_TRACE_PARAMETER](../20700.dbms-xplan-mysql/1000.set-opt-trace-parameter-mysql.md) | 現在のセッションのオプティマイザー全リンク追跡のパラメータを変更します。 |
