# DBMS_XPLANの概要

`DBMS_XPLAN` システムパッケージは、ロジックプランの最適化や追跡など、ロジックプラン管理に関する機能を提供します。

## DBMS_XPLAN権限の説明

PL/SQLを実行する権限を持つユーザーはこの機能を使用できます。

## DBMS_XPLANサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_XPLAN` サブプログラムとその簡単な説明を示しています。

| サブプログラム | 説明 |
| --- | --- |
| [DISPLAY_ACTIVE_SESSION_PLAN](../20700.dbms-xplan-mysql/200.display-active-session-plan-of-mysql-mode.md)| 指定されたセッションのリアルタイム実行計画の詳細を表示します。|
| [DISPLAY_CURSOR](../20700.dbms-xplan-mysql/300.display-cursor-of-mysql-mode.md) | 実行済みのクエリ計画の詳細を表示します。 |
| [DISPLAY](../20700.dbms-xplan-mysql/400.display-of-mysql-mode.md) | 過去の `EXPLAIN` プランを照会してフォーマットします。 |
| [DISABLE_OPT_TRACE](../20700.dbms-xplan-mysql/500.disable-opt-trace-mysql.md) | 現在のセッションのオプティマイザー全リンクトレース機能を無効にします。 |
| [DISPLAY_SQL_PLAN_BASELINE](../20700.dbms-xplan-mysql/600.display-sql-plan-baseline-of-mysql-mode.md) | SPMのベースライン計画を確認します。 |
| [ENABLE_OPT_TRACE](../20700.dbms-xplan-mysql/800.enable-opt-trace-mysql.md) | 現在のセッションのオプティマイザー全リンクトレースを有効にします。 |
| [SET_OPT_TRACE_PARAMETER](../20700.dbms-xplan-mysql/1000.set-opt-trace-parameter-mysql.md) | 現在のセッションのオプティマイザー全リンクトレースのパラメータを変更します。 |
