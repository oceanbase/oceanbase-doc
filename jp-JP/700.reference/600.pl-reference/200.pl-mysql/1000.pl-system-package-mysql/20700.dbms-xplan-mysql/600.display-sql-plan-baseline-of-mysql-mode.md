# DISPLAY_SQL_PLAN_BASELINE

`DISPLAY_SQL_PLAN_BASELINE` 関数は、SPMのベースライン計画を表示するために使用されます。

## 構文

```sql
DBMS_XPLAN.DISPLAY_SQL_PLAN_BASELINE(
           sql_handle   VARCHAR2  DEFAULT  NULL,
           plan_name    VARCHAR2  DEFAULT  NULL,
           format       VARCHAR2  DEFAULT  'TYPICAL',
           svr_ip       VARCHAR2 DEFAULT null,   -- default value: server connected by client
           svr_port     INTEGER DEFAULT 0,     -- default value: server connected by client
           tenant_id    INTEGER DEFAULT 0     -- default value: current tenant)
RETURN DBMS_XPLAN_TYPE_TABLE;
```

## パラメータ説明

| パラメータ | 説明 |
| --- | --- |
| sql_handle | Baseline計画のSQLハンドル。SPM関連ビューから取得できます。 |
| plan_name | Baseline計画の名前。 |
| format | 計画形式情報を指定します。オプションパラメータは以下のとおりです。<ul><li>`'BASIC'`：演算子ID、演算子名、演算子備考情報、式情報など、少量の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報などの基本情報を表示します。この計画が実行された場合は、実際のフィードバック情報（実行行数、コストなど）も表示されます。</li><li> `'ALL'`：演算子ID、演算子名、演算子備考情報、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なHint、Query Block Name Trace情報、アウトライン情報、ベーステーブル最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富な計画情報を表示します。</li><li> `'ADVANCED'`：豊富な計画情報を表示します。計画情報は'ALL'パラメータと同じですが、さらに複雑な計画についてはツリー構造情報も表示します。</li></ul>|
| svr_ip | 計画が存在するノードのIPアドレス。デフォルトはセッションが接続しているノードのIPアドレスです。|
| svr_port | 計画が存在するノードのポート番号。デフォルトはセッションが接続しているノードのポート番号です。|
| tenant_id | 計画が属するテナントID。デフォルトはセッションが現在接続しているテナントです。|
