# DISPLAY_ACTIVE_SESSION_PLAN

`DISPLAY_ACTIVE_SESSION_PLAN` 関数は、指定されたセッションのリアルタイム実行計画の詳細を表示するために使用されます。

## 関数定義

```sql
DBMS_XPLAN.DISPLAY_ACTIVE_SESSION_PLAN(
           session_id   INTEGER DEFAULT 0,
           format       VARCHAR2  DEFAULT  'TYPICAL',
           svr_ip       VARCHAR2  DEFAULT  NULL,      -- default value: server connected by client
           svr_port     INTEGER DEFAULT 0           -- default value: server connected by client
           )
return DISPLAY_ACTIVE_SESSION_PLAN;
```

## パラメータ説明

| パラメータ | 説明 |
| --- | --- |
| session_id | ユーザー接続のセッションIDです。プロキシセッションIDではなく、サーバー側のセッションIDです。 |
| format | 実行計画のフォーマット情報を指定します。オプションは以下のとおりです：<ul><li>`'BASIC'`：演算子ID、演算子名、演算子の備考、式情報など、必要最低限の情報を表示します。</li><li> `'TYPICAL'`：演算子ID、演算子名、演算子の備考、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報などの基本情報を表示します。この計画が実行されている場合は、実際のフィードバック情報（実行行数、コストなど）も初回実行時のものを表示します。</li><li> `'ALL'`：演算子ID、演算子名、演算子の備考、オプティマイザー推定の出力行数、オプティマイザー推定の実行時間、式情報、有効なヒント、Query Block Name Trace情報、アウトライン情報、ベーステーブルの最適化情報、定数パラメータ化情報、制約情報、Plan Noteなど、豊富な計画情報を表示します。</li><li> `'ADVANCED'`：'ALL'パラメータと同じ計画情報を表示します。さらに、複雑な計画についてはツリー構造情報も表示します。</li></ul> |
| svr_ip | 計画が存在するノードのIPアドレスです。デフォルトはセッションが接続しているノードのIPアドレスです。|
| svr_port | 計画が存在するノードのポート番号です。デフォルトはセッションが接続しているノードのポート番号です。|
