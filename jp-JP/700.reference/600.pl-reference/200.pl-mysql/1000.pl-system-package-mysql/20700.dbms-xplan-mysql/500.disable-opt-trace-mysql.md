# DISABLE_OPT_TRACE

`DISABLE_OPT_TRACE` プロシージャは、現在のセッションのオプティマイザー全リンクトレース機能を無効にするために使用されます。

## 構文

```sql
DBMS_XPLAN.DISABLE_OPT_TRACE;
```

## 例

現在のセッションのオプティマイザートレース機能を無効にします。

```shell
obclient> CALL DBMS_XPLAN.DISABLE_OPT_TRACE();
Query OK, 0 rows affected
```
