# DBMS_BALANCEの概要

`DBMS_BALANCE` システムパッケージは、パーティションの均衡に関するメソッドを提供します。

## DBMS_BALANCE権限の説明

PL/SQL実行権限を持つユーザーテナントはこの機能を使用できます。sysテナントが呼び出すと `OB_OP_NOT_ALLOW` エラーが発生します。

## DBMS_BALANCEサブプログラムの概要

次の表は、OceanBaseデータベースでサポートされている `DBMS_BALANCE` サブプログラムと対応する説明を示しています。

| サブプログラム | 説明 |
| --- | --- |
|[TRIGGER_PARTITION_BALANCE](200.trigger-partition-balance-mysql.md)|パーティションの自動バランスを手動でトリガーするために使用されます。|
|[SET_BALANCE_WEIGHT](150.set-balance-weight-mysql.md)              |パーティションの重みを手動で設定します。|
|[CLEAR_BALANCE_WEIGHT](160.clear-balance-weight-mysql.md)          |パーティションの重みを手動でクリアします。|
| [SET_TABLEGROUP_BALANCE_WEIGHT](300.set-tablegroup-balance-weight-of-mysql-mode.md) | `SHARDING NONE`タイプのテーブルグループのロードバランシングの重みを設定します。|
| [CLEAR_TABLEGROUP_BALANCE_WEIGHT](400.clear-tablegroup-balance-weight-of-mysql-mode.md) | `SHARDING NONE`タイプのテーブルグループのロードバランシングの重みを削除します。|
