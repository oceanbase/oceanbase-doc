# CLEAR_TABLEGROUP_BALANCE_WEIGHT

サブプログラム `CLEAR_TABLEGROUP_BALANCE_WEIGHT` は、`SHARDING NONE` タイプのテーブルグループの重みを削除するために使用されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このサブプログラムは、V4.4.1バージョンからサポートされています。</p>
</main>

## 構文

```sql
DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT(
    tablegroup_name       VARCHAR(65535)
    );
```

## パラメータ説明

| パラメータ | 説明 |
|------|------|
| tablegroup_name | テーブルグループ名。|

## 使用方法

`DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT` を使用して、指定した名前の `SHARDING NONE` テーブルグループの重みを削除します。

## 例

* sysテナント内で呼び出し、テナント `mysql` の下のテーブルグループ `TG_TD_test` の重みを削除します。

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test') TENANT = 'mysql';
    ```

* ユーザーテナント内で呼び出し、自身のテナントの下のテーブルグループ `TG_TD_test` の重みを削除します。

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test');
    ```
