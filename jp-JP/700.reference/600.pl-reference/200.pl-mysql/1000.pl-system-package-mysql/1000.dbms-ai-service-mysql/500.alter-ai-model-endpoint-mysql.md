# ALTER_AI_MODEL_ENDPOINT

`ALTER_AI_MODEL_ENDPOINT` プロシージャは、AIモデルオブジェクトのアクセスエンドポイントを変更するために使用されます。

## 構文

```sql
PROCEDURE alter_ai_model_endpoint(
    IN name VARCHAR(128),
    IN params JSON);
```

## 例

AIモデルオブジェクトのアクセスエンドポイントを変更します。

```sql
CALL DBMS_AI_SERVICE.ALTER_AI_MODEL_ENDPOINT (
  'my_model_endpoint1', '{
    "access_key" : "sk2-xxxxxxxxxxxx",
    "url": "https://api.deepseek.com/chat/completions"
  }');
```
