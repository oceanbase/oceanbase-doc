# DROP_AI_MODEL

`DROP_AI_MODEL` プロシージャは、AIモデルオブジェクトを削除するために使用されます。

## 構文

```sql
PROCEDURE drop_ai_model(
    IN name VARCHAR(128));
```

## パラメータ説明

| パラメータ | 説明 | 型 | 値の範囲 | NULL許容 |
|------|------|------|----------|----------|
| name | AIモデルオブジェクトの名前。 | VARCHAR(128) |  | No |

## 例

AIモデルオブジェクトを削除します。

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('my_ai_model_1');
```
