# CREATE_AI_MODEL

`CREATE_AI_MODEL` プロシージャは、AIモデルオブジェクトを作成するために使用され、モデルの名前、タイプなどの属性を指定する必要があります。

## 構文

```sql
PROCEDURE create_ai_model(
    IN name VARCHAR(128),
    IN params JSON);
```

## 例

AIモデルオブジェクトを作成します。タイプは `dense_embedding`、大規模言語モデルは `text-embedding-v2` です。

```sql
CALL DBMS_AI_SERVICE.CREATE_AI_MODEL (
'my_ai_model_1', '{
    "type": "dense_embedding",
    "model_name": "text-embedding-v2"
  }');
```
