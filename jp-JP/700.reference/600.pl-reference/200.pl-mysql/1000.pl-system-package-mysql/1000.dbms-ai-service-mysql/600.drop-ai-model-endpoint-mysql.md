# DROP_AI_MODEL_ENDPOINT

`DROP_AI_MODEL_ENDPOINT` プロシージャは、AIモデルオブジェクトのアクセスエンドポイントを削除するために使用されます。

## 構文

```sql
PROCEDURE drop_ai_model_endpoint(
    IN name VARCHAR(128));
```

## パラメータ説明

| パラメータ | 説明 | 型 | 値の範囲 | NULL許容 |
|------|------|------|----------|----------|
| name | AIモデルオブジェクトのアクセスエンドポイント名。 | VARCHAR(128) |  | No |

## 例

AIモデルオブジェクトのアクセスエンドポイントを削除します。

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL_ENDPOINT ('my_model_endpoint1');
```
