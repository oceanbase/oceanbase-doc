# DBMS_AI_SERVICEの概要

`DBMS_AI_SERVICE`システムパッケージは、AIサービスを管理するために使用されます。これには、AIモデルオブジェクトとAIモデルサービス接続ポイントオブジェクトが含まれます。

## DBMS.AI_SERVICEプロシージャの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている`DBMS_AI_SERVICE`プロシージャとその簡単な説明を示しています。

| **サブプログラム** | **説明** |
| --- | --- |
| [CREATE.AI_MODEL](200.create-ai-model-mysql.md) | AIモデルオブジェクトを作成します。 |
| [DROP_AI_MODEL](300.drop-ai-model-mysql.md) | AIモデルオブジェクトを削除します。 |
| [CREATE_AI_MODEL_ENDPOINT](400.create-ai-model-endpoint-mysql.md) | AIモデルサービスエンドポイントオブジェクトを作成します。 |
| [ALTER_AI_MODEL_ENDPOINT](500.alter-ai-model-endpoint-mysql.md) | AIモデルサービスエンドポイントオブジェクトを変更します。 |
| [DROP.AI_MODEL_ENDPOINT](600.drop-ai-model-endpoint-mysql.md) | AIモデルサービスエンドポイントオブジェクトを削除します。 |
