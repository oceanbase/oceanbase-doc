# DISPLAY_PROFILE

`DISPLAY_PROFILE`はSQL実行計画のパフォーマンス分析データを表示するために使用され、指定した`trace_id`に対応するSQL実行の診断情報を演算子単位で確認できます。

## 構文

```sql
DBMS_XPROFILE.DISPLAY_PROFILE(
    trace_id    varchar2 default null,
    tenant_id   integer default 0,
    format      varchar2 default 'AGGREGATED',
    level       integer default 1,
    svr_ip      varchar2 default null,
    svr_port    integer default 0,
    op_id       integer default null
    )
```

## パラメータ説明

| **パラメータ**  | **説明** |
|-----------|----------|
| trace_id  | オプションです。表示するプロファイルのトレースIDを指定します。省略するか、`null`または空文字列を指定すると、現在のセッションの直近のトレースIDが使用されます。|
| tenant_id | オプションです。テナントIDを指定します。省略または0を入力した場合、デフォルトでは現在のテナントIDが選択されます。システムテナント以外のユーザーテナントが他のテナントIDを指定した場合、空の結果が返されます。|
| format    | オプションです。表示形式を指定します。値は以下のとおりです：<ul><li>`AGGREGATED`：デフォルト値で、集約後のプロファイルを表示します。</li><li>`ORIGINAL`：集約前のスレッドレベルのプロファイルを出力します。</li></ul>|
| level     | オプションです。出力レベルを指定します。各指標にはそれぞれレベルがあり、指定した出力レベルを超える指標は表示されません。値は以下のとおりです：<ul><li>0：コア指標を表し、必ず出力されます。例えば、出力行数、dbtimeなどの情報です。</li><li>1：デフォルト値で、標準指標を表します。一般的に使用される指標はこのレベルに設定できます。</li><li>2：トラブルシューティング指標を表し、BUGの特定やさらなる分析に使用される指標です。あまり一般的ではなく、出力情報が多すぎます。</li></ul>|
| svr_ip    | オプションです。特定のIP上のプロファイルのみを表示するようフィルタリングします。デフォルト値は`null`で、全出力を意味します。|
| svr_port  | オプションです。特定のポート上のプロファイルのみを表示するようフィルタリングします。デフォルト値は0で、全出力を意味します。|
| op_id     | オプションです。計画内で指定したIDを持つ演算子のプロファイルのみを表示するようフィルタリングします。デフォルト値は`null`で、全出力を意味します。|

## 例

* sysテナント内で他のテナントのプロファイルを確認する。

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC30589818-0-0', tenant_id);
    ```

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>他のテナントのプロファイルを確認できるのはsysテナントのみです。<code>tenant_id</code>を指定する必要があります。</p>
    </main>

* ユーザーテナント(MySQLモード)が自身のプロファイルを照会する。

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC30589818-0-0');
    ```
