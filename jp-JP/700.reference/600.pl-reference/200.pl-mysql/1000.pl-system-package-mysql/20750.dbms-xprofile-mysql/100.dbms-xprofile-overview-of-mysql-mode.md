# DBMS_XPROFILEの概要

`DBMS_XPROFILE` システムパッケージは、パフォーマンス分析ツールキットであり、SQL実行プロセスにおけるリソース消費と演算子レベルのパフォーマンス指標を詳細に解析するために使用されます。

## DBMS_XPROFILE権限の説明

PL/SQLを実行する権限を持つユーザーはこの機能を使用できます。

## DBMS_XPROFILEサブプログラムの概要

次の表は、OceanBaseデータベースの現在のバージョンでサポートされている `DBMS_XPROFILE` サブプログラムとその簡潔な説明を示しています。

| サブプログラム | 説明 |
|--------|------|
| [DISPLAY_PROFILE](200.display-profile-of-mysql-mode.md)| SQL実行計画のパフォーマンス分析データを表示するために使用されます。指定された`trace_id`に対応する実行の演算子レベル診断情報を確認できます。|
