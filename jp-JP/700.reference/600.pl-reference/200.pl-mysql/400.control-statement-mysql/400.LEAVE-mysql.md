# LEAVE

`LEAVE` ステートメントは、指定されたラベルを持つプロシージャ制御ステートメントから抜け出すために使用します。ラベルが最も外側のストアドプログラムブロックに対応する場合、LEAVE を使用するとそのプログラムを終了します。

`LEAVE` ステートメントの構文は以下のとおりです：

```sql
LEAVE label
```

`LEAVE` ステートメントは、`BEGIN ... END` ブロック内、および `LOOP`、`REPEAT`、`WHILE` ループステートメント内で使用できます。
