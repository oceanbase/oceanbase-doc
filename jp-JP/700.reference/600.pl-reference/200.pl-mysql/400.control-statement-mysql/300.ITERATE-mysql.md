# ITERATE

`ITERATE` ステートメントは、ループの次の反復に進むために使用されます。

`ITERATE` ステートメントの構文は以下のとおりです：

```sql
ITERATE label
```

`ITERATE` は `LOOP`、`REPEAT`、`WHILE` ステートメント内でのみ使用できます。
