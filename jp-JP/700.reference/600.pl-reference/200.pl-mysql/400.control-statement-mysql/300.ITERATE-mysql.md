# ITERATE

`ITERATE` ステートメントは、ループステートメントを再度開始するために使用されます。

`ITERATE` ステートメントの構文は次のとおりです：

```sql
ITERATE label
```

`ITERATE` は `LOOP`、`REPEAT`、`WHILE` ステートメント内でのみ使用できます。
