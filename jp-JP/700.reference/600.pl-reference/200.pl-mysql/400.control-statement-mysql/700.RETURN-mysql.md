# RETURN

`RETURN` ステートメントは、ストアド関数の実行を終了し、結果を関数呼び出し元に返します。

`RETURN` ステートメントの構文は以下のとおりです：

```sql
RETURN expr
```

ストアド関数には少なくとも1つの `RETURN` ステートメントが必要です。関数の終了箇所が複数ある場合、複数の `RETURN` ステートメントが存在する可能性があります。

ストアドプロシージャやトリガーでは `RETURN` ステートメントは使用せず、`LEAVE` ステートメントを使用してプログラムを終了します。
