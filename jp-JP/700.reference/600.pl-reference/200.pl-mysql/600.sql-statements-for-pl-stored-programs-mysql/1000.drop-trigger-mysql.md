# DROP TRIGGER

`DROP TRIGGER` ステートメントは、トリガーを削除するために使用します。

`DROP TRIGGER` ステートメントの構文は以下のとおりです：

```sql
DROP TRIGGER [IF EXISTS] [schema_name.]trigger_name
```

スキーマ（データベース）名はオプションです。`schema_name` を省略した場合、デフォルトのスキーマからトリガーが削除されます。`DROP TRIGGER` を実行するには、トリガーが関連付けられているテーブルに対する `TRIGGER` 権限が必要です。

トリガーが存在しない場合、`IF EXISTS` 句を使用するとエラーを防ぎ、存在しないトリガーに対して `NOTE` を生成します。

テーブルを削除すると、そのテーブルのトリガーも削除されます。

`DROP TRIGGER` の例は以下のとおりです：

```sql
obclient> DROP TRIGGER IF EXISTS test_trg;
Query OK, 0 rows affected
```
