# カーソルの概要

PLストアドプログラムではカーソルがサポートされており、その構文は組み込みSQLと同じです。

カーソル宣言は、ハンドラ宣言の前、変数や条件宣言の後に記述する必要があります。カーソルには以下の特性があります：

* 不感応性：サーバーは結果テーブルをコピーする場合もあれば、コピーしない場合もあります。

* 読み取り専用性：更新できません。

* 不可ロールバック性：1つの方向にのみイテレーションでき、行をスキップすることはできません。
