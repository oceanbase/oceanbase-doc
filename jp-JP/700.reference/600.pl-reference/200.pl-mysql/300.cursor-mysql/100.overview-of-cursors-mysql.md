# カーソルの概要

PLストアドプログラムではカーソルがサポートされており、その構文は組み込みSQLと同じです。

カーソルの宣言は、処理手続きの宣言より前に、変数や条件の宣言より後に記述する必要があります。カーソルには以下の特性があります：

* 不感応性：サーバーは結果テーブルをコピーする場合もあれば、コピーしない場合もあります。

* 読み取り専用性：更新できません。

* 不可ロールバック性：1方向のみでイテレーション可能で、行をジャンプすることはできません。
