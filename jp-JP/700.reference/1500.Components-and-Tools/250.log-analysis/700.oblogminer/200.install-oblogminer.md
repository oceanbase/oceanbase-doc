# oblogminerのインストール

本記事では、oblogminerをインストールする2つの方法について説明します：YUMコマンドによるインストールとインストーラーによるインストールです。実際の状況に応じて、適切な方法を選択してください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>本記事で紹介しているのは、コミュニティエディションのoblogminerのインストール方法です。エンタープライズエディションのoblogminerは、エンタープライズ版OceanBaseデータベースのデプロイ時に自動的にインストールされます(<code>oceanbase/bin</code>配下)。</p>
</main>

## YUMコマンドによるインストール

YUMコマンドを使用して、OceanBaseのツール統合パッケージ(OceanBase Utils)を直接インストールすることで、oblogminerをインストールできます。YUMコマンドでインストールすると、oblogminerは`/usr/bin/`ディレクトリに配置されます。

1. ミラーソースの追加

   ```shell
   [admin@test001 ~]$ sudo yum-config-manager --add-repo https://mirrors.aliyun.com/oceanbase/OceanBase.repo
   ```

2. OceanBase Utilsのインストール

   ```shell
   [admin@test001 ~]$ sudo yum install oceanbase-ce-utils
   ```

3. oblogminerヘルプの表示

   インストールが完了したら、以下のコマンドを実行してoblogminerのヘルプを表示できます。

   ```shell
   [admin@test001 ~]$ oblogminer -h
   ```

## OceanBase Utilsインストーラーによるインストール

OceanBaseのツール統合パッケージ(OceanBase Utils)をインストールすることで、oblogminerをインストールできます。

1. [OceanBaseソフトウェアダウンロードセンター](https://en.oceanbase.com/softwarecenter)にアクセスし、OceanBase Utilsを検索して必要なバージョンをダウンロードします。

2. OceanBase Utilsがあるディレクトリで、以下のコマンドを実行してOceanBase Utilsをインストールします。

   ```shell
   [admin@test001 ~]$ sudo rpm -ivh oceanbase-ce-utils-<version>.rpm
   ```

   oblogminerのみを使用する場合は、以下のrpm2cpioコマンドを実行してoblogminerを取得できます。

   ```shell
   [admin@test001 ~]$ rpm2cpio oceanbase-ce-utils-<version> | cpio -idmv ./usr/bin/oblogminer
   ```

   rpm2cpioコマンドを使用した後、デプロイが完了したら、以下のコマンドを実行して`oblogminer`を`/usr/local/bin`ディレクトリにコピーします。

   ```shell
   [admin@test001 ~]$ sudo cp usr/bin/oblogminer /usr/local/bin
   ```

3. oblogminerヘルプの表示。

   インストールが完了したら、以下のコマンドを実行してoblogminerのヘルプを確認できます。

   ```shell
   [admin@test001 ~]$ oblogminer -h
   ```

## ソースコードからのコンパイル

OceanBaseデータベースのソースコードから自分でコンパイルすることもできます。

1. OceanBaseデータベースのオープンソースコードをローカルに取得します。

   ```shell
   [admin@test001 ~]$ git clone https://github.com/oceanbase/oceanbase.git
   ```

2. コードディレクトリで以下のコマンドを実行し、4.2.xブランチに切り替えます。

   ```shell
   [admin@test001 oceanbase]$ git checkout 4.2.x
   ```

3. 必要に応じて、コンパイルモードを選択してoblogminerをコンパイルします。

   * Debugモード

     build.shスクリプトを実行し、デバッグモードをdebugモードに指定します。

     ```shell
     [admin@test001 oceanbase]$ bash build.sh debug --init
     ```

     コンパイルディレクトリに移動します。

     ```shell
     [admin@test001 oceanbase]$ cd build_debug
     ```

     oblogminerをコンパイルします。

     ```shell
     [admin@test001 build_debug]$ make oblogminer
     ```

     コンパイル済み製品を`/usr/local/bin`ディレクトリにコピーします。

     ```shell
     [admin@test001 build_debug]$ sudo cp src/logservice/logminer/oblogminer /usr/local/bin
     ```

     oblogminerのコンパイル製品は、デフォルトで`<DEBUG_BUILD_DIR>/src/logservice/logminer`ディレクトリに保存されます。ここで、`<DEBUG_BUILD_DIR>`はコンパイルディレクトリを表し、Debugモードの場合、デフォルトは`build_debug`です。

   * Releaseモード

     build.shスクリプトを実行し、デバッグモードをreleaseモードに指定します。

     ```shell
     [admin@test001 oceanbase]$ bash build.sh release --init
     ```

     コンパイルディレクトリに移動します。

     ```shell
     [admin@test001 oceanbase]$ cd build_release
     ```

     oblogminerをコンパイルします。

     ```shell
     [admin@test001 build_release]$ make oblogminer
     ```

     コンパイル済みプロダクトを `/usr/local/bin` ディレクトリにコピーします。

     ```shell
     [admin@test001 build_release]$ sudo cp src/logservice/logminer/oblogminer /usr/local/bin
     ```

     oblogminerのコンパイル済みプロダクトは、デフォルトで`<DEBUG_BUILD_DIR>/src/logservice/logminer`に保存されます。ここで、`<DEBUG_BUILD_DIR>`はコンパイルディレクトリを表し、Releaseモードではデフォルトで`build_release`です。

4. oblogminerのヘルプを確認する

   コンパイルが成功したら、以下のコマンドを実行してoblogminerのヘルプを確認できます。

   ```shell
   [admin@test001 ~]$ oblogminer -h
   ```

## よくある質問

oblogminerの使用中に動的ライブラリ`libmariadb.so.3`が欠けている場合、以下のエラーが発生します：

```shell
oblogminer: error while loading shared libraries: libmariadb.so.3: cannot open shared object file: No such file or directory
```

OceanBaseデータベースには`libmariadb.so.3`が含まれています。findコマンドを使用して`libmariadb.so.3`のパスを特定し、環境変数で動的ライブラリの検索パスを指定することができます。具体的な操作手順は以下のとおりです：

1. findコマンドを実行して`libmariadb.so.3`のパスを特定する

   ```shell
   [admin@test001 ~]$ find / -name libmariadb.so.3
   ```

   環境に動的ライブラリ`libmariadb.so.3`が存在する場合、そのパスが出力されます。例：

   ```shell
   /home/admin/observer/lib/libmariadb.so.3
   ```

2. 環境変数`LD_LIBRARY_PATH`に動的ライブラリの検索パスを指定する

   ```shell
   [admin@test001 ~]$ export LD_LIBRARY_PATH=/home/admin/observer/lib
   ```

操作完了後、oblogminerのコマンドを正常に使用できます。oblogminerコマンドの詳細については、[コマンドラインパラメータ](300.command-line-parameters.md)を参照してください。
