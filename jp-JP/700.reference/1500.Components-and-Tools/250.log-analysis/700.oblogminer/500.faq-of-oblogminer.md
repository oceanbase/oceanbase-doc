# よくある質問

1. 列レベルのフィルタ条件を指定する際にデータベースとテーブルも指定する場合、`-l`/`--table-list` パラメータは不要なのでしょうか？

   データベースとテーブルレベルのフィルタリングはobcdc内で行われるため、不要なログを事前に除外できます。そのため、`-l`/`--table-list` パラメータも同時に指定することを推奨します。

2. oblogminer実行中に生成される実行ログ `oblogminer.log` が多すぎます。実行時のログ生成をどのように削減できますか？

   `-L`/`--log_level` パラメータを使用してログレベルを指定することで、実行ログの生成量を制御できます。例えば、ログレベルを `ALL.*:WARN` と定義します。

3. oblogminerの分析結果とユーザーが実際に実行したDML SQL文が異なるのはなぜですか？

   oblogminerは、ユーザーが実行したDML SQL文ではなく、clogログに基づいて分析を行います。そのため、分析結果の `SQL_REDO` とユーザーが実際に実行したDML SQL文との間に差異が生じる可能性がありますが、それはユーザーが実行したDML SQL文と等価であるはずです。

   例えば、主キーテーブルの主キー列に対するUPDATE操作について、oblogminerはDELETEおよびINSERT操作を生成します。

4. oblogminerの起動に失敗し、`init cdc instance failed` というエラーが表示されるのはなぜですか？

   起動に失敗する一般的な原因の一つは、開始時間（`-s`/`--start-time` で指定）がobcdcの開始タイムスタンプ要件を満たしていないことです。開始時間が早すぎると、oblogminerの起動に失敗します。具体的な制限については、[obcdc よくある質問](../../300.data-integrate/400.cdc/1000.faq-of-obcdc.md)を参照してください。
