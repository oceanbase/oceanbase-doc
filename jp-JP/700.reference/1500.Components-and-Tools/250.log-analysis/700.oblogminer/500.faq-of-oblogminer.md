# よくある質問

1. 列レベルのフィルター条件を指定する際にデータベースとテーブルも指定している場合、`-l`/`--table-list` パラメータは不要ですか？

   `-l`/`--table-list` パラメータも同時に指定することを推奨します。データベース・テーブルレベルのフィルタリングはobcdc内で行われるため、不要なログを事前に除外できます。

2. oblogminerの実行中に生成される実行ログ `oblogminer.log` が多すぎます。実行時のログ生成を減らす方法はありますか？

   `-L`/`--log_level` パラメータでログレベルを指定することで、実行ログの生成量を制御できます。例えば、ログレベルを `ALL.*:WARN` に設定します。

3. なぜoblogminerの分析結果とユーザーが実際に実行したDML SQL文が異なるのですか？

   oblogminerは、ユーザーが実行したDML SQL文ではなく、clogログに基づいて分析を行います。そのため、分析結果の `SQL_REDO` とユーザーが実際に実行したDML SQL文には差異が生じる可能性がありますが、ユーザーが実行したDML SQL文と等価であるはずです。

   例えば、主キーテーブルの主キーカラムに対するUPDATE操作について、oblogminerはDELETEとINSERTの操作を生成します。

4. なぜoblogminerの起動に失敗し、`init cdc instance failed` というエラーが表示されるのですか？

   起動失敗の一般的な原因の一つは、開始時刻（`-s`/`--start-time` で指定）がobcdcの起動タイムスタンプ要件を満たしていないことです。開始時刻が早すぎると、oblogminerの起動に失敗します。具体的な制限については、[obcdc よくある質問](../../300.data-integrate/400.cdc/1000.faq-of-obcdc.md)を参照してください。
