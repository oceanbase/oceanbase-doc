# obcdc_tailf

## obcdc_tailfとは

obcdc_tailfは、obcdc動的ライブラリを呼び出してOceanBaseデータベースの増分データを出力するためのシンプルなバイナリです。指定された形式でobcdcから取得したデータを出力（ファイルまたは画面に）し、obcdcの機能を体験したり、OceanBaseデータベースの増分トランザクションデータを観察したりできます。

## 使用方法

### 起動パラメータ

obcdc_tailfの起動パラメータと説明は、`./bin/obcdc_tailf -h` コマンドで確認できます。同様に、実行環境では必要なすべての動的ライブラリへのリンクが確立されている必要があります。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>obcdc_tailfの起動パラメータでファイルパスを指定する場合、異なるニーズに応じて相対パスまたは絶対パスを柔軟に設定できます。</p>
</main>

| パラメータ | 独立パラメータ |                                                    説明                                                     |
|----|--------|-----------------------------------------------------------------------------------------------------------|
| -f | N      | obcdc設定ファイルのパスを指定します。パラメータの後に続く内容は設定ファイルのパスです。[obcdcパラメータ説明](./200.obcdc-parameters/200.obcdc-configuration-items.md)を参照してください。 |
| -d | Y      | バックグラウンドで実行します。                                                                                                     |
| -D | N      | 出力データを記録するファイルを指定します。ファイル形式はカスタマイズ可能です。パラメータの後に続く内容はデータファイルのパスです。                                                                                     |
| -h | Y      | help情報を出力します。                                                                                               |
| -H | Y      | 安全ポイント情報を出力します。パラメータの後に続く内容は安全ポイントファイルのパスです。                                                                                 |
| -o | Y      | データを画面に出力します。                                                                                                   |
| -O | Y      | 16進数のみを出力します(NCHAR、NVARCHAR、VARCHARなど)。(その他の列は出力しません)。                                                              |
| -V | Y      | 検証モードを有効にし、行データの一意のIDを出力します。                                                                                       |
| -v | Y      | バージョン情報を出力します。                                                                                                   |
| -t | N      | セカンド単位のタイムスタンプでobcdcを起動します。後続の内容はタイムスタンプの値です。                                                                             |
| -T | N      | ミリ秒単位のタイムスタンプでobcdcを起動します。後続の内容はタイムスタンプの値です。                                                                            |
| -R | N      | 実行時間を指定します。                                                                                                   |
| -x | Y      | 一部の列に16進数を追加で出力します。                                                                                            |
| -m | Y      | LOB型列のMD5値を出力します。                                                                                        |
| -i | Y      | LogRecordの詳細情報を出力します(現在は主キー情報を非表示にしています)。                                                                            |
| -c | Y      | DMLトランザクションでは、データのチェックサム値(crc32アルゴリズム)のみを出力します。                                                                            |

## よくある質問

obcdc_tailfコマンドを実行する際、動的ライブラリ`libobcdc.so.4`が欠けている場合、次のようなエラーが発生します：

```shell
./bin/obcdc_tailf: error while loading shared libraries: libobcdc.so.4: cannot open shared object file: No such file or directory
```

findコマンドで`libobcdc.so.4`のパスを特定し、環境変数に動的ライブラリの検索パスを指定することができます。具体的な操作手順は以下のとおりです：

1. findコマンドを実行して`libobcdc.so.4`のパスを特定する

   ```shell
   [admin@test001 ~]$ find / -name libobcdc.so.4
   ```

   環境に動的ライブラリ`libobcdc.so.4`が存在する場合、そのパスが出力されます。例：

   ```shell
   /home/admin/oceanbase-ce/lib/libobcdc.so.4
   ```

2. 環境変数`LD_LIBRARY_PATH`に動的ライブラリの検索パスを指定する

   ```shell
   [admin@test001 ~]$ export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/home/admin/oceanbase-ce/lib/
   ```
