# obcdcの一般的なパラメータ

この記事では、obcdcでよく使用されるパラメータを例示します。すべてのパラメータについては、[obcdc パラメータ説明](../200.obcdc-parameters/200.obcdc-configuration-items.md)を参照してください。

|                    パラメータ                     |      機能      |                                                                        説明                                                                         |
|--------------------------------------------|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| log_level                                  | ログ           | ログレベル。モジュールごとに調整可能：例えば `TLOG FETCHER:DEBUG`、`TLOG:COMMITTER:ERROR`。FETCHER、PARSER、FORMATTER、SEQUENCER、COMMITTERを制御できます。モジュールの前には `TLOG.` プレフィックスを付ける必要があります。 |
| rootserver_list                            | OceanBaseへの接続 | 起動時にrootserviceが配置されているマシン情報を指定する形式：`server_ip:server_rpc_port:server_sql_port`。                                                                           |
| cluster_url                                | OceanBaseへの接続 | OceanBaseがcluster urlを持つ場合。obcdcはrootserver情報を取得するために使用され、サーバーの高可用性をサポートします。                                                                             |
| cluster_user                               | OceanBaseへの接続 | sysテナント配下のユーザーを設定する必要があります。このユーザーは内部テーブル（oceanbaseデータベース）の読み取り権限を持ちます。                                                                                                             |
| cluster_password                           | OceanBaseへの接続 | 上記sysテナント配下のユーザーに対応するパスワード。                                                                                                                               |
| tenant_endpoint                           | 対応テナントへの接続 | テナントが配置されているマシンのリスト。                                                                                                                             |
| tenant_user                           | 対応テナントへの接続 | テナントのユーザー名。                                                                                                                              |
| tenant_password                           | テナントへの接続 | 上記テナントのユーザー名に対応するパスワード。                                                                                                                               |
| config_fpath                               | 永続化の設定        | obcdcのすべての設定情報がこのファイルにダンプされます。                                                                                                                       |
| working_mode                               | 動作モード         | 動作モード：デフォルトは永続化モードです。                                   |
| store_service_path                         | 動作モード         | 永続化データの保存パス：永続化モードでのみ有効です。 相対パス：obcdcを呼び出したプロセスのパス配下に保存します。 絶対パス：指定された絶対パスに保存します。例：`store_service_path=/data/1`。        |
| tb_white_list                              | 同期粒度         | 同期するテーブルのホワイトリスト。                                                                                                                                         |
| tb_black_list                              | 同期粒度         | 同期するテーブルのブラックリスト。                                                                                                                                         |
| tablegroup_white_list                      | 同期粒度         | 同期するtablegroupのホワイトリスト。                                                                                                                               |
| tablegroup_black_list                      | 同期粒度         | 同期するtablegroupのブラックリスト。                                                                                                                               |
| enable_oracle_mode_match_case_sensitive    | 同期粒度         | OceanBase-Oracleモードのテナントにおけるアローリストおよびブラックリストのマッチング時の大文字小文字の区別を有効にするかどうかを指定します。                                                                                                                |
| cluster_id_black_list                      | cluster_id   | 同期対象のcluster_idのブラックリストです。                                                                                                                              |
| memory_limit                               | スループット制御         | obcdcがスループット制御をトリガーするメモリしきい値です。                                                                                                                               |
| system_memory_avail_percentage_lower_bound | スループット制御         | システム利用可能メモリの下限しきい値（割合）。                                                                                                                                  |
| part_trans_task_active_count_upper_bound   | スループット制御         | アクティブなパーティショントランザクション数の上限です。                                                                                                                                      |
| storager_task_count_upper_bound            | スループット制御         | storagerモジュールで永続化待ちのタスク数のスループット制御しきい値です。                                                                                                                       |
| part_trans_task_reusable_count_upper_bound | スループット制御         | 再利用可能なパーティショントランザクションの上限です。                                                                                                                                       |
| ready_to_seq_task_upper_bound              | スループット制御         | シーケンス待ちタスクの上限数。                                                                                                                                       |
| partition_count_upper_limit                | パーティション管理         | obcdcインスタンスが同時に同期できるパーティション数の上限。デフォルトは200万。                                                                                                                |
| stream_max_partition_count                 | パーティション管理         | 1つのログストリームが最大でサポートできるパーティション数。デフォルトは5000ですが、ホットパーティションが存在する場合、この値を下げることで同期効率を効果的に向上させることができます。                                                                                                      |
| enable_output_trans_order_by_sql_operation | LogRecord 出力 | トランザクション内の行データをSQL実行順に出力するかどうか。                                                                                                                            |
| sort_trans_participants                    | LogRecord 出力 | 分散トランザクションの参加者ごとにソートするかどうか（`enable_output_trans_order_by_sql_operation`と組み合わせることで、安定した行データの出力順序を得られます）。                                                                   |
| enable_output_hidden_primary_key           | LogRecord 出力 | 主キーのないテーブルの隠れた主キーを出力するかどうか。                                                                                                                                    |
| enable_convert_timestamp_to_unix_timestamp | LogRecord 出力 | timestampタイムスタンプをUNIX整数時間に変換するかどうか。デフォルトは`YYYY-MM-DD HH:MM:SS`形式です。                                                                                      |
| enable_output_invisible_column             | LogRecord 出力 | 隠れた列を出力するかどうか。                                                                                                                                          |
| output_heartbeat_interval_sec              | LogRecord 出力 | セキュリティポイント情報を出力する間隔。                                                                                                                                      |
| timezone                                   | LogRecord 出力 | obcdcが属するタイムゾーン。timestamp_with_local_timezone型の時刻を同期する際に、指定されたタイムゾーンの時間として出力するために使用されます。                                                                                                       |
