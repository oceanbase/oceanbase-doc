# 設定ファイルの例

obcdcの設定ファイルは、キーと値のペアで構成されており、必須パラメータとオプションパラメータが含まれます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>obcdcの設定パラメータの詳細については、<a href='200.obcdc-configuration-items.md'>obcdc設定パラメータの説明</a>を参照してください。</p>
</main>

設定ファイルで必須のパラメータは `cluster_user` と `cluster_password` であり、sysテナントのユーザー名とパスワードを設定するために使用されます。`cluster_url` と `rootserver_list` のうち、どちらか一方を必ず設定する必要があります。これらは、OceanBaseデータベース内のRoot Serviceが配置されているマシン情報を設定するために使用されます。両方を設定した場合は、`rootserver_list` の値が優先的に適用されます。また、オプションの設定パラメータもいくつか設定することを推奨します。設定ファイル名が `libobcdc.conf` である例を挙げると、設定ファイルの内容は以下のとおりです：

```shell
######### [cluster_info] #########
cluster_db_name=oceanbase
cluster_password=********
cluster_user=test
cluster_url=
# rootserver_list=

######### [working_mode] #########
meta_data_refresh_mode=data_dict

######### [synchronous information] #########
tb_white_list=*.*.*
tb_black_list=|

######### [module] #########
formatter_thread_num=20

######### [log] #########
log_level=ALL.*:INFO;PALF.*:WARN;SHARE.SCHEMA:WARN;TLOG.FETCHER:INFO;TLOG.FORMATTER:INFO;

enable_output_trans_order_by_sql_operation=1
```

## 設定ファイルの使用

obcdcをご自身のデータ消費パイプラインに接続して使用する場合、コードを記述する際に設定ファイルを指定できます。関連する操作については、[obcdc開発説明](../250.obcdc-development-instructions.md)を参照してください。

obcdc_tailfを使用してobcdc機能を利用する場合、obcdc_tailfコマンド実行時に設定ファイルを指定できます。例：

```shell
[admin@test oceanbase]$ ./bin/obcdc_tailf -f libobcdc.conf -D output.txt
```

ここでは、設定ファイルの相対パスを `libobcdc.conf` とし、obcdcが処理した出力データを `output.txt` ファイルに保存する例を挙げます。実際の状況に応じて、設定ファイル名と出力データの保存ファイル名を置き換えてください。obcdc_tailfコマンドの詳細については、[obcdc_tailf](../300.obcdc-tailf.md)を参照してください。
