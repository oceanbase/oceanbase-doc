# OceanBase Binlogサービス

OceanBase Binlogサービス（OceanBase Binlog Service、略称：Binlogサービス）は、OceanBaseデータベースのトランザクションログを収集し、MySQL Binlogに変換するサービスです。主にリアルタイムデータサブスクリプションなどのシナリオで利用されます。

## 関連コンポーネント

OceanBase Binlogサービスは、主に以下の3つの部分で構成されています：

* OceanBaseデータベース：Binlogログを生成する必要がある業務データベース。

* OceanBaseデータベースプロキシ：業務データベースのODP（OBProxyとも呼ばれる）。Binlogをサブスクライブするクライアントに接続サービスを提供します。

* OceanBase Binlogツール：OceanBase Binlogサービスのコアコンポーネントであるobbinlog（旧oblogproxy）。Clogの取得とBinlogログの生成を実行します。

## Binlogサービスドキュメント

Binlogサービスの詳細な紹介と使用方法については、公式サイトの[《OceanBase Binlogサービス》](https://en.oceanbase.com/docs/oblogproxy)ドキュメントを参照してください。
