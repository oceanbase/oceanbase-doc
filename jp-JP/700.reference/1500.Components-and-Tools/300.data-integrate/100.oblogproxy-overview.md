# OceanBase Binlogサービス

OceanBase Binlogサービス（OceanBase Binlog Service、略称Binlogサービス）は、OceanBaseデータベースのトランザクションログを収集し、MySQL Binlogに変換する機能を持ち、主にリアルタイムデータサブスクリプションなどのシナリオで利用されます。

## 関係コンポーネント

OceanBase Binlogサービスは、主に以下の3つの部分で構成されています：

* OceanBaseデータベース：Binlogログを生成する必要がある業務データベースです。

* OceanBaseデータベースプロキシ：業務データベースのODP（OBProxyとも呼ばれる）は、Binlogをサブスクライブするクライアントに接続サービスを提供します。

* OceanBase Binlogツール：OceanBase Binlogサービスのコアコンポーネントであるobbinlog（元のoblogproxy）は、clogの取得とBinlogログの生成を実行します。

## Binlogサービスドキュメント

Binlogサービスの詳細な説明と使用方法については、公式Webサイトの[《OceanBase Binlogサービス》](https://www.oceanbase.com/docs/oblogproxy-doc)ドキュメントを参照してください。
