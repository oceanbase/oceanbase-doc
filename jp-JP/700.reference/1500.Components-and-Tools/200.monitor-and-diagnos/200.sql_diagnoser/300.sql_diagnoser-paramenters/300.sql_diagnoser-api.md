# インターフェースの説明

オープンなインターフェースを通じて、必要な診断機能を独自に実装できます。sql_diagnoserに関連するインターフェースには、診断インターフェースと診断ルール関連インターフェースが含まれます。

* 診断インターフェースのアドレス：`http://ip:port/swagger-ui/index.html#/sql-diagnose-controller/diagnosisUsingPOST`。
* 診断ルール関連インターフェースには、**診断ルールの一覧取得インターフェース**、**診断ルールの削除インターフェース**、**ルールの追加診断インターフェース**、**診断ルールの更新インターフェース**が含まれます。
   * 診断ルールの一覧取得インターフェースのアドレス： `http://ip:port/swagger-ui/index.html#/sql-diagnose-controller/listDiagnoseRulesUsingGET`。
   * 診断ルールの削除インターフェースのアドレス： `http://ip:port/swagger-ui/index.html#/sql-diagnose-controller/deleteDiagnoseRuleUsingDELETE`。
   * ルールの追加診断インターフェースのアドレス： `http://ip:port/swagger-ui/index.html#/sql-diagnose-controller/addDiagnoseRuleUsingPOST`。
   * 診断ルールの更新インターフェースのアドレス： `http://ip:port/swagger-ui/index.html#/sql-diagnose-controller/updateDiagnoseRuleUsingPOST`。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>ip:port</code> はsql_diagnoserのデプロイメントアドレスであり、実際のデプロイメントアドレスに基づいて変更する必要があります。</p>
</main>
