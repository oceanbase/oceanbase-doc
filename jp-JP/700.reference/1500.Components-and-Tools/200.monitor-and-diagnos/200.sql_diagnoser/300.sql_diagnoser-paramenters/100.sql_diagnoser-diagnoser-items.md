# 組み込み診断項目

本記事では、sql_diagnoserの組み込み診断項目を例示し、具体的な説明を以下に示します。

|                              ディアグノスティック項目                              |                                  説明                                        |
|--------------------------------------------------------------|----------------------------------------------------------------------|
| フルテーブルスキャン、インデックスがあるにもかかわらず使用されていない          | SQLが対象とするすべてのテーブルにはインデックスが存在します。 |
| フルテーブルスキャン、利用可能なインデックスがない         | SQLが対象とするテーブルにインデックスが作成されていません。                |
| インデックスは使用されているがパフォーマンスが悪い          | SQLはインデックスを使用していますが、パフォーマンスは依然として悪い（応答時間またはCPU時間が悪い）。                                   |
| ヒントが反映されていない        | SQL実行時に、ヒントで指定されたインデックスが使用されていません。                                             |
| 影響行数が多すぎる       | SQLが影響する行数が設定値を超えています。                                      |
| 戻り行数が多すぎる      | SQLが返す行数が設定値を超えています。                                |
| SQLが対象とするテーブルが多すぎる       | SQLが対象とするテーブルの数が設定値を超えています。                                |
