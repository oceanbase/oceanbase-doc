# sql_diagnoserの概要

本記事では、sql_diagnoserとは何か、およびsql_diagnoserの機能と特徴について簡潔に紹介します。

## sql_diagnoserとは

sql_diagnoserは、アジャイル版のSQL診断ツールであり、業務クラスタを直接分析して一般的な疑わしいSQLや隠れたパフォーマンス問題を特定することができます。また、SQLレビューもサポートしており、ユーザーはSQLレビュー機能ページでSQLを入力して分析し、問題が存在するかどうかを検出できます。

## sql_diagnoserの機能と特徴

sql_diagnoserには以下の機能と特徴があります：

* sql_diagnoser（テナントSQL診断）は、いくつかの一般的な診断項目を組み込んでいるほか、カスタム診断項目もサポートしています。SQLに似た簡単な構文を理解すれば、診断ルールを定義できます。詳細については、[sql_diagnoserの使用](200.deploy-and-use-delsql_diagnoser/200.sql_diagnoser-development-guide.md)の**カスタム診断ルール**を参照してください。

* sql_diagnoser（テナントSQL診断）のインターフェースドキュメントが公開されており、公開されたインターフェースを通じて独自の診断機能を実装できます。詳細については、[インターフェース説明](300.sql_diagnoser-paramenters/300.sql_diagnoser-api.md)を参照してください。

* SQLレビューの診断ルールについては、ドキュメント[SQLレビューの診断項目](300.sql_diagnoser-paramenters/400.sql_diagnoser-review-items.md)を参照してください。
