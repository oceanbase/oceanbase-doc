# sql_diagnoserのインストール

本記事では、sql_diagnoserのインストール方法について説明します。

## 環境要件

sql_diagnoserをインストールするには、JDK 8以降が必要です。

## 前提条件

sql_diagnoserのデフォルトポートである8080が使用されていないこと。また、ポートはカスタマイズ可能です。

## インストール手順

1. [ダウンロードページ](https://en.oceanbase.com/softwarecenter)からsql_diagnoserのインストーラーをダウンロードし、解凍します。
2. 以下のコマンドを実行してインストールします。
    ```nohup java -jar /home/admin/sql-diagnoser-4.2.0.0.jar &```

    リスニングポートを指定したい場合は、実行コマンドに`-Dserver.port`を追加します。例：`nohup java -Dserver.port=9090 -jar /home/admin/sql-diagnoser-4.2.0.0.jar &`。

3. ブラウザで`localhost:8080`にアクセスし、ツールが正常にインストールされたか確認します。
ツールが正常にインストールされると、ログの保存パスは `${user.home}/logs/ob-tool/` になります。
