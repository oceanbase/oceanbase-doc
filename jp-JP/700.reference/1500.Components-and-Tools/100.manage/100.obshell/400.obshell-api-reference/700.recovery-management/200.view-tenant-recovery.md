# テナントの復元状況を確認する

本記事では、APIを使用してテナントの復元状況を確認する方法について説明します。

## 呼び出しの説明

### インターフェース制約

パスワードが設定されている場合は、認証を通過する必要があります。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/tenant/:name/restore/overview

### 戻り値

| パラメータ | 型 | 説明 |
|------|-----|------|
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | int | HTTPステータスコードに準拠したエンコードです。 |
| traceId | string | リクエストのトレースIDです。 |
| data | RestoreOverview | 復元タスクの詳細情報です。詳細については、以下の**RestoreOverviewのデータ構造**を参照してください。 |
| error | ApiError | リクエストによって生成されたErrorで、以下の情報が含まれます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

RestoreOverviewのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| tenant_id | int | 復元タスクを実行するテナントID。 |
| job_id | int | 復元に属するjob_id。1回の復元タスクに対応します。 |
| restore_tenant_name | string | 復元対象のテナント名。 |
| restore_tenant_id | int | 復元対象のテナントID。 |
| backup_tenant_name | string | バックアップのソーステナント名。 |
| backup_tenant_id | int | バックアップのソーステナントID。 |
| backup_cluster_name | string | バックアップのソースクラスタ名。 |
| backup_dest | string | バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します。 |
| restore_option | string | 復元オプション。 |
| restore_scn | int | ユーザー指定の復元ポイント。 |
| restore_scn_display | string | ユーザー指定の復元ポイントのタイムスタンプ表現。 |
| status | string | 復元状態。 |
| start_timestamp | time.time | 復元タスク開始時刻のタイムスタンプ。 |
| backup_set_list | string | 復元に依存するデータバックアップセットパスリスト。 |
| backup_piece_list | string | 復元に依存するログアーカイブシャーディングパスリスト。 |
| tablet_count | int | 復元対象のtablet総数。 |
| total_bytes | int | 復元総バイト数。 |
| description | string | 説明情報。 |
| finish_tablet_count | int | 復元完了のtablet総数。 |
| finish_bytes | int | 完了復元バイト数。 |
| finish_bytes_display | string | 完了復元バイト数をストレージ容量単位で表示。 |
| total_bytes_display | string | 復元総バイト数をストレージ容量単位で表示。 |
| recover_scn | int | ログrecoverポイント。 |
| recover_scn_display | time.time | ログrecoverポイントのタイムスタンプ表現。 |
| recover_progress | DECIMAL(6, 2) | ログrecover進捗。 |
| restore_progress | DECIMAL(6, 2) | データ復元進捗。 |
| backup_cluster_version | int | バックアップソースクラスタのバージョン番号。 |
| ls_count | int | 復元ログストリーム総量。 |
| finish_ls_count | int | 完了復元ログストリーム数。 |
| comment | string | 復元失敗時に失敗情報を記録。 |
| finish_timestamp | time.time | 復元タスク終了時刻のタイムスタンプ。 |
