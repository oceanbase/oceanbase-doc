# テナントの復元状況を確認する

本記事では、APIを使用してテナントの復元状況を確認する方法について説明します。

## 呼び出しの概要

### インターフェース制約

パスワードが設定されている場合は、認証が必要です。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/tenant/:name/restore/overview

### 戻り値

| パラメータ | 型 | 説明 |
|------|-----|------|
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | int | HTTPステータスコード規格に準拠したエンコードです。 |
| traceId | string | リクエストのTrace IDです。 |
| data | RestoreOverview | 復元タスクの詳細情報です。詳細については、以下の**RestoreOverviewのデータ構造**を参照してください。 |
| error | ApiError | リクエストによって生成されたErrorで、以下の情報が含まれます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

RestoreOverviewのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| tenant_id | int | 復元タスクを実行するテナントIDです。 |
| job_id | int | 復元が属するjob_idで、1回の復元タスクに対応します。 |
| restore_tenant_name | string | 復元対象のテナント名です。 |
| restore_tenant_id | int | 復元対象のテナントIDです。 |
| backup_tenant_name | string | バックアップのソーステナント名です。 |
| backup_tenant_id | int | バックアップのソーステナントIDです。 |
| backup_cluster_name | string | バックアップのソースクラスタ名です。 |
| backup_dest | string | バックアップセットのパスで、ユーザーが入力したデータバックアップパスとログアーカイブパスを指します。 |
| restore_option | string | 復元オプションです。 |
| restore_scn | int | ユーザーが指定した復元ポイントです。 |
| restore_scn_display | string | ユーザーが指定した復元ポイントのタイムスタンプ表現です。 |
| status | string | 復元状態です。 |
| start_timestamp | time.time | 復元タスク開始時のタイムスタンプです。 |
| backup_set_list | string | 復元に依存するデータバックアップセットのパスリストです。 |
| backup_piece_list | string | 復元に依存するログアーカイブシャーディングのパスリストです。 |
| tablet_count | int | 復元対象のtabletの総数です。 |
| total_bytes | int | 復元したデータの総バイト数。 |
| description | string | 説明情報。 |
| finish_tablet_count | int | 復元が完了したtabletの合計数。 |
| finish_bytes | int | 復元が完了したバイト数。 |
| finish_bytes_display | string | 容量単位で表示された復元完了バイト数。 |
| total_bytes_display | string | 容量単位で表示された復元データの総バイト数。 |
| recover_scn | int | ログ復元のポイント。 |
| recover_scn_display | time.time | ログ復元ポイントをタイムスタンプで表す。 |
| recover_progress | DECIMAL(6, 2) | ログ復元の進捗状況。 |
| restore_progress | DECIMAL(6, 2) | データ復元の進捗状況。 |
| backup_cluster_version | int | バックアップ元クラスタのバージョン番号。 |
| ls_count | int | 復元されるログストリームの総数。 |
| finish_ls_count | int | 復元されたログストリームの数。 |
| comment | string | 復元に失敗した場合、失敗情報を記録します。 |
| finish_timestamp | time.time | 復元タスク終了時刻のタイムスタンプ。 |
