# ステータスの確認

本記事では、ノードの現在のステータスを確認する方法について説明します。ノードのアイデンティティ、プロセス情報、サービス状態などの内容が含まれます。

## 呼び出しの説明

### インターフェース制約

obshell ServerはこのAPIに対してセキュリティ検証を行います。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/status

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | int | HTTPステータスコード規格に準拠したエンコードです。 |
| traceId | string | リクエストのTrace IDです。 |
| data | AgentStatus | 詳細については、以下の**AgentStatus情報のデータ構造**を参照してください。 |
| error | ApiError | リクエストによって生成されたErrorで、以下の情報が含まれます：<ul><li>`code`：エラーコード。</li><li>`message`：エラーの詳細情報。</li><li>`subErrors`：サブエラー情報。</li></ul> |

AgentStatus情報のデータ構造：

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| agent | AgentInfoWithIdentity | ノードのアイデンティティ情報を表し、以下の3つの情報を含みます：<ul><li>`ip`：obshellのIPアドレスを表します。</li><li>`port`：obshellのポートを表します。</li><li>`identity`：obshellのアイデンティティを表します。アイデンティティ識別子の詳細については、以下の<b>ノードのアイデンティティ識別子</b>を参照してください。</li></ul> |
| state | int | ノードサービスの状態で、以下のような状態があります：<ul><li>`1`：起動中</li><li>`2`：実行中</li><li>`3`：停止中</li><li>`4`：停止済み</li></ul> |
| version | string | 使用しているobshellのバージョンです。 |
| pid | int | ノードサービスプロセスIDです。 |
| startAt | int | ノードがサービスを開始した時間です。 |
| port | int | ノードのポート番号です。 |
| obState | int | ノードが管理するOceanBaseデータベースの現在の状態で、以下のような状態があります：<ul><li>`0`：OceanBaseデータベースが起動していない</li><li>`1`：OceanBaseデータベースが起動している</li><li>`2`：OceanBaseデータベースが初期化されていない</li><li>`3`：OceanBaseデータベースが初期化されている</li></ul> |
| underMaintenance | bool | ノードがメンテナンス状態にあるかどうかを示します。 |

ノードのアイデンティティ識別子：

| 識別子 | 説明 |
| --- | --- |
| `SINGLE` | ノードがどのクラスタにも属していないことを示します |
| `FOLLOWER`/`MASTER` | ノードが初期化されていないクラスタに属していることを示します |
| `CLUSTER AGENT` | ノードが初期化されたクラスタに属していることを示します |
| `TAKE OVER MASTER`/`TAKE OVER FOLLOWER` | ノードがタッケオーバー状態にあることを示します |
| `SCALING OUT` | ノードがスケールアウト状態にあることを示します |
| `UNIDENTIFIED` | ノードが未定義であることを示します |

## 例

### リクエスト例

GET 10.10.10.1:2886/api/v1/status

### レスポンス例

この例では、`CLUSTER AGENT`ノードのステータスが返されています。これは、現在のノードが正常にサービスを提供でき、メンテナンス状態にないことを示しています。

```json
{
  "successful": true,
  "timestamp": "2024-01-09T20:01:52.466963232+08:00",
  "duration": 3,
  "status": 200,
  "traceId": "",
  "data": {
    "agent": {
        "ip": "10.10.10.1",
        "port": 2886,
        "identity": "CLUSTER AGENT"
    },
    "state": 2,
    "version": "4.2.1.0-0",
    "pid": 74314,
    "startAt": 1704801582437828890,
    "port": 2886,
    "obState": 3,
    "underMaintenance": false
  }
}
```
