# テナント情報のクエリ

本記事では、APIを使用して指定したテナントの詳細情報をクエリする方法について説明します。

## 呼び出しの説明

パスワードが設定されている場合は、認証が必要です。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/tenant/:name

### 戻り値

| パラメータ | 型 | 説明 |
|-------|------|-----|
| successful | bool | リクエストが成功したかどうか。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | in | HTTP Status仕様に準拠したエンコード。 |
| traceId | string | リクエストのTrace ID。 |
| data | TenantInfo | 指定したテナントの詳細情報。詳細については、**TenantInfoのデータ構造**を参照してください。 |
| error | ApiError | リクエストによって生成されたError。以下の情報を含みます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

TenantInfoのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| name | string | テナント名。 |
| id | int | テナントID。 |
| created_time | time.Time | テナント作成日時。 |
| mode | string | テナントモード。 |
| status | string | テナント状態。 |
| locked | string | テナントがロックされているかどうか。 |
| primary_zone | string | テナントのPrimary Zone。 |
| locality | string | テナントのLocality情報。 |
| in_recyclebin | string | テナントがごみ箱にあるかどうか。 |
| charset | string | テナントで使用される文字セット。 |
| collation | string | テナントで使用される照合順序。 |
| whitelist | string | テナントのアクセスホワイトリスト。 |
| pool | []ResourcePoolWithUnit | テナントが使用するリソースプール情報。詳細については、**ResourcePoolWithUnitのデータ構造**を参照してください。 |

ResourcePoolWithUnitのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| pool_name | string | リソースプール名。 |
| pool_id | int | リソースプールID。 |
| zone_list | string | リソースプールが配置されているZoneのリスト。 |
| unit_num | int | リソースプールのユニット数。 |
| unit_config | ObUnitConfig | リソースプールで使用されるすべてのリソース構成の情報。詳細については、**ObUnitConfigのデータ構造**を参照してください。 |

ObUnitConfigのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| create_time | time.Time | リソース構成の作成時間。 |
| modify_time | time.Time | リソース構成の変更時間。 |
| unit_config_id | int | リソース構成ID。 |
| name | string | リソース構成名。 |
| max_cpu | float64 | CPU構成の上限。 |
| min_cpu | float64 | CPU構成の下限。 |
| memory_size | int | メモリ構成。 |
| log_disk_size | int | ログディスク容量のサイズ。 |
| max_iops | uint | IOPSの上限。 |
| min_iops | uint | IOPSの下限。 |
