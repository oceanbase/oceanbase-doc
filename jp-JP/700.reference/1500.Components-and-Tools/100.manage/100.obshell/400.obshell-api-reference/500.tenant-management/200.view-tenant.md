# テナント情報のクエリ

本記事では、APIを使用して指定したテナントの詳細情報をクエリする方法について説明します。

## 呼び出しの説明

パスワードが設定されている場合は、認証を通過する必要があります。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/tenant/:name

### 戻り値

| パラメータ | 型 | 説明 |
|-------|------|-----|
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | in | HTTPステータスコードに準拠したエンコードです。 |
| traceId | string | リクエストのTrace IDです。 |
| data | TenantInfo | 指定されたテナントの詳細情報です。詳細については、**TenantInfoのデータ構造**を参照してください。 |
| error | ApiError | リクエストで発生したErrorで、以下の情報が含まれます。<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

TenantInfoのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| name | string | テナント名。 |
| id | int | テナントID。 |
| created_time | time.Time | テナントの作成日時。 |
| mode | string | テナントモード。 |
| status | string | テナントステータス。 |
| locked | string | テナントがロックされているかどうか。 |
| primary_zone | string | テナントのプライマリゾーン。 |
| locality | string | テナントのローカリティ情報。 |
| in_recyclebin | string | テナントがごみ箱にあるかどうか。 |
| charset | string | テナントで使用される文字セット。 |
| collation | string | テナントで使用される照合順序。 |
| whitelist | string | テナントのアクセスホワイトリスト。 |
| pool | []ResourcePoolWithUnit | テナントが使用するリソースプール情報。詳細は、**ResourcePoolWithUnitのデータ構造**を参照してください。 |

ResourcePoolWithUnitのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| pool_name | string | リソースプール名。 |
| pool_id | int | リソースプールID。 |
| zone_list | string | リソースプールが配置されるZoneのリスト。 |
| unit_num | int | リソースプールのユニット数。 |
| unit_config | ObUnitConfig | リソースプールで使用されるすべてのリソース仕様の情報です。詳細については、**ObUnitConfigのデータ構造**を参照してください。 |

ObUnitConfigのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| create_time | time.Time | リソース仕様の作成日時。 |
| modify_time | time.Time | リソース仕様の変更日時。 |
| unit_config_id | int | リソース仕様ID。 |
| name | string | リソース仕様名。 |
| max_cpu | float64 | CPUスペックの上限。 |
| min_cpu | float64 | CPUスペックの下限、 |
| memory_size | int | メモリサイズ。 |
| log_disk_size | int | ログディスク容量。 |
| max_iops | uint | IOPSの上限。 |
| min_iops | uint | IOPSの下限。 |
