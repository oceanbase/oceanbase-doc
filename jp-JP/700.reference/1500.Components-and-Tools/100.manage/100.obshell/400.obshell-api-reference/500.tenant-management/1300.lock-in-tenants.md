# テナントのロック

本記事では、APIを使用して指定したテナントをロックする方法について説明します。テナントがロックされると、そのテナント上で新しい接続を作成することはできませんが、既存の接続は維持されます。

## 呼び出しの説明

パスワードが設定されている場合は、認証が必要です。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

POST /api/v1/tenant/:name/lock

### 戻り値

| パラメータ | 型 | 説明 |
|------|------|-----|
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | int | HTTPステータスコードに準拠したエンコードです。 |
| traceId | string | リクエストのTrace IDです。 |
| error | ApiError | リクエストで発生したErrorで、以下の情報が含まれます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

## 例

### リクエスト例

POST 10.10.10.1:2886/api/v1/tenant/t1/lock

### 返却例

```json
{
    "successful": true,
    "timestamp": "2024-10-14T10:29:49.199126252+08:00",
    "duration": 59,
    "status": 200,
    "traceId": "0f40c14342ff2e32"
}
```
