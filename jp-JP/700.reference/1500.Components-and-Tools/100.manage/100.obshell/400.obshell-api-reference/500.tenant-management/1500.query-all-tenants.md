# すべてのテナントの概要を取得する

本記事では、APIを使用してすべてのテナントの概要を取得する方法について説明します。

## 呼び出しの説明

パスワードが設定されている場合は、認証を通過する必要があります。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/tenants/overview

### 実行結果

| パラメータ | タイプ | 説明 |
|------|------|-----|
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | int | HTTP Status規格に準拠したエンコードです。 |
| traceId | string | リクエストのトレースIDです。 |
| data | []DbaObTenant | 取得したすべてのテナントの概要情報です。詳細については、**DbaObTenantのデータ構造**を参照してください。 |
| error | ApiError | リクエストによって生成されたエラーで、以下の情報が含まれます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

DbaObTenantのデータ構造：

| パラメータ | タイプ | 説明 |
|-------|------|------|
| tenant_id | int | テナントID。 |
| tenant_name | string | テナント名。 |
| mode | string | テナントモード。 |
| status | string | テナントのステータス。 |
| locked | string | テナントがロックされているかどうか。 |
| primary_zone | string | テナントのPrimary Zone。 |
| locality | string | テナントのレプリカ情報。 |
| in_recyclebin | string | テナントがごみ箱にあるかどうか。 |
| created_time | time.Time | テナントが作成された時間。 |
