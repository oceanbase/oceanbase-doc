# テナントパスワードの変更

本記事では、APIを使用して指定したテナントのrootユーザーパスワードを変更する方法について説明します。

## 呼び出しの概要

パスワードが設定されている場合は、認証が必要です。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

PUT /api/v1/tenant/:name/password

### リクエストパラメータ

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|-------|-----|-----|-----|--------|
| old_password | string | いいえ | "****" | テナントのrootユーザーの古いパスワード。 |
| new_password | string | はい | "******" | テナントのrootユーザーの新しいパスワード。 |

### 戻り値

| パラメータ | 型 | 説明 |
|------|-------|------|
| successful | bool | リクエストが成功したかどうか。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | int | HTTP Status仕様に準拠したコード。 |
| traceId | string | リクエストのTrace ID。 |
| error | ApiError | リクエストで発生したError。以下の情報を含みます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

## 例

### リクエスト例

PUT 10.10.10.1:2886/api/v1/tenant/t1/password

```json
{
    "old_password": "",
    "new_password": "******"
}
```

### 返却例

```json
{
    "successful": true,
    "timestamp": "2024-10-14T11:40:00.696664135+08:00",
    "duration": 120,
    "status": 200,
    "traceId": "66b976ef15984730"
}
```
