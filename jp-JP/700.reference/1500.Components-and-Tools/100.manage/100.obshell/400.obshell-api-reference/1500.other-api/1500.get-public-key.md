# 公開鍵の取得

本記事では、指定されたノードの公開鍵を取得する方法について説明します。

## 呼び出しの概要

### インターフェース制約

obshell ServerはこのAPIに対してセキュリティ検証を行います。詳細については、[API混合暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/secret

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | bool | リクエストが成功したかどうか。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | int | HTTPステータスコード規格に準拠したエンコード。 |
| traceId | string | リクエストのTrace ID。 |
| data | AgentSecret | 以下の情報を含みます：<ul><li>`ip`：指定ノードのIPアドレス。</li><li>`port`：指定ノードのポート。</li><li>`public_key`：指定ノードの公開鍵文字列。</li></ul> |
| error | ApiError | リクエストによって生成されたErrorで、以下の情報を含みます：<ul><li>`code`：エラーコード。</li><li>`message`：エラーの詳細情報。</li><li>`subErrors`：サブエラー情報。</li></ul> |

## 例

### リクエスト例

GET 10.10.10.1:2886/api/v1/secret
