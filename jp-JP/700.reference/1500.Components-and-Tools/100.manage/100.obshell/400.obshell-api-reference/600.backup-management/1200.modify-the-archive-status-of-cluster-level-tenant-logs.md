# クラスタレベルのログアーカイブ状態を変更する

本記事では、APIを使用してクラスタレベルのログアーカイブ状態を変更する方法について説明します。

## 呼び出しの概要

### インターフェース制約

パスワードが設定されている場合は、認証が必要です。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

PATCH /api/v1/obcluster/backup/log

### リクエストパラメータ

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|------|------|------|---------|------|
| status | string | いいえ | "stop" | ログアーカイブの状態。`stop` と `doing` をサポートします。デフォルトは `stop` です。 |

### 戻り結果

| パラメータ | 型 | 説明 |
|-----|-------|------|
| successful | bool | リクエストが成功したかどうか。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | int | HTTPステータスコード規格に準拠したエンコード。 |
| traceId | string | リクエストのTrace ID。 |
| error | ApiError | リクエストで発生したError。以下の情報を含みます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

## 例

### リクエスト例

PATCH 10.10.10.1:2886/api/v1/obcluster/backup/log

```json
{
  "status": "stop",
}
```

### 返却例

```json
{
  "successful": true,
  "timestamp": "2024-01-09T17:11:43.385889278+08:00",
  "duration": 1,
  "status": 200,
  "traceId": "877fe32b83634153",
}
```
