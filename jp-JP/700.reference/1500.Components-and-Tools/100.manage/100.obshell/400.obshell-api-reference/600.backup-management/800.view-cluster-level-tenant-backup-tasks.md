# クラスタレベルのバックアップタスクを表示する

本記事では、APIを使用してクラスタレベルのバックアップタスクを表示する方法について説明します。

## 呼び出しの説明

### インターフェース制約

パスワードが設定されている場合は、認証を通過する必要があります。詳細については、[API 混合暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/obcluster/backup/overview

### 戻り値

| パラメータ | 型 | 説明 |
|------|------|------|
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）です。 |
| status | int | HTTPステータスコードに準拠したエンコードです。 |
| traceId | string | リクエストのTrace IDです。 |
| data | []CdbObBackupTask | バックアップタスクのリストです。詳細については、以下の**CdbObBackupTaskのデータ構造**を参照してください。 |
| error | ApiError | リクエストで発生したErrorです。以下の情報が含まれます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

CdbObBackupTaskのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| tenant_id | int | テナントID。 |
| task_id | int | タスクレベルのバックアップタスクIDで、1つのバックアップセットに対応するタスクを表します。 |
| job_id | int | このタスクが属するJOB_IDです。 |
| incarnation | int | Flashback Database後の第何回目のインカーネーションを表します。 |
| backup_set_id | int | このタスクに対応するバックアップセットIDです。 |
| start_timestamp | time.Time | タスクの開始時間です。 |
| end_timestamp | time.Time | タスクの終了時間です。 |
| status | string | バックアップの状態です。 |
| start_scn | int | バックアップ開始時のSCNです。 |
| end_scn | int | バックアップ終了時のSCNです。 |
| user_ls_start_scn | int | バックアップログログストリームMETAのSCNです。 |
| encryption_mode | string | 暗号化モード。以下の値があります。<ul><li>`None`：暗号化しないことを表します。</li><li>`Password`：パスワードによるみだけの保護を表します。</li><li>`Password Encryption`：暗号化し、パスワードで保護することを表します。</li><li>`Transparent Encryption`：TDE暗号化を使用することを表します。</li><li>`Dual mode Encryption`：TDE暗号化とパスワード保護の両方を使用することを表します。</li></ul>現在は`None`と`Password`の2つのモードのみをサポートしています。 |
| input_bytes | int | 入力バイト数です。 |
| output_bytes | int | 出力バイト数です。 |
| output_rate_bytes | int | 1秒間の出力バイト数です。 |
| extra_meta_bytes | int | 追加バイト数です。 |
| tablet_count | int | TABLETの総数です。 |
| finish_tablet_count | int | バックアップが完了したTABLETの総数です。 |
| macro_block_count | int | マクロブロック数です。 |
| finish_macro_block_count | in | バックアップが完了したマクロブロック数です。 |
| file_count | int | バックアップファイル数です。 |
| meta_turn_id | int | バックアップMETAのサイクル数です。 |
| data_turn_id | int | バックアップDATAのサイクル数です。 |
| result | int | バックアップエラーコードの結果です。 |
| comment | string | エラーコードの説明です。 |
| path | string | バックアップパスです。 |
