# すべてのリソース仕様情報を取得する

本記事では、APIを使用してすべてのリソース仕様情報を取得する方法について説明します。

## 呼び出しの概要

パスワードが設定されている場合は、認証が必要です。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/units/config

### 戻り値

| パラメータ | 型 | 説明 |
|------|------|-----|
| successful | bool | リクエストが成功したかどうか。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | int | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | int | HTTPステータスコード規格に準拠したエンコード。 |
| traceId | string | リクエストのTrace ID。 |
| data | []DbaObUnitConfig | リソース仕様の詳細情報。詳細については、以下の**DbaObUnitConfigのデータ構造**を参照してください。 |
| error | ApiError | リクエストによって生成されたError。以下の情報を含みます：<ul><li><code>code</code>：エラーコード。</li><li><code>message</code>：エラーの詳細情報。</li><li><code>subErrors</code>：サブエラー情報。</li></ul> |

DbaObUnitConfigのデータ構造：

| パラメータ | 型 | 説明 |
|------|------|------|
| unit_config_id | int | リソース仕様ID。 |
| name | string | リソース仕様名。 |
| max_cpu | float64 | CPUスペックの上限。 |
| min_cpu | float64 | CPUスペックの下限。 |
| memory_size | int | メモリスペック。 |
| log_disk_size | int | ログディスク容量のサイズ。 |
| max_iops | uint | IOPSの上限。 |
| min_iops | uint | IOPSの下限。 |
| create_time | time.Time | リソース仕様の作成日時。 |
| modify_time | time.Time | リソース仕様の変更日時。 |
