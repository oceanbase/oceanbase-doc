# obshellの最後の運用タスクを照会する

このドキュメントでは、obshellの最後の運用タスクを照会する方法について説明します。

## 呼び出しに関する説明

### インターフェースの制約

obshell ServerはこのAPIに対してセキュリティ検証を行います。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

### リクエストパス

GET /api/v1/task/dag/maintain/agent

### 結果

| パラメータ | タイプ | 説明 |
| --- | --- | --- |
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理に要した時間（ミリ秒）です。 |
| status | int | HTTP Status 標準に準拠したエンコードです。 |
| traceId | string | リクエストの Trace ID です。 |
| data | DagDetailDTO | 詳細については、以下の **DagDetailDTO情報のデータ構造** を参照してください。 |
| error | ApiError | リクエストで発生したエラー。含まれる情報は次のとおりです：<ul><li>`code`：エラーコード。</li><li>`message`：エラーの詳細な情報。</li><li>`subErrors`：サブエラー情報。</li></ul> |

DagDetailDTO情報のデータ構造は以下のとおりです：

| パラメータ | タイプ | 説明 |
| --- | --- | --- |
| id | string | DAGの汎用ID。 |
| dag_id | int | DAGのIDは、OceanBaseデータベースに記録された主キーです。 |
| name | string | DAGの名前。 |
| stage | int | DAGの現在の実行フェーズ。 |
| max_stage | int | DAGの実行プロセスにおける総ステージ数。 |
| state | string | DAGの実行状態。 |
| operator | string | DAGの実行操作タイプ。 |
| start_time | time.Time | DAGの実行開始時間。 |
| end_time | time.Time | DAGの実行終了時間。 |
| additional_data | map[string]any | DAGのその他のデータ。 |
| nodes | []NodeDetailDTO | DAG内のすべてのNode情報。詳細については、[Nodeの詳細情報を取得する](../1000.task-management/2100.get-node-detail.md)を参照してください。 |

### 要求例

GET 10.10.10.1:2886/api/v1/task/dag/maintain/agent
