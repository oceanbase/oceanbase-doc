# OceanBaseクラスタの完了していないタスクを照会する

この記事では、CLUSTER AGENTとしてのノードが完了していないクラスタタスクを照会する方法について説明します。

## 呼び出しの注意点

### インターフェースの制約

* obshell ServerはこのAPIに対してセキュリティ検証を行います。詳細については、[APIハイブリッド暗号化](../20.api-hybrid-encryption.md)を参照してください。

* リクエストオブジェクトのアイデンティティはCLUSTER AGENTでなければなりません。

### リクエストパス

GET /api/v1/task/dag/ob/unfinish

### リクエストパラメータ

| パラメータ | タイプ | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- |
| show_detail | bool | いいえ | true | subTaskの詳細情報を表示するかどうかを制御します。デフォルトは`true`で、つまり表示が必要です。 |

### 戻り値

| パラメータ | タイプ | 説明 |
| --- | --- | --- |
| successful | bool | リクエストが成功したかどうかを示します。 |
| timestamp | time.Time | サーバーがリクエストを完了したタイムスタンプです。 |
| duration | int | サーバーがリクエストを処理に要した時間（ミリ秒）です。 |
| status | int | HTTP Status 標準に準拠したエンコードです。 |
| traceId | string | リクエストの Trace ID です。 |
| data | DagDetailDTO | 詳細については、以下の **DagDetailDTO情報のデータ構造** を参照してください。 |
| error | ApiError | リクエストで発生したエラー。含まれる情報は次のとおりです：<ul><li>`code`：エラーコード。</li><li>`message`：エラーの詳細な情報。</li><li>`subErrors`：サブエラー情報。</li></ul> |

DagDetailDTO情報のデータ構造は以下のとおりです：

| パラメータ | タイプ | 説明 |
| --- | --- | --- |
| id | string | DAGの汎用IDです。 |
| dag_id | int | DAG IDは、OceanBaseデータベースに記録された主キーです。 |
| name | string | DAGの名前です。 |
| stage | int | DAGの現在の実行段階です。 |
| max_stage | int | DAGの実行プロセスにおける合計段階数です。 |
| state | string | DAGの実行状態です。 |
| operator | string | DAGの実行操作タイプです。 |
| start_time | time.Time | DAGの実行開始時間です。 |
| end_time | time.Time | DAGの実行終了時間です。 |
| additional_data | map[string]any | DAGのその他のデータです。 |
| nodes | []NodeDetailDTO | DAG内のすべてのNode情報。詳細については、[Nodeの詳細情報を取得する](../1000.task-management/2100.get-node-detail.md)を参照してください。 |

## 例

### 要求例

GET 10.10.10.1:2886/api/v1/task/dag/ob/unfinish
