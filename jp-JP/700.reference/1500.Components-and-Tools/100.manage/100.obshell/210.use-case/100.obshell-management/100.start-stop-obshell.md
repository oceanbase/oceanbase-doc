# obshellの起動と停止

## obshellの起動

以下のコマンドを実行すると、obshellが起動します。

```shell
${home_path}/bin/obshell agent start [--ip] [-P] [--takeover]
```

例：

```shell
[admin@test001 ~]$ /home/admin/oceanbase/bin/obshell agent start --ip 10.10.10.1 -P 2886
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。

オプションの説明は以下の表を参照してください：

| オプション名      | 必須      | データ型   | デフォルト値 | 説明   |
|------------|----------|---------|---------|------|
| --ip       | いいえ    | string  | なし      | obshellがバインドするIPアドレスを設定します |
| -P/--port  | いいえ    | int     | 2886    | obshellがバインドするポート番号を設定します |
| --takeover | いいえ    | int     | 1       | 値を0以外に設定すると、テイクオーバー起動を示します。値を0に設定すると、非テイクオーバー起動を示します。デフォルトは`1`で、テイクオーバー起動を意味します |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>初めてobshellを起動する場合で、OceanBaseクラスタがまだ起動されていない場合は、IPアドレスを指定する必要があります。ポートはオプションです。</li>
  <li>初めてobshellを起動する場合で、OceanBaseクラスタが既に起動されている場合は、引き継ぎを行う必要がある場合は、<a href="../200.cluster-management/300.take-over-non-obshell-deployed-clusters.md'>非obshellデプロイメントクラスタの引き継ぎ</a>を参照してください。</li>
  <li>obshellが既に正常に起動されている場合は、IPアドレスとポートはどちらもオプションです。</li>
  </ul>
</main>

## obshellの停止

以下のコマンドを実行すると、obshellが停止します。

```shell
${home_path}/bin/obshell agent stop
```

例：

```shell
[admin@test001 ~]$ /home/admin/oceanbase/bin/obshell agent stop
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。
