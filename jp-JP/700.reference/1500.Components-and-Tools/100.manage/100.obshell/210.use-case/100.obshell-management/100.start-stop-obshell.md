# obshellの起動と停止

## obshellの起動

以下のコマンドを実行すると、obshellが起動します。

```shell
${home_path}/bin/obshell agent start [--ip] [-P] [--takeover]
```

例：

```shell
[admin@test001 ~]$ /home/admin/oceanbase/bin/obshell agent start --ip 10.10.10.1 -P 2886
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
|------------|----------|---------|---------|------|
| --ip       | いいえ       | string  | なし      | このobshellがバインドするIPアドレスを設定します |
| -P/--port  | いいえ       | int  | 2886    | このobshellがバインドするポート番号を設定します |
| --takeover | いいえ       | int     | 1       | 値を0以外に設定した場合は、タケオーバー起動を意味し、値を0に設定した場合は、タケオーバー起動ではないことを意味します。デフォルトは`1`であり、タケオーバー起動を意味します |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>初めてobshellを起動する場合、かつOceanBaseクラスタが一度も起動されたことがない場合は、IPアドレスを指定する必要があります。ポート番号は省略可能です。</li>
  <li>初めてobshellを起動する場合、かつOceanBaseクラスタが起動済みで、引き継ぎを行う必要がある場合は、<a href="../200.cluster-management/300.take-over-non-obshell-deployed-clusters.md">obshell以外でデプロイされたクラスタの引き継ぎ</a>を参照してください。</li>
  <li>obshellが正常に起動済みの場合、IPアドレスとポート番号はどちらも省略可能です。</li>
  </ul>
</main>

## obshellの停止

以下のコマンドを実行すると、obshellが停止します。

```shell
${home_path}/bin/obshell agent stop
```

例：

```shell
[admin@test001 ~]$ /home/admin/oceanbase/bin/obshell agent stop
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。
