# obshellの起動と停止

## obshellの起動

以下のコマンドを実行すると、obshellが起動します。

```shell
${home_path}/bin/obshell agent start [--ip] [-P] [--takeover]
```

例：

```shell
[admin@test001 ~]$ /home/admin/oceanbase/bin/obshell agent start --ip 10.10.10.1 -P 2886
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。

オプションの説明は以下の表のとおりです：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
|------------|----------|---------|---------|------|
| --ip       | いいえ     | string  | なし      | このobshellがバインドするIPアドレスを設定します |
| -P/--port  | いいえ     | int  | 2886    | このobshellがバインドするポート番号を設定します |
| --takeover | いいえ     | int     | 1       | 値を0以外に設定すると、タッケオーバー起動を意味します。値を0に設定すると、タッケオーバーではない起動を意味します。デフォルトは`1`で、タッケオーバー起動を意味します |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>初めてobshellを起動する場合、かつOceanBaseクラスタが一度も起動されたことがない場合は、IPアドレスを指定する必要があります。ポートはオプションです。</li>
  <li>初めてobshellを起動する場合、かつOceanBaseクラスタが起動済みで、タッケオーバーが必要な場合は、<a href="../200.cluster-management/300.take-over-non-obshell-deployed-clusters.md'>非obshellデプロイメントクラスタのタッケオーバー</a>を参照してください。</li>
  <li>obshellが正常に起動済みの場合、IPアドレスとポートはどちらもオプションです。</li>
  </ul>
</main>

## obshellの停止

以下のコマンドを実行すると、obshellが停止します。

```shell
${home_path}/bin/obshell agent stop
```

例：

```shell
[admin@test001 ~]$ /home/admin/oceanbase/bin/obshell agent stop
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。
