# RPMパッケージの検索

この記事では、obshell-sdk-pythonを使用して必要なRPMパッケージを検索する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a>を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## サンプルコード

:::tab

tab ローカルの同一アーキテクチャのRPMパッケージを検索する

* 最新バージョンのRPMパッケージを検索する

  ```python
  from obshell import search_package

  # 実行マシンと同一のアーキテクチャおよびシステムで最新のobshellパッケージを検索・実行
  def search_same_arch():
      pkgs = search_package("obshell")
      print (pkgs)
  ```

* 指定バージョンのRPMパッケージを検索する

  ```python
  from obshell import search_package

  # 実行マシンと同一のアーキテクチャおよびシステムで、指定バージョンのコミュニティ版OceanBaseデータベースパッケージを検索
  def search_same_arch_version():
      pkgs = search_package("oceanbase-ce", version="4.3.5.0")
      print (pkgs)
  ```

tab 指定されたアーキテクチャまたはシステムのRPMパッケージを検索する

* 最新バージョンのRPMパッケージを検索する

  ```python
  from obshell.mirror import BASE_COMMUNITY_MIRROR, EL8, AARCH64

  # 実行マシンと異なるアーキテクチャで最新のobshellパッケージを検索
  def search_diff_arch():
      # アーキテクチャとシステムをそれぞれ aarch64、el8 に指定する
      mirror = BASE_COMMUNITY_MIRROR.get_mirror(EL8, AARCH64)
      pkgs = mirror.search("obshell")
      print (pkgs)
  ```

* 特定バージョンの RPM パッケージを検索する

  ```python
  from obshell.mirror import BASE_COMMUNITY_MIRROR, EL8, AARCH64

  # 実行マシンとアーキテクチャが異なる指定バージョンの obshell パッケージを検索して実行する
  def search_diff_arch_version():
      # アーキテクチャとシステムをそれぞれ aarch64、el8 に指定する
      mirror = BASE_COMMUNITY_MIRROR.get_mirror(EL8, AARCH64)
      pkgs = mirror.search("obshell", version="4.2.4.0")
      print (pkgs)
  ```
