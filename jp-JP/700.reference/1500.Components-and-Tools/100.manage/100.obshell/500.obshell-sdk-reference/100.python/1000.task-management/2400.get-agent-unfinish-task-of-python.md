# Agentの未完了タスクの照会

本記事では、obshell-sdk-pythonを使用して現在のobshellノードの未完了タスクの詳細情報を取得する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
# 所属クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# 現在のobshellノードの未完了タスクの詳細情報を取得します。
dag = client.v1.get_agent_unfinished_dag()
```
