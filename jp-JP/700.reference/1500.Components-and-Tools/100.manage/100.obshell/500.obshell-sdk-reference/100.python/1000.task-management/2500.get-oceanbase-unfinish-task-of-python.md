# OceanBaseクラスタの未完了タスクを照会する

本記事では、obshell-sdk-pythonを使用して、クラスタ内の未完了タスクの詳細情報を取得する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のクライアントが対応するノードが、照会対象のクラスタ内にあることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
# 所在クラスタのroot@sysパスワードは '****' です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# クラスタの未完了タスクの詳細情報を取得します。
dag = client.v1.get_cluster_unfinished_dag()
```
