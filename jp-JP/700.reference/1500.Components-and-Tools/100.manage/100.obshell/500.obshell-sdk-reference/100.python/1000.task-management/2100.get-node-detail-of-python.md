# Nodeの詳細情報を取得する

本記事では、obshell-sdk-pythonを使用してNodeの詳細情報を取得する方法について説明します。NodeはDAG（タスク）のメンバーであり、1つのDAGは1つまたは複数のNodeで構成されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# clientインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
# 所在クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# generic_idが20194912107080886のNodeの詳細情報を取得します。
node = client.v1.get_node("20194912107080886")
```
