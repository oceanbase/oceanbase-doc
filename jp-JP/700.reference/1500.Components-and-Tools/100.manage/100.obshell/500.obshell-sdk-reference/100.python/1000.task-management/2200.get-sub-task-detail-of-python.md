# SubTaskの詳細情報を取得する

本記事では、obshell-sdk-pythonを使用してSubTaskの詳細情報を取得する方法について説明します。SubTaskはNodeのメンバーであり、1つのNodeは1つまたは複数のSubTaskで構成されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a> を参照して、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
# 所属クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# generic_idが20194912107080886のSubTaskの詳細情報を取得します。
sub_task = client.v1.get_sub_task("20194912107080886")
```
