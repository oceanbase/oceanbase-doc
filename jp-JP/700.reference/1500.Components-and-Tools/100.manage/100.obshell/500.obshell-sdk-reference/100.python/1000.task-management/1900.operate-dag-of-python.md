# タスクの操作

本記事では、obshell-sdk-pythonを使用してタスクを操作する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照して、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

:::tab

タブ同期実行

```python
from obshell import ClientSet, TaskExecuteFailedError
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
# クラスタのroot@sysパスワードは '****' です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

try:
    # クラスタを初期化します。
    client.v1.init_sync()
except TaskExecuteFailedError as e:  # クラスタの初期化タスクが失敗したことをキャッチします。
    client.v1.operate_dag_sync(e.dag-generic_id, "ROLLBACK")  # このタスクをロールバックします。
```

タブ タスクの非同期実行

```python
from obshell import ClientSet, TaskExecuteFailedError
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは '10.10.10.1'、ポートは2886です。
# クラスタのroot@sysパスワードは '****' です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

try:
    # クラスタを初期化します。
    client.v1.init_sync()
except TaskExecuteFailedError as e:  # クラスタの初期化タスクが失敗したことをキャッチします。
    client.v1.operate_dag(e.dag-generic_id, "ROLLBACK") # このタスクをロールバックします。
```
