# ごみ箱からテナントの削除

本記事では、obshell-sdk-pythonを使用してごみ箱内のテナントを削除する方法について説明します。これにより、対応するリソースプールも解放されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のクライアントが存在するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

:::tab

tab タスクの同期的実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

client.v1.purge_recyclebin_tenant_sync("t1")
```

tab タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

dag = client.v1.purge_recyclebin_tenant("t1")
# タスク完了を待ちます。
if dag is not None:
    client.v1.wait_dag_succeed(dag-generic_id)
```

:::
