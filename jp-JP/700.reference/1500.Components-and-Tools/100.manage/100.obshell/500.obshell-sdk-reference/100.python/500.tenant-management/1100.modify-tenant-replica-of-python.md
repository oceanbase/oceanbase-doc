# テナントレプリカの変更

本記事では、obshell-sdk-pythonを使用して指定されたテナントレプリカのプロパティを変更する方法について説明します。一括で変更することも可能です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、その状態がNORMALであることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

:::tab

タブ：タスクの同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth
from obshell.model import ModifyReplicaParam

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# t1のzone1上のレプリカタイプをREADONLYに変更します。
client.v1.modify_tenant_replica_sync(
    "t1", [ModifyReplicaParam("zone1", replica_type="READONLY")])
```

タブ タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth
from obshell.model import ModifyReplicaParam

# clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# t1のzone1上のレプリカタイプをREADONLYに変更します。
dag = client.v1.modify_tenant_replica(
    "t1", [ModifyReplicaParam("zone1", replica_type="READONLY")])
# タスク完了を待機します。
client.v1.wait_dag_succeed(dag-generic_id)
```

:::
