# テナントの削除

本記事では、obshell-sdk-pythonを使用して指定されたテナントを削除する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが既に存在し、状態がNORMALであることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

:::tab

タブ同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

client.v1.drop_tenant_sync("t1")
```

タブ：タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

dag = client.v1.drop_tenant("t1")
# タスク完了を待機します。
if dag is not None:
    client.v1.wait_dag_succeed(dag-generic_id)
```

:::
