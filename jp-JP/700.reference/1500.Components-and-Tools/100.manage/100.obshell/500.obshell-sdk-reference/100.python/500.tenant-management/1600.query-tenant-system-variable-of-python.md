# テナントシステム変数のクエリ

本記事では、obshell-sdk-pythonを使用してテナントシステム変数をクエリする方法について説明します。これには、指定クエリとあいまいクエリが含まれます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 指定されたシステム変数のクエリ

### 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、その状態がNORMALであることを確認してください。

* リクエスト元のクライアントに対応するノードが初期化済みのクラスタ内にあることを確認してください。

### サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

variable = client.v1.get_tenant_variable("t1","max_connections")
```

## テナントシステム変数のあいまいクエリ

### 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、その状態がNORMALであることを確認してください。

* リクエスト元のクライアントに対応するノードが初期化済みのクラスタ内にあることを確認してください。

### サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

variables = client.v1.get_tenant_variables("t1", "max_connect%")
```
