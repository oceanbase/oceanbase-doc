# テナントシステム変数のクエリ

本記事では、obshell-sdk-pythonを使用してテナントシステム変数をクエリする方法について説明します。これには、指定クエリとあいまいクエリが含まれます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>obshell-sdk-pythonの使用方法については、<a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a>を参照してください。</p>
</main>

## 指定されたシステム変数のクエリ

### 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、状態がNORMALであることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

### サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

variable = client.v1.get_tenant_variable("t1","max_connections")
```

## テナントシステム変数のあいまいクエリ

### 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、状態がNORMALであることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

### サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

variables = client.v1.get_tenant_variables("t1", "max_connect%")
```
