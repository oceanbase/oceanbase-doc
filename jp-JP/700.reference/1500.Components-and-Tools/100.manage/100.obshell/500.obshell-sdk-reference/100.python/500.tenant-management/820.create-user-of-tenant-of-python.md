# ユーザーの作成

本記事では、obshell-sdk-pythonを使用してテナントにユーザーを作成する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
  <li><p>まず、<a href='../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a>を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p></li>
  <li><p>obshell V4.2.6から、obshell-sdk-pythonを使用してテナントにユーザーを作成できるようになりました。</p></li>
  </ul>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のクライアントが初期化済みのクラスタ内のノードに対応していることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
# testテナントにuser_1ユーザーを追加する例を示します。sysテナントにユーザーを追加する場合は、tenant_nameとroot_passwordの設定を省略できます。
db_priv = {
        "db_name": "oceanbase",
        "privileges": ["SELECT"]
    }
client.v1.create_user(user_name="user_1", password="******", tenant_name="test", root_password="*****", global_privileges=["CREATE", "DELETE"], db_privileges=[db_priv])
```
