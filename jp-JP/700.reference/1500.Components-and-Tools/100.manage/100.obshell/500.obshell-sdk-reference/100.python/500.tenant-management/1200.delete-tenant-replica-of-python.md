# テナントレプリカの削除

本記事では、obshell-sdk-pythonを使用して指定したテナントのレプリカを削除する方法について説明します。一括削除も可能です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、その状態がNORMALであることを確認してください。

* リクエスト元のクライアントに対応するノードが初期化済みのクラスタ内にあることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# テナントのzone3上のレプリカを削除します。
client.v1.delete_tenant_replica_sync("t1", ["zone3"])
```

tab タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth
from obshell.model import ZoneParam

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# テナントのzone3上のレプリカを削除します。
dag = client.v1.delete_tenant_replica("t1", ["zone3"])
# タスクの完了を待機します。
if dag is not None:
    client.v1.wait_dag_succeed(dag_generic_id)
```

:::
