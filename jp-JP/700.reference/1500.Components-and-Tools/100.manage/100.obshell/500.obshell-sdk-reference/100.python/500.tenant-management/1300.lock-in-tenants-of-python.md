# テナントのロック

本記事では、obshell-sdk-pythonを使用してテナントをロックする方法について説明します。ロックされたテナントは新しい接続を作成できなくなります。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a> を参照して、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが既に存在し、状態がNORMALであることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

client.v1.lock_tenant("t1")
```
