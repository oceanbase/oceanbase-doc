# obshellのインストール

本記事では、obshell-sdk-pythonを使用して各ノードにobshell RPMパッケージを解凍・インストールする方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

obshellをインストールする前に、必要なRPMパッケージをマシンにダウンロードしておいてください。手動でダウンロードするか、obshell-sdk-pythonを使用してダウンロードすることもできます。obshell-sdk-pythonを使用したダウンロードの詳細については、[RPMパッケージのダウンロード](../1500.other-api/400.download-rpm-package-of-python.md)を参照してください。

## サンプルコード

```python
from obshell import install_obshell, NodeConfig

def init_nodes():
    ips = [
        "10.10.10.1",
        "10.10.10.2",
        "10.10.10.3",
    ]
    work_dir = "/data/ob" # OceanBaseデータベースの作業ディレクトリ
    nodes_config = []
    for _, ip in enumerate(ips):
        node = NodeConfig(ip, work_dir)
        nodes_config.append(node)

    # obshellのインストール
    install_obshell("/tmp/obshell-4.2.4.2-12024102115.el7.x86_64.rpm", nodes_config)
```
