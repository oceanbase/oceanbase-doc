# Agentアップグレードチェック

本記事では、obshell-sdk-pythonを使用してobshellノードのアップグレード前チェックを実行する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a>を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に動作していることを確認してください。

* リクエスト元のクライアントがアップグレード対象のクラスタ内にあるノードに対応していることを確認してください。

## サンプルコード

:::tab

tab タスクの同時実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
# 所在クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# クラスタでagentアップグレード前チェックを実行します。
client.v1.upgrade_agent_check_sync("4.2.2.0", "xxx.el7")
```

tab タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
# 所在クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# クラスタでagentアップグレード前チェックを実行します。
client.v1.upgrade_agent_check("4.2.2.0", "xxx.el7")
# タスク完了を待ちます。
client.v1.wait_dag_succeed(dag_generic_id)
```

:::
