# ノードのパスワードを設定する

本記事では、obshell-sdk-pythonを使用してノードのパスワードを設定する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
  <li><p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することを推奨します。</p></li>
  <li><p>obshell V4.2.6以降では、obshell-sdk-pythonを使用してノードのパスワードを設定できます。</p></li>
  </ul>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886、root@sysのパスワードは'***'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth(password='***'))
# ノードに既にパスワードが設定されている場合、clientの初期化にはノードのパスワード(agent_password)を使用する必要があります。
# client = ClientSet("10.10.10.1", 2886, PasswordAuth（agent_password='***'）)

client.v1.set_agent_password("****")
```
