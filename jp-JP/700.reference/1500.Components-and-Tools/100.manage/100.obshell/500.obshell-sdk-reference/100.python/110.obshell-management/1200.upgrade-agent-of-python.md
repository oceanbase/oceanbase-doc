# Agentのアップグレード

本記事では、obshell-sdk-pythonを使用してクラスタ内のobshellノードをアップグレードする方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照して、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストされたクライアントに対応するノードがアップグレード対象のクラスタ内にあることを確認してください。

## サンプルコード

:::tab

タブ：タスクの同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
# 所属クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# Agentのアップグレード
client.v1.upgrade_agent_sync("4.2.2.0", "xxx.el7")
```

タブ タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
# 所属クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# agentをアップグレードします。
client.v1.upgrade_agent("4.2.2.0", "xxx.el7")
# タスク完了を待機します。
client.v1.wait_dag_succeed(dag_generic_id)
```

:::
