# ステータスの確認

本記事では、obshell-sdk-pythonを使用してノードの現在のステータスを確認する方法について説明します。これには、ノードのアイデンティティ、プロセス情報、サービスステータスなどが含まれます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照して、obshell-sdk-pythonの使用方法をご確認ください。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# clientインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
# 所属クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# 現在のノードのステータスを取得します。
status = client.v1.get_status()
```
