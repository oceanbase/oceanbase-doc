# 単一テナントのバックアップ設定を設定する

本記事では、obshell-sdk-pythonを使用してテナントレベルのバックアップ設定を行う方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href='../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a>を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のクライアントに対応するノードが初期化済みのクラスタ内にある必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
client.v1.post_tenant_backup_config_sync(
    "tenant1",
    "file:///data/backup/data",
    "file:///data/backup/archive"
    log_archive_concurrency=100,
    ha_low_thread_score=100,
    delete_recovery_window="2d",
)
```
