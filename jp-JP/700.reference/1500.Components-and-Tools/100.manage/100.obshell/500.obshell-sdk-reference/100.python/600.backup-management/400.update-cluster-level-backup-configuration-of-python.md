# クラスタレベルのバックアップ設定の更新

本記事では、obshell-sdk-pythonを使用してクラスタレベルのバックアップ設定を更新する方法について説明します。

クラスタレベルのバックアップ設定を更新する際の注意点として、[クラスタレベルのバックアップ設定の設定](200.backup-configuration-for-cluster-of-python.md)との違いは、`backup_base_uri` を設定しなくてもよいことです。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code> と <code>piece_switch_interval</code> を設定する場合でも、<code>backup_base_uri</code> は依然として設定が必要です。これは、3つのパラメータが結びついており、増分設定はサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内に存在する必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
client.v1.patch_cluster_backup_config_sync(
    log_archive_concurrency=100,
    ha_low_thread_score=100,
    delete_recovery_window="2d",
)
```
