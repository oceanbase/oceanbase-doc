# クラスタレベルのバックアップ設定を更新する

本記事では、obshell-sdk-pythonを使用してクラスタレベルのバックアップ設定を更新する方法について説明します。

クラスタレベルのバックアップ設定を更新する場合と[クラスタレベルのバックアップ設定を設定する](200.backup-configuration-for-cluster-of-python.md)場合の違いは、`backup_base_uri`を設定しなくてもよい点です。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code>と<code>piece_switch_interval</code>を設定する必要がある場合でも、<code>backup_base_uri</code>は設定が必要です。これら3つは紐づけられており、個別に増分で設定することはサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a>を参照し、obshell-sdk-pythonの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のクライアントに対応するノードが、初期化済みのクラスタ内に存在する必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
client.v1.patch_cluster_backup_config_sync(
    log_archive_concurrency=100,
    ha_low_thread_score=100,
    delete_recovery_window="2d",
)
```
