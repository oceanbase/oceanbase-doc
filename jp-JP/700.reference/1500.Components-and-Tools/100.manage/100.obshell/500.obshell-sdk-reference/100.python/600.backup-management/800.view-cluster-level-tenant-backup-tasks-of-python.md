# クラスタレベルのバックアップタスクを表示する

本記事では、obshell-sdk-pythonを使用してクラスタレベルのテナントバックアップタスクを表示する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照して、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
client.v1.get_cluster_backup_overview()
```
