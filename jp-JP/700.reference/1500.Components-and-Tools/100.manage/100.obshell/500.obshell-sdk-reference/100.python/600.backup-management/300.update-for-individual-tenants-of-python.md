# 単一テナントのバックアップ設定の更新

本記事では、obshell-sdk-pythonを使用して特定のテナントのバックアップ設定を更新する方法について説明します。

単一テナントのバックアップ設定を更新する際の使用方法は、[単一テナントのバックアップ設定の設定](100.backup-configuration-for-individual-tenants-of-python.md)と異なり、`data_base_uri`と`archive_base_uri`は設定しなくても構いません。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code>と<code>piece_switch_interval</code>を設定する場合でも、<code>archive_base_uri</code>は引き続き設定する必要があります。これは、3つが結びついており、増分設定はサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは、<a href="../100.quickstart-of-python.md'>obshell-sdk-pythonクイックスタート</a>を参照して、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
client.v1.patch_tenant_backup_config_sync(
    "tenant1",
    log_archive_concurrency=100,
    ha_low_thread_score=100,
    delete_recovery_window="2d",
)
```
