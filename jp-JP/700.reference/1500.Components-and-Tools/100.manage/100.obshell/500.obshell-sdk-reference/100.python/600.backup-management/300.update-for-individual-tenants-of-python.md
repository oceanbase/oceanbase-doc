# 単一テナントのバックアップ設定を更新する

本記事では、obshell-sdk-pythonを使用して特定のテナントのバックアップ設定を更新する方法について説明します。

単一テナントのバックアップ設定を更新する場合と [単一テナントのバックアップ設定を設定する](100.backup-configuration-for-individual-tenants-of-python.md) の違いは、`data_base_uri` と `archive_base_uri` を設定しなくてもよい点です。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code> と <code>piece_switch_interval</code> を設定する必要がある場合でも、<code>archive_base_uri</code> は設定する必要があります。これら3つは紐づけられており、増分設定はサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-python の使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshell が正常に実行されていることを確認してください。

* リクエスト元のクライアントが対応するノードが初期化済みのクラスタ内にある必要があります。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))
client.v1.patch_tenant_backup_config_sync(
    "tenant1",
    log_archive_concurrency=100,
    ha_low_thread_score=100,
    delete_recovery_window="2d",
)
```
