# OBProxyインストールパッケージのアップロード

本記事では、obshell-sdk-pythonを使用して、OceanBaseデータベースプロキシ(OceanBase Proxy、ODPとも呼ばれる)のアップグレードに必要なインストールパッケージをobshellメタデータベースにアップロードする方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>obshell V4.2.6以降では、obshell-sdk-pythonを使用してOBProxyのアップグレードに必要なインストールパッケージをアップロードできます。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストしたクライアントに対応するノードにOBProxyがデプロイされていることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886、ノードのagent passwordは'***'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth(agent_password='***'))

client.v1.upload_obproxy_pkg(
        "/home/download/obproxy-ce-4.3.3.0-5.el7.x86_64.rpm")
```
