# OBProxyの停止

本記事では、obshell-sdk-pythonを使用して、指定されたノード上のOBProxy（OceanBaseデータベースプロキシ、ODPとも呼ばれる）を停止する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>obshell V4.2.6以降、obshell-sdk-pythonを使用して指定ノードのOBProxyを停止できます。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のクライアントに対応するノードにOBProxyがデプロイされていることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886、ノードのagentパスワードは'***'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth(agent_password='***'))

client.v1.stop_obproxy_sync()
```

tab タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886、ノードのagentパスワードは'***'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth(agent_password='***'))

dag = client.v1.stop_obproxy()
client.v1.wait_dag_succeed(dag.generic_id)
```

:::
