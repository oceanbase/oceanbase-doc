# Zoneの削除

本記事では、obshell-sdk-pythonを使用して、クラスタ内の指定されたZoneおよびそのZone内のノードを削除する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a>を参照し、obshell-sdk-pythonの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

クラスタのスケールインまたはスケールアウトを実行する前に、以下の要件に注意してください：

* リクエストを送信するクライアントに対応するノードが、スケールインまたはスケールアウト対象のクラスタ内に存在し、かつ削除対象のZoneには含まれていないこと。

* obshellが正常に実行されていること。

* 削除対象のZone上にユニットが存在しないこと。

## サンプルコード

:::tab

tab タスクの同期的実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
# クラスタのroot@sysのパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# zone3をクラスタから削除します。
client.v1.delete_zone_sync("zone3")
```

tab タスクの非同期実行

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
# クラスタのroot@sysパスワードは '****' です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# zone3をクラスタから削除します。
dag = client.v1.delete_zone("zone3")
# タスク完了を待ちます。
if dag is not None:
    client.v1.wait_dag_succeed(dag-generic_id)
```

:::
