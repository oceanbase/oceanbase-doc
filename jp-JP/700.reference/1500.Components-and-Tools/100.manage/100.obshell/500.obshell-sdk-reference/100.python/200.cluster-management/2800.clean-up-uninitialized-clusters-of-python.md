# 初期化されていないクラスタのクリーンアップ

本記事では、obshell-sdk-pythonを使用して現在のobshellノードをクリーンアップする方法について説明します。クリーンアップされたノードのアイデンティティはSINGLE（どのクラスタにも属さない）に変更されます。リクエストノードがMASTERの場合、クラスタ内のすべてのノードのアイデンティティがSINGLEに変更されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-python.md">obshell-sdk-pythonクイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストしたクライアントに対応するノードが、クリーンアップ対象のクラスタ内にあることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
# 所在クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# クラスタノードをクリーンアップします。
client.v1.agg_clear_uninitialized_agent()
```
