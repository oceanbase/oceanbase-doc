# 未初期化クラスタのクリーンアップ

本記事では、obshell-sdk-pythonを使用して現在のobshellノードをクリーンアップする方法について説明します。クリーンアップされたノードの状態はSINGLE（どのクラスタにも属さない）になります。クリーンアップ対象のノードがMASTERノードの場合、クラスタ内のすべてのノードの状態がSINGLEになります。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md">obshell-sdk-python クイックスタート</a>を参照し、obshell-sdk-pythonの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientが対応するノードがクリーンアップ対象のクラスタ内にあることを確認してください。

## サンプルコード

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# clientインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
# 所在クラスタのroot@sysパスワードは'****'です。
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# クラスタノードをクリーンアップします。
client.v1.agg_clear_uninitialized_agent()
```
