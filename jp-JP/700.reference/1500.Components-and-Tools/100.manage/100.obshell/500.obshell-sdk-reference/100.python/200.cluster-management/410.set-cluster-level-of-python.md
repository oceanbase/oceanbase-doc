# クラスタレベル設定の設定

本記事では、obshell-sdk-pythonを使用して初期化されていないクラスタにクラスタレベル設定を設定する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-python.md'>obshell-sdk-python クイックスタート</a> を参照し、obshell-sdk-pythonの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientに対応するノードが初期化されていないクラスタ内にあることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```python
from obshell import ClientSet

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886)

# クラスタ名、ID、root@sysユーザーのパスワードを設定します。
dag = client.v1.config_obcluster_sync("test-sdk", 11, "****")
```

tab タスクの非同期実行

```python
from obshell import ClientSet

# クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
client = ClientSet("10.10.10.1", 2886)

# クラスタ名、ID、root@sysユーザーのパスワードを設定します。
dag = client.v1.config_obcluster("test-sdk", 11, "****")
# タスク完了を待ちます。
client.v1.wait_dag_succeed(dag.generic_id)
```

:::
