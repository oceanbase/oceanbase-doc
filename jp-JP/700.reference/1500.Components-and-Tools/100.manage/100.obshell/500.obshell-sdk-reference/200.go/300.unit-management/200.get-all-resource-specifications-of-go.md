# すべてのリソース仕様情報を取得する

本記事では、obshell-sdk-goを使用してすべてのリソース仕様情報を取得する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-go.md">obshell-sdk-goクイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.4", 2886, "********")
  if err != nil {
    fmt.Print(err)
    return
  }

  unitConfigs, err := client.V1().GetAllUnitConfigs()
  if err != nil {
    fmt.Print(err)
    return
  }
  fmt.Print(unitConfigs)
}
```
