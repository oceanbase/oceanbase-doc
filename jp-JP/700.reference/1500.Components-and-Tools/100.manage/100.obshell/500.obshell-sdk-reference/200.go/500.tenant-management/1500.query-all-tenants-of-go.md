# すべてのテナントの概要を取得する

本記事では、obshell-sdk-goを使用してクラスタ内のすべてのテナントの概要を取得する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href='../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストを送信するクライアントに対応するノードが初期化済みのクラスタ内にある必要があります。

## サンプルコード

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  tenants, err := client.V1().GetAllTenantOverview()
  if err != nil {
    fmt.Print(err)
    return
  }
  fmt.Printf("tenants' overview: %v\n", tenants)
}
```
