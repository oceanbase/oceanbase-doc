# テナントレプリカの変更

本記事では、obshell-sdk-goを使用して指定したテナントのレプリカ属性を変更する方法について説明します。一括変更も可能です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* テナントが存在し、その状態がNORMALであることを確認してください。

* リクエスト元のクライアントに対応するノードが初期化済みのクラスタ内にあることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```go
package main

import (
    "fmt"

    "github.com/oceanbase/obshell-sdk-go/services"
    "github.com/oceanbase/obshell-sdk-go/services/v1"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
    if err != nil {
        fmt.Print(err)
        return
    }

    req := client.V1().NewModifyTenantReplicasRequest("t1", []v1.ZoneParam{
        {
            Name:           "zone2",
            UnitConfigName: "s2",
        },
    })

    if _, err := client.V1().ModifyTenantReplicasSyncWithRequest(req); err != nil {
        fmt.Print(err)
        return
    }
}
```

tab タスクの非同期実行

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
  "github.com/oceanbase/obshell-sdk-go/services/v1"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  req := client.V1().NewModifyTenantReplicasRequest("t1", []v1.ZoneParam{
    {
      Name:           "zone2",
      UnitConfigName: "s2",
    },
  })

  dag, err := client.V1().ModifyTenantReplicasWithRequest(req)
  if err != nil {
    fmt.Print(err)
    return
  }

  // タスクが成功するまで待機します。
  if dag != nil && dag.GenericDTO != nil {
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
      fmt.Print(err)
      return
    }
  }
}
```
