# テナントの作成

本記事では、obshell-sdk-goを使用してテナントを作成する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストのクライアントに対応するノードが初期化済みのクラスタ内にある必要があります。

## サンプルコード

:::tab

tab タスクの同時実行

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
  "github.com/oceanbase/obshell-sdk-go/services/v1"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  req := client.V1().NewCreateTenantRequest("t1", []v1.ZoneParam{
    {
      Name:           "zone1",
      ReplicaType:    "FULL",
      UnitConfigName: "s1",
      UnitNum:        1,
    },
  })

  if _, err = client.V1().CreateTenantSyncWithRequest(req); err != nil {
    fmt.Print(err)
    return
  }
}
```

タブ テナントの非同期実行

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
  "github.com/oceanbase/obshell-sdk-go/services/v1"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  req := client.V1().NewCreateTenantRequest("t1", []v1.ZoneParam{
    {
      Name:           "zone1",
      ReplicaType:    "FULL",
      UnitConfigName: "s1",
      UnitNum:        1,
    },
  })

  dag, err := client.V1().CreateTenantWithRequest(req)
  if err != nil {
    fmt.Print(err)
    return
  }

  // タスクが成功するまで待機します。
  if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
    fmt.Print(err)
    return
  }
}
```
