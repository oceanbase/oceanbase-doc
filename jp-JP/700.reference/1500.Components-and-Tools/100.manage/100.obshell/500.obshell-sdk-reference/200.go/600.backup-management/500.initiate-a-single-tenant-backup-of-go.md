# 単一テナントのバックアップを開始する

本記事では、obshell-sdk-goを使用して単一テナントのバックアップを行う方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href('../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストを送信するクライアントの対応ノードは、初期化済みのクラスタ内に存在している必要があります。

## サンプルコード

```go
package main

import (
  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    panic(err)
  }

  request := client.V1().NewTenantBackupRequest("tenant2")
  request.SetBackupMode("full")
  _, err = client.V1().TenantBackupSyncWithRequest(request)
  if err != nil {
    panic(err)
  }
}
```
