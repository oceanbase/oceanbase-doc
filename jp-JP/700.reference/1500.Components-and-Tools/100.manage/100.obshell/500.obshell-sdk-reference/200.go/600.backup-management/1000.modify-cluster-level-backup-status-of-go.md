# クラスタレベルのバックアップ状態を変更する

本記事では、obshell-sdk-goを使用してクラスタレベルのバックアップ状態を変更する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href='../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストを送信するクライアントの対応ノードが初期化済みのクラスタ内にある必要があります。

## サンプルコード

```go
package main

import (
  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
      panic(err)
  }

  request := client.V1().NewClusterBackupStatusPatchRequest()
  request.SetStatus("canceled")
  err = client.V1().ClusterBackupStatusWithPatchRequest(request)
  if err != nil {
    panic(err)
  }
}
```
