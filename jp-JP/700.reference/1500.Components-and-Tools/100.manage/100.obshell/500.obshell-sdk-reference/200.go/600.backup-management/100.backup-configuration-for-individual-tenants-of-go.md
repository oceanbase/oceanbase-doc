# 単一テナントのバックアップ設定を設定する

本記事では、obshell-sdk-goを使用してテナントレベルのバックアップ設定を行う方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientに対応するノードが初期化済みのクラスタ内にある必要があります。

## サンプルコード

```go
package main

import (
  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // clientインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    panic(err)
  }

  request := client.V1().NewTenantBackupConfigPostRequest("tenant2", "file:///data/backup/data", "file:///data/backup/archive")
  request.SetLogArchiveConcurrency(50)
  _, err = client.V1().TenantBackupConfigSyncWithRequest(request)
  if err != nil {
    panic(err)
  }
}
```
