# クラスタレベルのバックアップ設定を更新する

本記事では、obshell-sdk-goを使用してクラスタレベルのバックアップ設定を更新する方法について説明します。

クラスタレベルのバックアップ設定を更新する場合と[クラスタレベルのバックアップ設定を設定する](200.backup-configuration-for-cluster-of-go.md)場合の違いは、`backup_base_uri`を設定しなくてもよい点です。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code>と<code>piece_switch_interval</code>を設定する必要がある場合でも、<code>backup_base_uri</code>は設定する必要があります。これら3つは紐づけられており、個別に増分で設定することはサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使い方を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientに対応するノードが、初期化済みのクラスタ内にある必要があります。

## サンプルコード

```go
package main

import (
  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // clientインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    panic(err)
  }

  request := client.V1().NewClusterBackupConfigPatchRequest()
  request.SetLogArchiveConcurrency(99)
  _, err = client.V1().ClusterBackupConfigSyncWithRequest(request)
  if err != nil {
    panic(err)
  }
}
```
