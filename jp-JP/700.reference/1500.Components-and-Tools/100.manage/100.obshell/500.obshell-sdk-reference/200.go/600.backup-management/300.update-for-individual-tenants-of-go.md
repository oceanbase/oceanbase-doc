# 単一テナントのバックアップ設定を更新する

本記事では、obshell-sdk-goを使用して特定のテナントのバックアップ設定を更新する方法について説明します。

単一テナントのバックアップ設定を更新する場合の使用方法は、[単一テナントのバックアップ設定を設定する](100.backup-configuration-for-individual-tenants-of-go.md)と異なり、`data_base_uri`と`archive_base_uri`は設定しなくてもかまいません。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code>と<code>piece_switch_interval</code>を設定する必要がある場合でも、<code>archive_base_uri</code>は設定する必要があります。これら3つは紐づけられており、増分設定はサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientに対応するノードが初期化済みのクラスタ内にあることを確認してください。

## サンプルコード

```go
package main

import (
  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // clientインスタンスを作成します。ノードのアドレスは'10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    panic(err)
  }

  request := client.V1().NewTenantBackupConfigPatchRequest("tenant2")
  request.SetDeletePolicy("", "3d")
  _, err = client.V1().TenantBackupConfigSyncWithRequest(request)
  if err != nil {
    panic(err)
  }
}
```
