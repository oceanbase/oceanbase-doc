# 単一テナントのバックアップ設定の更新

本記事では、obshell-sdk-goを使用して特定のテナントのバックアップ設定を更新する方法について説明します。

単一テナントのバックアップ設定を更新する際の使用方法は、[単一テナントのバックアップ設定の設定](100.backup-configuration-for-individual-tenants-of-go.md)と異なり、`data_base_uri`と`archive_base_uri`は設定しなくても構いません。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>binding</code>と<code>piece_switch_interval</code>を設定する場合でも、<code>archive_base_uri</code>は依然として設定が必要です。これは、3つのパラメータが結びついており、増分設定はサポートされていないためです。</p>
</main>

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは、<a href="../100.quickstart-of-go.md'>obshell-sdk-goクイックスタート</a>を参照し、obshell-sdk-goの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストのクライアントに対応するノードは、初期化済みのクラスタ内に存在する必要があります。

## サンプルコード

```go
package main

import (
  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // Create a client instance with the node address '10.10.10.1' and port 2886.
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    panic(err)
  }

  request := client.V1().NewTenantBackupConfigPatchRequest("tenant2")
  request.SetDeletePolicy("", "3d")
  _, err = client.V1().TenantBackupConfigSyncWithRequest(request)
  if err != nil {
    panic(err)
  }
}
```
