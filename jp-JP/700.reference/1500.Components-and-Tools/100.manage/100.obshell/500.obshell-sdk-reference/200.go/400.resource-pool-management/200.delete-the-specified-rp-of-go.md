# リソースプールの削除

本記事では、obshell-sdk-goを使用して、使用されていないリソースプールを削除する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientが対応するノードは、初期化済みのクラスタ内に存在している必要があります。

* 削除対象の指定したリソースプールが使用されていないことを確認してください。

## サンプルコード

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  if err := client.V1().DropResourcePool("p1"); err != nil {
    fmt.Print(err)
    return
  }
}
```
