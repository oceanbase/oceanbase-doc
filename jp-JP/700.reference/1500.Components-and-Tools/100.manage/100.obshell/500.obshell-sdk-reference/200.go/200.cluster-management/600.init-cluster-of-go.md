# クラスタの初期化

本記事では、obshell-sdk-goを使用してクラスタを初期化する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-go.md'>obshell-sdk-goクイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストするクライアントに対応するノードが、初期化対象のクラスタ内にあることを確認してください。

## サンプルコード

:::tab

タブのタスクを同期して実行する

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    // 所属クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタを初期化します。
    req := client.V1().NewInitRequest()
    if _, err = client.V1().InitSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

タブ：タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    // 所属クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタを初期化します。
    req := client.V1().NewInitRequest()
    dag, err := client.V1().InitWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するまで待機します
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```

:::
