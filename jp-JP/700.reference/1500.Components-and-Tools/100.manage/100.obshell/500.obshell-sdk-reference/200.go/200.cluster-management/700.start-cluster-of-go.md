# クラスタの起動

本記事では、obshell-sdk-goを使用してクラスタを起動する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientに対応するノードが、起動対象のクラスタ内にあることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
    "github.com/oceanbase/obshell-sdk-go/services/v1"
)

func main() {
    // clientインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタ内のすべてのOBServerノードを起動します。
    req := client.V1().NewStartRequest(v1.SCOPE_GLOBAL)
    if _, err = client.V1().StartSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

tab タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
    "github.com/oceanbase/obshell-sdk-go/services/v1"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタ内のすべてのOBServerノードを起動します。
    req := client.V1().NewStartRequest(v1.SCOPE_GLOBAL)
    dag, err := client.V1().StartWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するまで待機します。
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```

:::
