# クラスタの乗っ取り

本記事では、obshell-sdk-goを使用してクラスタを乗っ取る方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

クラスタを乗っ取る前に、必要なobshellがすべてのマシンで解凍され、インストールされていることを確認してください。手動で解凍するか、obshell-sdk-goを使用して解凍・インストールすることもできます。obshell-sdk-goを使用した解凍・インストールの操作については、[obshellのインストール](../110.obshell-management/300.install-obshell-of-go.md)を参照してください。

## サンプルコード

```go
func main() {
    ips := []string{
        "10.10.10.1",
        "10.10.10.2",
        "10.10.10.3",
    }

    workDir := "/data/ob" // OceanBaseデータベースの作業ディレクトリ
    nodeConfigs := make([]util.NodeConfig, 0)
    for _, ip := range ips {
        nodeConfigs = append(nodeConfigs, util.NewNodeConfig(ip, workDir, 2886))
    }

    // パラメータ説明：
    // password: 乗っ取るクラスタのroot@sysのパスワード
    // configs: ノードの設定情報
    if err := util.Takeover("pwd", nodeConfigs...); err != nil {
        panic(err)
    }
}
```
