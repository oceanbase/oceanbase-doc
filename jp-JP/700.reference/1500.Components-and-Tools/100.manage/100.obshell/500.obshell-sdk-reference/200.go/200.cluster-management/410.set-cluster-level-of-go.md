# クラスタレベル設定の設定

本記事では、obshell-sdk-goを使用して初期化されていないクラスタにクラスタレベル設定を設定する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientに対応するノードが初期化されていないクラスタ内にあることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタ名、ID、root@sysユーザーのパスワードを設定します。
    req := client.V1().NewConfigObclusterRequest("obshell-sdk-test", 12358).SetRootPwd("1111")
    if _, err = client.V1().ConfigObclusterSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

tab タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタ名、ID、root@sysユーザーのパスワードを設定します。
    req := client.V1().NewConfigObclusterRequest("obshell-sdk-test", 12358).SetRootPwd("1111")
    dag, err := client.V1().ConfigObclusterWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するまで待機します。
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```

:::
