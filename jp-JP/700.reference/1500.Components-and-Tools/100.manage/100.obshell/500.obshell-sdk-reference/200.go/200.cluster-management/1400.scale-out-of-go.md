# クラスタの拡張

本記事では、obshell-sdk-goを使用してクラスタを拡張する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意点

クラスタの拡張を行う前に、以下の要件に注意してください：

* リクエスト元のクライアントに対応するノードが、拡張対象のクラスタ内に存在していること。

* obshellが正常に実行されていること。

* クラスタに追加する拡張ノードは、これまで一度もどのクラスタにも参加したことがないこと。

## サンプルコード

:::tab

tab タスクの同期的実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    configs := map[string]string{
        "datafile_size": "24G", "log_disk_size": "24G",
        "cpu_count": "16", "memory_limit": "16G", "system_memory": "8G",
        "enable_syslog_recycle": "true", "enable_syslog_wf": "true"}
    // クラスタにノード '10.10.10.4:2886' を追加します。OBServerノードはzone3に配置され、configsで設定されます。
    req := client.V1().NewScaleOutRequest("10.10.10.4", 2886, "zone3", configs)
    if _, err = client.V1().ScaleOutSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

tab タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    configs := map[string]string{
        "datafile_size": "24G", "log_disk_size": "24G",
        "cpu_count": "16", "memory_limit": "16G", "system_memory": "8G",
        "enable_syslog_recycle": "true", "enable_syslog_wf": "true"}
    // クラスタにノード '10.10.10.4:2886' を追加します。OBServerノードはzone3に配置され、configsで設定されます。
    req := client.V1().NewScaleOutRequest("10.10.10.4", 2886, "zone3", configs)
    dag, err := client.V1().ScaleOutWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するまで待機します。
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```
