# 未初期化クラスタのクリーンアップ

本記事では、obshell-sdk-goを使用して現在のobshellノードをクリーンアップする方法について説明します。クリーンアップされたノードの状態はSINGLE（どのクラスタにも属さない）になります。リクエストノードがMASTERの場合、クラスタ内のすべてのノードの状態もSINGLEになります。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md">obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエスト元のclientが対応するノードがクリーンアップ対象のクラスタ内にあることを確認してください。

## サンプルコード

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // clientインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタノードをクリーンアップします。
    err = client.V1().Clear()
    if err != nil {
        panic(err)
    }
}
```
