# 初期化されていないクラスタのクリーンアップ

本記事では、obshell-sdk-goを使用して現在のobshellノードをクリーンアップする方法について説明します。クリーンアップされたノードのアイデンティティはSINGLE（どのクラスタにも属さない）に変更されます。リクエストノードがMASTERの場合、クラスタ内のすべてのノードのアイデンティティがSINGLEに変更されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-go.md">obshell-sdk-goクイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストクライアントに対応するノードが、クリーンアップ対象のクラスタ内にあることを確認してください。

## サンプルコード

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタノードをクリーンアップします。
    err = client.V1().Clear()
    if err != nil {
        panic(err)
    }
}
```
