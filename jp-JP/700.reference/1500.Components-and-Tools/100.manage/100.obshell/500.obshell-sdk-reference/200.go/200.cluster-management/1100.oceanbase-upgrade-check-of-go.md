# OceanBaseデータベースのアップグレードチェック

本記事では、obshell-sdk-goを使用してOceanBaseデータベースのアップグレード前チェックを実行する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に動作していることを確認してください。

* リクエスト元のclientが対応するノードがアップグレード対象のクラスタ内にあることを確認してください。

## サンプルコード

:::tab

tab タスクの同期的実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // clientインスタンスを作成。ノードアドレスは'10.10.10.1'、ポートは2886。
    // 所在クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタでアップグレード前チェックを実行。
    req := client.V1().NewUpgradeObCheckRequest("4.2.2.0", "xxx.el7")
    if _, err = client.V1().UpgradeObCheckSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

tab タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタでアップグレード前チェックを実行します。
    req := client.V1().NewUpgradeObCheckRequest("4.2.2.0", "xxx.el7")
    dag, err := client.V1().UpgradeObCheckWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するまで待機します。
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```
