# OceanBaseデータベースのアップグレードチェック

本記事では、obshell-sdk-goを使用してOceanBaseデータベースのアップグレード前にチェックを実行する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-go.md">obshell-sdk-goクイックスタート</a> を参照して、obshell-sdk-goの使用方法を確認することを推奨します。</p>
</main>

## 注意事項

* obshellが正常に動作していることを確認してください。

* リクエストされたクライアントに対応するノードが、アップグレード対象のクラスタ内にあることを確認してください。

## サンプルコード

:::tab

タブ：タスクの同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    // 所属クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタでのアップグレード実行前のチェックを実行します。
    req := client.V1().NewUpgradeObCheckRequest("4.2.2.0", "xxx.el7")
    if _, err = client.V1().UpgradeObCheckSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

タブ タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    // 所属クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // クラスタの実行アップグレード前チェック。
    req := client.V1().NewUpgradeObCheckRequest("4.2.2.0", "xxx.el7")
    dag, err := client.V1().UpgradeObCheckWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するまで待機
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```

:::
