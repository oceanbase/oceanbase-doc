# クラスタ初期化前にノードを追加する

本記事では、obshell-sdk-goを使用して、初期化されていないクラスタにノードを追加する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

初期化されていないクラスタにノードを追加する前に、以下の要件に注意してください：

* リクエスト元のclientに対応するノードが、初期化対象のクラスタ内に存在している必要があります（自己追加は除く）。

* 追加するノードが、これまでにどのクラスタにも参加したことがないことを確認する必要があります。

* 自身のノードを追加する場合、そのノードがこれまでにどのクラスタにも参加したことがなく、かつobshellが正常に実行されていることを確認する必要があります。

## サンプルコード

以下のコードは、`10.10.10.1` マシンに自身のノードを追加してMasterとし、さらに別のノード（`10.10.10.2`）を追加してFollowerとします。

:::tab

tab タスクの同時実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // clientインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    client, err := services.NewClient("10.10.10.1", 2886)
    if err != nil {
        panic(err)
    }

    // 自身にjoinします。
    req := client.V1().NewJoinRequest("10.10.10.1", 2886, "zone1")
    if _, err = client.V1().JoinSyncWithRequest(req); err != nil {
        panic(err)
    }

    // '10.10.10.1' が存在するクラスタに、ノード '10.10.10.2:2886' を追加します。
    req = client.V1().NewJoinRequest("10.10.10.2", 2886, "zone1")
    if _, err = client.V1().JoinSyncWithRequest(req); err != nil {
        panic(err)
    }
}
```

タブ タスクの非同期実行

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは 2886 です。
    client, err := services.NewClient("10.10.10.1", 2886)
    if err != nil {
        panic(err)
    }

    // 自身を join します。
    req := client.V1().NewJoinRequest("10.10.10.1", 2886, "zone1")
    dag, err := client.V1().JoinWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するのを待ちます。
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }

    // '10.10.10.1' が存在するクラスタに、ノード '10.10.10.2:2886' を追加します。
    req = client.V1().NewJoinRequest("10.10.10.2", 2886, "zone1")
    dag, err = client.V1().JoinWithRequest(req)
    if err != nil {
        panic(err)
    }
    // タスクが成功するのを待ちます。
    if  _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
        panic(err)
    }
}
```
