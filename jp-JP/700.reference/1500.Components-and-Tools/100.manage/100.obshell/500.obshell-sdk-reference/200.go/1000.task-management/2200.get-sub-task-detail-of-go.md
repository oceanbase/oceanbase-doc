# SubTaskの詳細情報を取得する

本記事では、obshell-sdk-goを使用してSubTaskの詳細情報を取得する方法について説明します。SubTaskはNodeのメンバーであり、1つのNodeは1つ以上のSubTaskで構成されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```go
package main

import (
    "fmt"

    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // generic_idが20194912107080886のSubTaskの詳細情報を取得します。
    subTask, err := client.V1().GetSubTask("20194912107080886")
    if err != nil {
        panic(err)
    }
    fmt.Print(subTask)
}
```
