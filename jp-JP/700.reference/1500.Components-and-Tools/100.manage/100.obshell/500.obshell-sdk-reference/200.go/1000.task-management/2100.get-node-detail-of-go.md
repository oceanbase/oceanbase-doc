# Nodeの詳細情報を取得する

本記事では、obshell-sdk-goを使用してNodeの詳細情報を取得する方法について説明します。NodeはDAG（タスク）のメンバーであり、1つのDAGは1つ以上のNodeで構成されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href='../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```go
package main

import (
    "fmt"

    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
    // 所在クラスタのroot@sysパスワードは '****' です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // generic_id が20194912107080886 の Nodeの詳細情報を取得します。
    node, err := client.V1().GetNode("20194912107080886")
    if err != nil {
        panic(err)
    }
    fmt.Print(node)
}
```
