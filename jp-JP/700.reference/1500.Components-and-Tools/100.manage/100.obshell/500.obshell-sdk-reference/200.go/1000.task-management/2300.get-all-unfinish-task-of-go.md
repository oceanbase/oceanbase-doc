# すべての未完了タスクの照会

本記事では、obshell-sdk-goを使用してすべての未完了タスクの詳細情報を取得する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まずは <a href="../100.quickstart-of-go.md">obshell-sdk-goクイックスタート</a> を参照して、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

obshellが正常に実行されていることを確認してください。

## サンプルコード

```go
package main

import (
    "fmt"

    "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
    // clientインスタンスを作成します。ノードアドレスは'10.10.10.1'、ポートは2886です。
    // 所属クラスタのroot@sysパスワードは'****'です。
    client, err := services.NewClientWithPassword("10.10.10.1", 2886, "***")
    if err != nil {
        panic(err)
    }

    // すべての未完了タスクの詳細情報を取得します。
    dags, err := client.V1().GetUnfinishedDags()
    if err != nil {
        panic(err)
    }
    fmt.Print(dags)
}
```
