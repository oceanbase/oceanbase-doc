# ごみ箱のテナントを削除する

本記事では、obshell-sdk-goを使用してごみ箱内のテナントを削除する方法について説明します。対応するリソースプールも解放されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使用方法を確認することをお勧めします。</p>
</main>

## 注意事項

* obshellが正常に実行されていることを確認してください。

* リクエストを送信するクライアントの対応ノードは、初期化済みのクラスタ内にある必要があります。

## サンプルコード

:::tab

tab タスクの同時実行

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  req := client.V1().NewPurgeRecyclebinTenantRequest("t1")

  if _, err := client.V1().PurgeRecyclebinTenantSyncWithRequest(req); err != nil {
    fmt.Print(err)
    return
  }
}
```

tab タスクの非同期実行

```go
package main

import (
  "fmt"

  "github.com/oceanbase/obshell-sdk-go/services"
)

func main() {
  // クライアントインスタンスを作成します。ノードのアドレスは '10.10.10.1'、ポートは2886です。
  client, err := services.NewClientWithPassword("10.10.10.1", 2886, "****")
  if err != nil {
    fmt.Print(err)
    return
  }

  req := client.V1().NewPurgeRecyclebinTenantRequest("t1")

  dag, err := client.V1().PurgeRecyclebinTenantWithRequest(req)
  if err != nil {
    fmt.Print(err)
    return
  }

  if dag != nil && dag.GenericDTO != nil {
    // タスクが成功するまで待機します。
    if _, err = client.V1().WaitDagSucceed(dag.GenericID); err != nil {
      fmt.Print(err)
      return
    }
  }
}
```
