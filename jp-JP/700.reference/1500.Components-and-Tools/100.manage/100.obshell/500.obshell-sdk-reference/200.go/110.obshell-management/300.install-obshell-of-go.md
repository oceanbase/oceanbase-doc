# obshellのインストール

本記事では、obshell-sdk-goを使用して各ノードにobshell RPMパッケージを解凍・インストールする方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href='../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a>を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

obshellをインストールする前に、必要なRPMパッケージをマシンにダウンロードしておいてください。手動でダウンロードするか、obshell-sdk-goを使用してダウンロードすることもできます。obshell-sdk-goを使用したダウンロードの詳細については、[RPMパッケージのダウンロード](../1500.other-api/400.download-rpm-package-of-go.md)を参照してください。

## サンプルコード

```go
func main() {
    ips := []string{
        "10.10.10.1",
        "10.10.10.2",
        "10.10.10.3",
    }

    workDir := "/data/ob" // OceanBaseデータベースの作業ディレクトリ
    nodeConfigs := make([]util.NodeConfig, 0)
    for _, ip := range ips {
        nodeConfigs = append(nodeConfigs, util.NewNodeConfig(ip, workDir, 2886))
    }

    if err := util.InstallObshell("/tmp/obshell-4.2.4.2-12024102115.el7.x86_64.rpm", nodeConfigs...); err != nil {
        panic(err)
    }
}
```
