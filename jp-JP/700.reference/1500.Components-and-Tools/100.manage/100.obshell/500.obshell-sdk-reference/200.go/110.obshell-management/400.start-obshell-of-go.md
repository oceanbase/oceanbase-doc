# obshellの起動

本記事では、obshell-sdk-goを使用してobshellプロセスを起動する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>まず、<a href="../100.quickstart-of-go.md'>obshell-sdk-go クイックスタート</a> を参照し、obshell-sdk-goの使い方を確認することをお勧めします。</p>
</main>

## 注意事項

obshellを起動する前に、すべてのノードの作業ディレクトリにobshellがインストールされていることを確認してください。RPMを手動でダウンロードして解凍してインストールするか、obshell-sdk-goを使用してノードを初期化することもできます。初期化プロセスでobshellがインストールされます。obshell-sdk-goを使用したノード初期化の詳細については、[ノードの初期化](../200.cluster-management/550.initialize-node-of-go.md)を参照してください。

## サンプルコード

```go
package main

import (
    "github.com/oceanbase/obshell-sdk-go/util"
)

func startObshell() error {
    ips := []string{
        "10.10.10.1",
        "10.10.10.2",
        "10.10.10.3",
    }

    workDir := "/data/ob" // OceanBaseデータベースの作業ディレクトリ
    nodeConfigs := make([]util.NodeConfig, 0)
    for _, ip := range ips {
        nodeConfigs = append(nodeConfigs, util.NewNodeConfig(ip, workDir, 2886))
    }

    // obshellの起動
    return util.StartObshell(nodeConfigs...)
}
```
