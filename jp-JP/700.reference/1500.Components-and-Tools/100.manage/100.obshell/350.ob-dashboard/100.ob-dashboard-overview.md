# obshellダッシュボード

obshellダッシュボードは、obshellが提供するWebベースのインタラクティブな管理ページであり、OceanBaseクラスタおよびテナントリソースの管理を専門に設計されています。主要なリソースとパフォーマンス指標の監視機能を備えており、ユーザーがOceanBaseクラスタを効率的に管理できるよう支援します。

obshellダッシュボードサービスは、obshellプロセスに完全に統合されており、ユーザーはobshellがデプロイされた任意のサービスアドレスにアクセスすることでOceanBaseクラスタを管理できます。この設計は管理プロセスを簡素化するだけでなく、非常に低いリソース消費を保証し、ユーザーにシンプルで使いやすい管理体験を提供します。

## 特徴

obshellダッシュボードは現在、OceanBaseクラスタ管理の以下の機能をサポートしています：

* クラスタ管理：[クラスタ情報](200.ob-dashboard-cluster-overview.md)を表示します。これには、状態情報、リソース消費量、トポロジー構造などの主要な情報、および[クラスタ管理](300.ob-dashboard-cluster.md)、[パラメータ管理](500.ob-dashboard-parameter.md)などの機能が含まれます。

* テナント管理：クラスタ内のテナントおよびテナント内のデータベース、ユーザー、パラメータを管理します。詳細については、[テナント管理](400.ob-dashboard-tenant/100.ob-dashboard-tenant.md)の章を参照してください。

* ソフトウェアパッケージ管理：ソフトウェアパッケージをアップロードし、クラスタとobshellをアップグレードするには、対象バージョンのソフトウェアパッケージがアップロードされている必要があります。具体的な操作については、[ソフトウェアパッケージ管理](600.ob-dashboard-package.md)を参照してください。

## ログインとログアウト

obshell V4.3.0.0以降では、グラフィカルインターフェースを使用したインタラクティブなクラスタ管理がサポートされています。obshellが正常にインストールされた後、obshellノードのIPアドレスとobshellポートを使用してobshellダッシュボード（obshellインタラクティブ管理ページ）にアクセスできます。アクセス時は、デフォルトでsysテナントのrootユーザーでログインし、パスワードはOceanBaseクラスタをデプロイした際に設定されたroot@sysユーザーのパスワードです。root@sysのパスワードが空の場合は、**ログイン**ボタンを直接クリックしてログインできます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>ノードのパブリックIPアドレスを使用する必要があります。</p>
</main>

obshellダッシュボードコンソールにログインした後、ページ右上の<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-overview-01.png" alt="User" style="height: 20px;"></span>アイコンにカーソルを合わせて、表示される**ログアウト**をクリックし、ポップアップウィンドウで**OK**をクリックするとログアウトできます。

## バージョンの確認

obshellダッシュボードコンソールにログインした後、ページ右上の**ヘルプ**>**obshellダッシュボードについて**をクリックすると、obshellダッシュボードのバージョンを確認できます。
