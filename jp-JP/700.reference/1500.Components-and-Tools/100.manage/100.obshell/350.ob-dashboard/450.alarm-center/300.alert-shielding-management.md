# アラートマスキングの管理

## マスキングの新規作成

### 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">アラートセンター</UI-TERM>** を選択します。

3. **<UI-TERM key="obcloud-console.Alarm.Suppress.AlarmMask">アラートのブロック</UI-TERM>** タブをクリックします。

4. **<UI-TERM key="ocp-v2.page.Alarm.AlarmMask">アラートの無効化</UI-TERM>** タブで、**新規作成** をクリックします。

5. **<UI-TERM key="obcloud-console.Alarm.Suppress.ShieldingCondition">抑止条件</UI-TERM>** ページでマスキング条件を設定します。

   | パラメータ  | 説明  |
   |-------|------|
   | マスキング対象タイプ | 実際のニーズに応じて、マスキング対象のドロップダウンボックスから具体的なアラート対象を選択します。<ul><li>マスキング対象タイプが obcluster の場合、マスキング対象としてターゲットクラスタを選択する必要があります。</li><li>マスキング対象タイプが obtenant の場合、マスキング対象として対応するターゲットクラスタとターゲットテナント（全テナントまたは指定したターゲットテナント）を選択する必要があります。</li><li>マスキング対象タイプが observer の場合、マスキング対象として対応するターゲットクラスタとターゲットホスト（全ホストまたは指定されたIPアドレスのホスト）を選択する必要があります。 |
   | マスキングルール | 対応するドロップダウンボックスからマスキングしたいアラートを選択します。複数選択可能です。アラートルールは **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">アラートルール</UI-TERM>** タブのルールリストと一致しています。詳細はそのタブで確認できます。 |
   | タグ | 指定したメトリクスのマスキングをサポートします。タグのマッチング条件に基づいてアラートをマスキングし、値のマッチングまたは正規表現をサポートします。すべての条件を満たした場合にのみアラートがマスキングされます。オプションです。 |
   | マスキング終了時間 | アラートマスキングの終了時間を設定します。終了時間までに、マスキングされたアラートは送信されません。必須項目です。マスキング終了時間の設定方法は以下の2通りです：<ul><li>ボックス内をクリックして、終了時間をカスタマイズできます。</li><li>ボックス後ろの時間をクリックすることもできます。例えば、「6時間」をクリックすると、システムが現在時刻に6時間を加算してボックスに入力します。</li></ul> |
   | 備考 | マスキングルールの説明を追加することができます。これにより、後の参照や再利用が容易になります。必須項目です。 |

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>特定のアラートをマスキングする必要がある場合、<b>アラートイベント</b>ページのイベントリスト右側の<b>マスキング</b>ボタンを使用することをお勧めします。これにより、<b>アラートマスキング</b>タブの<b>マスキング条件</b>ページに自動的にジャンプし、そのアラートイベントに関連付けられたマスキング対象タイプ、マスキングルール、タグ情報が自動的に入力されます。あとはアラートマスキングの終了時間を設定し、備考を追加するだけで、該当するアラートを正常にマスキングできます。</p>
   </main>

   <!-- ![マスク条件](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-01.png) -->

6. **<UI-TERM key="obcloud-console.ObClawChatView.ObClawAssistantMessageActions.Submit">送信</UI-TERM>** をクリックします。システムは **<UI-TERM key="ocp-v2.Alarm.Shield.MaskList">ブロックリスト</UI-TERM>** を返し、リストに新しいデータ、つまり新規作成したマスキングが追加されます。

## マスキングの編集

このセクションでは、既に作成されたアラートマスキング条件を編集する方法について説明します。

### 前提条件

マスキングリストに変更が必要なマスキング情報が存在します。

### 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="oms-community.SystemParam.contants.AlertCenter">アラートセンター</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.page.Alarm.AlarmMask">アラートの無効化</UI-TERM>**タブをクリックします。

4. **<UI-TERM key="obcloud-console.Alarm.Suppress.AlarmMask">アラートのブロック</UI-TERM>**タブの検索エリアに検索条件を入力し、マスキングを正確に検索できます。**<UI-TERM key="ocp-v2.Alarm.Shield.MaskList">ブロックリスト</UI-TERM>**には、検索条件に一致するすべてのマスキング情報が返されます。

5. 編集するマスキングを選択し、対応する**<UI-TERM key="odc.Secure.MaskingAlgorithm.Operation">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Edit">編集</UI-TERM>**をクリックします。

   <!-- ![編集](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-02.png) -->

6. **<UI-TERM key="obcloud-console.Alarm.Suppress.ShieldingCondition">抑止条件</UI-TERM>**ページに移動すると、該当するマスキングのマスキング条件を編集できます。マスキングオブジェクトタイプ、マスキングオブジェクト、アラートルール、タグ、マスキング時間、備考などを設定できます。具体的なパラメータは、上記の[新規作成](#マスキングの新規作成)のパラメータ説明を参照して設定してください。

   <!-- ![マスク条件](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-03.png) -->

7. **<UI-TERM key="OMS.ViewObjectByWildCard.components.SecondContent.Submit">提出する</UI-TERM>**をクリックすると、マスキングの編集が完了します。

## マスキングの解除

このセクションでは、作成したアラートマスキングを解除する方法について説明します。

### 前提条件

マスキングが既に作成されていること。

### 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="oms-community.layout.constants.AlertCenter">アラートセンター</UI-TERM>**を選択します。

3. **<UI-TERM key="obcloud-console.Alarm.Suppress.AlarmMask">アラートのブロック</UI-TERM>**タブをクリックします。

4. **<UI-TERM key="obcloud-console.Alarm.Suppress.AlarmMask">アラートのブロック</UI-TERM>**タブの検索エリアに検索条件を入力し、マスキングを正確に検索できます。**<UI-TERM key="ocp-v2.Alarm.Shield.MaskList">ブロックリスト</UI-TERM>**には、検索条件に一致するすべてのマスキング情報が返されます。

5. 解除するマスキングを選択し、対応する**<UI-TERM key="ocp-v2.Component.ZoneList.Operation">操作</UI-TERM>**列の**マスキング解除**をクリックします。

   <!-- ![ブロックの解除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-04.png) -->

6. 表示された確認ダイアログで**<UI-TERM key="ocp-v2.Cluster.Component.DisassociationDrawer.Release">解除する</UI-TERM>**をクリックすると、マスキングの解除が完了します。

   <!-- ![クリックで解除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-05.png) -->

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>マスキングを解除すると元に戻りませんので、ご注意ください。</p>
   </main>

7. マスキングを解除すると、マスキングリストにおけるマスキングオブジェクトの状態は**アクティブ**から**<UI-TERM key="obcloud-console.ApiKeyManagement.hooks.columns.Expired">期限切れ</UI-TERM>**に変わります。操作列の**<UI-TERM key="odc.components.TriggerPage.Editing">編集</UI-TERM>**および**マスキング解除**ボタンは灰色になり、以降の操作はできなくなります。

   <!-- ![マスク後のページ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-06.png) -->
