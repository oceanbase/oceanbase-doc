# アラートのブロックを管理する

## シャドウイングの新規作成

### 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで**アラートセンター**を選択します。

3. **アラートシャドウイング**タブをクリックします。

4. **アラートシャドウイング**タブで、**新規作成**をクリックします。

5. **シャドウイング条件**ページでシャドウイング条件を設定します。

   | パラメータ  | 説明  |
   |-------|------|
   | ブロック対象タイプ | 実際のニーズに応じて、ブロック対象のドロップダウンリストから具体的なアラート対象を選択します。<ul><li>ブロック対象タイプがobclusterの場合、ブロック対象としてターゲットクラスタを選択する必要があります。</li><li>ブロック対象タイプがobtenantの場合、ブロック対象として対応するターゲットクラスタとターゲットテナント（全テナントまたは指定したターゲットテナント）を選択する必要があります。</li><li>ブロック対象タイプがobserverの場合、ブロック対象として対応するターゲットクラスタとターゲットホスト（全ホストまたは指定されたIPアドレスのホスト）を選択する必要があります。 |
   | ブロックするアラートルール | 対応するドロップダウンリストからブロックするアラートを選択します。複数選択可能です。アラートルールは、**アラートルール**タブのルールリストと一致しています。詳細はそのタブで確認できます。 |
   | タグ | 指定したメトリクスに対するブロックをサポートします。タグのマッチング条件に基づいてアラートをブロックし、値のマッチングまたは正規表現をサポートします。すべての条件を満たした場合にのみ、アラートがブロックされます。オプションです。 |
   | ブロック終了時間 | アラートブロックの終了時間を設定します。終了時間まで、ブロックされたアラートは送信されません。必須項目です。ブロック終了時間の設定方法は以下の2通りです：<ul><li>ボックス内をクリックして、終了時間をカスタマイズできます。</li><li>または、ボックス後ろの時間をクリックすることもできます。例えば、「6時間」をクリックすると、システムが現在時刻に6時間を加算してボックスに入力します。</li></ul> |
   | 備考 | ブロックルールの説明を追加することができます。これにより、後の参照や識別、再利用が容易になります。必須項目です。 |

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>特定のアラートをシャドウイングする場合は、<b>アラートイベント</b>ページのイベントリスト右側の<b>シャドウイング</b>ボタンを使用することを推奨します。これにより、<b>アラートシャドウイング</b>タブの<b>シャドウイング条件</b>ページに自動的に移動し、そのアラートイベントに関連付けられたシャドウイング対象タイプ、アラートルール、タグ情報が自動的に入力されます。あとは、アラートシャドウイングの終了時間と備考を設定するだけで、該当するアラートを正常にシャドウイングできます。</p>
   </main>

   <!-- ![シャドウイング条件](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-01.png) -->

6. **送信**をクリックします。システムは**シャドウイングリスト**を返し、リストには新規作成したシャドウイングが新しいデータとして追加されます。

## シャドウイングの編集

このセクションでは、既に作成されたアラートシャドウイング条件を編集する方法について説明します。

### 前提条件

シャドウイングリストに変更対象のシャドウイング情報が存在します。

### 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで**アラートセンター**を選択します。

3. **アラートシャドウイング**タブをクリックします。

4. **アラートシャドウイング**タブの検索エリアに検索条件を入力します。シャドウイングの正確な検索をサポートしており、**シャドウイングリスト**には検索条件に一致するすべてのシャドウイング情報が返されます。

5. 編集対象のシャドウイングを選択し、対応する**操作**列の**編集**をクリックします。

   <!-- ![編集](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-02.png) -->

6. **シャドウイング条件**ページに移動すると、対応するシャドウイングの条件を編集できます。シャドウイング対象タイプ、シャドウイング対象、アラートルール、タグ、シャドウイング時間、備考などを編集できます。具体的なパラメータは、上記の[シャドウイングの新規作成](#シャドウイングの新規作成)のパラメータ説明を参照して設定してください。

   <!-- ![シャドウイング条件](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-03.png) -->

7. **送信**をクリックすると、シャドウイングの編集が完了します。

## ブロックの解除

このセクションでは、作成したアラートのブロックを解除する方法について説明します。

### 前提条件

ブロックが既に作成されていること。

### 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで**アラートセンター**を選択します。

3. **アラートブロック**タブをクリックします。

4. **アラートブロック**タブの検索エリアに検索条件を入力します。ブロックの正確な検索がサポートされており、**ブロックリスト**には検索条件に一致するすべてのブロック情報が返されます。

5. 解除したいブロックを選択し、対応する**操作**列の**ブロック解除**をクリックします。

   <!-- ![ブロック解除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-04.png) -->

6. 表示された再確認ダイアログで**解除**をクリックすると、ブロックが正常に解除されます。

   <!-- ![解除をクリック](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-05.png) -->

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>ブロックを解除すると元に戻りませんので、ご注意ください。</p>
   </main>

7. ブロックが解除されると、ブロックリストにおける該当ブロックのステータスは**アクティブ**から**期限切れ**に変わり、操作列の**編集**および**ブロック解除**ボタンがグレーアウトされ、以降の操作ができなくなります。

   <!-- ![ブロック解除後のページ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/300.alert-shielding-management-06.png) -->
