# アラートイベントの表示

この章では、アラートイベントの詳細を表示する方法について説明します。

## 手順

1. obshell Dashboardコンソールにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="oms-v2.SystemParam.contants.AlertCenter">アラートセンター</UI-TERM>** を選択します。

3. **<UI-TERM key="oms-community.Notification.Group.AlertEvents">アラートイベント</UI-TERM>** タブをクリックします。

4. クエリボックスにクエリ条件を設定します。**<UI-TERM key="oms-v2.Notification.System.AlertEvents">アラートイベント</UI-TERM>** リストには、クエリ条件に一致するすべてのアラートイベントが返されます。

   * アラートイベントは、**<UI-TERM key="odc.component.CreateTypeModal.ObjectType">オブジェクトタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Component.BackupAlarm.AlertObject">アラートの対象</UI-TERM>**、**<UI-TERM key="ocp-v2.component.alarm.RuleDetail.AlertLevel">警報レベル</UI-TERM>**、**<UI-TERM key="ocp-v2.component.alarm.Search.Keywords">キーワード</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Task.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Compaction.Detail.EndTime">終了時間</UI-TERM>** などの条件で正確に検索できます。

     | パラメータ  | 説明  |
     |-------|------|
     |オブジェクトタイプ | オブジェクトタイプは、obcluster、obtenant、observerに分類されます。<ul><li>obclusterは、アラート対象がクラスタであることを指します。</li><li>obtenantは、アラート対象がテナントであることを指します。</li><li>observerは、アラート対象がobserverノードであることを指します。</li></ul> |
     | アラート対象 | **<UI-TERM key="ocp-v2.Inspection.Task.InspectionObjectType">オブジェクトタイプ</UI-TERM>** に応じて、ここでドロップダウンリストから異なるアラート対象を選択できます。複数のアラート対象が存在する場合、そのうち1つのみを選択できます。<ul><li>オブジェクトタイプがobclusterの場合、アラート対象はクラスタ名です。</li><li>オブジェクトタイプがobtenantの場合、アラート対象は該当するテナント名です。</li><li>オブジェクトタイプがobserverの場合、アラート対象はobserverノードのIPです。</li></ul> |
     | アラートレベル | 重大、警告、注意、リマインダーの4段階に分かれています。<ul><li>重大：システムの可用性が低下し、完全に利用不能になるのを防ぐため、緊急に修正が必要です。例：`マシンのメモリ使用率が90%を3分間超える`。</li><li>警告：システムはまだ利用可能ですが、まもなく利用不能状態に達するため、可用性の低下を防ぐ措置を講じる必要があります。例：`OceanBaseテナントの接続数が上限の80%を超える`。</li><li>注意：傾向から判断して、システムの主要なパフォーマンス指標が低下していますが、警告をトリガーするレベルには達していません。この時点で調査を行うことで、警告の発生を回避できる潜在的な問題を発見できます。</li><li>リマインダー：操作のリマインダーです。本質的にはアラートではなく、通常は管理者が重要な操作を実行する際に表示されます。例：`管理者がクラスタのオフライン操作を実行する`。</li></ul> |
     | キーワード | アラートのキーワードです。キーワードに基づいて対応するアラートイベントを検索できます。自由に入力できます。 |
     | 開始時間 | アラートイベントの開始時間を指します。 |
     | 終了時間 | アラートイベントの終了時間を指します。 |

   * **<UI-TERM key="oms-community.Migration.constants.Reset">リセット</UI-TERM>** ボタンをクリックすると、クエリ内容が空になり、再度入力できます。

   * **<UI-TERM key="oceanbase-intl-business.common.APBackup.TimeList.Collapse">しまう</UI-TERM>** ボタンをクリックすると、クエリボックスが折りたたまれます。この時点では、**<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertObjectType">オブジェクトタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.AlertObject">警告対象</UI-TERM>**、**<UI-TERM key="obcloud-console.Alarm.components.RuleAlarmTemplateExpression.AlertLevel">アラートレベル</UI-TERM>** のみを設定してクエリを実行できます。

5. アラートイベントに対して **<UI-TERM key="obcloud-console.Alarm.History.AlarmHistoryTable.Block">ミュートする</UI-TERM>** 操作を実行できます。

   * アラートイベントに注目する必要がない場合、**<UI-TERM key="ocp-v2.Component.SQLTable.Actions">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Alarm.Event.Shield">遮蔽</UI-TERM>** をクリックすると、アラートメッセージを迅速にブロックできます。

     <!-- ![イベントリスト](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/450.alarm-center/200.view-alarm-events-01.png) -->

   * **<UI-TERM key="ocp-v2.Alarm.Event.Shield">遮蔽</UI-TERM>** をクリックすると、ページは **<UI-TERM key="ocp-v2.page.Alarm.AlarmMask">アラートの無効化</UI-TERM>** ページに移動し、次に **<UI-TERM key="obcloud-console.Alarm.Suppress.ShieldingCondition">抑止条件</UI-TERM>** ページがポップアップ表示されます。ブロック対象タイプ、ブロック対象、ブロックアラートルール、タグが自動的に入力されます。あとはブロック終了時間と備考情報を入力し、**<UI-TERM key="oma-pro.EvaluationLabel.DocumentEvaluation.formComponent.Submit">提出する</UI-TERM>** をクリックするだけで、対応するアラートイベントのアラート状態が **抑制** に変わり、設定された終了時間までそのアラートは送信されません。具体的な設定方法については、[アラートブロックの管理](300.alert-shielding-management.md)の新規作成を参照してください。
