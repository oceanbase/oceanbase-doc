# アラートの概要

obshell Dashboardのアラートセンターは、OceanBaseクラスタ内のアラートイベントを一元管理および監視するために使用されます。このページでは、アラートイベントの確認、アラートのミュート設定、アラートルールの設定ができ、異常状態への迅速な対応と処理を通じてシステムの安定稼働を確保できます。

## アクセスパス

obshell Dashboardコンソールにログインした後、Alertmanagerのアドレス、ユーザー名、パスワードを入力し、**開始** をクリックすると **アラートセンター** ページに入ります。既存のAlertmanagerアドレスを使用してアラートセンターを有効化できますが、まだデプロイしていない場合は、obdを使用してインストール・デプロイすることを推奨します。アラートセンターページの上部にある **アラートイベント**、**アラートのミュート**、**アラートルール** の各タブをクリックすると、対応するページに移動します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>アラートセンターページに初めてログインする際のみ、Alertmanagerのアドレス、ユーザー名、パスワードなどの情報を入力する必要があります。</p>
</main>

## アラートイベント

**アラートイベント** タブでは、**オブジェクトタイプ**、**アラートオブジェクト**、**アラートレベル**、**キーワード**、**開始時間**、**終了時間** などの条件で精密検索が可能です。

アラートイベントリストでは、**アラートイベント**、**アラートオブジェクト**、**アラートレベル**、**アラートステータス**、**発生時間**、**終了時間**、**操作** などの具体的なアラート情報を確認できます。**アラートレベル**、**アラートステータス**、**発生時間**、**終了時間** でのソートがサポートされています。

詳細については、[アラートイベントの表示](200.view-alarm-events.md)を参照してください。

## アラートのミュート

**アラートのミュート** タブの検索エリアに検索条件を入力すると、**オブジェクトタイプ**、**ミュートオブジェクト**、**キーワード** でミュート条件の精密検索が可能です。また、指定したミュート内容に対して **編集** および **ミュートの解除** 操作を実行できます。

ミュートリストでは、ミュート条件の **ミュートアプリケーション/オブジェクトタイプ**、**ミュートオブジェクト**、**ミュートアラートルール**、**ミュート終了時間**、**作成者**、**ステータス**、**作成時間**、**備考**、**操作** などの情報を確認できます。**ミュート終了時間**、**ステータス**、**作成時間** でのソートがサポートされており、指定したミュート内容に対して **編集** および **ミュートの解除** 操作を実行できます。詳細については、[アラートのミュートの管理](300.alert-shielding-management.md)を参照してください。

## アラートルール

**アラートルール** タブでは、**オブジェクトタイプ**、**アラートレベル**、**キーワード** で精密検索が可能です。

ルールリストでは、**アラートルール名**、**トリガールール**、**持続時間**、**オブジェクトタイプ**、**アラートレベル**、**タイプ** などの情報を確認できます。**アラートレベル** でのソートがサポートされており、**タイプ** で **カスタム** または **デフォルト** タイプのアラートルールをフィルタリングできます。
