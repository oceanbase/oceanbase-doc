# アラートの概要

obshell Dashboard アラートセンターは、OceanBaseクラスタ内のアラートイベントを一元的に管理および監視するために使用されます。このページでは、アラートイベントの確認、アラートのミュート設定、アラートルールの設定ができ、異常状態への迅速な対応と処理を通じてシステムの安定稼働を確保できます。

## アクセスパス

obshell Dashboardコンソールにログインした後、Alertmanagerのアドレス、ユーザー名、パスワードを入力し、**<UI-TERM key="obcloud-console.component.FormBackupStrategy.ArchiveBackup.Open">有効にする</UI-TERM>** をクリックすると、**<UI-TERM key="oms-community.SystemParam.contants.AlertCenter">アラートセンター</UI-TERM>** ページに移動します。既存のAlertmanagerアドレスを使用してアラートセンターを開始できますが、まだデプロイされていない場合は、obdを使用してインストールおよびデプロイすることを推奨します。アラートセンターページの上部で、**<UI-TERM key="oms-community.Notification.Group.AlertEvents">アラートイベント</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Alarm.AlarmMask">アラートの無効化</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRules">アラートルール</UI-TERM>** のいずれかをクリックすると、対応するタブに移動します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>アラートセンターページに初めてログインする際にのみ、Alertmanagerのアドレス、ユーザー名、パスワードなどの情報を入力する必要があります。</p>
</main>

## アラートマスキング

**<UI-TERM key="obcloud-console.Alarm.Suppress.AlarmMask">アラートのブロック</UI-TERM>** タブの検索エリアに検索条件を入力すると、**<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertObjectType">オブジェクトタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterWithExclude.MaskObject">ブロック対象</UI-TERM>**、**<UI-TERM key="ocp-v2.component.alarm.Search.Keywords">キーワード</UI-TERM>** でマスキング条件の精密検索が可能です。また、指定したマスキング内容に対して **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">編集</UI-TERM>** および **マスキングの解除** 操作を実行できます。

マスキングリストでは、マスキング条件の **<UI-TERM key="ocp-v2.Alarm.Shield.MaskApplicationObjectType">マスクアプリケーション/オブジェクトタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.alarm.FormListWithExclude.HostWithExclude.MaskObject">ブロック対象</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Shield.MaskAlertRules">アラーム遮断ルール</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Shield.MaskDeadline">遮断終了時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Founder">創設者</UI-TERM>**、**<UI-TERM key="oms-community.SystemManage.Authorization.Status">状態</UI-TERM>**、**<UI-TERM key="obcloud-console.ClusterSecurity.TDEEncryption.CreationTime">作成日時</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.Remarks">備考</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Binlog.Operation">操作</UI-TERM>** などの情報を確認できます。**<UI-TERM key="ocp-v2.Alarm.Shield.MaskDeadline">遮断終了時間</UI-TERM>**、**<UI-TERM key="obcloud-console.AiDatabase.Collection.Status">ステータス</UI-TERM>**、**<UI-TERM key="oms-community.Operation.components.operationDetail.Created">作成時間</UI-TERM>** でのソートがサポートされています。また、指定したマスキング内容に対して **<UI-TERM key="src.pages.TaskList.DataClear.List.628560A8">編集</UI-TERM>** および **マスキングの解除** 操作を実行できます。詳細については、[アラートマスキングの管理](300.alert-shielding-management.md)を参照してください。
