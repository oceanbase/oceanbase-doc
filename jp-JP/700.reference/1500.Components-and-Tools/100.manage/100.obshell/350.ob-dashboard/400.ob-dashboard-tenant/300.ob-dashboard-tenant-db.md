# データベース管理

左側のナビゲーションバーで **テナント管理** をクリックし、**テナント管理** ページで **テナント一覧** のテナント名をクリックして該当するテナントの **概要** ページに移動します。その後、左側のナビゲーションバーで **データベース管理** をクリックすると、**データベース管理** ページにアクセスできます。本記事では、**データベース管理** ページの情報と、このページで実行できる操作について説明します。

<!-- ![概要](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-01.png) -->

## データベースの作成

**データベース管理** ページの右上にある **データベースの作成** ボタンをクリックします。**データベースの作成** ページで、**データベース名**、**文字セット**、**照合順序**、および読み取り専用かどうかを設定します。設定完了後、**送信** をクリックすると、新規作成が完了します。

<!-- ![データベースの作成](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-03.png) -->

| パラメータ | 説明 |
|-------|------|
| データベース名 | 新規作成するデータベースの名前を設定します。データベース名には以下の要件を満たす必要があります：<ul><li>長さは2～128文字です。</li><li>小文字の英字、数字、アンダースコアを含むことができますが、英字で始める必要があります。</li></ul> |
| 文字セット | プルダウンリストから文字セットを選択できます。 |
| 照合順序 | プルダウンリストから適切な照合順序を選択できます。 |
| 読み取り専用 | チェックボックスをオンにして、新規作成するデータベースを読み取り専用データベースにするかどうかを設定します。  |

## データベースの変更

**操作** 列の **編集** フィールドをクリックすると、対応するデータベースの **文字セット**、**照合順序**、および読み取り専用かどうかを変更できます。変更内容を確認したら、**送信** をクリックすると、データベースの変更が完了します。

<!-- ![データベースの編集](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-02.png) -->

## データベースの削除

**操作** 列の **削除** フィールドをクリックし、表示されるウィンドウの入力欄に `delete` と入力してから **削除** ボタンをクリックすると、対応するデータベースを削除できます。

<!-- ![データベースの削除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-04.png) -->
