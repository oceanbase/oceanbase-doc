# データベース管理

左側のナビゲーションバーで **<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">テナント</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">テナント管理</UI-TERM>** ページで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** のテナント名をクリックします。対応するテナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動したら、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Database.DatabaseManagement">データベース管理</UI-TERM>** をクリックします。これにより、**<UI-TERM key="ocp-v2.Detail.Database.DatabaseManagement">データベース管理</UI-TERM>** ページに移動します。この記事では、**<UI-TERM key="ocp-v2.page.Iframe.DatabaseManagement">データベース管理</UI-TERM>** ページの情報と、そのページで実行できる操作について説明します。

## データベースの新規作成

**<UI-TERM key="odc.Record.RecordPage.interface.DatabaseManagement">データベース管理</UI-TERM>** ページの右上隅にある **<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">新しいデータベースを作成</UI-TERM>** ボタンをクリックします。**<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">新しいデータベースを作成</UI-TERM>** ページで、**<UI-TERM key="oas.Optimization.Outline.DatabaseName">データベース名</UI-TERM>**、**<UI-TERM key="OMA.pages.CompatibilityReport.constents.CharacterSet">文字セット</UI-TERM>**、**照合順序**、および読み取り専用かどうかを設定します。設定が完了したら、**<UI-TERM key="ocp-v2.Binlog.New.Submit">提出する</UI-TERM>** をクリックして新規作成を完了します。

<!-- ![データベースの新規作成](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-03.png) -->

| パラメータ  | 説明  |
|-------|------|
| データベース名 | 新規作成するデータベースの名前を設定します。データベース名は以下の要件を満たす必要があります：<ul><li>長さは2～128文字です。</li><li>小文字の英字、数字、アンダースコアを含めることができますが、英字で始める必要があります。</li></ul> |
| 文字セット | ドロップダウンリストから文字セットを選択できます。 |
| 照合順序  | ドロップダウンリストから適切な照合順序を選択できます。 |
| 読み取り専用 | 新規作成するデータベースを読み取り専用データベースに設定するかどうかを選択します。  |

## データベースの変更

**<UI-TERM key="ocp-v2.Alarm.Rule.Operation">操作</UI-TERM>** 列の **<UI-TERM key="src.pages.TaskList.PartitionPlan.List.C663AA87">編集</UI-TERM>** 項目をクリックすると、対応するデータベースの **<UI-TERM key="src.pages.List.DataSourceList.472DE745">文字セット</UI-TERM>**、**照合順序**、および読み取り専用かどうかを変更できます。変更後、**<UI-TERM key="oms-v2.JDBCWriter.New.Submitted">提出する</UI-TERM>** をクリックすると、データベースの変更が完了します。

<!-- ![データベースの編集](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/300.ob-dashboard-tenant-db-02.png) -->

## データベースの削除

**<UI-TERM key="src.pages.TaskList.PartitionPlan.Detail.1621B450">アクション</UI-TERM>** 列の **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.TreeNodeMenu.config.2DE4A3B7">削除</UI-TERM>** 項目をクリックし、ポップアップウィンドウの入力欄に `delete` と入力して **<UI-TERM key="ocp-v2.MultiCluster.Detail.Delete">削除</UI-TERM>** ボタンをクリックすると、対応するデータベースを削除できます。
