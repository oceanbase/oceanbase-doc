# リストアの開始

obshell Dashboardでは、バックアップ済みのテナントに対してリストアを開始できます。以下の2つの方法でリストアを開始できます：

+ **方法1**：obshell Dashboardにログインし、**<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.TenantManagement">テナント</UI-TERM>** ページに移動します。右上の **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.InitiateRecovery">回復を開始する</UI-TERM>** をクリックします。

+ **方法2**：obshell Dashboardにログインし、**<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">テナント管理</UI-TERM>** ページに移動します。テナントリストから対象テナント名をクリックし、**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動したら、左側のナビゲーションバーにある **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックします。これにより、**<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** ページが表示されます。ページの右上にある **<UI-TERM key="ocp-v2.Backup.Restore.InitiateRecovery">回復を開始する</UI-TERM>** をクリックします。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>方法1は、<b>テナント管理</b> のグローバルページからリストアを開始するものです。リストア開始時には、ストレージ設定を入力または変更する必要があります。方法2は、テナントリストから選択した対象テナントからリストアを開始するものです。リストア開始時には、そのテナントのバックアップストレージ設定を再利用でき、ストレージ設定の入力や変更は不要です。</p>
</main>

## 手順

以下の手順は、**方法1** を例に説明します。

1. obshell Dashboardにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.TenantManagement">テナント</UI-TERM>** をクリックします。

3. ページの右上にある **<UI-TERM key="ocp-v2.Backup.Restore.InitiateRecovery">回復を開始する</UI-TERM>** をクリックし、**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.Backup.InitiateRecovery">復元</UI-TERM>** ページに移動します。

4. グローバルページでリストアを開始する場合、復元対象のバックアップファイルのストレージ設定を入力する必要があります（この手順は **方法1** のみで設定が必要です）。

5. 入力または変更が完了したら、**<UI-TERM key="ocp-v2.Cluster.New.Test">テスト</UI-TERM>** をクリックします。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><b>テスト</b> をクリックすると、obshellは復元対象のバックアップファイルのストレージ設定をテストします。テストに成功すると、<b>復元元情報欄</b> に対応する復元元テナント名が表示されます。テストに失敗した場合はエラーが表示されますので、正しいストレージ設定を入力してください。</p>
   </main>

   <!-- ![ストレージ構成](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/300.Initiate-restoration-01.png) -->

6. **<UI-TERM key="OMA.Performance.componentsDetail.BackupRecoveryDetail.RestoreSourceInformation">ソース情報の復元</UI-TERM>** を入力します。復元日は、表示されている復元可能時間帯内である必要があります。復元可能時間範囲を確認するには、ツール統合パッケージである oceanbase-ce-utils をインストールしてください。これにより、システムがバックアップセット関連情報を解析できるようになります。詳細なインストール操作については、[ob_admin インストール](../../../../200.ob-admin/100.overview-of-ob-admin.md)を参照してください。復元日を指定しない場合、デフォルトで最新のポイントまで復元されます。

   <!-- ![リストアソース情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/300.Initiate-restoration-04.png) -->

7. **<UI-TERM key="oms-cloud.Performance.componentsDetail.BackupRecoveryDetail.RestoreTargetInformation">復元ターゲット情報</UI-TERM>** を入力します。

   <!-- ![リストアターゲット情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/300.Initiate-restoration-03.png) -->

   | パラメータ  | 説明  |
   |-------|------|
   | 準備テナント | テナント名を任意に設定してください。ただし、既存のテナント名と重複してはなりません。システムはここで指定したテナント名に基づいて対応するテナントを作成し、バックアップ内容をそのテナントに復元します。 |
   | 各ゾーンのUnit数 | 各ゾーンのUnit数を設定してください。ゾーン内の最小OBServer数によって、Unitの最大設定数が決まります。 |
   | レプリカタイプ | 値の範囲：<ul><li>フル機能レプリカ：現在サポートされている通常レプリカであり、トランザクションログ、MemTable、SSTableなど、すべての完全なデータと機能を備えています。いつでも迅速にリーダーに切り替えて外部へのサービス提供が可能です。</li><li>読み取り専用レプリカ：完全なログ、MemTable、SSTableなどを含みます。業務上、データ読み取りの一貫性に対する要求が高くない場合に選択することを推奨します。</li></ul> |
   | ユニット仕様 | このユニットが占用するリソース仕様です。現在設定可能な範囲内の値を手動で入力できます。 |
   | ユニット数 | 各ゾーンのユニット数を表示します。<main id="notice" type='explain'><h4>説明</h4><p>ユニット数は <b>各ゾーンのユニット数</b> の設定と一致し、変更はできません。</p></main>  |
   | ゾーン優先順位 | テナントのプライマリレプリカに優先順位を指定します。最も優先順位の高いゾーンがプライマリゾーンと見なされ、これは1つだけ存在できます。ゾーン優先順位を設定しない場合は、ランダム優先順位となります。ソート方法は以下の通りです：<ol><li>左側のリストボックスから1つまたは複数のゾーンを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのゾーンが表示されます。</li><li>中央の **>** ボタンをクリックします。選択したゾーンが <b>優先順位付き</b> リストに移動します。</li><li>a、bの操作を繰り返して、次に低い優先順位のゾーンを追加します。</li><li>優先順位を調整する必要がある場合は、<b>優先順位付き</b> リスト内でドラッグ＆ドロップして順序を変更できます。リストは上から下に向かって、優先順位が段階的に低下します。</li><li>ゾーンの後ろにある削除ボタンをクリックするか、**<UI-TERM key="ocp-v2.component.FormPrimaryZone.RestoreToDefault">デフォルトに戻す</UI-TERM>** をクリックすると、<b>優先順位付き</b> リスト内のゾーンを左側のリストに戻すことができます。</li></ol>  |

8. **<UI-TERM key="ocp-v2.Detail.Backup.InitiateRecovery">回復を開始する</UI-TERM>** をクリックすると、復元タスクが生成されます。**<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewTasks">タスクを表示</UI-TERM>** をクリックすると、復元タスクの進捗状況を確認できます。
