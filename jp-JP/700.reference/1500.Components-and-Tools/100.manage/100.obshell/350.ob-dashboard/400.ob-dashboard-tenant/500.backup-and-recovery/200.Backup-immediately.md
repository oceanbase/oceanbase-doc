# 即時バックアップ

## 前提条件

* バックアップを実行する前に、NFSのデプロイが完了していることを確認してください。NFSのデプロイに関する操作については、[NFSのデプロイ](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971092)を参照してください。

* 事前にデータストレージディレクトリとログストレージディレクトリを作成し、対応する読み書き権限を付与しておく必要があります。各テナントのバックアップパスは独立した空ディレクトリに設定する必要があり、異なるテナント間で同じバックアップパスを設定することはできません。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>現在、obshell DashboardはNFSバックアップメディアタイプのみをサポートしています。</p>
</main>

## 手順

1. obshell Dashboardにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">テナント</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">テナント管理</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** のテナント名をクリックします。

4. 対応するテナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動し、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックして、**<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。

5. ページの右上にある **<UI-TERM key="ocp-v2.Detail.Backup.BackUpNow">今すぐバックアップしてください</UI-TERM>** をクリックして、**<UI-TERM key="ocp-v2.Backup.Backup.BackUpNow">今すぐバックアップしてください</UI-TERM>** ページに移動します。

6. ストレージ設定を入力または変更します。

   * バックアップ対象のテナントに既存のバックアップストレージ設定がある場合、その設定が自動的に入力されます。編集ボックスで変更できます。

   * バックアップ対象のテナントにバックアップストレージ設定がない場合、手動でストレージ設定を入力する必要があります。

7. 入力または変更が完了したら、**テストして設定** をクリックして、ストレージ設定をテストします。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><b>テストして設定</b> をクリックすると、obshellは対応するストレージ設定のテストタスクを作成します。<b>タスクを見る</b> をクリックするとタスクを確認できます。通常、このタスクは数秒以内に正常に完了します。失敗した場合は、タスクセンターに移動してエラー原因を確認し、修正してください。タスクが完了してから <b>即時バックアップ</b> をクリックしてバックアップを実行してください。</p>
   </main>

   <!-- ![今すぐバックアップ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.3.2/200.Backup-immediately.png) -->

8. データバックアップ方式を選択します。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>物理バックアップでは、増分バックアップを実行する前に、一度のフルデータバックアップが必要です。</p>
   </main>

9. **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.BackUpNow">今すぐバックアップしてください</UI-TERM>** をクリックすると、バックアップタスクが生成されます。**<UI-TERM key="oat.Tool.DataX.ResultSuccess.ViewTasks">タスクを確認する</UI-TERM>** をクリックすると、バックアップタスクの進捗状況を確認できます。
