# バックアップ・リストアの概要

左側のナビゲーションバーで **テナント管理** をクリックし、**テナント管理** ページで **テナント一覧** のテナント名をクリックして対応するテナントの **概要** ページに移動した後、左側のナビゲーションバーの **バックアップ・リストア** をクリックすると、**バックアップ・リストア** ページに入ります。本記事では、**バックアップ・リストア** ページの情報と、そのページで実行できる操作について説明します。

**バックアップ・リストア** ページでは、現在のobshell Dashboardのバックアップ・リストアの基本情報、バックアップタスク、リストアタスクを確認できます。また、対応するページに移動してリストアの開始や即時バックアップ操作を実行することもできます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>システムテナント（sysテナント）に対しては、バックアップ・リストア操作を実行することはできません。</p>
</main>

## 基本情報

基本情報セクションでは、**直近データバックアップ**、**ログバックアップポイント**、**ログ遅延**のデータを確認し、現在のバックアップ・リストアのタイミング情報を把握できます。

## バックアップタスク

バックアップタスクは、データバックアップとログバックアップに分かれています。

### データバックアップ

**データバックアップ**タブでは、データの**ID**、**データバックアップ方式**、**バックアップセットID**、**開始時間**、**終了時間**、**状態**、**操作**を確認できます。異なる状態に基づいてバックアップタスクをフィルタリングすることもできます。詳細は下表を参照してください。**開始時間**または**終了時間**の後ろのソートアイコンをクリックすると、データバックアップ情報を昇順または降順で表示するように選択できます。また、このモジュールの右上隅で、過去24時間、過去7日間、過去30日間のデータバックアップタスク情報を表示するか、カスタム時間を選択して、特定の期間内のデータバックアップタスク情報を表示することができます。

<!-- ![バックアップタスク](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.tenant-backup-and-recovery-overview-06.png) -->

| パラメータ  | 説明  |
|-------|------|
| ID | データバックアップタスクの一意の識別子です。IDの左側にある+ボタンをクリックすると、**バックアップ方式**、**バックアップ時間**、**データバージョン**、および**ストレージディレクトリ**が展開されます。展開後、IDの前の-ボタンをクリックすると表示を元に戻すことができます。  |
| データバックアップ方式 | **増分** と **フル** の2種類があります。 |
| バックアップセットID | バックアップセットのIDです。  |
| 開始時間 | バックアップの開始時刻です。  |
| 終了時間 | バックアップの終了時刻です。  |
| ステータス | データバックアップの状態です。バックアップのステータスでフィルタリングが可能です。 |
| 操作 | <ul><li>データバックアップタスクが失敗した場合、**操作** の下の **原因を見る** をクリックして詳細なログを確認できます。</li><li>タスクが進行中の場合、**操作** の下の **キャンセル** をクリックしてデータバックアップタスクをキャンセルできます。</li></ul> |

### ログバックアップ

**ログバックアップ**タブでは、データの**バックアップ方式**、**最新バックアップ時点**、**遅延(s)**、**ストレージディレクトリ**、**開始時間**、**状態**、**操作**を確認できます。詳細は下表を参照してください。**最新バックアップ時点**または**遅延(s)**の後ろのソートアイコンをクリックすると、データバックアップ情報を昇順または降順で表示するように選択できます。また、このモジュールの右上隅で、過去24時間、過去7日間、過去30日間のログバックアップタスク情報を表示するか、カスタム時間を選択して、特定の期間内のログバックアップタスク情報を表示することができます。

<!-- ![ログバックアップ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.backup-and-recovery-overview-03.png) -->

| パラメータ  | 説明  |
|-------|------|
| バックアップ方式 | テナントのバックアップ方式です。現在、**物理バックアップ** のみサポートしています。  |
| 最終バックアップ時刻 | 現在時刻までに完了したログバックアップの時刻です。  |
| 遅延時間 (s) | バックアップデータと実際のデータとの時間差です。単位は秒です。  |
| ストレージディレクトリ | バックアップストレージディレクトリです。  |
| 開始時間 | バックアップ開始時点。
| 状態 | ログバックアップの状態。  |
| 操作 **進行中** のテナントに対しては **停止** および **一時停止** 操作を、**一時停止** 中のテナントに対しては **復元** または **停止** 操作を実行できます。<main id="notice" type='explain'><h4>説明</h4><p>ログバックアップを停止すると、システムは任意の時点での復元をサポートせず、データの安全性を保証できません。慎重に操作してください。</p></main>|

## リストアタスク

**リストアタスク** タブでは、タスクの **ID**、**バックアップクラスタ**、**バックアップテナント**、**バックアップ方式**、**ターゲットテナント**、**リストアオブジェクト**、**開始時間**、**リストア時間**、**ステータス**、および **操作** を確認できます。また、異なるステータスに基づいてリストアタスクをフィルタリングして表示することもできます。このモジュールの右上隅で、過去24時間、過去7日間、過去30日間のデータリストアタスク情報を表示するか、カスタムの期間を選択して特定の期間内のデータリストアタスクを表示することができます。

<!-- ![リストアタスク](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.tenant-backup-and-recovery-overview-09.png) -->

| パラメータ | 説明 |
|-------|------|
| ID | 復元タスクの一意の識別子です。IDの左側にある+ボタンをクリックすると、**復元ポイント**、**終了時間**、**ログ保存ディレクトリ**、**データ保存ディレクトリ**が展開されます。展開後、IDの前の-ボタンをクリックすると表示を元に戻すことができます。  |
| バックアップクラスタ | バックアップテナントが存在するクラスタ。 |
| バックアップテナント | バックアップクラスタ内でバックアップが完了したテナントです。このテナントのデータは、同一クラスタ内の他のテナントに復元できます。|
| バックアップ方式 | バックアップテナントのバックアップ方式です。現在、物理バックアップのみサポートしています。 |
| ターゲットテナント | データを復元するテナントです。バックアップテナントのデータをターゲットテナントに復元します。 |
| 復元オブジェクト | 復元対象のタイプです。 |
| 開始時間 | 復元タスクの開始時間です。 |
| 復元時間 | 復元タスクにかかった時間です。 |
| ステータス | タスクのステータスでフィルタリングできます。物理バックアップのタスクステータスは、**復元中**、**テナント作成**、**アップグレード**、**復元成功**、**復元失敗**、**テナント復元完了待ち**、**既に完了**、**失敗**が含まれます。 |
| 操作 | ステータスが**テナント作成**または**テナント復元完了待ち**のテナントについては**キャンセル**操作を、ステータスが**失敗**のテナントについては**原因を見る**操作を実行できます。 |
