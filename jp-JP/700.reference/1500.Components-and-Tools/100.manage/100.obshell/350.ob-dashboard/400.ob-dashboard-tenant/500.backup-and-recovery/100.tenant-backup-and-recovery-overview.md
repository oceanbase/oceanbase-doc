# バックアップ・リストアの概要

左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">テナント管理</UI-TERM>** をクリックし、**<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.TenantManagement">テナント</UI-TERM>** ページで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** のテナント名をクリックします。対応するテナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動したら、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックすると、**<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに入ります。この記事では、**<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** ページの情報と、そのページで実行できる操作について説明します。

**<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** ページでは、現在のobshell Dashboardバックアップ・リストアの基本情報、バックアップタスク、リストアタスクを確認できます。また、対応するページに移動してリストアの開始や即時バックアップ操作を実行することもできます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>システムテナント（sysテナント）に対しては、バックアップ・リストア操作を実行できません。</p>
</main>

## 基本情報

基本情報セクションでは、**直近データバックアップ**、**ログバックアップポイント**、**ログ遅延**のデータを確認でき、現在のバックアップ・リストアの時間ポイント情報を把握することができます。

## バックアップタスク

バックアップタスクは、データバックアップとログバックアップに分かれています。

### データバックアップ

**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.Backup.utils.DataBackup">データバックアップ</UI-TERM>**タブで、データの**<UI-TERM key="oceanbase-intl-console.ClusterWorkbench.components.ClusterInfo.ID">ID</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.DataBackupMethod">データバックアップ方法</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.BackupSetId">バックアップセット ID</UI-TERM>**、**<UI-TERM key="ocp-v2.Trace.Visualizer.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceContent.PlanOperation.EndTime">終了時間</UI-TERM>**、**<UI-TERM key="src.page.WorkspaceCluster.List.96F1CCE1">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.component.ParameterTemplate.Operation">操作</UI-TERM>**を確認できます。異なる状態に基づいてバックアップタスクをフィルタリングできます。詳細は下表を参照してください。**<UI-TERM key="ocp-v2.Detail.Component.Event.StartTime">開始時間</UI-TERM>**または**<UI-TERM key="ocp-v2.Backup.Backup.Data.EndTime">終了時間</UI-TERM>**の後のソートアイコンをクリックすると、データバックアップ情報を昇順または降順で表示できます。また、このモジュールの右上で、過去24時間、過去7日間、過去30日間のデータバックアップタスク情報を表示するか、カスタム時間を選択して、特定の期間内のデータバックアップタスク情報を表示することができます。

<!-- ![バックアップタスク](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.tenant-backup-and-recovery-overview-06.png) -->

| パラメータ | 説明 |
|-------|------|
| ID | データバックアップタスクの一意の識別子です。IDの左側にある+ボタンをクリックすると、**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Detail.BackupMethod">バックアップ方法</UI-TERM>**、**<UI-TERM key="obcloud-console.Backup.component.PanelBackupTask.BackupDuration">バックアップ期間</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.DataVersion">データバージョン</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.StorageConfigCard.StorageDirectory">ストレージディレクトリ</UI-TERM>**を展開して表示できます。展開後、IDの前の-ボタンをクリックすると、表示を元に戻せます。  |
| データバックアップ方式 | **<UI-TERM key="workspace.window.createSequence.params.increment">増分</UI-TERM>**と**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.Backup.utils.Total">全量</UI-TERM>**の2種類があります。 |
| バックアップセットID | バックアップセットのID。  |
| 開始時間 | バックアップの開始時刻。  |
| 終了時間 | バックアップの終了時刻。  |
| 状態 | データバックアップの状態です。バックアップ状態に基づいてフィルタリングできます。 |
| 操作 | <ul><li>データバックアップタスクが失敗した場合、**<UI-TERM key="OMS.Detail.components.FullMigration.Operation">操作</UI-TERM>**の下の**<UI-TERM key="OMS.components.ModifyRecordTable.ViewReason">原因を確認する</UI-TERM>**をクリックして、具体的なログを確認できます。</li><li>タスクが進行中の場合、**<UI-TERM key="obcloud-console.models.components.RateLimitTable.Operation">操作</UI-TERM>**の下の**<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.Cancel">キャンセル</UI-TERM>**をクリックして、データバックアップタスクをキャンセルできます。</li></ul> |

### ログバックアップ

**<UI-TERM key="ocp-v2.Component.StorageTrend.LogBackup">ログのバックアップ</UI-TERM>**タブで、データの**<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.BackupMethod">バックアップ方法</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Log.LatestBackupTime">最新のバックアップ時点</UI-TERM>**、**<UI-TERM key="oms-v2.Operation.Store.LatencyS">遅延 (s)</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Log.StorageDirectory">ストレージディレクトリ</UI-TERM>**、**<UI-TERM key="ocp-v2.Transaction.Detail.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="src.pages.TaskList.util.52E4A68F">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Operation">操作</UI-TERM>**を確認できます。詳細は下表を参照してください。**<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Log.LatestBackupTime">最新のバックアップ時点</UI-TERM>**または**<UI-TERM key="oms-community.Operation.Store.LatencyS">遅延(s)</UI-TERM>**の後のソートアイコンをクリックすると、データバックアップ情報を昇順または降順で表示できます。また、このモジュールの右上で、過去24時間、過去7日間、過去30日間のログバックアップタスク情報を表示するか、カスタム時間を選択して、特定の期間内のログバックアップタスク情報を表示することができます。

<!-- ![ログバックアップ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.backup-and-recovery-overview-03.png) -->

| パラメータ | 説明 |
|-------|------|
| バックアップ方式 | テナントのバックアップ方式です。現在、**<UI-TERM key="ocp-v2.Component.AddBackupStrategy.PhysicalBackup">物理バックアップ</UI-TERM>**のみサポートされています。  |
| 最新バックアップ時点 | 現在時点までに完了したログバックアップです。  |
| 遅延(s) | バックアップデータと実際のデータの時間差で、単位は秒です。  |
| ストレージディレクトリ | バックアップストレージディレクトリ。  |
| 開始時間 | バックアップの開始時刻。
| 状態 | ログバックアップの状態。  |
| 操作 | **<UI-TERM key="oas.MultiCloud.Optimization.constants.InProgress">進行中</UI-TERM>**のテナントに対しては、**<UI-TERM key="ocp-v2.Backup.Backup.Log.Stop">停止する</UI-TERM>**および**<UI-TERM key="ocp-v2.src.constant.backup.Pause">一時停止</UI-TERM>**操作を実行できます。また、**<UI-TERM key="ocp-v2.src.constant.backup.Pause">一時停止</UI-TERM>**されたテナントに対しては、**<UI-TERM key="oms-v2.Migration.constants.Recovery">回復</UI-TERM>**または**<UI-TERM key="ocp-v2.Component.ZoneList.Stop">停止する</UI-TERM>**操作を実行できます。<main id="notice" type='explain'><h4>説明</h4><p>ログバックアップを停止すると、システムは任意の時点での復元をサポートしなくなり、データの安全性が保証されなくなります。ご注意ください。</p></main>|

## 復元タスク

**<UI-TERM key="ocp-v2.Backup.Overview.Task.RestoreTask">タスクの復元</UI-TERM>** タブで、タスクの **<UI-TERM key="oceanbase-intl-console.ClusterWorkbench.components.ClusterInfo.ID">ID</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.BackupCluster">バックアップクラスター</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">バックアップテナント</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.BackupMethod">バックアップ方法</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Component.RestoreTenantCard.TargetTenant">対象テナント</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.RestoreObjects">復元対象</UI-TERM>**、**<UI-TERM key="oms-cloud.pages.Performance.PerformanceEvaluationList.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.RecoveryDuration">回復時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.State">ステータス</UI-TERM>**、および **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Operation">操作</UI-TERM>** を確認できます。また、異なる状態に応じて復元タスクを管理することができます。このモジュールの右上で、過去24時間、過去7日間、過去30日間のデータ復元タスク情報を表示するか、カスタムの期間を選択して特定の期間内のデータ復元タスクを表示することができます。

<!-- ![リストアタスク](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.tenant-backup-and-recovery-overview-09.png) -->

| パラメータ | 説明 |
|-------|------|
| ID | 復元タスクの一意の識別子です。IDの左側にある+ボタンをクリックすると、**<UI-TERM key="obcloud-console.create.CreateRestore.RecoveryTimePoint">復元時点</UI-TERM>**、**<UI-TERM key="ocp-v2.Compaction.Detail.EndTime">終了時間</UI-TERM>**、**ログストレージディレクトリ**、および **データストレージディレクトリ** が展開されます。展開後、IDの前の-ボタンをクリックすると、表示を解除できます。  |
| バックアップクラスタ | バックアップテナントが配置されているクラスタです。 |
| バックアップテナント | バックアップクラスタ内でバックアップが完了したテナントです。このテナントのデータは、同一クラスタ内の他のテナントに復元できます。|
| バックアップ方式 | バックアップテナントのバックアップ方式です。現在、物理バックアップのみサポートしています。 |
| ターゲットテナント | データを復元するテナントです。バックアップテナントのデータをターゲットテナントに復元します。 |
| 復元オブジェクト | 復元ターゲットのタイプです。 |
| 開始時間 | 復元タスクの開始時間です。 |
| 復元時間 | 復元タスクにかかった時間です。 |
| 状態 | タスクの状態をフィルタリングできます。物理バックアップのタスク状態は、以下のとおりです：**<UI-TERM key="oceanbase-intl-console.utils.textFormat.getTenantStatusText.Recovering">復元中</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Welcome.CreateATenant">テナントの作成</UI-TERM>**、**<UI-TERM key="obcloud-console.tenant.UpgradeProxyArchitecture.Upgrade">アップグレード</UI-TERM>**、**<UI-TERM key="oms-cloud.components.VerifyObjectTable.map.RecoverySucceeded">正常に再開しました</UI-TERM>**、**<UI-TERM key="oms-v2.components.VerifyObjectTable.map.RecoveryFailed">復元に失敗しました。</UI-TERM>**、**テナント復元完了待ち**、**<UI-TERM key="oms-cloud.PublicCloud.Task.constants.Completed">完了しました</UI-TERM>**、および **<UI-TERM key="oms-community.components.BatchSelect.BatchSwitch.Failed">失敗</UI-TERM>**。 |
| 操作 | 状態が **<UI-TERM key="ocp-v2.page.Welcome.CreateATenant">テナントの作成</UI-TERM>** または **テナント復元完了待ち** のテナントに対しては、**<UI-TERM key="ocp-v2.Detail.Session.List.Cancel">取り消し</UI-TERM>** 操作を実行できます。また、状態が **<UI-TERM key="obcloud-console.TenantLoadData.DetailModal.Failed">失敗しました</UI-TERM>** のテナントに対しては、**<UI-TERM key="OMS.components.ModifyRecordTable.ViewReason">原因を確認する</UI-TERM>** 操作を実行できます。 |
