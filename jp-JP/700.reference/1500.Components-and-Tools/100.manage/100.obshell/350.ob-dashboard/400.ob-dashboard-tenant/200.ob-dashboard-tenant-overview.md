# テナント概要

左側のナビゲーションバーで **<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.TenantManagement">テナント</UI-TERM>** をクリックして、**<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">テナント管理</UI-TERM>** ページに移動します。**<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** のテナント名をクリックすると、そのテナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動します。本記事では、**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの情報と、このページで実行できる操作について説明します。

## 基本情報

**<UI-TERM key="ocp-v2.Component.AddZoneDrawer.BasicInformation">基本情報</UI-TERM>** モジュールには、テナントの名前、モード、テナントが存在するクラスタで使用されているOceanBaseデータベースのバージョン番号、文字セット、照合順序、接続文字列、テーブルの大文字小文字区別、タイムゾーン、ロック状態、作成日時、備考が表示されます。

**接続文字列** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style="height: 20px;"></span> アイコンをクリックすると、接続文字列をコピーして後で使用できます。**<UI-TERM key="ocp-v2.Detail.Overview.LockedState">ロック状態</UI-TERM>** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/200.ob-dashboard-tenant-overview-01.png" alt="変更" style="height: 20px;"></span> アイコンをクリックすると、テナントのロック状態を変更できます。対応するロック状態を選択し、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Ok">確定</UI-TERM>** をクリックします。テナントをロックすると、ユーザーはそのテナントにアクセスできなくなりますので、ご注意ください。

## レプリカ詳細

**<UI-TERM key="ocp-v2.Tenant.Detail.CopyDetails">コピーの詳細</UI-TERM>** ページでは、レプリカが属する **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.ZoneName">ゾーン名</UI-TERM>**、**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Detail.ReplicaType">コピーの種類</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.ModifyResourcePoolModal.UnitSpecification">ユニット仕様</UI-TERM>**、**<UI-TERM key="ocp-v2.component.FormZoneReplicaTable.UnitQuantity">ユニット数</UI-TERM>** を確認できます。レプリカの変更および削除操作をサポートしています。

<!-- ![レプリカの詳細](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-02.png) -->

* レプリカの変更

  **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.column.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Edit">編集</UI-TERM>** 項目をクリックすると、対応するレプリカタイプとUnit仕様を変更できます。対応するUnit構成では、現在設定可能な範囲値が表示されます。値の範囲に従って設定し、変更後に **<UI-TERM key="ocp-v2.Component.SQLTable.Actions">操作</UI-TERM>** 列の **<UI-TERM key="obcloud-business.InvoiceOB.InvoiceDownload.useMemoModal.Determine">確定</UI-TERM>** をクリックすると、現在のレプリカを変更できます。

  **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.CopyDetails">コピーの詳細</UI-TERM>** モジュールの右上にある **<UI-TERM key="ocp-v2.Detail.Overview.ModifyUnit">ユニットの変更</UI-TERM>** ボタンをクリックすると、すべてのZoneのUnit数とUnit仕様を変更できます。変更後に **<UI-TERM key="OMS.components.ViewObj.AddObject.Ok">確定</UI-TERM>** をクリックすると、obshell DashboardはUnitを一括変更するタスクを生成します。**<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

* レプリカの削除

  **<UI-TERM key="oms-cloud.TransferSub.ConsumerList.Operation">アクション</UI-TERM>** 列の **<UI-TERM key="must.pages.compatibilityAssessment.CompatibilityList.Delete">削除</UI-TERM>** 項目をクリックし、表示されたウィンドウで **<UI-TERM key="oms-v2.Operation.constants.Delete">削除</UI-TERM>** をクリックします。obshell Dashboardはレプリカを削除するタスクを生成します。**<UI-TERM key="oat.Tool.DataX.ResultSuccess.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

  異なるZoneの前にあるチェックボックスを選択して複数のレプリカを一括削除することもできます。**<UI-TERM key="src.page.Workspace.Worksheets.List.Explore.6DE2A38B">一括削除</UI-TERM>** をクリックし、表示されたウィンドウで **<UI-TERM key="oms-community.IncrSync.New.Delete">削除</UI-TERM>** をクリックします。obshell Dashboardはレプリカを一括削除するタスクを生成します。**<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。レプリカを選択した後、**<UI-TERM key="odc.component.CommonTable.TableInfo.Deselect">選択を解除する</UI-TERM>** をクリックすると、すべてのレプリカの選択を解除できます。つまり、すべて未選択の状態に戻ります。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>レプリカデータの削除は元に戻せません。ご注意ください。</p>
  </main>

## Zone優先順位

**<UI-TERM key="ocp-v2.component.TenantList.ZonePriority">ゾーンの優先順位</UI-TERM>** モジュールには、テナント内のプライマリレプリカの配置優先順位が表示されます。モジュールの右側にある **<UI-TERM key="OMS.Audit.constants.Modify">修正</UI-TERM>** ボタンをクリックすると、テナント内のZone優先順位を変更できます。

<!-- ![優先順位の変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-03.png) -->

最も優先順位の高いZoneはPrimary Zoneと見なされ、1つしか存在できません。指定しない場合、デフォルトで最初のZoneが第一優先順位となります。ソート方法は以下の通りです：

1. 左側のリストボックスから1つ以上のZoneを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのZoneが表示されます。

2. 中央の **>** ボタンをクリックします。選択されたZoneは <b>優先順位ソート</b> リストに移動します。同時に選択された複数のZoneは同じ優先順位を持ちます。

3. 1、2の操作を繰り返し、次に低い優先順位のZoneを追加します。

4. 優先順位を調整する必要がある場合、<b>優先順位ソート</b> リスト内でドラッグして順序を変更します。リストは上から下に向かって、優先順位が順次低下します。

5. Zoneの後ろにある削除ボタンをクリックするか、**<UI-TERM key="ocp-v2.component.FormPrimaryZone.RestoreToDefault">デフォルトに戻す</UI-TERM>** をクリックすると、<b>優先順位ソート</b> リストのZoneを左側のリストに戻すことができます。

変更後に **<UI-TERM key="oms-v2.biz.ETL.ColumnFamilyEtlDrawer.Determine">確定</UI-TERM>** ボタンをクリックすると、obshell DashboardはZone優先順位を変更するタスクを生成します。**<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

## アローリスト

**<UI-TERM key="oms-community.ConfigTabs.BlackWhiteList.VirtualizedBlackWhiteList.WhiteList">アローリスト</UI-TERM>** モジュールには、テナントに接続できるアドレスのリストが表示されます。モジュールの右側にある **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Modification">修正</UI-TERM>** ボタンをクリックすると、アローリストを変更できます。

<!-- ![アローリストの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-04.png) -->

アクセス可能なIPをカスタマイズ設定するか、すべてのIPからのアクセスを許可するように設定できます。カスタム設定を選択した場合、**<UI-TERM key="ocp-v2.component.WhitelistInput.CustomIpAddress">カスタムIP</UI-TERM>** の入力ボックスにログインを許可するクライアントのリストを指定します。IPを入力した後、キーボードのEnterキーを押すか、半角カンマ（`,`）を入力することで、複数のノードIPを設定できます。**<UI-TERM key="obcloud-console.components.Rule.NotificationConfig.ViewConfigurationInstructions">設定説明を表示</UI-TERM>** にカーソルを合わせると、設定IPの説明を確認できます。IP設定でサポートされている形式は以下のとおりです：

* IPアドレス、例：127.0.0.10,127.0.0.11

* サブネット/マスク、例：127.0.0.0/24

* あいまい一致、例：127.0.0.% または 127.0.0._

* 複数形式の混合、例：127.0.0.10,127.0.0.11,127.0.0.%,127.0.0._,127.0.0.0/24

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>%</code> に設定すると、すべてのクライアントが接続できることを意味し、アクセスのセキュリティ上のリスクが伴います。ご注意ください。</p>
</main>

## メジャーコンパクションの管理

メジャーコンパクションの管理モジュールには、現在のテナントの **<UI-TERM key="oma-pro.EvaluationLabel.SqlEvaluation.Status">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.TenantMergeList.LastMergeStartTime">直近1回目のマージ開始時刻</UI-TERM>**、および **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.TenantMergeList.LastConsolidationEndTime">最近の1回の合併終了時間</UI-TERM>** が表示されます。**<UI-TERM key="oms-community.SystemManage.Authorization.Status">ステータス</UI-TERM>** の隣にある **<UI-TERM key="ocp-v2.Compaction.Detail.InitiateAMerge">合併を開始する</UI-TERM>** をクリックし、ポップアップウィンドウで **<UI-TERM key="obcloud-console.Model.ModelConfigApiKey.Determine">確定</UI-TERM>** をクリックすると、メジャーコンパクションを開始できます。

## レプリカの追加

**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.Detail.Component.AddReplicaModal.NewCopy">新しいコピーを追加</UI-TERM>** ボタンをクリックし、ポップアップウィンドウでレプリカ情報を設定します。設定完了後、**<UI-TERM key="oms-community.Detail.components.SyncSteps.Determine">OK</UI-TERM>** ボタンをクリックすると、obshell Dashboardは新規レプリカのタスクを生成します。**<UI-TERM key="oat.components.ActionBar.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

<!-- ![レプリカの追加](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-10.png) -->

| パラメータ  | 説明  |
|-------|------|
| ターゲットZone | ドロップダウンリストから、新規レプリカを追加するZoneを選択します。 |
| レプリカタイプ  | ドロップダウンリストからレプリカタイプを選択します。**<UI-TERM key="ocp-v2.src.constant.oceanbase.AllPurposeReplica">オールインワンコピー</UI-TERM>** と **<UI-TERM key="ocp-v2.src.constant.oceanbase.ReadOnlyCopy">読み取り専用コピー</UI-TERM>** をサポートしています。 |
| Unit仕様 | UnitのCPU仕様の上限とメモリ仕様を設定します。  |
| Unit数 | 各ZoneのUnit数を表示します。変更はできません。  |
