# テナント概要

左側のナビゲーションバーで **テナント管理** をクリックして **テナント管理** ページに移動し、**テナント一覧** のテナント名をクリックすると、そのテナントの **概要** ページに移動します。本記事では、この **概要** ページの情報と、そこで実行できる操作について説明します。

## 基本情報

**基本情報** モジュールには、テナント名、モード、テナントが存在するクラスタで使用されているOceanBaseデータベースのバージョン番号、文字セット、照合順序、接続文字列、テーブル名の大文字小文字の区別、タイムゾーン、ロック状態、作成日時、および備考が表示されます。

**接続文字列** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style="height: 20px;"></span> アイコンをクリックすると、後の使用のために接続文字列をコピーできます。**ロック状態** の後ろの <span style="vertical-align: middle;"><!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/200.ob-dashboard-tenant-overview-01.png" alt="変更" style="height: 20px;"> --></span> アイコンをクリックすると、テナントのロック状態を変更できます。対応するロック状態を選択してから **OK** をクリックします。テナントをロックすると、ユーザーはそのテナントにアクセスできなくなりますので、ご注意ください。

## レプリカの詳細

**レプリカの詳細** ページでは、レプリカが属する **Zone名**、**レプリカタイプ**、**Unit構成**、**Unit数** を確認できます。レプリカの変更および削除操作がサポートされています。

<!-- ![レプリカの詳細](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-02.png) -->

* レプリカの変更

  **操作** 列の **編集** ボタンをクリックすると、対応するレプリカのタイプとUnit構成を変更できます。対応するUnit構成では、現在設定可能な範囲の値が表示されます。値の範囲に従って設定し、変更後に **操作** 列の **OK** をクリックすると、現在のレプリカを変更できます。

  また、**レプリカの詳細** モジュールの右上にある **Unitの変更** ボタンをクリックすると、すべてのZoneのUnit数とUnit構成を変更できます。変更後に **OK** をクリックすると、obshell DashboardはUnitを一括変更するタスクを生成します。**タスクの表示** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

* レプリカの削除

  **操作** 列の **削除** ボタンをクリックし、ポップアップウィンドウで **削除** をクリックします。obshell Dashboardはレプリカを削除するタスクを生成します。**タスクの表示** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

  また、異なるZoneの前のチェックボックスを選択して複数のレプリカを一括削除することもできます。**一括削除** をクリックし、ポップアップウィンドウで **削除** をクリックすると、obshell Dashboardはレプリカを一括削除するタスクを生成します。**タスクの表示** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。レプリカを選択した後、**選択を解除** をクリックすると、すべてのレプリカの選択を解除し、すべて未選択状態に戻すことができます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>レプリカデータの削除は元に戻せません。ご注意ください。</p>
  </main>

## Zoneの優先順位

**Zoneの優先順位** モジュールは、テナント内のプライマリレプリカの配置優先順位を表示します。モジュール右側の **変更** ボタンをクリックすると、テナント内のZoneの優先順位を変更できます。

<!-- ![優先順位の変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-03.png) -->

最も優先順位が高いZoneがPrimary Zoneと見なされ、そのようなZoneは1つしか存在できません。指定しない場合、デフォルトで最初のZoneが第一優先順位となります。ソート方法は以下の通りです：

1. 左側のリストボックスから1つ以上のZoneを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのZoneが表示されます。

2. 中央の **>** ボタンをクリックします。選択したZoneが <b>優先順位ソート</b> リストに移動します。複数のZoneを同時に選択した場合、それらのZoneは同じ優先順位を持ちます。

3. 1、2の操作を繰り返し、次に低い優先順位のZoneを追加します。

4. 優先順位を調整する必要がある場合、<b>優先順位ソート</b> リスト内でドラッグして順序を変更できます。リストでは上から下へ、優先順位が順次低下します。

5. Zoneの後ろにある削除ボタンをクリックするか、**デフォルトに戻す** をクリックすると、<b>優先順位ソート</b> リストのZoneを左側のリストに戻すことができます。

変更後、**OK** ボタンをクリックすると、obshell DashboardはZoneの優先順位を変更するタスクを生成します。**タスクの表示** ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

## アローリスト

**アローリスト** モジュールは、テナントに接続できるアドレスのリストを表示します。モジュール右側の **変更** ボタンをクリックすると、アローリストを変更できます。

<!-- ![アローリストの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-04.png) -->

アクセス可能なIPをカスタマイズ設定するか、すべてのIPがアクセス可能に設定できます。カスタム設定を選択した場合、**カスタムIP** の下の入力ボックスにログインを許可するクライアントのリストを指定できます。IPを入力した後、キーボードのEnterキーを押すか、英字のカンマ（`,`）を入力すると、複数のノードIPを設定できます。**設定説明を見る** にカーソルを合わせると、IP設定の説明を確認できます。IP設定でサポートされている形式は以下の通りです：

* IPアドレス、例：127.0.0.10,127.0.0.11

* サブネット/マスク、例：127.0.0.0/24

* あいまい一致、例：127.0.0.% または 127.0.0._

* 複数形式の混合、例：127.0.0.10,127.0.0.11,127.0.0.%,127.0.0._,127.0.0.0/24

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>%</code> に設定すると、すべてのクライアントが接続できることを意味しますが、これにはセキュリティ上のリスクが伴いますので、ご注意ください。</p>
</main>

## メジャーコンパクション管理

メジャーコンパクション管理モジュールは、現在のテナントの **状態**、**直近1回のメジャーコンパクション開始時間**、および **直近1回のメジャーコンパクション終了時間** を表示します。**状態** の後ろの **メジャーコンパクションの開始** をクリックし、表示されたウィンドウで **OK** をクリックすると、メジャーコンパクションを開始できます。

<!-- ![メジャーコンパクションの開始](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-05.png) -->

## レプリカの追加

**概要**ページの右上にある**レプリカを追加**ボタンをクリックし、ポップアップウィンドウでレプリカ情報を設定します。設定完了後、**OK**ボタンをクリックすると、obshell Dashboardは新規レプリカのタスクを生成します。**タスクを見る**ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

<!-- ![レプリカの追加](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-10.png) -->

| パラメータ  | 説明  |
|-------|------|
| ターゲットゾーン | ドロップダウンリストから、新規レプリカを追加するゾーンを選択します。 |
| レプリカタイプ  | ドロップダウンリストからレプリカタイプを選択します。**フル機能レプリカ**と**読み取り専用レプリカ**を設定できます。 |
| ユニット構成 | ユニットのCPUスペックの上限とメモリスペックを設定します。  |
| ユニット数 | 各ゾーンのユニット数を表示します。変更はできません。  |

## テナントの削除

**概要**ページの右上にある**テナントを削除**ボタンをクリックし、ポップアップウィンドウの入力欄に`delete`と入力してから**削除**ボタンをクリックします。obshell Dashboardはテナント削除のタスクを生成します。**タスクを見る**ボタンをクリックすると、タスクの詳細な実行情報を確認できます。

<!-- ![テナントの削除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/200.ob-dashboard-tenant-overview-06.png) -->
