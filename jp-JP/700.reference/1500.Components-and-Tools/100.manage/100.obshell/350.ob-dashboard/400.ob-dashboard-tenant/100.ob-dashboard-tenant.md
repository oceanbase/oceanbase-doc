# テナント管理の概要

テナントとは、OceanBaseにおいてリソース割り当ての単位であり、データベースオブジェクト管理やリソース管理の基盤となる論理的な概念です。obshell Dashboardにログインし、左側のナビゲーションバーから**テナント管理**をクリックすると、**テナント管理**ページにアクセスできます。このページでは、デフォルトでクラスタ内のすべてのテナントの一覧情報が表示されます。このページでは、すべてのテナントの基本情報を確認したり、[テナントの作成](#テナントの作成)を行ったりできます。

## テナント一覧

**テナント一覧**ページには、テナントの**テナント名**、**テナントモード**、**接続文字列**、**読み取り専用**かどうか、**ロック**されているかどうか、**ステータス**、**作成時間**などの情報と、実行可能な**操作**が表示されます。

* テナント名をクリックすると、対応するテナントの詳細情報を[概要](200.ob-dashboard-tenant-overview.md)ページで確認できます。また、テナント内のデータベース、ユーザー、パラメータを管理することもできます。具体的な操作については、[データベース管理](300.ob-dashboard-tenant-db.md)、[ユーザー管理](400.ob-dashboard-tenant-user.md)、および[パラメータ管理](../500.ob-dashboard-parameter.md)機能を参照してください。

* **接続文字列**列の<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style="height: 20px;"></span>アイコンをクリックすると、後で使用するためにテナントの接続文字列をコピーできます。

* **ステータス**の後ろにある<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span>アイコンをクリックすると、異なるテナントステータスでフィルタリングできます。

* **作成時間**の後ろにある<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-03.png" alt="ソート" style="height: 20px;"></span>アイコンをクリックすると、テナントを昇順または降順で表示するように選択でき、クラスタのテナントを簡単に確認できます。

* **操作**列の**ロック**フィールドをクリックすると、対応するテナントをロックできます。テナントをロックすると、ユーザーはそのテナントにアクセスできなくなるため、慎重に操作してください。

## テナントの作成

ページ右上の**新規テナント**をクリックすると、**新規テナント**ページに移動します。新規テナントを作成するには、**基本情報**、**ゾーン情報**、**セキュリティ設定**、**パラメータ設定**を設定する必要があります。このセクションではそれぞれについて説明します。

1. 基本情報

   **基本情報**部分は、テナントモード、名前、パスワードなどの情報を設定するために使用されます。内容は以下の通りです。

   <!-- ![基本情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-01.png) -->

   | パラメータ | 説明 |
   |--------|------|
   | テナントモード | ドロップダウンリストからテナントモードを選択します。<main id="notice" type='explain'><h4>説明</h4><p>現在、obshell DashboardでMySQLモードのテナントを作成することのみがサポートされています。</p></main> |
   | テナント名 | 新規作成するテナントの名前を設定します。テナント名は以下の要件を満たす必要があります：<ul><li>長さは2～32文字です。</li><li>大文字と小文字の英字、数字、アンダースコアを含むことができますが、英字で始まり、英字または数字で終わる必要があります。</li></ul>  |
   | 管理者初期パスワード | **ランダム生成**をクリックすると、obshell Dashboardが自動的にランダムな文字列を生成します。また、カスタマイズして設定することもできます。カスタマイズ設定の場合、パスワードの複雑さは以下の要件を満たす必要があります：<ul><li>長さは8～32文字です。</li><li>少なくとも以下の4種類の文字をそれぞれ2つずつ含む：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（〜! @ # % ^ & * _ - + = \ | （） { } [ ] : ; , . ? / ）</li></ul> 設定後、**パスワードのコピー**をクリックして、後で使用するために設定したパスワードをコピーして保存します。  |
   | 文字セット | デフォルトはutf8mb4です。ドロップダウンリストから他の文字セットを選択できます。 |
   | Collation（オプション） | ドロップダウンリストから適切なCollationを選択します。 |
   | 備考（オプション）  | テナントの説明で、テナントをより効果的に管理できます。 |

2. ゾーン情報

   **ゾーン情報**部分は、**各ゾーンのユニット数**、ゾーンの**レプリカタイプ**、**ユニット仕様**、**ゾーン優先順位**を設定するために使用されます。内容は以下の通りです。

   <!-- ![ゾーン情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-02.png) -->

   | パラメータ | 説明 |
   |---------|-----|
   | 各ZoneのUnit数 | Zone内の最小OBServer数によって、Unitの最大設定可能数が決定されます。 |
   | Zone名 | デフォルトはクラスタ内のZone名であり、変更することはできません。対応するZoneの前のチェックボックスをクリックすることで、どのZone上にUnitを作成するかを設定できます。 |
   | レプリカタイプ | プルダウンリストからレプリカタイプを選択でき、**汎用型レプリカ**と**読み取り専用型レプリカ**に設定できます。 |
   | Unit仕様 | UnitのCPU仕様の上限とメモリ仕様を設定します。クラスタリソースによって設定範囲が異なるため、対応する入力欄の範囲に従って設定してください。  |
   | Unit数 | 各ZoneのUnit数を表示します。 |
   | Zone優先順位付け | テナントのプライマリレプリカの配置に優先順位を指定します。最も高い優先順位を持つZoneはPrimary Zoneと見なされ、その数は1つだけです。指定しない場合、デフォルトでは最初のZoneが第一優先となります。優先順位の付け方は以下の通りです：<ol><li>左側のリストボックスから1つまたは複数のZoneを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのZoneが表示されています。</li><li>中央の**>**ボタンをクリックします。これにより、選択したZoneは<b>優先順位付け</b>リストに移動します。同時に選択した複数のZoneは、同一の優先順位を持ちます。</li><li>a、bの操作を繰り返し、次に低い優先順位のZoneを追加します。</li><li>優先順位を調整する必要がある場合は、<b>優先順位付け</b>リスト内でドラッグアンドドロップして順序を変更できます。リスト内では上から下へ向かって、優先順位が順次低下します。</li><li>Zoneの後ろにある削除ボタンをクリックするか、**デフォルトに戻す**をクリックすると、<b>優先順位付け</b>リスト内のZoneが再び左側のリストに移動します。</li></ol>   |

3. セキュリティ設定

   **セキュリティ設定**部分は、IPアドレスのアローリストを設定するために使用されます。アクセス可能なIPアドレスをカスタマイズして設定するか、すべてのIPアドレスからのアクセスを許可するように設定できます。カスタム設定を選択した場合、**カスタムIP**の入力ボックスにログインを許可するクライアントのリストを指定し、IPアドレスを入力してキーボードのEnterキーを押すか、英字のカンマ（`,`）を入力することで複数のノードIPアドレスを設定できます。**設定の説明を見る**上にカーソルを合わせると、設定IPの説明を確認できます。IPアドレスの設定でサポートされる形式は以下の通りです：

   * IPアドレス。例：127.0.0.10,127.0.0.11

   * サブネット/マスク。例：127.0.0.0/24

   * あいまい一致。例：127.0.0.%または127.0.0._

   * 複数の形式を混在させる。例：127.0.0.10,127.0.0.11,127.0.0.%,127.0.0._,127.0.0.0/24

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><code>%</code>に設定すると、すべてのクライアントが接続できることを意味し、アクセスセキュリティ上のリスクが存在します。慎重に操作してください。</p>
   </main>

   <!-- ![セキュリティ設定](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-03.png) -->

4. パラメータ設定

   **パラメータ設定**の後ろにあるボタンをクリックしてテナントパラメータを設定できます。**+テナントパラメータの追加**をクリックして複数のテナントパラメータを設定できます。**パラメータ名**の下に手動で入力するか、ドロップダウンリストから設定するテナントパラメータを選択し、**パラメータ値**の入力ボックスに対応するパラメータの値を設定します。**操作**列の**削除**オプションをクリックすると、設定した対応するパラメータを削除できます。

   <!-- ![パラメータ設定](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-04.png) -->

5. 送信

   設定完了後、ページ右下の**送信**ボタンをクリックして新規テナント作成タスクを開始します。**テナントリストに戻る**または**タスクの詳細を見る**を選択できます。

   <!-- ![送信](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-05.png) -->

## テナントのロック

**操作** 列の **ロック** フィールドをクリックし、表示されるウィンドウで **ロック** をクリックすると、対応するテナントがロックされます。テナントをロックすると、ユーザーはそのテナントにアクセスできなくなりますので、ご注意ください。
