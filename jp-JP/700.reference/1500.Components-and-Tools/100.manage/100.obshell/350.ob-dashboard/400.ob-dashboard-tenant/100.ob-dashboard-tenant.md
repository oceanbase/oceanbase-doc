# テナント管理の概要

テナントは論理的な概念であり、OceanBaseにおいてはリソース割り当ての単位であり、データベースオブジェクト管理とリソース管理の基盤となります。obshell Dashboardにログインした後、左側のナビゲーションバーで**テナント管理**をクリックすると、**テナント管理**ページに移動します。このページにはデフォルトでクラスタ内のすべてのテナントのリスト情報が表示されます。このページでは、すべてのテナントの基本情報を確認したり、[新規テナントの作成](#テナントの作成)を行ったりできます。

## テナント一覧

**テナント一覧** には、テナントの **テナント名**、**テナントモード**、**接続文字列**、**読み取り専用** かどうか、**ロック** されているかどうか、**ステータス**、**作成日時** などの情報が表示され、実行可能な **操作** も表示されます。

* テナント名をクリックすると、[概要](200.ob-dashboard-tenant-overview.md) ページで対応するテナントの詳細情報を確認できます。また、テナント内のデータベース、ユーザー、パラメータの管理もサポートしています。具体的な操作については、[データベース管理](300.ob-dashboard-tenant-db.md)、[ユーザー管理](400.ob-dashboard-tenant-user.md)、[パラメータ管理](../500.ob-dashboard-parameter.md) の各機能を参照してください。

* **接続文字列** 列の <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style="height: 20px;"></span> アイコンをクリックすると、後の使用のためにテナントの接続文字列をコピーできます。

* **ステータス** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンをクリックすると、異なるテナントステータスでフィルタリングできます。

* **作成日時** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-03.png" alt="ソート" style="height: 20px;"></span> アイコンをクリックすると、テナントを昇順または降順で表示するように選択でき、クラスタのテナントを容易に確認できます。

* **操作** 列の **ロック** フィールドをクリックすると、対応するテナントをロックできます。テナントをロックすると、そのテナントにアクセスできなくなりますので、ご注意ください。

## テナントの作成

ページの右上にある **新規テナント** をクリックすると、**新規テナント** ページに移動します。新規テナントの作成では、**基本情報**、**ゾーン情報**、**セキュリティ設定**、および **パラメータ設定** を設定する必要があります。このセクションでは、それぞれについて説明します。

1. 基本情報

   **基本情報** セクションでは、テナントモード、名前、パスワードなどの情報を設定します。内容は以下の通りです。

   <!-- ![基本情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.ob-dashboard-tenant-01.png) -->

   | パラメータ | 説明 |
   |--------|------|
   | テナントモード | ドロップダウンリストからテナントモードを選択します。<main id="notice" type='explain'><h4>説明</h4><p>現在、obshell DashboardでMySQLテナントの作成のみがサポートされています。</p></main> |
   | テナント名 | 新規作成するテナントの名前を設定します。テナント名は以下の要件を満たす必要があります：<ul><li>長さが2～32文字です。</li><li>大文字と小文字の英字、数字、アンダースコアを含めることができますが、英字で始まり、英字または数字で終わる必要があります。</li></ul>  |
   | 管理者初期パスワード | **ランダムに生成**をクリックすると、obshell Dashboardが自動的にランダム文字列を生成します。また、カスタマイズして設定することもできます。カスタム設定の場合、パスワードの複雑さは以下の要件を満たす必要があります：<ul><li>長さが8～32文字です。</li><li>少なくとも以下の4種類の文字をそれぞれ2つ含む：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（~!@#%^&*_-+=\|(){}[]:;,.?/）</li></ul> 設定後、**パスワードをコピー**をクリックして、後の使用のために設定したパスワードを保存することができます。  |
   | 文字セット | デフォルトはutf8mb4です。ドロップダウンリストから他の文字セットを選択できます。 |
   | Collation（オプション） | ドロップダウンリストから適切なCollationを選択します。 |
   | テーブル名の大文字小文字区別 | ドロップダウンリストで設定でき、`0`、`1`、`2`をサポートします。<ul><li>`0`：テーブル名は指定された大文字小文字形式で格納され、大文字小文字を区別して比較されます。</li><li>`1`：テーブル名は小文字形式で格納され、大文字小文字を区別せずに比較されます。</li><li>`2`：テーブル名は指定された大文字小文字形式で格納され、大文字小文字を区別せずに比較されます。</li></ul> |
   | タイムゾーン | デフォルトは(GMT+08:00)中国標準時です。ドロップダウンリストから他のタイムゾーンを選択できます。 |
   | 備考（オプション）  | テナントの説明で、テナントの管理を容易にします。 |
   | ロードタイプ | **ロードタイプ**の下のドロップダウンリストをクリックし、実際のビジネスニーズに応じて適切なロードタイプを選択します。オプションは以下のとおりです：<ul><li>COMPLEX_OLAP：銀行、保険システムなどのワークロードに適しています。これらは通常、複雑な結合、複雑な相関サブクエリ、PLで記述されたバッチ処理ジョブ、および長トランザクションと大規模トランザクションを特徴とします。短時間で実行されるクエリでは、パラレル実行が使用されることがあります。</li><li>OLAP：リアルタイムデータウェアハウス分析シナリオに使用されます。</li><li>KV：キー・バリュー・ワークロードやHBaseに似たワイドカラムワークロードに使用されます。これらのワークロードは通常、非常に高いスループットを持ち、レイテンシに敏感です。</li><li>HTAP：OLAPとOLTPの混合ワークロードに適しています。通常、アクティブな運用データ、不正検出、パーソナライズド提案から即時の洞察を得るために使用されます。</li><li>EXPRESS_OLTP：貿易、決済基幹システム、インターネットの高スループットアプリケーションなどのワークロードに適しています。外部キーなどの制限がなく、ストアドプロシージャ、長トランザクション、大規模トランザクション、複雑な結合、複雑なサブクエリもありません。</li></ul> |

2. ゾーン情報

   **ゾーン情報** セクションでは、**各ゾーンのユニット数**、ゾーンの **レプリカタイプ**、**ユニット仕様**、および **ゾーン優先順位** を設定します。内容は以下の通りです。

   <!-- ![ゾーン情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-02.png) -->

   | パラメータ  | 説明  |
   |---------|-----|
   | 各ZoneのUnit数 | Zone内の最小OBServer数によって、Unitの最大設定可能数が決まります。 |
   | Zone名  | デフォルトでクラスタ内のZone名となり、変更はできません。対応するZoneの前のチェックボックスをクリックすることで、どのZoneにUnitを作成するかを設定できます。 |
   | レプリカタイプ | ドロップダウンリストからレプリカタイプを選択できます。**フル機能レプリカ**と**読み取り専用レプリカ**をサポートしています。 |
   | Unit構成 | UnitのCPU構成の上限とメモリ構成を設定します。クラスタのリソース状況によって設定可能範囲が異なるため、対応する入力欄の下に記載されている範囲に従って設定してください。  |
   | Unit数  | 各ZoneのUnit数を表示します。 |
   | Zone優先順位付け | テナントのプライマリレプリカの配置に優先順位を指定します。最も高い優先順位を持つZoneはPrimary Zoneと見なされ、1つしか存在できません。並べ替え方は以下のとおりです。<ol><li>左側のリストボックスから1つまたは複数のZoneを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのZoneが表示されています。</li><li>中央の**>**ボタンをクリックします。これにより、選択したZoneが<b>優先順位付け</b>リストに移動します。同時に複数のZoneを選択した場合、それらのZoneはすべて同じ優先順位を持ちます。</li><li>a、bの操作を繰り返し、次に低い優先順位のZoneを追加します。</li><li>優先順位を調整する必要がある場合、<b>優先順位付け</b>リスト内でドラッグ＆ドロップして順序を変更できます。リストは上から下に向かって、優先順位が順次低下します。</li><li>Zoneの後ろにある削除ボタンをクリックするか、**デフォルトに戻す**をクリックすると、<b>優先順位付け</b>リストにあるZoneを左側のリストに戻すことができます。</li></ol>   |

3. セキュリティ設定

   **セキュリティ設定** セクションでは、IPアドレスのホワイトリストを設定します。アクセス可能なIPをカスタマイズして設定するか、すべてのIPからのアクセスを許可するように設定できます。カスタム設定を選択した場合、**カスタムIP** の入力ボックスにログインを許可するクライアントリストを指定できます。IPを入力してキーボードのEnterキーを押すか、英字のカンマ（`,`）を入力することで、複数のノードIPを設定できます。**設定説明を見る** にカーソルを合わせると、IP設定の説明を確認できます。IP設定でサポートされている形式は以下の通りです：

   * IPアドレス、例：127.0.0.10,127.0.0.11

   * サブネット/マスク、例：127.0.0.0/24

   * あいまい一致、例：127.0.0.% または 127.0.0._

   * 複数形式の混合、例：127.0.0.10,127.0.0.11,127.0.0.%,127.0.0._,127.0.0.0/24

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><code>%</code> に設定すると、すべてのクライアントが接続できることを意味し、アクセスのセキュリティリスクが伴います。慎重に操作してください。</p>
   </main>

   <!-- ![セキュリティ設定](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-03.png) -->

4. パラメータ設定

   **パラメータ設定** の後ろのボタンをクリックしてテナントパラメータを設定できます。**+テナントパラメータの追加** をクリックして複数のテナントパラメータを設定できます。**パラメータ名** の下に手動で入力するか、ドロップダウンリストから設定するテナントパラメータを選択できます。**パラメータ値** の入力ボックスに対応するパラメータの値を設定し、**操作** 列の **削除** オプションをクリックすると、設定した対応するパラメータを削除できます。

   <!-- ![パラメータ設定](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-04.png) -->

5. 提交

   設定完了後、ページの右下にある **提交** ボタンをクリックして新規テナントタスクを開始します。**テナントリストに戻る** または **タスク詳細を見る** を選択できます。

   <!-- ![提交](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-05.png) -->

## テナントのロック

**操作** 列の **ロック** フィールドをクリックし、表示されたウィンドウで **ロック** をクリックすると、対応するテナントがロックされます。テナントをロックすると、そのテナントにアクセスできなくなりますので、ご注意ください。
