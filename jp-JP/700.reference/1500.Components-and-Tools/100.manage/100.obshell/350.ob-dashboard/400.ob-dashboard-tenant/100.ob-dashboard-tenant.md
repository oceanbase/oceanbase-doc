# テナント管理の概要

テナントは論理的な概念であり、OceanBaseではリソース割り当ての単位であり、データベースオブジェクト管理およびリソース管理の基盤となります。obshell Dashboardにログインした後、左側のナビゲーションバーで**テナント管理**をクリックすると、**テナント管理**ページに移動します。このページには、クラスタ内のすべてのテナントの一覧情報がデフォルトで表示されます。このページでは、すべてのテナントの基本情報を確認できるほか、[新規テナントの作成](#テナントの新規作成)も行えます。

## テナント一覧

**<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** には、テナントの **<UI-TERM key="ocp-v2.ReportTable.PartitionStatInfo.PartitionHitStatInfoTable.TenantName">テナント名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.New.TenantMode">テナントモデル</UI-TERM>**、**接続文字列**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ReadOnly">読み取り専用</UI-TERM>** かどうか、**<UI-TERM key="ocp-v2.Tenant.Detail.Locking">ロックする</UI-TERM>** かどうか、**<UI-TERM key="oms-v2.Detail.components.StructMigration.State">ステータス</UI-TERM>**、**<UI-TERM key="src.pages.DataChangesTaskList.Detail.3980E80C">作成日時</UI-TERM>** などの情報と、実行可能な **<UI-TERM key="obcloud-console.Detail.CrossProjectAuth.Operation">操作</UI-TERM>** が表示されます。

* テナント名をクリックすると、[概要](200.ob-dashboard-tenant-overview.md)ページで対応するテナントの詳細情報を確認できます。また、テナント内のデータベース、ユーザー、パラメータの管理もサポートしています。具体的な操作については、[データベース管理](300.ob-dashboard-tenant-db.md)、[ユーザー管理](400.ob-dashboard-tenant-user.md)、[パラメータ管理](../500.ob-dashboard-parameter.md)機能を参照してください。

* **接続文字列** 列の <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style="height: 20px;"></span> アイコンをクリックすると、後の使用のためにテナントの接続文字列をコピーできます。

* **<UI-TERM key="workspace.window.sql.record.column.status">ステータス</UI-TERM>** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンをクリックすると、異なるテナント状態でフィルタリングできます。

* **<UI-TERM key="odc.src.component.Task.ApplyPermission.DetailContent.CreationTime">作成日時</UI-TERM>** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-03.png" alt="ソート" style="height: 20px;"></span> アイコンをクリックすると、テナントを昇順または降順で表示するように選択でき、クラスタのテナントを容易に確認できます。

* **<UI-TERM key="oms-cloud.TransferSub.ConsumerList.Operation">アクション</UI-TERM>** 列の **<UI-TERM key="oceanbase-intl-console.src.constants.tenantUser.Locking">ロック</UI-TERM>** フィールドをクリックすると、対応するテナントをロックできます。テナントをロックすると、ユーザーはそのテナントにアクセスできなくなりますので、ご注意ください。

## テナントの新規作成

ページの右上にある **<UI-TERM key="ocp-v2.Cluster.Detail.NewTenant">新しいテナントを作成</UI-TERM>** をクリックすると、**<UI-TERM key="ocp-v2.Detail.Tenant.NewTenant">新しいテナントを作成</UI-TERM>** ページに移動します。テナントの新規作成では、**<UI-TERM key="oms-v2.components.FirstStep.BasicSection.BasicInformation">基本情報</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.UpgradeDistributedClusterDrawer.ZoneInformation">ゾーン情報</UI-TERM>**、**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.ClusterSecurity.SecuritySettings">セキュリティ</UI-TERM>**、および **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.ParameterSettings">パラメータ設定</UI-TERM>** を設定する必要があります。このセクションでは、それぞれについて説明します。

1. 基本情報

   **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.constant.BasicInformation">基本情報</UI-TERM>** セクションでは、テナントモード、名前、パスワードなどの情報を設定します。内容は以下の通りです。

   <!-- ![基本情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.3.2/100.ob-dashboard-tenant-01.png) -->

   |  パラメータ  |  説明  |
   |--------|------|
   | テナントモード | ドロップダウンリストからテナントモードを選択できます。<main id="notice" type='explain'><h4>説明</h4><p>現在、obshell DashboardでMySQLモードのテナントのみをサポートしています。</p></main> |
   | テナント名  | 新規作成するテナントの名前を設定します。テナント名は以下の要件を満たす必要があります：<ul><li>長さが2～32文字です。</li><li>大文字と小文字の英字、数字、アンダースコアを含めることができますが、英字で始まり、英字または数字で終わる必要があります。</li></ul>  |
   | 管理者初期パスワード | **<UI-TERM key="oat.pages.User.RandomGeneration">ランダム生成</UI-TERM>** をクリックすると、obshell Dashboardが自動的にランダム文字列を生成します。また、カスタマイズして設定することもできます。カスタマイズ設定時のパスワードの複雑さ要件は以下の通りです：<ul><li>長さが8～32文字です。</li><li>少なくとも以下の4種類の文字をそれぞれ2つ含みます：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（~!@#%^&*_-+=\|(){}[]:;,.?/）</li></ul> 設定後、**<UI-TERM key="oat.components.StrengthPassword.CopyPassword">パスワードをコピー</UI-TERM>** をクリックして、後の使用のために設定したパスワードを保存することができます。  |
   | 文字セット | デフォルトはutf8mb4です。ドロップダウンリストから他の文字セットを選択できます。 |
   | Collation（オプション） | ドロップダウンリストから適切なCollationを選択できます。 |
   | テーブル名の大文字小文字の区別 | ドロップダウンリストで設定でき、`0`、`1`、または `2` をサポートします。<ul><li>`0`：テーブル名は指定された大文字小文字の形式で保存され、大文字小文字を区別して比較されます。</li><li>`1`：テーブル名は小文字の形式で保存され、大文字小文字を区別せずに比較されます。</li><li>`2`：テーブル名は指定された大文字小文字の形式で保存され、大文字小文字を区別せずに比較されます。</li></ul> |
   | タイムゾーン | デフォルトは(GMT+08:00)中国標準時です。ドロップダウンリストから他のタイムゾーンを選択できます。 |
   | 備考（オプション）  | テナントの説明で、テナントの管理を容易にします。 |
   | ロードタイプ | **<UI-TERM key="ocp-v2.Cluster.New.LoadType">負荷タイプ</UI-TERM>** の下のドロップダウンリストをクリックし、実際のビジネスニーズに応じて適切なロードタイプを選択します。オプションは以下の通りです：<ul><li>COMPLEX_OLAP：銀行、保険システムなどのワークロードに適しています。これらは通常、複雑な結合、複雑な相関サブクエリ、PLで記述されたバッチ処理ジョブ、および長トランザクションと大規模トランザクションを特徴とします。短時間で実行されるクエリに対して並列実行を使用する場合があります。</li><li>OLAP：リアルタイムデータウェアハウス分析シナリオに使用されます。</li><li>KV：キー・バリュー・ワークロードやHBaseに似たワイドカラムワークロードに使用されます。これらのワークロードは通常、非常に高いスループットを持ち、レイテンシに敏感です。</li><li>HTAP：OLAPとOLTPの混合ワークロードに適しています。通常、アクティブな運用データ、不正検出、パーソナライズド推薦から即時の洞察を得るために使用されます。</li><li>EXPRESS_OLTP：貿易、決済基幹システム、インターネット高スループットアプリケーションなどのワークロードに適しています。外部キーなどの制限がなく、ストアドプロシージャ、長トランザクション、大規模トランザクション、複雑な結合、複雑なサブクエリもありません。</li></ul> |

2. ゾーン情報

   **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.ZoneInformation">ゾーン情報</UI-TERM>** セクションでは、**各ゾーンのUnit数**、ゾーンの **<UI-TERM key="ocp-v2.Detail.Component.BatchDeleteUnitModal.CopyType">コピーの種類</UI-TERM>**、**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Detail.UnitSpecifications">ユニット仕様</UI-TERM>**、および **<UI-TERM key="ocp-v2.Detail.Component.ModifyPrimaryZoneDrawer.ZonePrioritySorting">ゾーンの優先順位付け</UI-TERM>** を設定します。内容は以下の通りです。

   <!-- ![ゾーン情報](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-02.png) -->

   | パラメータ  |  説明  |
   |---------|-----|
   | 各ゾーンのUnit数 | ゾーン内の最小OBServer数によって、Unitの最大設定数が決まります。 |
   | ゾーン名  | デフォルトはクラスタ内のゾーン名で、変更できません。対応するゾーンの前のチェックボックスをクリックすることで、Unitを作成するゾーンを設定できます。 |
   | レプリカタイプ | ドロップダウンリストからレプリカタイプを選択できます。**<UI-TERM key="obcloud-console.const.replica.OmnidirectionalCopy">フル機能レプリカ</UI-TERM>** と **<UI-TERM key="ocp-v2.src.constant.oceanbase.ReadOnlyCopy">読み取り専用コピー</UI-TERM>** を設定できます。 |
   | Unit仕様 | UnitのCPU仕様の上限とメモリ仕様を設定します。クラスタのリソースが異なる場合、設定可能範囲も異なります。対応する入力ボックスの下の範囲に従って設定してください。  |
   | Unit数  | 各ゾーンのUnit数を表示します。 |
   | ゾーン優先順位ソート | テナントのプライマリレプリカの分散に優先順位を指定します。最も高い優先順位を持つゾーンがプライマリゾーンと見なされ、プライマリゾーンは1つしか存在できません。ソート方法は以下の通りです：<ol><li>左側のリストボックスから1つ以上のゾーンを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのゾーンが表示されます。</li><li>中央の **>** ボタンをクリックします。選択されたゾーンは <b>優先順位ソート</b> リストに移動します。同時に選択された複数のゾーンは同じ優先順位を持ちます。</li><li>a、bの操作を繰り返して、次に低い優先順位のゾーンを追加します。</li><li>優先順位を調整する必要がある場合、<b>優先順位ソート</b> リスト内でドラッグして順序を変更できます。リストは上から下に向かって、優先順位が順次低下します。</li><li>ゾーンの後ろにある削除ボタンをクリックするか、**<UI-TERM key="ocp-v2.component.FormPrimaryZone.RestoreToDefault">デフォルトに戻す</UI-TERM>** をクリックすると、<b>優先順位ソート</b> リストのゾーンを左側のリストに戻すことができます。</li></ol>   |

3. セキュリティ設定

   **<UI-TERM key="obcloud-console.MainMenu.personal.menu.SecuritySettings">セキュリティ設定</UI-TERM>** セクションでは、IPアドレスのホワイトリストを設定します。アクセス可能なIPをカスタマイズして設定するか、すべてのIPがアクセス可能に設定することができます。カスタム設定を選択した場合、**<UI-TERM key="ocp-v2.component.WhitelistInput.CustomIpAddress">カスタムIP</UI-TERM>** の下の入力ボックスにログインを許可するクライアントリストを指定できます。IPを入力してキーボードのEnterキーを押すか、英字のカンマ（`,`）を入力することで、複数のノードIPを設定できます。**<UI-TERM key="obcloud-console.components.Rule.NotificationConfig.ViewConfigurationInstructions">設定説明を表示</UI-TERM>** にカーソルを合わせると、IP設定の説明を見ることができます。IP設定でサポートされている形式は以下の通りです：

   * IPアドレス、例：127.0.0.10,127.0.0.11

   * サブネット/マスク、例：127.0.0.0/24

   * あいまい一致、例：127.0.0.% または 127.0.0._

   * 複数形式の混合、例：127.0.0.10,127.0.0.11,127.0.0.%,127.0.0._,127.0.0.0/24

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><code>%</code> に設定すると、すべてのクライアントが接続できることを意味します。これにはアクセスセキュリティ上のリスクが伴いますので、ご注意ください。</p>
   </main>

   <!-- ![セキュリティ設定](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-03.png) -->

4. パラメータ設定

   **<UI-TERM key="ocp-v2.Component.ZoneList.AddOBServerDrawer.ParameterSettings">パラメータ設定</UI-TERM>** の後ろにあるボタンをクリックしてテナントパラメータを設定できます。**+テナントパラメータの追加** をクリックすると、複数のテナントパラメータを設定できます。**<UI-TERM key="odc.components.PLDebugResultSet.Parameter.1">パラメータ名</UI-TERM>** の下に、設定するテナントパラメータを手動で入力するか、ドロップダウンリストから選択します。**<UI-TERM key="oat.src.constants.config.ParameterValue">パラメーター値</UI-TERM>** の入力欄に対応するパラメータの値を設定し、**<UI-TERM key="obcloud-business.CostUnit.ResourceTable.config.Operation">操作</UI-TERM>** 列の **<UI-TERM key="src.pages.List.DataSourceList.29586A53">削除</UI-TERM>** オプションをクリックすると、設定した対応するパラメータを削除できます。

   <!-- ![パラメータ設定](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/100.ob-dashboard-tenant-04.png) -->

5. 送信

   設定が完了したら、ページの右下にある **<UI-TERM key="oma-pro.EvaluationLabel.CodeAssessment.formComponent.Submit">提出する</UI-TERM>** ボタンをクリックして新規テナントタスクを開始します。**<UI-TERM key="ocp-v2.Tenant.Result.Success.ReturnToTenantList">テナントリストに戻る</UI-TERM>** または **<UI-TERM key="ocp-v2.page.Result.Success.ViewTaskDetails">タスクの詳細を確認する</UI-TERM>** を選択できます。

## テナントのロック

**<UI-TERM key="oceanbase-intl-business.Bills.DomesticBills.config.Operation">操作</UI-TERM>** 列の **<UI-TERM key="oceanbase-intl-console.utils.textFormat.getAccountStatusText.Locking">ロック</UI-TERM>** フィールドをクリックし、表示されたウィンドウで **<UI-TERM key="ocp-v2.Statistics.components.PartitionDrawer.Lock">ロックする</UI-TERM>** をクリックすると、対応するテナントがロックされます。テナントをロックすると、そのテナントにアクセスできなくなりますので、ご注意ください。
