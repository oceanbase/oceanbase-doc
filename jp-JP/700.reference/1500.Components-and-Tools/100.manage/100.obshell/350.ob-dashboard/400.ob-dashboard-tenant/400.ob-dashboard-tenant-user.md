# ユーザー管理

左側のナビゲーションバーで **テナント管理** をクリックし、**テナント管理** ページで **テナント一覧** のテナント名をクリックして該当するテナントの **概要** ページに移動します。その後、左側のナビゲーションバーで **ユーザー管理** をクリックすると、**ユーザー管理** ページにアクセスできます。本記事では、**ユーザー管理** ページの情報と、このページで実行できる操作について説明します。

## ユーザーの作成

**ユーザー管理**ページの右上にある**新規ユーザー**ボタンをクリックし、**新規データベースユーザー**ページで**ユーザー名**、**パスワード**、**グローバル権限**、**データベース権限**を設定します。設定完了後、**送信**をクリックすると作成が完了します。

<!-- ![新規ユーザー](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/400.ob-dashboard-tenant-user-02.png) -->

| パラメータ | 説明 |
|-------|------|
| ユーザー名 | 新規ユーザーの名前を設定します。ユーザー名は以下の要件を満たす必要があります。<ul><li>長さは2～64文字です。</li><li>小文字の英字、数字、アンダースコアを含むことができますが、英字で始まる必要があります。</li></ul> |
| パスワード | パスワードの複雑さについては、以下の要件を満たす必要があります。<ul><li>長さは8～32文字です。</li><li>少なくとも以下の4種類の文字をそれぞれ2つ含みます：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（〜! @ # % ^ & * _ - + = \ | （） { } [ ] : ; , . ? / ）</li></ul> 設定後、**パスワードのコピー** をクリックして、後で使用するために設定したパスワードをコピーして保存できます。 |
| パスワード確認 | 設定したパスワードを再度入力して二重確認します。2回入力したパスワードが一致しない場合、`2回入力した新しいパスワードが一致しません。再入力してください` というメッセージが表示されます。 |
| グローバル権限（オプション） | プルダウンボックスからユーザーが持つことができる権限を選択できます。設定した権限はすべてのデータベースに適用されます。設定されていない場合、デフォルトではそのユーザーには権限が付与されません。  |
| データベース権限 | 新規作成するユーザーが各データベースに対して持つ権限を設定します。指定されたデータベース内のすべてのターゲットに適用されます。設定方法は以下のとおりです：<ol><li>左側のリストボックスから1つまたは複数のデータベースをチェックします。左側のリストボックスには、現在のクラスタ内のすべての選択可能なデータベースが表示されます。データベースが多すぎる場合は、左側のリストボックスの検索ボックスを使用して特定のデータベースを検索することもできます。</li><li>中央の **>** ボタンをクリックします。このとき、チェックされたデータベースは右側のリストボックスに移動します。</li><li>右側のリストボックスで、指定されたデータベース内でユーザーが持つことができる権限をチェックします。対応するデータベースの右上の **すべて** をチェックすると、ユーザーに現在のデータベースのすべての権限を設定できます。</li><li>1、2、3の操作を繰り返して、異なるデータベースに対してユーザー権限を設定します。右側のリストボックスに移動したデータベースが多すぎる場合は、右側の検索ボックスで指定のデータベースを検索することもできます。</li><li>指定されたデータベースのユーザー権限を解除するには、右側のリストボックスでデータベースの右上の **削除** をクリックして、対応するデータベースを左側のリストボックスに戻します。または、右側のリストボックスの右上の **すべての削除** フィールドをクリックし、ポップアップウィンドウで **OK** をクリックすると、右側のリストボックスのすべてのデータベースが左側のリストボックスに戻ります。</li></ol>  |

## ユーザーのロック

**ロック** カラムのスイッチアイコンを使用して、ユーザーをロックするかどうかを制御できます。ユーザーがロックされていない場合は、<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/400.ob-dashboard-tenant-user-01.png" alt="スイッチ" style="height: 20px;"></span> をクリックし、表示されるウィンドウで **OK** をクリックすると、現在のユーザーがロックされます。ロックされたユーザーはログインできなくなりますので、ご注意ください。ユーザーがロックされている場合は、<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/400.ob-dashboard-tenant-user-02.png" alt="スイッチ" style="height: 20px;"></span> をクリックし、表示されるウィンドウで **OK** をクリックすると、現在のユーザーがロック解除されます。ロック解除されたユーザーはログインできるようになります。

<!-- ![ユーザーのロック](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/400.ob-dashboard-tenant-user-03.png) -->

## パスワードの変更

**操作** カラムの **パスワードの変更** フィールドをクリックし、表示されるウィンドウで **新しいパスワード** と **パスワードの確認** を入力します。入力完了後、**OK** をクリックすると、ユーザーのパスワード変更が完了します。

<!-- ![パスワードの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/400.ob-dashboard-tenant-user-04.png) -->

## 権限の変更

**操作** カラムの **権限の変更** フィールドをクリックすると、対応するユーザーのグローバル権限とデータベース権限を変更できます。変更方法は以下のとおりです：

1. 左側のリストボックスから1つまたは複数のデータベースを選択します。左側のリストボックスには、現在のクラスタ内のすべての選択可能なデータベースが表示されます。データベースが多すぎる場合は、左側の検索ボックスで指定したいデータベースを検索することもできます。

2. 中央の **>** ボタンをクリックします。これにより、選択されたデータベースが右側のリストボックスに移動します。

3. 右側のリストボックスで、指定したデータベース内でユーザーが持つことができる権限を選択します。対応するデータベースの右上にある **すべて** を選択すると、ユーザーに現在のデータベースのすべての権限を設定できます。

4. 1、2、3の手順を繰り返し、異なるデータベースに対してユーザー権限を設定します。右側のリストボックスに移動したデータベースが多すぎる場合は、右側の検索ボックスで指定したいデータベースを検索することもできます。

5. 指定したデータベースのユーザー権限を取り消す必要がある場合は、右側のリストボックスでデータベースの右上にある **削除** をクリックして、対応するデータベースを左側のリストボックスに戻します。または、右側のリストボックスの右上にある **すべてを削除** フィールドをクリックし、表示されるウィンドウで **OK** をクリックすると、右側のリストボックスのすべてのデータベースが左側のリストボックスに戻ります。

6. 設定完了後、**送信** をクリックすると、変更が完了します。

## ユーザーの削除

**操作** 列の **削除** ボタンをクリックし、表示されるウィンドウの入力欄に `delete` と入力して **削除** をクリックすると、該当するユーザーが削除されます。ユーザーを削除すると、そのユーザーの下にあるすべてのオブジェクトとデータも削除されるため、慎重に操作してください。
