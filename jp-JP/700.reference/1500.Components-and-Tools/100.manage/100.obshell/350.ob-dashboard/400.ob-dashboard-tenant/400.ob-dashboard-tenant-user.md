# ユーザー管理

左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">テナント管理</UI-TERM>** をクリックし、**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">テナント</UI-TERM>** ページで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** のテナント名をクリックします。対応するテナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動したら、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.User.MySQL.UserManagement">ユーザー管理</UI-TERM>** をクリックすると、**<UI-TERM key="oms-v2.utils.hooks.useLayoutMenus.UserManagement">ユーザー管理</UI-TERM>** ページに移動します。本記事では、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.UserManagement">ユーザー管理</UI-TERM>** ページの情報と、このページで実行できる操作について説明します。

## ユーザーの新規作成

**<UI-TERM key="oms-v2.SystemParam.contants.UserManagement">ユーザー管理</UI-TERM>** ページの右上にある **<UI-TERM key="odc.components.UserPage.CreateUser">新規ユーザーの作成</UI-TERM>** ボタンをクリックし、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.CreateADatabaseUser">新規データベースユーザー</UI-TERM>** ページで、**<UI-TERM key="odc.component.Login.RegisterForm.Username">ユーザー名</UI-TERM>**、**<UI-TERM key="src.page.Workspace.Edit.2CF94BE5">パスワード</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.GlobalPermissions">グローバル権限</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.DatabasePermissions">データベース権限</UI-TERM>** を設定します。設定後、**<UI-TERM key="ocp-v2.Oracle.Component.RoleSelect.Submitted">提出する</UI-TERM>** をクリックすると新規作成が完了します。

<!-- ![ユーザーの作成](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/400.tenant/400.ob-dashboard-tenant-user-02.png) -->

| パラメータ  | 説明  |
|-------|------|
| ユーザー名 | 新規ユーザーの名前を設定します。ユーザー名は以下の要件を満たす必要があります：<ul><li>長さが2～64文字です。</li><li>小文字の英字、数字、アンダースコアを含めることができますが、英字で始まる必要があります。</li></ul> |
| パスワード | パスワードの複雑さは以下の要件を満たす必要があります：<ul><li>長さが8～32文字です。</li><li>少なくとも以下の4種類の文字をそれぞれ2つ含みます：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（~!@#%^&*_-+=\|(){}[]:;,.?/）</li></ul> 設定後、**<UI-TERM key="oat.components.Password.CopyPassword">パスワードをコピーする</UI-TERM>** をクリックして、後の使用のために設定したパスワードをコピー保存することができます。 |
| パスワード確認 | 設定したパスワードを再度入力して二重確認します。入力した2つのパスワードが一致しない場合、`2回入力した新しいパスワードが一致しません。再入力してください`というメッセージが表示されます。 |
| グローバル権限（オプション） | ドロップダウンリストからユーザーが持つことができる権限を選択できます。設定された権限はすべてのデータベースに適用されます。設定しない場合、デフォルトでこのユーザーにはいかなる権限も付与されません。  |
| データベース権限 | 新規作成するユーザーの各データベースに対する権限を設定します。これは指定されたデータベース内のすべてのターゲットに適用されます。設定方法は以下のとおりです：<ol><li>左側のリストボックスで1つまたは複数のデータベースを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのデータベースが表示されます。データベースが多すぎる場合は、左側のリストボックスの検索ボックスで特定のデータベースを検索することもできます。</li><li>中央の **>** ボタンをクリックします。すると、選択されたデータベースが右側のリストボックスに移動します。</li><li>右側のリストボックスで、指定したデータベース内でユーザーが持つことができる権限を選択します。対応するデータベースの右上にある **<UI-TERM key="ocp-v2.component.common.BinlogClusterSelect.All">すべて</UI-TERM>** を選択すると、ユーザーに現在のデータベースのすべての権限を付与できます。</li><li>1、2、3の手順を繰り返して、異なるデータベースに対するユーザー権限を設定します。右側のリストボックスに移動したデータベースが多すぎる場合は、右側の検索ボックスで特定のデータベースを検索することもできます。</li><li>指定したデータベースのユーザー権限を取り消す場合は、右側のリストボックスでデータベースの右上にある **<UI-TERM key="obcloud-console.components.MessageSubscriptionTable.ReceiverManageModal.Delete">削除</UI-TERM>** をクリックして、該当するデータベースを左側のリストボックスに戻します。または、右側のリストボックスの右上にある **<UI-TERM key="obcloud-console.create.RestoreTransfer.RemoveAll">すべて削除</UI-TERM>** フィールドをクリックし、ポップアップウィンドウで **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeDrawer.Determine">確定</UI-TERM>** をクリックすると、右側のリストボックスのすべてのデータベースが左側のリストボックスに戻ります。</li></ol>  |

## ユーザーのロック

**<UI-TERM key="ocp-v2.Auth.User.Locking">ロックする</UI-TERM>** のスイッチアイコンをクリックすると、ユーザーのロック状態を切り替えることができます。ユーザーがロックされていない状態の場合、<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/400.ob-dashboard-tenant-user-01.png" alt="スイッチ" style="height: 20px;"></span> をクリックし、ポップアップウィンドウで **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">確定</UI-TERM>** をクリックすると、現在のユーザーをロックできます。ロックされたユーザーはログインできなくなりますので、ご注意ください。ユーザーがロックされている場合、<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/400.ob-dashboard-tenant-user-02.png" alt="スイッチ" style="height: 20px;"></span> をクリックし、ポップアップウィンドウで **<UI-TERM key="ocp-v2.TrendAndOutline.SQLHistory.Ok">確定</UI-TERM>** をクリックすると、現在のユーザーをロック解除できます。ロック解除されたユーザーはログインできるようになります。

## パスワードの変更

**<UI-TERM key="obcloud-console.Detail.CrossProjectAuth.Operation">操作</UI-TERM>** の **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.ChangePassword">パスワードを変更</UI-TERM>** フィールドをクリックし、ポップアップウィンドウに **<UI-TERM key="oms-v2.components.ResetPassword.ResetOwnPassword.NewPassword">新しいパスワード</UI-TERM>** と **<UI-TERM key="ocp-v2.Detail.Component.ChangePasswordModal.ConfirmPassword">パスワードの確認</UI-TERM>** を入力します。入力後、**<UI-TERM key="oms-cloud.ETL.ColumnFamilyEtl.Confirm">OK</UI-TERM>** をクリックすると、ユーザーのパスワード変更が完了します。

## 権限の変更

**<UI-TERM key="odc.Env.components.InnerEnvironment.Operation">操作</UI-TERM>** の **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.ModifyPermissions">権限の変更</UI-TERM>** フィールドをクリックすると、対応するユーザーのグローバル権限とデータベース権限を変更できます。変更方法は以下のとおりです：

1. 左側のリストボックスで1つまたは複数のデータベースを選択します。左側のリストボックスには、現在のクラスタで利用可能なすべてのデータベースが表示されます。データベースが多すぎる場合は、左側の検索ボックスで特定のデータベースを検索することもできます。

2. 中央の **>** ボタンをクリックします。すると、選択されたデータベースが右側のリストボックスに移動します。

3. 右側のリストボックスで、指定したデータベース内でユーザーが持つことができる権限を選択します。対応するデータベースの右上にある **<UI-TERM key="oat.pages.Task.All">すべて</UI-TERM>** を選択すると、ユーザーに現在のデータベースのすべての権限を付与できます。

4. 1、2、3の手順を繰り返して、異なるデータベースに対するユーザー権限を設定します。右側のリストボックスに移動したデータベースが多すぎる場合は、右側の検索ボックスで特定のデータベースを検索することもできます。

5. 指定したデータベースのユーザー権限を取り消す場合は、右側のリストボックスでデータベースの右上にある **<UI-TERM key="ocp-v2.Detail.Component.DeleteReplicaModal.Delete">削除</UI-TERM>** をクリックして、該当するデータベースを左側のリストボックスに戻します。または、右側のリストボックスの右上にある **<UI-TERM key="obcloud-console.create.RestoreTransfer.RemoveAll">すべて削除</UI-TERM>** フィールドをクリックし、ポップアップウィンドウで **<UI-TERM key="obcloud-console.component.UnbindModal.Determine">OK</UI-TERM>** をクリックすると、右側のリストボックスのすべてのデータベースが左側のリストボックスに戻ります。

6. 設定後、**<UI-TERM key="oma-pro.EvaluationLabel.CodeAssessment.formComponent.Submit">提出する</UI-TERM>** をクリックすると変更が完了します。

## ユーザーの削除

**<UI-TERM key="oms-community.Operation.components.operationDetail.Operation">操作</UI-TERM>** の **<UI-TERM key="odc.src.store.snippet.Delete">削除</UI-TERM>** フィールドをクリックし、ポップアップウィンドウの入力欄に `delete` と入力してから、**<UI-TERM key="odc.SensitiveColumn.components.ScanForm.Delete">削除</UI-TERM>** ボタンをクリックすると、対応するユーザーを削除できます。ユーザーを削除すると、そのユーザーの下にあるすべてのオブジェクトとデータも削除されますので、ご注意ください。
