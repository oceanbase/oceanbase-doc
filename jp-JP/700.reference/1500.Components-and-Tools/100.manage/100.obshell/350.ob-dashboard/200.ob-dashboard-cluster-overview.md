# クラスタ情報

obshell Dashboardにログインすると、システムはデフォルトで **クラスタ管理** ページに移動します。**クラスタ管理** ページには、現在ログインしているユーザーのクラスタ概要情報が表示されます。これには、**クラスタ割り当てリソース**、**OBServer統計**、**テナント統計**、**テナントメジャーコンパクション時間Top3**、**テナントリソース使用量Top3**、および **トポロジー構造** が含まれます。また、パラメータ管理、クラスタの起動・停止、クラスタバージョンのアップグレード、およびobshellのアップグレード操作もサポートしています。

本記事では、**クラスタ管理** ページの表示情報についてのみ説明します。その他の操作手順については、[クラスタ管理](300.ob-dashboard-cluster.md)を参照してください。

## クラスタ割り当てリソース

**クラスタ** エリアには、クラスタの稼働状態およびクラスタのCPU、メモリ、ディスクのうちテナントに割り当てられた割合が表示されます。リソースの棒グラフ部分にカーソルを合わせると、詳細な割り当て状況が表示されます。モジュールの右上の **···** にカーソルを合わせると、クラスタ名とデプロイメントモードの情報を確認できます。

## OBServer統計

**OBServer統計** モジュールでは、クラスタ内のOBServerノードの稼働状態を確認でき、異常な状態のOBServerノードに対する運用保守管理を容易に行えます。

<!-- ![OBServer統計](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-02.png) -->

## テナント統計

**テナント統計** モジュールでは、クラスタ内のテナントの稼働状態を確認でき、異常な状態のテナントに対する運用保守管理を容易に行えます。稼働状態の後ろにある数字をクリックすると、ページは **テナント管理** ページに移動します。

<!-- ![テナント統計](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-03.png) -->

## テナントメジャーコンパクション時間Top3

**テナントメジャーコンパクション時間Top3** エリアには、直近のメジャーコンパクション時間で並べ替えられた上位3つのテナントが表示されます。メジャーコンパクション（Major freeze）とは、動的および静的データをマージする操作であり、時間がかかります。ダンプによって生成された増分データが一定量に達すると、メジャーコンパクション操作によって大規模なバージョンの統合が実現されます。

<!-- ![メジャーコンパクション時刻](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-09.png) -->

## テナントリソース使用量Top3

**CPU消費比率**、**メモリ消費比率**、および **データ量** の上位3つのOceanBaseテナントデータを表示します。

<!-- ![リソース使用状況](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-06.png) -->
