# クラスタ情報

obshell Dashboardにログインすると、システムはデフォルトで**クラスタ管理**ページに移動します。**クラスタ管理**ページでは、現在のログインユーザーの下にあるクラスタの概要情報が表示されます。これには、**クラスタ割り当てリソース**、**OBServer統計**、**テナント統計**、**テナントコンパクション時間Top3**、**テナントリソース使用量Top3**、および**トポロジー**が含まれます。同時に、パラメータ管理、クラスタの起動・停止、クラスタバージョンのアップグレード、およびobshellのアップグレード操作もサポートしています。

本記事では、**クラスタ管理**ページの表示情報についてのみ説明します。その他の操作手順については、[クラスタ管理](300.ob-dashboard-cluster.md)を参照してください。

## クラスタ割り当て済みリソース

**クラスタ** セクションには、クラスタの稼働状態と、クラスタのCPU、メモリ、ディスクがテナントに割り当てられた割合が表示されます。リソースの棒グラフ部分にカーソルを移動すると、詳細な割り当て状況が表示されます。モジュールの右上にある **···** にカーソルを移動すると、クラスタ名とデプロイモードの情報を確認できます。

<!-- ![クラスタ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-01.png) -->

## OBServer統計

**OBServer統計** モジュールでは、クラスタ内のOBServerノードの稼働状態を確認でき、異常な状態のOBServerノードに対して迅速に運用保守管理を行うことができます。

<!-- ![OBServer統計](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-02.png) -->

## テナント統計

**テナント統計** モジュールでは、クラスタ内のテナントの稼働状態を確認でき、異常な状態のテナントに対して迅速に運用保守管理を行うことができます。稼働状態の後ろにある数字をクリックすると、ページは **テナント管理** ページにジャンプします。

<!-- ![テナント統計](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-03.png) -->

## テナントコンパクション時間Top3

**テナントコンパクション時間Top3** セクションには、直近のコンパクション時間でソートされた上位3つのテナントが表示されます。コンパクション操作（Major freeze）とは、動的および静的データをマージするもので、時間がかかります。ダンプによって生成された増分データが一定量蓄積されると、コンパクション操作によってメジャーコンパクションが実現されます。

<!-- ![コンパクション時間](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-09.png) -->

## テナントリソース使用量Top3

**CPU消費率**、**メモリ消費率**、**データ量** の上位3つのOceanBaseテナントデータを表示します。

<!-- ![リソース使用](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/200.cluster/200.ob-dashboard-cluster-overview-06.png) -->

## トポロジー

**トポロジー** エリアで、クラスタ内のゾーンの名前、所属するリージョン、OBServer数、ルートサーバー、およびステータスを確認できます。ゾーン名の前にある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/200.ob-dashboard-cluster-overview-01.png" alt="展開" style="height: 20px;"></span> をクリックすると、そのゾーンの **OBServer IP**、**SQLポート**、**RPCポート**、**ハードウェアアーキテクチャ**、**リソース使用状況**、**ステータス** を含むOBServerの詳細を表示できます。**ステータス** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンをクリックすると、ゾーンのステータスでゾーンをフィルタリングできます。
