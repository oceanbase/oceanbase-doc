# タスク管理

obshell Dashboardインターフェースを通じて開始されたOceanBaseクラスタ、テナント、およびホストの運用保守・管理タスクや、obshell Dashboardシステム自体の管理タスクについて、obshell Dashboardはその管理と表示を提供します。

## タスクの詳細を見る

obshell Dashboardに**実行中**または**失敗**のタスクがある場合、obshell Dashboardのシステムページ右上の**タスク**に具体的なタスク数が表示されます。タスクの詳細は以下の2つの方法で確認できます：

* 方法1：obshell Dashboardコンソールにログインした後、ページ右上の**タスク**フィールドをクリックすると、**タスクセンター**に入ります。

* 方法2：obshell Dashboardコンソールにログインした後、左側のナビゲーションバーで**システム管理** > **タスクセンター**をクリックして、**タスクセンター**ページに入ります。

タスクは状態でフィルタリングするか、検索ボックスで指定したタスクを見つけて、対応するタスク名をクリックすると詳細を確認できます。

<!-- ![タスクセンター](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.5/zh-CN/700.reference/1500.Components-and-Tools/100.obshell/700.ob-dashboard-task-01.png) -->

タスクの種類は**ローカルタスク**と**クラスタタスク**の2種類があります。詳細は以下の通りです：

* **ローカルタスク**には、**非運用**、**グローバル運用**、**OBProxy運用**の3種類の運用タイプがあります。グローバル運用タスク同士は互斥し、OBProxy運用タスク同士も互斥しますが、グローバル運用タスクとOBProxy運用タスクは共存可能です。

* **クラスタタスク**には、**非運用**、**グローバル運用**、**テナント運用**の3種類の運用タイプがあります。グローバル運用タスク同士は互斥し、グローバル運用タスクとテナント運用タスクも互斥しますが、異なるテナントのテナント運用タスクは共存可能です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>上記で述べた<b>共存</b>と<b>互斥</b>の概念は、いずれも未完了のタスクに関するものです。ローカルタスクの種類であるグローバル運用タスクを例にすると、未完了のグローバル運用タスクがある場合、別のグローバル運用タスクを開始することはできませんが、別のOBProxy運用タスクを開始することは可能です。</p>
</main>

タスクの実行に失敗した場合は、タスク詳細ページの右側に表示されるログ情報を基にトラブルシューティングを行うか、右側のログ情報ページの右上にある**ログをダウンロード**をクリックして、現在の段階のログをダウンロードし、公式サイトの[Q&Aセクション](https://open.oceanbase.com/)に投稿すると、専門スタッフがトラブルシューティングと対応を手伝います。

## 失敗したタスクの管理

タスクが **失敗** した場合、タスクの再試行、ロールバック、スキップ操作をサポートしています。

失敗したタスクを管理する方法は以下の2つです：

* 方法1：obshell Dashboardにログインし、ページ右上の **タスク** フィールドをクリックして **タスクセンター** に移動します。タスクリストで操作対象の失敗したタスク名をクリックし、タスク詳細ページに進みます。

* 方法2：obshell Dashboardにログインし、左側のナビゲーションバーで **システム管理** > **タスクセンター** をクリックして **タスクセンター** ページに移動します。タスクリストで操作対象の失敗したタスク名をクリックし、タスク詳細ページに進みます。

以下の操作手順は、方法1を例としています：

1. obshell Dashboardにログインします。

2. ページ右上の **タスク** フィールドをクリックして **タスクセンター** に移動します。

3. タスクリストで操作対象の失敗したタスク名をクリックし、タスク詳細ページに進みます。

4. 右上の **再試行** ボタンをクリックすると、失敗したステップを再実行します。実行が成功すれば、次の手順に進みます。

5. 右上の **ロールバック** ボタンをクリックすると、そのタスクで失敗した箇所から実行されたすべてのステップをロールバックします。実行が成功すれば、次の手順に進みます。

6. 右上の **タスクをスキップ** ボタンをクリックすると、タスク全体が直接スキップされ、タスクの状態は **失敗** から **完了** に変わります。タスクに関連するクラスタやテナントの運用状態には一切影響しません。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>タスクの実行中に、<b>現在の進捗状況を特定</b> をクリックすると、実行中のサブタスクにすばやく移動でき、タスクの実行状態や関連ログ情報を確認しやすくなります。<b>失敗</b> したタスクについては、<b>現在の進捗状況を特定</b> をクリックすると、実行失敗したサブタスクとタスクの実行異常情報をすばやく特定できます。</p>
   </main>
