# タスク管理

obshell Dashboardコンソールにログインした後、ページ右上の**タスク**フィールドをクリックすると、**タスクセンター**に移動します。**タスクセンター**では、obshell Dashboard内のすべてのタスクを確認できます。

タスクはタスクの状態でフィルタリングしたり、検索ボックスで特定のタスクを表示したりできます。対応するタスク名をクリックすると、タスクの詳細を確認できます。

タスクの種類は**ローカルタスク**と**クラスタタスク**の2種類に分かれており、具体的な説明は以下の通りです：

* **ローカルタスク**については、**非メンテナンス**、**グローバルメンテナンス**、**OBProxyメンテナンス**の3種類の運用保守タイプがあります。グローバルメンテナンスタスク間は排他的であり、OBProxyメンテナンスタスク間も排他的ですが、グローバルメンテナンスタスクとOBProxyメンテナンスタスクは共存可能です。

* **クラスタタスク**については、**非メンテナンス**、**グローバルメンテナンス**、**テナントメンテナンス**の3種類の運用保守タイプがあります。グローバルメンテナンスタスク間は排他的であり、グローバルメンテナンスタスクとテナントメンテナンスタスク間も排他的ですが、異なるテナントのテナントメンテナンスタスクは共存可能です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>上記で述べられている<b>共存</b>と<b>排他</b>の概念は、未完了のタスクに対して適用されます。例えば、ローカルタスクのグローバルメンテナンスタスクの場合、未完了のグローバルメンテナンスタスクがある場合、別のグローバルメンテナンスタスクを開始することはできませんが、別のOBProxyメンテナンスタスクを開始することはできます。</p>
</main>

タスクの実行に失敗した場合は、タスク詳細ページ右側に表示されるログ情報を基にトラブルシューティングを行うか、右側のログ情報ページ右上の**ログダウンロード**をクリックして、現在の段階のログを公式サイトの[Q&Aセクション](https://open.oceanbase.com/)に投稿することができます。専門スタッフがトラブルシューティングと処理を支援します。
