# ソフトウェアパッケージ管理

左側のナビゲーションバーで **システム構成** > **ソフトウェアパッケージ管理** をクリックして **ソフトウェアパッケージ** ページに移動します。本記事では、obshell Dashboardを使用してソフトウェアパッケージを表示またはアップロードする方法について説明します。

## ソフトウェアパッケージの表示

ソフトウェアパッケージページには、obshell Dashboardにアップロードされたソフトウェアパッケージの **ソフトウェアパッケージ名**、**バージョン**、**ハードウェアアーキテクチャ**、**サイズ(MB)**、**MD5**、**アップロード時間** が表示されます。

**バージョン** と **ハードウェアアーキテクチャ** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンを使用して、ソフトウェアパッケージのバージョンとハードウェアアーキテクチャでソフトウェアパッケージをフィルタリングして表示することができます。また、**ソフトウェアパッケージ名** と **アップロード時間** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-03.png" alt="ソート" style="height: 20px;"></span> アイコンを使用して、ソフトウェアパッケージを昇順または降順に並べ替えることもできます。アップロードされたソフトウェアパッケージが多すぎる場合は、ページの左上にある検索ボックスで指定したソフトウェアパッケージが存在するかどうかを検索できます。

## ソフトウェアパッケージのアップロード

**ソフトウェアパッケージ** ページの右上にある **ソフトウェアパッケージのアップロード** ボタンをクリックし、**ソフトウェアパッケージの選択** をクリックしてローカルからインストールパッケージをアップロードします。ローカルに対応するインストールパッケージがない場合は、**RPMパッケージのダウンロードURL** をクリックしてオープンソースミラーサイトから対応するソフトウェアパッケージをダウンロードできます。
