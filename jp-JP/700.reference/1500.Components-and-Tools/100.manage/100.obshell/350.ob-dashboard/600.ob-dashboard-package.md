# ソフトウェアパッケージ管理

左側のナビゲーションバーで **システム設定** > **<UI-TERM key="ocp-v2.src.constant.auditEvent.SoftwarePackageManagement">ソフトウェアパッケージ管理</UI-TERM>** をクリックして、**<UI-TERM key="ocp-v2.src.constant.auth.SoftwarePackage">ソフトウェアパッケージ</UI-TERM>** ページに移動します。この記事では、obshell Dashboardを使用してソフトウェアパッケージを表示またはアップロードする方法について説明します。

## ソフトウェアパッケージの表示

ソフトウェアパッケージページには、obshell Dashboardにアップロードされたソフトウェアパッケージの **<UI-TERM key="ocp-v2.page.Package.PackageName">パッケージ名</UI-TERM>**、**<UI-TERM key="ocp-v2.MultiCluster.Detail.Version">バージョン</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Component.ReinstallModal.HardwareArchitecture">ハードウェアアーキテクチャ</UI-TERM>**、**サイズ(MB)**、**MD5**、および **<UI-TERM key="ocp-v2.page.Package.UploadTime">アップロード時間</UI-TERM>** が表示されます。

**<UI-TERM key="obcloud-business.src.constants.createCluster.Version">バージョン</UI-TERM>** と **<UI-TERM key="oat.components.ImageManager.HardwareArchitecture">ハードウェアアーキテクチャ</UI-TERM>** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンを使用して、バージョンやハードウェアアーキテクチャでソフトウェアパッケージをフィルタリング・表示できます。また、**<UI-TERM key="ocp-v2.page.Package.PackageName">パッケージ名</UI-TERM>** と **<UI-TERM key="ocp-v2.page.Package.UploadTime">アップロード時間</UI-TERM>** の後ろの <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-03.png" alt="ソート" style="height: 20px;"></span> アイコンをクリックすると、昇順または降順でソフトウェアパッケージを並べ替えることができます。アップロード済みのソフトウェアパッケージが多すぎる場合は、ページ上部左側の検索ボックスで指定したソフトウェアパッケージが存在するかどうか検索できます。

## ソフトウェアパッケージのアップロード

**<UI-TERM key="ocp-v2.src.constant.auth.SoftwarePackage">ソフトウェアパッケージ</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.src.hook.usePackageOperatingSystemCheck.UploadSoftwarePackage">ソフトウェアパッケージをアップロードする</UI-TERM>** ボタンをクリックし、**<UI-TERM key="ocp-v2.component.UploadPackageDrawer.SelectASoftwarePackage">パッケージの選択</UI-TERM>** をクリックして、ローカルからインストールパッケージをアップロードします。ローカルに対応するインストールパッケージがない場合は、**RPMパッケージのダウンロードURL** をクリックしてオープンソースミラーサイトにアクセスし、該当するソフトウェアパッケージをダウンロードできます。
