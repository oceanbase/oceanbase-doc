# ソフトウェアパッケージ管理

左側のナビゲーションバーで **システム設定** > **ソフトウェアパッケージ管理** をクリックし、**ソフトウェアパッケージ** ページに移動します。本記事では、obshell Dashboardを使用してソフトウェアパッケージを表示またはアップロードする方法について説明します。

## ソフトウェアパッケージの表示

ソフトウェアパッケージページには、obshell Dashboardにアップロードされたソフトウェアパッケージの **パッケージ名**、**バージョン**、**ハードウェアアーキテクチャ**、**サイズ(MB)**、**MD5**、**アップロード時間** が表示されます。

**バージョン** と **ハードウェアアーキテクチャ** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンを使用して、バージョンやハードウェアアーキテクチャでソフトウェアパッケージをフィルタリング・表示できます。また、**パッケージ名** と **アップロード時間** の後ろにある <span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="ソート" style="height: 20px;"></span> アイコンを使用して、昇順または降順でソフトウェアパッケージを並べ替えることができます。アップロード済みのソフトウェアパッケージが多すぎる場合は、ページ上部左側の検索ボックスで指定したソフトウェアパッケージが存在するかどうか検索できます。

## ソフトウェアパッケージのアップロード

**ソフトウェアパッケージ** ページの右上にある **ソフトウェアパッケージをアップロード** ボタンをクリックし、**ソフトウェアパッケージを選択** してローカルからインストールパッケージをアップロードします。ローカルに対応するインストールパッケージがない場合は、**RPMパッケージのダウンロードURL** をクリックしてオープンソースミラーサイトから対応するソフトウェアパッケージをダウンロードできます。
