# パラメータ管理

本記事では、obshell Dashboardを使用してOceanBaseクラスタのパラメータを確認および変更する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><b>クラスタ管理</b>ページで表示されるパラメータはすべてOceanBaseクラスタの構成パラメータ（クラスタレベルおよびテナントレベル）です。<b>テナント管理</b>ページで表示されるパラメータは、OceanBaseクラスタのテナントレベル構成パラメータとグローバルシステム変数です。</p>
</main>

## クラスタ管理ページ

左側のナビゲーションバーで**クラスタ管理**をクリックし、**クラスタ管理**ページで右上の**パラメータ管理**をクリックして、**パラメータ管理**ページに移動します。

**パラメータ管理**ページには、構成パラメータの**パラメータ名**、**カテゴリ**、**現在値**、**説明**、**再起動が必要かどうか**、**読み取り専用**かどうか、およびパラメータに対して実行できる操作が表示されます。特定の構成パラメータを確認するには、ページの右上にある検索ボックスで該当するパラメータを検索できます。また、ページ内のさまざまな列の後ろにあるフィルターボタンを使用して、異なるタイプごとに構成パラメータを表示することもできます。現在、パラメータカテゴリ（**カテゴリ**）、有効範囲（**現在値**）、有効化方法（**再起動が必要かどうか**）、変更は可能かどうか（**読み取り専用**）など、いくつかのタイプで構成パラメータを表示することがサポートされています。

<!-- ![クラスタ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-01.png) -->

**操作**列の**値の変更**フィールドをクリックすると、対応する構成パラメータの**値**、**有効範囲**、**適用対象**を変更できます。異なる有効範囲の値を設定する場合は、**+ 値を追加**をクリックして複数の値を設定できます。設定完了後、**OK**ボタンをクリックし、値の変更情報を確認した上で再度**OK**をクリックすると、パラメータの変更が完了します。

<!-- ![パラメータの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-02.png) -->

## テナント管理ページ

左側のナビゲーションバーで**テナント管理**をクリックして、**テナント管理**ページに移動します。**テナント一覧**のテナント名をクリックし、テナントの**概要**ページに移動したら、左側のナビゲーションバーの**パラメータ管理**をクリックすると、**パラメータ管理**ページに入ります。

**パラメータ管理**ページには、構成パラメータの**パラメータ名**、**現在値**、**説明**、**読み取り専用**かどうか、およびパラメータに対して実行できる操作が表示されます。特定の構成パラメータを確認するには、ページの右上にある検索ボックスで該当するパラメータを検索できます。また、ページの**読み取り専用**の後ろにある<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span> アイコンを使用して、パラメータの変更は可能かどうかをフィルタリングして構成パラメータを確認することもできます。

<!-- ![テナント](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-03.png) -->

**操作**列の**値の変更**フィールドをクリックすると、対応する構成パラメータの値を変更できます。設定完了後、**送信**ボタンをクリックすると、パラメータの変更が完了します。

<!-- ![パラメータの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-04.png) -->
