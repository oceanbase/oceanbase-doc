# パラメータ管理

本記事では、obshell Dashboardを使用してOceanBaseクラスタのパラメータを表示および変更する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><b>クラスタ管理</b>ページで表示されるパラメータはすべてOceanBaseクラスタの構成パラメータ（クラスタレベルおよびテナントレベル）です。<b>テナント管理</b>ページで表示されるパラメータは、OceanBaseクラスタのテナントレベル構成パラメータとGlobalシステム変数です。</p>
</main>

## クラスタ管理ページ

左側のナビゲーションバーで**クラスタ管理**をクリックし、**クラスタ管理**ページで右上の**<UI-TERM key="oceanbase-intl-console.components.Parameter.ParameterConfiguration">パラメータ</UI-TERM>**をクリックして、**<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>**ページに移動します。

**<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>**ページには、構成パラメータの**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Parameter">パラメーター名</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Parameter.List.Category">カテゴリ</UI-TERM>**、**<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.CurrentValue">現在の値</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.Basic.Description">説明</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherToRestartEntryInto">再起動して適用しますか？</UI-TERM>**、**<UI-TERM key="obcloud-console.component.AddReadOnly">読み取り専用</UI-TERM>**の有無、および対象パラメータに対して実行可能な操作が表示されます。特定の構成パラメータを見るには、ページ右上の検索ボックスで該当するパラメータを検索できます。また、ページ内の各列の後ろにあるフィルターボタンを使用して、パラメータの種類別に表示することもできます。現在、パラメータのカテゴリ（**<UI-TERM key="ocp-v2.Detail.Parameter.List.Category">カテゴリ</UI-TERM>**）、適用範囲（**<UI-TERM key="ocp-v2.MultiAzone.Parameter.CurrentValue">現在の値</UI-TERM>**）、適用方法（**<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.WhetherToRestartEntryInto">再起動して適用しますか？</UI-TERM>**）、変更は可能か（**<UI-TERM key="ocp-v2.Topo.TopoGraph.ReadOnly">読み取り専用</UI-TERM>**）に基づいて、パラメータを表示することができます。

<!-- ![クラスタ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-01.png) -->

**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Operation">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyTheValue">値を変更する</UI-TERM>**フィールドをクリックすると、対応する構成パラメータの**<UI-TERM key="odc.ruleItems.CharItem.Value">値</UI-TERM>**、**<UI-TERM key="oas.SqlList.TabsTable.ScopeOfEntryIntoForce">適用範囲</UI-TERM>**、**<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveObject">発効対象</UI-TERM>**を変更できます。異なる適用範囲の値を設定する場合は、**+ 値を追加**をクリックして複数の値を設定できます。設定後、**<UI-TERM key="oms-v2.Migration.New.Confirmation">確定</UI-TERM>**ボタンをクリックし、値の変更内容を確認した上で、**<UI-TERM key="ocp-v2.TakeOver.Component.LoadBalancer.Ok">確定</UI-TERM>**をクリックすると、パラメータの変更が完了します。

## テナント管理ページ

左側のナビゲーションバーで**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.TenantList.TenantManagement">テナント</UI-TERM>**をクリックして、**<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.TenantManagement">テナント</UI-TERM>**ページに移動します。**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**のテナント名をクリックして、テナントの**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>**ページに移動した後、左側のナビゲーションバーで**<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.tenantMenu.ParameterManagement">パラメータ</UI-TERM>**をクリックすると、**<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.tenantMenu.ParameterManagement">パラメータ</UI-TERM>**ページに移動します。

**<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.clusterMenu.ParameterManagement">パラメータ管理</UI-TERM>**ページには、構成パラメータの**<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">パラメーター名</UI-TERM>**、**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.CurrentValue">現在の値</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Overview.Description">説明</UI-TERM>**、**<UI-TERM key="obcloud-console.TenantUserManagement.ManageAccessObj.ReadOnly">読み取り専用</UI-TERM>**の有無、および対象パラメータに対して実行可能な操作が表示されます。特定の構成パラメータを見るには、ページ右上の検索ボックスで該当するパラメータを検索できます。また、ページの**<UI-TERM key="ocp-v2.Topo.TopoGraph.ReadOnly">読み取り専用</UI-TERM>**の後ろにある<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style="height: 20px;"></span>アイコンをクリックすると、パラメータの変更は可能かどうかでフィルタリングして表示することができます。

<!-- ![テナント](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-03.png) -->

**<UI-TERM key="ocp-v2.Component.SQLTable.Actions">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">値を修正する</UI-TERM>**フィールドをクリックすると、対応する構成パラメータの値を変更できます。設定後、**<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Submitted">送信</UI-TERM>**ボタンをクリックすると、パラメータの変更が完了します。
