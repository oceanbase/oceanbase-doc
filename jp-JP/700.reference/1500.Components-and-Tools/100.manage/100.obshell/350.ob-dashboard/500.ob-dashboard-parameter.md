# パラメータ管理

本記事では、obshellダッシュボードを使用してOceanBaseクラスタのパラメータを表示および変更する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><b>クラスタ管理</b>ページで表示されるパラメータはすべてOceanBaseクラスタの構成パラメータ（クラスタレベルとテナントレベル）であり、<b>テナント管理</b>ページで表示されるパラメータはOceanBaseクラスタのテナントレベルの構成パラメータとグローバルシステム変数です。</p>
</main>

## クラスタ管理ページ

左側のナビゲーションバーから**クラスタ管理**をクリックし、**クラスタ管理**ページで右上の**パラメータ管理**をクリックして**パラメータ管理**ページに移動します。

**パラメータ管理**ページには、構成パラメータの**パラメータ名**、**カテゴリ**、**現在値**、**説明**、**再起動後に有効化**、**読み取り専用**かどうか、およびパラメータに対して実行できる操作が表示されます。特定の構成パラメータを表示するには、ページ右上の検索ボックスで該当する構成パラメータを検索します。また、ページ内の異なる列の後ろにあるフィルタボタンを使用して、パラメータの種類別に構成パラメータを表示することもできます。現在、パラメータの種類（**カテゴリ**）、適用範囲（**現在値**）、適用方法（**再起動後に有効化**）、変更可否（**読み取り専用**）に基づいて構成パラメータを表示することがサポートされています。

<!-- ![クラスタ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-01.png) -->

**操作**列の**値の変更**フィールドをクリックすると、対応する構成パラメータの**値**、**適用範囲**、**適用対象**を変更できます。異なる適用範囲の値を設定するには、**+ 値の追加**をクリックして複数の値を設定します。設定完了後、**OK**ボタンをクリックし、値の変更情報を確認したら**OK**をクリックすると、パラメータの変更が完了します。

<!-- ![パラメータの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-02.png) -->

## テナント管理ページ

左側のナビゲーションバーから**テナント管理**をクリックして**テナント管理**ページに移動し、**テナント一覧**のテナント名をクリックしてテナントの**概要**ページに移動した後、左側のナビゲーションバーから**パラメータ管理**をクリックすると、**パラメータ管理**ページに移動します。

**パラメータ管理**ページには、構成パラメータの**パラメータ名**、**現在値**、**説明**、**読み取り専用**かどうか、およびパラメータに対して実行できる操作が表示されます。特定の構成パラメータを表示するには、ページ右上の検索ボックスで該当する構成パラメータを検索します。また、ページの**読み取り専用**の後ろにある<span style="vertical-align: middle;"><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルタ" style="height: 20px;"></span>アイコンを使用して、パラメータの変更可否に基づいて構成パラメータをフィルタリングして表示することもできます。

<!-- ![テナント](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-03.png) -->

**操作**列の**値の変更**フィールドをクリックすると、対応する構成パラメータの値を変更できます。設定完了後、**送信**ボタンをクリックすると、パラメータの変更が完了します。

<!-- ![パラメータの変更](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.ob-dashboard-parameter-04.png) -->
