# obshell ごみ箱コマンドグループ

このドキュメントでは、obshellのごみ箱コマンドグループについて説明します。ごみ箱コマンドグループは、OceanBaseクラスタのごみ箱内のプロパティを管理するために使用されます。このコマンドグループを使用するには、OceanBaseクラスタが初期化済みである必要があります。コマンドのヘルプ情報を表示するには、コマンドに`-h` / `--help`オプションを指定します。タスク実行時にエラーが発生した場合は、`-v` / `--verbose`オプションを指定してコマンドの詳細な実行プロセスを確認することもできます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>現在、このコマンドグループにはtenantという1つのサブコマンドグループしかありません。</p>
</main>

## obshell recyclebin tenant purge

このコマンドを使用すると、ごみ箱内の指定されたテナントを削除でき、そのリソースプールもクリーンアップされます。

```shell
${home_path}/bin/obshell recyclebin tenant purge {tenant_name | object_name} [-y]

# example
/home/admin/oceanbase/bin/obshell recyclebin tenant purge t1 -y
/home/admin/oceanbase/bin/obshell recyclebin tenant purge '__recycle_$_1_1720679549921648'
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。`tenant_name` は削除対象のテナントの元の名前を設定し、`object_name` はごみ箱内の削除対象のテナントのオブジェクト名を設定します。どちらか一方を設定するだけで構いません。

例の `t1` はごみ箱内で削除対象のテナントの元の名前であり、`__recycle_$_1_1720679549921648` はごみ箱内で削除対象のテナントのオブジェクト名です。

`-y`/`--yes` を使用して、再確認をキャンセルするかどうかを制御できます。値を渡す必要はありません。

## obshell recyclebin tenant flashback

このコマンドを使用すると、ごみ箱内の指定されたテナントを復元できます。

```shell
${home_path}/bin/obshell recyclebin tenant flashback {tenant_name | object_name} [-n]

# example
/home/admin/oceanbase/bin/obshell recyclebin tenant flashback t1 -n t2
/home/admin/oceanbase/bin/obshell recyclebin tenant flashback __recycle_$_1_1720679549921648
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。`tenant_name` は復元対象のテナントの元の名前を設定し、`object_name` はごみ箱内の復元対象のテナントのオブジェクト名を設定します。どちらか一方を設定するだけで構いません。

例の `t1` はごみ箱内で復元対象のテナントの元の名前であり、`__recycle_$_1_1720679549921648` はごみ箱内で復元対象のテナントのオブジェクト名です。

`-n`/`--new_name` を使用して、ごみ箱から復元後のテナントの新しい名前を設定できます。指定されていない場合は、元のテナント名に復元されます。

## obshell recyclebin tenant show

このコマンドを使用すると、ごみ箱内の指定されたテナントまたはすべてのテナントを表示できます。

```shell
${home_path}/bin/obshell recyclebin tenant show [tenant_name | object_name]

# example
obshell recyclebin tenant show t1
obshell recyclebin tenant show '__recycle_$_1_1720679549921648'
obshell recyclebin tenant show
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。`tenant_name` は表示対象のテナントの元の名前を設定し、`object_name` はごみ箱内の表示対象のテナントのオブジェクト名を設定します。どちらか一方を設定するだけで構いません。両方とも設定しない場合は、ごみ箱内のすべてのテナントがデフォルトで表示されます。

例の `t1` はごみ箱内で表示対象のテナントの元の名前であり、`__recycle_$_1_1720679549921648` はごみ箱内で表示対象のテナントのオブジェクト名です。
