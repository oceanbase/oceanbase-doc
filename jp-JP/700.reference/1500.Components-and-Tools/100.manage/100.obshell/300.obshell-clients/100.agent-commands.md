# obshellエージェントコマンド

本記事では、obshellのエージェントコマンドについて説明します。エージェントコマンドはobshellの管理に使用できます。コマンドに`-h`/`--help`オプションを設定すると、そのコマンドのヘルプ情報を表示できます。

## obshell agent start

このコマンドを使用して、obshellを起動します。

```shell
${home_path}/bin/obshell agent start [--ip] [-P] [--takeover] [--password]

# example
/home/admin/oceanbase/bin/obshell agent start --ip 10.10.10.1 -P 2886
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。

オプションの説明は以下の表のとおりです：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
|------------|----------|---------|---------|------|
| --ip       | いいえ       | string  | なし      | このobshellがバインドされるIPアドレスを設定します。 |
| -P/--port  | いいえ       | int  | 2886    | このobshellがバインドされるポート番号を設定します。 |
| --takeover | いいえ       | int     | 1       | 値を0以外に設定すると、テイクオーバー起動を示します。値を0に設定すると、テイクオーバー以外の起動を示します。デフォルトは`1`で、テイクオーバー起動を意味します。 |
| --password | いいえ       | string  | なし      | このオプションはOceanBaseクラスタのテイクオーバー時にのみ使用します。テイクオーバー時には、このオプションを使用してOceanBaseクラスタのsysテナントのrootユーザーパスワードを指定する必要があります。環境変数`OB_ROOT_PASSWORD`を使用してrootユーザーパスワードを指定することもできます。 |

## obshell agent stop

このコマンドを使用して、obshellを停止します。

```shell
${home_path}/bin/obshell agent stop
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。

OceanBaseクラスタのテイクオーバー時には、`--password`オプションを使用して、OceanBaseクラスタのsysテナントのrootユーザーパスワードを指定する必要があります。環境変数`OB_ROOT_PASSWORD`を使用してrootユーザーパスワードを指定することもできます。

## obshell agent restart

このコマンドを使用して、obshellを再起動します。

```shell
${home_path}/bin/obshell agent restart
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。

## obshell agent upgrade

このコマンドを使用して、obshellをアップグレードします。

```shell
${home_path}/bin/obshell agent upgrade -d [-V] [-t] [-y]

# example
/home/admin/oceanbase/bin/obshell agent upgrade -d /home/admin/oceanbase/upgrade/ -V 4.2.2.0-20231224224959
```

`home_path`はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の`bin`ディレクトリに配置されています。

オプションの説明は以下の表を参照してください。

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
|------------|----------|---------|---------|------|
| -d/--pkg_directory | はい | string | なし | アップグレードパッケージの保存先パスを設定します。 |
| -V/--target_version | いいえ | string | なし | ターゲットバージョンを指定します。形式は正しくする必要があります。例：`4.2.2.0`または`4.2.2.0-20231224224959`。指定しない場合、`-d`ディレクトリ内の最新バージョンのobshell RPMパッケージが選択されます。 |
| -t/--tmp_directory | いいえ | string | ${home_path}/upgrade | アップグレードプロセス中の一時ディレクトリを指定します。ダウンロードしたインストールパッケージや解凍・インストールプロセスで生成されるすべてのファイルを格納します。絶対パスで設定する必要があります。 |
| -y/--yes | いいえ | なし | なし | `-y`/`--yes`を設定すると、二度目の確認を省略します。値を指定する必要はありません。 |
| -v/--verbose | いいえ  | なし  | なし | `-v`/`--verbose`を設定すると、実行プロセスの詳細情報を出力します。値を指定する必要はありません。 |
