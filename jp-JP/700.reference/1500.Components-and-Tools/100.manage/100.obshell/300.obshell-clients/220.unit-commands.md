# obshellリソース仕様コマンドグループ

本記事では、obshellのリソース仕様コマンドグループについて説明します。リソース仕様コマンドグループは、OceanBaseクラスタ内のリソース仕様を管理するために使用されます。このコマンドグループを使用するには、OceanBaseクラスタが初期化済みである必要があります。

コマンド内で`-h` / `--help`オプションを設定することで、コマンドのヘルプ情報を表示できます。また、タスク実行時にエラーが発生した場合は`-v` / `--verbose`オプションを設定して、コマンドの詳細な実行プロセスを確認することもできます。

## obshell unit create

このコマンドを使用すると、クラスタに新しいリソース仕様を作成できます。

```shell
${home_path}/bin/obshell unit create <unit_config_name> -m -c [--min_cpu] [--log_disk_size] [--min_iops] [--max_iops]

# example
/home/admin/oceanbase/bin/obshell unit create unit_1 -m 5G -c 2
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されます。`unit_config_name` は、作成するリソース仕様の名前として設定する必要があります。

コマンドのオプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明  |
|-------|----------|---------|--------|-------|
| -m/--memory_size | はい | string | なし | メモリの仕様を指定します。その最小値は、非表示構成パラメータ`__min_full_resource_pool_memory`によって制御されます(デフォルトは5GB)。システムの安定性を確保するため、メモリ仕様の最小値は4GBに設定することを推奨します。  |
| -c/--max_cpu | はい | float | なし | CPU仕様の上限を指定します。最小値は1で、1コアを表します。 |
| --min_cpu | いいえ | float | なし | CPU仕様の下限を指定します。最小値は1で、1コアを表します。このオプションが指定されていない場合、デフォルト値は構成された`-c`/`--max_cpu`値と等しくなります。 |
| --max_iops | いいえ | int | なし | IOPSの上限を指定します。最小値は1024で、構成値は`--min_iops`値以上である必要があります。このオプションが指定されていない場合、システムは次のルールに基づいて`--max_iops`の値を自動的に計算します：<ul><li><code>--min_iops</code>の値が指定されている場合、<code>--max_iops</code>の値は<code>--min_iops</code>の値と等しくなります。</li><li><code>--min_iops</code>も指定されていない場合、<code>--max_iops</code>と<code>--min_iops</code>の値はどちらも<code>INT64_MAX</code>となります。</li></ul> |
| --min_iops | いいえ | int | なし | IOPSの下限を指定します。最小値は1024です。このオプションが指定されていない場合、システムは次のルールに基づいて`--min_iops`の値を自動的に計算します：<ul><li><code>--max_iops</code>の値が指定されている場合、<code>--min_iops</code>の値は<code>--max_iops</code>の値と等しくなります。</li><li><code>--max_iops</code>も指定されていない場合、<code>--min_iops</code>と<code>--max_iops</code>の値はどちらも<code>INT64_MAX</code>となります。</li></ul> |
| --log_disk_size | いいえ | string | なし | テナントログディスク容量のサイズを指定します。指定されていない場合、デフォルト値はメモリ仕様の3倍のサイズで、最小値は2GBです。 |

## obshell unit show

このコマンドを使用すると、リソース仕様を照会できます。

```shell
${home_path}/bin/obshell unit show [unit_config_name]

# example
/home/admin/oceanbase/bin/obshell unit show
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されます。`unit_config_name` は、照会対象のリソース仕様の名前として設定する必要があります。設定されていない場合、デフォルトではクラスタ内のすべてのユニットリソース仕様が表示されます。

## obshell unit drop

このコマンドを使用すると、指定された未使用のリソース仕様を削除できます。

```shell
${home_path}/bin/obshell unit drop <unit_config_name> [-y]

# example
/home/admin/oceanbase/bin/obshell unit drop unit_1
```

`home_path` はOceanBaseデータベースのインストールディレクトリであり、obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。`unit_config_name` は削除対象のリソース仕様名を設定します。

`-y` / `--yes` を設定することで、確認ダイアログを省略するかどうかを制御できます。このオプションに値を指定する必要はなく、設定した場合は確認ダイアログが省略されます。
