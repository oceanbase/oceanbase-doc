# obshell リソース構成コマンドグループ

本記事では、obshellのリソース構成コマンドグループについて説明します。このコマンドグループは、OceanBaseクラスタ内のリソース構成を管理するために使用されます。このコマンドグループを使用する前に、OceanBaseクラスタが初期化されている必要があります。

コマンドで `-h`/`--help` オプションを設定すると、コマンドのヘルプ情報を表示できます。タスク実行時にエラーが発生した場合、`-v`/`--verbose` オプションを設定すると、コマンドの詳細な実行プロセスを確認できます。

## obshell unit create

このコマンドを使用して、クラスタ用の新しいリソース構成を作成できます。

```shell
${home_path}/bin/obshell unit create <unit_config_name> -m -c [--min_cpu] [--log_disk_size] [--min_iops] [--max_iops]

# example
/home/admin/oceanbase/bin/obshell unit create unit_1 -m 5G -c 2
```

`home_path` はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されます。`unit_config_name` には、作成するリソース構成の名前を設定する必要があります。

コマンドのオプションの説明は以下の表のとおりです：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明  |
|-------|----------|---------|--------|-------|
| -m/--memory_size | はい | string | なし | メモリ構成を指定します。その最小値は隠れたパラメータ `__min_full_resource_pool_memory` によって制御されます（デフォルトは5G）。システムの安定性を確保するため、メモリ構成の最小値は4Gに設定することを推奨します。  |
| -c/--max_cpu | はい | float | なし | CPU構成の上限を指定します。最小値は1で、1 Coreを意味します。 |
| --min_cpu | いいえ | float | なし | CPU構成の下限を指定します。最小値は1で、1 Coreを意味します。このオプションが指定されていない場合、デフォルトで `-c`/`--max_cpu` の値に設定されます。 |
| --max_iops | いいえ | int | なし | IOPSの上限を指定します。最小値は1024です。設定値は `--min_iops` の値以上である必要があります。このオプションが指定されていない場合、システムは以下のルールに基づいて `--max_iops` の値を自動的に計算します：<ul><li><code>--min_iops</code> の値が指定されている場合、<code>--max_iops</code> の値は <code>--min_iops</code> の値と同じになります。</li><li><code>--min_iops</code> も指定されていない場合、<code>--max_iops</code> と <code>--min_iops</code> の値はどちらも <code>INT64_MAX</code> になります。</li></ul> |
| --min_iops | いいえ | int | なし | IOPSの下限を指定します。最小値は1024です。このオプションが指定されていない場合、システムは以下のルールに基づいて `--min_iops` の値を自動的に計算します：<ul><li><code>--max_iops</code> の値が指定されている場合、<code>--min_iops</code> の値は <code>--max_iops</code> の値と同じになります。</li><li><code>--max_iops</code> も指定されていない場合、<code>--min_iops</code> と <code>--max_iops</code> の値はどちらも <code>INT64_MAX</code> になります。</li></ul> |
| --log_disk_size | いいえ | string | なし | テナントログディスク容量のサイズを指定します。指定されていない場合、デフォルトでメモリ構成の3倍のサイズに設定され、最小値は2Gです。 |

## obshell unit show

このコマンドを使用して、リソース構成を照会できます。

```shell
${home_path}/bin/obshell unit show [unit_config_name]

# example
/home/admin/oceanbase/bin/obshell unit show
```

`home_path` はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されます。`unit_config_name` には、照会するリソース構成の名前を設定する必要があります。設定されていない場合、デフォルトでクラスタ内のすべてのユニットリソース構成が表示されます。

## obshell unit drop

このコマンドを使用して、指定された未使用のリソース構成を削除できます。

```shell
${home_path}/bin/obshell unit drop <unit_config_name> [-y]

# example
/home/admin/oceanbase/bin/obshell unit drop unit_1
```

`home_path` はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されます。`unit_config_name` には、削除するリソース構成の名前を設定する必要があります。

`-y`/`--yes` を設定することで、二度目の確認をキャンセルするかどうかを制御できます。このオプションには値を指定する必要はなく、設定するだけで二度目の確認がキャンセルされます。
