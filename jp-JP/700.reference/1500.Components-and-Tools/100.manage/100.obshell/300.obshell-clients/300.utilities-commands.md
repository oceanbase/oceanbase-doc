# obshellタスクコマンドグループ

このドキュメントでは、obshellのタスクコマンドグループについて説明します。タスクコマンドグループはobshellタスクを管理するために使用できます。コマンドで `-h`/`--help` オプションを設定すると、そのコマンドのヘルプ情報を表示できます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>obshell V4.2.3以降、タスクコマンドグループは <code>obshell utilities</code> から <code>obshell task</code> に変更されました。<code>obshell utilities</code> コマンドも引き続き使用できます。<code>obshell utilities</code> コマンドの詳細については、<a href='https://en.oceanbase.com/docs/common-oceanbase-database-10000000001168955'>obshellタスクコマンドグループ</a> を参照してください。</p>
</main>

## obshell task show

このコマンドを使用すると、指定したタスクの情報を表示できます。

```shell
${home_path}/bin/obshell task show [-i]

# example
/home/admin/oceanbase/bin/obshell task show -i 11
```

`home_path` はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -i/--id | いいえ | string | なし | 表示するタスクのIDを指定します。指定しない場合、現在実行中のタスクがデフォルトで表示されます。現在タスクがない場合は、タスク情報は表示されません。 |
| -d/--show_detail | いいえ | なし | なし | タスクの詳細情報を表示するかどうかを制御します。値を指定する必要はありません。 |
| -v/--verbose | いいえ  | なし  | なし | `-v`/`--verbose` を設定すると、実行プロセスの詳細情報を出力します。値を指定する必要はありません。 |

## obshell task cancel

このコマンドを使用すると、未完了のタスクを停止できます。

```shell
${home_path}/bin/obshell task cancel -i

# example
/home/admin/oceanbase/bin/obshell task cancel -i 11
```

`home_path` はOceanBaseデータベースのインストールディレクトリです。obshellはデフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -i/--id | はい | string | なし | キャンセルするタスクのIDを指定します。 |
| -y/--yes  | いいえ  | なし  |  なし   | クリア確認を行うかどうかを制御します。値を指定する必要はありません。  |

## obshell task watch

このコマンドを使用すると、指定したタスクの実行進捗状況をリアルタイムで確認できます。

```shell
${home_path}/bin/obshell task watch -i

# example
/home/admin/oceanbase/bin/obshell task watch -i 11
```

`home_path` はOceanBaseデータベースのインストールディレクトリです。obshellは、デフォルトでOceanBaseデータベースのインストールディレクトリ内の `bin` ディレクトリに配置されています。`-i/--id` は、監視対象の実行中タスクのIDを指定するために使用されます。
