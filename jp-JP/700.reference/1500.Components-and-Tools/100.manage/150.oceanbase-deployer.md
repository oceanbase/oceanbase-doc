# obd

obd（OceanBase Deployer、すなわちOceanBaseのインストールおよびデプロイツール）は、OceanBaseクラスタのインストールおよびデプロイツールであり、コマンドラインによるデプロイまたはGUIによるデプロイの方法を通じて、複雑な設定プロセスを標準化し、クラスタのデプロイ難易度を低減します。詳細な操作については、[コマンドラインを使用したOceanBaseデータベースの本番環境へのデプロイ](../../../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/500.deploy-OceanBase-database-of-multi-node-cluster.md)および[obd GUIを使用したOceanBaseクラスタのデプロイ](../../../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/400.deploy-by-ui/100.deploy-by-obd.md)を参照してください。

その中で、コマンドラインでは設定ファイルの編集が可能であり、より柔軟に設定調整を行うことができます。OceanBaseについて深く理解する必要があるユーザーに適しており、一定の習熟が必要です。一方、GUIでは設定が簡単で、ページのガイドに従って設定するだけでクラスタのデプロイが完了します。迅速に試用し、標準環境を構築するユーザーに適しています。

クラスタのデプロイに加えて、obdはパッケージマネージャー、ストレステストソフトウェア、クラスタ管理など、一般的な運用保守機能も提供しており、ユーザーがOceanBase分散データベースをより快適に利用できるようサポートしています。
