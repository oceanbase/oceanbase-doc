# log_tool

OceanBaseデータベースのclogログは、従来のデータベースのredoログに類似しています。clogログは、トランザクションのコミット時にトランザクションデータを永続化する役割を担います。トランザクションデータとは、データベースに対するトランザクションの変更履歴です。log_toolは、clogファイルを解析して出力するために使用されます。この記事では、log_toolの使用方法について説明します。

log_toolは、旧バージョンのclog_toolであり、OceanBaseデータベースV4.xバージョンで適合更新が行われました。一部のコマンド形式が変更され、一部の機能が削除されています。

## log_toolコマンド

現在、log_toolはob_adminツールに統合されており、`ob_admin`コマンドを実行することでlog_toolを呼び出すことができます。
次の表は、log_toolの一般的なコマンドを示しています。

|      コマンドライン      |                   説明                   |
|---------------|----------------------------------------|
| `dump_log`    | 指定されたclogファイルを解析して出力します。                      |
| `dump_tx_format` | 指定されたclogファイルを解析し、このログファイルをSQL形式に準じて出力します。    |
| `dump_filter` | 指定されたclogファイルを解析し、フィルタ条件を満たすレコードをこのログファイルから出力します。     |
| `stat`   | 指定されたclogファイルを解析し、このログファイルの統計情報を出力します。          |

### dump_log

```Shell
ob_admin log_tool dump_log <clog_file_name>
```

コードの使用方法：

* `dump_log`コマンドを使用して、指定されたclogファイルとアーカイブファイルを解析して出力します。複数のファイルを解析する場合、ファイル名はスペースで区切る必要があります。

* `clog_file_name`は指定するclogファイル名です。`clog_file_name`にはファイルパスを含めることができます。例：

  * 単一のclogファイルを解析して出力します。ここで解析対象のclogファイル名が`101`で、このファイルが現在のディレクトリにある場合、以下のコマンドを実行してこのファイルを解析して出力します。

    ```Shell
    ob_admin log_tool dump_log 101
    ```

  * 複数のclogファイルを解析して出力します。ここで解析対象のclogファイル名が`101`と`103`で、これら2つのファイルがどちらも現在のディレクトリにある場合、以下のコマンドを実行してこれら2つのファイルを解析して出力します。

    ```Shell
    ob_admin log_tool dump_log 101 103
    ```

  * 連続する複数のclogファイルを解析して出力します。ここで解析対象のclogファイル名が`101`、`102`、`103`、`104`で、これらのファイルがすべて現在のディレクトリにある場合、以下のコマンドを実行してこれらのファイルを解析して出力します。

    ```Shell
    ob_admin log_tool dump_log {101..104}
    ```

### dump_filter

```Shell
ob_admin log_tool dump_filter '<filter_name>' <clog_file_name>
```

コードの使用方法：

* `dump_filter` を使用して、フィルター条件に基づいてclogファイル内のトランザクション関連情報を出力します。

* `<clog_file_name>` の使用方法の詳細については、[dump_log](#dump_log)を参照してください。

* 現在、`filter_name` の取り得る値は以下のとおりです：

    |     フィルター条件名     |   説明    |
    |----------------|---------|
    | `tablet_id`    | データテーブル識別子   |
    | `tx_id`        | トランザクション識別子     |

  `filter_name` は単独で使用することも、組み合わせて使用することもできます。複数の条件でフィルタリングする場合、条件名は半角セミコロン (;) で区切ります。例：

  * `tablet_id` が 123、clogファイル名が `101` で現在のディレクトリにある場合、以下のコマンドを実行してこのファイルを解析し、出力します。

    ```Shell
    ob_admin log_tool dump_filter 'tablet_id=123' 101
    ```

  * `tablet_id` が `123`、`tx_id` が `26058724`、解析対象のclogファイルが `101` で現在のディレクトリにある場合、以下のコマンドを実行してこのファイルを解析し、出力します。

    ```Shell
    ob_admin log_tool dump_filter 'tablet_id=123;tx_id=26058724' 101
    ```

### stat

```Shell
ob_admin log_tool stat <clog_file_name>
```

コードの使用方法：

* `stat` コマンドを使用して、指定されたclogファイルの統計情報を取得します。ログファイルサイズ、ログレコード数、トランザクション数などの情報が含まれます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>clog_toolは、環境変数 <code>CLOG_TOOL_BREAK_ON_FAIL</code> によって、解析プロセス中に直接終了するか、エラーを無視して続行するかを制御できます。<code>CLOG_TOOL_BREAK_ON_FAIL</code> の値が true の場合は直接終了し、<code>CLOG_TOOL_BREAK_ON_FAIL</code> の値が false の場合はエラーを無視して解析を続行します。</p>
  </main>

* `<clog_file_name>` の使用方法の詳細については、[dump_log](#dump_log)を参照してください。
