# dump_backup

dump_backup機能はob_adminのサブ機能であり、物理バックアップ用のデータバックアップ内容を解析することができます。本記事では主にdump_backupのいくつかの使用方法について説明します。

## helpコマンド

このコマンドを使用して、dump_backupの使い方を出力できます。

```shell
./ob_admin dump_backup --help
```

出力は次のとおりです：

```shell
Usage: dump_backup command [command args] [options]
commands:
        -h,--help                     display this message.
options:
        -d,--backup-file-path         absolute backup file path with file prefix
        -s,--storage-info             oss/cos should provide storage info
        -f,--file-path                relative data file path
        -o,--offset                   data offset
        -l,--length                   data length
        -c,--check-exist              check file is exist or not
samples:
  dump meta:
        ob_admin dump_backup -dfile:///home/admin/backup_info
  dump macro:
        ob_admin dump_backup -dfile:///home/admin/macro_block_1.0 -o1024 -l2048
  dump data with -f:
        ob_admin dump_backup -f/home/admin/macro_block_1.0 -o1024 -l2048
  dump data with -s:
        ob_admin dump_backup -d'oss://home/admin/backup_info' -s'host=xxx.com&access_id=111&access_key=222'
```

オプションの説明は以下のとおりです：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明  |
|--------|---------|----------|-------|------|
| -d/--backup-file-path | はい  | 文字列  | なし  | データバックアップファイルの絶対パスを指定します。 |
| -s/--storage-info  | いいえ  | 文字列  | なし  | オブジェクトストレージのホストアドレスと検証情報を指定します。検証情報には、アクセスID（access_id）とアクセスキー（access_key）が含まれます。Amazon S3サービスの場合は、リージョン（s3_region）も明示的に指定する必要があります。    |
| -f/--file-path  | いいえ  | 文字列  | なし | データバックアップファイルの相対パスを指定します。<main id="notice" type='notice'><h4>注意</h4><p>このオプションは廃止されています。設定しないでください。</p></main> |
| -o/--offset    | いいえ  | 整数型  | 0  | 読み取りオフセットを設定します。指定されたデータバックアップファイルによって、以下の2つのケースがあります：<ul><li>指定されたデータバックアップがマクロブロックファイルの場合、読み取るマクロブロックのバイトオフセットを表します。</li><li>指定されたデータバックアップがtable_listファイルの場合、読み取るtable_listエントリのオフセットを表します。<code>-o</code>/<code>--offset</code>の設定値がtable_listの総数を超える場合、出力は空になります。</li></ul>    |
| -l/--length  | いいえ  | 整数型  | 0  | 読み取り長さを設定します。指定されたデータバックアップファイルによって、以下の2つのケースがあります：<ul><li>指定されたデータバックアップがマクロブロックファイルの場合、読み取るマクロブロックのバイト数を表します。</li><li>指定されたデータバックアップがtable_listファイルの場合、読み取るtable_listエントリ数を表します。読み取りオフセット（offset）と読み取り長さ（length）の合計がtable_listの総数（以下のサンプル出力の<code>count</code>）を超える場合、出力範囲は[offset,count)となります。</li></ul>  |
| -c/--check-exist  | いいえ | ブール型 | false  | データバックアップファイルが存在するかどうかをチェックするかどうかを制御します。このオプションを指定すると、コマンドは入力されたデータバックアップファイルが存在するかどうかをチェックし、ファイルが存在する場合は`true`を出力し、そうでない場合は`false`を出力します。 |

## よく使われるファイルの説明

| ${backup_data_path}/backup_set_1_full/ | フルバックアップセット |
