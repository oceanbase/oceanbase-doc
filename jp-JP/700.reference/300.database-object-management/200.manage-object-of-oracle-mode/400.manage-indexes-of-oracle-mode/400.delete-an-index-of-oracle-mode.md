# インデックスの削除

インデックスが多すぎると、メンテナンスコストが増加します。不要なインデックスは必要に応じて削除できます。

インデックスを削除する構文は以下のとおりです：

```sql
DROP INDEX index_name;
```

テーブルのインデックスを削除する例は以下のとおりです：

```sql
obclient> DROP INDEX t3_ind2;
Query OK, 0 rows affected (0.02 sec)
```
