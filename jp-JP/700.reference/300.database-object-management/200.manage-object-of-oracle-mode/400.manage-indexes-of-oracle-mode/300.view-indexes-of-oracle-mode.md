# インデックスの確認

システムビューを使用してインデックスを確認できます。インデックスを確認するためのビューには、USER_INDEXES、ALL_INDEXES、DBA_INDEXES、ALL_IND_COLUMNS、DBA_IND_COLUMNS、USER_IND_COLUMNSがあります。

* ユーザーが所有するすべてのテーブルのインデックス情報を確認するために使用されます

## インデックスがGLOBALかLOCALかを確認する

ビュー [sys.DBA_OB_TABLE_LOCATIONS](../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/14300.dba_ob_table_locations-of-oracle-mode.md) を使用して、インデックスがグローバルインデックス（`GLOBAL`）かローカルインデックス（`LOCAL`）かを確認できます。

**例：**

1. テーブル `TBL1` にどのようなビューがあるかを確認します。

    ```sql
    SELECT OWNER, TABLE_NAME, INDEX_NAME
    FROM sys.DBA_INDEXES
    WHERE TABLE_NAME = 'TBL1';
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+------------+------------+
    | OWNER | TABLE_NAME | INDEX_NAME |
    +-------+------------+------------+
    | SYS   | TBL1       | TBL1_IDX1  |
    | SYS   | TBL1       | TBL1_IDX2  |
    +-------+------------+------------+
    2 rows in set
    ```

2. インデックス `TBL1_IDX1` がグローバルインデックス（`GLOBAL`）かローカルインデックス（`LOCAL`）かを確認します。

    ```sql
    SELECT DATABASE_NAME, INDEX_NAME, INDEX_TYPE
    FROM sys.DBA_OB_TABLE_LOCATIONS
    WHERE INDEX_NAME = 'TBL1_IDX1';
    ```

    実行結果は次のとおりです：

    ```shell
    +---------------+------------+------------+
    | DATABASE_NAME | INDEX_NAME | INDEX_TYPE |
    +---------------+------------+------------+
    | SYS           | TBL1_IDX1  | LOCAL      |
    +---------------+------------+------------+
    1 row in set
    ```

3. ビュー `sys.DBA_INDEXES` と `sys.DBA_OB_TABLE_LOCATIONS` からテーブル `TBL1` のインデックス情報を取得します。

    ```sql
    SELECT ds.OWNER, ds.TABLE_NAME, ds.INDEX_NAME, ls.INDEX_TYPE
    FROM sys.DBA_INDEXES ds, sys.DBA_OB_TABLE_LOCATIONS ls
    WHERE ds.OWNER = ls.DATABASE_NAME
      AND ds.INDEX_NAME = ls.INDEX_NAME
      AND ds.TABLE_NAME = 'TBL1';
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+------------+------------+------------+
    | OWNER | TABLE_NAME | INDEX_NAME | INDEX_TYPE |
    +-------+------------+------------+------------+
    | SYS   | TBL1       | TBL1_IDX1  | LOCAL      |
    | SYS   | TBL1       | TBL1_IDX2  | LOCAL      |
    +-------+------------+------------+------------+
    2 rows in set
    ```
