# インデックスの確認

システムビューを使用してインデックスを確認できます。インデックスを確認するビューは以下のとおりです：USER_INDEXES、ALL_INDEXES、DBA_INDEXES、ALL_IND_COLUMNS、DBA_IND_COLUMNS、USER_IND_COLUMNS。

* ユーザーが所有するすべてのテーブルのインデックス情報を確認するために使用します。

  obclient> SELECT * FROM USER_INDEXES WHERE table_name='TEST';

  `TABLE_NAME` は、クエリ対象のテーブル名として `TEST` を指定します。

  `INDEX_TYPE` はインデックスタイプを表し、`NORMAL` は通常インデックスを表します。

  `UNIQUENESS` はインデックスが一意かどうかを表します。このフィールドが `NONUNIQUE` と表示されている場合は、一意ではありません。

* テーブルのすべてのインデックスを確認するために使用します。

  `COMPRESSION` フィールドの情報は、インデックス圧縮機能が有効かどうかを表します。デフォルトは `ENABLED` 状態です。

  `PREFIX_LENGTH` は、インデックス圧縮で圧縮されたフィールド数を表します。

  `INCLUDE_COLUMN` フィールドには、インデックス組織テーブルの主キー（オーバーフローなし）インデックスの最後の列の列IDが含まれます。

  `DISTINCT_KEYS` は異なるインデックス値の数を表します。

  `DROPPED` は、インデックスが削除されたかどうか、およびゴミ箱にあるかどうかを示します。

  `OWNER` このフィールドは、現在のデータベースユーザーが `SYS` であることを表します。

  `INDEX_TYPE` はインデックスタイプを表し、`NORMAL` は通常インデックスを表します。

  `UNIQUENESS` は一意で重複を許さないインデックスを表します。

* ユーザーがアクセス可能なすべてのテーブルのインデックスのインデックス列情報を確認するために使用します。

  ```sql
  bclient> SELECT * FROM ALL_IND_COLUMNS ;
  +-------------+---------------------------------------+-------------+-------------+-------------+-----------------+---------------+-------------+---------+
  | INDEX_OWNER | INDEX_NAME                            | TABLE_OWNER | TABLE_NAME  | COLUMN_NAME | COLUMN_POSITION | COLUMN_LENGTH | CHAR_LENGTH | DESCEND |
  +-------------+---------------------------------------+-------------+-------------+-------------+-----------------+---------------+-------------+---------+
  | SYS         | TABLE_NAME1_OBPK_1639997002986248     | SYS         | TABLE_NAME1 | W_ID        |               1 |            22 |           0 | ASC     |
  +-------------+---------------------------------------+-------------+-------------+-------------+-----------------+---------------+-------------+---------+
  12 rows in set (0.02 sec)
  ```

  * `DESCEND` このフィールドが `ASC` の場合、昇順インデックスを意味します。

  * `COLUMN_NAME` は列名を表します。

* データベース内のすべてのテーブルのインデックスのインデックス列情報を確認するために使用します。

  ```sql
  obclient> SELECT * FROM DBA_IND_COLUMNS ;
  +-------------+---------------------------------------+-------------+-------------+-------------+-----------------+---------------+-------------+---------+
  | INDEX_OWNER | INDEX_NAME                            | TABLE_OWNER | TABLE_NAME  | COLUMN_NAME | COLUMN_POSITION | COLUMN_LENGTH | CHAR_LENGTH | DESCEND |
  +-------------+---------------------------------------+-------------+-------------+-------------+-----------------+---------------+-------------+---------+
  | SYS         | TABLE_NAME1_OBPK_1639997002986248     | SYS         | TABLE_NAME1 | W_ID        |               1 |            22 |           0 | ASC     |
  +-------------+---------------------------------------+-------------+-------------+-------------+-----------------+---------------+-------------+---------+
  12 rows in set (0.02 sec)
  ```

  * `INDEX_OWNER` はインデックス所有者を表します。

  * `INDEX_NAME` はインデックス名です。

* テーブルのインデックスの詳細情報を確認するために使用します。

  ```sql
  obclient> SELECT * FROM USER_IND_COLUMNS WHERE table_name='TEST';
  +-------------+------------+-------------+-----------------+---------------+-------------+---------+
  | INDEX_NAME  | TABLE_NAME | COLUMN_NAME | COLUMN_POSITION | COLUMN_LENGTH | CHAR_LENGTH | DESCEND |
  +-------------+------------+-------------+-----------------+---------------+-------------+---------+
  | T5_NAME_IND | TEST       | NAME        |               1 |             1 |           1 | ASC     |
  +-------------+------------+-------------+-----------------+---------------+-------------+---------+
  1 row in set (0.02 sec)
  ```

  * `COLUMN_POSITION` は列の位置情報を表します。

  * `COLUMN_LENGTH` は列の長さを表します。

  * `CHAR_LENGTH` は文字の長さを表します。
