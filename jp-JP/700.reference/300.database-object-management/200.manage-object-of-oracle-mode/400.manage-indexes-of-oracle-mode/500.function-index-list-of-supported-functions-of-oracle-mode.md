# 関数インデックスでサポートされているシステム関数のリスト

このセクションでは、関数インデックスで使用できる、または条件を満たして使用できるシステム関数を主にリストアップします。

## パラメータタイプに制限のないシステム関数

|---------------|----------------|----------------|---------------|
| TRIM          |    ACOS        |   REMAINDER    |    FLOOR      |
| ATAN          |    SUBSTRB     |   CEIL         |    ATAN2      |
| WIDTH_BUCKET  |    RPAD        |   COS          |    TRANSLATE  |
| NULLIF        |    TAN         |   TO_BINARY_FLOAT | PAD        |
| SIN           |    TO_BINARY_DOUBLE  | POSITION |    IS_JSON    |
| VSIZE         |    LTRIM       |   POWER        |    ORAHASH    |
| RTRIM         |    LENGTHC     |   EMPTY_BLOB   |    LPAD       |
| INSTRC        |    TO_BLOB     |   SQRT         |    ASCIISTR   |
| NLSSORT       |    EXP         |   ORA_TRUNC    |    TREAT      |
| LN            |    TO_NUMBER   |   SINH         |    LOG        |
| HEXTORAW      |    COSH        |   ASIN         |    FROM_TZ    |
| TANH          |    TO_CHAR     |   TO_NCHAR     | - |

## パラメータタイプに制限のあるシステム関数

以下のシステム関数は、パラメータタイプが文字列型でデフォルト形式の場合、関数インデックスや生成列に使用することは禁止されています。また、日時形式がデフォルトではない場合は、形式パラメータにも要件があります。例えば、`TO_DATE(expr, fmt)` の場合、`fmt` には日付が含まれている必要があります。

|-----------------|----------------|-----------------|-----------------|
| NEXT_DAY        |  TO_DATE       |  LAST_DAY       | ADD_MONTHS      |
| TO_TIMESTAMP    |  TIMESTAMP_NVL |  MONTHS_BETWEEN | TO_TIMESTAMP_TZ |
| SYS_EXTRACT_UTC |  - | - | - |

## CAST式

CAST式は特殊であり、その対象型または源型が時刻型の場合、関数インデックスとして使用することは禁止されています。具体的なシナリオは以下の表のとおりです。

| ソース型                                  | ターゲット型                                                  | 説明            |
|----------------------------------------|-----------------------------------------------------------|----------------|
| TIMESTAMP/DATE                         | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | 関数インデックスとしての使用は禁止されています |
| string                                 | 時間型                                                   | 関数インデックスとしての使用は禁止されています |
| 時間型                                | string                                                    | 関数インデックスとしての使用は禁止されています |
