# 関数インデックスがサポートするシステム関数の一覧

この記事では、関数インデックスに使用できる、または条件を満たしているシステム関数を主にリストアップします。

|---------------|----------------|----------------|---------------|
| TRIM          |    ACOS        |   REMAINDER    |    FLOOR      |
| ATAN          |    SUBSTRB     |   CEIL         |    ATAN2      |
| WIDTH_BUCKET  |    RPAD        |   COS          |    TRANSLATE  |
| NULLIF        |    TAN         |   TO_BINARY_FLOAT | PAD        |
| SIN           |    TO_BINARY_DOUBLE  | POSITION |    IS_JSON    |

## パラメータタイプに制限があるシステム関数

以下のシステム関数は、パラメータタイプが文字列（string）であり、形式が省略されている場合、関数インデックスや生成列に使用することが禁止されています。また、日付時刻の形式が省略されていない場合は、形式パラメータにも要件があります。例えば、`TO_DATE(expr, fmt)` の場合、`fmt` に日付が含まれている必要があります。

|-----------------|----------------|-----------------|-----------------|
| ADD_MONTHS         | LAST_DAY           | MONTHS_BETWEEN     | NEXT_DAY          |
| SYS_EXTRACT_UTC    | TIMESTAMP_NVL      | TO_DATE            | TO_TIMESTAMP      |
| TO_TIMESTAMP_TZ    | -                  | -                  | -                 |

## CAST式

CAST式は特殊であり、そのターゲット型またはソース型が日付時刻型の場合、関数インデックスとして使用することは禁止されています。具体的なシナリオは以下の表に示されています。

| ソースタイプ                                  | ターゲットタイプ                                                  | 説明            |
|----------------------------------------|-----------------------------------------------------------|----------------|
| TIMESTAMP/DATE                         | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | 関数インデックスとしての使用を禁止 |
| string                                 | 時間型                                                   | 関数インデックスとしての使用を禁止 |
| 時間型                                | string                                                    | 関数インデックスとしての使用を禁止 |
