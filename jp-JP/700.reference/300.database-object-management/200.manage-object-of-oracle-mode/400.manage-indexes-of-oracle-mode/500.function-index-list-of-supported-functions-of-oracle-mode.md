# 関数ベースのインデックスでサポートされているシステム関数のリスト

このセクションでは、関数ベースのインデックスで使用できるシステム関数を、使用条件とともに示します。

## パラメータタイプに制限のないシステム関数

| | | | |
|---------------|----------------|----------------|---------------|
| TRIM          |    ACOS        |   REMAINDER    |    FLOOR      |
| ATAN          |    SUBSTRB     |   CEIL         |    ATAN2      |
| WIDTH_BUCKET  |    RPAD        |   COS          |    TRANSLATE  |
| NULLIF        |    TAN         |   TO_BINARY_FLOAT | PAD        |
| SIN           |    TO_BINARY_DOUBLE  | POSITION |    IS JSON    |
| VSIZE         |    LTRIM       |   POWER        |    ORA_HASH   |
| RTRIM         |    LENGTHC     |   EMPTY_BLOB   |    LPAD       |
| INSTRC        |    TO_BLOB     |   SQRT         |    ASCIISTR   |
| NLSSORT       |    EXP         |   TRUNC        |    TREAT      |
| LN            |    TO_NUMBER   |   SINH         |    LOG        |
| HEXTORAW      |    COSH        |   ASIN         |    FROM_TZ    |
| TANH          |    TO_CHAR     |   TO_NCHAR     | - |

なお、`IS JSON` は条件式であり、通常の関数ではありません。

## パラメータタイプに制限があるシステム関数

以下のシステム関数は、引数が文字列型で書式を省略した場合、関数ベースのインデックスや生成列に使用することは禁じられています。さらに、日時のフォーマットがデフォルトではない場合は、フォーマットパラメータにも要件があります。例えば、`TO_DATE(expr, fmt)` の場合、`fmt` には日付が含まれている必要があります。

| | | | |
|-----------------|----------------|-----------------|-----------------|
| NEXT_DAY        |  TO_DATE       |  LAST_DAY       | ADD_MONTHS      |
| TO_TIMESTAMP    |  TIMESTAMP_NVL |  MONTHS_BETWEEN | TO_TIMESTAMP_TZ |
| SYS_EXTRACT_UTC |  - | - | - |

## CAST式

CAST式は特殊であり、そのターゲット型またはソース型が日時型の場合、関数ベースのインデックスの式には使用できません。具体的なケースは以下の表のとおりです。

| ソース型                                | ターゲット型                                              | 説明            |
|----------------------------------------|-----------------------------------------------------------|----------------|
| TIMESTAMP/DATE                         | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | インデックスの式には使用不可 |
| string                                 | 日時型                                                   | インデックスの式には使用不可 |
| 日時型                                | string                                                    | インデックスの式には使用不可 |
