# 関数インデックスでサポートされているシステム関数のリスト

このセクションでは、関数インデックスとして使用できる、または条件を満たして使用できるシステム関数を主にリストアップします。

## パラメータタイプに制限のないシステム関数

|---------------|----------------|----------------|---------------|
| TRIM          |    ACOS        |   REMAINDER    |    FLOOR      |
| ATAN          |    SUBSTRB     |   CEIL         |    ATAN2      |
| WIDTH_BUCKET  |    RPAD        |   COS          |    TRANSLATE  |
| NULLIF        |    TAN         |   TO_BINARY_FLOAT | PAD        |
| SIN           |    TO_BINARY_DOUBLE  | POSITION |    IS_JSON    |
| VSIZE         |    LTRIM       |   POWER        |    ORAHASH    |
| RTRIM         |    LENGTHC     |   EMPTY_BLOB   |    LPAD       |
| INSTRC        |    TO_BLOB     |   SQRT         |    ASCIISTR   |
| NLSSORT       |    EXP         |   ORA_TRUNC    |    TREAT      |
| LN            |    TO_NUMBER   |   SINH         |    LOG        |
| HEXTORAW      |    COSH        |   ASIN         |    FROM_TZ    |
| TANH          |    TO_CHAR     |   TO_NCHAR     | - |

## パラメータタイプに制限があるシステム関数

以下のシステム関数は、パラメータタイプが文字列型でフォーマットがデフォルトの場合、関数インデックスや生成列に使用することは禁じられています。さらに、日時のフォーマットがデフォルトではない場合は、フォーマットパラメータにも要件があります。例えば、`TO_DATE(expr, fmt)` の場合、`fmt` には日付が含まれている必要があります。

|-----------------|----------------|-----------------|-----------------|
| NEXT_DAY        |  TO_DATE       |  LAST_DAY       | ADD_MONTHS      |
| TO_TIMESTAMP    |  TIMESTAMP_NVL |  MONTHS_BETWEEN | TO_TIMESTAMP_TZ |
| SYS_EXTRACT_UTC |  - | - | - |

## CAST式

CAST式は特殊であり、その対象型または源型が日時型の場合、関数インデックスとしては使用できません。具体的なケースは以下の表のとおりです。

| 源类型                                  | 目标类型                                                  | 说明            |
|----------------------------------------|-----------------------------------------------------------|----------------|
| TIMESTAMP/DATE                         | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | 関数インデックスとしての使用は禁止 |
| string                                 | 時間型                                                   | 関数インデックスとしての使用は禁止 |
| 時間型                                | string                                                    | 関数インデックスとしての使用は禁止 |
