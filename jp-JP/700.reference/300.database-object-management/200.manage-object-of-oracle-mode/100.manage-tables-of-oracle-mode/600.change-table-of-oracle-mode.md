# テーブルの変更

テーブル作成後は、`ALTER TABLE` ステートメントを使用してテーブルを変更できます。

## 注意点

テーブルの主キーまたは列型を変更する操作を実行している間は、他のDDL操作の実行を禁止します。同様に、他のDDL操作を実行している間は、テーブルの主キーまたは列型を変更する操作の実行を禁止します。

## 列の追加、変更、削除、および廃棄列のクリーンアップ

OceanBaseデータベースは、列の追加、列とその属性の変更、列の削除、および廃棄列のクリーンアップなどをサポートしています。

### 列の追加

OceanBaseデータベースはテーブルに列を追加することをサポートしていますが、主キー列の直接追加はサポートしていません。主キー列を追加する必要がある場合は、まず列を追加し、その後その列に主キーを設定することを推奨します。主キーの追加に関する操作については、[列の制約タイプの定義](../100.manage-tables-of-oracle-mode/400.define-the-constraint-type-for-a-column-of-oracle-mode.md)を参照してください。

列を追加するSQL構文は以下のとおりです：

```sql
ALTER TABLE table_name ADD column_definition;
```

**例：**

1. テストテーブル `test_tbl1` を作成します。

    ```sql
    CREATE TABLE test_tbl1 (
      col1 NUMBER(38),
      col2 VARCHAR2(50),
      PRIMARY KEY(col1));
    ```

2. テーブル `test_tbl1` に列 `col3` を追加します。

    ```sql
    ALTER TABLE test_tbl1 ADD col3 NUMBER(38);
    ```

3. テーブル `test_tbl1` の構造を確認します。

    ```sql
    DESCRIBE test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+--------------+------+------+---------+-------+
    | FIELD | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
    +-------+--------------+------+------+---------+-------+
    | COL1  | NUMBER(38)   | NO   | PRI  | NULL    | NULL  |
    | COL2  | VARCHAR2(50) | YES  | NULL | NULL    | NULL  |
    | COL3  | NUMBER(38)   | YES  | NULL | NULL    | NULL  |
    +-------+--------------+------+------+---------+-------+
    3 rows in set
    ```

### 列の変更

#### 列属性の変更

OceanBaseデータベースは、さまざまな列型間の変換、デフォルト値、およびNOT NULL制約などをサポートしています。OceanBaseデータベースにおける列型の変換ルールおよび詳細については、[列型変更ルール](../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/1000.ddl-function-of-oracle-mode/900.column-type-change-rule-of-oracle-mode.md)を参照してください。

列型を変更するSQL構文は以下のとおりです：

```sql
ALTER TABLE table_name MODIFY [COLUMN] column_definition;
```

**例：**

1. テストテーブル `test_tbl2` を作成します。

    ```sql
    CREATE TABLE test_tbl2 (
      col1 NUMBER(38),
      col2 VARCHAR2(20));
    ```

2. テーブル `test_tbl2` の構造を確認します。

    ```sql
    DESCRIBE test_tbl2;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+--------------+------+------+---------+-------+
    | FIELD | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
    +-------+--------------+------+------+---------+-------+
    | COL1  | NUMBER(38)   | YES  | NULL | NULL    | NULL  |
    | COL2  | VARCHAR2(20) | YES  | NULL | NULL    | NULL  |
    +-------+--------------+------+------+---------+-------+
    2 rows in set
    ```

3. テーブル `test_tbl2` の列 `col2` の型を `CHAR(50)` に変更します。

    ```sql
    ALTER TABLE test_tbl2 MODIFY col2 CHAR(50);
    ```

4. テーブル `test_tbl2` の列 `col1` のデフォルト値を 0 に変更します。

    ```sql
    ALTER TABLE test_tbl2 MODIFY col1 DEFAULT 0;
    ```

5. テーブル `test_tbl2` の列 `col2` にNOT NULL制約を設定します。

    ```sql
    ALTER TABLE test_tbl2 MODIFY col2 NOT NULL;
    ```

6. テーブル `test_tbl2` の構造を確認します。

    ```sql
    DESCRIBE test_tbl2;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+------------+------+------+---------+-------+
    | FIELD | TYPE       | NULL | KEY  | DEFAULT | EXTRA |
    +-------+------------+------+------+---------+-------+
    | COL1  | NUMBER(38) | YES  | NULL | 0       | NULL  |
    | COL2  | CHAR(50)   | NO   | NULL | NULL    | NULL  |
    +-------+------------+------+------+---------+-------+
    2 rows in set
    ```

#### 列名の変更

列名を変更するSQL構文は次のとおりです：

```sql
ALTER TABLE table_name RENAME COLUMN old_col_name TO new_col_name;
```

**例：**

1. テストテーブル `test_tbl3` を作成します。

    ```sql
    CREATE TABLE test_tbl3 (
      col1 NUMBER(38),
      col2 VARCHAR2(20),
      PRIMARY KEY(col1));
    ```

2. テーブル `test_tbl3` の列 `col1` の名前を `col1_new` に変更します。

    ```sql
    ALTER TABLE test_tbl3 RENAME COLUMN col1 TO col1_new;
    ```

3. テーブル `test_tbl3` の構造を確認します。

    ```sql
    DESCRIBE test_tbl3;
    ```

    実行結果は次のとおりです：

    ```shell
    +----------+--------------+------+------+---------+-------+
    | FIELD    | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
    +----------+--------------+------+------+---------+-------+
    | COL1_NEW | NUMBER(38)   | NO   | PRI  | NULL    | NULL  |
    | COL2     | VARCHAR2(20) | YES  | NULL | NULL    | NULL  |
    +----------+--------------+------+------+---------+-------+
    2 rows in set
    ```

### 列の削除

列を削除することができます。テーブル内の列は削除できますが、主キー列の削除は許可されません。

#### 単一列の削除

単一列を削除するSQL構文は次のとおりです：

```sql
ALTER TABLE table_name DROP COLUMN column_name;
```

**例：**

1. テストテーブル `test_tbl4` を作成します。

    ```sql
    CREATE TABLE test_tbl4 (
      col1 NUMBER(38),
      col2 VARCHAR2(50),
      PRIMARY KEY(col1));
    ```

2. テーブル `test_tbl4` の列 `col2` を削除します。

    ```sql
    ALTER TABLE test_tbl4 DROP COLUMN col2;
    ```

3. テーブル `test_tbl4` の構造を確認します。

    ```sql
    DESCRIBE test_tbl4;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+------------+------+------+---------+-------+
    | FIELD | TYPE       | NULL | KEY  | DEFAULT | EXTRA |
    +-------+------------+------+------+---------+-------+
    | COL1  | NUMBER(38) | NO   | PRI  | NULL    | NULL  |
    +-------+------------+------+------+---------+-------+
    1 row in set
    ```

#### 複数列の削除

複数列を削除するSQL構文は次のとおりです：

```sql
ALTER TABLE table_name DROP (column_name1, column_name1, ...);
```

または

```sql
ALTER TABLE table_name DROP COLUMN column_name1, DROP COLUMN column_name2, ...;
```

**例：**

1. テストテーブル `test_tbl5` を作成します。

    ```sql
    CREATE TABLE test_tbl5 (
      col1 NUMBER(38),
      col2 VARCHAR2(50),
      col3 NUMBER(38),
      col4 NUMBER(38),
      col5 NUMBER(38),
      col6 NUMBER(38),
      col7 NUMBER(38),
      PRIMARY KEY(col1));
    ```

2. テーブル `test_tbl5` の列 `col6` と `col7` を削除します。

    ```sql
    ALTER TABLE test_tbl5 DROP (col6, col7);
    ```

3. テーブル `test_tbl5` の列 `col4` と `col5` を削除します。

    ```sql
    ALTER TABLE test_tbl5 DROP COLUMN col4, DROP COLUMN col5;
    ```

4. テーブル `test_tbl5` の構造を確認します。

    ```sql
    DESCRIBE test_tbl5;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+--------------+------+------+---------+-------+
    | FIELD | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
    +-------+--------------+------+------+---------+-------+
    | COL1  | NUMBER(38)   | NO   | PRI  | NULL    | NULL  |
    | COL2  | VARCHAR2(50) | YES  | NULL | NULL    | NULL  |
    | COL3  | NUMBER(38)   | YES  | NULL | NULL    | NULL  |
    +-------+--------------+------+------+---------+-------+
    3 rows in set
    ```

### 廃棄列のクリーンアップ

一部の列が削除された場合、それらの列が使用されなくなっても物理ストレージ容量を占有し続けます。これらの廃棄列を削除して関連する領域を回収するには、廃棄列をクリーンアップする必要があります。

廃棄列をクリーンアップするSQL構文は以下のとおりです：

```sql
ALTER TABLE table_name FORCE;
```

**例：**

```sql
ALTER TABLE test_tbl5 FORCE;
```

## 一意性制約の追加

OceanBaseデータベースでは、既存のテーブルに一意性制約を追加できます。

一意性制約を追加するSQL構文は以下のとおりです：

```sql
ALTER TABLE table_name ADD [CONSTRAINT [constraint_name]] UNIQUE (column_name [, column_name ]...);
```

**例：**

1. テストテーブル `test_tbl6` を作成します。

    ```sql
    CREATE TABLE test_tbl6 (
      col1 NUMBER(38),
      col2 VARCHAR2(50),
      PRIMARY KEY(col1));
    ```

2. テーブル `test_tbl6` の列 `col2` に一意性制約を追加します。

    ```sql
    ALTER TABLE test_tbl6 ADD UNIQUE(col2);
    ```

3. テーブル `test_tbl6` の構造を確認します。

    ```sql
    DESCRIBE test_tbl6;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------+--------------+------+------+---------+-------+
    | FIELD | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
    +-------+--------------+------+------+---------+-------+
    | COL1  | NUMBER(38)   | NO   | PRI  | NULL    | NULL  |
    | COL2  | VARCHAR2(50) | YES  | UNI  | NULL    | NULL  |
    +-------+--------------+------+------+---------+-------+
    2 rows in set
    ```

## テーブルの名前を変更する

テーブル作成後、テーブル名を変更できます。

テーブル名を変更するSQL構文は以下のとおりです：

```sql
ALTER TABLE old_table_name RENAME TO new_table_name;
```

または

```sql
RENAME old_table_name TO new_table_name;
```

**例：**

```sql
ALTER TABLE test RENAME TO t1;
```

または

```sql
RENAME test TO t1;
```

## テーブルの主キーと外部キーを変更する

テーブル作成後、OceanBaseデータベースではテーブルの主キーと外部キーの追加や削除がサポートされています。テーブルの主キーと外部キーを変更する具体的な操作と説明については、[列の制約タイプの定義](../100.manage-tables-of-oracle-mode/400.define-the-constraint-type-for-a-column-of-oracle-mode.md)を参照してください。

## 列のスキップインデックス属性を変更する

OceanBaseデータベースでは、`ALTER TABLE` ステートメントを使用してスキップインデックス属性の追加、変更、削除をサポートしています。

スキップインデックスの詳細については、[列のスキップインデックス属性](250.identify-skip-index-properties-of-oracle-mode.md)を参照してください。

**例：**

1.  以下のSQLステートメントを使用して、テーブル `test_skidx` を作成します。

    ```sql
    CREATE TABLE test_skidx(
      col1 NUMBER SKIP_INDEX(MIN_MAX, SUM),
      col2 FLOAT SKIP_INDEX(MIN_MAX),
      col3 VARCHAR2(1024) SKIP_INDEX(MIN_MAX),
      col4 CHAR(10)
      );
    ```

2.  テーブル `test_skidx` の列 `col2` のスキップインデックス属性を `SUM` スキップインデックスタイプに変更します。

    ```sql
    ALTER TABLE test_skidx MODIFY col2 FLOAT SKIP_INDEX(SUM);
    ```

3.  テーブル作成後に列のスキップインデックス属性を追加します。テーブル `test_skidx` の列 `col4` に `MIN_MAX` スキップインデックスタイプを追加します。

    ```sql
    ALTER TABLE test_skidx MODIFY col4 CHAR(10) SKIP_INDEX(MIN_MAX);
    ```

4.  テーブル作成後に列のスキップインデックス属性を削除します。テーブル `test_skidx` の列 `col1` のスキップインデックス属性を削除します。

    ```sql
    ALTER TABLE test_skidx MODIFY col1 NUMBER SKIP_INDEX();
    ```

## テーブルの行ストアとカラムストアの変換

OceanBaseデータベースでは、デフォルトでテーブルを作成すると行ストアテーブルが構築されます。`WITH COLUMN GROUP`オプションを設定することで、明示的にカラムストアまたは行ストアとカラムストアを併用する形式を指定できます。

テーブル作成後、`ALTER TABLE`ステートメントを使用してテーブルの行ストアとカラムストアを変換できます。構文は以下のとおりです：

* テーブルをカラムストアテーブルに変更する：

  ```sql
  ALTER TABLE table_name ADD COLUMN GROUP([all columns,] each column) [DELAYED];
  ```

* テーブルのストレージ形式を削除する：

  ```sql
  ALTER TABLE table_name DROP COLUMN GROUP([all columns,] each column);
  ```

**パラメータの説明：**

* `table_name`：テーブル名を指定します。
* `ADD COLUMN GROUP(all columns, each column)`：テーブルを行ストアとカラムストアを併用する形式に変更します。
* `ADD COLUMN GROUP(each column)`：テーブルをカラムストア形式に変更します。
* `DELAYED`：オプションです。行ストアテーブルをカラムストアテーブルに変換するコマンドの実行を遅延（非同期）させます。コマンド実行後、テーブル定義のストレージ形式は変更されますが、実際の行ストアからカラムストアへの変換はメジャーコンパクションタスクの実行時に行われます。この操作は現在のDMLをブロックせず、Online DDLです。`DELAYED`を指定しない場合、デフォルトはOffline DDLとなり、行ストアテーブルからカラムストアテーブルへの変換は同期的に実行されます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul><li>現在、行ストアテーブルをカラムストアテーブル(<code>each column</code>)や行ストアとカラムストアを併用する形式(<code>all columns, each column</code>)に変更する場合にのみ <code>DELAYED</code>を指定できます。</li><li><code>DELAYED</code>を使用して行ストアテーブルをカラムストアテーブルに変換するコマンドを遅延実行した後、ベースラインデータのメジャーコンパクションが完了するまで、データストレージ形式が実際に変換されていないため、クエリのパフォーマンスが期待通りにならない可能性があります。</li></ul>
  </main>

* `DROP COLUMN GROUP(all columns, each column)`：テーブルの行ストアとカラムストアを併用する形式を削除します。
* `DROP COLUMN GROUP(all columns)`：テーブルの行ストア形式を削除します。
* `DROP COLUMN GROUP(each column)`：テーブルのカラムストア形式を削除します。

### 行ストアテーブルからカラムストアテーブルへの変換

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>WITH COLUMN GROUP(all columns)</code>オプションを使用して作成した行ストアテーブルをカラムストアテーブルに変換する場合、<code>ADD COLUMN GROUP(each column)</code>を設定した後、行ストアの列グループを削除するために <code>DROP COLUMN GROUP(all columns)</code> コマンドも実行する必要があります。</p>
</main>

**例：**

* デフォルトで行ストアテーブルを作成します。

  1. 行ストアテーブル `tbl1` を作成します。

      ```sql
      CREATE TABLE tbl1(col1 NUMBER, col2 VARCHAR2(30));
      ```

  2. 行ストアテーブル `tbl1` をカラムストアテーブルに変更します。

      * Offline DDLで変更する場合は以下のとおりです：

        ```sql
        ALTER TABLE tbl1 ADD COLUMN GROUP(each column);
        ```

      * Online DDL（行ストアテーブルを非同期でカラムストアテーブルに変換する）で変更する場合は以下のとおりです：

        ```sql
        ALTER TABLE tbl1 ADD COLUMN GROUP(each column) DELAYED;
        ```

* `WITH COLUMN GROUP(all columns)` オプションを設定して作成した行ストアテーブル。

  1. 行ストアテーブル `tbl1` を作成します。

      ```sql
      CREATE TABLE tbl1_ac(col1 NUMBER, col2 VARCHAR2(30)) WITH COLUMN GROUP(all columns);
      ```

  2. 行ストアテーブル `tbl1` をカラムストアテーブルに変換します。

      * Offline DDLで変更する場合は以下のとおりです：

        ```sql
        ALTER TABLE tbl1_ac ADD COLUMN GROUP(each column);
        ```

      * Online DDL（行ストアテーブルを非同期でカラムストアテーブルに変換する）で変更する場合は以下のとおりです：

        ```sql
        ALTER TABLE tbl1_ac ADD COLUMN GROUP(each column) DELAYED;
        ```

  3. `DROP COLUMN GROUP(all columns)` を設定して行ストア形式を削除します。

      ```sql
      ALTER TABLE tbl1_ac DROP COLUMN GROUP(all columns);
      ```

### 行ストアテーブルから行ストアとカラムストアを併用するテーブルへの変換

**例：**

1. 行ストアテーブル `tbl2` を作成します。

    ```sql
    CREATE TABLE tbl2(col1 NUMBER, col2 VARCHAR2(30));
    ```

2. 行ストアテーブル `tbl2` を行ストアとカラムストアを併用するテーブルに変換します。

    * Offline DDLで変更する場合は以下のとおりです：

      ```sql
      ALTER TABLE tbl2 ADD COLUMN GROUP(all columns, each column);
      ```

    * Online DDL（行ストアテーブルを非同期で行ストアとカラムストアを併用するテーブルに変換する）で変更する場合は以下のとおりです：

      ```sql
      ALTER TABLE tbl2 ADD COLUMN GROUP(all columns, each column) DELAYED;
      ```

### 行ストアとカラムストアを併用するテーブルからカラムストアテーブルへの変換

**例：**

1. 行ストアとカラムストアを併用するテーブル `tbl3` を作成します。

    ```sql
    CREATE TABLE tbl3(col1 NUMBER, col2 VARCHAR2(30)) WITH COLUMN GROUP(all columns, each column);
    ```

2. 行ストアとカラムストアを併用するテーブル `tbl3` をカラムストアテーブルに変換します。

    ```sql
    ALTER TABLE tbl3 DROP COLUMN GROUP(all columns);
    ```

### 行ストアとカラムストアを併用するテーブルを行ストアテーブルに変換する

**例：**

1. 行ストアとカラムストアを併用するテーブル `tbl4` を作成します。

    ```sql
    CREATE TABLE tbl4(col1 NUMBER, col2 VARCHAR2(30)) WITH COLUMN GROUP(all columns, each column);
    ```

2. 行ストアとカラムストアを併用するテーブル `tbl4` を行ストアテーブルに変換します。

    ```sql
    ALTER TABLE tbl4 DROP COLUMN GROUP(each column);
    ```

    または

    ```sql
    ALTER TABLE tbl4 DROP COLUMN GROUP(all columns, each column);
    ```
