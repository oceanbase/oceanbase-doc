# テーブルの定義を確認する

テーブルの作成が完了した後、SQLステートメントを使用してテーブルの定義を確認できます。

以下のステートメントを使用して、テーブルの定義を確認します：

```sql
obclient> SELECT dbms_metadata.get_ddl( 'TABLE', 'TEST', 'SYS' ) FROM DUAL;
+-------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Table | Create Table                                                                                                                                                                                                                                                                                                                                                                       |
+-------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| TEST    | CREATE TABLE `test` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `name` varchar(50) DEFAULT NULL,
  `gmt_create` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) AUTO_INCREMENT = 1 DEFAULT CHARSET = utf8mb4 ROW_FORMAT = DYNAMIC COMPRESSION = 'zstd_1.3.8' REPLICA_NUM = 1 BLOCK_SIZE = 16384 USE_BLOOM_FILTER = FALSE TABLET_SIZE = 134217728 PCTFREE = 0 |
+-------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set (0.01 sec)
```

特定のテーブルまたはテーブルスペースのDDLを確認したい場合は、`dbms_metadata.get_ddl`パッケージを使用して確認できます。`TABLE`フィールドはDDLステートメントのオブジェクトタイプがテーブルを表し、`TEST`フィールドはテーブル名を表し、`SYS`は`SYS`ユーザーの下にあるテーブルを確認することを表します。
