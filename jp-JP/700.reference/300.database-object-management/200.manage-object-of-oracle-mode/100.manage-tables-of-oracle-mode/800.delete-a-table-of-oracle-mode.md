# テーブルの削除

テーブルが不要になった場合、`DROP TABLE` ステートメントを使用して削除できます。

テーブルの削除例は以下のとおりです：

```sql
obclient> DROP TABLE test;
```

`DROP TABLE` 操作について：

* テナントでゴミ箱機能が無効な場合、`DROP TABLE` 操作はテーブルの削除を意味します。ゴミ箱のスイッチはシステム変数 `recyclebin` によって制御され、デフォルトでは無効です。

* テナントでゴミ箱機能が有効な場合、`DROP TABLE` 操作は削除されたテーブルがゴミ箱に移動することを意味します。ゴミ箱内のテーブルについては、後からゴミ箱機能を通じて削除または復元できます。ゴミ箱に関する操作については、[ゴミ箱オブジェクトの復元](../../../../600.manage/400.high-availability/500.recyclebin-management/400.restore-the-recyclebin-objects.md)を参照してください。
