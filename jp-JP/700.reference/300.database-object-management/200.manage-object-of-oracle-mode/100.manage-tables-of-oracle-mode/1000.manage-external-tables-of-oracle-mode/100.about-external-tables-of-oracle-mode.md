# 外部テーブルと外部ファイルについて

外部テーブル（External Table）のデータは、OceanBaseクラスタ外部のストレージシステム（ローカルディレクトリ、オブジェクトストレージ、HDFSなど）に格納され、データベース内にはメタデータとアクセスパスのみが保存されます。作成後は通常のテーブルと同様に`SELECT`、JOIN、集計などに使用できますが、**読み取り専用**であり、DML、制約、インデックスはサポートされません。

通常のテーブルとの違い：

| 比較項目 | 外部テーブル | 通常のテーブル |
| ---- | ---- | ------ |
| データの場所 | 外部ストレージ | OceanBase内部 |
| 読み書き | 外部テーブルは**読み取り専用**：`SELECT`は可能ですが、`INSERT`、`UPDATE`、`DELETE` などのDMLは実行できません。 | 読み書き |
| 制約とインデックス | サポートされていません | サポートされています |
| 典型的なパフォーマンス | ネットワークと外部システムの影響を受ける | ローカルアクセスの方が高速 |

## 注意点

* 作成時には `LOCATION`、`PATTERN` に基づいてファイルリストを収集します。新しいファイルを追加するには、リフレッシュが必要です。詳細については、[外部ファイルの管理](300.manage-external-files-of-oracle-mode.md)および[ALTER EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/100.alter-external-table-of-oracle-mode.md)を参照してください。
* 外部テーブルのパーティションで `PARTITION_TYPE = USER_SPECIFIED` の場合、[ALTER EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/100.alter-external-table-of-oracle-mode.md) を使用してパーティションの `LOCATION` を追加または削除できます（MySQLモードのALTER機能については、対応するドキュメントをご確認ください）。
* 削除された外部ファイルはクエリ時にエラーが報告されません。外部ファイルを同時に変更すると予期しない結果が発生する可能性があります。

## 外部データへのアクセス方法

| 方法 | テーブルオブジェクトの作成 | 典型的なシナリオ | 構文とドキュメントの入口 |
| ---- | -------------- | -------- | -------------- |
| **外部テーブル(CREATE EXTERNAL TABLE)** | はい | 繰り返しクエリが必要な場合、内部テーブルとJOINする必要がある場合、ファイルリストとパーティションを管理する必要がある場合 | [CREATE EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1600.create-external-table-of-oracle-mode.md)、[外部テーブルの作成とクエリ](200.create-a-external-table-of-oracle-mode.md) |
| **FILESテーブル関数** | いいえ | 一時的な探索、一度の読み取り | [FILESテーブル関数](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/500.functions-of-oracle-mode/550.table-functions-of-oracle-mode/200.files-table-function-of-oracle-mode.md)、[URL外部テーブル(メタデータなし)](../../../../../620.obap/400.data-lake/300.url-external-table.md) |

## HDFS外部テーブル

HDFSにアクセスするには、[OceanBaseデータベースJAVA SDK環境のデプロイ](../../../../../400.deploy/300.deploy-oceanbase-enterprise-edition/500.deploy-the-ob-java-sdk-environment.md)が必要であり、[ob_enable_java_env](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/16630.ob_enable_java_env.md)などの設定も必要です。詳細については、[CREATE EXTERNAL TABLE](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1600.create-external-table-of-oracle-mode.md)を参照してください。障害のトラブルシューティングについては、[外部テーブルのよくある質問とトラブルシューティングガイド](../../../../../600.manage/1000.troubleshooting/1700.external-table-troubleshooting.md)を参照してください。
