# パーティションの追加

パーティションテーブルを作成した後、そのパーティションテーブルにパーティションを追加できます。

## パーティションテーブルにおけるパーティション追加操作のサポート状況

OceanBaseデータベースのOracleモードでは：

* 1階層のパーティションテーブルについては、現在RangeパーティションとListパーティションにのみパーティションの追加操作をサポートしており、Hashパーティションへの追加操作は現在サポートされていません。

* コンポジット・パーティションテーブルについては、現在Range/Listタイプ（組み合わせ）のパーティションにのみパーティションの追加操作をサポートしています。

OceanBaseデータベースのOracleモードにおける、1階層のパーティションテーブルとコンポジット・パーティションテーブルのパーティション追加操作に対する具体的なサポート状況は、次の表のとおりです。

|  パーティションテーブル   |      パーティションタイプ                 | 第1レベルのパーティションの追加 | サブパーティションの追加 |
|-----------|------------------------------|-------------|-------------|
|  1階層のパーティションテーブル | Range / List                 | サポート   | -      |
|  1階層のパーティションテーブル | Hash                         | サポートされていません | -      |
|  コンポジット・パーティションテーブル | Range + Range / Range + List | サポート   | サポート    |
|  コンポジット・パーティションテーブル | Range + Hash                 | サポート   | サポートされていません  |
|  コンポジット・パーティションテーブル | List + Range / List + List   | サポート   | サポート    |
|  コンポジット・パーティションテーブル | List + Hash                  | サポート   | サポートされていません  |
|  コンポジット・パーティションテーブル | Hash + Range / Hash + List   | サポートされていません | サポート    |
|  コンポジット・パーティションテーブル | Hash + Hash                  | サポートされていません | サポートされていません  |

## 第1レベルのパーティションの追加

1階層のパーティションテーブル、テンプレート型コンポジット・パーティションテーブル、非テンプレート型コンポジット・パーティションテーブルに第1レベルのパーティションを追加できます。

### 1階層のパーティションテーブルとテンプレート型コンポジット・パーティションテーブルへの第1レベルのパーティションの追加

1階層のパーティションテーブルとテンプレート型コンポジット・パーティションテーブルに第1レベルのパーティションを追加するSQL構文は以下のとおりです：

```sql
ALTER TABLE table_name ADD PARTITION partition_option;

partition_option:
  range_partition_option | list_partition_option

range_partition_option:
  partition_name VALUES LESS THAN partition_expr

list_partition_option:
  partition_name VALUES partition_expr
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <div>
    <ul>
        <li>Rangeパーティションの場合、最大のパーティションの後にのみパーティションを追加でき、途中や開始位置には追加できません。現在のパーティションに<code>MAXVALUE</code>のパーティションがある場合は、パーティションの追加を続けることはできません。</li>
        <li>Listパーティションに第1レベルのパーティションを追加する場合、追加するパーティションが既存のパーティションと重複しない必要があります。Listパーティションにデフォルトパーティション、すなわち<code>Default Partition</code>がある場合は、いかなるパーティションも追加できません。</li>
        <li>Range/Listパーティションに第1レベルのパーティションを追加しても、グローバルインデックスとローカルインデックスの使用には影響しません。</li>
        <li>テンプレート型のコンポジット・パーティションテーブルに第1レベルのパーティションを追加する場合、第1レベルのパーティションの定義のみを指定すれば、サブパーティションの定義はテンプレートに従って自動的に埋め込まれます。
            <ul>
                <li>V4.4.2バージョンでは、V4.4.2 BP2バージョンから、テンプレート型のコンポジット・パーティションテーブルに第1レベルのパーティションを追加する際に、追加する第1レベルのパーティションに対応するサブパーティションの定義を指定できるようになりました。これにより、テンプレート型とカスタム型のサブパーティションを組み合わせて使用できるようになりました。</li>
            </ul>
        </li>
    </ul>
  </div>
</main>

一部の例：

* Rangeパーティションの1階層のパーティションテーブル `tbl1_r` を作成し、パーティション `M202006` を追加します。

  ```sql
  obclient> CREATE TABLE tbl1_r(log_id INT,log_date DATE NOT NULL DEFAULT SYSDATE)
  PARTITION BY RANGE(log_date)
  (PARTITION M202001 VALUES LESS THAN(TO_DATE('2020/02/01','YYYY/MM/DD'))
  , PARTITION M202002 VALUES LESS THAN(TO_DATE('2020/03/01','YYYY/MM/DD'))
  , PARTITION M202003 VALUES LESS THAN(TO_DATE('2020/04/01','YYYY/MM/DD'))
  , PARTITION M202004 VALUES LESS THAN(TO_DATE('2020/05/01','YYYY/MM/DD'))
  , PARTITION M202005 VALUES LESS THAN(TO_DATE('2020/06/01','YYYY/MM/DD'))
  );
  Query OK, 0 rows affected

  obclient> ALTER TABLE tbl1_r ADD PARTITION
         M202006 VALUES LESS THAN(TO_DATE('2020/07/01','YYYY/MM/DD'));
  Query OK, 0 rows affected
  ```

* Listパーティションの1階層のパーティションテーブル `tbl1_l` を作成し、パーティション `p4` を追加します。

  ```sql
  obclient> CREATE TABLE tbl1_l(log_id INT,log_value VARCHAR2(20))
         PARTITION BY LIST(log_value)
          (PARTITION p1 VALUES ('A'),
           PARTITION p2 VALUES ( 'B' ),
           PARTITION p3 VALUES ( 'C' )
          );
  Query OK, 0 rows affected

  obclient> ALTER TABLE tbl1_l ADD PARTITION p4 VALUES('D');
  Query OK, 0 rows affected
  ```

* Range + Rangeパーティションのテンプレート型コンポジット・パーティションテーブル `t2_m_rr` を作成し、さらに第1レベルのパーティション `p2` を追加します。

  ```sql
  obclient> CREATE TABLE t2_m_rr(col1 INT,col2 INT)
         PARTITION BY RANGE(col1)
         SUBPARTITION BY RANGE(col2)
         SUBPARTITION TEMPLATE
           (SUBPARTITION mp0 VALUES LESS THAN(2020),
            SUBPARTITION mp1 VALUES LESS THAN(2021),
            SUBPARTITION mp2 VALUES LESS THAN(2022)
            )
           (PARTITION p0 VALUES LESS THAN(100),
            PARTITION p1 VALUES LESS THAN(200)
            );
  Query OK, 0 rows affected

  obclient> ALTER TABLE t2_m_rr ADD PARTITION p2 VALUES LESS THAN(300);
  Query OK, 0 rows affected
  ```

* Range + Rangeパーティションのテンプレート型パーティションテーブルを作成し、その後第1レベルのパーティションを追加する際にカスタムサブパーティションを追加します。

  1. テンプレート型テーブル `st_rr` を作成します。

      ```shell
      obclient> CREATE TABLE st_rr (col1 INT, col2 INT)
          PARTITION BY RANGE(col1)
          SUBPARTITION BY RANGE(col2)
          SUBPARTITION TEMPLATE
              (SUBPARTITION mp1 VALUES LESS THAN(100),
              SUBPARTITION mp2 VALUES LESS THAN(200),
              SUBPARTITION mp3 VALUES LESS THAN(300)
              )
              (PARTITION p0 VALUES LESS THAN(2020),
              PARTITION p1 VALUES LESS THAN(2021),
              PARTITION p2 VALUES LESS THAN(2022)
              );
      ```

  2. テーブル `st_rr` に第1レベルのパーティションを追加し、サブパーティションを指定します。

      ```shell
      obclient> ALTER TABLE st_rr
          ADD PARTITION p3 VALUES LESS THAN(2026)
              (SUBPARTITION p3sp0 VALUES LESS THAN(300),
              SUBPARTITION p3sp1 VALUES LESS THAN(600));
      ```

  3. テーブル `st_rr` の定義を確認します。

      ```shell
      obclient> SHOW CREATE TABLE st_rr;
      ```

      実行結果は次のとおりです：


### 非テンプレート型コンポジット・パーティションテーブルに第1レベルのパーティションを追加する

非テンプレート型コンポジット・パーティションテーブルに第1レベルのパーティションを追加するSQL構文は次のとおりです：

```sql
ALTER TABLE table_name ADD PARTITION partition_option (subpartition_option);

partition_option:
  range_partition_option | list_partition_option

range_partition_option:
  partition_name VALUES LESS THAN partition_expr

list_partition_option:
  partition_name VALUES partition_expr

subpartition_option:
  {SUBPARTITION subpartition_name VALUES LESS THAN range_partition_expr, ...}
 |{SUBPARTITION subpartition_name VALUES list_partition_expr, ....}
 |{SUBPARTITION subpartition_name, ....}
```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>非テンプレート型のコンポジット・パーティションテーブルに第1レベルのパーティションを追加する場合は、第1レベルのパーティションの定義とそのパーティション内のサブパーティションの定義を同時に指定する必要があります。</p>
  </main>

Range + Rangeパーティションの非テンプレート型コンポジット・パーティションテーブル`t2_f_rr`を作成し、さらに第1レベルのパーティション`p2`を追加する例を以下に示します：

```sql
obclient> CREATE TABLE t2_f_rr(col1 INT,col2 INT)
       PARTITION BY RANGE(col1)
       SUBPARTITION BY RANGE(col2)
        (PARTITION p0 VALUES LESS THAN(100)
          (SUBPARTITION sp0 VALUES LESS THAN(2020),
           SUBPARTITION sp1 VALUES LESS THAN(2021)
          ),
         PARTITION p1 VALUES LESS THAN(200)
          (SUBPARTITION sp2 VALUES LESS THAN(2020),
           SUBPARTITION sp3 VALUES LESS THAN(2021),
           SUBPARTITION sp4 VALUES LESS THAN(2022)
           )
         );
Query OK, 0 rows affected

obclient> ALTER TABLE t2_f_rr ADD PARTITION p2 VALUES LESS THAN(300)
       (SUBPARTITION sp5 VALUES LESS THAN(2020),
        SUBPARTITION sp6 VALUES LESS THAN(2021),
        SUBPARTITION sp7 VALUES LESS THAN(2022)
        );
Query OK, 0 rows affected
```

## サブパーティションの追加

OceanBaseデータベースのOracleモードは、現在非テンプレート型のコンポジット・パーティションテーブルにのみサブパーティションの追加をサポートしています。

### 構文

```sql
ALTER TABLE table_name MODIFY PARTITION partition_name ADD subpartition_list;

subpartition_list:
    {SUBPARTITION subpartition_name VALUES LESS THAN range_partition_expr, ...}
    | {SUBPARTITION subpartition_name VALUES list_partition_expr, ...}
```

### パラメータの説明

|        パラメータ         |          説明          |
|-------------------|----------------------|
| table_name        | テーブル名を指定します。                |
| partition_name    | 追加するサブパーティションが属する第1レベルのパーティション名を指定します。 |
| subpartition_name | 追加するサブパーティション名を指定します。       |

### 例

Range + Rangeパーティションの非テンプレート型コンポジット・パーティションテーブル`t2_f_rr`を作成し、第1レベルのパーティション`p1`にサブパーティション`sp5`と`sp6`を追加します。

```sql
obclient> CREATE TABLE t2_f_rr(col1 INT,col2 INT)
       PARTITION BY RANGE(col1)
       SUBPARTITION BY RANGE(col2)
        (PARTITION p0 VALUES LESS THAN(100)
          (SUBPARTITION sp0 VALUES LESS THAN(2020),
           SUBPARTITION sp1 VALUES LESS THAN(2021)
          ),
         PARTITION p1 VALUES LESS THAN(200)
          (SUBPARTITION sp2 VALUES LESS THAN(2020),
           SUBPARTITION sp3 VALUES LESS THAN(2021),
           SUBPARTITION sp4 VALUES LESS THAN(2022)
           )
         );
Query OK, 0 rows affected

obclient> ALTER TABLE t2_f_rr MODIFY PARTITION p1 ADD
       SUBPARTITION sp5 VALUES LESS THAN(2023),
       SUBPARTITION sp6 VALUES LESS THAN(2024);
Query OK, 0 rows affected
```
