# Catalogの削除

Catalogが不要になった場合、`DROP CATALOG external_catalog_name;` ステートメントを使用して削除できます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>MySQLモードとは異なり、Oracleモードでは <code>DROP CATALOG</code> ステートメントは <code>IF EXISTS</code> 句をサポートしていません。削除対象のCatalogが存在しない場合、エラーが発生し、エラーコードは <code>-11080</code> です。</p>
</main>

Catalogを削除すると、他のユーザーがそのCatalogに対して持っていた `USE CATALOG` オブジェクト権限も同時に取り消されます。

## 権限要件

External Catalogを削除するには、現在のユーザーが `CREATE CATALOG` システム権限を持っている必要があります。

OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 例

```sql
obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

obclient> DROP CATALOG tmp_catalog;
```
