# カタログの表示

カタログを作成した後、SQLステートメントを使用してその情報を確認できます。

## カタログ作成ステートメントの表示

`SHOW CREATE CATALOG external_catalog_name;` を使用して、カタログの作成ステートメントを確認できます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>セキュリティ上の理由から、作成ステートメント内の機密属性（例：ODPSの<code>ACCESSID</code>、<code>ACCESSKEY</code>、<code>STSTOKEN</code>、JDBCの<code>URL</code>など）はマスキングされて表示されます。</p>
</main>

**例：**

```sql
obclient> SHOW CREATE CATALOG test_jdbc_catalog;
```

## 現在のユーザーが参照可能なカタログの表示

`SHOW CATALOGS;` を使用して、現在のユーザーが参照可能なカタログを確認できます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>現在のユーザーが <code>USE CATALOG</code> 権限を持たないカタログは、結果には表示されません。</p>
</main>

**例：**

```sql
obclient> SHOW CATALOGS;
```

## 現在のカタログの確認

`CURRENT_CATALOG()` または `CATALOG()` 関数を使用して、現在のセッションが属するカタログを確認できます。

**例：**

```sql
obclient> SELECT CURRENT_CATALOG() FROM dual;
```

## カタログ内のデータの表示

カタログ内では、データベース内のテーブルと同様にクエリ操作を実行でき、カタログ間での結合クエリも可能です。

**例：**

* 3部構成の名前（カタログ名・スキーマ名・テーブル名）で外部テーブルに直接アクセスします。

  ```text
  SELECT * FROM test_jdbc_catalog.dbo.table_name;
  ```

* カタログ間の結合クエリを実行します。

  ```text
  SELECT * FROM internal.system.test_t1, test_odps_catalog.project_name.test_t1;
  ```

## カタログの切り替え

`SET CATALOG catalog_name;` ステートメントを使用してカタログを切り替えることができます。詳細については、[SET CATALOG](../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/4900.set-catalog-of-oracle-mode.md)を参照してください。

**例：**

* システム内部のカタログに切り替えます。

  ```sql
  obclient> SET CATALOG internal;
  ```

* 外部カタログに切り替えます。

  ```sql
  obclient> SET CATALOG test_jdbc_catalog;
  ```
