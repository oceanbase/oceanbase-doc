# 作成済みのDBLinkの確認

DBLinkを作成した後、ビューを通じて作成されたDBLink情報を確認できます。

## 手順

DBLinkの作成が完了したら、`DBA_DB_LINKS`、`ALL_DB_LINKS`、`USER_DB_LINKS` などのビューを使用して、作成されたDBLinkを確認できます。

```sql
SELECT * FROM SYS.USER_DB_LINKS;
```

クエリ結果は次のとおりです。

```shell
+-----------+----------+----------+-----------------+------------------+---------------------+-----------+--------+----------------+-------+-----------+-------------+---------------------+--------------+----------------------+--------------+--------------+------------------+
| DB_LINK   | USERNAME | PASSWORD | CREDENTIAL_NAME | CREDENTIAL_OWNER | HOST                | CREATED   | HIDDEN | SHARD_INTERNAL | VALID | INTRA_CDB | TENANT_NAME | REVERSE_TENANT_NAME | CLUSTER_NAME | REVERSE_CLUSTER_NAME | REVERSE_HOST | REVERSE_PORT | REVERSE_USERNAME |
+-----------+----------+----------+-----------------+------------------+---------------------+-----------+--------+----------------+-------+-----------+-------------+---------------------+--------------+----------------------+--------------+--------------+------------------+
| OB_DBLINK | SYS      |  NULL    | NULL            | NULL             | xx.xx.xx.xx:2881    | 22-MAY-23 | NULL   | NULL           | YES   | NULL      | oracle001   | NULL                | NULL         | NULL                 | 0.0.0.0      |            0 | NULL             |
+-----------+----------+----------+-----------------+------------------+---------------------+-----------+--------+----------------+-------+-----------+-------------+---------------------+--------------+----------------------+--------------+--------------+------------------+
1 row in set
```

クエリ結果に含まれる一部のフィールドの説明は以下のとおりです：

* `DB_LINK`：作成されたDBLinkの名前。
* `USERNAME`：DBLinkがリモートデータベースに接続するために使用するユーザー名。
* `HOST`：DBLinkが接続するリモートデータベースのホスト名（IPアドレス）。
* `CREATED`：DBLinkの作成日時。
* `VALID`：DBLinkが利用可能かどうかを示すフラグです。互換性のためにのみ使用され、デフォルトは `YES` です。
* `TENANT_NAME`：DBLinkがリモートデータベースに接続するために使用するテナント名。
* `REVERSE_HOST`：リバースDBLinkがローカル側のデータベースに接続するホスト名（IPアドレス）。現在のDBLinkにリバースリンク機能がない場合は `0.0.0.0` と表示されます。
* `REVERSE_PORT`：リバースDBLinkがローカル側のデータベースに接続するポート番号。現在のDBLinkにリバースリンク機能がない場合は `0` と表示されます。
* `REVERSE_USERNAME`：リバースDBLinkがローカル側のデータベースに接続するユーザー名。現在のDBLinkにリバースリンク機能がない場合は `NULL` と表示されます。

`DBA_DB_LINKS`、`ALL_DB_LINKS`、`USER_DB_LINKS` などのビューに含まれるフィールドの詳細については、[DBA_DB_LINKS](../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/7900.dba_db_links.md)、[ALL_DB_LINKS](../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/900.all_db_links.md)、および [USER_DB_LINKS](../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/26000.user_db_links.md) を参照してください。
