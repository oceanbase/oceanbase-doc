# DBLinkの管理

OceanBaseデータベースは、DBLinkを管理するためのパラメータを提供しており、ビジネス戦略に応じてDBLink機能を有効または無効にすることができます。また、特定のビジネス要件に合わせて、リモートデータベース接続の再利用状況を調整することも可能です。

## DBLink機能の有効化または無効化

OceanBaseデータベースでは、クラスタレベルのパラメータ`enable_dblink`を使用してDBLink機能を有効または無効にできます。`enable_dblink`オプションはデフォルトで有効(`True`)状態に設定されており、DBLink機能を利用可能にしています。`True`に設定するとDBLink機能が有効になり、`False`に設定するとDBLink機能が無効になります。DBLink機能を使用する際には`OB_OP_NOT_ALLOW`エラーが発生し、操作が許可されないことを示します。

クラスタレベルの構成パラメータ`enable_dblink`の詳細については、[enable_dblink](../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/6500.enable_dblink.md)を参照してください。

**例：**

sysテナントで以下のステートメントを実行し、DBLink機能の使用状態を設定します。

* DBLink機能を有効にします。

    ```sql
    ALTER SYSTEM SET enable_dblink = True;
    ```

* DBLink機能を無効にします。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><code>enable_dblink</code>はクラスタレベルのパラメータであり、特別な場合を除きDBLink機能を無効にする必要はありません。</p>
    </main>

    ```sql
    ALTER SYSTEM SET enable_dblink = False;
    ```

## DBLinkによるリモートデータベース接続の再利用の設定

OceanBaseデータベースは、パラメータ`_enable_dblink_reuse_connection`を使用してDBLink接続の再利用を制御します。このオプションを有効にすると、同一セッション内でリモートデータベースへの接続を再利用できるようになり（長い接続）、効率とパフォーマンスが向上します。ネットワーク環境が不安定または異常が発生した場合は、このオプションを無効にすることで、リモートデータベースへのアクセスごとに新しい接続（短い接続）を確立し、潜在的な接続問題を回避できます。

|   プロパティ   |   説明   |
|----------|----------|
| パラメータタイプ  | 整数型     |
| デフォルト値    | 1、デフォルトで接続再利用スイッチがオンになっていることを示します。|
| 値の範囲  | 0または1。<ul><li>1：接続再利用スイッチがオンであることを示します。</li><li>0：接続再利用スイッチがオフであることを示します。</li></ul> |
| 有効化モード  | 即時に反映 |
| レベル      | テナントレベル |

**例：**

* ユーザーテナントで以下のステートメントを実行し、セッション内でDBLinkが接続を再利用しないように設定します。

  ```sql
  ALTER SYSTEM SET "_enable_dblink_reuse_connection" = 0;
  ```

* ユーザーテナントで以下のステートメントを実行し、セッション内でDBLinkが接続を再利用するように設定します。

  ```sql
  ALTER SYSTEM SET "_enable_dblink_reuse_connection" = 1;
  ```
