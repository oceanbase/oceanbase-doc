# DBLinkの削除

不要なDBLinkを削除できます。

## 手順

DBLinkを削除する構文は次のとおりです：

```sql
obclient> DROP DATABASE LINK dblink_name;
```

ステートメントの使用方法：

* このステートメントを実行するユーザーには`DROP DATABASE LINK`権限が付与されている必要があります。ユーザーへの権限付与に関する操作については、[直接権限付与](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/200.authority-of-oracle-mode.md)を参照してください。

* `dblink_name` は削除対象のDBLink名を表します。

例：

```sql
obclient> DROP DATABASE LINK ob_dblink;
Query OK, 1 row affected
```

```sql
obclient> DROP DATABASE LINK orcl_dblink;
Query OK, 1 row affected
```
