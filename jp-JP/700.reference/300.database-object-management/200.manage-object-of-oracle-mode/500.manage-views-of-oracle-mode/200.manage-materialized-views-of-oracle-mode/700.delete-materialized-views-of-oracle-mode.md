# マテリアライズドビューの削除

## 権限要件

マテリアライズドビューを削除するには、`DROP TABLE` 権限が必要です。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 注意事項

* マテリアライズドビューを単独で削除する場合、マテリアライズドビューはゴミ箱に移動しません。
* マテリアライズドビューのベーステーブルにマテリアライズドビューのログが作成されている場合、ベーステーブルを削除する前に、そのベーステーブル上のマテリアライズドビューのログを削除する必要があります。そうでない場合、エラーが発生します。

## 構文

マテリアライズドビューを削除するSQLステートメントの形式は次のとおりです：

```sql
DROP MATERIALIZED VIEW [ schema. ] materialized_view;
```

**パラメータ説明：**

|       **パラメータ**    |       **説明**           |
|-------------------|--------------------------|
| schema.           | オプションです。マテリアライズドビューが存在するスキーマを指定します。`schema.` を省略した場合、デフォルトで自身のスキーマになります。|
| materialized_view | マテリアライズドビューの名前を指定します。|

## 例

以下では、マテリアライズドビューの作成、クエリ、削除の情報を示します。

1. ベーステーブルとして `test_tbl1` テーブルを作成します。

    ```sql
    CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR2(20), col3 INT);
    ```

2. `test_tbl1` テーブルに基づいて、`mv_test_tbl1` という名前のマテリアライズドビューを作成します。

    ```sql
    CREATE MATERIALIZED VIEW mv_test_tbl1(PRIMARY KEY (col1))
        AS SELECT col1, col2
           FROM test_tbl1;
    ```

3. マテリアライズドビュー `mv_test_tbl1` にマテリアライズドビューのログを作成します。

    ```sql
    CREATE MATERIALIZED VIEW LOG ON mv_test_tbl1
        WITH PRIMARY KEY (col2) INCLUDING NEW VALUES;
    ```

4. マテリアライズドビュー `mv_test_tbl1` に基づいて、マテリアライズドビュー（ネストされたマテリアライズドビュー） `mv_mv_test_tbl1` を作成します。

    ```sql
    CREATE MATERIALIZED VIEW mv_mv_test_tbl1
        AS SELECT col1
           FROM mv_test_tbl1;
    ```

5. 現在のすべてのマテリアライズドビュー情報を確認します。

    ```sql
    SELECT owner, mview_name, container_name, query, refresh_mode
    FROM sys.DBA_MVIEWS
    WHERE OWNER = 'TEST_USER001';
    ```

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>Oracleモードでは、ビュー<code>sys.DBA_MVIEWS</code>のフィールド<code>OWNER</code>がスキーマ名と一致する場合、スキーマ名は大文字である必要があります。</p>
    </main>

    実行結果は次のとおりです：

    ```shell
    +--------------+-----------------+-----------------+--------------------------------------------------------------------------------------------------------------------------------+--------------+
    | OWNER        | MVIEW_NAME      | CONTAINER_NAME  | QUERY                                                                                                                          | REFRESH_MODE |
    +--------------+-----------------+-----------------+--------------------------------------------------------------------------------------------------------------------------------+--------------+
    | TEST_USER001 | MV_TEST_TBL1    | MV_TEST_TBL1    | select "TEST_USER001"."TEST_TBL1"."COL1" AS "COL1","TEST_USER001"."TEST_TBL1"."COL2" AS "COL2" from "TEST_USER001"."TEST_TBL1" | DEMAND       |
    | TEST_USER001 | MV_MV_TEST_TBL1 | MV_MV_TEST_TBL1 | select "MV_TEST_TBL1"."COL1" AS "COL1" from "TEST_USER001"."MV_TEST_TBL1" "MV_TEST_TBL1"                                       | DEMAND       |
    +--------------+-----------------+-----------------+--------------------------------------------------------------------------------------------------------------------------------+--------------+
    2 rows in set
    ```

6. マテリアライズドビュー`mv_mv_test_tbl1`を削除します。

    ```sql
    DROP MATERIALIZED VIEW mv_mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

7. マテリアライズドビュー`mv_test_tbl1`を削除します。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>マテリアライズドビューのベーステーブルにマテリアライズドビューのログが作成されている場合、ベーステーブルを削除する前に、まずベーステーブル上のマテリアライズドビューのログを削除する必要があります。そうしないと、エラーが発生します。</p>
    </main>

    ```sql
    DROP MATERIALIZED VIEW mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    OBE-00600: internal error code, arguments: -4007, drop table required by materialized view refresh is not supported
    ```

8. マテリアライズドビュー`mv_test_tbl1`上のマテリアライズドビューのログを削除します。

    ```sql
    DROP MATERIALIZED VIEW LOG ON mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

9. マテリアライズドビュー`mv_test_tbl1`を再度削除します。

    ```sql
    DROP MATERIALIZED VIEW mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```
