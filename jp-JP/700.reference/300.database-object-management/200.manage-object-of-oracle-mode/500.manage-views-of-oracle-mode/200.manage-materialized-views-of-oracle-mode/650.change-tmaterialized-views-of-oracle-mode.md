# マテリアライズドビューのプロパティを変更する

本記事では、SQLステートメントを使用してマテリアライズドビューのプロパティを変更する方法について説明します。

## 権限要件

マテリアライズドビューを変更するには、現在のユーザーが操作対象に対する `ALTER` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[Oracleモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

## 構文

マテリアライズドビューを変更するSQLステートメントの形式は次のとおりです：

```sql
ALTER MATERIALIZED VIEW [schema.]view_name alter_mview_action_list;

alter_mview_action_list:
    alter_mview_action [, alter_mview_action ...]

alter_mview_action:
    parallel_clause
    | REFRESH [nested_refresh_option] [[START WITH expr] [NEXT expr]]

parallel_clause:
    NOPARALLEL
    | PARALLEL integer
    | REFRESH PARALLEL integer

nested_refresh_option:
    INDIVIDUAL
    | INCONSISTENT
    | CONSISTENT
```

## パラメータ説明

* `schema.`：オプションです。マテリアライズドビューが存在するスキーマを指定します。`schema.` を省略した場合、デフォルトでマテリアライズドビューは現在のセッションが存在するスキーマに配置されます。
* `view_name`：変更対象のマテリアライズドビューの名前を指定します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースでは、<code>RENAME TABLE</code> ステートメントを使用してマテリアライズドビューの名前を変更できます。</p>
  </main>

* `alter_mview_action_list`：マテリアライズドビューに対して実行できる変更操作のリストを示します。複数の操作を同時に指定することができ、英字のカンマ（`,`）で区切ります。

マテリアライズドビューを変更する構文の詳細なパラメータ説明については、[ALTER MATERIALIZED VIEW](../../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/250.alter-materialized-view-of-oracle-mode-in-sql.md)を参照してください。

## 例

1. テーブル `test_tbl1` を作成します。

    ```sql
    CREATE TABLE test_tbl1 (col1 NUMBER PRIMARY KEY, col2 VARCHAR2(20), col3 NUMBER, col4 BLOB);
    ```

2. `mv_test_tbl1` という名前のマテリアライズドビューを作成します。

    ```sql
    CREATE MATERIALIZED VIEW mv_test_tbl1
        AS SELECT col1, col2, col3
           FROM test_tbl1;
    ```

3. マテリアライズドビュー `mv_test_tbl1` のクエリ並列度を5に変更します。

    ```sql
    ALTER MATERIALIZED VIEW mv_test_tbl1 PARALLEL 5;
    ```

4. マテリアライズドビュー `mv_test_tbl1` のリフレッシュ計画を変更し、初期リフレッシュ時刻を現在日付に設定します。その後、1日ごとにマテリアライズドビューをリフレッシュします。

    ```sql
    ALTER MATERIALIZED VIEW mv_test_tbl1
        REFRESH START WITH current_date NEXT current_date + 1;
    ```

5. マテリアライズドビュー `mv_test_tbl1` を基に、`mv_mv_test_tbl1` という名前のネストされたマテリアライズドビューを作成します。リフレッシュポリシーは `INDIVIDUAL` に設定します。

    ```sql
    CREATE MATERIALIZED VIEW mv_mv_test_tbl1
        REFRESH COMPLETE INDIVIDUAL
        AS SELECT col1, col2
           FROM mv_test_tbl1;
    ```

6. ネストされたマテリアライズドビュー `mv_mv_test_tbl1` のリフレッシュポリシーを `INCONSISTENT` に変更します。

    ```sql
    ALTER MATERIALIZED VIEW mv_mv_test_tbl1
        REFRESH INCONSISTENT;
    ```

7. ネストされたマテリアライズドビュー `mv_mv_test_tbl1` のリフレッシュ並列度を3に変更します。

    ```sql
    ALTER MATERIALIZED VIEW mv_mv_test_tbl1
        REFRESH PARALLEL 3;
    ```
