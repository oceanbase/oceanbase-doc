# マテリアライズドビューのリソース分離

OceanBaseデータベースは、`DBMS_RESOURCE_MANAGER`がマテリアライズドビューの増分更新およびMLOG Purgeに対してリソース分離機能を提供することをサポートしており、マテリアライズドビューが使用できるリソースの上限を設定できます。

## 例

1. リソースプラン `mview_task` を作成します。

    ```sql
    CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('mview_task','このリソースプランはマテリアライズドビュー処理に使用されます');
    ```

    リソースプランの作成に関する詳細は、[CREATE_PLAN](../../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/13300.dbms-resource-manager-oracle/300.create-plan-oracle.md)を参照してください。

2. リソースユーザーグループ `mview_group` を定義します。

    ```sql
    CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('mview_group','マテリアライズドビュー処理グループ');
    ```

    リソースユーザーグループの作成に関する詳細は、[CREATE_CONSUMER_GROUP](../../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/13300.dbms-resource-manager-oracle/200.create-consumer-group-oracle.md)を参照してください。

3. CPUリソース使用率の上限を5%に制限するリソースプランを作成します。

    ```sql
    CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE(
        PLAN => 'mview_task',
        GROUP_OR_SUBPLAN => 'mview_group',
        UTILIZATION_LIMIT => 5
        );
    ```

    リソースプランの作成に関する詳細は、[CREATE_PLAN_DIRECTIVE](../../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/13300.dbms-resource-manager-oracle/400.create-plan-directive-oracle.md)を参照してください。

4. リソースプランを `FUNCTION` にバインドします。

    ```sql
    CALL DBMS_RESOURCE_MANAGER.SET_CONSUMER_GROUP_MAPPING(
        ATTRIBUTE => 'FUNCTION',
        VALUE => 'MVIEW',
        CONSUMER_GROUP => 'mview_group'
        );
    ```

    セッションとリソースグループのマッピングに関する詳細は、[SET_CONSUMER_GROUP_MAPPING](../../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/13300.dbms-resource-manager-oracle/800.set-consumer-group-mappingn-directive-oracle.md)を参照してください。

5. リソース管理プラン `mview_task` を有効化します。

    ```sql
    SET GLOBAL resource_manager_plan = 'mview_task';
    ```

    リソース管理プランの有効化に関する詳細は、[resource_manager_plan](../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/11500.resource_manager_plan-global.md)を参照してください。

6. CPUリソース使用率の上限を30%に変更します。

    ```sql
    CALL DBMS_RESOURCE_MANAGER.UPDATE_PLAN_DIRECTIVE(
        PLAN => 'mview_task',
        GROUP_OR_SUBPLAN => 'mview_group',
        NEW_UTILIZATION_LIMIT => 30
        );
    ```

    リソースプランの更新に関する詳細は、[UPDATE_PLAN_DIRECTIVE](../../../../600.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/13300.dbms-resource-manager-oracle/900.update-plan-directive-oracle.md)を参照してください。
