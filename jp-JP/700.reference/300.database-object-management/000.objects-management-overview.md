# データベースオブジェクト管理の概要

データベースオブジェクトはデータベースの重要な構成要素であり、一般的なデータベースオブジェクトにはテーブル、インデックス、ビュー、トリガーなどがあります。

OceanBaseデータベースV4.0.0バージョンでは、object_idが導入され、一部のデータベースオブジェクトに対してグローバルな統一コードが割り当てられました。object_idによるコード割り当てはテナント内で一意です。

object_idによって統一的にコード化されるデータベースオブジェクトは以下のとおりです：

* テーブル（table）

* テーブルパーティション（partition）

* データベース（database）

* ユーザー（user）

* ロール（role）

* シーケンス（sequence）

* アウトライン（outline）

* 制約（constraint）

* 外部キー（foreign key）

* シノニム（synonym）

* UDF

* PL（UDT、routine、package）

* トリガー（trigger）

* ケーストア（keystore、マスターキーを含む）

* label_se_policy、label_se_component、label_se_label、label_se_user_level

* テーブルスペース（tablespace）

* プロファイル（profile）

* 監査（audit）

* dblink

* ディレクトリ（directory）

* コンテキスト（context）
