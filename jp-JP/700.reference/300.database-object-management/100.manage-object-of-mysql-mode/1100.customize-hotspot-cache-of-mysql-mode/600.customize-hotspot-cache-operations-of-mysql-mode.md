# カスタムホットスポットキャッシュ戦略の運用ガイド

本記事では、SQLステートメントを使用してカスタムホットスポットキャッシュ戦略のバックグラウンドタスク実行を制御する方法について説明します。これには、一時停止、再開、および手動でのトリガー操作が含まれます。

## バックグラウンドキャッシュタスクの一時停止/再開

OceanBaseデータベースは、バックグラウンドキャッシュタスクを一時停止するかどうかを設定する構成パラメータ`suspend_storage_cache_task`を提供しています。値は以下のとおりです：

* `True`：現在進行中および新規に開始されるキャッシュタスクを一時停止します。
* `False`：バックグラウンドのキャッシュタスクを一時停止せず、一時停止状態のキャッシュタスクを再開します。

この構成パラメータの詳細については、[suspend_storage_cache_task](../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/8070.suspend_storage_cache_task.md)を参照してください。

### 例

* 以下のコマンドを実行して、テナント内のすべてのホットスポットキャッシュタスクを一時停止します。

    ```shell
    obclient> ALTER SYSTEM SET suspend_storage_cache_task = true;
    ```

* 以下のコマンドを実行して、テナント内で一時停止状態のすべてのホットスポットキャッシュタスクを再開します。

    ```shell
    obclient> ALTER SYSTEM SET suspend_storage_cache_task = false;
    ```

## ホットデータキャッシュタスクを1回手動でトリガーする

カスタムホットスポットキャッシュ戦略が有効になった後、以下のSQLステートメントを実行することで、ホットデータキャッシュタスクの実行を手動で即座に1回トリガーできます：

```sql
ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```

### 例

以下のコマンドを実行すると、ホットスポットキャッシュタスクが即座に1回トリガーされます。

```shell
obclient> ALTER SYSTEM TRIGGER STORAGE_CACHE_POLICY_EXECUTOR;
```
