## パラメータタイプに制限があるシステム関数

以下のシステム関数は、パラメータがTIME型の場合、関数インデックスとして使用することを禁止されています。例えば、`DATE` 関数では、最初のパラメータがTIMEの場合、関数インデックスとして使用することを禁止します。また、`DATEDIFF` 関数では、いずれかのパラメータがTIME型の場合、関数インデックスとして使用することを禁止します。

|------------|------------------|------------|---------------|
| ADDDATE       | DAY            | DAYNAME        | DAYOFMONTH     |
| DAYOFWEEK     | DAYOFYEAR      | DATEDIFF       | DATE           |
| DATE_SUB      | LAST_DAY       | MONTH          | MONTHNAME      |
| QUARTER       | TIMESTAMP      | TIMESTAMPADD   | TIMESTAMPDIFF  |
| TIMESTAMP_NVL | TO_DAYS        | WEEK           | WEEKDAY        |
| WEEKOFYEAR    | YEAR           | YEARWEEK       |                |

## CAST式

CAST式は特殊であり、そのターゲットタイプまたはソースタイプが時間型の場合、関数インデックスとして使用することを禁止されています。具体的なシナリオは以下の表に示されています。

| ソースタイプ                                  | ターゲットタイプ                       | 説明            |
|----------------------------------------|--------------------------------|----------------|
| TIME                                   | DATETIME / TIMESTAMP / DATE    | 関数インデックスとしての使用を禁止 |
| datetime/TIMESTAMP/DATE                | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | 関数インデックスとしての使用を禁止 |
