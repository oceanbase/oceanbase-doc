## パラメータタイプに制限があるシステム関数

以下のシステム関数は、パラメータがTIME型の場合、関数インデックスとして使用することは禁止されています。例えば、`DATE` 関数では、最初のパラメータがTIMEの場合に関数インデックスとして使用することが禁止されています。`DATEDIFF` 関数では、いずれかのパラメータがTIME型の場合に関数インデックスとして使用することが禁止されています。

|------------|------------------|------------|---------------|
| DATE       | TIMESTAMP        | MONTHNAME  |  ADDDATE      |
| DATE_SUB   | DAY              | MONTH      | TIMESTAMP_NVL |
| DAYNAME    | YEAR             | TIMESTAMPDIFF | QUARTER    |
| DAYOFMONTH | WEEKOFYEAR       | TO_DAYS    | DAYOFWEEK     |
| WEEKDAY    | DATEDIFF         | DAYOFYEAR  | YEARWEEK      |
| TIMESTAMPADD  |  LAST_DAY     | WEEK       |    -          |

## CAST式

CAST式はやや特殊であり、その対象型または源型が時間型の場合、関数インデックスとして使用することは禁止されています。具体的なシナリオは以下の表のとおりです。

| ソース型                                  | ターゲット型                       | 説明            |
|----------------------------------------|--------------------------------|----------------|
| TIME                                   | DATETIME / TIMESTAMP / DATE    | 関数インデックスとしての使用は禁止されています |
| datetime/TIMESTAMP/DATE                | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | 関数インデックスとしての使用は禁止されています |
