## CAST式

CAST式には特別な制限があり、変換元または変換先の型が日時型の場合、関数ベースのインデックスでは使用できません。具体的な条件は次の表のとおりです。

| 変換元の型 | 変換先の型 | 説明 |
|----------------------------------------|--------------------------------|----------------|
| TIME                                   | DATETIME / TIMESTAMP / DATE    | 関数ベースのインデックスとしての使用は禁止されています |
| datetime/TIMESTAMP/DATE                | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | 関数ベースのインデックスとしての使用は禁止されています |
