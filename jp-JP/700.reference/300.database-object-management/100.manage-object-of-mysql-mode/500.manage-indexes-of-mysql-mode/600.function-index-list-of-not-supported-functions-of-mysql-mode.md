# 関数インデックスがサポートされないシステム関数の一覧

OceanBaseデータベースのMySQLモードでは、関数インデックスの式に制限があります。このセクションでは、関数インデックスに使用することを禁止されているシステム関数を主にリストアップします。

## 非決定性システム関数

以下の非決定性システム関数の式は、関数インデックスに使用することが禁止されています。

|----------------|-----------------|----------------|-----------------|
| BENCHMARK      | Charset         | Collation      | NAME_CONST    |
| NOW            | RAND            | UNIX_TIMESTAMP | -             |

## GISシステム関数

以下のGISシステム関数はOceanBaseデータベース独自のシステム関数であり、現在関数インデックスへの使用が禁止されています。

|--------------------------|--------------------------|----------------------------|---------------------------|
| PRIV_ST_ASEWKB     | PRIV_ST_ASEWKT     | PRIV_ST_BESTSRID   | PRIV_ST_BUFFER   |
| PRIV_ST_POINT      | PRIV_ST_SETSRID    | ST_COVERS          | ST_DWITHIN       |

## 非ユーザー定義のシステム関数

非ユーザー定義のシステム関数は、デフォルトではすべて関数インデックスへの使用が禁止されています。
