# 関数ベースのインデックスでサポートされていないシステム関数のリスト

OceanBaseデータベースのMySQLモードでは、関数ベースのインデックスの式に制限があります。このセクションでは、関数ベースのインデックスで使用することが禁止されているシステム関数を主に説明します。

## 非決定的なシステム関数

以下の非決定的なシステム関数の式は、関数ベースのインデックスでの使用が禁止されています。

<table>
<tr><td>RAND</td><td>BENCHMARK</td><td>UNIX_TIMESTAMP</td><td>NOW</td></tr>
<tr><td>Charset</td><td>Collation</td><td>NAME_CONST</td><td>-</td></tr></table>

## 空間システム関数

以下の空間システム関数は、OceanBaseデータベース独自のシステム関数であり、現在関数ベースのインデックスでの使用は禁止されています。

<table>
<tr><td>ST_COVERS</td><td>ST_DWITHIN</td><td>PRIV_ST_BESTSRID</td><td>PRIV_ST_POINT</td></tr>
<tr><td>PRIV_ST_ASEWKT</td><td>PRIV_ST_BUFFER</td><td>PRIV_ST_SETSRID</td><td>PRIV_ST_ASEWKB</td></tr></table>

## ユーザー向けではないシステム関数

ユーザー向けではないシステム関数は、デフォルトですべて関数ベースのインデックスでの使用が禁止されています。
