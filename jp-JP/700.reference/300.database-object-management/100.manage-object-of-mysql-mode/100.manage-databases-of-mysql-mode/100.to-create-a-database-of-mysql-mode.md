# データベースの作成

この記事では、MySQLモードにおけるデータベースの作成ステートメントと操作方法について説明します。

## 前提条件

現在のユーザーが`CREATE`権限を持っていることを確認してください。現在持っている権限を確認する操作については、[ユーザー権限の確認](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。`CREATE`権限がない場合は、管理者に連絡して追加してもらい、ユーザーに権限を追加する関連操作については、[直接権限付与](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

## 手順

1. ユーザーがクラスタのMySQLテナントにログインします。

2. `CREATE DATABASE`ステートメントを使用してデータベースを作成します。

   例：

   * データベース`test2`を作成し、文字セットを`UTF8`と指定します。

     ```sql
     obclient> CREATE DATABASE test2 DEFAULT CHARACTER SET UTF8;
     Query OK, 1 row affected
     ```

   * 読み書きプロパティのデータベース`test3`を作成します。

     ```sql
     obclient> CREATE DATABASE test3 READ WRITE;
     Query OK, 1 row affected
     ```

   * 読み取り専用プロパティのデータベース`test4`を作成します。

     ```sql
     obclient> CREATE DATABASE test4 READ ONLY;
     Query OK, 1 row affected
     ```
