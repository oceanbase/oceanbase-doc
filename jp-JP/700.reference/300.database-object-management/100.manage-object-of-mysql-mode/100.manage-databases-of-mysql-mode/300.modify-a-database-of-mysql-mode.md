# データベースの変更

このセクションでは、MySQLモードにおけるデータベースの変更ステートメントと操作方法について説明します。

## 前提条件

現在のユーザーが `ALTER` 権限を持っていることを確認してください。現在持っている権限を確認する操作については、[ユーザー権限の確認](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。`ALTER` 権限がない場合は、管理者に連絡し、追加してもらってください。ユーザー権限の追加に関する操作については、[直接権限付与](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

## 手順

1. ユーザーがクラスタのMySQLテナントにログインします。

2. `ALTER DATABASE` ステートメントを使用してデータベースのプロパティを変更します。

   **例：**

   データベース `test2` の文字セットを `UTF8MB4`、照合規則を `UTF8MB4_BIN` に変更し、読み書き可能な属性に設定します。

   ```shell
   obclient> ALTER DATABASE test2 DEFAULT CHARACTER SET UTF8MB4;
   ```

   ```shell
   obclient> ALTER DATABASE test2 DEFAULT COLLATE UTF8MB4_BIN;
   ```

   ```shell
   obclient> ALTER DATABASE test2 READ WRITE;
   ```
