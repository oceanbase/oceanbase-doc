# データベースの変更

この記事では、MySQLモードにおけるデータベースの変更ステートメントと操作方法について説明します。

## 前提条件

現在のユーザーが`ALTER`権限を持っていることを確認してください。現在持っている権限を確認する操作については、[ユーザー権限の確認](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。`ALTER`権限がない場合は、管理者に連絡して追加してもらい、ユーザーに権限を付与する関連操作については、[直接権限付与](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

## 手順

1. ユーザーがクラスタのMySQLテナントにログインします。

2. `ALTER DATABASE`ステートメントを使用してデータベースのプロパティを変更します。

   例：

   データベース`test2`の文字セットを`UTF8MB4`、照合ルールを`UTF8MB4_BIN`に変更し、読み書きプロパティにします。

   ```sql
   obclient> ALTER DATABASE test2 DEFAULT CHARACTER SET UTF8MB4;

   obclient> ALTER DATABASE test2 DEFAULT COLLATE UTF8MB4_BIN;

   obclient> ALTER DATABASE test2 READ WRITE;
   ```

## 関連ドキュメント

`ALTER DATABASE`ステートメントの詳細な構文については、[ALTER DATABASE](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1200.alter-database-of-mysql-mode.md)を参照してください。
