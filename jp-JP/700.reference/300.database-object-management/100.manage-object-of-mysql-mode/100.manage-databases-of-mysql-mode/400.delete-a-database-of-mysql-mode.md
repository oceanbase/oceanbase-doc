# データベースの削除

この記事では、MySQLモードにおけるデータベースの削除ステートメントと操作方法について説明します。

## 前提条件

現在のユーザーが`DROP`権限を持っていることを確認してください。現在持っている権限を確認する操作については、[ユーザー権限の確認](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。`DROP`権限がない場合は、管理者に連絡して追加してもらってください。ユーザーに権限を追加する関連操作については、[直接権限付与](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

## 手順

1. ユーザーがクラスタのMySQLテナントにログインします。

2. `DROP DATABASE`ステートメントを使用してデータベースを削除します。

   例：

   ```shell
   obclient> DROP DATABASE my_db;
   ```

## 次のステップ

誤ってデータベースを削除した場合は、ごみ箱機能を有効にしていれば復元できます。関連操作については、[ごみ箱オブジェクトの復元](../../../../600.manage/400.high-availability/500.recyclebin-management/400.restore-the-recyclebin-objects.md)を参照してください。

## 関連ドキュメント

`DROP DATABASE`ステートメントの詳細な構文については、[DROP DATABASE](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/3400.drop-database-of-mysql-mode.md)を参照してください。
