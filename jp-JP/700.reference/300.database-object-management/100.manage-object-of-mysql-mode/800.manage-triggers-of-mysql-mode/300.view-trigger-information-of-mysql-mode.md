# トリガー情報の確認

トリガー情報の確認とは、データベース内に既存するトリガーの定義、ステータス、構文情報などを確認することを指します。

トリガー情報を確認するには、以下の方法があります：

* `SHOW` ステートメントを使用する

  ```sql
  obclient>SHOW TRIGGERS [FROM database_name];
  ```

  ここで、`database_name` は指定されたデータベース名を表します。`FROM database_name` を使用しない場合は、現在のデータベースのトリガー情報を確認することを意味します。

* ビューを使用する

  ```sql
  obclient>SELECT * FROM information_schema.triggers [where trigger_name = 'xx'];
  ```

  クエリ条件を指定しない場合は、すべてのトリガー情報を確認することを意味します。
