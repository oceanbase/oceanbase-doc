# トリガーの削除

`DROP TRIGGER` ステートメントを使用してトリガーを削除できます。

トリガーを削除するユーザーは、そのトリガーに関連するテーブルに対する権限が必要です。テーブルを削除すると、そのテーブルに関連するトリガーも削除されます。

トリガーを削除する構文は以下のとおりです：

```sql
obclient> DROP TRIGGER [IF EXISTS] [database_name.]trigger_name;
```

ここで：

* `IF EXISTS` は、作成したトリガーが既に存在する場合、トリガーを再作成することを意味します。

* `database_name` はデータベース名を表し、オプションのパラメータです。指定しない場合は、現在のデータベースからトリガーを削除します。

例：

```sql
obclient> DROP TRIGGER test.test_trg;
```
