# DBLinkの管理

OceanBaseデータベースは、DBLinkを管理するための構成パラメータを提供しており、ビジネス戦略に応じてDBLink機能を有効または無効にすることができます。また、特定のビジネスニーズに合わせて、リモートデータベース接続の再利用状況を調整することも可能です。

## DBLink機能の有効化または無効化

OceanBaseデータベースでは、クラスタレベルの構成パラメータ`enable_dblink`を使用してDBLink機能を有効または無効にできます。`enable_dblink`オプションはデフォルトでオン(`True`)状態に設定されており、DBLink機能を利用可能な状態にします。`True`に設定するとDBLink機能が有効になり、`False`に設定するとDBLink機能が無効になります。この状態でDBLink機能を使用すると`OB_OP_NOT_ALLOW`エラーが発生し、操作が許可されないことを示します。

クラスタレベルの構成パラメータ`enable_dblink`の詳細については、[enable_dblink](../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/6500.enable_dblink.md)を参照してください。

**例：**

sysテナントで以下のステートメントを実行し、DBLink機能の使用状態を設定します。

* DBLink機能を有効にします。

    ```sql
    ALTER SYSTEM SET enable_dblink = True;
    ```

* DBLink機能を無効にします。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><code>enable_dblink</code>はクラスタレベルの構成パラメータであり、特別な場合を除きDBLink機能を無効にする必要はありません。</p>
    </main>

    ```sql
    ALTER SYSTEM SET enable_dblink = False;
    ```

## DBLinkによるリモートデータベース接続の再利用の設定

OceanBaseデータベースは、隠し構成パラメータ`_enable_dblink_reuse_connection`を通じて、DBLink接続の再利用を制御します。このオプションを有効にすると、同一セッション内でリモートデータベースへの接続を維持して再利用することが可能になり、効率とパフォーマンスが向上します。ネットワーク環境が不安定または異常が発生した場合は、このオプションを無効にすることで、リモートデータベースへのアクセスごとに新しい一時的な接続を確立し、潜在的な接続問題を回避できます。

|   プロパティ   |   説明   |
|----------|----------|
| パラメータの型  | ブール型 |
| デフォルト値    | True、デフォルトで接続再利用スイッチがオンであることを示します。|
| 値の範囲  | FalseまたはTrue。<ul><li>True：接続再利用スイッチがオンであることを示します。</li><li>False：接続再利用スイッチがオフであることを示します。</li></ul> |
| 反映タイミング  | 即時に反映されます |
| レベル      | テナントレベル |

### 例

* ユーザーテナントで以下のステートメントを実行し、セッション内でDBLinkが接続を再利用しないように設定します。

  ```sql
  ALTER SYSTEM SET _enable_dblink_reuse_connection = False;
  ```

* ユーザーテナントで以下のステートメントを実行し、セッション内でDBLinkが接続を再利用するように設定します。

  ```sql
  ALTER SYSTEM SET _enable_dblink_reuse_connection = True;
  ```
