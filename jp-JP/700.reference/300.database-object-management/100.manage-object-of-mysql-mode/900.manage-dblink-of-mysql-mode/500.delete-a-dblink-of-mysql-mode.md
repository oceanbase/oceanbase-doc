# DBLinkの削除

不要なDBLinkは削除できます。

## 手順

DBLinkを削除する構文は次のとおりです：

```sql
DROP DATABASE LINK [IF EXISTS] dblink_name;
```

ステートメントの使用方法：

* このステートメントを実行するユーザーには、`DROP DATABASE LINK`権限が付与されている必要があります。ユーザーへの権限付与に関する操作については、[直接権限付与](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

* `IF EXISTS`：`IF EXISTS`を指定した場合、削除対象のDBLinkが存在しなくてもエラーは報告されません。指定されていない場合、削除対象のDBLinkが存在しないとシステムからエラーが報告されます。

* `dblink_name`は、削除対象のDBLinkの名前を表します。

例：

```sql
DROP DATABASE LINK IF EXISTS ob_dblink;
```
