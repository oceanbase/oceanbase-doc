# 作成済みのDBLinkを確認する

DBLinkを作成した後、ビューを通じて作成されたDBLinkの情報を確認できます。これには、データベースリンクを作成したユーザー、データベースリンク名、リモートデータベースのIPアドレス、ポート番号などが含まれます。

## 手順

DBLinkの作成が成功した後、`DBA_DB_LINKS`ビューを使用して作成されたDBLinkを確認できます。

```sql
SELECT * FROM oceanbase.DBA_DB_LINKS;
```

クエリ結果は次のとおりです。

```sql
+--------+-----------+----------+-----------------+------------------+---------------------+---------------------+--------+----------------+-------+-----------+-------------+---------------+---------------------+--------------+----------------------+--------------+--------------+
| OWNER  | DB_LINK   | USERNAME | CREDENTIAL_NAME | CREDENTIAL_OWNER | HOST                | CREATED             | HIDDEN | SHARD_INTERNAL | VALID | INTRA_CDB | TENANT_NAME | DATABASE_NAME | REVERSE_TENANT_NAME | CLUSTER_NAME | REVERSE_CLUSTER_NAME | REVERSE_HOST | REVERSE_PORT |
+--------+-----------+----------+-----------------+------------------+---------------------+---------------------+--------+----------------+-------+-----------+-------------+---------------+---------------------+--------------+----------------------+--------------+--------------+
| PUBLIC | ob_dblink | test     |                 |                  | xx.xx.xx.xx:2881    | 2023-05-25 13:40:35 |        |                | YES   |           | mysql001    | mydb          |                     |              |                      | 0.0.0.0      |            0 |
+--------+-----------+----------+-----------------+------------------+---------------------+---------------------+--------+----------------+-------+-----------+-------------+---------------+---------------------+--------------+----------------------+--------------+--------------+
1 row in set
```

クエリ結果の一部のフィールドについて説明します：

* `OWNER`：DBLinkの所有者。現在、すべてのDBLinkは`PUBLIC`であり、テナント範囲内のすべてのユーザーが利用可能であることを示します。
* `DB_LINK`：作成されたDBLinkの名前。
* `USERNAME`：DBLinkがリモートデータベースに接続するために使用するユーザー名。
* `HOST`：DBLinkが接続するリモートデータベースのホスト名（IPアドレス）。
* `CREATED`：DBLinkの作成時間。
* `VALID`：DBLinkが利用可能かどうかを示すために使用されます。互換性のためにのみ使用され、デフォルトは`YES`です。
* `TENANT_NAME`：DBLinkがリモートデータベースに接続するために使用するテナント名。
* `DATABASE_NAME`：DBLinkが接続するリモートデータベース名。
* `REVERSE_TENANT_NAME`：リバースDBLinkがローカルデータベースに接続するために使用するテナント名。MySQLモードでは、リバースLink機能は現在サポートされていません。
* `CLUSTER_NAME`：DBLinkがリモートデータベースに接続するために使用するクラスタ名。
* `REVERSE_CLUSTER_NAME`：リバースDBLinkがローカルデータベースに接続するために使用するクラスタ名。MySQLモードでは、リバースLink機能は現在サポートされていません。
* `REVERSE_HOST`：リバースDBLinkがローカルデータベースに接続するためのホスト名（IPアドレス）。現在のDBLinkにリバースLink機能がない場合、`0.0.0.0`と表示されます。MySQLモードでは、リバースLink機能は現在サポートされていません。
* `REVERSE_PORT`：リバースDBLinkがローカルデータベースに接続するためのポート番号。現在のDBLinkにリバースLink機能がない場合、`0`と表示されます。MySQLモードでは、リバースLink機能は現在サポートされていません。

`DBA_DB_LINKS`ビューのフィールドの詳細については、[DBA_DB_LINKS](../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/7700.dba_db_links.md)を参照してください。
