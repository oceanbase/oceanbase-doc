# 作成済みのDBLinkの確認

DBLinkを作成すると、ビューを通じて作成したDBLinkの情報を確認できます。これには、データベースリンクを作成したユーザー、データベースリンク名、リモートデータベースのIPアドレス、ポート番号などの情報が含まれます。

## 手順

DBLinkの作成が成功すると、`DBA_DB_LINKS` ビューで作成されたDBLinkを確認できます。

```sql
SELECT * FROM oceanbase.DBA_DB_LINKS;
```

クエリ結果は次のとおりです。

```sql
+--------+-----------+----------+-----------------+------------------+---------------------+---------------------+--------+----------------+-------+-----------+-------------+---------------+---------------------+--------------+----------------------+--------------+--------------+
| OWNER  | DB_LINK   | USERNAME | CREDENTIAL_NAME | CREDENTIAL_OWNER | HOST                | CREATED             | HIDDEN | SHARD_INTERNAL | VALID | INTRA_CDB | TENANT_NAME | DATABASE_NAME | REVERSE_TENANT_NAME | CLUSTER_NAME | REVERSE_CLUSTER_NAME | REVERSE_HOST | REVERSE_PORT |
+--------+-----------+----------+-----------------+------------------+---------------------+---------------------+--------+----------------+-------+-----------+-------------+---------------+---------------------+--------------+----------------------+--------------+--------------+
| PUBLIC | ob_dblink | test     |                 |                  | xx.xx.xx.xx:2881    | 2023-05-25 13:40:35 |        |                | YES   |           | mysql001    | mydb          |                     |              |                      | 0.0.0.0      |            0 |
+--------+-----------+----------+-----------------+------------------+---------------------+---------------------+--------+----------------+-------+-----------+-------------+---------------+---------------------+--------------+----------------------+--------------+--------------+
1 row in set
```

クエリ結果の一部のフィールドについて説明します：

* `OWNER`：DBLinkの所有者。現在すべてのDBLinkは`PUBLIC`であり、テナント範囲内のすべてのユーザーが使用できることを意味します。
* `DB_LINK`：作成されたDBLinkの名前。
* `USERNAME`：DBLinkがリモートデータベースに接続するために使用するユーザー名。
* `HOST`：DBLinkが接続するリモートデータベースのホスト名（IPアドレス）。
* `CREATED`：DBLinkの作成日時。
* `VALID`：DBLinkが使用可能かどうかを示すフラグです。互換性のためにのみ使用され、デフォルトは`YES`です。
* `TENANT_NAME`：DBLinkがリモートデータベースに接続するために使用するテナント名。
* `DATABASE_NAME`：DBLinkが接続するリモートデータベース名。
* `REVERSE_TENANT_NAME`：ローカルデータベースに接続するための逆DBLink接続用テナント名。MySQLモードは現在、逆リンク機能をサポートしていません。
* `CLUSTER_NAME`：DBLinkがリモートデータベースに接続するために使用するクラスタ名。
* `REVERSE_CLUSTER_NAME`：ローカルデータベースに接続するための逆DBLink接続用クラスタ名。MySQLモードは現在、逆リンク機能をサポートしていません。
* `REVERSE_HOST`：ローカルデータベースに接続するための逆DBLink接続用ホスト名（IPアドレス）。現在のDBLinkが逆リンク機能を持たない場合、`0.0.0.0` と表示されます。MySQLモードは現在、逆リンク機能をサポートしていません。
* `REVERSE_PORT`：ローカルデータベースに接続するための逆DBLink接続用ポート番号。現在のDBLinkが逆リンク機能を持たない場合、`0` と表示されます。MySQLモードは現在、逆リンク機能をサポートしていません。

`DBA_DB_LINKS` ビューのフィールドに関する詳細情報については、[oceanbase.DBA_DB_LINKS](../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/4400.o-dba_db_links-of-mysql-mode.md) を参照してください。
