# Catalogの確認

Catalogを作成した後、SQLステートメントを使用してその関連情報を確認できます。

## Catalog作成ステートメントの確認

`SHOW CREATE CATALOG external_catalog_name;` を使用してCatalogの作成ステートメントを確認できます。

**例：**

```shell
obclient> SHOW CREATE CATALOG test_odps_catalog;
```

## 現在のテナントのCatalogの確認

`SHOW CATALOGS;` を使用して現在のテナントのCatalogを確認できます。

**例：**

```shell
obclient> SHOW CATALOGS;
```

## Catalog内のデータの確認

Catalogでは、データベース内のテーブルと同様に任意のクエリ操作を実行でき、またCatalog間での結合クエリも可能です。

**例：**

```shell
obclient> SELECT * FROM internal.test.t1, odps_catalog.default.t1;
```

## Catalogの切り替え

`SET CATALOG catalog_name;` ステートメントを使用してCatalogを切り替えることができます。

`USE internal.test;` または `USE odps_catalog.default` を使用すると、Catalogとデータベースの切り替えを一度に完了できます。

**例：**

* システム内部Catalogに切り替える。

    ```shell
    obclient> SET CATALOG internal;
    ```

* 外部Catalogに切り替える。

    ```shell
    obclient> SET CATALOG external_catalog_name;
    ```
