# Catalogの削除

Catalogが不要になった場合、`DROP CATALOG [IF EXISTS] external_catalog_name;` ステートメントを使用して削除できます。

Catalogを削除する際に `IF EXISTS` を指定すると、削除対象のCatalogが存在しない場合でもエラーは報告されません。`IF EXISTS` を指定しない場合は、エラーが報告されます。

**例：**

```shell
obclient> DROP CATALOG IF EXISTS test_odps_catalog;
```
