# テーブルの削除

テーブルが不要になった場合、`DROP TABLE` ステートメントを使用して削除できます。

テーブルの削除例は以下のとおりです：

```sql
obclient> DROP TABLE test;
```

または

```sql
obclient> DROP TABLE IF EXISTS test;
```

テーブルを削除する際に `IF EXISTS` を指定した場合、削除対象のテーブルが存在しなくてもエラーは報告されません。`IF EXISTS` を指定しない場合は、エラーが報告されます。

`DROP TABLE` 操作について：

* テナントがゴミ箱機能を無効にしている場合、`DROP TABLE` 操作はテーブルの削除を意味します。

* テナントがゴミ箱機能を有効にしている場合、`DROP TABLE` 操作は削除されたテーブルがゴミ箱に移動することを意味します。ゴミ箱内のテーブルについては、後でゴミ箱機能を使用してさらに削除または復元できます。ゴミ箱関連の操作については、[ゴミ箱オブジェクトの復元](../../../../600.manage/400.high-availability/500.recyclebin-management/400.restore-the-recyclebin-objects.md)を参照してください。

* ゴミ箱の有効/無効はシステム変数 `recyclebin` によって制御され、デフォルトでは無効になっています。
