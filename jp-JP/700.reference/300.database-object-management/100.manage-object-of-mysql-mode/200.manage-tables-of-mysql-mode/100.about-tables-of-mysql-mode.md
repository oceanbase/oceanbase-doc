# テーブルについて

OceanBaseデータベースでは、テーブルは最も基本的なデータストレージユニットです。テーブルにはすべてのユーザーがアクセスできるデータが含まれており、各テーブルには複数の行があり、各行は複数の列で構成されています。

テーブルを作成して使用する前に、管理者はビジネスニーズに基づいて計画を立てることができます。主に以下の原則に従う必要があります：

* テーブルを規範的に使用し、テーブル構造を適切に見積もって、データの冗長性を最小限に抑える必要があります。

* テーブルの各列に適切なSQLデータ型を選択します。

  SQLデータ型の詳細については、[データ型](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/100.data-type-overview-of-mysql-mode.md)を参照してください。

* 実際のニーズに応じて、適切なタイプのテーブルを作成します。OceanBaseデータベースは現在、パーティションテーブルとパーティションテーブルをサポートしています。
