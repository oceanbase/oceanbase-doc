# テーブルの確認

テーブルの作成が完了した後、SQL文を使用してデータベース内のすべてのテーブルを確認することができます。また、指定されたテーブルの定義や構造なども確認できます。

## データベース内のテーブルを確認する

テーブルの作成が成功した後、`SHOW TABLES` ステートメントを使用してデータベース内のすべてのテーブルを確認できます。ステートメントは以下のとおりです：

```sql
SHOW [EXTENDED] [FULL] TABLES [{FROM | IN} database_name];
```

ステートメント内で：

* `EXTENDED`：隠れたテーブルを表示します。OceanBaseデータベースの現行バージョンでは隠れたテーブルが生成されないため、このパラメータには実際の効果はありません。

* `FULL`：テーブルタイプを表示します。

* `database_name`：照会対象のデータベース。

データベース `test` 内のすべてのテーブルを確認する例は次のとおりです：

```sql
SHOW TABLES FROM test;
```

クエリ結果は次のとおりです：

```shell
+----------------+
| Tables_in_test |
+----------------+
| t1             |
+----------------+
1 row in set
```

`SHOW TABLES` ステートメントの詳細については、[SHOW](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8700.show-of-mysql-mode.md)を参照してください。

## テーブルの定義を確認する

テーブル作成が完了した後、`SHOW CREATE TABLE` ステートメントを使用してテーブルの定義を確認できます。

テーブル `test` の定義を確認する例は以下のとおりです：

```sql
obclient [test]> SHOW CREATE TABLE test;
```

結果は次のとおりです：

```shell
+-------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Table | Create Table                                                                                                                                                                                                                                                  |
+-------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| test  | CREATE TABLE `test` (
  `id` int(11) DEFAULT NULL,
  `name` char(50) DEFAULT NULL
) DEFAULT CHARSET = utf8mb4 ROW_FORMAT = DYNAMIC COMPRESSION = 'zstd_1.3.8' REPLICA_NUM = 1 BLOCK_SIZE = 16384 USE_BLOOM_FILTER = FALSE TABLET_SIZE = 134217728 PCTFREE = 0 |
+-------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```

一部のフィールドの説明は以下のとおりです：

* `DEFAULT CHARSET = utf8mb4`：デフォルトの文字セットを `utf8mb4` に指定します。

* `ROW_FORMAT = DYNAMIC`：データエンコーディングを有効にすることを示します。

* `COMPRESSION`：テーブルの圧縮方式です。

* `PCTFREE`：このブロックデータを更新するために使用される空き容量を示します。

## テーブル構造の確認

テーブル作成後、`SHOW COLUMNS/FIELDS` ステートメントを使用してテーブル構造を確認できます。ステートメントは以下のとおりです：

```sql
SHOW [EXTENDED] [FULL] {COLUMNS | FIELDS}
    {FROM | IN} table_name
    [{FROM | IN} database_name];
```

ステートメント内で：

* `EXTENDED`：隠れた列を表示します。

* `FULL`：列の照合順序、権限、コメントを表示します。

* `table_name`：照会対象のテーブル。

* `database_name`：照会対象のテーブルが属するデータベース。

例：

* テーブル `test` のテーブル構造を確認します。

  ```sql
  obclient [test]> SHOW COLUMNS FROM test;
  ```

  クエリ結果は次のとおりです：

  ```shell
  +-------+----------+------+-----+---------+-------+
  | Field | Type     | Null | Key | Default | Extra |
  +-------+----------+------+-----+---------+-------+
  | id    | int(11)  | YES  |     | NULL    |       |
  | name  | char(50) | YES  |     | NULL    |       |
  +-------+----------+------+-----+---------+-------+
  2 rows in set
  ```

* テーブル `test` 内の隠れた列を含むすべての列を確認します。

  ```sql
  obclient [test]> SHOW EXTENDED COLUMNS FROM test;
  ```

  クエリ結果は次のとおりです：

  ```shell
  +----------------+-----------------+------+-----+---------+-------+
  | Field          | Type            | Null | Key | Default | Extra |
  +----------------+-----------------+------+-----+---------+-------+
  | id             | int(11)         | YES  |     | NULL    |       |
  | name           | char(50)        | YES  |     | NULL    |       |
  | __pk_increment | bigint unsigned | NO   | PRI | NULL    |       |
  +----------------+-----------------+------+-----+---------+-------+
  3 rows in set
  ```

`SHOW COLUMNS/FIELDS` ステートメントの詳細については、[SHOW](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8700.show-of-mysql-mode.md)を参照してください。

## テーブルのチェック

`CHECK TABLE` ステートメントを使用して、データベース内のテーブルが存在するかどうかを確認できます。

`CHECK TABLE` ステートメントの詳細については、[CHECK TABLE](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2050.check-table-of-mysql-mode.md)を参照してください。

**例：**

1. テーブル `tbl1` が存在しない場合、テーブル `tbl1` のチェック結果を確認します。

    ```shell
    obclient [test]> CHECK TABLE tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    +-----------+-------+----------+---------------------------------+
    | Table     | Op    | Msg_type | Msg_text                        |
    +-----------+-------+----------+---------------------------------+
    | test.tbl1 | check | Error    | Table 'test.tbl1' doesn't exist |
    | test.tbl1 | check | status   | Operation failed                |
    +-----------+-------+----------+---------------------------------+
    2 rows in set
    ```

2. テーブル `tbl1` を作成します。

    ```shell
    obclient [test]> CREATE TABLE tbl1(col1 INT, col2 VARCHAR(18));
    ```

3. 再度テーブル `tbl1` をチェックし、実行結果を確認します。

    ```shell
    obclient [test]> CHECK TABLE tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    +-----------+-------+----------+----------+
    | Table     | Op    | Msg_type | Msg_text |
    +-----------+-------+----------+----------+
    | test.tbl1 | check | status   | OK       |
    +-----------+-------+----------+----------+
    1 row in set
    ```
