# マテリアライズドビューのプロパティを変更する

本記事では、SQLステートメントを使用してマテリアライズドビューのプロパティを変更する方法について説明します。

## 権限要件

マテリアライズドビューを変更するには、現在のユーザーが対象オブジェクトに対する `ALTER` 権限を持っている必要があります。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

マテリアライズドビューを変更するSQLステートメントの形式は以下のとおりです：

```sql
ALTER MATERIALIZED VIEW [database.]view_name alter_mview_action_list;

alter_mview_action_list:
    alter_mview_action [, alter_mview_action ...]

alter_mview_action:
    parallel_clause
    | REFRESH [nested_refresh_option] [[START WITH expr] [NEXT expr]]

parallel_clause:
    NOPARALLEL
    | PARALLEL integer

nested_refresh_option:
    INDIVIDUAL
    | INCONSISTENT
    | CONSISTENT
```

## パラメータ説明

* `database.`：オプションです。マテリアライズドビューが存在するデータベースを指定します。`database.` を省略した場合、デフォルトでマテリアライズドビューは現在のセッションが接続しているデータベースに存在します。
* `view_name`：変更対象のマテリアライズドビューの名前を指定します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースでは、<code>RENAME TABLE</code> ステートメントを使用してマテリアライズドビューの名前を変更できます。</p>
  </main>

* `alter_mview_action_list`：マテリアライズドビューに対して実行できる変更操作のリストを表します。複数の操作を同時に指定することができ、英字のカンマ（`,`）で区切ります。

マテリアライズドビューを変更する構文の詳細なパラメータ説明については、[ALTER MATERIALIZED VIEW](../../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1250.alter-materialized-view-of-mysql-mode-in-sql.md)を参照してください。

## 例

1. テーブル `test_tbl1` を作成します。

    ```sql
    CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(20), col3 INT, col4 TEXT);
    ```

2. `mv_test_tbl1` という名前のマテリアライズドビューを作成します。

    ```sql
    CREATE MATERIALIZED VIEW mv_test_tbl1(c1, c2, c3, PRIMARY KEY(c1))
        AS SELECT col1, col2, col3
           FROM test_tbl1;
    ```

3. マテリアライズドビュー `mv_test_tbl1` の並列度を5に変更します。

    ```sql
    ALTER MATERIALIZED VIEW mv_test_tbl1 PARALLEL 5;
    ```

4. マテリアライズドビュー `mv_test_tbl1` の更新計画を変更し、初期更新日時を現在日付に設定し、その後1日ごとにマテリアライズドビューを更新します。

    ```sql
    ALTER MATERIALIZED VIEW mv_test_tbl1
        REFRESH START WITH sysdate() NEXT sysdate() + interval 1 DAY;
    ```

5. マテリアライズドビュー `mv_test_tbl1` を基に、`mv_mv_test_tbl1` という名前のネストされたマテリアライズドビューを作成し、更新戦略を `INDIVIDUAL` に設定します。

    ```sql
    CREATE MATERIALIZED VIEW mv_mv_test_tbl1
        REFRESH COMPLETE INDIVIDUAL
        AS SELECT c1, c2
           FROM mv_test_tbl1;
    ```

6. ネストされたマテリアライズドビュー `mv_mv_test_tbl1` の更新戦略を `INCONSISTENT` に変更します。

    ```sql
    ALTER MATERIALIZED VIEW mv_mv_test_tbl1
        REFRESH INCONSISTENT;
    ```
