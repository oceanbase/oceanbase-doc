# マテリアライズドビューの削除

## 注意事項

* マテリアライズドビューを単独で削除する場合、マテリアライズドビューはゴミ箱に移動しません。
* マテリアライズドビューのベーステーブルにマテリアライズドビューのログが作成されている場合、ベーステーブルを削除する前に、そのベーステーブル上のマテリアライズドビューのログを削除する必要があります。そうしないと、エラーが発生します。

## 権限要件

マテリアライズドビューを削除するには、`DROP TABLE` 権限が必要です。OceanBaseデータベースの権限の詳細については、[MySQLモードの権限分類](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)を参照してください。

## 構文

```sql
DROP MATERIALIZED VIEW [IF EXISTS] materialized_view_list [opt_drop_behavior];

materialized_view_list:
    [ database. ]materialized_view [,[ database. ]materialized_view]...

opt_drop_behavior:
    RESTRICT | CASCADE
```

## パラメータ説明

|       **パラメータ**    |       **説明**           |
|-------------------|--------------------------|
| IF EXISTS         | オプションです。`IF EXISTS` を指定した場合、削除対象のマテリアライズドビューが存在しなくてもエラーは報告されません。指定しない場合、削除対象のマテリアライズドビューが存在しないとエラーが発生します。 |
| database.         | オプションです。マテリアライズドビューが存在するデータベースを指定します。`database.` を省略した場合、デフォルトで自身のデータベース内になります。|
| materialized_view | マテリアライズドビューの名前を指定します。|
| RESTRICT \| CASCADE | オプションです。削除操作の動作を示します。<ul><li>CASCADE はデフォルト値で、マテリアライズドビューを削除すると同時に、それに依存する他のオブジェクトも削除します。</li><li>RESTRICT は、他のオブジェクトがそのマテリアライズドビューに依存している場合、マテリアライズドビューの削除を許可しません。</li></ul>|

## 例

以下では、マテリアライズドビューの作成、クエリ、削除の情報を示します。

1. ベーステーブルとして `test_tbl1` テーブルを作成します。

    ```sql
    CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(20), col3 INT);
    ```

2. `test_tbl1` テーブルに基づいて、`mv_test_tbl1` という名前のマテリアライズドビューを作成します。

    ```sql
    CREATE MATERIALIZED VIEW mv_test_tbl1(PRIMARY KEY (col1))
        AS SELECT col1, col2
           FROM test_tbl1;
    ```

3. マテリアライズドビュー `mv_test_tbl1` にマテリアライズドビューのログを作成します。

    ```sql
    CREATE MATERIALIZED VIEW LOG ON mv_test_tbl1
        WITH PRIMARY KEY (col2) INCLUDING NEW VALUES;
    ```

4. マテリアライズドビュー `mv_test_tbl1` に基づいて、マテリアライズドビュー（ネストされたマテリアライズドビュー） `mv_mv_test_tbl1` を作成します。

    ```sql
    CREATE MATERIALIZED VIEW mv_mv_test_tbl1
        AS SELECT col1
           FROM mv_test_tbl1;
    ```

5.  現在のすべてのマテリアライズドビュー情報を確認します。

    ```sql
    SELECT owner, mview_name, container_name, query, refresh_mode
    FROM oceanbase.DBA_MVIEWS;
    ```

    実行結果は次のとおりです：

    ```shell
    +---------+-----------------+-----------------+-----------------------------------------------------------------------------------------------------------------+--------------+
    | owner   | mview_name      | container_name  | query                                                                                                           | refresh_mode |
    +---------+-----------------+-----------------+-----------------------------------------------------------------------------------------------------------------+--------------+
    | db_test | mv_mv_test_tbl1 | mv_mv_test_tbl1 | select `mv_test_tbl1`.`col1` AS `col1` from `db_test`.`mv_test_tbl1` `mv_test_tbl1`                             | DEMAND       |
    | db_test | mv_test_tbl1    | mv_test_tbl1    | select `db_test`.`test_tbl1`.`col1` AS `col1`,`db_test`.`test_tbl1`.`col2` AS `col2` from `db_test`.`test_tbl1` | DEMAND       |
    +---------+-----------------+-----------------+-----------------------------------------------------------------------------------------------------------------+--------------+
    2 rows in set
    ```

6.  マテリアライズドビュー `mv_mv_test_tbl1` を削除します。

    ```sql
    DROP MATERIALIZED VIEW mv_mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

7.  マテリアライズドビュー `mv_test_tbl1` を削除します。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>マテリアライズドビューのベーステーブルにマテリアライズドビューのログが作成されている場合、ベーステーブルを削除する前に、まずベーステーブル上のマテリアライズドビューのログを削除する必要があります。そうでない場合、エラーが発生します。</p>
    </main>

    ```sql
    DROP MATERIALIZED VIEW mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    ERROR 1235 (0A000): drop table required by materialized view refresh is not supported
    ```

8.  マテリアライズドビュー `mv_test_tbl1` 上のマテリアライズドビューのログを削除します。

    ```sql
    DROP MATERIALIZED VIEW LOG ON mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

9.  マテリアライズドビュー `mv_test_tbl1` を再度削除します。

    ```sql
    DROP MATERIALIZED VIEW mv_test_tbl1;
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```
