# シーケンスの削除

`DROP SEQUENCE` ステートメントを使用してシーケンスを削除できます。

シーケンスを削除するSQL構文は次のとおりです：

```sql
DROP SEQUENCE [IF EXISTS] [database_name.]sequence_name;
```

ステートメントの使用方法：

* このステートメントを実行するユーザーには、`DROP` 権限が付与されている必要があります。

* `IF EXISTS` を指定した場合、削除対象のシーケンスが存在しなくてもエラーは報告されません。指定しない場合、システムはエラーを報告します。

* `database_name.` は、シーケンスが存在するデータベースを指定するために使用されます。`database_name.` を指定しない場合、現在ログインしているデータベースのシーケンスがデフォルトとなります。

シーケンス `S1` を削除する例は次のとおりです：

```sql
obclient> DROP SEQUENCE S1;
Query OK, 0 rows affected
```

`DROP SEQUENCE` ステートメントの詳細については、[DROP SEQUENCE](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/3900.drop-sequence-of-mysql-mode.md)を参照してください。
