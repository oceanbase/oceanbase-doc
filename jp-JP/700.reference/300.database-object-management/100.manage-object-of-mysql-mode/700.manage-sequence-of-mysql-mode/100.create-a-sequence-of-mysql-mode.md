# シーケンスの作成

OceanBaseデータベースにおいて、シーケンス（Sequence）とは、一定のルールに従ってデータベースが生成する自動インクリメント型の数値シーケンス番号であり、通常は間隔を置いた一連の数値（数値型）です。シーケンスは自動インクリメント特性を持つため、通常は主キーや一意キーとして使用されます。

`CREATE SEQUENCE` ステートメントを使用してシーケンスを作成できます。シーケンスには、現在のシーケンス値と次のシーケンス値を返すための2つの擬似列 `CURRVAL` と `NEXTVAL` が提供されます。`NEXTVAL` を照会するたびに、`CURRVAL` の値が進みます。

SQL構文は以下のとおりです：

```sql
CREATE SEQUENCE [IF NOT EXISTS] [database_name.]sequence_name
[MINVALUE int_value | NOMINVALUE]
[MAXVALUE int_value | NOMAXVALUE]
[START WITH int_value]
[INCREMENT BY int_value]
[CACHE int_value | NOCACHE]
[ORDER | NOORDER]
[CYCLE | NOCYCLE];
```

ステートメントの使用方法：

* このステートメントを実行するユーザーには `CREATE` 権限が付与されている必要があります。

* `IF NOT EXISTS`：オプション。作成対象のシーケンスが既に存在し、かつ `IF NOT EXISTS` が指定されていない場合、システムはエラーを報告します。

* `database_name.`：オプション。シーケンスが属するデータベースを指定するために使用されます。`database_name.` を指定しない場合、現在ログインしているデータベースのシーケンスが作成されます。

* `MINVALUE int_value | NOMINVALUE`：シーケンスの最小値を指定します。値の範囲は \[-10<sup>27</sup> \~ (10<sup>27</sup>-1)\] です。

  `NOMINVALUE` と指定した場合、昇順時の最小値は1、降順時の最小値は -(10<sup>27</sup>-1) となります。

  `MINVALUE` を指定しない場合、デフォルトは `NOMINVALUE` となります。

* `MAXVALUE int_value | NOMAXVALUE`：シーケンスの最大値を指定します。値の範囲は \[(-10<sup>27</sup>+1) \~ (10<sup>28</sup>-1)\] です。

  `NOMAXVALUE` と指定した場合、昇順時の最大値は `(10`<sup>28</sup>`-1)`、降順時の最大値は `-1` となります。

  `MAXVALUE` を指定しない場合、デフォルトは `NOMAXVALUE` となります。

* `START WITH`：シーケンスの開始値を指定します。この値は `MAXVALUE` 以下かつ `MINVALUE` 以上である必要があります。指定しない場合、昇順時のデフォルト値は最小値、降順時のデフォルト値は最大値となります。

* `INCREMENT BY`：シーケンスの自動インクリメントのステップサイズを指定します。この値は `0` にすることはできません。正の数を指定した場合、シーケンスは昇順になります。負の数を指定した場合、シーケンスは降順になります。指定しない場合、デフォルト値は `1` となります。

* `CACHE`：メモリ内に事前割り当てる自動インクリメント値の個数を指定します。デフォルトは `20` です。

* `ORDER | NOORDER`：シーケンスの値が順序立てて生成されるかどうかを指定します。`ORDER` は順序立てて生成されることを意味し、`NOORDER` は順序立てて生成されないことを意味します。デフォルトは `NOORDER` です。

* `CYCLE | NOCYCLE`：シーケンスの値が繰り返し生成されるかどうかを指定します。`CYCLE` は繰り返し生成されることを意味し、`NOCYCLE` は繰り返し生成されないことを意味します。デフォルトは `NOCYCLE` です。

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li><code>MINVALUE</code> と <code>MAXVALUE</code> を同時に指定する場合、<code>MINVALUE</code> は <code>MAXVALUE</code> より小さい必要があります。</li>
<li><code>MAXVALUE</code> と <code>MINVALUE</code> の差は <code>INCREMENT BY int_value</code> 以上である必要があります。</li>
<li><code>CACHE</code> の値は <code>1</code> より大きい必要があります。もし <code>CACHE INT_VALUE</code> の値が <code>1</code> の場合、<code>NOCACHE</code> と同等です。</li>
<li><code>CYCLE</code> を指定し、かつ <code>INCREMENT BY</code> の値が <code>0</code> より小さい場合、<code>MINVALUE</code> を指定する必要があります。</li>
<li><code>CYCLE</code> を指定した場合、<code>CACHE</code> の数は <code>CYCLE</code> を超えてはなりません。</li>
</ul>
</main>

シーケンス `seq1` を作成し、自動インクリメントのステップサイズを `2` と指定する例は以下のとおりです：

```sql
obclient> CREATE SEQUENCE seq1 START WITH 1 MINVALUE 1 MAXVALUE 10 INCREMENT BY 2 NOCYCLE NOORDER CACHE 30;
```
