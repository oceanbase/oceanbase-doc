# パーティションの追加

パーティションテーブルを作成した後、そのテーブルにパーティションを追加できます。

## パーティションテーブルにおけるパーティションの追加に対するサポート状況

OceanBaseデータベースのMySQLモードでは、パーティションテーブルとサブパーティションテーブルにおけるパーティションの追加に対するサポート状況は、次の表のとおりです。

|   パーティションテーブル   |      パーティションタイプ      | パーティションの追加 | サブパーティションの追加 |
|-----------|--------------------|-------------|-------------|
| パーティションテーブル | <ul><li>Range</li><li>Range Columns</li><li>List</li><li>List Columns</li></ul> | サポート | - |
| パーティションテーブル | <ul><li>Hash</li><li>Key</li></ul>| サポートなし | - |
| サブパーティションテーブル | <ul><li>Range + Range</li><li>Range + Range Columns</li><li>Range + List</li><li>Range + List Columns</li></ul> | サポート | サポート |
| サブパーティションテーブル | <ul><li>Range + Hash</li><li>Range + Key</li></ul> | サポート | サポートなし |
| サブパーティションテーブル | <ul><li>Range Columns + Range</li><li>Range Columns + Range Columns</li><li>Range Columns + List</li><li>Range Columns + List Columns</li></ul> | サポート | サポート |
| サブパーティションテーブル | <ul><li>Range Columns + Hash</li><li>Range Columns + Key</li></ul> | サポート | サポートなし |
| サブパーティションテーブル | <ul><li>List + Range</li><li>List + Range Columns</li><li>List + List</li><li>List + List Columns</li></ul> | サポート     | サポート |
| サブパーティションテーブル | <ul><li>List + Hash</li><li>List + Key</li></ul> | サポート     | サポートなし |
| サブパーティションテーブル | <ul><li>List Columns + Range</li><li>List Columns + Range Columns</li><li>List Columns + List</li><li>List Columns + List Columns</li></ul> | サポート | サポート |
| サブパーティションテーブル | <ul><li>List Columns + Hash</li><li>List Columns + Key</li></ul> | サポート | サポートなし |
| サブパーティションテーブル | <ul><li>Hash + Range</li><li>Hash + Range Columns</li><li>Hash + List</li><li>Hash + List Columns</li></ul> | サポートなし | サポート |
| サブパーティションテーブル | <ul><li>Hash + Hash</li><li>Hash + Key</li></ul> | サポートなし | サポートなし |
| サブパーティションテーブル | <ul><li>Key + Range</li><li>Key + Range Columns</li><li>Key + List</li><li>Key + List Columns</li></ul> | サポートなし | サポート |
| サブパーティションテーブル | <ul><li>Key + Hash</li><li>Key + Key</li></ul> | サポートなし | サポートなし |

## パーティションの追加

パーティションテーブル、テンプレート付きサブパーティションテーブル、非テンプレート付きサブパーティションテーブルにパーティションを追加できます。

### パーティションテーブルとテンプレート付きサブパーティションテーブルへのパーティションの追加

パーティションテーブルとテンプレート付きサブパーティションテーブルにパーティションを追加するSQL構文は以下のとおりです：

```sql
ALTER TABLE table_name ADD PARTITION (partition_option);

partition_option:
  {PARTITION partition_name VALUES LESS THAN range_partition_expr
     [,PARTITION partition_name VALUES LESS THAN range_partition_expr]... }
 |{PARTITION partition_name VALUES IN list_partition_expr
     [,PARTITION partition_name VALUES IN list_partition_expr]...}
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>
    <ul>
        <li>Range/Range Columnsパーティションでは、最大のパーティションの後にのみパーティションを追加でき、途中や開始位置には追加できません。現在のパーティションに<code>MAXVALUE</code>のパーティションが含まれている場合は、パーティションの追加を続けることはできません。</li>
        <li>List/List Columnsパーティションにパーティションを追加する場合、追加するパーティションが前のパーティションと競合しないことが条件です。List/List Columnsパーティションにデフォルトパーティション、すなわち<code>Default Partition</code>がある場合は、いかなるパーティションも追加できません。</li>
        <li>Range/Range Columns/List/List Columnsパーティションにパーティションを追加しても、グローバルインデックスとローカルインデックスの使用に影響しません。</li>
        <li>テンプレート付きサブパーティションテーブルにパーティションを追加する場合、パーティションの定義のみを指定する必要があります。対応するサブパーティションの定義は、テンプレートに従って自動的に埋め込まれます。
            <ul>
                <li>V4.4.2バージョンでは、V4.4.2 BP2バージョンから、テンプレート付きサブパーティションテーブルにパーティションを追加する際に、追加するパーティションに対応するサブパーティションの定義を指定することができるようになりました。これにより、テンプレートとカスタムサブパーティションのハイブリッド使用が可能になりました。</li>
            </ul>
        </li>
    </ul>
  </p>
</main>

一部の例は以下のとおりです：

* Rangeパーティションテーブル`tbl1_r`を作成し、パーティション`M202106`を追加します。

  ```sql
  obclient> CREATE TABLE tbl1_r (id INT NOT NULL,value varchar(50),time TIMESTAMP NOT NULL)
         PARTITION BY RANGE(UNIX_TIMESTAMP(time))
          (PARTITION M202101 VALUES LESS THAN(UNIX_TIMESTAMP('2021/02/01')),
           PARTITION M202102 VALUES LESS THAN(UNIX_TIMESTAMP('2021/03/01')),
           PARTITION M202103 VALUES LESS THAN(UNIX_TIMESTAMP('2021/04/01')),
           PARTITION M202104 VALUES LESS THAN(UNIX_TIMESTAMP('2021/05/01')),
           PARTITION M202105 VALUES LESS THAN(UNIX_TIMESTAMP('2021/06/01'))
          );
  Query OK, 0 rows affected

  obclient> ALTER TABLE tbl1_r ADD PARTITION
         (PARTITION M202106 VALUES LESS THAN(UNIX_TIMESTAMP('2021/07/01')));
  Query OK, 0 rows affected
  ```

* リストパーティションテーブル `tbl1_l` を作成し、パーティション `p2` と `p3` を追加します。

  ```sql
  obclient> CREATE TABLE tbl1_l (col1 INT PRIMARY KEY,col2 VARCHAR(50))
         PARTITION BY LIST(col1)
          (PARTITION p0 VALUES IN (1,2,3),
           PARTITION p1  VALUES IN (5,6)
          );
  Query OK, 0 rows affected

  obclient> ALTER TABLE tbl1_l ADD PARTITION
         (PARTITION p2 VALUES IN (7,8),
          PARTITION p3  VALUES IN (DEFAULT)
         );
  Query OK, 0 rows affected
  ```

* Range Columns + Range Columns パーティションのテンプレート型パーティションテーブル `t_m_rcrc` にパーティション `p3` と `p4` を追加します。

  ```sql
  obclient> CREATE TABLE t_m_rcrc(col1 INT,col2 INT)
         PARTITION BY RANGE COLUMNS(col1)
         SUBPARTITION BY RANGE COLUMNS(col2)
         SUBPARTITION TEMPLATE
          (SUBPARTITION mp0 VALUES LESS THAN(1000),
           SUBPARTITION mp1 VALUES LESS THAN(2000),
           SUBPARTITION mp2 VALUES LESS THAN(3000)
          )
          (PARTITION p0 VALUES LESS THAN(100),
           PARTITION p1 VALUES LESS THAN(200),
           PARTITION p2 VALUES LESS THAN(300)
          );
  Query OK, 0 rows affected

  obclient> ALTER TABLE t_m_rcrc ADD PARTITION
         (PARTITION p3 VALUES LESS THAN(400),
          PARTITION p4 VALUES LESS THAN(500)
         );
  Query OK, 0 rows affected
  ```

* Range + Range パーティションのテンプレート型パーティションテーブルを作成し、その後、パーティションにカスタムサブパーティションを追加します。

  1. 純粋なテンプレート型テーブル `st_rr` を作成します。

      ```shell
      obclient> CREATE TABLE st_rr (col1 INT, col2 INT)
          PARTITION BY RANGE(col1)
          SUBPARTITION BY RANGE(col2)
          SUBPARTITION TEMPLATE
              (SUBPARTITION mp1 VALUES LESS THAN(100),
              SUBPARTITION mp2 VALUES LESS THAN(200),
              SUBPARTITION mp3 VALUES LESS THAN(300)
              )
              (PARTITION p0 VALUES LESS THAN(2020),
              PARTITION p1 VALUES LESS THAN(2021),
              PARTITION p2 VALUES LESS THAN(2022)
              );
      ```

  2. テーブル `st_rr` にパーティションを追加し、サブパーティションを指定します。

      ```shell
      obclient> ALTER TABLE st_rr
          ADD PARTITION
              (PARTITION p3 VALUES LESS THAN(2026)
                  (SUBPARTITION p3sp0 VALUES LESS THAN(300),
                  SUBPARTITION p3sp1 VALUES LESS THAN(600))
              );
      ```

  3. テーブル `st_rr` の定義を確認します。

      ```shell
      obclient> SHOW CREATE TABLE st_rr;
      ```

      実行結果は次のとおりです：

      ```shell
      +-------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
      | Table | Create Table                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
      ```

### 非テンプレート型サブパーティションテーブルにパーティションを追加する

非テンプレート型サブパーティションテーブルにパーティションを追加するSQL構文は次のとおりです：

```sql
ALTER TABLE table_name ADD PARTITION (partition_option);

partition_option:
  {PARTITION partition_name VALUES LESS THAN range_partition_expr (subpartition_option)
     [,PARTITION partition_name VALUES LESS THAN range_partition_expr (subpartition_option)]... }
 |{PARTITION partition_name VALUES IN list_partition_expr (subpartition_option)
     [,PARTITION partition_name VALUES IN list_partition_expr (subpartition_option)]...}

subpartition_option：
  {SUBPARTITION subpartition_name VALUES LESS THAN range_partition_expr, ...}
 |{SUBPARTITION subpartition_name VALUES IN list_partition_expr, ....}
 |{SUBPARTITION subpartition_name, ....}
```

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p>テンプレート化されていないサブパーティションテーブルの場合、パーティションを追加する際には、そのパーティションの定義と、そのパーティションに含まれるサブパーティションの定義を同時に指定する必要があります。</p>
</main>

Range + Range型の非テンプレート化パーティションテーブル`t_f_rclc`にパーティション`p2`を追加する例を以下に示します。

```sql
obclient> CREATE TABLE t_f_rclc (col1 INT,col2 INT)
       PARTITION BY RANGE COLUMNS(col1)
       SUBPARTITION BY LIST COLUMNS(col2)
       (PARTITION p0 VALUES LESS THAN(100)
         (SUBPARTITION sp0 VALUES IN(1,3),
          SUBPARTITION sp1 VALUES IN(4,6),
          SUBPARTITION sp2 VALUES IN(7,9)),
        PARTITION p1 VALUES LESS THAN(200)
         (SUBPARTITION sp3 VALUES IN(1,3),
          SUBPARTITION sp4 VALUES IN(4,6),
          SUBPARTITION sp5 VALUES IN(7,9))
       );

obclient> ALTER TABLE t_f_rclc ADD PARTITION
       (PARTITION p2 VALUES LESS THAN(300)
         (SUBPARTITION sp6 VALUES IN(1,3),
          SUBPARTITION sp7 VALUES IN(4,6),
          SUBPARTITION sp8 VALUES IN(7,9))
       );
Query OK, 0 rows affected
```

## サブパーティションの追加

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><ul><li>HashまたはKeyタイプのサブパーティションを追加するシナリオはサポートされていません。</li><li>追加するサブパーティション名は、テーブル内の既存のパーティション名やサブパーティション名と重複してはなりません。</li><li>Rangeサブパーティションを追加する場合、Rangeの上限値は現在のパーティション内の最大サブパーティションの上限値より大きくする必要があります。複数のRangeサブパーティションを追加する場合、上限値は増分して並べる必要があります。つまり、上限値が大きいRangeサブパーティションを後方に配置します。</li><li>Listサブパーティションを追加する場合、現在のパーティション内の既存のサブパーティションの値と重複してはなりません。</li><li>複数のサブパーティションを追加する操作は原子的です。すべて成功するか、すべて失敗します。</li></ul></p>
</main>

### 構文

```sql
ALTER TABLE table_name MODIFY PARTITION partition_name
    ADD SUBPARTITION (subpartition_option);

subpartition_option:
    {SUBPARTITION subpartition_name VALUES LESS THAN range_partition_expr
        [, SUBPARTITION subpartition_name VALUES LESS THAN range_partition_expr] ...}
    | {SUBPARTITION subpartition_name VALUES IN list_partition_expr
        [, SUBPARTITION subpartition_name VALUES IN list_partition_expr] ...}
```

### パラメータの説明

|         パラメータ         |   説明    |
|----------------------|----------|
| table_name           | テーブル名を指定します。|
| partition_name       | 追加するサブパーティションが属するパーティション名を指定します。|
| subpartition_name    | 追加するサブパーティション名を指定します。|
| subpartition_option  | 新規サブパーティションの定義を表します。|
| range_partition_expr | Range/Range Columnsパーティション式を表します。|
| list_partition_expr  | List/List Columnsパーティション式を表します。|

### 例

* Range + Rangeテンプレートパーティションテーブルにサブパーティションテーブルを追加します。

  1. Range + Rangeパーティションのテンプレートサブパーティションテーブル `tbl1_m_rr` を作成します。

      ```sql
      CREATE TABLE tbl1_m_rr (col1 INT, col2 INT, col3 INT)
          PARTITION BY RANGE(col1)
             SUBPARTITION BY RANGE(col2)
             SUBPARTITION TEMPLATE
             (SUBPARTITION p0 VALUES LESS THAN (1000),
              SUBPARTITION p1 VALUES LESS THAN (2000))
          (PARTITION p0 VALUES LESS THAN (100),
           PARTITION p1 VALUES LESS THAN (200));
      ```

  2. テーブル `tbl1_m_rr` のパーティション `p1` にサブパーティション `p1sp2` を追加します。

      ```sql
      ALTER TABLE tbl1_m_rr MODIFY PARTITION p1
          ADD SUBPARTITION (SUBPARTITION p1sp2 VALUES LESS THAN (3000));
      ```

* Range + Range非テンプレートパーティションテーブルにサブパーティションテーブルを追加します。

  1. Range + Rangeパーティションの非テンプレートサブパーティションテーブル `tbl2_f_rr` を作成します。

      ```sql
      CREATE TABLE tbl2_f_rr(col1 INT, col2 INT)
          PARTITION BY RANGE(col1)
              SUBPARTITION BY RANGE(col2)
          (PARTITION p0 VALUES LESS THAN(100)
             (SUBPARTITION sp0 VALUES LESS THAN(2020),
              SUBPARTITION sp1 VALUES LESS THAN(2021)
              ),
           PARTITION p1 VALUES LESS THAN(200)
             (SUBPARTITION sp2 VALUES LESS THAN(2020),
              SUBPARTITION sp3 VALUES LESS THAN(2021),
              SUBPARTITION sp4 VALUES LESS THAN(2022)
              )
           );
      ```

  2. テーブル `tbl2_f_rr` のパーティション `p1` にサブパーティション `sp5` と `sp6` を追加します。

      ```sql
      ALTER TABLE tbl2_f_rr MODIFY PARTITION p1
          ADD SUBPARTITION
             (SUBPARTITION sp5 VALUES LESS THAN(2023),
              SUBPARTITION sp6 VALUES LESS THAN(2024));
      ```
