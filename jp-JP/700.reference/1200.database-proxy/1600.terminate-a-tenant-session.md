# テナントセッションの終了

OceanBaseデータベースでは、`KILL` ステートメントを使用してセッションを終了できます。

セッションを終了するSQLステートメントは以下のとおりです：

```sql
KILL [CONNECTION] 'session_id';
```

ステートメントの使用方法：

* `KILL` ステートメントは一度に1つのセッションしか終了できません。

* `PROCESS` 権限がある場合、すべてのセッションを確認できます。`SUPER` 権限がある場合、すべてのセッションとステートメントを個別に終了できます。それ以外の場合、自身のセッションとステートメントのみを確認および終了できます。管理者はすべてのセッションとステートメントを個別に終了できます。

指定されたセッションを終了する例は次のとおりです：

```sql
KILL session_id;
```

または

```sql
KILL CONNECTION session_id;
```

ここで、`session_id` とはセッションIDであり、`SHOW PROCESSLIST` ステートメントまたは `SHOW FULL PROCESSLIST` ステートメントを使用して取得できます。セッションIDの取得方法の詳細については、[テナントセッションの確認](../1200.database-proxy/1500.view-tenant-sessions.md)を参照してください。

`KILL` ステートメントのその他の使用方法と説明については、[KILL(MySQLモード)](../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5800.kill-of-mysql-mode.md)および[KILL(Oracleモード)](../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/300.dcl-of-oracle-mode/1800.kill-of-oracle-mode.md)を参照してください。
