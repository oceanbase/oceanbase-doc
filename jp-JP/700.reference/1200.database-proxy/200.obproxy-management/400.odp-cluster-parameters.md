# OBProxyパラメータ説明

OBProxyクラスタを作成する際、パラメータ設定で起動パラメータを構成できます。本記事では、OBProxy起動に関連するパラメータの説明を紹介します。

## 起動パラメータ

OBProxyクラスタを作成する際、以下の説明を参考に起動パラメータを構成してください。設定しない場合、システムはデフォルト値でOBProxyを作成します。

|             パラメータ名              |         デフォルト値         |            値の範囲             |     説明      |
|------------------------------|---------------------|-----------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| app_name        | dropship            | -              | OBProxyサービスのアプリケーション名。            |
| automatic_match_work_thread  | true                | <ul><li>true</li> <li>false</li></ul>       | CPUコア数に応じてワーカースレッドを自動的に作成するかどうかを判断します。このオプションがtrueの場合、上限はwork_thread_numです。            |
| block_thread_num             | 1      | \[1, 4\]       | OBProxyブロッキングタスクのスレッド数で、スレッドの初期化に使用されます。             |
| enable_cpu_topology          | false               | <ul><li>true</li> <li>false</li></ul>       | CPUアフィニティを有効にするかどうか、つまり各ワーカースレッドを異なるCPUにバインドするかどうかを示します。          |
| enable_metadb_used           | false               | <ul><li>true</li> <li>false</li></ul>       | OBProxy実行時にOCPのMetaDBにアクセスできるかどうかを示します。        |
| enable_strict_kernel_release | false               | <ul><li>true</li> <li>false</li></ul>       | OS kernelの検証が必要かどうかを示します。 </br>値の範囲： <ul><li>true：5u/6u/7u仕様のRedHat OSのみ検証をサポートします。</li> <li>false：OS kernelを検証しませんが、Proxyは不安定になる可能性があります。</li></ul>    |
| frequent_accept              | true                | <ul><li>true</li> <li>false</li></ul>       | net acceptパラメータを初期化するかどうかを示します。     |
| grpc_client_num              | 9      | \[9,16\]       | grpcクライアント数。               |
| grpc_thread_num              | 8      | \[8,16\]       | grpcスレッド数。                |
| listen_port     | 2883                | (1024, 65536)               | OBProxyのリスニングポート。           |
| local_bound_ip               | 0.0.0.0             | -              | OBProxyのローカルIP。          |
| net_accept_threads           | 2      | \[0, 8\]       | acceptを実行するスレッド数。          |
| obproxy_config_server_url    | -      | -              | OCP対外のconfigurlサービスアドレス。               |
| prometheus_cost_ms_unit      | false               | <ul><li>true</li> <li>false</li></ul>       | prometheusのコスト単位をミリ秒に許可するかどうかを示します。デフォルトはマイクロ秒です。       |
| prometheus_listen_port       | 2884                | (1024, 65536)               | OBProxy prometheusリスニングポート。              |
| proxy_id        | 0      | \[0,255\]      | OBProxyのIDで、各OBProxyを識別するために使用されます。proxy_service_modeがserverに設定されている場合、proxy_idを0に設定することはできません。          |
| proxy_service_mode           | client              | <ul><li>client</li> <li>server</li></ul>    | OBProxyのデプロイメントおよびサービスモードを示します。        |
| rootservice_cluster_name     | -      | -              | Root Serviceリストのデフォルトクラスタ名を示します。                 |
| rootservice_list             | xx.xx.xx.xx:2881 | -              | Root Serviceリスト。形式はip1:sql_port1;ip2:sql_port2              |
| skip_proxy_sys_private_check | true                | <ul><li>true</li> <li>false</li></ul>       | OBProxyのプライベートネットワークセグメントでのチェックをスキップするかどうかを示します。                |
| stack_size      | 1MB                 | \[1MB, 10MB\]               | スレッドスタックサイズで、スレッドの作成に使用されます。            |
| enable_proxy_scramble        | true                | <ul><li>true</li> <li>false</li></ul>      | OBProxyのチャレンジランダムナンバーを有効にするかどうかを示します。     |
| task_thread_num              | 2      | \[1, 4\]       | OBProxyタスクスレッド数。           |
| work_thread_num              | 128                 | \[1, 128\]     | OBProxyワーカースレッド数。 automatic_match_work_threadがtrueの場合、最大ワーカースレッド数を示します。           |

## 関連情報

OBProxyのパラメータは起動パラメータとその他のパラメータに分かれています。その他のパラメータの詳細については、[パラメータの設定](https://en.oceanbase.com/docs/enterprise-odp-enterprise-en-10000000000841253)を参照してください。
