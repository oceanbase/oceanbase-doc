# OBProxyのアップグレード

OBProxyに新しいバージョンがリリースされた場合、OCP上で単一または複数のOBProxyをアップグレードできます。

## 前提条件

現在OCPにログインしているユーザーが、対象OBProxyの管理権限を持っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスターリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. 以下の操作を実行します：

   * **OBProxyリスト** で、アップグレード対象のOBProxyを見つけ、対応する **操作** 列の **アップグレード** をクリックし、アップグレード用バージョンパッケージを選択またはアップロードして **OK** をクリックすると、単一のOBProxyをアップグレードできます。

      <!-- ![単一ODPのアップグレード](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/update-an-odp.png) -->

   * **OBProxyリスト** で、複数のOBProxyを選択し、リストの右上で **一括アップグレード** をクリックして、アップグレード用バージョンパッケージを選択またはアップロードし、**OK** をクリックすると、複数のOBProxyをアップグレードできます。

      <!-- ![一括アップグレード](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odps.png) -->

5. ポップアップウィンドウで **アップグレードバージョン** を選択します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7%E5%8D%95%E4%B8%AAobproxy1.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>アップグレード先のソフトウェアパッケージのバージョンは、現在のOBProxyバージョンより高く、かつパッケージのハードウェアアーキテクチャは現在のホストのハードウェアアーキテクチャと一致している必要があります。</p>
   </main>

6. **OK** をクリックしてアップグレードを完了します。

   ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、進捗状況を確認できます。

   タスクの状態が **完了** になり、かつクラスタの **概要** ページの **OBProxyリスト** におけるそのOBProxyの状態が **実行中** になっていれば、アップグレードは成功です。

## 関連情報
