# OBProxyのアップグレード

OBProxyの新しいバージョンがリリースされた場合、OCP上で単一または複数のOBProxyをアップグレードできます。

## 前提条件

現在ログインしているOCPユーザーに、そのOBProxyの管理権限が付与されていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスターリストから対象のOBProxyクラスターを選択し、OBProxyクラスターの **概要** ページに移動します。

4. 以下の手順を実行します：

   * **OBProxyリスト** で、アップグレード対象のOBProxyを見つけ、対応する **操作** 列で **アップグレード** をクリックし、アップグレード用のバージョンパッケージを選択またはアップロードし、**OK** をクリックすると、単一のOBProxyをアップグレードできます。

      <!-- ![単一ODPのアップグレード](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/update-an-odp.png) -->

   * **OBProxyリスト** で複数のOBProxyを選択し、リストの右上で **一括アップグレード** をクリックし、アップグレード用のバージョンパッケージを選択またはアップロードし、**OK** をクリックすると、複数のOBProxyをアップグレードできます。

      <!-- ![一括アップグレード](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odps.png) -->

5. ポップアップウィンドウで **アップグレードバージョン** を選択します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7%E5%8D%95%E4%B8%AAobproxy1.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>アップグレード先のソフトウェアパッケージバージョンは、現在のOBProxyバージョンよりも高く、かつソフトウェアパッケージのハードウェアアーキテクチャが現在のホストのハードウェアアーキテクチャとマッチしている必要があります。</p>
   </main>

6. **OK** をクリックしてアップグレードを完了します。

   ポップアップウィンドウの **タスクの表示** ボタンを使用して、進捗状況を確認できます。

   このタスクのステータスが **完了** であり、クラスターの **概要** ページの **OBProxyリスト** における該当OBProxyのステータスが **実行中** の場合、アップグレードは成功したことを意味します。

## 関連情報
