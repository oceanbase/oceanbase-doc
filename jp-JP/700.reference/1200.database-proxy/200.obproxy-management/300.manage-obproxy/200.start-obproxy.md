# OBProxyの起動

OBProxyが正常にデプロイされた後、コマンドを使用して個々のobproxyプロセスを起動できます。

## 前提条件

OBProxyがデプロイ済みであることを確認してください。OBProxyのデプロイ手順については、[OBProxyのデプロイ](../../../../400.deploy/300.deploy-oceanbase-enterprise-edition/400.deploy-through-the-command-line/300.deploy-obproxy-command-line.md)を参照してください。

## 背景

obproxyプロセスを起動するには、以下の2つの方法がサポートされています：

* 起動コマンドに`-r`パラメータを指定して、OceanBaseクラスタのRootServer情報を指定します。この起動方法は追加の設定が不要であり、一般的に開発デバッグ段階で使用されます。

* 起動コマンドに`obproxy_config_server_url`パラメータを指定して、OceanBaseクラスタのRootServer情報を照会取得します。この方法では`obproxy_config_server_url`の設定が必要なため、Config Serverの起動に依存します。そのため、この方法でOBProxyを起動することを推奨します。

## 手順

1. adminユーザーで、起動するOBProxyが存在するマシンにログインします。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>OBServersを起動する際は、adminユーザーでログインし、OBProxyソフトウェアのホームディレクトリで起動コマンドを実行してください。他のユーザーまたは他のディレクトリからOBServersを起動すると問題が発生する可能性があります。</p>
   </main>

2. OBProxyのインストールディレクトリに移動します。

3. 以下のコマンドを実行して、OBProxyを起動します。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>OBServersを起動する前に、<code>./bin/obproxy -h</code> コマンドを使用して、OBServers起動関連のパラメータを確認できます。</p>
   </main>

   * 起動コマンドに `-r` パラメータを指定します

      コマンドは次のとおりです：

      ```shell
      $./bin/obproxy -p6789 -r'ip:port' -e -n appname -o obproxy_config_server_url='' -c cluster_name
      ```

      パラメータの説明：

      * `-p` OBProxyがリスニングするポート番号を指定します。クライアントはMySQL経由でこのポートに接続し、OceanBaseデータベースにアクセスします。このパラメータは初回起動時にのみ指定する必要があり、その後の通常の起動やアップグレードなどでは追加する必要はありません。

      * `-r'ip:port'`：指定されたOceanBaseクラスタのRoot Server情報、IPアドレスとポート番号を含みます。このPortはOBServerノードのSQL Portを指し、RPC Portではありません。

      * `-e` テーブル作成操作を指定するために使用され、初回のOBServers起動時にのみ実行することを推奨します。その後の通常の起動やアップグレードなどでは、このパラメータを追加する必要はありません。

      * `-n` (オプション)：起動するOBServersのアプリケーション名を指定します。

         OBServersのアプリケーション名は、`app_name`構成パラメータを使用して変更でき、デフォルトは`undefined`です。

      * `-o` ハードウェアまたはカーネルパラメータ設定を指定するために使用されます。指定しない場合は、システムのデフォルト設定が使用されます。

         `obproxy_config_server_url=''` Config Serverなしで起動することを意味します。

      * `-c cluster_name` OceanBaseクラスタを指定するために使用されます。

      例：

      ```shell
      $./bin/obproxy -r'10.10.10.1:26506;10.10.10.2:26506' -n test -c mycluster
      ```

   * 起動コマンドに `obproxy_config_server_url` パラメータを指定します

      コマンドは次のとおりです：

      ```shell
      $./bin/obproxy -p6789 -e -n appname -o obproxy_config_server_url='your_config_url'
      ```

      その中で：

      * `-p` OBProxyがリスニングするポート番号を指定します。クライアントはMySQL経由でこのポートに接続し、OceanBaseデータベースにアクセスします。このパラメータは初回起動時にのみ指定する必要があり、その後の通常の起動やアップグレードなどでは追加する必要はありません。

      * `-e` テーブル作成操作を指定するために使用され、初回のOBServers起動時にのみ実行することを推奨します。その後の通常の起動やアップグレードなどでは、このパラメータを追加する必要はありません。

      * `-n`：アプリケーション名を指定します。

         OBServersのアプリケーション名は、`app_name`構成パラメータを使用して変更でき、デフォルトは`undefined`です。

      * `-o` ハードウェアまたはカーネルパラメータ設定を指定するために使用されます。指定しない場合は、システムのデフォルト設定が使用されます。

      * `obproxy_config_server_url` Config Serverへのアクセスアドレスを指定します。

      例：

      ```shell
      $./bin/obproxy -n test -o obproxy_config_server_url='http://xx.xx.xx.xx:8877/obproxy_config'
      ```

4. 起動後、以下のコマンドを実行して、obproxyプロセスが存在するかどうかを確認します。

   ```shell
   $ps -ef|grep obproxy
   ```
