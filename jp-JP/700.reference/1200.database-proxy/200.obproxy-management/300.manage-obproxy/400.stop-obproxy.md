# OBProxyの停止

OBProxyが正常にデプロイされると、デフォルトでプロセスは起動状態になります。コマンドを使用して個々のobproxyプロセスを停止できます。

## obproxyプロセスの停止

1. adminユーザーで、obproxyプロセスが存在するマシンにログインします。

2. 以下のコマンドを実行し、obproxyプロセスのプロセス番号を確認します。

   ```shell
   $ps -ef|grep obproxy
   admin     37360      0  6 11:35 ?        00:00:09 bin/obproxy
   admin     43055  36750  0 11:37 pts/10   00:00:00 grep --color=auto obproxy
   root      85623      1  0 Jun02 ?        00:15:19 /home/admin/ocp_agent/obagent/obstat2 -o http://xx.xx.xx.xx:81 -c test323 __obproxy__ -f 20
   ```

   obproxyのプロセス番号は37360です。

3. 以下のコマンドを実行し、確認したプロセス番号に基づいてobproxyプロセスを停止します。

   ```shell
   $kill -9 37360
   ```

4. 停止が成功したら、再度以下のコマンドを実行し、obproxyプロセスが存在しないことを確認します。

   ```shell
   $ps -ef|grep obproxy
   admin     45795  36750  0 11:39 pts/10   00:00:00 grep --color=auto obproxy
   root      85623      1  0 Jun02 ?        00:15:19 /home/admin/ocp_agent/obagent/obstat2 -o http://xx.xx.xx.xx:81 -c test323 __obproxy__ -f 20
   ```
