# OBProxyの再起動

本記事では、OBProxyを再起動する方法について説明します。

## コマンドによる単一OBProxyの再起動

OBProxyに異常が発生した場合、コマンドを使用して単一のobproxyプロセスを再起動できます。

具体的な操作は以下のとおりです：

1. adminユーザーでOBProxyが稼働しているマシンにログインします。

2. obproxyプロセスを停止します。

   obproxyプロセスを停止する具体的な操作については、[OBProxyの停止](../300.manage-obproxy/400.stop-obproxy.md)を参照してください。

3. obproxyプロセスを起動します。

   obproxyプロセスを起動する具体的な操作については、[OBProxyの起動](../300.manage-obproxy/200.start-obproxy.md)を参照してください。
