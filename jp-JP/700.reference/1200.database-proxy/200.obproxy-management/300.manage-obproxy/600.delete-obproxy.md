# OBProxyの削除

本記事では、OCP上で不要になったOBProxyを削除する方法について説明します。業務ニーズに応じて、単一または複数のOBProxyを削除できます。

## 前提条件

該当するOBProxyに業務接続がないことを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. 以下の手順を実行します：

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p><ul>
   <li>削除するOBProxyがOBProxyクラスタの最後のOBProxyの場合、削除後はアプリケーションが対応するデータベースに接続できなくなります。慎重に操作してください。</li>
   <li>OBProxyを削除すると、ロードバランシングポリシー設定から削除され、所属するアプリケーションに影響が出ます。</li>
   </ul></p>
   </main>

   * **OBProxyリスト** から削除するOBProxyを見つけ、対応する **操作** 列で ... アイコンをクリックし、**削除** を選択します。表示されるダイアログボックスで再度 **削除** をクリックすると、単一のOBProxyを削除できます。

      <!-- ![OBProxyの削除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-an-odp.png) -->

   * **OBProxyリスト** で複数のOBProxyを選択し、リストの右上で **...** アイコンをクリックして **一括削除** を選択します。表示されるダイアログボックスで再度 **削除** をクリックすると、複数のOBProxyを同時に削除できます。

      <!-- ![一括削除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odps.png) -->

5. ポップアップウィンドウで **削除** を選択します。

   ポップアップウィンドウの **タスクの表示** ボタンを使用して、削除の進捗状況を確認できます。

   タスクのステータスが **完了** であり、かつクラスタの **概要** ページの **OBProxyリスト** にそのOBProxyが表示されなくなった場合、削除は成功したことを意味します。
