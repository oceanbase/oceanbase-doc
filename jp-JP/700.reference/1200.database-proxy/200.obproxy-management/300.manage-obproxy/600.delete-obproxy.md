# OBProxyの削除

本記事では、OCP上で不要になったOBProxyを削除する方法について説明します。業務ニーズに応じて、単一または複数のOBProxyを削除できます。

## 前提条件

該当するOBProxyに業務接続がないことを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスターリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 以下の操作を実行します：

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p><ul>
   <li>削除するOBProxyがOBProxyクラスタの最後のOBProxyの場合、削除後はアプリケーションが対応するデータベースに接続できなくなります。慎重に操作してください。</li>
   <li>OBProxyを削除すると、そのOBProxyはロードバランシングポリシーの設定から除外され、所属するアプリケーションに影響を与えます。</li>
   </ul></p>
   </main>

   * **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** で、削除対象のOBProxyを見つけます。対応する **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">操作</UI-TERM>** 列の ... アイコンをクリックし、**<UI-TERM key="OMS.Audit.constants.Delete">削除</UI-TERM>** を選択します。ポップアップダイアログで再度 **<UI-TERM key="odc.Datasource.Info.Delete">削除</UI-TERM>** をクリックすると、単一のOBProxyを削除できます。

      <!-- ![OBProxyの削除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-an-odp.png) -->

   * **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** で、複数のOBProxyを選択します。リストの右上で **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.page.Package.BatchDelete">一括削除</UI-TERM>** を選択します。ポップアップダイアログで再度 **<UI-TERM key="oma-pro.ResourceLabel.DatabaseResource.Delete">削除</UI-TERM>** をクリックすると、複数のOBProxyを同時に削除できます。

      <!-- ![一括削除](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odps.png) -->

5. ポップアップダイアログで **<UI-TERM key="oat.Tool.DataX.Delete">削除</UI-TERM>** を選択します。

   ポップアップダイアログの **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、削除の進捗状況を確認できます。

   タスクの状態が **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow.Completed">完了しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.pages.Alarm.Overview">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** にそのOBProxyが表示されなくなったら、削除は成功です。

## 関連情報
