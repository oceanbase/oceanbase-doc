# OBProxyの追加

本記事では、OCPを使用して既存のOBProxyクラスタに新しいOBProxyを追加する方法について説明します。

## 前提条件

OBProxyクラスタが作成済みであること。OBProxyクラスタの作成手順については、[OBProxyクラスタの作成](../200.manage-obproxy-clusters/100.create-an-obproxy-cluster.md)を参照してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、そのOBProxyクラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.page.OBProxy.AddObproxy">OBProxyを追加する</UI-TERM>** をクリックします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp.png) -->

5. ポップアップウィンドウで、**<UI-TERM key="ocp-v2.Binlog.New.SoftwareVersion">ソフトウェアバージョン</UI-TERM>**、**<UI-TERM key="ocp-v2.OBProxy.New.SqlPort">SQLポート</UI-TERM>**、**Exporter**、**<UI-TERM key="ocp-v2.src.component.AddHostDrawer.ComputerRoom">データセンター</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.OBServerList.Models">機種</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.credential.Host">ホスト</UI-TERM>**などの情報を入力します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp2.png) -->

   情報入力時の参考として、次の表をご覧ください：

   |      パラメータ       |                         説明                         |
   |---------------|----------------------------------------------------|
   | SQLポート        | デフォルトは2883です。                                          |
   | Exporterポート   | デフォルトは2884です。                                          |
   | ソフトウェアバージョン          | インストールするOBProxyのバージョンを選択します。                                 |
   | データセンター、マシンタイプ(オプション)、ホスト | OBProxyのデプロイに使用するホストを選択します。ホストの **<UI-TERM key="ocp-v2.OBProxy.New.ComputerRoom">データセンター</UI-TERM>**、**マシンタイプ(オプション)**、**<UI-TERM key="src.page.Datasource.Datasource.components.DFD3CA9C">ホスト</UI-TERM>** が含まれます。 |

6. **<UI-TERM key="obcloud-business.CostUnit.ResourceTable.ResourceModals.Determine">確認</UI-TERM>** をクリックします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p><ul>
   <li>OBProxyクラスタがV4.0以降の場合、V4.0.0以降のソフトウェアパッケージのみを選択できます。</li><li>OBProxyクラスタがV3.x以下の場合、V1.8.0以上、V4.0.0未満のソフトウェアパッケージのみを選択できます。</li>
   <li>OBProxyクラスタ内にOBProxyが作成または引き継がれていない場合、OBProxyを追加する際にSQLポートとExporterポートをカスタマイズできます。OBProxyクラスタ内に既存のOBProxyが存在する場合、SQLポートとExporterポートは、OBProxyクラスタ作成時にデプロイされたOBProxyで設定されたポート番号をデフォルトで継承し、カスタマイズはサポートされません。</li>
   </ul></p>
   </main>
