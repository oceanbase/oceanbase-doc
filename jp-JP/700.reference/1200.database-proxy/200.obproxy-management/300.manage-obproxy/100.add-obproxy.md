# OBProxyの追加

本記事では、OCPを使用して既存のOBProxyクラスタに新しいOBProxyを追加する方法について説明します。

## 前提条件

OBProxyクラスタが作成済みであること。OBProxyクラスタの作成手順については、[OBProxyクラスタの作成](../200.manage-obproxy-clusters/100.create-an-obproxy-cluster.md)を参照してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタ一覧から操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. **OBProxyの追加** をクリックします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp.png) -->

5. ポップアップウィンドウで **ソフトウェアバージョン**、**SQLポート**、**Exporter**、**データセンター**、**マシンタイプ**、**ホスト** などの情報を入力します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp2.png) -->

   次の表を参考に情報を入力します：

   |      パラメータ       |                         説明                         |
   |---------------|----------------------------------------------------|
   | SQLポート        | デフォルトは2883です。                                          |
   | エクスポーターポート   | デフォルトは2884です。                                          |
   | ソフトウェアバージョン          | インストールするOBProxyのバージョンを選択します。                                 |
   | ラック、マシンタイプ（オプション）、ホスト | OBProxyをデプロイするために使用するホストを選択します。これには、そのホストの**ラック**、**マシンタイプ（オプション）**、**ホスト**が含まれます。 |

6. **OK** をクリックします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p><ul>
   <li>OBProxyクラスタがV4.0以降のバージョンの場合、V4.0.0以降のソフトウェアパッケージのみを選択できます。</li><li>OBProxyクラスタがV3.x以下のバージョンの場合、V1.8.0以降およびV4.0.0以下のソフトウェアパッケージのみを選択できます。</li>
   <li>OBProxyクラスタ内にOBProxyが作成または引き継がれていない場合、OBProxyを追加する際にSQLポートとExporterポートをカスタマイズできます。一方、OBProxyクラスタ内に既にOBProxyが存在する場合、SQLポートとExporterポートはデフォルトでOBProxyクラスタにOBProxyをデプロイした際に設定されたポート番号を継承し、カスタマイズはサポートされません。</li>
   </ul></p>
   </main>
