# OBProxyの追加

本記事では、OCPを使用して既存のOBProxyクラスタに新しいOBProxyを追加する方法について説明します。

## 前提条件

OBProxyクラスタが作成済みであること。OBProxyクラスタの作成手順については、[OBProxyクラスタの作成](../200.manage-obproxy-clusters/100.create-an-obproxy-cluster.md)を参照してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、そのOBProxyクラスタの **概要** ページに移動します。

4. **OBProxyの追加** をクリックします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp.png) -->

5. ポップアップウィンドウで、**ソフトウェアバージョン**、**SQLポート**、**Exporter**、**データセンター**、**マシンタイプ**、**ホスト**などの情報を入力します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp2.png) -->

   次の表を参考に情報を入力してください：

   |      パラメータ       |                         説明                         |
   |---------------|----------------------------------------------------|
   | SQLポート        | デフォルトは2883です。                                          |
   | Exporterポート   | デフォルトは2884です。                                          |
   | ソフトウェアバージョン          | インストールするOBProxyのバージョンを選択します。                                 |
   | データセンター、マシンタイプ(オプション)、ホスト | OBProxyをデプロイするために使用するホストを選択します。ホストの **データセンター**、**マシンタイプ(オプション)**、**ホスト** を指定します。 |

6. **OK** をクリックします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p><ul>
   <li>OBProxyクラスタがV4.0以降の場合、選択可能なソフトウェアパッケージはV4.0.0以降のみです。</li><li>OBProxyクラスタがV3.x以下の場合、選択可能なソフトウェアパッケージはV1.8.0以上、V4.0.0未満のみです。</li>
   <li>OBProxyクラスタ内にOBProxyが作成または引き継がれていない場合、OBProxyを追加する際にSQLポートとExporterポートをカスタマイズできます。OBProxyクラスタ内に既にOBProxyが存在する場合、SQLポートとExporterポートは、OBProxyクラスタ作成時にデプロイされたOBProxyで設定されたポート番号をデフォルトで継承し、カスタマイズはサポートされません。</li>
   </ul></p>
   </main>
