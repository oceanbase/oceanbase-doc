# OBProxyクラスタのすべてのOBProxyを再起動する

本記事では、OCP上でOBProxyクラスタのすべてのOBProxyを再起動する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーがOBPROXY_MANAGERロールであること。

## 注意事項

OBProxyの再起動により接続が切断される場合がありますので、ご注意ください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタ一覧から対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上隅にある **...** アイコンをクリックし、**すべて再起動** を選択します。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>OBProxyの再起動により接続が切断される場合がありますので、ご注意ください。</p>
   </main>

   <!-- ![restart-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで **再起動** をクリックします。

   ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、再起動の進捗状況を確認できます。

   このタスクのステータスが **完了** であり、かつクラスタの **概要** ページの **OBProxyリスト** においてすべてのOBProxyのステータスが **実行中** である場合、再起動は成功したことを意味します。
