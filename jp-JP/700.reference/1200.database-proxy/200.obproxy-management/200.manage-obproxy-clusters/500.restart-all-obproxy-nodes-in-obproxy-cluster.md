# OBProxyクラスタ内のすべてのOBProxyを再起動する

本記事では、OCP上でOBProxyクラスタ内のすべてのOBProxyを再起動する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーがOBPROXY_MANAGERロールであること。

## 注意事項

OBProxyを再起動すると接続が切断されます。慎重に操作してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**OBProxy**をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの**<UI-TERM key="obcloud-console.SubMenu.maas.menu.Overview">概要</UI-TERM>**ページに移動します。

4. ページの右上隅にある**...**アイコンをクリックし、**<UI-TERM key="ocp-v2.Detail.Overview.RestartAll">すべて再起動</UI-TERM>**を選択します。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>OBProxyを再起動すると接続が切断されます。慎重に操作してください。</p>
   </main>

   <!-- ![restart-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで**<UI-TERM key="ocp-v2.src.constant.backup.Restart">再起動</UI-TERM>**をクリックします。

   ポップアップウィンドウの**<UI-TERM key="oat.Tool.DataX.ResultSuccess.ViewTasks">タスクを確認する</UI-TERM>**ボタンをクリックすると、再起動の進捗状況を確認できます。

   このタスクの状態が**<UI-TERM key="oms-community.src.constants.Complete">完了</UI-TERM>**になり、かつクラスタの**<UI-TERM key="oceanbase-intl-business.en.Charge.DomesticBilling.Overview">概要</UI-TERM>**ページの**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>**にあるすべてのOBProxyの状態が**<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.Backup.utils.Running">実行中</UI-TERM>**になったら、再起動は成功です。
