# OBProxyクラスタ内のすべてのOBProxyを再起動する

本記事では、OCP上でOBProxyクラスタ内のすべてのOBProxyを再起動する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーがOBPROXY_MANAGERロールであること。

## 注意事項

OBProxyを再起動すると接続が切断されます。慎重に操作してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上隅にある **...** アイコンをクリックし、**すべて再起動** を選択します。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>OBProxyを再起動すると接続が切断されます。慎重に操作してください。</p>
   </main>

   <!-- ![restart-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで **再起動** をクリックします。

   ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、再起動の進捗状況を確認できます。

   このタスクの状態が **完了** になり、かつクラスタの **概要** ページの **OBProxyリスト** において、すべてのOBProxyの状態が **実行中** になっていれば、再起動は成功です。
