# OBProxyクラスタのパフォーマンス監視

本記事では、OCP上でOBProxyクラスタのパフォーマンス監視情報を確認する方法について説明します。サービス監視情報とシステム監視情報が含まれます。

## サービス監視

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **パフォーマンス監視** ページの **サービス監視** タブに移動します。

   * **サービス監視** タブでは、**直近5分間**、**直近10分間**、**直近20分間**、**直近30分間**、**直近1時間**、**直近3時間**、**直近6時間**、**直近12時間**、または **カスタム時間** の監視データを確認できます。

     <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/performance-aoto-refresh.png) -->

   * **自動更新** ボタンをクリックすると、システムは10秒ごとにデータを更新します。

4. **総覧** エリアでは、現在のOBProxyクラスタのパフォーマンス監視状況を確認できます。右上の **すべて表示** をクリックすると、**1秒あたりのトランザクション数**、**1秒あたりのリクエスト数**、**クライアント接続数**、**サーバー接続数**、**SQL応答時間の平均値**、**ルーティングテーブルの1秒あたりの平均クエリ回数**、**ネットワークリクエストまたは応答1回あたりの平均バイト数** の情報を確認できます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%95%B0%E6%8D%AE%E6%80%BB%E8%A7%881.png) -->

5. **接続されているOceanBaseクラスタデータ** エリアでは、現在のOBProxyクラスタとそれがプロキシしているOceanBaseクラスタ間の通信のパフォーマンス状況を確認します。

   各指標の最大値、最小値、平均値を確認できます。**列管理** をクリックして、表示する指標情報を選択します。

6. **OBProxy IPデータ** エリアでは、現在のOBProxyクラスタ内の各OBProxyノードのパフォーマンス状況を確認します。

   各指標の最大値、最小値、平均値を確認できます。**列管理** をクリックして、表示する指標情報を選択します。

## システム監視

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **パフォーマンス監視** ページの **システム監視** タブに移動します。

   **システム監視** タブでは、**直近5分間**、**直近10分間**、**直近20分間**、**直近30分間**、**直近1時間**、**直近3時間**、**直近6時間**、**直近12時間**、または **カスタム時間** の監視データを確認できます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/performance-aoto-refresh.png) -->

   **自動更新** ボタンをクリックすると、リアルタイムデータ更新を確認できます。

4. **総覧** セクションで、右上の **すべて表示** をクリックし、**Linux システム負荷**、**CPU使用率**、**I/O 使用率**、**I/O キュー長**、**平均 I/O 回数/秒**、**1回あたりの平均I/O所要時間**、**平均 I/O データ量/秒**、**ネットワークスループット**、**メモリ**、**ディスク使用率** の情報を確認します。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/system-monitor.png) -->

5. **OBProxy IP データ** セクションでは、現在の OBProxy クラスタ内の各 OBProxy ノードのパフォーマンス状況を確認できます。**列管理** をクリックして、表示する指標情報を選択します。

   <!-- ![014](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/obproxyIP%E6%95%B0%E6%8D%AE-1-1.png) -->
