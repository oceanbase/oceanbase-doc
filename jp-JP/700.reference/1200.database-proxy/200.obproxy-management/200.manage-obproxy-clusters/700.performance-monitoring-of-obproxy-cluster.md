# OBProxyクラスタのパフォーマンス監視

本記事では、OCP上でOBProxyクラスタのパフォーマンス監視情報を確認する方法について説明します。これには、サービス監視情報とシステム監視情報が含まれます。

## サービス監視

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスターリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **パフォーマンス監視** ページの **サービス監視** タブに移動します。

   * **サービス監視** タブでは、**過去5分**、**過去10分**、**過去20分**、**過去30分**、**過去1時間**、**過去3時間**、**過去6時間**、**過去12時間**、または **カスタム時間** 内の監視データを確認できます。

     <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/performance-aoto-refresh.png) -->

   * **自動更新** ボタンをクリックすると、システムが10秒ごとにデータを更新します。

4. **概要** エリアでは、現在のOBProxyクラスタのパフォーマンス監視状況を確認できます。右上の **すべて表示** をクリックして、**1秒あたりのトランザクション数**、**1秒あたりのリクエスト数**、**クライアント接続数**、**サーバー接続数**、**SQL応答時間の平均**、**1秒あたりのルーティングテーブルクエリ回数の平均**、**1回のネットワークリクエストまたは応答の平均バイト数** の情報を確認します。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%95%B0%E6%8D%AE%E6%80%BB%E8%A7%881.png) -->

5. **接続されているOceanBaseクラスタデータ** エリアでは、現在のOBProxyクラスタとそれがプロキシしているOceanBaseクラスタ間の相互接続性能状況を確認します。

   各指標の最大値、最小値、平均値を確認できます。**列の管理** をクリックして、表示する指標情報を選択します。

6. **OBProxy IPデータ** エリアでは、現在のOBProxyクラスタ内の各OBProxyノードの性能状況を確認します。

   各指標の最大値、最小値、平均値を確認できます。**列の管理** をクリックして、表示する指標情報を選択します。

## システム監視

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスターリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **パフォーマンス監視** ページの **システム監視** タブに移動します。

   **システム監視** タブでは、**過去5分**、**過去10分**、**過去20分**、**過去30分**、**過去1時間**、**過去3時間**、**過去6時間**、**過去12時間**、または **カスタム時間** 内の監視データを確認できます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/performance-aoto-refresh.png) -->

   **自動更新** ボタンをクリックすると、リアルタイムデータ更新を確認できます。

4. **概要** エリアで右上の **すべて表示** をクリックし、**Linuxシステム負荷**、**CPU使用率**、**I/O使用率**、**I/Oキュー長**、**1秒あたりのI/O回数の平均**、**1回のI/O処理時間の平均**、**1秒あたりのI/Oデータ量の平均**、**ネットワークスループット**、**メモリ**、**ディスク使用率** の情報を確認します。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/system-monitor.png) -->

5. **OBProxy IPデータ** エリアでは、現在のOBProxyクラスタ内の各OBProxyノードの性能状況を確認できます。**列の管理** をクリックして、表示する指標情報を選択します。

   <!-- ![014](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/obproxyIP%E6%95%B0%E6%8D%AE-1-1.png) -->
