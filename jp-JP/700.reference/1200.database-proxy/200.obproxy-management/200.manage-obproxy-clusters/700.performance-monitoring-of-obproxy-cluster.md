# OBProxyクラスタのパフォーマンス監視

本記事では、OCP上でOBProxyクラスタのパフォーマンス監視情報を確認する方法について説明します。サービス監視情報とシステム監視情報が含まれます。

## サービス監視

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Monitor.ServiceMonitoring">サービスモニタリング</UI-TERM>** タブに移動します。

   * **<UI-TERM key="ocp-v2.Detail.Monitor.ServiceMonitoring">サービスモニタリング</UI-TERM>** タブでは、**<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong">直近5分間</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.1">約10分間</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.2">約20分</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">約30分</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyHour">ほぼ1時間</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHours">約3時間</UI-TERM>**、**<UI-TERM key="oceanbase-intl-console.src.constants.NearlySixHours">過去6時間</UI-TERM>**、**<UI-TERM key="oms-v2.Operation.components.MetricChart.NearlyHours">直近12時間</UI-TERM>**、または **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">カスタム時間</UI-TERM>** の監視データを確認できます。

     <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/performance-aoto-refresh.png) -->

   * **<UI-TERM key="src.page.WorkBench.components.CreateMaterializedView.BaseInfo.87CFF5CB">自動更新</UI-TERM>** ボタンをクリックすると、システムは10秒ごとにデータを更新します。

4. **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** エリアでは、現在のOBProxyクラスタのパフォーマンス監視状況を確認できます。右上の **<UI-TERM key="ocp-v2.SQLDetail.DiagnosisDetail.ViewAll">すべてを見る</UI-TERM>** をクリックすると、**1秒あたりのトランザクション数**、**1秒あたりのリクエスト数**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ClientConnections">クライアント接続数</UI-TERM>**、**サーバー接続数**、**SQL応答時間の平均値**、**ルーティングテーブルの1秒あたりの平均クエリ回数**、**ネットワークリクエストまたは応答の1バイトあたりの平均数** の情報を確認できます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%95%B0%E6%8D%AE%E6%80%BB%E8%A7%881.png) -->

5. **接続されているOceanBaseクラスタデータ** エリアでは、現在のOBProxyクラスタとそれがプロキシしているOceanBaseクラスタ間の相互接続性能状況を確認します。

   各指標の最大値、最小値、平均値を確認できます。**<UI-TERM key="workspace.window.sql.button.columnFilter">リスト管理</UI-TERM>** をクリックして、表示する指標情報を選択します。

6. **OBProxy IPデータ** エリアでは、現在のOBProxyクラスタ内の各OBProxyノードのパフォーマンス状況を確認します。

   各指標の最大値、最小値、平均値を確認できます。**<UI-TERM key="ocp-v2.Component.filter.ColumnManagement">列管理</UI-TERM>** をクリックして、表示する指標情報を選択します。

## システム監視

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Monitor.SystemMonitoring">システム監視</UI-TERM>** タブに移動します。

   **<UI-TERM key="ocp-v2.Detail.Monitor.SystemMonitoring">システム監視</UI-TERM>** タブでは、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes">直近5分間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong.1">約10分間</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.2">約20分</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">約30分</UI-TERM>**、**<UI-TERM key="obcloud-console.space.memory.MemorySpaceDetailMemoryTab.NearlyHour">過去1時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyHours">3時間近く</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.1">約6時間</UI-TERM>**、**<UI-TERM key="oms-v2.Operation.components.MetricChart.NearlyHours">直近12時間</UI-TERM>**、または **<UI-TERM key="oms-cloud.src.components.ranger.customTime">カスタム時間</UI-TERM>** の監視データを確認できます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/performance-aoto-refresh.png) -->

   **<UI-TERM key="src.page.Workspace.components.MaterializedViewPage.MvViewPageBaseInfoForm.E5131CB2">自動更新</UI-TERM>** ボタンをクリックすると、リアルタイムデータ更新を確認できます。

4. **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** セクションで、右上の **<UI-TERM key="oceanbase-intl-console.components.PerformanceCharts.ViewAll">すべて表示</UI-TERM>** をクリックし、**Linux システム負荷**、**<UI-TERM key="ocp-v2.Compaction.Detail.CpuAndMemoryChart.CpuUsage">CPU使用率</UI-TERM>**、**I/O 使用率**、**I/O キュー長**、**平均 I/O 回数/秒**、**平均 I/O 消費時間/回**、**平均 I/O データ量/秒**、**ネットワークスループット**、**<UI-TERM key="oms-v2.components.SystemSource.Memory">メモリ</UI-TERM>**、**<UI-TERM key="oas.components.CapacityReport.DiskUsage">ディスク使用率</UI-TERM>** の情報を確認します。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/system-monitor.png) -->

5. **OBProxy IP データ** セクションでは、現在の OBProxy クラスタ内の各 OBProxy ノードのパフォーマンス状況を確認できます。**<UI-TERM key="workspace.window.sql.button.columnFilter">リスト管理</UI-TERM>** をクリックして、表示する指標情報を選択します。

   <!-- ![014](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/obproxyIP%E6%95%B0%E6%8D%AE-1-1.png) -->
