# OBProxyが接続するOceanBaseクラスタの管理

本記事では、OCPを使用してOBProxyに接続可能なOceanBaseクラスタを追加したり、既に接続されているOceanBaseクラスタを削除したりする方法について説明します。

## 接続可能なOceanBaseクラスタの追加

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタ一覧から操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上隅で、**接続可能なOBクラスタの追加** をクリックします。

5. 右側のポップアップウィンドウで、接続可能なOceanBaseクラスタを選択します。

   OceanBaseクラスタのProxyroパスワードとOBProxyクラスタのProxyroパスワードが一致している場合にのみ、Proxyroは対応するOceanBaseクラスタにアクセスできます。ProxyroアカウントのパスワードでOceanBaseクラスタに接続できない場合は、以下の2つの方法で解決できます：

   * OBProxyクラスタのProxyroパスワードを変更します。詳細な操作手順については、[Proxyroアカウントのパスワードの変更](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000002099346)を参照してください。

   * OceanBaseクラスタのproxyroユーザーのパスワードを変更します。詳細な操作手順については、[MySQLテナントユーザー管理](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000002100871)を参照してください。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E5%8F%AF%E8%BF%9E%E6%8E%A5ob%E9%9B%86%E7%BE%A41.png) -->

6. **OK** をクリックして、追加を完了します。

## 既に接続されているOceanBaseクラスタの削除

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OBProxyクラスタに接続されているOceanBaseクラスタを削除すると、現在のOBProxyクラスタのOBProxyはそのOceanBaseクラスタにアクセスできなくなります。削除する前に、OceanBaseクラスタが使用されなくなっていることを確認してください。</p>
</main>

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタ一覧から操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. **接続可能なOBクラスタ** 項目で、該当するクラスタの後ろにある **削除** をクリックします。

   <!-- ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6620460261/p271769.png) -->

5. ポップアップウィンドウで **OK** をクリックします。
