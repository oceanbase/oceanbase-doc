# OBProxyクラスタ内のすべてのOBProxyをアップグレードする

OBProxyに新しいバージョンがリリースされた場合、OCP上でOBProxyクラスタ内のすべてのOBProxyをアップグレードできます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上隅にある **...** アイコンをクリックし、**全てアップグレード** を選択します。

   <!-- ![update-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウでアップグレードバージョンを選択します。

   <!-- ![08161435](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7obproxy1.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>
    <p>現在の最高バージョンより高いソフトウェアパッケージのみを選択できます。</p>
    </li>
    <li>
    <p>複数のCPUアーキテクチャを持つOBProxyクラスタをアップグレードする際、特定の <b>CPUアーキテクチャ</b> で選択したインストールパッケージのバージョンが欠けている場合、アップグレードはできません。</p>
    </li>
    </ul>
   </main>

6. **OK** をクリックします。

   ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、アップグレードの進捗状況を確認できます。

   タスクの状態が **完了** であり、かつクラスタの **概要** ページの **OBProxyリスト** 内の各OBProxyの状態が **実行中** であれば、アップグレードは成功です。
