# OBProxyクラスタ内のすべてのOBProxyをアップグレードする

新しいバージョンのOBProxyがリリースされた場合、OCP上でOBProxyクラスタ内のすべてのOBProxyをアップグレードできます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタ一覧から対象となるOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上にある **...** アイコンをクリックし、**全てアップグレード** を選択します。

   <!-- ![update-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウでアップグレードするバージョンを選択します。

   <!-- ![08161435](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7obproxy1.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>
    <p>現在の最高バージョンよりも高いソフトウェアパッケージのみを選択できます。</p>
    </li>
    <li>
    <p>複数のCPUアーキテクチャを持つOBProxyクラスタをアップグレードする際、特定の <b>CPUアーキテクチャ</b> で選択したインストールパッケージのバージョンが不足している場合、アップグレードは実行できません。</p>
    </li>
    </ul>
   </main>

6. **OK** をクリックします。

   ポップアップウィンドウの **タスクを見る** ボタンをクリックすると、アップグレードの進捗状況を確認できます。

   このタスクのステータスが **完了** であり、かつクラスタの **概要** ページの **OBProxyリスト** 内の各OBProxyのステータスが **実行中** の場合、アップグレードは成功です。
