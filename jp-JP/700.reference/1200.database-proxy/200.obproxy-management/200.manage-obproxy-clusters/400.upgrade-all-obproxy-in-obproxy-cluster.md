# OBProxyクラスタ内のすべてのOBProxyをアップグレードする

OBProxyの新しいバージョンがリリースされた場合、OCP上でOBProxyクラスタ内のすべてのOBProxyをアップグレードできます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="oms-v2.Operation.Overview.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. ページの右上隅にある **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Detail.Overview.UpgradeAll">すべてのアップグレード</UI-TERM>** を選択します。

   <!-- ![update-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウでアップグレードバージョンを選択します。

   <!-- ![08161435](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7obproxy1.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>
    <p>現在の最高バージョンより高いソフトウェアパッケージのみを選択できます。</p>
    </li>
    <li>
    <p>複数のCPUアーキテクチャを持つOBProxyクラスタをアップグレードする際、特定の <b>CPUアーキテクチャ</b> で選択したインストールパッケージのバージョンが欠けている場合、アップグレードはできません。</p>
    </li>
    </ul>
   </main>

6. **<UI-TERM key="oms-v2.Migration.hooks.useMigrationParams.Determine">確定</UI-TERM>** をクリックします。

   ポップアップウィンドウの **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewTasks">タスクを表示</UI-TERM>** ボタンをクリックすると、アップグレードの進捗状況を確認できます。

   このタスクの状態が **<UI-TERM key="oms-community.components.ImportTransferObj.Complete">完了</UI-TERM>** であり、かつクラスタの **<UI-TERM key="oma-pro.OverView.components.CardNumber.Overview">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** 内の各OBProxyの状態が **<UI-TERM key="oms-community.Operator.constants.Running">実行中</UI-TERM>** の場合、アップグレードは成功です。
