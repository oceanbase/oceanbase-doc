# OBProxyクラスタパラメータ管理

本記事では、OCPを使用して、OBProxyクラスタのパラメータ管理ページで**パラメータリスト**と**変更履歴**を確認する方法について説明します。

## パラメータの確認または変更

1. OCPにログインします。

2. 左側のナビゲーションバーで**OBProxy**をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの**概要**ページに移動します。

4. 左側のナビゲーションバーで**パラメータ管理**をクリックすると、デフォルトで**パラメータリスト**タブが表示されます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/obproxy%E5%8F%82%E6%95%B0%E7%AE%A1%E7%90%86.png) -->

   このページでは、以下の操作を実行できます：

   * パラメータの確認

     検索ボックスにパラメータ名を入力し、検索ボタンをクリックすると、指定したパラメータ情報を確認できます。あいまい検索もサポートしています。

   * パラメータの変更

     1. 指定したパラメータの**操作**列の**値の変更**ボタンをクリックします。
     2. **値**を入力し、**OK**をクリックします。
     3. 対象パラメータの値の変更が完了したら、**変更の送信**をクリックします。
     4. ポップアップパネルで変更情報を確認し、**変更を確定**します。変更タスクの実行が完了すると、変更は成功です。

        パラメータの変更が完了した後、パラメータの**再起動が必要かどうか**の情報を確認することで、パラメータがどのように反映されるかを判断できます：

        * 再起動が不要なパラメータ：パラメータの変更が成功した後、約3分で反映されます。
        * 再起動が必要なパラメータ：OBProxyを再起動しないと反映されません。

## 変更履歴の確認

1. OCPにログインします。

2. 左側のナビゲーションバーで**OBProxy**をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの**概要**ページに移動します。

4. 左側のナビゲーションバーで**パラメータ管理**をクリックすると、デフォルトで**パラメータリスト**タブが表示されます。

5. **変更履歴**タブを選択します。

   **変更履歴**タブでは、**変更日**や**パラメータ名**に該当する情報を入力し、**検索**をクリックすることで、パラメータをフィルタリングできます。パラメータリストでは、**パラメータ名**、**値-変更前**（変更前のパラメータ値）、**値-変更後**（変更後のパラメータ値）、**変更時間**、**操作ユーザー**などの情報を確認できます。
