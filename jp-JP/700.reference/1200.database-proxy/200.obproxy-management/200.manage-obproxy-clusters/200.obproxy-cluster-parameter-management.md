# OBProxyクラスタパラメータ管理

本記事では、OCPを使用して、OBProxyクラスタのパラメータ管理ページで **パラメータリスト** と **変更履歴** を確認する方法について説明します。

## パラメータの確認または変更

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、そのOBProxyクラスタの **<UI-TERM key="obcloud-console.SubMenu.maas.menu.Overview">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="oceanbase-intl-console.MyComponents.MyMenu.tenantMenu.ParameterManagement">パラメータ</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">パラメータリスト</UI-TERM>** タブが表示されます。

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/obproxy%E5%8F%82%E6%95%B0%E7%AE%A1%E7%90%86.png) -->

   このページでは、以下の操作を実行できます：

   * パラメータの確認

     検索ボックスにパラメータ名を入力し、検索ボタンをクリックすると、指定したパラメータ情報を確認できます。あいまい検索もサポートしています。

   * パラメータの変更

     1. 指定したパラメータの **<UI-TERM key="obcloud-console.models.components.RateLimitTable.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">値を修正する</UI-TERM>** ボタンをクリックします。
     2. **<UI-TERM key="oas.SqlList.SearchInfo.SQLCondition.Value">値</UI-TERM>** を入力し、**<UI-TERM key="OMS.components.ViewObj.DelObject.Ok">確定</UI-TERM>** をクリックします。
     3. 対象パラメータの値の変更が完了したら、**<UI-TERM key="ocp-v2.Detail.Parameter.SubmitModification">修正を提出する</UI-TERM>** をクリックします。
     4. ポップアップパネルで変更情報を確認し、**<UI-TERM key="oceanbase-intl-console.ClusterParameter.ParameterSetDrawer.ConfirmModification">変更する</UI-TERM>** をクリックします。変更タスクの実行が完了すると、変更は成功です。

        パラメータの変更が完了した後、パラメータの **<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherToRestartEntryInto">再起動して適用しますか？</UI-TERM>** 情報を確認することで、パラメータが有効になる方法を判断できます：

        * 再起動が不要なパラメータ：パラメータの変更が成功すると約3分で有効になります。
        * 再起動が必要なパラメータ：OBProxyを再起動しなければ有効になりません。

## 変更履歴の確認

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、そのOBProxyクラスタの **<UI-TERM key="oms-v2.utils.hooks.useLayoutMenus.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="oceanbase-intl-console.components.Parameter.ParameterConfiguration">パラメータ</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterList">パラメータリスト</UI-TERM>** タブが表示されます。

5. **<UI-TERM key="ocp-v2.Detail.Parameter.ModificationHistory">変更履歴</UI-TERM>**タブを選択します。

   **<UI-TERM key="oceanbase-intl-console.ClusterWorkspace.ClusterParameter.utils.ModificationHistory">変更履歴</UI-TERM>**タブでは、**<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">更新日</UI-TERM>**や**<UI-TERM key="ocp-v2.Detail.Parameter.History.ParameterName">パラメータ名</UI-TERM>**に対応する情報を入力し、**<UI-TERM key="src.page.Project.User.ManageModal.Table.A3D05C57">照会</UI-TERM>**をクリックすると、パラメータをフィルタリングできます。パラメータリストでは、**<UI-TERM key="ocp-v2.TakeOver.Component.ParameterDiffDrawer.Parameter">パラメータ名</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Parameter.History.ValueBeforeChange">値－変更前</UI-TERM>**（変更前のパラメータ値）、**<UI-TERM key="ocp-v2.Detail.Component.ShowParameterListDrawer.ValueAfterTheChange">値－変更後</UI-TERM>**（変更後のパラメータ値）、**<UI-TERM key="oms-v2.pages.SystemParam.ModificationTime">修正時刻</UI-TERM>**、および**<UI-TERM key="ocp-v2.Detail.Parameter.History.OperationUser">ユーザー操作</UI-TERM>**などの情報を確認できます。
