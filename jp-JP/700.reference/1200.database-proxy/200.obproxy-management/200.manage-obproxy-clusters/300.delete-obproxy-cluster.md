# OBProxyクラスタの削除

ビジネスニーズに応じて、不要となったOBProxyクラスタを削除できます。これにより、クラスタ内のすべてのOBProxyサービスが各ホストからアンインストールされ、ホスト上のOBProxyサービスが占有していたリソースが解放されます。

## 前提条件

* 現在OCPにログインしているユーザーがOBPROXY_MANAGERロールを持っていること。

* 現在のOBProxyクラスタがビジネスでプロキシサービスを提供していないことを確認すること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**OBProxy**をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの**概要**ページに移動します。

4. ページの右上隅にある**...**アイコンをクリックし、**クラスタの削除**を選択します。

   <!-- ![delete-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで**削除**をクリックすると、OBProxyクラスタの削除操作が完了します。

   ポップアップウィンドウの**タスクを確認する**ボタンをクリックすると、進捗状況を確認できます。

   このタスクの状態が**完了**になり、かつOBProxyページの**クラスタ一覧**にそのOBProxyクラスタが表示されなくなった場合、削除は成功したことを意味します。
