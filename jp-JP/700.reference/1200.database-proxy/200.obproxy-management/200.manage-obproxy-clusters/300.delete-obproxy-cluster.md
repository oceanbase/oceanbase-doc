# OBProxyクラスタの削除

ビジネスニーズに応じて、不要になったOBProxyクラスタを削除できます。これにより、クラスタ内のすべてのOBProxyサービスが各ホストからアンインストールされ、ホスト上のOBProxyサービスが占有していたリソースが解放されます。

## 前提条件

* 現在OCPにログインしているユーザーがOBPROXY_MANAGERロールであること。

* 現在のOBProxyクラスタがビジネスでプロキシサービスを提供していないことを確認する。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストで操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上隅にある **...** アイコンをクリックし、**クラスタの削除** を選択します。

   <!-- ![delete-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで **削除** をクリックすると、OBProxyクラスタの削除操作が完了します。

   ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、進捗状況を確認できます。

   タスクの状態が **完了** になり、かつOBProxyページの **クラスタリスト** にそのOBProxyクラスタが表示されなくなった場合、削除は成功です。
