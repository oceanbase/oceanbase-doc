# OBProxyクラスタの削除

ビジネスニーズに応じて、不要となったOBProxyクラスタを削除できます。これにより、クラスタ内のすべてのOBProxyサービスが各ホストからアンインストールされ、ホスト上のOBProxyサービスが占有していたリソースが解放されます。

## 前提条件

* 現在OCPにログインしているユーザーがOBPROXY_MANAGERロールであること。

* 現在のOBProxyクラスタがビジネスでプロキシサービスを提供していないことを確認すること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**OBProxy**をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの**<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。

4. ページの右上隅にある**...**アイコンをクリックし、**<UI-TERM key="ocp-v2.Topo.TopoGraph.DeleteACluster">クラスターの削除</UI-TERM>**を選択します。

   <!-- ![delete-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで**<UI-TERM key="oceanbase-intl-console.TenantList.TenantOperation.DeleteTenant">削除</UI-TERM>**をクリックすると、OBProxyクラスタの削除操作が完了します。

   ポップアップウィンドウの**<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>**ボタンをクリックすると、進捗状況を確認できます。

   このタスクの状態が**<UI-TERM key="odc.component.TaskDetailDrawer.status.Complete">完成しました。</UI-TERM>**になり、かつOBProxyページの**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスター一覧</UI-TERM>**にそのOBProxyクラスタが表示されなくなった場合、削除は成功したことを意味します。
