# OBProxyクラスタの削除

業務上の必要に応じて、使用されなくなったOBProxyクラスタを削除できます。この操作では、クラスタ内のすべてのOBProxyサービスが各ホストからアンインストールされ、ホスト上のOBProxyサービスが占有していたリソースが解放されます。

## 前提条件

* 現在OCPにログインしているユーザーがOBPROXY_MANAGERロールであること。

* 現在のOBProxyクラスタが、業務に対するプロキシサービスを提供していないことを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタ一覧から、操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **概要** ページに移動します。

4. ページの右上隅にある **...** アイコンをクリックし、**クラスタの削除** を選択します。

   <!-- ![delete-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png) -->

5. ポップアップウィンドウで **削除** をクリックして、OBProxyクラスタの削除操作を完了します。

   ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、進捗状況を確認できます。

   このタスクのステータスが **完了** になり、かつOBProxyページの **クラスタ一覧** にそのOBProxyクラスタが表示されなくなった場合、削除は成功したことを意味します。
