# 物理接続

本記事では、現在のテナントのセッション数とODP上のすべてのネットワーク接続の内部プロパティ状態を確認する方法について説明します。

## 現在のテナントのセッション数とセッションIDの確認

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このドキュメントは、OceanBaseデータベースV4.3.0、ODP V4.2.3を例に、クエリ方法と出力情報を紹介します。</p>
</main>

1. ODPを使用してOceanBaseデータベースに接続します。ここでは、`root@sys`ユーザーへの接続を例にします。

   ```shell
   obclient -h10.10.10.1 -P2883 -uroot@sys -p -Doceanbase -A
   ```

2. `SHOW PROCESSLIST`ステートメントを使用して、現在のテナントのセッション数とセッションIDを確認します。

   ```shell
   obclient> SHOW PROCESSLIST;
   ```

   ODP構成パラメータ`client_session_id_version`の値によって、以下の2種類の出力結果があります。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><code>client_session_id_version</code>構成パラメータは、Client Session ID生成の計算ロジックを設定するために使用されます。詳細については、<a href='https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517691'>client_session_id_version</a>を参照してください。<code>2</code>に設定することを推奨します。新しい計算ロジックを使用することで、Client Session IDのグローバル一意性を保証します。</p>
   </main>

   * ODP構成パラメータ`client_session_id_version`が`2`に設定されている場合、ODPは新しい計算ロジックを使用してIDを生成し、Client Session IDのグローバル一意性を保証します。この場合、出力にはテナントに対応するOBServerノード上のセッション情報が表示されます。クエリ結果は次のとおりです：

     ```shell
     +------------+---------+---------------------+-----------+---------+------+--------+------------------+
     | Id         | User    | Host                | db        | Command | Time | State  | Info             |
     +------------+---------+---------------------+-----------+---------+------+--------+------------------+
     |          1 | root    | 10.10.10.1:39512    | oceanbase | Query   |    0 | ACTIVE | SHOW PROCESSLIST |
     | 3221501386 | proxyro | 10.10.10.1:37728    | oceanbase | Sleep   |   13 | SLEEP  | NULL             |
     +------------+---------+---------------------+-----------+---------+------+--------+------------------+
     ```

     各フィールドの意味は以下の表のとおりです：

     |        フィールド         |          フィールド           |
     |-------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
     | Id                | このセッションのID、すなわち`cs id`を表します。     |
     | User              | このセッションが属するユーザーを表します。   |
     | Host              | このセッションを開始したクライアントのIPアドレスとポート番号を表します。           |
     | db                | このセッションが現在接続しているデータベース名を表します。Oracleモードでは、ユーザー名と同じ名前のスキーマ名が表示されます。  |
     | Command           | このセッションが実行しているコマンドタイプを表します。 |
     | Time              | 現在のコマンド実行時間を秒単位で表します。コマンドが再試行された場合、システムはゼロリセットして再計算します。 |
     | State             | このセッションの現在の状態を表します。   |
     | Info              | このセッションが実行しているステートメントを表します。  |

   * ODPの構成パラメータ`client_session_id_version`が`1`に設定されている場合、ODPは元の計算ロジックを使用してIDを生成します。この場合、出力には対応するODPノード上のセッション情報が表示されます。クエリ結果は次のとおりです：

     ```shell
     +------+--------+------+---------------------+-----------+-------------+-------------------+-------------------+-------+-------+
     | Id   | Tenant | User | Host                | db        | trans_count | svr_session_count | state             | tid   | pid   |
     +------+--------+------+---------------------+-----------+-------------+-------------------+-------------------+-------+-------+
     |    9 | sys    | root | 10.10.10.1:17890    | oceanbase |           0 |                 1 | MCS_ACTIVE_READER | 48243 | 48243 |
     +------+--------+------+---------------------+-----------+-------------+-------------------+-------------------+-------+-------+
     ```

     各フィールドの意味は以下の表のとおりです：

     |        フィールド         |          フィールド           |
     |-------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
     | Id                | ODPが各クライアントセッション（Client Session）に付与する内部識別子（`id`）、すなわち`cs id`     |
     | Tenant            | そのセッションが属するテナントを示します   |
     | User              | そのセッションが属するユーザーを示します   |
     | Host              | そのセッションを開始したクライアントのIPアドレスとポート番号を示します            |
     | db                | そのセッションが現在接続しているデータベース名を示します。Oracleモードでは、ユーザー名と同じ名前のスキーマ名が表示されます  |
     | trans_count       | そのセッション内でODPが転送したトランザクション数を示します       |
     | svr_session_count | セッション数                  |
     | state             | クライアントセッションの状態。以下のような状態があります： <ul><li>MCS_INIT（初期化）</li> <li>MCS_ACTIVE_READER（アクティブ）</li><li>MCS_KEEP_ALIVE（アライブ）</li><li>MCS_HALF_CLOSE（ハーフクローズ）</li><li>MCS.Closed（クローズ済み）</li></ul>    |
     | tid               | スレッドID                 |
     | pid               | プロセスID                 |

## ODP上のすべてのネットワーク接続の内部プロパティ状態を確認する

`SHOW PROXYNET CONNECTION`ステートメントを使用して、ODP上のすべてのネットワーク接続の内部プロパティ状態を確認します。

```sql
SHOW PROXYNET CONNECTION [thread_id [LIMIT xx]]
```

パラメータ説明：

* `thread_id` を指定しない場合、ODP上のすべてのネットワーク接続の内部プロパティ状態が表示されます。

* `thread_id` を指定すると、指定されたスレッド上の接続状態が表示されます。`LIMIT [offset,] rows` および `LIMIT rows OFFSET offset` パラメータの指定をサポートしており、形式はMySQLと完全に互換性があります。`rows == -1` の場合、すべての行が表示されます。
