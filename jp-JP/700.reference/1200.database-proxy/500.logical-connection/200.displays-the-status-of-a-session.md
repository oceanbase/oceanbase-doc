# セッションの詳細な状態を表示する

本記事では、ODP上で指定されたクライアントセッションの内部状態を詳しく確認する方法について説明します。

## 手順

`sys`テナントとユーザーテナントは、`SHOW PROXYSESSION ATTRIBUTE`ステートメントを使用して、指定されたクライアントセッションの詳細な内部状態を確認できます。これには、そのクライアントセッションに関連するサーバーセッションも含まれます。

1. ODP経由でOceanBaseデータベースに接続します。

    接続例は以下のとおりです：

    ```shell
    obclient -h10.xx.xx.xx -uusername@obtenant#obdemo -P2883 -p****** -c -A oceanbase
    ```

    ODP経由でデータベースに接続する方法の詳細な操作ガイドについては、[OBClientを使用してOceanBaseテナントに接続する（MySQLモード）](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)および[OBClientを使用してOceanBaseテナントに接続する（Oracleモード）](../../../300.develop/200.application-development-of-oracle-mode/100.connect-to-oceanbase-database-of-oracle-mode/200.connect-to-an-oceanbase-tenant-by-using-obclient-of-oracle-mode.md)を参照してください。

2. 指定されたクライアントセッションの詳細な内部状態を確認します。

    SQLステートメントは次のとおりです：

    ```sql
    SHOW PROXYSESSION ATTRIBUTE [id [LIKE 'xxx']]
    ```

    パラメータの説明：

    * `id`を指定しない場合、現在のセッションの詳細な状態が表示されます(ODPバージョン1.1.0以降でサポート)。現在のセッションの指定されたプロパティ名の値に対するあいまいクエリもサポートされています(proxyバージョン1.1.2以降でサポート)。

    * `id`を指定した場合、指定されたプロパティ名の値に対するあいまいクエリもサポートされます(ODPバージョン1.1.0以降でサポート)。

    * `id`は`cs_id`または`connection_id`のいずれかであり、表示結果は同じです。

      `cs_id`はODP内部で各クライアントに割り当てられる`id`番号であり、`connection_id`はOceanBaseデータベース全体で各クライアントに割り当てられる`id`番号です。

      MySQLモードの`connection_id`は`SELECT CONNECTION_ID();`ステートメントで取得し、Oracleモードの`connection_id`は`SHOW FULL PROCESSLIST;`ステートメントで取得します。

    * `LIKE`はあいまい一致をサポートし、'%'と'_'が使用されます。

    各フィールドの意味は以下の表のとおりです：

    |       フィールド       |  説明  |
    |-----------------|------|
    | attribute_name | プロパティ名 |
    | value          | プロパティ値  |
    | info           | 基本情報 |

    よくあるプロパティとその説明は以下の表のとおりです：

    |           フィールド           |               フィールド                |
    |------------------------|---------------------------------|
    | proxy_sessid           | ODPのセッションID番号                |
    | cs_id                  | ODP内部で各Clientを識別するための`id`番号|
    | cluster                | Client Sessionが所属するクラスタ名         |
    | tenant                 | テナント                              |
    | user                   | ユーザー                              |
    | host_ip                | ユーザーIP                           |
    | host_port              | ユーザー端末のポート番号                           |
    | db                     | データベース                             |
    | total_trans_cnt        | トランザクションの総数                        |
    | svr_session_cnt        | セッションの総数                           |
    | active                 | 生存しているかどうか                            |
    | read_state             | クライアントセッションの状態                        |
    | tid                    | スレッドID                           |
    | pid                    | プロセスID                           |
    | modified_time          | 歴史的な変更時間                          |
    | reported_time          | 歴史的な報告時間                          |
    | hot_sys_var_version    | ホットアップデートされたシステム変数のバージョン                      |
    | sys_var_version        | システム変数のバージョン                          |
    | user_var_version       | ユーザー変数のバージョン                          |
    | last_insert_id_version | 最後に挿入されたIDのバージョン                      |
    | db_name_version        | データベース名のバージョン                         |
    | server_ip              | OBServerノードのIPアドレス                |
    | server_port            | OBServerノードのポート番号                   |
    | server_sessid          | OBServerノードのセッションID番号               |
    | ss_id                  | ODPがServer Sessionに付与するID番号         |
    | state                  | ネットワーク接続状態                            |
    | transact_count                   | 現在のServer Sessionが実行したトランザクションの数                   |
    | server_trans_stat                | 現在のServerセッションの実行状態。主に現在のServerセッションのリクエスト実行状況が正確かどうかを検証するために使用されます                    |
    | hot_sys_var_version              | ODPが保持する一般的なシステム変数のバージョン                    |
    | sys_var_version                  | ODPが保持するシステム変数のバージョン                   |
    | user_var_version                 | ODPが保持するユーザー系システム変数のバージョン                    |
    | last_insert_id_version           | ODPが保持する`last_insert_id`変数のバージョン                    |
    | db_name_version                  | ODPが保持する現在のデータベース変数のバージョン                    |
    | is_checksum_supported            | 現在のServerセッションでチェックサムが有効になっているかどうか                    |
    | is_safe_read_weak_supported      | 安全な弱い読み取りがサポートされているかどうか                    |
    | is_checksum_switch_supported     | チェックサムスイッチがリアルタイムで有効または無効になることをサポートしているかどうか                  |
    | checksum_switch                  | チェックサムのスイッチ状態                |
    | enable_extra_ok_packet_for_stats | 追加の返却ステータス確認データパケットがサポートされているかどうか                    |
