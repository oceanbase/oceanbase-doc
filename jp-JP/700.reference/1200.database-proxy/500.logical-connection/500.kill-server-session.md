# Serverセッションの終了

本記事では、ODP上の指定されたクライアントセッションおよびそのクライアントセッション上のサーバーセッションを終了する方法について説明します。

## 手順

`sys` テナントは `KILL PROXYSESSION` ステートメントを使用して、指定されたセッションを終了できます。

1. `root` ユーザーとしてODP経由で接続し、クラスタの `sys` テナントにログインします。

    接続例：

    ```shell
    obclient -h10.xx.xx.xx -uroot@sys#obdemo -P2883 -p****** -c -A oceanbase
    ```

    ODP経由でデータベースに接続する操作手順の詳細については、[OBClientを使用したOceanBaseテナントへの接続（MySQLモード）](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)および[OBClientを使用したOceanBaseテナントへの接続（Oracleモード）](../../../300.develop/200.application-development-of-oracle-mode/100.connect-to-oceanbase-database-of-oracle-mode/200.connect-to-an-oceanbase-tenant-by-using-obclient-of-oracle-mode.md)を参照してください。

2. 指定されたクライアントセッションを終了します。

   * 指定されたクライアントセッションを終了する

     ```sql
     KILL PROXYSESSION {cs_id | connection_id};
     ```

     パラメータ説明：

     * `id` は `cs_id` または `connection_id` のいずれかを指定でき、表示結果は同じです。

       `cs_id` はODP内部で各クライアントに付与される `id` 番号であり、`connection_id` はOceanBaseデータベース全体で各クライアントに付与される `id` 番号です。`connection_id` は `SELECT CONNECTION_ID();` ステートメントで取得できます。

     * `KILL connection_id` と同じ効果があります。`KILL` ステートメントの詳細については、[KILL（MySQLモード）](../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5800.kill-of-mysql-mode.md)または[KILL（Oracleモード）](../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/300.dcl-of-oracle-mode/1800.kill-of-oracle-mode.md)を参照してください。

     例：

     1. クライアントセッションを確認し、`cs_id` または `connection_id` を取得します。

        以下のステートメントを実行して `cs_id` を取得します。

        ```sql
        SHOW PROXYSESSION;
        ```

        クエリ結果は以下のとおりです。戻り値の `Id` が `cs_id` です。

        ```shell
        +----------------------+-------+----------+----------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
        | proxy_sessid         | Id    | Cluster  | Tenant   | User | Host                 | db   | trans_count | svr_session_count | state             | tid   | pid   | using_ssl |
        +----------------------+-------+----------+----------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
        | 12402504630519660553 | 56932 | test420  | sys      | root | 100.xx.xx.xx:63882   | NULL |           0 |                 1 | MCS_ACTIVE_READER | 76286 | 76286 |         0 |
        +----------------------+-------+----------+----------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
        1 row in set
        ```

        または、以下のステートメントを実行して `connection_id` を取得します。

        ```sql
        SELECT CONNECTION_ID ();
        ```

        実行結果は以下のとおりです。

        ```shell
        +------------------+
        | CONNECTION_ID () |
        +------------------+
        |       3221562906 |
        +------------------+
        1 row in set
        ```

     2. `cs_id`が`56392`または`connection_id`が`3221562906`のクライアントセッションを終了します。

        ```sql
        KILL PROXYSESSION 56392;
        ```

        または

        ```sql
        KILL PROXYSESSION 3221562906;
        ```

        実行が成功すると、以下のようなエラーメッセージが表示されます。

        ```shell
        ERROR 1317 (70100): Query execution was interrupted
        ```

     3. クエリが中断した後、クライアントセッションを確認すると、接続が切断されていることがわかります。

        ```sql
        SHOW PROXYSESSION;
        ```

        以下のメッセージが表示されます：

        ```shell
        ERROR 2013 (HY000): Lost connection to MySQL server during query
        ```

     4. 再度クライアントセッションを確認します。

        ```sql
        SHOW PROXYSESSION;
        ```

        以下のメッセージが表示されます：

        ```shell
        ERROR 2006 (HY000): OceanBase server has gone away
        No connection. Trying to reconnect...
        Connection id:    57195
        Current database: *** NONE ***

        +----------------------+-------+----------+--------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
        | proxy_sessid         | Id    | Cluster  | Tenant | User | Host                 | db   | trans_count | svr_session_count | state             | tid   | pid   | using_ssl |
        +----------------------+-------+----------+--------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
        | 12402504630519660555 | 57195 | test420  | sys    | root | 100.xx.xx.xx:24996   | NULL |           0 |                 1 | MCS_ACTIVE_READER | 76286 | 76286 |         0 |
        +----------------------+-------+----------+--------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
        1 row in set
        ```

     この例からわかるように、`cs_id`または`connection_id`を指定して現在のセッションをKILLする場合、コマンドの実行が成功すると、現在の接続は切断されます。`SHOW PROXYSESSION`で確認すると、OBClientは新しいセッション接続を確立し、SQLを実行して結果を表示します。

   * 指定されたクライアントセッション上のサーバーセッションを終了する

     ```sql
     KILL PROXYSESSION {cs_id | connection_id} ss_id
     ```

     パラメータ説明：

     * `id`は`cs_id`または`connection_id`のいずれかを指定でき、表示される結果は同じです。

       `cs_id`はODP内部で各クライアントに付与される`id`番号であり、`connection_id`はOceanBaseデータベース全体で各クライアントに付与される`id`番号です。`connection_id`は`SELECT CONNECTION_ID();`ステートメントで取得できます。

     * `ss_id`はODP内部で各サーバー側セッション（Server Session）に付与される`id`番号を表し、`SHOW PROXYSESSION ATTRIBUTE id`から取得できます。詳細な取得手順については、[セッションの詳細状態を表示する](../500.logical-connection/200.displays-the-status-of-a-session.md)を参照してください。

     例：

     1. クライアントセッションを確認し、`cs_id` を取得します。

        ```sql
        SHOW PROXYSESSION;
        ```

        クエリ結果は次のとおりです。戻り値の `Id` が `cs_id` に該当します。

        ```shell
        +----------------------+-------+----------+--------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+

        +----------------------+-------+----------+--------+------+----------------------+------+------------- +-------------------+-------------------+-------+-------+-----------+
        1 row in set
        ```

        ```sql
        KILL PROXYSESSION 64940 16;
        ```
