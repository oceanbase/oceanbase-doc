# V3.xとV4.xのビュー変更

OceanBaseデータベースV4.xでは、内部テーブルと仮想テーブルに多くの改良を加え、システム情報を表示するための多くのビューを提供しています。V4.xで最も大きな変更は、内部情報のクエリが全面的にビューへと移行したことです。統一的に定義されたビューはバージョン間で互換性があり、情報もより明確になっています。

例えば、以前は各パーティションの位置情報を記録するためによく使用されていた`__all_tenant_meta_table`は、V4.xではパーティションが独立した位置情報を持たなくなり、特定のログストリームに属するようになったため、パーティションの位置情報はその所属するログストリームの位置によって決定されます。ログストリームの位置はビュー`DBA_OB_LS_LOCATIONS`で確認できます。また、クラスタのメジャーコンパクション状態を確認するために使用されていた`__all_zone`では、V4.xではシステムテナントは`__all_zone`テーブルにクラスタのZoneやRegionなどの情報のみを格納し、メジャーコンパクション状態は専用の内部テーブルに分割されています。ビュー`DBA_OB_MAJOR_COMPACTION`で全体的なメジャーコンパクション状態を、ビュー`DBA_OB_ZONE_MAJOR_COMPACTION`で各Zoneのメジャーコンパクション状態を確認できます。特に、以前のバージョンではクラスタ全体の状態であったのに対し、V4.xでは各テナントが個別にメジャーコンパクションを実行するため、各テナントは`DBA_OB_MAJOR_COMPACTION`と`DBA_OB_ZONE_MAJOR_COMPACTION`を使用して自身のテナントのメジャーコンパクション状態を確認できます。

さらに、V4.xではビュー定義の仕様に基づき、既存の独自ビューに対していくつかの改良が行われました。改良点は以下の通りです：

* 不要なビューを「削除」しました。
* ビュー名に一律に`OB_`プレフィックスを追加しました。
* ビュー名とビューの列名をすべて大文字に変更しました。
* テナントレベルのビューの場合、ユーザーテナントではそのテナントのデータのみが表示され、システムテナントではすべてのテナントのデータが表示されます。

## V4.x系で名前が変更されたビュー

ビューの名前変更は主にビュー内容を規範化し、利用時の操作をより効率的に行えるようにするためです。V3.x系とV4.x系では、ビュー名の変更に以下の違いがあります：

* OceanBaseデータベース V4.0以前のバージョンでは、一部の独自ビューに`OB_`プレフィックスが付きません。例：`v$plan_cache_stat`、`v$obrpc_outgoing`などのビュー。
* OceanBaseデータベース V4.0以降のバージョンでは、すべてに`OB_`プレフィックスが付けられます。例：`V$OB_PLAN_CACHE_STAT`、`V$OB_RPC_OUTGOING`などのビュー。
