# V3.xとV4.xのビュー変更

OceanBaseデータベースV4.xでは、内部テーブルと仮想テーブルに対して多くの改善を加えました。また、システム情報を表示するための多くのビューも提供しています。V4.xの最大の変化は、内部情報のクエリが完全にビューへと移行し、統一的に定義されたビューはバージョン間で互換性を持ち、情報もより明確になったことです。

例えば、以前よく使われていた各パーティションの位置情報を記録していた`__all_tenant_meta_table`ですが、V4.xではパーティションが独立して位置情報を保有するのではなく、あるログストリームに属しており、そのパーティションの位置情報は所属するログストリームの位置によって決定されます。ログストリームの位置はビュー`DBA_OB_LS_LOCATIONS`で確認できます。次に、クラスタのメジャーコンパクション状態を確認するための`__all_zone`ですが、V4.xではシステムテナントは`__all_zone`テーブルにクラスタのZoneやRegionなどの情報をのみ保存し、メジャーコンパクション状態は専用の内部テーブルに分割されています。全体のメジャーコンパクション状態はビュー`DBA_OB_MAJOR_COMPACTION`で確認でき、各Zoneのメジャーコンパクション状態はビュー`DBA_OB_ZONE_MAJOR_COMPACTION`で確認できます。特に、以前のバージョンではメジャーコンパクションはクラスタ全体の状態でしたが、V4.xでは各テナントがそれぞれメジャーコンパクションを実行するため、各テナントは`DBA_OB_MAJOR_COMPACTION`と`DBA_OB_ZONE_MAJOR_COMPAクション`を使用して、自らのテナントのメジャーコンパクション状態を確認できます。

さらに、V4.xではビューの定義規範に基づいて、既存の独自ビューに対していくつかの改善を行いました。改善点には以下のものが含まれます：

* 不要なビューは「削除」されました。
* ビュー名に`OB_`というプレフィックスを統一的に追加しました。
* ビュー名とビューのカラム名をすべて大文字に統一しました。
* テナントレベルのビューの場合、ユーザーのテナントでは自身のテナントのデータのみが表示され、システムテナントでは全テナントのデータが表示されます。

## V4.x系で名前が変更されたビュー

ビューの名前の変更は、主にビューの内容を一貫性を持たせ、使用時により効率的な操作を実行できるようにするためです。V3.x系とV4.x系では、ビュー名の変更に以下の違いがあります：

* OceanBaseデータベースのV4.0以前のバージョンでは、一部のシステムビューには`OB_*`プレフィックスが付けられません。例えば、v$plan_cache_stat、v$obrpc_outgoingなどのビューです。
* OceanBaseデータベースのV4.0以降のバージョンでは、一貫して`OB_*`プレフィックスが追加されます。例えば、V$OB_PLAN_CACHE_STAT、V$OB_RPC_OUTGOINGなどのビューです。
