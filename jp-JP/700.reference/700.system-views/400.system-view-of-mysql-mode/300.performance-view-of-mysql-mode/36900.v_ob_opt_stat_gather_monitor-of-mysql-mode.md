# V$OB_OPT_STAT_GATHER_MONITOR

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上で、現在のテナントの統計情報収集タスクのリアルタイム状態を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | クリーンアップタスクが存在するテナントID |
| SVR_IP | varchar(46) | NO | クリーンアップタスクが存在するノードのIPアドレス |
| SVR_PORT | bigint(20) | NO | クリーンアップタスクが存在するノードのポート |
| SESSION_ID | bigint(20) | NO | クリーンアップタスクが存在するセッションID<br>V4.3.x系では：<ul><li> V4.3.5 BP2未満のバージョンでは：<br>すべての接続方式(直接接続モード/ODPモード)において、このフィールドはServer Session IDを表します。</li><li> V4.3.5 BP2以降のバージョンでは:<ul><li>直接接続モードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはClient Session IDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul> |
| TRACE_ID | varchar(64) | NO | クリーンアップタスクが存在するTRACE ID |
| TASK_ID | varchar(36) | NO | クリーンアップタスクID（UUID形式で生成されるグローバル一意の値） |
| TYPE | varchar(16) | NO | クリーンアップタスクの種類 |
| TASK_START_TIME | datetime(6) | NO | クリーンアップタスクの開始時間 |
| TASK_DURATION_TIME | bigint(20) | NO | クリーンアップタスクの継続時間。単位はマイクロ秒 |
| TASK_TABLE_COUNT | bigint(20) | NO | クリーンアップタスクで収集対象となるテーブル数 |
| COMPLETED_TABLE_COUNT | bigint(20) | NO | クリーンアップタスクで既に収集が完了したテーブル数 |
| RUNNING_TABLE_OWNER | varchar(128) | NO | クリーンアップタスクで収集中のテーブルの所有者ユーザー名 |
| RUNNING_TABLE_NAME | varchar(256) | NO | クリーンアップタスクで収集中のテーブル名 |
| RUNNING_TABLE_DURATION_TIME | bigint(20) | NO | クリーンアップタスクで収集中のテーブルの継続時間 |
| RUNNING_TABLE_PROGRESS      | varchar(256) | NO   | クリーンアップタスクの収集進捗状況 |
