# V$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のノードで実行中のメジャーコンパクションの進捗状況を表示します。

## フィールドの説明

|          フィールド名           |      型      | NULL許容 |                                            説明                                            |
|-------------------------|--------------|------------|--------|
|SVR_IP    |varchar(46)    |NO   |サーバーIPアドレス    |
|SVR_PORT    |bigint(20)    |NO   |サーバーポート番号    |
|TENANT_ID    |bigint(20)    |NO   |テナントID    |
|TYPE    |varchar(64)    |NO   |Compactionのタイプ：<ul><li> MINI：ダンプ/L0コンパクション、MemTableはダンプによりSSTableに変換される </li><li>MAJOR：メジャーコンパクション </li><li>MINOR：L1コンパクション、複数のMini SSTableが1つに合成される</li></ul>    |
|ZONE    |varchar(128)    |NO   |Zone情報    |
|COMPACTION_SCN    |bigint(20) unsigned    |NO   |メジャーコンパクションのバージョン情報    |
|STATUS    |varchar(10)    |NO   |ステータス情報    |
|TOTAL_TABLET_CNT    |bigint(20)    |NO   |tabletの総数    |
|UNFINISHED_TABLET_CNT    |bigint(20)    |NO   |未完了のtablet数    |
|DATA_SIZE    |bigint(20)    |NO   |Compactionが必要なデータ量の合計、単位はバイト |
|UNFINISHED_DATA_SIZE    |bigint(20)    |NO   |未完了のCompactionデータ量、単位はバイト   |
|COMPRESSION_RATIO    |bigint(20)    |NO   |新規データの圧縮率（前回のメジャーバージョンポイント以降に新規書き込まれたデータの圧縮率のみ記録）    |
|START_TIME    |timestamp(6)    |NO   |開始時間    |
|ESTIMATED_FINISH_TIME    |timestamp(6)    |NO   |推定完了時間（もし    |
|    |    |NO   |compaction_progressが100の場合、終了時間を表示する）    |
| COMMENTS         | varchar(1024) | NO  | コメント情報。メジャーコンパクション中は、最新のCompactionイベントを記録します。メジャーコンパクション終了後は、全体の所要時間を記録します  |

ユーザーテナントが現在のOBServerノード上での自身のテナントのメジャーコンパクション進捗状況を確認します。

obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_COMPACTION_PROGRESS;
