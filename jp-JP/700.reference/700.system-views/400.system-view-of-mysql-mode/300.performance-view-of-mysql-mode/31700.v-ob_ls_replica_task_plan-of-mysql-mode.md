# V$OB_LS_REPLICA_TASK_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在生成すべきすべてのタスク（既に生成済みのものと未生成のものを含む）を表示します。

## フィールド説明

| フィールド名                 | 型           |  NULL許容 |   説明                             |
|-------------------------|----------------|-----------------|------------------------------------|
| TENANT_ID               | bigint(20)     | NO              | テナントID                            |
| LS_ID                   | bigint(20)     | NO              | ログストリームID                          |
|  TASK_TYPE              | varchar(64)    | NO              | タスクタイプ。<ul><li>MIGRATE REPLICA：レプリカの移行</li><li>ADD REPLICA：レプリカの追加</li> <li>REMOVE PAXOS REPLICA：レプリカの削除</li> <li>MODIFY PAXOS REPLICA NUMBER：法定レプリカ数の変更</li></ul>|
| PRIORITY                | varchar(5)     | NO              | タスク優先度。<ul><li>LOW：低優先度タスク。移行タスクのみが低優先度となる場合があります。</li><li>HIGH：高優先度タスク</li></ul>|
| TARGET_REPLICA_SVR_IP   | varchar(46)    | YES             | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT | bigint(20)     | YES             | ターゲットレプリカが存在するマシンのポート番号 |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20) | YES             | ターゲットレプリカの法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE     | varchar(16)    | YES             | ターゲットレプリカタイプ |
| SOURCE_REPLICA_SVR_IP   | varchar(46)    | YES             | ソースレプリカが存在するマシンのIPアドレス</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLと表示されます。 |
| SOURCE_REPLICA_SVR_PORT | bigint(20)     | YES             | ソースレプリカが存在するマシンのポート番号</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、0と表示されます。 |
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20) | YES             | ソースレプリカの法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE     | varchar(16)    | YES             | ソースレプリカタイプ</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLと表示されます。 |
| TASK_EXEC_SVR_IP        | varchar(46)    | YES             | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT      | bigint(20)     | YES             | タスク実行マシンのポート番号 |
| COMMENT                 | varchar(2048)  | YES             | タスク生成理由の備考 |
| CONFIG_VERSION          | varchar(128)   | YES             | ディザスタリカバリタスク実行時のclog層のconfig_version情報を記録 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0バージョンから導入されました。</p></main>  |
