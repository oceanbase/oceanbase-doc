# GV$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、すべてのノード上でのTabletレベルCompactionの進捗状況を表示します。

## フィールドの説明

|             フィールド名             |      型      | NULL許容 |                                            説明                                            |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | サーバーIPアドレス                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | サーバーポート番号|
| TENANT_ID                    | bigint(20)   | NO         | テナントID |
| TYPE                         | varchar(64)  | NO         | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのマージ</li> <li>`MEDIUM_MERGE`：パーティションレベルのマージ</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプで、指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>    |
| LS_ID                        | bigint(20)   | NO         |ログストリームID|
| TABLET_ID                    | bigint(20)   | NO         | データシャーディングID                                                                                  |
| COMPACTION_SCN                      | bigint(20) unsigned   | NO         | マージバージョン情報|
| TASK_ID                      | varchar(64)  | NO         | 実行中のトレース                                                                                |
| STATUS                       | varchar(15)  | NO         | タスクの状態  |
| DATA_SIZE                    | bigint(20)   | NO         | Compactionが必要な総データ量、単位はバイト |
| UNFINISHED_DATA_SIZE         | bigint(20)   | NO         | 未完了Compactionのデータ量、単位はバイト    |
| PROGRESSIVE_COMPACTION ROUND | bigint(20)   | NO         | 減算マージラウンド数|
| CREATE_TIME                  | timestamp(6) | NO         | タスク作成時間|
| START_TIME                   | timestamp(6) | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME        | timestamp(6) | NO         | 予定完了時間|
| START_CG_ID                  | bigint(20)   | NO         | Column GroupのStart ID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>  |
| END_CG_ID                    | bigint(20)   | NO         | Column GroupのEnd ID <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>   |
