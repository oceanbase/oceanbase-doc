# GV$OB_RPC_INCOMING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントがすべてのOBServerノードから受信したRPCリクエストの統計情報を表示します。

## フィールドの説明

|    **フィールド名**    |    **タイプ**    | **NULL値を許容するか** |        **説明**         |
|----------------|--------------|----------------|-----------------------|
| TENANT_ID      | bigint(20)   | NO             | テナントID                 |
| SVR_IP         | varchar(46)  | NO             | IPアドレス                 |
| SVR_PORT       | bigint(20)   | NO             | ポート番号                   |
| PCODE          | bigint(20)   | NO             | RPCパケットコード       |
| PCODE_NAME     | varchar(256) | NO             | RPCパケットコードに対応する名前 |
| COUNT          | bigint(20)   | NO             | この種類のRPCリクエストを受信した回数   |
| TOTAL_SIZE     | bigint(20)   | NO             | 受信データの総量、単位はバイト              |
| NET_TIME       | bigint(20)   | NO             | RPCが送信元から送信されてから、宛先で受信されるまでの時間差、単位はマイクロ秒                  |
| WAIT_TIME      | bigint(20)   | NO             | 受信時間からリクエストがキューに入れられるまでの時間、単位はマイクロ秒       |
| QUEUE_TIME     | bigint(20)   | NO             | キュー内で待機している時間、単位はマイクロ秒             |
| PROCESS_TIME   | bigint(20)   | NO             | 実際の処理に要した時間、単位はマイクロ秒             |
| LAST_TIMESTAMP | timestamp(6) | NO             | 前回更新された時間               |
| DCOUNT         | bigint(20)   | NO             | 各Pcode RPCのリクエストカウント、30秒を1統計期間とする                     |

## クエリ例

ユーザーテナント内で、そのテナントがすべてのノードから受信したRPCリクエストのうち、キュー内での待機時間が1秒を超えるリクエストを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_RPC_INCOMING WHERE QUEUE_TIME > 1000000;
```
