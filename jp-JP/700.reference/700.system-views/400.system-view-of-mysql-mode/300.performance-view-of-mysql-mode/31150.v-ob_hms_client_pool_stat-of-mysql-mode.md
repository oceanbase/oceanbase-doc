# V$OB_HMS_CLIENT_POOL_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントのHMSカタログクライアントの使用状況を表示するために使用されます。

## フィールドの説明

|     フィールド名    |     型    | NULL許容    |      説明      |
|----------------|-------------|----------------|----------------|
| SVR_IP         | varchar(46) | NO             | レプリカが存在するノードのアドレスを表します。|
| SVR_PORT       | bigint(20)  | NO             | レプリカが存在するノードのポートを表します。|
| TENANT_ID      | bigint(20)  | NO             | テナントIDを表します。値は以下のとおりです：<ul><li>1：システムテナントIDを表します。 </li><li>その他の値：ユーザーテナントまたはMetaテナントIDを表します。</li></ul>|
| CATALOG_ID     | bigint(20)  | NO             | テナント内の特定のCatalogのIDを表します。|
| TOTAL_CLIENTS  | bigint(20)  | NO             | 現在のテナント配下の対応するCatalogに作成されたクライアントの総数を表します。|
| IN_USE_CLIENTS | bigint(20)  | NO             | 現在のテナント配下の対応するCatalogで使用中のクライアント数を表します。|
| IDLE_CLIENTS   | bigint(20)  | NO             | 現在のテナント配下の対応するCatalogで使用されていない（アイドル）クライアント数を表します。|

## クエリ例

現在のテナントのHMSカタログクライアントの使用状況を照会します。

```shell
obclient> SELECT * FROM oceanbase.V$OB_HMS_CLIENT_POOL_STAT;
```

クエリ結果は次のとおりです：

```shell

| xx.xxx.xxx.xxx |    17131 |      1004 |     500006 |             1 |              0 |            1 |
| xx.xxx.xxx.xxx |    17131 |      1004 |     500005 |             1 |              0 |            1 |

2 rows in set
```
