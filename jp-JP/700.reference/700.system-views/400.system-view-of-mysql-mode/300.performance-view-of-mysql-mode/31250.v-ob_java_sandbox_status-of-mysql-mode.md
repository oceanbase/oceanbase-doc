# V$OB_JAVA_SANDBOX_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2系列では、このビューはV4.4.2 BP4で導入されました。</p>
</main>

## 機能の概要

このビューは、現在のOBServerノードにおける現在のテナントのJava UDFサンドボックスの状態を表示します。サンドボックスの各世代のライフサイクル、通信チャネルプール、サンドボックスプロセスとそのJVMのリソースに関する情報などを確認できます。

利用時の注意点は以下のとおりです。

* 構成パラメータ `ob_enable_java_udf_sandbox` を有効にすると、Java UDFは独立したサンドボックスプロセス内で実行されます。各行は1世代（Generation）のサンドボックスに対応し、各世代のサンドボックスは1つのサンドボックスJVMプロセスに対応します。
* このビューには既存のサンドボックスのみが表示され、このビューをクエリしてもサンドボックスの作成はトリガーされません。
* `INSTANCE_COUNT` から `LAST_FORCE_KILL_REASON` まではテナントレベルの集計情報であり、同一テナント内の各行の値は同じです。
* まだ正常に収集できていない、または取得できない指標はNULLとして表示され、実際の値が`0`の指標と区別されます。

| STATUS | varchar(32) | NO | この世代のサンドボックスの実行状態：<ul><li>`STARTING`：起動中</li><li>`UP`：実行中</li><li>`DRAINING`：ドレイン中</li><li>`DOWN`：停止済み</li><li>`START_FAILED`：起動失敗</li></ul> |
| PROCESS_PID | bigint(20) | YES | サンドボックスJVMプロセスのプロセスID。 |
| START_TIME | timestamp(6) | YES | この世代のサンドボックスの起動時刻。 |
| UPTIME_MS | bigint(20) | YES | この世代のサンドボックスの稼働時間。単位はミリ秒。 |
| DRAIN_REASON | varchar(32) | YES | この世代のサンドボックスがドレイン状態になった理由。`GENERATION_STATE`が`DRAINING`の場合にのみ値が設定されます。<ul><li>`IDLE_RETIRE`：アイドル状態に伴う世代の終了</li><li>`MANUAL_RETIRE`：手動操作による世代の終了</li><li>`TIMEOUT_STUCK`：リクエストタイムアウト</li><li>`OOM`：メモリ不足</li><li>`CHANNEL_ERROR`：通信チャネルエラー</li><li>`CHANNEL_DEGRADED`：通信チャネルの劣化</li><li>`PROCESS_DEAD`：サンドボックスプロセスの終了</li><li>`PROTOCOL_ERROR`：通信プロトコルエラー</li><li>`HANDLER_FATAL`：リクエスト処理で致命的なエラー発生</li><li>`DRAIN_DEADLINE_EXPIRED`：ドレインのタイムアウト</li><li>`MAX_GENERATION_LIMIT`：サンドボックス世代数が上限に達した場合</li></ul> |
| DRAIN_DEADLINE | timestamp(6) | YES | ドレインの期限。`GENERATION_STATE`が`DRAINING`の場合にのみ値が設定されます。期限までに処理中のリクエストが完了しない場合、サンドボックスプロセスは強制終了されます。 |
| FORCE_KILLED | tinyint(4) | YES | この世代のサンドボックスプロセスが強制的に終了されたかどうか：<ul><li>`0`：いいえ</li><li>`1`：はい</li></ul> |
| FORCE_KILL_REASON | varchar(32) | YES | 強制終了の理由。値は`DRAIN_REASON`と同じです。`FORCE_KILLED`が`1`の場合にのみ値が設定されます。 |
| INSTANCE_COUNT | bigint(20) | YES | 当該テナントの現在のサンドボックスインスタンス数。 |
| MAX_GENERATION_COUNT | bigint(20) | YES | 当該テナントで同時に存在できるサンドボックス世代数の上限。 |
| DRAINING_GENERATION_COUNT | bigint(20) | YES | 当該テナントで現在ドレイン状態にあるサンドボックス世代数。 |
| DEFERRED_GENERATION_COUNT | bigint(20) | YES | 当該テナントで遅延回収を待っているサンドボックス世代数。 |
| START_COUNT | bigint(20) | YES | 当該テナントのサンドボックスの累計起動回数。 |

| START_FAILURE_COUNT | bigint(20) | YES | 当該テナントのサンドボックスの累計起動失敗回数。 |
| LAST_START_ERROR_CODE | bigint(20) | YES | 当該テナントの直近のサンドボックス起動失敗時のエラーコード。起動失敗が発生していない場合はNULL。 |
| LAST_START_ERROR_TIME | timestamp(6) | YES | 当該テナントでサンドボックスの起動に最後に失敗した時刻。起動失敗が発生していない場合はNULL。 |
| ROLLOVER_COUNT | bigint(20) | YES | 当該テナントのサンドボックスの累計置換（Rollover）回数。新しい世代のサンドボックスで古いサンドボックスを置き換えた回数です。 |

## クエリ例

現在のテナントにおける、現在のOBServerノード上のJava UDFサンドボックスの状態とメモリ使用状況を照会します。

```shell
obclient> SELECT SVR_IP, TENANT_ID, GENERATION_ID, GENERATION_STATE, STATUS, PROCESS_PID, PROCESS_RSS_BYTES, HEAP_USED_BYTES, MONITOR_STATUS FROM oceanbase.V$OB_JAVA_SANDBOX_STATUS;
```
