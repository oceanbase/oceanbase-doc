# V$DML_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上のユーザーテーブルのDML情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート番号 |
| INST_ID | bigint(20) | NO | テナントID |
| OBJN | bigint(20) | NO | オブジェクトID |
| INS | bigint(20) | NO | 最後の統計収集以降の挿入回数 |
| UPD | bigint(20) | NO | 最後の統計収集以降の更新回数 |
| DEL | bigint(20) | NO | 最後の統計収集以降の削除回数 |
| DROPSEG | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| CURROWS | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| PAROBJN | bigint(20) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| LASTUSED | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| FLAGS | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| CON_ID | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |

## クエリ例

現在のテナントが現在のOBServerノード上のユーザーテーブルのDML情報を確認します。

obclient [oceanbase]> SELECT * FROM oceanbase.V$DML_STATS;
