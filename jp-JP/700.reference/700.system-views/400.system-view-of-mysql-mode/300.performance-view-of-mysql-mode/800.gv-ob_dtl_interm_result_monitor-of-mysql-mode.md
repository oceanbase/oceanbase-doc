# GV$OB_DTL_INTERM_RESULT_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

DTL中間結果マネージャーの監視情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート番号 |
| TENANT_ID | bigint(20) | NO | テナントID |
| TRACE_ID | varchar(64) | NO | ステートメントのTRACE ID |
| OWNER | varchar(64) | NO | 中間結果の使用者 |
| START_TIME | timestamp(6) | NO | 中間結果を書き込んだ時間 |
| EXPIRE_TIME | timestamp(6) | NO | 中間結果の有効期限 |
| HOLD_MEMORY | bigint(20) | NO | 使用中のメモリサイズ、単位はバイト |
| DUMP_SIZE | bigint(20) | NO | ダンプサイズ、単位はバイト |
| DUMP_COST | bigint(20) | NO | ダンプにかかった時間 |
| DUMP_TIME | timestamp(6) | YES | ダンプ時刻 |
| DUMP_FD | bigint(20) | NO | ダンプファイルのFD |
| DUMP_DIR_ID | bigint(20) | NO | ダンプファイルのディレクトリID |
| CHANNEL_ID | bigint(20) | NO | DTLのCHANNEL ID |
| QC_ID | bigint(20) | NO | 送信者のQC ID |
| DFO_ID | bigint(20) | NO | 送信者のDFO ID |
| SQC_ID | bigint(20) | NO | 送信者のSQC ID |
| BATCH_ID | bigint(20) | NO | px batch rescanシナリオにおけるバッチ内の順序 |
| MAX_HOLD_MEMORY | bigint(20) | NO | 最大使用メモリサイズ、単位はバイト |
