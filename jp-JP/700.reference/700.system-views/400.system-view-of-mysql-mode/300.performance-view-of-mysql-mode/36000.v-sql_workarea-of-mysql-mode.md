# V$SQL_WORKAREA

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

SQLの自動メモリ管理によって実行されるすべてのOperatorのworkarea統計情報を表示します。

## フィールドの説明

|        **フィールド名**        |    **型**    | **NULL許容** |                                                                **説明**                                                                 |
|------------------------|--------------|----------------|---------|
| ADDRESS                | varbinary(8) | NO             | SQLに対応するHandleアドレス。現在値は指定されていません                           |
| HASH_VALUE             | bigint(0)    | NO             | ステートメントのHash Valueの値                                  |
| DB_ID                  | bigint(20)   | NO             | このSQLリクエストの接続が属するデータベースID  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li> <li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>  |
| SQL_ID                 | varchar(32)  | NO             | SQLステートメントのSQL一意の識別子                                   |
| CHILD_NUMBER           | bigint(0)    | NO             | このcursorの数                                       |
| WORKAREA_ADDRESS       | varbinary(8) | NO             | workareaアドレス                                        |
| OPERATION_TYPE         | varchar(40)  | NO             | workareaオペレータタイプ。例：Sort、Hash Join、Group byなど        |
| OPERATION_ID           | bigint(20)   | NO             | プランツリー内でオペレータを識別する一意の識別子                                     |
| POLICY                 | varchar(10)  | NO             | workareaのポリシー：<ul><li>>MANUAL</li><li> AUTO </li></ul>   |
| ESTIMATED_OPTIMAL_SIZE | bigint(20)   | NO             | 最適状態でオペレータを実行するための推定メモリサイズ、単位：bytes                        |
| ESTIMATED_ONEPASS_SIZE | bigint(20)   | NO             | One Passシナリオでオペレータを実行するための推定メモリサイズ、単位：bytes                |
| LAST_MEMORY_USED       | bigint(20)   | NO             | カーソルが前回実行時に使用したメモリサイズ、単位：bytes                            |
| LAST_EXECUTION         | varchar(10)  | NO             | 前回の実行時にworkareaがoptimal、one pass、またはmulti passesを選択したかどうか                                                                                  |
| LAST_DEGREE            | bigint(20)   | NO             | 前回の実行の並列度                                            |
| TOTAL_EXECUTIONS       | bigint(20)   | NO             | workareaを使用して実行した合計回数                                |
| OPTIMAL_EXECUTIONS     | bigint(20)   | NO             | 最適シナリオでの実行回数                                         |
| ONEPASS_EXECUTIONS     | bigint(20)   | NO             | One Passシナリオでの実行回数                                   |
| MULTIPASSES_EXECUTIONS | bigint(20)   | NO             | Multi Passesシナリオでの実行回数                               |
| ACTIVE_TIME            | bigint(20)   | NO             | workareaがアクティブだった平均時間、単位：s                             |
| MAX_TEMPSEG_SIZE       | bigint(20)   | NO             | workarea使用時の最大一時ディスク容量、単位：bytes；NULLの場合は一時空間未使用を意味します |
| LAST_TEMPSEG_SIZE      | bigint(20)   | NO             | workareaが前回実行時に使用した一時ディスク容量；NULLの場合は一時空間未使用を意味します         |
| CON_ID                 | bigint(20)   | NO             | テナントID                   |
| SVR_IP                 | varchar(46)   | NO             | サーバーIPアドレス                   |
| SVR_PORT                 | bigint(20)   | NO             | サーバーポート番号                   |
