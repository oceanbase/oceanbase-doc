# V$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上でどの程度のメモリを使用しているかを表示します。

## フィールドの説明

|   フィールド名    |     型      | NULL許容   |    説明     |
|-----------|-------------|------------|-----------|
| TENANT_ID | bigint(20)  | NO         | テナントID     |
| SVR_IP    | varchar(46) | NO         | サーバーIPアドレス |
| SVR_PORT  | bigint(20)  | NO         | サーバーポート番号    |
| HOLD      | bigint(20)  | NO         | テナント使用メモリ、単位：バイト   |
| FREE      | bigint(21)  | NO         | テナント空きメモリ、単位：バイト    |

## クエリ例

ユーザーテナントが、現在のノード上での自身のテナントのメモリ使用状況を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_MEMORY;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+-----------+------------+
| TENANT_ID | SVR_IP         | SVR_PORT | HOLD      | FREE       |
+-----------+----------------+----------+-----------+------------+
|      1002 | 172.xx.xxx.xxx |     2882 | 725221376 | 4643487744 |
+-----------+----------------+----------+-----------+------------+
1 row in set
```
