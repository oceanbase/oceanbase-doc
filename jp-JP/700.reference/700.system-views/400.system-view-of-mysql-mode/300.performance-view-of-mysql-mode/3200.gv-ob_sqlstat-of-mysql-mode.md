# GV$OB_SQLSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_SQLSTAT` は、クラスタ内のSQLの基本的なパフォーマンス統計データを表示するために使用されます。各SQLステートメントが1行（つまり、それぞれの `SQL_ID` + `Plan_Hash` の一意な値が1行）となります。そのうち、 `_DELTA` を含む列は、前回のWRスナップショットから現在時刻までの間の統計値の増分を示します。
