# V$OB_PS<Item_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_PS<Item_INFO`は、prepared statementに対するモニタリング機能を提供するために使用され、PS Cache内のすべてのprepared statementの基本情報が含まれます。

## フィールドの説明

|      **フィールド名**       |     タイプ      | **NULLを許容するか** |             説明             |
|---------------------|-------------|----------------|----------------------------|
| TENANT_ID           | bigint(20)  | NO             | テナントID                      |
| SVR_IP              | varchar(46) | NO             | サーバーIPアドレス                  |
| SVR_PORT            | bigint(20)  | NO             | サーバーのポート番号                     |
| STMT_ID             | bigint(20)  | NO             | PS Cache内の対応するステートメントのstmt_id情報 |
| DB_ID               | bigint(20)  | NO             | prepareステートメントに関連するデータベースID       |
| PS_SQL              | longtext    | NO             | prepareのSQL情報           |
| PARAM_COUNT         | bigint(20)  | NO             | prepareのパラメータ数情報            |
| STMT_ITEM_REF_COUNT | bigint(20)  | NO             | stmt_itemの参照カウント情報          |
| STMT_INFO_REF_COUNT | bigint(20)  | NO             | stmt_infoの参照カウント情報          |
| MEM_HOLD            | bigint(20)  | NO             | このprepare stmtが占有するメモリサイズ     |
| STMT_TYPE           | bigint(20)  | NO             | このprepare stmtのタイプ情報       |
| CHECKSUM            | bigint(20)  | NO             | このprepare stmtのchecksum  |
| EXPIRED             | tinyint(4)  | NO             | このprepare stmtが有効期限切れかどうか                           |

## クエリ例

PS Cache内のすべての準備ステートメントの基本情報を確認し、最初のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PS_ITEM_INFO LIMiT 1\G
```
