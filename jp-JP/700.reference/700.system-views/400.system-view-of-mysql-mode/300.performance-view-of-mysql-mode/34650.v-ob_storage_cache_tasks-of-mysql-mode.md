# V$OB_STORAGE_CACHE_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このビューはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このビューはV4.3.5 BP2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上でキャッシュタスク情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールド説明

|      フィールド名    |         型          | NULL許容 |                       説明      |
|-----------------|-----------------------|----------------|---------------------------------|
| SVR_IP          | varchar(46)           | NO             |  OBServerノードのIPアドレス    |
| SVR_PORT        | bigint(20)            | NO             |  OBServerノードのポート番号      |
| TENANT_ID       | bigint(20)            | NO             |  Tabletが属するテナントID    |
| TABLET_ID       | bigint(20)            | NO             |  Tablet ID   |
| STATUS          | varchar(64)           | NO             |  キャッシュタスクの状態：<ul><li>`WAITING`：タスクの初期化中</li> <li>`DONIG`：タスクが実行中</li> <li>`FINISHED`：タスクが完了</li> <li>`SUSPENDED`：タスクが一時停止</li> <li>`CANCELED`：タスクがキャンセル</li> <li>`FAILED`：タスクの実行に失敗</li></ul>    |
| SPEED           | varchar(29)           | NO             |  Tabletの取得速度     |
| START_TIME      | timestamp(6)          | NO             |  キャッシュタスク開始時間    |
| COMPLETE_TIME   | timestamp(6)          | NO             |  キャッシュタスク終了時間    |
| RESULT          | bigint(20)            | NO             |  タスクの実行に失敗した場合、対応するエラーコードを表示    |
| COMMENT         | varchar(4096)         | NO             |  タスク失敗後の詳細なエラー説明。`trace_id`情報を含む    |
