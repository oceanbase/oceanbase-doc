# GV$OB_SESSION

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_SESSION` は、すべてのサーバーで作成されたセッション情報を記録するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| ID | bigint(20) unsigned | NO |  V4.3.x系について：<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>    |
| USER | varchar(32) | NO |  このセッションが属するユーザーを表します |
| TENANT | varchar(128) | NO |  アクセスするテナント名   |
| HOST | varchar(128) | NO | セッションを開始したクライアントのIPアドレスとポート番号を表します。ODPを介してデータベースに接続する場合は、ODPのホストIPアドレスとポート番号を表します   |
| DB | varchar(128) | YES |  このセッションが現在接続しているデータベース名を表します   |
| COMMAND | varchar(4096) | NO |  このセッションが実行中のコマンドを表します  |
| SQL_ID | varchar(32) | NO |  SQL ID情報   |
| TIME | bigint(21) | NO |  現在のコマンド実行時間を秒単位で表します。コマンドが再試行された場合は、リセットされて再計算されます   |
| STATE | varchar(128) | YES |  このセッションの現在の状態を表します   |
| INFO | varchar(262143) | YES |  このセッションが実行中の文を表します   |
| SVR_IP | varchar(46) | NO |  サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO |  サーバーのRPCポート番号   |
| SQL_PORT | bigint(20) | NO |  サーバーのSQLポート番号   |
| PROXY_SESSID | bigint(20) unsigned | YES |  現在のクライアントがODPの場合、この列にODPのセッションIDが表示されます   |
| USER_CLIENT_IP | varchar(46) | YES |  ユーザークライアントのIPアドレス   |
| USER_HOST | varchar(128) | YES |  ユーザークライアントのホスト名   |
| TRANS_ID | bigint(20) unsigned | NO |  トランザクションID   |
| THREAD_ID | bigint(20) unsigned | NO |  スレッドID   |
| TRACE_ID | varchar(64) | YES |  Trace ID   |
| REF_COUNT | bigint(20) | NO | 接続参照カウント |
| BACKTRACE | varchar(16384) | YES | 接続参照呼び出しスタック |
| TRANS_STATE | varchar(32) | YES |  トランザクションの状態（セッションにトランザクションがない場合はNULLを返す）：<ul><li>`IDLE`：アイドル状態。トランザクションが開始されていないことを示します。</li> <li>`ACTIVE`：明示的に開始されたトランザクション。`START TRANSACTION`、`BEGIN` などのステートメントで明示的に開始されます。</li> <li>`IMPLICIT_ACTIVE`：暗黙的に開始されたトランザクション。`autocommit = on`モードで、DMLなどデータを変更するステートメントを実行した後にトランザクションが開始されます。</li> <li>`ROLLBACK_SAVEPOINT`：トランザクションがセーブポイントまでロールバック中です。</li> <li>`IN_TERMINATE`：トランザクションが終了中です。内部的な理由による終了や、ユーザーが発行したトランザクション終了（例えば、`COMMIT`、`ROLLBACK` ステートメントの実行）が含まれます。</li> <li>`ABORTED`：異常が発生したため、トランザクションが内部的に終了またはロールバックされました。</li> <li>`ROLLED_BACK`：トランザクションがロールバックされました。</li> <li>`COMMIT_TIMEOUT`：トランザクションコミットタイムアウト。</li> <li>`COMMIT_UNKNOWN`：トランザクションコミット結果が不明です。</li> <li>`COMMITTED`：トランザクションが正常にコミットされました。</li></ul>   |
| USER_CLIENT_PORT | bigint(20)          | NO   | ユーザークライアントのポート番号 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.x系では、このフィールドはV4.4.0から導入されました。</p></main>  |
| TOTAL_CPU_TIME | bigint(21) | NO | 現在のコマンド実行CPU使用時間。単位は秒 |
