# V$OB_SERVER_SCHEMA_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ローカルマシンのスキーマ情報を表示します。

## フィールドの説明

|          **フィールド名**          |   **タイプ**    | **NULL許容** |              **説明**              |
|----------------------------|-------------|----------------|----------------------------------|
| SVR_IP                     | varchar(46) | NO             | サーバーのIPアドレス                        |
| SVR_PORT                   | bigint(20)  | NO             | サーバーのポート番号                           |
| TENANT_ID                  | bigint(20)  | NO             | テナントID                            |
| REFRESHED_SCHEMA_VERSION   | bigint(20)  | NO             | テナントがリフレッシュしたスキーマのバージョン                 |
| RECEIVED_SCHEMA_VERSION    | bigint(20)  | NO             | テナントがリフレッシュすべきスキーマのバージョン               |
| SCHEMA_COUNT               | bigint(20)  | NO             | 対応するスキーマバージョンにおける、各スキーマオブジェクト数の合計                   |
| SCHEMA_SIZE                | bigint(20)  | NO             | 対応するスキーマバージョンにおける、各スキーマオブジェクトが占有するメモリサイズの合計、単位はバイト                   |
| MIN_SSTABLE_SCHEMA_VERSION | bigint(20)  | NO             | テナントSSTableに記録されている最小schema_version |

## クエリ例

ユーザーテナントが現在のOBServerノード上のスキーマ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_SERVER_SCHEMA_INFO;
```

クエリ結果は次のとおりです。

```shell
+----------------+----------+-----------+--------------------------+-------------------------+--------------+-------------+----------------------------+
| SVR_IP         | SVR_PORT | TENANT_ID | REFRESHED_SCHEMA_VERSION | RECEIVED_SCHEMA_VERSION | SCHEMA_COUNT | SCHEMA_SIZE | MIN_SSTABLE_SCHEMA_VERSION |
+----------------+----------+-----------+--------------------------+-------------------------+--------------+-------------+----------------------------+
| 172.xx.xxx.xxx |     2882 |      1002 |         1735785545009528 |        1735785545009528 |         1774 |     1725881 |                         -1 |
+----------------+----------+-----------+--------------------------+-------------------------+--------------+-------------+----------------------------+
1 row in set
```
