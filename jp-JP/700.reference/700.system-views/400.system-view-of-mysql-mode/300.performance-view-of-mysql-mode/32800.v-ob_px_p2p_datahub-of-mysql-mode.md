# V$OB_PX_P2P_DATAHUB

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

パラレル実行されるデータ転送操作に関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| TRACE_ID | varchar(64) | NO | このデータに関連するSQLのTRACE_ID |
| DATAHUB_ID | bigint(20) | NO | このデータのDatahub ID |
| MESSAGE_TYPE | varchar(256) | NO | データが属するメッセージタイプ |
| TENANT_ID | bigint(20) | NO | 所属テナントID |
| HOLD_SIZE | bigint(20) | NO | マテリアライズされたデータサイズ |
| TIMEOUT_TS | datetime | NO | このデータの予想されるタイムアウト時間 |
| START_TIME | datetime | NO | 書き込み開始時間 |
