# V$OB_PS_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける現在のOBServerノード上のPS Cacheの全体的な状態を監視します。これには、ヒット率、メモリ使用量、キャッシュのアイテム数が含まれます。

## フィールドの説明

|     フィールド名     |     タイプ      | NULLを許容するか |         説明          |
|--------------|-------------|------------|---------------------|
| TENANT_ID    | bigint(20)  | NO         | テナントID               |
| SVR_IP       | varchar(46) | NO         | サーバーIPアドレス           |
| SVR_PORT     | bigint(20)  | NO         | サーバーのポート番号              |
| STMT_COUNT   | bigint(20)  | NO         | PS Cacheに現在キャッシュされているステートメント数 |
| HIT_COUNT    | bigint(20)  | NO         | PS Cacheの総ヒット回数     |
| ACCESS_COUNT | bigint(20)  | NO         | PS Cacheへのアクセス総回数    |
| MEM_HOLD     | bigint(20)  | NO         | PS Cacheが使用しているメモリ量（単位：バイト）    |

## クエリ例

ユーザーテナント内で、現在のノード上のPS Cacheの全体的な状態を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PS_STAT;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+------------+-----------+--------------+----------+
| TENANT_ID | SVR_IP         | SVR_PORT | STMT_COUNT | HIT_COUNT | ACCESS_COUNT | MEM_HOLD |
+-----------+----------------+----------+------------+-----------+--------------+----------+
|      1002 | 11.xxx.xxx.xxx |    28825 |          1 |         0 |            1 |    16384 |
+-----------+----------------+----------+------------+-----------+--------------+----------+
1 row in set
```
