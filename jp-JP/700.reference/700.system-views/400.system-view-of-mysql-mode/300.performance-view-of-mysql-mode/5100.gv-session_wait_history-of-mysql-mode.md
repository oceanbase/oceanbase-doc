# GV$SESSION_WAIT_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのOBServerノード上で、すべてのセッションにおける過去10回の待機イベント情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはServer Session IDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul> |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート |
| SEQ# | bigint(20) | NO | 待機イベントのシーケンス番号 |
| EVENT# | bigint(20) | NO | 待機イベントの番号 |
| EVENT | varchar(64) | NO | 待機イベントの名前 |
| P1TEXT | varchar(64) | NO | 待機イベントのパラメータ1の説明 |
| P1 | bigint(20) unsigned | NO | 待機イベントのパラメータ1の値 |
| P2TEXT | varchar(64) | NO | 待機イベントのパラメータ2の説明 |
| P2 | bigint(20) unsigned | NO | 待機イベントのパラメータ2の値 |
| P3TEXT | varchar(64) | NO | 待機イベントのパラメータ3の説明 |
| P3 | bigint(20) unsigned | NO | 待機イベントのパラメータ3の値 |
| WAIT_TIME | double | NO | 待機イベントの待機時間、単位は百分の一秒 |
| WAIT_TIME_MICRO | bigint(20) | NO | 待機イベントの待機時間、単位はマイクロ秒 |
| TIME_SINCE_LAST_WAIT_MICRO | bigint(20) | NO | 前回の待機終了から現在の待機までの時間、単位はマイクロ秒 |

## クエリ例

ユーザーテナント内で、このテナントのすべてのOBServerノード上におけるすべてのセッションの過去10回分の待機イベント情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSION_WAIT_HISTORY;
```
