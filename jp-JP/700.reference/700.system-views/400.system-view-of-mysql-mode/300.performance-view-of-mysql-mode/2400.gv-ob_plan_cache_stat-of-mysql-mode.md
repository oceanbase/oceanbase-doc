# GV$OB_PLAN_CACHE_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノード上で持つ各プランキャッシュ全体の状態を表示します。

## フィールドの説明

|     フィールド名     |     型      | NULL許容 |                説明                 |
|--------------|-------------|------------|-----------------------------------|
| TENANT_ID    | bigint(20)  | NO         | テナントID                             |
| SVR_IP       | varchar(46) | NO         | サーバーのIPアドレス                        |
| SVR_PORT     | bigint(20)  | NO         | ポート番号                               |
| SQL_NUM      | bigint(20)  | NO         | プランキャッシュに関連するSQL文数              |
| MEM_USED     | bigint(20)  | NO         | プランキャッシュで使用されているメモリ                |
| MEM_HOLD     | bigint(20)  | NO         | プランキャッシュが保持しているメモリ                  |
| ACCESS_COUNT | bigint(20)  | NO         | プランキャッシュへのクエリアクセス回数                |
| HIT_COUNT    | bigint(20)  | NO         | プランキャッシュへのヒット回数                 |
| HIT_RATE     | bigint(20)  | NO         | プランキャッシュのヒット率                   |
| PLAN_NUM     | bigint(20)  | NO         | プランの数                          |
| MEM_LIMIT    | bigint(20)  | NO         | プランキャッシュのメモリ上限、単位はバイト                  |
| HASH_BUCKET  | bigint(20)  | NO         | プランキャッシュのハッシュマップ内のバケットの数 |
| STMTKEY_NUM  | bigint(20)  | NO         | プランキャッシュ内のstmt_keyの数         |

## クエリ例

ユーザーテナント内で、自身のテナントがすべてのノード上で持つプランキャッシュの全体的な状態を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PLAN_CACHE_STAT;
```

```shell
1 row in set
```
