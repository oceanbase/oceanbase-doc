# GV$OB_LS_SNAPSHOTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_LS_SNAPSHOTS` は、すべてのUnitに永続化されたログストリームスナップショットの情報を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| SNAPSHOT_ID | bigint(20) | NO | スナップショットID |
| LS_ID | bigint(20) | NO | ログストリームID |
| SVR_IP | varchar(46) | NO | ログストリームが存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | ログストリームが存在するサーバーのポート番号 |
| META_EXISTED | varchar(3) | NO | スナップショットのメタ情報がUnitに保存されているかどうか（YES/NO） |
| BUILD_STATUS | varchar(10) | NO | スナップショットの作成状態 |
| REBUILD_SEQ_START | bigint(20) | YES | スナップショット作成開始時のログストリームのREBUILD SEQ（Sequence） |
| REBUILD_SEQ_END | bigint(20) | YES | スナップショット作成終了時のログストリームのREBUILD SEQ（Sequence） |
| END_INTERVAL_SCN | bigint(20) | YES | 再生終了SCNポイント |
| LS_META_PACKAGE | longtext | YES | 再生開始ポイントに対応するログストリームのメタデータ |
| TSNAP_IS_RUNNING | varchar(3) | NO | 対応テナントのスナップショットが実行中かどうか（YES/NO） |
| TSNAP_HAS_UNFINISHED_CREATE_DAG | varchar(3) | NO | 対応テナントのスナップショットで未完了のCreateタスクがあるかどうか（YES/NO） |
| TSNAP_HAS_UNFINISHED_GC_DAG | varchar(3) | NO | 対応テナントのスナップショットで未完了のGCタスクがあるかどうか（YES/NO） |
| TSNAP_CLONE_REF | bigint(20) | YES | 対応テナントのスナップショットのクローンタスク数 |
| TSNAP_META_EXISTED | varchar(3) | NO | 対応テナントのスナップショットのメタ情報がUnitに保存されているかどうか（YES/NO） |
