# V$RSRC_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在アクティブなテナントのリソース管理計画を表示します。

## フィールドの説明

|            フィールド名            |      タイプ       | NULLを許容するか |                       説明                       |
|----------------------------|---------------|------------|--------------------------------------------------------------------------------|
| ID                         | decimal(10,0)        | NO         | リソース計画ID。グローバルに一意です                                  |
| NAME                       | varchar(128) | NO         | リソース計画名                                        |
| IS_Top_PLAN                | varchar(5)   | NO         | 現在のリソース計画が現在設定されているトップレベルの計画であるかどうか：<ul><li> `TRUE`：現在のリソース計画が現在設定されているトップレベルの計画であることを示します    </li><li> `FALSE`：現在のリソース計画が現在のトップレベルの計画のサブ計画であることを示します</li></ul>  <br>  現在、OceanBaseデータベースではこの値は固定されており、`TRUE` となります |
| CPU_MANAGED                | varchar(3)   | NO         | 現在のリソース計画でCPU利用率を管理するためのパラメータが設定されているかどうか：<ul><li>`ON`：設定済み    </li><li> `OFF`：未設定</li></ul>  </br>現在、OceanBaseデータベースではこの値は固定されており、`ON` となります                               |
| INSTANCE_CAGING            | varchar(3)   | NO         | 互換性のためにのみ使用され、現在この値は固定されており、`NULL` となります                          |
| PARALLEL_SERVERS_ACTIVE    | decimal(10,0)        | NO         | 互換性のためにのみ使用され、現在この値は固定されており、`NULL` となります                          |
| PARALLEL_SERVERS_TOTAL     | decimal(10,0)        | NO         | 互換性のためにのみ使用され、現在この値は固定されており、`NULL` となります                          |
| PARALLEL_EXECUTION_MANAGED | varchar(32)  | NO         | 互換性のためにのみ使用され、現在この値は固定されており、`NULL` となります                          |

## クエリ例

ユーザーテナントが現在のアクティブなテナントのリソース管理計画を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$RSRC_PLAN;
```

クエリ結果は次のとおりです：

```shell
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| ID   | NAME    | IS_TOP_PLAN | CPU_MANAGED | INSTANCE_CAGING | PARALLEL_SERVERS_ACTIVE | PARALLEL_SERVERS_TOTAL | PARALLEL_EXECUTION_MANAGED |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| NULL | daytime | TRUE        | ON          | NULL            |                    NULL |                   NULL | NULL                       |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
1 row in set
```
