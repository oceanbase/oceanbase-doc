# GV$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべてのノード上でのTabletレベルのCompactionの進捗状況を表示します。

## フィールドの説明

|             フィールド名             |      タイプ      | NULLを許容するか |                                            説明                                            |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | サーバーのIPアドレス                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | サーバーのポート番号|
| TENANT_ID                    | bigint(20)   | NO         | テナントID |
| TYPE                         | varchar(64)  | NO         | コンパクションのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なコンパクションタイプ。指定された時間点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>   |
| LS_ID                        | bigint(20)   | NO         | ログストリームID|
| TABLET_ID                    | bigint(20)   | NO         | データシャードID                                                                                  |
| COMPACTION_SCN                      | bigint(20) unsigned   | NO         | コンパクションバージョン情報|
| TASK_ID                      | varchar(64)  | NO         | 実行されるトレース                                                                                |
| STATUS                       | varchar(15)  | NO         | タスクの状態  |
| DATA_SIZE                    | bigint(20)   | NO         | コンパクションが必要な総データ量、単位はバイト   |
| UNFINISHED_DATA_SIZE         | bigint(20)   | NO         | 未完了のコンパクションのデータ量、単位はバイト   |
| PROGRESSIVE_COMPACTION_round | bigint(20)   | NO         | 減算コンパクションラウンド|
| CREATE_TIME                  | timestamp(6) | NO         | タスク作成時間|
| START_TIME                   | timestamp(6) | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME        | timestamp(6) | NO         | 予想完了時間|
