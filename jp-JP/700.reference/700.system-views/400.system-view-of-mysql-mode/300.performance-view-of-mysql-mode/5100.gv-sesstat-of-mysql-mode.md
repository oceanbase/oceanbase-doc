# GV$SESSTAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$SESSTAT`は、すべてのOBServerノードのセッションレベルの統計イベント情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | V4.3.x系について：<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード / ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | 情報が存在するサーバーのポート番号 |
| STATISTICS# | bigint(20) | NO | 統計イベントのインデックス |
| VALUE | bigint(20) | NO | 統計イベントの発生回数 |

## クエリ例

すべてのOBServerノードのセッションレベルの統計イベント情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSTAT LIMIT 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SID: 1152921504606863376
    CON_ID: 1002
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
