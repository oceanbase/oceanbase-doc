# GV$OB_SHARED_STORAGE_QUOTA

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上のI/Oアクセスリソース情報を表示します。

## フィールドの説明

| フィールド名     | 型          | NULL許容 | 説明                                                        |
|-------------|---------------|----------------|-------------------------------------------------------------|
| SVR_IP      | varchar(46)   | NO   | OBServerノードのIPアドレス    |
| SVR_PORT    | bigint(20)    | NO   | OBServerノードのポート番号     |
| ENDPOINT    | varchar(256)  | NO   | このフィールドの値は空になります。     |
| PATH        | varchar(1024) | NO   | オブジェクトストレージのパス。</br>このパスで一般的に使用されるタイプは以下のとおりです：`local://`、`oss://`、`file://`、`s3://` 等。   |
| CLASS_ID    | bigint(20)    | NO   | マーカー用ID。オブジェクトストレージのBucketの用途によって、意味が異なります：<ul><li>Bucketがclogストレージまたはデータストレージに使用される場合、このフィールドは無意味で、値は`0`です。</li> <li>Bucketがバックアップ・リカバリ、データインポート、エクスポートなどのタスクに使用される場合、このフィールドの意味はテナントIDです。</li></ul>      |
| TYPE        | varchar(32)   | NO   | 指標タイプ。主なタイプは以下のとおりです：<ul><li>`IPS`：1秒間の命令数</li> <li>`OPS`：1秒間に実行される操作数</li> <li>`IOPS`：1秒間の入出力操作数</li> <li>`IBW`：入力帯域幅</li> <li>`OBW`：出力帯域幅</li> <li>`IOBW`：入出力帯域幅</li> <li>`TAG`：ユーザー設定のタグ情報</li></ul>     |
| REQUIREMENT | bigint(20)    | NO   | サーバーが必要とする各種リソース    |
| ASSIGN      | bigint(20)    | NO   | サーバーに対してスロットリングアルゴリズムによって指定された各種リソースの上限値     |

## クエリ例

ユーザーテナント内で、clogストレージやデータストレージなどのシナリオについて、すべてのOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。バックアップ・リカバリ、データインポート、エクスポートなどのシナリオでは、当該テナントのすべてのOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SHARED_STORAGE_QUOTA;
```
