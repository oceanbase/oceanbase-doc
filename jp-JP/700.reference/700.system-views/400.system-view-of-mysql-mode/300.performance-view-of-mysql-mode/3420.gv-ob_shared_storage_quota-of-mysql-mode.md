# GV$OB_SHARED_STORAGE_QUOTA

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上のI/Oアクセスリソース情報を表示します。

## フィールドの説明

| フィールド名     | 型          | NULL許容 | 説明                                                        |
|-------------|---------------|----------------|-------------------------------------------------------------|
| SVR_IP      | varchar(46)   | NO   | OBServerノードのIPアドレス    |
| SVR_PORT    | bigint(20)    | NO   | OBServerノードのポート番号     |
| ENDPOINT    | varchar(256)  | NO   | 共有ストレージのEndpoint。Shared-Nothing (SN)モードでは、このフィールドの値は空になります。     |
| PATH        | varchar(1024) | NO   | オブジェクトストレージのパス。Shared-Nothing (SN)モードでは、ローカルパスとして表示されます。</br>このパスでよく使われるタイプは、`local://`、`oss://`、`file://`、`s3://`などです。   |
| CLASS_ID    | bigint(20)    | NO   | マーカーID。オブジェクトストレージのBucketの用途に応じて、異なる意味を持ちます：<ul><li>Bucketがclogストレージまたはデータストレージに使用される場合、このフィールドは無意味で、値は`0`です。</li> <li>Bucketがバックアップ・リストア、データインポート、エクスポートなどのタスクに使用される場合、このフィールドはテナントIDを表します。</li></ul>      |
| TYPE        | varchar(32)   | NO   | 指標タイプ。主なタイプは以下の通りです：<ul><li>`IPS`：1秒間の命令数</li> <li>`OPS`：1秒間に実行される操作数</li> <li>`IOPS`：1秒間に入力または出力される操作数</li> <li>`IBW`：入力帯域幅</li> <li>`OBW`：出力帯域幅</li> <li>`IOBW`：入力または出力帯域幅</li> <li>`TAG`：ユーザー設定のタグ情報</li></ul>     |
| REQUIREMENT | bigint(20)    | NO   | サーバーが必要とする各種リソース    |
| ASSIGN      | bigint(20)    | NO   | サーバーに割り当てられた制限アルゴリズムによって指定された各種リソースの上限     |

## クエリ例

ユーザーテナント内で、clogストレージやデータストレージなどのシナリオについて、すべてのOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。バックアップ・リストア、データインポート、エクスポートなどのシナリオについては、そのテナントのすべてのOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SHARED_STORAGE_QUOTA;
```
