# V$RESTORE_POINT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBase データベース V4.x バージョンは、現在 Restore Point 機能をサポートしていないため、このビューは V4.0.0 バージョン以降の削除されました。</p>
</main>

## 機能の概要

ビュー `V$RESTORE_POINT` は、復元ポイントに関する情報を表示するために使用されます。

## フィールドの説明

| **フィールド名**  |    **タイプ**    | **NULL許容** |     **説明**     |
|-----------|--------------|----------------|----------------|
| TENANT_ID | bigint(20)   | YES            | テナントID          |
| SNAPSHOT  | bigint(20)   | NO             | 復元ポイント作成時のデータベースSCN |
| TIME      | timestamp(6) | NO             | 復元ポイント作成時の時間      |
| NAME      | varchar(512) | YES            | 復元ポイント名          |

## クエリ例

現在のテナント内のすべての復元ポイント情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$RESTORE_POINT;
```

クエリ結果は次のとおりです。

```shell
+-----------+------------------+----------------------------+----------+
| TENANT_ID | SNAPSHOT         | TIME                       | NAME     |
+-----------+------------------+----------------------------+----------+
|      1001 | 1710987516261317 | 2024-03-21 10:18:36.263262 | rt1      |
|      1001 | 1710987957553230 | 2024-03-21 10:25:57.554246 | rt_mysql |
+-----------+------------------+----------------------------+----------+
2 rows in set
```
