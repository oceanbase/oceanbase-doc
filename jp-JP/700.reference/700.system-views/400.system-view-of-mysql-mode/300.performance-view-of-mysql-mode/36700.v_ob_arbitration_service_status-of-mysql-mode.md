# V$OB_ARBITRATION_SERVICE_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントノードとアービトレーションサービス間の通信状態を表示します。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | ローカルIPアドレス |
| SVR_PORT | bigint(20) | NO | ローカルRPCポート |
| ARBITRATION_SERVICE_ADDRESS | varchar(512) | NO | アービトレーションサービスのアドレス |
| STATUS | varchar(46) | NO | Serverとアービトレーションサービス間の通信状態。値は以下のとおりです。<ul><li>  `ACTIVE`：アービトレーションサービスとローカル間の通信が正常であることを示します。</li><li> `INACTIVE`：アービトレーションサービスとローカル間で通信できないことを示します。</li></ul>|

## クエリ例

現在のテナントノードとアービトレーションサービス間の通信状態を確認します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.V$OB_ARBITRATION_SERVICE_STATUS;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------------------------+--------+
| SVR_IP         | SVR_PORT | ARBITRATION_SERVICE_ADDRESS | STATUS |
+----------------+----------+-----------------------------+--------+
| xxx.xx.xxx.207 |     2882 | xxx.xx.xxx.224:2882         | ACTIVE |
+----------------+----------+-----------------------------+--------+
1 row in set
```
