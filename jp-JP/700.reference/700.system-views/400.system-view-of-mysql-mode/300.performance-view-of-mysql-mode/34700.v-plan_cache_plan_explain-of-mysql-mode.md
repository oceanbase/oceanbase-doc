# V$OB_PLAN_CACHE_PLAN_EXPLAIN

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_PLAN_CACHE_PLAN_EXPLAIN`は、現在のOBServerノードの計画キャッシュにキャッシュされている物理実行計画を表示するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>このビューはGet操作のみをサポートしており、クエリ時には <code>TENANT_ID</code> と <code>PLAN_ID</code> フィールドを指定する必要があります。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULL値の許容** |      **説明**      |
|--------------|---------------|------------|------------------|
| TENANT_ID    | bigint(20)    | NO         | テナントID            |
| SVR_IP       | varchar(46)   | NO         | サーバーIPアドレス        |
| SVR_PORT     | bigint(20)    | NO         | サーバーのポート番号           |
| PLAN_ID      | bigint(20)    | NO         | プランのID           |
| PLAN_DEPTH   | bigint(20)    | NO         | Operator表示時の深さ |
| PLAN_LINE_ID | bigint(20)    | NO         | Operatorの番号     |
| OPERATOR     | varchar(128)  | NO         | Operatorの名前     |
| NAME         | varchar(256)  | NO         | テーブル名             |
| ROWS         | bigint(20)    | NO         | 予想される結果行数          |
| COST         | bigint(20)    | NO         | 予想されるコスト            |
| PROPERTY     | varchar(4096) | NO         | 対応するOperatorの情報  |

## クエリ例

現在のOBServerノードの計画キャッシュにキャッシュされている物理実行計画を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PLAN_CACHE_PLAN_EXPLAIN limit 1;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+---------+------------+--------------+-----------+------+------+------+----------+
| TENANT_ID | SVR_IP         | SVR_PORT | PLAN_ID | PLAN_DEPTH | PLAN_LINE_ID | OPERATOR  | NAME | ROWS | COST | PROPERTY |
+-----------+----------------+----------+---------+------------+--------------+-----------+------+------+------+----------+
|         1 |   xx.xx.xx.xx  |     2882 |    7699 |          0 |            0 | PHY_LIMIT | NULL |    1 | 1306 | NULL     |
+-----------+----------------+----------+---------+------------+--------------+-----------+------+------+------+----------+
1 row in set (0.006 sec)
```
