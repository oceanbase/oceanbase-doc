# GV$OB_PX_WORKER_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

パラレル実行シナリオにおいて、現在のテナントがすべてのOBServerノード上で各スレッドの実行情報を表示します。

## フィールドの説明

|  **フィールド名**  |      型        | **NULL許容** |       説明       |
|------------|--------------|----------------|----------------|
| SESSION_ID | bigint(20)   | NO             | V4.3.x系について：<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード / ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>     |
| TENANT_ID  | bigint(20)   | NO             | テナントID          |
| SVR_IP     | varchar(46)  | NO             | サーバーのIPアドレス     |
| SVR_PORT   | bigint(20)   | NO             | サーバーポート          |
| TRACE_ID   | varchar(128) | NO             | SQLのtrace_id |
| QC_ID      | bigint(20)   | NO             | px内のqc_id    |
| SQC_ID     | bigint(20)   | NO             | px内のsqc_id   |
| WORKER_ID  | bigint(20)   | NO             | スレッドID          |
| DFO_ID     | bigint(20)   | NO             | px内のdfo_id   |
| START_TIME | timestamp(6) | NO             | スレッド開始実行時間      |

## クエリ例

ユーザーテナント内で、パラレル実行シナリオにおいて、当該テナントがすべてのOBServerノード上のすべてのスレッドの実行情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PX_WORKER_STAT\G
```
