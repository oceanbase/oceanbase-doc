# V$OB_SS_SSTABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントの共有ストレージ上のSSTable情報を表示します。

<main id="notice" >
<h4>適用対象</h4>
<p>このビューは共有ストレージ(SS)モードでのみ適用されます。シェアードナッシング(SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールド説明

|          フィールド名        |     型    | NULL許容 |     説明                        |
|-------------------------|-------------|----------------|---------------------------------|
| TENANT_ID               | bigint(20)  | NO   |  テナントID           |
| LS_ID                   | bigint(20)  | NO   |  ログストリームID          |
| TABLET_ID               | bigint(20)  | NO   |  パーティションID           |
| TRANSFER_SCN            | bigint(20)  | NO   |  Transferバージョン番号          |
| TABLE_TYPE              | varchar(20) | NO   |  SSTableタイプ。MAJOR、MINOR、MINI、META、DDL_DUMP、CO_MAJOR、NORMAL_CG、ROWKEY_CG、COL_ORIENTED_META、DDL_MERGE_CO、DDL_MERGE_CG、DDL_MEM_CO、DDL_MEM_CG、DDL_MEM_MINI_SSTABLE、MDS_MINI、MDS_MINOR、INVALIDなどが含まれる          |
| CG_IDX                  | bigint(20)  | NO   |  カラムストアデータに対応するSSTableの列番号          |
| START_LOG_SCN           | bigint(20)  | NO   |  SSTableの左端          |
| END_LOG_SCN             | bigint(20)  | NO   |  SSTableの右端          |
| DATA_CHECKSUM           | bigint(20)  | NO   |  データチェックサム          |
| SIZE                    | bigint(20)  | NO   |  SSTableが実際に使用しているディスク容量（バイト単位）          |
| REC_SCN                 | bigint(20)  | NO   |  このSSTableをアップロードした後に必要なログ再生ポイント          |
| UPPER_TRANS_VERSION     | bigint(20)  | NO   |  SSTable内で最大のトランザクションコミットバージョン番号         |
| CONTAIN_UNCOMMITTED_ROW | varchar(3)  | NO   |  未コミットデータを含むかどうか          |

## クエリ例

ユーザーテナント内で、指定されたログストリームの指定された`TABLET_ID`に対応するSSTable情報を確認します。

```shell
obclient> SELECT * FROM oceanbase.V$OB_SS_SSTABLES WHERE LS_ID=1 AND TABLET_ID=60263;
```
