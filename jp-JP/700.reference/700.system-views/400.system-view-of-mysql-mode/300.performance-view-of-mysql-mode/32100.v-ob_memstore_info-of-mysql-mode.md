# V$OB_MEMSTORE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>V$MEMSTORE_INFO</code> は、V4.0.0バージョン以降、<code>V$OB_MEMSTORE_INFO</code> に名称が変更されました。V4.0.0以降のバージョンでは、新しいビュー名 <code>V$OB_MEMSTORE_INFO</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>V$MEMSTORE_INFO</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

現在のテナントが現在のサーバー上に持つすべてのパーティションのMemTableの詳細情報を表示します。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート |
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリーム |
| TABLE_ID | bigint(20) | NO | データシャーディングID |
| IS_ACTIVE | varchar(3) | NO | アクティブかどうか |
| START_SCN | bigint(20) unsigned | NO | ストレージ開始ポイント |
| END_SCN | bigint(20) unsigned | NO | ストレージ終了ポイント |
| FREEZE_TS | bigint(20) | NO | 凍結された時刻 |

## クエリ例

ユーザーテナントが、現在のサーバー上にある自身のテナントのすべてのパーティションのMemTableの詳細情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_MEMSTORE_INFO;
```
