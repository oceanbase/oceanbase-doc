# GV$SQL_PLAN_MONITOR

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$SQL_PLAN_MONITOR`は、このテナント内のすべてのOBServerノードにおけるスロークエリのOperationレベルの統計を表示するために使用されます。各スロークエリの各Operationについて統計情報が提供されます。
