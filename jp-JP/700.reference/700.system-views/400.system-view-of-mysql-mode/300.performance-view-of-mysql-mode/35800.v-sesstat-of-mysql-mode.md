# V$SESSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、現在のOBServerノード上でのセッションレベルの統計イベントの概要を表示します。ここで、`STATISTIC#` は統計項目の番号を表し、ビュー `V$STATNAME` から対応する統計項目の番号に対応する統計項目名とその意味を照会できます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはServerセッションIDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはServerセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ<code>client_session_id_version = 2</code>の場合、このフィールドはClientセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code>の場合、このフィールドはServerセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | 情報が存在するServerのIPアドレス |
| SVR_PORT | bigint(20) | NO | 情報が存在するServerのポート番号 |
| STATISTICS# | bigint(20) | NO | 統計イベントのインデックス |
| VALUE | bigint(20) | NO | 統計イベントの発生回数 |

## クエリ例

ユーザーテナント内で、現在のOBServerノード上におけるテナント自身のセッションレベルの統計イベント情報を確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSTAT LIMIT 10;
```
