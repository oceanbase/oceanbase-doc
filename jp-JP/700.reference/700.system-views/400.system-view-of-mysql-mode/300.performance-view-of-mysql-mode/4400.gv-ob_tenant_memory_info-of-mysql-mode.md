# GV$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのノード上で使用しているメモリ状況を表示します。

## フィールドの説明

|   フィールド名    |     型      | NULL許容   |   説明    |
|-----------|-------------|------------|---------|
| TENANT_ID | bigint(20)  | NO         | テナントID   |
| SVR_IP    | varchar(46) | NO         | マシンのIPアドレス  |
| SVR_PORT  | bigint(20)  | NO         | マシンのポート番号  |
| HOLD      | bigint(20)  | NO         | テナント使用済みメモリ、単位：バイト |
| FREE      | bigint(21)  | NO         | テナント空きメモリ、単位：バイト  |

## クエリ例

ユーザーテナントが自身のテナントがすべてのノード上でどの程度のメモリを使用しているかを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_MEMORY;
```

クエリ結果は次のとおりです：

```shell

3 rows in set
```
