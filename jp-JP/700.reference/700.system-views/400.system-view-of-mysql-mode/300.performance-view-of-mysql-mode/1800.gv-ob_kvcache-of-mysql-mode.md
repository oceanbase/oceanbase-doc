# GV$OB_KVCACHE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントの各OBServerノード上のKVcache情報を表示します。

## フィールドの説明

|      フィールド名      |      タイプ       | NULL値を許容するか |    説明     |
|----------------|---------------|------------|-----------|
| SVR_IP         | varchar(46)   | NO         | サーバーIPアドレス |
| SVR_PORT       | bigint(20)    | NO         | サーバーのポート番号 |
| TENANT_ID      | bigint(20)    | NO         | テナントID     |
| CACHE_NAME     | varchar(128)  | NO         | Cache項目名 |
| PRIORITY       | bigint(20)    | NO         | 優先順位       |
| CACHE_SIZE     | bigint(20)    | NO         | Cacheサイズ、単位はバイト |
| HIT_RATIO      | decimal(38,3) | NO         | 命中率       |
| TOTAL.PUT_CNT  | bigint(20)    | NO         | PUT回数    |
| TOTAL_HIT_CNT  | bigint(20)    | NO         | 命中回数      |
| TOTAL_miss_CNT | bigint(20)    | NO         | ミス回数     |

## クエリ例

ユーザーテナントは、各OBServerノード上のKVcache情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_KVCACHE;
```
