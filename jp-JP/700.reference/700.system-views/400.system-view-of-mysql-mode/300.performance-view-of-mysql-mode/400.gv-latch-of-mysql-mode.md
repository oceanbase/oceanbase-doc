# GV$LATCH

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.x系では、機能の調整により、このビューはV4.2.5以降のバージョンからデータを記録しなくなりました。ロック診断関連データは、<a href="../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/6100.gv-system_event-of-mysql-mode.md">GV$SYSTEM_EVENT</a>ビューおよび<a href="../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/800.gv-ob_active_session_history-of-mysql-mode.md">GV$OB_ACTIVE_SESSION_HISTORY</a>ビューで確認できます。</p>
</main>

## 機能の概要

クラスタ内のすべてのOBServerノードのLatch情報を表示するビューです。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | IPアドレス |
| SVR_PORT | bigint(20) | NO | ポート番号 |
| ADDR | varchar(256) | NO | 現在はNULL |
| LATCH# | bigint(20) | NO | latchが所属するクラスのインデックス |
| LEVEL# | bigint(20) | NO | latchが所属するレベルのインデックス |
| NAME | varchar(256) | NO | latchの名前 |
| HASH | bigint(20) | NO | この値は現在0です |
| GETS | bigint(20) | NO | ロック成功回数 |
| MISSES | bigint(20) | NO | ロック待機回数 |
| SLEEPS | bigint(20) | NO | 合計yield回数 |
| IMMEDIATE_GETS | bigint(20) | NO | try_lock成功回数 |
| IMMEDIATE_MISSES | bigint(20) | NO | try_lock失敗回数 |
| SPIN_GETS | bigint(20) | NO | 合計spin回数 |
| WAIT_TIME | bigint(20) | NO | 待機sleep時間 |
