# V$STATNAME

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべての統計イベントの関連定義を表示します。

## フィールドの説明

|   **フィールド名**   |   **タイプ**    | **NULL値を許容するか** |   **説明**    |
|--------------|-------------|----------------|-------------|
| CON_ID       | bigint(20)  | NO             | テナントのID      |
| STAT_ID      | bigint(20)  | NO             | 統計イベントのID    |
| STATISTICS#  | bigint(20)  | NO             | 統計イベントのインデックス     |
| NAME         | varchar(64) | NO             | 統計イベントの名前     |
| DISPLAY_NAME | varchar(64) | NO             | 統計イベントのエイリアス     |
| CLASS        | bigint(20)  | NO             | 統計イベントが属するタイプの別名 |

## クエリ例

このテナントのすべての統計イベントの関連定義を確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$STATNAME LIMIT 10;
```
