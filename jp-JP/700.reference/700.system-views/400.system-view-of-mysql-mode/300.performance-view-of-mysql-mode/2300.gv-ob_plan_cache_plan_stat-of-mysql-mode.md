# GV$OB_PLAN_CACHE_PLAN_STAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.0.0以降、このビューの名前はGV$PLAN_CACHE_PLAN_STATからGV$OB_PLAN_CACHE_PLAN_STATに変更されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_PLAN_CACHE_PLAN_STAT` は、現在のテナントがすべてのOBServerノード上のプランキャッシュにキャッシュされている各キャッシュオブジェクトの状態を表示します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>このビューはSQL計画オブジェクトだけでなく、PLオブジェクト（匿名ブロック、PLパッケージ、PL関数など）もキャッシュします。一部のフィールドは特定のオブジェクトにのみ有効です。</p>
  </main>
