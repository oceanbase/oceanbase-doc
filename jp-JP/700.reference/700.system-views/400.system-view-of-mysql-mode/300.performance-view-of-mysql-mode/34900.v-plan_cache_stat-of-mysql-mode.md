# V$OB_PLAN_CACHE_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上で各計画キャッシュ全体の状態を表示します。

## フィールドの説明

|     フィールド名     |     タイプ      | NULLを許容するか |                説明                 |
|--------------|-------------|------------|-----------------------------------|
| TENANT_ID    | bigint(20)  | NO         | テナントID                             |
| SVR_IP       | varchar(46) | NO         | サーバーのIPアドレス                        |
| SVR_PORT     | bigint(20)  | NO         | サーバーのポート番号                               |
| SQL_NUM      | bigint(20)  | NO         | plan_cacheに関連するSQL文の数              |
| MEM_USED     | bigint(20)  | NO         | plan_cacheで使用済みのメモリ、単位はバイト                |
| MEM_HOLD     | bigint(20)  | NO         | plan_cacheが保持しているメモリ、単位はバイト                  |
| ACCESS_COUNT | bigint(20)  | NO         | plan_cacheへのクエリアクセス回数                 |
| HIT_COUNT    | bigint(20)  | NO         | plan_cacheへのヒット回数                 |
| HIT_RATE     | bigint(20)  | NO         | plan_cacheのヒット率                   |
| PLAN_NUM     | bigint(20)  | NO         | planの数                          |
| MEM_LIMIT    | bigint(20)  | NO         | plan_cacheのメモリ上限、単位はバイト                  |
| HASH_BUCKET  | bigint(20)  | NO         | plan_cache hash map内のBucketの数 |
| STMTKEY_NUM  | bigint(20)  | NO         | plan_cache内のstmt_keyの数         |

## クエリ例

ユーザーテナント内で、現在のノード上における当該テナントの計画キャッシュ全体の状態を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PLAN_CACHE_STAT;
```

```shell

|      1002 | 11.xxx.xxx.xxx |    28825 |     462 |  5906439 | 75497472 |      4828434 |   4824966 |       99 |      462 | 214748360 |       49157 |           0 |

```
