# GV$OB_RPC_INCOMING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントがすべてのOBServerノードで受信したRPCリクエストの統計情報を表示します。

## フィールド説明

|    **フィールド名**    |    **型**    | **NULL許容** |        **説明**         |
|----------------|--------------|----------------|-----------------------|
| TENANT_ID      | bigint(20)   | NO             | テナントID                 |
| SVR_IP         | varchar(46)  | NO             | IPアドレス                 |
| SVR_PORT       | bigint(20)   | NO             | ポート番号                   |
| PCODE          | bigint(20)   | NO             | RPCパケットコード           |
| PCODE_NAME     | varchar(256) | NO             | RPCパケットコードに対応する名前 |
| COUNT          | bigint(20)   | NO             | この種類のRPCリクエストを受信した回数   |
| TOTAL_SIZE     | bigint(20)   | NO             | 受信データサイズの合計               |
| NET_TIME       | bigint(20)   | NO             | ネットワーク時間                  |
| WAIT_TIME      | bigint(20)   | NO             | 受信からリクエストがキューに入るまでの時間       |
| QUEUE_TIME     | bigint(20)   | NO             | キュー待ち時間             |
| PROCESS_TIME   | bigint(20)   | NO             | 実際の処理にかかった時間             |
| LAST_TIMESTAMP | timestamp(6) | NO             | 最終更新時刻               |
| DCOUNT         | bigint(20)   | NO             | 各Pcode RPCのリクエスト数、統計期間は30秒                     |

## クエリ例

ユーザーテナント内で、そのテナントがすべてのノードから受信したRPCリクエストのうち、キューでの待機時間が1秒を超えるリクエストを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_RPC_INCOMING WHERE QUEUE_TIME > 1000000;
```
