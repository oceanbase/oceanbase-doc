# GV$SQL_WORKAREA_HISTOGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のすべてのノードにおける、過去のすべてのワークエリアで実行された統計情報を表示します。例えば、1MB～2MBの範囲で完全にインメモリ処理された回数や、ワンパス処理の回数などです。

## フィールドの説明

|        **フィールド名**        |   **型**   | **NULL許容** |                  **説明**                  |
|------------------------|------------|----------------|------------------------------------------|
| LOW_OPTIMAL_SIZE       | bigint(20) | NO             | workareaがoptimalモードで使用する最小メモリ量             |
| HIGH_OPTIMAL_SIZE      | bigint(20) | NO             | workareaがoptimalモードで使用する最大メモリ量             |
| OPTIMAL_EXECUTIONS     | bigint(20) | NO             | workareaが最低および最高範囲でoptimalモードで実行した回数             |
| ONEPASS_EXECUTIONS     | bigint(20) | NO             | workareaが最低および最高範囲でワンパスモードで実行した回数     |
| MULTIPASSES_EXECUTIONS | bigint(20) | NO             | workareaが最低および最高範囲でマルチパスモードで実行した回数 |
| TOTAL_EXECUTIONS       | bigint(20) | NO             | workareaの総実行回数                         |
| CON_ID                 | bigint(20) | NO             | テナントID                                    |
| SVR_IP                 | varchar(46)   | NO             | サーバーIPアドレス                   |
| SVR_PORT                 | bigint(20)   | NO             | サーバーポート番号                   |

## クエリ例

テナント内のすべてのノードにおける、過去のすべてのWorkareaで実行された統計情報を確認し、上位10件のレコードを表示します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.GV$SQL_WORKAREA_HISTOGRAM LIMIT 10;
```
