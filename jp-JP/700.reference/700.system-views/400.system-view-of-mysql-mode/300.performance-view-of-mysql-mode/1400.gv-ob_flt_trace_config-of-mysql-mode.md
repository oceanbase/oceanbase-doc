# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

フルトレースの診断情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| TYPE | varchar(16) | NO | 診断情報のモニタリングレベル  </li><li>module/actionレベル：モジュールおよび操作レベルで診断情報をモニタリング </li><li>client_identifierレベル：クライアント識別子レベルで診断情報をモニタリング </li></ul> |
| TENANT_NAME | varchar(128) | NO | テナント名 |
| MODULE_NAME | varchar(4096) | NO | Module名 |
| ACTION_NAME | varchar(4096) | NO | Action名 |
| CLIENT_IDENTIFIER | varchar(65) | NO | Client Identifier名 |
| LEVEL | bigint(20) | NO | このセッションのエンドツーエンドトレースモニタリングレベルを示します。例えば、1はレベル1の診断情報を示します |
| SAMPLE_PERCENTAGE | bigint(20) | NO | このセッションのエンドツーエンドトレースのサンプリング頻度を示します。 例えば、50は診断情報のサンプリングを50％の確率で行うことを示します |
| RECORD_POLICY | varchar(32) | NO | このセッションのエンドツーエンドトレース記録ポリシーを示します。主に以下の3種類のポリシーをサポートしています：<ul><li>ALL：すべてのヒットサンプリングでTraceが有効になっているTraceのトレース情報は、ログファイルに出力され、各span終了時にログファイルに出力されます。 </li><li>ONLY_SLOW_QUERY：すべてのヒットサンプリングでTraceが有効になっているTraceのトレース情報のうち、Slow Queryに属するリクエストTraceはログファイルに出力され、その他は破棄されます。この出力ポリシーでは、Traceログの出力タイミングはリクエスト終了後にSlow Queryと判断された場合にのみ出力されます。Proxyでは、ルートspan、つまりトランザクションレベルのspanは、Slow Queryが検出された場合にのみルートspanが出力されます。 </li><li>SAMPLE_AND_SLOW_QUERY：すべてのヒットサンプリングでTraceが有効になっているTraceのトレース情報のうち、以下の条件を満たすTraceはすべてログファイルに出力されます：<ol><li>隠し構成パラメータ <code>_print_sample_ppm</code> を使用して1万分の1の確率でサンプリングし、サンプリング結果が選択された場合にのみログに出力されます</li><li>ONLY_SLOW_QUERY モードの出力条件を満たす</li></ol>このモードでは、ログの出力タイミングもspan終了時ではありません。条件1を満たす場合、クライアント上でそのTraceログが強制的に出力されるとマークされ、その情報は後続のリンクコンポーネントに渡されます：条件2を満たす場合、出力タイミングはONLY_SLOW_QUERYと同じです。</li></ul> |
