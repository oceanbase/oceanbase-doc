# GV$SQL_WORKAREA_HISTOGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのノードで以前に実行されたすべてのワークエリアに関する統計情報を表示します。例えば、1MB～2MBの区間でフルインメモリ処理が実行された回数やワンパス処理の回数などです。

## フィールドの説明

|        **フィールド名**        |   **タイプ**   | **NULLを許容するか** |                  **説明**                  |
|------------------------|------------|----------------|------------------------------------------|
| LOW_OPTIMAL_SIZE       | bigint(20) | NO             | workareaがoptimalモードで使用する最小メモリ量             |
| HIGH_OPTIMAL_SIZE      | bigint(20) | NO             | workareaがoptimalモードで使用する最大メモリ量             |
| OPTIMAL_EXECUTIONS     | bigint(20) | NO             | workareaが最小および最大範囲内でoptimalモードで実行される回数             |
| ONEPASS_EXECUTIONS     | bigint(20) | NO             | workareaが最小および最大範囲内でone passモードで実行される回数     |
| MULTIPASSES_EXECUTIONS | bigint(20) | NO             | workareaが最小および最大範囲内でmulti passesモードで実行される回数 |
| TOTAL_EXECUTIONS       | bigint(20) | NO             | workareaの合計実行回数                         |
| CON_ID                 | bigint(20) | NO             | テナントID                                    |
| SVR_IP                 | varchar(46)   | NO             | サーバーIPアドレス                   |
| SVR_PORT                 | bigint(20)   | NO             | サーバーのポート番号                   |
