# GV$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ログストリームPalfの状態を表示します。一般的なユースケースは以下のとおりです：

* ログストリームにリーダーが存在するかどうか（リーダーが存在するレプリカ）を確認する。
* ログストリームのメンバーリスト（Paxosレプリカ数）を確認する。
* レプリカの同期状態を確認する。
* ログストリームのログで回収可能なポイントを確認する。
* ログストリームがログ消費サービスを提供できる範囲（LSN/SCNを含む）を確認する。
* Palfのアクセスモードを確認する。

このビューを照会するテナントによって、取得される結果は異なります。具体的には以下のとおりです：

* システムテナントからこのビューを照会する場合、すべてのテナントのログストリームPalfの状態が表示されます。
* 通常テナントからこのビューを照会する場合、そのテナント自身のログストリームPalfの状態のみが表示されます。

| PROPOSAL_ID | bigint(20) | NO | PaxosのProposal ID |

| PAXOS_REPLICA_NUM | bigint(20) | NO | Paxosレプリカ数 |

| MAX_SCN | bigint(20) | NO | 最大書き込みポイント(SCN) |
| ARBITRATION_MEMBER | varchar(128) | NO | 仲裁メンバーのサーバーアドレス <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| DEGRADED_LIST | varchar(1024) | NO | 仲裁が有効なシナリオでデグレードされたフル機能レプリカのリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| LEARNER_LIST | longtext| NO | 現在のログストリームの読み取り専用レプリカリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main> |
