# GV$OB_CGROUP_CONFIG

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.0バージョンから導入されました。</li>
<li>V4.2.1系では、このビューはV4.2.1 BP2バージョンから導入されました。V4.2.x系の他のバージョンでは、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`GV$OB_CGROUP_CONFIG` ビューは、すべてのOBServerノードのcgroup設定を簡単に照会するために使用されます。ビューフィールド情報は、OBServerノードのインストールディレクトリ配下のcgroupディレクトリ（例：`/home/admin/oceanbase/cgroup`）から取得します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | OBServerのIPアドレス |
| SVR_PORT | bigint(20) | NO | OBServerのポート番号 |
| CFS_QUOTA_US | bigint(20) | NO | スレッドのCPU時間スライス。単位はマイクロ秒。このフィールドの情報は、pathディレクトリ配下の`cpu.cfs_quota_us`から取得します |
| CFS_PERIOD_US | bigint(20) | NO | cgroupの制御周期時間。単位はマイクロ秒。Quotaと組み合わせて使用します。このフィールドの情報は、pathディレクトリ配下の`cpu.cfs_period_us`から取得します |
| SHARES | bigint(20) | NO | スレッドのCPU利用率（CPUがフル負荷の場合にのみ有効）。このフィールドの情報は、pathディレクトリ配下の`cpu.shares`から取得します |
| CGROUP_PATH | varchar(256) | NO | OBServerのcgroupディレクトリのパス |

## クエリ例

ユーザーテナント内で、すべてのOBServerノードのcgroup設定をクエリします。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.GV$OB_CGROUP_CONFIG;
```
