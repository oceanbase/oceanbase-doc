# V$SESSTAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$SESSTAT` は、セッションレベルの統計イベントの概要を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョンでは：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPのパラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> が設定されている場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | 情報が存在するサーバーのポート番号 |
| STATISTICS# | bigint(20) | NO | 統計イベントのインデックス |
| VALUE | bigint(20) | NO | 統計イベントの発生回数 |

## クエリ例

セッションレベルの統計イベントの概要を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSTAT LIMIT 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SID: 1152921504606863376
    CON_ID: 1002
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
