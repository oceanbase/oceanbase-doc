# V$OB_SHARED_STORAGE_QUOTA

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上のI/Oアクセスリソース情報を表示します。

## フィールドの説明

| フィールド名     | 型          | NULL許容 | 説明                                                        |
|-------------|---------------|----------------|-------------------------------------------------------------|
| SVR_IP      | varchar(46)   | NO   | OBServerノードのIPアドレス  |
| SVR_PORT    | bigint(20)    | NO   | OBServerノードのポート番号     |
| ENDPOINT    | varchar(256)  | NO   | 共有ストレージのEndpoint。シェアードナッシング(Shared-Nothing, SN)モードでは、このフィールドの値は空になります。     |
| PATH        | varchar(1024) | NO   | オブジェクトストレージのパス。シェアードナッシング(Shared-Nothing, SN)モードでは、ローカルパスとして表示されます。</br>このパスで一般的に使用されるタイプは、`local://`、`oss://`、`file://`、`s3://`などです。   |
| CLASS_ID    | bigint(20)    | NO   | 識別子ID。オブジェクトストレージのBucketの用途によって、異なる意味を持ちます。<ul><li>Bucketがclogストレージやデータストレージに使用されている場合、このフィールドは無意味で、値は`0`になります。</li> <li>Bucketがバックアップ・リストア、データインポート、エクスポートなどのタスクに使用されている場合、このフィールドの意味はテナントIDです。</li></ul>      |
| TYPE        | varchar(32)   | NO   | 指標タイプ。主なタイプは以下の通りです：<ul><li>`IPS`：1秒あたりの命令数</li> <li>`OPS`：1秒あたりに実行される操作数</li> <li>`IOPS`：1秒あたりの入出力操作数</li> <li>`IBW`：入力帯域幅</li> <li>`OBW`：出力帯域幅</li> <li>`IOBW`：入出力帯域幅</li> <li>`TAG`：ユーザー設定のタグ情報</li></ul>     |
| REQUIREMENT | bigint(20)    | NO   | サーバーが必要とする各種リソース    |
| ASSIGN      | bigint(20)    | NO   | サーバーに割り当てられた上限リソース量     |

## クエリ例

ユーザーテナント内で、clogストレージやデータストレージなどのシナリオについて、現在のOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。バックアップ・リストア、データインポート、エクスポートなどのシナリオでは、そのテナントの現在のOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。

```shell
obclient> SELECT * FROM oceanbase.V$OB_SHARED_STORAGE_QUOTA;
```
