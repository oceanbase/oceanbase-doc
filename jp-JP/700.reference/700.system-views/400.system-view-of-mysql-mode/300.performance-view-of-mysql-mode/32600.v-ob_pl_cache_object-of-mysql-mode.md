# V$OB_PL_CACHE_OBJECT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_PL_CACHE_OBJECT`は、このテナントのPL関連キャッシュオブジェクトの基本情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)          | NO   | テナントID：<ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>   |
| SVR_IP            | varchar(46)         | NO   | キャッシュオブジェクトが存在するノードのアドレス   |
| SVR_PORT          | bigint(20)          | NO   | キャッシュオブジェクトが存在するノードのポート   |
| CACHE_OBJECT_ID   | bigint(20)          | NO   | lib cacheによって割り当てられたキャッシュオブジェクトID   |
| PARAMETERIZE_TEXT | longtext            | NO   |  <ul><li>匿名ブロックおよびPSモードのCALL文の場合：パラメータ化されたSQLテキストを表します  </li><li>Procedure/Fuction/Packageなどの場合：ストアドプロシージャオブジェクト名を表します </li></ul>    |
| OBJECT_TEXT       | longtext            | NO   | クエリステートメントのテキスト。このフィールドは匿名ブロックおよびPSモードのCALL文の場合にのみ有効です   |
| FIRST_LOAD_TIME   | timestamp(6)        | NO   | 初回ロード時間（単位：マイクロ秒）  |
| LAST_ACTIVE_TIME  | timestamp(6)        | NO   | 前回のキャッシュヒット時間（単位：マイクロ秒）   |
| AVG_EXE_USEC      | bigint(20)          | NO   | 平均実行時間（単位：マイクロ秒）   |
| SLOWEST_EXE_TIME  | timestamp(6)        | NO   | 最も遅い実行のタイムスタンプ（単位：マイクロ秒）   |
| SLOWEST_EXE_USEC  | bigint(20)          | NO   | 最も遅い実行時間（単位：マイクロ秒）  |
| HIT_COUNT         | bigint(20)          | NO   | キャッシュヒット数   |
| CACHE_OBJ_SIZE    | bigint(20)          | NO   | キャッシュオブジェクトが占有するメモリサイズ   |
| EXECUTIONS        | bigint(20)          | NO   | ストアドプロシージャの正常な実行回数   |
| ELAPSED_TIME      | bigint(20) unsigned | NO   | 最後のストアドプロシージャ実行時間（単位：マイクロ秒）   |
| OBJECT_TYPE       | longtext            | NO   | キャッシュオブジェクトのタイプ（例：Procedure、Function、Triggerなど）   |
| OBJECT_ID         | bigint(20) unsigned | NO   | ストアドプロシージャオブジェクトID（`routine_id`/`package_id`）   |
| COMPILE_TIME      | bigint(20) unsigned | NO   | ストアドプロシージャのコンパイル時間（単位：マイクロ秒）   |
| SCHEMA_VERSION    | bigint(20)          | NO   | Schemaバージョン番号   |
| PS_STMT_ID        | bigint(20)          | NO   | リクエストに対応するPrepare ID：<ul><li>`-1`：SQLステートメントがPSプロトコルを使用していないことを示します  </li><li>`-1`以外の値：SQLステートメントがPSプロトコルを使用していることを示し、このステートメントに対してPSプロトコルが返す一意の識別子を表します    |
| DB_ID             | bigint(20) unsigned | NO   | ストアドプロシージャのコンパイル時に使用されるデータベースID     |
| PL_CG_MEM_HOLD    | bigint(20)          | NO   | PL CG段階でホールドされるメモリを表します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>    |
| SYS_VARS          | varchar(4096)       | NO   | 現在のセッション上で計画生成に影響を与えるシステム変数を表します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>    |
| PARAM_INFOS       | longtext            | NO   | 匿名ブロックおよびCALL PROC INFOに対してパラメータ化された型情報を表示し、マッチングが成功したかどうかを判断するために使用されます。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>   |
