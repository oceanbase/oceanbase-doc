# V$OB_KV_CONNECTIONS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1_CE BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_KV_CONNECTIONS`は、サーバー上のOBKVが保持する接続統計情報を確認するために使用します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)   | NO   |  テナントID   |
| USER_ID           | bigint(20)   | NO   |  ユーザーID   |
| DB_ID             | bigint(20)   | NO   |  データベースID   |
| SVR_IP            | varchar(46)  | NO   |  サーバーIPアドレス  |
| SVR_PORT          | bigint(20)   | NO   |  サーバーポート   |
| CLIENT_IP         | varchar(46)  | NO   |  クライアントIPアドレス  |
| CLIENT_PORT       | bigint(20)   | NO   |  クライアントポート   |
| FIRST_ACTIVE_TIME | timestamp(6) | NO   |  接続の最初のリクエストが処理された時間   |
| LAST_ACTIVE_TIME  | timestamp(6) | NO   |  接続の最後のリクエストが処理された時間  |
