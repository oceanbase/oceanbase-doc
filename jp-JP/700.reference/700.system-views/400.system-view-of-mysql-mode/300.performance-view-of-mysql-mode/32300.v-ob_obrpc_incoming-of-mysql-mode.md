# V$OB_RPC_INCOMING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノードで受信したRPCリクエストの統計情報を表示します。

## フィールドの説明

|    **フィールド名**    |    **タイプ**    | **NULL許容** |        **説明**         |
|----------------|--------------|----------------|-----------------------|
| TENANT_ID      | bigint(20)   | NO             | テナントID                 |
| SVR_IP         | varchar(46)  | NO             | IPアドレス                 |
| SVR_PORT       | bigint(20)   | NO             | ポート番号                   |
| PCODE          | bigint(20)   | NO             | RPCパケットコード       |
| PCODE_NAME     | varchar(256) | NO             | RPCパケットコードに対応する名前 |
| COUNT          | bigint(20)   | NO             | この種類のRPCリクエストの受信数   |
| TOTAL_SIZE     | bigint(20)   | NO             | 受信データの合計サイズ               |
| NET_TIME       | bigint(20)   | NO             | ネットワーク時間                  |
| WAIT_TIME      | bigint(20)   | NO             | 受信からリクエストがキューに入るまでの時間       |
| QUEUE_TIME     | bigint(20)   | NO             | キューで待機していた時間             |
| PROCESS_TIME   | bigint(20)   | NO             | 実際の処理にかかった時間             |
| LAST_TIMESTAMP | timestamp(6) | NO             | 最終更新時刻               |
| DCOUNT         | bigint(20)   | NO             | 各Pcode RPCのリクエスト数、統計周期は30秒  |

## クエリ例

ユーザーテナント内で、現在のノードで受信したRPCリクエストのうち、キューでの待機時間が1秒を超えるリクエストを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RPC_INCOMING WHERE QUEUE_TIME > 1000000;
```
