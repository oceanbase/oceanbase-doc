# GV$OB_LOG_TRANSPORT_DEST_STAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `GV$OB_LOG_TRANSPORT_DEST_STAT` は、テナント内のすべてのOBServerにおけるダウンストリームログ同期リンク（OBCDC/ネットワークスタンバイデータベース）の情報を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID                   | bigint(20)          | NO   | テナントID     |
| SVR_IP                      | varchar(46)         | NO   | サーバーIPアドレス     |
| SVR_PORT                    | bigint(20)          | NO   | サーバーRPC_PORT     |
| LS_ID                       | bigint(20)          | NO   | 要求されたログストリームID     |
| CLIENT_IP                   | varchar(46)         | NO   | 要求側のプロセスが存在するマシンのIP     |
| CLIENT_PID                  | bigint(20)          | NO   | 要求側のプロセスID     |
| CLIENT_TENANT_ID            | bigint(20)          | NO   | 要求側のテナントID     |
| CLIENT_TYPE                 | varchar(7)          | NO   | 要求側のタイプ：<ul><li>STANDBY：ネットワークスタンバイデータベース </li><li>CDC：OBCDC </li><li>UNKNOWN：クライアントタイプ不明 </li></ul>    |
| START_SERVE_TIME            | timestamp(6)        | NO   | 設定日時     |
| LAST_SERVE_TIME             | timestamp(6)        | NO   | 最終変更日時     |
| LAST_READ_SOURCE            | varchar(7)          | NO   | 前回のリクエスト処理時のログの読み取り元：<ul><li>ONLINE：オンラインログ </li><li>ARCHIVE：アーカイブログ </li><li>UNKNOWN：ソース不明 </li></ul>     |
| LAST_REQUEST_TYPE           | varchar(24)         | NO   | 前回のリクエストのRPCタイプ：<ul><li>0：SEQUENTIAL_READ_SERIAL、直列ログ転送プロトコルを使用してログを順次読み取ることを示す </li><li>1：SEQUENTIAL_READ_PARALLEL、並列ログ転送プロトコルを使用してログを順次読み取ることを示す </li><li>2：SCATTERED_READ、前回のリクエストが離散したログの読み取りであったことを示す </li><li>その他の値：RPCタイプが不明であることを示す </li></ul>     |
| LAST_REQUEST_LOG_LSN        | bigint(20) unsigned | NO   | 前回のリクエストのログのLSN     |
| LAST_REQUEST_LOG_SCN        | bigint(20) unsigned | NO   | 前回のリクエストのログのSCN     |
| LAST_FAILED_REQUEST         | longtext            | NO   | 前回失敗したRPC情報、送信時間/TRACE_ID/エラーコードなど    |
| AVG_REQUEST_PROCESS_TIME    | bigint(20)          | NO   | RPC処理平均時間     |
| AVG_REQUEST_QUEUE_TIME      | bigint(20)          | NO   | RPC待機平均時間     |
| AVG_REQUEST_READ_LOG_TIME   | bigint(20)          | NO   | RPCログ読み取り平均時間     |
| AVG_REQUEST_READ_LOG_SIZE   | bigint(20)          | NO   | RPCログ読み取り平均サイズ     |
| AVG_LOG_TRANSPORT_bandWIDTH | varchar(29)         | NO   | 平均ログ転送帯域幅     |
