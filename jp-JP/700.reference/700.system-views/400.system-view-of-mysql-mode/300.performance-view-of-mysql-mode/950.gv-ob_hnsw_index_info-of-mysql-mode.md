# GV$OB_HNWS_INDEX_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントにおけるすべてのOBServerノード上のHNSWベクトルインデックスの基本情報とリアルタイム状態を表示します。

## フィールド説明

|             フィールド名          |      データ型    | NULL許容    |            説明                                            |  情報タイプ |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | レプリカが存在するノードのアドレス                                              | 基本情報 |
| SVR_PORT                     | bigint(20)   | NO             | レプリカが存在するノードのRPC_PORT                                              | 基本情報 |
| TENANT_ID                    | bigint(20)   | NO             | テナントID：<ul><li>1：システムテナントID</li> <li>その他の値：ユーザーテナントまたはMetaテナントID</li></ul>                                                    | 基本情報 |
| DATA_TABLE_ID                | bigint(20)   | NO             | データテーブルID                                                    | 基本情報 |
| DATA_TABLET_ID               | bigint(20)   | NO             | パーティションID                                                    | 基本情報 |
| TABLE_NAME                   | varchar(256) | NO             | テーブル名                                                    | 基本情報 |
| INDEX_NAME                   | varchar(256) | NO             | インデックス名                                                    | インデックス情報 |
| ROLE                         | varchar(8)   | NO             | ロール：<ul><li>leader：リーダーレプリカ</li> <li>follower：フォロワーレプリカ</li></ul>                                                    | 基本情報 |
| INDEX_PARAM                  | longtext     | NO             | インデックスパラメータ                                                    | インデックス情報 |
| MEMORY_USED                  | bigint(20)   | NO             | メモリ使用量                                                    | インデックス情報 |
| MEMORY_HOLD                  | bigint(20)   | NO             | 使用メモリ                                                    | インデックス情報 |
| INCR_MEM_HOLD                | bigint(20)   | NO             | 増分メモリ使用量                                                    | インデックス情報 |
| SNAP_MEM_HOLD                | bigint(20)   | NO             | スナップショットメモリ使用量                                                    | インデックス情報 |
| INCR_INDEX_CNT               | bigint(20)   | NO             | 増分ベクトル数                                                    | インデックス情報 |
| SNAP_INDEX_CNT               | bigint(20)   | NO             | スナップショットベクトル数                                                    | インデックス情報 |
| INCR_DATA_SCN                | bigint(20) unsigned  | NO             | 増分データバージョン                                                    | インデックス情報 |
| SNAP_DATA_SCN                | bigint(20) unsigned  | NO             | スナップショットデータバージョン                                                    | インデックス情報 |
| LAST_SUCC_SYNC_TIME          | datetime     | NO             | 最後の成功時間                                                    | 同期情報 |
| LAST_FAILED_SYNC_TIME        | datetime     | NO             | 最近の失敗時間                                                    | 同期情報 |
| LAST_FAILED_CODE             | bigint(20)   | NO             | 最近の失敗エラーコード                                                    | 同期情報 |
