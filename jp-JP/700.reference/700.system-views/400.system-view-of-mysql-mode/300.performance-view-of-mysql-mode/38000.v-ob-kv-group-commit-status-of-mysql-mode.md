# V$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、V4.3.4バージョンから導入されました。</li> <li>V4.2.x系では、V4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

MySQLテナントでは、ビュー`V$OB_KV_GROUP_COMMIT_STATUS`を使用して、現在のノード上のOBKVテナントクライアントが接続されているグループのコミット状態情報にアクセスできます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | グループコミットgroupが存在するノードのIPアドレス |
| SVR_PORT | bigint(20) | NO | グループコミットgroupが存在するノードのポート番号 |
| TENANT_ID | bigint(20) | NO | テナントID：<ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| TABLE_ID | bigint(20) | NO | グループコミットgroupに属するテーブルのid |
| LS_ID | bigint(20) | NO | グループコミットgroupに属するLSのid |
| SCHEMA_VERSION | bigint(20) | NO | グループコミットgroupに属するテーブルのschema_version |
| GROUP_TYPE | varchar(32) | NO | グループコミットgroupのタイプ。現在サポートされているキューのタイプ：<ul><li>get：getリクエストキュー </li><li>put：putリクエストキュー </li><li>del：deleteリクエストキュー </li><li>replace：replaceリクエストキュー </li><li>insert：insertリクエストキュー </li><li>hybird：ハイブリッド操作リクエストキュー </li><li>fail：batch実行失敗のキュー </li></ul>  |
| QUEUE_SIZE | bigint(20) | NO | グループコミットgroup内のリクエストキューのサイズ。現在未消費のリクエスト数を表す |
| BATCH_SIZE | bigint(20) | NO | グループコミットgroup内のbatchのサイズ |
| CREATE_TIME | timestamp(6) | NO  | グループコミット中にこのgroupが作成された時間  |
| UPDATE_TIME | timestamp(6) | NO  | グループコミット中にこのgroupのステータス情報が更新された時間  |

## クエリ例

現在のノードにおけるOBKVテナントクライアント接続のグループコミット状態情報を照会し、1日目のレコードを表示します。

```shell
obclient > SELECT * FROM oceanbase.V$OB_KV_GROUP_COMMIT_STATUS limit 1;
```
