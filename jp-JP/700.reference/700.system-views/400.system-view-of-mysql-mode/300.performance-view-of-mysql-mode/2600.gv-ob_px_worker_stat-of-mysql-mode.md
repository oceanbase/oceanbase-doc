# GV$OB_PX_WORKER_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

パラレル実行シナリオにおいて、現在のテナントがすべてのOBServerノード上で各スレッドの実行情報を表示します。

## フィールドの説明

|  **フィールド名**  |      タイプ      | **NULL値を許容するか** |       説明       |
|------------|--------------|----------------|----------------|
| SESSION_ID | bigint(20)   | NO             | V4.2.x系について：<ul><li> V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはServer Session IDを表します。</li><li> V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ<code>client_session_id_version = 2</code>の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code>の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul>      |
| TENANT_ID  | bigint(20)   | NO             | テナントID          |
| SVR_IP     | varchar(46)  | NO             | サーバーのIPアドレス     |
| SVR_PORT   | bigint(20)   | NO             | サーバーのポート番号          |
| TRACE_ID   | varchar(128) | NO             | SQLのtrace_id |
| QC_ID      | bigint(20)   | NO             | px内のqc_id    |
| SQC_ID     | bigint(20)   | NO             | px内のsqc_id   |
| WORKER_ID  | bigint(20)   | NO             | スレッドID          |
| DFO_ID     | bigint(20)   | NO             | px内のdfo_id   |
| START_TIME | timestamp(6) | NO             | スレッド開始時刻      |

## クエリ例

ユーザーテナント内で、パラレル実行シナリオにおいて、当該テナントがすべてのOBServerノード上で全スレッドの実行情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PX_WORKER_STAT\G
```
