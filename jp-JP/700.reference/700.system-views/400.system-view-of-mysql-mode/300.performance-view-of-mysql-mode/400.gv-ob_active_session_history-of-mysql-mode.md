# GV$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `GV$OB_ACTIVE_SESSION_HISTORY` は、テナント内のすべてのOBServerノード上のアクティブセッションの履歴を表示するために使用されます。
