# GV$OB_TABLET_LOCAL_CACHE

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このビューはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このビューはV4.3.5 BP2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノード上で保持しているキャッシュの全体状況を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(SS)モードでのみ適用されます。共有なし(SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールドの説明

|      フィールド名         |         型  | NULL許容 |                       説明      |
|----------------------|---------------|----------------|---------------------------------|
| SVR_IP               | varchar(46)   | NO   |  OBServerノードのIPアドレス    |
| SVR_PORT             | bigint(20)    | NO   |  OBServerノードのポート番号      |
| TENANT_ID            | bigint(20)    | NO   |  テナントID    |
| TABLET_ID            | bigint(20)    | NO   |  Tablet ID    |
| STORAGE_CACHE_POLICY | varchar(64)   | NO   |  このTabletが現在保持するキャッシュ状態。<ul><li>`AUTO`：自動的にホット/コールドデータを識別する</li> <li>`HOT`：ホットデータ</li></ul>   |
| CACHED_DATA_SIZE     | bigint(20)    | NO   |  このTabletにローカルキャッシュされたデータ量、単位はバイト    |
| CACHE_HIT_COUNT      | bigint(20)    | NO   |  このTabletのキャッシュヒット回数。現在このフィールドは有効化されておらず、値は`-1`となります    |
| CACHE_MISS_COUNT     | bigint(20)    | NO   |  このTabletのキャッシュミス回数。現在このフィールドは有効化されておらず、値は`-1`となります    |
| CACHE_HIT_SIZE       | bigint(20)    | NO   |  このTabletのキャッシュヒットデータ量、単位はバイト。現在このフィールドは有効化されておらず、値は`-1`となります   |
| CACHE_MISS_SIZE      | bigint(20)    | NO   |  このTabletのキャッシュミスデータ量、単位はバイト。現在このフィールドは有効化されておらず、値は`-1`となります   |
| INFO                 | varchar(4096) | NO   |  その他の情報    |

