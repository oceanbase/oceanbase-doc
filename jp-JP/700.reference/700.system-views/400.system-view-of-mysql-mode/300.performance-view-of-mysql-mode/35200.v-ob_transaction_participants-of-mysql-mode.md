# V$OB_TRANSACTION_PARTICIPANTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_TRANSACTION_PARTICIPANTS` は、すべてのOBServerノード上のトランザクション参加者情報を表示するために使用されます。

## フィールドの説明

|       フィールド名       |      型       | NULL許容 |    説明     |
|------------------|---------------|------------|-----------|
| TENANT_ID        | bigint(20)    | NO         | テナントID     |
| SVR_IP           | varchar(46)   | NO         | サーバーIPアドレス |
| SVR_PORT         | bigint(20)    | NO         | サーバーポート番号    |
| SESSION_ID       | bigint(20)    | NO         | V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）で、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>      |
| SCHEDULER_ADDR   | varchar(64)   | NO         | スケジューラーが属するノードのアドレス |
| TX_TYPE          | varchar(11)   | NO         | トランザクションタイプ      |
| TX_ID            | bigint(20)    | NO         | トランザクションID      |
| LS_ID            | bigint(20)    | NO         | 所属ログストリームID   |
| PARTICIPANTS     | varchar(1024) | NO         | 参加者リスト     |
| CTX_CREATE_TIME  | timestamp(6)  | NO        | コンテキスト作成時刻  |
| TX_EXPIRED_TIME  | timestamp(6)  | NO        | トランザクションタイムアウト時刻   |
| STATE            | varchar(13)   | NO         | コンテキストコミット状態   |
| ACTION           | varchar(10)   | NO         | 最後に実行されたアクション  |
| PENDING_LOG_SIZE | bigint(20)    | NO         | 永続化待ちデータサイズ  |
| FLUSHED_LOG_SIZE | bigint(20)    | NO         | 永続化済みデータサイズ  |
| ROLE             | varchar(8)    | NO         | コンテキストロール     |
| COORD             | bigint(20)    | NO   | 対応するコーディネーターIS ID（コミット段階に入った場合に有効）    |
| LAST_REQUEST_TIME | timestamp(6)  | NO  | 最後に外部リクエストを受信した時刻    |
| FORMATID          | bigint(20)    | NO   | xid形式タイプ    |
| GLOBALID          | varchar(257)  | NO   | XAトランザクショングローバル識別子    |
| BRANCHID          | varchar(257)  | NO   | XAトランザクションブランチ限定子    |

## クエリ例

すべてのOBServerノード上のトランザクション参加者情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TRANSACTION_PARTICIPANTS LIMIT 1\G
```
