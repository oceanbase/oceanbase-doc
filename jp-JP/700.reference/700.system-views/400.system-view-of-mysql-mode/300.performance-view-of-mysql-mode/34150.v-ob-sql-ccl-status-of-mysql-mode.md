# V$OB_SQL_CCL_STATUS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このビューはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このビューはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>

## 機能の概要

現在の時点で、テナント内の現在のノードが対応するレート制限ルールにヒットしたSQL数を記録し、システムで設定されているレート制限ルールの影響を観測するために使用されます。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
|---------|-------|-------------|--------|
| CON_ID              | bigint(20)  | NO   |テナントID      |
| SVR_IP              | varchar(46) | NO   |OBServerノードのIPアドレス     |
| SVR_PORT            | bigint(20)  | NO   |BServerノードのポート番号      |
| CCL_RULE_ID         | bigint(20)  | NO   |有効なレート制限ルールID     |
| FORMAT_SQLID        | varchar(32) | NO   |レート制限の有効粒度:<li>ルールレベル: 0 </li><li>SQL_IDレベル:1</li>      |
| CURRENT_CONCURRENCY | bigint(20)  | NO   |現在実行中で、このレート制限ルールにヒットしたSQLの数     |
| MAX_CONCURRENCY     | bigint(20)  | NO   |このレート制限ルールの並列度の上限    |

## クエリ例

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SQL_CCL_STATUS;
```
