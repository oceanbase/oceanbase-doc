# V$OB_GROUP_IO_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントが現在のOBServerノード上で使用している各リソースグループのリアルタイム状態を表示します。

## フィールド説明

|             フィールド名          |      型    | NULL許容    |            説明                                            |
|------------------------------|--------------|----------------|------------------------------------------------------------|
| TENANT_ID                    | bigint(20)   | NO             | テナントID                                                    |
| SVR_IP                       | varchar(46)  | NO             | サーバーIPアドレス                                              |
| SVR_PORT                     | bigint(20)   | NO             | サーバーポート番号                                                |
| GROUP_ID                     | bigint(20)   | NO             | 対応するリソースグループID     |
| GROUP_NAME                   | varchar(128) | NO             | 対応するリソースグループ名     |
| MODE                         | varchar(128) | NO             | 読み書きモード。<ul><li>`READ`：読み取りモード</li> <li>`WRITE`：書き込みモード</li></ul>     |
| MIN_IOPS                     | bigint(20)   | NO             | リソースグループ内の最小IOPS     |
| MAX_IOPS                     | bigint(20)   | NO             | リソースグループ内の最大IOPS     |
| NORM_IOPS                    | bigint(20)   | NO             | 現在のIOPS（16KB読み取りに換算した値を表示）<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このフィールドはV4.3.5 BP1バージョンから導入されました。</li></ul></main>  |
| REAL_IOPS                    | bigint(20)   | NO             | 現在のIOPS     |
| MAX_NET_bandWIDTH            | bigint(20)   | NO             | リソースグループ内の最大ネットワーク帯域幅、単位はバイト     |
| MAX_NET_bandWIDTH_DISPLAY    | varchar(128) | NO             | 変換後に表示されるリソースグループ内の最大ネットワーク帯域幅。例：10 GB/s、10MB/sなど。     |
| REAL_NET_bandWIDTH           | bigint(20)   | NO             | 現在のネットワーク帯域幅、単位はバイト    |
| REAL_NET_bandWIDTH_DISPLAY   | varchar(128) | NO             | 変換後に表示される現在のネットワーク帯域幅。例：10 GB/s、10MB/sなど。     |

## クエリ例

ユーザーテナントが、現在のOBServerノード上における自身のテナントの各リソースグループのリアルタイム状態を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_GROUP_IO_STAT LIMIT 1\G
```

クエリ結果は次のとおりです：

