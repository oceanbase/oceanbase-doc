# V$OB_ENCRYPTED_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで暗号化機能が有効になっているテーブルの暗号化状態を表示します。

## フィールドの説明

|     **フィールド名**     |       **タイプ**        | **NULL値を許容** |                       **説明**                       |
|------------------|---------------------|------------|------------------------------------------------------------------------------------|
| TABLE_ID         | bigint(20)          | NO         | テーブルID                                               |
| TABLE_NAME       | varchar(256)        | NO         | テーブル名                                                |
| TABLESPACE_ID    | bigint(20)          | NO         | テーブルスペースID                                             |
| ENCRYPTIONALG    | varchar(30)         | NO         | 暗号化アルゴリズム名：<ul><li>AES-128   </li><li> AES-192   </li><li> AES-256   </li><li> SM4</li></ul>  |
| ENCRYPTED        | varchar(3)          | NO         | 暗号化完了か：<ul><li>YES   </li><li> NO </li></ul>          |
| ENCRYPTEDKEY     | varchar(33)         | NO         | マスターキーによって暗号化された暗号化キー                                      |
| MASTERKEYID      | bigint(20) unsigned | NO         | マスターキーのバージョン                                              |
| BLOCKS_ENCRYPTED | decimal(20,0)       | NO         | 暗号化されたマクロブロックの数                                            |
| BLOCKS_DECRYPTED | decimal(21,0)       | NO         | 暗号化されていないマクロブロックの数                                           |
| STATUS           | varchar(10)         | NO           | 暗号化状態：<ul><li> NORMAL：正常な状態   </li><li> ENCRYPTING：暗号化中   </li><li> DECRYPTING：復号中 </li></ul>  |
| CON_ID           | bigint(20)          | NO         | テナントID     |

## クエリ例

現在のテナントで暗号化機能が有効になっているテーブルの暗号化状態を確認します。

```shell
obclient [oceanbase]> SELECT TABLE_NAME, ENCRYPTIONALG, ENCRYPTED FROM oceanbase.V$OB_ENCRYPTED_TABLES;
```

クエリ結果は次のとおりです：

```shell
+------------+---------------+-----------+
| TABLE_NAME | ENCRYPTIONALG | ENCRYPTED |
+------------+---------------+-----------+
| t1         | aes-256       | YES       |
+------------+---------------+-----------+
1 row in set
```
