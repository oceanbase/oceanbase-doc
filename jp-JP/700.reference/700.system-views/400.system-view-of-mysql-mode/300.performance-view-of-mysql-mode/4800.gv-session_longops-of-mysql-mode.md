# GV$SESSION_LONGOPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

クラスタのDDL操作の実行状態と進捗を表示します。

## フィールドの説明

|     **フィールド名**     |    **型**     | **NULL許容** |  **説明**   |
|------------------|---------------|----------------|-----------|
| SID              | bigint(20)    | NO             | セッションID     |
| TRACE_ID         | varchar(64)  | NO   | このステートメントのtrace_id    |
| OPNAME           | varchar(64)  | NO             | 操作名      |
| TARGET           | varchar(64)  | NO             | 操作対象      |
| SVR_IP           | varchar(46)   | NO             | 操作が行われているマシンのIPアドレス |
| SVR_PORT         | bigint(20)    | NO             | 操作が行われているマシンのポート番号 |
| START_TIME       | date    | NO             | 開始時間      |
| ELAPSED_SECONDS  | bigint(21) | NO             | 消費済み時間    |
| TIME_REMAINING   | bigint(20)    | NO             | 推定残り時間  |
| LAST_UPDATE_TIME | date    | NO             | 統計情報更新時間  |
| MESSAGE          | varchar(512)  | NO             | 備考情報      |
