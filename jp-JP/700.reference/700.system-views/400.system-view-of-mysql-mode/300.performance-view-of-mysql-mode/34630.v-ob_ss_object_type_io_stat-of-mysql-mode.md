# V$OB_SS_OBJECT_TYPE_IO_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_SS_OBJECT_TYPE_IO_STAT` は、テナントの現在のノード上で異なる種類のオブジェクトに対する読み取り、書き込み、または削除の使用量を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。シェアードナッシング(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールド説明

|      フィールド名    |         型          | NULL許容 |                       説明      |
|-----------------|-----------------------|----------------|---------------------------------|
| SVR_IP          | varchar(46)  | NO   | OBServerノードのIPアドレス     |
| SVR_PORT        | bigint(20)   | NO   | OBServerノードのポート番号      |
| TENANT_ID       | bigint(20)   | NO   | テナントID     |
| OBJECT_TYPE     | varchar(128) | NO   | オブジェクトのタイプ     |
| MODE            | varchar(32)  | NO   | 統計データのソース：<ul><li>`local`：ローカル</li><li>`remote`：オブジェクトストレージ</li></ul>     |
| READ_CNT        | bigint(20)   | NO   | IO読み取りの総回数     |
| READ_SIZE       | bigint(20)   | NO   | IO読み取りの総サイズ、バイト単位     |
| READ_FAIL_CNT   | bigint(20)   | NO   | IO読み取り失敗の総回数     |
| READ_IOPS       | bigint(20)   | NO   | IO読み取りの平均IOPS     |
| WRITE_CNT       | bigint(20)   | NO   | IO書き込みの総回数     |
| WRITE_SIZE      | bigint(20)   | NO   | IO書き込みの総サイズ、バイト単位     |
| WRITE_FAIL_CNT  | bigint(20)   | NO   | IO書き込み失敗の総回数     |
| WRITE_IOPS      | bigint(20)   | NO   | IO書き込みの平均IOPS     |
| DELETE_CNT      | bigint(20)   | NO   | オブジェクト削除の総回数     |
| DELETE_FAIL_CNT | bigint(20)   | NO   | オブジェクト削除失敗の総回数    |
| DELETE_IOPS     | bigint(20)   | NO   | オブジェクト削除のIOPS     |
