# GV$OB_VECTOR_MEMORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>このビューはV4.4.1バージョンから導入されました。</li></ul>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノード上で使用しているベクトルインデックスデータのメモリ使用状況に関する詳細な統計情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)          | NO   |  テナントID：<ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>   |
| SVR_IP            | varchar(46)         | NO   |  ノードアドレス   |
| SVR_PORT          | bigint(20)          | NO   |  ノードポート   |
| VECTOR_MEM_HOLD   | bigint(20)          | NO   |  ベクトルインデックスデータのメモリ使用量、単位はバイト   |
| VECTOR_MEM_LIMIT  | bigint(20)          | NO   |  ベクトルインデックスデータのメモリ上限設定値、単位はバイト   |
| VECTOR_MEM_USED   | bigint(20)          | NO   |  ベクトルインデックスデータの実際のメモリ使用量、単位はバイト   |

## クエリ例

現在のテナントがすべてのOBServerノード上で使用しているベクトルインデックスデータのメモリ使用状況に関する詳細な統計情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_VECTOR_MEMORY  \G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
                svr_ip: 11.xxx.xx.xx
              svr_port: 46002
             tenant_id: 1004
       vector_mem_hold: 82231296
       vector_mem_used: 77876328
      vector_mem_limit: 429496720
1 row in set
```
