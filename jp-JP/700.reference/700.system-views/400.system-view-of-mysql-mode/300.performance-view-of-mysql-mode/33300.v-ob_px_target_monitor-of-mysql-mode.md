# V$OB_PX_TARGET_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上で使用しているPXスレッドの状況を表示します。

## フィールド説明

|             フィールド名             |         型           | NULL許容   |    説明     |
|------------------------------|---------------------|------------|-----------|
| SVR_IP                       | varchar(46)         | NO         | ローカルサーバーのIPアドレス |
| SVR_PORT                     | bigint(20)          | NO         | ローカルサーバーのポート番号    |
| TENANT_ID                    | bigint(20)          | NO         | テナントID     |
| IS_LEADER                    | varchar(1)          | NO         | ダミーテーブルのリーダーかどうか          |
| VERSION                      | bigint(20) unsigned | NO         | 統計情報の再収集回数          |
| PEER_IP                      | varchar(46)         | NO         | パートナーサーバーのIPアドレス          |
| PEER_PORT                    | bigint(20)          | NO         | パートナーサーバーのポート番号          |
| PEER_TARGET                  | bigint(20)          | NO         | パートナーサーバーのPXスレッド総数          |
| PEER_TARGET_USED             | bigint(20)          | NO         | パートナーサーバーのPXスレッド使用数          |
| LOCAL_TARGET_USED            | bigint(20)          | NO         | ローカルサーバーが使用するパートナーPXスレッド数          |
| LOCAL_PARALLEL_SESSION_COUNT | bigint(20)          | NO         | ローカルサーバーで並列実行中のセッション数          |

## クエリ例

ユーザーテナント内で、そのテナントの現在のOBServerノード上のPXスレッドの使用状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PX_TARGET_MONITOR;
```

