# V$OB_LOG_TRANSPORT_DEST_STAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_LOG_TRANSPORT_DEST_STAT` は、このテナント内のこのOBServerの下流ログ同期リンク（OBCDC/ネットワークスタンバイデータベース）の情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID                   | bigint(20)          | NO   | テナントID     |
| SVR_IP                      | varchar(46)         | NO   | サーバーIPアドレス     |
| SVR_PORT                    | bigint(20)          | NO   | サーバーRPC_PORT     |
| LS_ID                       | bigint(20)          | NO   | リクエストされたログストリームID     |
| CLIENT_IP                   | varchar(46)         | NO   | リクエスト側のプロセスが存在するマシンのIP     |
| CLIENT_PID                  | bigint(20)          | NO   | リクエスト側のプロセスID     |
| CLIENT_TENANT_ID            | bigint(20)          | NO   | リクエスト側のテナントID     |
| CLIENT_TYPE                 | varchar(7)          | NO   | リクエスト側のタイプ：<ul><li>STANDBY：ネットワークスタンバイ </li><li>CDC：OBCDC </li><li>UNKNOWN：不明なクライアントタイプ </li></ul>    |
| START_SERVE_TIME            | timestamp(6)        | NO   | 作成時間を記録     |
| LAST_SERVE_TIME             | timestamp(6)        | NO   | 変更時間を記録     |
| LAST_READ_SOURCE            | varchar(7)          | NO   | 前回のリクエスト処理時のログの読み取り元：<ul><li>ONLINE：オンラインログ </li><li>ARCHIVE：アーカイブログ </li><li>UNKNOWN：不明なソース </li></ul>     |
| LAST_REQUEST_TYPE           | varchar(24)         | NO   | 前回のリクエストのRPCタイプ：<ul><li>0：SEQUENTIAL_READ_SERIAL、直列ログ転送プロトコルを使用してログを順次読み取ることを示す </li><li>1：SEQUENTIAL_READ_PARALLEL、並列ログ転送プロトコルを使用してログを順次読み取ることを示す </li><li>2：SCATTERED_READ、前回のリクエストが離散したログの読み取りであることを示す </li><li>その他の値：不明なRPCタイプを示す </li></ul>     |
| LAST_REQUEST_LOG_LSN        | bigint(20) unsigned | NO   | 前回のリクエストのログのLSN     |
| LAST_REQUEST_LOG_SCN        | bigint(20) unsigned | NO   | 前回のリクエストのログのSCN     |
| LAST_FAILED_REQUEST         | longtext            | NO   | 前回失敗したRPC情報、送信時間/TRACE_ID/エラーコードなど    |
| AVG_REQUEST_PROCESS_TIME    | bigint(20)          | NO   | 平均RPC処理時間     |
| AVG_REQUEST_QUEUE_TIME      | bigint(20)          | NO   | 平均RPCキュー待ち時間     |
| AVG_REQUEST_READ_LOG_TIME   | bigint(20)          | NO   | 平均RPCログ読み取り時間     |
| AVG_REQUEST_READ_LOG_SIZE   | bigint(20)          | NO   | 平均RPCログ読み取りサイズ     |
| AVG_LOG_TRANSPORT_bandWIDTH | varchar(29)         | NO   | 平均ログ転送帯域幅     |
