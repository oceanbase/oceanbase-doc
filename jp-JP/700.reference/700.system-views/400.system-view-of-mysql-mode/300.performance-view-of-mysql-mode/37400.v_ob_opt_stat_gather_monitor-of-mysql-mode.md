# V$OB_OPT_STAT_GATHER_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上で、現在のテナントの統計情報収集タスクのリアルタイム状態を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 収集タスクが属するテナントID |
| SVR_IP | varchar(46) | NO | 収集タスクが存在するノードのアドレス |
| SVR_PORT | bigint(20) | NO | 収集タスクが存在するノードのポート |
| SESSION_ID | bigint(20) | NO | 収集タスクが存在するセッションID<br>V4.2.x系では：<ul><li>V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはServer Session IDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODP内の構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul> |
| TRACE_ID | varchar(64) | NO | 収集タスクが存在するTRACE ID |
| TASK_ID | varchar(36) | NO | 収集タスクID（UUID生成、グローバル一意） |
| TYPE | varchar(16) | NO | 収集タスクのタイプ |
| TASK_START_TIME | datetime(6) | NO | 収集タスクの開始時間 |
| TASK_DURATION_TIME | bigint(20) | NO | 収集タスクの持続時間（マイクロ秒単位） |
| TASK_TABLE_COUNT | bigint(20) | NO | 収集タスクで収集対象となるテーブル数 |
| COMPLETED_TABLE_COUNT | bigint(20) | NO | 収集タスクで完了したテーブル数 |
| RUNNING_TABLE_OWNER | varchar(128) | NO | 収集タスクで収集中のテーブルのユーザー名 |
| RUNNING_TABLE_NAME | varchar(256) | NO | 収集タスクで収集中のテーブルの名前 |
| RUNNING_TABLE_DURATION_TIME | bigint(20) | NO | 収集タスクで収集中のテーブルの持続時間 |
| RUNNING_TABLE_PROGRESS      | varchar(256) | NO   | 収集タスクの収集進捗 |

obclient> SELECT * FROM oceanbase.V$OB_OPT_STAT_GATHER_MONITOR;
