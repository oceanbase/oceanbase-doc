# GV$OB_LS_LOG_REPLAY_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_LS_LOG_REPLAY_STAT`は、テナント内のすべてのノード上における各LS（ログストリーム）レプリカのログ再生進捗状況を表示します。クエリ時には、スタンバイデータベース（またはプライマリデータベース上でフォロワーレプリカをクエリする）で実行する必要があります。

プライマリテナント（プライマリデータベース）のリーダーレプリカではログが再生されないため、クエリ結果において、プライマリテナント上の`ROLE = LEADER`の場合、その行のレコードは無意味です。

## フィールドの説明

|      フィールド名       |      型           | NULL許容 |    説明     |
|--------------------|---------------------|----------------|-------------|
| TENANT_ID          | bigint(20)          | NO   | テナントID     |
| SVR_IP             | varchar(46)         | NO   | ログストリームID     |
| SVR_PORT           | bigint(20)          | NO   | サーバーIPアドレス     |
| LS_ID              | bigint(20)          | NO   | サーバーポート番号     |
| ROLE               | varchar(32)         | NO   | ログストリームレプリカの役割：<ul><li>`LEADER`：リーダーレプリカ</li> <li>`FOLLOWER`：フォロワーレプリカ</li></ul>      |
| ENABLED            | tinyint(4)          | NO   | ログ再生サービス（Replay Service）が有効かどうか    |
| END_LSN            | bigint(20) unsigned | NO   | Palfに書き込まれたLSN（ログ再生の右端）      |
| UNSUBMITTED_LSN    | bigint(20) unsigned | NO   | 再生キューに次に送信されるログのLSN     |
| UNSUBMITTED_SCN    | bigint(20) unsigned | NO   | 再生キューに次に送信されるログのSCN     |
| MIN_UNREPLAYED_LSN | bigint(20) unsigned | NO   | 再生キュー内の最小未再生ログのLSN     |
| MIN_UNREPLAYED_SCN | bigint(20) unsigned | NO   | 再生キュー内の最小未再生ログのSCN     |
| PENDING_CNT        | bigint(20)          | NO   | メモリ内で再生待ちのタスク数     |

## クエリ例

スタンバイテナント内で、自身のテナントに属するすべてのノード上の各ログストリームレプリカのログ再生進捗状況を確認します。

```shell
obclient(root@standby_tenant)[oceanbase]> SELECT SVR_IP, SVR_PORT, LS_ID, ROLE, ENABLED,
        END_LSN, UNSUBMITTED_LSN, MIN_UNREPLAYED_LSN, PENDING_CNT
        FROM oceanbase.GV$OB_LS_LOG_REPLAY_STAT;
```

クエリ結果は次のとおりです：

```shell

| SVR_IP       | SVR_PORT | LS_ID | ROLE     | ENABLED | END_LSN   | UNSUBMITTED_LSN | MIN_UNREPLAYED_LSN | PENDING_CNT |
+--------------+----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
| 6.xx.xxx.160 |     2882 |     1 | FOLLOWER |       1 | 300636581 |       300227763 |          300227763 |           0 |
| 6.xx.xxx.160 |     2882 |  1001 | FOLLOWER |       1 | 197547054 |       197197913 |          197197913 |           0 |
+--------------+----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
2 rows in set
```
