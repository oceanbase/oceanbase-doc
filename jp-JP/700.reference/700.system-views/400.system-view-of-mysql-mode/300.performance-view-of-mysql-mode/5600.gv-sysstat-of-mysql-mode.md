# GV$SYSSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノード上で発生した統計イベント情報を表示します。

ここで：

* `STATISTIC#`：統計項目番号を表します。同一の統計項目でも、OBServerノードのバージョンによって番号が変更される場合があります。

* `STAT_ID`：統計項目IDを表します。同一の統計項目のIDは、異なるOBServerノードのバージョン間でも同じであることが保証されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューを使用するには、モニタリングを有効にする必要があります。つまり、構成パラメータ<code>enable_perf_event</code>の値をTrueに設定する必要があります。</p>
</main>

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | 情報が存在するサーバーのポート番号 |
| STATISTIC# | bigint(20) | NO | 統計イベントのインデックス |
| NAME | varchar(64) | NO | 統計イベント名 |
| CLASS | bigint(20) | NO | 統計イベントが属するタイプ |
| VALUE | bigint(20) | NO | 統計イベントに対応する結果値 |
| VALUE_TYPE | varchar(16) | NO | 統計値のタイプ：<ul><li>ADD：累積</li><li>SET：更新</li></ul> |
| STAT_ID | bigint(20) | NO | 統計イベントID |

## クエリ例

