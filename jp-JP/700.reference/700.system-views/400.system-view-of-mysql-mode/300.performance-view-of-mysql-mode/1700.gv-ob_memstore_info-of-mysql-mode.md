# GV$OB_MEMSTORE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>GV$MEMSTORE_INFO</code> は V4.0.0 以降、<code>GV$OB_MEMSTORE_INFO</code> に名前が変更されました。V4.0.0 以降のバージョンでは、新しいビュー名 <code>GV$OB_MEMSTORE_INFO</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>GV$MEMSTORE_INFO</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

現在のテナントがすべてのサーバー上のすべてのパーティションの MemTable の詳細情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーの IP アドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート |
| TENANT_ID | bigint(20) | NO | テナント ID |
| LS_ID | bigint(20) | NO | ログストリーム |
| TABLE_ID | bigint(20) | NO | データシャード ID |
| IS_ACTIVE | varchar(3) | NO | アクティブかどうか |
| START_SCN | bigint(20) unsigned | NO | ストレージ開始時刻 |
| END_SCN | bigint(20) unsigned | NO | ストレージ終了時刻 |
| FREEZE_TS | bigint(20) | NO | 凍結された時刻 |
