# oceanbase.DBA_OB_SERVICES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_OB_SERVICES`は、テナント内のすべての`SERVICE_NAME`に関する情報を表示するために使用されます。

## フィールドの説明

|           フィールド名         |      型     | NULL許容 |  説明  |
|---------------------------|---------------|----------------|--------|
| CREATE_TIME     | timestamp(6) | NO   | サービスの作成日時。     |
| MODIFIED_TIME   | timestamp(6) | NO   | サービス関連情報の更新日時。     |
| SERVICE_NAME_ID | bigint(20)   | NO   | サービス名ID。サービス名を一意に識別するために使用されます。     |
| SERVICE_NAME    | varchar(64)  | NO   | サービス名。     |
| SERVICE_STATUS  | varchar(64)  | NO   | サービス状態。主な状態は以下のとおりです：<ul><li>STARTED：サービスが起動しています。</li><li>STOPPING：サービスが一時停止中です。</li><li>STOPPED：サービスが停止しました。</li></ul>|

## クエリ例

テナント内のすべての`SERVICE_NAME`に関する情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SERVICES;
```

クエリ結果は次のとおりです：

```shell
+----------------------------+----------------------------+-----------------+------------------+----------------+
| CREATE_TIME                | MODIFIED_TIME              | SERVICE_NAME_ID | SERVICE_NAME     | SERVICE_STATUS |
+----------------------------+----------------------------+-----------------+------------------+----------------+
| 2024-06-18 14:18:36.405999 | 2024-06-18 14:18:36.405999 |               3 | service_mysql001 | STARTED        |
+----------------------------+----------------------------+-----------------+------------------+----------------+
1 row in set
```
