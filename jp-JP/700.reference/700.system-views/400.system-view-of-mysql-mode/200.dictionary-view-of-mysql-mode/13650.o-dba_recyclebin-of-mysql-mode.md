# oceanbase.DBA_RECYCLEBIN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのゴミ箱オブジェクトの情報を表示します。

## フィールド説明

|      フィールド名   |  型     | NULL許容 |    説明             |
|----------------|---------------|------------|--------------------|
| OWNER          | varchar(128) | NO   | オブジェクトの元所有者名     |
| OBJECT_NAME    | varchar(128) | NO   | オブジェクトの新しい名前     |
| ORIGINAL_NAME  | varchar(128) | NO   | オブジェクトの元の名前     |
| OPERATION      | varchar(9)   | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。      |
| TYPE           | varchar(25)  | NO   | オブジェクトタイプ     |
| TS_NAME        | varchar(30)  | NO   | オブジェクトが属するテーブルスペース名     |
| CREATETIME     | date         | YES  | オブジェクト作成日時     |
| DROPTIME       | date         | YES  | オブジェクトがゴミ箱に移動した日時     |
| DROPSCN        | bigint(0)    | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。     |
| PARTITION_NAME | varchar(128) | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。     |
| CAN_UNDROP     | varchar(3)   | NO   | オブジェクトをゴミ箱から復元できるか：<ul><li>YES </li><li>NO </li></ul>      |
| CAN_PURGE      | varchar(3)   | NO   | オブジェクトを削除できるか：<ul><li>YES </li><li>NO </li></ul>      |
| RELATED        | bigint(0)    | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。     |
| BASE_OBJECT    | bigint(0)    | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。    |
| PURGE_OBJECT   | bigint(0)    | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。     |
| SPACE          | bigint(0)    | NO   | このフィールドは現在サポートされていません。デフォルトはNULLです。     |
