# oceanbase.DBA_SEQUENCES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のすべてのシーケンスを表示します。

## フィールドの説明

| フィールド名        | 型          | NULL許容 | 説明              |
|----------------|---------------|----------------|-------------------|
| SEQUENCE_OWNER | varchar(128)  | NO   | シーケンスが存在するデータベースの名前   |
| SEQUENCE_NAME  | varchar(128)  | NO   | シーケンス名     |
| MIN_VALUE      | decimal(28,0) | NO   | 取得可能な最小値（含む）     |
| MAX_VALUE      | decimal(28,0) | NO   | 取得可能な最大値（最大値を含む）    |
| INCREMENT_BY   | decimal(28,0) | NO   | 各値取得時のステップサイズ。正の整数または負の整数を指定できますが、0は指定できません      |
| CYCLE_FLAG     | varchar(1)    | NO   | 値を繰り返し取得できるかどうか   |
| ORDER_FLAG     | varchar(1)    | NO   | 値の取得がグローバルに順序付けられているかどうか   |
| CACHE_SIZE     | decimal(28,0) | NO   | 各ノードがキャッシュする値の数    |
| LAST_NUMBER    | decimal(38,0) | NO   | ノードに割り当て可能な次の値を記録します   |

## クエリ例

テナント配下のすべてのシーケンスの詳細情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SEQUENCES;
```

クエリ結果は次のとおりです：

```shell
+----------------+---------------+-----------+-----------+--------------+------------+------------+------------+-------------+
| SEQUENCE_OWNER | SEQUENCE_NAME | MIN_VALUE | MAX_VALUE | INCREMENT_BY | CYCLE_FLAG | ORDER_FLAG | CACHE_SIZE | LAST_NUMBER |
+----------------+---------------+-----------+-----------+--------------+------------+------------+------------+-------------+
| infotest       | seq1          |         1 |        10 |            2 | N          | N          |         30 |           1 |
+----------------+---------------+-----------+-----------+--------------+------------+------------+------------+-------------+
1 row in set
```
