# oceanbase.DBA_OB_USER_DEFINED_RULES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントでカスタムに書き換えられたSQL文のルールを記録します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DB_NAME | varchar(128) | NO | ルール定義時に指定したDB_NAME |
| RULE_NAME | varchar(256) | NO | ルール名 |
| RULE_ID | bigint(20) | NO | ルールID |
| PATTERN | longtext | NO | ルールがマッチする文のパターン |
| REPLACEMENT | longtext | NO | Patternにマッチする文のパターンを書き換える方法を指示するもの |
| NORMALIZED_PATTERN | longtext | NO | パラメータ化後のPattern |
| STATUS | varchar(10) | NO |<ul><li> ENABLEは現在のルールが有効であることを示します。</li><li> DISABLEは現在のルールが無効であることを示します。</li></ul>|
| VERSION | bigint(20) | NO | ルールのバージョン番号 |
| PATTERN_DIGEST | bigint(20) unsigned | NO | NORMALIZED_PATTERNのHash値 |

## クエリ例

現在のテナントのカスタムに書き換えられたSQL文のルールを確認します。

