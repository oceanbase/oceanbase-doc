# oceanbase.DBA_OB_TABLE_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のテーブルに対する履歴的統計情報収集の実行状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | テーブルのユーザー名 |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TASK_ID | varchar(36) | NO | テーブル収集に属するタスクID |
| STATUS | varchar(8) | NO | 収集タスクのステータス<ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| START_TIME | datetime(6) | YES | テーブル収集開始時間 |
| END_TIME | datetime(6) | YES | テーブル収集終了時間 |
| MEMORY_USED | bigint(20) | YES | テーブル収集で使用されたメモリ |
| STAT_REFRESH_FAILED_LIST | text | YES | テーブル収集による統計情報キャッシュのリフレッシュ失敗リスト |
| PROPERTIES | text | YES | テーブル収集のプロパティ設定 |

## クエリ例

このテナント内のテーブル `tbl1` の履歴的統計情報収集の実行状況を確認します。
