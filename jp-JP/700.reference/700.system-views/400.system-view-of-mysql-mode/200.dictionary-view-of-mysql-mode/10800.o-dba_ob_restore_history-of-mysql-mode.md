# oceanbase.DBA_OB_RESTORE_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで完了したテナントレベルの復元タスクを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID                           | bigint(20)          |  NO   |復元対象のjob_id。1つの復元タスクに対応する |
| RESTORE_TENANT_NAME              | varchar(128)        |  NO   |復元対象のテナント名  |
| RESTORE_TENANT_ID                | bigint(20)          |  NO   |復元対象のテナントID  |
| BACKUP_TENANT_NAME               | varchar(128)        |  NO   |バックアップ元のテナント名    |
| BACKUP_TENANT_ID                 | bigint(20)          |  NO   |バックアップ元のテナントID  |
| BACKUP_CLUSTER_NAME              | varchar(128)        |  NO   |バックアップ元のクラスタ名   |
| BACKUP_DEST                      | longtext            |  NO   |バックアップセットのパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指す   |
| RESTORE_SCN                      | bigint(20) unsigned |  NO   |ユーザー指定の復元ポイント  |
| RESTORE_SCN_DISPLAY              | datetime(6)         |  NO   |ユーザー指定の復元ポイントのタイムスタンプ表記  |
| RESTORE_OPTION                   | varchar(4096)       |  NO   |復元オプション。復元開始時にユーザーが指定した `restore_option`  |
| RESTORE_TYPE                      | varchar(4096)            |  NO   |復元タイプ：<ul> <li>`FULL`：フル復元を表す</li> <li> `QUICK`：クイック復元を表す</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main>   |
| START_TIMESTAMP                  | timestamp(6)        |  YES   |復元タスク開始時のタイムスタンプ  |
| FINISH_TIMESTAMP                 | timestamp(6)        |  YES   |復元タスク終了時のタイムスタンプ  |
| STATUS                           | varchar(64)         |  NO   |復元結果：<ul> <li> `SUCCESS`：復元が成功したことを表す </li> <li> `FAILED`：復元に失敗したことを表す </li></ul> |
| BACKUP_PIECE_LIST                | longtext            |  NO   |復元に依存するログアーカイブシャーディングパスのリスト。シャーディング間は `,` で区切る。例：`file:///data/nfs/backup/archive/2_1_2,file:///data/nfs/backup/archive/2_1_3` |
| BACKUP_SET_LIST                  | longtext            |  NO   |復元に依存するデータバックアップセットパスのリスト。バックアップセット間は `,` で区切る。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc` |
| BACKUP_CLUSTER_VERSION           | bigint(20)          |  NO   |バックアップ元クラスタのバージョン番号 |
| LS_COUNT                         | bigint(20)          |  NO   |復元されたログストリームの総数   |
| FINISH LS COUNT                  | bigint(20)          |  NO   |復元済みログストリーム数  |
| TABLET COUNT                     | bigint(20)          |  NO   |復元シャード総量  |
| FINISH TABLET COUNT              | bigint(20)          |  NO   |復元済みシャード数  |
| TOTAL BYTES                      | bigint(20)          |  NO   |復元総バイト数  |
| TOTAL BYTES DISPLAY              | varchar(27)         |  NO   |ストレージ容量単位で表示された復元総バイト数  |
| FINISH BYTES                     | bigint(20)          |  NO   |復元済みバイト数  |
| FINISH BYTES DISPLAY             | varchar(27)         |  NO   |ストレージ容量単位で表示された復元済みバイト数  |
| DESCRIPTION                      | varchar(1024)       |  YES   |復元コマンドで指定された `DESCRIPTION` 情報  |
| COMMENT                          | varchar(1024)       |  YES   |復元失敗時に失敗情報を記録する  |
