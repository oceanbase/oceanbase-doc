# oceanbase.DBA_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのパーティションテーブルに関するテンプレート化されたセカンダリパーティション情報を表示します。

## フィールドの説明

|         フィールド名          |       タイプ        | NULLを許容するか |    説明     |
|-----------------------|-----------------|------------|-----------|
| USER_NAME             | varchar(128)    | NO         | パーティションテーブルの所有者   |
| TABLE_NAME            | varchar(128)    | NO         | パーティションテーブル名      |
| SUBPARTITION_NAME     | varchar(132)    | NO         | サブパーティション名      |
| SUBPARTITION_POSITION | bigint(21)      | NO         | サブパーティション位置     |
| TABLESPACE_NAME       | varchar(30)     | NO         | パーティションが属するテーブルスペース名 |
| HIGH_BOUND            | mediumtext | NO         | パーティションテンプレート式   |
| COMPRESSION           | varchar(4)      | NO         | サブパーティションテンプレート内で新しく追加される複合パーティションごとに、そのサブパーティションデータを圧縮形式で保存するかどうかを示します。<ul><li>YES</li><li>（デフォルト）NO <br>この値はサブパーティションテンプレートで指定可能です </li></ul>  |
| INDEXING              | varchar(4)      | NO         | サブパーティションテンプレート内で新しく追加される複合パーティションごとに、そのサブパーティションデータを部分的なインデックスとして扱うかどうかを示します。<ul><li>ON</li><li>（デフォルト）OFF<br>この値はサブパーティションテンプレートで指定可能です </li></ul>   |
| READ_ONLY             | varchar(4)      | NO         | サブパーティションテンプレート内で新しく追加される複合パーティションごとに、そのサブパーティションデータを読み取り専用とするかどうかを示します。<ul><li>YES</li><li>（デフォルト）NO<br>この値はサブパーティションテンプレートで指定可能です </li></ul>   |

## クエリ例

ユーザーテナントは、自身のテナントにおけるパーティションテーブルのテンプレート化されたサブパーティション情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPARTITION_TEMPLATES;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| USER_NAME | TABLE_NAME | SUBPARTITION_NAME | SUBPARTITION_POSITION | TABLESPACE_NAME | HIGH_BOUND | COMPRESSION | INDEXING | READ_ONLY |

| infotest  | t2_m_rch   | p0                |                     1 | NULL            | NULL       | NULL        | NULL     | NULL      |
| infotest  | t2_m_rch   | p1                |                     2 | NULL            | NULL       | NULL        | NULL     | NULL      |
| infotest  | t2_m_rch   | p2                |                     3 | NULL            | NULL       | NULL        | NULL     | NULL      |
| infotest  | t2_m_rch   | p3                |                     4 | NULL            | NULL       | NULL        | NULL     | NULL      |
| infotest  | t2_m_rch   | p4                |                     5 | NULL            | NULL       | NULL        | NULL     | NULL      |
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
5 rows in set
```
