# information_schema.role_routine_grants

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.3x系では、このビューはV4.3.3バージョンから導入されました。V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

`role_routine_grants` ビューは、現在のセッションでユーザーに付与された有効なロールのルーチン権限情報、およびそれらのロールが他のロールに付与したルーチン権限情報を表示します。

## フィールドの説明

| **フィールド名**   | **型**     | **NULL許容**  | **説明**        |
|----------------|--------------|----------------------|-----------------|
| GRANTOR        | varchar(97)  | YES  | そのロールに権限を付与したアカウントのユーザー名部分です。    |
| GRANTOR_HOST   | varchar(256) | YES  | そのロールに権限を付与したアカウントのホスト部分です。      |
| GRANTEE        | varchar(32)  | NO   | そのロールに対応するアカウントのユーザー名部分です。      |
| GRANTEE_HOST   | varchar(255) | NO   | そのロールに対応するアカウントのホスト名部分です。    |
| SPECIFIC_CATALOG | varchar(3) | NO   | そのロールに付与されたルーチンが属するディレクトリ名です。この値は常にdefです。   |
| SPECIFIC_SCHEMA  | varchar(64)| NO   | そのロールに付与されたルーチンが属するデータベース名です。   |
| SPECIFIC_NAME    | varchar(64)| NO   | そのロールに付与されたルーチンの名前です。         |
| ROUTINE_CATALOG  | varchar(3) | NO   | そのロールに付与されたルーチンが属するディレクトリ名です。この値は常にdefです。         |
| ROUTINE_SCHEMA   | varchar(64)| NO   | そのロールに付与されたルーチンが属するデータベース名です。          |
| ROUTINE_NAME     | varchar(64)| NO   | そのロールに付与されたルーチンの名前です。         |
| PRIVILEGE_TYPE   | varchar(90)| NO   | 付与された権限です。この値はルーチンレベルで付与可能な任意の権限です。         |
| IS_GRANTABLE     | varchar(3) | NO   | そのロールの権限が他のユーザーに付与可能かどうかを示します。         |

## クエリ例

1. ロールと関数を作成します。

   ロール `employee` を作成します：

   ```shell
   obclient [test]> CREATE ROLE employee;
   ```

   関数 `add_numbers` を作成します：

   ```shell
   obclient [test]> DELIMITER //
   ```

   ```shell
   obclient [test]> CREATE FUNCTION test.add_numbers(a INT, b INT)
   RETURNS INT
   BEGIN
         RETURN a + b;
   END;//
   ```

   ```shell
   obclient [test]> DELIMITER ;
   ```

2. ロールにルーチン権限を付与します。

   ```shell
   obclient [test]> GRANT EXECUTE,ALTER ROUTINE ON test.add_numbers TO employee;
   ```

3. ユーザーにロールを付与します。

   ```shell
   obclient [test]> GRANT employee TO user1;
   ```

4. ユーザー`user1`でデータベースに接続します。

5. 現在のセッションで`employee`ロールを有効化します。

   ```shell
   obclient [test]> SET ROLE employee;
   ```

6. 現在のセッションでユーザーが付与されている有効なロールのルーチン権限情報を確認します。

   ```shell
   obclient [test]> USE information_schema;
   ```

   ```shell
   obclient [information_schema]> SELECT * FROM information_schema.role_routine_grants;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
   | GRANTOR | GRANTOR_HOST | GRANTEE   | GRANTEE_HOST | SPECIFIC_CATALOG | SPECIFIC_SCHEMA | SPECIFIC_NAME | ROUTINE_CATALOG | ROUTINE_SCHEMA | ROUTINE_NAME | PRIVILEGE_TYPE        | IS_GRANTABLE |
   +---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
   | root    | %            | employee  | %            | def              | test            | add_numbers   | def             | test           | add_numbers  | Execute,Alter Routine | NO           |
   +---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
   1 row in set
   ```
