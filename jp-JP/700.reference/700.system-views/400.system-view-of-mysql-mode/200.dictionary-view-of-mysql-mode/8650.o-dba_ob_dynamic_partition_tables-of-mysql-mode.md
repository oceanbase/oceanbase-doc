# oceanbase.DBA_OB_DYNAMIC_PARTITION_TABLES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.4.x系では、このビューはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このビューはV4.3.5 BP2バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

テナント内の動的パーティションテーブル情報を表示します。

## フィールドの説明

|        フィールド        |      型      | NULL許容 | 説明 |
|--------------------|---------------|-------------|------|
| DATABASE_NAME      | varchar(128)  | NO          | 動的パーティションテーブルが存在するデータベース名。|
| TABLE_NAME         | varchar(256)  | NO          | 動的パーティションテーブル名。|
| TABLE_ID           | bigint(20)    | NO          | 動的パーティションテーブルID。|
| MAX_HIGH_BOUND_VAL | varchar(4096) | NO          | 最大Rangeパーティションの上限値。|
| ENABLE             | varchar(4096) | NO          | 動的パーティション管理を有効にするかどうか。|
| TIME_UNIT          | varchar(4096) | NO          | 動的パーティション管理の`time_unit`。|
| PRECREATE_TIME     | varchar(4096) | NO          | 動的パーティション管理の`precreate_time`。|
| EXPIRE_TIME        | varchar(4096) | NO          | 動的パーティション管理の`expire_time`。|
| TIME_ZONE          | varchar(4096) | NO          | 動的パーティション管理の`time_zone`。|
| BIGINT_PRECISION   | varchar(4096) | NO          | 動的パーティション管理の`bigint_precision`。|

## クエリ例

テナント内の動的パーティションテーブルの情報を1件確認します。

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_DYNAMIC_PARTITION_TABLES LIMIT 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
     DATABASE_NAME: db_test
        TABLE_NAME: tbl2
          TABLE_ID: 502062
MAX_HIGH_BOUND_VAL: '2025-04-15 14:00:00'
            ENABLE: TRUE
         TIME_UNIT: HOUR
    PRECREATE_TIME: 3HOUR
       EXPIRE_TIME: 1DAY
         TIME_ZONE: +8:00
  BIGINT_PRECISION: NONE
1 row in set
```
