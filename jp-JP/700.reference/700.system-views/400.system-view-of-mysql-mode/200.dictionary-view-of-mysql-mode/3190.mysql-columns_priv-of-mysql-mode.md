# mysql.columns_priv

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`mysql.columns_priv` ビューは、ユーザーに付与された列権限を確認するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| Host        | varchar(255) | NO   | 権限を付与したホスト名。'%' の場合、すべてのホストにこの権限が付与されたことを意味します。    |
| Db          | varchar(128) | NO   | テーブルが属するデータベース名     |
| User        | varchar(128) | NO   | 権限を付与されたユーザー名     |
| Table_name  | varchar(128) | NO   | テーブル名     |
| Column_name | varchar(128) | NO   | 列名     |
| Column_priv | varchar(31)  | NO   | 列権限。Select、Insert、Updateなどが含まれます。     |
| Timestamp   | datetime     | YES  | タイムスタンプ。権限が最後に変更された時間を示します。     |

## クエリ例

1. ユーザーu1にテーブルt1の列c1に対するSELECT権限、および列c2に対するUPDATE権限を付与します。

   ```shell
   obclient [mysql]> grant select(c1), update(c2) on t1 to u1;
   ```

2. ユーザーu1に付与された列権限を確認します。

   ```shell
   obclient [mysql]> select * from mysql.columns_priv;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +------+------+------+------------+-------------+-------------+---------------------+
   | Host | Db   | User | Table_name | Column_name | Column_priv | Timestamp           |
   +------+------+------+------------+-------------+-------------+---------------------+
   | %    | test | u1   | t1         | c2          | Update      | 2024-04-24 14:38:20 |
   | %    | test | u1   | t1         | c1          | Select      | 2024-04-24 14:38:20 |
   +------+------+------+------------+-------------+-------------+---------------------+
   2 rows in set (0.092 sec)
   ```
