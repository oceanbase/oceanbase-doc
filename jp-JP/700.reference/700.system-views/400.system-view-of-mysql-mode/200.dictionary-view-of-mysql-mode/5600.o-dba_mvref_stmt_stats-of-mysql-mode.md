# oceanbase.DBA_MVREF_STMT_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_MVREF_STMT_STATS` は、リフレッシュステートメントに関連する情報を記述するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_OWNER | varchar(128) | NO | マテリアライズドビューの所有者名 |
| MV_NAME | varchar(128) | NO | マテリアライズドビュー名 |
| REFRESH_ID | bigint(20) | NO | リフレッシュID |
| STEP | bigint(20) | NO | ステップ番号。1から連続して付番されます |
| SQLID | varchar(32) | YES | SQL ID |
| STMT | longtext | NO | SQLテキスト |
| EXECUTION_TIME | bigint(20) | NO | SQL実行時間（秒単位） |
| EXECUTION_PLAN | longtext | YES | 内部スタッフによる問題調査時のみ使用<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性があり、デフォルト値はNULLです。</p></main> |
