## 機能の概要

## フィールドの説明

|     **フィールド名**     |   **タイプ**   | **NULL値を許容するか** | **説明** |
|------------------|------------|-----------------|--------|
| Time_zone_id     | bigint(20) | NO              | タイムゾーンID  |
| Use_leap_seconds | varchar(8) | NO              | レプソンドを使用するか |
