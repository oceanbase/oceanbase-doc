# information_schema.CHARACTER_SETS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

OceanBaseデータベースの文字セット情報を表示します。

## フィールドの説明

|       **フィールド名**       |    **タイプ**    | **NULL許容** | **説明**  |
|----------------------|--------------|----------------|---------|
| CHARACTER_SET_NAME   | varchar(128) | NO             | 文字セット名   |
| DEFAULT_COLLATE_NAME | varchar(128) | NO             | 文字セット比較方法 |
| DESCRIPTION          | varchar(64)  | NO             | 文字セットの説明 |
| MAXLEN               | bigint(20)   | NO             | 文字セットの最大長 |

## クエリ例

OceanBaseデータベースの文字セット情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.CHARACTER_SETS;
```
