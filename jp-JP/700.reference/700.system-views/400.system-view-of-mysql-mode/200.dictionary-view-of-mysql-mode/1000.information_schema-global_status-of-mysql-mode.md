# information_schema.GLOBAL_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

OceanBaseデータベースのグローバルサーバーステータス変数情報を記録します。

## フィールドの説明

|    **フィールド名**    |    **型**     | **NULL許容** |   **説明**    |
|----------------|---------------|----------------|-------------|
| VARIABLE_NAME  | varchar(128)  | NO             | グローバル状態に対応する変数名 |
| VARIABLE_VALUE | varchar(1024) | YES            | グローバル状態に対応する変数内容 |

## クエリ例

OceanBaseデータベース内のグローバルサーバーステータス変数と対応する値を確認します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.GLOBAL_STATUS;
```

クエリ結果は次のとおりです：

```shell
+-------------------+----------------+
| VARIABLE_NAME     | VARIABLE_VALUE |
+-------------------+----------------+
| Threads_connected | 1              |
| Uptime            | 254110         |
+-------------------+----------------+
2 rows in set
```
