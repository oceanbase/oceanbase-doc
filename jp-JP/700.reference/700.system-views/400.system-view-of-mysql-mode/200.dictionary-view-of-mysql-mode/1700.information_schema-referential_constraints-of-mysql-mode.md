# information_schema.REFERENTIAL_CONSTRAINTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

外部キー制約のメタデータを表示するために使用されます。

## フィールド説明

|         **フィールド名**          |                 **型**                  | **NULL許容** |                            **説明**                            |
|---------------------------|-----------------------------------------|----------------|--------------------------------------------------------------|
| CONSTRAINT_CATALOG        | varchar(64)                           | NO             | この値は常にdefです                                                    |
| CONSTRAINT_SCHEMA         | varchar(128)                            | NO             | 制約が属するデータベースの名前                                                     |
| CONSTRAINT_NAME           | varchar(128)                            | NO             | 制約名                                                         |
| UNIQUE_CONSTRAINT_CATALOG | varchar(64)                           | NO             | この値は常にdefです                                                    |
| UNIQUE_CONSTRAINT_SCHEMA  |  varchar(128)  | NO             | 制約が参照する一意制約または主キーを持つデータベースの名前                                           |
| UNIQUE_CONSTRAINT_NAME    | varchar(128)                            | NO            | 制約が参照する一意制約または主キーの名前                                              |
| MATCH_OPTION              | varchar(64)                             | NO             | 制約MATCHプロパティの値。有効な値はNONEのみです                                |
| UPDATE_RULE               | varchar(64)                             | NO             | 制約ON UPDATEプロパティの値。取り得る値はCASCADE、SET NULL、RESTRICT、NO ACTIONです  |
| DELETE_RULE               | varchar(64)                             | NO             | 制約ON DELETEプロパティの値。取り得る値はCASCADE、SET NULL、RESTRICT、NO ACTIONです |
| TABLE_NAME                | varchar(256)                            | NO             | 制約が存在するサブテーブルの名前                                                    |
| REFERENCED_TABLE_NAME     | varchar(256)                            | NO             | 制約が参照する親テーブルの名前                                                   |

## クエリ例

テーブル `tbl4` の外部キー制約のメタデータ情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.REFERENTIAL_CONSTRAINTS WHERE TABLE_NAME='tbl4';
```

