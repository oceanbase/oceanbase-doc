# oceanbase.DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_BALANCE_TASKS`は、テナントが現在実行中のロードバランシングタスクを表示します。同一テナント内で複数のロードバランシングタスクが同時に実行されている場合があり、これらのタスクはすべて同一のロードバランシングジョブ（JOB）に属します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | ------- |
| TASK_ID                  | bigint(20)    | NO  | ロードバランシングタスクID |
| CREATE_TIME              | timestamp(6)  | YES | 作成時間 |
| MODIFY_TIME              | timestamp(6)  | YES | 情報更新時間 |
| TASK_TYPE                | varchar(64)   | NO  | タスクタイプ <ul><li>`LS_SPLIT`：ログストリームの分割  </li><li>`LS_ALTER`：ログストリームの属性変更 </li><li>`LS_MERGE`：ログストリームのメジャーコンパクション </li><li>`LS_TRANSFER`：ログストリームのTransfer </li></ul>|
| SRC_LS                   | bigint(20)    | NO  | ソースログストリーム（データソースから生成されるログデータストリーム） |
| DEST_LS                  | bigint(20)    | NO  | デスティネーションログストリーム |
| PART_LIST                | longtext      | YES | パーティションリスト。ユーザーテーブルのパーティションとグローバルインデックスのパーティションを含む |
| FINISHED_PART_LIST       | longtext      | YES | 現在完了したバランシング処理のパーティションリスト |
| PART_COUNT               | bigint(20)    | YES | パーティションリスト内のパーティション数 |
| FINISHED_PART_COUNT      | bigint(20)    | YES | 現在完了したバランシング処理のパーティション数 |
| LS_GROUP_ID              | bigint(20)    | NO  | ログストリームグループID |
| STATUS                   | varchar(64)   | NO  | タスクステータス <ul><li>`INIT`：タスクの作成  </li><li>`CREATE_LS`：ログストリームの作成 </li><li>`ALTER_LS`：ログストリームの属性変更 </li><li>`SET_LS_MERGING`：ログストリームのメジャーコンパクション </li> <li>`TRANSFER`：ログストリームのTransfer</li> <li>`DROP_LS`：ログストリームの削除 </li><li>`COMPLETED`：タスクの実行成功 </li><li>`CANCELED`：タスクのキャンセル </li></ul>|
| PARENT_LIST              | varchar(1024) | YES | 親タスクリスト |
| CHILD_LIST               | varchar(1024) | YES | 子タスクリスト |
| CURRENT_TRANSFER_TASK_ID | bigint(20)    | NO  | 現在のロードバランシングタスクがトリガーするTransferタスクID |
| JOB_ID                   | bigint(20)    | NO  | 現在のタスクが属するJob ID |
| COMMENT                  | longtext      | YES | コメント情報 |
| BALANCE_STRATEGIE         | varchar(64)   | YES | Balanceタスクに対応するバランシング戦略：<ul><li>`LS balance by migrate`：移行によるバランシング  </li><li>`LS balance by alter`：ログストリームの属性変更によるバランシング </li><li>`LS balance by expand`：スケールアップによるバランシング </li><li>`LS balance by shrink`：スケールダウンによるバランシング </li><li>`partition balance`：パーティションバランシング </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.2.x系では、このフィールドはV4.2.4以降で導入されました。V4.3.x系では、このフィールドはV4.3.2以降で導入されました。</p></main> |

## クエリ例

このテナントで現在実行中のロードバランシングタスクを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_TASKS\G
```
