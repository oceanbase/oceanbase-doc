# oceanbase.DBA_OB_SPM_EVO_RESULT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPM計画進化情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OWNER               | varchar(128) | NO   |    エボリューションタスクを実行したユーザー。  |
| RECORD_TIME         | timestamp(6) | NO   |    エボリューション結果が記録された時間。  |
| SVR_IP              | varchar(46)  | NO   |    エボリューションタスクを実行したサーバーのIPアドレス。  |
| SVR_PORT            | bigint(20)   | NO   |    エボリューションタスクを実行したサーバーのポート番号。 |
| SQL_ID              | varchar(32)  | NO   |    エボリューションタスクを実行したSQL ID。  |
| TYPE                | varchar(32)  | NO   |    記録のタイプ：<ul><li>`OnlineEvolve`：オンラインエボリューションモードで、エボリューションタスクの結果が記録されています。以下のすべてのフィールドは、タイプがこの値の場合にのみ有効です。</li><li>`FirstBaseline`：最初のベースラインを生成したSQLが記録されています。</li><li>`UnReproducible`：現在のSQLを再現できるベースラインがないことを示しています。</li><li>`BaselineFirst`：ベースライン優先モードで新しい計画が生成されたものの、ベースライン計画が復元され使用されたことを示しています。</li><li>`BestBaseline`：最適なベースライン計画が生成され使用されたことを示しています。</li><li>`FixedBaseline`：固定ベースライン計画が使用されたことを示しています。</li></ul>  |
| START_TIME          | timestamp(6) | YES  |  エボリューションタスク開始時刻。    |
| END_TIME            | timestamp(6) | YES  |   エボリューションタスク終了時刻。   |
| STATUS              | varchar(7)   | YES  |   エボリューションタスクの状態：<ul><li>`success`：エボリューションタスクが正常に終了したことを示しています。</li><li>`timeout`：エボリューションタスクがタイムアウトしたことを示しています（この場合、エボリューション中の実行情報に基づいてどちらの計画が優れているか判断されます）。   |
| NEW_PLAN_BETTER     | tinyint(4)   | YES  |   エボリューション計画が優れているかどうかを示しています。   |
| EVO_PLAN_EXEC_COUNT | bigint(20)   | YES  |   エボリューション中のエボリューション計画の実行回数。   |
| EVO_PLAN_CPU_TIME   | bigint(20)   | YES  |   エボリューション中のエボリューション計画の平均CPUコスト。   |
| BASELINE_EXEC_COUNT | bigint(20)   | YES  |   エボリューション中のベースライン計画の実行回数。  |
| BASELINE_CPU_TIME   | bigint(20)   | YES  |   エボリューション中のベースライン計画の平均CPUコスト。   |
