# oceanbase.DBA_OB_RESTORE_PROGRESS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在、テナントで進行中のリストアタスクを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| ------ | ------ | ------ | ------ |
| JOB_ID                           | bigint(20)          |  NO   |復元対象のjob_id。1つの復元タスクに対応します  |
| RESTORE_TENANT_NAME              | longtext            |  NO   |復元対象のテナント名  |
| RESTORE_TENANT_ID                | longtext            |  NO   |復元対象のテナントID  |
| BACKUP_TENANT_NAME               | longtext            |  NO   |バックアップ元テナント名  |
| BACKUP_TENANT_ID                 | longtext            |  NO   |バックアップ元テナントID  |
| BACKUP_CLUSTER_NAME              | longtext            |  NO   |バックアップ元クラスタ名  |
| BACKUP_DEST                      | longtext            |  NO   |バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します    |
| RESTORE_OPTION                   | longtext            |  NO   |復元オプション。復元を開始する際にユーザーが指定した`restore_option`  |
| RESTORE_TYPE                     | varchar(4096)            |  NO   |復元タイプ。<ul> <li>`FULL`：フル復元を表します</li> <li> `QUICK`：クイック復元を表します</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main> |
| RESTORE_SCN                      | bigint(20) unsigned |  NO   |ユーザーが指定した復元ポイント  |
| RESTORE_SCN_DISPLAY              | datetime(6)         |  NO   |ユーザーが指定した復元ポイントのタイムスタンプ表現  |
| STATUS                           | longtext            |  NO   |復元状態：システムテナントの復元タスクと復元対象テナントの復元タスクの状態が一致しません。<br>システムテナント：<ul><li> `CREATE_TENANT`：テナントの作成。この段階でシステムテナントが復元対象テナントを作成します </li> <li> `WAIT_TENANT_RESTORE_FINISH`：復元対象テナントの復元終了を待機 </li> <li> `RESTORE_SUCCESS`：テナントの復元に成功しました </li> <li> `RESTORE_FAIL`：テナントの復元に失敗しました </li></ul> <br>復元対象テナント：<ul><li> `RESTORE_PRE`：復元前の準備。暗号化を設定している場合、暗号化情報を設定します </li> <li> `RESTORE_CREATE_INIT_LS`：ログストリームの作成 </li> <li> `RESTORE_WAIT_LS`：ログストリームの復元完了を待機 </li> <li> `POST_CHECK`：テナントロールをチェックし、スタンバイデータベースに復元します </li> <li> `UPGRADE`：アップグレード。バージョン間復元の場合、テナントはアップグレードプロセスを実行します </li> <li> `RESTORE_SUCCESS`：復元に成功しました </li> <li> `RESTORE_FAIL`：復元に失敗しました </li></ul> |
| START_TIMESTAMP                  | datetime(6)         |  NO   |復元タスク開始時刻のタイムスタンプ  |
| BACKUP_SET_LIST                  | longtext            |  NO   |復元に依存するデータバックアップセットパスのリスト。バックアップセット間は`,`で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`  |
| BACKUP_PIECE_LIST                | longtext            |  NO   |復元に依存するログアーカイブのシャードパスリスト。シャード間は `,` で区切る。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`  |
| RECOVER_SCN                      | bigint(20) unsigned |  NO   |ログの復元ポイント。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_SCN_DISPLAY              | datetime(6)         |  NO   |ログの復元ポイントをタイムスタンプで表す。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_PROGRESS                 | decimal(6,2)        |  NO   |ログ復元の進捗状況。結果は小数点以下2桁を保持します。例：`87.65` と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TABLET_COUNT                     | bigint(20)          |  NO   |復元待ちのTabletの総数。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main>  |
| FINISH_TABLET_COUNT              | bigint(20)          |  NO   |復元が完了したTabletの総数。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RESTORE_PROGRESS                 | decimal(6,2)        |  NO   |データ復元の進捗状況。結果は小数点以下2桁を保持します。例：`87.65` と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TOTAL_BYTES                      | bigint(20)          |  NO   |復元総バイト数  |
| TOTAL_BYTES_DISPLAY              | varchar(27)         |  NO   |復元総バイト数。ストレージ容量単位で表示されます  |
| FINISH_BYTES                     | bigint(20)          |  NO   |完了した復元バイト数  |
| FINISH_BYTES_DISPLAY             | varchar(27)         |  NO   |完了した復元バイト数。ストレージ容量単位で表示されます  |
| DESCRIPTION                      | longtext            |  NO   |復元コマンドで指定された `DESCRIPTION` 情報   |
