# oceanbase.DBA_OB_TENANT_flashBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.5 BP4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OB_TENANT_flashBACK_LOG_SCN` は、このテナント内で行われた各ログクリップに関する情報を表示するために使用されます。

## フィールドの説明

| フィールド        | タイプ         | NULLか | 説明                                       |
|------------|--------------|-------------|------------------------------------------|
| TIMESTAMP         | timestamp(6) | NO          | 作成時間、単位はマイクロ秒                   |
| OP_TYPE           | varchar(64)  | NO          | 操作タイプ。以下を含みます：<ul><li>`FAILOVER_TO_PRIMARY`：これはFailover操作のタイプであり、プライマリテナントが利用不可能な場合にスタンバイテナントをプライマリテナントに切り替える操作です</li><li>`FLASHBACK_STANDBY_LOG`：これはスタンバイテナントのログトリミング操作のタイプであり、スタンバイテナントのログを指定されたSCN位置までトリミングするために使用されます</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20)   | YES         | テナントログを後ろから前へとトリミングする終了点             |
| SWITCHOVER_EPOCH  | bigint(20)   | YES         | テナントのロールが`NORMAL`状態に切り替わった時の`SWITCHOVER_EPOCH`。`SWITCHOVER_EPOCH`は、テナントのロール切り替え（Switchover/Failover）操作を識別するための一意の識別子です |

## クエリ例

このテナント内で行われた各ログクリップに関する情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```

実行結果は次のとおりです：

```shell
+-----------+----------------------------+------------------+---------------------+---------------------+
| TENANT_ID | TIMESTAMP                  | SWITCHOVER_EPOCH | OP_TYPE             | FLASHBACK_LOG_SCN   |
+-----------+----------------------------+------------------+---------------------+---------------------+
|      1006 | 2025-05-21 16:48:53.583749 | 1747817333380437 | FAILOVER TO PRIMARY | 1747817331313513000 |
+-----------+----------------------------+------------------+---------------------+---------------------+
1 row in set
```
