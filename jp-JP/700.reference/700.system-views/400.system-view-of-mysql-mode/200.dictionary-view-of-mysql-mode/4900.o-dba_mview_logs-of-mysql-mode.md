# oceanbase.DBA_MVIEW_LOGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_MVIEW_LOGS` は、マテリアライズドビューのログ情報を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| LOG_OWNER | varchar(128) | NO | マテリアライズドビューのログ所有者名を表します |
| MASTER | varchar(128) | NO | マテリアライズドビューのログが属するメインテーブル名を表します |
| LOG_TABLE | varchar(128) | NO | マテリアライズドビューのログテーブル名を表します |
| LOG_TRIGGER | varchar(128) | YES | メインテーブル上の行トリガーを表し、行をマテリアライズドビューのログに挿入するために使用されます<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はNULLです。</p></main> |
| ROWIDS | varchar(3) | NO | Rowid情報を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| PRIMARY_KEY | varchar(3) | NO | 主キー情報を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| OBJECT_ID | varchar(3) | NO | オブジェクトテーブルにオブジェクト識別情報が記録されているかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はNOです。</p></main> |
| FILTER_COLUMNS | varchar(3) | NO | フィルターカラム情報を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| SEQUENCE | varchar(3) | NO | 追加のソート情報を提供するシーケンス値を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| INCLUDE_NEW_VALUES | varchar(3) | NO | 古い値と新しい値を同時に記録するかどうかを表します<ul><li>YES：古い値と新しい値を同時に記録 </li><li>NO：古い値を記録するが新しい値は記録しない </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| PURGE_ASYNCHRONOUS | varchar(3) | NO | マテリアライズドビューのログが非同期でクリーンアップされるかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| PURGE_DEFERRED | varchar(3) | NO | マテリアライズドビューのログが遅延方式でクリーンアップされるかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| PURGE_START | datetime | YES | 遅延クリーンアップの開始日付を表します |
| PURGE_INTERVAL | varchar(200) | YES | 遅延クリーンアップのクリーンアップ時間間隔を表します |
| LAST_PURGE_DATE | datetime | YES | 最終のマテリアライズドビューのログクリーンアップ日付を表します |
| LAST_PURGE_STATUS | bigint(1) | NO | 最終のマテリアライズドビューのログクリーンアップの状態を表します<ul><li>エラーコード  </li><li>0 ：成功 </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常に0です。</p></main> |
| NUM_ROWS_PURGED | bigint(20) | YES | 最終のマテリアライズドビューのログクリーンアップで削除された行数を表します |
| COMMIT_SCN_BASED | varchar(3) | NO | マテリアライズドビューのログがコミットSCNに基づいているかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| STAGING_LOG | varchar(3) | NO | マテリアライズドビューのログが同期更新の一時ログかどうかを示します。<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性があり、デフォルト値はNOです。</p></main> |
| PURGE_DOP          | bigint(20)   | NO   | マテリアライズドビューのログをクリーンアップする並列度。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、このフィールドはV4.3.5 BP2バージョンから導入されました。</p></main>|
| LAST_PURGE_TIME    | bigint(20)   | YES  | 最終のマテリアライズドビューのログクリーンアップタスクにかかった時間。単位は秒。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、このフィールドはV4.3.5 BP2バージョンから導入されました。</p></main>|
