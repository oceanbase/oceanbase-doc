# oceanbase.DBA_TAB_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのテーブルの列のヒストグラムを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | テーブルの所有者 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| COLUMN_NAME | varchar(128) | NO | オブジェクトタイプ列の列名またはプロパティ |
| ENDPOINT_NUMBER | decimal(10,0) | NO | ヒストグラムのバケット数 |
| ENDPOINT_VALUE | decimal(10,0) | NO | このバケットの標準化されたエンドポイント値 |
| ENDPOINT_ACTUAL_VALUE | text | NO | このバケットエンドポイントの実際の文字列値（非標準化） |
| ENDPOINT_ACTUAL_VALUE_RAW | text | NO | プリミティブ形式のエンドポイント実際値 |
| ENDPOINT_REPEAT_COUNT | decimal(10,0) | NO | エンドポイント頻度（ハイブリッドヒストグラムにのみ適用され、他のヒストグラムタイプでは0に設定されます） |
| SCOPE | varchar(7) | NO | この値は、グローバル一時テーブル以外の任意のテーブルで収集される統計情報に使用されます。<br>グローバル一時テーブルの場合、可能な値は次のとおりです：<ul><li>SESSION：統計情報がセッション固有であることを示します。</li><li>SHARED：統計情報がすべてのセッションで共有されることを示します。</li></ul> |
