# oceanbase.DBA_OB_BACKUP_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナント自身のバックアップジョブタスクを表示します。

## フィールド説明

| フィールド名 | フィールド名 | NULL許容 | フィールド名 |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | バックアップJOBタスクID。1回のバックアップに対応する1件のJOBタスクレコード |
| INCARNATION | bigint(20) | NO | Flashback Database後の分身の回数を示す |
| BACKUP_SET_ID | bigint(20) | YES | バックアップセットID。sysテナントはデフォルトで0、通常テナントは1から連番 |
| INITIATOR_TENANT_ID | bigint(20) | NO | タスク発起者のテナントID。バックアップSQLコマンドを実行したテナントIDに対応する |
| INITIATOR_JOB_ID | bigint(20) | NO | タスク発起者が属するJOB_ID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | このJOBレベルバックアップタスクに関連する、バックアップを実行する必要があるテナントID |
| PLUS_ARCHIVELOG | varchar(4096) | NO | ログ補完機能の有無：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul> |
| BACKUP_TYPE | varchar(4096) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを示す </li> <li>`INC`：増分バックアップを示す</li></ul> |
| JOB_LEVEL | varchar(4096) | NO | JOBレベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始する場合</li><li>SYS_TENANT：sysテナントが指定されたテナントのバックアップタスクを開始する場合</li><li>USER_TENANT：通常テナントが自身のバックアップを開始する場合</li></ul> |
| ENCRYPTION_MODE | varchar(4096) | YES | 暗号化モード：<ul><li>None：暗号化しないことを示す</li><li>Password：パスワードによるみだけの保護を示す</li><li>Password Encryption ：暗号化し、パスワードで保護することを示す</li><li>Transparent Encryption：TDE暗号化を使用することを示す</li><li>Dual mode Encryption ：TDE暗号化およびパスワード保護を使用することを示す</li></ul> </br>現在、NoneとPasswordの2つのモードのみサポートしています |
| PASSWD | varchar(4096) | YES | パスワード |
| START_TIMESTAMP | timestamp(6) | NO | JOBレベルバックアップタスクの開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | JOBレベルバックアップタスクの終了時間 |
| STATUS | varchar(4096) | NO | バックアップの状態 |
| RESULT | bigint(20) | NO | バックアップエラーコードの結果 |
| COMMENT | varchar(4096) | YES | エラーコードの説明 |
| DESCRIPTION | varchar(4096) | YES | ユーザー指定のバックアップ説明情報 |
| PATH | varchar(4096) | YES | バックアップパス |

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_JOBS\G
```
