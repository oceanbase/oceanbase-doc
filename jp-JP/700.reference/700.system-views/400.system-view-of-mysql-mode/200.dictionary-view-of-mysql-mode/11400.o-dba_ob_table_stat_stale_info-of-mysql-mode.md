# oceanbase.DBA_OB_TABLE_STAT_STALE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下で、前回統計情報を収集して以来に各テーブルで発生したDML操作の回数、および現在の統計情報が期限切れかどうかを表示します。

## フィールド説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| DATABASE_NAME | varchar(128) | NO | テーブルが存在するデータベース名 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| PARTITION_NAME | varchar(128) | YES | パーティション名。パーティションテーブルにおいて、この列の値がNULLの場合、現在のレコードがテーブルレベルで集計されていることを示します |
| SUBPARTITION_NAME | varchar(128) | YES | サブパーティション名。サブパーティションテーブルにおいて、この列の値がNULLの場合、現在のレコードがテーブルレベルまたはパーティションレベルで集計されていることを示します |
| LAST_ANALYZED_ROWS | bigint(20) | YES | 前回統計情報を収集した時の行数。値がNULLの場合、統計情報が収集されたことがないことを示します |
| LAST_ANALYZED_TIME | timestamp(6) | YES | 前回統計情報を収集した時の時間。値がNULLの場合、統計情報が収集されたことがないことを示します |
| INSERTS | bigint(21) | NO | 前回統計情報を収集してから、挿入された行数 |
| UPDATES | bigint(21) | NO | 前回統計情報を収集してから、更新された行数 |
| DELETES | bigint(21) | NO | 前回統計情報を収集してから、削除された行数 |
| STALE_PERCENT | bigint(21) | NO | 統計情報の有効期限が切れたかどうかを判定する割合 |
| IS_STALE | varchar(3) | NO | 統計情報が有効期限切れかどうか。<ul><li>`YES`は有効期限切れを示します。</li><li>テーブルの統計情報が収集されている場合、有効期限切れの条件は`INSERTS + UPDATES + DELETES > LAST_ANALYZED_ROWS * STALE_PERCENT / 100`です。</li><li>テーブルの統計情報が収集されていない場合、有効期限切れの条件は`INSERTS + UPDATES + DELETES > 0`です。</li></ul></li><li>`NO`は有効期限切れではないことを示します。</li></ul>|

## クエリ例

obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLE_STAT_STALE_INFO WHERE TABLE_NAME='t_subpart';
