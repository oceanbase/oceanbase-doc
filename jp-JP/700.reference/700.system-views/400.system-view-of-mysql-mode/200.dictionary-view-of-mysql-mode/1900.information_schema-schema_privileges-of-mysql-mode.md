# information_schema.SCHEMA_PRIVILEGES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

データベース権限情報を表示します。

## フィールドの説明

|    **フィールド名**    |    **タイプ**     | **NULL許容** |  **説明**  |
|----------------|---------------|----------------|----------|
| GRANTEE        | varchar(81)   | NO             | 権限を付与されたアカウント名     |
| TABLE_CATALOG  | varchar(512) | NO             | 定数値（def） |
| TABLE_SCHEMA   | varchar(128)  | NO             | データベース名     |
| PRIVILEGE_TYPE | varchar(64)   | NO             | 付与された権限    |
| IS_GRANTABLE   | varchar(3)    | NO             | 転送可能かどうか    |

## クエリ例

データベース権限情報を確認し、最初の5件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SCHEMA_PRIVILEGES LIMIT 5;
```

クエリ結果は次のとおりです。

```shell
+------------+---------------+--------------------+----------------+--------------+
| GRANTEE    | TABLE_CATALOG | TABLE_SCHEMA       | PRIVILEGE_TYPE | IS_GRANTABLE |
+------------+---------------+--------------------+----------------+--------------+
| 'root'@'%' | def           | information_schema | ALTER          | NO           |
| 'root'@'%' | def           | information_schema | CREATE         | NO           |
| 'root'@'%' | def           | information_schema | DELETE         | NO           |
| 'root'@'%' | def           | information_schema | DROP           | NO           |
| 'root'@'%' | def           | information_schema | INSERT         | NO           |
+------------+---------------+--------------------+----------------+--------------+
5 rows in set
```
