# oceanbase.DBA_OB_ARCHIVELOG_PIECE_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのバックアップセット内のピースの状態を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | パス番号。システムは設定された各パスに一意のIDを割り当てます |
| ROUND_ID | bigint(20) | NO | 完全なclogバックアップデータストリームのラウンドを識別するために使用されます |
| PIECE_ID | bigint(20) | NO | バックアップログフラグメントのID |
| INCARNATION | bigint(20) | NO | Flashback Database後のいくつ目の化身を表します |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別します。例えば、log_archive_destのdest_noは0、log_archive_dest_1のdest_noは1などです |
| STATUS | varchar(64) | NO | Pieceの状態：<br>ACTIVE：現在アクティブなPiece<br>FREEZING：凍結中のPiece<br>FROZEN：凍結済みのPiece。この状態以降、Pieceの状態は変更されません |
| START_SCN | bigint(20) unsigned | NO | Pieceが実際に開始したポイント |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に換算した表示 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に換算した表示 |
| MAX_SCN | bigint(20) unsigned | NO | 最大アーカイブポイント |
| END_SCN | bigint(20) unsigned | NO | Pieceの理論上の終了ポイント |
| END_SCN_DISPLAY | datetime(6) | NO | Piece終了時の時間点 |
| COMPATIBLE | bigint(20) | NO | ログアーカイブの互換バージョン番号 |
| UNIT_SIZE | bigint(20) | NO | ログアーカイブデータの1回あたりの圧縮または暗号化されるログブロックサイズ。現在、このフィールドはサポートされていません |
| COMPRESSION | varchar(128) | NO | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを表す </li><li> lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを表す </li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを表す</li></ul>現在、このフィールドはサポートされていません |
| INPUT_BYTES | bigint(20) | NO | 生データ量、単位はバイト |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | INPUT_BYTESを単位に換算した表示 |
| OUTPUT_BYTES | bigint(20) | NO | 暗号化・圧縮後の有効データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | OUTPUT_BYTESを単位に換算した表示 |
| COMPRESSION_RATIO | decimal(23,2) | NO | 圧縮率 |
| FILE_STATUS | varchar(64) | NO | バックアップログフラグメントのファイル状態：<br>AVAILABLE：有効なバックアップであり、復旧に使用できることを表します<br>COPYING：ログファイルがバックアップ中であることを表します<br>INCOMPLETE：Piece内のログが不完全で、一部のログストリームのログが欠けていることを表します<br>DELETING：ログファイルが削除中であることを表します<br>EXPIRED：バックアップファイルが無効であることを表します<br>BROKEN：バックアップファイルが不完全で使用できないことを表します<br>DELETED：ログファイルが削除されたことを表します |
| PATH | varchar(2048) | NO | アーカイブパス |
