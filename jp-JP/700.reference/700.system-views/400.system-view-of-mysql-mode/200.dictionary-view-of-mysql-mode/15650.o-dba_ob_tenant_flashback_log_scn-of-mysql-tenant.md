# oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN` は、テナント内で行われた各ログトリミング操作の関連情報を表示するために使用されます。

## フィールドの説明

| フィールド               | 型                | NULL許容 | 説明                                       |
|-------------------|---------------------|-------------|------------------------------------------|
| TENANT_ID         | bigint(20)          | NO   | テナントID |
| TIMESTAMP         | timestamp(6)        | NO   | クリエーション時間、マイクロ秒単位                   |
| SWITCHOVER_EPOCH  | bigint(20)          | NO   | テナントロールが `NORMAL` 状態に切り替わった時の `SWITCHOVER_EPOCH`。`SWITCHOVER_EPOCH` は、テナントロール切り替え（Switchover/Failover）操作を識別する一意の識別子です |
| OP_TYPE           | varchar(64)         | NO   | 操作タイプ。以下を含みます：<ul><li>`FAILOVER_TO_PRIMARY`：これはFailover操作のタイプで、プライマリテナントが利用不可な場合にスタンバイテナントをプライマリテナントに切り替える操作です</li><li>`FLASHBACK_STANDBY_LOG`：これはスタンバイテナントのログトリミング操作のタイプで、スタンバイテナントのログを指定されたSCN位置までトリミングするために使用されます</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20) unsigned | NO   | テナントログを後方から前方へトリミングした終点             |

## クエリ例

テナント内で行われた各ログトリミング操作の関連情報を照会します。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```

実行結果は次のとおりです：

```shell
+-----------+----------------------------+------------------+---------------------+---------------------+
| TENANT_ID | TIMESTAMP                  | SWITCHOVER_EPOCH | OP_TYPE             | FLASHBACK_LOG_SCN   |
+-----------+----------------------------+------------------+---------------------+---------------------+
|      1002 | 2025-05-21 16:48:53.583749 | 1747817333380437 | FAILOVER TO PRIMARY | 1747817331313513000 |
+-----------+----------------------------+------------------+---------------------+---------------------+
1 row in set
```
