# oceanbase.DBA_OB_DATABASE_PRIVILEGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のユーザーが保有するデータベース権限を表示します。

## フィールド説明

| フィールド名                     | フィールドタイプ          | NULL許容 | 説明 |
|-------------------|--------------|------|-----|
| USER_ID           | bigint(20)   | NO   |  ユーザーID   |
| USERNAME          | varchar(128) | NO   |  ユーザー名  |
| DATABASE_NAME     | varchar(128) | NO   |  データベース名   |
| GMT_CREATE        | timestamp(6) | NO   |  作成日時   |
| GMT_MODIFIED      | timestamp(6) | NO   |  変更日時   |
| PRIV_ALTER        | varchar(3)   | NO   |  データベースまたはテーブルを変更する権限があるかどうか   |
| PRIV_CREATE       | varchar(3)   | NO   |  データベースまたはテーブルを作成する権限があるかどうか   |
| PRIV_DELETE       | varchar(3)   | NO   |  データベースまたはテーブルのレコードを削除する権限があるかどうか   |
| PRIV_DROP         | varchar(3)   | NO   |  データベースまたはテーブルを削除する権限があるかどうか   |
| PRIV_GRANT_OPTION | varchar(3)   | NO   |  権限を委譲する権限があるかどうか   |
| PRIV_INSERT       | varchar(3)   | NO   |  レコードを挿入する権限があるかどうか   |
| PRIV_UPDATE       | varchar(3)   | NO   |  レコードを更新する権限があるかどうか   |
| PRIV_SELECT       | varchar(3)   | NO   |  レコードをクエリする権限があるかどうか   |
| PRIV_INDEX        | varchar(3)   | NO   |  インデックスの作成および削除の権限があるかどうか   |
| PRIV_CREATE_VIEW  | varchar(3)   | NO   |  ビューを作成する権限があるかどうか   |
| PRIV_SHOW_VIEW    | varchar(3)   | NO   |  ビューを参照する権限があるかどうか   |
| PRIV_EXECUTE        | varchar(3) | NO   |  ProcedureおよびFunctionを実行する権限があるかどうか |
| PRIV_ALTER_ROUTINE  | varchar(3) | NO   |  ProcedureおよびFunctionを変更または削除する権限があるかどうか |
| PRIV_CREATE_ROUTINE | varchar(3) | NO   |  ProcedureおよびFunctionを作成する権限があるかどうか |
| PRIV_REFERENCES     | varchar(3) | NO   |  外部キーを作成する権限があるかどうか |
| PRIV_TRIGGER        | varchar(3) | NO   |  トリガー操作を有効化する権限があるかどうか |
| PRIV_LOCK_TABLE     | varchar(3) | NO   |  テーブルにロックをかける権限があるかどうか |
| PRIV_EVENT          | varchar(3) | NO   |  イベントの作成および管理の権限があるかどうか |
