# oceanbase.DBA_OB_LS_LOCATIONS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのログストリーム（LS）レプリカの分散情報を表示します。

## フィールド説明

|     フィールド名     |       型       | NULL許容 |       説明        |
|--------------|----------------|------------|----------------------------------------------------------------------|
| CREATE_TIME  | datetime(6)         | NO         |   作成日時       |
| MODIFY_TIME  | datetime(6)         | NO         |   変更日時      |
| LS_ID        | bigint(20)          | NO         |   ログストリームID       |
| SVR_IP       | varchar(46)        | NO         | サーバーIPアドレス       |
| SVR_PORT     | bigint(20)   | NO         | サーバーポート番号          |
| SQL_PORT     | bigint(20)   | NO         | SQLポート番号         |
| ZONE         | varchar(128)  | NO         | Zone名         |
| ROLE         | varchar(8)    | NO         | レプリカロール：<ul><li> `LEADER` </li><li> `FOLLOWER`</li></ul>  |
| MEMBER_LIST  | varchar(4480) | NO         | レプリカメンバーリスト。複数のレプリカはカンマで区切る。<ul><li>ロールが `LEADER` の場合、このフィールドは有効です。単一レプリカの表示形式は`svr_ip:svr_port:timestamp`です。ここで：<ul><li>`svr_ip`：レプリカが存在するマシンのIP</li> <li>`svr_port`：レプリカが存在するマシンのポート番号</li> <li>`timestamp`：レプリカがメンバーリストに追加された時間。デフォルトは `1` ですが、レプリカの補完や移行操作が行われた場合、この値は変化します</li></ul></br> 表示例：172.xx.xxx.xxx:2882:1</li> <li>ロールが `LEADER` 以外の場合、`NULL` として表示されます。</li></ul>      |
| PAXOS_REPLICA_NUMBER       | bigint(20)    | NO         | Paxos法定レプリカ数：ロールが `LEADER` の場合、このフィールドは有効です。それ以外の場合は `NULL` です  |
| REPLICA_TYPE | varchar(18)   | NO         | レプリカタイプ：<ul><li> `FULL`：フル機能タイプのレプリカ </li> <li> `READONLY`：読み取り専用レプリカ </li> <li>`COLUMNSTORE`：カラムストアレプリカ</li></ul>    |
| LEARNER_LIST | longtext      | YES        | 現在のログストリームの読み取り専用レプリカリスト。複数のレプリカはカンマで区切る。単一レプリカの表示形式は `svr_ip:svr_port:timestamp:flag` です。ここで：<ul><li>`svr_ip`：レプリカが存在するマシンのIP</li> <li>`svr_port`：レプリカが存在するマシンのポート番号</li> <li>`timestamp`：レプリカが追加された時間。デフォルトは `1` ですが、レプリカの補完や移行操作が行われた場合、この値は変化します</li> <li>`flag`：レプリカが移行中かどうかを示すフラグ。`0` はレプリカが移行中でないことを示し、`2` はレプリカが移行中であることを示します。</li></ul></br> 表示例：172.xx.xxx.xxx:2882:1:0 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REBUILD      | varchar(5)    | NO         | このレプリカがRebuild中かどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main>|
