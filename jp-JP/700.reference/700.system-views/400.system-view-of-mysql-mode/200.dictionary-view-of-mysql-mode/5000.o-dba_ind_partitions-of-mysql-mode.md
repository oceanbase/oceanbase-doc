# oceanbase.DBA_IND_PARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべてのインデックスのパーティション情報を表示します。

## フィールドの説明

|          フィールド名           |       タイプ        | NULLを許容するか |                                                                        説明                                                                         |
|-------------------------|-----------------|------------|---------|
| INDEX_OWNER             | varchar(128)    | NO         | インデックスが属する所有者 |
| INDEX_NAME              | varchar(128)    | NO         | インデックス名  |
| TABLE_NAME              | varchar(128)    | NO         | インデックスが属するテーブル名 |
| COMPOSITE               | varchar(3)      | NO         | パーティションがcomposited-partitionテーブルのローカルインデックスに属するかどうかを示します。<ul><li>YES</li><li>NO </li></ul>  |
| PARTITION_NAME          | varchar(128)    | NO         | パーティション名   |
| SUBPARTITION_COUNT      | bigint(20)      | NO         | サブパーティション数   |
| HIGH_VALUE              | mediumtext      | NO         | パーティションバインド値の式   |
| HIGH_VALUE_LENGTH       | bigint(20)      | NO         | パーティションバインド値式の長さ      |
| PARTITION_POSITION      | bigint(20)      | NO         | インデックス内のパーティションの位置             |
| STATUS                  | varchar(8)      | NO         | インデックスパーティションが利用可能かどうかを示します              |
