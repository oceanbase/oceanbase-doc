# oceanbase.DBA_OB_CONCURRENT_LIMIT_SQL

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのレート制限ルールのアウトラインに関する情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | timestamp(6) | YES | 作成日時のタイムスタンプ |
| MODIFY_TIME | timestamp(6) | YES | 変更日時のタイムスタンプ |
| TENANT_ID | bigint(20) | NO | テナントID |
| DATABASE_ID | bigint(20) | NO | データベースID |
| OUTLINE_ID | bigint(20) | NO | スロットリングルールのアウトラインID |
| DATABASE_NAME | varchar(128) | NO | データベース名 |
| OUTLINE_NAME | varchar(128) | NO | スロットリングルールのアウトライン名 |
| OUTLINE_CONTENT | longtext | NO | スロットリングルールに対応するアウトライン内容。Emptyを指定できます |
| VISIBLE_SIGNATURE | longtext | NO | Signatureの逆シリアライズ結果 |
| SQL_TEXT | longtext | NO | スロットリングルールのアウトライン作成時に、on clauseで指定したSQL |
| CONCURRENT_NUM | bigint(20) | NO | 現在のSQLが制限する並列数 |
| LIMIT_TARGET | longtext | NO | スロットリングされるSQL |

## クエリ例

ユーザーテナントが自身のテナントのレート制限ルールのアウトラインに関する情報を照会します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_CONCURRENT_LIMIT_SQL\G
```
