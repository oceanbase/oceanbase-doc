# oceanbase.DBA_RSRC_GROUP_MAPPINGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のユーザーとリソースグループ間のバインディング関係を表示します。

## フィールドの説明

|      フィールドタイプ      |       タイプ       | NULLにすることができるか |                説明                 |
|----------------|----------------|------------|-----------------------------------|
| ATTRIBUTE      | varchar(128)  | NO         | カテゴリ。現在のバージョンでは`ORACLE_USER`のみサポートされています。         |
| VALUE          | varbinary(128) | NO         | 値。カテゴリが`ORACLE_USER`の場合、ログインユーザー名が記録されます。 |
| CONSUMER_GROUP | varchar(128)  | YES        | ユーザーがバインドされたリソースグループの名前。                     |
| STATUS         | varchar(128)  | NO         | リソースグループのステータス。互換性のためにのみ使用され、現在の値は固定されており`NULL`です。       |

## クエリ例

ユーザーテナントが、自身のテナント内のユーザーとリソースグループ間のバインディング関係を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_GROUP_MAPPINGS;
```

クエリ結果は次のとおりです：

```shell
+-----------+-------+-------------------+--------+
| ATTRIBUTE | VALUE | CONSUMER_GROUP    | STATUS |
+-----------+-------+-------------------+--------+
| user      | root  | interactive_group | NULL   |
+-----------+-------+-------------------+--------+
1 row in set
```
