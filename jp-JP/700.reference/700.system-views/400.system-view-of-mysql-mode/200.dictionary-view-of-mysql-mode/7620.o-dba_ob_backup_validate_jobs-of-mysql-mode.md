# oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</li>
<li>V4.6.xバージョンでは、このビューはV4.6.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS` は、テナントが開始したJobレベルのバックアップ検証タスクに関する情報を表示するために使用されます。各Jobは1つのバックアップ検証指示に対応しています。

## フィールドの説明

| フィールド名             | 型           | NULL許容 | 説明           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | bigint(20)     | NO   | タスクID     |
| INCARNATION         | bigint(20)     | NO   | 分身ID     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | このJobを開始したテナントID   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | このJobを開始したjob_id。値が0の場合、このJobを開始したのは現在のJob自身であることを示します     |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | このJobに対応する検証タスクを実行するユーザーテナントのtenant_idです。値がNULLの場合、検証タスクを実行するのは現在のテナント自身であることを示します     |
| TYPE                | varchar(64)    | NO   | 検証タスクのタイプ：<ul><li>`DATABASE`：バックアップパスとアーカイブパス配下のすべてのバックアップセットおよびログアーカイブPieceを検証します</li> <li>`BACKUPSET`：指定されたバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定されたログアーカイブPieceを検証します</li></ul>     |
| PATH                | longtext       | YES  | ユーザーが指定したバックアップパスまたはログアーカイブパスです。値がNULLの場合、このタスクは指定パス以外の検証であることを示します     |
| PATH_TYPE           | varchar(64)    | YES  | ユーザーが指定したパス配下で検証するタイプです（値がNULLの場合、このタスクは指定パス以外の検証であることを示します）：<ul><li>`BACKUPSET`：指定パス配下のバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定パス配下のログアーカイブPieceを検証します</li></ul>     |
| ID                  | longtext       | YES  | <p>検証対象のバックアップセットの `backup_set_id` またはアーカイブPieceの `piece_id`</p><p>デフォルトはNULLで、現在のバックアップパスとアーカイブパス配下のすべてのバックアップセットおよびログアーカイブPieceを意味します。ユーザーがバックアップセットの `backup_set_id` またはアーカイブPieceの `piece_id` を指定すると、値は対応するIDまたはIDリストに変更されます</p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | 検証レベル：<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一致性をチェックします。</li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | 検証タスクの開始時間     |
| END_TIMESTAMP       | timestamp(6)   | NO   | 検証タスクの終了時間     |
| STATUS              | varchar(64)    | NO   | Jobの状態：<ul><li>`INIT`：検証タスクが初期化中です</li> <li>`DOING`：検証タスクが実行中です</li> <li>`COMPLETED`：検証タスクが完了しました</li> <li>`FAILED`：検証タスクの実行に失敗しました</li> <li>`CANCELED`：検証タスクがキャンセルされました</li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | 再試行回数     |
| TASK_COUNT          | bigint(20)     | YES  | バックアップセットまたはログアーカイブPieceの総検証タスク数     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | バックアップセットまたはログアーカイブPieceの検証に成功したタスク数     |
| RESULT              | bigint(20)     | NO   | 検証結果のエラーコード情報    |
| DESCRIPTION         | varchar(4096)  | YES  | OCPが提供する外部情報    |
| COMMENT             | varchar(4096)  | YES  | 検証タスクが失敗した原因の説明      |

## クエリ例

ユーザーテナントは、自身が開始したJobレベルのバックアップ検証タスクに関する情報を確認します。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS\G
```
