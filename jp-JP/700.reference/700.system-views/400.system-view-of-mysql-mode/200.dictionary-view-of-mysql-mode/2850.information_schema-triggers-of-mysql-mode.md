# information_schema.TRIGGERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `information_schema.TRIGGERS` は、トリガーに関する情報を表示します。

## フィールドの説明

|      フィールド名    |         型       | NULL許容 |    説明     |
|-----------------|--------------------|----------------|-------------|
| TRIGGER_CATALOG            | varchar(512) | NO   | トリガーが属するカタログ名。この値は常にdefです。 |
| TRIGGER_SCHEMA             | varchar(64)  | NO   | トリガーが属するスキーマ（データベース）名。|
| TRIGGER_NAME               | varchar(64)  | NO   | トリガー名。 |
| EVENT_MANIPULATION         | varchar(6)   | NO   | トリガーイベント。これはトリガーが関連付けられているテーブル上で有効になる操作タイプです。この値はINSERT（1行挿入）、DELETE（1行削除）、またはUPDATE（1行更新）を指定できます。     |
| EVENT_OBJECT_CATALOG       | varchar(512) | NO   | トリガーに関連付けられたテーブルが存在するカタログ。この値は常にdefです |
| EVENT_OBJECT_SCHEMA        | varchar(64)  | NO   | トリガーに関連付けられたテーブルが存在するスキーマ（データベース）    |
| EVENT_OBJECT_TABLE         | varchar(64)  | NO   | トリガーに関連付けられたテーブル名    |
| ACTION_ORDER               | bigint(20)   | NO   | 同一テーブル上で `EVENT_MANIPULATION` と `ACTION_TIMING` の値が同じトリガーのリスト内での、トリガー操作の順序と位置。     |
| ACTION_CONDITION           | longtext     | NO   | この値は常にNULLです    |
| ACTION_STATEMENT           | longtext     | NO   | トリガーが有効化されたときに実行されるステートメント|
| ACTION_ORIENTATION         | varchar(9)   | NO   | この値は常にROWです     |
| ACTION_TIMING              | varchar(6)   | NO   | トリガーがイベントの前に有効化されるか後に有効化されるか。この値はBEFOREまたはAFTERを指定できます     |
| ACTION_REFERENCE_OLD_TABLE | varchar(64)  | NO   | この値は常にNULLです     |
| ACTION_REFERENCE_NEW_TABLE | varchar(64)  | NO   | この値は常にNULLです     |
| ACTION_REFERENCE_OLD_ROW   | varchar(3)   | NO   | 古い行識別子。この値は常にOLDです     |
| ACTION_REFERENCE_NEW_ROW   | varchar(3)   | NO   | 新しい行識別子。この値は常にNEWです     |
| CREATED                    | datetime(2)  | YES  | トリガー作成日時     |
| SQL_MODE                   | text         | NO   | トリガー作成時に有効なSQLモード     |
| DEFINER                    | varchar(93)  | YES  | `DEFINER` 句で指定されたアカウント（通常はトリガーを作成したユーザー）。形式は `'user_name'@'host_name'`     |
| CHARACTER_SET_CLIENT       | varchar(32)  | NO   | トリガー作成時の `character_set_client` システム変数の現在のセッションでの値     |
| COLLATION_CONNECTION       | varchar(32)  | NO   | トリガー作成時の `collation_connection` システム変数の現在のセッションでの値     |
| DATABASE_COLLATION         | varchar(32)  | NO   | トリガーに関連付けられたデータベースの照合順序     |
|----------------------------|--------------|------|------|

## クエリ例

テーブル`t1`の詳細情報を照会します。

```sql
SELECT * FROM information_schema.TRIGGERS;
```
