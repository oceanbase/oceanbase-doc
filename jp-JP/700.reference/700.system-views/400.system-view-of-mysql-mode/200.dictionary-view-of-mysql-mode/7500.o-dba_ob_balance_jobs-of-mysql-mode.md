# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_BALANCE_JOBS`は、テナントが現在実行中のロードバランシングジョブを表示します。各テナントでは同時に1つのロードバランシングジョブしか実行できません。各ロードバランシングジョブは複数のロードバランシングタスクを生成し、これらのタスクがロードバランシングを実現するための具体的な操作を行います。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | ------- |
| JOB_ID                  | bigint(20)   | NO  | ロードバランシングジョブID |
| CREATE_TIME             | timestamp(6) | YES | 作成時間 |
| MODIFY_TIME             | timestamp(6) | YES | 情報更新時間 |
| BALANCE_STRATEGIE        | varchar(64)  | NO  | バランシング戦略名 <ul><li>`LS balance by migrate`：移行によるバランシング  </li><li>`LS balance by alter`：ログストリーム属性変更によるバランシング </li><li>`LS balance by expand`：スケールアップによるバランシング </li><li>`LS balance by shrink`：スケールダウンによるバランシング </li><li>`partition balance`：パーティションによるバランシング </li></ul>|
| JOB_TYPE                | varchar(64)  | NO  | ジョブタイプ <ul><li>`LS_BALANCE`：ログストリームのバランシング  </li><li>`PARTITION_BALANCE`：パーティションのバランシング </li></ul>|
| TARGET_UNIT_NUM         | bigint(20)   | NO  | 変更対象の各ZoneのUnit数 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドの値はV4.2.5 BP5以降のバージョンから常に<code>NULL</code>となります。</p></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20)   | NO  | 変更対象のPrimary Zone数 |
| STATUS                  | varchar(64)  | NO  | ジョブの状態 <ul><li>`DOING`：Jobの実行中  </li><li>`COMPLETED`：ジョブの実行が成功 </li><li>`CANCELING`：ジョブのキャンセル中 </li><li>`CANCELED`：ジョブのキャンセル </li> <li>`SUSPEND`：ジョブの一時停止</li></ul>|
| COMMENT                 | longtext     | YES | コメント情報 |
| MAX_END_TIME            | timestamp(6) | YES | ロードバランシングジョブの最大終了時間 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.x系では、このフィールドはV4.2.4以降のバージョンから導入されました。V4.3.x系では、このビューはV4.3.4以降のバージョンから導入されました。</p></main>  |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | テナントの各ZoneのUnit数 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドはV4.2.5 BP5以降のバージョンから導入されました。</p></main> |
| PARAMETER_LIST          | longtext      | NO   | バランシング関連の構成パラメータ <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドはV4.2.5 BP5以降のバージョンから導入されました。</p></main> |

