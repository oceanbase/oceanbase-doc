# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のログストリームの状態と復元進捗を表示します。

## フィールド説明

| フィールド名       | 型                | NULL許容        | 説明               |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO   | ログストリームID |
| STATUS        | varchar(100)        | NO   | ログストリームのステータス。<ul><li>`CREATING`：ログストリームの作成中</li><li>`CREATED`：ログストリームの作成完了</li><li>`NORMAL`：ログストリームがサービスを提供可能</li><li>`DROPPING`：ログストリームの削除予定で、ログストリーム上のTabletの移行が必要</li><li>`TENANT DROPPING`：ログストリームが存在するテナントの削除中で、ログストリームも削除が必要</li><li>`WAIT OFFLINE`：ログストリームデータの削除が完了し、GCを待機中</li><li>`CREATE ABORT`：ログストリームの作成に失敗したか、作成不要と判断されたため、削除予定</li></ul> |
| PRIMARY_ZONE  | longtext            | YES  | ログストリームの選出優先度 |
| UNIT_GROUP_ID | bigint(20)          | NO | UnitグループID <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2バージョンから常に値が0となります。</li><li>V4.2.5系では、このフィールドはV4.2.5 BP5バージョンから常に値が0となります。</li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO   | ログストリームグループIDです。システムログストリーム（1番ログストリーム）およびブロードキャストログストリームについては、このフィールドは0と表示され、そのログストリームが特定のログストリームグループに属さないことを示します。 |
| CREATE_SCN    | bigint(20) unsigned | NO   | ログストリームにログ書き込みが開始された時点のSCN |
| DROP_SCN      | bigint(20) unsigned | NO   | ログストリームが削除された時点のSCN、すなわちすべてのユーザーデータが終了した時点のSCNです。ログストリームが削除された場合、このフィールドには削除時のSCNが記録されます。削除されていない場合、このフィールドはNULLです。 |
| SYNC_SCN      | bigint(20) unsigned | NO   | ログストリームの同期時点であり、ログストリームが最後に正常に同期されたトランザクションのSCNを示します。 |
| READABLE_SCN  | bigint(20) unsigned | NO   | ログストリームの読み取り可能な時点であり、ログストリームが読み取り可能な最小SCNを示します。 |
| FLAG          | varchar(2048)       | NO   | ログストリームのフラグ。<ul><li>空：通常のログストリーム</li><li> DUPLICATE：ユーザーテナントのブロードキャストログストリームで、レプリケーションテーブルがこのログストリーム上に作成されています。</li> <li>BLOCK_TABLET_IN：このログストリーム上にTabletを作成できないことを示します。</li> <li>DUPLICATE\|BLOCK_TABLET_IN：ブロードキャストログストリームでは現在Tabletの作成が許可されていません。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | ユーザーログストリームが分散しているUnitのリストです。システムログストリームとブロードキャストログストリームは、具体的な位置を指定しない場合、この列は空になります。 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2バージョンから導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5バージョンから導入されました。</li></ul></main>  |

## クエリ例

ユーザーテナントが自身のテナントのログストリームの状態と復元進捗を確認します。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```
