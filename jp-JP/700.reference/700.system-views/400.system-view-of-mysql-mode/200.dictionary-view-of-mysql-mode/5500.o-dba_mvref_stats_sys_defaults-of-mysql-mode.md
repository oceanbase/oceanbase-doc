# oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_MVREF_STATS_SYS_DEFAULTS`は、マテリアライズドビューのリフレッシュ履歴統計プロパティのシステム範囲デフォルト値を参照するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(16) | NO | パラメータ名<ul><li>COLLECTION_LEVEL：データ収集のレベルまたは詳細度。</li><li>RETENTION_PERIOD：データの保持期間。</li></ul>|
| VALUE | varchar(40) | NO | パラメータのシステム範囲デフォルト値 |

## クエリ例

マテリアライズドビューのリフレッシュ履歴統計プロパティのシステム範囲デフォルト値を照会します。

```shell
obclient [test_db]> SELECT * FROM oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS;
```

クエリ結果は次のとおりです：

```shell
+------------------+---------+
| PARAMETER_NAME   | VALUE   |
+------------------+---------+
| COLLECTION_LEVEL | TYPICAL |
| RETENTION_PERIOD | 31      |
+------------------+---------+
2 rows in set
```
