# information_schema.ST_GEOMETRY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

空間データ列や空間データ型などの情報を含むテーブルを表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TABLE_SCHEMA | varchar(128) | NO | 列が属するデータベース |
| TABLE_NAME | varchar(256) | NO | その空間列を含むテーブル名 |
| COLUMN_NAME | varchar(128) | NO | 列名 |
| SRS_NAME | varchar(128) | NO | 空間座標系の名前 |
| SRS_ID | bigint(20) unsigned | NO | 空間座標系ID |
| GEOMETRY_TYPE_NAME | varchar(15) | NO | 空間データ型 |
