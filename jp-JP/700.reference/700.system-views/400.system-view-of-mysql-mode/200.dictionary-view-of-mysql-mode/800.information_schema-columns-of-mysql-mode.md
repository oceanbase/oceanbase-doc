# information_schema.COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

列情報を記録します。

## フィールドの説明

|         **フィールド名**         |       **タイプ**        | **NULL許容** |             **説明**             |
|--------------------------|---------------------|----------------|--------------------------------|
| TABLE_CATALOG            | varchar(4096)       | NO             | 固定値（def）                       |
| TABLE_SCHEMA             | varchar(128)        | NO             | Columnが対応するテーブルが属するデータベース                |
| TABLE_NAME               | varchar(256)        | NO             | Columnが対応するテーブル名                   |
| COLUMN_NAME              | varchar(128)        | NO             | 列名                             |
| ORDINAL_POSITION         | bigint(20) unsigned | NO             | 列番号                            |
| COLUMN_DEFAULT           | varchar(262144)     | YES            | 列のデフォルト値                           |
| IS_NULLABLE              | varchar(4)          | NO             | 列値がNULLを許容するかどうか                   |
| DATA_TYPE                | varchar(64)         | NO             | 列のデータ型                         |
| CHARACTER_MAXIMUM_LENGTH | bigint(20) unsigned | YES            | 列の最大文字数                        |
| CHARACTER_OCTET_LENGTH   | bigint(20) unsigned | YES            | 列の最大バイト数                        |
| NUMERIC_PRECISION        | bigint(20) unsigned | YES            | 数字精度                           |
| NUMERIC_SCALE            | bigint(20) unsigned | YES            | 小数点以下の桁数                           |
| DATETIME_PRECISION       | bigint(20) unsigned | YES            | datetime型の精度                  |
| CHARACTER_SET_NAME       | varchar(128)        | YES            | Columnが対応する文字セット名                       |
| COLLATION_NAME           | varchar(128)        | YES            | 文字セットの照合方法                        |
| COLUMN_TYPE              | varchar(64)         | NO             | フィールドタイプ                           |
| COLUMN_KEY               | varchar(3)          | NO             | インデックスまたは主キー列                        |
| EXTRA                    | varchar(4096)       | NO             | その他の情報                           |
| PRIVILEGES               | varchar(200)        | NO             | 権限情報                           |
| COLUMN_COMMENT           | varchar(2048)       | NO             | コメント                             |
| GENERATION_EXPRESSION    | varchar(262144)     | NO             | 生成列については、列値を計算するために使用される式を表示します。 非生成列はNULLです。 |
| SRS_ID                   | bigint(20) unsigned | YES            | 空間座標系ID     |
