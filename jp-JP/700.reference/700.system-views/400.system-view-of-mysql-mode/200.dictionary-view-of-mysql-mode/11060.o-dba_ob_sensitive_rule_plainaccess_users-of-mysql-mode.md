# oceanbase.DBA_OB_SENSITIVE_RULE_PLAINACCESS_USERS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内で、特定の機密ルールに関連付けられた列への平文データアクセス権限を持つすべてのユーザーまたはロールを表示します。

## フィールドの説明

|        フィールド名         |      型           | NULL許容   |                      説明                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| RULE_NAME         | varchar(256)    | NO         | 感度ルール名                                           |
| USER_NAME      | varchar(128)    | NO         | ユーザー名                                        |
| USER_TYPE        | varchar(4)    | NO         | ユーザータイプ。値は`USER`または`ROLE`です。`USER`はユーザーを表し、`ROLE`はロールを表します                                      |

## クエリ例

現在のテナント内で、特定の機密ルールに関連付けられた列への平文データアクセス権限を持つすべてのユーザーまたはロールを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SENSITIVE_RULE_PLAINACCESS_USERS;
```

クエリ結果は次のとおりです：

```shell
+-----------+-----------+-----------+
| RULE_NAME | USER_NAME | USER_TYPE |
+-----------+-----------+-----------+
| r1        | root      | USER      |
+-----------+-----------+-----------+
1 row in set
```
