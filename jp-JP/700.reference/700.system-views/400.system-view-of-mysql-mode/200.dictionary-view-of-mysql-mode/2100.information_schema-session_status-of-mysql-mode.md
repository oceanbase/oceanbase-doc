# information_schema.SESSION_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

セッションのサーバーステータス変数情報を記録します。現在のアクティブ接続数、データベース稼働時間(Uptime)などが含まれます。

## フィールドの説明

|    **フィールド名**    |    **型**     | **NULL許容** |   **説明**    |
|----------------|---------------|----------------|-------------|
| VARIABLE_NAME  | varchar(128)  | NO             | セッションステータス名 |
| VARIABLE_VALUE | varchar(1024) | YES            | セッションステータス値 |

## クエリ例

セッションのサーバーステータス変数と対応する値を確認します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SESSION_STATUS;
```

クエリ結果は次のとおりです：

```shell
+-------------------+----------------+
| VARIABLE_NAME     | VARIABLE_VALUE |
+-------------------+----------------+
| Threads_connected | 2              |
| Uptime            | 255239         |
+-------------------+----------------+
2 rows in set
```
