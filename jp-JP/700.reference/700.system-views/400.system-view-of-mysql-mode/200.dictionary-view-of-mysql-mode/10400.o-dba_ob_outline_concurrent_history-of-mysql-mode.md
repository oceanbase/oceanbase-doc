# oceanbase.DBA_OB_OUTLINE_CONCURRENT_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントの実行計画とレート制限ルールのアウトライン履歴情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME     | timestamp(6)     | YES  | 作成タイムスタンプ   |
| MODIFY_TIME     | timestamp(6)     | YES  | 変更タイムスタンプ    |
| TENANT_ID | bigint(20) | NO | テナントID |
| DATABASE_ID | bigint(20) | YES | データベースID |
| OUTLINE_ID | bigint(20) | NO | アウトラインID |
| OUTLINE_NAME | varchar(128) | YES | アウトライン名 |
| SQL_TEXT | longtext | YES | アウトライン作成時にon句で指定したSQL |
| OUTLINE_PARAMS | varbinary(65536) | YES | アウトライン作成時の関連するレート制御ルールパラメータ |
| OUTLINE_TARGET | longtext | YES | アウトライン作成時にto句で指定したSQL |
| SQL_ID | varchar(32) | YES | SQL識別子 |
| OUTLINE_CONTENT | longtext | YES | 完全なアウトライン情報 |
| IS_DELETED | varchar(3) | NO | 削除されているかどうか |
| ENABLED | varchar(3) | NO | 有効かどうか |
