# oceanbase.DBA_OB_OUTLINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントの実行計画アウトライン情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | timestamp(6) | YES | 作成タイムスタンプ |
| MODIFY_TIME | timestamp(6) | YES | 変更タイムスタンプ |
| TENANT_ID | bigint(20) | NO | テナントID |
| DATABASE_ID | bigint(20) | NO | データベースID |
| OUTLINE_ID | bigint(20) | NO | 実行計画アウトラインID |
| DATABASE_NAME | varchar(128) | NO | データベース名 |
| OUTLINE_NAME | varchar(128) | NO | 実行計画アウトライン名 |
| VISIBLE_SIGNATURE | longtext | NO | Signatureの逆シリアル化結果 |
| SQL_TEXT | longtext | NO | 実行計画アウトライン作成時にon句で指定したSQL |
| OUTLINE_TARGET | longtext | NO | 実行計画アウトライン作成時にto句で指定したSQL |
| OUTLINE_SQL | longtext | NO | 完全な実行計画アウトライン情報を持つSQL |
| SQL_ID | varchar(32) | NO | SQL識別子 |
| OUTLINE_CONTENT | longtext | NO | 完全な実行計画アウトライン情報 |
