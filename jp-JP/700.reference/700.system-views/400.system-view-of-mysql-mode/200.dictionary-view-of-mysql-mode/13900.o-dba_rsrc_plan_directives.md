# oceanbase.DBA_RSRC_PLAN_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>このビューはV3.1.2バージョンから導入されました。</li>
<li>現在のバージョンでは、テナントのResource Managerにおける各種リソース設定パラメータ情報を確認するには、ビュー<a href="11020.o-dba_ob_rsrc_directives-of-mysql-mode.md">DBA_OB_RSRC_DIRECTIVES</a>の使用を推奨します。</li></ul>
</main>

## 機能の概要

データベース内の各リソース計画命令の詳細情報を表示します。
