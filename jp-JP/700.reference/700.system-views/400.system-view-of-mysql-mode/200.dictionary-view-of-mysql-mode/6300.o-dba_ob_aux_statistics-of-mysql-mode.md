# DBA_OB_AUX_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_AUX_STATISTICS`は、各テナントの補助統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
|---------------------------|--------------|----------------------|-----------|
| LAST_ANALYZED             | timestamp(6) | NO   | 最終の統計情報収集時刻のタイムスタンプ     |
| CPU_SPEED(MHZ)            | bigint(20)   | YES  | 現在の環境のCPU周波数、単位はMHz     |
| DISK_SEQ_READ_SPEED(MB/S) | bigint(20)   | YES  | ハードディスクのシーケンシャル読み取り速度、単位はMB/s     |
| DISK_RND_READ_SPEED(MB/S) | bigint(20)   | YES  | ハードディスクのランダム読み取り速度、単位はMB/s     |
| NETWORK_SPEED(MB/S)       | bigint(20)   | YES  | ネットワーク転送速度、単位はMB/s     |

## クエリ例

1. 補助統計情報の収集を手動で有効にします：

   ```shell
   obclient [oceanbase]> CALL dbms_stats.gather_system_stats();
   ```

2. テナントの補助統計情報を照会します：

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AUX_STATISTICS;
   ```

3. クエリ結果は次のとおりです：

   ```shell
   ------------------------+----------------+---------------------------+---------------------------+---------------------+
   | LAST_ANALYZED              | CPU_SPEED(MHZ) | DISK_SEQ_READ_SPEED(MB/S) | DISK_RND_READ_SPEED(MB/S) | NETWORK_SPEED(MB/S) |
   +----------------------------+----------------+---------------------------+---------------------------+---------------------+
   | 2024-03-14 11:36:55.196214 |           2500 |                      3257 |                       407 |                1250 |
   +----------------------------+----------------+---------------------------+---------------------------+---------------------+
   1 row in set (0.002 sec)
   ```
