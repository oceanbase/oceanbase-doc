# oceanbase.DBA_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OB_LOB_CHECK_EXCEPTION_RESULT` は、現在のテナント内のLOB整合性チェックで異常が検出されたテーブルとtablet、および異常タイプを表示します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
|--------------|-----------|---------------------|-----------|
| LS_ID | bigint(20) | NO | ログストリームID |
| CREATE_TIME | timestamp(6) | NO | 異常結果の作成時間 |
| UPDATE_TIME | timestamp(6) | NO | 異常結果の変更時間 |
| TABLE_NAME | varchar(256) | NO | 異常が発生したテーブルの名前 |
| TABLE_ID | bigint(20) | NO | 異常が発生したテーブルオブジェクトのID |
| INCONSISTENCY_TYPE | varchar(16) | NO | 異常タイプ <ul><li>LOB_NOT_FOUND：メインテーブルが存在しないLOBを参照しています</li><li>LOB_LEN_MISMATCH：メタデータの長さと実際の長さが一致しません </li><li>LOB_ORPHANED：LOBは存在しますが、メインテーブルにlocatorがありません</li></ul>  |
| TABLET_IDS | longtext | YES | 異常が発生したパーティションのID |
