# oceanbase.DBA_WR_SNAPSHOT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントの`SNAPSHOT`情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | クラスタID |
| TENANT_ID | bigint(20) | NO | テナントID |
| SNAP_ID | bigint(20) | NO | スナップショットID |
| SVR_IP | varchar(46) | NO | ノードIPアドレス |
| SVR_PORT | bigint(20) | NO | ノードポート |
| BEGIN_INTERVAL_TIME | timestamp(6) | NO | スナップショット開始時刻。タイムスタンプはミリ秒単位です。 |
| END_INTERVAL_TIME | timestamp(6) | NO | スナップショット終了時刻。タイムスタンプはミリ秒単位です。 |
| SNAP_FLAG | bigint(20) | YES | スナップショットのトリガー原因 |
| STARTUP_TIME | timestamp(6) | YES | プロセス起動時間。タイムスタンプはミリ秒単位です。 |

## クエリ例

本テナントの`SNAPSHOT`情報を照会し、最初のレコードを表示します。
