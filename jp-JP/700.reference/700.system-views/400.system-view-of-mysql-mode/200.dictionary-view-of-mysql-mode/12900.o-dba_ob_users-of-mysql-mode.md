# oceanbase.DBA_OB_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のユーザーとロールの情報を表示します。

## フィールド説明

| フィールド名                   | フィールドタイプ      | NULL許容 | 説明 |
|---------------------------|---------------|------|----|
| USER_NAME                 | varchar(128)  | NO   |  ユーザー名またはロール名   |
| HOST                      | varchar(128)  | NO   |  サーバー名   |
| PASSWD                    | varchar(128)  | NO   |  ユーザーまたはロールのパスワード   |
| INFO                      | varchar(4096) | NO   |  ユーザーまたはロール情報   |
| PRIV_ALTER                | varchar(3)    | NO   |  データベースまたはテーブルを変更する権限があるかどうか   |
| PRIV_CREATE               | varchar(3)    | NO   |  データベースまたはテーブルを作成する権限があるかどうか   |
| PRIV_DELETE               | varchar(3)    | NO   |  データベースまたはテーブルレコードを削除する権限があるかどうか   |
| PRIV_DROP                 | varchar(3)    | NO   |  データベースまたはテーブルを削除する権限があるかどうか   |
| PRIV_GRANT_OPTION         | varchar(3)    | NO   |  権限を委譲する権限があるかどうか   |
| PRIV_INSERT               | varchar(3)    | NO   |  レコードを挿入する権限があるかどうか   |
| PRIV_UPDATE               | varchar(3)    | NO   |  レコードを更新する権限があるかどうか   |
| PRIV_SELECT               | varchar(3)    | NO   |  レコードをクエリする権限があるかどうか   |
| PRIV_INDEX                | varchar(3)    | NO   |  インデックスを設定する権限があるかどうか   |
| PRIV_CREATE_VIEW          | varchar(3)    | NO   |  ビューを作成する権限があるかどうか   |
| PRIV_SHOW_VIEW            | varchar(3)    | NO   |  ビューを表示する権限があるかどうか   |
| PRIV_SHOW_DB              | varchar(3)    | NO   |  すべてのデータベースを表示する権限があるかどうか   |
| PRIV_CREATE_USER          | varchar(3)    | NO   |  ユーザーを作成する権限があるかどうか   |
| PRIV_SUPER                | varchar(3)    | NO   |  スーパーユーザー権限があるかどうか   |
| IS_LOCKED                 | varchar(3)    | NO   |  ロックされているかどうか   |
| PRIV_PROCESS              | varchar(3)    | NO   |  すべてのスレッドを表示する権限があるかどうか   |
| PRIV_CREATE_SYNONYM       | varchar(3)    | NO   |  同義語を作成する権限があるかどうか   |
| SSL_TYPE                  | bigint(20)    | NO   |  SSL標準暗号化セキュリティタイプ   |
| SSL_cipher                | varchar(1024) | NO   |  SSL標準暗号化セキュリティパスワード   |
| X509_ISSUER               | varchar(1024) | NO   |  X.509 発行者名   |
| X509_SUBJECT              | varchar(1024) | NO   |  X.509 証書主体名   |
| TYPE                      | varchar(4)    | NO   |  タイプ：<ul><li>`USER`：ユーザー</li> <li>`ROLE`：ロール</li></ul>   |
| PROFILE_ID                | bigint(20)    | NO   |  Profile ID   |
| PASSWORD_LAST_CHANGED     | timestamp(6)  | YES  |  最後にパスワードを変更した日時   |
| PRIV_FILE                 | varchar(3)    | NO   |  ファイルの閲覧権限の有無   |
| PRIV_ALTER_TENANT         | varchar(3)    | NO   |  テナント情報の変更権限の有無   |
| PRIV_ALTER_SYSTEM         | varchar(3)    | NO   |  サーバー構成パラメータの変更権限の有無   |
| PRIV_CREATE_RESOURCE_POOL | varchar(3)    | NO   |  リソースプールの作成・変更・削除権限の有無   |
| PRIV_CREATE_RESOURCE_UNIT | varchar(3)    | NO   |  リソースユニットの作成・変更・削除権限の有無   |
| MAX_CONNECTIONS           | bigint(20)    | NO   |  最大接続数   |
| MAX_USER_CONNECTIONS      | bigint(20)    | NO   |  最大テナント接続数   |
| PRIV_REPL_SLAVE           | varchar(3)    | NO   |  スレーブサーバー管理。テナントはレプリケーションのスレーブサーバーとマスターサーバーの場所を指定できます。   |
| PRIV_REPL_CLIENT          | varchar(3)    | NO   |  マスターサーバー管理。テナントはレプリケーションデータベース環境のメンテナンスに使用されるバイナリログファイルを読み取ることができます。このユーザーはマスターシステム上に配置され、ホストとクライアント間の通信に有利です。   |
| PRIV_DROP_DATABASE_LINK   | varchar(3)    | NO   |  データベースリンクの削除権限の有無     |
| PRIV_CREATE_DATABASE_LINK | varchar(3)    | NO   |  データベースリンクの作成権限の有無     |
| PRIV_EXECUTE              | varchar(3)    | NO   |  ProcedureとFunctionの実行権限の有無    |
| PRIV_ALTER_ROUTINE        | varchar(3)    | NO   |  ProcedureとFunctionの変更・削除権限の有無      |
| PRIV_CREATE_ROUTINE       | varchar(3)    | NO   |  ProcedureとFunctionの作成権限の有無     |
| PRIV_CREATE_TABLESPACE    | varchar(3)    | NO   |  テーブルスペースの作成・変更・削除権限の有無     |
| PRIV_SHUTDOWN             | varchar(3)    | NO   |  mysqladmin shutdownコマンドの実行権限の有無     |
| PRIV_RELOAD               | varchar(3)    | NO   |  Flush操作の実行権限の有無     |
| PRIVREFERENCES           | varchar(3)    | NO   |  外部キーの作成権限の有無     |
| PRIV_CREATE_ROLE          | varchar(3)    | NO   |  ロールの作成権限の有無     |
| PRIV_DROP_ROLE            | varchar(3)    | NO   |  ロールの削除権限の有無     |
| PRIV_TRIGGER              | varchar(3)    | NO   |  トリガー操作の有効化権限の有無     |
| PRIV_ENCRYPT              | varchar(3)    | NO   |  ENHANCED_AES_ENCRYPT関数を呼び出せるかどうか     |
| PRIV_DECRYPT              | varchar(3)    | NO   | ENHANCED_AES_DECRYPT関数を呼び出せるかどうか     |
