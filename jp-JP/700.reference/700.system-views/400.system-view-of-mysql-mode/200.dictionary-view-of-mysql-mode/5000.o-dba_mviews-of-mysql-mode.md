# oceanbase.DBA_MVIEWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_MVIEWS` は、すべてのマテリアライズドビュー情報を表示するために使用されます。
