# oceanbase.DBA_OB_KV_REDIS_TABLE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OB_KV_REDIS_TABLE` は、このテナントのRedisにおけるさまざまなデータ構造に固有のコマンドと、それに対応するストレージテーブル名を格納するために使用されます。

## フィールドの説明

| **フィールド名**   | **タイプ**     | **NULLを許容するか**  | **説明**        |
|----------------|--------------|----------------------|-----------------|
| COMMAND_NAME   | varchar(1024) | NO  | Redisコマンド名。例：get、set、hgetall。      |
| TABLE_NAME        | varchar(OB_MAX_TABLE_NAME_LENGTH)  | NO   | データテーブル名。      |
| GMT_CREATE   | timestamp(6) | NO   | 作成時間。    |
| GMT_MODIFIED | timestamp(6) | NO   | 最後の変更時間。replace時にこの時間が変更されます。   |

## クエリ例

このテナントのRedisにおける各種データ構造に特有のコマンドと、それに対応するストレージテーブル名を照会します。
