# mysql.db

</main>

## 機能の概要

データベースレベルの権限情報を表示するために使用されます。

## フィールド説明

|       **フィールド名**        |    **型**    | **NULL許容** |         **説明**       |
|-----------------------|--------------|----------------|----------------------------------|
| host                  | varchar(128) | NO             | ホスト名                                                                    |
| db                    | varchar(128) | NO             | データベース名                                                                   |
| user                  | varchar(128) | NO             | ユーザー名                                                                    |
| select_priv           | varchar(1)   | NO             | SELECTステートメントを実行できるかどうかを示します。                                                        |
| insert_priv           | varchar(1)   | NO             | INSERTステートメントを実行できるかどうかを示します。                                                        |
| update_priv           | varchar(1)   | NO             | UPDATEステートメントを実行できるかどうかを示します。                                                        |
| delete_priv           | varchar(1)   | NO             | DELETEステートメントを実行できるかどうかを示します。                                                        |
| create_priv           | varchar(1)   | NO             | CREATEステートメントを実行できるかどうかを示します。                                                        |
| drop_priv             | varchar(1)   | NO             | DROPステートメントを実行できるかどうかを示します。                                                          |
| grant_priv            | varchar(1)   | NO             | 権限付与操作を実行できるかどうかを示します。                                                              |
| reference_priv        | varchar(1)   | NO             | 現在は使用されていません                                                                   |
| index_priv            | varchar(1)   | NO             | インデックスを作成できるかどうかを示します                                                            |
| alter_priv            | varchar(1)   | NO             | `ALTER TABLE` ステートメントを実行できるかどうかを示します                                                 |
| create_tmp_table_priv | varchar(1)   | NO             | 一時テーブルを作成できるかどうかを示します。現在、このフィールドは使用されていません                |
| lock_tables_priv      | varchar(1)   | NO             | `LOCK TABLES`ステートメントを実行できるかどうか。ユーザーはテーブルに対するSELECT権限も必要です。このフィールドは現在未使用です |
| create_view_priv      | varchar(1)   | NO             | `CREATE VIEW`ステートメントを実行できるかどうか                                                 |
| show_view_priv        | varchar(1)   | NO             | `SHOW CREATE VIEW`ステートメントを実行できるかどうか                                            |
| create_routine_priv   | varchar(1)   | NO             | ストアドプロシージャを作成できるかどうか（現在未使用）   |
| alter_routine_priv    | varchar(1)   | NO             | `ALTER FUNCTION`ステートメントを実行できるかどうか（現在未使用）                         |
| execute_priv          | varchar(1)   | NO             | ストアドプロシージャを実行できるかどうか（現在未使用）      |
| event_priv            | varchar(1)   | NO             | イベントの作成、削除、または変更を実行できるかどうか（現在未使用）    |
| trigger_priv          | varchar(1)   | NO             | `CREATE TRIGGER`または`DROP TRIGGER`ステートメントを実行できるかどうか。このフィールドは現在未使用です   |

## クエリ例

ユーザー `test2` のデータベースレベル権限情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM mysql.db WHERE user='test2' \G
```
