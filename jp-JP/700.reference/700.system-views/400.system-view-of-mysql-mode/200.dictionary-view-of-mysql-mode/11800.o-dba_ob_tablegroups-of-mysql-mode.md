# oceanbase.DBA_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルグループのメタ情報を表示します。主に、テーブルグループのパーティション情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.0以降のバージョンでは、このビュー内のパーティション属性フィールドは意味を持たなくなり、すべて<code>NONE</code>または</code>NULL</code>として表示されます。</p>
</main>

## フィールド説明

|           フィールド名            |      型        | NULL許容    |      説明      |
|---------------------------|--------------|------------|--------------------------------------------------------------------------------------------------------|
| TABLEGROUP_NAME           | varchar(128) | NO         | テーブルグループ名          |
| PARTITIONING_TYPE         | varchar(13)  | NO         | テーブルグループのパーティション、およびパーティションのサブパーティションのパーティショニングタイプ。<ul><li>`NONE`：非パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0以降で使用可能になります。値は <code>NULL</code> です。</p></main>            |
| SUBPARTITIONING_TYPE      | varchar(13)  | NO         | パーティションのテーブルグループのサブパーティションのパーティショニングタイプ。<ul><li> `NONE`：非パーティションテーブルグループ、パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ</li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0以降で使用可能になります。値は <code>NULL</code> です。</p></main>     |
| PARTITION_COUNT           | bigint(20)   | NO         | この値は `NULL`            |
| DEF_SUBPARTITION_COUNT    | bigint(0)    | NO         | この値は `NULL`|
| PARTITIONING_KEY_COUNT    | bigint(20)   | NO         | この値は `NULL`         |
| SUBPARTITIONING_KEY_COUNT | bigint(20)   | NO         | この値は `NULL`       |
| SHARDING                  | varchar(10)  | NO         | テーブルグループのSHARDINGプロパティ。取り得る値は以下のとおりです：<ul><li>`NONE`：このプロパティを持つテーブルグループでは、グループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、グループへのテーブルの追加に制限はありません。</li> <li>`PARTITION`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータがパーティション単位で分散されます。サブパーティションテーブルの場合、パーティション内のすべてのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータが適応型方式で分散されます。具体的には、グループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散されます。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main> |

## クエリ例

1. テーブルグループ `tblgroup1` を作成します。

   ```shell
   obclient [test]> CREATE TABLEGROUP tblgroup1 SHARDING = 'PARTITION';
   ```

2. テーブルグループ `tblgroup1` の SHARDING プロパティを確認します。

   ```shell
   obclient [test]> SELECT TABLEGROUP_NAME, SHARDING FROM oceanbase.DBA_OB_TABLEGROUPS WHERE tablegroup_name = 'tblgroup1';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +-----------------+-----------+
   | TABLEGROUP_NAME | SHARDING  |
   +-----------------+-----------+
   | tblgroup1       | PARTITION |
   +-----------------+-----------+
   1 row in set
   ```
