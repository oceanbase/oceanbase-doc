# oceanbase.DBA_PART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのパーティションオブジェクトに含まれるパーティションキーを構成する列を表示します。

## フィールドの説明

|      **フィールド名**      |    **タイプ**     | **NULLを許容するか** |  **説明**  |
|--------------------|---------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | varchar(128)  | NO             | パーティションテーブルまたはパーティションインデックスの所有者            |
| NAME               | varchar(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前             |
| OBJECT_TYPE        | varchar(5)    | NO             | パーティションオブジェクトのタイプ：<ul><li>TABLE   </li><li>INDEX </li></ul>   |
| COLUMN_NAME        | text | NO             | 列の名前     |
| COLUMN_POSITION    | bigint(20)    | NO             | パーティションキー内の列の位置|
| COLLATED_COLUMN_ID | bigint(0)     | NO             | 現在このフィールドはサポートされておらず、現在このフィールドはデフォルトでNULLです |

## クエリ例

ユーザーテナントが、自身のテナントにあるパーティションテーブル`tbl1_h`のパーティションキーを構成する列を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_PART_KEY_COLUMNS WHERE NAME='tbl1_h';
```

クエリ結果は次のとおりです：

```shell
+----------+--------+-------------+-------------+-----------------+--------------------+
| OWNER    | NAME   | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+----------+--------+-------------+-------------+-----------------+--------------------+
| infotest | tbl1_h | TABLE       | col1        |               1 |               NULL |
+----------+--------+-------------+-------------+-----------------+--------------------+
1 row in set
```
