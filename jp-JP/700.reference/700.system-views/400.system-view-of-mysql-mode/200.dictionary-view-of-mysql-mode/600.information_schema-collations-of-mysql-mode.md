# information_schema.COLLATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

各文字セットの比較方式情報を表示します。

## フィールド説明

|      **フィールド名**      |    **型**    | **NULL許容** |                           |
|--------------------|--------------|----------------|---------------------------|
| COLLATION_NAME     | varchar(128) | NO             | 照合方法名                    |
| CHARACTER_SET_NAME | varchar(128) | NO             | collationに関連付けられた文字セット名      |
| ID                 | bigint(20)   | NO             | collationのID            |
| IS_DEFAULT         | varchar(4)   | NO             | collationが対応する文字セットのデフォルト照合方法かどうか |
| IS_COMPILED        | varchar(4)   | NO             | 文字セットがサーバーにコンパイルされているかどうか             |
| SORTLEN            | bigint(20)   | NO             | 文字セットのソートに必要なメモリサイズ、単位はバイト            |

## クエリ例

各文字セットの比較方法情報を確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.COLLATIONS LIMIT 10;
```
