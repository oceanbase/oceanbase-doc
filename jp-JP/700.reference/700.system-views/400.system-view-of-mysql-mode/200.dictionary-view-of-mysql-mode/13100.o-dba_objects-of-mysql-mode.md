# oceanbase.DBA_OBJECTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OBJECTS` は、データベース内のすべてのデータベースオブジェクトを表示するために使用されます。ビュー定義はビュー `ALL_OBJECTS` と同一です。

## フィールド説明

|       フィールド名        |      型      | NULL許容 |              説明               |
|-------------------|--------------|------------|-------------------------------|
| OWNER             | varchar(128) | NO         | オブジェクトの所有者                      |
| OBJECT_NAME       | varchar(128) | NO         | オブジェクト名                          |
| SUBOBJECT_NAME    | varchar(128) | NO         | サブオブジェクト名（例：パーティション）           |
| OBJECT_ID         | bigint(20)   | NO         | オブジェクトのディクショナリID値                    |
| DATA_OBJECT_ID    | bigint(20)   | NO         | そのオブジェクトを含むセグメントのディクショナリID値         |
| OBJECT_TYPE       | varchar(23)  | NO         | オブジェクトタイプ。テーブル、インデックス、パーティション、パッケージ、ストアドプロシージャ、シノニム、シーケンスなどが含まれる |
| CREATED           | datetime     | NO         | オブジェクト作成日時                        |
| LAST_DDL_TIME     | datetime     | NO         | オブジェクトの最終DDL実行時間                 |
| TIMESTAMP         | datetime     | NO         | オブジェクトの指定されたタイムスタンプ。文字列として出力される              |
| STATUS            | varchar(7)   | NO         | オブジェクトの状態：<ul><li>>VALID：有効</li><li>INVALID：無効</li></ul>   |
| TEMPORARY         | varchar(1)   | NO         | このオブジェクトが一時オブジェクトであることを示す                  |
| GENERATED         | varchar(1)   | NO         | オブジェクト名がシステムによって生成されたかどうかを示す              |
| SECONDARY         | varchar(1)   | NO         | 現在このフィールドは使用されていない                     |
| NAMESPACE         | bigint(1)    | NO         | オブジェクトの名前空間                       |
| EDITION_NAME      | varchar(128) | NO         | 予約語フィールド                          |
| SHARING           | varchar(18)  | NO         | デフォルト値は`NULL`           |
| EDITIONABLE       | varchar(1)   | NO         | デフォルト値は`NULL`         |
| ORACLE_MAINTAINED | varchar(1)   | NO         | デフォルト値は`NULL`              |
| APPLICATION       | varchar(1)   | NO         | デフォルト値は`NULL`                   |
| DEFAULT_COLLATION | varchar(1)   | NO         | デフォルト値は`NULL`                       |
| DUPLICATED        | varchar(1)   | NO         | デフォルト値は`NULL`        |
| SHARDED           | varchar(1)   | NO         | デフォルト値は`NULL`                           |
| IMPORTED_OBJECT   | varchar(1)   | NO         | デフォルト値は `NULL`                            |
| CREATED_APPID     | bigint(0)    | NO         | デフォルト値は `NULL`   |
| CREATED_VSNID     | bigint(0)    | NO         | デフォルト値は `NULL`          |
| MODIFIED_APPID    | bigint(0)    | NO         | デフォルト値は `NULL`     |
| MODIFIED_VSNID    | bigint(0)    | NO         | デフォルト値は `NULL`        |
