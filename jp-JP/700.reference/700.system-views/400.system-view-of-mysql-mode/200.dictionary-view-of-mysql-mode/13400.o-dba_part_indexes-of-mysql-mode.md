# oceanbase.DBA_PART_INDEXES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのパーティションインデックスのパーティション情報を表示します。

## フィールド説明

|           フィールド名            |      型       | NULL許容 |  説明  |
|---------------------------|---------------|------------|--------------------------------|
| OWNER                     | varchar(128)  | NO         | パーティションインデックスの所有者        |
| INDEX_NAME                | varchar(128)  | NO         | パーティションインデックスの名前               |
| TABLE_NAME                | varchar(128)  | NO         | インデックスが関連付けられているテーブルの名前        |
| PARTITIONING_TYPE         | varchar(13)   | NO         | パーティショニング方式：<ul><li> HASH  </li><li> RANGE </li><li> LIST </li></ul>       |
| SUBPARTITIONING_TYPE      | varchar(13)   | NO         | サブパーティションのパーティショニング方式：<ul><li> HASH </li><li> RANGE  </li><li> LIST</li></ul>    |
| PARTITION_COUNT           | bigint(20)    | NO         | インデックス内のパーティション数                 |
| DEF_SUBPARTITION_COUNT    | bigint(20)    | NO         | 複合パーティションインデックスの場合、サブパーティションの数（指定されている場合）          |
| PARTITIONING_KEY_COUNT    | bigint(21)    | NO         | パーティションキーの列数             |
| SUBPARTITIONING_KEY_COUNT | bigint(21)    | NO         | 複合パーティションインデックスの場合、サブパーティションのパーティションキー数                  |
| LOCALITY                  | varchar(6)    | NO         | パーティションインデックスがローカル（LOCAL）かグローバル（GLOBAL）か                |
| ALIGNMENT                 | varchar(12)   | NO         | パーティションインデックスがプレフィックス付き（PREFIXED）かプレフィックスなし（NON_PREFIXED）か     |
| DEF_TABLESPACE_NAME       | varchar(30)   | NO         | ローカルインデックスの場合、テーブルパーティションの追加または分割時のデフォルトテーブルスペース        |
| DEF_PCT_FREE              | bigint(1)     | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です          |
| DEF_INI_TRANS             | bigint(1)     | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です              |
| DEF_MAX_TRANS             | bigint(1)     | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です                |
| DEF_INITIAL_EXTENT        | varchar(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです             |
| DEF_NEXT_EXTENT           | varchar(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです          |
| DEF_MIN_EXTENTS           | varchar(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです            |
| DEF_MAX_EXTENTS           | varchar(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。       |
| DEF_MAX_SIZE              | varchar(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。       |
| DEF_PCT_INCREASE          | varchar(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。       |
| DEF_FREELISTS             | bigint(1)     | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です。         |
| DEF_FREELIST_GROUPS       | bigint(1)     | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です。            |
| DEF_LOGGING               | varchar(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。          |
| DEF_BUFFER_POOL           | varchar(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。           |
| DEF_flash_CACHE           | varchar(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。            |
| DEF_CELL_FLASH_CACHE      | varchar(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。             |
| DEF_PARAMETERS            | text          | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。                |
| INTERVAL                  | text          | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は`NO`です。           |
| AUTOLIST                  | varchar(3)    | NO         | ローカルインデックスが自動リストパーティションを使用するかどうかを指定します。<ul><li>YES</li><li>NO</li></ul>        |
| INTERVAL_SUBPARTITION     | text          | NO         | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。     |
| AUTOLIST_SUBPARTITION     | text          | NO         | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。     |
