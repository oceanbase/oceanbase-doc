# information_schema(KEY_COLUMN_USAGE)

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルの列におけるキーの制約情報を表示します。

## フィールドの説明

|           **フィールド名**            |    **タイプ**    | **NULL値を許容** |                                         **説明**                                          |
|-------------------------------|--------------|------------|---------------------|
| CONSTRAINT_CATALOG            | varchar(3)   | NO         | 固定値（def）                                                                                |
| CONSTRAINT_SCHEMA             | varchar(128) | NO         | データベース名 |
| CONSTRAINT_NAME               | varchar(7)   | NO         | 约束名、PRIMARYまたは列名または外部キー名であること。                                                                   |
| TABLE_CATALOG                 | varchar(3)   | NO         | テーブルカタログ  |
| TABLE_SCHEMA                  | varchar(128) | NO         | データベース名 |
| TABLE_NAME                    | varchar(256) | NO         | テーブル名   |
| COLUMN_NAME                   | varchar(128) | NO         | 列名   |
| ORDINAL_POSITION              | bigint(20)   | NO         | この列のテーブル内の番号                                                                                |
| POSITION_IN_UNIQUE_CONSTRAINT | null         | NO         | 唯一および主キー制約については、制約定義内の現在の列の順序を示します。外部キー制約については、参照されるテーブル内の主キーの順序位置を示します |
| REFERENCED_TABLE_SCHEMA       | varchar(128) | NO         | 現在このフィールドはデフォルトでNULLです。                                                                                  |
| REFERENCED_TABLE_NAME         | varchar(256) | NO         | 現在このフィールドはデフォルトでNULLです |
| REFERENCED_COLUMN_NAME        | varchar(128) | NO         | 現在このフィールドはデフォルトでNULLです |

## クエリ例

テーブル `tbl4` の列におけるキーの制約情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.KEY_COLUMN_USAGE WHERE TABLE_NAME='tbl4';
```
