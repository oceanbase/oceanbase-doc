# oceanbase.DBA_OB_BACKUP_STORAGE_INFO_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントでバックアップ・リストアに使用されたバックアップ先の履歴情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| PATH | varchar(1024) | NO | バックアップのルートパス |
| ENDPOINT | varchar(256) | NO | オブジェクトストレージへのアクセスに必要なホスト |
| DEST_ID | bigint(20) | YES | バックアップ先の番号 |
| DEST_TYPE | varchar(64) | YES | バックアップ先のタイプ：<ul><li>`archive_log`：ログアーカイブ</li> <li>`backup_data`：データバックアップ</li></ul> |
| AUTHORIZATION | varchar(1024) | NO | オブジェクトストレージの認証情報 |
| EXTENSION | varchar(512) | NO | バックアップ先のその他のパラメータ |
| CHECK_FILE_NAME | varchar(256) | YES | 接続性検証ファイル名 |
| LAST_CHECK_TIMESTAMP | timestamp(6) | YES | 前回の接続性検証が合格した時間 |
| MAX_IOPS             | bigint(20)   | NO | バックアップで使用するバックアップ媒体が許可する最大IOPS <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5バージョンから導入されました。</p></main>    |
| MAX_bandWIDTH        | bigint(20)   | NO | バックアップで使用するバックアップ媒体が許可する最大帯域幅、単位はバイト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5バージョンから導入されました。</p></main>      |
| MAX_bandWIDTH_DISPLAY| varchar(29)  | NO | 最大帯域幅を変換した表示形式。変換後の形式は10GB/sや10MB/sなどとなります <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5バージョンから導入されました。</p></main>      |
