# oceanbase.DBA_OB_LS_ARB_REPLICA_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで実行中のアービトレーションサービスタスクを表示します。

## フィールドの説明

| フィールド | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | datetime | NO | ジョブの生成時間 |
| MODIFY_TIME | datetime | NO | ジョブの変更時間 |
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| TASK_ID | bigint(20) | NO | ジョブID |
| TRACE_ID | varchar(200) | NO | ジョブ実行時のトレースID |
| TASK_TYPE | varchar(32) | NO | ジョブタイプ：<ul><li> `ADD REPLICA`はレプリカ追加ジョブを指します。 </li><li> `REMOVE REPLICA`はレプリカ削除ジョブを指します。</li></ul>|
| ARBITRATION_SERVICE | varchar(512) | NO | アービトレーションサービスアドレス |
| ARBITRATION_SERVICE_TYPE | varchar(64) | NO | アービトレーションサービスタイプ。現在は`ADDR`のみサポートしています |
| COMMENT | varchar(2048) | YES | ジョブの説明 |
