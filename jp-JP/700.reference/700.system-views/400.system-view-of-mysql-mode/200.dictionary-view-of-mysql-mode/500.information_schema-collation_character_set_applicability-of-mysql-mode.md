# information_schema.COLLATION_CHARACTER_SET_APPLICABILITY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

characterとcollationの対応関係を記録します。

## フィールドの説明

|      **フィールド名**      |    **タイプ**    | **NULL許容** | **説明** |
|--------------------|--------------|----------------|--------|
| COLLATION_NAME     | varchar(128) | NO             | 照合方法名 |
| CHARACTER_SET_NAME | varchar(128) | NO             | 文字セット名  |

## クエリ例

データベース内のCharacterとCollationの対応関係を確認し、上位10件のレコードを表示します。

```shell
obclient [infotest]> SELECT * FROM information_schema.COLLATION_CHARACTER_SET_APPLICABILITY LIMIT 10;
```

クエリ結果は次のとおりです：

