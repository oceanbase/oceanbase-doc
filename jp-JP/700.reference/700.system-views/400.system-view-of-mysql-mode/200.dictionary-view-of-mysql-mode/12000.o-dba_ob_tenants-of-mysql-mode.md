# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントの基本情報を表示します。

* システムテナントからこのビューをクエリすると、システムテナント、ユーザーが作成したテナント（ユーザーテナント）、およびMetaテナントを含むすべてのテナントの情報が表示されます。ユーザーは`TENANT_TYPE`列に基づいてテナントタイプを区別できます。
* 通常のテナントからこのビューをクエリすると、そのテナントの情報のみが表示されます。
