# oceanbase.DBA_OB_AUTO_INCREMENT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内にあるすべての自動インクリメント列の情報を表示します。

## フィールドの説明

| フィールド名              | 型                | NULL許容        | 説明              |
|----------------------|---------------------|----------------|-------------------|
| CREATE_TIME          | datetime(6)         | YES            | カラム作成日時    |
| MODIFY_TIME          | datetime(6)         | YES            | カラム変更日時    |
| AUTO_INCREMENT_KEY   | bigint(20)          | NO             | カラムが存在するテーブルのキー  |
| COLUMN_ID            | bigint(20)          | NO             | 列ID              |
| AUTO_INCREMENT_VALUE | bigint(20) unsigned | YES            | 次に使用可能な自動インクリメント値   |
| SYNC_VALUE           | bigint(20) unsigned | NO             |同期値。`INSERT`ステートメントで明示的に指定した、かつ現在のカラム値より大きい値を指します。|

## クエリ例

テナント内のすべての自動インクリメント列情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AUTO_INCREMENT;
```

クエリ結果は次のとおりです：

```shell
+----------------------------+----------------------------+--------------------+-----------+----------------------+------------+
| CREATE_TIME                | MODIFY_TIME                | AUTO_INCREMENT_KEY | COLUMN_ID | AUTO_INCREMENT_VALUE | SYNC_VALUE |
+----------------------------+----------------------------+--------------------+-----------+----------------------+------------+
| 2025-02-20 14:37:01.322987 | 2025-02-20 14:37:07.197611 |             500006 |        16 |              1000001 |          0 |
| 2025-02-20 14:39:18.505040 | 2025-02-20 14:39:18.505040 |             500008 |        16 |                    1 |          0 |
+----------------------------+----------------------------+--------------------+-----------+----------------------+------------+
2 rows in set
```
