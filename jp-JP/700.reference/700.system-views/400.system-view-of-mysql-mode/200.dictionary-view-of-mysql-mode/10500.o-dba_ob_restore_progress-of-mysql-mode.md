# oceanbase.DBA_OB_RESTORE_PROGRESS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントで進行中のリカバリタスクを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| ------ | ------ | ------ | ------ |
| JOB_ID                           | bigint(20)          |  NO   |復元に属するjob_id。1回の復元タスクに対応します。 |
| RESTORE_TENANT_NAME              | longtext            |  NO   |復元対象のテナント名  |
| RESTORE_TENANT_ID                | longtext            |  NO   |復元対象のテナントID  |
| BACKUP_TENANT_NAME               | longtext            |  NO   |バックアップのソーステナント名  |
| BACKUP_TENANT_ID                 | longtext            |  NO   |バックアップのソーステナントID  |
| BACKUP_CLUSTER_NAME              | longtext            |  NO   |バックアップのソースクラスタ名  |
| BACKUP_DEST                      | longtext            |  NO   |バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します。    |
| RESTORE_OPTION                   | longtext            |  NO   |復元オプション。復元を開始する際に、ユーザーが指定した`restore_option`  |
| RESTORE_SCN                      | bigint(20) unsigned |  NO   |ユーザーが指定した復元ポイント  |
| RESTORE_SCN_DISPLAY              | datetime(6)         |  NO   |ユーザーが指定した復元ポイントのタイムスタンプ表記  |
| STATUS                           | longtext            |  NO   |復元状態：システムテナントの復元タスクと復元されるテナントの復元タスクの状態が一致しません。<br>システムテナント：<ul><li>`CREATE_TENANT`：テナントの作成。この段階でシステムテナントは復元対象のテナントを作成します </li> <li>`WAIT_TENANT_RESTORE_FINISH`：復元対象のテナントの復元終了を待機 </li> <li>`RESTORE_SUCCESS`：テナントの復元に成功 </li> <li>`RESTORE_FAIL`：テナントの復元に失敗 </li></ul> <br>復元されるテナント：<ul><li>`RESTORING`：テナントデータの復元中 </li> <li>`RESTORE_SUCCESS`：復元に成功 </li> <li>`RESTORE_FAIL`：復元に失敗 </li></ul> |
| START_TIMESTAMP                  | datetime(6)         |  NO   |復元タスクの開始タイムスタンプ  |
| BACKUP_SET_LIST                  | longtext            |  NO   |復元に依存するデータバックアップセットパスのリスト。バックアップセット間は`,`で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`  |
| BACKUP_PIECE_LIST                | longtext            |  NO   |復元に依存するログアーカイブピースパスのリスト。ピース間は`,`で区切ります。例：`file:///data/nfs/backup/archive/piece_d1001r1p1,file:///data/nfs/backup/archive/piece_d1001r2p2`  |
| RECOVER_SCN                      | bigint(20) unsigned |  NO   | ログの復旧ポイント。システムテナントについては、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_SCN_DISPLAY              | datetime(6)         |  NO   | ログの復旧ポイントのタイムスタンプ表記。システムテナントについては、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_PROGRESS                 | decimal(6,2)        |  NO   | ログ復旧の進捗状況。結果は小数点以下2桁を保持します。例えば、`87.65` と表示される場合、現在の進捗率は87.65%を意味します。システムテナントについては、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TABLET_COUNT                     | bigint(20)          |  NO   | 復旧待ちのTabletの総数。システムテナントについては、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main>  |
| FINISH_TABLET_COUNT              | bigint(20)          |  NO   | 復旧完了のTabletの総数。システムテナントについては、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RESTORE_PROGRESS                 | decimal(6,2)        |  NO   | データ復旧の進捗状況。結果は小数点以下2桁を保持します。例えば、`87.65` と表示される場合、現在の進捗率は87.65%を意味します。システムテナントについては、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TOTAL_BYTES                      | bigint(20)          |  NO   | 復旧した総バイト数 |
| TOTAL_BYTES_DISPLAY              | varchar(27)         |  NO   | ストレージ容量単位で表示される復旧した総バイト数 |
| FINISH_BYTES                     | bigint(20)          |  NO   | 完了した復旧バイト数。現行バージョンでは、この値は常に0です |
| FINISH_BYTES_DISPLAY             | varchar(27)         |  NO   |復元完了バイト数。ストレージ容量単位で表示されます。現行バージョンでは、この値は常に0です。 |
| DESCRIPTION                      | longtext            |  NO   |復元コマンドで指定された`DESCRIPTION`情報   |
