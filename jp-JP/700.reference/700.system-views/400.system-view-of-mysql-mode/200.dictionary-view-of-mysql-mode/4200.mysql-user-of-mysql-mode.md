# mysql.user

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーのグローバル権限情報(VIRTUAL_TABLE)を表示します。

## フィールド説明

|        **フィールド名**        |    **型**     | **NULL許容** |                      **説明**                       |
|------------------------|---------------|----------------|---------------------------------------------------|
| host                   | varchar(128)  | NO             | ホスト名                                               |
| user                   | varchar(128)  | NO             | ユーザー名                                               |
| password               | varchar(128)  | NO             | ユーザーパスワード                                              |
| select_priv            | varchar(1)    | NO             | SELECT文を実行できるかどうか                                   |
| insert_priv            | varchar(1)    | NO             | INSERT文を実行できるかどうか                                   |
| update_priv            | varchar(1)    | NO             | UPDATE文を実行できるかどうか                                   |
| delete_priv            | varchar(1)    | NO             | DELETE文を実行できるかどうか                                   |
| create_priv            | varchar(1)    | NO             | CREATE文を実行できるかどうか                                   |
| drop_priv              | varchar(1)    | NO             | DROP文を実行できるかどうか                                     |
| reload_priv            | varchar(1)    | NO             | FLUSH文を実行できるかどうか。現在このフィールドは使用されていません                          |
| shutdown_priv          | varchar(1)    | NO             | SHUTDOWNコマンドを実行できるかどうか。現在このフィールドは使用されていません                       |
| process_priv           | varchar(1)    | NO             | アクティブスレッド情報を照会できるかどうか                                       |
| file_priv              | varchar(1)    | NO             | ファイルの読み書き権限があるかどうか。現在このフィールドは使用されていません                              |
| grant_priv             | varchar(1)    | NO             | 権限付与文を実行できるかどうか                                         |
| reference_priv         | varchar(1)    | NO             | 現在は使用されていません                                              |
| index_priv             | varchar(1)    | NO             | インデックスを作成できるかどうか                                   |
| alter_priv             | varchar(1)    | NO             | ALTER文を実行できるかどうか                                  |
| show_db_priv           | varchar(1)    | NO             | `show database`文を実行できるかどうか                   |
| super_priv             | varchar(1)    | NO             | スーパーユーザー権限を持つかどうか                             |
| create_tmp_table_priv  | varchar(1)    | NO             | 一時テーブルを作成できるかどうか                                 |
| lock_tables_priv       | varchar(1)    | NO             | `lock tables`文を実行できるかどうか。現在このフィールドは使用されていません |
| execute_priv           | varchar(1)    | NO             | ストアドプロシージャを実行できるかどうか。現在このフィールドは使用されていません                               |
| repl_slave_priv        | varchar(1)    | NO             | 現在は使用されていません                                              |
| repl_client_priv       | varchar(1)    | NO             | 現在は使用されていません                                              |
| create_view_priv       | varchar(1)    | NO             | ビューを作成できるかどうか                                           |
| show_view_priv         | varchar(1)    | NO             | `show create view`文を実行できるかどうか                       |
| create_routine_priv    | varchar(1)    | NO             | ストアドプロシージャを作成できるかどうか。現在このフィールドは使用されていません                               |
| alter_routine_priv     | varchar(1)    | NO             | ストアドプロシージャを変更できるかどうか。現在このフィールドは使用されていません                               |
| create_user_priv       | varchar(1)    | NO             | `create user`文を実行できるかどうか                            |
| event_priv             | varchar(1)    | NO             | イベントの作成、変更、削除を実行できるかどうか。現在このフィールドは使用されていません                         |
| trigger_priv           | varchar(1)    | NO             | TRIGGERを操作する権限があるかどうか。現在このフィールドは使用されていません                      |
| create_tablespace_priv | varchar(1)    | NO             | tablespaceを作成できるかどうか。現在このフィールドは使用されていません                        |
| ssl_type               | varchar(10)   | NO             | 現在このフィールドは使用されていません                                         |
| ssl_cipher             | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| x509_issuer            | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| x509_subject           | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| max_questions          | bigint(20)    | NO             | ユーザーが1時間に実行できる最大クエリ数（未使用）                               |
| max_updates            | bigint(20)    | NO             | ユーザーが1時間に実行できる最大更新数。現在このフィールドは使用されていません                          |
| max_connections        | bigint(20)    | NO             | ユーザーが1時間に受信できる最大接続数。現在このフィールドは使用されていません                          |
| max_user_connections   | bigint(20)    | NO             | 同時リクエストの最大接続数。現在このフィールドは使用されていません                              |
| plugin                 | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| authentication_string  | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| password_expired       | varchar(1)    | NO             | ユーザーパスワードが有効期限切れかどうか。現在このフィールドは使用されていません                                |
| account_locked         | varchar(1)    | NO   | ユーザーがロックされているかどうか    |
| drop_database_link_priv   | varchar(1)    | NO   | データベースリンクを削除できるかどうか     |
| create_database_link_priv | varchar(1)    | NO   | データベースリンクを作成できるかどうか     |
| create_role_priv          | varchar(1)    | NO   | ロールを作成できるかどうか     |
| drop_role_priv            | varchar(1)    | NO   | ロールを削除できるかどうか    |
