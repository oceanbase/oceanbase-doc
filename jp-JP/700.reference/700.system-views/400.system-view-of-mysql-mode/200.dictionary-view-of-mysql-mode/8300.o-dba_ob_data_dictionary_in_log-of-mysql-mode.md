# oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

データディクショナリがシステムログストリーム内に配置される範囲を記録し、CDCがデータディクショナリを利用する際に役立ちます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | データディクショナリ生成時のテナント対応SNAPSHOT SCN |
| REPORT_TIME | timestamp(6) | YES | データディクショナリ生成完了後、内部テーブルに報告された時間（単位：マイクロ秒） |
| START_LSN | bigint(20) unsigned | NO | テナント1号ログストリームに永続化された最初のログのLSN |
| END_LSN | bigint(20) unsigned | NO | テナント1号ログストリームに永続化された最後のログのLSN |

## クエリ例

システムテナントがすべてのユーザーテナントのデータディクショナリがシステムログストリーム内に配置される範囲を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_DATA_DICTIONARY_IN_LOG;
```
