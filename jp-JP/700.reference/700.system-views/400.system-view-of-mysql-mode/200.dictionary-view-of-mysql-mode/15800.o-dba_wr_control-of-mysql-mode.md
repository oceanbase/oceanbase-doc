# oceanbase.DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

WR関連の設定情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID <ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| SNAP_INTERVAL | varchar(64) | NO | スナップショット間の間隔設定。読みやすさのため`DD HH:mm:SS`形式を使用します |
| RETENTION | varchar(64) | NO | 各スナップショットの保持時間。読みやすさのため`DD HH:mm:SS`形式を使用します |
| TOPNSQL | bigint(20) | NO | 保存されるトップNのSQL |
