# oceanbase.DBA_MVREF_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_MVREF_STATS`は、マテリアライズドビューのリフレッシュに関する基本的な計時統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_OWNER | varchar(128) | NO | マテリアライズドビューの所有者 |
| MV_NAME | varchar(128) | NO | マテリアライズドビューの名前 |
| REFRESH_ID | bigint(20) | NO | リフレッシュのID |
| REFRESH_METHOD | varchar(30) | NO | マテリアライズドビューのリフレッシュ方式。<ul><li>FAST：増分リフレッシュ  </li><li>COMPLETE：全量リフレッシュ </li></ul>|
| REFRESH_OPTIMIZATIONS | text | NO | リフレッシュの最適化。例：空リフレッシュやマテリアライズドビューのリフレッシュ中のアプリケーションの主キー/外部キー。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| ADDITIONAL_EXECUTIONS | text | NO | 追加の実行処理。例：インデックスの再構築やマテリアライズドビューのリフレッシュ中に関与したログ操作。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| START_TIME | datetime | NO | リフレッシュ開始時間 |
| END_TIME | datetime | NO | リフレッシュ終了時間 |
| ELAPSED_TIME | bigint(20) | NO | リフレッシュ実行時間。<ul><li>V4.4.2 BP2 より前のバージョンでは秒単位です。</li><li>V4.4.2 バージョンでは、V4.4.2 BP2 以降はマイクロ秒単位です。</li></ul> |
| LOG_SETUP_TIME | bigint(1) | NO | マテリアライズドビューのログ設定時間、秒単位。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値は0です。</p></main> |
| LOG_PURGE_TIME | bigint(20) | YES | マテリアライズドビューのログクリーンアップ時間。<ul><li>V4.4.2 BP2 より前のバージョンでは秒単位です。</li><li>V4.4.2 バージョンでは、V4.4.2 BP2 以降はマイクロ秒単位です。</li></ul> |
| INITIAL_NUM_ROWS | bigint(20) | NO | マテリアライズドビューの初期行数（リフレッシュ開始時） |
| FINAL_NUM_ROWS | bigint(20) | NO | マテリアライズドビューの最終行数（リフレッシュ終了時） |
| NUM_STEPS             | bigint(20)          | NO   | このリフレッシュのステップ総数を表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドは V4.4.2 BP2 以降から導入されました。</p></main>|
| RESULT                | bigint(20)          | NO   | このリフレッシュタスクの実行結果コードを表します。0 が成功。<main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドは V4.4.2 BP2 以降から導入されました。</p></main>|
| REFRESH_SCN           | bigint(20) unsigned | YES  | リフレッシュ開始時のSCNを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドは V4.4.2 BP2 以降から導入されました。</p></main>|
| SVR_IP                | varchar(64)         | YES  | リフレッシュを実行したOBServerのIPアドレスを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドは V4.4.2 BP2 以降から導入されました。</p></main>|
| SVR_PORT              | bigint(20)          | YES  | リフレッシュを実行したOBServerのポートを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドは V4.4.2 BP2 以降から導入されました。</p></main>|
