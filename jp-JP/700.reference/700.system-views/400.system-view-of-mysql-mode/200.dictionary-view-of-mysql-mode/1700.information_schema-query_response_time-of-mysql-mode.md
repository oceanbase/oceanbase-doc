# information_schema.QUERY_RESPONSE_TIME

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

RESPONSE TIMEヒストグラムなどのデータ型(Histogram)を表示し、Prometheusによるモニタリングを可能にします。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| RESPONSE_TIME | bigint(14) | NO | 応答時間 |
| COUNT | bigint(14) | NO | 応答時間内のリクエスト数 |
| TOTAL | bigint(14) | NO | リクエストの総応答時間 |

## クエリ例
