# information_schema.PROCESSLIST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

実行中のスレッド情報を提供します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
|----------|---------------------|----------------|--------------|
| ID       | bigint(20) unsigned | NO             | 接続識別子 <br>V4.2.xバージョンの場合：<ul><li> V4.2.5 BP5より前のバージョン：<br>すべての接続モード（直結モード/ODPモード）で、このフィールドはServer Session IDを表します。</li><li> V4.2.5 BP5以降のバージョン：<ul><li>直結モードの場合：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの設定項目<code>client_session_id_version = 2</code>の場合、このフィールドはClient Session IDを表します。</li> <li><code>client_session_id_version = 1</code>の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul> |
| USER     | varchar(32)         | NO             | ユーザー名          |
| HOST     | varchar(128)        | NO             | クライアントホスト名      |
| DB       | varchar(128)        | YES            | データベース名        |
| COMMAND  | varchar(4096)       | NO             | スレッドが実行するコマンドの種類    |
| TIME     | bigint(20)          | NO             | スレッドが現在の状態にある時間、単位は秒 |
| STATE    | varchar(128)        | YES            | スレッドが実行中のタスクを示す識別子 |
| INFO     | varchar(262143)     | YES            | 現在のスレッドが実行している文  |

## クエリ例

ユーザーテナントが実行中のすべてのスレッド情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```

クエリ結果は次のとおりです：

```shell
+------------+------+----------------------+-----------+---------+------+--------+----------------------------------------------+

| 3221633480 | SYS  | 100.xx.xxx.xxx:59160 | SYS       | Sleep   | 1150 | SLEEP  | NULL                                         |
```
