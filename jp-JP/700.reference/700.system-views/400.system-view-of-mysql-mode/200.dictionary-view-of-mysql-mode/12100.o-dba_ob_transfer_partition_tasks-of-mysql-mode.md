# oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_TRANSFER_PARTITION_TASKS` は、このテナントで現在処理中のパーティション移行タスクを表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | bigint(20)   | NO   |  Transfer Partitionタスクの一意な識別子   |
| CREATE_TIME      | timestamp(6) | YES  |  作成時間   |
| MODIFY_TIME      | timestamp(6) | YES  |  情報更新時間   |
| TABLE_ID         | bigint(20)   | NO   |  Transferのパーティションが存在するテーブルID   |
| OBJECT_ID        | bigint(20)   | NO   |  Transferのパーティションの`OBJECT_ID`   |
| DEST_LS          | bigint(20)   | NO   |  目的地ログストリーム   |
| BALANCE_JOB_ID   | bigint(20)   | NO   |  タスク実行時に関連付けられるロードバランシングジョブID   |
| TRANSFER_TASK_ID | bigint(20)   | NO   |  タスク実行時に関連付けられるTransferタスクID   |
| STATUS           | varchar(64)  | NO   |  タスクステータス：<ul><li>WAITING：タスク待機中、実行開始されていない</li><li>INIT：タスクスケジューリング開始</li><li>DOING：タスクTransferの実行開始</li></ul>   |
| COMMENT          | longtext     | YES  |  コメント情報   |

## クエリ例

このテナントで現在処理中のパーティション移行タスクを照会します。

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS;
```

クエリ結果は次のとおりです：

```shell
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|       4 | 2023-12-01 11:21:11.357272 | 2023-12-01 11:21:17.904857 |   500012 |    500014 |    1003 |         737367 |                9 | DOING  | NULL    |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set (0.002 sec)
```
