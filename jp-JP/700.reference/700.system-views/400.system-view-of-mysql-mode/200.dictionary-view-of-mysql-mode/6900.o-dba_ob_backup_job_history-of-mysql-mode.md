# oceanbase.DBA_OB_BACKUP_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナント自身のバックアップJOBタスクの履歴を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | バックアップJOBタスクID。1回のバックアップに対応する1件のJOBタスクレコード |
| INCARNATION | bigint(20) | NO | Flashback Database後の何番目のインカーネーションかを示します |
| BACKUP_SET_ID | bigint(20) | YES | バックアップセットID。sysテナントはデフォルトで0、通常テナントでは1から増加します。アーカイブログバックアップタスク(`BACKUP_TYPE`が`BACKUP_ARCHIVE`または`BACKUP_ARCHIVE_DELETE_INPUT`)のレコードでは、このフィールドに実際の意味はありません。 |
| INITIATOR_TENANT_ID | bigint(20) | NO | タスクを開始したテナントのID。このタスクを開始したテナント、つまりバックアップSQLコマンドを実行したテナントIDを示す |
| INITIATOR_JOB_ID | bigint(20) | NO | タスクを開始したテナントに属するJOB_ID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | このJOBレベルバックアップタスクに関連する、バックアップを実行する必要があるテナントID |
| PLUS_ARCHIVELOG | varchar(4096) | NO | ログ補完機能の有無：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul>アーカイブログバックアップタスク(`BACKUP_TYPE`が`BACKUP_ARCHIVE`または`BACKUP_ARCHIVE_DELETE_INPUT`)のレコードでは、このフィールドに実際の意味はありません。 |
| BACKUP_TYPE | varchar(4096) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを表す </li> <li>`INC`：増分バックアップを表す</li><li>`BACKUP_ARCHIVE`：アーカイブログバックアップを表す。`ALTER SYSTEM BACKUP ARCHIVELOG ALL`ステートメントで開始されます。</li><li>`BACKUP_ARCHIVE_DELETE_INPUT`：`DELETE INPUT`を伴うアーカイブログバックアップを表す。`ALTER SYSTEM BACKUP ARCHIVELOG ALL DELETE INPUT`ステートメントで開始されます。</li></ul><br>V4.4.x系では、`BACKUP_ARCHIVE`と`BACKUP_ARCHIVE_DELETE_INPUT`はV4.4.2 BP3バージョンから導入されました。|
| JOB_LEVEL | varchar(4096) | NO | JOBレベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始する場合</li><li>SYS_TENANT：sysテナントが指定したテナントのバックアップタスクを開始する場合</li><li>USER_TENANT：通常テナントが自身のバックアップを開始する場合</li></ul> |
| ENCRYPTION_MODE | varchar(4096) | YES | 暗号化モード：<ul><li>None：暗号化しないことを表す</li><li>Password：パスワードのみによる保護を表す</li><li>Password Encryption：暗号化し、パスワードで保護することを表す</li><li>Transparent Encryption：TDE暗号化を使用することを表す</li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用することを表す</li></ul> <br>現在、NoneとPasswordの2種類のモードのみサポートしています |
| PASSWD | varchar(4096) | YES | パスワード |
| START_TIMESTAMP | timestamp(6) | NO | JOBレベルバックアップタスクの開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | JOBレベルバックアップタスクの終了時間 |
| STATUS | varchar(4096) | NO | バックアップの状態 |
| RESULT | bigint(20) | NO | バックアップエラーコードの結果 |
| COMMENT | varchar(4096) | YES | エラーコードの説明 |
| DESCRIPTION | varchar(4096) | YES | ユーザーが指定したバックアップの説明情報 |
| PATH | varchar(4096) | YES | バックアップパス |
