# information_schema.SCHEMATA

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

データベースのメタ情報を表示します。

## フィールドの説明

|          **フィールド名**          |    **型**    | **NULL許容** | **説明**  |
|----------------------------|--------------|----------------|---------|
| CATALOG_NAME               | varchar(3)   | NO             | 定数 def |
| SCHEMA_NAME                | varchar(128) | NO             | データベース名    |
| DEFAULT_CHARACTER_SET_NAME | varchar(7)   | NO             | デフォルト文字セット   |
| DEFAULT_COLLATION_NAME     | varchar(18)  | NO             | デフォルト照合規則  |
| SQL_PATH                   | null         | NO             | NULL    |
| DEFAULT_ENCRYPTION         | varchar(2)   | NO   | デフォルト暗号化の有無    |

## クエリ例

現在のテナント配下のすべてのデータベースのメタ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SCHEMATA;
```
