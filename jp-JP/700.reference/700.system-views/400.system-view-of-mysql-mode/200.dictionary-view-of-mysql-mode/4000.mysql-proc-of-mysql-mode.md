# mysql.proc

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ストアドプロシージャの情報を表示するために使用されます。

## フィールドの説明

|       **フィールド名**       |      **タイプ**      | **NULLを許容するか** |                                                                                  **説明**|
|----------------------|------------------|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| db                   | varchar(128)     | NO             | データベース名|
| name                 | varchar(128)     | NO             | ストアドプロシージャの名前                                                                                |
| type                 | varchar(10)      | NO             | ストアドプロシージャのタイプ：<ul><li>PROCEDURE：ストアドプロシージャ </li><li>FUNCTION：ストアドファンクション </li></ul>      |
| specific_name        | varchar(128)      | NO             | nameフィールドと同じです。</br> |
| language             | varchar(4)       | NO             | 使用されていません。現在は固定値SQLです。</br> |
| sql_data_access      | varchar(32)      | NO             | 使用されていません。現在は固定値CONTAINS_SQLです。</br> |
| is_deterministic     | varchar(4)       | NO             | 使用されていません。ストアドプロシージャが`DETERMINISTIC`特性を使用して定義されているかどうかを示します。<ul><li>YES </li><li> NO</li></ul> |
| security_type        | varchar(10)      | NO             | 使用されていません。SQLのアクセス属性を示します：<ul><li>DEFINER </li><li>INVOKER</li></ul>     |
| param_list           | longblob | NO             | ストアドプロシージャのパラメータリスト情報。</br> |
| returns              | longblob | NO             | ストアドプロシージャの戻り値情報。</br> |
| body                 | longblob | NO             | ストアドプロシージャ定義のテキスト情報。</br> |
| definer              | varchar(77)      | NO             | ストアドプロシージャを作成したユーザー                                                                              |
| created              | timestamp(6)     | NO             | ストアドプロシージャの作成日時                                                                           |
| modified             | timestamp(6)     | NO             | ストアドプロシージャの最終変更日時                                                                         |
| sql_mode             | text      | NO             | ストアドプロシージャの作成または変更時に有効なSQLモード。このモードでストアドプロシージャが実行される                                                       |
| comment              | varchar(4096) | NO             | コメントテキスト|
| character_set_client | varchar(128)     | NO             | ストアドプロシージャの作成または変更時のcharacter_set_clientシステム変数のセッション値                                             |
| collation_connection | varchar(128)     | NO             | ストアドプロシージャの作成または変更時のcollation_connectionシステム変数のセッション値                                               |
| collation_database   | varchar(128)     | NO             | ストアドプロシージャの作成または変更時のcollation_databaseシステム変数のセッション値                                                 |
| body_utf8            | longblob | NO             | プロシージャ定義。bodyフィールドと同じです                                                                       |

