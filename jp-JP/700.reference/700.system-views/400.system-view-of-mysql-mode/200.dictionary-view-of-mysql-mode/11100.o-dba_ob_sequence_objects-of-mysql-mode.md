# oceanbase.DBA_OB_SEQUENCE_OBJECTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのシーケンスを表示します。

## フィールド説明

|        フィールド名         |      型       | NULL許容 |                               説明                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| SEQUENCE_ID         | bigint(20)    | NO         | テナント内で一意のシーケンスID                                            |
| SCHEMA_VERSION      | bigint(20)    | NO         | シーケンスが記録されたスキーマのバージョン                                        |
| DATABASE_ID         | bigint(20)    | NO         | シーケンスが属するデータベースのID                                      |
| SEQUENCE_NAME       | varchar(128)  | NO         | シーケンス名                                                     |
| MIN_VALUE           | decimal(28,0) | NO         | シーケンスの最小値（含む）                                              |
| MAX_VALUE           | decimal(28,0) | NO         | シーケンスの最大値（最大値を含む）                                           |
| INCREMENT_BY        | decimal(28,0) | NO         | 値を取得する際のステップサイズ。正の整数または負の整数を指定できますが、0は指定できません                                         |
| START_WITH          | decimal(28,0) | NO         | シーケンスの開始値                                                 |
| CACHE_SIZE          | decimal(28,0) | NO         | 各ノードにキャッシュされる値の数                                                      |
| ORDER_FLAG          | tinyint(4)    | NO         | 値の取得順序がグローバルに保証されるかどうか                                                      |
| CYCLE_FLAG          | tinyint(4)    | NO         | 値を繰り返し取得できるかどうか                                                        |
| IS_SYSTEM_GENERATED | tinyint(4)    | NO         | 内部生成のシーケンスかどうか。現在、IDENTITY COLUMNで生成されるシーケンスではこのフィールドをTrueに設定します |

## クエリ例

現在のテナント配下のすべてのシーケンスを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SEQUENCE_OBJECTS;
```

クエリ結果は次のとおりです：

```shell

+-------------+------------------+-------------+---------------+-----------+-----------+--------------+------------+------------+------------+------------+---------------------+
|      500058 | 1741936647884232 |      500005 | seq1          |         1 |        10 |            2 |          1 |         30 |          0 |          0 |                   0 |

1 row in set
```
