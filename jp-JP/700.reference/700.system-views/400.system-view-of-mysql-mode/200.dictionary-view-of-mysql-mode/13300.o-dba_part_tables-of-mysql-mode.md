# oceanbase.DBA_PART_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのパーティションテーブルのパーティション情報を表示します。

## フィールドの説明

|           フィールド名            |      タイプ       | NULL値を許容するか |  説明  |
|---------------------------|---------------|------------|--------------------------------|
| OWNER                     | varchar(128)  | NO         | パーティションテーブルの所有者                                                                                 |
| TABLE_NAME                | varchar(128)  | NO         | パーティションテーブルの名前                                                                                  |
| PARTITIONING_TYPE         | varchar(13)   | NO         | パーティショニング方式：<ul><li>HASH   </li><li> RANGE   </li><li> LIST  </li></ul>  |
| SUBPARTITIONING_TYPE      | varchar(13)   | NO         | サブパーティションのパーティショニング方式：<ul><li>HASH   </li><li> RANGE   </li><li> LIST </li></ul>   |
| PARTITION_COUNT           | bigint(20)    | NO         | パーティションテーブル内のパーティション数                                                                                |
| DEF_SUBPARTITION_COUNT    | bigint(20)    | NO         | 複合パーティションテーブルにおいて、サブパーティションの数を示す                                                                        |
| PARTITIONING_KEY_COUNT    | bigint(21)    | NO         | パーティションキーの数                                                                                  |
| SUBPARTITIONING_KEY_COUNT | bigint(21)    | NO         | 複合パーティションテーブルにおいて、サブパーティションキーの数を示す                                                                       |
| STATUS                    | varchar(8)    | NO         | 現在このフィールドはサポートされておらず、現在デフォルトでNULLとなっています                                                                |

| DEF_PCT_FREE              | bigint(0)     | NO         | 現在このフィールドはサポートされておらず、現在デフォルトでNULLとなっています                                                                |
| DEF_PCT_USED              | bigint(0)     | NO         | 現在このフィールドはサポートされておらず、現在デフォルトでNULLとなっています                                                                |

| DEF_MAX_TRANS             | bigint(0)     | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです。                                                                |

| DEF_MAX_EXTENTS           | varchar(40)   | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです。                                                                |
| DEF_MAX_SIZE              | varchar(40)   | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです。                                                                |

| DEF_FREELISTS             | bigint(0)     | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです。                                                                |

| DEF_LOGGING               | varchar(7)    | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです。                                                                |
| DEF_COMPRESSION           | varchar(8)    | NO         | 圧縮を有効にするかどうか                                                                                  |
| DEF_COMPRESS_FOR          | varchar(12)   | NO         | 圧縮方式 |
| DEF_BUFFER_POOL           | varchar(7)    | NO         | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。                                                                |

| DEF_INMEMORY              | varchar(8)    | NO         | デフォルト値はNULLであり、実際の意味はありません                              |

| DEF_READ_ONLY             | varchar(3)    | NO         | 新しいパーティションのデフォルト設定を示します。<ul><li>YES：新しいパーティションのデフォルト設定は読み取り専用です</li><li>NO：新しいパーティションのデフォルト設定は読み書き可能です  </li></ul> |

| AUTO                      | varchar(3)    | NO         | テーブルが自動パーティション分割されるかどうかを示します。<ul><li>YES</li><li>NO </li></ul>   |
