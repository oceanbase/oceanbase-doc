# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントで現在実行中のロードバランシングジョブを表示します。各テナントは同一時刻に1つのロードバランシングジョブ(JOB)しか実行できません。各ロードバランシングジョブは、ロードバランシングの具体的な操作を実現するために複数のロードバランシングタスク(TASK)を生成します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | ロードバランシングジョブID |
| CREATE_TIME | timestamp(6) | YES | 作成日時 |
| MODIFY_TIME | timestamp(6) | YES | 情報更新日時 |
| BALANCE_STRATEGY | varchar(64) | NO | バランシング戦略名：<ul><li>`LS balance by migrate`：移行によるバランシング  </li><li>`LS balance by alter`：ログストリーム属性変更によるバランシング </li><li>`LS balance by expand`：拡張によるバランシング </li><li>`LS balance by shrink`：縮小によるバランシング </li><li>`partition balance`：パーティションによるバランシング </li></ul>|
| JOB_TYPE | varchar(64) | NO | ジョブタイプ <ul><li>`LS_BALANCE`：ログストリームのバランシング  </li><li>`PARTITION_BALACNE`：パーティションのバランシング </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | 変更先の各ゾーンのユニット数 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2以降、常に<code>NULL</code>となります。</li> <li>V4.2.5系では、このフィールドの値はV4.2.5 BP5以降、常に<code>NULL</code>となります。</li></ul></main>  |

| STATUS | varchar(64) | NO | ジョブのステータス：<ul><li>`DOING`：Jobの実行中  </li><li>`COMPLETED`：ジョブが正常に終了しました </li><li>`CANCELING`：ジョブのキャンセル中 </li><li>`CANCELED`：ジョブがキャンセルされました</li> <li>`SUSPEND`：ジョブが一時停止されています </li></ul>|
| COMMENT | longtext | YES | コメント |
| MAX_END_TIME | timestamp(6) | YES | ロードバランシングジョブの最大終了時間 <main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、このビューはV4.3.4から導入されました。V4.2.x系では、このフィールドはV4.2.4から導入されました。</p></main>  |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | テナントの各ゾーンのユニット数 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | バランシング関連の構成パラメータ  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
