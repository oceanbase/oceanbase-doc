# oceanbase.DBA_WR_STATNAME

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのシステム統計項目の名前を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | クラスタID |
| TENANT_ID | bigint(20) | NO | テナントID |
| STAT_ID | bigint(20) | NO | 統計項目ID |
| STAT_NAME | varchar(64) | NO | 統計項目名 |

## クエリ例

このテナントのシステム統計項目の名前を照会し、最初のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_STATNAME LIMIT 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
CLUSTER_ID: 10001
 TENANT_ID: 1
   STAT_ID: 10000
 STAT_NAME: rpc packet in
1 row in set (0.021 sec)
```
