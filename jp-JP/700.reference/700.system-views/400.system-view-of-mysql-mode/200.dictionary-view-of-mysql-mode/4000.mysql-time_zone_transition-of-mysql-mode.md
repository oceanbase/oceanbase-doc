# mysql.time_zone_transition

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>

## 機能の概要

タイムゾーン変換情報を表示するシステムビューです。

## フィールドの説明

|      **フィールド名**      |   **型**   | **NULL許容** |  **説明**   |
|--------------------|------------|----------------|-----------|
| Time_zone_id       | bigint(20) | NO             | タイムゾーンID     |
| Transition_time    | bigint(20) | NO             | タイムゾーン変換時間    |
| Transition_type_id | bigint(20) | NO             | タイムゾーン変換タイプID |
