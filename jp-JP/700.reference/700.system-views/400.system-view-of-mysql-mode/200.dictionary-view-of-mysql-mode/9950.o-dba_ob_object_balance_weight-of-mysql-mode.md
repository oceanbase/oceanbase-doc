# oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.5バージョンについて、このビューはV4.2.5 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_OBJECT_BALANCE_WEIGHT`は、現在のユーザーテナントで特別な重みが設定されたすべてのパーティションを表示するために使用されます。

## フィールドの説明

|       フィールド名     |      タイプ    | NULLを許容するか |         説明                                 |
|-------------------|--------------|----------------|----------------------------------------------|
| TABLE_ID          | bigint(20)   | NO             | テーブルID     |
| PARTITION_ID      | bigint(20)   | NO             | パーティションID。パーティション重みが設定されていない場合、値は`NULL`となります     |
| SUBPARTITION_ID   | bigint(20)   | NO             | サブパーティションID。サブパーティション重みが設定されていない場合、値は`NULL`となります。現在、サブパーティション重みの設定はサポートされていません     |
| WEIGHT            | bigint(20)   | NO             | パーティション重み値     |
| DATABASE_NAME     | varchar(128) | NO             | テーブルが属するデータベース名     |
| TABLE_NAME        | varchar(256) | NO             | テーブル名     |
| PARTITION_NAME    | varchar(64)  | NO             | パーティション名     |
| SUBPARTITION_NAME | varchar(64)  | NO             | サブパーティション名     |
| TABLEGROUP_NAME   | varchar(128) | NO             | テーブルが属するテーブルグループ名     |
| DATABASE_ID       | bigint(20)   | NO             | テーブルが属するデータベースID     |
| TABLEGROUP_ID     | bigint(20)   | NO             | テーブルが属するテーブルグループID     |
| OBJECT_ID         | bigint(20)   | NO             | テーブルが属するオブジェクトID     |

## クエリ例

ユーザーテナントは、自身のテナント内で特別な重みが設定されたパーティションを照会します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
```
