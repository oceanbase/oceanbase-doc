# oceanbase.DBA_OB_TABLEGROUPS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルグループのメタ情報を表示します。主に、テーブルグループのパーティション情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.0以降のバージョンでは、このビュー内のパーティションプロパティフィールドは意味を持たなくなり、統一的に<code>NONE</code>または</code>NULL</code>として表示されます。</p>
</main>

## フィールドの説明

|           フィールド名            |      タイプ      | NULLを許容するか |      説明      |
|---------------------------|--------------|------------|--------------------------------------------------------------------------------------------------------|
| TABLEGROUP_NAME           | varchar(128) | NO         | テーブルグループ名          |
| PARTITIONING_TYPE         | varchar(13)  | NO         | パーティションテーブルグループのパーティションタイプ：<ul><li>`NONE`：パーティションされていないテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0以降のバージョンから <code>NULL</code> の値を取ります。</p></main>            |
| SUBPARTITIONING_TYPE      | varchar(13)  | NO         | パーティションテーブルグループのサブパーティションタイプ：<ul><li>`NONE`：パーティションされていないテーブルグループ、パーティションされたテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0以降のバージョンから <code>NULL</code> の値を取ります。</p></main>     |
| PARTITION_COUNT           | bigint(20)   | NO         | パーティションテーブルグループのパーティション数。パーティションされていないテーブルグループの場合、この値は `NULL` です            |
| DEF_SUBPARTITION_COUNT    | bigint(0)    | NO         | パーティションテーブルグループのサブパーティションテンプレートのパーティション数。サブパーティションテンプレートが定義されていないテーブルグループの場合、この値は `NULL` です|
| PARTITIONING_KEY_COUNT    | bigint(20)   | NO         | パーティションテーブルグループのパーティションキー数。パーティションされていないテーブルグループの場合、この値は `NULL` です         |
| SUBPARTITIONING_KEY_COUNT | bigint(20)   | NO         | パーティションテーブルグループのサブパーティションのパーティションキー数。サブパーティションされていないテーブルグループの場合、この値は `NULL` です       |
| SHARDING                  | varchar(10)  | NO         | テーブルグループのSHARDINGプロパティです。値は以下のとおりです：<ul><li>`NONE`：このプロパティを持つテーブルグループでは、グループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、グループに追加されるテーブルに制限はありません。</li> <li>`PARTITION`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータがパーティション単位で分散されます。パーティションテーブルの場合、パーティション内のすべてのサブパーティションが一緒に集約されます。</li> <li>`ADAPTIVE`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータが適応型方式に基づいて分散されます。つまり、グループ内のテーブルがパーティションテーブルの場合はパーティション単位で分散され、サブパーティションテーブルの場合は各パーティション内のサブパーティション単位で分散されます。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |

## クエリ例

1. テーブルグループ `tblgroup1` を作成します。

    ```shell
    obclient [test]> CREATE TABLEGROUP tblgroup1 SHARDING = 'PARTITION';
    ```

2. テーブルグループ `tblgroup1` のSHARDINGプロパティを確認します。

    ```shell
    obclient [test]> SELECT TABLEGROUP_NAME, SHARDING FROM oceanbase.DBA_OB_TABLEGROUPS WHERE tablegroup_name = 'tblgroup1';
    ```

    クエリ結果は次のとおりです：

    ```shell
    +-----------------+-----------+
    | TABLEGROUP_NAME | SHARDING  |
    +-----------------+-----------+
    | tblgroup1       | PARTITION |
    +-----------------+-----------+
    1 row in set
    ```
