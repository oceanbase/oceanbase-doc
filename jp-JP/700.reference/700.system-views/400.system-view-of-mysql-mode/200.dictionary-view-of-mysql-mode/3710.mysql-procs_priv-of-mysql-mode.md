# mysql.procs_priv

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`mysql.procs_priv` ビューは、ストアドプロシージャおよび関数の権限情報を格納するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| Host         | varchar(60) | NO   | ホスト名     |
| Db           | varchar(64) | NO   | データベース名     |
| User         | varchar(32) | NO   | ユーザー名 (被授与者)     |
| Routine_name | varchar(64) | NO   | Routine名     |
| Routine_type | varchar(9)  | NO   | Routineタイプ     |
| Grantor      | varchar(93) | YES  | 授与者      |
| Proc_priv    | varchar(27) | NO   | 被授予的权限     |
| Timestamp    | date        | YES  | 授予时间     |

## クエリ例

ストアドプロシージャおよび関数の権限情報を照会し、最初のレコードを表示します。

```shell
obclient [mysql]> SELECT * FROM mysql.procs_priv LIMIT 1;
```

クエリ結果は次のとおりです：

```shell
+------+---------+------+-------------------+--------------+---------+-----------------------+------------+
| Host | Db      | User | Routine_name      | Routine_type | Grantor | Proc_priv             | Timestamp  |
+------+---------+------+-------------------+--------------+---------+-----------------------+------------+
| %    | test_db | root | pro_generate_data | PROCEDURE    | root@%  | Execute,Alter Routine | 2023-12-21 |
+------+---------+------+-------------------+--------------+---------+-----------------------+------------+
1 row in set (0.032 sec)
```
