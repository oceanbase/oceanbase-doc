# oceanbase.DBA_JAVA_POLICY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2バージョンでは、このビューはV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_JAVA_POLICY`は、DBAに現在のJava UDF権限設定の詳細を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| KIND        | varchar(8)    | NO   |  権限の種類    |
| GRANTEE     | varchar(128)  | NO   |  権限を付与されたユーザー名    |
| TYPE_SCHEMA | varchar(128)  | NO   |  権限タイプが存在するスキーマ    |
| TYPE_NAME   | varchar(4096) | YES  |  権限タイプ名    |
| NAME        | varchar(4096) | YES  |  権限名    |
| ACTION      | varchar(4096) | YES  |  具体の権限    |
| ENABLED     | varchar(8)    | NO   |  現在の権限が有効かどうか    |
| SEQ         | bigint(20)    | NO   |   `java_policy` の `key` に対応   |

## クエリ例

現在のMySQLテナント内のJava UDF権限設定の詳細を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_JAVA_POLICY;
```
