# information_schema.events

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.2バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.1 BP5バージョンとV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`information_schema.events` ビューは、すべてのイベント情報を記録するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | -------- | ------------------- | -------- |
| EVENT_CATALOG        | varchar(64)        | NO   | イベントが属するカタログ名です。この値は常にdefです。defは、システムビュー内のオブジェクトがデフォルトカタログに属することを示す汎用的な識別子です。     |
| EVENT_SCHEMA         | varchar(128)       | NO   | イベントが属するデータベース名です。     |
| EVENT_NAME           | varchar(64)        | NO   | イベント名です。     |
| DEFINER              | varchar(93)        | NO   | イベントを作成したユーザーです。     |
| TIME_ZONE            | varchar(64)        | NO   | イベントのタイムゾーン、つまりイベントのスケジューリングや実行時に適用されるタイムゾーンです。デフォルト値はSYSTEMです。     |
| EVENT_BODY           | varchar(8)         | NO   | イベントのDO句で使用されるステートメントの言語です。この値は常にSQLです。     |
| EVENT_definition     | mediumtext         | YES  | イベントのDO句を構成するSQLステートメントのテキストです。     |
| EVENT_TYPE           | varchar(9)         | NO   | イベントの繰り返しタイプです。一度きりのものか、繰り返し発生するものかを示します。     |
| EXECUTE_AT           | datetime           | YES  | 一度きりのイベントの開始時間です。繰り返し可能な場合はNULLです。     |
| INTERVAL_VALUE       | varchar(256)       | YES  | 繰り返しイベントにおいて、イベントの実行間隔で待機する回数を示します。一度きりのイベントでは、値は常にNULLです。     |
| INTERVAL_FIELD       | varchar(18)        | YES  | 繰り返しイベントが繰り返し前に待機する時間単位で使用される時間間隔です。一度きりのイベントでは、値は常にNULLです。     |
| SQL_MODE             | text               | NO   | イベントの作成または変更時に有効なSQLモード、およびイベント実行時に使用されるSQLモードです。     |
| STARTS               | datetime           | YES  | 定期的なイベントの開始日時です。イベントに開始日時が定義されていない場合はNULLです。一度きりのイベントでは、この列は常にNULLです。     |
| ENDS                 | datetime           | YES  | ENDS句を含む定義を持つ定期イベントについて、この列には対応するDATETIME値が含まれます。`EXECUTE_AT`列と同様に、この値は使用される任意の式を解釈します。イベントのタイミングに影響を与えるENDS句がない場合、この列はNULLです。     |
| STATUS               | varchar(18)        | NO   | イベントの状態です。<ul><li>ENABLED：イベントが有効な状態です。</li><li>DISABLED：イベントが無効な状態です。</li><li>SLAVESIDE_DISABLED：イベントがスレーブサイドで無効になっています。</li></ul>      |
| ON_COMPLETION        | varchar(12)        | NO   | 値は次のとおりです：<ul><li>PRESERVE：イベント終了後、イベント定義を保持します。</li><li>NOT PRESERVE：イベント終了後、イベント定義を保持しません。</li></ul>     |
| CREATED              | datetime           | YES  | イベントの作成日時です。     |
| LAST_ALTERED         | datetime           | YES  | イベントが最後に変更された日時です。     |
| LAST_EXECUTED        | datetime           | YES  | イベントが最後に実行された日時です。イベントが一度も実行されていない場合、この列はNULLになります。LAST_EXECUTEDはイベントの開始時間を表します。そのため、ENDS列の値は決してLAST_EXECUTEDより小さくなることはありません。     |
| EVENT_COMMENT        | text               | YES  | イベントにコメントがある場合は、そのコメントのテキストです。なければ、この値は空になります。     |
| ORIGINATOR           | bigint(0) unsigned | NO   | イベントを作成したMySQLサーバーのサービスIDで、レプリケーションで使用されます。レプリケーションソースでALTER EVENTステートメントを実行すると、この値はそのステートメントが発生した時点のサーバーのサービスIDに更新される可能性があります。デフォルト値は0です。     |
| CHARACTER_SET_CLIENT | varchar(32)        | NO   | イベント作成時のセッションの`character_set_client`システム変数の値です。     |
| COLLATION_CONNECTION | varchar(32)        | NO   | イベント作成時のセッションの`collation_connection`システム変数の値です。     |
| DATABASE_COLLATION   | varchar(32)        | NO   | イベントに関連付けられたデータベースの照合順序です。     |

## クエリ例

1. `e_1` という名前のイベントを作成します。このイベントは3000年1月1日00:00:00にスケジュールされ、SQL文 `SELECT 1` を実行します。

   ```shell
   obclient> CREATE EVENT e_1 ON SCHEDULE AT "3000-01-01 00:00:00" DO SELECT 1;
   ```

2. `e_1` イベントのすべての情報を照会します。

   ```shell
   obclient> SELECT * FROM information_schema.events\G
   ```
