# oceanbase.DBA_MVIEW_DEPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.5 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントのマテリアライズドビューの依存関係を表示するために使用されます。

## フィールドの説明

| **フィールド名** |   **型**  | **NULL許容** | **説明** |
|-------------|--------------|---------------------|---------|
| MVIEW_OWNER | varchar(128) | NO   | マテリアライズドビューの所有者名。|
| MVIEW_NAME  | varchar(256) | NO   | マテリアライズドビューの名前。|
| DEP_OWNER   | varchar(128) | NO   | 依存オブジェクトの所有者名。|
| DEP_NAME    | varchar(256) | NO   | 依存オブジェクトの名前。|
| DEP_TYPE    | varchar(64)  | NO   | 依存オブジェクトのタイプ：<ul><li>`MV`：マテリアライズドビュー</li><li>`TABLE`：通常テーブル</li><li>`EXTERNAL TABLE`：外部テーブル</li></ul>|

## クエリ例

```shell
obclient [(none)]> SELECT * FROM oceanbase.DBA_MVIEW_DEPS;
```

実行結果は次のとおりです：

```shell
+-------------+------------------+-----------+---------------+----------------+
| MVIEW_OWNER | MVIEW_NAME       | DEP_OWNER | DEP_NAME      | DEP_TYPE       |
+-------------+------------------+-----------+---------------+----------------+
| db_test     | mv_mv1_tbl3_tbl4 | db_test   | mv1_tbl3_tbl4 | MV             |
| db_test     | mv1_tbl3_tbl4    | db_test   | tbl4          | TABLE          |
| db_test     | mv1_tbl3_tbl4    | db_test   | tbl3          | TABLE          |
| db_test     | mv_ext_tbl1      | db_test   | ext_tbl1      | EXTERNAL TABLE |
+-------------+------------------+-----------+---------------+----------------+
4 rows in set
```
