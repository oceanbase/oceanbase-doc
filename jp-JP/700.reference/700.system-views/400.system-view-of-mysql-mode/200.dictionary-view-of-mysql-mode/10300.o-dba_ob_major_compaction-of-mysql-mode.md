# oceanbase.DBA_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのメジャーコンパクションに関するグローバル情報を表示します。

## フィールド説明

|           フィールド名           |     型      | NULL許容    |        説明         |
|--------------------------|-------------|------------|---------------------------------------------|
| FROZEN_SCN           | bigint(20) unsigned  | NO         | 最後のメジャーコンパクションのバージョン番号           |
| FROZEN_TIME              | timestamp(6)  | NO         | 最後のメジャーコンパクション開始時刻（FROZEN_SCNを読みやすい形式で表示）          |
| GLOBAL_BROADCAST_SCN | bigint(20) unsigned  | NO         | グローバルブロードキャストのメジャーコンパクションバージョン         |
| LAST_SCN             | bigint(20) unsigned  | NO         | 直前に完了したメジャーコンパクションのバージョン      |
| LAST_FINISH_TIME         | timestamp(6)  | NO         | 前回のメジャーコンパクション終了時刻         |
| START_TIME               | timestamp(6)  | NO         | メジャーコンパクション開始時刻            |
| STATUS                   | varchar(10) | NO         | <ul><li>`IDLE`：現在メジャーコンパクション中ではありません </li><li> `COMPACTING`：現在メジャーコンパクション中です </li><li>`CHECKSUM`：チェックサムの検証中 </li></ul>   |
| IS_ERROR                 | varchar(3)  | NO         | <ul><li>`YES`：メジャーコンパクション処理中にエラーが発生しました </li><li> `NO`：メジャーコンパクション処理中にエラーは報告されていません </li></ul>   |
| IS_SUSPENDED             | varchar(3)  | NO         | <ul><li>`YES`：メジャーコンパクションが一時停止状態です </li><li>`NO`：メジャーコンパクションは一時停止されていません   </li></ul>   |
| INFO                     | varchar(14) | NO         | メジャーコンパクション情報を表示します。例：メジャーコンパクション失敗の原因  |

## クエリ例

ユーザーテナントが自身のテナントにおけるメジャーコンパクションのグローバル情報を確認します。

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_MAJOR_COMPACTION;
```

クエリ結果は次のとおりです：

```shell
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+
| FROZEN_SCN          | FROZEN_TIME                | GLOBAL_BROADCAST_SCN | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS | IS_ERROR | IS_SUSPENDED | INFO |
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+
| 1748455203748142000 | 2025-05-29 02:00:03.748142 |  1748455203748142000 | 1748455203748142000 | 2025-05-29 02:05:55.876675 | 2025-05-29 02:00:03.770352 | IDLE   | NO       | NO           |      |
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+
1 row in set
```
