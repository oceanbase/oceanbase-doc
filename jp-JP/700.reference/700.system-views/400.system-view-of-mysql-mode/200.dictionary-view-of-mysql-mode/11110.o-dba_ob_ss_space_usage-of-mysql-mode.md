# oceanbase.DBA_OB_SS_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_SS_SPACE_USAGE`は、現在のテナントのオブジェクトストレージ上のストレージ容量使用状況を記録するために使用されます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールドの説明

| フィールド名       | 型          | NULL許容      | 説明                                        |
|---------------|---------------|---------------------|----------------------------------------|
| ENDPOINT      | varchar(128)  | NO   | ストレージを共有するEndpoint。      |
| PATH          | varchar(128)  | NO   | ストレージを共有するPath。      |
| STORAGE_TYPE  | varchar(32)   | NO   | ストレージタイプ：<ul><li>`Local All Bytes`：オブジェクトストレージ上のローカルディレクトリのすべてのデータ</li> <li>`Shared Data Bytes`：オブジェクトストレージ上のパブリックディレクトリのデータ</li> <li>`Shared Meta Bytes`：オブジェクトストレージ上のすべてのメタデータ</li></ul>     |
| VALUE         | bigint(20)    | NO   | `STORAGE_TYPE`に対応する使用容量。単位はバイトです。   |

## クエリ例

共有ストレージモードで、自身のテナントのオブジェクトストレージ上のストレージ容量使用状況を確認します。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_SS_SPACE_USAGE;
```

クエリ結果は次のとおりです：

```shell
+----------+-------+-------------------+----------+
| ENDPOINT | PATH  | STORAGE_TYPE      | VALUE    |
+----------+-------+-------------------+----------+
| UNUSE    | UNUSE | Local All Bytes   |        0 |
| UNUSE    | UNUSE | Shared Data Bytes | 22203985 |
| UNUSE    | UNUSE | Shared Meta Bytes |  6508544 |
+----------+-------+-------------------+----------+
3 rows in set
```
