# oceanbase.DBA_WR_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

リソースグループ粒度のsysstatを表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20)  | NO   | クラスタID    |
| TENANT_ID  | bigint(20)  | NO   | テナントID    |
| GROUP_ID   | bigint(20)  | NO   | consumer_group_id   |
| SNAP_ID    | bigint(20)  | NO   | スナップショットID    |
| SVR_IP     | varchar(46) | NO   | ノードIP    |
| SVR_PORT   | bigint(20)  | NO   | ノードポート   |
| STAT_ID    | bigint(20)  | NO   | 統計項目ID    |
| VALUE      | bigint(20)  | YES  | 統計値    |

## クエリ例

リソースグループ粒度のsysstatを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_RES_MGR_SYSSTAT limit 1;
```

クエリ結果は次のとおりです。

```shell
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
| CLUSTER_ID | TENANT_ID | SNAP_ID | SVR_IP          | SVR_PORT | STAT_ID | VALUE  | group_id |
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
|          1 |         1 |       1 | xxx.xxx.xxx.198 |    49708 |   10000 | 460384 |        1 |
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
1 row in set
```
