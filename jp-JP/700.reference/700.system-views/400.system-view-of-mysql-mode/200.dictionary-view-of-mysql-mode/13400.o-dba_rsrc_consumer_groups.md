# oceanbase.DBA_RSRC_CONSUMER_GROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのリソースグループの情報を表示します。

## フィールドの説明

|       フィールドタイプ        |       タイプ       | NULLを許容するか |                  説明                  |
|-------------------|----------------|------------|--------------------------------------|
| CONSUMER_GROUP_ID | bigint(20)     | NO         | リソースグループID。                              |
| CONSUMER_GROUP    | varchar(128)  | NO         | ユーザーがバインドされているリソースグループの名前。                        |
| CPU_METHOD        | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                 |
| MGMT_METHOD       | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                 |
| INTERNAL_USE      | varchar(3)    | NO         | このリソースグループが内部専用であるかどうかを示します。互換性のためにのみ使用され、現在の値は固定で`NULL`です。 |
| COMMENTS          | varchar(2000) | YES        | リソースグループの備考情報。                           |
| CATEGORY          | varchar(128)  | NO         | リソースグループのカテゴリ。互換性のためにのみ使用され、現在の値は固定で`NULL`です。          |
| STATUS            | varchar(128)  | NO         | リソースグループのステータス。互換性のためにのみ使用され、現在の値は固定で`NULL`です。          |
| MANDATORY         | varchar(3)    | NO         | このリソースグループが必須であるかどうかを示します。互換性のためにのみ使用され、現在の値は固定で`NULL`です。     |

## クエリ例

ユーザーテナントが自身のすべてのリソースグループの情報を照会します。

```shell
obclient [oceanbase]> SELECT CONSUMER_GROUP_ID, CONSUMER_GROUP FROM oceanbase.DBA_RSRC_CONSUMER_GROUPS;
```

クエリ結果は次のとおりです：

```shell
+-------------------+-------------------+
| CONSUMER_GROUP_ID | CONSUMER_GROUP    |
+-------------------+-------------------+
|             10001 | batch_group       |
|             10000 | interactive_group |
+-------------------+-------------------+
2 rows in set
```
