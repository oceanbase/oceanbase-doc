# oceanbase.DBA_OB_TABLET_REPLICAS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのTabletレプリカ情報を表示します。各Tabletレプリカは、`<TABLET_ID, SVR_IP, SVR_PORT, LS_ID>`という組み合わせキーによって一意に特定されます。

## フィールド説明

|     フィールド名      |     型      | NULL許容   |              説明              |
|---------------|-------------|------------|------------------------------------------------------------|
| CREATE_TIME     | timestamp(6)  | NO         | 作成日時    |
| MODIFY_TIME     | timestamp(6)  | NO         | 変更日時     |
| TABLET_ID     | bigint(20)  | NO         | TABLET ID     |
| SVR_IP        | varchar(46) | NO         | サーバーIPアドレス     |
| SVR_PORT      | bigint(20)  | NO         | サーバーポート番号        |
| LS_ID         | bigint(20)  | NO         | TABLETが属するログストリームID             |
| COMPACTION_SCN  | bigint(20) unsigned  | NO         | データスナップショットバージョン番号         |
| DATA_SIZE     | bigint(20)  | NO         | データの実際のサイズ、単位はバイト        |
| REQUIRED_SIZE | bigint(20)  | NO         | データ割り当てサイズ、単位はバイト。データ保存はマクロブロック（2MB）を最小単位とするため、`REQUIRED_SIZE >= DATA_SIZE` |

## クエリ例
