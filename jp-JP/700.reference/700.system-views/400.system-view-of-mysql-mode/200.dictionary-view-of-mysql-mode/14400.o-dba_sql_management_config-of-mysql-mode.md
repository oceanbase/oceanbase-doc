# oceanbase.DBA_SQL_MANAGEMENT_CONFIG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMに含まれる構成パラメータを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(128) | NO | 構成パラメータ名：<ul><li>SPACE_BUDGET_PERCENT</li><li>PLAN_RETENTION_WEEKS</li></ul> |
| PARAMETER_VALUE | text | YES | 構成パラメータの値 |
| LAST_MODIFIED | timestamp(6) | YES | パラメータ値が最後に更新された日時 |
| MODIFIED_BY | varchar(128) | NO | パラメータ値を最後に更新したユーザー |

## クエリ例

現在のテナントのSPMに含まれる構成パラメータを確認します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_SQL_MANAGEMENT_CONFIG;
```
