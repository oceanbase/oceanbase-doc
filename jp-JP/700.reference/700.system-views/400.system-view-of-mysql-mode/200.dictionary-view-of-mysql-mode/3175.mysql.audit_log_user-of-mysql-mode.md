# mysql.audit_log_user

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.3.x系では、このビューはV4.3.3バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

ビュー`mysql.audit_log_user`は、監査フィルターとユーザーのマッピング関係を表示するために使用されます。

<main id="notice" >
  <h4>適用対象</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは、現在監査機能をサポートしていません。</p>
</main>

## フィールドの説明

| **フィールド名** | **型**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| USER       | varchar(128) | NO | ユーザー名 |
| HOST       | varchar(128) | NO | ホスト名 |
| FILTERNAME | varchar(64)  | NO | フィルター名 |

## クエリ例

監査フィルターとユーザーのマッピング関係を確認します。

```shell
obclient [mysql]> select * from mysql.audit_log_user;
```

クエリ結果は次のとおりです：

```shell
+---------+------+------------+
| USER    | HOST | FILTERNAME |
+---------+------+------------+
| user001 | %    | log_all    |
+---------+------+------------+
1 row in set (0.003 sec)
```
