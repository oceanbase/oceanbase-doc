# oceanbase.DBA_OB_ARCHIVELOG_PIECE_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのバックアップコレクション内のPieceの状態を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | パス番号。システムは設定された各パスに一意のIDを割り当てます |
| ROUND_ID | bigint(20) | NO | 完全なClogバックアップデータストリームのラウンド番号を識別するために使用されます |
| PIECE_ID | bigint(20) | NO | バックアップログログフラグメントのID |
| INCARNATION | bigint(20) | NO | Flashback Database後の化身の回数を表します |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するために使用されます。例：log_archive_destのdest_noは0、log_archive_dest_1のdest_noは1などです |
| STATUS | varchar(64) | NO | Pieceの状態：<ul><li>ACTIVE：現在アクティブなPiece</li><li>FREEZING：凍結中のPiece</li><li>FROZEN：既に凍結されたPiece。この状態以降、そのPieceの状態は変更されません</li></ul> |
| START_SCN | bigint(20) unsigned | NO | Pieceが実際に開始したポイント |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に変換した表示 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に変換した表示 |
| MAX_SCN | bigint(20) unsigned | NO | 最大アーカイブポイント |
| END_SCN | bigint(20) unsigned | NO | Pieceの理論上の終了ポイント |
| END_SCN_DISPLAY| datetime(6) |NO | Piece終了時の時点|
| COMPATIBLE | bigint(20) | NO | ログアーカイブの互換バージョン番号 |
| UNIT_SIZE   | bigint(20)   | NO   | ログアーカイブデータの1回の圧縮または暗号化におけるログブロックサイズ。現在このフィールドはサポートされていません  |
| COMPRESSION | varchar(128) | NO   | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを表します </li><li> lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを表します </li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを表します</li></ul>現在このフィールドはサポートされていません   |
| INPUT_BYTES | bigint(20) | NO | 元データ量、単位はバイト |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | INPUT_BYTESを単位変換した表示 |
| OUTPUT_BYTES | bigint(20) | NO | 暗号化・圧縮後の有効データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | OUTPUT_BYTESを単位変換した表示 |
| COMPRESSION_RATIO | decimal(23,2) | NO | 圧縮率。現在このフィールドはサポートされていません |
| FILE_STATUS | varchar(64) | NO | バックアップログログフラグメントのファイル状態：<ul><li>AVAILABLE：有効なバックアップであり、復元に使用できることを表します</li><li>COPYING：ログファイルがバックアップ中であることを表します</li><li>INCOMPELTE：Piece内のログが不完全で、一部のログストリームのログが欠けていることを表します</li><li>DELETING：ログファイルが削除中であることを表します</li><li>EXPIRED：バックアップファイルが無効になったことを表します</li><li>BROKEN：バックアップファイルが不完全で使用できないことを表します</li><li>DELETED：ログファイルが削除されたことを表します</li></ul> |
| PATH | varchar(2048) | NO | アーカイブパス |
