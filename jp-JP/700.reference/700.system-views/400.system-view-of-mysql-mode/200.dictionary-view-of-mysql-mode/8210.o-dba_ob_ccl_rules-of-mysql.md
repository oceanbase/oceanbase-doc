# oceanbase.DBA_OB_CCL_RULES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このビューはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このビューはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>

## 機能の概要

ユーザーテナントの現在のすべてのレート制限ルールを記録するために使用されます。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
|TENANT_ID| bigint(20)| NO| テナントID|
|CCL_RULE_ID|bigint(20)|NO|レート制限ルールID|
|CCL_RULE_NAME| varchar(128)| NO| レート制限ルール名|
|AFFECT_USER_NAME| varchar(128)| NO |レート制限が適用されるユーザー|
|AFFECT_HOST| varchar(128)| NO| レート制限が適用されるIPアドレス|
|AFFECT_FOR_ALL_DATABASES| tinyint(4)| NO| すべてのデータベースに適用されるかどうか|
|AFFECT_FOR_ALL_TABLES| tinyint(4)| NO| すべてのテーブルに適用されるかどうか|
|AFFECT_DML| bigint(20)| NO| レート制限が適用されるDMLタイプのステートメント|
|AFFECT_DATABASE| bigint(20)| YES |レート制限が適用されるデータベース|
|AFFECT_TABLE| bigint(20)| YES| レート制限が適用されるテーブル|
|AFFECT_SCOPE| bigint(10)| NO |レート制限の適用粒度:<li>ルールレベル: 0 </li><li>Format SQLIDレベル:1</li>|
|CCL_KEYWORDS| varchar(1048576)| NO |レート制限のキーワード|
|MAX_CONCURRENCY| bigint(20)| NO |レート制限の並列度の上限|

## クエリ例

ユーザーテナントが自身のテナントのレート制限ルールを照会します。

```shell
obclient[oceanbase]> SELECT * FROM DBA_OB_CCL_RULES;
```
