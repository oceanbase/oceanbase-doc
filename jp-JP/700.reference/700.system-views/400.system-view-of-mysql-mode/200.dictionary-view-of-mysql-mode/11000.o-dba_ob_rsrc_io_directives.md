# oceanbase.DBA_OB_RSRC_IO_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>このビューはV4.1.0バージョンから導入されました。</li>
<li>現在のバージョンでは、テナントのResource Managerにおける各種リソース設定パラメータ情報を確認するには、ビュー<a href="11020.o-dba_ob_rsrc_directives-of-mysql-mode.md">DBA_OB_RSRC_DIRECTIVES</a>の使用を推奨します。</li></ul>
</main>

## 機能の概要

Resource Manager内のI/Oリソース設定状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| PLAN | varchar(128) | NO | 指令が属するリソース計画名 |
| GROUP_OR_SUBPLAN | varchar(128) | NO | 指令が制御するリソースグループ名 |
| COMMENTS    | varchar(2000) | YES | リソース計画の備考 |
| MIN_IOPS    | bigint(20)    | NO | I/O競合が発生した場合にリザーブされるIOPSリソース。すべてのリソースグループで指定された`MIN_IOPS`の合計は100を超えてはならない。デフォルト値は`0`     |
| MAX_IOPS    | bigint(20)    | NO | リソースグループが使用できる最大IOPSリソース。すべてのリソースグループで指定された`MAX_IOPS`の合計は100を超えてもよい。デフォルト値は`100`     |
| WEIGHT_IOPS | bigint(20)    | NO | I/Oリソース競合が発生した場合のIOPSの重み値。すべてのリソースグループで指定された`WEIGHT_IOPS`の合計は100を超えてもよい。`MIN_IOPS`および`MAX_IOPS`の設定を満たす前提で、I/Oリソースは重みの正規化値に従って割り当てられる。デフォルト値は`0`     |

## クエリ例

ユーザーテナントが自身のテナントのResource Manager内のI/Oリソース設定状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RSRC_IO_DIRECTIVES;
```

クエリ結果は次のとおりです：

```shell
+---------+------------------+----------+----------+----------+-------------+
| PLAN    | GROUP_OR_SUBPLAN | COMMENTS | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS |
+---------+------------------+----------+----------+----------+-------------+
| daytime | batch_group      |          |       40 |       80 |          70 |
+---------+------------------+----------+----------+----------+-------------+
1 row in set
```
