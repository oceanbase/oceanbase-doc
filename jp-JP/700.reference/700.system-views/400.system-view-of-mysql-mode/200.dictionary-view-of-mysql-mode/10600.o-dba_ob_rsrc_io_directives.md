# oceanbase.DBA_OB_RSRC_IO_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

Resource Manager内のI/Oリソース構成を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| PLAN | varchar(128) | NO | コマンドが属するリソース計画名 |
| GROUP_OR_SUBPLAN | varchar(128) | NO | コマンドが制御するリソースグループ名 |
| COMMENTS | varchar(2000) | YES | リソース計画の備考 |
| MIN_IOPS | bigint(20) | NO | IOPSの予約語義。値は`0-100` |
| MAX_IOPS | bigint(20) | NO | IOPSの上限語義。値は`0-100` |
| WEIGHT_IOPS | bigint(20) | NO | IOPSの共有語義。値は`0-100` |

## クエリ例

ユーザーテナントが自身のテナントのResource Manager内のI/Oリソース構成を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RSRC_IO_DIRECTIVES;
```

クエリ結果は次のとおりです：

```shell
+---------+------------------+----------+----------+----------+-------------+
| PLAN    | GROUP_OR_SUBPLAN | COMMENTS | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS |
+---------+------------------+----------+----------+----------+-------------+
| daytime | batch_group      |          |       40 |       80 |          70 |
+---------+------------------+----------+----------+----------+-------------+
1 row in set
```
