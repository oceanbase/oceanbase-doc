# information_schema.TABLES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

`information_schema.TABLES` ビューは、テーブルの情報を表示します。

## フィールド説明

|      フィールド名    |         型           | NULL許容 |    説明     |
|-----------------|--------------------|----------------|-------------|
| TABLE_CATALOG   | varchar(512)        | NO | テーブルカタログ。 |
| TABLE_SCHEMA    | varchar(64)         | NO | データベース名。 |
| TABLE_NAME      | varchar(64)         | NO | テーブル名。 |
| TABLE_TYPE      | varchar(64)         | NO | テーブルタイプ。 |
| ENGINE          | varchar(64)         | NO | 使用されているストレージエンジンのタイプ。 |
| VERSION         | bigint(0) unsigned  | NO | バージョン。 |
| ROW_FORMAT      | varchar(10)         | NO | 行フォーマット。 |
| TABLE_ROWS      | bigint(21) unsigned | NO | テーブルの行数。 |
| AVG_ROW_LENGTH  | bigint(21) unsigned | NO | 平均行長。 |
| DATA_LENGTH     | bigint(21) unsigned | NO | データ長、すなわちテーブルが占有するストレージ容量。マクロブロックサイズ単位で計算され、単位はByteです。<main id="notice" type='explain'><h4>説明</h4>p>V4.3.x系では、このフィールドはV4.3.5バージョンから有効になります。</p></main> |
| MAX_DATA_LENGTH | bigint(0) unsigned  | NO | 最大データ長。 |
| INDEX_LENGTH    | bigint(0) unsigned  | NO | インデックス長、すなわち非主キーインデックスが占有するストレージ容量。マクロブロックサイズ単位で計算され、単位はByteです。<main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、このフィールドはV4.3.5バージョンから有効になります。</p></main> |
| DATA_FREE       | bigint(0) unsigned  | NO | 残り容量。 |
| AUTO_INCREMENT  | bigint(0) unsigned  | NO | 現在の自動インクリメント値。 |
| CREATE_TIME     | datetime            | NO | テーブルの作成日時。 |
| UPDATE_TIME     | datetime            | NO | テーブルの最終更新日時。 |
| CHECK_TIME      | datetime            | NO | テーブルの最終チェック日時。 |
| TABLE_COLLATION | varchar(32)         | NO | テーブルの文字セット比較方式。 |
| CHECKSUM        | bigint(0) unsigned  | NO | チェックサム。 |
| CREATE_OPTIONS  | varchar(255)        | NO | 作成オプション。 |
| TABLE_COMMENT   | text                | NO | テーブルのコメント。 |
| AUTO_SPLIT    | varchar(16) | NO | テーブルの自動パーティショニングが有効かどうかを示します。値は以下のとおりです：<ul><li>`FALSE`（デフォルト値）：テーブルの自動パーティショニングが無効であることを示します。</li><li>`TRUE`：テーブルの自動パーティショニングが有効であることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>|
| AUTO_SPLIT_TABLET_SIZE | bigint(20) unsigned | NO | 自動パーティション分割のしきい値を示します。`AUTO_SPLIT` フィールドの値が `FALSE` の場合、`AUTO_SPLIT_TABLET_SIZE` の値は0になります。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>|
| ORGANIZATION    | varchar(12)         | NO | テーブルの組織モードを示します。値は以下のとおりです。<ul><li>`HEAP`：ヒープ組織テーブルモードを示します。</li><li>`INDEX`：インデックス組織テーブルモードを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、このフィールドはV4.3.5 BP1バージョンからサポートされています。</p></main>|
