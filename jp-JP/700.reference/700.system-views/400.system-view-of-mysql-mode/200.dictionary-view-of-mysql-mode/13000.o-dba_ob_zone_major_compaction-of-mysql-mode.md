# oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントの各ゾーンにおけるメジャーコンパクション情報を表示します。

## フィールド説明

|       フィールド名        |      型      | NULL許容    |         説明         |
|-------------------|--------------|------------|------------------|
| ZONE              | varchar(128) | NO         | Zone名            |
| BROADCAST_SCN | bigint(20) unsigned   | NO         | ブロードキャストされたメジャーコンパクションのバージョン番号           |
| LAST_SCN      | bigint(20) unsigned   | NO         | 最終メジャーコンパクションのバージョン番号          |
| LAST_FINISH_TIME  | timestamp(6)   | NO         | 最終メジャーコンパクション終了時間          |
| START_TIME        | timestamp(6)   | NO         | メジャーコンパクション開始時間             |
| STATUS            | varchar(10)  | NO         | <ul><li> `IDLE`：メジャーコンパクション中ではありません  </li><li>`COMPACTING`：メジャーコンパクション中 </li></ul> |

## クエリ例

ユーザーテナントが本テナントの各ゾーンにおけるメジャーコンパクション情報を確認します。

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION;
```

クエリ結果は次のとおりです：

```shell
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| ZONE  | BROADCAST_SCN       | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| zone1 | 1748455203748142000 | 1748455203748142000 | 2025-05-29 02:05:55.879349 | 2025-05-29 02:00:03.782431 | IDLE   |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
1 row in set
```
