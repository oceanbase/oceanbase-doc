# mysql.time_zone_transition_type

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

タイムゾーン変換タイプを表示します(SYSTEM_VIEW)。

## フィールドの説明

|      **フィールド名**      |   **型**   | **NULL許容** |  **説明**   |
|--------------------|------------|----------------|-----------|
| Time_zone_id       | bigint(20) | NO             | タイムゾーンID     |
| Transition_type_id | bigint(20) | NO             | タイムゾーン変換タイプID |
| Offset             | bigint(20) | NO             | タイムゾーンオフセット      |
| Is_DST             | bigint(20) | NO             | 夏時間かどうか    |
| Abbreviation       | varchar(8) | NO             | 略称        |
