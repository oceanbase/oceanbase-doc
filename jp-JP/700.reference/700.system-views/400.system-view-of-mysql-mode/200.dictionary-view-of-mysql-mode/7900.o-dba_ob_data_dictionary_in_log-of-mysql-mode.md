# oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

データディクショナリがシステムログストリーム内に存在する範囲を記録し、CDCがデータディクショナリを消費する際に便利です。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | データディクショナリ生成時の対応テナントのSNAPSHOT SCN |
| REPORT_TIME | timestamp(6) | YES | データディクショナリ生成完了後、内部テーブルへ報告されるまでの時間（単位：マイクロ秒） |
| START_LSN | bigint(20) unsigned | NO | テナント1号ログストリームに永続化された最初のログのLSN |
| END_LSN | bigint(20) unsigned | NO | テナント1号ログストリームに永続化された最後のログのLSN |

## クエリ例

このテナントのデータディクショナリがシステムログストリーム内に存在する範囲を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG;
```

クエリ結果は次のとおりです：

```shell
+---------------------+----------------------------+-----------+---------+
| SNAPSHOT_SCN        | REPORT_TIME                | START_LSN | END_LSN |
+---------------------+----------------------------+-----------+---------+
| 1722408567371559602 | 2024-07-31 14:49:27.420098 |   9118467 | 9118467 |
+---------------------+----------------------------+-----------+---------+
1 row in set
```
