# oceanbase.DBA_OBJECTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OBJECTS` は、このテナントのすべてのデータベースオブジェクトを表示するために使用されます。ビューの定義はビュー `ALL_OBJECTS` と一致します。

## フィールドの説明

|       フィールド名        |      タイプ      | NULLを許容するか |              説明               |
|-------------------|--------------|------------|-------------------------------|
| OWNER             | varchar(128) | NO         | オブジェクトが属する所有者                      |
| OBJECT_NAME       | varchar(128) | NO         | オブジェクト名                          |
| SUBOBJECT_NAME    | varchar(128) | NO         | サブオブジェクト名（例えば、パーティション）           |
| OBJECT_ID         | bigint(20)   | NO         | オブジェクトのディクショナリID値                    |
| DATA_OBJECT_ID    | bigint(20)   | NO         | そのオブジェクトのセグメントを含むディクショナリID値         |
| OBJECT_TYPE       | varchar(23)  | NO         | オブジェクトタイプ。テーブル、インデックス、パーティション、パッケージ、ストアドプロシージャ、シノニム、シーケンスなどを含む |
| CREATED           | datetime     | NO         | オブジェクト作成時間                        |
| LAST_DDL_TIME     | datetime     | NO         | オブジェクトの最後のDDL実行時間                 |
| TIMESTAMP         | datetime     | NO         | オブジェクトに指定されたタイムスタンプ。文字列として出力されます              |
| STATUS            | varchar(7)   | NO         | オブジェクトのステータス：<ul><li>`VALID`：有効</li><li> `INVALID`：無効 </li></ul>  |
| TEMPORARY         | varchar(1)   | NO         | このオブジェクトが一時オブジェクトであるかどうか                  |
| GENERATED         | varchar(1)   | NO         | このオブジェクトの名前がシステムによって生成されたものかどうか              |
| SECONDARY         | varchar(1)   | NO         | 現在このフィールドは使用されていません                     |
| NAMESPACE         | bigint(1)    | NO         | オブジェクトのネームスペース                       |
| EDITION_NAME      | varchar(128) | NO         | 予約フィールド                          |
| SHARING           | varchar(18)  | NO         | このフィールドのデフォルト値は`NULL`です                           |
| EDITIONABLE       | varchar(1)   | NO         | このフィールドのデフォルト値は`NULL`です  |
| ORACLE_MAINTAINED | varchar(1)   | NO         | このフィールドのデフォルト値は`NULL`です                              |
| APPLICATION       | varchar(1)   | NO         | このフィールドのデフォルト値は`NULL`です                             |
| DEFAULT_COLLATION | varchar(1)   | NO         | このフィールドのデフォルト値は`NULL`です                            |
| DUPLICATED        | varchar(1)   | NO         | このフィールドのデフォルト値は`NULL`です         |
| SHARDED           | varchar(1)   | NO         | このフィールドはデフォルトで `NULL` です                             |
| IMPORTED_OBJECT   | varchar(1)   | NO         | このフィールドはデフォルトで `NULL` です                            |
| CREATED_APPID     | bigint(0)    | NO         | このフィールドはデフォルトで `NULL` です      |
| CREATED_VSNID     | bigint(0)    | NO         | このフィールドはデフォルトで `NULL` です           |
| MODIFIED_APPID    | bigint(0)    | NO         | このフィールドはデフォルトで `NULL` です     |
| MODIFIED_VSNID    | bigint(0)    | NO         | このフィールドはデフォルトで `NULL` です      |
