# information_schema.SESSION_VARIABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのSession変数（「_」で始まる隠れた変数を含む）の情報を記録します。

## フィールドの説明

|    **フィールド名**    |    **タイプ**     | **NULLを許容するか** |   **説明**    |
|----------------|---------------|----------------|-------------|
| VARIABLE_NAME  | varchar(128)  | NO             | セッション変数名 |
| VARIABLE_VALUE | varchar(1024) | YES            | セッション変数値 |

## クエリ例

Session変数`ob_trx_timeout`の値を確認します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SESSION_VARIABLES WHERE VARIABLE_NAME='ob_trx_timeout';
```

クエリ結果は次のとおりです：

```shell
+----------------+----------------+
| VARIABLE_NAME  | VARIABLE_VALUE |
+----------------+----------------+
| ob_trx_timeout | 86400000000    |
+----------------+----------------+
1 row in set
```
