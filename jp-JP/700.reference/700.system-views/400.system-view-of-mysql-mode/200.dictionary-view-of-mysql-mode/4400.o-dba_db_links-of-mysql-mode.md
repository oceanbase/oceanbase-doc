# oceanbase.DBA_DB_LINKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで作成されたすべてのDBLinkを表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | このDBLINKを作成したユーザー名 |
| DB_LINK | varchar(128) | NO | DBLINK名 |
| USERNAME | varchar(128) | NO | DBLINKがリモートデータベースに接続するために使用するユーザー名 |
| CREDENTIAL_NAME | varchar(128) | NO | リモートデータベースへの接続に使用されるCredentials名。互換性のみのために使用されます |
| CREDENTIAL_OWNER | varchar(128) | NO | リモートデータベースへの接続に使用されるCredentials所有者。互換性のみのために使用されます |
| HOST | text | YES | DBLINKがリモートデータベースに接続するホスト名(IPアドレス) |
| CREATED | datetime | NO | DBLINKの作成日時 |
| HIDDEN | varchar(3) | NO | 内部使用フィールド。互換性のみのために使用されます |
| SHARD_INTERNAL | varchar(3) | NO | DBLINKが共有接続をサポートするかどうかを示すために使用されます。ローカルデータベースとリモートデータベース間の接続数を削減するために使用されます。互換性のみのために使用されます |
| VALID | varchar(3) | NO | DBLINKが利用可能かどうかを示すために使用されます。互換性のみのために使用され、デフォルトはYESです |
| INTRA_CDB | varchar(3) | NO | 内部使用フィールド。互換性のみのために使用されます |
| TENANT_NAME | varchar(128) | NO | DBLINKがリモートデータベースに接続するために使用するテナント名 |
| DATABASE_NAME | varchar(128) | YES | DBLINKがリモートの指定されたデータベースに接続するために使用するデータベース名 |
| REVERSE_TENANT_NAME | varchar(128) | YES | 反方向DBLINKがローカルデータベースに接続するために使用するテナント名 |
| CLUSTER_NAME | varchar(128) | YES | DBLINKがリモートデータベースに接続するために使用するクラスタ名 |
| REVERSE_CLUSTER_NAME | varchar(128) | YES | 反方向DBLINKがローカル側データベースに接続するために使用するクラスタ名 |
| REVERSE_HOST | text | YES | 反方向DBLINKがローカル側データベースに接続するホスト名(IPアドレス) |
| REVERSE_PORT |  bigint(20) | YES | 反方向DBLINKがローカル側データベースに接続するポート番号 |
| REVERSE_USERNAME | VARCHAR2(128) | YES | 反方向DBLINKがローカル側データベースに接続するユーザー名 |
