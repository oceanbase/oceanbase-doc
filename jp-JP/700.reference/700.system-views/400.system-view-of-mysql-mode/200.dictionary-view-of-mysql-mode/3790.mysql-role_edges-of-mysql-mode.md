# mysql.role_edges

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`mysql.role_edges`は、ロールとユーザー間の権限付与関係を表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | -------- |
| FROM_HOST         | varchar(255) | NO   | 権限が付与されたRoleアカウントのホスト名     |
| FROM_USER         | varchar(128) | NO   | 権限が付与されたRoleアカウント名     |
| TO_HOST           | varchar(255) | NO   | 受領者アカウントのホスト名     |
| TO_USER           | varchar(128) | NO   | 受領者アカウント名     |
| WITH_ADMIN_OPTION | varchar(1)   | NO   | 権限を付与されたRoleの権限にADMIN権限オプションが含まれるかどうか     |

## クエリ例

Role `role1`とユーザー`user001`間の権限付与関係を照会します。

1. Role `role1`を作成します。

   ```shell
   obclient [oceanbase]> CREATE ROLE IF NOT EXISTS role1;
   Query OK, 0 rows affected, 1 warning
   ```

2. `ALTER SYSTEM`権限をRole `role1`に付与します。

   ```shell
   obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
   ```

3. ユーザー`user001`を作成します。

   ```shell
   obclient [oceanbase]> CREATE USER 'user001'@'%' IDENTIFIED BY '******';
   ```

4. Role `role1`を新しく作成したユーザー`user001`に付与します。

   ```shell
   obclient [oceanbase]>GRANT role001 TO user001 WITH ADMIN OPTION;;
   ```

5. ロール `role1` とユーザー `user001` 間の付与関係を照会します。

   ```shell
   obclient > SELECT * FROM mysql.role_edges;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +-----------+-----------+---------+---------+-------------------+
   | FROM_HOST | FROM_USER | TO_HOST | TO_USER | WITH_ADMIN_OPTION |
   +-----------+-----------+---------+---------+-------------------+
   | %         | role001   | %       | user001 | Y                 |
   +-----------+-----------+---------+---------+-------------------+
   1 row in set
   ```
