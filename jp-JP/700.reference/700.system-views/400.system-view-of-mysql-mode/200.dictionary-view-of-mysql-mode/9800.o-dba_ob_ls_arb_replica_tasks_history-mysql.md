# oceanbase.DBA_OB_LS_ARB_REPLICA_TASK_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで実行されたアービトレーションサービスのタスク履歴を表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| TASK_ID | bigint(20) | NO | タスクID |
| EXECUTE_RESULT | varchar(2048) | NO | タスクの実行結果と実行時間。形式は「[ret:0; elapsed:72160;]」です。 |
| CREATE_TIME | datetime | NO | タスク生成時間 |
| FINISH_TIME | datetime | NO | タスク完了時間 |
| TRACE_ID | varchar(200) | NO | ログ内でこのタスクが実行されたtrace_id |
| TASK_TYPE | varchar(32) | NO |  タスクタイプ：<ul><li> `ADD REPLICA` はレプリカ追加タスクを指します。  </li><li> `REMOVE REPLICA` はレプリカ削除タスクを指します。</li></ul>|
| ARBITRATION_SERVICE | varchar(512) | NO | アービトレーションサービスのアドレス |
| ARBITRATION_SERVICE_TYPE | varchar(64) | NO | アービトレーションサービスのタイプ。現在は `ADDR` のみサポートしています |
| COMMENT | varchar(2048) | YES | タスクの説明 |
