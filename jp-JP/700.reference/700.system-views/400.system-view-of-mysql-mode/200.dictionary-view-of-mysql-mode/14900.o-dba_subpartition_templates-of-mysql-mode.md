# oceanbase.DBA_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのパーティションテーブルのテンプレート化されたサブパーティション情報を表示します。

## フィールド説明

|         フィールド名          |       型        | NULL許容   |    説明     |
|-----------------------|-----------------|------------|-----------|
| USER_NAME             | varchar(128)    | NO         | パーティションテーブルの所有者   |
| TABLE_NAME            | varchar(128)    | NO         | パーティション名      |
| SUBPARTITION_NAME     | varchar(132)    | NO         | サブパーティション名      |
| SUBPARTITION_POSITION | bigint(21)      | NO         | サブパーティションの位置     |
| TABLESPACE_NAME       | varchar(30)     | NO         | パーティションが属するテーブルスペース名 |
| HIGH_BOUND            | mediumtext | NO         | パーティションのテンプレート式   |
| COMPRESSION           | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内の各新規作成コンポジットパーティションにおいて、そのサブパーティションデータを圧縮形式で保存するかどうかを示します。<li>YES<li>NO <br>この値はサブパーティションテンプレート内で指定できます        |
| INDEXING              | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内の各新規作成コンポジットパーティションにおいて、そのサブパーティションデータを部分的インデックスとして扱うかどうかを示します。<li>ON<li>OFF<br>この値はサブパーティションテンプレート内で指定できます          |
| READ_ONLY             | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内の各新規作成コンポジットパーティションにおいて、そのサブパーティションデータを読み取り専用とするかどうかを示します。<li>YES<li>NO<br>この値はサブパーティションテンプレート内で指定できます          |

## クエリ例

ユーザーテナントが自身のテナントに属するパーティションテーブルのテンプレート化されたサブパーティション情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPARTITION_TEMPLATES;
```
