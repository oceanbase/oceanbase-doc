# oceanbase.DBA_OB_RECOVER_TABLE_JOB_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのテーブルレベル復元タスクの結果を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | ジョブID |
| INITIATOR_TENANT_ID | bigint(20) | NO | 親ジョブのテナントID |
| INITIATOR_JOB_ID | bigint(20) | NO | 親ジョブが属するJOB ID |
| START_TIMESTAMP | timestamp(6) | NO | ジョブ開始時のテナントの現在時刻 |
| FINISH_TIMESTAMP | timestamp(6) | NO | ジョブ完了時のテナントの現在時刻 |
| STATUS | varchar(64) | NO | ジョブのステータス。<ul><li>COMPLETED：ジョブ完了 </li><li>FAILED：ジョブ失敗 </li></ul> |
| AUX_TENANT_NAME | varchar(64) | NO | 補助テナント名 |
| TARGET_TENANT_NAME | varchar(64) | NO | 対象テナント名 |
| IMPORT_ALL | tinyint(4) | NO | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが`RECOVER TABLE *.*`を指定した場合にのみ、この値は1となり、その他のシナリオでは値は0となる |
| DB_LIST | longtext | YES | 完全に復元するデータベース |
| TABLE_LIST | longtext | YES | 復元するテーブル |
| RESTORE_SCN | bigint(20) unsigned | NO | ユーザーが指定した復元ポイント |
| RESTORE_SCN_DISPLAY | datetime(6) | NO | ユーザーが指定した復元ポイントのタイムスタンプ表現 |
| RESTORE_OPTION | varchar(4096) | NO | 補助テナントが依存するrestore_optionパラメータ |
| BACKUP_DEST | varchar(4096) | NO | バックアップおよびアーカイブのパス |
| BACKUP_SET_LIST | longtext | NO | データバックアップのパス |
| BACKUP_PIECE_LIST | longtext | NO | ログアーカイブのパス |
| BACKUP_PASSWD | varchar(4096) | YES | バックアップセットのパスワード |
| EXTERNAL_KMS_INFO | varchar(4096) | YES | ソーステナントでキーマネージメントが設定されている場合は、セッションでこの項目を設定する必要があります。 |
| REMAP_DB_LIST | longtext | YES | 名前を変更するデータベース。形式は次のとおりです：db1:new_db1, db2:newdb2 |
| REMAP_TABLE_LIST | longtext | YES | 名前を変更するテーブル。形式は次のとおりです：db1.t1:new_t1, db1.t2:db2.new_t2 |
| REMAP_TABLEGROUP_LIST | longtext | YES | テーブルグループの再マッピングリスト。テーブルを元のテーブルグループから対象のテーブルグループに再マッピングできます。形式は次のとおりです：tg1:new_tg1, tg2:new_tg2 |
| REMAP_TABLESPACE_LIST | longtext | YES | テーブルスペースの再マッピングリスト。テーブルを元のテーブルスペースから対象のテーブルスペースに再マッピングできます。形式は次のとおりです：ts1:new_ts1, ts2:new_ts2 |
| RESULT | varchar(64) | YES | テーブルレベルの復元タスクの結果：<ul><li>SUCCESS  </li><li>FAIL </li></ul> |
| COMMENT | longtext | YES | 備考情報 |
| DESCRIPTION | longtext | YES | 復元コマンドで指定されたDESCRIPTION情報 |
