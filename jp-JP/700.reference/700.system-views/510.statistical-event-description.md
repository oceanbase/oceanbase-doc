# モニタリング項目一覧

OceanBaseデータベースおよびそのクラスタ、テナント、ホストなど、すべてのコアコンポーネントに関する主要なモニタリング指標を網羅しています。

## モニタリング項目のクエリ

システムテナントではSQLステートメントを使用して、すべてのモニタリング項目の定義情報をクエリできます。例：

```shell
obclient> SELECT STAT_ID, CLASS, NAME FROM V$STATNAME;
```

多くのモニタリング項目は内部実装に関連付けられているため、変更または削除される可能性があります。詳細は実際の状況によります。具体的なモニタリング項目のカテゴリに関するクエリについては、[モニタリング項目](../../600.manage/700.monitor/200.monitor-items-introduction/100.system-monitor/200.monitor-items.md)を参照してください。

## モニタリング項目のカテゴリ

OceanBaseデータベースV4.xバージョンでサポートされているモニタリング項目は、15の大カテゴリ、600以上のモニタリング項目があり、ネットワーク、リクエストキュー、トランザクション、SQL、キャッシュ、ストレージ、リソースクォータ、ログなど、すべての重要な実行情報を網羅しています。具体的な分類は以下のとおりです：

| 1             | NETWORK    | ネットワーク           |

| 4             | TRANS      | トランザクション           |
