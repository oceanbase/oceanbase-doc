# モニタリング項目一覧

OceanBaseデータベースおよびそのクラスタ、テナント、ホストなど、すべてのコアコンポーネントに関する重要なモニタリング指標を網羅しています。

## モニタリング項目の確認方法

システムテナントで次のSQL文を実行すると、すべてのモニタリング項目の定義を確認できます。

```shell
obclient> SELECT STAT_ID, CLASS, NAME FROM V$STATNAME;
```

多くのモニタリング項目は内部実装に依存し、変更または削除されることがあります。利用できる項目は実際の環境で確認してください。カテゴリ別の確認方法については、[モニタリング項目](../../600.manage/700.monitor/200.monitor-items-introduction/100.system-monitor/200.monitor-items.md)を参照してください。

## モニタリング項目のカテゴリ

OceanBaseデータベース V4.xでは、600を超えるモニタリング項目を15のカテゴリに分類しています。ネットワーク、リクエストキュー、トランザクション、SQL、キャッシュ、ストレージ、リソースクォータ、ログなど、データベースの稼働状況を確認できます。

| ------------- | ---------- | -------------- |
| 1             | NETWORK    | ネットワーク           |
