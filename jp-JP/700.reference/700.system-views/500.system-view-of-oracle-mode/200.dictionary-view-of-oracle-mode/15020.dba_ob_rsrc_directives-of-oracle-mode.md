# DBA_OB_RSRC_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

リソースマネージャ内のテナントにおける各種リソース設定パラメータ情報を表示します。

## フィールドの説明

|           フィールド名            |      型       | NULL許容 |         説明         |
|------------------------------|-----------------|----------------|-----------------------|
| PLAN                         | VARCHAR2(128)   | NO             | リソースプランの内容が属するリソースプラン名    |
| GROUP_OR_SUBPLAN             | VARCHAR2(128)   | NO             | リソースプランの内容が制御するリソースグループ名     |
| COMMENTS                     | VARCHAR2(2000)  | YES            | リソースプランの内容に対応するコメント    |
| MGMT_P1                      | NUMBER(38)      | NO             | システムがフル負荷の場合の相対的に利用可能な最大CPU占有率。デフォルト値は`100`    |
| UTILIZATION_LIMIT            | NUMBER(38)      | NO             | リソースグループが使用するCPUリソースがテナントのCPU総リソースに占める割合の上限。デフォルト値は`100`で、テナントの全CPUリソースを使用できることを意味します   |
| MIN_IOPS                     | NUMBER(38)      | NO             | I/O競合が発生した場合にリソースグループが予約するIOPSリソース。すべてのリソースグループで指定された`MIN_IOPS`の合計は100を超えてはならず、デフォルト値は`0`     |
| MAX_IOPS                     | NUMBER(38)      | NO             | リソースグループが使用できる最大IOPSリソース。すべてのリソースグループで指定された`MAX_IOPS`の合計は100を超えてもかまいませんが、デフォルト値は`100`     |
| WEIGHT_IOPS                  | NUMBER(38)      | NO             | I/Oリソース競合が発生した場合のIOPSの重み値。すべてのリソースグループで指定された`WEIGHT_IOPS`の合計は100を超えてもかまいませんが、`MIN_IOPS`、`MAX_IOPS`の設定を満たす前提で、I/Oリソースは重みの正規化値に従って割り当てられます。デフォルト値は`0`     |
| MAX_NET_bandWIDTH            | NUMBER(38)      | NO             | リソースグループが使用するネットワーク帯域幅の上限。すべてのリソースグループで指定された`MAX_NET_BANDWIDTH`の合計は100を超えてもかまいませんが、デフォルト値は`100`     |
| NET_BANDWIDTH_WEIGHT         | NUMBER(38)      | NO             | ネットワークリソース競合が発生した場合の帯域幅の重み。すべてのリソースグループで指定された`NET_BANDWIDTH_WEIGHT`の合計は100を超えてもかまいませんが、`MAX_NET_BANDWIDTH`の設定を満たす前提で、ネットワーク帯域幅リソースは重みの正規化値に従って割り当てられます。デフォルト値は`0`      |

## クエリ例

SN（Shared-Nothing）モードで、ユーザーテナントがリソースマネージャ内の自身のテナントにおける各種リソース設定パラメータ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_RSRC_DIRECTIVES;
```

クエリ結果は次のとおりです：

```shell
+--------+------------------+-----------+---------+-------------------+----------+----------+-------------+-------------------+----------------------+
| PLAN   | GROUP_OR_SUBPLAN | COMMENTS  | MGMT_P1 | UTILIZATION_LIMIT | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS | MAX_NET_BANDWIDTH | NET_BANDWIDTH_WEIGHT |
+--------+------------------+-----------+---------+-------------------+----------+----------+-------------+-------------------+----------------------+
| PLAN_A | BIG_GROUP        | new       |      40 |                60 |       20 |      100 |          10 |                60 |                   60 |
| PLAN_A | SMALL_GROUP      | AP 优先   |     100 |               100 |       10 |       90 |          30 |               100 |                    0 |
+--------+------------------+-----------+---------+-------------------+----------+----------+-------------+-------------------+----------------------+
2 rows in set
```
