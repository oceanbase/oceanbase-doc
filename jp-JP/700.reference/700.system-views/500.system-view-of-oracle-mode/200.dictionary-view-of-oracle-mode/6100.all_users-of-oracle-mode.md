# ALL_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが可視できるすべてのデータベースユーザーを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
|----------|--------------|----------------|---------|
| USERNAME | VARCHAR2(30) | NO | ユーザー名 |
| USERID | NUMBER(38) | NO | ユーザーID |
| CREATED | DATE | NO | ユーザー作成時間 |
| COMMON | VARCHAR2(3) | NO | ユーザーがパブリックユーザーであるか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| ORACLE_MAINTAINED | VARCHAR2(1) | NO | ユーザーがOracleモードによって提供されるスクリプトによって作成および維持されているか<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| INHERITED | VARCHAR2(3) | NO | ユーザーが他のコンテナから継承されたか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| DEFAULT_COLLATION | VARCHAR2(100) | NO | デフォルトの文字セット <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| IMPLICIT | VARCHAR2(3) | NO | ユーザーが暗黙的アプリケーションによって作成されたか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| ALL_SHARD | VARCHAR2(3) | NO | シャーディングが有効な場合に作成されたか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
