# DBA_SEGMENTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのセグメントにおける物理ストレージの割り当て状況を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>
