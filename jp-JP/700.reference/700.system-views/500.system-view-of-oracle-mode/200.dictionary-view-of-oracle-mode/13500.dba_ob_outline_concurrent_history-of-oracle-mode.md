# DBA_OB_OUTLINE_CONCURRENT_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントの実行計画とレートリミットルールのアウトライン履歴情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | TIMESTAMP(6) | NO | 作成タイムスタンプ |
| MODIFY_TIME | TIMESTAMP(6) | NO | 変更タイムスタンプ |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| DATABASE_ID | NUMBER(38) | YES | データベースID |
| OUTLINE_ID | NUMBER(38) | NO | アウトラインID |
| OUTLINE_NAME | VARCHAR2(128) | YES | アウトライン名 |
| SQL_TEXT | CLOB | YES | アウトライン作成時にon句で指定されたSQL |
| OUTLINE_PARAMS | VARBINARY(65536) | YES | アウトライン作成時の関連する制限ルールパラメータ |
| OUTLINE_TARGET | CLOB | YES | アウトライン作成時にto句で指定されたSQL |
| SQL_ID | VARCHAR2(32) | YES | SQL識別子 |
| OUTLINE_CONTENT | CLOB | YES | 完全なアウトライン情報 |
| IS_deleted | VARCHAR2(3) | NO | 削除されているか |
| ENABLED | VARCHAR2(3) | NO | 有効か |
