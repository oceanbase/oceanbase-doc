# DBA_OB_LOG_RESTORE_SOURCE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントのログ復元ソースを表示します。

## フィールドの説明

| **項目** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| ID | NUMBER(38) | NO | ログ復元ソース番号 |
| TYPE | VARCHAR2(32) | NO |ログ復元ソースタイプ <ul><li>`SERVICE`：ネットワーク直接接続のログ復元ソース  </li><li>`LOCATION`：アーカイブログのログ復元ソース </li><li>`RAWPATH`：ユーザー管理ログ復元ソース </li></ul> |
| VALUE | CLOB | NO | ログ復元ソースのエントリアドレス <ul><li>SERVICEタイプ：プライマリテナントのアクセスエントリ。例："IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,COMPATIBILITY_MODE=ORACLE,IS_ENCRYPTED=true"  </li><li>LOCATION：ログアーカイブディレクトリ。例："file:///data/1/archive/" </li><li>RAWPATH：ユーザー定義ディレクトリ </li></ul>|
| RECOVERY_UNTIL_SCN | NUMBER(38) | NO | ログ取得上限。INT64_MAXまたは0より大きい有限値を指定できます。 |

## クエリ例

ユーザーテナントが自身のログ復元ソースをクエリします。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LOG_RESTORE_SOURCE;
```

クエリ結果は次のとおりです：

```shell
+-----------+------+----------+----------------------------------------+---------------------+
| TENANT_ID | ID   | TYPE     | VALUE                                  | RECOVERY_UNTIL_SCN  |
+-----------+------+----------+----------------------------------------+---------------------+
|      1018 |    1 | LOCATION | file:///home/admin/oceanbase/arglogorc | 4611686018427387903 |
+-----------+------+----------+----------------------------------------+---------------------+
1 row in set
```
