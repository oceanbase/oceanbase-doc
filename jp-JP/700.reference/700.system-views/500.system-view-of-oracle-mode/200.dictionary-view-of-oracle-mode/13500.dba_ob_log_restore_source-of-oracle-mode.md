# DBA_OB_LOG_RESTORE_SOURCE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントのログ復元ソースを表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| ID | NUMBER(38) | NO | ログ復元ソース番号 |
| TYPE | VARCHAR2(32) | NO |ログ復元ソースタイプ <ul><li>`SERVICE`：ネットワーク直接接続ログ復元ソース  </li><li>`LOCATION`：アーカイブログ復元ソース </li><li>`RAWPATH`：ユーザー管理ログ復元ソース </li></ul> |
| VALUE | CLOB | NO | ログ復元ソースのエントリアドレス <ul><li>SERVICEタイプ：プライマリテナントのアクセスエントリ、例："IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,COMPATIBILITY_MODE=ORACLE,IS_ENCRYPTED=true"  </li><li>LOCATION：ログアーカイブディレクトリ、例："file:///data/1/archive/" </li><li>RAWPATH：ユーザー定義ディレクトリ </li></ul>|
| RECOVERY_UNTIL_SCN | NUMBER(38) | NO | ログ取得の上限。INT64_MAXまたは0より大きい有限値が指定できます |
| RECOVERY_DELAY      | NUMBER(38) | NO | テナントの同期遅延設定。単位はマイクロ秒です。デフォルト値は0で、遅延なしを意味します <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP2バージョンから導入されました。</p></main> |

## クエリ例

ユーザーテナントが自身のログ復元ソースを照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LOG_RESTORE_SOURCE;
```
