# DBA_AUDIT_EXISTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`AUDIT EXISTS` および `AUDIT NOT EXISTS` によって生成される監査トレースエントリを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## クエリ例

現在のテナントにおいて、`AUDIT EXISTS` および `AUDIT NOT EXISTS` によって生成されたすべての監査トレースエントリを確認します。

```shell
obclient [SYS]> SELECT USERNAME, USERHOST, TIMESTAMP, ACTION_NAME, SQL_TEXT FROM SYS.DBA_AUDIT_EXISTS;
```

クエリ結果は次のとおりです：

```shell
+----------+----------------+-----------+-------------+------------------------------------+
| USERNAME | USERHOST       | TIMESTAMP | ACTION_NAME | SQL_TEXT                           |
+----------+----------------+-----------+-------------+------------------------------------+
| TEST2    | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
| TEST2    | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
| TEST2    | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
+----------+----------------+-----------+-------------+------------------------------------+
3 rows in set
```
