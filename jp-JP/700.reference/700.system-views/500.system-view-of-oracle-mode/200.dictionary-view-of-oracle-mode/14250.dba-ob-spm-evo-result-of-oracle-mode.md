# DBA_OB_SPM_EVO_RESULT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPM計画進化情報を表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
|----------|----------|-----------------|----------|
| OWNER               | VARCHAR2(128)                     | YES  | エボリューションタスクを実行したユーザー。 |
| RECORD_TIME         | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | エボリューション結果を記録した時間。 |
| SVR_IP              | VARCHAR2(46)                      | NO   | エボリューションタスクを実行したサーバーのIPアドレス。 |
| SVR_PORT            | NUMBER(38)                        | NO   | エボリューションタスクを実行したサーバーのポート番号。 |
| SQL_ID              | VARCHAR2(32)                      | NO   | エボリューションタスクを実行したSQLのID。 |
| TYPE                | VARCHAR2(32)                      | NO   | 記録のタイプ：<ul><li>`OnlineEvolve`：オンラインエボリューションモードで記録されるのは、エボリューションタスクの結果です。以下のすべてのフィールドは、タイプがこの値の場合にのみ有効です。</li><li>`FirstBaseline`：最初のベースラインを生成するSQLを記録していることを示します。</li><li>`UnReproducible`：現在のSQLを再現できるベースラインがないことを示します。</li><li>`BaselineFirst`：ベースライン優先モードで新しい計画が生成されましたが、ベースライン計画を復元して使用したことを示します。</li></ul> |
| START_TIME          | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | エボリューションタスク開始時の時間。 |
| END_TIME            | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | エボリューションタスク終了時の時間。 |
| STATUS              | VARCHAR2(7)                       | YES  | エボリューションタスクの状態：<ul><li>`success`：エボリューションタスクが正常に終了しました。</li><li>`timeout`：エボリューションタスクがタイムアウトしました（この場合、エボリューション期間中の実行情報に基づいてどの計画がより良いかを判断します）。 |
| NEW_PLAN_BETTER     | NUMBER(38)                        | YES  | エボリューション計画がより優れているかどうか。 |
| EVO_PLAN_EXEC_COUNT | NUMBER(38)                        | YES  | エボリューション期間中のエボリューション計画の実行回数。 |
| EVO_PLAN_CPU_TIME   | NUMBER(38)                        | YES  | エボリューション期間中のエボリューション計画の平均CPUコスト。 |
| BASELINE_EXEC_COUNT | NUMBER(38)                        | YES  | エボリューション期間中のベースライン計画の実行回数。 |
| BASELINE_CPU_TIME   | NUMBER(38)                        | YES  | エボリューション期間中のベースライン計画の平均CPUコスト。 |
