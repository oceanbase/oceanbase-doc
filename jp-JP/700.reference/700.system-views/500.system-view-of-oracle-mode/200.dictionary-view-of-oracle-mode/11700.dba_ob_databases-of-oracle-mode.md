# DBA_OB_DATABASES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのデータベースメタ情報を表示します。

## フィールドの説明

|     フィールド名      |       タイプ       | NULL値を許容するか |             説明             |
|---------------|----------------|------------|----------------------------|
| DATABASE_NAME | VARCHAR2(128)  | NO         | データベース名                       |
| IN_RECYCLEBIN | VARCHAR2(3)    | NO         | データベースがゴミ箱にあるかどうか：<ul><li>YES</li><li>NO</li></ul> |
| COLLATION     | VARCHAR2(128)  | NO         | データベースのデフォルトCOLLATION            |
| READ_ONLY     | VARCHAR2(3)    | NO         | OCPが取得したデータベースの読み取り専用状態：<ul><li>YES：読み取り専用</li><li>NO：読み取り/書き込み可能</li></ul> |
| COMMENT       | VARCHAR2(2048) | NO         | データベースの説明                     |

## クエリ例

ユーザーテナントが自身のデータベースメタ情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_DATABASES;
```

クエリ結果は次のとおりです：

```shell

7 rows in set
```
