# USER_PROCEDURES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するすべての関数とプロシージャ、およびそれらの関連属性を表示します。列は `ALL_PROCEDURES` の列と同じですが、`OWNER` フィールドは除外されています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|    **フィールド名**    |    **型**     | **NULL許容** |                     **説明**                     |
|----------------|---------------|----------------|------------------------------------------------|
| OBJECT_NAME    | VARCHAR2(128) | YES            | パッケージ名                                             |
| PROCEDURE_NAME | VARCHAR2(128) | NO             | プロシージャまたは関数名                                        |
| OBJECT_ID      | NUMBER        | NO             | オブジェクトID                                          |
| SUBPROGRAM_ID  | NUMBER        | NO             | パッケージ内での出現順序、独立したプロシージャまたは関数の場合この値は1                     |
| OVERLOAD       | NUMBER        | NO             | パッケージソースファイル内でのオーバーロードの回数                                 |
| OBJECT_TYPE    | VARCHAR2(9)   | NO             | オブジェクトのタイプ                                          |
| AGGREGATE      | VARCHAR2(3)   | NO             | 現在このフィールドはサポートされていません。現在デフォルトはNO             |
| PIPELINED      | VARCHAR2(3)   | NO             | このプロシージャがパイプライン関数かどうかを示します                                  |
| IMPLTYPEOWNER  | VARCHAR2(30)  | NO             | 現在このフィールドはサポートされていません。現在デフォルトはNULL             |
| IMPLTYPENAME   | VARCHAR2(30)  | NO             | 現在このフィールドはサポートされていません。現在デフォルトはNULL                |
| PARALLEL       | VARCHAR2(3)   | NO             | プロシージャまたは機能が並列実行可能かどうかを示します                                |
| INTERFACE      | VARCHAR2(3)   | NO             | 現在このフィールドはサポートされていません。現在デフォルトはNULL |
| DETERMINISTIC  | VARCHAR2(3)   | NO             | このプロシージャ/機能が決定的であることを宣言しています                                 |
| AUTHID         | VARCHAR2(12)  | NO             | INVOKER/DEFINER                                |
| ORIGIN_CON_ID  | NUMBER(38)    | NO             | オブジェクトが属するテナントのテナントID。システムパッケージの場合、この値は0                        |
