# USER_CONSTRAINTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーが所有するすべてのテーブルの制約情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|     **フィールド名**      |     **タイプ**     | **NULL許容** |                      **説明**                      |
|-------------------|----------------|----------------|--------------------------------------------------|
| OWNER             | VARCHAR2(128)  | NO             | 制約の所有者                                           |
| CONSTRAINT_NAME   | VARCHAR2(128)  | NO             | 制約名                                             |
| CONSTRAINT_TYPE   | VARCHAR2(1)    | NO             | インデックスタイプ。現在はNORMALタイプのみサポートしています                             |
| TABLE_NAME        | VARCHAR2(128)  | NO             | 制約が存在するテーブル名                                        |
| SEARCH_CONDITION  | VARCHAR2(4000) | NO             | CHECK制約のsearch conditionのテキスト                    |
| R_OWNER           | VARCHAR2(128)  | NO             | 引用された制約の所有者                                        |
| R_CONSTRAINT_NAME | VARCHAR2(128)  | NO             | 引用された制約の名前                                         |
| DELETE_RULE       | VARCHAR2(9)    | NO             | 外部キー制約のカスケード削除ルール                                      |
| STATUS            | VARCHAR2(8)    | NO             | 制約がENABLEまたはDISABLEのどちらであるかを示します                          |
| DEFERRABLE        | VARCHAR2(14)   | NO             | 制約がDEFERRABLEまたはNOT DEFERRABLEであるかを示します               |
| DEFERRED          | VARCHAR2(9)    | NO             | 制約がDEFERREDまたはIMMEDIATEであるかを示します                      |
| VALIDATED         | VARCHAR2(13)   | NO             | 制約がVALIDATEDまたはNOT VALIDATEDであるかを示します |
| GENERATED         | VARCHAR2(14)   | NO             | 制約名がUSER NAMEかGENERATED NAMEかを示します             |
| BAD               | VARCHAR2(3)    | NO             | このフィールドは現在サポートされていません。デフォルトはNULLです                               |
| RELY              | VARCHAR2(4)    | NO             | 制約がRELY状態であるかどうかを示します                                  |
| LAST_CHANGE       | DATE           | NO             | 制約が最後にENABLEまたはDISABLEに変更された日時                   |
| INDEX_OWNER       | VARCHAR2(128)  | NO             | 制約上のインデックスの所有者                                        |
| INDEX_NAME        | VARCHAR2(128)  | NO             | 制約上のインデックス名                                         |
| INVALID           | VARCHAR2(7)    | NO             | 制約がINVALIDATE状態であるかどうかを示します                            |
| VIEW_RELATED      | VARCHAR2(14)   | NO             | 制約がビュー上に作成されているかどうかを示します                                     |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.USER_CONSTRAINTS\G
```
