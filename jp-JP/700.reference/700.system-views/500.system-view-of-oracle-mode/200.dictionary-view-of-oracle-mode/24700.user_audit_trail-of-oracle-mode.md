# USER_AUDIT_TRAIL

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーに関連する標準的な監査トレースエントリを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## クエリ例

現在のユーザーのすべての監査トレースエントリを表示します。

```shell
obclient [SYS]> SELECT USERNAME, USERHOST, TIMESTAMP, ACTION, SQL_TEXT FROM SYS.USER_AUDIT_TRAIL;
```

クエリ結果は次のとおりです：

```shell
+----------+----------------+-----------+--------+----------+
| USERNAME | USERHOST       | TIMESTAMP | ACTION | SQL_TEXT |
+----------+----------------+-----------+--------+----------+
| SYS      | 100.xx.xxx.xxx | 08-APR-25 |    100 | CONNECT  |
| SYS      | 100.xx.xxx.xxx | 08-APR-25 |    100 | CONNECT  |
| SYS      | 100.xx.xxx.xxx | 08-APR-25 |    100 | CONNECT  |
+----------+----------------+-----------+--------+----------+
3 rows in set
```
