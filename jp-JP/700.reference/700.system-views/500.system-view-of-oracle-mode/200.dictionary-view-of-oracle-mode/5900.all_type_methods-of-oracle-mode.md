# ALL_TYPE_METHODS

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースは、このビューをサポートしていません。</p>
  </main>

## 機能の概要

現在のユーザーがアクセスできるオブジェクトタイプを表示するメソッドです。

## フィールドの説明

|   **フィールド名**   |    **タイプ**    | **NULLを許容するか** |                                                                                 **説明**                                                                                  |
|--------------|--------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER        | VARCHAR2(30) | NO             | タイプの所有者                                                                               |
| TYPE_NAME    | VARCHAR2(30) | NO             | タイプの名前                                                                                |
| METHOD_NAME  | VARCHAR2(30) | NO             | メソッドの名前                                                                                |
| METHOD_NO    | NUMBER       | NO             | メソッド番号。オーバーロードされたメソッドを区別するために使用されます                                                                        |
| METHOD_TYPE  | VARCHAR2(6)  | NO             | メソッドタイプ：<ul><li> MAP  </li><li> ORDER </li><li>PUBLIC </li></ul>   |
| PARAMETERS   | NUMBER       | NO             | メソッドパラメータの数                                                                              |
| RESULTS      | NUMBER       | NO             | メソッドが返す結果の数                                                                            |
| FINAL        | VARCHAR2(3)  | NO             | このメソッドがFINALであるかどうかを示します。<ul><li> YES  </li><li> NO </li></ul>           |
| INSTANTIABLE | VARCHAR2(3)  | NO             | このメソッドがインスタンス化可能であるかどうかを示します。<ul><li> YES   </li><li> NO  </li></ul>                                  |
| OVERRIDING   | VARCHAR2(3)  | NO             | このメソッドがスーパータイプのメソッドをオーバーライドしているかどうかを示します。<ul><li> YES  </li><li> NO </li></ul>                            |
| INHERITED    | VARCHAR2(3)  | NO             | このメソッドがスーパータイプから継承されているかどうかを示します： <ul><li> YES  </li><li> NO  </li></ul>                            |
