# DBA_PART_INDEXES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのパーティションインデックスのパーティション情報を表示します。

## フィールド説明

|           フィールド名            |       型       | NULL許容 |  説明  |
|---------------------------|----------------|------------|--------------------------------|
| OWNER                     | VARCHAR2(128)  | NO         | パーティションインデックス所有者              |
| INDEX_NAME                | VARCHAR2(128)  | NO         | パーティションインデックスの名前         |
| TABLE_NAME                | VARCHAR2(128)  | NO         | インデックス関連テーブル名             |
| PARTITIONING_TYPE         | VARCHAR2(9)    | NO         | パーティショニング方式：<ul><li>HASH </li><li>RANGE </li><li> LIST </li></ul>       |
| SUBPARTITIONING_TYPE      | VARCHAR2(9)    | NO         | サブパーティションのパーティショニング方式：<ul><li>HASH </li><li> RANGE  </li><li>LIST </li></ul>   |
| PARTITION_COUNT           | NUMBER         | NO         | インデックス内のパーティション数           |
| DEF_SUBPARTITION_COUNT    | NUMBER         | NO         | 複合パーティションインデックスの場合、サブパーティションの数（指定されている場合）        |
| PARTITIONING_KEY_COUNT    | NUMBER         | NO         | パーティションキーの列数                    |
| SUBPARTITIONING_KEY_COUNT | NUMBER         | NO         | 複合パーティションインデックスの場合、サブパーティションのパーティションキー数       |
| LOCALITY                  | VARCHAR2(6)    | NO         | パーティションインデックスがローカル（LOCAL）かグローバル（GLOBAL）か          |
| ALIGNMENT                 | VARCHAR2(12)   | NO         | パーティションインデックスがプレフィックス付き（PREFIXED）かプレフィックスなし（NON_PREFIXED）か       |
| DEF_TABLESPACE_NAME       | VARCHAR2(30)   | NO         | ローカルインデックスの場合、テーブルパーティションの追加または分割時のデフォルトテーブル領域           |
| DEF_PCT_FREE              | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です          |
| DEF_INI_TRANS             | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です              |
| DEF_MAX_TRANS             | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です                |
| DEF_INITIAL_EXTENT        | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです             |
| DEF_NEXT_EXTENT           | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです          |
| DEF_MIN_EXTENTS           | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです            |
| DEF_MAX_EXTENTS           | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。       |
| DEF_MAX_SIZE              | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。       |
| DEF_PCT_INCREASE          | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。       |
| DEF_FREELISTS             | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です。         |
| DEF_FREELIST_GROUPS       | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は0です。            |
| DEF_LOGGING               | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。          |
| DEF_BUFFER_POOL           | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。           |
| DEF_flash_CACHE           | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。            |
| DEF_cell_FLASH_CACHE      | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。             |
| DEF_PARAMETERS            | VARCHAR2(1000) | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。                |
| INTERVAL                  | VARCHAR2(1000) | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値は`NO`です。           |
| AUTOLIST                  | VARCHAR2(3)    | NO         | ローカルインデックスが自動リストパーティションを使用するかどうかを示します。<ul><li>YES</li><li>NO</li></ul>        |
| INTERVAL_SUBPARTITION     | VARCHAR2(1000) | NO         | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。     |
| AUTOLIST_SUBPARTITION     | VARCHAR2(1000) | NO         | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。     |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_PART_INDEXES WHERE INDEX_NAME='TBL1_H_IDX1'\G
```
