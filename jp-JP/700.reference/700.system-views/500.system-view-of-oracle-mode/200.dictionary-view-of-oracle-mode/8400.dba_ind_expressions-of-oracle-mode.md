# DBA_IND_EXPRESSIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30から導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべての関数ベースインデックスの情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|     **フィールド名**      |     **タイプ**     | **NULL許容** |        **説明**        |
|-------------------|----------------|----------------|----------------------|
| INDEX_OWNER       | VARCHAR2(128)  | NO             | インデックス所有者             |
| INDEX_NAME        | VARCHAR2(128)  | NO             | インデックス名                 |
| TABLE_OWNER       | VARCHAR2(128)  | NO             | インデックスが存在するテーブルの所有者            |
| TABLE_NAME        | VARCHAR2(128)  | NO             | インデックスが存在するテーブル名             |
| COLUMN_EXPRESSION | VARCHAR2(1000) | NO             | 関数ベースインデックスの式 |
| COLUMN_POSITION   | NUMBER(38)     | NO             | 列がインデックス内における位置             |

## クエリ例

現在のテナント内のすべての関数インデックスの情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_IND_EXPRESSIONS;
```

クエリ結果は次のとおりです：

```shell
+-------------+----------------+-------------+------------+-------------------+-----------------+
| INDEX_OWNER | INDEX_NAME     | TABLE_OWNER | TABLE_NAME | COLUMN_EXPRESSION | COLUMN_POSITION |
+-------------+----------------+-------------+------------+-------------------+-----------------+
| SYS         | TBL2_FUNC_IDX1 | SYS         | TBL2_FUNC  | ("C1" + 1)        |               1 |
+-------------+----------------+-------------+------------+-------------------+-----------------+
1 row in set
```
