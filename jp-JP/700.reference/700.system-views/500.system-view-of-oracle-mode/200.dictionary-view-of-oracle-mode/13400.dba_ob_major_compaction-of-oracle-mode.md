# DBA_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのメジャーコンパクションのグローバル情報を表示します。

## フィールドの説明

|           フィールド名           |      タイプ      | NULLを許容するか |        説明         |
|--------------------------|--------------|------------|---------------------------------------------|
| FROZEN_SCN           | NUMBER(38)   | NO         | 最後のコンパクションのバージョン番号           |
| GLOBAL_BROADCAST_SCN | NUMBER(38)   | NO         | グローバルブロードキャストのコンパクションバージョン        |
| LAST_SCN             | NUMBER(38)   | NO         | 前回完了したコンパクションのバージョン      |
| LAST_FINISH_TIME         | NUMBER(38)   | NO         | 前回のコンパクション終了時間         |
| START_TIME               | NUMBER(38)   | NO         | コンパクション開始時間            |
| STATUS                   | VARCHAR2(10) | NO         | <ul><li>`IDLE`：コンパクション中ではありません   </li><li> `COMPACTING`：コンパクション中   </li><li> `CHECKSUM`：チェックサムの検証 </li></ul>   |
| IS_ERROR                 | VARCHAR2(3)  | NO         | <ul><li> `YES`：コンパクションプロセスにエラーが発生しました   </li><li> `NO`：コンパクションプロセスでエラーは報告されませんでした  </li></ul>    |
| IS_SUSPENDED             | VARCHAR2(3)  | NO         | <ul><li> `YES`：コンパクションが一時停止状態   </li><li> `NO`：コンパクションは一時停止されていません   </li></ul> |
| INFO                     | VARCHAR2(14) | NO         | コンパクション情報を表示します。例：コンパクション失敗の理由  |

## クエリ例

ユーザーテナントが自身のテナントのメジャーコンパクション情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_MAJOR_COMPACTION;
```

クエリ結果は次のとおりです：

```shell
+---------------------+----------------------+---------------------+------------------+------------------+--------+----------+--------------+------+
| FROZEN_SCN          | GLOBAL_BROADCAST_SCN | LAST_SCN            | LAST_FINISH_TIME | START_TIME       | STATUS | IS_ERROR | IS_SUSPENDED | INFO |
+---------------------+----------------------+---------------------+------------------+------------------+--------+----------+--------------+------+
| 1736359202149291000 |  1736359202149291000 | 1736359202149291000 | 1736359425486421 | 1736359202174093 | IDLE   | NO       | NO           | NULL |
+---------------------+----------------------+---------------------+------------------+------------------+--------+----------+--------------+------+
1 row in set
```
