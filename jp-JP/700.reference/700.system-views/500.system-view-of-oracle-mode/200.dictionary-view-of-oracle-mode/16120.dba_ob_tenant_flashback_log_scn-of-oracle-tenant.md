# DBA_OB_TENANT_flashBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_TENANT_flashBACK_LOG_SCN` は、テナント内で行われた各ログトリミングに関する情報を表示するために使用されます。

## フィールドの説明

| フィールド               | 型                              | NULL許容 | 説明                                       |
|-------------------|-----------------------------------|-------------|------------------------------------------|
| TENANT_ID         | NUMBER(38)                        | NO   | テナントID |
| TIMESTAMP         | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | クリエーション時間、単位はマイクロ秒 |
| SWITCHOVER_EPOCH  | NUMBER(38)                        | NO   | テナントロールが`NORMAL`状態に切り替わったときの`SWITCHOVER_EPOCH`。`SWITCHOVER_EPOCH`は、テナントロール切り替え（Switchover/Failover）操作を識別するための一意の識別子です |
| OP_TYPE           | VARCHAR2(64)                      | NO   | 操作タイプ。次のものが含まれます：<ul><li>`FAILOVER_TO_PRIMARY`：これはFailover操作のタイプで、プライマリテナントが利用不可な場合にスタンバイテナントをプライマリテナントに切り替える操作です。</li><li>`FLASHBACK_STANDBY_LOG`：これはスタンバイテナントのログトリミング操作のタイプで、スタンバイテナントのログを指定されたSCN位置までトリミングします。</li></ul> |
| FLASHBACK_LOG_SCN | NUMBER(38)                        | NO   | テナントログを後から前にトリミングする終点 |

## クエリ例

テナント内で行われた各ログトリミングに関する情報を照会します。

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```

実行結果は次のとおりです：

```shell
+-----------+----------------------------+------------------+---------------------+---------------------+
| TENANT_ID | TIMESTAMP                  | SWITCHOVER_EPOCH | OP_TYPE             | FLASHBACK_LOG_SCN   |
+-----------+----------------------------+------------------+---------------------+---------------------+
|      1006 |  21-MAY-25 16:48:53.583749 | 1747817333380437 | FAILOVER TO PRIMARY | 1747817331313513000 |
+-----------+----------------------------+------------------+---------------------+---------------------+
1 row in set
```
