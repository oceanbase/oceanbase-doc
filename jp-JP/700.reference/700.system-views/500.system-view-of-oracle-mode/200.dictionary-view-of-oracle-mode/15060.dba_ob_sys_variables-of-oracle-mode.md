# DBA_OB_SYS_VARIABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `DBA_OB_SYS_VARIABLES` は、現在のテナントのシステム変数（名前が「_」で始まる隠れた変数を含む）の設定を表示するために使用されます。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 作成日時 |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 変更日時 |
| NAME | VARCHAR2(128) | YES | システム変数名 |
| VALUE | VARCHAR2(65536) | YES | システム変数の現在値 |
| MIN_VALUE | VARCHAR2(65536) | YES | 最小値 |
| MAX_VALUE | VARCHAR2(65536) | YES | 最大値 |
| SCOPE | VARCHAR2(16) | NO | システム変数のスコープ |
| INFO | VARCHAR2(4096) | NO | 説明 |
| DEFAULT_VALUE | VARCHAR2(65536) | YES | システム変数のデフォルト値 |
| ISDEFAULT | VARCHAR2(3) | NO | デフォルト値かどうか |

## クエリ例

このテナントのシステム変数 `ob_query_timeout` の関連情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
```

クエリ結果は次のとおりです：

```shell
+------------------------------+------------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
| CREATE_TIME                  | MODIFY_TIME                  | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
+------------------------------+------------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
| 29-JUL-24 02.59.39.316063 PM | 29-JUL-24 02.59.39.316063 PM | ob_query_timeout | 10000000 | NULL      | NULL      | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | YES       |
+------------------------------+------------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
1 row in set
```
