# USER_MVIEW_LOGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`USER_MVIEW_LOGS`は、マテリアライズドビューのログ情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| LOG_OWNER | VARCHAR2(128) | YES | マテリアライズドビューのログ所有者名を表します |
| MASTER | VARCHAR2(128) | NO | マテリアライズドビューのログが属する主表の名前を表します |
| LOG_TABLE | VARCHAR2(128) | YES | マテリアライズドビューのログテーブル名を表します |
| LOG_TRIGGER | VARCHAR2(128) | YES | 主表の行をマテリアライズドビューのログに挿入するトリガーを表します<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| ROWIDS | VARCHAR2(3) | NO | Rowid情報を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| PRIMARY_KEY | VARCHAR2(3) | NO | 主キー情報を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| OBJECT_ID | VARCHAR2(3) | NO | オブジェクトテーブルにオブジェクト識別情報が記録されているかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNOです。</p></main> |
| FILTER_COLUMNS | VARCHAR2(3) | NO | フィルターカラム情報を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| SEQUENCE | VARCHAR2(3) | NO | 追加のソート情報を提供するシーケンス値を記録するかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| INCLUDE_NEW_VALUES | VARCHAR2(3) | NO | 古い値と新しい値を同時に記録するかどうかを表します<ul><li>YES：古い値と新しい値を同時に記録 </li><li>NO：古い値を記録するが新しい値は記録しない </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| PURGE_ASYNCHRONOUS | VARCHAR2(3) | NO | マテリアライズドビューのログが非同期でクリーンアップされるかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| PURGE_DEFERRED | VARCHAR2(3) | NO | マテリアライズドビューのログが遅延してクリーンアップされるかどうかを表します<ul><li> YES </li><li>NO </li></ul>|
| PURGE_START | DATE | YES | 遅延クリーンアップの開始日付を表します |
| PURGE_INTERVAL | VARCHAR2(200) | YES | 遅延クリーンアップのクリーンアップ時間間隔を表します |
| LAST_PURGE_DATE | DATE | YES | 最後にマテリアライズドビューのログをクリーンアップした日付を表します |
| LAST_PURGE_STATUS | NUMBER | NO | 最後にマテリアライズドビューのログをクリーンアップした状態を表します<ul><li>エラーコード  </li><li>0 ：成功 </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常に0です。</p></main> |
| NUM_ROWS_PURGED | NUMBER | YES | 最後にマテリアライズドビューのログをクリーンアップした際の削除行数を表します |
| COMMIT_SCN_BASED | VARCHAR2(3) | NO | マテリアライズドビューのログがコミットSCNに基づいているかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| STAGING_LOG | VARCHAR2(3) | NO | マテリアライズドビューのログが同期更新の一時ログであるかどうかを表します<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNOです。</p></main> |
| PURGE_DOP          | NUMBER(38)    | NO   | マテリアライズドビューのログをクリーンアップする並列度。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5バージョンでは、このフィールドはV4.3.5 BP2バージョンから導入されました。</p></main>|
| LAST_PURGE_TIME    | NUMBER(38)    | YES  | 前回のマテリアライズドビューのログクリーンアップタスクの実行時間を表します。単位は秒。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5バージョンでは、このフィールドはV4.3.5 BP2バージョンから導入されました。</p></main>|
