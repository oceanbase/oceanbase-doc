# DBA_OB_CONCURRENT_LIMIT_SQL

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのレート制限ルールのアウトラインに関する情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | TIMESTAMP(6) | NO | 作成タイムスタンプ |
| MODIFY_TIME | TIMESTAMP(6) | NO | 変更タイムスタンプ |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| DATABASE_ID | NUMBER(38) | NO | データベースID |
| OUTLINE_ID | NUMBER(38) | NO | スロットルルールのアウトラインID |
| DATABASE_NAME | VARCHAR2(128) | NO | データベース名 |
| OUTLINE_NAME | VARCHAR2(128) | NO | スロットルルールのアウトライン名 |
| OUTLINE_CONTENT | CLOB | NO | スロットルルールに対応するアウトライン内容。Emptyとすることができます |
| VISIBLE_SIGNATURE | CLOB | NO | Signatureの逆シリアライズ結果 |
| SQL_TEXT | CLOB | NO | スロットルルールのアウトラインを作成する際に、on句で指定されたSQL |
| CONCURRENT_NUM | NUMBER(38) | NO | 現在のSQL制限の並列数 |
| LIMIT_TARGET | CLOB | NO | スロットルされるSQL |
