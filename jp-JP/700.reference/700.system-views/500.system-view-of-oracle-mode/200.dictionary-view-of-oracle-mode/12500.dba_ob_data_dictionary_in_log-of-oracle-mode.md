# DBA_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

データディクショナリがシステムログストリーム内に配置される範囲を記録し、CDCがデータディクショナリを利用する際の利便性を高めます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SNAPSHOT_SCN | NUMBER(38) | NO | データディクショナリ生成時の対応テナントのSNAPSHOT SCN |
| REPORT_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | データディクショナリ生成完了後、内部テーブルに報告された時間（マイクロ秒単位） |
| START_LSN | NUMBER(38) | NO | テナントの1号ログストリームに永続化された最初のログのLSN |
| END_LSN | NUMBER(38) | NO | テナントの1号ログストリームに永続化された最後のログのLSN |

## クエリ例

本テナントのデータディクショナリがシステムログストリーム内に配置される範囲を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_DATA_DICTIONARY_IN_LOG;
```

クエリ結果は次のとおりです：

```shell
+---------------------+------------------------------+-----------+-----------+
| SNAPSHOT_SCN        | REPORT_TIME                  | START_LSN | END_LSN   |
+---------------------+------------------------------+-----------+-----------+
| 1723084155932969000 | 08-AUG-24 10.29.15.983581 AM |  16136726 |  16136726 |
| 1723170556335749000 | 09-AUG-24 10.29.16.366229 AM | 148555952 | 148555952 |
+---------------------+------------------------------+-----------+-----------+
2 rows in set
```
