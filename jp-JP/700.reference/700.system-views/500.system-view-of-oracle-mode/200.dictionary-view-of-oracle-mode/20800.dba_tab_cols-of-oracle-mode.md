# DBA_TAB_COLS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_TAB_COLS` は、データベース内のすべてのテーブルおよびビューのすべての列を表示します。

ビュー `DBA_TAB_COLS` と [DBA_TAB_COLUMNS](20900.dba_tab_columns-of-oracle-mode.md) の違いは、`DBA_TAB_COLS` がクイックデリートされた列も表示するのに対し、`DBA_TAB_COLUMNS` は表示しない点です。

<main id="notice" >
  <h4>適用対象</h4>
  <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>
