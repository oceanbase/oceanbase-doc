# ALL_COLL_TYPES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

データベースで利用可能なユーザー定義のコレクションタイプを一覧表示します。列は`DBA_COLL_TYPES`と同じです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|      **フィールド名**      |    **型**     | **NULL許容** |   **説明**    |
|--------------------|---------------|----------------|---------------------------------------------|
| OWNER              | VARCHAR2(128) | NO             | オブジェクトが属する所有者    |
| TYPE_NAME          | VARCHAR2(64)  | NO             | タイプ名         |
| COLL_TYPE          | VARCHAR2(10)  | NO             | コレクションタイプ：<ul><li>VARYING   </li><li> ARRAY   </li><li> NESTED TABLE</li></ul>    |
| UPPER_BOUND        | NUMBER(38)    | YES            | VARYINGの場合、コレクションの最大サイズを記録します                                                                           |
| ELEM_TYPE_MOD      | VARCHAR2(7)   | YES            | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです                                                                         |
| ELEM_TYPE_OWNER    | VARCHAR2(128) | YES            | コレクション要素タイプの所有者  |
| ELEM_TYPE_NAME     | VARCHAR2(324) | YES            | コレクション要素タイプ名     |
| LENGTH             | NUMBER(38)    | YES            | コレクション要素タイプの長さ    |
| NUMBER_PRECISION   | NUMBER(38)    | YES            | コレクション要素タイプの精度    |
| SCALE              | NUMBER(38)    | YES            | コレクション要素タイプの小数点以下のデータの長さ                                                                               |
| CHARACTER_SET_NAME | CHAR(7)       | YES            | コレクション要素タイプの文字セット   |
| ELEM_STORAGE       | CHAR(3)       | YES            | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです                                                                         |
| NULLS_STORED       | CHAR(1)       | YES            | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです                                                                         |
