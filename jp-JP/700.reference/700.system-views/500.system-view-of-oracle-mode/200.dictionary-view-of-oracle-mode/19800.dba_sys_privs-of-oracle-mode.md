# DBA_SYS_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーとロールに付与されたシステム権限を説明します。このビューには`USERNAME`列は表示されません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULLを許容するか** |      **説明**      |
|--------------|---------------|----------------|------------------|
| GRANTEE      | VARCHAR2(128) | NO             | 権限を付与される被付与者の名前、ユーザーまたはロール |
| PRIVILEGE    | VARCHAR2(40)  | NO             | 付与されるシステム権限             |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | 管理オプションを付与するかどうか           |

## クエリ例

`DBA`ロールに付与されたシステム権限を確認し、上位5件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM DBA_SYS_PRIVS WHERE GRANTEE='DBA' AND ROWNUM <=5;
```

クエリ結果は次のとおりです：

```shell
+---------+------------------+--------------+
| GRANTEE | PRIVILEGE        | ADMIN_OPTION |
+---------+------------------+--------------+
| DBA     | CREATE SESSION   | YES          |
| DBA     | CREATE TABLE     | YES          |
| DBA     | CREATE ANY TABLE | YES          |
| DBA     | ALTER ANY TABLE  | YES          |
| DBA     | BACKUP ANY TABLE | YES          |
+---------+------------------+--------------+
5 rows in set
```
