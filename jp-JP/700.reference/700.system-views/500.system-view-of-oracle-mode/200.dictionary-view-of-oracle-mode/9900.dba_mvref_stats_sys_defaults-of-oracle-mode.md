# DBA_MVREF_STATS_SYS_DEFAULTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_MVREF_STATS_SYS_DEFAULTS`は、マテリアライズドビューのリフレッシュ履歴統計プロパティのシステム範囲デフォルト値を参照するために使用されます。

## フィールドの説明

| **項目名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| PARAMETER_NAME | CHAR(16) | NO | パラメータ名。<ul><li>COLLECTION_LEVEL：データ収集のレベルまたは詳細度。</li><li>RETENTION_PERIOD：データ保持期間。</li></ul>|
| VALUE | VARCHAR2(40) | NO | パラメータのシステム範囲のデフォルト値 |

## クエリ例

マテリアライズドビューのリフレッシュ履歴統計プロパティのシステム範囲デフォルト値を照会します。

```shell
obclient [test_db]> SELECT * FROM SYS.DBA_MVREF_STATS_SYS_DEFAULTS;
```

クエリ結果は次のとおりです：

```shell
+------------------+---------+
| PARAMETER_NAME   | VALUE   |
+------------------+---------+
| COLLECTION_LEVEL | TYPICAL |
| RETENTION_PERIOD | 31      |
+------------------+---------+
2 rows in set (0.007 sec)
```
