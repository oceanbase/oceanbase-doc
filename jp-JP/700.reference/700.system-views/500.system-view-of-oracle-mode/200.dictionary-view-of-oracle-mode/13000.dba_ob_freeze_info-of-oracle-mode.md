# DBA_OB_FREEZE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のメジャーコンパクション(major_freeze)によって生成されたバージョン情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| FROZEN_SCN | NUMBER(38) | NO | major_freezeで生成されたメジャーコンパクションのバージョン番号 |
| CLUSTER_VERSION | NUMBER(38) | NO | major_freeze時の現在のクラスターバージョン番号 |
| SCHEMA_VERSION | NUMBER(38) | NO | major_freeze時の現在のスキーマバージョン番号 |
| GMT_CREATE | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 作成日時を記録 |
| GMT_MODIFIED | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 最終変更日時を記録 |

## クエリ例

ユーザーテナントが自身のテナントで発生したメジャーコンパクションによるバージョン情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_FREEZE_INFO;
```
