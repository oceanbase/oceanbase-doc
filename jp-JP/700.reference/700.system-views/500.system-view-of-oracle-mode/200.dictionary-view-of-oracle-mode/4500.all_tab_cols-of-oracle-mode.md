# ALL_TAB_COLS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `ALL_TAB_COLS` は、現在のユーザーがアクセスできるテーブルおよびビューのすべての列を表示します。

ビュー `ALL_TAB_COLS` と[ALL_TAB_COLUMNS](4600.all_tab_columns-of-oracle-mode.md) の違いは、`ALL_TAB_COLS` はクイックデリートされた列を表示するのに対し、`ALL_TAB_COLUMNS` はクイックデリートされた列を表示しないことです。

<main id="notice" >
  <h4>適用対象</h4>
  <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
</main>
