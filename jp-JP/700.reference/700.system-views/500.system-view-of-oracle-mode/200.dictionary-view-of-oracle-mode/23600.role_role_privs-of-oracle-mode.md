# ROLE_ROLE_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

他のロールに付与されたロールを記述します。ユーザーがアクセスできるロールに関する情報のみを提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULL値を許容** |       **説明**       |
|--------------|---------------|------------|--------------------|
| ROLE         | VARCHAR2(128) | NO         | ロール名               |
| GRANTED_ROLE | VARCHAR2(128) | NO         | 授与されたロール              |
| ADMIN_OPTION | VARCHAR2(3)   | NO         | このロールにADMINオプションが付与されているかどうか |

## クエリ例

現在のユーザーがアクセスできるロールのうち、ロール`ROLE1`に付与されているロールを確認します。

```shell
obclient [SYS]> SELECT * FROM ROLE_ROLE_PRIVS WHERE ROLE = 'ROLE1';
```

クエリ結果は次のとおりです：

```shell
+-------+--------------+--------------+
| ROLE  | GRANTED_ROLE | ADMIN_OPTION |
+-------+--------------+--------------+
| ROLE1 | ROLE2        | NO           |
+-------+--------------+--------------+
1 row in set
```
