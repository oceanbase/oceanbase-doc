# DBA_COL_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

データベース内で付与されたすべての列オブジェクトに関する権限を説明します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanbaseデータベースのOracleモードは、現在列権限機能をサポートしていません。</p>
</main>

## フィールドの説明

|  **フィールド名**   |    **型**     | **NULL許容** |    **説明**     |
|-------------|---------------|----------------|---------------|
| GRANTEE     | VARCHAR2(128) | NO             | 権限が付与されたユーザー名 |
| OWNER       | VARCHAR2(128) | NO             | オブジェクト所有者        |
| TABLE_NAME  | VARCHAR2(256) | NO             | オブジェクト名         |
| COLUMN_NAME | VARCHAR2(128) | NO             | 列名          |
| GRANTOR     | VARCHAR2(128) | NO             | 権限を付与したユーザー名    |
| PRIVILEGE   | VARCHAR2(40)  | NO             | 列に対する権限         |
| GRANTABLE   | VARCHAR2(3)   | NO             | 割り当てオプションの使用を示す    |
