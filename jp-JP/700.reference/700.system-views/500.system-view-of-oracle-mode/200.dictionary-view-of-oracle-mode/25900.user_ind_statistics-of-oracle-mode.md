# USER_IND_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するテーブルのインデックスに関するオプティマイザー統計情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| INDEX_NAME | VARCHAR2(128) | NO | インデックス名 |
| TABLE_OWNER | VARCHAR2(128) | NO | インデックスオブジェクトの所有者 |
| TABLE_NAME | VARCHAR2(128) | NO | インデックスオブジェクトの名前 |
| PARTITION_NAME | VARCHAR2(128) | NO | パーティション名 |
| PARTITION_POSITION | NUMBER | NO | インデックス内のパーティションの位置 |
| SUBPARTITION_NAME | VARCHAR2(128) | NO | サブパーティション名 |
| SUBPARTITION_POSITION | NUMBER | NO | パーティション内のサブパーティションの位置 |
| OBJECT_TYPE | VARCHAR2(12) | NO | オブジェクトタイプ：<ul><li>INDEX</li><li>PARTITION</li><li>SUBPARTITION </li></ul> |
| BLEVEL             | NUMBER | NO | このフィールドはデフォルトでNULLです |
| LEAF_BLOCKS        | NUMBER | NO | このフィールドはデフォルトでNULLです |
| DISTINCT_KEYS      | NUMBER | NO | このフィールドはデフォルトでNULLです |
| AVG_LEAF_BLOCKS_PER_KEY | NUMBER | NO | このフィールドはデフォルトでNULLです |
| AVG_DATA_BLOCKS_PER_KEY | NUMBER | NO | このフィールドはデフォルトでNULLです |
| CLUSTERING_FACTOR       | NUMBER | NO | このフィールドはデフォルトでNULLです |
| NUM_ROWS                | NUMBER | NO | インデックス内の行数 |
| AVG_CACHED_BLOCKS       | NUMBER | NO | このフィールドはデフォルトでNULLです |
| AVG_CACHE_hit_RATIO     | NUMBER | NO | このフィールドはデフォルトでNULLです |
| SAMPLE_SIZE             | NUMBER | NO | このフィールドはデフォルトでNULLです |
| LAST_ANALYZED           | DATE   | NO | 最後にインデックスを分析した日付 |
| GLOBAL_STATS            | VARCHAR2(3) | NO | 統計情報が収集または増分メンテナンスされたかどうかを示します。<ul><li>YES</li><li>NO </li></ul> |
| USER_STATS              | VARCHAR2(3) | NO | 統計情報がユーザーによって直接入力されたかどうかを示します。<ul><li>YES</li><li>NO </li></ul>|
| STATTYPE_LOCKED         | VARCHAR2(5) | NO | 統計ロックタイプ |
| STALE_STATS             | VARCHAR2(3) | NO | オブジェクトの統計情報が古いかどうか |
| SCOPE                   | VARCHAR2(7) | NO | このフィールドはデフォルトでNULLです |
