# DBA_AUDIT_OBJECT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_AUDIT_OBJECT` は、データベース内のすべてのオブジェクトに関する監査追跡レコードを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## クエリ例

現在のテナント内のすべてのオブジェクトに関する監査追跡エントリを確認します。

```shell
obclient [SYS]> SELECT USERNAME, USERHOST, TIMESTAMP, ACTION_NAME, SQL_TEXT FROM SYS.DBA_AUDIT_OBJECT;
```

クエリ結果は次のとおりです：

```shell
+------------+----------------+-----------+-------------+------------------------------------+
| USERNAME   | USERHOST       | TIMESTAMP | ACTION_NAME | SQL_TEXT                           |
+------------+----------------+-----------+-------------+------------------------------------+
| TEST2      | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
| TEST2      | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
| TEST2      | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM SYS.DBA_AUDIT_EXISTS |
| ORAAUDITOR | 100.xx.xxx.xxx | 08-APR-25 | SELECT      | SELECT * FROM TEST                 |
+------------+----------------+-----------+-------------+------------------------------------+
4 rows in set
```
