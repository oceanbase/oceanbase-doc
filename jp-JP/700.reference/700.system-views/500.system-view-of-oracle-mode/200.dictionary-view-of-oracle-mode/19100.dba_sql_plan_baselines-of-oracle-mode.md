# DBA_SQL_PLAN_BASELINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMにおけるSQLの計画ベースラインを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| SIGNATURE | NUMBER | NO | 正規化されたSQLによって生成されるSQLの一意識別子 |
| SQL_HANDLE | VARCHAR2(32) | NO | 一意のSQLテキスト |
| SQL_TEXT | CLOB | NO | 正規化されていないSQLテキスト |
| PLAN_NAME | VARCHAR2(128) | NO | 一意のテキスト形式の計画識別子 |
| CREATOR | VARCHAR2(128) | NO | この計画ベースラインを作成したユーザー |
| ORIGIN | VARCHAR2(29) | NO | 計画ベースラインの作成方法：<ul><li>MANUAL-LOAD</li><li>AUTO-CAPTURE</li><li>MANUAL-SQLTUNE</li><li>AUTO-SQLTUNE </li></ul> |
| PARSING_SCHEMA_NAME | VARCHAR2(128) | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| DESCRIPTION | VARCHAR2(500) | YES | 計画ベースラインの説明 |
| VERSION | VARCHAR2(256) | NO | 計画ベースライン作成時のデータベースバージョン |
| CREATED | TIMESTAMP(6) | NO | 計画ベースラインの作成時間 |
| LAST_MODIFIED | TIMESTAMP(6) | NO | 計画ベースラインの最終変更時間 |
| LAST_EXECUTED | NUMBER | NO | 計画ベースラインの最終実行時間 |
| LAST_VERIFIED | NUMBER | NO | 計画ベースラインの最終検証時間 |
| ENABLED | VARCHAR2(3) | NO | 計画ベースラインが有効かどうかを示します：<ul><li>YES</li><li>NO</li></ul> |
| ACCEPTED | VARCHAR2(3) | NO | 計画ベースラインが採用されたかどうかを示します：<ul><li>YES</li><li>NO</li></ul> |
| FIXED | VARCHAR2(3) | NO | 計画ベースラインが固定されているかどうかを示します：<ul><li>YES</li><li>NO</li></ul> |
| REPRODUCED | VARCHAR2(3) | NO | 計画ベースラインが再現可能かどうかを示します：<ul><li>YES</li><li>NO </li></ul>|
| AUTOPURGE | VARCHAR2(3) | NO | 計画ベースラインが自動クリーンアップされるかどうかを示します：<ul><li>YES</li><li>NO</li></ul> |
| ADAPTIVE | VARCHAR2(3) | NO | SPMによって自動的にキャプチャされた計画ベースラインが適応されているかどうかを示します：<ul><li>YES</li><li>NO</li></ul> |
| OPTIMIZER_COST | NUMBER | NO | 計画ベースライン作成時のオプティマイザーによる計画コストの推定値 |
| MODULE | VARCHAR2(64) | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| ACTION | VARCHAR2(64) | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| EXECUTIONS | NUMBER | NO | 計画ベースライン作成時の計画の実行回数 |
| ELAPSED_TIME | NUMBER | NO | 計画ベースライン作成時の計画の総経過時間 |
| CPU_TIME | NUMBER | NO | 計画ベースライン作成時の計画の総CPU時間 |
| BUFFER_GETS | NUMBER | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| DISK_READS | NUMBER | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| DIRECT_WRITES | NUMBER | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| ROWS_PROCESSED | NUMBER | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| FETCHES | NUMBER | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
| END_OF_FETCH_COUNT | NUMBER | NO | 現在、このフィールドはサポートされておらず、デフォルトではNULLです |
