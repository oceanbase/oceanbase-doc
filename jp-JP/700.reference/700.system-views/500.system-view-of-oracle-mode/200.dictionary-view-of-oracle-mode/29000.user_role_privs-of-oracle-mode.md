# USER_ROLE_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーに付与されているロールを説明します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**    | **NULL許容** |           **説明**           |
|--------------|--------------|----------------|----------------------------|
| GRANTEE      | VARCHAR2(30) | NO             | ユーザー名、またはPUBLIC             |
| GRANTED_ROLE | VARCHAR2(30) | NO             | ユーザーに付与されたロール名                  |
| ADMIN_OPTION | VARCHAR2(3)  | NO             | 権限付与にADMINオプションが含まれるかどうかを示します          |
| DEFAULT_ROLE | VARCHAR2(3)  | NO             | ロールがユーザーのDEFAULT ROLEとして指定されているかどうかを示します |

## クエリ例

現在のユーザーが持っているロールを確認します。

```shell
obclient [SYS]> SELECT * FROM USER_ROLE_PRIVS;
```

クエリ結果は次のとおりです：

```shell
+---------+--------------+--------------+--------------+
| GRANTEE | GRANTED_ROLE | ADMIN_OPTION | DEFAULT_ROLE |
+---------+--------------+--------------+--------------+
| SYS     | ROLE1        | YES          | YES          |
| SYS     | ROLE2        | YES          | YES          |
+---------+--------------+--------------+--------------+
2 rows in set
```
