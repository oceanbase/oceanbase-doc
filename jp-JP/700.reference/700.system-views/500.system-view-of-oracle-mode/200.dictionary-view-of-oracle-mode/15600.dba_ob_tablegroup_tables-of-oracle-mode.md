# DBA_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のテーブルグループとテーブル間の関連性を表示します。テーブルグループに属していないテーブルは表示されません。

## フィールドの説明

|      フィールド名       |      型          | NULL許容    |      説明       |
|-----------------|---------------|------------|---------------|
| TableGROUP_NAME | VARCHAR2(128) | NO         | テーブルグループ名           |
| OWNER           | VARCHAR2(128) | NO         | テーブルが属するデータベース名 |
| TABLE_NAME      | VARCHAR2(256) | NO         | テーブル名       |
| SHARDING        | VARCHAR2(10)  | NO         | テーブルグループのSHARDINGプロパティ：<ul><li>`NONE`：テーブルグループ内のすべてのテーブルのすべてのパーティションは同一マシンに集約され、テーブルグループへの追加テーブルに制限はありません。</li> <li>`PARTITION`：テーブルグループ内の各テーブルのデータをパーティション単位で分散します。サブパーティションテーブルの場合、各パーティションのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：テーブルグループ内の各テーブルのデータを適応型方式で分散します。つまり、テーブルグループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散します。</li></ul>  |

## クエリ例

ユーザーテナントが自身のテナントにおける`TBLGROUP1`という名前のテーブルグループの関連性をクエリします。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'TBLGROUP1';
```

クエリ結果は次のとおりです：

```shell
+-----------------+-------+------------+----------+
| TABLEGROUP_NAME | OWNER | TABLE_NAME | SHARDING |
+-----------------+-------+------------+----------+
| TBLGROUP1       | SYS   | TBL3       | NONE     |
+-----------------+-------+------------+----------+
1 row in set
```
