# USER_MVREF_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `USER_MVREF_STATS` は、マテリアライズドビューのリフレッシュに関する基本的な計時統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_NAME | VARCHAR2(128) | YES | マテリアライズドビューの名前 |
| REFRESH_ID | NUMBER | NO | リフレッシュのID |
| REFRESH_METHOD | VARCHAR2(30) | NO | マテリアライズドビューのリフレッシュ方式。<ul><li>FAST：増分リフレッシュ  </li><li>COMPLETE：全量リフレッシュ </li></ul>|
| REFRESH_OPTIMIZATIONS | VARCHAR2(4000) | NO | リフレッシュの最適化。例：空リフレッシュやマテリアライズドビューのリフレッシュ中のアプリケーションの主キー/外部キー。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| ADDITIONAL_EXECUTIONS | VARCHAR2(4000) | NO | 追加の実行処理。例：インデックスの再構築やマテリアライズドビューのリフレッシュ中に関与するログ操作。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| START_TIME | TIMESTAMP(6) | NO | リフレッシュ開始時刻 |
| END_TIME | TIMESTAMP(6) | NO | リフレッシュ終了時刻 |
| ELAPSED_TIME | NUMBER | NO | リフレッシュ実行時間、単位は秒 |
| LOG_SETUP_TIME | NUMBER | NO | マテリアライズドビューのログ設定時間、単位は秒<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値は0です。</p></main> |
| LOG_PURGE_TIME | NUMBER | NO | マテリアライズドビューのログクリーンアップ時間、単位は秒 |
| INITIAL_NUM_ROWS | NUMBER | NO | マテリアライズドビューの初期行数（リフレッシュ開始時） |
| FINAL_NUM_ROWS | NUMBER | NO | マテリアライズドビューの最終行数（リフレッシュ終了時） |
