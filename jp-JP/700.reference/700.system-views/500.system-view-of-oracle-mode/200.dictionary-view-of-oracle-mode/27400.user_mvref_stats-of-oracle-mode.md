# USER_MVREF_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `USER_MVREF_STATS` は、マテリアライズドビューのリフレッシュに関する基本的な計時統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_NAME | VARCHAR2(128) | YES | マテリアライズドビュー名 |
| REFRESH_ID | NUMBER | NO | リフレッシュのID |
| REFRESH_METHOD | VARCHAR2(30) | NO | マテリアライズドビューのリフレッシュ方式。<ul><li>FAST：増分リフレッシュ  </li><li>COMPLETE：全量リフレッシュ </li></ul>|
| REFRESH_OPTIMIZATIONS | VARCHAR2(4000) | NO | リフレッシュの最適化。例：空リフレッシュやマテリアライズドビューのリフレッシュ中のアプリケーションの主キー/外部キー。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はNULLです。</p></main> |
| ADDITIONAL_EXECUTIONS | VARCHAR2(4000) | NO | 追加の実行。例：インデックスの再構築やマテリアライズドビューのリフレッシュ中に関与したログ操作。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はNULLです。</p></main> |
| START_TIME | TIMESTAMP(6) | NO | リフレッシュ開始時間 |
| END_TIME | TIMESTAMP(6) | NO | リフレッシュ終了時間 |
| ELAPSED_TIME | NUMBER | NO | リフレッシュ実行時間。<ul><li>V4.4.2 BP2 より前のバージョンでは秒単位です。</li><li>V4.4.2 バージョンでは、V4.4.2 BP2 以降はマイクロ秒単位です。</li></ul> |
| LOG_SETUP_TIME | NUMBER | NO | マテリアライズドビューのログ設定時間、秒単位<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値は0です。</p></main> |
| LOG_PURGE_TIME | NUMBER | YES | マテリアライズドビューのログクリーンアップ時間。<ul><li>V4.4.2 BP2 より前のバージョンでは秒単位です。</li><li>V4.4.2 バージョンでは、V4.4.2 BP2 以降はマイクロ秒単位です。</li></ul> |
| INITIAL_NUM_ROWS | NUMBER | NO | マテリアライズドビューの初期行数（リフレッシュ開始時） |
| FINAL_NUM_ROWS | NUMBER | NO | マテリアライズドビューの最終行数（リフレッシュ終了時） |
| NUM_STEPS             | NUMBER         | NO   | このリフレッシュのstep合計を表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 から導入されました。</p></main>|
| RESULT                | NUMBER         | NO   | このリフレッシュタスクの実行結果コードを表します。0は成功。<main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 から導入されました。</p></main>|
| REFRESH_SCN           | NUMBER         | YES  | リフレッシュ開始時のSCNを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 から導入されました。</p></main>|
| SVR_IP                | VARCHAR2(64)   | YES  | リフレッシュを実行したOBServerのIPアドレスを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 から導入されました。</p></main>|
| SVR_PORT              | NUMBER         | YES  | リフレッシュを実行したOBServerのポートを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 から導入されました。</p></main>|
