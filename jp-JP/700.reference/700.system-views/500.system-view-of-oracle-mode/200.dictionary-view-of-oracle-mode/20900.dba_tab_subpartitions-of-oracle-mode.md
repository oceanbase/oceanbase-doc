# DBA_TAB_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのパーティションテーブルのサブパーティション情報を表示します。これには、サブパーティション名、テーブルおよび所属するパーティションの名前、そのストレージプロパティ、および`DBMS_STATS`パッケージが生成した統計情報が含まれます。

## クエリ例

ユーザーテナントは、自身のテナントにあるテーブル `TBL2_F_RL` のパーティション情報を確認します。

```shell
obclient [SYS]> SELECT TABLE_OWNER，TABLE_NAME, PARTITION_NAME, SUBPARTITION_NAME, HIGH_VALUE, HIGH_VALUE_LENGTH, PARTITION_POSITION, SUBPARTITION_POSITION
   FROM SYS.DBA_TAB_SUBPARTITIONS
   WHERE TABLE_NAME='TBL2_F_RL';
```

クエリ結果は次のとおりです：

```shell

| TABLE_OWNER | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | HIGH_VALUE | HIGH_VALUE_LENGTH | PARTITION_POSITION | SUBPARTITION_POSITION |
+-------------+------------+----------------+-------------------+------------+-------------------+--------------------+-----------------------+
| SYS         | TBL2_F_RL  | P0             | SP0               | 1,3        |                 3 |                  1 |                     1 |
| SYS         | TBL2_F_RL  | P0             | SP1               | 4,6        |                 3 |                  1 |                     2 |
| SYS         | TBL2_F_RL  | P0             | SP2               | 7,9        |                 3 |                  1 |                     3 |
| SYS         | TBL2_F_RL  | P1             | SP3               | 1,3        |                 3 |                  2 |                     1 |
| SYS         | TBL2_F_RL  | P1             | SP4               | 4,6        |                 3 |                  2 |                     2 |
| SYS         | TBL2_F_RL  | P1             | SP5               | 7,9        |                 3 |                  2 |                     3 |

6 rows in set
```

## 関連するビューまたはドキュメント

* すべてのテナントのパーティションテーブルのサブパーティション情報を表示するには、[CDB_TAB_SUBPARTITIONS](../../300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/13000.o-cdb_tab_subpartitions-of-sys-tenant.md)参照してください。

* 現在のユーザーがアクセスできるパーティションテーブルのサブパーティション情報を表示するには、[ALL_TAB_SUBPARTITIONS](5400.all_tab_subpartitions-of-oracle-mode.md)参照してください。

* 現在のユーザーが所有するパーティションテーブルのサブパーティション情報を表示するには、[USER_TAB_SUBPARTITIONS](29800.user_tab_subpartitions-of-oracle-mode.md)参照してください。

* このテナントのパーティションテーブルのパーティションの詳細情報を表示するには、[DBA_TAB_PARTITIONS](20500.dba_tab_partitions-of-oracle-mode.md)参照してください。
