# USER_JAVA_POLICY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.4.2バージョンでは、このビューはV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`USER_JAVA_POLICY`は、DBAに現在のJava UDF権限設定の詳細を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| KIND        | varchar2(8)    | NO   |  権限の種類    |
| GRANTEE     | varchar2(128)  | NO   |  権限を付与されたユーザー名    |
| TYPE_SCHEMA | varchar2(128)  | YES   |  権限タイプが存在するスキーマ    |
| TYPE_NAME   | varchar2(4096) | YES  |  権限タイプ名    |
| NAME        | varchar2(4096) | YES  |  権限名    |
| ACTION      | varchar2(4096) | YES  |  具体の権限    |
| ENABLED     | varchar2(8)    | NO   |  現在の権限が有効かどうか    |
| SEQ         | NUMBER(38)    | NO   |   `java_policy` の `key` に対応   |

## クエリ例

現在のユーザーのJava UDF権限設定の詳細を確認します。

```shell
obclient> SELECT * FROM USER_JAVA_POLICY;
```
