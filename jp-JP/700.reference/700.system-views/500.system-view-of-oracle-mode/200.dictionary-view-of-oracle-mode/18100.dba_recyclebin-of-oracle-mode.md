# DBA_RECYCLEBIN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのリサイクルバイン対象に関する情報を表示します。

## フィールドの説明

|      フィールド名      |      型       | NULL許容 |                                                                 説明                                                                 |
|----------------|---------------|------------|------------------------------------------------------------------------------------------------------------------------------------|
| OWNER          | VARCHAR2(128) | NO         | 対象の元所有者名                                      |
| OBJECT_NAME    | VARCHAR2(128) | NO         | 対象の新しい名前                                          |
| ORIGINAL_NAME  | VARCHAR2(128) | NO         | 対象の元の名前                                         |
| OPERATION      | VARCHAR2(9)   | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| TYPE           | VARCHAR2(25)  | NO         | 対象のタイプ                                            |
| TS_NAME        | VARCHAR2(30)  | NO         | 対象が属するテーブルスペースの名前                                     |
| CREATETIME     | VARCHAR2(19)  | NO         | 対象の作成時刻                                         |
| DROPTIME       | VARCHAR2(19)  | NO         | 対象がリサイクルバインに移動した時間                                      |
| DROPSCN        | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| PARTITION_NAME | VARCHAR2(128) | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| CAN_UNDROP     | VARCHAR2(3)   | NO         | 対象をリサイクルバインから復元できるかどうか：<ul><li>YES  </li><li> NO </li></ul>    |
| CAN_PURGE      | VARCHAR2(3)   | NO         | 対象を削除できるかどうか：<ul><li>YES  </li><li> NO </li></ul>         |
| RELATED        | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| BASE_OBJECT    | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| PURGE_OBJECT   | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| SPACE          | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
