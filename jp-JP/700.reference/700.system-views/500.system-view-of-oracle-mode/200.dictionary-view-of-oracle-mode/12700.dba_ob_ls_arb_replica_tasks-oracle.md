# DBA_OB_LS_ARB_REPLICA_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで実行中のアービトレーションサービスタスクを表示します。

## フィールドの説明

| フィールド | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | TIMESTAMP(6) | NO | タスクの生成時間 |
| MODIFY_TIME | TIMESTAMP(6) | NO | タスクの変更時間 |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| TASK_ID | NUMBER(38) | NO | タスクID |
| TRACE_ID | VARCHAR2(200) | NO | ログ内でこのタスクが実行されたtrace_id |
| TASK_TYPE | VARCHAR2(32) | NO | タスクタイプ：<ul><li> `ADD REPLICA`はレプリカ追加タスクを指します </li><li> `REMOVE REPLICA`はレプリカ削除タスクを指します </li></ul>|
| ARBITRATION_SERVICE | VARCHAR2(512) | NO | アービトレーションサービスアドレス |
| ARBITRATION_SERVICE_TYPE | VARCHAR2(64) | NO | アービトレーションサービスタイプ。現在は`ADDR`のみサポートしています |
| COMMENT | VARCHAR2(2048) | YES | タスクの説明 |
