# DBA_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルグループのメタ情報を表示します。主に、テーブルグループのパーティション情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.0以降のバージョンから、このビュー内のパーティションプロパティフィールドは意味を持たなくなり、統一的に<code>NONE</code>または</code>NULL</code>として表示されます。</p>
</main>

## フィールドの説明

|           フィールド名            |      タイプ       | NULL値を許容するか |            説明            |
|---------------------------|---------------|------------|----------------------------------------------------------|
| TABLEGROUP_NAME           | VARCHAR2(128) | NO         | テーブルグループ名                      |
| PARTITIONING_TYPE         | VARCHAR2(13)  | NO         | パーティションテーブルグループのパーティションタイプ：<ul><li>`NONE`：パーティションされていないテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul>          |
| SUBPARTITIONING_TYPE      | VARCHAR2(13)  | NO         | パーティションテーブルグループのサブパーティションタイプ：<ul><li>`NONE`：パーティションされていないテーブルグループ、パーティションされたテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul>   |
| PARTITION_COUNT           | NUMBER        | NO         | パーティションテーブルグループのパーティション数。パーティションされていないテーブルグループの場合、この値は `NULL`            |
| DEF_SUBPARTITION_COUNT    | NUMBER        | NO         | パーティションテーブルグループのサブパーティションテンプレートのパーティション数。サブパーティションテンプレートが定義されていないテーブルグループの場合、この値は `NULL`      |
| PARTITIONING_KEY_COUNT    | NUMBER        | NO         | パーティションテーブルグループのパーティションキー数。パーティションされていないテーブルグループの場合、この値は `NULL`               |
| SUBPARTITIONING_KEY_COUNT | NUMBER        | NO         | パーティションテーブルグループのサブパーティションキー数。サブパーティションされていないテーブルグループの場合、この値は `NULL`                      |
| SHARDING                  | VARCHAR2(10)  | NO         | テーブルグループのSHARDINGプロパティ。値は以下のとおりです：<ul><li>`NONE`：このプロパティを持つテーブルグループでは、グループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、グループへの追加テーブルに制限はありません。</li> <li>`PARTITION`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータがパーティション単位で分散されます。サブパーティションテーブルの場合、パーティション内のすべてのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータが適応型方式で分散されます。つまり、グループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散されます。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |

## クエリ例

1. テーブルグループ `tblgroup1` を作成します。

    ```shell
    obclient [SYS]> CREATE TABLEGROUP tblgroup1 SHARDING = 'PARTITION';
    ```

2. テーブルグループ `TBLGROUP1` のSHARDINGプロパティを確認します。

    ```shell
    obclient [SYS]> SELECT TABLEGROUP_NAME, SHARDING FROM SYS.DBA_OB_TABLEGROUPS WHERE tablegroup_name = 'TBLGROUP1';
    ```

    クエリ結果は次のとおりです：

    ```shell
    +-----------------+-----------+
    | TABLEGROUP_NAME | SHARDING  |
    +-----------------+-----------+
    | TBLGROUP1       | PARTITION |
    +-----------------+-----------+
    1 row in set
    ```
