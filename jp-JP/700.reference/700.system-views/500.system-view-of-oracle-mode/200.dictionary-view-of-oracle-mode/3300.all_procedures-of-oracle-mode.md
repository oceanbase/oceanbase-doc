# ALL_PROCEDURES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべての関数とプロシージャ、および関連するプロパティを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|    **フィールド名**    |    **型**     | **NULL許容** |                     **説明**                     |
|----------------|---------------|----------------|------------------------------------------------|
| OWNER          | VARCHAR2(128) | NO             | オブジェクトが属する所有者                                       |
| OBJECT_NAME    | VARCHAR2(128) | YES            | パッケージ名                                             |
| PROCEDURE_NAME | VARCHAR2(128) | NO             | プロシージャまたは関数名                                        |
| OBJECT_ID      | NUMBER        | NO             | オブジェクトID                                          |
| SUBPROGRAM_ID  | NUMBER        | NO             | パッケージ内での出現順序。独立したプロシージャや関数の場合、この値は1                     |
| OVERLOAD       | NUMBER        | NO             | パッケージソースファイル内でのオーバーロードの回数                                 |
| OBJECT_TYPE    | VARCHAR2(9)   | NO             | オブジェクトのタイプ                                          |
| AGGREGATE      | VARCHAR2(3)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNO             |
| PIPELINED      | VARCHAR2(3)   | NO             | プロシージャがパイプライン関数かどうかを示します                                  |
| IMPLTYPEOWNER  | VARCHAR2(30)  | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULL             |
| IMPLTYPENAME   | VARCHAR2(30)  | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULL                |
| PARALLEL       | VARCHAR2(3)   | NO             | プロシージャまたは機能が並列で有効かどうかを示します                                |
| INTERFACE      | VARCHAR2(3)   | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULL |
| DETERMINISTIC  | VARCHAR2(3)   | NO             | プロシージャまたは機能が決定的であることを宣言しています                                 |
| AUTHID         | VARCHAR2(12)  | NO             | INVOKER/DEFINER                                |
| ORIGIN_CON_ID  | NUMBER(38)    | NO             | オブジェクトが属するテナントのテナントID。システムパッケージの場合、この値は0                       |
