# DBA_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのメジャーコンパクションに関するグローバル情報を表示します。

## フィールド説明

|           フィールド名           |      型      | NULL許容    |        説明         |
|--------------------------|--------------|------------|---------------------------------------------|
| FROZEN_SCN               | NUMBER(38)   | NO         | 最後のメジャーコンパクションのバージョン番号           |
| GLOBAL_BROADCAST_SCN     | NUMBER(38)   | NO         | グローバルブロードキャストのメジャーコンパクションバージョン         |
| LAST_SCN                 | NUMBER(38)   | NO         | 前回完了したメジャーコンパクションのバージョン      |
| LAST_FINISH_TIME         | NUMBER(38)   | NO         | 前回のメジャーコンパクション終了時間         |
| START_TIME               | NUMBER(38)   | NO         | メジャーコンパクション開始時間            |
| STATUS                   | VARCHAR2(10) | NO         | <ul><li> `IDLE`：メジャーコンパクション中ではありません </li><li>`COMPACTING`：メジャーコンパクション中です </li><li>`CHECKSUM`：チェックサムの検証中 </li></ul>   |
| IS_ERROR                 | VARCHAR2(3)  | NO         | <ul><li>`YES`：メジャーコンパクションプロセスでエラーが発生しました</li><li>`NO`：メジャーコンパクションプロセスでエラーは報告されていません </li></ul>   |
| IS_SUSPENDED             | VARCHAR2(3)  | NO         | <ul><li>`YES`：メジャーコンパクションが一時停止状態です </li><li> `NO`：メジャーコンパクションは一時停止されていません </li></ul> |
| INFO                     | VARCHAR2(14) | NO         | メジャーコンパクション情報を表示します。例：メジャーコンパクション失敗の原因  |

## クエリ例

ユーザーテナントが自身のテナントのメジャーコンパクションに関するグローバル情報を確認します。

```shell
obclient> SELECT * FROM SYS.DBA_OB_MAJOR_COMPACTION;
```

クエリ結果は次のとおりです：

```shell
+---------------------+----------------------+---------------------+------------------+------------------+--------+----------+--------------+------+
| FROZEN_SCN          | GLOBAL_BROADCAST_SCN | LAST_SCN            | LAST_FINISH_TIME | START_TIME       | STATUS | IS_ERROR | IS_SUSPENDED | INFO |
+---------------------+----------------------+---------------------+------------------+------------------+--------+----------+--------------+------+
| 1748455200327759000 |  1748455200327759000 | 1748455200327759000 | 1748455572483698 | 1748455200351135 | IDLE   | NO       | NO           | NULL |
+---------------------+----------------------+---------------------+------------------+------------------+--------+----------+--------------+------+
1 row in set
```
