# ALL_TAB_COLS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`ALL_TAB_COLS` ビューは、現在のユーザーがアクセス可能なテーブルおよびビューのすべての列を表示します。

`ALL_TAB_COLS` ビューと [ALL_TAB_COLUMNS](4800.all_tab_columns-of-oracle-mode.md) の違いは、`ALL_TAB_COLS` がクイック削除された列も表示するのに対し、`ALL_TAB_COLUMNS` は表示しない点です。

<main id="notice" >
  <h4>適用対象</h4>
  <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>
