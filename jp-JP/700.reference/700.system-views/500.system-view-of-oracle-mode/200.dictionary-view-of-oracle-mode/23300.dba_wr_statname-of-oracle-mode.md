# DBA_WR_STATNAME

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

テナントのシステム統計項目名を表示します。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | NUMBER(38) | NO | クラスタID |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| STAT_ID | NUMBER(38) | NO | 統計項目ID |
| STAT_NAME | VARCHAR2(64) | NO | 統計項目名 |

## クエリ例

テナントのシステム統計項目名を照会し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_STATNAME WHERE ROWNUM <= 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
CLUSTER_ID: 10001
 TENANT_ID: 1004
   STAT_ID: 10000
 STAT_NAME: rpc packet in
1 row in set (0.063 sec)
```
