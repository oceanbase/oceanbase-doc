# DBA_SQL_MANAGEMENT_CONFIG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMに含まれる構成パラメータを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| PARAMETER_NAME | VARCHAR2(128) | NO | 構成パラメータ名：<li>SPACE_BUDGET_PERCENT<li>PLAN_RETENTION_WEEKS |
| PARAMETER_VALUE | text | YES | 構成パラメータの値 |
| LAST_MODIFIED | TIMESTAMP(6) | NO | パラメータ値が最後に更新された時間 |
| MODIFIED_BY | VARCHAR2(128) | NO | パラメータ値が最後に更新されたオブジェクト |

## クエリ例

現在のテナントのSPMに含まれる構成パラメータを照会します。

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_SQL_MANAGEMENT_CONFIG;
```
