# DBA_DEPENDENCIES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

データベース内の各オブジェクト間のすべての依存関係を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|       **フィールド名**       |    **型**     | **NULL許容** |      **説明**       |
|----------------------|---------------|----------------|-------------------|
| OWNER                | VARCHAR2(128) | NO             | 依存関係の所有者の名前     |
| NAME                 | VARCHAR2(128) | NO             | 依存関係の名前            |
| TYPE                 | VARCHAR2(23)  | NO             | 依存関係のタイプ            |
| REFERENCED_OWNER     | VARCHAR2(128) | NO             | 被依存関係の所有者名    |
| REFERENCED_NAME      | VARCHAR2(128) | NO             | 被依存関係の名前           |
| REFERENCED_TYPE      | VARCHAR2(18)  | NO             | 被依存関係のタイプ           |
| REFERENCED_LINK_NAME | VARCHAR2(128) | NO             | 被依存関係のDblink名   |
| DEPENDENCY_TYPE      | VARCHAR2(4)   | NO             | この依存関係が強い依存関係か、その他の依存関係タイプを示す |

## クエリ例

データベース内の各オブジェクト間のすべての依存関係を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_DEPENDENCIES;
```

クエリ結果は次のとおりです：

```shell
+----------+-----------------+----------+------------------+------------------+-----------------+----------------------+-----------------+
| OWNER    | NAME            | TYPE     | REFERENCED_OWNER | REFERENCED_NAME  | REFERENCED_TYPE | REFERENCED_LINK_NAME | DEPENDENCY_TYPE |
+----------+-----------------+----------+------------------+------------------+-----------------+----------------------+-----------------+
| SYS      | VERIFY_FUNCTION | FUNCTION | SYS              | COMPLEXITY_CHECK | FUNCTION        | NULL                 | HARD            |
| __public | VERIFY_FUNCTION | SYNONYM  | SYS              | VERIFY_FUNCTION  | FUNCTION        | NULL                 | HARD            |
+----------+-----------------+----------+------------------+------------------+-----------------+----------------------+-----------------+
2 rows in set
```
