# DBA_SCHEDULER_RUNNING_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内で現在実行中のすべてのジョブを表示します。

## フィールドの説明

| フィールド名                     | フィールドタイプ          | NULL許容 | 説明 |
|-------------------|--------------|------|-----|
| OWNER                   | varchar(128)  | NO   |ジョブ所有者 |
| JOB_NAME                | varchar(128)  | NO   |ジョブ名 |
| JOB_SUBNAME             | varchar(128)  | NO   |このフィールドは現在のバージョンではサポートされていません |
| JOB_STYLE               | varchar(17)   | YES  |`REGULAR`に統一されています |
| DETACHED                | varchar(5)    | NO   |このフィールドは現在のバージョンではサポートされていません |
| SESSION_ID              | decimal(10,0) | YES  |セッションID |
| SLAVE_PROCESS_ID        | decimal(10,0) | NO   |このフィールドは現在のバージョンではサポートされていません |
| SLAVE_OS_PROCESS_ID     | decimal(10,0) | NO   |このフィールドは現在のバージョンではサポートされていません |
| RUNNING_INSTANCE        | decimal(10,0) | NO   |このフィールドは現在のバージョンではサポートされていません |
| RESOURCE_CONSUMER_GROUP | varchar(128)  | NO   |このフィールドは現在のバージョンではサポートされていません |
| ELAPSED_TIME            | decimal(10,0) | NO   |実行時間 |
| CPU_USED                | decimal(10,0) | NO   |このフィールドは現在のバージョンではサポートされていません |
| DESTINATION_OWNER       | varchar(261)  | NO   |このフィールドは現在のバージョンではサポートされていません |
| DESTINATION             | varchar(261)  | YES  |このフィールドは現在のバージョンではサポートされていません |
| CREDENTIAL_OWNER        | varchar(128)  | NO   |このフィールドは現在のバージョンではサポートされていません||
| CREDENTIAL_NAME         | varchar(128)  | YES  |このフィールドは現在のバージョンではサポートされていません |
| THIS_DATE               | datetime(6)   | YES  |ジョブの今回の開始実行時間(rpc送信開始時点から計算) |
| THIS_EXEC_DATE          | datetime(6)   | YES  |ジョブの今回の開始実行時間(実行側でセッション作成開始時点から計算) |
| THIS_EXEC_ADDR          | varchar(128)  | YES  |ジョブの今回の実行SVR IPアドレス |
| THIS_EXEC_TRACE_ID      | varchar(128)  | YES  |ジョブの今回の実行トレースID |

## クエリ例

以下のコマンドを実行して、現在実行中の`test_job`という名前のジョブの状態情報を照会します。

```shell
obclient> SELECT * FROM DBA_SCHEDULER_RUNNING_JOBS WHERE job_name='test_job'\G
```
