# DBA_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内で設定された、期限切れクリーンアップ/自動クリーンアップのクリーンアップポリシーを表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| POLICY_NAME | VARCHAR2(256) | NO | クリーンアップポリシー名。<ul><li>`default`：テナントの現在の`DATA_BACKUP_DEST`および`LOG_ARCHIVE_DEST`パラメータに設定されているバックアップを自動的にクリーンアップします。</li> <li>`log_only`：テナントの現在の`LOG_ARCHIVE_DEST`パラメータで設定されているアーカイブパス内のログを自動的にクリーンアップします。</li></ul> |
| RECOVERY_WINDOW | VARCHAR2(64) | NO | 復元可能時間ウィンドウ。デフォルト値：0 |

## クエリ例

ユーザーテナントが自身のテナントのクリーンアップポリシーを確認する。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_POLICY;
```

クエリ結果は次のとおりです：

```shell
+-------------+-----------------+
| POLICY_NAME | RECOVERY_WINDOW |
+-------------+-----------------+
| default     | 7d              |
+-------------+-----------------+
1 row in set
```
