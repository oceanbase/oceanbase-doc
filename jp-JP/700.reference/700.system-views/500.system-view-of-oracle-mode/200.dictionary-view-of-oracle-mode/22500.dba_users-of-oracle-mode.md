# DBA_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`DBA_USERS` ビューは、データベース内のすべてのユーザーを確認するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースEnterprise Editionでのみ適用されます。</p>
  </main>
