# DBA_PART_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのパーティションテーブルのパーティション情報を表示します。

## フィールドの説明

| OWNER                     | VARCHAR2(128)  | NO         | パーティションテーブルの所有者                                                                                 |
