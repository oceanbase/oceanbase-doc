# USER_ALL_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するオブジェクトテーブルとリレーショナルテーブルを表示します。OWNERフィールド以外は、`ALL_ALL_TABLES`と同じです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## クエリ例

ユーザーが所有するオブジェクトテーブルとリレーショナルテーブルのうち、テーブル `T_SUBPART` の情報を確認します。

```shell
obclient [SYS]> SELECT TABLE_NAME, STATUS, PCT_FREE, NUM_ROWS, PARTITIONED, TEMPORARY, ROW_MOVEMENT, DROPPED, EXTERNAL FROM SYS.USER_ALL_TABLES WHERE TABLE_NAME='T_SUBPART';
```

クエリ結果は次のとおりです：

```shell
+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
| TABLE_NAME | STATUS | PCT_FREE | NUM_ROWS | PARTITIONED | TEMPORARY | ROW_MOVEMENT | DROPPED | EXTERNAL |
+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
| T_SUBPART  | VALID  |        0 |     1000 | YES         | N         | NO           | NO      | NO       |
+------------+--------+----------+----------+-------------+-----------+--------------+---------+----------+
1 row in set
```
