# DBA_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルグループのメタ情報を表示します。主にテーブルグループのパーティション情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.0バージョン以降、このビューのパーティション属性フィールドは意味を持たなくなり、すべて <code>NONE</code> または </code>NULL</code> として表示されます。</p>
</main>

## フィールド説明

|           フィールド名            |      型           | NULL許容   |            説明            |
|---------------------------|---------------|------------|-----------------------------------------------------|
| TABLEGROUP_NAME           | VARCHAR2(128) | NO         | テーブルグループ名                      |
| PARTITIONING_TYPE         | VARCHAR2(13)  | NO         | パーティションのテーブルグループのサブパーティションタイプ：<ul><li>`NONE`：非パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul>          |
| SUBPARTITIONING_TYPE      | VARCHAR2(13)  | NO         | パーティションのテーブルグループのサブパーティションタイプ：<ul><li>`NONE`：非パーティションテーブルグループ、パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul>   |
| PARTITION_COUNT           | NUMBER        | NO         | この値は `NULL` を指定します。                                                                             |
| DEF_SUBPARTITION_COUNT    | NUMBER        | NO         | この値は `NULL` を指定します。         |
| PARTITIONING_KEY_COUNT    | NUMBER        | NO         | この値は `NULL` を指定します。            |
| SUBPARTITIONING_KEY_COUNT | NUMBER        | NO         | この値は `NULL` を指定します。           |
| SHARDING                  | VARCHAR2(10)  | NO         | テーブルグループのSHARDINGプロパティ。取り得る値は以下のとおりです：<ul><li>`NONE`：このプロパティを持つテーブルグループでは、グループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、グループへのテーブル追加に制限はありません。</li> <li>`PARTITION`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータをパーティション単位で分散します。サブパーティションテーブルの場合、各パーティション内のすべてのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：このプロパティを持つテーブルグループでは、グループ内の各テーブルのデータを適応型方式で分散します。つまり、グループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散します。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |

## クエリ例

1. テーブルグループ `tblgroup1` を作成します。

   ```shell
   obclient [SYS]> CREATE TABLEGROUP tblgroup1 SHARDING = 'PARTITION';
   ```

2. テーブルグループ `TBLGROUP1` の SHARDING プロパティを確認します。

   ```shell
   obclient [SYS]> SELECT TABLEGROUP_NAME, SHARDING FROM SYS.DBA_OB_TABLEGROUPS WHERE tablegroup_name = 'TBLGROUP1';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +-----------------+-----------+
   | TABLEGROUP_NAME | SHARDING  |
   +-----------------+-----------+
   | TBLGROUP1       | PARTITION |
   +-----------------+-----------+
   1 row in set
   ```
