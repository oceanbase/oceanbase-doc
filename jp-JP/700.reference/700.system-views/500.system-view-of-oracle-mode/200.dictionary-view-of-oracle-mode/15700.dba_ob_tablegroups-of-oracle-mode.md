# DBA_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルグループのメタ情報を表示します。主にテーブルグループのパーティション情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.0バージョン以降、このビューのパーティション属性フィールドは意味を持たなくなり、統一して<code>NONE</code>または</code>NULL</code>と表示されます。</p>
</main>

## フィールドの説明

|           フィールド名            |      型       | NULL許容 |            説明            |
|---------------------------|---------------|------------|-----------------------------------------------------|
| TABLEGROUP_NAME           | VARCHAR2(128) | NO         | テーブルグループ名                      |
| PARTITIONING_TYPE         | VARCHAR2(13)  | NO         | パーティションのテーブルグループのサブパーティションのパーティションタイプ：<ul><li>`NONE`：非パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul>          |
| SUBPARTITIONING_TYPE      | VARCHAR2(13)  | NO         | パーティションのテーブルグループのサブパーティションのサブパーティションタイプ：<ul><li>`NONE`：非パーティションテーブルグループ、パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ </li></ul>   |
| PARTITION_COUNT           | NUMBER        | NO         | この値は`NULL`です。                                                                             |
| DEF_SUBPARTITION_COUNT    | NUMBER        | NO         | この値は`NULL`です。         |
| PARTITIONING_KEY_COUNT    | NUMBER        | NO         | この値は`NULL`です。            |
| SUBPARTITIONING_KEY_COUNT | NUMBER        | NO         | この値は`NULL`です。           |
| SHARDING                  | VARCHAR2(20)  | NO         | テーブルグループのSHARDING属性。取り得る値は次のとおりです：<ul><li>`NONE`：この属性を持つテーブルグループでは、テーブルグループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、テーブルグループへのテーブルの追加に制限はありません。</li> <li>`PARTITION`：この属性を持つテーブルグループでは、テーブルグループ内の各テーブルのデータがパーティション単位で分散されます。サブパーティションを持つテーブルの場合、パーティション内のすべてのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：この属性を持つテーブルグループでは、テーブルグループ内の各テーブルのデータが適応型方式で分散されます。つまり、テーブルグループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションを持つテーブルの場合は各パーティションのサブパーティション単位で分散されます。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| SCOPE                     | VARCHAR2(20)  | YES        | テーブルグループの`SCOPE`属性。取り得る値は次のとおりです：<ul><li>`SERVER`：すべてのパーティショングループのリーダーが同一ノード上に配置されていることを示します。 </li><li>`ZONE`：すべてのパーティショングループのリーダーが同一ゾーン内に配置され、ゾーン内の各ノードに分散されていることを示します。 </li><li>`CLUSTER`：すべてのパーティショングループのリーダーがクラスタ内の各ノードに分散されていることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンについては、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>|

## クエリ例

テーブルグループ `TBLGROUP1` の属性を確認します。

```shell
obclient> SELECT * FROM SYS.DBA_OB_TABLEGROUPS WHERE tablegroup_name = 'TBLGROUP1'\G
```

実行結果は次のとおりです：

```shell
*************************** 1. row ***************************
          TABLEGROUP_NAME: TBLGROUP1
        PARTITIONING_TYPE: NONE
     SUBPARTITIONING_TYPE: NONE
          PARTITION_COUNT: NULL
   DEF_SUBPARTITION_COUNT: NULL
   PARTITIONING_KEY_COUNT: NULL
SUBPARTITIONING_KEY_COUNT: NULL
                 SHARDING: NONE
                    SCOPE: ZONE
1 row in set
```
