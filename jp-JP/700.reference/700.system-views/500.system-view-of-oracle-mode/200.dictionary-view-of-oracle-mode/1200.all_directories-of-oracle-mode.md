# ALL_DIRECTORIES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのディレクトリを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**    |     **型**     | **NULL許容** |   **説明**    |
|----------------|----------------|----------------|-------------|
| OWNER          | VARCHAR2(128)  | NO             | ディレクトリの所有者 |
| DIRECTORY_NAME | VARCHAR2(128)  | NO             | ディレクトリ名        |
| DIRECTORY_PATH | VARCHAR2(4000) | NO             | ディレクトリパス        |
| ORIGIN_CON_ID  | NUMBER(38)     | NO             | テナントID       |

## クエリ例

現在ユーザーがアクセス可能なすべてのディレクトリを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_DIRECTORIES;
```

クエリ結果は次のとおりです：

```shell
+-------+----------------+----------------------+---------------+
| OWNER | DIRECTORY_NAME | DIRECTORY_PATH       | ORIGIN_CON_ID |
+-------+----------------+----------------------+---------------+
| SYS   | SQL_FILE_DIR   | /home/admin/sqldump  |          1004 |
+-------+----------------+----------------------+---------------+
1 row in set
```
