# DBA_OB_ACCESS_POINT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのテナントエントリのサーバー一覧を表示します。ネットワークベースの物理スタンバイデータベースシナリオでは、主テナントが存在するレプリカのOBServerノードのIPアドレスとSQLポート番号を取得するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID<ul><li>1：システムテナント  </li><li>その他の値：ユーザーテナント </li></ul>|
| TENANT_NAME | VARCHAR2(128) | NO | テナント名 |
| SVR_IP | VARCHAR2(46) | NO | システムログストリームレプリカが属するサーバーのIPアドレス |
| SQL_PORT | NUMBER(38) | NO | システムログストリームレプリカが属するSQLポート |

## クエリ例

ユーザーテナントが自身のテナントエントリのサーバー一覧を照会します。

```shell
obclient [SYS]> SELECT SVR_IP, SQL_PORT FROM SYS.DBA_OB_ACCESS_POINT;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+
| SVR_IP         | SQL_PORT |
+----------------+----------+
| 172.xx.xxx.xxx |     2881 |
+----------------+----------+
1 row in set
```
