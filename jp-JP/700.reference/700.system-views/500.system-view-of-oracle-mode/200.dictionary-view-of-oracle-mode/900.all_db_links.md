# ALL_DB_LINKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのDBLinkを表示します。

## フィールド説明

| フィールド | 型 | NULL許容 | 説明 |
| ------ | ------ | ------ | ------ |
| OWNER | VARCHAR2(128) | NO | このDBLINKを作成したユーザー名。 |
| DB_LINK | VARCHAR2(128) | NO | DBLINK名。 |
| USERNAME | VARCHAR2(128) | NO | DBLINKがリモートデータベースに接続するために使用するユーザー名。 |
| CREDENTIAL_NAME | VARCHAR2(128) | NO | リモートデータベースへの接続に使用されるCredentials名。互換性のみのために使用されます。 |
| CREDENTIAL_OWNER | VARCHAR2(128) | NO | リモートデータベースへの接続に使用されるCredentials所有者。互換性のみのために使用されます。 |
| HOST | VARCHAR2(2000) | NO | DBLINKがリモートデータベースに接続するホスト名(IPアドレス)。 |
| CREATED | DATE | NO | DBLINKの作成日時。 |
| HIDDEN | VARCHAR2(3) | NO | 内部使用フィールドです。互換性のみのために使用されます。 |
| SHARD_INTERNAL | VARCHAR2(3) | NO | DBLINKが共有接続をサポートするかどうかを示すマーカーです。ローカルデータベースとリモートデータベース間の接続数を削減するために使用されます。互換性のみのために使用されます。 |
| VALID | VARCHAR2(3) | NO | DBLINKが利用可能かどうかを示すマーカーです。互換性のみのために使用され、デフォルトはYESです。 |
| INTRA_CDB | VARCHAR2(3) | NO | 内部使用フィールドです。互換性のみのために使用されます。 |
| TENANT_NAME | VARCHAR2(128) | NO | DBLINKがリモートデータベースに接続するために使用するテナント名。 |
| REVERSE_TENANT_NAME | VARCHAR2(128) | YES | リバースDBLINKがローカルデータベースに接続するために使用するテナント名。 |
| CLUSTER_NAME | VARCHAR2(128) | YES | DBLINKがリモートデータベースに接続するために使用するクラスタ名。 |
| REVERSE_CLUSTER_NAME | VARCHAR2(128) | YES | リバースDBLINKがローカルデータベースに接続するために使用するクラスタ名。 |
| REVERSE_HOST | VARCHAR2(46)   | YES | リバースDBLINKがローカルデータベースに接続するホスト名(IPアドレス)。 |
| REVERSE_PORT | NUMBER(38)  | YES | リバースDBLINKがローカルデータベースに接続するポート番号。 |
| REVERSE_USERNAME | VARCHAR2(128) | YES | リバースDBLINKがローカルデータベースに接続するユーザー名。 |

## クエリ例
