# DBA_TAB_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのテーブルの列統計情報とヒストグラム情報を表示します。

## フィールド説明

|     フィールド名      |      型           | **NULL許容** |                                                               説明                                                               |
|---------------|---------------|----------------|--------------------------------------------------------------------------------------------------------------------------------|
| OWNER         | VARCHAR2(128) | NO             | 列が属するユーザー                                      |
| TABLE_NAME    | VARCHAR2(128) | NO             | 列が属するテーブル名                                      |
| COLUMN_NAME   | VARCHAR2(128) | NO             | 列名                                          |
| NUM_DISTINCT  | NUMBER        | NO             | 列の異なる値の数                                    |
| LOW_VALUE     | VARCHAR2(128) | NO             | 列の最小値                                       |
| HIGH_VALUE    | VARCHAR2(128) | NO             | 列の最大値                                       |
| DENSITY       | NUMBER        | NO             | 列の密度                                        |
| NUM_NULLS     | NUMBER        | NO             | 列内の`NULL`値の数                              |
| NUM_BUCKETS   | NUMBER        | NO             | 列のヒストグラムにおけるバケット数                                   |
| LAST_ANALYZED | DATE          | NO             | 最終分析日時                                     |
| SAMPLE_SIZE   | NUMBER        | NO             | 分析時のサンプルサイズ                                    |
| GLOBAL_STATS  | VARCHAR2(3)   | NO             | <ul><li> `YES`：統計情報が直接収集されたか、増分でメンテナンスされたことを示す  </li> <li> `NO`：その他の場合  </li></ul>  |
| USER_STATS    | VARCHAR2(3)   | NO             | パーティション統計情報がユーザー設定かどうか                              |
| NOTES         | VARCHAR2(80)  | NO             | 追加の属性を記録                                   |
| AVG_COL_LEN   | NUMBER        | NO             | 列の平均長                                      |
| HISTOGRAM     | VARCHAR2(15)  | NO             | ヒストグラムタイプ                                       |
| SCOPE         | VARCHAR2(7)   | NO             | 統計情報の有効範囲                                   |

## クエリ例

ユーザーテナントが自身のテナント内にあるテーブル `T_SUBPART` の列統計情報とヒストグラム情報を照会します。

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, COLUMN_NAME, NUM_DISTINCT, LOW_VALUE, HIGH_VALUE, DENSITY, NUM_NULLS, NUM_BUCKETS, SAMPLE_SIZE, AVG_COL_LEN, HISTOGRAM FROM SYS.DBA_TAB_COL_STATISTICS WHERE TABLE_NAME ='T_SUBPART' ORDER BY 1, 2, 3;
```

クエリ結果は次のとおりです：

```shell

+-------+------------+-------------+--------------+-----------+------------+------------------------+-----------+-------------+-------------+-------------+-----------+
| SYS   | T_SUBPART  | C1          |        10191 | 0         | 9999       | .000098125797272102829 |         0 |           5 |       10000 |          20 | HYBRID    |
| SYS   | T_SUBPART  | C2          |         1031 | 0         | 999        |  .00096993210475266732 |         0 |           5 |       10000 |          20 | HYBRID    |
| SYS   | T_SUBPART  | C3          |         1973 | 0         | 1999       |  .00050684237202230106 |         0 |           5 |       10000 |          20 | HYBRID    |
+-------+------------+-------------+--------------+-----------+------------+------------------------+-----------+-------------+-------------+-------------+-----------+
3 rows in set
```
