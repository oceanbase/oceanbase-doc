# DBA_RSRC_PLAN_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>このビューはV3.1.2バージョンから導入されました。</li>
<li>現在のバージョンでは、テナントのResource Managerにおける各種リソース設定パラメータ情報を確認するには、ビュー<a href="15020.dba_ob_rsrc_directives-of-oracle-mode.md">DBA_OB_RSRC_DIRECTIVES</a>の使用を推奨します。</li></ul>
</main>

## 機能の概要

`DBA_RSRC_PLAN_DIRECTIVES` ビューは、データベース内の各リソース計画指示の詳細情報を記録するために使用されます。
