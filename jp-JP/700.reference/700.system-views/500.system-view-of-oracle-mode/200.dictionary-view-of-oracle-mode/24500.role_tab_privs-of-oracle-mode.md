# ROLE_TAB_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ロールに付与されたテーブル権限を説明します。ユーザーがアクセス可能なロールの情報のみを提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|  **フィールド名**   |    **型**     | **NULL許容** |       **説明**       |
|-------------|---------------|----------------|--------------------|
| ROLE        | VARCHAR2(128) | NO             | ロール名               |
| OWNER       | VARCHAR2(128) | NO             | オブジェクト所有者             |
| TABLE_NAME  | VARCHAR2(128) | NO             | オブジェクト名              |
| COLUMN_NAME | VARCHAR2(128) | NO             | 列名（使用されている場合）         |
| PRIVILEGE   | VARCHAR2(40)  | NO             | ロールに付与されたオブジェクト権限          |
| GRANTABLE   | VARCHAR2(3)   | NO             | このロールにADMINオプションが付与されているかどうか |

## クエリ例

ユーザーがアクセス可能なロールのうち、ロール `ROLE1` に付与されたテーブル権限を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ROLE_TAB_PRIVS WHERE ROLE = 'ROLE1';
```

クエリ結果は次のとおりです。

```shell
+-------+-------+------------+-------------+-----------+-----------+
| ROLE  | OWNER | TABLE_NAME | COLUMN_NAME | PRIVILEGE | GRANTABLE |
+-------+-------+------------+-------------+-----------+-----------+
| ROLE1 | SYS   | TBL2       | NULL        | UPDATE    | NO        |
| ROLE1 | SYS   | TBL2       | NULL        | SELECT    | NO        |
+-------+-------+------------+-------------+-----------+-----------+
2 rows in set
```
