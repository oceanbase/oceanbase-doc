# USER_PART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーのパーティションのヒストグラム関連情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|           フィールド名            |       タイプ       | NULLを許容するか |      説明       |
|---------------------------|----------------|------------|---------------|
| TABLE_NAME                | VARCHAR2(128)  | NO         | ヒストグラムが属するテーブル名       |
| PARTITION_NAME            | VARCHAR2(128)  | NO         | ヒストグラムが属するパーティション名    |
| COLUMN_NAME               | VARCHAR2(128)  | NO         | ヒストグラムが属する列名       |
| ENDPOINT_NUMBER           | NUMBER         | NO         | Bucket累積頻度  |
| ENDPOINT_VALUE            | NUMBER         | NO         | Bucket端点正規化値 |
| ENDPOINT_ACTUAL_VALUE     | VARCHAR2(4000) | NO         | Bucket端点値    |
| ENDPOINT_ACTUAL_VALUE_RAW | VARCHAR2(4000) | NO         | Bucket端点バイナリ値 |
| ENDPOINT_REPEAT_COUNT     | NUMBER         | NO         | Bucket端点値の頻度 |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.USER_PART_HISTOGRAMS WHERE TABLE_NAME ='T_SUBPART';
```
