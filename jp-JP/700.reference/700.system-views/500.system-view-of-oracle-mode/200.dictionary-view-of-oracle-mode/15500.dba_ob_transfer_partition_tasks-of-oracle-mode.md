# DBA_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TRANSFER_PARTITION_TASKS`は、このテナントで現在処理中のパーティション転送タスクを表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | NUMBER(38)  | NO   |  Transfer Partitionタスクの一意識別子   |
| CREATE_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  |  作成時間   |
| MODIFY_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  |  情報更新時間   |
| TABLE_ID         | NUMBER(38)   | NO   |  Transferのパーティションが存在するテーブルID   |
| OBJECT_ID        | NUMBER(38)   | NO   |  Transferのパーティションの`OBJECT_ID`   |
| DEST_LS          | NUMBER(38)   | NO   |  目的地ログストリーム   |
| BALANCE_JOB_ID   | NUMBER(38)   | NO   |  タスク実行時に関連付けられるロードバランシングジョブID   |
| TRANSFER_TASK_ID | NUMBER(38)   | NO   |  タスク実行時に関連付けられるTransferタスクID   |
| STATUS           | VARCHAR2(64) | NO   |  タスク状態：<ul><li>WAITING：タスク待機中、実行開始されていない</li><li>INIT：タスクスケジューリング開始</li><li>DOING：タスクTransferの実行開始</li></ul>   |
| COMMENT          | CLOB     | YES  |  コメント情報   |

## クエリ例

このテナントで現在処理中のパーティション転送タスクを確認します。

```shell
obclient> SELECT * FROM SYS.DBA_OB_TRANSFER_PARTITION_TASKS;
```

クエリ結果は次のとおりです：

```shell
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|       4 | 2023-12-01 11:21:11.357272 | 2023-12-01 11:21:17.904857 |   500012 |    500014 |    1003 |         737367 |                9 | DOING  | NULL    |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set
```
