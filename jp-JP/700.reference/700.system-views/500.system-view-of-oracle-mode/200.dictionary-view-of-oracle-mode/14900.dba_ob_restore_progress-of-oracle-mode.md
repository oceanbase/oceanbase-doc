# DBA_OB_RESTORE_PROGRESS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在、対象テナントで進行中の復元タスクを表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | 復元に属するjob_id。1回の復元タスクに対応します |
| RESTORE_TENANT_NAME | VARCHAR2(4096) | NO | 復元対象のテナント名 |
| RESTORE_TENANT_ID | NUMBER(38) | NO | 復元対象のテナントID |
| BACKUP_TENANT_NAME | VARCHAR2(4096) | NO | バックアップ元のソーステナント名 |
| BACKUP_TENANT_ID | VARCHAR2(4096) | NO | バックアップ元のソーステナントID |
| BACKUP_CLUSTER_NAME | VARCHAR2(4096) | NO | バックアップ元のソースクラスタ名 |
| BACKUP_DEST | VARCHAR2(4096) | NO | バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します |
| RESTORE_OPTION | VARCHAR2(4096) | NO | 復元オプション。復元を開始する際にユーザーが指定した`restore_option` |
| RESTORE_TYPE   | VARCHAR2(4096) | NO |復元タイプ。<ul> <li>`FULL`：フル復元を表します</li> <li> `QUICK`：クイック復元を表します</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main> |
| RESTORE_SCN | NUMBER(38) | NO | ユーザーが指定した復元ポイント |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | ユーザーが指定した復元ポイントのタイムスタンプ表現 |
| STATUS | VARCHAR2(4096) | NO | 復元状態：システムテナントの復元タスクと復元対象テナントの復元タスクの状態が一致しません。<br>システムテナント：<ul><li> `CREATE_TENANT`：テナントの作成。この段階ではシステムテナントが復元対象テナントを作成します </li> <li> `WAIT_TENANT_RESTORE_FINISH`：復元対象テナントの復元終了を待機 </li> <li> `RESTORE_SUCCESS`：テナントの復元に成功 </li> <li> `RESTORE_FAIL`：テナントの復元に失敗 </li></ul> <br>復元対象テナント：<ul><li> `RESTORE_PRE`：復元前の準備。暗号化を設定している場合、暗号化情報を設定します </li> <li> `RESTORE_CREATE_INIT_LS`：ログストリームの作成 </li> <li> `RESTORE_WAIT_LS`：ログストリームの復元完了を待機 </li> <li> `POST_CHECK`；テナントロールのチェック、スタンバイデータベースへの復元 </li> <li> `UPGRADE`：アップグレード。バージョン間での復元の場合、テナントはアップグレードプロセスを実行します </li> <li> `RESTORE_SUCCESS`：復元に成功 </li> <li> `RESTORE_FAIL`：復元に失敗 </li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | 復元タスク開始時刻のタイムスタンプ |
| BACKUP_SET_LIST | VARCHAR2(4096) | NO | 復元に依存するデータバックアップセットパスのリスト。バックアップセット間は`,`で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`   |
| BACKUP_PIECE_LIST | VARCHAR2(4096) | NO | 復元に依存するログアーカイブピースのパスリスト。ピース間は`,`で区切ります。例：`file:///data/nfs/backup/archive/2_1_2,file:///data/nfs/backup/archive/2_1_3`  |
| RECOVER_SCN                      | NUMBER(38)     | NO   | ログの復元ポイント。システムテナントの場合、このフィールドの値は`NULL`です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_SCN_DISPLAY              | TIMESTAMP(9)   | NO   | ログの復元ポイントのタイムスタンプ表現。システムテナントの場合、このフィールドの値は`NULL`です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_PROGRESS                 | NUMBER         | NO   | ログ復元の進捗状況。結果は小数点以下2桁を保持します。例：`87.65`と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は`NULL`です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TABLET_COUNT                     | NUMBER(38)     | NO   | 復元待ちのTabletの総数。システムテナントの場合、このフィールドの値は`NULL`です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| FINISH_TABLET_COUNT              | NUMBER(38)     | NO   | 復元済みのTabletの総数。システムテナントの場合、このフィールドの値は`NULL`です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RESTORE_PROGRESS                 | NUMBER         | NO   | データ復元の進捗状況。結果は小数点以下2桁を保持します。例：`87.65`と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は`NULL`です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TOTAL_BYTES          | NUMBER(38)     | NO   | 復元総バイト数 |
| TOTAL_BYTES_DISPLAY  | VARCHAR2(42)   | NO   | ストレージ容量単位で表示された復元総バイト数 |
| FINISH_BYTES         | NUMBER(38)     | NO   | 完了復元バイト数 |
| FINISH_BYTES_DISPLAY | VARCHAR2(42)   | NO   | ストレージ容量単位で表示された復元総バイト数 |
| DESCRIPTION          | VARCHAR2(4096) | NO   | 復元コマンドで指定された`DESCRIPTION`情報 |
