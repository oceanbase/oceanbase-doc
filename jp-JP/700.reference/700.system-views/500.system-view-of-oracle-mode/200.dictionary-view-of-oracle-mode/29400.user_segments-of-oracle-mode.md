# USER_SEGMENTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するセグメントの物理ストレージ割り当て状況を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。s</p>
  </main>

## クエリ例

現在のユーザーが所有するテーブルのうち、テーブル `T_SUBPART` の物理ストレージ割り当て状況を確認します。

```shell
obclient [SYS]> SELECT SEGMENT_NAME, PARTITION_NAME, SEGMENT_TYPE, BYTES, BLOCKS FROM SYS.DBA_SEGMENTS WHERE SEGMENT_NAME='T_SUBPART';
```
