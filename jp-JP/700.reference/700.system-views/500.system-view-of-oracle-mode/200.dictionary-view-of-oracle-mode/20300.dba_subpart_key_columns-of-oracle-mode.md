# DBA_SUBPART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのパーティションオブジェクトにおいて、サブパーティションキーに含まれる列を表示します。

## フィールド説明

|      **フィールド名**      |     **型**     | **NULL許容** |                                                              **説明**                                                              |
|--------------------|----------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの所有者                                  |
| NAME               | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前                                   |
| OBJECT_TYPE        | CHAR(5)        | NO             | パーティションオブジェクトのタイプ：<ul><li>TABLE   </li><li> INDEX </li></ul>   |
| COLUMN_NAME        | VARCHAR2(4000) | NO             | 列の名前                                          |
| COLUMN_POSITION    | NUMBER         | NO             | パーティションキーにおける列の位置                                     |
| COLLATED_COLUMN_ID | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在、このフィールドのデフォルト値はNULLです                       |

## クエリ例

ユーザーテナントが自身のテナント内にあるパーティションテーブル `TBL2_F_RL` のサブパーティションキーに含まれる列を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_SUBPART_KEY_COLUMNS WHERE NAME='TBL2_F_RL';
```

クエリ結果は次のとおりです：

```shell
+-------+-----------+-------------+-------------+-----------------+--------------------+
| OWNER | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-------+-----------+-------------+-------------+-----------------+--------------------+
| SYS   | TBL2_F_RL | TABLE       | COL2        |               1 |               NULL |
+-------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
