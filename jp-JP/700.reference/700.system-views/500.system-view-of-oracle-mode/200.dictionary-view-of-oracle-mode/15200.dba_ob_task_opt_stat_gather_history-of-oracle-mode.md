# DBA_OB_TASK_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントの履歴収集タスクの実行状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER | NO | 収集タスクが属するテナントID |
| TASK_ID | VARCHAR2(36) | NO | 収集タスクID（UUID生成、グローバル一意） |
| TYPE | VARCHAR2(16) | NO | 収集タスクのタイプ：<ul><li>`MANUAL GATHER`：手動収集</li> <li>`AUTO GATHER`：自動収集</li> <li>`ASYNC GATHER`：非同期収集</li></ul> |
| STATUS | VARCHAR2(8) | NO | 収集タスクのステータス<ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| TASK_TABLE_COUNT | NUMBER | YES | 収集タスクで収集する必要があるテーブル数 |
| FAILED_COUNT | NUMBER | YES | 収集タスクで収集に失敗したテーブル数 |
| TASK_START_TIME | TIMESTAMP(6) | NO | 収集タスク開始時間 |
| TASK_END_TIME | TIMESTAMP(6) | NO | 収集タスク終了時間 |
