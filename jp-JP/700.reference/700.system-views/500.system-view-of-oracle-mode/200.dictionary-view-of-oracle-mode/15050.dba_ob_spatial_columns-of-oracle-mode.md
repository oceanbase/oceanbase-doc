# DBA_OB_SPATIAL_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_SPATIAL_COLUMNS` は、空間インデックス列に対応するデータベース名、テーブル名、型、およびSRS情報を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | -------- | -------------------- | ------- |
| TABLE_SCHEMA       | VARCHAR2(128) | NO   | 列が属するデータベース。|
| TABLE_NAME         | VARCHAR2(256) | NO   | この空間列を含むテーブル名。|
| COLUMN_NAME        | VARCHAR2(128) | NO   | 列名。|
| SRS_NAME           | VARCHAR2(128) | NO   | 空間座標系名。|
| SRS_ID             | NUMBER(10)    | NO   | 空間座標系ID。|
| GEOMETRY_TYPE_NAME | VARCHAR2(128) | NO   | 空間データ型。|
| DIMINFO            | VARCHAR2(512) | NO   | 各緯度の設定です。この列の設定は現在サポートされていないため、デフォルト値として表示されます。|
| INDEX_NAME         | VARCHAR2(128) | NO   | この列に対応するインデックス名。インデックスがない場合はNULL。|

## クエリ例

空間インデックス列に対応するデータベース名、テーブル名、タイプ、およびSRS情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_SPATIAL_COLUMNS;
```
