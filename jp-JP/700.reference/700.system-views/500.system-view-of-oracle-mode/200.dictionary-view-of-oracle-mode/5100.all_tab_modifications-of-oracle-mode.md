# ALL_TAB_MODIFICATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なテーブルの累積変更情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TABLE_OWNER | VARCHAR2(128) | NO | テーブル所有者を変更します。 |
| TABLE_NAME | VARCHAR2(128) | NO | テーブル名を変更します。 |
| PARTITION_NAME | VARCHAR2(128) | NO | パーティション名を変更します。 |
| SUBPARTITION_NAME | VARCHAR2(128) | NO | サブパーティション名を変更します。 |
| INSERTS | NUMBER | NO | 約定数の挿入回数 |
| UPDATES | NUMBER | NO | 約定数の更新回数 |
| DELETES | NUMBER | NO | 約定数の削除回数 |
| TIMESTAMP | DATE | NO | テーブルが最後に変更された日時を示します。 |
| TRUNCATED | VARCHAR2(3) | NO | 現在、実際の意味はありません。デフォルトはNULLです。 |
| DROP_SEGMENTS | NUMBER | NO | 現在、実際の意味はありません。デフォルトはNULLです。 |

## クエリ例

