# DBA_PROFILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのProfileファイルとそのパラメータ情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**    |    **タイプ**    | **NULL許容** |              **説明**              |
|---------------|--------------|----------------|----------------------------------|
| PROFILE       | VARCHAR2(30) | NO             | Profileファイル名                            |
| RESOURCE_NAME | VARCHAR2(32) | NO             | パラメータ名                            |
| RESOURCE_TYPE | VARCHAR2(8)  | NO             | パラメータタイプ：<ul><li>`KERNEL`</li> <li>`PASSWORD`</li></ul>  |
| LIMIT         | VARCHAR2(128) | NO             | パラメータの制限値                         |
| PASSWORD_ROLLOVER_TIME | bigint(20) | NO             | パスワードローリング時間（単位：マイクロ秒）。古いパスワードが変更後も有効な時間枠を定義します。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main> |

## クエリ例

現在のテナント内のすべてのProfileファイルとそのパラメータ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_PROFILES;
```
