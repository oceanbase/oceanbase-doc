# DBA_PROFILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのProfileファイルとそのパラメータ情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**    |    **タイプ**    | **NULL許容** |              **説明**              |
|---------------|--------------|----------------|----------------------------------|
| PROFILE       | VARCHAR2(30) | NO             | Profileファイル名                            |
| RESOURCE_NAME | VARCHAR2(32) | NO             | パラメータ名。以下を含みます：<ul><li>`FAILED_LOGIN_ATTEMPTS`</li><li>`PASSWORD_GRACE_TIME`</li><li>`PASSWORD_LIFE_TIME`</li><li>`PASSWORD_LOCK_TIME`</li><li>`PASSWORD_VERIFY_FUNCTION`</li><li>`PASSWORD_ROLLOVER_TIME`</li><li>`IDLE_TIME`：セッションの最大アイドル時間（単位：分）。V4.4.x系では、V4.4.2 BP4バージョンからサポートされています。</li></ul> |
| RESOURCE_TYPE | VARCHAR2(8)  | NO             | パラメータタイプ：<ul><li>`KERNEL`</li> <li>`PASSWORD`</li></ul>  |
| LIMIT         | VARCHAR2(128) | NO             | パラメータの制限値。`IDLE_TIME`の取り得る値は、分単位の時間、`0`、`UNLIMITED`、または`DEFAULT`です。詳細な意味については、下記の注意を参照してください。 |

## クエリ例

現在のテナント内のすべてのProfileファイルとそのパラメータ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_PROFILES;
```

クエリ結果は次のとおりです：

```shell
+----------+--------------------------+---------------+-----------------+
| PROFILE  | RESOURCE_NAME            | RESOURCE_TYPE | LIMIT           |
+----------+--------------------------+---------------+-----------------+
| DEFAULT  | IDLE_TIME                | KERNEL        | 0               |
| DEFAULT  | FAILED_LOGIN_ATTEMPTS    | PASSWORD      | UNLIMITED       |
| DEFAULT  | PASSWORD_GRACE_TIME      | PASSWORD      | UNLIMITED       |
| DEFAULT  | PASSWORD_LIFE_TIME       | PASSWORD      | UNLIMITED       |
| DEFAULT  | PASSWORD_LOCK_TIME       | PASSWORD      | 86400000000     |
| DEFAULT  | PASSWORD_VERIFY_FUNCTION | PASSWORD      | NULL            |
| DEFAULT  | PASSWORD_ROLLOVER_TIME   | PASSWORD      | DEFAULT         |
| profile1 | IDLE_TIME                | KERNEL        | DEFAULT         |
| profile1 | FAILED_LOGIN_ATTEMPTS    | PASSWORD      | 5               |
| profile1 | PASSWORD_GRACE_TIME      | PASSWORD      | DEFAULT         |
| profile1 | PASSWORD_LIFE_TIME       | PASSWORD      | 5184000000000   |
| profile1 | PASSWORD_LOCK_TIME       | PASSWORD      | 86400000000     |
| profile1 | PASSWORD_VERIFY_FUNCTION | PASSWORD      | VERIFY_FUNCTION |
+----------+--------------------------+---------------+-----------------+
13 rows in set
```

<main id="notice" type='notice'>
<h4>注意</h4>
<p><code>IDLE_TIME</code> の表示値の意味は以下のとおりです：<code>0</code> はこのパラメータが無効であることを表します。正の整数は、セッションに許可される最大アイドル時間（分）を表します。<code>UNLIMITED</code> はアイドル時間に制限がないことを表します。<code>DEFAULT</code> は <code>DEFAULT</code> プロファイルの値を継承することを表します。新しいプロファイル作成時に <code>IDLE_TIME</code> を指定しなかった場合、このパラメータの値は <code>DEFAULT</code> となり、ビューにも <code>DEFAULT</code> と表示されます。<code>DEFAULT</code> プロファイルの <code>IDLE_TIME</code> は <code>0</code> であるため、この場合実際にはこのパラメータは有効になりません。</p>
</main>
