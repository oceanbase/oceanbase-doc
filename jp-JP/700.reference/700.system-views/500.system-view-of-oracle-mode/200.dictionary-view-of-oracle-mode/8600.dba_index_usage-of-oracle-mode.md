# DBA_INDEX_USAGE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、この構成パラメータはV4.3.0バージョンから導入されました。</li> <li>V4.2.x系では、この構成パラメータはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_INDEX_USAGE`は、インデックス使用状況のデータ情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| OBJECT_ID | NUMBER | NO | インデックステーブルID |
| NAME | VARCHAR2(128) | YES | インデックステーブル名 |
| OWNER | VARCHAR2(128) | YES | データベース名 |
| TOTAL_ACCESS_COUNT | NUMBER | NO | 総アクセス回数 |
| TOTAL_EXEC_COUNT | NUMBER | NO | 総実行回数 |
| TOTAL_ROWS_RETURNED | NUMBER | NO | 総リターンされたインデックステーブル行数 |
| BUCKET_0_ACCESS_COUNT | NUMBER | NO | インデックステーブルの使用0回 |
| BUCKET_1_ACCESS_COUNT | NUMBER | NO | インデックステーブルの使用1回 |
| BUCKET_2_10_ACCESS_COUNT | NUMBER | NO | インデックステーブルの使用2～10回 |
| BUCKET_2_10_ROWS_RETURNED | NUMBER | NO | インデックステーブルからの2～10行の返却 |
| BUCKET_11_100_ACCESS_COUNT | NUMBER | NO | インデックステーブルのアクセス11～100回 |
| BUCKET_11_100_ROWS_RETURNED | NUMBER | NO | インデックステーブルからの11～100行の返却 |
| BUCKET_101_1000_ACCESS_COUNT | NUMBER | NO | インデックステーブルのアクセス101～1000回 |
| BUCKET_101_1000_ROWS_RETURNED | NUMBER | NO | インデックステーブルからの101～1000行の返却 |
| BUCKET_1000_PLUS_ACCESS_COUNT | NUMBER | NO | インデックステーブルの使用が1000回を超える |
| BUCKET_1000_PLUS_ROWS_RETURNED | NUMBER | NO | インデックステーブルからの1000行を超える返却 |
| LAST_USED | VARCHAR2(128) | NO | インデックステーブルが最後に使用された時間 |

## クエリ例

インデックス使用状況のデータ情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_INDEX_USAGE;
```
