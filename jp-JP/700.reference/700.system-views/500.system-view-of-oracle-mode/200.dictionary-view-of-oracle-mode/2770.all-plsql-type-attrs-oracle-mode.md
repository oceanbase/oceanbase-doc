# ALL_PLSQL_TYPE_ATTRS

<main id="notice" >
    <h4>説明</h4>
    <p>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。<br>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</p>
  </main>

## 機能の概要

`ALL_PLSQL_TYPE_ATTRS`は、パッケージで定義されたレコード型の全体的な情報を表示するために使用されます。
パッケージ内の型がこのビューに表示されるには、パッケージが正常にコンパイルされている必要があります。

<main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|         **フィールド名**          |     **型**     | **NULL許容** |**説明**|
|---------------------------|---|---|--------------------------------------------|
| OWNER              | VARCHAR2(128) | YES  | PL/SQL型属性の所有者名を格納します。 |
| TYPE_NAME          | VARCHAR2(136) | NO   | PL/SQL型の名前です。 |
| PACKAGE_NAME       | VARCHAR2(128) | YES  | PL/SQL型を含むパッケージ名です。 |
| ATTR_NAME          | VARCHAR2(128) | NO   | 型の属性名です。 |
| ATTR_TYPE_MOD      | VARCHAR2(7)   | NO   | 属性の型修飾子です。 |
| ATTR_TYPE_OWNER    | VARCHAR2(128) | NO   | 属性の型所有者名です。 |
| ATTR_TYPE_NAME     | VARCHAR2(136) | NO   | 属性の型名です。 |
| ATTR_TYPE_PACKAGE  | VARCHAR2(128) | NO   | 属性型を含むパッケージ名です。 |
| LENGTH             | NUMBER(38)    | NO   | 属性値の長さです。 |
| PRECISION          | NUMBER(38)    | NO   | 属性値の精度です。 |
| SCALE              | NUMBER(38)    | NO   | 属性値の小数点以下の桁数です。 |
| CHARACTER_SET_NAME | VARCHAR2(44)  | NO   | 文字セット名です。 |
| ATTR_NO            | NUMBER(38)    | NO   | 属性の順序番号です。 |
| CHAR_USED          | VARCHAR2(1)   | NO   | 文字型データ型が使用されているかどうかを示します。 |
