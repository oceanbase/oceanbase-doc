# DBA_OB_RECOVER_TABLE_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのテーブルレベルの復旧タスクに関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | ジョブID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | 親ジョブのテナントID |
| INITIATOR_JOB_ID | NUMBER(38) | NO | 親ジョブが属するJOB ID |
| START_TIMESTAMP | VARCHAR2(256) | NO | ジョブ開始時のテナント現在時間 |
| FINISH_TIMESTAMP | VARCHAR2(256) | NO | ジョブ完了時のテナント現在時間 |
| STATUS | VARCHAR2(64) | NO | ジョブステータス。<ul><li>PREPARE：ジョブ初期化段階 </li><li>RECOVERING：復旧中 </li><li>RESTORE_AUX_TENANT：復旧補助テナント </li><li>PRECHECK_IMPORT：インポート前チェック </li><li>GEN_IMPORT_JOB：インポートジョブ初期化 </li><li>IMPORTING：テーブルインポート中 </li><li>CANCELING：ジョブキャンセル中</li><li>COMPLETED：ジョブ完了 </li><li>FAILED：ジョブ失敗 </li></ul> |
| AUX_TENANT_NAME | VARCHAR2(64) | NO | 補助テナント名 |
| TARGET_TENANT_NAME | VARCHAR2(64) | NO | ターゲットテナント名 |
| IMPORT_ALL | NUMBER(38) | NO | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが`RECOVER TABLE *.*`と指定した場合にのみこの値は1となり、その他のシナリオでは値は0となる |
| DB_LIST | CLOB | YES | 完全に復旧するデータベース |
| TABLE_LIST | CLOB | YES | 復旧するテーブル |
| RESTORE_SCN | NUMBER(38) | NO | ユーザーが指定する復旧ポイント |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | ユーザーが指定する復旧ポイントのタイムスタンプ表記 |
| RESTORE_OPTION | VARCHAR2(4096) | NO | 補助テナントに依存するrestore_optionパラメータ |
| BACKUP_DEST | VARCHAR2(4096) | NO | バックアップおよびアーカイブパス |
| BACKUP_SET_LIST | CLOB | NO | データバックアップパス |
| BACKUP_PIECE_LIST | CLOB | NO | ログアーカイブパス |
| BACKUP_PASSWD | VARCHAR2(4096) | YES | バックアップセットパスワード |
| EXTERNAL_KMS_INFO | VARCHAR2(4096) | YES | ソーステナントで秘密鍵のホスティングが設定されている場合、この項目をセッション設定で指定する必要があります。 |
| REMAP_DB_LIST | CLOB | YES | 重命名されたデータベース。フォーマットは次のとおりです：`db1:new_db1, db2:newdb2` |
| REMAP_TABLE_LIST | CLOB | YES | 重命名されたテーブル。フォーマットは次のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2` |
| REMAP_TABLEGROUP_LIST | CLOB | YES | テーブルグループの再マッピングリスト。元のテーブルグループからターゲットテーブルグループへテーブルを再マッピングできます。フォーマットは次のとおりです：`tg1:new_tg1, tg2:new_tg2` |
| REMAP_TABLESPACE_LIST | CLOB | YES | テーブルスペースの再マッピングリスト。元のテーブルスペースからターゲットテーブルスペースへテーブルを再マッピングできます。フォーマットは次のとおりです：`ts1:new_ts1, ts2:new_ts2` |
| RESULT | VARCHAR2(64) | YES | テーブルレベルの復旧ジョブの結果：<ul><li>SUCCESS  </li><li>FAIL </li></ul> |
| COMMENT | CLOB | YES | 備考情報 |
| DESCRIPTION | CLOB | YES | 復旧コマンドで指定されたDESCRIPTION情報 |
