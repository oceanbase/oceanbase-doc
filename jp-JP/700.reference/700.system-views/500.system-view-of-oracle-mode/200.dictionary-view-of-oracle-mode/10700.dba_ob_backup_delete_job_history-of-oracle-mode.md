# DBA_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内で実行されたバックアップクリーンアップタスクの履歴情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | ジョブID。一意で、値は連番です。 |
| INCARNATION | NUMBER(38) | NO | 分身ID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | このJOBを開始したテナントID |
| INITIATOR_JOB_ID | NUMBER(38) | NO | このJOBを開始したテナントに属する
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | クリーンアップタスクを実行したテナントの一覧 |
| TYPE | VARCHAR2(64) | NO | クリーンアップタイプ：<ul><li>`DELETE OBSOLETE BACKUP`：期限切れクリーンアップ</li> <li>`DELETE BACKUP ALL`：パス内のすべてのバックアップまたはアーカイブデータを削除</li> <li>`DELETE BACKUPSET`：指定されたデータバックアップセットをクリーンアップ</li> <li>`DELETE ARCHIVELOG_PIECE`：指定されたログアーカイブPieceをクリーンアップ </li></ul> |
| PARAMETER | VARCHAR2(1024) | NO | クリーンアップパラメータ。異なるクリーンアップタイプの具体的なパラメータ情報を記述します |
| JOB_LEVEL | VARCHAR2(64) | NO | タスク開始レベル：<ul><li> `USER_TENANT`：ユーザーテナントが開始したタスク</li><li> `SYS_TENANT`：システムテナントが開始したタスク</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時のテナントの現在時刻 |
| END_TIMESTAMP | VARCHAR2(256) | NO | タスク終了時のテナントの現在時刻 |
| STATUS | VARCHAR2(64) | NO | タスク状態： <ul><li> `INIT`：タスクの初期化段階 </li><li> `DOING`：タスクの実行段階 </li><li> `CANCELING`：タスクがキャンセルされている段階 </li><li> `COMPLETED`：タスクが正常に実行された </li><li> `FAILED`：タスクの実行に失敗した </li><li> `CANCELED`：タスクが正常にキャンセルされた </li></ul> |
| TASK_COUNT | NUMBER(38) | YES | backup_set/pieceタスク数 |
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | backup_set/piece実行成功タスク数 |
| RESULT | NUMBER(38) | NO | エラーコード |
| COMMENT | VARCHAR2(4096) | YES | タスク実行の説明 |

## クエリ例

ユーザーテナントが自身のテナントで実行されたバックアップクリーンアップタスクの履歴情報を照会し、上位5件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOB_HISTORY WHERE ROWNUM <= 5\G
```
