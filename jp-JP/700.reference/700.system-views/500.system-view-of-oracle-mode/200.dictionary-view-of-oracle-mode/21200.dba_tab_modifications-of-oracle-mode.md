# DBA_TAB_MODIFICATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のテーブルの累積変更情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TABLE_OWNER | VARCHAR2(128) | NO | 変更されたテーブルが属するデータベース |
| TABLE_NAME | VARCHAR2(128) | NO | 変更されたテーブル名 |
| PARTITION_NAME | VARCHAR2(128) | NO | 変更されたパーティション名 |
| SUBPARTITION_NAME | VARCHAR2(128) | NO | 変更されたサブパーティション名 |
| INSERTS | NUMBER | NO | 累計挿入回数 |
| UPDATES | NUMBER | NO | 累計更新回数 |
| DELETES | NUMBER | NO | 累計削除回数 |
| TIMESTAMP | DATE | NO | テーブルの最終変更時刻 |
| TRUNCATED | VARCHAR2(3) | NO | 現在のところ実質的な意味はありません。デフォルトはNULLです。 |
| DROP_SEGMENTS | NUMBER | NO | 現在のところ実質的な意味はありません。デフォルトはNULLです。 |
