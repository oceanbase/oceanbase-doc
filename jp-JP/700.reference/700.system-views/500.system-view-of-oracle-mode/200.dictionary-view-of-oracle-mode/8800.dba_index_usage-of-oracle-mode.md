# DBA_INDEX_USAGE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.3.x系では、このビューはV4.3.0バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

`DBA_INDEX_USAGE` ビューは、インデックスの使用状況データ情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OBJECT_ID | NUMBER | NO | インデックステーブルID |
| NAME | VARCHAR2(128) | YES | インデックステーブル名 |
| OWNER | VARCHAR2(128) | YES | データベース名 |
| TOTAL_ACCESS_COUNT | NUMBER | NO | 総アクセス回数 |
| TOTAL_EXEC_COUNT | NUMBER | NO | 総実行回数 |
| TOTAL_ROWS_RETURNED | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_0_ACCESS_COUNT | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_1_ACCESS_COUNT | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_2_10_ACCESS_COUNT | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_2_10_ROWS_RETURNED | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_11_100_ACCESS_COUNT | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_11_100_ROWS_RETURNED | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_101_1000_ACCESS_COUNT | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_101_1000_ROWS_RETURNED | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_1000_PLUS_ACCESS_COUNT | NUMBER | NO | このフィールドは現在サポートされていません |
| BUCKET_1000_PLUS_ROWS_RETURNED | NUMBER | NO | このフィールドは現在サポートされていません |
| LAST_USED | VARCHAR2(128) | NO | インデックステーブルが最後に使用された時間 |

## クエリ例

インデックスの使用状況データ情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_INDEX_USAGE;
```
