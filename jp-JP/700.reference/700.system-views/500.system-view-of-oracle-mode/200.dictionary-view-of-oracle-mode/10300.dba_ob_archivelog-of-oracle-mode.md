# DBA_OB_ARCHIVELOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内の各パスにおけるログアーカイブの状態を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| ------ | ------ | ------ | ------ |
| DEST_ID | NUMBER(38) | NO | パス識別子 |
| ROUND_ID | NUMBER(38) | NO | バックアップのラウンド番号 |
| INCARNATION | NUMBER(38) | NO | Flashback Database後の化身回数 |
| DEST_NO | NUMBER(38) | NO | log_archive_dest_nを識別するための番号 |
| STATUS | VARCHAR2(64) | NO | アーカイブ状態：<ul><li>`PREPARE`：アーカイブ開始点`START_SCN`の準備中 </li> <li>`BEGINNING`：ログアーカイブの開始中 </li> <li>`DOING`：ログアーカイブ中 </li><li>`INTERRUPTED`：ログアーカイブが中断し、手動介入が必要 </li><li>`STOP`：ログアーカイブが停止 </li><li>`STOPPING`：ログアーカイブの停止中 </li><li>`SUSPENDING`：ログアーカイブが一時停止 </li><li>`SUSPEND`：ログアーカイブが一時停止 </li></ul> |
| START_SCN | NUMBER(38) | NO | バックアップ開始ポイント |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | START_SCNを時間単位に変換した表示 |
| CHECKPOINT_SCN | NUMBER(38) | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | CHECKPOINT_SCNを時間単位に変換した表示 |
| COMPATIBLE | NUMBER(38) | NO | 互換性バージョン |
| BASE_PIECE_ID | NUMBER(38) | NO | そのラウンドの最初のPIECE ID |
| USED_PIECE_ID | NUMBER(38) | NO | そのラウンドで使用されたPIECE ID |
| PIECE_SWITCH_INTERVAL | NUMBER(38) | NO | Piece切り替え間隔 |
| UNIT_SIZE   | NUMBER(38)     | NO   | ログアーカイブデータの1回の圧縮または暗号化におけるログブロックサイズ。現在このフィールドはサポートされていません |
| COMPRESSION | VARCHAR2(128)  | NO   | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを表す </li><li> lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを表す </li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを表す</li></ul>現在このフィールドはサポートされていません |
| INPUT_BYTES | NUMBER | NO | 読み取ったデータ量、単位はバイト |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | INPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| OUTPUT_BYTES | NUMBER | NO | 出力データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | OUTPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| COMPRESSION_RATIO | NUMBER | NO | 圧縮率。現在このフィールドはサポートされていません |
| DELETED_INPUT_BYTES | NUMBER(38) | NO | 削除された生データ量、単位はバイト |
| DELETED_INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | DELETED_INPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| DELETED_OUTPUT_BYTES | NUMBER(38) | NO | 削除された有効データ量、単位はバイト |
| DELETED_OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | DELETED_OUTPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| COMMENT | VARCHAR2(262144) | NO | エラーメッセージを表示するために使用 |
| PATH | VARCHAR2(2048) | NO | アーカイブパス |
