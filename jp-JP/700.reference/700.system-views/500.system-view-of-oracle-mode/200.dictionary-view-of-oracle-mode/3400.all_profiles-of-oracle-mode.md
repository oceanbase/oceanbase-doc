# ALL_PROFILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのProfileファイルとそのパラメータ情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**    |    **型**    | **NULL許容** |              **説明**               |
|---------------|--------------|----------------|-----------------------------------|
| PROFILE       | VARCHAR2(30) | NO             | Profileファイル名                             |
| RESOURCE_NAME | VARCHAR2(32) | NO             | リソースパラメータ名                             |
| RESOURCE_TYPE | VARCHAR2(8)  | NO             | リソースパラメータタイプ:<ul><li>`KERNEL`</li> <li>`PASSWORD`</li></ul>   |
| LIMIT_ON_RESOURCE | VARCHAR2(40) | NO         | リソースパラメータの制限値                           |

## クエリ例

現在ユーザーがアクセス可能なProfileファイルとそのパラメータ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_PROFILES;
```

クエリ結果は次のとおりです：

```shell
+----------+---------------+---------------+-------------------+
| PROFILE  | RESOURCE_NAME | RESOURCE_TYPE | LIMIT_ON_RESOURCE |
+----------+---------------+---------------+-------------------+
| DEFAULT  | NULL          | NULL          | NULL              |
| profile1 | NULL          | NULL          | NULL              |
+----------+---------------+---------------+-------------------+
2 rows in set
```
