# USER_POLICIES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するアクセス制御ポリシーを表示します。あるテーブルに対してアクセス制御を行う際、そのテーブルに複数のポリシーを作成できます。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | ポリシーで制御されるオブジェクトの所有者 |
| OBJECT_NAME | VARCHAR2(128) | NO | ポリシーで制御されるオブジェクトの名前 |
| POLICY_GROUP | VARCHAR2(128) | NO | ポリシーグループ名 |
| POLICY_NAME | VARCHAR2(128) | NO | ポリシー名 |
| PF_OWNER | VARCHAR2(128) | NO | ポリシー関数の所有者 |
| PACKAGE | VARCHAR2(128) | NO | ポリシー関数が含まれるパッケージ名 |
| FUNCTION | VARCHAR2(128) | NO | ポリシー関数名 |
| SEL | VARCHAR2(3) | NO | オブジェクトのSelect操作に影響するかどうか：YESまたはNO |
| INS | VARCHAR2(3) | NO | オブジェクトのInsert操作に影響するかどうか：YESまたはNO |
| UPD | VARCHAR2(3) | NO | オブジェクトのUpdate操作に影響するかどうか：YESまたはNO |
| DEL | VARCHAR2(3) | NO | オブジェクトのDelete操作に影響するかどうか：YESまたはNO |
| IDX | VARCHAR2(3) | NO | オブジェクトのIndex操作に影響するかどうか：YESまたはNO |
| CHK_OPTION | VARCHAR2(3) | NO | Insert、Update操作で更新後の値をチェックするかどうか：YESまたはNO |
| ENABLE | VARCHAR2(3) | NO | ポリシーが有効かどうか：YESまたはNO |
| STATIC_POLICY | VARCHAR2(3) | NO | 静的ポリシーかどうか：YESまたはNO |
| POLICY_TYPE | VARCHAR2(24) | NO | ポリシーのタイプ：<ul><li> STATIC  </li><li> SHARED_STATIC </li><li>CONTEXT_SENSITIVE </li><li>  SHARED_CONTEXT_SENSITIVE</li><li>DYNAMIC </li></ul>|
| LONG_PREDICATE | VARCHAR2(3) | NO | ポリシー関数が返す述語が4000を超えるかどうか |
| COMMON | VARCHAR2(3) | NO | 互換性のためのみ使用され、現在の値は常にNOです。 |
| INHERITED | VARCHAR2(3) | NO | 互換性のためのみ使用され、現在の値は常にNOです。 |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.USER_POLICIES;
```
