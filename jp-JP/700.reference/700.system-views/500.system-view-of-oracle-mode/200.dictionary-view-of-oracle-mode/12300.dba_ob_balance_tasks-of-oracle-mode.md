# DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在、このテナントで実行中のロードバランシングタスクを表示します。各テナントでは同時に複数のロードバランシングタスクが実行されている可能性がありますが、これらのタスクはすべて同一のロードバランシングジョブに属します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | ロードバランシングタスクID |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 作成日時 |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 情報更新日時 |
| TASK_TYPE | VARCHAR2(64) | NO | タスクタイプ：<ul><li>`LS_SPLIT`：ログストリームの分割  </li><li>`LS_ALTER`：ログストリーム属性の変更 </li><li>`LS_MERGE`：ログストリームのメジャーコンパクション </li><li>`LS_TRANSFER`：ログストリームTransfer </li></ul>|
| SRC_LS | NUMBER(38) | NO | ソースログストリーム（データソースから生成されるログデータストリーム） |
| DEST_LS | NUMBER(38) | NO | デスティネーションログストリーム |
| PART_LIST | CLOB | YES | パーティションリスト。ユーザーテーブルのパーティションとグローバルインデックスのパーティションを含みます |
| FINISHED_PART_LIST | CLOB | YES | 現在バランシング処理が完了したパーティションのリスト |
| PART_COUNT | NUMBER(38) | YES | パーティションリスト内のパーティション数 |
| FINISHED_PART_COUNT | NUMBER(38) | YES | 現在バランシング処理が完了したパーティション数 |
| LS_GROUP_ID | NUMBER(38) | NO | ログストリームグループID |
| STATUS | VARCHAR2(64) | NO | タスクのステータス：<ul><li>`INIT`：タスクの作成  </li><li>`CREATE_LS`：ログストリームの作成 </li><li>`ALTER_LS`：ログストリーム属性の変更 </li><li>`SET_LS_MERGING`：ログストリームのメジャーコンパクション </li><li>`DROP_LS`：ログストリームの削除 </li><li>`COMPLETED`：タスクの実行が成功しました </li><li>`CANCELED`：タスクがキャンセルされました </li></ul>|
| PARENT_LIST | VARCHAR2(1024) | YES | 親タスクリスト |
| CHILD_LIST | VARCHAR2(1024) | YES | 子タスクリスト |
| CURRENT_TRANSFER_TASK_ID | NUMBER(38) | NO | 現在のロードバランシングタスクによってトリガーされたTransferタスクID |
| JOB_ID | NUMBER(38) | NO | 現在のタスクが属するJob ID |
| COMMENT | CLOB | YES | コメント情報 |
| BALANCE_STRATEGY         | VARCHAR2(64)   | YES | Balance Taskに対応するバランシング戦略：<ul><li>`LS balance by migrate`：移行バランシング  </li><li>`LS balance by alter`：ログストリーム属性変更によるバランシング </li><li>`LS balance by expand`：拡張バランシング </li><li>`LS balance by shrink`：縮小バランシング </li><li>`partition balance`：パーティションバランシング </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、このフィールドはV4.3.2バージョンから導入されました。V4.2.x系では、このフィールドはV4.2.4バージョンから導入されました。</p></main>   |
