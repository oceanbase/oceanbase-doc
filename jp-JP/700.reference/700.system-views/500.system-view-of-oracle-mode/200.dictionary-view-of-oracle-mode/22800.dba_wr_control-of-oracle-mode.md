# DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

WR関連の設定情報を表示します。

## フィールドの説明

| **項目** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID <ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| SNAP_INTERVAL | VARCHAR2(64) | NO | スナップショット間の間隔設定。読みやすいように `DD HH:mm:SS` の形式を使用します |
| RETENTION | VARCHAR2(64) | NO | 各スナップショットの保持時間。読みやすいように `DD HH:mm:SS` の形式を使用します |
| TOPNSQL | NUMBER(38) | NO | 保存されるトップNのSQL |
