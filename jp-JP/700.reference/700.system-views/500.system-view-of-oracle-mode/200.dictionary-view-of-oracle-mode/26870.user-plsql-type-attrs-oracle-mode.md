# USER_PLSQL_TYPE_ATTRS

<main id="notice" >
    <h4>説明</h4>
    <p>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。<br>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</p>
  </main>

## 機能の概要

`USER_PLSQL_TYPE_ATTRS`は、現在のユーザーパッケージで定義されたレコード型の全体的な情報を表示するために使用されます。パッケージが正常にコンパイルされている場合にのみ、そのパッケージ内の型がこのビューに表示されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|         **フィールド名**          |     **型**     | **NULL許容** |**説明**|
|---------------------------|---|---|--------------------------------------------|
| TYPE_NAME          | VARCHAR2(136) | NO   | PL/SQL型の名前。 |
| PACKAGE_NAME       | VARCHAR2(128) | YES  | PL/SQL型を含むパッケージ名。 |
| ATTR_NAME          | VARCHAR2(128) | NO   | 型の属性名。 |
| ATTR_TYPE_MOD      | VARCHAR2(7)   | NO   | 属性の型修飾子。 |
| ATTR_TYPE_OWNER    | VARCHAR2(128) | NO   | 属性の型所有者名。 |
| ATTR_TYPE_NAME     | VARCHAR2(136) | NO   | 属性の型名。 |
| ATTR_TYPE_PACKAGE  | VARCHAR2(128) | NO   | 属性型を含むパッケージ名。 |
| LENGTH             | NUMBER(38)    | NO   | 属性値の長さ。 |
| PRECISION          | NUMBER(38)    | NO   | 属性値の精度。 |
| SCALE              | NUMBER(38)    | NO   | 属性値の小数点以下の桁数。 |
| CHARACTER_SET_NAME | VARCHAR2(44)  | NO   | 文字セット名。 |
| ATTR_NO            | NUMBER(38)    | NO   | 属性の順序番号。 |
| CHAR_USED          | VARCHAR2(1)   | NO   | 文字型データ型が使用されているかどうかを示すために使用されます。 |

## クエリ例

```sql
obclient> SELECT * FROM USER_PLSQL_TYPE_ATTRS;
```
