# USER_PLSQL_TYPE_ATTRS

<main id="notice" >
    <h4>説明</h4>
    <p>このビューはV4.2.5バージョンから導入されました。パッケージが正常にコンパイルされた場合にのみ、そのパッケージ内の型がこのビューに表示されます。</p>
  </main>

## 機能の概要

`USER_PLSQL_TYPE_ATTRS`ビューは、現在のユーザーが所有するパッケージで定義されているレコード型の全体的な情報を表示します。

<main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|         **フィールド名**          |     **タイプ**     | **NULLを許容するか** |**説明**|
|---------------------------|---|---|--------------------------------------------|
| TYPE_NAME          | VARCHAR2(136) | NO   | PL/SQL型の名前。 |
| PACKAGE_NAME       | VARCHAR2(128) | YES  | PL/SQL型を含むパッケージの名前。 |
| ATTR_NAME          | VARCHAR2(128) | NO   | 型のプロパティの名前。 |
| ATTR_TYPE_MOD      | VARCHAR2(7)   | NO   | プロパティの型修飾子。 |
| ATTR_TYPE_OWNER    | VARCHAR2(128) | NO   | プロパティの型の所有者の名前。 |
| ATTR_TYPE_NAME     | VARCHAR2(136) | NO   | プロパティの型の名前。 |
| ATTR_TYPE_PACKAGE  | VARCHAR2(128) | NO   | プロパティ型を含むパッケージの名前。 |
| LENGTH             | NUMBER(38)    | NO   | プロパティ値の長さ。 |
| PRECISION          | NUMBER(38)    | NO   | プロパティ値の精度。 |
| SCALE              | NUMBER(38)    | NO   | プロパティ値のスケール。 |
| CHARACTER_SET_NAME | VARCHAR2(44)  | NO   | 文字セットの名前。 |
| ATTR_NO            | NUMBER(38)    | NO   | プロパティの順序番号。 |
| CHAR_USED          | VARCHAR2(1)   | NO   | 文字データ型を使用するかどうかを示します。 |

## クエリ例

現在のユーザーが所有するパッケージで定義されているレコードタイプの全体的な情報を確認します。

```sql
obclient> SELECT * FROM SYS.USER_PLSQL_TYPE_ATTRS;
```
