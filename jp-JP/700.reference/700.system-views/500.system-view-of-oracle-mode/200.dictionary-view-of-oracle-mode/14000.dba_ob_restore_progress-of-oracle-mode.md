# DBA_OB_RESTORE_PROGRESS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントで進行中のリカバリタスクを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | リカバリが属するjob_idで、1回のリカバリタスクに対応します |
| RESTORE_TENANT_NAME | VARCHAR2(4096) | NO | 復元対象のテナント名 |
| RESTORE_TENANT_ID | NUMBER(38) | NO | 復元対象のテナントID |
| BACKUP_TENANT_NAME | VARCHAR2(4096) | NO | バックアップのソーステナント名 |
| BACKUP_TENANT_ID | VARCHAR2(4096) | NO | バックアップのソーステナントID |
| BACKUP_CLUSTER_NAME | VARCHAR2(4096) | NO | バックアップのソースクラスタ名 |
| BACKUP_DEST | VARCHAR2(4096) | NO | バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します |
| RESTORE_OPTION | VARCHAR2(4096) | NO | リカバリオプション。リカバリ開始時にユーザーが指定した`restore_option` |
| RESTORE_SCN | NUMBER(38) | NO | ユーザーが指定したリカバリポイント |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | ユーザーが指定したリカバリポイントのタイムスタンプ表記 |
| STATUS | VARCHAR2(4096) | NO | リカバリ状態：システムテナントのリカバリタスクと復元されるテナントのリカバリタスクの状態が一致しません。<br>システムテナント：<ul><li>`CREATE_TENANT`：テナントの作成。この段階でシステムテナントは復元対象のテナントを作成します </li> <li>`WAIT_TENANT_RESTORE_FINISH`：復元対象のテナントのリカバリ終了を待機 </li> <li>`RESTORE_SUCCESS`：テナントのリカバリ成功 </li> <li> `RESTORE_FAIL`：テナントのリカバリ失敗 </li></ul> <br>復元対象のテナント：<ul><li>`RESTORING`：テナントデータのリカバリ中 </li> <li>`RESTORE_SUCCESS`：リカバリ成功 </li> <li>`RESTORE_FAIL`：リカバリ失敗 </li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | リカバリタスク開始時のタイムスタンプ |
| BACKUP_SET_LIST | VARCHAR2(4096) | NO | リカバリに依存するデータバックアップセットパスのリスト。バックアップセット間は`,`で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`   |
| BACKUP_PIECE_LIST | VARCHAR2(4096) | NO | リカバリに依存するログアーカイブピースパスのリスト。ピース間は`,`で区切ります。例：`file:///data/nfs/backup/archive/piece_d1001r1p1,file:///data/nfs/backup/archive/piece_d1001r2p2`  |
| RECOVER_SCN                      | NUMBER(38)     | NO   | ログのリカバリポイント。システムテナントの場合、このフィールドの値は`NULL`です <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xの他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_SCN_DISPLAY              | TIMESTAMP(9)   | NO   | ログのリカバリポイントのタイムスタンプ表記。システムテナントの場合、このフィールドの値は`NULL`です  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xの他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RECOVER_PROGRESS                 | NUMBER         | NO   | ログ復旧の進捗状況。結果は小数点以下2桁に四捨五入されます。例えば、`87.65` と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TABLET_COUNT                     | NUMBER(38)     | NO   | 復旧待ちのTabletの総数。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| FINISH_TABLET_COUNT              | NUMBER(38)     | NO   | 復旧が完了したTabletの総数。システムテナントの場合、このフィールドの値は `NULL` です。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| RESTORE_PROGRESS                 | NUMBER         | NO   | データ復旧の進捗状況。結果は小数点以下2桁に四捨五入されます。例えば、`87.65` と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は `NULL` です。 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.1バージョンでは、このフィールドはV4.2.1 BP7バージョンから導入されました。</li> <li>V4.2.xのその他のバージョンでは、このフィールドはV4.2.3バージョンから導入されました。</li></ul> </main> |
| TOTAL_BYTES          | NUMBER(38)     | NO   | 復旧したデータの総バイト数 |
| TOTAL_BYTES_DISPLAY  | VARCHAR2(42)   | NO   | ストレージ容量単位で表示される復旧したデータの総バイト数 |
| FINISH_BYTES         | NUMBER(38)     | NO   | 完了した復旧のバイト数。現行バージョンでは、この値は常に0です |
| FINISH_BYTES_DISPLAY | VARCHAR2(42)   | NO   | ストレージ容量単位で表示される復旧したデータの総バイト数。現行バージョンでは、この値は常に0です |
| DESCRIPTION          | VARCHAR2(4096) | NO   | 復旧コマンドで指定された `DESCRIPTION` 情報 |
