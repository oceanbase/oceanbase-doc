# DBA_RSRC_PLANS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

`DBA_RSRC_PLANS`ビューは、システムが定義するすべてのリソース管理計画を記録するために使用されます。

## フィールドの説明

|           フィールド名            |       タイプ       | NULL値を許容するか |                         説明                         |
|---------------------------|----------------|------------|----------------------------------------------------|
| PLAN_ID                   | NUMBER         | NO         | リソース計画のID。                                          |
| PLAN                      | VARCHAR2(128)  | NO         | リソース計画名。                                             |
| NUM_PLAN_DIRECTIVES       | NUMBER         | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。 |
| CPU_METHOD                | VARCHAR2(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| MGMT_METHOD               | VARCHAR2(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| ACTIVE_SESS_POOL_MTH      | VARCHAR2(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| PARALLEL_DEGREE_LIMIT_MTH | VARCHAR2(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| QUEUING_MTH               | VARCHAR2(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| SUB_PLAN                  | VARCHAR2(3)    | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| COMMENTS                  | VARCHAR2(2000) | YES        | リソース計画の備考情報。                                         |
| STATUS                    | VARCHAR2(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |
| MANDATORY                 | VARCHAR2(3)    | NO         | 互換性のためにのみ使用され、現在の値は固定で`NULL`です。                               |

## クエリ例

ユーザーテナントは、システム定義のすべてのリソース管理計画を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_RSRC_PLANS;
```

クエリ結果は次のとおりです：

```shell
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
| PLAN_ID | PLAN    | NUM_PLAN_DIRECTIVES | CPU_METHOD | MGMT_METHOD | ACTIVE_SESS_POOL_MTH | PARALLEL_DEGREE_LIMIT_MTH | QUEUING_MTH | SUB_PLAN | COMMENTS | STATUS | MANDATORY |
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
|    NULL | daytime |                NULL | NULL       | NULL        | NULL                 | NULL                      | NULL        | NULL     | TPFirst  | NULL   | NULL      |
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
1 row in set
```
