# DBA_OB_TABLE_LOCATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルやパーティションの場所を表示します。対象となるのは、システムテーブル、ユーザーテーブル、インデックステーブルなどです。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DATABASE_NAME | VARCHAR2(128) | NO | データベース名 |
| TABLE_NAME | VARCHAR2(256) | NO | テーブル名 |
| TABLE_ID | NUMBER(38) | NO | テーブルID |
| TABLE_TYPE | VARCHAR2(13) | NO | テーブルタイプ：<ul><li>USER TABLE：ユーザーテーブル </li><li>SYSTEM TABLE：システムテーブル、システムが作成したテーブル </li><li>INDEX：インデックステーブル </li><li>LOB AUX TABLE：LOB補助テーブル、システムが作成したテーブルで、LOB列の実装を補助するために使用されます</li></ul> |
| PARTITION_NAME | VARCHAR2(64) | NO | パーティション名。非パーティションテーブルの場合はNULLを返します |
| SUBPARTITION_NAME | VARCHAR2(64) | NO | サブパーティション名。サブパーティションが存在しない場合はNULLを返します |
| INDEX_NAME | VARCHAR2(1024) | NO | インデックステーブルの場合はその名前を表示し、それ以外の場合はNULLを返します |
| DATA_TABLE_ID | NUMBER | NO | インデックステーブルまたはLOB補助テーブルの場合は、それらが属する親テーブルのIDを表示します。それ以外の場合はNULLを返します |
| TABLET_ID | NUMBER(38) | NO | TABLET ID |
| LS_ID | NUMBER | NO | オブジェクトが存在するログストリーム |
| ZONE | VARCHAR2(128) | NO | レプリカが存在するゾーン  |
| SVR_IP | VARCHAR2(46) | NO | レプリカのIPアドレス |
| SVR_PORT | NUMBER | NO | レプリカのポート番号 |
| ROLE | VARCHAR2(8) | NO | レプリカのロール |
| REPLICA_TYPE | VARCHAR2(18) | NO | ログストリームレプリカタイプ：<ul><li>`FULL`：フル機能レプリカ</li> <li>READONLY：読み取り専用レプリカ</li> <li>`COLUMNSTORE`：カラムストアレプリカ</li></ul>  |
| DUPLICATE_SCOPE | VARCHAR2(7) | NO | このテーブルがレプリケーションテーブルかどうかを示します。値は以下の通りです：<ul><li>`CLUSTER`：レプリケーションテーブル  </li><li>`NONE`：通常のテーブル </li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| DUPLICATE_READ_CONSISTENCY | varchar(6) | NO | レプリケーションテーブルのスタンバイレプリカの読み取り一貫性制約を示します。値は以下の通りです：<ul><li>`NONE`：非レプリケーションテーブルを示します。このプロパティは意味がありません。</li><li>`STRONG`：レプリケーションテーブルのスタンバイレプリカが強整合性読み取りをサポートすることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>|
| OBJECT_ID | NUMBER(38) | NO | パーティションに対応するオブジェクトID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| TABLEGROUP_NAME | VARCHAR2(128) | NO | テーブルに対応するTable Groupの名前<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| TABLEGROUP_ID | NUMBER(38) | NO | テーブルに対応するTable GroupのID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| SHARDING | VARCHAR2(20) | NO | テーブルに対応するTable GroupのShardingプロパティ（均等モード）<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| SCOPE    | VARCHAR2(20) | YES | テーブルグループの`SCOPE`プロパティ。値は以下の通りです：<ul><li>`SERVER`：すべてのパーティショングループのリーダーが同一ノード上に分散していることを示します。 </li><li>`ZONE`：すべてのパーティショングループのリーダーが同一ゾーン内に分散していることを示します。 </li><li>`CLUSTER`：すべてのパーティショングループのリーダーがクラスタ内の各ノードに分散していることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>|
| INDEX_TYPE                 | VARCHAR2(6)   | NO   | インデックステーブルのインデックスの`GLOBAL`/`LOCAL`プロパティ情報を表示します。値は以下の3種類です：<ul><li>`NULL`：非インデックステーブルを示します。</li><li>`GLOBAL`：グローバルインデックスを示します。`INDEX_TYPE_NORMAL_GLOBAL`、INDEX_TYPE_UNIQUE_GLOBAL`、`INDEX_TYPE_SPATIAL_GLOBAL`を含みます。</li><li>`LOCAL`：ローカルインデックスを示します。`INDEX_TYPE_NORMAL_LOCAL`、`INDEX_TYPE_UNIQUE_LOCAL`、`INDEX_TYPE_PRIMARY`、`INDEX_TYPE_DOMAIN_CTXCAT`、`INDEX_TYPE_NORMAL_GLOBAL_LOCAL_STORAGE`、`INDEX_TYPE_UNIQUE_GLOBAL_LOCAL_STORAGE`、`INDEX_TYPE_SPATIAL_LOCAL`、`INDEX_TYPE_SPATIAL_GLOBAL_LOCAL_STORAGE`を含みます。</li></ul> <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.1バージョンから導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP2バージョンから導入されました。</li></ul></main>     |
