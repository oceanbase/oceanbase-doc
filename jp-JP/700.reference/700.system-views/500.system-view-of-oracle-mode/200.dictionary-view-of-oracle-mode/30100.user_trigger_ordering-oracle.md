# USER_TRIGGER_ORDERING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが持つトリガーのソートを表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| TRIGGER_NAME | VARCHAR2(128) | NO | トリガー名 |
| REFERENCED_TRIGGER_OWNER | VARCHAR2(128) | NO | 引用されるトリガーの所有者 |
| REFERENCED_TRIGGER_NAME | VARCHAR2(128) | NO | 引用されるトリガー名 |
| ORDERING_TYPE | VARCHAR2(8) | NO | ソートのタイプ |

## クエリ例

現在のユーザーが持つすべてのトリガーのソートを確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.USER_TRIGGER_ORDERING;
```

クエリ結果は次のとおりです：

```shell
+------------------+--------------------------+-------------------------+---------------+
| TRIGGER_NAME     | REFERENCED_TRIGGER_OWNER | REFERENCED_TRIGGER_NAME | ORDERING_TYPE |
+------------------+--------------------------+-------------------------+---------------+
| TRG_AUDIT_DETAIL | SYS                      | TRG_AUDIT_BASE          | FOLLOWS       |
+------------------+--------------------------+-------------------------+---------------+
1 row in set
```
