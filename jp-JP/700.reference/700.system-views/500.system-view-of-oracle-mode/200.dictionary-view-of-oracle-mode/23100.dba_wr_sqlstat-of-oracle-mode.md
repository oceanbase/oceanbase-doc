# DBA_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `DBA_WR_SQLSTAT` は、テナントで実行されたSQLの基本的なパフォーマンス統計データを表示するために使用されます。ここで、`_DELTA` を含む列は、前回のWRスナップショットから現在までの統計値の増分を示しています。
