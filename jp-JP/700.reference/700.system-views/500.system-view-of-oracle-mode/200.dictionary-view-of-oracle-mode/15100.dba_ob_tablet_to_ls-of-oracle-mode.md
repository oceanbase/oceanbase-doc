# DBA_OB_TABLET_TO_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのTabletリストと、それぞれのTabletが属するログストリーム情報を表示します。

## フィールドの説明

|   フィールド名    |   タイプ   | NULL値を許容するか |        説明        |
|-----------|--------|------------|------------------|
| TABLET_ID | NUMBER | NO         | TABLET ID        |
| LS_ID     | NUMBER | NO         | TABLETが所属するログストリームID |

## クエリ例

ユーザーテナントが自身のテナントにおけるログストリーム1001のTabletリスト情報を照会し、上位5件を表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLET_TO_LS WHERE LS_ID=1001 AND ROWNUM <= 5;
```

クエリ結果は以下のとおりです：

```shell
+-----------+-------+
| TABLET_ID | LS_ID |
+-----------+-------+
|    200004 |  1001 |
|    200005 |  1001 |
|    200006 |  1001 |
|    200007 |  1001 |
|    200008 |  1001 |
+-----------+-------+
5 rows in set
```
