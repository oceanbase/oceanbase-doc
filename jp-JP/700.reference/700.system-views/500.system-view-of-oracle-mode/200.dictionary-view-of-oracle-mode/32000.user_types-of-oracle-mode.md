# USER_TYPES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するユーザー定義型を一覧表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|     **フィールド名**     |    **型**    | **NULL許容** |          **説明**          |
|------------------|--------------|----------------|--------------------------|
| TYPE_NAME        | VARCHAR2(64) | NO             | 型名                      |
| TYPE_OID         | NUMBER(38)   | NO             | 型OID                   |
| TYPECODE         | VARCHAR2(10) | NO             | オブジェクトのタイプを表す。例：OBJECT、COLLなど |
| ATTRIBUTES       | NUMBER(38)   | NO             | 型が含む属性数                 |
| METHODS          | NUMBER(38)   | NO             | 型が含むメソッド数                 |
| PREDEFINED       | CHAR(2)      | NO             | システムで事前定義された型かどうか               |
| INCOMPLETE       | CHAR(2)      | NO             | 不完全な型かどうか。名前のみでメソッドや属性がない場合 |
| FINAL            | CHAR(3)      | NO             | 継承できないかどうか                  |
| INSTANTIABLE     | CHAR(3)      | NO             | 実装可能かどうか                   |
| SUPERTYPE_OWNER  | VARCHAR2(30) | NO             | 親型の所有者                  |
| SUPERTYPE_NAME   | VARCHAR2(30) | NO             | 親型名                     |
| LOCAL_ATTRIBUTES | NUMBER(38)   | NO             | ローカル属性数                    |
| LOCAL_METHODS    | NUMBER(38)   | NO             | ローカルメソッド数                    |
| TYPEID           | NUMBER(38)   | YES            | このフィールドは現在サポートされておらず、デフォルトでNULLに設定されています |
