# DBA_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_WR_SQLSTAT`は、このテナントで実行されたSQLの基本的なパフォーマンス統計データを表示するために使用されます。その中で、`_DELTA`を含む列は、前回のWRスナップショットから現在までの統計値の増分を示します。
