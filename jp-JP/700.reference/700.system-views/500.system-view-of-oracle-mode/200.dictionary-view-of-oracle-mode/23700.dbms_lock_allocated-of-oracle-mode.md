# DBMS_LOCK_ALLOCATED

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

申請済みで期限切れになっていない `DBMS_LOCK` 情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| NAME       | VARCHAR2(128)                     | NO   | ロック名、Primary Key |
| LOCKID     | NUMBER(38)                        | NO   | ロックID |
| EXPIRATION | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | ロックの有効期限 |

## クエリ例

現在のテナント配下で申請済みかつ期限切れになっていない `DBMS_LOCK` 情報を確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.DBMS_LOCK_ALLOCATED;
```

クエリ結果は次のとおりです：

```shell
+--------+------------+------------------------------+
| NAME   | LOCKID     | EXPIRATION                   |
+--------+------------+------------------------------+
| test01 | 1074054503 | 08-MAY-25 03.40.32.552443 PM |
+--------+------------+------------------------------+
1 row in set
```
