# ALL_INDEXES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

ALL_INDEXESは、ユーザーがアクセス可能なすべてのテーブルのインデックスに含まれる列情報を確認するために使用します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>
