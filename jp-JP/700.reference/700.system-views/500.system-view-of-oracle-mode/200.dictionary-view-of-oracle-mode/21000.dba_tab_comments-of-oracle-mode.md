# DBA_TAB_COMMENTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのテーブルとビューのコメントを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|  **フィールド名**  |     **型**     | **NULL許容** |  **説明**  |
|------------|----------------|----------------|----------|
| OWNER      | VARCHAR2(128)  | NO             | テーブルやビューの所有者 |
| TABLE_NAME | VARCHAR2(128)  | NO             | テーブルやビューの名前  |
| TABLE_TYPE | VARCHAR2(11)   | NO             | オブジェクトタイプ     |
| COMMENTS   | VARCHAR2(4000) | NO             | オブジェクトのコメント     |

## クエリ例

現在のテナント内のテーブル `STUDENT` のコメント情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_TAB_COMMENTS WHERE TABLE_NAME='STUDENT';
```

実行結果は次のとおりです：

```shell
+-------+------------+------------+---------------------------+
| OWNER | TABLE_NAME | TABLE_TYPE | COMMENTS                  |
+-------+------------+------------+---------------------------+
| SYS   | STUDENT    | TABLE      | student information table |
+-------+------------+------------+---------------------------+
1 row in set
```
