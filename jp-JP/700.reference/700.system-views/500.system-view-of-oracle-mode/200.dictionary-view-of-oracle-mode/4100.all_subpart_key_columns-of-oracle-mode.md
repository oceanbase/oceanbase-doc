# ALL_SUBPART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーがアクセス可能なすべてのパーティションオブジェクトにおいて、サブパーティションキーを含む列を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|              **フィールド名**          |     **タイプ**   | **NULL値を許容するか** |         **説明**                   |
|------------------------------------|----------------|----------------|----------------------------------------|
| OWNER                              | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの所有者                                  |
| NAME                               | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前                                   |
| OBJECT_TYPE                        | CHAR(5)        | NO             | パーティションオブジェクトのタイプ：<ul><li>TABLE </li><li>INDEX </li></ul>   |
| COLUMN_NAME                        | VARCHAR2(4000) | NO             | 列の名前                                          |
| COLUMN_POSITION                    | NUMBER         | NO             | パーティションキー内の列の位置                                     |
| COLLATED_COLUMN_ID                 | NUMBER         | NO             | 現在このフィールドはサポートされておらず、現在このフィールドのデフォルト値はNULLです                        |

## クエリ例

現在のユーザーがアクセス可能なパーティションテーブル`TBL2_F_RL`において、サブパーティションキーを含む列を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_SUBPART_KEY_COLUMNS WHERE NAME='TBL2_F_RL';
```

クエリ結果は次のとおりです：

```shell
+-------+-----------+-------------+-------------+-----------------+--------------------+
| OWNER | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-------+-----------+-------------+-------------+-----------------+--------------------+
| SYS   | TBL2_F_RL | TABLE       | COL2        |               1 |               NULL |
+-------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
