# DBA_CONS_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30から導入されました。</p>
</main>

## 機能の概要

すべてのテーブルの制約に含まれる列情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|    **フィールド名**     |     **型**     | **NULL許容** |  **説明**  |
|-----------------|----------------|----------------|----------|
| OWNER           | VARCHAR2(128)  | NO             | 约束の所有者   |
| CONSTRAINT_NAME | VARCHAR2(128)  | NO             | 约束名     |
| TABLE_NAME      | VARCHAR2(128)  | NO             | 约束が存在するテーブル名 |
| COLUMN_NAME     | VARCHAR2(4000) | NO             | 约束で指定されている列名   |
| POSITION        | NUMBER         | NO             | 列が制約内で占める位置 |

## クエリ例

テーブル `TBL3` の制約に含まれる列情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_CONS_COLUMNS WHERE TABLE_NAME='TBL3';
```

クエリ結果は次のとおりです：

```shell
+-------+----------------------------+------------+-------------+----------+
| OWNER | CONSTRAINT_NAME            | TABLE_NAME | COLUMN_NAME | POSITION |
+-------+----------------------------+------------+-------------+----------+
| SYS   | TBL3_OBPK_1744012420113641 | TBL3       | COL1        |        1 |
+-------+----------------------------+------------+-------------+----------+
1 row in set
```
