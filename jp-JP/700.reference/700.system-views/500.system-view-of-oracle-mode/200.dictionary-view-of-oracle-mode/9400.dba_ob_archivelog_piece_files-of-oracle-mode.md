# DBA_OB_ARCHIVELOG_PIECE_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのバックアップセット内のピースの状態を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | パス番号。システムは設定された各パスに一意のIDを割り当てます |
| ROUND_ID | NUMBER(38) | NO | 完全なclogバックアップデータストリームのラウンドを識別するために使用されます |
| PIECE_ID | NUMBER(38) | NO | バックアップログラムのID |
| INCARNATION | NUMBER(38) | NO | Flashback Database後の分身回数を表します |
| DEST_NO | NUMBER(38) | NO | log_archive_dest_nを識別します。例えば、log_archive_destのdest_noは0、log_archive_dest_1のdest_noは1などです |
| STATUS | VARCHAR2(64) | NO | Pieceの状態：<ul><li>ACTIVE：現在アクティブなPiece</li><li>FREEZING：凍結中のPiece</li><li>FROZEN：凍結済みのPiece。この状態以降、Pieceの状態は変更されません</li></ul> |
| START_SCN | NUMBER(38) | NO | Piece開始ポイント |
| START_SCN_DISPLAY | TIMESTAMP(9) | NO | START_SCNを時間単位に換算した表示 |
| CHECKPOINT_SCN | NUMBER(38) | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | TIMESTAMP(9) | NO | CHECKPOINT_SCNを時間単位に換算した表示 |
| MAX_SCN | NUMBER(38) | NO | 最大アーカイブポイント |
| END_SCN | NUMBER(38) | NO | Pieceの理論上の終了ポイント |
| COMPATIBLE  | NUMBER(38) | NO | ログアーカイブの互換バージョン番号 |
| UNIT_SIZE   | NUMBER(38)     | NO   | ログアーカイブデータの1回あたりの圧縮または暗号化のログブロックサイズ。現在このフィールドはサポートされていません |
| COMPRESSION | VARCHAR2(128)  | NO   |  圧縮アルゴリズム：<ul><li> none：圧縮しないことを表す </li><li> lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを表す </li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを表す</li></ul>現在このフィールドはサポートされていません   |
| INPUT_BYTES | NUMBER(38) | NO | 生データ量、単位はバイト |
| INPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | INPUT_BYTESを単位に換算した表示 |
| OUTPUT_BYTES | NUMBER(38) | NO | 暗号化・圧縮後の有効データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | VARCHAR2(42) | NO | OUTPUT_BYTESを単位に換算した表示 |
| COMPRESSION_RATIO | NUMBER | NO | 圧縮率 |
| FILE_STATUS | VARCHAR2(64) | NO | バックアップログラムのファイル状態：<ul><li>AVAILABLE：有効なバックアップであり、復旧に使用できることを表す</li><li>COPYING：ログファイルがバックアップ中であることを表す</li><li>INCOMPLETE：ログファイルが部分的にコピーされていることを表す。これは定期的なバックアップログラムの場合に限られます。このCopyのcheckpoint_tsは元のバックアップのcheckpoint_tsより小さく、checkpoint_ts以前の復旧に使用できます</li><li>DELETING：ログファイルが削除中であることを表す</li><li>EXPIRED：バックアップファイルが無効であることを表す</li><li>BROKEN：バックアップファイルが不完全であり、使用できないことを表す</li><li>DELETED：ログファイルが削除されたことを表す </li></ul> |
| PATH | VARCHAR2(2048) | NO | アーカイブパス |
