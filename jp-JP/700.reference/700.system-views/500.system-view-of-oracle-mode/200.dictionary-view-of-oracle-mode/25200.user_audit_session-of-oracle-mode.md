# USER_AUDIT_SESSION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`USER_AUDIT_SESSION` ビューは、現在のユーザーに関連する接続および切断の監査追跡レコードを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## クエリ例

現在のユーザーに関する接続および切断(`CONNECT` と `DISCONNECT`)の監査トレースエントリを確認します。

```shell
obclient [SYS]> SELECT USERNAME, USERHOST, TIMESTAMP, ACTION_NAME FROM SYS.USER_AUDIT_SESSION;
```
