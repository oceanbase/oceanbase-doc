# DBA_SUBPART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内にあるすべてのパーティションテーブルのサブパーティションに関するヒストグラム情報を表示します。

## フィールド説明

|           フィールド名            |       型        | NULL許容   |      説明       |
|---------------------------|----------------|------------|---------------|
| OWNER                     | VARCHAR2(128)  | NO         | ヒストグラム所有者ユーザー      |
| TABLE_NAME                | VARCHAR2(128)  | NO         | ヒストグラムが属するテーブル名       |
| SUBPARTITION_NAME         | VARCHAR2(128)  | NO         | ヒストグラムが属するサブパーティション名    |
| COLUMN_NAME               | VARCHAR2(128)  | NO         | ヒストグラムが属する列名       |
| ENDPOINT_NUMBER           | NUMBER         | NO         | Bucket累積頻度  |
| ENDPOINT_VALUE            | NUMBER         | NO         | Bucket端点正規化値 |
| ENDPOINT_ACTUAL_VALUE     | VARCHAR2(4000) | NO         | Bucket端点値    |
| ENDPOINT_ACTUAL_VALUE_RAW | VARCHAR2(4000) | NO         | Bucket端点バイナリ値 |
| ENDPOINT_REPEAT_COUNT     | NUMBER         | NO         | Bucket端点値の頻度 |

## クエリ例

このテナントのパーティションテーブル `T_SUBPART` のサブパーティションのヒストグラム情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_SUBPART_HISTOGRAMS WHERE TABLE_NAME ='T_SUBPART';
```
