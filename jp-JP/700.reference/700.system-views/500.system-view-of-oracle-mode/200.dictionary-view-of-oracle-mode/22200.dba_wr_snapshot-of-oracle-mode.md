# DBA_WR_SNAPSHOT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントの`SNAPSHOT`情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | NUMBER(38) | NO | クラスタID |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| SNAP_ID | NUMBER(38) | NO | スナップショットID |
| SVR_IP | VARCHAR2(46) | NO | ノードIPアドレス |
| SVR_PORT | NUMBER(38) | NO | ノードポート |
| BEGIN_INTERVAL_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | スナップショット開始時間。タイムスタンプはミリ秒単位で正確です |
| END_INTERVAL_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | スナップショット終了時間。タイムスタンプはミリ秒単位で正確です |
| SNAP_FLAG | NUMBER(38) | YES | スナップショットのトリガー理由 |
| STARTUP_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | プロセス起動時間。タイムスタンプはミリ秒単位で正確です |

## クエリ例

このテナントの`SNAPSHOT`情報を照会し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_SNAPSHOT WHERE ROWNUM <= 1\G
```
