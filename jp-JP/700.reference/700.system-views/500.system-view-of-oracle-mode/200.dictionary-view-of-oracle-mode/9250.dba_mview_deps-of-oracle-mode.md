# DBA_MVIEW_DEPS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.4.x系では、このビューはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このビューはV4.3.5 BP2バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

このビューは、現在のテナントのマテリアライズドビューの依存関係を表示するために使用されます。

## フィールドの説明

| **フィールド名** |   **型**  | **NULL許容** | **説明** |
|-------------|---------------|---------------------|---------|
| MVIEW_OWNER | VARCHAR2(128) | YES  | マテリアライズドビュー所有者名。|
| MVIEW_NAME  | VARCHAR2(256) | YES  | マテリアライズドビュー名。|
| DEP_OWNER   | VARCHAR2(128) | YES  | 依存オブジェクト所有者名。|
| DEP_NAME    | VARCHAR2(256) | YES  | 依存オブジェクト名。|
| DEP_TYPE    | VARCHAR2(12)  | NO   | 依存オブジェクトタイプ：<ul><li>`MV`：マテリアライズドビュー</li><li>`TABLE`：通常テーブル</li><li>`EXTERNAL TABLE`：外部テーブル</li></ul>|

## クエリ例

現在のテナントのマテリアライズドビューの依存関係を確認します。

```shell
obclient> SELECT * FROM sys.DBA_MVIEW_DEPS;
```

実行結果は次のとおりです：

```shell
+-------------+------------------+-----------+---------------+------------------------------------------------------------------+
| MVIEW_OWNER | MVIEW_NAME       | DEP_OWNER | DEP_NAME      | DEP_TYPE                                                         |
+-------------+------------------+-----------+---------------+------------------------------------------------------------------+
| SYS         | MV_EXT_TBL1      | SYS       | EXT_TBL1      | EXTERNAL TABLE                                                   |
| SYS         | MV1_TBL3_TBL4    | SYS       | TBL3          | TABLE                                                            |
| SYS         | MV1_TBL3_TBL4    | SYS       | TBL4          | TABLE                                                            |
| SYS         | MV_MV1_TBL3_TBL4 | SYS       | MV1_TBL3_TBL4 | MV                                                               |
+-------------+------------------+-----------+---------------+------------------------------------------------------------------+
4 rows in set
```
