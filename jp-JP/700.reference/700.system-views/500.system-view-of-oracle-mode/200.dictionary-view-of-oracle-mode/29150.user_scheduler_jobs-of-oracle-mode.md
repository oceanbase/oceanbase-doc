# USER_SCHEDULER_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なスケジューラーのジョブ情報を表示します。

## フィールドの説明

|      フィールド名 |    型       | NULL許容 |    説明    |
|--------------|---------------|---------------|------------|
| OWNER | VARCHAR2(128) | NO | スケジューラー・ジョブの所有者 |
| JOB_NAME | VARCHAR2(128) | NO | スケジューラー・ジョブ名 |
| JOB_SUBNAME | VARCHAR2(128) | NO | スケジューラー・ジョブのサブ名 |
| JOB_STYLE | VARCHAR2(17) | YES | ジョブスタイル：<ul><li>REGULAR：指定された時刻にタスクを実行することを指します。  </li><li>LIGHTWEIGHT：指定された時間間隔でタスクを実行することを指します。 </li></ul>|
| JOB_CREATOR | VARCHAR2(128) | NO | スケジューラー・ジョブの作成者 |
| CLIENT_ID | VARCHAR2(65) | NO | ジョブを作成したユーザーのクライアント識別子 |
| GLOBALUid | VARCHAR2(33) | NO | ジョブを作成したユーザーのグローバルユーザー識別子 |
| PROGRAM_OWNER | VARCHAR2(4000) | NO | ジョブに関連するプログラムの所有者 |
| PROGRAM_NAME | VARCHAR2(4000) | YES | ジョブに関連するプログラム名 |
| JOB_TYPE | VARCHAR2(16) | YES |  ジョブ操作タイプ：<ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul> |
| JOB_ACTION | VARCHAR2(4000) | YES | 結合ジョブ操作 |
| NUMBER_OF_ARGUMENTS | NUMBER | YES | ジョブパラメータの結合数 |
| SCHEDULE_OWNER | VARCHAR2(4000) | NO | ジョブで使用されるスケジュールの所有者 |
| SCHEDULE_NAME | VARCHAR2(4000) | NO | ジョブで使用されるスケジュール名 |
| SCHEDULE_TYPE | VARCHAR2(12) | NO | デフォルト値はNULL |
| START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブの元のスケジュール開始日 |
| REPEAT_INTERVAL | VARCHAR2(4000) | YES | 結合スケジュールPL/SQL式またはカレンダーストリング |
| EVENT_QUEUE_OWNER | VARCHAR2(128) | NO | イベントを発生させるソースキューの所有者 |
| EVENT_QUEUE_NAME | VARCHAR2(128) | NO | イベントを発生させるソースキューの名前 |
| EVENT_QUEUE_AGENT | VARCHAR2(523) | NO | ユーザーがイベントソースキューで使用するAQエージェントの名前 |
| EVENT_CONDITION | VARCHAR2(4000) | NO | ソースキュー上のイベントのサブスクリプションルール |
| EVENT_RULE | VARCHAR2(261) | NO | コーディネーターがイベントベースのジョブをトリガーするために使用するルール名 |
| FILE_WATCHER_OWNER | VARCHAR2(261) | NO | そのジョブが基づいているファイルウォッチャーの所有者 |
| FILE_WATCHER_NAME | VARCHAR2(261) | NO | そのジョブが基づいているファイルウォッチャーの名前 |
| END_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブが実行されなくなる日付 |
| JOB_CLASS | VARCHAR2(128) | YES | ジョブに関連付けられたジョブカテゴリ名 |
| ENABLED | VARCHAR2(5) | YES | ジョブが有効かどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| AUTO_DROP | VARCHAR2(5) | YES | ジョブの完了後に削除されるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul>  |
| RESTART_ON_RECOVERY | VARCHAR2(5) | NO | クラスタ再起動時にジョブを再起動するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| RESTART_ON_FAILURE | VARCHAR2(5) | NO | ジョブ実行失敗時にジョブを再起動するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| STATE | VARCHAR2(15) | YES | ジョブの状態：<li>DISABLED<li>RETRY SCHEDULED<li>SCHEDULED<li>BLOCKED<li>RUNNING<li>COMPLETED<li>BROKEN<li>FAILED<li>REMOTE<li>RESOURCE_UNAVAILABLE<li>SUCCEEDED<li>CHAIN_STALLED |
| JOB_PRIORITY | NUMBER | NO | 同一種類の他のジョブに対するこのジョブの優先順位 |
| RUN_COUNT | NUMBER | YES | ジョブの実行回数 |
| MAX_RUNS | NUMBER | NO | ジョブの計画実行回数の上限 |
| FAILURE_COUNT | NUMBER | YES | ジョブの実行失敗回数 |
| MAX_FAILURES | NUMBER | NO | 損傷としてマークされる前に許容されるジョブの失敗回数 |
| RETRY_COUNT | NUMBER | YES | ジョブのリトライ回数 |
| LAST_START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブが実行を開始した最終日付 |
| LAST_RUN_DURATION | INTERVAL DAY (9) TO SECOND (6) | NO | 前回の実行中にジョブを完了するのにかかった時間 |
| NEXT_RUN_DATE | TIMESTAMP(6) WITH TIME ZONE | NO | ジョブの計画実行日の次の日付 |
| SCHEDULE_LIMIT | INTERVAL DAY (3) TO SECOND (0) | NO | まだ実行されていないジョブが再スケジュールされる時間 |
| MAX_RUN_DURATION | INTERVAL DAY (3) TO SECOND (0) | NO | ジョブの実行が許可される最長時間 |
| LOGGING_LEVEL | VARCHAR2(11) | NO | ジョブ関連のログ記録:<ul><li>OFF  </li><li>RUNS </li><li>FAILED RUNS </li><li>FULL </li></ul> |
| STORE_OUTPUT | VARCHAR2(5) | NO | ジョブ実行の出力をデータベースに保存するかどうか：<ul><li>TRUE  </li><li>FALSE </li></ul> |
| STOP_ON_WINDOW_CLOSE | VARCHAR2(5) | NO | ジョブが属するスケジューリングウィンドウが閉じたとき、そのジョブの実行を停止するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| INSTANCE_STICKINESS | VARCHAR2(5) | NO | ジョブにインスタンス粘着性があるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul>|
| RAISE_EVENTS | VARCHAR2(4000) | NO | デフォルト値はNULL |
| SYSTEM | VARCHAR2(5) | NO | ジョブがシステムジョブかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| JOB_WEIGHT | NUMBER | NO | ジョブの重み。スケジューリング時の優先順位を指定するために使用されます。 |
| NLS_ENV | VARCHAR2(4000) | YES | ジョブの国語環境設定。 |
| SOURCE | VARCHAR2(128) | NO | ジョブのソースコードまたはスクリプト。 |
| NUMBER_OF_DESTINATIONS | NUMBER | NO | ジョブのターゲット数。 |
| DESTINATION_OWNER | VARCHAR2(261) | NO | ジョブターゲットの所有者。 |
| DESTINATION | VARCHAR2(261) | NO | ジョブのターゲット、つまりジョブが実行する対象または場所。 |
| CREDENTIAL_OWNER | VARCHAR2(128) | NO | 資格証の所有者。 |
| CREDENTIAL_NAME | VARCHAR2(128) | NO | 資格証の名前。 |
| INSTANCE_ID | NUMBER | YES | ユーザーがジョブの実行を要求するインスタンス |
| DEFERRED_DROP | VARCHAR2(5) | NO | ジョブの削除を遅延させるかどうか。 |
| ALLOW_RUNS_IN_RESTRICTED_MODE | VARCHAR2(5) | NO | ジョブが制限モードで実行されることを許可するかどうか。 |
| COMMENTS | VARCHAR2(4000) | YES | ジョブのコメントまたは説明情報。 |
| FLAGS | NUMBER | NO | ジョブのフラグビット。 |
| RESTARTABLE | VARCHAR2(5) | NO | ジョブが再起動可能かどうか。 |
| CONNECT_CREDENTIAL_OWNER | VARCHAR2(128) | NO | 接続資格証の所有者。 |
| CONNECT_CREDENTIAL_NAME | VARCHAR2(128) | NO | 接続資格証の名前。 |
