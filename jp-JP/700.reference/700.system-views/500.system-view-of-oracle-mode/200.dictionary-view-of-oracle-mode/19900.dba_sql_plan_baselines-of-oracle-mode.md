# DBA_SQL_PLAN_BASELINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMにおけるSQLの実行計画のベースラインを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SIGNATURE | NUMBER | NO | 正規化されたSQLによって生成されるSQLの一意の識別子 |
| SQL_HANDLE | VARCHAR2(32) | NO | 統一されたSQLテキスト |
| SQL_TEXT | CLOB | NO | 正規化されていないSQLテキスト |
| PLAN_NAME | VARCHAR2(128) | NO | プランベースラインの一意のテキスト形式の識別子 |
| CREATOR | VARCHAR2(128) | NO | このプランベースラインを作成したユーザー |
| ORIGIN | VARCHAR2(29) | NO | プランベースラインの作成方法：<ul><li>MANUAL-LOAD</li><li>AUTO-CAPTURE</li><li>MANUAL-SQLTUNE</li><li>AUTO-SQLTUNE</li></ul> |
| PARSING_SCHEMA_NAME | VARCHAR2(128) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| DESCRIPTION | VARCHAR2(500) | YES | プランベースラインの説明 |
| VERSION | VARCHAR2(256) | NO | プランベースライン作成時のデータベースバージョン |
| CREATED | TIMESTAMP(6) | NO | プランベースラインの作成日時 |
| LAST_MODIFIED | TIMESTAMP(6) | NO | プランベースラインの最終変更日時 |
| LAST_EXECUTED | NUMBER | NO | プランベースラインの最終実行日時 |
| LAST_VERIFIED | NUMBER | NO | プランベースラインの最終検証日時 |
| ENABLED | VARCHAR2(3) | NO | プランベースラインが有効かどうかを示します：<ul><li>YES</li><li>NO</li></ul>    |
| ACCEPTED | VARCHAR2(3) | NO | プランベースラインが採用されたかどうかを示します:<ul><li>YES</li><li>NO</li></ul>    |
| FIXED | VARCHAR2(3) | NO | プランベースラインが固定されているかどうかを示します:<ul><li>YES</li><li>NO</li></ul>   |
| REPRODUCED | VARCHAR2(3) | NO | プランベースラインが再現可能かどうかを示します:<ul><li>YES</li><li>NO</li></ul>   |
| AUTOPURGE | VARCHAR2(3) | NO | プランベースラインが自動クリーンアップされるかどうかを示します:<ul><li>YES</li><li>NO</li></ul>    |
| ADAPTIVE | VARCHAR2(3) | NO | SPMによって自動キャプチャされたプランベースラインが適応済みかどうかを示します:<ul><li>YES</li><li>NO</li></ul>    |
| OPTIMIZER_COST | NUMBER | NO | プランベースライン作成時にオプティマイザーが推定した計画コスト |
| MODULE | VARCHAR2(64) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| ACTION | VARCHAR2(64) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| EXECUTIONS | NUMBER | NO | プランベースライン作成時の計画の実行回数 |
| ELAPSED_TIME | NUMBER | NO | プランベースライン作成時の計画の総実行時間 |
| CPU_TIME | NUMBER | NO | プランベースライン作成時の計画のCPU時間の合計 |
| BUFFER_GETS | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| DISK_READS | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| DIRECT_WRITES | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| ROWS_PROCESSED | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| FETCHES | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| END_OF_FETCH_COUNT | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
