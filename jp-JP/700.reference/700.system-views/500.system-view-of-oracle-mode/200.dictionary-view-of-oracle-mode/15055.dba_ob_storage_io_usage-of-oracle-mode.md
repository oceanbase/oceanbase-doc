# DBA_OB_STORAGE_IO_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのオブジェクトストレージおよびクラウドディスクの各種I/O操作状況を表示します。

## フィールドの説明

| フィールド名   | 型          | NULL許容 | 説明                          |
|-----------|---------------|----------------|-------------------------------|
| PATH      | VARCHAR2(1024)| NO   | パス形式は `oss://`、`file://`、`s3://` などと同様です    |
| ENDPOINT  | VARCHAR2(256) | NO   | <ul><li>シェアードナッシング（Shared-Nothing, SN）モードでは、バックアップ・リストア、データインポート、データエクスポートのオブジェクトストレージのEndpointを表示します。</li> <li>シェアードストレージ（Shared-Storage, SS）モードでは、ログ（clog）またはデータ（Data）ストレージおよびバックアップ・リストア、データインポート、データエクスポートのオブジェクトストレージデバイスのEndpointを表示します。</li></ul> |
| TYPE      | VARCHAR2(128) | NO   | 操作タイプ：<ul><li>`READ`：読み取りタイプ</li> <li>`WRITE`：書き込みタイプ</li> <li>`READ_BYTES`：オブジェクトストレージネットワークの入り口トラフィック</li> <li>`WRITE_BYTES`：オブジェクトストレージネットワークの出口トラフィック</li> <li>`TAG`：オブジェクトストレージ内のタグタイプ。ローカルディスクとクラウドディスクにはこのタイプは表示されません</li></ul>     |
| TOTAL     | NUMBER(38)    | NO   | 各タイプ(`TYPE`)に対応する累計値：<ul><li>`READ`：読み取りタイプに関連する操作回数の累計</li> <li>`WRITE`：書き込みタイプに関連する操作回数の累計</li> <li>`READ_BYTES`：オブジェクトストレージネットワークの入り口トラフィックの合計。単位はバイト</li> <li>`WRITE_BYTES`：オブジェクトストレージネットワークの出口トラフィックの合計。単位はバイト</li> <li>`TAG`：オブジェクトストレージ内のタグタイプの累計値。ローカルディスクとクラウドディスクにはこの統計項目は表示されません</li></ul>      |
