# ALL_POLICY_GROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのビューのポリシーグループ情報を表示します。ポリシーコンテキストと組み合わせることで、異なるユーザーに異なるポリシーを適用することができます。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | ポリシーの対象となるオブジェクトの所有者 |
| OBJECT_NAME | VARCHAR2(128) | YES | ポリシーの対象となるオブジェクトの名前 |
| POLICY_GROUP | VARCHAR2(128) | NO | ポリシーグループ名 |
| COMMON | VARCHAR2(3) | NO | 互換性のためのみ使用され、現在の値は常にNOです。 |
| INHERITED | VARCHAR2(3) | NO | 互換性のためのみ使用され、現在の値は常にNOです。 |

## クエリ例

現在ユーザーがアクセス可能なすべてのビューのポリシーグループ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_POLICY_GROUPS;
```

クエリ結果は次のとおりです：

```shell
+--------------+----------------+--------------+--------+-----------+
| OBJECT_OWNER | OBJECT_NAME    | POLICY_GROUP | COMMON | INHERITED |
+--------------+----------------+--------------+--------+-----------+
| SYS          | V_ORDERS_CTX   | GROUP_REGION | NO     | NO        |
| SYS          | V_SALES_SECURE | GROUP_SALES  | NO     | NO        |
+--------------+----------------+--------------+--------+-----------+
2 rows in set
```
