# DBA_OB_TABLET_REPLICAS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのTabletレプリカ情報を表示します。各Tabletレプリカは、結合キーによって一意に特定されます：`<TABLET_ID, SVR_IP, SVR_PORT, LS_ID>`。

## フィールド説明

|     フィールド名      |      型          | NULL許容    |                             説明                             |
|---------------|--------------|------------|------------------------------------------------------------|
| CREATE_TIME     | TIMESTAMP(6) WITH LOCAL TIME ZONE       | NO         | 作成日時                                                  |
| MODIFY_TIME     | TIMESTAMP(6) WITH LOCAL TIME ZONE       | NO         | 変更日時                                                  |
| TABLET_ID     | NUMBER       | NO         | TABLET ID                                                  |
| SVR_IP        | VARCHAR2(46) | NO         | サーバーIPアドレス                                                  |
| SVR_PORT      | NUMBER       | NO         | サーバーポート番号                                                     |
| LS_ID         | NUMBER       | NO         | TABLETが属するログストリームID                                           |
| COMPACTION_SCN  | NUMBER       | NO         | データスナップショットバージョン番号                                      |
| DATA_SIZE     | NUMBER       | NO         | データの実際のサイズ、単位はバイト                                         |
| REQUIRED_SIZE | NUMBER       | NO         | データの割り当てサイズ、単位はバイト。データ保存はマクロブロック（2MB）を最小単位とするため、`REQUIRED_SIZE >= DATA_SIZE` |

## クエリ例

