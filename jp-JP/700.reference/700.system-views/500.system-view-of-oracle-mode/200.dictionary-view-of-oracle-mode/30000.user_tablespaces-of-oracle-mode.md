# USER_TABLESPACES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできるテーブルスペースを表示します。列は`DBA_TABLESPACES`と同じですが、`PLUGGED_IN`フィールドは除外されています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## クエリ例

現在のユーザーがアクセスできるすべてのテーブルスペースを確認します。

```shell
obclient [SYS]> SELECT TABLESPACE_NAME, ENCRYPTED FROM SYS.USER_TABLESPACES;
```

クエリ結果は次のとおりです：

```shell
+-----------------+-----------+
| TABLESPACE_NAME | ENCRYPTED |
+-----------------+-----------+
| SECTEST_TS1     | YES       |
| TS2             | NO        |
+-----------------+-----------+
2 rows in set
```
