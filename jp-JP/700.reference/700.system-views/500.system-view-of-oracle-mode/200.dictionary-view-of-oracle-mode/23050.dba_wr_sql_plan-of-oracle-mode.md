# DBA_WR_SQL_PLAN

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_WR_SQL_PLAN`は、WR収集の[GV$OB_SQL_PLAN](../300.performance-view-of-oracle-mode/3600.gv-ob_sql_plan-of-oracle-mode.md)データを表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | -------------- | -------- |
| TENANT_ID          | NUMBER(38)          | NO   | テナントID     |
| CLUSTER_ID         | NUMBER(38)          | NO   | クラスタID     |
| SNAP_ID            | NUMBER(38)          | NO   | スナップID     |
| SVR_IP             | VARCHAR2(46)        | NO   | ノードIP     |
| SVR_PORT           | NUMBER(38)          | NO   | ノードPORT     |
| SQL_ID             | VARCHAR2(32)        | NO   | SQL文ID     |
| PLAN_HASH          | NUMBER(38)          | NO   | 実行計画HASH値     |
| PLAN_ID            | NUMBER(38)          | NO   | 実行計画ID     |
| ID                 | NUMBER(38)          | NO   | 演算子ID    |
| DB_ID              | NUMBER(38)          | NO   | データベースID     |
| GMT_CREATE         | TIMESTAMP(6) WITH LOCAL TIME ZONE        | NO   | レコード作成時間     |
| OPERATOR           | VARCHAR2(255)        | NO   | 演算子名     |
| OPTIONS            | VARCHAR2(255)        | NO   | オプション     |
| OBJECT_NODE        | VARCHAR2(40)         | NO   | 現在の演算子がDBLINK関連の場合、DBlinkの名前を示します     |
| OBJECT_ID          | NUMBER(38)           | NO   | 演算子が操作するテーブルまたはインデックスオブジェクト番号     |
| OBJECT_OWNER       | VARCHAR2(128)        | NO   | オブジェクト所有者     |
| OBJECT_NAME        | VARCHAR2(128)        | NO   | オブジェクト名     |
| OBJECT_ALIAS       | VARCHAR2(261)        | NO   | 文中のオブジェクトのエイリアス     |
| OBJECT_TYPE        | VARCHAR2(20)         | NO   | オブジェクトタイプ     |
| OPTIMIZER          | VARCHAR2(4000)       | NO   | インデックス関連情報（例：物理行、論理行、再テーブル行数、使用統計情報タイプ、統計情報バージョン番号）     |
| PARENT_ID          | NUMBER(38)           | NO   | 親演算子のID     |
| DEPTH              | NUMBER(38)           | NO   | 演算子階層の深さ。ルート演算子の深さは0     |
| POSITION           | NUMBER(38)           | NO   | 同じ親演算子を持つすべての演算子の中での順序位置     |
| IS_LAST_CHILD      | NUMBER(38)           | NO   | 現在の論理演算子が親演算子の最後の子ノードであるかどうか     |
| COST               | NUMBER(38)           | NO   | 最適化エンジンが推定したコスト     |
| REAL_COST          | NUMBER(38)           | NO   | 初回実行時の実際のコスト     |
| CARDINALITY        | NUMBER(38)           | NO   | オプティマイザーが推定した出力行数     |
| REAL_CARDINALITY   | NUMBER(38)           | NO   | 最初実行時の実際の出力行数    |
| BYTES              | NUMBER(38)           | NO   | オプティマイザーが推定した現在の演算子データ幅     |
| ROWSET             | NUMBER(38)           | NO   | 現在の演算子のベクトル化サイズ     |
| OTHER_TAG          | VARCHAR2(4000)       | NO   | 現在のクエリで使用されたヒント。プランの最初の行にのみ格納されます     |
| PARTITION_START    | VARCHAR2(4000)       | NO   | スキャンするパーティション情報     |
| OTHER              | VARCHAR2(4000)       | NO   | 最適化情報。例：プランタイプ、Fast Parserのパラメータ化情報、Plan Note、プランがヒットした制約情報    |
| CPU_COST           | NUMBER(38)           | NO   | プランが最初に実行されたときの現在の演算子の実際のCPUコスト（実行フィードバック情報）     |
| IO_COST            | NUMBER(38)           | NO   | プランが最初に実行されたときの現在の演算子の実際のIOコスト（実行フィードバック情報）     |
| ACCESS_PREDICATES  | VARCHAR2(4000)       | NO   | 現在の演算子がアクセスする必要がある式情報     |
| FILTER_PREDICATES  | VARCHAR2(4000)       | NO   | 現在の演算子のフィルター条件     |
| FILTER_PREDICATES  | VARCHAR2(4000)       | NO   | 現在の演算子のフィルター条件     |
| PROJECTION         | VARCHAR2(4000)       | NO   | 現在の演算子の出力式情報     |
| SPECIAL_PREDICATES | VARCHAR2(4000)       | NO   | 現在の演算子の固有な式情報。例：Join Condition、GROUP EXPRS、SORT EXPRSなど     |
| QBLOCK_NAME        | VARCHAR2(128)        | NO   | 現在の演算子が存在するクエリブロック名     |
| REMARKS            | VARCHAR2(4000)       | NO   | qb_nameの変更追跡情報     |
| OTHER_XML          | VARCHAR2(4000)       | NO   | OUTLINE DATA     |
