# DBA_WR_SYSSTAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのシステム統計項目の詳細情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | NUMBER(38) | NO | クラスタID |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| SNAP_ID | NUMBER(38) | NO | スナップショットID |
| SVR_IP | VARCHAR2(46) | NO | ノードIP |
| SVR_PORT | NUMBER(38) | NO | ノードPORT |
| STAT_ID | NUMBER(38) | NO | 統計項目ID |
| VALUE | NUMBER(38) | YES | 統計項目の値 |

## クエリ例

本テナントのシステム統計項目の詳細情報を確認し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_SYSSTAT  WHERE ROWNUM <= 1\G
```

実行結果は次のとおりです：

