# USER_TYPE_ATTRS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが持つカスタム型プロパティ情報を一覧表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|      **フィールド名**      |    **タイプ**     | **NULL値を許容するか** |          **説明**          |
|--------------------|---------------|----------------|--------------------------|
| TYPE_NAME          | VARCHAR2(64)  | NO             | タイプ名                      |
| ATTR_NAME          | VARCHAR2(64)  | NO             | タイプのプロパティ名                    |
| ATTR_TYPE_MOD      | VARCHAR2(7)   | NO             | 現在このフィールドは使用されていません  |
| ATTR_TYPE_OWNER    | VARCHAR2(128) | NO             | プロパティのタイプ所有者                 |
| ATTR_TYPE_NAME     | VARCHAR2(324) | NO             | プロパティのデータ型名                   |
| LENGTH             | NUMBER(38)    | NO             | プロパティタイプの長さ                   |
| NUMBER_PRECISION   | NUMBER(38)    | NO             | プロパティ数値型の長さ                |
| SCALE              | NUMBER(38)    | NO             | 数値型の小数点以下のデータ長           |
| CHARACTER_SET_NAME | CHAR(7)       | NO             | プロパティタイプの文字セット名：<ul><li>`CHAR_CS`</li> <li> `NCHAR_CS` </li></ul>  |
| ATTR_NO            | NUMBER(38)    | NO             | プロパティ番号                     |
| INHERITED          | CHAR(2)       | NO             | このプロパティが親タイプから継承されているかどうか              |
| CHAR_USED          | CHAR(1)       | YES            | このプロパティがバイト長（B）または文字長（C）で定義されているかを示します |

## クエリ例

現在のユーザーが持つユーザー定義型のプロパティ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_TYPE_ATTRS;
```

クエリ結果は次のとおりです：

```shell
+-------------+--------------+---------------+-----------------+----------------+--------+------------------+-------+--------------------+---------+-----------+-----------+
| TYPE_NAME   | ATTR_NAME    | ATTR_TYPE_MOD | ATTR_TYPE_OWNER | ATTR_TYPE_NAME | LENGTH | NUMBER_PRECISION | SCALE | CHARACTER_SET_NAME | ATTR_NO | INHERITED | CHAR_USED |
+-------------+--------------+---------------+-----------------+----------------+--------+------------------+-------+--------------------+---------+-----------+-----------+
| PROJECT_OBJ | PROJECT_NAME | NULL          | NULL            | VARCHAR2       |    100 |                2 |    -1 | CHAR_CS            |       1 | NO        | C         |
| PROJECT_OBJ | STATUS       | NULL          | NULL            | VARCHAR2       |     20 |                2 |    -1 | CHAR_CS            |       2 | NO        | C         |
+-------------+--------------+---------------+-----------------+----------------+--------+------------------+-------+--------------------+---------+-----------+-----------+
2 rows in set
```
