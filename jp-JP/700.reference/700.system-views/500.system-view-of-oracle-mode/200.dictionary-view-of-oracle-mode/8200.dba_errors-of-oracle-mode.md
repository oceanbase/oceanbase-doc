# DBA_ERRORS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

データベース内の現在のストレージオブジェクトのエラー情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**    |     **型**     | **NULL許容** |                                             **説明**                                              |
|----------------|----------------|----------------|-----------------------------------|
| OWNER          | VARCHAR2(128)  | NO             | オブジェクト所有者。      |
| NAME           | VARCHAR2(128)  | NO             | オブジェクト名。       |
| TYPE           | VARCHAR2(19)   | NO             | オブジェクトのタイプ：<ul><li>VIEW   </li><li> PROCEDUCE   </li><li> FUNCTION   </li><li> PACKAGE   </li><li> PACKAGE_BODY   </li><li> TRIGGER   </li><li> TYPE   </li><li> TYPE BODY   </li><li> LIBRARY   </li><li> JAVA SOURCE   </li><li> JAVA CLASS   </li><li> DIMENSION </li></ul>   |
| SEQUENCE       | NUMBER         | NO             | 同一コンパイルで複数のエラーが発生した場合のエラー番号（ソート用）。                                                                            |
| LINE           | NUMBER         | NO             | エラーが発生した行番号。     |
| POSITION       | NUMBER         | NO             | エラーが発生した列番号。     |
| TEXT           | VARCHAR2(4000) | NO             | エラーテキスト。      |
| ATTRIBUTE      | VARCHAR2(9)    | NO             | ErrorかWarningかを示す文字列。                                                                           |
| MESSAGE_NUMBER | NUMBER         | NO             | エラーコード。        |
