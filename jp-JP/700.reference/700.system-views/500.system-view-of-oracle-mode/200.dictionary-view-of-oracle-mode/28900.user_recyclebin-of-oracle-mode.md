# USER_RECYCLEBIN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するゴミ箱オブジェクトの情報を表示します。列は `DBA_RECYCLEBIN` ビューと同じですが、`OWNER` 列は除外されています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|      フィールド名      |      型           | NULL許容    |                                                                 説明                                                                 |
|----------------|---------------|------------|------------------------------------------------------------------------------------------------------------------------------------|
| OBJECT_NAME    | VARCHAR2(128) | NO         | オブジェクトの新しい名前                                          |
| ORIGINAL_NAME  | VARCHAR2(128) | NO         | オブジェクトの元の名前                                         |
| OPERATION      | VARCHAR2(9)   | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| TYPE           | VARCHAR2(25)  | NO         | オブジェクトタイプ                                            |
| TS_NAME        | VARCHAR2(30)  | NO         | オブジェクトが属するテーブル名                                       |
| CREATETIME     | VARCHAR2(19)  | NO         | オブジェクト作成時刻                                         |
| DROPTIME       | VARCHAR2(19)  | NO         | オブジェクトがゴミ箱に移動した時刻                                      |
| DROPSCN        | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| PARTITION_NAME | VARCHAR2(128) | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| CAN_UNDROP     | VARCHAR2(3)   | NO         | オブジェクトをゴミ箱から復元できるかどうか：<ul><li>YES  </li><li> NO </li></ul>    |
| CAN_PURGE      | VARCHAR2(3)   | NO         | オブジェクトを削除できるかどうか:<ul><li>YES  </li><li> NO </li></ul>    |
| RELATED        | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| BASE_OBJECT    | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| PURGE_OBJECT   | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
| SPACE          | NUMBER        | NO         | このフィールドは現在サポートされていません。デフォルトはNULLです。 |
