# ALL_SCHEDULER_WINDOWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセス可能なすべてのスケジューラーウィンドウの情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| フィールド名          | タイプ          | NULLを許容するか | 説明              |
|------------------|---------------|----------------|-------------------|
| OWNER            | VARCHAR2(128)                  | NO   | スケジューラーウィンドウの所有者    |
| WINDOW_NAME      | VARCHAR2(128)                  | NO   | スケジューラーウィンドウの名前  |
| RESOURCE_PLAN    | VARCHAR2(128)                  | NO   | ウィンドウに関連付けられたリソース計画。現在、このフィールドは使用されていません   |
| SCHEDULE_OWNER   | VARCHAR2(4000)                 | 窓口時間表の所有者。現在、このフィールドは使用されていません   |
| SCHEDULE_NAME    | VARCHAR2(4000)                 | NO   | 窓口の時間表名。現在、このフィールドは使用されていません   |
| SCHEDULE_TYPE    | VARCHAR2(8)                    | NO   | 窓口計画タイプ：<ul><li>ONCE：繰り返し間隔はNULL</li><li>NAMED：命名時間表</li><li>CALENDAR：スケジュール表として使用されるカレンダー式</li></ul></br>現在、このフィールドは使用されていません。 |
| START_DATE       | TIMESTAMP(6) WITH TIME ZONE    | YES  | 窓口の開始時間 |
| REPEAT_INTERVAL  | VARCHAR2(4000)                 | YES  | 窓口の周期間隔時間|
| END_DATE         | TIMESTAMP(6) WITH TIME ZONE    | YES  | 窓口の終了時間 |
| DURATION         | INTERVAL DAY (3) TO SECOND (0) | YES  | 窓口の持続時間    |
| WINDOW_PRIORITY  | VARCHAR2(4)                    | NO   | ジョブの他のウィンドウに対する優先順位：<ul><li>HIGH</li><li>LOW</li></ul> </br>現在、このフィールドは使用されていません。|
| NEXT_RUN_DATE    | TIMESTAMP(6) WITH TIME ZONE    | NO   | 窓口の次回の開始時間 |
| LAST_START_DATE  | TIMESTAMP(6) WITH TIME ZONE    | YES  | 最後にウィンドウが開始された時間|
| ENABLED          | VARCHAR2(5)                    | YES  | ウィンドウが有効(TRUE)か無効(FALSE)かを示します    |
| ACTIVE           | VARCHAR2(5)                    | NO   | ウィンドウが開いている(True)か閉じている(False)かを示します。現在、このフィールドは使用されていません      |
| MANUAL_OPEN_TIME | TIMESTAMP(6) WITH TIME ZONE    | NO   | 手動でウィンドウを開いた開始時間。そうでない場合はNULLです。現在、このフィールドは使用されていません      |
| MANUAL_DURATION  | INTERVAL DAY (3) TO SECOND (0) | NO   | 手動で開いたウィンドウの持続時間。そうでない場合はNULLです。現在、このフィールドは使用されていません    |
| COMMENTS         | VARCHAR2(4000)                 | YES  | ウィンドウの説明   |
