# ALL_SCHEDULER_WINDOWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのスケジューラーウィンドウの情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

| フィールド名          | 型          | NULL許容 | 説明              |
|------------------|---------------|----------------|-------------------|
| OWNER            | VARCHAR2(128)                  | NO   | スケジューラーウィンドウの所有者    |
| WINDOW_NAME      | VARCHAR2(128)                  | NO   | スケジューラーウィンドウの名前  |
| RESOURCE_PLAN    | VARCHAR2(128)                  | NO   | ウィンドウに関連付けられたリソース計画。現在このフィールドは使用されていません   |
| SCHEDULE_OWNER   | VARCHAR2(4000)                 | NO   | ウィンドウスケジュールの所有者。現在このフィールドは使用されていません   |
| SCHEDULE_NAME    | VARCHAR2(4000)                 | NO   | ウィンドウのスケジュール名。現在このフィールドは使用されていません   |
| SCHEDULE_TYPE    | VARCHAR2(8)                    | NO   | ウィンドウ計画タイプ：<ul><li>ONCE：繰り返し間隔がNULL</li><li>NAMED：名前付きスケジュール</li><li>CALENDAR：スケジュールとして使用するカレンダー式</li></ul></br>現在このフィールドは使用されていません。 |
| START_DATE       | TIMESTAMP(6) WITH TIME ZONE    | YES  | ウィンドウの開始時刻 |
| REPEAT_INTERVAL  | VARCHAR2(4000)                 | YES  | ウィンドウの周期間隔時間|
| END_DATE         | TIMESTAMP(6) WITH TIME ZONE    | YES  | ウィンドウの終了時刻 |
| DURATION         | INTERVAL DAY (3) TO SECOND (0) | YES  | ウィンドウの継続時間    |
| WINDOW_PRIORITY  | VARCHAR2(4)                    | NO   | ジョブの他のウィンドウに対する優先順位：<ul><li>HIGH</li><li>LOW</li></ul> </br>現在このフィールドは使用されていません。|
| NEXT_RUN_DATE    | TIMESTAMP(6) WITH TIME ZONE    | NO   | ウィンドウの次回開始時刻 |
| LAST_START_DATE  | TIMESTAMP(6) WITH TIME ZONE    | YES  | 最後にウィンドウが開始された時刻|
| ENABLED          | VARCHAR2(5)                    | YES  | ウィンドウが有効(TRUE)か無効(FALSE)かを示します    |
| ACTIVE           | VARCHAR2(5)                    | NO   | ウィンドウが開いている(TRUE)か閉じている(FALSE)かを示します。現在このフィールドは使用されていません      |
| MANUAL_OPEN_TIME | TIMESTAMP(6) WITH TIME ZONE    | NO   | ウィンドウを手動で開いた開始時刻です。そうでない場合はNULLです。現在このフィールドは使用されていません      |
| MANUAL_DURATION  | INTERVAL DAY (3) TO SECOND (0) | NO   | 手動で開いたウィンドウの継続時間です。そうでない場合はNULLです。現在このフィールドは使用されていません    |
| COMMENTS         | VARCHAR2(4000)                 | YES  | ウィンドウの説明   |
