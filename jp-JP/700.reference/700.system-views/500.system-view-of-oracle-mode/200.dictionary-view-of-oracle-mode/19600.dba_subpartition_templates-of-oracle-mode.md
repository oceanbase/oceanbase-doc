# DBA_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのパーティションテーブルのテンプレート化されたサブパーティション情報を表示します。

## フィールドの説明

|         フィールド名          |       タイプ        | NULLを許容するか |    説明     |
|-----------------------|-----------------|------------|-----------|
| USER_NAME             | VARCHAR2(128)   | NO         | パーティションテーブルの所有者   |
| TABLE_NAME            | VARCHAR2(128)   | NO         | パーティションテーブル名      |
| SUBPARTITION_NAME     | VARCHAR2(132)   | NO         | サブパーティション名      |
| SUBPARTITION_POSITION | NUMBER          | NO         | サブパーティションの位置     |
| TABLESPACE_NAME       | VARCHAR2(30)    | NO         | パーティションが属するテーブルスペース名 |
| HIGH_BOUND            | VARCHAR2(32767) | NO         | パーティションテンプレート式   |
| COMPRESSION           | VARCHAR2(4)     | NO         | サブパーティションテンプレート内で新しく追加される各複合パーティションについて、サブパーティションデータを圧縮形式で保存するかどうかを指示します。<li>YES<li>(デフォルト)NO <br>この値はサブパーティションテンプレートで指定できます          |
| INDEXING              | VARCHAR2(4)     | NO         | サブパーティションテンプレート内で新しく追加される各複合パーティションについて、サブパーティションデータを部分的なインデックスとして扱うかどうかを指示します。<li>ON<li>(デフォルト)OFF<br>この値はサブパーティションテンプレートで指定できます          |
| READ_ONLY             | VARCHAR2(4)     | NO         | サブパーティションテンプレート内で新しく追加される各複合パーティションについて、サブパーティションデータを読み取り専用とするかどうかを指示します。<li>YES<li>(デフォルト)NO<br>この値はサブパーティションテンプレートで指定できます          |

## クエリ例

ユーザーテナントが、自身のテナントに属するパーティションテーブルのテンプレート化されたサブパーティション情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_SUBPARTITION_TEMPLATES;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| USER_NAME | TABLE_NAME | SUBPARTITION_NAME | SUBPARTITION_POSITION | TABLESPACE_NAME | HIGH_BOUND | COMPRESSION | INDEXING | READ_ONLY |
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| SYS       | T2_M_LR    | MP0               |                     1 | NULL            | 100        | NULL        | NULL     | NULL      |
| SYS       | T2_M_LR    | MP1               |                     2 | NULL            | 200        | NULL        | NULL     | NULL      |
| SYS       | T2_M_LR    | MP2               |                     3 | NULL            | 300        | NULL        | NULL     | NULL      |
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
3 rows in set
```
