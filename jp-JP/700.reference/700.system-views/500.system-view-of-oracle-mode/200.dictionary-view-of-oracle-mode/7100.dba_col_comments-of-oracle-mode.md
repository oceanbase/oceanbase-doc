# DBA_COL_COMMENTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのビューとテーブルのすべての列のコメントを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|  **フィールド名**   |     **タイプ**     | **NULL値を許容するか** | **説明** |
|-------------|----------------|----------------|--------|
| OWNER       | VARCHAR2(128)  | NO             | オブジェクトの所有者 |
| TABLE_NAME  | VARCHAR2(128)  | NO             | オブジェクト名   |
| COLUMN_NAME | VARCHAR2(128)  | NO             | 列名     |
| COMMENTS    | VARCHAR2(4000) | YES            | 列のコメント    |

## クエリ例

テーブル `T1` のすべての列のコメントを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_COL_COMMENTS WHERE TABLE_NAME='T1';
```

クエリ結果は次のとおりです：

```shell
+-------+------------+----------------+----------+
| OWNER | TABLE_NAME | COLUMN_NAME    | COMMENTS |
+-------+------------+----------------+----------+
| SYS   | T1         | __pk_increment | NULL     |
| SYS   | T1         | ID1            | score    |
| SYS   | T1         | ID2            | NULL     |
+-------+------------+----------------+----------+
3 rows in set
```
