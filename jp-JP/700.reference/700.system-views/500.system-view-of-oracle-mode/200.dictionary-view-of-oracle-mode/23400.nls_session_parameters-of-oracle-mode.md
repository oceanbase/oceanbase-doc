# NLS_SESSION_PARAMETERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

セッションレベルのNLSパラメータを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名**  |     **タイプ**      | **NULL値を許容するか** | **説明** |
|-----------|-----------------|----------------|--------|
| PARAMETER | VARCHAR2(128)   | NO             | パラメータ名   |
| VALUE     | VARCHAR2(65536) | YES            | パラメータ値   |

## クエリ例

現在のテナント内のセッションレベルのNLSパラメータを確認します。

```shell
obclient> SELECT * FROM SYS.NLS_SESSION_PARAMETERS;
```

クエリ結果は次のとおりです：

```shell
+-------------------------+----------------------------------+
| PARAMETER               | VALUE                            |
+-------------------------+----------------------------------+
| NLS_DATE_FORMAT         | YYYY-MM-DD HH24:MI:SS            |
| NLS_TIMESTAMP_FORMAT    | YYYY-MM-DD HH24:MI:SS.FF         |
| NLS_TIMESTAMP_TZ_FORMAT | YYYY-MM-DD HH24:MI:SS.FF TZR TZD |
| NLS_LANGUAGE            | AMERICAN                         |
| NLS_TERRITORY           | AMERICA                          |
| NLS_SORT                | BINARY                           |
| NLS_COMP                | BINARY                           |
| NLS_DATE_LANGUAGE       | AMERICAN                         |
| NLS_LENGTH_SEMANTICS    | BYTE                             |
| NLS_NCHAR_CONV_EXCP     | FALSE                            |
| NLS_CALENDAR            | GREGORIAN                        |
| NLS_NUMERIC_CHARACTERS  | .,                               |
+-------------------------+----------------------------------+
12 rows in set
```
