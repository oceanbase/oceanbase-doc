# DBA_OB_DATABASES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのデータベースメタ情報を表示します。

## フィールドの説明

|     フィールド名      |       型       | NULL許容 |             説明             |
|---------------|----------------|------------|----------------------------|
| DATABASE_NAME | VARCHAR2(128)  | NO         | データベース名                       |
| IN_RECYCLEBIN | VARCHAR2(3)    | NO         | データベースがゴミ箱にあるかどうか：<ul><li>YES</li><li>NO</li></ul> |
| COLLATION     | VARCHAR2(128)  | NO         | データベースのデフォルトCOLLATION            |
| READ_ONLY     | VARCHAR2(3)    | NO   | OCPが取得したデータベースの読み取り専用状態：<ul><li>YES：読み取り専用</li><li>NO：読み書き可能</li></ul> |
| COMMENT       | VARCHAR2(2048) | NO         | データベースの説明                     |
| TABLEGROUP_NAME | VARCHAR2(128)  | NO       | DataBaseにバインドされたテーブルグループ名 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.1バージョンから導入されました。</p></main>|

## クエリ例

ユーザーテナントが本テナントのデータベースメタ情報をクエリします。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_DATABASES WHERE DATABASE_NAME = 'SYS'\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
  DATABASE_NAME: SYS
  IN_RECYCLEBIN: NO
      COLLATION: utf8mb4_bin
      READ_ONLY: NO
        COMMENT: oracle sys schema
TABLEGROUP_NAME: NULL
1 row in set
```
