# USER_MVREF_STATS_PARAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `USER_MVREF_STATS_PARAMS` は、各マテリアライズドビューに関連付けられたリフレッシュ統計情報のプロパティを表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_OWNER | VARCHAR2(128) | NO | マテリアライズドビューの所有者名 |
| MV_NAME | VARCHAR2(128) | NO | マテリアライズドビュー名 |
| COLLECTION_LEVEL | VARCHAR2(8) | NO | リフレッシュ統計情報の収集レベル。<ul><li>NONE：統計情報を収集しません。  </li><li>TYPICAL：標準的な統計情報を収集します。 </li><li>ADVANCED：より詳細な統計情報を収集します。 </ li></ul>|
| RETENTION_PERIOD | NUMBER | NO | リフレッシュ統計情報の保持日数 |

## クエリ例

```shell
obclient [test_db]> SELECT * FROM SYS.USER_MVREF_STATS_PARAMS;
```

クエリ結果は次のとおりです：

```shell
+----------+---------------+------------------+------------------+
| MV_OWNER | MV_NAME       | COLLECTION_LEVEL | RETENTION_PERIOD |
+----------+---------------+------------------+------------------+
| test_db  | mv1_tbl1_tbl2 | TYPICAL          |               31 |
| test_db  | mv2_tbl1_tbl2 | TYPICAL          |               31 |
| test_db  | t1_mv0        | TYPICAL          |               31 |
+----------+---------------+------------------+------------------+
3 rows in set (0.020 sec)
```
