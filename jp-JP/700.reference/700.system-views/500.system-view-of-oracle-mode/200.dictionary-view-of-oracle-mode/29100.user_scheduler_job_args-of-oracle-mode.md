# USER_SCHEDULER_JOB_ARGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースは、このビューをサポートしていません。</p>
</main>

## 機能の概要

現在ユーザーが所有するスケジュールジョブのパラメータ情報を表示します。

## フィールドの説明

|       **フィールド名**        |     **型**     | **NULL許容** |         **説明**          |
|-----------------------|----------------|----------------|-------------------------|
| JOB_NAME              | VARCHAR2(30)   | NO             | パラメータが属するジョブの名前               |
| ARGUMENT_NAME         | VARCHAR2(30)   | NO             | パラメータのオプション名                 |
| ARGUMENT_POSITION     | NUMBER         | NO             | パラメータリスト内のパラメータの位置             |
| ARGUMENT_TYPE         | VARCHAR2(61)   | NO             | パラメータのデータ型                 |
| VALUE                 | VARCHAR2(4000) | NO             | パラメータが文字列型の場合、そのデフォルト値     |
| DEFAULT_ANYDATA_VALUE | VARCHAR2(128)  | NO             | パラメータがANYDATA型の場合、そのデフォルト値 |
| OUT_ARGUMENT          | VARCHAR2(5)    | NO             | 予約語フィールド                    |
