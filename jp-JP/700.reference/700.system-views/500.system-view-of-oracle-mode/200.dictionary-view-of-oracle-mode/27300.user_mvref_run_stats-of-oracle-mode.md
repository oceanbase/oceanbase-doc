# USER_MVREF_RUN_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`USER_MVREF_RUN_STATS`は、マテリアライズドビューの各リフレッシュ実行に関する情報を表示します。各実行はREFRESH_IDで識別されます。この情報には、実行に関連するタイミング統計情報と、その実行で指定されたパラメータが含まれます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| REFRESH_ID | NUMBER | NO | リフレッシュのID |
| NUM_MVS | NUMBER | NO | リフレッシュされたマテリアライズドビューの数 |
| MVIEWS | VARCHAR2(4000) | NO | APIで指定されたマテリアライズドビュー名のパラメータ |
| BASE_TABLES | VARCHAR2(4000) | YES | 内部専用 |
| METHOD | VARCHAR2(4000) | YES | APIで指定されたMETHODパラメータ |
| ROLLBACK_SEG | VARCHAR2(4000) | YES | APIで指定されたROLLBACK_SEGパラメータ |
| PUSH_DEFERRED_RPC | CHAR(1) | NO | APIで指定されたPUSH_DEFERRED_RPCパラメータ |
| REFRESH_AFTER_ERRORS | CHAR(1) | NO | APIで指定されたREFRESH_AFTER_ERRORSパラメータ |
| PURGE_OPTION | NUMBER | NO | APIで指定されたPURGE_OPTIONパラメータ |
| PARALLELISM | NUMBER | NO | APIで指定されたPARALLELISMパラメータ |
| HEAP_SIZE | NUMBER | NO | APIで指定されたHEAP_SIZEパラメータ |
| ATOMIC_REFRESH | CHAR(1) | NO | APIで指定されたATOMIC_REFRESHパラメータ |
| NESTED | CHAR(1) | NO | APIで指定されたNESTEDパラメータ |
| OUT_OF_PLACE | CHAR(1) | NO | APIで指定されたOUT_OF_PLACEパラメータ |
| NUMBER_OF_FAILURES | NUMBER | NO | API処理時に発生した失敗回数 |
| START_TIME | TIMESTAMP(6) | NO | リフレッシュ実行の開始時間 |
| END_TIME | TIMESTAMP(6) | NO | リフレッシュ実行の終了時間 |
| ELAPSED_TIME | NUMBER | NO | リフレッシュ実行の時間長。<ul><li>V4.4.2 BP2 より前のバージョンでは、単位は秒です。</li><li>V4.4.2 バージョンでは、V4.4.2 BP2 以降、単位はマイクロ秒です。</li></ul> |
| LOG_SETUP_TIME | NUMBER | NO | マテリアライズドビューのログ設定時間、単位は秒<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値は0です。</p></main> |
| LOG_PURGE_TIME | NUMBER | NO | マテリアライズドビューのログクリーンアップ時間。<ul><li>V4.4.2 BP2 より前のバージョンでは、単位は秒です。</li><li>V4.4.2 バージョンでは、V4.4.2 BP2 以降、単位はマイクロ秒です。</li></ul> |
| COMPLETE_STATS_AVAILABLE | CHAR(1) | NO | この実行で全ての完全リフレッシュ統計情報が利用可能かどうかを示します。<ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はYです。</p></main> |
| MVIEW_ID                 | NUMBER         | YES  | マテリアライズドビューIDを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 以降から導入されました。</p></main>|
| MVIEW_NAME               | VARCHAR2(128)  | YES  | マテリアライズドビュー名を表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 以降から導入されました。</p></main>|
| DATA_TARGET_SCN          | NUMBER         | YES  | ターゲットデータ同期SCNを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 以降から導入されました。</p></main>|
| TRACE_ID                 | VARCHAR2(64)   | YES  | リフレッシュタスクのTrace識別子を表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2 バージョンでは、このフィールドはV4.4.2 BP2 以降から導入されました。</p></main>|
