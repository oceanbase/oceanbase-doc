# DBA_OB_TASK_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントの履歴収集タスクの実行状況を表示します。

## フィールド説明

| **項目** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER | NO | 収集タスクが存在するテナントID |
| TASK_ID | VARCHAR2(36) | NO | 収集タスクID（UUID形式で生成され、グローバルに一意） |
| TYPE | VARCHAR2(16) | NO | 収集タスクのタイプ |
| STATUS | VARCHAR2(8) | NO | 収集タスクのステータス。<ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| TASK_TABLE_COUNT | NUMBER | YES | 収集タスクで収集するテーブル数 |
| FAILED_COUNT | NUMBER | YES | 収集タスクで収集に失敗したテーブル数 |
| TASK_START_TIME | TIMESTAMP(6) | NO | 収集タスク開始時刻 |
| TASK_END_TIME | TIMESTAMP(6) | NO | 収集タスク終了時刻 |
