# TENANT_VIRTUAL_SESSION_VARIABLE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのセッション変数情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**    |     **型**      | **NULL許容** |   **説明**    |
|---------------|-----------------|----------------|-------------|
| VARIABLE_NAME | VARCHAR2(128)   | NO             | セッション変数名 |
| VALUE         | VARCHAR2(65536) | YES            | セッション変数値 |

## クエリ例

現在のテナント内のセッション変数`ob_query_timeout`の値を確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.TENANT_VIRTUAL_SESSION_VARIABLE WHERE VARIABLE_NAME = 'ob_query_timeout';
```

クエリ結果は次のとおりです：

```shell
+------------------+----------+
| VARIABLE_NAME    | VALUE    |
+------------------+----------+
| ob_query_timeout | 10000000 |
+------------------+----------+
1 row in set
```
