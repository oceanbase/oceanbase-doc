# DBA_OB_DYNAMIC_PARTITION_TABLES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.4.x系では、このビューはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このビューはV4.3.5 BP2バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

このテナントの動的パーティションテーブル情報を表示します。

## フィールドの説明

|        フィールド        |       型       | NULL許容 | 説明 |
|--------------------|-----------------|-------------|------|
| DATABASE_NAME      | VARCHAR2(128)   | YES         | 動的パーティションテーブルが存在するスキーマ名。|
| TABLE_NAME         | VARCHAR2(256)   | NO          | 動的パーティションテーブル名。|
| TABLE_ID           | NUMBER(38)      | NO          | 動的パーティションテーブルID。|
| MAX_HIGH_BOUND_VAL | VARCHAR2(4096)  | NO          | 最大Rangeパーティションの上限値。|
| ENABLE             | VARCHAR2(16384) | NO          | 動的パーティション管理を有効にするかどうか。|
| TIME_UNIT          | VARCHAR2(16384) | NO          | 動的パーティション管理の`time_unit`。|
| PRECREATE_TIME     | VARCHAR2(16384) | NO          | 動的パーティション管理の`precreate_time`。|
| EXPIRE_TIME        | VARCHAR2(16384) | NO          | 動的パーティション管理の`expire_time`。|
| TIME_ZONE          | VARCHAR2(16384) | NO          | 動的パーティション管理の`time_zone`。|
| BIGINT_PRECISION   | VARCHAR2(16384) | NO          | 動的パーティション管理の`bigint_precision`。|

## クエリ例

このテナントの動的パーティションテーブルの情報を1件確認します。

```shell
obclient> SELECT * FROM sys.DBA_OB_DYNAMIC_PARTITION_TABLES\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
     DATABASE_NAME: TEST_USER001
        TABLE_NAME: TBL2
          TABLE_ID: 502075
MAX_HIGH_BOUND_VAL: Timestamp '2025-02-04 21:00:00.000000'
            ENABLE: TRUE
         TIME_UNIT: HOUR
    PRECREATE_TIME: 3HOUR
       EXPIRE_TIME: 1DAY
         TIME_ZONE: +8:00
  BIGINT_PRECISION: NONE
1 row in set
```
