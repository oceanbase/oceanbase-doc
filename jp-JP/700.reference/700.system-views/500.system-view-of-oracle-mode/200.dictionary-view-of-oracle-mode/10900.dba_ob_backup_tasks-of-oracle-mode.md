# DBA_OB_BACKUP_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント自身のタスクレベルのバックアップタスクを表示します。

## フィールドの説明

| フィールド名 | フィールド名 | フィールド名 | フィールド名 |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | タスクレベルのバックアップタスクID。1つのバックアップセットに対応するタスクを表します。 |
| JOB_ID | NUMBER(38) | NO | このタスクが属するJOB_ID |
| INCARNATION | NUMBER(38) | NO | Flashback Database後の何回目の化身を表します |
| BACKUP_SET_ID | NUMBER(38) | NO | このタスクに対応するバックアップセットID |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスクの開始時間 |
| END_TIMESTAMP | VARCHAR2(256) | NO | タスクの終了時間 |
| STATUS | VARCHAR2(4096) | NO | バックアップの状態 |
| START_SCN | NUMBER(38)  | NO | バックアップ開始時のSCN |
| END_SCN | NUMBER(38)  | NO | バックアップ終了時のSCN |
| USER_LS_START_SCN | NUMBER(38)  | NO | バックアップログストリームMETAのSCN |
| ENCRYPTION_MODE | VARCHAR2(4096) | YES | 暗号化モード：<ul><li>None：暗号化しないことを表します</li><li>Password：パスワードによるみなし保護のみを表します</li><li>Password Encryption：暗号化され、パスワードによる保護も行われます</li><li>Transparent Encryption：TDE暗号化を使用することを表します</li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用することを表します</li></ul> <br>現在はNoneとPasswordの2種類のモードのみサポートしています |
| PASSWD | VARCHAR2(4096) | YES | パスワード |
| INPUT_BYTES | NUMBER(38) | YES | 入力バイト数 |
| OUTPUT_BYTES | NUMBER(38) | YES | 出力バイト数 |
| OUTPUT_RATE_BYTES | NUMBER | NO | 1秒あたりの出力バイト数 |
| EXTRA_META_BYTES | NUMBER(38) | YES | 追加バイト数 |
| TABLET_COUNT | NUMBER(38) | YES | TABLETの総数 |
| FINISH_TABLET_COUNT | NUMBER(38) | YES | バックアップ完了のTABLETの総数 |
| MACRO_BLOCK_COUNT | NUMBER(38) | YES | マクロブロック数 |
| FINISH_MACRO_BLOCK_COUNT | NUMBER(38) | YES | バックアップ完了のマクロブロック数 |
| FILE_COUNT | NUMBER(38) | YES | バックアップファイル数 |
| META_TURN_ID | NUMBER(38) | YES | バックアップMETAのラウンド |
| DATA_TURN_ID | NUMBER(38) | YES | バックアップDATAのラウンド |
| RESULT | NUMBER(38) | YES | バックアップエラーコード結果 |
| COMMENT | VARCHAR2(4096) | YES | エラーコードの説明 |
| PATH | VARCHAR2(4096) | YES | バックアップパス |
| MINOR_TURN_ID                 | NUMBER(38)     | NO              | ダンプデータバックアップ終了のラウンド      |
| MAJOR_TURN_ID                 | NUMBER(38)     | NO              | ベースラインデータバックアップ終了のラウンド      |
