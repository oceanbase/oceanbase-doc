# DBA_OB_TABLEGROUP_PARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.2.0以降では、テーブルグループにはパーティションの概念がなくなりました。このビューは使用されなくなりました。ユーザーはこのビューをクエリできますが、クエリ結果は空になります。</li>
<li>V4.2.0以降では、ビュー<a href="15700.dba_ob_tablegroups-of-oracle-mode.md">DBA_OB_TABLEGROUPS</a>を使用してテーブルグループ情報を照会できます。テーブルグループの詳細については、<a href="../../../300.database-object-management/200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md">テーブルグループについて</a>を参照してください。</li>
</ul>
</main>

## 機能の概要

パーティションを持つテーブルグループのパーティション情報を表示します。

## フィールドの説明

|        フィールド名        |       型       | NULL許容 |             説明                          |
|--------------------|----------------|------------|---------------------------|
| TABLEGROUP_NAME    | VARCHAR2(128)  | NO         | TABLEGROUP名                                            |
| COMPOSITE          | VARCHAR2(3)    | NO         | パーティションを持つテーブルグループがサブパーティションかどうか。値は`YES`または`NO`                             |
| PARTITION_NAME     | VARCHAR2(64)   | NO         | パーティションを持つテーブルグループのパーティション名                                              |
| SUBPARTITION_COUNT | NUMBER         | NO         | この値は`NULL`                  |
| HIGH_VALUE         | VARCHAR2(4096) | NO         | この値は`NULL`            |
| HIGH_VALUE_LENGTH  | NUMBER         | NO         | この値は`NULL`                             |
| PARTITION_POSITION | NUMBER         | NO         | この値は`NULL`   |
