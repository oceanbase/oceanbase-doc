# DBA_JOBS_RUNNING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

実行中のタスクを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名**  |    **型**     | **NULL許容** |         **説明**          |
|-----------|---------------|----------------|-------------------------|
| SID       | NUMBER        | NO             | このタスクを実行しているプロセスの識別子です。         |
| JOB       | NUMBER        | NO             | タスク識別子。                  |
| FAILURES  | NUMBER        | YES            | このタスクが前回正常に実行されて以来の成功と失敗の回数を記録します。 |
| LAST_DATE | DATE          | YES            | このタスクが前回正常に実行された日付です。           |
| LAST_SEC  | VARCHAR2(32)  | NO             | このタスクが前回正常に実行された開始時刻です。         |
| THIS_DATE | DATE          | YES            | このタスクの開始日です。             |
| THIS_SEC  | VARCHAR2(32)  | NO             | このタスクが正常に実行された開始時刻です。           |
| INSTANCE  | VARCHAR2(128) | YES            | Jobが実行されるZoneを指定します。        |
