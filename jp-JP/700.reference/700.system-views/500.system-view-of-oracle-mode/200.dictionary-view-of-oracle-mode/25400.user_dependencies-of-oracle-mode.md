# USER_DEPENDENCIES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザースキーマ内の各オブジェクト間の依存関係を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|       **フィールド名**       |    **タイプ**     | **NULLを許容するか** |      **説明**       |
|----------------------|---------------|----------------|-------------------|
| NAME                 | VARCHAR2(128) | NO             | 依存関係のある側の名前            |
| TYPE                 | VARCHAR2(23)  | NO             | 依存関係のある側のタイプ            |
| REFERENCED_OWNER     | VARCHAR2(128) | NO             | 依存関係のある側のOwner名    |
| REFERENCED_NAME      | VARCHAR2(128) | NO             | 依存関係のある側の名前           |
| REFERENCED_TYPE      | VARCHAR2(18)  | NO             | 依存関係のある側のタイプ           |
| REFERENCED_LINK_NAME | VARCHAR2(128) | NO             | 依存関係のある側のDblink名   |
| SCHEMAID             | NUMBER        | NO             | 現在のユーザーに対応するスキーマID |
| DEPENDENCY_TYPE      | VARCHAR2(4)   | NO             | この依存関係が強い依存関係またはその他の依存関係であることを示す   |

## クエリ例

現在のユーザースキーマ内の各オブジェクト間の依存関係を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_DEPENDENCIES;
```

クエリ結果は次のとおりです：

```shell
+-----------------+----------+------------------+------------------+-----------------+----------------------+----------+-----------------+
| NAME            | TYPE     | REFERENCED_OWNER | REFERENCED_NAME  | REFERENCED_TYPE | REFERENCED_LINK_NAME | SCHEMAID | DEPENDENCY_TYPE |
+-----------------+----------+------------------+------------------+-----------------+----------------------+----------+-----------------+
| VERIFY_FUNCTION | FUNCTION | SYS              | COMPLEXITY_CHECK | FUNCTION        | NULL                 |   201006 | HARD            |
| VERIFY_FUNCTION | SYNONYM  | SYS              | VERIFY_FUNCTION  | FUNCTION        | NULL                 |   201006 | HARD            |
+-----------------+----------+------------------+------------------+-----------------+----------------------+----------+-----------------+
2 rows in set (0.207 sec)
```
