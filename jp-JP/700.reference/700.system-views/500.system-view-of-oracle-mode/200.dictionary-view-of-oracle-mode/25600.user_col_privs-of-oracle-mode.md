# USER_COL_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがオブジェクト所有者、付与者、または被付与者として持つ列オブジェクトの権限付与状況を記述します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースのOracleモードは、現在列権限機能をサポートしていません。</p>
</main>

## フィールドの説明

|  **フィールド名**   |    **型**     | **NULL許容** |      **説明**      |
|-------------|---------------|----------------|------------------|
| GRANTEE     | VARCHAR2(128) | NO             | アクセス権限を付与されるユーザー名    |
| OWNER       | VARCHAR2(128) | NO             | オブジェクト所有者           |
| TABLE_NAME  | VARCHAR2(256) | NO             | オブジェクト名            |
| COLUMN_NAME | VARCHAR2(128) | NO             | 列名             |
| GRANTOR     | VARCHAR2(128) | NO             | 権限を付与するユーザー名       |
| PRIVILEGE   | VARCHAR2(40)  | NO             | 列に対する特権            |
| GRANTABLE   | VARCHAR2(3)   | NO             | GRANTで権限を付与できるかどうか |
