# USER_SYS_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーに付与されているシステム権限を一覧表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **型**     | **NULL許容** |      **説明**      |
|--------------|---------------|----------------|------------------|
| GRANTEE      | VARCHAR2(128) | NO             | 権限を付与される被許諾者の名前、ユーザー、またはロール |
| PRIVILEGE    | VARCHAR2(40)  | NO             | 付与されるシステム権限             |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | 管理オプションを付与するかどうか           |

## クエリ例

`SYS`ユーザーに付与されているシステム権限を確認し、最初の5件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM USER_SYS_PRIVS WHERE USERNAME='SYS' AND ROWNUM <=5;
```

クエリ結果は次のとおりです：

```shell
+----------+------------------+--------------+
| USERNAME | PRIVILEGE        | ADMIN_OPTION |
+----------+------------------+--------------+
| SYS      | CREATE SESSION   | YES          |
| SYS      | CREATE TABLE     | YES          |
| SYS      | CREATE ANY TABLE | YES          |
| SYS      | ALTER ANY TABLE  | YES          |
| SYS      | BACKUP ANY TABLE | YES          |
+----------+------------------+--------------+
5 rows in set
```
