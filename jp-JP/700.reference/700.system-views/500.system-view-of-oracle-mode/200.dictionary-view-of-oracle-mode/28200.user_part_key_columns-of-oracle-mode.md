# USER_PART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するすべてのパーティションオブジェクトにおいて、パーティションキーを構成する列を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|      **フィールド名**      |     **型**     | **NULL許容** |                                                              **説明**                                                              |
|--------------------|----------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| NAME               | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前                                   |
| OBJECT_TYPE        | CHAR(5)        | NO             | パーティションオブジェクトのタイプ：<ul><li> TABLE  </li> <li> INDEX   </li></ul> |
| COLUMN_NAME        | VARCHAR2(4000) | NO             | 列名                                              |
| COLUMN_POSITION    | NUMBER         | NO             | パーティションキーにおける列の位置                                     |
| COLLATED_COLUMN_ID | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在、このフィールドのデフォルト値はNULLです                       |

## クエリ例

ユーザーが所有するパーティションインデックス`TBL1_H_IDX1`のパーティションキーを構成する列を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_PART_KEY_COLUMNS WHERE NAME='TBL1_H_IDX1';
```

クエリ結果は次のとおりです：

```shell
+-------------+-------------+-------------+-----------------+--------------------+
| NAME        | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-------------+-------------+-------------+-----------------+--------------------+
| TBL1_H_IDX1 | INDEX       | COL2        |               1 |               NULL |
+-------------+-------------+-------------+-----------------+--------------------+
1 row in set
```
