# DBA_OB_BACKUP_STORAGE_INFO_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで使用されているバックアップ先の履歴情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| PATH | VARCHAR2(1024) | NO | バックアップのルートパス |
| ENDPOINT | VARCHAR2(256) | NO | オブジェクトストレージへのアクセスに必要なホスト |
| DEST_ID | NUMBER(38) | YES | バックアップ先の番号 |
| DEST_TYPE | VARCHAR2(64) | YES | バックアップ先のタイプ：<ul><li>`archive_log`：ログアーカイブ</li> <li>`backup_data`：データバックアップ</li></ul> |
| AUTHORIZATION | VARCHAR2(1024) | NO | オブジェクトストレージの認証情報 |
| EXTENSION | VARCHAR2(512) | NO | バックアップ先のその他のパラメータ |
| CHECK_FILE_NAME | VARCHAR2(256) | YES | 通信性検証ファイル名 |
| LAST_CHECK_TIMESTAMP | VARCHAR2(256) | NO | 前回の通信性チェックが成功した時間 |
