# DBA_OB_BACKUP_DELETE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のバックアップクリーンアップジョブタスクの実行進捗状況を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | ジョブID。一意で連番です。 |
| INCARNATION | NUMBER(38) | NO | 分身ID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | このJOBを開始したテナントID |
| INITIATOR_JOB_ID | NUMBER(38) | NO | このJOBを開始したテナントが属する
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | クリーンアップタスクを実行したテナントID |
| TYPE | VARCHAR2(64) | NO | クリーンアップタイプ：<ul><li>`DELETE OBSOLETE BACKUP`：期限切れクリーンアップ</li> <li>`DELETE BACKUP ALL`：パス内のすべてのバックアップまたはアーカイブデータを削除</li> <li>`DELETE BACKUPSET`：指定されたデータバックアップセットをクリーンアップ</li> <li>`DELETE ARCHIVELOG_PIECE`：指定されたログアーカイブPieceをクリーンアップ </li></ul> |
| PARAMETER | VARCHAR2(1024) | NO | クリーンアップパラメータ。クリーンアップタイプごとの具体的なパラメータ情報を記述します  |
| JOB_LEVEL | VARCHAR2(64) | NO | ジョブ開始レベル：<ul><li>`USER_TENANT`：ユーザーテナントが開始したタスク</li><li>`SYS_TENANT`：システムテナントが開始したタスク</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時のテナント現在時刻 |
| END_TIMESTAMP | VARCHAR2(256) | NO | タスク終了時のテナント現在時刻 |
| STATUS | VARCHAR2(64) | NO | タスクステータス：<ul><li>`INIT`：タスク初期化段階 </li><li>`DOING`：タスク実行段階 </li><li>`CANCELING`：タスクキャンセル中の段階 </li><li>`COMPLETED`：タスクが正常に実行された </li><li>`FAILED`：タスクの実行に失敗した </li><li>`CANCELED`：タスクが正常にキャンセルされた </li></ul>  |
| TASK_COUNT | NUMBER(38) | YES | backup_set/piece タスク数 |
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | backup_set/piece 実行成功タスク数 |
| RESULT | NUMBER(38) | NO | エラーコード |
| COMMENT | VARCHAR2(4096) | YES | タスク実行の説明 |

## クエリ例

ユーザーテナントが自身のテナント内のバックアップクリーンアップジョブタスクの実行進捗状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOBS\G
```

クエリ結果は次のとおりです。

