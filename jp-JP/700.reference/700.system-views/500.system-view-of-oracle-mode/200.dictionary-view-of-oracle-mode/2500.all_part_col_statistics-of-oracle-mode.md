# ALL_PART_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`ALL_PART_COL_STATISTICS`は、現在ユーザーがアクセス可能なパーティションテーブルのパーティションに関する列統計情報とヒストグラム情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|      フィールド名   |    **型**   | **NULL許容** |                            **説明**                      |
|----------------|---------------|----------------|---------------------------------------------------------------|
| OWNER          | VARCHAR2(128) | NO             | 列が属するユーザー                                                           |
| TABLE_NAME     | VARCHAR2(128) | NO             | テーブル名                                                               |
| PARTITION_NAME | VARCHAR2(128) | NO             | パーティション名                                                              |
| COLUMN_NAME    | VARCHAR2(128) | NO             | 列名                                                               |
| NUM_DISTINCT   | NUMBER        | YES            | 列の異なる値の数                                                         |
| LOW_VALUE      | VARCHAR2(128) | YES            | 列の最小値                                                            |
| HIGH_VALUE     | VARCHAR2(128) | YES            | 列の最大値                                                            |
| DENSITY        | NUMBER        | YES            | 列の密度                                                             |
| NUM_NULLS      | NUMBER        | YES            | 列内の`NULL`値の数                                                   |
| NUM_BUCKETS    | NUMBER        | YES            | 列のヒストグラムにおけるバケット数                                                        |
| SAMPLE_SIZE    | NUMBER        | YES            | 分析時のサンプルサイズ                                                         |
| LAST_ANALYZED  | DATE          | YES            | 最終分析日時                                                          |
| GLOBAL_STATS   | VARCHAR2(3)   | YES            | <ul><li>`YES`：統計情報が直接収集されたことを示します。   </li><li> `NO`：統計情報がサブパーティションの統計情報から推定されたか、統計情報が収集されていないことを示します。</li></ul>    |
| USER_STATS     | VARCHAR2(3)   | YES            | パーティション統計情報がユーザー設定であるかどうかを示します                                                 |
| NOTES          | VARCHAR2(80)  | YES            | 追加のプロパティを記録します                                                        |
| AVG_COL_LEN    | NUMBER        | YES            | 列の平均長                                                           |
| HISTOGRAM      | VARCHAR2(15)  | YES            | ヒストグラムタイプ                                                            |
