# ALL_LOCATIONS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

`ALL_LOCATIONS`は、現在のテナントのExternal Locationオブジェクト情報を確認するために使用します。

<main id="notice" >
  <h4>適用対象</h4>
  <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>

## フィールドの説明

|        **フィールド名**         |     **タイプ**     | **NULL許容** |               **説明**               |
|-------------------------|----------------|----------------|--------------------------------------------------------------------|
| OWNER         | VARCHAR2(128)  | NO   | 所属するOwner |
| LOCATION_NAME | VARCHAR2(128)  | YES  | 名前 |
| LOCATION_URL  | VARCHAR2(4000) | YES  | パス |
| ORIGIN_CON_ID | NUMBER(38)     | NO   | テナントID |
| ACCESS_INFO   | VARCHAR2(8000) | YES  | アクセス情報 |
|---------------|----------------|------|------|

## クエリ例

現在のテナントのExternal Locationオブジェクト情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_LOCATIONS ;
```
