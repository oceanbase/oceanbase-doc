# USER_PLSQL_TYPES

<main id="notice" >
    <h4>説明</h4>
    <p>このビューはV4.2.5バージョンから導入されました。パッケージが正常にコンパイルされた場合にのみ、そのパッケージ内の型がこのビューに表示されます。</p>
  </main>

## 機能の概要

現在のユーザーが持つすべてのPL/SQLデータ型の情報を表示します。

<main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|         **フィールド名**          |     **タイプ**     | **NULLを許容するか** |**説明**|
|---------------------------|---|---|--------------------------------------------|
| TYPE_NAME      | VARCHAR2(136) | NO   | PL/SQL型の名前。 |
| PACKAGE_NAME   | VARCHAR2(128) | YES  | PL/SQL型が属するパッケージの名前。 |
| TYPE OID       | RAW(16)       | NO   | PL/SQL型のオブジェクト識別子。 |
| TYPECODE       | VARCHAR2(58)  | NO   | PL/SQL型のコード。 |
| ATTRIBUTES     | NUMBER(38)    | NO   | PL/SQL型に含まれるプロパティの数。 |
| CONTAINS_PLSQL | VARCHAR2(3)   | NO   | PL/SQL型がPL/SQLコードを含むかどうか。 |

## クエリ例

現在のユーザーが持つすべてのPL/SQLデータ型の情報を確認します。

```sql
obclient> SELECT * FROM USER_PLSQL_TYPES;
```

クエリ結果は次のとおりです：

```shell
+-----------+--------------+----------+------------+------------+----------------+
| TYPE_NAME | PACKAGE_NAME | TYPE_OID | TYPECODE   | ATTRIBUTES | CONTAINS_PLSQL |
+-----------+--------------+----------+------------+------------+----------------+
| TY1       | PKG1         | NULL     | COLLECTION |          0 | NO             |
| TY2       | PKG1         | NULL     | COLLECTION |          0 | NO             |
+-----------+--------------+----------+------------+------------+----------------+
2 rows in set
```
