# USER_PLSQL_TYPES

<main id="notice" >
    <h4>説明</h4>
    <p>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。<br>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</p>
  </main>

## 機能の概要

`USER_PLSQL_TYPES` ビューは、現在のユーザー配下のパッケージタイプの全体的な情報を表示するために使用されます。パッケージが正常にコンパイルされた場合にのみ、そのパッケージ内のタイプがこのビューに表示されます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|         **フィールド名**          |     **タイプ**     | **NULL許容** |**説明**|
|---------------------------|---|---|--------------------------------------------|
| TYPE_NAME      | VARCHAR2(136) | NO   | PL/SQLタイプの名前。 |
| PACKAGE_NAME   | VARCHAR2(128) | YES  | PL/SQLタイプが属するパッケージの名前。 |
| TYPE OID       | RAW(16)       | NO   | PL/SQLタイプのオブジェクト識別子。 |
| TYPECODE       | VARCHAR2(58)  | NO   | PL/SQLタイプのコード。 |
| ATTRIBUTES     | NUMBER(38)    | NO   | PL/SQLタイプが含む属性の数。 |
| CONTAINS_PLSQL | VARCHAR2(3)   | NO   | PL/SQLタイプがPL/SQLコードを含むかどうか。 |

## クエリ例

現在のユーザー配下のパッケージタイプの全体的な情報を照会します。

```shell
obclient> SELECT * FROM USER_PLSQL_TYPES;
```
