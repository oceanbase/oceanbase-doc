# DBA_OB_TABLE_STAT_STALE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

前回統計情報を収集して以来、各テーブルで発生したDML操作の回数と、現在の統計情報が有効期限切れかどうかを表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | NO | テーブルの所有者 |
| TABLE_NAME | VARCHAR2(128) | NO | テーブル名 |
| PARTITION_NAME | VARCHAR2(128) | YES | パーティション名。パーティションテーブルにおいてこの列の値がNULLの場合、現在のレコードはテーブルレベルで集計されていることを示します |
| SUBPARTITION_NAME | VARCHAR2(128) | YES | サブパーティション名。サブパーティションテーブルにおいてこの列の値がNULLの場合、現在のレコードはテーブルレベルまたはパーティションレベルで集計されていることを示します |
| LAST_ANALYZED_ROWS | NUMBER | YES | 前回統計情報を収集した際の行数。値がNULLの場合、統計情報が収集されたことがないことを示します |
| LAST_ANALYZED_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 前回統計情報を収集した際の時間。値がNULLの場合、統計情報が収集されたことがないことを示します |
| INSERTS | NUMBER | NO | 前回統計情報を収集してから、何行が挿入されたか |
| UPDATES | NUMBER | NO | 前回統計情報を収集してから、何行が更新されたか |
| DELETES | NUMBER | NO | 前回統計情報を収集してから、何行が削除されたか |
| STALE_PERCENT | NUMBER | NO | 統計情報が期限切れとなる判定基準となる割合 |
| IS_STALE | VARCHAR2(3) | NO | 統計情報が期限切れかどうか。<ul><li>`YES` 期限切れを示します <ul><li>テーブルに統計情報が収集されている場合、期限切れの条件は `INSERTS + UPDATES + DELETES > LAST_ANALYZED_ROWS * STALE_PERCENT / 100`  </li><li>テーブルに統計情報が収集されていない場合、期限切れの条件は `INSERTS + UPDATES + DELETES > 0` </li></ul>  </li><li>`NO` 期限切れではないことを示します </li></ul>

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLE_STAT_STALE_INFO WHERE TABLE_NAME='T_SUBPART';
```
