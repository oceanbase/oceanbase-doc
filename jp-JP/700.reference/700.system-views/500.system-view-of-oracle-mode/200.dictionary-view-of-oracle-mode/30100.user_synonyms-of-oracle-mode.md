# USER_SYNONYMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するシノニムを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **型**     | **NULL許容** |                          **説明**                          |
|--------------|---------------|----------------|----------------------------------------------------------|
| SYNONYM_NAME | VARCHAR2(128) | NO             | シノニム名                                                    |
| TABLE_OWNER  | VARCHAR2(128) | NO             | シノニムが参照するオブジェクトの名前。ここでのTABLE_NAMEは単なる列名にすぎず、シノニムは他のオブジェクト（ビューなど）のシノニムでも構いません |
| TABLE_NAME   | VARCHAR2(128) | NO             | シノニムが参照するオブジェクト名                                               |
| DB_LINK      | VARCHAR2(128) | NO             | データベースリンクを参照している場合、そのデータベースリンクの名前を表します                           |

## クエリ例

現在のユーザーが所有するすべてのシノニムを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_SYNONYMS;
```

クエリ結果は次のとおりです：

```shell
+--------------+-------------+------------+---------+---------------+
| SYNONYM_NAME | TABLE_OWNER | TABLE_NAME | DB_LINK | ORIGIN_CON_ID |
+--------------+-------------+------------+---------+---------------+
| S1           | SYS         | TEST       | NULL    |             0 |
+--------------+-------------+------------+---------+---------------+
1 row in set
```
