# USER_COL_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがオブジェクトの所有者、付与者、または被付与者であるかどうかを示す列オブジェクトの付与を記述します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースのOracleモードでは、現在列権限機能はサポートされていません。</p>
</main>

## フィールドの説明

|  **フィールド名**   |    **タイプ**     | **NULL値を許容するか** |      **説明**      |
|-------------|---------------|----------------|------------------|
| GRANTEE     | VARCHAR2(128) | NO             | アクセス権限が付与されるユーザーの名前    |
| OWNER       | VARCHAR2(128) | NO             | オブジェクトの所有者           |
| TABLE_NAME  | VARCHAR2(256) | NO             | オブジェクトの名前            |
| COLUMN_NAME | VARCHAR2(128) | NO             | 列の名前             |
| GRANTOR     | VARCHAR2(128) | NO             | 権限付与を実行するユーザーの名前       |
| PRIVILEGE   | VARCHAR2(40)  | NO             | 列上の特権            |
| GRANTABLE   | VARCHAR2(3)   | NO             | GRANTによる権限付与が可能か |
