# ALL_ERRORS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできる現在のストレージオブジェクトのエラーメッセージを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**    |     **タイプ**     | **NULLを許容するか** |                                             **説明**                                              |
|----------------|----------------|----------------|-----------------------------------|
| OWNER          | VARCHAR2(128)  | NO             | オブジェクトの所有者。      |
| NAME           | VARCHAR2(128)  | NO             | オブジェクトの名前。       |
| TYPE           | VARCHAR2(19)   | NO             | オブジェクトのタイプ：<ul><li> VIEW   </li><li> PROCEDUCE   </li><li> FUNCTION   </li><li> PACKAGE   </li><li> PACKAGE_BODY   </li><li> TRIGGER   </li><li> TYPE   </li><li> TYPE BODY   </li><li> LIBRARY   </li><li> JAVA SOURCE   </li><li> JAVA CLASS   </li><li> DIMENSION </li></ul>   |
| SEQUENCE       | NUMBER         | NO             | 同一コンパイルで複数のエラーが発生した場合のエラー番号（ソート用）。                                                                          |
| LINE           | NUMBER         | NO             | エラー発生行。      |
| POSITION       | NUMBER         | NO             | エラー発生列。      |
| TEXT           | VARCHAR2(4000) | NO             | エラーメッセージテキスト。      |
| ATTRIBUTE      | VARCHAR2(9)    | NO             | ErrorかWarningかを示す。                                                                           |
| MESSAGE_NUMBER | number         | NO             | エラーコード。        |
