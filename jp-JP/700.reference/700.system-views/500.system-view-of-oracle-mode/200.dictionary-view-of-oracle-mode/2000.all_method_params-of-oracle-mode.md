# ALL_METHOD_PARAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースは、このビューをサポートしていません。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできるオブジェクトタイプのメソッドパラメータを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|      **フィールド名**      |    **タイプ**    | **NULLを許容するか** |                                                                                **説明**                                                                                |
|--------------------|--------------|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | VARCHAR2(30) | NO             | タイプの所有者                                                                            |
| TYPE_NAME          | VARCHAR2(30) | NO             | タイプ名                                                                              |
| METHOD_NAME        | VARCHAR2(30) | NO             | メソッド名                                                                              |
| METHOD_NO          | NUMBER       | NO             | オーバーロードされたメソッドについて、この番号は同じ名前の別のメソッドと区別します。これをオブジェクトIDと混同しないでください。                                          |
| PARAM_NAME         | VARCHAR2(30) | NO             | パラメータ名                                                                             |
| PARAM_NO           | NUMBER       | NO             | パラメータ番号（正の数）                                                                          |
| PARAM_MODE         | VARCHAR2(6)  | NO             | パラメータモード：<ul><li> IN   </li><li> OUT   </li><li> IN OUT  </li></ul> |
| PARAM_TYPE_MOD     | VARCHAR2(7)  | NO             | パラメータが他のオブジェクトを参照するかどうか                                                                       |
| PARAM_TYPE_OWNER   | VARCHAR2(30) | NO             | パラメータタイプの所有者                                                                          |
| PARAM_TYPE_NAME    | VARCHAR2(30) | NO             | パラメータタイプの名前                                                                           |
| CHARACTER_SET_NAME | VARCHAR2(44) | NO             | デフォルト値はNULL |
