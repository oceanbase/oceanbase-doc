# DBA_IND_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのインデックスに関するオプティマイザー統計情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | NO | インデックス所有者 |
| INDEX_NAME | VARCHAR2(128) | NO | インデックス名 |
| TABLE_OWNER | VARCHAR2(128) | NO | インデックス対象の所有者 |
| TABLE_NAME | VARCHAR2(128) | NO | インデックス対象の名前 |
| PARTITION_NAME | VARCHAR2(128) | NO | パーティション名 |
| PARTITION_POSITION | NUMBER | NO | インデックス内のパーティション位置 |
| SUBPARTITION_NAME | VARCHAR2(128) | NO | サブパーティション名 |
| SUBPARTITION_POSITION | NUMBER | NO | パーティション内のサブパーティション位置 |
| OBJECT_TYPE | VARCHAR2(12) | NO | オブジェクトタイプ：<ul><li>INDEX</li><li>PARTITION</li><li>SUBPARTITION</li></ul> |
| BLEVEL | NUMBER | NO | デフォルト値はNULL |
| LEAF_BLOCKS | NUMBER | NO | デフォルト値はNULL |
| DISTINCT_KEYS | NUMBER | NO | デフォルト値はNULL |
| AVG_LEAF_BLOCKS_PER_KEY | NUMBER | NO | デフォルト値はNULL |
| AVG_DATA_BLOCKS_PER_KEY | NUMBER | NO | デフォルト値はNULL |
| CLUSTERING_FACTOR | NUMBER | NO | デフォルト値はNULL |
| NUM_ROWS | NUMBER | NO | インデックス内の行数 |
| AVG_CACHED_BLOCKS | NUMBER | NO | デフォルト値はNULL |
| AVG_CACHE_hit_RATIO | NUMBER | NO | デフォルト値はNULL |
| SAMPLE_SIZE | NUMBER | NO | デフォルト値はNULL |
| LAST_ANALYZED | DATE | NO | 最終インデックス分析日付 |
| GLOBAL_STATS | VARCHAR2(3) | NO | 統計情報が収集または増分メンテナンスされているかどうかを示します。<ul><li>YES</li><li>NO</li></ul> |
| USER_STATS | VARCHAR2(3) | NO | 統計情報がユーザーによって直接入力されたかどうかを示します。<ul><li>YES</li><li>NO</li></ul> |
| STATTYPE_LOCKED | VARCHAR2(5) | NO | 統計ロックタイプ |
| STALE_STATS | VARCHAR2(3) | NO | オブジェクトの統計情報が古くなっているかどうか |
| SCOPE | VARCHAR2(7) | NO | デフォルト値はNULL |
