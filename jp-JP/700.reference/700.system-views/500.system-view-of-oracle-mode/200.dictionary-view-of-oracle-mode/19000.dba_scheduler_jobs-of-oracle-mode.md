# DBA_SCHEDULER_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なスケジューラーのジョブ情報を表示します。

## フィールド説明

|      フィールド名 |    型           | NULL許容   |    説明    |
|--------------|---------------|---------------|------------|
| OWNER | VARCHAR2(128) | NO | スケジューラー・ジョブの所有者 |
| JOB_NAME | VARCHAR2(128) | NO | スケジューラー・ジョブ名 |
| JOB_SUBNAME | VARCHAR2(128) | NO | スケジューラー・ジョブのサブ名 |
| JOB_STYLE | VARCHAR2(17) | YES | デフォルト値はNULL |
| JOB_CREATOR | VARCHAR2(128) | NO | スケジューラー・ジョブ作成者 |
| CLIENT_ID | VARCHAR2(65) | NO | ジョブを作成したユーザーのクライアント識別子 |
| GLOBAL UID | VARCHAR2(33) | NO | ジョブを作成したユーザーのグローバルユーザー識別子 |
| PROGRAM_OWNER | VARCHAR2(4000) | NO | ジョブに関連するプログラムの所有者 |
| PROGRAM_NAME | VARCHAR2(4000) | YES | ジョブに関連するプログラム名 |
| JOB_TYPE | VARCHAR2(16) | YES |  ジョブ操作タイプ：<ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul> |
| JOB_ACTION | VARCHAR2(4000) | YES | インライン・ジョブ操作 |
| NUMBER_OF_ARGUMENTS | NUMBER | YES | ジョブパラメータのインライン数 |
| SCHEDULE_OWNER | VARCHAR2(4000) | NO | ジョブで使用されるスケジュールの所有者 |
| SCHEDULE_NAME | VARCHAR2(4000) | NO | ジョブで使用されるスケジュール名 |
| SCHEDULE_TYPE | VARCHAR2(12) | NO | デフォルト値はNULL |
| START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブの元のスケジュール開始日 |
| REPEAT_INTERVAL | VARCHAR2(4000) | YES | インラインスケジュールPL/SQL式またはカレンダーストリング |
| EVENT_QUEUE_OWNER | VARCHAR2(128) | NO | イベントが発生するソースキューの所有者 |
| EVENT_QUEUE_NAME | VARCHAR2(128) | NO | イベントが発生するソースキュー名 |
| EVENT_QUEUE_AGENT | VARCHAR2(523) | NO | ユーザーがイベントソースキューで使用するAQエージェント名 |
| EVENT_CONDITION | VARCHAR2(4000) | NO | ソースキュー上のイベントのサブスクリプションルール |
| EVENT_RULE | VARCHAR2(261) | NO | コーディネーターがイベントベースのジョブをトリガーするために使用するルール名 |
| FILE_WATCHER_OWNER | VARCHAR2(261) | NO | そのジョブが基づいているファイルウォッチャーの所有者 |
| FILE_WATCHER_NAME | VARCHAR2(261) | NO | そのジョブが基づいているファイルウォッチャー名 |
| END_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブが実行されなくなる日付 |
| JOB_CLASS | VARCHAR2(128) | YES | ジョブに関連付けられたジョブカテゴリ名 |
| ENABLED | VARCHAR2(5) | YES | ジョブが有効かどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| AUTO_DROP | VARCHAR2(5) | YES | ジョブ完了後に削除されるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul>  |
| RESTART_ON_RECOVERY | VARCHAR2(5) | NO | デフォルト値はNULL |
| RESTART_ON_FAILURE | VARCHAR2(5) | NO | デフォルト値はNULL |
| STATE | VARCHAR2(15) | YES | 実行状況:<ul><li>DISABLED</li><li>RETRY SCHEDULED</li><li>SCHEDULED</li><li>BLOCKED</li><li>RUNNING</li><li>COMPLETED</li><li>BROKEN</li><li>FAILED</li><li>REMOTE</li><li>RESOURCE_UNAVAILABLE</li><li>SUCCEEDED</li><li>CHAIN_STALLED </li></ul>|
| JOB_PRIORITY | NUMBER | NO | ジョブの優先順位 |
| RUN_COUNT | NUMBER | YES | ジョブの実行回数 |
| MAX_RUNS | NUMBER | NO | ジョブの最大実行回数 |
| FAILURE_COUNT | NUMBER | YES | ジョブの失敗回数 |
| MAX_FAILURES | NUMBER | NO | 損傷としてマークされるまでに許容されるジョブの失敗回数 |
| RETRY_COUNT | NUMBER | YES | ジョブの再試行回数 |
| LAST_START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブが最後に開始された日付 |
| LAST_RUN_DURATION | INTERVAL DAY (9) TO SECOND (6) | NO | 前回の実行でジョブを完了するのにかかった時間 |
| NEXT_RUN_DATE | TIMESTAMP(6) WITH TIME ZONE | NO | ジョブの次回の予定実行日 |
| SCHEDULE_LIMIT | INTERVAL DAY (3) TO SECOND (0) | NO | 未実行のジョブが再スケジュールされる時刻 |
| MAX_RUN_DURATION | INTERVAL DAY (3) TO SECOND (0) | NO | ジョブの実行可能な最大時間 |
| LOGGING_LEVEL | VARCHAR2(11) | NO | デフォルト値はNULL |
| STORE_OUTPUT | VARCHAR2(5) | NO | デフォルト値はNULL |
| STOP_ON_WINDOW_CLOSE | VARCHAR2(5) | NO | デフォルト値はNULL |
| INSTANCE_STICKINESS | VARCHAR2(5) | NO | デフォルト値はNULL |
| RAISE_EVENTS | VARCHAR2(4000) | NO | デフォルト値はNULL |
| SYSTEM | VARCHAR2(5) | NO | デフォルト値はNULL |
| JOB_WEIGHT | NUMBER | NO | ジョブの重み。スケジューリング時の優先順位を指定するために使用されます。 |
| NLS_ENV | VARCHAR2(4000) | YES | ジョブの言語環境設定。 |
| SOURCE | VARCHAR2(128) | NO | ジョブのソースコードまたはスクリプト。 |
| NUMBER_OF_DESTINATIONS | NUMBER | NO | ジョブのターゲット数。 |
| DESTINATION_OWNER | VARCHAR2(261) | NO | ジョブターゲットの所有者。 |
| DESTINATION | VARCHAR2(261) | NO | ジョブのターゲット、つまりジョブが実行する対象または場所。 |
| CREDENTIAL_OWNER | VARCHAR2(128) | NO | 資格情報の所有者。 |
| CREDENTIAL_NAME | VARCHAR2(128) | NO | 資格情報の名前。 |
| INSTANCE_ID | NUMBER | YES | ユーザーがジョブの実行を要求したインスタンス |
| DEFERRED_DROP | VARCHAR2(5) | NO | ジョブの削除を遅延させるかどうか。 |
| ALLOW_RUNS_IN_RESTRICTED_MODE | VARCHAR2(5) | NO | ジョブが制限モードで実行されるかどうか。 |
| COMMENTS | VARCHAR2(4000) | YES | ジョブのコメントまたは説明情報。 |
| FLAGS | NUMBER | NO | ジョブのフラグビット。 |
| RESTARTABLE | VARCHAR2(5) | NO | ジョブを再開できるかどうかを示します。 |
| CONNECT_CREDENTIAL_OWNER | VARCHAR2(128) | NO | 接続資格の所有者です。 |
| CONNECT_CREDENTIAL_NAME | VARCHAR2(128) | NO | 接続資格の名前です。 |
