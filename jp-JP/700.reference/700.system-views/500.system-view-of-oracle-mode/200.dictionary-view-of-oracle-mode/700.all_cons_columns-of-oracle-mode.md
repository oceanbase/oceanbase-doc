# ALL_CONS_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーがアクセスできるすべてのテーブルの制約に含まれる列情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**     |     **タイプ**     | **NULLを許容するか** |  **説明**  |
|-----------------|----------------|----------------|----------|
| OWNER           | VARCHAR2(128)  | NO             | 约束の所有者   |
| CONSTRAINT_NAME | VARCHAR2(128)  | NO             | 约束名     |
| TABLE_NAME      | VARCHAR2(128)  | NO             | 约束が存在するテーブル名 |
| COLUMN_NAME     | VARCHAR2(4000) | NO             | 约束内の列名   |
| POSITION        | NUMBER         | NO             | 列が約束内での位置 |

## クエリ例

ユーザーがアクセスできるすべてのテーブルのうち、テーブル`TBL3`の制約に含まれる列情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_CONS_COLUMNS WHERE TABLE_NAME='TBL3';
```

クエリ結果は次のとおりです：

```shell
+-------+----------------------------+------------+-------------+----------+
| OWNER | CONSTRAINT_NAME            | TABLE_NAME | COLUMN_NAME | POSITION |
+-------+----------------------------+------------+-------------+----------+
| SYS   | TBL3_OBPK_1744012420113641 | TBL3       | COL1        |        1 |
+-------+----------------------------+------------+-------------+----------+
1 row in set
```
