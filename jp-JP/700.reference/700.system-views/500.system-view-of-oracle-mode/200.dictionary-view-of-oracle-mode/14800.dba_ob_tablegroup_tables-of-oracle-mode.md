# DBA_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのテーブルグループとテーブル間の関連関係を表示します。テーブルグループに属していないテーブルは表示されません。

## フィールドの説明

|      フィールド名       |      タイプ       | NULLを許容するか |      説明       |
|-----------------|---------------|------------|---------------|
| TableGROUP_NAME | VARCHAR2(128) | NO         | テーブルグループ名           |
| OWNER           | VARCHAR2(128) | NO         | テーブルが属するデータベース名 |
| TABLE_NAME      | VARCHAR2(256) | NO         | テーブル名       |
| SHARDING        | VARCHAR2(10)  | NO         | テーブルグループのSHARDINGプロパティ：<ul><li>`NONE`：テーブルグループ内のすべてのテーブルのすべてのパーティションは同一マシンに集約され、テーブルグループに追加されるテーブルに制限はありません。</li> <li>`PARTITION`：テーブルグループ内の各テーブルのデータはパーティション単位で分散されます。パーティションテーブルの場合、パーティション内のすべてのコンポジットパーティションは一緒に集約されます。</li> <li>`ADAPTIVE`：テーブルグループ内の各テーブルのデータは適応型方式に基づいて分散されます。つまり、テーブルグループ内のテーブルがパーティションテーブルの場合はパーティション単位で分散され、コンポジットパーティションテーブルの場合は各パーティション内のコンポジットパーティション単位で分散されます。</li></ul>  |

## クエリ例

ユーザーテナントが、自身のテナント内で名前が `TBLGROUP1` のテーブルグループの関連関係を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'TBLGROUP1';
```

クエリ結果は次のとおりです：

```shell
+-----------------+-------+------------+----------+
| TABLEGROUP_NAME | OWNER | TABLE_NAME | SHARDING |
+-----------------+-------+------------+----------+
| TBLGROUP1       | SYS   | TBL3       | NONE     |
+-----------------+-------+------------+----------+
1 row in set
```
