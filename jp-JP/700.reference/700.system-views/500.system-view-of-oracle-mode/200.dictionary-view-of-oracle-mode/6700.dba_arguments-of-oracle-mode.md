# DBA_ARGUMENTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで利用可能な関数とプロシージャのパラメータを表示します。列は `ALL_ARGUMENTS` ビューの列と同じです。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|      **フィールド名**      |    **型**     | **NULL許容** |     **説明**      |
|--------------------|---------------|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | VARCHAR2(128) | NO             | オブジェクトの所有者        |
| OBJECT_NAME        | VARCHAR2(128) | YES            | プロシージャまたは関数名         |
| PACKAGE_NAME       | VARCHAR2(128) | YES            | パッケージ名              |
| OBJECT_ID          | NUMBER        | NO             | オブジェクトID           |
| OVERLOAD           | NUMBER        | YES            | パッケージソースファイル内でのオーバーロード回数  |
| SUBPROGRAM_ID      | NUMBER        | YES            | パッケージ内での順序。独立したプロシージャや関数ではこの値は1になります。                                                                          |
| ARGUMENT_NAME      | VARCHAR2(128) | YES            | パラメータ名。この値がNULLの場合、関数の戻り値を表します。</li> |
| POSITION           | NUMBER(38)    | NO             | パラメータリスト内での位置     |
| SEQUENCE           | NUMBER(38)    | NO             | 複合型の場合、この値はプロパティの番号を表します。|
| DATA_LEVEL         | NUMBER(38)    | NO             | ネストされた複合型の場合、この値は現在の型のネストレベルを表します。                                                                            |
| DATA_TYPE          | VARCHAR2(128) | YES            | パラメータのデータ型。ネストされた複合型の場合、この値は現在の層のデータ型を表します。                                                                    |
| DEFAULTED          | CHAR(2)       | YES            | 現在のパラメータにデフォルト値があるかどうかを示します。    |
| DATA_LENGTH        | NUMBER(38)    | YES            | データ型の長さ         |
| IN_OUT             | VARCHAR2(5)   | YES            | パラメータの入出力属性（NULLは戻り値を表します）：<ul><li> IN   </li><li> OUT   </li><li> IN OUT</li></ul>    |
| DATA_PRECISION     | NUMBER(38)    | YES            | 数値型の最大長       |
| DATA_SCALE         | NUMBER(38)    | YES            | 数値型の小数点以下のデータ長  |
| CHARACTER_SET_NAME | VARCHAR2(7)   | YES            | パラメータの文字セット名         |
| COLLATION          | VARCHAR2(18)  | YES            | 文字セットのソート規則         |
| TYPE_OWNER         | NUMBER(38)    | YES            | 複合データ型の型所有者    |
| TYPE_NAME          | VARCHAR2(128) | YES            | 複合データ型の名前       |
| TYPE_SUBNAME       | VARCHAR2(128) | YES            | パッケージ内の型の場合、このフィールドはパッケージ名を表す                                                                 |
| ORIGIN_CON_ID      | NUMBER(38)    | YES            | このフィールドは現在テナントIDを表す    |
