# ALL_SYNONYMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできるすべてのシノニムを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULLを許容するか** |                          **説明**                          |
|--------------|---------------|----------------|----------------------------------------------------------|
| OWNER        | VARCHAR2(128) | NO             | シノニムの所有者                                                  |
| SYNONYM_NAME | VARCHAR2(128) | NO             | シノニム名                                                    |
| TABLE_OWNER  | VARCHAR2(128) | NO             | シノニムが参照する対象の名前。ここでのTABLE_NAMEは単なる列名であり、シノニムは他のオブジェクト（例えばビューなど）に対するシノニムでもよい |
| TABLE_NAME   | VARCHAR2(128) | NO             | シノニムが参照する対象の名前                                               |
| DB_LINK      | VARCHAR2(128) | NO             | 参照しているのがDBリンクの場合、そのDBリンクの名前を表す                           |

## クエリ例

現在のユーザーがアクセスできるすべてのシノニムを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_SYNONYMS;
```

クエリ結果は次のとおりです：

```shell
+----------+--------------+-------------+------------+---------+
| OWNER    | SYNONYM_NAME | TABLE_OWNER | TABLE_NAME | DB_LINK |
+----------+--------------+-------------+------------+---------+
| __public | SYN_PUB      | SYS         | TEST       | NULL    |
| SYS      | S1           | SYS         | TEST       | NULL    |
+----------+--------------+-------------+------------+---------+
2 rows in set
```
