# USER_MVIEWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

`USER_MVIEWS` ビューは、マテリアライズドビューの情報を表示するために使用されます。
