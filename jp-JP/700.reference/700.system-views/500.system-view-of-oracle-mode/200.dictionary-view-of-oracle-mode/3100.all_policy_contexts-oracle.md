# ALL_POLICY_CONTEXTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なビューのコンテキスト情報を表示します。ビューにアクセスする際、コンテキストの値に基づいて対応するポリシーグループが適用されます。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | ポリシーで制御されるオブジェクトの所有者 |
| OBJECT_NAME | VARCHAR2(128) | YES | ポリシーで制御されるオブジェクトの名前 |
| NAMESPACE | VARCHAR2(128) | NO | 関連するコンテキスト名 |
| ATTRIBUTE | VARCHAR2(128) | NO | 関連するコンテキスト内の属性名 |
| COMMON | VARCHAR2(3) | NO | 互換性のためにのみ使用され、現在の値は常にNOです。 |
| INHERITED | VARCHAR2(3) | NO | 互換性のためにのみ使用され、現在の値は常にNOです。 |

## クエリ例

すべてのビューのポリシーグループのコンテキスト情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_POLICY_CONTEXTS;
```

クエリ結果は次のとおりです：

```shell
+--------------+--------------+------------+----------------+--------+-----------+
| OBJECT_OWNER | OBJECT_NAME  | NAMESPACE  | ATTRIBUTE      | COMMON | INHERITED |
+--------------+--------------+------------+----------------+--------+-----------+
| SYS          | V_ORDERS_CTX | REGION_CTX | CURRENT_REGION | NO     | NO        |
| SYS          | V_ORDERS_CTX | DEPT_CTX   | CURRENT_DEPT   | NO     | NO        |
+--------------+--------------+------------+----------------+--------+-----------+
2 rows in set
```
