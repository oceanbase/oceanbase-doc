# DBA_OB_LS_LOCATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのログストリーム（LS）レプリカの分布情報を表示します。

## フィールドの説明

|     フィールド名     |      タイプ       | NULL値を許容するか |                                                                          説明                                                                           |
|--------------|---------------|------------|-------------------------------------|
| CREATE_TIME        | VARCHAR2(19)    | NO         | 作成時間                                                              |
| MODIFY_TIME        | VARCHAR2(19)    | NO         | 変更時間                                                              |
| SVR_IP       | varchar2(46)   | NO         | サーバーIPアドレス                                                          |
| SVR_PORT     | NUMBER    | NO         | サーバーのポート番号                                                             |
| SQL_PORT     | NUMBER    | NO         | SQLポート番号                                                            |
| ZONE         | varchar2(128)  | NO         | Zone名                                                            |
| ROLE         | varchar2(8)    | NO         | レプリカロール：<ul><li>`LEADER`   </li><li> `FOLLOWER` </li><li>    |
| MEMBER_LIST  | varchar2(4480) | NO         | レプリカメンバーリスト。複数のレプリカ間はカンマで区切る。<ul><li>ロールが`LEADER`の場合、このフィールドは有効です。単一レプリカの表示形式は`svr_ip:svr_port:timestamp`です。その内訳は以下の通りです：<ul><li>`svr_ip`：レプリカが存在するマシンのIPアドレス</li> <li>`svr_port`：レプリカが存在するマシンのポート番号</li> <li>`timestamp`：レプリカがメンバーリストに追加された時間。デフォルトは`1`です。レプリカの補完や移行操作が行われた場合、この値は変更されます</li></ul></br> 表示例：172.xx.xxx.xxx:2882:1</li> <li>ロールが`LEADER`以外の場合、このフィールドは`NULL`として表示されます。</li></ul>   |
| PAXOS_REPLICA_NUMBER | NUMBER | NO         | Paxosの法定レプリカ数：ロールが`LEADER`の場合、このフィールドは有効です。それ以外の場合は`NULL`となります                       |
| REPLICA_TYPE | varchar2(18)   | NO         | レプリカタイプ：<ul><li>`FULL`：フル機能タイプのレプリカ   </li><li> `READONLY`：読み取り専用タイプのレプリカ </li><li>  |
| LEARNER_LIST | CLOB           | YES  | 現在のログストリームの読み取り専用レプリカリストで、複数のレプリカはカンマで区切られます。単一レプリカの表示形式は `svr_ip:svr_port:timestamp:flag` です。そのうち：<ul><li>`svr_ip`：レプリカが存在するマシンのIPアドレス</li> <li>`svr_port`：レプリカが存在するマシンのポート番号</li> <li>`timestamp`：レプリカが追加された時間。デフォルトは `1` です。補完レプリカまたは移行レプリカ操作が実行された場合、この値は変更されます</li> <li>`flag`：レプリカが移行中かどうか。`0` はレプリカが移行中ではないことを示し、`2` はレプリカが移行中であることを示します。</li></ul></br> 表示例：172.xx.xxx.xxx:2882:1:0  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REBUILD      | VARCHAR2(5)    | NO   | このレプリカがRebuild中かどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main>|
