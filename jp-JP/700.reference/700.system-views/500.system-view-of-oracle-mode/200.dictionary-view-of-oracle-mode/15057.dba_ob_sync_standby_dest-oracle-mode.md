# DBA_OB_SYNC_STANDBY_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_SYNC_STANDBY_DEST`は、テナントの強力同期ダウンストリーム情報を表示するために使用されます。

## フィールドの説明

| フィールド名   | 型          | NULL許容 | 説明                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | NUMBER(38)   | NO             | テナントID     |
| DEST_ID   | NUMBER(38)   | NO             | 強力同期スタンバイテナントのID。現在、1つのプライマリテナントがIDが0の強力同期スタンバイテナントを1つしか持てない制限があります     |
| VALUE     | CLOB         | NO             | 強力同期のスタンバイテナント情報。ip_list、ログイン名、パスワード、cluster_idなどが含まれます     |

## クエリ例

ユーザーテナントが自身のテナントの強力同期ダウンストリーム情報を照会します。

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_SYNC_STANDBY_DEST\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
TENANT_ID: 1004
  DEST_ID: 0

1 row in set
```
