# ROLE_SYS_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ロールに付与されたシステム特権を説明します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **型**     | **NULL許容** |       **説明**       |
|--------------|---------------|----------------|--------------------|
| ROLE         | VARCHAR2(128) | NO             | ロール名               |
| PRIVILEGE    | VARCHAR2(40)  | NO             | このロールに付与されるシステム権限         |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | このロールにADMINオプションが付与されているかどうか |

## クエリ例

ロール`ROLE2`に付与されたシステム権限を確認します。

```shell
obclient [SYS]> SELECT * FROM ROLE_SYS_PRIVS WHERE ROLE = 'ROLE2';
```

クエリ結果は次のとおりです：

```shell
+-------+-----------------+--------------+
| ROLE  | PRIVILEGE       | ADMIN_OPTION |
+-------+-----------------+--------------+
| ROLE2 | CREATE SEQUENCE | NO           |
+-------+-----------------+--------------+
1 row in set
```
