# DBA_PART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のすべてのパーティションオブジェクトにおいて、パーティションキーを構成する列を表示します。

## フィールドの説明

|      **フィールド名**      |     **型**     | **NULL許容** |                                                              **説明**                                                              |
|--------------------|----------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの所有者                                  |
| NAME               | VARCHAR2(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前                                   |
| OBJECT_TYPE        | CHAR(5)        | NO             | パーティションオブジェクトのタイプ：<ul><li>TABLE   </li><li> INDEX </li></ul>   |
| COLUMN_NAME        | VARCHAR2(4000) | NO             | 列の名前                                          |
| COLUMN_POSITION    | NUMBER         | NO             | パーティションキー内の列の位置                                     |
| COLLATED_COLUMN_ID | NUMBER         | NO             | 現在このフィールドはサポートされていません。現在このフィールドはデフォルトでNULLです                       |

## クエリ例

ユーザーテナントが自身のテナントにあるパーティションテーブル `TBL1_H` のパーティションキーを構成する列を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_PART_KEY_COLUMNS WHERE NAME='TBL1_H';
```

クエリ結果は次のとおりです：

```shell
+-------+--------+-------------+-------------+-----------------+--------------------+
| OWNER | NAME   | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-------+--------+-------------+-------------+-----------------+--------------------+
| SYS   | TBL1_H | TABLE       | COL1        |               1 |               NULL |
+-------+--------+-------------+-------------+-----------------+--------------------+
1 row in set
```
