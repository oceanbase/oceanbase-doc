# DBA_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TRANSFER_PARTITION_TASKS`は、現在テナント内で処理中のTransfer Partitionタスクを表示します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | NUMBER(38)  | NO   | Transfer Partitionタスクの一意の識別子   |
| CREATE_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | 作成時間   |
| MODIFY_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | 情報更新時間   |
| TABLE_ID         | NUMBER(38)   | NO   | Transferのパーティションが存在するテーブルID   |
| OBJECT_ID        | NUMBER(38)   | NO   | Transferのパーティションの`OBJECT_ID`   |
| DEST_LS          | NUMBER(38)   | NO   | 宛先ログストリーム   |
| BALANCE_JOB_ID   | NUMBER(38)   | NO   | タスク実行時に関連付けられたロードバランシングジョブID   |
| TRANSFER_TASK_ID | NUMBER(38)   | NO   | タスク実行時に関連付けられたTransferタスクID   |
| STATUS           | VARCHAR2(64) | NO   | タスクの状態：<ul><li>WAITING：タスク待機中、実行開始前</li><li>INIT：タスクのスケジューリング開始</li><li>DOING：Transferの実行開始</li></ul>   |
| COMMENT          | CLOB     | YES  | コメント情報   |

## クエリ例

テナント内で現在処理中のTransfer Partitionタスクを照会します。

```shell
obclient> SELECT * FROM SYS.DBA_OB_TRANSFER_PARTITION_TASKS;
```

クエリ結果は次のとおりです。

```shell
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|       4 | 2023-12-01 11:21:11.357272 | 2023-12-01 11:21:17.904857 |   500012 |    500014 |    1003 |         737367 |                9 | DOING  | NULL    |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set
```
