# USER_POLICY_GROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するビューのポリシーグループ情報を表示します。ポリシーコンテキストと組み合わせることで、異なるユーザーに対して異なるポリシーを適用できます。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OBJECT_NAME | VARCHAR2(128) | YES | ポリシーで制御されるオブジェクトの名前 |
| POLICY_GROUP | VARCHAR2(128) | NO | ポリシーグループ名 |
| COMMON | VARCHAR2(3) | NO | 互換性のためにのみ使用され、現在の値は常にNOです。 |
| INHERITED | VARCHAR2(3) | NO | 互換性のためにのみ使用され、現在の値は常にNOです。 |

## クエリ例

現在のユーザーが所有するビューのポリシーグループ情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_POLICY_GROUPS;
```

クエリ結果は次のとおりです：

```shell
+----------------+--------------+--------+-----------+
| OBJECT_NAME    | POLICY_GROUP | COMMON | INHERITED |
+----------------+--------------+--------+-----------+
| V_SALES_SECURE | GROUP_SALES  | NO     | NO        |
| V_ORDERS_CTX   | GROUP_REGION | NO     | NO        |
+----------------+--------------+--------+-----------+
2 rows in set
```
