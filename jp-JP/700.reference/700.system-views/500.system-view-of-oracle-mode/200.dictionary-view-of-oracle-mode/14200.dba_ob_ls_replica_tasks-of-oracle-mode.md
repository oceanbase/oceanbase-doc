# DBA_OB_LS_REPLICA_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_LS_REPLICA_TASKS` は、現在のテナントで実行中のレプリカレベルのディザスタリカバリタスクを表示するために使用されます。

## フィールド説明

| フィールド名                | 型           | NULL許容     | 説明               |
|------------------------|----------------|--------------------|--------------------|
| LS_ID                  | NUMBER(38)     | NO                 |   ログストリームID        |
| TASK_TYPE              | VARCHAR2(64)   | NO                 | タスクタイプ。<ul><li>MIGRATE REPLICA：レプリカの移行</li> <li>ADD REPLICA：レプリカの追加</li><li>REMOVE PAXOS REPLICA：レプリカの削除</li><li>MODIFY PAXOS REPLICA NUMBER：法定レプリカ数の変更</li></ul>|
| TASK_ID                | VARCHAR2(200)  | NO                 | タスクID            |
| TASK_STATUS            | VARCHAR2(2048) | YES                | タスクの状態。<ul><li>`INPROGRESS`：スケジュール実行中</li> <li>`WAITING`：タスク待機中</li></ul> |
| PRIORITY               | CHAR(5)        | NO                 | タスクの優先度。<ul><li>LOW：低優先度タスク。移行タスクのみが低優先度となる場合があります</li><li>HIGH：高優先度タスク</li></ul>|
| TARGET_REPLICA_SVR_IP  | VARCHAR2(46)   | YES                | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT| NUMBER(38)     | YES                | ターゲットレプリカが存在するマシンのポート番号 |
| TARGET_PAXOS_REPLICA_NUMBER | NUMBER(38)| YES                | ログストリームのターゲット法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE    | VARCHAR2(16)   | YES                | ターゲットレプリカタイプ |
| SOURCE_REPLICA_SVR_IP  | VARCHAR2(46)   | YES                | ソースレプリカが存在するマシンのIPアドレス。</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLと表示されます。|
| SOURCE_REPLICA_SVR_PORT| NUMBER(38)     |YES                 | ソースレプリカが存在するマシンのポート番号。</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、0と表示されます。|
| SOURCE_PAXOS_REPLICA_NUMBER | NUMBER(38)| YES                | ログストリームの元の法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE    | VARCHAR2(16)   | YES                | ソースレプリカタイプ。</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLと表示されます。 |
| DATA_SOURCE_SVR_IP     | VARCHAR2(46)   | YES                | データソースIP  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>    |
| DATA_SOURCE_SVR_PORT   | NUMBER(38)     | YES                | データソースのポート番号  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>   |
| IS_MANUAL              | CHAR(6)        | NO                 | ディザスタリカバリタスクの出所。<ul><li>`TRUE`：手動の運用コマンドによってトリガーされたディザスタリカバリタスクを示します。</li><li>`FALSE`：デフォルト値。RS層のディザスタリカバリで自動生成されたディザスタリカバリタスクを示します。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>    |
| TASK_EXEC_SVR_IP       | VARCHAR2(46)   | YES                | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT     | NUMBER(38)     | YES                | タスク実行マシンのポート番号 |
| CREATE_TIME            | TIMESTAMP(6)   | NO                 | タスク生成時間 |
| START_TIME             | TIMESTAMP(6)   | NO                 | タスクスケジューリング時間 |
| MODIFY_TIME            | TIMESTAMP(6)   | NO                 | タスク状態更新時間 |
| COMMENT                | VARCHAR2(2048) | YES                | タスク生成理由の備考 |
| CONFIG_VERSION         | VARCHAR2(128)  | YES                | ディザスタリカバリタスク実行時のclog層のconfig_version情報を記録 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0バージョンから導入されました。</p></main>  |
