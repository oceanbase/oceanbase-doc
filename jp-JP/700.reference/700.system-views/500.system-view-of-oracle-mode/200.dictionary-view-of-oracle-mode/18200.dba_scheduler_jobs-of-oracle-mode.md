# DBA_SCHEDULER_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがアクセス可能なスケジューラーのジョブ情報を表示します。

## フィールドの説明

|      フィールド名 |    タイプ       | NULL値を許容するか |    説明    |
|--------------|---------------|---------------|------------|
| OWNER | VARCHAR2(128) | NO | スケジューラー・ジョブの所有者 |
| JOB_NAME | VARCHAR2(128) | NO | スケジューラー・ジョブの名前 |
| JOB_SUBNAME | VARCHAR2(128) | NO | スケジューラー・ジョブのサブ名 |
| JOB_STYLE | VARCHAR2(17) | YES | ジョブスタイル：<ul><li>REGULAR：指定された時点でタスクを実行します。  </li><li>LIGHTWEIGHT：指定された時間間隔でタスクを実行します。 </li></ul>|
| JOB_CREATOR | VARCHAR2(128) | NO | スケジューラー・ジョブの作成者 |
| CLIENT_ID | VARCHAR2(65) | NO | ジョブを作成したユーザーのクライアント識別子 |
| GLOBALUid | VARCHAR2(33) | NO | ジョブを作成したユーザーのグローバルユーザー識別子 |
| PROGRAM_OWNER | VARCHAR2(4000) | NO | ジョブに関連するプログラムの所有者 |
| PROGRAM_NAME | VARCHAR2(4000) | YES | ジョブに関連するプログラム名 |
| JOB_TYPE | VARCHAR2(16) | YES |  ジョブ操作タイプ：<ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul> |
| JOB_ACTION | VARCHAR2(4000) | YES | インラインジョブ操作 |
| NUMBER_OF_ARGUMENTS | NUMBER | YES | ジョブパラメータのインライン数 |
| SCHEDULE_OWNER | VARCHAR2(4000) | NO | ジョブが使用する計画の所有者 |
| SCHEDULE_NAME | VARCHAR2(4000) | NO | ジョブが使用する計画名 |
| SCHEDULE_TYPE | VARCHAR2(12) | NO | デフォルト値はNULL |
| START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブの元の計画開始日 |
| REPEAT_INTERVAL | VARCHAR2(4000) | YES | インライン計画PL/SQL式またはカレンダー文字列 |
| EVENT_QUEUE_OWNER | VARCHAR2(128) | NO | イベントを発生させるソースキューの所有者 |
| EVENT_QUEUE_NAME | VARCHAR2(128) | NO | イベントを発生させるソースキューの名前 |
| EVENT_QUEUE_AGENT | VARCHAR2(523) | NO | ユーザーがイベントソースキューで使用するAQエージェントの名前 |
| EVENT_CONDITION | VARCHAR2(4000) | NO | ソースキュー上のイベントのサブスクリプションルール |
| EVENT_RULE | VARCHAR2(261) | NO | コーディネーターがイベントベースのジョブをトリガーするために使用するルール名 |
| FILE_WATCHER_OWNER | VARCHAR2(261) | NO | このジョブが基づくファイルウォッチャーの所有者 |
| FILE_WATCHER_NAME | VARCHAR2(261) | NO | このジョブが基づくファイルウォッチャーの名前 |
| END_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブが実行されなくなる日付 |
| JOB_CLASS | VARCHAR2(128) | YES | ジョブに関連付けられたジョブカテゴリの名前 |
| ENABLED | VARCHAR2(5) | YES | ジョブが有効かどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| AUTO_DROP | VARCHAR2(5) | YES | ジョブ完了後に削除されるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul>  |
| RESTART_ON_RECOVERY | VARCHAR2(5) | NO | クラスタ再起動時に、このジョブを再起動するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| RESTART_ON_FAILURE | VARCHAR2(5) | NO | ジョブの実行が失敗した場合、ジョブを再起動するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| STATE | VARCHAR2(15) | YES | ジョブの現在の状態：<ul><li>DISABLED</li><li>RETRY SCHEDULED</li><li>SCHEDULED</li><li>BLOCKED</li><li>RUNNING</li><li>COMPLETED</li><li>BROKEN</li><li>FAILED</li><li>REMOTE</li><li>RESOURCE_UNAVAILABLE</li><li>SUCCEEDED</li><li>CHAIN_STALLED </li></ul> |
| JOB_PRIORITY | NUMBER | NO | 同種類の他のジョブに対するこのジョブの優先順位 |
| RUN_COUNT | NUMBER | YES | ジョブが実行された回数 |
| MAX_RUNS | NUMBER | NO | ジョブが計画されている最大実行回数 |
| FAILURE_COUNT | NUMBER | YES | ジョブの実行失敗回数 |
| MAX_FAILURES | NUMBER | NO | 損傷としてマークされる前に許容されるジョブの失敗回数 |
| RETRY_COUNT | NUMBER | YES | ジョブのリトライ回数 |
| LAST_START_DATE | TIMESTAMP(6) WITH TIME ZONE | YES | ジョブが実行を開始した最後の日付 |
| LAST_RUN_DURATION | INTERVAL DAY (9) TO SECOND (6) | NO | 前回の実行期間中にジョブを完了するために費やされた時間 |
| NEXT_RUN_DATE | TIMESTAMP(6) WITH TIME ZONE | NO | ジョブが計画されている次の実行日 |
| SCHEDULE_LIMIT | INTERVAL DAY (3) TO SECOND (0) | NO | まだ実行されていないジョブが再スケジュールされる時間 |
| MAX_RUN_DURATION | INTERVAL DAY (3) TO SECOND (0) | NO | ジョブの実行に許可される最長時間 |
| LOGGING_LEVEL | VARCHAR2(11) | NO | ジョブ関連のログレコード：<ul><li>OFF  </li><li>RUNS </li><li>FAILED RUNS </li><li>FULL </li></ul> |
| STORE_OUTPUT | VARCHAR2(5) | NO | ジョブ実行の出力をデータベースに保存するかどうか：<ul><li>TRUE  </li><li>FALSE </li></ul> |
| STOP_ON_WINDOW_CLOSE | VARCHAR2(5) | NO | ジョブが属するスケジューリングウィンドウが閉じたとき、ジョブの実行を停止するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| INSTANCE_STICKINESS | VARCHAR2(5) | NO | ジョブにインスタンス粘着性があるかどうか：<ul><li>TRUE  </li><li>FALSE </li></ul>|
| RAISE_EVENTS | VARCHAR2(4000) | NO | デフォルト値はNULLです |
| SYSTEM | VARCHAR2(5) | NO | ジョブがシステムジョブであるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| JOB_WEIGHT | NUMBER | NO | ジョブの重み。スケジューリング時のジョブの優先順位を指定するために使用されます。 |
| NLS_ENV | VARCHAR2(4000) | YES | ジョブの国語環境設定。 |
| SOURCE | VARCHAR2(128) | NO | ジョブのソースコードまたはスクリプト。 |
| NUMBER_OF_DESTINATIONS | NUMBER | NO | ジョブのターゲット数。 |
| DESTINATION_OWNER | VARCHAR2(261) | NO | ジョブターゲットの所有者。 |
| DESTINATION | VARCHAR2(261) | NO | ジョブのターゲット、つまりジョブが実行する対象または場所。 |
| CREDENTIAL_OWNER | VARCHAR2(128) | NO | 認証情報の所有者。 |
| CREDENTIAL_NAME | VARCHAR2(128) | NO | 認証情報の名前。 |
| INSTANCE_ID | NUMBER | YES | ユーザーがジョブの実行をリクエストしたインスタンス |
| DEFERRED_DROP | VARCHAR2(5) | NO | ジョブの削除を遅延させるかどうか。 |
| ALLOW_RUNS_IN_RESTRICTED_MODE | VARCHAR2(5) | NO | ジョブが制限モードでの実行を許可されているかどうか。 |
| COMMENTS | VARCHAR2(4000) | YES | ジョブのコメントまたは説明情報。 |
| FLAGS | NUMBER | NO | ジョブのフラグビット。 |
| RESTARTABLE | VARCHAR2(5) | NO | ジョブが再起動可能かどうか。 |
| CONNECT_CREDENTIAL_OWNER | VARCHAR2(128) | NO | 接続認証情報の所有者。 |
| CONNECT_CREDENTIAL_NAME | VARCHAR2(128) | NO | 接続認証情報の名前。 |
