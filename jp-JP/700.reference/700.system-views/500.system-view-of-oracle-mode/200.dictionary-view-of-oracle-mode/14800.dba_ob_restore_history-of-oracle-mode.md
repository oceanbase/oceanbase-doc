# DBA_OB_RESTORE_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで完了したテナントレベルの復元タスクを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | 復元に属するjob_id。1回の復元タスクに対応します。 |
| RESTORE_TENANT_NAME | VARCHAR2(128) | NO | 復元するテナント名 |
| RESTORE_TENANT_ID | NUMBER(38) | NO | 復元するテナントID |
| BACKUP_TENANT_NAME | VARCHAR2(128) | NO | バックアップのソーステナント名 |
| BACKUP_TENANT_ID | NUMBER(38) | NO | バックアップのソーステナントID |
| BACKUP_CLUSTER_NAME | VARCHAR2(128) | NO | バックアップのソースクラスタ名 |
| BACKUP_DEST | CLOB | NO | バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します |
| RESTORE_SCN | NUMBER(38) | NO | ユーザーが指定した復元ポイント |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | ユーザーが指定した復元ポイントのタイムスタンプ表現 |
| RESTORE_OPTION      | VARCHAR2(4096) | NO   | 復元オプション。復元を開始する際に、ユーザーが指定した `restore_option` |
| RESTORE_TYPE                      | varchar(4096)            |  NO   |復元タイプ。<ul> <li>`FULL`：フル復元を示します</li> <li> `QUICK`：クイック復元を示します</li></ul>   <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main>  |
| START_TIMESTAMP        | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | 復元タスク開始時のタイムスタンプ |
| FINISH_TIMESTAMP       | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | 復元タスク終了時のタイムスタンプ |
| STATUS                 | VARCHAR2(64) | NO | 復元結果：<ul> <li> `SUCCESS`：復元が成功したことを示します </li> <li> `FAILED`：復元に失敗したことを示します </li></ul>|
| BACKUP_PIECE_LIST | CLOB | NO | 復元に依存するログアーカイブシャーディングパスのリスト。シャーディング間は `,` で区切ります。例：`file:///data/nfs/backup/archive/2_1_2,file:///data/nfs/backup/archive/2_1_3` |
| BACKUP_SET_LIST | CLOB | NO | 復元に依存するデータバックアップセットパスのリスト。バックアップセット間は `,` で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`  |
| BACKUP_CLUSTER_VERSION | NUMBER(38)   | NO   | バックアップソースクラスタのバージョン番号 |
| LS_COUNT               | NUMBER(38)   | NO   | 復元待ちのログストリームの合計数 |
| FINISH_LS_COUNT        | NUMBER(38)   | NO   | 復元完了のログストリーム数 |
| TABLET_COUNT           | NUMBER(38)   | NO   | 復元待ちのシャーディングの合計数 |
| FINISH_TABLET_COUNT    | NUMBER(38)   | NO   | 復元完了のシャーディング数 |
| TOTAL_BYTES          | NUMBER(38)     | NO   | 復元総バイト数 |
| TOTAL_BYTES_DISPLAY  | VARCHAR2(42)   | NO   | ストレージ容量単位で表示された復元総バイト数 |
| FINISH_BYTES         | NUMBER(38)     | NO   | 復元完了バイト数 |
| FINISH_BYTES_DISPLAY | VARCHAR2(42)   | NO   | ストレージ容量単位で表示された復元総バイト数 |
| DESCRIPTION          | VARCHAR2(1024) | NO   | 復元コマンドで指定された`DESCRIPTION`情報 |
| COMMENT              | VARCHAR2(1024) | YES  | 復元失敗時に失敗情報を記録する |
