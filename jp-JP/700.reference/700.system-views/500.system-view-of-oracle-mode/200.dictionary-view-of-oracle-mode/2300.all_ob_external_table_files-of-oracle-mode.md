# ALL_OB_EXTERNAL_TABLE_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス権を持つ外部テーブルのファイルリストを表示します。

## フィールドの説明

| **項目** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TABLE_NAME | VARCHAR2(256) | YES | 外部テーブル名 |
| OWNER | VARCHAR2(128) | YES | 外部テーブルが存在するデータベース名 |
| PARTITION_NAME | CHAR(2) | NO | 外部テーブルのPARTITION NAME |
| FILE_URL | VARBINARY(16384) | NO | 外部テーブルのファイルURL |
| FILE_SIZE | NUMBER(38) | NO | このファイルのサイズ |

## クエリ例

現在ユーザーがアクセス権を持つ外部テーブルのファイルリストを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_OB_EXTERNAL_TABLE_FILES;
```

クエリ結果は次のとおりです：

```shell
+------------+-------+----------------+------------------------------+-----------+
| TABLE_NAME | OWNER | PARTITION_NAME | FILE_URL                     | FILE_SIZE |
+------------+-------+----------------+------------------------------+-----------+
| EXT_T3     | SYS   | P0             | xx.xx.xx.208:2882%data.csv   |        29 |
+------------+-------+----------------+------------------------------+-----------+
1 row in set
```
