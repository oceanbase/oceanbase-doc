# ALL_TRIGGER_ORDERING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのトリガーをソートしたものを表示します。

## フィールドの説明

| **項目** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TRIGGER_OWNER | VARCHAR2(128) | YES | トリガー所有者 |
| TRIGGER_NAME | VARCHAR2(128) | NO | トリガー名 |
| REFERENCED_TRIGGER_OWNER | VARCHAR2(128) | YES | 引用元のトリガー所有者 |
| REFERENCED_TRIGGER_NAME | VARCHAR2(128) | YES | 引用元のトリガー名 |
| ORDERING_TYPE | VARCHAR2(8) | NO | ソートタイプ |

## クエリ例

現在ユーザーがアクセス可能なすべてのトリガーをソートして確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.ALL_TRIGGER_ORDERING;
```

クエリ結果は次のとおりです：

```shell
+---------------+------------------+--------------------------+-------------------------+---------------+
| TRIGGER_OWNER | TRIGGER_NAME     | REFERENCED_TRIGGER_OWNER | REFERENCED_TRIGGER_NAME | ORDERING_TYPE |
+---------------+------------------+--------------------------+-------------------------+---------------+
| SYS           | TRG_AUDIT_DETAIL | SYS                      | TRG_AUDIT_BASE          | FOLLOWS       |
+---------------+------------------+--------------------------+-------------------------+---------------+
1 row in set
```
