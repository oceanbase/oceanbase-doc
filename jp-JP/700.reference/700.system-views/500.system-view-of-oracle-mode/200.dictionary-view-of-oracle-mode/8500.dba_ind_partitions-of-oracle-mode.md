# DBA_IND_PARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのインデックスパーティションの情報を表示します。
