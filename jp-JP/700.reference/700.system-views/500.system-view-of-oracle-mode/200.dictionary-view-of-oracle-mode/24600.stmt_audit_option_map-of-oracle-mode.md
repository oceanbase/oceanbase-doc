# STMT_AUDIT_OPTION_MAP

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

ステートメントレベル監査のTypeと、それに対応する名前および優先順位を記録します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名** |    **型**     | **NULL許容** |               **説明**                |
|----------|---------------|----------------|-------------------------------------|
| OPTION#  | NUMBER(38)    | NO             | ステートメントレベル監査のType ID                     |
| NAME     | VARCHAR2(128) | NO             | ステートメントレベル監査のTypeに対応する名前                  |
| PROPERTY | NUMBER        | NO             | ステートメントレベル監査Typeの優先順位。現在このフィールドはサポートされていないため、デフォルトはNULLです |
