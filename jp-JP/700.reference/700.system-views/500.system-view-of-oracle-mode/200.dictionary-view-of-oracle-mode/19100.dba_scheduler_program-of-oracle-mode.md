# DBA_SCHEDULER_PROGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のすべてのスケジューラー情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|        フィールド名         |       型           | NULL許容    |                説明                 |
|---------------------|----------------|------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER               | VARCHAR2(128)  | YES        | スケジューラの所有者                          |
| PROGRAM_NAME        | VARCHAR2(30)   | NO         | スケジューラ名                            |
| PROGRAM_TYPE        | VARCHAR2(16)   | YES        | プログラム操作のタイプ：<ul><li>`PLSQL_BLOCK`   </li><li> `STORED_PROCEDURE`   </li><li> `EXECUTABLE`</li></ul>    |
| PROGRAM_ACTION      | VARCHAR2(4000) | YES        | プログラム操作を指定する文字列                        |
| NUMBER_OF_ARGUMENTS | NUMBER(38)     | YES        | プログラムが受け付ける引数の数                         |

## クエリ例

本テナント配下のすべてのスケジューラー情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_SCHEDULER_PROGRAM;
```

クエリ結果は次のとおりです：

```shell
+-------+--------------+------------------+----------------+---------------------+
| OWNER | PROGRAM_NAME | PROGRAM_TYPE     | PROGRAM_ACTION | NUMBER_OF_ARGUMENTS |
+-------+--------------+------------------+----------------+---------------------+
| SYS   | empprogram   | STORED_PROCEDURE | hr.empprogram  |                   0 |
+-------+--------------+------------------+----------------+---------------------+
1 row in set
```
