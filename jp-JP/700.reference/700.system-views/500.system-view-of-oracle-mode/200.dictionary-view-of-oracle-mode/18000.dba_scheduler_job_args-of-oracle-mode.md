# DBA_SCHEDULER_JOB_ARGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースは、このビューをサポートしていません。</p>
</main>

## 機能の概要

現在のテナント内でスケジュールされているジョブのパラメータ情報を表示します。

## フィールドの説明

|       **フィールド名**        |     **タイプ**     | **NULLを許容するか** |         **説明**          |
|-----------------------|----------------|----------------|-------------------------|
| OWNER                 | VARCHAR2(30)   | NO             | パラメータが属するジョブの所有者              |
| JOB_NAME              | VARCHAR2(30)   | NO             | パラメータが属するジョブの名前               |
| ARGUMENT_NAME         | VARCHAR2(30)   | NO             | パラメータのオプション名                 |
| ARGUMENT_POSITION     | NUMBER         | NO             | パラメータリスト内でのパラメータの位置             |
| ARGUMENT_TYPE         | VARCHAR2(61)   | NO             | パラメータのデータ型                 |
| VALUE                 | VARCHAR2(4000) | NO             | パラメータが文字列型の場合、パラメータのデフォルト値     |
| DEFAULT_ANYDATA_VALUE | VARCHAR2(128)  | NO             | パラメータがANYDATA型の場合、パラメータのデフォルト値 |
| OUT_ARGUMENT          | VARCHAR2(5)    | NO             | 予約語                      |
