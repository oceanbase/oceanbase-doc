# DBA_PART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのパーティションテーブルのパーティションに関するヒストグラム情報を表示します。

## フィールド説明

|           フィールド名            |       型        | NULL許容   |      説明       |
|---------------------------|----------------|------------|---------------|
| OWNER                     | VARCHAR2(128)  | NO         | ヒストグラム所有者ユーザー      |
| TABLE_NAME                | VARCHAR2(128)  | NO         | ヒストグラムが属するテーブル名       |
| PARTITION_NAME            | VARCHAR2(128)  | NO         | ヒストグラムが属するパーティション名    |
| COLUMN_NAME               | VARCHAR2(128)  | NO         | ヒストグラムが属する列名       |
| ENDPOINT_NUMBER           | NUMBER         | NO         | バケット累積頻度  |
| ENDPOINT_VALUE            | NUMBER         | NO         | バケット端点正規化値 |
| ENDPOINT_ACTUAL_VALUE     | VARCHAR2(4000) | NO         | バケット端点値    |
| ENDPOINT_ACTUAL_VALUE_RAW | VARCHAR2(4000) | NO         | バケット端点バイナリ値 |
| ENDPOINT_REPEAT_COUNT     | NUMBER         | NO         | バケット端点値の頻度 |
