# DBA_WR_EVENT_NAME

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_WR_EVENT_NAME`は、テナント内で永続化されたテナントレベルの待機イベント名を表示するために使用されます。

## フィールドの説明

| **フィールド名**  | **タイプ**    | **NULL許容** | **説明**                               |
|---------------|-------------|---------------------|----------------------------------------|
| EVENT_ID      | NUMBER(38)  | NO   |  待機イベントID   |
| EVENT_NAME    | VARCHAR2(64) | YES  |  待機時間名    |
| PARAMETER1    | VARCHAR2(64) | YES  |  待機時間パラメータ1の名前   |
| PARAMETER2    | VARCHAR2(64) | YES  |  待機時間パラメータ2の名前   |
| PARAMETER3    | VARCHAR2(64) | YES  |  待機時間パラメータ3の名前   |
| WAIT_CLASS_ID | NUMBER(38)  | YES  |  待機イベントが属するクラスID     |
| WAIT_CLASS    | VARCHAR2(64) | YES  |  待機イベントが属するクラス名   |

ビューの`WAIT_CLASS`列の値には、待機イベントが属するタイプ名と対応する待機イベント番号IDが含まれており、その内容は次の表のとおりです。

| 待機イベントが属するタイプ名 | 待機イベント番号ID | 説明 |
|------|----|------|
| OTHER | 100 | 他のタイプに分類されない待機イベント |
| APPLICATION | 101 | クライアントコードによって発生した待機イベント |
| CONFIGURATION | 102 | データベースまたはインスタンスのリソース設定が不足していることが原因で発生した待機イベント |
| ADMINISTRATIVE | 103 | データベース管理者がコマンドを入力したことによりユーザーが待機する待機イベント |
| CONCURRENCY | 104 | データベース内部リソースを待機する待機イベント |
| COMMIT | 105 | ログコミットに関連する待機イベント |
| IDLE | 106 | セッションが非アクティブ状態でタスクを待機する待機イベント |
| NETWORK | 107 | ネットワーク通信に関連する待機イベント |
| USER_IO | 108 | ユーザーI/Oを待機する待機イベント |
| SYSTEM_IO | 109 | バックグラウンドプロセスのI/Oを待機する待機イベント |
| CLUSTER | 111 | クラスタに関連する待機イベント |

## クエリ例

このテナントの永続化されたテナントレベルの待機イベント名を照会し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_EVENT_NAME WHERE ROWNUM = 1;
```

照会結果は次のとおりです。

```shell
+----------+-----------------------------------+------------+------------+------------+---------------+-------------+
| EVENT_ID | EVENT_NAME                        | PARAMETER1 | PARAMETER2 | PARAMETER3 | WAIT_CLASS_ID | WAIT_CLASS  |
+----------+-----------------------------------+------------+------------+------------+---------------+-------------+
|        0 | latch: latch wait queue lock wait | address    | number     | tries      |           104 | CONCURRENCY |
+----------+-----------------------------------+------------+------------+------------+---------------+-------------+
1 row in set
```
