# USER_ERRORS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するストレージオブジェクトのエラー情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**    |     **型**     | **NULL許容** |                                             **説明**                                              |
|----------------|----------------|----------------|-----------------------------------|
| NAME           | VARCHAR2(128)  | NO             | オブジェクト名です。       |
| TYPE           | VARCHAR2(19)   | NO             | オブジェクトのタイプ：<ul><li> VIEW </li>  <li> PROCEDUCE  </li> <li> FUNCTION  </li> <li> PACKAGE </li>  <li> PACKAGE_BODY   </li> <li> TRIGGER  </li> <li> TYPE  </li> <li> TYPE BODY  </li> <li> LIBRARY </li>  <li> JAVA SOURCE  </li> <li> JAVA CLASS  </li> <li> DIMENSION </li> </ul>  |
| SEQUENCE       | NUMBER         | NO             | 複数のエラーを一度にコンパイルした際のエラー番号（未ソート）。                                                                            |
| LINE           | NUMBER         | NO             | エラー発生行番号です。     |
| POSITION       | NUMBER         | NO             | エラー発生列番号です。     |
| TEXT           | VARCHAR2(4000) | NO             | エラーメッセージのテキストです。      |
| ATTRIBUTE      | VARCHAR2(9)    | NO             | ErrorかWarningかを示します。                                                                           |
| MESSAGE_NUMBER | NUMBER         | NO             | エラーコードです。        |
