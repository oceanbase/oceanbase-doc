# USER_ERRORS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するストレージオブジェクトのエラー情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**    |     **タイプ**     | **NULLを許容するか** |                                             **説明**                                              |
|----------------|----------------|----------------|-----------------------------------|
| NAME           | VARCHAR2(128)  | NO             | オブジェクトの名前。       |
| TYPE           | VARCHAR2(19)   | NO             | オブジェクトのタイプ：<ul><li> VIEW </li>  <li> PROCEDURE  </li> <li> FUNCTION  </li> <li> PACKAGE </li>  <li> PACKAGE_BODY   </li> <li> TRIGGER  </li> <li> TYPE  </li> <li> TYPE BODY  </li> <li> LIBRARY </li>  <li> JAVA SOURCE  </li> <li> JAVA CLASS  </li> <li> DIMENSION </li> </ul>  |
| SEQUENCE       | NUMBER         | NO             | 同一コンパイルで複数のエラーが発生した場合のエラー番号（ソートされていない）。                                                                            |
| LINE           | NUMBER         | NO             | エラー発生行番号。     |
| POSITION       | NUMBER         | NO             | エラー発生列番号。     |
| TEXT           | VARCHAR2(4000) | NO             | エラーメッセージテキスト。      |
| ATTRIBUTE      | VARCHAR2(9)    | NO             | ErrorかWarningかを示す。                                                                           |
| MESSAGE_NUMBER | NUMBER         | NO             | エラーコード。        |
