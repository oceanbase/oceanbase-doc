# DBA_OB_IMPORT_TABLE_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のテーブルインポートタスクのレコードを表示します。

## フィールド説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | ロードバランシングタスクID |
| JOB_ID | NUMBER(38) | NO | タスクID |
| SRC_TENANT_ID | NUMBER(38) | NO | ソーステナントID |
| SRC_TABLESPACE | VARCHAR2(128) | YES | ソーステーブルのTABLESPACE |
| SRC_TABLEGROUP | VARCHAR2(128) | YES | ソーステーブルのTABLEGROUP |
| SRC_DATABASE | VARCHAR2(128) | YES | ソーステーブルのDATABASE |
| SRC_TABLE | VARCHAR2(128) | YES | ソーステーブル名 |
| SRC_PARTITION | VARCHAR2(64) | YES | ソーステーブルのPARTITION名 |
| TARGET_TABLESPACE | VARCHAR2(128) | YES | リマッピング後のテーブルスペース名。リマッピングされていない場合は空文字列を返します |
| TARGET_TABLEGROUP | VARCHAR2(128) | YES | リマッピング後のテーブルグループ名。リマッピングされていない場合は空文字列を返します |
| TARGET_DATABASE | VARCHAR2(128) | YES | リマッピング後のデータベース名。リマッピングされていない場合は空文字列を返します |
| TARGET_TABLE | VARCHAR2(128) | YES | リネーム後のテーブル名。リネームされていない場合は空文字列を返します |
| TABLE_COLUMN | NUMBER(38) | NO | テーブル列の数 |
| STATUS | VARCHAR2(64) | NO | タスクの状態：<ul><li>`INIT`：テーブルレベルインポートタスクが初期化されました。</li> <li>`DOING`：テーブルレベルインポートが実行中です。</li> <li>`FINISH`：インポートが終了しました。</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時のテナントの現在時刻 |
| COMPLETION_TIMESTAMP | VARCHAR2(256) | NO | タスク完了時のテナントの現在時刻 |
| CUMULATIVE_TS | NUMBER(38) | NO | 累計時間 |
| TOTAL_INDEX_COUNT | NUMBER(38) | NO | 総インデックス数 |
| IMPORTED_INDEX_COUNT | NUMBER(38) | NO | インポート済みのインデックス数 |
| FAILED_INDEX_COUNT | NUMBER(38) | NO | インポート失敗したインデックス数 |
| TOTAL_CONSTRAINT_COUNT | NUMBER(38) | NO | 総制約数 |
| IMPORTED_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート済みの制約数 |
| FAILED_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート失敗した制約数 |
| TOTAL_REF_CONSTRAINT_COUNT | NUMBER(38) | NO | 総参照制約数 |
| IMPORTED_REF_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート済みの参照制約数 |
| FAILED_REF_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート失敗した参照制約数 |
| RESULT | VARCHAR2(64) | YES | タスク完了の結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行されました。</li><li>`FAIL`：インポートタスクが失敗しました。</li></ul> |
| COMMENT | CLOB | YES | 備考情報 |
