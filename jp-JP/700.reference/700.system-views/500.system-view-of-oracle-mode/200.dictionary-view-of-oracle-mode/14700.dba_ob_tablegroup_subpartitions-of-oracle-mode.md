# DBA_OB_TABLEGROUP_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.2.0以降のバージョンでは、テーブルグループにパーティションという概念がなくなったため、このビューは使用されなくなりました。ユーザーはこのビューを照会できますが、結果は空になります。</li>
<li>V4.2.0以降のバージョンでは、ビュー<a href="14900.dba_ob_tablegroups-of-oracle-mode.md">DBA_OB_TABLEGROUPS</a>を使用してテーブルグループ情報を照会できます。テーブルグループの詳細については、<a href="../../../300.database-object-management/200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md">テーブルグループについて</a>を参照してください。</li>
</ul>
</main>

## 機能の概要

パーティションを持つテーブルグループのサブパーティション情報を表示します。

## フィールドの説明

|         フィールド名          |       タイプ       | NULL値を許容するか |        説明        |
|-----------------------|----------------|------------|----------------------------------------------------------------------|
| TABLEGROUP_NAME       | VARCHAR2(128)  | NO         | TABLEGROUP名    |
| PARTITION_NAME        | VARCHAR2(64)   | NO         | テーブルグループのサブパーティションに対応するパーティション名  |
| SUBPARTITION_NAME     | VARCHAR2(64)   | NO         | テーブルグループのサブパーティション名         |
| HIGH_VALUE            | VARCHAR2(4096) | NO         | このフィールドの値は`NULL`です                   |
| HIGH_VALUE_LENGTH     | NUMBER         | NO         | このフィールドの値は`NULL`です                              |
| PARTITION_POSITION    | NUMBER         | NO         | このフィールドの値は`NULL`です    |
| SUBPARTITION_POSITION | NUMBER         | NO         | このフィールドの値は`NULL`です        |
