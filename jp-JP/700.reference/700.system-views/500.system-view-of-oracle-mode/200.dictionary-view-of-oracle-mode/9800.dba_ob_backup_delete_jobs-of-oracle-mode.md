# DBA_OB_BACKUP_DELETE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのバックアップクリーンアップジョブタスクの実行状況を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | ジョブID。単調増加します。 |
| INCARNATION | NUMBER(38) | NO | 分身ID。 |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | このJOBを開始したテナントID。 |
| INITIATOR_JOB_ID | NUMBER(38) | NO | このJOBを開始したテナントに属する
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | クリーンアップタスクを実行するテナントの一覧 |
| TYPE | VARCHAR2(64) | NO | クリーンアップタイプ：<ul><li> DELETE OBSOLETE BACKUP：期限切れクリーンアップ</li></ul> |
| PARAMETER | VARCHAR2(1024) | NO | クリーンアップパラメータ。有効期限を記録します  |
| JOB_LEVEL | VARCHAR2(64) | NO | ジョブ開始レベル：<ul><li>`USER_TENANT`：ユーザーテナントが開始したジョブ</li><li>`SYS_TENANT`：システムテナントが開始したジョブ</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | ジョブ開始時のテナントの現在時間 |
| END_TIMESTAMP | VARCHAR2(256) | NO | ジョブ終了時のテナントの現在時間 |
| STATUS | VARCHAR2(64) | NO | ジョブのステータス：<ul><li>`INIT`：ジョブの初期化段階 </li><li>`DOING`：ジョブの実行段階 </li><li>`CANCELING`：ジョブがキャンセルされた段階 </li><li>`COMPLETED`：ジョブの実行に成功 </li><li>`FAILED`：ジョブの実行に失敗 </li><li>`CANCELED`：ジョブが正常にキャンセル </li></ul>  |
| TASK_COUNT | NUMBER(38) | YES | backup_set/piece ジョブ数 |
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | backup_set/piece 実行に成功したジョブ数 |
| RESULT | NUMBER(38) | NO | エラーコード |
| COMMENT | VARCHAR2(4096) | YES | ジョブの実行説明 |

## クエリ例

ユーザーテナントは、このテナントのバックアップクリーンアップジョブタスクの実行状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOBS\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************

             INCARNATION: 1

               JOB_LEVEL: USER_TENANT
         START_TIMESTAMP: 2022-06-01 12:09:53.389512
           END_TIMESTAMP:
                  STATUS: DOING
              TASK_COUNT: 2
      SUCCESS_TASK_COUNT: 1
                  RESULT: 0
                 COMMENT:
1 row in set
```
