# DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_BALANCE_JOBS`は、このテナントで現在実行中のロードバランシングジョブを表示します。各テナントでは同一時刻に1つのロードバランシングジョブしか実行できません。各ロードバランシングジョブは複数のロードバランシングタスク(TASK)を生成し、これらのタスクがロードバランシングの具体的な操作を実行します。

## フィールドの説明

| MODIFY_TIME             | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | 情報更新時間 |

| JOB_TYPE                | VARCHAR2(64)                      | NO  | ジョブタイプ  <ul><li>`LS_BALANCE`：ログストリームバランシング  </li><li>`PARTITION_BALANCE`：パーティションバランシング </li></ul>|

| STATUS                  | VARCHAR2(64)                      | NO  | ジョブの状態  <ul><li>`DOING`：Jobが実行中  </li><li>`COMPLETED`：ジョブの実行が成功 </li><li>`CANCELING`：ジョブのキャンセル中 </li><li>`CANCELED`：ジョブのキャンセル </li> <li>`SUSPEND`：ジョブの一時停止</li></ul>|
| COMMENT                 | longtext                          | YES | コメント情報 |
| COMMENT                 | CLOB                              | YES | コメント情報 |

| ZONE_UNIT_NUM_LIST      | VARCHAR2(4096)| NO   | テナントの各ZoneのUnit数 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドはV4.2.5 BP5以降のバージョンから導入されました。</p></main> |
| PARAMETER_LIST          | CLOB          | NO   | バランシング関連の構成パラメータ <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドはV4.2.5 BP5以降のバージョンから導入されました。</p></main> |

## クエリ例

このテナントで現在実行中のロードバランシングタスクを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOBS;
```

