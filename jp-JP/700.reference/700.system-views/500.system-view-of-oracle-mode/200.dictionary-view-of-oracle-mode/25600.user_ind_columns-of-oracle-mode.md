# USER_IND_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーが所有するすべてのテーブルのインデックスに関する情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|    **フィールド名**     |     **タイプ**     | **NULLを許容するか** |            **説明**            |
|-----------------|----------------|----------------|------------------------------|
| INDEX_NAME      | VARCHAR2(128)  | NO             | インデックス名                         |
| TABLE_OWNER     | VARCHAR2(128)  | NO             | インデックスが存在するテーブルの所有者                   |
| COLUMN_NAME     | VARCHAR2(4000) | NO             | インデックス列の名前                       |
| COLUMN_POSITION | NUMBER         | NO             | インデックス内でのインデックス列の位置                   |
| COLUMN_LENGTH   | NUMBER         | NO             | インデックス列の長さ                       |
| CHAR_LENGTH     | NUMBER         | NO             | インデックス列の文字長                     |
| DESCEND         | VARCHAR2(4)    | NO             | インデックス列が降順（DESC）にソートされるか、昇順（ASC）にソートされるかを示す |
| COLLATED_COLUMN_ID | NUMBER      | NO             | 現在このフィールドはサポートされておらず、現在このフィールドのデフォルト値はNULLです                             |

## クエリ例

ユーザーが所有するすべてのテーブルにおいて、インデックステーブル `TBL2` のインデックス列情報を確認します。

```shell
obclient [SYS]> SELECT * FROM USER_IND_COLUMNS WHERE TABLE_NAME='TBL2';
```

クエリ結果は次のとおりです：

```shell
+--------------------------------+------------+-------------+-----------------+---------------+-------------+---------+--------------------+
| INDEX_NAME                     | TABLE_NAME | COLUMN_NAME | COLUMN_POSITION | COLUMN_LENGTH | CHAR_LENGTH | DESCEND | COLLATED_COLUMN_ID |
+--------------------------------+------------+-------------+-----------------+---------------+-------------+---------+--------------------+
| TBL2_OBUNIQUE_1737535889306073 | TBL2       | COL1        |               1 |            22 |           0 | ASC     |               NULL |
| TBL2_IDX1                      | TBL2       | COL2        |               1 |            22 |           0 | ASC     |               NULL |
+--------------------------------+------------+-------------+-----------------+---------------+-------------+---------+--------------------+
2 rows in set
```
