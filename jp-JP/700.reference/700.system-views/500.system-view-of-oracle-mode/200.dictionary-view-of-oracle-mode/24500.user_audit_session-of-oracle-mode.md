# USER_AUDIT_SESSION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーに関連する接続および切断の監査トレースエントリを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|      **フィールド名**      |           **タイプ**            | **NULLを許容するか** |                        **説明**                         |
|--------------------|-----------------------------|----------------|-------------------------------------------------------|
| OS_USERNAME        | VARCHAR2(255)               | NO             | 監査対象ユーザーのOSログインユーザー名。現在このフィールドはサポートされておらず、デフォルトでNULLとなります            |
| USERNAME           | VARCHAR2(64)                | NO             | 監査対象ユーザーの名前                                           |
| USERHOST           | VARCHAR2(32)                | NO             | 監査対象ユーザーのホストIPアドレス    |

| LOGOFF_LWRITE      | NUMBER                      | NO             | セッションの論理書き込み操作。現在このフィールドはサポートされておらず、デフォルトでNULLとなります                      |
| LOGOFF_DLOCK       | VARCHAR2(40)                | NO             | セッション中にデッドロックが検出された場合に設定されます。現在このフィールドはサポートされておらず、デフォルトでNULLとなります                    |
| SESSIONID          | NUMBER(38)                  | NO             | セッションのデジタルID<br>V4.2.x系では：<ul><li> V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはServer Session IDを表します。</li><li> V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ<code>client_session_id_version = 2</code>の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code>の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul>                                              |
| RETURNCODE         | NUMBER(38)                  | NO             | 操作によって生成されるエラーコード                                             |
| CLIENT_ID          | VARCHAR2(40)                | NO             | セッション内のクライアント識別子                                            |
| SESSION_CPU        | NUMBER(38)                  | NO             | セッションで使用されるCPU時間                                          |
| EXTENDED_TIMESTAMP | TIMESTAMP(6) WITH TIME ZONE | NO             | UTCタイムゾーンで監査トレースエントリが作成された日付時刻                                 |

| GLOBAL UID         | NUMBER(38)                  | NO             | ユーザーのグローバルユーザー識別子                                            |
| INSTANCE_NUMBER    | VARCHAR2(40)                | NO             | INSTANCE_NUMBER初期化パラメータで指定されたインスタンス番号。現在このフィールドはサポートされておらず、デフォルトはNULLです |
| OS_PROCESS         | VARCHAR2(40)                | NO             | オペレーティングシステムのプロセス識別子。現在このフィールドはサポートされておらず、デフォルトはNULLです                     |
