# DBA_JOBS_RUNNING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

実行中のタスクを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名**  |    **タイプ**     | **NULLを許容するか** |         **説明**          |
|-----------|---------------|----------------|-------------------------|
| SID       | NUMBER        | NO             | このタスクを実行しているプロセスの識別子です。         |
| JOB       | NUMBER        | NO             | タスク識別子です。                  |
| FAILURES  | NUMBER        | YES            | このタスクが前回正常に実行されて以来の成功と失敗の回数を記録します。 |
| LAST_DATE | DATE          | YES            | このタスクが前回正常に実行された日付です。           |
| LAST_SEC  | VARCHAR2(32)  | NO             | このタスクが前回正常に実行された開始時刻です。         |
| THIS_DATE | DATE          | YES            | このタスクが開始された日付です。             |
| THIS_SEC  | VARCHAR2(32)  | NO             | このタスクが正常に実行された開始時刻です。           |
| INSTANCE  | VARCHAR2(128) | YES            | Jobが実行されるゾーンを指定します。        |
