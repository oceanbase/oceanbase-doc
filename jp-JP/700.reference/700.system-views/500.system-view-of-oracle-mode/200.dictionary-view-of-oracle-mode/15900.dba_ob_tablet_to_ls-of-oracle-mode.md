# DBA_OB_TABLET_TO_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のすべてのTabletリストと、各Tabletが属するログストリーム情報を表示します。

## フィールドの説明

|   フィールド名    |   型   | NULL許容 |        説明        |
|-----------|--------|------------|------------------|
| TABLET_ID | NUMBER | NO         | TABLET ID        |
| LS_ID     | NUMBER | NO         | TABLETが属するログストリームID |

## クエリ例

ユーザーテナントが自身のテナントにおける1001番ログストリームのTabletリスト情報を照会し、上位5件の情報を表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLET_TO_LS WHERE LS_ID=1001 AND ROWNUM <= 5;
```

クエリ結果は次のとおりです：

```shell
+-----------+-------+
| TABLET_ID | LS_ID |
+-----------+-------+
|    200004 |  1001 |
|    200005 |  1001 |
|    200006 |  1001 |
|    200007 |  1001 |
|    200008 |  1001 |
+-----------+-------+
5 rows in set
```
