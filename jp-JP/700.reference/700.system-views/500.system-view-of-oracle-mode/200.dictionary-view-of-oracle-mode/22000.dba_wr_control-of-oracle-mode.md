# DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

WR関連の構成情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID <ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| SNAP_INTERVAL | VARCHAR2(64) | NO | スナップショット間の間隔設定。読みやすいように`DD HH:mm:SS`形式を使用します |
| RETENTION | VARCHAR2(64) | NO | スナップショット間の保持時間。読みやすいように`DD HH:mm:SS`形式を使用します |
| TOPNSQL | NUMBER(38) | NO | 保存されるトップNのSQL |

## クエリ例

WR関連の構成情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_CONTROL WHERE ROWNUM <= 1\G
```
