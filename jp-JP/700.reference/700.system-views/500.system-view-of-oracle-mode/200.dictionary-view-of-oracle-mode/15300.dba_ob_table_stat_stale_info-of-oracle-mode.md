# DBA_OB_TABLE_STAT_STALE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内で、前回統計情報を収集して以来に各テーブルで発生したDML操作の回数、および現在の統計情報が期限切れかどうかを表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | NO | テーブル所有者 |
| TABLE_NAME | VARCHAR2(128) | NO | テーブル名 |
| PARTITION_NAME | VARCHAR2(128) | YES | パーティション名。パーティションテーブルでは、この列の値がNULLの場合、現在のレコードがテーブルレベルで集計されていることを意味します |
| SUBPARTITION_NAME | VARCHAR2(128) | YES | サブパーティション名。サブパーティションテーブルでは、この列の値がNULLの場合、現在のレコードがテーブルレベルまたはパーティションレベルで集計されていることを意味します |
| LAST_ANALYZED_ROWS | NUMBER | YES | 前回統計情報を収集した際の行数。値がNULLの場合、統計情報が収集されたことがないことを意味します |
| LAST_ANALYZED_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 前回統計情報を収集した時間。値がNULLの場合、統計情報が収集されたことがないことを意味します |
| INSERTS | NUMBER | NO | 前回統計情報を収集して以来に発生した挿入行数 |
| UPDATES | NUMBER | NO | 前回統計情報を収集して以来に発生した更新行数 |
| DELETES | NUMBER | NO | 前回統計情報を収集して以来に発生した削除行数 |
| STALE_PERCENT | NUMBER | NO | 統計情報の有効期限が切れたかどうかを判定する割合 |
| IS_STALE | VARCHAR2(3) | NO | 統計情報が期限切れかどうか。<ul><li>`YES`は期限切れを意味します。<ul><li>テーブルの統計情報が収集されている場合、期限切れの条件は`INSERTS + UPDATES + DELETES > LAST_ANALYZED_ROWS * STALE_PERCENT / 100`です。 </li><li>テーブルの統計情報が収集されていない場合、期限切れの条件は`INSERTS + UPDATES + DELETES > 0`です。 </li></ul>  </li><li>`NO`は期限切れではないことを意味します。 </li></ul>|

## クエリ例

obclient [SYS]> SELECT * FROM SYS.DBA_OB_TABLE_STAT_STALE_INFO WHERE TABLE_NAME='T_SUBPART';
