# USER_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するパーティションテーブルのテンプレート化されたサブパーティション情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|       **フィールド名**        |     **型**     | **NULL許容** |  **説明**   |
|-----------------------|----------------|----------------|-----------|
| TABLE_NAME            | VARCHAR2(256)  | NO             | パーティションテーブル名     |
| SUBPARTITION_NAME     | VARCHAR2(132)   | NO             | サブパーティション名      |
| SUBPARTITION_POSITION | NUMBER         | YES            | サブパーティション位置     |
| TABLESPACE_NAME       | VARCHAR2(30)   | NO             | パーティションが属するテーブルスペース名 |
| HIGH_BOUND            | VARCHAR2(32767) | NO             | パーティションテンプレート式   |
| COMPRESSION           | VARCHAR2(4)     | NO         | デフォルト値はNULLです。サブパーティションテンプレート内の各新規追加の複合パーティションについて、そのサブパーティションデータを圧縮形式で保存するかどうかを示します。<ul><li>YES </li><li>NO </li></ul><br>この値はサブパーティションテンプレート内で指定できます          |
| INDEXING              | VARCHAR2(4)     | NO         | デフォルト値はNULLです。サブパーティションテンプレート内の各新規追加の複合パーティションについて、そのサブパーティションデータを部分的なインデックスとして扱うかどうかを示します。<ul><li>ON</li><li>OFF </li></ul><br>この値はサブパーティションテンプレート内で指定できます          |
| READ_ONLY             | VARCHAR2(4)     | NO         | デフォルト値はNULLです。サブパーティションテンプレート内の各新規追加の複合パーティションについて、そのサブパーティションデータを読み取り専用にするかどうかを示します。<ul><li>YES</li><li>NO </li></ul><br>この値はサブパーティションテンプレート内で指定できます          |

## クエリ例

現在ユーザーが所有するパーティションテーブルのテンプレート化されたサブパーティション情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_SUBPARTITION_TEMPLATES;
```

クエリ結果は次のとおりです：

```shell
+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| TABLE_NAME | SUBPARTITION_NAME | SUBPARTITION_POSITION | TABLESPACE_NAME | HIGH_BOUND | COMPRESSION | INDEXING | READ_ONLY |
+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| T2_M_LR    | MP0               |                     1 | NULL            | 100        | NULL        | NULL     | NULL      |
| T2_M_LR    | MP1               |                     2 | NULL            | 200        | NULL        | NULL     | NULL      |
| T2_M_LR    | MP2               |                     3 | NULL            | 300        | NULL        | NULL     | NULL      |
+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
3 rows in set
```
