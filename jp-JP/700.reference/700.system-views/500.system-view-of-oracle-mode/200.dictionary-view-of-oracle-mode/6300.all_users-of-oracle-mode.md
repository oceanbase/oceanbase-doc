# ALL_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

`ALL_USERS` ビューは、現在のユーザーが参照できるすべてのデータベースユーザーを確認するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースEnterprise Editionでのみ適用されます。</p>
  </main>

## フィールド説明

| **フィールド名** |    **型**    | **NULL許容** | **説明**  |
|----------|--------------|----------------|---------|
| USERNAME | VARCHAR2(30) | NO             | ユーザー名     |
| USERID   | NUMBER(38)   | NO             | ユーザーID   |
| CREATED  | DATE         | NO             | ユーザー作成日時 |
| COMMON            | VARCHAR2(3)   | NO   | 公共ユーザーかどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| ORACLE_MAINTAINED | VARCHAR2(1)   | NO   | Oracleモードで提供されるスクリプトによって作成・管理されているかどうか<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| INHERITED         | VARCHAR2(3)   | NO   | ユーザーが他のコンテナから継承されたかどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| DEFAULT_COLLATION | VARCHAR2(100) | NO   | デフォルトの文字セット <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| IMPLICIT          | VARCHAR2(3)   | NO   | 隠れたアプリケーションによって作成されたユーザーかどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|
| ALL_SHARD         | VARCHAR2(3)   | NO   | シャーディングが有効な状態で作成されたかどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1 BP2バージョンから導入されました。</p></main>|

## クエリ例

現在のユーザーが参照可能なすべてのデータベースユーザーを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_USERS\G
```
