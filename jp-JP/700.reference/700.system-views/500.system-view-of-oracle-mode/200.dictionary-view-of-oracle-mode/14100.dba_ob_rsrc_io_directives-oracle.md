# DBA_OB_RSRC_IO_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

Resource Manager内のI/Oリソース構成を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| PLAN | VARCHAR2(128) | NO | ステートメントが属するリソース計画の名前 |
| GROUP_OR_SUBPLAN | VARCHAR2(128) | NO | ステートメントが制御するリソースグループの名前 |
| COMMENTS | VARCHAR2(2000) | YES | リソース計画の備考 |
| MIN_IOPS |  NUMBER(38) | NO | IOPSの予約語。値は`0-100` |
| MAX_IOPS |  NUMBER(38) | NO | IOPSの上限語。値は`0-100` |
| WEIGHT_IOPS |  NUMBER(38) | NO | IOPSの共有語。値は`0-100` |

## クエリ例

ユーザーテナントが自身のテナントのResource Manager内のI/Oリソース構成を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_RSRC_IO_DIRECTIVES;
```

クエリ結果は次のとおりです：

```shell
+--------+------------------+-----------+----------+----------+-------------+
| PLAN   | GROUP_OR_SUBPLAN | COMMENTS  | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS |
+--------+------------------+-----------+----------+----------+-------------+
| PLAN_A | BIG_GROUP        | TP 优先   |       20 |      100 |          20 |
+--------+------------------+-----------+----------+----------+-------------+
1 row in set
```
