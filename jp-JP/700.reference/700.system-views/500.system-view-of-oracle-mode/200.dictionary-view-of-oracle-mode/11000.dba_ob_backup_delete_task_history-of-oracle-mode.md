# DBA_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントで完了した`backup_set`/`backup_piece`クリーンアップタスクの履歴情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TASK_ID | NUMBER(38) | NO | タスクグループID。一連のタスクを識別するために使用されます |
| INCARNATION | NUMBER(38) | NO | 分身ID |
| JOB_ID | NUMBER(38) | NO | タスクID。JOBテーブルに対応します |
| TASK_TYPE | VARCHAR2(64) | NO | タスクタイプ：<ul><li>`BACKUP SET`：`backup_set`のクリーンアップ</li><li>`BACKUP PIECE`：`backup_piece`のクリーンアップ</li></ul> |
| ID | NUMBER(38) | NO | タスクID。backup_set、pieceを含みます |
| ROUND_ID | NUMBER(38) | NO | pieceが属するdest_round_id。backup_setのクリーンアップでは、ROUND_IDは0です |
| DEST_ID | NUMBER(38) | NO | バックアップ宛先のDEST_ID |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時間 |
| END_TIMESTAMP | VARCHAR2(256) | NO | タスク終了時間 |
| STATUS | VARCHAR2(64) | NO | タスク状態：<ul><li>`COMPLETED`：タスクが正常に実行されました </li><li>`FAILED`：タスクの実行に失敗しました </li><li>`CANCELED`：タスクがキャンセルされました </li></ul> |
| TOTAL_LS_COUNT | NUMBER(38) | YES | タスク内のログストリーム数 |
| FINISH_LS_COUNT | NUMBER(38) | YES | 成功したログストリームタスク数 |
| RESULT | NUMBER(38) | YES | エラーコード |
| COMMENT | VARCHAR2(4096) | YES | コメント |
| PATH | VARCHAR2(1024) | NO | backup_set/backup_pieceが属するバックアップ宛先 |

## クエリ例

ユーザーテナントが本テナントで完了した`backup_set`または`backup_piece`クリーンアップタスクの履歴情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
```
