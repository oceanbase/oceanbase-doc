# USER_SYS_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーに付与されたシステム権限を一覧表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULL値を許容するか** |      **説明**      |
|--------------|---------------|----------------|------------------|
| USERNAME      | VARCHAR2(128) | NO             | 権限付与されるユーザー |
| PRIVILEGE    | VARCHAR2(40)  | NO             | 付与されるシステム権限             |
| ADMIN_OPTION | VARCHAR2(3)   | NO             | 管理オプションを付与するか           |

## クエリ例

`SYS`ユーザーに付与されたシステム権限を確認し、上位5件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM USER_SYS_PRIVS WHERE USERNAME='SYS' AND ROWNUM <=5;
```

クエリ結果は次のとおりです：

```shell
+----------+------------------+--------------+
| USERNAME | PRIVILEGE        | ADMIN_OPTION |
+----------+------------------+--------------+
| SYS      | CREATE SESSION   | YES          |
| SYS      | CREATE TABLE     | YES          |
| SYS      | CREATE ANY TABLE | YES          |
| SYS      | ALTER ANY TABLE  | YES          |
| SYS      | BACKUP ANY TABLE | YES          |
+----------+------------------+--------------+
5 rows in set
```
