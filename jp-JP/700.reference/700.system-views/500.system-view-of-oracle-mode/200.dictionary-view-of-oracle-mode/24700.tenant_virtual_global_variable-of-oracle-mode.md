# TENANT_VIRTUAL_GLOBAL_VARIABLE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のすべてのグローバル変数情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|   **フィールド名**    |     **型**      | **NULL許容** | **説明** |
|---------------|-----------------|----------------|--------|
| VARIABLE_NAME | VARCHAR2(128)   | NO             | 変数名    |
| VALUE         | VARCHAR2(65536) | YES            | 変数値    |

## クエリ例

現在のテナント配下のグローバル変数`max_user_connections`の値を確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE WHERE VARIABLE_NAME = 'max_user_connections';
```

クエリ結果は次のとおりです：

```shell
+----------------------+-------+
| VARIABLE_NAME        | VALUE |
+----------------------+-------+
| max_user_connections | 0     |
+----------------------+-------+
1 row in set
```
