# DBA_WR_SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_WR_SYSTEM_EVENT`は、テナント内の永続化されたテナントレベルの待機イベント情報を表示するために使用されます。

## フィールドの説明

| **フィールド名**      | **型**    | **NULL許容** | **説明**                               |
|-------------------|-------------|---------------------|----------------------------------------|
| SNAP_ID           | NUMBER(38)  | NO   |  スナップショットID   |
| SVR_IP            | VARCHAR2(46) | NO   |  ノードIPアドレス   |
| SVR_PORT          | NUMBER(38)  | NO   |  ノードポート番号    |
| EVENT_ID          | NUMBER(38)  | NO   |  待機イベントID   |
| EVENT_NAME        | VARCHAR2(64) | YES  |  待機イベント名    |
| WAIT_CLASS_ID     | NUMBER(38)  | YES  |  待機イベントが属するクラスID      |
| WAIT_CLASS        | VARCHAR2(64) | YES  |  待機イベントが属するクラス名       |
| TOTAL_WAITS       | NUMBER(38)  | YES  |  待機イベントの合計待機回数       |
| TOTAL_TIMEOUTS    | NUMBER(38)  | YES  |  待機イベントの合計タイムアウト回数        |
| TIME_WAITED_MICRO | NUMBER(38)  | YES  |  待機イベントの合計待機時間       |

ビューの`WAIT_CLASS`列の値に含まれる待機イベントの種類名と対応する待機イベントIDは、次の表のとおりです。

| 待機イベントの種類名 | 待機イベントID | 説明 |
|------|----|------|
| OTHER | 100 | その他の種類に分類されない待機イベント |
| APPLICATION | 101 | クライアントコードによって発生した待機イベント |
| CONFIGURATION | 102 | データベースまたはインスタンスのリソース設定不足によって発生した待機イベント |
| ADMINISTRATIVE | 103 | データベース管理者がコマンドを入力したことによりユーザーが待機する待機イベント |
| CONCURRENCY | 104 | データベース内部リソースを待機する待機イベント |
| COMMIT | 105 | ログコミットに関連する待機イベント |
| IDLE | 106 | セッションが非アクティブ状態でタスクを待機する待機イベント |
| NETWORK | 107 | ネットワーク通信に関連する待機イベント |
| USER_IO | 108 | ユーザーI/Oを待機する待機イベント |
| SYSTEM_IO | 109 | バックグラウンドプロセスのI/Oを待機する待機イベント |
| CLUSTER | 111 | クラスタに関連する待機イベント|

## クエリ例

本テナントの永続化されたテナントレベルの待機イベント情報を照会し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_SYSTEM_EVENT WHERE ROWNUM = 1;
```

クエリ結果は次のとおりです：

```shell
+---------+----------------+----------+----------+---------------------------------+---------------+-------------+-------------+----------------+-------------------+
| SNAP_ID | SVR_IP         | SVR_PORT | EVENT_ID | EVENT_NAME                      | WAIT_CLASS_ID | WAIT_CLASS  | TOTAL_WAITS | TOTAL_TIMEOUTS | TIME_WAITED_MICRO |
+---------+----------------+----------+----------+---------------------------------+---------------+-------------+-------------+----------------+-------------------+
|      27 | 172.xx.xxx.xxx |     2882 |        2 | latch: default spin rwlock wait |           104 | CONCURRENCY |          35 |              0 |             22996 |
+---------+----------------+----------+----------+---------------------------------+---------------+-------------+-------------+----------------+-------------------+
1 row in set
```
