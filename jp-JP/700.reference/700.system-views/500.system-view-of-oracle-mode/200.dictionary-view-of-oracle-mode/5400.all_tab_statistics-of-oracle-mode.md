# ALL_TAB_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なテーブルのオプティマイザー統計情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## クエリ例

現在ユーザーがアクセス可能なテーブルのうち、テーブル `T_SUBPART` のオプティマイザー統計情報を確認します。

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, OBJECT_TYPE, NUM_ROWS, AVG_ROW_LEN FROM SYS.ALL_TAB_STATISTICS WHERE TABLE_NAME = 'T_SUBPART' ORDER BY 1, 2, 3;
```

```shell

| SYS   | T_SUBPART  | PARTITION    |     4966 |          60 |

| SYS   | T_SUBPART  | SUBPARTITION |      829 |          60 |

| SYS   | T_SUBPART  | SUBPARTITION |      560 |          60 |
```
