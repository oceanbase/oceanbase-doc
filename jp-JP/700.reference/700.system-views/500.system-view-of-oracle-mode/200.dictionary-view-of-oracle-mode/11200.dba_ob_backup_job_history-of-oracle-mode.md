# DBA_OB_BACKUP_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナント自身のバックアップJOBタスクの履歴を表示します。

## フィールド説明

| フィールド名 | フィールド名 | NULL許容 | フィールド名 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | バックアップJOBタスクID。1回のバックアップに対応する1件のJOBタスクレコード |
| INCARNATION | NUMBER(38) | NO | Flashback Database後の何番目の分身かを示す |
| BACKUP_SET_ID | NUMBER(38) | YES | バックアップセットID。sysテナントはデフォルトで0、一般テナントは1から連番 |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | タスク発起者のテナントID。バックアップSQLコマンドを実行したテナントIDに対応する |
| INITIATOR_JOB_ID | NUMBER(38) | NO | タスク発起者が属するJOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | そのJOBレベルバックアップタスクに関連する、バックアップを実行する必要があるテナントID |
| PLUS_ARCHIVELOG | VARCHAR2(4096) | NO | ログ補完機能の有無：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul> |
| BACKUP_TYPE | VARCHAR2(4096) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを示す </li> <li>`INC`：増分バックアップを示す</li></ul> |
| JOB_LEVEL | VARCHAR2(4096) | NO | JOBレベル：<ul><li>CLUSTER：sysテナントが全テナントのバックアップタスクを開始する場合</li><li>SYS_TENANT：sysテナントが指定テナントのバックアップタスクを開始する場合</li><li>USER_TENANT：一般テナントが自身のバックアップを開始する場合</li></ul> |
| ENCRYPTION_MODE | VARCHAR2(4096) | YES | 暗号化モード：<ul><li>None：暗号化しないことを示す</li><li>Password：パスワードによるみだけの保護を示す</li><li>Password Encryption：暗号化し、パスワードで保護することを示す</li><li>Transparent Encryption：TDE暗号化を使用することを示す</li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用することを示す</li></ul> </br>現在、NoneとPasswordの2つのモードのみサポートしています |
| PASSWD | VARCHAR2(4096) | YES | パスワード |
| START_TIMESTAMP | VARCHAR2(256) | NO | JOBレベルバックアップタスクの開始時間 |
| END_TIMESTAMP | VARCHAR2(256) | NO | JOBレベルバックアップタスクの終了時間 |
| STATUS | VARCHAR2(4096) | NO | バックアップの状態 |
| RESULT | NUMBER(38) | NO | バックアップエラーコードの結果 |
| COMMENT | VARCHAR2(4096) | YES | エラーコードの説明 |
| DESCRIPTION | VARCHAR2(4096) | YES | ユーザー指定のバックアップ説明情報 |
| PATH | VARCHAR2(4096) | YES | バックアップパス |

## クエリ例

ユーザーテナントが自身のテナントにおけるバックアップジョブタスクの履歴を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_JOB_HISTORY\G
```
