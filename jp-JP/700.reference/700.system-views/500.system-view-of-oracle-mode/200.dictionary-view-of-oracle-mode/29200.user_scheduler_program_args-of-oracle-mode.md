# USER_SCHEDULER_PROGRAM_ARGS

<main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースは、このビューをサポートしていません。</p>
  </main>

## 機能の概要

現在のユーザーが所有するスケジューラーパラメータ情報を表示します。

## フィールドの説明

|       **フィールド名**        |     **タイプ**     | **NULL許容** |                                                  **説明**                                                  |
|-----------------------|----------------|----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROGRAM_NAME          | VARCHAR2(30)   | NO             | パラメータが属するプログラム名             |
| ARGUMENT_NAME         | VARCHAR2(30)   | NO             | パラメータのオプション名               |
| ARGUMENT_POSITION     | NUMBER         | NO             | パラメータリスト内のパラメータ位置           |
| ARGUMENT_TYPE         | VARCHAR2(61)   | NO             | パラメータのデータ型               |
| METADATA_ATTRIBUTE    | VARCHAR2(19)   | NO             | メタデータの属性：<ul><li>JOB_NAME   </li><li> JOB_OWNER   </li><li> JOB_START   </li><li> WINDOW_START   </li><li> WINDOW_END   </li><li> JOB_SUBNAME   </li><li> EVENT_MESSAGE   </li><li> JOB_SCHEDULER_START </li></ul>   |
| DEFAULT_VALUE         | VARCHAR2(4000) | NO             | パラメータが文字列タイプの場合、デフォルト値   |
| DEFAULT_ANYDATA_VALUE | VARCHAR2(128)  | NO             | パラメータがANYDATAタイプの場合、デフォルト値                                                                                  |
| OUT_ARGUMENT          | VARCHAR2(5)    | NO             | 予約語フィールド                  |
