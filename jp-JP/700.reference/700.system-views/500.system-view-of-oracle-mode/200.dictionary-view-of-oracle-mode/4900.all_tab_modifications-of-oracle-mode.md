# ALL_TAB_MODIFICATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできるテーブルの累計変更情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TABLE_OWNER | VARCHAR2(128) | NO | テーブルの所有者を変更します |
| TABLE_NAME | VARCHAR2(128) | NO | テーブル名を変更します |
| PARTITION_NAME | VARCHAR2(128) | NO | パーティション名を変更します |
| SUBPARTITION_NAME | VARCHAR2(128) | NO | サブパーティション名を変更します |
| INSERTS | NUMBER | NO | 約の挿入回数 |
| UPDATES | NUMBER | NO | 約の更新回数 |
| DELETES | NUMBER | NO | 約の削除回数 |
| TIMESTAMP | DATE | NO | テーブルが最後に変更された時間を示します |
| TRUNCATED | VARCHAR2(3) | NO | 現在は実際の意味はなく、デフォルトはNULLです |
| DROP_SEGMENTS | NUMBER | NO | 現在は実際の意味はなく、デフォルトはNULLです |
