# USER_USERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザー情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースEnterprise Editionにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| USERNAME                    | VARCHAR2(128)  | NO   | ユーザー名 |
| USERID                      | NUMBER(38)     | NO   | ユーザーID |
| ACCOUNT_STATUS              | VARCHAR2(32)   | NO   | アカウントのステータス：<ul><li>OPEN：アカウントが有効化されています</li><li>EXPIRED：アカウントのパスワードが期限切れになりました </li><li>EXPIRED(GRACE)：アカウントのパスワードが期限切れになりましたが、パスワード変更期限まで残り時間があります </li><li>LOCKED(TIMED)：連続ログイン失敗回数が制限を超えたため、アカウントがロックされました </li><li>LOCKED：アカウントがロックされました </li><li>EXPIRED & LOCKED(TIMED)：アカウントのパスワードが期限切れになり、かつ連続ログイン失敗回数が制限を超えたため、アカウントがロックされました </li><li>EXPIRED(GRACE) & LOCKED(TIMED)：パスワードが期限切れになり、かつパスワード変更期限まで残り時間があり、さらに連続ログイン失敗回数が制限を超えたため、アカウントがロックされました </li><li>EXPIRED & LOCKED：アカウントはパスワード更新期間中です </li><li>EXPIRED(GRACE) & LOCKED：パスワードが期限切れになり、かつパスワード変更期限まで残り時間がありません </li></ul>|
| LOCK_DATE                   | DATE           | NO   | アカウントのステータスがロックされている場合、ロックされた日付 |
| EXPIRY_DATE                 | DATE           | NO   | アカウントの有効期限 |
| DEFAULT_TABLESPACE          | VARCHAR2(30)   | NO   | データのデフォルトテーブルスペース |
| TEMPORARY_TABLESPACE        | VARCHAR2(30)   | NO   | 一時テーブルのデフォルトテーブルスペース名またはテーブルスペースグループ名 |
| LOCAL_TEMP_TABLESPACE       | VARCHAR2(30)   | NO   | ローカル一時テーブルスペース |
| CREATED                     | DATE           | NO   | ユーザー作成日 |
| INITIAL_RSRC_CONSUMER_GROUP | VARCHAR2(30)   | NO   | ユーザーの初期リソースユーザーグループ |
| EXTERNAL_NAME               | VARCHAR2(4000) | NO   | ユーザーの外部名 |
| PROXY_ONLY_CONNECT          | VARCHAR2(1)    | NO   | プロキシユーザー経由でのみ接続可能か |
| COMMON                      | VARCHAR2(3)    | NO   | パブリックユーザーか |
| ORACLE_MAINTAINED           | VARCHAR2(1)    | NO   | Oracleモードによって提供されるスクリプトで作成および維持管理されているか |
| INHERITED                   | VARCHAR2(3)    | NO   | ユーザーが他のコンテナから継承されているか |
| DEFAULT_COLLATION           | VARCHAR2(100)  | NO   | デフォルトの文字セット |
| IMPLICIT                    | VARCHAR2(3)    | NO   | 隠れたアプリケーションによって作成されたユーザーか |
| ALL_SHARD                   | VARCHAR2(3)    | NO   | シャーディングが有効な場合に作成されたか |
| PASSWORD_CHANGE_DATE        | DATE           | YES  | 最後のパスワード変更日時 |
