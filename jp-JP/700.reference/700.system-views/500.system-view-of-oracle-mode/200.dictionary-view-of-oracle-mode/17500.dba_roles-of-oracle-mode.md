# DBA_ROLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内に存在するすべてのロールを表示します。

<main id="notice" >
<h4>適用対象</h4>
<p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
</main>

## フィールドの説明

|      **フィールド名**   |    **タイプ**    | **NULLを許容するか** |               **説明**               |
|---------------------|--------------|----------------|------------------------------------|
| ROLE                | VARCHAR2(30) | NO             | ロール名                               |
| PASSWORD_REQUIRED   | VARCHAR2(8)  | NO             | ロールにパスワードを有効にするかどうかを示します。現在、ロールのパスワード機能はサポートされていますが、このフィールドは正しく表示されません |
| AUTHENTICATION_TYPE | VARCHAR2(11) | NO             | ロールの認証メカニズムを示します。現在、このフィールドはサポートされていません。             |

## クエリ例

このテナント内に存在するすべてのロールを確認します。

```shell
obclient> SELECT * FROM SYS.DBA_ROLES;
```

クエリ結果は次のとおりです：

```shell
+---------------------+-------------------+---------------------+
| ROLE                | PASSWORD_REQUIRED | AUTHENTICATION_TYPE |
+---------------------+-------------------+---------------------+
| CONNECT             | NO                | NONE                |
| RESOURCE            | NO                | NONE                |
| DBA                 | NO                | NONE                |
| PUBLIC              | NO                | NONE                |
| STANDBY_REPLICATION | NO                | NONE                |
| ROLE1               | NO                | NONE                |
+---------------------+-------------------+---------------------+
6 rows in set
```
