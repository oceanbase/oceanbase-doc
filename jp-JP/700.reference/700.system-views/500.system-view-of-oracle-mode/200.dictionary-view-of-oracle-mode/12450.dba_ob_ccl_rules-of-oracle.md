# DBA_OB_CCL_RULES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このビューはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このビューはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>

## 機能の概要

ユーザーテナントの現在のすべてのレート制限ルールを記録するために使用されます。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID                | NUMBER(38)        | NO   |テナントID |
| CCL_RULE_ID              | NUMBER(38)        | NO   |レート制限ルールID|
| CCL_RULE_NAME            | VARCHAR2(128)     | NO   |レート制限ルール名 |
| AFFECT_USER_NAME         | VARCHAR2(64)      | NO   |レート制限が適用されるユーザー|
| AFFECT_HOST              | VARCHAR2(128)     | NO   |レート制限が適用されるIPアドレス |
| AFFECT_FOR_ALL_DATABASES | NUMBER(38)        | NO   |すべてのデータベースに適用するかどうか|
| AFFECT_FOR_ALL_TABLES    | NUMBER(38)        | NO   |すべてのテーブルに適用するかどうか|
| AFFECT_DATABASE          | VARCHAR2(128)     | YES  |レート制限が適用されるデータベース |
| AFFECT_TABLE             | VARCHAR2(256)     | YES  |レート制限が適用されるテーブル|
| AFFECT_DML               | NUMBER(38)        | NO   |レート制限が適用されるDMLステートメントの種類 |
| AFFECT_SCOPE             | NUMBER(38)        | NO   |レート制限の適用粒度:<li>ルールレベル: 0 </li><li>Format SQLIDレベル:1</li>|
| CCL_KEYWORDS             | VARCHAR2(1048576) | NO   |レート制限キーワード|
| MAX_CONCURRENCY          | NUMBER(38)        | NO   |レート制限の最大並列度|

## クエリ例

ユーザーテナントが自身のテナントのレート制限ルールをクエリします。

```shell
obclient > SELECT * FROM DBA_OB_CCL_RULES;
```
