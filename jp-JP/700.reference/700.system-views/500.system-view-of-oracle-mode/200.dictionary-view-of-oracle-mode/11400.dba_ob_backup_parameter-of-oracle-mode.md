# DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで設定されているバックアップパラメータ情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| NAME | varchar2(1024) | NO | パラメータ名 |
| VALUE | CLOB | NO | パラメータ値 |

## クエリ例

ユーザーテナントが自身のテナントに設定されたバックアップパラメータ情報を確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_PARAMETER;
```

クエリ結果は次のとおりです：

```shell
+------------------+------------------------------------------------------------------------------------------------------------------------------+
| NAME             | VALUE                                                                                                                        |
+------------------+------------------------------------------------------------------------------------------------------------------------------+
| data_backup_dest | oss://example_path/data?host=cn-heyuan.aliyuncs.com&access_id=******&access_key=******&checksum_type=md5&enable_worm=true    |
+------------------+------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```
