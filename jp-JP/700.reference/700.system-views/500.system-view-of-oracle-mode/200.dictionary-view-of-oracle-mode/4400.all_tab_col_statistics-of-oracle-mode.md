# ALL_TAB_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`ALL_TAB_COL_STATISTICS`は、現在のユーザーがアクセス可能なテーブルの列統計情報とヒストグラム情報を表示するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|     フィールド名      |      タイプ       | **NULLを許容するか** |                                                               説明                                                               |
|---------------|---------------|----------------|--------------------------------------------------------------------------------------------------------------------------------|
| OWNER         | VARCHAR2(128) | NO             | 列が属するユーザー                                      |
| TABLE_NAME    | VARCHAR2(128) | NO             | 列が属するテーブル名                                      |
| COLUMN_NAME   | VARCHAR2(128) | NO             | 列名                                          |
| NUM_DISTINCT  | NUMBER        | YES            | 列内の異なる値の数                                    |
| LOW_VALUE     | VARCHAR2(128) | YES            | 列の最小値                                       |
| HIGH_VALUE    | VARCHAR2(128) | YES            | 列の最大値                                       |
| DENSITY       | NUMBER        | YES            | 列の密度                                        |
| NUM_NULLS     | NUMBER        | YES            | 列内の`NULL`値の数                              |
| NUM_BUCKETS   | NUMBER        | YES            | 列ヒストグラムのバケット数                                   |
| LAST_ANALYZED | DATE          | YES            | 前回の分析時間                                     |
| SAMPLE_SIZE   | NUMBER        | YES            | 分析時のサンプリングサイズ                                    |
| GLOBAL_STATS  | VARCHAR2(3)   | YES            | <ul><li> `YES`：統計情報が直接収集されたか、増分メンテナンスされたことを示す </li><li> `NO`：その他の場合 </li></ul> |
| USER_STATS    | VARCHAR2(3)   | YES            | パーティション統計情報がユーザー設定であるかどうか                              |
| NOTES         | VARCHAR2(80)  | YES            | いくつかの追加のプロパティを記録                                   |
| AVG_COL_LEN   | NUMBER        | YES            | 列の平均長                                      |
| HISTOGRAM     | VARCHAR2(15)  | YES            | ヒストグラムタイプ                                       |
| SCOPE         | VARCHAR2(7)   | YES            | 統計情報の有効範囲                                   |

## クエリ例

現在のユーザーがアクセス可能なテーブルのうち、テーブル `T_SUBPART` の列統計情報を確認します。

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, COLUMN_NAME, NUM_DISTINCT, LOW_VALUE, HIGH_VALUE, DENSITY, NUM_NULLS, NUM_BUCKETS, SAMPLE_SIZE, AVG_COL_LEN, HISTOGRAM FROM SYS.ALL_TAB_COL_STATISTICS WHERE TABLE_NAME ='T_SUBPART'  ORDER BY 1, 2, 3;
```

クエリ結果は次のとおりです：

```shell

+-------+------------+-------------+--------------+-----------+------------+------------------------+-----------+-------------+-------------+-------------+-----------+
| SYS   | T_SUBPART  | C1          |        10191 | 0         | 9999       | .000098125797272102829 |         0 |           5 |       10000 |          20 | HYBRID    |
| SYS   | T_SUBPART  | C2          |         1031 | 0         | 999        |  .00096993210475266732 |         0 |           5 |       10000 |          20 | HYBRID    |
| SYS   | T_SUBPART  | C3          |         1973 | 0         | 1999       |  .00050684237202230106 |         0 |           5 |       10000 |          20 | HYBRID    |
```
