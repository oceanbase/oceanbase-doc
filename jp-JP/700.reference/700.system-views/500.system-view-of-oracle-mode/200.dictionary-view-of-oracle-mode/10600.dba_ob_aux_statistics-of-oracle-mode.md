# DBA_OB_AUX_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_AUX_STATISTICS`は、各テナントの補助統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名**              | **タイプ**     | **NULL許容**  | **説明** |
|---------------------------|--------------|----------------------|-----------|
| LAST_ANALYZED             | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | 最終の統計収集時刻のタイムスタンプ     |
| CPU_SPEED(MHZ)            | NUMBER(38)   | YES  | 現在の環境のCPU周波数（MHz単位）     |
| DISK_SEQ_READ_SPEED(MB/S) | NUMBER(38)   | YES  | ハードディスクのシーケンシャル読み取り速度（MB/s単位）     |
| DISK_RND_READ_SPEED(MB/S) | NUMBER(38)   | YES  | ハードディスクのランダム読み取り速度（MB/s単位）     |
| NETWORK_SPEED(MB/S)       | NUMBER(38)   | YES  | ネットワーク転送速度（MB/s単位）     |

## クエリ例

1. 補助統計情報の収集を手動で開始します：

   ```shell
   obclient [SYS]> CALL dbms_stats.gather_system_stats();
   ```

2. テナントの補助統計情報を照会します：

   ```shell
   obclient [SYS]> SELECT * FROM SYS.DBA_OB_AUX_STATISTICS;
   ```

3. クエリ結果は次のとおりです：

   ```shell
   +------------------------------+----------------+---------------------------+---------------------------+---------------------+
   | LAST_ANALYZED                | CPU_SPEED(MHZ) | DISK_SEQ_READ_SPEED(MB/S) | DISK_RND_READ_SPEED(MB/S) | NETWORK_SPEED(MB/S) |
   +------------------------------+----------------+---------------------------+---------------------------+---------------------+
   | 14-MAR-24 02.40.36.904572 PM |           2499 |                      2675 |                       370 |                1250 |
   +------------------------------+----------------+---------------------------+---------------------------+---------------------+
   1 row in set (0.017 sec)
   ```
