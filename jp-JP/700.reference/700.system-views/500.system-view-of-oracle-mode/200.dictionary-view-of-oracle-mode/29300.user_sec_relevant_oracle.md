# USER_SEC_RELEVANT_COLS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するテーブルまたはビューにおいて、ポリシーに関連付けられたすべての列の情報を表示します。特定の列と列レベルのポリシーを関連付けることで、その列にアクセスした際に対応するポリシーが適用されます。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OBJECT_NAME | VARCHAR2(128) | YES | ポリシーで制御されるオブジェクトの名前 |
| POLICY_GROUP | VARCHAR2(128) | NO | ポリシーグループ名 |
| POLICY_NAME | VARCHAR2(128) | NO | ポリシー名 |
| SEC_REL_COLUMN | VARCHAR2(128) | YES | 列レベルポリシーが関連付けられている列名 |
| COLUMN_OPTION | VARCHAR2(8) | NO |   ポリシーオプション：<ul><li> NONE </li><li> ALL_ROWS </li></ul>|
| COMMON | VARCHAR2(3) | NO | 互換性のためにのみ使用され、現在の値は常にNOです。 |
| INHERITED | VARCHAR2(3) | NO | 互換性のためにのみ使用され、現在の値は常にNOです。 |

## クエリ例

現在ユーザーが所有するテーブルまたはビューにおいて、ポリシーに関連付けられたすべての列の情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_SEC_RELEVANT_COLS;
```

クエリ結果は次のとおりです：

```shell
+----------------+--------------+----------------+----------------+---------------+--------+-----------+
| OBJECT_NAME    | POLICY_GROUP | POLICY_NAME    | SEC_REL_COLUMN | COLUMN_OPTION | COMMON | INHERITED |
+----------------+--------------+----------------+----------------+---------------+--------+-----------+
| V_SALES_SECURE | GROUP_SALES  | POLICY_REGION  | AMOUNT         | NONE          | NO     | NO        |
| V_ORDERS_CTX   | GROUP_REGION | POLICY_DYNAMIC | AMOUNT         | NONE          | NO     | NO        |
+----------------+--------------+----------------+----------------+---------------+--------+-----------+
2 rows in set
```
