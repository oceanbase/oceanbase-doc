# ALL_PART_INDEXES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセス可能なパーティションインデックスのパーティション情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|         **フィールド名**          |     **タイプ**     | **NULLを許容するか** |**説明**|
|---------------------------|----------------|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER                     | VARCHAR2(128)  | NO             | パーティションインデックスの所有者                                                                                |
| INDEX_NAME                | VARCHAR2(128)  | NO             | パーティションインデックスの名前                                                                                 |
| TABLE_NAME                | VARCHAR2(128)  | NO             | インデックスが属するテーブルの名前                                                                               |
| PARTITIONING_TYPE         | VARCHAR2(9)    | NO             | パーティショニング方式：<ul><li> HASH   </li><li> RANGE   </li><li> LIST  </li></ul>      |
| SUBPARTITIONING_TYPE      | VARCHAR2(9)    | NO             | サブパーティションのパーティショニング方式：<ul><li> HASH   </li><li> RANGE   </li><li> LIST </li></ul>   |
| PARTITION_COUNT           | NUMBER         | NO             | インデックス内のパーティション数                                                                                 |
| DEF_SUBPARTITION_COUNT    | NUMBER         | NO             | 複合パーティションインデックスにおいて、サブパーティションの数を示す                                                                       |
| PARTITIONING_KEY_COUNT    | NUMBER         | NO             | パーティションキーの数                                                                                  |
| SUBPARTITIONING_KEY_COUNT | NUMBER         | NO             | 複合パーティションインデックスにおいて、サブパーティションキーの数を示す                                                                      |
| LOCALITY                  | VARCHAR2(6)    | NO             | パーティションインデックスがローカル（LOCAL）かグローバル（GLOBAL）か                                                            |
| ALIGNMENT                 | VARCHAR2(12)   | NO             | パーティションインデックスがプレフィックス付き（PREFIXED）かプレフィックスなし（NON_PREFIXED）か                                                   |
| DEF_TABLESPACE_NAME       | VARCHAR2(30)   | NO             | ローカルインデックスに対して、テーブルパーティションの追加または分割時のデフォルトのテーブルスペース |
| DEF_PCT_FREE              | NUMBER         | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値は0です          |
| DEF_INI_TRANS             | NUMBER         | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値は0です              |
| DEF_MAX_TRANS             | NUMBER         | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値は0です                |
| DEF_INITIAL_EXTENT        | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです             |
| DEF_NEXT_EXTENT           | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです          |
| DEF_MIN_EXTENTS           | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです            |
| DEF_MAX_EXTENTS           | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです       |
| DEF_MAX_SIZE              | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです       |
| DEF_PCT_INCREASE          | VARCHAR2(40)   | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです       |
| DEF_FREELISTS             | NUMBER         | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値は0です         |
| DEF_FREELIST_GROUPS       | NUMBER         | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値は0です            |
| DEF_LOGGING               | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです          |
| DEF_BUFFER_POOL           | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです           |
| DEF_flash_CACHE           | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです            |
| DEF_cell_flash_CACHE      | VARCHAR2(7)    | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです             |
| DEF_PARAMETERS            | VARCHAR2(1000) | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです                |
| INTERVAL                  | VARCHAR2(1000) | NO             | 現在このフィールドはサポートされておらず、現在のデフォルト値は`NO`です           |
| AUTOLIST                  | VARCHAR2(3)    | NO         | ローカルインデックスが自動リストパーティションを使用するかどうかを指定します：<ul><li>YES</li><li>NO </li></ul>  |
| INTERVAL_SUBPARTITION     | VARCHAR2(1000) | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです     |
| AUTOLIST_SUBPARTITION     | VARCHAR2(1000) | NO         | 現在このフィールドはサポートされておらず、現在のデフォルト値はNULLです     |
