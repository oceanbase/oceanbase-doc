# DBA_CONTEXT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのコンテキスト名前空間情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|     フィールド名      |      型       | NULL許容 |          説明           |
|---------------|---------------|------------|-----------------------|
| NAMESPACE     | VARCHAR2(128) | NO         | コンテキスト名前空間の名前            |
| SCHEMA        | VARCHAR2(128) | NO         | この名前空間を使用してプロパティが属するパッケージのユーザー名を設定できます |
| PACKAGE       | VARCHAR2(128) | NO         | この名前空間を使用してプロパティの指定パッケージのパッケージ名を設定できます  |
| TYPE          | VARCHAR2(22)  | NO         | コンテキストの作成タイプ              |
| ORIGIN_CON_ID | NUMBER        | NO         | テナントID                 |
| TRACKING | VARCHAR2(3)        | NO         | 互換性のためのみ使用され、現在の値は常に`YES`です                |

## クエリ例

現在のテナント内のすべてのコンテキスト名前空間情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_CONTEXT;
```

クエリ結果は次のとおりです：

```shell
+------------+--------+-------------------+------------------+---------------+----------+
| NAMESPACE  | SCHEMA | PACKAGE           | TYPE             | ORIGIN_CON_ID | TRACKING |
+------------+--------+-------------------+------------------+---------------+----------+
| SALES_CTX  | SYS    | SET_SALES_CTX_PKG | ACCESSED LOCALLY |          1004 | YES      |
| REGION_CTX | SYS    | REGION_CTX_PKG    | ACCESSED LOCALLY |          1004 | YES      |
| DEPT_CTX   | SYS    | DEPT_CTX_PKG      | ACCESSED LOCALLY |          1004 | YES      |
+------------+--------+-------------------+------------------+---------------+----------+
3 rows in set
```
