# DBA_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</li>
<li>V4.6.xバージョンでは、このビューはV4.6.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_OB_BACKUP_VALIDATE_JOBS`は、テナントが開始したJobレベルのバックアップ検証タスクに関する情報を表示するために使用されます。各Jobは1つのバックアップ検証命令に対応します。

## フィールドの説明

| フィールド名             | 型           | NULL許容 | 説明           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | NUMBER(38)     | NO   | タスクID     |
| INCARNATION         | NUMBER(38)     | NO   | 分身ID     |
| INITIATOR_TENANT_ID | NUMBER(38)     | NO   | このJobを開始したテナントID   |
| INITIATOR_JOB_ID    | NUMBER(38)     | NO   | このJobを開始したjob_id。値が0の場合、このJobを開始したのは現在のJobであることを示します     |
| EXECUTOR_TENANT_ID  | VARCHAR2(65536)| NO   | このJobに対応する検証タスクを実行するユーザーテナントのtenant_id。値が空の場合、検証タスクを実行したのは現在のテナントであることを示します     |
| TYPE                | VARCHAR2(64)   | NO   | 検証タスクのタイプ：<ul><li>`DATABASE`：バックアップパスとアーカイブパス配下のすべてのバックアップセットおよびログアーカイブPieceを検証します</li> <li>`BACKUPSET`：指定されたバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定されたログアーカイブPieceを検証します</li></ul>     |
| PATH                | CLOB           | YES  | ユーザーが指定した検証用バックアップパスまたはログアーカイブパスです。値が空の場合、このタスクは指定パス以外の検証であることを示します     |
| PATH_TYPE           | VARCHAR2(64)   | YES  | ユーザーが指定したパス配下で検証するタイプです（値が空の場合、このタスクは指定パス以外の検証であることを示します）：<ul><li>`BACKUPSET`：指定パス配下のバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定パス配下のログアーカイブPieceを検証します</li></ul>     |
| ID                  | CLOB           | YES  | <p>検証対象のバックアップセットの`backup_set_id`またはアーカイブPieceの`piece_id`</p><p>デフォルトは空で、現在のバックアップパスとアーカイブパス配下のすべてのバックアップセットおよびログアーカイブPieceを意味します。ユーザーがバックアップセットの`backup_set_id`またはアーカイブPieceの`piece_id`を指定すると、値は対応するIDまたはIDリストに変更されます</p>     |
| VALIDATE_LEVEL      | VARCHAR2(64)   | NO   | 検証レベル：<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一貫性をチェックします。</li></ul>    |
| START_TIMESTAMP     | VARCHAR2(256)  | NO   | 検証タスクの開始時刻     |
| END_TIMESTAMP       | VARCHAR2(256)  | NO   | 検証タスクの終了時刻     |
| STATUS              | VARCHAR2(64)   | NO   | Jobの状態：<ul><li>`INIT`：検証タスクが初期化中です</li> <li>`DOING`：検証タスクが実行中です</li> <li>`COMPLETED`：検証タスクが完了しました</li> <li>`FAILED`：検証タスクの実行に失敗しました</li> <li>`CANCELED`：検証タスクがキャンセルされました</li></ul>   |
| RETRY_COUNT         | NUMBER(38)     | YES  | 再試行回数     |
| TASK_COUNT          | NUMBER(38)     | YES  | バックアップセットまたはログアーカイブPieceの総検証タスク数     |
| SUCCESS_TASK_COUNT  | NUMBER(38)     | YES  | バックアップセットまたはログアーカイブPieceの検証に成功したタスク数     |
| RESULT              | NUMBER(38)     | NO   | 検証結果のエラーコード情報    |
| DESCRIPTION         | VARCHAR2(4096) | YES  | OCP提供の外部情報    |
| COMMENT             | VARCHAR2(4096) | YES  | 検証タスク失敗の原因の説明      |

## クエリ例

ユーザーテナントが自身が開始したJobレベルのバックアップ検証タスクに関する情報を確認します。

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOBS\G
```
