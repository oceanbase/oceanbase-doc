# DBA_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TRANSFER_PARTITION_TASK_HISTORY`は、このテナントで実行されたパーティション転送タスクの履歴を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | NUMBER(38)   | NO   |  Transfer Partitionタスクの一意識別子   |
| CREATE_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   |  作成時間   |
| FINISH_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   |  タスク完了時間。成功およびキャンセルを含む   |
| TABLE_ID         | NUMBER(38)   | NO   |  Transferのパーティションが存在するテーブルID   |
| OBJECT_ID        | NUMBER(38)   | NO   |  Transferのパーティションの`OBJECT_ID`   |
| DEST_LS          | NUMBER(38)   | NO   |  目的地ログストリーム   |
| BALANCE_JOB_ID   | NUMBER(38)   | NO   |  タスク実行時に関連付けられるロードバランシングジョブID   |
| TRANSFER_TASK_ID | NUMBER(38)   | NO   |  タスク実行時に関連付けられるTransferタスクID   |
| STATUS           | VARCHAR2(64) | NO   |  タスクステータス：<ul><li>COMPLETED：タスク実行成功</li><li>FAILED:  タスク失敗</li></ul>   |
| COMMENT          | CLOB         | YES  |  コメント情報   |

## クエリ例

このテナントで実行されたTransfer Partitionタスクの履歴を確認します。

```shell
obclient> SELECT * FROM SYS.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY;
```
