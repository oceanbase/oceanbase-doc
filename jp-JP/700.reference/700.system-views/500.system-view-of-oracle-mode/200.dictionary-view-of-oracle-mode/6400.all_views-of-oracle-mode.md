# ALL_VIEWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なビューを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## クエリ例

現在のユーザーがアクセス可能なすべてのビューのうち、ビュー `VIEW2` の情報を確認します。

```shell
obclient [SYS]> SELECT OWNER, VIEW_NAME, TEXT_LENGTH, TEXT FROM SYS.DBA_VIEWS WHERE VIEW_NAME='VIEW2';
```

クエリ結果は次のとおりです：

```shell
+-------+-----------+-------------+--------------------------------------------+
| OWNER | VIEW_NAME | TEXT_LENGTH | TEXT                                       |
+-------+-----------+-------------+--------------------------------------------+
| SYS   | VIEW2     |          42 | SELECT "A","B" FROM tbl2 WHERE tbl2.b > 1  |
+-------+-----------+-------------+--------------------------------------------+
1 row in set
```
