# USER_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在コミットされているタスクの概要を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|  **フィールド名**   |     **型**     | **NULL許容** |                                                                  **説明**                                                                   |
|-------------|----------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| JOB         | NUMBER(38)     | NO             | タスク識別子。インポート、エクスポート、または再実行によってもこのパラメータの値は変更されません。                            |
| LOG_USER    | VARCHAR2(128)  | NO             | タスクをコミットした際のログインユーザー。                                            |
| PRIV_USER   | VARCHAR2(128)  | NO             | このタスクに適用されるデフォルト権限を持つユーザー。                                         |
| SCHEMA_USER | VARCHAR2(128)  | NO             | タスクを解析するデフォルトのSchemaユーザー。                                     |
| LAST_DATE   | DATE           | YES            | このタスクが最後に正常に実行された日付。                                          |
| LAST_SEC    | VARCHAR2(32)   | YES            | このタスクが最後に正常に実行された開始時刻。                                        |
| THIS_DATE   | DATE           | YES            | このタスクの開始実行日。                                            |
| THIS_SEC    | VARCHAR2(32)   | YES            | このタスクが正常に実行された開始時刻。                                          |
| NEXT_DATE   | DATE           | NO             | このタスクの次回実行日。                                            |
| NEXT_SEC    | VARCHAR2(32)   | YES            | このタスクの次回実行開始時刻。                                          |
| TOTAL_TIME  | NUMBER         | YES            | このタスクが初めて実行されて以来、システムがこのタスクに費やした合計クロック時間（秒単位）。この値は累積されます。             |
| BROKEN      | VARCHAR2(1)    | YES            | このタスクを実行するかどうか：<ul><li>`N`：このタスクを実行しない   </li><li> `Y`：このタスクを実行する </li></ul>   |
| INTERVAL    | VARCHAR2(200)  | NO             | 日付関数。このタスクの開始実行時刻から次回実行開始時刻までの時間間隔を記録します。                      |
| FAILURES    | NUMBER(38)     | YES            | このタスクが最後に正常に実行されて以来の成功と失敗の回数を記録します。                                |
| WHAT        | VARCHAR2(4000) | YES            | タスク実行の匿名PLブロックの本体。                                       |
| NLS_ENV     | VARCHAR2(4000) | YES            | タスクのNLS環境を記述するセッションパラメータ。                                      |
| MISC_ENV    | NULL           | YES            | このタスクに適用されるその他のセッションパラメータ。                                         |
| INSTANCE    | VARCHAR2(128)  | YES            | タスクを実行可能または実行中のZone。デフォルトは空です。                               |
