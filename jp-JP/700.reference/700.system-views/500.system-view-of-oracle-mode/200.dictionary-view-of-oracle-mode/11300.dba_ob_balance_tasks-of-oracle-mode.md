# DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_BALANCE_TASKS` は、このテナントで現在実行中のロードバランシングタスクを表示します。各テナントでは同時に複数のロードバランシングタスクが実行されている可能性があり、これらのタスクはすべて同一のロードバランシングジョブ（JOB）に属します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | ------- |
| TASK_ID                  | NUMBER(38)                        | NO  | ロードバランシングタスクID |
| CREATE_TIME              | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | 作成時間 |
| MODIFY_TIME              | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | 情報更新時間 |
| TASK_TYPE                | VARCHAR2(64)                      | NO  | タスクタイプ <ul><li>`LS_SPLIT`：ログストリームの分割 </li><li>`LS_ALTER`：ログストリーム属性の変更 </li><li>`LS_MERGE`：ログストリームのメジャーコンパクション </li><li>`LS_TRANSFER`：ログストリームの転送 </li></ul>|
| SRC_LS                   | NUMBER(38)                        | NO  | ソースログストリーム（データソースから生成されるログデータストリーム） |
| DEST_LS                  | NUMBER(38)                        | NO  | デスティネーションログストリーム |
| PART_LIST                | CLOB                              | YES | パーティションリスト。ユーザーテーブルのパーティションとグローバルインデックスのパーティションを含む |
| FINISHED_PART_LIST       | CLOB                              | YES | 現在完了したロードバランシング処理のパーティションリスト |
| PART_COUNT               | NUMBER(38)                        | YES | パーティションリスト内のパーティション数 |
| FINISHED_PART_COUNT      | NUMBER(38)                        | YES | 現在完了したロードバランシング処理のパーティション数 |
| LS_GROUP_ID              | NUMBER(38)                        | NO  | ログストリームグループID |
| STATUS                   | VARCHAR2(64)                      | NO  | タスクステータス <ul><li>`INIT`：タスクの作成 </li><li>`CREATE_LS`：ログストリームの作成 </li><li>`ALTER_LS`：ログストリーム属性の変更 </li><li>`SET_LS_MERGING`：ログストリームのメジャーコンパクション </li> <li>`TRANSFER`：ログストリームの転送</li> <li>`DROP_LS`：ログストリームの削除 </li><li>`COMPLETED`：タスクの実行が成功 </li><li>`CANCELED`：タスクのキャンセル </li></ul>|
| PARENT_LIST              | VARCHAR2(1024)                    | YES | 親タスクリスト |
| CHILD_LIST               | VARCHAR2(1024)                    | YES | 子タスクリスト |
| CURRENT_TRANSFER_TASK_ID | NUMBER(38)                        | NO  | 現在のロードバランシングタスクによってトリガーされたTransferタスクID |
| JOB_ID                   | NUMBER(38)                        | NO  | 現在のタスクが属するJob ID |
| COMMENT                  | CLOB                              | YES | コメント情報 |
| BALANCE_STRATEGIE         | VARCHAR2(64)                      | YES | Balance Taskに対応する均衡戦略：<ul><li>`LS balance by migrate`：移行による均衡 </li><li>`LS balance by alter`：ログストリーム属性の変更による均衡 </li><li>`LS balance by expand`：スケールアップによる均衡 </li><li>`LS balance by shrink`：スケールダウンによる均衡 </li><li>`partition balance`：パーティションによる均衡 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.2.x系では、このフィールドはV4.2.4バージョンから導入されました。V4.3.x系では、このフィールドはV4.3.2バージョンから導入されました。</p></main>

