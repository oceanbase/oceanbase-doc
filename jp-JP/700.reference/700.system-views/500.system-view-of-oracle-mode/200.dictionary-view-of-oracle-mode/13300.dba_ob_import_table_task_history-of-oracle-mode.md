# DBA_OB_IMPORT_TABLE_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下におけるテーブルレベルのテナント間インポートタスクの履歴を表示します。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | VARCHAR2(4096) | NO | ロードバランシングタスクID |
| JOB_ID | NUMBER(38) | NO | タスクID |
| SRC_TENANT_ID | NUMBER(38) | NO | ソーステナントID |
| SRC_TABLESPACE | VARCHAR2(128) | YES | ソーステーブルのTABLESPACE |
| SRC_TABLEGROUP | VARCHAR2(128) | YES | ソーステーブルのTABLEGROUP |
| SRC_DATABASE | VARCHAR2(128) | YES | ソーステーブルのDATABASE |
| SRC_TABLE | VARCHAR2(128) | YES | ソーステーブル名 |
| SRC_PARTITION | VARCHAR2(64) | YES | ソーステーブルのPARTITION名 |
| TARGET_TABLESPACE | VARCHAR2(128) | YES | 重マッピングテーブルスペース名。未重マッピングの場合は空文字を表示 |
| TARGET_TABLEGROUP | VARCHAR2(128) | YES | 重マッピングテーブルグループ名。未重マッピングの場合は空文字を表示 |
| TARGET_DATABASE | VARCHAR2(128) | YES | 重マッピングデータベース名。未重マッピングの場合は空文字を表示 |
| TARGET_TABLE | VARCHAR2(128) | YES | 重名後のテーブル名。未重名の場合は空文字を表示 |
| TABLE_COLUMN | NUMBER(38) | NO | テーブル列数 |
| STATUS | VARCHAR2(64) | NO | タスク状態：<ul><li>`INIT`：テーブルレベルインポートタスク初期化</li> <li>`DOING`：テーブルレベルインポート実行中</li> <li>`FINISH`：インポート終了</li></ul>  |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時のテナント現在時刻 |
| COMPLETION_TIMESTAMP | VARCHAR2(256) | NO | タスク完了時のテナント現在時刻 |
| CUMULATIVE_TS | NUMBER(38) | NO | 累計時間 |
| TOTAL_INDEX_COUNT | NUMBER(38) | NO | 総インデックス数 |
| IMPORTED_INDEX_COUNT | NUMBER(38) | NO | インポート済みインデックス数 |
| FAILED_INDEX_COUNT | NUMBER(38) | NO | インポート失敗したインデックス数 |
| TOTAL_CONSTRAINT_COUNT | NUMBER(38) | NO | 総制約数 |
| IMPORTED_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート済み制約数 |
| FAILED_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート失敗した制約数 |
| TOTAL_REF_CONSTRAINT_COUNT | NUMBER(38) | NO | 総参照制約数 |
| IMPORTED_REF_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート済み参照制約数 |
| FAILED_REF_CONSTRAINT_COUNT | NUMBER(38) | NO | インポート失敗した参照制約数 |
| RESULT | VARCHAR2(64) | YES | タスクの実行結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行されました。</li><li>`FAIL`：インポートタスクが失敗しました。</li></ul> |
| COMMENT | CLOB | YES | 備考 |

## クエリ例

ユーザーテナントが自身のテナント内のテーブルレベルで、テナント間インポートタスクの履歴を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_IMPORT_TABLE_TASK_HISTORY\G
```
