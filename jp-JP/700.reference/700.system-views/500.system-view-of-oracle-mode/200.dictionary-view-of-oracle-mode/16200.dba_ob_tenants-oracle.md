# DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントの基本情報を表示します。

* システムテナントがこのビューをクエリする場合、システムテナント、ユーザーが作成したテナント（ユーザーテナント）、およびMetaテナントを含むすべてのテナントの情報が表示されます。`TENANT_TYPE`列に基づいてテナントタイプを区別できます。
* 通常のテナントがこのビューをクエリする場合、そのテナント自身の情報のみが表示されます。

| SWITCHOVER_EPOCH | NUMBER | NO | SWITCHOVER/FAILOVERの一意の識別子 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0バージョンから導入されました。</p></main> |

| COMPATIBLE | VARCHAR2(65536) | NO | 互換性バージョン<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
