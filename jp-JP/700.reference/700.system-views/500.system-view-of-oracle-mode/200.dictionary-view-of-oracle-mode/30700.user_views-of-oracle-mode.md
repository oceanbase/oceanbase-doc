# USER_VIEWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するビューを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## クエリ例

現在のユーザーが所有するビュー`VIEW1`の情報を確認します。

```shell
obclient [SYS]> SELECT VIEW_NAME, TEXT_LENGTH, TEXT FROM SYS.USER_VIEWS WHERE VIEW_NAME='VIEW1';
```

クエリ結果は次のとおりです：

```shell
+-----------+-------------+-----------------------------+
| VIEW_NAME | TEXT_LENGTH | TEXT                        |
+-----------+-------------+-----------------------------+
| VIEW1     |          27 | SELECT col1, col2 FROM tbl1 |
+-----------+-------------+-----------------------------+
1 row in set
```
