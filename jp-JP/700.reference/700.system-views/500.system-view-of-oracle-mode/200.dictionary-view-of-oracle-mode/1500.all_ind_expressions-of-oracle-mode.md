# ALL_IND_EXPRESSIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能な関数ベースのインデックス情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|     **フィールド名**      |     **型**     | **NULL許容** |        **説明**        |
|-------------------|----------------|----------------|----------------------|
| INDEX_OWNER       | VARCHAR2(128)  | NO             | インデックスの所有者             |
| INDEX_NAME        | VARCHAR2(128)  | NO             | インデックス名                 |
| TABLE_OWNER       | VARCHAR2(128)  | NO             | インデックスが存在するテーブルの所有者            |
| TABLE_NAME        | VARCHAR2(128)  | NO             | インデックスが存在するテーブル名             |
| COLUMN_EXPRESSION | VARCHAR2(1000) | NO             | function-baseインデックスの式 |
| COLUMN_POSITION   | NUMBER(38)     | NO             | 列が存在するインデックス内の位置             |

## クエリ例

現在ユーザーがアクセス可能なすべての関数インデックス情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_IND_EXPRESSIONS;
```

クエリ結果は次のとおりです：

```shell
+-------------+----------------+-------------+------------+-------------------+-----------------+
| INDEX_OWNER | INDEX_NAME     | TABLE_OWNER | TABLE_NAME | COLUMN_EXPRESSION | COLUMN_POSITION |
+-------------+----------------+-------------+------------+-------------------+-----------------+
| SYS         | TBL2_FUNC_IDX1 | SYS         | TBL2_FUNC  | ("C1" + 1)        |               1 |
+-------------+----------------+-------------+------------+-------------------+-----------------+
1 row in set
```
