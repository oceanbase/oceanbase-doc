# USER_SUBPART_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーに属するパーティションテーブル内のサブパーティションの列統計情報とヒストグラム情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|       フィールド名        |    **タイプ**     | **NULL値を許容するか** |                                                           **説明**                                                           |
|-------------------|---------------|----------------|----------------------------------------------------------------------------------------------------------------------------|
| TABLE_NAME        | VARCHAR2(128) | NO             | テーブル名                                      |
| SUBPARTITION_NAME | VARCHAR2(128) | NO             | サブパーティション名                                   |
| COLUMN_NAME       | VARCHAR2(128) | NO             | 列名                                      |
| NUM_DISTINCT      | NUMBER        | YES            | 列内の異なる値の数                                |
| LOW_VALUE         | VARCHAR2(128) | YES            | 列の最小値                                   |
| HIGH_VALUE        | VARCHAR2(128) | YES            | 列の最大値                                   |
| DENSITY           | NUMBER        | YES            | 列の密度                                    |
| NUM_NULLS         | NUMBER        | YES            | 列内の`NULL`値の数                          |
| NUM_BUCKETS       | NUMBER        | YES            | 列ヒストグラムのバケット数                               |
| SAMPLE_SIZE       | NUMBER        | YES            | 分析時のサンプリングサイズ                                |
| LAST_ANALYZED     | DATE          | YES            | 前回の分析日時                                 |
| GLOBAL_STATS      | VARCHAR2(3)   | YES            | <ul><li>`YES`：統計情報が収集されたことを示す </li><li>`NO`：統計情報が収集されていないことを示す </li></ul>   |
| USER_STATS        | VARCHAR2(3)   | YES            | パーティション統計情報がユーザー設定であるかどうかを示す                        |
| NOTES             | VARCHAR2(80)  | YES            | その他の追加属性を記録                               |
| AVG_COL_LEN       | NUMBER        | YES            | 列の平均長                                  |
| HISTOGRAM         | VARCHAR2(15)  | YES            | ヒストグラムのタイプ                                   |
