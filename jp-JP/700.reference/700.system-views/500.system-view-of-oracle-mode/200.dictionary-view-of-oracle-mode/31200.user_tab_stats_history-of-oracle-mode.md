# USER_TAB_STATS_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するすべてのテーブルの統計変更履歴を表示します。

## フィールド説明

|     **フィールド名**      |           **型**            | **NULL許容** |  **説明**   |
|-------------------|-----------------------------|----------------|-----------|
| TABLE_NAME        | VARCHAR2(128)               | NO             | テーブル名        |
| PARTITION_NAME    | VARCHAR2(128)               | YES            | パーティション名      |
| SUBPARTITION_NAME | VARCHAR2(128)               | YES            | サブパーティション名     |
| STATS_UPDATE_TIME | TIMESTAMP(6) WITH TIME ZONE | YES            | 統計情報更新時刻 |

## クエリ例

現在のユーザーが所有するテーブルのうち、テーブル `T_SUBPART` のテーブル統計の変更履歴を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_TAB_STATS_HISTORY WHERE TABLE_NAME='T_SUBPART';
```
