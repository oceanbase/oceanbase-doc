# DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントで現在実行中のロードバランシングジョブを表示します。各テナントは同一時刻に1つのロードバランシングジョブ(JOB)しか実行できません。各ロードバランシングジョブは、ロードバランシングの具体的な操作を実現するために複数のロードバランシングタスク(TASK)を生成します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |

| JOB_ID | NUMBER(38) | NO | ロードバランシングジョブID |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 作成日時 |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 情報更新日時 |
| BALANCE_STRATEGY | VARCHAR2(64) | NO | バランシング戦略名：<ul><li>`LS balance by migrate`：移行によるバランシング  </li><li>`LS balance by alter`：ログストリーム属性変更によるバランシング </li><li>`LS balance by expand`：スケールアウトによるバランシング </li><li>`LS balance by shrink`：スケールインによるバランシング </li><li>`partition balance`：パーティションによるバランシング </li></ul>|
| JOB_TYPE | VARCHAR2(64) | NO | ジョブタイプ  <ul><li>`LS_BALANCE`：ログストリームのバランシング  </li><li>`PARTITION_BALACNE`：パーティションのバランシング </li></ul>|

| TARGET_PRIMARY_ZONE_NUM | NUMBER(38) | NO | 変更対象のプライマリゾーン数 |

| ZONE_UNIT_NUM_LIST      | VARCHAR2(4096) | NO   | テナントの各ゾーンのユニット数 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
| PARAMETER_LIST          | CLOB           | NO   | バランシング関連のパラメータ  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOBS;
```
