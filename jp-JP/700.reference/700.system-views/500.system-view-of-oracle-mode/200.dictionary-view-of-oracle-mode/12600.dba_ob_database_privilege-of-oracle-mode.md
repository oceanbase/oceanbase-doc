# DBA_OB_DATABASE_PRIVILEGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のユーザーを制御するために持っている権限を表示します。

## フィールドの説明

| フィールド名          | 型          | NULL許容 | 説明              |
|-------------------|-----------------------------------|------|-----|
| USER_ID           | NUMBER(38)                        | NO   |   ユーザーID      |
| USERNAME          | VARCHAR2(128)                     | NO   |   ユーザー名      |
| DATABASE_NAME     | VARCHAR2(128)                     | NO   |   現在のユーザー名       |
| GMT_CREATE        | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   |   作成時間       |
| GMT_MODIFIED      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   |   変更時間      |
| PRIV_ALTER        | VARCHAR2(3)                       | NO   |   テーブルを変更する権限があるかどうか       |
| PRIV_CREATE       | VARCHAR2(3)                       | NO   |   テーブルを作成する権限があるかどうか      |
| PRIV_DELETE       | VARCHAR2(3)                       | NO   |   テーブルレコードを削除する権限があるかどうか      |
| PRIV_DROP         | VARCHAR2(3)                       | NO   |   テーブルを削除する権限があるかどうか      |
| PRIV_GRANT_OPTION | VARCHAR2(3)                       | NO   |   権限を委譲する権限があるかどうか      |
| PRIV_INSERT       | VARCHAR2(3)                       | NO   |   レコードを挿入する権限があるかどうか      |
| PRIV_UPDATE       | VARCHAR2(3)                       | NO   |   レコードを更新する権限があるかどうか      |
| PRIV_SELECT       | VARCHAR2(3)                       | NO   |   レコードをクエリする権限があるかどうか      |
| PRIV_INDEX        | VARCHAR2(3)                       | NO   |   テーブルにインデックスを追加する権限があるかどうか      |
| PRIV_CREATE_VIEW  | VARCHAR2(3)                       | NO   |   ビューを作成する権限があるかどうか      |
| PRIV_SHOW_VIEW    | VARCHAR2(3)                       | NO   |   ビューを参照する権限があるかどうか      |
