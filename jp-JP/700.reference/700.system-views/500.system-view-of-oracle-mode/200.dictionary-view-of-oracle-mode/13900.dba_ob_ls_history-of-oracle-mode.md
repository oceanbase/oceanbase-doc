# DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内で過去に存在したログストリームを表示します。

## フィールドの説明

| フィールド    | 型            | NULL許容   | 説明                                                                 |
|-------------|---------------|-------------|-----------------------------------------------------------------------------------------------------------|
| LS_ID       | NUMBER        | NO          |  ログストリームID                                 |
| LS_GROUP_ID | NUMBER        | NO          |  ログストリームグループID                               |
| STATUS      | VARCHAR2(100) | NO          |  ログストリームの現在の状態。<ul><li>CREATING：ログストリームの作成中</li><li>NORMAL：通常のログストリームの状態</li><li>DROPPING：ログストリームが削除されている</li><li>PRE_TENANT_DROPPING：システムログストリームの特殊な状態で、テナント内のすべてのログストリームの削除を開始することを示します</li><li>TENANT_DROPPING：テナントが削除され、ログストリームが削除されている状態</li><li>DROPPED：ログストリームが回収されたか、回収中です。</li><li>WAIT_OFFLINE：ログストリームが回収を待機しています</li><li>CREATE_ABORT：ログストリームの作成が中止されました</li></ul>        |
| FLAG        | VARCHAR2(2048)| NO          |  ログストリームフラグ：<ul><li>NULL：通常のログストリーム</li><li>  DUPLICATE：ユーザーテナントのブロードキャストログストリーム。レプリケーションテーブルはこのログストリーム上に作成されます </li> <li>BLOCK_TABLET_IN：このログストリーム上にTabletを作成できないことを示します</li> <li>DUPLICATE\|BLOCK_TABLET_IN：ブロードキャストログストリームでは現在Tabletの作成が許可されていません</li></ul>                        |
| CREATE_SCN  | NUMBER        | NO          |  ログストリーム作成時のGTS。単位はナノ秒              |

## クエリ例

ユーザーテナントが自身のテナント内で過去に存在したログストリームを照会します。

```sshell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_HISTORY;
```

クエリ結果は次のとおりです：

```shell
+-------+-------------+--------+------+---------------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN          |
+-------+-------------+--------+------+---------------------+
|     1 |           0 | NORMAL | NULL |                   0 |
|  1001 |        1001 | NORMAL | NULL | 1736152507462028000 |
+-------+-------------+--------+------+---------------------+
2 rows in set
```
