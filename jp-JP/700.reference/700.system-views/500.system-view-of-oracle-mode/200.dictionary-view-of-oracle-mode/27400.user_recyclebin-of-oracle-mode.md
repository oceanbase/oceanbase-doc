# USER_RECYCLEBIN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するごみ箱の情報を表示します。列は`DBA_RECYCLEBIN`の列と同じですが、`OWNER`フィールドは除外されています。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|      フィールド名      |      タイプ       | NULL値を許容するか |                                                                 説明                                                                 |
|----------------|---------------|------------|------------------------------------------------------------------------------------------------------------------------------------|
| OBJECT_NAME    | VARCHAR2(128) | NO         | オブジェクトの新しい名前                                          |
| ORIGINAL_NAME  | VARCHAR2(128) | NO         | オブジェクトの元の名前                                         |
| OPERATION      | VARCHAR2(9)   | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
| TYPE           | VARCHAR2(25)  | NO         | オブジェクトタイプ                                            |
| TS_NAME        | VARCHAR2(30)  | NO         | オブジェクトが属するテーブルの名前                                       |
| CREATETIME     | VARCHAR2(19)  | NO         | オブジェクト作成時刻                                         |
| DROPTIME       | VARCHAR2(19)  | NO         | オブジェクトがゴミ箱に移動した時間                                      |
| DROPSCN        | NUMBER        | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
| PARTITION_NAME | VARCHAR2(128) | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
| CAN_UNDROP     | VARCHAR2(3)   | NO         | オブジェクトをゴミ箱から復元できるか：<ul><li> YES   </li><li> NO </li></ul>   |
| CAN_PURGE      | VARCHAR2(3)   | NO         | オブジェクトを削除できるか： <ul><li>YES </li><li>NO </li></ul>        |
| RELATED        | NUMBER        | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
| BASE_OBJECT    | NUMBER        | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
| PURGE_OBJECT   | NUMBER        | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
| SPACE          | NUMBER        | NO         | このフィールドは現在サポートされておらず、デフォルトはNULLです                                |
