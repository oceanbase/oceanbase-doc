# ALL_PART_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なパーティションテーブルのパーティション情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_PART_TABLES WHERE TABLE_NAME='TBL2_F_RL'\G
```
