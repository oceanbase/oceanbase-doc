# DBA_DB_LINKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで作成されたすべてのDBLinkを表示します。

## フィールドの説明

| フィールド | **タイプ** | NULLか | **説明** |
| --- | --- | --- | --- |
| OWNER | VARCHAR2(128) | NO | このDBLinkを作成したユーザー名。 |
| DB_LINK | VARCHAR2(128) | NO | DBLink名。 |
| USERNAME | VARCHAR2(128) | NO | DBLinkがリモートデータベースに接続するためのユーザー名。 |
| CREDENTIAL_NAME | VARCHAR2(128) | NO | リモートデータベースへの接続に使用されるCredentials名。互換性のためにのみ使用されます。 |
| CREDENTIAL_OWNER | VARCHAR2(128) | NO | リモートデータベースへの接続に使用されるCredentialsの所有者。互換性のためにのみ使用されます。 |
| HOST | VARCHAR2(2000) | NO | DBLinkがリモートデータベースに接続するためのホスト名（IPアドレス）。 |
| CREATED | DATE | NO | DBLinkが作成された時間。 |
| HIDDEN | VARCHAR2(3) | NO | 内部使用フィールドで、互換性のためにのみ使用されます。 |
| SHARD_INTERNAL | VARCHAR2(3) | NO | DBLinkが共有接続をサポートしているかどうかを示すために使用されます。これにより、ローカルデータベースとリモートデータベース間の接続数を削減します。互換性のためにのみ使用されます。 |
| VALID | VARCHAR2(3) | NO | DBLinkが利用可能かどうかを示すために使用されます。互換性のためにのみ使用され、デフォルトはYESです。 |
| INTRA_CDB | VARCHAR2(3) | NO | 内部使用フィールドで、互換性のためにのみ使用されます。 |
| TENANT_NAME | VARCHAR2(128) | NO | DBLinkがリモートデータベースに接続するためのテナント名。 |
| REVERSE_TENANT_NAME | VARCHAR2(128) | YES | 反転DBLinkがローカルデータベースに接続するためのテナント名。 |
| CLUSTER_NAME | VARCHAR2(128) | YES | DBLinkがリモートデータベースに接続するためのクラスタ名。 |
| REVERSE_CLUSTER_NAME | VARCHAR2(128) | YES | 反転DBLinkがローカル側のデータベースに接続するためのクラスタ名。 |
| REVERSE_HOST | VARCHAR2(46)   | YES | 反転DBLinkがローカル側のデータベースに接続するためのホスト名（IPアドレス）。 |
| REVERSE_PORT | NUMBER(38)  | YES | 反転DBLinkがローカル側のデータベースに接続するためのポート番号。 |
| REVERSE_USERNAME | VARCHAR2(128) | YES | 反転DBLinkがローカル側のデータベースに接続するためのユーザー名。 |

## クエリ例

ユーザーテナントは、自身のテナント内に作成されたDBLinkを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_DB_LINKS;
```
