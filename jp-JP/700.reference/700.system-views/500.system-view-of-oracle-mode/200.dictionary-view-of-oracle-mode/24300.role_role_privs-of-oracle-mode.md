# ROLE_ROLE_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

他のロールに付与されているロールを記述します。ユーザーがアクセス可能なロールの情報のみを提供します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **型**     | **NULL許容** |       **説明**       |
|--------------|---------------|------------|--------------------|
| ROLE         | VARCHAR2(128) | NO         | ロール名               |
| GRANTED_ROLE | VARCHAR2(128) | NO         | 付与されたロール              |
| ADMIN_OPTION | VARCHAR2(3)   | NO         | このロールにADMINオプションが付与されているかどうか |

## クエリ例

現在ユーザーがアクセス可能なロールのうち、ロール`ROLE1`が付与されているロールを確認します。

```shell
obclient [SYS]> SELECT * FROM ROLE_ROLE_PRIVS WHERE ROLE = 'ROLE1';
```

クエリ結果は次のとおりです：

```shell
+-------+--------------+--------------+
| ROLE  | GRANTED_ROLE | ADMIN_OPTION |
+-------+--------------+--------------+
| ROLE1 | ROLE2        | NO           |
+-------+--------------+--------------+
1 row in set
```
