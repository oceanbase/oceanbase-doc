# DBA_IND_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

データベース内のすべてのテーブルのインデックスに関する列情報を表示します。

<main id="notice" >
<h4>適用対象</h4>
<p>このビューは、OceanBaseデータベースのOracleモードでのみ適用されます。</p>
</main>

## フィールド説明

|      **フィールド名**      |     **型**     | **NULL許容** |            **説明**            |
|--------------------|----------------|----------------|------------------------------|
| INDEX_OWNER        | VARCHAR2(128)  | NO             | インデックスの所有者                     |
| INDEX_NAME         | VARCHAR2(128)  | NO             | インデックス名                         |
| TABLE_OWNER        | VARCHAR2(128)  | NO             | インデックスが存在するテーブルの所有者                   |
| TABLE_NAME         | VARCHAR2(128)  | NO             | インデックスが存在するテーブル名                    |
| COLUMN_NAME        | VARCHAR2(4000) | NO             | インデックス列名                       |
| COLUMN_POSITION    | NUMBER         | NO             | インデックス内の列の位置                   |
| COLUMN_LENGTH      | NUMBER         | NO             | インデックス列の長さ                       |
| CHAR_LENGTH        | NUMBER         | NO             | インデックス列の文字長                     |
| DESCEND            | VARCHAR2(4)    | NO             | インデックス列が降順（DESC）か昇順（ASC）で並べ替えられるかを示す |
| COLLATED_COLUMN_ID | NUMBER         | NO             | 現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています                             |

## クエリ例

このテナント内のインデックステーブル `TBL2` のインデックス列情報を確認します。

```shell
obclient [SYS]> SELECT * FROM DBA_IND_COLUMNS WHERE TABLE_NAME='TBL2';
```

クエリ結果は次のとおりです：

```shell
+-------------+--------------------------------+-------------+------------+-------------+-----------------+---------------+-------------+---------+--------------------+
| INDEX_OWNER | INDEX_NAME                     | TABLE_OWNER | TABLE_NAME | COLUMN_NAME | COLUMN_POSITION | COLUMN_LENGTH | CHAR_LENGTH | DESCEND | COLLATED_COLUMN_ID |
+-------------+--------------------------------+-------------+------------+-------------+-----------------+---------------+-------------+---------+--------------------+
| SYS         | TBL2_OBUNIQUE_1737535889306073 | SYS         | TBL2       | COL1        |               1 |            22 |           0 | ASC     |               NULL |
| SYS         | TBL2_IDX1                      | SYS         | TBL2       | COL2        |               1 |            22 |           0 | ASC     |               NULL |
+-------------+--------------------------------+-------------+------------+-------------+-----------------+---------------+-------------+---------+--------------------+
2 rows in set
```
