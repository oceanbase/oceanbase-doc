# USER_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが提出したタスクの概要を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|  **フィールド名**   |     **タイプ**     | **NULLを許容するか** |                                                                  **説明**                                                                   |
|-------------|----------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| JOB         | NUMBER(38)     | NO             | タスク識別子です。インポート、エクスポート、または再実行によってこのパラメータ値は変更されません。                            |
| LOG_USER    | VARCHAR2(128)  | NO             | タスクの送信時のログインユーザー。                                            |
| PRIV_USER   | VARCHAR2(128)  | NO             | デフォルト権限が適用されるユーザー。                                         |
| SCHEMA_USER | VARCHAR2(128)  | NO             | タスク解析のデフォルトスキーマユーザー。                                     |
| LAST_DATE   | DATE           | YES            | このタスクが最後に正常に実行された日付。                                          |
| LAST_SEC    | VARCHAR2(32)   | YES            | このタスクが最後に正常に実行された開始時間。                                        |
| THIS_DATE   | DATE           | YES            | このタスクの開始実行日。                                            |
| THIS_SEC    | VARCHAR2(32)   | YES            | このタスクの正常実行開始時間。                                          |
| NEXT_DATE   | DATE           | NO             | このタスクの次回実行日。                                            |
| NEXT_SEC    | VARCHAR2(32)   | YES            | このタスクの次回実行開始時間。                                          |
| TOTAL_TIME  | NUMBER         | YES            | このタスクが初めて実行されて以来、システムがこのタスクに費やした合計クロック時間（秒単位）。この値は累積されます。             |
| BROKEN      | VARCHAR2(1)    | YES            | このタスクを実行するかどうか：<ul><li>`N`：このタスクを実行 </li><li>`Y`：このタスクを実行しない </li></ul>   |
| INTERVAL    | VARCHAR2(200)  | NO             | 日付関数。このタスクの開始実行時間から次回実行の開始時間までの時間間隔を記録します。                      |
| FAILURES    | NUMBER(38)     | YES            | このタスクが最後に正常に実行されて以来の成功と失敗の回数を記録します。                                |
| WHAT        | VARCHAR2(4000) | YES            | タスク実行の匿名PLブロックの本体。                                       |
| NLS_ENV     | VARCHAR2(4000) | YES            | タスクのNLS環境を記述するセッションパラメータです。                                      |
| MISC_ENV    | NULL           | YES            | このタスクに適用されるその他のセッションパラメータです。                                         |
| INSTANCE    | VARCHAR2(128)  | YES            | タスクを実行できる、または実行中のゾーン。デフォルトは空です。                               |
