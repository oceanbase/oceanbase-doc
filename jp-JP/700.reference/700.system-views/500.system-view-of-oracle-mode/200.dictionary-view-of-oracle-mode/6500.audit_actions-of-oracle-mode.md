# AUDIT_ACTIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

監査レコード内のアクションIDと対応する名前を記録します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

| **フィールド名** |    **型**     | **NULL許容** |          **説明**          |
|----------|---------------|----------------|--------------------------|
| ACTION   | NUMBER(38)    | NO             | 監査レコード内のAction ID         |
| NAME     | VARCHAR2(128) | NO             | 監査レコード内のAction IDに対応するName |

## クエリ例

監査レコード内のアクションIDと対応する名前を確認し、上位10件を表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.AUDIT_ACTIONS WHERE ROWNUM <=10;
```

クエリ結果は次のとおりです：

```shell
+--------+----------------+
| ACTION | NAME           |
+--------+----------------+
|      0 | UNKNOWN        |
|      1 | CREATE TABLE   |
|      2 | INSERT         |
|      3 | SELECT         |
|      4 | CREATE CLUSTER |
|      5 | ALTER CLUSTER  |
|      6 | UPDATE         |
|      7 | DELETE         |
|      8 | DROP CLUSTER   |
|      9 | CREATE INDEX   |
+--------+----------------+
10 rows in set
```
