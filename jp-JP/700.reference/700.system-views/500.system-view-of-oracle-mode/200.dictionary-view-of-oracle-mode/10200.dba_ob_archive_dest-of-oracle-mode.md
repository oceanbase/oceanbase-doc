# DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのアーカイブパス設定を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DEST_NO | NUMBER(38) | NO | log_archive_dest_nを識別するためのフィールド |
| NAME | VARCHAR2(1024) | NO | フィールド名。以下のフィールドを含みます。<ul><li>`binding`：アーカイブとビジネスの優先モード</li> <li>`dest_id`：アーカイブ宛先のID</li> <li>`path`：アーカイブパス情報</li> <li>`piece_switch_interval`：Pieceの切り替え間隔</li> <li>`state`：アーカイブ宛先の状態</li></ul>  |
| VALUE | VARCHAR2(4096) | NO | `name` フィールドに対応するフィールド値 |

## クエリ例

ユーザーテナントが自身のテナントのアーカイブパス設定を確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_OB_ARCHIVE_DEST;
```

クエリ結果は次のとおりです：

```shell
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
| DEST_NO | NAME                  | VALUE                                                                                                                         |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
|       0 | binding               | OPTIONAL                                                                                                                      |
|       0 | dest_id               | 1004                                                                                                                          |
|       0 | path                  | oss://example_patharchive?host=cn-******.aliyuncs.com&access_id=******&access_key=*****&checksum_type=md5&enable_worm=true    |
|       0 | piece_switch_interval | 1d                                                                                                                            |
|       0 | state                 | ENABLE                                                                                                                        |
+---------+-----------------------+-------------------------------------------------------------------------------------------------------------------------------+
5 rows in set
```
