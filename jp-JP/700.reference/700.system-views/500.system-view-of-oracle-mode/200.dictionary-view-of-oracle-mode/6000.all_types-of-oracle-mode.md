# ALL_TYPES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできるユーザー定義型を一覧表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|     **フィールド名**     |    **タイプ**     | **NULL値を許容するか** |          **説明**           |
|------------------|---------------|----------------|---------------------------|
| OWNER            | VARCHAR2(128) | NO             | オブジェクトが属する所有者                  |
| TYPE_NAME        | VARCHAR2(64)  | NO             | タイプ名                       |
| TYPE_OID         | NUMBER(38)    | NO             | タイプのOID                    |
| TYPECODE         | VARCHAR2(10)  | NO             | オブジェクトを表すタイプ。例：OBJECT、COLLECTIONなど |
| ATTRIBUTES       | NUMBER(38)    | NO             | タイプに含まれる属性数                  |
| METHODS          | NUMBER(38)    | NO             | タイプに含まれるメソッド数                  |
| PREDEFINED       | CHAR(2)       | NO             | システム定義のタイプかどうか                |
| INCOMPLETE       | CHAR(2)       | NO             | 不完全なタイプかどうか。名前のみでメソッドや属性がない場合     |
| FINAL            | CHAR(3)       | NO             | 継承できないかどうか                   |
| INSTANTIABLE     | CHAR(3)       | NO             | インスタンス化可能かどうか                    |
| SUPERTYPE_OWNER  | VARCHAR2(30)  | NO             | 親タイプの所有者                   |
| SUPERTYPE_NAME   | VARCHAR2(30)  | NO             | 親タイプ名                      |
| LOCAL_ATTRIBUTES | NUMBER(38)    | NO             | ローカル属性数                     |
| LOCAL_METHODS    | NUMBER(38)    | NO             | ローカルメソッド数                     |
| TYPEID           | NUMBER(38)    | YES            | タイプID    |
