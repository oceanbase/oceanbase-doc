# DBA_SCHEDULER_JOB_RUN_DETAILS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_SCHEDULER_JOB_RUN_DETAILS` は、現在のテナント内のすべてのスケジューラー・ジョブの情報を表示します。
