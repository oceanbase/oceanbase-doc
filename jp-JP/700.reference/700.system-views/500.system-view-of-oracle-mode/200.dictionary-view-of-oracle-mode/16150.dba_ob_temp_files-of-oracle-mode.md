# DBA_OB_TEMP_FILES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TEMP_FILES`は、一時ファイルに関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | ------------------ | -------- |
| SVR_IP           | VARCHAR2(46)  | NO   | OBServerのIPアドレス     |
| SVR_PORT         | NUMBER(38)   | NO   | OBServerのポート番号     |
| FILE_ID          | NUMBER(38)   | NO   | 一時ファイルのFile ID     |
| TRACE_ID         | VARCHAR2(64)  | NO   | 一時ファイルを開いたときの現在環境のTRACE ID    |
| DIR_ID           | NUMBER(38)   | NO   | 一時ファイルに対応するディレクトリID    |
| BYTES            | NUMBER(38)   | NO   | 一時ファイルのデータサイズ、単位はバイト     |
| START_OFFSET     | NUMBER(38)   | NO   | 一時ファイルの開始バイトオフセット、有効データの開始位置   |
| TOTAL_WRITES     | NUMBER(38)   | NO   | 一時ファイルへの書き込みリクエスト総数    |
| UNALIGNED_WRITES | NUMBER(38)   | NO   | 一時ファイルへの非アライメント書き込みリクエスト総数    |
| TOTAL_READS      | NUMBER(38)   | NO   | 一時ファイルからの読み取りリクエスト総数     |
| UNALIGNED_READS  | NUMBER(38)   | NO   | 一時ファイルからの非アライメント読み取りリクエスト総数    |
| TOTAL_READ_BYTES | NUMBER(38)   | NO   | 一時ファイルからの読み取りリクエストの総サイズ、単位はバイト    |
| LAST_ACCESS_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | 一時ファイルの最終アクセス時間    |
| LAST_MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | 一時ファイルの最終変更時間    |
| BIRTH_TIME       | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | 一時ファイルの作成時間    |

## クエリ例

一時ファイルに関する情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_TEMP_FILES WHERE ROWNUM < 2\G
```
