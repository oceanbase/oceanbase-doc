# USER_IND_PARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するインデックスパーティションの情報を表示します。`ALL_IND_PARTITIONS`や`DBA_IND_PARTITIONS`と比較して、`INDEX_OWNER`フィールドがありません。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>
