# DBA_TAB_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのテーブルに対するオプティマイザー統計情報を表示します。

## フィールドの説明

|           フィールド名            |      タイプ       | **NULL値を許容するか** |                                                               説明                                                               |
|---------------------------|---------------|----------------|--------------------------------------------------------------------------------------------------------------------------------|
| OWNER                     | VARCHAR2(128) | NO             | エンティティが属するユーザー                                     |
| TABLE_NAME                | VARCHAR2(128) | NO             | テーブル名                                          |
| PARTITION_NAME            | VARCHAR2(128) | NO             | パーティション名                                         |
| PARTITION_POSITION        | NUMBER        | NO             | テーブル内のパーティションの位置                                    |
| SUBPARTITION_NAME         | VARCHAR2(128) | NO             | サブパーティション名                                       |
| SUBPARTITION_POSITION     | NUMBER        | NO             | パーティション内のサブパーティションの位置                                 |
| OBJECT_TYPE               | VARCHAR2(12)  | NO             | エンティティタイプ                                        |
| NUM_ROWS                  | NUMBER        | NO            | エンティティ内の行数                                      |
| BLOCKS                    | NUMBER        | NO            | 値は `NULL` となります                                  |
| EMPTY_BLOCKS              | NUMBER        | NO            | 値は `NULL` となります                                  |
| AVG_SPACE                 | NUMBER        | NO            | 値は `NULL` となります                                  |
| CHAIN_CNT                 | NUMBER        | NO            | 値は `NULL` となります                                  |
| AVG_ROW_LEN               | NUMBER        | NO            | エンティティの平均行長                                     |
| AVG_SPACE_FREELIST_BLOCKS | NUMBER        | NO            | 値は `NULL` となります                                  |
| NUM_FREELIST_BLOCKS       | NUMBER        | NO            | 値は `NULL` です                                  |
| AVG_CACHED_BLOCKS         | NUMBER        | NO            | 値は `NULL` です                                  |
| AVG_CACHE_hit_RATIO       | NUMBER        | NO            | 値は `NULL` です                                  |
| IM_IMCU_COUNT             | NUMBER        | NO            | 値は `NULL` です                                  |
| IM_BLOCK_COUNT            | NUMBER        | NO            | 値は `NULL` です                                  |
| IM_STAT_UPDATE_TIME       | TIMESTAMP(9)  | NO            | 値は `NULL` です                                  |
| SCAN_RATE                 | NUMBER        | NO            | 値は `NULL` です                                  |
| SAMPLE_SIZE               | NUMBER        | NO            | 統計情報収集時のサンプリングサイズ                                |
| LAST_ANALYZED             | DATE          | NO            | 前回の分析時間                                     |
| GLOBAL_STATS              | VARCHAR2(3)   | NO            | <ul><li>`YES`：統計情報が直接収集された、または増分メンテナンスされたことを示します </li><li> `NO`：その他の場合 </li></ul>   |
| USER_STATS                | VARCHAR2(3)   | NO            | パーティション統計情報がユーザー設定であるかどうか                              |
| STATTYPE_LOCKED           | VARCHAR2(5)   | NO            | 統計情報のロックタイプ                                    |
| STALE_STATS               | VARCHAR2(3)   | NO            | 統計情報が古いかどうか                                    |
| SCOPE                     | VARCHAR2(7)   | NO            | 統計情報の有効範囲                                   |

## クエリ例

このテナントのすべてのテーブルにおける、テーブル `T_SUBPART` のオプティマイザー統計情報を確認します。

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, OBJECT_TYPE, NUM_ROWS, AVG_ROW_LEN FROM SYS.DBA_TAB_STATISTICS WHERE TABLE_NAME = 'T_SUBPART' ORDER BY 1, 2, 3;
```
