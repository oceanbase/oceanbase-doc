# DBA_OB_TABLEGROUP_PARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.2.0以降のバージョンでは、テーブルグループにパーティションという概念がなくなったため、このビューは使用されなくなりました。ユーザーがこのビューを照会しても、結果は空になります。</li>
<li>V4.2.0以降のバージョンでは、ビュー<a href="14900.dba_ob_tablegroups-of-oracle-mode.md">DBA_OB_TABLEGROUPS</a>を使用してテーブルグループ情報を照会できます。テーブルグループの詳細については、<a href="../../../300.database-object-management/200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md">テーブルグループについて</a>を参照してください。</li>
</ul>
</main>

## 機能の概要

パーティションを持つテーブルグループのパーティション情報を表示します。

## フィールドの説明

|        フィールド名        |       タイプ       | NULLを許容するか |                                                                     説明                                                                      |
|--------------------|----------------|------------|---------------------------|
| TABLEGROUP_NAME    | VARCHAR2(128)  | NO         | TABLEGROUPの名前                                            |
| COMPOSITE          | VARCHAR2(3)    | NO         | パーティションテーブルグループがコンポジットパーティションであるかどうか。値は`YES`または`NO`です                             |
| PARTITION_NAME     | VARCHAR2(64)   | NO         | パーティションテーブルグループのパーティション名                                              |
| SUBPARTITION_COUNT | NUMBER         | NO         | このフィールドの値は`NULL`です                 |
| HIGH_VALUE         | VARCHAR2(4096) | NO         | このフィールドの値は`NULL`です            |
| HIGH_VALUE_LENGTH  | NUMBER         | NO         | このフィールドの値は`NULL`です                              |
| PARTITION_POSITION | NUMBER         | NO         | このフィールドの値は`NULL`です   |
