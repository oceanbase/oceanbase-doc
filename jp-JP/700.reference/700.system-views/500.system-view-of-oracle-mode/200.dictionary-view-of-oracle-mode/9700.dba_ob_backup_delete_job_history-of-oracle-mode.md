# DBA_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内で実行されたバックアップクリーンアップタスクの履歴情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | ジョブID。単調増加します。 |
| INCARNATION | NUMBER(38) | NO | 分身ID。 |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | このJOBを開始したテナントID。 |
| INITIATOR_JOB_ID | NUMBER(38) | NO | このJOBを開始したテナントに属する
JOB_ID |
| EXECUTOR_TENANT_ID | VARCHAR2(65536) | NO | クリーンアップタスクを実行したテナントの一覧 |
| TYPE | VARCHAR2(64) | NO | クリーンアップタイプ：<ul><li>DELETE OBSOLETE BACKUP：期限切れのクリーンアップ</li></ul> |
| PARAMETER | VARCHAR2(1024) | NO | クリーンアップパラメータ。有効期限を記録 |
| JOB_LEVEL | VARCHAR2(64) | NO | タスク開始レベル：<ul><li> `USER_TENANT` : ユーザーテナントが開始したタスク</li><li> `SYS_TENANT` : システムテナントが開始したタスク</li></ul> |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時のテナントの現在時間 |
| END_TIMESTAMP | VARCHAR2(256) | NO | タスク終了時のテナントの現在時間 |
| STATUS | VARCHAR2(64) | NO | タスクのステータス： <ul><li> `INIT` : タスクの初期化段階 </li><li>`DOING`：タスクの実行段階 </li><li>`CANCELING`：タスクがキャンセルされた段階 </li><li> `COMPLETED`：タスクの実行に成功 </li><li>`FAILED`：タスクの実行に失敗 </li><li>`CANCELED`：タスクが正常にキャンセル </li></ul> |
| TASK_COUNT | NUMBER(38) | YES | backup_set/piece のタスク数 |
| SUCCESS_TASK_COUNT | NUMBER(38) | YES | backup_set/piece の実行に成功したタスク数 |
| RESULT | NUMBER(38) | NO | エラーコード |
| COMMENT | VARCHAR2(4096) | YES | タスクの実行説明 |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOB_HISTORY WHERE ROWNUM <= 5\G
```

## 関連するビューまたはドキュメント

* 実行中のバックアップクリーンアップジョブの進捗状況を確認するには、[DBA_OB_BACKUP_DELETE_JOBS](9800.dba_ob_backup_delete_jobs-of-oracle-mode.md)参照してください。

* 実行中のバックアップクリーンアップタスクの進捗状況を確認するには、[DBA_OB_BACKUP_DELETE_TASKS](10100.dba_ob_backup_delete_tasks-of-oracle-mode.md)参照してください。

* バックアップクリーンアップタスクの履歴情報を確認するには、[DBA_OB_BACKUP_DELETE_TASK_HISTORY](10000.dba_ob_backup_delete_task_history-of-oracle-mode.md)参照してください。

* 期限切れバックアップの自動クリーンアップの詳細な操作については、[期限切れバックアップの自動クリーンアップ](../../../../600.manage/600.backup-and-recovery/500.clear-backup-data/100.cleaning-up-backed-up-data-automatically.md)を参照してください。
