# DBA_OB_SOURCE

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>V4.2.x系では、このビューはV4.2.5 BP7バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_SOURCE`は、現在のテナント内のすべてのストレージオブジェクトのソースコード情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
|------------|-------------|---------------------|----------------------------------------|
| OWNER         | VARCHAR2(128)  | NO   | オブジェクト所有者のユーザー名。 |
| TYPE          | VARCHAR2(12)   | NO   | オブジェクトのタイプ。 |
| LINE          | NUMBER(38)     | NO   | ソースコードの行番号で、オブジェクト定義内におけるその行の位置を示します。 |
| TEXT          | VARCHAR2(4000) | NO   | ソースコードのテキストで、その行に対応する実際のコード内容を格納します。 |
| ORIGIN_CON_ID | NUMBER(38)     | NO   | テナントIDで、オブジェクトが属するテナントを識別します。 |

## クエリ例

以下のコマンドを実行して、現在のテナント内のすべてのストレージオブジェクトのソースコード情報を表示し、上位5件のレコードを表示します。

```shell
obclient [oceanbase]>SELECT * FROM DBA_OB_SOURCE WHERE rownum <=5;
```

クエリ結果は次のとおりです：

```shell
+-------+------------+---------+------+--------------------------------------------------------------------+---------------+
| OWNER | NAME       | TYPE    | LINE | TEXT                                                               | ORIGIN_CON_ID |
+-------+------------+---------+------+--------------------------------------------------------------------+---------------+
| SYS   | dbms_stats | PACKAGE |    1 | PACKAGE dbms_stats AUTHID CURRENT_USER                             |             1 |
| SYS   | dbms_stats | PACKAGE |    2 | DECLARE DEFAULT_METHOD_OPT     VARCHAR(1) DEFAULT 'Z';             |             1 |
| SYS   | dbms_stats | PACKAGE |    3 | DECLARE DEFAULT_GRANULARITY    VARCHAR(1) DEFAULT 'Z';             |             1 |
| SYS   | dbms_stats | PACKAGE |    4 | DECLARE AUTO_SAMPLE_SIZE       DECIMAL(20, 10) DEFAULT 0;          |             1 |
| SYS   | dbms_stats | PACKAGE |    5 | DECLARE DEFAULT_STAT_CATEGORY  VARCHAR(20) DEFAULT 'OBJECT_STATS'; |             1 |
+-------+------------+---------+------+--------------------------------------------------------------------+---------------+
```
