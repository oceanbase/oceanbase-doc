# DBA_OB_CS_REPLICA_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このビューはV4.4.0バージョンから導入されました。</li>
<li>V4.3.5系では、このビューはV4.3.5 BP1バージョンから導入されました。</li></ul>
</main>

## 機能の概要

テナント内の各OBServer上にあるCコピーのログストリームにおけるTabletからカラムストアへの変換進捗状況を表示します。

## フィールドの説明

| フィールド名                   | 型          | NULL許容      | 説明                                |
|---------------------------|---------------|---------------------|-------------------------------------|
| SVR_IP                    | VARCHAR2(46)  | NO   | Cコピーが配置されているサーバーのIPアドレス |
| SVR_PORT                  | NUMBER(38)    | NO   | Cコピーが配置されているサーバーのポート番号  |
| LS_ID                     | NUMBER(38)    | NO   | ログストリームID  |
| TOTAL_TABLET_CNT          | NUMBER(38)    | NO   | カラムストア化対象のパーティション数  |
| AVAILABLE_TABLET_CNT      | NUMBER        | NO   | 利用可能なパーティション数    |
| TOTAL_MACRO_BLOCK_CNT     | NUMBER        | NO   | 総ベースラインマクロブロック数（マルチバージョンを除く）  |
| AVAILABLE_MACRO_BLOCK_CNT | NUMBER        | NO   | 利用可能なベースラインマクロブロック数（マルチバージョンを除く）   |
| AVAILABLE                 | VARCHAR2(5)   | NO   | ログストリームの利用可能性：<ul><li>`TRUE`：利用可能。このログストリーム上のすべてのTabletが利用可能な場合に、ログストリームは完全に利用可能となります。</li> <li>`FALSE`：利用不可</li></ul>  |

## クエリ例

ユーザーテナントが、自身のテナント内の各OBServer上にあるCコピーのログストリームにおけるTabletからカラムストアへの変換進捗状況を照会します。

```shell
obclient[SYS]> SELECT * FROM SYS.DBA_OB_CS_REPLICA_STATS;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
| SVR_IP         | SVR_PORT | LS_ID | TOTAL_TABLET_CNT | AVAILABLE_TABLET_CNT | TOTAL_MACRO_BLOCK_CNT | AVAILABLE_MACRO_BLOCK_CNT | AVAILABLE |
+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
| xx.xxx.xxx.212 |    63000 |  1001 |              133 |                  133 |                   875 |                       875 | TRUE      |
+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
1 row in set
```

クエリ結果に基づき、`AVAILABLE_TABLET_CNT / TOTAL_TABLET_CNT`または`AVAILABLE_MACRO_BLOCK_CNT / TOTAL_MACRO_BLOCK_CNT`の値を計算することで、行ストアからカラムストアへの変換進捗状況を大まかに推定できます。
