# DBA_SEQUENCES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のすべてのシーケンスを表示します。

## フィールドの説明

| フィールド名        | 型          | NULL許容 | 説明              |
|----------------|---------------|----------------|-------------------|
| SEQUENCE_OWNER | VARCHAR2(128) | NO   | シーケンスが存在するデータベースの名前   |
| SEQUENCE_NAME  | VARCHAR2(128) | NO   | シーケンス名     |
| MIN_VALUE    | NUMBER(28)    | NO             | シーケンスの取り得る最小値（最小値を含む）   |
| MAX_VALUE    | NUMBER(28)    | NO             | シーケンスの取り得る最大値（最大値を含む）   |
| INCREMENT_BY | NUMBER(28)    | NO             | 毎回の値の増分。正の整数または負の整数を指定できますが、0は指定できません |
| CYCLE_FLAG   | CHAR(1)       | NO             | 値を繰り返し取得できるかどうか                |
| ORDER_FLAG   | CHAR(1)       | NO             | 値の取得がグローバルに順序付けられるかどうか              |
| CACHE_SIZE   | NUMBER(28)    | NO             | 各ノードがキャッシュする値の数              |
| LAST_NUMBER  | NUMBER(38)    | NO             | ノードに割り当て可能な次の値を記録           |

## クエリ例

テナント配下のすべてのシーケンスの詳細情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_SEQUENCES;
```

クエリ結果は次のとおりです：

```shell
+----------------+---------------+-----------+------------------------------+--------------+------------+------------+------------+-------------+
| SEQUENCE_OWNER | SEQUENCE_NAME | MIN_VALUE | MAX_VALUE                    | INCREMENT_BY | CYCLE_FLAG | ORDER_FLAG | CACHE_SIZE | LAST_NUMBER |
+----------------+---------------+-----------+------------------------------+--------------+------------+------------+------------+-------------+
| SYS            | SEQ_T1        |         1 | 9999999999999999999999999999 |            1 | N          | N          |         50 |       10050 |
+----------------+---------------+-----------+------------------------------+--------------+------------+------------+------------+-------------+
1 row in set
```
