# DBA_AUDIT_STATEMENT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`DBA_AUDIT_STATEMENT`は、データベース全体における`GRANT`、`REVOKE`、`AUDIT`、`NOAUDIT`、および`ALTER SYSTEM`ステートメントに関する監査追跡レコードを表示するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## クエリ例

現在のテナント内のすべての `GRANT`、`REVOKE`、`AUDIT`、`NOAUDIT`、および `ALTER SYSTEM` ステートメントに関する監査トレイルエントリを確認します。

```shell
obclient [SYS]> SELECT USERNAME, USERHOST, TIMESTAMP, ACTION_NAME, SQL_TEXT FROM SYS.DBA_AUDIT_STATEMENT;
```

クエリ結果は次のとおりです：

```shell
+----------+----------------+-----------+--------------+---------------------------------+
| USERNAME | USERHOST       | TIMESTAMP | ACTION_NAME  | SQL_TEXT                        |
+----------+----------------+-----------+--------------+---------------------------------+
| SYS      | 100.xx.xxx.xxx | 08-APR-25 | ALTER SYSTEM | SET GLOBAL event_scheduler = ON |
+----------+----------------+-----------+--------------+---------------------------------+
1 row in set
```
