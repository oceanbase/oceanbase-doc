# DBA_OB_SENSITIVE_COLUMNS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下で機密保持ルールによって保護されているすべての列を表示します。

## フィールドの説明

|        フィールド名         |      型       | NULL許容 |                      説明                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| RULE_NAME         | varchar(256)    | NO         | 機密保持ルール名                                           |
| USER_NAME      | varchar(128)    | NO         | ユーザー名                                        |
| TABLE_NAME         | varchar(128)    | NO         | テーブル名                                      |
| COLUMN_NAME        | varchar(128)    | NO         | 列名                                                     |

## クエリ例

現在のテナント配下で機密保持ルールによって保護されているすべての列を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_SENSITIVE_COLUMNS;
```

クエリ結果は次のとおりです：

```shell
+-----------+-----------+------------+-------------+
| RULE_NAME | USER_NAME | TABLE_NAME | COLUMN_NAME |
+-----------+-----------+------------+-------------+
| r1        | u1        | t2         | c           |
| r1        | u1        | t1         | a           |
+-----------+-----------+------------+-------------+
2 row in set
```
