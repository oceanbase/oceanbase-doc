# DBA_OB_RESTORE_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで完了したリカバリタスクを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | 復旧に属するjob_idで、1回の復旧タスクに対応します |
| RESTORE_TENANT_NAME | VARCHAR2(128) | NO | 復旧対象のテナント名 |
| RESTORE_TENANT_ID | NUMBER(38) | NO | 復旧対象のテナントID |
| BACKUP_TENANT_NAME | VARCHAR2(128) | NO | バックアップ元のテナント名 |
| BACKUP_TENANT_ID | NUMBER(38) | NO | バックアップ元のテナントID |
| BACKUP_CLUSTER_NAME | VARCHAR2(128) | NO | バックアップ元のクラスタ名 |
| BACKUP_DEST | CLOB | NO | バックアップセットパス。ユーザーが入力したデータバックアップパスとログアーカイブパスを指します |
| RESTORE_SCN | NUMBER(38) | NO | ユーザー指定の復旧ポイント |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | ユーザー指定の復旧ポイントのタイムスタンプ表記 |
| RESTORE_OPTION      | VARCHAR2(4096) | NO   | 復旧オプション。復旧開始時にユーザーが指定した`restore_option` |
| START_TIMESTAMP        | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | 復旧タスク開始のタイムスタンプ |
| FINISH_TIMESTAMP       | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES  | 復旧タスク終了のタイムスタンプ |
| STATUS                 | VARCHAR2(64) | NO | 復旧結果：<ul> <li>`SUCCESS`：復旧成功を示す </li> <li>`FAILED`：復旧失敗を示す </li></ul>|
| BACKUP_PIECE_LIST | CLOB | NO | 復旧に依存するログアーカイブシャードパスリスト。シャード間は`,`で区切ります。例：`file:///data/nfs/backup/archive/2_1_2,file:///data/nfs/backup/archive/2_1_3` |
| BACKUP_SET_LIST | CLOB | NO | 復旧に依存するデータバックアップセットパスリスト。バックアップセット間は`,`で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc`  |
| BACKUP_CLUSTER_VERSION | NUMBER(38)   | NO   | バックアップ元のクラスタバージョン番号 |
| LS_COUNT               | NUMBER(38)   | NO   | 復旧待機のログストリーム総数 |
| FINISH_LS_COUNT        | NUMBER(38)   | NO   | 復旧完了のログストリーム数 |
| TABLET_COUNT           | NUMBER(38)   | NO   | 復旧待機のシャード総数 |
| FINISH_TABLET_COUNT    | NUMBER(38)   | NO   | 復旧完了のシャード数 |
| TOTAL_BYTES          | NUMBER(38)     | NO   | 復旧総バイト数 |
| TOTAL_BYTES_DISPLAY  | VARCHAR2(42)   | NO   | 復旧総バイト数。ストレージ容量単位で表示 |
| FINISH_BYTES         | NUMBER(38)     | NO   | 復旧完了バイト数。現行バージョンでは、この値は常に0です   |
| FINISH_BYTES_DISPLAY | VARCHAR2(42)   | NO   | 復旧総バイト数。ストレージ容量単位で表示。現行バージョンでは、この値は常に0です   |
| DESCRIPTION          | VARCHAR2(1024) | NO   | 復旧コマンドで指定された`DESCRIPTION`情報 |
| COMMENT              | VARCHAR2(1024) | YES  | 復旧失敗時に失敗情報を記録 |
