# DBA_OB_BACKUP_VALIDATE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</li>
<li>V4.6.xバージョンでは、このビューはV4.6.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_OB_BACKUP_VALIDATE_TASK_HISTORY`は、テナントが開始したタスクレベルのバックアップ検証タスクの実行履歴を表示するために使用されます。各タスクは、1つのバックアップセットまたはログアーカイブピースの検証タスクに対応します。

## フィールドの説明

| フィールド名           | 型          | NULL許容 | 説明           |
| ----------------- | ------------- | -------------- | -------------- |
| TASK_ID           | NUMBER(38)    | NO   | タスクのtask_id     |
| INCARNATION       | NUMBER(38)    | NO   | 分身ID     |
| JOB_ID            | NUMBER(38)    | NO   | タスクのjob_id     |
| TASK_TYPE         | VARCHAR2(64)  | NO   | 検証タスクの種類：<ul><li>`BACKUPSET`：指定されたバックアップセットの検証</li> <li>`ARCHIVELOG_PIECE`：指定されたログアーカイブピースの検証</li></ul>       |
| ID                | NUMBER(38)    | YES  | 検証されたバックアップセットの`backup_set_id`またはアーカイブピースの`piece_id`       |
| PATH              | CLOB          | YES  | 検証されたバックアップパスまたはログアーカイブパス      |
| PATH_TYPE         | VARCHAR2(64)  | YES  | 検証されたパスの種類：<ul><li>`BACKUP_SET_DEST`：データバックアップパス</li> <li>`ARCHIVELOG_PIECE_DEST`：ログアーカイブパス</li></ul>  |
| DEST_ID           | NUMBER(38)    | YES  | 検証されたバックアップパスまたはアーカイブパスのID     |
| PLUS_ARCHIVELOG   | VARCHAR2(64)  | NO   | 補償ログを含むかどうか      |
| INITIATOR_TASK_ID | NUMBER(38)    | NO   | 補償ログ検証タスクの親task_id、それ以外の場合は0     |
| VALIDATE_LEVEL    | VARCHAR2(64)  | NO   | 検証レベル：<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一致性をチェックします。</li></ul>      |
| ROUND_ID          | NUMBER(38)    | NO   | ログアーカイブピースを検証した際のラウンドID、それ以外の場合は0 |
| START_TIMESTAMP   | VARCHAR2(256) | NO   | 検証タスクの開始時間     |
| END_TIMESTAMP     | VARCHAR2(256) | NO   | 検証タスクの終了時間     |
| STATUS            | VARCHAR2(64)  | NO   | タスクの状態：<ul><li>`COMPLETED`：検証タスクが完了しました</li> <li>`FAILED`：検証タスクの実行に失敗しました</li> <li>`CANCELED`：検証タスクがキャンセルされました</li></ul>       |
| TOTAL_LS_COUNT    | NUMBER(38)    | YES  | タスクに含まれるログストリーム数     |
| FINISH_LS_COUNT   | NUMBER(38)    | YES  | 完了した検証のログストリーム数     |
| TOTAL_BYTES       | NUMBER(38)    | YES  | 検証が必要なデータ量の見積もり、単位はバイト     |
| VALIDATED_BYTES   | NUMBER(38)    | YES  | 完了した検証のデータ量、単位はバイト     |
| RESULT            | NUMBER(38)    | NO   | 検証結果のエラーコード情報     |
| COMMENT           | VARCHAR2(4096)| YES  | 検証タスクが失敗した原因の説明      |

## クエリ例

ユーザーテナントは、自身が開始したタスクレベルのバックアップ検証タスクの実行履歴を確認します。

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_TASK_HISTORY\G
```
