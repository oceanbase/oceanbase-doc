# PROXY_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`PROXY_USERS`は、ユーザー間のプロキシ情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL値を許容するか** | **説明**      |
|--------------|-----------|---------------------|---------------|
| PROXY          | VARCHAR2(128) | NO   |プロキシユーザーの名前 |
| CLIENT         | VARCHAR2(128) | NO   |プロキシ対象ユーザーの名前 |
| AUTHENTICATION | VARCHAR2(3)   | NO   |プロキシユーザーがプロキシ対象ユーザーの資格情報を提供する必要があるかどうか：<ul><li>YES：提供が必要</li><li>NO：提供不要</li></ul> |
| FLAGS          | VARCHAR2(35)  | NO   |プロキシに関する追加情報を記録：<ul><li>PROXY MAY ACTIVATE ALL CLIENT ROLES：プロキシユーザーはすべてのクライアントロールを有効化する権限を持つ</li><li>NO CLIENT ROLES MAY BE ACTIVATED：プロキシユーザーはいずれのクライアントロールも有効化できない</li><li>PROXY MAY ACTIVATE ROLE：プロキシユーザーは特定のクライアントロールを有効化する権限を持つ</li><li>PROXY MAY NOT ACTIVATE ROLE：プロキシユーザーはクライアントロールを有効化する権限を持たない</li></ul>現在、PROXY MAY ACTIVATE ALL CLIENT ROLESのみ表示されます |

## クエリ例

ユーザー間のプロキシ情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.PROXY_USERS WHERE ROWNUM = 1;
```

クエリ結果は次のとおりです：

```shell
+-------+--------+----------------+-------------------------------------+
| PROXY | CLIENT | AUTHENTICATION | FLAGS                               |
+-------+--------+----------------+-------------------------------------+
| U1    | U1     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U3    | U2     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U3    | U1     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U4    | U2     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
| U4    | U1     | NO             | PROXY MAY ACTIVATE ALL CLIENT ROLES |
+-------+--------+----------------+-------------------------------------+
```
