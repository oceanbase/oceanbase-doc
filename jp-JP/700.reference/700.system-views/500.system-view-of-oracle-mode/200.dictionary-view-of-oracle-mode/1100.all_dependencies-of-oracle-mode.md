# ALL_DEPENDENCIES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

データベース内のすべてのオブジェクト間の依存関係を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|       **フィールド名**       |    **タイプ**     | **NULL許容** |     **説明**      |
|----------------------|---------------|----------------|-----------------|
| OWNER                | VARCHAR2(128) | NO             | 依存元のOwner名   |
| NAME                 | VARCHAR2(128) | NO             | 依存元の名前          |
| TYPE                 | VARCHAR2(23)  | NO             | 依存元のタイプ          |
| REFERENCED_OWNER     | VARCHAR2(128) | NO             | 依存先のOwner名  |
| REFERENCED_NAME      | VARCHAR2(128) | NO             | 依存先の名前         |
| REFERENCED_TYPE      | VARCHAR2(18)  | NO             | 依存先のタイプ         |
| REFERENCED_LINK_NAME | VARCHAR2(128) | NO             | 依存先のDblink名 |
| DEPENDENCY_TYPE      | VARCHAR2(4)   | NO             | この依存が強い依存かその他の依存かを示す |

## クエリ例

データベース内のすべてのオブジェクト間の依存関係を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_DEPENDENCIES;
```

クエリ結果は次のとおりです：

```shell
+----------+-----------------+----------+------------------+------------------+-----------------+----------------------+-----------------+
| OWNER    | NAME            | TYPE     | REFERENCED_OWNER | REFERENCED_NAME  | REFERENCED_TYPE | REFERENCED_LINK_NAME | DEPENDENCY_TYPE |
+----------+-----------------+----------+------------------+------------------+-----------------+----------------------+-----------------+
| SYS      | VERIFY_FUNCTION | FUNCTION | SYS              | COMPLEXITY_CHECK | FUNCTION        | NULL                 | HARD            |
| __public | VERIFY_FUNCTION | SYNONYM  | SYS              | VERIFY_FUNCTION  | FUNCTION        | NULL                 | HARD            |
+----------+-----------------+----------+------------------+------------------+-----------------+----------------------+-----------------+
2 rows in set
```
