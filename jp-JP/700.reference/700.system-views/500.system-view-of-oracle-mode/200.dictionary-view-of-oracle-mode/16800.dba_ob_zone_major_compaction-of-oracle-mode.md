# DBA_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントの各ゾーンにおけるメジャーコンパクション情報を表示します。

## フィールド説明

|       フィールド名        |      型      | NULL許容    |         説明         |
|-------------------|--------------|------------|----------------------------------------------|
| ZONE              | VARCHAR2(128) | NO         | Zone名            |
| BROADCAST_SCN | NUMBER(38)   | NO         | ブロードキャストされたメジャーコンパクションのバージョン番号           |
| LAST_SCN      | NUMBER(38)   | NO         | 前回のメジャーコンパクションのバージョン番号          |
| LAST_FINISH_TIME  | NUMBER(38)   | NO         | 前回のメジャーコンパクション終了時間          |
| START_TIME        | NUMBER(38)   | NO         | メジャーコンパクション開始時間             |
| STATUS            | VARCHAR2(10)  | NO         | <ul><li> `IDLE`：メジャーコンパクション中ではありません  </li><li>`COMPACTING`：メジャーコンパクション中 </li></ul>    |

## クエリ例

ユーザーテナントが本テナントの各ゾーンにおけるメジャーコンパクション情報を確認します。

```shell
obclient> SELECT * FROM SYS.DBA_OB_ZONE_MAJOR_COMPACTION;
```

クエリ結果は次のとおりです：

```shell
+-------+---------------------+---------------------+------------------+------------------+--------+
| ZONE  | BROADCAST_SCN       | LAST_SCN            | LAST_FINISH_TIME | START_TIME       | STATUS |
+-------+---------------------+---------------------+------------------+------------------+--------+
| zone1 | 1748455200327759000 | 1748455200327759000 | 1748455572486949 | 1748455200370343 | IDLE   |
+-------+---------------------+---------------------+------------------+------------------+--------+
1 row in se
```
