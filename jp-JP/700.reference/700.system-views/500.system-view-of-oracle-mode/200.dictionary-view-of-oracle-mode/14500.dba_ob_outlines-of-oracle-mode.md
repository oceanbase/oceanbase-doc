# DBA_OB_OUTLINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントの実行計画のアウトライン情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | TIMESTAMP(6) | NO | 作成タイムスタンプ |
| MODIFY_TIME | TIMESTAMP(6) | NO | 変更タイムスタンプ |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| DATABASE_ID | NUMBER(38) | NO | データベースID |
| OUTLINE_ID | NUMBER(38) | NO | 実行計画アウトラインID |
| DATABASE_NAME | VARCHAR2(128) | NO | データベース名 |
| OUTLINE_NAME | VARCHAR2(128) | NO | 実行計画アウトライン名 |
| VISIBLE_SIGNATURE | CLOB | NO | Signatureの逆シリアル化結果 |
| SQL_TEXT | CLOB | NO | 実行計画アウトライン作成時にON句で指定されたSQL |
| OUTLINE_TARGET | CLOB | NO | 実行計画アウトライン作成時にTO句で指定されたSQL |
| OUTLINE_SQL | CLOB | NO | 完全な実行計画アウトライン情報を持つSQL |
| SQL_ID | VARCHAR2(32) | NO | SQL識別子 |
| OUTLINE_CONTENT | CLOB | NO | 完全な実行計画アウトライン情報 |
