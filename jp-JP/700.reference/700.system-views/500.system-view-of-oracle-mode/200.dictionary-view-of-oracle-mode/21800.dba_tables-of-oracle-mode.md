## 機能の概要

データベース内のすべてのテーブルを表示します。

```shell

| SYS   | TBL2_F_RL  | VALID  |        0 | N         | NO     | NO           | NO      | NO       |
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
1 row in set
```
