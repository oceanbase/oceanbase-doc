# DBA_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_TRANSFER_PARTITION_TASK_HISTORY` は、テナントで実行されたパーティション転送タスクの履歴を表示します。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | NUMBER(38)   | NO   |  Transfer Partitionタスクの一意の識別子   |
| CREATE_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   |  作成時間   |
| FINISH_TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   |  タスク完了時間。成功・キャンセルを含む   |
| TABLE_ID         | NUMBER(38)   | NO   |  Transfer対象パーティションが存在するテーブルID   |
| OBJECT_ID        | NUMBER(38)   | NO   |  Transfer対象パーティションの`OBJECT_ID`   |
| DEST_LS          | NUMBER(38)   | NO   |  宛先ログストリーム   |
| BALANCE_JOB_ID   | NUMBER(38)   | NO   |  タスク実行時に関連付けられたロードバランシングジョブID   |
| TRANSFER_TASK_ID | NUMBER(38)   | NO   |  タスク実行時に関連付けられたTransferタスクID   |
| STATUS           | VARCHAR2(64) | NO   |  タスク状態：<ul><li>COMPLETED：タスクが正常に実行されました。</li><li>FAILED：タスクが失敗しました。</li></ul>   |
| COMMENT          | CLOB         | YES  |  コメント   |

## クエリ例

```shell
obclient> SELECT * FROM SYS.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY;
```
