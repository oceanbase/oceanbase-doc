# DBA_SYNONYMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのシノニムを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULL値を許容するか** |                     **説明**                      |
|--------------|---------------|----------------|-------------------------------------------------|
| OWNER        | VARCHAR2(128) | NO             | シノニムの所有者                                         |
| SYNONYM_NAME | VARCHAR2(128) | NO             | シノニム名                                           |
| TABLE_OWNER  | VARCHAR2(128) | NO             | シノニムが参照するオブジェクトの所有者                                     |
| TABLE_NAME   | VARCHAR2(128) | NO             | シノニムが参照するオブジェクト名                                      |
| DB_LINK      | VARCHAR2(128) | NO             | 参照対象がDBリンクの場合、そのDBリンク名を示します。現在、シノニムはDBリンクをサポートしていません |

## クエリ例

現在のテナント内のすべてのシノニムを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_SYNONYMS;
```

クエリ結果は次のとおりです：

```shell
+----------+--------------+-------------+------------+---------+
| OWNER    | SYNONYM_NAME | TABLE_OWNER | TABLE_NAME | DB_LINK |
+----------+--------------+-------------+------------+---------+
| __public | SYN_PUB      | SYS         | TEST       | NULL    |
| SYS      | S1           | SYS         | TEST       | NULL    |
+----------+--------------+-------------+------------+---------+
2 rows in set
```
