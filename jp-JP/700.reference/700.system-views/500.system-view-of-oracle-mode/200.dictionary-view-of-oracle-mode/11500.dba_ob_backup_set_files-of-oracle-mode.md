# DBA_OB_BACKUP_SET_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能

テナントのバックアップセットのファイル状態を表示します。

## フィールド説明

| フィールド名                       | フィールド名        | NULL許容 | フィールド説明                         |
|-------------------------------|----------------|-----------------|----------------------------------|
| BACKUP_SET_ID | NUMBER(38) | NO | バックアップセットID |
| DEST_ID | NUMBER(38) | NO | バックアップパスID |
| INCARNATION | NUMBER(38) | NO | Flashback Database後の化身の回数を表す |
| BACKUP_TYPE | VARCHAR2(64) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを表す </li> <li>`INC`：増分バックアップを表す</li></ul> |
| PREV_FULL_BACKUP_SET_ID | NUMBER(38) | NO | 現在のバックアップセットが依存する直前のフルバックアップのBACKUP_SET_ID |
| PREV_inc_BACKUP_SET_ID | NUMBER(38) | NO | 現在のバックアップセットが依存する直前の増分バックアップのBACKUP_SET_ID |
| START_TIMESTAMP | VARCHAR2(256)| NO | バックアップセットの開始タイムスタンプ |
| END_TIMESTAMP | VARCHAR2(256) | NO | バックアップセットの終了タイムスタンプ |
| STATUS | varchar2(64) | NO | バックアップの状態 |
| FILE_STATUS | varchar2(64) | NO | バックアップセットのファイル状態：<ul><li>COPYING：ファイルがバックアップ中であることを表す</li><li>AVAILABLE：このバックアップが有効であることを表す</li><li>DELETING：ファイルが削除中であることを表す</li><li>EXPIRED：バックアップファイルが無効になったことを表す</li><li>INCOMPLETE：バックアップファイルに欠落があることを表す</li><li>BROKEN：バックアップファイルが不完全で使用できないことを表す</li><li>DELETED：バックアップファイルが削除されたことを表す</li></ul> |
| ELAPSED_SECONDES | NUMBER | NO | バックアップにかかった時間 |
| PLUS_ARCHIVELOG | varchar2(4096) | NO | ログの補完があるかどうか |
| START_REPLAY_SCN | NUMBER(38) | NO | バックアップセットが依存するログ再生SCN |
| START_REPLAY_SCN_DISPLAY | TIMESTAMP(9) | NO | バックアップセットが依存するログ再生タイムスタンプポイント |
| MIN_RESTORE_SCN | NUMBER(38)  | NO | バックアップセットで最新に復元可能なSCN |
| MIN_RESTORE_SCN_DISPLAY | VARCHAR2(4096) | NO | バックアップセットで最小に復元可能なタイムスタンプポイント |
| INPUT_BYTES | NUMBER(38) | YES | 入力バイト数 |
| OUTPUT_BYTES | NUMBER(38) | YES | 出力バイト数 |
| OUTPUT_RATE_BYTES | NUMBER | NO | 1秒間の出力バイト数 |
| EXTRA_META_BYTES | NUMBER(38) | YES | 追加バイト数 |
| TABLET_COUNT | NUMBER(38) | YES | バックアップTABLETの総数 |
| FINISH_TABLET_COUNT | NUMBER(38) | YES | バックアップ完了TABLETの総数 |
| MACRO_BLOCK_COUNT | NUMBER(38) | YES | バックアップマクロブロックの総数 |
| FINISH_MACRO_BLOCK_COUNT | NUMBER(38) | YES | バックアップ完了マクロブロックの総数 |
| FILE_COUNT | NUMBER(38) | YES | バックアップファイル数 |
| META_TURN_ID | NUMBER(38) | YES | バックアップMETAのラウンド |
| DATA_TURN_ID | NUMBER(38) | YES | バックアップデータのサイクル番号 |
| RESULT | NUMBER(38) | NO | バックアップエラーコードの結果 |
| COMMENT | varchar2(4096) | YES | バックアップエラーコードの説明 |
| ENCRYPTION_MODE | varchar2(64) | YES | 暗号化モード：<ul><li>None：暗号化しないことを示します。</li><li>Password：パスワードによるみだけの保護を示します。</li><li>Password Encryption：暗号化され、パスワードで保護されます。</li><li>Transparent Encryption：TDEによる暗号化を使用することを示します。</li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用することを示します。</li></ul> </br>現在、NoneとPasswordの2つのモードのみをサポートしています |
| PASSWD | varchar2(128) | YES | パスワード |
| TENANT_COMPATIBLE | varchar2(4096) | NO | テナントのバージョン番号 |
| BACKUP_COMPATIBLE | NUMBER(38) | NO | バックアップセットのバージョン番号 |
| PATH | varchar2(4096) | YES | バックアップパス |
| CLUSTER_VERSION               | varchar(4096)  | NO              | クラスタのバージョン番号 |
| CONSISTENT_SCN                | NUMBER(38)          | NO         | バックアップの一貫性のある時点      |
| MINOR_TURN_ID                 | NUMBER(38)          | NO         | ダンプデータバックアップ終了のサイクル      |
| MAJOR_TURN_ID                 | NUMBER(38)          | NO         | ベースラインデータバックアップ終了のサイクル      |
