# DBA_WR_SYS_TIME_MODEL

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_WR_SYS_TIME_MODEL`は、テナントのTime Model統計項目のWRデータを表示します。

## フィールドの説明

| **フィールド名** | **型**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| SNAP_ID    | NUMBER(38)  | NO   | スナップID      |
| SVR_IP     | VARCHAR2(46) | NO   | ノードIPアドレス       |
| SVR_PORT   | NUMBER(38)  | NO   | ノードポート番号        |
| STAT_ID    | NUMBER(38)  | NO   | 統計項目ID         |
| STAT_NAME  | VARCHAR2(64) | NO   | 統計項目名       |
| VALUE      | NUMBER(38)  | NO   | 統計項目値        |

ビュー内の`STAT_NAME`列の値に含まれる統計イベント名および対応する統計イベントIDは、次の表のとおりです。

| 統計イベント名 | 説明 | 統計イベントID | 統計イベントの種類 |
| ------------|------|------------|----------------|
| DB time                                |  データベースアクティビティの総時間。CPUおよび非アイドル待機時間の累積値を含む  |  200001 |  3072 |
| DB CPU                                 |  データベースアクティビティ中のCPU消費時間                    |  200002 |  3072 |
| background elapsed time                |  バックグラウンドプロセスの実行総時間                           |  200005 |  3072 |
| background cpu time                    |  バックグラウンドプロセスが消費したCPU時間                        |  200006 |  3072 |
| non idle wait time                     |  非アイドル待機時間。セッションが待機状態にあるが、アイドル待機ではない総時間  |  200010 |  3072 |
| idle wait time                         |  アイドル待機時間。セッションがアイドル待機状態にある総時間    |  200011 |  3072 |
| background database time               |  バックグラウンドプロセスによるデータベース操作の実行総時間                   |  200012 |  3072 |
| background database non-idle wait time |  バックグラウンドプロセスが非アイドル待機状態でデータベース操作を実行した時間    |  200013 |  3072 |
| background database idle wait time     |  バックグラウンドプロセスがアイドル待機状態でデータベース操作を実行した時間      |  200014 |  3072 |
| concurrency wait total time            | 並行性問題による待機時間の合計。例：リソースロックによる待機時間 | 220001 |  3072 |
| user io wait total time                | ユーザープロセスがI/O操作（データの読み取りやディスクへの書き込みなど）の完了を待つ総時間 | 220002 |  3072 |
| application wait total time            | ユーザーアプリケーションコードによって発生した待機時間の合計（例：行レベルロックや明示的なロックコマンドによるロック待ち）| 2200013 |  3072 |

## クエリ例

このテナントのTime Model統計項目のWRデータを照会し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_WR_SYS_TIME_MODEL WHERE ROWNUM = 1;
```

照会結果は次のとおりです。

```shell
+---------+----------------+----------+---------+-----------+-------+
| SNAP_ID | SVR_IP         | SVR_PORT | STAT_ID | STAT_NAME | VALUE |
+---------+----------------+----------+---------+-----------+-------+
|       1 | 172.xx.xxx.xxx |     2882 |  200001 | DB time   | 31910 |
+---------+----------------+----------+---------+-----------+-------+
1 row in set
```
