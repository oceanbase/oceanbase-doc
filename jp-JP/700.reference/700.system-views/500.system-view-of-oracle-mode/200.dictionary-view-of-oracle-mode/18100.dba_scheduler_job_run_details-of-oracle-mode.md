# DBA_SCHEDULER_JOB_RUN_DETAILS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのスケジューラー作業に関する情報を表示します。

| OWNER             | VARCHAR2(128)                     | NO   | ジョブの所有者。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.4バージョンから導入されました。</p></main>|
