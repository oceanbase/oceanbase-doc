# DBA_OB_RECOVER_TABLE_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのテーブルレベル復元タスクに関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| JOB_ID | NUMBER(38) | NO | タスクID |
| INITIATOR_TENANT_ID | NUMBER(38) | NO | 親タスクのテナントID |
| INITIATOR_JOB_ID | NUMBER(38) | NO | 親タスクが属するJOB ID |
| START_TIMESTAMP | VARCHAR2(256) | NO | タスク開始時のテナントの現在時刻 |
| FINISH_TIMESTAMP | VARCHAR2(256) | NO | タスク完了時のテナントの現在時刻 |
| STATUS | VARCHAR2(64) | NO | タスクの状態。<ul><li>PREPARE：タスク初期化段階  </li><li>RECOVERING：復元中 </li><li>RESTORE_AUX_TENANT：復元補助テナント </li><li>PRECHECK_IMPORT：インポート前チェック </li><li>GEN_IMPORT_JOB：インポートタスク初期化 </li><li>IMPORTING：テーブルインポート中 </li><li> CANCELING：タスクキャンセル中</li><li>COMPLETED：タスク完了 </li><li>FAILED：タスク失敗 </li></ul> |
| AUX_TENANT_NAME | VARCHAR2(64) | NO | 補助テナント名 |
| TARGET_TENANT_NAME | VARCHAR2(64) | NO | 対象テナント名 |
| IMPORT_ALL | NUMBER(38) | NO | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが `RECOVER TABLE *.*` を指定した場合のみ、この値は1となり、他のシナリオでは値は0となります |
| DB_LIST | CLOB | YES | 完全に復元するデータベース |
| TABLE_LIST | CLOB | YES | 復元するテーブル |
| RESTORE_SCN | NUMBER(38) | NO | ユーザーが指定した復元ポイント |
| RESTORE_SCN_DISPLAY | TIMESTAMP(9) | NO | ユーザーが指定した復元ポイントのタイムスタンプ表現 |
| RESTORE_OPTION | VARCHAR2(4096) | NO | 補助テナントが依存するrestore_optionパラメータ |
| BACKUP_DEST | VARCHAR2(4096) | NO | バックアップおよびアーカイブパス |
| BACKUP_SET_LIST | CLOB | NO | データバックアップパス |
| BACKUP_PIECE_LIST | CLOB | NO | ログアーカイブパス |
| BACKUP_PASSWD | VARCHAR2(4096) | YES | バックアップセットのパスワード |
| EXTERNAL_KMS_INFO | VARCHAR2(4096) | YES | ソーステナントで秘密鍵のホスティングが設定されている場合、セッションでこのパラメータを設定する必要があります。 |
| REMAP_DB_LIST | CLOB | YES | 名前を変更するデータベース。形式は次のとおりです：db1:new_db1, db2:newdb2 |
| REMAP_TABLE_LIST | CLOB | YES | 名前を変更するテーブル。形式は次のとおりです：db1.t1:new_t1, db1.t2:db2.new_t2 |
| REMAP_TABLEGROUP_LIST | CLOB | YES | テーブルグループの再マッピングリスト。テーブルを元のテーブルグループから対象テーブルグループに再マッピングできます。形式は次のとおりです：tg1:new_tg1, tg2:new_tg2 |
| REMAP_TABLESPACE_LIST | CLOB | YES | テーブルスペースの再マッピングリスト。テーブルを元のテーブルスペースから対象テーブルスペースに再マッピングできます。形式は次のとおりです：ts1:new_ts1, ts2:new_ts2 |
| RESULT | VARCHAR2(64) | YES | テーブルレベル復元タスクの結果：<ul><li>SUCCESS  </li><li>FAIL </li></ul> |
| COMMENT | CLOB | YES | 備考 |
| DESCRIPTION | CLOB | YES | 復元コマンドで指定されたDESCRIPTION情報 |
