# DBA_OB_LS_REPLICA_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `DBA_OB_LS_REPLICA_TASK_HISTORY` は、すべてのテナントのディザスタリカバリタスクの実行履歴を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| TASK_TYPE | VARCHAR2(64) | NO | タスクタイプ。値は以下のとおりです。<ul><li>`MIGRATE REPLICA`：レプリカの移行</li><li>`ADD REPLICA`：レプリカの追加</li><li>`TYPE TRANSFORM`：レプリカタイプの変換</li><li>`REMOVE PAXOS REPLICA`：Paxosメンバーレプリカの削除</li><li>`REMOVE NON PAXOS REPLICA`：非Paxosメンバーレプリカの削除</li><li>`MODIFY PAXOS REPLICA NUMBER`：法定レプリカ数の変更</li></ul>|
| TASK_ID | VARCHAR2(200) | NO | タスクID |
| TASK_STATUS | VARCHAR2(2048) | YES | タスクの状態。値は以下のとおりです。<ul><li>`INPROGRESS`：スケジュール実行中</li><li>`COMPLETED`：タスク完了</li><li>`CANCELED` ：タスクキャンセル</li></ul>|
| PRIORITY | CHAR(5) | NO | タスクの優先順位。値は以下のとおりです：<ul><li>`LOW`：低優先順位のタスク</li><li>`HIGH`：高優先順位のタスク</li></ul>|
| TARGET_REPLICA_SVR_IP | VARCHAR2(46) | YES | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT | NUMBER(38) | YES | ターゲットレプリカが存在するマシンのポート |
| TARGET_PAXOS_REPLICA_NUMBER | NUMBER(38) | YES | ログストリームのターゲット法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE | VARCHAR2(16) | YES | ターゲットレプリカタイプ |
| SOURCE_REPLICA_SVR_IP | VARCHAR2(46) | YES | ソースレプリカが存在するマシンのIPアドレス |
| SOURCE_REPLICA_SVR_PORT | NUMBER(38) | YES | ソースレプリカが存在するマシンのポート |
| SOURCE_PAXOS_REPLICA_NUMBER | NUMBER(38) | YES | ログストリームの元法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE | VARCHAR2(16) | YES | ソースレプリカタイプ |
| DATA_SOURCE_SVR_IP | VARCHAR2(46) | YES | データソースのIPアドレス |
| DATA_SOURCE_SVR_PORT | NUMBER(38) | YES | データソースのポート |
| IS_MANUAL | CHAR(6) | NO | 災害復旧タスクの出所。値は以下のとおりです：<ul><li>`TRUE`：手動運用コマンドによってトリガーされた災害復旧タスクを示します</li><li>`FALSE`：デフォルト値で、RS層の災害復旧によって自動生成された災害復旧タスクを示します</li></ul>|
| TASK_EXEC_SVR_IP | VARCHAR2(46) | YES | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT | NUMBER(38) | YES | タスク実行マシンのポート |
| CREATE_TIME | TIMESTAMP(6) | NO | タスク生成時間 |
| START_TIME | TIMESTAMP(6) | NO | タスクスケジュール時間 |
| MODIFY_TIME | TIMESTAMP(6) | NO | タスク状態更新時間 |
| FINISH_TIME | TIMESTAMP(6) | NO | タスク終了時間 |
| EXECUTE_RESULT | VARCHAR2(2048) | YES | タスク実行結果 |
| COMMENT | VARCHAR2(2048) | YES | タスク生成理由の備考 |
| CONFIG_VERSION         | VARCHAR2(128)   | YES                | 災害復旧タスク実行時のclog層のconfig_version情報を記録します <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0バージョンから導入されました。</p></main>  |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_REPLICA_TASK_HISTORY WHERE ROWNUM <= 1\G
```
