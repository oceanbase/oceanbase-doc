# USER_MVREF_STMT_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`USER_MVREF_STMT_STATS`は、リフレッシュステートメントに関連する情報を記述するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_OWNER | VARCHAR2(128) | YES | マテリアライズドビュー所有者名 |
| MV_NAME | VARCHAR2(128) | YES | マテリアライズドビュー名 |
| REFRESH_ID | NUMBER | NO | リフレッシュID |
| RETRY_ID       | NUMBER        | NO   | このリフレッシュステップが属するリトライバッチのIDを表します。 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP2バージョンから導入されました。</p></main>|
| STEP | NUMBER | NO | ステップ番号。1から連続して番号が付けられます |
| SQLID | VARCHAR2(14) | YES | SQL ID |
| STMT | CLOB | NO | SQLテキスト |
| EXECUTION_TIME | NUMBER | NO | SQL実行時間。<ul><li>V4.4.2 BP2以前のバージョンでは、単位は秒です。</li><li>V4.4.2バージョンでは、V4.4.2 BP2バージョンから単位はマイクロ秒です。</li></ul> |
| EXECUTION_PLAN | CLOB | YES | 内部スタッフの問題調査時のみ使用。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| RESULT         | NUMBER        | NO   | このリフレッシュステップの実行結果コードを表します。取り得る値は以下のとおりです：<ul><li>0：実行が成功したことを表します。</li><li>1：実行待ち/実行中を表します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP2バージョンから導入されました。</p></main>|
