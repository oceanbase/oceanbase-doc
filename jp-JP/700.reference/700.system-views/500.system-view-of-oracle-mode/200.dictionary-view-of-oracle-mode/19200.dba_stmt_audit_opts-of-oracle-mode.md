# DBA_STMT_AUDIT_OPTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

ステートメントレベルの監査の詳細な設定を記録します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューは、OceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **タイプ**     | **NULLを許容するか** |             **説明**             |
|--------------|---------------|----------------|--------------------------------|
| USER_NAME    | VARCHAR2(128) | NO             | 監査対象のユーザー名                        |
| PROXY_NAME   | VARCHAR2(128) | NO             | 監査対象のProxyユーザー名。現在、このフィールドの値は常にNULLです |
| AUDIT_OPTION | VARCHAR2(128) | NO             | ステートメントレベル監査のType ID                |
| SUCCESS      | VARCHAR2(10)  | NO             | ステートメント実行成功時の監査モード                   |
| FAILURE      | VARCHAR2(10)  | NO             | ステートメント実行失敗時の監査モード                   |

## クエリ例

ステートメントレベルの監査の詳細な設定を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_STMT_AUDIT_OPTS;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------+----------------+-----------+-----------+
| USER_NAME | PROXY_NAME | AUDIT_OPTION   | SUCCESS   | FAILURE   |
+-----------+------------+----------------+-----------+-----------+
| SYS       | NULL       | TABLE          | BY ACCESS | NOT SET   |
| SYS       | NULL       | ALL STATEMENTS | BY ACCESS | BY ACCESS |
| NULL      | NULL       | SESSION        | BY ACCESS | BY ACCESS |
+-----------+------------+----------------+-----------+-----------+
3 rows in set
```
