# DBA_OB_DEADLOCK_EVENT_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_deadLOCK_EVENT_HISTORY`は、現在のテナントにおけるデッドロックイベントの履歴を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| ------- | ---- | -------------- | ---- |
| EVENT_ID       | NUMBER(38)                        | NO  | デッドロックイベントの番号 |
| SVR_IP         | VARCHAR2(46)                      | NO  | デッドロックイベントに関与したノードのIPアドレス |
| SVR_PORT       | NUMBER(38)                        | NO  | デッドロックイベントに関与したノードのポート番号 |
| DETECTOR_ID    | NUMBER(38)                        | NO  | デッドロックイベントに関与したノードID識別子（プロセス内で一意） |
| REPORT_TIME    | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | デッドロックイベントの報告時間（報告サーバーのタイムスタンプに準ずる） |
| CYCLE_IDX      | NUMBER(38)                        | NO  | そのノードがループ内での番号 |
| CYCLE_SIZE     | NUMBER(38)                        | NO  | デッドロックイベントに関与したノードの数 |
| ROLE           | CLOB                              | NO  | そのノードがデッドロックイベントにおける役割：<ul><li>witness</li><li>victim </li></ul>|
| PRIORITY_LEVEL | CLOB                              | NO  | そのノードの優先度のレベル説明：<ul><li>extreme-low</li><li>low</li><li>normal</li><li>high</li><li>extreme-high </li></ul>|
| PRIORITY       | NUMBER(38)                        | NO  | そのノードが持つ優先度の値。優先度が同じ場合にのみ優先度の値が比較可能となり、ループ内で優先度値が最も低いノードが除外される |
| CREATE_TIME    | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO  | そのノードの作成時間 |
| START_DELAY_US | NUMBER(38)                        | NO  | そのノードが作成されてからデッドロックの検出を開始するまでの許容される間隔時間、単位はマイクロ秒 |
| MODULE         | CLOB                              | NO  | そのノードが存在するモジュール、値は固定でtransaction |
| VISITOR        | CLOB                              | NO  | そのノードが代表するリソースアクセス者、形式は`{session_id:$1}:{txid:$2}`、`$1`と`$2`はどちらも数字 |
| OBJECT         | CLOB                              | NO  | そのノードが取得しようとしているリソース、行の主キー内容の説明、形式は`{addr:“$1:$2”}:{ls:$3}:{tablet:$4}:{row_key:{$5}}`、ここで<ul><li><code>\$1</code> はIPアドレス。 </li><li><code>\$2</code> はPORT。 <code>\$1</code>と共に競合が発生したマシンのプロセスアドレスを構成する。 </li><li><code>\$3</code> は競合が発生した際に存在したログストリーム。 </li><li><code>\$4</code> は競合が発生した際に存在したTablet。 </li><li><code>\$5</code> は行ロックの主キーを文字列化した内容。 </li></ul>  |
| EXTRA_NAME1    | CLOB                              | YES | 上層部がデッドロック報告イベントに追加したい追加情報名1、形式は `wait_sql` |
| EXTRA_VALUE1   | CLOB                              | YES | トランザクションがデッドロックを発生させた現在実行中のSQL内容 |
| EXTRA_NAME2    | CLOB                              | YES | 上層部がデッドロック報告イベントに追加したい追加情報名2、形式は `hold_sql_request_time`  |
| EXTRA_VALUE2   | CLOB                              | YES | ロック保持ステートメントのリクエスト時間 |
| EXTRA_NAME3    | CLOB                              | YES | 上層部がデッドロック報告イベントに追加したい追加情報名3、形式は `hold_sql` |
| EXTRA_VALUE3   | CLOB                              | YES | `cycle_idx - 1`行レコードに対応するObjectを保持するSQLステートメント |

## クエリ例

本テナントのデッドロックイベントの履歴を照会します。

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_DEADLOCK_EVENT_HISTORY;
```
