# ALL_POLICY_CONTEXTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセスできるビューのコンテキスト情報を表示します。ビューにアクセスする際には、コンテキストの値に基づいて対応するポリシーグループが有効になります。

## フィールドの説明

| フィールド | タイプ | NULL値を許容するか | 説明 |
| --- | --- | --- | --- |
| OBJECT_OWNER | VARCHAR2(128) | YES | ポリシーによって制御されるオブジェクトの所有者 |
| OBJECT_NAME | VARCHAR2(128) | YES | ポリシーによって制御されるオブジェクトの名前 |
| NAMESPACE | VARCHAR2(128) | NO | 関連するContextの名前 |
| ATTRIBUTE | VARCHAR2(128) | NO | 関連するContext内のプロパティ名 |
| COMMON | VARCHAR2(3) | NO | 機互運用性のためにのみ使用され、現在の値は常にNOです。 |
| INHERITED | VARCHAR2(3) | NO | 機互運用性のためにのみ使用され、現在の値は常にNOです。 |

## クエリ例

すべてのビューのポリシーグループのコンテキスト情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_POLICY_CONTEXTS;
```

クエリ結果は次のとおりです：

```shell
+--------------+--------------+------------+----------------+--------+-----------+
| OBJECT_OWNER | OBJECT_NAME  | NAMESPACE  | ATTRIBUTE      | COMMON | INHERITED |
+--------------+--------------+------------+----------------+--------+-----------+
| SYS          | V_ORDERS_CTX | REGION_CTX | CURRENT_REGION | NO     | NO        |
| SYS          | V_ORDERS_CTX | DEPT_CTX   | CURRENT_DEPT   | NO     | NO        |
+--------------+--------------+------------+----------------+--------+-----------+
2 rows in set
```
