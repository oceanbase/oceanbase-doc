# DBA_OBJECTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`DBA_OBJECTS` ビューは、データベース内のすべてのデータベースオブジェクトを確認するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

|   フィールド名  |    型  | NULL許容 |     説明 |
|-------------------|---------------|------------|-------------|
| OWNER             | VARCHAR2(128) | NO         | オブジェクトの所有者                                     |
| OBJECT_NAME       | VARCHAR2(128) | NO         | オブジェクト名                                         |
| SUBOBJECT_NAME    | VARCHAR2(128) | NO         | サブオブジェクト名（例：パーティション）                          |
| OBJECT_ID         | NUMBER        | NO         | オブジェクトのディクショナリID値                                   |
| DATA_OBJECT_ID    | NUMBER        | NO         | そのオブジェクトのセグメントを含むディクショナリID値                        |
| OBJECT_TYPE       | VARCHAR2(23)  | NO         | オブジェクトタイプ。テーブル、インデックス、パーティション、パッケージ、ストアドプロシージャ、シノニム、シーケンスなどを含む                |
| CREATED           | DATE          | NO         | オブジェクト作成日時                                       |
| LAST_DDL_TIME     | DATE          | NO         | オブジェクトの最終DDL実行日時                                |
| TIMESTAMP         | VARCHAR2(19)  | NO         | オブジェクト指定のタイムスタンプ。文字列として出力される                             |
| STATUS            | VARCHAR2(7)   | NO         | オブジェクトの状態。<ul><li>VALID：有効</li><li>INVALID：無効</li></ul>   |
| TEMPORARY         | VARCHAR2(1)   | NO         | このオブジェクトが一時オブジェクトであることを示す                                 |
| GENERATED         | VARCHAR2(1)   | NO         | オブジェクト名がシステムによって生成されたかどうかを示す                             |
| SECONDARY         | VARCHAR2(1)   | NO         | 現在このフィールドは未使用                                    |
| NAMESPACE         | NUMBER        | NO         | オブジェクトの名前空間                                      |
| EDITION_NAME      | VARCHAR2(128) | NO         | 予約語フィールド                                         |
| SHARING           | VARCHAR2(18)  | NO         | デフォルト値は`NULL`               |
| EDITIONABLE       | VARCHAR2(1)   | NO         | デフォルト値は`NULL`  |
| ORACLE_MAINTAINED | VARCHAR2(1)   | NO         | デフォルト値は`NULL`                            |
| APPLICATION       | VARCHAR2(1)   | NO         | デフォルト値は`NULL`                        |
| DEFAULT_COLLATION | VARCHAR2(1)   | NO         | デフォルト値は`NULL`            |
| DUPLICATED        | VARCHAR2(1)   | NO         | デフォルト値は `NULL`        |
| SHARDED           | VARCHAR2(1)   | NO         | デフォルト値は `NULL`                             |
| IMPORTED_OBJECT   | VARCHAR2(1)   | NO         | デフォルト値は `NULL`                             |
| CREATED_APPID     | NUMBER    | NO         | デフォルト値は `NULL`     |
| CREATED_VSNID     | NUMBER    | NO         | デフォルト値は `NULL`            |
| MODIFIED_APPID    | NUMBER    | NO         | デフォルト値は `NULL`      |
| MODIFIED_VSNID    | NUMBER    | NO          | デフォルト値は `NULL`        |

