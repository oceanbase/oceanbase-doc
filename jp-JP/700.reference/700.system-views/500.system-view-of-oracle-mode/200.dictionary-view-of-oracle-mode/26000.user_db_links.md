# USER_DB_LINKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーが作成したDBLinkを表示します。

## フィールド説明

| フィールド | **型** | NULL許容 | **説明** |
| --- | --- | --- | --- |
| DB_LINK | VARCHAR2(128)| NO | DBLINK名。|
| USERNAME| VARCHAR2(128)| NO | DBLINKがリモートデータベースに接続するために使用するユーザー名。|
| PASSWORD| VARCHAR2(30)| NO | 空欄。互換性のみを目的としています。|
| CREDENTIAL_NAME| VARCHAR2(128)| NO | リモートデータベースに接続するために使用されるCredentials名。互換性のみを目的としています。|
| CREDENTIAL_OWNER| VARCHAR2(128)| NO | リモートデータベースに接続するために使用されるCredentials所有者。互換性のみを目的としています。 |
| HOST| VARCHAR2(2000)| NO | DBLINKがリモートデータベースに接続するホスト名(IPアドレス)。 |
| CREATED| DATE| NO | DBLINKの作成日時。|
| HIDDEN| VARCHAR2(3)| NO | 内部使用フィールド。互換性のみを目的としています。|
| SHARD_INTERNAL| VARCHAR2(3) | NO | DBLINKが共有接続をサポートするかどうかを示すために使用されます。ローカルデータベースとリモートデータベース間の接続数を削減するために使用されます。互換性のみを目的としています。|
| VALID| VARCHAR2(3)| NO | DBLINKが使用可能かどうかを示すために使用されます。互換性のみを目的としており、デフォルトはYESです。 |
| INTRA_CDB| VARCHAR2(3)| NO | 内部使用フィールド。互換性のみを目的としています。 |
| TENANT_NAME| VARCHAR2(128)| NO | DBLINKがリモートデータベースに接続するために使用するテナント名。 |
| REVERSE_TENANT_NAME| VARCHAR2(128) | YES | ローカルデータベースに接続するための逆DBLINK接続で使用されるテナント名。 |
| CLUSTER_NAME| VARCHAR2(128)| YES | DBLINKがリモートデータベースに接続するために使用するクラスタ名。 |
| REVERSE_CLUSTER_NAME| VARCHAR2(128)| YES | ローカルデータベースに接続するための逆DBLINK接続で使用されるクラスタ名。 |
| REVERSE_HOST| VARCHAR2(46) | YES | ローカルデータベースに接続するための逆DBLINK接続のホスト名(IPアドレス)。 |
| REVERSE_PORT| NUMBER(38) | YES | ローカルデータベースに接続するための逆DBLINK接続のポート番号。 |
| REVERSE_USERNAME| VARCHAR2(128) | YES | ローカルデータベースに接続するための逆DBLINK接続のユーザー名。 |
