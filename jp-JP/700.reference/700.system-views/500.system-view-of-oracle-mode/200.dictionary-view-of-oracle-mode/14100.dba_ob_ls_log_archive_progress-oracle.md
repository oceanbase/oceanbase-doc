# DBA_OB_LS_LOG_ARCHIVE_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントのログストリームアーカイブの進捗状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | 説明 |
| --- | --- | --- | --- |
| DEST_ID | NUMBER(38) | NO | アーカイブ先ID |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| ROUND_ID | NUMBER(38) | NO | ログストリームラウンドID |
| PIECE_ID | NUMBER(38) | NO | 最新Piece ID |
| INCARNATION | NUMBER(38) | NO | 分身ID |
| START_SCN | NUMBER(38) | NO | アーカイブ開始SCN |
| MIN_LSN | NUMBER(38) | NO | 現在のPieceログストリームの最小LSN |
| MAX_LSN | NUMBER(38) | NO | 現在のPieceログストリームの最大LSN |
| CHECKPOINT_SCN | NUMBER(38) | NO | 現在のPieceログストリームの最大アーカイブ進捗 |
| STATUS | VARCHAR2(64) | NO | アーカイブステータス |
| FILE_ID | NUMBER(38) | NO | 現在のPieceの最大アーカイブファイルID |
| FILE_OFFSET | NUMBER(38) | NO | 現在のPieceの最大アーカイブファイルOFFSET |
| INPUT_BYTES | NUMBER(38) | NO | 読み取ったログデータ量、単位はバイト |
| OUTPUT_BYTES | NUMBER(38) | NO | アーカイブされたログデータ量、単位はバイト |

## クエリ例

ユーザーテナントが自身のログストリームアーカイブの進捗状況を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_LS_LOG_ARCHIVE_PROGRESS\G
```
