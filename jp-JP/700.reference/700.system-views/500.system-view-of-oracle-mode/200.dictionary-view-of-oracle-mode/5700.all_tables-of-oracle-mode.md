# ALL_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのテーブルを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## クエリ例

現在のユーザーがアクセス可能なテーブルのうち、テーブル `TBL1` の情報を確認します。

```shell
obclient [SYS]> SELECT OWNER, TABLE_NAME, STATUS, PCT_FREE, TEMPORARY, NESTED, ROW_MOVEMENT, DROPPED, EXTERNAL FROM SYS.ALL_TABLES WHERE TABLE_NAME = 'TBL1';
```

クエリ結果は次のとおりです：

```shell
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
| OWNER | TABLE_NAME | STATUS | PCT_FREE | TEMPORARY | NESTED | ROW_MOVEMENT | DROPPED | EXTERNAL |
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
| SYS   | TBL1       | VALID  |        0 | N         | NO     | NO           | NO      | NO       |
+-------+------------+--------+----------+-----------+--------+--------------+---------+----------+
1 row in set
```
