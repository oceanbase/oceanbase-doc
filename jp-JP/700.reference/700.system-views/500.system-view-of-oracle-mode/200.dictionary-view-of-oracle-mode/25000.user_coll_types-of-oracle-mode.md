# USER_COLL_TYPES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーが所有するカスタムコレクションタイプを一覧表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|      **フィールド名**      |    **タイプ**     | **NULLを許容するか** |   **説明**    |
|--------------------|---------------|----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE_NAME          | VARCHAR2(64)  | NO             | タイプ名         |
| COLL_TYPE          | VARCHAR2(10)  | NO             | コレクションタイプ：<ul><li>VARYING   </li><li> ARRAY   </li><li> NESTED TABLE </li><li> TABLE </li></ul>   |
| UPPER_BOUND        | NUMBER(38)    | YES            | VARYINGに対して、レコードコレクションの最大サイズ                                                                           |
| ELEM_TYPE_MOD      | VARCHAR2(7)   | YES            | 現在このフィールドはサポートされておらず、現在デフォルトでNULLとなります                                                                        |
| ELEM_TYPE_OWNER    | VARCHAR2(128) | YES            | コレクション要素タイプの所有者  |
| ELEM_TYPE_NAME     | VARCHAR2(324) | YES            | コレクション要素タイプ名     |
| LENGTH             | NUMBER(38)    | YES            | コレクション要素タイプの長さ    |
| NUMBER_PRECISION   | NUMBER(38)    | YES            | コレクション要素タイプの精度    |
| SCALE              | NUMBER(38)    | YES            | コレクション要素タイプの小数点以下のデータの長さ                                                                               |
| CHARACTER_SET_NAME | CHAR(7)       | YES            | コレクション要素タイプの文字セット   |
| ELEM_STORAGE       | CHAR(7)       | YES            | 現在このフィールドはサポートされておらず                                                                     |
| NULLS_STORED       | CHAR(7)       | YES            | 現在このフィールドはサポートされておらず                                                              |

## クエリ例

現在のユーザーが所有するカスタムコレクションタイプを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_COLL_TYPES;
```

クエリ結果は次のとおりです：

```shell
+--------------+-----------+-------------+---------------+-----------------+----------------+--------+------------------+-------+--------------------+--------------+--------------+

+--------------+-----------+-------------+---------------+-----------------+----------------+--------+------------------+-------+--------------------+--------------+--------------+
| PROJECT_LIST | TABLE     |          -1 | NULL          | NULL            | VARCHAR2       |    100 |                2 |    -1 | CHAR_CS            | YES          | B            |
+--------------+-----------+-------------+---------------+-----------------+----------------+--------+------------------+-------+--------------------+--------------+--------------+
1 row in set
```
