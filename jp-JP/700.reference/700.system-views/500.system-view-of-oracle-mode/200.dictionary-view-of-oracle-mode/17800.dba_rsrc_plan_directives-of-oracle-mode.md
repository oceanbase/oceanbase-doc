# DBA_RSRC_PLAN_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

`DBA_RSRC_PLAN_DIRECTIVES`ビューは、このテナントの各リソース計画指示の詳細情報を記録するために使用されます。

## クエリ例

ユーザーテナントは、自身のテナントにおける各リソースプラン指示情報を照会します。

```shell
obclient [SYS]> SELECT PLAN, GROUP_OR_SUBPLAN FROM SYS.DBA_RSRC_PLAN_DIRECTIVES;
```

クエリ結果は次のとおりです：

```shell
+--------+------------------+
| PLAN   | GROUP_OR_SUBPLAN |
+--------+------------------+
| PLAN_A | BIG_GROUP        |
+--------+------------------+
1 row in set
```
