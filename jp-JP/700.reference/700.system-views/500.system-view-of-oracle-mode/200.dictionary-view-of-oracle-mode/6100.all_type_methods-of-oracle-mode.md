# ALL_TYPE_METHODS

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースは、このビューをサポートしていません。</p>
  </main>

## 機能の概要

現在ユーザーがアクセス可能なオブジェクトタイプを表示するメソッドです。

## フィールド説明

|   **フィールド名**   |    **型**    | **NULL許容** |                                                                                 **説明**                                                                                  |
|--------------|--------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OWNER        | VARCHAR2(30) | NO             | 型の所有者                                                                               |
| TYPE_NAME    | VARCHAR2(30) | NO             | 型の名前                                                                                |
| METHOD_NAME  | VARCHAR2(30) | NO             | メソッド名                                                                                |
| METHOD_NO    | NUMBER       | NO             | メソッド番号。オーバーロードされたメソッドを区別するために使用されます。                                                                        |
| METHOD_TYPE  | VARCHAR2(6)  | NO             | メソッドタイプ：<ul><li> MAP   </li><li> ORDER   </li><li> PUBLIC </li></ul>   |
| PARAMETERS   | NUMBER       | NO             | メソッドパラメータの数                                                                              |
| RESULTS      | NUMBER       | NO             | メソッドが返す結果の数                                                                            |
| FINAL        | VARCHAR2(3)  | NO             | このメソッドがFINALであるかどうかを示します。<ul><li>YES</li><li>NO</li></ul>       |
| INSTANTIABLE | VARCHAR2(3)  | NO             | このメソッドがインスタンス化可能かどうかを示します。<ul><li>YES</li><li>NO</li></ul>                         |
| OVERRIDING   | VARCHAR2(3)  | NO             | このメソッドがスーパータイプのメソッドをオーバーロードしているかどうかを示します。<ul><li>YES</li><li>NO</li></ul>              |
| INHERITED    | VARCHAR2(3)  | NO             | このメソッドがスーパータイプから継承されているかどうかを示します。<ul><li>YES</li><li>NO</li></ul>                |
