# USER_USERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

`USER_USERS` ビューは、現在のユーザー情報を表示するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースEnterprise Editionでのみ適用されます。</p>
  </main>

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| USERNAME                    | VARCHAR2(128)  | NO   | ユーザー名 |
| USERID                      | NUMBER(38)     | NO   | ユーザーID |
| ACCOUNT_STATUS              | VARCHAR2(32)   | NO   | アカウントのステータス：<ul><li>OPEN：アカウントが有効です。</li><li>EXPIRED：アカウントのパスワードが期限切れになりました。 </li><li>EXPIRED(GRACE)：アカウントのパスワードが期限切れになりましたが、パスワードを変更する期限まで猶予期間があります。 </li><li>LOCKED(TIMED)：連続ログイン失敗回数が制限を超えたため、アカウントがロックされました。 </li><li>LOCKED：アカウントがロックされました。 </li><li>EXPIRED & LOCKED(TIMED)：アカウントのパスワードが期限切れになり、かつ連続ログイン失敗回数が制限を超えたため、アカウントがロックされました。 </li><li>EXPIRED(GRACE) & LOCKED(TIMED)：パスワードが期限切れになり、かつパスワードを変更する期限まで猶予期間があり、さらに連続ログイン失敗回数が制限を超えたため、アカウントがロックされました。 </li><li>EXPIRED & LOCKED：アカウントは現在パスワードの更新期間中です。 </li><li>EXPIRED(GRACE) & LOCKED：パスワードが期限切れになり、かつパスワードを変更する期限まで猶予期間があります。 </li></ul>|
| LOCK_DATE                   | DATE           | NO   | アカウントのステータスがLOCKEDの場合、アカウントがロックされた日付です。 |
| EXPIRY_DATE                 | DATE           | NO   | アカウントの有効期限日 |
| DEFAULT_TABLESPACE          | VARCHAR2(30)   | NO   | データのデフォルトテーブルスペース |
| TEMPORARY_TABLESPACE        | VARCHAR2(30)   | NO   | 一時テーブルのデフォルトテーブルスペース名またはテーブルスペースグループ名 |
| LOCAL_TEMP_TABLESPACE       | VARCHAR2(30)   | NO   | ローカル一時テーブルスペース |
| CREATED                     | DATE           | NO   | ユーザー作成日 |
| INITIAL_RSRC_CONSUMER_GROUP | VARCHAR2(30)   | NO   | ユーザーの初期リソースユーザーグループ |
| EXTERNAL_NAME               | VARCHAR2(4000) | NO   | ユーザーの外部名 |
| PROXY_ONLY_CONNECT          | VARCHAR2(1)    | NO   | プロキシユーザー接続のみ許可するかどうか |
| COMMON                      | VARCHAR2(3)    | NO   | 公共ユーザーかどうか |
| ORACLE_MAINTAINED           | VARCHAR2(1)    | NO   | Oracleモードで提供されるスクリプトによって作成および管理されているかどうか |
| INHERITED                   | VARCHAR2(3)    | NO   | ユーザーが他のコンテナから継承されたかどうか |
| DEFAULT_COLLATION           | VARCHAR2(100)  | NO   | デフォルトの文字セット |
| IMPLICIT                    | VARCHAR2(3)    | NO   | 隠れたアプリケーションによって作成されたユーザーかどうか |
| ALL_SHARD                   | VARCHAR2(3)    | NO   | シャーディングが有効な状態で作成されたかどうか |
| PASSWORD_CHANGE_DATE        | DATE           | YES  | 最終パスワード変更日時 |
