# USER_USERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`USER_USERS`は、現在のユーザー情報を表示するために使用されます。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースEnterprise Editionでのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| USERNAME                    | VARCHAR2(128)  | NO   | ユーザー名 |
| USERID                      | NUMBER(38)     | NO   | ユーザーID |
| ACCOUNT_STATUS              | VARCHAR2(32)   | NO   | アカウント状態：<ul><li>OPEN：アカウントが有効です。</li><li>OPEN & IN ROLLOVER：アカウントは正常ですが、パスワードのローリングオーバー期間中であり、新旧のパスワードどちらも使用可能です。</li><li>EXPIRED：アカウントのパスワードが期限切れです。 </li><li>EXPIRED(GRACE)：アカウントのパスワードが期限切れですが、パスワード変更の期限まではまだ到来していません。 </li><li>LOCKED(TIMED)：連続ログイン失敗回数が制限を超えたため、アカウントがロックされました。 </li><li>LOCKED：アカウントがロックされました。 </li><li>EXPIRED & LOCKED(TIMED)：アカウントのパスワードが期限切れであり、かつ連続ログイン失敗回数が制限を超えたため、アカウントがロックされました。 </li><li>EXPIRED(GRACE) & LOCKED(TIMED)：パスワードが期限切れであり、かつパスワード変更の期限まではまだ到来していないため、アカウントがロックされました。 </li><li>EXPIRED & LOCKED：アカウントは現在パスワード更新期間中です。 </li><li>EXPIRED(GRACE) & LOCKED：パスワードが期限切れであり、かつパスワード変更の期限まではまだ到来していないため、アカウントがロックされました。 </li></ul><main id="notice" type='explain'><h4>説明</h4><p>OPEN & IN ROLLOVER状態はV4.4.2 BP1バージョンからサポートされています。</p></main>|
| LOCK_DATE                   | DATE           | NO   | アカウントがロックされた日付です。 |
| EXPIRY_DATE                 | DATE           | NO   | アカウントの有効期限日です。 |
| DEFAULT_TABLESPACE          | VARCHAR2(30)   | NO   | データのデフォルトテーブルスペースです。 |
| TEMPORARY_TABLESPACE        | VARCHAR2(30)   | NO   | 一時テーブルのデフォルトテーブルスペース名またはテーブルスペースグループ名です。 |
| LOCAL_TEMP_TABLESPACE       | VARCHAR2(30)   | NO   | ローカル一時テーブルスペースです。 |
| CREATED                     | DATE           | NO   | ユーザー作成日です。 |
| INITIAL_RSRC_CONSUMER_GROUP | VARCHAR2(30)   | NO   | ユーザーの初期リソース使用者グループです。 |
| EXTERNAL_NAME               | VARCHAR2(4000) | NO   | ユーザーの外部名です。 |
| PROXY_ONLY_CONNECT          | VARCHAR2(1)    | NO   | プロキシユーザー接続のみ可能かどうかです。 |
| COMMON                      | VARCHAR2(3)    | NO   | 公共ユーザーかどうかです。 |
| ORACLE_MAINTAINED           | VARCHAR2(1)    | NO   | Oracleモードが提供するスクリプトによって作成および管理されているかどうかです。 |
| INHERITED                   | VARCHAR2(3)    | NO   | ユーザーが他のコンテナから継承されたかどうかです。 |
| DEFAULT_COLLATION           | VARCHAR2(100)  | NO   | デフォルトの文字セットです。 |
| IMPLICIT                    | VARCHAR2(3)    | NO   | 隠れたアプリケーションによって作成されたユーザーかどうかです。 |
| ALL_SHARD                   | VARCHAR2(3)    | NO   | シャーディングが有効な状態で作成されたかどうかです。 |
| PASSWORD_CHANGE_DATE        | DATE           | YES  | 最終パスワード変更日です。 |
