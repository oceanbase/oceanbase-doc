# ALL_COL_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

`ALL_COL_PRIVS`ビューは、以下の種類の権限を記述します：

* 現在のユーザーがオブジェクトの所有者、付与者、または被付与者である場合の列オブジェクト権限

* 有効なロールまたは被付与者がPUBLICである場合の列オブジェクト権限

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|  **フィールド名**   |    **タイプ**     | **NULL許容** |    **説明**     |
|-------------|---------------|----------------|---------------|
| GRANTOR     | VARCHAR2(128) | NO             | 権限を付与したユーザー名    |
| GRANTEE     | VARCHAR2(128) | NO             | アクセス権限を付与されたユーザー名 |
| OWNER       | VARCHAR2(128) | NO             | オブジェクトの所有者        |
| TABLE_NAME  | VARCHAR2(256) | NO             | オブジェクト名         |
| COLUMN_NAME | VARCHAR2(128) | NO             | 列名          |
| PRIVILLEGE  | VARCHAR2(40)  | NO             | 列の権限          |
| GRANTABLE   | VARCHAR2(3)   | NO             | 権限付与オプションの使用状況      |
