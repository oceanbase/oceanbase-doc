# ALL_COL_PRIVS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ALL_COL_PRIVSは、以下のタイプの権限を記述します：

* 現在のユーザーがそのオブジェクトの所有者、付与者または被付与者である場合の列オブジェクト権限

* 構成済みロールまたは被付与者がPUBLICである場合の列オブジェクト権限

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースのOracleモードでは、現在列権限機能はサポートされていません。</p>
</main>

## フィールドの説明

|  **フィールド名**   |    **タイプ**     | **NULLを許容するか** |    **説明**     |
|-------------|---------------|----------------|---------------|
| GRANTOR     | VARCHAR2(128) | NO             | 権限付与を実行するユーザーの名前    |
| GRANTEE     | VARCHAR2(128) | NO             | アクセス権限が付与されるユーザーの名前 |
| OWNER       | VARCHAR2(128) | NO             | オブジェクトの所有者        |
| TABLE_NAME  | VARCHAR2(256) | NO             | オブジェクトの名前         |
| COLUMN_NAME | VARCHAR2(128) | NO             | 列の名前          |
| PRIVILLEGE  | VARCHAR2(40)  | NO             | 列の権限          |
| GRANTABLE   | VARCHAR2(3)   | NO             | GRANTで権限を付与できるかどうか      |
