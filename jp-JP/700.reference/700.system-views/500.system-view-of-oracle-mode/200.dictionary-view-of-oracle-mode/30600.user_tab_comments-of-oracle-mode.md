# USER_TAB_COMMENTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30から導入されました。</p>
</main>

## 機能の概要

現在ユーザーが所有するテーブルやビューのコメントを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。s</p>
  </main>

## フィールドの説明

|  **フィールド名**  |     **型**     | **NULL許容** | **説明**  |
|------------|----------------|----------------|---------|
| TABLE_NAME | VARCHAR2(128)  | NO             | テーブルまたはビューの名前 |
| TABLE_TYPE | VARCHAR2(11)   | NO             | オブジェクトタイプ    |
| COMMENTS   | VARCHAR2(4000) | NO             | オブジェクトのコメント    |

## クエリ例

現在ユーザーが所有するすべてのテーブルのうち、テーブル `T1` のコメント情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_TAB_COMMENTS WHERE TABLE_NAME='T1';
```

実行結果は次のとおりです：

```shell
+------------+------------+------------+
| TABLE_NAME | TABLE_TYPE | COMMENTS   |
+------------+------------+------------+
| T1         | TABLE      | test table |
+------------+------------+------------+
1 row in set
```
