# DBA_RSRC_CONSUMER_GROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

本テナント内のすべてのリソースグループ情報を表示するために使用されます。

## フィールドの説明

|       フィールドタイプ        |       型       | NULL許容 |                  説明                  |
|-------------------|----------------|------------|--------------------------------------|
| CONSUMER_GROUP_ID | NUMBER(38)     | NO         | リソースグループID。                              |
| CONSUMER_GROUP    | VARCHAR2(128)  | NO         | ユーザーがバインドされているリソースグループ名。                        |
| CPU_METHOD        | VARCHAR2(128)  | NO         | 互換性のみのために使用され、現在の値は常に `NULL` です。                 |
| MGMT_METHOD       | VARCHAR2(128)  | NO         | 互換性のみのために使用され、現在の値は常に `NULL` です。                 |
| INTERNAL_USE      | VARCHAR2(3)    | NO         | このリソースグループが内部使用専用かどうかを示します。互換性のみのために使用され、現在の値は常に `NULL` です。 |
| COMMENTS          | VARCHAR2(2000) | YES        | リソースグループの備考情報。                           |
| CATEGORY          | VARCHAR2(128)  | NO         | リソースグループのカテゴリ。互換性のみのために使用され、現在の値は常に `NULL` です。          |
| STATUS            | VARCHAR2(128)  | NO         | リソースグループのステータス。互換性のみのために使用され、現在の値は常に `NULL` です。          |
| MANDATORY         | VARCHAR2(3)    | NO         | このリソースグループが必須かどうかを示します。互換性のみのために使用され、現在の値は常に `NULL` です。     |

## クエリ例

ユーザーテナントが本テナント内のすべてのリソースグループ情報を照会します。

```shell
obclient [SYS]> SELECT CONSUMER_GROUP_ID, CONSUMER_GROUP FROM SYS.DBA_RSRC_CONSUMER_GROUPS;
```

クエリ結果は次のとおりです：

```shell
+-------------------+----------------+
| CONSUMER_GROUP_ID | CONSUMER_GROUP |
+-------------------+----------------+
|             10000 | BIG_GROUP      |
|             10001 | SMALL_GROUP    |
+-------------------+----------------+
2 rows in set
```
