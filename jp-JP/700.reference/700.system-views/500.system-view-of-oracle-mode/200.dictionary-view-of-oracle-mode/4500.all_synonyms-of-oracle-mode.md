# ALL_SYNONYMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

現在ユーザーがアクセス可能なすべてのシノニムを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |    **型**     | **NULL許容** |                          **説明**                          |
|--------------|---------------|----------------|----------------------------------------------------------|
| OWNER        | VARCHAR2(128) | NO             | シノニムの所有者                                                  |
| SYNONYM_NAME | VARCHAR2(128) | NO             | シノニム名                                                    |
| TABLE_OWNER  | VARCHAR2(128) | NO             | シノニムが参照するオブジェクト名。ここでのTABLE_NAMEは列名にすぎず、シノニムは他のオブジェクト（ビューなど）のシノニムでもよい |
| TABLE_NAME   | VARCHAR2(128) | NO             | シノニムが参照するオブジェクト名                                               |
| DB_LINK      | VARCHAR2(128) | NO             | データベースリンクを参照している場合は、そのデータベースリンク名を示します                           |

## クエリ例

現在ユーザーがアクセス可能なすべてのシノニムを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_SYNONYMS;
```

クエリ結果は次のとおりです：

```shell
+----------+--------------+-------------+------------+---------+
| OWNER    | SYNONYM_NAME | TABLE_OWNER | TABLE_NAME | DB_LINK |
+----------+--------------+-------------+------------+---------+
| __public | SYN_PUB      | SYS         | TEST       | NULL    |
| SYS      | S1           | SYS         | TEST       | NULL    |
+----------+--------------+-------------+------------+---------+
2 rows in set
```
