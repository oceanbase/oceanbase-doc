# DBA_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_LOB_CHECK_EXCEPTION_RESULT` は、現在のテナント内のLOB整合性チェックで異常が検出されたテーブルとtablet、および異常タイプを表示します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
|--------------|-----------|---------------------|-----------|
| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| CREATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZON | NO | 異常結果の作成時間 |
| UPDATE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZON | NO | 異常結果の変更時間 |
| TABLE_NAME | VARCHAR2(256) | NO | 異常が発生したテーブルの名前 |
| TABLE_ID | NUMBER(38) | NO | 異常が発生したテーブルオブジェクトのID |
| INCONSISTENCY_TYPE | VARCHAR2(16) | NO | 異常タイプ <ul><li>LOB_NOT_FOUND：メインテーブルが存在しないLOBを参照しています</li><li>LOB_LEN_MISMATCH：メタデータの長さと実際の長さが一致しません </li><li>LOB_ORPHANED：LOBは存在しますが、メインテーブルにlocatorがありません</li></ul>  |
| TABLET_IDS | CLOB | NO | 異常が発生したパーティションのID |
| TASK_SCOPE | VARCHAR2(6) | NO | タスクタイプ <ul><li>TENANT: テナントレベルタスク</li><li>LS：LSレベルタスク</li></ul> |
