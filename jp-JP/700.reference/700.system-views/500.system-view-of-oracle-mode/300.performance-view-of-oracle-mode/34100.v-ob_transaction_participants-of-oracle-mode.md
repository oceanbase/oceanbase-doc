# V$OB_TRANSACTION_PARTICIPANTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_TRANSACTION_PARTICIPANTS` は、現在のOBServerノード上のトランザクション参加者のコンテキスト情報を表示するために使用されます。

## フィールドの説明

|       フィールド名       |                型                     | NULL許容   |    説明     |
|------------------|-----------------------------------|------------|-----------|
| TENANT_ID        | NUMBER(38)                        | NO         | テナントID     |
| SVR_IP           | VARCHAR2(46)                      | NO         | サーバーIPアドレス |
| SVR_PORT         | NUMBER(38)                        | NO         | サーバーポート番号    |
| SESSION_ID       | NUMBER(38)                        | NO         | V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョンでは：<br>すべての接続方式(直接接続モード/ODPモード)で、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>      |
| SCHEDULER_ADDR   | VARCHAR2(64)                      | NO         | スケジューラー所属ノードアドレス |
| TX_TYPE          | VARCHAR2(11)                      | NO         | トランザクションタイプ      |
| TX_ID            | NUMBER(38)                        | NO         | トランザクションID      |
| LS_ID            | NUMBER(38)                        | NO         | 所属ログストリームID   |
| PARTICIPANTS     | VARCHAR2(1024)                    | NO         | 参加者リスト     |
| CTX_CREATE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | コンテキスト作成時刻  |
| TX_EXPIRED_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | トランザクションタイムアウト時刻   |
| STATE            | VARCHAR2(9)                       | NO         | コンテキストコミット状態   |
| ACTION           | VARCHAR2(10)                      | NO         | 最後に実行されたアクション  |
| PENDING_LOG_SIZE | NUMBER(38)                        | NO         | 永続化待ちデータサイズ  |
| FLUSHED_LOG_SIZE | NUMBER(38)                        | NO         | 永続化済みデータサイズ  |
| IS_EXITING       | VARCHAR2(3)                       | NO         | 現在終了中かどうか    |
| ROLE             | VARCHAR2(8)                       | NO         | コンテキストロール     |
| COORD             | NUMBER(38)    | NO   | 対応するコーディネーターIS ID（コミット段階に入った場合に有効）    |
| LAST_REQUEST_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE  | NO  | 最後に外部リクエストを受信した時刻    |
| FORMATID          | NUMBER(38)    | NO   | xid形式タイプ    |
| GLOBALID          | VARCHAR2(256)  | NO   | XAトランザクショングローバル識別子    |
| BRANCHID          | VARCHAR2(256)  | NO   | XAトランザクションブランチ限定子    |

## クエリ例

現在のOBServerノード上のトランザクション参加者のコンテキスト情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_TRANSACTION_PARTICIPANTS WHERE ROWNUM =1\G
```
