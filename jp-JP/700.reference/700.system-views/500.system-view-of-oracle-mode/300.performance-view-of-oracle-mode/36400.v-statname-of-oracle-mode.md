# V$STATNAME

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのすべての統計項目の名前を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
|--------------|-------------|---------------------|----------------------------------------|
| CON_ID       | NUMBER       | NO   | テナントID |
| STAT_ID      | NUMBER       | NO   | 統計項目ID |
| STATISTIC#   | NUMBER       | NO   | 統計項目の番号 |
| NAME         | VARCHAR2(64) | NO   | 統計項目名 |
| DISPLAY_NAME | VARCHAR2(64) | NO   | 統計項目名  |
| CLASS        | NUMBER       | NO   | 統計項目のカテゴリ。1つの番号で1種類または複数種類の統計項目を表すことができます。以下の番号は足し合わせることができます：<ul><li>1：NETWORK</li> <li>2：QUEUE</li> <li>4：TRANS</li> <li>8：SQL</li> <li>16：CACHE</li> <li>32：STORAGE</li> <li>64：RESOURCE</li> <li>128：DEBUG</li> <li>256：CLOG</li> <li>512：ELECT</li> <li>1024：OBSERVER</li> <li>2048：RS</li> <li>3072：Time Model</li> <li>4096：TABLEAPI</li> <li>8192：WR</li></ul> |

## クエリ例

このテナントのすべての統計イベントに関する定義を確認し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$STATNAME WHERE ROWNUM = 1;
```

クエリ結果は次のとおりです：

```shell
+--------+---------+------------+---------------+---------------+-------+
| CON_ID | STAT_ID | STATISTIC# | NAME          | DISPLAY_NAME  | CLASS |
+--------+---------+------------+---------------+---------------+-------+
|   1004 |   10000 |          0 | rpc packet in | rpc packet in |     1 |
+--------+---------+------------+---------------+---------------+-------+
1 row in set
```
