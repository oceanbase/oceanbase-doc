# V$OB_COMPACTION_DIAGNOSE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上でのCompactionの診断情報を表示します。

## フィールドの説明

|     フィールド名      |      タイプ      | NULL値を許容するか |                                            説明                                            |
|---------------|--------------|------------|-------------|
| SVR_IP        | VARCHAR2(46) | NO         | サーバーのIPアドレス                                                                                |
| SVR_PORT      | NUMBER(38)   | NO         | サーバーのポート番号|
| TENANT_ID     | NUMBER(38)   | NO         | テナントID |
| TYPE          | VARCHAR2(64) | NO         | コンパクションのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なコンパクションタイプで、指定された時間点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>   |
| LS_ID         | NUMBER(38)   | NO         | ログストリームID|
| TABLET_ID     | NUMBER(38)   | NO         | データシャードID                                                                                  |
| STATUS        | VARCHAR2(15) | NO         | タスクの状態  |
| DIAGNOSE_INFO | VARCHAR2(1024) | NO         | 診断情報  |

## クエリ例

ユーザーテナントが現在のノード上でのCompactionの診断情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_COMPACTION_DIAGNOSE_INFO;
```
