# V$GLOBALCONTEXT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のセッションがアクセス可能なグローバルコンテキストプロパティの`CLIENT_IDENTIFIER`値を表示します。

## フィールドの説明

|       フィールド名        |       型       | **NULL許容** |        説明        |
|-------------------|----------------|----------------|------------------|
| NAMESPACE         | VARCHAR2(128)  | NO             | グローバルにアクセス可能なコンテキストの名前空間    |
| ATTRIBUTE         | VARCHAR2(128)  | NO             | グローバルにアクセス可能なコンテキストのプロパティ      |
| VALUE             | VARCHAR2(4000) | NO             | グローバルにアクセス可能なコンテキストのプロパティ値     |
| USERNAME          | VARCHAR2(128)  | NO             | グローバルにアクセス可能なコンテキスト値に適用されるユーザー名 |
| CLIENT_IDENTIFIER | VARCHAR2(65)   | NO             | グローバルにアクセス可能なコンテキストのクライアント識別子  |
| CON_ID            | NUMBER(38)     | NO             | テナントID            |
