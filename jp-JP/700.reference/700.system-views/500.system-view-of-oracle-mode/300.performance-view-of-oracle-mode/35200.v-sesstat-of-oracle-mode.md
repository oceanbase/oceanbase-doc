# V$SESSTAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$SESSTAT` は、セッションレベルの統計情報を表示するために使用されます。

ここで、`STATISTIC#` は統計項目番号を表し、対応する統計項目番号の統計項目名およびその意味は `V$STATNAME` から照会できます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | NUMBER | NO | V4.3.x系において：<ul><li> V4.3.5 BP2未満のバージョンでは：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> が設定されている場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート番号 |
| STATISTIC# | NUMBER | NO | 統計項目番号 |
| VALUE | NUMBER | NO | 統計値 |

## クエリ例

セッションレベルの統計情報をクエリします。

```shell
obclient [SYS]> SELECT * FROM SYS.V$SESSTAT WHERE ROWNUM =1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SID: 1152921504606867748
    CON_ID: 1004
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
