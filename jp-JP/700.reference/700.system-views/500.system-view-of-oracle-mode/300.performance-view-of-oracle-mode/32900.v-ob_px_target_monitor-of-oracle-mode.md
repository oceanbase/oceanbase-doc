# V$OB_PX_TARGET_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上で使用しているPXスレッドの状況を表示します。

## フィールド説明

|             フィールド名             |      型        | NULL許容   |    説明     |
|------------------------------|--------------|------------|-----------|
| SVR_IP                       | VARCHAR2(46) | NO         | ローカルサーバーのIPアドレス |
| SVR_PORT                     | NUMBER(38)   | NO         | ローカルサーバーのポート番号    |
| TENANT_ID                    | NUMBER(38)   | NO         | テナントID     |
| IS_LEADER                    | CHAR(1)      | NO         | Dummyテーブルのリーダーかどうか          |
| VERSION                      | NUMBER(38)   | NO         | 統計情報の再収集回数         |
| PEER_IP                      | VARCHAR2(46) | NO         | パートナーサーバーのIPアドレス          |
| PEER_PORT                    | NUMBER(38)   | NO         | パートナーサーバーのポート番号         |
| PEER_TARGET                  | NUMBER(38)   | NO         | パートナーサーバーのPXスレッド総数          |
| PEER_TARGET_USED             | NUMBER(38)   | NO         | パートナーサーバーのPXスレッド使用数          |
| LOCAL_TARGET_USED            | NUMBER(38)   | NO         | ローカルサーバーが使用するパートナーPXスレッド数          |
| LOCAL_PARALLEL_SESSION_COUNT | NUMBER(38)   | NO         | ローカルサーバーで並列実行中のセッション数          |

## クエリ例

ユーザーテナント内で、そのテナントの現在のOBServerノード上のPXスレッドの使用状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PX_TARGET_MONITOR;
```

クエリ結果は次のとおりです：

```shell

+----------------+----------+-----------+-----------+-----------------+----------------+-----------+-------------+------------------+-------------------+------------------------------+
| 11.xxx.xxx.xxx |    28825 |      1004 | Y         | 334988734352026 | 11.xxx.xxx.xxx |     28825 |          10 |                0 |                 0 |                            0 |
+----------------+----------+-----------+-----------+-----------------+----------------+-----------+-------------+------------------+-------------------+------------------------------+
1 row in set
```
