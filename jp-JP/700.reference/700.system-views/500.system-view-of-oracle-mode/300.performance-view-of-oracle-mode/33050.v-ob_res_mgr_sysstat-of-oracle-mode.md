# V$OB_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `V$OB_RES_MGR_SYSSTAT` は、テナント内のOBServerにおけるリソースグループの統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| CON_ID     | NUMBER       | NO   | テナントID |
| GROUP_ID   | NUMBER       | NO   | 所属リソースグループID |
| SVR_IP     | VARCHAR2(46) | NO   | ノードIPアドレス |
| SVR_PORT   | NUMBER(38)   | NO   | ノードポート |
| STATISTIC# | NUMBER       | NO   | 統計項目番号 |
| NAME       | VARCHAR2(64) | NO   | 統計項目名 |
| CLASS      | NUMBER       | NO   | 統計項目の種類 |
| VALUE      | NUMBER       | NO   | 統計値 |
| VALUE_TYPE | VARCHAR2(16) | NO   | 値のタイプ：累積型、代入型 |
| STAT_ID    | NUMBER       | NO   | 統計項目ID |

## クエリ例

テナント内のOBServerにおけるリソースグループの統計情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_RES_MGR_SYSSTAT  WHERE ROWNUM < 10;
```
