# GV$SESSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、現在のOBServerノード上でのセッションレベルの統計情報を表示します。ここで、`STATISTIC#` は統計項目の番号を表し、`V$STATNAME` から対応する統計項目の番号に対する統計項目名とその意味を照会できます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| SID | NUMBER | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>このフィールドは、すべての接続方式（直接接続モード/ODPモード）において、サーバーセッションIDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータで <code>client_session_id_version = 2</code> と設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーのポート番号 |
| STATISTIC# | NUMBER | NO | 統計項目番号 |
| VALUE | NUMBER | NO | 統計項目値 |

## クエリ例

ユーザーテナント内で、このテナントのすべてのOBServerノードにおけるセッションレベルの統計イベント情報を確認し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSTAT WHERE ROWNUM <= 10;
```
