# GV$SESSTAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$SESSTAT`は、すべてのサーバー上のセッションレベルの統計情報を表示するために使用されます。

ここで、`STATISTIC#`は統計項目番号を表し、対応する統計項目番号の統計項目名およびその意味は`V$STATNAME`で照会できます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | NUMBER | NO | V4.3.x系について：<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード / ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート番号 |
| STATISTIC# | NUMBER | NO | 統計項目番号 |
| VALUE | NUMBER | NO | 統計項目値 |

## クエリ例

すべてのサーバー上のセッションレベルの統計情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSTAT WHERE ROWNUM =1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SID: 1152921504606867748
    CON_ID: 1004
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
