# V$STATNAME

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`V$STATNAME` ビューは、統計項目の名前を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型**  | **NULL許容** | **説明**                               |
|--------------|-------------|---------------------|----------------------------------------|
| CON_ID       | NUMBER       | NO   | テナントID |
| STAT_ID      | NUMBER       | NO   | 統計項目ID |
| STATISTIC#   | NUMBER       | NO   | 統計項目番号 |
| NAME         | VARCHAR2(64) | NO   | 統計項目名 |
| DISPLAY_NAME | VARCHAR2(64) | NO   | 表示名 |
| CLASS        | NUMBER       | NO   | 統計項目の種類。各統計項目は1つのタイプにのみ該当します。ID:<ul><li>1：NETWORK</li> <li>2：QUEUE</li> <li>4：TRANS</li> <li>8：SQL</li> <li>16：CACHE</li> <li>32：STORAGE</li> <li>64：RESOURCE</li> <li>128：DEBUG</li> <li>256：CLOG</li> <li>512：ELECT</li> <li>1024：OBSERVER</li> <li>2048：RS</li> <li>3072：Time Model</li> <li>4096：TABLEAPI</li> <li>8192：WR</li></ul> |

## クエリ例

テナント内のすべての統計イベントの定義を確認し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$STATNAME WHERE ROWNUM = 1;
```

クエリ結果は次のとおりです：

```shell
+--------+---------+------------+---------------+---------------+-------+
| CON_ID | STAT_ID | STATISTIC# | NAME          | DISPLAY_NAME  | CLASS |
+--------+---------+------------+---------------+---------------+-------+
|   1004 |   10000 |          0 | rpc packet in | rpc packet in |     1 |
+--------+---------+------------+---------------+---------------+-------+
1 row in set
```
