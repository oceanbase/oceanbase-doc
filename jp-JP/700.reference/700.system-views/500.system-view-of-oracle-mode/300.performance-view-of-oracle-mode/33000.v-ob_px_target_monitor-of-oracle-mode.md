# V$OB_PX_TARGET_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、現在のOBServerノード上でのPXスレッドの使用状況を表示します。

## フィールドの説明

|             フィールド名             |      タイプ      | NULL値を許容するか |    説明     |
|------------------------------|--------------|------------|-----------|
| SVR_IP                       | VARCHAR2(46) | NO         | ローカルサーバーのIPアドレス |
| SVR_PORT                     | NUMBER(38)   | NO         | ローカルサーバーのポート番号    |
| TENANT_ID                    | NUMBER(38)   | NO         | テナントID     |
| IS_LEADER                    | CHAR(1)      | NO         | ダミーテーブルのリーダーであるか          |
| VERSION                      | NUMBER(38)   | NO         | 統計情報の再開始回数         |
| PEER_IP                      | VARCHAR2(46) | NO         | ピアサーバーのIPアドレス          |
| PEER_PORT                    | NUMBER(38)   | NO         | ピアサーバーのポート番号         |
| PEER_TARGET                  | NUMBER(38)   | NO         | ピアサーバーのPXスレッド総数          |
| PEER_TARGET_USED             | NUMBER(38)   | NO         | ピアサーバーのPXスレッド使用数          |
| LOCAL_TARGET_USED            | NUMBER(38)   | NO         | ローカルサーバーが使用するピアサーバーのPXスレッド数          |
| LOCAL_PARALLEL_SESSION_COUNT | NUMBER(38)   | NO         | ローカルサーバー上で並行実行中のSESSION数          |

## クエリ例

ユーザーテナント内で、現在のテナントにおけるOBServerノード上のPXスレッドの使用状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PX_TARGET_MONITOR;
```

クエリ結果は次のとおりです：

```shell

+----------------+----------+-----------+-----------+-----------------+----------------+-----------+-------------+------------------+-------------------+------------------------------+
| 11.xxx.xxx.xxx |    28825 |      1004 | Y         | 334988734352026 | 11.xxx.xxx.xxx |     28825 |          10 |                0 |                 0 |                            0 |
```
