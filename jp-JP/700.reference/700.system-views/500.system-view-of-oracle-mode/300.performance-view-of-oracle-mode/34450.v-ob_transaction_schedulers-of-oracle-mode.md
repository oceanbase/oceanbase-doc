# V$OB_TRANSACTION_SCHEDULERS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`V$OB_TRANSACTION_SCHEDULERS`は、現在のサーバーのトランザクションスケジューラー情報を照会するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | コピーが存在するサーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | コピーが存在するサーバーのポート |
| SESSION_ID | NUMBER(38) | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODP内の構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| TX_ID | NUMBER(38) | NO | トランザクションID |
| STATE | VARCHAR2(18) | NO | トランザクションの状態 |
| CLUSTER_ID | NUMBER(38) | NO | クラスター固有ID |
| COORDINATOR | NUMBER(38) | NO | コーディネーターが存在するログストリームID |
| PARTICIPANTS | VARCHAR2(1024) | NO | トランザクションの参加者情報 |
| ISOLATION_LEVEL | VARCHAR2(16) | NO | 分離レベル |
| SNAPSHOT_VERSION | NUMBER(38)  | NO | RRまたはSERIAL分離レベルで有効なスナップショットバージョン。無効な場合は-1 |
| ACCESS_MODE | VARCHAR2(10) | NO | アクセスモード（読み取り専用または読み書き） |
| TX_OP_SN | NUMBER(38)  | NO | トランザクションレベルの操作シーケンス番号 |
| ACTIVE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | トランザクションが明示的または暗黙的に開始されたタイムスタンプ |
| EXPIRE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | トランザクションの有効期限タイムスタンプ |
| CAN_EARLY_LOCK_RELEASE | VARCHAR2(7) | NO | 早期ロック解放が可能か |
| FORMATID               | NUMBER(38)          | NO   | グローバルトランザクションのフォーマット識別子 |
| GLOBALID               | VARCHAR2(256)        | NO  | グローバルトランザクションの一意識別子 |
| BRANCHID               | VARCHAR2(256)        | NO  | ブランチトランザクションの一意識別子 |

## クエリ例

次のコマンドを実行して、現在のサーバーのトランザクションスケジューラー情報を照会します：

```shell
obclient > SELECT * FROM oceanbase.V$OB_TRANSACTION_SCHEDULERS;
```
