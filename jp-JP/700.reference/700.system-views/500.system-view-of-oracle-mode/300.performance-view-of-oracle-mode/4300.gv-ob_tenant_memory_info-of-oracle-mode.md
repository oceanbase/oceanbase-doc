# GV$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのノードで使用しているメモリ状況を表示します。

## フィールドの説明

| **フィールド名**  |    **型**    | **NULL許容** | **説明**  |
|-----------|--------------|----------------|---------|
| TENANT_ID | NUMBER(38)   | NO             | テナントID   |
| SVR_IP    | VARCHAR2(46) | NO             | マシンのIPアドレス  |
| SVR_PORT  | NUMBER(38)   | NO             | マシンのポート番号   |
| HOLD      | NUMBER(38)   | NO             | テナント使用メモリ、単位はバイト |
| FREE      | NUMBER       | NO             | テナント空きメモリ、単位はバイト  |

## クエリ例

ユーザーテナントが、自身のテナントがすべてのノードで使用しているメモリ状況を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_TENANT_MEMORY;
```

クエリ結果は次のとおりです：

```shell

|      1004 | 172.xx.xxx.xxx |     2882 | 1158885376 | 4209823744 |
|      1004 | 172.xx.xxx.xxx |     2882 |  809107456 | 4559601664 |

3 rows in set
```
