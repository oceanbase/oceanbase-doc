# GV$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ログストリームPalfの状態を表示します。一般的なユースケースは以下のとおりです：

* ログストリームにリーダーが存在するかどうか（リーダーが存在するレプリカ）を確認する。
* ログストリームのメンバーリスト（Paxosレプリカ数）を確認する。
* レプリカの同期状態を確認する。
* ログストリームのログで回収可能なポイントを確認する。
* ログストリームがログ消費サービスを提供できる範囲（LSN/SCNを含む）を確認する。
* Palfのアクセスモードを確認する。

## フィールドの説明

| SVR_PORT | NUMBER(38) | NO | サーバーポート番号 |

| PROPOSAL_ID | NUMBER(38) | NO | PaxosのProposal ID |
| CONFIG_VERSION | VARCHAR2(128) | NO | 設定変更に対応するバージョン番号（例：メンバーリストの変更、レプリカ数の変更、アクセスモードの変更など） |
| ACCESS_MODE | VARCHAR2(32) | NO | アクセスモード：<ul><li>APPEND</li><li>RAW_WRITE</li></ul> |
| SYNC_MODE         | VARCHAR2(128)  | NO | ログストリームの同期モード：<ul><li>`ASYNC`：非同期同期モード</li> <li>`SYNC`：強同期モード</li> <li>`PRE_ASYNC`：強同期モードから非同期同期モードへの切り替え中</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main> |
| PAXOS_MEMBER_LIST | VARCHAR2(1024) | NO | Paxosメンバーリスト |
| PAXOS_REPLICA_NUM | NUMBER(38) | NO | Paxosレプリカ数 |

| BASE_LSN | NUMBER(38) | NO | 最大回収可能ポイント |

| BEGIN_SCN | NUMBER(38) | NO | 最小消費可能ポイント（SCN） |
| END_LSN | NUMBER(38) | NO | 最大連続多数派のポイント/最大消費可能ポイント（LSN） |
| END_SCN | NUMBER(38) | NO | 最大連続多数派のポイント/最大消費可能ポイント（SCN） |

| MAX_SCN | NUMBER(38) | NO | 最大書き込みポイント（SCN） |
| ARBITRATION_MEMBER | VARCHAR2(128)    | NO | アービトレーションメンバーのサーバーアドレス <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| DEGRADED_LIST |VARCHAR2(1024) | NO | アービトレーションが有効なシナリオで降格したフル機能レプリカのリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| LEARNER_LIST | CLOB| NO | 現在のログストリームの読み取り専用レプリカリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main> |
