# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
    <ul><li>V4.3.x系では、このビューはV4.3.5バージョンから<a href="31200.v-ob_active_session_history-of-oracle-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a>に、V4.2.x系ではV4.2.2バージョンから<a href="31200.v-ob_active_session_history-of-oracle-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a>に変更されました。</li>
  <li>このビューはV4.0.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `V$ACTIVE_SESSION_HISTORY` は、現在のテナント配下のOBServerノードにおけるアクティブセッションの履歴を表示します。
