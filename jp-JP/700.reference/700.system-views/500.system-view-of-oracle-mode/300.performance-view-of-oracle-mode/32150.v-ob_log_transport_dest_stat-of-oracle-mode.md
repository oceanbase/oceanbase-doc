# V$OB_LOG_TRANSPORT_DEST_STAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `V$OB_LOG_TRANSPORT_DEST_STAT` は、テナント内の現在のOBServerにおけるダウンストリームログ同期リンク（OBCDC/ネットワークスタンバイデータベース）の情報を表示します。

## フィールド説明

| **項目** | **型** | **NULL許容** | **説明** |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID                   | NUMBER(38)                        | NO   | テナントID     |
| SVR_IP                      | VARCHAR2(46)                      | NO   | サーバーIPアドレス     |
| SVR_PORT                    | NUMBER(38)                        | NO   | サーバーRPC_PORT     |
| LS_ID                       | NUMBER(38)                        | NO   | 要求されたログストリームID     |
| CLIENT_IP                   | VARCHAR2(46)                      | NO   | リクエスタープロセスのマシンのIPアドレス     |
| CLIENT_PID                  | NUMBER(38)                        | NO   | リクエスタープロセスID     |
| CLIENT_TENANT_ID            | NUMBER(38)                        | NO   | リクエスターテナントID     |
| CLIENT_TYPE                 | VARCHAR2(7)                       | NO   | リクエスタータイプ：<ul><li>STANDBY：ネットワークスタンバイデータベース </li><li>CDC：OBCDC </li><li>UNKNOWN：クライアントタイプ不明 </li></ul>    |
| START_SERVE_TIME            | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | レコード作成日時     |
| LAST_SERVE_TIME             | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | レコード変更日時     |
| LAST_READ_SOURCE            | VARCHAR2(7)          | NO   | 最終リクエスト時のログ読み取り元：<ul><li>ONLINE：オンラインログ </li><li>ARCHIVE：アーカイブログ </li><li>UNKNOWN：ソース不明 </li></ul>     |
| LAST_REQUEST_TYPE           | VARCHAR2(24)         | NO   | 最終リクエストのRPCタイプ：<ul><li>0：SEQUENTIAL_READ_SERIAL、直列ログ転送プロトコルを使用した順次ログ読み取りを示す </li><li>1：SEQUENTIAL_READ_PARALLEL、並列ログ転送プロトコルを使用した順次ログ読み取りを示す </li><li>2：SCATTERED_READ、前回のリクエストが離散ログの読み取りであったことを示す </li><li>その他の値：RPCタイプが不明であることを示す </li></ul>     |
| LAST_REQUEST_LOG_LSN        | NUMBER(38)                        | NO   | 前回リクエストのログLSN     |
| LAST_REQUEST_LOG_SCN        | NUMBER(38)                        | NO   | 前回リクエストのログSCN     |
| LAST_FAILED_REQUEST         | CLOB                              | NO   | 前回失敗したRPC情報、送信時間/TRACE_ID/エラーコードなど    |
| AVG_REQUEST_PROCESS_TIME    | NUMBER(38)                        | NO   | 平均RPC処理時間     |
| AVG_REQUEST_QUEUE_TIME      | NUMBER(38)                        | NO   | 平均RPC待機時間     |
| AVG_REQUEST_READ_LOG_TIME   | NUMBER(38)                        | NO   | 平均RPC読み取りログ時間     |
| AVG_REQUEST_READ_LOG_SIZE   | NUMBER(38)                        | NO   | 平均RPC読み取りログサイズ     |
| AVG_LOG_TRANSPORT_BANDWIDTH | VARCHAR2(44)                      | NO   | 平均ログ転送帯域幅     |
