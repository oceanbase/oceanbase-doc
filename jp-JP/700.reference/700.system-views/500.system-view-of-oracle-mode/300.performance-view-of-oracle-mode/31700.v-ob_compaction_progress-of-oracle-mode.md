# V$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、現在のノード上でのコンパクション進捗情報を表示します。

## フィールドの説明

|          フィールド名           |                タイプ                 | NULLを許容するか |                                            説明                                            |
|-------------------------|-----------------------------------|------------|--------|
| SVR_IP                  | VARCHAR2(46)                      | NO         | サーバーのIPアドレス                                                                                |
| SVR_PORT                | NUMBER(38)                        | NO         | サーバーのポート番号|
| TENANT_ID               | NUMBER(38)                        | NO         | テナントID |
| TYPE                    | VARCHAR2(64)                      | NO         | コンパクションのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なコンパクションタイプ。指定された時点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>  |
| ZONE                    | VARCHAR2(128)                     | NO         | Zone情報                                                                                  |
| COMPACTION_SCN          | NUMBER(38)                        | NO         | コンパクションバージョン情報|
| STATUS                  | VARCHAR2(15)                      | NO         | ステータス情報  |
| TOTAL_TABLET_COUNT      | NUMBER(38)                        | NO         | TABLETの総数                                                                                |
| UNFINISHED_TABLET_COUNT | NUMBER(38)                        | NO         | 未完了のTABLET数                                                                           |
| DATA_SIZE               | NUMBER(38)                        | NO         | コンパクションが必要な総データ量（単位：バイト）  |
| UNFINISHED_DATA_SIZE    | NUMBER(38)                        | NO         | 未完了のコンパクションのデータ量、単位はバイトです  |
| COMPRESSION_RATIO       | NUMBER(38)                        | NO         | 新規データの圧縮率：前のメジャーバージョン以降に新しく書き込まれたデータの圧縮率のみを記録します                                                |
| START_TIME              | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME   | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 予想完了時間：compaction_progressが100の場合、終了時間を表示します                                               |
| COMMENTS                | VARCHAR2(1024)                     | NO         | コメント情報。コンパクションが進行中の場合は、現在の最新のコンパクションイベントを記録します。コンパクションが終了した場合は、全体の所要時間を記録します    |

## クエリ例

ユーザーテナントは、現在のOBServerノード上での自身のテナントのメジャーコンパクションの進捗状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_COMPACTION_PROGRESS;
```
