# GV$OB_OPT_STAT_GATHER_MONITOR

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、すべてのOBServerノード上での統計情報収集タスクのリアルタイム状態を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER | NO | クリーンアップタスクが存在するテナントID |
| SVR_IP | VARCHAR2(46) | NO | クリーンアップタスクが存在するノードのIPアドレス |
| SVR_PORT | NUMBER | NO | クリーンアップタスクが存在するノードのポート |
| SESSION_ID | NUMBER | NO | クリーンアップタスクが存在するセッションID<br>V4.3.x系では：<ul><li> V4.3.5 BP2未満のバージョンでは：<br>すべての接続モード(ダイレクト接続モード/ODPモード)において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>ダイレクト接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| TRACE_ID | VARCHAR2(64) | NO | クリーンアップタスクが存在するTRACE ID |
| TASK_ID | VARCHAR2(36) | NO | クリーンアップタスクID(UUID形式で生成されたグローバル一意のID) |
| TYPE | VARCHAR2(16) | NO | クリーンアップタスクのタイプ |
| TASK_START_TIME | TIMESTAMP(6) | NO | クリーンアップタスクの開始時間 |
| TASK_DURATION_TIME | NUMBER | NO | クリーンアップタスクの継続時間(マイクロ秒単位) |
| TASK_TABLE_COUNT | NUMBER | NO | クリーンアップタスクで収集対象となるテーブル数 |
| COMPLETED_TABLE_COUNT | NUMBER | NO | クリーンアップタスクで既に完了したテーブル数 |
| RUNNING_TABLE_OWNER | VARCHAR2(128) | NO | クリーンアップタスクで収集中のテーブルの所有者ユーザー名 |
| RUNNING_TABLE_NAME | VARCHAR2(256) | NO | クリーンアップタスクで収集中のテーブル名 |
| RUNNING_TABLE_DURATION_TIME | VARCHAR2(256) | NO | クリーンアップタスクで収集中のテーブルの継続時間 |
| RUNNING_TABLE_PROGRESS      | VARCHAR2(256) | NO   | クリーンアップタスクの収集進捗状況 |
