# GV$OB_PLAN_CACHE_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノード上で各計画キャッシュ全体の状態を表示します。

## フィールドの説明

|   **フィールド名**   |    **タイプ**    | **NULL値を許容するか** |              **説明**               |
|--------------|--------------|----------------|-----------------------------------|
| SVR_IP       | VARCHAR2(32) | NO             | サーバーのIPアドレス                        |
| SVR_PORT     | NUMBER(38)   | NO             | サーバーのポート番号                               |
| SQL_NUM      | NUMBER(38)   | NO             | plan_cacheに関連するSQL文の数              |
| MEM_USED     | NUMBER(38)   | NO             | plan_cacheで使用されているメモリ、単位はバイト                |
| MEM_HOLD     | NUMBER(38)   | NO             | plan_cacheが保持しているメモリ、単位はバイト                  |
| ACCESS_COUNT | NUMBER(38)   | NO             | plan_cacheへのクエリアクセス回数                 |
| HIT_COUNT    | NUMBER(38)   | NO             | plan_cacheへのヒット回数                 |
| HIT_RATE     | NUMBER(38)   | NO             | plan_cacheのヒット率                   |
| PLAN_NUM     | NUMBER(38)   | NO             | プランの数                          |
| MEM_LIMIT    | NUMBER(38)   | NO             | plan_cacheのメモリ上限、単位はバイト                  |
| HASH_BUCKET  | NUMBER(38)   | NO             | plan_cacheのhash map内のBucketの数 |
| STMTKEY_NUM  | NUMBER(38)   | NO             | plan_cache内のstmt_keyの数         |

## クエリ例

ユーザーテナント内で、このテナントのすべてのノード上における計画キャッシュの全体的な状態を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_PLAN_CACHE_STAT;
```
