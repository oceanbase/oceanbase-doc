# V$OB_SHARED_STORAGE_QUOTA

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上のI/Oアクセスリソース情報を表示します。

## フィールドの説明

| フィールド名     | 型     | NULL許容 | 説明                                                        |
|-------------|----------|----------------|-------------------------------------------------------------|
| SVR_IP      | VARCHAR2(46)  | NO   | OBServerノードのIPアドレス     |
| SVR_PORT    | NUMBER(38)    | NO   | OBServerノードのポート番号     |
| ENDPOINT    | VARCHAR2(256) | NO   | 共有ストレージのEndpoint。シェアードナッシング（Shared-Nothing、SN）モードでは、このフィールドの値は空になります。     |
| PATH        | VARCHAR2(1024)| NO   | オブジェクトストレージのパス。シェアードナッシング（Shared-Nothing、SN）モードでは、ローカルパスとして表示されます。</br>このパスでよく使われるタイプは、`local://`、`oss://`、`file://`、`s3://` などです。   |
| CLASS_ID    | NUMBER(38)    | NO   | マーカー用ID。オブジェクトストレージのBucketの用途によって、意味が異なります。<ul><li>Bucketがclogストレージまたはデータストレージに使用される場合、このフィールドは無意味で、値は `0` です。</li> <li>Bucketがバックアップ・リストア、データインポート、エクスポートなどのタスクに使用される場合、このフィールドはテナントIDを表します。</li></ul>      |
| TYPE        | VARCHAR2(32)  | NO   | 指標タイプ。主な種類は以下の通りです：<ul><li>`IPS`：1秒間の命令数</li> <li>`OPS`：1秒間に実行される操作数</li> <li>`IOPS`：1秒間の入出力操作数</li> <li>`IBW`：入力帯域幅</li> <li>`OBW`：出力帯域幅</li> <li>`IOBW`：入出力帯域幅</li> <li>`TAG`：ユーザーが設定したタグ情報</li></ul>     |
| REQUIREMENT | NUMBER(38)    | NO   | サーバーに必要な各種リソース    |
| ASSIGN      | NUMBER(38)    | NO   | サーバーに対してスロットリングアルゴリズムが指定する各種リソースの上限値     |

## クエリ例

ユーザーテナント内で、clogストレージやデータストレージなどのシナリオにおいて、現在のOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。バックアップ・リカバリ、データインポート、エクスポートなどのシナリオでは、当該テナントの現在のOBServerノード上のオブジェクトストレージの各指標の申請クォータと制限クォータを照会します。

```shell
obclient> SELECT * FROM SYS.V$OB_SHARED_STORAGE_QUOTA;
```
