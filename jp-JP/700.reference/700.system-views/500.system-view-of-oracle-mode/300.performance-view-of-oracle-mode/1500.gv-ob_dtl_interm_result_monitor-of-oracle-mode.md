# GV$OB_DTL_INTERM_RESULT_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

DTL中間結果マネージャーの監視情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーのポート番号 |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| TRACE_ID | VARCHAR2(64) | NO | ステートメントのTRACE ID |
| OWNER | VARCHAR2(64) | NO | 中間結果の使用者 |
| START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 中間結果を書き込んだ時間 |
| EXPIRE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | 中間結果のタイムアウト時間 |
| HOLD_MEMORY | NUMBER(38) | NO | 使用しているメモリサイズ、単位はバイト |
| DUMP_SIZE | NUMBER(38) | NO | ダンプサイズ、単位はバイト |
| DUMP_COST | NUMBER(38) | NO | ダンプにかかる時間 |
| DUMP_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | ダンプのタイミング |
| DUMP_FD | NUMBER(38) | NO | ダンプファイルのFD |
| DUMP_DIR_ID | NUMBER(38) | NO | ダンプファイルのディレクトリID |
| CHANNEL_ID | NUMBER(38) | NO | DTLのチャネルID |
| QC_ID | NUMBER(38) | NO | 送信者のQC ID |
| DFO_ID | NUMBER(38) | NO | 送信者のDFO ID |
| SQC_ID | NUMBER(38) | NO | 送信者のSQC ID |
| BATCH_ID | NUMBER(38) | NO | px batch rescanシナリオにおけるバッチ内の順序 |
| MAX_HOLD_MEMORY | NUMBER(38) | NO | 最大使用メモリサイズ、単位はバイト |
