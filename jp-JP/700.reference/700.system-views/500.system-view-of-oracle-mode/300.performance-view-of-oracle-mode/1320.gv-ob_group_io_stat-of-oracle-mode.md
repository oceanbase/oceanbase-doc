# GV$OB_GROUP_IO_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナント内のすべてのOBServerノード上の各リソースグループのリアルタイム状態を表示します。

## フィールド説明

|             フィールド名          |      型    | NULL許容    |            説明                                            |
|------------------------------|--------------|----------------|------------------------------------------------------------|
| TENANT_ID                    | NUMBER(38)   | NO             | テナントID                                                    |
| SVR_IP                       | VARCHAR2(46) | NO             | サーバーIPアドレス                                              |
| SVR_PORT                     | NUMBER(38)   | NO             | サーバーポート番号                                                |
| GROUP_ID                     | NUMBER(38)   | NO             | 対応するリソースグループID     |
| GROUP_NAME                   | VARCHAR2(128)| NO             | 対応するリソースグループ名     |
| MODE                         | VARCHAR2(128)| NO             | 読み書きモード。<ul><li>`READ`：読み取りモード</li> <li>`WRITE`：書き込みモード</li></ul>     |
| MIN_IOPS                     | NUMBER(38)   | NO             | リソースグループ内の最小IOPS     |
| MAX_IOPS                     | NUMBER(38)   | NO             | リソースグループ内の最大IOPS     |
| NORM_IOPS                    | NUMBER(38)   | NO             | 現在のIOPS（16KB読みに換算した値を表示）。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0から導入されました。</li><li>V4.3.5系では、このフィールドはV4.3.5 BP1から導入されました。</li></ul></main>  |
| REAL_IOPS                    | NUMBER(38)   | NO             | 現在のIOPS     |
| MAX_NET_BANDWIDTH            | NUMBER(38)   | NO             | リソースグループ内の最大ネットワーク帯域幅（バイト単位） |
| MAX_NET_bandWIDTH_DISPLAY    | VARCHAR2(128)| NO             | 変換後に表示されるリソースグループ内の最大ネットワーク帯域幅。例：10GB/s、10MB/sなどの形式で表示されます。     |
| REAL_NET_BANDWIDTH           | NUMBER(38)   | NO             | 現在のネットワーク帯域幅（バイト単位）    |
| REAL_NET_BANDWIDTH_DISPLAY   | VARCHAR2(128)| NO             | 変換後に表示される現在のネットワーク帯域幅。例：10GB/s、10MB/sなどの形式で表示されます。     |

## クエリ例

ユーザーテナントが自身のテナント内にあるすべてのOBServerノード上の各リソースグループのリアルタイム状態を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_GROUP_IO_STAT WHERE ROWNUM <= 2\G
```
