# GV$OB_JAVA_SANDBOX_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP4バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントにおけるすべてのOBServerノード上のJava UDFサンドボックスの状態を表示します。これには、サンドボックス世代のライフサイクル、通信チャネルプール、サンドボックスプロセスリソース、サンドボックスJVMリソースなどの情報が含まれます。

使用方法は以下のとおりです：

* 構成パラメータ `ob_enable_java_udf_sandbox` を有効にすると、Java UDFは独立したサンドボックスプロセスで実行されます。各行は1世代（Generation）のサンドボックスに対応し、各世代のサンドボックスは1つのサンドボックスJVMプロセスに対応します。
* このビューは既存のサンドボックスのみを表示します。このビューをクエリしてもサンドボックスの作成はトリガーされません。
* `INSTANCE_COUNT` から `LAST_FORCE_KILL_REASON` まではテナントレベルの集計情報であり、同一テナント内の各行の値は同じです。
* まだ正常に収集できていない、または取得できない指標はNULLとして表示され、実際の値が`0`の指標と区別されます。

| SVR_PORT | NUMBER(38) | NO | OBServerノードのポート番号。 |
| TENANT_ID | NUMBER(38) | NO | テナントID。 |
| GENERATION_ID | NUMBER(38) | NO | サンドボックス世代（Generation）ID。各世代のサンドボックスは、それぞれサンドボックスJVMプロセスに対応します。 |
| GENERATION_STATE | VARCHAR2(32) | YES | 当該世代サンドボックスのライフサイクル状態：<ul><li>`CREATING`：作成中</li><li>`ACTIVE`：正常にサービス提供中</li><li>`DRAINING`：ドレイン中、実行中のリクエスト終了を待機中</li><li>`STOPPING`：停止中</li><li>`DEAD`：終了済み</li><li>`START_FAILED`：起動失敗</li></ul> |
| STATUS | VARCHAR2(32) | NO | 当該世代サンドボックスの実行状態：<ul><li>`STARTING`：起動中</li><li>`UP`：実行中</li><li>`DRAINING`：ドレイン中</li><li>`DOWN`：停止済み</li><li>`START_FAILED`：起動失敗</li></ul> |
| PROCESS_PID | NUMBER(38) | YES | サンドボックスJVMプロセスのプロセスID。 |
| START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 当該世代サンドボックスの起動時刻。 |
| UPTIME_MS | NUMBER(38) | YES | 当該世代サンドボックスの稼働時間。単位はミリ秒。 |
| DRAIN_REASON | VARCHAR2(32) | YES | 当該世代サンドボックスがドレイン状態になった原因。`GENERATION_STATE`が`DRAINING`の場合にのみ値が設定されます：<ul><li>`IDLE_RETIRE`：アイドル状態による廃止</li><li>`MANUAL_RETIRE`：手動による廃止</li><li>`TIMEOUT_STUCK`：リクエストタイムアウト</li><li>`OOM`：メモリ不足</li><li>`CHANNEL_ERROR`：通信チャネルエラー</li><li>`CHANNEL_DEGRADED`：通信チャネルの機能低下</li><li>`PROCESS_DEAD`：サンドボックスプロセス終了</li><li>`PROTOCOL_ERROR`：通信プロトコルエラー</li><li>`HANDLER_FATAL`：リクエスト処理で致命的エラー発生</li><li>`DRAIN_DEADLINE_EXPIRED`：ドレインタイムアウト</li><li>`MAX_GENERATION_LIMIT`：サンドボックス世代数が上限に達した場合</li></ul> |
| DRAIN_DEADLINE | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | ドレインの締め切り時刻。`GENERATION_STATE`が`DRAINING`の場合にのみ値が設定されます。この時刻までにドレインが完了しない場合、サンドボックスプロセスは強制的に終了されます。 |
| FORCE_KILLED | NUMBER(38) | YES | 当該世代サンドボックスプロセスが強制的に終了されたかどうか：<ul><li>`0`：いいえ</li><li>`1`：はい</li></ul> |
| FORCE_KILL_REASON | VARCHAR2(32) | YES | 強制終了の原因。値は `DRAIN_REASON` と同じです。`FORCE_KILLED` が `1` の場合にのみ値が設定されます。 |
| INSTANCE_COUNT | NUMBER(38) | YES | 当該テナントの現在のサンドボックスインスタンス数。 |
| MAX_GENERATION_COUNT | NUMBER(38) | YES | 当該テナントで同時に存在できるサンドボックス世代数の上限。 |
| DRAINING_GENERATION_COUNT | NUMBER(38) | YES | 当該テナントで現在ドレイン状態にあるサンドボックス世代数。 |
| DEFERRED_GENERATION_COUNT | NUMBER(38) | YES | 当該テナントで遅延回収を待機しているサンドボックス世代数。 |
| START_COUNT | NUMBER(38) | YES | 当該テナントサンドボックスの累計起動回数。 |
| RESTART_COUNT | NUMBER(38) | YES | 当該テナントサンドボックスの累計再起動回数。初回起動は含まれません。 |
| START_FAILURE_COUNT | NUMBER(38) | YES | 当該テナントサンドボックスの累計起動失敗回数。 |
| LAST_START_ERROR_CODE | NUMBER(38) | YES | 当該テナントの直近のサンドボックス起動失敗時のエラーコード。起動失敗が発生していない場合はNULLです。 |
| LAST_START_ERROR_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 当該テナントの直近のサンドボックス起動失敗時刻。起動失敗が発生していない場合はNULLです。 |
| ROLLOVER_COUNT | NUMBER(38) | YES | 当該テナントサンドボックスの累計置換（Rollover）回数。新しい世代のサンドボックスで古いサンドボックスを置き換えた回数です。 |
| ROLLOVER_COUNT_60S | NUMBER(38) | YES | 当該テナントの直近60秒間のサンドボックス置換回数。 |
| LAST_ROLLOVER_REASON | VARCHAR2(32) | YES | 当該テナントの直近のサンドボックス置換理由。値は `DRAIN_REASON` と同じです。置換が発生していない場合はNULLです。 |
| LAST_ROLLOVER_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 当該テナントの直近のサンドボックス置換時刻。置換が発生していない場合はNULLです。 |
| ROLLOVER_COOLDOWN_REMAIN_US | NUMBER(38) | YES | サンドボックス置換のクールダウン期間の残り時間。単位はマイクロ秒です。短期間に置換回数が多すぎるとクールダウン期間に入ります。クールダウン期間外は `0` です。 |

| LAST_FORCE_KILL_REASON | VARCHAR2(32) | YES | 当該テナントの直近のサンドボックスプロセス強制終了理由。値は `DRAIN_REASON` と同じです。強制終了が発生していない場合はNULLです。 |
| CHANNEL_POOL_CAPACITY | NUMBER(38) | YES | OBServerとサンドボックスプロセス間の通信チャネルプールの容量。 |
