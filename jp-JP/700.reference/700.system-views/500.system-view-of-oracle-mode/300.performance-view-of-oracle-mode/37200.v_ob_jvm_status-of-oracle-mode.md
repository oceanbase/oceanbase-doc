# V$OB_JVM_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP4バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のOBServerノード上のOBServerプロセス内のJVMの実行状態とリソース使用状況を表示します。JVMの状態、ヒープメモリ、メタスペース、GC、スレッド数、ファイルディスクリプタ数などの情報が含まれます。各OBServerノードに対応して1行のレコードが存在します。

使用方法は以下の通りです：

* 構成パラメータ`ob_enable_java_env`が有効に設定されている場合にのみ、OBServerプロセスはJVMを起動します。無効の場合、`STATUS`は`DISABLED`となります。
* JVMが起動すると、システムはデフォルトで60秒ごとにJVMの状態を収集します。このビューに表示されるのは最新の収集結果であり、JVMの起動や収集をトリガーするものではありません。
* まだ収集に成功していない、または取得できない指標はNULLとして表示され、実際の値が`0`の指標と区別されます。
* Java UDFがサンドボックスプロセス内で実行される場合、サンドボックスJVMの状態については[V$OB_JAVA_SANDBOX_STATUS](37400.v_ob_java_sandbox_status-of-oracle-mode.md)を参照してください。

## フィールドの説明

|     フィールド名    |     型    | NULL許容 |      説明      |
|----------------|-------------|----------------|----------------|
| SVR_IP | VARCHAR2(46) | NO | OBServerノードのIPアドレス。 |
| SVR_PORT | NUMBER(38) | NO | OBServerノードのポート番号。 |
| PROCESS_PID | NUMBER(38) | YES |
| STATUS | VARCHAR2(32) | NO | OBServerプロセス内のJVMの状態：<ul><li>`DISABLED`：Java環境が有効化されていない（構成パラメータ`ob_enable_java_env`が`False`の場合）</li><li>`NOT_STARTED`：JVMがまだ起動していない</li><li>`STARTING`：JVMが起動中、または起動済みでも最初の収集が完了していない</li><li>`UP`：JVMが実行中で、直近の収集が成功した</li><li>`INIT_FAILED`：JVMの初期化に失敗した</li><li>`COLLECT_ERROR`：JVMの状態収集に失敗した</li><li>`DOWN`：OBServerプロセスが終了中、またはJVMの監視が停止した</li></ul> |
| INIT_ATTEMPT_COUNT | NUMBER(38) | YES |

## クエリ例

```shell
obclient> SELECT SVR_IP, SVR_PORT, STATUS, HEAP_USED_BYTES, HEAP_MAX_BYTES, GC_COUNT, THREAD_COUNT, SNAPSHOT_TIME FROM SYS.V$OB_JVM_STATUS;
```
