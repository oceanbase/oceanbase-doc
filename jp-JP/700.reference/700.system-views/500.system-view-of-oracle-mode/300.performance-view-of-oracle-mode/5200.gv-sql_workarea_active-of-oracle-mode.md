# GV$SQL_WORKAREA_ACTIVE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上で現在アクティブなOperatorのWorkarea情報を表示します。

## **フィールド説明**

|     **フィールド名**     |    **型**    | **NULL許容** |                    **説明**                    |
|------------------|--------------|----------------|------------------------------------------------------------------------------|
| SQL_HASH_VALUE   | NUMBER       | NO             | 実行されたステートメントのHash値です。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています        |
| SQL_ID           | VARCHAR2(32) | NO             | SQLステートメントの一意の識別子                             |
| SQL_EXEC_START   | DATE         | NO             | SQL実行開始時間です。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています           |
| SQL_EXEC_ID      | NUMBER   | NO             | SQL実行の一意の識別子                                   |
| WORKAREA_ADDRESS | RAW(8)       | NO             | workareaアドレスです。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています          |
| OPERATION_TYPE   | VARCHAR2(160) | NO             | workareaオペレータタイプ。例：Sort、Hash Join、Group byなど  |
| OPERATION_ID     | NUMBER   | NO             | プランツリー内でオペレータを識別する一意の識別子                               |
| POLICY           | VARCHAR2(24)  | NO             | workareaのポリシー：<ul><li> MANUAL   </li><li> AUTO   </li></ul>   |
| SID              | NUMBER   | NO             | セッションの一意の識別子                                |
| QCINST_ID        | NUMBER       | NO             | クエリコーディネータのインスタンスIDです。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています          |
| QCSID            | NUMBER       | NO             | クエリコーディネータセッション識別IDです。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています  |
| ACTIVE_TIME      | NUMBER   | NO             | workareaの平均アクティブ時間、単位：ms                       |
| WORK_AREA_SIZE   | NUMBER       | NO             | オペレータが使用するworkareaの最大サイズ、単位：bytes                 |
| EXPECT_SIZE      | NUMBER   | NO             | workareaの推定サイズ、単位：bytes                      |
| ACTUAL_MEM_USED  | NUMBER   | NO             | workareaに割り当てられたメモリ量、単位：bytes                    |
| MAX_MEM_USED     | NUMBER   | NO             | workareaで使用される最大メモリ量、単位：bytes                |
| NUMBER_PASSES    | NUMBER   | NO             | workareaがどのモードで実行されているか：<ul><li> 0：optimalモード   </li><li> 1：one passモード   </li><li> \>=2：multi passモード </li></ul>   |
| TEMPSEG_SIZE     | NUMBER   | NO             | workareaが使用する一時空間のサイズ、単位：bytes。NULLの場合は一時ファイルへの書き込みが発生していないことを意味します                                                                              |
| TABLESPACE       | VARCHAR2(128) | NO             | 一時ファイルが書き込まれるテーブル名前空間です。NULLの場合は一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています                                                                        |
| SEGRFNO#         | NUMBER       | NO             | 一時ファイル書き込み関連のファイル数です。NULLは一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています                                                                           |
| SEGBLK#          | NUMBER       | NO             | workareaが作成した一時ファイルのblock数です。NULLは一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています                                                              |
| CON_ID           | NUMBER   | NO             | テナントID       |
| SVR_IP                 | VARCHAR2(46)   | NO             | サーバーIPアドレス   |
| SVR_PORT               | NUMBER(38)   | NO             | サーバーポート番号   |
