# GV$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのノードで実行しているメジャーコンパクションの進捗状況を表示します。

## フィールド説明

|          フィールド名           |                型                 | NULL許容   |                                            説明                                               |
|-------------------------|-----------------------------------|------------|--------|
| SVR_IP                  | VARCHAR2(46)                      | NO         | サーバーIPアドレス                                                                                |
| SVR_PORT                | NUMBER(38)                        | NO         | サーバーポート番号|
| TENANT_ID               | NUMBER(38)                        | NO         | テナントID |
| TYPE                    | VARCHAR2(64)                      | NO         | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>    |
| ZONE                    | VARCHAR2(128)                     | NO         | Zone情報                                                                                  |
| COMPACTION_SCN          | NUMBER(38)                        | NO         | メジャーコンパクションのバージョン情報|
| STATUS                  | VARCHAR2(15)                      | NO         | ステータス情報  |
| TOTAL_TABLET_COUNT      | NUMBER(38)                        | NO         | TABLETの総数                                                                                |
| UNFINISHED_TABLET_COUNT | NUMBER(38)                        | NO         | 未完了のTABLET数                                                                           |
| DATA_SIZE               | NUMBER(38)                        | NO         | コンパクションが必要なデータの合計サイズ、単位はバイト |
| UNFINISHED_DATA_SIZE    | NUMBER(38)                        | NO         | 未完了なCompactionのデータ量。単位はバイトです  |
| COMPRESSION_RATIO       | NUMBER(38)                        | NO         | 新規データの圧縮率。直近のメジャーバージョン以降に新規に書き込まれたデータの圧縮率のみを記録します                                                |
| START_TIME              | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME   | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 予定終了時間。compaction_progressが100の場合、終了時間を表示します                                               |
| COMMENTS                | VARCHAR2(1024)                     | NO         | コメント情報。マージ中は現在の最新のCompactionイベントを記録します。マージ終了後は、全体の所要時間を記録します    |
