# V$DML_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上のユーザーテーブルのDML情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーIPアドレス |
| SVR_PORT | NUMBER | NO | サーバーポート番号 |
| INST_ID | NUMBER | NO | テナントID |
| OBJN | NUMBER | NO | オブジェクトID |
| INS | NUMBER | NO | 最終統計収集時からの挿入回数の概数 |
| UPD | NUMBER | NO | 最終統計収集時からの更新回数の概数 |
| DEL | NUMBER | NO | 最終統計収集時からの削除回数の概数 |
| DROPSEG | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| CURROWS | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| PAROBJN | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| LASTUSED | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| FLAGS | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| CON_ID | NUMBER | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |

## クエリ例

現在のテナントが現在のOBServerノード上のユーザーテーブルのDML情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$DML_STATS;
```
