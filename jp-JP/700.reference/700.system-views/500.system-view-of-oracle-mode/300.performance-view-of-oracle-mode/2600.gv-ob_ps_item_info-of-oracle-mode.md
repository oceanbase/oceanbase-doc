# GV$OB_PS_ITEM_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能

ビュー`GV$OB_PS_ITEM_INFO`は、プリペアドステートメントの監視機能を提供し、PSキャッシュ内のすべてのプリペアドステートメントの基本情報を含みます。

## フィールド説明

|        フィールド名         |      型      | NULL許容 |             説明             |
|---------------------|--------------|------------|----------------------------|
| SVR_IP              | VARCHAR2(46) | NO         | サーバーIPアドレス                  |
| SVR_PORT            | NUMBER(38)   | NO         | サーバーのポート番号                     |
| STMT_ID             | NUMBER(38)   | NO         | ps cache内の対応するステートメントのstmt_id情報 |
| DB_ID               | NUMBER(38)   | NO         | プリペアステートメントが関連するデータベースID       |
| PS_SQL              | CLOB         | NO         | プリペアのSQL情報           |
| PARAM_COUNT         | NUMBER(38)   | NO         | プリペアのパラメータ数情報            |
| STMT_ITEM_REF_COUNT | NUMBER(38)   | NO         | stmt_itemの参照カウント情報          |
| STMT_INFO_REF_COUNT | NUMBER(38)   | NO         | stmt_infoの参照カウント情報          |
| MEM_HOLD            | NUMBER(38)   | NO         | そのプリペアstmtが占用するメモリサイズ     |
| STMT_TYPE           | NUMBER(38)   | NO         | そのプリペアstmtのタイプ情報|
| CHECKSUM            | NUMBER(38)   | NO         | そのプリペアstmtのchecksum |
| EXPIRED             | NUMBER(38)   | NO         | そのプリペアstmtが期限切れかどうか |
