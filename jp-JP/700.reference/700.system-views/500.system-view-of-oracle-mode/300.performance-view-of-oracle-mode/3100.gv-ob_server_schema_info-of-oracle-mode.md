# GV$OB_SERVER_SCHEMA_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上のスキーマ情報を表示します。

## フィールド説明

|            フィールド名            |      型      | NULL許容 |                説明                |
|----------------------------|--------------|------------|----------------------------------|
| SVR_IP                     | VARCHAR2(46) | NO         | サーバーIPアドレス                        |
| SVR_PORT                   | NUMBER(38)   | NO         | サーバーポート番号                           |
| TENANT_ID                  | NUMBER(38)   | NO         | テナントID                            |
| REFRESHED_SCHEMA_VERSION   | NUMBER(38)   | NO         | テナントでリフレッシュ済みのスキーマバージョン                 |
| RECEIVED_SCHEMA_VERSION    | NUMBER(38)   | NO         | テナントでリフレッシュが必要なスキーマバージョン               |
| SCHEMA_COUNT               | NUMBER(38)   | NO         | 対応するスキーマバージョンにおける、各スキーマオブジェクト数の合計                    |
| SCHEMA_SIZE                | NUMBER(38)   | NO         | 対応するスキーマバージョンにおける、各スキーマオブジェクトが占有するメモリサイズの合計、単位はバイト                   |
| MIN_SSTABLE_SCHEMA_VERSION | NUMBER(38)   | NO         | テナントSSTableに記録されている最小schema_version |

## クエリ例

ユーザーテナントが、自身のテナントに属するすべてのOBServerノード上のスキーマ情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_SERVER_SCHEMA_INFO;
```
