# V$TIMEZONE_NAMES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

有効なタイムゾーン名を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名** |    **タイプ**     | **NULLを許容するか** |     **説明**     |
|----------|---------------|----------------|----------------|
| TZNAME   | varchar(64)   | NO             | タイムゾーンエリア           |
| TZABBREV | varchar(8)    | NO             | 相対時間の略称（例：PDT） |
| CON_ID   | decimal(38,0) | NO             | テナントID          |
