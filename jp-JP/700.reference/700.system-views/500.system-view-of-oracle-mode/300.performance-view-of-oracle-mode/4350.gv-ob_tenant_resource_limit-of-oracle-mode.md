# GV$OB_TENANT_RESOURCE_LIMIT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li>
<li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `GV$OB_TENANT_RESOURCE_LIMIT` は、現在のテナントがすべてのOBServer上で使用している論理リソース量、上限値、有効な制限条件、およびダウン後の再起動時の最大使用量を表示するために使用されます。

## フィールド説明

| フィールド名  |  型  | NULL許容 |     説明     |
|----------|--------|-----------------|-------------|
| SVR_IP               | VARCHAR2(46)  | NO   |  OBServerのIPアドレス    |
| SVR_PORT             | NUMBER(38)    | NO   |  OBServerのRPCポート    |
| TENANT_ID            | NUMBER(38)    | NO   |  テナントID    |
| ZONE                 | VARCHAR2(128) | NO   |  ZONE名    |
| RESOURCE_NAME        | VARCHAR2(128) | NO   |  リソース名    |
| CURRENT_UTILIZATION  | NUMBER(38)    | NO   |  リソースの現在の使用量    |
| MAX_UTILIZATION      | NUMBER(38)    | NO   |  マシン起動後のリソース最大使用量    |
| RESERVED_VALUE       | NUMBER(38)    | NO   |  事前割り当て量。この値は安定稼働のための最低保証値です    |
| LIMIT_VALUE          | NUMBER(38)    | NO   |  容認される最大使用量    |
| EFFECTIVE_LIMIT_TYPE | VARCHAR2(128) | NO   |  効力を生じる制限タイプ。例：パラメータ、メモリ、CPU、ディスクなど    |

## クエリ例

現在のテナントがすべてのOBServer上で使用している論理リソース量、上限値、有効な制限条件、ダウン後の再起動時の最大使用量を照会します。

```shell
obclient[SYS]> SELECT * FROM SYS.GV$OB_TENANT_RESOURCE_LIMIT;
```
