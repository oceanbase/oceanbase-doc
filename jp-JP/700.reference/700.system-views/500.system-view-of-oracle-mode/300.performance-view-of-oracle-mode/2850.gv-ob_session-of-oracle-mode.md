# GV$OB_SESSION

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.0バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`GV$OB_SESSION`は、すべてのサーバーで作成されたセッション情報を記録するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| ID | NUMBER(38) | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>このフィールドは、すべての接続方式（直接接続モード/ODPモード）において、Server Session IDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ<code>client_session_id_version = 2</code>の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code>の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul>   |
| USER | CHAR(193) | NO | このセッションが属するユーザーを表します |
| TENANT | VARCHAR2(128) | NO | アクセスするテナント名   |
| HOST | VARCHAR2(128) | NO | セッションを開始したクライアントのIPアドレスとポート番号を表します。ODP経由でデータベースに接続している場合は、ODPのホストIPアドレスとポート番号を表します   |
| DB | VARCHAR2(128) | YES | このセッションが現在接続しているデータベース名を表します   |
| COMMAND | VARCHAR2(4096) | NO | このセッションが実行中のコマンドを表します  |
| SQL_ID | VARCHAR2(32) | NO |  SQL ID情報   |
| TIME | NUMBER(38) | NO | 現在のコマンドの実行時間を秒単位で表します。コマンドが再試行された場合、ゼロリセットされて再計算されます   |
| STATE | VARCHAR2(128) | YES | このセッションの現在の状態を表します   |
| INFO | VARCHAR2(262143) | YES | このセッションが実行中の文を表します   |
| SVR_IP | VARCHAR2(46) | NO |  サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO |  サーバーのRPCポート番号   |
| SQL_PORT | NUMBER(38) | NO |  サーバーのSQLポート番号   |
| PROXY_SESSID | NUMBER(38) | YES | 現在のクライアントがODPの場合、この列にODPのSession IDが表示されます   |
| USER_CLIENT_IP | VARCHAR2(46) | YES |  ユーザークライアントのIP   |
| USER_HOST | VARCHAR2(128) | YES |  ユーザークライアントのホスト名   |
| TRANS_ID | NUMBER(38) | NO |  トランザクションID   |
| THREAD_ID | NUMBER(38) | NO |  スレッドID   |
| TRACE_ID | VARCHAR2(64) | YES |  Trace ID   |
| REF_COUNT | NUMBER(38) | NO | 接続参照カウント |
| BACKTRACE | VARCHAR2(16384) | YES | 接続参照呼び出しスタック |
| TRANS_STATE | VARCHAR2(32) | YES |  トランザクションの状態   |
| TOTAL_CPU_TIME | NUMBER(38) | NO | 現在のコマンドの実行CPU使用時間、単位は秒 |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_SESSION WHERE ROWNUM <= 1\G
```
