# V$SQL_WORKAREA_HISTOGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントノード上で、過去にすべてのワークエリアが実行した統計情報を表示します。これには、1MB～2MBの範囲でフルインメモリ処理された回数や、ワンパス処理の回数などが含まれます。

## **フィールドの説明**

|        **フィールド名**        |   **タイプ**   | **NULL許容** |                  **説明**                  |
|------------------------|------------|----------------|------------------------------------------|
| LOW_OPTIMAL_SIZE       | NUMBER | NO             | workareaがoptimalモードで使用する最小メモリ量              |
| HIGH_OPTIMAL_SIZE      | NUMBER | NO             | workareaがoptimalモードで使用する最大メモリ量              |
| OPTIMAL_EXECUTIONS     | NUMBER | NO             | workareaが最低および最高範囲でoptimalモードで実行した回数             |
| ONEPASS_EXECUTIONS     | NUMBER | NO             | workareaが最低および最高範囲でone passモードで実行した回数     |
| MULTIPASSES_EXECUTIONS | NUMBER | NO             | workareaが最低および最高範囲でmulti passesモードで実行した回数 |
| TOTAL_EXECUTIONS       | NUMBER | NO             | workareaの総実行回数                         |
| CON_ID                 | NUMBER | NO             | テナントID                                    |
| SVR_IP                 | VARCHAR2(46)   | NO             | サーバーIPアドレス   |
| SVR_PORT               | NUMBER   | NO             | サーバーポート番号   |

## クエリ例

現在のテナントノード上で、過去にすべてのワークエリアが実行した統計情報を確認し、上位10件のレコードを表示します。

```shell
obclient[SYS]> SELECT * FROM SYS.V$SQL_WORKAREA_HISTOGRAM WHERE ROWNUM<= 10;
```
