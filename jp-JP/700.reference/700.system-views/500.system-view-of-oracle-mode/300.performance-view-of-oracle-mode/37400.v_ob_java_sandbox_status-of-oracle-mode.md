# V$OB_JAVA_SANDBOX_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP4バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントが現在のOBServerノード上で使用しているJava UDFサンドボックスの状態を表示します。これには、サンドボックス世代のライフサイクル、通信チャネルプール、サンドボックスプロセスリソース、サンドボックスJVMリソースなどの情報が含まれます。

使用方法は以下のとおりです：

* 構成パラメータ `ob_enable_java_udf_sandbox` を有効にすると、Java UDFは独立したサンドボックスプロセスで実行されます。各行は1世代（Generation）のサンドボックスに対応し、各世代のサンドボックスは1つのサンドボックスJVMプロセスに対応します。
* このビューには既存のサンドボックスのみが表示され、このビューをクエリしてもサンドボックスの作成はトリガーされません。
* `INSTANCE_COUNT` から `LAST_FORCE_KILL_REASON` まではテナントレベルの集計情報であり、同一テナント内の各行の値は同じです。
* まだ正常に収集できていない、または取得できない指標はNULLとして表示されます。これは、実際の値が `0` の指標と区別するためです。
