# GV$SESSION_WAIT_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$SESSION_WAIT_HISTORY`は、すべてのノード上のすべてのセッションにおける直近10回の待機イベント情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | NUMBER | NO | V4.3.x系バージョンについて：<ul><li> V4.3.5 BP2以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート |
| SEQ# | NUMBER | NO | 待機イベントのシーケンス番号 |
| EVENT# | NUMBER | NO | 待機イベント番号 |
| EVENT | VARCHAR2(64) | NO | 待機イベント名 |
| P1TEXT | VARCHAR2(64) | NO | 待機イベントの第1引数の説明 |
| P1 | NUMBER | NO | 待機イベントの第1引数の値 |
| P2TEXT | VARCHAR2(64) | NO | 待機イベントの第2引数の説明 |
| P2 | NUMBER | NO | 待機イベントの第2引数の値 |
| P3TEXT | VARCHAR2(64) | NO | 待機イベントの第3引数の説明 |
| P3 | NUMBER | NO | 待機イベントの第3引数の値 |
| WAIT_TIME | NUMBER | NO | 待機イベントの待機時間、単位は百分の一秒 |
| WAIT_TIME_MICRO | NUMBER | NO | 待機イベントの待機時間、単位はマイクロ秒 |
| TIME_SINCE_LAST_WAIT_MICRO | NUMBER | NO | 前回の待機終了から現在の待機までの時間、単位はマイクロ秒 |

## クエリ例

すべてのノード上のすべてのセッションにおける直近10回の待機イベント情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSION_WAIT_HISTORY WHERE ROWNUM =1\G
```
