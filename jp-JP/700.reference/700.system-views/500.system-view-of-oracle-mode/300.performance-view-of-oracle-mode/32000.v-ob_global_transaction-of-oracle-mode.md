# V$OB_GLOBAL_TRANSACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノードを元のスケジューラとするすべてのXAトランザクションの情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| FORMATID | NUMBER(38) | NO | トランザクション識別子の形式タイプ |
| GLOBALID | VARCHAR2(256) | NO | グローバルトランザクションのトランザクション識別子 |
| BRANCHID | VARCHAR2(256) | NO | ブランチ限定子 |
| TX_ID | NUMBER(38) | NO | トランザクションID |
| SVR_IP | VARCHAR2(128) | NO | トランザクションスケジューラーが存在するノードのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | トランザクションスケジューラーが存在するノードのポート番号 |
| COORD_LS_ID | NUMBER(38) | NO | コーディネータログストリームID |
| IS_READONLY | VARCHAR2(5) | NO | 読み取り専用トランザクションか |
| STATE | VARCHAR2(12) | NO | このブランチの状態 |
| FLAG | NUMBER(38) | NO | このブランチの状態の数値表現 |
