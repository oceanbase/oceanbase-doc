# V$OB_KVCACHE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上のテナントのKVcache情報を表示します。

## フィールド説明

|      フィールド名      |      型       | NULL許容   |    説明     |
|----------------|---------------|------------|-----------|
| SVR_IP         | VARCHAR2(46)  | NO         | サーバーIPアドレス |
| SVR_PORT       | NUMBER(38)    | NO         | サーバーポート番号    |
| TENANT_ID      | NUMBER(38)    | NO         | テナントID     |
| CACHE_NAME     | VARCHAR2(128) | NO         | CACHEキー名 |
| PRIORITY       | NUMBER(38)    | NO         | 優先順位       |
| CACHE_SIZE     | NUMBER(38)    | NO         | CACHEサイズ  |
| HIT_RATIO      | NUMBER(38,3)  | NO         | 命中率       |
| TOTAL_PUT_CNT  | NUMBER(38)    | NO         | PUT回数    |
| TOTAL_HIT_CNT  | NUMBER(38)    | NO         | 命中回数      |
| TOTAL_MISS_CNT | NUMBER(38)    | NO         | 不命中回数     |

## クエリ例

ユーザーテナントが、現在のOBServerノード上における自身のテナントのKVcache情報をクエリします。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_KVCACHE;
```
