# V$OB_NIC_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_NIC_INFO` は、現在のOBServerノードのNIC情報を表示するために使用されます。主にNICの速度が表示されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | ------- | ------------------- | -------- |
| SVR_IP     | VARCHAR2(46)  | NO   | OBServerのIPアドレス    |
| SVR_PORT   | NUMBER(20)    | NO   | OBServerのRPCポート    |
| DEVNAME    | VARCHAR2(128) | NO   | OBServerが配置されているマシンのNIC名     |
| SPEED_MBPS | NUMBER(20)    | NO   | NIC速度、単位はMbps     |

## クエリ例

現在のOBServerノードのNIC情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_NIC_INFO;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+---------+------------+
| SVR_IP         | SVR_PORT | DEVNAME | SPEED_MBPS |
+----------------+----------+---------+------------+
| xx.xx.xx.xx    |     2882 | eth0    |      10000 |
+----------------+----------+---------+------------+
```
