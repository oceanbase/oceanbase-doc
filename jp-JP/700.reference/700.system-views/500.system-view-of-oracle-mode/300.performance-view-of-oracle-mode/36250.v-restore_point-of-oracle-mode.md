# V$RESTORE_POINT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースV4.x系では、Restore Point機能が現在サポートされていないため、このビューはV4.0.0以降のバージョンから削除されました。</p>
</main>

## 機能の概要

ビュー`V$RESTORE_POINT`は、復元ポイントに関する情報を表示するために使用されます。

|   フィールド名 |                タイプ               | **NULL値を許容するか** |     **説明**     |
|-----------|-----------------------------------|---------------------|--------------------|
| TENANT_ID | NUMBER(38)                        | YES            | テナントID          |
| SCN       | NUMBER(38)                        | NO             | 復元ポイント作成時のデータベースSCN |
| TIME      | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO             | 復元ポイント作成時の時間      |
| NAME      | VARCHAR2(512)                     | YES            | 復元ポイント名          |

## クエリ例

現在のテナント内のすべての復元ポイント情報を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$RESTORE_POINT;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------------+------------------------------+-----------+
| TENANT_ID | SNAPSHOT         | TIME                         | NAME      |
+-----------+------------------+------------------------------+-----------+
|      1002 | 1710987930807517 | 21-MAR-24 10.25.30.808594 AM | RT_ORACLE |
+-----------+------------------+------------------------------+-----------+
1 row in set
```
