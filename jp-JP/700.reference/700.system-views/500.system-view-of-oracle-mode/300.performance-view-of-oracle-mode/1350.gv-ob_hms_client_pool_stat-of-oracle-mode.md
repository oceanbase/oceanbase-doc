# GV$OB_HMS_CLIENT_POOL_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されましたが、機能はまだ有効ではありません。</p>
</main>

## 機能の概要

このビューは、現在のテナントのHMS Catalogクライアントの使用状況を表示するために使用されます。

## フィールドの説明

|    フィールド名     |     型     | NULL許容 |       説明      |
|----------------|--------------|----------------|-----------------|
| SVR_IP         | VARCHAR2(46) | NO             | レプリカが配置されているノードのアドレスを表します。|
| SVR_PORT       | NUMBER(38)   | NO             | レプリカが配置されているノードのポートを表します。|
| TENANT_ID      | NUMBER(38)   | NO             | テナントIDを表します。値は以下のとおりです：<ul><li>1：システムテナントIDを表します。 </li><li>その他の値：ユーザーテナントまたはMetaテナントIDを表します。</li></ul>|
| CATALOG_ID     | NUMBER(38)   | NO             | テナント内の特定のCatalogのIDを表します。|
| TOTAL_CLIENTS  | NUMBER(38)   | NO             | 現在のテナント内の対応するCatalogに作成されたクライアントの合計数を表します。|
| IN_USE_CLIENTS | NUMBER(38)   | NO             | 現在のテナント内の対応するCatalogで使用中のクライアント数を表します。|
| IDLE_CLIENTS   | NUMBER(38)   | NO             | 現在のテナント内の対応するCatalogで使用されていない（アイドル）クライアント数を表します。|
