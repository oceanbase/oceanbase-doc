# V$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上で使用しているメモリ状況を表示します。

## フィールドの説明

| **フィールド名**  |    **タイプ**    | **NULL値を許容するか** | **説明**  |
|-----------|--------------|----------------|---------|
| TENANT_ID | NUMBER(38)   | NO             | テナントID   |
| SVR_IP    | VARCHAR2(46) | NO             | マシンのIPアドレス  |
| SVR_PORT  | NUMBER(38)   | NO             | マシンのポート番号   |
| HOLD      | NUMBER(38)   | NO             | テナントが使用したメモリ、単位はバイト |
| FREE      | NUMBER       | NO             | テナントの残りメモリ、単位はバイト  |

## クエリ例

ユーザーテナントが現在のノード上でのメモリ使用状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_TENANT_MEMORY;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+-----------+------------+
| TENANT_ID | SVR_IP         | SVR_PORT | HOLD      | FREE       |
+-----------+----------------+----------+-----------+------------+
|      1004 | 172.xx.xxx.xxx |     2882 | 748290048 | 4620419072 |
+-----------+----------------+----------+-----------+------------+
1 row in set
```
