# V$OB_KVCACHE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントの現在のOBServerノード上のKVcache情報を表示します。

## フィールドの説明

|      フィールド名      |      タイプ       | NULLを許容するか |    説明     |
|----------------|---------------|------------|-----------|
| SVR_IP         | VARCHAR2(46)  | NO         | サーバーIPアドレス |
| SVR_PORT       | NUMBER(38)    | NO         | サーバーのポート番号 |
| TENANT_ID      | NUMBER(38)    | NO         | テナントID     |
| CACHE_NAME     | VARCHAR2(128) | NO         | Cache項目名 |
| PRIORITY       | NUMBER(38)    | NO         | 優先順位       |
| CACHE_SIZE     | NUMBER(38)    | NO         | Cacheサイズ、単位はバイト  |
| HIT_RATIO      | NUMBER(38,3)  | NO         | 命中率       |
| TOTAL_PUT_CNT  | NUMBER(38)    | NO         | PUT回数    |
| TOTAL_HIT_CNT  | NUMBER(38)    | NO         | 命中回数      |
| TOTAL_miss_CNT | NUMBER(38)    | NO         | ミス回数     |

## クエリ例

ユーザーテナントは、現在のOBServerノード上における自身のテナントのKVcache情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_KVCACHE;
```
