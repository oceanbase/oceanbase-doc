# GV$OB_SS_LOCAL_CACHE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

共有ストレージモードにおいて、現在のテナントが各OBServerノードのローカルキャッシュに保持する各種キャッシュデータの関連指標を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールドの説明

|      フィールド名    |         型          | NULL許容 |                       説明      |
|-----------------|-----------------------|----------------|---------------------------------|
| SVR_IP          | VARCHAR2(46)          | NO             |  OBServerノードのIPアドレス    |
| SVR_PORT        | NUMBER(38)            | NO             |  OBServerノードのポート番号      |
| TENANT_ID       | NUMBER(38)            | NO             |  テナントID                   |
| CACHE_NAME      | VARCHAR2(128)         | NO             |  ローカルキャッシュ内の特定データ種類のキャッシュ名。主に以下の種類が含まれます：<ul><li>`ss_micro_cache`：マイクロブロックキャッシュ</li> <li>`ss_local_cache_tmpfile`：一時ファイルキャッシュ</li> <li>`ss_local_cache_major_macro`：ベースラインマクロブロックキャッシュ</li></ul>    |
| PRIORITY        | bigint(20)            | NO             |  キャッシュ優先度。値が大きいほど優先度が高い。現在このフィールドは使用されておらず、デフォルト値は`0`です     |
| HIT_RATIO       | NUMBER(38,3)          | NO             |  キャッシュヒット率                    |
| TOTAL_HIT_CNT   | NUMBER(38)            | NO             |  キャッシュヒットの総回数               |
| TOTAL_MISS_CNT  | NUMBER(38)            | NO             |  キャッシュミスの総回数             |
| HOLD_SIZE       | NUMBER(38)            | NO             |  キャッシュに格納されているオブジェクトの合計サイズ、単位はバイト    |
| ALLOC_DISK_SIZE | NUMBER(38)            | NO             |  既に割り当てられたディスク容量、単位はバイト    |
| USED_DISK_SIZE  | NUMBER(38)            | NO             |  使用済みディスク容量（ディスク容量が割り当てられているものの、まだ使用されていない場合がある）。単位はバイト    |
| USED_MEM_SIZE   | NUMBER(38)            | NO             |  使用済みメモリ容量、単位はバイト                 |
