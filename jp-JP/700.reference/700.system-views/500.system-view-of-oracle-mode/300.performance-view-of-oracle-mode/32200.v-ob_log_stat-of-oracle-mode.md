# V$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ログストリームPalfの状態を表示します。一般的な使用シナリオは以下のとおりです：

* ログストリームにリーダーが存在するかどうかを照会します（リーダーが存在するレプリカ）。
* ログストリームのメンバーリスト（Paxosレプリカ数）を照会します。
* レプリカ同期状態を照会します。
* ログストリームのログの回収可能なポイントを照会します。
* ログストリームで許可されるログ消費サービスの範囲（LSN/SCNを含む）を照会します。
* Palfのアクセスモードを照会します。

## フィールドの説明

| フィールド名 | タイプ | NULL値を許容するか | 説明 |

| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリームID |

| SVR_PORT | NUMBER(38) | NO | サーバーのポート番号 |

| END_SCN | NUMBER(38) | NO | 最大連続多数派のポイント／最大消費可能なポイント（SCN） |

| LEARNER_LIST | CLOB| NO | 現在のログストリームの読み取り専用レプリカリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
