# GV$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_ACTIVE_SESSION_HISTORY`は、このテナント内のすべてのOBServerノードにおけるアクティブセッション履歴を表示するために使用されます。
