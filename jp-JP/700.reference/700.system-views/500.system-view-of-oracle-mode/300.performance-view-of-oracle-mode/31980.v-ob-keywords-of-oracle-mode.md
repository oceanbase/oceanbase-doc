# V$OB_KEYWORDS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.4.2 BP3バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、外部からのキーワード検索機能を提供するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| KEYWORD | VARCHAR2(128) | NO | キーワード名 |
| LENGTH | NUMBER | NO | キーワードの長さ |
| TYPE | VARCHAR2(16) | NO | キーワードの種類。現在の取り得る値は `SQL` または `PL` のみです |
| RESERVED | NUMBER(38) | NO | 予約語かどうか |

## 使用上の注意

このビューは、特定の文字列がidentifierとして使用できるかどうかをチェックするために使用される可能性があります。しかし、OceanBaseデータベースの現在の実装では、一部の非予約語も実際にはidentifierとして使用できません。

以下の非予約語は、Oracleテナントではidentifierとして使用できません：

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>すべての場合に適用されるわけではありません。例えば、一部のキーワードはテーブルのエイリアスとしては使用できませんが、列名としては使用できます。オブジェクト、テーブル名、列名などidentifierを使用する場面では、これらのキーワードを避けることをお勧めします。</p>
</main>

OracleテナントのSQLモードでは以下のキーワードが使用できません：

* `USING`
* `BULK`
* `COLLATE`
* `CROSS`
* `FULL`
* `INNER`
* `JOIN`
* `LOG`
* `LEFT`
* `NATURAL`
* `RETURN`
* `RIGHT`
* `RETURNING`

OracleテナントのPLモードでは：

* `CHARACTER`
* `CONSTANT`
* `DATE`
* `FLOAT`
* `LOOP`
* `NUMBER`
* `RAW`
* `REAL`
* `VARCHAR`
* `VARCHAR2`

## クエリ例

```shell
obclient > SELECT * FROM SYS.V$OB_KEYWORDS WHERE ROWNUM <= 5;
```

クエリ結果は次のとおりです。

```shell
+---------+--------+------+----------+
| KEYWORD | LENGTH | TYPE | RESERVED |
+---------+--------+------+----------+
| access  |      6 | SQL  |        1 |
| add     |      3 | SQL  |        1 |
| all     |      3 | SQL  |        1 |
| alter   |      5 | SQL  |        1 |
| and     |      3 | SQL  |        1 |
+---------+--------+------+----------+
```
