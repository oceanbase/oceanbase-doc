# GV$OB_PX_P2P_DATAHUB

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

並列実行におけるデータ転送操作に関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート番号 |
| TRACE_ID | CHAR(64) | NO | 対象SQLのTRACE_ID |
| DATAHUB_ID | NUMBER | NO | データのDataHub ID |
| MESSAGE_TYPE | VARCHAR2(256) | NO | データのメッセージタイプ |
| TENANT_ID | NUMBER | NO | 所属テナントID |
| HOLD_SIZE | NUMBER | NO | 物理化されたデータサイズ |
| TIMEOUT_TS | TIMESTAMP(6) | NO | データの予想されるタイムアウト時間 |
| START_TIME | TIMESTAMP(6) | NO | 書き込み開始時刻 |
