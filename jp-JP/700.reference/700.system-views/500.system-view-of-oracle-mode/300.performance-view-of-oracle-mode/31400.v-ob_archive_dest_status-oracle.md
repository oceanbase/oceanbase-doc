# V$OB_ARCHIVE_DEST_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内の各アーカイブ宛先の状態を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| DEST_ID | NUMBER(38) | NO | アーカイブ先ID |
| PATH | VARCHAR2(4096) | NO | アーカイブパス |
| STATUS | VARCHAR2(64) | NO | アーカイブ状態 |
| CHECKPOINT_SCN | NUMBER(38) | NO | アーカイブ済みログの連続チェックポイント |
| SYNCHRONIZED | VARCHAR2(32) | NO | アーカイブがテナントログと同期されているかどうか。<ul><li> `YES`はテナントログと同期されていることを示します。  </li><li> `NO`はテナントログと同期されていないことを示します。 </li></ul>|
| COMMENT | VARCHAR2(262144) | NO | エラーメッセージ |

## クエリ例

ユーザーテナントが自身のテナントにおけるアーカイブ宛先の状態を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_ARCHIVE_DEST_STATUS;
```

クエリ結果は次のとおりです：

```shell
+-----------+---------+----------------------------------------+--------+---------------------+--------------+---------+
| TENANT_ID | DEST_ID | PATH                                   | STATUS | CHECKPOINT_SCN      | SYNCHRONIZED | COMMENT |
+-----------+---------+----------------------------------------+--------+---------------------+--------------+---------+
|      1004 |    1002 | file:///home/admin/oceanbase/arglogorc | DOING  | 1736321349494697000 | NO           |         |
+-----------+---------+----------------------------------------+--------+---------------------+--------------+---------+
1 row in set
```
