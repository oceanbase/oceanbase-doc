# V$OB_TABLET_COMPACTION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_TABLET_COMPACTION_HISTORY` は、TabletレベルのCompactionの履歴情報を表示するために使用されます。

## フィールド説明

|                 フィールド名    |      型       | NULL許容   |         説明          |
|--------------------------------------|---------------|------------|--------|
| SVR_IP                               | VARCHAR2(46)  | NO         | サーバーのIPアドレス                                                                                |
| SVR_PORT                             | NUMBER(38)    | NO         | サーバーのポート番号|
| TENANT_ID                            | NUMBER(38)    | NO         | テナントID |
| LS_ID                                | NUMBER(38)    | NO         | ログストリームID|
| TABLET_ID                            | NUMBER(38)    | NO         | データシャーディングID                                                                                  |
| TYPE                                 | VARCHAR2(64)  | NO         |  Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータや未コミットトランザクションデータは含まれません。</li></ul>    |
| COMPACTION_SCN                              | NUMBER(38)    | NO         | メジャーコンパクションのバージョン：minorはsnapshot_versionを表します                                                            |
| START_TIME                           | TIMESTAMP(6) WITH LOCAL TIME ZONE    | NO         | 開始時間  |
| FINISH_TIME                          | TIMESTAMP(6) WITH LOCAL TIME ZONE    | NO         | 終了時間  |
| OCCUPY_SIZE                          | NUMBER(38)    | NO         | データ量   |
| MACRO_BLOCK_COUNT                    | NUMBER(38)    | NO         | マクロブロック数   |
| MULTIPLEXED_MACRO_BLOCK_COUNT        | NUMBER(38)    | NO         | 再利用マクロブロック数 |
| NEW_MICRO_COUNT_IN_NEW_MACRO         | NUMBER(38)    | NO         | 新規生成マクロブロック内の新規マイクロブロック数                                                                              |
| MULTIPLEXED_MICRO_COUNT_IN_NEW_MACRO | NUMBER(38)    | NO         | 新規生成マクロブロック内の再利用マイクロブロック数                                                                             |
| TOTAL_ROW_COUNT                      | NUMBER(38)    | NO         | 総行数   |
| INCREMENTAL_ROW_COUNT                | NUMBER(38)    | NO         | 新規出力行 |
| COMPRESSION_RATIO                    | NUMBER(38)    | NO         | 新規データの圧縮率：新規マクロブロックデータの圧縮後/圧縮前比率                                                                 |
| PROGRESSIVE_COMPACTION_round         | NUMBER(38)    | NO         | 渐進的メジャーコンパクションのラウンド数。フルコンパクションの場合、この列は-1となります。                                                                  |
| PROGRESSIVE_COMPACTION_NUM           | NUMBER(38)    | NO         | 渐進的メジャーコンパクションの総ラウンド数                                                                                  |
| PARALLEL_DEGREE                      | NUMBER(38)    | NO         | 並列度   |
| PARALLEL_INFO                        | VARCHAR2(512) | NO         | 並列タスク情報。並列タスクがスキャンしたデータ量/実行時間/出力データ量の統計情報(min/max/avg)を表示します                                       |
|MACRO_ID_LIST    |varchar2(256)    |NO   |出力されるマクロブロックリストです。マクロブロックリストが長すぎる場合は表示されません    |
|COMMENTS    |varchar2(256)    |NO   |失敗したCompactionの履歴情報や、今回のCompactionの収集時間などを記録します    |
| START_CG_ID                     | NUMBER(38)   | NO   |  Column GroupのStart ID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| END_CG_ID                       | NUMBER(38)   | NO   |  Column GroupのEnd ID <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>   |
| KEPT_SNAPSHOT                   | VARCHAR2(128)| NO   |  今回のCompactionで選択されたマルチバージョンポイントの保持情報を表示します<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| MERGE_LEVEL                     | VARCHAR2(64) | NO   |  今回の実行時にメジャーコンパクション/マイクロブロックの再利用を使用しているかどうかを表示します<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| EXEC_MODE                       | VARCHAR2(64) | NO   | このメジャーコンパクションTraceのモードを表示します：<ul><li>`EXEC_MODE_LOCAL`：ローカルモード。マクロブロックをローカルディスクに出力します</li> <li>`EXEC_MODE_VALIDATE`：共有モード。Checksumのみを計算し、マクロブロックは出力しません。現在のバージョンではこのモードはサポートされていません。</li> <li>`EXEC_MODE_OUTPUT`：共有モード。マクロブロックを共有ストレージに出力します。現在のバージョンではこのモードはサポートされていません。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| IS_FULL_MERGE                   | VARCHAR2(5)  | NO   | フルコンパクションかどうか。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| IO_COST_TIME_PERCENTAGE         | NUMBER(38)   | NO   | IO時間がメジャーコンパクション時間に占める割合。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| MERGE_REASON                    | VARCHAR2(32) | NO   | メジャーコンパクションが開始された理由。値は以下のとおりです：<ul><li>`LOAD_DATA_SCENE`：データロードシナリオ</li> <li>`TOMBSTONE_SCENE`：Tombstoneシナリオ</li> <li>`INEFFICIENT_QUERY`：スロークエリシナリオ</li> <li>`FREQUENT_WRITE`：頻繁な書き込みシナリオ</li> <li>`TENANT_MAJOR`：テナントレベルのメジャーコンパクション</li> <li>`USER_REQUEST`：ユーザーが開始したメジャーコンパクション</li> <li>`REBUILD_COLUMN_GROUP`：行から列への変換シナリオ</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| BASE_MAJOR_STATUS               | VARCHAR2(64) | NO   | メジャーコンパクション前のMajor SSTableのタイプ：<ul><li>`COL_WITH_ALL`：定義時は行列混合テーブル、ベースラインデータは行列混合</li> <li>`COL_ONLY_ALL`：定義時は行列混合テーブル、ベースラインデータは自動最適化により行ストアのみ保存</li> <li>`PURE_COL`：定義時は純粋なカラムストアテーブル、ベースラインデータは純粋なカラムストア</li> <li>`PURE_COL_ONLY_ALL`：定義時は純粋なカラムストアテーブル、ベースラインデータは自動最適化により行ストアのみ保存</li> <li>`ROW_STORE_MAJOR`：行ストアテーブル</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main>|
| CO_MERGE_TYPE                   | VARCHAR2(64) | NO   | カラムストアのメジャーコンパクションタイプ：<ul><li>`BUILD_COLUMN_STORE_MERGE`：カラムストアにコンパクション</li> <li>`BUILD_ROW_STORE_MERGE`：行ストアにコンパクション</li> <li>`USE_RS_BUILD_SCHEMA_MATCH_MERGE`：スキーマが一致するストレージタイプにコンパクション</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| MDS_FILTER_INFO                 | VARCHAR2(1024) | NO | メジャーコンパクションで使用されるMDSフィルター情報を表示します <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5バージョンから導入され、V4.3.5 BP2バージョンから有効になります。</p></main> |
| EXECUTE_TIME                    | NUMBER(38)     | NO | メジャーコンパクションタスクが消費したCPU時間。単位はマイクロ秒です  |
