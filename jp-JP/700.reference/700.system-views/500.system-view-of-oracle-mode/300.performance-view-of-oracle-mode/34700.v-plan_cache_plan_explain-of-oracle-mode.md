# V$OB_PLAN_CACHE_PLAN_EXPLAIN

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_PLAN_CACHE_PLAN_EXPLAIN`は、現在のOBServerノードにキャッシュされている計画キャッシュ内の物理実行計画を表示するために使用されます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>このビューはGet操作のみをサポートしており、クエリ時には <code>TENANT_ID</code> と <code>PLAN_ID</code> フィールドを指定する必要があります。</p>
  </main>

## フィールドの説明

|   **フィールド名**   |     **タイプ**     | **NULL値を許容するか** |      **説明**      |
|--------------|----------------|----------------|------------------|
| TENANT_ID    | NUMBER(38)     | NO             | テナントID            |
| SVR_IP       | VARCHAR2(46)   | NO             | サーバーIPアドレス        |
| SVR_PORT     | NUMBER(38)     | NO             | サーバーのポート番号           |
| PLAN_ID      | NUMBER(38)     | NO             | プランのID           |
| PLAN_DEPTH   | NUMBER(38)     | NO             | Operator表示時の深さ |
| PLAN_LINE_ID | NUMBER(38)     | NO             | Operatorの番号     |
| OPERATOR     | VARCHAR2(128)  | NO             | Operatorの名前     |
| NAME         | VARCHAR2(256)  | NO             | テーブル名             |
| ROWS         | NUMBER(38)     | NO             | 予想される結果行数          |
| COST         | NUMBER(38)     | NO             | 予想されるコスト            |
| PROPERTY     | VARCHAR2(4096) | NO             | 対応するOperatorの情報  |

## クエリ例

現在のOBServerノードにキャッシュされている計画キャッシュ内の物理実行計画を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PLAN_CACHE_PLAN_EXPLAIN WHERE ROWNUM <= 1;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+---------+------------+--------------+-----------+------+------+------+----------+
| TENANT_ID | SVR_IP         | SVR_PORT | PLAN_ID | PLAN_DEPTH | PLAN_LINE_ID | OPERATOR  | NAME | ROWS | COST | PROPERTY |
+-----------+----------------+----------+---------+------------+--------------+-----------+------+------+------+----------+
|      1004 |   xx.xx.xx.xx  |     2882 |    2012 |          0 |            0 | PHY_LIMIT | NULL |    1 |  105 | NULL     |
+-----------+----------------+----------+---------+------------+--------------+-----------+------+------+------+----------+
1 row in set (0.008 sec)
```
