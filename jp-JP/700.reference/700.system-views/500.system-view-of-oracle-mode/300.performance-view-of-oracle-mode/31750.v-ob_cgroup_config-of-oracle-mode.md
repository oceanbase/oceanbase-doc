# V$OB_CGROUP_CONFIG

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.0バージョンから導入されました。</li>
<li>V4.2.1系では、このビューはV4.2.1 BP2バージョンから導入されました。V4.2.x系の他のバージョンでは、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

`V$OB_CGROUP_CONFIG` ビューは、現在のOBServerノードのcgroup設定を簡単に照会するために使用されます。ビューのフィールド情報は、OBServerノードのインストールディレクトリ配下のcgroupディレクトリ（例：`/home/admin/oceanbase/cgroup`）から取得します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | OBServerのIPアドレス|
| SVR_PORT | NUMBER(38) | NO | OBServerのポート番号|
| CFS_QUOTA_US | NUMBER(38) | NO | スレッドのCPU時間スライス。単位はマイクロ秒です。このフィールドの情報は、pathディレクトリ配下の `cpu.cfs_quota_us` ファイルから取得します |
| CFS_PERIOD_US | NUMBER(38) | NO | cgroupの制御周期時間。単位はマイクロ秒です。Quotaと組み合わせて使用します。このフィールドの情報は、pathディレクトリ配下の `cpu.cfs_period_us` ファイルから取得します  |
| SHARES | NUMBER(38) | NO | スレッドのCPU利用率（CPUが満載の場合にのみ有効）。このフィールドの情報は、pathディレクトリ配下の `cpu.shares` ファイルから取得します |
| CGROUP_PATH | VARCHAR2(256) | NO | OBServerのcgroup設定ディレクトリのパス |

## クエリ例

ユーザーテナント内で、現在のOBServerノードのcgroup設定を照会します。

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.V$OB_CGROUP_CONFIG;
```
