# V$OB_LS_REPLICA_TASK_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0から導入されました。</p>
</main>

## 機能の概要

現在生成すべきすべてのタスク（既に生成済みのものと未生成のものを含む）を表示します。

## フィールドの説明

| フィールド名                 | 型           |  NULL許容 |   説明                             |
|-------------------------|----------------|-----------------|------------------------------------|
| LS_ID                   | NUMBER(38)     | NO              | ログストリームID                          |
| TASK_TYPE               | VARCHAR2(64)   | NO              | タスクタイプ。値は以下のとおりです。<ul><li>`MIGRATE REPLICA`：レプリカの移行</li><li>`ADD REPLICA`：レプリカの追加</li> <li>`REMOVE PAXOS REPLICA`：レプリカの削除</li> <li>`MODIFY PAXOS REPLICA NUMBER`：法定レプリカ数の変更</li></ul>|
| PRIORITY                | CHAR(5)        | NO              | タスクの優先順位。値は以下のとおりです。<ul><li>`LOW`：低優先順位タスク。移行タスクのみが低優先順位になる場合があります</li><li>`HIGH`：高優先順位タスク</li></ul>|
| TARGET_REPLICA_SVR_IP   | VARCHAR2(46)   | YES             | 対象レプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT | NUMBER(38)     | YES             | 対象レプリカが存在するマシンのポート番号 |
| TARGET_PAXOS_REPLICA_NUMBER | NUMBER(38) | YES             | 対象レプリカの法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE     | VARCHAR2(16)   | YES             | 対象レプリカタイプ |
| SOURCE_REPLICA_SVR_IP   | VARCHAR2(46)   | YES             | ソースレプリカが存在するマシンのIPアドレス</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLとして表示されます。 |
| SOURCE_REPLICA_SVR_PORT | NUMBER(38)     | YES             | ソースレプリカが存在するマシンのポート番号</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、0として表示されます。 |
| SOURCE_PAXOS_REPLICA_NUMBER | NUMBER(38) | YES             | ソースレプリカの法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE     | VARCHAR2(16)   | YES             | ソースレプリカタイプ</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLとして表示されます。 |
| TASK_EXEC_SVR_IP        | VARCHAR2(46)   | YES             | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT      | NUMBER(38)     | YES             | タスク実行マシンのポート番号 |
| COMMENT                 | VARCHAR2(2048) | YES             | タスク生成理由の備考 |
| CONFIG_VERSION          | VARCHAR2(128)   | YES             | ディザスタリカバリタスク実行時のclog層のconfig_version情報を記録 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0から導入されました。</p></main>  |
