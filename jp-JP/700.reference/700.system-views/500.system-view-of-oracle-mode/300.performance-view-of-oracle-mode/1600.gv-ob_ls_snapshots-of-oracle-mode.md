# GV$OB_LS_SNAPSHOTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_LS_SNAPSHOTS` は、すべてのUnitに永続的に保存されたログストリームスナップショットの情報を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| SNAPSHOT_ID | NUMBER(38) | NO | スナップショットID |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| SVR_IP | VARCHAR2(46) | NO | ログストリームが存在するサーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | ログストリームが存在するサーバーのポート番号 |
| META_EXISTED | VARCHAR2(3) | NO | スナップショットのメタ情報がUnitに保存されているかどうか（YES/NO） |
| BUILD_STATUS | VARCHAR2(10) | NO | スナップショットの作成状態 |
| REBUILD_SEQ_START | NUMBER(38) | YES | スナップショット作成開始時のログストリームのREBUILD SEQ（Sequence） |
| REBUILD_SEQ_END | NUMBER(38) | YES | スナップショット作成終了時のログストリームのREBUILD SEQ（Sequence） |
| END_INTERVAL_SCN | NUMBER(38) | YES | 再生終了SCNポイント |
| LS_META_PACKAGE | CLOB | YES | 再生開始ポイントに対応するログストリームのメタデータ |
| TSNAP_IS_RUNNING | VARCHAR2(3) | NO | 対応するテナントのスナップショットが実行中かどうか（YES/NO） |
| TSNAP_HAS_UNFINISHED_CREATE_DAG | VARCHAR2(3) | NO | 対応するテナントのスナップショットで未完了のCreateタスクがあるかどうか（YES/NO） |
| TSNAP_HAS_UNFINISHED_GC_DAG | VARCHAR2(3) | NO | 対応するテナントのスナップショットで未完了のGCタスクがあるかどうか（YES/NO） |
| TSNAP_CLONE_REF | NUMBER(38) | YES | 対応するテナントのスナップショットのクローンタスク数 |
| TSNAP_META_EXISTED | VARCHAR2(3) | NO | 対応するテナントのスナップショットのメタ情報がUnitに保存されているかどうか（YES/NO） |

## クエリ例
