# GV$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべてのノード上でのTabletレベルCompactionの進捗情報を表示します。

## フィールド説明

|             フィールド名             |                型                 | NULL許容 |                                            説明                                            |
|------------------------------|-----------------------------------|------------|--------|
| SVR_IP                       | VARCHAR2(46)                      | NO         | サーバーのIPアドレス                                                                                |
| SVR_PORT                     | NUMBER(38)                        | NO         | サーバーのポート番号|
| TENANT_ID                    | NUMBER(38)                        | NO         | テナントID |
| TYPE                         | VARCHAR2(64)                      | NO         | Compactionのタイプ <ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのマージ</li> <li>`MEDIUM_MERGE`：パーティションレベルのマージ</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータや未コミットトランザクションデータは含まれません。</li></ul>     |
| LS_ID                        | NUMBER(38)                        | NO         | ログストリームID|
| TABLET_ID                    | NUMBER(38)                        | NO         | データシャーディングID                                                                                  |
| COMPACTION_SCN                      | NUMBER(38)                        | NO         | マージバージョン情報|
| TASK_ID                      | VARCHAR2(64)                      | NO         | 実行中のTrace                                                                                |
| STATUS                       | VARCHAR2(15)                      | NO         | タスク状態  |
| DATA_SIZE                    | NUMBER(38)                        | NO         | Compactionが必要な総データ量（バイト単位）  |
| UNFINISHED_DATA_SIZE         | NUMBER(38)                        | NO         | 未完了Compactionのデータ量、単位はバイト  |
| PROGRESSIVE_COMPACTION ROUND | NUMBER(38)                        | NO         | 渐進的マージのラウンド数|
| CREATE_TIME                  | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | タスク作成時間|
| START_TIME                   | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME        | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 予定完了時間|
| START_CG_ID                  | NUMBER(38)                        | NO         | Column GroupのStart ID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0から導入されました。</p></main>    |
| END_CG_ID                    | NUMBER(38)                        | NO         | Column GroupのEnd ID <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0から導入されました。</p></main>   |
