# GV$SESSION_WAIT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべてのOBServerノード上のすべてのセッションについて、現在または前回の待機イベントの情報を表示します。これには、待機イベント名や待機時間などが含まれます。

## フィールドの説明

| **フィールド名** | **タイプ** | NULLを許容するか | **説明** |
| --- | --- | --- | --- |
| SID | NUMBER | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>このフィールドは、すべての接続方式（直接接続モード/ODPモード）において、Server Session IDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul> |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーのポート番号 |
| EVENT | VARCHAR2(64) | NO | 待機中のイベント名 |
| P1TEXT | VARCHAR2(64) | NO | 待機中のイベントの第1引数の説明 |
| P1 | NUMBER | NO | 待機中のイベントの第1引数の値 |
| P2TEXT | VARCHAR2(64) | NO | 待機中のイベントの第2引数の説明 |
| P2 | NUMBER | NO | 待機中のイベントの第2引数の値 |
| P3TEXT | VARCHAR2(64) | NO | 待機中のイベントの第3引数の説明 |
| P3 | NUMBER(38) | NO | 待機中のイベントの第3引数の値 |
| WAIT_CLASS_ID | NUMBER | NO | 待機中のイベントのカテゴリID |
| WAIT_CLASS# | NUMBER | NO | 待機中のイベントのカテゴリ番号 |
| WAIT_CLASS | VARCHAR2(64) | NO | 待機中のイベントのカテゴリ名 |
| STATE | VARCHAR2(19) | NO | 現在の待機中のイベントの状態。4種類の状態が含まれます：<ul><li>Waiting：Sessionがこのイベントを待機中</li> <li>Waited unknown time：timed_statistics値がfalseに設定されているため、時間情報を取得できません。待機が発生しましたが、時間は非常に短いことを示します</li><li>Wait short time：待機が発生しましたが、時間が非常に短く、1時間単位を超えないため、記録されません</li><li>Waited known time：Sessionが待機して必要なリソースを取得した場合、waitingからこの状態に移行します</li></ul> |
| WAIT_TIME_MICRO | NUMBER | NO | 待機時間。単位はマイクロ秒です。現在待機中である場合、既に待機している時間を表します。現在待機していない場合、最後の待機の合計待機時間を表します |
| TIME_REMAINING_MICRO | NUMBER | NO |<ul><li>> 0：最後の待機時間。単位：マイクロ秒。現在待機状態ではありません</li><li>0：Sessionが現在のイベントを待機中</li><li>-1：最後の待機時間が1統計単位未満。現在待機状態ではありません</li><li>-2：時間統計状態が利用可能に設定されていない。現在待機状態ではありません</li></ul> |
| TIME_SINCE_LAST_WAIT_MICRO | NUMBER | NO | 前回の待機終了から現在までの時間。単位はマイクロ秒です。現在待機中である場合、その値は0です |

## クエリ例

ユーザーテナント内で、現在または前回の待機イベントの詳細情報をすべてのノードに対して確認し、上位2件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SESSION_WAIT WHERE ROWNUM <=2\G
```
