# GV$OB_TABLET_COMPACTION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`GV$OB_TABLET_COMPACTION_HISTORY` ビューは、TabletレベルのCompactionの履歴情報を表示するために使用されます。

## フィールド説明

|                 フィールド名    |      型           | NULL許容   |    説明       |
|--------------------------------------|---------------|------------|--------|
| SVR_IP                               | VARCHAR2(46)  | NO         | サーバーのIPアドレス                                                                 |
| SVR_PORT                             | NUMBER(38)    | NO         | サーバーのポート番号 |
| TENANT_ID                            | NUMBER(38)    | NO         | テナントID |
| LS_ID                                | NUMBER(38)    | NO         | ログストリームID |
| TABLET_ID                            | NUMBER(38)    | NO         | データシャーディングID                                                                 |
| TYPE                                 | VARCHAR2(64)  | NO         | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのマージ</li> <li>`MEDIUM_MERGE`：パーティションレベルのマージ</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>   |
| COMPACTION_SCN                              | NUMBER(38)    | NO         | マージバージョン：minorはsnapshot_version                                                            |

| FINISH_TIME                          | TIMESTAMP(6) WITH LOCAL TIME ZONE    | NO         | 終了時間  |
| OCCUPY_SIZE                          | NUMBER(38)    | NO         | データ量   |
| MACRO_BLOCK_COUNT                    | NUMBER(38)    | NO         | マクロブロック数   |

| TOTAL_ROW_COUNT                      | NUMBER(38)    | NO         | 総行数   |
| INCREMENTAL_ROW_COUNT                | NUMBER(38)    | NO         | 新規出力行 |
| COMPRESSION_RATIO                    | NUMBER(38)    | NO         | 新規データの圧縮率：新規マクロブロックデータの圧縮後／圧縮前比率                                                                 |
| PROGRESSIVE_COMPACTION_round         | NUMBER(38)    | NO         | 減算メジャーコンパクションのラウンド数。フルコンパクションの場合はこの列は-1を返します。                                                                  |

| PARALLEL_DEGREE                      | NUMBER(38)    | NO         | 並列度   |
| PARALLEL_INFO                        | VARCHAR2(512) | NO         | 並列タスク情報。並列タスクがスキャンしたデータ量・実行時間・出力データ量の統計情報(min/max/avg)を表示します                                       |
|MACRO_ID_LIST    |varchar2(256)    |NO   |出力されるマクロブロックリストです。マクロブロックリストが長すぎる場合は表示しません    |
|COMMENTS    |varchar2(256)    |NO   |失敗したことのあるCompactionの履歴情報や、今回のCompactionでの処理時間などの収集情報を記録します    |
| START_CG_ID                     | NUMBER(38)   | NO   |  Column Group の Start ID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| END_CG_ID                       | NUMBER(38)   | NO   |  Column Group の End ID <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>   |
| KEPT_SNAPSHOT                   | VARCHAR2(128)| NO   |  今回のCompactionで選択されたマルチバージョンポイントの保持情報を表示します<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| MERGE_LEVEL                     | VARCHAR2(64) | NO   |  この実行でメジャーコンパクション/マイクロブロックの再利用が使用されたかどうかを示します<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| EXEC_MODE                       | VARCHAR2(64) | NO   | このメジャーコンパクショントレースのモードを示します：<ul><li>`EXEC_MODE_LOCAL`：ローカルモード。マクロブロックをローカルディスクに出力します</li> <li>`EXEC_MODE_VALIDATE`：共有モード。チェックサムを計算するだけで、マクロブロックは出力しません。現在のバージョンではこのモードはサポートされていません。</li> <li>`EXEC_MODE_OUTPUT`：共有モード。マクロブロックを共有ストレージに出力します。現在のバージョンではこのモードはサポートされていません。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| IS_FULL_MERGE                   | VARCHAR2(5)  | NO   | 完全メジャーコンパクションかどうかを示します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| IO_COST_TIME_PERCENTAGE         | NUMBER(38)   | NO   | IO時間がメジャーコンパクション時間に占める割合。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| MERGE_REASON                    | VARCHAR2(32) | NO   | メジャーコンパクションの開始理由。値は以下のとおりです：<ul><li>`LOAD_DATA_SCENE`：データロードシナリオ</li> <li>`TOMBSTONE_SCENE`：タンボストーンシナリオ</li> <li>`INEFFICIENT_QUERY`：スロークエリシナリオ</li> <li>`FREQUENT_WRITE`：頻繁な書き込みシナリオ</li> <li>`TENANT_MAJOR`：テナントレベルのメジャーコンパクション</li> <li>`USER_REQUEST`：ユーザー発信のメジャーコンパクション</li> <li>`REBUILD_COLUMN_GROUP`：行から列への変換シナリオ</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| BASE_MAJOR_STATUS               | VARCHAR2(64) | NO   | メジャーコンパクション前のMajor SSTableのタイプ：<ul><li>`COL_WITH_ALL`：定義時は行と列のハイブリッドテーブル、ベースラインデータは行と列のハイブリッド</li> <li>`COL_ONLY_ALL`：定義時は行と列のハイブリッドテーブル、ベースラインデータは自動最適化で行ストアのみ保存</li> <li>`PURE_COL`：定義時は純粋な列指向テーブル、ベースラインデータは純粋な列指向</li> <li>`PURE_COL_ONLY_ALL`：定義時は純粋な列指向テーブル、ベースラインデータは自動最適化で行ストアのみ保存</li> <li>`ROW_STORE_MAJOR`：行ストアテーブル</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main>|
| CO_MERGE_TYPE                   | VARCHAR2(64) | NO   | カラムストアのマージタイプ：<ul><li>`BUILD_COLUMN_STORE_MERGE`：カラムストアにマージする</li> <li>`BUILD_ROW_STORE_MERGE`：行ストアにマージする</li> <li>`USE_RS_BUILD_SCHEMA_MATCH_MERGE`：スキーマが一致するストレージタイプにマージする</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| MDS_FILTER_INFO                 | VARCHAR2(1024) | NO | マージで使用されたMDSフィルター情報を表示します <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入され、有効になります。</li><li>V4.3.5系では、このフィールドはV4.3.5バージョンから導入され、V4.3.5 BP2バージョンから有効になります。</li></ul></main> |
| EXECUTE_TIME                    | NUMBER(38)     | NO | マージタスクが消費したCPU時間。単位はミリ秒です。  |
