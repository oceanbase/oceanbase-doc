# V$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ログストリームPalfの状態を表示します。一般的なユースケースは以下のとおりです：

* ログストリームにリーダーが存在するかどうか（リーダーが存在するレプリカ）を確認する。
* ログストリームのメンバーリスト（Paxosレプリカ数）を確認する。
* レプリカの同期状態を確認する。
* ログストリームのログで回収可能なポイントを確認する。
* ログストリームがログ消費サービスを提供できる範囲（LSN/SCNを含む）を確認する。
* Palfのアクセスモードを確認する。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| SVR_IP | VARCHAR2(46) | NO | サーバーIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート番号 |
| ROLE | VARCHAR2(32) | NO | レプリカロール：<ul><li>LEADER</li><li>FOLLOWER </li></ul>|
| PROPOSAL_ID | NUMBER(38) | NO | PaxosのProposal ID |
| CONFIG_VERSION | VARCHAR2(128) | NO | 構成変更に対応するバージョン番号（例：メンバーリストの変更、レプリカ数の変更、アクセスモードの変更など） |
| ACCESS_MODE | VARCHAR2(32) | NO | アクセスモード：<ul><li>APPEND</li><li>RAW_WRITE</li></ul> |
| PAXOS_MEMBER_LIST | VARCHAR2(1024) | NO | Paxosメンバーリスト |
| PAXOS_REPLICA_NUM | NUMBER(38) | NO | Paxosレプリカ数 |

| BASE_LSN | NUMBER(38) | NO | 最大回収可能リトリーブポイント |
| BEGIN_LSN | NUMBER(38) | NO | 最小消費可能リトリーブポイント(LSN) |

| END_LSN | NUMBER(38) | NO | 最大連続多数派のポイント/最大消費可能リトリーブポイント(LSN) |
| END_SCN | NUMBER(38) | NO | 最大連続多数派のポイント/最大消費可能リトリーブポイント(SCN) |
| MAX_LSN | NUMBER(38) | NO | 最大書き込みポイント(LSN) |
| MAX_SCN | NUMBER(38) | NO | 最大書き込みポイント(SCN) |
| ARBITRATION_MEMBER | VARCHAR2(128)    | NO | 仲裁メンバーのサーバーアドレス <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0バージョンから導入されました。</p></main> |

| LEARNER_LIST | CLOB| NO | 現在のログストリームの読み取り専用レプリカリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
