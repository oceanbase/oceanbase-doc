# V$OB_PLAN_CACHE_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上で持つプランキャッシュ全体の状態を表示します。

## **フィールド説明**

|   **フィールド名**   |    **タイプ**    | **NULL許容** |              **説明**               |
|--------------|--------------|----------------|-----------------------------------|
| SVR_IP       | VARCHAR2(46) | NO             | サーバーのIPアドレス                        |
| SVR_PORT     | NUMBER(38)   | NO             | ポート番号                               |
| SQL_NUM      | NUMBER(38)   | NO             | plan_cacheに関連するSQL文数              |
| MEM_USED     | NUMBER(38)   | NO             | plan_cacheで使用されているメモリ                |
| MEM_HOLD     | NUMBER(38)   | NO             | plan_cacheが保持しているメモリ                  |
| ACCESS_COUNT | NUMBER(38)   | NO             | plan_cacheへのクエリアクセス回数                 |
| HIT_COUNT    | NUMBER(38)   | NO             | plan_cacheへのヒット回数                 |
| HIT_RATE     | NUMBER(38)   | NO             | plan_cacheのヒット率                   |
| PLAN_NUM     | NUMBER(38)   | NO             | プランの数                          |
| MEM_LIMIT    | NUMBER(38)   | NO             | plan_cacheのメモリ上限、単位はバイト                  |
| HASH_BUCKET  | NUMBER(38)   | NO             | plan_cache hash map内のBucket数 |
| STMTKEY_NUM  | NUMBER(38)   | NO             | plan_cache内のstmt_key数         |

## クエリ例

ユーザーテナント内で、現在のノード上のテナントのプランキャッシュ全体の状態を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PLAN_CACHE_STAT;
```
