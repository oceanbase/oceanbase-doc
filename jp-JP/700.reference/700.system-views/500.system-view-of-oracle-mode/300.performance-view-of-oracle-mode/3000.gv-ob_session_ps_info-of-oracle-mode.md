# GV$OB_SESSION_PS_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_SESSION_PS_INFO`は、現在のテナント内のすべてのセッションで開いているPS情報の表示に使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
| ------------ | -------- | ------------------- | -------- |
| SVR_IP             | VARCHAR2(46) | NO | OBServer IP |
| SVR_PORT           | NUMBER(38)   | NO | OBServer PORT |
| TENANT_ID          | NUMBER(38)   | NO | テナントID |
| PROXY_SESSION_ID   | NUMBER(38)   | NO | ODP内のセッションID |
| SESSION_ID         | NUMBER(38)   | NO | V4.2.x系の場合：<ul><li>V4.2.5 BP4以前のバージョン：<br>すべての接続方式（ダイレクトモード/ODPモード）において、このフィールドはServerセッションIDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODP内のパラメータ<code>client_session_id_version = 2</code>が設定されている場合、このフィールドはClientセッションIDを表します。</li><li><code>client_session_id_version = 1</code>の場合、このフィールドはServerセッションIDを表します。</li></ul></ul></li></ul>   |
| PS_CLIENT_STMT_ID  | NUMBER(38)   | NO | クライアントからPrepareリクエストが送信された後、クライアントに返されるPS ID |
| PS_INNER_STMT_ID   | NUMBER(38)   | NO | OBServer内の内部PS ID (PS Cache内のPS ID) |
| STMT_TYPE          | VARCHAR2(256)| NO | Prepare文のステートメントタイプ。値は`T_SELECT`、`T_INSERT`、`T_REPLACE`、`T_DELETE`、`T_UPDATE`、`T_MERGE`、`T_EXPLAIN`、`T_CREATE_TABLE`、`T_DROP_TABLE`などです。 |
| PARAM_COUNT        | NUMBER(38)   | NO | PSのパラメータ数 |
| PARAM_TYPES        | CLOB         | NO | パラメータタイプリスト。Prepare文のすべてのパラメータのタイプリスト。各パラメータタイプは数字で表され、異なるパラメータタイプ間は英数字カンマで区切ります。 |
| REF_COUNT          | NUMBER(38)   | NO | `ps_session_info_` の参照カウント。`ps_session_info_` はセッション上のプロパティであり、セッションが1つのステートメントをPrepareした後、そのセッション上には`ps_session_info_`が存在します。 |
| CHECKSUM           | NUMBER(38)   | NO | PS Cache内でのパラメータ化後のSQL文字列のチェックサム |

## クエリ例

現在のテナントで、すべてのセッションが開いているPS情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_SESSION_PS_INFO;
```

クエリ結果は次のとおりです：

```shell
+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+

+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+
| xx.xx.xx.xx   |    17119 |      1010 |                0 | 3221625481 |                 1 |                3 | T_SELECT  |           3 | 3, 15, 5    |         1 | 1817423648 |
+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+
```
