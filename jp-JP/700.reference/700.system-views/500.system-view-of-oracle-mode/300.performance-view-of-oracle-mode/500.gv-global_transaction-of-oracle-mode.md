# GV$GLOBAL_TRANSACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上で現在アクティブなグローバルトランザクションの情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|   フィールド名    |     **タイプ**   | **NULLを許容するか** |             **説明**              |
|--------------|----------------|----------------|-----------------------------------|
| FORMATID     | NUMBER(38)     | NO             | グローバルトランザクションのフォーマット識別子                      |
| SVR_IP       | VARCHAR2(128)  | NO             | サーバーIP                          |
| SVR_PORT     | NUMBER(38)     | NO             | サーバーのポート番号                          |
| GLOBALID     | VARCHAR2(256 ) | NO             | グローバルトランザクションの識別子                        |
| BRANCHID     | VARCHAR2(256 ) | NO             | グローバルトランザクションのブランチ資格                       |
| BRANCHES     | NUMBER(38)     | NO             | グローバルトランザクション内のブランチの総数                    |
| REFCOUNT     | NUMBER(38)     | NO             | グローバルトランザクションの同級数、ブランチと同じでなければならない              |
| PREPARECOUNT | NUMBER         | NO             | 準備済みのグローバルトランザクションのブランチ数                   |
| STATE        | CHAR(6)        | NO             | グローバルトランザクションのブランチの状態：<ul><li>ACTIVE   </li><li> COLLECTING   </li><li> FINALIZED   </li><li> FAILED   </li><li> RECOVERING   </li><li> UNASSOCIATED   </li><li> FORGOTTEN   </li><li> READY FOR RECOVERY   </li><li> NO-READONLY FAILED   </li><li> SIBLING INFO WRITTEN   </li><li> \[ORACLE COORDINATED\]ACTIVE   </li><li> \[ORACLE COORDINATED\]COLLECTING   </li><li> \[ORACLE COORDINATED\]FINALIZED   </li><li> \[ORACLE COORDINATED\]FAILED   </li><li> \[ORACLE COORDINATED\]RECOVERING   </li><li> \[ORACLE COORDINATED\]UNASSOCIATED   </li><li> \[ORACLE COORDINATED\]FORGOTTEN   </li><li> \[ORACLE COORDINATED\]READY FOR RECOVERY   </li><li> \[ORACLE COORDINATED\]NO-READONLY FAILED   </li><li> \[MULTINODE\]ACTIVE   </li><li> \[MULTINODE\]COLLECTING   </li><li> \[MULTINODE\]FINALIZED   </li><li> \[MULTINODE\]FAILED   </li><li> \[MULTINODE\]RECOVERING   </li><li> \[MULTINODE\]UNASSOCIATED   </li><li> \[MULTINODE\]FORGOTTEN   </li><li> \[MULTINODE\]READY FOR RECOVERY   </li><li> \[MULTINODE\]NO-READONLY FAILED   </li><li> \[MULTINODE\]SIBLING INFO WRITTEN   </li><li> COMBINATION </li></ul>   |
| FLAGS        | NUMBER         | NO             | ステータスの数値表現                         |
| COUPLING     | CHAR(15)       | NO             | ブランチがFREE、LOOSELY COUPLED、またはTIGHTLY COUPLEDであることを示す                                                         |
| CON_ID       | VARCHAR2(256)  | NO             | テナントID                           |
