# V$OB_TIMESTAMP_SERVICE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントのGTSサービスにおけるGTS/STS値、クロックサービスが配置されているノード情報、およびクロックソースのタイプを表示します。

* データベースによって以下のように区別されます：

  * プライマリデータベースの場合、現在割り当てられているGTS値が表示されます。
  * スタンバイデータベースの場合、現在読み取り可能なポイント（STS）値が表示されます。

* テナントによって以下のように区別されます：

  * システムテナントでは、すべてのテナントのクロックを確認できます。
  * ユーザーテナントでは、自身のテナントのクロックのみを確認できます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID <ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>|
| TS_TYPE | VARCHAR2(100) | NO | クロックソースタイプ <ul><li>GTS：プライマリデータベースのクロック </li><li>STS：スタンバイデータベースのクロック </li></ul>|
| TS_VALUE | NUMBER(38) | NO | メモリに格納されている現在のクロック |
| SVR_IP | VARCHAR2(46) | NO | クロックサービスが属するノードのアドレス |
| SVR_PORT | NUMBER(38) | NO | クロックサービスが属するノードのポート番号 |

## クエリ例

ユーザーテナントで、自身のテナントのGTS/STS、クロックサービスが配置されているノード情報、およびクロックソースのタイプを確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_TIMESTAMP_SERVICE;
```

クエリ結果は次のとおりです：

```shell
+-----------+---------+---------------------+----------------+----------+
| TENANT_ID | TS_TYPE | TS_VALUE            | SVR_IP         | SVR_PORT |
+-----------+---------+---------------------+----------------+----------+
|      1004 | GTS     | 1742974578234478001 | 11.xxx.xxx.xxx |    28825 |
+-----------+---------+---------------------+----------------+----------+
1 row in set
```
