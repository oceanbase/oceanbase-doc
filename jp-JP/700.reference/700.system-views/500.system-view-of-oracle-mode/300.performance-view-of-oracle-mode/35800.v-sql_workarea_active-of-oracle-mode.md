# V$SQL_WORKAREA_ACTIVE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在ノード上でアクティブなOperatorのワークエリア情報を表示します。

## **フィールド説明**

|     **フィールド名**     |    **型**    | **NULL許容** |                    **説明**                    |
|------------------|--------------|----------------|------------------------------------------------------------------------------|
| SQL_HASH_VALUE   | NUMBER       | NO             | 実行されたステートメントのHash値です。現在このフィールドはサポートされていません。現在デフォルトはNULLです        |
| SQL_ID           | VARCHAR2(32) | NO             | SQLステートメントのSQL一意の識別子                             |
| SQL_EXEC_START   | DATE         | NO             | SQLの実行開始時刻です。現在このフィールドはサポートされていません。現在デフォルトはNULLです           |
| SQL_EXEC_ID      | NUMBER   | NO             | SQL実行の一意の識別子                                   |
| WORKAREA_ADDRESS | RAW(8)       | NO             | workareaアドレスです。現在このフィールドはサポートされていません。現在デフォルトはNULLです          |
| OPERATION_TYPE   | VARCHAR2(160) | NO             | workarea演算子のタイプ。例えばSort、Hash Join、Group byなど  |
| OPERATION_ID     | NUMBER   | NO             | プランツリー内で演算子を識別する一意の識別子                               |
| POLICY           | VARCHAR2(24)  | NO             | workareaのポリシー：<ul><li> MANUAL   </li><li> AUTO  </li></ul>    |
| SID              | NUMBER   | NO             | セッションの一意の識別子                                |
| QCINST_ID        | NUMBER       | NO             | クエリコーディネーターのインスタンスIDです。現在このフィールドはサポートされていません。現在デフォルトはNULLです          |
| QCSID            | NUMBER       | NO             | クエリコーディネーターセッション識別IDです。現在このフィールドはサポートされていません。現在デフォルトはNULLです  |
| ACTIVE_TIME      | NUMBER   | NO             | workareaの平均アクティブ時間、単位：ms                       |
| WORK_AREA_SIZE   | NUMBER       | NO             | 演算子が使用するworkareaの最大サイズ、単位：bytes                 |
| EXPECT_SIZE      | NUMBER   | NO             | workareaの期待サイズ、単位：bytes                      |
| ACTUAL_MEM_USED  | NUMBER   | NO             | workareaに割り当てられたメモリ量、単位：bytes                    |
| MAX_MEM_USED     | NUMBER   | NO             | workareaで使用される最大メモリ量、単位：bytes                |
| NUMBER_PASSES    | NUMBER   | NO             | workareaがどのモードで実行されているか：<ul><li> 0：optimalモード   </li><li> 1：one passモード   </li><li> \>=2：multi passモード </li></ul>   |
| TEMPSEG_SIZE     | NUMBER   | NO             | workareaが使用する一時空間サイズ、単位：バイト。NULLの場合は、一時ファイルへの書き込みが発生していないことを意味します。                                                                              |
| TABLESPACE       | VARCHAR2(128) | NO             | 一時ファイルが書き込まれるテーブルの名前空間。NULLの場合は、一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています。                                                                        |
| SEGRFNO#         | NUMBER       | NO             | 一時ファイル書き込み関連ファイル数。NULLは一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています。                                                                           |
| SEGBLK#          | NUMBER       | NO             | workareaが作成した一時ファイルのブロック数。NULLは一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトでNULLに設定されています。                                                              |
| CON_ID           | NUMBER   | NO             | テナントID       |
| SVR_IP                 | VARCHAR2(46)   | NO             | サーバーIPアドレス   |
| SVR_PORT               | NUMBER(38)   | NO             | サーバーポート番号   |
