# V$EVENT_NAME

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下における各種待機イベントの定義を表示します。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | NUMBER | NO | テナントID |
| EVENT_ID | NUMBER | NO | 待機イベントID |
| EVENT# | NUMBER | NO | 待機イベント番号 |
| NAME | VARCHAR2(64) | NO | 待機イベント名 |
| DISPLAY_NAME | VARCHAR2(64) | NO | 待機イベント表示名 |
| PARAMETER1 | VARCHAR2(64) | NO | 待機イベントパラメータ1 |
| PARAMETER2 | VARCHAR2(64) | NO | 待機イベントパラメータ2 |
| PARAMETER3 | VARCHAR2(64) | NO | 待機イベントパラメータ3 |
| WAIT_CLASS_ID | NUMBER | NO | 待機イベントが属するタイプのID |
| WAIT_CLASS# | NUMBER | NO | 待機イベントが属するタイプのインデックス |
| WAIT_CLASS | VARCHAR2(64) | NO | 待機イベントが属するタイプの名前 |

## クエリ例

ユーザーテナント内で、そのテナント下のすべてのイベント待機関連定義を確認し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$EVENT_NAME WHERE ROWNUM <= 10;
```
