# V$SQL_WORKAREA

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

SQLの自動メモリ管理によって実行されたすべてのOperatorのワークエリア統計情報を集計します。

## フィールド説明

|        **フィールド名**        |    **型**    | **NULL許容** |                                                                **説明**                                                                 |
|------------------------|--------------|----------------| ----------|
| ADDRESS                | RAW(8)       | NO             | SQLに対応するハンドルアドレスです。現在値は指定されていません。このフィールドは現在サポートされておらず、デフォルトでNULLに設定されています   |
| HASH_VALUE             | NUMBER       | NO             | ステートメントのHash Value値です。このフィールドは現在サポートされておらず、デフォルトでNULLに設定されています           |
| DB_ID                  | NUMBER(38)    | NO            | このSQLリクエストの接続が属するデータベースID    <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li> <li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>  |
| SQL_ID                 | VARCHAR2(32) | NO             | SQLステートメントのSQL一意の識別子                                   |
| CHILD_NUMBER           | NUMBER       | NO             | このカーソルの子カーソル数です。このフィールドは現在サポートされておらず、デフォルトでNULLに設定されています               |
| WORKAREA_ADDRESS       | RAW(8)       | NO             | workareaアドレスです。このフィールドは現在サポートされておらず、デフォルトでNULLに設定されています                   |
| OPERATION_TYPE         | VARCHAR2(40) | NO             | workarea演算子のタイプ。例：Sort、Hash Join、Group byなど        |
| OPERATION_ID           | NUMBER(38)   | NO             | プランツリー内で演算子を識別する一意の識別子                                     |
| POLICY                 | VARCHAR2(10) | NO             | workareaのポリシー：<ul><li>MANUAL   </li><li> AUTO  </li></ul>  |
| ESTIMATED_OPTIMAL_SIZE | NUMBER(38)   | NO             | 最適条件下で演算子を実行する際の推定メモリサイズ、単位：bytes                        |
| ESTIMATED_ONEPASS_SIZE | NUMBER(38)   | NO             | one passシナリオで演算子を実行する際の推定メモリサイズ、単位：bytes                  |
| LAST_MEMORY_USED       | NUMBER(38)   | NO             | カーソルが前回実行時に使用したメモリサイズ、単位：bytes                            |
| LAST_EXECUTION         | VARCHAR2(10) | NO             | 前回の実行時にworkareaがoptimal、one pass、またはmulti passesを選択したかどうかを示します。」                                                                 |
| LAST_DEGREE            | NUMBER(38)   | NO             | 前回の実行並列度                                            |
| TOTAL_EXECUTIONS       | NUMBER(38)   | NO             | workareaを使用した実行総回数                                |
| OPTIMAL_EXECUTIONS     | NUMBER(38)   | NO             | 最適な場合での実行回数                                         |
| ONEPASS_EXECUTIONS     | NUMBER(38)   | NO             | one passシナリオでの実行回数                                   |
| MULTIPASSES_EXECUTIONS | NUMBER(38)   | NO             | multi passesシナリオでの実行回数                               |
| ACTIVE_TIME            | NUMBER(38)   | NO             | workareaがアクティブだった平均時間、単位：秒                             |
| MAX_TEMPSEG_SIZE       | NUMBER(38)   | NO             | work area使用時の最大一時ディスク容量、単位：バイト；NULLの場合は一時空間未使用を示す |
| LAST_TEMPSEG_SIZE      | NUMBER(38)   | NO             | workareaで前回実行時に使用された一時ディスク容量；NULLの場合は一時空間未使用を示す        |
| CON_ID                 | NUMBER(38)   | NO             | テナントID                                              |
| SVR_IP                 | VARCHAR2(46)  | NO            | サーバーIPアドレス  |
| SVR_PORT               | NUMBER(38)    | NO            | サーバーポート番号  |
