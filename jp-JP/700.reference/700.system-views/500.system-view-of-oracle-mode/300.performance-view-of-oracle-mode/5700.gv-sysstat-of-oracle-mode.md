# GV$SYSSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべてのOBServerノード上での統計イベント情報を表示します。

その中で：

* `STATISTIC#`：統計項目の番号を示します。同一の統計項目でも、異なるOBServerノードのバージョン間で番号が変更される場合があります。
* `STAT_ID`：統計項目のIDを示します。同一の統計項目のIDは、異なるOBServerノードのバージョン間でも同じであることが保証されています。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューを使用するには、モニタリングを有効にする必要があります。つまり、構成パラメータ <code>enable_perf_event</code> の値をTrueに設定する必要があります。</p>
</main>

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | 情報が存在するサーバーのポート番号 |
| STATISTIC# | NUMBER | NO | 統計イベントのインデックス |
| NAME | VARCHAR2(64) | NO | 統計イベントの名前 |
| CLASS | NUMBER | NO | 統計イベントが属するタイプ |
| VALUE | NUMBER | NO | 統計イベントに対応する結果値 |
| STAT_ID | NUMBER | NO | 統計イベントID |

## クエリ例

ユーザーテナント内で、現在のテナントがすべてのノード上で発生した統計イベント情報を確認し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$SYSSTAT WHERE ROWNUM <= 10;
```
