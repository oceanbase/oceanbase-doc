# GV$OB_ARBITRATION_SERVICE_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内の各ノードとアービトレーションサービスとの間の通信状態を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | ホストのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | ホストのRPCポート |
| ARBITRATION_SERVICE_ADDRESS | VARCHAR2(512) | NO | アービトレーションサービスのアドレス |
| STATUS | VARCHAR2(64) | NO | Serverとアービトレーションサービス間の通信状態。値は以下の通りです：<ul><li>  `ACTIVE`：アービトレーションサービスとの通信が正常であることを示します </li><li> `INACTIVE`：アービトレーションサービスとの通信ができないことを示します </li></ul>|

## クエリ例

このテナント内の各ノードとアービトレーションサービスとの間の通信状態を確認します。

```shell
obclient[SYS]> SELECT * FROM SYS.GV$OB_ARBITRATION_SERVICE_STATUS;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------------------------+--------+
| SVR_IP         | SVR_PORT | ARBITRATION_SERVICE_ADDRESS | STATUS |
+----------------+----------+-----------------------------+--------+
| xxx.xx.xxx.207 |     2882 | xxx.xx.xxx.224:2882         | ACTIVE |
| xxx.xx.xxx.218 |     2882 | xxx.xx.xxx.224:2882         | ACTIVE |
+----------------+----------+-----------------------------+--------+
2 rows in set
```
