# V$OB_UNITS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上のUnit情報を表示します。

## フィールドの説明

|       フィールド名       |      型      | NULL許容 |                                            説明                |
|------------------|--------------|------------|-------------------------------------------------------------------------|
| SVR_IP           | VARCHAR2(46)  | NO         | サーバーのIPアドレス                                                              |
| SVR_PORT         | NUMBER(38)   | NO         | サーバーのポート番号                                                                 |
| UNIT_ID          | NUMBER(38)   | NO         | Unit ID                                                                |
| TENANT_ID        | NUMBER(38)   | NO         | Unitが属するテナントID                                                          |
| ZONE             | VARCHAR2(128) | NO         | Zone名                                                                |
| ZONE_TYPE        | VARCHAR2(128) | NO         | Unitが配置されているZoneのZoneタイプ。<ul><li>`NULL`：この列の値が無効であることを示します。OBServerノードの再起動時に一時的に無効な値が表示される場合があります。</li> <li>`ReadWrite`：読み書き可能なZone</li> <li>`Encryption`：暗号化Zone</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REGION           | VARCHAR2(128) | NO         | Unitが配置されているZoneが属するRegion名。設定されていない場合、デフォルトで`default_region`となります。値が`NULL`の場合、この列の値が無効であることを示します。OBServerノードの再起動時に一時的に無効な値が表示される場合があります。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>  |
| MIN_CPU          | NUMBER(38)       | NO         | CPUスペックの下限                                                               |
| MAX_CPU          | NUMBER(38)       | NO         | CPUスペックの上限                                                               |
| MEMORY_SIZE      | NUMBER(38)   | NO         | メモリサイズ、単位はバイト                                                           |
| MIN_IOPS         | NUMBER(38)   | NO         | ディスクIOPSスペックの下限                                                           |
| MAX_IOPS         | NUMBER(38)   | NO         | ディスクIOPSスペックの上限                                                           |
| IOPS_WEIGHT      | NUMBER(38)   | NO         | IOPS重み |
| MAX_NET_BANDWIDTH| NUMBER(38)   | YES        | Unitの最大ネットワーク帯域幅、単位はバイト  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main> |
| NET_BANDWIDTH_WEIGHT |NUMBER(38)| YES        | Unitのネットワーク帯域幅の重み値 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>  |
| LOG_DISK_SIZE    | NUMBER(38)   | NO         | ログディスクサイズ、単位はバイト                                                                    |
| LOG_DISK_IN_USE  | NUMBER(38)   | NO         | ログディスクの使用済みサイズ、単位はバイト                                                               |
| DATA_DISK_SIZE   | NUMBER(38)   | YES        | <ul><li>Unitが使用可能なローカルキャッシュサイズ、単位はバイト。共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。</li> <li>シェアードナッシング(Shared-Nothing, SN)モードでは、このフィールドの値は`NULL`となり、未定義を意味します。他のテナントのディスク容量を競合的に使用することが許可されます。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>     |
| DATA_DISK_IN_USE | NUMBER(38)   | NO         | <ul><li>SSモードでは、Unitが使用しているローカルキャッシュサイズ、単位はバイトを表します。</li> <li>SNモードでは、Unitが使用しているデータディスクサイズ、単位はバイトを表します。  </li></ul>                    |
| STATUS           | VARCHAR2(64)  | NO         | Unitの状態：<ul><li>`NORMAL`：正常状態   </li><li> `MIGRATING IN`：移行中   </li><li> `MIGRATING OUT`：移出行中   </li><li> `MARK DELETING`：削除予定</li><li>`WAIT GC`：GCデータ待ち </li><li>`DELETING`：GC完了、削除中 </li><li> `ERROR`：エラー状態 </li></ul> |
| CREATE_TIME      | NUMBER(38) | NO         | UnitがOBServerノード上に作成された時間                                                 |
| REPLICA_TYPE     | VARCHAR2(7)   | NO         | レプリカタイプ。デフォルトは`FULL` <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、<code>REPLICA_TYPE</code>フィールドはV4.4.0 BP1バージョンから導入されました。</li> <li>V4.5.x系では、<code>REPLICA_TYPE</code>フィールドはV4.5.0バージョンから導入されました。</li><li>V4.2.5系では、<code>REPLICA_TYPE</code>フィールドはV4.2.5 BP7バージョンから導入されました。</li></ul></main>  |
