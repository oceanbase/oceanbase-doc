# V$OB_SQL_AUDIT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

`V$OB_SQL_AUDIT` ビューは、現在のOBServerノードにおける各SQLリクエストのソース、実行状態などの統計情報を表示するために使用されます。このビューはテナントごとに分割されており、システムテナントを除く他のテナントでは、テナント間でクエリを実行することはできません。
