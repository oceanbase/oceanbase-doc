# V$OB_SESS_TIME_MODEL

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`V$OB_SESS_TIME_MODEL`は、現在のノード上のセッションレベルのTime Model統計項目を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| SID        | NUMBER       | NO   | セッションID     |
| TENANT_ID  | NUMBER       | NO   | テナントID     |
| SVR_IP     | VARCHAR2(46) | NO   | ノードIP       |
| SVR_PORT   | NUMBER(38)   | NO   | ノードポート番号        |
| STAT_ID    | NUMBER       | NO   | 統計項目ID         |
| STAT_NAME  | VARCHAR2(64) | NO   | 統計項目名       |
| VALUE      | NUMBER       | NO   | 統計項目値        |

ビュー内の`STAT_NAME`列の値に含まれる統計イベント名および対応する統計イベントIDは、次の表のとおりです。

| 統計イベント名 | 説明 | 統計イベントID | 統計イベントの種類 |
| ------------|------|------------|----------------|
| DB time                                |  データベースアクティビティの合計時間。CPU時間と非アイドル待機時間の合計値  |  200001 |  3072 |
| DB CPU                                 |  データベースアクティビティにおけるCPU消費時間                    |  200002 |  3072 |
| background elapsed time                |  バックグラウンドプロセスの実行時間                           |  200005 |  3072 |
| background cpu time                    |  バックグラウンドプロセスのCPU時間                        |  200006 |  3072 |
| non idle wait time                     |  非アイドル待機時間。セッションが待機状態にあるが、アイドル待機ではない時間の合計  |  200010 |  3072 |
| idle wait time                         |  アイドル待機時間。セッションがアイドル待機状態にある時間の合計    |  200011 |  3072 |
| background database time               |  バックグラウンドプロセスによるデータベース操作の実行時間                   |  200012 |  3072 |
| background database non-idle wait time |  バックグラウンドプロセスが非アイドル待機状態でデータベース操作を実行した時間    |  200013 |  3072 |
| background database idle wait time     |  バックグラウンドプロセスがアイドル待機状態でデータベース操作を実行した時間      |  200014 |  3072 |
| concurrency wait total time            | 並行問題による待機時間の合計。例：リソースロックによる待機時間 | 220001 |  3072 |
| user io wait total time                | ユーザープロセスがI/O操作（データの読み取りやディスクへの書き込みなど）の完了を待機している時間の合計 | 220002 |  3072 |
| application wait total time            | ユーザーアプリケーションコードによって発生した待機時間の合計（例：行レベルロックや明示的なロックコマンドによるロック待機）| 2200013 |  3072 |

## クエリ例

現在のノード上のセッションレベルのTime Model統計項目を確認し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SESS_TIME_MODEL WHERE ROWNUM = 1;
```

クエリ結果は次のとおりです。

```shell
+---------------+-----------+----------------+----------+---------+--------------------+-------+
| SID           | TENANT_ID | SVR_IP         | SVR_PORT | STAT_ID | STAT_NAME          | VALUE |
+---------------+-----------+----------------+----------+---------+--------------------+-------+
| 4947802324992 |      1004 | 172.xx.xxx.xxx |     2882 |  200010 | non idle wait time |     0 |
+---------------+-----------+----------------+----------+---------+--------------------+-------+
1 row in set
```
