# V$VERSION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

データベース製品のすべてのコンポーネント名とバージョン情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名** |     **型**      | **NULL許容** |  **説明**   |
|----------|-----------------|----------------|-----------|
| BANNER   | VARCHAR2(65536) | YES            | 製品名およびバージョン番号 |
| CON_ID   | NUMBER          | NO             | コンテナID     |

## クエリ例

データベースのバージョン情報を確認します。

```shell
obclient> SELECT * FROM V$VERSION;
```

クエリ結果は次のとおりです：

```shell
+---------------------------------------------------------------------------------------------------------------+--------+
| BANNER                                                                                                        | CON_ID |
+---------------------------------------------------------------------------------------------------------------+--------+
| OceanBase 4.4.0.0 (r100000562025070723-014a767e54eac8efc0e4a5c8bbc34126e41892dd) (Built Jul  7 2025 23:15:18) |      0 |
+---------------------------------------------------------------------------------------------------------------+--------+
1 row in set
```
