# V$SQL_MONITOR_STATNAME

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$SQL_MONITOR_STATNAME` は、`[G]V$SQL_PLAN_MONITOR` の `OTHERSTAT_X_ID` フィールドに含まれる数値の意味を示します。

## フィールドの説明

|  **フィールド名**   |    **型**     | **NULL許容** |          **説明**          |
|-------------|---------------|----------------|--------------------------|
| CON_ID      | NUMBER        | NO             | テナントID                    |
| ID          | NUMBER        | NO             | フィールドID                    |
| GROUP_ID    | NUMBER        | NO             | フィールドの分類IDです。同じ種類の演算子は、1つの分類IDを共有します |
| NAME        | VARCHAR2(40)  | NO             | フィールド名                     |
| DESCRIPTION | VARCHAR2(200) | NO             | フィールドの詳細な説明                   |
| TYPE        | NUMBER        | NO             | 予約語                         |
| FLAGS       | NUMBER        | NO             | 予約語                         |

## クエリ例

`GV$SQL_PLAN_MONITOR` の `OTHERSTAT_X_ID` フィールドに含まれる数値の意味を照会し、最初のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$SQL_MONITOR_STATNAME WHERE ROWNUM =  1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
     CON_ID: NULL
         ID: 1
   GROUP_ID: 0
       NAME: min hash entry count
DESCRIPTION: element count in shortest hash slot
       TYPE: 1
      FLAGS: 0
1 row in set (0.012 sec)
```
