# V$GLOBAL_TRANSACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上でアクティブなグローバルトランザクションの情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

| CON_ID       | VARCHAR2(256) | NO             | 状態の数値表現                         |
