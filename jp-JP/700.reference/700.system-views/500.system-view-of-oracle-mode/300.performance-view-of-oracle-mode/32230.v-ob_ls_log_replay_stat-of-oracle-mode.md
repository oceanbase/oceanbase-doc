# V$OB_LS_LOG_REPLAY_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_LS_LOG_REPLAY_STAT`は、テナントの現在のノード上にある各LS（ログストリーム）レプリカのログ再生進捗状況を表示するために使用されます。クエリ時には、スタンバイデータベース（またはプライマリデータベース上でフォロワーレプリカをクエリする）でクエリを実行する必要があります。

プライマリテナント（プライマリデータベース）のリーダーレプリカではログが再生されないため、クエリ結果において、プライマリテナント上の`ROLE = LEADER`の場合、その行のレコードは無意味です。

## フィールドの説明

|      フィールド名       |      型           | NULL許容 |    説明     |
|--------------------|---------------------|----------------|-------------|
| TENANT_ID          | NUMBER(38)          | NO   | テナントID     |
| SVR_IP             | VARCHAR2(46)        | NO   | ログストリームID     |
| SVR_PORT           | NUMBER(38)          | NO   | サーバーIPアドレス     |
| LS_ID              | NUMBER(38)          | NO   | サーバーポート番号     |
| ROLE               | VARCHAR2(32)        | NO   | ログストリームレプリカの役割：<ul><li>`LEADER`：リーダーレプリカ</li> <li>`FOLLOWER`：フォロワーレプリカ</li></ul>      |
| ENABLED            | NUMBER(38)          | NO   | ログ再生サービス（Replay Service）が有効かどうか    |
| END_LSN            | NUMBER(38)          | NO   | Palfに書き込まれたLSN（ログ再生の右端）      |
| UNSUBMITTED_LSN    | NUMBER(38)          | NO   | 再生キューに次に送信されるログのLSN     |
| UNSUBMITTED_SCN    | NUMBER(38)          | NO   | 再生キューに次に送信されるログのSCN     |
| MIN_UNREPLAYED_LSN | NUMBER(38)          | NO   | 再生キュー内の最小未再生ログのLSN     |
| MIN_UNREPLAYED_SCN | NUMBER(38)          | NO   | 再生キュー内の最小未再生ログのSCN     |
| PENDING_CNT        | NUMBER(38)          | NO   | メモリ内で再生待ちのタスク数     |

## クエリ例

スタンバイテナント内で、自身のテナントの現在のノード上にある各ログストリームレプリカのログ再生進捗状況を確認します。

```shell
obclient(root@standby_tenant)[SYS]> SELECT LS_ID, ROLE, ENABLED,
        END_LSN, UNSUBMITTED_LSN, MIN_UNREPLAYED_LSN, PENDING_CNT
        FROM SYS.V$OB_LS_LOG_REPLAY_STAT;
```

クエリ結果は次のとおりです：

```shell
+-------+----------+---------+-----------+-----------------+--------------------+-------------+
| LS_ID | ROLE     | ENABLED | END_LSN   | UNSUBMITTED_LSN | MIN_UNREPLAYED_LSN | PENDING_CNT |
+-------+----------+---------+-----------+-----------------+--------------------+-------------+
|     1 | FOLLOWER |       1 | 300636581 |       300299240 |          300299240 |           0 |
|  1001 | FOLLOWER |       1 | 197547054 |       197259486 |          197259486 |           0 |
+-------+----------+---------+-----------+-----------------+--------------------+-------------+
2 rows in set
```
