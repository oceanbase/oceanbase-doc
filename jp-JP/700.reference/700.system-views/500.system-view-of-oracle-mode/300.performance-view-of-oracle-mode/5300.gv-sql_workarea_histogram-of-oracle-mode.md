# GV$SQL_WORKAREA_HISTOGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのノードにおいて、過去にすべてのワークエリアで実行された統計情報を表示します。例えば、1MB～2MBの範囲で全てインメモリ処理された回数や、ワンパス処理の回数などです。

## **フィールド説明**

|        **フィールド名**        |   **型**   | **NULL許容** |                  **説明**                  |
|------------------------|------------|----------------|------------------------------------------|
| LOW_OPTIMAL_SIZE       | NUMBER | NO             | workareaのoptimalモードにおける最小メモリ量              |
| HIGH_OPTIMAL_SIZE      | NUMBER | NO             | workareaのoptimalモードにおける最大メモリ量              |
| OPTIMAL_EXECUTIONS     | NUMBER | NO             | workareaの最低および最高範囲でoptimalモードで実行された回数             |
| ONEPASS_EXECUTIONS     | NUMBER | NO             | workareaの最低および最高範囲でone passモードで実行された回数     |
| MULTIPASSES_EXECUTIONS | NUMBER | NO             | workareaの最低および最高範囲でmulti passesモードで実行された回数 |
| TOTAL_EXECUTIONS       | NUMBER | NO             | workareaの合計実行回数                         |
| CON_ID                 | NUMBER | NO             | テナントID                                    |
| SVR_IP                 | VARCHAR2(46)   | NO             | サーバーIPアドレス   |
| SVR_PORT               | NUMBER   | NO             | サーバーポート番号   |

## クエリ例

このテナントのすべてのノード上で以前に実行されたすべてのワークエリアの統計情報を確認し、上位10件のレコードを表示します。

```shell
obclient[SYS]> SELECT * FROM SYS.GV$SQL_WORKAREA_HISTOGRAM WHERE ROWNUM<= 10;
```
