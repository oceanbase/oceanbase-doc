# V$DBLINK

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは現在サポートされていません。作成済みのDBLinkを確認するには、<a href="../200.dictionary-view-of-oracle-mode/7700.dba_db_links.md">DBA_DB_LINKS</a>、<a href="../200.dictionary-view-of-oracle-mode/900.all_db_links.md">ALL_DB_LINKS</a>、<a href="../200.dictionary-view-of-oracle-mode/25300.user_db_links.md">USER_DB_LINKS</a>などのビューを使用してください。</p>
</main>

## 機能の概要

このノードで開始されたクエリセッションが開いたすべてのデータベースリンク（`IN_TRANSACTION=YES` のリンク）を表示します。これらのデータベースリンクは、閉じる前にコミットまたはロールバックする必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

|       **フィールド名**        |    **タイプ**     | **NULL値を許容するか** |             **説明**             |
|-----------------------|---------------|----------------|--------------------------------|
| DB_LINK               | VARCHAR2(128) | NO             | データベースリンクの名前                       |
| OWNER_ID              | NUMBER        | NO             | データベースリンクUIDの所有者                 |
| LOGGED_ON             | VARCHAR2(3)   | NO             | データベースリンクが現在ログインしているかどうか                    |
| HETEROGENEOUS         | VARCHAR2(3)   | NO             | データベースリンクがアクセスするデータベースが異種であるかどうか               |
| PROTOCOL              | VARCHAR2(6)   | NO             | データベースリンクの通信プロトコル：<ul><li>OceanBase：OceanBase内部プロトコルを使用してOceanBaseデータベースにアクセスすることを示します(OceanBaseモード)</li><li>OCI ( Oracle Call Interface )：OCIライブラリを使用してOracleデータベースにアクセスすることを示します</li></ul> |
| OPEN_CURSORS          | NUMBER        | NO             | データベースリンクに開いているカーソルがあるかどうか                  |
| IN_TRANSACTION        | VARCHAR2(3)   | NO             | データベースリンクが現在トランザクション中かどうか                 |
| UPDATE_SENT           | VARCHAR2(3)   | NO             | データベースリンクに更新があるかどうか                     |
| COMMIT_POINT_STRENGTH | NUMBER        | NO             | データベースリンク上のトランザクションのコミットポイント強度                 |
| CON_ID                | NUMBER        | NO             | データベースリンクを作成したテナントID                  |
