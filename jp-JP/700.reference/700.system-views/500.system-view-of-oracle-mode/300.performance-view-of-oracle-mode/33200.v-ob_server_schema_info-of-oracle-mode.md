# V$OB_SERVER_SCHEMA_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このマシンのスキーマ情報を表示します。

## フィールドの説明

|            フィールド名            |      タイプ      | NULLを許容するか |                説明                |
|----------------------------|--------------|------------|----------------------------------|
| SVR_IP                     | VARCHAR2(46) | NO         | サーバーのIPアドレス                        |
| SVR_PORT                   | NUMBER(38)   | NO         | サーバーのポート番号                           |
| TENANT_ID                  | NUMBER(38)   | NO         | テナントID                            |
| REFRESHED_SCHEMA_VERSION   | NUMBER(38)   | NO         | テナントがリフレッシュしたSchemaバージョン                 |
| RECEIVED_SCHEMA_VERSION    | NUMBER(38)   | NO         | テナントがリフレッシュすべきSchemaバージョン               |
| SCHEMA_COUNT               | NUMBER(38)   | NO         | 対応するSchemaバージョンにおける、各Schemaオブジェクト数の合計                  |
| SCHEMA_SIZE                | NUMBER(38)   | NO         | 対応するSchemaバージョンにおける、各Schemaオブジェクトが占めるメモリ総サイズ、単位はバイト                    |
| MIN_SSTABLE_SCHEMA_VERSION | NUMBER(38)   | NO         | テナントSSTable上に記録されている最小schema_version |

## クエリ例

ユーザーテナントは、現在のOBServerノード上にある自身のテナントのスキーマ情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SERVER_SCHEMA_INFO;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+--------------------------+-------------------------+--------------+-------------+----------------------------+
| SVR_IP         | SVR_PORT | TENANT_ID | REFRESHED_SCHEMA_VERSION | RECEIVED_SCHEMA_VERSION | SCHEMA_COUNT | SCHEMA_SIZE | MIN_SSTABLE_SCHEMA_VERSION |
+----------------+----------+-----------+--------------------------+-------------------------+--------------+-------------+----------------------------+
| 172.xx.xxx.xxx |     2882 |      1004 |         1735872883840472 |        1735872883840472 |         2360 |     2321104 |                         -1 |
+----------------+----------+-----------+--------------------------+-------------------------+--------------+-------------+----------------------------+
1 row in set
```
