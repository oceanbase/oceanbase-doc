# V$ENCRYPTED_TABLESPACES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで暗号化機能が有効なテーブルスペースの暗号化状態を表示します。

## フィールド説明

|     **フィールド名**     |    **型**    | **NULL許容** |                       **説明**                       |
|------------------|--------------|------------|------------------------------------------------------------------------------------|
| TABLESPACE_ID    | NUMBER(38)   | NO         | テーブルスペースID                                             |
| ENCRYPTIONALG    | VARCHAR2(30) | NO         | 暗号化アルゴリズム名：<ul><li>AES-128   </li><li> AES-192   </li><li> AES-256   </li><li> SM4 </li></ul>   |
| ENCRYPTED        | VARCHAR2(3)  | NO         | 暗号化の完了状況：<ul><li>YES   </li><li> NO </li></ul> |
| ENCRYPTEDKEY     | VARCHAR2(32) | NO         | マスターキーで暗号化された暗号化キー                                      |
| MASTERKEYID      | NUMBER(38)   | NO         | マスターキーのバージョン                                              |
| BLOCKS_ENCRYPTED | NUMBER       | NO         | 暗号化されたマクロブロックの数                                            |
| BLOCKS_DECRYPTED | NUMBER       | NO         | 暗号化されていないマクロブロックの数                                           |
| STATUS           | VARCHAR2(10) | NO         | 暗号化状態：<ul><li>NORMAL：正常状態   </li><li> ENCRYPTING：暗号化中   </li><li> DECRYPTING：復号化中 </li></ul>                           |
| CON_ID           | NUMBER(38)   | NO         | テナントID                                              |

## クエリ例

現在のテナントで暗号化機能が有効なテーブルスペースの暗号化状態を確認します。

```shell
obclient [SYS]> SELECT TABLESPACE_ID, ENCRYPTIONALG, ENCRYPTED, STATUS FROM SYS.V$ENCRYPTED_TABLESPACES;
```

クエリ結果は次のとおりです：

```shell
+---------------+---------------+-----------+--------+
| TABLESPACE_ID | ENCRYPTIONALG | ENCRYPTED | STATUS |
+---------------+---------------+-----------+--------+
|        500099 | sm4-cbc       | YES       | NORMAL |
+---------------+---------------+-----------+--------+
1 row in set
```
