# V$SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上で待機しているイベントを表示し、各種待機イベントの発生回数、待機時間、タイムアウト回数などの統計情報を提供します。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | NUMBER | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | 情報が存在するサーバーのポート番号 |
| EVENT_ID | NUMBER | NO | 待機中のイベントID |
| EVENT | VARCHAR2(64) | NO | 待機中のイベントの説明 |
| WAIT_CLASS_ID | NUMBER | NO | 待機中のイベントが属するクラスID |
| WAIT_CLASS# | NUMBER | NO | 待機中のイベントが属するクラスのインデックス |
| WAIT_CLASS | VARCHAR2(64) | NO | 待機中のイベントが属するクラス |
| TOTAL_WAITS | NUMBER | NO | その待機イベントの合計待機回数 |
| TOTAL_TIMEOUTS | NUMBER | NO | その待機イベントの合計タイムアウト回数 |
| TIME_WAITED | NUMBER | NO | その待機イベントの合計待機時間、単位は10ミリ秒 |
| AVERAGE_WAIT | NUMBER | NO | その待機イベントの平均待機時間、単位は10ミリ秒 |
| TIME_WAITED_MICRO | NUMBER | NO | その待機イベントの合計待機時間、単位はマイクロ秒 |

## クエリ例

ユーザーテナント内で、現在のノード上における自身のテナントのすべての待機イベントを確認し、上位10件のレコードを表示します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$SYSTEM_EVENT WHERE ROWNUM <= 10;
```
