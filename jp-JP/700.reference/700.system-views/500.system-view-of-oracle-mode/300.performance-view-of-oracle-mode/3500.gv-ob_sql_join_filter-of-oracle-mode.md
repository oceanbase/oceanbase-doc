# GV$SQL_JOIN_FILTER

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのすべてのOBServerノードでJoin Filterが実行された関連情報を動的に表示します。

## フィールド説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート番号 |
| QC_SESSION_ID | NUMBER | NO | 指定されたパラレルクエリのカーソルに対応するQC（Query Coordinator）セッションID<br>V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョンでは：<br>すべての接続モード（直接接続モード/ODPモード）で、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code>が設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code>が設定されている場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| QC_INSTANCE_ID | NUMBER | NO | 指定されたパラレルクエリのカーソルに対応するQC（Query Coordinator）インスタンスID |
| SQL_PLAN_HASH_VALUE | NUMBER | NO | 指定されたパラレルクエリのカーソルのSQL計画のHash値 |
| FILTER_ID | NUMBER | NO | 接続フィルターを識別するID。このIDは実行計画内のフィルターIDに対応します |
| BITS_SET | NUMBER | NO | BLOOM_FILTERで使用されるBitmap（結合ビットマップ）のサイズ。現在のバージョンでは互換性のためにのみ使用されます |
| FILTERED | NUMBER | NO | 接続フィルターが処理した行数 |
| PROBED | NUMBER | NO | ビットマップフィルターテストを通過した右テーブルの行数。ここではフィルター済み行数と未フィルター行数の合計を指します |
| ACTIVE | NUMBER | NO | フィルターがアクティブ状態（はい）か非アクティブ状態（いいえ）か |
| CON_ID | NUMBER | NO | データが属するコンテナのID |
| TRACE_ID | CHAR(64) | NO | SQLステートメントに対応するTrace ID |
