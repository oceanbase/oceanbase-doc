# V$OPEN_CURSOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在、Open状態にあるSession Cursorの関連情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

| フィールド名                 | 型           |  NULL許容 |   説明                             |
|-------------------------|----------------|-----------------|------------------------------------|
| SVR_IP               | VARCHAR2(46) | NO   | サーバーIPアドレス  |
| SVR_PORT             | NUMBER(38)   | NO   | サーバーポート番号 |
| SADDR                | VARCHAR2(8)  | NO   | セッションメモリアドレス |
| SID                  | NUMBER       | NO   | セッションID |
| USER_NAME            | VARCHAR2(30) | NO   | ユーザー名 |
| ADDRESS              | VARCHAR2(8)  | NO   | SQLアドレス。SQL Hashと組み合わせて、SQLを一意に特定します。現在このフィールドはNULLです |
| HASH_VALUE           | NUMBER       | NO   | SQL Hash。現在このフィールドはNULLです |
| SQL_ID               | VARCHAR2(32) | NO   | SQL ID |
| SQL_TEXT             | VARCHAR2(60) | NO   | SQLテキストの最初の60文字列 |
| LAST_SQL_ACTIVE_TIME | DATE         | NO   | 最後に実行された時間 |
| SQL_EXEC_ID          | NUMBER       | NO   | 現在このフィールドはNULLです |
| CURSOR_TYPE          | VARCHAR2(30) | NO   | Cursorタイプ。現在、以下の2つの状態が含まれます：<ul><li>OPEN：現在すべてのSessionでOpenされているSQL文を示します。</li><li>SESSION CURSOR：現在すべてのSessionでOpenされているSession Cursorを示します。</li></ul>|
| CHILD_ADDRESS        | VARCHAR2(30) | NO   | 現在、このフィールドはサポートされていません |
| CON_ID               | NUMBER       | NO   | データが属するコンテナのID。現在の値は`1`です |
