# V$OB_PL_CACHE_OBJECT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `V$OB_PL_CACHE_OBJECT` は、現在のテナント配下のサーバー内におけるPL関連キャッシュオブジェクトの基本情報を表示します。

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | NUMBER(38)         | NO   |  テナントID：<ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>   |
