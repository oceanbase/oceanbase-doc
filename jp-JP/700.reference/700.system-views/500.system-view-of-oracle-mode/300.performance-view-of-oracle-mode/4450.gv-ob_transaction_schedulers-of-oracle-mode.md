# GV$OB_TRANSACTION_SCHEDULERS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`GV$OB_TRANSACTION_SCHEDULERS`は、すべてのサーバーのトランザクションスケジューラー情報を照会するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| SVR_IP | VARCHAR2(46) | NO | レプリカが存在するサーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | レプリカが存在するサーバーのポート |
| SESSION_ID | NUMBER(38) | NO | V4.3.x系について：<ul><li> V4.3.5 BP2以前のバージョン：<br>接続方式（直接接続モード/ODPモード）に関係なく、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODPでパラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| TX_ID | NUMBER(38) | NO | トランザクションID |
| STATE | VARCHAR2(18) | NO | トランザクションの状態 |
| CLUSTER_ID | NUMBER(38) | NO | クラスターの一意のID |
| COORDINATOR | NUMBER(38) | NO | コーディネーターが存在するログストリームID |
| PARTICIPANTS | VARCHAR2(1024) | YES | トランザクションの参加者情報 |
| ISOLATION_LEVEL | VARCHAR2(16) | NO | 分離レベル |
| SNAPSHOT_VERSION | NUMBER(38)  | YES | RRまたはSERIAL分離レベルで有効なスナップショットバージョン。無効な場合は-1 |
| ACCESS_MODE | VARCHAR2(10) | NO | アクセスモード（読み取り専用または読み書き） |
| TX_OP_SN | NUMBER(38)  | NO | トランザクションレベルの操作シーケンス番号 |
| ACTIVE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | トランザクションの開始または暗黙的開始時刻のタイムスタンプ |
| EXPIRE_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | トランザクションの有効期限のタイムスタンプ |
| CAN_EARLY_LOCK_RELEASE | VARCHAR2(7) | NO | ロックを早期に解除できるかどうか |
| FORMATID               | NUMBER(38)          | NO   | グローバルトランザクションの形式識別子 |
| GLOBALID               | VARCHAR2(256)        | YES  | グローバルトランザクションの一意の識別子 |
| BRANCHID               | VARCHAR2(256)        | YES  | ブランチトランザクションの一意の識別子 |
