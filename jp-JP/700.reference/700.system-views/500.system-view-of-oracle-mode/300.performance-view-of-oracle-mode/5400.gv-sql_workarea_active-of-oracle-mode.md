# GV$SQL_WORKAREA_ACTIVE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上で現在アクティブなOperatorのワークエリア情報を表示します。

## **フィールドの説明**

|     **フィールド名**     |    **タイプ**    | **NULLを許容するか** |                    **説明**                    |
|------------------|--------------|----------------|------------------------------------------------------------------------------|
| SQL_HASH_VALUE   | NUMBER       | NO             | 実行されるステートメントのハッシュ値。現在このフィールドはサポートされておらず、デフォルトではNULLとなります        |
| SQL_ID           | VARCHAR2(32) | NO             | SQLステートメントのSQL一意識別子                             |
| SQL_EXEC_START   | DATE         | NO             | SQL実行開始時間。現在このフィールドはサポートされておらず、デフォルトではNULLとなります           |
| SQL_EXEC_ID      | NUMBER   | NO             | SQL実行の一意識別子                                   |
| WORKAREA_ADDRESS | RAW(8)       | NO             | workareaアドレス。現在このフィールドはサポートされておらず、デフォルトではNULLとなります          |
| OPERATION_TYPE   | VARCHAR2(160) | NO             | workarea演算子の種類。例えばSort、Hash Join、Group byなど  |
| OPERATION_ID     | NUMBER   | NO             | プランツリー内で演算子を識別するための一意識別子                               |
| POLICY           | VARCHAR2(24)  | NO             | workareaのポリシー：<ul><li> MANUAL </li><li>AUTO </li></ul>   |
| SID              | NUMBER   | NO             | セッションの一意識別子                                |
| QCINST_ID        | NUMBER       | NO             | クエリコーディネータのインスタンスID。現在このフィールドはサポートされておらず、デフォルトではNULLとなります          |
| QCSID            | NUMBER       | NO             | クエリコーディネータセッション識別ID。現在このフィールドはサポートされておらず、デフォルトではNULLとなります  |
| ACTIVE_TIME      | NUMBER   | NO             | workareaがアクティブな平均時間（単位：ミリ秒）                       |
| WORK_AREA_SIZE   | NUMBER       | NO             | 演算子がworkareaを使用する最大サイズ（単位：バイト）         |
| EXPECT_SIZE      | NUMBER   | NO             | workareaの期待サイズ（単位：バイト）            |
| ACTUAL_MEM_USED  | NUMBER   | NO             | workareaに割り当てられたメモリ量（単位：バイト）                |
| MAX_MEM_USED     | NUMBER   | NO             | workareaで使用される最大メモリ量（単位：バイト）              |

| TEMPSEG_SIZE     | NUMBER   | NO             | workareaで使用される一時領域のサイズ、単位：バイト。NULLの場合は、一時ファイルへの書き込みが発生していないことを意味します。                                                                              |
| TABLESPACE       | VARCHAR2(128) | NO             | 一時ファイルを書き込むテーブルのネームスペース。NULLの場合は、一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトではNULLに設定されています。                                                                        |
| SEGRFNO#         | NUMBER       | NO             | 一時ファイル関連のファイル数。NULLの場合は、一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトではNULLに設定されています。                                                                           |
| SEGBLK#          | NUMBER       | NO             | workareaで作成された一時ファイルのブロック数。NULLの場合は、一時ファイルへの書き込みが発生していないことを意味します。現在このフィールドはサポートされておらず、デフォルトではNULLに設定されています。                                                              |
| CON_ID           | NUMBER   | NO             | テナントID       |
| SVR_IP                 | VARCHAR2(46)   | NO             | サーバーIPアドレス   |
| SVR_PORT               | NUMBER(38)   | NO             | サーバーのポート番号   |
