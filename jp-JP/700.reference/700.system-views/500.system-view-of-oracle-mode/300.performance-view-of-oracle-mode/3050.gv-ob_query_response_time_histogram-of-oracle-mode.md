# GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.1系では、このビューはV4.2.1 BP7バージョンから導入されました。V4.2.x系の他のバージョンでは、このビューはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM` は、現在のテナント内のすべてのノードにおけるQuery実行時間のヒストグラム情報を集計するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | -------- | ------------------ | -------- |
| SVR_IP        | VARCHAR2(46)  | NO   | ノードのIPアドレス     |
| SVR_PORT      | NUMBER(38)    | NO   | ノードのポート番号     |
| TENANT_ID     | NUMBER(38)    | NO   | テナント     |
| SQL_TYPE      | VARCHAR2(128) | NO   | QUERYのステートメントタイプ：<ul><li>SELECT</li><li>INSERT</li><li>UPDATE</li><li>DELETE</li><li>REPLACE</li><li>COMMIT</li><li>OTHER</li><li>INNER SQL</li><li>TABLEAPI SELECT</li><li>TABLEAPI INSERT</li><li>TABLEAPI DELETE</li><li>TABLEAPI UPDATE</li><li>TABLEAPI REPLACE</li><li>TABLEAPI QUERY AND MUTATE</li><li>TABLEAPI OTHER</li><li>HBASE SCAN</li><li>HBASE PUT</li><li>HBASE DELETE</li><li>HBASE APPEND</li><li>HBASE INCREMENT</li><li>HBASE CHECK AND PUT</li><li>HBASE CHECK AND DELETE</li><li>HBASE HYBRID BATCH</li></ul>     |
| RESPONSE_TIME | NUMBER        | NO   | 応答時間の区間値。単位は秒     |
| COUNT         | NUMBER(38)    | NO   | 対応する区間のカウント     |
| TOTAL         | NUMBER        | NO   | 対応する区間の時間合計。単位は秒     |

## クエリ例

現在のテナントのすべてのノードにおけるQuery実行時間のヒストグラム情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM WHERE ROWNUM = 2\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SVR_IP: xx.xx.xx.xx
     SVR_PORT: 2882
    TENANT_ID: 1002
     SQL_TYPE: SELECT
RESPONSE_TIME: 0.000001
        COUNT: 0
        TOTAL: 0.000000
*************************** 2. row ***************************
       SVR_IP: xx.xx.xx.xx
     SVR_PORT: 2882
    TENANT_ID: 1002
     SQL_TYPE: SELECT
RESPONSE_TIME: 0.000010
        COUNT: 0
        TOTAL: 0.000000
2 rows in set
```

現在のテナントのすべてのノード上で `TABLEAPI SELECT` タイプのQuery実行時間のヒストグラム情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM WHERE SQL_TYPE = "TABLEAPI SELECT" AND ROWNUM = 2\G
```

クエリ結果は次のとおりです：
