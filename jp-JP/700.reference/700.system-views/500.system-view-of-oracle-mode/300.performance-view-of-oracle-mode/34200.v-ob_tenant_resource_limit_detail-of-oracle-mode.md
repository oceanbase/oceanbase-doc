# V$OB_TENANT_RESOURCE_LIMIT_DETAIL

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`V$OB_TENANT_RESOURCE_LIMIT_DETAIL`は、現在のテナントがこのOBServer上で受ける論理リソースの制限と、各制限の上限値を表示するために使用されます。

## フィールドの説明

| フィールド名  |  タイプ  | NULLを許容するか |     説明     |
|----------|--------|-----------------|-------------|
| SVR_IP               | VARCHAR2(46)  | NO   |  OBServerのIPアドレス    |
| SVR_PORT             | NUMBER(38)    | NO   |  OBServerのRPCポート    |
| TENANT_ID            | NUMBER(38)    | NO   |  テナントID    |
| RESOURCE_NAME        | VARCHAR2(128) | NO   |  リソース名    |
| LIMIT_TYPE           | VARCHAR2(128) | NO   |  制限名    |
| LIMIT_VALUE          | NUMBER(38)    | NO   |  制限値    |

## クエリ例

現在のテナントがこのOBServer上で受ける論理リソースの制限と、各制限の上限値を照会します。

```shell
obclient[SYS]> SELECT * FROM SYS.V$OB_TENANT_RESOURCE_LIMIT_DETAIL WHERE ROWNUM = 5;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+---------------+---------------+---------------------+
| SVR_IP         | SVR_PORT | TENANT_ID | RESOURCE_NAME | LIMIT_TYPE    | LIMIT_VALUE         |
+----------------+----------+-----------+---------------+---------------+---------------------+
|   xx.xx.xx.xx  |     2882 |      1002 | ls            | configuration |                  90 |
|   xx.xx.xx.xx  |     2882 |      1002 | ls            | memstore      | 9223372036854775807 |
|   xx.xx.xx.xx  |     2882 |      1002 | ls            | memory        |                   8 |
|   xx.xx.xx.xx  |     2882 |      1002 | ls            | data_disk     | 9223372036854775807 |
|   xx.xx.xx.xx  |     2882 |      1002 | ls            | clog_disk     |                  27 |
+----------------+----------+-----------+---------------+---------------+---------------------+
5 rows in set
```
