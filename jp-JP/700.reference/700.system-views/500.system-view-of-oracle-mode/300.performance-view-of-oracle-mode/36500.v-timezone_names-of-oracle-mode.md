# V$TIMEZONE_NAMES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

有効なタイムゾーン名を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>

## フィールド説明

| **フィールド名** |    **型**     | **NULL許容** |     **説明**     |
|----------|---------------|----------------|----------------|
| TZNAME   | varchar(64)   | NO             | タイムゾーンの地域名           |
| TZABBREV | varchar(8)    | NO             | 比較時間の略称（例：PDT） |
| CON_ID   | decimal(38,0) | NO             | テナントID          |
