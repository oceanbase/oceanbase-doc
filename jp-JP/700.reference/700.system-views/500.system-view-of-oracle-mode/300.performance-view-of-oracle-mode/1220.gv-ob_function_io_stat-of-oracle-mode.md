# GV$OB_FUNCTION_IO_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントにおけるすべてのOBServerノード上でのFunctionレベルのIO統計情報を表示します。Functionレベルのバックグラウンドタスクに対応するリソースグループでリソース管理計画が有効になっていない場合、表示されるIO情報は統計参照用であり、対応するリソースは制限されません。

## フィールドの説明

|             フィールド名          |      型    | NULL許容 |            説明                                            |
|------------------------------|--------------|----------------|------------------------------------------------------------|
| SVR_IP                       | VARCHAR2(46) | NO             | サーバーIPアドレス     |
| SVR_PORT                     | NUMBER(38)   | NO             | サーバーポート番号       |
| TENANT_ID                    | NUMBER(38)   | NO             | テナントID            |
| FUNCTION_NAME                | VARCHAR2(32) | NO             | Functionに対応するバックグラウンドタスク名：<ul><li>`COMPACTION_HIGH`：Mini MergeおよびDDL KV Mergeタスク</li> <li>`HA_HIGH`：レプリケーション、Rebuild、復元などの高優先順位・高信頼性タスク</li> <li>`COMPACTION_MID`：Minor Mergeタスク</li> <li>`HA_MID`：中優先順位・高信頼性タスク、例えば移行タスク</li> <li>`COMPACTION_LOW`：Major Mergeタスク</li> <li>`HA_LOW`：バックアップやバックアップクリーンアップなどの低優先順位・高信頼性タスク</li> <li>`DDL`：一意インデックス検証、列削除後のデータ補完などのシナリオのタスク</li> <li>`DDL_HIGH`：DDL MemTableのダンプタスク</li> <li>`CLOG_LOW`：物理スタンバイデータベースとCDCの読み取りタスク</li> <li>`CLOG_MID`<：Followerレプリカが共有ストレージから読み取る、ログアーカイブがローカルディスクから読み取るなどのタスク</li> <li>`CLOG_HIGH`：clogをローカルディスクに書き込む、clogファイルを共有ストレージにアップロードする、Followerレプリカがローカルディスクから読み取るなどのタスク</li> <li>`GC_MACRO_BLOCK`：マクロブロックの回収および再利用タスク</li> <li>`OPT_STATS`：統計情報収集タスク</li> <li>`IMPORT`：インポートタスク</li> <li>`SQL_AUDIT`：SQL監査ログの永続化タスク</li> <li>`DEFAULT_FUNCTION`：既に定義されたタスク以外のすべてのバックグラウンドタスク</li></ul>    |
| MODE                         | VARCHAR2(32) | NO             | IOに対応する読み書きモード（共有ストレージのリクエストはリモートリクエスト、その他のタイプのリクエストはローカルリクエスト）：<ul><li>`LOCAL READ`：ローカル読み取り</li> <li>`LOCAL WRITE`：ローカル書き込み</li> <li>`REMOTE READ`：リモート読み取り</li> <li>`REMOTE WRITE`：リモート書き込み</li></ul>    |
| SIZE                         | NUMBER(38)   | NO             | 平均IOサイズ     |
| REAL_IOPS                    | NUMBER(38)   | NO             | 実際のIOPS     |
| REAL_MBPS                    | NUMBER(38)   | NO             | 実際の帯域幅、単位はMB/s     |
| SCHEDULE_US                  | NUMBER(38)   | NO             | IOスケジューリングの平均消費時間、単位はus     |
| IO_DELAY_US                  | NUMBER(38)   | NO             | ディスクIOの平均実行時間、単位はus     |
| TOTAL_US                     | NUMBER(38)   | NO             | IOの全体的な平均実行時間、単位はus     |

## クエリ例

ユーザーテナントが、自身のテナントにおけるすべてのOBServerノード上でのFunctionレベルのIO統計情報をクエリします。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_FUNCTION_IO_STAT WHERE ROWNUM >= 5;
```

クエリ結果は次のとおりです：

