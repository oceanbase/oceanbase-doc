# GV$DBLINK

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは現在サポートされていません。作成済みのDBLinkを確認するには、<a href="../200.dictionary-view-of-oracle-mode/7900.dba_db_links.md">DBA_DB_LINKS</a>、<a href="../200.dictionary-view-of-oracle-mode/900.all_db_links.md">ALL_DB_LINKS</a>、<a href="../200.dictionary-view-of-oracle-mode/26000.user_db_links.md">USER_DB_LINKS</a> などのビューを使用してください。</p>
</main>

## 機能の概要

すべてのノードで開始されたクエリセッションが開いた後のすべてのデータベース接続（`IN_TRANSACTION=YES` の接続）を表示します。これらのデータベース接続は、閉じる前にコミットまたはロールバックする必要があります。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードでのみ適用されます。</p>
  </main>
