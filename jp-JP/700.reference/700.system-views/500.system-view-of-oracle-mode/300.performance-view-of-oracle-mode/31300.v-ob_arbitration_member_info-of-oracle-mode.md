# V$OB_ARBITRATION_MEMBER_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのアービトレーションメンバー情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリームID |
| SVR_IP | VARCHAR2(46) | NO | アービトレーションサーバーIPアドレス |
| SVR_PORT | NUMBER(38) | NO | アービトレーションサーバーポート |
| PROPOSAL_ID | NUMBER(38) | NO | Paxos提案ID |
| CONFIG_VERSION | VARCHAR2(128) | NO | 構成情報バージョン番号 |
| ACCESS_MODE | VARCHAR2(32) | NO | アクセスモード |
| PAXOS_MEMBER_LIST | VARCHAR2(1024) | NO | メンバーリスト |
| PAXOS_REPLICA_NUM | NUMBER(38) | NO | 合意数 |
| ARBITRATION_MEMBER | VARCHAR2(128) | NO | アービトレーションメンバー |
| DEGRADED_LIST | VARCHAR2(1024) | NO | 降格されたレプリカのリスト |
