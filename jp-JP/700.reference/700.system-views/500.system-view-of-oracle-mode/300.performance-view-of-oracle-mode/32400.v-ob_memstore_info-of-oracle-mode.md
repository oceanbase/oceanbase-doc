# V$OB_MEMSTORE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>V$MEMSTORE_INFO</code> は、V4.0.0バージョン以降、<code>V$OB_MEMSTORE_INFO</code> に名称が変更されました。V4.0.0以降のバージョンでは、新しいビュー名 <code>V$OB_MEMSTORE_INFO</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>V$MEMSTORE_INFO</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

現在のテナントが現在のサーバー上に持つすべてのパーティションのMemTableの詳細情報を表示します。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリーム |
| TABLE_ID | NUMBER(38) | NO | データシャーディングID |
| IS_ACTIVE | VARCHAR2(3) | NO | アクティブかどうか |
| START_SCN | NUMBER(38) | NO | ストレージ開始ポイント |
| END_SCN | NUMBER(38) | NO | ストレージ終了ポイント |
| FREEZE_TS | NUMBER(38) | NO | 凍結された時点 |

## クエリ例

ユーザーテナントが、現在のサーバー上にある自身のテナントのすべてのパーティションのMemTableの詳細情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_MEMSTORE_INFO;
```
