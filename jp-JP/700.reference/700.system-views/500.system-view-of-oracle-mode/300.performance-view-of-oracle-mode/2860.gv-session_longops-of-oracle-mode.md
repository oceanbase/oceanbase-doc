# GV$SESSION_LONGOPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

クラスタのDDL操作の実行状態と進捗を表示します。

## フィールドの説明

|     **フィールド名**     |    **型**     | **NULL許容** |  **説明**   |
|------------------|---------------|----------------|-----------|
| SID              | NUMBER    | NO             | セッションID     |
| TRACE_ID         | VARCHAR(64)  | NO   | ステートメントのtrace_id    |
| OPNAME           | VARCHAR(64)  | NO             | 操作名      |
| TARGET           | VARCHAR(64)  | NO             | 操作対象      |
| SVR_IP           | VARCHAR(46)   | NO             | 操作が行われたマシンのIPアドレス |
| SVR_PORT         | NUMBER    | NO             | 操作が行われたマシンのポート番号 |
| START_TIME       | VARCHAR(256)    | NO             | 開始時間      |
| ELAPSED_SECONDS  | NUMBER | NO             | 消費済み時間    |
| TIME_REMAINING   | NUMBER    | NO             | 残りの推定時間  |
| LAST_UPDATE_TIME | VARCHAR(256)   | NO             | 統計情報の更新時間  |
| MESSAGE          | VARCHAR(512)  | NO             | 備考情報      |
