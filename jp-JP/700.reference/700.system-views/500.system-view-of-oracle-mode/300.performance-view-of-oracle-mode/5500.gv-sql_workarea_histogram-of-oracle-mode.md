# GV$SQL_WORKAREA_HISTOGRAM

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのノードで以前に実行されたすべてのワークエリアに関する統計情報を表示します。例えば、1M～2Mの区間でフルインメモリ処理が行われた回数やワンパス処理の回数などです。

## **フィールドの説明**

|        **フィールド名**        |   **タイプ**   | **NULL値を許容するか** |                  **説明**                  |
|------------------------|------------|----------------|------------------------------------------|
| LOW_OPTIMAL_SIZE       | NUMBER | NO             | workareaがoptimalモードで使用する最小メモリ量              |
| HIGH_OPTIMAL_SIZE      | NUMBER | NO             | workareaがoptimalモードで使用する最大メモリ量              |
| OPTIMAL_EXECUTIONS     | NUMBER | NO             | workareaが最低および最高範囲のoptimalモードで実行される回数             |
| ONEPASS_EXECUTIONS     | NUMBER | NO             | workareaが最低および最高範囲のone passモードで実行される回数     |
| MULTIPASSES_EXECUTIONS | NUMBER | NO             | workareaが最低および最高範囲のmulti passesモードで実行される回数 |
| TOTAL_EXECUTIONS       | NUMBER | NO             | workareaの合計実行回数                         |
| CON_ID                 | NUMBER | NO             | テナントID                                    |
| SVR_IP                 | VARCHAR2(46)   | NO             | サーバーIPアドレス   |
| SVR_PORT               | NUMBER   | NO             | サーバーのポート番号   |

## クエリ例

このテナントのすべてのノードで以前に実行されたすべてのワークエリアの統計情報を確認し、上位10件のレコードを表示します。

```shell
obclient[SYS]> SELECT * FROM SYS.GV$SQL_WORKAREA_HISTOGRAM WHERE ROWNUM<= 10;
```
