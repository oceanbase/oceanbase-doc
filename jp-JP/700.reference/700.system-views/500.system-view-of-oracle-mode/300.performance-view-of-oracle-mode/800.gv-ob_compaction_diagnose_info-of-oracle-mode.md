# GV$OB_COMPACTION_DIAGNOSE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上のCompaction診断情報を表示します。

## フィールドの説明

|     フィールド名      |      型      | NULL許容    |                                            説明                                            |
|---------------|--------------|------------|---------|
| SVR_IP        | VARCHAR2(46) | NO         | サーバーIPアドレス                                                                                |
| SVR_PORT      | NUMBER(38)   | NO         | サーバーポート番号|
| TENANT_ID     | NUMBER(38)   | NO         | テナントID |
| TYPE          | VARCHAR2(64) | NO         | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのマージ</li> <li>`MEDIUM_MERGE`：パーティションレベルのマージ</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>  |
| LS_ID         | NUMBER(38)   | NO         | ログストリームID|
| TABLET_ID     | NUMBER(38)   | NO         | データシャーディングID                                                                                  |
| STATUS        | VARCHAR2(15) | NO         | タスク状態  |
| CREATE_TIME        | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO         | 作成日時  |
| DIAGNOSE_INFO | VARCHAR2（1024） | NO         | 診断情報  |
