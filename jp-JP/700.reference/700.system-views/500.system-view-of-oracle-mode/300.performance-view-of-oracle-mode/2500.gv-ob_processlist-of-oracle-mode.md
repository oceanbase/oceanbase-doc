# GV$OB_PROCESSLIST

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_PROCESSLIST` は、テナントが存在するすべてのOBServerノード上のセッション情報を表示するために使用されます。

## フィールド説明

|----------------|------------------|------------|--------------------------------------------------------------|

## クエリ例

テナントが存在するすべてのOBServerノード上のセッション情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_PROCESSLIST WHERE ROWNUM < = 1 \G
```
