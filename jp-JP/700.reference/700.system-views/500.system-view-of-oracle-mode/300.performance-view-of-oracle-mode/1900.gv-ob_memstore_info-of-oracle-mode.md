# GV$OB_MEMSTORE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>GV$MEMSTORE_INFO</code> は V4.0.0 以降、<code>GV$OB_MEMSTORE_INFO</code> に変更されました。V4.0.0 以降のバージョンでは、新しいビュー名 <code>GV$OB_MEMSTORE_INFO</code> を使用してクエリを実行する必要があります。古いビュー名 <code>GV$MEMSTORE_INFO</code> を使用したクエリはエラーになります。</p>
</main>

## 機能の概要

現在のテナントがすべてのサーバー上のすべてのパーティションの MemTable の詳細情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーポート |
| TENANT_ID | NUMBER(38) | NO | テナントID |
| LS_ID | NUMBER(38) | NO | ログストリーム |
| TABLE_ID | NUMBER(38) | NO | データシャードID |
| IS_ACTIVE | VARCHAR2(3) | NO | アクティブかどうか |
| START_SCN | NUMBER(38) | NO | ストレージ開始ポイント |
| END_SCN | NUMBER(38) | NO | ストレージ終了ポイント |
| FREEZE_TS | NUMBER(38) | NO | 凍結された時点 |

ユーザーテナントが現在のテナントがすべてのサーバー上のすべてのパーティションの MemTable の詳細情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_MEMSTORE_INFO;
```
