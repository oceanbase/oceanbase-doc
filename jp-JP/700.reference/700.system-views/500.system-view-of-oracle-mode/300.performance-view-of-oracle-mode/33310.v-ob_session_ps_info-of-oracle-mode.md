# V$OB_SESSION_PS_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_SESSION_PS_INFO` は、現在のOBServerテナント内のすべてのセッションが開いているPS情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| ------------ | -------- | ------------------- | -------- |
| SVR_IP             | VARCHAR2(46) | NO | OBServer IP |
| SVR_PORT           | NUMBER(38)   | NO | OBServer PORT |
| TENANT_ID          | NUMBER(38)   | NO | テナントID |
| PROXY_SESSION_ID   | NUMBER(38)   | NO | ODP内のSession ID |
| SESSION_ID         | NUMBER(38)   | NO | V4.2.x系バージョンについて：<ul><li>V4.2.5 BP3 Hotfix5 より前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはServer Session IDを表します。</li><li>V4.2.5 BP3 Hotfix5 以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODP内のパラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul>  |
| PS_CLIENT_STMT_ID  | NUMBER(38)   | NO | クライアントがPrepareリクエストを送信した後、クライアントに返されるPS ID |
| PS_INNER_STMT_ID   | NUMBER(38)   | NO | OBServer内の内部PS ID（PS Cache内のPS ID） |
| STMT_TYPE          | VARCHAR2(256)| NO | Prepareのステートメントタイプ。値は `T_SELECT`、`T_INSERT`、`T_REPLACE`、`T_DELETE`、`T_UPDATE`、`T_MERGE`、`T_EXPLAIN`、`T_CREATE_TABLE`、`T_DROP_TABLE` などです。 |
| PARAM_COUNT        | NUMBER(38)   | NO | PSのパラメータ数 |
| PARAM_TYPES        | CLOB         | NO | パラメータタイプのリスト。Prepareステートメント内のすべてのパラメータのタイプリストで、各パラメータタイプは数字で表され、異なるパラメータタイプは英字のカンマで区切られます。 |
| REF_COUNT          | NUMBER(38)   | NO | `ps_session_info_` の参照カウント。`ps_session_info_` はセッション上のプロパティであり、セッションがステートメントをPrepareした後、そのセッション上に `ps_session_info_` が存在します。 |
| CHECKSUM           | NUMBER(38)   | NO | PS Cache内のパラメータ化されたSQLの文字列チェックサム |

## クエリ例

現在のOBServerテナント内のすべてのセッションが開いているPS情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SESSION_PS_INFO;
```

クエリ結果は次のとおりです：

```shell
+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+
| SVR_IP        | SVR_PORT | TENANT_ID | PROXY_SESSION_ID | SESSION_ID | PS_CLIENT_STMT_ID | PS_INNER_STMT_ID | STMT_TYPE | PARAM_COUNT | PARAM_TYPES | REF_COUNT | CHECKSUM   |
+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+
| xx.xx.xx.xx   |    17119 |      1002 |                0 | 3221643421 |                 1 |                1 | T_SELECT  |           3 | 3, 15, 202  |         1 | 1807504655 |
+---------------+----------+-----------+------------------+------------+-------------------+------------------+-----------+-------------+-------------+-----------+------------+
```
