# V$OB_UNITS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_UNITS`は、このOBServerノードのUnit情報を表示します。

## フィールドの説明

|       フィールド名       |      タイプ      | NULL値を許容するか |                                                                            説明                                                                             |
|------------------|--------------|------------|-------------------------------------------------------------------------|
| SVR_IP           | VARCHAR2(46)  | NO         | サーバーのIPアドレス                                                              |
| SVR_PORT         | NUMBER(38)   | NO         | サーバーのポート番号                                                                 |
| UNIT_ID          | NUMBER(38)   | NO         | Unit ID                                                                |
| TENANT_ID        | NUMBER(38)   | NO         | Unitが所属するテナントID                                                          |
| ZONE             | VARCHAR2(128) | NO         | Zone名                                                                |
| ZONE_TYPE        | VARCHAR2(128) | NO         | Unitが存在するZoneのZoneタイプ。値は以下のとおりです：<ul><li>`NULL`：この列の値が無効であり、OBServerノードの再起動時に一時的に無効な値が表示されることを示します。</li> <li>`ReadWrite`：読み書きゾーン</li> <li>`Encryption`：暗号化ゾーン</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REGION           | VARCHAR2(128) | NO         | Unitが存在するZoneが属するRegion名。設定されていない場合、デフォルトは`default_region`です。値が`NULL`の場合、この列の値が無効であり、OBServerノードの再起動時に一時的に無効な値が表示されることを示します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>  |
| MIN_CPU          | NUMBER(38)       | NO         | CPUスペックの下限                                                               |
| MAX_CPU          | NUMBER(38)       | NO         | CPUスペックの上限                                                               |
| MEMORY_SIZE       | NUMBER(38)   | NO         | メモリサイズ、単位はバイト                                                           |
| MIN_IOPS         | NUMBER(38)   | NO         | ディスクIOPSスペックの下限                                                           |
| MAX_IOPS         | NUMBER(38)   | NO         | ディスクIOPSの上限値                                                           |
| IOPS_WEIGHT    | NUMBER(38)   | NO         | IOPSの重み |
| LOG_DISK_SIZE  | NUMBER(38)   | NO         | ログディスクサイズ                                                                    |
| LOG_DISK_IN_USE | NUMBER(38)   | NO         | ログディスクの使用済みサイズ                                                               |
| DATA_DISK_IN_USE | NUMBER(38)   | NO         | データディスクの使用済みサイズ                                                               |
| STATUS           | VARCHAR2(64)  | NO         | Unitの状態：<ul><li>`NORMAL`：正常な状態   </li><li> `MIGRATING IN`：移入中   </li><li> `MIGRATING OUT`：移出中   </li><li> `MARK DELETING`：削除マーク付け</li><li>`WAIT GC`：GCデータ待機 </li><li>`DELETING`：GC完了、削除中 </li><li> `ERROR`：エラー状態</li></ul>  |
| CREATE_TIME      | NUMBER(38) | NO         | UnitがOBServerノード上で作成された時間                                                 |
| REPLICA_TYPE     | VARCHAR2(7)   | NO         | レプリカタイプ。デフォルトは`FULL` <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、フィールド<code>REPLICA_TYPE</code>はV4.2.5 BP7バージョンから導入されました。</p></main>    |
