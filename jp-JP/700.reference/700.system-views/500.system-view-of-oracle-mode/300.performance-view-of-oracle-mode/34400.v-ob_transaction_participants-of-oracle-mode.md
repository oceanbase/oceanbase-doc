# V$OB_TRANSACTION_PARTICIPANTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける、現在のOBServerノード上でアクティブなトランザクションの参加者コンテキスト情報を表示します。

## フィールドの説明

|       フィールド名       |                タイプ                 | NULLを許容するか |    説明     |
|------------------|-----------------------------------|------------|-----------|
| TENANT_ID        | NUMBER(38)                        | NO         | テナントID     |
| SVR_IP           | VARCHAR2(46)                      | NO         | サーバーIPアドレス |
| SVR_PORT         | NUMBER(38)                        | NO         | サーバーのポート番号    |
| SESSION_ID       | NUMBER(38)                        | NO         | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>このフィールドは、すべての接続方式（直接接続モード/ODPモード）においてサーバーセッションIDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODP内の構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>       |
| SCHEDULER_ADDR   | VARCHAR2(64)                      | NO         | スケジューラーが所属するノードのアドレス |
| TX_TYPE          | VARCHAR2(11)                      | NO         | トランザクションタイプ      |
| TX_ID            | NUMBER(38)                        | NO         | トランザクションID      |
| LS_ID            | NUMBER(38)                        | NO         | 所属ログストリームID   |
| PARTICIPANTS     | VARCHAR2(1024)                    | NO         | 参加者リスト     |
| CTX_CREATE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | コンテキスト作成時点  |
| TX_EXPIRED_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES        | トランザクションタイムアウト時点   |
| STATE            | VARCHAR2(9)                       | NO         | コンテキストコミット状態   |
| ACTION           | VARCHAR2(10)                      | NO         | 前回実行されたアクション  |
| PENDING_LOG_SIZE | NUMBER(38)                        | NO         | 永続化待ちデータサイズ  |
| FLUSHED_LOG_SIZE | NUMBER(38)                        | NO         | 永続化済みデータサイズ  |
| IS_EXITING       | VARCHAR2(3)                       | NO         | 現在終了中か    |
| ROLE             | VARCHAR2(8)                       | NO         | コンテキストロール     |

obclient [SYS]> SELECT * FROM SYS.V$OB_TRANSACTION_PARTICIPANTS\G
