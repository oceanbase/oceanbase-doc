# V$OB_PS_ITEM_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_PS_ITEM_INFO` は、プリペアドステートメントの監視機能を提供し、PSキャッシュ内のすべてのプリペアドステートメントの基本情報を含みます。

## フィールドの説明

|        フィールド名         |      型      | NULL許容 |             説明             |
|---------------------|--------------|------------|----------------------------|
| SVR_IP              | VARCHAR2(46) | NO         | サーバーのIPアドレス                  |
| SVR_PORT            | NUMBER(38)   | NO         | サーバーのポート番号                     |
| STMT_ID             | NUMBER(38)   | NO         | PSキャッシュ内の対応するステートメントのstmt_id情報 |
| DB_ID               | NUMBER(38)   | NO         | プリペアドステートメントが関連するデータベースID       |
| PS_SQL              | CLOB         | NO         | プリペアドステートメントのSQL情報           |
| PARAM_COUNT         | NUMBER(38)   | NO         | プリペアドステートメントのパラメータ数情報            |
| STMT_ITEM_REF_COUNT | NUMBER(38)   | NO         | stmt_itemの参照カウント情報          |
| STMT_INFO_REF_COUNT | NUMBER(38)   | NO         | stmt_infoの参照カウント情報          |
| MEM_HOLD            | NUMBER(38)   | NO         | そのプリペアドステートメントが占用するメモリサイズ     |
| STMT_TYPE           | NUMBER(38)   | NO         | そのプリペアドステートメントのタイプ情報|
| CHECKSUM            | NUMBER(38)   | NO         | そのプリペアドステートメントのchecksum |
| EXPIRED             | NUMBER(38)   | NO         | そのプリペアドステートメントが期限切れかどうか |
