# GV$OB_TENANT_RESOURCE_LIMIT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`GV$OB_TENANT_RESOURCE_LIMIT`は、現在のテナントがすべてのOBServer上で使用している論理リソースの使用量、上限値、有効な制限条件、およびダウンタイム後の再起動時に許容される最大使用量を表示するために使用されます。

## フィールドの説明

| フィールド名  |  タイプ  | NULLを許容するか |     説明     |
|----------|--------|-----------------|-------------|
| SVR_IP               | VARCHAR2(46)  | NO   |  OBServerのIPアドレス    |
| SVR_PORT             | NUMBER(38)    | NO   |  OBServerのRPCポート    |
| TENANT_ID            | NUMBER(38)    | NO   |  テナントID    |
| ZONE                 | VARCHAR2(128) | NO   |  ZONEの名前    |
| RESOURCE_NAME        | VARCHAR2(128) | NO   |  リソース名    |
| CURRENT_UTILIZATION  | NUMBER(38)    | NO   |  リソースの現在の使用量    |
| MAX_UTILIZATION      | NUMBER(38)    | NO   |  マシン起動後のリソースの最大使用量    |
| RESERVED_VALUE       | NUMBER(38)    | NO   |  予約された量。この値は安定した運用にとって最も基本的な保証です    |
| LIMIT_VALUE          | NUMBER(38)    | NO   |  許可される最大使用量    |
| EFFECTIVE_LIMIT_TYPE | VARCHAR2(128) | NO   |  効力を持つ制限タイプ。例：構成パラメータ、メモリ、CPU、ディスクなど    |

## クエリ例

現在のテナントがすべてのOBServer上で使用している論理リソースの使用量、上限値、有効な制限条件、およびダウンタイム後の再起動時の最大使用量を照会します。

```shell
obclient[SYS]> SELECT * FROM SYS.GV$OB_TENANT_RESOURCE_LIMIT;
```
