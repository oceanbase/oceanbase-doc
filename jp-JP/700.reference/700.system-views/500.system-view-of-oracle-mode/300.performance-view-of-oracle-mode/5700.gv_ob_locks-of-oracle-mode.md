# GV$OB_LOCKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

`GV$OB_LOCKS` ビューは、現在ユーザーが各テーブルで保持または要求しているロックの状況を表示するために使用されます。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SVR_IP | VARCHAR2(46) | NO | ロックを保持またはロックを要求しているOBServerノードのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | ロックを保持またはロックを要求しているOBServerノードのポート番号 |
| TENANT_ID | NUMBER(38) | NO | ロックを保持またはロックを要求しているテナントのID |
| TRANS_ID | NUMBER(38) | NO | ロックを保持またはロックを要求しているトランザクションID |
| SESSION_ID | NUMBER(38)    | NO   | ロックを保持またはロックを要求しているセッションID<ul><li>V4.3.x系では、このフィールドはV4.3.2バージョンから導入されました。<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> </li><li>V4.2.x系では、このフィールドはV4.2.5バージョンから導入されました。すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。 </li></ul> |
| TYPE | VARCHAR2(9) | NO | ロックタイプ：<ul><li>TM：テーブルロック</li><li>TX：トランザクションロック</li><li>TR：行ロック</li></ul> |
| ID1 | bigint(20) | NO | ロック識別子1：<ul><li>TM：トランザクションID</li><li>TX：トランザクションID</li><li>TR：トランザクションID</li></ul> |
| ID2 | bigint(20) | NO | ロック識別子2：<ul><li>TM：セッションID（トランザクション外部テーブルロックの場合はNULL）</li><li>TX：セッションID</li><li>TR：セッションID</li></ul> |
| ID3 | varchar(512) | NO | ロック識別子3：<ul><li>TM：TABLE_ID / TABLET_ID</li><li>TX：NULL</li><li>TR：TABLET_ID + 行rowkey</li></ul> <main id="notice" type='explain'><h4>説明</h4><p><ul><li>V4.3.x系では、このフィールドはV4.3.2バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.5バージョンから導入されました。</li></ul></p></main>|
| LMODE | VARCHAR2(4) | NO | 現在保持しているロックのモード：<ul><li>NONE：いずれのロックも保持していないことを示します</li><li>RS：ROW SHARE</li><li>RX：ROW EXCLUSIVE</li><li>S：SHARE</li><li>SRX：SHARE ROW EXCLUSIVE</li><li>X：EXCLUSIVE</li></ul> |
| REQUEST | VARCHAR2(8) | NO | 現在要求しているロックのモード：<ul><li>NONE：いずれのロックも要求していないことを示します </li><li>RS：ROW SHARE  </li><li>RX：ROW EXCLUSIVE  </li><li>S：SHARE  </li><li>SRX：SHARE ROW EXCLUSIVE  </li><li>X：EXCLUSIVE  </li></ul>|
| CTIME | NUMBER(38) | NO | ロックの保持または待機時間、単位はマイクロ秒 |
| BLOCK | NUMBER | NO | 現在のトランザクションが要求するロックが他のトランザクションによって保持されているかどうかを示します：<ul><li>0：要求するロックが他のトランザクションによって保持されていないことを示し、そのトランザクションがロックを保持しています  </li><li>1：要求するロックが他のトランザクションによって保持されていることを示し、そのトランザクションがブロックされています </li></ul>|
