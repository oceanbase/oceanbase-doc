# V$OB_JAVA_UDF_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP4バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のテナントが現在のOBServerノード上で実行したJava UDFの統計情報を表示します。これには、呼び出し回数、成功および失敗回数、同時実行数、所要時間の分布、各実行段階の所要時間などが含まれます。各Java UDFは、関数タイプと実行モードごとに集計されます。

使用方法は以下の通りです：

* 統計情報はメモリ内にのみ保存され、OBServerノードが再起動するとクリアされます。
* 各テナントは各OBServerノード上で最大1024件の統計情報を保持できます。上限を超えた場合、削除済みのJava UDFの統計情報から優先的に削除し、次に、最後の呼び出しから最も長い時間が経過したJava UDFの統計情報から順に削除します。統計情報の削除や破棄はJava UDFの実行に影響しません。
* 現在のテナントに存在し、現在のユーザーがアクセス権限を持つJava UDFの統計情報のみが表示されます。

## フィールドの説明

|     フィールド名    |     型    | NULL許容 |      説明      |
|----------------|-------------|----------------|----------------|
| SVR_IP | VARCHAR2(46) | NO | OBServerノードのIPアドレス。 |
| SVR_PORT | NUMBER(38) | NO | OBServerノードのポート番号。 |
| TENANT_ID | NUMBER(38) | NO | テナントID。 |
| PACKAGE_ID | NUMBER(38) | NO | Java UDFが属するパッケージのID。 |
| UDF_ID | NUMBER(38) | NO | Java UDFのID。 |
| DATABASE_ID | NUMBER(38) | YES |
| UDF_NAME | VARCHAR2(128) | NO | Java UDFの名前。 |
| SCHEMA_STATUS | VARCHAR2(16) | NO | Java UDFのスキーマ状態：<ul><li>`ACTIVE`：Java UDFが存在する</li></ul> |
| CLASS_NAME | VARCHAR2(1024) | YES |
| ROUTINE_TYPE | VARCHAR2(32) | NO | 関数タイプ：<ul><li>`UDF`：Java UDF</li><li>`UDAF`：Java UDAF</li><li>`UDTF`：Java UDTF</li><li>`UNKNOWN`：未知のタイプ</li></ul> |
| EXECUTION_MODE | VARCHAR2(16) | NO | 実行モード：<ul><li>`IN_PROCESS`：JNIを介してOBServerプロセス内で実行</li><li>`SANDBOX`：独立したサンドボックスプロセスで実行</li></ul> |
| CALL_COUNT | NUMBER(38) | NO | 累計呼び出し回数。ベクトル化された一括呼び出しは1回としてカウントされます。 |
| ROW_COUNT | NUMBER(38) | NO | 処理した入力行数の累計。 |
| SUCCESS_COUNT | NUMBER(38) | NO | 成功した呼び出し回数の累計。 |
| FAIL_COUNT | NUMBER(38) | NO | 失敗した呼び出し回数の累計。タイムアウトおよび中断された呼び出しを含みます。 |
| TIMEOUT_COUNT | NUMBER(38) | NO | タイムアウトした呼び出し回数の累計。`FAIL_COUNT`に含まれます。 |
| INTERRUPT_COUNT | NUMBER(38) | NO | 中断された（例えばKillまたはキャンセルされた）呼び出し回数の累計。`FAIL_COUNT`に含まれます。 |
| CURRENT_CONCURRENCY | NUMBER(38) | NO | 現在実行中の呼び出し数。 |
| PEAK_CONCURRENCY | NUMBER(38) | NO | ピーク時の同時呼び出し数。 |
| CALL_COUNT_1M | NUMBER(38) | NO | 最近1分間の呼び出し回数。 |
| QPS_1M | NUMBER(38) | NO | 過去1分間の平均1秒あたりの呼び出し回数。 |
| TOTAL_ELAPSED_US | NUMBER(38) | NO | 完了した呼び出しの累積実行時間（マイクロ秒単位）。 |
| AVG_ELAPSED_US | NUMBER(38) | YES |
| MAX_ELAPSED_US | NUMBER(38) | NO | 単一呼び出しの最大実行時間（マイクロ秒単位）。 |
| P95_ELAPSED_US_5M | NUMBER(38) | YES |
| P99_ELAPSED_US_5M | NUMBER(38) | YES |
| SERIALIZE_TIME_US | NUMBER(38) | NO | OceanBaseパラメータをJavaパラメータまたはサンドボックスリクエストに変換するための累積実行時間（マイクロ秒単位）。 |
| DISPATCH_TIME_US | NUMBER(38) | NO | 入力準備完了からJava実行結果またはサンドボックス応答を受信するまでの累積実行時間（マイクロ秒単位）。 |
| JAVA_TIME_US | NUMBER(38) | YES |
| DESERIALIZE_TIME_US | NUMBER(38) | NO | Java実行結果またはサンドボックス応答をOceanBase結果に変換するための累積実行時間（マイクロ秒単位）。 |
| INPUT_BYTES | NUMBER(38) | YES |
| OUTPUT_BYTES | NUMBER(38) | YES |
| LAST_CALL_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES |
| LAST_ERROR_CODE | NUMBER(38) | YES |
| LAST_ERROR_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES |
| STAT_START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | この統計情報の記録開始時刻。 |

## クエリ例

```shell
obclient> SELECT PACKAGE_ID, UDF_ID, UDF_NAME, ROUTINE_TYPE, EXECUTION_MODE, CALL_COUNT, SUCCESS_COUNT, FAIL_COUNT, QPS_1M, AVG_ELAPSED_US FROM SYS.V$OB_JAVA_UDF_STATS;
```
