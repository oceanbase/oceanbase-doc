# V$OB_COMPACTION_SUGGESTIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上でのCompactionに関する推奨情報を表示します。

## フィールドの説明

|    フィールド名     |                型                 | **NULL許容** |                                            説明                                            |
|-------------|-----------------------------------|----------------|--------|
| SVR_IP      | VARCHAR2(46)                      | NO             | サーバーIPアドレス                                                                                |
| SVR_PORT    | NUMBER(38)                        | NO             | サーバーポート番号|
| TENANT_ID   | NUMBER(38)                        | NO             | テナントID |
| TYPE        | VARCHAR2(64)                      | NO             | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータや未コミットトランザクションデータは含まれません。</li></ul>    |
| TABLE_ID    | NUMBER(38)                        | NO             | メインテーブルID |
| LS_ID       | NUMBER(38)                        | NO             | ログストリームID|
| TABLET_ID   | NUMBER(38)                        | NO             | データシャーディングID                                                                                  |
| START_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO             | 開始時間  |
| FINISH_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO             | 終了時間  |
| SUGGESTION  | VARCHAR2(1024)                      | NO             | 提案情報  |
