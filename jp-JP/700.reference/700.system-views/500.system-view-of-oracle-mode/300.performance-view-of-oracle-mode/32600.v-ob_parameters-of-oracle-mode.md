# V$OB_PARAMETERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_PARAMETERS`は、このOBServerノード上の構成パラメータ情報（名前にアンダースコア "_" で始まる隠しパラメータを含む）を表示するために使用されます。

## フィールドの説明

|    フィールド名    |       タイプ        | NULLを許容するか |                                説明                                 |
|------------|-----------------|------------|---------------------------------------------------------------------------------------------------|
| SVR_IP     | VARCHAR2(46)    | NO         | サーバーのIPアドレス                                                         |
| SVR_PORT   | NUMBER(38)      | NO         | サーバーのポート番号                                                            |
| ZONE       | VARCHAR2(128)   | NO         | ZONE名                                                             |
| SCOPE      | VARCHAR2(64)    | NO         | <ul><li>`CLUSTER`クラスタレベルの構成パラメータ </li><li> `TENANT`テナントレベルの構成パラメータ </li></ul> |
| TENANT_ID  | NUMBER(38)      | YES        | テナントID：<ul><li>`NULL`はどのテナントにも属していません</li><li>有効な値：テナントID </li></ul>    |
| NAME       | VARCHAR2(128)   | NO         | パラメータ名                                                             |
| DATA_TYPE  | VARCHAR2(128)   | YES        | パラメータ値のタイプ                                                            |
| VALUE      | VARCHAR2(65536) | NO         | パラメータ値                                                              |
| INFO       | VARCHAR2(4096)  | NO         | パラメータの説明                                                             |
| SECTION    | VARCHAR2(128)   | NO         | パラメータが属するモジュール                                                          |
| EDIT_LEVEL | VARCHAR2(128)   | NO         | パラメータ変更の有効化方法：<ul><li>`READONLY`：読み取り専用、変更不可   </li><li> `STATIC_EFFECTIVE`：変更後は再起動が必要 </li><li> `DYNAMIC_EFFECTIVE`：変更後は動的に有効化 </li></ul>   |
| DEFAULT_VALUE | VARCHAR2(65536) | NO   | パラメータのデフォルト値<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.2バージョンから導入されました。</p></main>       |
| ISDEFAULT     | VARCHAR2(3)     | NO   | 現在の値がデフォルト値であるか：<ul><li>NO：現在の値がデフォルト値ではないことを示します</li><li>YES：現在の値がデフォルト値であることを示します</li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.2バージョンから導入されました。</p></main> |

## クエリ例

このOBServerノード上の構成パラメータ情報を照会し、最初のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM SYS.V$OB_PARAMETERS WHERE ROWNUM < 2\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SVR_IP: xx.xx.xx.xx
     SVR_PORT: 28825
         ZONE: zone1
        SCOPE: CLUSTER
    TENANT_ID: NULL
         NAME: _restore_io_max_retry_count
    DATA_TYPE: NULL
        VALUE: 3
         INFO: the maximum number of retry attempts for restoring when encountering I/O errors.Range: [0,64] in integer
      SECTION: OBSERVER
   EDIT_LEVEL: DYNAMIC_EFFECTIVE
DEFAULT_VALUE: 3
    ISDEFAULT: YES
1 row in set (0.049 sec)
```
