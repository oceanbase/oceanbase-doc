# V$OB_PARAMETERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_PARAMETERS` は、現在のOBServerノード上のパラメータ（アンダースコア「_」で始まる非表示パラメータを含む）情報を表示するために使用されます。

## フィールド説明

|    フィールド名    |       型        | NULL許容   |                                説明                                 |
|------------|-----------------|------------|---------------------------------------------------------------------------------------------------|
| SVR_IP     | VARCHAR2(46)    | NO         | サーバーIPアドレス                                                         |
| SVR_PORT   | NUMBER(38)      | NO         | サーバーポート番号                                                            |
| ZONE       | VARCHAR2(128)   | NO         | Zone名                                                             |
| SCOPE      | VARCHAR2(64)    | NO         | <ul><li>`CLUSTER` クラスタレベル構成パラメータ   </li><li> `TENANT` テナントレベル構成パラメータ  </li></ul> |
| TENANT_ID  | NUMBER(38)      | YES        | テナントID ：<ul><li> `NULL` どのテナントにも属さない </li><li>有効値：テナントID  </li></ul> |
| NAME       | VARCHAR2(128)   | NO         | パラメータ名                                                             |
| DATA_TYPE  | VARCHAR2(128)   | YES        | パラメータ値の型    <main id="notice" type='explain'><h4>説明</h4><p>V4.3.0以降、このフィールドの値は`NULL`から変更され、構成パラメータの具体的なタイプ情報を表示するようになりました。</p></main>   |
| VALUE      | VARCHAR2(65536) | NO         | パラメータ値                                                              |
| INFO       | VARCHAR2(4096)  | NO         | パラメータの説明                                                             |
| SECTION    | VARCHAR2(128)   | NO         | パラメータが属するモジュール                                                          |
| EDIT_LEVEL | VARCHAR2(128)   | NO         | パラメータ変更の有効化方法：<ul><li>`READONLY`：読み取り専用、変更不可   </li><li> `STATIC_EFFECTIVE`：変更後は再起動が必要   </li><li> `DYNAMIC_EFFECTIVE`：変更後は動的に反映</li></ul>    |
| DEFAULT_VALUE | VARCHAR2(65536) | NO   | パラメータのデフォルト値<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li></ul></main>       |
| ISDEFAULT     | VARCHAR2(3)     | NO   | 現在の値がデフォルト値かどうかを示します。<ul><li>NO：現在の値がデフォルト値ではないことを示します。</li><li>YES：現在の値がデフォルト値であることを示します。</li></ul><main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li></ul></main> |

ビューの `DATA_TYPE` フィールドの取り得る値は以下のとおりです：

| フィールド値 | 説明 | 例（NAME=VALUE）|
| --------| ------ |------------------ |
| BOOL    | ブール型           | enable_ddl=True |
| INT     | 整数型           | log_disk_percentage=1 |
| DOUBLE  | 浮動小数点数型         | server_cpu_quota_min=1.0 |
| STRING  | 文字列型         | leak_mod_to_check='NONE' |
| STR_LIST| セミコロン区切りの文字列リスト| config_additional_dir='etc2;etc3' |
| TIME    | 時間範囲             | merger_check_interval='10m' |
| MOMENT  | 時点             | major_freeze_duty_time='02:00' |
| CAPACITY| 容量、例：3MB、5G   | log_disk_size='0M' |
| VERSION | バージョン番号             | compatible='4.3.0.0' |
| MODE    | OBKVの対応機能の有効/無効を指定する | _obkv_feature_mode = 'ttl=off, rerouting=on' |

## クエリ例

このOBServerノード上のパラメータ`large_query_threshold`に関する情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_PARAMETERS WHERE NAME LIKE '%large_query_threshold%'\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
       SVR_IP: 11.xx.xx.xx
     SVR_PORT: 12615
         ZONE: z1
        SCOPE: CLUSTER
    TENANT_ID: NULL
         NAME: large_query_threshold
    DATA_TYPE: TIME
        VALUE: 5s
         INFO: threshold for execution time beyond which a request may be paused and rescheduled as a \'large request\', 0ms means disable \'large request\'. Range: [0ms, +∞)
      SECTION: TENANT
   EDIT_LEVEL: DYNAMIC_EFFECTIVE
DEFAULT_VALUE: 5s
    ISDEFAULT: NO
1 row in set
```
