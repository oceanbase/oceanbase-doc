# GV$OB_PROCESSLIST

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_PROCESSLIST`は、テナントが存在するすべてのOBServerノードのセッション情報を表示するために使用されます。

## フィールドの説明

|      フィールド名      |        タイプ        | NULLを許容するか |                              説明                              |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_PROCESSLIST WHERE ROWNUM <= 1\G
```
