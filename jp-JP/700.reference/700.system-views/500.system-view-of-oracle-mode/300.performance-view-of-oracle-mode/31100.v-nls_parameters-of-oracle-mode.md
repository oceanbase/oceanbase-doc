# V$NLS_PARAMETERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

セッションレベルのすべてのNLSパラメータを表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
|-----------|-----------------|----------------|--------|
| PARAMETER | VARCHAR2(128)   | NO             | パラメータ名   |
| VALUE     | VARCHAR2(65536) | YES            | パラメータ値   |
| CON_ID    | NUMBER          | NO             | 実際の意味はありません  |

## クエリ例

現在のテナント内のセッションレベルのすべてのNLSパラメータを確認します。

```shell
obclient> select * from V$NLS_PARAMETERS;
```
