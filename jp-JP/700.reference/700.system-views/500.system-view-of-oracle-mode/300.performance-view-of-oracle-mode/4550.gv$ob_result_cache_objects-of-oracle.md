# GV$OB_RESULT_CACHE_OBJECTS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul>このビューはV4.4.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

このビューは、すべてのOBServerノード上で`result_cache`としてマークされた`udf`の実行時に作成された`result cache`内にキャッシュされているオブジェクト情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
|TENANT_ID|bigint(20)|NO|テナントID：<ul><li>1：システムテナントIDを表します。</li><li>その他の値：ユーザーテナントまたはMetaテナントIDを表します。</li></ul>|
|SVR_IP|varchar(46)|NO|レプリカが存在するノードのアドレス。|
|SVR_PORT|bigint(20)|NO|レプリカが存在するノードのポート番号。|
|CACHE_OBJECT_ID|bigint(20)|NO|lib cacheに割り当てられたキャッシュオブジェクトID。|
|UDF_NAME|longtext|NO|UDFオブジェクト名。|
|FIRST_LOAD_TIME|timestamp(6)|NO|キャッシュオブジェクトが初めてロードされた時間。|
|LAST_ACTIVE_TIME| timestamp(6)|NO|キャッシュが最後にアクセスされた時間。|
|HIT_COUNT| bigint(20)| NO| キャッシュヒット数。|
|CACHE_OBJ_SIZE| bigint(20)|NO| キャッシュオブジェクトが占有するメモリサイズ。|
|BUILD_TIME| bigint(20)|NO| UDF実行時間。|
|OBJECT_TYPE| longtext|NO| キャッシュオブジェクトタイプ。result cacheでは現在UDF_RESULTのみが対応しています。|
|OBJECT_ID| bigint(20)|NO| udf routine id。|
|DB_ID| bigint(20)|NO| UDFが属するDB ID。|
|HASH| bigint(20)|NO| キャッシュオブジェクトのhashテーブルにおけるhash値。|
|SYS_VARS| varchar(4096)|NO| UDF実行に影響を与えるシステム変数の集合。|
|CONFIGS| varchar(4096)|NO| UDF実行に影響を与えるパラメータの集合。|

## クエリ例

以下のコマンドを実行して、`result cache`内にキャッシュされているオブジェクト情報を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_RESULT_CACHE_OBJECTS;
```
