# GV$OB_SQL_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノードでEXPLAIN PLANを実行して収集した実行計画情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 実行計画情報が属するテナントID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main> |
| SVR_IP | VARCHAR2(46) | NO | レプリカが存在するノードのアドレス |
| SVR_PORT | NUMBER(38) | NO | レプリカが存在するノードのポート |
| DB_ID | NUMBER(38) | NO | 実行計画ID |
| SQL_ID | VARCHAR2(32) | NO | クエリID |
| PLAN_HASH | NUMBER(38) | NO | クエリが属するスキーマID |
| PLAN_ID | NUMBER(38) | NO | 実行計画のハッシュ値 |
| GMT_CREATE | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO | レコード作成時間 |
| OPERATOR | VARCHAR2(255) | NO | 演算子名（例：TABLE SCAN、SORT） |
| OBJECT_NODE | VARCHAR2(40) | NO | 現在の演算子がDBLINK関連の場合、DBLINKの名前を示します |
| OBJECT_ID | NUMBER(38) | NO | スキャン対象ID（例：TABLE SCAN演算子がスキャンする物理テーブルID） |
| OBJECT_OWNER | VARCHAR2(128) | NO | スキャン対象が属するユーザー |
| OBJECT_NAME | VARCHAR2(128) | NO | スキャン対象名（例：TABLE SCAN演算子がスキャンする物理テーブル名） |
| OBJECT_ALIAS | VARCHAR2(261) | NO | スキャン対象のエイリアス（例：TABLE SCAN演算子がスキャンする物理テーブルのエイリアス） |
| OBJECT_TYPE | VARCHAR2(20) | NO | スキャン対象タイプ（例：SYNONYM、DBLINK、BASIC TABLE） |
| OPTIMIZER | VARCHAR2(4000) | NO | インデックス関連情報（例：物理行、論理行、再テーブル行数、使用する統計情報タイプ、統計情報バージョン番号） |
| ID | NUMBER(38) | NO | 論理演算子ID |
| PARENT_ID | NUMBER(38) | NO | 論理演算子の親演算子ID |
| DEPTH | NUMBER(38) | NO | 論理演算子が現在の計画における深さ、つまり二分計画木の何層目にあるか |
| POSITION | NUMBER(38) | NO | 現在の論理演算子が親演算子のいくつ目の子ノードであるかを示す演算子 |
| COST | NUMBER(38) | NO | 最適化エンジンが見積もったコスト |
| REAL_COST | NUMBER(38) | NO | 実行計画が初めて実行されたときの実際のコスト（実行フィードバック情報） |
| CARDINALITY | NUMBER(38) | NO | 最適化エンジンが見積もった現在の演算子の出力行数 |
| REAL_CARDINALITY | NUMBER(38) | NO | 実行計画が初めて実行されたときの現在の演算子の実際の出力行数（実行フィードバック情報） |
| IO_COST | NUMBER(38) | NO | 実行計画が初めて実行されたときの現在の演算子の実際のI/Oコスト（実行フィードバック情報） |
| CPU_COST | NUMBER(38) | NO | 実行計画が初めて実行されたときの現在の演算子の実際のCPUコスト（実行フィードバック情報） |
| BYTES | NUMBER(38) | NO | オプティマイザーが現在の演算子データの幅を推定した値 |
| ROWSET | NUMBER(38) | NO | 現在の演算子のベクトル化サイズ |
| OTHER_TAG | VARCHAR2(4000) | NO | 現在のクエリで使用されたヒント。プランの最初の行にのみ格納されます |
| PARTITION_START | VARCHAR2(4000) | NO | TABLE SCANでスキャンするパーティション情報 |
| OTHER | VARCHAR2(4000) | NO | 最適化情報。例：プランタイプ、Fast Parserのパラメータ化情報、Plan Note、プランがヒットした制約情報など |
| ACCESS_PREDICATES | VARCHAR2(4000) | NO | 現在の演算子がアクセスする必要がある式の情報 |
| FILTER_PREDICATES | VARCHAR2(4000) | NO | 現在の演算子のフィルター条件 |
| STARTUP_PREDICATES | VARCHAR2(4000) | NO | 現在の演算子の開始条件 |
| PROJECTION | VARCHAR2(4000) | NO | 現在の演算子の出力式の情報 |
| SPECIAL_PREDICATES | VARCHAR2(4000) | NO | 現在の演算子の固有の式の情報。例：Join Condition、GROUP EXPRS、SORT EXPRSなど |
| QBLOCK_NAME | VARCHAR2(128) | NO | 現在の演算子が存在するクエリブロックの名前 |
| REMARKS | VARCHAR2(4000) | NO | qb_nameの変更追跡情報 |
| OTHER_XML | VARCHAR2(4000) | NO | OUTLINE DATA |
