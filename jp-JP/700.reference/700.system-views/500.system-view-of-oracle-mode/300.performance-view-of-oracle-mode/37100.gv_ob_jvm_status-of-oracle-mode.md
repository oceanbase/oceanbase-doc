# GV$OB_JVM_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP4バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、すべてのOBServerノード上のOBServerプロセス内のJVMの実行状態とリソース使用状況を表示します。JVMの状態、ヒープメモリ、メタスペース、GC、スレッド数、ファイルディスクリプタ数などの情報が含まれます。各OBServerノードに対応して1行のレコードが表示されます。

使用方法は以下の通りです：

* 構成パラメータ`ob_enable_java_env`が有効に設定されている場合にのみ、OBServerプロセスはJVMを起動します。無効な場合、`STATUS`は`DISABLED`となります。
* JVMが起動すると、システムはデフォルトで60秒ごとにJVMの状態を収集します。このビューに表示されるのは、最新の収集結果であり、JVMの起動や収集をトリガーするものではありません。
* まだ正常に収集されていない、または取得できない指標はNULLとして表示されます。これは、実際の値が`0`の指標と区別するためです。
* Java UDFがサンドボックスプロセス内で実行される場合、サンドボックスJVMの状態については、[GV$OB_JAVA_SANDBOX_STATUS](37300.gv_ob_java_sandbox_status-of-oracle-mode.md)を参照してください。

## フィールドの説明

|     フィールド名    |     型    | NULL許容 |      説明      |
|----------------|-------------|----------------|----------------|
| SVR_IP | VARCHAR2(46) | NO | OBServerノードのIPアドレス。 |
| SVR_PORT | NUMBER(38) | NO | OBServerノードのポート番号。 |
| PROCESS_PID | NUMBER(38) | YES | OBServerプロセスのプロセスID。 |
| STATUS | VARCHAR2(32) | NO | OBServerプロセス内JVMの状態：<ul><li>`DISABLED`：Java環境が有効化されていない（構成パラメータ`ob_enable_java_env`が`False`の場合）</li><li>`NOT_STARTED`：JVMがまだ起動していない</li><li>`STARTING`：JVMが起動中、または起動済みでも初回収集が完了していない</li><li>`UP`：JVMが実行中で、直近の収集が成功した</li><li>`INIT_FAILED`：JVMの初期化に失敗した</li><li>`COLLECT_ERROR`：JVMの状態収集に失敗した</li><li>`DOWN`：OBServerプロセスが終了中、またはJVMの監視が停止した</li></ul> |
| INIT_ATTEMPT_COUNT | NUMBER(38) | YES | JVMの初期化試行回数の合計。 |
| INIT_FAILURE_COUNT | NUMBER(38) | YES | JVMの初期化失敗回数の合計。 |
| LAST_INIT_ERROR_CODE | NUMBER(38) | YES | 最後のJVM初期化失敗時のエラーコード。初期化失敗が発生していない場合はNULL。 |
| LAST_INIT_ERROR_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 最後のJVM初期化失敗時刻。初期化失敗が発生していない場合はNULL。 |
| JVM_START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | JVMの起動時刻。 |
| JVM_UPTIME_MS | NUMBER(38) | YES | JVMの稼働時間、単位はミリ秒。 |
| MONITOR_BRIDGE_VERSION | NUMBER(38) | YES | JVM監視インターフェースのバージョン番号。 |
| HEAP_USED_BYTES | NUMBER(38) | YES | JVMヒープメモリの使用サイズ、単位はバイト。 |
| HEAP_COMMITTED_BYTES | NUMBER(38) | YES | JVMヒープメモリのコミット済みサイズ、単位はバイト。 |
| HEAP_MAX_BYTES | NUMBER(38) | YES | JVMヒープメモリの最大利用可能サイズ、単位はバイト。 |
| YOUNG_USED_BYTES | NUMBER(38) | YES | JVMヤング世代の使用サイズ、単位はバイト。 |
| OLD_USED_BYTES | NUMBER(38) | YES | JVMオールド世代の使用サイズ、単位はバイト。 |
| METASPACE_USED_BYTES | NUMBER(38) | YES | JVMメタスペースの使用サイズ、単位はバイト。 |
| METASPACE_COMMITTED_BYTES | NUMBER(38) | YES | JVMメタスペースのコミット済みサイズ、単位はバイト。 |
| METASPACE_MAX_BYTES | NUMBER(38) | YES | JVMメタスペースの最大利用可能サイズ、単位はバイト。 |
| CODE_CACHE_USED_BYTES | NUMBER(38) | YES | JVMコードキャッシュ（Code Cache）の使用サイズ、バイト単位。 |
| DIRECT_BUFFER_USED_BYTES | NUMBER(38) | YES | JVMダイレクトバッファ（Direct Buffer）の使用メモリサイズ、バイト単位。 |
| DIRECT_BUFFER_COUNT | NUMBER(38) | YES | JVMダイレクトバッファの数。 |
| GC_COUNT | NUMBER(38) | YES | JVMの累積GC回数。 |
| GC_TIME_MS | NUMBER(38) | YES | JVMの累積GC時間、ミリ秒単位。 |
| YOUNG_GC_COUNT | NUMBER(38) | YES | JVMの累積ヤング世代GC回数。 |
| YOUNG_GC_TIME_MS | NUMBER(38) | YES | JVMの累積ヤング世代GC時間、ミリ秒単位。 |
| MAJOR_GC_COUNT | NUMBER(38) | YES | JVMの累積Major GC（オールド世代GC）回数。 |
| MAJOR_GC_TIME_MS | NUMBER(38) | YES | JVMの累積Major GC時間、ミリ秒単位。 |
| THREAD_COUNT | NUMBER(38) | YES | JVMの現在のスレッド数。 |
| PEAK_THREAD_COUNT | NUMBER(38) | YES | JVMのピークスレッド数。 |
| OPEN_FD_COUNT | NUMBER(38) | YES | OBServerプロセスが現在開いているファイルディスクリプタの数。 |
| MAX_FD_COUNT | NUMBER(38) | YES | OBServerプロセスが開けるファイルディスクリプタの最大数。 |
| COLLECT_ERROR_CODE | NUMBER(38) | YES | 最後に収集した際のエラーコード。`0`は収集成功を示します。 |
| COLLECT_COST_US | NUMBER(38) | YES | 直近の収集にかかった時間、マイクロ秒単位。 |
| LAST_COLLECT_ATTEMPT_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 最後に収集を試みた時刻。 |
| SNAPSHOT_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES | 最後に収集が成功した時刻。 |
| SNAPSHOT_AGE_US | NUMBER(38) | YES | 最後に収集が成功してから経過した時間、マイクロ秒単位。 |

## クエリ例

```shell
obclient> SELECT SVR_IP, SVR_PORT, STATUS, HEAP_USED_BYTES, HEAP_MAX_BYTES, GC_COUNT, THREAD_COUNT, SNAPSHOT_TIME FROM SYS.GV$OB_JVM_STATUS;
```
