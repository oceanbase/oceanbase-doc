# V$SQL_WORKAREA

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

SQL自動メモリ管理が実行したすべてのOperatorのワークエリア統計情報を集計します。

## **フィールドの説明**

|        **フィールド名**        |    **タイプ**    | **NULL値を許容するか** |                                                                **説明**                                                                 |
|------------------------|--------------|----------------| ----------|
| ADDRESS                | RAW(8)       | NO             | SQLに対応するハンドルアドレス。現在は値が指定されていません。このフィールドは現在サポートされておらず、デフォルトでNULLとなります   |
| HASH_VALUE             | NUMBER       | NO             | ステートメントのHash Value値。現在はこのフィールドをサポートしておらず、デフォルトでNULLとなります           |
| DB_ID                  | NUMBER(38)    | NO            | このSQLリクエストの接続が属するデータベースID    <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.3バージョンから導入されました。</p></main>  |
| SQL_ID                 | VARCHAR2(32) | NO             | SQLステートメントの一意の識別子                                   |
| CHILD_NUMBER           | NUMBER       | NO             | このカーソルの数。現在はこのフィールドをサポートしておらず、デフォルトでNULLとなります               |
| WORKAREA_ADDRESS       | RAW(8)       | NO             | workareaアドレス。現在はこのフィールドをサポートしておらず、デフォルトでNULLとなります                   |
| OPERATION_TYPE         | VARCHAR2(40) | NO             | workarea演算子のタイプ。例えばSort、Hash Join、Group byなど        |
| OPERATION_ID           | NUMBER(38)   | NO             | プランツリー内で演算子を識別するための一意の識別子                                     |
| POLICY                 | VARCHAR2(10) | NO             | workareaのポリシー：<ul><li>MANUAL</li><li>AUTO </li></ul>   |
| ESTIMATED_OPTIMAL_SIZE | NUMBER(38)   | NO             | 最適な場合に演算子を実行するための推定メモリサイズ。単位：バイト                        |
| ESTIMATED_ONEPASS_SIZE | NUMBER(38)   | NO             | one passシナリオにおける演算子の実行メモリサイズの推定値。単位：バイト                  |
| LAST_MEMORY_USED       | NUMBER(38)   | NO             | カーソルが前回の実行で使用したメモリサイズ。単位：バイト                            |
| LAST_EXECUTION         | VARCHAR2(10) | NO             | 前回の実行時にworkareaがoptimal、one pass、またはmulti passesを選択したかどうかを示します。</p>
| LAST_DEGREE            | NUMBER(38)   | NO             | 前回の実行の並列度                                            |
| TOTAL_EXECUTIONS       | NUMBER(38)   | NO             | workareaを使用した実行回数の合計                                |
| OPTIMAL_EXECUTIONS     | NUMBER(38)   | NO             | 最適なシナリオでの実行回数                                         |
| ONEPASS_EXECUTIONS     | NUMBER(38)   | NO             | one passシナリオでの実行回数                                   |
| MULTIPASSES_EXECUTIONS | NUMBER(38)   | NO             | multi passesシナリオでの実行回数                               |
| ACTIVE_TIME            | NUMBER(38)   | NO             | workareaがアクティブだった平均時間、単位：秒                             |
| MAX_TEMPSEG_SIZE       | NUMBER(38)   | NO             | work area使用時の最大一時ディスク容量、単位：バイト；NULLの場合は一時容量未使用を示す |
| LAST_TEMPSEG_SIZE      | NUMBER(38)   | NO             | workareaが前回実行時に使用した一時ディスク容量；NULLの場合は一時容量未使用を示す        |
| CON_ID                 | NUMBER(38)   | NO             | テナントID                                              |
| SVR_IP                 | VARCHAR2(46)  | NO            | サーバーIPアドレス  |
| SVR_PORT               | NUMBER(38)    | NO            | サーバーのポート番号  |
