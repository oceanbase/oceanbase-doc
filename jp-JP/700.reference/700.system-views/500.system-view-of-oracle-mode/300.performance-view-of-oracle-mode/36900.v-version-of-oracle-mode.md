# V$VERSION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.30バージョンから導入されました。</p>
</main>

## 機能の概要

データベース製品のすべてのコンポーネントの名前とバージョン情報を表示します。

  <main id="notice" >
    <h4>適用対象</h4>
    <p>このビューはOceanBaseデータベースのOracleモードにのみ適用されます。</p>
  </main>

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
|----------|-----------------|----------------|-----------|
| BANNER   | VARCHAR2(65536) | YES            | プロダクトの名前とバージョン番号 |
| CON_ID   | NUMBER          | NO             | コンテナID     |

## クエリ例

データベースのバージョン情報を確認します。

```shell
obclient> SELECT * FROM V$VERSION;
```

クエリ結果は次のとおりです：

```shell
+---------------------------------------------------------------------------------------------------------------+--------+
| BANNER                                                                                                        | CON_ID |
+---------------------------------------------------------------------------------------------------------------+--------+
| OceanBase 4.0.0.0 (r100000302022111120-7cef93737c5cd03331b5f29130c6e80ac950d33b) (Built Nov 11 2022 20:38:33) |      0 |
+---------------------------------------------------------------------------------------------------------------+--------+
1 row in set
```
