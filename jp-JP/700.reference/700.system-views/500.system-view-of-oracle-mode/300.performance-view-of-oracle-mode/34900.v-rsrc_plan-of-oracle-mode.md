# V$RSRC_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

`V$RSRC_PLAN` ビューは、現在アクティブなテナントのリソース管理計画を表示するために使用されます。

## フィールド説明

|            フィールド名            |      型       | NULL許容 |                       説明                       |
|----------------------------|---------------|------------|--------------------------------------------------------------------------------|
| ID                         | NUMBER        | NO         | リソースプランID。グローバルに一意です。                                  |
| NAME                       | VARCHAR2(128) | NO         | リソースプラン名。                                        |
| IS_Top_PLAN                | VARCHAR2(5)   | NO         | 現在のリソースプランが現在設定されているトップレベルプランかどうか。<ul><li>`TRUE`：現在のリソースプランが現在設定されているトップレベルプランであることを示します。   </li><li> `FALSE`：現在のリソースプランが現在のトップレベルプランのサブプランであることを示します。</li></ul> 現在、OceanBaseデータベースではこの値は常に `TRUE` に固定されています。 |
| CPU_MANAGED                | VARCHAR2(3)   | NO         | 現在のリソースプランでCPU利用率を管理するパラメータが設定されているかどうか。<ul><li> `ON`：設定済み   </li><li> `OFF`：未設定</li></ul> 現在、OceanBaseデータベースではこの値は常に `ON` に固定されています。                               |
| INSTANCE_CAGING            | VARCHAR2(3)   | NO         | 互換性のためにのみ使用されます。現在、この値は常に `NULL` に固定されています。                          |
| PARALLEL_SERVERS_ACTIVE    | NUMBER        | NO         | 互換性のためにのみ使用されます。現在、この値は常に `NULL` に固定されています。                          |
| PARALLEL_SERVERS_TOTAL     | NUMBER        | NO         | 互換性のためにのみ使用されます。現在、この値は常に `NULL` に固定されています。                          |
| PARALLEL_EXECUTION_MANAGED | VARCHAR2(32)  | NO         | 互換性のためにのみ使用されます。現在、この値は常に `NULL` に固定されています。                          |

## クエリ例

ユーザーテナントが現在アクティブなテナントのリソース管理計画を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.V$RSRC_PLAN;
```

クエリ結果は次のとおりです：

```shell
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| ID   | NAME    | IS_TOP_PLAN | CPU_MANAGED | INSTANCE_CAGING | PARALLEL_SERVERS_ACTIVE | PARALLEL_SERVERS_TOTAL | PARALLEL_EXECUTION_MANAGED |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| NULL | daytime | TRUE        | ON          | NULL            |                    NULL |                   NULL | NULL                       |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
1 row in set
```
