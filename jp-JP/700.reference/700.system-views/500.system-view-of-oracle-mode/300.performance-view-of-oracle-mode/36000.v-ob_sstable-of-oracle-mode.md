# V$OB_SSTABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上の各パーティションにおけるMemTableとSSTableの情報を表示します。

## フィールドの説明

|          フィールド名           |      型       | NULL許容 |                                                                                 説明                                                                                 |
|-------------------------|---------------|------------|------------------------------|
| SVR_IP                  | VARCHAR2(46)  | NO         | サーバーIPアドレス                                                                       |
| SVR_PORT                | NUMBER(38)    | NO         | サーバーポート番号                                                                          |
| TABLE_TYPE              | VARCHAR2(20)  | NO         | テーブルタイプ                                                                                |
| LS_ID                   | NUMBER(38)    | NO         | ログストリームID                                                                          |
| TABLET_ID               | NUMBER(38)    | NO         | データシャーディングID                                                                         |
| START_LOG_SCN            | NUMBER(38)    | NO         | このテーブル内データのログタイムスタンプ範囲の左端                                                               |
| END_LOG_SCN              | NUMBER(38)    | NO         | このテーブル内データのログタイムスタンプ範囲の右端                                                               |
| SIZE                    | NUMBER(38)    | NO         | ディスク使用容量、単位はバイト   |
| REF                     | NUMBER(38)    | NO         | このテーブルの参照数、単位は件数    |
| UPPER_TRANS_VERSION     | NUMBER(38)    | NO         | コミット済みトランザクションの最大トランザクションバージョン番号                   |
| IS_ACTIVE               | VARCHAR2(3)   | NO         | アクティブなMemTableかどうか |
| CONTAIN_UNCOMMITTED_ROW | VARCHAR2(3)   | NO         | このテーブルに未コミットのトランザクション行が含まれているかどうか：<ul><li>`NO`：このテーブルに未コミットのトランザクション行が含まれていないことを示す   </li><li> `YES`：このテーブルに未コミットのトランザクション行が含まれていることを示す </li></ul>   |
