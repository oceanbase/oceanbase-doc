# GV$OB_PS<Item_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_PS<Item_INFO`は、prepared statementに対するモニタリング機能を提供するために使用され、PS Cache内のすべてのprepared statementの基本情報が含まれます。

## フィールドの説明

|        フィールド名         |      タイプ      | NULLを許容するか |             説明             |
|---------------------|--------------|------------|----------------------------|
| SVR_IP              | VARCHAR2(46) | NO         | サーバーのIPアドレス                  |
| SVR_PORT            | NUMBER(38)   | NO         | サーバーのポート番号                     |
| STMT_ID             | NUMBER(38)   | NO         | ps cache内の対応するステートメントのstmt_id情報 |
| DB_ID               | NUMBER(38)   | NO         | prepareステートメントに関連するデータベースID       |
| PS_SQL              | CLOB         | NO         | prepareのSQL情報           |
| PARAM_COUNT         | NUMBER(38)   | NO         | prepareのパラメータ数情報            |
| STMT_ITEM_REF_COUNT | NUMBER(38)   | NO         | stmt_itemの参照カウント情報          |
| STMT_INFO_REF_COUNT | NUMBER(38)   | NO         | stmt_infoの参照カウント情報          |
| MEM_HOLD            | NUMBER(38)   | NO         | このprepare stmtが占有するメモリサイズ     |
| STMT_TYPE           | NUMBER(38)   | NO         | このprepare stmtのタイプ情報 |
| CHECKSUM            | NUMBER(38)   | NO         | このprepare stmtのチェックサム |
| EXPIRED             | NUMBER(38)   | NO         | このprepare stmtは期限切れか |
