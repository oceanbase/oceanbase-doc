# GV$SQL_JOIN_FILTER

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントにおけるすべてのOBServerノード上でのJoin Filter実行に関する情報を動的に表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーのポート番号 |
| QC_SESSION_ID | NUMBER | NO | 指定されたパラレルクエリのカーソルに対するQC（Query Coordinator）セッションID<br>V4.2.x系では：<ul><li> V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.2.5 BP4以降のバージョン：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODP内の構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| QC_INSTANCE_ID | NUMBER | NO | 指定されたパラレルクエリのカーソルに対するQC（Query Coordinator）インスタンスID |
| SQL_PLAN_HASH_VALUE | NUMBER | NO | 指定されたパラレルクエリのカーソルに対するSQL計画のHash値 |
| FILTER_ID | NUMBER | NO | 指定されたカーソル内で接続フィルターを識別するIDであり、このIDは実行計画内のフィルターIDに対応します |
| BITS_SET | NUMBER | NO | BLOOM_FILTER内で使用されるBitmap（結合ビットマップ）のサイズで、現在のバージョンでは互換性のためにのみ使用されます |
| FILTERED | NUMBER | NO | 接続フィルターが処理した行数 |
| PROBED | NUMBER | NO | ビットマップフィルターのテストを通過した右側テーブルの行数。ここではフィルタリングされた行数とフィルタリングされていない行数の合計を指します |
| ACTIVE | NUMBER | NO | フィルターがアクティブ状態（はい）または非アクティブ状態（いいえ）かどうか |
| CON_ID | NUMBER | NO | データが属するコンテナのID |
| TRACE_ID | CHAR(64) | NO | SQL文に対応するTrace ID |
