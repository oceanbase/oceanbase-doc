# GV$OB_MEMSTORE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>GV$SERVER_MEMSTORE</code> はV4.0.0バージョン以降、<code>GV$OB_MEMSTORE</code> に名称が変更されました。V4.0.0以降のバージョンでは、新しいビュー名 <code>GV$OB_MEMSTORE</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>GV$SERVER_MEMSTORE</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

すべてのサーバー上のすべてのテナントのMemTableのメモリ使用状況を表示します。

## フィールド説明

|    **フィールド名**    |    **型**    | **NULL許容** |              **説明**              |
|----------------|--------------|----------------|----------------------------------|
| SVR_IP         | VARCHAR2(46) | NO             | サーバーのIPアドレス                          |
| SVR_PORT       | NUMBER(38)   | NO             | サーバーポート                            |
| TENANT_ID      | NUMBER(38)   | NO             | テナントID                            |
| ACTIVE_SPAN    | NUMBER(38)   | NO             | アクティブMemTableが使用するメモリの推定値（過大評価される場合あり）。単位：バイト |
| FREEZE_TRIGGER | NUMBER(38)   | NO             | MemTableのフリーズをトリガーするメモリサイズ。単位：バイト        |
| FREEZE_CNT     | NUMBER(38)   | NO             | MemTableのフリーズ回数                   |
| MEMSTORE_USED  | NUMBER(38)   | NO             | MemTableが現在使用中のメモリサイズの合計。単位：バイト        |
| MEMSTORE_LIMIT | NUMBER(38)   | NO             | MemTableのメモリサイズの上限。単位：バイト           |

## クエリ例

ユーザーテナントが自身のテナントに属するすべてのサーバー上のMemTableのメモリ使用状況を照会します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_MEMSTORE;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| SVR_IP         | SVR_PORT | TENANT_ID | ACTIVE_SPAN | FREEZE_TRIGGER | FREEZE_CNT | MEMSTORE_USED | MEMSTORE_LIMIT |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| 172.xx.xxx.xxx |     2882 |      1004 |    25165824 |      603982068 |          0 |      25165824 |     2684354550 |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
1 row in set
```
