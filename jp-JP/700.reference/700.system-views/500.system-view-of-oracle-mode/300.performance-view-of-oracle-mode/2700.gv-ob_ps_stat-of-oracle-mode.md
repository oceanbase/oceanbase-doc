# GV$OB_PS_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントがすべてのOBServerノード上で使用しているPSキャッシュの全体的な状態を監視します。ヒット率、メモリ使用量、キャッシュされたアイテム数が含まれます。

## フィールドの説明

|   **フィールド名**   |    **型**    | **NULL許容** |       **説明**        |
|--------------|--------------|----------------|---------------------|
| SVR_IP       | VARCHAR2(46) | NO             | サーバーのIPアドレス            |
| SVR_PORT     | NUMBER(38)   | NO             | サーバーのポート番号              |
| STMT_COUNT   | NUMBER(38)   | NO             | PSキャッシュに現在キャッシュされているステートメント数 |
| HIT_COUNT    | NUMBER(38)   | NO             | PSキャッシュの総ヒット数     |
| ACCESS_COUNT | NUMBER(38)   | NO             | PSキャッシュへのアクセス総回数    |
| MEM_HOLD     | NUMBER(38)   | NO             | PSキャッシュが使用するメモリ    |

## クエリ例

ユーザーテナント内で、自身のテナントがすべてのノード上で使用しているPSキャッシュの全体的な状態を確認します。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_PS_STAT;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+------------+-----------+--------------+----------+
| TENANT_ID | SVR_IP         | SVR_PORT | STMT_COUNT | HIT_COUNT | ACCESS_COUNT | MEM_HOLD |
+-----------+----------------+----------+------------+-----------+--------------+----------+
|      1004 | 11.xxx.xxx.xxx |    28825 |          1 |         0 |            1 |    16384 |
+-----------+----------------+----------+------------+-----------+--------------+----------+
1 row in set
```
