# V$OB_PX_P2P_DATAHUB

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

パラレル実行されるデータ転送操作に関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | VARCHAR2(46) | NO | サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO | サーバーのポート番号 |
| TRACE_ID | CHAR(64) | NO | このデータに関連するSQLのTRACE_ID |
| DATAHUB_ID | NUMBER | NO | このデータのDatahub ID |
| MESSAGE_TYPE | VARCHAR2(256) | NO | データが属するメッセージタイプ |
| TENANT_ID | NUMBER | NO | 所属テナントID |
| HOLD_SIZE | NUMBER | NO | マテリアライズされたデータサイズ |
| TIMEOUT_TS | TIMESTAMP(6) | NO | このデータの予想されるタイムアウト時間 |
| START_TIME | TIMESTAMP(6) | NO | 書き込み開始時間 |
