# V$OB_PL_CACHE_OBJECT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_PL_CACHE_OBJECT`は、すべてのテナントのPL関連キャッシュオブジェクトの基本情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | NUMBER(38)         | NO   | テナントID：<ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>   |
| SVR_IP            | VARCHAR2(46)       | NO   | キャッシュオブジェクトが存在するノードのアドレス   |
| SVR_PORT          | NUMBER(38)         | NO   | キャッシュオブジェクトが存在するノードのポート   |
| CACHE_OBJECT_ID   | NUMBER(38)         | NO   | lib cacheによって割り当てられたキャッシュオブジェクトID   |
| PARAMETERIZE_TEXT | CLOB               | NO   |  <ul><li>匿名ブロックおよびPSモードのCALL文の場合：パラメータ化されたSQLテキストを表す  </li><li>Procedure/Fuction/Packageなどの場合：ストアドプロシージャオブジェクト名を表す </li></ul>    |
| OBJECT_TEXT       | CLOB               | NO   | クエリ文のテキスト。このフィールドは匿名ブロックおよびPSモードのCALL文の場合にのみ有効です   |
| FIRST_LOAD_TIME   | TIMESTAMP(6) WITH LOCAL TIME ZONE     | NO   | 最初の読み込み時間（単位：マイクロ秒）  |
| LAST_ACTIVE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE     | NO   | 前回のキャッシュヒット時間（単位：マイクロ秒）   |
| AVG_EXE_USEC      | NUMBER(38)         | NO   | 平均実行時間（単位：マイクロ秒）   |
| SLOWEST_EXE_TIME  | TIMESTAMP(6) WITH LOCAL TIME ZONE     | NO   | 最も遅い実行のタイムスタンプ（単位：マイクロ秒）   |
| SLOWEST_EXE_USEC  | NUMBER(38)         | NO   | 最も遅い実行時間（単位：マイクロ秒）  |
| HIT_COUNT         | NUMBER(38)         | NO   | キャッシュヒット回数   |
| CACHE_OBJ_SIZE    | NUMBER(38)         | NO   | キャッシュオブジェクトが占有するメモリサイズ   |
| EXECUTIONS        | NUMBER(38)         | NO   | ストアドプロシージャの正常な実行回数   |
| ELAPSED_TIME      | NUMBER(38)         | NO   | 最後のストアドプロシージャ実行時間（単位：マイクロ秒）   |
| OBJECT_TYPE       | CLOB               | NO   | キャッシュオブジェクトのタイプ（例：Procedure、Function、Triggerなど）   |
| OBJECT_ID         | NUMBER(38)         | NO   | ストアドプロシージャオブジェクトID（`routine_id`/`package_id`）   |
| COMPILE_TIME      | NUMBER(38)         | NO   | ストアドプロシージャのコンパイル時間（単位：マイクロ秒）   |
| SCHEMA_VERSION    | NUMBER(38)         | NO   | Schemaバージョン番号   |
| PS_STMT_ID        | NUMBER(38)         | NO   | リクエストに対応するPrepare ID：<ul><li>`-1`：SQL文がPSプロトコルを使用していないことを示す  </li><li>`-1`以外の値：SQL文がPSプロトコルを使用していることを示し、その文に対してPSプロトコルが返す一意の識別子を表す    |
| DB_ID             | NUMBER(38)         | NO   | ストアドプロシージャのコンパイル時に使用されるデータベースID |
| PL_CG_MEM_HOLD    | NUMBER(38)          | NO   | PL CG段階でのホールドされるメモリを表します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>    |
| SYS_VARS          | VARCHAR2(4096)       | NO   | 現在のセッション上で計画生成に影響を与えるシステム変数を表します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>    |
| PARAM_INFOS       | CLOB            | NO   | 匿名ブロックおよびCALL PROC INFOに対してパラメータ化された型情報を表示し、マッチングが成功したかどうかを判断するために使用されます。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>   |
