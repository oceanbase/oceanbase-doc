# V$OB_SESSION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_SESSION` は、現在のサーバーで作成されたセッション情報を記録するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| ID | NUMBER(38) | NO |  V4.3.x系では：<ul><li> V4.3.5 BP2 より前のバージョンでは：<br>すべての接続方式（直接接続モード / ODPモード）で、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョンでは：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </ li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>    |
| USER | CHAR(193) | NO |  このセッションが属するユーザーを表します |
| TENANT | VARCHAR2(128) | NO |  アクセスするテナント名   |
| HOST | VARCHAR2(128) | NO | セッションを開始したクライアントのIPアドレスとポート番号を表します。ODP経由でデータベースに接続している場合は、ODPのホストIPアドレスとポート番号を表します   |
| DB | VARCHAR2(128) | YES |  このセッションが現在接続しているデータベース名を表します   |
| COMMAND | VARCHAR2(4096) | NO |  このセッションが実行中のコマンドを表します  |
| SQL_ID | VARCHAR2(32) | NO |  SQL ID情報   |
| TIME | NUMBER(38) | NO |  現在のコマンド実行時間を秒単位で表します。コマンドが再試行された場合は、リセットされて再計算されます   |
| STATE | VARCHAR2(128) | YES |  このセッションの現在の状態を表します   |
| INFO | VARCHAR2(262143) | YES |  このセッションが実行中のステートメントを表します   |
| SVR_IP | VARCHAR2(46) | NO |  サーバーのIPアドレス |
| SVR_PORT | NUMBER(38) | NO |  サーバーのRPCポート番号   |
| SQL_PORT | NUMBER(38) | NO |  サーバーのSQLポート番号   |
| PROXY_SESSID | NUMBER(38) | YES |  現在のクライアントがODPの場合、この列はODPのセッションIDを表示します   |
| USER_CLIENT_IP | VARCHAR2(46) | YES |  ユーザークライアントのIPアドレス   |
| USER_HOST | VARCHAR2(128) | YES |  ユーザークライアントのホスト名   |
| TRANS_ID | NUMBER(38) | NO |  トランザクションID   |
| THREAD_ID | NUMBER(38) | NO |  スレッドID   |
| TRACE_ID | VARCHAR2(64) | YES |  Trace ID   |
| REF_COUNT | NUMBER(38) | NO | 接続参照カウント |
| BACKTRACE | VARCHAR2(16384) | YES | 接続参照呼び出しスタック |
| TRANS_STATE | VARCHAR2(32) | YES |  トランザクションの状態（セッションにトランザクションがない場合は空と表示されます）：<ul><li>`IDLE`：アイドル状態。トランザクションが開始されていないことを示します。</li> <li>`ACTIVE`：トランザクションが明示的に開始されました。`START TRANSACTION`、`BEGIN` などのステートメントで明示的に開始されます。</li> <li>`IMPLICIT_ACTIVE`：トランザクションが暗黙的に開始されました。`autocommit = on` モードで、DMLなどデータを変更するステートメントを実行した後にトランザクションが開始されます。</li> <li>`ROLLBACK_SAVEPOINT`：トランザクションがセーブポイントまでロールバックされています。</li> <li>`IN_TERMINATE`：トランザクションが終了しています。内部原因による終了や、ユーザーが発行したトランザクション終了（例えば、`COMMIT`、`ROLLBACK` ステートメントの実行）が含まれます。</li> <li>`ABORTED`：トランザクションが異常により内部で終了またはロールバックされました。</li> <li>`ROLLED_BACK`：トランザクションがロールバックされました。</li> <li>`COMMIT_TIMEOUT`：トランザクションコミットタイムアウト。</li> <li>`COMMIT_UNKNOWN`：トランザクションコミット結果が不明です。</li> <li>`COMMITTED`：トランザクションが正常にコミットされました。</li></ul>    |
| USER_CLIENT_PORT  | NUMBER(38)    | NO         | ユーザークライアントのポート番号 <main id="notice" type='explain'><h4>説明</h4><p>V4.4.x系では、このフィールドはV4.4.0バージョンから導入されました。</p></main> |
| TOTAL_CPU_TIME | NUMBER(38) | NO | 現在のコマンド実行CPU使用時間、単位は秒 |

## クエリ例

```shell
obclient [SYS]> SELECT * FROM SYS.V$OB_SESSION WHERE ROWNUM <= 1\G
```
