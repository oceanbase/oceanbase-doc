# gv$tenant

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系ではテナント管理機能のアーキテクチャが最適化されたため、このビューはV4.x系には適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、システムテナントとユーザーテナントの詳細情報をビュー<a href="../200.dictionary-view-of-sys-tenant/22200.o-dba_ob_tenants-of-sys-tenant.md">DBA_OB_TENANTS</a>で確認できます。</li></ul>
</main>

## 機能の概要

クラスタ内のすべてのテナントの詳細情報を表示します。

## フィールドの説明

|    **フィールド名**    |    **タイプ**     | **NULL値を許容するか** |      **説明**      |
|----------------|---------------|----------------|------------------|
| tenant_id      | bigint(20)    | NO             | テナントID            |
| tenant_name    | varchar(128)  | NO             | テナントの名前            |
| zone_list      | varchar(8192) | NO             | テナントのゾーン集合      |
| primary_zone   | varchar(128)  | YES            | テナントのプライマリゾーン |
| collation_type | bigint(20)    | NO             | テナントの照合情報 |
| info           | varchar(4096) | NO             | テナントの情報            |
| read_only      | bigint(20)    | NO             | テナントが読み取り専用モードかどうか。この値は廃止されました |
| locality       | varchar(256)  | NO             | テナントのレプリカ配置方式        |
