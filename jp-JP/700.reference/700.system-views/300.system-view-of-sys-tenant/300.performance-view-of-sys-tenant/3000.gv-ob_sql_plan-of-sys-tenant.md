# GV$OB_SQL_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントにおいて、すべてのOBServerノードで実行されたEXPLAIN PLANによって収集された計画情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID       | bigint(20)          | NO | テナントID     |
| SVR_IP          | varchar(46)         | NO | サーバーIPアドレス |
| SVR_PORT        | bigint(20)          | NO | サーバーのポート番号 |
| PLAN_ID         | bigint(20)          |  | プランID |
| SQL_ID    | varchar(32)         | NO | クエリID |
| DB_ID     | bigint(20)          | NO | クエリが属するスキーマID |
| PLAN_HASH  | bigint(20) unsigned | NO | プランのハッシュ値 |
| GMT_CREATE   | timestamp(6)        | NO | 生成時間を記録 |
| OPERATOR     | varchar(255)        | NO | 演算子名（例：TABLE SCAN、SORT） |
| OBJECT_NODE    | varchar(40)         | NO | 現在の演算子がDBLINK関連である場合、dlinkの名前を示す |
| OBJECT_ID         | bigint(20)          | NO | スキャン対象のID（例：TABLE SCAN演算子がスキャンする物理テーブルのID） |
| OBJECT_OWNER    | varchar(128)        | NO | スキャン対象が属するユーザー |
| OBJECT_NAME    | varchar(128)        | NO | スキャン対象の名前（例：TABLE SCAN演算子がスキャンする物理テーブルの名前） |
| OBJECT_ALIAS    | varchar(261)        | NO | スキャン対象のエイリアス（例：TABLE SCAN演算子がスキャンする物理テーブルのエイリアス） |
| OBJECT_TYPE    | varchar(20)         | NO | スキャン対象のタイプ（例：SYNONYM、DBLINK、BASIC TABLE） |
| OPTIMIZER     | varchar(4000)       | NO | インデックス関連情報（例：物理行、論理行、テーブルへのフィードバック行数、使用する統計情報のタイプ、統計情報のバージョン番号） |
| ID     | bigint(20)          | NO | 論理演算子ID |
| PARENT_ID     | bigint(20)          | NO | 論理演算子の親演算子ID |
| DEPTH     | bigint(20)          | NO | 現在のプランにおける論理演算子の深さ、つまり二分プランツリーの何層目に位置するか |
| POSITION     | bigint(20)          | NO | 現在の論理演算子が親演算子のいくつ目の子供であるか |
| COST     | bigint(20)          | NO | 最適化エンジンが推定したコスト |
| REAL_COST | bigint(20)   | NO | プランが初めて実行された際の実際のコスト（実行フィードバック情報） |
| CARDINALITY    | bigint(20)          | NO | 最適化エンジンが現在の演算子の出力行数を推定 |
| REAL_CARDINALITY    | bigint(20)          | NO | プランが初めて実行された際の現在の演算子の実際の出力行数（実行フィードバック情報） |
| IO_COST    | bigint(20)          | NO | プランが初めて実行された際の現在の演算子の実際のI/Oコスト（実行フィードバック情報） |
| CPU_COST    | bigint(20)          | NO | プランが初めて実行された際の現在の演算子の実際のCPUコスト（実行フィードバック情報） |
| BYTES     | bigint(20)          | NO | 最適化エンジンが現在の演算子のデータ幅を推定 |
| ROWSET | bigint(20)          | NO | 現在の演算子のベクトル化サイズ |
| OTHER_TAG     | varchar(4000)       | NO | 現在のクエリで使用されたヒントは、プランの最初の行のレコードにのみ格納されます |
| PARTITION_START  | varchar(4000)       | NO | TABLE SCANスキャンのパーティション情報 |
| OTHER     | varchar(4000)       | NO | 最適化情報。例：計画タイプ、Fast Parserのパラメータ化情報、Plan Note、計画がヒットした制約情報 |
| ACCESS_PREDICATES | varchar(4000)       | NO | 現在の演算子がアクセスする必要がある式情報 |
| FILTER_PREDICATES | varchar(4000)       | NO | 現在の演算子のフィルター条件 |
| STARTUP_PREDICATES | varchar(4000)    | NO | 現在の演算子の起動条件 |
| PROJECTION   | varchar(4000)       | NO | 現在の演算子の出力式情報 |
| SPECIAL_PREDICATES | varchar(4000)   | NO | 現在の演算子固有の式情報。例：Join Condition、GROUP EXPRS、SORT EXPRSなど |
| QBLOCK_NAME   | varchar(128)       | NO | 現在の演算子が属するクエリブロックの名前 |
| REMARKS    | varchar(4000)       | NO | qb_nameの変更追跡情報 |
| OTHER_XML    | varchar(4000)         | NO | OUTLINE DATA |
