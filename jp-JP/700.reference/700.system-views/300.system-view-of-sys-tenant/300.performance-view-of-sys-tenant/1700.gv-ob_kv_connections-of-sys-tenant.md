# GV$OB_KV_CONNECTIONS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1_CE BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_KV_CONNECTIONS`は、すべてのサーバーのOBKV保持接続に関する統計情報を確認するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID         | bigint(20)   | NO   | テナントID   |
| USER_ID           | bigint(20)   | NO   | ユーザーID   |
| DB_ID             | bigint(20)   | NO   | データベースID   |
| SVR_IP            | varchar(46)  | NO   | サーバーIPアドレス  |
| SVR_PORT          | bigint(20)   | NO   | サーバーのポート   |
| CLIENT_IP         | varchar(46)  | NO   | クライアントIP   |
| CLIENT_PORT       | bigint(20)   | NO   | クライアントのポート   |
| FIRST_ACTIVE_TIME | timestamp(6) | NO   | この接続で最初に処理されたリクエストの時間   |
| LAST_ACTIVE_TIME  | timestamp(6) | NO   | この接続で最後に処理されたリクエストの時間  |
