# V$OB_TABLET_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上で全テナントのTabletレベルCompactionの進捗情報を表示します。

## フィールド説明

|             フィールド名             |      型      | NULL許容 |                                            説明                                            |
|------------------------------|--------------|------------|--------|
| SVR_IP                       | varchar(46)  | NO         | サーバーIPアドレス                                                                                |
| SVR_PORT                     | bigint(20)   | NO         | サーバーポート番号|
| TENANT_ID                    | bigint(20)   | NO         | テナントID |
| TYPE                         | varchar(64)  | NO         | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに、または複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>    |
| TABLE_ID                     | bigint(20)   | NO         | メインテーブルID |
| LS_ID                        | bigint(20)   | NO         | ログストリームID|
| TABLET_ID                    | bigint(20)   | NO         | データシャーディングID                                                                                  |
| COMPACTION_SCN                      | bigint(20) unsigned   | NO         | メジャーコンパクションのバージョン情報|
| TASK_ID                      | varchar(64)  | NO         | 実行中のトレース                                                                                |
| STATUS                       | varchar(15)  | NO         | タスクの状態  |
| DATA_SIZE                    | bigint(20)   | NO         | Compactionが必要なデータの合計サイズ、単位はバイト  |
| UNFINISHED_DATA_SIZE         | bigint(20)   | NO         | 未完了のCompactionデータ量、単位はバイト  |
| PROGRESSIVE_COMPACTION_round | bigint(20)   | NO         | 減算メジャーコンパクションラウンド|
| CREATE_TIME                  | timestamp(6) | NO         | タスク作成時間|
| START_TIME                   | timestamp(6) | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME        | timestamp(6) | NO         | 予定終了時間|
| START_CG_ID                  | bigint(20)   | NO         | Column GroupのStart ID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>  |
| END_CG_ID                    | bigint(20)   | NO         | Column GroupのEnd ID <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>   |

## クエリ例

```shell
obclient [oceanbase]> SELECT * FROM ocenbase.V$OB_TABLET_COMPACTION_PROGRESS WHERE TENANT_ID=1002 AND TYPE='MAJOR_MERGE'\G
```
