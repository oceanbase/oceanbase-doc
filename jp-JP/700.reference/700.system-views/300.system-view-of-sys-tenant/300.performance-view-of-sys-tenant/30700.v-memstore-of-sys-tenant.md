# V$OB_MEMSTORE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>V$SERVER_MEMSTORE</code> は、V4.0.0バージョンから <code>V$OB_MEMSTORE</code> に変更されました。V4.0.0以降のバージョンでは、新しいビュー名 <code>V$OB_MEMSTORE</code> を使用してクエリを実行する必要があります。元のビュー名 <code>V$SERVER_MEMSTORE</code> を使用してクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

現在のサーバー上にあるすべてのテナントのMemStore統計情報を表示します。

## フィールドの説明

|    **フィールド名**    |   **タイプ**    | **NULL値を許容するか** |              **説明**              |
|----------------|-------------|----------------|----------------------------------|
| SVR_IP         | varchar(46) | NO             | サーバーのIPアドレス                          |
| SVR_PORT       | bigint(20)  | NO             | サーバーのポート番号                            |
| TENANT_ID      | bigint(20)  | NO             | テナントID                            |
| ACTIVE_SPAN    | bigint(20)  | NO             | アクティブなMemTableが使用しているメモリの推定値（過大評価される可能性あり）、単位はバイト |
| FREEZE_TRIGGER | bigint(20)  | NO             | MemTableの凍結をトリガーするメモリサイズ、単位はバイト        |
| FREEZE_CNT     | bigint(20)  | NO             | MemTableの凍結回数                   |
| MEMSTORE_USED  | bigint(20)  | NO             | MemTableが現在使用している総メモリサイズ、単位はバイト        |
| MEMSTORE_LIMIT      | bigint(20)  | NO             | MemTableのメモリサイズ制限、単位はバイト           |

## クエリ例

システムテナントは、テナントIDが`1002`のテナントの現在のサーバー上のMemTableのメモリ使用状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_MEMSTORE WHERE TENANT_ID=1002;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| SVR_IP         | SVR_PORT | TENANT_ID | ACTIVE_SPAN | FREEZE_TRIGGER | FREEZE_CNT | MEMSTORE_USED | MEMSTORE_LIMIT |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| 172.xx.xxx.xxx |     2882 |      1002 |    62914560 |      603982068 |          0 |      62914560 |     2684354550 |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
1 row in set
```
