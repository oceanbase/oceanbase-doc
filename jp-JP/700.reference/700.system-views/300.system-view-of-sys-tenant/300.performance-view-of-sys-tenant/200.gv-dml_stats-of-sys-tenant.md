# GV$DML_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントのすべてのOBServerノード上にあるユーザーテーブルのDML情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| INST_ID | bigint(20) | NO | テナントID |
| OBJN | bigint(20) | NO | オブジェクトID |
| INS | bigint(20) | NO | 統計情報を最後に収集して以来の挿入回数の概数 |
| UPD | bigint(20) | NO | 統計情報を最後に収集して以来の更新回数の概数 |
| DEL | bigint(20) | NO | 統計情報を最後に収集して以来の削除回数の概数 |
| DROPSEG | bigint(0) | NO | 現在このフィールドはサポートされていません。デフォルトでNULLです。 |
| CURROWS | bigint(0) | NO | 現在このフィールドはサポートされていません。デフォルトでNULLです。 |
| PAROBJN | bigint(20) | NO | 現在このフィールドはサポートされていません。デフォルトでNULLです。 |
| LASTUSED | bigint(0) | NO | 現在このフィールドはサポートされていません。デフォルトでNULLです。 |
| FLAGS | bigint(0) | NO | 現在このフィールドはサポートされていません。デフォルトでNULLです。 |
| CON_ID | bigint(0) | NO | 現在このフィールドはサポートされていません。デフォルトでNULLです。 |

## クエリ例

テナントIDが1004のテナントにおける、すべてのOBServerノード上のユーザーテーブルのDML情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$DML_STATS WHERE INST_ID=1004;
```
