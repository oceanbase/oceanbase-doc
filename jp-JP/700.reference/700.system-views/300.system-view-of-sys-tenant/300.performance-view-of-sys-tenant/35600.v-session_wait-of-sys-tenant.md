# V$SESSION_WAIT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$SESSION_WAIT` は、現在のノード上で各セッションが待機中のイベントの詳細を表示します。規定により、各待機イベントには3つのパラメータがあり、それぞれ対応する値が記録されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | V4.3.x系について：<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート |
| EVENT | varchar(64) | NO | 待機中のイベント名 |
| P1TEXT | varchar(64) | NO | 待機中のイベントの最初のパラメータの説明 |
| P1 | bigint(20) unsigned | NO | 待機中のイベントの最初のパラメータの値 |
| P2TEXT | varchar(64) | NO | 待機中のイベントの2番目のパラメータの説明 |
| P2 | bigint(20) unsigned | NO | 待機中のイベントの2番目のパラメータの値 |
| P3TEXT | varchar(64) | NO | 待機中のイベントの3番目のパラメータの説明 |
| P3 | bigint(20) unsigned | NO | 待機中のイベントの3番目のパラメータの値 |
| WAIT_CLASS_ID | bigint(20) | NO | 待機中のイベントのクラスID |
| WAIT_CLASS# | bigint(20) | NO | 待機中のイベントのクラス番号 |
| WAIT_CLASS | varchar(64) | NO | 待機中のイベントのクラス名 |
| STATE | varchar(19) | NO | 現在の待機イベントの状態。4つの状態が含まれます：<ul><li>Waiting：セッションがこのイベントを待機しています。</li><li>Waited unknown time：timed_statistics値がfalseに設定されているため、時間情報を取得できません。待機が発生したことを示しますが、時間は非常に短かったことを意味します。</li><li>Wait short time：待機が発生しましたが、時間が1単位を超えないほど非常に短かったため、記録されていません。</li><li>Waited known time：セッションが待機して必要なリソースを取得した場合、waiting状態からこの状態に移行します。</li></ul> |
| WAIT_TIME_MICRO | bigint(20) | NO | 待機時間。単位はマイクロ秒です。現在待機中の場合、待機している時間を表します。現在待機していない場合、最後の待機の合計待機時間を表します |
| TIME_REMAINING_MICRO | bigint(20) | NO |<ul><li>> 0：最後の待機時間（単位：マイクロ秒）、現在待機状態ではありません</li><li>0：セッションが現在のイベントを待機しています。</li><li>-1：最後の待機時間が統計単位1未満、現在待機状態ではありません</li><li>-2：時間統計状態が利用可能に設定されていない、現在待機状態ではありません</li></ul> |
| TIME_SINCE_LAST_WAIT_MICRO | bigint(20) | NO | 前回の待機終了から現在までの時間。単位はマイクロ秒です。現在待機中の場合、その値は0です |

## クエリ例

現在のノード上で、すべてのセッションが現在待機しているイベントの詳細を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSION_WAIT LIMIT 1\G
```
