# GV$OB_IO_BENCHMARK

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上のI/Oモジュールが使用するディスクキャリブレーションデータを表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート番号 |
| STORAGE_NAME | varchar(1024) | NO | ストレージ名。例：DATA、REDO |
| MODE | varchar(256) | NO | I/Oモード。例：READ、WRITE |
| SIZE | bigint(20) | NO | I/Oサイズ。単位はバイト |
| IOPS | bigint(20) | NO | 1秒間に完了するI/Oリクエスト数 |
| MBPS | bigint(20) | NO | ディスク帯域幅。単位はMB/s |
| LATENCY | bigint(20) | NO | 応答時間。単位はus |

## クエリ例

すべてのノード上のI/Oモジュールが使用するディスクキャリブレーションデータを確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_IO_BENCHMARK LIMIT 10;
```
