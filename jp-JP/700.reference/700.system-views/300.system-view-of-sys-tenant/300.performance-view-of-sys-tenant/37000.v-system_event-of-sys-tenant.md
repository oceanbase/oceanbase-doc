# V$SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上で各テナントが待機しているイベントを表示し、各種待機イベントの発生回数、待機時間、タイムアウト回数などを統計します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | 情報が存在するサーバーのポート番号 |
| EVENT_ID | bigint(20) | NO | 待機イベントのID |
| EVENT | varchar(64) | NO | 待機イベントの説明 |
| WAIT_CLASS_ID | bigint(20) | NO | 待機イベントが属するクラスのID |
| WAIT_CLASS# | bigint(20) | NO | 待機イベントが属するクラスのインデックス |
| WAIT_CLASS | varchar(64) | NO | 待機イベントが属するクラス |
| TOTAL_WAITS | bigint(20) | NO | この待機イベントの合計待機回数 |
| TOTAL_TIMEOUTS | bigint(20) | NO | この待機イベントの合計タイムアウト回数 |
| TIME_WAITED | double | NO | この待機イベントの合計待機時間、単位は10ms |
| AVERAGE_WAIT | double | NO | この待機イベントの平均待機時間、単位は10ms |
| TIME_WAITED_MICRO | bigint(20) | NO | この待機イベントの合計待機時間、単位はマイクロ秒 |

## クエリ例

システムテナントで、現在のノード上にあるすべてのテナントの待機イベントを確認し、上位10件を表示します。

obclient [oceanbase]> SELECT * FROM oceanbase.V$SYSTEM_EVENT LIMIT 10;
