# GV$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのOBServerノードレベルのメジャーコンパクション進捗情報を表示します。

## フィールドの説明

|          フィールド名           |      型      | NULL許容 |                                            説明                                            |
|-------------------------|--------------|------------|--------|
| SVR_IP                  | varchar(46)  | NO         | サーバーIPアドレス                                                                                |
| SVR_PORT                | bigint(20)   | NO         | サーバーポート番号|
| TENANT_ID               | bigint(20)   | NO         | テナントID |
| TYPE                    | varchar(64)  | NO         | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを1つの新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを合成して新しいMinor SSTableを作成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>  |
| ZONE                    | varchar(128) | NO         | Zone情報                                                                                  |
| COMPACTION_SCN                 |bigint(20) unsigned  | NO         | メジャーコンパクションのバージョン情報|
| STATUS                  | varchar(15)  | NO         | ステータス情報  |
| TOTAL_TABLET_COUNT      | bigint(20)   | NO         | TABLETの総数                                                                                |
| UNFINISHED_TABLET_COUNT | bigint(20)   | NO         | 完了していないTABLET数                                                                           |
| DATA_SIZE               | bigint(20)   | NO         | コンパクションが必要なデータの合計サイズ、単位はバイト   |
| UNFINISHED_DATA_SIZE    | bigint(20)   | NO         | 完了していないコンパクションのデータサイズ、単位はバイト  |
| COMPRESSION_RATIO       | double       | NO         | 新しいデータの圧縮率：直近のメジャーバージョンポイント以降に新規書き込まれたデータの圧縮率のみ記録します                                                |
| START_TIME              | timestamp(6) | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME   | timestamp(6) | NO         | 予定完了時間：compaction_progressが100の場合、終了時間を表示します                                               |
| COMMENTS                | varchar(1024) | NO  | コメント情報。メジャーコンパクション中は、現在の最新のCompactionイベントを記録します。メジャーコンパクション終了後は、全体の所要時間を記録します   |
