# V$OB_TRANSACTION_SCHEDULERS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`V$OB_TRANSACTION_SCHEDULERS`は、すべてのサーバーのトランザクションScheduler情報を照会するために使用されます。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | レプリカが存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | レプリカが存在するサーバーのポート |
| SESSION_ID | bigint(20) | NO | V4.3.x系について：<ul><li> V4.3.5 BP2 より前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2 以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODPでパラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはクライアントセッションIDを表します。 </ li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| TX_ID | bigint(20) | NO | トランザクションID |
| STATE | varchar(18) | NO | トランザクションの状態 |
| CLUSTER_ID | bigint(20) | NO | クラスターの一意のID |
| COORDINATOR | bigint(20) | NO | コーディネーターが存在するログストリームID |
| PARTICIPANTS | varchar(1024) | NO | トランザクションの参加者情報 |
| ISOLATION_LEVEL | varchar(16) | NO | 隔離レベル |
| SNAPSHOT_VERSION | bigint(20) unsigned  | NO | RRまたはSERIAL隔離レベルで有効なスナップショットバージョン。無効な場合は-1 |
| ACCESS_MODE | varchar(10) | NO | アクセスモード（読み取り専用または読み書き） |
| TX_OP_SN | bigint(20)  | NO | トランザクションレベルの操作シーケンス番号 |
| ACTIVE_TIME | timestamp(6) | NO | トランザクションが明示的または暗黙的に開始されたタイムスタンプ |
| EXPIRE_TIME | timestamp(6) | NO | トランザクションの有効期限タイムスタンプ |
| CAN_EARLY_LOCK_RELEASE | varchar(7) | NO | ロックを早期に解除できるかどうか |
| FORMATID               | bigint(20)          | NO   | グローバルトランザクションの形式識別子 |
| GLOBALID               | varchar(257)        | NO  | グローバルトランザクションの一意の識別子 |
| BRANCHID               | varchar(257)        | NO  | 分岐トランザクションの一意の識別子 |
