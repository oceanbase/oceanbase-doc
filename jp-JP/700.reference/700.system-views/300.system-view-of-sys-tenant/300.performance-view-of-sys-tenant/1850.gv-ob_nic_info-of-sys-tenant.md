# GV$OB_NIC_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_NIC_INFO`は、テナントが存在するすべてのOBServerノードのNIC情報を表示するために使用されます。現在、主にNICの速度が表示されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | ------- | ------------------- | -------- |
| SVR_IP     | varchar(46)  | NO   | OBServerのIPアドレス    |
| SVR_PORT   | bigint(20)   | NO   | OBServerのRPCポート    |
| DEVNAME    | varchar(128) | NO   | OBServerが配置されているマシンのNIC名     |
| SPEED_MBPS | bigint(20)   | NO   | NIC速度、単位はMbps     |

## クエリ例

テナントが存在するすべてのOBServerノードのNIC情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_NIC_INFO;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+---------+------------+
| SVR_IP         | SVR_PORT | DEVNAME | SPEED_MBPS |
+----------------+----------+---------+------------+
| xx.xx.xx.xx    |     2882 | eth0    |      10000 |
| xx.xx.xx.xx    |     2884 | bond0   |      10000 |
| xx.xx.xx.xx    |     2886 | bond0   |      10000 |
+----------------+----------+---------+------------+
```
