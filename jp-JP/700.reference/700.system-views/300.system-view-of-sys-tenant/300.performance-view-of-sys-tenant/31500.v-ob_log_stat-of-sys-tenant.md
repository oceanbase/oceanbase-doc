# V$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ログストリームPalfの状態を表示します。一般的なユースケースは以下のとおりです：

* ログストリームにリーダーが存在するかどうか（リーダーが存在するレプリカ）を確認する。
* ログストリームのメンバーリスト（Paxosレプリカ数）を確認する。
* レプリカの同期状態を確認する。
* ログストリームのログで回収可能な最新ポイントを確認する。
* ログストリームがログ消費サービスを提供できる範囲（LSN/SCNを含む）を確認する。
* Palfのアクセスモードを確認する。

このビューを照会するテナントによって、得られる結果は異なります。具体的には以下のとおりです：

* システムテナントからこのビューを照会する場合、すべてのテナントのログストリームPalfの状態が表示されます。
* 通常テナントからこのビューを照会する場合、そのテナントのログストリームPalfの状態のみが表示されます。

| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| SVR_IP | varchar(46) | NO | OBServer IP |
| SVR_PORT | bigint(20) | NO | OBServerポート番号 |
| ROLE | varchar(32) | NO | レプリカロール：<ul><li> `LEADER`はレプリカロールがLEADERであることを示します。  </li><li>`FOLLOWER`はレプリカロールがFOLLOWERであることを示します。  </li></ul> |
| PROPOSAL_ID | bigint(20) | NO | PaxosのProposal ID |
| CONFIG_VERSION | varchar(128) | NO | 設定変更に対応するバージョン番号 |
| ACCESS_MODE | varchar(32) | NO | アクセスモード：<ul><li> `APPEND`ログストリームレプリカがプライマリテナントで書き込み可能な状態にあることを示します。  </li><li> `RAW_WRITE`ログストリームレプリカがスタンバイテナントで読み取り専用の状態にあることを示します。 </li></ul>|
| SYNC_MODE         | varchar(128)  | NO | ログストリームの同期モード：<ul><li>`ASYNC`：非同期同期モード</li> <li>`SYNC`：強同期モード</li> <li>`PRE_ASYNC`：強同期モードから非同期同期モードへの切り替え中</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main> |
| PAXOS_MEMBER_LIST | varchar(1024) | NO | Paxosメンバーリスト |
| PAXOS_REPLICA_NUM | bigint(20) | NO | Paxosレプリカ数 |
| IN_SYNC | varchar(3) | NO | レプリカとリーダーが完全に同期しているかどうか |
| BASE_LSN | bigint(20) | NO | 最大回収可能ポイント |
| BEGIN_LSN | bigint(20) | NO | 最小消費可能ポイント（LSN） |
| BEGIN_SCN | bigint(20) | NO | 最小消費可能な時刻（SCN） |
| END_LSN | bigint(20) | NO | 最大連続多数派の時刻/最大消費可能な時刻（LSN） |
| END_SCN | bigint(20) | NO | 最大連続多数派の時刻/最大消費可能な時刻（SCN） |
| MAX_LSN | bigint(20) | NO | 最大書き込み時刻（LSN） |
| MAX_SCN | bigint(20) | NO | 最大書き込み時刻（SCN） |
| ARBITRATION_MEMBER | varchar(128) | NO | アービトレーションメンバーのサーバーアドレス <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0バージョンから導入されました。</p></main> |
| DEGRADED_LIST | varchar(1024) | NO | アービトレーションが有効なシナリオで降格されたフル機能レプリカのリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0バージョンから導入されました。</p></main> |
| LEARNER_LIST | longtext| NO | 現在のログストリームの読み取り専用レプリカリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
