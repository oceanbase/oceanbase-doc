# GV$OB_SERVER_SCHEMA_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上のすべてのテナントのスキーマ情報を表示します。

## フィールドの説明

|          **フィールド名**          |   **タイプ**    | **NULL値を許容するか** |              **説明**              |
|----------------------------|-------------|----------------|----------------------------------|
| SVR_IP                     | varchar(46) | NO             | サーバーのIPアドレス                        |
| SVR_PORT                   | bigint(20)  | NO             | サーバーのポート番号                           |
| TENANT_ID                  | bigint(20)  | NO             | テナントID                            |
| REFRESHED_SCHEMA_VERSION   | bigint(20)  | NO             | テナントがリフレッシュしたSchemaバージョン                 |
| RECEIVED_SCHEMA_VERSION    | bigint(20)  | NO             | テナントがリフレッシュすべきSchemaバージョン               |
| SCHEMA_COUNT               | bigint(20)  | NO             | 対応するSchemaバージョンにおける、各Schemaオブジェクト数の合計                     |
| SCHEMA_SIZE                | bigint(20)  | NO             | 対応するSchemaバージョンにおける、各Schemaオブジェクトが占めるメモリ総サイズ、単位はバイト                     |
| MIN_SSTABLE_SCHEMA_VERSION | bigint(20)  | NO             | テナントSSTable上に記録されている最小schema_version |

## クエリ例

システムテナントは、すべてのOBServerノード上のすべてのテナントのスキーマ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_SERVER_SCHEMA_INFO;
```
