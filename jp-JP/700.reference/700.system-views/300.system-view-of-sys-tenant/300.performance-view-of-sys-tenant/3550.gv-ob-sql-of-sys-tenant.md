# GV$OB_SQL_CCL_STATUS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>V4.3.X系では、このビューはOceanBaseデータベースV4.3.5 BP3バージョンから導入されました。<br>V4.4.X系では、このビューはOceanBaseデータベースV4.4.1バージョンから導入されました。</p>
  </main>

## 機能の概要

現在時点で、全テナントの全ノードで、対応するレート制限ルールに一致したSQLの数を記録し、システムで設定されたレート制限ルールの影響を観測するために使用されます。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
|---------|-------|-------------|--------|
| CON_ID              | bigint(20)  | NO   | テナントID      |
| SVR_IP              | varchar(46) | NO   | OBServerノードのIPアドレス     |
| SVR_PORT            | bigint(20)  | NO   | BServerノードのポート番号      |
| CCL_RULE_ID         | bigint(20)  | NO   | 有効なレート制限ルールID     |
| FORMAT_SQLID        | varchar(32) | NO   | レート制限の適用単位：<ul><li>ルール単位：0</li><li>Format SQLID単位：1</li></ul>      |
| CURRENT_CONCURRENCY | bigint(20)  | NO   | このレート制限ルールにヒットして現在実行中のSQL数     |
| MAX_CONCURRENCY     | bigint(20)  | NO   | このレート制限ルールの同時実行数の上限    |

## クエリ例

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SQL_CCL_STATUS;
```
