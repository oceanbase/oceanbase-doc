# V$OB_RPC_OUTGOING

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上で、すべてのテナントによるRPC送信統計情報を表示します。

## フィールドの説明

|    **フィールド名**    |    **タイプ**    | **NULL値を許容するか** |        **説明**         |
|----------------|--------------|----------------|-----------------------|
| TENANT_ID      | bigint(20)   | NO             | テナントID                 |
| SVR_IP         | varchar(46)  | NO             | サーバーIPアドレス              |
| SVR_PORT       | bigint(20)   | NO             | サーバーのポート番号                |
| PCODE          | bigint(20)   | NO             | RPCパケットコード       |
| PCODE_NAME     | varchar(256) | NO             | RPCパケットコードに対応する名前 |
| COUNT          | bigint(20)   | NO             | RPC送信回数                   |
| TOTAL_TIME     | bigint(20)   | NO             | 総合計費用時間、単位はマイクロ秒                |
| TOTAL_SIZE     | bigint(20)   | NO             | 総送信データ量サイズ、単位はバイト            |
| FAILURE        | bigint(20)   | NO             | 送信失敗回数                |
| TIMEOUT        | bigint(20)   | NO             | 送信タイムアウト回数                |
| SYNC           | bigint(20)   | NO             | 同期待機RPCリクエスト数         |
| ASYNC          | bigint(20)   | NO             | 非同期コールバックRPCリクエスト数         |
| LAST_TIMESTAMP | timestamp(6) | NO             | 統計情報最終更新時間            |

## クエリ例

システムテナント内で、テナントIDが1004のテナントが現在のノードに送信したRPCリクエストを確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RPC_OUTGOING WHERE TENANT_ID=1004 LIMIT 10;
```
