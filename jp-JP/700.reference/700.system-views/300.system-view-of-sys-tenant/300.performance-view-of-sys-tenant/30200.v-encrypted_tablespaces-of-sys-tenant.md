# V$ENCRYPTED_TABLESPACES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで暗号化機能が有効なテーブルスペースの暗号化状態を表示します。システムテナントでは暗号化を有効にすることはできません。

## フィールドの説明

|     **フィールド名**     |       **型**        | **NULL許容** |                       **説明**                       |
|------------------|---------------------|------------|------------------------------------------------------------------------------------|
| TABLESPACE_ID    | bigint(20)          | NO         | テーブルスペースID                                             |
| ENCRYPTIONALG    | varchar(30)         | NO         | 暗号化アルゴリズム名：<ul><li>AES-128   </li><li> AES-192   </li><li> AES-256   </li><li> SM4 </li></ul>   |
| ENCRYPTED        | varchar(3)          | NO         | 暗号化の完了状況：<ul><li>YES</li><li>NO</li></ul>      |
| ENCRYPTEDKEY     | varchar(33)         | NO         | マスターキーで暗号化された暗号鍵                                      |
| MASTERKEYID      | bigint(20) unsigned | NO         | マスターキーのバージョン                                              |
| BLOCKS_ENCRYPTED | decimal(20,0)       | NO         | 暗号化マクロブロックの数                                            |
| BLOCKS_DECRYPTED | decimal(21,0)       | NO         | 未暗号化マクロブロックの数                                           |
| STATUS           | varchar(10)         | NO         | 暗号化状態：<ul><li> NORMAL：正常状態   </li><li> ENCRYPTING：暗号化中   </li><li> DECRYPTING：復号化中   </li></ul>   |
| CON_ID           | bigint(20)          | NO         | テナントID                                              |
