# V$OB_COMPACTION_SUGGESTIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上でのCompactionに関する推奨情報を表示します。

## フィールドの説明

|    フィールド名     |      型           | NULL許容    |                                                    説明                                                    |
|-------------|---------------|------------|--------|
| SVR_IP      | varchar(46)   | NO         | サーバーのIPアドレス                                                                 |
| SVR_PORT    | bigint(20)    | NO         | サーバーのポート番号 |
| TENANT_ID   | bigint(20)    | NO         | テナントID |
| TYPE        | varchar(64)   | NO         | Compactionのタイプ： <ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのマージ</li> <li>`MEDIUM_MERGE`：パーティションレベルのマージ</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに、または複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>    |
| LS_ID       | bigint(20)    | NO         |ログストリームID|
| TABLET_ID   | bigint(20)    | NO         | データシャーディングID                                                                                  |
| START_TIME  | timestamp(6)  | NO         | 開始時間  |
| FINISH_TIME | timestamp(6)  | NO         | 終了時間  |
| SUGGESTION  | varchar(1024) | NO         | 推奨情報  |
