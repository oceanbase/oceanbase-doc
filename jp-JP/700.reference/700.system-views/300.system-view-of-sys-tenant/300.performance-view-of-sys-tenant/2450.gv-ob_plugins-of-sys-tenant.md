# GV$OB_PLUGINS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

プラグインのリストと各プラグインの詳細情報を表示します。

## フィールドの説明

|     フィールド名     |     型      | NULL許容 |                説明                 |
|-------------------|----------------|------|------|
| SVR_IP            | varchar(46)    | NO   | レプリカが存在するノードのアドレス |
| SVR_PORT          | bigint(20)     | NO   | レプリカのポート番号 |
| NAME              | varchar(64)    | YES  | プラグイン名 |
| STATUS            | varchar(64)    | YES  | プラグインの状態：<ul><li>READY：有効</li><li>UNINIT：初期化されていない</li><li>DEAD：無効</li></ul> |
| TYPE              | varchar(80)    | YES  | プラグインタイプ：FTPARSER（分詞プラグイン） |
| LIBRARY           | varchar(128)   | YES  | プラグインの動的リンクライブラリ名（組み込みプラグインには対応するリンクライブラリなし） |
| LIBRARY_VERSION   | varchar(80)    | YES  | このプラグインが依存するプラグインのベースライブラリバージョン |
| LIBRARY_REVISION  | varchar(80)    | YES  | プラグインライブラリの改訂版 |
| INTERFACE_VERSION | varchar(80)    | YES  | このプラグインが実装する具体的なインターフェースAPIバージョン |
| AUTHOR            | varchar(64)    | YES  | プラグインの著者情報 |
| LICENSE           | varchar(64)    | YES  | プラグインのライセンス |
| DESCRIPTION       | varchar(65535) | YES  | プラグインの説明情報 |

## クエリ例

システムテナントで、すべてのプラグインリストと各プラグインの詳細情報を確認します。
