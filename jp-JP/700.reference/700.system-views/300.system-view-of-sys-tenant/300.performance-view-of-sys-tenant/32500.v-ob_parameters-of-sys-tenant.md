# V$OB_PARAMETERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_PARAMETERS` は、現在のOBServerノード上のパラメータ（アンダースコア「_」で始まる隠れたパラメータを含む）情報を表示するために使用されます。

## フィールド説明

|    フィールド名    |       型           | NULL許容   |                                説明                                 |
|------------|----------------|------------|---------------------------------------------------------------------------------------------------|
| SVR_IP     | varchar(46)    | NO         | サーバーのIPアドレス                                                         |
| SVR_PORT   | bigint(20)     | NO         | サーバーのポート番号                                                            |
| ZONE       | varchar(128)   | NO         | Zone名                                                             |
| SCOPE      | varchar(64)    | NO         | <ul><li>`CLUSTER` クラスタレベル構成パラメータ </li></ul>`TENANT` テナントレベル構成パラメータ  </li></ul> |
| TENANT_ID  | bigint(20)     | YES        | テナントID：<ul><li>`NULL` どのテナントにも属さない </li><li>有効値：テナントID </li></ul> |
| NAME       | varchar(128)   | NO         | パラメータ名                                                             |
| DATA_TYPE  | varchar(128)   | YES        | パラメータ値の型 <main id="notice" type='explain'><h4>説明</h4><p>V4.3.0以降、このフィールドの値は`NULL`から変更され、構成パラメータの具体的なタイプ情報を表示するようになりました。</p></main>  |
| VALUE      | varchar(65536) | NO         | パラメータ値                                                              |
| INFO       | varchar(4096)  | NO         | パラメータの説明                                                             |
| SECTION    | varchar(128)   | NO         | パラメータが属するモジュール                                                          |
| EDIT_LEVEL | varchar(128)   | NO         | パラメータ変更の有効化方法：<ul><li>`READONLY`：読み取り専用で、変更できません </li><li>`STATIC_EFFECTIVE`：変更後は再起動が必要です </li><li> `DYNAMIC_EFFECTIVE`：変更後は動的に反映されます</li></ul>    |
| DEFAULT_VALUE | varchar(65536) | NO   | パラメータのデフォルト値<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li></ul></main>      |
| ISDEFAULT     | varchar(3)     | NO   | 現在の値がデフォルト値かどうか。<ul><li>NO：現在の値がデフォルト値ではないことを示します。</li><li>YES：現在の値がデフォルト値であることを示します。</li></ul><main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li></ul></main>     |

ビューにおける `DATA_TYPE` フィールドの取り得る値は以下のとおりです。

| フィールド値 | 説明 | 例（NAME=VALUE）|
| --------| ------ |------------------ |
| BOOL    | ブール型           | enable_ddl=True |
| INT     | 整数型           | log_disk_percentage=1 |
| DOUBLE  | 浮動小数点数型         | server_cpu_quota_min=1.0 |
| STRING  | 文字列型         | leak_mod_to_check='NONE' |
| STR_LIST| セミコロン区切り文字列リスト| config_additional_dir='etc2;etc3' |
| TIME    | 時間範囲             | merger_check_interval='10m' |
| MOMENT  | 時刻             | major_freeze_duty_time='02:00' |
| CAPACITY| 容量、例：3MB、5G   | log_disk_size='0M' |
| VERSION | バージョン番号             | compatible='4.3.0.0' |
| MODE    | OBKVの該当機能の有効/無効を指定する | _obkv_feature_mode = 'ttl=off, rerouting=on' |

## クエリ例

このOBServerノード上のパラメータ`large_query_threshold`に関する情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PARAMETERS WHERE NAME LIKE '%large_query_threshold%'\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************

    TENANT_ID: NULL

        VALUE: 5s
         INFO: threshold for execution time beyond which a request may be paused and rescheduled as a \'large request\', 0ms means disable \'large request\'. Range: [0ms, +∞)
      SECTION: TENANT
   EDIT_LEVEL: DYNAMIC_EFFECTIVE
DEFAULT_VALUE: 5s
    ISDEFAULT: NO
1 row in set
```
