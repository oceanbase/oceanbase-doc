# GV$OB_SERVER_STORAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上で共有ストレージクラスタ設定を使用するオブジェクトストレージの関連情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールドの説明

| フィールド名              | 型          | NULL許容 | 説明                          |
|----------------------|---------------|----------------|-------------------------------|
| SVR_IP               | varchar(46)   | NO   | OBServerノードのIPアドレス    |
| SVR_PORT             | bigint(20)    | NO   | OBServerノードのポート番号     |
| PATH                 | varchar(1024) | NO   | オブジェクトストレージが使用するルートパス。このパスで一般的に使用されるタイプには、`oss://`、`s3://`などがあります。   |
| ENDPOINT             | varchar(1024) | NO   | オブジェクトストレージのEndpoint。     |
| USED_FOR             | varchar(256)  | NO   | オブジェクトストレージの使用者。現在は`ALL`のみサポートしており、clogとdataが使用することを示します。    |
| ZONE                 | varchar(128)  | NO   | Zone名    |
| STORAGE_ID           | bigint(20)    | NO   | オブジェクトストレージパスの番号。同じパスは同じSTORAGE_IDを持ちます     |
| MAX_IOPS             | bigint(20)    | NO   | オブジェクトストレージの最大IOPS      |
| MAX_bandWIDTH        | bigint(20)    | NO   | オブジェクトストレージの最大帯域幅、単位はバイト     |
| CREATE_TIME          | timestamp(6)  | NO   | オブジェクトストレージの作成時間     |
| AUTHORIZATION        | varchar(1024) | NO   | オブジェクトストレージの認証情報     |
| STATE                | varchar(256)  | NO   | オブジェクトストレージの状態：<ul><li>`ADDING`：追加中の状態 </li> <li>`ADDED`：正常に追加済み</li> <li>`DROPPING`：削除中の状態</li> <li>`ROTATING`：AK/SKのローテーション中</li> <li>`ROTATED`：AK/SKのローテーション完了</li></ul>      |
| STATE_INFO           | varchar(1024) | NO   | オブジェクトストレージの状態情報     |
| LAST_CHECK_TIMESTAMP | timestamp(6)  | NO   | 最終チェック時間     |
| EXTENSION            | varchar(4096) | NO   | オブジェクトストレージのその他の情報     |
