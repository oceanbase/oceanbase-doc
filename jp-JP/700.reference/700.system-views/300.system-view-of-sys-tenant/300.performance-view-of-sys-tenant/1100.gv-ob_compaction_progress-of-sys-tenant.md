# GV$OB_COMPACTION_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのOBServerノードレベルのコンパクション進捗状況を表示します。

## フィールドの説明

|          フィールド名           |      タイプ      | NULLを許容するか |                                            説明                                            |
|-------------------------|--------------|------------|--------|
| SVR_IP                  | varchar(46)  | NO         | サーバーのIPアドレス                                                                                |
| SVR_PORT                | bigint(20)   | NO         | サーバーのポート番号|
| TENANT_ID               | bigint(20)   | NO         | テナントID |
| TYPE                    | varchar(64)  | NO         | コンパクションのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なコンパクションタイプ。指定された時点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>   |
| ZONE                    | varchar(128) | NO         | Zone情報                                                                                  |
| COMPACTION_SCN                 |bigint(20) unsigned  | NO         | コンパクションバージョン情報|
| STATUS                  | varchar(15)  | NO         | ステータス情報  |
| TOTAL_TABLET_COUNT      | bigint(20)   | NO         | TABLETの総数                                                                                |
| UNFINISHED_TABLET_COUNT | bigint(20)   | NO         | 未完了のTABLET数                                                                           |
| DATA_SIZE               | bigint(20)   | NO         | コンパクションが必要な総データ量（単位：バイト）   |
| UNFINISHED_DATA_SIZE    | bigint(20)   | NO         | 未完了のコンパクションデータ量（単位：バイト）  |
| COMPRESSION_RATIO       | double       | NO         | 新データの圧縮率：前のmajor version以降に新しく書き込まれたデータの圧縮率のみを記録します                                                |
| START_TIME              | timestamp(6) | NO         | 開始時間  |
| ESTIMATED_FINISH_TIME   | timestamp(6) | NO         | 予想完了時間：compaction_progressが100の場合、終了時間を表示します                                               |
| COMMENTS                | varchar(1024) | NO  | コメント情報。コンパクション中は現在の最新のコンパクションイベントを記録します。コンパクションが終了した場合は、全体の所要時間を記録します   |
