# GV$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_ACTIVE_SESSION_HISTORY`は、すべてのテナントにおけるすべてのOBServerノード上でアクティブなセッションの履歴を表示するために使用されます。
