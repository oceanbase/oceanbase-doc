# GV$OB_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューは、V4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_RES_MGR_SYSSTAT`は、すべてのテナントのすべてのOBServerにおけるリソースグループの統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
|------------|-------------|---------------------|----------------------------------------|
| CON_ID     | bigint(20)  | NO   | テナントID     |
| GROUP_ID   | bigint(20)  | NO   | 所属リソースグループID     |
| SVR_IP     | varchar(46) | NO   | ノードIP     |
| SVR_PORT   | bigint(20)  | NO   | ノードPORT    |
| STATISTIC# | bigint(20)  | NO   | 統計項目番号     |
| NAME       | varchar(64) | NO   | 統計項目名    |
| CLASS      | bigint(20)  | NO   | 統計項目カテゴリ     |
| VALUE      | bigint(20)  | NO   | 統計項目値     |
| VALUE_TYPE | varchar(16) | NO   | 値のタイプ：累積型、代入型     |
| STAT_ID    | bigint(20)  | NO   | 統計項目ID     |

## クエリ例

すべてのテナントのすべてのOBServer上のリソースグループに関する統計情報を照会します。
