# V$OB_ARCHIVE_DEST_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのユーザーテナントの各アーカイブ宛先のステータスを表示します。

## フィールドの説明

| フィールド | タイプ | NULL値を許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)   | NO | テナントID |
| DEST_ID | bigint(20)   | NO | アーカイブ先のID |
| PATH | varchar(4096) | NO | アーカイブパス |
| STATUS | varchar(64) | NO | アーカイブ状態 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | アーカイブ済みログの連続的な時点 |
| SYNCHRONIZED | varchar(32) | NO | アーカイブがテナントログと同期されているかどうか：<ul><li> `YES`はテナントログと同期されていることを示します。 </li><li> `NO`はテナントログと同期されていないことを示します。 </li></ul>|
| COMMENT | varchar(262144) | NO | エラーメッセージ |

## クエリ例

システムテナントがユーザーテナントの各アーカイブ宛先のステータスを照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_ARCHIVE_DEST_STATUS;
```

クエリ結果は次のとおりです：

```shell
+-----------+---------+-------------------------------------+--------+---------------------+--------------+---------+
| TENANT_ID | DEST_ID | PATH                                | STATUS | CHECKPOINT_SCN      | SYNCHRONIZED | COMMENT |
+-----------+---------+-------------------------------------+--------+---------------------+--------------+---------+
|      1002 |    1001 | file:///home/admin/oceanbase/arglog | DOING  | 1736321349494697000 | NO           |         |
+-----------+---------+-------------------------------------+--------+---------------------+--------------+---------+
1 row in set
```
