# V$DML_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上にある各テナントのユーザーテーブルのDML情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| INST_ID | bigint(20) | NO | テナントID |
| OBJN | bigint(20) | NO | オブジェクトID |
| INS | bigint(20) | NO | 前回の統計情報収集以降のおおよその挿入回数 |
| UPD | bigint(20) | NO | 前回の統計情報収集以降のおおよその更新回数 |
| DEL | bigint(20) | NO | 前回の統計情報収集以降のおおよその削除回数 |
| DROPSEG | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLとなっています |
| CURROWS | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLとなっています |
| PAROBJN | bigint(20) | NO | 物理パーティションID、すなわちTablet ID |
| LASTUSED | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLとなっています |
| FLAGS | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLとなっています |
| CON_ID | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLとなっています |

## クエリ例

テナントIDが1004のテナントにおける、現在のOBServerノード上のユーザーテーブルのDML情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$DML_STATS WHERE INST_ID=1004;
```
