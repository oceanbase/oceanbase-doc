# V$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナントでは、ビュー`V$OB_KV_GROUP_COMMIT_STATUS`を使用して、現在のノード上のすべてのOBKVテナントクライアント接続のグループコミット状態情報にアクセスできます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | グループコミットが存在するノードのIPアドレス |
| SVR_PORT | bigint(20) | NO | グループコミットが存在するノードのポート番号 |
| TENANT_ID | bigint(20) | NO | テナントID： <ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID</li></ul> |
| TABLE_ID | bigint(20) | NO | グループコミットが属するテーブルのID |
| LS_ID | bigint(20) | NO | グループコミットが属するLS ID |
| SCHEMA_VERSION | bigint(20) | NO | グループコミットが属するテーブルのschema_version |
| GROUP_TYPE | varchar(32) | NO | グループコミットのタイプ。現在サポートされているキュータイプ：<ul><li> get：GETリクエストキュー </li><li>put：PUTリクエストキュー </li><li>del：DELETEリクエストキュー </li><li>replace：REPLACEリクエストキュー </li><li>insert：INSERTリクエストキュー </li><li>hybird：混合操作リクエストキュー </li><li>fail：バッチ実行失敗キュー </li></ul>  |
| QUEUE_SIZE | bigint(20) | NO | グループコミット内のリクエストキューのサイズ。現在未消費のリクエスト数を表す |
| BATCH_SIZE | bigint(20) | NO | グループコミット内のバッチサイズ |
| CREATE_TIME | timestamp(6) | NO  | グループコミット内のこのグループが作成された時間  |
| UPDATE_TIME | timestamp(6) | NO  | グループコミット内のこのグループの状態情報が更新された時間  |

## クエリ例

現在のノード上の自身のOBKVテナントクライアント接続のグループコミット状態情報を照会し、1日目のレコードを表示します。

```shell
obclient > SELECT * FROM oceanbase.V$OB_KV_GROUP_COMMIT_STATUS limit 2;
```
