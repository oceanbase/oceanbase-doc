# GV$OB_MERGE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>GV$MERGE_INFO</code> は、V4.0.0バージョン以降で <code>GV$OB_MERGE_INFO</code> に変更されました。V4.0.0以降のバージョンでは、新しいビュー名 <code>GV$OB_MERGE_INFO</code> を使用してクエリを実行する必要があります。元のビュー名 <code>GV$MERGE_INFO</code> を使用してクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

OceanBaseクラスタで完了したコンパクションに関する統計情報を表示します。

## フィールドの説明

|       フィールド名        |      タイプ       | NULLを許容するか |                                 説明                                  |
|-------------------|---------------|------------|-----------------------------------------------------------------------------------------------------|
| SVR_IP            | varchar(46)   | NO         | サーバーのIPアドレス                                                           |
| SVR_PORT          | bigint(20)    | NO         | サーバーのポート番号                                                              |
| TENANT_ID         | bigint(20)    | NO         | テナントID                                                               |
| LS_ID             | bigint(20)    | NO         | ログストリームID                                                              |
| TABLET_ID         | bigint(20)    | NO         | データシャードID                                                             |
| ACTION            | varchar(64)   | NO         | Compactionの具体的な動作：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに統合するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに統合します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプで、指定された時点以前のデータをMeta Major SSTableに統合します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータやコミットされていないトランザクションデータは含まれません。</li></ul>    |
| COMPACTION_SCN    | bigint(20) unsigned    | NO         | コンパクションのバージョン番号                                                      |
| START_TIME        | timestamp(6)  | NO         | コンパクション開始時間                                                     |
| END_TIME          | timestamp(6)  | NO         | コンパクション終了時間                                                     |
| MACRO_BLOCK_COUNT | bigint(20)    | NO         | コンパクションのマクロブロックの総数                                                     |
| REUSE_PCT         | decimal(26,2) | NO         | コンパクションマクロブロックの再利用率                                                    |
| PARALLEL_DEGREE   | bigint(20)    | NO         | コンパクションの並列度                                                      |

## クエリ例

sysテナントは、クラスタ内で完了したダンプ（`MINI_MERGE`）の統計情報を照会し、上位5件のレコードを返します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MERGE_INFO WHERE ACTION='MINI_MERGE' LIMIT 5;
```
