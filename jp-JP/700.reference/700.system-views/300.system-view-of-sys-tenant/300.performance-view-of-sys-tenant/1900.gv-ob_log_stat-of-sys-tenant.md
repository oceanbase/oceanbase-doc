# GV$OB_LOG_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ログストリームPalfの状態を表示します。主な利用シナリオは以下のとおりです：

* ログストリームにリーダーが存在するかどうかを照会します（リーダーが存在するレプリカ）。
* ログストリームのメンバーリスト（Paxosレプリカ数）を照会します。
* レプリカ同期状態を照会します。
* ログストリームのログの回収可能なポイントを照会します。
* ログストリームで許可されるログ消費サービスの範囲（LSN/SCNを含む）を照会します。
* Palfのアクセスモードを照会します。

このビューを照会するテナントによって、取得される結果は異なります。具体的には：

* システムテナントからこのビューを照会する場合、すべてのテナントのログストリームPalfの状態を表示できます。
* 通常のテナントからこのビューを照会する場合、そのテナントのログストリームPalfの状態のみが表示されます。

| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| SVR_IP | varchar(46) | NO | OBServer IPアドレス |
| SVR_PORT | bigint(20) | NO | OBServerポート番号 |
| ROLE | varchar(32) | NO | レプリカロール：<ul><li> `LEADER`はレプリカロールがLEADERであることを示します。 </li><li>`FOLLOWER`はレプリカロールがFOLLOWERであることを示します。 </li></ul> |
| PROPOSAL_ID | bigint(20) | NO | Paxosの提案ID |
| CONFIG_VERSION | varchar(128) | NO | 構成変更に対応するバージョン番号 |
| ACCESS_MODE | varchar(32) | NO | アクセスモード：<ul><li> `APPEND`ログストリームレプリカはプライマリテナントで書き込み可能な状態です。 </li><li> `RAW_WRITE`ログストリームレプリカはスタンバイテナントで読み取り専用の状態です。 </li></ul>|
| PAXOS_MEMBER_LIST | varchar(1024) | NO | Paxosメンバーリスト |
| PAXOS_REPLICA_NUM | bigint(20) | NO | Paxosレプリカ数 |
| IN_SYNC | varchar(3) | NO | レプリカとリーダーが完全に同期されているかどうか |
| BASE_LSN | bigint(20) | NO | 最大回収可能ポイント |
| BEGIN_LSN | bigint(20) | NO | 最小消費可能ポイント（LSN） |
| BEGIN_SCN | bigint(20) | NO | 最小消費可能ポイント（SCN） |
| END_LSN | bigint(20) | NO | 最大連続多数派のポイント／最大消費可能ポイント（LSN） |
| END_SCN | bigint(20) | NO | 最大連続多数派のポイント／最大消費可能ポイント（SCN） |
| MAX_LSN | bigint(20) | NO | 最大書き込みポイント（LSN） |
| MAX_SCN | bigint(20) | NO | 最大書き込みポイント（SCN） |
| ARBITRATION_MEMBER | varchar(128) | NO | アービトレーションメンバーのサーバーアドレス <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0バージョンから導入されました。</p></main> |
| DEGRADED_LIST | varchar(1024) | NO | アービトレーションが有効なシナリオで降格されたフル機能レプリカの一覧 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0バージョンから導入されました。</p></main> |
| LEARNER_LIST | longtext| NO | 現在のログストリームの読み取り専用レプリカリスト <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
