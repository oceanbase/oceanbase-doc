# V$OB_CGROUP_CONFIG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`V$OB_CGROUP_CONFIG`は、OBServerのcgroup構成を簡単に照会するために使用されます。ビューのフィールド情報は、OBServerのインストールディレクトリ内のcgroupディレクトリ（例：`/home/admin/oceanbase/cgroup`）から取得されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | OBServerのIPアドレス |
| SVR_PORT | bigint(20) | NO | OBServerのポート番号 |
| CFS_QUOTA_US | bigint(20) | NO | スレッドのCPU時間スライス、単位はマイクロ秒。このフィールドの情報は、pathディレクトリ内の`cpu.cfs_quota_us`から取得します |
| CFS_PERIOD_US | bigint(20) | NO | cgroupの制御周期時間、単位はマイクロ秒。Quotaと組み合わせて使用します。このフィールドの情報は、pathディレクトリ内の`cpu.cfs_period_us`から取得します |
| SHARES | bigint(20) | NO | スレッドのCPU利用率の割合（CPUがフル負荷の場合にのみ有効）。このフィールドの情報は、pathディレクトリ内の`cpu.shares`から取得します |
| CGROUP_PATH | varchar(256) | NO | OBServerが設定するcgroupディレクトリの特定の階層パス |

## クエリ例

OBServerのcgroup構成を照会します。

```shell
obclient > SELECT * FROM oceanbase.GV$OB_CGROUP_CONFIG;
```
