# gv$tenant_memstore_allocator_info

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが最適化されたため、このビューはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ビュー<a href="600.gv-memstore-of-sys-tenant.md">GV$OB_MEMSTORE</a>およびビュー<a href="2000.gv-ob_memstore_info-of-sys-tenant.md">GV$OB_MEMSTORE_INFO</a>を使用してMemTableに関する情報を確認できます。</li></ul>
</main>

## 機能の概要

`gv$tenant_memstore_allocator_info`ビューは、接続先のOBServerノード上のMemTableに関するいくつかの情報を表示します。主にテナントのMemStoreメモリが長時間解放されない問題のトラブルシューティングに使用されます。各行のレコードは、単一のMemTableの情報に対応します。

## フィールドの説明

|      **フィールド名**   |   **タイプ**  | **NULL値を許容するか** |                  **説明**                 |
|---------------------|-------------|----------------|-----------------------------------------------|
| SVR_IP              | varchar(32) | NO           | OBServerのIPアドレス。                         |
| SVR_PORT            | bigint(20)  | NO             | OBServerのポート。                             |
| TENANT_ID           | bigint(20)  | NO             | テナントID。                                    |
| TABLE_ID            | bigint(20)  | NO             | テーブルID。                                     |
| PARTITION_ID        | bigint(20)  | NO             | パーティションID。                                    |
| MT_BASE_VERSION     | bigint(20)  | NO             | このMemTableに対応する開始トランザクションバージョン。                     |
| RETIRE_clock        | bigint(20)  | NO             | このMemTableが属するテナントの現在のMemStoreに割り当てられたメモリの総量、単位はバイトです。      |
| MT_IS_FROZEN        | bigint(20)  | NO             | このMemTableが凍結されているかどうか。                        |
| MT_PROTECTION_CLOCK | bigint(20)  | NO             | このMemTableに初めてメモリが割り当てられた時点で、所属するテナントのMemStoreに既に割り当てられていたメモリ量、単位はバイトです。 |
| MT_SNAPSHOT_VERSION | bigint(20)  | NO             | このMemTableのスナップショットバージョン。                         |

## クエリ例

クラスタ内のすべてのテナントのOBServerノード上のMemTable情報を確認し、上位5件のレコードを表示するように指定します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.gv$tenant_memstore_allocator_info LIMIT 5;
```
