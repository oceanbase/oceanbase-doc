# GV$OB_OPT_STAT_GATHER_MONITOR

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上のすべてのテナントにおける統計情報収集タスクのリアルタイム状態を表示します。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| TENANT_ID | bigint(20) | NO | 収集タスクが存在するテナントID |
| SVR_IP | varchar(46) | NO | 収集タスクが存在するノードのアドレス |
| SVR_PORT | bigint(20) | NO | 収集タスクが存在するノードのポート |
| SESSION_ID | bigint(20) | NO |収集タスクが存在するセッションID<br>V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョンでは：<br>すべての接続方式(直接接続モード/ODPモード)において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>直接接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| TRACE_ID | varchar(64) | NO | 収集タスクが存在するTRACE ID |
| TASK_ID | varchar(36) | NO | 収集タスクID(UUID生成、グローバル一意) |
| TYPE | varchar(16) | NO | 収集タスクの種類 |
| TASK_START_TIME | datetime(6) | NO | 収集タスク開始時間 |
| TASK_DURATION_TIME | bigint(20) | NO | 収集タスクの継続時間、単位はマイクロ秒 |
| TASK_TABLE_COUNT | bigint(20) | NO | 収集タスクで収集するテーブル数 |
| COMPLETED_TABLE_COUNT | bigint(20) | NO | 収集タスクで完了したテーブル数 |
| RUNNING_TABLE_OWNER | varchar(128) | NO | 収集タスクが収集中のテーブルのユーザー名 |
| RUNNING_TABLE_NAME | varchar(256) | NO | 収集タスクが収集中のテーブル名 |
| RUNNING_TABLE_DURATION_TIME | bigint(20) | NO | 収集タスクが収集中のテーブルの継続時間 |
| RUNNING_TABLE_PROGRESS      | varchar(256) | NO   | 収集タスクの収集進捗 |

## クエリ例

```shell
obclient> SELECT * FROM oceanbase.GV$OB_OPT_STAT_GATHER_MONITOR WHERE TENANT_ID = 1006;
```
