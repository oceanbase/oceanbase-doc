# V$SQL_JOIN_FILTER

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上で各テナントのJoin Filter実行に関する情報を動的に表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート番号 |
| QC_SESSION_ID | bigint(0) | NO | 指定されたパラレルクエリのカーソルに対応するQC（Query Coordinator）セッションID<br>V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョンでは：<br>すべての接続方式（ダイレクト接続モード/ODPモード）で、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョンでは：<ul><li>ダイレクト接続モードでは：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code>が設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code>が設定されている場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| QC_INSTANCE_ID | bigint(0) | NO | 指定されたパラレルクエリのカーソルに対応するQC（Query Coordinator）インスタンスID |
| SQL_PLAN_HASH_VALUE | bigint(0) | NO | 指定されたパラレルクエリのカーソルに対応するSQL計画のHash値 |
| FILTER_ID | bigint(20) | NO | 接続フィルターを識別するID。実行計画内のフィルターIDに対応します |
| BITS_SET | bigint(0) | NO | BLOOM_FILTERで使用されるBitmap（結合ビットマップ）のサイズ。現在のバージョンでは互換性のためにのみ使用されます |
| FILTERED | bigint(20) | NO | 接続フィルターが処理した行数 |
| PROBED | bigint(20) | NO | ビットマップフィルターテストを通過した右テーブルの行数。ここではフィルタリングされた行数とされなかった行数の合計を指します |
| ACTIVE | bigint(0) | NO | フィルターがアクティブ状態（はい）または非アクティブ状態（いいえ）かどうか |
| CON_ID | bigint(20) | NO | データが属するコンテナのID |
| TRACE_ID | varchar(64) | NO | SQL文に対応するTrace ID |
