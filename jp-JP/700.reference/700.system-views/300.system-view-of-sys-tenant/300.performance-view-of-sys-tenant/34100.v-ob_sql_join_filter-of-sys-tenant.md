# V$SQL_JOIN_FILTER

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントが現在のOBServerノード上でJoin Filterを実行した関連情報を動的に表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート番号 |
| QC_SESSION_ID | bigint(0) | NO | 指定された並列クエリのカーソルのQC（Query Coordinator）セッションID<br>V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの設定パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| QC_INSTANCE_ID | bigint(0) | NO | 指定された並列クエリのカーソルのQC（Query Coordinator）インスタンスID |
| SQL_PLAN_HASH_VALUE | bigint(0) | NO | 指定された並列クエリのカーソルのSQL計画のHash値 |
| FILTER_ID | bigint(20) | NO | 接続フィルターを識別するID。このIDは実行計画内のフィルターIDに対応します |
| BITS_SET | bigint(0) | NO |  BLOOM_FILTERで使用されるBitmap（結合ビットマップ）のサイズ。現在のバージョンでは互換性のためにのみ使用されます |
| FILTERED | bigint(20) | NO | 接続フィルターが処理した行数 |
| PROBED | bigint(20) | NO | ビットマップフィルターテストを通過した右テーブルの行数。ここではフィルタリングされた行数とされなかった行数の合計を指します |
| ACTIVE | bigint(0) | NO | フィルターがアクティブ状態（はい）または非アクティブ状態（いいえ）かどうか |
| CON_ID | bigint(20) | NO | データが属するコンテナのID |
| TRACE_ID | varchar(64) | NO | SQLステートメントに対応するTrace ID |
