# V$OB_DTL_INTERM_RESULT_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.4バージョンから導入されました。</p>

## 機能の概要

DTL中間結果マネージャーの監視情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| TENANT_ID | bigint(20) | NO | テナントID |
| TRACE_ID | varchar(64) | NO | ステートメントのTRACE ID |
| OWNER | varchar(64) | NO | 中間結果の使用者 |
| START_TIME | timestamp(6) | NO | 中間結果を書き込んだ時間 |
| EXPIRE_TIME | timestamp(6) | NO | 中間結果のタイムアウト時間 |
| HOLD_MEMORY | bigint(20) | NO | 使用しているメモリサイズ、単位はバイト |
| DUMP_SIZE | bigint(20) | NO | ダンプサイズ、単位はバイト |
| DUMP_COST | bigint(20) | NO | ダンプに費やした時間 |
| DUMP_TIME | timestamp(6) | NO | ダンプの時点 |
| DUMP_FD | bigint(20) | NO | ダンプファイルのFD |
