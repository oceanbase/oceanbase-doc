# V$OB_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.5バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`V$OB_RES_MGR_SYSSTAT`は、すべてのテナント配下の現在のOBServerにおけるリソースグループの統計項目情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| CON_ID     | bigint(20)  | NO   | テナントID     |
| GROUP_ID   | bigint(20)  | NO   | 所属リソースグループID     |
| SVR_IP     | varchar(46) | NO   | ノードIP     |
| SVR_PORT   | bigint(20)  | NO   | ノードPORT    |
| STATISTIC# | bigint(20)  | NO   | 統計項目番号     |
| NAME       | varchar(64) | NO   | 統計項目名    |
| CLASS      | bigint(20)  | NO   | 統計項目カテゴリ     |
| VALUE      | bigint(20)  | NO   | 統計項目値     |
| VALUE_TYPE | varchar(16) | NO   | 値の種類：累積型、代入型     |
| STAT_ID    | bigint(20)  | NO   | 統計項目ID     |

## クエリ例

すべてのテナント配下の現在のOBServerにおけるリソースグループの統計項目情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_RES_MGR_SYSSTAT LIMIT 10;
```
