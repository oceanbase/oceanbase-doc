# V$OB_PLAN_CACHE_PLAN_STAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョン以降、ビュー名がV$PLAN_CACHE_PLAN_STATからV$OB_PLAN_CACHE_PLAN_STATに変更されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上の計画キャッシュにキャッシュされている各キャッシュオブジェクトの状態を表示します。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>このビューはSQL計画オブジェクトだけでなく、PLオブジェクト（匿名ブロック、PLパッケージ、PL関数など）もキャッシュしており、一部のフィールドは特定のオブジェクトに対してのみ有効です。</p>
  </main>
