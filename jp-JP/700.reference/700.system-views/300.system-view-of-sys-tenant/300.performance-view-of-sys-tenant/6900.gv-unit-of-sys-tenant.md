# GV$UNIT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系ではリソース管理機能のアーキテクチャが最適化されたため、このビューはV4.x系には適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ビュー<a href="../200.dictionary-view-of-sys-tenant/22900.o-dba_ob_units-of-sys-tenant.md">DBA_OB_UNITS</a>および<a href="4000.gv-ob_units-of-sys-tenant.md">GV$OB_UNITS</a>を使用して、クラスタ内のOBServerノードのUnit情報を照会できます。</li>
</ul>
</ul>
</main>

## 機能の概要

ビュー`GV$UNIT`は、クラスタ内のすべてのユニットのメタ情報を表示するために使用されます。

## フィールドの説明

|       **フィールド名**        |    **タイプ**    | **NULLを許容するか** |         **説明**         |
|-----------------------|--------------|----------------|------------------------|
| unit_id               | bigint(20)   | NO             | ユニットID                  |
| unit_config_id        | bigint(20)   | NO             | ユニット構成ID                |
| unit_config_name      | varchar(128) | NO             | ユニット構成名                  |
| resource_pool_id      | bigint(20)   | NO             | リソースプールID                 |
| resource_pool_name    | varchar(128) | NO             | リソースプール名                   |
| zone                  | varchar(128) | NO             | 所属Zone                |
| tenant_id             | bigint(20)   | NO             | テナントID                  |
| tenant_name           | varchar(128) | NO             | テナント名                   |
| svr_ip                | varchar(32)  | NO             | IPアドレス                  |

| migrate_from_svr_port | bigint(20)   | NO             | Unitの移行元Serverのポート番号 |
| max_cpu               | double       | NO             | 最大仮想CPUコア数            |
