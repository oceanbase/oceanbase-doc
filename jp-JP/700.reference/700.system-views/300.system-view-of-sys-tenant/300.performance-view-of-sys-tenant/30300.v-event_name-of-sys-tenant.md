# V$EVENT_NAME

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

すべての待機イベントに関する定義を表示します。

## フィールドの説明

|   **フィールド名**    |   **型**    | **NULL許容** |    **説明**    |
|---------------|-------------|----------------|--------------|
| CON_ID        | bigint(20)  | NO             | テナントID       |
| EVENT_ID      | bigint(20)  | NO             | 待機イベントID     |
| EVENT#        | bigint(20)  | NO             | 待機イベントのインデックス      |
| NAME          | varchar(64) | NO             | 待機イベント名      |
| DISPLAY_NAME  | varchar(64) | NO             | 待機イベントのエイリアス      |
| PARAMETER1    | varchar(64) | NO             | 待機イベントのパラメータ1    |
| PARAMETER2    | varchar(64) | NO             | 待機イベントのパラメータ2    |
| PARAMETER3    | varchar(64) | NO             | 待機イベントのパラメータ3    |
| WAIT_CLASS_ID | bigint(20)  | NO             | 待機イベントが属するクラスID |
| WAIT_CALSS#   | bigint(20)  | NO             | 待機イベントが属するクラスのインデックス  |
| WAIT_CLASS    | varchar(64) | NO             | 待機イベントが属するクラス名  |
