# V$OB_TENANT_MEMORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上の各テナントのメモリ使用状況を表示します。

## フィールドの説明

|   フィールド名    |     型      | NULL許容   |    説明     |
|-----------|-------------|------------|-----------|
| TENANT_ID | bigint(20)  | NO         | テナントID     |
| SVR_IP    | varchar(46) | NO         | サーバーIPアドレス |
| SVR_PORT  | bigint(20)  | NO         | サーバーポート番号    |
| HOLD      | bigint(20)  | NO         | テナント使用済みメモリ、単位：バイト   |
| FREE      | bigint(21)  | NO         | テナント空きメモリ、単位：バイト    |

## クエリ例

システムテナントが、現在のノード上でテナントIDが1002のテナントのメモリ使用状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_MEMORY WHERE TENANT_ID = 1002;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+-----------+------------+
| TENANT_ID | SVR_IP         | SVR_PORT | HOLD      | FREE       |
+-----------+----------------+----------+-----------+------------+
|      1002 | 172.xx.xxx.xxx |     2882 | 723124224 | 4645584896 |
+-----------+----------------+----------+-----------+------------+
1 row in set
```
