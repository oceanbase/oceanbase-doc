# GV$OB_PARAMETERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_PARAMETERS`は、テナントが存在するすべてのOBServerノード上の構成パラメータ情報を表示するために使用されます。

## フィールドの説明

|    フィールド名    |       タイプ       | NULLを許容するか |                                説明                                 |
|------------|----------------|------------|---------------------------------------------------------------------------------------------------|
| SVR_IP     | varchar(46)    | NO         | サーバーのIPアドレス                                                         |
| SVR_PORT   | bigint(20)     | NO         | サーバーのポート番号                                                            |
| ZONE       | varchar(128)   | NO         | ZONE名                                                             |
| SCOPE      | varchar(64)    | NO         | <ul><li>`CLUSTER`クラスタレベルの構成パラメータ   </li><li> `TENANT`テナントレベルの構成パラメータ </li></ul>  |
| TENANT_ID  | bigint(20)     | YES        | テナントID：<ul><li> `NULL`どのテナントにも属さない </li><li>有効な値：テナントID</li></ul>   |
| NAME       | varchar(128)   | NO         | パラメータ名                                                             |
| DATA_TYPE  | varchar(128)   | YES        | パラメータ値のタイプ                                                            |
| VALUE      | varchar(65536) | NO         | パラメータ値                                                              |
| INFO       | varchar(4096)  | NO         | パラメータの説明                                                             |
| SECTION    | varchar(128)   | NO         | パラメータが属するモジュール                                                          |
| EDIT_LEVEL | varchar(128)   | NO         | パラメータ変更の有効化方法：<ul><li>`READONLY`：読み取り専用、変更不可   </li><li> `STATIC_EFFECTIVE`：変更後は再起動が必要 </li><li> `DYNAMIC_EFFECTIVE`：変更後は動的に有効化 </li></ul>   |
| DEFAULT_VALUE | varchar(65536) | NO   | パラメータのデフォルト値<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.2バージョンから導入されました。</p></main>      |
| ISDEFAULT     | varchar(3)     | NO   | 現在の値がデフォルト値であるか：<ul><li>NO：現在の値がデフォルト値ではないことを示します</li><li>YES：現在の値がデフォルト値であることを示します</li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.2バージョンから導入されました。</p></main>     |

## クエリ例

すべてのOBServerノード上の構成パラメータ情報を照会し、2番目のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PARAMETERS limit 2;
```
