# GV$OB_PS_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのすべてのOBServerノード上のPSキャッシュの全体的な状態を監視します。ヒット率、メモリ使用量、キャッシュされたアイテム数が含まれます。

## フィールド説明

|     フィールド名     |     型      | NULL許容 |         説明          |
|--------------|-------------|------------|---------------------|
| TENANT_ID    | bigint(20)  | NO         | テナントID               |
| SVR_IP       | varchar(46) | NO         | サーバーIPアドレス           |
| SVR_PORT     | bigint(20)  | NO         | サーバーポート番号              |
| STMT_COUNT   | bigint(20)  | NO         | PSキャッシュに現在キャッシュされているステートメント数 |
| HIT_COUNT    | bigint(20)  | NO         | PSキャッシュの総ヒット回数     |
| ACCESS_COUNT | bigint(20)  | NO         | PSキャッシュへのアクセス総回数    |
| MEM_HOLD     | bigint(20)  | NO         | PSキャッシュが使用するメモリ    |

## クエリ例

システムテナントで、すべてのテナントのすべてのノード上のPSキャッシュの全体的な状態を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PS_STAT;
```
