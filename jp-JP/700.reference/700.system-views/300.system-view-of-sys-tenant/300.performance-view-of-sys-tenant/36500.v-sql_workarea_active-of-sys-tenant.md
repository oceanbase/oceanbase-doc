# V$SQL_WORKAREA_ACTIVE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上でアクティブなOperatorのワークエリア情報を表示します。

## フィールドの説明

|     **フィールド名**     |    **タイプ**    | **NULL値を許容するか** |                       **説明**                       |
|------------------|--------------|----------------|------------------------------------------------------------------------------------|
| SQL_HASH_VALUE   | bigint(0)    | NO             | 実行されたステートメントのハッシュ値。現在この値はNULLです                         |
| SQL_ID           | varchar(32)  | NO             | SQLステートメントのSQL一意識別子                                |
| SQL_EXEC_START   | date         | NO             | SQL実行開始時間                                       |
| SQL_EXEC_ID      | bigint(20)   | NO             | SQL実行の一意識別子                                        |
| WORKAREA_ADDRESS | varbinary(8) | NO             | Workareaのアドレス                                      |
| OPERATION_TYPE   | varchar(40)  | NO             | Workareaの演算子タイプ。例：Sort、Hash Join、Group byなど     |
| OPERATION_ID     | bigint(20)   | NO             | プランツリー内で演算子を識別する一意識別子                                  |
| POLICY           | varchar(6)   | NO             | Workareaのポリシー：<ul><li>MANUAL</li><li> AUTO </li></ul>   |
| SID              | bigint(20)   | NO             | セッションの一意識別子                                     |
| QCINST_ID        | bigint(0)    | NO             | クエリコーディネータのインスタンスID                                       |
| QCSID            | bigint(0)    | NO             | クエリコーディネータセッション識別子ID                              |
| ACTIVE_TIME      | bigint(20)   | NO             | Workareaがアクティブな平均時間。単位はミリ秒                            |
| WORK_AREA_SIZE   | bigint(20)   | NO             | 演算子がWorkareaを使用する最大値。単位はバイト       |
| EXPECT_SIZE      | bigint(20)   | NO             | Workareaの期待サイズ。単位はバイト                          |
| ACTUAL_MEM_USED  | bigint(20)   | NO             | Workareaに申請したメモリ量。単位はバイト                       |
| MAX_MEM_USED     | bigint(20)   | NO             | Workareaで使用する最大メモリ使用量。単位はバイト                   |
| NUMBER_PASSES    | bigint(20)   | NO             | Workareaがどのモードで実行されているか：<ul><li>0：optimalモードを示す</li><li> 1：one passモードを示す   </li><li> ≥2：multi passモードを示す </li></ul>   |
| TEMPSEG_SIZE     | bigint(20)   | NO             | Workareaが使用する一時領域サイズ、単位：バイト。NULLの場合、一時ファイルへの書き込みは発生していないことを示します |
| TABLESPACE       | varchar(20)  | NO             | 一時ファイルを書き込むテーブルのネームスペース。NULLの場合、一時ファイルへの書き込みは発生していないことを示します                  |
| SEGRFNO#         | bigint(0)    | NO             | 一時ファイル関連のファイル数。NULLは一時ファイルへの書き込みが発生していないことを示します                    |
| SEGBLK#          | bigint(0)    | NO             | Workareaが作成した一時ファイルのブロック数。NULLは一時ファイルへの書き込みが発生していないことを示します      |
| CON_ID           | bigint(20)   | NO             | テナントID  |
| SVR_IP                 | varchar(46)   | NO             | サーバーIPアドレス                   |
| SVR_PORT                 | bigint(20)   | NO             | サーバーのポート番号                   |
