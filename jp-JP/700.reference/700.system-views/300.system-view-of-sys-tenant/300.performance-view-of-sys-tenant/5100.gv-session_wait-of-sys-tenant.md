# GV$SESSION_WAIT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントにおけるすべてのOBServerノード上での全セッションについて、現在または前回の待機イベントの詳細情報を表示します。これには、待機イベント名や待機時間などが含まれます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| SID | bigint(20) | NO | セッションID |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| EVENT | varchar(64) | NO | 待機中のイベント名 |
| P1TEXT | varchar(64) | NO | 待機中のイベントの最初のパラメータの説明 |
| P1 | bigint(20) unsigned | NO | 待機中のイベントの最初のパラメータの値 |
| P2TEXT | varchar(64) | NO | 待機中のイベントの2番目のパラメータの説明 |
| P2 | bigint(20) unsigned | NO | 待機中のイベントの2番目のパラメータの値 |
| P3TEXT | varchar(64) | NO | 待機中のイベントの3番目のパラメータの説明 |
| P3 | bigint(20) unsigned | NO | 待機中のイベントの3番目のパラメータの値 |
| WAIT_CLASS_ID | bigint(20) | NO | 待機中のイベントのカテゴリID |
| WAIT_CLASS# | bigint(20) | NO | 待機中のイベントのカテゴリ番号 |
| WAIT_CLASS | varchar(64) | NO | 待機中のイベントのカテゴリ名 |
| STATE | varchar(19) | NO | 現在の待機中のイベントの状態。以下の4つの状態が含まれます：<ul><li>>Waiting：セッションがこのイベントを待機中</li><li>Waited unknown time：timed_statistics値がfalseに設定されているため、時間情報を取得できません。待機は発生しましたが、時間は非常に短いことを示します</li><li>Wait short time：待機が発生しましたが、時間が非常に短く、1単位を超えないため、記録されていません</li><li>Waited known time：セッションが待機して必要なリソースを取得した場合、waitingからこの状態に移行します</li></ul> |
| WAIT_TIME_MICRO | bigint(20) | NO | 待機時間（マイクロ秒単位）。現在待機中の場合、既に待機している時間を示します。現在待機していない場合、最後の待機の合計待機時間を示します |
| TIME_REMAINING_MICRO | bigint(20) | NO | <ul><li>> 0：最後の待機時間（単位：マイクロ秒）、現在待機状態ではありません</li><li>0：セッションが現在のイベントを待機中</li><li>-1：最後の待機時間が1統計単位未満、現在待機状態ではありません</li><li>-2：時間統計状態が利用可能に設定されていない、現在待機状態ではありません</li></ul> |
| TIME_SINCE_LAST_WAIT_MICRO | bigint(20) | NO | 前回の待機終了から現在までの時間（マイクロ秒単位）。現在待機中の場合、その値は0です |

## クエリ例

システムテナント内で、すべてのテナントにおけるすべてのOBServerノード上のすべてのセッションに対する現在または前回の待機イベントの詳細情報を確認し、上位2件の情報を表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSION_WAIT LIMIT 2\G
```
