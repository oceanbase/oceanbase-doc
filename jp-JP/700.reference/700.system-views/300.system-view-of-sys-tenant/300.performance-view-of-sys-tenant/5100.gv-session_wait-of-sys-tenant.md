# GV$SESSION_WAIT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$SESSION_WAIT`は、すべてのノード上のすべてのセッションにおける現在または前回の待機イベントの情報を表示します。これには、待機イベント名や待機時間などが含まれます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | V4.3.x系では：<ul><li> V4.3.5 BP2以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.3.5 BP2以降のバージョン：<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはクライアントセッションIDを表します。 </ li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>  |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート |
| EVENT | varchar(64) | NO | 待機イベント名 |
| P1TEXT | varchar(64) | NO | 待機イベントの最初のパラメータの説明 |
| P1 | bigint(20) unsigned | NO | 待機イベントの最初のパラメータの値 |
| P2TEXT | varchar(64) | NO | 待機イベントの2番目のパラメータの説明 |
| P2 | bigint(20) unsigned | NO | 待機イベントの2番目のパラメータの値 |
| P3TEXT | varchar(64) | NO | 待機イベントの3番目のパラメータの説明 |
| P3 | bigint(20) unsigned | NO | 待機イベントの3番目のパラメータの値 |
| WAIT_CLASS_ID | bigint(20) | NO | 待機イベントのカテゴリID |
| WAIT_CLASS# | bigint(20) | NO | 待機イベントのカテゴリ番号 |
| WAIT_CLASS | varchar(64) | NO | 待機イベントのカテゴリ名 |
| STATE | varchar(19) | NO | 現在の待機イベントの状態。4つの状態が含まれます：<ul><li>Waiting：セッションがこのイベントを待機中</li><li>Waited unknown time：timed_statisticsの値がfalseに設定されているため、時間情報を取得できません。待機は発生しましたが、時間は非常に短かったことを示します</li><li>Wait short time：待機が発生しましたが、時間が1単位を超えないほど非常に短かったため、記録されませんでした</li><li>Waited known time：セッションが待機して必要なリソースを取得した場合、waiting状態からこの状態に移行します</li></ul> |
| WAIT_TIME_MICRO | bigint(20) | NO | 待機時間。単位はマイクロ秒です。現在待機中の場合、既に待機している時間を表します。現在待機していない場合、最後の待機の合計待機時間を表します |
| TIME_REMAINING_MICRO | bigint(20) | NO |<ul><li>> 0：最後の待機時間（単位：マイクロ秒）、現在待機状態ではありません</li><li>0：セッションが現在のイベントを待機中</li><li>-1：最後の待機時間が1統計単位未満、現在待機状態ではありません</li><li>-2：時間統計状態が利用可能に設定されていない、現在待機状態ではありません</li></ul> |
| TIME_SINCE_LAST_WAIT_MICRO | bigint(20) | NO | 前回の待機終了から現在までの時間。単位はマイクロ秒です。現在待機中の場合、その値は0です |

## クエリ例

すべてのノード上のすべてのセッションの現在または前回の待機イベントの情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SESSION_WAIT LIMIT 1\G
```
