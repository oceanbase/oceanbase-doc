# V$OB_SERVERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このOBServerノードの情報を表示します。

## フィールドの説明

|          フィールド名           |      タイプ      | NULLを許容するか |              説明              |
|-------------------------|--------------|------------|--------------------------------------------------------------|
| SVR_IP                  | varchar(46)  | NO         | サーバーのIPアドレス                    |
| SVR_PORT                | bigint(20)   | NO         | サーバーのポート番号                       |
| ZONE                    | varchar(128) | NO         | Zone名                      |
| SQL_PORT                | bigint(20)   | NO         | SQLポート                       |
| CPU_CAPACITY            | bigint(20)   | NO         | ノードのCPU総容量        |
| CPU_CAPACITY_MAX        | double       | NO         | ノードのCPU総容量のオーバーコミット値。これは`resource_hard_limit`構成パラメータによって制御されます：`CPU_CAPACITY_MAX =  CPU_CAPACITY * resource_hard_limit`                                                                   |
| CPU_ASSIGNED            | double       | NO         | OBServerノードに割り当てられたCPU数。これはOBServerノード上のすべてのUnitの`MIN_CPU`仕様の合計です。以下の制約があります：`CPU_ASSIGNED <= CPU_CAPACITY`                |
| CPU_ASSIGNED_MAX        | double       | NO         | OBServerノードに割り当てられたCPUの上限値。これはOBServerノード上のすべてのUnitの`MAX_CPU`仕様の合計です。以下の制約があります：`CPU_ASSIGNED_MAX <= CPU_CAPACITY_MAX`       |
| MEM_CAPACITY            | bigint(20)   | NO         |  OBServerノードでテナントに割り当て可能な総メモリサイズ。値は`memory_limit - system_memory`、単位はバイトです  |
| MEM_ASSIGNED            | bigint(20)   | NO         | OBServerノードに割り当てられたメモリサイズ。これはOBServerノード上のすべてのUnitの`MEMORY_SIZE`仕様の合計で、単位はバイトです。以下の制約があります：`MEM_ASSIGNED <= MEM_CAPACITY`                 |
| LOG_DISK_CAPACITY      | bigint(20)   | NO         | ログディスク容量の合計サイズ、単位はバイト                       |
| LOG_DISK_ASSIGNED      | bigint(20)   | NO         | ログディスクの割り当て済みサイズ。これはOBServerノード上のすべてのUnitの`LOG_DISK_SIZE`仕様の合計で、単位はバイトです          |
| LOG_DISK_IN_USE      | bigint(20)   | NO         | ログディスクの使用済みサイズ、単位はバイト                                                                               |
| DATA_DISK_CAPACITY      | bigint(20)   | NO         | データディスク容量の合計サイズ、単位はバイト                       |
| DATA_DISK_IN_USE        | bigint(20)   | NO         | データディスクの使用済みサイズ、単位はバイト                       |
| DATA_DISK_health_STATUS | varchar(20)  | NO         | データディスクのヘルス状態：<ul><li>`NORMAL`：正常な状態   </li><li>`WARNING`：異常が存在   </li><li>`ERROR`：エラーが存在 </li></ul>   |
| MEMORY_LIMIT            | bigint(20)   | NO         | OBServerノードで利用可能な総メモリサイズ、単位はバイト    |
| DATA_DISK_ALLOCATED     | bigint(20)   | NO         | OBServerが割り当てたデータディスクサイズ、単位はバイト<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>    |
| DATA_DISK_ABNORMAL_TIME | timestamp(6) | NO         | データディスクの前回の異常（`WARNING`および`ERROR`状態）の時間  |
| SSL_CERT_EXPIRED_TIME   | timestamp(6) | NO |現在のOBServerノードでSSLが有効になっている場合、現在のOBServerが使用しているSSL証書の有効期限とUTC時間をマイクロ秒単位で記録します |
