# GV$UNIT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系ではリソース管理機能のアーキテクチャが最適化されたため、このビューはV4.x系では適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ビュー<a href="../200.dictionary-view-of-sys-tenant/23900.o-dba_ob_units-of-sys-tenant.md">DBA_OB_UNITS</a>および<a href="4800.gv-ob_units-of-sys-tenant.md">GV$OB_UNITS</a>を使用して、クラスタ内のOBServerノードのUnit情報を照会できます。</li>
</ul>
</ul>
</main>

## 機能の概要

ビュー`GV$UNIT`は、クラスタ内のすべてのUnitのメタ情報を表示するために使用されます。

## フィールドの説明

|       **フィールド名**        |    **型**    | **NULL許容** |         **説明**         |
|-----------------------|--------------|----------------|------------------------|
| unit_id               | bigint(20)   | NO             | Unit ID                  |
| unit_config_id        | bigint(20)   | NO             | Unit構成ID                |
| unit_config_name      | varchar(128) | NO             | Unit構成名                  |
| resource_pool_id      | bigint(20)   | NO             | リソースプールID                 |
| resource_pool_name    | varchar(128) | NO             | リソースプール名                   |
| zone                  | varchar(128) | NO             | 所属Zone                |
| tenant_id             | bigint(20)   | NO             | テナントID                  |
| tenant_name           | varchar(128) | NO             | テナント名                   |
| svr_ip                | varchar(32)  | NO             | IPアドレス                  |
| svr_port              | bigint(20)   | NO             | ポート番号                     |
| migrate_from_svr_ip   | varchar(32)  | NO             | Unitの移行元サーバーのIP |
| migrate_from_svr_port | bigint(20)   | NO             | Unitの移行元サーバーのポート番号 |
| max_cpu               | double       | NO             | 最大仮想CPUコア数            |
| min_cpu               | double       | NO             | 最小仮想CPUコア数            |
| max_memory            | bigint(20)   | NO             | 最大メモリ使用量、単位はバイト     |
| min_memory            | bigint(20)   | NO             | 最小メモリ使用量、単位はバイト     |
| max_iops              | bigint(20)   | NO             | 最大IOPS                |
| min_iops              | bigint(20)   | NO             | 最小IOPS                |
| max_disk_size         | bigint(20)   | NO             | 最大ディスク使用量、単位はバイト    |
| max_session_num       | bigint(20)   | NO             | 最大セッション数          |
