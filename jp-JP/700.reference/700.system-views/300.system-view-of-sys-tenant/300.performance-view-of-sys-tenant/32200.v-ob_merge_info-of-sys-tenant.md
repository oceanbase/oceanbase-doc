# V$OB_MERGE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>V$MERGE_INFO</code> は V4.0.0 以降、<code>V$OB_MERGE_INFO</code> に名前が変更されました。V4.0.0 以降のバージョンでは、新しいビュー名 <code>V$OB_MERGE_INFO</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>V$MERGE_INFO</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

OceanBase クラスタで完了したCompactionに関連する統計情報を表示します。

## フィールドの説明

|       フィールド名        |      型       | NULL許容 |                                 説明                                  |
|-------------------|---------------|------------|-----------------------------------------------------------------------------------------------------|
| SVR_IP            | varchar(46)   | NO         | サーバーのIPアドレス                                                           |
| SVR_PORT          | bigint(20)    | NO         | サーバーのポート番号                                                              |
| TENANT_ID         | bigint(20)    | NO         | テナントID                                                               |
| LS_ID             | bigint(20)    | NO         | ログストリームID                                                              |
| TABLET_ID         | bigint(20)    | NO         | データシャーディングID                                                             |
| ACTION            | varchar(64)   | NO         | Compactionの具体的な動作：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：Mini Compaction。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：Minor Compaction。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータや未コミットトランザクションデータは含まれません。</li></ul>     |
| COMPACTION_SCN    | bigint(20) unsigned    | NO         | Compactionのバージョン番号                                                      |
| START_TIME        | timestamp(6)  | NO         | Compaction開始時間                                                     |
| END_TIME          | timestamp(6)  | NO         | Compaction終了時間                                                     |
| MACRO_BLOCK_COUNT | bigint(20)    | NO         | Compactionのマクロブロック総数                                                     |
| REUSE_PCT         | decimal(26,2) | NO         | Compactionのマクロブロック再利用率                                                    |
| PARALLEL_DEGREE   | bigint(20)    | NO         | Compactionの並列度                                                      |

## クエリ例

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_MERGE_INFO WHERE ACTION='MINI_MERGE' LIMIT 5;
```
