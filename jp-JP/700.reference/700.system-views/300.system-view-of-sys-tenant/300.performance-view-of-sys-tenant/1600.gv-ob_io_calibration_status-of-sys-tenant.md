# GV$OB_IO_CALIBRATION_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上で実行されているI/Oキャリブレーションタスクの状態を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| STORAGE_NAME | varchar(1024) | NO | ストレージ名。例：DATA、REDO |
| STATUS | varchar(256) | NO | I/Oキャリブレーションのステータス。<ul><li>NOT AVAILABLE</li><li>IN PROGRESS</li><li>READY </li></ul> |
| START_TIME | timestamp(6) | NO | 前回のI/Oキャリブレーション開始時間 |
| FINISH_TIME | timestamp(6) | NO | 前回のI/Oキャリブレーション終了時間 |

## クエリ例

すべてのノード上で実行されているI/Oキャリブレーションタスクの状態を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_IO_CALIBRATION_STATUS;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+--------------+--------+----------------------------+----------------------------+

| 172.xx.xxx.xxx |     2882 | DATA         | READY  | 2025-01-02 10:20:23.299880 | 2025-01-02 10:22:03.590106 |
| 172.xx.xxx.xxx |     2882 | DATA         | READY  | 2025-01-02 10:20:23.300319 | 2025-01-02 10:22:03.589117 |
+----------------+----------+--------------+--------+----------------------------+----------------------------+
3 rows in set
```
