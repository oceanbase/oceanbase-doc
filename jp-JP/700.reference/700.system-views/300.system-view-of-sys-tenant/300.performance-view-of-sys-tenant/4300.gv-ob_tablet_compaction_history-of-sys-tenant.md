# GV$OB_TABLET_COMPACTION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_TABLET_COMPACTION_HISTORY` は、TabletレベルのCompactionの履歴情報を表示するために使用されます。

## フィールド説明

|                 フィールド名  |      型   | **NULL許容** |     説明     |
|--------------------------------------|--------------|----------------|--------|
|SVR_IP    |varchar(46)    |NO   |サーバーIPアドレス    |
|SVR_PORT    |bigint(20)    |NO   |サーバーポート番号    |
|TENANT_ID    |bigint(20)    |NO   |テナントID    |
|LS_ID    |bigint(20)    |NO   |ログストリームID    |
|TABLET_ID    |bigint(20)    |NO   |データシャーディングID    |
|TYPE    |varchar(64)    |NO   | Compactionのタイプ：<ul><li>`MDS_TABLE_MERGE`：システムのメタデータをSSTable形式でディスクに永続化します。</li> <li>`MAJOR_MERGE`：テナントレベルのメジャーコンパクション</li> <li>`MEDIUM_MERGE`：パーティションレベルのメジャーコンパクション</li> <li>`MINI_MERGE`：ミニコンパクション。MemTableをMini SSTableに変換します。</li> <li>`MINOR_MERGE`：マイナーコンパクション。複数のMini SSTableを新しいMini SSTableに合成するか、複数のMini SSTableと1つのMinor SSTableを新しいMinor SSTableに合成します。</li> <li>`META_MAJOR_MERGE`：特殊なCompactionタイプです。指定された時点以前のデータをMeta Major SSTableに合成します。そのデータ形式はMajor SSTableと同じで、マルチバージョンデータや未コミットトランザクションデータは含まれません。</li></ul>   |
|COMPACTION_SCN    |bigint(20) unsigned    |NO   |メジャーコンパクションのバージョン情報    |
|START_TIME    |timestamp(6)    |NO   |開始時間    |
|FINISH_TIME    |timestamp(6)    |NO   |終了時間    |
|TASK_ID    |varchar(64)    |NO   |タスク実行のトレース    |
|OCCUPY_SIZE    |bigint(20)    |NO   |データ量    |
|MACRO_BLOCK_COUNT    |bigint(20)    |NO   |マクロブロック数    |

|NEW_MICRO_COUNT_IN_NEW_MACRO    |bigint(20)    |NO   |新規生成マクロブロック内の新規マイクロブロック数    |
|MULTIPLEXED_MICRO_COUNT_IN_NEW_MACRO    |bigint(20)    |NO   |新規生成マクロブロック内の再利用マイクロブロック数    |
|TOTAL_ROW_COUNT    |bigint(20)    |NO   |総行数    |
|INCREMENTAL_ROW_COUNT    |bigint(20)    |NO   |新規出力行数    |
|COMPRESSION_RATIO    |double    |NO   |新規データの圧縮率 = 圧縮後の新規マクロブロックデータ量 / 圧縮前データ量    |
|NEW_FLUSH_DATA_RATE    |bigint(20)    |NO   |新規データの出力速度、単位KB/s    |
|PROGRESSIVE_COMPACTION_round    |bigint(20)    |NO   |漸近メジャーコンパクションの現在ラウンド（フルコンパクションの場合、この列は-1）    |
|PROGRESSIVE_COMPACTION_NUM    |bigint(20)    |NO   |漸近メジャーコンパクションの総ラウンド数    |
|PARALLEL_DEGREE    |bigint(20)    |NO   |並列度    |
|PARALLEL_INFO    |varchar(512)    |NO   |並列タスク情報。並列タスクがスキャンしたデータ量/実行時間/出力データ量の統計情報（min/max/avg）を表示します    |
|PARTICIPANT_TABLE    |varchar(512)    |NO   |今回のコンパクションに参加するテーブル情報    |
|MACRO_ID_LIST    |varchar(256)    |NO   |出力されるマクロブロックリストです。マクロブロックリストが長すぎる場合は表示されません    |
|COMMENTS    |varchar(256)    |NO   |失敗したコンパクションの履歴情報や、今回のコンパクションの収集時間などを記録します    |
| START_CG_ID                     | bigint(20)   | NO   |  Column Group の Start ID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| END_CG_ID                       | bigint(20)   | NO   |  Column Group の End ID <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>   |
| KEPT_SNAPSHOT                   | varchar(128) | NO   |  今回のCompactionで選択されたマルチバージョンスナップショットの保持情報を表示します<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| MERGE_LEVEL                     | varchar(64)  | NO   |  実行時にメジャーコンパクション/マイクロブロックの再利用を使用しているかどうかを表示します<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.0バージョンから導入されました。</p></main>    |
| EXEC_MODE                       | varchar(64)  | NO   | このメジャーコンパクショントレースのモードを表示します：<ul><li>`EXEC_MODE_LOCAL`：ローカルモード。マクロブロックをローカルディスクに出力します</li> <li>`EXEC_MODE_VALIDATE`：共有モード。チェックサムを計算するだけで、マクロブロックは出力しません。現在のバージョンではこのモードはサポートされていません。</li> <li>`EXEC_MODE_OUTPUT`：共有モード。マクロブロックを共有ストレージに出力します。現在のバージョンではこのモードはサポートされていません。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| IS_FULL_MERGE                   | varchar(5)   | NO   | フルコンパクションかどうか。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| IO_COST_TIME_PERCENTAGE         | bigint(20)   | NO   | IO時間がメジャーコンパクション時間に占める割合。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| MERGE_reason                    | varchar(32)  | NO   | メジャーコンパクションの発生原因。<ul><li>`LOAD_DATA_SCENE`：データロードシナリオ</li> <li>`TOMBSTONE_SCENE`：タンブルストーンシナリオ</li> <li>`INEFFICIENT_QUERY`：スロークエリシナリオ</li> <li>`FREQUENT_WRITE`：頻繁な書き込みシナリオ</li> <li>`TENANT_MAJOR`：テナントレベルのメジャーコンパクション</li> <li>`USER_REQUEST`：ユーザーが発行したメジャーコンパクション</li> <li>`REBUILD_COLUMN_GROUP`：行から列への変換シナリオ</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| BASE_MAJOR_STATUS               | varchar(64)  | NO   | メジャーコンパクション前のMajor SSTableのタイプ。<ul><li>`COL_WITH_ALL`：定義時に行と列のハイブリッドテーブルで、ベースラインデータも行と列のハイブリッド形式</li> <li>`COL_ONLY_ALL`：定義時に行と列のハイブリッドテーブルで、ベースラインデータは自動最適化により行ストアのみに保存</li> <li>`PURE_COL`：定義時に純粋なカラムストアテーブルで、ベースラインデータも純粋なカラムストア形式</li> <li>`PURE_COL_ONLY_ALL`：定義時に純粋なカラムストアテーブルで、ベースラインデータは自動最適化により行ストアのみに保存</li> <li>`ROW_STORE_MAJOR`：行ストアテーブル</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main>|
| CO_MERGE_TYPE                   | varchar(64)  | NO   | カラムストアのメジャーコンパクションタイプ。<ul><li>`BUILD_COLUMN_STORE_MERGE`：メジャーコンパクション後のストレージタイプがカラムストア</li> <li>`BUILD_ROW_STORE_MERGE`：メジャーコンパクション後のストレージタイプが行ストア</li> <li>`USE_RS_BUILD_SCHEMA_MATCH_MERGE`：メジャーコンパクション後のストレージタイプがスキーマに一致する形式</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main> |
| MDS_FILTER_INFO                 | varchar(1024) | NO  | メジャーコンパクションで使用されたMDSフィルター情報 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入され、有効になります。</li><li>V4.3.5系では、このフィールドはV4.3.5バージョンから導入され、V4.3.5 BP2バージョンから有効になります。</li></ul></main> |
| EXECUTE_TIME                    | bigint(20)    | NO | メジャーコンパクションタスクがCPUを消費した時間。単位はミリ秒。  |
