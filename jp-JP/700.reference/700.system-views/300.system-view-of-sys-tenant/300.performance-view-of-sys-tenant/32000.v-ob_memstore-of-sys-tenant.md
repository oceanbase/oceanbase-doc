# V$OB_MEMSTORE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>V$SERVER_MEMSTORE</code> は V4.0.0 以降、<code>V$OB_MEMSTORE</code> に名前が変更されました。V4.0.0 以降のバージョンでは、新しいビュー名 <code>V$OB_MEMSTORE</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>V$SERVER_MEMSTORE</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

現在のノード上のすべてのテナントのMemStore統計情報を表示します。

## フィールドの説明

|    **フィールド名**    |   **型**    | **NULL許容** |              **説明**              |
|----------------|-------------|----------------|----------------------------------|
| SVR_IP         | varchar(46) | NO             | サーバーのIPアドレス                          |
| SVR_PORT       | bigint(20)  | NO             | サーバーポート                            |
| TENANT_ID      | bigint(20)  | NO             | テナントID                            |
| ACTIVE_SPAN    | bigint(20)  | NO             | アクティブなMemTableが占用するメモリの推定値（過大評価される可能性あり）、単位：バイト |
| FREEZE_TRIGGER | bigint(20)  | NO             | MemTableのフリーズをトリガーしたメモリサイズ、単位：バイト        |
| FREEZE_CNT     | bigint(20)  | NO             | MemTableのフリーズ回数                   |
| MEMSTORE_USED  | bigint(20)  | NO             | MemTableが現在使用中のメモリサイズの合計、単位：バイト        |
| MEMSTORE_LIMIT      | bigint(20)  | NO             | MemTableのメモリサイズ制限、単位：バイト           |

## クエリ例

システムテナントが、テナントIDが `1002` のテナントのすべてのサーバー上のMemTableのメモリ使用状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_MEMSTORE WHERE TENANT_ID=1002;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| SVR_IP         | SVR_PORT | TENANT_ID | ACTIVE_SPAN | FREEZE_TRIGGER | FREEZE_CNT | MEMSTORE_USED | MEMSTORE_LIMIT |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| 172.xx.xxx.xxx |     2882 |      1002 |    62914560 |      603982068 |          0 |      62914560 |     2684354550 |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
1 row in set
```
