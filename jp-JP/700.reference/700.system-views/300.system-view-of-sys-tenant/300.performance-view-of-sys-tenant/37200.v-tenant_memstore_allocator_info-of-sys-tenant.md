# v$tenant_memstore_allocator_info

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが最適化されたため、このビューはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ビュー<a href="32000.v-ob_memstore-of-sys-tenant.md">V$OB_MEMSTORE</a>およびビュー<a href="32100.v-ob_memstore_info-of-sys-tenant.md">V$OB_MEMSTORE_INFO</a>を使用してMemTableに関する情報を確認できます。</li></ul>
</main>

## 機能の概要

`v$tenant_memstore_allocator_info`ビューは、接続先のOBServerノード上のMemTableの情報を表示します。主に、テナントのMemStoreメモリが長時間解放されない問題のトラブルシューティングに使用されます。各行は単一のMemTableの情報に対応しています。

## フィールドの説明

|      **フィールド名**   |   **型**  | **NULL許容** |                  **説明**                   |
|---------------------|-------------|----------------|-------------------------------------------------|
| SVR_IP              | varchar(32) | NO             | OBServerのIPアドレス。                         |
| SVR_PORT            | bigint(20)  | NO             | OBServerのポート。                             |
| TENANT_ID           | bigint(20)  | NO             | テナントID。                                    |
| TABLE_ID            | bigint(20)  | NO             | テーブルID。                                     |
| PARTITION_ID        | bigint(20)  | NO             | パーティションID。                                    |
| MT_BASE_VERSION     | bigint(20)  | NO             | このMemTableに対応する開始トランザクションバージョン。                     |
| RETIRE_CLOCK        | bigint(20)  | NO             | このMemTableが属するテナントの現在のMemStoreの割り当て済みメモリの合計、単位はバイトです。      |
| MT_IS_FROZEN        | bigint(20)  | NO             | このMemTableが凍結されているかどうかを示します。                        |
| MT_PROTECTION_CLOCK | bigint(20)  | NO             | このMemTableが初めてメモリを割り当てられたとき、所属テナントのMemStoreの既割り当てメモリ量、単位はバイトです。 |
| MT_SNAPSHOT_VERSION | bigint(20)  | NO             | このMemTableのスナップショットバージョン。                         |
