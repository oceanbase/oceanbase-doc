# GV$OB_PX_TARGET_MONITOR

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントのすべてのOBServerノード上でのPXスレッドの使用状況を表示します。

## フィールドの説明

|             フィールド名             |         タイプ          | NULLを許容するか |    説明     |
|------------------------------|---------------------|------------|-----------|
| SVR_IP                       | varchar(46)         | NO         | ローカルサーバーのIPアドレス |
| SVR_PORT                     | bigint(20)          | NO         | ローカルサーバーのポート番号    |
| TENANT_ID                    | bigint(20)          | NO         | テナントID     |
| IS_LEADER                    | varchar(1)          | NO         | ダミーテーブルのリーダーであるか          |
| VERSION                      | bigint(20) unsigned | NO         | 統計情報の再開始回数          |
| PEER_IP                      | varchar(46)         | NO         | ピアサーバーのIPアドレス          |
| PEER_PORT                    | bigint(20)          | NO         | ピアサーバーのポート番号          |
| PEER_TARGET                  | bigint(20)          | NO         | ピアサーバーのPXスレッド総数          |
| PEER_TARGET_USED             | bigint(20)          | NO         | ピアサーバーのPXスレッド使用数          |
| LOCAL_TARGET_USED            | bigint(20)          | NO         | ローカルサーバーが使用するピアサーバーのPXスレッド数          |
| LOCAL_PARALLEL_SESSION_COUNT | bigint(20)          | NO         | ローカルサーバー上で並行実行中のSESSION数          |

## クエリ例

システムテナントで、すべてのテナントのすべてのOBServerノード上のPXスレッドの使用状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PX_TARGET_MONITOR;
```
