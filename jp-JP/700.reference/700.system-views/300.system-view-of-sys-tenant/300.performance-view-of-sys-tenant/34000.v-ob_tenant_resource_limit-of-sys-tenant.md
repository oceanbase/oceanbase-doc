# V$OB_TENANT_RESOURCE_LIMIT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`V$OB_TENANT_RESOURCE_LIMIT`は、すべてのテナントにおける本OBServer上での論理リソース使用量、上限値、有効な制限条件、およびダウンタイム再起動後の最大使用量を表示するために使用されます。

## フィールドの説明

| フィールド名  |  タイプ  | NULLを許容するか |     説明     |
|----------|--------|-----------------|-------------|
| SVR_IP               | varchar(46)  | NO   |  OBServerのIPアドレス    |
| SVR_PORT             | bigint(20)   | NO   |  OBServerのRPCポート    |
| TENANT_ID            | bigint(20)   | NO   |  テナントID    |
| ZONE                 | varchar(128) | NO   |  ZONEの名前    |
| RESOURCE_NAME        | varchar(128) | NO   |  リソース名    |
| CURRENT_UTILIZATION  | bigint(20)   | NO   |  リソースの現在の使用量    |
| MAX_UTILIZATION      | bigint(20)   | NO   |  マシン起動後のこのリソースの最大使用量    |
| RESERVED_VALUE       | bigint(20)   | NO   |  予約された量。この値は安定した運用にとって最も基本的な保証です    |
| LIMIT_VALUE          | bigint(20)   | NO   |  許可される最大使用量    |
| EFFECTIVE_LIMIT_TYPE | varchar(128) | NO   |  効力を持つ制限タイプ。例：構成パラメータ、メモリ、CPU、ディスクなど    |

## クエリ例

すべてのテナントにおける本OBServer上の論理リソース使用量、上限値、有効な制限条件、およびダウンタイム再起動後の最大使用量を照会します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_RESOURCE_LIMIT;
```
