# GV$OB_TRANSACTION_SCHEDULERS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`GV$OB_TRANSACTION_SCHEDULERS`は、すべてのサーバーのトランザクションスケジューラー情報を照会するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | コピーが存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | コピーが存在するサーバーのポート |
| SESSION_ID | bigint(20) | NO | V4.2.x系について：<ul><li>V4.2.5 BP4以前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li>V4.2.5 BP4以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODP内の構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul> |
| TX_ID | bigint(20) | NO | トランザクションID |
| STATE | varchar(18) | NO | トランザクションの状態 |
| CLUSTER_ID | bigint(20) | NO | クラスターの一意のID |
| COORDINATOR | bigint(20) | NO | コーディネーターが存在するログストリームID |
| PARTICIPANTS | varchar(1024) | YES | トランザクションの参加者情報 |
| ISOLATION_LEVEL | varchar(16) | NO | 分離レベル |
| SNAPSHOT_VERSION | bigint(20) unsigned  | YES | RRまたはSERIAL分離レベルで有効なスナップショットバージョン。無効な場合は-1 |
| ACCESS_MODE | varchar(10) | NO | アクセスモード（読み取り専用または読み書き） |
| TX_OP_SN | bigint(20)  | NO | トランザクションレベルの操作シーケンス番号 |
| ACTIVE_TIME | timestamp(6) | YES | トランザクションが明示的または暗黙的に開始された時間のタイムスタンプ |
| EXPIRE_TIME | timestamp(6) | YES | トランザクションの有効期限のタイムスタンプ |
| CAN_EARLY_LOCK_RELEASE | varchar(7) | NO | 早期ロック解放が可能か |
| FORMATID               | bigint(20)          | NO   | グローバルトランザクションのフォーマット識別子 |
| GLOBALID               | varchar(257)        | YES  | グローバルトランザクションの一意識別子 |
| BRANCHID               | varchar(257)        | YES  | ブランチトランザクションの一意識別子 |
