# gv$tenant_memstore_allocator_info

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが最適化されたため、このビューはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ビュー<a href="1600.gv-ob_memstore-of-sys-tenant.md">GV$OB_MEMSTORE</a>およびビュー<a href="1700.gv-ob_memstore_info-of-sys-tenant.md">GV$OB_MEMSTORE_INFO</a>を使用してMemTableに関する情報を確認できます。</li></ul>
</main>

## 機能の概要

`gv$tenant_memstore_allocator_info` ビューは、接続先のOBServerノード上のMemTableに関する情報を表示します。主に、テナントのMemStoreメモリが長時間解放されない問題のトラブルシューティングに使用されます。各行は単一のMemTableの情報に対応しています。

## フィールド説明

|      **フィールド名**   |   **型**  | **NULL許容** |                  **説明**                 |
|---------------------|-------------|----------------|-----------------------------------------------|
| SVR_IP              | varchar(32) | NO           | OBServerのIPアドレスです。                         |
| SVR_PORT            | bigint(20)  | NO             | OBServerのポート番号です。                             |
| TENANT_ID           | bigint(20)  | NO             | テナントIDです。                                    |
| TABLE_ID            | bigint(20)  | NO             | テーブルIDです。                                     |
| PARTITION_ID        | bigint(20)  | NO             | パーティションIDです。                                    |
| MT_BASE_VERSION     | bigint(20)  | NO             | このMemTableに対応する開始トランザクションバージョンです。                     |
| RETIRE_CLOCK        | bigint(20)  | NO             | このMemTableが属するテナントの現在のMemStoreに割り当てられているメモリの合計サイズです。単位はバイトです。      |
| MT_IS_FROZEN        | bigint(20)  | NO             | このMemTableが凍結されているかどうかを示します。                        |
| MT_PROTECTION_CLOCK | bigint(20)  | NO             | このMemTableに初めてメモリが割り当てられたとき、所属テナントのMemStoreに割り当てられていたメモリ量です。単位はバイトです。 |
| MT_SNAPSHOT_VERSION | bigint(20)  | NO             | このMemTableのスナップショットバージョンです。                         |

## クエリ例

クラスタ内のすべてのテナントのOBServerノード上のMemTable情報を確認し、上位5件のレコードを表示するよう指定します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.gv$tenant_memstore_allocator_info LIMIT 5;
```
