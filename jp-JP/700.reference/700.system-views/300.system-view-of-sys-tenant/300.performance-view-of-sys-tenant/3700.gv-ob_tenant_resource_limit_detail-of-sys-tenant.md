# GV$OB_TENANT_RESOURCE_LIMIT_DETAIL

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`GV$OB_TENANT_RESOURCE_LIMIT_DETAIL`は、すべてのテナントにおけるすべてのOBServer上での論理リソースに課される制限と、各制限の上限値を表示するために使用されます。

## フィールドの説明

| フィールド名  |  タイプ  | NULLを許容するか |     説明     |
|----------|--------|-----------------|-------------|
| SVR_IP               | varchar(46)  | NO   |  OBServerのIPアドレス    |
| SVR_PORT             | bigint(20)   | NO   |  OBServerのRPCポート    |
| TENANT_ID            | bigint(20)   | NO   |  テナントID    |
| RESOURCE_NAME        | varchar(128) | NO   |  リソース名    |
| LIMIT_TYPE           | varchar(128) | NO   |  制限名    |
| LIMIT_VALUE          | bigint(20)   | NO   |  制限値    |

## クエリ例

すべてのテナントにおけるすべてのOBServer上での論理リソースに課される制限と、各制限の上限値を照会し、上位5件のレコードを表示します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_RESOURCE_LIMIT_DETAIL LIMIT 5;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+---------------+---------------+---------------------+
| SVR_IP         | SVR_PORT | TENANT_ID | RESOURCE_NAME | LIMIT_TYPE    | LIMIT_VALUE         |

|   xx.xx.xx.xx  |     2882 |         1 | ls            | configuration |                  90 |
|   xx.xx.xx.xx  |     2882 |         1 | ls            | memstore      | 9223372036854775807 |
|   xx.xx.xx.xx  |     2882 |         1 | ls            | memory        |                  70 |
|   xx.xx.xx.xx  |     2882 |         1 | ls            | data_disk     | 9223372036854775807 |
|   xx.xx.xx.xx  |     2882 |         1 | ls            | clog_disk     |                  32 |
+----------------+----------+-----------+---------------+---------------+---------------------+
5 rows in set
```
