# V$OB_SQL_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上でEXPLAIN PLANを実行して収集した、すべてのテナントのプラン情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | プラン情報が属するテナントID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main> |
| SQL_ID    | varchar(32)         | NO | クエリID |
| DB_ID     | bigint(20)          | NO | クエリが属するスキーマID |
| PLAN_HASH  | bigint(20) unsigned | NO | プランのハッシュ値 |
| PLAN_ID         | bigint(20)          |  | プランID |
| GMT_CREATE   | timestamp(6)        | NO | レコード作成時間 |
| OPERATOR     | varchar(255)        | NO | 演算子名（例：TABLE SCAN、SORT） |
| OBJECT_NODE    | varchar(40)         | NO | 現在の演算子がDBLINK関連の場合、DBLINKの名前を示します |
| OBJECT_ID         | bigint(20)          | NO | スキャンオブジェクトID（例：TABLE SCAN演算子がスキャンする物理テーブルID） |
| OBJECT_OWNER    | varchar(128)        | NO | スキャンオブジェクトが属するユーザー |
| OBJECT_NAME    | varchar(128)        | NO | スキャンオブジェクト名（例：TABLE SCAN演算子がスキャンする物理テーブル名） |
| OBJECT_ALIAS    | varchar(261)        | NO | スキャンオブジェクトのエイリアス（例：TABLE SCAN演算子がスキャンする物理テーブルのエイリアス） |
| OBJECT_TYPE    | varchar(20)         | NO | スキャンオブジェクトタイプ（例：SYNONYM、DBLINK、BASIC TABLE） |
| OPTIMIZER     | varchar(4000)       | NO | インデックス関連情報（例：物理行、論理行、再テーブル行数、使用する統計情報タイプ、統計情報バージョン番号） |
| ID     | bigint(20)          | NO | 論理演算子ID |
| PARENT_ID     | bigint(20)          | NO | 論理演算子の親演算子ID |
| DEPTH     | bigint(20)          | NO | 論理演算子が現在のプランにおける深さ、つまり二分プラン木の何層目にあるか |
| POSITION     | bigint(20)          | NO | 現在の論理演算子が親演算子の何番目の子ノードであるかを示す演算子 |
| COST     | bigint(20)          | NO | 最適化エンジンが見積もったコスト |
| REAL_COST | bigint(20)   | NO | プランが初めて実行されたときの実際のコスト（実行フィードバック情報） |
| CARDINALITY    | bigint(20)          | NO | 最適化エンジンが現在の演算子の出力行数を見積もった値 |
| REAL_CARDINALITY    | bigint(20)          | NO | プランが初めて実行されたときの現在の演算子の実際の出力行数（実行フィードバック情報） |
| IO_COST    | bigint(20)          | NO | プランが初めて実行されたときの現在の演算子の実際のI/Oコスト（実行フィードバック情報） |
| CPU_COST    | bigint(20)          | NO | プランが初めて実行されたときの現在の演算子の実際のCPUコスト（実行フィードバック情報） |
| BYTES     | bigint(20)          | NO | 最適化エンジンが現在の演算子のデータ幅を見積もった値 |
| ROWSET | bigint(20)          | NO | 現在の演算子のベクトル化サイズ |
| OTHER_TAG     | varchar(4000)       | NO | 現在のクエリで使用されたヒント。プランの最初の行にのみ格納されます |
| PARTITION_START  | varchar(4000)       | NO | TABLE SCANでスキャンするパーティション情報 |
| OTHER     | varchar(4000)       | NO | 最適化情報。例：プランタイプ、Fast Parserのパラメータ化情報、Plan Note、プランがヒットした制約情報など |
| ACCESS_PREDICATES | varchar(4000)       | NO | 現在の演算子がアクセスする必要がある式の情報 |
| FILTER_PREDICATES | varchar(4000)       | NO | 現在の演算子のフィルター条件 |
| STARTUP_PREDICATES | varchar(4000)    | NO | 現在の演算子の開始条件 |
| PROJECTION   | varchar(4000)       | NO | 現在の演算子の出力式の情報 |
| SPECIAL_PREDICATES | varchar(4000)   | NO | 現在の演算子の固有の式情報。例：Join Condition、GROUP EXPRS、SORT EXPRSなど |
| QBLOCK_NAME   | varchar(128)       | NO | 現在の演算子が存在するクエリブロックの名前 |
| REMARKS    | varchar(4000)       | NO | qb_nameの変更追跡情報 |
| OTHER_XML    | varchar(4000)         | NO | OUTLINE DATA |
