# V$OB_PS<Item_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$OB_PS_Item_INFO` は、プリペアドステートメントの監視機能を提供し、PSキャッシュ内のすべてのプリペアドステートメントの基本情報を含みます。

## フィールドの説明

|      **フィールド名**       |     型      | **NULL許容** |             説明             |
|---------------------|-------------|----------------|----------------------------|
| TENANT_ID           | bigint(20)  | NO             | テナントID                      |
| SVR_IP              | varchar(46) | NO             | サーバーIPアドレス                  |
| SVR_PORT            | bigint(20)  | NO             | サーバーポート番号                     |
| STMT_ID             | bigint(20)  | NO             | PS Cache内の対応するステートメントのstmt_id情報 |
| DB_ID               | bigint(20)  | NO             | prepareステートメントに関連するデータベースID       |
| PS_SQL              | longtext    | NO             | prepareのSQL情報           |
| PARAM_COUNT         | bigint(20)  | NO             | prepareのパラメータ数情報            |
| STMT_ITEM_REF_COUNT | bigint(20)  | NO             | stmt_itemの参照カウント情報          |
| STMT_INFO_REF_COUNT | bigint(20)  | NO             | stmt_infoの参照カウント情報          |
| MEM_HOLD            | bigint(20)  | NO             | そのprepare stmtが占有するメモリサイズ     |
| STMT_TYPE           | bigint(20)  | NO             | そのprepare stmtのタイプ情報       |
| CHECKSUM            | bigint(20)  | NO             | そのprepare stmtのchecksum  |
| EXPIRED             | tinyint(4)  | NO             | そのprepare stmtが期限切れかどうか                           |
