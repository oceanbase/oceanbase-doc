# V$OB_SSTABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが現在のOBServerノード上の各パーティションにおけるMemTableとSSTableの情報を表示します。

## フィールド説明

|          フィールド名           |         型          | NULL許容 |                                                                                  説明|
|-------------------------|---------------------|------------|---------------------------------|
| SVR_IP                  | varchar(46)         | NO         | サーバーIPアドレス                                                                          |
| SVR_PORT                | bigint(20)          | NO         | サーバーポート番号                                                                             |
| TABLE_TYPE              | varchar(20)         | NO         | テーブルタイプ                                                                                |
| TENANT_ID               | bigint(20)          | NO         | テナントID                                                                              |
| LS_ID                   | bigint(20)          | NO         | ログストリームID                                                                             |
| TABLET_ID               | bigint(20)          | NO         | データシャーディングID                                                                            |
| START_LOG_SCN            | bigint(20) unsigned | NO         | このテーブルのデータのログタイムスタンプ範囲の左境界      |
| END_LOG_SCN              | bigint(20) unsigned | NO         | このテーブルのデータのログタイムスタンプ範囲の右境界       |
| SIZE                    | bigint(20)          | NO         | ディスク使用容量、単位はバイト        |
| REF                     | bigint(20)          | NO         | このテーブルが参照する数、単位は件数     |
| UPPER_TRANS_VERSION     | bigint(20) unsigned         | NO         | コミット済みトランザクションの最大トランザクションバージョン番号                                                       |
| IS_ACTIVE               | varchar(3)          | NO         | アクティブなMemTableかどうか   |
| CONTAIN_UNCOMMITTED_ROW | varchar(3)          | NO         | このテーブルに未コミットのトランザクション行が含まれているかどうか：<ul><li>`NO`：このテーブルに未コミットのトランザクション行が含まれていないことを示します。 </li><li>`YES`：このテーブルに未コミットのトランザクション行が含まれていることを示します。 </li></ul>   |
