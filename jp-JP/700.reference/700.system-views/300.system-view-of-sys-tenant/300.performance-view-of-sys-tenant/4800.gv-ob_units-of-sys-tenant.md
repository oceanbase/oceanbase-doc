# GV$OB_UNITS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントが配置されているOBServerノードのUnit情報を表示します。システムテナントは、クラスタ内のすべてのOBServerノードのUnit情報を確認できます。

## フィールド説明

|       フィールド名       |      型      | NULL許容 |                                                                            説明                                                                             |
|------------------|--------------|------------|-------------------------------------------------------------------------|
| SVR_IP           | varchar(46)  | NO         | サーバーIPアドレス                                                              |
| SVR_PORT         | bigint(20)   | NO         | サーバーポート番号                                                                 |
| UNIT_ID          | bigint(20)   | NO         | Unit ID                                                                |
| TENANT_ID        | bigint(20)   | NO         | Unitが属するテナントID                                                          |
| ZONE             | varchar(128) | NO         | Zone名                                                                |
| ZONE_TYPE | varchar(128) | NO | Unitが配置されているZoneのZoneタイプ。値は以下のとおりです：<ul><li>`NULL`：この列の値が無効であることを示します。OBServerノード再起動時に一時的に無効な値が表示されることがあります。</li> <li>`ReadWrite`：読み書きゾーン</li> <li>`Encryption`：暗号化ゾーン</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REGION | varchar(128) | NO | Unitが配置されているZoneが属するRegion名。設定されていない場合、デフォルトは`default_region`です。値が`NULL`の場合、この列の値が無効であることを示します。OBServerノード再起動時に一時的に無効な値が表示されることがあります。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| MAX_CPU          | double       | NO         | CPUスペックの上限                                                               |
| MIN_CPU          | double       | NO         | CPUスペックの下限                                                               |
| MEMORY_SIZE      | bigint(20)   | NO         | メモリサイズ、単位はバイト                                                           |
| MAX_IOPS         | bigint(20)   | NO         | ディスクIOPSスペックの上限                                                           |
| MIN_IOPS         | bigint(20)   | NO         | ディスクIOPS仕様の下限値                                                           |
| IOPS_WEIGHT      | bigint(20)   | NO         | IOPS重み |
| MAX_NET_BANDWIDTH| bigint(20)   | YES        | Unitの最大ネットワーク帯域幅、単位はバイト  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main> |
| NET_BANDWIDTH_WEIGHT |bigint(20)| YES        | Unitのネットワーク帯域幅の重み値 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>  |
| LOG_DISK_SIZE    | bigint(20)   | NO         | ログディスクサイズ、単位はバイト   |
| LOG_DISK_IN_USE  | bigint(20)   | NO         | ログディスクの使用済みサイズ、単位はバイト                                                                |
| DATA_DISK_SIZE   | bigint(20)   | YES        | このフィールドの値が`NULL`の場合、未定義を意味し、他のテナントのディスク容量を競合的に使用することが許可されます。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>     |
| DATA_DISK_IN_USE | bigint(20)   | NO         | Unitが使用しているデータディスクサイズを表します。     |
| STATUS           | varchar(64)  | NO         | Unitの状態：<ul><li>`NORMAL`：正常状態</li><li>`MIGRATING IN`：移入中 </li><li>`MIGRATING OUT`：移出中</li><li>`MARK DELETING`：削除マーク付け</li><li>`WAIT GC`：GCデータ待ち </li><li>`DELETING`：GC完了、削除中 </li><li> `ERROR`：エラー状態 </li></ul> |
| CREATE_TIME      | timestamp(6) | NO         | UnitがOBServerノード上に作成された時間                                                 |
| REPLICA_TYPE     | varchar(7)   | NO         | レプリカタイプ。デフォルトは `FULL` <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、<code>REPLICA_TYPE</code>フィールドはV4.4.0 BP1バージョンから導入されました。</li> <li>V4.5.x系では、<code>REPLICA_TYPE</code>フィールドはV4.5.0バージョンから導入されました。</li><li>V4.2.5系では、<code>REPLICA_TYPE</code>フィールドはV4.2.5 BP7バージョンから導入されました。</li></ul></main>  |
