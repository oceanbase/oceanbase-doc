# GV$OB_PROCESSLIST

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `GV$OB_PROCESSLIST`は、テナントが存在するすべてのOBServerノードのセッション情報を表示するために使用されます。

## フィールドの説明

|      フィールド名      |         タイプ          | NULL値を許容するか |                              説明                              |

| RECORD_POLICY | varchar(32) | NO | このセッションのエンドツーエンドトレースレコードポリシーを示します。主に以下の3種類のポリシーをサポートしています：<ul><li>ALL：サンプリングが有効なすべてのトレースのトレースポイント情報はログファイルに出力され、各span終了時に即座に出力されます。</li><li>ONLY_SLOW_QUERY：サンプリングが有効なトレースのトレースポイント情報の中で、Slow Queryに該当するリクエストのトレースのみがログファイルに出力され、他のものは破棄されます。この出力ポリシーでは、トレースログの出力タイミングはリクエストがSlow Queryと判定された後に発生します。Proxyにおいて、ルートspan（トランザクションレベルのspan）については、Slow Queryが検出された場合にのみルートspanが出力されます。</li><li>SAMPLE_AND_SLOW_QUERY：サンプリングが有効なトレースのトレースポイント情報の中で、以下の条件を満たすトレースはすべてログファイルに出力されます：<ol><li>隠しパラメータ<code>_print_sample_ppm</code>を使用して0.01%の確率でサンプリングを行い、かつサンプリング結果が選択された場合にのみログに出力されます。</li><li>ONLY_SLOW_QUERYモードでの出力条件を満たす。</li></ol>このモードでは、span終了時にログが出力されるわけではありません。条件1を満たす場合は、クライアント側でこのトレースログが強制的に出力されることがマークされ、その情報は後続のリンクコンポーネントに転送されます。条件2を満たす場合は、出力タイミングはONLY_SLOW_QUERYと同じです。</li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main> |
| LB_VID | bigint(20) | YES | 公有クラウド環境でロードバランサー経由で直接データベースに接続する場合、この列にはロードバランサーのVPC IDが表示されます。それ以外の場合、NULLが表示されます<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main> |

| USER_CLIENT_PORT  | bigint(20)          | NO   | クライアントアドレス情報<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.3バージョンから導入されました。</p></main>|
| PROXY_USER        | varchar(128)        | YES  |<ul><li>プロキシユーザーによるログインの場合、プロキシユーザーの名前が返されます。</li><li>プロキシユーザー以外によるログインの場合、空になります。</li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.3バージョンから導入されました。</p></main> |

## クエリ例

