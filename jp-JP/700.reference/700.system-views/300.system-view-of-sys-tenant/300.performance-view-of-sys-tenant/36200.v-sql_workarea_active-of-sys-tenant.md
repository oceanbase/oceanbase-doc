# V$SQL_WORKAREA_ACTIVE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

現在ノード上でアクティブなOperatorのワークエリア情報を表示します。

## フィールド説明

|     **フィールド名**     |    **型**    | **NULL許容** |                       **説明**                       |
|------------------|--------------|----------------|------------------------------------------------------------------------------------|
| SQL_HASH_VALUE   | bigint(0)    | NO             | 実行されたステートメントのHash値です。現在この値はNULLです。                          |
| SQL_ID           | varchar(32)  | NO             | SQLステートメントのSQL一意の識別子です。                                  |
| SQL_EXEC_START   | date         | NO             | SQLの実行開始時刻。                                        |
| SQL_EXEC_ID      | bigint(20)   | NO             | SQL実行の一意の識別子です。                                        |
| WORKAREA_ADDRESS | varbinary(8) | NO             | Workareaのアドレスです。                                      |
| OPERATION_TYPE   | varchar(40)  | NO             | Workareaの演算子タイプ。例：Sort、Hash Join、Group byなど。      |
| OPERATION_ID     | bigint(20)   | NO             | プランツリー内で演算子を識別する一意の識別子です。                                    |
| POLICY           | varchar(6)   | NO             | Workareaのポリシー：<ul><li>MANUAL</li><li> AUTO </li></ul>   |
| SID              | bigint(20)   | NO             | セッションの一意の識別子です。                                     |
| QCINST_ID        | bigint(0)    | NO             | クエリコーディネーターのインスタンスIDです。                                       |
| QCSID            | bigint(0)    | NO             | クエリコーディネーターセッション識別子IDです。                               |
| ACTIVE_TIME      | bigint(20)   | NO             | Workareaの平均アクティブ時間、単位：ms。                            |
| WORK_AREA_SIZE   | bigint(20)   | NO             | 演算子が使用するWorkareaの最大値、単位：bytes。                      |
| EXPECT_SIZE      | bigint(20)   | NO             | Workareaの期待サイズ、単位：bytes。                           |
| ACTUAL_MEM_USED  | bigint(20)   | NO             | Workareaに割り当てられたメモリ量、単位：bytes。                         |
| MAX_MEM_USED     | bigint(20)   | NO             | Workareaの最大メモリ使用量、単位：bytes。                     |
| NUMBER_PASSES    | bigint(20)   | NO             | Workareaの実行モード：<ul><li>0：optimalモードを表します。</li><li> 1：one passモードを表します。   </li><li> ≥2：multi passモードを表します。 </li></ul>   |
| TEMPSEG_SIZE     | bigint(20)   | NO             | Workareaが使用する一時空間サイズ、単位：バイト。NULLの場合は、一時ファイルの書き込みが発生していないことを意味します。  |
| TABLESPACE       | varchar(20)  | NO             | 一時ファイルが書き込まれるテーブルの名前空間。NULLの場合は、一時ファイルの書き込みが発生していないことを意味します。                  |
| SEGRFNO#         | bigint(0)    | NO             | 一時ファイルの書き込みに関連するファイル数。NULLは一時ファイルの書き込みが発生していないことを意味します。                     |
| SEGBLK#          | bigint(0)    | NO             | Workareaが一時ファイルを作成したBlock数。NULLは一時ファイルの書き込みが発生していないことを意味します。        |
| CON_ID           | bigint(20)   | NO             | テナントID  |
| SVR_IP                 | varchar(46)   | NO             | サーバーIPアドレス                   |
| SVR_PORT                 | bigint(20)   | NO             | サーバーポート番号                   |
