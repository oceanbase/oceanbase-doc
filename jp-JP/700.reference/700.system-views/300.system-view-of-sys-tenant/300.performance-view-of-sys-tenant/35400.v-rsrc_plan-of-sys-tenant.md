# V$RSRC_PLAN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

現在アクティブなテナントのリソース管理計画を表示します。

## フィールド説明

|            フィールド名            |      型       | NULL許容 |                       説明                       |
|----------------------------|---------------|------------|--------------------------------------------------------------------------------|
| ID                         | decimal(10,0)        | NO         | リソースプランID。グローバルに一意です。                                  |
| NAME                       | varchar(128) | NO         | リソースプラン名                                        |
| IS_Top_PLAN                | varchar(5)   | NO         | 現在のリソースプランが現在設定されているトップレベルプランかどうかを示します。  </li><li> `TRUE`：現在のリソースプランが現在設定されているトップレベルプランであることを示します。    </li><li> `FALSE`：現在のリソースプランが現在のトップレベルプランのサブプランであることを示します。  <br>  現在、OceanBaseデータベースではこの値は常に`TRUE`に固定されています。 |
| CPU_MANAGED                | varchar(3)   | NO         | CPU使用率を管理するパラメータが現在のリソースプランに設定されているかどうかを示します。  </li><li> `ON`：設定済み    </li><li> `OFF`：未設定  <br>  現在、OceanBaseデータベースではこの値は常に`ON`に固定されています。                               |
| INSTANCE_CAGING            | varchar(3)   | NO         | 互換性のためのみ使用されます。現在、この値は常に`NULL`に固定されています。                          |
| PARALLEL_SERVERS_ACTIVE    | decimal(10,0)        | NO         | 互換性のためのみ使用されます。現在、この値は常に`NULL`に固定されています。                          |
| PARALLEL_SERVERS_TOTAL     | decimal(10,0)        | NO         | 互換性のためのみ使用されます。現在、この値は常に`NULL`に固定されています。                          |
| PARALLEL_EXECUTION_MANAGED | varchar(32)  | NO         | 互換性のためのみ使用されます。現在、この値は常に`NULL`に固定されています。                          |

## クエリ例

システムテナントが現在アクティブなテナントのリソース管理計画を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$RSRC_PLAN;
```

クエリ結果は次のとおりです：

```shell
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| ID   | NAME    | IS_TOP_PLAN | CPU_MANAGED | INSTANCE_CAGING | PARALLEL_SERVERS_ACTIVE | PARALLEL_SERVERS_TOTAL | PARALLEL_EXECUTION_MANAGED |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| NULL | daytime | TRUE        | ON          | NULL            |                    NULL |                   NULL | NULL                       |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
1 row in set
```
