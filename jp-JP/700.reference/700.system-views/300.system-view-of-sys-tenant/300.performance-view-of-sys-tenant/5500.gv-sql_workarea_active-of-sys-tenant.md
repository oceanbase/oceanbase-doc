# GV$SQL_WORKAREA_ACTIVE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV2.2.77バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのノード上で現在アクティブなオペレータのワークエリア情報を表示します。

## フィールドの説明

|     **フィールド名**     |    **型**    | **NULL許容** |                       **説明**                       |
|------------------|--------------|----------------|------------------------------------------------------------------------------------|
| SQL_HASH_VALUE   | bigint(0)    | NO             | 実行されたステートメントのHash値。現在この値はNULLです。                          |
| SQL_ID           | varchar(32)  | NO             | SQLステートメントの一意の識別子。                                  |
| SQL_EXEC_START   | date         | NO             | SQLの実行開始時刻。                                        |
| SQL_EXEC_ID      | bigint(20)   | NO             | SQL実行の一意の識別子。                                        |
| WORKAREA_ADDRESS | varbinary(8) | NO             | ワークエリアのアドレス。                                      |
| OPERATION_TYPE   | varchar(40)  | NO             | ワークエリアのオペレータタイプ。例：Sort、Hash Join、Group byなど。      |
| OPERATION_ID     | bigint(20)   | NO             | プランツリー内でオペレータを識別する一意の識別子。                                    |
| POLICY           | varchar(6)   | NO             | ワークエリアのポリシー：<ul><li>MANUAL</li><li>AUTO </li></ul>   |
| SID              | bigint(20)   | NO             | セッションの一意の識別子。                                     |
| QCINST_ID        | bigint(0)    | NO             | クエリコーディネータのインスタンスID。                                       |
| QCSID            | bigint(0)    | NO             | クエリコーディネータのセッションID。                               |
| ACTIVE_TIME      | bigint(20)   | NO             | ワークエリアの平均アクティブ時間、単位：ms。                            |
| WORK_AREA_SIZE   | bigint(20)   | NO             | オペレータが使用するワークエリアの最大サイズ、単位：バイト。                      |
| EXPECT_SIZE      | bigint(20)   | NO             | ワークエリアが必要とするサイズ、単位：バイト。                           |
| ACTUAL_MEM_USED  | bigint(20)   | NO             | ワークエリア用に要求したメモリ量、単位：バイト。                         |
| MAX_MEM_USED     | bigint(20)   | NO             | ワークエリアで使用される最大メモリ量、単位：バイト。                     |
| NUMBER_PASSES    | bigint(20)   | NO             | ワークエリアがどのモードで実行されているか：<ul><li>0：optimalモードを表す</li><li> 1：one passモードを表す</li><li>≥2：multi passモードを表す </li></ul>   |
| TEMPSEG_SIZE     | bigint(20)   | NO             | ワークエリアが使用する一時空間のサイズ、単位：バイト。NULLの場合、一時ファイルへの書き込みが発生していないことを意味します。  |
| TABLESPACE       | varchar(20)  | NO             | 一時ファイルが書き込まれるテーブル名前空間。NULLの場合、一時ファイルへの書き込みが発生していないことを意味します。                  |
| SEGRFNO#         | bigint(0)    | NO             | 一時ファイル書き込み関連のファイル数。NULLは一時ファイルへの書き込みが発生していないことを意味します。                     |
| SEGBLK#          | bigint(0)    | NO             | ワークエリアが作成した一時ファイルのBlock数。NULLは一時ファイルへの書き込みが発生していないことを意味します。        |
| CON_ID           | bigint(20)   | NO             | テナントID  |
| SVR_IP                 | varchar(46)   | NO             | サーバーIPアドレス                   |
| SVR_PORT                 | bigint(20)   | NO             | サーバーポート番号                   |
