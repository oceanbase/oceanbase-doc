# V$OB_TENANT_RUNTIME_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノード上のテナントスレッドにおけるキューとスレッド制限に関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーのポート番号 |
| TENANT_ID | bigint(20) | NO | テナントID |
| COMPAT_MODE | bigint(20) | NO | テナントの互換モード |
| UNIT_MIN_CPU | double | NO | 最小CPUコア数 |
| UNIT_MAX_CPU | double | NO | 最大CPUコア数 |
| SLICE | double | NO | テナントユニットのスライスサイズ |
| REMAIN_SLICE | double | NO | 残りのスライスサイズ |
| TOKEN_CNT | bigint(20) | NO | スケジューラが割り当てたToken数。1つのTokenは1つのワーカースレッドに変換される |
| ASS_TOKEN_CNT | bigint(20) | NO | テナントが現在確認しているToken数（token_cntに基づいて確認する。通常は両者が等しい） |
| LQ_TOKENS | bigint(20) | NO | Large Query Tokenの数 |
| USED_LQ_TOKENS | bigint(20) | NO | 現在LQ Tokenを保持しているWorker数 |
| STOPPED | bigint(20) | NO | テナントUnitが削除中かどうか |
| IDLE_US | bigint(20) | NO | 1ラウンド（10秒）におけるワーカースレッドのアイドル時間の合計。いわゆるアイドルとは、実際には待機キューでの待機時間のみをカウントする |
| RECV_HP_RPC_CNT | bigint(20) | NO | テナントが累計で受信したHP（High）レベルのRPCリクエスト数 |
| RECV_NP_RPC_CNT | bigint(20) | NO | テナントが累計で受信したNP（Normal）レベルのRPCリクエスト数 |
| RECV_LP_RPC_CNT | bigint(20) | NO | テナントが累計で受信したLP（Low）レベルのRPCリクエスト数 |
| RECV_MYSQL_CNT | bigint(20) | NO | テナントが累計で受信したMySQLリクエスト数 |
| RECV_TASK_CNT | bigint(20) | NO | テナントが累計で受信した内部タスク数 |
| RECV_LARGE_REQ_CNT | bigint(20) | NO | テナントが累計で予測した大規模リクエスト数。増加のみで、ゼロリセットはない。実際には再試行時に増加する。 |
| RECV_LARGE_QUERIES | bigint(20) | NO | テナントが累計で受信した大規模クエリ数 |
| ACTIVES | bigint(20) | NO | アクティブなワーカースレッド数。通常はWorkersと等しく、その差には以下が含まれる：テナントワーカースレッドキャッシュ + ワーカースレッドを伴う大規模リクエストキャッシュ |
| WORKERS | bigint(20) | NO | テナントが保持するワーカースレッド数。実際には`workers_list`のサイズである。 |
| LQ_WAITING_WORKERS | bigint(20) | NO | Large Queryを待機しているワーカースレッド数 |
| REQ_QUEUE_TOTAL_SIZE | bigint(20) | NO | リクエストキューの総サイズ |
| QUEUE_0 | bigint(20) | NO | キュー0のサイズ |
| QUEUE_1 | bigint(20) | NO | キュー1のサイズ |
| QUEUE_2 | bigint(20) | NO | キュー2のサイズ |
| QUEUE_3 | bigint(20) | NO | キュー3のサイズ |
| QUEUE_4 | bigint(20) | NO | キュー4のサイズ |
| QUEUE_5 | bigint(20) | NO | キュー5のサイズ |
| LARGE_QUEUED | bigint(20) | NO | キューに並んでいる大規模リクエスト数 |
