# V$OB_UNITS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このOBServerノードのUnit情報を表示します。

## フィールドの説明

|       フィールド名       |      タイプ      | NULL値を許容するか |                                                                            説明                                                                             |
|------------------|--------------|------------|-------------------------------------------------------------------------|
| SVR_IP           | varchar(46)  | NO         | サーバーのIPアドレス                                                              |
| SVR_PORT         | bigint(20)   | NO         | サーバーのポート番号                                                                 |
| UNIT_ID          | bigint(20)   | NO         | Unit ID                                                                |
| TENANT_ID        | bigint(20)   | NO         | Unitが所属するテナントID                                                          |
| ZONE             | varchar(128) | NO         | Zone名                                                                |
| ZONE_TYPE | varchar(128) | NO | Unitが存在するZoneのZoneタイプ。値は以下のとおりです：<ul><li>`NULL`：この列の値が無効であることを示します。OBServerノードの再起動時に一時的に無効な値が表示される場合があります。</li> <li>`ReadWrite`：読み書きゾーン</li> <li>`Encryption`：暗号化ゾーン</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REGION | varchar(128) | NO | Unitが存在するZoneが属するRegion名。設定されていない場合、デフォルトは`default_region`です。値が`NULL`の場合、この列の値が無効であることを示し、OBServerノードの再起動時に一時的に無効な値が表示される場合があります。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| MAX_CPU          | double       | NO         | CPUスペックの上限                                                               |
| MIN_CPU          | double       | NO         | CPUスペックの下限                                                               |
| MEMORY_SIZE       | bigint(20)   | NO         | メモリサイズ（単位：バイト）                                                           |
| MAX_IOPS         | bigint(20)   | NO         | ディスクIOPSの上限规格                                                           |
| MIN_IOPS         | bigint(20)   | NO         | ディスクIOPSの最小仕様値                                                           |
| IOPS_WEIGHT    | bigint(20)   | NO         | IOPS重み |
| LOG_DISK_SIZE  | bigint(20)   | NO         | ログディスクサイズ、単位はバイト  |
| LOG_DISK_IN_USE | bigint(20)   | NO         | ログディスクの使用済みサイズ、単位はバイト                                                               |
| DATA_DISK_IN_USE | bigint(20)   | NO         | データディスクの使用済みサイズ、単位はバイト                                                               |
| STATUS           | varchar(64)  | NO         | Unitの状態：<ul><li>`NORMAL`：正常な状態   </li><li> `MIGRATING IN`：移入中   </li><li> `MIGRATING OUT`：移出中   </li><li> `MARK DELETING`：削除マーク</li><li>`WAIT GC`：GCデータ待機 </li><li>`DELETING`：GC完了、削除中 </li><li> `ERROR`：エラー状態</li></ul>  |
| CREATE_TIME      | timestamp(6) | NO         | UnitがOBServerノード上で作成された時間                                                 |
| REPLICA_TYPE     | varchar(7)   | NO         | レプリカタイプ。デフォルトは`FULL` <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、フィールド<code>REPLICA_TYPE</code>はV4.2.5 BP7バージョンから導入されました。</p></main>    |

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.V$OB_UNITS WHERE TENANT_ID=1002\G
```
