# V$OB_IO_CALIBRATION_STATUS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のノード上でのI/Oキャリブレーションタスクの実行状態を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | サーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | サーバーポート番号 |
| STORAGE_NAME | varchar(1024) | NO | ストレージ名。例：DATA、REDO |
| STATUS | varchar(256) | NO | I/Oキャリブレーションの状態。<ul><li>NOT AVAILABLE</li><li>IN PROGRESS</li><li>READY</li></ul> |
| START_TIME | timestamp(6) | NO | 最終のI/Oキャリブレーション開始時間 |
| FINISH_TIME | timestamp(6) | NO | 最終のI/Oキャリブレーション終了時間 |

## クエリ例

現在のノード上でのI/Oキャリブレーションタスクの実行状態を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_IO_CALIBRATION_STATUS;
```

クエリ結果は次のとおりです。

```shell
+----------------+----------+--------------+--------+----------------------------+----------------------------+
| SVR_IP         | SVR_PORT | STORAGE_NAME | STATUS | START_TIME                 | FINISH_TIME                |
+----------------+----------+--------------+--------+----------------------------+----------------------------+
| 172.xx.xxx.xxx |     2882 | DATA         | READY  | 2025-01-02 10:20:23.299385 | 2025-01-02 10:22:03.578395 |
+----------------+----------+--------------+--------+----------------------------+----------------------------+
1 row in set
```
