# GV$OB_KV_GROUP_COMMIT_STATUS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナントでは、ビュー`GV$OB_KV_GROUP_COMMIT_STATUS`を使用して、すべてのOBKVテナントクライアント接続のグループコミット状態情報にアクセスできます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | グループコミットのグループが存在するノードのIPアドレス |
| SVR_PORT | bigint(20) | NO | グループコミットのグループが存在するノードのポート番号 |
| TENANT_ID | bigint(20) | NO | テナントID：<ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID</li></ul> |
| TABLE_ID | bigint(20) | NO | グループコミットのグループが属するテーブルのID |
| LS_ID | bigint(20) | NO | グループコミットのグループが属するログストリームのID |
| SCHEMA_VERSION | bigint(20) | NO |  グループコミットのグループが属するテーブルのschema_version |
| GROUP_TYPE | varchar(32) | NO | グループコミットのグループのタイプ。現在サポートされているキュータイプ：<ul><li> get：getリクエストキュー </li><li>put：putリクエストキュー </li><li>del：deleteリクエストキュー </li><li>replace：replaceリクエストキュー </li><li>insert：insertリクエストキュー </li><li>hybird：混合操作リクエストキュー </li><li>fail：バッチ実行に失敗したキュー </li></ul> |
| QUEUE_SIZE | bigint(20) | NO | グループコミットのグループ内のリクエストキューのサイズ。現在未消費のリクエスト数を表します |
| BATCH_SIZE | bigint(20) | NO | グループコミットのグループ内のバッチのサイズ |
| CREATE_TIME | timestamp(6) | NO  | グループコミットにおける、このグループの作成日時  |
| UPDATE_TIME | timestamp(6) | NO  | グループコミットにおける、このグループの状態情報がリフレッシュされた日時  |

## クエリ例

すべてのノード上の現在のOBKVテナントクライアント接続のグループコミット状態情報を照会し、1日目のレコードを表示します。

```shell
obclient > SELECT * FROM oceanbase.GV$OB_KV_GROUP_COMMIT_STATUS limit 2;
```
