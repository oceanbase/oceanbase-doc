# GV$OB_SERVERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノードの情報を表示します。

## フィールド説明

|          フィールド名           |      型      | NULL許容   |              説明              |
|-------------------------|--------------|------------|-------|
| SVR_IP                  | varchar(46)  | NO         | サーバーのIPアドレス                    |
| SVR_PORT                | bigint(20)   | NO         | サーバーのポート番号                       |
| ZONE                    | varchar(128) | NO         | Zone名                         |
| SQL_PORT                | bigint(20)   | NO         | SQLポート                       |
| CPU_CAPACITY            | bigint(20)   | NO         | ノードのCPU総容量        |
| CPU_CAPACITY_MAX        | double       | NO         | ノードのCPU総容量のオーバーコミット値。`resource_hard_limit`構成パラメータによって制御されます：`CPU_CAPACITY_MAX =  CPU_CAPACITY * resource_hard_limit`                                                                   |
| CPU_ASSIGNED            | double       | NO         | OBServerノードに割り当てられているCPU数。これはOBServerノード上のすべてのUnitの`MIN_CPU`仕様の合計です。制約条件：`CPU_ASSIGNED <= CPU_CAPACITY`                |
| CPU_ASSIGNED_MAX        | double       | NO         | OBServerノードに割り当てられているCPU数の上限値。これはOBServerノード上のすべてのUnitの`MAX_CPU`仕様の合計です。制約条件：`CPU_ASSIGNED_MAX <= CPU_CAPACITY_MAX`       |
| MEM_CAPACITY            | bigint(20)   | NO         | OBServerノードがテナントに割り当て可能なメモリサイズの合計。値は`memory_limit - system_memory`、単位はバイト    |
| MEM_ASSIGNED            | bigint(20)   | NO         | OBServerノードに割り当て済みのメモリサイズ。これはOBServerノード上のすべてのUnitの`MEMORY_SIZE`仕様の合計で、単位はバイトです。制約条件：`MEM_ASSIGNED <= MEM_CAPACITY`     |
| LOG_DISK_CAPACITY       | bigint(20)   | NO         | ログディスクの総容量、単位はバイト     |
| LOG_DISK_ASSIGNED       | bigint(20)   | NO         | ログディスクの割り当て済みサイズ。これはOBServerノード上のすべてのUnitの`LOG_DISK_SIZE`の合計で、単位はバイト         |
| LOG_DISK_IN_USE         | bigint(20)   | NO         | ログディスクの使用済みサイズ、単位はバイト               |
| DATA_DISK_CAPACITY      | bigint(20)   | NO         | OBServerノード上のデータディスク領域の総サイズを表します。単位はバイト。  |
| DATA_DISK_ASSIGNED      | bigint(20)   | YES        | このフィールドの値は`NULL`となり、未定義を意味し、他のテナントのディスク容量を競合的に使用することを許可します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main>    |
| DATA_DISK_IN_USE        | bigint(20)   | NO         | OBServerノードで使用中のデータディスクサイズを表します。単位はバイト。  |
| DATA_DISK_health_STATUS | varchar(20)  | NO         | データディスクの健全状態：<ul><li> `NORMAL`：正常状態 </li><li>`WARNING`：異常が存在します</li><li>`ERROR`：エラーが存在します </li></ul>   |
| MEMORY_LIMIT            | bigint(20)   | NO         | OBServerノードで利用可能なメモリサイズの合計。単位はバイトです   |
| DATA_DISK_ALLOCATED     | bigint(20)   | NO         | OBServerで割り当て済みのデータディスクサイズ。単位はバイト<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>    |
| DATA_DISK_ABNORMAL_TIME | timestamp(6) | NO         | データディスクの前回の異常(`WARNING`および`ERROR`状態)時間  |
| SSL_CERT_EXPIRED_TIME    | timestamp(6) | NO         | 現在のOBServerノードでSSLを有効にした際に使用されていたSSL証書の有効期限およびUTC時刻を記録します。単位はマイクロ秒です |
| SS_DATA_DISK_OPERATION_SUGGESTED | varchar(32)| YES  | このフィールドの値は`NULL`となります。  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このフィールドはV4.3.5 BP2バージョンから導入されました。</li></ul></main>     |
| SS_DATA_DISK_SIZE_SUGGESTED      | bigint(20) | YES  | このフィールドの値は`NULL`となります。  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このフィールドはV4.3.5 BP2バージョンから導入されました。</li></ul></main>    |
