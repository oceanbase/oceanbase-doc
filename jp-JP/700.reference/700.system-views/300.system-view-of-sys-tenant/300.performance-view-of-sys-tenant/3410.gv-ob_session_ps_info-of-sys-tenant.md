# GV$OB_SESSION_PS_INFO

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_SESSION_PS_INFO`は、現在のテナント内で全セッションが開いているPS情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | -------- | ------------------- | -------- |
| SVR_IP             | varchar(46) | NO | OBServer IP |
| SVR_PORT           | bigint(20)  | NO | OBServer PORT |
| TENANT_ID          | bigint(20)  | NO |  テナントID |
| PROXY_SESSION_ID   | bigint(20) unsigned | NO | ODP内のSession ID  |
| SESSION_ID         | bigint(20) unsigned | NO | V4.2.x系バージョンについて：<ul><li> V4.2.5 BP3 Hotfix5 より前のバージョン：<br>すべての接続方式（直接接続モード/ODPモード）において、このフィールドはサーバーセッションIDを表します。</li><li> V4.2.5 BP3 Hotfix5 以降のバージョン：<ul><li>ODPモードの場合：</li><ul><li>ODP内のパラメータ <code>client_session_id_version = 2</code> が設定されている場合、このフィールドはクライアントセッションIDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul></li></ul>   |
| PS_CLIENT_STMT_ID  | bigint(20)  | NO | クライアントがPrepareリクエストを送信した後、クライアントに返されるPS ID |
| PS_INNER_STMT_ID   | bigint(20)  | NO | OBServer内の内部PS ID（PS Cache内のPS ID） |
| STMT_TYPE          | varchar(256)| NO | Prepareのステートメントタイプ。値は `T_SELECT`、`T_INSERT`、`T_REPLACE`、`T_DELETE`、`T_UPDATE`、`T_MERGE`、`T_EXPLAIN`、`T_CREATE_TABLE`、`T_DROP_TABLE` などです。 |
| PARAM_COUNT        | bigint(20)  | NO |  PSのパラメータ数 |
| PARAM_TYPES        | longtext    | NO | パラメータタイプのリスト。Prepareステートメント内のすべてのパラメータのタイプをリストアップします。各パラメータタイプは数字で表し、異なるパラメータタイプ間は半角カンマで区切ります。 |
| REF_COUNT          | bigint(20)  | NO | `ps_session_info_` の参照カウント。`ps_session_info_` はセッション上のプロパティであり、セッションがステートメントをPrepareした後、そのセッション上に `ps_session_info_` が存在します。 |
| CHECKSUM           | bigint(20)  | NO | PS Cache内のパラメータ化後SQLの文字列チェックサム |

## クエリ例

現在のテナント内で、すべてのセッションが開いているPS情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_SESSION_PS_INFO;
```
