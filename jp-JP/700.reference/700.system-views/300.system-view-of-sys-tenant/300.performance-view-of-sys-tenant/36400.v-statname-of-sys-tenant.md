# V$STATNAME

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `V$STATNAME` は、すべての統計イベントに関する定義を表示するために使用されます。

## フィールド説明

|   **フィールド名**   |   **タイプ**    | **NULL許容** |   **説明**    |
|--------------|-------------|----------------|-------------|
| CON_ID       | bigint(20)  | NO             | テナントID      |
| STAT_ID      | bigint(20)  | NO             | 統計イベントID    |
| STATISTICS#  | bigint(20)  | NO             | 統計イベントのインデックス     |
| NAME         | varchar(64) | NO             | 統計イベント名     |
| DISPLAY_NAME | varchar(64) | NO             | 統計イベントのエイリアス     |
| CLASS        | bigint(20)  | NO             | 統計項目のカテゴリ。各統計項目は1つのタイプにのみ該当します。ID:<ul><li>1： NETWORK</li> <li>2：QUEUE</li> <li>4：TRANS</li> <li>8：SQL</li> <li>16：CACHE</li> <li>32：STORAGE</li> <li>64：RESOURCE</li> <li>128：DEBUG</li> <li>256：CLOG</li> <li>512：ELECT</li> <li>1024：OBSERVER</li> <li>2048：RS</li> <li>3072：Time Model</li> <li>4096：TABLEAPI</li> <li>8192：WR</li></ul> |

## クエリ例

統計イベントの関連定義を確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$STATNAME limit 10;
```
