# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>このビューは、V4.2.2バージョンから <a href="30900.v-ob_active_session_history-of-sys-tenant.md">V$OB_ACTIVE_SESSION_HISTORY</a> に変更されました。</li>
  <li>このビューは、V4.0.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

アクティブセッションの履歴を表示します。
