# gv$tenant

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系ではテナント管理機能のアーキテクチャが最適化されたため、このビューはV4.x系では適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、システムテナントとユーザーテナントはどちらもビュー<a href="../200.dictionary-view-of-sys-tenant/23100.o-dba_ob_tenants-of-sys-tenant.md">DBA_OB_TENANTS</a>を使用してテナントの詳細情報を確認できます。</li></ul>
</main>

## 機能の概要

クラスタ内のすべてのテナントの詳細情報を表示します。

## フィールドの説明

|    **フィールド名**    |    **型**     | **NULL許容** |      **説明**      |
|----------------|---------------|----------------|------------------|
| tenant_id      | bigint(20)    | NO             | テナントID            |
| tenant_name    | varchar(128)  | NO             | テナント名            |
| zone_list      | varchar(8192) | NO             | テナントのゾーン集合      |
| primary_zone   | varchar(128)  | YES            | テナントのプライマリゾーン |
| collation_type | bigint(20)    | NO             | テナントの照合情報 |
| info           | varchar(4096) | NO             | テナントの情報            |
| read_only      | bigint(20)    | NO             | テナントが読み取り専用モードかどうか、この値は廃止されました |
| locality       | varchar(256)  | NO             | テナントのレプリカ配置方式        |

## クエリ例

現在のクラスタ内のすべてのテナントの詳細情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.gv$tenant;
```

クエリ結果は次のとおりです：

```shell

|      1001 | mysql001    | zone1     | zone1        |              0 |               |         0 | FULL{1}@zone1 |
|      1002 | oracle001   | zone1     | zone1        |              0 |               |         0 | FULL{1}@zone1 |

3 rows in set
```
