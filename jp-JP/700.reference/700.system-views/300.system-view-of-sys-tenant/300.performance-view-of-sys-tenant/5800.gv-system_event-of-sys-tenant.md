# GV$SYSTEM_EVENT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

クラスタ内の各テナントがすべてのOBServerノード上で発生した待機イベントを表示し、各種待機イベントの発生回数、待機時間、タイムアウト回数などの統計情報を集計します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | 情報が存在するサーバーのIPアドレス |
| SVR_PORT | bigint(20) | NO | 情報が存在するサーバーのポート番号 |
| EVENT_ID | bigint(20) | NO | 待機イベントのID |
| EVENT | varchar(64) | NO | 待機イベントの説明 |
| WAIT_CLASS_ID | bigint(20) | NO | 待機イベントが属するClassのID |
| WAIT_CLASS# | bigint(20) | NO | 待機イベントが属するClassのインデックス |
| WAIT_CLASS | varchar(64) | NO | 待機イベントが属するClass |
| TOTAL_WAITS | bigint(20) | NO | その待機イベントの総待機回数 |
| TOTAL_TIMEOUTS | bigint(20) | NO | その待機イベントの総タイムアウト回数 |
| TIME_WAITED | double | NO | その待機イベントの総待機時間。単位は10ミリ秒 |
| AVERAGE_WAIT | double | NO | その待機イベントの平均待機時間。単位は10ミリ秒 |
| TIME_WAITED_MICRO | bigint(20) | NO | その待機イベントの総待機時間。単位はマイクロ秒 |

## クエリ例

システムテナントで、すべてのテナントのすべてのノード上のすべての待機イベントを確認し、上位10件のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SYSTEM_EVENT LIMIT 10;
```
