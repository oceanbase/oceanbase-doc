# V$OB_IVF_INDEX_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、現在のOBServerノード上におけるすべてのテナントのIVFベクトルインデックスの基本情報とリアルタイム状態を表示します。

## フィールド説明

|             フィールド名          |      データ型    | NULL許容 |            説明                                            |  情報タイプ |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | レプリカが存在するノードのアドレス                                              | 基本情報 |
| SVR_PORT                     | bigint(20)   | NO             | レプリカが存在するノードのRPC_PORT                                              | 基本情報 |
| TENANT_ID                    | bigint(20)   | NO             | テナントID：<ul><li>1：システムテナントID</li> <li>その他の値：ユーザーテナントまたはMetaテナントID</li></ul>                                                    | 基本情報 |
| DATA_TABLE_ID                | bigint(20)   | NO             | データテーブルID                                                    | 基本情報 |
| TABLE_NAME                   | varchar(256) | NO             | テーブル名                                                    | 基本情報 |
| INDEX_NAME                   | varchar(256) | NO             | インデックス名                                                    | インデックス情報 |
| INDEX_TABLE_ID               | bigint(20)   | NO             | インデックステーブルID                                                    | インデックス情報 |
| INDEX_TABLET_ID              | bigint(20)   | NO             | インデックステーブルパーティションID                                                    | インデックス情報 |
| INDEX_PARAM                  | varchar(1024)     | NO             | インデックスパラメータ                                                    | インデックス情報 |
| CACHE_TYPE                   | varchar(29)   | NO             | IVFインデックスキャッシュタイプ：<ul><li>IVF_CENTROID_CACHE：IVFインデックスの中心点キャッシュ</li> <li>IVF_PQ_CENTROID_CACHE：IVF_PQインデックスの中心点キャッシュ</li> <li>IVF_PQ_PRECOMPUTE_TABLE_CACHE：IVF_PQインデックスの事前計算テーブルキャッシュ</li></ul>                                                    | キャッシュ情報 |
| IS_INIT                      | varchar(5)   | NO             | 初期化されているかどうか：<ul><li>TRUE：初期化済み</li> <li>FALSE：初期化されていない</li></ul>                                                    | キャッシュ情報 |
| MEMORY_USED                  | bigint(20)   | NO             | メモリ使用量                                                    | インデックス情報 |
| MEMORY_HOLD                  | bigint(20)   | NO             | 使用中メモリ                                                    | インデックス情報 |
| CACHE_INFO                   | varchar(512)     | NO             | JSON形式のキャッシュ属性情報                                                    | キャッシュ情報 |
