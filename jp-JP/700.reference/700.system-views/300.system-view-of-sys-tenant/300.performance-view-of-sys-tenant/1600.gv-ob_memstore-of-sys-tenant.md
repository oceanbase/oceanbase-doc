# GV$OB_MEMSTORE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>ビュー <code>GV$SERVER_MEMSTORE</code> は V4.0.0 以降、<code>GV$OB_MEMSTORE</code> に名前が変更されました。V4.0.0 以降のバージョンでは、新しいビュー名 <code>GV$OB_MEMSTORE</code> を使用してクエリを実行する必要があります。旧ビュー名 <code>GV$SERVER_MEMSTORE</code> でクエリを実行すると、エラーが発生します。</p>
</main>

## 機能の概要

すべてのサーバー上のすべてのテナントの MemTable のメモリ使用状況を表示します。

## フィールドの説明

|    **フィールド名**    |   **タイプ**    | **NULL許容** |              **説明**              |
|----------------|-------------|----------------|----------------------------------|
| SVR_IP         | varchar(46) | NO             | サーバーの IP アドレス                          |
| SVR_PORT       | bigint(20)  | NO             | サーバーのポート番号                            |
| TENANT_ID      | bigint(20)  | NO             | テナント ID                            |
| ACTIVE_SPAN    | bigint(20)  | NO             | アクティブな MemTable が占用するメモリの推定値（過大評価される可能性あり）、単位：バイト |
| FREEZE_TRIGGER | bigint(20)  | NO             | MemTable 凍結をトリガーしたメモリサイズ、単位：バイト        |
| FREEZE_CNT     | bigint(20)  | NO             | MemTable の凍結回数                   |
| MEMSTORE_USED  | bigint(20)  | NO             | MemTable が現在使用中のメモリサイズの合計、単位：バイト        |
| MEMSTORE_LIMIT      | bigint(20)  | NO             | MemTable のメモリサイズ制限、単位：バイト           |

## クエリ例

システムテナントが、テナント ID が `1002` のテナントのすべてのサーバー上の MemTable のメモリ使用状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MEMSTORE WHERE TENANT_ID=1002;
```

クエリ結果は次のとおりです：

```shell
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| SVR_IP         | SVR_PORT | TENANT_ID | ACTIVE_SPAN | FREEZE_TRIGGER | FREEZE_CNT | MEMSTORE_USED | MEMSTORE_LIMIT |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| 172.xx.xxx.xxx |     2882 |      1002 |    62914560 |      603982068 |          0 |      62914560 |     2684354550 |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
1 row in set
```
