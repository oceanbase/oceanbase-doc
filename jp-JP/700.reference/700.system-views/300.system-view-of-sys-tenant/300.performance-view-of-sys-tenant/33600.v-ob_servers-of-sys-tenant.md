# V$OB_SERVERS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のOBServerノードの情報を表示します。

## フィールド説明

|          フィールド名           |      型      | NULL許容    |              説明              |
|-------------------------|--------------|------------|--------------------------------------------------------------|
| SVR_IP                  | varchar(46)  | NO         | サーバーIPアドレス                    |
| SVR_PORT                | bigint(20)   | NO         | サーバーポート番号                       |
| ZONE                    | varchar(128) | NO         | Zone名                         |
| SQL_PORT                | bigint(20)   | NO         | SQLポート                       |
| CPU_CAPACITY            | bigint(20)   | NO         | ノードのCPU総容量        |
| CPU_CAPACITY_MAX        | double       | NO         | ノードのCPU総容量のオーバーコミット値。`resource_hard_limit`構成パラメータによって制御されます：`CPU_CAPACITY_MAX =  CPU_CAPACITY * resource_hard_limit`                                                                   |
| CPU_ASSIGNED            | double       | NO         | OBServerノードに割り当てられているCPU数。OBServerノード上のすべてのUnitの`MIN_CPU`仕様の合計です。制約条件：`CPU_ASSIGNED <= CPU_CAPACITY`                |
| CPU_ASSIGNED_MAX        | double       | NO         | OBServerノードに割り当てられているCPU数の上限値。OBServerノード上のすべてのUnitの`MAX_CPU`仕様の合計です。制約条件：`CPU_ASSIGNED_MAX <= CPU_CAPACITY_MAX`       |
| MEM_CAPACITY            | bigint(20)   | NO         | OBServerノードがテナントに割り当て可能な総メモリサイズ。値は`memory_limit - system_memory`、単位はバイト           |
| MEM_ASSIGNED            | bigint(20)   | NO         | OBServerノードに割り当て済みのメモリサイズ。OBServerノード上のすべてのUnitの`MEMORY_SIZE`仕様の合計、単位はバイトです。制約条件：`MEM_ASSIGNED <= MEM_CAPACITY`                 |
| LOG_DISK_CAPACITY      | bigint(20)   | NO         | ログディスクの総容量、単位はバイト                      |
| LOG_DISK_ASSIGNED      | bigint(20)   | NO         | ログディスクの割り当て済みサイズ。OBServerノード上のすべてのUnitの`LOG_DISK_SIZE`仕様の合計、単位はバイト         |
| LOG_DISK_IN_USE         | bigint(20)   | NO         | ログディスクの使用済みサイズ、単位はバイト                                                                              |
| DATA_DISK_CAPACITY      | bigint(20)   | NO         | OBServerノード上のデータディスク領域の総サイズを表します。単位はバイト。 |
| DATA_DISK_ASSIGNED      | bigint(20)   | YES        | このフィールドの値は `NULL` となり、未定義を意味し、他のテナントのディスク領域を競合的に使用することが許可されます。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.3バージョンから導入されました。</p></main>    |
| DATA_DISK_IN_USE        | bigint(20)   | NO         | OBServerノードで使用中のデータディスクサイズを表します。単位はバイト。 |
| DATA_DISK_HEALTH_STATUS | varchar(20)  | NO         | データディスクのヘルス状態：<ul><li> `NORMAL`：正常状態 </li><li>`WARNING`：異常が検出されています </li><li>`ERROR`：エラーが発生しています</li></ul>    |
| MEMORY_LIMIT            | bigint(20)  | NO         | OBServerノードで利用可能なメモリの総サイズ。単位はバイトです    |
| DATA_DISK_ALLOCATED     | bigint(20)   | NO         | OBServerノードに割り当てられたデータディスクサイズを表します。単位はバイト。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>    |
| DATA_DISK_ABNORMAL_TIME | timestamp(6) | NO         | データディスクの前回の異常(`WARNING`および`ERROR`状態)時間                                                                              |
| SSL_CERT_EXPIRED_TIME   | timestamp(6) | NO |現在のOBServerノードでSSLが有効な場合、そのSSL証書の有効期限およびUTC時刻をマイクロ秒単位で記録します |
| SS_DATA_DISK_OPERATION_SUGGESTED | varchar(32)| YES  | このフィールドの値は `NULL` となります。 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このフィールドはV4.3.5 BP2バージョンから導入されました。</li></ul></main>     |
| SS_DATA_DISK_SIZE_SUGGESTED      | bigint(20) | YES  | このフィールドの値は `NULL` となります。 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.0バージョンから導入されました。</li><li>V4.3.5系では、このフィールドはV4.3.5 BP2バージョンから導入されました。</li></ul></main>     |
