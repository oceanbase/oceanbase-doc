# V$OB_TENANT_RESOURCE_LIMIT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li>
<li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `V$OB_TENANT_RESOURCE_LIMIT` は、すべてのテナントが現在のOBServer上で使用している論理リソース量、上限値、有効な制限条件、およびダウン後の再起動時の最大使用量を表示します。

## フィールド説明

| フィールド名  |  型  | NULL許容 |     説明     |
|----------|--------|-----------------|-------------|
| SVR_IP               | varchar(46)  | NO   |  OBServerのIPアドレス    |
| SVR_PORT             | bigint(20)   | NO   |  OBServerのRPCポート    |
| TENANT_ID            | bigint(20)   | NO   |  テナントID    |
| ZONE                 | varchar(128) | NO   |  ZONE名    |
| RESOURCE_NAME        | varchar(128) | NO   |  リソース名    |
| CURRENT_UTILIZATION  | bigint(20)   | NO   |  リソースの現在の使用量    |
| MAX_UTILIZATION      | bigint(20)   | NO   |  マシン起動後のリソース最大使用量    |
| RESERVED_VALUE       | bigint(20)   | NO   |  事前割り当て量。この値は安定稼働のための最低保証値です    |
| LIMIT_VALUE          | bigint(20)   | NO   |  容認される最大使用量    |
| EFFECTIVE_LIMIT_TYPE | varchar(128) | NO   |  効力を生じる制限タイプ。例：パラメータ、メモリ、CPU、ディスクなど    |

## クエリ例

すべてのテナントの現在のOBServer上での論理リソース使用量、上限値、有効な制限条件、ダウン後の再起動時の最大使用量を照会します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_RESOURCE_LIMIT;
```
