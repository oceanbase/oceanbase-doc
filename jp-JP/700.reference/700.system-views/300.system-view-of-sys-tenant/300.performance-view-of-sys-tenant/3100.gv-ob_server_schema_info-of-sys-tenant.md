# GV$OB_SERVER_SCHEMA_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード上のスキーマ情報を表示します。

## フィールドの説明

|          **フィールド名**          |   **タイプ**    | **NULL許容** |              **説明**              |
|----------------------------|-------------|----------------|----------------------------------|
| SVR_IP                     | varchar(46) | NO             | サーバーIPアドレス                        |
| SVR_PORT                   | bigint(20)  | NO             | サーバーポート番号                           |
| TENANT_ID                  | bigint(20)  | NO             | テナントID                            |
| REFRESHED_SCHEMA_VERSION   | bigint(20)  | NO             | テナントがリフレッシュしたスキーマバージョン                 |
| RECEIVED_SCHEMA_VERSION    | bigint(20)  | NO             | テナントがリフレッシュすべきスキーマバージョン               |
| SCHEMA_COUNT               | bigint(20)  | NO             | 対応するスキーマバージョンにおける、各スキーマオブジェクト数の合計                    |
| SCHEMA_SIZE                | bigint(20)  | NO             | 対応するスキーマバージョンにおける、各スキーマオブジェクトが占有するメモリサイズの合計、単位はバイト                   |
| MIN_SSTABLE_SCHEMA_VERSION | bigint(20)  | NO             | テナントSSTableに記録されている最小schema_version |

## クエリ例

システムテナントがすべてのOBServerノード上のすべてのテナントのスキーマ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_SERVER_SCHEMA_INFO;
```
