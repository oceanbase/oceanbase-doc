# V$OB_LS_LOG_REPLAY_STAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2系では、このビューはV4.4.2 BP2で導入されました。</p>
</main>

## 機能の概要

ビュー`GV$OB_LS_LOG_REPLAY_STAT`は、テナントの現在のノード上にある各LS（ログストリーム）レプリカのログリプレイの進捗状況を表示します。スタンバイデータベースで照会してください。プライマリデータベースで照会する場合は、フォロアーレプリカを対象にしてください。

プライマリテナント（プライマリデータベース）のリーダーレプリカではログがリプレイされないため、クエリ結果において、プライマリテナント上の`ROLE = LEADER`の行には有効な情報が含まれません。

## フィールドの説明

|      フィールド名       |      型           | NULL許容 |    説明     |
|--------------------|---------------------|----------------|-------------|
| TENANT_ID          | bigint(20)          | NO   | テナントID     |
| SVR_IP             | varchar(46)         | NO   | ログストリームID     |
| SVR_PORT           | bigint(20)          | NO   | サーバーIPアドレス     |
| LS_ID              | bigint(20)          | NO   | サーバーポート番号     |
| ROLE               | varchar(32)         | NO   | ログストリームレプリカの役割：<ul><li>`LEADER`：リーダーレプリカ</li> <li>`FOLLOWER`：フォロアーレプリカ</li></ul>      |
| ENABLED            | tinyint(4)          | NO   | ログリプレイサービス（Replay Service）が有効かどうか    |
| END_LSN            | bigint(20) unsigned | NO   | Palfに書き込まれたLSN（ログリプレイの右端）      |
| UNSUBMITTED_LSN    | bigint(20) unsigned | NO   | 次にリプレイキューに投入されるログのLSN     |
| UNSUBMITTED_SCN    | bigint(20) unsigned | NO   | 次にリプレイキューに投入されるログのSCN     |
| MIN_UNREPLAYED_LSN | bigint(20) unsigned | NO   | リプレイキューでまだリプレイされていないログのうち、最小のLSN     |
| MIN_UNREPLAYED_SCN | bigint(20) unsigned | NO   | リプレイキューでまだリプレイされていないログのうち、最小のSCN     |
| PENDING_CNT        | bigint(20)          | NO   | メモリ内でリプレイ待ちのタスク数     |

## クエリ例

スタンバイテナントが存在するクラスタの`sys`テナント内で、テナントIDが1002のスタンバイテナントの現在のノード上にある各ログストリームレプリカのログリプレイの進捗状況を確認します。

```shell
obclient(root@sys)[oceanbase]> SELECT TENANT_ID, LS_ID, ROLE, ENABLED,
        END_LSN, UNSUBMITTED_LSN, MIN_UNREPLAYED_LSN, PENDING_CNT
        FROM oceanbase.V$OB_LS_LOG_REPLAY_STAT WHERE TENANT_ID = 1002;
```

クエリ結果は次のとおりです：

```shell
+-----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
| TENANT_ID | LS_ID | ROLE     | ENABLED | END_LSN   | UNSUBMITTED_LSN | MIN_UNREPLAYED_LSN | PENDING_CNT |
+-----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
|      1002 |     1 | FOLLOWER |       1 | 300636581 |       300060582 |          300060582 |           0 |
|      1002 |  1001 | FOLLOWER |       1 | 197547054 |       197052262 |          197052262 |           0 |
+-----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
2 rows in set
```
