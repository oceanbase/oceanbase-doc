# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

エンドツーエンド・トレースの診断情報を表示します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID <ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| TYPE | varchar(16) | NO | 診断情報のモニタリングレベル <ul><li>Tenantレベル：テナントレベルで診断情報をモニタリングする  </li><li>module/actionレベル：モジュールとアクションレベルで診断情報をモニタリングする </li><li>client_identifierレベル：クライアント識別子レベルで診断情報をモニタリングする </li></ul> |
| TENANT_NAME | varchar(128) | NO | テナント名 |
| MODULE_NAME | varchar(4096) | NO | モジュール名 |
| ACTION_NAME | varchar(4096) | NO | アクション名 |
| CLIENT_IDENTIFIER | varchar(65) | NO | クライアント識別子名 |
| LEVEL | bigint(20) | NO | そのセッションのエンドツーエンド・トレースのモニタリングレベルを表します。例えば、1はレベル1の診断情報を表します |
| SAMPLE_PERCENTAGE | bigint(20) | NO | そのセッションのエンドツーエンド・トレースのサンプリング頻度を表します。例えば、50は診断情報を50%の確率でサンプリングすることを意味します |
| RECORD_POLICY | varchar(32) | NO | そのセッションのエンドツーエンド・トレースの記録ポリシーを表します。主に以下の3種類のポリシーをサポートしています：<ul><li>ALL：サンプリング対象として選ばれ、トレースが有効になったリクエストのトレースポイント情報をすべてログファイルに出力します。各spanの終了時に出力します。 </li><li>ONLY_SLOW_QUERY：サンプリング対象として選ばれ、トレースが有効になったリクエストのトレースポイント情報のうち、Slow Queryに該当するリクエストのトレースのみをログファイルに出力し、その他は破棄します。このポリシーでは、リクエストの終了後、Slow Queryと判定された時点でトレースログを出力します。Proxyでは、ルートspan（トランザクションレベルのspan）はSlow Queryが検出された場合にのみ出力します。 </li><li>SAMPLE_AND_SLOW_QUERY：サンプリング対象として選ばれ、トレースが有効になったリクエストのトレースポイント情報のうち、以下の条件を満たすトレースをログファイルに出力します：<ol><li>隠し構成パラメータ <code>_print_sample_ppm</code> を使用して1万分の1の確率でサンプリングし、その対象として選ばれた場合</li><li>ONLY_SLOW_QUERYモードの出力条件を満たす場合</li></ol>このモードでも、span終了時にはログを出力しません。条件1を満たす場合、そのトレースログはクライアント側で強制出力対象としてマークされ、この情報が後続の処理経路上のコンポーネントに渡されます。条件2を満たす場合、出力タイミングはONLY_SLOW_QUERYと同じです。</li></ul> |
