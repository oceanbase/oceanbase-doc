# GV$OB_FLT_TRACE_CONFIG

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

エンドツーエンド・トレースの診断情報を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID <ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| TYPE | varchar(16) | NO | 診断情報のモニタリングレベル <ul><li>Tenantレベル：テナントレベルで診断情報をモニタリングする  </li><li>module/actionレベル：モジュールと操作レベルで診断情報をモニタリングする </li><li>client_identifierレベル：クライアント識別子レベルで診断情報をモニタリングする </li></ul> |
| TENANT_NAME | varchar(128) | NO | テナント名 |
| MODULE_NAME | varchar(4096) | NO | Module名 |
| ACTION_NAME | varchar(4096) | NO | Action名 |
| CLIENT_IDENTIFIER | varchar(65) | NO | Client Identifier名 |
| LEVEL | bigint(20) | NO | このセッションのエンドツーエンドトレースのモニタリングレベルを表します。例えば、1はレベル1の診断情報を表します |
| SAMPLE_PERCENTAGE | bigint(20) | NO | このセッションのエンドツーエンドトレースのサンプリング頻度を表します。例えば、50は診断情報を50%の確率でサンプリングすることを意味します |
| RECORD_POLICY | varchar(32) | NO | このセッションのエンドツーエンドトレースの記録ポリシーを表します。主に以下の3種類のポリシーをサポートしています：<ul><li>ALL：すべてのヒットサンプリングでトレースが有効な場合、そのトレースの打点情報をログファイルに出力し、各span終了時にログファイルに出力します。 </li><li>ONLY_SLOW_QUERY：すべてのヒットサンプリングでトレースが有効な場合、Slow Queryのリクエストトレースのみをログファイルに出力し、その他は破棄します。この出力ポリシーでは、トレースログの出力タイミングは、リクエストが終了してSlow Queryと判断された後です。Proxyでは、ルートspan、つまりトランザクションレベルのspanは、Slow Queryが検出された場合にのみ出力されます。 </li><li>SAMPLE_AND_SLOW_QUERY：すべてのヒットサンプリングでトレースが有効な場合、以下の条件を満たすトレースをログファイルに出力します：<ol><li>隠れパラメータ <code>_print_sample_ppm</code> を使用して万分の一の確率でサンプリングし、サンプリング結果が選択された場合にのみログに出力する場合</li><li>ONLY_SLOW_QUERYモードの出力条件を満たす場合</li></ol>このモードでは、ログの出力タイミングもspan終了時ではありません。条件1を満たす場合、クライアント側でそのトレースログが強制的に出力されるとマークされ、その情報は後続のリンクコンポーネントに渡されます。条件2を満たす場合、出力タイミングはONLY_SLOW_QUERYと同じです。</li></ul> |
