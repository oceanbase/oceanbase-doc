# V$LATCH

<main id="notice" type='explain'>
<h4>説明</h4>
<p>機能の調整により、このビューはデータを記録しなくなりました。ロック診断関連のデータは、<a href="../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/36600.v-system_event-of-sys-tenant.md">V$SYSTEM_EVENT</a> ビューおよび <a href="../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/30500.v-ob_active_session_history-of-sys-tenant.md">V$OB_ACTIVE_SESSION_HISTORY</a> ビューで確認できます。</p>
</main>

## 機能の概要

クラスタ内のすべてのOBServerノードのLATCH情報を表示するビューです。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | テナントID |
| SVR_IP | varchar(46) | NO | IPアドレス |
| SVR_PORT | bigint(20) | NO | ポート番号 |
| ADDR | varchar(256) | NO | 現在はNULL |
| LATCH# | bigint(20) | NO | latchが属するclassのインデックス |
| LEVEL# | bigint(20) | NO | latchが属するlevelのインデックス |
| NAME | varchar(256) | NO | latchの名前 |
| HASH | bigint(20) | NO | この値は現在0です |
| GETS | bigint(20) | NO | ロック成功回数 |
| MISSES | bigint(20) | NO | ロック待機回数 |
| SLEEPS | bigint(20) | NO | 合計yield回数 |
| IMMEDIATE_GETS | bigint(20) | NO | try_lock成功回数 |
| IMMEDIATE_MISSES | bigint(20) | NO | try_lock失敗回数 |
| SPIN_GETS | bigint(20) | NO | 合計spin回数 |
| WAIT_TIME | bigint(20) | NO | 待機sleep時間 |
