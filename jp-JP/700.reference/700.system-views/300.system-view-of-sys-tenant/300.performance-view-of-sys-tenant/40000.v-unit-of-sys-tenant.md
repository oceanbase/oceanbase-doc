# V$UNIT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.x系ではリソース管理機能のアーキテクチャが最適化されたため、このビューはV4.x系には適用されなくなり、V4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、ビュー<a href="../200.dictionary-view-of-sys-tenant/22900.o-dba_ob_units-of-sys-tenant.md">DBA_OB_UNITS</a>および<a href="34500.v-ob_units-of-sys-tenant.md">V$OB_UNITS</a>を使用してOBServerノードのUnit情報を照会できます。</li>
</ul>
</main>

## 機能の概要

ビュー`V$UNIT`は、現在のOBServerノード上のUnitのメタ情報を表示するために使用されます。
