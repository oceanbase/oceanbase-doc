# V$OB_ARBITRATION_MEMBER_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

このクラスタのアービトレーションメンバー情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| SVR_IP | varchar(46) | NO | アービトレーションサーバーIPアドレス |
| SVR_PORT | bigint(20) | NO | アービトレーションサーバーのポート番号 |
| PROPOSAL_ID | bigint(20) | NO | Paxos提案ID |
| CONFIG_VERSION | varchar(128) | NO | 構成情報バージョン番号 |
| ACCESS_MODE | varchar(32) | NO | アクセスモード |
| PAXOS_MEMBER_LIST | varchar(1024) | NO | メンバーリスト |
| PAXOS_REPLICA_NUM | bigint(20) | NO | 法定レプリカ数 |
| ARBITRATION_MEMBER | varchar(128) | NO | アービトレーションメンバー |
| DEGRADED_LIST | varchar(1024) | NO | ダウングレードされたレプリカのリスト |
