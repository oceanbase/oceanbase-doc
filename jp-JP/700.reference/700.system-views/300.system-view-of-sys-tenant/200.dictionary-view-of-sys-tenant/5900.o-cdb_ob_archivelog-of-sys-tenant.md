# oceanbase.CDB_OB_ARCHIVELOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナント内の各パスにおけるログアーカイブの状態を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| DEST_ID | bigint(20) | NO | パス識別子 |
| ROUND_ID | bigint(20) | NO | バックアップラウンド数を示す |
| INCARNATION | bigint(20) | NO | Flashback Database後の現在の分身回数を示す |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するために使用されます |
| STATUS | varchar(64) | NO | アーカイブ状態：<ul><li>`PREPARE`：アーカイブ開始ポイント `START_SCN` の準備中 </li> <li>`BEGINNING`：ログアーカイブの開始中 </li> <li>`DOING`：ログアーカイブ中 </li><li> `INTERRUPTED`：ログアーカイブが中断され、人為的介入が必要です </li><li>`STOP`：ログアーカイブが停止しました </li><li>`STOPPING`：ログアーカイブの停止中 </li><li>`SUSPENDING`：ログアーカイブが一時停止中 </li><li>`SUSPEND`：ログアーカイブが一時停止しました </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | バックアップ開始ポイント |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に変換した表示 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に変換した表示 |
| COMPATIBLE | bigint(20) | NO | 互換性バージョン |
| BASE_PIECE_ID | bigint(20) | NO | そのラウンドの最初のPIECE ID |
| USED_PIECE_ID | bigint(20) | NO | そのラウンドで使用済みのPIECE ID |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | Piece切り替え間隔 |
| UNIT_SIZE   | bigint(20)   | NO   | ログアーカイブデータの1回の圧縮または暗号化におけるログブロックサイズ。現在このフィールドはサポートされていません    |
| COMPRESSION | varchar(128) | NO   | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを示します </li><li> lz4_1.0：圧縮アルゴリズム lz4_1.0 を使用することを示します </li><li>zstd_1.3.8：圧縮アルゴリズム zstd_1.3.8を使用することを示します</li></ul>現在このフィールドはサポートされていません    |
| INPUT_BYTES | bigint(21) | NO | 読み取ったデータ量、単位はバイト|
| INPUT_BYTES_DISPLAY | varchar(28) | NO | INPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれかです|
| OUTPUT_BYTES | bigint(21) | NO | 出力データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(28) | NO | OUTPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれかです|
| COMPRESSION_RATIO | decimal(24,2) | NO | 圧縮率。現在このフィールドはサポートされていません  |
| DELETED_INPUT_BYTES | bigint(20) | NO | 削除された生データ量、単位はバイト |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_INPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれかです |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | 削除された有効データ量、単位はバイト |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_OUTPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれかです |
| COMMENT | varchar(262144) | NO | エラーメッセージを表示するために使用されます |
| PATH | varchar(2048) | NO | アーカイブパス |
