# oceanbase.DBA_OB_ARBITRATION_SERVICE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナントのみがアクセス可能で、現在のクラスタのアービトレーションサービス設定情報を表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | datetime | YES | ビュー作成日時 |
| MODIFY_TIME | datetime | YES | ビュー変更日時 |
| ARBITRATION_SERVICE_KEY | varchar(256) | NO | アービトレーションサービス名。現在デフォルトはDEFAULTです |
| ARBITRATION_SERVICE | varchar(512) | NO | アービトレーションサービスのURL |
| PREVIOUS_ARBITRATION_SERVICE | varchar(512) | YES | 値がある場合、現在のクラスタでアービトレーションサービスのURLが切り替えられていることを示します。この場合、`ARBITRATION_SERVICE` の値が新しいアービトレーションサービスのURLを、`PREVIOUS_ARBITRATION_SERVICE` が古いアービトレーションサービスのURLを表します。 |
| TYPE | varchar(64) | NO | アービトレーションサービスのタイプ。現在は `ADDR` のみサポートしています |

## クエリ例

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ARBITRATION_SERVICE;
```

クエリ結果は次のとおりです：

```shell
+---------------------+---------------------+-------------------------+---------------------+------------------------------+------+
| CREATE_TIME         | MODIFY_TIME         | ARBITRATION_SERVICE_KEY | ARBITRATION_SERVICE | PREVIOUS_ARBITRATION_SERVICE | TYPE |
+---------------------+---------------------+-------------------------+---------------------+------------------------------+------+
| 2023-06-26 19:30:19 | 2023-06-30 09:42:40 | default                 | xx.xx.xx.192:2882   |                              | ADDR |
+---------------------+---------------------+-------------------------+---------------------+------------------------------+------+
1 row in set
```
