# oceanbase.CDB_OB_RECOVER_TABLE_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルレベルの復元タスクに関する情報を表示します。テーブルの復元プロセス全体には、補助テナントの復元操作とテナント間のインポート操作が含まれます。このビューには2つのタスクレコードが対応しています：1つは`sys`テナントのタスクレコードで、もう1つは対象ユーザーテナント自身のタスクレコードです。ここで：

* `sys`テナントのタスクレコードは、主に対象ユーザーテナントのテーブルごとの復元進捗状況を記録します。対象テナントのテーブルごとの復元タスク全体が終了した場合、そのタスクは終了したことを意味します。

* 対象ユーザーテナント自身のタスクレコードには、補助テナントの復元進捗状況とテーブルインポートタスクの進捗状況が含まれます。補助テナントの復元タスクとテーブルのインポートタスクの両方が終了した場合、そのタスクは終了したことを意味します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | タスクテナントID |
| JOB_ID | bigint(20) | NO | タスクID |
| INITIATOR_TENANT_ID | bigint(20) | NO | 親タスクのテナントID |
| INITIATOR_JOB_ID | bigint(20) | NO | 親タスクが属するJOB ID |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時のテナント現在時刻 |
| FINISH_TIMESTAMP | timestamp(6) | NO | タスク完了時のテナント現在時刻 |
| STATUS | varchar(64) | NO | タスク状態。次のものが含まれます：<ul><li>PREPARE：タスク初期化段階  </li><li>RECOVERING：復元中 </li><li>RESTORE_AUX_TENANT：補助テナントの復元 </li><li>PRECHECK_IMPORT：インポート前チェック </li><li>GEN_IMPORT_JOB：インポートタスク初期化 </li><li>IMPORTING：テーブルインポート中 </li><li> CANCELING：タスクキャンセル中</li><li>COMPLETED：タスク完了 </li><li>FAILED：タスク失敗 </li></ul> |
| AUX_TENANT_NAME | varchar(64) | NO | 補助テナント名 |
| TARGET_TENANT_NAME | varchar(64) | NO | 対象テナント名 |
| IMPORT_ALL | tinyint(4) | NO | テナント内のすべてのテーブルをインポートするかどうかを示します。ユーザーが`RECOVER TABLE *.*`を指定した場合にのみ、この値は1になります。その他のシナリオでは値は0です |
| DB_LIST | longtext | YES | 完全に復元するデータベース |
| TABLE_LIST | longtext | YES | 復元するテーブル |
| RESTORE_SCN | bigint(20) unsigned | NO | ユーザーが指定した復元ポイント |
| RESTORE_SCN_DISPLAY | datetime(6) | NO | ユーザーが指定した復元ポイントのタイムスタンプ表現 |
| RESTORE_OPTION | varchar(4096) | NO | 補助テナントが依存するrestore_optionパラメータ |
| BACKUP_DEST | varchar(4096) | NO | バックアップおよびアーカイブパス |
| BACKUP_SET_LIST | longtext | NO | データバックアップパス |
| BACKUP_PIECE_LIST | longtext | NO | ログアーカイブパス |
| BACKUP_PASSWD | varchar(4096) | YES | バックアップセットのパスワード |
| EXTERNAL_KMS_INFO | varchar(4096) | YES | ソーステナントにキーマネジメントが設定されている場合、このパラメータをセッションで設定する必要があります。 |
| REMAP_DB_LIST | longtext | YES | 名前を変更したデータベース。形式は次のとおりです：`db1:new_db1, db2:newdb2` |
| REMAP_TABLE_LIST | longtext | YES | 名前を変更したテーブル。形式は次のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2` |
| REMAP_TABLEGROUP_LIST | longtext | YES | リマッピング対象のテーブルグループのリストです。テーブルを元のテーブルグループからターゲットのテーブルグループに再マッピングできます。形式は次のとおりです：`tg1:new_tg1, tg2:new_tg2` |
| REMAP_TABLESPACE_LIST | longtext | YES | リマッピング対象のテーブルスペースのリストです。テーブルを元のテーブルスペースからターゲットのテーブルスペースに再マッピングできます。形式は次のとおりです：`ts1:new_ts1, ts2:new_ts2` |
| RESULT | varchar(64) | YES | テーブルレベル復元タスクの結果：<ul><li>SUCCESS  </li><li>FAIL </li></ul> |
| COMMENT | longtext | YES | 備考情報 |
| DESCRIPTION | longtext | YES | 復元コマンドで指定されたDESCRIPTION情報 |
