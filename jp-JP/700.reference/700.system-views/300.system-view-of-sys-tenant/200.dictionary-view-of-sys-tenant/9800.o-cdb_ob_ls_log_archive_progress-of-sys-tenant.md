# oceanbase.CDB_OB_LS_LOG_ARCHIVE_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのログストリームアーカイブ進捗状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)   | NO | テナントID |
| DEST_ID | bigint(20)   | NO | アーカイブ先エンドID |
| LS_ID | bigint(20)   | NO | ログストリームID |
| ROUND_ID | bigint(20)   | NO | ログストリームラウンドID |
| PIECE_ID | bigint(20)  | NO | 最新Piece ID |
| INCARNATION | bigint(20) | NO | 分身ID |
| START_SCN | bigint(20) unsigned | NO | アーカイブ開始SCN |
| MIN_LSN | bigint(20) unsigned | NO | 現在のPieceログストリームの最小LSN |
| MAX_LSN | bigint(20) unsigned | NO | 現在のPieceログストリームの最大LSN |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のPieceログストリームの最大アーカイブ進捗 |
| STATUS | varchar(64)  | NO | テナントアーカイブ状態：<ul><li> PREPARE：アーカイブ開始時の初期状態 </li><li>BEGINNING：アーカイブ開始の基本チェックが終了し、この状態に入る </li><li> DOING：通常のアーカイブ状態 </li><li> INTERRUPTED：アーカイブが中断し、続行できない状態 </li><li> STOPPING：アーカイブ停止を開始し、この状態に入る</li><li>STOP：アーカイブ停止状態 </li><li> SUSPENDING：アーカイブが一時停止状態に入った場合 </li><li> SUSPEND：アーカイブが一時停止状態 </li></ul>|
| FILE_ID  | bigint(20)  | NO | 現在のPieceの最大アーカイブファイルID |
| FILE_OFFSET  | bigint(20)  | NO | 現在のPieceの最大アーカイブファイルOFFSET |
| INPUT_BYTES  | bigint(20)  | NO | 読み取ったログデータ量 |
| OUTPUT_BYTES   | bigint(20)  | NO | アーカイブされたログデータ量 |
