# oceanbase.CDB_OB_VECTOR_INDEX_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_VECTOR_INDEX_TASKS` は、クラスタ内のすべてのテナントにおけるすべてのベクトルインデックスパーティションの再構築タスク情報を表示します。

## フィールド説明

| フィールド名                   | フィールドタイプ      | NULL許容 | 説明 |
|---------------------------|---------------|------|----|
| TENANT_ID	                | bigint(20)	| YES   | テナントID |
| TABLE_ID	                | bigint(20)	| YES   | テーブルID |
| TABLET_ID	                | bigint(20)	| YES   | パーティションID |
| TASK_ID	                | bigint(20)	| YES   | タスクID |
| START_TIME	                | timestamp(6)	| YES   | タスク開始時間 |
| MODIFY_TIME	                | timestamp(6)	| YES   | タスク終了時間 |
| TRIGGER_TYPE	                | varchar(16)	| NO   | タスクのトリガータイプ：<ul><li><code>0</code>：自動トリガー</li><li><code>1</code>：手動トリガー</li></ul> |
| STATUS	                | varchar(16)	| NO   | タスクの状態：<ul><li><code>0</code>：タスク準備中</li><li><code>1</code>：タスク実行中</li><li><code>2</code>：タスク一時停止</li><li><code>3</code>：タスク終了</li></ul> |
| TASK_TYPE	                | bigint(20)	| NO   | タスクタイプ：<ul><li><code>0</code>：非同期構築</li><li><code>1</code>：インデックスパーティション再構築</li></ul>      | |
| TASK_SCN	                | bigint(20)	| NO   | タスクバージョン番号 |
| RET_CODE	                | bigint(20)	| NO   | タスク終了時の状態：<ul><li><code>0</code>：成功</li><li><code>非0</code>：失敗</li></ul> |
| TRACE_ID	                | varchar(512)	| NO   | タスク実行追跡ID |
| PROGRESS_INFO	                | varchar(512)	| NO   | タスクの実行進捗情報をJSON形式で表示します。通常は現在の操作、推定行数、完了行数、完了率、推定残り時間などが含まれます。この情報は10秒ごとに更新されます。Json文字列で、status、estimated_row、finished_row、progress、time_remaining(s)フィールドを含みます：<ul><li><code>status</code>：タスクの状態。<code>preparing</code>、<code>inserting vectors</code>、<code>serializing snap index</code>、<code>replacing old index</code>の4種類があります。</li> <li><code>estimated_row</code>：挿入予定の行数</li> <li><code>finished_row</code>：挿入済みの行数</li> <li><code>progress</code>：完了進捗率の割合</li> <li><code>time_remaining(s)</code>：推定残り時間</li></ul> |
