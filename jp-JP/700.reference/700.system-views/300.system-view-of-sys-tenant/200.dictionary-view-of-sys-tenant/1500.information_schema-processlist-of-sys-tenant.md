# information_schema.PROCESSLIST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

実行中のスレッド情報を提供します。

## フィールドの説明

| **フィールド名** |       **型**        | **NULL許容** |    **説明**    |
|----------|---------------------|----------------|--------------|
| ID       | bigint(20) unsigned | NO             | 接続識別子<ul><li>直接接続モードの場合：<br>このフィールドはサーバーセッションIDを表します。</li> <li>ODPモードの場合：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはクライアントセッションIDを表します。 </li> <li> <code>client_session_id_version = 1</code> の場合、このフィールドはサーバーセッションIDを表します。</li></ul></ul>        |
| USER     | varchar(32)         | NO             | ユーザー名          |
| HOST     | varchar(128)        | NO             | クライアントホスト名      |
| DB       | varchar(128)        | YES            | データベース名        |
| COMMAND  | varchar(4096)       | NO             | スレッドが実行するコマンドタイプ    |
| TIME     | bigint(20)          | NO             | スレッドが現在の状態にある時間、単位は秒 |
| STATE    | varchar(128)        | YES            | スレッドが実行しているタスクを示す識別子 |
| INFO     | varchar(262143)     | YES            | 現在のスレッドが実行している文  |

## クエリ例

システムテナントで実行中のすべてのスレッド情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```

