# oceanbase.CDB_OB_LS_REPLICA_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `CDB_OB_LS_REPLICA_TASK_HISTORY` は、すべてのテナントのディザスタリカバリタスクの実行履歴を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID                    | &#124;bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| TASK_TYPE | varchar(64) | NO | タスクタイプ。次の値を取ります。<ul><li>`MIGRATE REPLICA`：レプリカの移行</li><li>`ADD REPLICA`：レプリカの追加</li><li>`TYPE TRANSFORM`：レプリカタイプの変換</li><li>`REMOVE PAXOS REPLICA`：Paxosメンバーレプリカの削除</li><li>`REMOVE NON PAXOS REPLICA`：非Paxosメンバーレプリカの削除</li><li>`MODIFY PAXOS REPLICA NUMBER`：法定レプリカ数の変更</li></ul>|
| TASK_ID | varchar(200) | NO | タスクID |
| TASK_STATUS | varchar(2048) | YES | タスクのステータス。次の値を取ります。<ul><li>`INPROGRESS`：スケジュール実行中</li><li>`COMPLETED`：タスク完了</li><li>`CANCELED` ：タスクキャンセル</li></ul>|
| PRIORITY | varchar(5) | NO | タスクの優先度。次の値を取ります：<ul><li>`LOW`：低優先度のタスク</li><li>`HIGH`：高優先度のタスク</li></ul>|
| TARGET_REPLICA_SVR_IP | varchar(46) | YES | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT | bigint(20) | YES | ターゲットレプリカが存在するマシンのポート |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20) | YES | ログストリームのターゲット法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE | varchar(16) | YES | ターゲットレプリカタイプ |
| SOURCE_REPLICA_SVR_IP | varchar(46) | YES | ソースレプリカが存在するマシンのIPアドレス |
| SOURCE_REPLICA_SVR_PORT | bigint(20) | YES | ソースレプリカが存在するマシンのポート |
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20) | YES | ログストリームの元法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE | varchar(16) | YES | ソースレプリカタイプ |
| DATA_SOURCE_SVR_IP | varchar(46) | YES | データソースのIPアドレス |
| DATA_SOURCE_SVR_PORT | bigint(20) | YES | データソースのポート |
| IS_MANUAL | varchar(6) | NO | 災害復旧タスクの出所。次の値を取ります：<ul><li>`TRUE`：手動運用コマンドによってトリガーされた災害復旧タスクを示します</li><li>`FALSE`：デフォルト値で、RS層の災害復旧によって自動生成された災害復旧タスクを示します</li></ul>|
| TASK_EXEC_SVR_IP | varchar(46) | YES | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT | bigint(20) | YES | タスク実行マシンのポート |
| CREATE_TIME | datetime | NO | タスク生成時間 |
| START_TIME | datetime | NO | タスクスケジュール時間 |
| MODIFY_TIME | datetime | NO | タスクステータス更新時間 |
| FINISH_TIME | datetime | NO | タスク終了時間 |
| EXECUTE_RESULT | varchar(2048) | YES | タスク実行結果 |
| COMMENT | varchar(2048) | YES | タスク生成理由の備考 |
| CONFIG_VERSION         | varchar(128)   | YES                | ディザスタリカバリタスク実行時のclog層のconfig_version情報を記録します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0バージョンから導入されました。</p></main>  |
