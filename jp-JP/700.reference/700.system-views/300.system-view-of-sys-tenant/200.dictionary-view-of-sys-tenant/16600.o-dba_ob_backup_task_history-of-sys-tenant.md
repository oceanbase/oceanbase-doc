# oceanbase.DBA_OB_BACKUP_TASK_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント自身のタスクレベルのバックアップタスクの履歴を表示します。`sys` テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名 | フィールド名 | フィールド名 | フィールド名 |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | タスクレベルのバックアップタスクID。1つのバックアップセットに対応するタスクを表します。 |
| JOB_ID | bigint(20) | NO | このタスクが属するJOB_ID |
| INCARNATION | bigint(20) | NO | Flashback Database後の何回目の化身を表します |
| BACKUP_SET_ID | bigint(20) | NO | このタスクに対応するバックアップセットID |
| START_TIMESTAMP | timestamp(6) | NO | タスクの開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | タスクの終了時間 |
| STATUS | varchar(4096) | NO | バックアップの状態 |
| START_SCN | bigint(20) unsigned | NO | バックアップ開始時のSCN |
| END_SCN | bigint(20) unsigned | NO | バックアップ終了時のSCN |
| USER_LS_START_SCN | bigint(20) unsigned | NO | バックアップログストリームMETAのSCN |
| ENCRYPTION_MODE | varchar(4096) | YES | 暗号化モード：<br>None：暗号化しないことを表します<br>Password：パスワードのみで保護することを表します<br>Password Encryption：暗号化し、パスワードで保護することを表します<br>Transparent Encryption：TDE暗号化を使用することを表します<br>Dual mode Encryption：TDE暗号化およびパスワード保護を使用することを表します<br>現在はNoneとPasswordの2種類のモードのみサポートしています |
| PASSWD | varchar(4096) | YES | パスワード |
| INPUT_BYTES | bigint(20) | YES | 入力バイト数 |
| OUTPUT_BYTES | bigint(20) | YES | 出力バイト数 |
| OUTPUT_RATE_BYTES | decimal(28,4) | NO | 毎秒出力バイト数 |
| EXTRA_META_BYTES | bigint(20) | YES | 追加バイト数 |
| TABLET_COUNT | bigint(20) | YES | TABLETの総数 |
| FINISH_TABLET_COUNT | bigint(20) | YES | バックアップ完了のTABLETの総数 |
| MACRO_BLOCK_COUNT | bigint(20) | YES | マクロブロック数 |
| FINISH_macro_BLOCK_COUNT | bigint(20) | YES | バックアップ完了のマクロブロック数 |
| FILE_COUNT | bigint(20) | YES | バックアップファイル数 |
| META_TURN_ID | bigint(20) | YES | バックアップMETAのラウンド |
| DATA_TURN_ID | bigint(20) | YES | バックアップDATAのラウンド |
| RESULT | bigint(20) | YES | バックアップエラーコード結果 |
| COMMENT | varchar(4096) | YES | エラーコードの説明 |
| PATH | varchar(4096) | YES | バックアップパス |
| MINOR_TURN_ID                 | bigint(20)     | NO              | ダンプデータバックアップ終了のラウンド      |
| MAJOR_TURN_ID                 | bigint(20)     | NO              | ベースラインデータバックアップ終了のラウンド      |
