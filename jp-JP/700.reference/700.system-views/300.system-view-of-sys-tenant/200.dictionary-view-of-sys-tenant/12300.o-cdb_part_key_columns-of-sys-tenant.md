# oceanbase.CDB_PART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのパーティションオブジェクト（パーティションテーブル、パーティションインデックス）のパーティションキーに含まれる列を表示します。

## フィールドの説明

|      **フィールド名**      |    **タイプ**     | **NULL許容** |                                                              **説明**                                                              |
|--------------------|---------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| CON_ID             | bigint(20)    | NO             | テナントID                                         |
| OWNER              | varchar(128)  | NO             | パーティションテーブルまたはパーティションインデックスの所有者                                  |
| NAME               | varchar(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前                                   |
| OBJECT_TYPE        | varchar(5)    | NO             | パーティションオブジェクトのタイプ：<ul><li>TABLE   </li><li> INDEX </li></ul>   |
| COLUMN_NAME        | text          | NO             | 列名                                              |
| COLUMN_POSITION    | bigint(20)    | NO             | 列がパーティションキー内で占める位置                                     |
| COLLATED_COLUMN_ID | bigint(0)    | NO             | 現在このフィールドはサポートされていません。現在のデフォルト値はNULLです。                       |

## クエリ例

システムテナント内で、テナントIDが1002のテナントのパーティションテーブル`tbl2_f_rl`のパーティションキーに含まれる列を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_PART_KEY_COLUMNS WHERE CON_ID=1002 AND NAME='tbl2_f_rl';
```

クエリ結果は次のとおりです：

```shell
+--------+----------+-----------+-------------+-------------+-----------------+--------------------+
| CON_ID | OWNER    | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+--------+----------+-----------+-------------+-------------+-----------------+--------------------+
|   1002 | infotest | tbl2_f_rl | TABLE       | col1        |               1 |               NULL |
+--------+----------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
