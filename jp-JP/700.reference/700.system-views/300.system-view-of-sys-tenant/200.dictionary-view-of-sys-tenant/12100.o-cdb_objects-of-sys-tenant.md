# oceanbase.CDB_OBJECTS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OBJECTS` は、すべてのテナントのオブジェクト情報を表示するために使用されます。

## フィールドの説明

|       フィールド名        |      型      | NULL許容 |              説明               |
|-------------------|--------------|------------|-------------------------------|
| CON_ID            | bigint(20)   | NO         | テナントID  |
| OWNER             | varchar(128) | NO         | オブジェクトが属する所有者                      |
| OBJECT_NAME       | varchar(128) | NO         | オブジェクト名                          |
| SUBOBJECT_NAME    | varchar(128) | NO         | サブオブジェクト名（例：partition）           |
| OBJECT_ID         | bigint(20)   | NO         | オブジェクトのディクショナリID値                    |
| DATA_OBJECT_ID    | bigint(20)   | NO         | そのオブジェクトSegmentを含むディクショナリID値         |
| OBJECT_TYPE       | varchar(23)  | NO         | オブジェクトタイプ。テーブル、インデックス、パーティション、パッケージ、ストアドプロシージャ、シノニム、シーケンスなどを含む |
| CREATED           | datetime     | NO         | オブジェクト作成時刻                        |
| LAST_DDL_TIME     | datetime     | NO         | オブジェクトの最終DDL実行時刻                 |
| TIMESTAMP         | datetime     | NO         | オブジェクト指定のタイムスタンプ。文字列で出力              |
| STATUS            | varchar(7)   | NO         | オブジェクト状態： VALID INVALID           |
| TEMPORARY         | varchar(1)   | NO         | そのオブジェクトが一時オブジェクトであることを示す                  |
| GENERATED         | varchar(1)   | NO         | オブジェクト名がシステム生成かどうかを示す              |
| SECONDARY         | varchar(1)   | NO         | 現在このフィールドは未使用                     |
| NAMESPACE         | bigint(20)   | NO         | オブジェクトの名前空間                       |
| EDITION_NAME      | varchar(128) | NO         | 予約語フィールド                          |
| SHARING           | varchar(18)  | NO         | デフォルト値は `NULL`                              |
| EDITIONABLE       | varchar(1)   | NO         | デフォルト値は `NULL`         |
| ORACLE_MAINTAINED | varchar(1)   | NO         | デフォルト値は `NULL`      |
| APPLICATION       | varchar(1)   | NO         | デフォルト値は `NULL`            |
| DEFAULT_COLLATION | varchar(1)   | NO         | デフォルト値は `NULL`                              |
| DUPLICATED        | varchar(1)   | NO         | デフォルト値は `NULL`         |
| SHARDED           | varchar(1)   | NO         | デフォルト値は `NULL`                            |
| IMPORTED_OBJECT   | varchar(1)   | NO         | デフォルト値は `NULL`                              |
| CREATED_APPID     | bigint(0)    | NO         | デフォルト値は `NULL`       |
| CREATED_VSNID     | bigint(0)    | NO         | デフォルト値は `NULL`          |
| MODIFIED_APPID    | bigint(0)    | NO         | デフォルト値は`NULL`です       |
| MODIFIED_VSNID    | bigint(0)    | NO         | デフォルト値は`NULL`です      |
