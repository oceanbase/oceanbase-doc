# oceanbase.DBA_PART_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのパーティションテーブルの列統計情報とヒストグラム情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | パーティションテーブルの所有者 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| PARTITION_NAME | varchar(128) | NO | テーブルパーティション名 |
| COLUMN_NAME | varchar(128) | NO | 列名 |
| NUM_DISTINCT | decimal(10,0) | NO | 列内の異なる値の数 |
| LOW_VALUE | varchar(128) | NO | 列の最小値 |
| HIGH_VALUE | varchar(128) | NO | 列の最大値 |
| DENSITY | decimal(10,0) | NO | 列の密度。`COLUMN_NAME` でヒストグラムが利用可能な場合、この列はヒストグラム上の2つより少ない端点をまたぐ値の選択性を示します。2つ以上の端点をまたぐ値の選択性を表すものではありません。`COLUMN_NAME` でヒストグラムが利用できない場合、この列の値は `1 / NUM_DISTINCT` となります |
| NUM_NULLS | decimal(10,0) | NO | 列内のNULL値の数 |
| NUM_BUCKETS | decimal(10,0) | NO | 列ヒストグラムのバケット数 |
| LAST_ANALYZED | datetime(6) | NO | この列を最後に分析した日付 |
| SAMPLE_SIZE | decimal(10,0) | NO | この列を分析する際のサンプリングサイズ |
| GLOBAL_STATS | varchar(3) | NO | 統計情報が収集されたかどうかを示します：<ul><li>YES：収集済み</li><li>NO：サブパーティションから集計されていない、または収集されていない</li></ul> |
| NOTES | varchar(80) | NO | 統計情報の追加プロパティを説明します：<ul><li>INCREMENTAL：この列にはサマリーがあることを示します</li><li>INCREMENTAL(HLL)：この列にはサマリーがあり、サマリーはhyperloglog形式を使用していることを示します</li><li>INCREMENTAL(SAMPLING)：この列にはサマリーがあり、サマリーは適応型サンプリング形式を使用していることを示します</li></ul><br>この列は、適応型サンプリング形式のサマリーが完全に廃棄され、正しくクリーンアップされたかどうかを判断するために使用できます |
| AVG_COL_LEN | decimal(10,0) | NO | 列の平均長（バイト単位） |
| HISTOGRAM | varchar(15) | NO | ヒストグラムのタイプを示します：<ul><li>NONE</li><li>FREQUENCY</li><li>HEIGHT BALANCED</li><li>HYBRID</li><li>TOP-FREQUENCY</li></ul> |

## 関連するビューまたはドキュメント

* テーブルレベルの列統計情報を表示するには、[DBA_TAB_STATISTICS](25800.o-dba_tab_statistics-of-sys-tenant.md)参照してください。

* グローバルレベルの列統計情報を表示するには、[DBA_TAB_COL_STATISTICS](25400.o-dba_tab_col_statistics-of-sys-tenant.md)参照してください。

* Subpartitionレベルの列統計情報を表示するには、[DBA_SUBPART_COL_STATISTICS](25000.o-dba_subpart_col_statistics-of-sys-tenant.md)参照してください。

* テーブルレベルのヒストグラム統計情報を表示するには、[DBA_TAB_HISTOGRAMS](25500.o-dba_tab_histograms-of-sys-tenant.md)参照してください。

* Partitionレベルのヒストグラム統計情報を表示するには、[DBA_PART_HISTOGRAMS](23600.o-dba_part_histograms-of-sys-tenant.md)参照してください。

* Subpartitionレベルのヒストグラム統計情報を表示するには、[DBA_SUBPART_HISTOGRAMS](25100.o-dba_subpart_histograms-of-sys-tenant.md)参照してください。

* インデックス統計情報を表示するには、[DBA_IND_STATISTICS](14400.o-dba_ind_statistics-of-sys-tenant.md)参照してください。

* 統計情報の収集方法については、次のドキュメントを参照してください。

  * [自動で統計情報を収集する](../../../1000.performance-tuning-guide/500.sql-optimization/400.sql-optimization/400.optimizer-statistics/200.statistics-collection-methods/400.collect-statistics-automatically.md)
