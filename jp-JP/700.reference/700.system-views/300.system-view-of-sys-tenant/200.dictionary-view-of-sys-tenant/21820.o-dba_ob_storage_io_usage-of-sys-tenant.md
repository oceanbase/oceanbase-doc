# oceanbase.DBA_OB_STORAGE_IO_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのオブジェクトストレージおよびクラウドディスクの各種I/O操作状況を表示します。

## フィールドの説明

| フィールド名   | 型          | NULL許容 | 説明                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | bigint(20)    | NO   | テナントID     |
| PATH      | varchar(1024) | NO   | `oss://`、`file://`、`s3://` などの形式を指定します    |
| ENDPOINT  | varchar(256)  | NO   | バックアップ・リストア、データインポート、データエクスポートのオブジェクトストレージのEndpointを表示します。 |
| TYPE      | varchar(128)  | NO   | 操作タイプ：<ul><li>`READ`：読み取りタイプ</li> <li>`WRITE`：書き込みタイプ</li> <li>`READ_BYTES`：オブジェクトストレージのネットワーク入口トラフィック</li> <li>`WRITE_BYTES`：オブジェクトストレージのネットワーク出口トラフィック</li> <li>`TAG`：オブジェクトストレージ内のタグタイプ。ローカルディスクとクラウドディスクにはこのタイプは表示されません</li></ul>     |
| TOTAL     | bigint(20)    | NO   | 各タイプ (`TYPE`) に対応する累計値：<ul><li>`READ`：読み取りタイプ関連操作の回数の累計</li> <li>`WRITE`：書き込みタイプ関連操作の回数の累計</li> <li>`READ_BYTES`：オブジェクトストレージのネットワーク入口トラフィックの合計、単位はバイト</li> <li>`WRITE_BYTES`：オブジェクトストレージのネットワーク出口トラフィックの合計、単位はバイト</li> <li>`TAG`：オブジェクトストレージ内のタグタイプの累計値。ローカルディスクとクラウドディスクにはこの統計項目は表示されません</li></ul>      |
