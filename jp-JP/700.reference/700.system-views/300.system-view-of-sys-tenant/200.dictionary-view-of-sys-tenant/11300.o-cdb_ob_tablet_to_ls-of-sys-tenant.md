# oceanbase.CDB_OB_TABLET_TO_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下において、すべてのテナントのTabletリストおよび各Tabletが属するログストリーム情報を表示します。

## フィールドの説明

|   フィールド名    |     型     | NULL許容   |        説明        |
|-----------|------------|------------|------------------|
| TENANT_ID | bigint(20) | NO         | テナントID            |
| TABLET_ID | bigint(20) | NO         | TABLET ID        |
| LS_ID     | bigint(1)  | NO         | TABLETが属するログストリームID |

## クエリ例

システムテナントで、テナントIDが1002のテナントのログストリーム1001番のTabletリスト情報を照会し、最初の5件の情報を表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLET_TO_LS WHERE TENANT_ID=1002 AND LS_ID=1001 LIMIT 5;
```

クエリ結果は次のとおりです：

```shell
+-----------+-----------+-------+
| TENANT_ID | TABLET_ID | LS_ID |
+-----------+-----------+-------+
|      1002 |    200004 |  1001 |
|      1002 |    200005 |  1001 |
|      1002 |    200007 |  1001 |
|      1002 |    200008 |  1001 |
|      1002 |    200009 |  1001 |
+-----------+-----------+-------+
5 rows in set
```
