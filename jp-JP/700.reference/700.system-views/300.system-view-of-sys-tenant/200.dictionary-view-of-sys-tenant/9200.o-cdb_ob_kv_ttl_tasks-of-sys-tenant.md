# oceanbase.CDB_OB_KV_TTL_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.1.4バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下で、すべてのテナントが実行中のTTLタスクを確認できます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)  | NO | テナントID |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TABLE_ID | bigint(20) | NO | テーブルID |
| TABLET_ID | bigint(20) | NO | Tablet ID |
| TASK_ID | bigint(20) | NO | タスクID。1から開始します。 |
| START_TIME | timestamp(6) | NO | タスクの開始時間 |
| END_TIME | timestamp(6) | NO | タスクの終了時間 |
| TRIGGER_TYPE | varchar(8) | NO | タスクのトリガータイプ。PERIODICとUSERの2種類があります。 |
| STATUS | varchar(13) | NO | タスクの現在の状態 |
| TTL_DEL_CNT | bigint(20) | NO | `time_to_live`に基づいて削除されたレコード数 |
| MAX_VERSION_DEL_CNT | bigint(20) | NO | `MAX_VERSION`に基づいて削除されたレコード数 |
| SCAN_CNT | bigint(20) | NO | タスクでスキャンされたレコード数 |
| RET_CODE | varchar(512) | NO | タスクの戻りコード |
