# oceanbase.CDB_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下におけるすべてのテナントのテーブルグループのメタ情報を表示します。主にテーブルグループのパーティション情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.0バージョン以降、このビュー内のパーティション属性フィールドは意味を持たなくなり、統一して <code>NONE</code> または </code>NULL</code> と表示されます。</p>
</main>

## フィールドの説明

|           フィールド名            |      型      | NULL許容 |            説明            |
|---------------------------|--------------|------------|-------------------------------------|
| TENANT_ID                 | bigint(20)   | NO         | テナントID                    |
| TABLEGROUP_NAME           | varchar(128) | NO         | テーブルグループ名                      |
| PARTITIONING_TYPE         | varchar(13)  | NO         | パーティションのテーブルグループのサブパーティションのパーティションタイプ：<ul><li>`NONE`：非パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョン以降、値は <code>NULL</code> です</p></main>            |
| SUBPARTITIONING_TYPE      | varchar(13)  | NO         | パーティションのテーブルグループのサブパーティションのサブパーティションタイプ：<ul><li>`NONE`：非パーティションテーブルグループ、パーティションテーブルグループ   </li><li> `HASH`：HASHパーティション（単一パーティションキー）   </li><li> `KEY`：KEYパーティション   </li><li> `RANGE`：RANGEパーティション（単一パーティションキー）   </li><li> `RANGE COLUMNS`：RANGE COLUMNSパーティション   </li><li> `LIST`：LISTパーティション（単一パーティションキー）   </li><li> `LIST COLUMNS`：LIST COLUMNSパーティション   </li><li> `UNKNOWN`：異常タイプ</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョン以降、値は <code>NULL</code> です</p></main>     |
| PARTITION_COUNT           | bigint(0)   | NO         | この値は `NULL`            |
| DEF_SUBPARTITION_COUNT    | bigint(0)    | NO         | この値は `NULL`            |
| PARTITIONING_KEY_COUNT    | bigint(0)   | NO         | この値は `NULL`            |
| SUBPARTITIONING_KEY_COUNT | bigint(0)   | NO         | この値は `NULL`            |
| SHARDING                  | varchar(20)  | NO         | テーブルグループのSHARDING属性。取り得る値は以下の通りです：<ul><li>`NONE`：この属性を持つテーブルグループでは、テーブルグループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、テーブルグループへのテーブルの追加に制限はありません。</li> <li>`PARTITION`：この属性を持つテーブルグループでは、テーブルグループ内の各テーブルのデータがパーティション単位で分散されます。サブパーティションテーブルの場合、パーティション内のすべてのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：この属性を持つテーブルグループでは、テーブルグループ内の各テーブルのデータが適応型方式で分散されます。つまり、テーブルグループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散されます。</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| SCOPE                     | varchar(20)  | NO         | テーブルグループの `SCOPE` 属性。取り得る値は以下の通りです：<ul><li>`SERVER`：すべてのパーティショングループのリーダーが同一ノード上に配置されていることを示します。 </li><li>`ZONE`：すべてのパーティショングループのリーダーが同一ゾーン内に配置され、ゾーン内の各ノードに分散されていることを示します。 </li><li>`CLUSTER`：すべてのパーティショングループのリーダーがクラスタ内の各ノードに分散されていることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>|

## クエリ例

テーブルグループ `tblgroup1` の属性を確認します。

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TABLEGROUPS
    WHERE tablegroup_name = 'tblgroup1'
    LIMIT 1\G
```

実行結果は次のとおりです：

```shell
*************************** 1. row ***************************
                TENANT_ID: 1002
          TABLEGROUP_NAME: tblgroup1
        PARTITIONING_TYPE: NONE
     SUBPARTITIONING_TYPE: NONE
          PARTITION_COUNT: NULL
   DEF_SUBPARTITION_COUNT: NULL
   PARTITIONING_KEY_COUNT: NULL
SUBPARTITIONING_KEY_COUNT: NULL
                 SHARDING: NONE
                    SCOPE: ZONE
1 row in set
```
