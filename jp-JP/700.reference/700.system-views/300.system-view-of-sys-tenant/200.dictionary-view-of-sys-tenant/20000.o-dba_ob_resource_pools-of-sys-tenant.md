# oceanbase.DBA_OB_RESOURCE_POOLS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのリソースプール情報を表示します。

## フィールドの説明

|     フィールド名     |       タイプ       | NULL値を許容するか |                                                                          説明                                                                           |
|--------------|----------------|------------|-------------------------------------|
| RESOURCE_POOL_ID | bigint(20)    | NO  | リソースプールの一意のID                                                                              |
| NAME             | varchar(128)  | NO  | リソースプール名                                                                                 |
| TENANT_ID        | bigint(20)    | NO  | テナントID：<ul><li>`NULL`：どのテナントにも属していないことを示す   </li><li>有効な値：所属するテナントIDを示す </li></ul> |
| CREATE_TIME      | timestamp(6)  | YES | 作成時間          |
| MODIFY_TIME      | timestamp(6)  | YES | 最後の変更時間        |
| UNIT_COUNT       | bigint(20)    | NO  | ユニット数       |
| UNIT_CONFIG_ID   | bigint(20)    | NO  | リソースプールのリソース仕様ID   |
| ZONE_LIST        | varchar(8192) | NO  | リソースプールのゾーンリスト  |
| REPLICA_TYPE     | varchar(18)   | NO  | リソースプールがサポートするレプリカタイプ：<ul><li> `FULL`：フル機能タイプのレプリカに限らず、すべてのレプリカタイプをサポートします  </li><li> `READONLY`：読み取り専用レプリカのみをサポートします   </li> <li> `NULL`：不明なレプリカタイプ </li></ul>   |
