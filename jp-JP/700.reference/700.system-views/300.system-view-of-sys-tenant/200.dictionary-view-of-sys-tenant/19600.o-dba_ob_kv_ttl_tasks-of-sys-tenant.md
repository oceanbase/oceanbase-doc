# oceanbase.DBA_OB_KV_TTL_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.1.4バージョンから導入されました。</p>
</main>

## 機能の概要

現在、テナントで実行中のTTLタスクを表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TABLE_ID | bigint(20) | NO | テーブルID |
| TABLET_ID | bigint(20) | NO | Tablet ID |
| TASK_ID | bigint(20) | NO | タスクID（1から開始） |
| START_TIME | timestamp(6) | NO | タスク開始時間 |
| END_TIME | timestamp(6) | NO | タスク終了時間 |
| TRIGGER_TYPE | varchar(8) | NO | タスクのトリガータイプ。PERIODICとUSERの2種類があります |
| STATUS | varchar(13) | NO | タスクの現在の状態 |
| TTL_DEL_CNT | bigint(20) | NO | `time_to_live`に基づいて削除されたレコード数 |
| MAX_VERSION_DEL_CNT | bigint(20) | NO | `MAX_VERSION`に基づいて削除されたレコード数 |
| SCAN_CNT | bigint(20) | NO | タスクでスキャンしたレコード数 |
| RET_CODE | varchar(512) | NO | タスクの戻りコード |
| TASK_TYPE | varchar(12) | NO | TTLタスクのタイプ。NORMALとHBASE ROWKEYの2種類があります。現在、HBASE ROWKEYタイプはOBKV-HBaseでのみサポートされています |
| SCAN_INDEX | varchar(128) | NO | タスクでスキャンに使用されるインデックス。デフォルトはPRIMARY KEY |
