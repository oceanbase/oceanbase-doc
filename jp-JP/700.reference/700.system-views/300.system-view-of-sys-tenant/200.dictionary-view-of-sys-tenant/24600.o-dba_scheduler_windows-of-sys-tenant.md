# oceanbase.DBA_SCHEDULER_WINDOWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのスケジューラーウィンドウの情報を表示します。

## フィールドの説明

| フィールド名          | タイプ          | NULLを許容するか | 説明              |
|------------------|---------------|----------------|-------------------|
| OWNER            | varchar(128)  | NO   | スケジューラーウィンドウの所有者    |
| WINDOW_NAME      | varchar(128)  | NO   | スケジューラーウィンドウの名前  |
| RESOURCE_PLAN    | varchar(128)  | NO   | ウィンドウに関連付けられたリソース計画。現在、このフィールドは使用されていません   |
| SCHEDULE_OWNER   | varchar(4000) | NO   | ウィンドウスケジュールの所有者。現在、このフィールドは使用されていません   |
| SCHEDULE_NAME    | varchar(4000) | NO   | ウィンドウのスケジュール名。現在、このフィールドは使用されていません   |
| SCHEDULE_TYPE    | varchar(8)    | NO   | ウィンドウ計画タイプ：<ul><li>ONCE：繰り返し間隔はNULL</li><li>NAMED：命名スケジュール</li><li>CALENDAR：スケジュールとして使用されるカレンダー式</li></ul></br>現在、このフィールドは使用されていません。 |
| START_DATE       | datetime(6)   | YES  | ウィンドウ開始日（インライン計画の場合）   |
| REPEAT_INTERVAL  | varchar(4000) | YES  | ウィンドウの周期間隔時間|
| END_DATE         | datetime(6)   | YES  | ウィンドウの終了時間   |
| DURATION         | bigint(20)    | YES  | ウィンドウの持続時間    |
| WINDOW_PRIORITY  | varchar(4)    | NO   | ジョブの他のウィンドウに対する優先順位：<ul><li>HIGH</li><li>LOW</li></ul> </br>現在、このフィールドは使用されていません。|
| NEXT_RUN_DATE    | datetime(6)   | NO   | ウィンドウの次回開始時刻   |
| LAST_START_DATE  | datetime(6)   | YES  | 最後にウィンドウが開始された時刻   |
| ENABLED          | varchar(5)    | YES  | ウィンドウが有効(TRUE)か無効(FALSE)かを示します    |
| ACTIVE           | varchar(5)    | NO   | ウィンドウが開いている(TRUE)か閉じている(FALSE)かを示します。現在、このフィールドは使用されていません      |
| MANUAL_OPEN_TIME | datetime(6)   | NO   | ウィンドウを手動で開いた開始時刻。そうでない場合はNULL。現在、このフィールドは使用されていません      |
| MANUAL_DURATION  | bigint(0)     | NO   | 手動で開いたウィンドウの持続時間。そうでない場合はNULL。現在、このフィールドは使用されていません    |
| COMMENTS         | varchar(4000) | YES  | ウィンドウの説明   |
