# oceanbase.DBA_OB_TASK_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける履歴収集タスクの実行状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 収集タスクが属するテナントID |
| TASK_ID | varchar(36) | NO | 収集タスクID（UUID生成、グローバル一意） |
| TYPE | varchar(16) | NO | 収集タスクのタイプ：<ul><li>`MANUAL GATHER`：手動収集</li> <li>`AUTO GATHER`：自動収集</li> <li>`ASYNC GATHER`：非同期収集</li></ul> |
| STATUS | varchar(8) | NO | 収集タスクのステータス<ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| TABLE_COUNT | bigint(20) | YES | 収集タスクで収集する必要があるテーブル数 |
| FAILED_COUNT | bigint(20) | YES | 収集タスクで収集に失敗したテーブル数 |
| START_TIME | datetime(6) | NO | 収集タスク開始時間 |
| END_TIME | datetime(6) | NO | 収集タスク終了時間 |

## クエリ例

このテナントの手動収集タスクの履歴実行状況を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TASK_OPT_STAT_GATHER_HISTORY WHERE TYPE='MANUAL GATHER';
```
