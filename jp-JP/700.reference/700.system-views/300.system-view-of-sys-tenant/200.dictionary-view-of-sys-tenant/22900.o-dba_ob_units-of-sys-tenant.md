# oceanbase.DBA_OB_UNITS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのユニット情報を表示します。

## フィールドの説明

|         フィールド名          |      タイプ      | NULLを許容するか |   説明   |
|-----------------------|--------------|------------|--------------------|
| UNIT_ID| bigint(20)   | NO         | Unit ID|
| TENANT_ID             | bigint(20)   | NO         | Unitが所属するテナントID：<ul><li>`NULL`：現在のUnitはどのテナントにも属していません   </li><li>有効な値：ターゲットテナントID </li></ul>   |
| STATUS | varchar(128) | NO         | <ul><li> `ACTIVE`：正常状態   </li> <li>`ADDING`：増加中</li> <li> `DELETING`：削除中</li></ul>       |
| RESOURCE_POOL_ID      | bigint(20)   | NO         | Unitが所属するリソースプールID        |
| UNIT_GROUP_ID         | bigint(20)   | NO         | Unitが所属するUnitグループID|
| CREATE_TIME           | timestamp(6) | YES        | Unit作成時間             |
| MODIFY_TIME           | timestamp(6) | YES        | Unit変更時間     |
| ZONE   | varchar(128) | NO         | Zone名|
| SVR_IP | varchar(46)  | NO         | Unitが所属するOBServer IP  |
| SVR_PORT              | bigint(20)   | NO         | Unitが所属するOBServerポート番号 |
| MIGRATE_FROM_SVR_IP   | varchar(46)  | NO         | <ul><li> `NULL`：Unitは移行中ではありません </li><li>有効な値：Unitが移行中であり、移行元のサーバーIPアドレスを示します </li></ul> |
| MIGRATE_FROM_SVR_PORT | bigint(20)   | NO         | <ul><li> `NULL`：Unitは移行中ではありません  </li><li>有効な値：Unitが移行中であり、移行元のサーバーのポート番号を示します  </li></ul>    |
| MANUAL_MIGRATE        | varchar(3)   | NO         | <ul><li> `NULL`：Unitは移行中ではありません </li><li>`YES`：ユーザーが開始したUnit移行   </li><li> `NO`：自動で開始されたUnit移行 </li></ul>    |
| UNIT_CONFIG_ID        | bigint(20)   | NO         |  Unitが採用する仕様ID   |
| MAX_CPU               | double       | NO         |  CPU仕様の上限   |
| MIN_CPU               | double       | NO         |  CPU仕様の下限   |
| MEMORY_SIZE           | bigint(20)   | NO         |  メモリ仕様、単位はバイト   |
| LOG_DISK_SIZE         | bigint(20)   | NO         |  ログディスク仕様、単位はバイト   |
| MAX_IOPS              | bigint(20)   | NO         |  ディスクIOPS仕様の上限   |
| MIN_IOPS              | bigint(20)   | NO         |  ディスクIOPS仕様の下限   |
| IOPS_WEIGHT           | bigint(20)   | NO         |  IOPS重み   |
| REPLICA_TYPE          | varchar(7)   | NO         |  フォロワーのタイプ。デフォルトは`FULL`です。<main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、フィールド<code>REPLICA_TYPE</code>はV4.2.5 BP7バージョンから導入されました。</p></main>   |
