# oceanbase.CDB_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下において、すべてのテナントのメジャーコンパクションに関するグローバル情報を表示します。

## フィールド説明

|           フィールド名           |     型      | NULL許容   |        説明         |
|--------------------------|-------------|------------|---------------------------------------------|
| TENANT_ID                | bigint(20)  | NO         | テナントID             |
| FROZEN_SCN           | bigint(20) unsigned  | NO         | 最後のメジャーコンパクションのバージョン番号           |
| FROZEN_TIME              | timestamp(6)  | NO         | 最後のメジャーコンパクション開始時刻（FROZEN_SCNを読みやすい形式で表示）           |
| GLOBAL_BROADCAST_SCN | bigint(20) unsigned  | NO         | グローバルブロードキャストのメジャーコンパクションバージョン         |
| LAST_SCN             | bigint(20) unsigned  | NO         | 直前に完了したメジャーコンパクションのバージョン      |
| LAST_FINISH_TIME         | timestamp(6)  | NO         | 前回のメジャーコンパクション終了時刻         |
| START_TIME               | timestamp(6)  | NO         | メジャーコンパクション開始時刻            |
| STATUS                   | varchar(10) | NO         | <ul><li>`IDLE`：メジャーコンパクション中ではない</li><li> `COMPACTION`：メジャーコンパクション中   </li><li> `CHECKSUM`：チェックサムの検証</li></ul> |
| IS_ERROR                 | varchar(3)  | NO         | <ul><li>`YES`：メジャーコンパクション処理中にエラーが発生 </li><li> `NO`：メジャーコンパクション処理中にエラーが報告されていない   </li></ul>  |
| IS_SUSPENDED             | varchar(3)  | NO         | <ul><li> `YES`：メジャーコンパクションが一時停止状態</li><li>`NO`：メジャーコンパクションは一時停止されていない</li></ul> |
| INFO                     | varchar(14) | NO         | メジャーコンパクション情報を表示します。例：メジャーコンパクション失敗の原因  |
