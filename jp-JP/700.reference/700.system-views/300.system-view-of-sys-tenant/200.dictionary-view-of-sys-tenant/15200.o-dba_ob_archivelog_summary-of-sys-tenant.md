# oceanbase.DBA_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントの履歴および現在のすべてのログアーカイブ状態を表示します。`sys` テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | パス番号。システムは設定された各パスに一意のIDを割り当てます。 |
| ROUND_ID | bigint(20) | NO | 完全なclogバックアップデータストリームのラウンドを識別するために使用されます。 |
| INCARNATION | bigint(20) | NO | Flashback Database後の分身回数を表します。 |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別します。例えば、log_archive_destのdest_noは0、log_archive_dest_1のdest_noは1などです。 |
| STATUS | varchar(64) | NO | アーカイブ状態：<ul><li>`PREPARE`：アーカイブ開始点`START_SCN`の準備</li> <li>`BEGINNING`：ログアーカイブが開始されています。</li> <li>`DOING`：ログアーカイブが進行中です。</li><li>`INTERRUPTED`：ログアーカイブが中断されました。人の介入が必要です。</li><li>`STOP`：ログアーカイブが停止しました。</li><li>`STOPPING`：ログアーカイブが停止中です。</li><li>`SUSPENDING`：ログアーカイブが一時停止されています。</li><li>`SUSPEND`：ログアーカイブが一時停止されました。</li></ul> |
| START_SCN | bigint(20) unsigned | NO | バックアップ開始ポイント |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に変換した表示 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に変換した表示 |
| COMPATIBLE | bigint(20) | NO | 互換性バージョン |
| BASE_PIECE_ID | bigint(20) | NO | このラウンドの最初のPIECE ID |
| USED_PIECE_ID | bigint(20) | NO | このラウンドで使用されたPIECE ID |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | Piece切り替え周期 |
| UNIT_SIZE | bigint(20) | NO | ログアーカイブデータの1回あたりの圧縮または暗号化されるログブロックサイズ。現在、このフィールドはサポートされていません。 |
| COMPRESSION | varchar(128) | NO | 圧縮アルゴリズム：<ul><li>none：圧縮しないことを意味します。</li><li>lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを意味します。</li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを意味します。</li></ul>現在、このフィールドはサポートされていません。 |
| INPUT_BYTES | bigint(20) | NO | 読み取ったデータ量、単位はバイト |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | 単位付きの読み取りデータ量。例：798.01 Mまたは5.25 G |
| OUTPUT_BYTES | bigint(20) | NO | 出力データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | 単位付きの出力データ量。例：798.01 Mまたは5.25 G |
| COMPRESSION_RATIO | decimal(23,2) | NO | 圧縮率。OceanBaseデータベースは現在、このフィールドをサポートしていません。 |
| DELETED_INPUT_BYTES | bigint(20) | NO | 削除された元のデータ量、単位はバイト |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_INPUT_BYTESの単位変換後の表示。単位はMB、GB、TB、PBのいずれかです |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | 削除された有効データ量、単位はバイト |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_OUTPUT_BYTESを単位変換した後の表示形式。MB、GB、TB、PBのいずれかを指定します。 |
| PATH | varchar(2048) | NO | アーカイブパス |
| COMMENT | varchar(262144) | NO | エラーメッセージの表示 |
