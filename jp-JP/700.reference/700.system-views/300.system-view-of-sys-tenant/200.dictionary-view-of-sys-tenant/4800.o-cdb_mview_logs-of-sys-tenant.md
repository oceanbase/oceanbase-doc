# CDB_MVIEW_LOGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_MVIEW_LOGS` は、すべてのマテリアライズドビューのログ情報を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| LOG_OWNER | varchar(128) | NO | マテリアライズドビューのログ所有者名を表す |
| MASTER | varchar(128) | NO | マテリアライズドビューのログが属する主表名を表す |
| LOG_TABLE | varchar(128) | NO | マテリアライズドビューのログテーブル名を表す |
| LOG_TRIGGER | varchar(128) | YES | 主表の行に後続するトリガーで、行をマテリアライズドビューのログに挿入するために使用される<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| ROWIDS | varchar(3) | NO | Rowid情報を記録するかどうかを表す<ul><li> YES </li><li>NO </li></ul>|
| PRIMARY_KEY | varchar(3) | NO | 主キー情報を記録するかどうかを表す<ul><li> YES </li><li>NO </li></ul>|
| OBJECT_ID | varchar(3) | NO | オブジェクト識別情報をオブジェクトテーブルに記録しているかどうかを表す<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNOです。</p></main> |
| FILTER_COLUMNS | varchar(3) | NO | フィルターカラム情報を記録するかどうかを表す<ul><li> YES </li><li>NO </li></ul>|
| SEQUENCE | varchar(3) | NO | 追加のソート情報を提供するシーケンス値を記録するかどうかを表す<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| INCLUDE_NEW_VALUES | varchar(3) | NO | 古い値と新しい値を同時に記録するかどうかを表す<ul><li>YES：古い値と新しい値を同時に記録します  </li><li>NO：古い値を記録し、新しい値は記録しません </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| PURGE_ASYNCHRONOUS | varchar(3) | NO | マテリアライズドビューのログが非同期でクリアされるかどうかを表す<ul><li> YES </li><li>NO </li></ul>|
| PURGE_DEFERRED | varchar(3) | NO | マテリアライズドビューのログを遅延方式でクリアするかどうかを表す<ul><li> YES </li><li>NO </li></ul>|
| PURGE_START | datetime | YES | 遅延クリアの開始日を表す |
| PURGE_INTERVAL | varchar(200) | YES | 遅延クリアのクリア時間間隔を表す |
| LAST_PURGE_DATE | datetime | YES | 最終のマテリアライズドビューのログクリア日を表す |
| LAST_PURGE_STATUS | bigint(1) | NO | 最終のマテリアライズドビューのログクリア状態を表す<ul><li>エラーコード  </li><li>0 ：成功を表す </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常に0です。</p></main> |
| NUM_ROWS_PURGED | bigint(20) | YES | 最終のマテリアライズドビューのログクリアで削除された行数を表す |
| COMMIT_SCN_BASED | varchar(3) | NO | マテリアライズドビューのログがコミットSCNに基づくかどうかを表す<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>現在、このフィールドの値は常にYESです。</p></main> |
| STAGING_LOG | varchar(3) | NO | マテリアライズドビューのログが同期更新の一時ログかどうかを示します。<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性があり、デフォルト値はNOです。</p></main> |
| PURGE_DOP          | bigint(20)   | NO   | マテリアライズドビューのログをクリーンアップする並列度。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、このフィールドはV4.3.5 BP2バージョンから導入されました。</p></main>|
| LAST_PURGE_TIME    | bigint(20)   | YES  | 最終のマテリアライズドビューのログクリーンアップタスクにかかった時間（秒単位）。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、このフィールドはV4.3.5 BP2バージョンから導入されました。</p></main>|
