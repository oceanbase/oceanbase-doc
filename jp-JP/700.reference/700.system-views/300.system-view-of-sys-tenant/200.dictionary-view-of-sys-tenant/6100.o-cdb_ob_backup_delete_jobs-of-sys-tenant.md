# oceanbase.CDB_OB_BACKUP_DELETE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントレベルのバックアップクリーンアップジョブタスクの実行状況を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| JOB_ID | bigint(20) | NO | ジョブID。単調増加 |
| INCARNATION | bigint(20) | NO | 分身ID |
| INITIATOR_TENANT_ID | bigint(20) | NO | このJOBを開始したテナントID |
| INITIATOR_JOB_ID | bigint(20) | NO | このJOBを開始したテナントが属するJOB_ID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | クリーンアップジョブを実行するテナントの一覧 |
| TYPE | varchar(64) | NO | クリーンアップタイプ：<ul><li>DELETE OBSOLETE BACKUP：期限切れクリーンアップ</li></ul> |
| PARAMETER | timestamp(6) | NO | クリーンアップパラメータ。期限切れ時間を記録 |
| JOB_LEVEL | varchar(64) | NO | ジョブ開始レベル：<ul><li>`USER_TENANT`：ユーザーテナントが開始したジョブ</li><li>`SYS_TENANT`：システムテナントが開始したジョブ</li></ul> |
| START_TIMESTAMP | timestamp(6) | NO | ジョブ開始時のテナント現在時間 |
| END_TIMESTAMP | timestamp(6) | NO | ジョブ終了時のテナント現在時間 |
| STATUS | varchar(64) | NO | ジョブステータス：<ul><li>`INIT`：ジョブ初期化段階 </li><li>`DOING`：ジョブ実行段階 </li><li>`CANCELING`：ジョブがキャンセルされた段階 </li><li>`COMPLETED`：ジョブ実行成功 </li><li>`FAILED`：ジョブ実行失敗 </li><li>`CANCELED`：ジョブが正常にキャンセルされた </li></ul> |
| TASK_COUNT | bigint(20) | YES | backup_set/pieceジョブ数 |
| SUCCESS_TASK_COUNT | bigint(20) | YES | backup_set/piece実行成功したジョブ数 |
| RESULT | bigint(20) | NO | エラーコード |
| COMMENT | varchar(4096) | YES | ジョブ実行説明 |
