# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントが設定しているデータバックアップパラメータ情報を表示します。システムテナントにはユーザーデータが含まれておらず、クラスタ管理用のテナントであるため、バックアップ・リカバリはサポートされていません。そのため、`sys` テナントにはバックアップパラメータが設定されていません。`sys` テナントでは、このビューのクエリ結果は常に空になります。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | パラメータ名 |
| VALUE | longtext | NO | パラメータ値 |
