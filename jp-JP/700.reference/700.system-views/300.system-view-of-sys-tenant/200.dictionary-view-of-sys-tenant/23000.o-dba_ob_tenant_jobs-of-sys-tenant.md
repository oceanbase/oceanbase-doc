# oceanbase.DBA_OB_TENANT_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントレベルのタスク情報を表示します。

## フィールド説明

|    フィールド名     |      型      | NULL許容 |                                                              説明                                                               |
|-------------|--------------|------------|-------------|
| JOB_ID      | bigint(20)   | NO         | タスクID                                      |
| JOB_TYPE    | varchar(128) | NO         | タスクタイプ：<ul><li> `ALTER_TENANT_LOCALITY`：テナントのローカリティを変更する</li> <li>`ROLLBACK_ALTER_TENANT_LOCALITY`：テナントのローカリティをロールバックする</li> <li>`SHRINK_RESOURCE_TENANT_UNIT_NUM`：テナントのユニット数を縮小する</li> <li>`ALTER_TENANT_PRIMARY_ZONE`：テナントの`PRIMARY_ZONE`を変更する</li>  <li>`ALTER_RESOURCE_TENANT_UNIT_NUM`：テナントリソースプールの`UNIT_NUM`を変更する</li> <li>`UPGRADE_POST_ACTION`：アップグレードの前処理</li> <li>`UPGRADE_SYSTEM_VARIABLE`：システム変数のアップグレード</li> <li>`UPGRADE_SYSTEM_TABLE`：システムテーブルのアップグレード</li> <li>`UPGRADE_BEGIN`：アップグレード開始</li> <li>`UPGRADE_VIRTUAL_SCHEMA`：Schemaのアップグレード</li> <li>`UPGRADE_SYSTEM_PACKAGE`：システムパッケージのアップグレード</li> <li>`UPGRADE_ALL_POST_ACTION`：アップグレードの後処理</li> <li>`UPGRADE_INSPECTION`：アップグレード検査</li> <li>`UPGRADE_END`：アップグレード終了</li> <li>`UPGRADE_ALL`：すべてのテナントをアップグレードする</li></ul>   |
| JOB_STATUS  | varchar(128) | NO         | タスク状態：<ul><li>`INPROGRESS`：進行中 </li><li>`SUCCESS`：成功</li><li>`FAILED`：失敗 </li></ul>     |
| RESULT_CODE | bigint(20)   | YES        | タスク終了コード                                      |
| PROGRESS    | bigint(20)   | NO         | タスクの進捗率（値の範囲は \[0, 100\]）                     |
| START_TIME  | timestamp(6) | YES        | タスク開始時刻                                     |
| MODIFY_TIME | timestamp(6) | YES        | タスク最終変更時刻                                 |
| TENANT_ID   | bigint(20)   | YES        | テナントID                                      |
| SQL_TEXT    | longtext     | YES        | 関連SQL文字列                                 |
| EXTRA_INFO  | varchar(512) | YES        | 追加情報                                      |
| RS_SVR_IP   | varchar(46)  | NO         | Root ServiceサーバーIPアドレス                      |
| RS_SVR_PORT | bigint(20)   | NO         | Root Serviceサーバーポート番号                         |

## クエリ例

システムテナントがすべてのテナントのタスク情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_JOBS\G
```
