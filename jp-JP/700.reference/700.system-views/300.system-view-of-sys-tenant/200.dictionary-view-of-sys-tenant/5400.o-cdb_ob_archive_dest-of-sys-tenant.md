# oceanbase.CDB_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのアーカイブパス設定を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するための番号 |
| NAME | varchar(1024) | NO | フィールド名。以下のフィールドが含まれます：<ul><li>`binding`：アーカイブと業務の優先モード</li> <li>`dest_id`：アーカイブ宛先のID</li> <li>`path`：アーカイブパス情報</li> <li>`piece_switch_interval`：Pieceの切り替えサイクル</li> <li>`state`：アーカイブ宛先の状態</li></ul> |
| VALUE | varchar(4096) | NO | `name`フィールドに対応するフィールド値 |

## クエリ例

システムテナントが、テナントIDが1002のテナントのアーカイブパス設定を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_ARCHIVE_DEST WHERE TENANT_ID = 1002;
```

クエリ結果は次のとおりです：

```shell
+-----------+---------+-----------------------+-----------------------------------------------------------------------------------------------------------------------------+
| TENANT_ID | DEST_NO | NAME                  | VALUE                                                                                                                       |
+-----------+---------+-----------------------+-----------------------------------------------------------------------------------------------------------------------------+
|      1002 |       0 | binding               | OPTIONAL                                                                                                                    |
|      1002 |       0 | dest_id               | 1001                                                                                                                        |
|      1002 |       0 | path                  | oss://example_patharchive?host=cn-******.aliyuncs.com&access_id=******&access_key=*****&checksum_type=md5&enable_worm=true  |
|      1002 |       0 | piece_switch_interval | 1d                                                                                                                          |
|      1002 |       0 | state                 | ENABLE                                                                                                                      |
+-----------+---------+-----------------------+-----------------------------------------------------------------------------------------------------------------------------+
5 rows in set
```
