# oceanbase.DBA_OB_BACKUP_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント自身のバックアップジョブタスクの履歴を表示します。`sys` テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名 | フィールドタイプ | NULLを許容するか | フィールド名 |
| ------- | -------- | -------------- | ------- |
| JOB_ID | bigint(20) | NO | バックアップJOBタスクID。1回のバックアップに対応して1件のJOBタスクレコードが生成されます |
| INCARNATION | bigint(20) | NO | Flashback Database後の何番目の分身を表します |
| BACKUP_SET_ID | bigint(20) | YES | バックアップセットID。sysテナントのデフォルトは0、一般テナントは1から増加します |
| INITIATOR_TENANT_ID | bigint(20) | NO | タスク発起者のテナントID。このタスクを開始したテナントを表し、バックアップSQLコマンドを実行するテナントIDに対応します |
| INITIATOR_JOB_ID | bigint(20) | NO | タスク発起者が属するJOB_ID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | このJOBレベルのバックアップタスクに関連付けられた、バックアップを実行する必要があるテナントID |
| PLUS_ARCHIVELOG | varchar(4096) | NO | ログ補完機能を有効にするかどうか：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul> |
| BACKUP_TYPE | varchar(4096) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを表す </li> <li>`INC`：増分バックアップを表す</li></ul> |
| JOB_LEVEL | varchar(4096) | NO | JOBレベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始する</li><li>SYS_TENANT：sysテナントが開始した指定されたテナントのバックアップタスク</li><li>USER_TENANT：一般テナントが自身のバックアップを開始する</li></ul> |
| ENCRYPTION_MODE | varchar(4096) | YES | 暗号化モード：<ul><li>None：暗号化しないことを表す</li><li>Password：パスワードのみを使用して保護することを表す</li><li>Password Encryption：暗号化し、パスワードで保護することを表す</li><li>Transparent Encryption：TDE暗号化を使用することを表す</li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用することを表す</li></ul> </br>現在、NoneとPasswordの2種類のモードのみサポートしています |
| PASSWD | varchar(4096) | YES | パスワード |
| START_TIMESTAMP | timestamp(6) | NO | JOBレベルのバックアップタスクの開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | JOBレベルのバックアップタスクの終了時間 |
| STATUS | varchar(4096) | NO | バックアップの状態 |
| RESULT | bigint(20) | NO | バックアップエラーコード結果 |
| COMMENT | varchar(4096) | YES | エラーコードの説明 |
| DESCRIPTION | varchar(4096) | YES | ユーザー指定のバックアップ説明情報 |
| PATH | varchar(4096) | YES | バックアップパス |
