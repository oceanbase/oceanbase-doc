# oceanbase.DBA_RECYCLEBIN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおけるすべてのゴミ箱オブジェクトの情報を表示します。

## フィールドの説明

|      フィールド名   |  タイプ     | NULLを許容するか |    説明             |
|----------------|---------------|------------|--------------------|
| OWNER          | varchar(128) | NO   | オブジェクトの元の所有者名     |
| OBJECT_NAME    | varchar(128) | NO   | オブジェクトの新しい名前     |
| ORIGINAL_NAME  | varchar(128) | NO   | オブジェクトの元の名前     |
| OPERATION      | varchar(9)   | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです      |
| TYPE           | varchar(25)  | NO   | オブジェクトタイプ     |
| TS_NAME        | varchar(30)  | NO   | オブジェクトが属するスペースの名前     |
| CREATETIME     | date         | YES  | オブジェクト作成時間     |
| DROPTIME       | date         | YES  | オブジェクトがゴミ箱に移動した時間     |
| DROPSCN        | bigint(0)    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです     |
| PARTITION_NAME | varchar(128) | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです     |
| CAN_UNDROP     | varchar(3)   | NO   | オブジェクトをゴミ箱から復元できるか：<ul><li>YES </li><li>NO </li></ul>      |
| CAN_PURGE      | varchar(3)   | NO   | オブジェクトを削除できるか：<ul><li>YES </li><li>NO </li></ul>      |
| RELATED        | bigint(0)    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです     |
| BASE_OBJECT    | bigint(0)    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです    |
| PURGE_OBJECT   | bigint(0)    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです     |
| SPACE          | bigint(0)    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです     |
