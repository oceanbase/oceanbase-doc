# oceanbase.CDB_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_TRANSFER_PARTITION_TASKS` は、すべてのテナントで現在処理中のパーティション転送タスクを表示します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID        | bigint(20)   | NO   |  ユーザーテナントID   |
| TASK_ID          | bigint(20)   | NO   |  パーティション転送タスクの一意の識別子   |
| CREATE_TIME      | timestamp(6) | NO   |  作成時間   |
| MODIFY_TIME      | timestamp(6) | NO   |  情報更新時間   |
| TABLE_ID         | bigint(20)   | NO   |  転送対象のパーティションが存在するテーブルID   |
| OBJECT_ID        | bigint(20)   | NO   |  転送対象のパーティションの `OBJECT_ID`   |
| DEST_LS          | bigint(20)   | NO   |  宛先ログストリーム   |
| BALANCE_JOB_ID   | bigint(20)   | NO   |  タスク実行時に関連付けられたロードバランシングジョブID   |
| TRANSFER_TASK_ID | bigint(20)   | NO   |  タスク実行時に関連付けられた転送タスクID   |
| STATUS           | varchar(64)  | NO   |  タスク状態：<ul><li>WAITING：タスク待機中、実行開始前</li><li>INIT：タスクのスケジューリング開始</li><li>DOING：タスクの転送実行開始</li></ul>   |
| COMMENT          | longtext     | YES  |  コメント情報   |

## クエリ例

1006テナントで現在処理中のパーティション転送タスクを照会します。

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TRANSFER_PARTITION_TASKS WHERE TENANT_ID = 1006;
```

クエリ結果は次のとおりです：

```shell
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TENANT_ID | TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|      1006 |       3 | 2023-12-01 11:26:43.757677 | 2023-12-01 11:27:11.192958 |   500003 |    500009 |    1001 |         760894 |             2954 | DOING  | NULL    |
+-----------+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set
```
