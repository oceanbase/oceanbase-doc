# oceanbase.DBA_OB_TABLEGROUP_PARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.2.0以降のバージョンでは、テーブルグループにパーティションという概念がなくなったため、このビューは使用されなくなりました。ユーザーがこのビューをクエリしても、結果は空になります。</li>
<li>V4.2.0以降のバージョンでは、ビュー<a href="21600.o-dba_ob_tablegroups-of-sys-tenant.md">DBA_OB_TABLEGROUPS</a>を使用してテーブルグループ情報を照会できます。テーブルグループの詳細については、<a href="../../../300.database-object-management/100.manage-object-of-mysql-mode/400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md">テーブルグループについて</a>を参照してください。</li>
</ul>
</main>

## 機能の概要

パーティションを持つテーブルグループのパーティション情報を表示します。

## フィールドの説明

|        フィールド名        |      タイプ       | NULL値を許容するか |                                                                     説明                                                                      |
|--------------------|---------------|------------|---------------------------|
| TABLEGROUP_NAME    | varchar(128)  | NO         | TABLEGROUPの名前                                            |
| COMPOSITE          | varchar(3)    | NO         | パーティションテーブルグループがコンポジットパーティションであるかどうか。値は`YES`または`NO`です                             |
| PARTITION_NAME     | varchar(64)   | NO         | パーティションテーブルグループのパーティション名                                              |
| SUBPARTITION_COUNT | bigint(20)    | NO         | このフィールドの値は`NULL`です                 |
| HIGH_VALUE         | varchar(4096) | NO         | このフィールドの値は`NULL`です            |
| HIGH_VALUE_LENGTH  | bigint(20)    | NO         | このフィールドの値は`NULL`です                              |
| PARTITION_POSITION | bigint(20) unsigned   | NO         | このフィールドの値は`NULL`です    |
