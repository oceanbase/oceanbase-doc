# oceanbase.DBA_OB_LS_LOCATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのログストリーム（LS）レプリカの分布情報を表示します。

## フィールドの説明

|     フィールド名  |       タイプ    | NULLを許容するか |       説明        |
|--------------|---------------|------------|----------------------------------------------------------------------|
| CREATE_TIME  | datetime(6)   | NO         |   作成時間       |
| MODIFY_TIME  | datetime(6)   | NO         |   変更時間      |
| LS_ID        | bigint(20)    | NO         |   ログストリームID       |
| SVR_IP       | varchar(46)   | NO         |   サーバーIPアドレス       |
| SVR_PORT     | bigint(20)    | NO         |   サーバーのポート番号          |
| SQL_PORT     | bigint(20)    | NO         |   SQLポート番号         |
| ZONE         | varchar(128)  | NO         |   ゾーン名         |
| ROLE         | varchar(8)    | NO         | レプリカロール：<ul><li>`LEADER`   </li><li> `FOLLOWER` </li></ul>      |
| MEMBER_LIST  | varchar(4480) | NO         | レプリカメンバーリスト。複数のレプリカ間はカンマで区切る。<ul><li>このフィールドは、ロールが `LEADER` の場合に有効です。単一レプリカの表示形式は `svr_ip:svr_port:timestamp` です。その内容は以下の通りです：<ul><li>`svr_ip`：レプリカが存在するマシンのIPアドレス</li> <li>`svr_port`：レプリカが存在するマシンのポート番号</li> <li>`timestamp`：レプリカがメンバーリストに追加された時間。デフォルトは `1` です。レプリカの補完または移行操作が実行された場合、この値は変更されます</li></ul></br> 表示例：172.xx.xxx.xxx:2882:1</li> <li>ロールが `LEADER` 以外の場合、このフィールドは `NULL` として表示されます。</li></ul>   |
| PAXOS_REPLICA_NUMBER       | bigint(20)    | NO         | Paxosの法定レプリカ数：ロールが `LEADER` の場合にこのフィールドは有効です。それ以外の場合は `NULL` です  |
| REPLICA_TYPE | varchar(18)   | NO         | レプリカタイプ：<ul><li>`FULL`：フル機能タイプのレプリカ </li><li> `READONLY`：読み取り専用タイプのレプリカ </li><li>   |
| LEARNER_LIST | longtext      | YES        | 現在のログストリームの読み取り専用レプリカリスト。複数のレプリカ間はカンマで区切る。単一レプリカの表示形式は `svr_ip:svr_port:timestamp:flag` です。その内容は以下の通りです：<ul><li>`svr_ip`：レプリカが存在するマシンのIPアドレス</li> <li>`svr_port`：レプリカが存在するマシンのポート番号</li> <li>`timestamp`：レプリカが追加された時間。デフォルトは `1` です。レプリカの補完または移行操作が実行された場合、この値は変更されます</li> <li>`flag`：レプリカが移行中かどうか。`0` はレプリカが移行中ではないことを表し、`2` はレプリカが移行中であることを表します。</li></ul></br> 表示例：172.xx.xxx.xxx:2882:1:0  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| REBUILD      | varchar(5)    | NO         | このレプリカがRebuild中かどうか <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main>|

obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_LOCATIONS;
