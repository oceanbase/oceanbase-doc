# oceanbase.DBA_OB_DATABASES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのデータベースメタ情報を表示します。

## フィールドの説明

|     フィールド名      |      タイプ       | NULL値を許容するか |             説明             |
|---------------|---------------|------------|----------------------------|
| DATABASE_NAME | varchar(128)  | NO         | データベース名                       |
| IN_RECYCLEBIN | varchar(3)    | NO         | データベースがごみ箱にあるかどうか：<ul><li>YES</li><li>NO</li></ul> |
| COLLATION     | varchar(128)  | NO         | データベースのデフォルトCOLLATION            |
| READ_ONLY     | varchar(3)    | NO   | OCPがデータベースの読み取り専用状態を取得する。<ul><li>YES：読み取り専用</li><li>NO：読み書き可能</li></ul>    |
| COMMENT       | varchar(2048) | NO         | データベースの説明                     |

## クエリ例

システムテナント内で、自身のデータベースメタ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DATABASES;
```
