# oceanbase.DBA_OB_SYS_VARIABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_SYS_VARIABLES`は、現在のテナントのシステム変数（ "_" で始まる隠し変数を含む）の設定を表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CREATE_TIME | timestamp(6) | YES | 作成時間 |
| MODIFY_TIME | timestamp(6) | YES | 変更時間 |
| NAME | varchar(128) | NO | システム変数名 |
| VALUE | varchar(65536) | YES | システム変数の現在値 |
| MIN_VALUE | varchar(65536) | NO | 最小値 |
| MAX_VALUE | varchar(65536) | NO | 最大値 |
| SCOPE | varchar(16) | NO | システム変数のレベル |
| INFO | varchar(4096) | NO | 情報コメント |
| DEFAULT_VALUE | varchar(65536) | YES | システム変数のデフォルト値 |
| ISDEFAULT | varchar(3) | NO | デフォルト値かどうか |

## クエリ例

このテナントのシステム変数`ob_query_timeout`に関する情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
```

```shell
+----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+

+----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
| 2024-07-23 15:16:40.982646 | 2024-07-23 15:16:40.982646 | ob_query_timeout | 10000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | YES       |
+----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
1 row in set
```
