# oceanbase.DBA_OB_IMPORT_TABLE_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のテーブルインポートタスクのレコードを表示します。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | ロードバランシングタスクID |
| JOB_ID | bigint(20) | NO | タスクID |
| SRC_TENANT_ID | bigint(20) | NO | ソーステナントID |
| SRC_TABLESPACE | varchar(128) | YES | ソーステーブルのTABLESPACE |
| SRC_TABLEGROUP | varchar(128) | YES | ソーステーブルのTABLEGROUP |
| SRC_DATABASE | varchar(128) | YES | ソーステーブルのDATABASE |
| SRC_TABLE | varchar(128) | YES | ソーステーブル名 |
| SRC_PARTITION | varchar(64) | YES | ソーステーブルのPARTITION名 |
| TARGET_TABLESPACE | varchar(128) | YES | リマッピング後のテーブルスペース名。リマッピングされていない場合は空文字列を返します |
| TARGET_TABLEGROUP | varchar(128) | YES | リマッピング後のテーブルグループ名。リマッピングされていない場合は空文字列を返します |
| TARGET_DATABASE | varchar(128) | YES | リマッピング後のデータベース名。リマッピングされていない場合は空文字列を返します |
| TARGET_TABLE | varchar(128) | YES | リネーム後のテーブル名。リネームされていない場合は空文字列を返します |
| TABLE_COLUMN | bigint(20) | NO | テーブル列の数 |
| STATUS | varchar(64) | NO | タスクの状態：<ul><li>`INIT`：テーブルインポートタスクの初期化</li> <li>`DOING`：テーブルインポート実行中</li> <li>`FINISH`：インポート終了</li></ul> |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時のテナントの現在時刻 |
| COMPLETION_TIMESTAMP | timestamp(6) | NO | タスク完了時のテナントの現在時刻 |
| CUMULATIVE_TS | bigint(20) | NO | 累計時間 |
| TOTAL_INDEX_COUNT | bigint(20) | NO | 総インデックス数 |
| IMPORTED_INDEX_COUNT | bigint(20) | NO | インポート済みのインデックス数 |
| FAILED_INDEX_COUNT | bigint(20) | NO | インポート失敗のインデックス数 |
| TOTAL_CONSTRAINT_COUNT | bigint(20) | NO | 総制約数 |
| IMPORTED_CONSTRAINT_COUNT | bigint(20) | NO | インポート済みの制約数 |
| FAILED_CONSTRAINT_COUNT | bigint(20) | NO | インポート失敗の制約数 |
| TOTAL_REF_CONSTRAINT_COUNT | bigint(20) | NO | 総参照制約数 |
| IMPORTED_REF_CONSTRAINT_COUNT | bigint(20) | NO | インポート済みの参照制約数 |
| FAILED_REF_CONSTRAINT_COUNT | bigint(20) | NO | インポート失敗の参照制約数 |
| RESULT | varchar(64) | YES | タスクの実行結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行されました。</li><li>`FAIL`：インポートタスクが失敗しました。</li></ul> |
| COMMENT | longtext | YES | 備考 |
