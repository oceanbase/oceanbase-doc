# CDB_MVREF_STATS_SYS_DEFAULTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## ## 機能の概要

ビュー `CDB_MVREF_STATS_SYS_DEFAULTS` は、マテリアライズドビューのリフレッシュ履歴統計プロパティのシステム範囲デフォルト値を提供します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| PARAMETER_NAME | varchar(16) | NO | パラメータ名<ul><li>COLLECTION_LEVEL：データ収集のレベルまたは詳細度。</li><li>RETENTION_PERIOD：データ保持期間。</li></ul>|
| VALUE | varchar(40) | NO | パラメータのシステム範囲のデフォルト値 |

## クエリ例

マテリアライズドビューのリフレッシュ履歴統計プロパティのシステム範囲デフォルト値を照会します。

```shell
obclient [test_db]> SELECT * FROM oceanbase.CDB_MVREF_STATS_SYS_DEFAULTS;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------------+---------+
| TENANT_ID | PARAMETER_NAME   | VALUE   |

|         1 | RETENTION_PERIOD | 31      |
|      1002 | COLLECTION_LEVEL | TYPICAL |
|      1002 | RETENTION_PERIOD | 31      |
|      1004 | COLLECTION_LEVEL | TYPICAL |
|      1004 | RETENTION_PERIOD | 31      |
+-----------+------------------+---------+
6 rows in set (0.015 sec)
```
