# oceanbase.CDB_TAB_COLS_V$

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのテーブルおよびビューの列情報を表示します。このビューは`CDB_TAB_COLS`と一致していますが、`NOTES`列が追加されています。ただし、現在`NOTES`列は使用されていません。

## フィールドの説明

|         フィールド名         |       タイプ        | NULLを許容するか |                                                               説明                                                                |
|----------------------|-----------------|------------|---------------|
| CON_ID               | bigint(20)      | NO         | テナントID                                        |
| OWNER                | varchar(128)    | NO         | テーブル、ビュー、またはクラスタの所有者                                  |
| TABLE_NAME           | varchar(128)    | NO         | テーブル、ビュー、またはクラスタの名前                                   |

| COLUMN_ID            | bigint(20)      | NO         | 作成された列のシリアル番号                                     |

| NOTES                | varchar(80)     | NO         | このフィールドはデフォルトでNULLです |
| AVG_COL_LEN          | bigint(21)      | NO         | 列の平均長（バイト単位）                               |

| CHAR_USED            | varchar(1)      | NO         | この列が `BYTE` 長さセマンティクス（`B`）または `CHAR` 長さセマンティクス（`C`）を使用していることを示します。データ型が以下のいずれにも該当しない場合は、`NULL` として表示されます：<ul><li>`CHAR`   </li><li> `VARCHAR2`   </li><li> `NCHAR`   </li><li> `NVARCHAR2`  </li></ul>    |
| V80_FMT_IMAGE        | varchar(3)      | NO         | このフィールドはデフォルトでNULLです   |

| UNUSABLE_BEFORE      | varchar(128)    | NO         | このフィールドはデフォルトでNULLです                     |

| COLLATION            | varchar(100)    | NO         | このフィールドはデフォルトでNULLです                     |
| COLLATED_COLUMN_ID   | bigint(0)       | NO         | このフィールドはデフォルトでNULLです                     |
