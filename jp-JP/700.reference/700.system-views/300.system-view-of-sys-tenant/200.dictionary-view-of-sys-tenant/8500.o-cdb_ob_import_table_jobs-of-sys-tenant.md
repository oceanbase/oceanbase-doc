# oceanbase.CDB_OB_IMPORT_TABLE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

テナントレベルのインポートタスクに関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | ジョブテナントID |
| JOB_ID | bigint(20) | NO | ジョブID |
| INITIATOR_TENANT_ID | bigint(20) | NO | 親ジョブのテナントID |
| INITIATOR_JOB_ID | bigint(20) | NO | 親ジョブが属するJOB ID |
| START_TIMESTAMP | timestamp(6) | NO | ジョブ開始時のテナント現在時間 |
| FINISH_TIMESTAMP | timestamp(6) | NO | ジョブ完了時のテナント現在時間 |
| SRC_TENANT_NAME | varchar(64) | NO | ソーステナント名 |
| SRC_TENANT_ID | bigint(20) | NO | ソーステナントID |
| STATUS | varchar(64) | NO | ジョブステータス。<ul><li>INIT：ジョブ初期化状態</li><li>IMPORT_TABLE：テーブルのインポート</li><li>RECONSTRUCT_REF_CONSTRAINT：参照制約の再構築</li><li>CANCELING：キャンセル</li><li>IMPORT_FINISH：インポート終了</li></ul> |
| IMPORT_ALL | tinyint(4) | NO | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが`RECOVER TABLE *.*`を指定した場合にのみ、この値は1となり、他のシナリオでは値は0となります |
| DB_LIST | longtext | YES | 完全に復元するデータベース |
| TABLE_LIST | longtext | YES | 復元するテーブル |
| REMAP_DB_LIST | longtext | YES | 重命名されるデータベース。書式は次のとおりです：`db1:new_db1, db2:newdb2` |
| REMAP_TABLE_LIST | longtext | YES | 重命名されるテーブル。書式は次のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2` |
| REMAP_TABLEGROUP_LIST | longtext | YES | 重マッピングされるテーブルグループのリスト。テーブルを元のテーブルグループからターゲットテーブルグループに再マッピングできます。書式は次のとおりです：`tg1:new_tg1, tg2:new_tg2` |
| REMAP_TABLESPACE_LIST | longtext | YES | 重マッピングされるテーブルスペースのリスト。テーブルを元のテーブルスペースからターゲットテーブルスペースに再マッピングできます。書式は次のとおりです：`ts1:new_ts1, ts2:new_ts2` |
| TOTAL_TABLE_COUNT | bigint(20) | NO | テーブルインポートの総数 |
| FINISHED_TABLE_COUNT | bigint(20) | NO | インポートが完了したテーブル数 |
| FAILED_TABLE_COUNT | bigint(20) | NO | インポートに失敗したテーブル数 |
| RESULT | varchar(64) | YES | テーブルレベルの復元ジョブの結果：<ul><li>SUCCESS </li><li>FAIL </li></ul> |
| COMMENT | longtext | YES | 備考情報 |
| DESCRIPTION | longtext | YES | 復元コマンドで指定されたDESCRIPTION情報 |
