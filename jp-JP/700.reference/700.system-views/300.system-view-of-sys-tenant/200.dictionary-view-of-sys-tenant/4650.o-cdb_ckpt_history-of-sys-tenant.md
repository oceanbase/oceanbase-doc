# oceanbase.CDB_CKPT_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが最適化されたため、このビューはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、Mini Compactionタイプ（ダンプ）については明確な開始時刻と終了時刻が存在しないため、チェックポイント関連情報を照会することが一時的にできません。Major Compactionタイプ（メジャーコンパクション）については、システムテナントはビュー<a href="9800.o-cdb_ob_major_compaction-of-sys-tenant.md">CDB_OB_MAJOR_COMPACTION</a>を使用して各テナントのチェックポイント実行状況を照会できます。ユーザーテナントはビュー<a href="../../400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/9900.o-dba_ob_major_compaction-of-mysql-mode.md">DBA_OB_MAJOR_COMPACTION</a>を使用して自身のテナントのチェックポイント実行状況を照会できます。</li></ul>
</main>

## 機能の概要

`CDB_CKPT_HISTORY`は、システム内の各テナントにおけるチェックポイントの実行状況を表示するために使用されます。これには、チェックポイントのタイプ、バージョン番号、クラスタバージョン、開始時間および終了時間が含まれます。
