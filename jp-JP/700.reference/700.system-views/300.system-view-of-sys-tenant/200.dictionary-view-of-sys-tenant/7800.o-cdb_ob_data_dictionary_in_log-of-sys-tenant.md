# oceanbase.CDB_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

データディクショナリがシステムログストリーム内に存在する範囲を記録し、CDCがデータディクショナリを消費する際に便利です。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID <ul><li> 1：システムテナントID </li><li> その他の値：ユーザーテナントID </li></ul> |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | データディクショナリ生成時の対応するテナントのSNAPSHOT SCN |
| REPORT_TIME | timestamp(6) | NO | データディクショナリ生成完了後、内部テーブルへ報告されるまでの時間（単位：マイクロ秒） |
| START_LSN | bigint(20) unsigned | NO | テナントのログストリーム1に永続化された最初のログのLSN |
| END_LSN | bigint(20) unsigned | NO | テナントのログストリーム1に永続化された最後のログのLSN |

## クエリ例

システムテナントがすべてのユーザーテナントのデータディクショナリがシステムログストリーム内に存在する範囲を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_DATA_DICTIONARY_IN_LOG;
```

クエリ結果は次のとおりです：

```shell
+-----------+---------------------+----------------------------+-----------+----------+
| TENANT_ID | SNAPSHOT_SCN        | REPORT_TIME                | START_LSN | END_LSN  |
+-----------+---------------------+----------------------------+-----------+----------+
|      1002 | 1722408567371559602 | 2024-07-31 14:49:27.420098 |   9118467 |  9118467 |
|      1004 | 1722408697334096435 | 2024-07-31 14:51:37.373029 |  13706567 | 13706567 |
+-----------+---------------------+----------------------------+-----------+----------+
2 rows in set
```
