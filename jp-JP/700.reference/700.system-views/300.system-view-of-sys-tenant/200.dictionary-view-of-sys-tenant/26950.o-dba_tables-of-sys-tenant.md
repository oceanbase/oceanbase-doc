# oceanbase.DBA_TABLES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.4.x系では、このビューはV4.4.2バージョンから導入されました。</li><li>V4.5.x系では、このビューはV4.5.0バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

このビューは、現在のテナントにおけるすべてのテーブル情報を表示するために使用されます。
