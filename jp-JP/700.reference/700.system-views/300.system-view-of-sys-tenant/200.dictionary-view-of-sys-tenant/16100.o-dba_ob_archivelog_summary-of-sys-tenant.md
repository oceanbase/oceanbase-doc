# oceanbase.DBA_OB_ARCHIVELOG_SUMMARY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントの履歴および現在のすべてのログアーカイブの状態を表示します。`sys`テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | パス番号。システムは設定された各パスに一意のIDを割り当てます |
| ROUND_ID | bigint(20) | NO | 完全なClogバックアップデータストリームのラウンド数を識別するために使用されます |
| INCARNATION | bigint(20) | NO | Flashback Database後の分身回数を表します |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するために使用されます。例：log_archive_destのdest_noは0、log_archive_dest_1のdest_noは1などです |
| STATUS | varchar(64) | NO | アーカイブ状態：<ul><li>`PREPARE`：アーカイブ開始点`START_SCN`の準備中 </li> <li>`BEGINNING`：ログアーカイブの開始中 </li> <li>`DOING`：ログアーカイブ中 </li><li> `INTERRUPTED`：ログアーカイブが中断し、人為的介入が必要です </li><li>`STOP`：ログアーカイブが停止しました </li><li>`STOPPING`：ログアーカイブの停止中 </li><li>`SUSPENDING`：ログアーカイブが一時停止中 </li><li>`SUSPEND`：ログアーカイブが一時停止しました </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | バックアップ開始ポイント |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に変換した表示形式 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に変換した表示形式 |
| COMPATIBLE | bigint(20) | NO | 互換性バージョン |
| BASE_PIECE_ID | bigint(20) | NO | そのラウンドの最初のPIECE ID |
| USED_PIECE_ID | bigint(20) | NO | そのラウンドで使用済みのPIECE ID |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | Piece切り替え間隔 |
| UNIT_SIZE   | bigint(20)   | NO   | ログアーカイブデータの1回の圧縮または暗号化におけるログブロックサイズ。現在このフィールドはサポートされていません    |
| COMPRESSION | varchar(128) | NO   | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを表します </li><li> lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを表します </li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを表します</li></ul>現在このフィールドはサポートされていません   |
| INPUT_BYTES | bigint(20) | NO | 読み取ったデータ量。単位はバイト |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | 単位を含む読み取ったデータ量。例：798.01 M または 5.25 G |
| OUTPUT_BYTES | bigint(20) | NO | 出力データ量。単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | 単位を含む出力データ量。例：798.01 M または 5.25 G |
| COMPRESSION_RATIO | decimal(23,2) | NO | 圧縮率。現在このフィールドはサポートされていません |
| DELETED_INPUT_BYTES | bigint(20) | NO | 削除された生データ量。単位はバイト |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_INPUT_BYTESをMB、GB、TB、PBのいずれかの単位に変換した表示 |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | 削除された有効データ量。単位はバイト |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_OUTPUT_BYTESをMB、GB、TB、PBのいずれかの単位に変換した表示 |
| PATH | varchar(2048) | NO | アーカイブパス |
| COMMENT | varchar(262144) | NO | エラーメッセージを表示します  |
