# oceanbase.CDB_OB_BACKUP_STORAGE_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントにおけるバックアップ復旧で使用されるバックアップ先の関連情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| PATH | varchar(1024) | NO | バックアップのルートパス |
| ENDPOINT | varchar(256) | NO | オブジェクトストレージへのアクセスに必要なホスト |
| DEST_ID | bigint(20) | YES | バックアップ先の番号 |
| DEST_TYPE | varchar(64) | YES | バックアップ先のタイプ：<ul><li>`archive_log`：ログアーカイブ</li> <li>`backup_data`：データバックアップ</li></ul> |
| AUTHORIZATION | varchar(1024) | NO | オブジェクトストレージの認証情報 |
| EXTENSION | varchar(512) | NO | バックアップ先のその他のパラメータ |
| CHECK_FILE_NAME | varchar(256) | YES | 通信性検証ファイル名 |
| LAST_CHECK_TIMESTAMP | timestamp(6) | YES | 前回の通信性検証に合格した時間 |

## クエリ例

すべてのテナントにおけるバックアップ復旧で使用されるバックアップ先の関連情報を確認します。
