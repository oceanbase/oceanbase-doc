# oceanbase.DBA_OB_BACKUP_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント自身のタスクレベルバックアップタスクを表示します。OceanBaseデータベースは、`sys` テナントとMetaテナントに対する物理バックアップをサポートしていません。

## フィールド説明

| フィールド名                       | フィールド名        | NULL許容 | フィールド名                         |
|-------------------------------|----------------|-----------------|----------------------------------|
| TASK_ID                       | bigint(20)     | NO              | タスクレベルのバックアップタスクID。1つのバックアップセットに対応するタスクを表す |
| JOB_ID                        | bigint(20)     | NO              | このタスクが属するJOB_ID |
| INCARNATION                   | bigint(20)     | NO              | Flashback Database後の何番目のインカーネーションかを示す |
| BACKUP_SET_ID                 | bigint(20)     | NO              | このタスクが対応するバックアップセットID |
| START_TIMESTAMP               | timestamp(6)   | NO              | このタスクの開始時間 |
| END_TIMESTAMP                 | timestamp(6)   | NO              | タスクの終了時間 |
| STATUS                        | varchar(4096)  | NO              | バックアップの状態 |
| START_SCN                     | bigint(20) unsigned | NO         | バックアップ開始時のSCN |
| END_SCN                       | bigint(20) unsigned | NO         | バックアップ終了時のSCN |
| USER_LS_START_SCN             | bigint(20) unsigned | NO         | バックアップログストリームMETAのSCN |
| ENCRYPTION_MODE               | varchar(4096)  | YES             | 暗号化モード：<ul><li>None：暗号化しないことを示す</li><li>Password：パスワードによるみだけの保護を示す</li><li>Password Encryption ：暗号化し、パスワードで保護することを示す</li><li>Transparent Encryption：TDE暗号化を使用することを示す</li><li>Dual mode Encryption ：TDE暗号化およびパスワードによる保護を使用することを示す</li></ul> </br>現在、NoneとPasswordの2種類のモードのみサポートしています |
| PASSWD                        | varchar(4096)  | YES             | パスワード |
| INPUT_BYTES                   | bigint(20)     | YES             | 入力バイト数 |
| OUTPUT_BYTES                  | bigint(20)     | YES             | 出力バイト数 |
| OUTPUT_RATE_BYTES             | decimal(28,4)  | NO              | 1秒間の出力バイト数 |
| EXTRA_META_BYTES              | bigint(20)     | YES             | 追加メタデータバイト数 |
| TABLET_COUNT                  | bigint(20)     | YES             | バックアップされたTABLETの総数 |
| FINISH_TABLET_COUNT           | bigint(20)     | YES             | バックアップ完了したTABLETの総数 |
| MACRO_BLOCK_COUNT             | bigint(20)     | YES             | マクロブロック数 |
| FINISH_MACRO_BLOCK_COUNT      | bigint(20)     | YES             | バックアップが完了したマクロブロック数 |
| FILE_COUNT                    | bigint(20)     | YES             | バックアップファイル数 |
| META_TURN_ID                  | bigint(20)     | YES             | バックアップMETAのサイクル |
| DATA_TURN_ID                  | bigint(20)     | YES             | バックアップDATAのサイクル |
| RESULT                        | bigint(20)     | YES             | バックアップエラーコード結果 |
| COMMENT                       | varchar(4096)  | YES             | エラーコードの説明 |
| PATH                          | varchar(4096)  | YES             | バックアップパス |
| MINOR_TURN_ID                 | bigint(20)     | NO              | ダンプデータバックアップ終了のサイクル      |
| MAJOR_TURN_ID                 | bigint(20)     | NO              | ベースラインデータバックアップ終了のサイクル      |
| DATA_PROGRESS                 | decimal(26,2)  | NO              | データバックアップの進捗状況。計算方法は `完了したマクロブロック数 / 総マクロブロック数`、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗が87.65%を表します。     |
| LOG_FILE_COUNT                | bigint(20)     | NO              | アーカイブclogファイルの合計数      |
| FINISH_LOG_FILE_COUNT         | bigint(20)     | NO              | バックアップが完了したアーカイブclogファイル数      |
| LOG_PROGRESS                  | decimal(26,2)  | NO              | アーカイブclogファイルのバックアップ進捗状況。計算方法は `バックアップが完了したアーカイブclogファイル数 / アーカイブclogファイルの合計数`、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗が87.65%を表します。       |
