# oceanbase.DBA_OB_LS_LOG_ARCHIVE_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントのログストリームアーカイブの進捗状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| DEST_ID | bigint(20)   | NO | アーカイブ先ID |
| LS_ID | bigint(20)   | NO | ログストリームID |
| ROUND_ID | bigint(20)   | NO | ログストリームラウンドID |
| PIECE_ID | bigint(20)  | NO | 最終ピースID |
| INCARNATION | bigint(20)  | NO | 分身ID |
| START_SCN | bigint(20) unsigned | NO | アーカイブ開始SCN |
| MIN_LSN | bigint(20) unsigned | NO | 現在のピースのログストリームの最小LSN |
| MAX_LSN | bigint(20) unsigned | NO | 現在のピースのログストリームの最大LSN |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のピースのログストリームの最大アーカイブ進捗 |
| STATUS | varchar(64)  | NO | アーカイブ状態 |
| FILE_ID  | bigint(20)  | NO | 現在のピースの最大アーカイブファイルID |
| FILE_OFFSET  | bigint(20)  | NO | 現在のピースの最大アーカイブファイルOFFSET |
| INPUT_BYTES  | bigint(20)  | NO | 読み取ったログデータ量、単位はバイト |
| OUTPUT_BYTES   | bigint(20)  | NO | アーカイブされたログデータ量、単位はバイト |
