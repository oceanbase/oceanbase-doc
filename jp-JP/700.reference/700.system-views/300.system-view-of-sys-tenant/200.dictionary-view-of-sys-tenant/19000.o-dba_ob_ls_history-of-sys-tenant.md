# oceanbase.DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントに存在したことのあるログストリームを表示します。

## フィールドの説明

| フィールド        | タイプ           | NULLか | 説明                                       |
|-------------|---------------|-------------|-------------------------------------------|
| LS_ID       | bigint(20)    | NO          |  ログストリームID                                 |
| LS_GROUP_ID | bigint(20)    | NO          |  ログストリームグループID                               |
| STATUS      | varchar(100)  | NO          |  ログストリームの現在のステータス：<ul><li>CREATING：ログストリームの作成中</li><li>NORMAL：通常のログストリームの状態</li><li>DROPPING：ログストリームが削除されている</li><li>PRE_TENANT_DROPPING：システムログストリームの特殊な状態で、テナント内のすべてのログストリームの削除を開始することを示します</li><li>TENANT_DROPPING：テナントが削除され、ログストリームが削除されている状態</li><li>DROPPED：ログストリームはすでに回収されているか、回収中です。</li><li>WAIT_OFFLINE：ログストリームは回収待機中</li><li>CREATE_ABORT：ログストリームの作成が停止</li></ul>        |
| FLAG        | varchar(2048) | NO          |  ログストリームのマーク：<ul><li>NULL：通常のログストリーム</li><li> DUPLICATE：ユーザーテナントのブロードキャストログストリームで、複製テーブルはこのログストリーム上に作成されます </li> <li>BLOCK_TABLET_IN：このログストリーム上にTabletを作成できないことを示します</li> <li>DUPLICATE\|BLOCK_TABLET_IN：ブロードキャストログストリームでは現在Tabletの作成が許可されていません</li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          |  ログストリーム作成時のGTS。単位はナノ秒              |

## クエリ例

システムテナントが、このテナントに存在したことのあるログストリームを照会します。

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```

クエリ結果は次のとおりです：

```shell
+-------+-------------+--------+------+------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN |
+-------+-------------+--------+------+------------+
|     1 |           0 | NORMAL |      |          0 |
+-------+-------------+--------+------+------------+
1 row in set
```
