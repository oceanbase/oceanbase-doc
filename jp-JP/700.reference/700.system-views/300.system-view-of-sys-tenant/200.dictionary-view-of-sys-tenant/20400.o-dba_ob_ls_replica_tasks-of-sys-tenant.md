# oceanbase.DBA_OB_LS_REPLICA_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_LS_REPLICA_TASKS`は、現在のテナントで実行中のレプリカレベルのディザスタリカバリタスクを表示します。

## フィールドの説明

| フィールド名                | 型           | NULL許容     | 説明               |
|------------------------|----------------|--------------------|--------------------|
| LS_ID                  | bigint(20)     | NO                 |   ログストリームID        |
| TASK_TYPE              | varchar(64)    | NO                 | タスクタイプ。値は以下のとおりです。<ul><li>`MIGRATE REPLICA`：レプリカの移行</li> <li>`ADD REPLICA`：レプリカの追加</li><li>`REMOVE PAXOS REPLICA`：レプリカの削除</li><li>`MODIFY PAXOS REPLICA NUMBER`：規定レプリカ数の変更</li></ul>|
| TASK_ID                | varchar(200)   | NO                 | タスクID            |
| TASK_STATUS            | varchar(2048)  | YES                | タスクの状態。値は以下のとおりです。<ul><li>`INPROGRESS`：スケジュール実行中</li></ul> |
| PRIORITY               | varchar(5)     | NO                 | タスクの優先度。値は以下のとおりです。<ul><li>`LOW`：低優先度タスク。移行タスクのみが低優先度になる場合があります</li><li>`HIGH`：高優先度タスク</li></ul>|
| TARGET_REPLICA_SVR_IP  | varchar(46)    | YES                | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT| bigint(20)     | YES                | ターゲットレプリカが存在するマシンのポート番号 |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20)| YES                | ログストリームの目標のPaxos規定レプリカ数 |
| TARGET_REPLICA_TYPE    | varchar(16)    | YES                | ターゲットレプリカタイプ |
| SOURCE_REPLICA_SVR_IP  | varchar(46)    | YES                | ソースレプリカが存在するマシンのIPアドレス。</br>レプリカの削除や規定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLとして表示されます。|
| SOURCE_REPLICA_SVR_PORT| bigint(20)      |YES                 | ソースレプリカが存在するマシンのポート番号。</br>レプリカの削除や規定レプリカ数の変更などのタスクでは、このフィールドは無効で、0として表示されます。|
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20)| YES                | ログストリームの元のPaxos規定レプリカ数 |
| SOURCE_REPLICA_TYPE    | varchar(16)    | YES                | ソースレプリカタイプ。</br>レプリカの削除や規定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLとして表示されます。 |
| DATA_SOURCE_SVR_IP     | varchar(46)    | YES                | データソースのIPアドレス   <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>    |
| DATA_SOURCE_SVR_PORT   | bigint(20)     | YES                | データソースのポート番号   <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>    |
| IS_MANUAL              | varchar(6)     | NO                 | ディザスタリカバリタスクの生成元。取り得る値：<ul><li>`TRUE`：手動運用コマンドによってトリガーされたディザスタリカバリタスクを示します</li><li>`FALSE`：デフォルト値。RS層のディザスタリカバリ機能によって自動生成されたディザスタリカバリタスクを示します</li></ul>    <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>   |
| TASK_EXEC_SVR_IP       | varchar(46)    | YES                | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT     | bigint(20)     | YES                | タスク実行マシンのポート番号 |
| CREATE_TIME            | datetime       | NO                 | タスクの生成日時 |
| START_TIME             | datetime       | NO                 | タスクがスケジュールされた日時 |
| MODIFY_TIME            | datetime       | NO                 | タスクの状態が更新された日時 |
| COMMENT                | varchar(2048)  | YES                | タスク生成理由の備考 |
| CONFIG_VERSION         | varchar(128)   | YES                | ディザスタリカバリタスク実行時のclog層のconfig_version情報を記録 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0バージョンから導入されました。</p></main>  |
