# oceanbase.DBA_SCHEDULER_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのスケジューラー作業の情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| ------ | ------ | ------ | ------ |
| OWNER                         | varchar(128) | NO   | スケジューラジョブの所有者|
| JOB_NAME                      | varchar(128) | NO   | スケジューラジョブ名  |
| JOB_SUBNAME                   | varchar(128) | NO   | スケジューラジョブのサブ名 |
| JOB_STYLE                     | varchar(17)  | YES  | デフォルト値はNULL |
| JOB_CREATOR                   | varchar(128) | NO   | スケジューラジョブの作成者 |
| CLIENT_ID                     | varchar(65)  | NO   | ジョブを作成したユーザーのクライアント識別子 |
| GLOBAL UID                    | varchar(33)  | NO   | ジョブを作成したユーザーのグローバルユーザー識別子 |
| PROGRAM_OWNER                 | text         | NO   | ジョブに関連するプログラムの所有者|
| PROGRAM_NAME                  | text         | YES  | ジョブに関連するプログラム名 |
| JOB_TYPE                      | varchar(16)  | YES  | ジョブ操作タイプ：<ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul> |
| JOB_ACTION                    | text         | YES  | 組み込みジョブ操作 |
| NUMBER_OF_ARGUMENTS           | bigint(20)   | YES  | ジョブパラメータの組み込み数 |
| SCHEDULE_OWNER                | text         | NO   | ジョブで使用されるスケジュールの所有者 |
| SCHEDULE_NAME                 | text         | NO   | ジョブで使用されるスケジュール名 |
| SCHEDULE_TYPE                 | varchar(12)  | NO   | デフォルト値はNULL |
| START_DATE                    | datetime(6)  | YES  | ジョブの元のスケジュール開始日 |
| REPEAT_INTERVAL               | text         | YES  | 組み込みスケジュールPL/SQL式またはカレンダーストリング |
| EVENT_QUEUE_OWNER             | varchar(128) | NO   | イベントが発生するソースキューの所有者 |
| EVENT_QUEUE_NAME              | varchar(128) | NO   | イベントが発生するソースキューの名前 |
| EVENT_QUEUE_AGENT             | text         | NO   | ユーザーがイベントソースキューで使用するAQエージェントの名前 |
| EVENT_CONDITION               | text         | NO   | ソースキュー上のイベントのサブスクリプションルール |
| EVENT_RULE                    | varchar(261) | NO   | コーディネーターがイベントベースのジョブをトリガーするために使用するルール名 |
| FILE_WATCHER_OWNER            | varchar(261) | NO   | そのジョブが基づいているファイルウォッチャーの所有者 |
| FILE_WATCHER_NAME             | varchar(261) | NO   | そのジョブが基づいているファイルウォッチャーの名前 |
| END_DATE                      | datetime(6)  | YES  | ジョブが実行されなくなる日付 |
| JOB_CLASS                     | varchar(128) | YES  | ジョブに関連付けられたジョブカテゴリ名 |
| ENABLED                       | varchar(5)   | YES  | ジョブが有効かどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| AUTO_DROP                     | varchar(5)   | YES  | ジョブ完了後に削除されるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul>  |
| RESTART_ON_RECOVERY           | varchar(5)   | NO   | デフォルト値はNULL |
| RESTART_ON_FAILURE            | varchar(5)   | NO   | デフォルト値はNULL |
| STATE                         | varchar(15)  | YES  | ジョブの現状：<ul><li>DISABLED</li><li>RETRY SCHEDULED</li><li>SCHEDULED</li><li>BLOCKED</li><li>RUNNING</li><li>COMPLETED</li><li>BROKEN</li><li>FAILED</li><li>REMOTE</li><li>RESOURCE_UNAVAILABLE</li><li>SUCCEEDED</li><li>CHAIN_STALLED</li></ul> |
| JOB_PRIORITY                  | bigint(0)    | NO   | このジョブが同種の他のジョブに対する優先順位 |
| RUN_COUNT                     | bigint(20)   | YES  | ジョブが実行された回数 |
| MAX_RUNS                      | bigint(0)    | NO   | ジョブ計画の最大実行回数 |
| FAILURE_COUNT                 | bigint(20)   | YES  | ジョブの実行失敗回数 |
| MAX_FAILURES                  | bigint(0)    | NO   | 損傷としてマークされる前にジョブの失敗を許容する回数 |
| RETRY_COUNT                   | bigint(20)   | YES  | ジョブの再試行回数 |
| LAST_START_DATE               | datetime(6)  | YES  | ジョブが実行を開始した最終日付 |
| LAST_RUN_DURATION             | bigint(20)   | YES  | 前回の実行中にジョブを完了するのにかかった時間 |
| NEXT_RUN_DATE                 | datetime(6)  | NO   | ジョブ計画の次回実行日 |
| SCHEDULE_LIMIT                | bigint(0)    | NO   | まだ実行されていないジョブが再スケジュールされる時刻 |
| MAX_RUN_DURATION              | bigint(20)   | YES  | ジョブの実行を許可する最長時間 |
| LOGGING_LEVEL                 | varchar(11)  | NO   | デフォルト値はNULL |
| STORE_OUTPUT                  | varchar(5)   | NO   | デフォルト値はNULL |
| STOP_ON_WINDOW_CLOSE          | varchar(5)   | NO   | デフォルト値はNULL |
| INSTANCE_STICKINESS           | varchar(5)   | NO   | デフォルト値はNULL |
| RAISE_EVENTS                  | text         | NO   | デフォルト値はNULLです |
| SYSTEM                        | varchar(5)   | NO   | デフォルト値はNULLです |
| JOB_WEIGHT                    | bigint(0)    | NO   | ジョブの重み。スケジューリング時の優先順位を指定するために使用されます。 |
| NLS_ENV                       | text         | YES  | ジョブの国語環境設定。 |
| SOURCE                        | varchar(128) | NO   | ジョブのソースコードまたはスクリプト。 |
| NUMBER_OF_DESTINATIONS        | bigint(0)    | NO   | ジョブのターゲット数。 |
| DESTINATION_OWNER             | varchar(261) | NO   | ジョブターゲットの所有者。 |
| DESTINATION                   | varchar(261) | NO   | ジョブのターゲット、つまりジョブが実行する対象または場所。 |
| CREDENTIAL_OWNER              | varchar(128) | NO   | 資格証の所有者。 |
| CREDENTIAL_NAME               | varchar(128) | NO   | 資格証の名前。 |
| INSTANCE_ID                   | bigint(21)   | YES  | ユーザーがジョブの実行を要求するインスタンス |
| DEFERRED_DROP                 | varchar(5)   | NO   | ジョブの削除を遅延させるかどうか。 |
| ALLOW_RUNS_IN_RESTRICTED_MODE | varchar(5)   | NO   | ジョブが制限モードで実行されるかどうかを許可するかどうか。 |
| COMMENTS                      | text         | YES  | ジョブのコメントまたは説明情報。 |
| FLAGS                         | bigint(20)   | NO   | ジョブのフラグビット。 |
| RESTARTABLE                   | varchar(5)   | NO   | ジョブが再起動可能かどうか。 |
| CONNECT_CREDENTIAL_OWNER      | varchar(128) | NO   | 接続資格証の所有者。 |
| CONNECT_CREDENTIAL_NAME       | varchar(128) | NO   | 接続資格証の名前。 |
