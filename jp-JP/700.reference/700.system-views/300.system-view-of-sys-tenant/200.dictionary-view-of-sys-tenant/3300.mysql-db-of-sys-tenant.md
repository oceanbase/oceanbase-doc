# mysql.db

<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

データベースレベルの権限情報を表示するために使用されます。

## フィールドの説明

|       **フィールド名**        |    **タイプ**    | **NULLを許容するか** |                                 **説明**       |
|-----------------------|--------------|----------------|------------------------------------------------------------------------|
| host                  | varchar(128) | NO             | ホスト名                                                                    |
| db                    | varchar(128) | NO             | データベース名                                                                   |
| user                  | varchar(128) | NO             | ユーザー名                                                                    |
| select_priv           | varchar(1)   | NO             | select文を実行できるかどうか                                                        |
| insert_priv           | varchar(1)   | NO             | insert文を実行できるかどうか                                                        |
| update_priv           | varchar(1)   | NO             | update文を実行できるかどうか                                                        |
| delete_priv           | varchar(1)   | NO             | delete文を実行できるかどうか                                                        |
| create_priv           | varchar(1)   | NO             | create文を実行できるかどうか                                                        |
| drop_priv             | varchar(1)   | NO             | drop文を実行できるかどうか                                                          |
| grant_priv            | varchar(1)   | NO             | 権限付与操作を実行できるかどうか                                                              |
| references_priv        | varchar(1)   | NO             | 現在使用されていない                                                                   |
| index_priv            | varchar(1)   | NO             | indexを作成できるかどうか                                                            |
| alter_priv            | varchar(1)   | NO             | `alter table`文を実行できるかどうか                                                 |
| create_tmp_table_priv | varchar(1)   | NO             | 一時テーブルを作成できるかどうか。現在、このフィールドは使用されていません                |
| lock_tables_priv      | varchar(1)   | NO             | `LOCK TABLES`ステートメントを実行できるかどうか。ユーザーにはテーブル上のSELECT権限も必要です。現在、このフィールドは使用されていません |
| create_view_priv      | varchar(1)   | NO             | `CREATE VIEW`ステートメントを実行できるかどうか                                                 |
| show_view_priv        | varchar(1)   | NO             | `SHOW CREATE VIEW`ステートメントを実行できるかどうか                                            |
| create_routine_priv   | varchar(1)   | NO             | ストアドプロシージャを作成できるかどうか（現在使用されていない）   |
| alter_routine_priv    | varchar(1)   | NO             | `ALTER FUNCTION`ステートメントを実行できるかどうか（現在使用されていない）                         |
| execute_priv          | varchar(1)   | NO             | ストアドプロシージャを実行できるかどうか（現在使用されていない）      |
| event_priv            | varchar(1)   | NO             | イベントを作成、削除、または変更できるかどうか（現在使用されていない）    |
| trigger_priv          | varchar(1)   | NO             | `CREATE TRIGGER`または`DROP TRIGGER`ステートメントを実行できるかどうか。現在、このフィールドは使用されていません   |

## クエリ例

ユーザー`test2`のデータベースレベルの権限情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM mysql.db WHERE user='test2' \G
```
