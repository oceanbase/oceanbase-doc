# oceanbase.DBA_OB_TABLEGROUP_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.2.0以降では、テーブルグループにはパーティションの概念がなくなりました。このビューは使用されなくなりました。ユーザーはこのビューをクエリできますが、クエリ結果は空になります。</li>
<li>V4.2.0以降では、ビュー<a href="22500.o-dba_ob_tablegroups-of-sys-tenant.md">DBA_OB_TABLEGROUPS</a>を使用してテーブルグループ情報を照会できます。テーブルグループの詳細については、<a href="../../../300.database-object-management/100.manage-object-of-mysql-mode/400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md">テーブルグループについて</a>を参照してください。</li>
</ul>
</main>

## 機能の概要

パーティションを持つテーブルグループのサブパーティション情報を表示します。

## フィールドの説明

|         フィールド名          |      型       | NULL許容 |        説明        |
|-----------------------|---------------|------------|----------------------------------------------------------------------|
| TABLEGROUP_NAME       | varchar(128)  | NO         | TABLEGROUP名    |
| PARTITION_NAME        | varchar(64)   | NO         | テーブルグループのサブパーティションに対応するパーティション名  |
| SUBPARTITION_NAME     | varchar(64)   | NO         | テーブルグループのサブパーティション名         |
| HIGH_VALUE            | varchar(4096) | NO         | この値は`NULL`です                                                       |
| HIGH_VALUE_LENGTH     | bigint(20)    | NO         | この値は`NULL`です                                                                          |
| PARTITION_POSITION    | bigint(20) unsigned | NO   | この値は`NULL`です      |
| SUBPARTITION_POSITION | bigint(20) unsigned | NO   | この値は`NULL`です             |
