# oceanbase.CDB_OB_SYNC_STANDBY_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_SYNC_STANDBY_DEST` は、すべてのテナントの強同期ダウンストリーム情報を表示するために使用されます。

## フィールドの説明

| フィールド名   | 型          | NULL許容 | 説明                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | bigint(20)    | NO             | テナントID     |
| DEST_ID   | bigint(20)    | NO             | 強同期スタンバイテナントのID。現在、1つのプライマリテナントがIDが0の強同期スタンバイテナントを1つしか持てない制限があります     |
| VALUE     | longtext      | NO             | 強同期スタンバイテナントの情報。ip_list、ログイン名、パスワード、cluster_idなどが含まれます     |

## クエリ例

システムテナントがすべてのテナントの強同期ダウンストリーム情報を確認します。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_SYNC_STANDBY_DEST\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
TENANT_ID: 1002
  DEST_ID: 0
    VALUE: IP_LIST=6.xx.xxx.xx:2881+2882,USER=rep_user@standby_tenant,PASSWORD=*****************************************************************,TENANT_ID=1002,CLUSTER_ID=10002,COMPATIBILITY_MODE=MYSQL,IS_ENCRYPTED=true,net_timeout=20000000,health_check_time=40000000
1 row in set
```
