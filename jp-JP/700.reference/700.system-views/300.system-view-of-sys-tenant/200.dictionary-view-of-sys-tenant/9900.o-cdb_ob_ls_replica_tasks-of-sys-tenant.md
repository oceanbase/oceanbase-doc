# oceanbase.CDB_OB_LS_REPLICA_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`CDB_OB_LS_REPLICA_TASKS`は、すべてのテナントで実行中のレプリカレベルのディザスタリカバリタスクを表示するために使用されます。システムテナントのみが参照できます。

## フィールドの説明

| フィールド名                 | 型           |  NULL許容 |   説明                             |
|-------------------------|----------------|-----------------|------------------------------------|
| TENANT_ID              | bigint(20)     | NO                 | テナントID          |
| LS_ID                  | bigint(20)     | NO                 | ログストリームID        |
| TASK_TYPE              | varchar(64)    | NO                 | タスクタイプ。値は以下のとおりです：<ul><li>MIGRATE REPLICA：レプリカの移行</li> <li>ADD REPLICA：レプリカの追加</li><li>REMOVE PAXOS REPLICA：レプリカの削除</li><li>MODIFY PAXOS REPLICA NUMBER：法定レプリカ数の変更</li></ul>|
| TASK_ID                | varchar(200)   | NO                 | タスクID            |
| TASK_STATUS            | varchar(2048)  | YES                | タスクの状態。値は以下のとおりです：<ul><li>`INPROGRESS`：スケジュール実行中</li> <li>`WAITING`：タスク待機中</li></ul> |
| PRIORITY               | varchar(5)     | NO                 | タスクの優先順位。値は以下のとおりです：<ul><li>LOW：低優先順位タスク。移行タスクのみが低優先順位になる可能性があります</li><li>HIGH：高優先順位タスク</li></ul>|
| TARGET_REPLICA_SVR_IP  | varchar(46)    | YES                | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT| bigint(20)     | YES                | ターゲットレプリカが存在するマシンのポート番号 |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20)| YES                | ログストリームのターゲット法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE    | varchar(16)    | YES                | ターゲットレプリカタイプ |
| SOURCE_REPLICA_SVR_IP  | varchar(46)    | YES                | ソース側レプリカが存在するマシンのIPアドレス。</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLとして表示されます。|
| SOURCE_REPLICA_SVR_PORT| bigint(20)      |YES                 | ソース側レプリカが存在するマシンのポート番号。</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、0として表示されます。|
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20)| YES                | ログストリームの元法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE    | varchar(16)    | YES                | ソース側レプリカタイプ。</br>レプリカの削除や法定レプリカ数の変更などのタスクでは、このフィールドは無効で、NULLとして表示されます。 |
| DATA_SOURCE_SVR_IP     | varchar(46)    | YES                | データソースIP  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>   |
| DATA_SOURCE_SVR_PORT   | bigint(20)     | YES                | データソースPORT <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>    |
| IS_MANUAL              | varchar(6)     | NO                 | ディザスタリカバリタスクの出所。取り得る値：<ul><li>`TRUE`：手動運用コマンドによってトリガーされたディザスタリカバリタスクを示します</li><li>`FALSE`：デフォルト値。RS層ディザスタリカバリによって自動生成されたディザスタリカバリタスクを示します</li></ul>  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.3バージョンから導入されました。</li></ul></main>   |
| TASK_EXEC_SVR_IP       | varchar(46)    | YES                | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT     | bigint(20)     | YES                | タスク実行マシンのポート番号 |
| CREATE_TIME            | datetime       | NO                 | タスク生成時間 |
| START_TIME             | datetime       | NO                 | タスクスケジュール時間 |
| MODIFY_TIME            | datetime       | NO                 | タスク状態更新時間 |
| COMMENT                | varchar(2048)  | YES                | タスク生成理由の備考 |
| CONFIG_VERSION         | varchar(128)   | YES                | ディザスタリカバリタスク実行時のclog層のconfig_version情報を記録 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.0バージョンから導入されました。</p></main>  |
