# oceanbase.CDB_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_TRANSFER_PARTITION_TASK_HISTORY` は、すべてのテナントで実行されたTransfer Partitionタスクの履歴を表示します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID        | bigint(20)   | NO   |  ユーザーテナントID   |
| TASK_ID          | bigint(20)   | NO   |  Transfer Partitionタスクの一意の識別子   |
| CREATE_TIME      | timestamp(6) | NO   |  作成時間   |
| FINISH_TIME      | timestamp(6) | NO   |  タスク完了時間。成功・キャンセルを含む   |
| TABLE_ID         | bigint(20)   | NO   |  Transferのパーティションが存在するテーブルID   |
| OBJECT_ID        | bigint(20)   | NO   |  Transferのパーティションの`OBJECT_ID`   |
| DEST_LS          | bigint(20)   | NO   |  宛先ログストリーム   |
| BALANCE_JOB_ID   | bigint(20)   | NO   |  タスク実行時に関連付けられたロードバランシングジョブID   |
| TRANSFER_TASK_ID | bigint(20)   | NO   |  タスク実行時に関連付けられたTransferタスクID   |
| STATUS           | varchar(64)  | NO   |  タスク状態：<ul><li>COMPLETED：タスク実行成功</li><li>FAILED:  タスク失敗</li></ul>   |
| COMMENT          | longtext     | YES  |  コメント情報   |

## クエリ例

テナントIDが1006のテナントで実行されたTransfer Partitionタスクの履歴を確認します。

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TRANSFER_PARTITION_TASK_HISTORY  WHERE TENANT_ID = 1006;
```

クエリ結果は次のとおりです：

