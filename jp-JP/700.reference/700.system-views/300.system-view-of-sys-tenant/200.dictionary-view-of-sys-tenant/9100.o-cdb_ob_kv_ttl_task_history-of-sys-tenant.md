# oceanbase.CDB_OB_KV_TTL_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV3.1.4バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下で、すべてのテナントの履歴TTLタスクを参照するために使用します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)  | NO | テナントID |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TABLE_ID | bigint(20) | NO | テーブルID |
| TABLET_ID | bigint(20) | NO | Tablet ID |
| TASK_ID | bigint(20) | NO | タスクID。1から開始 |
| START_TIME | timestamp(6) | NO | タスク開始時間 |
| END_TIME | timestamp(6) | NO | タスク終了時間 |
| TRIGGER_TYPE | varchar(8) | NO | タスクのトリガータイプ。PERIODICとUSERの2種類が含まれます |
| STATUS | varchar(13) | NO | タスクのステータス。タスクステータスの説明を参照 |
| TTL_DEL_CNT | bigint(20) | NO | `time_to_live` に基づいて削除されたレコード数 |
| MAX_VERSION_DEL_CNT | bigint(20) | NO | `MAX_VERSION` に基づいて削除されたレコード数 |
| SCAN_CNT | bigint(20) | NO | タスクでスキャンされたレコード数 |
| RET_CODE | varchar(512) | NO | タスクの戻りコード |
| SCAN_INDEX | varchar(128) | NO | タスクでスキャンに使用されたインデックス。デフォルトはPRIMARY KEY |

## クエリ例

システムテナント配下で、すべてのテナントの履歴TTLタスクを参照します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_KV_TTL_TASK_HISTORY LIMIT 10\G;
```
