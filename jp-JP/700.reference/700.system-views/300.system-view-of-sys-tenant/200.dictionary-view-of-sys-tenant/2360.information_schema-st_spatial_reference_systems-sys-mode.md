# information_schema.ST_SPATIAL_REFERENCE_SYSTEMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

システムが現在サポートしている空間参照座標系の情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SRS_ID | bigint(20) unsigned | NO | 空間座標系ID |
| SRS_NAME | varchar(128) | NO | 空間座標系名 |
| ORGANIZATION | varchar(256) | YES | 空間座標系が基づく座標系の組織名 |
| ORGANIZATION_COORDSYS_ID | bigint(20) unsigned | YES | 空間座標系が基づく座標系の組織ID |
| DEFINITION | varchar(4096) | NO | 空間座標系の定義。OGC（Open Geospatial Consortium）が定義するSRS WKT文字列形式 |
| DESCRIPTION | varchar(2048) | YES | 空間座標系の説明情報。システム組み込みの座標系はデフォルトでNULL |
