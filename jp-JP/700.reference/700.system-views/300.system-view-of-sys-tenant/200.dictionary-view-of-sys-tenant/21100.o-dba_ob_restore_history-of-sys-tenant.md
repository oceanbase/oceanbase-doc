# oceanbase.DBA_OB_RESTORE_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで完了したテナントレベルの復元タスクを表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| JOB_ID                           | bigint(20)          |  NO   |復元に属するjob_id、1回の復元タスクに対応します |
| RESTORE_TENANT_NAME              | varchar(128)        |  NO   |復元されたテナント名  |
| RESTORE_TENANT_ID                | bigint(20)          |  NO   |復元されたテナントID  |
| BACKUP_TENANT_NAME               | varchar(128)        |  NO   |バックアップのソーステナント名    |
| BACKUP_TENANT_ID                 | bigint(20)          |  NO   |バックアップのソーステナントID  |
| BACKUP_CLUSTER_NAME              | varchar(128)        |  NO   |バックアップのソースクラスタ名   |
| BACKUP_DEST                      | longtext            |  NO   |バックアップセットパス、ユーザーが入力したデータバックアップパスとログアーカイブパス   |
| RESTORE_SCN                      | bigint(20) unsigned |  NO   |ユーザー指定の復元ポイント  |
| RESTORE_SCN_DISPLAY              | datetime(6)         |  NO   |ユーザー指定の復元ポイントのタイムスタンプ表記  |
| RESTORE_OPTION                   | varchar(4096)       |  NO   |復元オプション、復元開始時にユーザーが指定した `restore_option`  |
| RESTORE_TYPE                      | varchar(4096)            |  NO   |復元タイプ。<ul> <li>`FULL`：フル復元を示します</li> <li> `QUICK`：クイック復元を示します</li></ul>   <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.5 BP1バージョンから導入されました。</p></main>  |
| START_TIMESTAMP                  | timestamp(6)        |  YES   |復元タスク開始のタイムスタンプ  |
| FINISH_TIMESTAMP                 | timestamp(6)        |  YES   |復元タスク終了のタイムスタンプ  |
| STATUS                           | varchar(64)         |  NO   |復元結果：<ul> <li> `SUCCESS`：復元が成功したことを示します </li> <li> `FAILED`：復元に失敗したことを示します </li></ul> |
| BACKUP_PIECE_LIST                | longtext            |  NO   |復元に依存するログアーカイブシャーディングパスリスト、シャーディング間は `,` で区切ります。例：`file:///data/nfs/backup/archive/2_1_2,file:///data/nfs/backup/archive/2_1_3` |
| BACKUP_SET_LIST                  | longtext            |  NO   |復元に依存するデータバックアップセットパスリスト、バックアップセット間は `,` で区切ります。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc` |
| BACKUP_CLUSTER_VERSION           | bigint(20)          |  NO   |バックアップソースクラスタのバージョン番号 |
| LS_COUNT                         | bigint(20)          |  NO   |復元ログストリームの合計数   |
| FINISH_LS_COUNT                  | bigint(20)          |  NO   |復元済みログストリームの数  |
| TABLET_COUNT                     | bigint(20)          |  NO   |復元シャーディングの合計数  |
| FINISH_TABLET_COUNT              | bigint(20)          |  NO   |復元済みシャーディングの数  |
| TOTAL_BYTES                      | bigint(20)          |  NO   |復元総バイト数  |
| TOTAL_BYTES_DISPLAY              | varchar(27)         |  NO   |復元総バイト数、ストレージ容量単位で表示  |
| FINISH_BYTES                     | bigint(20)          |  NO   |復元済みバイト数  |
| FINISH_BYTES_DISPLAY             | varchar(27)         |  NO   |復元済みバイト数、ストレージ容量単位で表示  |
| DESCRIPTION                      | varchar(1024)       |  YES   |復元コマンドで指定された `DESCRIPTION` 情報  |
| COMMENT                          | varchar(1024)       |  YES   |復元失敗時に失敗情報を記録します  |
