# oceanbase.CDB_OB_DATABASES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下における、すべてのテナントのデータベースメタ情報を表示します。

## フィールドの説明

|     フィールド名      |      型       | NULL許容 |             説明             |
|---------------|---------------|------------|----------------------------|
| TENANT_ID     | bigint(20)    | NO         | テナントID                      |
| DATABASE_NAME | varchar(128)  | NO         | データベース名                       |
| IN_RECYCLEBIN | varchar(3)    | NO         | データベースがゴミ箱にあるかどうか：<ul><li> `YES` </li><li> `NO`</li></ul> |
| COLLATION     | varchar(128)  | NO         | データベースのデフォルトCOLLATION            |
| READ_ONLY     | varchar(3)    | NO   | <ul><li>YES：読み取り専用</li><li>NO：読み書き可能</li></ul>    |
| COMMENT       | varchar(2048) | NO         | データベースの説明                     |
| TABLEGROUP_NAME | varchar(128)  | NO       | DataBaseにバインドされたテーブルグループ名 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.1バージョンから導入されました。</p></main>|

## クエリ例

システムテナント配下で、テナントIDが1002のテナントのデータベースメタ情報を照会します。

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_DATABASES WHERE TENANT_ID =1002 LIMIT 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
      TENANT_ID: 1002
  DATABASE_NAME: oceanbase
  IN_RECYCLEBIN: NO
      COLLATION: utf8mb4_general_ci
      READ_ONLY: NO
        COMMENT: system database
TABLEGROUP_NAME: NULL
1 row in set
```
