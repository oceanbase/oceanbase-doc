# oceanbase.CDB_INDEXES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのINDEX情報を表示します。
