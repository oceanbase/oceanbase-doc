# oceanbase.CDB_PART_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのパーティションテーブルのパーティション情報を表示します。
