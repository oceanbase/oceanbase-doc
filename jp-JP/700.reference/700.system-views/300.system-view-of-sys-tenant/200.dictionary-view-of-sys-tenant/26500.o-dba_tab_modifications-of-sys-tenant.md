# oceanbase.DBA_TAB_MODIFICATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のテーブルの累積変更情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TABLE_OWNER | varchar(128) | NO | 変更されたテーブルが属するデータベース |
| TABLE_NAME | varchar(128) | NO | 変更されたテーブル名 |
| PARTITION_NAME | varchar(128) | NO | 変更されたパーティション名 |
| SUBPARTITION_NAME | varchar(128) | NO | 変更されたサブパーティション名 |
| INSERTS | bigint(20) | NO | 累計挿入回数 |
| UPDATES | bigint(20) | NO | 累計更新回数 |
| DELETES | bigint(20) | NO | 累計削除回数 |
| TIMESTAMP | date | NO | テーブルが最後に変更された日時 |
| TRUNCATED | varchar(3) | NO | 現在のところ実質的な意味はありません。デフォルトはNULLです |
| DROP_SEGMENTS | bigint(0) | NO | 現在のところ実質的な意味はありません。デフォルトはNULLです |
