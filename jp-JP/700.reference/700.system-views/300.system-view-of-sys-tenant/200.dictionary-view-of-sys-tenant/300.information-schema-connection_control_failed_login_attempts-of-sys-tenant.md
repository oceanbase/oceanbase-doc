# information_schema.CONNECTION_CONTROL_FAILED_LOGIN_ATTEMPTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

`information_schema.CONNECTION_CONTROL_FAILED_LOGIN_ATTEMPTS`ビューは、異なるユーザーによるログイン失敗の試行回数を表示します。

## フィールドの説明

|    **フィールド名**     |    **タイプ**    | **NULLを許容するか** |                             **説明**                             |
|-----------------|--------------|----------------|----------------------------------------------------------------|
| USERHOST        | varchar(261) | NO             | ログイン失敗のユーザー名とホスト情報の組み合わせを表し、その形式は `<user_name>@<hostname or ip address>` です |
| FAILED_ATTEMPTS | bigint(20)   | NO             | ログイン失敗の試行回数                                                      |

## クエリ例

ユーザーのログイン失敗の試行回数を確認します。

```shell
obclient> SELECT * FROM information_schema.CONNECTION_CONTROL_FAILED_LOGIN_ATTEMPTS;
```

クエリ結果は次のとおりです：

```shell
+-------------+-----------------+
| USERHOST    | FAILED_ATTEMPTS |
+-------------+-----------------+
| 'test'@'%'  |               5 |
+-------------+-----------------+
1 row in set
```
