# oceanbase.DBA_OB_UNITS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのユニット情報を表示します。

## フィールド説明

|         フィールド名          |      型      | NULL許容 |   説明   |
|-----------------------|--------------|------------|--------------------|
| UNIT_ID| bigint(20)   | NO         | Unit ID|
| TENANT_ID             | bigint(20)   | NO         | Unitが属するテナントID：<ul><li>`NULL`：現在のUnitはどのテナントにも属していません   </li><li> 有効値：ターゲットテナントID </li></ul>   |
| STATUS | varchar(128) | NO         | <ul><li>`ACTIVE`：正常状態   </li> <li>`ADDING`：増加中の状態</li> <li> `DELETING`：削除中の状態</li></ul>       |
| RESOURCE_POOL_ID      | bigint(20)   | NO         | Unitが属するリソースプールID        |
| UNIT_GROUP_ID         | bigint(20)   | NO         | Unitが属するUnitグループID|
| CREATE_TIME           | timestamp(6) | YES        | Unit作成日時             |
| MODIFY_TIME           | timestamp(6) | YES        | Unit変更日時     |
| ZONE   | varchar(128) | NO         | Zone名|
| SVR_IP | varchar(46)  | NO         | Unitが属するOBServer IP  |
| SVR_PORT              | bigint(20)   | NO         | Unitが属するOBServerポート番号 |
| MIGRATE_FROM_SVR_IP   | varchar(46)  | NO         | <ul><li>`NULL`：Unitは移行中ではありません </li><li>有効値：Unitが移行中である場合、移行元サーバーのIPアドレスを示します </li></ul>  |
| MIGRATE_FROM_SVR_PORT | bigint(20)   | NO         | <ul><li> `NULL`：Unitは移行中ではありません </li><li> 有効値：Unitが移行中である場合、移行元サーバーのポート番号を示します </li></ul>     |
| MANUAL_MIGRATE        | varchar(3)   | NO         | <ul><li>`NULL`：Unitは移行中ではありません </li><li>`YES`：ユーザーが発起したUnit移行 </li><li>`NO`：自動で発起されたUnit移行 </li></ul>   |
| UNIT_CONFIG_ID        | bigint(20)   | NO         |  Unitが採用する仕様ID   |
| MAX_CPU               | double       | NO         |  CPUスペックの上限   |
| MIN_CPU               | double       | NO         |  CPUスペックの下限   |
| MEMORY_SIZE           | bigint(20)   | NO         |  メモリ仕様、単位はバイト   |
| LOG_DISK_SIZE         | bigint(20)   | NO         |  ログディスクの仕様、単位はバイト   |
| DATA_DISK_SIZE        | bigint(20)   | NO         |  Unitが使用可能なローカルキャッシュサイズ、単位はバイト。共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このフィールドの値は`NULL`となり、定義されていないことを意味し、他のテナントのディスク容量を競合的に使用できます。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>   |
| MAX_IOPS              | bigint(20)   | NO         |  ディスクIOPSの上限値   |
| MIN_IOPS              | bigint(20)   | NO         |  ディスクIOPSの下限値   |
| IOPS_WEIGHT           | bigint(20)   | NO         |  IOPS重み   |
| MAX_NET_BANDWIDTH     | bigint(20)   | NO         |  Unitの最大ネットワーク帯域幅、単位はバイト  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>    |
| NET_bandWIDTH_WEIGHT  | bigint(20)   | NO         |  Unitのネットワーク帯域幅の重み値 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>     |
| REPLICA_TYPE          | varchar(7)   | NO         |  レプリカタイプ。デフォルトは`FULL` <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、<code>REPLICA_TYPE</code>フィールドはV4.4.0 BP1バージョンから導入されました。</li> <li>V4.5.x系では、<code>REPLICA_TYPE</code>フィールドはV4.5.0バージョンから導入されました。</li><li>V4.2.5系では、<code>REPLICA_TYPE</code>フィールドはV4.2.5 BP7バージョンから導入されました。</li></ul></main>  |
