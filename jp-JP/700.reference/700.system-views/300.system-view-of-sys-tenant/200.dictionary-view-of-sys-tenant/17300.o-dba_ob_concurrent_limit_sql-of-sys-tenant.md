# oceanbase.DBA_OB_CONCURRENT_LIMIT_SQL

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのルーティングルールのアウトラインに関する情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | timestamp(6) | YES | 作成タイムスタンプ |
| MODIFY_TIME | timestamp(6) | YES | 変更タイムスタンプ |
| TENANT_ID | bigint(20) | NO | テナントID |
| DATABASE_ID | bigint(20) | NO | データベースID |
| OUTLINE_ID | bigint(20) | NO | スロットルルールのアウトラインID |
| DATABASE_NAME | varchar(128) | NO | データベース名 |
| OUTLINE_NAME | varchar(128) | NO | スロットルルールのアウトライン名 |
| OUTLINE_CONTENT | longtext | NO | スロットルルールに対応するアウトライン内容、Emptyとすることができる |
| VISIBLE_SIGNATURE | longtext | NO | Signatureの逆シリアライズ結果 |
| SQL_TEXT | longtext | NO | スロットルルールアウトライン作成時にon句で指定されたSQL |
| CONCURRENT_NUM | bigint(20) | NO | 現在のSQL制限の並列数 |
| LIMIT_TARGET | longtext | NO | スロットルされるSQL |

## クエリ例

システムテナントは、自身のテナントのルーティングルールのアウトラインに関する情報を照会します。

```shell
obclient[oceanbase]>  SELECT * FROM oceanbase.DBA_OB_CONCURRENT_LIMIT_SQL\G
```
