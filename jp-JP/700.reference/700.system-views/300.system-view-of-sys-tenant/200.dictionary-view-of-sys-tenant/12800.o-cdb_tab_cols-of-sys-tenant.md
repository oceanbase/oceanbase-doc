# oceanbase.CDB_TAB_COLS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのテーブルおよびビューの列情報を表示します。このビューは `CDB_TAB_COLS_V$` と一致しますが、`NOTES` 列は含まれません。`NOTES` 列は現在利用されていません。

## フィールド説明

| CON_ID               | bigint(20)      | NO         | テナントID                                        |

| USER GENERATED       | varchar(3)      | NO         | 列の生成属性を示します。取り得る値は以下のとおりです：<ul><li>`YES`：この列がユーザー生成の列であることを示します。</li><li>`NO`：この列がシステム生成の列、つまり論理削除された列（ストレージ層では削除されていない）であることを示します。<main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.3.5では、このフィールドはV4.3.5 BP1から有効になります。</p></main>|
