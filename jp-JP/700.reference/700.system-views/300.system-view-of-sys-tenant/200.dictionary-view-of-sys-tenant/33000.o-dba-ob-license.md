# oceanbase.DBA_OB_license

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>このビューはスタンドアロン版にのみ適用されます。分散環境では、このビューのクエリは空になります。</li>
  <li>このビューはV4.2.5 BP3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ユーザーが現在ロードしているライセンス情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| END_USER | varchar(512) | NO | 権限付与されたユーザー名。 |
| LICENSE_ID | varchar(128) | NO | ライセンスのID。 |
| LICENSE_CODE | varchar(128) | NO | 契約番号。 |
| LICENSE_TYPE | varchar(128) | NO | ライセンスの種類。<ul><li>Commercial：Enterprise Editionの略称で、単一マシン版を表します。</li><li>Trial：Trial Editionの略称で、トライアル版を表します。</li></ul>|
| PRODUCT_TYPE | varchar(128) | NO | 製品の種類。<ul><li>SE：Standalone Enterprise Editionの略称で、単一マシン版を表します。</li><li>DE：Distributed Enterprise Editionの略称で、分散型Enterprise Editionを表します。</li></ul>|
| ISSUANCE_DATE | timestamp(6) | NO | ライセンスの発行日時。 |
| ACTIVATION_TIME | timestamp(6) | NO | ライセンスの有効化日時。 |
| EXPIRED_TIME | varchar(128) | NO | ライセンスの有効期限。 |
| OPTIONS | varchar(1024) | NO | ライセンスに含まれる機能オプション。<ul><li>EE：Enterprise Editionの略称で、OceanBaseの単一マシン版の基本機能を表します。</li><li>PS：Primary-Standbyの略称で、OceanBaseの単一マシンクラスタ間レプリケーションオプションを表します。</li><li>MT：Multitenantの略称で、OceanBaseの単一マシンマルチテナントオプションを表します。</li><li>AP：OLAPの略称で、OceanBaseの単一マシンOLAPオプションを表します。</li></ul>|
| NODE_NUM | bigint(20) unsigned | NO | 権限付与されたノード数。単一マシン版では固定値として1が設定されます。 |
| CLUSTER_ULID | varchar(30) | NO | クラスタ起動時に自動生成されます。 |

## クエリ例

システムテナントがロード済みのライセンス情報を確認します。

```shell
obclient [oceanbase]> select * from oceanbase.DBA_OB_LICENSE;
```
