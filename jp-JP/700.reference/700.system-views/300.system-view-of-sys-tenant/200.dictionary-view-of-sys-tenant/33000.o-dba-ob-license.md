# oceanbase.DBA_OB_LICENSE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>このビューは集中型構成でのみ使用できます。分散型構成で問い合わせると、結果は空になります。</li>
  <li>このビューは V4.4.2 BP1 で導入されました。</li></ul>
</main>

## 機能の概要

ユーザーが現在ロードしているライセンス情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| END_USER | varchar(512) | NO | ライセンスの付与先ユーザー名。 |
| LICENSE_ID | varchar(128) | NO | ライセンスID。 |
| LICENSE_CODE | varchar(128) | NO | 契約番号。|
| LICENSE_TYPE | varchar(128) | NO | ライセンスタイプ。<ul><li>Commercial：商用版。</li><li>Trial：試用版。</li></ul>|
| PRODUCT_TYPE | varchar(128) | NO | 製品タイプ。<ul><li>SE：Standalone Enterprise Editionの略で、スタンドアロンのEnterprise版を表します。</li><li>DE：Distributed Enterprise Editionの略で、分散型のEnterprise版を表します。</li></ul>|
| ISSUANCE_DATE | timestamp(6) | NO | ライセンスの発行日時。 |
| ACTIVATION_TIME | timestamp(6) | NO | ライセンスの有効化日時。 |
| EXPIRED_TIME | timestamp(6) | NO | ライセンスの有効期限。 |
| OPTIONS | varchar(1024) | NO | ライセンスに含まれる機能オプション。<ul><li>EE：Enterprise Editionの略で、OceanBaseスタンドアロン版（Enterprise版）の基本機能を表します。</li><li>PS：Primary-Standbyの略で、OceanBaseスタンドアロン版のクラスタ間レプリケーションオプションを表します。</li><li>MT：Multitenantの略で、OceanBaseスタンドアロン版のマルチテナントオプションを表します。</li><li>AP：OLAPの略で、OceanBaseスタンドアロン版のOLAPオプションを表します。</li></ul>|
| CORE_NUM | bigint(20) unsigned | NO | ライセンスで使用が認められたCPUコア数。|
| NODE_NUM | bigint(20) unsigned | NO | ライセンスで使用が認められたノード数。スタンドアロン版では常に1です。|
| CLUSTER_ULID | varchar(30) | NO | クラスタ起動時に自動生成されます。 |

## クエリ例

システムテナントで、読み込み済みのライセンス情報を確認します。

```shell
obclient [oceanbase]> select * from oceanbase.DBA_OB_LICENSE;
```
