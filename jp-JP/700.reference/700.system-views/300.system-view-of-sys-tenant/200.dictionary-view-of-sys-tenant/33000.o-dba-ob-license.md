# oceanbase.DBA_OB_LICENSE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>このビューは集中型にのみ適用されます。分散型では、このビューのクエリ結果は空になります。</li>
  <li>このビューはV4.4.2 BP1バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ユーザーが現在ロードしているライセンス情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| END_USER | varchar(512) | NO | 権限付与されたユーザー名。 |
| LICENSE_ID | varchar(128) | NO | ライセンスのID。 |
| LICENSE_CODE | varchar(128) | NO | 契約番号。|
| LICENSE_TYPE | varchar(128) | NO | ライセンスタイプ。<ul><li>Commercial：商用版。</li><li>Trial：試用版。</li></ul>|
| PRODUCT_TYPE | varchar(128) | NO | 製品タイプ。<ul><li>SE：Standalone Enterprise Editionの略で、単一マシンEnterprise Editionを表します。</li><li>DE：Distributed Enterprise Editionの略で、分散Enterprise Editionを表します。</li></ul>|
| ISSUANCE_DATE | timestamp(6) | NO | ライセンスの発行日時。 |
| ACTIVATION_TIME | timestamp(6) | NO | ライセンスの有効化日時。 |
| EXPIRED_TIME | timestamp(6) | NO | ライセンスの有効期限。 |
| OPTIONS | varchar(1024) | NO | ライセンスに含まれる機能オプション。<ul><li>EE：Enterprise Editionの略で、OceanBase単一マシンEnterprise Editionの基本機能を表します。</li><li>PS：Primary-Standbyの略で、OceanBase単一マシンクラスタ間レプリケーションオプションを表します。</li><li>MT：Multitenantの略で、OceanBase単一マシンマルチテナントオプションを表します。</li><li>AP：OLAPの略で、OceanBase単一マシンOLAPオプションを表します。</li></ul>|
| CORE_NUM | bigint(20) unsigned | NO | 権限付与されたCPUコア数。|
| NODE_NUM | bigint(20) unsigned | NO | 権限付与されたノード数。単一マシン版は固定で1です。|
| CLUSTER_ULID | varchar(30) | NO | クラスタ起動時に自動生成されます。 |

## クエリ例

システムテナントがロードされたライセンス情報を確認する。

```shell
obclient [oceanbase]> select * from oceanbase.DBA_OB_LICENSE;
```
