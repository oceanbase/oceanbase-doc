# oceanbase.DBA_SQL_MANAGEMENT_CONFIG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMにおける構成パラメータを表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(128) | NO | 構成パラメータ名：<ul><li>SPACE_BUDGET_PERCENT</li><li>PLAN_RETENTION_WEEKS</li></ul> |
| PARAMETER_VALUE | text | YES | 構成パラメータの値 |
| LAST_MODIFIED | timestamp(6) | YES | パラメータ値が最後に更新された時間 |
| MODIFIED_BY | varchar(128) | NO | パラメータ値が最後に更新されたユーザー |

## クエリ例

現在のテナントのSPMにおける構成パラメータを確認します。
