## 機能の概要

タイムゾーン名情報（SYSTEM_VIEW）を表示します。

## フィールドの説明

|     フィールド名     |     タイプ      | NULLを許容するか |  説明   |
|--------------|-------------|------------|-------|
| Name         | varchar(64) | NO         | タイムゾーン名  |
| Time_zone_id | bigint(20)  | NO         | タイムゾーンID |
