# oceanbase.DBA_SUBPART_KEY_COLUMNS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のすべてのパーティションオブジェクトに含まれるサブパーティションキーの列を表示します。

## フィールドの説明

|      **フィールド名**      |    **型**     | **NULL許容** |                                                              **説明**                                                              |
|--------------------|---------------|----------------|----------------------------------------------------------------------------------------------------------------------------------|
| OWNER              | varchar(128)  | NO             | パーティションテーブルまたはパーティションインデックスの所有者                                  |
| NAME               | varchar(128)  | NO             | パーティションテーブルまたはパーティションインデックスの名前                                   |
| OBJECT_TYPE        | varchar(5)    | NO             | パーティションオブジェクトのタイプ：<ul><li>TABLE   </li><li> INDEX </li></ul>   |
| COLUMN_NAME        | text | NO             | 列名                                              |
| COLUMN_POSITION    | bigint(21)    | NO             | パーティションキー内の列の位置                                     |
| COLLATED_COLUMN_ID | bigint(0)     | NO             | 現在このフィールドはサポートされていません。現在、このフィールドのデフォルト値はNULLです                       |

## クエリ例

システムテナントが自身のテナント内のパーティションテーブル `tbl2_f_rl` のサブパーティションキーに含まれる列を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPART_KEY_COLUMNS WHERE NAME='tbl2_f_rl';
```

クエリ結果は次のとおりです：

```shell
+-------+-----------+-------------+-------------+-----------------+--------------------+
| OWNER | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-------+-----------+-------------+-------------+-----------------+--------------------+
| test  | tbl2_f_rl | TABLE       | col2        |               1 |               NULL |
+-------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```

## 関連ビューまたはドキュメント

すべてのテナント内のすべてのパーティションオブジェクトに含まれるサブパーティションキーの列を確認するには、[CDB_SUBPART_KEY_COLUMNS](12500.o-cdb_subpart_key_columns-of-sys-tenant.md)を参照してください。
