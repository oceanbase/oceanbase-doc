# oceanbase.CDB_OB_BACKUP_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

クラスタ内のすべてのテナントのバックアップJOBタスクを表示します。ユーザーがバックアップタスクを開始するたびに、1件のJOBタスクレコードが記録されます。

## フィールドの説明

| フィールド名 | フィールド名 | NULL許容 | フィールド名 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| JOB_ID | bigint(20) | NO | バックアップJOBタスクID。1回のバックアップに対応して1件のJOBタスクレコードが生成されます |
| INCARNATION | bigint(20) | NO | Flashback Database後の分身の回数を示します |
| BACKUP_SET_ID | bigint(20) | YES | バックアップセットID。sysテナントはデフォルトで0、通常テナントは1から連番で付与されます |
| INITIATOR_TENANT_ID | bigint(20) | NO | タスク発行者のテナントID。バックアップSQLコマンドを実行したテナントIDに対応します |
| INITIATOR_JOB_ID | bigint(20) | NO | タスク発行者が属するJOB_ID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | このJOBレベルバックアップタスクに関連する、バックアップを実行する必要があるテナントID |
| PLUS_ARCHIVELOG | varchar(4096) | NO | ログ補完機能の有無。<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする |
| BACKUP_TYPE | varchar(4096) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを表します </li> <li>`INC`：増分バックアップを表します</li></ul> |
| JOB_LEVEL | varchar(4096) | NO | JOBレベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始する場合</li><li>SYS_TENANT：sysテナントが特定のテナントのバックアップタスクを開始する場合</li><li>USER_TENANT：通常テナントが自身のバックアップを開始する場合 |
| ENCRYPTION_MODE | varchar(4096) | YES | 暗号化モード：<ul><li>None：暗号化しないことを表します</li><li>Password：パスワードによるみだけの保護を表します</li><li>Password Encryption ：暗号化し、パスワードによる保護も行います</li><li>Transparent Encryption：TDE暗号化を使用します</li><li>Dual mode Encryption ：TDE暗号化とパスワードによる保護の両方を使用します</li></ul> </br>現在、NoneとPasswordの2つのモードのみサポートしています |
| PASSWD | varchar(4096) | YES | パスワード |
| START_TIMESTAMP | timestamp(6) | NO | JOBレベルバックアップタスクの開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | JOBレベルバックアップタスクの終了時間 |
| STATUS | varchar(4096) | NO | バックアップの状態 |
| RESULT | bigint(20) | NO | バックアップエラーコードの結果 |
| COMMENT | varchar(4096) | YES | エラーコードの説明 |
| DESCRIPTION | varchar(4096) | YES | ユーザーが指定したバックアップの説明情報 |
| PATH | varchar(4096) | YES | バックアップパス |

## クエリ例

システムテナントで、テナントIDが1002のテナントのバックアップJobタスクを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_JOBS WHERE TENANT_ID = 1002\G
```
