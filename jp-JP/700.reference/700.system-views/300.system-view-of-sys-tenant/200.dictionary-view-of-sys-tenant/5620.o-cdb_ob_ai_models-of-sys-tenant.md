# oceanbase.CDB_OB_AI_MODELS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのAIモデル情報を表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | YES | テナントID。 |
| MODEL_ID | int(20) | NO | モデルの一意な識別子。 |
| NAME | varchar(128) | NO | ユーザー定義のモデル名。AI関数や`DBMS_AI_SERVICE`システムパッケージを呼び出す際に使用します。 |
| TYPE | varchar(128) | NO | モデルタイプ。以下のいずれかの値である必要があります。<ul><li><code>dense_embedding</code>：密集ベクトルモデル</li><li><code>sparse_embedding</code>：疎ベクトルモデル</li><li><code>completion</code>：テキスト補完モデル</li><li><code>rerank</code>：再ランキングモデル</li></ul><main id="notice" type='notice'><h4>注意</h4><p>疎ベクトルモデルは現在利用できません。</p></main> |
| MODEL_NAME | varchar(128) | NO | モデル名（例：`text-embedding-v2`）。 |

## クエリ例

すべてのテナントのAIモデル情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_AI_MODELS;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------+---------------+-----------------+-------------------+
| TENANT_ID | MODEL_ID | NAME          | TYPE            | MODEL_NAME        |
+-----------+----------+---------------+-----------------+-------------------+
|      1004 |   500005 | my_ai_model_1 | DENSE_EMBEDDING | text-embedding-v1 |
+-----------+----------+---------------+-----------------+-------------------+
1 row in set
```
