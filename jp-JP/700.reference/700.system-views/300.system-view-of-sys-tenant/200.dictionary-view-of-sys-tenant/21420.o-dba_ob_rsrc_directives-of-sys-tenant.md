# oceanbase.DBA_OB_RSRC_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

リソースマネージャーにおける本テナントの各種リソース設定パラメータ情報を表示します。

## フィールド説明

|           フィールド名            |      型       | NULL許容   |         説明         |
|------------------------------|-----------------|----------------|-----------------------|
| PLAN                         | varchar(128)    | NO             | リソース計画の内容が属するリソース計画名    |
| GROUP_OR_SUBPLAN             | varchar(128)    | NO             | リソース計画の内容が制御するリソースグループ名     |
| COMMENTS                     | varchar(2000)   | YES            | リソース計画の内容に対応するコメント    |
| MGMT_P1                      | bigint(20)      | NO             | システムがフル負荷の場合の、相対的に利用可能な最大CPU利用率。デフォルト値は `100`     |
| UTILIZATION_LIMIT            | bigint(20)      | NO             | リソースグループが使用するCPUリソースがテナントのCPU総リソースに占める割合の上限。デフォルト値は `100` で、テナントの全CPUリソースを最大限に使用できることを意味します   |
| MIN_IOPS                     | bigint(20)      | NO             | I/O競合が発生した場合に、リソースグループが予約するIOPSリソース。すべてのリソースグループで指定された `MIN_IOPS` の合計は100を超えてはならず、デフォルト値は `0`     |
| MAX_IOPS                     | bigint(20)      | NO             | リソースグループが使用できる最大IOPSリソース。すべてのリソースグループで指定された `MAX_IOPS` の合計は100を超えても構いませんが、デフォルト値は `100`     |
| WEIGHT_IOPS                  | bigint(20)      | NO             | I/Oリソース競合が発生した場合のIOPSの重み値。すべてのリソースグループで指定された `WEIGHT_IOPS` の合計は100を超えても構いませんが、`MIN_IOPS`、`MAX_IOPS` の設定を満たす前提で、I/Oリソースは重みの正規化値に従って割り当てられます。デフォルト値は `0`     |
| MAX_NET_BANDWIDTH            | bigint(20)      | NO             | リソースグループが使用するネットワーク帯域幅の上限。すべてのリソースグループで指定された `MAX_NET_BANDWIDTH` の合計は100を超えても構いませんが、デフォルト値は `100`     |
| NET_bandWIDTH_WEIGHT         | bigint(20)      | NO             | ネットワークリソース競合が発生した場合の帯域幅の重み。すべてのリソースグループで指定された `NET_BANDWIDTH_WEIGHT` の合計は100を超えても構いませんが、`MAX_NET_BANDWIDTH` の設定を満たす前提で、ネットワーク帯域幅リソースは重みの正規化値に従って割り当てられます。デフォルト値は `0`      |
