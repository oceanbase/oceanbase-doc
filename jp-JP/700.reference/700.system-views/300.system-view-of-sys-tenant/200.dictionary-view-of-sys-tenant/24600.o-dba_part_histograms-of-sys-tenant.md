# oceanbase.DBA_PART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのパーティションテーブルのパーティションに対するヒストグラムデータ（各ヒストグラムの端点）を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | テーブル所有者 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| PARTITION_NAME | varchar(128) | NO | パーティションテーブル名 |
| COLUMN_NAME | varchar(128) | NO | 列名 |
| ENDPOINT_NUMBER | decimal(10,0) | NO | ヒストグラムのバケット番号 |
| ENDPOINT_VALUE | decimal(10,0) | NO | バケットの標準化エンドポイント値 |
| ENDPOINT_ACTUAL_VALUE | text | NO | バケットエンドポイントの実際の文字列値（非標準化） |
| ENDPOINT_ACTUAL_VALUE_RAW | text | NO | エンドポイントの実際の値（生データ） |
| ENDPOINT_REPEAT_COUNT | decimal(10,0) | NO | エンドポイント頻度（ハイブリッドヒストグラムのみ。その他のヒストグラムタイプは0に設定） |

## クエリ例

システムテナントが自身のテナントにあるパーティションテーブル `test_part_hist` のパーティションのヒストグラム情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_PART_HISTOGRAMS WHERE TABLE_NAME ='test_part_hist';
```
