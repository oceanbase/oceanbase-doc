# oceanbase.CDB_WR_STATNAME

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのシステム統計項目名を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | クラスタID |
| TENANT_ID | bigint(20) | NO | テナントID |
| STAT_ID | bigint(20) | NO | 統計項目ID |
| STAT_NAME | varchar(64) | NO | 統計項目名 |

## クエリ例

すべてのテナントのシステム統計項目名を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_WR_STATNAME limit 1;
```

結果は次のとおりです：

```shell
+------------+-----------+---------+---------------+
| CLUSTER_ID | TENANT_ID | STAT_ID | STAT_NAME     |
+------------+-----------+---------+---------------+
|       4000 |         1 |   10000 | rpc packet in |
+------------+-----------+---------+---------------+
1 row in set (0.001 sec)
```
