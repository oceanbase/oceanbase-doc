# oceanbase.DBA_OB_CLONE_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_CLONE_PROGRESS`は、実行中のクローンタスク情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLONE_JOB_ID | bigint(20) | NO | 主キー、クローンタスクID |
| TRACE_ID | varchar(64) | NO | クローンタスクのTrace ID |
| SOURCE_TENANT_ID | bigint(20) | NO | ソーステナントID |
| SOURCE_TENANT_NAME | varchar(128) | NO | ソーステナント名 |
| CLONE_TENANT_ID | bigint(20) | NO | クローンテナントID |
| CLONE_TENANT_NAME | varchar(128) | NO | クローンテナント名 |
| TENANT_SNAPSHOT_ID | bigint(20) | NO | スナップショットID |
| TENANT_SNAPSHOT_NAME | varchar(128) | NO | スナップショット名 |
| RESOURCE_POOL_ID | bigint(20) | NO | クローンテナントのリソースプールID |
| RESOURCE_POOL_NAME | varchar(128) | NO | クローンテナントのリソースプール名 |
| UNIT_CONFIG_NAME | varchar(128) | NO | クローンテナントUnit設定名 |
| RESTORE_SCN | bigint(20) unsigned | NO | クローンテナントのターゲット再生ポイント |
| STATUS | varchar(64) | NO | クローンタスクの現在の状態 |
| CLONE_JOB_TYPE | varchar(16) | NO | クローンタスクのタイプ：FORK（テナントの現在の状態に基づいてテナントをクローン）|
| CLONE_START_TIME | timestamp(6) | NO | クローンタスク開始時間 |
| CLONE_FINISHED_TIME | timestamp(6) | YES | クローンタスク終了時間 |
| RET_CODE | bigint(20) | YES | クローンタスクエラーコード。NULLを許容 |
| ERROR_MESSAGE | varchar(512) | YES | クローンタスク失敗時のメッセージ。NULLを許容 |
