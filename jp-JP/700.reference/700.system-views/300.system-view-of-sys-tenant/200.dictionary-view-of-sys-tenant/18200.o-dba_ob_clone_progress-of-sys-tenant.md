# oceanbase.DBA_OB_CLONE_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_CLONE_PROGRESS` は、実行中のクローンタスク情報を表示するために使用されます。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLONE_JOB_ID | bigint(20) | NO | クローンタスクID。主キーです。 |
| TRACE_ID | varchar(64) | NO | クローンタスクのTrace IDです。 |
| SOURCE_TENANT_ID | bigint(20) | NO | ソーステナントIDです。 |
| SOURCE_TENANT_NAME | varchar(128) | NO | ソーステナント名です。 |
| CLONE_TENANT_ID | bigint(20) | NO | クローンテナントIDです。 |
| CLONE_TENANT_NAME | varchar(128) | NO | クローンテナント名です。 |
| TENANT_SNAPSHOT_ID | bigint(20) | NO | スナップショットIDです。 |
| TENANT_SNAPSHOT_NAME | varchar(128) | NO | スナップショット名です。 |
| RESOURCE_POOL_ID | bigint(20) | NO | クローンテナントのリソースプールIDです。 |
| RESOURCE_POOL_NAME | varchar(128) | NO | クローンテナントのリソースプール名です。 |
| UNIT_CONFIG_NAME | varchar(128) | NO | クローンテナントのUnit構成名です。 |
| RESTORE_SCN | bigint(20) unsigned | NO | クローンテナントのターゲット再生ポイントです。 |
| STATUS | varchar(64) | NO | クローンタスクの現在の状態です。 |
| CLONE_JOB_TYPE | varchar(16) | NO | クローンタスクのタイプ：FORK（テナントの現在の状態に基づいてテナントをクローンします）。|
| CLONE_START_TIME | timestamp(6) | NO | クローンタスク開始時間です。 |
| CLONE_FINISHED_TIME | timestamp(6) | YES | クローンタスク終了時間です。 |
| RET_CODE | bigint(20) | YES | クローンタスクエラーコード。NULLを許容します。 |
| ERROR_MESSAGE | varchar(512) | YES | クローンタスク失敗時のメッセージ。NULLを許容します。 |
