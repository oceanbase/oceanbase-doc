# oceanbase.DBA_OB_BALANCE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントが現在実行中のロードバランシングジョブを表示します。各テナントは同一時刻に1つのロードバランシングジョブしか実行できません。各ロードバランシングジョブは、ロードバランシングの具体的な操作を実現するために複数のロードバランシングタスクを生成します。
