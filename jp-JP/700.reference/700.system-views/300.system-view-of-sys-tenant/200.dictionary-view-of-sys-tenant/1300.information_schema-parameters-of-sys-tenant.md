## 機能の概要

現在のテナント配下におけるストアドプロシージャのパラメータと戻り値に関する情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SPECIFIC_CATALOG | varchar(512) | NO | 定数 (def) |
| SPECIFIC_SCHEMA | varchar(128) | NO | データベース名 |
| SPECIFIC_NAME | varchar(64) | NO | ストアドプロシージャ名 |
| ORDINAL_POSITION | bigint(20) | NO | パラメータの位置（関数の戻り値はこの値が0） |
| PARAMETER_MODE | varchar(5) | NO | パラメータタイプ：<ul><li>   IN</li><li>   OUT</li><li>   INOUT</li><li>    NULL</li></ul> |
| PARAMETER_NAME | varchar(64) | YES | パラメータ名 |
| DATA_TYPE | varchar(64) | NO | パラメータのデータ型 |
| CHARACTER_MAXIMUM_LENGTH | bigint(20) | NO | String型のパラメータについて、文字の最大長を記録 |
| CHARACTER_OCTET_LENGTH | bigint(20) | NO | String型のパラメータについて、バイトの最大長を記録 |
| NUMERIC_PRECISION | bigint(20) unsigned | NO | 数値型のパラメータについて、Precisionを記録 |
| NUMERIC_SCALE | bigint(20) | NO | 数値型のパラメータについて、Scaleを記録 |
| DATETIME_PRECISION | bigint(20) unsigned | NO | 日付型について、日付型の精度を記録 |
| CHARACTER_SET_NAME | varchar(64) | NO | String型のパラメータについて、文字セットを記録 |
| COLLATION_NAME | varchar(64) | NO | String型のパラメータについて、照合順序を記録 |
| DTD_IDENTIFIER | longtext | NO | データ型の詳細情報を文字形式で記録 |
| ROUTINE_TYPE | varchar(9) | NO | ストアドプロシージャのタイプ（プロシージャ/関数） |
