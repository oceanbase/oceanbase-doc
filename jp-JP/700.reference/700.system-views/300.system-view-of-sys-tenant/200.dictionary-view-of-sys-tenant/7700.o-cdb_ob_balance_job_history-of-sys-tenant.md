# oceanbase.CDB_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントで実行されたロードバランシングの作業履歴を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID <ul><li>1：システムテナントID  </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>|
| JOB_ID | bigint(20) | NO | ロードバランシングジョブID |
| CREATE_TIME | timestamp(6) | NO | ジョブ作成時間 |
| FINISH_TIME | timestamp(6) | NO | ジョブ完了時間。成功およびキャンセル時間を含む |
| BALANCE_STRATEGY | varchar(64) | NO | バランシング戦略名  <ul><li>`LS balance by migrate`：移行によるバランシング  </li><li>`LS balance by alter`：ログストリーム属性変更によるバランシング </li><li>`LS balance by expand`：拡張によるバランシング </li><li>`LS balance by shrink`：縮小によるバランシング </li><li>`partition balance`：パーティションによるバランシング </li></ul>|
| JOB_TYPE | varchar(64) | NO | タスクタイプ  <ul><li>`LS_BALANCE`：ログストリームのバランシング  </li><li>`PARTITION_BALACNE`：パーティションのバランシング </li></ul>|
| TARGET_UNIT_NUM | bigint(20) | NO | 変更先の各ゾーンのUnit数  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2以降、常に<code>NULL</code>となります。</li> <li>V4.2.5系では、このフィールドの値はV4.2.5 BP5以降、常に<code>NULL</code>となります。</li></ul></main>  |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | 変更先のPrimaryゾーン数 |
| STATUS | varchar(64) | NO | タスクの状態 <ul><li>`DOING`：Jobが実行中  </li><li>`COMPLETED`：タスクが正常に終了 </li><li>`CANCELING`：タスクがキャンセル中 </li><li>`CANCELED`：タスクがキャンセルされました </li></ul>|
| COMMENT | longtext | YES | コメント情報 |
| MAX_END_TIME | timestamp(6) | YES | ロードバランシングタスクの最大終了時間 <main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、このビューはV4.3.4から導入されました。V4.2.x系では、このフィールドはV4.2.4から導入されました。</p></main>  |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | テナントの各ゾーンのUnit数 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
| PARAMETER_LIST          | longtext      | NO   | バランシング関連の構成パラメータ  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
