# oceanbase.ALL_OB_EXTERNAL_TABLE_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のユーザーがアクセス権を持つ外部テーブルのファイルリストを表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TABLE_NAME | varchar(256) | NO | 外部テーブル名 |
| TABLE_SCHEMA | varchar(128) | NO | 外部テーブルが存在するデータベース名 |
| PARTITION_NAME | varchar(2) | NO | 外部テーブルのPARTITION NAME |
| FILE_URL | varbinary(16384) | NO | 外部テーブルのファイルURL |
| FILE_SIZE | bigint(20) | NO | ファイルのサイズ、単位はバイト |

## クエリ例

現在のユーザーがアクセス権を持つ外部テーブルのファイルリストを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.ALL_OB_EXTERNAL_TABLE_FILES;
```

クエリ結果は次のとおりです：

```shell
+-------------------------------+------------------+----------------+-------------------------------+-----------+
| TABLE_NAME                    | TABLE_SCHEMA     | PARTITION_NAME | FILE_URL                      | FILE_SIZE |
+-------------------------------+------------------+----------------+-------------------------------+-----------+
| __all_external_alert_log_info | sys_external_tbs | P0             | 172.xx.xxx.xxx:2882%alert.log |      6473 |
+-------------------------------+------------------+----------------+-------------------------------+-----------+
1 row in set
```
