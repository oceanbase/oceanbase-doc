# oceanbase.DBA_SQL_PLAN_BASELINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMにおけるSQLの計画ベースラインを表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SIGNATURE | bigint(20) unsigned | NO | 正規化されたSQLによって生成されたSQLの一意の識別子 |
| SQL_HANDLE | varchar(32) | NO | 統一されたSQLテキスト |
| SQL_TEXT | longtext | NO | 正規化されていないSQLテキスト |
| PLAN_NAME | varchar(128) | NO | プラン識別子の一意のテキスト形式 |
| CREATOR | varchar(128) | NO | この計画ベースラインを作成したユーザー |
| ORIGIN | varchar(29) | NO | 計画ベースラインの作成方法：<ul><li>MANUAL-LOAD</li><li>AUTO-CAPTURE</li><li>MANUAL-SQLTUNE</li><li>AUTO-SQLTUNE</li></ul> |
| PARSING_SCHEMA_NAME | varchar(128) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| DESCRIPTION | varchar(500) | YES | 計画ベースラインの説明 |
| VERSION | varchar(256) | NO | 計画ベースライン作成時のデータベースバージョン |
| CREATED | timestamp(6) | YES | 計画ベースラインの作成日時 |
| LAST_MODIFIED | timestamp(6) | YES | 計画ベースラインの最終変更日時 |
| LAST_EXECUTED | bigint(20) | NO | 計画ベースラインの最終実行日時 |
| LAST_VERIFIED | bigint(20) | NO | 計画ベースラインの最終検証日時 |
| ENABLED | varchar(3) | NO | 計画ベースラインが有効かどうかを示します：<ul><li>YES</li><li>NO</li></ul>  |
| ACCEPTED | varchar(3) | NO | 計画ベースラインが採用されたかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| FIXED | varchar(3) | NO | 計画ベースラインが固定されているかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| REPRODUCED | varchar(3) | NO | 計画ベースラインが再現可能かどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| AUTOPURGE | varchar(3) | NO | 計画ベースラインが自動クリーンアップされるかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| ADAPTIVE | varchar(3) | NO | SPMによって自動キャプチャされた計画ベースラインが適応済みかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| OPTIMIZER_COST | bigint(20) | NO | 計画ベースライン作成時のオプティマイザー推定計画コスト |
| MODULE | varchar(64) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| ACTION | varchar(64) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| EXECUTIONS | bigint(20) | NO | 計画ベースライン作成時の計画実行回数 |
| ELAPSED_TIME | bigint(20) | NO | 計画ベースライン作成時の計画総実行時間 |
| CPU_TIME | bigint(20) | NO | 計画ベースライン作成時の計画総CPU時間 |
| BUFFER_GETS | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです |
| DISK_READS | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです。 |
| DIRECT_WRITES | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです。 |
| ROWS_PROCESSED | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです。 |
| FETCHES | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです。 |
| END_OF FETCH_COUNT | bigint(0) | NO | 現在このフィールドはサポートされておらず、デフォルトでNULLです。 |
