# oceanbase.DBA_SQL_PLAN_BASELINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPMにおけるSQLの計画ベースラインを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| SIGNATURE | bigint(20) unsigned | NO | 正規化されたSQLによって生成されるSQLの一意の識別子 |
| SQL_HANDLE | varchar(32) | NO | 統一されたSQLテキスト |
| SQL_TEXT | longtext | NO | 正規化されていないSQLテキスト |
| PLAN_NAME | varchar(128) | NO | プランの一意のテキスト形式の識別子 |
| CREATOR | varchar(128) | NO | このプランベースラインを作成したユーザー |
| ORIGIN | varchar(29) | NO | プランベースラインの作成方法：<ul><li>MANUAL-LOAD</li><li>AUTO-CAPTURE</li><li>MANUAL-SQLTUNE</li><li>AUTO-SQLTUNE</li></ul> |
| PARSING_SCHEMA_NAME | varchar(128) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| DESCRIPTION | varchar(500) | YES | プランベースラインの説明 |
| VERSION | varchar(256) | NO | プランベースライン作成時のデータベースバージョン |
| CREATED | timestamp(6) | YES | プランベースラインの作成日時 |
| LAST_MODIFIED | timestamp(6) | YES | プランベースラインの最終変更日時 |
| LAST_EXECUTED | bigint(20) | NO | プランベースラインの最終実行日時 |
| LAST_VERIFIED | bigint(20) | NO | プランベースラインの最終検証日時 |
| ENABLED | varchar(3) | NO | プランベースラインが有効かどうかを示します：<ul><li>YES</li><li>NO</li></ul>  |
| ACCEPTED | varchar(3) | NO | プランベースラインが採用されたかどうかを示します：<ul><li>YES</li><li>NO</li></ul>  |
| FIXED | varchar(3) | NO | プランベースラインが固定されているかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| REPRODUCED | varchar(3) | NO | プランベースラインが再現可能かどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| AUTOPURGE | varchar(3) | NO | プランベースラインが自動クリーンアップされるかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| ADAPTIVE | varchar(3) | NO | SPMによって自動的にキャプチャされたプランベースラインが適応済みかどうかを示します:<ul><li>YES</li><li>NO</li></ul>  |
| OPTIMIZER_COST | bigint(20) | NO | プランベースライン作成時のオプティマイザーによる計画コストの推定値 |
| MODULE | varchar(64) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| ACTION | varchar(64) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| EXECUTIONS | bigint(20) | NO | プランベースライン作成時の計画の実行回数 |
| ELAPSED_TIME | bigint(20) | NO | プランベースライン作成時の計画の総実行時間 |
| CPU_TIME | bigint(20) | NO | プランベースライン作成時の計画の総CPU時間 |
| BUFFER_GETS | bigint(0) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| DISK_READS | bigint(0) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| DIRECT_WRITES | bigint(0) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| ROWS_PROCESSED | bigint(0) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| FETCHES | bigint(0) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
| END_OF_FETCH_COUNT | bigint(0) | NO | 現在、このフィールドはサポートされておらず、デフォルトでNULLです |
