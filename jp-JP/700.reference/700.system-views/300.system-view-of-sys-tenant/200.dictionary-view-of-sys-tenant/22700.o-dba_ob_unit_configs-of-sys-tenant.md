# oceanbase.DBA_OB_UNIT_CONFIGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのユニット仕様情報を表示します。

## フィールドの説明

|      フィールド名       |      タイプ      | NULL値を許容するか |        説明        |
|-----------------|--------------|------------|------------------|
| UNIT_CONFIG_ID  | bigint(20)   | NO         | ユニット仕様ID       |
| NAME            | varchar(128) | NO         | ユニット仕様名        |
| CREATE_TIME         | timestamp(6)       | YES         | ユニット仕様の作成時間         |
| MODIFY_TIME         | timestamp(6)       | YES         | 情報更新時間         |
| MAX_CPU         | double       | NO         | CPU仕様の上限         |
| MIN_CPU         | double       | NO         | CPU仕様の下限         |
| MEMORY_SIZE      | bigint(20)   | NO         | メモリ仕様、単位はバイト     |
| LOG_DISK_SIZE      | bigint(20)   | NO         | ログディスク仕様、単位はバイト     |
| MAX_IOPS        | bigint(20)   | NO         | ディスクIOPS仕様の上限     |
| MIN_IOPS        | bigint(20)   | NO         | ディスクIOPS仕様の下限     |
| IOPS_WEIGHT   | bigint(20)   | NO         | IOPS重み   |

## クエリ例
