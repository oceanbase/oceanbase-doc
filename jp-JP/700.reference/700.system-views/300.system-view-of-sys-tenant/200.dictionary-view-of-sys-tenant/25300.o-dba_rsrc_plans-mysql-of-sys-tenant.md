# oceanbase.DBA_RSRC_PLANS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

システムで定義されているすべてのリソース管理計画を表示します。

## フィールド説明

|           フィールド名            |       型       | NULL許容 |                         説明                         |
|---------------------------|----------------|------------|----------------------------------------------------|
| PLAN_ID                   | decimal(10,0)         | NO         | リソースプランのID                                          |
| PLAN                      | varchar(128)  | NO         | リソースプラン名                                             |
| NUM_PLAN_DIRECTIVES       | decimal(10,0)         | NO         | 現在のリソースプランで定義されている指示数。互換性のためにのみ使用され、現在の値は常に `NULL` です |
| CPU_METHOD                | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| MGMT_METHOD               | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| ACTIVE_SESS_POOL_MTH      | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| PARALLEL_DEGREE_LIMIT_MTH | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| QUEUING_MTH               | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| SUB_PLAN                  | varchar(3)    | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| COMMENTS                  | varchar(2000) | YES        | リソースプランの備考情報                                         |
| STATUS                    | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |
| MANDATORY                 | varchar(3)    | NO         | 互換性のためにのみ使用され、現在の値は常に `NULL` です                               |

## クエリ例

システムテナントは、システムが定義したすべてのリソース管理計画を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_PLANS;
```

```shell

+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
|    NULL | daytime |                NULL | NULL       | NULL        | NULL                 | NULL                      | NULL        | NULL     | TPFirst  | NULL   | NULL      |
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
1 row in set
```
