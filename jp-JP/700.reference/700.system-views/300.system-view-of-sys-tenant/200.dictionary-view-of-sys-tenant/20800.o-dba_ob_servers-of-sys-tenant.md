# oceanbase.DBA_OB_SERVERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノードの情報を表示します。

## フィールドの説明

|         フィールド名          |      タイプ      | NULLを許容するか |                        説明                        |
|-----------------------|--------------|------------|----------------------------------------------------------------------------|
| SVR_IP                | varchar(46)  | NO         | サーバーのIPアドレス                                        |
| SVR_PORT              | bigint(20)   | NO         | サーバーのポート番号                                           |
| ID                    | bigint(20)   | NO         | クラスタが割り当てた一意のID                                     |
| ZONE                  | varchar(128) | NO         | OBServerノードが属するゾーン                                |
| SQL_PORT              | bigint(20)   | NO         | OBServerノードがSQLリクエストにサービスを提供するためのポート                          |
| WITH_ROOTSERVER       | varchar(3)   | NO         | <ul><li>`YES`：Root Serviceサービスが存在します   </li><li> `NO`：Root Serviceサービスが存在しません  </li></ul>  |
| STATUS                | varchar(64)  | NO         | <ul><li>`ACTIVE`：OBServerノードとRSとの間で正常なハートビートが確立されています   </li><li> `INACTIVE`：OBServerノードとRSとの間でハートビートが途絶えました   </li><li> `DELETING`：OBServerノードが削除中です </li></ul> |
| START_SERVICE_TIME    | timestamp(6) | NO         | ノードプロセス起動後、外部にサービスを提供できるようになった時点：<ul><li>`NULL`：ノードプロセスが起動していないか、ノードの状態が利用不可能です。   </li><li> 有効値：ノードプロセス起動後、外部にサービスを提供できるようになった時点</li></ul> |
| STOP_TIME             | timestamp(6) | NO         | ユーザーがノードサービスを停止した時点：<ul><li>`NULL`：ノードは停止されていません   </li><li> 有効値：OBServerノードが停止された時間</li></ul>   |
| BLOCK_MIGRATE_IN_TIME | timestamp(6) | NO         | OBServerノードがデータの移入を禁止した時間：<ul><li>`NULL`：現在、データの移入を禁止していません   </li><li> 有効値：データの移入を禁止した時間 </li></ul>  |
|CREATE_TIME            | timestamp(6) | YES        |テーブルの作成時間|
|MODIFY_TIME            | timestamp(6) | YES        |最終のタスク変更時間|
| BUILD_VERSION         | varchar(256) | NO         | OBServerノードのバイナリビルドバージョン番号      |
| LAST_OFFLINE_TIME     | timestamp(6) | NO         | OBServerノードが前回オフラインになった時間：`NULL`：OBServerノードは一度もオフラインになっていません   </li><li> 有効値：OBServerノードの前回のオフライン時間</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>       |
