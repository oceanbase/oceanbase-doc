# oceanbase.CDB_OB_BACKUP_VALIDATE_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</li>
<li>V4.6.xバージョンでは、このビューはV4.6.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `oceanbase.CDB_OB_BACKUP_VALIDATE_TASKS` は、すべてのテナントが開始したバックアップ検証タスクの関連情報を表示するために使用されます。各タスクは、バックアップセットまたはログアーカイブピースの検証タスクに対応しています。

## フィールドの説明

| フィールド名           | 型          | NULL許容 | 説明           |
| ----------------- | ------------- | -------------- | -------------- |
| TENANT_ID         | bigint(20)    | NO   | テナントID。検証タスクを実行したテナントのID     |
| TASK_ID           | bigint(20)    | NO   | タスクのtask_id     |
| INCARNATION       | bigint(20)    | NO   | 分身ID     |
| JOB_ID            | bigint(20)    | NO   | タスクのjob_id     |
| TASK_TYPE         | varchar(64)   | NO   | 検証タスクのタイプ：<ul><li>`BACKUPSET`：指定されたバックアップセットの検証</li> <li>`ARCHIVELOG_PIECE`：指定されたログアーカイブピースの検証</li></ul>       |
| ID                | bigint(20)    | YES  | 検証されたバックアップセットの `backup_set_id` またはアーカイブピースの `piece_id`       |
| PATH              | longtext      | YES  | 検証されたバックアップパスまたはログアーカイブパス      |
| PATH_TYPE         | varchar(64)   | YES  | 検証されたパスタイプ：<ul><li>`BACKUP_SET_DEST`：データバックアップパス</li> <li>`ARCHIVELOG_PIECE_DEST`：ログアーカイブパス</li></ul>      |
| DEST_ID           | bigint(20)    | YES  | 検証されたバックアップパスまたはアーカイブパスのID     |
| PLUS_ARCHIVELOG   | varchar(64)   | NO   | 補償ログを含むかどうか      |
| INITIATOR_TASK_ID | bigint(20)    | NO   | 補償ログ検証タスクの親 task_id。それ以外の場合は0     |
| VALIDATE_LEVEL    | varchar(64)   | NO   | 検証レベル：<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一貫性をチェックします。</li></ul>      |
| ROUND_ID          | bigint(20)    | NO   | ログアーカイブピースを検証する際の所属ラウンドID。それ以外の場合は0|
| START_TIMESTAMP   | timestamp(6)  | NO   | 検証タスクの開始時間     |
| END_TIMESTAMP     | timestamp(6)  | NO   | 検証タスクの終了時間     |
| STATUS            | varchar(64)   | NO   | タスクの状態：<ul><li>`INIT`：検証タスクが初期化中</li> <li>`DOING`：検証タスクが実行中</li> <li>`COMPLETED`：検証タスクが完了しました</li> <li>`FAILED`：検証タスクの実行に失敗しました</li> <li>`CANCELED`：検証タスクがキャンセルされました</li></ul>       |
| TOTAL_LS_COUNT    | bigint(20)    | YES  | タスクに含まれるログストリーム数     |
| FINISH_LS_COUNT   | bigint(20)    | YES  | 検証が完了したログストリーム数     |
| TOTAL_BYTES       | bigint(20)    | YES  | 検証が必要なデータ量の見積もり値。単位はバイト     |
| VALIDATED_BYTES   | bigint(20)    | YES  | 検証が完了したデータ量。単位はバイト     |
| RESULT            | bigint(20)    | NO   | 検証結果のエラーコード情報     |
| COMMENT           | varchar(4096) | YES  | 検証タスクが失敗した原因の説明      |
