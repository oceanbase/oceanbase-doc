# oceanbase.DBA_SUBPART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのサブパーティションテーブルのセカンダリパーティションに対するヒストグラムデータ（各ヒストグラムの端点）を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | テーブルの所有者 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| SUBPARTITION_NAME | varchar(128) | NO | サブパーティションテーブル名 |
| COLUMN_NAME | varchar(128) | NO | 列名 |
| ENDPOINT_NUMBER | decimal(10,0) | NO | ヒストグラムのバケット番号 |
| ENDPOINT_VALUE | decimal(10,0) | NO | バケットの標準化されたエンドポイント値 |
| ENDPOINT_ACTUAL_VALUE | text | NO | バケットエンドポイントの実際の文字列値（非標準化） |
| ENDPOINT_ACTUAL_VALUE_RAW | text | NO | プリミティブ形式のエンドポイント実際値 |
| ENDPOINT_REPEAT_COUNT | decimal(10,0) | NO | エンドポイント頻度（ハイブリッドヒストグラムにのみ適用。他のヒストグラムタイプでは0に設定されます） |

## クエリ例

システムテナントは、自身のパーティションテーブル `sales_subpart` のサブパーティションのヒストグラム情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPART_HISTOGRAMS WHERE TABLE_NAME ='sales_subpart';
```
