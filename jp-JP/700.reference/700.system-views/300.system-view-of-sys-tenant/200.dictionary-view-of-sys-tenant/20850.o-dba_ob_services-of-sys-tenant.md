# oceanbase.DBA_OB_SERVICES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_SERVICES`は、このテナント内のすべての`SERVICE_NAME`に関する情報を表示するために使用されます。

## フィールドの説明

|           フィールド名         |      タイプ     | NULLを許容するか |  説明  |
|---------------------------|---------------|----------------|--------|
| CREATE_TIME     | timestamp(6) | NO   | サービスの作成時間。     |
| MODIFIED_TIME   | timestamp(6) | NO   | サービス関連情報の更新時間。     |
| SERVICE_NAME_ID | bigint(20)   | NO   | サービス名IDで、サービス名を一意に識別します。     |
| SERVICE_NAME    | varchar(64)  | NO   | サービス名。     |
| SERVICE_STATUS  | varchar(64)  | NO   | サービスの状態。主な状態は以下のとおりです：<ul><li>STARTED：サービスが起動されました。</li><li>STOPPING：サービスが一時停止中です。</li><li>STOPPED：サービスが停止されました。</li></ul>|

## クエリ例

このテナント内のすべての`SERVICE_NAME`に関する情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SERVICES;
```

クエリ結果は次のとおりです：

```shell
+----------------------------+----------------------------+-----------------+------------------+----------------+
| CREATE_TIME                | MODIFIED_TIME              | SERVICE_NAME_ID | SERVICE_NAME     | SERVICE_STATUS |
+----------------------------+----------------------------+-----------------+------------------+----------------+
| 2024-06-18 14:18:36.405999 | 2024-06-18 14:18:36.405999 |               3 | service_mysql001 | STARTED        |
+----------------------------+----------------------------+-----------------+------------------+----------------+
1 row in set (0.012 sec)
```
