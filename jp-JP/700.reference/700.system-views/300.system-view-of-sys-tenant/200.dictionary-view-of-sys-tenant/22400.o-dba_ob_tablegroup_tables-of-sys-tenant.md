# oceanbase.DBA_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のテーブルグループとテーブルの関連性を表示します。テーブルグループに属していないテーブルは表示されません。

## フィールドの説明

|      フィールド名       |      型      | NULL許容 |      説明       |
|-----------------|--------------|------------|---------------|
| TABLEGROUP_NAME | varchar(128) | NO         | テーブルグループ名           |
| OWNER           | varchar(128) | NO         | テーブルが属するデータベース名 |
| TABLE_NAME      | varchar(256) | NO         | テーブル名       |
| SHARDING        | varchar(20)   | NO         | テーブルグループのSHARDINGプロパティ。<ul><li>`NONE`：テーブルグループ内のすべてのテーブルのすべてのパーティションが同一マシンに集約され、テーブルグループへの追加テーブルに制限はありません。</li> <li>`PARTITION`：テーブルグループ内の各テーブルのデータをパーティション単位で分散します。サブパーティションテーブルの場合、各パーティションのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：テーブルグループ内の各テーブルのデータを適応型方式で分散します。つまり、テーブルグループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散します。</li></ul>    |
| SCOPE           | varchar(20)   | NO         | テーブルグループの`SCOPE`プロパティ。取り得る値は以下の通りです：<ul><li>`SERVER`：すべてのパーティショングループのリーダーが同一ノード上に配置されていることを示します。 </li><li>`ZONE`：すべてのパーティショングループのリーダーが同一ゾーン内に配置され、ゾーン内の各ノードに分散されていることを示します。 </li><li>`CLUSTER`：すべてのパーティショングループのリーダーがクラスタ内の各ノードに分散されていることを示します。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>|
