# oceanbase.DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのアーカイブパス設定を表示します。システムテナントにはユーザーデータが含まれておらず、クラスタ管理用のテナントであるため、バックアップ・リストアはサポートされていません。そのため、`sys` テナントにはアーカイブパスが設定されていません。`sys` テナントでは、このビューのクエリ結果は常に空になります。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するための番号 |
| NAME | varchar(1024) | NO | フィールド名。以下のフィールドを含みます：<ul><li>`binding`：アーカイブと業務の優先モード</li> <li>`dest_id`：アーカイブ宛先のID</li> <li>`path`：アーカイブパス情報</li> <li>`piece_switch_interval`：Pieceの切り替え間隔</li> <li>`state`：アーカイブ宛先の状態</li></ul>  |
| VALUE | varchar(4096) | NO | `name` フィールドに対応するフィールド値 |
