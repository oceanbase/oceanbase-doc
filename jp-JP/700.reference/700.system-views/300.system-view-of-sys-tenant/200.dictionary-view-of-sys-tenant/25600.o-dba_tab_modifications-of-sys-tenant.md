# oceanbase.DBA_TAB_MODIFICATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のテーブルの累計変更情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TABLE_OWNER | varchar(128) | NO | 変更対象のテーブルが属するデータベース |
| TABLE_NAME | varchar(128) | NO | 変更対象のテーブル名 |
| PARTITION_NAME | varchar(128) | NO | 変更対象のパーティション名 |
| SUBPARTITION_NAME | varchar(128) | NO | 変更対象のサブパーティション名 |
| INSERTS | bigint(20) | NO | 約の挿入回数 |
| UPDATES | bigint(20) | NO | 約の更新回数 |
| DELETES | bigint(20) | NO | 約の削除回数 |
| TIMESTAMP | date | NO | テーブルの最後の変更時間を示す |
| TRUNCATED | varchar(3) | NO | 現在は実際の意味はなく、デフォルトはNULL |
| DROP_SEGMENTS | bigint(0) | NO | 現在は実際の意味はなく、デフォルトはNULL |
