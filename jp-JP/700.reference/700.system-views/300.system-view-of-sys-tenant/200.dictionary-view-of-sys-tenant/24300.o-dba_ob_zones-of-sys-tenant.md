# oceanbase.DBA_OB_ZONES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのゾーンの情報を表示します。

## フィールドの説明

|  フィールド名  |      型       | NULL許容 |        説明         |
|--------|---------------|------------|-----------------------------|
| ZONE   | varchar(128)  | NO         | ゾーン名           |
| CREATE_TIME | timestamp(6)  | NO    | ゾーンの作成日時     |
| MODIFY_TIME | timestamp(6)  | NO    | ゾーンの変更日時    |
| STATUS | varchar(4096) | NO         | ゾーンの状態：<ul><li>`ACTIVE`：現在アクティブ状態で、サービスを正常に提供しています</li><li>`INACTIVE`：ゾーンが停止状態です</li></ul>    |
| IDC    | varchar(4096) | NO         | ゾーンが属するIDC情報   |
| REGION | varchar(4096) | NO         | ゾーンが属するリージョン情報|
| TYPE   | varchar(4096) | NO         | ゾーンのタイプ：<ul><li>`ReadWrite`：読み書きゾーン </li><li>`Encryption`：暗号化ゾーン </li></ul>   |

## クエリ例

システムテナントがクラスタ内のすべてのゾーン情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONES;
```

クエリ結果は次のとおりです。

```shell
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC  | REGION  | TYPE      |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| zone1 | 2025-01-06 16:31:31.733840 | 2025-01-07 13:53:45.645465 | ACTIVE |      | region1 | ReadWrite |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
1 row in set
```
