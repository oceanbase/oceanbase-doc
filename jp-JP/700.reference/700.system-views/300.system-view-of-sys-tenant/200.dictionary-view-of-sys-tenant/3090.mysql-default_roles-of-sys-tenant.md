# mysql.default_roles

<main id="notice" type='explain'>
 <h4>説明</h4>
 <ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`mysql.default_roles`は、ユーザーがデフォルトで有効にしているロール情報を表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | -------- |
| HOST              | varchar(255) | NO   | アカウントのホスト名     |
| USER              | varchar(128) | NO   | アカウント名     |
| DEFAULT_ROLE_HOST | varchar(255) | NO   | デフォルトで有効なロールのホスト名     |
| DEFAULT_ROLE_USER | varchar(128) | NO   | デフォルトで有効なロールのアカウント名     |

## クエリ例

ユーザー`user001`がデフォルトで有効にしているロール情報を照会します。

1. 新しいロール`role1`を作成します。

   ```shell
   obclient [oceanbase]> CREATE ROLE IF NOT EXISTS role1;
   Query OK, 0 rows affected, 1 warning
   ```

2. `ALTER SYSTEM`権限をロール`role1`に付与します。

   ```shell
   obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
   ```

3. 新しいユーザー`user001`を作成します。

   ```shell
   obclient [oceanbase]> CREATE USER 'user001'@'%' IDENTIFIED BY '******';
   ```

4. 新しく作成したユーザー`user001`にロール`role1`を付与します。

   ```shell
   obclient [oceanbase]>GRANT role001 TO user001 WITH ADMIN OPTION;;
   ```

5. ユーザー`user001`がログイン時にデフォルトで有効にするロールを指定します。

   ```shell
   obclient > SET DEFAULT ROLE ALL TO user001;
   ```

6. ユーザー`user001`がデフォルトで有効にしているロール情報を照会します。

   ```shell
   obclient > SELECT * FROM mysql.default_roles;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +------+---------+-------------------+-------------------+
   | HOST | USER    | DEFAULT_ROLE_HOST | DEFAULT_ROLE_USER |
   +------+---------+-------------------+-------------------+
   | %    | user001 | %                 | role001           |
   +------+---------+-------------------+-------------------+
   1 row in set (0.001 sec)
   ```
