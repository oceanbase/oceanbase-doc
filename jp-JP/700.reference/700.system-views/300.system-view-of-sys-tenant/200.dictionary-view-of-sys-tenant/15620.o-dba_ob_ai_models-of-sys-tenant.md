# oceanbase.DBA_OB_AI_MODELS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのAIモデル情報を表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| MODEL_ID | int(20) | NO | ダイナミックAIモデルの一意の識別子です。 |
| NAME | varchar(128) | NO | ユーザー定義のダイナミックAIモデル名です。AI関数や`DBMS_AI_SERVICE`システムパッケージを呼び出す際に、この名前を使用します。 |
| TYPE | varchar(128) | NO | ダイナミックAIモデルのタイプです。以下のいずれかの値である必要があります：<ul><li><code>dense_embedding</code>：密ベクトルモデル</li><li><code>sparse_embedding</code>：疎ベクトルモデル</li><li><code>completion</code>：テキスト補完モデル</li><li><code>rerank</code>：再ランキングモデル</li></ul><main id="notice" type='notice'><h4>注意</h4><p>疎ベクトルモデルは現在利用できません。</p></main> |
| MODEL_NAME | varchar(128) | NO | ダイナミックAIモデル名（例：`text-embedding-v2`）。 |

## クエリ例

本テナントのAIモデル情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_MODELS;
```

クエリ結果は次のとおりです。

```shell
+----------+---------------+-----------------+-------------------+
| MODEL_ID | NAME          | TYPE            | MODEL_NAME        |
+----------+---------------+-----------------+-------------------+
|   500005 | my_ai_model_1 | DENSE_EMBEDDING | text-embedding-v1 |
+----------+---------------+-----------------+-------------------+
1 row in set
```
