# oceanbase.CDB_OB_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのログストリームの状態と復元進捗を表示します。

## フィールド説明

| フィールド名       | 型                | NULL許容        | 説明               |
|---------------|---------------------|-----------------------|--------------------|
| TENANT_ID     | bigint(20)          | NO | テナントID |
| LS_ID         | bigint(20)          | NO | ログストリームID |
| STATUS        | varchar(100)        | NO | ログストリームのステータス。<ul><li>`CREATING`：ログストリームの作成中</li><li>`CREATED`：ログストリームの作成完了</li><li>`NORMAL`：ログストリームがサービスを提供可能</li><li>`DROPPING`：ログストリームの削除予定。ログストリーム上のTabletを移行する必要があります</li><li>`TENANT DROPPING`：ログストリームが存在するテナントが削除中で、ログストリームも削除する必要があります</li><li>`WAIT OFFLINE`：ログストリームデータの削除が完了し、GCを待機中</li><li>`CREATE ABORT`：ログストリームの作成に失敗したか、作成不要と判断されたため、削除予定</li></ul> |
| PRIMARY_ZONE  | longtext            | YES| ログストリームの選出優先度 |
| UNIT_GROUP_ID | bigint(20)          | NO | UnitグループID <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2バージョンから常に0に設定されます。</li><li>V4.2.5系では、このフィールドはV4.2.5 BP5バージョンから常に0に設定されます。</li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO | ログストリームグループIDです。システムログストリーム（1番ログストリーム）およびブロードキャストログストリームでは、このフィールドは0と表示され、そのログストリームが特定のログストリームグループに属さないことを示します |
| CREATE_SCN    | bigint(20) unsigned | NO | ログストリームでのログ書き込み開始時点 |
| DROP_SCN      | bigint(20) unsigned | NO | ログストリーム削除時点、すなわちすべてのユーザーデータ終了時点です。ログストリームが削除された場合、このフィールドには削除時のSCNが記録されます。削除されていない場合、このフィールドはNULLです。 |
| SYNC_SCN      | bigint(20) unsigned | NO | ログストリームの同期時点で、ログストリームが最後に正常に同期されたトランザクションのSCNを示します |
| READABLE_SCN  | bigint(20) unsigned | NO | ログストリームの可読時点で、ログストリームが読み取り可能な最小SCNを示します |
| FLAG          | varchar(2048)       | NO | ログストリームのフラグ：<ul><li>空：通常のログストリーム</li><li> DUPLICATE：ユーザーテナントのブロードキャストログストリームで、レプリケーションテーブルがこのログストリーム上に作成されています </li> <li>BLOCK_TABLET_IN：このログストリーム上にTabletを作成できないことを示します</li> <li>DUPLICATE\|BLOCK_TABLET_IN：ブロードキャストログストリームでは現在Tabletの作成が許可されていません</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | ユーザーログストリームが配置されているUnitのリストです。システムログストリームおよびブロードキャストログストリームは、具体的な位置を指定しない場合、この列は空になります。 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2バージョンから導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5バージョンから導入されました。</li></ul></main>  |
