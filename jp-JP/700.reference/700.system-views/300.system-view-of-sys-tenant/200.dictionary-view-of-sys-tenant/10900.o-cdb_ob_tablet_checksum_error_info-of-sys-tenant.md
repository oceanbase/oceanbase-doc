# oceanbase.CDB_OB_TABLET_CHECKSUM_ERROR_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

Tabletコピー間で発生したデータの不整合情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| TABLET_ID | bigint(20) | NO | 校正和の不一致が発生したTABLETのID |

## クエリ例

システムテナントがTabletコピー間で発生したデータの不整合情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLET_CHECKSUM_ERROR_INFO;
```
