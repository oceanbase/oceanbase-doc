# oceanbase.DBA_OB_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のユーザーおよびロール情報を表示します。

## フィールド説明

| フィールド名                   | フィールドタイプ      | NULL許容 | 説明 |
|---------------------------|---------------|------|----|
| USER_NAME                 | varchar(128)  | NO   |  ユーザー名またはロール名   |
| HOST                      | varchar(128)  | NO   |  サーバー名   |
| PASSWD                    | varchar(128)  | NO   |  ユーザーまたはロールのパスワード   |
| INFO                      | varchar(4096) | NO   |  ユーザーまたはロールの情報   |
| PRIV_ALTER                | varchar(3)    | NO   |  データベースまたはテーブルを変更する権限があるかどうか   |
| PRIV_CREATE               | varchar(3)    | NO   |  データベースまたはテーブルを作成する権限があるかどうか   |
| PRIV_DELETE               | varchar(3)    | NO   |  データベースまたはテーブルレコードを削除する権限があるかどうか   |
| PRIV_DROP                 | varchar(3)    | NO   |  データベースまたはテーブルを削除する権限があるかどうか   |
| PRIV_GRANT_OPTION         | varchar(3)    | NO   |  権限を付与する権限があるかどうか   |
| PRIV_INSERT               | varchar(3)    | NO   |  レコードを挿入する権限があるかどうか   |
| PRIV_UPDATE               | varchar(3)    | NO   |  レコードを更新する権限があるかどうか   |
| PRIV_SELECT               | varchar(3)    | NO   |  レコードを照会する権限があるかどうか   |
| PRIV_INDEX                | varchar(3)    | NO   |  インデックスを設定する権限があるかどうか   |
| PRIV_CREATE_VIEW          | varchar(3)    | NO   |  ビューを作成する権限があるかどうか   |
| PRIV_SHOW_VIEW            | varchar(3)    | NO   |  ビューを参照する権限があるかどうか   |
| PRIV_SHOW_DB              | varchar(3)    | NO   |  すべてのデータベースを参照する権限があるかどうか   |
| PRIV_CREATE_USER          | varchar(3)    | NO   |  ユーザーを作成する権限があるかどうか   |
| PRIV_SUPER                | varchar(3)    | NO   |  スーパーユーザー権限があるかどうか   |
| IS_LOCKED                 | varchar(3)    | NO   |  ロックされているかどうか   |
| PRIV_PROCESS              | varchar(3)    | NO   |  すべてのスレッドを参照する権限があるかどうか   |
| PRIV_CREATE_SYNONYM       | varchar(3)    | NO   |  同義語を作成する権限があるかどうか   |
| SSL_TYPE                  | bigint(20)    | NO   |  SSL標準暗号化セキュリティタイプ   |
| SSL_cipher                | varchar(1024) | NO   |  SSL標準暗号化セキュリティパスワード   |
| X509_ISSUER               | varchar(1024) | NO   |  X.509 発行者名   |
| X509_SUBJECT              | varchar(1024) | NO   |  X.509 証書主体名   |
| TYPE                      | varchar(4)    | NO   |  種類：<ul><li>`USER`：ユーザー</li> <li>`ROLE`：ロール</li></ul>   |
| PROFILE_ID                | bigint(20)    | NO   |  Profile ID   |
| PASSWORD_LAST_CHANGED     | timestamp(6)  | YES  |  最後にパスワードを変更した時間   |
| PRIV_FILE                 | varchar(3)    | NO   |  ファイルを参照する権限があるかどうか   |
| PRIV_ALTER_TENANT         | varchar(3)    | NO   |  テナント情報を変更する権限があるかどうか   |
| PRIV_ALTER_SYSTEM         | varchar(3)    | NO   |  サーバー構成パラメータを変更する権限があるかどうか   |
| PRIV_CREATE_RESOURCE_POOL | varchar(3)    | NO   |  リソースプールの作成、変更、削除権限があるかどうか   |
| PRIV_CREATE_RESOURCE_UNIT | varchar(3)    | NO   |  リソースユニットの作成、変更、削除権限があるかどうか   |
| MAX_CONNECTIONS           | bigint(20)    | NO   |  最大接続数   |
| MAX_USER_CONNECTIONS      | bigint(20)    | NO   |  テナント最大接続数   |
| PRIV_REPL_SLAVE           | varchar(3)    | NO   |  スレーブサーバー管理。テナントはレプリケーションのスレーブサーバーとマスターサーバーの場所を指定できます。   |
| PRIV_REPL_CLIENT          | varchar(3)    | NO   |  マスターサーバー管理。テナントはレプリケーションデータベース環境のメンテナンスに使用されるバイナリログファイルを読み取ることができます。このユーザーはマスターシステム上に配置され、ホストとクライアント間の通信に有利です。   |
| PRIV_DROP_DATABASE_LINK   | varchar(3)    | NO   |  データベースリンクを削除する権限があるかどうか     |
| PRIV_CREATE_DATABASE_LINK | varchar(3)    | NO   |  データベースリンクを作成する権限があるかどうか     |
| PRIV_EXECUTE              | varchar(3)    | NO   |  ProcedureとFunctionを実行する権限があるかどうか    |
| PRIV_ALTER_ROUTINE        | varchar(3)    | NO   |  ProcedureとFunctionを変更・削除する権限があるかどうか      |
| PRIV_CREATE_ROUTINE       | varchar(3)    | NO   |  ProcedureとFunctionを作成する権限があるかどうか     |
| PRIV_CREATE_TABLESPACE    | varchar(3)    | NO   | テーブルスペースの作成、変更、削除権限があるかどうか     |
| PRIV_SHUTDOWN             | varchar(3)    | NO   | mysqladmin shutdownコマンドを実行する権限があるかどうか     |
| PRIV_RELOAD               | varchar(3)    | NO   | Flush操作を実行する権限があるかどうか     |
| PRIVREFERENCES           | varchar(3)    | NO   | 外部キーを作成する権限があるかどうか     |
| PRIV_CREATE_ROLE          | varchar(3)    | NO   | ロールを作成する権限があるかどうか     |
| PRIV_DROP_ROLE            | varchar(3)    | NO   | ロールを削除する権限があるかどうか     |
| PRIV_TRIGGER              | varchar(3)    | NO   | トリガーを有効化する操作権限があるかどうか     |
| PRIV_ENCRYPT              | varchar(3)    | NO   | ENHANCED_AES_ENCRYPT 関数を呼び出せるかどうか     |
| PRIV_DECRYPT              | varchar(3)    | NO   | ENHANCED_AES_DECRYPT 関数を呼び出せるかどうか     |
| PRIV_CREATE_SENSITIVE_RULE | varchar(3)   | NO   | 敏感なルールを作成する権限があるかどうか     |
| PRIV_PLAINACCESS          | varchar(3)    | NO   | すべての敏感なルールへの平文アクセス権限があるかどうか     |
| OLD_PASSWORD              | varchar(128)  | NO   | 古いパスワードのハッシュ値（暗号）。二要素認証が有効な場合やパスワードの自動切り替え期間中に有効です。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>            |
| OLD_PASSWORD_START_TIME   | bigint(20)    | NO   | 古いパスワードが有効だった時間点。値が `-1` の場合は利用可能な古いパスワードがないことを示します。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>                     |
| PLUGIN                    | varchar(64)   | NO   | パスワードHASH計算で使用されたplugin名を記録します。現在、以下の値のみ許可されています：<ul><li>空文字列 (`mysql_native_password` と同等)</li><li>`ob_native_password`：Oracleモードでは `mysql_native_password` と同等</li><li>`mysql_native_password`</li><li>`caching_sha2_password`</li></ul><main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.2 BP2バージョンから導入されました。</p></main>   |
