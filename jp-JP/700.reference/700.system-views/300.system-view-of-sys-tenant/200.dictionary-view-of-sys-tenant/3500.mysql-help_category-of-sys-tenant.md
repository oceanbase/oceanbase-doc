# mysql.help_category

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

他の3つのテーブル`mysql.help_relation`、`mysql.help_topic`、`mysql.help_keyword`と連携してhelpコマンドを生成します。

## フィールドの説明

|      **フィールド名**      |     **タイプ**     | **NULLを許容するか** | **説明** |
|--------------------|----------------|----------------|--------|
| help_category_id   | bigint(20)     | NO             | カテゴリID  |
| name               | varchar(64)    | NO             | カテゴリ名    |
| parent_category_id | bigint(20)     | YES            | 親カテゴリID |
| url                | varchar(65535) | NO             | URLアドレス |
