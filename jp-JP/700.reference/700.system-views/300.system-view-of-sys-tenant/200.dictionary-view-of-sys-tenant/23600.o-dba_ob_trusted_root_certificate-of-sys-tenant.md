# DBA_OB_TRUSTED_ROOT_CERTIFICATE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TRUSTED_ROOT_CERTIFICATE`は、OBserverクラスタが信頼するCAルート証書の一覧および証書の有効期限などの情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| ------------ | -------- | ------------------ | -------- |
| COMMON_NAME       | varchar(256) | NO   | 証書の一般名    |
| DESCRIPTION       | varchar(256) | NO   | 証書の出典や用途の説明    |
| CERT_EXPIRED_TIME | timestamp(6) | NO   | 証書の有効期限    |

## クエリ例

OBserverクラスタが信頼するCAルート証書の一覧および証書の有効期限などの情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TRUSTED_ROOT_CERTIFICATE;
```
