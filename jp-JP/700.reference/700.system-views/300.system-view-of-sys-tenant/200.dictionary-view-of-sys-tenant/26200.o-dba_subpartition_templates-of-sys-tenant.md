# oceanbase.DBA_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのパーティションテーブルに関する、テンプレート化されたサブパーティション情報を表示します。

## フィールドの説明

|         フィールド名          |       型        | NULL許容 |    説明     |
|-----------------------|-----------------|------------|-----------|
| USER_NAME             | varchar(128)    | NO         | パーティションテーブル所有者   |
| TABLE_NAME            | varchar(128)    | NO         | パーティションテーブル名      |
| SUBPARTITION_NAME     | varchar(132)    | NO         | サブパーティション名      |
| SUBPARTITION_POSITION | bigint(21)      | NO         | サブパーティション位置     |
| TABLESPACE_NAME       | varchar(30)     | NO         | パーティションが属するテーブルスペース名 |
| HIGH_BOUND            | mediumtext | NO         | パーティションテンプレート式   |
| COMPRESSION           | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内で新規作成される複合パーティションの各サブパーティションデータを圧縮形式で保存するかどうかを示します。<li>YES<li>NO <br>この値はサブパーティションテンプレート内で指定できます        |
| INDEXING              | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内で新規作成される複合パーティションの各サブパーティションデータを部分的インデックスとして扱うかどうかを示します。<li>ON<li>OFF<br>この値はサブパーティションテンプレート内で指定できます          |
| READ_ONLY             | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内で新規作成される複合パーティションの各サブパーティションデータを読み取り専用にするかどうかを示します。<li>YES<li>NO<br>この値はサブパーティションテンプレート内で指定できます          |

## クエリ例

システムテナントが本テナントのパーティションテーブルに関する、テンプレート化されたサブパーティション情報をクエリします。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPARTITION_TEMPLATES;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| USER_NAME | TABLE_NAME | SUBPARTITION_NAME | SUBPARTITION_POSITION | TABLESPACE_NAME | HIGH_BOUND | COMPRESSION | INDEXING | READ_ONLY |
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
| test      | t_m_rclc   | mp0               |                     1 | NULL            | 1,3        | NULL        | NULL     | NULL      |
| test      | t_m_rclc   | mp1               |                     2 | NULL            | 4,6        | NULL        | NULL     | NULL      |
| test      | t_m_rclc   | mp2               |                     3 | NULL            | 7          | NULL        | NULL     | NULL      |
+-----------+------------+-------------------+-----------------------+-----------------+------------+-------------+----------+-----------+
3 rows in set
```
