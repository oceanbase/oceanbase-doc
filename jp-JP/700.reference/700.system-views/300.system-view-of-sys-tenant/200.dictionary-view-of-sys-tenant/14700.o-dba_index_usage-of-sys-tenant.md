# oceanbase.DBA_INDEX_USAGE

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>V4.3.x系では、このビューはV4.3.0バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li></ul></p>
</main>

## 機能の概要

`DBA_INDEX_USAGE` ビューは、インデックスの使用状況データを表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OBJECT_ID | bigint(20) | NO | インデックステーブルID |
| NAME | varchar(128) | NO | インデックステーブル名 |
| OWNER | varchar(128) | NO | データベース名 |
| TOTAL_ACCESS_COUNT | bigint(20) | NO | 総アクセス回数 |
| TOTAL_EXEC_COUNT | bigint(20) | NO | 総実行回数 |
| TOTAL_ROWS_RETURNED | bigint(20) | NO | 現在このフィールドはサポートされていません |
| BUCKET_0_ACCESS_COUNT | bigint(20) | NO | 現在このフィールドはサポートされていません |
| BUCKET_1_ACCESS_COUNT | bigint(20) | NO | 現在このフィールドはサポートされていません |

| BUCKET_2_10_ROWS_RETURNED | bigint(20) | NO | 現在このフィールドはサポートされていません |
| BUCKET_11_100_ACCESS_COUNT | bigint(20) | NO | 現在このフィールドはサポートされていません |

## クエリ例

obclient [oceanbase]> SELECT * FROM oceanbase.DBA_INDEX_USAGE;
