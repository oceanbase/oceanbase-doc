# oceanbase.CDB_OB_COLUMN_CHECKSUM_ERROR_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

インデックステーブル（グローバルインデックスとローカルインデックスを含む）とメインテーブル間で発生した列チェックサムの不一致情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| FROZEN_SCN | bigint(20) unsigned | NO | 現在のコンパクションのSCN |
| INDEX_TYPE | varchar(12) | NO | インデックステーブルタイプ：<ul><li>0：ローカルインデックステーブル</li> <li>1：グローバルインデックステーブル</li></ul> |
| DATA_TABLE_ID | bigint(20) | NO | メインテーブルID |
| INDEX_TABLE_ID | bigint(20) | NO | グローバル/ローカルインデックステーブルID |
| DATA_TABLET_ID | bigint(20) | NO | メインテーブル上でチェックサムが不一致となったTABLET ID（ローカルインデックステーブルとメインテーブル間のチェックに限る） |
| INDEX_TABLET_ID | bigint(20) | NO | インデックステーブル上でチェックサムが不一致となったTABLET ID（ローカルインデックステーブルとメインテーブル間のチェックに限る） |
| COLUMN_ID | bigint(20) | NO | チェックサムエラーが発生した列のID |
| DATA_COLUMN_CHECKSUM | bigint(20) | NO | メインテーブルの該当列のcolumn checksum値 |
| INDEX_COLUMN_CHECKSUM | bigint(20) | NO | インデックステーブルの該当列のcolumn checksum値 |
