# oceanbase.DBA_OB_deadLOCK_EVENT_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_deadLOCK_EVENT_HISTORY`は、現在のテナントにおけるデッドロックイベントの履歴を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| ------- | ------ | ------ | ------ |
| EVENT_ID       | bigint(20) unsigned | NO   | デッドロックイベントの番号     |
| SVR_IP         | varchar(46)         | NO   | このデッドロックイベントに参加するノードのIPアドレス     |
| SVR_PORT       | bigint(20) unsigned | NO   | このデッドロックイベントに参加するノードのポート番号     |

| CYCLE_IDX      | bigint(20)          | NO   | このノードのループ内の番号     |
| CYCLE_SIZE     | bigint(20)          | NO   | このデッドロックイベントに参加するノードの数     |
| ROLE           | longtext            | NO   | このノードがこのデッドロックイベントで果たす役割：<li>witness<li>victim     |

## クエリ例

すべてのテナントのデッドロックイベントの履歴を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DEADLOCK_EVENT_HISTORY LIMIT 10;
```
