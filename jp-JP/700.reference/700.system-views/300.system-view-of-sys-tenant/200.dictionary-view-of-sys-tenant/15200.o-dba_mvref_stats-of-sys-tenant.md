# oceanbase.DBA_MVREF_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_MVREF_STATS` は、マテリアライズドビューのリフレッシュに関する基本的なタイミング統計情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| MV_OWNER | varchar(128) | NO | マテリアライズドビューの所有者 |
| MV_NAME | varchar(128) | NO | マテリアライズドビュー名 |
| REFRESH_ID | bigint(20) | NO | リフレッシュのID |
| REFRESH_METHOD | varchar(30) | NO | マテリアライズドビューのリフレッシュ方式。<ul><li>FAST：増分リフレッシュ  </li><li>COMPLETE：全量リフレッシュ </li></ul>|
| REFRESH_OPTIMIZATIONS | text | NO | リフレッシュの最適化。例：空リフレッシュやマテリアライズドビューのリフレッシュ中のアプリケーションの主キー/外部キー。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| ADDITIONAL_EXECUTIONS | text | NO | 追加の実行。例：インデックスの再構築やマテリアライズドビューのリフレッシュ中に関与するログ操作。<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値はNULLです。</p></main> |
| START_TIME | datetime | NO | リフレッシュ開始時間 |
| END_TIME | datetime | NO | リフレッシュ終了時間 |
| ELAPSED_TIME | bigint(20) | NO | リフレッシュ実行時間、単位は秒 |
| LOG_SETUP_TIME | bigint(1) | NO | マテリアライズドビューのログ設定時間、単位は秒<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみあり、デフォルト値は0です。</p></main> |
| LOG_PURGE_TIME | bigint(20) | NO | マテリアライズドビューのログクリーンアップ時間、単位は秒 |
| INITIAL_NUM_ROWS | bigint(20) | NO | マテリアライズドビューの初期行数（リフレッシュ開始時） |
| FINAL_NUM_ROWS | bigint(20) | NO | マテリアライズドビューの最終行数（リフレッシュ終了時） |
