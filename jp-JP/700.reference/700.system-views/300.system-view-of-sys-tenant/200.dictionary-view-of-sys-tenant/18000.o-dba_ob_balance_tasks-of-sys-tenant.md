# oceanbase.DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在、このテナントで実行中のロードバランシングタスクを表示します。各テナントでは同時に複数のロードバランシングタスクが実行されている可能性がありますが、これらのタスクはすべて同一のロードバランシングジョブに属します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | ロードバランシングタスクID |
| CREATE_TIME | timestamp(6) | YES | 作成日時 |
| MODIFY_TIME | timestamp(6) | YES | 情報更新日時 |
| TASK_TYPE | varchar(64) | NO | タスクタイプ <ul><li>`LS_SPLIT`：ログストリームの分割  </li><li>`LS_ALTER`：ログストリーム属性の変更 </li><li>`LS_MERGE`：ログストリームのメジャーコンパクション </li><li>`LS_TRANSFER`：ログストリームTransfer </li></ul>|
| SRC_LS | bigint(20) | NO | ソースログストリーム（データソースから生成されるログデータストリーム） |
| DEST_LS | bigint(20) | NO | デスティネーションログストリーム |
| PART_LIST | longtext | YES | パーティションリスト。ユーザーテーブルのパーティションとグローバルインデックスのパーティションを含みます |
| FINISHED_PART_LIST | longtext | YES | 現在均衡処理が完了したパーティションのリスト |
| PART_COUNT | bigint(20) | YES | パーティションリスト内のパーティション数 |
| FINISHED_PART_COUNT | bigint(20) | YES | 現在均衡処理が完了したパーティション数 |
| LS_GROUP_ID | bigint(20) | NO | ログストリームグループID |
| STATUS | varchar(64) | NO | タスク状態 <ul><li>`INIT`：タスク作成  </li><li>`CREATE_LS`：ログストリームの作成 </li><li>`ALTER_LS`：ログストリーム属性の変更 </li><li>`SET_LS_MERGING`：ログストリームのメジャーコンパクション </li><li>`DROP_LS`：ログストリームの削除 </li><li>`COMPLETED`：タスク実行成功 </li><li>`CANCELED`：タスクキャンセル </li></ul>|
| PARENT_LIST | varchar(1024) | YES | 親タスクリスト |
| CHILD_LIST | varchar(1024) | YES | 子タスクリスト |
| CURRENT_TRANSFER_TASK_ID | bigint(20) | NO | 現在のロードバランシングタスクがトリガーしたTransferタスクID |
| JOB_ID | bigint(20) | NO | 現在のタスクが属するJob ID |
| COMMENT | longtext | YES | コメント情報 |
| BALANCE_STRATEGY         | varchar(64)   | YES | Balance Taskに対応する均衡戦略：<ul><li>`LS balance by migrate`：移行均衡  </li><li>`LS balance by alter`：ログストリーム属性変更による均衡 </li><li>`LS balance by expand`：拡張均衡 </li><li>`LS balance by shrink`：縮小均衡 </li><li>`partition balance`：パーティション均衡 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.3.x系では、このフィールドはV4.3.2バージョンから導入されました。V4.2.x系では、このフィールドはV4.2.4バージョンから導入されました。</p></main>   |
