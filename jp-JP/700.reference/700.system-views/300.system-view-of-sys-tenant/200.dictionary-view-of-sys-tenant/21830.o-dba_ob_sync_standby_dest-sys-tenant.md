# oceanbase.DBA_OB_SYNC_STANDBY_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.4.2バージョンでは、このビューはV4.4.2 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_SYNC_STANDBY_DEST`は、テナントの強力同期ダウンストリーム情報を表示するために使用されます。

## フィールドの説明

| フィールド名   | 型          | NULL許容 | 説明                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | bigint(20)    | NO             | テナントID     |
| DEST_ID   | bigint(20)    | NO             | 強力同期スタンバイテナントのID。現在、1つのプライマリテナントがIDが0の強力同期スタンバイテナントを1つしか持てない制限があります     |
| VALUE     | longtext      | NO             | 強力同期のスタンバイテナントの情報。ip_list、ログイン名、パスワード、cluster_idなどが含まれます     |

## 関連ビューまたはドキュメント

システムテナントで全テナントの強力同期ダウンストリーム情報を照会するには、[CDB_OB_SYNC_STANDBY_DEST](10550.o-cdb-ob_sync_standby_dest-sys-tenant.md)を参照してください。
