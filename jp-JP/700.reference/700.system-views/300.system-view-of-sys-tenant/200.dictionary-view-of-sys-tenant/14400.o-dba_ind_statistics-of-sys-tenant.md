# oceanbase.DBA_IND_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのインデックスに対するオプティマイザー統計情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | インデックスの所有者 |
| INDEX_NAME | varchar(128) | NO | インデックス名 |
| TABLE_OWNER | varchar(128) | NO | インデックスオブジェクトの所有者 |
| TABLE_NAME | varchar(128) | NO | インデックスオブジェクトの名前 |
| PARTITION_NAME | varchar(128) | NO | パーティション名 |
| PARTITION_POSITION | decimal(10,0) | NO | インデックス内のパーティションの位置 |
| SUBPARTITION_NAME | varchar(128) | NO | サブパーティション名 |
| SUBPARTITION_POSITION | decimal(10,0) | NO | パーティション内のサブパーティションの位置 |
| OBJECT_TYPE | varchar(12) | NO | オブジェクトタイプ：<ul><li>INDEX</li><li>PARTITION</li><li>SUBPARTITION </li></ul> |
| BLEVEL                 | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| LEAF_BLOCKS            | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| DISTINCT_KEYS          | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| AVG_LEAF_BLOCKS_PER_KEY | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| AVG_DATA_BLOCKS_PER_KEY | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| CLUSTERING_FACTOR       | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| NUM_ROWS                | decimal(10,0) | NO | インデックス内の行数 |
| AVG_CACHED_BLOCKS       | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| AVG_CACHE_hit_RATIO     | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| SAMPLE_SIZE             | decimal(10,0) | NO | このフィールドはデフォルトでNULLです |
| LAST_ANALYZED           | datetime(6) | NO | 最後にインデックスを分析した日付 |
| GLOBAL_STATS            | varchar(3) | NO | 統計情報が収集または増分メンテナンスされたかどうかを示します。<ul><li>YES</li><li>NO </li></ul> |
| USER_STATS              | varchar(3) | NO | 統計情報がユーザーによって直接入力されたかどうかを示します。<ul><li>YES</li><li>NO </li></ul> |
| STATTYPE_LOCKED         | varchar(5) | NO | 統計ロックタイプ |
| STALE_STATS             | varchar(3) | NO | オブジェクトの統計情報が古いかどうか |
| SCOPE                   | varchar(7) | NO | このフィールドはデフォルトでNULLです |

## 関連するビューまたはドキュメント

* テーブルレベルの列統計情報を表示するには、[DBA_TAB_STATISTICS](25800.o-dba_tab_statistics-of-sys-tenant.md)参照してください。

* グローバルレベルの列統計情報を表示するには、[DBA_TAB_COL_STATISTICS](25400.o-dba_tab_col_statistics-of-sys-tenant.md)参照してください。

* パーティションレベルの列統計情報を表示するには、[DBA_PART_COL_STATISTICS](23500.o-dba_part_col_statistics-of-sys-tenant.md)参照してください。

* サブパーティションレベルの列統計情報を表示するには、[DBA_SUBPART_COL_STATISTICS](25000.o-dba_subpart_col_statistics-of-sys-tenant.md)参照してください。

* テーブルレベルのヒストグラム統計情報を表示するには、[DBA_TAB_HISTOGRAMS](25500.o-dba_tab_histograms-of-sys-tenant.md)参照してください。

* パーティションレベルのヒストグラム統計情報を表示するには、[DBA_PART_HISTOGRAMS](23600.o-dba_part_histograms-of-sys-tenant.md)参照してください。

* サブパーティションレベルのヒストグラム統計情報を表示するには、[DBA_SUBPART_HISTOGRAMS](25100.o-dba_subpart_histograms-of-sys-tenant.md)参照してください。

* 統計情報の収集方法については、次のドキュメントを参照してください。

  * [手動で統計情報を収集する](../../../1000.performance-tuning-guide/500.sql-optimization/400.sql-optimization/400.optimizer-statistics/200.statistics-collection-methods/300.collect-statistics-manually.md)

  * [自動で統計情報を収集する](../../../1000.performance-tuning-guide/500.sql-optimization/400.sql-optimization/400.optimizer-statistics/200.statistics-collection-methods/400.collect-statistics-automatically.md)
