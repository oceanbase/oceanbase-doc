# oceanbase.DBA_SUBPART_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内のすべてのサブパーティションテーブルの列統計情報とヒストグラム情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | パーティションテーブルの所有者 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| SUBPARTITION_NAME | varchar(128) | NO | サブパーティションテーブル名 |
| COLUMN_NAME | varchar(128) | NO | 列名 |
| NUM_DISTINCT | decimal(10,0) | NO | 列の異なる値の数 |
| LOW_VALUE | varchar(128) | NO | 列の最小値 |
| HIGH_VALUE | varchar(128) | NO | 列の最大値 |
| DENSITY | decimal(10,0) | NO | 列の密度。COLUMN_NAMEに対するヒストグラムが利用可能な場合、この列はヒストグラム上で2つの端点を越えない値の選択性を示します。2つ以上の端点を越える値の選択性を表すものではありません。COLUMN_NAMEに対するヒストグラムが利用不可な場合、この列の値は1/NUM_DISTINCTとなります |
| NUM_NULLS | decimal(10,0) | NO | 列内のNULL数 |
| NUM_BUCKETS | decimal(10,0) | NO | 列のヒストグラムのバケット数 |
| LAST_ANALYZED | datetime(6) | NO | 最終的に分析された日付 |
| SAMPLE_SIZE | decimal(10,0) | NO | カラム分析に使用されたサンプルサイズ |
| GLOBAL_STATS | varchar(3) | NO | 統計情報が収集されたかどうかを示します。<ul><li>YES</li><li>NO</li></ul>  |
| USER_STATS | varchar(3) | NO | 統計情報がユーザーによって直接入力されたかどうかを示します。<ul><li>YES</li><li>NO</li></ul> |
| NOTES | varchar(80) | NO | 統計情報の追加の属性を説明します。例：値がINCREMENTALの場合、グローバル統計情報はサマリーから取得されたものです。つまり、グローバル統計情報は増分でメンテナンスされています |
| AVG_COL_LEN | decimal(10,0) | NO | 列の平均長（バイト単位） |
| HISTOGRAM | varchar(15) | NO | ヒストグラムのタイプを示します。<ul><li>NONE</li><li>FREQUENCY</li><li>HEIGHT BALANCED</li><li>HYBRID</li><li>TOP-FREQUENCY</li></ul> |
