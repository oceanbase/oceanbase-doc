# oceanbase.DBA_OB_ZONES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのゾーンの情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
|--------|---------------|------------|-----------------------------|
| ZONE   | varchar(128)  | NO         | Zone名           |
| CREATE_TIME | timestamp(6)  | NO    | Zoneの作成時間     |
| MODIFY_TIME | timestamp(6)  | NO    | Zoneの変更時間    |
| STATUS | varchar(4096) | NO         | Zoneのステータス：<ul><li>`ACTIVE`：現在はアクティブ状態で、正常にサービスを提供しています   </li><li> `INACTIVE`：Zoneは停止状態です  </li></ul>  |
| IDC    | varchar(4096) | NO         | Zoneが所属するIDC情報   |
| REGION | varchar(4096) | NO         | Zoneが所属するRegion情報|
| TYPE   | varchar(4096) | NO         | Zoneのタイプ：<ul><li>`ReadWrite`：読み書きゾーン   </li><li> `Encryption`：暗号化ゾーン </li></ul>   |

## クエリ例

システムテナントがクラスタ内のすべてのゾーン情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONES;
```

クエリ結果は次のとおりです：

```shell
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC  | REGION  | TYPE      |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| zone1 | 2025-01-06 16:31:31.733840 | 2025-01-07 13:53:45.645465 | ACTIVE |      | region1 | ReadWrite |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
1 row in set
```
