# oceanbase.CDB_OB_ARCHIVELOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントの各パスにおけるログアーカイブ状態を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| DEST_ID | bigint(20) | NO | パス識別子 |
| ROUND_ID | bigint(20) | NO | バックアップラウンドの識別子 |
| INCARNATION | bigint(20) | NO | Flashback Database後の分身回数を表す |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別する |
| STATUS | varchar(64) | NO | アーカイブ状態：<ul><li>`PREPARE`：アーカイブ開始点`START_SCN`の準備中</li> <li>`BEGINNING`：ログアーカイブの起動中 </li> <li>`DOING`：ログアーカイブ中 </li><li> `INTERRUPTED`：ログアーカイブが中断され、人の介入が必要 </li><li>`STOP`：ログアーカイブが停止 </li><li>`STOPPING`：ログアーカイブの停止中 </li><li>`SUSPENDING`：ログアーカイブの一時停止中 </li><li>`SUSPEND`：ログアーカイブが一時停止 </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | バックアップ開始ポイント |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に変換した表示 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に変換した表示 |
| COMPATIBLE | bigint(20) | NO | 互換バージョン |
| BASE_PIECE_ID | bigint(20) | NO | このラウンドの最初のピースID |
| USED_PIECE_ID | bigint(20) | NO | このラウンドで使用されたピースID |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | ピース切り替え間隔 |
| UNIT_SIZE   | bigint(20)   | NO   | ログアーカイブデータの1回あたりの圧縮または暗号化されるログブロックサイズ。現在、このフィールドはサポートされていません。    |
| COMPRESSION | varchar(128) | NO   | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを表す </li><li> lz4_1.0：圧縮アルゴリズムlz4_1.0を使用することを表す </li><li>zstd_1.3.8：圧縮アルゴリズムzstd_1.3.8を使用することを表す</li></ul>現在、このフィールドはサポートされていません。    |
| INPUT_BYTES | bigint(21) | NO | 読み取ったデータ量、単位はバイト |
| INPUT_BYTES_DISPLAY | varchar(28) | NO | INPUT_BYTESを単位変換した表示、単位はMB、GB、TB、PBのいずれか<br>OceanBaseデータベースは現在、このフィールドをサポートしていません |
| OUTPUT_BYTES | bigint(21) | NO | 出力データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(28) | NO | OUTPUT_BYTESを単位変換した表示、単位はMB、GB、TB、PBのいずれか<br>OceanBaseデータベースは現在、このフィールドをサポートしていません |
| COMPRESSION_RATIO | decimal(24,2) | NO | 圧縮率。OceanBaseデータベースは現在、このフィールドをサポートしていません |
| DELETED_INPUT_BYTES | bigint(20) | NO | 削除された元のデータ量、単位はバイト |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_INPUT_BYTESを単位変換した表示、単位はMB、GB、TB、PBのいずれか |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | 削除された有効なデータ量、単位はバイト |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_OUTPUT_BYTESを単位変換した後の表示形式。単位はMB、GB、TB、PBのいずれか |
| COMMENT | varchar(262144) | NO | エラーメッセージを表示 |
| PATH | varchar(2048) | NO | アーカイブパス |
