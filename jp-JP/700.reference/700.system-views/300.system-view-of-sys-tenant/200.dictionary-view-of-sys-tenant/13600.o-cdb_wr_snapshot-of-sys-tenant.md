# oceanbase.CDB_WR_SNAPSHOT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントの`SNAPSHOT`情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | クラスタID |
| TENANT_ID | bigint(20) | NO | テナントID |
| SNAP_ID | bigint(20) | NO | スナップショットID |
| SVR_IP | varchar(46) | NO | ノードIP |
| SVR_PORT | bigint(20) | NO | ノードPORT |
| BEGIN_INTERVAL_TIME | timestamp(6) | NO | スナップショット開始時間。タイムスタンプはミリ秒単位です。 |
| END_INTERVAL_TIME | timestamp(6) | NO | スナップショット終了時間。タイムスタンプはミリ秒単位です。 |
| SNAP_FLAG | bigint(20) | YES | スナップショットのトリガー原因 |
| STARTUP_TIME | timestamp(6) | YES | プロセス起動時間。タイムスタンプはミリ秒単位です。 |

## 使用例

すべてのテナントの`SNAPSHOT`情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_WR_SNAPSHOT  LIMIT 1\G
```

クエリ結果は次のとおりです。

```shell

          SNAP_FLAG: 3

1 row in set (0.037 sec)
```
