# oceanbase.DBA_OB_UNIT_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのUnit関連タスクを表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
|-------------|--------------|-----|-----------------------------------------------------|
| JOB_ID      | bigint(20)   | NO  | タスクID                     |
| JOB_TYPE    | varchar(128) | NO  | タスクタイプ。`MIGRATE_UNIT`はUnit移行タスクを表す                                                                             |
| JOB_STATUS  | varchar(128) | NO  | タスクの状態。<ul><li>`INPROGRESS`：進行中</li><li>`SUCCESS`：成功</li><li>`FAILED`：失敗 </li></ul>   |
| RESULT_CODE | bigint(20)   | YES | タスク終了コード                     |
| PROGRESS    | bigint(20)   | NO  | タスクの進捗率（値の範囲は \[0, 100\]）    |
| START_TIME  | timestamp(6) | YES | タスク開始時間                    |
| MODIFY_TIME | timestamp(6) | YES | 最終のタスク変更時刻                |
| TENANT_ID   | bigint(20)   | YES | テナントID：<ul><li>`NULL`：Unitがどのテナントにも属さない場合 </li><li>有効な値：Unitが属するテナントID  </li></ul>  |
| UNIT_ID     | bigint(20)   | YES | Unit ID                   |
| SQL_TEXT    | longtext     | YES | 関連するSQL文字列                |
| EXTRA_INFO  | varchar(512) | YES | 追加情報                     |
| RS_SVR_IP   | varchar(46)  | NO  | Root ServiceサーバーのIPアドレス     |
| RS_SVR_PORT | bigint(20)   | NO  | Root Serviceサーバーのポート番号        |

## クエリ例

システムテナントがすべてのUnitに関連するタスク情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_JOBS;
```

+--------+--------------+------------+-------------+----------+----------------------------+----------------------------+-----------+---------+----------+------------+----------------+-------------+
|      6 | MIGRATE_UNIT | INPROGRESS |        NULL |        0 | 2025-07-04 11:27:51.957456 | 2025-07-04 11:27:51.957456 |      1006 |    1008 | NULL     | NULL       | 172.xx.xxx.xxx |        2882 |
+--------+--------------+------------+-------------+----------+----------------------------+----------------------------+-----------+---------+----------+------------+----------------+-------------+
1 row in set
