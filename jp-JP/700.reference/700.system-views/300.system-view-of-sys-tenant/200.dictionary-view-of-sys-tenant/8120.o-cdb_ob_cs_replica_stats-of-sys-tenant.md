# oceanbase.CDB_OB_CS_REPLICA_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.5 BP1バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントの各OBServer上におけるCコピーのログストリームにおいて、Tabletがカラムストアに変換される進捗状況を表示します。

## フィールド説明

| フィールド名                   | 型          | NULL許容      | 説明                                |
|---------------------------|---------------|---------------------|-------------------------------------|
| TENANT_ID                 | bigint(20)    | NO   | テナントID |
| SVR_IP                    | varchar(46)   | NO   | Cレプリカが配置されているサーバーのIPアドレス |
| SVR_PORT                  | bigint(20)    | NO   | Cレプリカが配置されているサーバーのポート番号  |
| LS_ID                     | bigint(20)    | NO   | ログストリームID  |
| TOTAL_TABLET_CNT          | bigint(20)    | NO   | カラムストアに変換するパーティション数  |
| AVAILABLE_TABLET_CNT      | decimal(42,0) | NO   | 利用可能なパーティション数    |
| TOTAL_MACRO_BLOCK_CNT     | decimal(42,0) | NO   | 総ベースラインマクロブロック数（マルチバージョンを除く）  |
| AVAILABLE_MACRO_BLOCK_CNT | decimal(42,0) | NO   | 利用可能なベースラインマクロブロック数（マルチバージョンを除く）   |
| AVAILABLE                 | varchar(5)    | NO   | ログストリームが完全に利用可能か：<ul><li>`TRUE`：利用可能。このログストリーム上のすべてのTabletが利用可能な場合に、このログストリームは完全に利用可能となります。</li> <li>`FALSE`：利用不可</li></ul>  |

## クエリ例

システムテナントが、テナントIDが1004のテナントの各OBServer上におけるCコピーのログストリームにおけるTabletからColumnarへの変換進捗状況を照会します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_CS_REPLICA_STATS WHERE TENANT_ID=1004;
```

クエリ結果は次のとおりです：

```shell
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
| TENANT_ID | SVR_IP         | SVR_PORT | LS_ID | TOTAL_TABLET_CNT | AVAILABLE_TABLET_CNT | TOTAL_MACRO_BLOCK_CNT | AVAILABLE_MACRO_BLOCK_CNT | AVAILABLE |
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
|      1004 | xx.xxx.xxx.212 |    63000 |  1001 |             1019 |                 1019 |                 10706 |                     10706 | TRUE      |
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
1 row in set
```

クエリ結果に基づき、`AVAILABLE_TABLET_CNT / TOTAL_TABLET_CNT` または `AVAILABLE_MACRO_BLOCK_CNT / TOTAL_MACRO_BLOCK_CNT` の値を計算することで、行ストアからColumnarストアへの移行進捗を大まかに推定できます。
