# oceanbase.DBA_SCHEDULER_JOB_RUN_DETAILS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_SCHEDULER_JOB_RUN_DETAILS` は、現在のテナント内のすべてのスケジューラーのジョブ情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | -------- |
| LOG_ID            | decimal(10,0)                    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| LOG_DATE          | datetime                         | NO   | ログエントリ。|
| OWNER             | varchar(128)                     | NO   | ジョブの所有者。|
| JOB_NAME          | varchar(128)                     | NO   | ジョブの名前。|
| JOB_SUBNAME       | varchar(128)                     | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| STATUS            | varchar(128)                     | NO   | ジョブのステータス。|
| CODE              | bigint(20)                       | YES  | ジョブ実行時に発生したエラーのエラー番号。 |
| REQ_START_DATE    | datetime                         | NO   | ジョブの予想開始時間。|
| ACTUAL_START_DATE | datetime                         | NO   | ジョブの実際の開始時間。|
| RUN_DURATION      | decimal(10,0)                    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| INSTANCE_ID       | varchar(128)                     | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| SESSION_ID        | decimal(10,0)                    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| SLAVE_PID         | varchar(128)                     | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| CPU_USED          | decimal(10,0)                    | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| CREDENTIAL_OWNER  | varchar(128)                     | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| CREDENTIAL_NAME   | varchar(128)                     | NO   | このフィールドは現在サポートされておらず、デフォルトはNULLです。|
| DESTINATION_OWNER | varchar(128)                     | NO   | 現在、クロスデータベースジョブはサポートされていないため、このフィールドはデフォルトでNULLです。|
| DESTINATION       | varchar(128)                     | NO   | 現在、クロスデータベースジョブはサポートされていないため、このフィールドはデフォルトでNULLです。|
| MESSAGE           | varchar(4000)                    | NO   | ジョブ実行時に返されるエラーメッセージ。 |
| JOB               | bigint(20)                       | NO   | プログラムジョブの名前。 |
| TIME              | timestamp(6)                     | NO   | ジョブ実行ログの記録時間、単位は秒。 |
| JOB_CLASS         | varchar(30)                      | YES  | プログラムジョブのカテゴリ。 |
| GMT_CREATE        | timestamp(6)                     | YES  | プログラムジョブの作成時間、単位は秒。 |
| GMT_MODIFIED      | timestamp(6)                     | YES  | プログラムジョブの変更時間、単位は秒です。 |
