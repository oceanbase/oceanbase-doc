# oceanbase.CDB_OB_TABLE_LOCATIONS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_TABLE_LOCATIONS` は、システムテーブル、ユーザーテーブル、インデックステーブルなどを含む、テーブルまたはパーティションの場所を表示するために使用されます。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| DATABASE_NAME | varchar(128) | NO | データベース名 |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TABLE_ID | bigint(20) | NO | テーブルID |
| TABLE_TYPE | varchar(13) | NO | テーブルタイプ：<ul><li>USER TABLE：ユーザーテーブル </li><li>SYSTEM TABLE：システムテーブル、システムが作成したテーブル </li><li>INDEX：インデックステーブル </li><li>LOB AUX TABLE：LOB補助テーブル、システムが作成したテーブルで、LOB列の補助的な実装に使用されます</li></ul> |
| PARTITION_NAME | varchar(64) | NO | パーティション名。パーティションテーブル以外の場合はデフォルトでNULL |
| SUBPARTITION_NAME | varchar(64) | NO | サブパーティション名。サブパーティションが存在しない場合はNULL |
| INDEX_NAME | varchar(256) | NO | インデックステーブルの場合はインデックス名を表示し、それ以外の場合はNULLを表示 |
| DATA_TABLE_ID | bigint(20) | NO | インデックステーブルまたはLOB補助テーブルの場合は、所属するメインテーブルのIDを表示し、それ以外の場合はNULLを表示 |
| TABLET_ID | bigint(20) | NO | TABLET ID |
| LS_ID | bigint(20) | NO | オブジェクトが属するログストリーム |
| ZONE | varchar(128) | NO | レプリカが属するゾーン |
| SVR_IP | varchar(46) | NO | レプリカのIPアドレス |
| SVR_PORT | bigint(20) | NO | レプリカのポート番号 |
| ROLE | varchar(8) | NO | レプリカの役割 |
| REPLICA_TYPE | varchar(18) | NO | ログストリームタイプ：<ul><li>`FULL`：フル機能型</li> <li>READONLY：読み取り専用型</li></ul> |
| DUPLICATE_SCOPE | varchar(7) | NO | このテーブルがレプリケーションテーブルであるかどうかを示します。値は以下のとおりです：<ul><li>`CLUSTER`：レプリケーションテーブル </li><li>`NONE`：通常のテーブル </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| OBJECT_ID | bigint(20) | NO | パーティションに対応するオブジェクトID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| TABLEGROUP_NAME | varchar(128) | NO | テーブルに対応するTable Groupの名前<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| TABLEGROUP_ID | bigint(20) | NO | テーブルに対応するTable GroupのID<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| SHARDING | varchar(10) | NO | テーブルに対応するTable GroupのSharding属性（均等化モード）<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| INDEX_TYPE | varchar(6) | YES | インデックステーブルのインデックスに関する`GLOBAL`/`LOCAL`プロパティ情報を表示します。以下の3つの値があります：<ul><li>`NULL`：非インデックステーブルを表します。</li><li>`GLOBAL`：グローバルインデックスを表し、`INDEX_TYPE_NORMAL_GLOBAL`、`INDEX_TYPE_UNIQUE_GLOBAL`、`INDEX_TYPE_SPATIAL_GLOBAL`を含みます。</li><li>`LOCAL`：ローカルインデックスを表し、`INDEX_TYPE_NORMAL_LOCAL`、`INDEX_TYPE_UNIQUE_LOCAL`、`INDEX_TYPE_PRIMARY`、`INDEX_TYPE_DOMAIN_CTXCAT`、`INDEX_TYPE_NORMAL_GLOBAL_LOCAL_STORAGE`、`INDEX_TYPE_UNIQUE_GLOBAL_LOCAL_STORAGE`、`INDEX_TYPE_SPATIAL_LOCAL`、`INDEX_TYPE_SPATIAL_GLOBAL_LOCAL_STORAGE`を含みます。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>OceanBaseデータベースV4.2.5では、このフィールドはV4.2.5 BP2バージョンから導入されました。</p></main>

## クエリ例

