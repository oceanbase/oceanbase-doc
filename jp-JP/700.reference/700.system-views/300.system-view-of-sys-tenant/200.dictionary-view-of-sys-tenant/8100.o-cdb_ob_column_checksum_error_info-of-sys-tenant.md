# oceanbase.CDB_OB_COLUMN_CHECKSUM_ERROR_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

インデックステーブル（グローバルインデックスとローカルインデックスを含む）とメインテーブル間で発生した列チェックサムの不整合情報を表示します。

## フィールド説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| FROZEN_SCN | bigint(20) unsigned | NO | 現在のマージSCN |
| INDEX_TYPE | varchar(12) | NO | インデックステーブルタイプ：<ul><li>0：ローカルインデックステーブル</li><li>1：グローバルインデックステーブル</li></ul> |
| DATA_TABLE_ID | bigint(20) | NO | メインテーブルID |
| INDEX_TABLE_ID | bigint(20) | NO | グローバル/ローカルインデックステーブルID |
| DATA_TABLET_ID | bigint(20) | NO | チェックサムが一致しない列が存在するメインテーブルのTABLET ID（ローカルインデックステーブルとメインテーブル間のチェックにのみ適用） |
| INDEX_TABLET_ID | bigint(20) | NO | チェックサムが一致しない列が存在するインデックステーブルのTABLET ID（ローカルインデックステーブルとメインテーブル間のチェックにのみ適用） |
| COLUMN_ID | bigint(20) | NO | checksum errorが発生した列のID |
| DATA_COLUMN_CHECKSUM | bigint(20) | NO | メインテーブルの該当列のcolumn checksum値 |
| INDEX_COLUMN_CHECKSUM | bigint(20) | NO | インデックステーブルの該当列のcolumn checksum値 |
