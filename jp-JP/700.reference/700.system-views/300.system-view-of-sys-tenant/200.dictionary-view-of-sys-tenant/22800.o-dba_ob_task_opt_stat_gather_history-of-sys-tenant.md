# oceanbase.DBA_OB_TASK_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントにおける履歴収集タスクの実行状況を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 収集タスクが存在するテナントID |
| TASK_ID | varchar(36) | NO | 収集タスクID（UUID形式で生成され、グローバルに一意） |
| TYPE | varchar(16) | NO | 収集タスクのタイプ |
| STATUS | varchar(8) | NO | 収集タスクのステータス。<ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| TABLE_COUNT | bigint(20) | YES | 収集タスクで収集するテーブル数 |
| FAILED_COUNT | bigint(20) | YES | 収集タスクで収集に失敗したテーブル数 |
| START_TIME | datetime(6) | NO | 収集タスクの開始時刻 |
| END_TIME | datetime(6) | NO | 収集タスクの終了時刻 |

## クエリ例

本テナントの手動収集タスクの履歴実行状況を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TASK_OPT_STAT_GATHER_HISTORY WHERE TYPE='MANUAL GATHER';
```
