# oceanbase.CDB_CKPT_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.x系ではストレージアーキテクチャが最適化されたため、このビューはV4.0.0以降のバージョンから削除されました。</li>
<li>V4.x系では、Mini Compactionタイプ（ダンプ）については明確な開始時刻と終了時刻が存在しないため、チェックポイント関連情報を一時的に照会できません。Major Compactionタイプ（メジャーコンパクション）については、システムテナントはビュー<a href="10000.o-cdb_ob_major_compaction-of-sys-tenant.md">CDB_OB_MAJOR_COMPACTION</a>を使用して各テナントのチェックポイント実行関連情報を照会でき、ユーザーテナントはビュー<a href="../../400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/10300.o-dba_ob_major_compaction-of-mysql-mode.md">DBA_OB_MAJOR_COMPACTION</a>を使用して自身のテナントのチェックポイント実行関連情報を照会できます。</li></ul>
</main>

## 機能の概要

`CDB_CKPT_HISTORY`は、システム内の各テナントが実行したチェックポイントに関する情報を表示するために使用されます。これには、チェックポイントのタイプ、バージョン番号、クラスタバージョン、開始時刻、終了時刻が含まれます。

## フィールド説明

|    **フィールド名**            |    **型**  | **NULL許容** |                    **説明**                                                            |
|----------------------------|--------------|------------|----------------------------------------------------------------------------------------------|
| SVR_IP                     | varchar(32)  | NO         | サーバーのIPアドレス                                                                            |
| SVR_PORT                   | bigint(20)   | NO         | サーバーのポート番号                                                                              |
| TENANT_ID                  | varchar(256) | NO         | テナントID                                                                                      |
| CHECKPOINT_SNAPSHOT        | longtext     | NO         | 書き込みチェックポイントのスナップショットバージョン番号を表す                                                          |
| CHECKPOINT_TYPE            | varchar(256) | NO         | チェックポイントのタイプ： <ul><li> META_CKPT：Major Compaction   </li><li> DATA_CKPT：Mini Compaction </li></ul> |
| CHECKPOINT_CLUSTER_VERSION | varchar(256) | NO         | 書き込みチェックポイントのOceanBaseクラスタのバージョン番号                                                    |
| START_TIME                 | timestamp(6) | NO         | チェックポイントの開始時間                                                                      |
| FINISH_TIME                | varchar(32)  | NO         | チェックポイントの終了時間                                                                      |
