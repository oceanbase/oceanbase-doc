# oceanbase.DBA_OB_BACKUP_SET_FILES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント自身のバックアップセットのファイル状態を表示します。OceanBaseデータベースは、`sys`テナントとMetaテナントに対する物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名                       | フィールド名        | NULL許容 | フィールド名                         |
|-------------------------------|----------------|-----------------|----------------------------------|
| BACKUP_SET_ID | bigint(20) | NO | バックアップセットID |
| DEST_ID | bigint(20) | NO | バックアップパスID |
| INCARNATION | bigint(20) | NO | Flashback Database後の分身の回数を表す |
| BACKUP_TYPE | varchar(64) | NO | バックアップタイプ：<ul><li>`FULL`：フルバックアップを表す </li> <li>`INC`：増分バックアップを表す</li></ul> |
| PREV_FULL_BACKUP_SET_ID | bigint(20) | NO | 現在のバックアップセットが依存する直前のフルバックアップのBACKUP_SET_ID |
| PREV_inc_BACKUP_SET_ID | bigint(20) | NO | 現在のバックアップセットが依存する直前の増分バックアップのBACKUP_SET_ID |
| START_TIMESTAMP | timestamp(6) | NO | バックアップセットの開始タイムスタンプ |
| END_TIMESTAMP | timestamp(6) | NO | バックアップセットの終了タイムスタンプ |
| STATUS | varchar(64) | NO | バックアップの状態 |
| FILE_STATUS | varchar(64) | NO | バックアップセットのファイル状態：<ul><li>COPYING：ファイルがバックアップ中であることを示す</li><li>AVAILABLE：このバックアップが有効であることを示す</li><li>DELETING：ファイルが削除中であることを示す</li><li>EXPIRED：バックアップファイルが無効であることを示す</li><li>INCOMPLETE：バックアップファイルに欠落があることを示す</li><li>BROKEN：バックアップファイルが不完全で使用できないことを示す</li><li>DELETED：バックアップファイルが削除されたことを示す</li></ul> |
| ELAPSED_SECONDES | decimal(22,0) | NO | バックアップにかかった時間 |
| PLUS_ARCHIVELOG | varchar(4096) | NO | ログの補完の有無 |
| START_REPLAY_SCN | bigint(20) unsigned | NO | バックアップセットが依存するログ再生SCN |
| START_REPLAY_SCN_DISPLAY | datetime(6) | NO | バックアップセットが依存するログ再生タイムスタンプ |
| MIN_RESTORE_SCN | bigint(20) unsigned | NO | バックアップセットの最新復元可能SCN |
| MIN_RESTORE_SCN_DISPLAY | varchar(4096) | NO | バックアップセットの最小復元可能タイムスタンプ |
| INPUT_BYTES | bigint(20) | YES | 入力バイト数 |
| OUTPUT_BYTES | bigint(20) | YES | 出力バイト数 |
| OUTPUT_RATE_BYTES | decimal(28,4) | NO | 1秒間の出力バイト数 |
| EXTRA_META_BYTES | bigint(20) | YES | 追加バイト数 |
| TABLET_COUNT | bigint(20) | YES | バックアップTABLETの総数 |
| FINISH_TABLET_COUNT | bigint(20) | YES | バックアップ完了TABLETの総数 |
| MACRO_BLOCK_COUNT | bigint(20) | YES | バックアップマクロブロックの総数 |
| FINISH_MACRO_BLOCK_COUNT | bigint(20) | YES | バックアップ完了マクロブロックの総数 |
| FILE_COUNT | bigint(20) | YES | バックアップファイル数 |
| META_TURN_ID | bigint(20) | YES | バックアップMETAのラウンド |
| DATA_TURN_ID | bigint(20) | YES | バックアップデータのサイクル番号 |
| RESULT | bigint(20) | NO | バックアップエラーコードの結果 |
| COMMENT | varchar(4096) | YES | バックアップエラーコードの説明 |
| ENCRYPTION_MODE | varchar(64) | YES | 暗号化モード：<ul><li>>None：暗号化しないことを示します。</li><li>Password：パスワードによるみだけの保護を示します。</li><li>Password Encryption：暗号化され、パスワードで保護されます。</li><li>Transparent Encryption：TDEによる暗号化を使用します。</li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用します。</li></ul> </br>現在、NoneとPasswordの2つのモードのみをサポートしています。 |
| PASSWD | varchar(128) | YES | パスワード |
| TENANT_COMPATIBLE | varchar(4096) | NO | テナントのバージョン番号 |
| BACKUP_COMPATIBLE | bigint(20) | NO | バックアップセットのバージョン番号 |
| PATH | varchar(4096) | YES | バックアップパス |
| CLUSTER_VERSION| varchar(4096)| NO | クラスタのバージョン番号|
| CONSISTENT_SCN                | bigint(20) unsigned | NO         | バックアップの一貫性ビットポイント      |
| MINOR_TURN_ID                 | bigint(20)          | NO         | ダンプデータバックアップ終了のサイクル      |
| MAJOR_TURN_ID                 | bigint(20)          | NO         | ベースラインデータバックアップ終了のサイクル      |
