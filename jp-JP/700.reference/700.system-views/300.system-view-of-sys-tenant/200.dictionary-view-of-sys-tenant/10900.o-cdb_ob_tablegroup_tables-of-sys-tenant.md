# oceanbase.CDB_OB_TABLEGROUP_TABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下におけるすべてのテナントのテーブルとテーブルグループの関連性を表示します。テーブルグループに属していないテーブルは表示されません。

## フィールドの説明

|      フィールド名       |      型          | NULL許容    |      説明       |
|-----------------|---------------|------------|---------------|
| TENANT_ID       | bigint(20)    | NO         | テナントID         |
| TABLEGROUP_NAME | VARCHAR2(128) | NO         | テーブルグループ名           |
| OWNER           | VARCHAR2(128) | NO         | テーブルが属するデータベース名 |
| TABLE_NAME      | VARCHAR2(256) | NO         | テーブル名       |
| SHARDING        | varchar(10)   | NO         | テーブルグループのSHARDINGプロパティ:<ul><li>`NONE`：テーブルグループ内のすべてのテーブルのすべてのパーティションは同一マシンに集約され、テーブルグループへの追加テーブルに制限はありません。</li> <li>`PARTITION`：テーブルグループ内の各テーブルのデータをパーティション単位で分散します。サブパーティションテーブルの場合、各パーティションのサブパーティションがまとめられます。</li> <li>`ADAPTIVE`：テーブルグループ内の各テーブルのデータを適応型方式で分散します。つまり、テーブルグループ内のテーブルがパーティションテーブルの場合はパーティション単位で、サブパーティションテーブルの場合は各パーティションのサブパーティション単位で分散します。</li></ul>    |

## クエリ例

システムテナント配下で、`tblgroup1` という名前のテーブルグループの関連性を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'tblgroup1';
```

クエリ結果は次のとおりです：

```shell
+-----------+-----------------+-------+------------+----------+
| TENANT_ID | TABLEGROUP_NAME | OWNER | TABLE_NAME | SHARDING |
+-----------+-----------------+-------+------------+----------+
|      1002 | tblgroup1       | test  | tbl3       | ADAPTIVE |
|      1004 | TBLGROUP1       | SYS   | TBL3       | NONE     |
+-----------+-----------------+-------+------------+----------+
2 rows in set
```
