# oceanbase.DBA_IND_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのインデックスのオプティマイザー統計情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | インデックス所有者 |
| INDEX_NAME | varchar(128) | NO | インデックス名 |
| TABLE_OWNER | varchar(128) | NO | インデックス対象の所有者 |
| TABLE_NAME | varchar(128) | NO | インデックス対象の名前 |
| PARTITION_NAME | varchar(128) | NO | パーティション名 |
| PARTITION_POSITION | decimal(10,0) | NO | インデックス内のパーティション位置 |
| SUBPARTITION_NAME | varchar(128) | NO | サブパーティション名 |
| SUBPARTITION_POSITION | decimal(10,0) | NO | パーティション内のサブパーティション位置 |
| OBJECT_TYPE           | varchar(12) | NO | オブジェクトタイプ：<ul><li>INDEX</li><li>PARTITION</li><li>SUBPARTITION </li></ul> |
| BLEVEL                 | decimal(10,0) | NO | デフォルト値はNULL |
| LEAF_BLOCKS            | decimal(10,0) | NO | デフォルト値はNULL |
| DISTINCT_KEYS          | decimal(10,0) | NO | デフォルト値はNULL |
| AVG_LEAF_BLOCKS_PER_KEY | decimal(10,0) | NO | デフォルト値はNULL |
| AVG_DATA_BLOCKS_PER_KEY | decimal(10,0) | NO | デフォルト値はNULL |
| CLUSTERING_FACTOR       | decimal(10,0) | NO | デフォルト値はNULL |
| NUM_ROWS                | decimal(10,0) | NO | インデックス内の行数 |
| AVG_CACHED_BLOCKS       | decimal(10,0) | NO | デフォルト値はNULL |
| AVG_CACHE_hit_RATIO     | decimal(10,0) | NO | デフォルト値はNULL |
| SAMPLE_SIZE             | decimal(10,0) | NO | デフォルト値はNULL |
| LAST_ANALYZED           | datetime(6) | NO | インデックスを最後に分析した日付 |
| GLOBAL_STATS            | varchar(3) | NO | 統計情報が収集または増分メンテナンスされているかどうかを示します。<ul><li>YES</li><li>NO</li></ul>  |
| USER_STATS              | varchar(3) | NO | 統計情報がユーザーによって直接入力されたかどうかを示します。<ul><li>YES</li><li>NO</li></ul>  |
| STATTYPE_LOCKED         | varchar(5) | NO | 統計ロックタイプ |
| STALE_STATS             | varchar(3) | NO | オブジェクトの統計情報が古くなっているかどうか |
| SCOPE                   | varchar(7) | NO | デフォルト値はNULL |
