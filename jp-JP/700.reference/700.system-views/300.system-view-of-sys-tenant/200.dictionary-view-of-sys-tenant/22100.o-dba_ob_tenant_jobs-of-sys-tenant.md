# oceanbase.DBA_OB_TENANT_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントレベルのタスク情報を表示します。

## フィールドの説明

|    フィールド名     |      タイプ      | NULLを許容するか |                                                              説明                                                               |
|-------------|--------------|------------|-------------|
| JOB_ID      | bigint(20)   | NO         | ジョブID                                      |
| JOB_TYPE    | varchar(128) | NO         | ジョブタイプ：<ul><li> `ALTER_TENANT_LOCALITY`：テナントのローカリティを変更</li> <li>`ROLLBACK_ALTER_TENANT_LOCALITY`：テナントのローカリティをロールバック</li> <li>`SHRINK_RESOURCE_TENANT_UNIT_NUM`：テナントのユニット数を縮小</li> <li>`ALTER_TENANT_PRIMARY_ZONE`：テナントの`PRIMARY_ZONE`を変更</li>  <li>`ALTER_RESOURCE_TENANT_UNIT_NUM`：テナントリソースプールの`UNIT_NUM`を変更</li> <li>`UPGRADE_POST_ACTION`：アップグレードの前処理</li> <li>`UPGRADE_SYSTEM_VARIABLE`：システム変数のアップグレード</li> <li>`UPGRADE_SYSTEM_TABLE`：システムテーブルのアップグレード</li> <li>`UPGRADE_BEGIN`：アップグレード開始</li> <li>`UPGRADE_VIRTUAL_SCHEMA`：スキーマのアップグレード</li> <li>`UPGRADE_SYSTEM_PACKAGE`：システムパッケージのアップグレード</li> <li>`UPGRADE_ALL_POST_ACTION`：アップグレードの後処理</li> <li>`UPGRADE_INSPECTION`：アップグレードチェック</li> <li>`UPGRADE_END`：アップグレード終了</li> <li>`UPGRADE_ALL`：すべてのテナントのアップグレード</li></ul>   |
| JOB_STATUS  | varchar(128) | NO         | ジョブ状態：<ul><li>`INPROGRESS`：進行中   </li><li> `SUCCESS`：成功   </li><li> `FAILED`：失敗    </li></ul>  |
| RESULT_CODE | bigint(20)   | YES        | ジョブ終了コード                                      |
| PROGRESS    | bigint(20)   | NO         | ジョブの進捗率（値の範囲：\[0, 100\]）                     |
| START_TIME  | timestamp(6) | YES        | ジョブ開始時間                                     |
| MODIFY_TIME | timestamp(6) | YES        | 最後のジョブ変更時間                                 |
| TENANT_ID   | bigint(20)   | YES        | テナントID                                      |
| SQL_TEXT    | longtext     | YES        | 関連するSQL文字列                                 |
| EXTRA_INFO  | varchar(512) | YES        | 追加情報                                      |
| RS_SVR_IP   | varchar(46)  | NO         | Root ServiceサーバーのIPアドレス                      |
| RS_SVR_PORT | bigint(20)   | NO         | Root Serviceサーバーのポート番号                         |

## クエリ例

システムテナントは、すべてのテナントのテナントタスク情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_JOBS\G
```
