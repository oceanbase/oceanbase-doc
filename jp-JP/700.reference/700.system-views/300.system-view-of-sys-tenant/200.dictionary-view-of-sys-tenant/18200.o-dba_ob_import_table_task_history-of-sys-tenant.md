# oceanbase.DBA_OB_IMPORT_TABLE_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのテーブルレベルでのテナント間インポートタスクの履歴を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | varchar(4096) | NO | ロードバランシングタスクID |
| JOB_ID | bigint(20) | NO | タスクID |
| SRC_TENANT_ID | bigint(20) | NO | ソーステナントID |
| SRC_TABLESPACE | varchar(128) | YES | ソーステーブルのTABLESPACE |
| SRC_TABLEGROUP | varchar(128) | YES | ソーステーブルのTABLEGROUP |
| SRC_DATABASE | varchar(128) | YES | ソーステーブルのDATABASE |
| SRC_TABLE | varchar(128) | YES | ソーステーブル名 |
| SRC_PARTITION | varchar(64) | YES | ソーステーブルのPARTITION名 |
| TARGET_TABLESPACE | varchar(128) | YES | 再マッピングされたテーブルスペース名。再マッピングされていない場合は空として表示されます |
| TARGET_TABLEGROUP | varchar(128) | YES | 再マッピングされたテーブルグループ名。再マッピングされていない場合は空として表示されます |
| TARGET_DATABASE | varchar(128) | YES | 再マッピングされたデータベース名。再マッピングされていない場合は空として表示されます |
| TARGET_TABLE | varchar(128) | YES | 重命名後のテーブル名。重命名されていない場合は空として表示されます |
| TABLE_COLUMN | bigint(20) | NO | テーブル列の数 |
| STATUS | varchar(64) | NO | タスクの状態：<ul><li>`INIT`：テーブルレベルのインポートタスクが初期化されました</li> <li>`DOING`：テーブルレベルのインポートが実行中</li> <li>`FINISH`：インポート終了</li></ul>   |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時のテナント現在時間 |
| COMPLETION_TIMESTAMP | timestamp(6) | NO | タスク完了時のテナント現在時間 |
| CUMULATIVE_TS | bigint(20) | NO | 累計時間 |
| TOTAL_INDEX_COUNT | bigint(20) | NO | 総インデックス数 |
| IMPORTED_INDEX_COUNT | bigint(20) | NO | インポート済みのインデックス数 |
| FAILED_INDEX_COUNT | bigint(20) | NO | インポートに失敗したインデックス数 |
| TOTAL_CONSTRAINT_COUNT | bigint(20) | NO | 総制約数 |
| IMPORTED_CONSTRAINT_COUNT | bigint(20) | NO | インポート済みの制約数 |
| FAILED_CONSTRAINT_COUNT | bigint(20) | NO | インポートに失敗した制約数 |
| TOTAL_REF_CONSTRAINT_COUNT | bigint(20) | NO | 総参照制約数 |
| IMPORTED_REF_CONSTRAINT_COUNT | bigint(20) | NO | インポート済みの参照制約数 |
| FAILED_REF_CONSTRAINT_COUNT | bigint(20) | NO | インポートに失敗した参照制約数 |
| RESULT | varchar(64) | YES | タスク完了の結果：<ul><li>`SUCCESS`：インポートタスクの実行に成功しました</li><li>`FAIL`：インポートタスクの実行に失敗しました</li></ul> |
| COMMENT | longtext | YES | 備考情報 |
