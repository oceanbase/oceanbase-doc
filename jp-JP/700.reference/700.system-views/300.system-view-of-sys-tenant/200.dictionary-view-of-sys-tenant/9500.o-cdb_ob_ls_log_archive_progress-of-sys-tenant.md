# oceanbase.CDB_OB_LS_LOG_ARCHIVE_PROGRESS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのログストリームアーカイブの進捗状況を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)   | NO | テナントID |
| DEST_ID | bigint(20)   | NO | アーカイブ先ID |
| LS_ID | bigint(20)   | NO | ログストリームID |
| ROUND_ID | bigint(20)   | NO | ログストリームラウンドID |
| PIECE_ID | bigint(20)  | NO | 最新ピースID |
| INCARNATION | bigint(20) | NO | 分身ID |
| START_SCN | bigint(20) unsigned | NO | アーカイブ開始SCN |
| MIN_LSN | bigint(20) unsigned | NO | 現在のピースログストリーム最小LSN |
| MAX_LSN | bigint(20) unsigned | NO | 現在のピースログストリーム最大LSN |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のピースログストリーム最大アーカイブ進捗 |
| STATUS | varchar(64)  | NO | テナントアーカイブ状態：<ul><li> PREPARE：アーカイブ開始時の初期状態 </li><li>BEGINNING：アーカイブ開始に関する基本チェックが完了し、この状態に移行 </li><li> DOING：通常のアーカイブ状態 </li><li> INTERRUPTED：アーカイブが中断され、継続できない </li><li> STOPPING：アーカイブの停止が開始され、この状態に移行 </li><li>STOP：アーカイブが停止した状態 </li><li> SUSPENDING：アーカイブが一時停止状態 </li><li> SUSPEND：アーカイブが一時停止状態 </li></ul>|
| FILE_ID  | bigint(20)  | NO | 現在のピースの最大アーカイブファイルID |
| FILE_OFFSET  | bigint(20)  | NO | 現在のピースの最大アーカイブファイルオフセット |
| INPUT_BYTES  | bigint(20)  | NO | 読み取ったログデータ量 |
| OUTPUT_BYTES   | bigint(20)  | NO | アーカイブされたログデータ量 |
