# oceanbase.DBA_OB.AI_MODEL_ENDPOINTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのAIモデルアクセス情報を表示します。

## フィールドの説明

| フィールド | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| ENDPOINT_ID | int(20) | NO | モデルアクセス情報の一意のID。 |
| ENDPOINT_NAME | varchar(128) | NO | ユーザー定義のモデルアクセス情報の一意の名前。 |
| AI_MODEL_NAME | varchar(128) | NO | アクセス情報が属するAIモデル名。 |
| SCOPE | varchar(128) | NO | 予約フィールドで、デフォルトは`all`です。将来、リージョン/ゾーンをまたいだモデルアクセス情報の設定に利用される可能性があります。 |
| URL | varchar(2048) | NO | モデルの呼び出しアドレス。URLはHTTPおよびHTTPSをサポートします。例：`https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings`。` |
| ACCESS_KEY | varchar(2048) | NO | モデル呼び出し時に使用されるAPIキー。 |
| PROVIDER | varchar(128) | NO | AIモデルプロバイダー。例：`openai`、`aliyun`、`deepseek`、`ollama`など。データベース内部のAPIメッセージ形式の適応に使用されます。空の場合はUDF関数を提供する必要があります。そうでない場合はエラーが発生します。 |
| REQUEST_MODEL_NAME | varchar(128) | YES | リクエストメッセージボディ内のユーザー定義のモデル名。例：`bge-m3-custom`。 |
| PARAMETERS | varchar(2048) | YES | 予約フィールドで、オプションパラメータです。モデル呼び出しの追加パラメータを設定するために使用されます。例：`context_window`や`max_output_tokens`など、バッチ処理をサポートするために使用されます。例：`{"context_window": 128000,"max_output_tokens": 8000}`。 |
| REQUEST_TRANSFORM_FN | varchar(64) | YES | 予約フィールドで、AIモデルに送信するリクエストデータの構築に使用されます。空の場合、システムは`PROVIDER`とモデルタイプ(`embedding`/`rerank`/`completion`)に基づいてデフォルトのメッセージ形式を使用してリクエストを送信します。 |
| RESPONSE_TRANSFORM_FN | varchar(64) | YES | 予約フィールドで、AIモデルが返すデータの解析に使用されます。空の場合、システムは`PROVIDER`とモデルタイプ(`embedding`/`rerank`/`completion`)に基づいてデフォルトの返信形式を使用して処理を行います。 |

## クエリ例

ユーザーテナントが本テナントのAIモデルアクセス情報をクエリします。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_MODEL_ENDPOINTS;
```
