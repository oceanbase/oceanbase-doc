# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで設定されているバックアップパラメータ情報を表示します。システムテナントにはユーザーデータが含まれておらず、クラスタ管理用のテナントであるため、バックアップ・リストアはサポートされていません。そのため、`sys` テナントにはバックアップパラメータが設定されていません。`sys` テナントでは、このビューのクエリ結果は常に空になります。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | パラメータ名 |
| VALUE | longtext | NO | パラメータ値 |
