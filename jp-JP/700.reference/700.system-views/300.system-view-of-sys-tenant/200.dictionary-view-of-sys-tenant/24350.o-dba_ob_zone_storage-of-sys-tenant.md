# oceanbase.DBA_OB_ZONE_STORAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

各ゾーン上の共有ストレージクラスタで設定されたオブジェクトストレージに関する情報を表示します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールドの説明

| フィールド名       | 型          | NULL許容 | 説明                          |
|---------------|---------------|----------------|-------------------------------|
| CREATE_TIME   | datetime      | YES  | レコードの作成日時     |
| MODIFY_TIME   | datetime      | YES  | レコードの変更日時     |
| ZONE          | varchar(128)  | NO   | Zone名     |
| PATH          | varchar(1024) | NO   | オブジェクトストレージが使用するルートパス。このパスは通常、`oss://`、`s3://` などの形式を使用します。     |
| ENDPOINT      | varchar(1024) | NO   | オブジェクトストレージのエンドポイント。    |
| USED_FOR      | varchar(256)  | NO   | オブジェクトストレージの使用者。現在は `ALL` のみサポートしており、clogとdataの使用を意味します。    |
| STORAGE_ID    | bigint(20)    | NO   | オブジェクトストレージパスの番号。同一パスには同じSTORAGE_IDが付与されます     |
| AUTHORIZATION | varchar(1024) | NO   | オブジェクトストレージの認証情報      |
| MAX_IOPS      | bigint(20)    | YES  | オブジェクトストレージの最大IOPS     |
| MAX_BANDWIDTH | bigint(20)    | YES  | オブジェクトストレージの最大帯域幅。単位はバイト     |
| STATE         | varchar(256)  | NO   | オブジェクトストレージの状態：<ul><li>`ADDING`：追加中の状態 </li> <li>`ADDED`：追加済み</li> <li>`DROPPING`：削除中の状態</li> <li>`ROTATING`：AK/SKのローテーション中</li> <li>`ROTATED`：AK/SKのローテーション完了</li></ul>     |
| EXTENSION     | varchar(4096) | YES  | オブジェクトストレージのその他の情報     |
