# oceanbase.DBA_SUBPART_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのサブパーティションテーブルのサブパーティションに関するヒストグラムデータ（各ヒストグラムのエンドポイント）を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER                     | varchar(128)  | NO   | テーブル所有者     |
| TABLE_NAME                | varchar(128)  | NO   | ヒストグラムが属するテーブル名     |
| SUBPARTITION_NAME         | varchar(128)  | NO   | ヒストグラムが属するサブパーティション名     |
| COLUMN_NAME               | varchar(128)  | NO   | ヒストグラムが属する列名     |
| ENDPOINT_NUMBER           | decimal(10,0) | NO   | バケットの累積頻度     |
| ENDPOINT_VALUE            | decimal(10,0) | NO   | バケット端点の正規化値     |
| ENDPOINT_ACTUAL_VALUE     | text          | NO   | バケット端点値     |
| ENDPOINT_ACTUAL_VALUE_RAW | text          | NO   | バケット端点のバイナリ値     |
| ENDPOINT_REPEAT_COUNT     | decimal(10,0) | NO   | バケット端点値の頻度     |

## クエリ例

システムテナントが自身のテナントにあるパーティションテーブル `sales_subpart` のサブパーティションのヒストグラム情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPART_HISTOGRAMS WHERE TABLE_NAME ='sales_subpart';
```
