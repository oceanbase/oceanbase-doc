# oceanbase.DBA_OB_BACKUP_DELETE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナント内で実行されたバックアップクリーンアップタスクの履歴情報を表示します。`sys`テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| JOB_ID | bigint(20) | NO | ジョブID。一意で、値は連番です。 |
| INCARNATION | bigint(20) | NO | アバターID |
| INITIATOR_TENANT_ID | bigint(20) | NO | このJOBを開始したテナントID |
| INITIATOR_JOB_ID | bigint(20) | NO | このJOBを開始したテナントが属するJOBのID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | クリーンアップタスクを実行したテナントの一覧 |
| TYPE | varchar(64) | NO | クリーンアップタイプ。<ul><li>`DELETE OBSOLETE BACKUP`：期限切れによるクリーンアップ</li> <li>`DELETE BACKUP ALL`：パス内のすべてのバックアップまたはアーカイブデータを削除</li> <li>`DELETE BACKUPSET`：指定されたデータバックアップセットをクリーンアップ</li> <li>`DELETE ARCHIVELOG_PIECE`：指定されたログアーカイブピースをクリーンアップ </li></ul> |
| PARAMETER | timestamp(6) | NO | クリーンアップパラメータ。クリーンアップタイプごとの具体的なパラメータ情報を記述します |
| JOB_LEVEL | varchar(64) | NO | ジョブ開始レベル。<ul><li> `USER_TENANT` ：ユーザーテナントが開始したジョブ</li><li> `SYS_TENANT` ：システムテナントが開始したジョブ</li></ul>|
| START_TIMESTAMP | timestamp(6) | NO | ジョブ開始時のテナントの現在時刻 |
| END_TIMESTAMP | timestamp(6) | NO | ジョブ終了時のテナントの現在時刻 |
| STATUS | varchar(64) | NO | ジョブの状態： <ul><li> `INIT` ：ジョブの初期化段階 </li><li> `DOING` ：ジョブの実行段階 </li><li> `CANCELING` ：ジョブがキャンセルされた段階 </li><li> `COMPLETED`：ジョブが正常に実行されました </li><li> `FAILED` ：ジョブの実行に失敗しました </li><li> `CANCELED` ：ジョブが正常にキャンセルされました </li></ul> |
| TASK_COUNT | bigint(20) | YES | backup_set/piece ジョブ数 |
| SUCCESS_TASK_COUNT | bigint(20) | YES | backup_set/piece 実行成功したジョブ数 |
| RESULT | bigint(20) | NO | エラーコード |
| COMMENT | varchar(4096) | YES | ジョブ実行の説明 |
