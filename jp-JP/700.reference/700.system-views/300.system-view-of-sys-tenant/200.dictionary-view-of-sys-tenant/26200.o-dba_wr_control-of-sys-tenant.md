# oceanbase.DBA_WR_CONTROL

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

WR関連の構成情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID <ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul> |
| SNAP_INTERVAL | varchar(64) | NO | スナップショット間の間隔設定。読みやすいように`DD HH:mm:SS`形式で指定します |
| RETENTION | varchar(64) | NO | スナップショット間の保持時間。読みやすいように`DD HH:mm:SS`形式で指定します |
| TOPNSQL | bigint(20) | NO | 保存されるトップNのSQL |

## クエリ例

WR関連の構成情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_CONTROL LIMIT 1\G
```

クエリ結果は次のとおりです：

```shell
*************************** 1. row ***************************
    TENANT_ID: 1
SNAP_INTERVAL: +0 01:00:00
    RETENTION: +7 00:00:00
      TOPNSQL: 30
1 row in set (0.008 sec)
```
