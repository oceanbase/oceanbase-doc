# oceanbase.CDB_OB_SYS_VARIABLES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナントには、すべてのテナントのシステム変数（「_」で始まる隠し変数を含む）情報が表示されます。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| CREATE_TIME | timestamp(6)   | NO   | システム変数の作成時間   |
| MODIFY_TIME | timestamp(6)   | NO   | システム変数の変更時間  |
| TENANT_ID | bigint(20) | NO | テナントID |
| NAME | varchar(128) | NO | システム変数名 |
| VALUE | varchar(65536) | YES | システム変数値 |
| MIN_VALUE | varchar(65536) | NO | 最小値 |
| MAX_VALUE | varchar(65536) | NO | 最大値 |
| SCOPE | varchar(16) | NO | 作用域。値は以下のとおりです。<ul><li>GLOBAL_ONLY：テナントレベルの変数</li><li>SESSION_ONLY：セッションレベルの変数</li><li>GLOBAL &#124; SESSION：テナントレベルとセッションレベルの変数</li></ul> |
| INFO | varchar(4096) | NO | 説明情報 |
| DEFAULT_VALUE | varchar(65536) | YES | システム変数のデフォルト値  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li> <li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li></ul> </main> |
| ISDEFAULT   | varchar(3)   | NO  | デフォルト値かどうか  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li> <li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li></ul> </main>   |

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SYS_VARIABLES  WHERE NAME='ob_query_timeout';
```
