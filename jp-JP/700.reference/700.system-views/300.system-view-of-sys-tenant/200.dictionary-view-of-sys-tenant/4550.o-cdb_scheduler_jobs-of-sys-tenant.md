# oceanbase.CDB_SCHEDULER_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

このビューは、すべてのテナント内のすべてのジョブを表示するために使用されます。

## フィールド説明

|          フィールド名           |       型        | NULL許容 |     説明     |
