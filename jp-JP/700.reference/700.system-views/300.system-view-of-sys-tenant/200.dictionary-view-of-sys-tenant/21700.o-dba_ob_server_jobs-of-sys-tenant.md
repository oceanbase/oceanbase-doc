# oceanbase.DBA_OB_SERVER_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノード関連のタスクを表示します。

## フィールドの説明

|    フィールド名     |      型      | NULL許容 |            説明             |
|-------------|--------------|------------|-----------------------------------------------------|
| JOB_ID      | bigint(20)   | NO         | タスクID                     |
| JOB_TYPE    | varchar(128) | NO         | タスクタイプ。`DELETE_SERVER`はOBServerノード削除タスクを表します。                                                                        |
| JOB_STATUS  | varchar(128) | NO         | タスクのステータス：<ul><li>`INPROGRESS`：進行中 </li><li> `SUCCESS`：成功</li><li>`FAILED`：失敗</li></ul>    |
| RESULT_CODE | bigint(20)   | YES        | タスク終了コード                     |
| PROGRESS    | bigint(20)   | NO         | タスクの進捗率（値の範囲は \[0, 100\]）    |
| START_TIME  | timestamp(6) | YES        | タスク開始時刻                    |
| MODIFY_TIME | timestamp(6) | YES        | 最終のタスク変更時刻                |
| SVR_IP      | varchar(46)  | YES        | 対象サーバーのIPアドレス               |
| SVR_PORT    | bigint(20)   | YES        | 対象サーバーのポート番号                  |
| SQL_TEXT    | longtext     | YES        | 関連するSQL文字列                |
| EXTRA_INFO  | varchar(512) | YES        | 追加情報                     |
| RS_SVR_IP   | varchar(46)  | NO         | Root ServiceサーバーのIPアドレス     |
| RS_SVR_PORT | bigint(20)   | NO         | Root Serviceサーバーのポート番号        |
