# mysql.help_topic

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

他の3つのテーブル `mysql.help_category`、`mysql.help_relation`、`mysql.help_keyword` と連携して、helpコマンドを生成します。

## フィールドの説明

|     **フィールド名**     |     **型**     | **NULL許容** | **説明** |
|------------------|----------------|----------------|--------|
| help_topic_id    | bigint(20)     | NO             | トピックID  |
| name             | varchar(64)    | NO             | トピック名    |
| help_category_id | bigint(20)     | NO             | カテゴリID  |
| description      | varchar(65535) | NO             | 説明     |
| example          | varchar(65535) | NO             | 例       |
| url              | varchar(65535) | NO             | URLアドレス |
