# oceanbase.CDB_OB_BALANCE_JOB_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`CDB_OB_BALANCE_JOB_HISTORY`は、すべてのテナントで実行されたロードバランシングジョブの履歴を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | ------- |
| TENANT_ID               | bigint(20)   | NO  | テナントID <ul><li>1：システムテナントID </li><li>その他の値：ユーザーテナントまたはMetaテナントID </li></ul>|
| JOB_ID                  | bigint(20)   | NO  | ロードバランシングジョブID |
| CREATE_TIME             | timestamp(6) | NO  | ジョブ作成時間 |
| FINISH_TIME             | timestamp(6) | NO  | ジョブ完了時間。成功およびキャンセル時間を含む |
| BALANCE_STRATEGIE        | varchar(64)  | NO  | バランシング戦略名  <ul><li>`LS balance by migrate`：移行によるバランシング  </li><li>`LS balance by alter`：変更ログストリーム属性によるバランシング </li><li>`LS balance by expand`：拡張によるバランシング </li><li>`LS balance by shrink`：縮小によるバランシング </li><li>`partition balance`：パーティションバランシング </li></ul>|
| JOB_TYPE                | varchar(64)  | NO  | ジョブタイプ  <ul><li>`LS_BALANCE`：ログストリームバランシング  </li><li>`PARTITION_BALANCE`：パーティションバランシング </li></ul>|
| TARGET_UNIT_NUM         | bigint(20)   | NO  | 変更対象の各ZoneのUnit数 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドの値はV4.2.5 BP5以降のバージョンから常に<code>NULL</code>に変更されました。</p></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20)   | NO  | 変更対象のPrimary Zone数 |
| STATUS                  | varchar(64)  | NO  | ジョブステータス <ul><li>`DOING`：ジョブ実行中  </li><li>`COMPLETED`：ジョブ実行成功 </li><li>`CANCELING`：ジョブキャンセル中 </li><li>`CANCELED`：ジョブキャンセル </li></ul>|
| COMMENT                 | longtext     | YES | コメント情報 |
| MAX_END_TIME            | timestamp(6) | YES | ロードバランシングジョブの最大終了時間 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.x系では、このフィールドはV4.2.4以降のバージョンから導入されました。V4.3.x系では、このビューはV4.3.4以降のバージョンから導入されました。</p></main>   |
| ZONE_UNIT_NUM_LIST      | varchar(4096) | NO   | テナントの各ZoneのUnit数 <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドはV4.2.5 BP5以降のバージョンから導入されました。</p></main> |
| PARAMETER_LIST          | longtext      | NO   | バランシング関連の構成パラメータ <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5系では、このフィールドはV4.2.5 BP5以降のバージョンから導入されました。</p></main> |

  * [CDB_OB_TRANSFER_PARTITION_TASKS](11300.o-cdb_ob_transfer_partition_tasks-of-sys-tenant.md)
