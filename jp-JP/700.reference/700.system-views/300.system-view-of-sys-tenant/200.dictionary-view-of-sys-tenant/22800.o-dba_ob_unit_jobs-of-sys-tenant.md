# oceanbase.DBA_OB_UNIT_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのユニット関連タスクを表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL値を許容するか** | **説明** |
|-------------|--------------|-----|-----------------------------------------------------|
| JOB_ID      | bigint(20)   | NO  | ジョブID                     |
| JOB_TYPE    | varchar(128) | NO  | ジョブの種類。`MIGRATE_UNIT`は移行ユニットジョブを表します                                                                             |
| JOB_STATUS  | varchar(128) | NO  | ジョブのステータス：<ul><li> `INPROGRESS`：進行中 </li><li>`SUCCESS`：成功 </li><li>`FAILED`：失敗 </li></ul>  |
| RESULT_CODE | bigint(20)   | YES | ジョブ終了コード                     |
| PROGRESS    | bigint(20)   | NO  | ジョブの進捗率（パーセンテージ）。値の範囲は \[0, 100\]    |
| START_TIME  | timestamp(6) | YES | ジョブ開始時間                    |
| MODIFY_TIME | timestamp(6) | YES | 最後のジョブ変更時間                |
| TENANT_ID   | bigint(20)   | YES | テナントID：<ul><li> `NULL`：ユニットはどのテナントにも属していません  </li><li> 有効な値：ユニットが所属するテナントID  </li></ul>   |
| UNIT_ID     | bigint(20)   | YES | ユニットID                   |
| SQL_TEXT    | longtext     | YES | 関連するSQL文字列                |
| EXTRA_INFO  | varchar(512) | YES | 追加情報                     |
| RS_SVR_IP   | varchar(46)  | NO  | Root ServiceサーバーのIPアドレス     |
| RS_SVR_PORT | bigint(20)   | NO  | Root Serviceサーバーのポート番号        |

## クエリ例

システムテナントは、すべてのUnitに関連するタスク情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_JOBS;
```

+--------+--------------+------------+-------------+----------+----------------------------+----------------------------+-----------+---------+----------+------------+----------------+-------------+
