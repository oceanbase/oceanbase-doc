# oceanbase.CDB_OB_SERVER_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_SERVER_SPACE_USAGE` は、各テナントの各ノードにおけるストレージ使用状況の詳細を監視するために使用されます。

## フィールド説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**                               |
|------------|-------------|---------------------|----------------------------------------|
| TENANT_ID   | varchar(128)  | NO   | テナントID    |
| TENANT_NAME | varchar(128)  | NO   | テナント名     |
| SERVER_IP   | varchar(46)   | NO   | テナントUintを含むノードのIPアドレス      |
| SERVER_PORT | bigint(20)    | NO   | テナントUintを含むノードのポート番号     |
| SPACE_TYPE  | varchar(9)    | NO   | 種類は以下のとおりです：<ul><li>Table Data：すべてのメインテーブルのすべてのパーティションのデータ、LOBパーティションを含む</li><li>Index Data：すべてのインデックステーブルのすべてのパーティションのデータ</li><li>Meta Data：すべてのメタデータ </li><li>Tmp Data：一時ファイル </li><li>clog Data：ノード上のclogの合計サイズ </li><li>slog Data：ノード上のslogの合計サイズ。共有ストレージ(SS)モードではこの項目はありません </li></ul><main id="notice" type='explain'><h4>説明</h4><ul><li>シェアードナッシング(Shared-Nothing, SN)モードでは、ノード上のすべてのデータを統計します。 </li><li>共有ストレージ(Shared-Storage, SS)モードでは、ノードのプライベートデータのみを統計します。 </li></ul></main>     |
| DATA_BYTES  | decimal(42,0) | NO   | データコンテンツサイズ、単位はバイト     |
| USAGE_BYTES | decimal(42,0) | NO   | 実際に使用されているディスク容量、単位はバイト     |

## クエリ例

SNモードで、sysテナントが各ノードのストレージ使用状況の詳細を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SERVER_SPACE_USAGE LIMIT 10;
```
