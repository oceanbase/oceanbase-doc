# oceanbase.DBA_INDEX_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、この構成パラメータはV4.3.0バージョンから導入されました。</li> <li>V4.2.x系では、この構成パラメータはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_INDEX_USAGE`は、インデックスの使用状況に関するデータ情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| OBJECT_ID | bigint(20) | NO | インデックステーブルID |
| NAME | varchar(128) | NO | インデックステーブル名 |
| OWNER | varchar(128) | NO | データベース名 |
| TOTAL_ACCESS_COUNT | bigint(20) | NO | 合計アクセス回数 |
| TOTAL_EXEC_COUNT | bigint(20) | NO | 合計実行回数 |
| TOTAL_ROWS_RETURNED | bigint(20) | NO | 合計返されたインデックステーブル行数 |
| BUCKET_0_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用0回 |
| BUCKET_1_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用1回 |
| BUCKET_2_10_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用2回から10回 |
| BUCKET_2_10_ROWS_RETURNED | bigint(20) | NO | インデックステーブル返す2回から10行 |
| BUCKET_11_100_ACCESS_COUNT | bigint(20) | NO | インデックステーブルアクセス11回から100回 |
| BUCKET_11_100_ROWS_RETURNED | bigint(20) | NO | インデックステーブル返す11回から100行 |
| BUCKET_101_1000_ACCESS_COUNT | bigint(20) | NO | インデックステーブルアクセス101回から1000回 |
| BUCKET_101_1000_ROWS_RETURNED | bigint(20) | NO | インデックステーブル返す101回から1000行 |
| BUCKET_1000_PLUS_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用が1000回を超える |
| BUCKET_1000_PLUS_ROWS_RETURNED | bigint(20) | NO | インデックステーブル返す1000行を超える |
| LAST_USED | varchar(128) | NO | インデックステーブルが最後に使用された時間 |

## クエリ例

インデックスの使用状況に関するデータ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_INDEX_USAGE;
```
