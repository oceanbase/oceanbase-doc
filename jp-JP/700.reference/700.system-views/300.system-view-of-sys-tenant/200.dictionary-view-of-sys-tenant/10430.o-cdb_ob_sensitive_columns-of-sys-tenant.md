# oceanbase.CDB_OB_SENSITIVE_COLUMNS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナント内で機密ルールによって保護されているすべての列を表示します。

## フィールドの説明

|        フィールド名         |      型           | NULL許容   |                      説明                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| TENANT_ID         | int(20)    | NO         | テナントID                                           |
| RULE_NAME         | varchar(256)    | NO         | 感度ルール名                                           |
| DATABASE_NAME      | varchar(128)    | NO         | データベース名                                        |
| TABLE_NAME         | varchar(128)    | NO         | テーブル名                                      |
| COLUMN_NAME        | varchar(128)    | NO         | 列名                                                     |

## クエリ例

すべてのテナント内で機密ルールによって保護されているすべての列を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SENSITIVE_COLUMNS;
```

クエリ結果は次のとおりです：

```shell
+-----------+-----------+---------------+------------+-------------+
| TENANT_ID | RULE_NAME | DATABASE_NAME | TABLE_NAME | COLUMN_NAME |
+-----------+-----------+---------------+------------+-------------+
| 1         | r1        | test          | t2         | c           |
| 1         | r1        | test          | t1         | a           |
+-----------+-----------+---------------+------------+-------------+
2 row in set
```
