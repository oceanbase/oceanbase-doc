# oceanbase.CDB_WR_SQL_PLAN

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`CDB_WR_SQL_PLAN`は、WR収集の[GV$OB_SQL_PLAN](../300.performance-view-of-sys-tenant/3000.gv-ob_sql_plan-of-sys-tenant.md)データを表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | -------------- | -------- |
| TENANT_ID          | bigint(20)          | NO   | テナントID     |
| CLUSTER_ID         | bigint(20)          | NO   | クラスタID     |
| SNAP_ID            | bigint(20)          | NO   | スナップショットID     |
| SVR_IP             | varchar(46)         | NO   | ノードIP     |
| SVR_PORT           | bigint(20)          | NO   | ノードPORT     |
| SQL_ID             | varchar(32)         | NO   | SQL文のID     |
| PLAN_HASH          | bigint(20) unsigned | NO   | 実行計画のHASH値     |
| PLAN_ID            | bigint(20)          | NO   | 実行計画ID     |
| ID                 | bigint(20) unsigned | NO   | 演算子ID    |
| DB_ID              | bigint(20)          | NO   | データベースID     |
| GMT_CREATE         | timestamp(6)        | NO   | 生成時間     |
| OPERATOR           | varchar(255)        | NO   | 演算子名     |
| OPTIONS            | varchar(255)        | NO   | オプション     |
| OBJECT_NODE        | varchar(40)         | NO   | 現在の演算子がDBLINK関連である場合、DBlinkの名前を示します     |
| OBJECT_ID          | bigint(20)          | NO   | 演算子が操作するテーブルまたはインデックスオブジェクト番号     |
| OBJECT_OWNER       | varchar(128)        | NO   | オブジェクト所有者     |
| OBJECT_NAME        | varchar(128)        | NO   | オブジェクト名     |
| OBJECT_ALIAS       | varchar(261)        | NO   | ステートメント内のオブジェクトのエイリアス     |
| OBJECT_TYPE        | varchar(20)         | NO   | オブジェクトタイプ     |
| OPTIMIZER          | varchar(4000)       | NO   | インデックス関連情報（例：物理行、論理行、テーブルへの回帰行数、使用される統計情報の種類、統計情報のバージョン番号）     |
| PARENT_ID          | bigint(20)          | NO   | 親演算子のID     |
| DEPTH              | bigint(20)          | NO   | 演算子階層の深さ。ルート演算子の深さは0     |
| POSITION           | bigint(20)          | NO   | 同じ親演算子を持つすべての演算子の中での順序位置     |
| IS_LAST_CHILD      | bigint(20)          | NO   | 現在の論理演算子が親演算子の最後の子ノードであること     |
| COST               | bigint(20)          | NO   | 最適化エンジンによって推定されたコスト     |
| REAL_COST          | bigint(20)          | NO   | 初回実行時の実際のコスト     |
| CARDINALITY        | bigint(20)          | NO   | 最適化エンジンによって推定された出力行数     |
| REAL_CARDINALITY   | bigint(20)          | NO   | 最初の実行時の実際の出力行数    |
| BYTES              | bigint(20)          | NO   | オプティマイザーが現在の演算子データの幅を推定した値     |
| ROWSET             | bigint(20)          | NO   | 現在の演算子のベクトル化サイズ     |
| OTHER_TAG          | varchar(4000)       | NO   | 現在のクエリで使用されたヒント。計画の最初の行にのみ格納されます     |
| PARTITION_START    | varchar(4000)       | NO   | スキャンするパーティション情報     |
| OTHER              | varchar(4000)       | NO   | 最適化情報。例：計画タイプ、Fast Parserのパラメータ化情報、Plan Note、計画がヒットした制約情報    |
| CPU_COST           | bigint(20)          | NO   | 計画が最初に実行されたときの現在の演算子の実際のCPUコスト（実行フィードバック情報）     |
| IO_COST            | bigint(20)          | NO   | 計画が最初に実行されたときの現在の演算子の実際のIOコスト（実行フィードバック情報）     |
| ACCESS_PREDICATES  | varchar(4000)       | NO   | 現在の演算子がアクセスする必要がある式情報     |
| FILTER_PREDICATES  | varchar(4000)       | NO   | 現在の演算子のフィルタ条件     |
| FILTER_PREDICATES  | varchar(4000)       | NO   | 現在の演算子のフィルタ条件     |
| PROJECTION         | varchar(4000)       | NO   | 現在の演算子の出力式情報     |
| SPECIAL_PREDICATES | varchar(4000)       | NO   | 現在の演算子固有の式情報。例：Join Condition、GROUP EXPRS、SORT EXPRSなど     |
| QBLOCK_NAME        | varchar(128)        | NO   | 現在の演算子が属するクエリブロックの名前     |
| REMARKS            | varchar(4000)       | NO   | qb_nameの変更追跡情報     |
| OTHER_XML          | varchar(4000)       | NO   | OUTLINE DATA     |
