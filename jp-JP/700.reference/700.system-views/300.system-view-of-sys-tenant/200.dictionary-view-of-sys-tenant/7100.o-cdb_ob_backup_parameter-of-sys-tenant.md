# oceanbase.CDB_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントで設定されたバックアップパラメータ情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| NAME | varchar(1024) | NO | パラメータ名 |
| VALUE | longtext | NO | パラメータ値 |

## クエリ例

システムテナント内で、すべてのテナントが設定したバックアップパラメータ情報を確認します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_PARAMETER;
```

クエリ結果は次のとおりです：

```shell
+-----------+------------------+------------------------------------------------------------------------------------------------------------------------------+
| TENANT_ID | NAME             | VALUE                                                                                                                        |
+-----------+------------------+------------------------------------------------------------------------------------------------------------------------------+
|      1002 | data_backup_dest | oss://example_path/data?host=cn-heyuan.aliyuncs.com&access_id=******&access_key=******&checksum_type=md5&enable_worm=true    |
+-----------+------------------+------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```
