# information_schema.CHECK_CONSTRAINTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV3.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

`CREATE TABLE` 操作時に、テーブルおよび列に関連する制約情報を記録します。

## フィールドの説明

|        フィールド名        |      型       | NULL許容 |          説明           |
|--------------------|---------------|------------|-----------------------|
| CONSTRAINT_CATALOG | varchar(64) | NO         | 制約が属するカタログ名。この値は常に `def` です |
| CONSTRAINT_SCHEMA  | varchar(128)  | NO         | 制約が属する `SCHEMA` 名     |
| CONSTRAINT_NAME    | varchar(64)  | NO         | 制約名                     |
| CHECK_CLAUSE       | text  | NO         | 制約条件の式を指定します            |

## クエリ例

現在のテナント配下のテーブルと列に関連する制約情報を確認します。

```shell
obclient [infotest]> SELECT * FROM information_schema.CHECK_CONSTRAINTS;
```

クエリ結果は次のとおりです：

```shell
+--------------------+-------------------+-------------------------------+--------------+
| CONSTRAINT_CATALOG | CONSTRAINT_SCHEMA | CONSTRAINT_NAME               | CHECK_CLAUSE |
+--------------------+-------------------+-------------------------------+--------------+
| def                | infotest          | tbl8_OBCHECK_1736909793670468 | (`col1` > 0) |
+--------------------+-------------------+-------------------------------+--------------+
1 row in set
```
