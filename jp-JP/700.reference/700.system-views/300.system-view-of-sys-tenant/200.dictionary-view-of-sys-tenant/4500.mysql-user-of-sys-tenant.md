# mysql.user

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

ユーザーのグローバル権限情報(VIRTUAL_TABLE)を表示します。

## フィールドの説明

|        **フィールド名**        |    **タイプ**     | **NULL値を許容するか** |                      **説明**                       |
|------------------------|---------------|----------------|---------------------------------------------------|
| host                   | varchar(128)  | NO             | ホスト名                                               |
| user                   | varchar(128)  | NO             | ユーザー名                                               |
| password               | varchar(128)  | NO             | ユーザーのパスワード                                              |
| select_priv            | varchar(1)    | NO             | select文を実行できるかどうか                                   |
| insert_priv            | varchar(1)    | NO             | insert文を実行できるかどうか                                   |
| update_priv            | varchar(1)    | NO             | update文を実行できるかどうか                                   |
| delete_priv            | varchar(1)    | NO             | delete文を実行できるかどうか                                   |
| create_priv            | varchar(1)    | NO             | create文を実行できるかどうか                                   |
| drop_priv              | varchar(1)    | NO             | drop文を実行できるかどうか                                     |
| reload_priv            | varchar(1)    | NO             | flush文を実行できるかどうか。現在、このフィールドは使用されていません                          |
| shutdown_priv          | varchar(1)    | NO             | shutdownコマンドを実行できるかどうか。現在、このフィールドは使用されていません                       |
| process_priv           | varchar(1)    | NO             | アクティブなスレッド情報を照会できるかどうか                                       |
| file_priv              | varchar(1)    | NO             | ファイルの読み書き権限があるかどうか。現在、このフィールドは使用されていません                              |
| grant_priv             | varchar(1)    | NO             | 権限付与文を実行できるかどうか                                         |
| references_priv         | varchar(1)    | NO             | 現在使用されていません                                              |
| index_priv             | varchar(1)    | NO             | インデックスを作成できるかどうか                                           |
| alter_priv             | varchar(1)    | NO             | alter文を実行できるか                                    |
| show_db_priv           | varchar(1)    | NO             | `show database`文を実行できるか                          |
| super_priv             | varchar(1)    | NO             | スーパーユーザー権限の文を実行できるか                                       |
| create_tmp_table_priv  | varchar(1)    | NO             | 一時テーブル（未使用）を作成できるか                                     |
| lock_tables_priv       | varchar(1)    | NO             | `lock tables`文を実行できるか。現在このフィールドは使用されていない |
| execute_priv           | varchar(1)    | NO             | ストアドプロシージャを実行できるか。現在このフィールドは使用されていない                               |
| repl_slave_priv        | varchar(1)    | NO             | 現在使用されていない                                              |
| repl_client_priv       | varchar(1)    | NO             | 現在使用されていない                                              |
| create_view_priv       | varchar(1)    | NO             | ビューを作成できるか                                           |
| show_view_priv         | varchar(1)    | NO             | `show create view`文を実行できるか                       |
| create_routine_priv    | varchar(1)    | NO             | ストアドプロシージャを作成できるか。現在このフィールドは使用されていない                               |
| alter_routine_priv     | varchar(1)    | NO             | ストアドプロシージャを変更できるか。現在このフィールドは使用されていない                               |
| create_user_priv       | varchar(1)    | NO             | `create user`文を実行できるか                            |
| event_priv             | varchar(1)    | NO             | イベントを作成、変更、削除できるか。現在このフィールドは使用されていない                         |
| trigger_priv           | varchar(1)    | NO             | triggerを操作する権限があるか。現在このフィールドは使用されていない                      |
| create_tablespace_priv | varchar(1)    | NO             | テーブルスペースを作成できるかどうか。現在このフィールドは使用されていません                        |
| ssl_type               | varchar(10)   | NO             | 現在このフィールドは使用されていません                                         |
| ssl_cipher             | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| x509_issuer            | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| x509_subject           | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| max_questions          | bigint(20)    | NO             | ユーザーが1時間に実行できる最大クエリ数（未使用）                               |
| max_updates            | bigint(20)    | NO             | ユーザーが1時間に実行できる最大更新数。現在このフィールドは使用されていません                          |
| max_connections        | bigint(20)    | NO             | ユーザーが1時間に受信できる最大接続数。現在このフィールドは使用されていません                          |
| max_user_connections   | bigint(20)    | NO             | 同時リクエストの最大接続数。現在このフィールドは使用されていません                              |
| plugin                 | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| authentication_string  | varchar(1024) | NO             | 現在このフィールドは使用されていません                                         |
| password_expired       | varchar(1)    | NO             | ユーザーのパスワードが有効期限切れかどうか。現在このフィールドは使用されていません                                |
| account_locked         | varchar(1)    | NO   | ユーザーがロックされているかどうか    |
| drop_database_link_priv   | varchar(1)    | NO   | データベースリンクを削除できるかどうか     |
| create_database_link_priv | varchar(1)    | NO   | データベースリンクを作成できるかどうか     |
| create_role_priv          | varchar(1)    | NO   | ロールを作成できるかどうか     |
| drop_role_priv            | varchar(1)    | NO   | ロールを削除できるかどうか    |
