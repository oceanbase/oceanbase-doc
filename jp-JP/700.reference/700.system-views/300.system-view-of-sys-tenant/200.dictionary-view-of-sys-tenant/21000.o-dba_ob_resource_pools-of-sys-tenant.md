# oceanbase.DBA_OB_RESOURCE_POOLS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのリソースプール情報を表示します。

## フィールド説明

|     フィールド名     |       型           | NULL許容   |                                                                          説明                                                                           |
|--------------|----------------|------------|-------------------------------------|
| RESOURCE_POOL_ID | bigint(20)    | NO  | リソースプールの一意のID                                                                              |
| NAME             | varchar(128)  | NO  | リソースプール名                                                                                 |
| TENANT_ID        | bigint(20)    | NO  | テナントID ：<ul><li>`NULL`：どのテナントにも属さないことを示す </li><li>有効値：所属するテナントIDを示す </li></ul>   |
| CREATE_TIME      | timestamp(6)  | YES | 作成日時          |
| MODIFY_TIME      | timestamp(6)  | YES | 最終変更日時        |
| UNIT_COUNT       | bigint(20)    | NO  | ユニット数       |
| UNIT_CONFIG_ID   | bigint(20)    | NO  | リソースプールのリソース構成ID   |
| ZONE_LIST        | varchar(8192) | NO  | リソースプールのゾーンリスト  |
| REPLICA_TYPE     | varchar(7)   | NO  | リソースプールがサポートするレプリカタイプ：<ul><li> `FULL`：フル機能タイプのレプリカに限定されず、すべてのレプリカタイプをサポートします</li> <li>`READONLY`：読み取り専用レプリカのみをサポートします</li> <li> `COLUMNSTORE`：カラムストアレプリカのみをサポートします</li></ul>   |
