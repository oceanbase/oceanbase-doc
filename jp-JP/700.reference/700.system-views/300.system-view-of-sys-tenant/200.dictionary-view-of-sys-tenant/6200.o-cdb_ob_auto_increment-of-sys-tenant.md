# oceanbase.CDB_OB_AUTO_INCREMENT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

クラスタ内のすべての自動インクリメント列の情報を表示します。システムテナントのみが参照できます。

## フィールドの説明

| フィールド名              | 型                | NULL許容      | 説明              |
|----------------------|---------------------|----------------|-------------------|
| CREATE_TIME          | datetime(6)         | YES            | 自動インクリメント列の作成日時    |
| MODIFY_TIME          | datetime(6)         | YES            | 自動インクリメント列の変更日時    |
| TENANT_ID            | bigint(20)          | NO             | テナントID          |
| AUTO_INCREMENT_KEY   | bigint(20)          | NO             | 自動インクリメント列が存在するテーブルのKEY  |
| COLUMN_ID            | bigint(20)          | NO             | 列ID              |
| AUTO_INCREMENT_VALUE | bigint(20) unsigned | YES            | 次に使用可能な自動インクリメント値   |
| SYNC_VALUE           | bigint(20) unsigned | NO             | 同期値。`INSERT`ステートメントで明示的に指定された、かつ現在の自動インクリメント列の値より大きい値。 |

## クエリ例

クラスタ内のすべての自動インクリメント列の情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_AUTO_INCREMENT;
```

```shell

| 2025-02-20 14:37:01.322987 | 2025-02-20 14:37:07.197611 |      1002 |             500006 |        16 |              1000001 |          0 |
| 2025-02-20 14:39:18.505040 | 2025-02-20 14:39:18.505040 |      1002 |             500008 |        16 |                    1 |          0 |
+----------------------------+----------------------------+-----------+--------------------+-----------+----------------------+------------+
2 rows in set
```
