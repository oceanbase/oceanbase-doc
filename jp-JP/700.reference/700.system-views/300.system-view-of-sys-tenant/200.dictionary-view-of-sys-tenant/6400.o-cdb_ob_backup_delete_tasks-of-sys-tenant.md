# oceanbase.CDB_OB_BACKUP_DELETE_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントで実行中の`backup_set` / `backup_piece`クリーンアップタスク情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| TASK_ID | bigint(20) | NO | ジョブグループID。一連のジョブを識別するために使用されます |
| INCARNATION | bigint(20) | NO | アバターID |
| JOB_ID | bigint(20) | NO | ジョブID。JOBテーブルに対応します |
| TASK_TYPE | varchar(64) | NO | ジョブタイプ：<ul><li> BACKUP SET ：`backup_set`のクリーンアップ </li><li>BACKUP PIECE ：`backup_piece`のクリーンアップ</li></ul>|
| ID | bigint(20) | NO | ジョブID。backup_set、pieceを含みます |
| ROUND_ID | bigint(20) | NO | pieceが所属するdest_round_id。backup_setのクリーンアップの場合、ROUND_IDは0です |
| DEST_ID | bigint(20) | NO | バックアップ宛先のDEST_ID |
| START_TIMESTAMP | timestamp(6) | NO | ジョブ開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | ジョブ終了時間 |
| STATUS | varchar(64) | NO | ジョブステータス：<ul><li>`INIT`：ジョブ初期化段階</li><li>`DOING`：ジョブ実行段階</li><li>`CANCELING`：ジョブキャンセル段階</li><li>`COMPLETED`：ジョブ実行成功 </li><li>`FAILED`：ジョブ実行失敗 </li><li>`CANCELED`：ジョブが正常にキャンセルされました</li></ul> |
| TOTAL_LS_COUNT | bigint(20) | YES | ジョブ内のログストリーム数 |
| FINISH_LS_COUNT | bigint(20) | YES | 成功したログストリームジョブ数 |
| RESULT | bigint(20) | YES | エラーコード |
| COMMENT | varchar(4096) | YES | コメント |
| PATH | varchar(1024) | NO | backup_set/backup_pieceが所属するバックアップ宛先 |
