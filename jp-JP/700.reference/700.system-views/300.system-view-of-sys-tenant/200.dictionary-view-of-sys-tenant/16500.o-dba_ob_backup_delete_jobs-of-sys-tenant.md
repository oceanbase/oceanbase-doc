# oceanbase.DBA_OB_BACKUP_DELETE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

本テナントのバックアップクリーンアップジョブタスクの実行進捗状況を表示します。`sys`テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| JOB_ID | bigint(20) | NO | ジョブID、単調増加 |
| INCARNATION | bigint(20) | NO | 分身ID |
| INITIATOR_TENANT_ID | bigint(20) | NO | このJOBを開始したテナントID |
| INITIATOR_JOB_ID | bigint(20) | NO | このJOBを開始したテナントが属するJOB_ID |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | クリーンアップタスクを実行したテナントの一覧 |
| TYPE | varchar(64) | NO | クリーンアップタイプ：<ul><li>`DELETE OBSOLETE BACKUP`：期限切れクリーンアップ</li> <li>`DELETE BACKUP ALL`：パス内のすべてのバックアップまたはアーカイブデータを削除</li> <li>`DELETE BACKUPSET`：指定されたデータバックアップセットをクリーンアップ</li> <li>`DELETE ARCHIVELOG_PIECE`：指定されたログアーカイブPieceをクリーンアップ</li> </ul> |
| PARAMETER | timestamp(6) | NO | クリーンアップパラメータ。異なるクリーンアップタイプの具体的なパラメータ情報を記述します |
| JOB_LEVEL | varchar(64) | NO | ジョブ開始レベル：<ul><li>`USER_TENANT`：ユーザーテナントが開始したタスク</li><li>`SYS_TENANT`：システムテナントが開始したタスク</li></ul>  |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時のテナントの現在時刻 |
| END_TIMESTAMP | timestamp(6) | NO | タスク終了時のテナントの現在時刻 |
| STATUS | varchar(64) | NO | タスク状態：<ul><li>`INIT`：タスクの初期化段階 </li><li>`DOING`：タスクの実行段階 </li><li>`CANCELING`：タスクがキャンセルされた段階 </li><li>`COMPLETED`：タスクが正常に実行された </li><li>`FAILED`：タスクの実行に失敗した </li><li>`CANCELED`：タスクが正常にキャンセルされた </li></ul> |
| TASK_COUNT | bigint(20) | YES | backup_set/pieceタスク数 |
| SUCCESS_TASK_COUNT | bigint(20) | YES | backup_set/pieceで正常に実行されたタスク数 |
| RESULT | bigint(20) | NO | エラーコード |
| COMMENT | varchar(4096) | YES | タスク実行の説明 |
