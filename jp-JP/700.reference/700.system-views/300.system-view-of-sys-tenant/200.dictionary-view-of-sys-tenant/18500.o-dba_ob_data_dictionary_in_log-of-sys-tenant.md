# oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

データディクショナリがシステムログストリーム内に配置される位置範囲を記録し、CDCがデータディクショナリを利用しやすくします。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | データディクショナリ生成時の対応テナントのSNAPSHOT SCN |
| REPORT_TIME | timestamp(6) | YES | データディクショナリ生成完了後、内部テーブルに報告された時間（単位：マイクロ秒） |
| START_LSN | bigint(20) unsigned | NO | テナントの1号ログストリームに永続化された最初のログのLSN |
| END_LSN | bigint(20) unsigned | NO | テナントの1号ログストリームに永続化された最後のログのLSN |

## クエリ例

本テナントのデータディクショナリがシステムログストリーム内に配置される位置範囲を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DATA_DICTIONARY_IN_LOG;
```

クエリ結果は次のとおりです：

```shell
+---------------------+----------------------------+-----------+-----------+
| SNAPSHOT_SCN        | REPORT_TIME                | START_LSN | END_LSN   |
+---------------------+----------------------------+-----------+-----------+
| 1723084121964378000 | 2024-08-08 10:28:42.014127 |  10713062 |  10713062 |
| 1723170522400303000 | 2024-08-09 10:28:42.439283 | 139661239 | 139661239 |
+---------------------+----------------------------+-----------+-----------+
2 rows in set
```
