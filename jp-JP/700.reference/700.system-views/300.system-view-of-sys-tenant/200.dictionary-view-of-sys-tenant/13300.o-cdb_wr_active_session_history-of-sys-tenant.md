# oceanbase.CDB_WR_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_WR_ACTIVE_SESSION_HISTORY` は、すべてのテナントの永続化されたASHデータを表示するために使用されます。
