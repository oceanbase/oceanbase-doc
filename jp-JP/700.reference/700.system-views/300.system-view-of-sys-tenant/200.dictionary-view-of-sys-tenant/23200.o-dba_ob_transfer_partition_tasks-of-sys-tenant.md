# oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TRANSFER_PARTITION_TASKS`は、現在のテナント内で処理中のパーティション転送タスクを表示します。

システムテナントのユーザーテーブルに対してパーティション転送操作を実行することはサポートされていないため、このビューのクエリ結果は空になります。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | bigint(20)   | NO   |  パーティション転送タスクの一意の識別子   |
| CREATE_TIME      | timestamp(6) | YES  |  作成日時   |
| MODIFY_TIME      | timestamp(6) | YES  |  情報の更新日時   |
| TABLE_ID         | bigint(20)   | NO   |  転送対象のパーティションが属するテーブルID   |
| OBJECT_ID        | bigint(20)   | NO   |  転送対象のパーティションの`OBJECT_ID`   |
| DEST_LS          | bigint(20)   | NO   |  宛先ログストリーム   |
| BALANCE_JOB_ID   | bigint(20)   | NO   |  タスク実行時に関連付けられたロードバランシングジョブID   |
| TRANSFER_TASK_ID | bigint(20)   | NO   |  タスク実行時に関連付けられた転送タスクID   |
| STATUS           | varchar(64)  | NO   |  タスク状態：<ul><li>WAITING：タスクが待機中で、実行は開始されていません</li><li>INIT：タスクのスケジューリングが開始されました</li><li>DOING：タスクが転送処理を開始しました</li></ul>   |
| COMMENT          | longtext     | YES  |  コメント情報   |
