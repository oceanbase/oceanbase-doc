# oceanbase.DBA_WR_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_WR_ACTIVE_SESSION_HISTORY` は、このテナントに永続化されたASHデータを表示します。
