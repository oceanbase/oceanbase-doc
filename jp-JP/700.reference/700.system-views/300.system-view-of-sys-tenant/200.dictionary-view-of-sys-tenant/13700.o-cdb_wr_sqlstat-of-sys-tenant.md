# oceanbase.CDB_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.5バージョンから導入されました。</li> <li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `CDB_WR_SQLSTAT` は、すべてのテナントで実行されたSQLの基本的なパフォーマンス統計データを表示するために使用されます。各SQL文は1行となります（つまり、各 `SQL_ID` + `Plan_Hash` の一意の値が1行となります）。そのうち、`_DELTA` を含む列は、前回のWRスナップショットから現在時点までの統計値の増分を示しています。
