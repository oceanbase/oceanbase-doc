# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下のログストリームの状態と復元進捗を表示します。

## フィールドの説明

| フィールド名       | 型                | NULL許容        | 説明               |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO | ログストリームID |
| STATUS        | varchar(100)        | NO | ログストリームの状態。<ul><li>`CREATING`：ログストリーム作成中</li><li>`CREATED`：ログストリーム作成完了</li><li>`NORMAL`：ログストリームがサービスを提供可能</li><li>`DROPPING`：ログストリームが削除されようとしており、ログストリーム上のTabletを移行する必要があります</li><li>`TENANT DROPPING`：ログストリームが存在するテナントが削除されようとしており、ログストリームも削除する必要があります</li><li>`WAIT OFFLINE`：ログストリームデータの削除が完了し、GCを待機中</li><li>`CREATE ABORT`：ログストリームの作成に失敗したか、作成不要と判断されたため、削除されようとしています</li></ul> |
| PRIMARY_ZONE  | longtext            | YES| ログストリームの選出優先度 |
| UNIT_GROUP_ID | bigint(20)          | NO | UnitグループID <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2バージョンから導入されました。このバージョンでは、このフィールドの値は常に0です。</li><li>V4.2.5系では、このフィールドはV4.2.5 BP5バージョンから導入されました。このバージョンでも、このフィールドの値は常に0です。</li></ul></main>  |
| LS_GROUP_ID   | bigint(20)          | NO | ログストリームグループIDです。システムログストリーム（1番ログストリーム）とブロードキャストログストリームでは、このフィールドは0と表示され、ログストリームが特定のログストリームグループに属さないことを示します |
| CREATE_SCN    | bigint(20) unsigned | NO | ログストリームでのログ書き込み開始時点 |
| DROP_SCN      | bigint(20) unsigned | NO | ログストリーム削除時点、すなわち全ユーザーデータ終了時点です。ログストリームが削除された場合、このフィールドには削除時のSCNが記録されます。削除されていない場合、このフィールドはNULLです。 |
| SYNC_SCN      | bigint(20) unsigned | NO | ログストリームの同期時点で、ログストリームが最後に正常に同期されたトランザクションのSCNを示します |
| READABLE_SCN  | bigint(20) unsigned | NO | ログストリームの読み取り可能ポイントで、ログストリームが読み取り可能な最小SCNを示します |
| FLAG          | varchar(2048)       | NO | ログストリームのフラグ。<ul><li>NULL：通常のログストリーム</li><li>`DUPLICATE`：ユーザーテナントのブロードキャストログストリームで、レプリケーションテーブルがこのログストリーム上に作成されています </li> <li>`BLOCK_TABLET_IN`：このログストリーム上にTabletを作成できないことを示します</li> <li>`DUPLICATE\|BLOCK_TABLET_IN`：ブロードキャストログストリームでは現在Tabletの作成が許可されていません</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>  |
| UNIT_LIST     | varchar(1216)       | NO   | ユーザーログストリームが分散されているUnitのリストです。システムログストリームとブロードキャストログストリームは、具体的な位置を指定しない場合、空になります。 <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2バージョンから導入されました。</li> <li>V4.2.5系では、このフィールドはV4.2.5 BP5バージョンから導入されました。</li></ul></main>  |

## クエリ例

システムテナントが自身のログストリームの状態と復元進捗を確認します。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```

クエリ結果は次のとおりです：

```shell
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
| LS_ID | STATUS | PRIMARY_ZONE | UNIT_GROUP_ID | LS_GROUP_ID | CREATE_SCN | DROP_SCN | SYNC_SCN | READABLE_SCN | FLAG | UNIT_LIST |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
|     1 | NORMAL | zone1        |             0 |           0 |       NULL |     NULL |     NULL |         NULL |      |           |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
1 row in set
```
