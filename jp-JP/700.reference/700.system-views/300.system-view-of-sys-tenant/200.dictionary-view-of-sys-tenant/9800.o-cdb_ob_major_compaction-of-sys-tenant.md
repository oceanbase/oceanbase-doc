# oceanbase.CDB_OB_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナントには、すべてのテナントのメジャーコンパクションのグローバル情報が表示されます。

## フィールドの説明

|           フィールド名           |     タイプ      | NULLを許容するか |        説明         |
|--------------------------|-------------|------------|---------------------------------------------|
| TENANT_ID                | bigint(20)  | NO         | テナントID             |
| FROZEN_SCN           | bigint(20) unsigned  | NO         | 最後のコンパクションのバージョン番号           |
| FROZEN_TIME              | timestamp(6)  | NO         | 最後のコンパクション開始時間（FROZEN_SCNを読み取り可能な形式で表示）           |
| GLOBAL_BROADCAST_SCN | bigint(20) unsigned  | NO         | グローバルブロードキャストのコンパクションバージョン         |
| LAST_SCN             | bigint(20) unsigned  | NO         | 前回完了したコンパクションのバージョン      |
| LAST_FINISH_TIME         | timestamp(6)  | NO         | 前回のコンパクション終了時間         |
| START_TIME               | timestamp(6)  | NO         | コンパクション開始時間            |
| STATUS                   | varchar(10) | NO         | <ul><li>`IDLE`：コンパクション中ではありません</li><li> `COMPACTION`：コンパクション中 </li><li>`CHECKSUM`：チェックサムの検証 </li></ul>  |
| IS_ERROR                 | varchar(3)  | NO         | <ul><li>`YES`：コンパクションプロセスにエラーが発生しました </li><li>`NO`：コンパクションプロセスでエラーは報告されませんでした  </li></ul> |
| IS_SUSPENDED             | varchar(3)  | NO         | <ul><li>`YES`：コンパクションが一時停止状態 </li><li> `NO`：コンパクションは一時停止されていません  </li></ul> |
| INFO                     | varchar(14) | NO         | コンパクション情報を表示します。例：コンパクション失敗の理由  |
