# oceanbase.DBA_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TRANSFER_PARTITION_TASK_HISTORY`は、現在のテナントで実行されたパーティション移動タスクの履歴を表示します。システムテナントのユーザーテーブルに対してパーティション移動操作をサポートしていないため、このビューのクエリ結果は空になります。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TASK_ID          | bigint(20)   | NO   |  Transfer Partitionタスクの一意の識別子   |
| CREATE_TIME      | timestamp(6) | NO   |  作成時間   |
| FINISH_TIME      | timestamp(6) | NO   |  タスク完了時間。成功およびキャンセルを含む   |
| TABLE_ID         | bigint(20)   | NO   |  Transferのパーティションが存在するテーブルID   |
| OBJECT_ID        | bigint(20)   | NO   |  Transferのパーティションの`OBJECT_ID`   |
| DEST_LS          | bigint(20)   | NO   |  目的地ログストリーム   |
| BALANCE_JOB_ID   | bigint(20)   | NO   |  タスク実行時に関連付けられるロードバランシングジョブID   |
| TRANSFER_TASK_ID | bigint(20)   | NO   |  タスク実行時に関連付けられるTransferタスクID   |
| STATUS           | varchar(64)  | NO   |  タスク状態：<ul><li>COMPLETED：タスク実行成功</li><li>FAILED：タスク失敗</li></ul>   |
| COMMENT          | longtext     | YES  |  コメント情報   |
