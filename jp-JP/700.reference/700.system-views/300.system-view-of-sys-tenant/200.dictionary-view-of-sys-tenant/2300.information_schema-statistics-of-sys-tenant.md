# information_schema.STATISTICS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `information_schema.STATISTICS` は、テーブルとインデックスの情報を記録するために使用されます。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| ------- | ---- | -------------- | ---- |
| TABLE_CATALOG | varchar(512) | NO | 定数 (def) |
| TABLE_SCHEMA  | varchar(128) | NO | データベース名 |
| TABLE_NAME    | varchar(256) | NO | テーブル名 |
| NON_UNIQUE    | bigint(20)   | NO | 唯一インデックスかどうか |
| INDEX_SCHEMA  | varchar(128) | NO | データベース名 |
| INDEX_NAME    | varchar(256) | NO | インデックス名 |
| SEQ_IN_INDEX  | bigint(20) unsigned | NO | インデックス番号 |
| COLUMN_NAME   | varchar(128) | NO | 列名 |
| COLLATION     | varchar(1)   | NO | 照合方法 |
| CARDINALITY   | bigint(0)    | NO | デフォルト値は `NULL` |
| SUB_PART      | bigint(20)   | NO | 列が部分的にのみインデックスに含まれる場合、インデックスされた文字数。列全体がインデックスに含まれる場合はNULL |
| PACKED        | varchar(10)  | NO | デフォルト値は `NULL` |
| NULLABLE      | varchar(3)   | NO | NULLを許容するかどうか |
| INDEX_TYPE    | varchar(16)  | NO | インデックスで使用されるデータ構造タイプ |
| COMMENT       | varchar(16)  | NO | インデックスのコメントまたは説明情報<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.1バージョンから、NULLではなく実際のインデックス状態の表示に変更されました。</p></main> |
| INDEX_COMMENT | text         | NO | インデックスコメント |
| IS_VISIBLE    | varchar(3)   | NO | インデックスが表示されるかどうか |
| EXPRESSION    | varbinary(262144) | NO | MySQLとの互換性のためにのみ使用されます。値は `NULL` です <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main>  |

## クエリ例

```shell
obclient [none]> SELECT * FROM information_schema.STATISTICS limit 1 \G
```
