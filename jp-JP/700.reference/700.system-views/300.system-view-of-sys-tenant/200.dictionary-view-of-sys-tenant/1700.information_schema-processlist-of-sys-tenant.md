# information_schema.PROCESSLIST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V1.4バージョンから導入されました。</p>
</main>

## 機能の概要

実行中のスレッドの情報を提供します。

## フィールドの説明

| **フィールド名** |       **型**        | **NULL値を許容するか** |    **説明**    |
|----------|---------------------|----------------|--------------|
| ID       | bigint(20) unsigned | NO             | 接続識別子<br>V4.2.x系では：<ul><li>V4.2.5 BP5以前のバージョン：<br>すべての接続方式（ダイレクトモード/ODPモード）において、このフィールドはServer Session IDを表します。</li><li>V4.2.5 BP5以降のバージョン：<ul><li>ダイレクトモードでは：<br>このフィールドはServer Session IDを表します。</li> <li>ODPモードでは：</li><ul><li>ODPの構成パラメータ <code>client_session_id_version = 2</code> の場合、このフィールドはClient Session IDを表します。 </li> <li><code>client_session_id_version = 1</code> の場合、このフィールドはServer Session IDを表します。</li></ul></ul></li></ul>        |
| USER     | varchar(32)         | NO             | ユーザー名          |
| HOST     | varchar(128)        | NO             | クライアントホスト名      |
| DB       | varchar(128)        | YES            | データベース名        |
| COMMAND  | varchar(4096)       | NO             | スレッドが実行しているコマンドのタイプ    |
| TIME     | bigint(20)          | NO             | 現在のステータスでスレッドが継続している時間、単位は秒です |
| STATE    | varchar(128)        | YES            | スレッドが実行しているタスクの識別子 |
| INFO     | varchar(262143)     | YES            | 現在のスレッドが実行しているステートメント  |

## クエリ例

システムテナントがすべての実行中のスレッド情報をクエリします。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```

