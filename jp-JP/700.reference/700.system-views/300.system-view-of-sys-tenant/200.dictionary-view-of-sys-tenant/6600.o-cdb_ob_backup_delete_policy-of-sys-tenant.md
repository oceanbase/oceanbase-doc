# oceanbase.CDB_OB_BACKUP_DELETE_POLICY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントで設定されている、期限切れクリーンアップ/自動クリーンアップのポリシーを表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| POLICY_NAME | varchar(256) | NO | クリーンアップポリシー名。<ul><li>`default`：テナントの現在の`DATA_BACKUP_DEST`および`LOG_ARCHIVE_DEST`パラメータに設定されたバックアップを自動的にクリーンアップします。</li> <li>`log_only`：テナントの現在の`LOG_ARCHIVE_DEST`パラメータで設定されたアーカイブパス内のログを自動的にクリーンアップします。</li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | 復元可能時間ウィンドウ。デフォルト値：0 |

## クエリ例

システムテナントがすべてのテナントのクリーンアップポリシーを確認する。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_POLICY;
```

クエリ結果は次のとおりです：

```shell
+-----------+-------------+-----------------+
| TENANT_ID | POLICY_NAME | RECOVERY_WINDOW |
+-----------+-------------+-----------------+
|      1002 | default     | 7d              |
+-----------+-------------+-----------------+
1 row in set
```
