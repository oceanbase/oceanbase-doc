# oceanbase.CDB_OB_DATABASE_PRIVILEGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナントのユーザーが持つデータベース権限を表示します。

## フィールドの説明

| フィールド名                     | フィールドタイプ          | NULL許容 | 説明 |
|-------------------|--------------|------|-----|
| TENANT_ID         | bigint(20)   | NO   |  テナントID   |
| USER_ID           | bigint(20)   | NO   |  ユーザーID   |
| USERNAME          | varchar(128) | NO   |  ユーザー名  |
| DATABASE_NAME     | varchar(128) | NO   |  データベース名   |
| GMT_CREATE        | timestamp(6) | NO   |  作成日時   |
| GMT_MODIFIED      | timestamp(6) | NO   |  変更日時   |
| PRIV_ALTER        | varchar(3)   | NO   |  データベースまたはテーブルを変更する権限の有無   |
| PRIV_CREATE       | varchar(3)   | NO   |  データベースまたはテーブルを作成する権限の有無   |
| PRIV_DELETE       | varchar(3)   | NO   |  データベースまたはテーブルのレコードを削除する権限の有無   |
| PRIV_DROP         | varchar(3)   | NO   |  データベースまたはテーブルを削除する権限の有無   |
| PRIV_GRANT_OPTION | varchar(3)   | NO   |  権限を付与する権限の有無   |
| PRIV_INSERT       | varchar(3)   | NO   |  レコードを挿入する権限の有無   |
| PRIV_UPDATE       | varchar(3)   | NO   |  レコードを更新する権限の有無   |
| PRIV_SELECT       | varchar(3)   | NO   |  レコードをクエリする権限の有無   |
| PRIV_INDEX        | varchar(3)   | NO   |  インデックスの作成と削除の権限の有無   |
| PRIV_CREATE_VIEW  | varchar(3)   | NO   |  ビューを作成する権限の有無   |
| PRIV_SHOW_VIEW    | varchar(3)   | NO   |  ビューを参照する権限の有無   |
| PRIV_EXECUTE        | varchar(3) | NO   |  ProcedureとFunctionを実行する権限の有無 |
| PRIV_ALTER_ROUTINE  | varchar(3) | NO   |  ProcedureとFunctionを変更または削除する権限の有無 |
| PRIV_CREATE_ROUTINE | varchar(3) | NO   |  ProcedureとFunctionを作成する権限の有無 |
| PRIV_REFERENCES     | varchar(3) | NO   |  外部キーを作成する権限の有無 |
| PRIV_TRIGGER        | varchar(3) | NO   |  トリガー操作を有効化する権限の有無 |
| PRIV_LOCK_TABLE     | varchar(3) | NO   |  テーブルにロックをかける権限の有無 |
| PRIV_EVENT          | varchar(3) | NO   |  イベントの作成と管理の権限の有無 |

obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_DATABASE_PRIVILEGE WHERE TENANT_ID=1002;
