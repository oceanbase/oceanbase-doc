# information_schema.VIEW_TABLE_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー定義で使用されているテーブルとビューの情報を表示します。

## フィールドの説明

|     フィールド名      |      型        | NULL許容   |               説明                |
|---------------|--------------|------------|---------------------------------|
| VIEW_CATALOG  | varchar(64)   | NO         | ビューが属するディレクトリ名                       |
| VIEW_SCHEMA   | varchar(128) | NO         | ビューが属するSCHEMA名                     |
| VIEW_NAME     | varchar(256) | NO         | ビュー名                              |
| TABLE_SCHEMA  | varchar(128) | NO         | ビュー定義で使用されているテーブルまたはビューが属するSCHEMA名       |
| TABLE_NAME    | varchar(256) | NO         | ビュー定義で使用されているテーブルまたはビューの名前                 |
| TABLE_CATALOG | varchar(64)   | NO         | ビュー定義で使用されているテーブルまたはビューが属するディレクトリ名。この値は常に`def`です |

## クエリ例

ビュー`view1`で使用されているテーブルとビューの情報を確認します。

```shell
obclient [infotest]> SELECT * FROM information_schema.VIEW_TABLE_USAGE WHERE VIEW_NAME='view1';
```

クエリ結果は次のとおりです：

```shell
+--------------+-------------+-----------+--------------+------------+---------------+
| VIEW_CATALOG | VIEW_SCHEMA | VIEW_NAME | TABLE_SCHEMA | TABLE_NAME | TABLE_CATALOG |
+--------------+-------------+-----------+--------------+------------+---------------+
| def          | infotest    | view1     | infotest     | tbl1       | def           |
+--------------+-------------+-----------+--------------+------------+---------------+
1 row in set
```
