# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントの基本情報を表示します。

* システムテナントがこのビューをクエリする場合、システムテナント、ユーザーが作成したテナント（ユーザーテナント）、およびMetaテナントを含むすべてのテナントの情報が表示されます。`TENANT_TYPE` 列に基づいてテナントタイプを区別できます。
* 通常のテナントがこのビューをクエリする場合、そのテナント自身の情報のみが表示されます。

## フィールド説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)| NO | テナントID：<ul><li> 1：システムテナントID  </li><li> その他の値：ユーザーテナントまたはMetaテナントID </li></ul>|
| TENANT_NAME| varchar(128)| NO | テナント名 |
| TENANT_TYPE| varchar(4)| NO | <ul><li> `SYS`：システムテナント  </li><li> `USER`：ユーザーテナント </li><li>`META`：Metaテナント </li></ul> |
| CREATE_TIME| timestamp(6)| YES | テナント作成時刻|
| MODIFY_TIME| timestamp(6)| YES | 情報更新時刻|

| LOCALITY| varchar(4096)| NO | テナントレプリカ配置情報|
| PREVIOUS_LOCALITY| varchar(4096)| NO | 変更前のLocality情報：<ul><li> この値が有効な場合、Localityの変更が完了していないことを示します。  </li><li>NULLはLocalityの変更が行われていないことを示します。  </li></ul> |
| COMPATIBILITY_MODE| varchar(6)| NO | <ul><li>`MYSQL`：MySQL互換モード </li><li>`ORACLE`：Oracle互換モード</li></ul> |

| IN_RECYCLEBIN| varchar(3)| NO | ごみ箱にあるかどうか：<ul><li>  `YES`：ごみ箱にあります </li><li> `NO`：ごみ箱にありません </li></ul>|
| LOCKED| varchar(3)| NO | ロックされているかどうか：<ul><li>  `YES`：ロック状態 </li><li>`NO`：ロックされていない状態  </li></ul>`ALTER TENANT xxx LOCK&#124;UNLOCK`コマンドでこのフィールドの値を変更できます|
| TENANT_ROLE| varchar(100) | NO | クラスタロール：<ul><li>`PRIMARY`：プライマリテナント   </li><li>  `STANDBY`：スタンバイテナント  </li><li> `RESTORE`：テナントが復元中 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| SWITCHOVER_STATUS| varchar(100)| NO | スイッチオーバー状態：<ul><li>`NORMAL`：通常状態、スイッチオーバー中ではありません   </li><li>`PREPARE SWITCHING TO PRIMARY`：スタンバイからプライマリへの切り替え準備中 </li><li> `SWITCHING TO PRIMARY`：スタンバイからプライマリへの切り替え中</li><li>`PREPARE FLASHBACK`：Flashback準備状態 </li><li> `FLASHBACK`：Flashback状態 </li><li>`PREPARE SWITCHING TO STANDBY`：プライマリからスタンバイへの切り替え準備中 </li><li> `SWITCHING TO STANDBY`：プライマリからスタンバイへの切り替え中 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| SWITCHOVER_EPOCH| bigint(20)| NO | スイッチオーバー/ファイルオーバーの一意の識別子 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| SYNC_SCN| bigint(20) unsigned| NO | 現在のテナントが同期したスナップションバージョン。システムテナントとMetaテナントには意味がなく、NULLを返します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| REPLAYABLE_SCN| bigint(20) unsigned| NO | 現在のテナントで再生可能なスナップションバージョン。システムテナントとMetaテナントには意味がなく、NULLを返します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| READABLE_SCN| bigint(20) unsigned| NO | 現在のテナントで読み取り可能なスナップションバージョン。システムテナントとMetaテナントには意味がなく、NULLを返します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| RECOVERY_UNTIL_SCN| bigint(20) unsigned| NO | 現在のテナントの最大復元ポイント。システムテナントとMetaテナントには意味がなく、NULLを返します。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| LOG_MODE| varchar(100)| NO | アーカイブモード：<ul><li>  `ARCHIVELOG`：アーカイブモードが有効化中 </li><li> `NOARCHIVELOG`：アーカイブモードが無効 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| ARBITRATION_SERVICE_STATUS |  varchar(64)   | NO | テナントのアービトレーションサービスの状態。値は以下のとおりです：<ul><li>`ENABLING`：有効化中   </li><li> `ENABLED`：有効化完了</li><li> `DISABLING`：無効化中</li><li>`DISABLED`：無効化完了 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| UNIT_NUM | bigint(20) | NO | テナントの各ゾーンにおける`UNIT_NUM`の最小値 <main id="notice" type='explain'><h4>説明</h4><ul><li>このフィールドはV4.2.0から導入されました。</li> <li>V4.4.x系では、このフィールドはV4.4.2から、「テナントの各ゾーンの<code>UNIT_NUM</code>値」から「テナントの各ゾーンの<code>UNIT_NUM</code>の最小値」に変更されました。</li> <li>V4.2.5では、V4.2.5 BP5（含まれない）以前のバージョンでは、このフィールドはテナントの各ゾーンの<code>UNIT_NUM</code>値を表し、V4.2.5 BP5以降のバージョンでは、このフィールドはテナントの各ゾーンの<code>UNIT_NUM</code>の最小値を表します。</li></ul></main> |
| ZONE_UNIT_NUM_LIST | varchar(65536) | NO | テナント内の各ゾーンにおけるUnit数を表示します。<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
| COMPATIBLE | varchar(65536) | NO | 互換性バージョン<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main> |
| MAX_LS_ID  | bigint(20)     | NO | テナントが存在したことのある最大のログストリームIDです。システムテナントとMetaテナントは1、ユーザーテナントは実際のサイズです。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main> |
| RESTORE_DATA_MODE  | varchar(128)     | NO | テナントデータ復元モードです。値は以下のとおりです：<ul><li>`NORMAL`：テナントが通常に作成されたか、フルデータ復元によって復元されたことを示します</li><li>`REMOTE`はテナントが高速復元されたことを示し、データはリモート参照状態にあります</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.2バージョンから導入されました。</p></main> |
| FLASHBACK_LOG_SCN | bigint(20) | NO | テナントの直近のログトリミングのポイントです。Failover後、このポイントまでバックアップテナントのログをトリミングする運用コマンドを使用して、元のプライマリテナントのバックアップテナントを新しいプライマリテナントに接続できます。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.1バージョンから導入されました。</p></main> |
| COMMENT                    | varchar(4096)       | NO   | コメント情報     |
