# oceanbase.DBA_OB_TENANTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントの基本情報を表示します。

* システムテナントがこのビューをクエリする場合、システムテナント、ユーザーが作成したテナント（ユーザーテナント）、およびMetaテナントを含むすべてのテナントの情報が表示されます。ユーザーは `TENANT_TYPE` 列に基づいてテナントタイプを区別できます。
* 通常のテナントがこのビューをクエリする場合、そのテナント自身の情報のみが表示されます。

## フィールド説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20)| NO | テナントID：<ul><li> 1：システムテナントID  </li><li> その他の値：ユーザーテナントまたはMetaテナントID </li></ul>|
| TENANT_NAME| varchar(128)| NO | テナント名 |
| TENANT_TYPE| varchar(4)| NO | <ul><li> `SYS`：システムテナント  </li><li> `USER`：ユーザーテナント </li><li>`META`：Metaテナント </li></ul> |
| CREATE_TIME| timestamp(6)| YES | テナント作成時刻|
| MODIFY_TIME| timestamp(6)| YES | 情報更新時刻|
| PRIMARY_ZONE| varchar(128)| YES | テナントPrimary Zone|
| LOCALITY| varchar(4096)| NO | テナントレプリカ配置情報|
| PREVIOUS_LOCALITY| varchar(4096)| NO | 変更前のLocality情報：<ul><li> この値が有効な場合、Locality変更が完了していないことを示します  </li><li>NULLはLocality変更が行われていないことを示します  </li></ul> |
| COMPATIBILITY_MODE| varchar(6)| NO | <ul><li>`MYSQL`：MySQL互換モード </li><li>`ORACLE`：Oracle互換モード</li></ul> |
| STATUS| varchar(64)| NO | 現在のテナント状態：<ul><li>`NORMAL`：正常なテナント </li><li>`RESTORE`：物理復元中のテナント  </li><li>`CREATING`：作成中のテナント </li><li> `DROPPING`：削除中のテナント </li></ul>|
| IN_RECYCLEBIN| varchar(3)| NO | ごみ箱にあるかどうか：<ul><li>  `YES`：ごみ箱にあります </li><li> `NO`：ごみ箱にありません </li></ul>|
| LOCKED| varchar(3)| NO | ロック状態かどうか：<ul><li>  `YES`：ロック状態 </li><li>`NO`：ロックされていない状態  </li></ul>`ALTER TENANT xxx LOCK&#124;UNLOCK`コマンドでこのフィールドの値を変更できます|
| TENANT_ROLE| varchar(100) | NO | クラスタロール：<ul><li>`PRIMARY`：プライマリテナント   </li><li>  `STANDBY`：スタンバイテナント  </li><li> `RESTORE`：テナントが復元中 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| SWITCHOVER_STATUS| varchar(100)| NO | SWITCHOVER状態：<ul><li>`NORMAL`：正常状態、切り替え中ではありません   </li><li>`PREPARE SWITCHING TO PRIMARY`：スタンバイからプライマリへの切り替え準備中 </li><li> `SWITCHING TO PRIMARY`：スタンバイからプライマリへの切り替え中</li><li>`PREPARE FLASHBACK`：Flashback準備状態 </li><li> `FLASHBACK`：Flashback状態 </li><li>`PREPARE SWITCHING TO STANDBY`：プライマリからスタンバイへの切り替え準備中 </li><li> `SWITCHING TO STANDBY`：プライマリからスタンバイへの切り替え中 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| SWITCHOVER_EPOCH| bigint(20)| NO | SWITCHOVER/FAILOVERの一意の識別子 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| SYNC_SCN| bigint(20) unsigned| NO | 現在のテナントが同期した最新のスナップショットバージョン。システムテナントとMetaテナントには意味がなく、NULLが表示されます <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| REPLAYABLE_SCN| bigint(20) unsigned| NO | 現在のテナントで再現可能な最新のスナップショットバージョン。システムテナントとMetaテナントには意味がなく、NULLが表示されます <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| READABLE_SCN| bigint(20) unsigned| NO | 現在のテナントで読み取り可能な最新のスナップショットバージョン。システムテナントとMetaテナントには意味がなく、NULLが表示されます <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| RECOVERY_UNTIL_SCN| bigint(20) unsigned| NO | 現在のテナントで復元可能な最新のポイント。システムテナントとMetaテナントには意味がなく、NULLが表示されます <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| LOG_MODE| varchar(100)| NO | アーカイブモード：<ul><li>  `ARCHIVELOG`：アーカイブモードが有効な状態 </li><li> `NOARCHIVELOG`：アーカイブモードが無効な状態 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| ARBITRATION_SERVICE_STATUS |  varchar(64)   | NO | テナントのアービトレーションサービスの状態。取り得る値は以下の通りです：<ul><li>`ENABLING`：有効化中   </li><li> `ENABLED`：有効化完了</li><li> `DISABLING`：無効化中</li><li>`DISABLED`：無効化完了 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.1.0から導入されました。</p></main> |
| UNIT_NUM | bigint(20) | NO | テナントの各Zoneの`UNIT_NUM`の最小値 <main id="notice" type='explain'><h4>説明</h4><ul><li>このフィールドはV4.2.0から導入されました。</li> <li>V4.4.x系では、このフィールドはV4.4.2から、「テナントの各Zoneの<code>UNIT_NUM</code>値」から「テナントの各Zoneの<code>UNIT_NUM</code>の最小値」に変更されました。</li> <li>V4.2.5では、V4.2.5 BP5（含まず）以前のバージョンでは、このフィールドはテナントの各Zoneの<code>UNIT_NUM</code>値を表し、V4.2.5 BP5以降のバージョンでは、このフィールドはテナントの各Zoneの<code>UNIT_NUM</code>の最小値を表します。</li></ul></main> |
| ZONE_UNIT_NUM_LIST | varchar(65536) | NO | テナント内の各Zone内のUnit数を示します <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.4.x系では、このフィールドはV4.4.2から導入されました。</li> <li>V4.2.5では、このフィールドはV4.2.5 BP5から導入されました。</li></ul></main> |
| COMPATIBLE | varchar(65536) | NO | 互換性バージョン<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main> |
| MAX_LS_ID  | bigint(20)     | NO | テナントが存在したことのある最大のログストリームID。システムテナントとMetaテナントは1、ユーザーテナントは実際のサイズ。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main> |
| RESTORE_DATA_MODE  | varchar(128)     | NO | テナントデータ復元モード。取り得る値は以下の通りです：<ul><li>`NORMAL`：テナントが正常に作成されたか、フルデータ復元によって復元されたことを示します</li><li>`REMOTE`：テナントが高速復元され、データがリモート参照状態にあることを示します</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.2から導入されました。</p></main> |
| FLASHBACK_LOG_SCN | bigint(20) | NO | テナントで最後に実行されたログトリミングのポイント。Failover後、スタンバイテナントのログを指定したポイントまでトリミングする運用コマンドを使用して、元のプライマリテナントのスタンバイテナントを新しいプライマリテナントに接続できます。<main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.4.1から導入されました。</p></main> |
| COMMENT                    | varchar(4096)       | NO   | コメント情報     |
| PROTECTION_MODE            | varchar(128)        | NO   | 現在のテナントの保護モード。取り得る値は以下の通りです：<ul><li>`MAXIMUM PERFORMANCE`：最大パフォーマンス</li> <li>`MAXIMUM PROTECTION`：最大保護</li> <li>`MAXIMUM AVAILABILITY`：最大可用性</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2では、このフィールドはV4.4.2 BP1から導入されました。</p></main> |
| PROTECTION_LEVEL           | varchar(128)        | NO   | 現在のテナントの保護レベル。値は以下のとおりです。<ul><li>`MAXIMUM PERFORMANCE`：最大パフォーマンス</li> <li>`MAXIMUM PROTECTION`：最大保護</li> <li>`MAXIMUM AVAILABILITY`：最大可用性</li> <li>`RESYNCHRONIZATION`：ログ追従状態</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.4.2バージョンでは、このフィールドはV4.4.2 BP1バージョンから導入されました。</p></main>  |
