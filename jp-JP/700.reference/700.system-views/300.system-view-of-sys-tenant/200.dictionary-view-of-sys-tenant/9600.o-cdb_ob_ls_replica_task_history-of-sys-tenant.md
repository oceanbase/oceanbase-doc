# oceanbase.CDB_OB_LS_REPLICA_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`CDB_OB_LS_REPLICA_TASK_HISTORY`は、すべてのテナントの災害復旧タスクの実行履歴を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | &#124;bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| TASK_TYPE | varchar(64) | NO | タスクの種類。値は以下のとおりです：<ul><li>`MIGRATE REPLICA`：レプリカの移行</li><li>`ADD REPLICA`：レプリカの追加</li><li>`TYPE TRANSFORM`：レプリカの種類変換</li><li>`REMOVE PAXOS REPLICA`：Paxosメンバーのレプリカの削除</li><li>`REMOVE NON PAXOS REPLICA`：非Paxosメンバーのレプリカの削除</li><li>`MODIFY PAXOS REPLICA NUMBER`：法定レプリカ数の変更</li></ul>|
| TASK_ID | varchar(200) | NO | タスクID |
| TASK_STATUS | varchar(2048) | YES | タスクの状態。値は以下のとおりです：<ul><li>`INPROGRESS`：スケジューリング中</li><li>`COMPLETED`：タスク完了</li><li>`CANCELED`：タスクキャンセル</li></ul>|
| PRIORITY | varchar(5) | NO | タスクの優先順位。値は以下のとおりです：<ul><li>`LOW`：低優先順位のタスク</li><li>`HIGH`：高優先順位のタスク</li></ul>|
| TARGET_REPLICA_SVR_IP | varchar(46) | YES | ターゲットレプリカが存在するマシンのIPアドレス |
| TARGET_REPLICA_SVR_PORT | bigint(20) | YES | ターゲットレプリカが存在するマシンのポート番号 |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20) | YES | ログストリームのターゲット法定Paxosレプリカ数 |
| TARGET_REPLICA_TYPE | varchar(16) | YES | ターゲットレプリカの種類 |
| SOURCE_REPLICA_SVR_IP | varchar(46) | YES | ソースレプリカが存在するマシンのIPアドレス |
| SOURCE_REPLICA_SVR_PORT | bigint(20) | YES | ソースレプリカが存在するマシンのポート番号 |
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20) | YES | ログストリームの元の法定Paxosレプリカ数 |
| SOURCE_REPLICA_TYPE | varchar(16) | YES | ソースレプリカの種類 |
| DATA_SOURCE_SVR_IP | varchar(46) | YES | データソースのIPアドレス |
| DATA_SOURCE_SVR_PORT | bigint(20) | YES | データソースのポート番号 |
| IS_MANUAL | varchar(6) | NO | フォールトトレランスタスクの出所。値は以下のとおりです：<ul><li>`TRUE`：手動運用コマンドによってトリガーされたフォールトトレランスタスクを示します</li><li>`FALSE`：デフォルト値で、RS層のフォールトトレランスによって自動的に生成されたフォールトトレランスタスクを示します</li></ul>|
| TASK_EXEC_SVR_IP | varchar(46) | YES | タスク実行マシンのIPアドレス |
| TASK_EXEC_SVR_PORT | bigint(20) | YES | タスク実行マシンのポート番号 |
| CREATE_TIME | datetime | NO | タスクの生成時間 |
| START_TIME | datetime | NO | タスクのスケジューリング時間 |
| MODIFY_TIME | datetime | NO | タスクの状態更新時間 |
| FINISH_TIME | datetime | NO | タスク終了時間 |
| EXECUTE_RESULT | varchar(2048) | YES | タスクの実行結果 |
| COMMENT | varchar(2048) | YES | タスク生成理由の備考 |
