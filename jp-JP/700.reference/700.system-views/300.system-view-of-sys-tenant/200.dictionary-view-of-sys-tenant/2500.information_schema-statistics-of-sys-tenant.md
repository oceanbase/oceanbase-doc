# information_schema.STATISTICS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

テーブルインデックス情報を記録します。

## フィールドの説明

| フィールド名 | タイプ | NULL値を許容するか | 説明 |
| --- | --- | --- | --- |
| TABLE_CATALOG | varchar(512) | NO | 定数（def） |
| TABLE_SCHEMA | varchar(128) | NO | データベース名 |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| NON_UNIQUE | bigint(20) | NO | 唯一インデックスであるか |
| INDEX_SCHEMA | varchar(128) | NO | データベース名 |
| INDEX_NAME | varchar(256) | NO | インデックスタイプ |
| SEQ_IN_INDEX | bigint(20) unsigned | NO | インデックス番号 |
| COLUMN_NAME | varchar(128) | NO | 列名 |
| COLLATION | varchar(1) | NO | 比較方法 |
| CARDINALITY | bigint(0) | NO | このフィールドはデフォルトでNULLです |
| SUB_PART | bigint(20) | NO | 列が部分的にのみインデックスに含まれている場合、インデックスに含まれる文字の数を示します。列全体がインデックスに含まれている場合はNULLです |
| PACKED | varchar(10) | NO | このフィールドはデフォルトでNULLです |
| NULLABLE | varchar(3) | NO | NULL値を許容するか |
| INDEX_TYPE | varchar(16) | NO | インデックスが使用するデータ構造のタイプ |
| COMMENT | varchar(16) | NO | コメント |
| INDEX_COMMENT | text | NO | インデックスコメント |
| IS_VISIBLE | varchar(3) | NO | インデックスが可視化されているか |
| EXPRESSION    | varbinary(262144) | NO | MySQLとの互換性のためにのみ使用されます。値は`NULL`です。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.1バージョンから導入されました。</p></main>  |

## クエリ例

1. インデックス付きテーブル `tbl1` を作成します。

   ```shell
   obclient [test]> CREATE TABLE tbl1(id INT,name VARCHAR(18),date DATE,PRIMARY KEY (id),INDEX tbl1_idx1 (date));
   ```

2. テーブル `tbl1` のインデックス情報を照会します。

   ```shell
   obclient [test]> SELECT * FROM information_schema.STATISTICS WHERE TABLE_NAME='tbl1';
   ```
