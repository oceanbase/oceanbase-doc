# oceanbase.DBA_OB_RSRC_IO_DIRECTIVES

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>このビューはV4.1.0バージョンから導入されました。</li>
<li>現在のバージョンでは、テナントのResource Managerにおける各種リソース設定パラメータ情報を確認するには、ビュー<a href="21420.o-dba_ob_rsrc_directives-of-sys-tenant.md">DBA_OB_RSRC_DIRECTIVES</a>の使用を推奨します。</li></ul>
</main>

## 機能の概要

Resource Manager内のI/Oリソース設定状況を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| PLAN | varchar(128) | NO | 指令が属するリソースプラン名 |
| GROUP_OR_SUBPLAN | varchar(128) | NO | 指令が制御するリソースグループ名 |
| COMMENTS    | varchar(2000) | YES | リソースプランの備考 |
| MIN_IOPS    | bigint(20) | NO | I/O競合発生時にリザーブされるリソースグループのIOPSリソース。すべてのリソースグループで指定された`MIN_IOPS`の合計は100を超えてはならない。デフォルト値は`0`です。 |
| MAX_IOPS    | bigint(20) | NO | リソースグループが使用可能な最大IOPSリソース。すべてのリソースグループで指定された`MAX_IOPS`の合計は100を超えても構いません。デフォルト値は`100`です。 |
| WEIGHT_IOPS | bigint(20) | NO | I/Oリソース競合が発生した場合のIOPSの重み値。すべてのリソースグループで指定された`WEIGHT_IOPS`の合計は100を超えても構いません。`MIN_IOPS`、`MAX_IOPS`の設定を満たす前提で、I/Oリソースは重みの正規化値に応じて割り当てられます。デフォルト値は`0`です。 |

## クエリ例

システムテナントが自身のテナントのResource Manager内のI/Oリソース設定状況を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RSRC_IO_DIRECTIVES;
```

クエリ結果は次のとおりです：

```shell
+---------+------------------+----------+----------+----------+-------------+
| PLAN    | GROUP_OR_SUBPLAN | COMMENTS | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS |
+---------+------------------+----------+----------+----------+-------------+
| daytime | batch_group      |          |       40 |       80 |          70 |
+---------+------------------+----------+----------+----------+-------------+
1 row in set
```
