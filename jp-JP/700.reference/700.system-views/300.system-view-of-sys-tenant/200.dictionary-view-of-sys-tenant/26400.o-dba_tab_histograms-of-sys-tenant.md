# oceanbase.DBA_TAB_HISTOGRAMS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下にあるすべてのテーブルの列のヒストグラムを表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| OWNER                     | varchar(128)  | NO   | ヒストグラム所有者ユーザー     |
| TABLE_NAME                | varchar(128)  | NO   | ヒストグラム対象テーブル名     |
| COLUMN_NAME               | varchar(128)  | NO   | ヒストグラム対象列名     |
| ENDPOINT_NUMBER           | decimal(10,0) | NO   | バケット累積頻度     |
| ENDPOINT_VALUE            | decimal(10,0) | NO   | バケット端点正規化値     |
| ENDPOINT_ACTUAL_VALUE     | text          | NO   | バケット端点値     |
| ENDPOINT_ACTUAL_VALUE_RAW | text          | NO   | バケット端点バイナリ値     |
| ENDPOINT_REPEAT_COUNT     | decimal(10,0) | NO   | バケット端点値の頻度     |
| SCOPE                     | varchar(7)    | NO   | ヒストグラム範囲     |

## クエリ例

システムテナント内で、自身のテナントにあるテーブル`t_subpart`のテーブルレベルヒストグラム関連情報を確認します。

obclient [oceanbase]> SELECT * FROM oceanbase.DBA_TAB_HISTOGRAMS WHERE TABLE_NAME='t_subpart';
