# oceanbase.DBA_OB_BACKUP_DELETE_TASKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントで実行中の`backup_set` / `backup_piece`クリーンアップタスク情報を表示します。`sys`テナントとMetaテナントはバックアップクリーンアップをサポートしていません。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | タスクグループID。一連のタスクを識別するために使用されます。 |
| INCARNATION | bigint(20) | NO | 分身ID |
| JOB_ID | bigint(20) | NO | ジョブID。JOBテーブルに対応します。 |
| TASK_TYPE | varchar(64) | NO | タスクタイプ：<ul><li> BACKUP SET ：`backup_set`のクリーンアップ </li><li>BACKUP PIECE ：`backup_piece`のクリーンアップ</li></ul> |
| ID | bigint(20) | NO | タスクID。backup_setおよびpieceを含みます。 |
| ROUND_ID | bigint(20) | NO | pieceが所属するdest_round_id。backup_setのクリーンアップの場合、ROUND_IDは0です。 |
| DEST_ID | bigint(20) | NO | バックアップ宛先のDEST_ID |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | タスク終了時間 |
| STATUS | varchar(64) | NO | タスクステータス：<ul><li>`INIT`：タスク初期化段階</li><li>`DOING`：タスク実行段階</li><li>`CANCELING`：タスクがキャンセルされた段階</li><li>`COMPLETED`：タスク実行成功 </li><li>`FAILED`：タスク実行失敗 </li><li>`CANCELED`：タスクが正常にキャンセルされました</li></ul> |
| TOTAL_LS_COUNT | bigint(20) | YES | タスク内のログストリーム数 |
| FINISH_LS_COUNT | bigint(20) | YES | 成功したログストリームタスク数 |
| RESULT | bigint(20) | YES | エラーコード |
| COMMENT | varchar(4096) | YES | コメント |
| PATH | varchar(1024) | NO | backup_set/backup_pieceが所属するバックアップ宛先 |
