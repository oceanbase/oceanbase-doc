# information_schema.ENGINES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ストレージエンジンに関する情報を記録します。

## フィールドの説明

|   **フィールド名**   |    **型**     | **NULL許容** |     **説明**      |
|--------------|---------------|----------------|-----------------|
| ENGINE       | varchar(64)   | NO             | エンジンタイプ            |
| SUPPORT      | varchar(8)    | NO             | 現在のストレージエンジンをサポートするかどうか      |
| COMMENT      | varchar(80)   | NO             | コメント              |
| TRANSACTIONS | varchar(3)    | NO             | トランザクション関連情報          |
| XA           | varchar(3)    | NO             | 分散トランザクション XA 関連情報   |
| SAVEPOINTS   | varchar(3)    | NO             | Savepoints 関連情報 |

## クエリ例

ストレージエンジンに関する情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM information_schema.ENGINES;
```

クエリ結果は次のとおりです：

```shell
+--------+---------+-----------------------+--------------+------+------------+
| ENGINE | SUPPORT | COMMENT               | TRANSACTIONS | XA   | SAVEPOINTS |
+--------+---------+-----------------------+--------------+------+------------+
| InnoDB | YES     | Supports transactions | YES          | NO   | YES        |
+--------+---------+-----------------------+--------------+------+------------+
1 row in set
```
