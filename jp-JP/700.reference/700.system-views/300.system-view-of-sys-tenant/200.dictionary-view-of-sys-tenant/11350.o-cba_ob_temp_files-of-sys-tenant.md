# oceanbase.CDB_OB_TEMP_FILES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.3.3バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_TEMP_FILES` は、一時ファイルに関する情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID        | bigint(20)   | NO   | テナントID     |
| SVR_IP           | varchar(46)  | NO   | OBServerのIPアドレス     |
| SVR_PORT         | bigint(20)   | NO   | OBServerのポート番号     |
| FILE_ID          | bigint(20)   | NO   | 一時ファイルのFile ID     |
| TRACE_ID         | varchar(64)  | NO   | 一時ファイルを開いたときの現在の環境のTRACE ID    |
| DIR_ID           | bigint(20)   | NO   | 一時ファイルに対応するディレクトリID    |
| BYTES            | bigint(20)   | NO   | 一時ファイルのデータサイズ、単位はバイト     |
| START_OFFSET     | bigint(20)   | NO   | 一時ファイルの開始バイトオフセット、有効データの開始位置   |
| TOTAL_WRITES     | bigint(20)   | NO   | 一時ファイルへの書き込みリクエスト総数    |
| UNALIGNED_WRITES | bigint(20)   | NO   | 一時ファイルへの非アライメント書き込みリクエスト総数    |
| TOTAL_READS      | bigint(20)   | NO   | 一時ファイルからの読み取りリクエスト総数     |
| UNALIGNED_READS  | bigint(20)   | NO   | 一時ファイルからの非アライメント読み取りリクエスト総数    |
| TOTAL_READ_BYTES | bigint(20)   | NO   | 一時ファイルからの読み取りリクエストの総サイズ、単位はバイト    |
| LAST_ACCESS_TIME | timestamp(6) | NO   | 一時ファイルの最終アクセス時間    |
| LAST_MODIFY_TIME | timestamp(6) | NO   | 一時ファイルの最終変更時間    |
| BIRTH_TIME       | timestamp(6) | NO   | 一時ファイルの作成時間    |
