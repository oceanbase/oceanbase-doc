# oceanbase.DBA_SCHEDULER_JOB_RUN_DETAILS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このビューはV4.3.3バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.4バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `DBA_SCHEDULER_JOB_RUN_DETAILS` は、現在のテナント内のすべてのスケジューラージョブの情報を表示します。

## フィールド説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | -------- |
| LOG_ID            | decimal(20,0)                    | NO   | このフィールドは現在サポートされていません。デフォルト値は0です。|
| LOG_DATE          | datetime                         | NO   | ログエントリの日付。|
| OWNER             | varchar(128)                     | NO   | ジョブの所有者。|
| JOB_NAME          | varchar(128)                     | NO   | ジョブ名。|
| JOB_SUBNAME       | varchar(128)                     | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| STATUS            | varchar(128)                     | NO   | ジョブのステータス。|
| CODE              | bigint(20)                       | YES  | ジョブ実行時に発生したエラーのコード番号。 |
| REQ_START_DATE    | datetime                         | NO   | ジョブの予定開始時刻。|
| ACTUAL_START_DATE | datetime                         | NO   | ジョブの実際の開始時刻。|
| RUN_DURATION      | decimal(20,0)                    | NO   | ジョブの実行時間。|
| INSTANCE_ID       | varchar(128)                     | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| SESSION_ID        | decimal(20,0)                    | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| SLAVE_PID         | varchar(128)                     | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| CPU_USED          | decimal(20,0)                    | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| CREDENTIAL_OWNER  | varchar(128)                     | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| CREDENTIAL_NAME   | varchar(128)                     | NO   | このフィールドは現在サポートされていません。デフォルト値はNULLです。|
| DESTINATION_OWNER | varchar(128)                     | NO   | 現在、クロスデータベースジョブはサポートされていません。デフォルト値はNULLです。|
| DESTINATION       | varchar(128)                     | NO   | 現在、クロスデータベースジョブはサポートされていません。デフォルト値はNULLです。|
| MESSAGE           | varchar(4000)                    | NO   | ジョブ実行時に返されたエラーメッセージ。 |
| JOB               | bigint(20)                       | NO   | プログラムジョブ名。 |
| TIME              | timestamp(6)                     | NO   | ジョブ実行ログの記録時間。単位は秒。 |
| JOB_CLASS         | varchar(30)                      | YES  | プログラムジョブの種類。 |
| GMT_CREATE        | timestamp(6)                     | YES  | プログラムジョブの作成時間。単位は秒。 |
| GMT_MODIFIED      | timestamp(6)                     | YES  | プログラムジョブによる変更時刻。単位は秒。 |
