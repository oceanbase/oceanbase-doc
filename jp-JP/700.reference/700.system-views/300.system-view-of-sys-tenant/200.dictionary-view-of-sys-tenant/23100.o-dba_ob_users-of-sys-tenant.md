# oceanbase.DBA_OB_USERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のユーザーとロールの情報を表示します。

## フィールドの説明

| フィールド名                   | フィールドタイプ      | NULLを許容するか | 説明 |
|---------------------------|---------------|------|----|
| USER_NAME                 | varchar(128)  | NO   | ユーザー名またはロール名   |
| HOST                      | varchar(128)  | NO   | サーバー名   |
| PASSWD                    | varchar(128)  | NO   | ユーザーまたはロールのパスワード   |
| INFO                      | varchar(4096) | NO   | ユーザーまたはロールの情報   |
| PRIV_ALTER                | varchar(3)    | NO   | データベースまたはテーブルを変更する権限があるか   |
| PRIV_CREATE               | varchar(3)    | NO   | データベースまたはテーブルを作成する権限があるか   |
| PRIV_DELETE               | varchar(3)    | NO   | データベースまたはテーブルのレコードを削除する権限があるか   |
| PRIV_DROP                 | varchar(3)    | NO   | データベースまたはテーブルを削除する権限があるか   |
| PRIV_GRANT_OPTION         | varchar(3)    | NO   | 権限を再付与する権限があるか   |
| PRIV_INSERT               | varchar(3)    | NO   | レコードを挿入する権限があるか   |
| PRIV_UPDATE               | varchar(3)    | NO   | レコードを更新する権限があるか   |
| PRIV_SELECT               | varchar(3)    | NO   | レコードをクエリする権限があるか   |
| PRIV_INDEX                | varchar(3)    | NO   | インデックスを設定する権限があるか   |
| PRIV_CREATE_VIEW          | varchar(3)    | NO   | ビューを作成する権限があるか   |
| PRIV_SHOW_VIEW            | varchar(3)    | NO   | ビューを表示する権限があるか   |
| PRIV_SHOW_DB              | varchar(3)    | NO   | すべてのデータベースを表示する権限があるか   |
| PRIV_CREATE_USER          | varchar(3)    | NO   | ユーザーを作成する権限があるか   |
| PRIV_SUPER                | varchar(3)    | NO   | スーパーユーザー権限があるか   |
| IS_LOCKED                 | varchar(3)    | NO   | ロックされているか   |
| PRIV_PROCESS              | varchar(3)    | NO   | すべてのスレッドを表示する権限があるか   |
| PRIV_CREATE_SYNONYM       | varchar(3)    | NO   | 同義語を作成する権限があるか   |
| SSL_TYPE                  | bigint(20)    | NO   | SSL標準暗号化セキュリティタイプをサポート   |
| SSL_cipher                | varchar(1024) | NO   | SSL標準暗号化セキュリティパスワードをサポート   |
| X509_ISSUER               | varchar(1024) | NO   | X.509発行者名   |
| X509_SUBJECT              | varchar(1024) | NO   | X.509証書のサブジェクト名   |
| TYPE                      | varchar(4)    | NO   | タイプ：<ul><li>`USER`：ユーザー</li> <li>`ROLE`：ロール</li></ul>   |
| PROFILE_ID                | bigint(20)    | NO   |  プロファイルID   |
| PASSWORD_LAST_CHANGED     | timestamp(6)  | YES  |  最後にパスワードが変更された時間   |
| PRIV_FILE                 | varchar(3)    | NO   |  ファイルの閲覧権限があるか   |
| PRIV_ALTER_TENANT         | varchar(3)    | NO   |  テナント情報の変更権限があるか   |
| PRIV_ALTER_SYSTEM         | varchar(3)    | NO   |  サーバー構成パラメータの変更権限があるか   |
| PRIV_CREATE_RESOURCE_POOL | varchar(3)    | NO   |  リソースプールの作成、変更、削除権限があるか   |
| PRIV_CREATE_RESOURCE_UNIT | varchar(3)    | NO   |  リソースユニットの作成、変更、削除権限があるか   |
| MAX_CONNECTIONS           | bigint(20)    | NO   |  最大接続数   |
| MAX_USER_CONNECTIONS      | bigint(20)    | NO   |  最大テナント接続数   |
| PRIV_REPL_SLAVE           | varchar(3)    | NO   |  スレーブサーバー管理。テナントはレプリケーションスレーブサーバーとプライマリサーバーの場所を指定できます。   |
| PRIV_REPL_CLIENT          | varchar(3)    | NO   |  プライマリサーバー管理。テナントはレプリケーションデータベース環境のメンテナンスに使用されるバイナリログファイルを読み取ることができます。このユーザーはプライマリシステム上にあり、ホストとクライアント間の通信に有利です。   |
| PRIV_DROP_DATABASE_LINK   | varchar(3)    | NO   |  データベースリンクの削除権限があるか     |
| PRIV_CREATE_DATABASE_LINK | varchar(3)    | NO   |  データベースリンクの作成権限があるか     |
| PRIV_EXECUTE              | varchar(3)    | NO   |  ProcedureとFunctionの実行権限があるか    |
| PRIV_ALTER_ROUTINE        | varchar(3)    | NO   |  ProcedureとFunctionの変更および削除権限があるか      |
| PRIV_CREATE_ROUTINE       | varchar(3)    | NO   |  ProcedureとFunctionの作成権限があるか     |
| PRIV_CREATE_TABLESPACE    | varchar(3)    | NO   |  テーブルスペースの作成、変更、削除権限があるか     |
| PRIV_SHUTDOWN             | varchar(3)    | NO   |  mysqladmin shutdownコマンドの実行権限があるか     |
| PRIV_RELOAD               | varchar(3)    | NO   |  Flush操作の実行権限があるか     |
| PRIV_REFERENCES           | varchar(3)    | NO   |  外部キーの作成権限があるか     |
| PRIV_CREATE_ROLE          | varchar(3)    | NO   |  ロールの作成権限があるか     |
| PRIV_DROP_ROLE            | varchar(3)    | NO   |  ロールの削除権限があるか     |
| PRIV_TRIGGER              | varchar(3)    | NO   |  トリガー操作の有効化権限があるか     |
| PRIV_LOCK_TABLE           | varchar(3)    | NO   |  テーブルのロック権限があるか     |
| PRIV_ENCRYPT              | varchar(3)    | NO   | ENHANCED_AES_ENCRYPT関数を呼び出すことができるか     |
| PRIV_DECRYPT              | varchar(3)    | NO   | ENHANCED_AES_DECRYPT関数を呼び出すことができるか     |
| PRIV_EVENT                | varchar(3)    | NO   | イベントの作成および管理権限があるか     |
