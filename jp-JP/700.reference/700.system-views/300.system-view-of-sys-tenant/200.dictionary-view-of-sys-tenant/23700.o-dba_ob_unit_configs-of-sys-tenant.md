# oceanbase.DBA_OB_UNIT_CONFIGS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのユニット構成情報を表示します。

## フィールド説明

|      フィールド名       |      型      | NULL許容   |        説明        |
|-----------------|--------------|------------|------------------|
| UNIT_CONFIG_ID  | bigint(20)   | NO         | Unit構成ID       |
| NAME            | varchar(128) | NO         | Unit構成名        |
| CREATE_TIME         | timestamp(6)       | YES         | Unit構成作成日時         |
| MODIFY_TIME         | timestamp(6)       | YES         | 情報更新日時         |
| MAX_CPU         | double       | NO         | CPU構成上限         |
| MIN_CPU         | double       | NO         | CPU構成下限         |
| MEMORY_SIZE      | bigint(20)   | NO         | メモリ構成、単位はバイト     |
| LOG_DISK_SIZE      | bigint(20)   | NO         | ログディスク構成、単位はバイト     |
| DATA_DISK_SIZE        | bigint(20)   | NO         |  Unitが使用可能なローカルキャッシュサイズ、単位はバイト、共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。共有なし(Shared-Nothing, SN)モードでは、このフィールドの値は`NULL`となり、定義されていないことを示します。他のテナントのディスク容量を競合的に使用することが許可されます。 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>   |
| MAX_IOPS        | bigint(20)   | NO         | ディスクIOPS構成上限     |
| MIN_IOPS        | bigint(20)   | NO         | ディスクIOPS構成下限     |
| IOPS_WEIGHT   | bigint(20)   | NO         | IOPS重み   |
| MAX_NET_BANDWIDTH     | bigint(20)   | NO         |  Unitの最大ネットワーク帯域幅、単位はバイト  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>    |
| NET_BANDWIDTH_WEIGHT  | bigint(20)   | NO         |  Unitのネットワーク帯域幅の重み値 <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.4バージョンから導入されました。</p></main>     |
