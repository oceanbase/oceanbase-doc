# oceanbase.DBA_OB_ARCHIVELOG

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内の各パスにおけるログアーカイブの状態を表示します。`sys` テナントとMetaテナントは物理バックアップをサポートしていません。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | パス識別子 |
| ROUND_ID | bigint(20) | NO | バックアップのラウンド番号を示す |
| INCARNATION | bigint(20) | NO | Flashback Database後の化身の回数を示す |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するために使用される |
| STATUS | varchar(64) | NO | アーカイブ状態：<ul><li>`PREPARE`：アーカイブ開始ポイント `START_SCN` の準備中 </li> <li>`BEGINNING`：ログアーカイブが開始されています  </li> <li>`DOING`：ログアーカイブが実行中です </li><li> `INTERRUPTED`：ログアーカイブが中断されました。人為的な介入が必要です </li><li>`STOP`：ログアーカイブが停止しました  </li><li>`STOPPING`：ログアーカイブが停止しています  </li><li>`SUSPENDING`：ログアーカイブが一時停止されています  </li><li>`SUSPEND`：ログアーカイブが一時停止されました  </li></ul>  |
| START_SCN | bigint(20) unsigned | NO | バックアップ開始時刻 |
| START_SCN_DISPLAY | datetime(6) | NO | START_SCNを時間単位に変換した表示 |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | 現在のアーカイブポイント |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | CHECKPOINT_SCNを時間単位に変換した表示 |
| COMPATIBLE | bigint(20) | NO | 互換性バージョン |
| BASE_PIECE_ID | bigint(20) | NO | そのラウンドの最初のPIECE ID |
| USED_PIECE_ID | bigint(20) | NO | そのラウンドで使用済みのPIECE ID |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | Piece切り替え間隔 |
| UNIT_SIZE   | bigint(20)   | NO   | ログアーカイブデータの1回の圧縮または暗号化におけるログブロックサイズ。現在このフィールドはサポートされていません   |
| COMPRESSION | varchar(128) | NO   | 圧縮アルゴリズム：<ul><li> none：圧縮しないことを示します </li><li> lz4_1.0：圧縮アルゴリズム lz4_1.0 を使用することを示します </li><li>zstd_1.3.8：圧縮アルゴリズム zstd_1.3.8 を使用することを示します</li></ul>現在このフィールドはサポートされていません   |
| INPUT_BYTES | bigint(21) | NO | 読み取ったデータ量、単位はバイト |
| INPUT_BYTES_DISPLAY | varchar(28) | NO | INPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| OUTPUT_BYTES | bigint(21) | NO | 出力データ量、単位はバイト |
| OUTPUT_BYTES_DISPLAY | varchar(28) | NO | OUTPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| COMPRESSION_RATIO | decimal(24,2) | NO | 圧縮率。現在このフィールドはサポートされていません |
| DELETED_INPUT_BYTES | bigint(20) | NO | 削除された生データ量、単位はバイト |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_INPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか  |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | 削除された有効データ量、単位はバイト |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | DELETED_OUTPUT_BYTESを単位変換した表示。単位はMB、GB、TB、PBのいずれか |
| COMMENT | varchar(262144) | NO | エラーメッセージを表示するために使用されます |
| PATH | varchar(2048) | NO | アーカイブパス |
