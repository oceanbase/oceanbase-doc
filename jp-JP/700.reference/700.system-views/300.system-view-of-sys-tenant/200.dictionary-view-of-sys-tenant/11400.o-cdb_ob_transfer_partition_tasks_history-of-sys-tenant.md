# oceanbase.CDB_OB_TRANSFER_PARTITION_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.1 BP2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`CDB_OB_TRANSFER_PARTITION_TASK_HISTORY`は、すべてのテナントで実行されたパーティション転送タスクの履歴を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULLを許容するか** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID        | bigint(20)   | NO   | ユーザーテナントID   |
| TASK_ID          | bigint(20)   | NO   | パーティション転送タスクの一意識別子   |
| CREATE_TIME      | timestamp(6) | NO   | 作成時間   |
| FINISH_TIME      | timestamp(6) | NO   | タスク完了時間。成功およびキャンセルを含む   |
| TABLE_ID         | bigint(20)   | NO   | 転送対象パーティションが存在するテーブルID   |
| OBJECT_ID        | bigint(20)   | NO   | 転送対象パーティションの`OBJECT_ID`   |
| DEST_LS          | bigint(20)   | NO   | 目的地ログストリーム   |
| BALANCE_JOB_ID   | bigint(20)   | NO   | タスク実行時に関連付けられるロードバランシングジョブID   |
| TRANSFER_TASK_ID | bigint(20)   | NO   | タスク実行時に関連付けられるパーティション転送タスクID   |
| STATUS           | varchar(64)  | NO   | タスク状態：<ul><li>COMPLETED：タスク実行成功</li><li>FAILED：タスク失敗</li></ul>   |
| COMMENT          | longtext     | YES  | コメント情報   |

## クエリ例

テナントIDが1006のテナントで実行されたパーティション移動タスクの履歴を確認します。

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TRANSFER_PARTITION_TASK_HISTORY WHERE TENANT_ID = 1006;
```

クエリ結果は次のとおりです：

```shell

|      1006 |       1 | 2023-11-29 16:02:17.501500 | 2023-11-29 16:03:18.000000 |   500003 |    500009 |    1003 |          17304 |                2 | COMPLETED | Partition transfer to dest LS |
```
