# oceanbase.CDB_OB_BACKUP_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

クラスタ内のすべてのテナントのタスクレベルバックアップタスクを表示します。1件のタスクレコードは1つの`backup_set`バックアップに対応します。タスクレコードとジョブレコードは1対1で対応しています。

## フィールド説明

| フィールド名                       | フィールド名        | NULL許容 | フィールド名                         |
|-------------------------------|----------------|-----------------|----------------------------------|
| TENANT_ID                     | bigint(20)     | NO              | テナントID |
| TASK_ID                       | bigint(20)     | NO              | タスクレベルのバックアップタスクID。1つのバックアップセットに対応するタスクを示す |
| JOB_ID                        | bigint(20)     | NO              | このタスクが属するJOB_ID |
| INCARNATION                   | bigint(20)     | NO              | Flashback Database後の現在の分身回数を示す |
| BACKUP_SET_ID                 | bigint(20)     | NO              | このタスクに対応するバックアップセットID |
| START_TIMESTAMP               | timestamp(6)   | NO              | タスクの開始時間 |
| END_TIMESTAMP                 | timestamp(6)   | NO              | タスクの終了時間 |
| STATUS                        | varchar(4096)  | NO              | バックアップの状態 |
| START_SCN                     | bigint(20) unsigned | NO         | バックアップ開始時のSCN |
| END_SCN                       | bigint(20) unsigned | NO         | バックアップ終了時のSCN |
| USER_LS_START_SCN             | bigint(20) unsigned | NO         | バックアップログストリームMETAのSCN |
| ENCRYPTION_MODE               | varchar(4096)  | YES             | 暗号化モード：<ul><li>None：暗号化しないことを示す</li><li>Password：パスワードによるみだけの保護を示す</li><li>Password Encryption ：暗号化し、かつパスワードで保護することを示す</li><li>Transparent Encryption：TDE暗号化を使用することを示す</li><li>Dual mode Encryption ：TDE暗号化およびパスワードによる保護を使用することを示す</li></ul> </br>現在、NoneとPasswordの2種類のモードのみサポートしています |
| PASSWD                        | varchar(4096)  | YES             | パスワード |
| INPUT_BYTES                   | bigint(20)     | YES             | 入力バイト数 |
| OUTPUT_BYTES                  | bigint(20)     | YES             | 出力バイト数 |
| OUTPUT_RATE_BYTES             | decimal(28,4)  | NO              | 1秒間の出力バイト数 |
| EXTRA_META_BYTES              | bigint(20)     | YES             | 追加バイト数 |
| TABLET_COUNT                  | bigint(20)     | YES             | TABLETの総数 |
| FINISH_TABLET_COUNT           | bigint(20)     | YES             | バックアップ完了したTABLETの総数 |
| MACRO_BLOCK_COUNT             | bigint(20)     | YES             | マクロブロック数 |
| FINISH_MACRO_BLOCK_COUNT      | bigint(20)     | YES             | バックアップ完了マクロブロック数 |
| FILE_COUNT                    | bigint(20)     | YES             | バックアップファイル数 |
| META_TURN_ID                  | bigint(20)     | YES             | バックアップMETAのサイクル |
| DATA_TURN_ID                  | bigint(20)     | YES             | バックアップDATAのサイクル |
| RESULT                        | bigint(20)     | YES             | バックアップエラーコード結果 |
| COMMENT                       | varchar(4096)  | YES             | エラーコード説明 |
| PATH                          | varchar(4096)  | YES             | バックアップパス |
| MINOR_TURN_ID                 | bigint(20)     | NO              | ダンプデータバックアップ終了のサイクル      |
| MAJOR_TURN_ID                 | bigint(20)     | NO              | ベースラインデータバックアップ終了のサイクル      |
| DATA_PROGRESS                 | decimal(26,2)  | NO              | データバックアップの進捗状況。計算方法は`完了したマクロブロック数 / 総マクロブロック数`で、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗が87.65%を表します。  <main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1から導入されました。</li> <li>V4.2.x系の他のバージョンでは、このフィールドはV4.2.1 BP3から導入されました。</li> </ul> </main>    |
| LOG_FILE_COUNT                | bigint(20)     | NO              | アーカイブclogファイルの合計数   <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.1から導入されました。</p></main>     |
| FINISH_LOG_FILE_COUNT         | bigint(20)     | NO              | バックアップ完了のアーカイブclogファイル数    <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.1から導入されました。</p></main>    |
| LOG_PROGRESS                  | decimal(26,2)  | NO              | アーカイブclogファイルのバックアップ進捗状況。計算方法は`バックアップ完了のアーカイブclogファイル数 / アーカイブclogファイルの合計数`で、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗が87.65%を表します。  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.3.1から導入されました。</p></main>       |
