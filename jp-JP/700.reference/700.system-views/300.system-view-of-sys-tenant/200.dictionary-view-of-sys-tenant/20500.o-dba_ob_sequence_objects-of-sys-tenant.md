# oceanbase.DBA_OB_SEQUENCE_OBJECTS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のすべてのシーケンスを表示します。

## フィールドの説明

|        フィールド名         |      タイプ       | NULLを許容するか |                               説明                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| SEQUENCE_ID         | bigint(20)    | NO         | このテナント内でのシーケンスの一意のID                                            |
| SCHEMA_VERSION      | bigint(20)    | NO         | シーケンスレコードに対応するSCHEMAバージョン                                        |
| DATABASE_ID         | bigint(20)    | NO         | シーケンスが属するデータベースのID                                      |
| SEQUENCE_NAME       | varchar(128)  | NO         | シーケンス名                                                     |
| MIN_VALUE           | decimal(28,0) | NO         | シーケンスが取り得る最小値（含む）                                              |
| MAX_VALUE           | decimal(28,0) | NO         | シーケンスが取り得る最大値（最大値を含む）                                           |
| INCREMENT_BY        | decimal(28,0) | NO         | 各値取得時のステップサイズ。正の整数または負の整数とする。0は指定できない                                         |
| START_WITH          | decimal(28,0) | NO         | シーケンス値取得の開始値                                                 |
| CACHE_SIZE          | decimal(28,0) | NO         | 各ノードのキャッシュ値数                                                      |
| ORDER_FLAG          | tinyint(4)    | NO         | 値がグローバルに順序付けされているかどうか                                                      |
| CYCLE_FLAG          | tinyint(4)    | NO         | 値を繰り返し取得できるかどうか                                                        |
| IS_SYSTEM GENERATED | tinyint(4)    | NO         | 内部生成のシーケンスかどうか。現在、IDENTITY COLUMNによって生成されるシーケンスではこのフィールドをTrueに設定します |

## クエリ例

現在のテナント内のすべてのシーケンスを確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SEQUENCE_OBJECTS;
```

1 row in set
