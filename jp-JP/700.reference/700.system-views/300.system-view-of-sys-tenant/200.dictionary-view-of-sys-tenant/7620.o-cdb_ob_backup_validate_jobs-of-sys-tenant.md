# oceanbase.CDB_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</li>
<li>V4.6.xバージョンでは、このビューはV4.6.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `oceanbase.CDB_OB_BACKUP_VALIDATE_JOBS` は、すべてのテナントが開始したジョブレベルのバックアップ検証タスクに関する情報を表示します。各ジョブは1つのバックアップ検証コマンドに対応します。コマンドの対象に複数のユーザーテナントが含まれる場合、ビューには各ユーザーテナントに対応する複数のサブジョブが表示されることがあります。

## フィールドの説明

| フィールド名             | 型           | NULL許容 | 説明           |
| ------------------- | -------------- | -------------- | -------------- |
| TENANT_ID           | bigint(20)     | NO   | テナントID。検証タスクを実行するテナントのID     |
| JOB_ID              | bigint(20)     | NO   | ジョブID     |
| INCARNATION         | bigint(20)     | NO   | インカーネーションID     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | このジョブを開始したテナントID   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | このジョブを開始したjob_id。値が0の場合、このジョブを開始したのが現在のジョブであることを示します      |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | このジョブに対応する、検証タスクを実行する必要があるユーザーテナントのtenant_id。値が0の場合、検証タスクを実行しているのが現在のテナントであることを示します     |
| TYPE                | varchar(64)    | NO   | 検証タスクのタイプ：<ul><li>`DATABASE`：バックアップパスとアーカイブパス配下のすべてのバックアップセットとログアーカイブピースを検証します</li> <li>`BACKUPSET`：指定されたバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定されたログアーカイブピースを検証します</li></ul>     |
| PATH                | longtext       | YES  | ユーザーが指定した検証用のバックアップパスまたはログアーカイブパスです。値が空の場合、このタスクはパスを指定しない検証であることを示します     |
| PATH_TYPE           | varchar(64)    | YES  | ユーザーが指定したパス配下で検証するタイプです（値が空の場合、このタスクはパスを指定しない検証であることを示します）：<ul><li>`BACKUPSET`：指定パス配下のバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定パス配下のログアーカイブピースを検証します</li></ul>     |
| ID                  | longtext       | YES  | <p>検証対象のバックアップセットの `backup_set_id` またはアーカイブピースの `piece_id`</p><p>デフォルトは空で、現在のバックアップパスとアーカイブパス配下のすべてのバックアップセットとログアーカイブピースを意味します。ユーザーがバックアップセットの `backup_set_id` またはアーカイブピースの `piece_id` を指定すると、値は対応するIDまたはIDリストに変更されます</p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | 検証レベル：<ul><li>`basic`：ファイルリストの完全性のみをチェックします。</li> <li>`physical`：物理データの正確性および論理的整合性をチェックします。</li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | 検証タスクの開始時間     |
| END_TIMESTAMP       | timestamp(6)   | NO   | 検証タスクの終了時間     |
| STATUS              | varchar(64)    | NO   | ジョブの状態：<ul><li>`INIT`：検証タスクが初期化中です</li> <li>`DOING`：検証タスクが実行中です</li> <li>`COMPLETED`：検証タスクが完了しました</li> <li>`FAILED`：検証タスクの実行に失敗しました</li> <li>`CANCELED`：検証タスクがキャンセルされました</li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | 再試行回数     |
| TASK_COUNT          | bigint(20)     | YES  | バックアップセットまたはログアーカイブピースの総検証タスク数     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | バックアップセットまたはログアーカイブピースの検証に成功したタスク数     |
| RESULT              | bigint(20)     | NO   | 検証結果のエラーコード情報    |
| DESCRIPTION         | varchar(4096)  | YES  | OCPが提供する外部情報    |
| COMMENT             | varchar(4096)  | YES  | 検証タスクが失敗した原因の説明      |
