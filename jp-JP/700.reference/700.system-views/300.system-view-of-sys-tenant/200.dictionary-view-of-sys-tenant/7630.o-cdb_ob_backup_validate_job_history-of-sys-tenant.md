# oceanbase.CDB_OB_BACKUP_VALIDATE_JOB_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.2バージョンでは、このビューはV4.4.2 BP2バージョンから導入されました。</li>
<li>V4.6.xバージョンでは、このビューはV4.6.0バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `oceanbase.CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` は、すべてのテナントが開始したJobレベルのバックアップ検証タスクの実行履歴を表示するために使用されます。各Jobは1つのバックアップ検証命令に対応します。バックアップ検証命令の実行時に、その命令が複数のユーザーテナントに関連している場合、ビュー内には複数のユーザーテナントレベルのサブJobが対応する可能性があります。

## フィールドの説明

| フィールド名             | 型           | NULL許容 | 説明           |
| ------------------- | -------------- | -------------- | -------------- |
| TENANT_ID           | bigint(20)     | NO   | テナントID。検証タスクを実行したテナントのID     |
| JOB_ID              | bigint(20)     | NO   | タスクID     |
| INCARNATION         | bigint(20)     | NO   | 分身ID     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | このJobを開始したテナントID   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | このJobを開始したjob_id。値が0の場合、このJobを開始したのが現在のJobであることを示します      |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | このJobに対応する、検証タスクを実行する必要があるユーザーテナントのtenant_id。値が0の場合、検証タスクを実行したのが現在のテナントであることを示します     |
| TYPE                | varchar(64)    | NO   | 検証タスクのタイプ：<ul><li>`DATABASE`：バックアップパス全体とアーカイブパス下のすべてのバックアップセットおよびログアーカイブPieceを検証します</li> <li>`BACKUPSET`：指定されたバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定されたログアーカイブPieceを検証します</li></ul>     |
| PATH                | longtext       | YES  | ユーザーが指定したバックアップパスまたはログアーカイブパスです。値が空の場合、このタスクは指定パス以外の検証であることを示します     |
| PATH_TYPE           | varchar(64)    | YES  | ユーザーが指定したパス下で検証するタイプです（値が空の場合、このタスクは指定パス以外の検証であることを示します）：<ul><li>`BACKUPSET`：指定パス下のバックアップセットを検証します</li> <li>`ARCHIVELOG_PIECE`：指定パス下のログアーカイブPieceを検証します</li></ul>     |
| ID                  | longtext       | YES  | <p>検証対象のバックアップセットの `backup_set_id` またはアーカイブPieceの `piece_id`</p><p>デフォルトは空で、現在のバックアップパスとアーカイブパス下のすべてのバックアップセットとログアーカイブPieceを意味します。ユーザーがバックアップセットの `backup_set_id` またはアーカイブPieceの `piece_id` を指定すると、値は対応するIDまたはIDリストに変更されます</p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | 検証レベル：<ul><li>`basic`：ファイルリストの整合性のみをチェックします。</li> <li>`physical`：物理データの正確性と論理的一貫性をチェックします。</li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | 検証タスクの開始時間     |
| END_TIMESTAMP       | timestamp(6)   | NO   | 検証タスクの終了時間     |
| STATUS              | varchar(64)    | NO   | Jobの状態：<ul><li>`COMPLETED`：検証タスクが完了しました</li> <li>`FAILED`：検証タスクの実行に失敗しました</li> <li>`CANCELED`：検証タスクがキャンセルされました</li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | 再試行回数     |
| TASK_COUNT          | bigint(20)     | YES  | バックアップセットまたはログアーカイブPieceの総検証タスク数     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | バックアップセットまたはログアーカイブPieceの検証に成功したタスク数     |
| RESULT              | bigint(20)     | NO   | 検証結果のエラーコード情報    |
| DESCRIPTION         | varchar(4096)  | YES  | OCPが提供する外部情報    |
| COMMENT             | varchar(4096)  | YES  | 検証タスクが失敗した原因の説明      |

## クエリ例

システムテナントがすべてのテナントが開始したJobレベルのバックアップ検証タスクの実行履歴を照会します。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_JOB_HISTORY\G
```

クエリ結果は次のとおりです。

