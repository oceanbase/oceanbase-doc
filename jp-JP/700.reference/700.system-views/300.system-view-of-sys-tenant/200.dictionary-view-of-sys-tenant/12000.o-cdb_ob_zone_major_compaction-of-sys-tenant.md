# oceanbase.CDB_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント配下におけるすべてのテナントの各ゾーンのメジャーコンパクション情報を表示します。

## フィールド説明

|       フィールド名        |      型      | NULL許容   |         説明         |
|-------------------|--------------|------------|----------------------------------------------|
| TENANT_ID              | bigint(20) | NO         | テナントID            |
| ZONE              | varchar(128) | NO         | Zone名            |
| BROADCAST_SCN | bigint(20) unsigned   | NO         | ブロードキャストされたメジャーコンパクションのバージョン番号           |
| LAST_SCN      | bigint(20) unsigned   | NO         | 最終メジャーコンパクションのバージョン番号          |
| LAST_FINISH_TIME  | timestamp(6)   | NO         | 最終メジャーコンパクション終了時間          |
| START_TIME        | timestamp(6)   | NO         | メジャーコンパクション開始時間             |
| STATUS            | varchar(10)  | NO         | <ul><li> `IDLE`：メジャーコンパクション中ではありません  </li><li>`COMPACTING`：メジャーコンパクション中 </li></ul>    |

## クエリ例

システムテナントがすべてのテナントの各ゾーンにおけるメジャーコンパクション情報を確認します。
