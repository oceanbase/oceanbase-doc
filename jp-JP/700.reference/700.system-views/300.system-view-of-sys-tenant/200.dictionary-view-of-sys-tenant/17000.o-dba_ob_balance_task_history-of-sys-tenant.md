# oceanbase.DBA_OB_BALANCE_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `DBA_OB_BALANCE_TASK_HISTORY` は、現在のテナントで実行されたすべてのロードバランシングタスクの履歴を表示します。システムテナントでは、そのクエリ結果は空になります。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | ------- |
| TASK_ID                  | bigint(20)    | NO  | ロードバランシングタスクID |
| CREATE_TIME              | timestamp(6)  | NO  | タスク開始時間 |
| FINISH_TIME              | timestamp(6)  | NO  | タスク完了時間。成功およびキャンセル時間を含む |
| TASK_TYPE                | varchar(64)   | NO  | タスクタイプ <ul><li>`LS_SPLIT`：ログストリームの分割  </li><li>`LS_ALTER`：ログストリーム属性の変更 </li><li>`LS_MERGE`：ログストリームのメジャーコンパクション </li><li>`LS_TRANSFER`：ログストリームのTransfer </li></ul>|
| SRC_LS                   | bigint(20)    | NO  | ソースログストリーム（データソースから生成されるログデータストリーム） |
| DEST_LS                  | bigint(20)    | NO  | デスティネーションログストリーム |
| PART_LIST                | longtext      | YES | パーティションリスト。ユーザーテーブルのパーティションとグローバルインデックスのパーティションが含まれます |
| FINISHED_PART_LIST       | longtext      | YES | 現在完了したロードバランシング処理のパーティションリスト |
| PART_COUNT               | bigint(20)    | YES | パーティションリスト内のパーティション数 |
| FINISHED_PART_COUNT      | bigint(20)    | YES | 現在完了したロードバランシング処理のパーティション数 |
| LS_GROUP_ID              | bigint(20)    | NO  | ログストリームグループID |
| STATUS                   | varchar(64)   | NO  | タスクステータス <ul><li>`INIT`：タスク作成  </li><li>`CREATE_LS`：ログストリームの作成 </li><li>`ALTER_LS`：ログストリーム属性の変更 </li><li>`SET_LS_MERGING`：ログストリームのメジャーコンパクション </li><li>`DROP_LS`：ログストリームの削除 </li><li>`COMPLETED`：タスク実行成功 </li><li>`CANCELED`：タスクキャンセル </li></ul>|
| PARENT_LIST              | varchar(1024) | YES | 親タスクリスト |
| CHILD_LIST               | varchar(1024) | YES | 子タスクリスト |
| CURRENT_TRANSFER_TASK_ID | bigint(20)    | NO  | 現在のロードバランシングタスクによってトリガーされたTransferタスクID |
| JOB_ID                   | bigint(20)    | NO  | 現在のタスクが属するJob ID |
| COMMENT                  | longtext      | YES | コメント情報 |
| BALANCE_STRATEGIE         | varchar(64)   | YES | Balanceタスクに対応するロードバランシング戦略：<ul><li>`LS balance by migrate`：移行によるロードバランシング  </li><li>`LS balance by alter`：ログストリーム属性の変更によるロードバランシング </li><li>`LS balance by expand`：スケールアップによるロードバランシング </li><li>`LS balance by shrink`：スケールダウンによるロードバランシング </li><li>`partition balance`：パーティションによるロードバランシング </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>V4.2.x系では、このフィールドはV4.2.4以降で導入されました。V4.3.x系では、このフィールドはV4.3.2以降で導入されました。</p></main>   |
