# oceanbase.DBA_OB_LS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのログストリームの状態と復旧進捗を表示します。

## フィールドの説明

| フィールド名       | タイプ                | NULLを許容するか        | 説明               |
|---------------|---------------------|-----------------------|--------------------|
| LS_ID         | bigint(20)          | NO | ログストリームID |
| STATUS        | varchar(100)        | NO | ログストリームのステータス。<ul><li>`CREATING`：ログストリームの作成中</li><li>`CREATED`：ログストリームの作成完了</li><li>`NORMAL`：ログストリームがサービスを提供可能</li><li>`DROPPING`：ログストリームが削除される予定であり、ログストリーム上のTabletを移行する必要があります</li><li>`TENANT DROPPING`：ログストリームが存在するテナントが削除されるため、ログストリームも削除する必要があります</li><li>`WAIT OFFLINE`：ログストリームデータの削除完了、GC待機中</li><li>`CREATE ABORT`：ログストリームの作成に失敗したか、作成不要と判断されたため、削除予定</li></ul> |
| PRIMARY_ZONE  | longtext            | YES| ログストリームの選出優先順位 |
| UNIT_GROUP_ID | bigint(20)          | NO | UnitグループID。システムログストリーム（1番目のログストリーム）およびブロードキャストログストリームについては、このフィールドは0として表示され、特定のUnitグループにバインドされていないことを示します。<main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、このフィールドはV4.2.5 BP5バージョンから常に値0となります。</p></main>  |
| LS_GROUP_ID   | bigint(20)          | NO | ログストリームグループID。システムログストリーム（1番目のログストリーム）およびブロードキャストログストリームについては、このフィールドは0として表示され、特定のログストリームグループに属していないことを示します |
| CREATE_SCN    | bigint(20) unsigned | NO | ログストリームにログ書き込みが開始された時点 |
| DROP_SCN      | bigint(20) unsigned | NO | ログストリームが削除された時点、すべてのユーザーデータが終了した時点です。ログストリームが削除された場合、このフィールドには削除時のSCNが記録されます。削除されていない場合、このフィールドは空になります。 |
| SYNC_SCN      | bigint(20) unsigned | NO | ログストリームの同期時点であり、ログストリームが最後に正常に同期されたトランザクションのSCNを示します |
| READABLE_SCN  | bigint(20) unsigned | NO | ログストリームの読み取り可能な時点であり、ログストリームが読み取り可能な最小SCNを示します |
| FLAG          | varchar(2048)       | NO | ログストリームのマーク：<ul><li>空：通常のログストリーム</li><li> DUPLICATE：ユーザーテナントのブロードキャストログストリームであり、レプリケーションテーブルはこのログストリーム上に作成されます </li> <li>BLOCK_TABLET_IN：このログストリーム上でTabletを作成できないことを示します</li> <li>DUPLICATE\|BLOCK_TABLET_IN：ブロードキャストログストリームでは現在Tabletの作成が許可されていません</li></ul>  <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0バージョンから導入されました。</p></main>  |
| UNIT_LIST     | varchar(1216)       | NO | ユーザーログストリームが配置されるUnitのリストです。システムログストリームおよびブロードキャストログストリームでは、具体的な位置が指定されない場合は空になります。  <main id="notice" type='explain'><h4>説明</h4><p>V4.2.5バージョンでは、このフィールドはV4.2.5 BP5バージョンから導入されました。</p></main>  |

## クエリ例

システムテナントは、自身のテナントのログストリームの状態と復旧進捗を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```

クエリ結果は次のとおりです：

```shell
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
| LS_ID | STATUS | PRIMARY_ZONE | UNIT_GROUP_ID | LS_GROUP_ID | CREATE_SCN | DROP_SCN | SYNC_SCN | READABLE_SCN | FLAG | UNIT_LIST |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
|     1 | NORMAL | z1,z2,z3     |             0 |           0 |       NULL |     NULL |     NULL |         NULL |      |           |
+-------+--------+--------------+---------------+-------------+------------+----------+----------+--------------+------+-----------+
1 row in set
```
