# information_schema.VIEWS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV1.4バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー情報を記録します。

## フィールドの説明

|       **フィールド名**       |     **型**     | **NULL許容** |                   **説明**                    |
|----------------------|----------------|------------|---------------------------------------------|
| TABLE_CATALOG        | varchar(64)     | NO         | テーブルカタログ                                         |
| TABLE_SCHEMA         | varchar(128)   | NO         | データベース名                                       |
| TABLE_NAME           | varchar(256)   | NO         | ビューの名前                                         |
| VIEW_definition      | longtext       | NO         | ビュー定義                                        |
| CHECK_OPTION         | varchar(8)     | NO         | チェックオプション                                        |
| IS_UPDATABLE         | varchar(3)     | NO         | 更新は可能か                                       |
| DEFINER              | varchar(288)   | NO         | ビューを作成したユーザー名                                    |
| SECURITY_TYPE        | varchar(7)     | NO         | セキュリティタイプ                                        |
| CHARACTER_SET_CLIENT | varchar(64)     | NO         | ビュー作成時のSession変数character_set_clientの値 |
| COLLATION_CONNECTION | varchar(64)    | NO         | ビュー作成時のsession変数collation_connectionの値 |
