# oceanbase.CDB_WR_SQLSTAT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`CDB_WR_SQLSTAT`は、すべてのテナントで実行されたSQL文の基本的なパフォーマンス統計データを表示するために使用されます。各SQL文は1行として扱われます（つまり、各`SQL_ID`+`Plan_Hash`の一意の値が1行に対応します）。そのうち、`_DELTA`を含む列は、前回のWRスナップショットから現在時点までの統計値の増分を示します。
