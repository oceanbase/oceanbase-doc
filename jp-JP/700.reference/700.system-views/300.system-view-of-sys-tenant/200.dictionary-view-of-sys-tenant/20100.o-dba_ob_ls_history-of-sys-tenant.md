# oceanbase.DBA_OB_LS_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

テナントの履歴に存在したログストリームを表示します。

## フィールドの説明

| フィールド        | 型           | NULL許容 | 説明                                       |
|-------------|---------------|-------------|-------------------------------------------|
| LS_ID       | bigint(20)    | NO          |  ログストリームID                                 |
| LS_GROUP_ID | bigint(20)    | NO          |  ログストリームグループID                               |
| STATUS      | varchar(100)  | NO          |  ログストリームの現在の状態：<ul><li>`CREATING`：ログストリーム作成中</li><li>`NORMAL`：通常のログストリームの状態</li><li>`DROPPING`：ログストリームが削除中</li><li>`PRE_TENANT_DROPPING`：システムログストリームの特別な状態で、テナント内のすべてのログストリームの削除開始を示します</li><li>`TENANT_DROPPING`：テナントが削除され、ログストリームが削除中の状態</li><li>`DROPPED`：ログストリームが回収されたか、回収中です。</li><li>`WAIT_OFFLINE`：ログストリームが回収を待機しています</li><li>`CREATE_ABORT`：ログストリームの作成が中止されました</li></ul>        |
| FLAG        | varchar(2048) | NO          |  ログストリームフラグ：<ul><li>空：通常のログストリーム</li><li>`DUPLICATE`：ユーザーテナントのブロードキャストログストリームで、レプリケーションテーブルはこのログストリーム上に作成されます </li> <li>`BLOCK_TABLET_IN`：このログストリーム上にTabletを作成できないことを示します</li> <li>`DUPLICATE\|BLOCK_TABLET_IN`：ブロードキャストログストリームでは現在Tabletの作成が許可されていません</li></ul>                        |
| CREATE_SCN  | decimal(20,0) | NO          |  ログストリーム作成時のGTS。単位はナノ秒              |

## クエリ例

システムテナントが自身の履歴に存在したログストリームを照会します。

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```

クエリ結果は次のとおりです：

```shell
+-------+-------------+--------+------+------------+
| LS_ID | LS_GROUP_ID | STATUS | FLAG | CREATE_SCN |
+-------+-------------+--------+------+------------+
|     1 |           0 | NORMAL |      |          0 |
+-------+-------------+--------+------+------------+
1 row in set
```
