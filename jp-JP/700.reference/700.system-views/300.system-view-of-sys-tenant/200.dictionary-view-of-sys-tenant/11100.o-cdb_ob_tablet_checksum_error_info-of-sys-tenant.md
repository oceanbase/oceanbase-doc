# oceanbase.CDB_OB_TABLET_CHECKSUM_ERROR_INFO

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

Tabletレプリカ間で発生したデータ不整合の情報を表示します。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| TABLET_ID | bigint(20) | NO | チェックサムが一致しないTABLETのID |

## クエリ例

システムテナントがTabletレプリカ間で発生したデータ不整合の情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_TABLET_CHECKSUM_ERROR_INFO;
```
