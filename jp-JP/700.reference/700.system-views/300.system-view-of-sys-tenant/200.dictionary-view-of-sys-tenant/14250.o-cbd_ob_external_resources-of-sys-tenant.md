# oceanbase.CDB_OB_EXTERNAL_resources

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.CDB_OB_EXTERNAL_RESOURCES` は、システムテナント配下にアップロードされたすべてのリソースファイルを表示するために使用されます。

| **フィールド名** | **型**  | **NULL許容** | **説明**               |
|------------|-------------|---------------------|----------------------------------------|
| TENANT_ID|bigint(20)|NO|リソースが属するテナントID。|
| RESOURCE_ID|bigint(20)|NO|リソースID。リソースの一意の識別子です。|
| DATABASE_ID        | bigint(20)  | NO   |   リソースが属するデータベースID。   |
| NAME |varchar(256)|NO|リソース名。|
| TYPE        | varchar   | NO   |   リソースタイプ。Java JARやPythonソースコードなどのリソースを区別するために使用されます。現在の値の範囲は『JAVA_JAR』および『PYTHON_PY』です。  |
| CONTENT     | longblob      | NO   |   リソースのバイナリコンテンツ。   |
| COMMENT     | varchar(4096) | NO   |   リソースをアップロードしたときに追加されたコメント。   |

## クエリ例

```shell
obclient > SELECT * FROM oceanbase.CDB_OB_EXTERNAL_RESOURCES;
```
