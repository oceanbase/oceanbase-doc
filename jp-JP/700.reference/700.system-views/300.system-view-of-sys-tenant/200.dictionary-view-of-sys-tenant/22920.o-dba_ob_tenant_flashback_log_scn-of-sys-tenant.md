# oceanbase.DBA_OB_TENANT_flashBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_TENANTFLASHBACK_LOG_SCN`は、テナント内の各ログトリミングに関する情報を表示するために使用されます。

## フィールドの説明

| フィールド    | 型            | NULL許容    | 説明                                        |
|------------|--------------|-------------|------------------------------------------|
| TENANT_ID         | bigint(20)          | NO   | テナントID |
| TIMESTAMP         | timestamp(6)        | NO          | クリエーション時間、マイクロ秒単位                   |
| SWITCHOVER_EPOCH  | bigint(20)          | NO          | テナントのロールが`NORMAL`状態に切り替わったときの`SWITCHOVER_EPOCH`。`SWITCHOVER_EPOCH`は、テナントのロール切り替え（Switchover/Failover）操作を識別するための一意の識別子です |
| OP_TYPE           | varchar(64)         | NO          | 操作タイプ。次のものが含まれます：<ul><li>`FAILOVER_TO_PRIMARY`：これはFailover操作のタイプで、プライマリテナントが利用不可な場合にスタンバイテナントをプライマリテナントに切り替える操作です</li><li>`FLASHBACK_STANDBY_LOG`：これはスタンバイテナントのログトリミング操作のタイプで、スタンバイテナントのログを指定されたSCN位置までトリミングします</li></ul> |
| FLASHBACK_LOG_SCN |  bigint(20) unsigned | NO  | テナントログを後から前へトリミングする終点             |

## クエリ例

テナント内の各ログトリミングに関する情報を照会します。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```
