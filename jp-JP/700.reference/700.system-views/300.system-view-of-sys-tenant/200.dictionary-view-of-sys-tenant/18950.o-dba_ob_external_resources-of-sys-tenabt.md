# oceanbase.DBA_OB_EXTERNAL_RESOURCES

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.DBA_OB_EXTERNAL_RESOURCES` は、アップロード済みのリソースファイルを表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ**  | **NULL許容** | **説明**               |
|------------|-------------|---------------------|----------------------------------------|
|RESOURCE_ID|bigint(20)|NO|リソースID。リソースの一意の識別子です。|
|DATABASE_ID|bigint(20)|NO|リソースが属するデータベースID。|
|DATABASE_NAME| varchar(128)  | NO|この外部リソースが存在するデータベース名を表示するために使用されます。|
| NAME        | varchar(256)  | NO   |   リソース名。   |
| TYPE        | varchar(12)   | NO   |   リソースタイプ。Java JARやPythonソースコードなどのリソースを区別するために使用されます。現在の値の範囲は『JAVA_JAR』、『PYTHON_PY』です。  |
| CONTENT     | longblob      | NO   |   リソースのバイナリコンテンツ。   |
| COMMENT     | varchar(4096) | NO   |   リソースをアップロードしたときに追加されたコメント。   |

## クエリ例

以下のSQLを実行して、現在のテナントでアップロードされたリソースファイルを確認します。

```shell
obclient > SELECT * FROM oceanbase.DBA_OB_EXTERNAL_RESOURCES;
```
