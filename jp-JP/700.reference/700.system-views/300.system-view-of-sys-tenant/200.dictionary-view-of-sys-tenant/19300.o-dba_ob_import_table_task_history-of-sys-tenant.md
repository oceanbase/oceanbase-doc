# oceanbase.DBA_OB_IMPORT_TABLE_TASK_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント配下で、テーブルレベルのテナント間インポートタスクの履歴を表示します。

## フィールドの説明

| **フィールド** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TASK_ID | varchar(4096) | NO | ロードバランシングタスクID |
| JOB_ID | bigint(20) | NO | タスクID |
| SRC_TENANT_ID | bigint(20) | NO | ソーステナントID |
| SRC_TABLESPACE | varchar(128) | YES | ソーステーブルのTABLESPACE |
| SRC_TABLEGROUP | varchar(128) | YES | ソーステーブルのTABLEGROUP |
| SRC_DATABASE | varchar(128) | YES | ソーステーブルのDATABASE |
| SRC_TABLE | varchar(128) | YES | ソーステーブル名 |
| SRC_PARTITION | varchar(64) | YES | ソーステーブルのPARTITION名 |
| TARGET_TABLESPACE | varchar(128) | YES | 重マッピングされたテーブルスペース名。重マッピングされていない場合は空文字列を返す |
| TARGET_TABLEGROUP | varchar(128) | YES | 重マッピングされたテーブルグループ名。重マッピングされていない場合は空文字列を返す |
| TARGET_DATABASE | varchar(128) | YES | 重マッピングされたデータベース名。重マッピングされていない場合は空文字列を返す |
| TARGET_TABLE | varchar(128) | YES | 重名後のテーブル名。重名されていない場合は空文字列を返す  |
| TABLE_COLUMN | bigint(20) | NO | テーブル列の数 |
| STATUS | varchar(64) | NO | タスク状態：<ul><li>`INIT`：テーブルレベルインポートタスクの初期化</li> <li>`DOING`：テーブルレベルインポート実行中</li> <li>`FINISH`：インポート終了</li></ul>  |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時のテナント現在時刻 |
| COMPLETION_TIMESTAMP | timestamp(6) | NO | タスク完了時のテナント現在時刻 |
| CUMULATIVE_TS | bigint(20) | NO | 累計時間 |
| TOTAL_INDEX_COUNT | bigint(20) | NO | 総インデックス数 |
| IMPORTED_INDEX_COUNT | bigint(20) | NO | インポート済みインデックス数 |
| FAILED_INDEX_COUNT | bigint(20) | NO | インポート失敗したインデックス数 |
| TOTAL_CONSTRAINT_COUNT | bigint(20) | NO | 総制約数 |
| IMPORTED_CONSTRAINT_COUNT | bigint(20) | NO | インポート済み制約数 |
| FAILED_CONSTRAINT_COUNT | bigint(20) | NO | インポート失敗した制約数 |
| TOTAL_REF_CONSTRAINT_COUNT | bigint(20) | NO | 総参照制約数 |
| IMPORTED_REF_CONSTRAINT_COUNT | bigint(20) | NO | インポート済み参照制約数 |
| FAILED_REF_CONSTRAINT_COUNT | bigint(20) | NO | インポート失敗した参照制約数 |
| RESULT | varchar(64) | YES | タスクの実行結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行されました。</li><li>`FAIL`：インポートタスクが失敗しました。</li></ul>|
| COMMENT | longtext | YES | 備考 |
