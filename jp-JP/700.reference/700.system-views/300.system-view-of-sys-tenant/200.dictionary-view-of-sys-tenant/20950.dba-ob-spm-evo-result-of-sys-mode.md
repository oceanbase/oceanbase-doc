# oceanbase.DBA_OB_SPM_EVO_RESULT

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.5バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントのSPM計画進化情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OWNER               | varchar(128) | NO   |    エボリューションタスクを実行したユーザー。  |
| RECORD_TIME         | timestamp(6) | NO   |    エボリューション結果が記録された時間。  |
| SVR_IP              | varchar(46)  | NO   |    エボリューションタスクを実行したサーバーのIPアドレス。  |
| SVR_PORT            | bigint(20)   | NO   |    エボリューションタスクを実行したサーバーのポート番号。 |
| SQL_ID              | varchar(32)  | NO   |    エボリューションタスクを実行したSQLのID。  |
| TYPE                | varchar(32)  | NO   |    記録のタイプ：<ul><li>`OnlineEvolve`：オンラインエボリューションモードで記録されるのは、エボリューションタスクの結果であり、以下のすべてのフィールドはこのタイプの場合にのみ有効です。</li><li>`FirstBaseline`：最初のベースラインを生成するSQLが記録されていることを示します。</li><li>`UnReproducible`：現在のSQLを再現できるベースラインがないことを示します。</li><li>`BaselineFirst`：ベースライン優先モードで新しい計画が生成されましたが、ベースライン計画が復元されて使用されました。</li></ul> |
| START_TIME          | timestamp(6) | YES  |  エボリューションタスク開始時刻。    |
| END_TIME            | timestamp(6) | YES  |   エボリューションタスク終了時刻。   |
| STATUS              | varchar(7)   | YES  |   エボリューションタスクの状態：<ul><li>`success`：エボリューションタスクが正常に終了しました。</li><li>`timeout`：エボリューションタスクがタイムアウトしました（この場合、エボリューション期間中の実行情報に基づいてどの計画がより良いかを判断します）。   |
| NEW_PLAN_BETTER     | tinyint(4)   | YES  |   エボリューション計画がより優れているかどうか。   |
| EVO_PLAN_EXEC_COUNT | bigint(20)   | YES  |   エボリューション期間中のエボリューション計画の実行回数。   |
| EVO_PLAN_CPU_TIME   | bigint(20)   | YES  |   エボリューション期間中のエボリューション計画の平均CPUコスト。   |
| BASELINE_EXEC_COUNT | bigint(20)   | YES  |   エボリューション期間中のベースライン計画の実行回数。  |
| BASELINE_CPU_TIME   | bigint(20)   | YES  |   エボリューション期間中のベースライン計画の平均CPUコスト。   |
