# oceanbase.DBA_OB_BALANCE_TASKS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー`DBA_OB_BALANCE_TASKS`は、現在このテナントで実行中のロードバランシングタスクを表示します。各テナントでは同時に複数のロードバランシングタスクが実行されている可能性があり、これらのタスクはすべて同一のロードバランシングジョブ（JOB）に属します。システムテナントの場合、そのクエリ結果は空になります。
