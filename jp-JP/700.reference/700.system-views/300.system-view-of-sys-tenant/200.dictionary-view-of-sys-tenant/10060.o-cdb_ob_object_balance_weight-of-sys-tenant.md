# oceanbase.CDB_OB_OBJECT_BALANCE_WEIGHT

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.4.x系では、このビューはV4.4.1バージョンから導入されました。</li>
<li>V4.2.5系では、このビューはV4.2.5 BP2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー `CDB_OB_OBJECT_BALANCE_WEIGHT` は、すべてのユーザーテナント内で特別な重みを設定したすべてのパーティションを表示するために使用されます。

## フィールド説明

|       フィールド名     |      型    | NULL許容   |         説明                                 |
|-------------------|--------------|----------------|----------------------------------------------|
| TENANT_ID         | bigint(20)   | NO             | テナントID     |
| TABLE_ID          | bigint(20)   | NO             | テーブルID     |
| PARTITION_ID      | bigint(20)   | NO             | パーティションID。パーティションの重みが設定されていない場合は`NULL`を返します     |
| SUBPARTITION_ID   | bigint(20)   | NO             | サブパーティションID。サブパーティションの重みが設定されていない場合は`NULL`を返します。現在、サブパーティションの重みの設定はサポートされていません     |
| WEIGHT            | bigint(20)   | NO             | パーティションの重み値     |
| DATABASE_NAME     | varchar(128) | NO             | テーブルが属するデータベース名     |
| TABLE_NAME        | varchar(256) | NO             | テーブル名     |
| PARTITION_NAME    | varchar(64)  | NO             | パーティション名     |
| SUBPARTITION_NAME | varchar(64)  | NO             | サブパーティション名     |
| TABLEGROUP_NAME   | varchar(128) | NO             | テーブルが属するテーブルグループ名     |
| DATABASE_ID       | bigint(20)   | NO             | テーブルが属するデータベースID     |
| TABLEGROUP_ID     | bigint(20)   | NO             | テーブルが属するテーブルグループID     |
| OBJECT_ID         | bigint(20)   | NO             | テーブルが属するオブジェクトID     |

## クエリ例

システムテナント内で、IDが1002のユーザーテナントに設定された特別な重みを持つパーティションをクエリします。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_OBJECT_BALANCE_WEIGHT WHERE TENANT_ID = 1002;
```
