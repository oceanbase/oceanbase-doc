# oceanbase.DBA_TAB_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのテーブルに対するオプティマイザー統計情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | オブジェクトの所有者 |
| TABLE_NAME | varchar(128) | NO | テーブル名 |
| PARTITION_NAME | varchar(128) | NO | パーティション名 |
| PARTITION_POSITION | decimal(10,0) | NO | テーブル内のパーティションの位置 |
| SUBPARTITION_NAME | varchar(128) | NO | サブパーティション名 |
| SUBPARTITION_POSITION | decimal(10,0) | NO | パーティション内のサブパーティションの位置 |
| OBJECT_TYPE | varchar(12) | NO | オブジェクトタイプ：<ul><li>TABLE</li><li>PARTITION</li><li>SUBPARTITION </li></ul> |
| NUM_ROWS | decimal(10,0) | NO | オブジェクト内の行数 |
| BLOCKS | decimal(10,0) | NO | オブジェクトで使用されるブロック数 |
| EMPTY_BLOCKS | decimal(10,0) | NO | オブジェクト内の空ブロック数 |
| AVG_SPACE | decimal(10,0) | NO | オブジェクト内の平均利用可能領域 |
| CHAIN_CNT | decimal(10,0) | NO | オブジェクト内の連結行数 |
| AVG_ROW_LEN | decimal(10,0) | NO | 行オーバーヘッドを含む平均行長 |
| AVG_SPACE_FREELIST_BLOCKS | decimal(10,0) | NO | FREELIST上のすべてのブロックの平均利用可能領域 |
| NUM_FREELIST_BLOCKS | decimal(10,0) | NO | FREELIST上のブロック数 |
| AVG_CACHED_BLOCKS | decimal(10,0) | NO | バッファキャッシュ内の平均ブロック数 |
| AVG_CACHE_hit_RATIO | decimal(10,0) | NO | オブジェクトの平均キャッシュヒット率 |
| IM_IMCU_COUNT | decimal(10,0) | NO | テーブル内のメモリ圧縮ユニット（IMCU）の数 |
| IM_BLOCK_COUNT | decimal(10,0) | NO | テーブル内のIn-Memoryブロック数 |
| IM_STAT_UPDATE_TIME | datetime | NO | メモリ内統計情報の最終更新日時 |
| SCAN_RATE | decimal(10,0) | NO | オブジェクトのスキャン速度（MB/秒単位） |
| SAMPLE_SIZE | decimal(10,0) | NO | テーブル分析用のサンプルサイズ |
| LAST_ANALYZED | datetime(6) | NO | 最後にテーブルを分析した日付 |
| GLOBAL_STATS | varchar(3) | NO | 統計情報が収集または増分保守されているかどうかを示します：<ul><li>YES</li><li>NO </li></ul> |
| USER_STATS | varchar(3) | NO | 統計情報がユーザーによって直接入力されたかどうかを示します：<ul><li>YES</li><li>NO </li></ul> |
| STATTYPE_LOCKED | varchar(5) | NO | 統計ロックタイプ：<ul><li>DATA</li><li>CACHE</li><li>ALL</li></ul> |
| STALE_STATS | varchar(3) | NO | 統計情報の追加プロパティを説明します。例えば、STATS_ON_CONVENTIONAL_LOADという値は、その統計情報が通常のDMLによるオンライン統計収集を通じて取得されたことを示します。 |
| SCOPE | varchar(7) | NO | この値は、グローバル一時テーブル以外の任意のテーブルで収集される統計情報に使用されます。<br>グローバル一時テーブルの場合、可能な値は次のとおりです：<ul><li>SESSION：統計情報がセッション固有であることを示します</li><li>SHARED：統計情報がすべてのセッションで共有されることを示します</li></ul> |

## クエリ例

このテナント内のテーブル`t_subpart`のオプティマイザー統計情報を確認します。

