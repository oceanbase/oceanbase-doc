# oceanbase.DBA_OB_SERVERS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのOBServerノードの情報を表示します。

## フィールド説明

|         フィールド名          |      型      | NULL許容 |                        説明                        |
|-----------------------|--------------|------------|----------------------------------------------------------------------------|
| SVR_IP                | varchar(46)  | NO         | サーバーIPアドレス                                        |
| SVR_PORT              | bigint(20)   | NO         | サーバーポート番号                                           |
| ID                    | bigint(20)   | NO         | クラスタが割り当てた一意のID                                     |
| ZONE                  | varchar(128) | NO         | OBServerノードが属するZone                                |
| SQL_PORT              | bigint(20)   | NO         | OBServerノードがSQLリクエストを処理するポート                          |
| WITH_ROOTSERVER       | varchar(3)   | NO         | <ul><li>`YES`：Root Serviceサービスが存在する </li><li>`NO`：Root Serviceサービスが存在しない</li></ul>  |
| STATUS                | varchar(64)  | NO         | <ul><li>`ACTIVE`：OBServerノードとRSのハートビートが正常 </li><li>`INACTIVE`：OBServerノードとRSのハートビートが切断 </li><li>`DELETING`：OBServerノードが削除中</li></ul>    |
| START_SERVICE_TIME    | timestamp(6) | NO         | ノードプロセス起動後、外部にサービスを提供できる時点：<ul><li>`NULL`：ノードプロセスが起動していないか、ノードの状態が利用不可。   </li><li> 有効値：ノードプロセス起動後、外部にサービスを提供できる時点</li></ul>  |
| STOP_TIME             | timestamp(6) | NO         | ユーザーがノードサービスを停止した時点：<ul><li>`NULL`：ノードがStopされていない   </li><li> 有効値：OBServerノードがStopされた時間</li></ul>  |
| BLOCK_MIGRATE_IN_TIME | timestamp(6) | NO         | OBServerノードでデータの移入を禁止する時間：<ul><li>`NULL`：現在データの移入を禁止していない   </li><li> 有効値：データの移入を禁止する時間を示す</li></ul>  |
|CREATE_TIME            | timestamp(6) | YES        |テーブルの作成日時|
|MODIFY_TIME            | timestamp(6) | YES        |最終のタスク変更日時|
| BUILD_VERSION         | varchar(256) | NO         | OBServerノードのバイナリビルドバージョン番号      |
| LAST_OFFLINE_TIME     | timestamp(6) | NO         | OBServerノードの前回オフラインになった時間：<ul><li> `NULL`：OBServerノードがオフラインになったことがない   </li><li> 有効値：OBServerノードの前回のオフライン時間</li></ul> <main id="notice" type='explain'><h4>説明</h4><p>このフィールドはV4.2.0から導入されました。</p></main>      |
