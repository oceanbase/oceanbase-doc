# oceanbase.CDB_OB_SS_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.1バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_SS_SPACE_USAGE` は、各テナントのオブジェクトストレージ上のストレージ容量使用状況を記録するために使用されます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは共有ストレージ(Shared-Storage, SS)モードでのみ適用されます。シェアードナッシング(Shared-Nothing, SN)モードでは、このビューのクエリ結果は空になります。</p>
</main>

## フィールドの説明

| フィールド名       | 型          | NULL許容      | 説明                                        |
|---------------|---------------|---------------------|----------------------------------------|
| TENANT_ID     | bigint(20)    | NO   | テナントID。     |
| TENANT_NAME   | varchar(128)  | NO   | テナント名。     |
| ENDPOINT      | varchar(128)  | NO   | 共有ストレージのEndpoint。      |
| PATH          | varchar(128)  | NO   | 共有ストレージのPath。      |
| STORAGE_TYPE  | varchar(32)   | NO   | ストレージタイプ：<ul><li>`Local All Bytes`：オブジェクトストレージ上のローカルディレクトリのすべてのデータ</li> <li>`Shared Data Bytes`：オブジェクトストレージ上のパブリックディレクトリのデータ</li> <li>`Shared Meta Bytes`：オブジェクトストレージ上のすべてのメタデータ</li></ul>    |
| VALUE         | bigint(20)    | NO   | `STORAGE_TYPE` に対応する容量使用量。単位はバイト。   |

## クエリ例

共有ストレージモードで、各テナントのオブジェクトストレージ上のストレージ容量使用状況を確認します。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_SS_SPACE_USAGE;
```
