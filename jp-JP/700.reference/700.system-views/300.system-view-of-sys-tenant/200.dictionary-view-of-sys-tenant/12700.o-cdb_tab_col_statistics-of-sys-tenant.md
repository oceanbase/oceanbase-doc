# oceanbase.CDB_TAB_COL_STATISTICS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナント内に、すべてのテナントの列統計情報とヒストグラム情報が表示されます。

## フィールド説明

|     フィールド名      |      型      | **NULL許容** |                                                               説明                                                               |
|---------------|--------------|----------------|--------------------------------------------------------------------------------------------------------------------------------|
| CON_ID        | bigint(20)   | NO             | テナントID                                       |
| OWNER         | varchar(128) | NO             | 列を所有するユーザー                                      |
| TABLE_NAME    | varchar(128) | NO             | 列を含むテーブル名                                      |
| COLUMN_NAME   | varchar(128) | NO             | 列名                                          |
| NUM_DISTINCT  | bigint(20)   | NO             | 列内の異なる値の数                                    |
| LOW_VALUE     | varchar(128) | NO             | 列の最小値                                       |
| HIGH_VALUE    | varchar(128) | NO             | 列の最大値                                       |
| DENSITY       | bigint(21)   | NO             | 列の密度                                        |
| NUM_NULLS     | bigint(20)   | NO             | 列内の`NULL`値の数                              |
| NUM_BUCKETS   | bigint(20)   | NO             | 列のヒストグラムにおけるバケット数                                   |
| LAST_ANALYZED | date         | NO             | 最終分析日時                                     |
| SAMPLE_SIZE   | bigint(20)   | NO             | 分析時のサンプリングサイズ                                    |
| GLOBAL_STATS  | varchar(3)   | NO             | <ul><li>`YES`：統計情報が直接収集されたか、増分でメンテナンスされたことを示す   </li><li> `NO`：その他の場合 </li></ul>   |
| USER_STATS    | varchar(3)   | NO             | パーティション統計情報がユーザー設定かどうか                              |
| NOTES         | varchar(80)  | NO             | 追加の属性を記録                                   |
| AVG_COL_LEN   | bigint(21)   | NO             | 列の平均長                                      |
| HISTOGRAM     | varchar(15)  | NO             | ヒストグラムのタイプ                                       |
| SCOPE         | varchar(7)   | NO             | 統計情報の有効範囲                                   |

## クエリ例

システムテナント内で、テナントIDが1004のテナントのテーブル`T2_M_LR`の列統計情報とヒストグラム情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_TAB_COL_STATISTICS WHERE CON_ID=1004 AND TABLE_NAME='T2_M_LR'\G
```
