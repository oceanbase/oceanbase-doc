# CDB_MVREF_CHANGE_STATS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_MVREF_CHANGE_STATS` は、マテリアライズドビューのリフレッシュに関連する統計情報を表示するために使用されます。これらの統計情報は、マテリアライズドビューがリフレッシュされるたびに、関連するベーステーブルでどれだけのデータが変更されたか、およびこれらの変更データをロードするために必要な情報量を示すために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| TBL_OWNER | varchar(128) | NO | ベーステーブル所有者名 |
| TBL_NAME | varchar(128) | NO | ベーステーブル名 |
| MV_OWNER | varchar(128) | NO | マテリアライズドビュー所有者名 |
| MV_NAME | varchar(128) | NO | マテリアライズドビュー名 |
| REFRESH_ID | bigint(20) | NO | リフレッシュID |
| NUM_ROWS_INS | bigint(20) | YES | insert行数 |
| NUM_ROWS_UPD | bigint(20) | YES | update行数 |
| NUM_ROWS_DEL | bigint(20) | YES | delete行数 |
| NUM_ROWS_DL_INS | bigint(1) | NO | direct load insert行数<main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値は0です。</p></main> |
| PMOPSOccurred | varchar(1) | NO | パーティションメンテナンス操作(PMOP)が発生したかどうかを示します。<ul><li>Y  </li><li>N </li><li>NULL </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はNです。</p></main> |
| PMOP_DETAILS | text | NO | PMOPの詳細情報は以下の形式で記述されます。<ul><li>TRUNCATE (low_bound, high_bound)  </li><li>EXECHANGE (low_bound, high_bound) </li></ul><main id="notice" type='explain'> <h4>説明</h4><p>このフィールドは互換性のみであり、デフォルト値はNULLです。</p></main> |
| NUM_ROWS | bigint(20) | YES | リフレッシュ操作開始時のベーステーブルの行数 |
