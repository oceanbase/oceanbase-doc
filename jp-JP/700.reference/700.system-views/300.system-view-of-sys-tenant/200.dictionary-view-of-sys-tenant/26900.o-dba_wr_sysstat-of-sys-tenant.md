# oceanbase.DBA_WR_SYSSTAT

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.2.1バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントのシステム統計項目の詳細情報を表示します。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | クラスタID |
| TENANT_ID | bigint(20) | NO | テナントID |
| SNAP_ID | bigint(20) | NO | スナップショットID |
| SVR_IP | varchar(46) | NO | ノードIPアドレス |
| SVR_PORT | bigint(20) | NO | ノードポート |
| STAT_ID | bigint(20) | NO | 統計ID |
| VALUE | bigint(20) | YES | 統計値 |

## クエリ例

このテナントのシステム統計項目の詳細情報を照会し、最初のレコードを表示します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_SYSSTAT LIMIT 1\G
```
