# oceanbase.DBA_OB_CLUSTER_EVENT_HISTORY

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.1.0バージョンから導入されました。</p>
</main>

## 機能の概要

システムテナントのみがアクセス可能なビュー`DBA_OB_CLUSTER_EVENT_HISTORY`は、クラスタレベルの重要イベントを表示するために使用されます。現在、クラスタのアップグレード関連イベントの表示のみをサポートしています。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TIMESTAMP | timestamp(6) | NO  | 作成日時 |
| MODULE  | varchar(256) | NO  | モジュール名 |
| EVENT   | varchar(256)  | NO  | イベント名 |
| NAME1   | varchar(256) | NO  | 最初のイベント属性名 |
| VALUE1  | text    | NO  | 最初のイベント属性値 |
| NAME2 | varchar(256) | NO  | 2番目のイベント属性名 |
| VALUE2 | text  | NO  | 2番目のイベント属性値 |
| NAME3 | varchar(256) | NO  | 3番目のイベント属性名 |
| VALUE3  | text | NO  | 3番目のイベント属性値 |
| NAME4 | varchar(256) | NO  | 4番目のイベント属性名 |
| VALUE4 | text | NO  | 4番目のイベント属性値 |
| NAME5 | varchar(256) | NO  | 5番目のイベント属性名 |
| VALUE5 | text | NO  | 5番目のイベント属性値 |
| NAME6  | varchar(256) | NO  | 6番目のイベント属性名 |
| VALUE6 | text | NO  | 6番目のイベント属性値 |
| EXTRA_INFO | text  | NO  | 追加情報 |

## クエリ例

クラスタレベルの重要イベントを照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_CLUSTER_EVENT_HISTORY \G
```
