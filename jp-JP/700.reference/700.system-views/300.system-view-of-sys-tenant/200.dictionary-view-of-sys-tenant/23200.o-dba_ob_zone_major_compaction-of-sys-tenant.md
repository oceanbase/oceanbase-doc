# oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナントの各ゾーンのコンパクション情報を表示します。

## フィールドの説明

|       フィールド名        |      タイプ      | NULL値を許容するか |         説明         |
|-------------------|--------------|------------|------------------|
| ZONE              | varchar(128) | NO         | ゾーン名            |
| BROADCAST_SCN | bigint(20) unsigned   | NO         | ブロードキャストされるコンパクションのバージョン番号           |
| LAST_SCN      | bigint(20) unsigned   | NO         | 前回のコンパクションのバージョン番号          |
| LAST_FINISH_TIME  | timestamp(6)   | NO         | 前回のコンパクション終了時間          |
| START_TIME        | timestamp(6)   | NO         | コンパクション開始時間             |
| STATUS            | varchar(10)  | NO         | <ul><li> `IDLE`：コンパクション中ではありません  </li><li>`COMPACTING`：コンパクション中です </li></ul>  |

## クエリ例

システムテナントが、自身の各ゾーンのコンパクション情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION;
```

クエリ結果は次のとおりです：

```shell
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| ZONE  | BROADCAST_SCN       | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| zone1 | 1736445603362416000 | 1736445603362416000 | 2025-01-10 02:02:17.252947 | 2025-01-10 02:00:03.403496 | IDLE   |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
1 row in set
```
