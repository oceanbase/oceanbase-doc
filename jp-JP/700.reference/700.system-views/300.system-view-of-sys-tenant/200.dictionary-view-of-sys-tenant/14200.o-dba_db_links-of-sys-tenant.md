# oceanbase.DBA_DB_LINKS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナントで作成されたすべてのDBLinkを表示します。

## フィールドの説明

| フィールド | タイプ | NULLか | 説明 |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | このDBLinkを作成したユーザー名 |
| DB_LINK | varchar(128) | NO | DBLink名 |
| USERNAME | varchar(128) | NO | DBLinkがリモートデータベースに接続するためのユーザー名 |
| CREDENTIAL_NAME | varchar(128) | NO | リモートデータベースへの接続に使用されるCredentials名。互換性のためのみ使用 |
| CREDENTIAL_OWNER | varchar(128) | NO | リモートデータベースへの接続に使用されるCredentialsの所有者。互換性のためのみ使用 |
| HOST | text | YES | DBLinkがリモートデータベースに接続するためのホスト名（IPアドレス） |
| CREATED | datetime | NO | DBLinkが作成された時間 |
| HIDDEN | varchar(3) | NO | 内部使用フィールド。互換性のためのみ使用 |
| SHARD_INTERNAL | varchar(3) | NO | DBLinkが共有接続をサポートしているかどうかを示すためのフィールド。ローカルデータベースとリモートデータベース間の接続数を削減するために使用されます。互換性のためのみ使用 |
| VALID | varchar(3) | NO | DBLinkが利用可能かどうかを示すためのフィールド。互換性のためのみ使用し、デフォルトはYESです |
| INTRA_CDB | varchar(3) | NO | 内部使用フィールド。互換性のためのみ使用 |
| TENANT_NAME | varchar(128) | NO | DBLinkがリモートデータベースに接続するためのテナント名 |
| DATABASE_NAME | varchar(128) | YES | DBLinkがリモートの指定されたデータベースに接続するための名前 |
| REVERSE_TENANT_NAME | varchar(128) | YES | 反転DBLinkがローカルデータベースに接続するためのテナント名 |
| CLUSTER_NAME | varchar(128) | YES | DBLinkがリモートデータベースに接続するためのクラスタ名 |
| REVERSE_CLUSTER_NAME | varchar(128) | YES | 反転DBLinkがローカル側のデータベースに接続するためのクラスタ名 |
| REVERSE_HOST | text | YES | 反転DBLinkがローカル側のデータベースに接続するためのホスト名（IPアドレス） |
| REVERSE_PORT |  bigint(20) | YES | 反転DBLinkがローカル側のデータベースに接続するためのポート番号 |
| REVERSE_USERNAME | VARCHAR2(128) | YES | 反転DBLinkがローカル側のデータベースに接続するためのユーザー名 |

## クエリ例
