# oceanbase.DBA_OB_SYS_VARIABLES

<main id="notice" type='explain'>
<h4>説明</h4>
<ul><li>V4.3.x系では、このビューはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このビューはV4.2.2バージョンから導入されました。</li></ul>
</main>

## 機能の概要

ビュー`DBA_OB_SYS_VARIABLES`は、現在のテナントのシステム変数（名前が"_"で始まる隠れた変数を含む）の設定を表示するために使用されます。

## フィールドの説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| -------- | -------- | --------------- | -------- |
| CREATE_TIME   | timestamp(6) | YES | 作成日時 |
| MODIFY_TIME   | timestamp(6) | YES | 変更日時 |
| NAME          | varchar(128) | NO | システム変数名 |
| VALUE         | varchar(65536) | YES | システム変数の現在値 |
| MIN_VALUE     | varchar(65536) | NO | 最小値 |
| MAX_VALUE     | varchar(65536) | NO | 最大値 |
| SCOPE         | varchar(16)    | NO | システム変数のスコープ |
| INFO          | varchar(4096)  | NO | 説明コメント |
| DEFAULT_VALUE | varchar(65536) | YES | システム変数のデフォルト値 |
| ISDEFAULT     | varchar(3)     | NO | デフォルト値かどうか |

## クエリ例
