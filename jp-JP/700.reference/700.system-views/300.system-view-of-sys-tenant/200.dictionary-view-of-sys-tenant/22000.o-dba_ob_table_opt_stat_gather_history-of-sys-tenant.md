# oceanbase.DBA_OB_TABLE_OPT_STAT_GATHER_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.2.0バージョンから導入されました。</p>
</main>

## 機能の概要

現在のテナント内のテーブルの履歴統計情報収集の実行状況を表示します。

## フィールド説明

| **フィールド** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | テーブル所有者名 |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TASK_ID | varchar(36) | NO | テーブル収集に属するタスクID |
| STATUS | varchar(8) | NO | 収集タスクの状態。<ul><li>SUCCESS   </li><li>FAILED  </li></ul>|
| START_TIME | datetime(6) | YES | 収集開始時刻 |
| END_TIME | datetime(6) | YES | 収集終了時刻 |
| MEMORY_USED | bigint(20) | YES | 収集で使用されたメモリ |
| STAT_REFRESH_FAILED_LIST | text | YES | 統計情報キャッシュのリフレッシュに失敗したリスト |
| PROPERTIES | text | YES | 属性設定 |

## クエリ例

このテナント内のテーブル `tbl1` の履歴統計情報収集の実行状況を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLE_OPT_STAT_GATHER_HISTORY WHERE TABLE_NAME='tbl1'\G
```
