# oceanbase.DBA_SCHEDULER_JOBS

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

このテナント内のすべてのスケジューラー作業に関する情報を表示します。

## フィールドの説明

| フィールド名 | タイプ | NULLを許容するか | 説明 |
| ------ | ------ | ------ | ------ |
| OWNER                         | varchar(128) | NO   | スケジューラーのジョブの所有者 |
| JOB_NAME                      | varchar(128) | NO   | スケジューラーのジョブ名 |
| JOB_SUBNAME                   | varchar(128) | NO   | スケジューラーのジョブのサブネーム |
| JOB_STYLE                     | varchar(17)  | YES  | ジョブスタイル：<ul><li>REGULAR：指定された時点でタスクを実行します。  </li><li>LIGHTWEIGHT：指定された時間間隔でタスクを実行します。 </li></ul> |
| JOB_CREATOR                   | varchar(128) | NO   | スケジューラーのジョブ作成者 |
| CLIENT_ID                     | varchar(65)  | NO   | ジョブを作成したユーザーのクライアント識別子 |
| GLOBALUid                    | varchar(33)  | NO   | ジョブを作成したユーザーのグローバルユーザー識別子 |
| PROGRAM_OWNER                 | text         | NO   | ジョブに関連するプログラムの所有者 |
| PROGRAM_NAME                  | text         | YES  | ジョブに関連するプログラム名 |
| JOB_TYPE                      | varchar(16)  | YES  | ジョブ操作タイプ：<ul><li>PLSQL_BLOCK  </li><li>STORED_PROCEDURE </li><li>EXECUTABLE </li><li>CHAIN </li></ul> |
| JOB_ACTION                    | text         | YES  | インラインジョブ操作 |
| NUMBER_OF_ARGUMENTS           | bigint(20)   | YES  | ジョブパラメータのインライン数 |
| SCHEDULE_OWNER                | text         | NO   | ジョブで使用される計画の所有者 |
| SCHEDULE_NAME                 | text         | NO   | ジョブで使用される計画名 |
| SCHEDULE_TYPE                 | varchar(12)  | NO   | ジョブで使用される計画タイプ：<ul><li>IMMEDIATE：開始日と繰り返し間隔がNULLです  </li><li>ONCE：繰り返し間隔がNULLです </li><li>PLSQL：PL/SQL式をタイムテーブルとして使用 </li><li>CALENDAR：カレンダー式をスケジュール表として使用</li><li>EVENT：イベントスケジュール </li><li>NAMED：命名タイムテーブル </li><li>WINDOW：タイムテーブルとして使用されるウィンドウ </li><li>WINDOW_GROUP：タイムテーブルとして使用されるウィンドウグループ </li></ul> |
| START_DATE                    | datetime(6)  | YES  | ジョブの元の計画開始日 |
| REPEAT_INTERVAL               | text         | YES  | インライン計画PL/SQL式またはカレンダー文字列 |
| EVENT_QUEUE_OWNER             | varchar(128) | NO   | イベントをトリガーするソースキューの所有者 |
| EVENT_QUEUE_NAME              | varchar(128) | NO   | イベントをトリガーするソースキューの名前 |
| EVENT_QUEUE_AGENT             | text         | NO   | ユーザーがイベントソースキューで使用するAQエージェントの名前 |
| EVENT_CONDITION               | text         | NO   | ソースキュー上のイベントのサブスクリプションルール |
| EVENT_RULE                    | varchar(261) | NO   | コーディネータがイベントベースのジョブをトリガーするために使用するルール名 |
| FILE_WATCHER_OWNER            | varchar(261) | NO   | このジョブが基づくファイルウォッチャーの所有者 |
| FILE_WATCHER_NAME             | varchar(261) | NO   | このジョブが基づくファイルウォッチャーの名前 |
| END_DATE                      | datetime(6)  | YES  | ジョブが実行されなくなる日付 |
| JOB_CLASS                     | varchar(128) | YES  | ジョブに関連付けられたジョブカテゴリの名前 |
| ENABLED                       | varchar(5)   | YES  | ジョブが有効かどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| AUTO_DROP                     | varchar(5)   | YES  | ジョブ完了後に削除されるかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul>  |
| RESTART_ON_RECOVERY           | varchar(5)   | NO   | クラスタ再起動時に、このジョブを再起動するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| RESTART_ON_FAILURE            | varchar(5)   | NO   | ジョブ実行失敗時に、このジョブを再起動するかどうかを示します。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| STATE                         | varchar(15)  | YES  | ジョブの現状：<li>DISABLED<li>RETRY SCHEDULED<li>SCHEDULED<li>BLOCKED<li>RUNNING<li>COMPLETED<li>BROKEN<li>FAILED<li>REMOTE<li>RESOURCE_UNAVAILABLE<li>SUCCEEDED<li>CHAIN_STALLED |
| JOB_PRIORITY                  | bigint(0)    | NO   | 同種の他のジョブに対するこのジョブの優先順位 |
| RUN_COUNT                     | bigint(20)   | YES  | ジョブが実行された回数 |
| MAX_RUNS                      | bigint(0)    | NO   | ジョブが計画されている最大実行回数 |
| FAILURE_COUNT                 | bigint(20)   | YES  | ジョブの実行失敗回数 |
| MAX_FAILURES                  | bigint(0)    | NO   | 破損としてマークされる前にジョブの失敗を許可する回数 |
| RETRY_COUNT                   | bigint(20)   | YES  | ジョブのリトライ回数 |
| LAST_START_DATE               | datetime(6)  | YES  | ジョブが実行を開始した最終日付 |
| LAST_RUN_DURATION             | bigint(20)   | YES  | 前回の実行期間中にジョブを完了するために費やされた時間 |
| NEXT_RUN_DATE                 | datetime(6)  | NO   | ジョブが計画されている次の実行日付 |
| SCHEDULE_LIMIT                | bigint(0)    | NO   | まだ実行されていないジョブが再スケジュールされる時間 |
| MAX_RUN_DURATION              | bigint(20)   | YES  | ジョブの実行に許可される最長時間 |
| LOGGING_LEVEL                 | varchar(11)  | NO   | ジョブ関連のログレコード：<ul><li>OFF  </li><li>RUNS </li><li>FAILED RUNS </li><li>FULL </li></ul> |
| STORE_OUTPUT                  | varchar(5)   | NO   | ジョブ実行の出力をデータベースに保存するか：<ul><li>TRUE  </li><li>FALSE </li></ul> |
| STOP_ON_WINDOW_CLOSE          | varchar(5)   | NO   | ジョブが属するスケジューリングウィンドウが閉じたとき、そのジョブの実行を停止するか：<ul><li>TRUE  </li><li>FALSE </li></ul> |
| INSTANCE_STICKINESS           | varchar(5)   | NO   | ジョブにインスタンス粘着性があるか：<ul><li>TRUE  </li><li>FALSE </li></ul> |
| RAISE_EVENTS                  | text         | NO   | この職位に関連する作業イベントリスト：<ul><li>JOB_STARTED  </li><li>JOB_SUCCEEDED </li><li>JOB_FAILED </li><li>JOB_BROKEN </li><li>JOB_COMPLETED </li><li>JOB_STOPPED </li><li>JOB_SCH_LIM_REACHED </li><li>JOB_DISABLED </li><li>JOB_chain_STALLED </li><li>JOB_OVER_MAX_DUR </li></ul> |
| SYSTEM                        | varchar(5)   | NO   | ジョブがシステムジョブであるかどうかを示す。<ul><li>TRUE  </li><li>FALSE </li></ul> |
| JOB_WEIGHT                    | bigint(0)    | NO   | ジョブの重み。スケジューリング時の優先順位を指定するために使用されます。 |
| NLS_ENV                       | text         | YES  | ジョブの国語環境設定。 |
| SOURCE                        | varchar(128) | NO   | ジョブのソースコードまたはスクリプト。 |
| NUMBER_OF_DESTINATIONS        | bigint(0)    | NO   | ジョブのターゲット数。 |
| DESTINATION_OWNER             | varchar(261) | NO   | ジョブターゲットの所有者。 |
| DESTINATION                   | varchar(261) | NO   | ジョブのターゲット、つまりジョブが実行する対象または場所。 |
| CREDENTIAL_OWNER              | varchar(128) | NO   | 認証情報の所有者。 |
| CREDENTIAL_NAME               | varchar(128) | NO   | 認証情報の名前。 |
| INSTANCE_ID                   | bigint(21)   | YES  | ユーザーがジョブの実行を要求したインスタンス |
| DEFERRED_DROP                 | varchar(5)   | NO   | ジョブの削除を遅延させるか。 |
| ALLOW_RUNS_IN_RESTRICTED_MODE | varchar(5)   | NO   | ジョブが制限モードでの実行を許可されているか。 |
| COMMENTS                      | text         | YES  | ジョブのコメントまたは説明情報。 |
| FLAGS                         | bigint(20)   | NO   | ジョブのフラグビット。 |
| RESTARTABLE                   | varchar(5)   | NO   | ジョブを再起動できるか。 |
| CONNECT_CREDENTIAL_OWNER      | varchar(128) | NO   | 接続資格の所有者。 |
| CONNECT_CREDENTIAL_NAME       | varchar(128) | NO   | 接続資格の名前。 |
