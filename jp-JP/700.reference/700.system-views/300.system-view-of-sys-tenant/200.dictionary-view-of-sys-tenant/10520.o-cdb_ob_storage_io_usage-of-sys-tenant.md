# oceanbase.CDB_OB_STORAGE_IO_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.3.4バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのオブジェクトストレージおよびクラウドディスクの各種I/O操作状況を表示します。

## フィールドの説明

| フィールド名   | 型          | NULL許容 | 説明                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | bigint(20)    | NO   | テナントID     |
| PATH      | varchar(1024) | NO   | `oss://`、`file://`、`s3://` などのパス形式    |
| ENDPOINT  | varchar(256)  | NO   | <ul><li>シェアードナッシング(Shared-Nothing, SN)モードでは、バックアップ・リストア、データインポート、データエクスポートのオブジェクトストレージのEndpointを表示します。</li> <li>シェアードストレージ(Shared-Storage, SS)モードでは、ログ(clog)またはデータ(Data)ストレージおよびバックアップ・リストア、データインポート、データエクスポートのオブジェクトストレージデバイスのEndpointを表示します。</li></ul> |
| TYPE      | varchar(128)  | NO   | 操作タイプ：<ul><li>`READ`：読み取りタイプ</li> <li>`WRITE`：書き込みタイプ</li> <li>`READ_BYTES`：オブジェクトストレージネットワーク入り口トラフィック</li> <li>`WRITE_BYTES`：オブジェクトストレージネットワーク出口トラフィック</li> <li>`TAG`：オブジェクトストレージ内のタグタイプ。ローカルディスクとクラウドディスクにはこのタイプは表示されません</li></ul>     |
| TOTAL     | bigint(20)    | NO   | 各タイプ(`TYPE`)に対応する累計値：<ul><li>`READ`：読み取りタイプ関連操作の回数の累計</li> <li>`WRITE`：書き込みタイプ関連操作の回数の累計</li> <li>`READ_BYTES`：オブジェクトストレージネットワーク入り口トラフィックの合計、単位はバイト</li> <li>`WRITE_BYTES`：オブジェクトストレージネットワーク出口トラフィックの合計、単位はバイト</li> <li>`TAG`：オブジェクトストレージ内のタグタイプの累計値。ローカルディスクとクラウドディスクにはこの統計項目は表示されません</li></ul>      |

## 関連ビューまたはドキュメント

現在のテナントのオブジェクトストレージおよびクラウドディスクの各種I/O操作状況を確認するには、[DBA_OB_STORAGE_IO_USAGE](21820.o-dba_ob_storage_io_usage-of-sys-tenant.md)を参照してください。
