# oceanbase.CDB_OB_BACKUP_DELETE_TASK_HISTORY

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

各テナント内で完了した`backup_set`/`backup_piece`クリーンアップタスクの履歴情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| TASK_ID | bigint(20) | NO | タスクグループID。一連のタスクを識別するために使用されます |
| INCARNATION | bigint(20) | NO | 分身ID |
| JOB_ID | bigint(20) | NO | タスクID。JOBテーブルに対応します |
| TASK_TYPE | varchar(64) | NO | タスクタイプ：<ul><li>`BACKUP SET`：`backup_set`のクリーンアップ </li><li>`BACKUP PIECE`：`backup_piece`のクリーンアップ </li></ul> |
| ID | bigint(20) | NO | タスクID。backup_set、pieceを含みます |
| ROUND_ID | bigint(20) | NO | pieceが属するdest_round_id。backup_setのクリーンアップの場合、ROUND_IDは0です |
| DEST_ID | bigint(20) | NO | バックアップ宛先のDEST_ID |
| START_TIMESTAMP | timestamp(6) | NO | タスク開始時間 |
| END_TIMESTAMP | timestamp(6) | NO | タスク終了時間 |
| STATUS | varchar(64) | NO | タスク状態：<ul><li>`COMPLETED`：タスクが正常に実行された </li><li>`FAILED`：タスクの実行に失敗しました </li><li>`CANCELED`：タスクがキャンセルされました </li></ul> |
| TOTAL_LS_COUNT | bigint(20) | YES | タスク内のログストリーム数 |
| FINISH_LS_COUNT | bigint(20) | YES | 成功したログストリームタスク数 |
| RESULT | bigint(20) | YES | エラーコード |
| COMMENT | varchar(4096) | YES | コメント |
| PATH | varchar(1024) | NO | backup_set/backup_pieceが属するバックアップ宛先 |

## クエリ例

システムテナントがすべてのテナントの完了した`backup_set`または`backup_piece`クリーンアップタスクの履歴情報を確認します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_TASK_HISTORY\G
```
