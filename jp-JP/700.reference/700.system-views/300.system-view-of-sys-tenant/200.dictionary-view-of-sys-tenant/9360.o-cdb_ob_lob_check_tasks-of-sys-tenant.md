# oceanbase.CDB_OB_LOB_CHECK_TASKS

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>このビューはV4.4.2バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `oceanbase.CDB_OB_LOB_CHECK_TASKS` は、システムテナントでLOB整合性チェックおよび整合性回復タスクのスキャン進捗状況を記録します。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
|--------------|-----------|---------------------|-----------|
| TENANT_ID | bigint(20) | NO | テナントID |
| LS_ID | bigint(20) | NO | ログストリームID |
| TABLE_NAME | varchar(256) | NO | テーブル名 |
| TABLE_ID | bigint(20) | NO | テーブルID |
| TABLET_ID | bigint(20) | NO | パーティションID |
| TASK_ID | bigint(20) | NO | 現在のバッチタスクのID |
| START_TIME | timestamp(6) | NO | タスク開始時間 |
| END_TIME | timestamp(6) | NO | タスク終了時間 |
| TRIGGER_TYPE | varchar(8) | NO | タスクをトリガーした主体（システムまたはユーザー） |
| STATUS | varchar(10) | NO | タスクの状態 <ul><li>LSレベルタスク状態：<ul><li>PREPARED：準備状態。データスキャンはまだ開始されていません。</li><li>RUNNING：実行中。メインテーブルまたは補助テーブルのデータをスキャンしています。</li><li>PENDING：一時停止状態。コマンドで実行を再開できます。</li><li>CANCELED：キャンセル状態。実行を再開できません。</li><li>FINISHED：完了状態。</li></ul></li><li>テナントレベルタスク状態：<ul><li>TRIGGERING：テナントのLOB整合性チェックまたは整合性回復タスクがトリガーされていることを示します。</li><li>SUSPENDING：テナントのLOB整合性チェックまたは整合性回復タスクの一時停止処理中であることを示します。</li><li>CANCELING：テナントのLOB整合性チェックまたは整合性回復タスクのキャンセル処理中であることを示します。</li><li>CLEANING：LOB整合性チェックまたは整合性回復タスクのレコードをクリーンアップしていることを示します。</li><li>INVALID：無効な状態。</li></ul></li></ul>|
| MISS_CNT | bigint(20) | NO | 整合性チェックのスキャンで検出された補助テーブルの欠落データ数 |
| MISMATCH_LEN_CNT | bigint(20) | NO | 整合性チェックのスキャンで検出されたメインテーブルと補助テーブルのbyte_lenが一致しないデータ数 |
| ORPHAN_CNT | bigint(20) | NO | 整合性チェックのスキャンで検出された補助テーブルの残留データ数 |
| CORRECT_CNT | bigint(20) | NO | 整合性回復で削除された補助テーブルの異常数 |
| RET_CODE | varchar(512) | NO | タスク終了時の状態 |
| TASK_TYPE | varchar(10) | NO | TTLタスクタイプ（"LOB_CHECK"または"LOB_CORRECT"） |
| TASK_SCOPE | varchar(6) | NO | タスクタイプ <ul><li>TENANT: テナントレベルタスク</li><li>LS：LSレベルタスク</li></ul> |
