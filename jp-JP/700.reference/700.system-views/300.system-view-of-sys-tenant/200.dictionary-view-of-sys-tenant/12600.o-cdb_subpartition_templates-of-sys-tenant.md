# oceanbase.CDB_SUBPARTITION_TEMPLATES

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのパーティションテーブルのテンプレートサブパーティション情報を表示します。

## フィールドの説明

|         フィールド名          |       型        | NULL許容 |    説明     |
|-----------------------|-----------------|------------|-----------|
| CON_ID                | decimal(10,0)   | NO         | テナントID     |
| USER_NAME             | varchar(128)    | NO         | パーティションテーブル所有者   |
| TABLE_NAME            | varchar(128)    | NO         | パーティションテーブル名      |
| SUBPARTITION_NAME     | varchar(132)    | NO         | サブパーティション名      |
| SUBPARTITION_POSITION | bigint(21)      | NO         | サブパーティション位置     |
| TABLESPACE_NAME       | varchar(30)     | NO         | パーティションが属するテーブルスペース名 |
| HIGH_BOUND            |  varchar(262144)       | NO         | パーティションテンプレート式   |
| COMPRESSION           | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内で新規作成される各複合パーティションのサブパーティションデータを圧縮形式で保存するかどうかを示します：<li>YES<li>NO <br>この値はサブパーティションテンプレート内で指定できます        |
| INDEXING              | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内で新規作成される各複合パーティションのサブパーティションデータを部分的なインデックスとして扱うかどうかを示します：<li>ON<li>OFF<br>この値はサブパーティションテンプレート内で指定できます          |
| READ_ONLY             | varchar(4)      | NO         | デフォルト値はNULLです。サブパーティションテンプレート内で新規作成される各複合パーティションのサブパーティションデータを読み取り専用にするかどうかを示します：<li>YES<li>NO<br>この値はサブパーティションテンプレート内で指定できます          |
