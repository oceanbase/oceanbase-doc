# CDB_INDEX_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.3.x系では、このビューはV4.3.0バージョンから導入されました。</li>
<li>V4.2.x系では、このビューはV4.2.3バージョンから導入されました。</li>
</ul>
</main>

## 機能の概要

`CDB_INDEX_USAGE` ビューは、インデックスの使用状況データ情報を表示するために使用されます。

## フィールドの説明

| **フィールド名** | **型** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | コンテナID（テナントID） |
| OBJECT_ID | bigint(20) | NO | インデックステーブルID |
| NAME | varchar(128) | NO | インデックステーブル名 |
| OWNER | varchar(128) | NO | データベース名 |
| TOTAL_ACCESS_COUNT | bigint(20) | NO | 総アクセス回数 |
| TOTAL_EXEC_COUNT | bigint(20) | NO | 総実行回数 |
| TOTAL_ROWS_RETURNED | bigint(20) | NO | 総戻されたインデックステーブル行数 |
| BUCKET_0_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用0回 |
| BUCKET_1_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用1回 |
| BUCKET_2_10_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用2～10回 |
| BUCKET_2_10_ROWS_RETURNED | bigint(20) | NO | インデックステーブル戻す2～10行 |
| BUCKET_11_100_ACCESS_COUNT | bigint(20) | NO | インデックステーブルアクセス11～100回 |
| BUCKET_11_100_ROWS_RETURNED | bigint(20) | NO | インデックステーブル戻す11～100行 |
| BUCKET_101_1000_ACCESS_COUNT | bigint(20) | NO | インデックステーブルアクセス101～1000回 |
| BUCKET_101_1000_ROWS_RETURNED | bigint(20) | NO | インデックステーブル戻す101～1000行 |
| BUCKET_1000_PLUS_ACCESS_COUNT | bigint(20) | NO | インデックステーブル使用1000回を超える |
| BUCKET_1000_PLUS_ROWS_RETURNED | bigint(20) | NO | インデックステーブル戻す1000行を超える |
| LAST_USED | varchar(128) | NO | インデックステーブル最終使用時間 |

## クエリ例

インデックスの使用状況データ情報を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_INDEX_USAGE;
```
