# CDB_INDEX_USAGE

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>V4.3.x系では、このビューはV4.3.0から導入されました。</li>
<li>V4.2.x系では、このビューはV4.2.3から導入されました。</li>
</ul>
</main>

## 機能の概要

`CDB_INDEX_USAGE`ビューは、インデックスの使用状況データを表示するために使用されます。

## フィールドの説明

| **フィールド名** | **タイプ** | **NULL許容** | **説明** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | コンテナID（テナントID） |
| OBJECT_ID | bigint(20) | NO | インデックス対象テーブルID |
| NAME | varchar(128) | NO | インデックス対象テーブル名 |
| OWNER | varchar(128) | NO | データベース名 |
| TOTAL_ACCESS_COUNT | bigint(20) | NO | 総アクセス回数 |
| TOTAL_EXEC_COUNT | bigint(20) | NO | 総実行回数 |
| TOTAL_ROWS_RETURNED | bigint(20) | NO | 総戻り行数 |
| BUCKET_0_ACCESS_COUNT | bigint(20) | NO | インデックス表使用0回 |
| BUCKET_1_ACCESS_COUNT | bigint(20) | NO | インデックス表使用1回 |
| BUCKET_2_10_ACCESS_COUNT | bigint(20) | NO | インデックス表使用2～10回 |
| BUCKET_2_10_ROWS_RETURNED | bigint(20) | NO | インデックス表戻り行数2～10行 |
| BUCKET_11_100_ACCESS_COUNT | bigint(20) | NO | インデックス表アクセス11～100回 |
| BUCKET_11_100_ROWS_RETURNED | bigint(20) | NO | インデックス表戻り行数11～100行 |
| BUCKET_101_1000_ACCESS_COUNT | bigint(20) | NO | インデックス表アクセス101～1000回 |
| BUCKET_101_1000_ROWS_RETURNED | bigint(20) | NO | インデックス表戻り行数101～1000行 |
| BUCKET_1000_PLUS_ACCESS_COUNT | bigint(20) | NO | インデックス表使用1000回超 |
| BUCKET_1000_PLUS_ROWS_RETURNED | bigint(20) | NO | インデックス表戻り行数1000行超 |
| LAST_USED | varchar(128) | NO | インデックス表最終使用日時 |

## クエリ例

インデックスの使用状況データを照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_INDEX_USAGE;
```
