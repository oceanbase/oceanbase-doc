# oceanbase.DBA_RSRC_PLANS

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューは、V3.1.2バージョンから導入されました。</p>
</main>

## 機能の概要

システムで定義されたすべてのリソース管理計画を表示します。

## フィールドの説明

|           フィールド名            |       タイプ       | NULLを許容するか |                         説明                         |
|---------------------------|----------------|------------|----------------------------------------------------|
| PLAN_ID                   | decimal(10,0)         | NO         | リソース計画のID                                          |
| PLAN                      | varchar(128)  | NO         | リソース計画名                                             |
| NUM_PLAN_DIRECTIVES       | decimal(10,0)         | NO         | 現在のリソース計画で定義されている指示数。互換性のためにのみ使用され、現在の値は固定されており`NULL`です |
| CPU_METHOD                | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| MGMT_METHOD               | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| ACTIVE_SESS_POOL_MTH      | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| PARALLEL_DEGREE_LIMIT_MTH | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| QUEUING_MTH               | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| SUB_PLAN                  | varchar(3)    | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| COMMENTS                  | varchar(2000) | YES        | リソース計画の備考情報                                         |
| STATUS                    | varchar(128)  | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |
| MANDATORY                 | varchar(3)    | NO         | 互換性のためにのみ使用され、現在の値は固定されており`NULL`です                               |

## クエリ例

システムテナントは、システムで定義されたすべてのリソース管理計画を照会します。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_PLANS;
```

```shell
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
|    NULL | daytime |                NULL | NULL       | NULL        | NULL                 | NULL                      | NULL        | NULL     | TPFirst  | NULL   | NULL      |
+---------+---------+---------------------+------------+-------------+----------------------+---------------------------+-------------+----------+----------+--------+-----------+
1 row in set
```
