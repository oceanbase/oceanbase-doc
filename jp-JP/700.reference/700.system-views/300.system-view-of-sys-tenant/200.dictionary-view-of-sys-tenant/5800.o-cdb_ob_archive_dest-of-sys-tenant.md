# oceanbase.CDB_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>説明</h4>
<p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

すべてのテナントのアーカイブパス設定情報を表示します。

## フィールドの説明

| フィールド名 | 型 | NULL許容 | 説明 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | テナントID |
| DEST_NO | bigint(20) | NO | log_archive_dest_nを識別するための番号 |
| NAME | varchar(1024) | NO | フィールド名。<ul><li>`binding`: アーカイブと業務の優先モード</li> <li>`dest_id`: アーカイブ宛先のID</li> <li>`path`: アーカイブパス情報</li> <li>`piece_switch_interval`: Pieceの切り替え間隔</li> <li>`state`: アーカイブ宛先の状態</li></ul> |
| VALUE | varchar(4096) | NO | `name`フィールドに対応するフィールド値 |

## クエリ例

システムテナントで、すべてのテナントのアーカイブパス設定情報を確認します。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_ARCHIVE_DEST;
```

クエリ結果は次のとおりです：

```shell

|      1002 |       0 | piece_switch_interval | 1d                                                                                                                            |

5 rows in set
```
