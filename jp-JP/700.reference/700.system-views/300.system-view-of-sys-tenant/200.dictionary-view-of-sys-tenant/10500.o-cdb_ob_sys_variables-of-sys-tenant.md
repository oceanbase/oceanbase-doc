# oceanbase.CDB_OB_SYS_VARIABLES

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このビューはV4.0.0バージョンから導入されました。</p>
</main>

## 機能の概要

ビュー `CDB_OB_SYS_VARIABLES` は、すべてのテナントのシステム変数（名前が「_」で始まる隠れた変数を含む）の情報を表示します。

## フィールド説明

| フィールド名 | 型 | NULL許容 | 説明 |
| ------- | ---- | -------------- | ---- |
| CREATE_TIME | timestamp(6)   | NO | システム変数の作成日時   |
| MODIFY_TIME | timestamp(6)   | NO | システム変数の変更日時  |
| TENANT_ID   | bigint(20)     | NO | テナントID |
| NAME        | varchar(128)   | NO | システム変数名 |
| VALUE       | varchar(65536) | YES | システム変数値 |
| MIN_VALUE   | varchar(65536) | NO | 最小値 |
| MAX_VALUE   | varchar(65536) | NO | 最大値 |
| SCOPE       | varchar(16)    | NO | 意味域。値は以下のとおりです。<ul><li>GLOBAL_ONLY：テナントレベル変数</li><li>SESSION_ONLY：セッションレベル変数</li><li>GLOBAL &#124; SESSION：テナントレベルおよびセッションレベル変数</li></ul>  |
| INFO        | varchar(4096)    | NO | 説明情報 |
| DEFAULT_VALUE | varchar(65536) | YES | システム変数のデフォルト値<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li></ul></main>|
| ISDEFAULT   | varchar(3)       | NO  |  デフォルト値かどうか<main id="notice" type='explain'><h4>説明</h4><ul><li>V4.3.x系では、このフィールドはV4.3.1バージョンから導入されました。</li><li>V4.2.x系では、このフィールドはV4.2.2バージョンから導入されました。</li></ul></main> |
