# 9000～9499

この範囲は、バックアップ・リカバリエラーコードおよびSTORAGE 3.0エラーコードを示します。

## ERROR 9001 (HY000) : URI error

* OceanBaseエラーコード：9001

* エラーの原因：バックアップ復旧設定のターゲットリンクが誤っている可能性があります。

* 解決策：バックアップ復旧に関する設定を確認し、修正してください。

## ERROR 9002 (HY000) : OSS file MD5 error

* OceanBaseエラーコード：9002

* エラーの原因：OSSファイルのデータ検証に誤りがあり、OSS上のデータに異常が発生している可能性があります。

* 解決策：OSSテクニカルサポートに連絡し、具体的な原因を調査してください。

## ERROR 9003 (HY000) : OSS error

* OceanBaseエラーコード：9003

* エラーの原因：OSSで未知のエラーが発生しました。

* 解決策：OSSテクニカルサポートに連絡し、具体的な原因を調査してください。

関連する問題例：

* [バックアップパスの設定に失敗し、エラーメッセージとしてOSS errorが表示された場合](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000208059)
* [バックアップ復旧に失敗し、テナントが復旧中のままになった場合](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000340640)

## ERROR 9004 (HY000) : Init MD5 fail

* OceanBaseエラーコード：9004

* エラーの原因：OpenSSL初期化時にMD5エラーが発生しました。

* 解決策：OceanBaseテクニカルサポートに連絡し、調査を依頼してください。

## ERROR 9005 (HY000) : Out of element

* OceanBaseエラーコード：9005

* エラーの原因：シャードの制限を超えています。

* 解決策：OceanBaseテクニカルサポートに連絡し、調査を依頼してください。

## ERROR 9006 (HY000) : Update MD5 fail

* OceanBaseエラーコード：9006

* エラーの原因：MD5の更新に失敗しました。

* 解決策：OceanBaseテクニカルサポートに連絡し、調査を依頼してください。

## ERROR 9007 (HY000) : Invalid OSS file length

* OceanBaseエラーコード：9007

* エラーの原因：無効なOSSファイル長。誤ったOSSファイルである可能性があります。

* 解決策：OceanBaseテクニカルサポートに連絡し、調査を依頼してください。

## ERROR 9010 (HY000) : OSS file MD5 not match

* OceanBaseエラーコード：9010

* エラーの原因：OSSファイルの検証と照合が一致しません。OSSのデータ異常またはバックアップ復旧プログラムのバグが原因である可能性があります。

* 解決策：OceanBaseテクニカルサポートに連絡し、調査を依頼してください。

## ERROR 9011 (HY000) : cannot find backup file

* OceanBaseエラーコード：9011

* エラーの原因：バックアップファイルが見つかりません。指定されたバックアップ復旧設定に誤りがある可能性があります。

* 解決策：バックアップ復旧に関する設定を確認し、修正してください。

関連する問題例：

* [リモート復旧時にバックアップオブジェクトを特定の時間点に復旧できないというエラーが表示された場合](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000208064)

## ERROR 9012 (HY000) : Can not get data version from timestamp

* OceanBaseエラーコード：9012

* エラーの原因：論理復旧のパラメータに`data version`が渡されていません。

* 解決策：OceanBaseテクニカルサポートに連絡し、調査を依頼してください。

## ERROR 9013 (HY000) : Write OSS file error

## ERROR 9014 (HY000) : Another restore is in progress

## ERROR 9016 (HY000) : ob cluster name not equal

## ERROR 9023 (HY000) : cannot start log archive backup

## ERROR 9024 (HY000) : log archive backup is already disabled

関連するケース：

## ERROR 9033 (HY000) : Backup meta info stored in system dictionary does not match with current system status

* OceanBaseエラーコード：9033

* エラーの原因：バックアップの状態が一致しません。

* 解決策：

  * OBServerノードのログアーカイブでエラーが発生した場合、通常はログアーカイブの開始または停止時に発生します。人の介入は不要です。

  * Root Serviceのログについては、OceanBaseテクニカルサポートにお問い合わせください。具体的な原因を調査します。

## ERROR 9035 (HY000) : restore index failed

* OceanBaseエラーコード：9035

* 解決策：復元テナント内のテーブルのロックインデックスが`error`のインデックスを確認し、そのインデックスを再作成する必要があります。

## ERROR 9036 (HY000) : Backup is in progress

* OceanBaseエラーコード：9036

* エラーの原因：一般的には、バックアップと排他的な操作が実行されたためです。

* 解決策：データバックアップとログアーカイブを停止してから、このコマンドを実行してください。

## ERROR 9037 (HY000) : log archive status is not valid

## ERROR 9038 (HY000) : Cannot add replica during set member list in restore

* OceanBaseエラーコード：9038

* エラーの原因：`set member list`フェーズではレプリケーションがサポートされていません。

* 解決策：復元の`set member list`ステップではレプリカの複製をサポートできません。この時点で多数派のレプリカが残っている場合、復元は続行可能です。多数派のレプリカが存在しなくなっている場合は、復元をキャンセルして復元タスクを再スケジュールする必要があります。

## ERROR 9039 (HY000) : pg log archive leader changed

* OceanBaseエラーコード：9039

* エラーの原因：ログアーカイブのリーダーが切り替わりました。

* 解決策：内部エラーコードです。リーダーの切り替えが検出されると、現在のPGのログアーカイブプロセスが中断されます。新しいリーダーは自動的にバックアップ作業を再開するため、運用保守の介入は不要です。

## ERROR 9040 (HY000) : backup can not start

* OceanBaseエラーコード：9040

* エラーの原因：ログアーカイブが`DOING`状態でないため、データバックアップを開始できません。

* 解決策：ログアーカイブが`DOING`状態になるまで待機してください。長期間`BEGINNING`状態が続く場合は、OceanBaseテクニカルサポートにお問い合わせください。具体的な原因を調査します。
