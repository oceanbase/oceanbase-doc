## ERROR 1210 (HY000) : Incorrect arguments to %s

* OceanBase エラーコード：4002

* MySQL互換エラーコード：1210

* 原因：

  このエラーが発生する原因として、以下のいずれかが考えられます。

  * サーバーの形式が正しくありません。
  * `data_source` の形式が正しくありません。
  * 提供された `paxos_replica_num` が0以下です。
  * `paxos_replica_num` とレプリカ数が多数決を満たしていません。
  * `paxos_replica_num` がメンバー数より少ないです。
  * `paxos_replica_num` の変化量は絶対値で1を超えてはなりません。
  * `paxos_replica_num` は変更されないでください。
  * 提供された `paxos_replica_num` は現在の `paxos_replica_num` よりも小さくなければなりません。

* 解決策：該当するビジネスシナリオに応じて処理するか、サポートチームに連絡してトラブルシューティングを依頼してください。
