* OceanBaseエラーコード：4002

* エラーの原因：

  このエラーメッセージが表示される原因は、以下のいずれかの可能性があります：

  * Serverの形式が正しくありません。
  * `data_source` の形式が正しくありません。
  * 提供された `paxos_replica_num` が 0 以下です。
  * `paxos_replica_num` とレプリカ数が過半数を満たしていません。
  * `paxos_replica_num < member list` の数です。

  * `paxos_replica_num` は変更されないようにする必要があります。

* 解決策：該当するビジネスシナリオに基づいて処理するか、テクニカルサポート担当者に連絡し、調査を支援してください。
