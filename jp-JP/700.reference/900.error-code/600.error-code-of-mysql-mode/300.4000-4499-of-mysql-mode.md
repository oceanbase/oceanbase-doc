## ERROR 4017 (HY000) : Entry already exist

* OceanBaseエラーコード：4017

* エラーの原因：

  このエラーメッセージが表示される原因は、以下のいずれかの可能性があります：

  * 現在のログストリームにはディザスタリカバリタスクが実行中であり、パラレル処理できません。
  * Server上に既にログストリームのレプリカが存在します。
  * Server上のこのログストリームのレプリカとターゲットタイプが同じです。
  * Destination Server上には既にレプリカが存在します。

* 解決策：対応するビジネスシナリオに基づいて処理するか、テクニカルサポート担当者に連絡して調査を支援してください。

## ERROR 4179 (HY000) : %s not allowed

* OceanBaseエラーコード：4179

* エラーの原因：

  このエラーメッセージが表示される原因は、以下のいずれかの可能性があります：

  * 現在のログストリームの状態では操作が許可されていません。
  * タスクを実行するServerの状態が異常です。
  * メンバーリストの上限に達しました。
  * 提供されたデータソースにはそのログストリームのレプリカが存在しません。
  * データソース側のServerがAlive状態ではありません。
  * データソース側のServerがStop状態です。
  * RレプリカはFレプリカのデータソースとして使用できません。
  * データソース側のレプリカのRestoreに失敗しました。
  * このレプリカを削除すると、プライマリがなくなります。
  * ソースとターゲットが同一ゾーンにありません。
  * 同型ゾーンモードでは、リソースプールの`UNIT_NUM`を変更してスケーリングアップ/ダウンを行うことはサポートされていません。
  * 同型ゾーンモードでは、各リソースプールの`UNIT_NUM`が異なります。各リソースプールの`UNIT_NUM`は同じである必要があります。
  * 異種ゾーンモードでは、テナント内の各リソースプールの`UNIT_NUM`が2種類を超えています。1つのテナント内のすべてのリソースプールの`UNIT_NUM`は最大2種類である必要があります。
  * `UNIT_NUM`のスケーリングアップ/ダウンプロセスが終了するまで、ロールバック操作を実行しない限り、`UNIT_NUM`を他の値に変更することは禁止されています。
  * `UNIT_NUM`のスケーリングアップ/ダウンプロセス中は、テナントのローカリティを変更することは禁止されています。
  * `UNIT_NUM`のスケーリングアップ/ダウンプロセス中は、テナントリソースプールの`ZONE_LIST`範囲を拡大することは禁止されています。
  * `UNIT_NUM`のスケーリングアップ/ダウンプロセス中は、テナントに新しいリソースプールを追加することは禁止されています。
  * `UNIT_NUM`のスケーリングアップ/ダウンプロセス中は、リソースプールのメジャーコンパクションを行うことは禁止されています。
  * `UNIT_NUM`のスケーリングアップ/ダウンプロセス中は、`DELETING`状態のユニットを移行することは禁止されています。
  * GTS専有が有効になっており、テナント内の各ゾーンの`UNIT_NUM`は2未満にすることができません。GTS専有が有効になっている場合、テナント内の各ゾーンの`UNIT_NUM`は2以上である必要があります。
  * GTS専有が有効になっており、GTS専有のユニットまたはユニットグループを削除することは許可されていません。

* 解決策：対応するビジネスシナリオに基づいて処理するか、技術サポート担当者に連絡して調査を依頼してください。
