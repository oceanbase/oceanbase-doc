## ERROR 4179 (HY000) : %s not allowed

* OceanBase エラーコード：4179

* エラーの原因：サポートされていない機能です。

  このエラーメッセージが表示される原因は、以下の可能性があります：

  * 現在のログストリームの状態では操作を許可できません。

  * タスクを実行しているサーバーの状態が異常です。

  * メンバーリストの上限数に達しました。

  * 提供されたデータソースにそのログストリームのレプリカが存在しません。

  * データソース側のサーバーがAlive状態ではありません。

  * データソース側のサーバーがStop状態です。

  * RレプリカはFレプリカのデータソースとして使用できません。

  * データソース側のレプリカのRestoreに失敗しました。

  * このレプリカを削除するとホストレス状態になります。

  * ソースとターゲットが同一ゾーンにありません。

  * 同一ゾーンモードでは、リソースプールの`UNIT_NUM`を変更してスケーリングを行うことはサポートされていません。

  * 同一ゾーンモードでは、各リソースプールの`UNIT_NUM`が異なります。すべてのリソースプールの`UNIT_NUM`は同じである必要があります。

  * 異種ゾーンモードでは、テナント内の各リソースプールの`UNIT_NUM`が2種類を超えています。テナント内のすべてのリソースプールの`UNIT_NUM`は最大2種類である必要があります。

  * `UNIT_NUM`のスケーリング処理終了前に、ロールバック操作を実行しない限り、`UNIT_NUM`を他の値に変更することは禁止されています。

  * `UNIT_NUM`のスケーリング処理中は、テナントのローカリティを変更することは禁止されています。

  * `UNIT_NUM`のスケーリング処理中は、テナントのリソースプールの`ZONE_LIST`範囲を拡大することは禁止されています。

  * `UNIT_NUM`のスケーリング処理中は、テナントに新しいリソースプールを追加することは禁止されています。

  * `UNIT_NUM`のスケーリング処理中は、リソースプールのメジャーコンパクションを行うことは禁止されています。

  * `UNIT_NUM`のスケーリング処理中は、`DELETING`状態のUnitを移行することは禁止されています。

  * GTS専有が有効な場合、テナント内の各ゾーンの`UNIT_NUM`は2未満にできません。GTS専有が有効な場合、テナント内の各ゾーンの`UNIT_NUM`は2以上である必要があります。

  * GTS専有が有効な場合、GTS専有のUnitまたはUnitグループの削除を指定することは許可されません。

* 解決策：対応するビジネスシナリオに基づいて処理するか、技術サポートに連絡して調査を依頼してください。
