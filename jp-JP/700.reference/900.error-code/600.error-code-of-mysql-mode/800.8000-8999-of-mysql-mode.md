# 8000 ~ 8999

この範囲は重大なエラーのエラーコードを示します。クライアントが8xxxエラーを受信した場合、SQL接続を閉じる必要があります。

## ERROR 8001 (08004) : Server is initializing

* OceanBase エラーコード：8001

* エラー原因：OBServerノードの起動中にRPCリクエストを受信しました。

* 解決策：OBServerノードの再起動完了を待ちます。

## ERROR 8002 (08004) : Server is stopping

* OceanBase エラーコード：8002

* エラー原因：OBServerノードの終了中にRPCリクエストを受信しました。

* 解決策：OBServerノードが正常に終了するのを待ちます。または、`kill -9` を実行してobserverプロセスを強制終了します。

## ERROR 8003 (08004) : Packet checksum error

* OceanBase エラーコード：8003

* エラー原因：OBServerノードがRPCパケットの `checksum` 検証に失敗しました。一般的な原因はバージョン互換性の問題です。

* 解決策：テクニカルサポートにお問い合わせいただき、調査をご依頼ください。

## ERROR 8004 (08004) : Packet cluster_id not match

* OceanBase エラーコード：8004

* エラー原因：OBServerノードが受信したRPCの `cluster_id` が予期されていません。一般的な原因は、別のOceanBaseクラスタのServerが本クラスタに接続されたことです。

* 解決策：別のクラスタのOBServerノードが誤って本クラスタに接続された場合、これはデプロイメントエラーであり、誤ってデプロイされたクラスタを速やかに停止する必要があります。その他の原因の場合は、テクニカルサポートにお問い合わせいただき、調査をご依頼ください。

## ERROR 8005(08005) : Tenant id not match

* OceanBase エラーコード：8005
* エラー原因：Proxy接続を介してSQLを実行する過程で、テナント名が変更されました。
* 解決策：テナント名を変更する前にProxy接続を切断し、変更後に再接続することを推奨します。
