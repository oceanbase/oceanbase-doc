## ERROR 11032 (HY000) : HDFS path message %s

* OceanBase エラーコード：11032

* エラー原因：HDFS でパスが見つかりません。

* 解決策：

  1. Kerberos 認証のキートップとプリンシパルが有効であり、対応するユーザーが HDFS クラスタへのアクセス権限を持っていることを確認します。外部テーブルの権限を再設定し、Kerberos 認証を設定します。

  2. 対応する HDFS パスが正しく存在することを確認し、外部テーブルの HDFS パスマッピングを再構築します。

  3. お客様の運用保守チームにフィードバックし、データの破損ブロック状況を確認した上で、破損ブロックの調整または環境の変更による検証を続けることができます。

## ERROR 11056 (HY000) : jvm.so not found %s

* OceanBase エラーコード：11056

* エラー原因：JNI Env 環境の初期化に失敗しました。

* 解決策：

  1. 現在の `java home` 設定が存在するか手動で確認し、特に現在のユーザーがそのパスへのアクセス権限を持っているかを検証します。`java home` は存在するものの、OBServer の起動ユーザーにそのパスへのアクセス権限がない場合があります。

  2. [ob_java_opts](../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/16650.ob_java_opts.md) を参照し、`ob_java_opts` に必要な項目が欠落していないか確認します。

  3. `_ob_additional_lib_path` 設定パスが存在するか、および OBServer の起動ユーザーがそのパスへのアクセス権限を持っているかを確認します。
