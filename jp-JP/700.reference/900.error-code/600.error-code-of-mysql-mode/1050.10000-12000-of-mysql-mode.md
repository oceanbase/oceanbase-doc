# 10000～12000

この範囲には、OBProxy関連エラーコード、OBShardingエラーコード、OBKVエラーコード、クライアントエラーコードなどが含まれます。

## ERROR 10501 (HY000) : TTL feature is not enabled

* OceanBaseエラーコード：10501

* エラーの原因：TTL機能が有効になっていません。

* 解決策：TTL機能が正しく有効になっていることを確認してください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このエラーコードはV4.2.2バージョンから導入されました。</p>
</main>

## ERROR 10502 (HY000) : TTL column '%.*s' not exists

* OceanBaseエラーコード：10502

* 解決策：指定されたTTL列がデータベーステーブルに存在するかどうか確認してください。

## ERROR 10504 (HY000) : TTL command is not allowed, current TTL status is '%s'

* OceanBaseエラーコード：10504

* エラーの原因：現在のTTLステータスが特定の値であるため、TTLコマンドの実行は許可されません。

* 解決策：現在のステータスが期待どおりであるか確認し、適切なTTLコマンドを使用してステータスを切り替えてください。

  <h4>説明</h4>
  <p>このエラーコードはV4.2.2バージョンから導入されました。</p>

## ERROR 10507 (HY000) : Time to live of hbase table must be greater than 0

* 解決策：現在のテーブルの `KV_ATTRIBUTES` プロパティを確認し、定義されたTimeToLiveが0より大きいことを確認してください。

## ERROR 10518 (HY000) : Check failed in %.*s

* OceanBaseエラーコード：10518

* エラーの原因：checkAndInsUpインターフェースでパラメータ`rollbackWhenCheckFailed`が`true`に設定されており、今回のチェックに失敗しました。

* 解決策：このエラーが返された場合はCASに失敗したことを意味します。業務側は実際の状況に応じてこのエラーを処理します。

  <h4>説明</h4>
  <p>このエラーコードはV4.2.5 BP4バージョンから導入されました。</p>
</main>
