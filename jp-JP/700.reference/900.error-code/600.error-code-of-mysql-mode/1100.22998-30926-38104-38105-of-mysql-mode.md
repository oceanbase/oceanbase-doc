# 22998、30926、38104、38105

この範囲はBLOB/CLOBエラーコードを表します。

## ERROR 22998 (HY000) : CLOB or NCLOB in multibyte character set not supported

* OceanBase エラーコード：22998

* エラーの原因：SQL文字列関数は `CLOB`、`NCLOB` 型をサポートしていません。

* 解決策：`DBMS_LOG` パッケージの関連関数を使用してください。

## ERROR 30926 (HY000) : unable to get a stable set of rows in the source tables

* OceanBase エラーコード：30926

* エラーの原因：DMLに非決定的な `WHERE` 条件が存在するため、安定した行セットを生成できません。

* 解決策：非決定的な条件を削除し、DMLステートメントを再実行してください。

## ERROR 38104 (HY000) : Columns referenced in the ON Clause cannot be updated:'%.\*s'.'%.\*s'

* OceanBase エラーコード：38104

* エラーの原因：`ON` 条件で参照されている列は更新できません。

## ERROR 38105 (HY000) : specified row no longer exists

* OceanBase エラーコード：38105

* エラーの原因：操作の実行開始後、該当する行が他のユーザーによって削除されました。

* 解決策：他のデータ行を処理するため、その操作を再実行してください。
