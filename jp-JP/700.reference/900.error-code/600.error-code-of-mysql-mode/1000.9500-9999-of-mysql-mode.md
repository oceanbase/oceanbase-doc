## ERROR 9502 (HY000) : OUT and IN/OUT modes cannot be used in this context

* OceanBaseエラーコード：9502

* エラーの原因：動的ステートメントのDMLステートメントに`returning`変数が含まれ、かつ外部に`INTO`変数がない場合にのみ、`OUT`パラメータを使用できます。

* 解決策：動的ステートメントで`OUT`パラメータを使用する際の書式が規範に適合しているか確認します。
