# 4500 ～ 4999

このエラーコード範囲はRoot Serviceのエラーコードを示します。

## ERROR 4507 (42000) : Convert error

* OceanBase エラーコード：4507

* エラーの原因：IPアドレスを文字列に出力しようとした際のエラーです。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせください。

## ERROR 4512 (HY000) : RootServer state error

* OceanBase エラーコード：4512

* エラーの原因：現在のRootServerの状態では、この操作を実行できません。

* 解決策：RootServerの現在の状態を確認してください。`__all_virtual_core_meta_table` テーブルをクエリすることで、RootServerがオンラインかどうかを判断できます。

## ERROR 4515 (HY000) : No replica is valid

* OceanBase エラーコード：4515

* エラーの原因：レプリカの状態が正しくありません。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせください。

## ERROR 4519 (HY000) : Iteration was stopped

* OceanBase エラーコード：4519

* エラーの原因：エラーコードではありません。MemTableの反復処理が終了したことを示します。

* 解決策：特に対処は不要です。

## ERROR 4530 (HY000) : Zone info \\'%s\\' not exist

* OceanBase エラーコード：4530

* エラーの原因：指定されたZoneが存在しません。通常は指定されたZoneでのメジャーコンパクション中、またはリーダー切り替え時の報告エラーです。

* 解決策：指定されたZoneが存在するかどうかを確認してください。`DBA_OB_ZONES` テーブルをクエリすることで解決できます。

## ERROR 4544 (42000) : Root not integrated

* OceanBase エラーコード：4544

* エラーの原因：ローテーションコンパクションの過程で、各パーティションのレプリカ数が多数派に達しているかどうかをチェックします。レプリカ数が多数派に満たないパーティションに対してこのエラーが報告されます。

* 解決策：直ちに人為的介入が必要です。そのパーティションが多数派を失った原因を調査してください。

## ERROR 4547 (HY000) : global merge not started

* OceanBase エラーコード：4547

* エラー原因：手動でのローテーションメジャーコンパクションを実行する前の事前検証において、クラスタがMajor Freezeを開始したことがない場合、手動メジャーコンパクションを開始できません。

* 解決策：クラスタがMajor Freezeを開始したことがあるかどうか確認します。

## ERROR 4548 (HY000) : merge already started

* OceanBase エラーコード：4548

* エラー原因：手動でのローテーションメジャーコンパクションを実行する前の事前検証において、特定のZoneで既に手動メジャーコンパクションが開始されている場合、そのZoneで再度手動メジャーコンパクションを開始できません。

* 解決策：そのZoneで既に手動メジャーコンパクションが開始されているかどうか確認します。

## ERROR 4549 (HY000) : rootservice already exist

* OceanBase エラーコード：4549

* エラー原因：現在のRS起動時の自己検査において、他のレプリカが既にRSである場合、現在のRSは前任者を辞任します。

* 解決策：RS起動前の自己検証であり、処理は不要です。

## ERROR 4550 (HY000) : rootservice is shutdown

* OceanBase エラーコード：4550

* エラー原因：リクエストが送信されたRSレプリカが非稼働状態にあるためです。これは、RSが現在リーダー不在の可能性があるか、またはリクエストがRSのスタンバイレプリカに送信された可能性があります。

* 解決策：通常、リクエストを再試行することで解決します。RSがリーダー不在の状態の場合は、さらなる調査が必要です。

## ERROR 4551 (HY000) : server migrate in denied

* OceanBase エラーコード：4551

* エラー原因：OBServerノードが`balance task`を実行する過程で、ディスク満杯やパーティション数が多すぎるなどの理由により`balance task`の実行が失敗した場合、OBServerノードはRSに対してこの`balance task`の実行失敗を返信し、このエラーコードを報告します。

* 解決策：RSはそのServerへのタスクスケジューリングを停止し、所定時間後に再度そのServerに対してタスクスケジューリングを試みます。Serverが引き続きこのエラーコードを報告する場合は、人為的に介入し、ディスクが過負荷になっていないか、パーティション数が多すぎないかを調査する必要があります。

## ERROR 4552 (HY000) : rebalance task can not executing now

* OceanBase エラーコード：4552

* エラー原因：RSが`balance task`を実行する前に、リーダーの切り替えが正常に完了したかどうか、ターゲットマシンにそのレプリカが既に存在するかどうか、レプリカのSchemaが存在するかどうかなど、一連のチェックを行います。チェックの結果、`balance task`を実行できないことが判明した場合、その`balance task`は終了し、このエラーコードが報告されます。

* 解決策：`balance task`実行前のチェック条件を確認し、具体的なエラーに応じて調査を進めます。例えば、リーダー移行前のリーダー切り替え失敗などの場合は、リーダー切り替え失敗の原因をさらに調査する必要があります。

## ERROR 4554 (HY000) : rebalance task not in progress on observer

* OceanBase エラーコード：4554

* エラー原因：RSは定期的にOBServerノードにRPCを送信し、各`balance task`が存在するかどうかを確認します。`balance task`が存在しなくなると、RSはその`balance task`が終了したと判断し、このエラーコードを返します。

* 解決策：このエラーは通常、meta_tableの報告遅延または`balance task`からRSへの応答パケットの欠落によって引き起こされます。通常は処理を必要としません。

## ERROR 4605 (HY000) : Data source timeout

## ERROR 4615 (HY000) : tablegroup is not empty

* OceanBaseエラーコード：4615

* エラー原因：Table groupを削除する際、以下のいずれかの状況が存在するとこのエラーが発生します：

  * Table group内にテーブルが存在する場合。

  * データベースの`default_tablegroup_id`のTable groupを削除した場合。

  * テナントの`default_tablegroup_id`のTable groupを削除した場合。

* 解決策：Table group内のテーブルを削除しますが、`default_tablegroup_id`のTable groupは削除しません。

## ERROR 4622 (HY000) : wait all rs online timeout

* OceanBaseエラーコード：4622

* エラー原因：

  1. Bootstrap時にRSが存在するServerが`ALIVE`であるかどうかをチェックします。`ALIVE`でない場合、このエラーが発生します。

  2. Bootstrap時にRSが配置されているサーバーが`in_service`状態であるか、または`start_service_time`が`0`であるかをチェックします。`in_service`状態ではない場合、または`start_service_time`が`0`の場合、このエラーが報告されます。

* 解決策：処理時間が長くなる原因を調査するか、タイムアウト時間を延長してください。

## ERROR 4624 (HY000) : zone '%s' server \'%s\' %s resource is not enough to hold a new unit

* OceanBase エラーコード：4624

* エラー原因：

  1. リソースの割り当て時（リソースプールの作成・変更、Unitの移行、レプリカの補完などのシナリオを含む）、リソースが十分かどうかをチェックします。リソースが不足している場合、このエラーが報告されます。

  2. テーブル作成時にリソースが十分かどうかをチェックします。リソースが不足している場合、このエラーが報告されます。

* 解決策：具体的な原因に応じて、リソースの割り当てサイズを調整してください。

## ERROR 4626 (HY000) : resource pool \\'%s\\' has already been granted to a tenant

* OceanBase エラーコード：4626

* エラー原因：既に他のテナントがそのリソースプールを使用しています。

* 解決策：`__all_resource_pool`を確認し、そのリソースプールを参照しているテナントの`tenant_id`を取得します。以下の解決策を採用できます。

  * 対応するテナントを削除します。

  * テナントのスケールインによりリソースプールを削減します。

  * 別の新しいリソースプールを作成し、このリソースプールを使用しないようにします。

関連する問題例：

  [リソースプールエラー、エラーコード4626](https://www.oceanbase.com/knowledge-base/oceanbase-database-20000010169?back=kb)

## ERROR 4630 (HY000) : server not in server white list

* OceanBase エラーコード：4630

* エラー原因：内部エラーです。Serverが現在のクラスタに存在しません。一般的なケース：

  * RS切り替え後、サービス提供前に一時的にエラーが発生する場合。

  * クラスタのBootstrapプロセス中に一時的にエラーが発生する場合。

  * 新規マシンで `add server` 操作が実行されていない場合。

  * 他のクラスタからのデータベースの乗っ取り（スティール）の場合。

* 解決策：

  * RS切り替え後にサービスが提供されていない場合や、クラスタがBootstrapプロセス中の場合、長時間エラーが続く場合を除き、特別な処理は不要です。

  * 新規マシンで `add server` 操作が実行されていない場合は、`add server` 操作を実行し忘れていないかご確認ください。

  * 他のクラスタからのデータベースの乗っ取り（スティール）の場合は、クラスタにそのような動作がないかご確認ください。もしそのような動作がある場合は、テクニカルサポートスタッフにお問い合わせいただき、調査をお願いいたします。

## ERROR 4631 (HY000) : server zone not match

* OceanBase エラーコード：4631

* 解決策：ゾーンを指定する場合は、`__all_server` 内のサーバーとゾーンが一致しているか確認してください。

## ERROR 4632 (HY000) : zone num has reach max zone num

## ERROR 4633 (HY000) : zone status not match

* OceanBase エラーコード：4633

* エラーの原因：`delete/start zone` コマンドの防御的エラーです。`delete zone` の際のゾーンステータスは `inactive` である必要があり、`start zone` の際のゾーンステータスは `active` 以外である必要があります。

* 解決策：`DBA_OB_ZONES` テーブルの内容を照会し、ゾーンのステータスを確認します。予想と異なる場合は、技術サポートに連絡し、調査を依頼してください。

## ERROR 4634 (HY000) : resource unit \\'%s\\' is referenced by some resource pool

* OceanBase エラーコード：4634

* エラーの原因：リソースユニットの削除または使用時に、そのリソースユニットが特定のリソースプールによって参照されていることが検出されました。

* 解決策：

  1. `__all_unit_config` または `__all_resource_pool` テーブルを確認し、どのリソースプールがそのリソースユニットを参照しているかを調べます。

  2. `ALTER RESOURCE POOL` ステートメントを実行し、リソースプールが参照するリソースユニットを変更して、そのリソースユニットを参照しないようにします。または、`DROP RESOURCE POOL` ステートメントを実行してリソースプールを直接削除します。

  3. `DROP RESOURCE UNIT` または `ALTER RESOURCE POOL` ステートメントを実行して、そのリソースユニットを削除または使用します。

## ERROR 4745 (HY000) : delete server not allowed

* OceanBase エラーコード：4745

* 解決策：同ゾーン内に空きサーバーを追加するか、空きサーバーを拡張します。

## ERROR 4770 (HY000) : Tenant (%ld) is in %.*s procedure, %.*s not allowed now

* OceanBase エラーコード：4770

* エラー原因：クローン操作がソーステナントの他の操作と競合しています。ソーステナントをクローンする際、一部の操作を制限します。

* 解決策：ソーステナントで以下の操作が実行されていないか確認してください：ソーステナントの削除、ソーステナントリソースプールの変更、ソーステナントのUnit移行、ソーステナントのログストリームレプリカに関する各種ディザスタリカバリタスク（レプリカの補完、削除、移行、レプリカタイプの変換、paxos_replica_numberの変更）、ソーステナントのSwitchover、ソーステナントのアップグレード、ソーステナントのTransferタスク、ソーステナントのログストリーム属性の変更などです。これらの操作が実行されている場合は、クローン操作と同時に実行されないようにしてください。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.x系では、このエラーコードはV4.2.3バージョンから導入されました。V4.3.x系では、このエラーコードはV4.3.0バージョンから導入されました。</p>
