# 7000 ～ 7999

この範囲は、選挙モジュールのエラーコードを示します。

## ERROR 7000 (HY000) : The log buffer is full

* OceanBase エラーコード：7000

* エラーの原因：選挙ログモジュールのバッファがいっぱいです。選挙モジュールによるログ帯域幅の使用量が予想を上回っています。内部ログの出力が過剰であるか、ログバッファ `buffer` の設定が小さすぎます。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせいただき、調査をお手伝いください。

## ERROR 7001(HY000) : The log buffer is empty

* **O** ceanBase エラーコード：7001

* エラーの原因：このエラーコードは現在、使用されていません。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせいただき、調査をお手伝いください。
