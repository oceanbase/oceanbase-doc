# 7000～7999

この範囲は、選出モジュールのエラーコードを示します。

## ERROR 7000 (HY000) : The log buffer is full


* OceanBaseエラーコード：7000

* エラーの原因：選出ログモジュールのバッファが満杯であり、ログ帯域幅の使用量が予想を上回っているか、内部ログの出力が過剰であるか、またはログバッファの`buffer`設定が小さすぎる。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせください。

## ERROR 7001(HY000) : The log buffer is empty


* **O** ceanBaseエラーコード：7001

* エラーの原因：このエラーコードは現在使用されていません。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせください。

## ERROR 7002 (HY000) : The object is not running


* OceanBaseエラーコード：7002

* エラーの原因：選出対象のスケジュールタスクが開始されていない。

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせください。

## ERROR 7003 (HY000) : The object is running

## ERROR 7004 (HY000) : Election does not reach majority

* 解決策：内部エラーコードです。テクニカルサポートにお問い合わせください。
