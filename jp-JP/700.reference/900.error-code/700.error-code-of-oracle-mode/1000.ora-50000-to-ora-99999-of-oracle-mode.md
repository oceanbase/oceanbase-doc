## ORA-54002：virtual column expressionには純粋関数のみを指定できます


* Ocean Baseエラーコード：5906

* SQLSTATE：HY000

* エラーの原因：virtual list expressionには値が不確定な関数が含まれています。

* 解決策：リスト式を書き換えて、純粋関数のみを参照するようにします。

## ORA-54003：指定されたデータ型は仮想列では
サポートされていません


* OceanBaseエラーコード：5893

* SQLSTATE：HY000

* エラーの原因：仮想列はスカラーデータ型のみをサポートしています。仮想列は`LONG`、`BLOB`、`REF`、および`BFILE`データ型をサポートしていません。

* 解決策：式列にサポートされるスカラーデータ型を指定します。

## ORA-54004：仮想列の結果データ型はサポートされていません

* OceanBaseエラーコード：5401

* SQLSTATE：HY000

* エラーの原因：仮想列は基底式のデータ型をサポートしておらず、スカラーデータ型のみをサポートしています。仮想列は`LONG`、`BLOB`、`REF`、および`BFILE`データ型をサポートしていません。

* 解決策：仮想列の式にサポートされるスカラーデータ型を指定します。

## ORA-54013：仮想列へのINSERT操作は許可されていません

* Ocean Baseエラーコード：5290

* SQLSTATE：HY000

* エラーの原因：値を仮想列に挿入しようとしています。

* 解決策：そのステートメントを再実行し、仮想列の値を提供しないようにします。

## ORA-54016：無効な列式が指定されました

* OceanBaseエラーコード：5908

* SQLSTATE：HY000

* エラーの原因：virtual list expressionは有効な算術式ではありません。それはテーブル内の別の列を参照している可能性があります。

* 解決策：仮想列の式を変更します。

## ORA-54017：仮想列へのUPDATE操作は許可されていません

* OceanBaseエラーコード：5907

* SQLSTATE：HY000

* エラーの原因：仮想列の値を更新しようとしています。

* 解決策：そのステートメントを再実行し、仮想列の値を設定しないようにします。

ORA-54037：テーブルには少なくとも1つのvirtualではない列が必要です

* OceanBaseエラーコード：5904

* SQLSTATE：42000

* エラーの原因：virtual columnのみを含むテーブルの作成を試みています。

* 解決策：作成するテーブルには、少なくとも1つのvirtualではない列を含めてください。

## ORA-54039：テーブルには少なくとも1つのinvisibleではない列が必要です

* OceanBaseエラーコード：5679

* SQLSTATE：HY000

* エラーの原因：テーブルを作成または変更して、invisibleな列のみを含めるようにしようとしています。

* 解決策：作成または変更するテーブルには、少なくとも1つのvisibleな列を含める必要があります。

ORA-54042：このタイプのテーブルではinvisible columnはサポートされていません

* OceanBaseエラーコード：5680

* SQLSTATE：HY000

* エラーの原因：invisible columnの作成や列の可視性の変更を試みていますが、現在のテーブルはinvisible columnをサポートしていません。invisible columnは、ヒープ組織化テーブルとインデックス組織化テーブル(IOT)のみがサポートしています。

* 解決策：これらの列はサポートされていません。DDLを変更してください。

## ORA-54046：列の可視性の変更は、他の変更された列のDDLオプションと組み合わせることはできません

* OceanBaseエラーコード：5681

* SQLSTATE：HY000

* エラーの原因：列の可視性の変更操作を、他の列の属性の変更操作と組み合わせようとしています。

* 解決策：列の可視性の変更操作を独立したDDLに配置してください。

ORA-54048：列式の変更は、他の列のDDL操作と組み合わせることができません

* OceanBaseエラーコード：5947

* SQLSTATE：HY000

* エラーの原因：列式の変更を他の列操作と組み合わせようとしています。

* 解決策：列式の変更操作を独立したDDLに分離してください。

## ORA-54053：SYSユーザーが所有するテーブルの列の可視性を変更できません

## ORA-00600：tmpファイルがディスククォータを超過

* OceanBaseエラーコード：9135

* SQLSTATE：HY000

* エラーの原因：一時ファイルのディスクへの書き込みデータ量が設定上限を超えました。

* 解決方法：現在のエラーを報告するSQLが予想以上のデータ量を生成したかどうかを確認します(例えば、予想される一時ファイルのディスクへの書き込みデータ量の最大値は500GBです)。予想通りであれば、構成パラメータ `temporary_file_max_disk_size` を適切な値に調整できます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>V4.2.5バージョンについては、このエラーコードはV4.2.5 BP3バージョンから導入されました。</p>
</main>

## ORA-00600：内部エラーコード、引数：-9147、バックアップセットファイルにアクセスできません

* OceanBaseエラーコード：9147

* SQLSTATE：HY000

* エラーの原因：物理復旧の実行中に、OBServerノードが指定されたバックアップメディア内のバックアップセットファイルに正常にアクセスできません。

* 解決方法：オブジェクトストレージの接続性を確認し、接続性に問題がないことを確認したら、技術サポート担当者に連絡して調査を支援してください。

<h4>説明</h4>
<p>V4.2.5バージョンについては、このエラーコードはV4.2.5 BP6バージョンから導入されました。</p>
