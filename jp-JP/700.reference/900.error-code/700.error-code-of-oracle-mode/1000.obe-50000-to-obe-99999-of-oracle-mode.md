# OBE-50000 ~ OBE-99999

<main id="notice" >

## OBE-53203：security violation

* OceanBase エラーコード：9793

* SQLSTATE：HY000

* エラー原因：セキュリティ違反。

* 解決策：データベースのセキュリティ製品の設定を確認してください。

## OBE-54002：only pure functions can be specified in a virtual column expression

* OceanBase エラーコード：5906

* SQLSTATE：HY000

* エラー原因：仮想列式に値が不確定な関数が含まれています。

* 解決策：式を書き直し、純粋関数のみを参照するようにしてください。

## OBE-54003：specified data type is not supported for a virtual column

* OceanBase エラーコード：5893

* SQLSTATE：HY000

* エラー原因：仮想列はスカラーデータ型のみをサポートします。仮想列は `LONG`、`BLOB`、`REF`、`BFILE` データ型をサポートしません。

* 解決策：式列に対してサポートされているスカラーデータ型を指定してください。

## OBE-54004：resultant data type of virtual column is not supported

* OceanBase エラーコード：5401

* SQLSTATE：HY000

* エラー原因：仮想列は基底式のデータ型をサポートせず、スカラーデータ型のみをサポートします。仮想列は `LONG`、`BLOB`、`REF`、`BFILE` データ型をサポートしません。

* 解決策：仮想列の式に対してサポートされているスカラーデータ型を指定してください。

## OBE-54013：INSERT operation disallowed on virtual columns

* OceanBase エラーコード：5290

* SQLSTATE：HY000

* エラー原因：仮想列に値を挿入しようとしました。

* 解決策：そのステートメントを再実行しますが、仮想列の値は指定しません。

## OBE-54016：Invalid column expression was specified

* OceanBase エラーコード：5908

* SQLSTATE：HY000

* エラーの原因：仮想列式は有効な算術式ではありません。テーブル内の別の列を参照している可能性があります。

* 解決策：仮想列の式を変更します。

## OBE-54017：UPDATE operation disallowed on virtual columns

* OceanBase エラーコード：5907

* SQLSTATE：HY000

* エラーの原因：仮想列の値を更新しようとしました。

* 解決策：そのステートメントを再実行しますが、仮想列の値は設定しません。

## OBE-54021：Cannot use PL/SQL expressions in partitioning or subpartitioning columns

* Ocean Base エラーコード：5995

* SQLSTATE：HY000

* エラーの原因：PL/SQL式を含む仮想列に基づいてテーブルをパーティション化しようとしました。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このエラーコードはV4.0.0バージョンから導入されました。</p>
</main>

## OBE-54023：Virtual column expression cannot be changed because a constraint is defined on column

* OceanBase エラーコード：5948

* SQLSTATE：HY000

* エラーの原因：トリガーボディ内で仮想列の値を変更することは許可されていません。

* 解決策：トリガー内で仮想列の値を変更しないでください。

## OBE-54029：Virtual column cannot be updated in trigger body

## OBE-54036：cannot define referential constraint with ON DELETE SET NULL clause on virtual column

* SQLSTATE：HY000
* エラー原因：仮想列にON DELETE SET NULL句を含む外部キー制約を定義することはできません。
* 解決策：仮想列にON DELETE SET NULL句を含む外部キー制約を定義しないでください。

## OBE-54037：table must have at least 1 column that is not virtual

* OceanBase エラーコード：5904

* SQLSTATE：42000

* エラー原因：仮想列のみを含むテーブルの作成を試みた場合。

* 解決策：作成するテーブルに、少なくとも1つの非仮想列を含めてください。

## OBE-54039：table must have at least one column that is not invisible

* OceanBase エラーコード：5679

* SQLSTATE：HY000

* エラー原因：テーブルを作成または変更しようとした際、そのテーブルに可視化されていない列のみが含まれている場合。

* 解決策：作成または変更するテーブルには、少なくとも1つの可視化された列を含めてください。

## OBE-54042：Invisible column is not supported on this type of table

* OceanBase エラーコード：5680

* SQLSTATE：HY000

* エラー原因：不可視列の作成、または列の可視性の変更を試みた場合で、現在のテーブルが不可視列をサポートしていない場合。不可視列はヒープおよびインデックス組織テーブル（IOT）でのみサポートされます。

* 解決策：これらの列はサポートされていません。DDLを変更してください。

## OBE-54046：Column visibility modifications cannot be combined with any other modified column DDL option

* OceanBase エラーコード：5681

* SQLSTATE：HY000

* エラー原因：列の可視性の変更操作を他の列属性の変更操作と組み合わせようとした場合。

* 解決策：列の可視性の変更操作を独立したDDLに配置してください。

## OBE-54048：Column expression modifications cannot be combined with any other column DDL operation

* OceanBase エラーコード：5947

* SQLSTATE：HY000

* エラーの原因：リスト式への変更を他の列操作と組み合わせようとしました。

* 解決策：リスト式への変更操作を独立したDDLに分離します。

## OBE-54053：The visibility of a column from a table owned by a SYS user cannot be changed

* OceanBaseエラーコード：5682

* SQLSTATE：HY000

* エラーの原因：SYSユーザーが所有するテーブルの列の可視性を変更しようとしました。

* 解決策：非SYSユーザーが所有するテーブルでこのDDLを実行します。

## OBE-56901：non-constant expression is not allowed for pivot\|unpivot values

* OceanBaseエラーコード：5805

* SQLSTATE：HY000

* エラーの原因：`pivot|unpivot` 値に非常数式を使用しようとしました。

* 解決策：`pivot|unpivot` 値に定数式を使用します。

## OBE-56902：expect aggregate function inside pivot operation

* OceanBaseエラーコード：5806

* SQLSTATE：HY000

* エラーの原因：`pivot` 操作内で非集約式を使用しようとしました。

* 解決策：集約式を使用します。

## OBE-56713：insufficient Resource Manager privileges

* OceanBaseエラーコード：4715

* SQLSTATE：HY000

* エラーの原因：Resource Managerを操作する権限がありません。

* 解決策：rootユーザーで関連操作を実行します。

## OBE-62550：Invalid SQL ROW LIMITING expression was specified

* OceanBaseエラーコード：5831

* SQLSTATE：HY000

* エラーの原因：SQLの`ROW LIMITING`式に、テキスト、バインド変数、関連変数、またはサブクエリ以外の要素が含まれています。

* 解決策：SQLの`ROW LIMITING`式を修正し、操作を再試行します。

## OBE-64500：invalid PL/SQL XML parser handle

* 解決方法：PL/SQL XMLパーサーの初期化と使用方法を確認し、操作前にパーサーハンドルが正しく作成されていることを保証します。
