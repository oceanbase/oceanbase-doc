## ORA-01543：tablespace '%.\*s' already exists

* OceanBaseエラーコード：4353

* SQLSTATE：HY000

* エラーの原因：既に存在するテーブルスペースを作成しようとしています。

* 解決策：別の名前で新しいテーブルスペースを作成します。

## ORA-01555：snapshot too old

* OceanBaseエラーコード：4138

* SQLSTATE：HY000

* エラーの原因：リーダーが一貫性読み取りを行うために必要なロールバックレコードが、他のライターによって上書きされました。

* 解決策：undo_retention値を変更して、ロールバックレコードの範囲を拡大してください。

関連する問題ケース：

* [ダンプエラー、エラーコード4138/ORA-01555](https://www.oceanbase.com/knowledge-base/oceanbase-database-20000000158?back=kb)
* [OMSフルデータ移行エラー、エラーコードORA-01555](https://www.oceanbase.com/knowledge-base/oms-ee-20000000012?back=kb)

## ORA-01719：outer join operator (+) not allowed in operand of OR or IN

* OceanBaseエラーコード：5623

* SQLSTATE：HY000

* エラーの原因：`OR` 句に外部結合が現れました。

* 解決策：AとBが述語の場合、`(A(+) or B)` の効果を得るには、次の構文を試してください：

  ```unknow
  SELECT WHERE (A(+) AND NOT B)) UNION ALL (SELECT WHERE (B));
  ```

## ORA-01720：grant option does not exist for '%.\*s.%.\*s'

* OceanBaseエラーコード：5371

* SQLSTATE：HY000

* エラーの原因：ビューに対する権限付与またはビューの置換が実行されていますが、ベースオブジェクトには権限付与オプションが存在しません。

* 解決策：ビューのすべてのベースオブジェクトに対する権限付与オプションを取得するか、ビュー上の既存の権限を取り消します。
