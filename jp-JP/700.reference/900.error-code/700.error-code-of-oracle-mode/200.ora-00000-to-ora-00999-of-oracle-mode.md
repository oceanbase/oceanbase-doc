* OceanBase エラーコード：5024

* SQLSTATE：23000

## OBE-00060: Migrate tx data not continues

* oceanbase エラーコード：4408

* SQLSTATE：HY000

* エラー原因：移行元のトランザクションデータテーブルがリサイクルされ、移行先のコピー時にトランザクションデータテーブルが連続していないことが検出され、失敗してエラーが発生しました。再試行してください。

* 解決方法：通常、再試行すると成功します。連続して失敗する場合は、Oceanbase サポートチームに連絡してトラブルシューティングを依頼してください。

## ORA-00600: arbitration service does not exist

* OceanBase エラーコード：4747

* SQLSTATE：HY000

* エラー原因：クラスタにアービトレーションサービスのアドレスが設定されていません。

* 解決方法：アービトレーションサービスのアドレスが設定されていない状態でアービトレーション関連の操作を行うことはサポートされていません。OCPを使用するか、SQLコマンド `alter system add arbitration service‘$svr_ip:$svr_port’;` を実行して、クラスタにアービトレーションサービスのアドレスを追加できます。

## ORA-00600: arbitration service already exist

* OceanBase エラーコード：4748

* SQLSTATE：HY000

* エラー原因：クラスタに有効なアービトレーションサービスのアドレスが既に存在します。

* 解決方法：1つのクラスタに複数のアービトレーションサービスを同時に設定することはサポートされていません。
