## ORA-12401：invalid label string

* OceanBase エラーコード：9756

* SQLSTATE：HY000

* エラー原因：既にマテリアライズドビューのログが存在するテーブルにマテリアライズドビューのログを作成しようとした場合。各主テーブルにはマテリアライズドビューのログは1つしか存在しません。

* 解決策：テーブル上のすべてのマテリアライズドビューは、そのテーブルのマテリアライズドビューのログを使用できます。既存のログを変更するには、`DROP MATERIALIZED VIEW LOG` コマンドを使用してマテリアライズドビューのログを削除し、再作成してください。

  <h4>説明</h4>
  <p>このエラーコードはV4.2.2バージョンから導入されました。</p>
</main>

## ORA-12052：マテリアライズドビュー %s.%s のクイックリフレッシュはできません

* OceanBase エラーコード：9760

* SQLSTATE：HY000

* エラー原因：

  * 定義に特定のテーブルのROWIDが不足している、または外部結合の内側のテーブルが結合列にUNIQUE制約を持っていない。
  * マテリアライズドビューに依存するテーブルオブジェクトが変更された。
  * マテリアライズドビューのログが存在しない。

* 解決策：

  * FORCEまたはCOMPLETEオプションを指定します。
  * 基盤テーブルの構造を確認し、修正してマテリアライズドビューの定義が依然として有効であることを確保し、完全なリフレッシュを行います。
  * マテリアライズドビューのログを再作成し、その後、マテリアライズドビューに対する完全なリフレッシュが必要になる可能性があります。これにより、マテリアライズドビューにはすべての最新データが含まれます。

## ORA-12704：COLLATION '%.\*s' is not valid for CHARACTER SET '%.\*s'

* OceanBase エラーコード：5144

* SQLSTATE：42000

* エラー原因：次のいずれかが原因である可能性があります。

  * 演算子または組み込み関数の文字列オペランド（`nlsparams` パラメータを除く）で使用されている文字セットが一致しません。

  * `nlsparams` オペランドがデータベースの文字セットに含まれていません。

  * 組み込み関数に渡された文字列データは、データベースの文字セット以外の文字セットを使用していますが、その文字セットは組み込み関数で受け入れられません。

  * `CHR（）` または `CSCONVERT（）` の2 番目のパラメータが `CHAR_CS` または `NCHAR_CS` ではありません。

  * `INSERT` ステートメントの `VALUES` 句または `UPDATE` ステートメントの `SET` 句に指定された文字列式の文字セットが、挿入する列で使用されている文字セットと一致しません。

  * テーブル作成時に `DEFAULT` 句で指定された値の文字セットが、列で宣言された文字セットと一致しません。

  * PL 関数のパラメータが、対応するパラメータの文字セット要件に適合していません。

## ORA-14020：this physical attribute may not be specified for a table partition

* OceanBase エラーコード：4398
* SQLSTATE：HY000
* エラー原因：パーティションテーブルを作成する際に、RANGE/LIST パーティションと HASH/KEY パーティションを同時に使用するなど、互換性のないパーティション方式が使用された場合。
* 解決策：
  * パーティション方式を修正する：RANGE/LIST パーティションと HASH/KEY パーティションを同時に使用する必要がある場合は、互換性のあるパーティション方式に修正してください。パーティション方式の修正やパーティションテーブルの分割は、既存のデータやアプリケーションに影響を与える可能性があるため、慎重に操作してください。
