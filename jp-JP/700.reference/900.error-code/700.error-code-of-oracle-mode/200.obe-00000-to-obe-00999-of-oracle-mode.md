## OBE-00001：unique constraint \\'%s\\' for key \\'%.\*s\\' violated

* OceanBase エラーコード：5024

* SQLSTATE：23000

* エラー原因：`UPDATE` または `INSERT` ステートメントが重複するキーの挿入を試みました。

* 解決策：`UNIQUE` 制約を外すか、そのキーを挿入しないでください。

## OBE-00600：arbitration service does not exist

* OceanBase エラーコード：4747

* SQLSTATE：HY000

* エラーの原因：クラスタにアービトレーションサービスのアドレスがまだ設定されていません。

* 解決策：アービトレーションサービスのアドレスが設定されていない状態では、アービトレーション関連の操作はサポートされません。OCPを使用するか、SQLコマンド`alter system add arbitration service‘$svr_ip:$svr_port’;`を実行して、クラスタにアービトレーションサービスのアドレスを追加できます。

  * ターゲットオブジェクトが存在しません。

  * シノニムが不正確なデータベースリンクを指定しています。

  * シノニムはバージョン管理されていませんが、バージョン管理されたターゲットオブジェクトが指定されています。

* 解決策：シノニムの定義を変更し、シノニムが有効なターゲットオブジェクトを指すようにします。
