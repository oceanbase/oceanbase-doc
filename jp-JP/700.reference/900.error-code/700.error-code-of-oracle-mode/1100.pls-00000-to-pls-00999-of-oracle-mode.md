## PLS-00001：PL/SQL common error", "%s

* OceanBase エラーコード：9656

* SQLSTATE：HY000

* エラーの原因：予期しない記号が出現しました。

* 解決策：エラー発生位置に出現した記号が予期されていないため、その記号を修正します。

## PLS-00103：Encountered the symbol %s when expecting one of the following: %s

* OceanBase エラーコード：9700

* SQLSTATE：HY000

* エラーの原因：パーザーはこの文脈では不適切なトークンを見つけました。

* 解決策：以前のトークンとエラーメッセージで示されているトークンを確認してください。エラーメッセージで示されている行番号と列番号は、エラーとなる言語構造の終わりの位置を示しています。

## PLS-00109：unknown exception name '%.\*s' in PRAGMA EXCEPTION_INIT

* OceanBase エラーコード：9583

* SQLSTATE：HY000

* エラーの原因：コンパイル指示の範囲内で、`EXCEPTION_INIT` コンパイル指示で参照されている例外名の宣言が見つかりません。

* 解決策：`pragma` が例外宣言に従っており、かつ同一範囲内にあることを確認してください。

## PLS-00113：END identifier '%.\*s' must match '%.\*s

* OceanBase エラーコード：9659

* SQLSTATE：HY000

* エラーの原因：キーワード `END` は、ループ、ブロック、関数、プロシージャなど、いくつかの言語構造を終了します。その後、その構造の名前をオプションで置くことができます。例えば、ループ `L` の定義の終わりには、`END L` を記述するかもしれません。オプションの名前が言語構造に割り当てられた名前と一致しない場合、このエラーが発生します。これは通常、誤った識別子や誤ったブロック構造によって引き起こされます。

* 解決策：終了識別子のスペルが言語構造に割り当てられた名前と一致していることを確認し、ブロック構造が正しいことを確認してください。

## PLS-00114：identifier ' %.\*s' too long

* OceanBase エラーコード：9526

* SQLSTATE：HY000

* エラーの原因：PL変数の名前が128文字を超えています。有効な識別子（ダブルクォート付きの識別子を含む）の最大長は128文字です。これは、文字列リテラルが誤ってダブルクォーテーションマークではなく単一引用符で囲まれている可能性があるためであり、その場合、PLはそれを引用符付きの識別子として扱います。

* 解決策：識別子を短くします。

## PLS-00115：this PRAGMA must follow the declaration of '%.\*s

* OceanBase エラーコード：9622

* SQLSTATE：HY000

* エラーの原因：`pragma` は未宣言または参照範囲外のPL/SQLオブジェクトを指しています。識別子は `pragma` で使用される前に宣言する必要があります。フォワード参照は許可されません。

* 解決策：識別子のスペルと宣言を確認してください。また、宣言がブロック構造内に正しく配置されていることを確認してください。

## PLS-00128：Illegal number of arguments for pragma EXCEPTION_INIT

* OceanBase エラーコード：9675

## PLS-00201: identifier '%.\*s' must be

declared

* OceanBase エラーコード：5543、5546

* SQLSTATE：42000

* エラーの原因：

  * 宣言されていない変数、例外プログラム、プロシージャを参照しています。

  * 権限が付与されていない型を参照しています。

  * ロールを通じてのみ権限が付与された型を参照しています。

  * ストレージ対象のオブジェクト（パッケージ、プロシージャ、関数、トリガー、ビュー）は、オブジェクト所有者のセキュリティドメイン内で実行され、`PUBLIC` を除き、他のロールも有効になっていません。

* 対処法：

  * 参照している名前のスペルと宣言を確認してください。

  * 参照している項目の宣言がブロック構造内に正しく配置されているか確認してください。

  * 実際に参照している項目が宣言されており、かつその項目への参照権限があると考えている場合は、権限を確認してください。

## PLS-00204：function or pseudo-column '%s' may be used inside a SQL statement only

* OceanBase エラーコード：9682

* SQLSTATE：HY000

* エラーの原因：プログラム文で擬似列または許可されていない関数を使用しました。SQL擬似列（LEVEL、ROWID、ROWNUM）はSQL文内でしか宣言できません。同様に、特定の関数（例：DECODE、DUMP、および VSIZE）やSQL集計関数（平均値、最小値、最大値、カウント、合計、STDEV、分散）はSQL文内でしか使用できません。

* 対処法：プログラムから擬似列の参照や関数呼び出しステートメントを削除します。あるいは、プログラム文をSELECT INTOステートメントに置き換えます。例えば、`bonus := DECODE(rating, 1, 5000, 2, 2500, ...);` を `SELECT DECODE(rating, 1, 5000, 2, 2500, ...) INTO bonus FROM dual;` に置き換えます。

* 対処法：変数宣言に初期化句を追加します。初期化の構文が複雑すぎる場合は、関数呼び出しを追加できます。

## PLS-00225：subprogram or cursor '%.\*s' reference is out of scope

* OceanBase エラーコード：9628

* SQLSTATE：HY000

* エラーの原因：限定名のプレフィックスが、閉じた範囲内にないサブルーチンまたはカーソルです。つまり、サブルーチンまたはカーソル名が範囲限定子として使用され、その範囲内に存在しないエンティティ（そのサブルーチンまたはカーソル内）を参照しようとしています。例：`declare x number; type t1 is record (a number); function f return t1 is a number; begin x := f.a;`：

  * 関数"f"を範囲限定子として使用する正しい方法

  * 関数"f"を範囲限定子として使用する不正な方法 `x :=f().a;`、戻り値レコードのコンポーネント"a"への正当な参照

* 対処法：

  * 非閉じた関数のローカル変数を参照しようとした場合、これは許可されていません。参照を削除してください。

  * パラメータなしの関数であり、その呼び出し結果のフィールドにアクセスしようとした場合、呼び出し時に空の括弧を使用してください。
