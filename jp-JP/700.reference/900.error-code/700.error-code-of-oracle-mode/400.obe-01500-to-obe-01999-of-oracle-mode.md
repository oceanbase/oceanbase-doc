## OBE-01543：tablespace '%.\*s' already exists

* OceanBase エラーコード：4353

* SQLSTATE：HY000

* エラーの原因：既存のテーブルスペースを作成しようとしました。

* 解決策：別の名前を使用して新しいテーブルスペースを作成します。

## OBE-01555：snapshot too old

* OceanBase エラーコード：4138

* SQLSTATE：HY000

* エラーの原因：リーダーが一貫性のある読み取りに必要なロールバックレコードが他のライターによって上書きされました。

* 解決策：undo_retention値を変更して、ロールバックレコードの範囲を広げてください。

関連する問題例：

* [ダンプエラー、エラーコード4138/OBE-01555](https://www.oceanbase.com/knowledge-base/oceanbase-database-20000000158?back=kb)
* [OMS フルデータ移行エラー、エラーコード OBE-01555](https://www.oceanbase.com/knowledge-base/oms-ee-20000000012?back=kb)

* SQLSTATE：HY000

* エラーの原因：`NOAUDIT` は `BY ACCESS` または `BY SESSION` 句を許可しません。

## OBE-01719：outer join operator (+) not allowed in operand of OR or IN

* OceanBase エラーコード：5623

* SQLSTATE：HY000

* エラーの原因：`OR` 句内に外部結合が現れています。

* 解決策：AとBが述語の場合、`(A(+) or B)` の効果を得るには、次のような書き方を試してください：

  ```shell
  SELECT WHERE (A(+) AND NOT B)) UNION ALL (SELECT WHERE (B));
  ```

## OBE-01720：grant option does not exist for '%.\*s.%.\*s'

* OceanBase エラーコード：5371

* SQLSTATE：HY000

* エラーの原因：ビューに対する権限付与またはビュー置換を実行している際、基礎オブジェクトに権限付与オプションが存在しません。

* 解決策：ビューのすべての基礎オブジェクトに対する権限付与オプションを取得するか、ビュー上の既存の権限を取り消します。
