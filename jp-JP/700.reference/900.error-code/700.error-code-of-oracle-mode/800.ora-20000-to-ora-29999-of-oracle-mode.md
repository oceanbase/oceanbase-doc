## ORA-20000： The stored procedure 'raise_application_error' was called which causes this error to be generated", "ORA%06ld: %.*s

* OceanBaseエラーコード：20000

* SQLSTATE：HY000

* エラー原因：プロシージャのカスタム エラーコード `RAISE_APPLICATION_ERROR` が呼び出されたため、このエラーが発生しました。

* 解決策：エラー メッセージの説明に従って問題を修正するか、アプリケーション管理者またはデータベース管理者に連絡して詳細を確認してください。

## ORA-21000：error number argument to raise_application_error of stringstring is out of range

* OceanBase エラーコード：21000

* SQLSTATE：HY000

* エラー原因：`RAISE_APPLICATION_ERROR` のエラー番号引数がパラメータの範囲を超えています。

## ORA-21560：argument %.\*s is null, invalid, or out of range

* OceanBase エラーコード：5934

* SQLSTATE：HY000

* エラー原因：渡されたパラメータ値が `NULL`、無効、または範囲外です。たとえば、`LOB / FILE` の位置またはサイズのパラメータ値が 1 から (4 GB-1) の範囲を超える場合、または無効なオープン モードでファイルを開く場合などが該当します。

* 解決策：プログラムを確認し、`NULL`、無効、または範囲外のパラメータ値を渡さないように修正してください。

## ORA-22003：value is out of range

* OceanBase エラーコード：4157

* SQLSTATE：22003

* エラー原因：指定された `TCP/IP` 関数 `func` を実行するときに予期しない通信エラーが発生しました。`TCP/IP` 関数の戻りコードは `rc`、関数 `func` のパラメータは `parm` です。

* 解決策：テクニカル サポートに連絡してトラブルシューティングを依頼してください。

## ORA-22369：invalid parameter encountered in method %s

* OceanBase エラーコード：5955

* SQLSTATE：HY000

* エラー原因：`SYS` に無効なパラメータが渡されました。無効なパラメータには、`SYS. any type`、`SYS. any data`、または `SYS. any dataset` が含まれます。

* 解決策：渡されたパラメータを確認し、許可されたパラメータであることを確認してください。

## ORA-22950：cannot ORDER objects without MAP or ORDER method

* OceanBase エラーコード：7412
* SQLSTATE：42000
* エラー原因：オブジェクトを比較する際、オブジェクトにMAPまたはORDERメソッドが定義されていません。
* 解決策：
   1. MAPまたはORDERメソッドを定義します：オブジェクトの定義にMAPまたはORDERメソッドを定義することで、並べ替え時に使用できます。MAPメソッドはオブジェクトをスカラ値にマッピングするために使用され、ORDERメソッドは2つのオブジェクトの大小比較に使用されます。
   2. 並べ替え方式を変更します：MAPまたはORDERメソッドを定義できない場合は、他の方法で並べ替えを行うことを検討します。例えば、他の列を使用して並べ替える方法があります。
