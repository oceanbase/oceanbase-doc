# Java サンプルアプリケーションの作成

本記事では、Java アプリケーションから OceanBase Connector/J ドライバーを使用して OceanBase データベースに接続し、使用する方法について説明します。

  <main id="notice" >
    <h4>機能適合性</h4>
    <p>この内容は OceanBase データベース Enterprise Edition にのみ適用されます。OceanBase データベース Community Edition は、MySQL モードのみご利用いただけます。</p>
  </main>

## 前提条件

* 基本的なデータベース開発環境が設定されていることを確認します。

* コンピュータの Java 環境が Java JDK 8 であることを確認します。

* OceanBase Connector/J ドライバーのインストールパッケージを取得します。OceanBase 公式 Web サイトの **リソース -> ダウンロードセンター -> Enterprise Edition -> ドライバーとミドルウェア** にある [OceanBase JDBC ドライバー](https://en.oceanbase.com/softwarecenter-cloud) から、該当するバージョンをクリックし、必要事項を入力後、OceanBase Connector/J ドライバーのインストールパッケージをダウンロードしてください。

## Java アプリケーションの作成

### 手順 1：データベース接続文字列の取得

OceanBase データベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
obclient  -h100.88.xx.xx -usys@oracle -p****** -P2881
```

データベース接続文字列には、データベースへのアクセスに必要なパラメーター情報が含まれています。アプリケーションを作成する前に、データベース接続文字列を用いてデータベースへのログインを検証し、接続文字列のパラメーターが正確であるか確認することができます。

パラメーターの説明：

* **-h**：OceanBase データベースに接続する際の IP アドレスであり、ODP アドレスの場合もあります。

* **-u**：テナントの接続ユーザー名であり、**ユーザー@テナント#クラスター名** の形式です。テナントの接続ユーザーであり、Oracle モードの管理者ユーザー名は、デフォルトで `sys` です。データベースに直接接続する場合、クラスター名は不要です。ODP を介して接続する場合は、クラスター名を入力する必要があります。

* **-p**：ユーザーパスワードです。

* **-P**：OceanBase データベースの接続ポートであり、ODP のリスニングポートでもあります。

### 手順 2：OceanBase Connector/J ドライバーのインストール

OceanBase Connector/J の JAR パッケージを解凍し、ローカルのパス `/usr/share/java` に配置した後、一時環境変数を設定します。

```shell
mv ./oceanbase-client-{version}.jar /usr/share/java
export CLASSPATH=/usr/share/java/oceanbase-client-{version}.jar:$CLASSPATH
```

### 手順 3：アプリケーションの作成

Java のサンプルファイル `Test.java` を作成します。

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;
import java.sql.ResultSet;
import java.sql.Statement;

public class Test {
    public static void main(String[] args) {
        try {

            Class.forName("com.oceanbase.jdbc.Driver");
            Connection connection = DriverManager.getConnection("jdbc:oceanbase://172.30.xx.xx:2881/?pool=false&user=s**@oracle&password=******");
            System.out.println(connection.getAutoCommit());
            Statement sm = connection.createStatement();
            //テーブル t_meta_form の新規作成
            sm.executeUpdate("CREATE TABLE t_meta_form (name varchar(36) , id int)");
            //データの挿入
            sm.executeUpdate("insert into t_meta_form values ('an','1')");
            //データの検索と結果の出力
            ResultSet rs = sm.executeQuery("select * from t_meta_form");
            while (rs.next()) {
                String name = rs.getString("name");
                String id = rs.getString("id");
                System.out.println(name + ','+ id);
            }
            //テーブルの削除
            sm.executeUpdate("drop table t_meta_form");
        }catch (SQLException ex) {
            System.out.println("error!");
            ex.printStackTrace() ;
        }catch (ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

コード内のデータベース接続パラメーターを変更します。以下のフィールドを参照し、対応する値は、手順 1 で取得したデータベース接続文字列から取得します。

* **url**：`-h` および `-P` パラメーターから取得し、`jdbc:oceanbase://IP:port/?pool=false` となります。OceanBase データベースに接続する際の IP アドレスであり、通常は ODP アドレスと、アクセスに使用するポート番号です。

* **user**：`-u` パラメーターから取得したテナントの接続ユーザー名であり、**ユーザー@テナント#クラスター名** の形式です。Oracle モードの管理者ユーザー名は、デフォルトで `sys` です。データベースに直接接続する場合、クラスター名は不要です。ODP を介して接続する場合は、クラスター名を入力する必要があります。

* **password**：`-p` パラメーターから取得したユーザーパスワードです。

### 手順 4：アプリケーションの実行

コードの編集が完了したら、以下のコマンドでコンパイルが可能になります：

```bash
javac Test.java
```

コンパイル完了後、実行した結果が以下のとおりである場合、データベースへの接続に成功し、サンプル文が正しく実行されたことを意味します：

```bash
java Test

true
an,1
```
