# SQLの基本操作 (Oracleモード)

このセクションでは、OceanBaseデータベースのOracleモードにおける基本的なSQL操作について説明します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity EditionはMySQLモードのみを提供します。</p>
  </main>

## テーブルの操作

このセクションでは、データベースにおけるテーブルの作成、表示、変更、削除の構文と例を説明します。

### テーブルの作成

`CREATE TABLE` ステートメントを使用して、データベースに新しいテーブルを作成します。

例：テーブル `TEST` を作成します。

```shell
obclient(SYS@oracletenant)[SYS]> CREATE TABLE TEST (C1 INT PRIMARY KEY, C2 VARCHAR(3));
```

`CREATE TABLE` ステートメントの詳細な構文については、[CREATE TABLE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/2400.create-table-of-oracle-mode.md)を参照してください。

### テーブルの変更

`ALTER TABLE` ステートメントを使用して、既存のテーブルの構造を変更します。これには、テーブルやテーブル属性の変更、列の追加、列や属性の変更、列の削除などが含まれます。

例：

* テーブル `TEST` の `C2` 列の型を変更します。

  1. テーブル `TEST` の列定義を確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> DESCRIBE TEST;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+-------------+------+-----+---------+-------+
     | FIELD | TYPE        | NULL | KEY | DEFAULT | EXTRA |
     +-------+-------------+------+-----+---------+-------+
     | C1    | NUMBER(38)  | NO   | PRI | NULL    | NULL  |
     | C2    | VARCHAR2(3) | YES  | NULL| NULL    | NULL  |
     +-------+-------------+------+-----+---------+-------+
     2 rows in set
     ```

  2. テーブル `TEST` の `C2` 列の型を `CHAR` に変更します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> ALTER TABLE TEST MODIFY C2 CHAR(10);
     ```

  3. 再度テーブル `TEST` の列定義を確認し、変更が成功したことを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> DESCRIBE TEST;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+------------+------+-----+---------+-------+
     | FIELD | TYPE       | NULL | KEY | DEFAULT | EXTRA |
     +-------+------------+------+-----+---------+-------+
     | C1    | NUMBER(38) | NO   | PRI | NULL    | NULL  |
     | C2    | CHAR(10)   | YES  | NULL| NULL    | NULL  |
     +-------+------------+------+-----+---------+-------+
     2 rows in set
     ```

* テーブル `TEST` に列を追加および削除します。

  1. 現在のテーブル `TEST` の列定義を確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> DESCRIBE TEST;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+------------+------+-----+---------+-------+
     | FIELD | TYPE       | NULL | KEY | DEFAULT | EXTRA |
     +-------+------------+------+-----+---------+-------+
     | C1    | NUMBER(38) | NO   | PRI | NULL    | NULL  |
     | C2    | CHAR(10)   | YES  | NULL| NULL    | NULL  |
     +-------+------------+------+-----+---------+-------+
     2 rows in set
     ```

  2. テーブル `TEST` に列 `C3` を追加します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> ALTER TABLE TEST ADD C3 int;
     ```

  3. 再度テーブル `TEST` の列定義を確認し、`C3` 列が正常に追加されたことを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> DESCRIBE TEST;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+------------+------+-----+---------+-------+
     | FIELD | TYPE       | NULL | KEY | DEFAULT | EXTRA |
     +-------+------------+------+-----+---------+-------+
     | C1    | NUMBER(38) | NO   | PRI | NULL    | NULL  |
     | C2    | CHAR(10)   | YES  | NULL | NULL   | NULL  |
     | C3    | NUMBER(38) | YES  | NULL | NULL   | NULL  |
     +-------+------------+------+-----+---------+-------+
     3 rows in set
     ```

  4. テーブル `TEST` の `C3` 列を削除します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> ALTER TABLE TEST DROP COLUMN C3;
     ```

  5. 再度テーブル `TEST` の列定義を確認し、`C3` 列が正常に削除されたことを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> DESCRIBE TEST;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+------------+------+-----+---------+-------+
     | FIELD | TYPE       | NULL | KEY | DEFAULT | EXTRA |
     +-------+------------+------+-----+---------+-------+
     | C1    | NUMBER(38) | NO   | PRI | NULL    | NULL  |
     | C2    | CHAR(10)   | YES  | NULL | NULL   | NULL  |
     +-------+------------+------+-----+---------+-------+
     2 rows in set
     ```

`ALTER TABLE` ステートメントの詳細な構文については、[ALTER TABLE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1000.alter-table-of-oracle-mode.md)を参照してください。

### テーブルの削除

`DROP TABLE` ステートメントを使用してテーブルを削除します。

例：テーブル `TEST` を削除します。

```shell
obclient(SYS@oracletenant)[SYS]> DROP TABLE TEST;
```

`DROP TABLE` ステートメントの詳細な構文については、[DROP TABLE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/3900.drop-table-of-oracle-mode.md)を参照してください。

## インデックス操作

インデックスは、テーブルに作成され、データベーステーブルの1列または複数列の値をソートする構造です。主な役割はクエリの速度を向上させ、データベースシステムのパフォーマンスオーバヘッドを低減することです。

### インデックスの作成

`CREATE INDEX` ステートメントを使用して、テーブルのインデックスを作成します。

例：テーブル `TEST` のインデックスを作成します。

1. テーブル `TEST` の列定義を確認します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> DESCRIBE TEST;
   ```

   実行結果は次のとおりです：

   ```shell
   +-------+------------+------+-----+---------+-------+
   | FIELD | TYPE       | NULL | KEY | DEFAULT | EXTRA |
   +-------+------------+------+-----+---------+-------+
   | C1    | NUMBER(38) | NO   | PRI | NULL    | NULL  |
   | C2    | CHAR(10)   | YES  | NULL| NULL    | NULL  |
   +-------+------------+------+-----+---------+-------+
   2 rows in set
   ```

2. テーブル `TEST` の列 `C1` と `C2` に、`TEST_INDEX` という名前の複合インデックスを作成します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> CREATE INDEX TEST_INDEX ON TEST (C1, C2);
   ```

`CREATE INDEX` ステートメントの詳細な構文については、[CREATE INDEX](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1600.create-index-of-oracle-mode.md)を参照してください。

### インデックスの確認

* ビュー `ALL_INDEXES` を使用して、テーブルのすべてのインデックスを確認します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> SELECT OWNER,INDEX_NAME,INDEX_TYPE,TABLE_OWNER,TABLE_NAME FROM ALL_INDEXES WHERE table_name='TEST';
  ```

  実行結果は次のとおりです：

  ```shell
  +-------+----------------------------+------------+-------------+------------+
  | OWNER | INDEX_NAME                 | INDEX_TYPE | TABLE_OWNER | TABLE_NAME |

  | SYS   | TEST_INDEX                 | NORMAL     | SYS         | TEST       |
  +-------+----------------------------+------------+-------------+------------+
  2 rows in set
  ```

* `USER_IND_COLUMNS` を使用して、テーブルのインデックスの詳細情報を確認します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> SELECT * FROM USER_IND_COLUMNS WHERE table_name='TEST'\G
  ```

  実行結果は次のとおりです：

  ```shell

          INDEX_NAME: TEST_OBPK_1762742804587195
          TABLE_NAME: TEST
         COLUMN_NAME: C1

         CHAR_LENGTH: 0
             DESCEND: ASC

  *************************** 2. row ***************************
          INDEX_NAME: TEST_INDEX
          TABLE_NAME: TEST
         COLUMN_NAME: C1
     COLUMN_POSITION: 1
       COLUMN_LENGTH: 22
         CHAR_LENGTH: 0
             DESCEND: ASC
  COLLATED_COLUMN_ID: NULL
  *************************** 3. row ***************************
          INDEX_NAME: TEST_INDEX
          TABLE_NAME: TEST

       COLUMN_LENGTH: 3

  COLLATED_COLUMN_ID: NULL
  3 rows in set
  ```

### インデックスの削除

`DROP INDEX` ステートメントを使用して、テーブルのインデックスを削除します。

例：インデックス `TEST_INDEX` を削除します。

```shell
obclient(SYS@oracletenant)[SYS]> DROP INDEX TEST_INDEX;
```

`DROP INDEX` ステートメントの詳細な構文については、[DROP INDEX](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/3200.drop-index-of-oracle-mode.md)を参照してください。

## データの挿入

`INSERT` ステートメントを使用して、テーブルに1つまたは複数のレコードを追加します。

例：

* `CREATE TABLE` を使用してテーブル `T1` を作成し、テーブル `T1` に1行のデータを挿入します。

  1. テーブル `t1` を作成します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> CREATE TABLE T1(C1 INT PRIMARY KEY, C2 INT);
     ```

  2. テーブル内のデータを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
     ```

     クエリ結果は空で、テーブルにデータはありません。

  3. テーブル `T1` に1行のデータを挿入します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> INSERT INTO T1 VALUES(1,1);
     ```

  4. 再度テーブル内のデータを確認し、1行のデータが正常に挿入されたことを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | C1 | C2   |
     +----+------+
     |  1 |    1 |
     +----+------+
     1 row in set
     ```

* サブクエリに直接データを挿入します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> INSERT INTO (SELECT * FROM T1) VALUES(2,2);
  ```

  実行が成功した後、テーブル内のデータを確認し、挿入が成功したことを確認します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
  ```

  実行結果は次のとおりです：

  ```shell
  +----+------+
  | C1 | C2   |
  +----+------+
  |  1 |    1 |
  |  2 |    2 |
  +----+------+
  2 rows in set
  ```

* `RETURNING` 句を含むデータの挿入。

  1. テーブル `T1` に1行のデータを挿入し、挿入行の `C1` 列のデータを返します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> INSERT INTO T1 VALUES(3,3) RETURNING C1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+
     | C1 |
     +----+
     |  3 |
     +----+
     1 row in set
     ```

  2. 再度テーブル内のデータを確認し、挿入が成功したことを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | C1 | C2   |
     +----+------+
     |  1 |    1 |
     |  2 |    2 |
     |  3 |    3 |
     +----+------+
     3 rows in set
     ```

`INSERT` ステートメントの詳細な構文については、[INSERT](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/200.insert-of-oracle-mode.md)を参照してください。

## データの削除

`DELETE` ステートメントを使用してデータを削除します。

例：テーブル `T1` から `C1=2` の行を削除します。

1. データを削除する前のテーブル `T1` の内容を確認します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
   ```

   実行結果は次のとおりです：

   ```shell
   +----+------+
   | C1 | C2   |
   +----+------+
   |  1 |    1 |
   |  2 |    2 |
   |  3 |    3 |
   +----+------+
   3 rows in set
   ```

2. テーブル `T1` から `C1=2` の行を削除します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> DELETE FROM T1 WHERE C1 = 2;
   ```

3. データを削除した後のテーブル `T1` の内容を確認します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
   ```

   実行結果は次のとおりです：

   ```shell
   +----+------+
   | C1 | C2   |
   +----+------+
   |  1 |    1 |
   |  3 |    3 |
   +----+------+
   2 rows in set
   ```

`DELETE` ステートメントの詳細な構文については、[DELETE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/100.delete-of-oracle-mode.md)を参照してください。

## データの更新

`UPDATE` ステートメントを使用して、テーブル内のフィールド値を変更します。

例：

* テーブル `T1` の `T1.C1=1` に対応する行の `C2` 列の値を `100` に変更します。

  1. データ更新前のテーブル `T1` のデータを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | C1 | C2   |
     +----+------+
     |  1 |    1 |
     |  3 |    3 |
     +----+------+
     2 rows in set
     ```

  2. テーブル `T1` の `T1.C1=1` に対応する行の `C2` 列の値を `100` に変更します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> UPDATE T1 SET T1.C2 = 100 WHERE T1.C1 = 1;
     ```

  3. データ更新後のテーブル `T1` のデータを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | C1 | C2   |
     +----+------+
     |  1 |  100 |
     |  3 |    3 |
     +----+------+
     2 rows in set
     ```

* サブクエリを直接操作し、サブクエリ内の `V.C1=3` に対応する行の `C2` 列の値を `300` に変更します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> UPDATE (SELECT * FROM T1) V SET V.C2 = 300 WHERE V.C1 = 3;
  ```

  ステートメントの実行が成功した後、データ更新後のテーブル `T1` のデータを確認します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> SELECT * FROM T1;
  ```

  実行結果は次のとおりです：

  ```shell
  +----+------+
  | C1 | C2   |
  +----+------+
  |  1 |  100 |
  |  3 |  300 |
  +----+------+
  2 rows in set
  ```

`UPDATE` ステートメントの詳細な構文については、[UPDATE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/600.update-of-oracle-mode.md)を参照してください。

## データのクエリ

`SELECT` ステートメントを使用して、テーブルの内容をクエリします。

例：

* `CREATE TABLE` を使用してテーブル `T2` を作成します。テーブル `T2` から `NAME` のデータを読み取ります。

  1. テーブル `t2` を作成します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> CREATE TABLE T2 (ID INT, NAME VARCHAR(50), NUM INT);
     ```

  2. テーブル `T2` に複数の行データを挿入します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> INSERT INTO T2 VALUES(1,'a',100),(2,'b',200),(3,'a',50);
     ```

  3. テーブル `T2` のデータを確認し、挿入が成功したことを確認します。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT * FROM T2;
     ```

     実行結果は次のとおりです：

     ```shell
     +------+------+------+
     | ID   | NAME | NUM  |
     +------+------+------+
     |    1 | a    |  100 |
     |    2 | b    |  200 |
     |    3 | a    |   50 |
     +------+------+------+
     3 rows in set
     ```

  4. テーブル `T2` からフィールド `NAME` のデータを読み取ります。

     ```shell
     obclient(SYS@oracletenant)[SYS]> SELECT NAME FROM T2;
     ```

     実行結果は次のとおりです：

     ```shell
     +------+
     | NAME |
     +------+
     | a    |
     | b    |
     | a    |
     +------+
     3 rows in set
     ```

* クエリ結果で `NAME` の重複処理を行います。

  ```shell
  obclient(SYS@oracletenant)[SYS]> SELECT DISTINCT NAME FROM T2;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+
  | NAME |
  +------+
  | a    |
  | b    |
  +------+
  2 rows in set
  ```

* テーブル `T2` からフィルター条件 `NAME = 'a'` に基づき、対応する `ID`、`NAME`、`NUM` を出力します。

  ```shell
  obclient(SYS@oracletenant)[SYS]> SELECT ID, NAME, NUM FROM T2 WHERE NAME = 'a';
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+------+
  | ID   | NAME | NUM  |
  +------+------+------+
  |    1 | a    |  100 |
  |    3 | a    |   50 |
  +------+------+------+
  2 rows in set
  ```

`SELECT` ステートメントの詳細な構文説明については、[SELECT](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/500.select-of-oracle-mode/100.simple-select-of-oracle-mode.md)を参照してください。

## トランザクションのコミット

`COMMIT` ステートメントを使用してトランザクションをコミットします。

トランザクションをコミットする前は、変更内容は現在のセッションにのみ可視され、他のデータベースセッションからは見えません。また、変更内容は永続化されていないため、`ROLLBACK` ステートメントで変更を取り消すことができます。

トランザクションをコミットすると、変更内容はすべてのデータベースセッションから可視されるようになります。変更結果は永続化されるため、`ROLLBACK` ステートメントで変更をロールバックすることはできません。

例：`CREATE TABLE` を使用してテーブル `T_INSERT` を作成します。`COMMIT` ステートメントを使用してトランザクションをコミットします。

1. テーブル `T_INSERT` を作成します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> CREATE TABLE T_INSERT(
        ID NUMBER NOT NULL PRIMARY KEY,
        NAME VARCHAR(10) NOT NULL,
        VALUE NUMBER NOT NULL,
        GMT_CREATE DATE NOT NULL DEFAULT sysdate
   );
   ```

2. テーブル `T_INSERT` に複数行のデータを挿入します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> INSERT INTO T_INSERT(ID, NAME, VALUE, GMT_CREATE) VALUES(1,'CN',10001, sysdate),(2,'US',10002, sysdate),(3,'EN',10003, sysdate);
   ```

3. 変更後のテーブル `T_INSERT` のデータを確認し、データが正常に挿入されたことを確認します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM T_INSERT;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+------------+
   | ID   | NAME | VALUE | GMT_CREATE |
   +------+------+-------+------------+
   |    1 | CN   | 10001 | 10-NOV-25  |
   |    2 | US   | 10002 | 10-NOV-25  |
   |    3 | EN   | 10003 | 10-NOV-25  |
   +------+------+-------+------------+
   3 rows in set
   ```

4. 再度、テーブル `T_INSERT` に1行のデータを挿入します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> INSERT INTO T_INSERT(ID, NAME, VALUE) VALUES(4,'JP',10004);
   ```

5. トランザクションをコミットします。

   ```shell
   obclient(SYS@oracletenant)[SYS]> COMMIT;
   ```

6. ログアウトします。

   ```shell
   obclient(SYS@oracletenant)[SYS]> exit;
   ```

7. データベースに再ログインします。


## トランザクションのロールバック

`ROLLBACK` ステートメントを使用すると、トランザクションをロールバックできます。

トランザクションのロールバックとは、トランザクションによる変更をすべて取り消すことです。未コミットのトランザクション全体をロールバックすることも、トランザクション内の任意のセーブポイントまでロールバックすることもできます。特定のセーブポイントまでロールバックする場合は、`ROLLBACK` と `TO SAVEPOINT` ステートメントを組み合わせて使用する必要があります。

ここで：

* トランザクション全体をロールバックする場合：

  * トランザクションは終了します。
  * すべての変更は破棄されます。
  * すべてのセーブポイントはクリアされます。
  * トランザクションが保持するすべてのロックが解放されます。

* 特定のセーブポイントまでロールバックする場合：

  * トランザクションは終了しません。
  * セーブポイント以前の変更は保持され、セーブポイント以降の変更は破棄されます。
  * 指定したセーブポイント以降のセーブポイント（指定したセーブポイント自身は除く）はクリアされます。
  * 指定したセーブポイント以降に、トランザクションが保持するすべてのロックが解放されます。

例：トランザクションのすべての変更をロールバックします。

1. 変更前のテーブル `T_INSERT` のデータを確認します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM T_INSERT;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+------------+
   | ID   | NAME | VALUE | GMT_CREATE |
   +------+------+-------+------------+
   |    1 | CN   | 10001 | 10-NOV-25  |
   |    2 | US   | 10002 | 10-NOV-25  |
   |    3 | EN   | 10003 | 10-NOV-25  |
   |    4 | JP   | 10004 | 10-NOV-25  |
   +------+------+-------+------------+
   4 rows in set
   ```

2. テーブル `T_INSERT` に2行のデータを挿入します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> INSERT INTO T_INSERT(ID, NAME, VALUE) VALUES(5,'FR',10005),(6,'RU',10006);
   ```

3. 変更後のテーブル `T_INSERT` のデータを確認し、データが正常に挿入されたことを確認します。

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM T_INSERT;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+------------+
   | ID   | NAME | VALUE | GMT_CREATE |
   +------+------+-------+------------+
   |    1 | CN   | 10001 | 10-NOV-25  |
   |    2 | US   | 10002 | 10-NOV-25  |
   |    3 | EN   | 10003 | 10-NOV-25  |
   |    4 | JP   | 10004 | 10-NOV-25  |
   |    5 | FR   | 10005 | 10-NOV-25  |
   |    6 | RU   | 10006 | 10-NOV-25  |
   +------+------+-------+------------+
   6 rows in set
   ```

4. トランザクションをロールバックします。

   ```shell
   obclient(SYS@oracletenant)[SYS]> ROLLBACK;
   ```

5. ロールバック後、再度テーブル `T_INSERT` のデータを確認すると、挿入したデータがロールバックされていることがわかります。

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM T_INSERT;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+------------+
   | ID   | NAME | VALUE | GMT_CREATE |
   +------+------+-------+------------+
   |    1 | CN   | 10001 | 10-NOV-25  |
   |    2 | US   | 10002 | 10-NOV-25  |
   |    3 | EN   | 10003 | 10-NOV-25  |
   |    4 | JP   | 10004 | 10-NOV-25  |
   +------+------+-------+------------+
   4 rows in set
   ```

その他のトランザクション制御ステートメントに関する説明については、[トランザクション管理の概要](../../300.develop/200.application-development-of-oracle-mode/600.transaction-in-develop-of-oracle-mode/100.transaction-management-overview-of-oracle-mode.md)を参照してください。
