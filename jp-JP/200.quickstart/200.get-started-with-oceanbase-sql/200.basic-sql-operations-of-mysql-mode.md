# SQLの基本操作（MySQLモード）

このセクションでは、OceanBaseデータベースのMySQLモードにおける基本的なSQL操作について説明します。

## データベースの作成

`CREATE DATABASE` ステートメントを使用してデータベースを作成します。

例：データベース `db1` を作成し、文字セットを `utf8mb4` に指定して、読み書き属性を設定します。

```shell
obclient(root@mysqltenant)[(none)]> CREATE DATABASE db1 DEFAULT CHARACTER SET utf8mb4 READ WRITE;
```

`CREATE DATABASE` ステートメントの詳細な構文については、[CREATE DATABASE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2100.create-database-of-mysql-mode.md)を参照してください。

作成後、`SHOW DATABASES` コマンドを使用して、現在のデータベースサーバー上のすべてのデータベースを確認できます。

```shell
obclient(root@mysqltenant)[(none)]> SHOW DATABASES;
```

実行結果は次のとおりです：

```shell
+--------------------+
| Database           |
+--------------------+
| db1                |
| information_schema |
| mysql              |
| oceanbase          |
| test               |
| test_db            |
+--------------------+
6 rows in set
```

## テーブルの操作

OceanBaseデータベースでは、テーブルが最も基本的なデータ格納単位であり、ユーザーがアクセス可能なすべてのデータを含んでいます。各テーブルは複数のレコードで構成され、各レコードは複数の列で構成されています。このセクションでは、データベース内のテーブルの作成、表示、変更、削除の構文と例を説明します。

### テーブルの作成

`CREATE TABLE` ステートメントを使用して、データベースに新しいテーブルを作成します。

例：データベース `db1` 内にテーブル `test` を作成します。

1. データベース `db1` に切り替えます。

   ```shell
   obclient(root@mysqltenant)[(none)]> USE db1;
   ```

2. テーブル `test` を作成します。

   ```shell
   obclient(root@mysqltenant)[db1]> CREATE TABLE test (c1 INT PRIMARY KEY, c2 VARCHAR(3));
   ```

`CREATE TABLE` ステートメントの詳細な構文については、[CREATE TABLE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2600.create-table-of-mysql-mode.md)を参照してください。

### テーブルの表示

`SHOW CREATE TABLE` ステートメントを使用して、テーブル作成ステートメントを表示します。

例：テーブル `test` のテーブル作成ステートメントを表示します。

```shell
obclient(root@mysqltenant)[db1]> SHOW CREATE TABLE test\G
```

実行結果は次のとおりです：

```shell
*************************** 1. row ***************************
        Table: test
  Create Table: CREATE TABLE `test` (
    `c1` int(11) NOT NULL,
    `c2` varchar(3) DEFAULT NULL,
    PRIMARY KEY (`c1`)
  ) ORGANIZATION INDEX DEFAULT CHARSET = utf8mb4 ROW_FORMAT = DYNAMIC COMPRESSION = 'zstd_1.3.8' REPLICA_NUM = 1 BLOCK_SIZE = 16384 USE_BLOOM_FILTER = FALSE ENABLE_MACRO_BLOCK_BLOOM_FILTER = FALSE TABLET_SIZE = 134217728 PCTFREE = 0
1 row in set
```

`SHOW TABLES` を使用して、指定したデータベース内のすべてのテーブルを確認することもできます。

例：`db1` データベース内のすべてのテーブルを確認します。

```shell
obclient(root@mysqltenant)[db1]> SHOW TABLES FROM db1;
```

実行結果は次のとおりです：

```shell
+---------------+
| Tables_in_db1 |
+---------------+
| test          |
+---------------+
1 row in set
```

その他の `SHOW` ステートメントに関する構文説明については、[SHOW](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8700.show-of-mysql-mode.md)を参照してください。

### テーブルの変更

`ALTER TABLE` ステートメントを使用して、既存のテーブルの構造を変更します。これには、テーブルやテーブル属性の変更、列の追加、列や属性の変更、列の削除などが含まれます。

例：

* テーブル `test` の列 `c2` の名前を `c3` に変更し、同時にその列の型も変更します。

  1. テーブル `test` の列定義を確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> DESCRIBE test;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+------------+------+-----+---------+-------+
     | Field | Type       | Null | Key | Default | Extra |
     +-------+------------+------+-----+---------+-------+
     | c1    | int(11)    | NO   | PRI | NULL    |       |
     | c2    | varchar(3) | YES  |     | NULL    |       |
     +-------+------------+------+-----+---------+-------+
     2 rows in set
     ```

  2. テーブル `test` の列 `c2` の名前を `c3` に変更し、同時にその列の型を `char` に変更します。

     ```shell
     obclient(root@mysqltenant)[db1]> ALTER TABLE test CHANGE COLUMN c2 c3 CHAR(10);
     ```

  3. 再度テーブル `test` の列定義を確認し、変更が成功したことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> DESCRIBE test;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+----------+------+-----+---------+-------+
     | Field | Type     | Null | Key | Default | Extra |
     +-------+----------+------+-----+---------+-------+
     | c1    | int(11)  | NO   | PRI | NULL    |       |
     | c3    | char(10) | YES  |     | NULL    |       |
     +-------+----------+------+-----+---------+-------+
     2 rows in set
     ```

* テーブル `test` に列を追加および削除します。

  1. 現在のテーブル `test` の列定義を確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> DESCRIBE test;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+----------+------+-----+---------+-------+
     | Field | Type     | Null | Key | Default | Extra |
     +-------+----------+------+-----+---------+-------+
     | c1    | int(11)  | NO   | PRI | NULL    |       |
     | c3    | char(10) | YES  |     | NULL    |       |
     +-------+----------+------+-----+---------+-------+
     2 rows in set
     ```

  2. テーブル `test` に列 `c4` を追加します。

     ```shell
     obclient(root@mysqltenant)[db1]> ALTER TABLE test ADD c4 int;
     ```

  3. 再度テーブル `test` の列定義を確認し、`c4` 列が正常に追加されたことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> DESCRIBE test;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+----------+------+-----+---------+-------+
     | Field | Type     | Null | Key | Default | Extra |
     +-------+----------+------+-----+---------+-------+
     | c1    | int(11)  | NO   | PRI | NULL    |       |
     | c3    | char(10) | YES  |     | NULL    |       |
     | c4    | int(11)  | YES  |     | NULL    |       |
     +-------+----------+------+-----+---------+-------+
     3 rows in set
     ```

  4. テーブル `test` から列 `c3` を削除します。

     ```shell
     obclient(root@mysqltenant)[db1]> ALTER TABLE test DROP c3;
     ```

  5. 再度テーブル `test` の列定義を確認し、`c3` 列が正常に削除されたことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> DESCRIBE test;
     ```

     実行結果は次のとおりです：

     ```shell
     +-------+---------+------+-----+---------+-------+
     | Field | Type    | Null | Key | Default | Extra |
     +-------+---------+------+-----+---------+-------+
     | c1    | int(11) | NO   | PRI | NULL    |       |
     | c4    | int(11) | YES  |     | NULL    |       |
     +-------+---------+------+-----+---------+-------+
     2 rows in set
     ```

`ALTER TABLE` ステートメントの詳細な構文説明については、[ALTER TABLE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1600.alter-table-of-mysql-mode.md)を参照してください。

### テーブルの削除

`DROP TABLE` ステートメントを使用してテーブルを削除します。

例：テーブル `test` を削除します。

```shell
obclient(root@mysqltenant)[db1]> DROP TABLE test;
```

`DROP TABLE` ステートメントの詳細な構文説明については、[DROP TABLE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/3700.drop-table-of-mysql-mode.md)を参照してください。

## インデックス操作

インデックスは、テーブル上に作成され、データベーステーブルの1列または複数列の値をソートするための構造です。主な役割はクエリの速度を向上させ、データベースシステムのパフォーマンスオーバヘッドを低減することです。このセクションでは、データベースにおけるインデックスの作成、表示、削除の構文と例について説明します。

### インデックスの作成

`CREATE INDEX` ステートメントを使用して、テーブルのインデックスを作成します。

例：テーブル `test` にインデックスを作成します。

1. テーブル `test` の列定義を確認します。

   ```shell
   obclient(root@mysqltenant)[db1]> DESCRIBE test;
   ```

   実行結果は次のとおりです：

   ```shell
   +-------+----------+------+-----+---------+-------+
   | Field | Type     | Null | Key | Default | Extra |
   +-------+----------+------+-----+---------+-------+
   | c1    | int(11)  | NO   | PRI | NULL    |       |
   | c2    | char(3)  | YES  |     | NULL    |       |
   +-------+----------+------+-----+---------+-------+
   2 rows in set
   ```

2. テーブル `test` の列 `c1` および `c2` に、`test_index` という名前の複合インデックスを作成します。

   ```shell
   obclient(root@mysqltenant)[db1]> CREATE INDEX test_index ON test (c1, c2);
   ```

`CREATE INDEX` ステートメントの詳細な構文については、[CREATE INDEX](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2200.create-index-of-mysql-mode.md)を参照してください。

## データの挿入

`INSERT` ステートメントを使用して、既存のテーブルにデータを挿入します。

例：

* テーブル `t1` を作成し、1行のデータを挿入します。

  1. テーブル `t1` を作成します。

     ```shell
     obclient(root@mysqltenant)[db1]> CREATE TABLE t1(c1 INT PRIMARY KEY, c2 int) PARTITION BY KEY(c1) PARTITIONS 4;
     ```

  2. テーブル内のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t1;
     ```

     クエリ結果は空で、テーブルにデータはありません。

  3. テーブル `t1` に1行のデータを挿入します。

     ```shell
     obclient(root@mysqltenant)[db1]> INSERT t1 VALUES(1,1);
     ```

  4. 再度テーブル内のデータを確認し、1行のデータが正常に挿入されたことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  1 |    1 |
     +----+------+
     1 row in set
     ```

* テーブル `t1` に複数行のデータを挿入します。

  1. 現在のテーブル内のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  1 |    1 |
     +----+------+
     1 row in set
     ```

  2. テーブル `t1` に複数行のデータを一度に挿入します。

     ```shell
     obclient(root@mysqltenant)[db1]> INSERT t1 VALUES(2,2),(3,default),(2+2,3*4);
     ```

  3. 再度テーブル内のデータを確認し、データが正常に挿入されたことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t1;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  1 |    1 |
     |  2 |    2 |
     |  3 | NULL |
     |  4 |   12 |
     +----+------+
     4 rows in set
     ```

`INSERT` ステートメントの詳細な構文については、[INSERT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5700.insert-sql-of-mysql-mode.md) を参照してください。

## データの削除

`DELETE` ステートメントを使用してデータを削除します。単一テーブルおよび複数テーブルのデータ削除をサポートしています。

例を説明しやすくするために、まずサンプルテーブル `t2` と `t3` を作成し、テーブルにデータを挿入します。

1. サンプルテーブル `t2` を作成し、データを挿入します。

   1. 非パーティションテーブル `t2` を作成します。

      ```shell
      obclient(root@mysqltenant)[db1]> CREATE TABLE t2(c1 INT PRIMARY KEY, c2 INT);
      ```

   2. テーブル `t2` に複数行のデータを挿入します。

      ```shell
      obclient(root@mysqltenant)[db1]> INSERT t2 VALUES(1,1),(2,2),(3,3),(5,5);
      ```

   3. テーブル内のデータを確認し、挿入が成功したことを確認します。

      ```shell
      obclient(root@mysqltenant)[db1]> SELECT * FROM t2;
      ```

      実行結果は次のとおりです：

      ```shell
      +----+------+
      | c1 | c2   |
      +----+------+
      |  1 |    1 |
      |  2 |    2 |
      |  3 |    3 |
      |  5 |    5 |
      +----+------+
      4 rows in set
      ```

2. サンプルテーブル `t3` を作成し、データを挿入します。

   1. `KEY` パーティションのパーティションテーブル `t3` を作成します。パーティション名は、システムがパーティションコマンドのルールに基づいて自動生成します。つまり、パーティション名は `p0`、`p1`、`p2`、`p3` となります。

      ```shell
      obclient(root@mysqltenant)[db1]> CREATE TABLE t3(c1 INT PRIMARY KEY, c2 INT) PARTITION BY KEY(c1) PARTITIONS 4;
      ```

   2. テーブル `t3` に複数行のデータを挿入します。

      ```shell
      obclient(root@mysqltenant)[db1]> INSERT INTO t3 VALUES(5,5),(1,1),(2,2),(3,3);
      ```

   3. テーブル内のデータを確認し、挿入が成功したことを確認します。

      ```shell
      obclient(root@mysqltenant)[db1]> SELECT * FROM t3;
      ```

      実行結果は次のとおりです：

      ```shell
      +----+------+
      | c1 | c2   |
      +----+------+
      |  5 |    5 |
      |  1 |    1 |
      |  2 |    2 |
      |  3 |    3 |
      +----+------+
      4 rows in set
      ```

例：

* テーブルから指定された行を削除します。

  1. 削除前のテーブル `t2` のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t2;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  1 |    1 |

     |  3 |    3 |
     |  5 |    5 |
     +----+------+
     4 rows in set
     ```

  2. テーブル `t2` から列 `c1` が `PRIMARY KEY` であるため、`c1=2` の行を削除します。

     ```shell
     obclient(root@mysqltenant)[db1]> DELETE FROM t2 WHERE c1 = 2;
     ```

  3. 削除後のテーブル `t2` のデータを確認し、削除が正常に行われたことを確認します。

     ```shell
     +----+------+

     |  5 |    5 |
     +----+------+
     3 rows in set
     ```

* 条件に合致する行をテーブルから削除します。

  1. 削除前のテーブル `t2` のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t2;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+

     +----+------+
     ```

  2. テーブル `t2` を列 `c2` でソートした後、最初の行のデータを削除します。

     ```shell
     obclient(root@mysqltenant)[db1]> DELETE FROM t2 ORDER BY c2 LIMIT 1;
     ```

  3. 削除後のテーブル `t2` のデータを確認し、削除が正常に行われたことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t2;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+

     +----+------+

     |  5 |    5 |

     3 rows in set
     ```

* テーブルの指定されたパーティションのデータを削除します。

  1. 削除前のテーブル `t3` のパーティション `p2` のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t3 PARTITION(p2);
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  1 |    1 |

     +----+------+
     3 rows in set
     ```

  2. テーブル `t3` のパーティション `p2` のデータを削除します。

     ```shell
     obclient(root@mysqltenant)[db1]> DELETE FROM t3 PARTITION(p2);
     ```

  3. 削除後のテーブル`t3`のデータを確認し、削除が成功したことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t3;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  5 |    5 |
     +----+------+
     1 row in set
     ```

* 複数のテーブルから同時にデータを削除します。

  1. 削除前のテーブル`t2`と`t3`のデータを確認します。

     テーブル`t2`のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t2;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+

     +----+------+
     ```

     テーブル`t3`のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t3;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  5 |    5 |
     +----+------+
     1 row in set
     ```

  2. `t2.c1 = t3.c1` のデータをテーブル`t2`と`t3`から削除します。

     ```shell
     obclient(root@mysqltenant)[db1]> DELETE t2, t3 FROM t2, t3 WHERE t2.c1 = t3.c1;
     ```

     このステートメントは、以下のものと同じです。

     ```shell
     obclient(root@mysqltenant)[db1]> DELETE FROM t2, t3 USING t2, t3 WHERE t2.c1 = t3.c1;
     ```

  3. 削除後のテーブル`t2`と`t3`のデータを確認し、削除が成功したことを確認します。

     テーブル`t2`のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t2;
     ```

     実行結果は次のとおりです：

     ```shell
     +----+------+
     | c1 | c2   |
     +----+------+
     |  3 |    3 |
     +----+------+
     1 row in set
     ```

     テーブル`t3`のデータを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t3;
     ```

     結果は空です。テーブル`t3`のデータは削除されました。

`DELETE`ステートメントの詳細な構文については、[DELETE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/3200.delete-of-mysql-mode.md)を参照してください。

## データのクエリ

`SELECT` ステートメントを使用して、テーブルの内容を照会します。

例：

* `CREATE TABLE` を使用してテーブル `t6` を作成します。テーブル `t6` から `name` のデータを読み取ります。

  1. テーブル `t6` を作成します。

     ```shell
     obclient(root@mysqltenant)[db1]> CREATE TABLE t6 (id INT, name VARCHAR(50), num INT);
     ```

  2. テーブル `t6` に複数行のデータを挿入します。

     ```shell
     obclient(root@mysqltenant)[db1]> INSERT INTO t6 VALUES(1,'a',100),(2,'b',200),(3,'a',50);
     ```

  3. テーブル `t6` のデータを確認し、挿入が成功したことを確認します。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT * FROM t6;
     ```

     実行結果は次のとおりです：

     ```shell
     +------+------+------+
     | ID   | NAME | NUM  |
     +------+------+------+
     |    1 | a    |  100 |
     |    2 | b    |  200 |
     |    3 | a    |   50 |
     +------+------+------+
     3 rows in set
     ```

  4. テーブル `t6` から `name` のデータを読み取ります。

     ```shell
     obclient(root@mysqltenant)[db1]> SELECT name FROM t6;
     ```

     実行結果は次のとおりです：

     ```shell
     +------+
     | NAME |
     +------+
     | a    |
     | b    |
     | a    |
     +------+
     3 rows in set
     ```

* クエリ結果で `name` の重複を除去します。

  ```shell
  obclient(root@mysqltenant)[db1]> SELECT DISTINCT name FROM t6;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+
  | NAME |
  +------+
  | a    |
  | b    |
  +------+
  2 rows in set
  ```

* テーブル `t6` からフィルタ条件 `name = 'a'` に基づき、対応する `id`、`name`、`num` を出力します。

  ```shell
  obclient(root@mysqltenant)[db1]> SELECT id, name, num FROM t6 WHERE name = 'a';
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+------+
  | ID   | NAME | NUM  |
  +------+------+------+
  |    1 | a    |  100 |
  |    3 | a    |   50 |
  +------+------+------+
  ```

## トランザクションのコミット

`COMMIT` ステートメントを使用してトランザクションをコミットします。

トランザクションをコミットする前に：

* お客様の変更は現在のセッションでのみ可視され、他のデータベースセッションからは見えません。
* お客様の変更は永続化されていません。ROLLBACKステートメントを使用して変更を取り消すことができます。

トランザクションをコミットした後：

* お客様の変更はすべてのデータベースセッションから可視されます。
* お客様の変更は正常に永続化されています。ROLLBACKステートメントで変更をロールバックすることはできません。

例：`CREATE TABLE` を使用してテーブル `t_insert` を作成します。`COMMIT` ステートメントを使用してトランザクションをコミットします。

1. テーブル `t_insert` を作成します。

   ```shell
   obclient(root@mysqltenant)[db1]> CREATE TABLE t_insert(
      id number NOT NULL PRIMARY KEY,
      name varchar(10) NOT NULL,
      value number,
      gmt_create DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
   );
   ```

2. トランザクションを開始します。

   ```shell
   obclient(root@mysqltenant)[db1]> BEGIN;
   ```

3. テーブル `t_insert` に複数行のデータを挿入します。

   ```shell
   obclient(root@mysqltenant)[db1]> INSERT INTO t_insert(id, name, value, gmt_create) VALUES(1,'CN',10001, current_timestamp),(2,'US',10002, current_timestamp),(3,'EN',10003, current_timestamp);
   ```

4. 変更後のテーブル `t_insert` のデータを確認します。データが正常に挿入されたことが確認できます。

   ```shell
   obclient(root@mysqltenant)[db1]> SELECT * FROM t_insert;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+---------------------+
   | id   | name | value | gmt_create          |
   +------+------+-------+---------------------+
   |    1 | CN   | 10001 | 2025-11-07 17:46:35 |
   |    2 | US   | 10002 | 2025-11-07 17:46:35 |
   |    3 | EN   | 10003 | 2025-11-07 17:46:35 |
   +------+------+-------+---------------------+
   3 rows in set
   ```

5. 再度、テーブル `t_insert` に1行のデータを挿入します。

   ```shell
   obclient(root@mysqltenant)[db1]> INSERT INTO t_insert(id,name) VALUES(4,'JP');
   ```

6. トランザクションをコミットします。

   ```shell
   obclient(root@mysqltenant)[db1]> COMMIT;
   ```

7. 現在のログインを終了します。

   ```shell
   obclient(root@mysqltenant)[db1]> exit;
   ```

8. データベースに再ログインします。

   ```shell
   obclient -h127.0.0.1 -ur**t@mysqltenant -P2881 -p****** -Ddb1
   ```

9. 再度、テーブル`t_insert`のデータを確認します。テーブル`t_insert`のデータ変更が正常に永続化されていることが確認できます。

   ```shell
   obclient(root@mysqltenant)[db1]> SELECT * FROM t_insert;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+---------------------+
   | id   | name | value | gmt_create          |
   +------+------+-------+---------------------+
   |    1 | CN   | 10001 | 2025-11-07 17:46:35 |
   |    2 | US   | 10002 | 2025-11-07 17:46:35 |
   |    3 | EN   | 10003 | 2025-11-07 17:46:35 |
   |    4 | JP   |  NULL | 2025-11-07 17:46:53 |
   +------+------+-------+---------------------+
   4 rows in set
   ```

トランザクション制御文の詳細については、[トランザクション管理の概要](../../300.develop/100.application-development-of-mysql-mode/600.transaction-in-develop-of-mysql-mode/100.transaction-management-overview-of-mysql-mode.md)を参照してください。

## トランザクションのロールバック

`ROLLBACK`ステートメントを使用してトランザクションをロールバックします。

トランザクションをロールバックするとは、トランザクションの変更をすべて取り消すことです。未コミットのトランザクション全体をロールバックすることも、トランザクション内の任意のセーブポイントまでロールバックすることもできます。特定のセーブポイントまでロールバックする場合は、`ROLLBACK`ステートメントと`TO SAVEPOINT`ステートメントを組み合わせて使用する必要があります。
その際：

* トランザクション全体をロールバックする場合：

  * トランザクションは終了します
  * すべての変更は破棄されます
  * すべてのセーブポイントはクリアされます
  * トランザクションが保持するすべてのロックが解放されます

* 特定のセーブポイントまでロールバックする場合：

  * トランザクションは終了しません
  * セーブポイント以前の変更は保持され、セーブポイント以降の変更は破棄されます
  * 対象となるセーブポイント以降のセーブポイント（対象セーブポイント自身は除く）はクリアされます
  * 対象セーブポイント以降にトランザクションが保持したすべてのロックが解放されます

例：トランザクションのすべての変更をロールバックします。

1. 変更前のテーブル`t_insert`のデータを確認します。

   ```shell
   obclient(root@mysqltenant)[db1]> SELECT * FROM t_insert;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+---------------------+
   | id   | name | value | gmt_create          |
   +------+------+-------+---------------------+
   |    1 | CN   | 10001 | 2025-11-07 17:46:35 |
   |    2 | US   | 10002 | 2025-11-07 17:46:35 |
   |    3 | EN   | 10003 | 2025-11-07 17:46:35 |
   +------+------+-------+---------------------+
   3 rows in set
   ```

2. トランザクションを開始します。

   ```shell
   obclient(root@mysqltenant)[db1]> BEGIN;
   ```

3. テーブル`t_insert`に複数行のデータを挿入します。

   ```shell
   obclient(root@mysqltenant)[db1]> INSERT INTO t_insert(id, name, value) VALUES(4,'JP',10004),(5,'FR',10005),(6,'RU',10006);
   ```

4. 変更後のテーブル`t_insert`のデータを確認します。データが正常に挿入されたことが確認できます。

   ```shell
   obclient(root@mysqltenant)[db1]> SELECT * FROM t_insert;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+---------------------+
   | id   | name | value | gmt_create          |
   +------+------+-------+---------------------+
   |    1 | CN   | 10001 | 2025-11-07 17:46:35 |
   |    2 | US   | 10002 | 2025-11-07 17:46:35 |
   |    3 | EN   | 10003 | 2025-11-07 17:46:35 |
   |    4 | JP   | 10004 | 2025-11-07 17:48:01 |
   |    5 | FR   | 10005 | 2025-11-07 17:48:01 |
   |    6 | RU   | 10006 | 2025-11-07 17:48:01 |
   +------+------+-------+---------------------+
   6 rows in set
   ```

5. トランザクションをロールバックします。

   ```shell
   obclient(root@mysqltenant)[db1]> ROLLBACK;
   ```

6. ロールバック後、再度テーブル`t_insert`のデータを確認すると、挿入したデータがロールバックされていることがわかります。

   ```shell
   obclient(root@mysqltenant)[db1]> SELECT * FROM t_insert;
   ```

   実行結果は次のとおりです：

   ```shell
   +------+------+-------+---------------------+
   | id   | name | value | gmt_create          |
   +------+------+-------+---------------------+
   |    1 | CN   | 10001 | 2025-11-07 17:46:35 |
   |    2 | US   | 10002 | 2025-11-07 17:46:35 |
   |    3 | EN   | 10003 | 2025-11-07 17:46:35 |
   +------+------+-------+---------------------+
   3 rows in set
   ```

トランザクション制御ステートメントの詳細については、[トランザクション管理の概要](../../300.develop/100.application-development-of-mysql-mode/600.transaction-in-develop-of-mysql-mode/100.transaction-management-overview-of-mysql-mode.md)を参照してください。
