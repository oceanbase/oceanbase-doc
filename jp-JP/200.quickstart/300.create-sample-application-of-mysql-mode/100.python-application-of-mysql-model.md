# Pythonサンプルアプリケーションの作成

本記事では、Pythonドライバーを使用してOceanBaseデータベースに接続し、使用する方法について説明します。異なるバージョンのPython環境では、使用するドライバーが異なります。Python 3.x系ではPyMySQLドライバー、Python 2.x系ではMySQL-pythonドライバーを使用する必要があります。

## 前提条件

ローカル環境にPythonランタイムがデプロイされていることを確認してください。

## Python 3.xによるアプリケーションの作成

Python 3.xでアプリケーションを作成する際は、データベースへの接続および使用にPyMySQLドライバーが必要です。

### ステップ１：データベース接続文字列を取得する

OceanBaseデータベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
obclient  -h100.88.xx.xx -uroot@test -p****** -P2881 -Doceanbase
```

データベース接続文字列には、データベースへのアクセスに必要なパラメータ情報が含まれています。アプリケーションを作成する前に、データベース接続文字列を使用してデータベースへのログインを検証し、接続文字列のパラメータ情報が正確であるか確認することができます。

パラメータの説明：

* **-h**：OceanBaseデータベースへの接続IPアドレス。ODPアドレスである場合もあります。
* **-u**：テナントの接続ユーザー名。書式は**ユーザー@テナント#クラスタ名**です。クラスタのデフォルトテナントは'sys'、テナントのデフォルト管理者ユーザーは'root'です。データベースに直接接続する場合はクラスタ名を入力しませんが、ODP経由で接続する場合は入力する必要があります。
* **-p**：ユーザーのパスワード。
* **-P**：OceanBaseデータベースの接続ポート番号。ODPのリスニングポートでもあります。
* **-D**：アクセス対象のデータベース名。

### ステップ2：PyMySQLドライバーをインストールする

PyMySQLは、Python3.x系でMySQLサーバーに接続するためのライブラリです。PyMySQLはPythonデータベースAPI v2.0規格に準拠しており、pure-Python MySQLクライアントライブラリを含んでいます。

PyMySQLの詳細については、[PyMySQL公式サイト](https://pypi.org/project/PyMySQL/)および[関連APIリファレンス](https://pymysql.readthedocs.io/en/latest/modules/index.html)を参照してください。

PyMySQLには、以下の2種類のインストール方法があります：

* コマンドラインによるインストール

   ```bash
   python3 -m pip install PyMySQL
   ```

* ソースコードからのコンパイルインストール

    ```bash
    git clone https://github.com/PyMySQL/PyMySQL
    cd PyMySQL/
    python3 setup.py install
    ```

### ステップ3：アプリケーションを作成する

実行例`test.py`を編集します。コードは以下のとおりです：

```python
#!/usr/bin/python3

import pymysql

conn = pymysql.connect(host="localhost", port=2881,
                       user="root", passwd="", db="test")

cur = conn.cursor()

try:

    #citiesテーブルを作成
    sql = 'create table cities (id int, name varchar(24))'
    cur.execute(sql)

    #citiesテーブルに2組のデータを挿入
    sql = "insert into cities values(1,'hangzhou'),(2,'shanghai')"
    cur.execute(sql)

    #citiesテーブル内のすべてのデータを照会
    sql = 'select * from cities'
    cur.execute(sql)
    ans = cur.fetchall()
    print(ans)

    #citiesテーブルを削除
    sql = 'drop table cities'
    cur.execute(sql)

finally:
    cur.close()
    conn.close()
```

コード内のデータベース接続パラメータを修正します。以下の項目を参考に、ステップ1で取得したデータベース接続文字列の対応する値を設定します。

* **user**：`-u`パラメータから取得します。テナントの接続ユーザー名。書式は**ユーザー@テナント#クラスタ名**です。クラスタのデフォルトテナントは'sys'、テナントのデフォルト管理者ユーザーは'root'です。データベースに直接接続する場合はクラスタ名を入力しませんが、ODP経由で接続する場合は入力する必要があります。

* **password**：`-p`パラメータから取得します。ユーザーのパスワード。

* **host**：`-h`パラメータから取得します。OceanBaseデータベースへの接続IPアドレス。ODPアドレスである場合もあります。

* **port**：`-P`パラメータから取得します。OceanBaseデータベースの接続ポート番号。ODPのリスニングポートでもあります。

* **db**：`-D`パラメータから取得します。アクセス対象のデータベース名。

### ステップ4：アプリケーションを実行する

コードの編集が完了したら、`test.py` を実行します。

```bash
python3 test.py
# 以下の結果が返された場合、データベースへの接続に成功し、サンプルステートメントが正しく実行されたことを示します。
((1, 'hangzhou'), (2, 'shanghai'))
```

### ステップ2：MySQL-pythonドライバーのインストール

MySQL-pythonは、PythonからMySQLデータベースに接続するためのインターフェースであり、PythonデータベースAPI仕様V2.0を実装しており、MySQL C APIに基づいて構築されています。

MySQL-pythonの詳細については、[MySQL-python公式サイト](https://pypi.org/project/MySQL-python/)および[Githubドキュメント](https://github.com/farcepest/MySQLdb1)を参照してください。

MySQL-pythonドライバーはyumを使用してインストールできます。コマンドは以下のとおりです：

```bash
yum install MySQL-python
```

### ステップ3：アプリケーションの作成

実行例`test2.py`を編集します。コードは以下のとおりです：

```python

    host='127.0.0.1',
    port = 2881,
    user='root',
    passwd='',
    db ='test'

try:

    #citiesテーブルの作成
    sql = 'create table cities (id int, name varchar(24))'

    sql = 'select * from cities'

```

* **user**：`-u`パラメータから取得します。テナントの接続ユーザー名。書式は**ユーザー@テナント#クラスタ名**となります。クラスタのデフォルトテナントは'sys'、テナントのデフォルト管理者ユーザーは'root'です。データベースに直接接続する場合はクラスタ名を入力しませんが、ODP経由で接続する場合は入力が必要です。

* **passwd**：`-p`パラメータから取得します。ユーザーのパスワード。

* **port**：`-P`パラメータから取得します。OceanBaseデータベースの接続ポート番号。ODPのリスニングポートでもあります。
