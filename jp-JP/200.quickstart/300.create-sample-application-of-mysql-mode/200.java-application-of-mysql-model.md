# Java サンプルアプリケーションの作成

OceanBase データベースは、MySQL 公式 JDBC ドライバーを使用した接続に対応しています。本記事では、MySQL Connector/J を使用して OceanBase データベースに接続し、使用する方法について説明します。

## 前提条件

* コンピュータの Java 環境が Java JDK 8 以上であることを確認します。

* MySQL Connector/J をインストールし、実行環境を設定します。

    MySQL Connector/J 5.1.47 バージョンが推奨されます。ダウンロードおよびインストール方法の詳細については、[Connector/J のダウンロード](https://downloads.mysql.com/archives/c-j/) および [Connector/J のインストール](https://dev.mysql.com/doc/connector-j/8.0/en/connector-j-installing.html) を参照してください。

## Java アプリケーションの作成

### 手順 1：データベース接続文字列の取得

OceanBase データベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
obclient  -h100.88.xx.xx -uroot@test -p****** -P2881 -Doceanbase
```

データベース接続文字列には、データベースへのアクセスに必要なパラメーター情報が含まれています。アプリケーションを作成する前に、データベース接続文字列を用いてデータベースへのログインを検証し、接続文字列のパラメーターが正確であるか確認することができます。

パラメーターの説明：

* **-h**：OceanBase データベースに接続する際の IP アドレスであり、ODP アドレスの場合もあります。
* **-u**：テナントの接続ユーザー名は、**ユーザー@テナント#クラスター名** の形式です。クラスターのデフォルトテナントは 'sys'、テナントのデフォルト管理者ユーザーは 'root' です。データベースに直接接続する場合、クラスター名は不要です。ODP を介して接続する場合は、クラスター名を入力する必要があります。
* **-p**：ユーザーパスワードです。
* **-P**：OceanBase データベースの接続ポートであり、ODP のリスニングポートでもあります。
* **-D**：アクセスが必要なデータベースの名前です。

### 手順 2：アプリケーションの作成

以下は、Linux 環境で Java ドライバー `Connector/J 5.1.47` を使用してデータベースに接続する例です。

MySQL Connector/J 5.1.47 ドライバーを正しくインストールし、環境を設定した後、以下の `Test.java` ファイルのサンプルコードを使用してデータベースに接続し、使用することができます。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>MySQL Connector/J 8.x を使用する場合、<code>Class.forName(&quot;com.mysql.jdbc.Driver&quot;)</code> の <code>com.mysql.jdbc.Driver</code> を <code>com.mysql.cj.jdbc.Driver</code> に置き換える必要があります。</p>
  </main>

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;

public class Test {
   public static void main(String[] args) {
       try {

            Class.forName("com.mysql.jdbc.Driver").newInstance();

            try{
                
                Connection connection = DriverManager.getConnection("jdbc:mysql://127.0.0.1:2881/test?user=r***&password=");
                System.out.println(connection.getAutoCommit());
                Statement sm = connection.createStatement();
                //テーブル t_meta_form の新規作成
                sm.executeUpdate("CREATE TABLE t_meta_form (name varchar(36) , id int)");
                //データの挿入
                sm.executeUpdate("insert into t_meta_form values ('an','1')");
                //データの検索と結果の出力
                ResultSet rs = sm.executeQuery("select * from t_meta_form");
                while (rs.next()) {
                    String name = rs.getString("name");
                    String id = rs.getString("id");
                    System.out.println(name + ','+ id);
                }
                //テーブルの削除
                sm.executeUpdate("drop table t_meta_form");                

            }catch(SQLException se){
                System.out.println("error!");
                se.printStackTrace() ;
            }
            }catch (Exception ex) {
                ex.printStackTrace();
        }
    }
}
```

コード内のデータベース接続パラメーターを変更します。以下のフィールドと連結方法を参照し、対応する値を、手順 1 で取得したデータベース接続文字列から取得します。

```java
connection = DriverManager.getConnection("jdbc:mysql://{host}:{port}/{dbname}?user={username}&password={******}")

//例
jdbc:mysql://100.88.xx.xx:2881/test?user=r***&password=******`
```

* **host**：`-h` パラメーターから取得した OceanBase データベースの接続アドレスで、ODP アドレスの場合もあります。

* **port**：`-P` パラメーターから取得した OceanBase データベースの接続ポートで、ODP のリスニングポートでもあります。

* **dbname**：`-D` パラメーターから取得したアクセスが必要なデータベースの名前です。

* **username**：`-u` パラメーターから取得したテナントの接続ユーザー名は、**ユーザー@テナント#クラスター名** の形式です。クラスターのデフォルトテナントは 'sys'、テナントのデフォルト管理者ユーザーは 'root' です。データベースに直接接続する場合、クラスター名は不要です。ODP を介して接続する場合は、クラスター名を入力する必要があります。

* **password**：`-p` パラメーターから取得したユーザーパスワードです。

### 手順 3：アプリケーションの実行

コードの編集が完了したら、以下のコマンドでコンパイルが可能になります：

```bash
#一時環境変数を設定する際は、mysql-connector-java-5.1.47.jar の実際のインストールパスに基づいて記入します。
export CLASSPATH=/usr/share/java/mysql-connector-java-5.1.47.jar:$CLASSPATH
#コンパイル
javac Test.java
```

コンパイル完了後、以下のコマンド使用して、`Test` を実行します：

```bash
java Test
#以下の結果が出力された場合は、データベースの接続に成功し、サンプル文が正しく実行されたことを意味します
true
an,1
```
