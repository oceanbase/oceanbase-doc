# OceanBase Community Edition クイックスタート

本記事では、利用シーンに基づいて、OceanBase データベースの 2 つのデプロイプラン、すなわち OceanBase データベースのクイックスタートと本番環境へのデプロイについて詳しく説明します。これにより、OceanBase データベースを迅速に習得し、活用できることを目指します。

## コンポーネントについて

* obd

  OceanBase Deployer は、OceanBase のインストール・デプロイツールで、obd と略称されます。詳細については、公式ドキュメント [OceanBase インストール・デプロイツール](https://en.oceanbase.com/docs/obd-en) を参照してください。

* ODP

  OceanBase Database Proxy、OceanBase データベースプロキシは、OceanBase データベース専用のプロキシサーバーであり、ODP (OBProxy とも呼ばれる) と略称されます。詳細については、公式ドキュメント [OceanBase データベースプロキシ](https://en.oceanbase.com/docs/odp-en) を参照してください。

* OCP Express

  Web ベースの OceanBase データベース 4.x 管理ツールは、OceanBase データベースクラスターに統合されており、データベースクラスターの主要なパフォーマンスと基本的なデータベース管理機能をサポートします。詳細については、[OceanBase クラウドプラットフォーム Express (OCP Express)](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971292) を参照してください。

* OBAgent

  OBAgent は OceanBase データベースの監視データ収集フレームワークであり、プッシュ型とプル型の 2 種類のデータ収集モードに対応しており、さまざまな利用シーンに対応可能です。

* Grafana

  Grafana はオープンソースのデータ可視化ツールであり、データソースの各種指標データを可視化して表示することで、システムの稼働状況とパフォーマンス指標をより直感的に把握することができます。詳細については、[Grafana 公式 Web サイト](https://grafana.com/) を参照してください。

* Prometheus

  Prometheus はオープンソースのモニタリングシステムおよび時系列データベースであり、汎用データモデルと高速なデータ収集、保存、およびクエリインターフェースを提供します。詳細については、[Prometheus 公式 Web サイト](https://prometheus.io/) を参照してください。

## プラン 1：OceanBase データベースのクイックスタート

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>本プランは本番環境には適用できません。本番環境で OceanBase データベースをデプロイする必要がある場合は、本ドキュメントの<a href="#プラン 2：本番環境へのデプロイ">プラン 2：本番環境へのデプロイ</a>をご確認ください。 </p>
</main>

このプランは、マシンが 1 台しかない場合、稼働可能な OceanBase データベース環境を迅速に構築するのに適しています。デプロイ済みの OceanBase データベース環境は、データベースの基本機能を備えており、OceanBase データベースを理解するのに役立ちます。ただし、この環境には分散型能力や高可用性特性が備わっておらず、長期的な使用は推奨されません。
以下の 4 つの方法で、OceanBase データベースをすぐに体験できます。

### 方法 1：All in One インストールパッケージの使用

```shell
bash -c "$(curl -s https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/download-center/opensource/oceanbase-all-in-one/installer.sh)"
source ~/.oceanbase-all-in-one/bin/env.sh
obd demo
```

上記はクイック体験用のコマンドです。最新バージョンの OceanBase All in One パッケージを **オンラインでダウンロード** し、**現在のアカウント** を使用して OceanBase データベースをデプロイします。その後は、obd コマンドで OceanBase データベースを管理できます。OceanBase All in One のオフラインインストール手順と obd demo コマンドの詳細については、公式 Web サイトの『OceanBase インストール・デプロイツール』ドキュメント [クイックスタート / obd のインストール](https://en.oceanbase.com/docs/community-obd-en-10000000001736381) と [obd コマンド / クイックデプロイコマンド](https://en.oceanbase.com/docs/community-obd-en-10000000001736374) を参照してください。

### 方法 2：RPM パッケージを直接使用

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この方法で OceanBase データベースをインストールできるのは、以下のシステムのみです。</p><ul><li>Anolis OS 8.X バージョン (カーネル Linux 3.10.0 以上)</li><li>CentOS Linux 7.X バージョン、8.X バージョン (カーネル Linux 3.10.0 以上)</li><li>Debian 10、11、12 バージョン (カーネル Linux 3.10.0 以上)</li><li>openEuler 22.03、24.03 バージョン (カーネル Linux 5.10.0 以上)</li><li>Ubuntu 18.04、20.04、22.04 バージョン (カーネル Linux 3.10.0 以上)</li></ul>
</main>

```shell
sudo bash -c "$(curl -s https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/download-center/opensource/service/installer.sh)"
```

上記はクイックスタートコマンドです。最新バージョンの RPM パッケージを **オンラインでダウンロード** し、`root`アカウントで直接インストールします。インストール後、systemctl コマンドで OceanBase データベースを管理できます。詳細な設定とオフラインインストール手順については、公式 Web サイトの『OceanBase データベース』ドキュメント [systemd を使用した OceanBase データベースのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/600.deploy-by-systemd.md) を参照してください。

### 方法 3：Docker によるクイックスタート

このプランは、Linux 以外の OS (例：Windows、macOS) を使用し、コンテナによって OceanBase データベースのデプロイと管理を行うことを希望するユーザーに適しています。このプランは、スケール化された検証が行われていないため、慎重に使用することを推奨します。

```shell
sudo docker run -p 2881:2881 --name obstandalone -e MODE=MINI -e OB_TENANT_PASSWORD=****** -d quay.io/oceanbase/oceanbase-ce
```

上記はクイックスタートコマンドです。最新のイメージを **オンラインでダウンロード** し、最小仕様の OceanBase データベースを起動します。その後は、docker コマンドで OceanBase データベースを管理できます。詳細設定については、公式 Web サイトの『OceanBase データベース』ドキュメント [OceanBase データベースコンテナ環境のデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/700.deploy-by-docker.md) を参照してください。

### 方法 4：OceanBase データベースデスクトップ版のインストール

OceanBase Desktop は、OceanBase データベースの管理と操作を行うためのデスクトップアプリケーションです。グラフィカルユーザーインターフェースにより、ユーザーはデータベース管理、クエリ実行、データインポート・エクスポートなどの操作を容易に行うことができます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBase Desktop は、Windows (x86-64 チップ搭載) および macOS (Apple Silicon チップ搭載) オペレーティングシステムでのみインストールできます。</p>
</main>

:::tab

tab Windows オペレーティングシステム

1. 依存関係のインストール

   具体的な操作方法については、[wsl のインストール方法](https://learn.microsoft.com/zh-cn/windows/wsl/install) を参照してください。

2. インストールパッケージをダウンロードする

   ダウンロードリンクにアクセスして、`exe` ファイル (例：`OceanBase-Desktop Setup 1.0.0.exe`) をダウンロードします。

3. アプリケーションをインストールして、OceanBase Desktop を起動します

   対応するインストールパッケージをダブルクリックして、OceanBase Desktop をインストールします。インストール後、`stop` 状態の OceanBase データベースが自動的にデプロイされます。グラフィカルインターフェース上の `start` ボタンをクリックすることで、OceanBase データベースを起動できます。

4. OceanBase Desktop に接続する

   コマンドラインで以下のコマンドを実行すると、起動済みの OceanBase Desktop に接続できます。

   ```shell
   wsl.exe -d oceanbase-desktop --exec obclient -h127.1 -P2881 -uroot@test -Doceanbase -A
   ```

tab macOS オペレーティングシステム

1. 依存関係のインストール

   以下のコマンドを実行して、qemu をインストールします。

   ```shell
   brew install qemu
   ```

2. インストールパッケージをダウンロードする

   ダウンロードリンクから `dmg` ファイル (例：`OceanBase-Desktop-1.0.0-arm64.dmg`) をダウンロードします。

3. アプリケーションをインストールして、OceanBase Desktop を起動します

   対応するインストールパッケージをダブルクリックして、OceanBase Desktop をインストールします。インストール後、プログラムは自動的に `stop` 状態の OceanBase データベースをデプロイします。グラフィカルインターフェース上の `start` をクリックすると、OceanBase データベースが起動します。

4. OceanBase Desktop に接続する

   コマンドラインで以下のコマンドを実行すると、起動済みの OceanBase Desktop に接続できます。

   ```shell
   mysql -h127.0.0.1 -P2881 -uroot@test -Doceanbase -A
   ```

:::

## プラン 2：本番環境へのデプロイ

OceanBase クラスターの本番環境は、実際の状況に応じて以下のいずれかの方法でデプロイできます。

### 方法 1：OceanBase All-in-One パッケージによるデプロイ

このプランは、OceanBase 分散データベースのアーキテクチャの原理と機能を深く理解する必要があるユーザーに適しています。デプロイされた OceanBase クラスターは、データベースのフル機能と分散高可用性を備えています。本プランでは、4vCPU、16 GB メモリ、100 GB SSD 以上の高性能ディスクを搭載したホストを少なくとも 3 台準備する必要があります。

* (推奨) OceanBase クラスターのグラフィカル管理
  
  複数の OceanBase クラスターをデプロイする場合、OCP (OceanBase クラウドプラットフォーム) のデプロイを推奨します。OCP は OceanBase データベースの運用保守と管理を効率化し、運用保守作業を大幅に削減します。
  
  まずは、3 台のマシンを使用して OCP および、その MetaDB をデプロイする必要があります。具体的な手順については、OceanBase 公式 Web サイトの『OceanBase インストール・デプロイツール』ドキュメント [使用ガイド / グラフィカルユーザーインターフェース / グラフィカルユーザーインターフェースによる OCP のデプロイ](https://en.oceanbase.com/docs/community-obd-en-10000000001736421) を参照してください。OCP のデプロイに成功後、OCP を使用して新しい OceanBase クラスターを作成し、ビジネスを支援できます。具体的な操作手順については、公式 Web サイトの『OceanBase クラウドプラットフォーム』ドキュメント [クラスター管理](https://en.oceanbase.com/docs/common-ocp-10000000001703562) セクションを参照してください。
  
  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>MetaDB は OCP のメタデータベースとしてのみ使用し、業務クラスターとしては使用しないでください。</p>
  </main>
  
* OceanBase クラスターのコマンドライン管理
  
  OceanBase クラスターを 1 セットだけデプロイする予定であれば、obd を使用して OceanBase クラスターをデプロイし、その後、obd コマンドで OceanBase クラスターを管理できます。具体的なデプロイ操作については、公式 Web サイトの『OceanBase データベース』ドキュメント [obd グラフィカルユーザーインターフェースによる OceanBase クラスターのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/400.deploy-by-ui/100.deploy-by-obd.md) を参照してください。obd コマンドの詳細については、公式 Web サイトの『OceanBase インストール・デプロイツール』ドキュメント [obd コマンド / クラスターコマンドグループ](https://en.oceanbase.com/docs/community-obd-en-10000000001736372) を参照してください。

### 方法 2：Kubernetes 環境での OceanBase クラスターのデプロイ

この方法は、本番環境で Kubernetes を大規模に導入済みであり、OceanBase データベースについて一定の知識と経験を持つユーザーを対象としています。デプロイ済みの OceanBase クラスターは、データベースのフル機能と分散型高可用性を備えています。始める前に、以下の条件を満たしていることをご確認ください。

* 使用可能な Kubernetes クラスターがあり、CPU 9 コア以上、メモリ 33 GB 以上、ストレージ 360 GB 以上のリソースが必要です。
* ob-operator は cert-manager に依存しています。cert-manager がインストール済みであることをご確認ください。cert-manager のインストール方法は、対応する [インストールドキュメント](https://cert-manager.io/docs/installation/) を参照してください。

具体的な操作手順については、公式 Web サイトの『OceanBase データベース』ドキュメント [Kubernetes 環境での OceanBase クラスターのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/300.deploy-in-the-k8s-cluster.md) を参照してください。
