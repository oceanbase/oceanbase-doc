# OceanBase Community Editionのクイックスタート

本記事では、使用シナリオに基づいてOceanBaseデータベースの2つのデプロイメントオプション、すなわちOceanBaseデータベースのクイックスタートと本番環境へのデプロイを詳しく説明します。これは、OceanBaseデータベースを迅速に習得し、成功裏に利用できるよう支援することを目的としています。

## コンポーネントの紹介

* obd

  OceanBase Deployer、OceanBaseインストールデプロイツール、略称はobdです。詳細については、公式ドキュメント[OceanBaseインストールデプロイツール](https://en.oceanbase.com/docs/obd-en)を参照してください。

* ODP

  OceanBase Database Proxy、OceanBaseデータベースプロキシは、OceanBaseデータベース専用のプロキシサーバーであり、略称はODP（OBProxyとも呼ばれます）。詳細については、公式ドキュメント[OceanBaseデータベースプロキシ](https://en.oceanbase.com/docs/odp-en)を参照してください。

* OBAgent

  OBAgentはOceanBaseデータベースモニタリング収集フレームワークであり、プッシュ型とプル型の2種類のデータ収集モードをサポートしており、さまざまなアプリケーションシナリオに対応できます。

* Grafana

  Grafanaはオープンソースのデータ可視化ツールであり、データソース内の各種メトリックデータを可視化表示することで、システムの稼働状態やパフォーマンス指標をより直感的に理解できるようにします。詳細については[Grafana公式サイト](https://grafana.com/)を参照してください。

* Prometheus

  Prometheusはオープンソースのサービス監視システムおよび時系列データベースであり、汎用的なデータモデルと迅速なデータ収集、保存、クエリのためのインターフェースを提供します。詳細については[Prometheus公式サイト](https://prometheus.io/)を参照してください。

## プラン1：OceanBaseデータベースを迅速に試用する

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このプランは本番環境には適用されません。本番環境でOceanBaseデータベースをデプロイする場合は、このドキュメントの<a href="#プラン2：本番環境へのデプロイ">プラン2：本番環境へのデプロイ</a>を参照してください。 </p>
</main>

このプランは、マシンが1台しかない場合に、迅速に利用可能なOceanBaseデータベース環境を構築するために適しています。デプロイされたOceanBaseデータベース環境は、データベースの基本的な機能を備えており、OceanBaseデータベースを理解するのに役立ちます。ただし、この環境には分散機能や高可用性機能は備わっていないため、長期間の使用は推奨されません。
以下の3つの方法で、OceanBaseデータベースを迅速に試用できます。

### 方法1：All-in-Oneインストールパッケージを使用する

```shell
bash -c "$(curl -s https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.2.0/en-US/2.quick-start/3.use-ui-deploy-oceanbase-02.png)"
source ~/.oceanbase-all-in-one/bin/env.sh
obd demo
```

上記はクイックスタートコマンドです。最新バージョンのOceanBase All-in-Oneパッケージを **オンラインでダウンロード** し、**現在のアカウント** を使用してOceanBaseデータベースを直接デプロイします。その後、obdコマンドを使用してOceanBaseデータベースを管理できます。OceanBase All-in-Oneのオフラインインストール手順とobd demoコマンドの詳細については、公式Webサイトの「OceanBaseインストールおよびデプロイツール」ドキュメント[クイックスタート／obdのインストール](https://www.oceanbase.com/docs/community-obd-cn-1000000001882001)および[obdコマンド／クイックデプロイコマンド](https://www.oceanbase.com/docs/community-obd-cn-1000000001881994)を参照してください。

`obd demo` コマンドが正常に実行されると、デプロイメントコンポーネントへの接続方法が出力されます。出力された接続文字列をコピーして実行し、rootユーザーでクラスタのsysテナントにログインします。クラスタにログインした後、SQL文を実行して簡単な機能体験を行うことができます。詳細については、[SQL基本操作（MySQLモード）](200.get-started-with-oceanbase-sql/200.basic-sql-operations-of-mysql-mode.md)を参照してください。

### 方法2：RPMパッケージを直接使用する

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
  <li>この方法はsystemctlコマンドに依存しています。非コンテナ環境で操作してください。</li>
  <li><p>この方法でOceanBaseデータベースをインストールする場合、以下のシステムのみがサポートされています：</p><ul><li>Anolis OS 8.Xバージョン（Linuxカーネル4.19バージョン以上）</li><li>CentOS Linux 8.Xバージョン（Linuxカーネル4.19バージョン以上）</li><li>Debian 10、11、12バージョン（Linuxカーネル4.19バージョン以上）</li><li>openEuler 22.03および24.03バージョン（Linuxカーネル5.10.0バージョン以上）</li><li>Ubuntu 18.04、20.04、22.04バージョン（Linuxカーネル4.19バージョン以上）</li></ul></li>
  </ul>
</main>

```shell
sudo bash -c "$(curl -s https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.1.0/en-US/2.quick-start/3.use-ui-deploy-oceanbase-03.png)"
```

上記はクイックスタートコマンドです。最新バージョンのRPMパッケージを **オンラインでダウンロード** し、`root` アカウントを使用して直接インストールします。その後、systemctlコマンドを使用してOceanBaseデータベースを管理できます。詳細な設定とオフラインインストール手順については、公式Webサイトの「OceanBaseデータベース」ドキュメント[systemdを使用したOceanBaseデータベースのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/600.deploy-by-systemd.md)を参照してください。

コマンドが正常に実行されると、OceanBaseデータベースへの接続方法が出力されます。出力された接続文字列をコピーして実行し、rootユーザーでクラスタのsysテナントにログインします。クラスタにログインした後、SQL文を実行して簡単な機能体験を行うことができます。詳細については、[SQL基本操作（MySQLモード）](200.get-started-with-oceanbase-sql/200.basic-sql-operations-of-mysql-mode.md)を参照してください。

### 方法3：Dockerを使用したクイックスタート

この方法は、Linux以外のOS（WindowsやmacOSなど）を使用し、コンテナを通じてOceanBaseデータベースをデプロイおよび管理したいユーザーに適しています。ただし、本番環境での検証が行われていないため、慎重にご利用ください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>x86アーキテクチャのMACマシンを使用する場合、OceanBaseデータベースのデプロイにはV4.9.0以降のバージョンのDockerのみがサポートされています。Dockerをダウンロードするには、<a href="https://desktop.docker.com/mac/main/amd64/81317/Docker.dmg?_gl=17jelfd_gcl_auOTk5Nzk0MDUwLjE3MTE4ODMyNzM._gaNDQyMjE1MDE5LjE3MTE4ODMyNzQ._ga_XJWPQMJYHQ*MTcxOTIxOTEwMy4xMS4xLjE3MTkyMjEwMTAuNjAuMC4w">リンク</a> をクリックしてください。</p>
</main>

```shell
sudo docker run -p 2881:2881 --name obstandalone -e MODE=MINI -d quay.io/oceanbase/oceanbase-ce
```

上記はクイックスタート用のコマンドです。最新のイメージを**オンラインでダウンロード**し、最小構成のOceanBaseデータベースを起動します。その後、dockerコマンドを使用してOceanBaseデータベースを管理できます。詳細な設定については、公式Webサイトの「OceanBaseデータベース」ドキュメント[OceanBaseデータベースコンテナ環境のデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/700.deploy-by-docker.md)を参照してください。

デプロイが成功したら、以下のコマンドを実行してrootユーザーとしてクラスタのsysテナントにログインします。クラスタにログインした後、SQL文を実行して簡単な機能を試すことができます。詳細については、[SQL基本操作（MySQLモード）](200.get-started-with-oceanbase-sql/200.basic-sql-operations-of-mysql-mode.md)を参照してください。

```shell
# Dockerコンテナに入る
sudo docker exec -it obstandalone bash
# クラスタに接続する。パスワードはデフォルトで空
obclient -uroot@sys -h127.0.0.1 -Doceanbase -P2881 -p
```

## プラン2：本番環境へのデプロイ

実際の状況に応じて、以下のいずれかの方法でOceanBaseクラスタを本番環境にデプロイできます。

### プラン1：OceanBase All-in-Oneパッケージを使用したデプロイ

このプランは、OceanBase分散データベースのアーキテクチャ原理や機能特性について深く理解しているユーザーに適しています。デプロイされたOceanBaseクラスタは、データベースの完全な機能と分散型の高可用性を備えています。このプランでは、少なくとも4vCPU、16GBメモリ、100GB以上のSSDまたはそれ以上のパフォーマンスを持つディスクを搭載した3台のホストが必要です。

* （推奨）OceanBaseクラスタのグラフィカル管理

  複数のOceanBaseクラスタをデプロイする場合は、OCP（OceanBaseクラウドプラットフォーム）のデプロイをお勧めします。OCPは、OceanBaseデータベースの運用保守と管理を容易にし、運用保守作業を大幅に削減します。

  まず、3台のマシンを使用してOCPとそのMetaDBをデプロイする必要があります。具体的な操作手順については、公式Webサイトの「OceanBaseインストール・デプロイツール」ドキュメント[使用ガイド/グラフィカルインターフェース/OCPのグラフィカルインターフェースによるデプロイ](https://www.oceanbase.com/docs/community-obd-cn-1000000001882005)を参照してください。OCPのデプロイに成功したら、OCPを使用して新しいOceanBaseクラスタを作成し、ビジネスにサービスを提供できます。具体的な操作手順については、公式Webサイトの「OceanBaseクラウドプラットフォーム」ドキュメント[クラスタ管理](https://www.oceanbase.com/docs/common-ocp-1000000001739837)の章を参照してください。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>MetaDBはOCPのメタデータベースとしてのみ使用してください。業務用クラスタとして使用しないでください。</p>
  </main>

* コマンドラインによるOceanBaseクラスタの管理

  一時的に1つのOceanBaseクラスタしかデプロイする予定がない場合は、obdを使用してOceanBaseクラスタをデプロイし、その後obdコマンドを使用してOceanBaseクラスタを管理できます。具体的なデプロイ操作については、公式Webサイトの「OceanBaseデータベース」ドキュメント[obdグラフィカルインターフェースによるOceanBaseクラスタのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/400.deploy-by-ui/100.deploy-by-obd.md)を参照してください。obdコマンドの紹介については、公式Webサイトの「OceanBaseインストール・デプロイツール」ドキュメント[obdコマンド/クラスタコマンドグループ](https://www.oceanbase.com/docs/community-obd-cn-1000000001881997)を参照してください。

### プラン2：Kubernetes環境でのOceanBaseクラスタのデプロイ

この方法は、本番環境で既に大規模にKubernetesが稼働しており、OceanBaseデータベースについて一定の知識と経験を持つユーザーに適しています。デプロイされたOceanBaseクラスタは、データベースの完全な機能と分散型の高可用性を備えています。開始する前に、以下の条件を満たしていることを確認してください：

* 利用可能なKubernetesクラスタがあり、少なくとも9個のCPUコア、33GBのメモリ、360GBのストレージ容量が確保されていること。
* ob-operatorはcert-managerに依存しているため、cert-managerがインストール済みであることを確認してください。cert-managerのインストール方法については、対応する[インストールドキュメント](https://cert-manager.io/docs/installation/)を参照してください。

具体的な操作手順については、公式Webサイトの「OceanBaseデータベース」ドキュメント[Kubernetes環境でのOceanBaseクラスタのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/300.deploy-in-the-k8s-cluster.md)を参照してください。
