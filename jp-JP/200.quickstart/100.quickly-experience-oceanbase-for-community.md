# OceanBaseデータベースCommunity Editionのクイックスタート

本記事では、ユースケースに基づき、OceanBaseデータベースを迅速にデプロイする方法を詳しく説明します。これにより、OceanBaseデータベースをすぐに習得し、スムーズに利用できるようになります。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このドキュメントは<b>本番環境には適用されません</b>。本番環境でOceanBaseデータベースをデプロイする場合は、<a href="../400.deploy/500.deploy-oceanbase-database-community-edition/100.deployment-overview.md">OceanBaseデータベースCommunity Editionデプロイ概要</a>を参照し、適切なデプロイ方法を選択してください。 </p>
</main>

## コンポーネント紹介

* obd

  OceanBase Deployer、OceanBaseインストールデプロイツール、略称obd。詳細は公式ドキュメント[OceanBaseインストールデプロイツール](https://www.oceanbase.com/docs/obd-cn)を参照してください。

* ODP

  OceanBase Database Proxy、OceanBaseデータベースプロキシは、OceanBaseデータベース専用のプロキシサーバーで、略称ODP（OBProxyとも呼ばれます）。詳細は公式ドキュメント[OceanBaseデータベースプロキシ](https://www.oceanbase.com/docs/odp-doc-cn)を参照してください。

* OBAgent

  OBAgentはOceanBaseデータベース監視収集フレームワークで、プッシュ型とプル型の2種類のデータ収集モードをサポートし、異なるアプリケーションシナリオに対応できます。

* Grafana

  Grafanaはオープンソースのデータ可視化ツールで、データソースのさまざまな指標データを可視化して表示し、システムの運用状態やパフォーマンス指標をより直感的に理解することができます。詳細は[Grafana公式サイト](https://grafana.com/)を参照してください。

* Prometheus

  Prometheusはオープンソースのサービス監視システムおよび時系列データベースで、汎用的なデータモデルと、高速なデータ収集・保存・クエリのインターフェースを提供します。詳細は[Prometheus公式サイト](https://prometheus.io/)を参照してください。

## OceanBaseデータベースをすぐに体験する

この方法は、マシンが1台しかない場合に、手早く利用可能なOceanBaseデータベース環境を構築するのに適しています。デプロイされるOceanBaseデータベース環境はデータベースの基本機能を備えており、OceanBaseデータベースを理解するのに役立ちます。ただし、分散機能や高可用性は備えていないため、長期的な使用は推奨されません。

以下のいずれかの方法で、OceanBaseデータベースをすぐに体験できます。

### 方法1：All-in-Oneインストールパッケージを使用する

以下のコマンドを実行して、OceanBase All-in-Oneをダウンロードしてインストールします。このコマンドは、最新バージョンのOceanBase All-in-Oneパッケージを**オンライン**でダウンロードしてインストールします。

```shell
bash -c "$(curl -s https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/download-center/opensource/oceanbase-all-in-one/installer.sh)"
source ~/.oceanbase-all-in-one/bin/env.sh
```

obdは以下の2種類のクイックデプロイコマンドを提供します：

* 最小構成デプロイ

  OceanBaseデータベースの最小構成で、単一ノードのOceanBaseデータベースおよび関連コンポーネントをデプロイして起動します。

  ```shell
  obd demo
  ```

* 最大構成デプロイ

  OceanBaseデータベースの最大構成で、単一ノードのOceanBaseデータベースおよび関連コンポーネントをデプロイして起動します。

  ```shell
  obd perf
  ```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>obdはV3.4.0から最大構成デプロイコマンド(<code>obd pref</code>)を提供しており、V4.0.0以降はコマンドが<code>obd perf</code>に更新されました。 </p>
  </main>

上記はクイック体験コマンドであり、**現在のアカウント**を使用してOceanBaseデータベース、ODP、監視コンポーネント(OBAgent、Grafana、Prometheus)を直接デプロイします。その後、obdコマンドを使用してOceanBaseデータベースおよびコンポーネントを管理できます。OceanBase All-in-Oneのオフラインインストール手順と`obd demo`/`obd perf`コマンドの詳細については、公式サイトの「OceanBaseインストール・デプロイツール」ドキュメント[クイックスタート/obdのインストール](https://www.oceanbase.com/docs/common-obd-cn-1000000004376514)および[obdコマンド/クイックデプロイコマンド](https://www.oceanbase.com/docs/common-obd-cn-1000000004376512)を参照してください。

`obd demo`/`obd perf`コマンドの実行が成功すると、デプロイされたコンポーネントへの接続方法が出力されます。その出力された接続文字列をコピーして`oceanbase-ce`コンポーネントで実行し、rootユーザーでクラスタのsysテナントにログインします。クラスタにログイン後、SQLステートメントを実行して簡単な機能を体験できます。詳細については[SQLの基本操作(MySQLモード)](200.get-started-with-oceanbase-sql/200.basic-sql-operations-of-mysql-mode.md)を参照してください。

### 方法2：RPMパッケージを直接使用する

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
  <li>この方法はsystemctlコマンドに依存しています。コンテナ環境以外で操作してください。</li>
  <li><p>この方法でOceanBaseデータベースをインストールする場合、以下のシステムのみをサポートしています：</p><ul><li>Anolis OS 8.X バージョン（Linuxカーネル 4.19 バージョン以上）</li><li>CentOS Linux 8.X バージョン（Linuxカーネル 4.19 バージョン以上）</li><li>Debian 10、11、12 バージョン（Linuxカーネル 4.19 バージョン以上）</li><li>openEuler 22.03 および 24.03 バージョン（Linuxカーネル 5.10.0 バージョン以上）</li><li>Ubuntu 18.04、20.04、22.04 バージョン（Linuxカーネル 4.19 バージョン以上）</li></ul></li>
  </ul>
</main>

```shell
sudo bash -c "$(curl -s https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/download-center/opensource/service/installer.sh)"
```

上記はクイック体験コマンドであり、最新バージョンのRPMパッケージを**オンラインでダウンロード**して、`root`アカウントで直接インストールします。その後、systemctlコマンドを使用してOceanBaseデータベースを管理できます。詳細な設定とオフラインインストールの手順については、公式サイトの「OceanBaseデータベース」ドキュメント[systemdを使用したOceanBaseデータベースのデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/600.deploy-by-systemd.md)を参照してください。

コマンドの実行が成功すると、OceanBaseデータベースの接続方法が出力されます。その出力された接続文字列をコピーして実行し、rootユーザーでクラスタのsysテナントにログインします。クラスタにログイン後、SQLステートメントを実行して簡単な機能を体験できます。詳細については[SQLの基本操作(MySQLモード)](200.get-started-with-oceanbase-sql/200.basic-sql-operations-of-mysql-mode.md)を参照してください。

### 方法3：Dockerを使用したクイック体験

この方法は、Linux以外のOS（WindowsやmacOSなど）を使用し、コンテナを利用してOceanBaseデータベースのデプロイや管理を実現したいユーザーに適しています。この方法は大規模環境での検証が行われていないため、慎重にご利用ください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>x86アーキテクチャのMACマシンを使用する場合、OceanBaseデータベースのデプロイはV4.9.0以下のDockerバージョンのみサポートされています。<a href="https://desktop.docker.com/mac/main/amd64/81317/Docker.dmg?_gl=17jelfd_gcl_auOTk5Nzk0MDUwLjE3MTE4ODMyNzM._gaNDQyMjE1MDE5LjE3MTE4ODMyNzQ._ga_XJWPQMJYHQ*MTcxOTIxOTEwMy4xMS4xLjE3MTkyMjEwMTAuNjAuMC4w">リンク</a> をクリックしてDockerをダウンロードしてください。</p>
</main>

```shell
sudo docker run -p 2881:2881 --name obstandalone -e MODE=MINI -d quay.io/oceanbase/oceanbase-ce
```

上記はクイック体験用のコマンドです。最新のイメージを**オンラインでダウンロード**し、最小構成のOceanBaseデータベースを起動します。その後、dockerコマンドを使用してOceanBaseデータベースを管理できます。詳細な設定については、公式サイトの「OceanBaseデータベース」ドキュメント[OceanBaseデータベースコンテナ環境のデプロイ](../400.deploy/500.deploy-oceanbase-database-community-edition/200.local-deployment/700.deploy-by-docker.md)を参照してください。

デプロイが成功したら、以下のコマンドを実行してrootユーザーでクラスタのsysテナントにログインします。クラスタにログイン後、SQLステートメントを実行して簡単な機能を体験できます。詳細については、[SQLの基本操作（MySQLモード）](200.get-started-with-oceanbase-sql/200.basic-sql-operations-of-mysql-mode.md)を参照してください。

```shell
# Dockerコンテナに入る
sudo docker exec -it obstandalone bash
# クラスタに接続する、パスワードはデフォルトで空
obclient -uroot@sys -h127.0.0.1 -Doceanbase -P2881 -p
```
