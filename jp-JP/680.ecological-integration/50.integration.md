# エコシステム統合の概要

OceanBaseは、高性能な分散リレーショナルデータベースとして、多様なツールを統合したエコシステムを段階的に構築してきました。これにより、データベース管理が簡素化され、運用効率が向上するとともに、多様なIT環境とのシームレスな連携が実現されています。

## 開発言語

* C：効率的な汎用プログラミング言語で、システムソフトウェアやアプリケーション開発に広く利用されています。詳細は[MySQL Connector/C による OceanBase データベース接続サンプルプログラム](../300.develop/100.application-development-of-mysql-mode/200.sample-program-of-mysql-mode/300.c-of-mysql-mode/100.connect-to-the-oceanbase-database-through-mysql-connector-c-of-mysql-mode.md)および[OceanBase Connector/C による OceanBase データベース接続サンプルプログラム](../300.develop/200.application-development-of-oracle-mode/200.sample-program-of-oracle-mode/300.c-of-oracle-mode/200.oceanbase-connector-odbc-connection-to-oceanbase-database-sample-program.md)を参照してください。
* Java：人気のオブジェクト指向プログラミング言語で、さまざまなアプリケーション分野に適しています。詳細は[OceanBase Connector/J による OceanBase データベース接続サンプルプログラム](../300.develop/200.application-development-of-oracle-mode/200.sample-program-of-oracle-mode/100.java-of-oracle-mode/100.oceanbase-connector-j-connection-to-oceanbase-database-sample-program.md)を参照してください。
* Python：多目的で高級なプログラミング言語で、読みやすい構文を備えています。詳細は[mysqlclient による OceanBase データベース接続サンプルプログラム](../300.develop/100.application-development-of-mysql-mode/200.sample-program-of-mysql-mode/200.python-of-mysql-mode/100.mysqlclient-connection-to-oceanbase-database-sample-program.md)を参照してください。

* PHP：広く使われているオープンソースのサーバーサイドスクリプト言語で、主にウェブサイト開発やサーバーサイドアプリケーションの作成に使用されます。詳細は[EXT ドライバーによる OceanBase データベース接続サンプルプログラム](../300.develop/100.application-development-of-mysql-mode/200.sample-program-of-mysql-mode/500.php-of-mysql-mode/100.ext-driver-connects-to-oceanbase-database.md)を参照してください。現在は Beta 状態にあり、初期テストは完了していますが、今後さらに徹底的な調整が必要です。
* Go：Google が開発した静的型付け・コンパイル型の言語で、並行処理と高効率で知られています。詳細は[Go-SQL-Driver/MySQL による OceanBase データベース接続サンプルプログラム](../300.develop/100.application-development-of-mysql-mode/200.sample-program-of-mysql-mode/400.go-of-mysql-mode/1.go-sql-driver-mysql-connection-oceanbase-sample-program.md)を参照してください。

## ORMフレームワーク

### Java

* SpringBoot：Spring アプリケーション開発を簡素化するフレームワークで、独立した本番レベルの Spring アプリケーションを迅速に構築できる機能を提供します。詳細は[SpringBoot による OceanBase データベース接続](200.orms-frameworks/100.java/100.connect-to-the-oceanbase-database-through-spring-boot.md)を参照してください。
* SpringBatch：バッチ処理タスク用のフレームワークで、大規模データの処理をサポートし、柔軟な実行および監視メカニズムを提供します。詳細は[SpringBatch による OceanBase データベース接続](200.orms-frameworks/100.java/200.connect-to-the-oceanbase-database-through-spring-batch.md)を参照してください。
* SpringJDBC：Spring JDBC は、Spring フレームワーク内でデータベースアクセスを簡素化するための重要なモジュールです。一連のクラスとインターフェースを提供し、Java アプリケーションからリレーショナルデータベースへのインタラクションをより簡単かつ効率的にします。詳細は [SpringJDBC による OceanBase データベース接続](200.orms-frameworks/100.java/300.connect-to-the-oceanbase-database-through-spring-jdbc.md)を参照してください。
* SpringJPA：Spring フレームワークの永続化レイヤーで、JPA スペックに基づき、データベース操作を簡素化し、コードの可読性を向上させます。詳細は[SpringJPA による OceanBase データベース接続](200.orms-frameworks/100.java/400.connect-to-the-oceanbase-database-through-springjpa.md)を参照してください。
* Hibernate：強力な ORM フレームワークで、Java オブジェクトとデータベーステーブルを自動マッピングし、複雑なクエリやトランザクション管理をサポートします。詳細は[Hibernate による OceanBase データベース接続](200.orms-frameworks/100.java/500.connect-to-the-oceanbase-database-through-hibernate.md)を参照してください。
* MyBatis：半自動化された永続化レイヤーフレームワークで、開発者が SQL をカスタマイズし、それを Java オブジェクトにマッピングできるため、柔軟性が高いです。詳細は[MyBatis による OceanBase データベース接続](200.orms-frameworks/100.java/600.connect-to-the-oceanbase-database-through-mybatis.md)を参照してください。

### Go

* **GORM**：機能豊富な ORM ライブラリで、シンプルな API、効率的なデータベース操作、多様なデータベースのサポート、およびマイグレーション機能を提供します。詳細は[GORM による OceanBase データベース接続サンプルプログラム](200.orms-frameworks/300.go/100.gorm-connection-oceanbase-database-program.md)を参照してください。

## データ統合

* Flink CDC：Flink は大規模データの処理と分析を目的としたオープンソースフレームワークで、Flink CDC はそのプラットフォーム上で実装されたデータベース変更イベントをキャプチャするコンポーネントです。両者を組み合わせることで、強力なリアルタイムデータ処理および分析ソリューションを提供できます。詳細は[Flink CDC を使用した MySQL データベースから OceanBase データベースへのデータ同期](../500.data-migration/200.migrate-data-from-mysql-database-to-oceanbase-database/600.use-flink-cdc-to-migrate-data-from-mysql-database-to-oceanbase-database.md)および[Flink CDC を使用した OceanBase データベースから MySQL データベースへのデータ移行](../500.data-migration/300.migrate-data-from-oceanbase-database-to-mysql-database/500.use-flink-cdc-to-migrate-data-from-oceanbase-database-to-mysql-database.md)を参照してください。
* Canal：データベース同期および統合のための変更データキャプチャ（CDC）フレームワークです。詳細は[Canal を使用した MySQL データベースから OceanBase データベースへのデータ同期](../500.data-migration/200.migrate-data-from-mysql-database-to-oceanbase-database/500.use-canal-to-migrate-data-from-mysql-database-to-oceanbase-database.md)および[Canal を使用した OceanBase データベースから MySQL データベースへのデータ同期](../500.data-migration/300.migrate-data-from-oceanbase-database-to-mysql-database/300.use-canal-to-migrate-data-from-oceanbase-database-to-mysql-database.md)を参照してください。
* AWS Glue：AWS Glue はサーバーレスのデータ統合サービスで、ユーザーが複数のソースからのデータを簡単に検出、準備、移動、統合し、分析、機械学習、アプリケーション開発を支援することを目的としています。データ検出、最新の ETL、データクレンジングと変換、そして一元化されたカタログといった包括的なデータ統合機能を単一のサービスで提供します。詳細は[AWS Glue を使用した OceanBase データの移行](https://www.oceanbase.com/docs/common-oceanbase-cloud-1000000001478166)を参照してください。
* dbt：SQL を通じてデータ変換を実現するオープンソースのデータ変換ツールで、コマンドをテーブルやビューに変換できます。詳細は[dbt を使用した OceanBase データの分析](400.data-ingestion/200.dbt.md)を参照してください。
* Maxwell：MySQL データベース用の変更データキャプチャ（CDC）ツールです。詳細は[Maxwell を使用した OceanBase データの読み取り](400.data-ingestion/1500.maxwell.md)を参照してください。
* SeaTunnel：分散型で高性能なデータ統合プラットフォームで、データ移行およびリアルタイムストリーム処理タスクに使用されます。詳細は[SeaTunnel を使用した OceanBase データの読み取りと同期](400.data-ingestion/1300.seatunnel.md)を参照してください。現在は Beta 状態にあり、初期テストは完了していますが、今後さらに徹底的な調整が必要です。
* Debezium：データベース変更を監視し、データ変動イベントをキャプチャして、イベントストリーム形式でさまざまなコンシューマーにエクスポートするためのオープンソースの分散型プラットフォームです。詳細は[Debezium を使用した OceanBase 接続とデータ取得](400.data-ingestion/1600.debezium.md)を参照してください。

## SQL開発

* Navicat：複数のデータベースを管理・開発できるツールで、多様なデータベースシステムへの接続をサポートします。詳細は[Navicat によるデータベース接続](500.sql-development/400.navicat.md)を参照してください。
* DBeaver：多機能で無料の汎用データベース管理ツールです。詳細は[DBeaver によるデータベース接続](500.sql-development/300.dbeaver.md)を参照してください。現在は Beta 状態にあり、初期テストは完了していますが、今後さらに徹底的な調整が必要です。
* DataGrip：JetBrains が開発した統合開発環境（IDE）で、データベース管理と SQL 開発専用です。データベース開発者やデータアナリストがデータベースの管理とクエリ、複雑な SQL クエリの作成、データベース設計およびメンテナンスをより効率的に行うのに役立ちます。詳細は[DataGrip での OceanBase データベース接続](500.sql-development/500.Datagrip.md)を参照してください。
* TablePlus：モダンでネイティブなデータベース管理ツールで、使いやすく親しみやすいグラフィカルユーザーインターフェースを提供し、MySQL、PostgreSQL、SQLite など、さまざまなリレーショナルデータベースの管理に使用できます。詳細は[TablePlus での OceanBase データベース接続](500.sql-development/600.Tableplus.md)を参照してください。
* Bytebase：ワークフローを簡素化するための協働型データベース管理ツールです。詳細は[ByteBase による OceanBase インスタンスの管理](1000.management/200.bytebase.md)を参照してください。現在は Beta 状態にあり、初期テストは完了していますが、今後さらに徹底的な調整が必要です。

* Grafana：主にOB Cloudクラウドデータベースのデータ監視に使用されます。詳細については、[Grafanaを使用したOB Cloud監視ダッシュボードの表示](https://www.oceanbase.com/docs/common-oceanbase-cloud-1000000001478761)を参照してください。

* Tableau：大量のデータ情報を整理・表示するために使用されます。直感的なインターフェースと強力なデータ処理機能を備えており、初心者からデータサイエンティストまで、誰もが効果的にデータの洞察を得ることができます。詳細については、[TableauでOceanBaseデータベースに接続する](700.visualization/500.tableau.md)を参照してください。現在はBeta版であり、初期テストは完了していますが、今後さらなる詳細な調整が予定されています。
