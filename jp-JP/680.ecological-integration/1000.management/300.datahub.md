# DataHubを使用したOceanBaseデータソースの管理

## 概要

DataHubは、エンドツーエンドのデータ検出、データ観測可能性、およびデータガバナンスを実現するための最新のデータカタログです。
本ドキュメントでは、OceanBaseをバックエンドストレージとして使用してDataHubサービスをデプロイする方法について説明し、簡単な例を通じてOceanBaseのメタデータ管理を示します。

## バージョン互換性

- OceanBaseバージョン：V4.2.4以上。
- DataHubバージョン：1.4.0.2（例）。

## 前提条件

DataHubを使用する前に、次のことを確認してください：
- OceanBaseデータベースのデプロイが完了し、MySQLモードのユーザーテナントが作成されていること。テナントの作成方法の詳細については、<a href="../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md">テナントの作成</a>を参照してください。
- Dockerのデプロイが完了し、Dockerサービスが実行中であり、現在のユーザーがdockerコマンドを実行する権限を持っていること（docker infoで確認可能）。
- Docker Compose V2がインストールされていること（docker-composeで確認可能）。
- Python 3.10+およびpipがインストールされていること。

### ステップ１：データベース接続文字列を取得する

OceanBaseデータベースのデプロイ担当者から接続文字列を取得します。例：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**
* `$host`：接続IP。ODP接続はODPアドレスを使用し、直接接続はOBServer IPを使用します。
* `$port`：接続ポート。ODPのデフォルトは`2883`、直接接続のデフォルトは`2881`です。
* `$database_name`：データベース名。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーには、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> および <code>SELECT</code> 権限が付与されていなければなりません。ユーザー権限の詳細については、<a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQLモードの権限分類</a>を参照してください。</p>
    </main>
* `$user_name`：接続アカウント。ODP形式：`ユーザー@テナント#クラスタ`または`クラスタ:テナント:ユーザー`。直接接続形式：`ユーザー@テナント`。
* `$password`：アカウントのパスワード。

接続文字列の詳細については、<a href="../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md">OBClientを使用してOceanBaseテナントに接続する</a>を参照してください。

**例：**
```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### ステップ2：DataHubのバックエンドストレージとしてOceanBaseを設定する

1. 依存関係をインストールし、環境変数を設定します。

```shell

datahub version #、datahubのバージョン情報を取得します。例：1.4.0.2

# 1. 必要な環境変数を設定します
datahub_version="1.4.0.2"

cat > .env << EOF
DATAHUB_VERSION=v${datahub_version}
UI_ingESTION_DEFAULTCLI_VERSION=${datahub_version}

# データベースの設定
host=your_database_host
port=your_database_port
user_name=your_database_username
password=your_database_password
database_name=your_database_dbname
EOF

source .env
```

### ステップ3：DataHubにアクセスする

1. DataHub UIページにアクセスします：`http://localhost:9002`、ログインユーザー名とパスワードは：`datahub` です。
2. DataHubサービスが正常に稼働していることを確認し、ログインして画面を確認できます。

### ステップ4：OceanBaseメタデータを管理する

OceanBaseをDataHubのバックエンドストレージとして使用するだけでなく、OceanBaseのメタデータを管理することもできます：

1. DataSourceページで、**Create source**ボタンをクリックします。
2. データソースタイプとして**MySQL**を選択します。
3. YAML設定ファイルを編集します。

```yaml
source:
type: mysql
config:
host_port: '$host:$port'
database: $database_name
username: $user_name
password: $password
include_tables: true
include_views: true
profiling:
enabled: true
profile_table_level_only: true
stateful_ingestion:
enabled: false
sink:
type: datahub-rest
config:
# docker inspect datahub-datahub-gms-quickstart-1 | grep "IPAddress"
server: 'http://172.19.0.5:8080'
```
データベースのアドレス、ポート番号、データベース名、ユーザー名、パスワードの取得については、ステップ1を参照してください。
YAML設定パラメータの詳細については、[DataHub公式Webサイト](https://docs.datahub.com/docs/generated/ingestion/sources/mysql)を参照してください。

4. **Next**と**Save & Run**をクリックします。
5. DataHub UIで、OceanBaseから取り込んだメタデータ情報を確認します。
