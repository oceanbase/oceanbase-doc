# OpenAI

OpenAI は、人工知能企業であり、これまでに複数の大規模言語モデルを開発しています。これらのモデルは、自然言語の理解や生成において優れた性能を発揮し、テキストの生成、質問への回答、対話などを行うことができます。これらのモデルは API を介してアクセスすることが可能です。

OceanBase データベースは、V4.3.3 バージョン以降、ベクトルタイプのストレージ、ベクトルインデックス、embedding ベクトル検索機能を提供しています。
OpenAI の API インターフェースを利用して、ベクトル化されたデータを OceanBase データベースにストレージし、OceanBase データベースのベクトル検索機能を使用して関連するデータをクエリします。

## 前提条件

* OceanBase データベース V4.3.3 以降のバージョンがデプロイ済みで、MySQL モードのテナントが作成されていること。[テナントの作成](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971591) の後、以下の手順を参照して操作してください。
* ご利用の環境には、既に利用可能な MySQL テナント、MySQL データベース、およびアカウントが存在し、データベースアカウントには読み書き権限が付与されていること。
* [Python 3.9 以降のバージョン](https://www.python.org/downloads/) と対応する [pip](https://pip.pypa.io/en/stable/installation/) をインストールします。
* [poetry](https://python-poetry.org/docs/)、[pyobvector](https://github.com/oceanbase/pyobvector)、OpenAI SDK をインストールします。

    ```shell
    python3 pip install poetry
    python3 pip install pyobvector
    python3 pip install openai
    ```

* [OpenAI API 秘密鍵](https://platform.openai.com/api-keys) を準備します。
* ベクトル検索機能を有効にするには、インスタンスで `ob_vector_memory_limit_percentage` 設定項目を既に設定していることを確認してください。推奨設定値は `30` です。より正確にこの設定項目を設定する必要がある場合は、[ob_vector_memory_limit_percentage](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001976671) を参照してこの値を計算してください。

## 手順 1：OceanBase データベースへの接続文字列を取得する

OceanBase データベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメーターの説明：**

* `$host`：OceanBase データベースへの接続 IP アドレスを提供します。OceanBase データベースプロキシ (OceanBase Database Proxy、ODP) 接続方式は ODP アドレスを使用し、直接接続方式は OBServer ノードの IP アドレスを使用します。
* `$port`：OceanBase データベースへの接続ポートを提供します。ODP 接続方式のデフォルトポートは `2883` で、ODP デプロイ時にカスタマイズ可能です。直接接続方式のデフォルトポートは `2881` で、OceanBase データベースのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセスするデータベースの名前。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーは、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および <code>SELECT</code> 権限が付与されていなければなりません。ユーザー権限の詳細については、<a href="https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974758">MySQL モードの権限分類</a>を参照してください。</p>
    </main>

* `$user_name`：テナントの接続アカウントを提供します。ODP 接続の一般的な形式：`ユーザー名@テナント名#クラスター名` または `クラスター名:テナント名:ユーザー名`、直接接続方式の形式：`ユーザー名@テナント名`。
* `$password`：アカウントのパスワードを提供します。

接続文字列の詳細については、[OBClient を使用して OceanBase テナントに接続する](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971649) を参照してください。

**例：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

## 手順 2：LLM プラットフォームアカウントに登録する

OpenAI API Key を取得する：

1. [OpenAI](https://platform.openai.com/) プラットフォームにログインします。

2. 右上の **API Keys** をクリックします。

3. **Create API Key** をクリックします。

4. 関連情報を入力し、**Create API Key** をクリックします。

OpenAI API Key を環境変数に設定する：

* Unix ベースのシステム (例えば、Ubuntu や MacOS) では、以下のコマンドをターミナルで実行することができます：

    ```shell
    export OPENAI_API_KEY='your-api-key'
    ```

* Windows システムでは、コマンドプロンプトで以下のコマンドを実行することができます：

    ```shell
    set OPENAI_API_KEY=your-api-key
    ```

`your-api-key` を実際の OpenAI API 秘密鍵に置き換えてください。

## 手順 3：OceanBase データベースにベクトルデータをストレージする

### OceanBase データベースにベクトルデータをストレージする

1. テストデータの準備

    事前に計算されたベクトル化データを含む [CSV](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240827/srxyhu/fine_food_reviews.csv) ファイルをダウンロードします。この CSV ファイルには、1000 件のグルメレビューデータセットが含まれており、最後の列はベクトル化された値であるため、ベクトルを再度計算する必要はありません。 以下のコードを使用して embedding 列 (つまりベクトル列) を再度計算し、新しい CSV ファイルを生成します。

    ```shell
    from openai import OpenAI
    import pandas as pd
    input_datapath = "./fine_food_reviews.csv"
    client = OpenAI()
    ## ここでは、text-embedding-ada-002 埋め込みモデルを使用しており、必要に応じて調整することができます
    def embedding_text(text, model="text-embedding-ada-002"):
        # embedding ベクトルを作成する方法については、以下を参照してください：https://community.openai.com/t/embeddings-api-documentation-needs-to-updated/475663
        res = client.embeddings.create(input=text, model=model)
        return res.data[0].embedding
    df = pd.read_csv(input_datapath, index_col=0)
    # 実際の生成には数分かかる場合があります。OpenAI Embedding API を逐次呼び出します
    df["embedding"] = df.combined.apply(embedding_text)
    output_datapath = './fine_food_reviews_self_embeddings.csv'
    df.to_csv(output_datapath)
    ```

2. 以下のスクリプトを実行して、テストデータを OceanBase データベースに挿入します。スクリプトのディレクトリは、テストデータのディレクトリと同じである必要があります。

```shell
    import os
    import sys
    import csv
    import json
    from pyobvector import *
    from sqlalchemy import Column, Integer, String
    # pyobvector を使用して OB に接続する際、ユーザー名とパスワードに @ 記号が含まれる場合は、%40 に置き換えてください
    client = ObVecClient(uri="host:port", user="username",password="****",db_name="test")
    # 事前に準備されたテストデータセットは、ベクトル化されており、デフォルトで Python スクリプトと同じディレクトリ内に配置されています。ご自身で再度ベクトル化する場合は、対応するファイルに置き換える必要があります。
    file_name = "fine_food_reviews.csv"
    file_path = os.path.join("./", file_name)
    # 列を定義し、ベクトル化された列を最後のフィールドに配置されています
    cols = [
        Column('id', Integer, primary_key=True, autoincrement=False),
        Column('product_id', String(256), nullable=True),
        Column('user_id', String(256), nullable=True),
        Column('score', Integer, nullable=True),
        Column('summary', String(2048), nullable=True),
        Column('text', String(8192), nullable=True),
        Column('combined', String(8192), nullable=True),
        Column('n_tokens', Integer, nullable=True),
        Column('embedding', VECTOR(1536))
    ]
    # テーブル名
    table_name = 'fine_food_reviews'
    # テーブルが存在しない場合、テーブルを作成します
    if not client.check_table_exists(table_name):
        client.create_table(table_name,columns=cols)
        # ベクトル列のインデックスの作成
        client.create_index(
            table_name=table_name,
            is_vec_index=True,
            index_name='vidx',
            column_names=['embedding'],
            vidx_params='distance=l2, type=hnsw, lib=vsag',
        )
    ## CSV ファイルを開いて読み取り
    with open(file_name, mode='r', newline='', encoding='utf-8') as csvfile:
        csvreader = csv.reader(csvfile)
        # タイトル行の読み取り
        headers = next(csvreader)
        print("Headers:", headers)
        batch = [] # データをストレージし、10 行ごとにデータベースに 1 回挿入します
        for i, row in enumerate(csvreader):
            # CSV ファイルには 9 つのフィールドがあります： id,product_id,user_id,score,summary,text,combined,n_tokens,embedding
            if not row:
                break
            food_review_line= {'id':row[0],'product_id':row[1],'user_id':row[2],'score':row[3],'summary':row[4],'text':row[5],\
            'combined':row[6],'n_tokens':row[7],'embedding':json.loads(row[8])}
            batch.append(food_review_line)
            # 10 行ごとに 1 回挿入する
            if (i + 1) % 10 == 0:
                client.insert(table_name,batch)
                batch = []  # キャッシュをクリア
        ## 残りの行を挿入する (もしあれば)
        if batch:
            client.insert(table_name,batch)
    # テーブル内のデータをチェックして、すべてのデータが挿入されていることを確認します
    count_sql = f"select count(*) from {table_name};"
    cursor = client.perform_raw_text_sql(count_sql)
    result = cursor.fetchone()
    print(f"インポートされたデータの合計数：{result[0]}")
```

### OceanBase データベースのデータをクエリします

1. 以下の Python スクリプトを保存し、`openAIQuery.py` という名前にします。

    ```shell
        import os
        import sys
        import csv
        import json
        from pyobvector import *
        from sqlalchemy import func
        from openai import OpenAI
        # コマンドラインパラメーターを取得する
        if len(sys.argv) != 2:
            print("クエリステートメントを入力してください。")
            sys.exit()
        queryStatement = sys.argv[1]
        # pyobvector を使用して OB に接続する際、ユーザー名とパスワードに @ 記号が含まれる場合は、%40 に置き換えてください
        client = ObVecClient(uri="host:port", user="usename",password="****",db_name="test")
        openAIclient = OpenAI()
        # テキストベクトルを生成する関数を定義する
        def generate_embeddings(text, model="text-embedding-ada-002"):
            # embedding ベクトルを作成する方法については、以下を参照してください：https://community.openai.com/t/embeddings-api-documentation-needs-to-updated/475663
            res = openAIclient.embeddings.create(input=text, model=model)
            return res.data[0].embedding

        def query_ob(query, tableName, vector_name="embedding", top_k=1):
            embedding = generate_embeddings(query)
            ## 近似最近傍検索の実行
            res = client.ann_search(
                table_name=tableName,
                vec_data=embedding,
                vec_column_name=vector_name,
                distance_func=func.l2_distance,
                topk=top_k,
                output_column_names=['combined']
            )
            for row in res:
                print(str(row[0]).replace("Title: ", "").replace("; Content: ", ": "))
        # テーブル名
        table_name = 'fine_food_reviews'
        query_ob(queryStatement,table_name,'embedding',1)
    ```

2. 質問を入力して、関連する回答を出力します。

    ```shell
    python3 openAIQuery.py 'pet food'
    ```

    期待される結果は次のとおりです：

    ```shell
    Crack for dogs.: These thing are like crack for dogs. I am not sure of the make-up but the doggies sure love them.
    ```
