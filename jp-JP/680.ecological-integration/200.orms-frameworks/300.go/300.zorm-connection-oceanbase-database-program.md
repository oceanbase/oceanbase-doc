# zorm により OceanBase データベースに接続するサンプルプログラム

zorm は、Go アプリケーション向けに設計された、ネイティブ SQL をベースとする Go 言語の軽量 ORM フレームワークです。次の特徴があります。

* `Finder` を使用して SQL を構築し、ネイティブ SQL の柔軟性を維持しながら、学習コストを抑えます。
* コアライブラリは依存関係がなく、データベースドライバーは必要に応じて導入します。
* `context.Context` を使用してトランザクションを伝播し、複数データソースと読み書き分離をサポートします。
* MySQL、PostgreSQL、Oracle、SQLite などのデータベースをサポートします。

本記事では、zorm を使用して OceanBase データベースに接続し、テーブルの作成、データの挿入、データの更新、データのクエリ、データの削除などの基本的なデータベース操作を実行する方法を紹介します。

<main id="notice" type='explain'>
  <h4>機能適用性</h4>
  <p>zorm ORM は、OceanBase データベースの MySQL モードに適用されます。</p>
</main>

## 前提条件

* Go 1.13 以降がインストールされていること。
* OceanBase データベースがインストールされ、MySQL モードのテナントが作成されていること。
* OceanBase データベースの接続文字列を取得していること。

## 操作手順

1. OceanBase データベースの接続文字列を取得します。
2. Go 言語と zorm をインストールします。
3. `main.go` ファイルを作成し、データベース操作を実装します。
4. プログラムを実行し、結果を確認します。

### 手順 1：OceanBase データベースの接続文字列を取得する

OceanBase データベースのデプロイ担当者または管理者に連絡し、対応するデータベース接続文字列を取得します。

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメーターの説明：**

* `$host`：OceanBase データベースに接続するための IP アドレス。OceanBase Database Proxy（ODP）接続方式では ODP のアドレスを使用し、直接接続方式では OBServer ノードの IP アドレスを使用します。
* `$port`：OceanBase データベースに接続するためのポート。ODP 接続方式のデフォルトポートは `2883` で、ODP のデプロイ時にカスタマイズできます。直接接続方式のデフォルトポートは `2881` で、OceanBase データベースのデプロイ時にカスタマイズできます。
* `$database_name`：アクセスするデータベースの名前。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーには、このデータベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>UPDATE</code>、<code>SELECT</code>、<code>DELETE</code> 権限が必要です。ユーザー権限の詳細については、<a href="https://docs.oceanbase.com/jp/oceanbase-database/privilege-types-mysql-compatible-mode">MySQL モードの権限分類</a>を参照してください。リンク先はオンラインドキュメントであり、本ガイドの対象バージョンと異なる場合があります。</p>
    </main>

* `$user_name`：テナントに接続するためのアカウント。ODP 接続の一般的な形式は `ユーザー名@テナント名#クラスター名` または `クラスター名:テナント名:ユーザー名` で、直接接続方式の形式は `ユーザー名@テナント名` です。
* `$password`：アカウントのパスワード。

接続文字列の詳細については、[OBClient を使用して OceanBase テナントに接続する](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md) を参照してください。

**例：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 手順 2：Go 言語と zorm をインストールする

Go がすでにインストールされている場合は、下記の手順 1（Go のインストール）のみスキップできます。zorm を別のプロジェクトで使用したことがある場合でも、このサンプル用の作業ディレクトリの作成、Go モジュールの初期化、依存関係のインストールが必要なため、手順 2 以降を実行してください。

1. Go 言語をインストールします。

    1. システムパッケージを更新し、必要な依存関係をインストールします：

        ```bash
        sudo apt update
        sudo apt install -y wget
        ```

    2. Go 言語をダウンロードしてインストールします：

        ```bash
        # Go 1.25.14 をダウンロードします（ここでは 1.25.14 を例として使用しています。最新バージョンは https://go.dev/dl/ を参照してください）。
        wget https://go.dev/dl/go1.25.14.linux-amd64.tar.gz

        # /usr/local ディレクトリに解凍します。
        sudo tar -C /usr/local -xzf go1.25.14.linux-amd64.tar.gz

        # インストールパッケージを削除します。
        rm go1.25.14.linux-amd64.tar.gz
        ```

    3. 環境変数を設定します：

        ```bash
        # ~/.bashrc ファイルを編集します。
        echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
        echo 'export GOPATH=$HOME/go' >> ~/.bashrc
        echo 'export PATH=$PATH:$GOPATH/bin' >> ~/.bashrc

        # 設定を反映します。
        source ~/.bashrc
        ```

    4. インストールを確認します：

        ```bash
        go version
        ```

        インストールに成功した場合、次のような出力が表示されます：

        ```bash
        go version go1.25.14 linux/amd64
        ```

2. zorm と MySQL ドライバーをインストールします。

    1. 作業ディレクトリを作成し、Go モジュールを初期化します：

       ```bash
       mkdir -p ~/go/src/zorm-oceanbase
       cd ~/go/src/zorm-oceanbase
       go mod init zorm-oceanbase
       ```

    2. zorm と MySQL ドライバーをインストールします：

       ```bash
       go get gitee.com/chunanyong/zorm
       go get github.com/go-sql-driver/mysql@v1.7.1
       ```

    3. （オプション）ネットワークの問題により直接インストールできない場合は、Go プロキシを設定します：

       ```bash
       go env -w GOPROXY=https://goproxy.cn,direct
       ```

       その後、インストールコマンドを再実行します。

3. インストールを確認します：

    ```bash
    go list -m gitee.com/chunanyong/zorm
    go list -m github.com/go-sql-driver/mysql
    ```

    インストールに成功した場合、対応するバージョン情報が表示されます。

### 手順 3：main.go ファイルを作成してデータベース操作を実装する

zorm は自動移行機能を提供しておらず、`Insert`、`Update`、`Delete` などの書き込み操作は、明示的に `zorm.Transaction` 内で実行する必要があります。この例では、`UpdateFinder` を使用して `users` テーブルを作成し、トランザクション内でデータの書き込みを完了します。本番環境では、データベースのバージョン管理ツールを使用してテーブル構造を維持することを推奨します。

次のコードの DSN を手順 1 で取得した接続情報に置き換えてください。ユーザー名、テナント名、データベース名、ポートは、手順 1 の接続文字列と一致している必要があります。その後、`main.go` として保存してください。

1. `main.go` という名前のファイルを作成し、次のコードを追加します：

    ```go
    package main

    import (
        "context"
        "fmt"
        "log"
        "time"

        "gitee.com/chunanyong/zorm"
        _ "github.com/go-sql-driver/mysql"
    )

    const usersTableName = "users"

    // User はユーザーモデルを定義します。
    type User struct {
        zorm.EntityStruct

        ID        int64     `column:"id"`
        Username  string    `column:"username"`
        Email     string    `column:"email"`
        Age       int       `column:"age"`
        CreatedAt time.Time `column:"created_at"`
        UpdatedAt time.Time `column:"updated_at"`
    }

    // GetTableName はテーブル名を指定します。
    func (u *User) GetTableName() string {
        return usersTableName
    }

    // GetPKColumnName は主キー列名を指定します。
    func (u *User) GetPKColumnName() string {
        return "id"
    }

    // initDB はデータベース接続を初期化します。
    func initDB() error {
        config := zorm.DataSourceConfig{
            // DSN の parseTime=true は時間型を自動的に time.Time に変換し、loc=Local はタイムゾーンを設定します。
            DSN:                   "root@mysql001:**********@tcp(xxx.xxx.xxx.xxx:2881)/db_test?charset=utf8mb4&parseTime=true&loc=Local",
            DriverName:            "mysql",
            Dialect:               "mysql",
            MaxOpenConns:          50,
            MaxIdleConns:          20,
            ConnMaxLifetimeSecond: 600,
            SlowSQLMillis:         -1,
        }

        if _, err := zorm.NewDBDao(&config); err != nil {
            return fmt.Errorf("zorm の初期化に失敗しました: %w", err)
        }
        return nil
    }

    // createTable はユーザーテーブルを作成します。
    func createTable(ctx context.Context) error {
        const ddl = `CREATE TABLE IF NOT EXISTS users (
            id BIGINT NOT NULL AUTO_INCREMENT,
            username VARCHAR(100) NOT NULL,
            email VARCHAR(100) NOT NULL,
            age INT NOT NULL DEFAULT 0,
            created_at DATETIME NOT NULL,
            updated_at DATETIME NOT NULL,
            PRIMARY KEY (id)
        ) DEFAULT CHARSET = utf8mb4`

        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.UpdateFinder(ctx, zorm.NewFinder().Append(ddl))
            return nil, err
        })
        return err
    }

    // createUser はユーザーデータを挿入します。
    func createUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Insert(ctx, user)
            return nil, err
        })
        return err
    }

    // getUserByID は主キーでユーザーをクエリします。
    func getUserByID(ctx context.Context, id int64) (*User, error) {
        user := &User{}
        finder := zorm.NewSelectFinder(usersTableName).Append("WHERE id = ?", id)
        has, err := zorm.QueryRow(ctx, finder, user)
        if err != nil {
            return nil, err
        }
        if !has {
            return nil, fmt.Errorf("ユーザー %d は存在しません", id)
        }
        return user, nil
    }

    // updateUser はユーザーデータを更新します。
    func updateUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Update(ctx, user)
            return nil, err
        })
        return err
    }

    // listUsers はユーザー一覧をクエリします。
    func listUsers(ctx context.Context) ([]User, error) {
        users := make([]User, 0)
        finder := zorm.NewSelectFinder(usersTableName).Append("ORDER BY id")
        if err := zorm.Query(ctx, finder, &users, nil); err != nil {
            return nil, err
        }
        return users, nil
    }

    // deleteUser はユーザーデータを削除します。
    func deleteUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Delete(ctx, user)
            return nil, err
        })
        return err
    }

    func main() {
        ctx := context.Background()

        // データベース接続を初期化します。
        if err := initDB(); err != nil {
            log.Fatal(err)
        }
        fmt.Println("zorm の初期化に成功しました")

        // データテーブルを作成します。
        if err := createTable(ctx); err != nil {
            log.Fatalf("データテーブルの作成に失敗しました: %v", err)
        }
        fmt.Println("データテーブルの作成に成功しました")

        // ユーザーデータを 1 件挿入します。
        now := time.Now()
        user := &User{
            Username:  "oceanbase_user",
            Email:     "zorm@oceanbase.com",
            Age:       28,
            CreatedAt: now,
            UpdatedAt: now,
        }
        if err := createUser(ctx, user); err != nil {
            log.Fatalf("データの挿入に失敗しました: %v", err)
        }
        fmt.Printf("挿入に成功しました。ID: %d\n", user.ID)

        // ユーザーデータをクエリします。
        queried, err := getUserByID(ctx, user.ID)
        if err != nil {
            log.Fatalf("データのクエリに失敗しました: %v", err)
        }
        fmt.Printf("クエリに成功しました: ID=%d, Username=%s, Age=%d\n", queried.ID, queried.Username, queried.Age)

        // ユーザーデータを更新します。
        queried.Age = 29
        queried.UpdatedAt = time.Now()
        if err := updateUser(ctx, queried); err != nil {
            log.Fatalf("データの更新に失敗しました: %v", err)
        }
        fmt.Println("更新に成功しました")

        // ユーザー一覧をクエリします。
        users, err := listUsers(ctx)
        if err != nil {
            log.Fatalf("一覧のクエリに失敗しました: %v", err)
        }
        fmt.Printf("%d 件のレコードが見つかりました\n", len(users))
        for _, item := range users {
            fmt.Printf("ID=%d, Username=%s, Age=%d\n", item.ID, item.Username, item.Age)
        }

        // ユーザーデータを削除します。
        if err := deleteUser(ctx, queried); err != nil {
            log.Fatalf("データの削除に失敗しました: %v", err)
        }
        fmt.Println("削除に成功しました")
    }
    ```

### 手順 4：プログラムを実行して結果を確認する

1. プログラムを実行します：

    ```bash
    cd ~/go/src/zorm-oceanbase
    go run main.go
    ```

2. `go: command not found` エラーが発生した場合は、手順 2 の説明に従って Go の環境変数が正しく設定されていることを確認してください。

3. プログラムの実行が完了すると、次のような出力が表示されます：

    ```bash
    zorm の初期化に成功しました
    データテーブルの作成に成功しました
    挿入に成功しました。ID: 1
    クエリに成功しました: ID=1, Username=oceanbase_user, Age=28
    更新に成功しました
    1 件のレコードが見つかりました
    ID=1, Username=oceanbase_user, Age=29
    削除に成功しました
    ```

    `ID` は自動増分の主キーであるため、サンプルを再実行すると値が増加します。
