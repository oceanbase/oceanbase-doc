# DolphinSchedulerにOceanBaseデータソースを設定する

DolphinSchedulerはOceanBaseデータソースをサポートしています。OceanBaseのMySQLモードを使用している場合は、MySQLデータソースとして設定できます。

DolphinSchedulerコンソールにログインし、上部のナビゲーションバーで、ソースセンター -> データソースの作成 -> ソースタイプを選択します。データソースタイプとしてMySQLを選択します。最新バージョンのDolphinSchedulerを使用している場合は、OCEANBASEデータソースタイプを選択できます。

DolphinSchedulerにOceanBaseデータソースを設定するには、以下のパラメータを指定する必要があります：

| パラメータ | 説明 |
| ---- | ---- |
| データソース | OCEANBASEを選択 |
| データソース名 | データソース名を入力 |
| IPアドレス | ホスト名：OceanBaseに接続するIPアドレスを入力 |
| ポート | OceanBaseに接続するポートを入力 |
| ユーザー名 | OceanBaseに接続するユーザー名を設定 |
| パスワード | OceanBaseに接続するパスワードを設定 |
| データベース名 | OceanBaseに接続するデータベース名を入力 |

詳細については、DolphinSchedulerの[公式ドキュメント](https://dolphinscheduler.apache.org/en-us/docs/3.2.1/guide/datasource/mysql)を参照してください。
