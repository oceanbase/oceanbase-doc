# DolphinScheduler に OceanBase データソースを設定する

DolphinScheduler は OceanBase データソースをサポートしています。OceanBase の MySQL モードを使用している場合は、MySQL の設定に従って OceanBase データソースを設定できます。

DolphinScheduler のコンソールにログインし、上部のナビゲーションバーで、「ソースセンター > データソースの作成 > ソースタイプの選択」をクリックします。データソースのタイプを MySQL に選択します。最新バージョンの DolphinScheduler を使用している場合は、OCEANBASE データソースタイプを選択できます。

DolphinScheduler に OceanBase データソースを設定するには、以下のパラメーターを提供する必要があります：

| パラメーター | 説明 |
| ---- | ---- |
| データソース | OceanBase を選択 |
| データソースの名前 | データソースの名前を入力 |
| IP アドレス | ホスト名：OceanBase への接続 IP アドレスを入力 |
| ポート | OceanBase に接続するポートを入力：
| ユーザー名 | OceanBase に接続するユーザー名を設定 |
| パスワード | OceanBase に接続するパスワードを設定 |
| データベース名 | OceanBase に接続するデータベースの名前を入力 |

詳細については、DolphinScheduler [公式ドキュメント](https://dolphinscheduler.apache.org/en-us/docs/3.2.1/guide/datasource/mysql) を参照してください。
