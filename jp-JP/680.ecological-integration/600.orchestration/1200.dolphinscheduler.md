# DolphinSchedulerにOceanBaseデータソースを設定する

DolphinSchedulerはOceanBaseデータソースをサポートしています。OceanBaseのMySQLモードを使用している場合は、MySQLデータソースとして設定できます。

DolphinSchedulerコンソールにログインし、上部のナビゲーションバーで、ソースセンター->データソースの作成->ソースタイプの選択をクリックします。データソースタイプとしてMySQLを選択します。最新バージョンのDolphinSchedulerを使用している場合は、OCEANBASEデータソースタイプを選択できます。

DolphinSchedulerにOceanBaseデータソースを設定するには、以下のパラメータを指定する必要があります：

| パラメータ | 説明 |
| ---- | ---- |
| データソース | OCEANBASEを選択します |
| データソース名 | データソースの名前を入力します |
| IPアドレス | ホスト名：OceanBaseに接続するIPアドレスを入力します |
| ポート | OceanBaseに接続するポートを入力します |
| ユーザー名 | OceanBaseに接続するユーザー名を設定します |
| パスワード | OceanBaseに接続するパスワードを設定します |
| データベース名 | OceanBaseに接続するデータベース名を入力します |

詳細については、DolphinSchedulerの[公式ドキュメント](https://dolphinscheduler.apache.org/en-us/docs/3.2.1/guide/datasource/mysql)を参照してください。
