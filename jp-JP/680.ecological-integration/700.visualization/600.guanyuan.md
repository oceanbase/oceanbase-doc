# GuanData BI で OceanBase データベースに接続する

本記事では、OceanBase データベースの MySQL モードを例に、GuanData BI で OceanBase データベースに接続し、データを表示する方法を紹介します。

## 前提条件

* GuanData BI を購入していること。
* OceanBase データベースがインストール済みで、MySQL モードのテナントが作成されていること。

## 手順 1：OceanBase データベースへの接続文字列を取得する

OceanBase データベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```SQL
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメーターの説明：**

* `$host`：OceanBase データベースへの接続 IP アドレスを提供します。OceanBase データベースプロキシ (OceanBase Database Proxy、ODP) 接続方式は ODP アドレスを使用し、直接接続方式は OBServer ノードの IP アドレスを使用します。
* `$port`：OceanBase データベースへの接続ポートを提供します。ODP 接続方式のデフォルトポートは `2883` で、ODP デプロイ時にカスタマイズ可能です。直接接続方式のデフォルトポートは `2881` で、OceanBase データベースのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセスするデータベースの名前。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーは、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および <code>SELECT</code> 権限が付与されていなければなりません。ユーザー権限の詳細については、<a href="https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974758">MySQL モードの権限分類</a>を参照してください。</p>
    </main>

* `$user_name`：テナントの接続アカウントを提供します。ODP 接続の一般的な形式：`ユーザー名@テナント名#クラスター名` または `クラスター名:テナント名:ユーザー名`。直接接続方式の形式：`ユーザー名@テナント名`。
* `$password`：アカウントのパスワードを提供します。

接続文字列の詳細については、[OBClient を使用して OceanBase テナントに接続する](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971649) を参照してください。

## 手順 2：GuanData BI でドライバーとコネクタを設定する

1. GuanData BI コンソールにログインし、ページの右上にある **管理センター** > **リソース管理** > **ドライバーとコネクタ管理** を選択します。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image001.png)

2. **ドライバー管理** タブの **新規ドライバー** をクリックし、ドライバーの名前を編集し、**保存** をクリックして、新規ドライバーの作成を完了します。

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image003.png)

3. 新しく作成したドライバー OceanBase-MySQL をクリックし、**ファイルのアップロード** ボタンをクリックしてドライバー Jar パッケージと利用可能な Driver Class をアップロードし、**適用** をクリックしてドライバー設定を完了します。

    <main id="notice" type='note'>
    <h4>説明</h4>
    <p>OceanBase (MySQL) のドライバー Jar パッケージをダウンロードするには、<a href="https://en.oceanbase.com/softwarecenter">OceanBase ソフトウェアダウンロードセンター</a> にアクセスし、CPU アーキテクチャに基づいてダウンロードを選択します。</p>
    </main>

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image005.png)

4. **データベースコネクタ管理** タブをクリックし、**新規データベースコネクタ** をクリックして、ポップアップウィンドウでデータベースコネクタを設定します。完了後、 **OK** をクリックします。

    |設定項目|説明|
    |-----|----|
    |表示 ICON| データアカウントやデータベースデータセットの新規作成時に表示されるカスタムデータ接続の画像 ICON を設定します。|
    |コネクタの名前|ユーザーの習慣に応じて自由に定義できますが、特殊文字はサポートされていません。|
    |デフォルト方言サポート|MySQL を選択します。|
    |テーブルリスト SQL の取得| `{"sql": "SHOW TABLES", "tableNameIdx": 1}` を入力します。|
    |デフォルトドライバー|手順 3 で新規作成した OceanBase-MySQL ドライバーを選択します。|

    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image007.png)

## 手順 3：GuanData BI でデータアカウントを作成する

1. GuanData BI コンソールで **データ準備** > **データアカウント** を選択します。

2. **新規データアカウント** をクリックして、データアカウントを設定します。

   a. コネクタの選択画面で、手順 2 で作成したコネクタ OceanBase-MySQL を選択します。完了後、**次へ** をクリックします。

   ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image009.png)

   b. データアカウントの設定画面で、データアカウント情報を設定します。設定が完了したら、**接続テスト** をクリックし、OceanBase データベースに正常に接続できるかどうかを確認します。確認後、**次へ** をクリックします。

    |設定項目|説明|
    |-----|----|
    | ユーザー名 | 接続文字列の `-u` パラメーターから取得したアカウントの名前。|
    |パスワード| 接続文字列の `-p` パラメーターから取得した、アカウントとパスワード。|
    |JDBC URL| 接続文字列中の `-h`、`-P`、`-D`、`-u`、`-p` パラメーターに基づいて連結されます。連結構文は次のとおりです：<br>`jdbc:oceanbase://host:port/databasename?[username&password]`<br>例：<br>`jdbc:oceanbase://t5******.aws-ap-southeast-1.oceanbase.cloud:3306/test?user=test_user001@sys&password=***1**`|
    |最大接続数| 単一データアカウントの接続プール数の上限を設定します。|
    |ドライバー|手順 2 で作成したドライバー OceanBase-MySQL をカスタマイズして選択します。|

   c. データアカウント情報の確認画面で、現在のデータベースのデータアカウントに名前を付けます。完了後、**新規作成の確認** をクリックします。

## 手順 4：GuanData BI にデータを接続する

1. GuanData BI コンソールで、ページ右上の **データ準備** > **データセット** を選択し、次に **新規データセット** > **データベース** を選択します。

    ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image011.png)

2. データセット接続情報を設定します：

   a. **データアカウントとデータテーブルの選択** で、手順 3 で作成したデータアカウント **OceanBase データアカウント** を選択し、SQL クエリを使用してデータを取得します。完了後、**次へ** をクリックします。

   ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image013.png)

   b. **データ接続および更新設定** で、データ接続および更新情報を設定します。完了後、**次へ** をクリックします。

   ![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image015.png)

   c. **データテーブル情報確認** で、データ取得結果を確認し、データセットの名前、保存パスなどを設定します。完了したら、**新規作成の確認** をクリックします。

3. データセットリストに接続したデータセットが表示される場合、データソースへの接続が成功したことを意味します。

    ![9](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/24V5/zh/guanyuan/image017.png)

## 次の操作

データソースの作成が完了したら、GuanData BI をご利用いただけます。GuanData BI の詳細な操作ガイドについては、[GuanData BI ヘルプセンター](https://docs.guandata.com/product/bi/) を参照してください。
