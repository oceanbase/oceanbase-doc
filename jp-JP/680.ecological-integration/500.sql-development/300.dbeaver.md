# DBeaverによるOceanBaseデータベースへの接続

DBeaverは汎用のデータベースクライアントツールであり、各データベースが提供するJDBCドライバを使用してデータベースに接続します。一般的なリレーショナルデータベース、非リレーショナルデータベース、分散型データベースなどをサポートしています。

DBeaverに組み込まれているOceanBaseドライバまたはMySQLドライバのいずれかを使用して、OceanBaseデータベースのMySQLテナントに接続できます。この記事では、OceanBaseドライバを例に、DBeaverを使用してOceanBaseデータベースのMySQLテナントに接続する方法を説明します。

## 前提条件

* DBeaverを取得し、インストール済みであることを確認してください。[DBeaver公式ダウンロードURL](https://dbeaver.io/download/)から、お使いのシステムに対応するDBeaverをダウンロードできます。

* 接続対象のOBServerノードのIPアドレスと、DBeaverが稼働しているマシン間でネットワークが接続されていることを確認してください。

* OceanBaseデータベースがインストール済みで、MySQLモードのテナントが作成されていることを確認してください。

## 手順

### ステップ１：データベース接続文字列の取得

OceanBaseデータベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：OceanBaseデータベースへの接続IPアドレス。OceanBaseデータベースプロキシ(OceanBase Database Proxy、ODP)接続方式ではODPアドレスを使用し、直接接続方式ではOBServerノードのIPアドレスを使用します。
* `$port`：OceanBaseデータベースへの接続ポート。ODP接続方式のデフォルトポートは`2883`で、ODPデプロイ時にカスタマイズ可能です。直接接続方式のデフォルトポートは`2881`で、OceanBaseデータベースのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセス対象のデータベース名。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーは、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および <code>SELECT</code> 権限が付与されていなければなりません。ユーザー権限の詳細については、<a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQLモードの権限分類</a>を参照してください。</p>
    </main>

* `$user_name`：テナントの接続アカウント。ODP接続の一般的な形式：`ユーザー名@テナント名#クラスタ名` または `クラスタ名:テナント名:ユーザー名`。直接接続方式の形式：`ユーザー名@テナント名`。
* `$password`：アカウントのパスワード。

接続文字列の詳細については、[OBClientによるOceanBaseテナントへの接続](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)を参照してください。

**例：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### ステップ2：DBeaverコンソールでOceanBaseデータベースに接続する

<main id="notice" type='notice'>
    <h4>説明</h4>
    <p>DBeaverのバージョンによって操作画面が異なる場合があります。このドキュメントでは、DBeaver 22.0.5を例にデータベース接続の手順を説明します。他のバージョンでの操作については、DBeaverの対応するバージョンの製品ドキュメントを参照してください。</p>
</main>

1. （オプション）ドライバーファイルのバージョンを変更します。

   DBeaver内のOceanBaseドライバーのデフォルトのドライバーファイルはmysql-connector-java-5.1.44です。このドキュメントではmysql-connector-java-5.1.47を例に説明します。ドライバーファイルの変更については、以下の手順を参照してください。

   1. MySQL公式[JDBCドライバーのダウンロード](https://downloads.mysql.com/archives/c-j/)ページから5.1.47バージョンのドライバーファイルをダウンロードします。

   2. **<UI-TERM key="oms-cloud.Performance.componentsAdd.RDSTargetEndType.Database">データベース</UI-TERM>** > **ドライバーマネージャー** をクリックし、OceanBaseを検索します。OceanBaseドライバーを選択し、**<UI-TERM key="odc.ExternalIntegration.SqlInterceptor.Edit">編集</UI-TERM>** をクリックしてドライバーの編集ページに入ります。

   3. **<UI-TERM key="obcloud-console.component.InitiateBackup.Library">データベース</UI-TERM>** タブを選択し、OceanBaseドライバーに付属するドライバーファイルを選択して、**<UI-TERM key="oms-cloud.pages.PrivateLinkSubscribe.Delete">削除</UI-TERM>** をクリックします。

   4. **ファイルの追加** をクリックして、ダウンロードしたドライバーファイルをライブラリに追加し、**<UI-TERM key="ocp-v2.Instance.Overview.Ok">確定</UI-TERM>** をクリックするとドライバーファイルの置き換えが完了します。

2. **<UI-TERM key="oas.RequestAnalysis.CardRequestList.Database">データベース</UI-TERM>** > **新しいデータベース接続** をクリックし、**データベースの選択** ページに入ります。**<UI-TERM key="ocp-v2.pages.Certificate.CreateCertificate.File">ファイル</UI-TERM>** の下のコネクター ![コネクター](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-01.png) をクリックして、直接 **データベースの選択** ページに入ることもできます。

   <!-- ![データベースの選択](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-02.png) -->

3. **データベースの選択** ページで **OceanBase** を選択し、**<UI-TERM key="must.compatibilityNew.online.NextStep">次のステップ</UI-TERM>** をクリックして **接続設定** ページに入ります。`Host`、`Port`、`Tenant`、ユーザー名、パスワードを入力し、**<UI-TERM key="oms-community.OCP.components.OCPForm.TestConnection">接続テスト</UI-TERM>** をクリックします。

   <!-- ![テスト](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-03.png) -->

   <main id="notice" type='notice'>
       <h4>説明</h4>
       <p>データベースへの接続には、IPアドレスによる直接接続とOBProxy経由での接続の2つの方法があります。直接接続する場合は、Portに設定された <code>mysql_port</code> を入力します。デフォルトポートは2881です。OBProxyを使用して接続する場合は、Portに設定された <code>proxy_port</code> を入力します。デフォルトポートは2883です。</p>
   </main>

4. **接続テスト** のポップアップウィンドウに **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.Connected">接続済み</UI-TERM>** と表示されれば、接続に成功しています。**<UI-TERM key="oms-community.pages.Sync.TableRow.Confirmation">OK</UI-TERM>** をクリックし、その後 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました。</UI-TERM>** をクリックすると、OceanBaseデータベースに接続できます。

   <!-- ![接続に成功しました](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-04.png) -->

5. **データベースナビゲーション** バーのデータベース名をダブルクリックし、以下のように展開されれば、OceanBaseデータベースへの接続に成功したことを意味します。

   <!-- ![接続結果](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer/V3.1.3/zh-CN/1.users-guide/5.database-connection-and-routing/4.administrator-guide-connect-to-oceanbase-database/4.connect-to-oceanbase-database-through-dbeaver-05.png) -->

## 詳細を見る

DBeaverを使用してOceanBaseデータベースに接続する際に問題が発生した場合は、[DBeaverクライアント公式ドキュメント](https://dbeaver.com/docs/dbeaver/)を参照することをお勧めします。
