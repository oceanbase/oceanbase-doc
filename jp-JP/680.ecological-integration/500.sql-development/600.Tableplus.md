# TablePlus で OceanBase データベースに接続する

TablePlus は、現代的でネイティブなデータベース管理ツールです。MySQL、PostgreSQL、SQLite などの様々なリレーショナルデータベースを管理するための、便利で使いやすいグラフィカルユーザーインターフェースを提供します。本記事では、OB Cloud のトランザクション型インスタンスの MySQL テナントと macOS オペレーティングシステムを例に、TablePlus で OceanBase データベースに接続する方法を紹介します。

## 前提条件

* TablePlus をダウンロードし、インストール済みであること。詳細については、[TablePlus 公式 Web サイト](https://tableplus.com/download) を参照してください。

* 接続する OBServer ノードの IP アドレスと TablePlus が配置されているマシンとの間で、ネットワーク接続が確立されていること。

* OceanBase データベースがインストール済みで、MySQL モードのテナントが作成されていること。

## 操作手順

### 手順 1：データベース接続文字列を取得する

OceanBase データベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメーターの説明：**

* `$host`：OceanBase データベースへの接続 IP アドレスを提供します。OceanBase データベースプロキシ (OceanBase Database Proxy、ODP) 接続方式は ODP アドレスを使用し、直接接続方式は OBServer ノードの IP アドレスを使用します。
* `$port`：OceanBase データベースへの接続ポートを提供します。ODP 接続方式のデフォルトポートは `2883` で、ODP デプロイ時にカスタマイズ可能です。直接接続方式のデフォルトポートは `2881` で、OceanBase データベースのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセスするデータベースの名前。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーに、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および <code>SELECT</code> 権限が付与されていなければなりません。ユーザー権限の詳細については、<a href="https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974758">MySQL モードの権限分類</a>を参照してください。</p>
    </main>

* `$user_name`：テナントの接続アカウントを提供します。ODP 接続の一般的な形式：`ユーザー名@テナント名#クラスター名` または `クラスター名:テナント名:ユーザー名`。直接接続方式の形式：`ユーザー名@テナント名`。
* `$password`：アカウントのパスワードを提供します。

接続文字列の詳細については、[OBClient を使用して OceanBase テナントに接続する](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971649) を参照してください。

**例：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 手順 2：TablePlus で OceanBase データソースを作成して接続する

1. ローカルコンピューターで TablePlus を開き、インターフェースの右側でマウスを右クリックし、**New** > **Connection** を選択します。

2. ポップアップウィンドウで **MySQL** を選択し、**Create** をクリックします。

3. **MySQL Connection** のダイアログボックスで、**手順 1：OceanBase データベース接続文字列を取得する** で取得した接続文字列に基づいて、以下の設定を完了します：

   |設定項目|説明|
   |-----|----|
   |Name| カスタマイズした Connection の名前。|
   |Host/IP| 接続文字列の `-h` パラメーターから取得した、OceanBase データベースの接続アドレス。|
   |Port| 接続文字列の `-P` パラメーターから取得した、OB Cloud クラウドデータベースの接続ポート。|
   |User| 接続文字列の `-u` パラメーターから取得したアカウント名、例：`test`。|
   |Password| 接続文字列の `-p` パラメーターから取得したアカウントパスワード。|
   |Database| 接続文字列の `-D` パラメーターから取得した、アクセスする必要があるデータベース名。|

5. **Test** をクリックして、接続が成功するかどうかテストします。入力ボックスの背景色が緑色に変わると、接続が成功したことを表します。

6. 接続テストが成功した後、**Connection** をクリックすると接続が完了します。

## 次の操作

接続が完了すると、TablePlus を使用できます。TablePlus の詳細な操作ガイドについては、[TablePlus 公式使用ドキュメント](https://docs.tableplus.com/) を参照してください。
