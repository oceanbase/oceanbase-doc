# LibreDB StudioでOceanBaseデータベースに接続する

LibreDB Studioは、ブラウザで動作するオープンソースのセルフホスト型SQL IDEです。サーバーに一度デプロイすれば、チームメンバーはデスクトップクライアントをインストールせずに、Webブラウザからデータベースに接続できます。本ドキュメントでは、OceanBaseデータベースのMySQLモードのテナントとLibreDB StudioのDockerイメージを例に、LibreDB StudioでOceanBaseデータベースに接続する方法を紹介します。

## 前提条件

* LibreDB Studioをデプロイ済みであること。例えば、`docker run -p 3000:3000 ghcr.io/libredb/libredb-studio:latest`を実行し、ブラウザで`http://localhost:3000`を開きます。初回起動時に、管理者パスワードがコンテナログに出力されます。詳細については、[LibreDB StudioのGitHubリポジトリ](https://github.com/libredb/libredb-studio)を参照してください。

* 接続対象のOBServerノードのIPアドレスと、LibreDB Studioがデプロイされたサーバー間でネットワークが接続されていること。

* OceanBaseデータベースをインストール済みで、MySQLモードのテナントが作成されていること。

## 操作手順

### ステップ１：データベース接続文字列を取得する

OceanBaseデータベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：OceanBaseデータベースへの接続IPアドレス。OceanBaseデータベースプロキシ(OceanBase Database Proxy、ODP)接続方式ではODPアドレスを使用し、直接接続方式ではOBServerノードのIPアドレスを使用します。
* `$port`：OceanBaseデータベースへの接続ポート。ODP接続方式のデフォルトポートは`2883`で、ODPデプロイ時にカスタマイズ可能です。直接接続方式のデフォルトポートは`2881`で、OceanBaseデータベースのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセスするデータベース名。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーは、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および <code>SELECT</code> 権限が付与されていなければなりません。その他のユーザー権限の詳細については、<a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQLモードの権限分類</a>を参照してください。</p>
    </main>

* `$user_name`：テナントの接続アカウント。ODP接続の一般的な形式：`ユーザー名@テナント名#クラスタ名`または`クラスタ名:テナント名:ユーザー名`。直接接続方式の形式：`ユーザー名@テナント名`。
* `$password`：アカウントのパスワード。

その他の接続文字列の情報については、[OBClientを使用してOceanBaseテナントに接続する](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)を参照してください。

**例：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### ステップ2：LibreDB StudioでOceanBase接続を作成する

1. ブラウザでLibreDB Studioを開き、サインインします。管理者としてサインインした場合は、まず**Editor**をクリックしてエディタを開きます。

2. 左側のサイドバー上部で、**LibreDB Studio**の右側にあるプラス記号(+)をクリックし、**New Connection**ダイアログボックスを開きます。

3. データベースの種類として**MySQL**を選択します。

4. **ステップ１：データベース接続文字列を取得する**で取得した接続文字列を使用して、以下の設定を完了します：

   |パラメータ|説明|
   |-----|----|
   |Connection Name|カスタマイズした接続名。|
   |Host & Instance|OceanBaseデータベースの接続アドレスとポート。1つ目の入力ボックスに接続文字列の `-h` パラメータの値を、2つ目の入力ボックスに `-P` パラメータの値を入力します。|
   |Username|接続文字列の `-u` パラメータから取得したアカウント名（例：`root@test`）。|
   |Password|接続文字列の `-p` パラメータから取得したアカウントのパスワード。|
   |Database Name|接続文字列の `-D` パラメータから取得した、アクセスするデータベース名。|

5. **Test Connection**をクリックします。**Connected successfully**で始まるメッセージが表示された場合、接続は成功です。

6. **Establish Connection**をクリックして接続を保存します。接続がサイドバーに表示され、その下にテナントのデータベースが一覧表示されます。

## 次のステップ

接続が完了したら、エディタでSQL文を実行し、サイドバーでテナントのデータベースとテーブルを参照できます。LibreDB Studioの詳細な使い方については、[LibreDB StudioのGitHubリポジトリ](https://github.com/libredb/libredb-studio)を参照してください。
