# SQL データ型

本節では、主に OceanBase データベースの Oracle モードとネイティブ Oracle データベースの SQL データ型の互換性比較情報の詳細について説明します。

Oracle データベースには 24 種類のデータ型がありますが、OceanBase データベースは現在、20 種類をサポートしています。詳細は以下の表のとおりです。


| シリアル番号 |       Oracle データベース        | OceanBase データベース |
|-----|-----------------------------|-----------------|
| 1  | CHAR (size)             | サポート            |
| 2  | NCHAR\[(size)\]         | サポート            |
| 3  | VARCHAR2(size)          | サポート            |
| 4  | VARCHAR(size)           | サポート            |
| 5  | NVARCHAR2(size)         | サポート            |
| 6  | NUMBER \[ (p \[, s\]) \]              | サポート            |
| 7  | FLOAT \[(p)\]           | サポート            |
| 8  | BINARY_FLOAT            | サポート            |
| 9  | BINARY_DOUBLE           | サポート            |
| 10 | LONG (Oracle データベースで廃止されたタイプ)   | サポートなし           |
| 11 | DATE      | サポート            |
| 12 | TIMESTAMP \[(fractional_seconds_precision)\]        | サポート            |
| 13 | TIMESTAMP   \[(fractional_seconds_precision)\] WITH TIME ZONE     | サポート            |
| 14 | TIMESTAMP   \[(fractional_seconds_precision)\] WITH LOCAL TIME ZONE             | サポート            |
| 15 | INTERVAL YEAR \[(year_precision)\] TO MONTH         | サポート            |
| 16 | INTERVAL DAY   \[(day_precision)\] TO SECOND \[(fractional_seconds_precision)\] | サポート            |
| 17 | RAW(size) | サポート            |
| 18 | LONG RAW (Oracle データベースで廃止されたタイプ)             | サポートなし           |
| 19 | ROWID     | サポート            |
| 20 | UROWID \[(size)\]       | サポート            |
| 21 | BFILE     | サポートなし         |
| 22 | BLOB      | サポート            |
| 23 | CLOB      | サポート            |
| 24 | NCLOB     | サポートなし           |
