# Oracle との互換性の概要

本節では、主に OceanBase データベースの Oracle モードとネイティブ Oracle データベースの互換性比較情報について説明します。

OceanBase データベースは、データ型、SQL 機能、データベースオブジェクトなどの基本機能において Oracle データベースと互換性があります。手続き型プログラミング言語 (Procedural Language、PL) の面では、ほぼ全ての開発機能と互換性があります。OceanBase データベースは、データベースセキュリティ、バックアップ復元、高可用性、オプティマイザーなどの高度な機能においても、互換性は非常に高く、一部の機能では Oracle データベースよりも優れています。これは、Oracle データベースから OceanBase データベースへの移行の際に、ユーザーは新しい知識の学習に多くの時間を費やす必要がなく、スムーズに Oracle データベースから OceanBase データベースへの移行を実現できることを意味します。

さらに、OceanBase データベースと Oracle データベースは、基盤となるアーキテクチャ、プロダクト形態などの点で異なるため、一部の機能については OceanBase データベースでは一時的に互換性が提供されないか、Oracle データベースとの動作が異なる場合があります。本節では、主に以下の観点から OceanBase データベースと Oracle データベースの互換性に関する比較情報を紹介します。

* SQL データ型

* 組み込み関数

* SQL 構文

* 手続き型言語

* システムビュー

* 文字セット

* 照合順序

* データベースオブジェクト管理

* セキュリティ機能

* バックアップと復元

* SQL エンジン

## SQL データ型

OceanBase データベースは、Oracle データベースでサポートされているほとんどのデータ型と互換性があります。詳細なサポート情報は、[SQL データ型](../400.compatibility-with-oracle/200.sql-data-type.md) を参照してください。

最適化のため、`LONG` および `LONG RAW` データ型は時代遅れであるため、OceanBase データベースでは現在、これらのデータ型をサポートする予定はありません。

## 組み込み関数

OceanBase データベースは、Oracle データベースでサポートされているほとんどの組み込み関数と互換性があります。詳細なサポート情報は、[組み込み関数](../400.compatibility-with-oracle/300.built-in-functions.md) を参照してください。

## SQL 構文

OceanBase データベースは Oracle データベースのほとんどの SQL 構文をサポートしますが、一部の機能が欠けている場合には、構文がサポートされていないというエラーが報告されることがあります。

:::tab
tab サポート

**SELECT**

* ほとんどのクエリ機能をサポートしています。単一テーブルおよび複数テーブルのクエリのサポート、サブクエリ、内部結合、半結合、外部結合のサポート、グループ化、集計のサポート、階層クエリのサポート、一般的な確率、線形回帰などのデータマイニング関数などのサポートを含みます。

* 以下の集合操作をサポートします：`UNION`、`UNION ALL`、`INTERSECT`、`MINUS`。

* `EXPLAIN` 構文を使用して実行計画の確認できます。

**INSERT**

* 単一行および複数行のデータ挿入をサポートし、指定されたパーティションへのデータ挿入もサポートします。

* `INSERT INTO ... SELECT ...` 文をサポートします。

* 単一テーブルおよび複数テーブルへのデータ挿入をサポートします。

**UPDATE**

* 単一列および複数列のデータ更新をサポートします。

* サブクエリによるデータ更新をサポートします。

* 集合によるデータ更新をサポートします。

**DELETE**

* 単一テーブルおよび複数テーブルの削除をサポートします。

**TRUNCATE**

* 指定されたテーブルを完全にクリアすることをサポートします。

**並列クエリ**

* Oracle データベースに類似した並列クエリをサポートします。

  OceanBase データベースは Auto DOP 機能をサポートしており、`Hint/Session` 変数を使用して手動で DOP を指定することもできます。

* 並列データ操作言語 (DML) をサポートします。

**Hint**

OceanBase データベースは Hint 構文の使用をサポートしています。Hint に関する詳細な説明は、[Hint](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001976301) を参照してください。

**マテリアライズドビュー**

* `CREATE MATERIALIZED VIEW` (マテリアライズドビューの作成)。
* `DROP MATERIALIZED VIEW` (マテリアライズドビューの削除)。

**マテリアライズドビューログ**

* `CREATE MATERIALIZED VIEW LOG` (マテリアライズドビューログの作成)。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBase データベースでは、<code>CREATE MATERIALIZED VIEW LOG</code> 構文の <code>with_clause</code> (<code>PRIMARY KEY</code>、<code>ROWID</code>、<code>SEQUENCE</code>) のデフォルト動作は、Oracle データベースと互換性がありません。</p>
  </main>

* `DROP MATERIALIZED VIEW LOG` (マテリアライズドビューログの削除)。

tab サポートなし

**マテリアライズドビュー**

* `CREATE MATERIALIZED VIEW` (マテリアライズドビューの作成) 構文では、リフレッシュモードは現在 `ON COMMIT` および `ON STATMENT` モードはサポートしていません。
* `DROP MATERIALIZED VIEW` (マテリアライズドビューの削除) 構文では、現在 `PRESERVE TABLE` 句はサポートしていません。

**マテリアライズドビューログ**

* `CREATE MATERIALIZED VIEW LOG` (マテリアライズドビューログの作成) 構文において：

  * `ASYNCHRONOUS` 句は現在サポートしていません (非同期でクリアを実行)。
  * `EXCLUDING NEW VALUES` 句を使用すると、エラーが発生します。
  * パーティションは現在サポートしていません。

:::

## 手続き型言語

OceanBase データベースは Oracle データベースのほとんどの PL 機能と互換性があります。PL 機能の詳細は、[PL リファレンス](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001972342) を参照してください。

:::tab
tab サポート

OceanBase データベースが主にサポートする PL 機能は以下のとおりです：

* データ型

* フロー制御

* 集合とレコード (多次元集合は現在サポートしていません)。

* 静的 SQL

* 動的 SQL

* サブプロセス

* トリガー

* 例外処理

* パッケージ

* パフォーマンス最適化

* カスタマデータ型

* PL システムパッケージは、`DBMS_CRYPTO`、`DBMS_DEBUG`、`DBMS_LOB`、`DBMS_LOCK`、`DBMS_METADATA`、`DBMS_OUTPUT`、`DBMS_RANDOM`、`DBMS_SQL`、`DBMS_XA`、`UTL_I18N`、`UTL_RAW` などを含みます。

* PL ラベルセキュリティパッケージは、`SA_SYSDBA`、`SA_COMPONENTS`、`SA_LABEL_ADMIN`、`SA_POLICY_ADMIN`、`SA_USER_ADMIN`、`SA_SESSION` などを含みます。

OceanBase データベースは、`NOCOPY` パラメーターの動作を実装する際に、Oracle データベースと互換性の違いがあります。

* プリミティブデータ型と純粋な OUT 属性の複雑なデータ型パラメーターは、Oracle データベースの参照渡し動作と互換性がありません。

* IN OUT 属性の複雑なデータ型パラメーターの場合、OceanBase データベースは Oracle データベースの参照渡し動作と互換性があります。

tab サポートなし

OceanBase データベースは、現在以下の PL 機能はサポートしていません。

* 条件コンパイル

:::

## システムビュー

OceanBase データベースは、一部の Oracle データベースのシステムビューと互換性があります。互換性のあるビューの詳細なリストは、[システムビュー](../400.compatibility-with-oracle/400.system-view.md) を参照してください。システムビューのフィールド説明の詳細は、[システムビュー](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001970992) を参照してください。

**テーブル管理**

* テーブルの作成：テーブルの作成をサポートしており、作成時にはパーティション、制約などの情報を指定できます。テーブル作成に関する詳細な構文は、[CREATE TABLE](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001975088) を参照してください。

* 基本テーブルの変更：`ALTER TABLE` ステートメントを使用して、列の追加、削除、変更、制約の追加、削除、パーティションの追加、削除、変更をサポートします。テーブル変更に関する詳細な構文は、[ALTER TABLE](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001975084) を参照してください。

* 基本テーブルの削除：テーブルの削除と制約のカスケードをサポートします。テーブル削除に関する詳細な構文は、[DROP TABLE](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001975087) を参照してください。

**制約**

* `CHECK`、`UNIQUE` および `NOT NULL` 制約をサポートします。

* `PRIMARY KEY` 制約をサポートします。

* `FOREIGN KEY` 制約をサポートします。

* `ALTER TABLE` ステートメントを使用して、`CHECK` 制約、`PRIMARY KEY` 制約、`FOREIGN KEY` 制約、`NOT NULL` 制約の追加をサポートします。

* カスケードにおける `SET NULL` をサポートします。

**パーティションサポート**

* 1 次パーティション、テンプレート化およびテンプレート化されていない 2 次パーティションをサポートします。

* ハッシュ (Hash)、レンジ (Range)、リスト (List)、および複合パーティションなどのパーティション形式をサポートします。

* ローカルインデックスとグローバルインデックスをサポートします。

* パーティションメンテナンス操作について：

  * 1 次パーティションテーブルは、1 次パーティションの追加、削除、TRUNCATE をサポートします。

  * テンプレート化された 2 次パーティションテーブルは、1 次パーティションの追加と削除をサポートします。テンプレート化されていない 2 次パーティションテーブルは、1 次パーティションの追加、削除、TRUNCATE、および 2 次パーティションの追加、削除、TRUNCATE をサポートします。

パーティションの詳細な説明および使用方法は、[パーティションの概要](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001973607) を参照してください。

**インデックス管理**

* OceanBase データベースは、BTree インデックス、関数インデックス、および空間インデックスのみをサポートします。

* インデックスの作成と削除をサポートします。

**ビュー管理**

* シンプルなビューまたは複雑なビューの作成をサポートします。

* ビューの削除にサポートします。

* `SELECT` ステートメントをサポートします。

* DML ステートメントをサポートします。

**シーケンス管理**

* シーケンスの作成をサポートします。

* シーケンスのリセット機能を含むシーケンスの変更をサポートします。

* シーケンスの削除をサポートします。

**シノニム**

* テーブル、ビュー、シノニム、シーケンスなどのオブジェクトのシノニムの作成をサポートします。

* 共通のシノニムの作成をサポートします。

**トリガー管理**

* トリガーの作成をサポートします。

* トリガーの変更をサポートします。

* トリガーの削除をサポートします。

**データベース接続**

* OceanBase データベース間での読み書き操作をサポートします。

* OceanBase データベースと Oracle データベース間の読み書き操作をサポートします。

tab サポートなし

**制約**

* `UNIQUE` 制約の `DISABLE` 操作はサポートしていません。

**パーティションサポート**

* テンプレート化された 2 次パーティションテーブルは現在、2 次パーティションの追加と削除はサポートしていません。

**インデックス管理**

* ビットマップや逆インデックスなどのインデックスタイプはサポートしていません。
* UPDATE GLOBAL INDEX を使用してインデックスを再構築している間、インデックスは使用できません。

**更新可能なビュー**

`WITH CHECK OPTION` 句はサポートしていません。

## セキュリティ機能

OceanBase データベースは豊富なセキュリティ機能を実装しています。

:::tab
tab サポート

**権限管理**

* Oracle データベースのほとんどのシステム権限と互換性があります。OceanBase データベースの Oracle モードでサポートされている権限については、[Oracle モードでの権限分類](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974760) を参照してください。

* 権限の付与や削除など、一般的なオブジェクト権限管理をサポートします。

* ホワイトリストポリシーをサポートし、ネットワークセキュリティアクセス制御を実現します。

* システム事前定義のロールとユーザー定義のロールをサポートします。

**身元認証**

* Oracle モードは、Oracle データベースのパスワードポリシーと互換性があります。

* ユーザーのロックとロック解除機能をサポートします。

**透過型暗号化**

Oracle データベースの TDE 機能と互換性があり、データはストレージデバイスに書き込まれる前に自動的に暗号化され、読み取り時に自動的に復号化されます。

**監査**

* Oracle データベースの標準監査をサポートします。

* ステートメントとオブジェクト監査タイプをサポートします。

* オブジェクト監査は現在、テーブル、シーケンス、関数、およびパッケージオブジェクトのみをサポートします。

* 監査結果は、ファイルまたは内部テーブルに保存できます。

* 監査に関連する各種システムビューをサポートします。

**タグセキュリティ**

* Oracle データベースのラベルセキュリティ (Label Security) 機能と互換性があります。

* Level 次元をサポートします。

**伝送リンク暗号化 SSL**

* クライアントと OceanBase データベースサーバー間の転送リンクの暗号化、および OceanBase データベースノード間のデータ伝送の暗号化をサポートします。

* SSL 単方向認証、X509 双方向認証に加え、暗号化アルゴリズムの指定、発行者認証の指定、SSL サブジェクト認証の指定など、特殊な双方向認証にもサポートします。

tab サポートなし

**監査**

* 統合監査と FGA による細粒度監査はサポートしていません。

* 権限監査とネットワーク監査はサポートしていません。

* 監査データの削除はサポートしていません。

**タグセキュリティ**

* Compartment と Group 次元はサポートしていません。
