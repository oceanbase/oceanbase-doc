# Oracleとの互換性の概要

このセクションでは、OceanBaseデータベースのOracleモードとネイティブOracleデータベースとの互換性を比較した情報について説明します。

OceanBaseデータベースは、データ型、SQL機能、データベースオブジェクトなどの基本的な機能において、Oracleデータベースと互換性があります。手続き型言語(Procedural Language、PL)に関しては、すでにほぼすべての開発機能と互換性があります。また、データベースのセキュリティ、バックアップ・リカバリ、高可用性、オプティマイザーなどの高度な機能においても、OceanBaseデータベースの互換性は非常に良好であり、一部の機能ではOracleデータベースよりも優れています。これは、OracleデータベースからOceanBaseデータベースへの移行時に、ユーザーが新しい知識を習得するために多くの時間を費やすことなく、スムーズに移行できることを意味します。

さらに、OceanBaseデータベースとOracleデータベースは、基盤となるアーキテクチャや製品形態などが異なるため、一部の機能については、現時点では互換性がないか、あるいはOracleデータベースとの動作に違いが生じる場合があります。このセクションでは、主に以下の側面からOceanBaseデータベースとOracleデータベースの互換性を比較した情報について説明します：

* SQLデータ型

* 内蔵関数

* SQL構文

* 手続き型言語

* システムビュー

* 文字セット

* 照合順序

* データベースオブジェクト管理

* セキュリティ機能

* バックアップ・リカバリ

* SQLエンジン

## SQLデータ型

OceanBaseデータベースは、Oracleデータベースでサポートされているほとんどのデータ型と互換性があります。詳細なサポート情報については、[SQLデータ型](../400.compatibility-with-oracle/200.sql-data-type.md)を参照してください。

最適化の観点から、`LONG`および`LONG RAW`データ型は古すぎるため、OceanBaseデータベースでは現時点でこれらのデータ型をサポートする予定はありません。

## 組み込み関数

OceanBaseデータベースは、Oracleデータベースでサポートされているほとんどの組み込み関数と互換性があります。詳細なサポート情報については、[組み込み関数](../400.compatibility-with-oracle/300.built-in-functions.md)を参照してください。

## SQL構文

OceanBaseデータベースは、OracleデータベースのほとんどすべてのSQL構文をサポートしています。一部の機能が欠けている場合は、構文がサポートされていないというエラーが表示されます。

:::tab
タブのサポート

**SELECT**

* 単一または複数のテーブルに対するクエリ、サブクエリ、ラテラル派生テーブル（Lateral Derived Table）、内部結合、セミ結合、外部結合、グループ化、集計、階層クエリ、一般的な確率関数や線形回帰などのデータマイニング関数を含む、ほとんどすべてのクエリ機能をサポートしています。

* 次の集合演算子をサポートしています：`UNION`、`UNION ALL`、`INTERSECT`、`MINUS`。

* `EXPLAIN`構文を使用して実行計画を表示できます。

**INSERT**

* 単一行および複数行のデータ挿入をサポートし、指定されたパーティションへのデータ挿入もサポートしています。

* `INSERT INTO ... SELECT ...`ステートメントをサポートしています。

* 単一テーブルおよび複数テーブルへのデータ挿入をサポートしています。

**UPDATE**

* 単一列および複数列のデータ更新をサポートしています。

* サブクエリを使用したデータ更新をサポートしています。

* 集合更新データをサポートしています。

**DELETE**

* 単一テーブルおよび複数テーブルのデータ削除をサポートしています。

**TRUNCATE**

* 指定されたテーブルのデータを完全に削除することをサポートしています。

**並列クエリ**

* Oracle系データベースの並列クエリをサポートしています。

  OceanBaseデータベースはAuto DOP機能をサポートしており、また`Hint/Session`変数を使用して手動でDOPを指定することもできます。

* パラレルDML（DML）をサポートしています。

**Hint**

OceanBaseデータベースはHint構文の使用をサポートしています。Hintの詳細については、[Hint](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/300.basic-elements-of-oracle-mode/600.annotation-of-oracle-mode/400.hint-of-oracle-mode/100.hint-overview-of-oracle-mode.md)を参照してください。

:::

## プロシージャリング言語

OceanBaseデータベースは、OracleデータベースのPL機能の大部分と互換性があります。PL機能の詳細については、[PLリファレンス](../../700.reference/500.sql-reference/300.pl-reference/100.what-is-pl/100.pl-introduction.md)を参照してください。

:::tab
タブサポート

OceanBaseデータベースが主にサポートするPL機能は以下のとおりです：

* データ型

* プロセス制御

* コレクションとレコード

* 静的SQL

* 動的SQL

* サブプロシージャ

* トリガー

* 例外処理

* プログラムパッケージ

* パフォーマンス最適化

* カスタムデータ型

* PLシステムパッケージ。これには、DBMS_CRYPTO、DBMS_DEBUG、DBMS_LOB、DBMS_LOCK、DBMS_METADATA、DBMS_OUTPUT、DBMS_RANDOM、DBMS_SQL、DBMS_XA、UTL_I18N、UTL_RAWなどが含まれます。

* PLラベルセキュリティパッケージ。これには、SA_SYSDBA、SA_COMPONENTS、SA_LABEL_ADMIN、SA_POLICY_ADMIN、SA_USER_ADMIN、SA_SESSIONなどが含まれます。

:::

## システムビュー

OceanBaseデータベースは、一部のOracleデータベースのシステムビューと互換性があります。その中で：

* ディクショナリビューが195個互換性あります。

* パフォーマンスビュー（v$で始まるもの）が20個互換性あります。

互換性のある詳細なビューのリストについては、[システムビュー](../400.compatibility-with-oracle/400.system-view.md)を参照してください。

その他のシステムビューのフィールドの説明については、[システムビュー](../../700.reference/700.system-views/200.system-view-overview.md)を参照してください。

## データベースオブジェクト管理

:::tab
タブのサポート

**テーブル管理**

* テーブルの作成：テーブルの作成をサポートしており、作成時にパーティションや制約などの情報を指定できます。テーブル作成の詳細な構文については、[CREATE TABLE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/2400.create-table-of-oracle-mode.md)を参照してください。

* ベーステーブルの変更：`ALTER TABLE` ステートメントを使用して、列の追加、削除、変更、制約の追加・削除、パーティションの追加・削除・変更をサポートします。テーブル変更の詳細な構文については、[ALTER TABLE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1000.alter-table-of-oracle-mode.md)を参照してください。

* ベーステーブルの削除：テーブルの削除と、それに伴う制約のカスケードをサポートします。テーブル削除の詳細な構文については、[DROP TABLE](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/3900.drop-table-of-oracle-mode.md)を参照してください。

**制約**

* `CHECK`、`UNIQUE`、`NOT NULL` 制約をサポートします。

* `PRIMARY KEY` 制約をサポートします。

* `FOREIGN KEY` 制約をサポートします。

* `ALTER TABLE` ステートメントを使用して、`CHECK` 制約、`PRIMARY KEY` 制約、`FOREIGN KEY` 制約、および `NOT NULL` 制約を追加することをサポートします。

* カスケード操作中の `SET NULL` をサポートします。

**パーティションのサポート**

* パーティション、テンプレート化されたおよびテンプレート化されていないコンポジットパーティションをサポートします。

* ハッシュ（Hash）、範囲（Range）、リスト（List）、およびコンポジットパーティションなどのパーティショニング形式をサポートします。

* ローカルインデックスとグローバルインデックスをサポートします。

* パーティションのメンテナンス操作について：

  * パーティションテーブルでは、パーティションの追加、削除、およびパーティションのトランケーションをサポートします。

  * テンプレート化されたコンポジットパーティションテーブルでは、パーティションの追加と削除をサポートします。テンプレート化されていないコンポジットパーティションテーブルでは、パーティションの追加、削除、トランケーション、コンポジットパーティションの追加、削除、トランケーションをサポートします。

パーティションの詳細については、[パーティションの概要](../../700.reference/300.database-object-management/200.manage-object-of-oracle-mode/200.manage-partitions-of-oracle-mode/100.partition-overview-of-oracle-mode.md)を参照してください。

**インデックス管理**

* OceanBaseデータベースは、BTreeインデックスと関数インデックスのみをサポートします。

* インデックスの作成と削除をサポートします。

**ビュー管理**

* シンプルまたは複雑なビューの作成をサポートします。

* ビューの削除機能をサポートします。

* `SELECT` ステートメントを使用したビューのクエリをサポートします。

* DMLステートメントをサポートします。

**シーケンス管理**

* シーケンスの作成をサポートします。

* シーケンスの変更をサポートし、シーケンスの値のリセット機能などが含まれます。

* シーケンスの削除をサポートします。

**シノニム**

* テーブル、ビュー、シノニム、シーケンスなどのオブジェクトに対してシノニムを作成することをサポートします。

* 公共シノニムの作成をサポートします。

**トリガー管理**

* トリガーの作成をサポートします。

* トリガーの変更をサポートします。

* トリガーの削除をサポートします。

**データベースリンク**

* OceanBaseデータベース間の読み取りおよび書き込み操作をサポートします。

* OceanBaseデータベースからOracleデータベースへの読み取りおよび書き込み操作をサポートします。

tabサポートされていません

**制約**

* `UNIQUE`制約の`DISABLE`操作はサポートされていません。

**パーティションのサポート**

* テンプレート化されたコンポジット・パーティションテーブルでは、現在コンポジット・パーティションの追加や削除はサポートされていません。

**インデックス管理**

* ビットマップや逆インデックスなどのインデックスタイプはサポートされていません。
* UPDATE GLOBAL INDEXを使用してインデックスを再構築する間、インデックスは利用できません。

**更新可能なビュー**

`WITH CHECK OPTION`句はサポートされていません。

:::

## セキュリティ機能

OceanBaseデータベースは豊富なセキュリティ機能を実装しています。

:::tab
タブサポート

**権限管理**

* Oracleデータベースのほとんどのシステム権限に互換性があります。OceanBaseデータベースのOracleモードでサポートされる権限については、[Oracleモードの権限分類](../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)を参照してください。

* 権限付与や権限解除など、一般的なオブジェクト権限管理をサポートします。

* アローリングリストポリシーをサポートし、ネットワークセキュリティアクセス制御を実現します。

* システム定義のロールとユーザー定義のロールをサポートします。

**認証**

* Oracleモードは、Oracleデータベースのパスワードポリシーと互換性があります。

* ユーザーのロックおよびロック解除機能をサポートします。

**透過的データ暗号化**

OracleデータベースのTDE機能と互換性があり、データはストレージデバイスに書き込まれる前に自動的に暗号化され、読み取り時には自動的に復号化されます。

**監査**

* Oracleデータベースの標準監査をサポートします。

* ステートメント監査とオブジェクト監査の両方をサポートします。

* オブジェクト監査は現在、テーブル、シーケンス、関数、パッケージオブジェクトのみをサポートしています。

* 監査結果はファイルまたは内部テーブルに保存できます。

* 監査関連の各種システムビューをサポートします。

**ラベルセキュリティ**

* Oracleデータベースのラベルセキュリティ（Label Security）機能と互換性があります。

* レベルの次元をサポートします。

**転送リンク暗号化SSL**

* クライアントとOceanBaseデータベースサーバー間の転送リンク暗号化、およびOceanBaseデータベースノード間のデータ転送暗号化をサポートします。

* SSL一方向認証、X509双方向認証に加えて、指定された暗号アルゴリズム、発行者認証、SSLトピック認証など、特殊な双方向認証もサポートしています。

tabサポートされていません

**監査**

* 統合監査とFGAの詳細な粒度の監査はサポートされていません。

* 権限監査とネットワーク監査はサポートされていません。

* 監査データの変更、上書き、削除はサポートされていません。

**ラベルセキュリティ**

* CompartmentおよびGroupの次元はサポートされていません。

:::
