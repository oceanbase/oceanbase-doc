# MySQL との互換性比較

本節では、主に OceanBase データベースの MySQL モードとネイティブ MySQL データベースの互換性比較情報について説明します。

OceanBase データベースの MySQL モードは、MySQL 5.7/8.0 のほとんどの機能と互換性があります。プロダクトアーキテクチャの違い、または顧客ニーズが低いことから、一部の機能はサポートされていません。本節では、主に OceanBase データベースの MySQL モードとネイティブ MySQL データベースの違いを以下の点から説明します：

* データ型

* SQL 構文

* 手続き型言語

* システムビュー

* 文字セット

* 照合順序

* 関数と式

* パーティションサポート

* バックアップと復元

* ストレージエンジン

* オプティマイザー


## データ型

OceanBase データベースがサポートするデータ型は次の通りです：

* データ型

  * 整数型：`BOOL`/`BOOLEAN`/`TINYINT`、`SMALLINT`、`MEDIUMINT`、`INT`/`INTEGER` および `BIGINT`。

  * 固定小数点型：`DECIMAL` と `NUMERIC`。

  * 浮動小数点型：`FLOAT` と `DOUBLE`。

  * Bit-Value 型：`BIT`。

* 日付時刻型：`DATETIME`、`TIMESTAMP`、`DATE`、`TIME` および `YEAR`。

* 文字型：`CHAR`、`VARCHAR`、`BINARY` および `VARBINARY`。

* 大規模オブジェクト型：`TINYBLOB`、`BLOB`、`MEDIUMBLOB` および `LONGBLOB`。

* テキスト型：`TINYTEXT`、`TEXT`、`MEDIUMTEXT`、`LONGTEXT` および `STRING`。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p> OceanBase データベース V4.3.5 バージョンでは、V4.3.5 BP1 バージョンよりテキストデータ型 <code>STRING</code> がサポートされています。</p>
  </main>

* 列挙型：`ENUM`。

* セット型：`SET`。

* JSON データ型

* 空間データ型

* 高効率圧縮ビットマップデータ型

* 配列データ型

* ベクトルデータ型

## SQL 構文

:::tab
tab サポート

**SELECT**

* 多くのクエリ機能をサポートしています。単一テーブルクエリ、複数テーブルクエリ、サブクエリ、内部結合、半結合、外部結合、グループ化、集計、一般的な確率関数、線形回帰などのデータマイニング関数などをサポートします。

* 複数の `SELECT` クエリ結果に対して、`UNION`、`UNION ALL`、`MINUS`、`EXCEPT`、`INTERSECT` などの集合演算をサポートします。

* `EXPLAIN` 構文を使用して実行計画を確認できます。

**INSERT**

* 単一行および複数行のデータ挿入をサポートし、指定されたパーティションへのデータ挿入もサポートします。

* `INSERT INTO ... SELECT ...` 文をサポートします。

**UPDATE**

* 単一列および複数列のデータ更新をサポートします。

* サブクエリによるデータ更新をサポートします。

* 集合によるデータ更新をサポートします。

**DELETE**

* 単一テーブルと複数テーブルの削除をサポートします。

**TRUNCATE**

* 指定されたテーブルを完全にクリアすることをサポートします。

tab サポートなし

**SELECT**

* `SELECT ... FOR SHARE ...` 構文はサポートされていません。

**TRUNCATE**

* トランザクション処理およびテーブルロックの実行中は操作できません。

:::

## 手続き型言語

OceanBase データベースは MySQL データベースの PL 機能の大部分をサポートしており、主な対応 PL 機能は以下のとおりです：

* データ型
* ストアドプロシージャ
* カスタマ関数
* トリガー
* 例外処理

さらに、OceanBase データベース独自の MySQL PL システムパッケージとして、`DBMS_RESOURCE_MANAGER`、`DBMS_STATS`、`DBMS_UDR`、`DBMS_XPLAN` および `DBMS_WORKLOAD_REPOSITORY` などがあります。

PL 関数の詳細については、[PL リファレンス](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001972342) を参照してください。

## システムビュー

OceanBase データベースは、information_schema と mysql の 2 つの内部データベースの大部分のビューを実装していまが、アーキテクチャの違いにより、OceanBase データベースすべてのビューが実装されていること、およびビュー内のすべての列の意味が MySQL と同一であることは保証していません。

システムビューに関する詳細の説明は、『参考ガイド』の [システムビュー](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001970992) の章を参照してください。

## 関数

:::tab
tab サポート

OceanBase データベースがサポートする分析 (ウィンドウ) 関数は、MySQL データベースのスーパーセットです。MySQL データベースの分析 (ウィンドウ) 関数は全て OceanBase データベースでサポートします。

tab サポートなし

MySQL データベースとの比較において、OceanBase データベースの MySQL モードは、以下の関数をサポートしていません：

* 文字列関数：`LOAD_FILE()` と `MATCH()`。

* XML 関数：`ExtractValue()` と `UpdateXML()`。

* その他の関数：`MASTER_POS_WAIT()`。

:::

## パーティションサポート

OceanBase データベースと MySQL データベースのパーティションサポートの違いは以下のとおりです：

* OceanBase データベースは、1 次パーティション、テンプレート化およびテンプレート化されていない 2 次パーティションをサポートします。MySQL データベースは、テンプレート化されていない 2 次パーティションをサポートしていません。

* OceanBase データベースの 2 次パーティションは、Hash、Key、Range、Range Columns、List および List Columns パーティションをサポートします。MySQL データベースの 2 次パーティションは、Hash パーティションと Key パーティションのみをサポートします。

* OceanBase データベースの 2 次パーティションテーブルは、2 次パーティションの追加と削除をサポートします。MySQL データベースは、2 次パーティションの追加と削除をサポートしません。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>2 次パーティションが Hash または Key である場合、2 次パーティションの追加と削除はサポートされていません。</li><li>OceanBase データベース V4.3.5 バージョンは、V4.3.5 BP1 バージョンから、2 次パーティションの新規サポートが開始されます。</li></ul></p>
  </main>

パーティションの詳細な説明および使用方法は、[パーティションの概要](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001973668) を参照してください。

## バックアップと復元

OceanBase データベースは、MySQL データベースのバックアップと復元機能の一部と互換性があります。

:::tab
tab サポート

* フルバックアップと増分バックアップをサポートします。

* ホットバックアップをサポートします。

* テーブルレベルおよびデータベースレベルの復元をサポートします。

* 指定されたパスの復元をサポートします。

* ログのアーカイブとバックアップデータの検証をサポートします。

tab サポートなし

* クラスターレベルのバックアップと復元はサポートしていません。

* コールドバックアップはサポートしていません。

* テナント内の一部データーベースおよびテーブルレベルのバックアップはサポートしていません。

## ストレージエンジン

MySQL データベースのブロックベースの InnoDB および MyISAM はエンジンが異なるため、OceanBase データベースは LSM-Tree アーキテクチャベースのストレージエンジンを使用しています。

## オプティマイザー

OceanBase データベースは、MySQL データベースのオプティマイザー機能の一部と互換性があります。オプティマイザーの詳細については、[SQL チューニングガイド](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971374) を参照してください。

tab サポート

* 実行計画を確認するコマンド

  * 出力される列情報は、`ID`、`OPERATOR`、`NAME`、`EST. ROWS` と `COST` および演算子の詳細情報のみ含まれます。

* 統計情報を確認

  * `ANALYZE TABLE` 文を実行して、データ検索に格納されている列値のヒストグラム統計情報を手動で照会できます。

  * ビューからテーブル統計情報と列統計情報を自動的に確認できます。

* クエリ書き換え検索の最適化をサポートします。

  * 外部結合の最適化をサポートします。

  * 外部結合の簡略化をサポートします。

  * ブロックネストループ結合とバッチキーアクセス結合をサポートします。

  * 条件フィルタリングをサポートします。

  * 定数畳み込の最適化をサポートします。

  * `IS NULL` の最適化をサポートします (インデックスは `NULL` 値が格納されません)。

  * `ORDER BY` の最適化をサポートします。

  * `GROUP BY` の最適化をサポートします。

  * `DISTINCT` の削除をサポートします。

  * `LIMIT` のプッシュダウンをサポートします。

  * Window 関数の最適化をサポートします。

  * フルテーブルスキャンの回避しますをサポートします。

  * 述語プッシュダウンをサポートします。

* Optimizer Hint の仕組み

  * Optimizer Hint の結合順序をサポートします。

  * テーブルレベルの Optimizer Hints をサポートします。

  * インデックスレベルの Optimizer Hints をサポートします。

  * `INDEX` Hint、`FULL` Hint、`ORDERED` Hint および `LEADING` Hint などの構文をサポートします。

* MySQL データベースとの互換性を維持しつつ、並列クエリ、並列レプリケーション、並列書き込みなどの並列実行機能を備えています。また、OceanBase データベースは、並列集計、並列結合、並列グループ化、並列ソートといった並列演算子を既にサポートしています。

* OceanBase データベースは計画キャッシュとプリコンパイルをサポートしますが、MySQL データベースはサポートしていません。

tab サポートなし

* 実行計画を確認するコマンド

  * `SHOW WARNINGS` を使用した追加情報の表示はサポートされていません。
