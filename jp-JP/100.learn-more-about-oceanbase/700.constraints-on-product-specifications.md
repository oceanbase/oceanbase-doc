#  利用制限

## 単一OBServerノードのマシン仕様

クラスタが安定して稼働できるようにする単一OBServerノードのマシン仕様は以下のとおりです：

| 構成項目    | 最大要件      | 最小要件      |
|------------|--------------|--------------|
| CPU        |  512コア      | 4コア        |
| メモリ      | 1 TB         | 16 GB         |

## トランザクションサイズの制限

OceanBaseデータベースは理論上、ストレージ容量の制限を除き、トランザクションサイズに制限はありません。

## 弱い整合性読み取りの遅延制限

OceanBaseデータベースでサポートされている弱い整合性読み取りの遅延時間は、テナントレベルの構成パラメータ [max_stale_time_for_weak_consistency](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/5400.max_stale_time_for_weak_consistency.md) によって制御されます。デフォルト値は5秒で、最小遅延5秒で最新データを読み取ることができます。

## clog関連の制限

|  プロトコル                   |   制限    |
|-------------------------|--------------------------------------------------------------------------------------------------|
| clog 単一ログサイズ        | 3.5 MB |
| clogログ同期の最大ネットワーク遅延 | clogログ同期の最大ネットワーク遅延は1秒以内であること。ただし、アービトレーションサービスとOceanBaseクラスタノード間の往復ネットワーク遅延は800ミリ秒以下であること。 |

## 機能の制限

### 物理スタンバイデータベース

物理スタンバイデータベースの制限事項は以下のとおりです。

| 制限事項                         |   詳細な説明                                                               |
|-------------------------------|--------------------------------------------------------------------------|
| プライマリテナントあたりのスタンバイテナント最大数 | 製品レベルでは、単一のプライマリテナントがサポートできるスタンバイテナント数に制限はありません。ただし、スタンバイテナントの同期処理ではプライマリテナントのCPU、メモリ、I/Oリソースおよびネットワーク帯域幅が消費されるため、ソーステナントのリソース使用状況と実際のビジネスニーズを踏まえてスタンバイテナントの数を決定することを推奨します         |
| プライマリ/スタンバイテナントのリソース構成    | 同一である必要はありませんが、同じリソース仕様を推奨します。                          |
| 構成パラメータ                         | プライマリテナントとスタンバイテナントの構成パラメータは互いに独立しており、物理的に同期されません。プライマリテナントの構成パラメータを変更した場合は、スタンバイテナントでも同様の変更が必要かどうか評価する必要があります。  |
| システム変数                       | プライマリテナントとスタンバイテナントのシステム変数は物理的に同期されます。プライマリテナントでシステム変数を変更した場合、システムはスタンバイテナントの対応するシステム変数に同期されます。             |
| ユーザーID/パスワード                 | ユーザーの作成およびパスワードの変更は、プライマリテナントでのみサポートされます。更新後の情報はスタンバイテナントに同期されます。                                            |
| 読み書き操作                       | スタンバイテナントは読み取り操作をサポートしますが、書き込み操作はサポートしません。                   |
| ダンプとメジャーコンパクション                     | プライマリテナントとスタンバイテナントのダンプは、互いに独立しています。</br>スタンバイテナントはプライマリテナントから情報を同期します。独立したメジャーコンパクションはサポートしていません。                             |
| スイッチオーバー制限                | スタンバイテナントのログストリームのすべてのレプリカがオンラインである必要があります。                        |
| フェイルオーバー制限                  | スタンバイテナントのログストリームのすべてのレプリカがオンラインである必要があります。                                    |
| オプティマイザー統計情報                  | スタンバイテナントでは統計情報は収集されません。スタンバイテナントの統計情報はプライマリテナントから同期されます。|
