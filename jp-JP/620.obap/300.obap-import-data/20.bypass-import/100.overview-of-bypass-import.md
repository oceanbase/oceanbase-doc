# バイパスインポートの概要

OceanBase データベースは、データベースにデータを挿入するバイパスインポート方式をサポートしています。つまり、OceanBase データベースは `data` ファイルに直接データを書き込む機能をサポートしています。バイパスインポートは、SQL 層のインターフェースを迂回して、`data` ファイル内で直接容量を割り当ててデータを挿入することで、データインポートの効率を向上させます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>バイパスインポートタスクの実行中にアップグレードを実行することは推奨されません。バイパスインポートタスクが失敗する可能性があります。</p>
</main>

## 機能の概要

OceanBase データベースは、 2 つのバイパスインポート方式：フルバイパスインポートとインクリメンタルバイパスインポートをサポートしています。

`LOAD DATA` ステートメント、`INSERT INTO SELECT` ステートメント、`CREATE TABLE AS SELECT` ステートメントでデータをインポートする際に、バイパスインポートをサポートしています。個別のインポートタスクに Hint を追加してデータのインポート方式をバイパスインポートに指定したり、グローバル設定項目 [default_load_mode](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001976661) でデータのインポート方式をバイパスインポートに指定したりすることも可能です。

* **フルバイパスインポート**

  * フルバイパスインポートは、完全なデータセットを一度にデータベースのデータファイルに直接書き込むために使用されます。この方法は、SQL 層のインターフェースを迂回して、データファイル内で直接容量を割り当ててデータを挿入することで、データインポートの効率を向上させます。
  * フルバイパスインポートは通常、データベースの初期化、データの移行、または大量のデータを高速でロードする必要がある場合に使用されます。

* **インクリメンタルバイパスインポート**
  
  * インクリメンタルバイパスインポートは、既に大量のデータが存在する状況で、新しく追加されたデータを SQL インターフェースを通さずにデータベースのデータファイルに直接書き込むために使用されます。この方法は、SQL 層のデータ処理プロセスを迂回して、新しく追加されたデータを直接データファイルに書き込むことで、データの書き込み効率を向上させます。
  * インクリメンタルバイパスインポートは通常、高スループットのデータ書き込みシナリオで使用されます。例えば、大規模なリアルタイムデータ収集、ログ書き込みなどのシナリオです。

## 使用シナリオ

バイパスインポート機能は、以下のシナリオで使用できます：

* データの移行と同期。データの移行と同期では、通常、さまざまな形式の大量のデータを異なるデータソースから OceanBase データベースに移行する必要があり、従来の SQL インターフェースのパフォーマンスでは時間的な要件を満たせない場合があります。

* 従来の ETL。ソース側でデータの抽出と変換を行った後、ターゲット側にロードする際、通常は短時間で大量のデータをロードする必要があります。バイパスインポート技術を使用することで、データインポートのパフォーマンスが向上します。ELT 技術においても、データをロードするプロセスでバイパスインポート技術を使用して効率を向上させることができます。

* テキストファイルやその他のデータソースから OceanBase データベースにデータをロードする際、バイパスインポート技術を利用することで、データロードの効率を向上させることができます。
