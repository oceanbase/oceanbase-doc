# AP シナリオにおけるパラメーター設定の推奨

本記事では、オンライントランザクション処理 (EXPRESS OLTP)、複雑なオンライントランザクション処理 (COMPLEX OLTP)、トランザクション処理と分析処理の混合 (HTAP)、リアルタイム分析 (OLAP)、OBKV アプリケーションを含む、いくつかの典型的なシナリオにおける推奨設定プランを紹介します。

ユーザーがさまざまなビジネスシナリオで OceanBase データベースに基づいて優れたパフォーマンスを得られるよう、OceanBase は過去の実運用環境での膨大なチューニング経験に基づいて、各ビジネスシナリオの主要な設定項目と変数の推奨設定をまとめ、これらの推奨設定をコア V4.3.2 以降のバージョンのインストールパッケージに格納しました。これはデプロイ後に直接確認できます。さらに、ユーザーがより便利に利用できるように、パラメーターテンプレートが OceanBase クラウドプラットフォーム (OceanBase Cloud Platform、OCP) および OceanBase インストール・デプロイツール (OceanBase Deployer、obd) でサポートされており、OCP または obd を使用してクラスターとテナントを作成する際に、ユーザーは対応するシナリオのパラメーターテンプレートを選択して直接設定を完成させることができます。

## パラメーター設定テンプレート

OceanBase データベースの RPM パッケージをインストールすると、`/home/admin/oceanbase/etc` ディレクトリで、さまざまなビジネスシナリオの推奨されるパラメーター設定のパラメーター設定テンプレートを確認することができます。

* `default_parameter.json`：設定項目の推奨設定が保存されました。
* `default_system_variable.json`：変数の推奨設定が保存されました。

## シナリオ紹介

### オンライントランザクション処理 (EXPRESS_OLTP)

オンライントランザクション処理 (EXPRESS_OLTP) とは、リアルタイムで、インタラクティブに、高頻度で、データベースにデータを追加、削除、更新、検索する操作を指します。これは銀行、小売、航空、ホテルなどの業界でよく見られ、請求書の支払い、在庫管理、注文処理などの日常的なビジネス操作を処理するために使用されます。OLTP シナリオでは、通常、大量の同時実行トランザクションを処理する必要があり、データベースはユーザーからのリクエストに迅速かつ確実に応答できる必要があります。

このシナリオの推奨設定の詳細については、[設定のベストプラクティス](../../400.deploy/700.best-practices.md) を参照してください。

### 複雑なオンライントランザクション処理 (COMPLEX OLTP)

複雑なオンライントランザクション処理 (COMPLEX OLTP) は、大量のデータと複雑なトランザクションを処理するシナリオです。このシナリオは、銀行や保険システムなどの分野のワークロードに適しています。これらには通常、複雑な接続、複雑な結合サブクエリ、PL で記述されたバッチジョブが含まれ、長時間トランザクションと大規模なトランザクションを特徴としています。場合によっては、短時間実行されるクエリを高速化するために、並列実行戦略が採用されることもあります。

このシナリオの推奨設定の詳細については、[設定のベストプラクティス](../../400.deploy/700.best-practices.md) を参照してください。

### トランザクション処理と分析処理の混合 (HTAP)

トランザクション処理と分析処理の混合 (以下 HTAP) は、OLTP (オンライントランザクションプロセッシング) と OLAP (オンラインアナリティカルプロセッシング) の両方を同時にサポートする、データベース管理システムまたはアーキテクチャを指します。トランザクション処理と分析処理の混合のシナリオには、金融取引、小売業、物流などの、リアルタイム分析とデータクエリが求められるビジネス環境が含まれます。これらの分野では、ビジネス上の意思決定と分析を支援するための、効率的なトランザクション処理とリアルタイムのデータ分析およびクエリ機能が必要です。HTAP アーキテクチャの利点は、データのコピーと変換のコストを削減し、リアルタイムのデータ分析能力があり、ビジネス意思決定プロセスを加速できる点です。

このシナリオの推奨設定の詳細については、[設定のベストプラクティス](../../400.deploy/700.best-practices.md) を参照してください。

### リアルタイム分析 (OLAP)

リアルタイム分析 (OLAP) は、大規模データセットを多次元的に分析するために用いられるデータ処理技術です。これにより、ユーザーがディメンション、度量、制限、ソートなど、さまざまな角度からデータに対する複雑な分析を実行できます。OLAP は、ユーザーがデータ内のモード、トレンド、関連性を識別して理解するのに役立ち、意思決定とビジネスインテリジェンスをサポートします。OLAP 技術は通常、データウェアハウスやビジネスインテリジェンスシステムで使用されます。

このシナリオの推奨設定の詳細については、[設定のベストプラクティス](../../400.deploy/700.best-practices.md) を参照してください。

### OBKV

OBKV は OceanBase のマルチモデル KV プロダクトであり、低コストで大規模な構造化 / 半構造化データストレージを提供し、シンプルな操作インターフェースで非常に強力なアクセスパフォーマンスを実現します。実装する際、OBKV は SQL 層を Bypass し、OceanBase の分散ストレージを基盤として、その上に様々なマルチモデル KV 形式を構築します。分散ストレージとマルチモデル形態の間の、OBKV には TableAPI と呼ばれるフレームワーク層があり、モデル層に対してカプセル化されたストレージ / トランザクション呼び出し機能を提供します。

このシナリオの推奨設定の詳細については、[設定のベストプラクティス](../../400.deploy/700.best-practices.md) を参照してください。
