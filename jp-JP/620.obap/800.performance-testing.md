# パフォーマンステスト

OceanBase は、高性能な分散型リレーショナルデータベースとして、Sysbench や TPC-H などの標準テストを通じて、AP シナリオにおけるパフォーマンスを検証することができます。以下、2 つの側面から分析を進めます：

## OceanBase データベース Sysbench テスト

Sysbench テストを使用して、OceanBase の高並列トランザクションシナリオにおけるスループット (QPS) とレイテンシのパフォーマンスを検証し、従来のスタンドアロン型データベース (MySQL など) のパフォーマンスと比較します。

詳細は以下をご覧ください：

- [OceanBase Sysbench 高性能パラメーター設定](https://en.oceanbase.com/docs/common-oceanbase-database-10000000002440118)

- [OceanBase Sysbench パフォーマンス問題分析](https://en.oceanbase.com/docs/common-oceanbase-database-10000000002440119)

## OceanBase データベース TPC-H テスト

TPC-H は、国際標準のビジネスインテリジェンス (BI) ベンチマークテストで、22 個の複雑なクエリ、集約、接続、ソートなどのシナリオが含まれています。そのコア指標には、以下が含まれます：

- QphH@size：1 時間あたりに処理するクエリ数量 (QphH) とデータサイズ (size、单位 GB) との比較値。
- レスポンス時間：各クエリがコミットされてから結果が返されるまでの時間。

詳細は以下をご覧ください：

- [OceanBase データベース TPC-H テスト](https://en.oceanbase.com/docs/common-oceanbase-database-10000000002414798)

- [OceanBase データベース TPC-H テストレポート](https://en.oceanbase.com/docs/common-oceanbase-database-10000000002414799)
