# CREATE TABLE AS SELECTステートメントを使用したデータのダイレクトロード

本記事では、**`CREATE TABLE AS SELECT`（CTAS）** を使用して、**テーブル作成と同時に** クエリ結果を新しいテーブルに書き込む方法、および **ダイレクトロード** ヒントと [default_load_mode](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2050.default_load_mode.md) の組み合わせ方について説明します。

データソースは、**内部テーブル、外部テーブル、`FILES(...)` を含む SELECT** などが可能です。

## ダイレクトロードモード（フル / 増分）

`CREATE TABLE AS SELECT` ステートメントでは、`DIRECT()` ヒントを設定することでダイレクトロードモードを指定します。ヒントが指定されていない場合は、パラメータ [default_load_mode](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2050.default_load_mode.md) でデフォルト動作を制御できます。

### 使用構文

```sql
CREATE /*+ [APPEND | DIRECT(need_sort,max_error,{'full'|'inc'|'inc_replace'})] parallel(N) */ TABLE table_name [AS] select_sentence
```

`CREATE TABLE AS SELECT` 構文の詳細については、[CREATE TABLE（MySQLモード）](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2600.create-table-of-mysql-mode.md) および [CREATE TABLE（Oracleモード）](../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/2400.create-table-of-oracle-mode.md) を参照してください。

**パラメータの説明：**

|パラメータ|説明|
|------|------|
| APPEND \| DIRECT()      | ヒントを使用してダイレクトロード機能を有効にします。<ul><li><code>APPEND</code> ヒントは、デフォルトで使用される <code>DIRECT(true, 0)</code> と同等であり、オンライン統計情報収集（<code>GATHER_OPTIMIZER_STATISTICS</code> ヒント）の機能も実現します。</li><li><code>DIRECT()</code> パラメータの説明は以下のとおりです：<ul><li><code>need_sort</code>：書き込むデータがソートが必要かどうかを示します。値は <code>bool</code> 型です：<ul><li><code>true</code>：ソートが必要です。</li><li><code>false</code>：ソートは不要です。</li></ul></li><li><code>max_error</code>：許容される最大誤り行数を示します。値は <code>INT</code> 型で、この値を超えるとインポートタスクの実行は失敗します。</li><li><code>full</code>：フルダイレクトロードを示します。</li><li><code>inc\|inc_replace</code>：増分ダイレクトロードの2つのモードを示します。<ul><li><code>inc</code>：増分インポートを示します。主キーの重複をチェックし、<code>INSERT</code> および <code>IGNORE</code> セマンティクスをサポートします。</li><li><code>inc_replace</code>：増分インポートを示しますが、主キーの重複をチェックしません。<code>REPLACE</code> セマンティクスの増分インポートに相当します。</li></ul></li></ul></li></ul><main id="notice" type='notice'><h4>注意</h4><p><code>load_mode</code> の値が <code>inc_replace</code> の場合、<code>CREATE TABLE AS SELECT</code> ステートメントに <code>REPLACE</code> または <code>IGNORE</code> キーワードを使用することはできません。</p></main>|
| parallel(N) | データロードの並列度です。必須項目で、1より大きい整数を指定します。|

### 使用例

:::tab
tab MySQLモード

ダイレクトロードを使用して、テーブル `tbl1` のデータを他のテーブルにインポートします。

1. テーブル `tbl1` を作成し、テストデータを書き込みます。

   ```shell
   obclient [test]> CREATE TABLE tbl1(c1 int);
   obclient [test]> INSERT INTO tbl1 VALUES (1),(2),(3);
   obclient [test]> SELECT * FROM tbl1;
   ```

2. `CREATE TABLE AS SELECT` を使用して `tbl2` にインポートします。

   * フルモード：

     ```shell
     obclient [test]> CREATE /*+ direct(true, 0, 'full') parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     ```

   * 増分モード：

     ```shell
     obclient [test]> CREATE /*+ direct(true, 0, 'inc') parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     obclient [test]> CREATE /*+ direct(true, 0, 'inc_replace') parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     ```

   * オプション：`APPEND` を使用する場合（`DIRECT(true, 0)` と同じ）：

     ```shell
     obclient [test]> CREATE /*+ append parallel(4) */ TABLE tbl2 AS SELECT * FROM tbl1;
     ```

3. ヒントを指定しない場合、パラメータでデフォルトモードを制御できます：

   ```shell
   obclient [test]> ALTER SYSTEM SET default_load_mode ='FULL_DIRECT_WRITE';
   obclient [test]> CREATE TABLE tbl2 AS SELECT * FROM tbl1;
   ```

   または：

   ```shell
   obclient [test]> ALTER SYSTEM SET default_load_mode ='INC_DIRECT_WRITE';
   obclient [test]> CREATE TABLE tbl2 AS SELECT * FROM tbl1;
   ```
