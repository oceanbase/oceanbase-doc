# データ同期

データ同期とは、移行または同期ツールが**上流の変更を継続的に読み取り**、その結果を**ターゲットのOceanBase**（または他の下流）に**書き込む**ことで、業務上許容される遅延範囲内でターゲットデータベースとソースデータベースを一貫性させるプロセスです。一度限りのデータ移行と比較して、長時間にわたるリンク運用、遅延監視、および一貫性のあるリプレイに重点を置いています。

OceanBaseエコシステムにおいて、**OMS（OceanBase Migration Service）**はリレーショナルソースデータベースからOceanBaseへの主要な移行ソリューションの一つであり、通常は**スキーマ + フルコンテンツ + 増分**を対象とし、切り替えのオーケストレーションもサポートしています。
