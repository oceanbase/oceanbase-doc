# OceanBaseデスクトップ版のデプロイ

OceanBaseデスクトップ版は、seekdbを管理および操作するためのデスクトップアプリケーションです。グラフィカルインターフェースを提供し、ユーザーがデータベース管理、クエリ実行、データのインポート・エクスポートなどの操作を容易に行えるようにします。

OceanBaseデスクトップ版には以下の特徴があります：

* **グラフィカルインターフェース**：直感的で使いやすいグラフィカルインターフェースにより、データベース管理タスクが簡素化されます。

* **データベース管理**：データベースインスタンスの作成と管理をサポートします。

* **クエリ実行**：SQLクエリのコマンドラインを提供します。

* **監視とログ**：データベースの状態をリアルタイムで監視します。

OceanBaseデスクトップ版のデプロイ方法の詳細については、[OceanBase Desktopのデプロイ](https://www.oceanbase.ai/docs/zh-CN/deploy-oceanbase-desktop/)を参照してください。
