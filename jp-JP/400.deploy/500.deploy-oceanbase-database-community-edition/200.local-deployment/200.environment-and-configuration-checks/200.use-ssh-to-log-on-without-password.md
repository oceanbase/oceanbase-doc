# (オプション) パスワードレス SSH ログインの設定

## 用語解説

* 中央制御マシン

  obd がインストールされたマシンは、OceanBase クラスターの管理と、OceanBase クラスターのインストールパッケージおよびクラスター構成情報の保存を行うために用いられます。
  
* ターゲットマシン

  OceanBase データベースがインストールされたマシン。

## 操作手順

中央制御マシンで、以下の手順に従ってパスワードレス SSH ログインを設定します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>使用するユーザー全員に対して、パスワードレスログインを設定する必要があります。OceanBase データベースを admin ユーザーでデプロイする予定がある場合、ターゲットマシンの admin ユーザーにパスワードレスログインを設定する必要があります。OceanBase データベースのデプロイには、admin ユーザーを使用することを推奨します。</p>
</main>

1. 中央制御マシンで以下のコマンドを実行して、キーが存在するかどうかを確認します。

   ```shell
   [admin@test001 ~]$ ls ~/.ssh/id_rsa.pub
   ```

   結果としてキーが既に存在していることが示された場合、新しいキーを生成する必要はありません。

2. (オプション) 中央制御マシンで以下のコマンドを実行して、SSH 公開鍵と秘密鍵を生成します。

   ```shell
   [admin@test001 ~]$ ssh-keygen -t rsa
   ```

3. 中央制御マシンの公開鍵をターゲットマシンの authorized_keys ファイルにコピーします。

   ```shell
   [admin@test001 ~]$ ssh-copy-id -i ~/.ssh/id_rsa.pub <user>@<server_ip>
   ```

### (付録) スクリプト参照

以下のスクリプトの使用を推奨します。以下のスクリプトの実行には sudo 権限が必要です。

```shell
#!/usr/bin/bash
   
SERVERS=("<user>@<server_ip1>" "<user>@<server_ip2>" "<user>@<server_ip3>")
PASSWORD="******"
keygen() {
sudo yum -y install expect
expect -c "
   spawn ssh-keygen -t rsa
   expect {
      *(~/.ssh/id_rsa):* { send -- \r;exp_continue}
      *(y/n)* { send -- y\r;exp_continue}
      *Enter* { send -- \r;exp_continue}
      *(y/n)* { send -- y\r;exp_continue}
      *Enter* { send -- \r;exp_continue}
      eof {exit 0}
   }
   expect eof
"
}
copy(){
expect -c "
   set timeout -1
   spawn ssh-copy-id $1
   expect {
      *(yes/no)* { send -- yes\r; exp_continue }
      *password:* { send -- $PASSWORD\r; exp_continue}
      eof {exit 0}
   }
   expect eof
"
}
ssh_copy_id_to_all(){
keygen ;
for host in ${SERVERS[@]}
do
      copy $host
done
}
ssh_copy_id_to_all
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>スクリプトの先頭 2 行の <strong>SERVERS</strong> リストと <strong>PASSWORD</strong> を、ご自身の実際のマシンリストとパスワードに置き換える必要があります。</p>
</main>
