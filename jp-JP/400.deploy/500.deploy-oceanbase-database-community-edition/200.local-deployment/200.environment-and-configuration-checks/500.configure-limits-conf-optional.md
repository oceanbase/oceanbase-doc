# （オプション）limits.confの設定

本記事では、`limits.conf` を設定してプロセス数を制限する方法について説明します。

個人ユーザーの場合は、この手順をスキップできます。企業ユーザーの場合は、`limits.conf` の設定を推奨します。

リソース制限を変更するには、以下の2つの方法があります：

* 起動時にセッションレベルで変更します。

* 設定ファイル `/etc/security/limits.conf` を使用してグローバルレベルで変更します。

OceanBaseデータベースのプロセスに関連する制限には、スレッドの最大スタックサイズ（Stack）、最大ファイルハンドル数（Open Files）、コアファイルサイズ（Core File Size）が含まれます。

## 設定の変更

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>この操作は、各マシンで個別に実行する必要があります。</p>
</main>

セッションレベルの最大スタックサイズを `unlimited`、最大ファイルハンドル数を `655350`、コアファイルサイズを `unlimited` に設定します。

次のコマンドを実行して、`/etc/security/limits.conf` 設定ファイルを開きます：

```shell
sudo vim /etc/security/limits.conf
```

`/etc/security/limits.conf` 設定ファイルに、次の内容を追加します：

```shell
root soft nofile 655350
root hard nofile 655350
* soft nofile 655350
* hard nofile 655350
* soft stack unlimited
* hard stack unlimited
* soft nproc 655360
* hard nproc 655360
* soft core unlimited
* hard core unlimited
```

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>/etc/security/limits.d/20-nproc.conf</code> ファイルにnprocの設定が存在するかどうか確認し、存在する場合はその値も同時に変更する必要があります。</p>
</main>

## 設定の確認

現在のセッションを終了し、再ログインします。次のコマンドを実行して、設定が有効になっているかどうか確認します。

```shell
ulimit -a
```

出力は次のとおりです。

```shell
core file size          (blocks, -c) unlimited
data seg size           (kbytes, -d) unlimited
scheduling priority             (-e) 0
file size               (blocks, -f) unlimited
pending signals                 (-i) 252876
max locked memory       (kbytes, -l) 64
max memory size         (kbytes, -m) unlimited
open files                      (-n) 655350
pipe size            (512 bytes, -p) 8
POSIX message queues     (bytes, -q) 819200
real-time priority              (-r) 0
stack size              (kbytes, -s) unlimited
cpu time               (seconds, -t) unlimited
max user processes              (-u) 655360
virtual memory          (kbytes, -v) unlimited
file locks                      (-x) unlimited
```

結果から次のことがわかります：

* core file size は、コアファイルの最大しきい値（ブロック単位）を表します。これは `limits.conf` 設定ファイルの core パラメータに対応しており、値が unlimited であるかどうか確認する必要があります。

* open files は、最大開いているファイル記述子数を表します。これは `limits.conf` 設定ファイルの nofile パラメータに対応しており、値が 655350 であるかどうか確認する必要があります。

* stack size は、スタックサイズ（キロバイト単位）を表します。これは `limits.conf` 設定ファイルの stack パラメータに対応しており、値が unlimited であるかどうか確認する必要があります。

* max user processes は、最大ユーザープロセス数を表します。これは `limits.conf` 設定ファイルの nproc パラメータに対応しており、値が 655360 であるかどうか確認する必要があります。
