# (オプション) ファイアウォールと SELinux を無効にする

本記事では、ファイアウォールと SELinux を無効にする方法について説明します。個人ユーザーの場合は、この手順をスキップできます。企業ユーザーの方は、本記事を参考にファイアウォールと SELinux を無効にすることを推奨します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>各マシンでこの操作を個別に実行する必要があります。</p>
</main>

## ファイアウォールを無効にする

以下のコマンドを順番に実行して、ファイアウォールを無効化します。

```shell
systemctl disable firewalld 
systemctl stop firewalld
systemctl status firewalld
```

## SELinux を無効化します

以下のコマンドを実行して、`/etc/selinux/config` 設定ファイルを開きます。

```shell
vi /etc/selinux/config
```

`/etc/selinux/config` 設定ファイルにおいて、該当の設定項目を以下のように変更します。

```shell
SELINUX=disabled
```

以下のコマンドを実行するか、またはサーバーを再起動して変更を有効にします。

```shell
setenforce 0
```

以下のコマンドを実行して、変更が有効になっているか確認します。

```shell
sestatus
```
