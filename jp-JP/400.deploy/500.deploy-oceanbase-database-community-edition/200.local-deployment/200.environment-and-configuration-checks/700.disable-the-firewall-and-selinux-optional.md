# （オプション）ファイアウォールとSELinuxを無効にする

本記事では、ファイアウォールとSELinuxを無効にする方法について説明します。個人ユーザーの場合は、この手順をスキップしてください。企業ユーザーの場合は、本記事を参照してファイアウォールとSELinuxを無効にすることを推奨します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>各マシンでこの操作を個別に実行する必要があります。</p>
</main>

## ファイアウォールを無効にする

次のコマンドを順番に実行して、ファイアウォールを無効にします：

```shell
systemctl disable firewalld
systemctl stop firewalld
systemctl status firewalld
```

## SELinuxを無効にする

次のコマンドを実行して、`/etc/selinux/config` 設定ファイルを開きます：

```shell
vi /etc/selinux/config
```

`/etc/selinux/config` 設定ファイル内の対応する構成パラメータを次の内容に変更します：

```shell
SELINUX=disabled
```

次のコマンドを実行するか、サーバーを再起動して変更を有効にします：

```shell
setenforce 0
```

次のコマンドを実行して、変更が有効になっているかどうか確認します：

```shell
sestatus
```
