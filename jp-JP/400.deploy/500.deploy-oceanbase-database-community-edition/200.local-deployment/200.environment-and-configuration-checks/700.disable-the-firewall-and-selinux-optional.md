# （オプション）ファイアウォールとSELinuxを無効にする

本記事では、ファイアウォールとSELinuxを無効化する方法について説明します。個人で試用する場合は、この手順をスキップできます。本番環境で使用する場合は、本記事を参考にファイアウォールとSELinuxを無効にすることをお勧めします。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>各マシンでこの操作を個別に実行する必要があります。</p>
</main>

## ファイアウォールを無効にする

以下のコマンドを順番に実行して、ファイアウォールを無効にします：

```shell
[admin@test001 ~]$ sudo systemctl disable firewalld
[admin@test001 ~]$ sudo systemctl stop firewalld
[admin@test001 ~]$ sudo systemctl status firewalld
```

## SELinuxを無効にする

以下のコマンドを実行して、`/etc/selinux/config` 設定ファイルを開きます：

```shell
[admin@test001 ~]$ sudo vim /etc/selinux/config
```

`/etc/selinux/config` 設定ファイル内の該当構成パラメータを以下の内容に変更します：

```shell
SELINUX=disabled
```

以下のコマンドを実行するか、サーバーを再起動して変更を有効にします：

```shell
[admin@test001 ~]$ setenforce 0
```

以下のコマンドを実行して、変更が有効になっているか確認します：

```shell
sestatus
```
