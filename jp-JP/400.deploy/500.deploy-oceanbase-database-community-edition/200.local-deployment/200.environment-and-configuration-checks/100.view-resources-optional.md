# (オプション)リソースの確認

分散型OceanBaseクラスタをデプロイする予定がある場合は、OceanBaseクラスタのデプロイ時にすべてのマシンで同一のソフトウェアおよびハードウェア構成を使用することを推奨します。詳細については、[ソフトウェアおよびハードウェア要件](../100.requirements-for-software-and-hardware.md)を参照してください。

単一マシンでOceanBaseデータベースをデプロイする予定がある場合は、この手順をスキップできます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>本記事の設定ファイルとは、obdを使用してOceanBaseデータベースをデプロイする際に設定する必要があるファイルを指します。その他の設定ファイルの詳細については、<a href="https://github.com/oceanbase/obdeploy/tree/master/example">設定ファイルの例</a>を参照してください。</p>
</main>

## オペレーティングシステムの確認

### Red Hat Enterprise Linux Server 7.X

以下のコマンドを実行して、オペレーティングシステム情報を確認します：

```shell
cat /etc/redhat-release
```

実行結果は次のとおりです：

```shell
Red Hat Enterprise Linux Server release 7.2 (Maipo)
```

## カーネルの確認

以下のコマンドを実行して、カーネル情報を確認します：

```shell
uname -r
```

OceanBaseデータベースでは、オペレーティングシステムが3.10.0以降であることが求められます。

## メモリの確認

以下のコマンドを実行して、メモリを確認します：

```shell
free -g
```

利用可能なメモリが設定ファイル内の`memory_limit`値より小さい場合は、キャッシュをクリーンアップするか、設定ファイルの`memory_limit`を変更し、利用可能なメモリより小さい値に変更してください。

以下のコマンドを実行して、キャッシュをクリーンアップします：

```shell
sudo sysctl -w vm.drop_caches=3
# または
sudo echo 3 > /proc/sys/vm/drop_caches
```

## ディスクの確認

以下のコマンドを実行して、ディスクを確認します：

```shell
df -h
```

設定ファイル内の`data_dir`、`redo_dir`、`home_path`に対応するディスクがマウント済みであることを確認してください。`data_dir`および`redo_dir`に対応するディレクトリは空であり、`data_dir`に対応するディレクトリのディスク使用率は4％未満でなければなりません。

## NIC名の確認

設定ファイル内の`devname`パラメータにNICを指定する必要があります。設定ファイルの例は次のとおりです：

```shell
# Please set devname as the network adaptor's name whose ip is  in the setting of severs.
# if set severs as "127.0.0.1", please set devname as "lo"
# if current ip is 192.168.1.10, and the ip's network adaptor's name is "eth0", please use "eth0"
devname: eth0
```

次のコマンドを実行して、NIC名を確認します。

```shell
ifconfig
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>ifconfig</code> コマンドを実行するには、<code>net-tools</code> 依存関係をインストールする必要があります。</p>
</main>
