# ソフトウェアおよびハードウェア要件

OceanBaseデータベースは分散型クラスタデータベースであり、本番環境では少なくとも3台のマシンが必要です。学習用途では、スタンドアロン版を導入することもできます。OceanBaseデータベースのデプロイは従来のデータベースと多くの共通点があり、オペレーティングシステム、ハードウェア、ソフトウェアの設定に関していくつかのベストプラクティスを推奨しています。これらは OceanBase データベースを高性能かつ安定して稼働させるための基盤となります。

## ソフトウェアリソースについて

下表では、異なるOSバージョンに対応するインストールパッケージが示されています。

|                       オペレーティングシステム                        |                                            インストールパッケージのダウンロード URL                                             |
|---------------------------------------------------|------------------------------------------------------------------------------------------------|
| Alibaba Cloud Linux 2、CentOS 7、RedHat 7、Ubuntu 16.X、Debian 9.X | [el7をダウンロード](https://mirrors.aliyun.com/oceanbase/community/stable/el/7/) |
| Alibaba Cloud Linux 3、CentOS 8、RedHat 8、Debian 10 、Anolis OS 8.X             | [el8をダウンロード](https://mirrors.aliyun.com/oceanbase/community/stable/el/8/) |
| Alibaba Cloud Linux 3、Rocky Linux 9              | [al8をダウンロード](https://mirrors.aliyun.com/oceanbase/community/stable/al/8)  |

<main id="notice" type='notice'>
  <h4>説明</h4>
  <p>Linux Kernel 5.10以上(glibc>=2.32)のオペレーティングシステムでは、al8 RPMパッケージの使用を推奨します。Linux Kernelが5.10未満のオペレーティングシステムでは、el7 RPMパッケージの使用を推奨します。</p>
</main>

## ハードウェアリソースの準備

OceanBaseデータベースは、以下の環境でシステムテストと検証を完了しています。下記のソフトウェアおよびハードウェア構成を推奨しますので、お使いのマシンで実際に利用可能なリソースが、表の要件を満たしていることをご確認ください。

| 項目               | 説明                                                         |
| ------------------ | ------------------------------------------------------------ |
| システム           | <ul><li>Anolis OS 8.X系 (カーネルLinux 4.19以上)</li><li>Alibaba Cloud Linux 2/3系 (カーネルLinux 4.19以上)</li><li>Red Hat Enterprise Linux Server 7.X系、8.X系 (カーネルLinux 4.19以上)</li><li>CentOS Linux 7.X系、8.X系 (カーネルLinux 4.19以上)</li><li>Rocky linux 9 (カーネルLinux 5.14)</li><li>Debian 9.X系以上 (カーネルLinux 4.19以上)</li><li>Ubuntu 16.X系以上 (カーネルLinux 4.19以上)</li><li>SUSE / openSUSE 15.X系以上 (カーネルLinux 4.19以上) </li><li>KylinOS V10</li><li>UOS (统信) V20</li><li>NFSChina (中科方德) 4.0以上</li><li>Inspur KOS (浪潮) 5.8</li></ul> |
| 物理CPU            | <ul><li> テスト環境の最小要件：2コア </li> <li>本番環境の最小要件：4コア (32コア以上を推奨)</li><li>性能テスト環境：24コア以上を推奨</li> </ul> |
| メモリ             | <ul><li> テスト環境の最小要件：6GB </li><li> 本番環境の最小要件：16GB、長期利用の場合は32GB以上が必須 (256GBから1024GBの範囲を推奨) </li><li>性能テスト環境：128GBから1024GBの範囲を推奨</li></ul><div><h4>注意</h4><p>複数のクラスタをデプロイする場合、OCP (OceanBase Cloud Platform) を使用した統合的な運用管理を推奨します。デプロイするクラスターが少ない場合は、OBD (OceanBase Deployer) を使用したインストールとデプロイを推奨します。</p></div> |
| ディスクタイプ     | SSDストレージを使用                                          |
| ディスク容量       | 最小要件：20GB                                               |
| ファイルシステム   | EXT4 または XFS (データが16TBを超える場合はXFSのみをサポート) |
| ネットワークカード | ギガビットイーサネット以上                                   |

さらに多くのソフトウェア・ハードウェア環境への対応をテスト中です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseクラスタをデプロイする際は、クラスター内のすべてのマシンの構成を統一してください。ここに記載した性能テスト環境および本番環境のリソース要件は、あくまでも推奨値です。Community Editionの今後のバージョンでは、メモリ要件をさらに引き下げる予定です。</p>
</main>

Red Hat Enterprise Linux (RHEL) 9より前のバージョンでは、以下のコマンドを実行して、手動でTransparent Huge Pages (THP)を無効にする必要があります。

```bash
echo never > /sys/kernel/mm/redhat_transparent_hugepage/enabled
```

Red Hat Enterprise Linux (RHEL) 9またはCentOSでは、以下のコマンドを実行して、手動でTransparent Huge Pages (THP)を無効にする必要があります。

```bash
echo never > /sys/kernel/mm/transparent_hugepage/enabled
```
