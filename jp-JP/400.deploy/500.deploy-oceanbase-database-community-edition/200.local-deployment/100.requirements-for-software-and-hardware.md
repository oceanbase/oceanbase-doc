# ソフトウェアおよびハードウェア要件

OceanBaseデータベースは分散型クラスタ製品であり、本番環境では少なくとも3台のマシンが必要です。学習環境では、スタンドアロン版をデプロイすることも可能です。OceanBaseデータベースのデプロイは従来のデータベースと多くの共通点があり、OSやハードウェア、ソフトウェア設定に関していくつかのベストプラクティスが推奨されています。これらは、OceanBaseデータベースが高パフォーマンスかつ安定して動作するための基盤となります。

## ソフトウェアリソースの紹介

以下の表は、異なるOSバージョンに適用されるインストールパッケージを示しています。

|                       オペレーティングシステム                        |                                            インストールパッケージのダウンロードURL                                             |
|---------------------------------------------------|------------------------------------------------------------------------------------------------|
| Alibaba Cloud Linux 2、CentOS 7、RedHat 7、Ubuntu 16.X、Debian 9.X | [el7のダウンロードURL](https://mirrors.aliyun.com/oceanbase/community/stable/el/7/x86_64/) |
| Anolis OS 8.X、Alibaba Cloud Linux 3、CentOS 8、RedHat 8、Debian 10              | [el8のダウンロードURL](https://mirrors.aliyun.com/oceanbase/community/stable/el/8/x86_64/) |

## ハードウェアリソースの準備

|----------|-----------------------------------------------------------------------------------------------------------------------|
|システム|<ul><li>Anolis OS 8.Xバージョン（カーネルLinux 4.19バージョン以上）</li><li>Alibaba Cloud Linux 2/3バージョン（カーネルLinux 4.19バージョン以上）</li><li>Red Hat Enterprise Linux Server 7.Xバージョン、8.Xバージョン（カーネルLinux 4.19バージョン以上）</li><li>CentOS Linux 7.Xバージョン、8.Xバージョン（カーネルLinux 4.19バージョン以上）</li><li>Rocky Linux 9（カーネルLinux 5.14）</li><li>Debian 9.Xバージョン以上（カーネルLinux 4.19バージョン以上）</li><li>Ubuntu 16.Xバージョン以上（カーネルLinux 4.19バージョン以上）</li><li>SUSE / openSUSE 15.Xバージョン以上（カーネルLinux 4.19バージョン以上） </li><li>KylinOS V10バージョン</li><li>統信UOS V20バージョン</li><li>中科方德NFSChina 4.0バージョン以上</li><li>浪潮Inspur kos 5.8バージョン</li></ul>|

| NIC     | ギガビット以上の接続速度                                                                                                           |

その他のソフトウェアおよびハードウェアプラットフォームへの対応も現在テスト中です。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>OceanBaseクラスタをデプロイする場合は、クラスタ内のすべてのマシンの構成が同一であることを確認してください。ここで示されているパフォーマンステスト環境と本番環境のリソース要件はあくまでも推奨値です。Community Editionの今後のバージョンでは、メモリ要件をさらに引き下げる予定です。</p>
</main>

Red Hat Enterprise Linux（RHEL）9以前のバージョンでは、以下のコマンドを実行して、手動でTransparent Huge Pagesを無効にする必要があります。

```bash
echo never > /sys/kernel/mm/redhat_transparent_hugepage/enabled
```

Red Hat Enterprise Linux（RHEL）9またはCentOSでは、以下のコマンドを実行して、手動でTransparent Huge Pagesを無効にする必要があります。

```bash
echo never > /sys/kernel/mm/transparent_hugepage/enabled
```
