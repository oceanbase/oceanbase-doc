# ソフトウェアおよびハードウェア要件

OceanBase データベースは分散型クラスタープロダクトであり、本番環境では少なくとも 3 台のマシンが必要です。学習環境ではスタンドアロン版をデプロイできます。OceanBase データベースのデプロイは、従来のデータベースのデプロイと多くの共通点があり、オペレーティングシステム、ハードウェア、ソフトウェアの設定などに関して、いくつかのベストプラクティスを提案します。これらは、OceanBase データベースが高性能かつ安定して動作するための基盤となります。

## ソフトウェアリソースの紹介

下表では、異なる OS バージョンに対応するインストールパッケージが示されています。

|                       オペレーティングシステム                        |                                            インストールパッケージのダウンロード URL                                             |
|---------------------------------------------------|------------------------------------------------------------------------------------------------|
| Alibaba Cloud Linux 2、CentOS 7、RedHat 7、Ubuntu 16.X、Debian 9.X | [el7 ダウンロード URL](https://mirrors.aliyun.com/oceanbase/community/stable/el/7/x86_64/) |
| Alibaba Cloud Linux 3、CentOS 8、RedHat 8、Debian 10、Anolis OS 8.X             | [el8 ダウンロード URL](https://mirrors.aliyun.com/oceanbase/community/stable/el/8/x86_64/) |

OceanBase データベースは、以下の構成でシステムテスト検証を実施しており、以下のハードウェアおよびソフトウェア構成を使用することが推奨されます：

|   項目   |                                                          説明                                                          |
|----------|-----------------------------------------------------------------------------------------------------------------------|
|システム|<ul><li>Anolis OS 8.X バージョン (カーネル Linux 3.10.0 以上)</li><li>Alibaba Cloud Linux 2/3 バージョン (カーネル Linux 3.10.0 以上)</li><li>Red Hat Enterprise Linux Server 7.X バージョン、8.X バージョン (カーネル Linux 3.10.0 以上)</li><li>CentOS Linux 7.X バージョン、8.X バージョン (カーネル Linux 3.10.0 以上)</li><li>Debian 9.X バージョン以上 (カーネル Linux 3.10.0 以上)</li><li>Ubuntu 16.X バージョン以上 (カーネル Linux 3.10.0 以上)</li><li>SUSE/OpenSUSE 15.X バージョン以上 (カーネル Linux 3.10.0 以上)</li><li>KylinOS V10</li><li>統信 UOS V20</li><li>中科方德 NFSChina 4.0 以上</li><li>浪潮 Inspur kos 5.8 バージョン</li></ul>|
| 物理 CPU    |<ul><li> テスト環境の最低要件は 2 コアです。 </li> <li>本番環境は、最低 4 コア、推奨は 32 コア以上です。</li><li>性能テストは 24 コア以上を推奨します。</li> </ul>                    |

より多くのソフトウェアおよびハードウェアプラットフォームへの対応がテスト中です。

<main id="notice" type='explain'>

  <p>OceanBase クラスターをデプロイする場合は、クラスター内のすべてのマシンの構成が同一であることを確認してください。ここで、性能テスト環境と本番環境のリソース要件は推奨事項です。Community Edition の今後のバージョンでは、メモリ要件がさらに低減します。</p>
</main>

Red Hat オペレーティングシステム RHEL 9 より前のバージョンでは、以下のコマンドを実行して、透過的巨大ページ (THP) を手動でオフにする必要があります：

```bash
echo never > /sys/kernel/mm/redhat_transparent_hugepage/enabled
```

Red Hat オペレーティングシステム RHEL 9 または CentOS の場合、以下のコマンドを実行して、透過的巨大ページ (THP) を手動でオフにする必要があります：

```bash
echo never > /sys/kernel/mm/transparent_hugepage/enabled
```
