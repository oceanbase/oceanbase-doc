# OceanBaseデータベースCommunity Editionデプロイ概要

OceanBaseデータベースCommunity Editionは、複数のデプロイ方法をサポートしています：

* スタンドアロン版のOceanBaseを迅速にデプロイして機能を体験したい場合は、クイックデプロイのセクションを参照してください。

* 本番環境で標準的なデプロイを行いたい場合は、標準デプロイのセクションを参照してください。

* オンラインで体験したい場合は、オンライン体験のセクションを参照してください。

## クイックデプロイ

クイックデプロイ操作は、マシンが1台しかない場合に、利用可能なOceanBaseデータベース環境を迅速に構築するのに適しています。デプロイされるOceanBaseデータベース環境はデータベースの基本機能を備えており、OceanBaseデータベースを理解するのに役立ちます。ただし、この環境には分散機能や高可用性の特性はなく、長期間の使用は推奨されません。

* ネイティブでサポートされていないOS（例：MACやWindows）の場合は、Dockerイメージを使用したデプロイを推奨します。具体的な操作については、[OceanBaseデータベースコンテナ環境のデプロイ](200.local-deployment/700.deploy-by-docker.md)を参照してください。

* ネイティブでサポートされているOS（Linux系、詳細はサポートOS一覧を参照）の場合は、obdを使用したデプロイを推奨します。具体的な操作については、公式サイトの「OceanBaseインストール・デプロイツール」ドキュメント[クイックスタート / OceanBaseデータベースのクイックデプロイ](https://en.oceanbase.com/docs/community-obd-en-10000000001736379)を参照してください。

## 標準デプロイ

標準デプロイは、OceanBase分散データベースのアーキテクチャ原理や機能特性を深く理解したいユーザーに適しています。デプロイされるOceanBaseクラスタは、データベースの完全な機能と分散型の高可用性を備えています。少なくとも3台のホストを準備する必要があり、各ホストは4vCPU、16GBメモリ、100GB SSD以上の高性能ディスクを搭載している必要があります。

* （推奨）OceanBaseクラスタのグラフィカル管理

  複数のOceanBaseクラスタをデプロイする場合は、OCP（OceanBaseクラウドプラットフォーム）のデプロイを推奨します。OCPはOceanBaseデータベースの運用管理を効率化し、運用手間を大幅に削減できます。

  まず、3台のマシンを使用してOCPおよびそのMetaDBをデプロイする必要があります。具体的な操作については、公式サイトの「OceanBaseインストール・デプロイツール」ドキュメント[使用ガイド / グラフィカルインターフェース / グラフィカルインターフェースによるOCPのデプロイ](https://en.oceanbase.com/docs/community-obd-en-10000000001736379)を参照してください。OCPのデプロイに成功したら、OCPを通じて新しいOceanBaseクラスタを作成し、ビジネスに活用できます。具体的な操作については、公式サイトの「OceanBaseクラウドプラットフォーム」ドキュメント[クラスタ管理](https://en.oceanbase.com/docs/common-ocp-10000000002854225)の章を参照してください。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>MetaDBはOCPのメタデータベースとしてのみ使用されます。業務クラスタとしては使用しないでください。</p>
  </main>

* コマンドラインによるOceanBaseクラスタの管理

  一時的に1つのOceanBaseクラスタのみをデプロイする予定であれば、obdを使用してOceanBaseクラスタをデプロイし、その後obdコマンドを使用してOceanBaseクラスタを管理できます。具体的なデプロイ操作については、公式サイトの「OceanBaseデータベース」ドキュメント[obdグラフィカルインターフェースによるOceanBaseクラスタのデプロイ](200.local-deployment/400.deploy-by-ui/100.deploy-by-obd.md)を参照してください。obdコマンドの紹介については、公式サイトの「OceanBaseインストール・デプロイツール」ドキュメント[obdコマンド / クラスタコマンドグループ](https://en.oceanbase.com/docs/community-obd-en-10000000003080847)を参照してください。

* Kubernetes環境でのOceanBaseクラスタのデプロイ

  この方法は、本番環境でKubernetesが既に大規模に導入されており、OceanBaseデータベースについて一定の理解と経験を持つユーザーに適しています。デプロイされるOceanBaseクラスタは、データベースの完全な機能と分散型の高可用性を備えています。

  開始前に、以下の条件を満たしていることを確認してください：

  * 利用可能なKubernetesクラスタがあり、少なくとも9個の利用可能なCPU、33GBの利用可能なメモリ、360GBの利用可能なストレージ空き容量があること。

  * ob-operatorはcert-managerに依存しているため、cert-managerがインストール済みであることを確認してください。cert-managerのインストール方法については、対応する[インストールドキュメント](https://cert-manager.io/docs/installation/)を参照してください。

  OceanBaseクラスタの具体的なデプロイ手順については、公式ドキュメント「OceanBaseデータベース」の[Kubernetes環境でOceanBaseクラスタをデプロイする](300.deploy-in-the-k8s-cluster.md)を参照してください。

## オンライン体験

オンラインで体験したい方は、[OceanBase体験サイト](https://www.oceanbase.com/demo/deploy-a-oceanbase-ce-single-node-cluster)にログインして機能を試すことができます。
