# OceanBase データベース Community Edition デプロイ概要

OceanBase データベース Community Edition は、複数のデプロイ方法をサポートしています。

* スタンドアロン版 OceanBase を迅速にデプロイして機能を試したい場合は、クイックデプロイセクションを参照することができます。

* 本番環境で標準化されたデプロイを行うには、標準デプロイセクションを参照することができます。

* オンライン体験をご希望の場合は、オンライン体験の部分を参考にすることができます。

## クイックデプロイ

* ネイティブサポートされていない OS (macOS、Windows など) の場合、Docker イメージを使用したデプロイが推奨されます。具体的な手順については、[OceanBase データベースコンテナ環境のデプロイ](200.local-deployment/700.deploy-by-docker.md) を参照してください。

* ネイティブサポート OS (Linux 系、詳細はサポート OS 一覧を参照) の場合、obd を使用したデプロイが推奨されます。具体的な手順は、公式 Web サイトの「OceanBase インストールデプロイツール」ドキュメント [クイックスタート / OceanBase データベースのクイックデプロイ](https://en.oceanbase.com/docs/community-obd-en-10000000002136403) を参照してください。

## 標準デプロイ

* オンライン環境では、obd を使用した標準的なデプロイが推奨されます。具体的な手順については、[obd のグラフィカルユーザーインターフェースを使用した OceanBase クラスターのデプロイ](200.local-deployment/400.deploy-by-ui/100.deploy-by-obd.md) を参照してください。

* Kubernetes 環境では、ob-operator を使用したデプロイが推奨されます。具体的な手順については、[Kubernetes クラスターへの OceanBase データベースのデプロイ](../500.deploy-oceanbase-database-community-edition/300.deploy-in-the-k8s-cluster.md) を参照してください。
