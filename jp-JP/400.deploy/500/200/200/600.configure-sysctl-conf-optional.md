# (オプション) sysctl.conf の設定

本記事では、マシンの `sysctl.conf` の設定を変更することで Linux システムのパフォーマンスを向上させる方法について説明します。

個人ユーザーの方は、この手順をスキップできます。企業ユーザーの方は、`sysctl.conf` の設定を行うことを推奨します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>各マシンでこの操作を個別に実行する必要があります。</p>
</main>

## 設定の変更

以下のコマンドを実行して、`/etc/sysctl.conf` 設定ファイルを開きます：

```shell
sudo vim /etc/sysctl.conf
```

`/etc/sysctl.conf` 設定ファイルに以下の内容を追加します：

```shell
# for oceanbase
## カーネル非同期 I/O 制限の変更
fs.aio-max-nr = 1048576

## ネットワーク最適化
net.core.somaxconn = 2048
net.core.netdev_max_backlog = 10000
net.core.rmem_default = 16777216
net.core.wmem_default = 16777216
net.core.rmem_max = 16777216
net.core.wmem_max = 16777216

net.ipv4.ip_forward = 0
net.ipv4.conf.default.rp_filter = 1
net.ipv4.conf.default.accept_source_route = 0
net.ipv4.tcp_syncookies = 1
net.ipv4.tcp_rmem = 4096 87380 16777216
net.ipv4.tcp_wmem = 4096 65536 16777216
net.ipv4.tcp_max_syn_backlog = 16384
net.ipv4.tcp_fin_timeout = 15
net.ipv4.tcp_slow_start_after_idle = 0

vm.swappiness = 0
vm.min_free_kbytes = 2097152
vm.overcommit_memory = 0

fs.file-max = 6573688
fs.pipe-user-pages-soft = 0

# プロセスの仮想メモリ領域数の変更
vm.max_map_count = 655360

# ここは OceanBase データベースの data ディレクトリです。
kernel.core_pattern = /data/core-%e-%p-%t
```

このうち、`kernel.core_pattern` の `/data` は OceanBase データベースの `data` ディレクトリです。

<main id="notice" type='notice'>
   <h4>注意</h4>
   <p><code>max_map_count</code> の設定が適切でない場合、深刻なメモリリークが発生する可能性があります。 </p>
</main>

## 設定の読み込み

設定変更後、以下のコマンドを実行して設定をロードし、有効にします。

```shell
sysctl -p
```

## ARM 環境デプロイ推奨事項

* bios/uefi およびカーネルブートパラメーターで NUMA サポートを有効にします。

* NUMA Balancing を無効化し、バランシング処理中のパフォーマンス変動を避けるため、以下のコマンドを実行します。

  ```shell
  sysctl kernel.numa_balancing=0
  ```

* メモリの回収と再割り当て機能を無効にするには、以下のコマンドを実行します。

  ```shell
  sysctl vm.zone_reclaim_mode=0
  ```
