# (オプション) リソースの確認

分散型 OceanBase クラスターのデプロイを計画されている場合、OceanBase クラスターをデプロイする際には、すべてのマシンで同一のハードウェア・ソフトウェア構成を使用することを推奨します。詳細については、[ソフトウェアとハードウェアの要件](../100.requirements-for-software-and-hardware.md) を参照してください。

OceanBase データベースをスタンドアロンデプロイする場合は、この手順をスキップできます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>本記事で説明する設定ファイルは、obd を使用して OceanBase データベースをデプロイする際に設定が必要なファイルです。詳細な設定ファイルの情報については、<a href="https://github.com/oceanbase/obdeploy/tree/master/example">設定ファイル例</a>を参照してください。</p>
</main>

## オペレーティングシステムの確認

### Red Hat Enterprise Linux Server 7.X

以下のコマンドを実行して、オペレーティングシステムの情報を確認します：

```shell
cat /etc/redhat-release
```

結果は次の通りとなります：

```shell
Red Hat Enterprise Linux Server release 7.2 (Maipo)
```

### CentOS 7.X

以下のコマンドを実行して、オペレーティングシステムの情報を確認します：

```shell

```

```shell

```

## カーネルの確認

以下のコマンドを実行して、カーネル情報を確認します：

```shell
uname -r
```

OceanBase データベースは、オペレーティングシステムとして 3.10.0 およびそれ以降を必要とします。

## メモリの確認

以下のコマンドを実行して、メモリの状況を確認します：

```shell
free -g
```

利用可能なメモリが設定ファイルの `memory_limit` 値より小さい場合は、キャッシュメモリをクリアするか、設定ファイルの `memory_limit` 値を利用可能なメモリより小さい値に変更してください。

以下のコマンドを実行して、キャッシュメモリをクリアします：

```shell
sudo sysctl -w vm.drop_caches=3
# または
sudo echo 3 > /proc/sys/vm/drop_caches
```

## ディスクの確認

以下のコマンドを実行して、ディスクを確認します：

```shell
df -h
```

設定ファイル内の `data_dir`、`redo_dir`、`home_path` に対応するディスクがマウントされていることを確認します。`data_dir` および `redo_dir` に対応するディレクトリは空であり、`data_dir` に対応するディレクトリのディスク使用率は 4% 未満である必要があります。

## NIC 名を確認する

設定ファイルの `devname` 設定項目に NIC を指定する必要があります。サンプル設定ファイルは以下のとおりとなります：

```shell
# Please set devname as the network adaptor's name whose ip is  in the setting of severs.
# if set severs as "127.0.0.1", please set devname as "lo"
# if current ip is 192.168.1.10, and the ip's network adaptor's name is "eth0", please use "eth0"
devname: eth0
```

以下のコマンドを実行して、NIC 名を確認します：

```shell
ifconfig
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>ifconfig</code> コマンドを実行するには、事前に <code>net-tools</code> パッケージをインストールする必要があります。</p>
</main>
