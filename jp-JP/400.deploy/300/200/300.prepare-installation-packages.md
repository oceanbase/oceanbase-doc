# インストールパッケージの準備

デプロイの前に、各プロダクトで使用するイメージとインストールパッケージを取得していることを確認してください。以降のインストールおよびデプロイメントで使用します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><a href="https://en.oceanbase.com/softwarecenter">OceanBase ソフトウェアダウンロードセンター</a>から OceanBase データベースおよび関連ツール、ドライバー、ミドルウェアのインストールパッケージをダウンロードしてください。対応するバージョンのインストールパッケージが見つからない場合は、テクニカルサポートにお問い合わせください。</p>
</main>

**OceanBase クラスターのデプロイに使用されるイメージとインストールパッケージは以下の表のとおりです：**

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>コマンドラインを使用して OceanBase クラスターをデプロイする場合は、OceanBase クラウドプラットフォーム関連のイメージ / インストールパッケージを準備する必要はありません。</p>
</main>
