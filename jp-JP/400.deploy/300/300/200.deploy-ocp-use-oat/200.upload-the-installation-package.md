# インストールパッケージのアップロード

OAT 上に OceanBase プロダクトをインストールしたり、コンポーネントを作成したりするには、各プロダクトのインストールパッケージ (イメージ) を OAT サーバーにアップロードするか、リモートでイメージに接続する必要があります。そのため、OAT を使用して OCP をデプロイする前に、まず OCP のインストールに必要なパッケージを、OAT がインストールされているサーバーにアップロードする必要があります。

本記事では、OCP に必要なインストールパッケージを OAT サーバーにアップロードする方法について説明します。

## 操作手順

### 手順 1：OCP インストールパッケージの OAT サーバーへのアップロード

OAT をインストールしてから、インストールパッケージを `/oat/data_dir/images` ディレクトリにアップロードする必要があります。

OCP のデプロイメントでは、OAT をインストールしたサーバーに、OCP docker イメージと MetaDB docker イメージの 2 つのイメージをアップロードする必要があります。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>oat-all-in-one インストールパッケージを使用して OAT をインストールした場合は、OCP docker イメージのみをアップロードする必要があります。</p>
</main>

例：

```shell
[root@hostname /]# scp ./ocp.tar <oat_server>:/oat/data_dir/images/ocp.tar
[root@hostname /]# scp ./meta_xxx.tar <oat_server>:/oat/data_dir/images/meta_xxx.tar
```

ここで `oat_server` は、OAT がデプロイされているサーバーの IP アドレスを表します。

### 手順 2：OAT サービスへのインストールパッケージの追加

1. OAT にログインします。

2. 左側のナビゲーションバーで、**システムとセキュリティ \> パッケージ** をクリックして **パッケージ管理** ページに移動し、右上の **イメージの追加** をクリックして、**ローカルスキャン** を選択します。
