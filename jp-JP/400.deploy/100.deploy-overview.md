# デプロイの概要

OceanBase データベースでは Enterprise Edition と Community Edition の 2 つのバージョンが用意されています。

* OceanBase データベース Enterprise Edition：完全自社開発のエンタープライズレベルのスタンドアロンと分散型の統合化データベースで、一般的なハードウェア上で金融業界レベルの高可用性を実現します。これまでにない「3 リージョン 5 センター」という障害による損失が発生しない自動ディザスタリカバリの新基準を確立し、TPC-C 標準テストにおいて新記録を達成しました。単一クラスターの規模は 1500 ノードを超え、クラウドネイティブ、強固な一貫性の実現、Oracle/MySQL との高い互換性などの機能を備えています。

* OceanBase データベース Community Edition：完全自社開発の MySQL と互換性を持つスタンドアロンと分散型の統合化データベースで、ネイティブ分散アーキテクチャを備えます。金融業界レベルの高可用性、透過的なスケールアウト、分散トランザクション、マルチテナント、および構文の互換性などエンタープライズレベルの機能がサポートされています。OceanBase Community Edition のデータベースカーネルはオープンソースです。オープンインターフェースと豊富なエコシステム機能を提供することで、企業や個人がカスタマイズされたビジネスニーズをより適切に実現できるようサポートします。

本マニュアルでは、主に OceanBase の Enterprise Edition と Community Edition をデプロイする方法と適用シナリオについて説明します。

## デプロイの方法

**OceanBase Enterprise Edition：**

* OCP を使用した OceanBase クラスターのデプロイ
* obd を使用した OceanBase クラスターのデプロイ
* コマンドラインを使用した OceanBase クラスターのデプロイ

**OceanBase Community Edition：**

* obd を使用した OceanBase クラスターのデプロイ
* OCP を使用した OceanBase クラスターのデプロイ
* Docker イメージを使用した OceanBase クラスターのデプロイ
* Kubernetes 環境下で ob-operator を使用した OceanBase クラスターのデプロイ

## 適用シナリオ

**OceanBase Enterprise Edition：**

* 本番環境では、OCP を使用した OceanBase クラスターのデプロイを推奨します。具体的な操作手順については、[OCP を使用した 3 レプリカ OceanBase クラスターのデプロイ](300.deploy-oceanbase-enterprise-edition/300.deploy-through-a-graphical-interface/300.deploy-oceanbase-cluster-use-ocp/500.deploy-three-oceanbase-replica-clusters-use-ocp.md) を参照してください。

* 本番環境以外では、コマンドラインを使用した OceanBase クラスターのデプロイができます。具体的な操作手順については、[コマンドラインを使用した 3 レプリカ OceanBase クラスターのデプロイ](300.deploy-oceanbase-enterprise-edition/400.deploy-through-the-command-line/200.deploy-the-oceanbase-cluster-command-line/400.deploy-three-oceanbase-replica-clusters.md) を参照してください。

**OceanBase Community Edition：**

* ネイティブ対応ではない OS (例：macOS、Windows) のクイックスタートシナリオでは、Docker イメージを使用したデプロイを推奨します。具体的な操作手順は、[OceanBase データベースコンテナ環境のデプロイ](500.deploy-oceanbase-database-community-edition/200.local-deployment/700.deploy-by-docker.md) を参照してください。

* ネイティブ対応の OS (Linux 系の場合、詳細はサポート対象 OS 一覧を参照) のクイックスタートシナリオでは、obd を使用したデプロイを推奨します。具体的な操作手順は、公式 Web サイトの「OceanBase インストール・デプロイツール」ドキュメントの [クイックスタート / OceanBase データベースのクイックデプロイ](https://www.oceanbase.com/docs/community-obd-cn-1000000001882000) を参照してください。

* オンライン環境では、obd を使用した標準的なデプロイを推奨します。具体的な操作手順は、[obd グラフィカルインターフェースを使用した OceanBase クラスターのデプロイ](500.deploy-oceanbase-database-community-edition/200.local-deployment/400.deploy-by-ui/100.deploy-by-obd.md) を参照してください。

* Kubernetes 環境では、ob-operator を使用したデプロイを推奨します。具体的な操作手順は、[Kubernetes クラスターへの OceanBase データベースのデプロイ](500.deploy-oceanbase-database-community-edition/300.deploy-in-the-k8s-cluster.md) を参照してください。
