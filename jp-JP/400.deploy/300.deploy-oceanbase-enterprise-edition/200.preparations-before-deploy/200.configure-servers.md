## OceanBaseサーバーのBIOS設定

### 特別な設定

* Intel x86アーキテクチャ環境において：

  * 設定ファイル`/etc/sysctl.conf`を変更し、パラメータ`vm.swappiness`を`0`に設定することを推奨します。方法は以下のとおりです：

    ```bash
    [root@xxx /]
    $vi /etc/sysctl.conf
    vm.swappiness = 0
    ```

    sysctl.conf設定ファイル内の値を適用します：

    ```bash
    [root@xxx /]
    $sysctl -p
    ```

* AMDまたはARMアーキテクチャ環境では、Numaを有効にすることを推奨します。

* ARMおよび海光アーキテクチャ環境では、設定ファイル`/etc/sysctl.conf`を変更し、パラメータ`kernel.numa_balancing`、`vm.zone_reclaim_mode`、`vm.swappiness`を`0`に設定することを推奨します。方法は以下のとおりです：

  ```bash
  [root@xxx /]
  $vi /etc/sysctl.conf
  kernel.numa_balancing = 0
  vm.zone_reclaim_mode = 0
  vm.swappiness = 0
  ```

  sysctl.conf設定ファイル内の値を適用します：

  ```bash
  [root@xxx /]
  $sysctl -p
  ```

### BIOSで次のオプションを無効にする必要があります

* Cstate

* Pstate

* EIST

* Power saving

* SMMU（ARMアーキテクチャ）

### BIOSで次のオプションを有効にする必要があります

* Automatic Power on After Power Loss: Always on

* Intel Virtualization Technology：有効

* Hyper-threading：有効

* Hardware prefetcher：有効

* VT-d：有効

* SR-IOV：有効

* Turbo Mode：有効

* Energy performance：最大パフォーマンスを有効にする

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>サーバーによってBIOSの変更方法は異なります。具体的な操作については、サーバーの取扱説明書を参照してください。</p>
  </main>

## NIC設定

2枚の10ギガビットNICを設定することを推奨します：

* ボンディングモードはbond0と命名し、結合モードはmode1またはmode4から選択できますが、mode4を推奨します。mode4モードでは、スイッチに802.3adプロトコルを設定する必要があります。
* NIC名はeth0、eth1を使用することを推奨します。

## SSDのI/Oスケジューラーに関する推奨事項

* NVMe SSDのデフォルトのI/Oスケジューラーは`none`であり、調整する必要はありません。
* SATA SSDのI/Oスケジューラーは`none`に設定することを推奨します。

## 注意事項

OceanBaseデータベースでは、V4.2.5 BP3、V4.2.5 BP4、V4.2.5 BP5、V4.3.5 BP1、V4.3.5 BP2、V4.3.5 BP3バージョンから、X86アーキテクチャ環境での実行に対する命令セット要件が追加されました。OBServerプロセスは起動前に現在の環境がAVX命令セットをサポートしているかどうかを確認し、その命令セットが欠けている場合は起動を禁止します。
