# OCPデプロイメントの説明

OCP製品はDocker形態で動作し、サーバー構成とLinuxオペレーティングシステムの要件はOceanBaseデータベースサーバーと同じです。

## 説明

OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、略称：OCP）は、OceanBaseデータベースと共に生まれた、OceanBaseデータベースを核とするエンタープライズ向けデータベース管理プラットフォームです。OCPを使用することで、OceanBaseデータベースクラスタのワンクリックでのインストール、アップグレード、拡張、アンインストール、運用保守タスクの作成と管理、クラスタの稼働状態の監視、およびアラートの確認が可能です。

OCPは現在、OceanBaseデータベースのすべての主要バージョンをサポートしており、OceanBaseクラスタやテナントなどのコンポーネントに対するライフサイクル全体の管理サービスを提供するだけでなく、OceanBaseデータベース関連のリソース（ホスト、ネットワーク、ソフトウェアパッケージなど）の管理サービスも提供します。これにより、OceanBaseクラスタをより効率的に管理し、企業のIT運用コストを削減できます。

現在、OCPは単一ノードデプロイメントと高可用性デプロイメントの2種類のデプロイメントモードをサポートしています。

## 単一ノードデプロイメント

単一ノードデプロイメントとは、OCPのすべての機能を単一ノードにデプロイし、そのノードがOCPの全機能を提供する方式です。これには以下が含まれます：OCP管理サービス（OCP-Server）、メタ情報データベース（MetaDB）、監視データベース（MonitorDB）、OBProxy。

単一ノードデプロイメントには以下の利点があります：

リソースの節約：すべてのサービスが同一ホストにデプロイされるため、ホストリソースを最大限に節約できます。

デバッグが容易：すべてのリクエストが同一ホストで処理されるため、分散処理の問題がなく、ログの検索が容易です。

依存関係が少ない：ロードバランシングサービスに依存しません。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>単一ノードデプロイメントは、可用性の要求が高くない場合や、迅速な検証が必要なシナリオで一般的です。</p>
  </main>

## 高可用性デプロイメント

高可用性デプロイメントは、マルチクラスタモードとマルチアベイラビリティゾーンモードに分けられます。マルチクラスタモードとは、地理的に離れた複数のクラスタをデプロイする方式で、異なる都市に配置されたOceanBaseのプライマリ/スタンバイデータベースの管理を提供し、複数のOCPクラスタにまたがるOceanBaseのプライマリ/スタンバイデータベースの作成、削除、アップグレード、日常的な切り替え、災害復旧時の切り替えなどの運用をサポートし、二つのデータセンターによる高可用性・災害復旧アーキテクチャを実現します。

高可用性デプロイメントでは、少数のホストまたはホスト上のサービスが利用不能になっても、システム全体は引き続き利用可能です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>高可用性デプロイメントは、本番環境など、システムの可用性に対する要求が高い場合に一般的です。</p>
  </main>
