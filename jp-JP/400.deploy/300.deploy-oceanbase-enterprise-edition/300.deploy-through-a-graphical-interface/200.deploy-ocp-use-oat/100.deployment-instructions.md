# OCPデプロイの説明

OCP製品はDocker形態で動作し、サーバー構成とLinuxオペレーティングシステムの要件はOceanBaseデータベースサーバーと同じです。

## 説明

OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、略称：OCP）は、OceanBaseデータベースと共に生まれた、OceanBaseデータベースを核とするエンタープライズ向けデータベース管理プラットフォームです。OCPを使用することで、OceanBaseデータベースクラスタのワンクリックでのインストール、アップグレード、拡張、アンインストール、運用保守タスクの作成と管理、クラスタの稼働状態監視、およびアラートの確認が可能です。

OCPは現在、OceanBaseデータベースのすべての主要バージョンをサポートしており、OceanBaseクラスタやテナントなどのコンポーネントに対するライフサイクル全体の管理サービスを提供するだけでなく、OceanBaseデータベース関連のリソース（ホスト、ネットワーク、ソフトウェアパッケージなど）の管理サービスも提供します。これにより、OceanBaseクラスタをより効率的に管理し、企業のIT運用コストを削減できます。

現在、OCPは単一ノードデプロイと高可用性デプロイの2種類のデプロイモードをサポートしています。

## 単一ノードデプロイ

単一ノードデプロイとは、OCPのすべての機能を単一ノードにデプロイし、そのノードがOCPの全機能を提供する方式です。これには以下が含まれます：OCP管理サービス（OCP-Server）、メタ情報データベース（MetaDB）、監視データベース（MonitorDB）、OBProxy。

単一ノードデプロイには以下の利点があります：

リソースの節約：すべてのサービスが同一ホストにデプロイされるため、ホストリソースを最大限に節約できます。

デバッグが容易：すべてのリクエストが同一ホストで処理されるため、分散処理の問題がなく、ログの検索が容易です。

依存関係が少ない：ロードバランシングサービスに依存しません。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>単一ノードデプロイは通常、可用性の要求が高くない場合や、迅速な検証が必要なシナリオで利用されます。</p>
  </main>

## 高可用性デプロイ

高可用性デプロイは、マルチクラスタモードとマルチアベイラビリティゾーンモードに分けられます。マルチクラスタモードとは、地理的に離れたマルチクラスタをデプロイする方式で、クロスリージョンOceanBaseのプライマリ/スタンバイデータベースの管理により、OCPクラスタ間のOceanBaseのプライマリ/スタンバイデータベースの作成、削除、アップグレード、日常的な切り替え、ディザスタリカバリ時の切り替えなどの運用をサポートし、デュアルデータセンターによる高可用性・ディザスタリカバリアーキテクチャを実現します。

高可用性デプロイでは、少数のホストまたはホスト上のサービスが利用不能になっても、システム全体は引き続き利用可能です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>高可用性デプロイは通常、本番環境など、システムの可用性に対する要求が高い場合に利用されます。</p>
  </main>
