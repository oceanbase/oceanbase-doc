# OCPデプロイの説明

OCP製品はDocker形式で動作し、サーバー構成およびLinuxオペレーティングシステムに関する要件はOceanBaseデータベースサーバーと同じです。

## 説明

OceanBaseクラウドプラットフォーム(OceanBase Cloud Platform、略称：OCP)は、OceanBaseデータベースと共に誕生した、OceanBaseデータベースを核とするエンタープライズ向けデータベース管理プラットフォームです。OCPを使用することで、OceanBaseデータベースクラスタのワンクリックインストール、アップグレード、スケールアップ、アンインストール、運用保守タスクの作成・管理、クラスタの稼働状態の監視、およびアラートの確認が可能になります。

OCPは現在、OceanBaseデータベースのすべての主要バージョンをサポートしており、OceanBaseクラスタやテナントなどのコンポーネントに対するライフサイクル全体の管理サービスを提供するだけでなく、OceanBaseデータベース関連のリソース(ホスト、ネットワーク、ソフトウェアパッケージなど)に対する管理サービスも提供しています。これにより、OceanBaseクラスタをより効率的に管理し、企業のIT運用保守コストを削減できます。

現在、OCPは単一ノードデプロイと高可用性デプロイの2種類のデプロイモードをサポートしています。

## 単一ノードデプロイ

単一ノードデプロイとは、OCPのすべての機能を同一ノード上にデプロイし、そのノードがOCPの全機能を提供する方式を指します。これには、OCP管理サービス(OCP-Server)、メタ情報データベース(MetaDB)、モニタリングデータベース(MonitorDB)、OBProxyが含まれます。

単一ノードデプロイの利点は以下の通りです：

リソースの節約、すべてのサービスが同一ホスト上にデプロイされるため、ホストリソースを最大限に節約できます。

デバッグが容易、すべてのリクエストが同一ホストで処理されるため、分散処理の問題がなく、ログ検索が容易です。

依存関係が少ない、ロードバランシングサービスに依存する必要がありません。

    <h4>説明</h4>
    <p>単一ノードデプロイは、可用性要件が低い場合や迅速な検証が必要なシナリオでよく見られます。</p>
  </main>

## 高可用性デプロイ

高可用性デプロイは、マルチクラスタモードとマルチアベイラビリティゾーンモードに分かれます。マルチクラスタモードとは、異なる地域に複数のクラスタをデプロイする方式であり、都市間のOceanBaseプライマリ/スタンバイデータベースの管理を提供します。また、OCPクラスタ間でのOceanBaseプライマリ/スタンバイデータベースの運用保守をサポートしており、OceanBaseプライマリ/スタンバイデータベースの作成、削除、アップグレード、日常的な切り替え、災害復旧時の切り替えなどを実現し、二重データセンターによる高可用性・災害復旧アーキテクチャを構築します。

高可用性デプロイの場合、少数のホストまたはその上のサービスが利用不可能になっても、システム全体は依然として利用可能です。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>高可用性デプロイは、本番環境で一般的であり、システムの可用性要件が高い場合によく見られます。</p>
  </main>
