# OCPのデプロイ

本記事では、OATを使用してOCPをインストールする方法について説明します。

<main id="notice" type='explain'>
   <h4>説明</h4>
   <p>このセクションでは、OAT V4.2.0を例に操作手順を説明します。OATのバージョンによって操作画面が異なる場合があります。実際の画面をご確認ください。</p>
</main>

## 前提条件

OCPをインストールする前に、以下の事項を確認してください。

* OATがインストール済みであること。詳細については、[OATのデプロイ](../../200.preparations-before-deploy/400.deploy-oat.md)を参照してください。
* スーパーユーザーまたは運用保守担当者権限を持つアカウントでOATにログインしていること。アカウントの詳細については、[ユーザー管理](https://www.oceanbase.com/docs/enterprise-oat-doc-cn-10000000002024815)を参照してください。
* OCPをインストールするサーバーの準備が整い、OATに追加されていること。詳細については、[サーバーの準備](../../200.preparations-before-deploy/100.prepare-servers.md)および[サーバーの追加](../100.configuring-the-deploy-environment-through-oat/100.add-server.md)を参照してください。
* OCPのメタデータベースMetaDBコンポーネントが作成済みであること。詳細については、[MetaDBの作成](../200.deploy-ocp-use-oat/300.create-metadb.md)を参照してください。
* OCPインストールパッケージがOATのサーバーに追加されていること。詳細については、[インストールパッケージのアップロード](../200.deploy-ocp-use-oat/200.upload-the-installation-package.md)を参照してください。
* ネットワーク環境がOCPの正常な稼働に必要なネットワークポート設定要件（ネットワークアクセス権限）を提供していること。管理者は、実際の環境におけるOCPコンポーネントのデプロイ計画に基づき、ネットワーク側およびホスト側で関連ポートを開放することができます。具体的な紹介情報については、[コンポーネントリスニングポート一覧](https://www.oceanbase.com/docs/common-ocp-1000000003339267)を参照してください。

## 手順

1. 左側のナビゲーションバーで、**プロダクトサービス \> プロダクト** をクリックして **<UI-TERM key="oat.ProductDeploy.Product.ProductManagement">プロダクトマネジメント</UI-TERM>** ページに移動し、右上の **<UI-TERM key="oat.components.CardStepGuide.InstallTheProduct">製品のインストール</UI-TERM>** をクリックして、**<UI-TERM key="oat.Product.ProductManage.InstallOcp">OCPのインストール</UI-TERM>** を選択します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/3%E5%AE%89%E8%A3%85ocp-0.png) -->

2. **<UI-TERM key="oat.Product.ProductManage.InstallOcp">OCPのインストール</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.BasicConfiguration">基本構成</UI-TERM>** を完了します。

   | パラメータ | 説明 |
   |------|------|
   | OCPイメージ | OCPのDockerイメージ。 |
   | プロダクト名 | プロダクト名。他のプロダクトと重複してはなりません。 |
   | 管理者パスワード | OCP管理者パスワード。パスワード形式要件は以下のとおりです：<ul><li>長さが8～32文字です。</li><li>次の4種類の文字のうち、少なくとも3種類以上を含みます：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字 <code>\~!@#%\^\&\*_-+=\`\|(){}\[\]:;',.?/</code>。</li></ul>|
   | マルチゾーンモード | マルチゾーンインストールを有効にする場合、以下のパラメータがあります：<ul><li>ゾーン名：ゾーン名。</li><li> サーバー：OCPをインストールするサーバーのIPアドレス。</li><li>OCPプロキシIP：このゾーンへのOCPアクセスエントリIP。</li><li>OCPプロキシポート：このゾーンへのOCPアクセスエントリポート番号。デフォルト値は`80`です。</li><li>MetaDBプロキシIP：MetaDBプロキシIPアドレス。</li><li>MetaDBプロキシポート：MetaDBプロキシポート。デフォルト値は`2883`です。|
   | サーバー | OCPをインストールするサーバーのIPアドレス。 |
   | CPU | サーバー上でOCPが使用可能なCPU。デフォルトは`8C`です。<main id="notice" type='notice'><h4>注意</h4><p>準備したOCPサーバーのCPUとメモリが16C 32GBの構成で、かつMetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合は、サーバー上でOCPが使用可能なCPUを8Cに設定する必要があります。</p></main> |
   | メモリ | サーバー上でOCPが使用可能なメモリ。デフォルトは`20GB`です。 <main id="notice" type='notice'><h4>注意</h4><p>準備したOCPサーバーのCPUとメモリが16C 32GBの構成で、かつMetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合は、サーバー上でOCPが使用可能なメモリを16GBに設定する必要があります。</p></main>|
   | HTTPポート | OCPのHTTPポート番号。デフォルトは`8080`です。 |
   | マルチクラスタモード | マルチクラスタインストールモードを有効にします。 |
   | ログディレクトリ | OCPのログ保存パス。デフォルトは`/home/admin/logs/ocp`です。 |

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/3%E5%AE%89%E8%A3%85ocp-1%E5%9F%BA%E7%A1%80%E8%AE%BE%E7%BD%AE.png) -->

3. **<UI-TERM key="oat.Product.ProductManage.InstallOcp">OCPのインストール</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Binlog.New.MetadbConfiguration">MetaDB構成</UI-TERM>** を完了します。

   MetaDBタイプは **<UI-TERM key="oat.components.MetaDBForm.MetadbCreated">MetaDBが作成されました。</UI-TERM>** と **<UI-TERM key="oat.components.MetaDBForm.OtherObMysql">その他のOB_MySQL</UI-TERM>** の2種類です。**<UI-TERM key="oat.components.MetaDBForm.OcpMetaTenants">OCPメタテナント</UI-TERM>** と **OCP Monitorテナント** を設定します：

   * 新しく作成されたMetaDBで、テナントが作成されていない場合、**<UI-TERM key="oat.components.MetaDBForm.MetadbCreated">MetaDBが作成されました。</UI-TERM>** タブをクリックします。具体的なパラメータは以下のとおりです：

      | パラメータ | 説明 |
      |------|------|
      | 既存のMetaDBの選択 | OCPに対して既存のMetaDBを選択します。 |
      | MetaDBクラスタをOCPに引き継ぐかどうか | OCPのクラスタ引き継ぎ機能を使用して選択したMetaDBを追加します。完了後はOCPで管理できますが、同一のMetaDBは一つのOCPによってのみ引き継がれます。 |
      | OCP Metaテナント | OCP MetaDB専用のテナント。 |
      | テナント名 | MetaDBテナント名。 |
      | テナントパスワード | MetaDBテナントパスワード。 |
      | CPU | OCP Metaテナントが使用可能なCPU。デフォルトは`2C`です。 <main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合は、OCP Metaテナントが使用可能なCPUを2Cに設定する必要があります。</p></main>|
      | メモリ | OCP Metaテナントが使用可能なメモリ。デフォルトは`5GB`です。 <main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合は、OCP Metaテナントが使用可能なメモリを3GBに設定する必要があります。</p></main>|
      | OCP Monitorテナント | OCP MonitorDB専用のテナント。 |
      | テナント名 | MonitorDBテナント名。 |
      | テナントパスワード | MonitorDBテナントパスワード。 |
      | CPU | OCP Monitorテナントが使用可能なCPU。デフォルトは`4C`です。 <main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合は、OCP Monitorテナントが使用可能なCPUを2Cに設定する必要があります。</p></main>|
      | メモリ | OCP Monitorテナントが使用可能なメモリ。デフォルトは`16GB`です。<main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合は、OCP Monitorテナントが使用可能なメモリを3GBに設定する必要があります。</p></main> |
      | MetaDBクラスタの引き継ぎ | MetaDBクラスタを引き継ぐためにチェックします。引き継いだ後は、このMetaDBクラスタがOCPで表示されます。各MetaDBクラスタは一つのOCPによってのみ引き継がれます。|

      <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/6MetaDB%E9%85%8D%E7%BD%AE.png) -->

   * 既存のテナントがある場合、**<UI-TERM key="oat.components.MetaDBForm.OtherObMysql">その他のOB_MySQL</UI-TERM>** タブをクリックし、**<UI-TERM key="oat.components.MetaDBForm.OcpMetaTenants">OCPメタテナント</UI-TERM>** と **OCP Monitorテナント** の接続情報を入力します。入力するユーザー名がrootでない場合、該当ユーザーにはデータベーステーブルを作成する権限が付与されていなければなりません。

      <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/5%E5%85%B6%E4%BB%96OB-MYSQL.png) -->

4. **<UI-TERM key="oat.Product.ProductManage.InstallOcp">OCPのインストール</UI-TERM>** ページで、**<UI-TERM key="oat.DetailPage.components.LoadBalanceCard.LoadBalancingConfiguration">負荷分散構成</UI-TERM>** を完了します。

   ロードバランシングモードは以下の4種類から選択できます：

   * 既存のNLB。

      <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/7%E5%B7%B2%E5%88%9B%E5%BB%BA%E7%9A%84NLB.png) -->

   * 既存のOBDNS。

      <!-- ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/8%E5%B7%B2%E5%88%9B%E5%BB%BA%E7%9A%84OBDNS.png) -->

   * その他のロードバランシング。

      <!-- ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/3%E5%AE%89%E8%A3%85ocp-2%E5%85%B6%E4%BB%96%E8%B4%9F%E8%BD%BD%E5%9D%87%E8%A1%A1.png) -->

   * 使用しない：ロードバランシングを使用しない場合、高可用性機能を利用できません。デフォルトでは最初のIPアドレスが接続情報として使用されます。

5. **<UI-TERM key="oat.Product.ProductManage.InstallOcp">OCPのインストール</UI-TERM>** ページで、**OpenSearchの設定** を完了します。

    OpenSearchの設定モードは以下の3種類です：

    * 既存のOpenSearch：ドロップダウンリストから、OATによって作成されたOpenSearchを選択できます。OpenSearchの作成方法については、[OpenSearchの作成とアンインストール](https://www.oceanbase.com/docs/enterprise-oat-doc-cn-10000000002438433)を参照してください。
    * 外部のOpenSearch：外部にデプロイされたOpenSearchのURL、ユーザー名、パスワードを入力する必要があります。
    * 使用しない。

6. OCPの設定が完了したら、**<UI-TERM key="OMS.ViewObjectByWildCard.components.SecondContent.Submit">提出する</UI-TERM>** をクリックします。

   設定に誤りがある場合、**<UI-TERM key="oms-cloud.Operation.OperationOrder.Reset">リセット</UI-TERM>** をクリックして、デフォルト設定にワンクリックで戻すことができます。

## 次のステップ

OCPのデプロイが完了したら、OCPにログインしてデプロイ後の確認を行います。

1. ブラウザにOCPのアクセスアドレスを入力し、Enterキーを押します。

   アクセスアドレスは次のとおりです：http://\< *OCPサーバーのIPアドレス* \>:8080

2. 表示されたログインページで、デフォルトのアカウント`admin`でログインします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OCP422/1%E7%99%BB%E5%BD%95.png) -->

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>ドメイン名からアクセスする場合は、ローカルのDNSサービスを設定する必要があります。</li>
    <li>OceanBaseアフターサービスサポートにお問い合わせいただき、adminアカウントのデフォルトパスワードを取得してください。アカウントのセキュリティを確保するため、初回ログイン後速やかにパスワードを変更してください。</li>
    </ul>
  </main>
