# OCPのデプロイ

本記事では、OATを使用してOCPをインストールする方法について説明します。

<main id="notice" type='explain'>
   <h4>説明</h4>
   <p>このセクションでは、OAT V4.2.0を例に操作手順を説明します。OATのバージョンによって操作画面が異なる場合があります。実際の画面をご確認ください。</p>
</main>

## 前提条件

OCPをインストールする前に、以下の事項を確認してください。

* OATがインストール済みであること。詳細については、[OATのデプロイ](../../200.preparations-before-deploy/400.deploy-oat.md)を参照してください。
* スーパーユーザーまたはO&M担当者権限を持つアカウントでOATにログインしていること。アカウントの詳細については、[ユーザー管理](https://en.oceanbase.com/docs/enterprise-oat-10000000000949581)を参照してください。
* OCPをインストールするサーバーの準備が整い、OATに追加されていること。詳細については、[サーバーの準備](../../200.preparations-before-deploy/100.prepare-servers.md)および[サーバーの追加](../100.configuring-the-deploy-environment-through-oat/100.add-server.md)を参照してください。
* OCP用のメタデータベースMetaDBコンポーネントが作成されていること。詳細については、[MetaDBの作成](../200.deploy-ocp-use-oat/300.create-metadb.md)を参照してください。
* OCPインストールパッケージがOATのサーバーに追加されていること。詳細については、[インストールパッケージのアップロード](../200.deploy-ocp-use-oat/200.upload-the-installation-package.md)を参照してください。
* ネットワーク環境がOCPの正常な稼働に必要なネットワークポート設定要件（ネットワークアクセス権限）を提供していること。管理者は、実際の環境でのOCPコンポーネントのデプロイ計画に基づき、ネットワーク側およびホスト側で関連ポートを開放することができます。具体的な紹介情報については、[コンポーネントリスニングポート一覧](https://en.oceanbase.com/docs/common-ocp-10000000002854267)を参照してください。

## 手順

1. 左側のナビゲーションバーで、**プロダクトサービス \> プロダクト** をクリックして **プロダクト管理** ページに移動し、右上の **プロダクトのインストール** をクリックして、**OCPのインストール** を選択します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/3%E5%AE%89%E8%A3%85ocp-0.png) -->

2. **OCPのインストール** ページで、**基本設定** を完了します。

   | パラメータ | 説明 |
   |------|------|
   | OCP イメージ | OCP の Docker イメージ。 |
   | 商品名 | 商品名。他の商品名と重複してはなりません。 |
   | 管理者パスワード | OCP管理者のパスワード。パスワードの形式要件は以下のとおりです：<ul><li>長さが8～32文字です。</li><li>次の4種類の文字のうち、少なくとも3種類以上を含みます：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字 <code>\~!@#%\^\&\*_-+=\`\|(){}\[\]:;',.?/</code>。</li></ul>|
   | マルチゾーンモード | マルチゾーンインストールを有効にする場合、以下のパラメータがあります：<ul><li>ゾーン名：ゾーン名。</li><li>サーバー：OCPをインストールするサーバーのIPアドレス。</li><li>OCPプロキシIP：このゾーンのOCPアクセスエントリIP。</li><li>OCPプロキシポート：このゾーンのOCPアクセスエントリポート番号。デフォルト値は`80`です。</li><li>MetaDBプロキシIP：MetaDBプロキシIPアドレス。</li><li>MetaDBプロキシポート：MetaDBプロキシポート。デフォルト値は`2883`です。|
   | サーバー | OCPをインストールするサーバーのIPアドレス。 |
   | CPU | サーバー上でOCPが使用可能なCPU。デフォルトは`8C`です。<main id="notice" type='notice'><h4>注意</h4><p>準備したOCPサーバーのCPUとメモリが16C 32GB構成で、かつMetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合、サーバー上でOCPが使用可能なCPUを8Cに設定する必要があります。</p></main> |
   | メモリ | サーバー上でOCPが使用可能なメモリ。デフォルトは`20GB`です。 <main id="notice" type='notice'><h4>注意</h4><p>準備したOCPサーバーのCPUとメモリが16C 32GB構成で、かつMetaDBがサーバー上で使用可能なCPUとメモリを8C 16GBに設定している場合、サーバー上でOCPが使用可能なメモリを16GBに設定する必要があります。</p></main>|
   | HTTPポート | OCPのHTTPポート番号。デフォルトは`8080`です。 |
   | マルチクラスタモード | マルチクラスタインストールモードを有効にします。 |
   | ログディレクトリ | OCPのログ保存パス。デフォルトは`/home/admin/logs/ocp`です。 |

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/3%E5%AE%89%E8%A3%85ocp-1%E5%9F%BA%E7%A1%80%E8%AE%BE%E7%BD%AE.png) -->

3. **OCPのインストール** ページで、**MetaDB設定** を完了します。

   MetaDBタイプは **既存MetaDB** と **その他OB_MySQL** の2種類です。**OCP Metaテナント** と **OCP Monitorテナント** を設定します：

   * 新しく作成されたMetaDBで、まだテナントが作成されていない場合は、**既存MetaDB** タブをクリックします。具体的なパラメータは以下のとおりです：

      | パラメータ | 説明 |
      |------|------|
      | 既存のMetaDBを選択 | OCPに対して既に作成済みのMetaDBを選択します。 |
      | MetaDBクラスタをOCPに移管するかどうか | OCPのクラスタ移管機能を使用して、選択したMetaDBを追加します。完了後はOCPで管理できますが、同一のMetaDBは一つのOCPによってのみ移管されます。 |
      | OCP Metaテナント | OCP MetaDB専用のテナントです。 |
      | テナント名 | MetaDBテナント名。 |
      | テナントパスワード | MetaDBテナントのパスワード。 |
      | CPU | OCP Metaテナントが使用可能なCPU数。デフォルトは`2C`です。 <main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8コア16GBに設定した場合、OCP Metaテナントが使用可能なCPUを2コアに設定する必要があります。</p></main>|
      | メモリ | OCP Metaテナントが使用可能なメモリ。デフォルトは`5GB`です。 <main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8コア16GBに設定した場合、OCP Metaテナントが使用可能なメモリを3GBに設定する必要があります。</p></main>|
      | OCP Monitorテナント | OCP MonitorDB専用のテナントです。 |
      | テナント名 | MonitorDBテナント名。 |
      | テナントパスワード | MonitorDBテナントのパスワード。 |
      | CPU | OCP Monitorテナントが使用可能なCPU数。デフォルトは`4C`です。 <main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8コア16GBに設定した場合、OCP Monitorテナントが使用可能なCPUを2コアに設定する必要があります。</p></main>|
      | メモリ | OCP Monitorテナントが使用可能なメモリ。デフォルトは`16GB`です。<main id="notice" type='notice'><h4>注意</h4><p>MetaDBがサーバー上で使用可能なCPUとメモリを8コア16GBに設定した場合、OCP Monitorテナントが使用可能なメモリを3GBに設定する必要があります。</p></main> |
      | MetaDBクラスタを移管する | MetaDBクラスタを移管するためにチェックします。移管後はOCPでこのMetaDBクラスタが表示されます。各MetaDBクラスタは一つのOCPによってのみ移管されます。|

      <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/6MetaDB%E9%85%8D%E7%BD%AE.png) -->

   * テナントが存在する場合は、**その他OB_MySQL** タブをクリックし、**OCP Metaテナント** と **OCP Monitorテナント** の接続情報を入力します。入力するユーザー名がrootでない場合、該当するユーザーにデータベーステーブルを作成する権限が付与されている必要があります。

      <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/5%E5%85%B6%E4%BB%96OB-MYSQL.png) -->

4. **OCPのインストール** ページで、**ロードバランシング設定** を完了します。

   ロードバランシングモードは以下の4種類から選択できます：

   * 既存のNLB。

      <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/7%E5%B7%B2%E5%88%9B%E5%BB%BA%E7%9A%84NLB.png) -->

   * 既存のOBDNS。

      <!-- ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/4.deploy/3.deploy-oceanbase-database-enterprise/1.deploy-ocp/8%E5%B7%B2%E5%88%9B%E5%BB%BA%E7%9A%84OBDNS.png) -->

   * その他のロードバランシング。

      <!-- ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/3%E5%AE%89%E8%A3%85ocp-2%E5%85%B6%E4%BB%96%E8%B4%9F%E8%BD%BD%E5%9D%87%E8%A1%A1.png) -->

   * 使用しない：ロードバランシングを使用しない場合、高可用性を得られません。デフォルトでは最初のIPアドレスが接続情報として使用されます。

5. **OCPのインストール** ページで、**OpenSearch設定** を完了します。

    OpenSearchの設定モードは以下の3種類です：

    * 既存のOpenSearch：OATで作成されたOpenSearchをドロップダウンリストから選択できます。OpenSearchの作成方法については、[OpenSearchの作成とアンインストール](https://en.oceanbase.com/docs/enterprise-oat-10000000000949560)を参照してください。
    * 外部のOpenSearch：外部にデプロイされたOpenSearchのURL、ユーザー名、パスワードを入力する必要があります。
    * 使用しない。

6. OCPの設定が完了したら、**送信** をクリックします。

   設定に誤りがある場合は、**リセット** をクリックしてデフォルト設定にワンクリックで戻すことができます。

## 次のステップ

OCPのデプロイが完了したら、OCPにログインしてデプロイ後の確認を行います。

1. ブラウザにOCPのアクセスアドレスを入力し、Enterキーを押します。

   アクセスアドレスは次のとおりです：http://\< *OCPサーバーのIPアドレス* \>:8080

2. 表示されたログインページで、デフォルトのアカウント`admin`でログインします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OCP422/1%E7%99%BB%E5%BD%95.png) -->

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>ドメイン名からアクセスする場合は、ローカルのDNSサービスを設定する必要があります。</li>
    <li>OceanBaseアフターサービスサポートにお問い合わせいただき、adminアカウントのデフォルトパスワードを取得してください。アカウントのセキュリティを確保するため、初回ログイン後、速やかにパスワードを変更してください。</li>
    </ul>
  </main>
