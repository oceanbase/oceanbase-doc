# インストールパッケージのアップロード

OATにOceanBase製品をインストールしたり、コンポーネントを作成したりするには、各製品のインストールパッケージ（イメージ）をOATサーバーにアップロードするか、リモートでイメージに接続する必要があります。そのため、OATを使用してOCPをデプロイする前に、まずOCPのインストールに必要なパッケージを、OATがインストールされているサーバーにアップロードする必要があります。

本記事では、OCPのインストールに必要なパッケージをOATサーバーにアップロードする方法について説明します。

## 手順

### ステップ1：OCPのインストールパッケージをOATサーバーにアップロード

OATをインストールした後、インストールパッケージを`/oat/data_dir/images`ディレクトリにアップロードする必要があります。

OCPのデプロイメントでは、OATをインストールしたサーバーに、OCP DockerイメージとMetaDB Dockerイメージの2つのイメージをアップロードする必要があります。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>oat-all-in-oneインストールパッケージを使用してOATをインストールした場合は、OCP Dockerイメージのみをアップロードする必要があります。</p>
</main>

例：

```shell
[root@hostname /]# scp ./ocp.tar <oat_server>:/oat/data_dir/images/ocp.tar
[root@hostname /]# scp ./meta_xxx.tar <oat_server>:/oat/data_dir/images/meta_xxx.tar
```

ここで、`oat_server`はOATがデプロイされているサーバーのIPアドレスを表します。

### ステップ2：インストールパッケージをOATサービスに追加

1. OATにログインします。

2. 左側のナビゲーションバーで、**システムとセキュリティ \> パッケージ** をクリックして、**<UI-TERM key="oat.System.InstallPackage.InstallationPackageManagement">インストールパッケージ管理</UI-TERM>**ページに移動し、右上の**<UI-TERM key="oat.ImageManager.ImageDrawer.AddImage">ミラーを追加</UI-TERM>**をクリックして、**<UI-TERM key="oat.BinaryManager.BinaryDrawer.Content.LocalScan">ローカルスキャン</UI-TERM>**を選択します。
