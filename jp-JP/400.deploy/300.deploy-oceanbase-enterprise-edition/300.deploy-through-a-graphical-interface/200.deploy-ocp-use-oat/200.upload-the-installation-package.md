# インストールパッケージのアップロード

OATにOceanBase製品をインストールしたり、コンポーネントを作成したりするには、各製品のインストールパッケージ（イメージ）をOATサーバーにアップロードするか、リモートでイメージに接続する必要があります。そのため、OATを使用してOCPをデプロイする前に、まずOCPに必要なインストールパッケージをOATをインストールしたサーバーにアップロードする必要があります。

本記事では、OCPに必要なインストールパッケージをOATサーバーにアップロードする方法について説明します。

## 手順

### ステップ１：OCPインストールパッケージをOATのサーバーにアップロード

OATをインストールした後、インストールパッケージを`/oat/data_dir/images`ディレクトリにアップロードする必要があります。

OCPのデプロイメントでは、OATをインストールしたサーバーに、OCP DockerイメージとMetaDB Dockerイメージの2つのイメージをアップロードする必要があります。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OATをoat-all-in-oneインストールパッケージを使用してインストールした場合は、OCP Dockerイメージのみをアップロードします。</p>
</main>

例：

```shell
[root@hostname /]# scp ./ocp.tar <oat_server>:/oat/data_dir/images/ocp.tar
[root@hostname /]# scp ./meta_xxx.tar <oat_server>:/oat/data_dir/images/meta_xxx.tar
```

ここで、`oat_server`はOATをデプロイするサーバーのIPアドレスを表します。

### ステップ2：インストールパッケージをOATサービスに追加

1. OATにログインします。

2. 左側のナビゲーションバーで、**システムとセキュリティ \> インストールパッケージ**をクリックして**インストールパッケージ管理**ページに移動し、右上の**イメージの追加**をクリックして、**ローカルスキャン**を選択します。
