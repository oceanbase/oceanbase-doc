# MetaDBの作成

コンテナデプロイメントベースのOceanBaseデータベースサービスで、OceanBase Proxyが組み込まれており、外部からの直接アクセスが容易です。OCP、ODC、OMSなどの製品のメタデータストレージとして利用できます。

本記事では、OATを使用してMetaDBを作成する方法について説明します。

<main id="notice" type='explain'>
   <h4>説明</h4>
   <p><ul><li>このセクションでは、OAT V4.2.0バージョンを例に操作手順を説明します。OATのバージョンによって操作画面が異なる場合があります。実際の画面をご確認ください。</li><li>MetaDB用にOceanBase内に独立したテナントを作成することを推奨します。MetaDBは監視データ以外の永続化データを格納するために使用されます。CPUとメモリは少なくとも4コア、8GBを割り当てることを推奨します。</li><li>ディスク容量は、OCPが管理するクラスタの規模、保存されるファイルリソース、データの保持期間などの要因の影響を受けます。一般的には100GB以上のディスクを推奨します。</li></ul></p>
</main>

## 前提条件

MetaDBを作成する前に、以下の情報を確認してください：

* OATがインストール済みであること。詳細については、[OATのデプロイ](../../200.preparations-before-deploy/400.deploy-oat.md)を参照してください。
* スーパーユーザーまたは運用保守担当者権限を持つアカウントでOATにログインしていること。アカウントの詳細については、[ユーザー管理](https://en.oceanbase.com/docs/enterprise-oat-10000000000949581)を参照してください。
* MetaDBをインストールするサーバーが追加済みであること。詳細については、[サーバーの追加](../100.configuring-the-deploy-environment-through-oat/100.add-server.md)を参照してください。

## 手順

1. 左側のナビゲーションバーで、**プロダクトサービス \> コンポーネント** をクリックして **<UI-TERM key="oat.Product.ComponentManage.ComponentManagement">コンポーネント管理</UI-TERM>** ページに移動し、右上の **<UI-TERM key="oat.components.CardStepGuide.CreateAComponent">コンポーネントの作成</UI-TERM>** をクリックして、**<UI-TERM key="oat.Product.ComponentManage.CreateMetadb">MetaDBの作成</UI-TERM>** を選択します。

    <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/2%E5%88%9B%E5%BB%BAmetadb-0.png) -->

2. **<UI-TERM key="oat.Product.ComponentManage.CreateMetadb">MetaDBの作成</UI-TERM>** ページで、**<UI-TERM key="OMS.biz.Sync.ParamCfgDetail.BasicConfiguration">基本設定</UI-TERM>** を構成します。

    | パラメータ | 説明 |
    |------|------|
    | MetaDB イメージ | MetaDBのDockerイメージ。 |
    | コンポーネント名 | コンポーネント名。他のコンポーネントと重複してはなりません。デフォルト名は `metadb` です。 |
    | サーバー | MetaDBをインストールするサーバーのIPアドレス。 |
    | カスタムZone | カスタムZoneを有効にする場合は、Zone名、データセンター、サーバー、Root Serverの場所を入力する必要があります。<main id="notice" type='notice'><h4>注意</h4><p>このパラメータとサーバーパラメータはどちらか一方を選択してください。カスタムZoneを有効にすると、上記のサーバーパラメータは自動的に非表示になります。</p></main>|
    | アービトレーションサービスの設定 | 自由に有効または無効にできます。有効にする場合は、アービトレーションサービスのアドレスを入力してください。例：xxx.xxx.xxx.xxx:xxxx。<main id="notice" type='notice'><h4>注意</h4><p>MetaDBイメージでV4.XバージョンのMetaDBを選択した場合にのみ、アービトレーションサービスを設定できます。</p></main>|
    | CPU | サーバー上でMetaDBが使用可能なCPU。デフォルトは `32C` です。 <main id="notice" type='explain'><h4>説明</h4><p>準備したOCPサーバーのCPUとメモリが16コア32GBの構成である場合、サーバー上でMetaDBが使用可能なCPUを8コアに設定することを推奨します。</p></main>|
    | メモリ | サーバー上でMetaDBが使用可能なメモリ。デフォルトは `90GB` です。 <main id="notice" type='explain'><h4>説明</h4><p>準備したOCPサーバーのCPUとメモリが16コア32GBの構成である場合、サーバー上でMetaDBが使用可能なメモリを16GBに設定することを推奨します。</p></main>|
    | MetaDBクラスタ名 | MetaDBのクラスタ名。 |
    | root@sys パスワード | MetaDBクラスタsysテナントのrootユーザーパスワード。 |

    <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/2%E5%88%9B%E5%BB%BAmetadb-1%E5%9F%BA%E7%A1%80%E8%AE%BE%E7%BD%AE.png) -->

3. **<UI-TERM key="oat.Product.ComponentManage.CreateMetadb">MetaDBの作成</UI-TERM>** ページで、**インストールパス（オプション）** を構成します。

    MetaDBのインストールパスを設定するパラメータは以下のとおりです：

    | パラメータ | 説明 |
    |------|------|
    | インストールディレクトリ | MetaDBのインストールパス。デフォルト値は `/home/admin/oceanbase` です。 |
    | データディレクトリ | MetaDBのデータ保存パス。デフォルト値は `/data/1` です。 |
    | ログディレクトリ | MetaDBのログ保存パス。デフォルト値は `/data/log1` です。 |
    | （オプション）バックアップディレクトリ | MetaDBのバックアップパス。デフォルト値は空です。 |

    <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.0.0/4.deploy-the-oceanbase-database/OAT/create-metadb/3%E5%AE%89%E8%A3%85%E8%B7%AF%E5%BE%84.png) -->

4. **<UI-TERM key="oat.Product.ComponentManage.CreateMetadb">MetaDBの作成</UI-TERM>**ページで、**起動パラメータ（オプション）**を設定します。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>準備したOCPサーバーのCPUとメモリが16コア32GB構成であり、MetaDBがサーバー上で利用可能なCPUとメモリを8コア16GBに設定している場合は、<b>observerプロセス起動パラメータ</b>で、<code>system_memory</code>の値を5G、<code>resource_hard_limit</code>の値を150に設定する必要があります。</p>
    </main>

    MetaDBの起動パラメータを設定するパラメータは以下のとおりです：

    | パラメータ | 説明 |
    |------|------|
    | MySQLポート | MetaDBのMySQLポート。デフォルト値は `2881` です。 |
    | RPCポート | MetaDBのRPCポート。デフォルト値は `2882` です。 |
    | （オプション）OBプロセス起動パラメータ | 必要に応じてobserverプロセスの起動パラメータを変更または追加できます。 |
    | OB Proxyサービスポート | OBProxyのサービスポート。デフォルト値は `2883` です。 |
    | （オプション）OB Proxyプロセス起動パラメータ | 必要に応じてOBProxyプロセスの起動パラメータを変更または追加できます。詳細については、[OBProxy設定パラメータ説明](https://en.oceanbase.com/docs/enterprise-odp-enterprise-en-10000000000864189)を参照してください。 |
    | SSHDポート | MetaDBコンテナ内のSSHDポート。デフォルト値は `2022` です。OCPはSSHDポートに接続してOCP Agentをデプロイします。 |
    | rootパスワード | MetaDBコンテナ内のrootユーザーパスワード。 |

    <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.0.0/4.deploy-the-oceanbase-database/OAT/create-metadb/4%E5%90%AF%E5%8A%A8%E5%8F%82%E6%95%B0.png) -->

5. MetaDBの設定が完了したら、**<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Submitted">送信</UI-TERM>**をクリックします。

   設定に誤りがある場合は、**<UI-TERM key="ocp-v2.src.util.component.Reset">リセット</UI-TERM>**をクリックして、デフォルト設定にワンクリックで戻すことができます。

## 次のステップ

MetaDBのインストール後、OceanBaseのエコシステムツールであるOCP、ODC、OMS、OB Shardingをインストールできます。
