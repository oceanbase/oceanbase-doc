# MetaDBの作成

コンテナデプロイメントに基づくOceanBaseデータベースサービスであり、OceanBase Proxyが組み込まれており、外部から直接アクセスしやすいです。OCP、ODC、OMSなどの製品のメタデータストレージとして使用できます。

本記事では、OATを使用してMetaDBを作成する方法について説明します。

<main id="notice" type='explain'>
   <h4>説明</h4>
   <p><ul><li>この記事は、OAT V4.2.0バージョンを例に操作ガイドを提供します。異なるOATバージョンの操作画面は異なる場合があるため、実際の画面に従ってください。</li><li>MetaDB用にOceanBase内に独立したテナントを作成することを推奨します。MetaDBは、監視データ以外の永続化データを格納するために使用され、CPUとメモリを4コア以上、8GB以上割り当てることを推奨します。</li><li>ディスク容量は、OCPが管理するクラスタの規模、保存されるファイルリソース、データ保持期間などの要因によって影響を受けるため、一般的には100GB以上のディスク容量を推奨します。</li></ul></p>
</main>

## 前提条件

MetaDBを作成する前に、以下の情報を確認する必要があります。

* OATがインストール済みであること。詳細については、[OATのデプロイ](../../200.preparations-before-deploy/400.deploy-oat.md)を参照してください。
* スーパー管理者または運用保守担当者権限を持つアカウントでOATにログインしていること。アカウントの詳細については、[ユーザー管理](https://www.oceanbase.com/docs/enterprise-oat-doc-cn-10000000002024815)を参照してください。
* MetaDBをインストールするサーバーが追加済みであること。詳細については、[サーバーの追加](../100.configuring-the-deploy-environment-through-oat/100.add-server.md)を参照してください。

## 手順

1. 左側のナビゲーションバーで、**プロダクトサービス \> コンポーネント** をクリックして **コンポーネント管理** ページに移動し、右上の **コンポーネントの作成** をクリックして **MetaDBの作成** を選択します。

    <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/2%E5%88%9B%E5%BB%BAmetadb-0.png) -->

2. **MetaDBの作成** ページで、**基本設定** を構成します。

    | パラメータ | 説明 |
    |------|------|
    | MetaDBイメージ | MetaDBのDockerイメージ。 |
    | コンポーネント名 | コンポーネントの名前。他のコンポーネントと重複してはなりません。デフォルト名は`metadb`です。 |
    | サーバー | MetaDBをインストールするサーバーのIPアドレス。 |
    | カスタムZone | カスタムZoneを有効にする場合は、Zone名、データセンター、サーバー、Root Serverの場所を入力する必要があります。<main id="notice" type='notice'><h4>注意</h4><p>このパラメータとサーバーのパラメータはどちらか一方を選択します。カスタムZoneを有効にすると、上記のサーバーのパラメータは自動的に非表示になります。</p></main>|
    | アービトレーションサービスの設定 | 自由に有効または無効にできます。有効にする場合は、アービトレーションサービスのアドレスを入力する必要があります。例：xxx.xxx.xxx.xxx:xxxx。<main id="notice" type='notice'><h4>注意</h4><p>MetaDBイメージでV4.XバージョンのMetaDBを選択した場合にのみ、アービトレーションサービスを設定できます。</p></main>|
    | CPU | サーバー上で利用可能なMetaDBのCPU数。デフォルトは`32C`です。 <main id="notice" type='explain'><h4>説明</h4><p>準備したOCPサーバーのCPUとメモリが16C 32GB構成の場合、サーバー上で利用可能なMetaDBのCPU数を8Cに設定することを推奨します。</p></main>|
    | メモリ | サーバー上で利用可能なMetaDBのメモリ。デフォルトは`90GB`です。 <main id="notice" type='explain'><h4>説明</h4><p>準備したOCPサーバーのCPUとメモリが16C 32GB構成の場合、サーバー上で利用可能なMetaDBのメモリを16GBに設定することを推奨します。</p></main>|
    | MetaDBクラスタの名前 | MetaDBのクラスタ名。 |
    | root@sysパスワード | MetaDBクラスタのsysテナントのrootユーザーのパスワード。 |

    <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.2/400.deploy/OAT420/2%E5%88%9B%E5%BB%BAmetadb-1%E5%9F%BA%E7%A1%80%E8%AE%BE%E7%BD%AE.png) -->

3. **MetaDBの作成** ページで、**インストールパス（オプション）** を構成します。

    MetaDBのインストールパス構成パラメータは以下のとおりです：

    | パラメータ | 説明 |
    |------|------|
    | インストールディレクトリ | MetaDBのインストールパス。デフォルト値は`/home/admin/oceanbase`です。 |
    | データディレクトリ | MetaDBのデータストレージパス。デフォルト値は`/data/1`です。 |
    | ログディレクトリ | MetaDBのログストレージパス。デフォルト値は`/data/log1`です。 |
    | (オプション)バックアップディレクトリ | MetaDBのバックアップパス。デフォルト値は空です。 |

    <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.0.0/4.deploy-the-oceanbase-database/OAT/create-metadb/3%E5%AE%89%E8%A3%85%E8%B7%AF%E5%BE%84.png) -->

4. **MetaDBの作成** ページで、**起動パラメータ（オプション）** を構成します。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>準備したOCPサーバーのCPUとメモリが16C 32GBの構成であり、MetaDBがサーバー上で利用可能なCPUとメモリを8C 16GBに設定した場合、<b>observerプロセス起動パラメータ</b> において、パラメータ <code>system_memory</code> の値を5G、パラメータ <code>resource_hard_limit</code> の値を150に設定する必要があります。</p>
    </main>

    MetaDBの起動パラメータ構成パラメータは以下のとおりです：

    | パラメータ | 説明 |
    |------|------|
    | MySQLポート | MetaDBのMySQLポート。デフォルト値は`2881`です。 |
    | RPCポート | MetaDBのRPCポート。デフォルト値は`2882`です。 |
    | (オプション)OBプロセス起動パラメータ | 必要に応じて、observerプロセスの起動パラメータを変更または追加できます。 |
    | OB Proxyサービスポート | OBProxyのサービスポート。デフォルト値は`2883`です。 |
    | (オプション)OB Proxyプロセス起動パラメータ | 必要に応じて、OBProxyプロセスの起動パラメータを変更または追加できます。詳細については、[OBProxy構成パラメータの説明](https://www.oceanbase.com/docs/enterprise-odp-enterprise-cn-10000000001717341)参照してください。 |
    | SSHDポート | MetaDBコンテナ内のSSHDPort。デフォルト値は`2022`です。OCPは、SSHDPortに接続してOCP Agentをデプロイします。 |
    | rootパスワード | MetaDBコンテナ内のrootユーザーのパスワード。 |

    <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.0.0/4.deploy-the-oceanbase-database/OAT/create-metadb/4%E5%90%AF%E5%8A%A8%E5%8F%82%E6%95%B0.png) -->

5. MetaDBの設定が完了したら、**送信** をクリックします。

   設定に誤りがある場合は、**リセット** をクリックしてデフォルト設定にワンクリックで復元できます。

## 次のステップ

MetaDBをインストールした後、OceanBaseのエコシステムツールであるOCP、ODC、OMS、OB Shardingをインストールできます。
