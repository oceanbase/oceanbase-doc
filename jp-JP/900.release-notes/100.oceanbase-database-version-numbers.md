# バージョン番号のルール

このセクションでは、OceanBaseデータベースのバージョン番号ルールとその意味について説明します。

OceanBaseデータベースは継続的にイテレーションと最適化が行われており、定期的に新しいバージョンがリリースされます。異なるバージョン間では機能や特徴に大きな差異が生じる場合があるため、正確なドキュメント情報を入手するためには、ご利用のデータベースのバージョン番号を確認する必要があります。

OceanBaseデータベースのバージョンはV.x.y.z.fで表され、各部分の意味は以下の通りです：

* x はメジャーバージョンを表し、通常はアーキテクチャのアップグレードや大規模な新機能のリリースが含まれます。

* y は計画されたイテレーションバージョンを表し、通常のイテレーション計画に含まれ、重要な機能や特徴の更新・向上が含まれます。

* z は更新バージョンを表し、少量の機能や特徴の更新、既知の問題の修正が含まれます。

* f はパッチアップグレードバージョンを表し、機能や問題の修正によりバージョン番号を引き上げる必要がある場合に使用されます。

## OceanBaseデータベースのバージョンの確認

version() 関数を呼び出すか、ビューを参照することで、現在のデータベースのバージョンを確認できます。

通常、OBClientやMySQLクライアントでデータベースに接続すると、データベースのバージョン情報が表示されます。現在使用しているデータベースのバージョン情報を確認したい場合は、以下の方法で照会できます。

### MySQLモードでデータベースのバージョンを確認する

管理者アカウントでログインした後、以下のコマンドを実行してバージョン番号を確認します。

```sql
obclient> SELECT version();
+-----------+
| version() |
+-----------+
| 4.0.0.0   |
+-----------+
1 row in set
```

### Oracleモードでデータベースのバージョンを確認する

管理者アカウントでログインした後、以下のコマンドを実行してバージョン番号を確認します。

```sql
obclient> SELECT * FROM v$version;
+-----------------------------------------------------------------------------------------------------------+--------+
| BANNER                                                                                                    | CON_ID |
+-----------------------------------------------------------------------------------------------------------+--------+
| OceanBase 4.0.0.0 (r20220525115829-1873fc2598d56060fe307ce3b7b88647686e0b09) (Built May 25 2022 12:12:10) |      0 |
+-----------------------------------------------------------------------------------------------------------+--------+
1 row in set
```
