# バージョン番号のルール

この記事では、OceanBaseデータベースのバージョン番号のルールとその意味について説明します。

OceanBaseデータベースは継続的にイテレーションと最適化が行われるため、定期的に新しいバージョンがリリースされます。異なるバージョン間で機能や特徴に大きな違いがある場合があるため、正確なドキュメント情報を取得するためには、ご自身のデータベースのバージョン番号を特定する必要があります。

OceanBaseデータベースのバージョンはV.x.y.z.fで表されます。ここで：

* xはメジャーバージョンを表し、このバージョンでは一般的にアーキテクチャのアップグレードや大規模な新機能のリリースが行われます。

* yは計画されたイテレーションバージョンを表し、通常のイテレーション計画内で重要な機能や特徴の更新および向上が含まれます。

* zは更新バージョンを表し、このバージョンには少数の機能や特徴の更新と既知の問題の修正が含まれます。

* fはパッチアップグレードバージョンを表し、第4のバージョン番号は機能や特徴、または問題の修正によりバージョン番号を引き上げる必要がある場合に使用されます。

## OceanBaseデータベースのバージョンを確認する

version()関数やビューを照会することで、現在のデータベースのバージョンを確認できます。

通常、OBClientやMySQLクライアントを使用してデータベースに接続すると、データベースのバージョン情報が表示されます。現在使用しているデータベースのバージョン情報を確認したい場合は、以下の方法で照会できます。

### MySQLモードでデータベースのバージョンを確認する

管理者アカウントでログインした後、以下のコマンドを実行してバージョン番号を確認します。

```sql
obclient> SELECT version();
+-----------+
| version() |
+-----------+
| 4.0.0.0   |
+-----------+
1 row in set
```

### Oracleモードでデータベースのバージョンを確認する

管理者アカウントでログインした後、以下のコマンドを実行してバージョン番号を確認します。

```sql
obclient> SELECT * FROM v$version;
+-----------------------------------------------------------------------------------------------------------+--------+
| BANNER                                                                                                    | CON_ID |
+-----------------------------------------------------------------------------------------------------------+--------+
| OceanBase 4.0.0.0 (r20220525115829-1873fc2598d56060fe307ce3b7b88647686e0b09) (Built May 25 2022 12:12:10) |      0 |
+-----------------------------------------------------------------------------------------------------------+--------+
1 row in set
```
