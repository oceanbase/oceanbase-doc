# OMSを使用してOceanBaseデータベースのOracleテナントからMySQLデータベースへ増分データを移行する

本記事では、OceanBase Migration Service（OMS）を使用してOceanBaseデータベースのOracleテナントからMySQLデータベースへ増分データを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールで、OceanBaseデータベースのOracleテナントからMySQLデータベースへデータを移行するためのデータ移行プロジェクトを作成します。増分同期を使用して、ソースとなるOceanBaseデータベースのOracleテナント内の増分データをMySQLデータベースに移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースのOracleテナントからMySQLデータベースへ増分データを移行する操作の詳細については、[OceanBaseデータベースのOracleテナントの増分データをMySQLデータベースに移行する](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091366)を参照してください。
