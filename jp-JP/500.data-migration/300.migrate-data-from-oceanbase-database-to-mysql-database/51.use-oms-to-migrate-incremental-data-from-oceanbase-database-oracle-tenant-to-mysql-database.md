# OMSを使用してOceanBaseデータベースのOracleテナントからMySQLデータベースへ増分データを移行する

本記事では、OceanBase Migration Service（OMS）を使用して、OceanBaseデータベースのOracleテナントからMySQLデータベースへ増分データを移行する背景について簡単に説明します。

## 背景情報

OMSコンソールで、OceanBaseデータベースのOracleテナントからMySQLデータベースへデータを移行するためのデータ移行プロジェクトを作成します。増分同期を通じて、移行元のOceanBaseデータベースのOracleテナント内の増分データをMySQLデータベースに移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースのOracleテナントからMySQLデータベースへ増分データを移行する操作の詳細については、[OceanBaseデータベースのOracleテナントの増分データをMySQLデータベースに移行する](https://docs.oceanbase.com/oms/V4.2.3-create-a-project-to-migrate-data-from-an-oracle-tenant-of-oceanbase-database-to-a-mysql-database)を参照してください。
