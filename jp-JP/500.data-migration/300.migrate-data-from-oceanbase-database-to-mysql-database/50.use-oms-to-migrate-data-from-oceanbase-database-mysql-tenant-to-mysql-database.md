# OMSを使用してOceanBaseデータベースのMySQLテナントからMySQLデータベースへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してOceanBaseデータベースのMySQLテナントからMySQLデータベースへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールで、OceanBaseデータベースのMySQLテナントからMySQLデータベースへのデータ移行プロジェクトを作成します。構造移行、フル移行、および増分同期を通じて、ソース側データベース内の既存業務データと増分データをMySQLデータベースへシームレスに移行できます。

MySQLデータベースは、単一マスター、単一スタンバイ、およびマスタースタンバイなどのモードをサポートしています。OceanBaseデータベースのMySQLテナントからMySQLデータベースへデータを移行する際、異なるタイプのデータソースに対応する操作も異なります。

| タイプ |                                                            サポートされる操作                                             |
|-----|---------------------------------------------------------------------------------------------------------------------|
| プライマリストア | スキャン移行 + フル移行 + 増分同期 + フル検証 + リバース増分                                                                                                    |
| スタンバイストア | スタンバイストアのMySQLデータソースをデータ移行のターゲットとしてサポートしていません。                                                                                                        |
| プライマリ/スタンバイストア | プライマリストア：スキャン移行 + フル移行 + 増分同期 + リバース増分をサポートします。</br> スタンバイストア：フル検証をサポートします。</br> <main id="notice" type='explain'><h4>説明</h4><p>プライマリストアとスタンバイストアのデータソースを選択した場合、OMSはスタンバイストアをフル検証のプライマリノードとして使用します。</p></main>  |
