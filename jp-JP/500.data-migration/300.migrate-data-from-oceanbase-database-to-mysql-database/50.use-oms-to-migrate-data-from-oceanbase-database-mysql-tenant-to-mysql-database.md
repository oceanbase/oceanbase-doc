# OMSを使用してOceanBaseデータベースのMySQLテナントからMySQLデータベースへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用して、OceanBaseデータベースのMySQLテナントからMySQLデータベースへデータを移行する背景について簡潔に説明します。

## 背景情報

OMSコンソールで、OceanBaseデータベースのMySQLテナントからMySQLデータベースへのデータ移行プロジェクトを作成します。構造移行、フル移行、増分同期を通じて、ソースデータベースの既存業務データと増分データをMySQLデータベースへシームレスに移行できます。

MySQLデータベースは、単一マスター、単一スタンバイ、マスタースタンバイなどのモードをサポートしています。OceanBaseデータベースのMySQLテナントのデータをMySQLデータベースに移行する際、異なるタイプのデータソースがサポートする操作も異なります。

| タイプ  |                                                            サポートされる操作                                             |
|-----|---------------------------------------------------------------------------------------------------------------------|
| シングルマスター | 構造移行 + フル移行 + 増分同期 + フル検証 + 反復増分                                                                                                    |
| シングルスタンバイ | シングルスタンバイデータソースのMｙSQLデータソースをデータ移行のデータ送信先として使用することには対応していません。                                                                                                        |
| マスター/スタンバイ | マスターデータベース：構造移行 + フル移行 + 増分同期 + 反復増分をサポートします。 </br> スタンバイデータベース：フル検証をサポートします。  </br> <main id="notice" type='explain'><h4>説明</h4><p>マスターデータベースとスタンバイデータベースのデータソースを選択した場合、OMSはスタンバイデータベースをフル検証のリーダーノードとして使用します。</p></main>  |
