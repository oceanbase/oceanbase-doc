# Canalを使用してOceanBaseデータベースからMySQLデータベースへデータを同期する

このドキュメントでは、CanalとOceanBase Binlogサービスを使用して、OceanBaseデータベースからMySQLデータベースへデータを同期する方法について説明します。

## OceanBase CDCの実装ロジック

OceanBase Binlogサービスは、OceanBaseデータベースの増分ログのプロキシサービスです。libobcdc（旧称：liboblog）を基盤とし、サービスとしてリアルタイムの増分データ連携への接続および管理機能を提供することで、アプリケーションからOceanBaseの増分ログへのアクセスを容易にします。ネットワークが分離されている状況でも増分ログのサブスクリプションに対応でき、多様な接続方式を提供します。

Canalは、MySQLのBinlogログを解析してデータベースの増分データを抽出し、サブスクライバーに送信します。サブスクライバーは受信したデータを利用・処理します。これにより、ユーザーはデータのリアルタイム同期やリアルタイム分析などを容易に実現できます。

Canalの公式バージョンおよび使用方法については、[alibaba/canal](https://github.com/alibaba/canal/releases)を参照してください。

データリンク：

```shell
ob_cluster -> obbinlog -> canal_server -> canal_adapter -> mysql
```

コンポーネント紹介：

* OceanBaseデータベース：Binlogログを生成する必要がある業務データベース。

* OceanBaseデータベースプロキシ：業務データベースのODP（OBProxyとも呼ばれる）。Binlogをサブスクライブするクライアントに接続サービスを提供します。

* OceanBase Binlogツール：OceanBase Binlogサービスのコアコンポーネントであるobbinlog（元のoblogproxy）。clogの取得とBinlogログの生成を実行します。

* Canal Server：Canalのサーバーサイドで、MySQLスレーブの動作をシミュレートしてソース側のBinlogログを解析し、増分データをCanalEntryに変換して下流で利用できるようにします。

* Canal Adapter：Canalのクライアントアダプターで、CanalEntryを解析し、増分データをターゲット側に同期します。本記事では、そのrdbモジュールを使用してデータをMySQLデータベースに同期します。

## 操作手順

### ステップ1：OceanBase Binlogサービスを有効化する

1. [Binlogクラスタの作成](https://docs.oceanbase.com/ocp/V4.3.3-create-a-binlog-cluster)を参照して、OceanBase Binlogサービスのインストールとデプロイを完了してください。

2. OCPのテナント概要ページで、業務テナントのBinlogサービスを有効にし、該当テナントに対応するOBProxyクラスタを関連付けます。Binlogサービスの有効化はMySQL互換モードのテナントでのみサポートされています。詳細な操作については、[テナントのBinlogサービスの管理](https://www.oceanbase.com/docs/common-ocp-1000000003339476)を参照してください。

3. データ同期用のユーザーを作成します。

    業務テナントで以下のSQLを実行し、ユーザーを作成して読み取り権限を付与します。

    ```sql
    CREATE USER 'canal'@'%' IDENTIFIED BY '******';
    GRANT SELECT ON *.* TO 'canal'@'%';
    ```

### ステップ2：Canal Serverをインストールする

1. ソフトウェアパッケージをダウンロードします。

    [canal.deployer-1.1.8.tar.gz](https://github.com/alibaba/canal/releases/download/canal-1.1.8/canal.deployer-1.1.8.tar.gz)をダウンロードします。

    ```bash
    wget https://github.com/alibaba/canal/releases/download/canal-1.1.8/canal.deployer-1.1.8.tar.gz
    ```

2. 圧縮ファイルを`/Canal_Home/canal`ディレクトリに解凍します。

    ```bash
    mkdir /Canal_Home/canal && tar zxvf canal.deployer-1.1.8.tar.gz -C /Canal_Home/canal
    ```

3. canal instanceを設定します。

    `/Canal_Home/canal/conf/example/instance.properties`を変更し、ソース側OceanBaseデータベースの接続情報を設定します。接続アドレスは業務テナントのODPのアドレスとポートで、ユーザー名の形式は`ユーザー名@テナント名#クラスタ名`です。

    ```bash
    cd /Canal_Home/canal/conf/example
    vi instance.properties

    # ソース側の接続情報。アドレスはODPのアドレスとポートです。
    canal.instance.master.address=10.10.10.1:2883
    canal.instance.dbUsername=canal@mysql001#test4000
    canal.instance.dbPassword=******

    # ログフィルタリング。[データベース名.テーブル名]の形式で、正規表現をサポートします。
    canal.instance.filter.regex=.*\\..*
    ```

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>Binlogサービスを有効にすると、ODPはクライアントのBinlogサブスクリプションリクエストを対応するBinlogインスタンスに転送するため、CanalがODPに接続すればOceanBaseデータベースの増分ログをサブスクライブできます。</p>
    </main>

4. Canal Serverを起動します。

    ```bash
    cd /Canal_Home/canal && sh bin/startup.sh
    ```

    ログを確認してCanal Serverが正常に起動したことを確認します。

    ```bash
    tail -f logs/canal/canal.log
    ```

### ステップ3：RDBアダプターの設定

1. ソフトウェアパッケージをダウンロードします。

    [canal.adapter-1.1.8.tar.gz](https://github.com/alibaba/canal/releases/download/canal-1.1.8/canal.adapter-1.1.8.tar.gz)をダウンロードします。

    ```bash
    wget https://github.com/alibaba/canal/releases/download/canal-1.1.8/canal.adapter-1.1.8.tar.gz
    ```

2. 圧縮ファイルを`/Canal_Home/adapter`ディレクトリに解凍します。

    ```bash
    mkdir /Canal_Home/adapter && tar zxvf canal.adapter-1.1.8.tar.gz -C /Canal_Home/adapter
    ```

3. `application.yml`を修正します。

    `/Canal_Home/adapter/conf/application.yml`を変更し、RDBアダプターを設定してCanal ServerにTCPモードで接続するとともに、ターゲットMySQLデータベースの接続情報を設定します。

    ```bash
    cd /Canal_Home/adapter/conf
    vi application.yml

    canal.conf:
      mode: tcp #tcp kafka rocketMQ rabbitMQ
      consumerProperties:
        # canal tcp consumer
        canal.tcp.server.host: 127.0.0.1:11111
      canalAdapters:
      - instance: example # canal instance Name or mq topic name
        groups:
        - groupId: g1
          outerAdapters:
          - name: logger
          - name: rdb
            key: mysql1
            properties:
              jdbc.driverClassName: com.mysql.cj.jdbc.Driver
              jdbc.url: jdbc:mysql://10.10.10.1:3306/test_data?useUnicode=false
              jdbc.username: root
              jdbc.password: ******
    ```

4. アダプターのデータベース/テーブルマッピングを修正します（ここではデータベースマッピングを例に説明します）。

    ```bash
    cd /Canal_Home/adapter/conf/rdb
    vi mytest_user.yml

    ## Mirror schema synchronize config
    dataSourceKey: defaultDS
    destination: example
    groupId: g1
    outerAdapterKey: mysql1
    concurrent: true
    dbMapping:
      mirrorDb: true
      database: test_data
    ```

5. Canal Adapterを起動します。

    ```bash
    cd /Canal_Home/adapter && sh bin/startup.sh
    ```

6. データ同期状況を確認します。

    OceanBaseのソース側にデータを書き込み、MySQLのターゲット側でデータの同期状況を確認します。

## 機能制限

* 同期するテーブルにはプライマリキーが必要です。ソース側でプライマリキーのないテーブルから任意の1件のレコードを削除すると、ターゲット側への同期時にテーブル全体が削除されます。

* DDLでは、テーブルの新規作成と列の追加をサポートします。
