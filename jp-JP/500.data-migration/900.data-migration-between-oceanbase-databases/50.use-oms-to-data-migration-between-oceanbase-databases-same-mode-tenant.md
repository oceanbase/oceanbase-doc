# OMSを使用してOceanBaseデータベースから同じ種類のテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してOceanBaseデータベースから同じ種類のテナントへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールで、OceanBaseデータベースから同じ種類のテナントへデータを移行するためのデータ移行プロジェクトを作成できます。構造移行、フル移行、増分同期を通じて、ソース側データベースの既存業務データと増分データをターゲット側データベースへシームレスに移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースから同じ種類のテナントへデータを移行する操作の詳細については、[OceanBaseデータベースの一方向データ移行](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091365)を参照してください。
