# OMSを使用してOceanBaseデータベースから同種テナントへのデータ移行

本記事では、OceanBase Migration Service（OMS）を使用して、OceanBaseデータベースから同種テナントへデータを移行する背景情報について簡潔に説明します。

## 背景情報

OMSコンソールでは、OceanBaseデータベースから同種テナントへのデータ移行プロジェクトを作成できます。構造移行、フル移行、増分同期を通じて、データ送信元データベースの既存業務データと増分データをデータ送信先データベースへシームレスに移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースから同種テナントへデータを移行する操作の詳細については、[OceanBaseデータベースの単方向データ移行](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091365)を参照してください。
