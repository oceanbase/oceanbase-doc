# OMSを使用してOceanBaseデータベースから同種テナントへのデータ移行

本記事では、OceanBase Migration Service（OMS）を使用して、OceanBaseデータベースから同種テナントへデータを移行する背景について簡潔に説明します。

## 背景

OMSコンソールでは、OceanBaseデータベースから同種テナントへのデータ移行プロジェクトを作成できます。構造移行、フル移行、増分同期を通じて、ソースデータベースの既存業務データと増分データをターゲットデータベースへシームレスに移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースから同種テナントへデータを移行する操作の詳細については、[OceanBaseデータベースの単方向データ移行](https://en.oceanbase.com/docs/enterprise-oms-doc-en-10000000000888345)を参照してください。
