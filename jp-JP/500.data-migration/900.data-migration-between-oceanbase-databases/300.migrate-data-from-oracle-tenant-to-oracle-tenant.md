# OceanBaseデータ移行ツールを使用して、OceanBaseクラスタのOracleテナント間でデータを移行する

本記事では、OceanBaseデータ移行ツールを使用して、OceanBaseクラスタのOracleテナント間でデータを移行する方法について説明します。

## OceanBaseデータ移行ツールの概要

OceanBaseデータ移行ツールには、エクスポートツールのobdumperとインポートツールのobloaderが含まれます。

* obdumperは、Javaで開発されたクライアントエクスポートツールです。このツールを使用して、OceanBaseデータベースで定義されたオブジェクトとデータをファイルにエクスポートできます。obdumperの詳細については、[obdumperの概要](https://en.oceanbase.com/docs/enterprise-oceanbase-dumper-loader-en-10000000000860074)を参照してください。

* obloaderは、Javaで開発されたクライアントインポートツールです。このツールは非常に柔軟なコマンドラインオプションを提供しており、多様な複雑なシナリオで定義とデータをOceanBaseにインポートできます。obloaderの詳細については、[obloaderの概要](https://en.oceanbase.com/docs/enterprise-oceanbase-dumper-loader-en-10000000000860068)を参照してください。

## 手順

1. obdumperとobloaderの実行環境を準備します。[環境の準備](https://en.oceanbase.com/docs/enterprise-oceanbase-dumper-loader-en-10000000000860066)および[ツールのダウンロード](https://en.oceanbase.com/docs/enterprise-oceanbase-dumper-loader-en-10000000000860067)を参照してください。

2. エクスポートデータを格納するディレクトリを作成します。

3. テーブル構造/データをエクスポートします。

   ```shell
   [xxx@xxx /ob-loader-dumper-4.0.0-RELEASE/bin]
   $./obdumper -h <ホストIP> -P <ポート> -u <ユーザー> -p <パスワード> [--sys-user <sysテナント内のユーザー名> --sys-password <sysテナント内の特定ユーザーのパスワード>] -c <クラスタ名> -t <テナント> -D <スキーマ名> [--ddl] [--csv|--sql] [--all|--table 'テーブル名'] -f <データファイルまたはディレクトリ>
   ```

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <ul>
     <li>OceanBaseの物理ノードのホストアドレスとポートを使用してデータをエクスポートする場合、<code>-c</code>オプションを指定する必要はありません。</li>
     <li>obdumperコマンドラインオプションの詳細については、<a href="https://en.oceanbase.com/docs/enterprise-oceanbase-dumper-loader-en-10000000000889516">コマンドラインオプション</a>を参照してください。</li>
     </ul>
   </main>

4. テーブル構造/データをインポートします。

   ```shell
   [xxx@xxx /ob-loader-dumper-4.0.0-RELEASE/bin]
   $./obloader -h <ホストIP> -P <ポート> -u <ユーザー> -p <パスワード>  --sys-user <sysテナント内のrootユーザーまたはproxyroユーザー> --sys-password <sysテナント内のアカウントパスワード> -c <クラスタ> -t <テナント> -D <スキーマ名> [--ddl] [--csv|--sql] [--all|--table 'テーブル名'] -f <データファイルまたはディレクトリ>
   ```

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <ul>
     <li>OceanBaseの物理ノードのホストアドレスとポートを使用してデータをインポートする場合、<code>-c</code>オプションを指定する必要はありません。</li>
     <li>obloaderコマンドラインオプションの詳細については、<a href="https://en.oceanbase.com/docs/enterprise-oceanbase-dumper-loader-en-10000000000860069">コマンドラインオプション</a>を参照してください。</li>
     </ul>
   </main>

### テーブル構造の移行

obdumperとobloaderを使用してテーブル構造を移行する場合、`--sys-user`と`--sys-password`オプションを指定してテーブル構造のメタデータ情報を取得する必要があります。これらのオプションを指定しない場合、エクスポート/インポートの機能とパフォーマンスが大幅に影響を受ける可能性があります。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><code>--sys-user</code>オプションは、<code>sys</code>テナント内で特定の権限を持つユーザーに接続するために使用されます。エクスポート時に<code>--sys-user</code>オプションを指定しない場合、デフォルトで<code>--sys-user root</code>が指定されます。</p>
  </main>
