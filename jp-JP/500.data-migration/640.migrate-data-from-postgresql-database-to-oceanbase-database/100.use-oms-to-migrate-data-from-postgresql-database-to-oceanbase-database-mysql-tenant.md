# OMSを使用してPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡潔に説明します。

## 背景

OMSコンソールでPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分同期を通じて、ソースデータベースの既存業務データおよび増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

PostgreSQLデータベースは、単一マスター、単一スタンバイ、マスタースタンバイなどのモードをサポートしています。PostgreSQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する際、異なるタイプのデータソースがサポートする操作も異なります。

| タイプ  |                          サポートされている操作                           |
|-----|----------------------------------------------------------|
| プライマリデータベースのみ | 構造移行 + フル移行 + 増分同期 + フル検証 + 反復増分                          |
| スタンバイデータベースのみ | 構造移行 + フル移行  + フル検証                                      |
| プライマリ/スタンバイデータベース | プライマリデータベース：増分同期 + 反復増分 <br>スタンバイデータベース：構造移行 + フル移行 + フル検証 |
