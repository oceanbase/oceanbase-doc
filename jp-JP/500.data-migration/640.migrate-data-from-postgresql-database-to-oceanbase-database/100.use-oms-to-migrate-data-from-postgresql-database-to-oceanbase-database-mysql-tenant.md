# OMSを使用してPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service(OMS)を使用してPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールでPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、および増分同期を通じて、ソース側データベースの既存業務データと増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

PostgreSQLデータベースは、単一のプライマリデータベース、単一のスタンバイデータベース、およびプライマリ/スタンバイデータベースなどのモードをサポートしています。PostgreSQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する際、異なるタイプのデータソースに対してサポートされる操作も異なります。

| タイプ | サポートされる操作 |
|-----|----------------------------------------------------------|
| プライマリ単一データベース | スキーマ移行 + フル移行 + 増分同期 + フル検証 + リバース増分 |
| スタンバイ単一データベース | スキーマ移行 + フル移行 + フル検証 |
| プライマリ/スタンバイデータベース | プライマリデータベース：増分同期 + リバース増分をサポート <br>スタンバイデータベース：スキーマ移行 + フル移行 + フル検証をサポート |

## 関連ドキュメント

OMSを使用してPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行するための詳細な手順については、[PostgreSQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091367)を参照してください。
