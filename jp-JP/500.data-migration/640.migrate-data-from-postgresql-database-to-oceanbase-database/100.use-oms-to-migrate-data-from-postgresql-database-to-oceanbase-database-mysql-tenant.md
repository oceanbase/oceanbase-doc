# OMSを使用してPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用して、PostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡潔に紹介します。

## 背景

OMSコンソールでPostgreSQLデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分同期を通じて、ソースデータベースの既存業務データおよび増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

PostgreSQLデータベースは、単一マスター、単一スタンバイ、マスター/スタンバイなどのモードをサポートしています。PostgreSQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する際、データソースのタイプによってサポートされる操作も異なります。

| タイプ  |                          サポートされる操作                           |
|-----|----------------------------------------------------------|
| 単一マスター | 構造移行 + フル移行 + 増分同期 + フル検証 + 反転増分                          |
| 単一スタンバイ | 構造移行 + フル移行  + フル検証                                      |
| マスター/スタンバイ | マスター：増分同期 + 反転増分 <br>スタンバイ：構造移行 + フル移行 + フル検証 |
