# リソースユニットの移行

クラスタ内の単一ゾーン内において、複数のOBServerノード間でリソースの配分が偏っている場合、テナントが使用するリソースの配分を調整することで、クラスタ全体のリソース使用量を均等化できます。

本記事では、主にSQLステートメントを使用したリソースユニットの移行方法について説明します。

  <main id="notice" >
    <h4>機能の適用範囲</h4>
    <p><code>ALTER SYSTEM MIGRATE UNIT</code> ステートメントは、sysテナントでのみ実行できます。</p>
  </main>

## 構文

```sql
ALTER SYSTEM MIGRATE UNIT [=] unit_id
    DESTINATION [=] ip_port;
```

パラメータの説明：

|   パラメータ   |               説明                |
| ------- | -------------------------------- |
| unit_id | ユニットID。                       |
| ip_port | ユニットを移行先ノードのアドレス。 |

## 例

1. リソースユニットの分布を確認する。

    以下のSQLステートメントを実行して、テナント `mysql001` のリソースユニットが各ゾーンにどのように分布しているか確認します。

    ```sql
    SELECT t.TENANT_NAME,u.ZONE,u.UNIT_ID,u.SVR_IP FROM oceanbase.DBA_OB_TENANTS t,oceanbase.DBA_OB_UNITS u WHERE t.TENANT_ID=u.TENANT_ID AND t.TENANT_NAME='mysql001';
    ```

    実行結果は次のとおりです：

    ```shell
    +-------------+-------+---------+------------+
    | TENANT_NAME | ZONE  | UNIT_ID | SVR_IP     |
    +-------------+-------+---------+------------+
    | mysql001    | zone1 |    1002 | 10.10.10.1 |
    | mysql001    | zone2 |    1004 | 10.10.10.2 |
    | mysql001    | zone3 |    1006 | 10.10.10.3 |
    +-------------+-------+---------+------------+
    3 rows in set
    ```

2. リソースユニットの移行を開始する。

    以下のSQLステートメントを実行し、テナント `mysql001` のzone3内のリソースユニットを `10.10.10.3:2882` から `10.10.10.4:2882` に移行します。

    ```sql
    ALTER SYSTEM MIGRATE UNIT = 1006 DESTINATION = '10.10.10.4:2882';
    ```

3. 移行状況を確認する。

    以下のSQLステートメントを実行して、テナント`mysql001`のリソースユニットが移行された後の各ゾーンでの分布状況を確認します。

    ```sql
    SELECT t.TENANT_NAME,u.ZONE,u.UNIT_ID,u.SVR_IP FROM oceanbase.DBA_OB_TENANTS t,oceanbase.DBA_OB_UNITS u  WHERE t.TENANT_ID=u.TENANT_ID AND t.TENANT_NAME='mysql001';
    ```

    実行結果は次のとおりです：

    ```shell
    +-------------+-------+---------+------------+
    | TENANT_NAME | ZONE  | UNIT_ID | SVR_IP     |
    +-------------+-------+---------+------------+
    | mysql001    | zone1 |    1002 | 10.10.10.1 |
    | mysql001    | zone2 |    1004 | 10.10.10.2 |
    | mysql001    | zone3 |    1006 | 10.10.10.4 |
    +-------------+-------+---------+------------+
    3 rows in set
    ```
