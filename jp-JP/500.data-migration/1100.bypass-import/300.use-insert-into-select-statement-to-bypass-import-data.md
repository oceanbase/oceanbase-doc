# INSERT INTO SELECTステートメントを使用したデータのダイレクトロード

`INSERT INTO SELECT` ステートメントは、Hintとして `append` と `enable_parallel_dml` を使用してダイレクトロードを実行します。

## 制限事項

* ダイレクトロードはPDML（Parallel Data Manipulation Language、並列データ操作言語）のみサポートしており、PDML以外の形式では利用できません。
* インポート処理中は同時に2つの書き込み操作文を実行することができません（つまり、同時に1つのテーブルに書き込むことはできません）。これは、インポート処理中にテーブルロックがかかるためであり、またインポート処理全体を通じて読み取り操作のみが可能だからです。
* トリガー（Trigger）での使用はサポートされていません。
* 生成列を含むテーブルはサポートされていません（一部のインデックスは隠れた生成列を生成します。例：KEY `idx_c2` (`c2`(16)) GLOBAL）。
* 単一行で2MBを超えるデータのインポートはサポートされていません。
* Liboblogやフラッシュバッククエリ（Flashback Query）はサポートされていません。
* `LOB`型はサポートされていますが、パフォーマンスは比較的低く、`LOB`は元のトランザクションによってデータが書き込まれた経路を使用します。
* ダイレクトロードはDDLステートメントに属し、複数の操作を含むマルチ行トランザクション内で実行することはできません。

  * BEGIN内で実行することはできません。
  * Autocommitは1に設定する必要があります。

## 構文

```sql
INSERT /*+ append enable_parallel_dml parallel(N) */ INTO  table_name select_sentence
```

`INSERT INTO`構文の詳細については、[INSERT（MySQLモード）](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5700.insert-sql-of-mysql-mode.md)および[INSERT（Oracleモード）](../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/200.insert-of-oracle-mode.md)を参照してください。

**パラメータの説明：**

|パラメータ|説明|
|------|------|
| append | ダイレクトロードを実行することを示します。|
| enable_parallel_dml parallel(N) | データの読み込み並列度。<main id="notice" type='explain'><h4>説明</h4><p>一般的に、<code>enable_parallel_dml</code> ヒントと <code>parallel</code> ヒントは組み合わせて使用する必要があります。ただし、ターゲットテーブルのスキーマでテーブルレベルの並列度が指定されている場合は、<code>enable_parallel_dml</code> ヒントのみを指定する必要があります。</p></main>|

## 例

ダイレクトロードを使用して、テーブル `tbl2` の一部データを `tbl1` にインポートします。

```shell
obclient [test]> SELECT * FROM tbl1;
Empty set

obclient [test]> SELECT * FROM tbl2;
+------+------+------+
| col1 | col2 | col3 |
+------+------+------+
|    1 | a1   |   11 |
|    2 | a2   |   22 |
|    3 | a3   |   33 |
+------+------+------+
3 rows in set

obclient [test]> INSERT /*+ append enable_parallel_dml parallel(16) */ INTO tbl1 SELECT t2.col1,t2.col3 FROM tbl2 t2;
Query OK, 3 rows affected
 Records: 3  Duplicates: 0  Warnings: 0

obclient [test]> SELECT * FROM tbl1;
+------+------+
| col1 | col2 |
+------+------+
|    1 |   11 |
|    2 |   22 |
|    3 |   33 |
+------+------+
3 rows in set
```
