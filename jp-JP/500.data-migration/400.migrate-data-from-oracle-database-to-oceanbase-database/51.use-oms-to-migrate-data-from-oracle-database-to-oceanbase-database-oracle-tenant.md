# OMSを使用してOracleデータベースからOceanBaseデータベースのOracleテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用して、OracleデータベースからOceanBaseデータベースのOracleテナントへデータを移行する際の背景情報について簡潔に紹介します。

## 背景情報

OMSコンソールでOracleデータベースからOceanBaseデータベースのOracleテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分データ同期を通じて、データ送信元データベースの既存業務データおよび増分データをOceanBaseデータベースのOracleテナントへシームレスに移行できます。

Oracleデータベースは、単一マスター、単一スタンバイ、マスタースタンバイなどのモードをサポートしています。OracleデータベースのデータをOceanBaseデータベースのOracleテナントに移行する際、データソースのタイプによってサポートされる操作も異なります。

| タイプ  |                           サポートされる操作                           |
|-----|-----------------------------------------------------------|
| プライマリデータベースのみ | 構造移行 + フル移行 + 増分同期 + フル検証 + 反復増分                           |
| スタンバイデータベースのみ | 構造移行 + フル移行 + 増分同期 + フル検証                                 |
| プライマリ/スタンバイデータベース | プライマリデータベース：反復増分をサポート スタンバイデータベース：構造移行 + フル移行 + 増分同期 + フル検証 |
