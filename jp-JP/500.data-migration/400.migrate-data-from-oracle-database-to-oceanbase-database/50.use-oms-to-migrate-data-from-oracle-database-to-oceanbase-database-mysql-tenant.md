# OMSを使用してOracleデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してOracleデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡潔に紹介します。

## 背景

OMSコンソールでOracleデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分データ同期を通じて、ソースデータベースの既存業務データおよび増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

Oracleデータベースは、単一マスター、単一スタンバイ、マスター/スタンバイなどのモードをサポートしています。OracleデータベースのデータをOceanBaseデータベースのMySQLテナントに移行する際、データソースのタイプによってサポートされる操作も異なります。

| タイプ  |                           サポートされる操作                           |
|-----|-----------------------------------------------------------|
| プライマリデータベースのみ | 構造移行 + フル移行 + 増分同期 + フル検証 + 反復増分                           |
| スタンバイデータベースのみ | 構造移行 + フル移行 + 増分同期 + フル検証                                 |
| プライマリ/スタンバイデータベース | プライマリデータベース：反復増分をサポート スタンバイデータベース：構造移行 + フル移行  + 増分同期 + フル検証 |
