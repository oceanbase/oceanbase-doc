# OMSを使用してOceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行する

本記事では、OceanBase Migration Service(OMS)を使用してOceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行するための背景情報について簡単に説明します。

## 背景

OMSコンソールでOceanBaseデータベースのOracleテナントからDB2 LUWデータベースへのデータ移行プロジェクトを作成すると、構造移行、フル移行、および増分同期を通じて、ソース側のOceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行するための詳細な操作手順については、[OceanBaseデータベースのOracleテナントからDB2 LUWデータベースへのデータ移行](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091372)を参照してください。
