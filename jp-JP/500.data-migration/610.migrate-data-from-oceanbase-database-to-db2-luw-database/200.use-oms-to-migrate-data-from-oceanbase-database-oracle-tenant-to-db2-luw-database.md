# OMSを使用してOceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用して、OceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行する背景情報について簡潔に説明します。

## 背景情報

OMSコンソールで、OceanBaseデータベースのOracleテナントからDB2 LUWデータベースへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分同期を通じて、データ送信元のOceanBaseデータベースのOracleテナント内のデータをDB2 LUWデータベースに移行できます。

## 関連ドキュメント

OMSを使用して、OceanBaseデータベースのOracleテナントからDB2 LUWデータベースへデータを移行する操作の詳細については、[OceanBaseデータベースのOracleテナントデータをDB2 LUWデータベースに移行する](https://docs.oceanbase.com/oms/V4.0.2-create-a-project-to-migrate-data-from-an-oracle-tenant-of-oceanbase-database-to-a-db2-luw-database)を参照してください。
