# OMSを使用してOceanBaseデータベースのMySQLテナントからDB2 LUWデータベースへデータを移行する

本記事では、OceanBase Migration Service(OMS)を使用してOceanBaseデータベースのMySQLテナントからDB2 LUWデータベースへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールでOceanBaseデータベースのMySQLテナントからDB2 LUWデータベースへのデータ移行プロジェクトを作成すると、構造移行、フル移行、および増分同期を通じて、ソース側のOceanBaseデータベースのMySQLテナントからDB2 LUWデータベースへデータを移行できます。

## 関連ドキュメント

OMSを使用してOceanBaseデータベースのMySQLテナントからDB2 LUWデータベースへデータを移行する手順の詳細については、[OceanBaseデータベースのMySQLテナントのデータをDB2 LUWデータベースに移行する](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091368)を参照してください。
