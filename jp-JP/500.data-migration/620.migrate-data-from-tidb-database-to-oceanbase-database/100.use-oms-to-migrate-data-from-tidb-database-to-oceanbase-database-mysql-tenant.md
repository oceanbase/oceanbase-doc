# OMSを使用してTiDBデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してTiDBデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSは、ソース側のTiDBデータベースからターゲット側のOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトの作成をサポートしています。構造移行、フル移行、増分同期などを通じて、ソース側データベースの既存業務データおよび増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

TiDBデータベースは、オンライントランザクション処理とオンライン分析処理（Hybrid Transactional and Analytical Processing、HTAP）をサポートする統合型分散データベース製品です。TiDBデータベースからOceanBaseデータベースのMySQLテナントへの増分データ同期を実現するためには、TiCDCクラスタとKafkaクラスタをデプロイする必要があります。

<!-- ![tidb-system-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/tidb-system-zh.png) -->

TiCDCは、TiDBデータベースの増分データ同期ツールであり、PDクラスタ（TiDBクラスタのスケジューリングモジュールで、通常3つのPDノードで構成される）を通じて高可用性を実現します。TiKV Serverは、TiDBクラスタ内のTiKVノードであり、変更ログ形式で変更データをTiCDCクラスタに積極的に送信します。TiCDCツールは、複数のTiCDCプロセスを通じてTiKVノードのデータを取得し、処理した後、Kafkaクラスタに同期します。Kafkaクラスタは、TiCDCツールによって変換されたTiDBデータベースの増分ログ情報を保存し、OMSが増分データ同期を実行する際に、Kafkaクラスタから対応するデータを取得し、リアルタイムでOceanBaseデータベースのMySQLテナントに移行できるようにします。新規のTiDBデータソースを作成する際に、Kafkaデータソースをバインドしなかった場合、増分同期を行うことができません。
