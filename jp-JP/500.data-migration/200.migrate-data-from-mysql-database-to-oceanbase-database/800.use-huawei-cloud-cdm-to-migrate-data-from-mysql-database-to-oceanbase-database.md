# Huawei Cloud CDMを使用したMySQLからOceanBase MySQLへのデータ移行

Huawei Cloud CDM(Cloud Data Migration)は、Huawei Cloudが提供するデータ移行サービスであり、さまざまなデータソース間のデータ移行をサポートしています。Huawei Cloud CDMは、MySQLコネクタを介してOceanBaseデータベースに接続し、MySQLからOceanBase MySQLへのデータ移行を実現します。

## バージョン互換性

| コンポーネント | 説明 |
|------|------|
| OceanBaseデータベース | ≥ V4.2.3.0 |

## 前提条件

Huawei Cloud CDMを使用する前に、以下の点を確認してください：
* Huawei Cloud CDMを購入済みであること。詳細については、[Huawei Cloud CDM公式ドキュメント](https://support.huaweicloud.com/productdesc-cdm/cdm_01_0143.html)を参照してください。
* OceanBaseデータベースのデプロイが完了し、MySQLモードのユーザーテナントが作成されていること。テナント作成の詳細については、[テナントの作成](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)を参照してください。
* ターゲット側のOceanBaseデータベースとテーブルが事前に作成されていること。

## 手順

### ステップ1：OceanBaseデータベースの接続文字列を取得する

OceanBaseデータベースのデプロイ担当者から接続文字列を取得します。例：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**
* `$host`：接続IPアドレス。ODP接続の場合はODPアドレスを、直接接続の場合はOBServer IPアドレスを使用します。
* `$port`：接続ポート。ODPのデフォルトは`2883`、直接接続のデフォルトは`2881`です。
* `$database_name`：データベース名。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>テナントに接続するユーザーは、データベースに対する <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および <code>SELECT</code> 権限が付与されていなければなりません。その他のユーザー権限の詳細については、<a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQLモードの権限分類</a>を参照してください。</p>
    </main>
* `$user_name`：接続アカウント。ODP形式：`ユーザー@テナント#クラスタ`または`クラスタ:テナント:ユーザー`、直接接続形式：`ユーザー@テナント`。
* `$password`：アカウントのパスワード。

接続文字列の詳細については、[OBClientを使用してOceanBaseテナントに接続する](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)を参照してください。

**例：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### ステップ2：データソースを設定する

1. Huawei Cloud CDMコンソールにログインし、クラスタ管理ページに移動します。
2. **<UI-TERM key="src.pages.List.NewBtn.D73F5BB8">データソースを作成する</UI-TERM>** をクリックし、**MySQL** コネクタタイプを選択します。
3. データソースの基本情報を入力します：
   * **<UI-TERM key="src.page.Secure.Record.RecordPage.14735BCB">データソース名</UI-TERM>**：カスタム名を入力します。例：`ob_source`。
   * **<UI-TERM key="oat.src.constants.config.ServerAddress">サーバーアドレス</UI-TERM>**：OceanBase接続IPアドレスを入力します。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>PrivateLinkを使用してHuawei Cloud OceanBaseに接続する場合は、ドメイン名ではなくエンドポイントIPアドレスを入力してください。</p>
    </main>
   * **<UI-TERM key="oms-v2.Endpoint.components.SybaseForm.Port">ポート</UI-TERM>**：OceanBase接続ポートを入力します。デフォルトは`2881`（直接接続）または`2883`（ODP）です。
   * **<UI-TERM key="oas.Optimization.History.DatabaseName">データベース名</UI-TERM>**：データベース名を入力します。
   * **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.Username">ユーザー名</UI-TERM>**：接続アカウントを入力します。
   * **<UI-TERM key="obcloud-console.MyComponents.MyProfile.Password">パスワード</UI-TERM>**：アカウントのパスワードを入力します。
4. **詳細なプロパティ** で、パフォーマンス要件に応じて以下のパラメータを調整できます：
   * **1回のコミット行数**：ソース側から指定された数の行を取得した後、宛先側にコミットします。デフォルト値はパフォーマンス向上のため調整可能です。
   * **1回の書き込み行数**：毎回宛先側に書き込む行数です。デフォルト値はパフォーマンス向上のため調整可能です。
5. **<UI-TERM key="oms-community.OCP.components.OCPForm.TestConnection">接続テスト</UI-TERM>** をクリックし、接続が成功したことを確認したらデータソースを保存します。

### ステップ3：移行ジョブを作成する

1. CDMコンソールで、**<UI-TERM key="src.components.TaskPageContainer.5022C5AA">ジョブを作成する</UI-TERM>** をクリックします。
2. ジョブタイプを **テーブル/ファイル移行** に選択します。
3. ソース側と宛先側を設定します：
   * **<UI-TERM key="src.components.DatasourceSelector.C4C45190">ソースデータソース</UI-TERM>**：作成済みのMySQLソースデータソースを選択します。
   * **宛先データソース**：作成済みのOceanBase宛先データソースを選択します。
4. ジョブパラメータを設定します：
   * 移行するデータベースとテーブルを選択します。
   * **ジョブ設定** で、**並列スレッド** 数を増やして移行パフォーマンスを向上させることができます。
5. ジョブ設定を保存します。

### ステップ4：移行を実行する

1. ジョブリストで、作成済みの移行ジョブを選択します。
2. **開始** をクリックして、データ移行を開始します。
3. ジョブの実行状態を監視し、移行完了を待ちます。

## 結果の検証

1. 宛先側のOceanBaseデータベースにログインします。
2. 以下のSQLステートメントを実行して、データが正常に移行されたかどうかを検証します：

   ```sql
   SELECT COUNT(*) FROM $database_name.$table_name;
   ```

3. ソース側と宛先側のデータレコード数を比較し、データの一貫性を確認します。

## よくある質問

**Q1：ローカルAPIモードで移行時に構文エラーが発生した場合はどうすればよいですか？**

**原因**：ローカルAPIモードで生成されたSQL構文がOceanBaseと互換性がないためです。例えば、区切り文字の構文 `fields terminated by X'0203'` はOceanBaseではサポートされていません。

**解決策**：データソースを作成する際に、ローカルAPIモードではなく **SQLモード** を選択してください。

**Q2：データソースのテスト接続は成功したのですが、移行先として選択できません。どうすればよいですか？**

**原因**：CDMクラスタのバージョンが原因である可能性があります。

**解決策**：CDMクラスタのバージョンを変更してみるか、Huawei Cloudサポートチームにお問い合わせください。
