# OMSを使用してMySQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してMySQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールで、自社構築のMySQLデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成します。構造移行、フル移行、および増分同期を通じて、ソース側データベースの既存業務データと増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

MySQLデータベースは、単一のプライマリデータベース、単一のスタンバイデータベース、およびプライマリ/スタンバイデータベースなどのモードをサポートしています。MySQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する際、異なるタイプのデータソースに対してサポートされる操作も異なります。

| タイプ |                          サポートされる操作                           |
|-----|----------------------------------------------------------|
| プライマリストア | スキーマ移行 + フル移行 + 増分同期 + フル検証 + リバース増分                          |
| スタンバイストア | スキーマ移行 + フル移行  + フル検証                                      |
| プライマリ/スタンバイストア | プライマリストア：増分同期 + リバース増分をサポート スタンバイストア：スキーマ移行 + フル移行 + フル検証をサポート |
