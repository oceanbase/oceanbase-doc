# OMSを使用してMySQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してMySQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する背景について簡潔に紹介します。

## 背景

OMSコンソールで、自社構築のMySQLデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、スキャラーマイグレーション、フルマイグレーション、増分同期を通じて、ソースデータベースの既存業務データと増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

MySQLデータベースは、単一マスター、単一スタンバイ、マスタースタンバイなどのモードをサポートしています。MySQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する際、異なるタイプのデータソースがサポートする操作も異なります。

| タイプ  |                          サポートされる操作                           |
|-----|----------------------------------------------------------|
| プライマリデータベースのみ | 構造移行 + フル移行 + 増分同期 + フル検証 + 反復増分                          |
| スタンバイデータベースのみ | 構造移行 + フル移行  + フル検証                                      |
| プライマリ/スタンバイデータベース | プライマリデータベース：増分同期 + 反復増分 スタンバイデータベース：構造移行 + フル移行 + フル検証 |
