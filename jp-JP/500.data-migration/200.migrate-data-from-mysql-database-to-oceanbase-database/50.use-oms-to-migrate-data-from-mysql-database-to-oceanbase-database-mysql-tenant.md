# OMSを使用してMySQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してMySQLデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する際の背景情報について簡潔に紹介します。

## 背景

OMSコンソールで、自社構築のMySQLデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、スキャナー移行、フル移行、増分同期を通じて、ソースデータベースの既存業務データおよび増分データをOceanBaseデータベースのMySQLテナントへシームレスに移行できます。

MySQLデータベースは、単一マスター、単一スタンバイ、マスタースタンバイなどのモードをサポートしています。MySQLデータベースのデータをOceanBaseデータベースのMySQLテナントへ移行する際、データソースのタイプによってサポートされる操作も異なります。

| タイプ  |                          サポートされる操作                           |
|-----|----------------------------------------------------------|
| 単一マスター | スキャナー移行 + フル移行 + 増分同期+ フル検証 + 反転増分                          |
| 単一スタンバイ | スキャナー移行 + フル移行  + フル検証                                      |
| マスタースタンバイ | マスター：増分同期 + 反転増分 スタンバイ：スキャナー移行 + フル移行 + フル検証 |
