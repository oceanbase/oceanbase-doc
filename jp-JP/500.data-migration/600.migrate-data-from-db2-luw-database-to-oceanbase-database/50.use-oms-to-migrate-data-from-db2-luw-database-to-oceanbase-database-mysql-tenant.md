# OMSを使用してDB2 LUWデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してDB2 LUWデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する背景について簡単に紹介します。

## 背景

OMSコンソールでDB2 LUWデータベースからOceanBaseデータベースのMySQLテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分同期を通じて、ソース側のDB2 LUWデータベースのデータをOceanBaseデータベースのMySQLテナントに移行できます。

## 関連ドキュメント

OMSを使用してDB2 LUWデータベースからOceanBaseデータベースのMySQLテナントへデータを移行する操作の詳細については、[DB2 LUWデータベースのデータをOceanBaseデータベースのMySQLテナントに移行する](https://en.oceanbase.com/docs/enterprise-oms-doc-en-10000000000888396)を参照してください。
