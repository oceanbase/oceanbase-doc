# OMSを使用してDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行する際の背景情報について簡単に説明します。

## 背景

OMSコンソールで、DB2 LUWデータベースからOceanBaseデータベースのOracleテナントへのデータ移行プロジェクトを作成します。構造移行、フル移行、および増分同期を通じて、ソース側のDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行できます。

## 関連ドキュメント

OMSを使用してDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行する操作の詳細については、[DB2 LUWデータベースのデータをOceanBaseデータベースのOracleテナントに移行する](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000091362)を参照してください。
