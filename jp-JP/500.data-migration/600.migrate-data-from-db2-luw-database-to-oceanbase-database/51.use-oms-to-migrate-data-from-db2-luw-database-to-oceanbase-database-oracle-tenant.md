# OMSを使用してDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行する

本記事では、OceanBase Migration Service（OMS）を使用してDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行する際の背景情報について簡潔に説明します。

## 背景情報

OMSコンソールでDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへのデータ移行プロジェクトを作成すると、構造移行、フル移行、増分同期を通じて、データ送信元のDB2 LUWデータベースのデータをOceanBaseデータベースのOracleテナントに移行できます。

## 関連ドキュメント

OMSを使用してDB2 LUWデータベースからOceanBaseデータベースのOracleテナントへデータを移行する操作の詳細については、[DB2 LUWデータベースのデータをOceanBaseデータベースのOracleテナントに移行する](https://docs.oceanbase.com/oms/V4.0.2-create-a-project-to-migrate-data-from-a-db2-luw-database-to-an-oracle-tenant-of-oceanbase-database)を参照してください。
