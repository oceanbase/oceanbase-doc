# アップグレード後のチェック

本記事では、OceanBaseクラスタのアップグレード完了後に行う状態チェックについて説明します。

## 手順

1. OceanBaseデータベースにログインします。

   **例：**

   `root`ユーザーを使用して`sys`テナントに接続します。

   ```shell
   obclient -h10.10.10.1 -P2881 -uroot@sys -p******
   ```

2. ビューを使用して、クラスタのアップグレード関連イベント情報を確認します。

   **例：**

   ```sql
   SELECT * FROM oceanbase.DBA_OB_CLUSTER_EVENT_HISTORY WHERE MODULE='UPGRADE'\G
   ```
