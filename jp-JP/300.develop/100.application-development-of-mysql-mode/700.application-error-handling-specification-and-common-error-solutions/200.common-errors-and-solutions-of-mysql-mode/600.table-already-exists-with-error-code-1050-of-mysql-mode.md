# テーブル作成時にテーブルが既に存在している場合、エラーコードERROR 1050

本記事では、OceanBaseデータベースのMySQLモードでテーブルを作成する際に、テーブルが既に存在しているため`ERROR 1050`エラーが発生した場合の対処方法について説明します。

## 現象

`student`テーブルを作成する際、システムからテーブルが既に存在しているというエラーが表示されます。

```sql
obclient> CREATE TABLE student(
     id int ,
     name varchar(18),
     sex char(1),
     age int,
     address varchar(200),
       email varchar(100),
      date date,
      PRIMARY KEY (id)
       );
ERROR 1050 (42S01): Table 'student' already exists
```

このエラー情報に対応するエラーコードは以下の通りです：

* エラーコード：ERROR 1050

* OceanBaseエラーコード：5020

* MySQL互換エラーコード：1050

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/600.error-code-of-mysql-mode/100.use-error-information-of-mysql-mode.md)を参照してください。

## 考えられる原因

テーブル作成時に`IF NOT EXISTS`キーワードを追加していないため、作成しようとしているテーブルが既に存在する場合、システムはエラーを報告します。

## 解決策

以下の手順に従って、テーブルが実際に存在するかどうか確認し、既存のテーブルをリネームしてから再度テーブルを作成してください。

1. データベース内にそのテーブルが既に存在するかどうか確認します。例：

   ```sql
   obclient> SHOW TABLES;
   +----------------+
   | Tables_in_test |
   +----------------+
   | student        |
   +----------------+
   1 row in set
   ```

2. 重複するテーブルが存在する場合は、既存のテーブルをリネームしてから再度テーブルを作成できます。

   例えば、元の`student`テーブルを`t_stu`テーブルに変更します。

   ```sql
   obclient> ALTER TABLE student RENAME TO t_stu;
   Query OK, 0 rows affected
   ```
