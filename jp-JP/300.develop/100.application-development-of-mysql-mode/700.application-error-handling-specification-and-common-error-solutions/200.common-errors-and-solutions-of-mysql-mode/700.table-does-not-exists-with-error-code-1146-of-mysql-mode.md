# テーブルのクエリ時にテーブルが存在しない場合、エラーコードERROR 1146

本記事では、OceanBaseデータベースのMySQLモードでテーブルをクエリした際にテーブルが存在せず、`ERROR 1146` エラーが発生した場合の対処方法について説明します。

## 現象

`student` テーブルをクエリすると、テーブルが存在しないと表示されます。

```sql
obclient> desc student;
ERROR 1146 (42S02): Table 'test.student' doesn't exist
```

このエラーメッセージに対応するエラーコード情報は次のとおりです：

* エラーコード：ERROR 1146

* OceanBaseエラーコード：5019

* MySQL互換エラーコード：1146

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/600.error-code-of-mysql-mode/100.use-error-information-of-mysql-mode.md)を参照してください。

## 考えられる原因

テーブル操作を行う際、操作対象のテーブルが存在しない場合、システムはエラーを報告します。

## 解決策

以下の手順を参照して、テーブルが存在するかどうか確認し、必要に応じて対応するテーブルを作成してください。

1. 現在のデータベース内にそのテーブルが存在するかどうか確認します。例：

   ```sql
   obclient> SHOW TABLES;
   +----------------+
   | Tables_in_test |
   +----------------+
   | ordr           |
   +----------------+
   1 row in set
   ```

2. テーブルが存在しない場合は、`CREATE TABLE` を使用して必要なテーブルを作成できます。例：

   ```sql
   CREATE TABLE student(
   id int,
   name varchar(18),
   sex char(1),
    age int,
    address varchar(200),
     email varchar(100),
    date date,
    PRIMARY KEY (id)
     );
   ```

3. 必要なテーブルをクエリします。

   ```sql
   obclient> desc student;
   +---------+--------------+------+-----+---------+-------+
   | Field   | Type         | Null | Key | Default | Extra |
   +---------+--------------+------+-----+---------+-------+
   | id      | int(11)      | NO   | PRI | NULL    |       |
   | name    | varchar(18)  | YES  |     | NULL    |       |
   | sex     | char(1)      | YES  |     | NULL    |       |
   | age     | int(11)      | YES  |     | NULL    |       |
   | address | varchar(200) | YES  |     | NULL    |       |
   | email   | varchar(100) | YES  |     | NULL    |       |
   | date    | date         | YES  |     | NULL    |       |
   +---------+--------------+------+-----+---------+-------+
   7 rows in set
   ```
