# 外部キーを追加する際にエラーが発生し、エラーコードERROR 1215

本記事では、OceanBaseデータベースのMySQLモードで外部キーを追加する際に`ERROR 1215`エラーが発生した場合の対処方法について説明します。

## 現象

`cust`テーブルに外部キー制約を作成する際、関連フィールドのエラーが表示されます。

```sql
obclient> ALTER TABLE cust ADD CONSTRAINT c_fk FOREIGN KEY (c_w_id) REFERENCES ware(w_name);
ERROR 1215 (HY000): Cannot add foreign key constraint
```

このエラーメッセージに対応するエラーコード情報は次のとおりです：

* エラーコード：ERROR 1215

* OceanBaseエラーコード：5317

* MySQL互換エラーコード：1215

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/600.error-code-of-mysql-mode/100.use-error-information-of-mysql-mode.md)を参照してください。

## 考えられる原因

* 外部キー制約を追加する際、外部キーのフィールドと関連フィールドの型がマッチしない場合、システムはエラーを報告します。

* 外部キーを追加する際、参照される親テーブルの列が主キーまたは一意インデックスでない場合、システムはエラーを報告します。

## 解決策

次の手順を参照して、現在のテーブルと関連テーブルの各フィールドタイプを確認し、関連テーブルの主キーを確認した後、外部キー制約を再作成してください。

1. `ware`テーブルと`cust`テーブルのテーブル構造を確認し、関連テーブルの主キーを見つけます。

   ```sql
   obclient> DESC ware;
   +--------+--------------+------+-----+---------+-------+
   | Field  | Type         | Null | Key | Default | Extra |
   +--------+--------------+------+-----+---------+-------+
   | w_id   | int(11)      | NO   | PRI | NULL    |       |
   | w_name | varchar(256) | YES  | UNI | NULL    |       |
   | w_city | varchar(256) | YES  | UNI | NULL    |       |
   +--------+--------------+------+-----+---------+-------+
   3 rows in set

   obclient> DESC cust;
   +--------+---------+------+-----+---------+-------+
   | Field  | Type    | Null | Key | Default | Extra |
   +--------+---------+------+-----+---------+-------+
   | c_id   | int(11) | NO   | PRI | NULL    |       |
   | c_w_id | int(11) | YES  |     | NULL    |       |
   +--------+---------+------+-----+---------+-------+
   2 rows in set
   ```

2. テーブル`cust`の外部キー制約を再作成します。

   ```sql
   obclient> ALTER TABLE cust ADD CONSTRAINT c_fk FOREIGN KEY (c_w_id) REFERENCES ware(w_id);
   Query OK, 0 rows affected
   ```
