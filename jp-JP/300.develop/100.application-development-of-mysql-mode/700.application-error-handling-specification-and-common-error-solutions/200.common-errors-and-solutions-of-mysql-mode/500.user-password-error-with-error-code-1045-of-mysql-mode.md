# ユーザーのパスワードが誤っている。エラーコード：ERROR 1045

本記事では、OceanBaseデータベースのMySQLモードにおいて、ユーザーのパスワード入力が誤った場合に表示される`ERROR 1045`エラーの処理方法について説明します。

## 現象

ユーザーがデータベースにログインしようとした際、パスワードを忘れていたため、パスワード入力が誤りとなり、エラーが発生しました。

```sql
[admin@k08j13249.eu95sqa /home/admin]
$obclient -hxx.xx.xx.1 -P2881 -uny1@MySQL -p**8*** -A
ERROR 1045 (42000): Access denied for user 'ny1'@'xxx.xxx.xxx.xxx' (using password: YES)
```

このエラーメッセージに対応するエラーコードは以下の通りです：

* エラーコード：ERROR 1045

* OceanBaseエラーコード：4043

* MySQL互換エラーコード：1045

エラーコードの詳細については、[エラーコードの概要](../../../../700.reference/900.error-code/600.error-code-of-mysql-mode/100.use-error-information-of-mysql-mode.md)を参照してください。

## 解決策

以下の手順に従って、ユーザーのパスワードを変更し、再度ログインしてください。

1. 管理者ユーザーでクラスタの該当するテナントにログインします。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>ユーザーのパスワード変更操作は通常管理者が行います。一般ユーザーが他のユーザーのパスワードを変更するには、グローバルな <code>CREATE USER</code> 権限が必要です。 </p>
   </main>

2. ユーザー`ny1`のパスワードを変更します。

   ```sql
   obclient> ALTER USER 'ny1' IDENTIFIED BY '**8***';
   Query OK, 0 rows affected
   ```

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>ユーザーにパスワードを設定する際、そのパスワードは現在のテナントのパスワード複雑性要件を満たしている必要があります。パスワード複雑性に関する操作や説明については、<a href="../../../../600.manage/500.security-and-permissions/200.identification-and-authentication/100.identification-and-authentication-of-mysql-mode/200.password-complexity-of-mysql-mode.md">パスワード複雑性</a>を参照してください。</p>
   </main>

3. 再び`ny1`ユーザーを使用して、クラスタの`MySQL`テナントにログインします。

   ```sql
   [admin@k08j13249.eu95sqa /home/admin]
   $obclient -h10.10.10.1 -P2881 -uny1@MySQL -p****** -A
   ```
