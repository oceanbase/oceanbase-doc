# データの挿入時にデータが切り捨てられ、エラーコードERROR 1265が発生する

本記事では、OceanBaseデータベースのMySQLモードでデータを挿入する際にデータが切り捨てられ、`ERROR 1265` エラーが報告される場合の対処方法について説明します。

## 現象

テーブル `ty` にデータを挿入する際、データが切り捨てられたことを示すエラーが報告されます。

```sql
obclient> INSERT INTO ty VALUE('1970-01-01');
ERROR 1265 (01000): Data truncated for argument
```

このエラーメッセージに対応するエラーコードは以下のとおりです：

* エラーコード：ERROR 1265

* OceanBaseエラーコード：4249

* MySQL互換エラーコード：1265

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/600.error-code-of-mysql-mode/100.use-error-information-of-mysql-mode.md) を参照してください。

## 考えられる原因

データを挿入する際、挿入値の長さが特定の列で許可されている最大長を超えると、データが切り捨てられ、エラーが報告されます。

## 解決策

次の手順を参照して、現在のテーブルの各フィールドタイプと長さを確認した後、正しい値を再度挿入してください。

1. 現在のテーブル `ty` のテーブル構造を確認します。

   ```sql
   obclient> DESC ty;
   +-------+---------+------+-----+---------+-------+
   | Field | Type    | Null | Key | Default | Extra |
   +-------+---------+------+-----+---------+-------+
   | c1    | year(4) | YES  |     | NULL    |       |
   +-------+---------+------+-----+---------+-------+
   1 row in set
   ```

2. フィールドタイプに応じて正しい値を挿入します。

   ```sql
   obclient> INSERT INTO ty VALUE('1970');
   Query OK, 1 row affected
   ```

3. 挿入されたデータを確認します。データの挿入に成功しました。

   ```sql
   obclient> SELECT * FROM ty;
   +------+
   | c1   |
   +------+
   | 1970 |
   +------+
   1 row in set
   ```
