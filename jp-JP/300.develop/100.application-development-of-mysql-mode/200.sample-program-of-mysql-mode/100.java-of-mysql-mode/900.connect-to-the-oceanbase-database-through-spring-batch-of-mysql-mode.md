# SpringBatchによるOceanBaseデータベースへの接続

本記事では、SpringBatchによる接続例を紹介します。

## 環境構成

* JDK1.8

* OceanBase 3.x（MySQLモード/Oracleモード）

* Spring Bootに基づき、Spring Batchを統合

## 依存関係の設定

```xml
  <dependency>
   <groupId>org.springframework.boot</groupId>
   <artifactId>spring-boot-starter-batch</artifactId>
  </dependency>
  <!--データベースドライバー-->
  <dependency>
   <groupId>mysql</groupId>
   <artifactId>mysql-connector-java</artifactId>
   <version>8.0.25</version>
  </dependency>
  <!--接続プール-->
  <dependency>
   <groupId>com.alibaba</groupId>
   <artifactId>druid</artifactId>
   <version>1.1.22</version>
  </dependency>
  <!--エンティティクラスに基づく自動テーブル作成-->
  <dependency>
   <groupId>org.springframework.boot</groupId>
   <artifactId>spring-boot-starter-data-jpa</artifactId>
  </dependency>

  <!--spring-bootコアおよびその他の依存関係は省略します。......-->
```

## サンプルコード

データを書き込むために、データベースの書き込みクラスメソッドを呼び出します。具体的な手順は以下のとおりです：

1. 必要なクラスを作成します。

   エンティティクラス：`People` と `PeopleDESC`。

   ```java
   //基本的なpeopleクラス

   @Entity
   @Table(name = "PEOPLE")
   public class People {
       @Id
       @GeneratedValue
       private int id;
       private String lastName;
       private String firstName;
       //。。。。。。略
   }
   ```

   ```java
   //加工後のpeopledescクラス（descプロパティを追加）

   @Entity
   @Table(name = "OK_PEOPLE")
   public class PeopleDESC {

       @Id
       @GeneratedValue  //strategy = AUTO / IDENTITY / SEQUENCE  3種類の主キー生成戦略はいずれもサポートされていません
       private int id;
       private String lastName;
       private String firstName;
       private String desc1;
       //。。。。。。略
   }
   ```

   バッチ処理クラス：`AddPeopleDescProcessor` と `AddDescPeopleWriter`。

   ```java
   //peopleにdescプロパティを追加し、peopledescクラスを返すプロセッサ

   public class AddPeopleDescProcessor implements ItemProcessor<People, PeopleDESC> {

       public PeopleDESC process(People item) throws Exception {

           return new PeopleDESC(item.getId() ,
                                 item.getLastName(),
                                 item.getFirstName(),
                                 Thread.currentThread().getName());
       }
   }
   ```

2. peopledescをデータベースに書き込むクラスを作成します。

   ```java
   //peopledescをデータベースに書き込むクラス

   public class AddDescPeopleWriter implements ItemWriter<PeopleDESC> {
       private JdbcTemplate jdbcTemplate;
       public void setDataSource(DataSource dataSource) {
           this.jdbcTemplate = new JdbcTemplate(dataSource);
       }

       public JdbcTemplate getJdbcTemplate() {
           return jdbcTemplate;
       }

       public void write(List<? extends PeopleDESC> items) throws Exception {
           for (PeopleDESC peopleDESC : items) {
               this.jdbcTemplate
                       .update("insert into ok_people (id,first_name,last_name,desc1) values (?, ?, ?, ?)",
                               peopleDESC.getId(), peopleDESC.getFirstName(),
                               peopleDESC.getLastName(), peopleDESC.getDesc());
           }
       }
   }
   ```

3. プロジェクト `spring-data-jpa` を起動すると、エンティティクラス `People` および `PeopleDESC` に基づいて自動的にテーブルが作成されます。サンプル結果は以下のとおりです。

5. バッチ処理メソッドを実行します。

   ```java
    public void writerTest() throws Exception {
           //peopleテーブルの結果セットを取得する
           String sql = "select * from people;";
           preparedStatement = dataSource.getConnection().prepareStatement(sql);
           ResultSet resultSet = preparedStatement.executeQuery();
           List list = new ArrayList<PeopleDESC>();
           //descプロパティを追加するプロセッサに基づいて結果セットを加工し、List<PeopleDESC>としてカプセル化する
           while (resultSet.next()){
               People people = peopleRowMapper.mapRow(resultSet, resultSet.getRow());
               PeopleDESC desc = addPeopleDescProcessor.process(people);
               list.add(desc);
           }
           //データベースの書き込みクラスメソッドを呼び出してデータを書き込む
           addDescPeopleWriter.setDataSource(dataSource);
           addDescPeopleWriter.write(list);
       }
   ```
