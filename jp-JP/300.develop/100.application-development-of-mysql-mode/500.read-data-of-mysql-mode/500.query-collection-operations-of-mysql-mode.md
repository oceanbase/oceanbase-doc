# 集合演算

OceanBaseデータベースのMySQLモードでは、集合演算子 `UNION`、`UNION ALL`、`INTERSECT`、および `MINUS | EXCEPT` を使用して複数のクエリを組み合わせることができます。これらの集合演算子はすべて同じ優先順位を持ちます。SQLステートメントに複数の集合演算子が含まれる場合、OceanBaseデータベースは、括弧で演算順序を明示的に指定しない限り、左から右の順に評価します。

本記事では、集合演算子 `UNION`、`UNION ALL`、`INTERSECT`、および `MINUS` の使用方法について説明します。

## 構文

```sql
select_clause_set_left
{ UNION | UNION ALL | MINUS | INTERSECT}
select_clause_set_right
```

集合クエリ構文の詳細については、[UNION句](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8100.select-of-mysql-mode/400.union-clause-of-mysql-mode.md)を参照してください。

**パラメータの説明：**

* `select_clause_set_left`：`SELECT` ステートメントで、集合演算の左側のセットを返します。
* `select_clause_set_right`：`SELECT` ステートメントで、集合演算の右側のセットを返します。
* `UNION`：2つ以上の `SELECT` ステートメントの結果セットを1つのセットに結合し、重複行を除去します。
* `UNION ALL`：2つ以上の `SELECT` ステートメントの結果セットを1つのセットに結合し、重複行を除去しません。
* `INTERSECT`：2つの `SELECT` ステートメントの結果セットの共通部分を返します。
* `MINUS | EXCEPT`：最初の `SELECT` ステートメントの結果セットから、2番目の `SELECT` ステートメントの結果セットに含まれない行を返します。`MINUS` は `EXCEPT` の同義語です。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>各集合演算子は、<code>SELECT</code> ステートメントの結果セットに対してのみ操作でき、各結果セットの列数とデータ型は同じでなければなりません。</p>
</main>

## 例

テストテーブル `test_tbl1` と `test_tbl2` があり、データは以下のとおりです。

```shell
obclient [test]> SELECT * FROM test_tbl1;
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
6 rows in set

obclient [test]> SELECT * FROM test_tbl2;
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
6 rows in set
```

### UNIONの例

以下のSQLステートメントでは、`UNION` を使用して2つの `SELECT` ステートメントの結果セットを1つのセットに結合し、重複行を除去します。

```sql
SELECT id, name FROM test_tbl1
UNION
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
9 rows in set
```

### UNION ALLの例

以下のSQLステートメントでは、`UNION ALL` を使用して2つの `SELECT` ステートメントの結果セットを1つのセットに結合し、重複行を除去しません。

```sql
SELECT id, name FROM test_tbl1
UNION ALL
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
12 rows in set
```

### INTERSECTの例

以下のSQLステートメントでは、`INTERSECT` を使用して2つの `SELECT` ステートメントの結果セットの共通部分を返します。

```sql
SELECT id, name FROM test_tbl1
INTERSECT
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
+------+------+
3 rows in set
```

### MINUSの例

以下のSQLステートメントでは、`MINUS` または `EXCEPT` を使用して、最初の `SELECT` ステートメントの結果セットに含まれているが、2番目の `SELECT` ステートメントの結果セットには含まれていない行を返します。

```sql
SELECT id, name FROM test_tbl1
MINUS
SELECT id, name FROM test_tbl2;
```

または

```sql
SELECT id, name FROM test_tbl1
EXCEPT
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| id   | name |
+------+------+
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
3 rows in set
```
