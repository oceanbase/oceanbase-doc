# クエリでの正規表現の使用

正規表現は、特定のパターンに一致するテキストを文字列内で検索および操作するためのパターンマッチングツールです。OceanBaseデータベースV4.1.0以降は、MySQL 8.0の正規表現機能と完全に互換性があり、POSIX 1003.2標準の拡張正規表現構文をサポートしています。

OceanBaseはICU正規表現エンジンを使用し、高性能な正規表現のマッチングと操作機能を提供します。また、より良いパフォーマンスを得るために、オプションでHyperscan正規表現エンジンもサポートしています。

## 基本構文

### 単純一致

```sql
-- 基本一致
SELECT 'hello world' REGEXP 'hello';  -- 1を返す (一致)
SELECT 'hello world' REGEXP 'goodbye'; -- 0を返す (不一致)

-- RLIKEの使用
SELECT 'hello world' RLIKE '^hello';  -- 1を返す (helloで始まる)
```

### 文字クラスと量化詞

```sql
-- ドットは任意の文字に一致する
SELECT 'abc' REGEXP 'a.c';  -- 1を返す

-- 文字クラス [abc] は a、b、または c に一致します。
SELECT 'bat' REGEXP '[abc]at';  -- 1を返す

-- 数量詞 * （0回以上）、+ （1回以上）、? （0回または1回）
SELECT 'caaat' REGEXP 'ca*t';  -- 1を返す (a が0回以上出現)
SELECT 'caaat' REGEXP 'ca+t';  -- 1を返す (a が1回以上出現)
SELECT 'cat' REGEXP 'ca?t';    -- 1を返す (a が0回または1回出現)
```

### アンカー

```sql
-- ^ は文字列の先頭に一致します。
SELECT 'hello world' REGEXP '^hello';  -- 1を返す

-- $ は文字列の末尾に一致します。
SELECT 'hello world' REGEXP 'world$';  -- 1を返す

-- \b は単語の境界に一致します。
SELECT 'hello world' REGEXP 'world\b'; -- 1を返す
```

### グループ化と参照

```sql
-- 括弧 () はグループ化に使用されます。
SELECT 'abab' REGEXP '(ab)+';  -- 1を返す

-- バック参照 \1, \2 など
SELECT 'abab' REGEXP '(ab)\1';  -- 1を返す
```

## 文字クラス

### 標準文字クラス

| 文字クラス | 意味 |
|--------|------|
| `[[:alnum:]]` | 英字と数字の文字 |
| `[[:alpha:]]` | 英字の文字 |
| `[[:blank:]]` | 空白文字（スペースとタブ） |
| `[[:cntrl:]]` | 制御文字 |
| `[[:digit:]]` | 数字の文字 |
| `[[:graph:]]` | 印刷可能な文字（スペースを除く） |
| `[[:lower:]]` | 小文字 |
| `[[:print:]]` | 印刷可能な文字（スペースを含む） |
| `[[:punct:]]` | 点字 |
| `[[:space:]]` | 空白文字（改行文字、キャリッジリターン文字などを含む） |
| `[[:upper:]]` | 大文字 |
| `[[:xdigit:]]` | 16進数の数字 |

```sql
-- 文字クラスの使用
SELECT 'abc123' REGEXP '[[:alnum:]]+';  -- 1を返す
SELECT 'hello' REGEXP '[[:alpha:]]+';   -- 1を返す
SELECT '123' REGEXP '[[:digit:]]+';     -- 1を返す
```

### 特殊文字クラス

```sql
-- POSIX文字クラス
SELECT 'a1' REGEXP '[[:alnum:]]';    -- 1を返す
SELECT 'A' REGEXP '[[:upper:]]';     -- 1を返す
SELECT 'a' REGEXP '[[:lower:]]';     -- 1を返す

-- 等価クラス [=character=]
SELECT 'a' REGEXP '[[=a=]]';         -- 1を返す

-- 整理要素 [.character.]
SELECT '.' REGEXP '[[..]]';          -- 1を返す
```

## エスケープ文字

正規表現では、一部の文字には特殊な意味があります。これらの文字自体とマッチさせる場合は、バックスラッシュ `\` を使用してエスケープする必要があります。

| 特殊文字 | エスケープ表記 |
|----------|----------|
| `.` | `\.` |
| `*` | `\*` |
| `+` | `\+` |
| `?` | `\?` |
| `^` | `\^` |
| `$` | `\$` |
| `(` | `\(` |
| `)` | `\)` |
| `[` | `\[` |
| `]` | `\]` |
| `{` | `\{` |
| `}` | `\}` |
| <code>\|</code> | <code>\\&#124;</code> |
| `\` | `\\` |

```sql
-- エスケープの例
SELECT 'a.c' REGEXP 'a\.c';        -- 1を返す (リテラルのピリオドとマッチ)
SELECT 'a*c' REGEXP 'a\*c';        -- 1を返す (リテラルのアスタリスクとマッチ)
SELECT 'a+c' REGEXP 'a\+c';        -- 0を返す (リテラルのプラス記号とマッチしない)
SELECT 'price: $100' REGEXP '\\$'; -- 1を返す (ドル記号とマッチ)
```

## 文字セットと照合順序

正規表現の操作は、入力文字列と正規パターンパラメータの文字セットおよび照合順序に基づいて、マッチング動作と比較方法を決定します。

* パラメータが異なる文字セットまたは照合順序を持つ場合、強制的なルールが適用されます。
* いずれかのパラメータがバイナリ文字列の場合、そのパラメータはバイナリ文字列として大文字小文字を区別する方法で処理されます。
* UTF-8、UTF-16 など、さまざまな文字セットをサポートしています。

```sql
-- 文字セットの例
SELECT 'OceanBase' REGEXP 'oceanbase';     -- 0 を返す (大文字小文字を区別)

-- バイナリ比較の例 (バイナリ照合順序の文字セットを使用する必要があります)
SELECT _utf8mb4'OceanBase' COLLATE utf8mb4_bin REGEXP _utf8mb4'oceanbase' COLLATE utf8mb4_bin; -- 0 を返す
```

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OceanBaseでは、<code>REGEXP</code> 関数で直接 <code>BINARY</code> キーワードを使用することはサポートされていません。バイナリ比較が必要な場合は、<code>COLLATE</code> 句を使用してバイナリ照合順序の文字セットを指定してください。</p>
</main>

## パフォーマンス最適化

OceanBaseのMySQLモードは、正規表現に対して複数のパフォーマンス最適化を施しています。

1. **式キャッシュ**：コンパイル済みの正規表現はキャッシュされ、再利用できます。
2. **定数最適化**：定数パターンの正規表現に対して、高速な計算経路を提供します。
3. **メモリ管理**：効率的な一時メモリの割り当てと管理。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>複雑な正規表現はクエリのパフォーマンスに影響を与える可能性があります。高並行環境では慎重に使用し、データベースのインデックスを活用してクエリ性能を最適化することを検討してください。</p>
</main>

## 適用シナリオ

### データ抽出

```sql
-- 文字列から数字を抽出
SELECT REGEXP_SUBSTR('Price: $123.45', '\\d+\\.\\d+") AS price;

-- URLからドメイン名を抽出
SELECT REGEXP_SUBSTR('https://www.example.com/path', 'https?://([^/]+)') AS domain;
```

### データクレンジング

```sql
-- 余分な空白文字を削除する
SELECT REGEXP_REPLACE('hello   world', '\\s+', ' ') AS cleaned_text;

-- 電話番号をフォーマットする
SELECT REGEXP_REPLACE('12345678901', '(\\d{3})(\\d{4})(\\d{4})', '$1-$2-$3') AS formatted_phone;
```
