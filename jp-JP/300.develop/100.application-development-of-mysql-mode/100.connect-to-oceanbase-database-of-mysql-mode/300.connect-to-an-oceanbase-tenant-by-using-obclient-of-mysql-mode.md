# OBClientを使用したOceanBaseテナントへの接続

本記事では、OBClientを使用してOceanBaseデータベースのMySQLテナントに接続するための前提条件、接続操作、およびその例について説明します。

## 前提条件

* OBClientアプリケーションがダウンロードおよびインストール済みであることを確認してください。OBClientアプリケーションをダウンロードしていない場合は、[ソフトウェアセンター](https://open.oceanbase.com/softwareCenter/community)にアクセスして、対応するバージョンのOBClientをダウンロードできます。

* テナントに接続する前に、現在のクライアントがテナントのアローリストに含まれていることを確認してください。テナントのアローリストの照会および設定の具体的な操作については、[テナントのアローリストの表示と設定](../../../600.manage/200.tenant-management/600.common-tenant-operations/500.view-and-set-whitelist.md)を参照してください。

## 接続操作

### ODP経由での接続方法

OBClientクライアントコマンドを使用して、OceanBaseデータベースプロキシ(OceanBase Database Proxy、ODP)を介してOceanBaseデータベースに接続する形式は以下のとおりです：

```shell
obclient -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

<main id="notice" type='explain'>
   <h4>説明</h4>
   <p>OceanBaseデータベースからODPへの圧縮機能がサポートされています。OceanBaseデータベースはV4.2.1 BP3または4.2.2 BP1以降のバージョンが必要であり、ODPはV4.2.3以降のバージョンが必要です。詳細については、以下のドキュメントを参照してください：
   <ul><li>ODPとOceanBaseデータベース間でOceanBase 2.0プロトコルを使用して転送するかどうかを制御する詳細については、[enable_ob_protocol_v2](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517753)を参照してください。
   </li><li>圧縮プロトコルを有効にするかどうかを制御する詳細については、[enable_compression_protocol](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517630)を参照してください。
   </li><li>圧縮プロトコルとOceanBase 2.0プロトコルの圧縮レベルを制御する詳細については、[compression_algorithm](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517613)を参照してください。</li></ul></p>
</main>

**パラメータの説明：**

* `-h`：OceanBaseデータベースへの接続IPアドレスを指定します。`$host`は実際のIPアドレスに置き換える必要があります。ODP経由で接続する場合は、ODPのアドレスを使用します。
* `-P`：OceanBaseデータベースの接続ポートを指定します。`$port`は実際のポート番号に置き換える必要があります。ODP経由で接続する場合、デフォルトでは2883を使用しますが、ODPデプロイ時にカスタマイズ可能です。
* `-u`：OceanBaseデータベースへの接続アカウントを指定します。`$user_name`の形式は以下のとおりです：`ユーザー名@テナント名#クラスタ名`、`クラスタ名:テナント名:ユーザー名`、`クラスタ名-テナント名-ユーザー名`または`クラスタ名.テナント名.ユーザー名`。MySQLモードのテナントの管理者ユーザー名はデフォルトで`root`です。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><ul><li>ODPを使用してOceanBaseクラスタに接続する場合、以下の方法でクラスタ名を取得できます：</br>まず、直接接続でOceanBaseデータベースに接続します。次に、<code>SHOW PARAMETERS LIKE 'cluster';</code>コマンドを使用してクラスタ名を取得します。このコマンドの実行結果における<code>VALUE</code>の値が、対応するOceanBaseクラスタの名前になります。</li><li>ODPが複数のクラスタをプロキシしている場合、接続時には必ずクラスタ名を指定する必要があります。ODPが単一のクラスタのみをプロキシしている場合、接続時にはクラスタ名を指定する必要はありません。</li></ul></p>
   </main>

* `-p`: OceanBaseデータベースへの接続パスワードを指定します。`******`は実際のパスワード文字列に置き換える必要があります。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>セキュリティ上の理由から、コマンドラインに直接パスワードを入力することは推奨されません。特にスクリプトや履歴が可視化される環境では、このオプションを省略し、プロンプトが表示された際にパスワードを入力することを推奨します。</p>
   </main>

* `-c`：オプション。OBClientの実行環境において、コメントを無視しないようにします。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Hintは特殊なコメントであり、<code>-c</code>の影響を受けません。</p>
   </main>

* `-A`: オプション。OBClientがデータベースに接続する際に統計情報を自動的に取得しないようにします。
* `$database_name`：オプション。OceanBaseデータベースに接続した後に使用するデフォルトのデータベースを指定します。これを指定しない場合、デフォルトではどのデータベースにも直接アクセスせず、接続後に手動で選択する必要があります。

**例：**

```shell
obclient -h10.10.10.1 -P2883 -uuser001@obtenant#obdemo -p****** -c -A oceanbase
```

#### ODPを使用したSERVICE_NAME経由での接続方法

OceanBaseデータベースは、ODPの`IP:PORT`と`SERVICE_NAME`を指定してログインすることをサポートしています。指定された`SERVICE_NAME`に基づき、ODPは接続文字列を`-uuser_name@プライマリテナント名#プライマリテナントが存在するクラスタ`に変換します。ユーザーはプライマリ/スタンバイ切り替え後に接続文字列を手動で変更する必要はありません。`SERVICE_NAME`の作成方法の詳細については、[サービスの作成](../../../600.manage/200.tenant-management/600.common-tenant-operations/1700.manage-service/100.create-service.md)を参照してください。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>この機能はOceanBaseクラウドプラットフォーム(OceanBase Cloud Platform, OCP)に依存します。OCPはV4.3.1以降のバージョンである必要があり、またOceanBaseクラスタがOCPによって管理されている場合にのみ正常に使用できます。</p>
</main>

ODPを使用して`SERVICE_NAME`経由でOceanBaseデータベースに接続する形式は以下のとおりです：

```shell
obclient -h$host -P$port -u$user_name@SERVICE:$service_name -p******
```

**パラメータの説明：**

* `$host`：ODPのIPアドレス。
* `$port`：ODPのポート番号。
* `$user_name`：ユーザー名。
* `$service_name`: サービス名。
* `-p`: OceanBaseデータベースに接続するためのパスワード。`******`は実際のパスワード文字列に置き換える必要があります。

**例：**

```sql
obclient -h10.10.10.1 -P2883 -uuser001@SERVICE:service_mysql001 -p******
```

### ダイレクト接続方式

OBClientクライアントコマンドを使用して、OceanBaseデータベースにダイレクト接続する形式は以下のとおりです：

```shell
obclient -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

**パラメータの説明：**

* `-h`：OceanBaseデータベースへの接続IPアドレスを指定します。`$host` は実際のIPアドレスに置き換える必要があります。ダイレクト接続方式では通常、OBServerノードのIPアドレスを使用します。

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>一般テナントがダイレクト接続方式で接続する場合、そのテナントのリソースが該当するOBServerノード上に配置されていることを確認する必要があります。もし該当するテナントのリソースがそのOBServerノード上に配置されていない場合、そのOBServerノードに直接接続してもそのテナントには接続できません。</p>
   </main>

* `-P`：OceanBaseデータベースの接続ポートを指定します。`$port` は実際のポート番号に置き換える必要があります。ダイレクト接続方式のデフォルトポートは2881ですが、OceanBaseデータベースのデプロイ時にカスタマイズ可能です。
* `-u`：OceanBaseデータベースの接続アカウントを指定します。`$user_name` の形式は `ユーザー名@テナント名` です。MySQLテナントの管理者ユーザー名はデフォルトで `root` です。

   <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>ダイレクト接続方式でOceanBaseデータベースに接続する際、接続パラメータ <code>-u</code> の後に正しい <code>ユーザー名@テナント名</code> を入力し、クラスタ名は指定しないでください。<code>-u</code> にクラスタ名が含まれていると、接続エラーが発生します。</p>
   </main>

* `-p`: OceanBaseデータベースに接続するためのパスワードを指定します。`******` は実際のパスワード文字列に置き換える必要があります。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>セキュリティ上の理由から、コマンドラインに直接パスワードを入力することは推奨されません。特にスクリプトや履歴が可視化される環境では、このオプションを省略し、プロンプトが表示された際にパスワードを入力することを推奨します。</p>
   </main>

* `-c`：オプション。OBClient実行環境において、コメントを無視しないようにします。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Hintは特殊なコメントであり、<code>-c</code> の影響を受けません。</p>
   </main>

* `-A`: オプション。OBClientがデータベースに接続する際、統計情報を自動取得しないようにします。
* `$database_name`：オプション。OceanBaseデータベースに接続した後に使用するデフォルトのデータベースを指定します。これを指定しない場合、デフォルトではどのデータベースにも直接アクセスされず、接続後に手動で選択する必要があります。

**例：**

```shell
obclient -h10.10.10.1 -P2881 -uuser001@obtenant -p****** -c -A oceanbase
```

## 接続例

1. コマンドラインターミナルを開きます。
2. OBClientクライアントを使用して、ODP経由でOceanBaseデータベースのMySQLモードテナントに接続します。

   ```shell
   obclient -hxxx.xx.xxx.xxx -P2883 -uroot@mysql001#test424 -p****** -A oceanbase
   ```

   実行結果は次のとおりです：

   ```shell
   Welcome to the OceanBase.  Commands end with ; or \g.
   Your OceanBase connection id is 16
   Server version: OceanBase 4.2.4.0 (r200000342024061210-c4c0c18741e45a1d40889b6147c3132574d6e7ea) (Built Jun 12 2024 10:58:58)

   Copyright (c) 2000, 2018, OceanBase and/or its affiliates. All rights reserved.

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

   obclient [oceanbase]>
   ```

3. OBClientコマンドラインを終了するには、`exit` と入力してEnterキーを押すか、**Ctrl** + **D** のショートカットキーを押します。
