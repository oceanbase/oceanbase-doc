# MySQLクライアントを使用したOceanBaseテナントへの接続

OceanBaseデータベースのMySQLテナントを使用する場合、MySQLクライアントを使用してそのテナントに接続できます。この記事では、この接続方法の前提条件、接続操作、およびサンプルについて説明します。

## 前提条件

MySQLクライアントを使用してデータベースに接続する前に、以下の情報を確認する必要があります：

* ローカルにMySQLクライアントが正しくインストールされていることを確認してください。OceanBaseデータベースの現行バージョンでサポートされているMySQLクライアントのバージョンは、V5.5、V5.6、V5.7、およびV8.0.2です。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>ODPを使用してOceanBaseデータベースに接続する場合、現在MySQLクライアントV8.0.2との互換性はありません。</p>
    </main>

* 環境変数`PATH`にMySQLクライアントコマンドのディレクトリが含まれていることを確認してください。

* テナントに接続する前に、現在のクライアントがテナントのアローリストに含まれていることを確認してください。テナントのアローリストのクエリと設定の具体的な操作については、[テナントのアローリストの表示と設定](../../../600.manage/200.tenant-management/600.common-tenant-operations/500.view-and-set-whitelist.md)を参照してください。

## 接続操作

### ODP経由での接続方法

OceanBaseデータベースプロキシ(OceanBase Database Proxy、ODP)を介して、MySQLクライアントコマンドを使用してOceanBaseデータベースに接続する形式は以下のとおりです：

```shell
mysql -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

<main id="notice" type='explain'>
   <h4>説明</h4>
   <p>OceanBaseデータベースからODPへの圧縮機能がサポートされています。OceanBaseデータベースはV4.2.1 BP3または4.2.2 BP1以降のバージョンが必要であり、ODPはV4.2.3以降のバージョンが必要です。詳細については、以下のドキュメントを参照してください：<ul><li>ODPとOceanBaseデータベース間でOceanBase 2.0プロトコルを有効にするかどうかを制御する詳細については、<a href= "https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517753">enable_ob_protocol_v2</a>を参照してください。
<li>圧縮プロトコルを有効にするかどうかを制御する詳細については、<a href="https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517630">enable_compression_protocol</a>を参照してください。</li><li>圧縮プロトコルとOceanBase 2.0プロトコルの圧縮レベルを制御する詳細については、<a href="https://www.oceanbase.com/docs/common-odp-doc-cn-1000000000517613">compression_algorithm</a>を参照してください。</li></ul></p>
</main>

**パラメータの説明：**

* `-h`：OceanBaseデータベースへの接続IPアドレスを指定します。`$host`は実際のIPアドレスに置き換える必要があります。ODP経由で接続する場合は、ODPのアドレスを使用します。
* `-P`：OceanBaseデータベースの接続ポートを指定します。`$port`は実際のポート番号に置き換える必要があります。ODP経由で接続する場合、デフォルトのポート番号は2883ですが、ODPのデプロイ時にカスタマイズ可能です。
* `-u`：OceanBaseデータベースへの接続アカウントを指定します。`$user_name`の形式は以下のとおりです：`ユーザー名@テナント名#クラスタ名`、`クラスタ名:テナント名:ユーザー名`、`クラスタ名-テナント名-ユーザー名`または`クラスタ名.テナント名.ユーザー名`。MySQLクライアントを使用して接続する場合、MySQLモードのテナントにのみ接続でき、MySQLモードのテナントの管理者ユーザー名はデフォルトで`root`です。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><ul><li>ODPを使用してOceanBaseクラスタに接続する場合、以下の方法でクラスタ名を取得できます：</br>まず、直接接続でOceanBaseデータベースに接続します。次に、<code>SHOW PARAMETERS LIKE 'cluster';</code>コマンドを使用してクラスタ名を取得します。このコマンドの実行結果における<code>VALUE</code>の値が、対応するOceanBaseクラスタの名前となります。</li><li>ODPが複数のクラスタをプロキシしている場合、接続時には必ずクラスタ名を指定する必要があります。ODPが単一のクラスタのみをプロキシしている場合、接続時にはクラスタ名を指定する必要はありません。</li></ul></p>
   </main>

* `-p`: OceanBaseデータベースに接続するためのパスワードを指定します。`******`は実際のパスワード文字列に置き換える必要があります。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>セキュリティ上の理由から、コマンドラインに直接パスワードを入力することは推奨されません。特にスクリプトや履歴が可視化される環境では、このオプションを省略し、プロンプトが表示された際にパスワードを入力することを推奨します。</p>
   </main>

* `-c`：オプション。MySQL実行環境において、コメントを無視しないようにします。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Hintは特殊なコメントであり、<code>-c</code>の影響を受けません。</p>
   </main>

* `-A`: オプション。MySQLがデータベースに接続する際に統計情報を自動的に取得しないようにします。
* `$database_name`：オプション。OceanBaseデータベースに接続した後に使用するデフォルトのデータベースを指定します。このオプションを指定しない場合、デフォルトではどのデータベースにも直接アクセスされず、接続後に手動で選択する必要があります。

**例：**

```shell
mysql -h10.10.10.1 -uuser001@obmysql#obdemo -P2883 -p****** -c -A oceanbase
```

### ダイレクト接続方式

MySQLクライアントコマンドを使用して、OceanBaseデータベースにダイレクト接続する形式は以下のとおりです：

```shell
mysql -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

**パラメータの説明：**

* `-h`：OceanBaseデータベースへの接続IPアドレス。`$host` は実際のIPアドレスに置き換える必要があります。ダイレクト接続方式では通常、OBServerノードのIPアドレスを使用します。

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>一般テナントがダイレクト接続方式で接続する場合、そのテナントのリソースが該当するOBServerノード上に配置されている必要があります。もし該当するテナントのリソースがそのOBServerノード上に配置されていない場合、そのOBServerノードに直接接続しても、そのテナントには接続できません。</p>
   </main>

* `-P`：OceanBaseデータベースの接続ポート。`$port` は実際のポート番号に置き換える必要があります。ダイレクト接続方式ではデフォルトで2881を使用しますが、OceanBaseデータベースのデプロイ時にカスタマイズ可能です。
* `-u`：OceanBaseデータベースの接続アカウント。`$user_name` の形式は `ユーザー名@テナント名` です。MySQLテナントの管理者ユーザー名はデフォルトで `root` です。

   <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>ダイレクト接続方式でOceanBaseデータベースに接続する際、接続パラメータ <code>-u</code> の後に正しい <code>ユーザー名@テナント名</code> を入力し、クラスタ名は指定しないでください。<code>-u</code> にクラスタ名が含まれていると、接続エラーが発生します。</p>
   </main>

* `-p`: OceanBaseデータベースへの接続パスワード。`******` は実際のパスワード文字列に置き換える必要があります。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>セキュリティ上の理由から、コマンドラインに直接パスワードを入力することは推奨されません。特にスクリプトや履歴が可視化される環境では、このオプションを省略し、プロンプトが表示された際にパスワードを入力することを推奨します。</p>
   </main>

* `-c`：オプション。MySQL実行環境において、コメントを無視しないようにします。

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>Hintは特殊なコメントであり、<code>-c</code> の影響を受けません。</p>
   </main>

* `-A`: オプション。MySQLがデータベースに接続する際、統計情報を自動取得しないようにします。
* `$database_name`：オプション。OceanBaseデータベースに接続した後に使用するデフォルトのデータベースを指定します。これを指定しない場合、デフォルトではどのデータベースにも直接アクセスせず、接続後に手動で選択する必要があります。

**例：**

```shell
mysql -h10.10.10.1 -uuser001@obmysql -P2881 -p****** -c -A oceanbase
```

## 接続例

1. コマンドラインターミナルを開きます。
2. MySQLクライアントを使用して、ODP経由でOceanBaseデータベースのMySQLモードテナントに接続します。

   ```shell
   mysql -hxxx.xx.xxx.xxx -P2883 -uroot@mysql001#test424 -p****** -A oceanbase
   ```

   実行結果は次のとおりです：

   ```shell
   Welcome to the MariaDB monitor.  Commands end with ; or \g.
   Your MySQL connection id is 15
   Server version: 5.6.25 OceanBase 4.2.4.0 (r200000342024061210-c4c0c18741e45a1d40889b6147c3132574d6e7ea) (Built Jun 12 2024 10:58:58)

   <...>

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

   MySQL [oceanbase]>
   ```

3. MySQLコマンドラインを終了するには、`exit` と入力してEnterキーを押すか、**Ctrl** + **D** のショートカットキーを押します。

## 詳細を見る

MySQLクライアントを使用してOceanBaseデータベースに接続する際に問題が発生した場合は、MySQLクライアントの公式ドキュメントを参照することをお勧めします。
