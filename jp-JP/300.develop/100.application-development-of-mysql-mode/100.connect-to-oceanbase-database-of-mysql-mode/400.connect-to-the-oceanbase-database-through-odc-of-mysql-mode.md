# ODCによるOceanBaseデータベースへの接続

ODCはOceanBaseデータベースのMySQLテナントへの接続をサポートしています。本記事では、この接続方法の前提条件と接続操作について説明します。

## 前提条件

OceanBase Developer Center（ODC）がデプロイ済みであり、Web版ODCのURLを取得していることを確認してください。デプロイの詳細な操作については、[ODCのデプロイ](https://www.oceanbase.com/docs/enterprise-odc-doc-cn-10000000000833940)を参照してください。

## 手順

Web版ODCで個人接続（mysql@tenant）を作成する例を挙げます。具体的な操作手順は以下のとおりです：

1. ODCのログイン画面にアクセスし、登録済みのアカウント、パスワード、認証コードを入力した後、**<UI-TERM key="OMS.Audit.constants.Login">ログイン</UI-TERM>** をクリックします。

   <!-- ![ODCへのログイン](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/340/ODC%20%E7%99%BB%E5%BD%95%E9%A1%B5.png) -->

2. ODCのホームページの **個人接続** タブの右上隅にある **<UI-TERM key="odc.components.RecordPage.CreateConnection">新規接続</UI-TERM>** をクリックして、個人接続を作成します。

   <!-- ![作成 1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/400/OBServer%20create%20connection.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>ODCを初めて実行する場合、読み込み時間が長くなることがあります。しばらくお待ちください。</p>
   </main>

3. 接続作成ページでは、以下の情報を入力または選択する必要があります。既にOceanBaseデータベースの接続文字列をお持ちの場合、以下の情報はすべて接続文字列から直接取得できます（mysql -h **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Hostname">ホスト名</UI-TERM>** -P **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.PortNumber">ポート番号</UI-TERM>** -u データベースユーザー名@テナント名# **<UI-TERM key="ocp-v2.Cluster.Import.OBServerTable.ClusterName">クラスター名</UI-TERM>** -D **<UI-TERM key="odc.src.page.Datasource.Datasource.NewDatasourceDrawer.Form.DefaultDatabase">デフォルトデータベース</UI-TERM>** -p '**<UI-TERM key="OMS.endpoints.ObForm.Entity.DatabasePassword">データベースのパスワード</UI-TERM>**'）。または、ページ内に提供されているインテリジェント解析ツールを使用して自動入力することもできます：

   <!-- ![作成 2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/400/%E6%96%B0%E5%BB%BA%E4%B8%AA%E4%BA%BA%E8%BF%9E%E6%8E%A5-1.png) -->

   |     情報項目     |  説明  |
   |-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | データベースタイプ       | **<UI-TERM key="src.page.Workspace.components.CreateTable.BaseInfo.4F605871">物理ライブラリ</UI-TERM>** または **<UI-TERM key="src.constant.D2F0EBE8">ロジックライブラリ</UI-TERM>** を選択します。<ul><li> 物理データベース：通常のデータベース。</li><li> 論理データベース：ODP (Sharding)。 </li></ul>  |
   | 所属リージョン        | 接続が存在するリージョンとして **独立デプロイ/専用クラウド** を選択します。   |
   | 接続名        | この接続の名前を指定します。    |
   | タグの設定        | タグを使用すると、接続に補足説明などの情報を追加できます。<br> **<UI-TERM key="odc.components.RecordPage.component.ConnectionName">接続名</UI-TERM>** テキストボックスの後ろにある **タグの設定** ボタンをクリックして、現在の接続にタグを指定します。表示されるドロップダウンリストで、タグの設定や管理を行えます： <ul><li>タグの設定：ドロップダウンリストから対象のタグを選択して設定を完了します。リストが空の場合は、まず新しいタグを作成してください。   </li><li>タグの管理：リストの一番下にある **<UI-TERM key="oms-cloud.ListTag.TagModal.NewLabel">新しいタグ</UI-TERM>** ボタン、またはリストの上部にある設定アイコンをクリックすると、**<UI-TERM key="ocp-v2.src.hook.useMenu.TagManagement">タグ管理</UI-TERM>** ウィンドウが表示されます。タグ管理ウィンドウでは、作成したタグの編集や削除が可能です。また、上部の **<UI-TERM key="obcloud-console.components.Tags.EditTagsModal.CreateATag">タグを作成</UI-TERM>** ボタンをクリックすると、新しいタグの名前とアイコンの色を指定できます。</li></ul> |
   | インテリジェント解析        | テキストボックスに接続文字列を貼り付けると、ODCが自動的にそれを認識し、各接続情報をウィンドウに入力します。  |
   | 接続モード        | **MySQL** を選択します（論理データベースはMySQLモードのみサポートします）。 |
   | 接続アドレス        |<ul><li>**<UI-TERM key="oms-community.Endpoint.components.DB2Form.HostIp">ホストIP</UI-TERM>** ：接続先データベースが配置されているサーバーのIPアドレス。</li><li> **<UI-TERM key="oms-v2.EndpointPublic.components.MySqlForm.Port">ポート</UI-TERM>** ：接続先データベースが配置されているサーバーのポート番号。</li><li>**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.ClusterName">クラスター名</UI-TERM>** ：接続先データベースが配置されているクラスタの名前（論理データベースは入力不要）。</li><li>**<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.TenantInfoTable.TenantName">テナント名</UI-TERM>** ：接続先データベースが配置されているテナントの名前（論理データベースは入力不要）。 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>ホスト名とポート番号は、接続先のデータベースが配置されているテナントの情報ページで取得できます。例えば、パブリッククラウドやOCP上で作成されたテナントの場合です。</p></main>|
   | データベースアカウント       | <ul><li> **<UI-TERM key="OMS.endpoints.MySqlForm.FormItem.DatabaseUsername">データベースユーザー名</UI-TERM>**：テナント内で作成されたアカウント（MySQLモードでは、このアカウントはデフォルトデータベースへのアクセス権限を持っている必要があります）。</li><li> **<UI-TERM key="OMS.endpoints.OracleForm.FormItem.DatabasePassword">データベースのパスワード</UI-TERM>**：テナント内で作成されたアカウントのパスワード。データベースパスワードボックスの後ろにある **<UI-TERM key="oms-community.Endpoint.New.TestConnection">接続テスト</UI-TERM>** ボタンをクリックして、ターゲットデータベースに接続できるか確認します。</li><li> **パスワードの保存**：このオプションをオフにすると、接続情報にデータベースのパスワードが保存されません。接続または接続テストを行うたびに、ポップアップ表示されるパスワード入力画面でパスワードを入力する必要があります。このオプションをオンにすると、接続情報にデータベースのパスワードが保存され、接続時に毎回パスワードを入力する必要がなくなります。</li></ul><main id="notice" type='explain'><h4>説明</h4><p><ul><li> 設定情報に誤りがある場合、ユーザー名やパスワードが間違っている、ネットワーク異常など、エラーメッセージが表示されます。</li><li> ユーザーは自身が所属するテナント内のデータベースにのみ接続できます。それ以外の場合、接続テスト失敗のエラーが表示されます。</li><li>ODC V4.0.0以降のバージョンでは、アカウントとパスワードを入力しなくても接続を保存できます。</li></ul></p></main>|
   | デフォルトデータベース/schema（オプション）       | MySQLテナント内のデータベースに接続する際、この接続で使用するデフォルトデータベースを入力する必要があります。<main id="notice" type='explain'><h4>説明</h4><p>MySQLモードでは、デフォルトのデータベースを指定しない場合、information_schemaデータベースに接続されます。information_schemaデータベースへの接続に失敗した場合は、デフォルトのデータベースをそのユーザーが権限を持つデータベースに設定してください。</p></main>|
   | SQLクエリのタイムアウト  | SQLのタイムアウト時間はカスタマイズ可能で、SQLクエリが指定された時間を超えると自動的にクエリが終了します（デフォルトは60秒）。  |
   | sysテナントアカウントの設定 | sysテナントアカウントを使用してテナントビューをクエリするかどうかを選択し、選択した場合は、**<UI-TERM key="oms-v2.User.Personal.Account">アカウント</UI-TERM>** と **<UI-TERM key="obcloud-console.MyComponents.MyProfile.Password">パスワード</UI-TERM>** を入力します。<br> データベースタイプが物理データベースの場合、`sys` テナントビューに対するクエリ権限を持つアカウントとパスワードを入力してください。**<UI-TERM key="portal.connection.form.address">接続アドレス</UI-TERM>** に **<UI-TERM key="OMA.Performance.componentsAdd.RDSTargetEndType.Tenant">テナント</UI-TERM>** がsysとして指定されている場合、この項目は自動的に入力されます。<ul><li> **アカウント** ：sysテナントビューに対するクエリ権限を持つアカウント。</li><li> **<UI-TERM key="oms-community.Endpoint.components.DB2Form.Password">パスワード</UI-TERM>** ：アカウントに対応するパスワード。</li></ul> アカウントとパスワードの情報を入力した後、パスワードボックスの後ろにある **<UI-TERM key="oms-v2.Endpoint.constants.TestConnection">接続テスト</UI-TERM>** ボタンをクリックして、アカウント情報が正しいか確認します。<main id="notice" type='explain'><h4>説明</h4><p><ul><li> ODC V2.3.0以降のバージョンでは、インポートおよびエクスポート機能は、接続作成時の詳細設定でroot@sysユーザーを設定する必要があります。</li><li> ODC V2.4.1以降のバージョンでは、インポートおよびエクスポート機能によるビュー情報のクエリにおいて、root@sysアカウントへの依存関係がなくなりました（root@sysアカウントが設定されていない場合、ODCの一部のオブジェクト、例えばストアドプロシージャや関数などはエクスポート機能をサポートしません。root@sysアカウントが設定されている場合、`sys` テナントのビュー情報にアクセスすることで最適なデータルーティング戦略を得て、エクスポート速度を向上させることができます）。</li><li>  **sysテナントアカウントとパスワード** は、クラスタテナント内のユーザーのアカウントとパスワードです（アカウントに「@sys#クラスタ」と入力しないでください）。例：アカウントはrootです。 </li></ul></p></main>|

4. ページ下部の **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Save">保存する</UI-TERM>** ボタンをクリックすると、現在の設定情報がODC接続リストに永続的に保存されます。再度ODCにログインする際、接続設定リストからその接続を直接選択することができます。接続設定を保存する際、接続テストが成功している必要はありません。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>保存する前に、<b>接続テスト</b>をクリックしてデータベース接続テストを行うことができます。データベースのユーザー名とパスワードが正しい場合、<b>接続成功</b>と表示されます。</p>
   </main>
