# ODCを使用してOceanBaseデータベースに接続する

ODCは、OceanBaseデータベースのMySQLテナントへの接続をサポートしています。本記事では、この接続方法の前提条件と接続操作について説明します。

## 前提条件

OceanBase開発者センター(ODC)がデプロイ済みであり、Web版ODCのURLを取得していることを確認してください。デプロイの詳細な手順については、[ODCのデプロイ](https://www.oceanbase.com/docs/enterprise-odc-doc-cn-10000000000833940)を参照してください。

## 手順

Web版ODCで個人接続（mysql@tenant）を作成する場合を例に説明します。具体的な手順は以下のとおりです：

1. ODCのログイン画面に移動し、登録したアカウント、パスワード、認証コードを入力してから、**ログイン**をクリックします。

   <!-- ![ODCにログイン](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/340/ODC%20%E7%99%BB%E5%BD%95%E9%A1%B5.png) -->

2. ODCのホームページの**個人接続**タブの右上にある**新規接続**をクリックして、個人接続を作成します。

   <!-- ![作成1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/400/OBServer%20create%20connection.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>ODCが初めて実行される際は、読み込み時間が長くなる場合があります。しばらくお待ちください。</p>
   </main>

3. 接続作成タブでは、以下の情報を入力または選択する必要があります。OceanBaseデータベースの接続文字列を既にお持ちの場合、以下の情報はすべて接続文字列から直接取得できます（mysql -h **ホスト名** -P **ポート番号** -u **データベースユーザー名@テナント名** # **クラスタ名** -D **デフォルトデータベース** -p '**データベースパスワード**'）または、タブ内に提供されているスマート解析ツールを使用して直接入力することもできます：

   <!-- ![作成2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/400/%E6%96%B0%E5%BB%BA%E4%B8%AA%E4%BA%BA%E8%BF%9E%E6%8E%A5-1.png) -->

   |     情報項目     |  説明  |
   |-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | データベースタイプ       | **物理データベース**または**論理データベース**を選択します。<ul><li> 物理データベース：通常のデータベース。</li><li> 論理データベース：ODP (Sharding)。 </li></ul>  |
   | 所属リージョン        | 接続例が存在するリージョンとして **独立デプロイ/プライベートクラウド** を選択します。   |
   | 接続名        | この接続の名前を指定します。    |
   | タグの設定        | タグを使用して、接続にヒントや説明などの情報を追加できます。<br> **接続名** テキストボックスの後ろにある **タグの設定** ボタンをクリックして、現在の接続にタグを指定します。表示されるドロップダウンリストで、タグの設定や管理を行うことができます： <ul><li>タグの設定：ドロップダウンリストからターゲットタグを選択して設定を完了します。リストが空の場合は、まず新しいタグを作成してください。   </li><li>タグの管理：リストの一番下にある **新規タグ** ボタンをクリックするか、リストの上部にある設定アイコンをクリックして **タグ管理** ウィンドウを表示します。タグ管理ウィンドウでは、作成したタグの編集や削除を行うことができます。同時に、上部の **新規タグ** ボタンをクリックして、新しいタグの名前とアイコンの色を指定することもできます。</li></ul> |
   | スマート解析        | テキストボックスに接続文字列情報を貼り付けると、ODCは自動的に接続文字列を認識し、ウィンドウ内に各接続情報を入力します。  |
   | 接続モード        | **MySQL** を選択します（論理データベースはMySQLモードのみサポートします）。 |
   | 接続アドレス        |<ul><li>**ホストIPアドレス**：接続先のデータベースが存在するサーバーのIPアドレス情報。</li><li> **ポート**：接続先のデータベースが存在するサーバーのポート番号情報。</li><li>**クラスタ名**：接続先のデータベースが存在するクラスタの名前（論理データベースは入力不要）。</li><li>**テナント名**：接続先のデータベースが存在するテナントの名前（論理データベースは入力不要）。 </li></ul> <main id="notice" type='explain'><h4>説明</h4><p>ホスト名とポート番号は、接続先のデータベースが存在するテナント情報ページから取得できます。例えば、パブリッククラウドやOCP上で作成されたテナントの場合です。</p></main>|
   | データベースアカウント       | <ul><li> **データベースユーザー名**：テナント内で作成されたアカウント（MySQLモードでは、このアカウントはデフォルトのデータベースへのアクセス権限を持っている必要があります）。</li><li> **データベースパスワード**：テナント内で作成されたアカウントのパスワードです。データベースパスワード入力欄の後ろにある**「接続テスト」**ボタンをクリックして、ターゲットデータベースへの接続が可能かどうかをテストします。</li><li> **パスワードの保存**：このオプションをオフにすると、接続情報にデータベースのパスワード情報は保存されません。接続または接続テストを行うたびに、表示されるパスワード入力ポップアップウィンドウにデータベースのパスワードを入力して接続します。このオプションをオンにすると、接続情報にデータベースのパスワード情報が保存され、次回接続する際にはパスワードの入力が不要になります。</li></ul><main id="notice" type='explain'><h4>説明</h4><p><ul><li> 設定情報に誤りがある場合、ユーザーまたはパスワードが間違っている、ネットワーク異常など、異常メッセージが表示されます。</li><li> ユーザーは自身のテナント内のデータベースにのみ接続できます。それ以外の場合は、接続テストに失敗したエラーが報告されます。</li><li> ODC V4.0.0以降のバージョンでは、アカウントとパスワードを入力しなくても接続を保存できます。</li></ul></p></main>|
   | デフォルトデータベース／スキーマ（オプション）       | MySQLテナント内のデータベースに接続する際に、この接続で使用するデフォルトのデータベースを入力する必要があります。<main id="notice" type='explain'><h4>説明</h4><p>MySQLモードでは、デフォルトのデータベースを指定しない場合、デフォルトでinformation_schemaデータベースに接続します。information_schemaデータベースへの接続に失敗した場合は、そのユーザーが権限を持つデータベースをデフォルトデータベースに設定してください。</p></main>|
   | SQLクエリのタイムアウト  | SQLのタイムアウト時間をカスタマイズできます。SQLクエリが指定された時間を超えると、クエリは自動的に終了します（デフォルトは60秒）。  |
   | sysテナントアカウント設定 | sysテナントアカウントを使用してテナントビューを照会するかどうかを選択します。チェックした場合は、**アカウント**と**パスワード**を入力してください。<br>データベースタイプが物理データベースの場合、`sys`テナントビューへの照会権限を持つアカウントとパスワードを入力してください。**接続先**で**テナント**がsysと指定されている場合、この項目は自動的に入力されます。<ul><li> **アカウント**：sysテナントビューの表示権限を持つアカウント。</li><li> **パスワード**：アカウントに対応するパスワード。</li></ul> アカウントとパスワード情報を入力した後、パスワードボックスの後ろにある**接続テスト**ボタンをクリックして、アカウント情報が正しいかどうかをテストします。<main id="notice" type='explain'><h4>説明</h4><p><ul><li> ODC V2.3.0以降のバージョンでは、インポートおよびエクスポート機能は、接続作成時の詳細設定でroot@sysユーザーを設定する必要があります。</li><li> ODC V2.4.1以降のバージョンでは、インポートおよびエクスポート機能によるビュー情報の照会において、root@sysアカウントへの強い依存性が解除されました（root@sysアカウントが設定されていない場合、ODCの一部のオブジェクト、例えばストアドプロシージャや関数などはエクスポート機能をサポートしません。root@sysアカウントが設定されている場合、`sys`テナント内のビュー情報にアクセスすることで最適なデータルーティング戦略を得られ、エクスポート速度が向上します）。</li><li> **sysテナントアカウントとパスワード**は、クラスタテナント内のユーザーのアカウントとパスワードです（アカウントに「@sys#クラスタ」と入力しないでください）。例：アカウントはrootです。 </li></ul></p></main>|

4. ページ下部の**保存**ボタンをクリックすると、現在の設定情報がODC接続リストに永続的に保存されます。再度ODCにログインする際は、接続設定リストからその接続を直接選択できます。接続設定を保存する際には、接続テストが必ず成功している必要はありません。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>保存する前に、<b>接続テスト</b>をクリックしてデータベース接続テストを行うことができます。データベースのユーザー名とパスワードが正しい場合、<b>接続成功</b>と表示されます。</p>
   </main>
