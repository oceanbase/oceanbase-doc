# NavicatによるOceanBaseデータベースへの接続（Oracleモード）

Navicatは強力なデータベース管理ツールであり、OceanBaseデータベースのOracleモードを含むさまざまなデータベースへの接続をサポートしています。本記事では、Navicatを使用してOceanBaseデータベースのOracleモードに接続する方法について説明します。

<main id="notice" type="explain">
    <h4>説明</h4>
    <p>本記事では、Navicatを使用してOracleプロトコルを介してOceanBaseデータベースに接続する方法について説明します。</p>
</main>

## バージョン互換性

* Navicat Premium 16.1.9以降は、OceanBase Enterprise Edition（Oracleモード）V3以降をサポートしています。
* Navicat For Oracle 16.1.9以降は、OceanBase Enterprise Edition（Oracleモード）V3以降をサポートしています。

<main id="notice" type="notice">
    <h4>注意</h4>
    <p>NavicatのmacOS版は現在、OceanBase（Oracleモード）をサポートしていません。</p>
</main>

## 前提条件

* Navicat Premium 16.1.9+ または Navicat for Oracle 16.1.9+ がインストール済みであること。
* OceanBaseデータベースの接続情報を取得していること：
  * データベースサーバーのアドレスとポート
  * テナント名
  * ユーザー名とパスワード

## OceanBase JDBCドライバーのダウンロード

1. [OceanBaseソフトウェアダウンロードセンター](https://en.oceanbase.com/softwarecenter-cloud)にアクセスし、**ドライバーとミドルウェア**カテゴリからOceanBase JDBCドライバー（OceanBase Connector/J）をダウンロードします。

2. ダウンロード完了後、JARファイルをローカルディレクトリに保存します。例：`/path/to/oceanbase-client.jar`

## Navicat接続の設定

1. Navicatを開き、メニューバーの**ファイル** > **新規接続** > **Oracle**をクリックします。

2. 接続設定ページで、以下の情報を入力します：

   | パラメータ | 説明 | サンプル値 |
   |------|------|--------|
   | ホスト | OceanBaseサーバーのアドレス | 127.0.0.1 |
   | ポート | データベースポート（デフォルト：2881） | 2881 |
   | ユーザー名 | データベースユーザー名 | user@tenant |
   | パスワード | データベースパスワード | ******** |

3. **詳細**タブに切り替えます：
   * **OCIライブラリ**セクションで、**OCIを使用**を選択します。
   * **OCIライブラリパス**で、Oracleクライアントの`oci.dll`ファイル（Windows）または`libclntsh.dylib`ファイル（macOS）を選択します。

4. **ドライバー**タブに切り替えます：
   * **カスタムJDBCドライバーを使用**を選択します。
   * **追加**ボタンをクリックし、ダウンロードしたOceanBase JDBCドライバーのJARファイルを選択します。
   * **クラス名**に以下を入力します：`com.alipay.oceanbase.jdbc.Driver`
   * **URLテンプレート**に以下を入力します：`jdbc:oceanbase://{host}:{port}/{database}`

5. **接続テスト**ボタンをクリックし、接続が成功するか確認します。

## Navicatを使用したOceanBaseデータベースの管理

接続に成功すると、Navicatのグラフィカルインターフェースを使用して以下の操作を実行できます：

* データベースオブジェクト（テーブル、ビュー、ストアドプロシージャなど）の参照
* SQLクエリの実行
* データのインポート/エクスポート
* データベースユーザーと権限の管理
* データベースパフォーマンスの監視
