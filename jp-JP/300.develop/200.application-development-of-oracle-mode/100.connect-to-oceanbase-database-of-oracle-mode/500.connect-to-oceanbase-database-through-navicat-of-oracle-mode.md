# NavicatによるOceanBaseデータベースへの接続（Oracleモード）

Navicatは、OceanBaseデータベースのOracleモードを含むさまざまなデータベースへの接続をサポートする、強力なデータベース管理ツールです。このドキュメントでは、Navicatを使用してOceanBaseデータベースのOracleモードに接続する方法について説明します。

<main id="notice" type="explain">
    <h4>説明</h4>
    <p>このドキュメントでは、Navicatを使用してOracleプロトコルを介してOceanBaseデータベースに接続する方法について説明します。</p>
</main>

## バージョン互換性

* Navicat Premium 16.1.9以降は、OceanBase Enterprise Edition（Oracleモード）V3以降をサポートしています。
* Navicat For Oracle 16.1.9以降は、OceanBase Enterprise Edition（Oracleモード）V3以降をサポートしています。

<main id="notice" type="notice">
    <h4>注意</h4>
    <p>NavicatのmacOS版は現在、OceanBase（Oracleモード）をサポートしていません。</p>
</main>

## 前提条件

* Navicat Premium 16.1.9+ または Navicat for Oracle 16.1.9+ がインストール済みであること。
* OceanBaseデータベースの接続情報を取得していること：
  * データベースサーバーのアドレスとポート
  * テナント名
  * ユーザー名とパスワード

## OceanBase JDBCドライバーのダウンロード

1. [OceanBaseソフトウェアダウンロードセンター](https://jp.oceanbase.com/softwarecenter)にアクセスし、**ドライバーとミドルウェア**カテゴリからOceanBase JDBCドライバー（OceanBase Connector/J）をダウンロードします。

2. ダウンロード完了後、JARファイルをローカルディレクトリに保存します。例：`/path/to/oceanbase-client.jar`

## Navicat接続の設定

1. Navicatを開き、メニューバーの**<UI-TERM key="ocp-v2.Detail.TakeOver.File">ファイル</UI-TERM>** > **<UI-TERM key="odc.components.RecordPage.CreateConnection">新規接続</UI-TERM>** > **Oracle**をクリックします。

2. 接続設定ページで、以下の情報を入力します：

   | パラメータ | 説明 | サンプル値 |
   |------|------|--------|
   | ホスト | OceanBaseサーバーアドレス | 127.0.0.1 |
   | ポート | データベースポート（デフォルト2881） | 2881 |
   | ユーザー名 | データベースユーザー名 | user@tenant |
   | パスワード | データベースパスワード | ******** |

3. **<UI-TERM key="odc.component.FormItemPanel.Superior">高級</UI-TERM>** タブに切り替えます。
   * **OCIライブラリ** 項目で、**OCIを使用する** を選択します。
   * **OCIライブラリパス** で、Oracleクライアントの `oci.dll` ファイル（Windows）または `libclntsh.dylib` ファイル（macOS）を選択します。

4. **ドライバー** タブに切り替えます。
   * **カスタムJDBCドライバーを使用する** を選択します。
   * **<UI-TERM key="src.component.FlowToolBar.8B3A0272">追加</UI-TERM>** ボタンをクリックし、ダウンロードしたOceanBase JDBCドライバーのJARファイルを選択します。
   * **クラス名** に次の文字列を入力します：`com.alipay.oceanbase.jdbc.Driver`
   * **<UI-TERM key="ocp-v2.Channel.FormComponent.HTTPForm.UrlTemplate">URLテンプレート</UI-TERM>** に次の文字列を入力します：`jdbc:oceanbase://{host}:{port}/{database}`

5. **<UI-TERM key="oms-community.EndpointPublic.components.FormContent.TestConnection">接続テスト</UI-TERM>** ボタンをクリックし、接続が成功するか確認します。

## Navicatを使用してOceanBaseデータベースを管理する

接続に成功すると、Navicatのグラフィカルインターフェースを使用して以下の操作を実行できます：

* データベースオブジェクト（テーブル、ビュー、ストアドプロシージャなど）の参照
* SQLクエリの実行
* データのインポート/エクスポート
* データベースユーザーと権限の管理
* データベースパフォーマンスの監視
