# DBeaverを使用してOceanBaseデータベースに接続する（Oracleモード）

DBeaverは汎用のデータベース管理ツールであり、OceanBaseデータベースのOracleモードを含むさまざまなデータベースへの接続をサポートしています。この記事では、DBeaverを使用してOceanBaseデータベースのOracleモードに接続する方法について説明します。

<main id="notice" type="explain">
    <h4>説明</h4>
    <p>この記事ではGenericモードとOceanBaseドライバを使用してデータベース接続を作成しています。これにはいくつかの機能的な制限があります。例えば、画面上でフィールド情報を変更することができません。</p>
</main>

## 前提条件

* DBeaver CommunityまたはEnterpriseバージョンがインストール済みであること（最新バージョンの使用を推奨します）
* OceanBaseデータベースの接続情報を取得していること：
  * データベースサーバーのアドレスとポート
  * テナント名
  * ユーザー名とパスワード

## OceanBase JDBCドライバのダウンロード

1. [OceanBaseソフトウェアダウンロードセンター](https://jp.oceanbase.com/softwarecenter)にアクセスし、**ドライバとミドルウェア**カテゴリからOceanBase JDBCドライバ（OceanBase Connector/J）をダウンロードします。

2. ダウンロード完了後、JARファイルをローカルディレクトリに保存します。例：`/path/to/oceanbase-client.jar`

## 新しいドライバの作成

1. DBeaverを開き、**<UI-TERM key="src.component.Schedule.modals.SQLPlan.Content.095FE231">データベース</UI-TERM>** > **ドライバマネージャ**をクリックします。

2. **<UI-TERM key="odc.components.RecordPage.Create">新規作成</UI-TERM>**ボタンをクリックして新しいドライバを作成します。

3. **<UI-TERM key="obcloud-console.ClusterWorkspace.Backup.utils.Library">データベース</UI-TERM>**タブで：
   * **フォルダを追加**をクリックし、ダウンロードしたOceanBase JDBCドライバのJARファイルを選択します。
   * **<UI-TERM key="oms-v2.components.SyncObjectForm.Determine">確定</UI-TERM>**をクリックしてドライバ設定を保存します。

## 新しい接続の作成

1. **<UI-TERM key="oas.components.Session.Database">データベース</UI-TERM>** > **新しいデータベース接続**をクリックします。
2. データベース選択画面で、**OceanBase Oracle**ドライバを選択し、**<UI-TERM key="oms-cloud.ConfigurationSubscribe.Group.Create.NextStep">次へ</UI-TERM>**をクリックします。
3. 接続設定ページで、以下の情報を入力します：

   | パラメータ | 説明 | サンプル値 |
   |------|------|--------|
   | ホスト | OceanBaseサーバーアドレス | 127.0.0.1 |
   | ポート | データベースポート（デフォルト2881） | 2881 |
   | ユーザー名 | データベースユーザー名 | user@tenant |
   | パスワード | データベースパスワード | ******** |

4. **<UI-TERM key="oma-pro.src.components.databaseForm.TestConnection">接続テスト</UI-TERM>** ボタンをクリックし、接続が成功するか確認します。

## DBeaverを使用してOceanBaseデータベースを管理する

接続に成功すると、DBeaverのグラフィカルインターフェースを使用して以下の操作を実行できます：

* データベースオブジェクト（テーブル、ビュー、ストアドプロシージャなど）の参照
* SQLクエリの実行
* データのインポート/エクスポート
* データベースユーザーと権限の管理
* データベースパフォーマンスの監視
