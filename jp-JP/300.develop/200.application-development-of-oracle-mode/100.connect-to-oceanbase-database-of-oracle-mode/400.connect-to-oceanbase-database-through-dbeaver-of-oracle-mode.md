# DBeaverによるOceanBaseデータベースへの接続（Oracleモード）

DBeaverは汎用のデータベース管理ツールであり、OceanBaseデータベースのOracleモードを含むさまざまなデータベースへの接続をサポートしています。本記事では、DBeaverを使用してOceanBaseデータベースのOracleモードに接続する方法について説明します。

<main id="notice" type="explain">
    <h4>説明</h4>
    <p>本記事ではGenericモードとOceanBaseドライバを使用してデータベース接続を作成しています。これにはいくつかの機能的な制限があります。例えば、画面上でフィールド情報を変更することができません。</p>
</main>

## 前提条件

* DBeaver CommunityまたはEnterpriseバージョンがインストールされていること（最新バージョンの使用を推奨します）
* OceanBaseデータベースの接続情報を取得していること：
  * データベースサーバーのアドレスとポート
  * テナント名
  * ユーザー名とパスワード

## OceanBase JDBCドライバのダウンロード

1. [OceanBaseソフトウェアダウンロードセンター](https://en.oceanbase.com/softwarecenter-cloud)にアクセスし、**ドライバとミドルウェア**カテゴリからOceanBase JDBCドライバ（OceanBase Connector/J）をダウンロードします。

2. ダウンロード完了後、JARファイルをローカルディレクトリに保存します。例：`/path/to/oceanbase-client.jar`

## 新しいドライバの作成

1. DBeaverを開き、**データベース** > **ドライバマネージャ**をクリックします。

2. **新規作成**ボタンをクリックして新しいドライバを作成します。

3. **ライブラリ**タブで：
   * **フォルダを追加**をクリックし、ダウンロードしたOceanBase JDBCドライバのJARファイルを選択します。
   * **OK**をクリックしてドライバ設定を保存します。

## 新しい接続の作成

1. **データベース** > **新しいデータベース接続**をクリックします。
2. データベース選択画面で、**OceanBase Oracle**ドライバを選択し、**次へ**をクリックします。
3. 接続設定ページで、以下の情報を入力します：

   | パラメータ | 説明 | サンプル値 |
   |------|------|--------|
   | ホスト | OceanBaseサーバーのアドレス | 127.0.0.1 |
   | ポート | データベースポート（デフォルト2881） | 2881 |
   | ユーザー名 | データベースユーザー名 | user@tenant |
   | パスワード | データベースパスワード | ******** |

4. **接続テスト**ボタンをクリックして、接続が成功するか確認します。

## DBeaverを使用したOceanBaseデータベースの管理

接続に成功すると、DBeaverのグラフィカルインターフェースを使用して以下の操作を実行できます：

* データベースオブジェクト（テーブル、ビュー、ストアドプロシージャなど）の参照
* SQLクエリの実行
* データのインポート/エクスポート
* データベースユーザーと権限の管理
* データベースパフォーマンスの監視
