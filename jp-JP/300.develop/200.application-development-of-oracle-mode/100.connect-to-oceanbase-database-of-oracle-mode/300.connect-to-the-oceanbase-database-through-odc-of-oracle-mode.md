# ODCによるOceanBaseデータベースへの接続

ODCはOceanBaseデータベースのOracleテナントへの接続をサポートしています。このドキュメントでは、この接続方法の前提条件と操作手順について説明します。

## 前提条件

[クライアント版ODC](https://help.aliyun.com/document_detail/212816.html)をダウンロードし、インストール済みであることを確認してください。

## 手順

このドキュメントでは、クライアント版ODCで個人接続(oracle@tenant)を作成する例を説明します。具体的な操作手順は以下のとおりです：

1. ODCにアクセスし、ODCホームページの**個人接続**タブの右上隅にある**<UI-TERM key="odc.components.RecordPage.CreateConnection">新規接続</UI-TERM>**をクリックして、個人接続を作成します。

   <!-- ![作成 1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/400/OBServer%20create%20connection-Oracle.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p> ODCを初めて実行する際は、読み込みに時間がかかる場合があります。しばらくお待ちください。 </p>
   </main>

2. 接続作成ページでは、以下の情報を入力または選択する必要があります。既にOceanBaseデータベースの接続文字列をお持ちの場合は、以下の情報はすべて接続文字列から直接取得できます（mysql -h **<UI-TERM key="ocp-v2.Component.BinlogServerList.Hostname">ホスト名</UI-TERM>** -P **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.PortNumber">ポート番号</UI-TERM>** -u データベースユーザー名@テナント名# **<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.ClusterName">クラスター名</UI-TERM>** -D **<UI-TERM key="odc.src.page.Datasource.Datasource.NewDatasourceDrawer.Form.DefaultDatabase">デフォルトデータベース</UI-TERM>** -p ' **<UI-TERM key="oms-community.endpoints.OracleForm.FormItem.DatabasePassword">データベースパスワード</UI-TERM>** '）または、ページに提供されているスマート解析ツールを使用して自動入力することもできます：

   <!-- ![作成 2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/400/%E6%96%B0%E5%BB%BA%E4%B8%AA%E4%BA%BA%E8%BF%9E%E6%8E%A5-1.png) -->

   |     情報項目     |  説明  |
   |-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | データベースタイプ       | **<UI-TERM key="src.constant.5363D697">物理ライブラリ</UI-TERM>**を選択します。その中で：<ul><li> 物理データベース：通常のデータベース。</li><li> 論理データベース：ODP (Sharding)。 </li></ul>  |
   | 所属エリア        | **独立デプロイ/専用クラウド**を選択します。   |
   | 接続名        | この接続の名前を指定します。    |
   | タグの設定        | タグを使用して、接続に補足説明などの情報を追加できます。<br> **<UI-TERM key="odc.components.RecordPage.component.ConnectionName">接続名</UI-TERM>** テキストボックスの後ろの **タグの設定** ボタンをクリックして、現在の接続にタグを指定します。表示されるドロップダウンリストで、タグの設定や管理を行えます： <ul><li>タグの設定：ドロップダウンリストから対象のタグを選択して設定を完了します。リストが空の場合は、まず新しいタグを作成してください。   </li><li>タグの管理：リストの一番下にある **<UI-TERM key="obcloud-console.components.Tags.EditTagsModal.CreateATag">タグを作成</UI-TERM>** ボタン、またはリストの上部にある設定アイコンをクリックすると、**<UI-TERM key="obcloud-console.MainMenu.org.constant.TagManagement">タグ</UI-TERM>** ウィンドウが表示されます。タグ管理ウィンドウでは、作成したタグの編集や削除を行えます。また、上部の **<UI-TERM key="oms-cloud.ListTag.TagModal.NewLabel">新しいタグ</UI-TERM>** ボタンをクリックして、新しいタグの名前とアイコンの色を指定できます。</li></ul> |
   | スマート解析        | テキストボックスに接続文字列情報を貼り付けると、ODCが自動的に接続文字列を認識し、各接続情報をウィンドウに入力します。  |
   | 接続モード        | **Oracle**を選択します（論理データベースはMySQLモードのみサポートします）。 |
   | 接続アドレス        |<ul><li>**<UI-TERM key="oms-v2.Endpoint.components.DB2Form.HostIp">ホストIP</UI-TERM>**：接続先のデータベースが存在するサーバーのIPアドレス情報。</li><li>**<UI-TERM key="portal.connection.form.port">ポート</UI-TERM>**：接続先のデータベースが存在するサーバーのポート番号情報。</li><li> **<UI-TERM key="ocp-v2.Report.Scan.ReportContent.ClusterName">クラスター名</UI-TERM>**：接続先のデータベースが存在するクラスタの名前（論理データベースは入力不要）。</li><li>**<UI-TERM key="oas.Optimization.Outline.NameOfTheTenant">テナント名</UI-TERM>**：接続先のデータベースが存在するテナントの名前（論理データベースは入力不要）。</li></ul><main id="notice" type='explain'><h4>説明</h4><p>ホスト名とポート番号は、接続先のデータベースが存在するテナント情報ページから取得できます。例えば、パブリッククラウドやOCP上で作成されたテナントなどです。</p></main>  |
   | データベースアカウント       | <ul><li> **<UI-TERM key="oms-community.endpoints.DbpForm.DatabaseUsername">データベースユーザー名</UI-TERM>**：テナント内で作成されたユーザー。</li><li> **<UI-TERM key="OMS.endpoints.OracleForm.FormItem.DatabasePassword">データベースのパスワード</UI-TERM>**：テナント内で作成されたユーザーのパスワード。データベースパスワードボックスの後ろの **<UI-TERM key="oat.Tool.DataX.TestConnection">接続テスト</UI-TERM>** ボタンをクリックして、ターゲットデータベースに接続できるか確認します。</li><li> **パスワードの保存**：このオプションをオフにすると、接続情報にデータベースのパスワード情報が保存されません。接続または接続テストを行うたびに、ポップアップされるパスワード入力ウィンドウにデータベースのパスワードを入力する必要があります。このオプションをオンにすると、接続情報にデータベースのパスワード情報が保存され、接続するたびにデータベースのパスワードを入力する必要がありません。</li></ul> <main id="notice" type='explain'><h4>説明</h4><p><ul><li>設定情報に誤りがある場合、ユーザー名やパスワードが間違っている、ネットワーク異常など、エラーメッセージが表示されます。</li><li>ユーザーは自身が所属するテナント内のデータベースにのみ接続できます。それ以外の場合、テスト失敗のエラーが表示されます。</li><li>ODC V4.0.0以降のバージョンでは、アカウントとパスワードを入力しなくても接続を保存できます。</li></ul></p></main> |
   | SQLクエリのタイムアウト  | SQLのタイムアウト時間をカスタマイズできます。SQLクエリが指定された時間を超えると、クエリは自動的に終了します（デフォルトは60秒）。  |
   | sysテナントアカウント設定 | `sys` テナントアカウントを使用してテナントビューをクエリするかどうかを選択し、選択した場合は、**<UI-TERM key="password.label.account">アカウント</UI-TERM>** と **<UI-TERM key="oms-v2.EndpointPublic.components.MySqlForm.Password">パスワード</UI-TERM>** を入力します。<br> データベースタイプが物理データベースの場合は、`sys` テナントビューのクエリ権限を持つアカウントとパスワードを入力してください。**<UI-TERM key="portal.connection.form.address">接続アドレス</UI-TERM>** に **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.DataBackupList.Tenant">テナント</UI-TERM>** が `sys` として指定されている場合、この項目は自動的に入力されます。<ul><li> **アカウント**：`sys` テナントビューのクエリ権限を持つアカウント。</li><li> **<UI-TERM key="oms-v2.EndpointPublic.components.KafkaForm.Password">パスワード</UI-TERM>**：アカウントに対応するパスワード。</li></ul>    アカウントとパスワードの情報を入力した後、パスワードボックスの後ろの **<UI-TERM key="oms-cloud.EndpointPublic.components.FormContent.TestConnection">接続テスト</UI-TERM>** ボタンをクリックして、アカウント情報が正しいか確認します。<main id="notice" type='explain'><h4>説明</h4><p></p><ul><li> ODC V2.3.0以降のバージョンでは、インポートおよびエクスポート機能は、接続作成時の詳細設定でroot@sysユーザーを設定する必要があります。</li><li> ODC V2.4.1以降のバージョンでは、インポートおよびエクスポート機能によるビュー情報のクエリ時の `root@sys` アカウントへの依存関係がなくなりました(`root@sys` アカウントが設定されていない場合、ODCの一部のオブジェクト、例えばストアドプロシージャや関数などはエクスポート機能をサポートしません。`root@sys` アカウントが設定されている場合、`sys` テナントのビュー情報にアクセスすることで最適なデータルーティング戦略を得て、エクスポート速度を向上させることができます)。</li><li>  **sysテナントアカウントとパスワード** は、クラスタテナント内のユーザーのアカウントとパスワードです（アカウントに「@sys#クラスタ」と入力しないでください）。例：アカウントは `root` です。 </li></ul></main> |

3. ページ下部の **<UI-TERM key="oms-v2.Sync.New.Save">保存する</UI-TERM>** ボタンをクリックすると、現在の設定情報がODC接続リストに永続的に保存されます。再度ODCにログインする際、接続設定リストからその接続を直接選択することができます。接続設定を保存する際、接続テストが成功している必要はありません。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>保存する前に、<b>接続テスト</b>をクリックしてデータベース接続テストを行うことができます。データベースのユーザー名とパスワードが正しい場合、<b>接続成功</b>と表示されます。 </p>
   </main>
