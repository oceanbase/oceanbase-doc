## 前提条件

* OceanBaseデータベースがインストール済みであり、Oracleモードのユーザーテナントが作成されていること。OceanBaseデータベースのインストール手順の詳細については、[デプロイの概要](../../../../400.deploy/100.deploy-overview.md)を参照してください。
* Visual StudioおよびNuGetパッケージマネージャープラグインと.NET Frameworkコンポーネントがインストール済みであること。
* OceanBase Connector/ODBCドライバーがインストール済みであること。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>OceanBase公式サイトの<a href="https://www.oceanbase.com/softwarecenter-enterprise">リソース > ダウンロードセンター > Enterprise Edition</a>ページの<b>ドライバーとミドルウェア</b>モジュールから、OceanBase ODBCドライバーWindows版のインストールパッケージをダウンロードしてください。Windows版OceanBase Connector/ODBCドライバーのインストールパッケージはワンクリックデプロイメント方式であり、デフォルトのガイドステップに従ってインストールするだけで済みます。</p>
    </main>

## 手順

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>本記事で示されている操作手順は、Windows環境においてVisual Studio Community 2019を使用してこのプロジェクトをコンパイルおよび実行する方法です。他のOS環境やコンパイラを使用している場合は、操作手順が若干異なる場合があります。</p>
</main>

1. `sqlsugar-oceanbase-odbc` プロジェクトを開きます。
2. SqlSugar関連のパッケージをインストールします。
3. データソースを設定します。
4. `sqlsugar-oceanbase-odbc` プロジェクト内のデータソースを修正します。
5. プロジェクトをビルドします。
6. アプリケーションを実行します。
7. 出力結果を確認します。

### ステップ3：データソースを設定する

1. データベースの接続情報を取得します。

    OceanBaseデータベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。

    **例：**

    ```shell
    obclient -hxxx.xxx.xxx.xxx -P2881 -usys@oracle001 -p******
    ```

    **パラメータの説明：**

    * `-h`：OceanBaseデータベースへの接続IPアドレス。ODP接続方式ではODPアドレスを使用し、直接接続方式ではOBServerノードのIPアドレスを使用します。
    * `-P`：OceanBaseデータベースへの接続ポート。ODP接続方式のデフォルトポートは`2883`で、ODPデプロイ時にカスタマイズ可能です。直接接続方式のデフォルトポートは`2881`で、OceanBaseデータベースのデプロイ時にカスタマイズ可能です。
    * `-u`：テナントの接続アカウント。ODP接続の一般的な形式は`ユーザー名@テナント名#クラスタ名`または`クラスタ名:テナント名:ユーザー名`です。直接接続方式の形式は`ユーザー名@テナント名`です。
    * `-p`：アカウントのパスワード。

    詳細な接続文字列の情報については、[OBClientを使用してOceanBaseテナントに接続する](../../100.connect-to-oceanbase-database-of-oracle-mode/200.connect-to-an-oceanbase-tenant-by-using-obclient-of-oracle-mode.md)を参照してください。

2. OceanBase Connector/ODBCドライバーが正常にインストールされているか確認します。

    **コントロールパネル** > **システムとセキュリティ** > **管理ツール** > **ODBCデータソース(64ビット)** > **ドライバー** を選択します。OceanBase Connector/ODBCドライバーが正常にインストールされている場合、ここに表示されます。

## プロジェクトコードについて

[sqlsugar-oceanbase-odbc](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.0/3.develop/demo/C%26C%2B%2B/sqlsugar-oceanbase-odbc.zip) をクリックしてプロジェクトコードをダウンロードします。これは、`sqlsugar-oceanbase-odbc.zip` という名前の圧縮ファイルです。

解凍すると、`sqlsugar-oceanbase-odbc` という名前のフォルダが作成されます。ディレクトリ構造は以下のとおりです：

```shell
sqlsugar-oceanbase-odbc
├─ Program.cs
├─ sqlsugar-oceanbase-odbc.csproj
└─ sqlsugar-oceanbase-odbc.sln
```

**ファイルの説明：**

* `Program.cs`：プロジェクトのメインプログラムファイルであり、プロジェクトのエントリポイントとデータテーブルの構造定義、およびデータテーブル操作を実装したソースコードファイルが含まれています。

* `sqlsugar-oceanbase-odbc.csproj`：Visual Studioのプロジェクトのメインプロジェクトファイルであり、プロジェクトの設定、依存関係、ビルド情報を定義するために使用されます。

* `sqlsugar-oceanbase-odbc.sln`：Visual Studioのソリューションファイルであり、このプロジェクトおよび関連プロジェクトの情報が含まれており、複数のプロジェクトを一元管理およびビルドするために使用されます。

### Program.csファイルのコード紹介

`Program.cs` コードは、SqlSugarを使用してOceanBaseデータベースを操作する方法を示しており、テーブルの作成、データの挿入、クエリなどの基本的な操作を実装しています。同時に、`AopEvents` オブジェクトを使用してログレコードなどのイベントコールバック関数を設定し、デバッグやトラブルシューティングを容易にします。

本記事の `Program.cs` ファイルのコードには、主に以下の部分が含まれます：

1. ネームスペースのインポート。

    `using` キーワードを使用して、ネームスペース `System`、`SqlSugar`、`System.Linq`、`System.Data`、`System.Data.Odbc` をインポートします。これらは、関連するデータアクセスクラスとデータベース操作クラスおよびメソッドをインポートするために使用されます。

    **コード：**

    ```c
    using System;
    using SqlSugar;
    using System.Linq;
    using System.Data;
    using System.Data.Odbc;
    ```

2. 関連するクラスとメソッドを配置するためのネームスペースを定義します。

    `GbaseTest` という名前のネームスペースを定義し、そのネームスペース内で `Program` と `TestEntity` の2つのクラスを定義します。

    **コード：**

    ```c
    namespace GbaseTest
    {
        internal class Program
        {
            ...
            ...
        }

        public class TestEntity
        {
            ...
            ...
        }
    }
    ```

3. プログラムの主要なロジックを含む `Program` という名前のクラスを定義します。

   `Program` という名前のクラスを定義し、プログラムの主要なロジックを含みます。具体的な手順は以下のとおりです：

   1. データベース接続文字列を格納するための、公開された静的文字列型変数 `ConnectionString` を定義します。この変数は、現在のプログラムアセンブリ内の任意の場所からアクセスできます。ここで、`DSN=your_dsn` はODBC接続方式を使用し、`your_dsn` という名前のデータソースを使用することを示します。

       <main id="notice" type='notice'>
         <h4>注意</h4>
         <p>プログラムを実行する際は、<b>ステップ1</b> で作成したデータソース名に <code>your_dsn</code> を置き換えてください。</p>
       </main>

   2. Mainメソッド：プログラムのエントリポイントであり、プログラムの主要なロジックを含みます。
      1. `try-catch` ブロック：
         1. `try` キーワードを使用して、例外を引き起こす可能性のあるコード、`using` ステートメント、およびデータベース操作を囲みます。
         2. `catch` キーワードを使用して例外をキャッチし、処理を行います。
      2. 最後に、プログラム終了前に `Program End.` を出力します。

   **コード：**

   ```c
       internal class Program
       {
           public static string ConnectionString = "DSN=your_dsn";

           static void Main(string[] args)
           {
               try
               {
                   using (...)
                   {
                       //データベース操作
                   }
               }
               catch (Exception ex)
               {
                   ...
                   ...
               }

               Console.WriteLine("Program End.");
           }
       }
   ```

4. `using` ステートメント。

    `ConnectionConfig` を使用して、データベース接続情報とその他のオプションを設定します。これには、データベースタイプODBC、接続文字列 `ConnectionString`、主キーのタイプ `Attribute`、自動接続クローズ、ログ実行イベントコールバック関数の設定が含まれます。`SqlSugarClient` オブジェクトを使用すると、テーブルの作成、データの挿入、クエリなど、データベース操作を簡単に実行できます。`using` ステートメントを使用すると、データベース接続の閉じるなど、関連するリソースを自動的に解放できます。具体的な手順は以下のとおりです：

    1. `SqlSugarClient` オブジェクトを作成し、`db` という名前の変数に代入します。

    2. 接続設定インスタンスを作成し、オブジェクト初期化子を使用して `DbType`、`ConnectionString`、`InitKeyType`、`IsAutoCloseConnection`、`AopEvents` などのプロパティを初期化します。

       1. データベースタイプをODBCに設定します。
       2. 接続文字列を `ConnectionString` に設定します。
       3. 主キーのタイプを `Attribute` に設定します。
       4. 自動接続クローズを設定します。

       5. `AopEvents` のログ実行イベントコールバック関数を設定します。ログ実行イベントコールバック関数の実装ロジックを設定します。ここで、`sql` は実行されるSQL文を、`p` はSQL文のパラメータリストを表します。実装ロジックでは、SQL文とパラメータリストをコンソールに出力します。

    **コード：**

    ```c
                    using (SqlSugarClient db = new SqlSugarClient(new ConnectionConfig()
                    {
                        DbType = SqlSugar.DbType.Odbc,
                        ConnectionString = ConnectionString,
                        InitKeyType = InitKeyType.Attribute,
                        IsAutoCloseConnection = true,
                        AopEvents = new AopEvents
                        {
                            OnLogExecuting = (sql, p) =>
                            {
                                Console.WriteLine(sql);
                                Console.WriteLine(string.Join(",", p?.Select(it => it.ParameterName + ":" + it.Value)));
                            }
                        }
                    }))
    ```

5. データベース操作。

    `SqlSugarClient.Ado.ExecuteCommand` メソッドを使用してSQL文を実行し、テーブルの作成とデータの挿入を行い、`SqlSugarClient.Ado.SqlQuery` メソッドを使用してデータのクエリを実行し、クエリ結果をイテレーションして出力します。`SqlSugarClient` オブジェクトを使用すると、テーブルの作成、データの挿入、クエリなど、データベース操作を簡単に実行できます。具体的な手順は以下のとおりです：

    1. テーブルの作成開始を示すヒントメッセージを出力します。
    2. SQL文を実行して、`id` と `name` の2つの列を含む `test_tbl1` という名前のテーブルを作成します。

    3. データの挿入開始を示すヒントメッセージを出力します。
    4. 変数 `tableName` を定義し、`test_tbl1` に代入します。この変数はテーブル名を格納するために使用されます。
    5. SQL文を実行して、`test_tbl1` という名前のテーブルにデータを挿入します。これには3つのレコードが含まれ、それぞれ `id` が `1`、`2`、`3` で、`name` が `John`、`Jack`、`Amy` です。

    6. データのクエリ開始を示すヒントメッセージを出力します。
    7. SQL文を実行して、`test_tbl1` という名前のテーブル内のすべてのデータをクエリし、クエリ結果を変数 `data` に代入します。`TestEntity` はクエリ結果のエンティティタイプです。
    8. クエリ結果のイテレーション開始を示すヒントメッセージを出力します。
    9. クエリ結果をイテレーションし、各レコードを変数 `item` に代入します。各レコードの `id` と `name` フィールドを出力します。

    **コード：**

    ```c
                    {
                        Console.WriteLine("Create Table:");
                        db.Ado.ExecuteCommand("CREATE TABLE test_tbl1(id NUMBER PRIMARY KEY, name VARCHAR2(50))");

                        Console.WriteLine("Insert Data:");
                        string tableName = "test_tbl1";
    ```

6. `catch` キーワードを使用して例外をキャッチし、処理を行います。

    プログラムで例外が発生すると、例外に関する情報が出力されます。例外をキャッチして情報を出力することで、デバッグや問題の特定を支援し、プログラムの堅牢性と信頼性を一定程度保証します。具体的な手順は以下のとおりです：

    1. `catch` キーワードを使用して例外をキャッチし、キャッチした例外オブジェクトを変数 `ex` に代入します。この例外オブジェクトは `Exception` タイプまたはそのサブクラスのインスタンスです。

    2. プログラムで例外が発生したことを示すヒントメッセージを出力します。

    3. キャッチした例外オブジェクトを文字列に変換して出力します。この文字列には、例外のタイプ、メッセージ、スタックトレースなどの情報が含まれます。

    **コード：**

    ```c
                catch (Exception ex)
                {
                    Console.WriteLine("Program Exception:");
                    Console.WriteLine(ex.ToString());
                }
    ```

7. `TestEntity` クラスを定義します。

    `TestEntity` という名前のクラスを定義します。このクラスには、`id` と `name` の2つのプロパティがあり、それぞれエンティティオブジェクトの `id` と `name` フィールドを表します。具体的な手順は以下のとおりです：

    1. `TestEntity` という名前のpublicクラスを定義します。

    2. エンティティオブジェクトの `id` フィールドを表すための、public整数型プロパティ `id` を定義します。プロパティの `get` および `set` メソッドを使用して、このフィールドを読み取りおよび設定できます。

    3. エンティティオブジェクトの `name` フィールドを表すための、public文字列型プロパティ `name` を定義します。プロパティの `get` および `set` メソッドを使用して、このフィールドを読み取りおよび設定できます。

    **コード：**

    ```c
        public class TestEntity
        {
            public int id { get; set; }
            public string name { get; set; }
        }
    ```
