# クエリにおける文字列関数の使用

一般的な文字列関数には、文字列の長さを取得する（Length）、文字列を切り出す（Substr）、文字列の連結、文字列の大文字小文字変換（Upper/Lower）、文字列の前後の空白を削除する（Ltrim/Rtrim/Trim）などがあります。

注意が必要なのは、Oracleテナント内で、文字列長関数Lengthの長さの単位は文字であり、Lengthbの文字列長の単位はバイトであり、文字セットに関連しているということです。

## 例

### 例1

漢字 '中' の文字列の長さを確認します。

```unknow
obclient> SELECT LENGTH('中'), LENGTHB('中') FROM DUAL;
+---------------+----------------+
| LENGTH('中')  | LENGTHB('中')  |
+---------------+----------------+
|             1 |              3 |
+---------------+----------------+
1 row in set
```

### 例2

NLS_CHARACTERSET文字セットの長さを確認します。

```unknow
obclient> SELECT * FROM sys.nls_database_parameters WHERE PARAMETER='NLS_CHARACTERSET';
+------------------+----------+
| PARAMETER        | VALUE    |
+------------------+----------+
| NLS_CHARACTERSET | AL32UTF8 |
+------------------+----------+
1 row in set
```
