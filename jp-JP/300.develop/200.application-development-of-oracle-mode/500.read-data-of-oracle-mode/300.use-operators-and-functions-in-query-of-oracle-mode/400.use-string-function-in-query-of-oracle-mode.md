# クエリでの文字列関数の使用

よく使われる文字列関数には、文字列の長さを求める（Length）、文字列の切り出し（Substr）、文字列の連結、文字列の大文字・小文字変換（Upper/Lower）、文字列の前後接辞の削除（Ltrim/Rtrim/Trim）があります。

注意すべき点として、Oracleテナントでは、文字列長関数Lengthの長さ単位は文字であり、LengthBの文字列長単位はバイトであり、かつ文字セットに依存します。

## 例

### 例1

漢字「中」の文字列長を確認します。

```unknow
obclient> SELECT LENGTH('中'), LENGTHB('中') FROM DUAL;
+---------------+----------------+
| LENGTH('中')  | LENGTHB('中')  |
+---------------+----------------+
|             1 |              3 |
+---------------+----------------+
1 row in set
```

### 例2

NLS_CHARACTERSET文字セットの長さを確認します。

```unknow
obclient> SELECT * FROM sys.nls_database_parameters WHERE PARAMETER='NLS_CHARACTERSET';
+------------------+----------+
| PARAMETER        | VALUE    |
+------------------+----------+
| NLS_CHARACTERSET | AL32UTF8 |
+------------------+----------+
1 row in set
```
