# INNER JOIN

内部結合（INNER JOIN）とは、2つ以上のテーブルを結合し、結合条件を満たす複数のテーブルデータを返すために使用されるものです。内部結合は単純結合とも呼ばれます。

## 内部結合の構文

内部結合では、デフォルトで`JOIN`が返す結果は`ON`の後に続く結合条件を満たします。通常、キーワード`INNER`は省略されます。`JOIN`の前後のテーブルはそれぞれ左テーブルと右テーブルと呼ばれ、`ON`の条件は左テーブルと右テーブルの結合条件およびフィルタリング条件を記述します。

内部結合のSQL構文は以下のとおりです：

```sql
SELECT select_list FROM table_name1 [INNER] JOIN table_name2 ON join_condition
[ WHERE query_condition ]
[ ORDER BY column_list ]
```

`WHERE`と`ORDER BY`の両方の句を同時に使用する場合、SQLが返す結果は`JOIN`の結果に基づいて、`WHERE`の後のクエリ条件でフィルタリングされ、さらに`ORDER BY`の後の列に従ってソートされます。

`ON`句がない場合、`INNER JOIN`が返すのは左テーブルと右テーブルのすべてのデータであり、これをデカルト積と呼びます。

同一の結合条件の下で、`ON`句は`WHERE`句に置き換えて内部結合クエリを実現することもできます。構文は以下のとおりです：

```sql
 SELECT select_list FROM table_name1，table_name2 [ WHERE query_condition ]
```

## 例

サンプルテーブルを作成し、データを挿入します。

```sql
obclient [SYS]> CREATE TABLE tbl1(id NUMBER NOT NULL PRIMARY KEY, name VARCHAR(50));
Query OK, 0 rows affected

obclient [SYS]> CREATE TABLE tbl2(id NUMBER NOT NULL PRIMARY KEY, name VARCHAR(50));
Query OK, 0 rows affected

obclient [SYS]> INSERT INTO tbl1 VALUES(1,'A1'),(2,'B1'),(4,'D1'),(6,'F1'),(8,'H1'),(10,'J1');
Query OK, 6 rows affected
Records: 6  Duplicates: 0  Warnings: 0

obclient [SYS]> INSERT INTO tbl2 VALUES(1,'B2'),(3,'C2'),(6,'F2'),(9,'I2');
Query OK, 4 rows affected
Records: 4  Duplicates: 0  Warnings: 0
```

### 結合条件を含むクエリの例

サンプルテーブルを作成し、適切なデータを挿入した上で、結合条件を用いたデータクエリを実行します。

* `tbl1` テーブルと `tbl2` テーブルの `id` が同一の `id` 列と `name` 列のデータを照会します。

   ```sql
   obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1 JOIN tbl2
             ON tbl1.id=tbl2.id;
   +----+------+----+------+
   | ID | NAME | ID | NAME |
   +----+------+----+------+
   |  1 | A1   |  1 | B2   |
   |  6 | F1   |  6 | F2   |
   +----+------+----+------+
   2 rows in set
   ```

* 内部結合を用いて、`tbl1` テーブルと `tbl2` テーブルの `id` が同一の `id` 列と `name` 列のデータを照会します。

   ```sql
   obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1
             INNER JOIN tbl2 ON tbl1.id=tbl2.id;
   +----+------+----+------+
   | ID | NAME | ID | NAME |
   +----+------+----+------+
   |  1 | A1   |  1 | B2   |
   |  6 | F1   |  6 | F2   |
   +----+------+----+------+
   2 rows in set
   ```

* `WHERE` 条件を用いて、`tbl1` テーブルと `tbl2` テーブルの `id` が同一の `id` 列と `name` 列のデータを照会します。

   ```sql
   obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1,tbl2
             WHERE tbl1.id=tbl2.id;
   +----+------+----+------+
   | id | name | id | name |
   +----+------+----+------+
   |  1 | A1   |  1 | B2   |
   |  6 | F1   |  6 | F2   |
   +----+------+----+------+
   2 rows in set
   ```

### 組み合わせ条件クエリの例

上記で作成されたテーブルとデータに基づき、条件を組み合わせてデータクエリを実行します。

* 内部結合 + AND結合条件を使用したデータクエリ。

  ```sql
  obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1
            INNER JOIN tbl2 ON tbl1.id=tbl2.id AND tbl1.id=6;
  +----+------+----+------+
  | id | name | id | name |
  +----+------+----+------+
  |  6 | F1   |  6 | F2   |
  +----+------+----+------+
  1 row in set
  ```

* 内部結合 + WHERE結合条件を使用したデータクエリ。

  ```sql
  obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1
            INNER JOIN tbl2 ON tbl1.id=tbl2.id WHERE tbl1.id=6;
  +----+------+----+------+
  | id | name | id | name |
  +----+------+----+------+
  |  6 | F1   |  6 | F2   |
  +----+------+----+------+
  1 row in set
  ```

* WHERE結合条件 + AND結合条件を使用したデータクエリ。

  ```sql
  obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1,tbl2
            WHERE tbl1.id=tbl2.id AND tbl1.id=6;
  +----+------+----+------+
  | id | name | id | name |
  +----+------+----+------+
  |  6 | F1   |  6 | F2   |
  +----+------+----+------+
  1 row in set
  ```

* 内部結合条件 + ORDER BYソートを使用したデータクエリ。

  ```sql
  obclient [SYS]> SELECT tbl1.id, tbl1.name, tbl2.id, tbl2.name FROM tbl1
            INNER JOIN tbl2 ON tbl1.id=tbl2.id ORDER BY tbl1.id DESC;
  +----+------+----+------+
  | id | name | id | name |
  +----+------+----+------+
  |  6 | F1   |  6 | F2   |
  |  1 | A1   |  1 | B2   |
  +----+------+----+------+
  2 rows in set
  ```
