# FULL JOIN

完全結合（FULL JOIN）とは、完全外部結合を意味し、このステートメントを使用することで、マッチするかどうかに関係なく、すべての結合に含まれるすべての行を返すことができます。

## 背景情報

外部結合（OUTER JOIN）とは、比較演算子を使用して2つのテーブルのデータを比較し、結合結果には結合条件に一致する行だけでなく、条件に一致しない行も含まれることを指します。

外部結合には、完全結合（FULL JOIN）、左結合（LEFT JOIN）、右結合（RIGHT JOIN）が含まれます。外部結合は結合条件を満たすすべての行を返し、同時に一方のテーブルから使用されない行を返し、もう一方のテーブルの対応する位置に`NULL`を補完します。

本記事では主に完全結合の例を説明します。左結合に関する例については[左結合](../200.multi-table-join-query-of-oracle-mode/300.left-join-of-oracle-mode.md)を参照してください。右結合に関する例については[右結合](../200.multi-table-join-query-of-oracle-mode/400.right-join-of-oracle-mode.md)を参照してください。

## FULL JOIN構文

外部結合ステートメントには通常、左側のテーブルと右側のテーブルが含まれます。`JOIN` 句の最も左側に記述されているテーブルが左側のテーブルであり、`JOIN` 句の最も右側に記述されているテーブルが右側のテーブルです。

FULL JOINの構文は以下のとおりです：

```sql
SELECT select_list FROM table_name1 FULL JOIN table_name2 ON join_condition
[ WHERE query_condition ]
[ ORDER BY column_list ];
```

ここで、`table_name1` が左側のテーブル、`table_name2` が右側のテーブルです。

## 例

サンプルテーブルを作成し、適切なデータを挿入します。

```sql
obclient [SYS]> CREATE TABLE tbl_a(id NUMBER NOT NULL PRIMARY KEY, name VARCHAR2(50));
Query OK, 0 rows affected

obclient [SYS]> CREATE TABLE tbl_b(num NUMBER NOT NULL PRIMARY KEY, value NUMBER);
Query OK, 0 rows affected

obclient [SYS]> INSERT INTO tbl_a VALUES(1,'ab'),(2,'cd'),(3,'ef'),(4,'gh');
Query OK, 6 rows affected
Records: 6  Duplicates: 0  Warnings: 0

obclient [SYS]> INSERT INTO tbl_b VALUES(1,1001),(3,1003),(5,1005);
Query OK, 4 rows affected
Records: 4  Duplicates: 0  Warnings: 0
```

### シンプルな全結合クエリ

全結合クエリを使用する場合、左側または右側のテーブルの行でマッチする行が見つからない場合、システムは自動的に `NULL` を埋めます。

例1：テーブル `tbl_a` とテーブル `tbl_b` に対して全結合クエリを実行し、実行結果を取得します。

```sql
obclient [SYS]> SELECT * FROM tbl_a;
+----+------+
| ID | NAME |
+----+------+
|  1 | ab   |
|  2 | cd   |
|  3 | ef   |
|  4 | gh   |
+----+------+
4 rows in set

obclient [SYS]> SELECT * FROM tbl_b;
+-----+-------+
| NUM | VALUE |
+-----+-------+
|   1 |  1001 |
|   3 |  1003 |
|   5 |  1005 |
+-----+-------+
3 rows in set

obclient [SYS]> SELECT * FROM tbl_a FULL JOIN tbl_b ON tbl_a.id=tbl_b.num;
+------+------+--------+-------+
| ID   | NAME |   NUM  | VALUE |
+------+------+--------+-------+
|    1 | ab   |      1 |  1001 |
|    2 | cd   |   NULL |  NULL |
|    3 | ef   |      3 |  1003 |
|    4 | gh   |   NULL |  NULL |
| NULL | NULL |      5 |  1005 |
+------+------+--------+-------+
5 rows in set
```

ご覧のように、テーブル `tbl_a` には値が `5` の行がないため、実行結果ではその行のレコードが `NULL` に埋められています。また、テーブル `tbl_b` には値が `2` および `4` の行がないため、実行結果ではこれらの2行が `NULL` に埋められています。

### 全結合とWHERE句の組み合わせ使用

全結合を使用して結合結果を取得した後、`WHERE` 句を使用して結合結果をフィルタリングできます。

例2：テーブル `tbl_a` とテーブル `tbl_b` に対して全結合クエリを実行した後、テーブル `tbl_b` 内の `value=1003` のデータを返します。

```sql
obclient [SYS]> SELECT * FROM tbl_a;
+----+------+
| ID | NAME |
+----+------+
|  1 | ab   |
|  2 | cd   |
|  3 | ef   |
|  4 | gh   |
+----+------+
4 rows in set

obclient [SYS]> SELECT * FROM tbl_b;
+-----+-------+
| NUM | VALUE |
+-----+-------+
|   1 |  1001 |
|   3 |  1003 |
|   5 |  1005 |
+-----+-------+
3 rows in set

obclient [SYS]> SELECT * FROM tbl_a FULL JOIN tbl_b ON tbl_a.id=tbl_b.num WHERE tbl_b.value=1003;
+----+------+-----+-------+
| ID | NAME | NUM | VALUE |
+----+------+-----+-------+
|  3 | ef   |   3 |  1003 |
+----+------+-----+-------+
1 row in set
```
