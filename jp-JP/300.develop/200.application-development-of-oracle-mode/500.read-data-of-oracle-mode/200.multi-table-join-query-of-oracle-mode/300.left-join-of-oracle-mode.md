# LEFT JOIN

左結合（LEFT JOIN）とは、左外部結合を示します。このステートメントは、右テーブルのマッチしない行を除き、左テーブルのすべての行を返します。

## 背景情報

外部結合（OUTER JOIN）とは、比較演算子を使用して2つのテーブルのデータを比較し、結合結果には結合条件に一致する行だけでなく、条件に一致しない行も含まれることを指します。

外部結合には、完全結合（FULL JOIN）、左結合（LEFT JOIN）、右結合（RIGHT JOIN）が含まれます。外部結合は結合条件を満たすすべての行を返し、同時に一方のテーブルから使用されない行を返し、もう一方のテーブルの対応する位置に`NULL`を埋めます。

本記事では主に左結合の例を説明します。完全結合に関する例については[完全結合](../200.multi-table-join-query-of-oracle-mode/200.full-join-of-oracle-mode.md)を参照してください。右結合に関する例については[右結合](../200.multi-table-join-query-of-oracle-mode/400.right-join-of-oracle-mode.md)を参照してください。

## LEFT JOIN構文

外部結合ステートメントには通常、左側のテーブルと右側のテーブルが含まれます。`JOIN` 句の最も左側に記述されているテーブルが左側のテーブルであり、`JOIN` 句の最も右側に記述されているテーブルが右側のテーブルです。

LEFT JOINの構文は以下のとおりです：

```sql
SELECT select_list FROM table_name1 LEFT JOIN table_name2 ON join_condition
[ WHERE query_condition ]
[ ORDER BY column_list ];
```

ここで、`table_name1` が左側のテーブル、`table_name2` が右側のテーブルです。

## 例

サンプルテーブルを作成し、適切なデータを挿入します。

```sql
obclient [SYS]> CREATE TABLE tbl_a(id NUMBER NOT NULL PRIMARY KEY, name VARCHAR2(50));
Query OK, 0 rows affected

obclient [SYS]> CREATE TABLE tbl_b(num NUMBER NOT NULL PRIMARY KEY, value NUMBER);
Query OK, 0 rows affected

obclient [SYS]> INSERT INTO tbl_a VALUES(1,'ab'),(2,'cd'),(3,'ef'),(4,'gh');
Query OK, 6 rows affected
Records: 6  Duplicates: 0  Warnings: 0

obclient [SYS]> INSERT INTO tbl_b VALUES(1,1001),(3,1003),(5,1005);
Query OK, 4 rows affected
Records: 4  Duplicates: 0  Warnings: 0
```

### シンプルな左結合クエリ

`JOIN` が返すデータに、結合条件およびフィルタ条件を満たすデータに加えて、左テーブルのフィルタ条件を満たすものの結合条件を満たさないデータも含める必要がある場合、左結合を使用できます。左結合で返される結果において、右テーブルに属するデータが存在しない場合、その列は `NULL` を返します。

例1：テーブル `tbl_a` とテーブル `tbl_b` に対して左結合クエリを実行し、実行結果を取得します。

```sql
obclient [SYS]> SELECT * FROM tbl_a;
+----+------+
| ID | NAME |
+----+------+
|  1 | ab   |
|  2 | cd   |
|  3 | ef   |
|  4 | gh   |
+----+------+
4 rows in set

obclient [SYS]> SELECT * FROM tbl_b;
+-----+-------+
| NUM | VALUE |
+-----+-------+
|   1 |  1001 |
|   3 |  1003 |
|   5 |  1005 |
+-----+-------+
3 rows in set

obclient [SYS]> SELECT tbl_a.id, tbl_a.name, tbl_b.num, tbl_b.value FROM tbl_a LEFT JOIN tbl_b on (tbl_a.id=tbl_b.num);
+------+------+--------+-------+
| ID   | NAME |   NUM  | VALUE |
+------+------+--------+-------+
|    1 | ab   |      1 |  1001 |
|    2 | cd   |   NULL |  NULL |
|    3 | ef   |      3 |  1003 |
|    4 | gh   |   NULL |  NULL |
+------+------+--------+-------+
4 rows in set
```

### 左結合とWHERE句の組み合わせ使用

左結合を使用して結合結果を取得した後、`WHERE` 句を使用して結合結果をフィルタリングできます。

```sql
obclient [SYS]> SELECT * FROM tbl_a;
+----+------+
| ID | NAME |
+----+------+
|  1 | ab   |
|  2 | cd   |
|  3 | ef   |
|  4 | gh   |
+----+------+
4 rows in set

obclient [SYS]> SELECT * FROM tbl_b;
+-----+-------+
| NUM | VALUE |
+-----+-------+
|   1 |  1001 |
|   3 |  1003 |
|   5 |  1005 |
+-----+-------+
3 rows in set

obclient [SYS]> SELECT tbl_a.id, tbl_a.name, tbl_b.num, tbl_b.value FROM tbl_a LEFT JOIN tbl_b ON tbl_a.id=tbl_b.num WHERE tbl_b.num IS NOT NULL;
+----+------+-----+-------+
| ID | NAME | NUM | VALUE |
+----+------+-----+-------+
|  1 | ab   |   1 |  1001 |
|  3 | ef   |   3 |  1003 |
+----+------+-----+-------+
2 rows in set
```
