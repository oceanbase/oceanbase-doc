# DBLinkを使用したクエリ

OceanBaseデータベースのDBLink機能は、データソース間でのアクセスを実現しており、ローカルデータベースからリモートデータベースにアクセスできます。DBLinkが正常に作成されると、テーブル、ビュー、シノニムなどのリモートデータベースのオブジェクトにDBLinkを介してアクセスできます。

## 前提条件

DBLinkが作成済みであること。DBLinkの作成方法の詳細については、[DBLinkの作成](../../../700.reference/300.database-object-management/200.manage-object-of-oracle-mode/1000.manage-dblink-of-oracle-mode/100.create-a-dblink-of-oracle-mode.md)を参照してください。

## リモートデータベース内のテーブルデータのクエリ

SQL文は以下のとおりです：

```sql
SELECT select_expr_list FROM table_name@dblink_name WHERE where_conditions;
```

パラメータの説明：

* `select_expr_list`：クエリ対象の式または列名を指定します。複数の列は英語のカンマ（,）で区切り、アスタリスク（\*）はすべての列を示します。

* `table_name@dblink_name`：クエリ対象のリモートデータベースのテーブルを指定します。複数のデータベースは英語のカンマ（,）で区切ります。

* `where_conditions`：フィルタ条件を指定します。クエリ結果には条件を満たすデータのみが含まれます。これはオプションです。

## 例

DBLinkを使用する手順は以下のとおりです：

1. 以下のSQL文を使用して、リモートのOceanBaseデータベースのOracleモードに接続するDBLinkを作成します。DBLinkの名前は`my_link`、リモートテナントは`oracle001`です。

    ```sql
    CREATE DATABASE LINK my_link CONNECT TO sys@oracle001 IDENTIFIED BY "******" OB HOST 'xxx.xxx.xxx.xxx:2881';
    ```

2. 以下のSQL文を使用して、`my_link`という名前のDBLinkを通じて、リモートデータベース内のテーブル`test_tbl1`のデータをクエリします。

    ```sql
    SELECT * FROM test_tbl1@my_link;
    ```

    実行結果は次のとおりです：

    ```shell
    +------+------+
    | COL1 | COL2 |
    +------+------+
    |    1 | a1   |
    |    2 | b2   |
    +------+------+
    2 rows in set
    ```
