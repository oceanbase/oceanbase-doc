# 集合演算

OceanBaseデータベースのOracleモードでは、集合演算子`UNION`、`UNION ALL`、`INTERSECT`、および`MINUS`を使用して複数のクエリを結合できます。これらの集合演算子はすべて同じ優先順位を持ちます。SQLステートメントに複数の集合演算子が含まれている場合、OceanBaseデータベースは明示的に括弧で演算の順序を指定しない限り、左から右の順にそれらを計算します。

本記事では、集合演算子`UNION`、`UNION ALL`、`INTERSECT`、および`MINUS`の使用方法について説明します。

## 構文

```sql
select_clause_set_left
{ UNION | UNION ALL | MINUS | INTERSECT}
select_clause_set_right
```

その他の集合クエリ構文の詳細については、[集合関数SELECT](../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/500.select-of-oracle-mode/200.collection-select-of-oracle-mode.md)を参照してください。

**パラメータの説明：**

* `select_clause_set_left`：`SELECT` ステートメントで、集合演算用の左側のセットを返します。
* `select_clause_set_right`：`SELECT` ステートメントで、集合演算用の右側のセットを返します。
* `UNION`：2つ以上の `SELECT` ステートメントの結果セットを1つのセットに統合し、重複する行を削除します。
* `UNION ALL`：2つ以上の `SELECT` ステートメントの結果セットを1つのセットに統合し、重複する行を削除しません。
* `INTERSECT`：2つの `SELECT` ステートメントの結果セットの共通部分を返します。
* `MINUS`：最初の `SELECT` ステートメントの結果セットから、2番目の `SELECT` ステートメントの結果セットに含まれない行を返します。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースのOracleモードは、<code>MINUS</code> のみをサポートしており、<code>EXCEPT</code> はサポートされていません。両者の意味は同じです。</p>
    </main>

その他の集合演算子のルールと制限の詳細については、[複合クエリ](../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/800.queries-and-subqueries-of-oracle-mode/400.collection-of-oracle-mode.md)を参照してください。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>各集合演算子は <code>SELECT</code> ステートメントの結果セットのみを操作でき、各結果セットの列数とデータ型は同じでなければなりません。</p>
</main>

## 例

既存のテストテーブル `test_tbl1` と `test_tbl2` があり、データは以下のとおりです：

```shell
obclient [SYS]> SELECT * FROM test_tbl1;
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
6 rows in set

obclient [SYS]> SELECT * FROM test_tbl2;
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
6 rows in set
```

### UNIONの例

以下のSQLステートメントでは、`UNION` を使用して2つの `SELECT` ステートメントの結果セットを1つの集合に統合します。統合された結果セットから重複する行は削除されます。

```sql
SELECT id, name FROM test_tbl1
UNION
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
9 rows in set
```

### UNION ALLの例

以下のSQLステートメントでは、`UNION ALL` を使用して2つの `SELECT` ステートメントの結果セットを1つの集合に統合します。統合された結果セットから重複する行は削除されません。

```sql
SELECT id, name FROM test_tbl1
UNION ALL
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
12 rows in set
```

### INTERSECTの例

以下のSQLステートメントでは、`INTERSECT` を使用して2つの `SELECT` ステートメントの結果セットの共通部分を返します。

```sql
SELECT id, name FROM test_tbl1
INTERSECT
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
+------+------+
3 rows in set
```

### MINUSの例

以下のSQLステートメントでは、`MINUS` を使用して最初の `SELECT` ステートメントの結果セットに含まれているが、2番目の `SELECT` ステートメントの結果セットには含まれない行を返します。

```sql
SELECT id, name FROM test_tbl1
MINUS
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
3 rows in set
```
