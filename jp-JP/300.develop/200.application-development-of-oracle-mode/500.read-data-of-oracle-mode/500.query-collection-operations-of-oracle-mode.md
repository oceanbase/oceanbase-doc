# 集合演算

OceanBaseデータベースのOracleモードでは、集合演算子 `UNION`、`UNION ALL`、`INTERSECT`、および `MINUS` を使用して複数のクエリを組み合わせることができます。これらの集合演算子はすべて同じ優先順位を持ちます。SQLステートメントに複数の集合演算子が含まれる場合、OceanBaseデータベースは、括弧で演算順序を明示的に指定しない限り、左から右の順に評価します。

本記事では、集合演算子 `UNION`、`UNION ALL`、`INTERSECT`、および `MINUS` の使用方法について説明します。

## 構文

```sql
select_clause_set_left
{ UNION | UNION ALL | MINUS | INTERSECT}
select_clause_set_right
```

集合クエリ構文の詳細については、[集合SELECT](../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/500.select-of-oracle-mode/200.collection-select-of-oracle-mode.md)を参照してください。

**パラメータの説明：**

* `select_clause_set_left`：集合演算の左側のセットを返す `SELECT` ステートメントです。
* `select_clause_set_right`：集合演算の右側のセットを返す `SELECT` ステートメントです。
* `UNION`：2つ以上の `SELECT` ステートメントの結果セットを1つのセットに結合し、重複行を削除します。
* `UNION ALL`：2つ以上の `SELECT` ステートメントの結果セットを1つのセットに結合し、重複行を削除しません。
* `INTERSECT`：2つの `SELECT` ステートメントの結果セットの共通部分を返します。
* `MINUS`：最初の `SELECT` ステートメントの結果セットから、2番目の `SELECT` ステートメントの結果セットに含まれない行を返します。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OceanBaseデータベースのOracleモードは <code>MINUS</code> のみをサポートし、<code>EXCEPT</code> はサポートしていません。両者の意味は同じです。</p>
    </main>

集合演算子のルールと制限の詳細については、[複合クエリ](../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/800.queries-and-subqueries-of-oracle-mode/400.collection-of-oracle-mode.md)を参照してください。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>各集合演算子は、<code>SELECT</code> ステートメントの結果セットに対してのみ操作でき、各結果セットの列数とデータ型は同じでなければなりません。</p>
</main>

## 例

テストテーブル `test_tbl1` と `test_tbl2` があり、データは以下のとおりです：

```shell
obclient [SYS]> SELECT * FROM test_tbl1;
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
6 rows in set

obclient [SYS]> SELECT * FROM test_tbl2;
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
6 rows in set
```

### UNIONの例

以下のSQLステートメントでは、`UNION` を使用して2つの `SELECT` ステートメントの結果セットを1つのセットに結合し、結合後の結果セットから重複行を削除します。

```sql
SELECT id, name FROM test_tbl1
UNION
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
9 rows in set
```

### UNION ALLの例

以下のSQLステートメントでは、`UNION ALL` を使用して2つの `SELECT` ステートメントの結果セットを1つのセットに結合します。結合された結果セットから重複する行は削除されません。

```sql
SELECT id, name FROM test_tbl1
UNION ALL
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
12 rows in set
```

### INTERSECTの例

以下のSQLステートメントでは、`INTERSECT` を使用して2つの `SELECT` ステートメントの結果セットの共通部分を返します。

```sql
SELECT id, name FROM test_tbl1
INTERSECT
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
+------+------+
3 rows in set
```

### MINUSの例

以下のSQLステートメントでは、`MINUS` を使用して、最初の `SELECT` ステートメントの結果セットに含まれているが、2番目の `SELECT` ステートメントの結果セットには含まれていない行を返します。

```sql
SELECT id, name FROM test_tbl1
MINUS
SELECT id, name FROM test_tbl2;
```

実行結果は次のとおりです：

```shell
+------+------+
| ID   | NAME |
+------+------+
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
3 rows in set
```
