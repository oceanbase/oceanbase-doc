# テーブルグループの作成

本記事では、OceanBaseデータベースのOracleモードにおいて、SQL文を使用してテーブルグループを作成する方法について説明します。

## 概要

テーブルグループとは、論理的な概念であり、テーブルの集合を表します。テーブルグループを定義することで、一連のテーブル間の物理的ストレージ上での隣接関係を制御できます。テーブルグループの詳細については、[テーブルグループについて](../../../700.reference/300.database-object-management/200.manage-object-of-oracle-mode/300.manage-table-groups-of-oracle-mode/100.about-table-groups-of-oracle-mode.md)を参照してください。

## 前提条件

テーブルグループを作成する前に、以下の事項を確認する必要があります：

* データベースのOracleテナントに接続されていることを確認してください。データベースへの接続操作については、[接続方法の概要](../100.connect-to-oceanbase-database-of-oracle-mode/100.connection-methods-overview-of-oracle-mode.md)を参照してください。

  <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>現在ログインしているテナントが属するテナントモードは、<code>sys</code>テナントで<code>oceanbase.DBA_OB_TENANTS</code>ビューを照会することで確認できます。 </p>
  </main>

## テーブルグループの作成

### テーブルグループ名の制限と推奨事項

テーブルグループを作成する際には、まずテーブルグループに名前を付ける必要があります。以下は、テーブルグループ名を定義する際の制限と推奨事項です：

* 各テーブルグループの名前は、同一テナント内で一意である必要があります。

* テーブルグループ名は64文字を超えてはなりません。

* テーブルグループ名には大文字と小文字の英字、数字、アンダースコアのみを使用でき、名前は必ず英字またはアンダースコアで始める必要があります。

* テーブルグループ名には、OceanBaseデータベースのキーワードを使用してはなりません。

* テーブルグループ名には、後の使用時に混乱を招かないよう、意味のある名前を付けることを推奨します。

### 構文

`CREATE TABLEGROUP` ステートメントの構文は以下のとおりです：

```sql
CREATE TABLEGROUP tablegroup_name [tablegroup_option];
```

**パラメータの説明：**

`tablegroup_name`：テーブルグループ名。
`tablegroup_option`：テーブルグループの `SHARDING` プロパティ。オプションです。`SHARDING` プロパティを指定しない場合、デフォルトで `ADAPTIVE` のテーブルグループが作成されます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><ul><li>本記事では <code>CREATE TABLEGROUP</code> ステートメントについて簡単に説明しています。詳細な構文情報については、<a href="../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/2500.create-tablegroup-of-oracle-mode.md">CREATE TABLEGROUP</a> を参照してください。</li><li>本記事の例では、すべて <code>CREATE TABLE</code> を使用して <code>TABLEGROUP</code> を指定し、テーブルをテーブルグループに追加しています。また、<a href="../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/1100.alter-tablegroup-of-oracle-mode.md">ALTER TABLEGROUP</a> ステートメントを使用して、テーブルをテーブルグループに追加することもできます。</li></ul></p>
</main>

#### 例1

1. `SHARDING` プロパティを指定しないテーブルグループを作成し、その名前を `test_tbl_tg1` とします。

    ```sql
    CREATE TABLEGROUP test_tbl_tg1;
    ```

2. 以下のSQLステートメントを使用して、Hash + Rangeパーティションのサブパーティションテーブル `test_tbl1_hr` を作成し、`TABLEGROUP` を `test_tbl_tg1` と指定します。

    ```sql
    CREATE TABLE test_tbl1_hr(col1 NUMBER,col2 NUMBER) TABLEGROUP = test_tbl_tg1
    PARTITION BY HASH(col1)
        SUBPARTITION BY RANGE(col2)
        SUBPARTITION TEMPLATE
        (SUBPARTITION p0 VALUES LESS THAN(100),
        SUBPARTITION p1 VALUES LESS THAN(200),
        SUBPARTITION p2 VALUES LESS THAN(300)
        )
    PARTITIONS 10;
    ```

3. 以下のSQLステートメントを使用して、パーティション化されていないテーブル `test_tbl1` を作成し、`TABLEGROUP` を `test_tbl_tg1` と指定するとエラーが表示されます。

    ```sql
    CREATE TABLE test_tbl1 (col NUMBER,col2 NUMBER) TABLEGROUP = test_tbl_tg1;
    ```

    実行結果は次のとおりです：

    ```shell
    ORA-00600: internal error code, arguments: -4179, not all tables are non-partitioned or partitioned, add table to tablegroup not allowed
    ```

4. 以下のSQLステートメントを使用して、Hashパーティションのパーティションテーブル `test_tbl1_h` を作成し、`TABLEGROUP` を `test_tbl_tg1` と指定するとエラーが表示されます。

    ```sql
    CREATE TABLE test_tbl1_h(col1 NUMBER,col2 NUMBER) TABLEGROUP = test_tbl_tg1
      PARTITION BY HASH(col1) PARTITIONS 10;
    ```

    実行結果は次のとおりです：

    ```shell
    ORA-00600: internal error code, arguments: -4179, part level is not equal, add table to tablegroup not allowed
    ```

5. 以下のSQLステートメントを使用して、テーブルグループ `test_tbl_tg1` 内のテーブルを確認します。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>OceanBaseデータベースのOracleモードでは、sys.DBA_OB_TABLEGROUP_TABLESビューを使用してテーブルグループを照会する際、テーブルグループ名に含まれる英字は大文字でなければなりません。</p>
    </main>

    ```sql
    SELECT * FROM sys.DBA_OB_TABLEGROUP_TABLES WHERE tablegroup_name = 'TEST_TBL_TG1';
    ```

    実行結果は次のとおりです：

    ```shell
    +-----------------+-------+--------------+----------+
    | TABLEGROUP_NAME | OWNER | TABLE_NAME   | SHARDING |
    +-----------------+-------+--------------+----------+
    | TEST_TBL_TG1    | SYS   | TEST_TBL1_HR | ADAPTIVE |
    +-----------------+-------+--------------+----------+
    1 row in set
    ```

### テーブルグループの`SHARDING`プロパティを選択する

テーブルグループの`SHARDING`プロパティは、次の値を取ります：

* `NONE`：テーブルグループに追加されるテーブルに制限はありません。
* `PARTITION`：テーブルグループに追加されるテーブルに対応するパーティションは、テーブルグループ内のすべてのテーブルのパーティションとパーティション方式が一致していなければなりません。これには、パーティションタイプ、パーティション数、およびパーティション値が含まれます。
* `ADAPTIVE`：`SHARDING`が指定されない場合のデフォルト値です。テーブルグループに追加されるテーブルに対応するパーティションとサブパーティションは、テーブルグループ内のすべてのテーブルのパーティションとサブパーティションのパーティション方式が一致していなければなりません。これには、パーティションタイプ、パーティション数、およびパーティション値が含まれます。

**同じパーティション方式には以下が含まれます：**

* パーティションタイプが同じであること（例えば、どちらもHash+Rangeパーティションである場合）。
* Hashパーティションの場合、参照する列数とパーティション数が同じである必要があります。
* Rangeパーティションの場合、参照する列数とパーティション数が同じであり、Range分割ポイントも同じである必要があります。

パーティションの詳細については、[パーティションの概要](../../../700.reference/300.database-object-management/100.manage-object-of-mysql-mode/300.manage-partitions-of-mysql-mode/100.partition-overview-of-mysql-mode.md)を参照してください。

#### 例2

1. 以下のSQLステートメントを使用して、`SHARDING` プロパティを `NONE` と指定するテーブルグループを作成し、名前を `test_tbl_tg2` とします。

    ```sql
    CREATE TABLEGROUP test_tbl_tg2 SHARDING = 'NONE';
    ```

2. 以下のSQLステートメントを使用して、パーティション化されていないテーブル `test_tbl2` を作成し、`TABLEGROUP` を `test_tbl_tg2` と指定します。

    ```sql
    CREATE TABLE test_tbl2 (col NUMBER) TABLEGROUP = test_tbl_tg2;
    ```

3. 以下のSQLステートメントを使用して、パーティションテーブル `test_tbl2_h` を作成し、`TABLEGROUP` を `test_tbl_tg2` と指定します。

    ```sql
    CREATE TABLE test_tbl2_h(col1 NUMBER,col2 VARCHAR(50)) TABLEGROUP = test_tbl_tg2
      PARTITION BY HASH(col1) PARTITIONS 10;
    ```

#### 例3

1. 以下のSQLステートメントを使用して、`SHARDING` プロパティを `PARTITION` と指定するテーブルグループを作成し、名前を `test_tbl_tg3` とします。

    ```sql
    CREATE TABLEGROUP test_tbl_tg3 SHARDING = 'PARTITION';
    ```

2. 以下のSQLステートメントを使用して、Hashパーティションのパーティションテーブル `test_tbl3_h` を作成し、`TABLEGROUP` を `test_tbl_tg3` と指定します。

    ```sql
    CREATE TABLE test_tbl3_h(col1 NUMBER) TABLEGROUP = test_tbl_tg3
      PARTITION BY HASH(col1) PARTITIONS 10;
    ```

3. 以下のSQLステートメントを使用して、パーティション化されていないテーブル `test_tbl3` を作成し、`TABLEGROUP` を `test_tbl_tg3` と指定するとエラーが表示されます。

    ```sql
    CREATE TABLE test_tbl3 (col NUMBER) TABLEGROUP = test_tbl_tg3;
    ```

    実行結果は次のとおりです：

    ```shell
    ORA-00600: internal error code, arguments: -4179, not all tables are non-partitioned or partitioned, add table to tablegroup not allowed
    ```

4. 以下のSQLステートメントを使用して、Hash + Rangeパーティションのコンポジット・パーティションテーブル `test_tbl3_hr` を作成し、`TABLEGROUP` を `test_tbl_tg3` と指定します。

    ```sql
    CREATE TABLE test_tbl3_hr(col1 NUMBER,col2 NUMBER) TABLEGROUP = test_tbl_tg3
    PARTITION BY HASH(col1)
        SUBPARTITION BY RANGE(col2)
        SUBPARTITION TEMPLATE
        (SUBPARTITION p0 VALUES LESS THAN(100),
        SUBPARTITION p1 VALUES LESS THAN(200),
        SUBPARTITION p2 VALUES LESS THAN(300)
        )
    PARTITIONS 10;
    ```
