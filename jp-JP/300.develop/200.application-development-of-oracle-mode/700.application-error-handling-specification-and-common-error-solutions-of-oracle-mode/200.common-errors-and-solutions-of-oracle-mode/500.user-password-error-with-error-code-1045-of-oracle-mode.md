# ユーザーのパスワードが誤っている場合、エラーコードERROR 1045が表示されます

本記事では、OceanBaseデータベースのOracleモードにおいて、ユーザーのパスワード入力が誤った場合に`ERROR 1045`エラーが表示される際の対処方法について説明します。

## 現象

ユーザーがデータベースにログインする際、パスワードを忘れてしまい、パスワードの入力が誤ってエラーが発生します。

```sql
[admin@k08j13249.eu95sqa /home/admin]
$obclient -h10.0.0.0 -P2881 -uny@Oracle -p -A
Enter password:
ERROR 1045 (42000): Access denied for user 'NY'@'xxx.xxx.xxx.xxx' (using password: YES)
```

## 解決策

以下の手順に従ってユーザーのパスワードを変更し、再度ログインしてください。

1. 管理者ユーザーとしてクラスタの該当するテナントにログインします。Oracleテナントのデフォルト管理者ユーザーは`SYS`ユーザーです。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>ユーザーのロック解除操作は通常管理者が行います。一般ユーザーがロック解除操作を実行する場合は、グローバルな <code>ALTER USER</code> 権限を持っている必要があります。</p>
   </main>

   ```sql
   [admin@k08j13249.eu95sqa /home/admin]
   $obclient -hxx.xx.xx.1 -P2881 -usys@Oracle -p -A
   Enter password:
   Welcome to the OceanBase.  Commands end with ; or \g.
   Your OceanBase connection id is 3221584177
   Server version: OceanBase 4.0.0.0 (r100000172022101218-6ab80a3950710941946c004d805fcfded7a4aa2c) (Built Oct 12 2022 18:43:39)

   Copyright (c) 2000, 2018, OceanBase Corporation Ab and others.

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.
   ```

2. `ny` ユーザーのパスワードを変更します。

   ```sql
    obclient [SYS]> ALTER USER ny IDENTIFIED BY ***3***;
   Query OK, 0 rows affected
   ```

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>ユーザーにパスワードを設定する際、そのパスワードは現在のテナントのパスワード複雑性要件を満たしている必要があります。パスワード複雑性に関する操作および説明については、<a href="../../../../600.manage/500.security-and-permissions/200.identification-and-authentication/200.identification-and-authentication-of-oracle-mode/200.password-complexity-of-oracle-mode.md">パスワード複雑性</a>を参照してください。</p>
   </main>

3. 再度 `ny` ユーザーを使用して、クラスタの `Oracle` テナントにログインします。

   ```sql
   [admin@k08j13249.eu95sqa /home/admin]
   $obclient -hxx.xx.xx.1 -P2881 -uny@Oracle -p****** -A
   Enter password:
   Welcome to the OceanBase.  Commands end with ; or \g.

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.
   ```
