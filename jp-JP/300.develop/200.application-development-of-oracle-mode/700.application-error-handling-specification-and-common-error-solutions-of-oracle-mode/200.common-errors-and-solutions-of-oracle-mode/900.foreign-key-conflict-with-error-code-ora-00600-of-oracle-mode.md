# 外部キーを追加する際にエラーが発生し、エラーコードORA-00600が表示される

本記事では、OceanBaseデータベースのOracleモードで外部キーを追加する際に`ORA-00600`エラーが発生した場合の対処方法について説明します。

## 現象

`cust`テーブルに外部キー制約を作成する際に、関連フィールドのエラーが表示されます。

```sql
obclient [SYS]> ALTER TABLE cust ADD CONSTRAINT C_FK FOREIGN KEY (c_w_id) REFERENCES ware(w_name);
ORA-00600: internal error code, arguments: -5317, Cannot add foreign key constraint
```

このエラーメッセージに対応するエラーコードは次のとおりです：

* エラーコード：ORA-00600

* OceanBaseエラーコード：5317

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/700.error-code-of-oracle-mode/100.use-error-information-of-oracle-mode.md)を参照してください。

## 考えられる原因

外部キー制約を追加する際に、外部キーのフィールドと関連フィールドの型がマッチしない場合、システムはエラーを報告します。

## 解決策

次の手順を参照して、現在のテーブルと関連テーブルの各フィールドタイプを確認し、関連テーブルの主キーを確認した後、外部キー制約を再作成してください。

1. 現在のテーブルと関連テーブル`ware`のテーブル構造を確認し、参照列が主キーまたは一意キーであるかどうかを確認します。外部キー参照列は、参照されるテーブルの一意キーまたは主キーでなければなりません。

   ```sql
   obclient> DESC CUST;
   +--------+------------+------+-----+---------+-------+
   | Field  | Type       | Null | Key | Default | Extra |
   +--------+------------+------+-----+---------+-------+
   | C_ID   | NUMBER(38) | NO   | PRI | NULL    |       |
   | C_W_ID | NUMBER(38) | YES  |     | NULL    |       |
   +--------+------------+------+-----+---------+-------+
   2 rows in set

   obclient [SYS]> DESC WARE;
   +--------+---------------+------+-----+---------+-------+
   | Field  | Type          | Null | Key | Default | Extra |
   +--------+---------------+------+-----+---------+-------+
   | W_ID   | NUMBER(38)    | NO   | PRI | NULL    |       |
   | W_NAME | VARCHAR2(256) | YES  | UNI | NULL    |       |
   | W_CITY | VARCHAR2(256) | YES  | UNI | NULL    |       |
   +--------+--------------+------+-----+---------+-------+
   3 rows in set
   ```

2. 主キーを選択してから、外部キー制約を再作成します。

   ```sql
   obclient [SYS]> ALTER TABLE CUST ADD CONSTRAINT C_FK FOREIGN KEY (c_w_id) REFERENCES WARE(w_id);
   Query OK, 0 rows affected
   ```
