# データの挿入時に重複した入力が表示され、エラーコードORA-00001が返される

本記事では、OceanBaseデータベースのOracleモードでデータを挿入する際に重複した入力が表示され、`ORA-00001` エラーが報告される場合の対処方法について説明します。

## 現象

主キーを持つテーブル `t_insert` にデータを挿入すると、主キー値が重複していることが示されます。

```sql
obclient [SYS]> INSERT INTO t_insert(id, name, value) VALUES (3,'US', 10003),(4, 'JP', 10004);
ORA-00001: unique constraint '3' for key 'PRIMARY' violated
```

このエラーメッセージに対応するエラーコードは次のとおりです：

* エラーコード：ORA-00001

* OceanBaseエラーコード：5024

* SQLSTATE：23000

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/700.error-code-of-oracle-mode/100.use-error-information-of-oracle-mode.md)を参照してください。

## 考えられる原因

テーブルにデータを挿入する際、テーブルに一意性制約がある場合、同じレコードを再度挿入すると、システムはエラーを報告します。

## 解決策

以下の2つの方法を参照して競合を解決してください。

1. `t_insert` テーブル内のデータを確認し、挿入するデータが主キー列のデータと重複していないか、既存の行データとどちらを保持するかを確認します。

   ```sql
   obclient [SYS]> SELECT * FROM t_insert;
   +----+------+-------+
   | ID | NAME | VALUE |
   +----+------+-------+
   |  1 | CN   | 10001 |
   |  2 | EN   | 10002 |
   |  3 | UK   | 10003 |
   |  4 | JP   | 10004 |
   +----+------+-------+
   4 rows in set
   ```

2. 既存の行を保持する必要がある場合は、以下のステートメントを実行して、対応する `id=3` のデータを更新します。

   ```sql
   obclient [SYS]> UPDATE t_insert SET name = 'US' WHERE id = 3;
   Query OK, 1 row affected
   ```

   <main id="notice" type='explain'>
      <h4>説明</h4>
      <ul>
      <li><code>MERGE INTO</code> ステートメントを使用して、一意キーの競合を回避することもできます。詳細な手順については、<a href="../../400.write-data-of-oracle-mode/400.replace-data-of-oracle-mode-in-develop.md">データの置換</a>を参照してください。</li>
      <li>既存の行を保持する必要がない場合は、条件に基づいて不要な行を削除できます。具体的な操作については、<a href="../../400.write-data-of-oracle-mode/300.delete-data-of-oracle-mode-in-develop.md">データの削除</a>を参照してください。</li>
      </ul>
   </main>

3. 操作が成功した後、再度 `t_insert` テーブル内のデータを確認します。

   ```sql
   obclient [SYS]>  SELECT * FROM t_insert;
   +----+------+-------+
   | ID | NAME | VALUE |
   +----+------+-------+
   |  1 | CN   | 10001 |
   |  2 | EN   | 10002 |
   |  3 | US   | 10003 |
   |  4 | JP   | 10004 |
   +----+------+-------+
   4 rows in set
   ```
