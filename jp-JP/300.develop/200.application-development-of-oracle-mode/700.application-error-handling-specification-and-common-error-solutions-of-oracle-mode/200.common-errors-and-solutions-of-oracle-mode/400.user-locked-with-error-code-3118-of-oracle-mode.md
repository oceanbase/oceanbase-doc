# ユーザーがロックされ、エラーコードERROR 3118が表示される

本記事では、OceanBaseデータベースのOracleモードでユーザーがロックされた後に`ERROR 3118`エラーが表示される場合の対処方法について説明します。

## 現象

`ny`ユーザーでクラスタの`Oracle`テナントにログインし、複数回不正なパスワードを入力した後、システムエラーが発生し、ユーザーがロックされたことを示すメッセージが表示されます。

```sql
[admin@k08j13249.eu95sqa /home/admin]
$obclient -hxx.xx.xx.xx -P2881 -uny@Oracle -p -A
Enter password:
ERROR 3118 (HY000): User locked
```

## 考えられる原因

OceanBaseデータベースは、ログイン失敗時の処理ポリシーを設定しています。複数回のログイン失敗があったユーザーに対して、OceanBaseデータベースはそのユーザーをロックします。これにより、悪意のあるパスワード攻撃を防ぎ、データベースを保護し、データベースのセキュリティを向上させます。ログイン失敗時の処理ポリシーに関する操作および説明については、[ログイン失敗時の処理](../../../../600.manage/500.security-and-permissions/200.identification-and-authentication/200.identification-and-authentication-of-oracle-mode/300.login-failure-handling-of-oracle-mode.md)を参照してください。

## 解決策

以下の手順に従ってユーザーをロック解除し、再ログインしてください。

1. 管理者ユーザーでクラスタの該当するテナントにログインします。Oracleテナントのデフォルト管理者ユーザーは`SYS`ユーザーです。

   <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>ユーザーのロック解除操作は通常管理者が行います。一般ユーザーがロック解除操作を実行するには、グローバルな<code>ALTER USER</code>権限が必要です。</p>
   </main>

   ```sql
   [admin@k08j13249.eu95sqa /home/admin]
   $obclient -hxx.xx.xx.1 -P2881 -usys@Oracle -p -A
   Enter password:
   Welcome to the OceanBase.  Commands end with ; or \g.
   Your OceanBase connection id is 3221584177
   Server version: OceanBase 4.0.0.0 (r100000172022101218-6ab80a3950710941946c004d805fcfded7a4aa2c) (Built Oct 12 2022 18:43:39)

   Copyright (c) 2000, 2018, OceanBase Corporation Ab and others.

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.
   ```

2. ユーザー`ny`のロックを解除します。

   ```sql
    obclient [SYS]> ALTER USER ny ACCOUNT UNLOCK ;
   Query OK, 0 rows affected
   ```

3. 再度`ny`ユーザーでクラスタの`Oracle`テナントにログインします。

   ```sql
   [admin@k08j13249.eu95sqa /home/admin]
   ```
