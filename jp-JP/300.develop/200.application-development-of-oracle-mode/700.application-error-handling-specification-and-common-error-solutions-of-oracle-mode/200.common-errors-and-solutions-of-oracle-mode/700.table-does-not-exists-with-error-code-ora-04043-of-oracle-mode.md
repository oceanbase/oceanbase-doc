# テーブルのクエリ時にテーブルが存在しない場合、エラーコードORA-04043

本記事では、OceanBaseデータベースのOracleモードでテーブルをクエリした際にテーブルが存在せず、`ORA-04043` エラーが発生した場合の対処方法について説明します。

## 現象

`student` テーブルをクエリすると、テーブルが存在しないと表示されます。

```sql
obclient [SYS]> desc student;
ORA-04043: object SYS.STUDENT does not exist
```

このエラーメッセージに対応するエラーコードは以下のとおりです：

* ORA-04043

* OceanBaseエラーコード：5400

* SQLSTATE：HY000

エラーコードの詳細な説明と紹介については、[エラーコードの概要](../../../../700.reference/900.error-code/700.error-code-of-oracle-mode/100.use-error-information-of-oracle-mode.md) を参照してください。

## 考えられる原因

テーブル操作を行う際、操作対象のテーブルが存在しない場合、システムはエラーを報告します。

## 解決策

以下の手順を参照して、テーブルが存在するかどうか確認し、必要に応じて対応するテーブルを作成してください。

1. 存在しない場合は、まずテーブル名が正しく入力されているか確認することを推奨します。間違いがないことを確認したら、`CREATE TABLE` を使用して必要なテーブルを作成できます。例：

   ```sql
   obclient [SYS]> CREATE TABLE student(
   id NUMBER,
   name varchar2(18),
   sex char(1),
   age NUMBER,
   address varchar2(200),
   email varchar2(100),
   c_date date,
   PRIMARY KEY (id)
   );
   ```

2. 作成が成功したら、作成されたテーブルの構造を確認します。

   ```sql
   obclient [SYS]> desc student;
   +---------+---------------+------+-----+----------+-------+
   | FIELD   | TYPE          | NULL | KEY | DEFAULT  | EXTRA |
   +---------+---------------+------+-----+----------+-------+
   | ID      | NUMBER(38)    | NO   | PRI | NULL     | NULL  |
   | NAME    | VARCHAR2(18)  | YES  | NULL | NULL    | NULL  |
   | SEX     | CHAR(1)       | YES  | NULL | NULL    | NULL  |
   | AGE     | NUMBER(38)    | YES  | NULL | NULL    | NULL  |
   | ADDRESS | VARCHAR2(200) | YES  | NULL | NULL    | NULL  |
   | EMAIL   | VARCHAR2(100) | YES  | NULL | NULL    | NULL  |
   | C_DATE  | DATE          | YES  | NULL | NULL    | NULL  |
   +---------+---------------+------+-----+---------+-------+
   7 rows in set
   ```
