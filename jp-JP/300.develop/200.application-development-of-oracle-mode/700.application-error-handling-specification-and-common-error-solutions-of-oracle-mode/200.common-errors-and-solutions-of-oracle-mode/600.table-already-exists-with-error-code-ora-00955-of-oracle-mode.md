# テーブル作成時にテーブルが既に存在している場合のエラーコードORA-00955

本記事では、OceanBaseデータベースのOracleモードでテーブルを作成しようとした際に、テーブルが既に存在しているため`ORA-00955`エラーが発生した場合の対処方法について説明します。

## 現象

`student`テーブルを作成する際、システムからテーブルが既に存在しているというエラーが表示されます。

```sql
obclient [SYS]> CREATE TABLE student(
          id NUMBER,
          name varchar(18),
          sex char(1),
          age NUMBER,
          address varchar(200),
           email varchar(100),
           c_date date,
           PRIMARY KEY (id)
           );
ORA-00955: name is already used by an existing object
```

このエラー情報に対応するエラーコードは以下の通りです：

* エラーコード：ORA-00955

* OceanBaseエラーコード：5331、5834

* SQLSTATE：HY000

エラーコードの詳細については、[エラーコードの概要](../../../../700.reference/900.error-code/700.error-code-of-oracle-mode/100.use-error-information-of-oracle-mode.md)を参照してください。

## 考えられる原因

テーブル作成時に、作成しようとしているテーブルが既に存在している場合、システムはエラーを返します。

## 解決策

以下の手順に従って、テーブルが実際に存在するかどうか確認し、既存のテーブルをリネームしてから再度テーブルを作成してください。

1. データベース内にそのテーブルが既に存在するかどうか確認します。例：

   ```sql
    obclient [SYS]> SELECT t.table_name tablename FROM user_tables t WHERE table_name = 'student';
   +------------+
   | TABLENAME  |
   +------------+
   | STUDENT    |
   +------------+
   1 row in set
   ```

2. そのテーブルが既に存在する場合、まず既存のテーブルが業務要件を満たしているかどうか確認してください。満たしていない場合は、新しいテーブル名を設計することを推奨します。例えば、`t_stu`テーブルを作成するように変更します。

   ```sql
    obclient [SYS]> CREATE TABLE t_stu(
          t_id NUMBER,
          t_name varchar(18),
          t_sex char(1),
          t_age NUMBER,
          t_address varchar(200),
          t_email varchar(100),
          t_c_date date,
          PRIMARY KEY (t_id)
           );
   Query OK, 0 rows affected
   ```

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>既存のテーブルが今後使用されないことが確認された場合は、<code>DROP TABLE</code>を使用してそのテーブルを削除し、再作成することもできます。</p>
  </main>
