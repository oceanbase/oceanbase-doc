# データ挿入時のデータ型が一致しない場合、エラーコードORA-00932

本記事では、OceanBaseデータベースのOracleモードでデータを挿入する際にデータが切り捨てられ、`ORA-00932` エラーが報告される場合の対処方法について説明します。

## 現象

テーブル `info` にデータを挿入する際、データが切り捨てられたというエラーが発生します。

```sql
obclient [SYS]> INSERT INTO info VALUES(1970);
ORA-00932: inconsistent datatypes
```

このエラーメッセージに対応するエラーコードは以下のとおりです：

* エラーコード：ORA-00932

* OceanBaseエラーコード：5083

* SQLSTATE：22000

エラーコードの詳細については、[エラーコードの概要](../../../../700.reference/900.error-code/700.error-code-of-oracle-mode/100.use-error-information-of-oracle-mode.md) を参照してください。

## 考えられる原因

テーブルにデータを挿入する際、挿入するデータのデータ型とテーブル内の列のデータ型が一致しない場合、システムはエラーを報告します。

## 解決策

次の手順に従って、現在のテーブルの各フィールドタイプと長さを確認した後、正しい値を再度挿入してください。

1. テーブル `info` の構造を確認します。

   ```sql
   obclient [SYS]> DESC info;
   +-------+------+------+-----+---------+-------+
   | FIELD | TYPE | NULL | KEY | DEFAULT | EXTRA |
   +-------+------+------+-----+---------+-------+
   | C1    | DATE | YES  | NULL | NULL    | NULL  |
   +-------+------+------+-----+---------+-------+
   1 row in set
   ```

2. フィールドタイプに基づいて正しい値を挿入します。

   ```sql
   obclient [SYS]> INSERT INTO info VALUES(date'1970-01-01');
   Query OK, 1 row affected
   ```

3. 挿入されたデータを確認します。

   ```sql
   obclient [SYS]> SELECT * FROM info;
   +-----------+
   | C1        |
   +-----------+
   | 01-JAN-70 |
   +-----------+
   1 row in set
   ```
