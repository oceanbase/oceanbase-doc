# OceanBaseのマルチモーダル融合による文化観光アシスタントの構築

本記事では、OceanBaseのマルチモーダル融合技術を活用して、専用のOceanBase文化観光アシスタントを構築します。

## 概念の紹介

:::collapse

* マルチモーダル統合：マルチモーダル統合は、OceanBaseの統合製品コンセプトの重要な方向性の一つです。本記事でのマルチモーダル統合は、主にマルチモーダルデータのハイブリッド検索技術を指します。OceanBaseはベクトルデータ、空間データ、ドキュメントデータ、スカラーデータなどのタイプの統合クエリをサポートし、ベクトルインデックス、空間インデックス、全文インデックスなど多様なインデックスのサポートに基づき、より高性能なハイブリッド検索機能を提供します。

  <!-- ![マルチモーダル統合の概念図](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/tutorial/AI/%E6%96%87%E6%97%85%E5%B0%8F%E5%8A%A9%E6%89%8B%E5%A4%9A%E6%A8%A1%E8%9E%8D%E5%90%88%E7%A4%BA%E6%84%8F%E5%9B%BE-1.jpg) -->

* LLM（Large Language Model）：大規模言語モデル。大量のテキストデータを用いて訓練された深層学習モデルであり、自然言語テキストを生成したり、言語テキストの意味を理解したりすることができます。大規模言語モデルは、テキスト分類、Q&A、対話など、多様な自然言語タスクを処理でき、人工知能への重要なアプローチです。

:::

## 前提条件

* OceanBase V4.3.3以降のバージョンのクラスタをデプロイし、MySQLモードのテナントを作成していること。OceanBaseクラスタのデプロイに関する詳細情報については、[デプロイの概要](../400.deploy/100.deploy-overview.md)を参照してください。

* 作成したMySQLモードのテナントに挿入およびクエリの権限が付与されていること。権限設定の詳細については、[直接権限付与](../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

* データベースを作成済みであること。データベースの作成に関する詳細情報については、[データベースの作成](../300.develop/100.application-development-of-mysql-mode/300.database-object-planning-of-mysql-mode/100.create-database-of-mysql-mode-in-develop.md)を参照してください。

* データベースでベクトル検索機能が有効になっていること。ベクトル検索機能の詳細については、[SQLを使用した迅速なベクトル検索](../640.ob-vector-search/120.ob-vector-search-quick-start/100.ob-vector-search-sql-quick-start.md)を参照してください。

    ```shell
    obclient> ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
    ```

* （推奨、必須ではない）[Python 3.10以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしてください。ご使用のマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.10以降の環境を作成できます。具体的な手順については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    ```shell
    conda create -n obmms python=3.10 && conda activate obmms
    ```

* [Poetry](https://python-poetry.org/docs/)をインストールしてください。参考コマンド：

    ```shell
    python3 -m ensurepip
    python3 -m pip install poetry
    ```

* 対応するPythonパッケージをインストールしてください。参考コマンド：

    ```shell
    pip install python-dotenv tqdm streamlit pyobvector==0.2.16
    ```

## ステップ3：公開データセットをダウンロードする

Kaggleの[中国都市観光スポット詳細](https://www.kaggle.com/datasets/audreyhengruizhang/china-city-attraction-details)データセットのZIP圧縮ファイルをダウンロードします。

## ステップ4：文化観光アシスタントを構築する

### プロジェクトリポジトリのクローン

1. 最新のプロジェクトリポジトリをクローンします。

    ```shell
    git clone https://github.com/oceanbase-devhub/ob-multi-model-search-demo.git
    cd ob-multi-model-search-demo
    ```

2. ダウンロードした `archive` データセットのZIPファイルを `ob-multi-model-search-demo` プロジェクトフォルダに移動し、`citydata` に名前を変更して解凍します。

    ```shell
    # archive.zipファイルの実際の保存パスに変更してください
    mv ./archive.zip ./citydata.zip
    unzip ./citydata.zip
    ```

### 依存関係のインストール

プロジェクトのルートディレクトリで、以下のコマンドを実行して依存関係をインストールします。

```shell
poetry install
```

### 環境変数の設定

`.env` ファイルに環境変数を設定します：

```shell
vim .env
```

`OB_` で始まる変数は、ご自身のデータベース接続情報に更新し、以下の変数を手動で追加する必要があります：`DASHSCOPE_API_KEY` をAlibaba Cloud Model Studioコンソールから取得したAPIキー値に更新し、`AMAP_API_KEY` を高徳地図APIサービスから取得したAPIキー値に更新して、ファイルを保存します。

```text
# データベース接続文字列のホストアドレス
OB_URL="******"
OB_USER="******"
OB_DB_NAME="******"
# データベース接続文字列のパスワード
OB_PWD="******"
# データベース接続文字列のSSL CAファイルパス（オプション）。SSLリンク暗号化を使用しない場合は、このパラメータを削除する必要があります。
OB_DB_SSL_CA_PATH="******"

# LLM APIキーを手動で追加
DASHSCOPE_API_KEY="******"
# 高徳地図APIキーを手動で追加
AMAP_API_KEY="******"
```

### データのインポート

このステップでは、ダウンロードしたデータセットのデータをOceanBaseにインポートします。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>初回構築時は、データセットの一部（例えば、最初の文字がAの観光スポットのみを選択してインポートすることをお勧めします。全量インポートは時間がかかります。</p>
</main>

```shell
python ./obmms/data/attraction_data_preprocessor.py
```

## トラブルシューティング

### 依存パッケージのインストール問題

#### Poetryのインストール失敗

`poetry install` コマンドが失敗した場合、以下の手順を試すことができます：

1. Poetryを最新バージョンに更新します：
   ```shell
   pip install --upgrade poetry
   ```

2. Poetryキャッシュをクリアします：
   ```shell
   poetry cache clear --all pypi
   ```

3. 依存関係を再インストールします：
   ```shell
   poetry install --no-cache
   ```

### 環境設定問題

#### Python環境が有効化されていない

<main id="notice" type='warning'>
  <h4>重要</h4>
  <p>依存関係のインストールを行う前に、正しいPython環境（例：obmms conda環境）が有効化されていることを確認してください。</p>
</main>

正しいconda環境が有効化されていることを確認してください：

```shell
conda activate obmms
```

#### Pythonバージョンの互換性

Python 3.10以降のバージョンを使用していることを確認してください：

```shell
python --version
```

バージョンが低すぎる場合は、環境を再作成してください：

```shell
conda create -n obmms python=3.10
conda activate obmms
```

### データベース接続問題

データベース接続に問題が発生した場合、以下を確認してください：

1. `.env` ファイル内のデータベース接続情報が正しいかどうか
2. OceanBaseクラスタが正常に稼働しているかどうか
3. ネットワーク接続が正常かどうか
4. データベースユーザーの権限が十分かどうか

### その他のよくある質問

#### ポートが占有されている

Streamlit起動時にポートが占有されているというメッセージが表示された場合、他のポートを指定できます：

```shell
poetry run streamlit run ./ui.py --server.port 8502
```

#### メモリ不足

データインポート中にメモリ不足の問題が発生した場合、以下の対処法があります：

1. バッチインポートのデータ量を減らす
2. システムメモリを増やす
3. OceanBaseのメモリ設定を調整する

#### APIキーの問題

以下の設定が正しく行われていることを確認してください：

1. 阿里云百炼APIキー（DASHSCOPE_API_KEY）
2. 高德地图APIキー（AMAP_API_KEY）

APIキーは `.env` ファイルで設定できます。
