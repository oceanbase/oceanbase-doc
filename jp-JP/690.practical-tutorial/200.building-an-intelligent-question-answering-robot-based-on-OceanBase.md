# OceanBase に基づくスマート QA チャットボットの構築

## 背景情報

さまざまな情報があふれる現代では、ユーザーは膨大なデータの中から必要な情報をすばやく検索する必要があります。例えば、オンライン文献データベース、e コマースプラットフォームのプロダクトカタログ、そして増え続けるマルチメディアコンテンツライブラリなど、ユーザーが興味のあるコンテンツをすばやく見つけるためには、効率的な検索システムが必要です。データ量が飛躍的に増加し続けるにつれ、従来のキーワードベースの検索手法では、検索精度と速度に対するユーザーのニーズを満たすことができなくなり、ベクトル検索の技術が登場しました。これは、テキスト、画像、音声などのさまざまなタイプのデータを数学的なベクトルにエンコードし、ベクトル空間で検索する技術です。この方法により、システムはデータの深い意味情報を捉えることで、より正確で効率的な検索結果を提供することができます。

本記事では、OceanBase のベクトル検索機能を用いて、ドキュメント AI アシスタントを構築します。

## ドキュメント AI アシスタントアーキテクチャ

ドキュメント AI アシスタントは、ドキュメントをベクトル形式で OceanBase データベースに一括保存します。ユーザーが UI インターフェースを通して質問すると、プログラムは BGE-M3 モデルを使用して質問内容をベクトルとして埋め込み、データベース内で類似ベクトルを検索します。類似ベクトルに対応するドキュメントのコンテンツを取得した後、アプリケーションはそれらをユーザーの質問と共に LLM に送信します。LLM は提供されたドキュメントに基づいて、より正確な回答を生成します。

## 前提条件

* OceanBase V4.3.3 以降のバージョンのクラスターをデプロイし、MySQL モードのテナントを作成していること。OceanBase クラスターのデプロイに関する詳細は、[デプロイの概要](../400.deploy/100.deploy-overview.md) を参照してください。

* 作成した MySQL モードのテナントに挿入とクエリを実行する権限が付与されていること。権限設定の詳細については、[直接権限の付与](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974754) を参照してください。

* データベースを作成済みであること。データベースの作成に関する詳細については、[データベースの作成](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971662) を参照してください。


* データベースのベクトル検索機能が有効になっていること。ベクトル検索機能の詳細については、[SQL を使用した高速なベクトル検索](../640.ob-vector-search/120.ob-vector-search-quick-start/100.ob-vector-search-sql-quick-start.md) を参照してください。

    ```shell
    obclient> ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
    ```

* Python 3.9 以降のバージョンをインストールします。

* Poetry のインストール：

    ```shell
    python3 -m ensurepip
    python3 -m pip install poetry
    ```

## 操作手順

1. Zhipu LLM プラットフォームのアカウント登録をします。

    [Zhipu LLM](https://open.bigmodel.cn/login?redirect=%2Fusercenter%2Fapikeys) に登録し、API キーを取得します。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <ul><li>Zhipu LLM は一定の無料クォータをご利用いただけます。ご利用の際は、無料クォータの使用状況にご注意ください。上限を超えると料金が発生します。</li>
      <li>本チュートリアルでは、Zhipu LLM を例に、QA チャットボットの構築方法を紹介します。他の LLM を使用して構築することもできます。他の LLM を使用する場合、.env ファイルの API_KEY、LLM_BASE_URL、LLM_MODEL を更新する必要があります。</li></ul>
    </main>

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/tutorial/zhipu-dashboard.png)
    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/tutorial/zhipu-api-key.png)

2. コードリポジトリをクローンします。

    ```shell
    git clone https://github.com/oceanbase-devhub/ai-workshop-2024.git
    cd ai-workshop-2024
    ```

3. 依存関係をインストールします。

    ```shell
    poetry install
    ```

4. 環境変数を設定します。

    ```shell
    cp .env.example .env
    # .env ファイルのデータベース情報を更新する
    vi .env
    ```

    .env ファイルの内容を更新します。

    ```shell
    API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxx ## ここでは上記 Zhipu LLM プラットフォームで取得した API キーを指す
    LLM_BASE_URL="https://open.bigmodel.cn/api/paas/v4/"  ## Zhipu 以外の LLM を選択する場合、このフィールドを更新する必要がある
    LLM_MODEL="glm-4-flash"  ## Zhipu 以外の LLM を選択する場合、このフィールドを更新する必要がある

    HF_ENDPOINT=https://hf-mirror.com
    BGE_MODEL_PATH=BAAI/bge-m3

    DB_HOST="127.0.0.1"     ## 対応するテナントの IP アドレスを設定する
    DB_PORT="2881"   ## 対応するテナントのポートを設定する
    DB_USER="root@mysql_tenant"  ## 対応するテナントとユーザー名を設定する
    DB_NAME="test"      ## 対応するデータベース名を設定する
    DB_PASSWORD=""      ## 対応するテナントとユーザーのパスワードを設定する
    ```

5. BGE-M3 モデルの準備を行います。

    ```shell
    poetry run python utils/prepare_bgem3.py
    ```

    以下の結果が返された場合、モデルが正しく読み込まれたことを示します。

    ```shell
    # ===================================
    # BGEM3FlagModel loaded successfully.
    # ===================================
    ```

6. ドキュメントのコーパスを準備します。

    <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>このプロセスでは、OceanBase のオープンソースドキュメントをベクトルに変換して OceanBase データベースに格納するため、時間がかかります。</p>
    </main>

   1. ドキュメントリポジトリをクローンします。

        ```shell
        cd doc_repos
        git clone --single-branch --branch V4.3.3 https://github.com/oceanbase/oceanbase-doc.git
        cd ..
        ```

   2. タイトルを標準的な Markdown 記法に変換します。

        ```shell
        poetry run python convert_headings.py \
          doc_repos/oceanbase-doc/zh-CN
        ```

   3. ドキュメントテキストをベクトルとして埋め込みます。

        ```shell
        poetry run python embed_docs.py --doc_base doc_repos/oceanbase-doc/zh-CN
        ```

7. UI チャットインターフェースを起動します。

    ```shell
    poetry run streamlit run --server.runOnSave false chat_ui.py
    ```

    結果は次のとおりです：

    ```shell
    Collecting usage statistics. To deactivate, set browser.gatherUsageStats to false.

        You can now view your Streamlit app in your browser.

        Local URL: http://localhost:8501
        Network URL: http://xxx.xxx.xxx.xxx:8501
        External URL: http://xxx.xxx.xxx.xxx:8501
    ```
