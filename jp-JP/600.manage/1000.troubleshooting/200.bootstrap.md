# BootStrap

## ディスク容量不足（エラーコード -4290）

OceanBaseデータベースV3.xおよびそれ以前のバージョンでは、ログディスクは独立してデプロイされ、そのディスクを専有する必要がありました。OceanBaseデータベースV4.0以降では、ログとその他のファイルを同一ディスクに配置できるため、ユーザーがログディスクのサイズを指定する必要があります。OceanBaseデータベースは、ユーザーの設定に基づき、OBServer起動時にデータディスクとCLOGディスクの容量を事前に割り当てます。

そのため、`log_disk_size`/`log_disk_percentage`という構成パラメータが導入されました。この2つのパラメータは組み合わせて使用する必要があります。

* `log_disk_size`：ログディスクのサイズを表します。これは、そのOBServerが使用可能なログディスクの総容量です。デフォルト値は0で、ローカルのログディスクの実際の容量に基づいて計算することを意味します（OceanBaseデータベースV3.xの動作と互換性があります）。

* `log_disk_percentage`：ログディスクの使用率を表します。ユーザーが`log_disk_size = 0`を設定した場合、ログディスクの容量は`log_disk_percentage`に基づいて割り当てられます。デフォルト値は0で、データと共用するディスクがあるかどうかに応じて自動的に計算されます。
2つのパラメータが同時に設定されている場合、`log_disk_size`の優先順位が高くなります。

`log_disk_size`と`log_disk_percentage`がどちらも0（デフォルト値）の場合、ディスク容量の計算方法は以下のとおりです：

* データとCLOGが同一ディスクの場合、データがディスクの60%、CLOGがディスクの30%を使用します。

* データとCLOGが異なるディスクの場合、データがディスクの90%、CLOGがディスクの90%を使用します。

Bootstrapプロセス中に以下のエラーが発生した場合、ディスク容量が不足していることを意味します：

```shell
grep 'ret=-4290' observer.log
```

**解決策：**

正しい`log_disk_percentage`または`log_disk_size`を指定してください。例えば、起動時に`-o log_disk_percentage=10`を指定します。
