# ログストリームの手動運用コマンドに関する問題

`ALTER SYSTEM CREATE LS` または `ALTER SYSTEM MODIFY LS` などのログストリーム手動運用コマンドを実行した後、システムがエラーメッセージを表示する場合があります。これらのエラーメッセージは、コマンドが正常に実行できなかった理由を示しています。本記事では、主にこれらのエラーメッセージの原因と対処方法について説明します。

## エラーメッセージ1：The tenant status is not NORMAL. CREATE LS is not allowed

### エラーの原因

テナントの状態が `NORMAL` ではないため、ログストリームの作成は許可されません。

### 解決策

ビュー `DBA_OB_TENANTS` をクエリしてテナントの状態を確認します。テナントが現在 `CREATING` 状態にある場合は、テナントの作成完了を待ってからログストリームを作成します。

## エラーメッセージ2：The tenant's switchover status is not normal, CREATE LS is not allowed

### エラーの原因

テナントの `SWITCHOVER_STATUS` 状態が `NORMAL` ではないため、ログストリームの作成は許可されません。

## エラーメッセージ3：Unknown tenant 'tenant_name'

### エラーの原因

存在しないテナントに対してログストリームの作成または変更を行うことは許可されません。

### 解決策

テナントが存在するかどうかを確認してください。

## エラーメッセージ4：Access denied

### エラーの原因

ユーザーテナント内で、自身の名前と一致しないテナント名を指定することは許可されません。

## エラーメッセージ5：Access denied; you need (at least one of) the SUPER or ALTER SYSTEM privilege(s) for this operation

### エラーの原因

`ALTER SYSTEM` 権限を持たないユーザーによるログストリームの作成または変更は許可されません。

### 解決策

GRANTステートメントを使用して、現在のユーザーに `ALTER SYSTEM` 権限を付与できます。ユーザー権限の詳細な操作については、[直接権限付与（MySQLモード）](../500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)および[直接権限付与（Oracleモード）](../500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/200.authority-of-oracle-mode.md)を参照してください。

## エラーメッセージ6：CREATE LS of META or SYS tenant is not supported

### エラーの原因

システムテナントまたはMetaテナントにログストリームを作成することは許可されません。

### 解決策

ユーザーテナントにログストリームを作成します。

## エラーメッセージ7：The tenant role is not primary, CREATE LS is not allowed

### エラーの原因

ログストリームはプライマリテナント上でのみ作成できます。

### 解決策

プライマリテナント上にログストリームを作成します。

## エラーメッセージ8：The specified unit_group is not active or does not exist, CREATE LS is not allowed

### エラーの原因

存在しない `UNIT_GROUP` にログストリームを作成することは許可されません。また、`UNIT_GROUP_ID` が0の `UNIT GROUP` にログストリームを作成することも許可されません。

### 解決策

ビュー `DBA_OB_UNITS` をクエリし、指定した `UNIT_GROUP` が正しいかどうかを確認します。

## エラーメッセージ9：Incorrect arguments to set invalid unit group

### エラーの原因

`UNIT_GROUP_ID` が1000未満の `UNIT GROUP` にログストリームを作成することは許可されません。

### 解決策

ビュー `DBA_OB_UNITS` をクエリし、指定した `UNIT_GROUP` が正しいかどうかを確認します。

## エラーメッセージ10：The specified primary_zone is not in the tenant's zone list, CREATE LS is not allowed

### エラーの原因

指定されたログストリームの `PRIMARY_ZONE` がテナントの `ZONE_LIST` に含まれていないため、ログストリームの作成は許可されません。ログストリームを作成する際には、指定された `PRIMARY_ZONE` がテナントの `ZONE_LIST` に含まれている必要があり、複数の `PRIMARY_ZONE` を指定することは許可されません。

### 解決策

ビュー `DBA_OB_TENANTS` をクエリし、テナントのローカリティを通じて、テナントがどのゾーンを持っているかを確認します。

## エラーメッセージ11：The specified LS does not exist, MODIFY LS is not allowed

### エラーの原因

ログストリームが存在しないため、ログストリームの変更は許可されません。

### 解決策

ビュー `CDB_OB_LS` または `DBA_OB_LS` を照会し、指定されたログストリームが正しいかどうか確認します。

## エラーメッセージ12：The specified LS's status is not normal, MODIFY LS is not allowed

### エラーの原因

ログストリームの状態が `NORMAL` 状態ではないため、ログストリームの変更は許可されません。

### 解決策

`CDB_OB_LS` ビューまたは `DBA_OB_LS` ビューを照会し、ログストリームの状態を確認します。ログストリームが `CREATING` 状態の場合は、ログストリームの作成完了を待ってから変更できますが、その他の状態では変更できません。

## エラーメッセージ13：The specified primary_zone is not in the tenant's zone list, MODIFY LS is not allowed

### エラーの原因

指定されたログストリームの `PRIMARY_ZONE` がテナントの `ZONE_LIST` に含まれていないため、ログストリームの変更は許可されません。ログストリームを変更する際には、指定された `PRIMARY_ZONE` がテナントの `ZONE_LIST` に含まれている必要があり、複数の `PRIMARY_ZONE` の指定は許可されません。

### 解決策

ビュー `DBA_OB_TENANTS` を照会し、テナントのローカリティを通じて、テナントがどのゾーンを持っているかを確認します。

## エラーメッセージ14：The specified unit_group is not active or does not exist, MODIFY LS is not allowed

### エラーの原因

`UNIT_GROUP` が存在しないか、状態が `ACTIVE` ではないため、ログストリームの変更は許可されません。

### 解決策

ビュー `DBA_OB_UNITS` を照会し、指定された `UNIT_GROUP` が正しいかどうか確認します。

## エラーメッセージ15：The specified LS has balance tasks, MODIFY LS is not allowed

### エラーの原因

プライマリテナントがログストリームの `UNIT_GROUP` を変更する際には、テナントが負荷分散タスクを実行していないことが要求されます。

### 解決策

ビュー `CDB_OB_BALANCE_TASKS` または `DBA_OB_BALANCE_TASKS` を照会し、現在のログストリームで進行中の負荷分散タスクがあるかどうかを確認します。ある場合は、負荷分散タスクが完了するまで待ってからログストリームを変更します。

## エラーメッセージ16：The tenant status is not NORMAL. CREATE LS is not allowed

### エラーの原因

テナントの状態が `NORMAL` 状態ではないため、ログストリームの変更は許可されません。

### 解決策

ビュー `DBA_OB_TENANTS` を照会し、テナントの状態を確認します。テナントが現在 `CREATING` 状態の場合は、テナントの作成完了を待ってからログストリームを変更できます。
