# アイドルトランザクション

以下のトランザクションの例：

```shell
create table test (id1 int);
set @@ob_query_timeout=200 * 1000 * 1000;
set @@ob_trx_timeout = 200 * 1000 * 1000;

begin;
insert into test values(1);
//150秒の間隔を空ける
insert into test values(2); //このSQLは、失われた接続というエラーが表示されます
select * from test;  //このクエリ結果は空で、上記トランザクションがロールバックされたことを示しています。
rollback;
```

上記の実行シーケンスでは、2番目のINSERT文が実行される際にクライアント側に「Lost connection」というエラーが表示されます。その理由は、トランザクション内の2つのSQL文の間に一定のしきい値を超える時間が経過すると、OceanBaseデータベースが強制的にセッションをキルし、クライアントとの接続を切断するとともにトランザクションをロールバックするためです。

この仕組みは、長時間のトランザクションやホストしているトランザクションの問題を解決するために導入されています。アイドルしきい値はテナントのシステム変数 `ob_trx_idle_timeout` で制御され、デフォルト値は86400000000マイクロ秒（つまり24時間）です。
