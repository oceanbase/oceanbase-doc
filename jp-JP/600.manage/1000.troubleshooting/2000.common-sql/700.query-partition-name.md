# パーティション名のクエリ

テーブルの `table_id` が既知の場合、ビュー `CDB_OB_TABLE_LOCATIONS` (システムテナント) または `DBA_OB_TABLE_LOCATIONS` (ユーザーテナント) を使用して、テーブル内のすべてのパーティションのパーティション名を照会できます。

* システムテナント

  システムテナントでは、次のステートメントを使用してクエリを実行できます。

  ```shell
  obclient> SELECT * FROM oceanbase.CDB_OB_TABLE_LOCATIONS WHERE TENANT_ID=tenant_id AND TABLE_ID=table_id;
  ```

* ユーザーテナント

  MySQLモードのユーザーテナントでは、次のステートメントを使用してクエリを実行できます。

  ```shell
  obclient> SELECT * FROM oceanbase.DBA_OB_TABLE_LOCATIONS WHERE TABLE_ID=table_id;
  ```

  Oracleモードのユーザーテナントでは、次のステートメントを使用してクエリを実行できます。

  ```shell
  obclient> SELECT * FROM SYS.DBA_OB_TABLE_LOCATIONS WHERE TABLE_ID=table_id;
  ```
