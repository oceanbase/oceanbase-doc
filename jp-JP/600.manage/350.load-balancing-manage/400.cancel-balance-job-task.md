# Load Balancingジョブのキャンセル

各テナントは同一時刻において、1つのLoad Balancingジョブ(Balance Job)しか実行できません。現在進行中のLoad Balancingジョブがビジネスニーズに合致しない場合、そのタスクをキャンセルできます。また、Transfer Partitionを開始したものの、現在有効なLoad Balancingジョブの実行によりTransfer Partitionタスクのスケジューリングが遅延している場合は、現在のLoad Balancingジョブをキャンセルすることができます。

## 使用制限

Load Balancingジョブのキャンセル操作は、プライマリデータベース(プライマリテナント)でのみ実行できます。

## 背景

各テナントは同一時刻において、1つのLoad Balancingジョブ(JOB)しか実行できません。これらのLoad Balancingジョブには、スケールアウト、スケールイン、移行バランシング、パーティションバランシングなどが含まれます。各Load Balancingジョブは、Load Balancingの具体的な操作を実現するための複数のLoad Balancingタスク(Task)を生成します。Load Balancingジョブをキャンセルすると、そのLoad Balancingジョブの下で実行中のすべてのTaskがキャンセルされます。

## システムテナントによる進行中のLoad Balancingジョブのキャンセル

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

   接続例は以下の通りです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. ビュー`CDB_OB_BALANCE_JOBS`をクエリし、現在実行中のタスクを取得します。

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, BALANCE_STRATEGY, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   クエリ結果の例は以下の通りです：

   ```shell
   +-----------+--------+----------------------+------------+--------+
   | TENANT_ID | JOB_ID | BALANCE_STRATEGY     | JOB_TYPE   | STATUS |
   +-----------+--------+----------------------+------------+--------+
   |      1002 | 520683 | LS balance by shrink | LS_BALANCE | DOING  |
   +-----------+--------+----------------------+------------+--------+
   1 row in set
   ```

3. クエリ結果に基づき、該当タスクが想定に合致しない場合は、以下の操作を実行してLoad Balancingジョブをキャンセルできます。

   ```sql
   ALTER SYSTEM CANCEL BALANCE JOB TENANT = 'tenant_name';
   ```

   例：

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM CANCEL BALANCE JOB TENANT ='mysql_tenant';
   ```

## ユーザーテナントによる進行中のLoad Balancingジョブのキャンセル

1. MySQLテナントまたはOracleテナントのテナント管理者がデータベースに接続します。

   接続例は以下の通りです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. ビュー`DBA_OB_BALANCE_JOBS`をクエリして、現在実行中のタスクを取得します。

   :::tab
   tab MySQLモード

   MySQLモードでのクエリステートメントは以下のとおりです：

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

   tab Oracleモード

   Oracleモードでのクエリステートメントは以下のとおりです：

   ```shell
   obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOBS;
   ```

   :::

3. クエリ結果に基づき、予想と異なる場合は、以下の操作を実行してそのBalance Jobをキャンセルできます。

   ```shell
   obclient> ALTER SYSTEM CANCEL BALANCE JOB;
   ```
