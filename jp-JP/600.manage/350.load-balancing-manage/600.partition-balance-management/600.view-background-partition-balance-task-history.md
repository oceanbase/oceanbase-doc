# バックグラウンドのパーティション均衡タスク履歴の表示

パーティション均衡タスクの実行が完了した後、ビューを使用してその実行履歴を確認できます。

## システムテナントによるバックグラウンドのパーティション均衡タスクの確認

1. `root`ユーザーでクラスタのsysテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 以下のステートメントを実行し、指定したテナントのバックグラウンドにおけるパーティション均衡タスクの履歴を確認します。

   * 指定したテナントのパーティション均衡タスク履歴の確認

     ビュー`CDB_OB_BALANCE_JOB_HISTORY`は、拡張、縮小、移行均衡、パーティション均衡など、すべてのテナントのマクロレベルの均衡タスクを表示します。

     ```shell
     obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_JOB_HISTORY WHERE TENANT_ID = 1002 AND JOB_TYPE = 'PARTITION_BALANCE';
     ```

     クエリ結果は次のとおりです：

     ```shell
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     | TENANT_ID | JOB_ID | CREATE_TIME                | FINISH_TIME                | BALANCE_STRATEGY                | JOB_TYPE          | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS    | COMMENT | MAX_END_TIME | ZONE_UNIT_NUM_LIST | PARAMETER_LIST                                                                               |
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     |      1002 | 312280 | 2024-06-14 11:00:49.034035 | 2024-06-14 11:01:04.528871 | partition attribution alignment | PARTITION_BALANCE |            NULL |                       1 | COMPLETED | NULL    | NULL         | zone1:1            | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     1 row in set
     ```

     ビュー`CDB_OB_BALANCE_JOB_HISTORY`の各フィールドの詳細については、[CDB_OB_BALANCE_JOB_HISTORY](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7700.o-cdb_ob_balance_job_history-of-sys-tenant.md)を参照してください。

   * 指定したテナントのLSレベルのパーティション均衡タスク履歴の確認

     ビュー`CDB_OB_BALANCE_TASK_HISTORY`は、LS分割(LS_SPLIT)、LSメジャーコンパクション(LS_MERGE)、LS転送(LS_TRANSFER)、LS属性変更(LS_ALTER)など、すべてのテナントのログストリームレベルのタスクを表示します。

     ```shell
     obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_TASK_HISTORY WHERE TENANT_ID = 1002 AND BALANCE_STRATEGY LIKE '%partition%';
     ```

   * 指定したテナントのTabletレベルのパーティション均衡タスク履歴の確認

## ユーザーテナントによるバックグラウンドのパーティション均等化タスクの確認

1. ユーザーテナントのテナント管理者が、クラスタのMySQLテナントまたはOracleテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のステートメントを実行し、自身のテナントのバックグラウンドにおけるパーティション均等化タスクの履歴を確認します。

     ビュー `DBA_OB_BALANCE_JOB_HISTORY` は、現在のテナントにおけるマクロレベルの均等化タスク（拡張、縮小、移行均等化、パーティション均等化などのタスク）を表示します。

