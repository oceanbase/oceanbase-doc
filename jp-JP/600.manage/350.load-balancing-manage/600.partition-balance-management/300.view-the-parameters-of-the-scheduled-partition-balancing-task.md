# スケジュールされたパーティションのバランス調整タスクの設定を確認する

システムには、スケジュールされたパーティションのバランス調整タスク `SCHEDULED_TRIGGER_PARTITION_BALANCE` が組み込まれています。ユーザーテナントは必要に応じて、このタスクの各パラメータ設定を確認できます。

## 手順

1. クラスタのMySQLテナントまたはOracleテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のステートメントを実行して、現在のテナントのスケジュールされたパーティションのバランス調整タスクの関連設定を確認します。

   ビュー `DBA_SCHEDULER_JOBS` は、現在のテナントのすべてのスケジュールタスク情報を表示します。

   :::tab
   tab MySQLモード

   ステートメントは以下のとおりです：

   ```shell
   obclient [oceanbase]> SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE,MAX_RUN_DURATION, COMMENTS FROM oceanbase.DBA_SCHEDULER_JOBS WHERE job_name = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

   tab Oracleモード

   ステートメントは以下のとおりです：

   ```shell
   obclient [SYS]> SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE,MAX_RUN_DURATION, COMMENTS FROM SYS.DBA_SCHEDULER_JOBS WHERE job_name = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

   :::

   クエリ結果の例は以下のとおりです：

   ```shell
   *************************** 1. row ***************************
            JOB_NAME: SCHEDULED_TRIGGER_PARTITION_BALANCE
          JOB_ACTION: DBMS_BALANCE.TRIGGER_PARTITION_BALANCE()
          START_DATE: 2024-06-14 00:00:00.000000
     REPEAT_INTERVAL: FREQ=DAILY; INTERVAL=1
             ENABLED: 1
       NEXT_RUN_DATE: 2024-06-15 00:00:00.000000
    MAX_RUN_DURATION: 7200
            COMMENTS: used to auto trigger partition balance
   1 row in set
   ```

   クエリ結果には以下の項目が含まれます：

   * `JOB_NAME`：スケジュールタスク名。この例では、`SCHEDULED_TRIGGER_PARTITION_BALANCE` がスケジュールされたパーティションのバランス調整タスク名です。
   * `JOB_ACTION`：スケジュールされたパーティションのバランス調整タスクが実行する内容を示します。
   * `START_DATE`：スケジュールされたパーティションのバランス調整タスクのトリガー時間を示します。デフォルトは毎日00:00です。
   * `REPEAT_INTERVAL`：スケジュールされたパーティションのバランス調整タスクのトリガー間隔と頻度を示します。デフォルトは1日1回です。
   * `ENABLED`：スケジュールされたパーティションのバランス調整タスクが有効かどうかを示します。`1` は有効、`0` は無効を意味します。デフォルトは `1` です。
   * `NEXT_RUN_DATE`：定期パーティションの均衡タスクが次に実行される時刻を表します。
   * `MAX_RUN_DURATION`：`JOB_ACTION` の実行タイムアウト時間を表します。デフォルトは7200秒です。

   ビュー `DBA_SCHEDULER_JOBS` の各フィールドの詳細については、[DBA_SCHEDULER_JOBS](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/14100.o-dba_scheduler_jobs-of-mysql-mode.md)を参照してください。
