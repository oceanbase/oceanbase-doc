# ログ復元の終点を設定する

デフォルトでは、スタンバイテナントは継続的同期モードにあります。現在のスタンバイテナントが継続的同期モードにない場合は、このドキュメントを参照してスタンバイテナントを継続的同期モードに設定してください。

## 手順

1. 管理者ユーザーでスタンバイテナント、またはそのスタンバイテナントが存在するクラスタの`sys`テナントにログインします。

2. `RECOVER`コマンドを実行し、スタンバイテナントのログ復元終点を設定します。

   ```sql
   ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] UNTIL UNLIMITED;
   ```

   ここで、`sys`テナントでコマンドを実行する場合のみ、ステートメントに`TENANT = tenant_name`パラメータを追加してスタンバイテナント名を指定する必要があります。`UNLIMITED`は無限大を表します。

   `sys`テナントでスタンバイテナントのログ復元終点を設定する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY TENANT = standby_tenant UNTIL UNLIMITED;
   ```

   スタンバイテナントが自身のログ復元終点を設定する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY UNTIL UNLIMITED;
   ```

   このステートメントを実行すると、スタンバイテナントは継続的同期モードに入ります。

## 詳細を見る

OceanBaseデータベースでは、`RECOVER`コマンドを使用して、スタンバイテナントの復元終点を任意の妥当な時点に設定することもサポートされています。構文は以下のとおりです：

* 指定したタイムスタンプまで復元

  ```sql
  ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] UNTIL TIME='timestamp';
  ```

* 指定したSCNまで復元

  ```sql
  ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] UNTIL SCN =scn;
  ```

一部のパラメータの説明は以下のとおりです：

* `sys`テナントでコマンドを実行する場合のみ、ステートメントに`TENANT = tenant_name`パラメータを追加してスタンバイテナント名を指定する必要があります。

* `timestamp`は指定されたタイムスタンプで、単位はナノ秒です。

* `scn` は指定されたSCNであり、論理的なシステム内部のタイムスタンプです。

上記のステートメントを実行すると、スタンバイテナントはそのポイントに復元され、そのポイント自体も含まれます。
