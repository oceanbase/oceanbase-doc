# ログ同期の一時停止または再開

スタンバイテナントでは、ログ同期中にログ同期を一時停止し、その後再開することができます。

## ログ同期の一時停止

1. 管理者ユーザーでスタンバイテナント、またはスタンバイテナントが属するクラスタの`sys`テナントにログインします。

2. 以下のコマンドを実行して、ログ同期を一時停止します。

   ```sql
   ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] CANCEL ;
   ```

   ただし、`sys`テナントからコマンドを実行する場合のみ、文に`TENANT = tenant_name`パラメータを追加してスタンバイテナント名を指定する必要があります。

   システムテナントでスタンバイテナントのログ同期を一時停止する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY TENANT = standby_tenant CANCEL ;
   ```

   スタンバイテナントでログ同期を一時停止する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY CANCEL;
   ```

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>ログ同期を一時停止すると、スタンバイテナントはプライマリテナントから一切のログを同期しなくなります。ログ同期の一時停止によるスタンバイテナントのログストリームの途絶えを避けるようにしてください。</p>
   </main>

3. 同期を一時停止した後、`DBA_OB_TENANTS`および`GV$OB_LOG_STAT`ビューをそれぞれ照会すると、この時点でログストリームの同期進捗がコマンド実行時点で停止していることがわかります。

   `DBA_OB_TENANTS`および`GV$OB_LOG_STAT`ビューを使用してログストリームの同期進捗を詳細に確認する手順については、[ログ同期の進捗状況を確認する](../300.log-transport-service/400.view-the-log-synchronization-progress.md)を参照してください。

## ログ同期の再開

ログ同期を一時停止した後、スタンバイテナントの復旧ポイントを変更することで、再度ログ同期を再開できます。

1. 管理者ユーザーでスタンバイテナント、またはスタンバイテナントが属するクラスタの`sys`テナントにログインします。

2. 以下のコマンドを実行して、ログ同期を再開します。

   ```sql
   ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] UNTIL UNLIMITED;
   ```

   ただし、`sys`テナントからコマンドを実行する場合のみ、文に`TENANT = tenant_name`パラメータを追加してスタンバイテナント名を指定する必要があります。`UNLIMITED`は無限大を意味します。

   `sys`テナントでスタンバイテナントのログ同期を再開する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY TENANT = standby_tenant UNTIL UNLIMITED;
   ```

   スタンバイテナントでログ同期を再開する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY UNTIL UNLIMITED;
   ```
