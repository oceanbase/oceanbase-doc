# ログ同期の一時停止または再開

スタンバイテナントはログ同期中に、ログ同期を一時停止し、一時停止後に再開することができます。

## ログ同期の一時停止

1. 管理者ユーザーとしてスタンバイテナント、またはそのテナントが属するクラスタの`sys`テナントにログインします。

2. 以下のコマンドを実行して、ログ同期を一時停止します。

   ```sql
   ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] CANCEL ;
   ```

   なお、`sys`テナントからコマンドを実行する場合のみ、ステートメントに`TENANT = tenant_name`パラメータを追加してスタンバイテナント名を指定する必要があります。

   システムテナントからスタンバイテナントのログ同期を一時停止する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY TENANT = standby_tenant CANCEL ;
   ```

   スタンバイテナント自身でログ同期を一時停止する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY CANCEL;
   ```

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>ログ同期を一時停止すると、スタンバイテナントはプライマリテナントから一切のログを同期しなくなります。ログ同期の一時停止によるスタンバイテナントのログストリームの途絶えをできるだけ避けてください。</p>
   </main>

3. 同期を一時停止した後、`DBA_OB_TENANTS`ビューと`GV$OB_LOG_STAT`ビューをそれぞれクエリすると、ログストリームの同期進捗がコマンド実行時点で停止していることが確認できます。

   `DBA_OB_TENANTS`ビューと`GV$OB_LOG_STAT`ビューを使用してログストリームの同期進捗を確認する詳細な操作については、[ログ同期の進捗状況を確認する](../300.log-transport-service/400.view-the-log-synchronization-progress.md)を参照してください。

## ログ同期の再開

ログ同期を一時停止した後、スタンバイテナントの復元ポイントを変更することで、再度ログ同期を開始できます。

1. 管理者ユーザーとしてスタンバイテナント、またはそのテナントが属するクラスタの`sys`テナントにログインします。

2. 以下のコマンドを実行して、ログ同期を再開します。

   ```sql
   ALTER SYSTEM RECOVER STANDBY [TENANT = tenant_name] UNTIL UNLIMITED;
   ```

   なお、`sys`テナントからコマンドを実行する場合のみ、ステートメントに`TENANT = tenant_name`パラメータを追加してスタンバイテナント名を指定する必要があります。`UNLIMITED`は無限大を表します。

   `sys`テナントからスタンバイテナントのログ同期を再開する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY TENANT = standby_tenant UNTIL UNLIMITED;
   ```

   スタンバイテナント自身でログ同期を再開する例：

   ```sql
   ALTER SYSTEM RECOVER STANDBY UNTIL UNLIMITED;
   ```
