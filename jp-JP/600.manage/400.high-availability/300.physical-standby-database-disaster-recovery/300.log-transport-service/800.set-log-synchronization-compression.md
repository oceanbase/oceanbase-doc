# ログ同期圧縮の設定

スタンバイテナントのログ同期プロセスにおいて、ログ同期圧縮を有効にすることで、ログ転送時に使用される帯域幅を削減できます。

## 手順

1. 管理者ユーザーでスタンバイテナントまたはそのクラスタの`sys`テナントにログインします。

2. 以下のコマンドを実行して、ログ同期圧縮を有効にします。

   テナントレベルの構成パラメータ`log_transport_compress_all`は、ログ転送で圧縮を有効にするかどうかを設定します。デフォルト値は`False`であり、ログ転送で圧縮が有効になっていないことを意味します。構成パラメータ`log_transport_compress_all`の詳細については、[log_transport_compress_all](../../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/5300.log_transport_compress_all.md)を参照してください。

   SQL文は次のとおりです：

   ```sql
   ALTER SYSTEM SET log_transport_compress_all = value [TENANT [=] tenant_name];
   ```

   ステートメントの使用方法：

   * `SET`：MySQLモードでは、このキーワードはオプションです。
   * `value`：変更後の構成パラメータの値を指定します。
   * `TENANT [=] tenant_name`：システムテナントのみが、テナントを指定することでテナントレベルの構成パラメータを設定できます。

   システムテナントでスタンバイテナントにログ同期圧縮を有効にする例：

   ```sql
   ALTER SYSTEM SET log_transport_compress_all = True TENANT = standby_tenant;
   ```

   スタンバイテナントでログ同期圧縮を有効にする例：

   :::tab
   tab MySQLモード

   MySQLテナントでログ同期圧縮を有効にします：

   ```sql
   ALTER SYSTEM SET log_transport_compress_all = True;
   ```

   tab Oracleモード

   Oracleテナントでログ同期圧縮を有効にします：

   ```sql
   ALTER SYSTEM SET log_transport_compress_all = 'True';
   ```

   :::

   ログ同期圧縮を有効にすると、システムはデフォルトで圧縮アルゴリズムlz4_1.0を使用してログを圧縮します。

3. (オプション)圧縮アルゴリズムを変更する必要がある場合は、構成パラメータ`log_transport_compress_func`の値を変更します。

   テナントレベルの構成パラメータ`log_transport_compress_func`は、ログ転送で使用する圧縮アルゴリズムを設定します。現在サポートされている圧縮アルゴリズムはlz4_1.0、zstd_1.0、zstd_1.3.8で、デフォルトはlz4_1.0です。構成パラメータ`log_transport_compress_func`の詳細については、[log_transport_compress_func](../../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/5400.log_transport_compress_func.md)を参照してください。

   SQL文は次のとおりです：

   ```sql
   ALTER SYSTEM SET log_transport_compress_func = 'value' [TENANT [=] tenant_name];
   ```

   ステートメントの使用方法：

   * `SET`：MySQLモードでは、このキーワードはオプションです。
   * `value`：変更後の構成パラメータの値を指定します。
   * `TENANT [=] tenant_name`：システムテナントのみが、テナントを指定することでテナントレベルの構成パラメータを設定できます。

   システムテナントで指定したスタンバイテナントの圧縮アルゴリズムを変更する例：

   ```sql
   ALTER SYSTEM SET log_transport_compress_func = 'zstd_1.0' TENANT = standby_tenant;
   ```

   スタンバイテナントで自身の圧縮アルゴリズムを変更する例：

   ```sql
   ALTER SYSTEM SET log_transport_compress_func = 'zstd_1.0';
   ```
