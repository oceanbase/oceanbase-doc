# リサイクルビンのオブジェクトの確認

`SHOW RECYCLEBIN` ステートメントを使用して、リサイクルビンのオブジェクトを確認できます。

## 注意事項

現在、テナントを削除できるのは `sys` テナントのみです。そのため、MySQLモードおよびOracleモードのテナントが削除された場合、それらのテナントは `sys` テナントのリサイクルビンに移動します。テナントの削除には強制的な方法と非強制的な方法の2種類があります。詳細については、[DROP TENANT](../../../700.reference/500.sql-reference/100.sql-syntax/100.system-tenants/1100.drop-tenant.md)を参照してください。`sys` テナントでは、自身のデータベース、テーブル、インデックスのリサイクルビンのオブジェクトを確認できるだけでなく、システム内のすべてのテナントのリサイクルビンのオブジェクトも確認できます。MySQLユーザーテナントでは、データベース、テーブル、インデックスのリサイクルビンのオブジェクトのみを確認できます。Oracleユーザーテナントでは、テーブルとインデックスのリサイクルビンのオブジェクトのみを確認できます。

## 背景情報

データベースオブジェクトまたはテナントに対してDROP操作を実行する際：

* リサイクルビンが有効な場合、そのオブジェクトはリサイクルビンに移動し、リサイクルビンでそのオブジェクトを検索できます。

* リサイクルビンが無効な場合、そのオブジェクトはリサイクルビンに移動せず、リサイクルビンでそのオブジェクトを検索することもできません。

## 操作手順

1. `sys`テナントまたはユーザーテナントのテナント管理者としてデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <ul>
   <li>MySQLテナントの管理者ユーザーは<code>root</code>ユーザー、Oracleテナントの管理者ユーザーは<code>SYS</code>ユーザーです。</li>
   <li>テナントのリサイクルビンのオブジェクトを確認する場合は、<code>sys</code>テナントでデータベースにログインする必要があります。</li>
   </ul>
   </main>

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

   データベース接続の詳細な操作手順については、[データベース接続の概要（MySQLモード）](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/100.connection-methods-overview-of-mysql-mode.md)および[データベース接続の概要（Oracleモード）](../../../300.develop/200.application-development-of-oracle-mode/100.connect-to-oceanbase-database-of-oracle-mode/100.connection-methods-overview-of-oracle-mode.md)を参照してください。

2. 以下のステートメントを実行して、リサイクルビンのオブジェクトを確認します。

   ```shell
   obclient [(none)]> SHOW RECYCLEBIN;
   +-------------------------------------+-------------------+--------+----------------------------+
   | OBJECT_NAME                         | ORIGINAL_NAME     | TYPE   | CREATETIME                 |
   +-------------------------------------+-------------------+--------+----------------------------+
   | RECYCLE_$_100017_1672050541224936   | oracle001         | TENANT | 2023-01-16 11:01:40.258000 |
   | __recycle_$_100017_1673426335319344 | __idx_500788_idx1 | INDEX  | 2023-01-11 16:38:55.318878 |
   | __recycle_$_100017_1673426335329040 | __idx_500788_idx2 | INDEX  | 2023-01-11 16:38:55.328312 |
   | __recycle_$_100017_1673426335331800 | t1                | TABLE  | 2023-01-11 16:38:55.331481 |
   +-------------------------------------+-------------------+--------+----------------------------+
   4 rows in set
   ```

   実行結果に含まれる関連フィールドの説明は以下のとおりです：

   * `OBJECT_NAME`：リサイクルビン内のオブジェクト名を表します。

   * `ORIGINAL_NAME`：元のオブジェクト名を表します。

   * `TYPE`：リサイクルビンのオブジェクトが属するタイプを表します。具体的には：

      * システムテナント(`sys`テナント)は`INDEX`、`TABLE`、`DATABASE`、`TENANT`の4種類をサポートします。この例では、`oracle001`はテナントタイプのリサイクルビンオブジェクトです。

      * MySQLユーザーテナントは`INDEX`、`TABLE`、`DATABASE`の3種類をサポートします。

      * Oracleユーザーテナントは`INDEX`と`TABLE`の2種類をサポートします。

   * `CREATETIME`：オブジェクトがリサイクルビンに移動した時間を表します。
