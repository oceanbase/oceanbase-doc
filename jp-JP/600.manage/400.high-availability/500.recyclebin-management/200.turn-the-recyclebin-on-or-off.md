# リサイクルビンの有効化または無効化

OceanBaseデータベースでは、システム変数 `recyclebin` を使用してリサイクルビンの有効化と無効化を制御します。デフォルトではリサイクルビンは無効な状態です。リサイクルビン機能を有効にすると、データベースオブジェクトやテナントに対してDrop操作を実行すると、そのオブジェクトやテナントはリサイクルビンに移動します。

## 背景情報

OceanBaseデータベースのシステム変数は、グローバル変数とセッション変数に分類されます。リサイクルビンを有効または無効にする際には、必要に応じて適切な設定方法を選択できます。

* グローバル変数：グローバルレベルでの変更を示します。データベース内の同一テナント内の異なるユーザー間でグローバル変数は共有されます。グローバル変数の変更は、セッションの終了によって無効になることはありません。ただし、グローバル変数を変更しても、その変更は現在開いているセッションには反映されません。変更を有効にするには、新しいセッションを確立する必要があります。

* セッション変数：セッションレベルでの変更を示します。クライアントがデータベースに接続すると、データベースはグローバル変数をコピーして自動的にセッション変数を生成します。セッション変数の変更は、現在のセッション内でのみ有効です。

OceanBaseデータベースでは、`sys` テナントとユーザーテナントが管理できるリサイクルビンオブジェクトは以下のとおりです。

* `sys` テナントでリサイクルビンが有効になっている場合、管理できるリサイクルビンオブジェクトには、データベース、テーブル、インデックス、およびテナントが含まれます。

* MySQLユーザーテナントでリサイクルビンが有効になっている場合、管理できるリサイクルビンオブジェクトには、データベース、テーブル、およびインデックスが含まれます。

* Oracleユーザーテナントでリサイクルビンが有効になっている場合、管理できるリサイクルビンオブジェクトには、テーブルとインデックスが含まれます。

## 操作手順

1. `sys`テナントまたはユーザーテナントのテナント管理者としてデータベースにログインします。

   <main id="notice" type='explain'>
        <h4>説明</h4>
        <p>MySQLテナントの管理者ユーザーは<code>root</code>ユーザー、Oracleテナントの管理者ユーザーは<code>SYS</code>ユーザーです。</p>
   </main>

   接続例は以下の通りです。データベースへの接続時は、実際の環境に合わせてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

   より詳細なデータベース接続操作の手順については、[データベース接続の概要（MySQLモード）](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/100.connection-methods-overview-of-mysql-mode.md)および[データベース接続の概要（Oracleモード）](../../../300.develop/200.application-development-of-oracle-mode/100.connect-to-oceanbase-database-of-oracle-mode/100.connection-methods-overview-of-oracle-mode.md)を参照してください。

2. 以下のステートメントを実行し、リサイクルビンの状態を確認します。

   ```shell
   obclient [(none)]> SHOW VARIABLES LIKE 'recyclebin';
   +---------------+-------+
   | Variable_name | Value |
   +---------------+-------+
   | recyclebin    | ON    |
   +---------------+-------+
   1 row in set
   ```

3. ビジネスニーズに応じて、適切な方法でリサイクルビン機能を有効化または無効化します。

   変数`recyclebin`はBool型の変数であるため、複数の値をサポートしています。具体的には：

   * `on`、`1`、または `true`：リサイクルビンが有効であることを示します。

   * `off`、`0`、または `false`：リサイクルビンが無効であることを示します。

   * テナント全体（Global）でリサイクルビンを有効化または無効化する

     Global設定はテナント全体で有効になります。設定後は現在のセッションには反映されません。有効にするには、再ログインして新しいセッションを確立する必要があります。

     ステートメントは以下のとおりです：

     ```shell
     obclient [(none)]> SET GLOBAL recyclebin = on;

     obclient [(none)]> SET GLOBAL recyclebin = off;
     ```

     または

     ```shell
     obclient [(none)]> SET GLOBAL recyclebin = 1;

     obclient [(none)]> SET GLOBAL recyclebin = 0;
     ```

     または

     ```shell
     obclient [(none)]> SET GLOBAL recyclebin = true;

     obclient [(none)]> SET GLOBAL recyclebin = false;
     ```

   * 現在のセッション(Session)でリサイクルビンを有効化または無効化する

     Session設定は現在のセッション内でのみ有効です。

     ```shell
     obclient [(none)]> SET @@recyclebin = on;

     obclient [(none)]> SET @@recyclebin = off;
     ```

     または

     ```sql
     obclient [(none)]> SET @@recyclebin = 1;

     obclient [(none)]> SET @@recyclebin = 0;
     ```

     または

     ```shell
     obclient [(none)]> SET @@recyclebin = true;

     obclient [(none)]> SET @@recyclebin = false;
     ```
