# アーカイブパス設定のクリア

アーカイブを停止した後、必要に応じてアーカイブパスの設定をクリアできます。アーカイブパス設定をクリアしても、元のアーカイブパス配下のファイルは削除されません。アーカイブパス設定をクリアした後、後から元のパスを再利用する必要がある場合は、再度 `SET LOG_ARCHIVE_DEST` コマンドを使用して、アーカイブパスを元のパスに設定できます。

## 注意事項

アーカイブパス設定をクリアするには、テナントの現在のアーカイブ状態が `STOP` 状態である必要があります。アーカイブ状態の詳細な操作については、[アーカイブ進捗の確認](600.view-log-archive-progress.md)を参照してください。

## 手順

1. `sys` テナントまたはユーザーテナントのテナント管理者としてデータベースにログインします。

   <main id="notice" type='explain'>
        <h4>説明</h4>
   <p>MySQLモードの管理者ユーザーは <code>root</code> ユーザー、Oracleモードの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

2. 以下のコマンドを実行して、アーカイブパス設定をクリアします。

   * システムテナントが指定テナントのアーカイブパス設定をクリアする場合

     ```shell
     obclient> ALTER SYSTEM SET LOG_ARCHIVE_DEST='' TENANT = tenant_name;
     ```

   * ユーザーテナントが自身のテナントのアーカイブパス設定をクリアする場合

     ```shell
     obclient> ALTER SYSTEM SET LOG_ARCHIVE_DEST='';
     ```
