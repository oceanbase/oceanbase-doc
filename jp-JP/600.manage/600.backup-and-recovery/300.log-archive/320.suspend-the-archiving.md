# アーカイブの一時停止

アーカイブモードを有効にした後、ターゲット側のアーカイブ状態を `DEFER` に変更することでアーカイブを一時停止できます。

## 背景

ターゲット側のアーカイブ状態とその説明は以下の表のとおりです。

| ステータス | 説明 |
|-------------|-----------------------------------------------------------------------------------|
| ENABLE      | ターゲット側のアーカイブが有効な状態です。デフォルトでは、ターゲット側のアーカイブステータスは`ENABLE`状態になっています。              |
| DEFER       | ターゲット側のアーカイブが一時停止されています。この状態のターゲット側では、アーカイブタスクがある場合、システムはアーカイブタスクを一時停止します。 |

## 手順

1. `sys` テナントまたはユーザーテナントのテナント管理者としてデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードの管理者ユーザーは <code>root</code> ユーザー、Oracleモードの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

2. ターゲット側のアーカイブを一時停止します。

   * システムテナントが指定されたテナントのターゲット側のアーカイブを一時停止する

      ```sql
      ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE='DEFER' TENANT = tenant_name;
      ```

   * ユーザーテナントが自身のターゲット側のアーカイブを一時停止する

      ```sql
      ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE='DEFER';
      ```

3. 設定が成功したら、ビューを使用してターゲット側の状態情報を確認できます。具体的な操作については、[アーカイブパラメータの確認](../300.log-archive/800.view-parameters-of-log-archive.md)を参照してください。

## 次のステップ

アーカイブを一時停止した後、再開する必要がある場合は、ターゲット側のアーカイブ状態を `ENABLE` に設定することでアーカイブを再開できます。
