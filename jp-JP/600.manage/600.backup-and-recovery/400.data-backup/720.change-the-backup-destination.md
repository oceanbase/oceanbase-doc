# バックアップの出力先を変更する

データバックアップを有効にした後、ビジネスニーズに応じてバックアップの出力先を変更できます。

## 注意事項

自動クリーンアップは、`DATA_BACKUP_DEST` および `LOG_ARCHIVE_DEST` で現在指定されているパス配下のバックアップデータとアーカイブデータのみをクリーンアップできます。バックアップの出力先を変更した後、元のバックアップパス配下のデータは手動でのみクリーンアップできます。バックアップの手動クリーンアップの詳細な操作については、[指定されたバックアップまたはアーカイブデータの手動クリーンアップ](../500.clear-backup-data/100.manual-backup-cleanup/200.cleaning-up-specified-backup-data.md)および[バックアップパスまたはアーカイブパスの手動クリーンアップ](../500.clear-backup-data/100.manual-backup-cleanup/300.clear-the-backup_dest_or_archivelog_dest.md)を参照してください。

## 手順

1. テナント管理者がクラスタの `sys` テナントまたはユーザーテナントにログインします。

2. 実行中のバックアップタスクがあるかどうかを確認します。詳細な操作については、[データバックアップの進捗状況を確認する](500.view-data-backup-progress.md)を参照してください。

   クエリ結果が空ではない場合、データバックアップが実行中であることを意味し、実行中のバックアップタスクを停止する必要があります。バックアップタスクの停止の詳細な操作については、[バックアップの停止](400.stop-data-backup.md)を参照してください。

3. バックアップの出力先を再設定します。

   バックアップの出力先を再設定する際、置き換えるディレクトリがそのテナントが以前使用したバックアップディレクトリの場合、そのディレクトリ配下に `format` ファイルが存在している必要があります。それ以外の場合、置き換えるディレクトリは空である必要があります。

   バックアップの出力先を設定する詳細な操作については、[バックアップ前の準備](100.preparation-before-data-backup.md)を参照してください。

4. 完了後、`sys` テナントで `CDB_OB_BACKUP_PARAMETER` ビューを、またはユーザーテナントで `DBA_OB_BACKUP_PARAMETER` ビューを照会し、新しいバックアップの出力先が正常に設定されているかどうかを確認します。詳細な操作については、[データバックアップ関連パラメータの確認](700.parameters-of-data-backup.md)を参照してください。

## 次のステップ

バックアップの出力先の変更が成功した後、フルデータバックアップを再度開始する必要があります。フルデータバックアップの開始の詳細な操作については、[フルデータバックアップの開始](200.initiate-full-data-backup.md)を参照してください。
