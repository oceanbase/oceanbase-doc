# データバックアップ関連ビューの紹介

OceanBaseデータベースでは、各ビューを通じてバックアップの進捗状況と結果を確認できます。

## CDB_OB_BACKUP_JOBS

`oceanbase.CDB_OB_BACKUP_JOBS`は、各テナントのジョブレベルデータバックアップの進捗状況を表示するために使用されます。

|  フィールド                             |  説明 |
|----------------------------------|--------------|
| TENANT_ID                        | バックアップタスクを実行するテナントID |
| JOB_ID                           | バックアップタスクが属するjob_id。1回のバックアップタスクに対応します |
| INCARNATION                      | 分身ID |
| BACKUP_SET_ID                    | バックアップセットID |
| INITIATOR_TENANT_ID              | このJobを開始したテナントID |
| INITIATOR_JOB_ID                 | このJobを開始したテナントが属するjob_id |
| EXECUTOR_TENANT_ID               | このJobに対応するバックアップが必要なtenant_id  |
| PLUS_ARCHIVELOG                  | ログ補完機能を有効にするかどうか：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul> |
| BACKUP_TYPE                      | バックアップタイプ：<ul><li>`FULL`：フルバックアップを表す </li> <li>`INC`：増分バックアップを表す</li></ul>|
| JOB_LEVEL                        | Jobタスクが開始されたレベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始する場合</li><li>SYS_TENANT：sysテナントが指定したテナントのバックアップタスクを開始する場合</li><li>USER_TENANT：通常テナントが自身のバックアップを開始する場合</li></ul>  |
| ENCRYPTION_MOD                   | 暗号化モード：<ul><li>`None`：暗号化しないことを表す </li><li>`Password`：パスワードによるみだけの保護を表す</li></ul> |
| PASSWD                           | バックアップセットの暗号化パスワード |
| START_TIMESTAMP                  | Jobレベルバックアップタスクの開始時間 |
| END_TIMESTAMP                    | Jobレベルバックアップタスクの終了時間 |
| STATUS                           | バックアップタスクのステータス |
| RESULT                           | タスクエラーコード |
| COMMENT                          | エラーコードの説明 |
| DESCRIPTION	                     | ユーザーが指定したバックアップの説明情報 |
| PATH                             | バックアップパス |

## CDB_OB_BACKUP_TASKS

`oceanbase.CDB_OB_BACKUP_TASKS`は、各テナントのタスクレベルデータバックアップタスクの進捗状況を表示するために使用されます。

|  フィールド                             |  説明 |
|----------------------------------|--------------|
| TENANT_ID                        | バックアップタスクを実行するテナントID |
| TASK_ID                          | タスクレベルバックアップタスクのID。1つのバックアップセットに対応するタスク |
| JOB_ID                           | タスクレベルバックアップタスクが属するjob_id。1回のバックアップタスクに対応する |
| INCARNATION                      | 分身ID |
| BACKUP_SET_ID                    | タスクに対応するバックアップセットID |
| START_TIMESTAMP                  | タスクの開始時間 |
| END_TIMESTAMP                    | タスクの終了時間 |
| STATUS                           | バックアップタスクの状態 |
| START_SCN                        | バックアップタスクの開始ポイント |
| END_SCN                          | バックアップタスクの終了ポイント |
| USER_LS_START_SCN                | ユーザーログストリームの開始ポイント |
| ENCRYPTION_MODE                  | 暗号化モード：<ul><li>None：暗号化しないことを表す </li><li>Password：パスワード保護のみを使用することを表す </li><li>Password Encryption ：暗号化し、パスワードで保護することを表す </li><li >Transparent Encryption：TDE暗号化を使用することを表す </li><li>Dual mode Encryption ：TDE暗号化とパスワード保護の両方を使用することを表す</li></ul></br>現在、NoneとPasswordの2種類のモードのみをサポートしています。 |
| PASSWD                           | バックアップセットの暗号化パスワード |
| INPUT_BYTES                      | 入力バイト数 |
| OUTPUT_BYTES                     | 出力バイト数 |
| OUTPUT_RATE_BYTES                | 出力レート |
| EXTRA_META_BYTES                 | メタデータの追加バイト数 |
| TABLET_COUNT                     | 総パーティション数 |
| FINISH_TABLET_COUNT              | バックアップが完了したパーティション数 |
| MACRO_BLOCK_COUNT                | マクロブロック数 |
| FINISH_MACRO_BLOCK_COUNT         | バックアップが完了したマクロブロック数 |
| FILE_COUNT                       | ファイル数 |
| META_TURN_ID                     | バックアップメタデータのサイクル |
| DATA_TURN_ID                     | バックアップデータのサイクル |
| RESULT                           | エラーコード |
| COMMENT                          | エラーコードの説明 |
| PATH                             | バックアップパス情報 |
| MINOR_TURN_ID                    | ダンプデータバックアップ終了のサイクル      |
| MAJOR_TURN_ID                    | ベースラインデータバックアップ終了のサイクル      |
| DATA_PROGRESS                    | データバックアップの進捗状況。計算方法は `完了したマクロブロック数 / 総マクロブロック数`、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗が87.65%であることを表します。     |
| LOG_FILE_COUNT                   | アーカイブclogファイルの合計数      |
| FINISH_LOG_FILE_COUNT            | バックアップが完了したアーカイブclogファイルの数      |
| LOG_PROGRESS                     | アーカイブclogファイルのバックアップ進捗状況。計算方法は `バックアップが完了したアーカイブclogファイルの数 / アーカイブclogファイルの合計数`、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗が87.65%であることを表します。       |
