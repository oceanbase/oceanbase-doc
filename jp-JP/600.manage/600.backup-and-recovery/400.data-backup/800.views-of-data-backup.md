# データバックアップ関連ビューの紹介

OceanBaseデータベースは、各ビューを通じてバックアップの進捗状況と結果を確認できます。

## CDB_OB_BACKUP_JOBS

`oceanbase.CDB_OB_BACKUP_JOBS`は、各テナントのジョブレベルデータバックアップの進捗状況を表示するために使用されます。

| フィールド                             | 説明 |
|----------------------------------|--------------|
| TENANT_ID                        | バックアップタスクを実行するテナントID |
| JOB_ID                           | バックアップタスクに属するjob_id。1回のバックアップタスクに対応 |
| INCARNATION                      | 分身ID |
| BACKUP_SET_ID                    | バックアップセットID |
| INITIATOR_TENANT_ID              | このJobを開始したテナントID |
| INITIATOR_JOB_ID                 | このJobを開始したテナントが属するjob_id |
| EXECUTOR_TENANT_ID               | このJobに対応する、バックアップが必要なtenant_id |
| PLUS_ARCHIVELOG                  | ログ補完機能を有効にするかどうか：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul> |
| BACKUP_TYPE                      | バックアップタイプ：<ul><li>`FULL`：フルバックアップを示す </li> <li>`INC`：増分バックアップを示す</li></ul> |
| JOB_LEVEL                        | Jobタスクの開始レベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始</li><li>SYS_TENANT：sysテナントが開始した指定されたテナントのバックアップタスク</li><li>USER_TENANT：通常のテナントが自身のバックアップを開始</li></ul> |
| ENCRYPTION_MOD                   | 暗号化モード：<ul><li>`None`：暗号化しないことを示す </li><li>`Password`：パスワードのみを使用して保護することを示す</li></ul> |
| PASSWD                           | バックアップセットの暗号化パスワード |
| START_TIMESTAMP                  | Jobレベルのバックアップタスクの開始時間 |
| END_TIMESTAMP                    | Jobレベルのバックアップタスクの終了時間 |
| STATUS                           | バックアップタスクの状態 |
| RESULT                           | タスクエラーコード |
| COMMENT                          | エラーコードの説明 |
| DESCRIPTION                      | ユーザー指定のバックアップ説明情報 |
| PATH                             | バックアップパス |

| フィールド                   | 説明 |
|----------------------------------|--------------|
| TENANT_ID                        | バックアップタスクを実行するテナントID |
| JOB_ID                           | バックアップタスクに属するjob_id。1回のバックアップタスクに対応します |
| INCARNATION                      | 分身ID |
| BACKUP_SET_ID                    | バックアップセットID |
| INITIATOR_TENANT_ID              | このJobを開始したテナントID |
| INITIATOR_JOB_ID                 | このJobを開始したテナントが属するjob_id |
| EXECUTOR_TENANT_ID               | このJobに対応する、バックアップが必要なtenant_id  |
| PLUS_ARCHIVELOG                  | ログ補完機能を有効にするかどうか：<ul><li>ON：ログ補完機能を有効にする</li><li>OFF：ログ補完機能を無効にする</li></ul> |
| BACKUP_TYPE                      | バックアップタイプ：<ul><li>`FULL`：フルバックアップを示す </li> <li>`INC`：増分バックアップを示す</li></ul>|
| JOB_LEVEL                        | Jobタスクの開始レベル：<ul><li>CLUSTER：sysテナントがすべてのテナントのバックアップタスクを開始する</li><li>SYS_TENANT：sysテナントが開始した指定されたテナントのバックアップタスク</li><li>USER_TENANT：通常のテナントが自身のバックアップを開始する</li></ul> |
| ENCRYPTION_MOD                   | 暗号化モード：<ul><li>None：暗号化しないことを示す </li><li>Password：パスワードによるみだけの保護を示す </li><li>Password Encryption：暗号化し、パスワードによる保護を示す </li><li >Transparent Encryption：TDE暗号化を使用することを示す </li><li>Dual mode Encryption：TDE暗号化とパスワード保護の両方を使用することを示す</li></ul></br>現在、NoneとPasswordの2種類のモードのみサポートしています。|
| PASSWD                           | バックアップセットの暗号化パスワード |
| START_TIMESTAMP                  | Jobレベルのバックアップタスクの開始時間 |
| END_TIMESTAMP                    | Jobレベルのバックアップタスクの終了時間 |
| STATUS                           | バックアップタスクの状態 |
| RESULT                           | タスクエラーコード |
| COMMENT                          | エラーコードの説明 |
| DESCRIPTION                      | ユーザー指定のバックアップ説明情報 |
| PATH                             | バックアップパス |

## CDB_OB_BACKUP_TASKS

`oceanbase.CDB_OB_BACKUP_TASKS`は、各テナントのタスクレベルのデータバックアップタスクの進捗状況を表示するために使用されます。

| フィールド                             | 説明 |
|----------------------------------|--------------|
| TENANT_ID                        | バックアップタスクを実行するテナントID |
| TASK_ID                          | タスクレベルのバックアップタスクのID。1つのバックアップセットに対応するタスク |
| JOB_ID                           | タスクレベルのバックアップタスクが属するjob_id。1回のバックアップタスクに対応 |
| INCARNATION                      | 分身ID |
| BACKUP_SET_ID                    | タスクに対応するバックアップセットID |
| START_TIMESTAMP                  | タスクの開始時間 |
| END_TIMESTAMP                    | タスクの終了時間 |
| STATUS                           | バックアップタスクの状態 |
| START_SCN                        | バックアップタスクの開始ポイント |
| END_SCN                          | バックアップタスクの終了ポイント |
| USER_LS_START_SCN                | ユーザーログストリームの開始ポイント |
| ENCRYPTION_MODE                  | 暗号化モード：<ul><li>None：暗号化しないことを示す </li><li>Password：パスワードによるみなし保護を示す </li><li>Password Encryption：暗号化およびパスワードによる保護を示す </li><li >Transparent Encryption：TDE暗号化を使用することを示す </li><li>Dual mode Encryption：TDE暗号化およびパスワードによる保護を使用することを示す</li></ul></br>現在、NoneとPasswordの2種類のモードのみサポートしています。 |
| PASSWD                           | バックアップセットの暗号化パスワード |
| INPUT_BYTES                      | 入力バイト数 |
| OUTPUT_BYTES                     | 出力バイト数 |
| OUTPUT_RATE_BYTES                | 出力レート |
| EXTRA_META_BYTES                 | メタデータの追加バイト数 |
| TABLET_COUNT                     | 合計パーティション数 |
| FINISH_TABLET_COUNT              | バックアップ完了のパーティション数 |
| MACRO_BLOCK_COUNT                | マクロブロック数 |
| FINISH_macro_BLOCK_COUNT         | バックアップ完了のマクロブロック数 |
| FILE_COUNT                       | ファイル数 |
| META_TURN_ID                     | バックアップメタデータのラウンド |
| DATA_TURN_ID                     | バックアップデータのラウンド |
| RESULT                           | エラーコード |
| COMMENT                          | エラーコードの説明 |
| PATH                             | バックアップパス情報 |
| MINOR_TURN_ID                    | ダンプデータバックアップ終了のラウンド      |
| MAJOR_TURN_ID                    | ベースラインデータバックアップ終了のラウンド      |
| DATA_PROGRESS                    | データバックアップの進捗状況。計算方法は`完了したマクロブロック数 / 合計マクロブロック数`で、結果は小数点以下2桁を保持します。例えば、87.65は現在の進捗率が87.65%であることを示します。     |

| END_TIMESTAMP            | バックアップ終了時刻 |
