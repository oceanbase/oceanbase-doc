# バックアップ構成パラメータ

OceanBaseデータベースは、テナントレベルの構成パラメータとクラスタレベルの構成パラメータのバックアップをサポートしています。構成パラメータをバックアップすることで、後のクラスタやテナントの状態を迅速に復元する際の設定の参照に役立ちます。

## 注意事項

本記事で説明しているクラスタレベル構成パラメータおよびテナントレベル構成パラメータは、ユーザーの設定参考として提供されているものです。物理復元時には、これらの設定はクラスタやテナントには反映されません。

## クラスタレベル構成パラメータのバックアップ

データバックアップではクラスタレベル構成パラメータはバックアップされません。クラスタレベル構成パラメータをバックアップする場合は、コマンドを手動で実行して、元のクラスタレベル構成パラメータを指定のパスにバックアップする必要があります（デフォルト設定以外のクラスタ範囲の構成パラメータのみをバックアップします）。

### 使用上の制限と注意事項

* クラスタレベル構成パラメータをバックアップできるのは `sys` テナントのみです。ユーザーテナントではサポートされていません。

* クラスタレベル構成パラメータをバックアップする際、`all_server_list`、`rootservice_list`、`debug_sync_timeout` などのパラメータは、値がデフォルト値であるかどうかに関係なく、バックアップされません。

### 手順

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

2. 以下のSQLステートメントを実行して、クラスタレベル構成パラメータをバックアップします。

   SQLステートメントは以下のとおりです：

   ```sql
   ALTER SYSTEM BACKUP CLUSTER PARAMETERS TO 'parameters_backup_path';
   ```

   ここで、`parameters_backup_path`はクラスタレベル構成パラメータバックアップファイルのターゲットパスであり、ユーザーが自ら指定する必要があります。そのパス要件はデータバックアップのバックアップ宛先パス要件と同じでなければなりません。データバックアップのバックアップ宛先要件については、[データバックアップ前の準備](100.preparation-before-data-backup.md)を参照してください。

   関連する例は以下のとおりです：

   :::tab
   tab Alibaba Cloud OSS

   クラスタレベルのパラメータを`oss://oceanbase-test-bucket/backup/cluster_parameters?host=***.aliyun-inc.com&access_id=***&access_key=***`ディレクトリにバックアップします。

   ```shell

   ```

   tab NFS


   tab AWS S3

   クラスタレベルのパラメータを`s3://oceanbase-test-bucket/backup/data/cluster_parameters?host=s3.***.amazonaws.com&access_id=****&access_key=****&s3_region=****`ディレクトリにバックアップします。

## テナントレベル構成パラメータのバックアップ

テナントレベル構成パラメータについては、[フルデータバックアップ](200.initiate-full-data-backup.md)または[増分データバックアップ](300.initiate-incremental-data-backup.md)を実行する際、システムはテナントレベル構成パラメータ（デフォルト設定以外のテナント範囲のパラメータ）およびテナントのリソース構成などの情報をテナントデータバックアップの一部として、バックアップ先に一緒に保存します。追加のバックアップ操作は不要です。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>構成パラメータ<code>external_kms_info</code>と<code>tde_method</code>には暗号化に関連する機密情報が含まれているため、テナントレベル構成パラメータをバックアップする際には、その値がデフォルト値であるかどうかにかかわらず、バックアップされません。</p>
</main>

## 次のステップ

バックアップが正常に完了すると、ユーザーは事前に指定したバックアップパスで、テナントレベルおよびクラスタレベルの構成パラメータバックアップファイルを取得できます。テナントレベル構成パラメータとクラスタレベル構成パラメータのバックアップ後の詳細なディレクトリ構造については、[物理バックアップとリストアの概要](../100.overview-of-physical-backup-and-recovery.md)を参照してください。

構成パラメータのバックアップファイルを取得した後、ob_adminツールの`dump_backup`コマンドを使用して解析し、構成情報を取得することもできます。詳細な解析の説明と例については、[dump_backup](../../../700.reference/1500.Components-and-Tools/100.manage/200.ob-admin/400.backup-and-recovery/600.dump-backup.md)を参照してください。
