# バックアップ関連ビューのクリーンアップについて

## CDB_OB_BACKUP_DELETE_JOBS

システムテナントはこのビューを通じて、すべてのテナントで実行中のバックアップクリーンアップタスクの進捗状況を確認できます。

|  フィールド |  説明 |
|------|-------|
| TENANT_ID                 |   テナントID |
| JOB_ID                    |   クリーンアップタスクを実行するJOB_ID。各テナント間で独立しています |
| INCARNATION               |   分身ID |
| INITIATOR_TENANT_ID       |   クリーンアップタスクを開始したテナントID |
| INITIATOR_JOB_ID          |   クリーンアップタスクを開始したJOB_ID |
| EXECUTOR_TENANT_ID        |   クリーンアップタスクを実行するテナントIDのリスト |
| TYPE                      |   クリーンアップタイプ：<ul><li>`DELETE OBSOLETE BACKUP`：期限切れクリーンアップ</li> <li>`DELETE BACKUP ALL`：パス内のすべてのバックアップまたはアーカイブデータを削除</li> <li>`DELETE BACKUPSET`：指定されたデータバックアップセットをクリーンアップ</li> <li>`DELETE ARCHIVELOG_PIECE`：指定されたログアーカイブPieceをクリーンアップ</li></ul> |
| PARAMETER                 |   クリーンアップパラメータ。クリーンアップタイプごとの具体的なパラメータ情報を説明します |
| JOB_LEVEL                 |   タスク開始レベル: <ul><li> `USER_TENANT` ：ユーザーテナントが開始したタスク</li><li> `SYS_TENANT` ：システムテナントが開始したタスク</li></ul>|
| START_TIMESTAMP           |   タスク開始時のテナント現在時刻 |
| END_TIMESTAMP             |   タスク終了時のテナント現在時刻 |
| STATUS                    |    タスク状態： <ul><li> `INIT` ：タスクの初期化段階です </li><li> `DOING` ：タスクの実行段階です</li><li> `CANCELING` ：タスクがキャンセルされた段階です</li><li> `COMPLETED` : タスクが正常に実行されました </li><li> `FAILED` ：タスクの実行に失敗しました </li><li> `CANCELED` ：タスクが正常にキャンセルされました </li></ul> |
| TASK_COUNT                |   合計のbackup_set/backup_pieceタスク数 |
| SUCCESS_TASK_COUNT        |  成功したbackup_set/backup_pieceタスク数 |
| RESULT                    |   実行結果。エラーコードを表示します|
| COMMENT                   |   クリーンアップタスク失敗レコードの説明情報|

## CDB_OB_BACKUP_DELETE_TASKS

システムテナントはこのビューを通じて、すべてのテナントで実行中の`backup_set/backup_piece`バックアップ・クリーンアップタスクの進捗状況を確認できます。

|  フィールド |  説明 |
|------|-------|
| TENANT_ID           |   テナントID |
| TASK_ID             |   タスクID。1つのタスクは1つの`backup_set/backup_piece`のクリーンアップに対応します |
| INCARNATION         |   分身ID |
| JOB_ID              |   タスクが属するJOB_ID |
| TASK_TYPE           |   タスクタイプ：<ul><li> BACKUP SET ：`backup_set`のクリーンアップ </li><li>BACKUP PIECE ：`backup_piece`のクリーンアップ </li></ul>|
| ID                  |   クリーンアップされる`backup_set/backup_piece`のID |
| ROUND_ID            |   タスクタイプがBACKUP PIECEの場合、該当するログアーカイブラウンド |
| DEST_ID             |   バックアップが存在する宛先のdest_id |
| START_TIMESTAMP     |   タスク開始時のテナント現在時刻 |
| END_TIMESTAMP       |   タスク終了時のテナント現在時刻 |
| STATUS                    |    タスク状態： <ul><li> `INIT` ：タスクの初期化段階です </li><li> `DOING` ：タスクの実行段階です</li><li> `CANCELING` ：タスクがキャンセルされた段階です</li><li> `COMPLETED` : タスクが正常に実行されました </li><li> `FAILED` ：タスクの実行に失敗しました </li><li> `CANCELED` ：タスクが正常にキャンセルされました </li></ul> |
| TOTAL_LS_COUNT      |  タスク内のログストリームの総数 |
| FINISH_LS_COUNT     |   クリーンアップに成功したログストリームタスク数 |
| RESULT              |   タスク結果。エラーコードを表示 |
| COMMENT             |   クリーンアップタスクの失敗レコードの説明情報 |
| PATH                |   バックアップが存在する宛先のパス情報 |
