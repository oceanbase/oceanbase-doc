# バックアップクリーンアップ結果の確認

クリーンアップポリシーが正常に設定され、自動クリーンアップがトリガーされた後、クリーンアップタスクの実行が完了すると、履歴テーブルでその実行結果を確認できます。

## システムテナントによるクリーンアップタスク履歴の確認

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

   接続例は以下の通りです。データベースへの接続時は、実際の環境に合わせてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. クリーンアップタスクの履歴を確認します。

   * Jobレベルのクリーンアップタスク履歴を確認します。

      Jobレベルのクリーンアップタスクには、クリーンアップタスクの開始に関する情報が記録されています。

      ```shell
      obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_JOB_HISTORY WHERE TENANT_ID=1002\G
      ```

## ユーザーテナントによるクリーンアップタスク履歴の確認

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLテナントの管理者ユーザーは<code>root</code>ユーザー、Oracleテナントの管理者ユーザーは<code>SYS</code>ユーザーです。</p>
   </main>

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. クリーンアップタスクの履歴を確認します。

   * ジョブレベルのクリーンアップタスク履歴を確認します。

     ジョブレベルのクリーンアップタスクでは、クリーンアップタスクの開始に関する情報が記録されています。

     :::tab
     tab MySQLモード

     MySQLモードでのクエリ例は以下のとおりです：

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     tab Oracleモード

     Oracleモードでのクエリ例は以下のとおりです：

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     :::

     `TENANT_ID`フィールドが欠けている点を除き、ビュー`DBA_OB_BACKUP_DELETE_JOB_HISTORY`のすべてのフィールドはビュー`CDB_OB_BACKUP_DELETE_JOB_HISTORY`に対応しています。クエリ結果の詳細な説明については、**システムテナントによるクリーンアップタスク履歴の確認**を参照してください。

   * タスクレベルのクリーンアップタスク履歴を確認します。

     タスクレベルのクリーンアップタスクでは、`backup_set/backup_piece`がクリーンアップされた詳細情報が記録されています。

     :::tab
     tab MySQLモード

     MySQLモードでのクエリ例は以下のとおりです：

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     tab Oracleモード

     Oracleモードでのクエリ例は以下のとおりです：

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     :::

     `TENANT_ID` フィールドが欠けている点を除き、ビュー `DBA_OB_BACKUP_DELETE_TASK_HISTORY` のすべてのフィールドはビュー `CDB_OB_BACKUP_DELETE_TASK_HISTORY` の対応するフィールドと一致します。クエリ結果の詳細については、**システムテナントによるクリーンアップタスク履歴の確認**を参照してください。
