# スタンバイテナントからプライマリテナントへの切り替え

リストアが成功すると、リストアされたテナントはすべてスタンバイテナントとなります。`ACTIVATE STANDBY` コマンドを使用して、スタンバイテナントをプライマリテナントに切り替えることができます。

## 背景情報

物理リストアのプロセスは物理スタンバイデータベースと統一されており、物理リストア後のテナントはスタンバイテナントとなります。その後、このテナントはスタンバイテナントとして関連サービスを提供することも、プライマリテナントに切り替えてサービスを提供することもできます。

## 前提条件

リストア操作が成功したことを確認してください。リストア結果の確認に関する操作については、[リストア結果の確認](../600.restore-data/500.view-the-restore-history.md)を参照してください。

## 使用上の制限

クイックリストアではこの機能をサポートしていません。

## システムテナントによるスタンバイテナントからプライマリテナントへの切り替え

システムテナントは、システム内のスタンバイテナントをプライマリテナントに切り替えることができます。

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 以下のステートメントを実行して、スタンバイからプライマリへの切り替えを行います。

   ステートメントは以下のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY TENANT tenant_name;
   ```

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>このコマンドは一度に1つのテナントしか切り替えられません。複数のテナントを切り替える必要がある場合は、このコマンドを繰り返し実行する必要があります。</p>
   </main>

   例：

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY TENANT mysql;
   ```

   コマンド内の各パラメータの説明については、[物理リストア関連パラメータ紹介](../600.restore-data/800.parameters-of-the-restore.md)を参照してください。

## ユーザーテナントによるスタンバイテナントからプライマリテナントへの切り替え

ユーザーテナントは、自身をスタンバイテナントからプライマリテナントに切り替えることができます。

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードの管理者ユーザーは <code>root</code> ユーザー、Oracleモードの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

2. 以下のステートメントを実行して、スタンバイからプライマリへの切り替えを行います。

   ステートメントは以下のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY;
   ```
