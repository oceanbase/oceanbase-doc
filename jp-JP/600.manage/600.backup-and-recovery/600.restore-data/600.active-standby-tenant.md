# スタンバイテナントをプライマリテナントに変更する

復旧が成功した後、復旧されたテナントはすべてスタンバイテナントとなります。`ACTIVATE STANDBY` コマンドを使用して、スタンバイテナントをプライマリテナントに変更できます。

## 背景

物理復旧の手順は物理スタンバイデータベースと統一されており、物理復旧後のテナントはスタンバイテナントとなります。その後、このテナントはスタンバイテナントとして関連サービスを提供することも、プライマリテナントとしてサービスを提供することも可能です。

## 前提条件

復旧操作が成功したことを確認してください。復旧結果の確認方法については、[復旧結果の確認](../600.restore-data/500.view-the-restore-history.md)を参照してください。

## システムテナントによるスタンバイテナントのプライマリテナントへの変更

システムテナントは、システム内のスタンバイテナントをプライマリテナントに変更できます。

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 以下のステートメントを実行して、スタンバイからプライマリへの切り替えを行います。

   ステートメントは次のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY TENANT tenant_name;
   ```

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>このコマンドは一度に1つのテナントしか切り替えられません。複数のテナントを切り替える必要がある場合は、このコマンドを繰り返し実行する必要があります。</p>
   </main>

   例：

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY TENANT mysql;
   ```

   コマンド内の各パラメータの説明については、[物理復旧関連パラメータの紹介](../600.restore-data/800.parameters-of-the-restore.md)を参照してください。

## ユーザーテナントによるスタンバイテナントのプライマリテナントへの変更

ユーザーテナントは、自身をスタンバイテナントからプライマリテナントに変更できます。

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードの管理者ユーザーは <code>root</code> ユーザー、Oracleモードの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

2. 以下のステートメントを実行して、スタンバイからプライマリへの切り替えを行います。

   ステートメントは次のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY;
   ```
