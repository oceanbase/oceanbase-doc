# 物理復旧関連ビューの紹介

OceanBaseデータベースは、各ビューを通じて復旧の進捗状況と結果を確認できます。

## CDB_OB_RESTORE_PROGRESS

`CDB_OB_RESTORE_PROGRESS`は、各テナントの復元進捗状況を表示するために使用されます。

| フィールド | 説明 |
|----------------------------------|------------------------|
| TENANT_ID                        | 復旧タスクを実行するテナントID  |
| JOB_ID                           | 復旧に属するjob_id、対応する復旧タスク  |
| RESTORE_TENANT_NAME              | 復旧対象のテナント名  |
| RESTORE_TENANT_ID                | 復旧対象のテナントID  |
| BACKUP_TENANT_NAME               | バックアップ元のテナント名  |
| BACKUP_TENANT_ID                 | バックアップ元のテナントID  |
| BACKUP_CLUSTER_NAME              | バックアップ元のクラスタ名  |
| BACKUP_DEST                      |バックアップセットパス、ユーザーが入力したデータバックアップパスとログアーカイブパスを指します    |
| RESTORE_OPTION                   | 復旧オプション、復旧開始時にユーザーが指定した`restore_option`  |
| RESTORE_SCN                      | ユーザーが指定した復旧ポイント  |
| RESTORE_SCN_DISPLAY              | ユーザーが指定した復旧ポイントのタイムスタンプ表記  |
| STATUS                           | 復旧状態：システムテナントの復旧タスクと復旧対象テナントの復旧タスクの状態が一致しません。<br>システムテナント：<ul><li>`CREATE_TENANT`：テナントの作成、この段階でシステムテナントは復旧対象テナントを作成します </li> <li>`WAIT_TENANT_RESTORE_FINISH`：復旧対象テナントの復旧終了を待機 </li> <li>`RESTORE_SUCCESS`：テナントの復旧成功 </li> <li>`RESTORE_FAIL`：テナントの復旧失敗 </li></ul> <br>復旧対象テナント：<ul><li>`RESTORING`：テナントデータの復旧中 </li> <li>`RESTORE_SUCCESS`：復旧成功 </li> <li>`RESTORE_FAIL`：復旧失敗 </li></ul> |
| START_TIMESTAMP                  | 復旧タスク開始時のタイムスタンプ  |
| BACKUP_SET_LIST                  | 復旧に依存するデータバックアップセットパスリスト、バックアップセット間は`,`で区切ります。例えば：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc` |
| BACKUP_PIECE_LIST                | 復旧に依存するログアーカイブピースパスリスト、ピース間は`,`で区切ります。例えば：`file:///data/nfs/backup/archive/piece_d1001r1p1,file:///data/nfs/backup/archive/piece_d1001r2p2`  |
| RECOVER_SCN                      | ログの復旧ポイント。システムテナントの場合、このフィールドの値は`NULL`です |
| RECOVER_SCN_DISPLAY              | ログの復旧ポイントのタイムスタンプ表記。システムテナントの場合、このフィールドの値は`NULL`です |
| RECOVER_PROGRESS                 | ログ復旧の進捗状況、結果は小数点以下2桁を保持します。例えば：`87.65`と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は`NULL`です |
| TABLET_COUNT                     | 復旧対象のTabletの総数。システムテナントの場合、このフィールドの値は`NULL`です |
| FINISH_TABLET_COUNT              | 完了した復旧のTabletの総数。システムテナントの場合、このフィールドの値は`NULL`です  |
| RESTORE_PROGRESS                 | データ復旧の進捗状況、結果は小数点以下2桁を保持します。例えば：`87.65`と表示される場合、現在の進捗率は87.65%を意味します。システムテナントの場合、このフィールドの値は`NULL`です |
| TOTAL_BYTES                      | 復旧総バイト数  |
| TOTAL_BYTES_DISPLAY              | 復元した総バイト数をストレージ容量単位で表示します  |
| FINISH_BYTES                     | 復元完了バイト数。現在のバージョンでは、この値は常に0です    |
| FINISH_BYTES_DISPLAY             | 復元完了バイト数をストレージ容量単位で表示します。現在のバージョンでは、この値は常に0です    |
| DESCRIPTION                      | 復元コマンドで指定された`DESCRIPTION`情報   |

## CDB_OB_RESTORE_HISTORY

`CDB_OB_RESTORE_HISTORY`は、各テナントの復元結果を表示するために使用されます。

| フィールド | 説明 |
|----------------------------------|--------------|
| TENANT_ID                        | 復旧タスクを実行するテナントID  |
| JOB_ID                           | 復旧に属するjob_id、対応する復旧タスクを表す |
| RESTORE_TENANT_NAME              | 復旧するテナント名  |
| RESTORE_TENANT_ID                | 復旧するテナントID  |
| BACKUP_TENANT_NAME               | バックアップのソーステナント名    |
| BACKUP_TENANT_ID                 | バックアップのソーステナントID  |
| BACKUP_CLUSTER_NAME              | バックアップのソースクラスタ名   |
| BACKUP_DEST                      | バックアップセットパス、ユーザーが入力したデータバックアップパスとログアーカイブパスを指す   |
| RESTORE_SCN                      | ユーザー指定の復旧ポイント  |
| RESTORE_SCN_DISPLAY              | ユーザー指定の復旧ポイントのタイムスタンプ表記  |
| RESTORE_OPTION                   | 復旧オプション、復旧開始時にユーザーが指定した`restore_option`  |
| START_TIMESTAMP                  | 復旧タスク開始タイムスタンプ  |
| FINISH_TIMESTAMP                 | 復旧タスク終了タイムスタンプ  |
| STATUS                           | 復旧結果：<ul> <li> `SUCCESS`：復旧成功を示す </li> <li> `FAILED`：復旧失敗を示す </li></ul> |
| BACKUP_PIECE_LIST                | 復旧に依存するログアーカイブシャードパスリスト、シャード間は`,`で区切る。例：`file:///data/nfs/backup/archive/piece_d1001r1p1,file:///data/nfs/backup/archive/piece_d1001r2p2` |
| BACKUP_SET_LIST                  | 復旧に依存するデータバックアップセットパスリスト、バックアップセット間は`,`で区切る。例：`file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc` |
| BACKUP_CLUSTER_VERSION           | バックアップソースクラスタのバージョン番号 |
| LS_COUNT                         | 復旧ログストリームの総数   |
| FINISH_LS_COUNT                  | 復旧完了ログストリーム数  |
| TABLET_COUNT                     | 復旧シャードの総数  |
| FINISH_TABLET_COUNT              | 復旧完了シャード数  |
| TOTAL_BYTES                      | 復旧総バイト数  |
| TOTAL_BYTES_DISPLAY              | 復旧総バイト数、ストレージ容量単位で表示  |
| FINISH_BYTES                     | 復旧完了バイト数。現在のバージョンでは、この値は常に0となる    |
| FINISH_BYTES_DISPLAY             | 復旧完了バイト数、ストレージ容量単位で表示。現在のバージョンでは、この値は常に0となる    |
| DESCRIPTION                      | 復旧コマンドで指定された`DESCRIPTION`情報  |
| COMMENT                          | 復旧失敗時に失敗情報を記録する  |
