# 物理復旧結果の確認

復旧が完了した後、ビューを通じて物理復旧の結果を確認できます。

## 手順

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

2. 復元が完了したら、以下のステートメントを実行して、クラスタの復元タスク結果を確認できます。

   ```sql
   obclient [(none)]> SELECT * FROM oceanbase.CDB_OB_RESTORE_HISTORY\G
   ```

## 次のステップ

物理復旧が正常に実行された後、復旧されたテナントはすべてスタンバイテナントとなります。以下の操作を実行できます：

* `recover` コマンドを実行し、スタンバイテナントとしてソーステナントからのログ再生を続けます。詳細な操作については、[スタンバイテナントのログ再生](510.recover-the-standby-tenant.md)を参照してください。

* スタンバイテナントからのプライマリテナントへの切り替えコマンドを実行し、スタンバイテナントをプライマリテナントに変換します。詳細な操作については、[スタンバイテナントからプライマリテナントへの切り替え](600.active-standby-tenant.md)を参照してください。
