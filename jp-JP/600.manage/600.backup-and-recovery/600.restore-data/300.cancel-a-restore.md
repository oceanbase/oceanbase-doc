# 物理復元のキャンセル

テナントデータの復元プロセス中に、`ALTER SYSTEM CANCEL RESTORE` ステートメントを使用して復元を停止できます。このステートメントは、復元状態にあるテナントを削除します。

## 手順

1. `root` ユーザーで、復元対象のテナントが存在するクラスタの `sys` テナントにログインします。

2. 以下のコマンドを実行して、復元を即時キャンセルし、復元対象のデータを持つテナントを削除します。

   ```sql
   ALTER SYSTEM CANCEL RESTORE tenant_name;
   ```

   ここで、`tenant_name` には復元対象のテナント名を入力する必要があります。
