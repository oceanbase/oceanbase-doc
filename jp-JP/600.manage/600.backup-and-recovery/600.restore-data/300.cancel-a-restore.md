# 物理リストアのキャンセル

テナントデータのリストアプロセス中に、`ALTER SYSTEM CANCEL RESTORE` ステートメントを使用してリストアを停止できます。このステートメントは、リストア状態にあるテナントを削除します。

## 操作手順

1. `root` ユーザーで、リストア対象のテナントが存在するクラスタの `sys` テナントにログインします。

2. 以下のコマンドを実行して、リストアを即座にキャンセルし、リストア対象のデータを持つテナントを削除します。

   ```sql
   ALTER SYSTEM CANCEL RESTORE tenant_name;
   ```

   ここで、`tenant_name` にはリストア対象のテナント名を入力する必要があります。
