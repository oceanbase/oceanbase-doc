# スタンバイテナントによるセグメントログの再生

復旧が成功すると、復旧されたテナントはすべてスタンバイテナントとなります。`RECOVER` コマンドを実行して、テナント復旧時に指定したログアーカイブソースからログの再生を続けることができます。

## 背景

物理復旧プロセスは物理スタンバイデータベースと統一されており、物理復旧後のテナントはスタンバイテナントとなります。その後、このテナントはスタンバイテナントとして関連サービスを提供することも、メインテナントとしてサービスを提供することも可能です。

## 前提条件

復旧操作が成功したことを確認してください。復旧結果の確認方法については、[復旧結果の確認](../600.restore-data/500.view-the-restore-history.md)を参照してください。

## システムテナントによるスタンバイテナントのログ再生

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 以下のステートメントを実行して、ログ再生操作を実行します。

   ステートメントは以下のとおりです：

   * 指定されたタイムスタンプまでログを再生し、そのタイムスタンプポイントを含みます。

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name UNTIL TIME='timestamp';
     ```

   * 指定されたSCNまでログを再生し、そのSCNポイントを含みます。

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name UNTIL SCN=scn;
     ```

   * 終了点なしで、アーカイブソースのログを継続的に再生します。

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name UNTIL UNLIMITED;
     ```

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>このコマンドでは一度に1つのスタンバイテナントしか指定できません。複数のテナントを指定する必要がある場合は、このコマンドを繰り返し実行する必要があります。</p>
     </main>

3. (オプション) 以下のステートメントを実行して、スタンバイテナントのログ再生をキャンセルできます。

   ```shell
   obclient [(none)]> ALTER SYSTEM RECOVER STANDBY TENANT tenant_name CANCEL;
   ```

## スタンバイテナントによる自己ログの再生

スタンバイテナント自身でもログの再生を開始できます。

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードの管理者ユーザーは <code>root</code> ユーザー、Oracleモードの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

2. 以下のステートメントを実行して、ログ再生操作を実行します。

   ステートメントは以下のとおりです：

   * 指定されたタイムスタンプまでログを再生し、そのタイムスタンプポイントを含みます。

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY UNTIL TIME='timestamp';
     ```

   * 指定されたSCNまでログを再生し、そのSCNポイントを含みます。

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY UNTIL SCN=scn;
     ```

   * 終了点なしで、アーカイブソースのログを継続的に再生します。

     ```shell
     obclient [(none)]> ALTER SYSTEM RECOVER STANDBY UNTIL UNLIMITED;
     ```

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>このコマンドでは一度に1つのスタンバイテナントしか指定できません。複数のテナントを指定する必要がある場合は、このコマンドを繰り返し実行する必要があります。</p>
     </main>

3. (オプション) 以下のステートメントを実行して、スタンバイテナントのログ再生をキャンセルできます。

   ```shell
   obclient [(none)]> ALTER SYSTEM RECOVER STANDBY CANCEL;
   ```

コマンド内の各パラメータの説明については、[復旧パラメータ](../600.restore-data/800.parameters-of-the-restore.md)を参照してください。
