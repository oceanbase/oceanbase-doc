# バックアップ検証の進捗状況を確認する

バックアップ検証を開始した後、ビューを使用して検証タスクの状態と進捗状況を確認できます。

## システムテナントからユーザーテナントのバックアップ検証タスクを確認する

システムテナントは、ビュー `CDB_OB_BACKUP_VALIDATE_JOBS` および `CDB_OB_BACKUP_VALIDATE_TASKS` を使用して、各ユーザーテナント内のすべての検証タスクの状態と進捗状況を確認できます。

ここで：

* ビュー `CDB_OB_BACKUP_VALIDATE_JOBS` では、各Jobは1つの検証指示に対応します。検証指示の実行時に複数のユーザーテナントが関連している場合、ビューには複数のユーザーテナントレベルのサブJobが対応する可能性があります。

* ビュー `CDB_OB_BACKUP_VALIDATE_TASKS` では、各Taskは1つのバックアップセット(backup_set)またはログアーカイブピース(archive_piece)の検証タスクに対応します。

システムテナントでバックアップ検証の進捗状況を確認する手順は以下のとおりです：

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Jobレベルの検証タスクの状態と進捗状況を確認します。

   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_JOBS\G

## ユーザーテナントが自身のテナント内のバックアップ検証タスクを確認する

ユーザーテナントは、ビュー `DBA_OB_BACKUP_VALIDATE_JOBS` と `DBA_OB_BACKUP_VALIDATE_TASKS` を使用して、自身のテナント内の検証タスクの状態と進捗を確認できます。

具体的には：

* ビュー `DBA_OB_BACKUP_VALIDATE_JOBS` では、各Jobは1つの検証指示に対応します。

* ビュー `DBA_OB_BACKUP_VALIDATE_TASKS` では、各Taskは1つのバックアップセット（backup_set）またはログアーカイブピース（archive_piece）の検証タスクに対応します。

ユーザーテナントでバックアップ検証の進捗を確認する手順は以下のとおりです：

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLテナントの管理者ユーザーは <code>root</code> ユーザー、Oracleテナントの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. Jobレベル検証タスクの状態と進捗を確認します。

   :::tab
   tab MySQLモード

   MySQLモードでのクエリステートメントは以下のとおりです：

   ```shell
   obclient(root@mysqltenant)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS;
   ```

   tab Oracleモード

   Oracleモードでのクエリステートメントは以下のとおりです：

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOBS;
   ```

   :::

   クエリ結果の例は以下のとおりです：
