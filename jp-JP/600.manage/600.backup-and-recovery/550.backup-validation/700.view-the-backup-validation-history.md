# バックアップ検証結果の確認

バックアップ検証タスク終了後、ビューを通じて検証タスクの実行結果を確認できます。

## システムテナントによる指定ユーザーテナントのバックアップ検証タスクの確認

システムテナントは、ビュー `CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` および `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY` を使用して、各ユーザーテナント内のすべての検証タスクの実行結果を確認できます。

なお：

* ビュー `CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` では、各ジョブは1つの検証指示に対応します。検証指示の実行時に複数のユーザーテナントが関連していた場合、ビュー上には複数のユーザーテナントレベルのサブジョブが対応する可能性があります。

* ビュー `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY` では、各タスクは1つのバックアップセット（backup_set）またはログアーカイブピース（archive_piece）の検証タスクに対応します。

システムテナントでバックアップ検証結果を確認する操作は以下のとおりです：

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

   接続例は以下のとおりですが、データベースへの接続時は実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. ジョブレベルの検証タスクの実行結果を確認します。

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_JOB_HISTORY\G
   ```

   クエリ結果は次のとおりです：

   ```shell
   *************************** 1. row ***************************
             TENANT_ID: 1002
                JOB_ID: 2
           INCARNATION: 1
   INITIATOR_TENANT_ID: 1002
      INITIATOR_JOB_ID: 0
    EXECUTOR_TENANT_ID:
                  TYPE: DATABASE
                  PATH:
             PATH_TYPE:
                    ID:
        VALIDATE_LEVEL: basic
       START_TIMESTAMP: 2026-03-03 13:58:07.778690
         END_TIMESTAMP: 2026-03-03 13:58:09.864257
                STATUS: COMPLETED
           RETRY_COUNT: 0
            TASK_COUNT: 1
    SUCCESS_TASK_COUNT: 1
                RESULT: 0
           DESCRIPTION:
               COMMENT: all archive pieces are not support for backup validate or not find any piece
   1 row in set
   ```

   クエリ結果は、テナントIDが1002のユーザーテナントのジョブレベル検証タスクの実行結果を表示しています。ここで、`job_id` は2、このジョブを開始したテナントは現在のテナントです（`INITIATOR_TENANT_ID` が1002）、検証タスクを実行するユーザーテナントも現在のテナントです（`EXECUTOR_TENANT_ID` は空）、検証対象はバックアップパスおよびアーカイブパス配下のすべてのバックアップセットとログアーカイブピースです（`TYPE` が `DATABASE`）、かつ指定パス以外の検証です（`PATH`、`PATH_TYPE`、`ID` などすべて空）、検証レベルはBasicレベル検証です（`VALIDATE_LEVEL` が `basic`）、検証タスクは完了しています（`STATUS` が `COMPLETED`）、検証結果は `all archive pieces are not support for backup validate or not find any piece` です。

3. タスクレベルのバックアップ検証タスク、すなわちバックアップセットまたはログアーカイブピースのバックアップ検証結果を確認します。

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_TASK_HISTORY\G
   ```

   クエリ結果は次のとおりです：

   ```shell
   *************************** 1. row ***************************
           TENANT_ID: 1002
             TASK_ID: 3
         INCARNATION: 1
              JOB_ID: 2
           TASK_TYPE: BACKUPSET
                  ID: 1
                PATH: file:///data/nfs/backup/data/backup_set_1_full
           PATH_TYPE: BACKUP_SET_DEST
             DEST_ID: 1002
     PLUS_ARCHIVELOG: OFF
   INITIATOR_TASK_ID: 0
      VALIDATE_LEVEL: basic
            ROUND_ID: 0
     START_TIMESTAMP: 2026-03-03 13:58:07.802366
       END_TIMESTAMP: 2026-03-03 13:58:09.860637
              STATUS: COMPLETED
      TOTAL_LS_COUNT: 2
     FINISH_LS_COUNT: 2
         TOTAL_BYTES: 21126037
     VALIDATED_BYTES: 0
              RESULT: 0
             COMMENT:
   1 row in set
   ```

   クエリ結果は、テナントIDが1002のユーザーテナントのタスクレベル検証タスクの実行結果を表示しています。ここで、`task_id` は3、対応する `job_id` は2、検証対象は `backup_set_id` が1のバックアップセットです（`TASK_TYPE` が `BACKUPSET`、`ID` が 1）；バックアップセットのパスは `file:///data/nfs/backup/data/backup_set_1_full`、バックアップパスのIDは1002（`DEST_ID` が1002）、このバックアップセットは補償ログではありません（`PLUS_ARCHIVELOG` が `OFF`）、検証レベルはBasicレベル検証です（`VALIDATE_LEVEL` が `basic`）、検証タスクは完了しています（`STATUS` が `COMPLETED`）。

## ユーザーテナントにおける自身のテナント内のバックアップ検証タスクの確認

ユーザーテナントは、ビュー `DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` と `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` を使用して、各ユーザーテナント内のすべての検証タスクの実行結果を確認できます。

ここで：

* ビュー `DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` では、各Jobが1つの検証指示に対応します。

* ビュー `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` では、各Taskが1つのバックアップセット（backup_set）またはログアーカイブピース（archive_piece）の検証タスクに対応します。

ユーザーテナントでバックアップ検証結果を確認する操作は以下のとおりです：

1. ユーザーテナントのテナント管理者がデータベースにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLテナントの管理者ユーザーは <code>root</code> ユーザー、Oracleテナントの管理者ユーザーは <code>SYS</code> ユーザーです。</p>
   </main>

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. Jobレベルの検証タスクの実行結果を確認します。

   :::tab
   tab MySQLモード

   MySQLモードでのクエリステートメントは以下のとおりです：

   ```shell
   obclient(root@mysqltenant)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY;
   ```

   tab Oracleモード

   Oracleモードでのクエリステートメントは以下のとおりです：

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY;
   ```

   :::

   クエリ結果の例は以下のとおりです：

   ```shell

           DESCRIPTION:

   1 row in set
   ```

3. Taskレベルのバックアップ検証タスク、すなわちバックアップセットまたはログアーカイブピースのバックアップ検証結果を確認します。

   :::tab
   tab MySQLモード

   MySQLモードでのクエリステートメントは以下のとおりです：

   ```shell

   ```

   tab Oracleモード

