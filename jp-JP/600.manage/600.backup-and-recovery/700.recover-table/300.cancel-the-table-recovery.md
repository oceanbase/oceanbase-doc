# テーブルレベルリストアのキャンセル

指定したテーブルのリストアプロセス中に、`ALTER SYSTEM CANCEL RECOVER TABLE` ステートメントを使用してテーブルのリストアを停止できます。このステートメントは、対応するテナント内のすべてのテーブルレベルリストアタスクをキャンセルしますが、リストア前の準備時に作成されたリソースプールは解放しません。

## 操作手順

1. `root` ユーザーで、リストア対象のテーブルがあるテナントが属するクラスタの `sys` テナントにログインします。

2. 以下のコマンドを実行して、リストアを即座にキャンセルします。

   ```sql
   ALTER SYSTEM CANCEL RECOVER TABLE dest_tenant_name;
   ```

   このうち、`dest_tenant_name` にはリストア対象のテーブルがあるターゲットテナント名を入力する必要があります。

## 次のステップ

テーブルレベルリストアをキャンセルした後、再度テーブルレベルリストア操作を実行しない場合は、対象テナントが存在するクラスタで以下のコマンドを実行して、リストア前の準備時に作成されたリソースプールを手動で解放できます。

```sql
DROP RESOURCE POOL restore_pool;
```

このうち、`restore_pool` はリストア前の準備時にサポートテナントのために作成されたリソースプール名を表します。

リソースプールの削除に関する詳細な操作と説明については、[リソースプールの削除](../../200.tenant-management/600.common-tenant-operations/1500.resource-pool-management/600.delete-resource-pool.md)を参照してください。
