# テーブルレベル復元関連ビューの紹介

## CDB_OB_RECOVER_TABLE_JOBS

`CDB_OB_RECOVER_TABLE_JOB`/`DBA_OB_RECOVER_TABLE_JOBS`は、テーブルレベルのリストアタスクのジョブレコードを表示するために使用されます。

|  フィールド                  |  説明                                          |
|-----------------------|------------------------------------------------|
| TENANT_ID             | 現在リストアタスクを実行しているテナントのID                      |
| JOB_ID                | タスクのJOB_ID                                   |
| INITIATOR_TENANT_ID   | ソーステナントを識別するためのテナントID                           |
| INITIATOR_JOB_ID      | 親タスクを識別するためのJOB_ID                          |
| START_TIMESTAMP       | タスクの開始時間、単位はマイクロ秒                        |
| FINISH_TIMESTAMP      | タスクの完了時間、単位はマイクロ秒                        |
| STATUS                | リストアタスクの状態：<ul><li>`PREPARE`：タスクの初期化段階</li> <li>`RECOVERING`：ターゲットテナントのリストア完了を待機中。この状態は`sys`テナントでのみ表示されます</li> <li>`RESTORE_AUX_TENANT`：リストア補助テナント</li> <li>`PRECHECK_IMPORT`：インポート前チェック</li> <li>`GEN_IMPORT_JOB`：インポートタスクの初期化</li> <li>`IMPORTING`：テーブルのインポート中</li> <li>`CANCELING`：タスクのキャンセル中</li> <li>`COMPLETED`：タスク完了</li> <li>`FAILED`：タスク失敗</li></ul>          |
| AUX_TENANT_NAME       | 補助テナント名                                      |
| TARGET_TENANT_NAME    | ターゲットテナント名                               |
| IMPORT_ALL            | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが復元対象のテーブルを`*.*`と指定した場合、このフィールドの値は`1`となり、その他の場合は`0`となります。  |
| DB_LIST               | 完全にリストアするデータベース                             |
| TABLE_LIST            | リストアするテーブル                                    |
| RESTORE_SCN           | リストアするパーティション                                  |
| RESTORE_SCN_DISPLAY   | タイムスタンプを使用して、ユーザーが指定した復元ポイントを表示   |
| RESTORE_OPTION        | 補助テナントが依存する`restore_option`パラメータの情報         |
| BACKUP_DEST           | バックアップパスとアーカイブパス                               |
| BACKUP_SET_LIST       | データバックアップパス                                     |
| BACKUP_PIECE_LIST     | ログアーカイブパス                                     |
| BACKUP_PASSWD         | バックアップセットのパスワード                                       |
| EXTERNAL_KMS_INFO     | リストアコマンド実行時に指定された秘密鍵バックアップ情報                   |
| REMAP_DB_LIST         | 重命名予定のデータベース。形式は次のとおりです：`db1:new_db1,db2:newdb2`。ここで、`db1` と `db2` は元のデータベース名です     |
| REMAP_TABLE_LIST      | 重命名予定のテーブル。形式は次のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2`。ここで、`t1` と `t2` は元のテーブル名です        |
| REMAP_TABLEGROUP_LIST | テーブルグループのリマッピングリスト。テーブルを元のテーブルグループからターゲットテーブルグループに再マッピングできます。形式は次のとおりです：`tg1:new_tg1, tg2:new_tg2`。ここで、`tg1` と `tg2` は元のテーブルグループ名です    |
| REMAP_TABLESPACE_LIST | テーブルスペースのリマッピングリスト。テーブルを元のテーブルスペースからターゲットテーブルスペースに再マッピングできます。形式は次のとおりです：`ts1:new_ts1, ts2:new_ts2`。ここで、`ts1` と `ts2` は元のテーブルスペース名です    |
| RESULT                | タスク完了の結果：<ul><li>`SUCCESS`：タスク実行成功</li><li>`FAIL`：タスク実行失敗</li></ul>      |
| COMMENT               | タスク実行失敗後の、タスク関連のエラー情報                |
| DESCRIPTION           | リストアコマンド実行時に指定された `DESCRIPTION` 情報                                   |

|  フィールド                  |  説明                                  |
|-----------------------|----------------------------------------|
| TENANT_ID             | 現在のタスクを実行しているテナントのID                 |
| JOB_ID                | 現在のタスクのJOB_ID                          |
| INITIATOR_TENANT_ID   | 親タスクを実行するテナントIDを識別するために使用されます   |
| INITIATOR_JOB_ID      | 親タスクを識別するためのJOB_ID      |
| START_TIMESTAMP       | タスクの開始時間、単位はマイクロ秒      |
| FINISH_TIMESTAMP      | タスクの完了時間、単位はマイクロ秒    |
| SRC_TENANT_NAME       | ソーステナントのテナント名     |
| SRC_TENANT_ID         | ソーステナントのテナントID       |
| STATUS                | タスクの状態：<ul><li>`INIT`：タスクの初期化</li> <li>`IMPORT_TABLE`：テーブルのインポート</li> <li>`RECONSTRUCT_REF_CONSTRAINT`：参照制約の再構築</li> <li>`CANCELING`：インポートタスクのキャンセル中</li> <li>`IMPORT_FINISH`：インポート終了</li></ul>      |
| IMPORT_ALL            | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが復元対象のテーブルを`*.*`と指定した場合、このフィールドの値は`1`となり、その他の場合は`0`となります。     |
| DB_LIST               | インポートするデータベース                      |
| TABLE_LIST            | インポートするテーブル                             |
| REMAP_DB_LIST         | リマッピング対象のデータベースリスト。形式は以下のとおりです：`db1:new_db1,db2:newdb2`。ここで、`db1` と `db2` は元のデータベース名です     |
| REMAP_TABLE_LIST      | 名前を変更するテーブル。形式は以下のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2`。ここで、`t1` と `t2` は元のテーブル名です        |
| REMAP_TABLEGROUP_LIST | リマッピング対象のテーブルグループのリスト。テーブルを元のテーブルグループからターゲットテーブルグループに再マッピングできます。形式は以下のとおりです：`tg1:new_tg1, tg2:new_tg2`。ここで、`tg1` と `tg2` は元のテーブルグループ名です    |
| REMAP_TABLESPACE_LIST | リマッピング対象のテーブルスペースのリスト。テーブルを元のテーブルスペースからターゲットテーブルスペースに再マッピングできます。形式は以下のとおりです：`ts1:new_ts1, ts2:new_ts2`。ここで、`ts1` と `ts2` は元のテーブルスペース名です    |
| TOTAL_TABLE_COUNT     | インポートするテーブルの合計数      |
| FINISHED_TABLE_COUNT  | インポートが完了したテーブル数     |
| FAILED_TABLE_COUNT    | インポートに失敗したテーブル数       |
| RESULT                | インポートタスクの実行結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行されました</li><li>`FAIL`：インポートタスクが失敗しました</li></ul>      |
| COMMENT               | タスクの実行が失敗した場合の、タスク関連のエラー情報                |
| DESCRIPTION           | リカバリコマンドを実行する際に指定した `DESCRIPTION` 情報                                  |
