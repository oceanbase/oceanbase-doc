# テーブルレベル復元関連ビューの紹介

## CDB_OB_RECOVER_TABLE_JOBS

`CDB_OB_RECOVER_TABLE_JOB`/`DBA_OB_RECOVER_TABLE_JOBS`は、テーブルレベルの復元タスクの実行履歴を表示するために使用されます。

|  フィールド                  |  説明                                          |
|-----------------------|------------------------------------------------|
| TENANT_ID             | 現在復元タスクを実行しているテナントのID                      |
| JOB_ID                | タスクのJOB_ID                                   |
| INITIATOR_TENANT_ID   | ソーステナントを識別するために使用されるテナントID                           |
| INITIATOR_JOB_ID      | 親タスクを識別するために使用されるJOB_ID                          |
| START_TIMESTAMP       | タスクの開始時間、単位はマイクロ秒                        |
| FINISH_TIMESTAMP      | タスクの完了時間、単位はマイクロ秒                        |
| STATUS                | 復元タスクの状態：<ul><li>`PREPARE`：タスク初期化段階</li> <li>`RECOVERING`：ターゲットテナントの復元完了を待機中。この状態は`sys`テナントでのみ表示されます</li> <li>`RESTORE_AUX_TENANT`：復元補助テナント</li> <li>`PRECHECK_IMPORT`：インポート前チェック</li> <li>`GEN_IMPORT_JOB`：インポートタスク初期化</li> <li>`IMPORTING`：テーブルインポート中</li> <li>`CANCELING`：タスクキャンセル中</li> <li>`COMPLETED`：タスク完了</li> <li>`FAILED`：タスク失敗</li></ul>          |
| AUX_TENANT_NAME       | 補助テナント名                                      |
| TARGET_TENANT_NAME    | ターゲットテナント名                               |
| IMPORT_ALL            | テナント内のすべてのテーブルをインポートするかどうか。ユーザーが復元対象のテーブルを`*.*`と指定した場合、このフィールドの値は`1`となり、その他の場合は`0`となります。  |
| DB_LIST               | 完全に復元するデータベース                             |
| TABLE_LIST            | 復元するテーブル                                    |
| RESTORE_SCN           | 復元するパーティション                                  |
| RESTORE_SCN_DISPLAY   | タイムスタンプを使用してユーザーが指定した復元ポイントを表示   |
| RESTORE_OPTION        | 補助テナントが依存する`restore_option`パラメータの情報         |
| BACKUP_DEST           | バックアップパスとアーカイブパス                               |
| BACKUP_SET_LIST       | データバックアップパス                                     |
| BACKUP_PIECE_LIST     | ログアーカイブパス                                     |
| BACKUP_PASSWD         | バックアップセットのパスワード                                       |
| EXTERNAL_KMS_INFO     | 復元コマンド実行時に指定された秘密鍵のバックアップ情報                   |
| REMAP_DB_LIST         | 重命名対象のデータベース。形式は次のとおりです：`db1:new_db1,db2:newdb2`。ここで、`db1`と`db2`は元のデータベース名です     |
| REMAP_TABLE_LIST      | 重命名対象のテーブル。形式は次のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2`。ここで、`t1`と`t2`は元のテーブル名です        |
| REMAP_TABLEGROUP_LIST | リマップされるテーブルグループのリスト。テーブルを元のテーブルグループからターゲットのテーブルグループに再マッピングできます。形式は次のとおりです：`tg1:new_tg1, tg2:new_tg2` ここで、`tg1` と `tg2` は元のテーブルグループ名です    |
| REMAP_TABLESPACE_LIST | リマップされるテーブルスペースのリスト。テーブルを元のテーブルスペースからターゲットのテーブルスペースに再マッピングできます。形式は次のとおりです：`ts1:new_ts1, ts2:new_ts2` ここで、`ts1` と `ts2` は元のテーブルスペース名です    |
| RESULT                | タスク完了の結果：<ul><li>`SUCCESS`：タスクが正常に実行されました</li><li>`FAIL`：タスクの実行に失敗しました</li></ul>      |
| COMMENT               | タスクの実行に失敗した場合の、タスク関連のエラー情報                |
| DESCRIPTION           | リカバリコマンドを実行する際に指定した `DESCRIPTION` 情報                                   |

## CDB_OB_IMPORT_TABLE_JOBS

`CDB_OB_IMPORT_TABLE_JOBS`/`DBA_OB_IMPORT_TABLE_JOBS`は、テナントレベルのインポートタスクのレコードを表示します。これはテーブルレベル復元タスクのサブタスクです。

|  フィールド                  |  説明                                  |
|-----------------------|----------------------------------------|
| TENANT_ID             | 現在のタスクを実行しているテナントのID                 |
| JOB_ID                | 現在のタスクのJOB_ID                          |
| INITIATOR_TENANT_ID   | 親タスクを実行したテナントIDを識別するために使用されます   |
| INITIATOR_JOB_ID      | 親タスクのJOB_IDを識別するために使用されます      |
| START_TIMESTAMP       | タスクの開始時間、単位はマイクロ秒      |
| FINISH_TIMESTAMP      | タスクの終了時間、単位はマイクロ秒    |
| SRC_TENANT_NAME       | ソーステナントのテナント名     |
| SRC_TENANT_ID         | ソーステナントのテナントID       |
| STATUS                | タスクの状態：<ul><li>`INIT`：タスクの初期化</li> <li>`IMPORT_TABLE`：テーブルのインポート</li> <li>`RECONSTRUCT_REF_CONSTRAINT`：参照制約の再構築</li> <li>`CANCELING`：インポートタスクがキャンセル中</li> <li>`IMPORT_FINISH`：インポート終了</li></ul>      |
| IMPORT_ALL            | テナント内のすべてのテーブルをインポートするかどうかを示します。復元対象のテーブルを`*.*`と指定した場合、このフィールドの値は`1`になります。その他の場合は`0`になります。     |
| DB_LIST               | インポートするデータベース                      |
| TABLE_LIST            | インポートするテーブル                             |
| REMAP_DB_LIST         | リマッピングするデータベースのリストです。形式は次のとおりです：`db1:new_db1,db2:newdb2`。ここで、`db1` と `db2` は元のデータベース名です     |
| REMAP_TABLE_LIST      | 名前を変更するテーブルです。形式は次のとおりです：`db1.t1:new_t1, db1.t2:db2.new_t2`。ここで、`t1` と `t2` は元のテーブル名です        |
| REMAP_TABLEGROUP_LIST | リマッピングするテーブルグループのリストです。テーブルを元のテーブルグループからターゲットのテーブルグループに再マッピングできます。形式は次のとおりです：`tg1:new_tg1, tg2:new_tg2`。ここで、`tg1` と `tg2` は元のテーブルグループ名です    |
| REMAP_TABLESPACE_LIST | リマッピングするテーブルスペースのリストです。テーブルを元のテーブルスペースからターゲットのテーブルスペースに再マッピングできます。形式は次のとおりです：`ts1:new_ts1, ts2:new_ts2`。ここで、`ts1` と `ts2` は元のテーブルスペース名です    |
| TOTAL_TABLE_COUNT     | インポートするテーブルの合計数      |
| FINISHED_TABLE_COUNT  | インポートが完了したテーブルの数     |
| FAILED_TABLE_COUNT    | インポートに失敗したテーブルの数       |
| RESULT                | インポートタスクの結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行されました</li><li>`FAIL`：インポートタスクが失敗しました</li></ul>      |
| COMMENT               | タスクの実行が失敗した場合の、タスク関連のエラー情報                |

| SRC_TABLE                     | ソーステーブル名    |
| SRC_PARTITION                 | ソーステーブルのパーティション名  |

| COMPLETION_TIMESTAMP          | タスクの完了時間、単位はマイクロ秒       |
| CUMULATIVE_TS                 | 累計時間、単位はマイクロ秒     |
| TOTAL_INDEX_COUNT             | テーブル内のインデックスの総数     |
| IMPORTED_INDEX_COUNT          | インポート済みのインデックス数    |
| FAILED_INDEX_COUNT            | インポート失敗したインデックス数      |
| TOTAL_CONSTRAINT_COUNT        | テーブル内の制約の総数     |
| IMPORTED_CONSTRAINT_COUNT     | インポート済みの制約数     |
| FAILED_CONSTRAINT_COUNT       | インポート失敗した制約数    |
| TOTAL_REF_CONSTRAINT_COUNT    | テーブル内の参照制約の総数     |
| IMPORTED_REF_CONSTRAINT_COUNT | インポート済みの参照制約数     |
| FAILED_REF_CONSTRAINT_COUNT   | インポート失敗した参照制約数    |
| RESULT                        | タスク完了の結果：<ul><li>`SUCCESS`：インポートタスクが正常に実行された</li><li>`FAIL`：インポートタスクの実行に失敗しました</li></ul>      |
