# オブジェクトストレージのキー情報を更新する

OceanBaseデータベースは、バックアップパスまたはアーカイブパスの`access_id`や`access_key`などの情報を動的に更新することをサポートしています。ユーザーがバックアップパスやアーカイブパスを設定した後、セキュリティ上の理由やその他の理由でオブジェクトストレージのキー情報を変更した場合、バックアップやアーカイブの正常な実行を保証するために、この方法で既に設定されているバックアップパスまたはアーカイブパスの`access_id`と`access_key`を変更できます。

## 使用制限

* オブジェクトストレージパスの`access_id`と`access_key`情報の変更のみをサポートします。

* ユーザーテナントは自身のテナントのバックアップパスまたはアーカイブパスのキー情報の変更のみをサポートし、システムテナントが指定されたユーザーテナントのバックアップパスまたはアーカイブパスのキー情報を変更することはサポートしません。

## 注意事項

* バックアップまたはアーカイブ中にオブジェクトストレージパスに対応するキー情報を変更した後、直ちにバックアップパスまたはアーカイブパスの`access_id`と`access_key`情報を変更する必要があります。そうでない場合、バックアップタスクの実行失敗やアーカイブの進行不能などの問題が発生する可能性があります。

* ログアーカイブを利用する物理スタンバイデータベースのシナリオでは、オブジェクトストレージパスに対応するキー情報を変更した後、速やかにスタンバイデータベース（スタンバイテナント）のログ復元パス内の`access_id`と`access_key`情報を更新する必要があります。そうでない場合、ログ同期が進行不能になる可能性があります。スタンバイデータベース（スタンバイテナント）のログ復元パス内の`access_id`と`access_key`情報を更新する詳細な操作については、[ログ復元ソースの設定](../400.high-availability/300.physical-standby-database-disaster-recovery/300.log-transport-service/200.configure-the-log-transport-service/100.set-log-restore-source.md)を参照してください。

## 手順

1. ユーザーテナントのテナント管理者がクラスタのユーザーテナントにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードの管理者ユーザーは<code>root</code>ユーザー、Oracleモードの管理者ユーザーは<code>SYS</code>ユーザーです。</p>
   </main>

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のステートメントを実行して、バックアップパスまたはアーカイブパスのキー情報を変更します。

   SQLステートメントは以下のとおりです：

   ```sql
   ALTER SYSTEM {ALTER|CHANGE|MODIFY} EXTERNAL_STORAGE_DEST PATH [=] 'path' SET ACCESS_INFO = 'access_id=new_access_id&access_key=new_access_key';
   ```

   関連パラメータの説明は以下のとおりです：

   * `path`：キー情報を変更する対象のバックアップパスまたはアーカイブパスを指定します。パスは現在のテナントで既に設定されているバックアップパスまたはアーカイブパスである必要があり、オブジェクトストレージパスである必要があります。また、パスには`host`情報を含める必要があります。

     OSSを例にすると、このパスの形式は次のとおりです：`oss://oceanbase-test-bucket/backup/data?host=***`。

   * `access_id=new_access_id&access_key=new_access_key`：変更後の新しい`access_id`と`access_key`情報を指定します。`access_id`と`access_key`は両方とも入力する必要があります。

   バックアップまたはアーカイブメディアをOSSとする例を挙げると、現在のユーザーテナントがバックアップ時に設定したバックアップパスが `oss://oceanbase-test-bucket/backup/data?host=cn-****.aliyuncs.com`、アーカイブパスが `oss://oceanbase-test-bucket/backup/archive?host=cn-****.aliyuncs.com` の場合、それぞれのパスのキー情報を変更する例を以下に示します。

   * バックアップパスのキー情報を変更する

      ```shell
      obclient> ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST PATH='oss://oceanbase-test-bucket/backup/data?host=cn-****.aliyuncs.com' SET ACCESS_INFO = 'access_id=******&access_key=******';
      ```

   * アーカイブパスのキー情報を変更する

      ```shell
      obclient> ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST PATH='oss://oceanbase-test-bucket/backup/archive?host=cn-****.aliyuncs.com' SET ACCESS_INFO = 'access_id=******&access_key=******';
      ```

    詳細な例については、[ALTER/CHANGE/MODIFY EXTERNAL_STORAGE_DEST](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1430.alter-system-change-external-storage-dest-of-mysql-mode.md)を参照してください。

3. 変更が成功した後、ビュー `DBA_OB_BACKUP_STORAGE_INFO` をクエリして確認できます。

   :::tab
   tab MySQLモード

   * バックアップパスの `access_id` と `access_key` 情報を確認する

      ```shell
      obclient[oceanbase]> SELECT AUTHORIZATION FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/data' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```

   * アーカイブパスの `access_id` と `access_key` 情報を確認する

      ```shell
      obclient[oceanbase]> SELECT AUTHORIZATION FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/archive' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```

   tab Oracleモード

   * バックアップパスの `access_id` と `access_key` 情報を確認する

      ```shell
      obclient[SYS]> SELECT AUTHORIZATION FROM SYS.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/data' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```

   * アーカイブパスの `access_id` と `access_key` 情報を確認する

      ```shell
      obclient[SYS]> SELECT AUTHORIZATION FROM SYS.DBA_OB_BACKUP_STORAGE_INFO WHERE PATH='oss://oceanbase-test-bucket/backup/archive' AND ENDPOINT = 'host=cn-****.aliyuncs.com';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +-------------------------------------+
      | AUTHORIZATION                       |
      +-------------------------------------+
      | access_id=******&encrypt_key=****** |
      +-------------------------------------+
      1 row in set
      ```
