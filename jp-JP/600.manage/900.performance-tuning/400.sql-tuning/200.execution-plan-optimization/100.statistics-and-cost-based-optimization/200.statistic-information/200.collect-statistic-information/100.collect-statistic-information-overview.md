# 統計情報収集の概要

OceanBase データベース V4.0 では、現在の統計情報収集は主に手動統計情報収集と自動統計情報収集の 2 種類に依存しています。

なお、現在のところ日次マージでは統計情報は収集されません。また、特に断りのない限り、統計情報収集の仕様は OceanBase データベースの MySQL モードと Oracle モードで同じであり、モードを問わず適用されます。これにより、ユーザーの学習コストを削減することができます。
