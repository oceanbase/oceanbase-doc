# 管理統計情報の概要

`DBMS_STATS`システムパッケージは、統計情報収集機能に加えて、統計情報管理機能も提供します。OceanBaseデータベースのオプティマイザーは、ネイティブOracleの`DBMS_STATS`パッケージに基づく統計情報管理機能を備えており、同様にOceanBaseデータベースのOracleモードおよびMySQLモードでも豊富な統計情報管理機能を提供しています（特に明記がない限り、両モードでの使用方法は同一です）。OceanBaseデータベースはV4.0バージョンから、オプティマイザーが主に統計情報の削除、統計情報の設定、統計情報のインポート・エクスポート、統計情報のロック、統計情報の履歴バージョン管理、および統計情報収集ポリシーのPrefs設定などの機能を提供しています。
