# オプティマイザーの行数推定メカニズム

前の章では、基本的な統計情報の収集や管理機能について説明しました。これらの統計情報はすべて、実行計画を生成する際に正確な行数推定を行うために利用されます。OceanBaseデータベースのオプティマイザーでは、現在、2種類の行数推定方法があります。1つは選択率に基づく行数推定であり、もう1つはストレージ層に基づく行数推定です。
