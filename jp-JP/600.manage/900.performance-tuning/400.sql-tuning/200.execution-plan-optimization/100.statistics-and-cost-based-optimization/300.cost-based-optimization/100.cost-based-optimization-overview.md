# オプティマイザーの行数推定メカニズム

前章では、基本的な統計情報の収集および管理機能について説明しました。これらの統計情報はすべて、計画生成時に正確な行数の推定を行うために利用されます。OceanBaseデータベースのオプティマイザーでは現在、2種類の行数推定方法があります。一つは選択率に基づく行数推定であり、もう一つはストレージ層に基づく行数推定です。
