# その他のハードウェアおよびネットワーク関連の問題

このセクションでは、ノードのダウン、ネットワークジッター、obproxyの障害以外に考えられるその他のハードウェアおよびネットワーク関連の異常問題について説明し、それぞれの緊急対応策を提案します。

## 緊急時の対処方法

一般的なノードのダウン、ネットワークジッター、obproxyの障害に加えて、ディスクI/O異常、ディスク損傷、NIC異常、ノードCPU/メモリ異常など、他にもさまざまなハードウェア異常があります。これらのハードウェア異常は通常、RTの増加やトランザクションのコミット不能などの影響を引き起こします。

不明なハードウェア問題が疑われる場合は、まず`stop server`を実行することができます。stop serverは無損失の安全な操作であり、最初の段階で障害を隔離するための最も効果的な手段です。ただし、この操作はクライアントが該当ノードにアクセスした際にエラーが発生するため、シナリオが許す限り、まず`isolate server`操作を実行してください。具体的な例は以下のとおりです：

```sql
ALTER SYSTEM ISOLATE SERVER 'xxx.xxx.xxx.xxx:2882';
ALTER SYSTEM  STOP SERVER 'xxx.xxx.xxx.xxx:2882';
```

ハードウェア異常によって明確にデータベースの問題が発生している場合は、障害機器を直接交換するだけで済みます。
