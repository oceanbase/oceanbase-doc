# ゾーンの追加

ゾーンの追加は、通常クラスタの拡張シナリオで使用されます。

## 手順

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

   データベースへの接続方法の詳細については、[データベース接続の概要(MySQLモード)](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/100.connection-methods-overview-of-mysql-mode.md)および[データベース接続の概要(Oracleモード)](../../../300.develop/200.application-development-of-oracle-mode/100.connect-to-oceanbase-database-of-oracle-mode/100.connection-methods-overview-of-oracle-mode.md)を参照してください。

2. 以下のコマンドを実行して、クラスタにZoneを追加します。

   ステートメントは次のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM ADD ZONE zone_name [IDC [=] 'idc_name', REGION [=] 'region_name', ZONE_TYPE [=] 'ReadWrite'];
   ```

   関連パラメータの説明は以下のとおりです：

   * `zone_name`：追加するZoneの名前。各ステートメントでは一度に1つのZoneのみを追加できます。複数のZoneを追加する必要がある場合は、このステートメントを繰り返し実行する必要があります。

   * `idc_name`：Zoneが配置されるデータセンターの名前。指定しない場合、デフォルトは空です。

   * `region_name`：Zoneが配置されるリージョンの名前。指定しない場合、デフォルト値は`default_region`です。

   * `ZONE_TYPE`：Zoneのタイプを指定します。現在のバージョンでは、読み書き可能なZone(`ReadWrite`)のみサポートされています。指定しない場合、デフォルトは読み書き可能なZoneです。

   クラスタに`zone4`を追加する例は次のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM ADD ZONE zone4 IDC 'hz1', REGION 'hangzhou';
   ```

3. 操作が成功したら、`oceanbase.DBA_OB_ZONES`ビューを照会して確認できます。

   ```shell
   obclient [(none)]> SELECT * FROM oceanbase.DBA_OB_ZONES;
   +-------+----------------------------+----------------------------+----------+-----+----------+-----------+
   | ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS   | IDC | REGION   | TYPE      |
   +-------+----------------------------+----------------------------+----------+-----+----------+-----------+
   | zone1 | 2022-12-20 17:50:17.168745 | 2022-12-20 17:50:40.801054 | ACTIVE   | HZ0 | hangzhou | ReadWrite |
   | zone2 | 2022-12-20 17:50:17.168745 | 2022-12-20 17:50:40.809504 | ACTIVE   | HZ0 | hangzhou | ReadWrite |
   | zone3 | 2022-12-20 17:50:17.169804 | 2022-12-20 17:50:40.815833 | ACTIVE   | SH0 | shanghai | ReadWrite |
   | zone4 | 2023-01-06 14:57:18.775946 | 2023-01-06 14:57:18.776974 | INACTIVE | hz1 | hangzhou | ReadWrite |
   +-------+----------------------------+----------------------------+----------+-----+----------+-----------+
   4 rows in set
   ```

   クエリ結果に新しく追加されたZoneがある場合、Zoneの追加は成功したことを意味します。新しく追加されたZoneのステータスは`INACTIVE`です。

   `DBA_OB_ZONES`ビューの詳細については、[oceanbase.DBA_OB_ZONES](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23300.o-dba_ob_zones-of-sys-tenant.md)を参照してください。

4. Zoneを追加した後、そのZoneを使用する場合は、Zoneを起動してステータスを`ACTIVE`に変更する必要があります。

   ステートメントは次のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM START ZONE zone_name;
   ```

   ここで、`zone_name`は起動するZoneの名前です。

   例：

   ```shell
   obclient [(none)]> ALTER SYSTEM START ZONE zone4;
   Query OK, 0 rows affected

   obclient [(none)]> SELECT * FROM oceanbase.DBA_OB_ZONES;
   +-------+----------------------------+----------------------------+--------+-----+----------+-----------+
   | ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC | REGION   | TYPE      |
   +-------+----------------------------+----------------------------+--------+-----+----------+-----------+
   | zone1 | 2022-12-20 17:50:17.168745 | 2022-12-20 17:50:40.801054 | ACTIVE | HZ0 | hangzhou | ReadWrite |
   | zone2 | 2022-12-20 17:50:17.168745 | 2022-12-20 17:50:40.809504 | ACTIVE | HZ0 | hangzhou | ReadWrite |
   | zone3 | 2022-12-20 17:50:17.169804 | 2023-01-30 17:34:11.228474 | ACTIVE | HZ1 | hangzhou | ReadWrite |
   | zone4 | 2023-01-06 15:30:30.887362 | 2023-01-31 13:47:56.107429 | ACTIVE | hz1 | hangzhou | ReadWrite |
   +-------+----------------------------+----------------------------+--------+-----+----------+-----------+
   4 rows in set
   ```

   例の結果からわかるように、Zoneの起動に成功すると、新しく追加されたZoneのステータスは`ACTIVE`に変更されます。

## 次のステップ

* Zoneを追加した後、そのZoneが属する`idc_name`または`region_name`を変更する必要がある場合は、Zoneを変更することで対応できます。Zoneの変更手順の詳細については、[Zoneの変更](../300.common-cluster-operations/1000.modify-a-zone.md)を参照してください。

* Zoneを追加した後、そのZoneを使用するには、まずそのZoneにノードを追加する必要があります。ノードの追加手順の詳細については、[ノードの追加](../300.common-cluster-operations/400.add-a-node.md)を参照してください。
