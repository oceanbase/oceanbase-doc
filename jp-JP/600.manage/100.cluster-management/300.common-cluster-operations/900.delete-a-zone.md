# Zoneの削除

Zoneの削除は、通常、クラスタのスケールインのシナリオで使用されます。

## 前提条件

Zoneを削除する前に、以下の事項を確認してください：

* そのZoneにノードが存在しないことを確認してください。Zone内のノードに関する操作については、[ノードの表示](../300.common-cluster-operations/200.view-an-observer.md)を参照してください。

* そのZoneが停止していることを確認してください。

  Zoneを停止するステートメントは以下のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM STOP ZONE zone_name;
   ```

   ここで、`zone_name` は停止対象のZoneの名前です。各ステートメントは、1回につき1つのZoneのみを停止できます。

   例：

   ```shell
   obclient [(none)]> ALTER SYSTEM STOP ZONE zone4;
   ```

## 手順

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

   より詳細なデータベース接続操作の手順については、[データベース接続の概要（MySQLモード）](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/100.connection-methods-overview-of-mysql-mode.md)および[データベース接続の概要（Oracleモード）](../../../300.develop/200.application-development-of-oracle-mode/100.connect-to-oceanbase-database-of-oracle-mode/100.connection-methods-overview-of-oracle-mode.md)を参照してください。

2. 以下のコマンドを実行し、クラスタ内のゾーンを削除します。

   ステートメントは以下のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM DELETE ZONE zone_name;
   ```

   ここで、`zone_name`は削除するゾーンの名前を表します。各ステートメントは1回につき1つのゾーンのみの削除をサポートします。複数のゾーンを削除する必要がある場合は、このステートメントを繰り返し実行する必要があります。

   クラスタ内の`zone4`を削除する例は以下のとおりです：

   ```shell
   obclient [(none)]> ALTER SYSTEM DELETE ZONE zone4;
   ```

3. 操作が成功した後、`oceanbase.DBA_OB_ZONES`ビューを確認することができます。

   ```shell
   obclient [(none)]> SELECT * FROM oceanbase.DBA_OB_ZONES;
   +-------+----------------------------+----------------------------+--------+-----+----------+-----------+
   | ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC | REGION   | TYPE      |
   +-------+----------------------------+----------------------------+--------+-----+----------+-----------+
   | zone1 | 2022-12-20 17:50:17.168745 | 2022-12-20 17:50:40.801054 | ACTIVE | HZ0 | hangzhou | ReadWrite |
   | zone2 | 2022-12-20 17:50:17.168745 | 2022-12-20 17:50:40.809504 | ACTIVE | HZ0 | hangzhou | ReadWrite |
   | zone3 | 2022-12-20 17:50:17.169804 | 2022-12-20 17:50:40.815833 | ACTIVE | SH0 | shanghai | ReadWrite |
   +-------+----------------------------+----------------------------+--------+-----+----------+-----------+
   3 rows in set
   ```

   クエリ結果にそのゾーンが表示されない場合、ゾーンの削除は成功したことを意味します。

   `oceanbase.DBA_OB_ZONES`ビューの詳細については、[oceanbase.DBA_OB_ZONES](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/24300.o-dba_ob_zones-of-sys-tenant.md)を参照してください。
