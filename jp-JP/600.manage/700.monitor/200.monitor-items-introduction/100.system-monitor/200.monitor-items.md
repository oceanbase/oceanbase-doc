# SYSSTATモニタリング項目

SYSSTATモニタリング項目は一般的な診断モニタリング情報の一つであり、SQL実行回数、実行時間、I/O回数など、システム稼働に関する重要なパフォーマンス数値を統計します。

## モニタリング項目の出典

モニタリング項目のデータは[[G]V$SYSSTAT](../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/5700.gv-sysstat-of-sys-tenant.md)ビューに格納されており、その主要なフィールドの説明は以下のとおりです。

| **フィールド名** | **説明**                                                    |
| ------------ | ----------------------------------------------------------- |
| CON_ID       | テナントID                                                     |
| SVR_IP       | ノードIP                                    |
| STAT_ID      | モニタリング項目ID                                                   |
| NAME         | モニタリング項目名                                                  |
| CLASS        | モニタリング項目の種類                                                  |
| VALUE        | モニタリング項目に対応する結果値                                        |
| VALUE_TYPE   | モニタリング項目値のタイプ：<ul><li>ADD：累積</li><li>SET：更新</li></ul> |

## モニタリング項目の種類

OceanBaseデータベースV4.xバージョンでサポートされているモニタリング項目は、15の大カテゴリに分けられます。詳細は以下のとおりです：

| モニタリング項目ID | モニタリング項目カテゴリ | モニタリング項目の説明 |
| ------------- | ---------- | -------------- |
| 1             | NETWORK    | ネットワーク           |
| 2             | QUEUE      | リクエストキュー       |
| 4             | TRANS      | トランザクション           |
| 8             | SQL        | SQL            |
| 16            | CACHE      | キャッシュ           |
| 32            | STORAGE    | ストレージ           |
| 64            | RESOURCE   | リソース           |
| 128           | DEBUG      | ログ           |
| 256           | CLOG       | CLOG           |
| 512           | ELECT      | 選挙           |
| 1024          | OBSERVER   | システム       |
| 2048          | RS         | Root Service   |
| 3072          | Time Model | 時間モデル           |
| 4096          | TABLEAPI   | TableAPI       |
| 8192          | WR         | WR           |

以下に、一般的なカテゴリのクエリと対応するモニタリング項目の説明をいくつか例示します。全モニタリング項目の内容については、[モニタリング項目一覧](../../../../700.reference/700.system-views/510.statistical-event-description.md)を参照してください。

### ネットワーク

以下の例を使用して、ネットワーク関連の監視メトリクスを照会できます。

```shell
obclient> select distinct class,stat_id,name,VALUE_TYPE from gv$sysstat where class=1 and stat_id in (10000,10001,10002,10003,10004,10005,10006);
```

実行結果は次のとおりです：

```shell
+-------+---------+----------------------+------------+
| class | stat_id | name                 | VALUE_TYPE |
+-------+---------+----------------------+------------+
|     1 |   10000 | rpc packet in        | ADD_VALUE  |
|     1 |   10001 | rpc packet in bytes  | ADD_VALUE  |
|     1 |   10002 | rpc packet out       | ADD_VALUE  |
|     1 |   10003 | rpc packet out bytes | ADD_VALUE  |
|     1 |   10004 | rpc deliver fail     | ADD_VALUE  |
|     1 |   10005 | rpc net delay        | ADD_VALUE  |
|     1 |   10006 | rpc net frame delay  | ADD_VALUE  |
+-------+---------+----------------------+------------+
7 rows in set (0.06 sec)
```

パラメータ説明：

| NAME                 | 説明                                                        |
| -------------------- | ----------------------------------------------------------- |
| rpc packet in        | テナントが受信した累計RPCパケット数。テナントがRPCリクエストを受信するか、RPCリクエストを送信した後に応答パケットを受信するたびに、カウントが1増加します。 |
| rpc packet in bytes  | テナントが受信した累計RPCパケットのバイト数（単位：Bytes）。テナントがRPCリクエストを受信するか、RPCを送信した後に応答パケットを受信するたびに、そのRPCリクエストまたは応答パケットのサイズを累積します。 |
| rpc packet out       | テナントが送信した累計RPCパケット数。テナントがRPCリクエストを送信するか、RPCリクエストを受信した後に応答パケットを送信するたびに、カウントが1増加します。 |
| rpc packet out bytes | テナントが送信した累計RPCパケットのバイト数（単位：Bytes）。テナントがRPCリクエストを送信するか、RPCリクエストを受信した後に応答パケットを送信するたびに、そのRPCリクエストまたは応答パケットのサイズを累積します。 |
| rpc deliver fail     | テナントのワーカースレッドキューへのRPCリクエスト転送の総失敗回数。RPC I/OがテナントキューへRPCリクエストを転送する際に転送に失敗した場合、カウントが1増加します。 |
| rpc net delay        | テナントで受信されたRPCリクエストの累計ネットワーク転送遅延（単位：マイクロ秒）。RPC I/OスレッドがRPCリクエストを解析した後、現在時刻を取得し、パケットヘッダーから取得した送信時刻スタンプから差を引いて差分を求め、それをRPC_NET_DELAYに累積します。 |
| rpc net frame delay  | テナントで受信されたRPCリクエストの累計ネットワークフレーム処理時間（単位：マイクロ秒）。RPC I/OがテナントキューへRPCリクエストを転送する際、現在時刻を取得し、RPCパケットを解析した際に記録した時刻スタンプから差を引いて差分を求め、それをRPC_NET_FRAME_DELAYに累積します。 |

以下の例を使用して、リクエストキュー関連の監視メトリクスを照会できます。

パラメータ説明：

| NAME                  | 説明                                                                                 |

## その他

`GV$SYSSTAT` ビュー以外にも、さまざまな観点からモニタリング項目を記述する豊富なビューがあります。

例えば、`GV$OB_PROCESSLIST` は、システム内の現在のセッション（アクティブ状態を含む）および実行中のSQL文を記述しています。また、`SID`、`SQL_ID`、`TRANS_ID`、`TRACE_ID` などの重要なフィールドも含まれており、エンドツーエンドのトレースに役立ちます。

* `GV$OB_PROCESSLIST` ビューに基づいてアクティブセッションをクエリする：

    ```shell
    obclient> select TENANT,SVR_IP,SVR_PORT,USER,HOST,COMMAND,STATE,INFO,SQL_ID,TRACE_ID
    from GV$OB_PROCESSLIST
    where STATE='ACTIVE' or null limit 10;
    ```

* `GV$OB_PROCESSLIST` ビューに基づいてUnit単位のアクティブセッション数をクエリする：

    ```shell
    obclient>
    select
    tenant_id, tenant_name,  svr_ip,
    case
        when cnt is null then 0
        else cnt end
    as cnt
    from (
        select DBA_OB_TENANTS.tenant_name, DBA_OB_TENANTS.tenant_id, svr_ip, cnt
        from DBA_OB_TENANTS
        left join (
            select count(`state`='ACTIVE' OR NULL) as cnt, tenant as tenant_name, svr_ip
            from GV$OB_PROCESSLIST
            group by tenant,svr_ip ) t1
    ```
