# フルトレース表示

フルトレース表示機能は、ユーザーが業務システムを簡単に管理および分析できるよう支援します。この機能により、JDBCまたはSQLインターフェースを使用して業務データベースに接続する際に、呼び出しリクエストに関連付けられたTrace IDを設定できます。このTrace IDはその後、OceanBaseデータベースのフルトレースシステムに記録され、ユーザーが後でシステム性能分析や障害調査を行いやすくなります。Show Traceコマンドを使用すると、Trace IDに関連する詳細情報を照会でき、システムの稼働状況をより明確に把握できます。

## OceanBase運用管理プラットフォーム(OCP)によるトレース情報の表示

OCPを使用すると、特定のリクエストを迅速に検索し、システムパフォーマンス分析や障害診断を実行できます。

### 位置特定分析

OCPは、時間消費量検索、Trace IDまたはSQL ID検索など、さまざまな検索軸をサポートしており、ユーザーが問題の所在を迅速に特定できるよう支援します。さらに、OCPは直感的なフルリンクトレース情報表示方式も提供しており、ユーザーはクライアントからデータベース内部の各段階に至るまでのリクエストの実行詳細を確認できます。

### 手順

OCPでは、以下の手順でリンク情報を照会できます。詳細については、[リンクの照会](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000002100810)を参照してください。

1. OCPにログインします。
2. 左側のナビゲーションバーで**システム管理 > ログサービス**を選択します。
3. **リンククエリ**タブをクリックして、**リンククエリ**画面に移動します。
4. **リンククエリ**画面でクエリ条件を設定することで、ターゲットTraceの特定を補助します。
5. **クエリ**ボタンをクリックします。カーソルをspanノードのタイムライン上に移動すると、ポップアップウィンドウにspanの詳細情報が表示されます。

## コマンドラインでトレース情報を表示する

OceanBaseデータベースのコマンドラインインターフェースでは、Show Trace機能を使用してSQL文の実行後に、実行プロセスの詳細な呼び出しチェーンと時間消費情報を迅速に取得することもできます。この方法により、パフォーマンスボトルネックを容易に特定し、さらなる分析やチューニングを行うことができます。

### ロケーション分析

ユーザーがコマンドラインで特定のステートメントを手動で実行した後、その実行プロセスに対するパフォーマンス分析やチューニングが必要な場合は、Show Trace機能を使用して、そのステートメントの実行呼び出しチェーンとチェーン内の各段階の時間消費状況を確認できます。この機能により、ユーザーはパフォーマンスのボトルネックポイントを容易に特定し、それに基づいて分析や最適化を行うことができます。

### 手順

以下の例は、2つの分散パラレル実行タスク（px_task）の実行状況を示しています。リンク関連のログ情報を表示するには、[Trace機能に基づいて前回のSQLリクエストログを検索する](https://www.oceanbase.com/docs/common-oceanbase-database-cn-10000000001702462)を参照してください。

1.  SQL Trace機能を有効にします。

    ```shell
    obclient [test]>SET ob_enable_show_trace = 1;
    ```

2.  クエリ対象のSQL文を手動で実行します。

    ```shell
    obclient [test]>select/*+parallel(2)*/ count(*) from t1;
    +----------+
    | count(*) |
    +----------+
    |        5 |
    +----------+
    1 row in set (0.005 sec)
    ```

3.  `SHOW TRACE` ステートメントを使用して、そのステートメントの実行呼び出しリンクとリンク内の各段階の時間消費状況を確認します。
