# ホスト情報の確認

本記事では、コマンドラインを使用してホストの状態を確認する方法について説明します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>本記事で説明するコマンドの出力は、システムの設定やバージョンによって若干異なる場合があります。</p>
</main>

## ホストのオンライン状態を確認する

以下のコマンドを使用して、ホストがオンラインかどうかを確認できます。

* `ping` コマンド：ホストのネットワーク接続性を確認します。ホストにネットワークプローブパケットを送信し、応答を待つことで、ホストがアクセス可能かどうかをテストします。

   ```shell
   ping <host_name_or_ip_address>
   ```

   ここで、`<host_name_or_ip_address>` は確認対象のホスト名またはIPアドレスです。ホストがオンラインの場合、一連の応答がホストから返されます。ホストがオフラインの場合は、エラーメッセージが表示されるか、応答がありません。

* `ssh` コマンド：SSHプロトコルを使用してホストにリモートログインを試みます。接続に成功すれば、ホストはオンラインです。

   ```shell
   ssh <user>@<host_name_or_ip_address>
   ```

   ここで、`<user>` はホストにログインするためのユーザー名、`<host_name_or_ip_address>` は確認対象のホスト名またはIPアドレスです。ホストに接続に成功すると、ホストのログインプロンプトが表示されます。

## CPU情報を確認する

`mpstat` コマンド：マルチコアCPUの監視とレポートに使用され、CPU使用状況に関する一連のパラメータを出力します。

```shell
mpstat
```

以下は `mpstat` コマンドが出力する一般的なパラメータとその意味の説明です：

* CPU：CPU番号を表示します。
* %usr：ユーザースペースプロセスがCPUを使用する割合を表示します。
* %nice：優先優順位を調整して実行されるユーザープロセスがCPUを使用する割合を表示します。
* %sys：システムカーネルプロセスがCPUを使用する割合を表示します。
* %iowait：I/O完了を待機しているプロセスがCPUを使用する割合を表示します。
* %irq：ハードウェア割り込みがCPUを使用する割合を表示します。
* %soft：ソフトウェア割り込みがCPUを使用する割合を表示します。
* %steal：仮想化環境（例：仮想マシン）によって奪われたCPU時間の割合を表示します。
* %guest：仮想化環境内で実行される仮想CPUのユーザータスクの割合を表示します。
* %idle：アイドルCPUの割合を表示します。

**例：**

```shell
[admin@xxx /home/admin]
$mpstat
Linux 3.10.0-327.ali2019.alios7.x86_64 (xxx)      09/13/2023      _x86_64_
     (64 CPU)

10:25:42 AM  CPU    %usr   %nice    %sys %iowait    %irq   %soft  %steal  %guest  %gnice   %idle
10:25:42 AM  all    8.36    0.00    2.38    0.04    0.00    0.18    0.00    0.00    0.00   89.04
```

## メモリ情報を確認する

`free -h` コマンド：システムメモリ使用状況に関するパラメータを表示するために使用されます。

```shell
free -h
```

以下は `free -h` コマンドの出力パラメータとその意味の説明です：

* total：物理メモリ（RAM）の合計サイズを表します。
* used：使用済みの物理メモリサイズを表します。
* free：空きの物理メモリサイズを表します。
* shared：複数のプロセスで共有されている物理メモリサイズを表します。
* buff/cache：キャッシュとバッファに使用されている物理メモリサイズを表します。
* available：現在利用可能な物理メモリサイズ、つまり残りの利用可能メモリ（free + buff/cache）を表します。

* Swap：スワップパーティション（swap）の使用状況を表します。
* total：スワップパーティションの合計サイズを表します。
* used：使用済みのスワップパーティションを表します。
* free：空きのスワップパーティションを表します。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p><code>-h</code> オプションは、メモリサイズをより読みやすい方法で表示するために使用されます。</p>
</main>

**例：**

```shell
[admin@xxx /home/admin]
$free -h
              total        used        free      shared  buff/cache   available
Mem:           503G        255G        7.2G        4.2M        240G        238G
Swap:            0B          0B          0B
```

## ディスク情報の確認

`df` コマンド：ディスク使用状況を確認し、パス、パーティションのディスク容量、使用済み容量、空き容量、使用率、およびマウントディレクトリの情報を取得します。

```shell
df [-h] [dir_name]
```

ここで、`-h` パラメータはディスクサイズをGB単位で表示するために使用され、`dir_name` は指定したディレクトリのディスクの総サイズをクエリすることを表します。

出力結果には以下の情報が含まれます：

* Filesystem：ファイルシステムのパスまたはデバイス名。
* Size：パーティションディスクの総サイズ。
* Used：使用済みのディスク容量。
* Available：利用可能なディスク容量。
* Use%：ディスク容量の使用率。
* Mounted on：マウントディレクトリ。

**例：**

```shell
[root@xxx /home/admin]# df -h /data/1
Filesystem      Size  Used Avail Use% Mounted on
-               196G  168G   19G  91% /data/1
```
