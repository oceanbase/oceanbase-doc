# OBServerのステータスを確認する

本記事では、OBServerのステータスを確認する方法について説明します。ご自身の状況に応じて選択できます。

## ホスト上からOBServerのステータスを確認する

1. OBServerが配置されているホストにログインします。

2. コマンドラインツールで以下のコマンドを実行して、observerプロセスを確認します。

   ```shell
   ps -ef |grep observer
   root       6136      0 99 11:23 ?        08:53:50 ./bin/observer
   root      20514  19521  0 16:09 pts/25   00:00:00 grep --color=auto observer
   ```

## ビューを使用してOBServerのステータスを確認する

```sql
obclient> SELECT status FROM oceanbase.DBA_OB_SERVERS;
+--------+
| status |
+--------+
| active |
| active |
+--------+
2 rows in set (0.00 sec)
```

* 実行結果が`active`の場合、OBServerは正常に稼働しています。

* 実行結果が`inactive`の場合、OBServerはオフライン状態です。

* 実行結果が`deleting`の場合、OBServerは削除中です。
