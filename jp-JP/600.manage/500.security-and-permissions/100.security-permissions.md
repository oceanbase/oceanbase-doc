# セキュリティ権限の概要

データベースシステムにおける重要な指標の一つは、システムのセキュリティを確保し、データベース管理システムを通じてデータベースの不正使用を防ぎ、データベースのファイルとデータを保護することです。本記事では、OceanBaseデータベースのセキュリティ体系について説明します。

OceanBaseデータベースは、データの最終的な担い手として、常にデータの安全性を重視しています。OceanBaseデータベースは、アイデンティティ認証・認可、アクセス制御、データ暗号化、モニタリング・アラート、セキュリティ監査など、企業向けのセキュリティ機能を比較的完全にサポートしており、ユーザーのデータセキュリティを効果的に保証できます。

![セキュリティ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/EN_US/700.reference/100.oceanbase-database-concepts/%E5%86%85%E6%A0%B823.png)

* アイデンティティ認証・認可

  OceanBaseデータベースは、アイデンティティ識別・認証、ユーザー管理、ロール管理をサポートし、データベースのセキュリティを向上させます。詳細については、[アイデンティティ認証・認可](200.identification-and-authentication/100.identification-and-authentication-of-mysql-mode/100.identification-of-mysql-mode.md)を参照してください。

* アクセス制御

  OceanBaseデータベースは、さまざまなシステムやオブジェクトの権限、およびロールを定義することで、ユーザーによるデータへのアクセスを制御します。詳細については、[アクセス制御](300.access-control/100.access-control-overview.md)を参照してください。

* データ暗号化

  OceanBaseデータベースは、データの転送および保存プロセスにおいて、データの暗号化をサポートしています。転送層においては、OceanBaseデータベースは全リンクデータ暗号化をサポートしています。同時に、データ保存時には、OceanBaseデータベースは透過的暗号化機能をサポートしており、保存メディアが紛失した場合でもデータの損失を防ぎ、ユーザーのデータセキュリティを最大限に保護します。詳細については、[データ転送の暗号化](400.data-transfer-encryption/100.data-transfer-encryption-overview.md)および[データの透過的暗号化](500.data-storage-encryption/100.datastore-encryption-overview.md)を参照してください。
  OceanBaseデータベースは、列暗号化機能もサポートしています。詳細については、[ENHANCED_AES_ENCRYPT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md)および[ENHANCED_AES_DECRYPT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md)を参照してください。

  <main id="notice">
      <h4>適用対象</h4>
      <p>OceanBaseデータベースCommunity Editionは、現在データの透過的暗号化をサポートしていません。</p>
  </main>

* セキュリティ監査

  OceanBaseデータベースは、データベースユーザーの行動を監査し、ユーザーの操作がすべて記録されるようにします。同時に、OceanBaseデータベースはデータベースオブジェクトに対する監査操作もサポートしており、ユーザーがデータにアクセスする際に監査情報を生成し、データアクセスが正確に記録されるようにします。詳細については、[セキュリティ監査](600.security-audit/100.security-audit-overview.md)を参照してください。

  <main id="notice">
      <h4>適用対象</h4>
      <p>OceanBaseデータベースCommunity Editionは、現在セキュリティ監査をサポートしていません。</p>
  </main>
