# パスワードの複雑さ

OceanBaseデータベースのOracleモードにおけるパスワードの複雑さポリシーは、Oracleデータベースのパスワードポリシーと互換性があります。悪意のあるパスワード攻撃を防ぎ、データベースのセキュリティを向上させるために、OceanBaseデータベースではユーザーが必要に応じてパスワードの複雑さ関数を設定し、ユーザーのログイン身元を検証できます。

<main id="notice" >
    <h4>適用対象</h4>
    <p>このドキュメントはOceanBaseデータベースのOracleモードにのみ適用されます。現在、OceanBaseデータベースCommunity EditionはMySQLモードのみを提供しています。MySQLモードにおけるパスワードの複雑さについては、<a href="../100.identification-and-authentication-of-mysql-mode/200.password-complexity-of-mysql-mode.md">パスワードの複雑さ</a>を参照してください。</p>
</main>

## 前提条件

Oracleモードでは、ユーザーはProfileの`PASSWORD_VERIFY_FUNCTION`属性を使用してパスワードの複雑さが要件を満たしているかどうかを検証できます。まず、パスワードの複雑さを検証するためのPL Functionを作成する必要があり、以下のインターフェースを満たす必要があります：

```sql
FUNCTION verify_function (username     IN VARCHAR2,
           password     IN VARCHAR2,
           old_password IN VARCHAR2)
RETURN BOOLEAN;
```

ユーザー作成時またはパスワード変更時に、この検証関数が呼び出され、関数の実行結果に基づいて新しいパスワードが複雑さ要件を満たしているかどうか判断されます。

## パスワードの複雑さを設定し、パスワードの複雑さ検証を有効にする

OceanBaseデータベースのOracleモードは、パスワードの複雑さが要件を満たしているかどうかを検証するための`PASSWORD_VERIFY_FUNCTION`パラメータを提供します。

`PASSWORD_VERIFY_FUNCTION`パラメータにより、PLのパスワード複雑さ検証関数を`CREATE PROFILE`および`ALTER PROFIL`ステートメントのパラメータとして渡すことが可能です。

<main id="notice" type='notice'>
    <h4>注意</h4>
    <p>本番環境では、パスワードの長さを20文字に設定し、数字、大文字、小文字、特殊文字を含めることを推奨します。パスワードの複雑さが低いほど、例えばユーザー名を含む場合や繰り返しの文字を使用する場合など、解読される可能性が高くなります。セキュリティ上の理由から、ユーザーのパスワードは高い複雑さを持つ必要があります。
    </li></p>
  </main>

1. `SYS`ユーザーでクラスタのOracleテナントにログインします。

    ```shell
    obclient -usys@oracle -h10.xxx.xxx.1 - P2881 -P*******
    ```

2. `PASSWORD_VERIFY_FUNCTION`パラメータに対応する関数を作成し、権限を付与します。

   以下では、パスワードの複雑さを以下のルールに設定する操作手順を説明します。

   * パスワードの長さは、最小8文字、最大256文字以内です。

   * 少なくとも1つの大文字、1つの小文字、1つの特殊文字を含む必要があります。

   * パスワードは、ユーザー名、ユーザー名の逆順、またはサーバー名であってはなりません。

   例：

    ```shell
    delimiter //

    CREATE OR REPLACE FUNCTION complexity_check
    (password varchar2,
        chars integer := NULL,
        letter integer := NULL,
        upper_c integer := NULL,
        lower_c integer := NULL,
        digit integer := NULL,
        special integer := NULL)
    RETURN boolean IS
        digit_array varchar2(10) := '0123456789';
        alpha_array varchar2(26) := 'abcdefghijklmnopqrstuvwxyz';
        cnt_letter integer := 0;
        cnt_upper integer := 0;
        cnt_lower integer := 0;
        cnt_digit integer := 0;
        cnt_special integer := 0;
        flag boolean := FALSE;
        len INTEGER := NVL(length(password), 0);
        i integer ;
        ch CHAR(1);
    BEGIN
        -- Check that the password length does not exceed 2 * (max DB pwd len)
        -- The maximum length of any DB User password is 128 bytes.
        -- This limit improves the performance of the Edit Distance calculation
        -- between old and new passwords.
    IF len > 256 THEN
        raise_application_error(-20020, 'Password length more than 256');
    END IF;

        -- Classify each character in the password.
        FOR i in 1..len LOOP
            ch := substr(password, i, 1);
            IF ch = '"' THEN
                flag := TRUE;
            ELSIF instr(digit_array, ch) > 0 THEN
                cnt_digit := cnt_digit + 1;
            ELSIF instr(alpha_array, LOWER(ch)) > 0 THEN
                cnt_letter := cnt_letter + 1;
                IF ch = LOWER(ch) THEN
                    cnt_lower := cnt_lower + 1;
                ELSE
                    cnt_upper := cnt_upper + 1;
                END IF;
            ELSE
                cnt_special := cnt_special + 1;
            END IF;
        END LOOP;
        IF flag = 1 THEN
            raise_application_error(-20012, 'password must NOT contain a '
                                                                || 'double-quote character, which is '
                                                                || 'reserved as a password delimiter');
        END IF;
        IF chars IS NOT NULL AND len < chars THEN
            raise_application_error(-20001, 'Password length less than ' ||
                                                                chars);
        END IF;
        IF letter IS NOT NULL AND cnt_letter < letter THEN
            raise_application_error(-20022, 'Password must contain at least ' ||
                                                                letter || ' letter(s)');
        END IF;
        IF upper_c IS NOT NULL AND cnt_upper < upper_c THEN
            raise_application_error(-20023, 'Password must contain at least ' ||
                                                                upper_c || ' uppercase character(s)');
        END IF;
        IF lower_c IS NOT NULL AND cnt_lower < lower_c THEN
            raise_application_error(-20024, 'Password must contain at least ' ||
                                                                    lower_c || ' lowercase character(s)');
        END IF;
        IF digit IS NOT NULL AND cnt_digit < digit THEN
            raise_application_error(-20025, 'パスワードには少なくとも ' ||
                                                                    数字 || ' 文字が含まれている必要があります。',
        END IF;
        IF special IS NOT NULL AND cnt_special < special THEN
            raise_application_error(-20026, 'パスワードには少なくとも ' ||
                                                                    特殊文字 || ' 個の特殊文字が含まれている必要があります。',
        END IF;
        RETURNTRUE;
        END;
    //

    CREATE OR REPLACE FUNCTION verify_function
    (username varchar2,
        password varchar2,
        old_password varchar2)
        -- この例では、ユーザー名 username、新しいパスワード password、古いパスワード old_password の3つの関数パラメータをカスタマイズしています。
    RETURN boolean IS
        differ integer;
        pw_lower varchar2(256);
        db_name varchar2(40);
        i integer;
        simple_password varchar2(10);
        reverse_user varchar2(32);
    BEGIN
        IF NOT complexity_check(password, 8, NULL, 1, 1, NULL, 1) THEN
            RETURN(FALSE);
        END IF;

        -- パスワードにユーザー名が含まれていないか確認する
        pw_lower := LOWER(password);
        IF instr(pw_lower, LOWER(username)) > 0 THEN
            raise_application_error(-20002, 'パスワードにユーザー名が含まれています。');
        END IF;

        -- パスワードにユーザー名の逆順が含まれているかどうかを確認する
        reverse_user := '';
        FOR i in REVERSE 1..length(username) LOOP
            reverse_user := reverse_user || substr(username, i, 1);
        END LOOP;
        IF instr(pw_lower, LOWER(reverse_user)) > 0 THEN
            raise_application_error(-20003, 'Password contains the username ' ||
                                                                                                    'reversed');
        END IF;

        -- パスワードにサーバー名が含まれているかどうかを確認する
        db_name := 'oceanbase';
        IF instr(pw_lower, LOWER(db_name)) > 0 THEN
            raise_application_error(-20004, 'Password contains the server name');

        END IF;

        -- パスワードに'oracle'が含まれているかどうかを確認する
        IF instr(pw_lower, 'oracle') > 0 THEN
            raise_application_error(-20006, 'Password too simple');
        END IF;

        RETURNTRUE);
    END;
    //
    delimiter ;

    obclient> GRANT EXECUTE ON verify_function TO PUBLIC;
    obclient> CREATE PUBLIC SYNONYM verify_function FOR sys.verify_function;
    ```

   関数の作成手順については、[関数の作成](../../../../700.reference/600.pl-reference/300.pl-oracle/700.stored-procedure-and-functions-oracle/300.create-a-function-oracle.md)を参照してください。

3. UserのProfileで`PASSWORD_VERIFY_FUNCTION`パラメータを指定し、パスワードの複雑さ検証を有効にします。

   ステートメントは以下のとおりです：

   ```shell
   obclient> ALTER PROFILE profile_name LIMIT PASSWORD_VERIFY_FUNCTION verify_function;
   ```

   ここで、`profile_name`にはカスタムプロファイルを使用することも、`DEFAULT`プロファイルを使用することもできます。

   `DEFAULT`プロファイルを使用して`PASSWORD_VERIFY_FUNCTION`パラメータを指定する例：

   ```shell
   obclient> ALTER PROFILE DEFAULT LIMIT PASSWORD_VERIFY_FUNCTION verify_function;
   Query OK, 0 rows affected
   ```

   `ALTER PROFILE`ステートメントの詳細については、[ALTER PROFILE](../../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/400.alter-profile-of-oracle-mode.md)を参照してください。

4. 完了後、以下のステートメントを実行して、パスワードの複雑さ検証が有効になっているかどうかを確認できます。

   戻り値が`NULL`の場合はパスワードの複雑さ検証が無効であり、先ほど指定した関数の値が返された場合はパスワードの複雑さ検証が有効であることを意味します。

   ```shell
   obclient> SELECT LIMIT FROM DBA_PROFILES WHERE RESOURCE_NAME='PASSWORD_VERIFY_FUNCTION' AND PROFILE='profile_name';
   ```

   例：

   ```shell
   obclient> SELECT LIMIT FROM DBA_PROFILES WHERE RESOURCE_NAME='PASSWORD_VERIFY_FUNCTION' AND PROFILE='DEFAULT';
   +-----------------+
   | LIMIT           |
   +-----------------+
   | VERIFY_FUNCTION |
   +-----------------+
   1 row in set
   ```

## パスワードの複雑さ設定が有効かどうかを確認する

1. `SYS`ユーザーでクラスタのOracleテナントにログインします。

   ```shell
   obclient -usys@oracle -h10.xxx.xxx.1 - P2881 -P*******
   ```

2. 要件を満たすパスワードと要件を満たさないパスワードを使用して、それぞれユーザー`sectest1`を作成します。

   ```shell
   obclient> CREATE USER sectest1 IDENTIFIED BY ******;
   ERROR-20023: Password must contain at least 1 uppercase character(s)

   obclient> CREATE USER sectest1 IDENTIFIED BY ******;
   ERROR-20002: Password contains the username

   obclient> CREATE USER sectest1 IDENTIFIED BY ******;
   Query OK, 0 rows affected
   ```

## パスワードの複雑さルールを確認する

パスワードの複雑さ設定が成功した後、次回具体的な複雑さルールを確認する必要がある場合は、関数の内容を照会することで取得できます。

手順は以下のとおりです：

1. sysユーザーでクラスタのOracleテナントにログインします。

   ```shell
   obclient -usys@oracle -h10.xxx.xxx.1 - P2881 -P*******
   ```

2. `DBA_SOURCE`ビューで対応する関数を検索します。

   `DBA_SOURCE`ビューは、システム内のすべてのストアドプロシージャと関数を記録しています。

   `DBA_SOURCE`ビューおよびそのフィールドの詳細については、[DBA_SOURCE](../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/19700.dba_source-of-oracle-mode.md)を参照してください。

   例：

   ```shell
   obclient> SELECT OWNER,NAME,TYPE FROM DBA_SOURCE WHERE TYPE='FUNCTION';
   +-------+------------------+----------+
   | OWNER | NAME             | TYPE     |
   +-------+------------------+----------+
   | SYS   | COMPLEXITY_CHECK | FUNCTION |
   | SYS   | STRING_DISTANCE  | FUNCTION |
   | SYS   | VERIFY_FUNCTION  | FUNCTION |
   +-------+------------------+----------+
   3 rows in set
   ```

3. `USER_SOURCE`ビューで、現在のユーザーが所有する関数`VERIFY_FUNCTION`の内容を確認します。

   `USER_SOURCE`ビューは、システム内で現在のユーザーが所有するすべてのストアドプロシージャと関数を記録しています。

   `USER_SOURCE`ビューおよびそのフィールドの詳細については、[USER_SOURCE](../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/29600.user_source-of-oracle-mode.md)を参照してください。

   例：

   ```shell
   obclient>SELECT TEXT FROM USER_SOURCE WHERE NAME='VERIFY_FUNCTION' AND
        TYPE='FUNCTION'\G
   *************************** 1. row ***************************
   TEXT: FUNCTION verify_function
        (username varchar2,
            password varchar2,
            old_password varchar2)
            -- この例では、ユーザー名username、新しいパスワードpassword、古いパスワードold_passwordの3つの関数パラメータをカスタマイズしています
        RETURN boolean IS
            differ integer;
            pw_lower varchar2(256);
            db_name varchar2(40);
            i integer;
            simple_password varchar2(10);
            reverse_user varchar2(32);
        BEGIN
            IF NOT complexity_check(password, 8, NULL, 1, 1, NULL, 1) THEN
                RETURN(FALSE);
            END IF;

            -- Check if the password contains the username
            pw_lower := LOWER(password);
            IF instr(pw_lower, LOWER(username)) > 0 THEN
                raise_application_error(-20002, 'Password contains the username');
            END IF;

            -- Check if the password contains the username reversed
            reverse_user := '';
            FOR i in REVERSE 1..length(username) LOOP
                reverse_user := reverse_user || substr(username, i, 1);
            END LOOP;
            IF instr(pw_lower, LOWER(reverse_user)) > 0 THEN
                raise_application_error(-20003, 'Password contains the username ' ||
                                                                                                        'reversed');
            END IF;

            -- Check if the password contains the server name
            db_name := 'oceanbase';
            IF instr(pw_lower, LOWER(db_name)) > 0 THEN
                raise_application_error(-20004, 'Password contains the server name');

            END IF;

            -- Check if the password contains 'oracle'
            IF instr(pw_lower, 'oracle') > 0 THEN
                raise_application_error(-20006, 'Password too simple');
            END IF;

            RETURN(TRUE);
        END
   1 row in set
   ```

関数の管理に関するその他の操作については、[ストアドプロシージャと関数の管理](../../../../700.reference/600.pl-reference/300.pl-oracle/700.stored-procedure-and-functions-oracle/400.view-and-delete-procedures-and-functions-oracle.md)を参照してください。
