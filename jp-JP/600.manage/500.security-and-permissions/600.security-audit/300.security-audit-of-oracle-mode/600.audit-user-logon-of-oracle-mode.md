# ユーザーログインの監査

監査機能は、ユーザーのログイン操作を監査できます。

## 指定ユーザーのログイン監査

`ORAAUDITOR` ユーザーでログインし、監査対象ユーザー `user1` のログインを設定します。

```shell
obclient> AUDIT SESSION BY user1;
```

## すべてのユーザーのログイン監査

`ORAAUDITOR` ユーザーでログインし、すべてのユーザーのログインを監査するように設定します。

```shell
obclient> AUDIT SESSION;
```

## 監査レコードの表示

`DBA_AUDIT_TRAIL` の監査レコードを表示します。

```shell
obclient> SELECT USERNAME,USERHOST,TIMESTAMP,SQL_TEXT FROM SYS.DBA_AUDIT_TRAIL;
+----------+----------------+-----------+----------+
| USERNAME | USERHOST       | TIMESTAMP | SQL_TEXT |
+----------+----------------+-----------+----------+
| USER1    | 10.10.10.10    | 22-DEC-21 | CONNECT  |
+----------+----------------+-----------+----------+
1 row in set
```
