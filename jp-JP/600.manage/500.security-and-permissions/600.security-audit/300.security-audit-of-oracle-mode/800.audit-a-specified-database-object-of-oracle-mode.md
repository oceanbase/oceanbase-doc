# 監査対象データベースオブジェクトの指定

OceanBaseデータベースは、監査対象となるデータベースオブジェクトを指定できます。監査時には、そのオブジェクトに対する特定の操作のみが記録されます。監査可能なデータベースオブジェクトには、テーブル（Table）、シーケンス（Sequence）、ビュー（View）が含まれます。

## データベースオブジェクトに対する単一ユーザーの操作の監査

例：`aud` ユーザーによる `tab1` への挿入操作を監査します。

`ORAAUDITOR` ユーザーでログインし、監査を開始します。

```shell
obclient> AUDIT INSERT ON tab1 BY aud;
```

## データベースオブジェクトに対するすべてのユーザーの操作の監査

例：すべてのユーザーによる `tab1` テーブルに対する失敗したDML操作を監査します。

`ORAAUDITOR` ユーザーでログインし、監査を開始します。

```shell
obclient> AUDIT INSERT, UPDATE, DELETE ON tab1 WHENEVER NOT SUCCESSFUL;
```
