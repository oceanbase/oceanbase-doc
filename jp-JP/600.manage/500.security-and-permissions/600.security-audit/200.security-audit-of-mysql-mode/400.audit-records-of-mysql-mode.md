# 監査レコードの表示

監査レコードはログ形式での永続化のみをサポートしています。現在、監査レコードのログ書き込み実装はシステムログへの書き込みによって行われており、各業務テナントには監査ログを出力するためのバックグラウンドスレッドが1つずつ割り当てられています。

<main id="notice" >
  <h4>機能の適用範囲</h4>
  <p>この内容はOceanBaseデータベースEnterprise Editionにのみ適用されます。OceanBaseデータベースCommunity Editionは、現在監査機能をサポートしていません。</p>
</main>

## ログフィールドの説明

監査レコードのフィールドは、既存の `[G]V$OB_SQL_AUDIT` ビューのフィールドから抽出されていますが、いくつかの点で異なります：

* `EVENT_CLASS` フィールドが追加され、監査イベントタイプを識別するために使用されます。値には `connection`、`table_access`、`general` が含まれ、フィルターの定義と一致しています。
* ユーザーセッションのリクエストのみが記録され、内部で発生したSQLログは記録されません。
* クエリSQLは `utf8` に変換され、エスケープ処理を施した後に出力されます。ログオン・ログオフイベントについては、`LOGON`/`LOGOFF` が記録されます。
* 超長SQLの場合、非同期ログ出力時には現在のスレッドのAllocatorを使用してメモリを割り当て、後から同期出力に切り替えます。

監査ログの具体的なフィールドリストは以下のとおりです。型は出力形式にのみ影響し、文字列と整数の2種類のみがあり、文字列型は引用符で囲まれます。
