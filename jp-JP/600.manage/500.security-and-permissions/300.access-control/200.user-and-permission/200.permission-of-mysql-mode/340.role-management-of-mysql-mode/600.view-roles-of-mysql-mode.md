# ロールの表示

ユーザーが有効なロール、ロールに含まれるロール、およびロールに含まれる権限を確認できます。

## ユーザーに付与されたロールと権限の表示

<main id="notice" type='notice'>
<h4>注意</h4>
<p>ユーザーは常に直接付与された権限を使用できますが、ロールを通じて間接的に取得した権限を使用できるとは限りません。ユーザーは現在のセッションで有効なロールの権限のみを使用できます。</p>
</main>

ユーザー `test1` に付与されたロールと権限を確認するステートメントは次のとおりです：

```shell
obclient [oceanbase]> SHOW GRANTS FOR test1;
```

クエリ結果は次のとおりです：

```shell
+-------------------------------------------------+
| Grants for test1@%                              |
+-------------------------------------------------+
| GRANT USAGE ON *.* TO 'test1'                   |
| GRANT `employee`@`%`,`role1`@`%` TO `test1`@`%` |
+-------------------------------------------------+
2 rows in set
```

ユーザーに付与されたロールについて、そのロールに含まれる権限をさらに表示したい場合は、`USING` 句を追加して、そのロールに含まれる権限を指定して表示します。

```shell
obclient [oceanbase]> SHOW GRANTS FOR test1 USING role1;
```

結果は次のとおりです：

```shell
+-------------------------------------------------+
| Grants for test1@%                              |
+-------------------------------------------------+
| GRANT ALTER SYSTEM ON *.* TO 'test1'            |
| GRANT UPDATE, SELECT ON `dbtest`.* TO 'test1'   |
| GRANT `employee`@`%`,`role1`@`%` TO `test1`@`%` |
+-------------------------------------------------+
3 rows in set
```

## ロールが付与されたロールまたは権限の表示

ロール `role1` が付与されたロールまたは権限を確認します。

```shell
obclient [oceanbase]> SHOW GRANTS FOR role1;
```

クエリ結果は次のとおりです：

```shell
+-------------------------------------------------------+
| Grants for role1@%                                    |
+-------------------------------------------------------+
| GRANT ALTER SYSTEM ON *.* TO 'role1'                  |
| GRANT SELECT ON `dbtest`.* TO 'role1'                 |
| GRANT SELECT ON `test1`.`tbl1` TO 'role1'             |
| GRANT `employee`@`%` TO `role1`@`%` WITH ADMIN OPTION |
+-------------------------------------------------------+
4 rows in set
```

## ユーザーログイン時のデフォルトで有効なロールの表示

グローバル変数 `activate_all_roles_on_login` によりログイン時にユーザーに付与されたすべてのロールが自動的に有効になっている場合、または `SET DEFAULT ROLE` ステートメントや `ALTER USER` ステートメントでログイン時のデフォルトで有効なロールが設定されている場合、`mysql.default_roles` ビューを照会することで、ユーザーログイン時のデフォルトで有効なロールが正しく設定されているかどうかを確認できます。

```shell
obclient [oceanbase]> SELECT * FROM mysql.default_roles;
```

結果は次のとおりです：

```shell
+------+-------+-------------------+-------------------+
| HOST | USER  | DEFAULT_ROLE_HOST | DEFAULT_ROLE_USER |
+------+-------+-------------------+-------------------+
| %    | test1 | %                 | role1             |
| %    | test1 | %                 | employee          |
+------+-------+-------------------+-------------------+
2 rows in set
```

ビュー `mysql.default_roles` の各フィールドについて詳しくは、[mysql.default_roles](../../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/3250.mysql-default_roles-of-mysql-mode.md)を参照してください。

## 現在のセッションでアクティブなロールを確認する

現在のユーザーが現在のセッションでアクティブなロールを確認するステートメントは以下のとおりです：

```shell
obclient [oceanbase]> SELECT current_role();
```

クエリ結果は次のとおりです：

```shell
+--------------------------------+
| current_role()                 |
+--------------------------------+
| `developer`@`%`,`employee`@`%` |
+--------------------------------+
1 row in set
```

クエリ結果が `NONE` の場合、現在のユーザーにはアクティブなロールがなく、ユーザーが使用できるのはアクティブなロールの権限のみです。

## ロールとユーザー間の権限付与関係を確認する

```shell
obclient [oceanbase]> SELECT * FROM mysql.role_edges;
```

クエリ結果は次のとおりです：

```shell
+-----------+-----------+---------+---------+-------------------+
| FROM_HOST | FROM_USER | TO_HOST | TO_USER | WITH_ADMIN_OPTION |
+-----------+-----------+---------+---------+-------------------+
| %         | employee  | %       | test2   | Y                 |
| %         | employee  | %       | role1   | Y                 |
| %         | developer | %       | test1   | N                 |
+-----------+-----------+---------+---------+-------------------+
3 rows in set
```

上記のクエリ結果では：

* 最初の行は、`employee` ロールが `test2` ユーザーにすべての権限を付与し、同時に `test2` ユーザーがそのロールを他のユーザーまたはロールに再付与することを許可していることを示しています。

* 2番目の行は、`employee` ロールが `role1` ロールにすべての権限を付与し、同時に `role1` ロールがそのロールを他のユーザーまたはロールに再付与することを許可していることを示しています。

* 3番目の行は、`developer` ロールが `test1` ユーザーにすべての権限を付与し、`test1` ユーザーはそのロールを他のユーザーまたはロールに再付与できないことを示しています。

ビュー `mysql.role_edges` の各フィールドについて詳しくは、[mysql.role_edges](../../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/3790.mysql-role_edges-of-mysql-mode.md)を参照してください。

## 現在アクティブなロールのテーブルレベル権限を確認する

ユーザーが現在のセッションで付与されたアクティブなロールのテーブルレベル権限情報、およびこれらのロールが他のロールに付与したテーブルレベル権限情報を確認するステートメントは以下のとおりです：

```shell
obclient [information_schema]> SELECT * FROM information_schema.role_table_grants;
```

クエリ結果は次のとおりです：

```shell
+---------+--------------+-----------+--------------+---------------+--------------+------------+--------------------+--------------+
| GRANTOR | GRANTOR_HOST | GRANTEE   | GRANTEE_HOST | TABLE_CATALOG | TABLE_SCHEMA | TABLE_NAME | PRIVILEGE_TYPE     | IS_GRANTABLE |
+---------+--------------+-----------+--------------+---------------+--------------+------------+--------------------+--------------+
| root    | %            | developer | %            | def           | test         | tbl2       | Drop,Update,Select | NO           |
+---------+--------------+-----------+--------------+---------------+--------------+------------+--------------------+--------------+
1 row in set
```

クエリ結果は、`root` ユーザーが `test.tbl2` テーブルの `Drop`、`Update`、`Select` 権限を `developer` ロールに付与したことを示しています。

ビュー `role_table_grants` の各フィールドについて詳しくは、[information_schema.role_table_grants](../../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/1710.information_schema-role-table-grants-of-mysql-mode.md)を参照してください。

## 現在アクティブなロールの列権限を確認する

現在のセッションでユーザーに付与されているアクティブなロールの列権限情報、およびこれらのロールが他のロールに付与した列権限情報を確認するステートメントは以下のとおりです：

```shell
obclient [information_schema]> SELECT * FROM information_schema.role_column_grants;
```

クエリ結果は次のとおりです：

```shell
+---------+--------------+----------+--------------+---------------+--------------+------------+-------------+----------------+--------------+
| GRANTOR | GRANTOR_HOST | GRANTEE  | GRANTEE_HOST | TABLE_CATALOG | TABLE_SCHEMA | TABLE_NAME | COLUMN_NAME | PRIVILEGE_TYPE | IS_GRANTABLE |
+---------+--------------+----------+--------------+---------------+--------------+------------+-------------+----------------+--------------+
|    NULL |         NULL | employee | %            | def           | test          | tbl1      | c1          | Select,Insert  | NO           |
|    NULL |         NULL | employee | %            | def           | test          | tbl1      | c2          | Insert         | NO           |
+---------+--------------+----------+--------------+---------------+--------------+------------+-------------+----------------+--------------+
2 rows in set
```

上記のクエリ結果では：

* 最初の行は、`employee` ロールがテーブル `test.tbl1` の列 `c1` に対して `Select`、`Insert` 権限を持っていることを示しています。
* 2行目は、`employee` ロールがテーブル `test.tbl1` の列 `c2` に対して `Insert` 権限を持っていることを示しています。

ビュー `role_column_grants` の各フィールドの詳細については、[information_schema.role_column_grants](../../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/1720.information_schema-role-column-grants-of-mysql-mode.md)を参照してください。

## 現在アクティブなロールのルーチン権限を確認する

現在のセッションでユーザーに付与されているアクティブなロールのルーチン権限情報、およびこれらのロールが他のロールに付与したルーチン権限情報を確認するステートメントは以下のとおりです：

```shell
obclient [information_schema]> SELECT * FROM information_schema.role_routine_grants;
```

上記のクエリ結果は次のとおりです：

```shell
+---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
| GRANTOR | GRANTOR_HOST | GRANTEE   | GRANTEE_HOST | SPECIFIC_CATALOG | SPECIFIC_SCHEMA | SPECIFIC_NAME | ROUTINE_CATALOG | ROUTINE_SCHEMA | ROUTINE_NAME | PRIVILEGE_TYPE        | IS_GRANTABLE |
+---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
| root    | %            | developer | %            | def              | test            | add_numbers   | def             | test           | add_numbers  | Execute,Alter Routine | NO           |
+---------+--------------+-----------+--------------+------------------+-----------------+---------------+-----------------+----------------+--------------+-----------------------+--------------+
1 row in set
```

クエリ結果は、`root` ユーザーがルーチン `test.add_numbers` の `Execute`、`Alter Routine` 権限を `developer` ロールに付与したことを示しています。

ビュー `role_routine_grants` の各フィールドの詳細については、[information_schema.role_routine_grants](../../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/1730.information_schema-role-routine-grants-of-mysql-mode.md)を参照してください。
