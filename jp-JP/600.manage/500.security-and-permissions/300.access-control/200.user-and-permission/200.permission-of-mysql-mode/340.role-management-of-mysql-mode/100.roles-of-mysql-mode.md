# ロール管理の概要

OceanBaseデータベースは、MySQLモードでユーザーロール管理機能をサポートしています。

MySQLモードでは、ロールは権限の集合です。ロールを使用することで、ユーザー権限を簡単に管理できます。

OceanBaseデータベースにおいて、ロールは以下の機能を備えています：

* 一般ユーザーと同様に、ロールにも権限を付与できます。

* ロールには他のロールを含めることができます。つまり、ロールは階層構造を持つことが可能です。

* 1人のユーザーに複数のロールを付与でき、1つのロールを複数のユーザーに付与することもできます。

現在、OceanBaseデータベースのMySQLモードでは、デフォルトのシステムロールはサポートされていません。
