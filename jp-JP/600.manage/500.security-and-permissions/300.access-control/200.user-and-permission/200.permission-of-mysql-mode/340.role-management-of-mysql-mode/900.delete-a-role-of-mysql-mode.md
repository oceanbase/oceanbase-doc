# ロールの削除

`DROP ROLE` ステートメントを使用して、不要なロールを削除できます。

## 前提条件

ロールを削除するには、現在のユーザーが `CREATE USER` 権限または `DROP ROLE` 権限を持っている必要があります。現在のユーザーが持つ権限の確認方法については、[ユーザー権限の確認](../400.view-user-permissions-of-mysql-mode.md)を参照してください。関連する権限がない場合は、管理者に連絡し、追加してもらってください。ユーザーへの権限付与に関する操作については、[直接権限付与](../200.authority-of-mysql-mode.md)を参照してください。

## 注意事項

ロールを削除すると、システムはそのロールを持つすべてのユーザーおよびロールから自動的にロールを取り消し、データベースから削除します。

## 操作例

* ロール `role1` を削除します。

  ```sql
  obclient [oceanbase]> DROP ROLE role1;
  ```

* ロール `role1` と `role2` を削除します。

  ```sql
  obclient [oceanbase]> DROP ROLE role1,role2;
  ```
