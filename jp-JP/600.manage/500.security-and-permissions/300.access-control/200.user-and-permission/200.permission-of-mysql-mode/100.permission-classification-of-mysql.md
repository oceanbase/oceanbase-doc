# MySQLモードの権限分類

本記事では、OceanBaseデータベースのMySQLモードにおける権限の分類について説明します。

## 分類

MySQLモードの権限は、3つのレベルに分かれています：

* グローバル権限：テナント全体に影響を及ぼす権限です。例えば、システム設定の変更やすべてのテーブルへのアクセスなどの権限が含まれます。
* データベース権限：特定のデータベース内のすべてのオブジェクトに影響を及ぼす権限です。例えば、対応するデータベース内でテーブルの作成・削除、テーブルへのアクセスなどの権限が含まれます。
* オブジェクト権限：特定のオブジェクトに影響を及ぼす権限です。例えば、特定のテーブル、ビュー、またはインデックスへのアクセス権限などが含まれます。
