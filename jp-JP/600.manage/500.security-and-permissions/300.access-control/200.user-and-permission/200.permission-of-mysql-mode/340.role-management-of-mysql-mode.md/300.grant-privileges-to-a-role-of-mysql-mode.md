# ロールに権限を追加する

ロールを作成した後、ユーザーがそのロールを通じて権限を利用できるようにするため、ロールに権限を追加する必要があります。

## 前提条件

ロールに権限を追加する際、現在のユーザーは付与された権限を保有している必要があり、また `GRANT OPTION` 権限も保有していなければなりません。現在のユーザーが保有する権限に関する操作の詳細については、[ユーザー権限の確認](../400.view-user-permissions-of-mysql-mode.md)を参照してください。該当する権限がない場合は、管理者に連絡し、追加してもらってください。ユーザーに権限を直接付与する操作の詳細については、[直接権限付与](../200.authority-of-mysql-mode.md)を参照してください。

## 操作例

* `ALTER SYSTEM` 権限をロール `role1` に付与します。

  ```shell
  obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
  ```

* データベース `dbtest` 内のすべてのオブジェクトに対する `SELECT` 権限をロール `role1` に付与します。

  ```shell
  obclient [oceanbase]> GRANT SELECT ON dbtest.* TO role1;
  ```

  1つまたは複数の権限を同時に複数のロールに追加することができます。

  ```shell
  obclient [oceanbase]> GRANT SELECT,UPDATE ON dbtest.* TO role1,role2;
  ```

* テーブル `test1.tbl1` の `SELECT` オブジェクト権限をロール `role1` に付与します。

  ```shell
  obclient [oceanbase]> GRANT SELECT ON test1.tbl1 TO role1;
  ```

* テーブル `test1.tbl1` の `c1` 列の `SELECT` 権限をロール `role1` に付与します。

  ```shell
  obclient [oceanbase]> GRANT SELECT(c1) ON test1.tbl1 TO role1;
  ```
