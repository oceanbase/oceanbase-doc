# ロールの削除

不要なロールを削除するには、`DROP ROLE` ステートメントを使用します。

## 前提条件

ロールを削除するには、現在のユーザーが `CREATE USER` 権限または `DROP ROLE` 権限を持っている必要があります。現在のユーザーが持つ権限に関する操作の詳細については、[ユーザー権限の確認](../400.view-user-permissions-of-mysql-mode.md)を参照してください。該当する権限がない場合は、管理者に連絡し、追加してもらってください。ユーザーに権限を付与する操作の詳細については、[直接権限付与](../200.authority-of-mysql-mode.md)を参照してください。

## 注意事項

ロールを削除すると、システムは自動的にそのロールを、そのロールに付与されたすべてのユーザーおよびロールから取り消し、データベースから削除します。

## 操作例

* ロール `role1` を削除します。

  ```sql
  obclient [oceanbase]> DROP ROLE role1;
  ```

* ロール `role1` と `role2` を削除します。

  ```sql
  obclient [oceanbase]> DROP ROLE role1,role2;
  ```
