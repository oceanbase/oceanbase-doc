# ロール管理の概要

OceanBaseデータベースは、MySQLモードにおけるユーザーロール管理機能をサポートしています。

MySQLモードでは、ロールとは一連の権限の組み合わせです。ロールを使用することで、ユーザー権限を簡単に管理できます。

OceanBaseデータベースにおいて、ロールは以下の機能を備えています：

* 通常のユーザーと同様に、ロールにも権限を付与できます。

* ロールに他のロールを含めることができます。つまり、ロール内に他のロールを格納できます。

* 1人のユーザーに複数のロールを付与したり、1つのロールを複数のユーザーに付与したりできます。

現在、OceanBaseデータベースのMySQLモードでは、デフォルトのシステムロールはサポートされていません。
