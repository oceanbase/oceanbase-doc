# ロールから権限を取り消す

ロールから権限を取り消すことができます。

## 前提条件

ロールの権限を取り消すには、現在のユーザーが取り消す権限を持ち、かつ `GRANT OPTION` 権限を有している必要があります。現在のユーザーが持つ権限の詳細な操作については、[ユーザー権限の確認](../400.view-user-permissions-of-mysql-mode.md)を参照してください。

## 操作例

* ロール `role1` から `ALTER SYSTEM` 権限を取り消します。

  ```shell
  obclient [oceanbase]> REVOKE ALTER SYSTEM ON *.* FROM role1;
  ```

* ロール `role1` からデータベース `dbtest` 内のすべてのオブジェクトに対する `SELECT` 権限を取り消します。

  ```shell
  obclient [oceanbase]> REVOKE SELECT ON dbtest.* FROM role1;
  ```

  複数のロールのうち1つまたは複数の権限を取り消すことができます。

  ```shell
  obclient [oceanbase]> REVOKE SELECT,UPDATE ON dbtest.* FROM role1,role2;
  ```

* ロール `role1` からテーブル `test1.tbl1` の `SELECT` オブジェクト権限を取り消します。

  ```shell
  obclient [oceanbase]> REVOKE SELECT ON test1.tbl1 FROM role1;
  ```

* ロール `role1` からテーブル `test1.tbl1` の `c1` 列の `SELECT` 権限を取り消します。

  ```shell
  obclient [oceanbase]> REVOKE SELECT(c1) ON test1.tbl1 FROM role1;
  ```
