# 間接的権限付与

ユーザーの権限には、直接付与された権限と、ロールを付与された後、そのロールを通じて間接的に取得した権限が含まれます。ほとんどの操作に必要な権限は、直接付与されたものであれ、ロールを通じて間接的に持っているものであれ、条件を満たすことができます。

## ロールを付与されることで間接的に権限を取得する

ユーザーまたは他のユーザーのロールにロールを付与すると、そのロールを付与されたユーザーは、そのロールに含まれる権限を間接的に取得します。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>ユーザーは常に直接付与された権限を使用できますが、ロールを通じて間接的に取得した権限を使用できるとは限りません。ユーザーは、現在のセッションでアクティブなロールの権限のみを使用できます。ロールのアクティブ化の詳細な操作については、<a href="340.role-management-of-mysql-mode/500.activating-roles-of-mysql-mode.md">ロールのアクティブ化</a>を参照してください。</p>
</main>

### 前提条件

他のユーザーまたはロールにロールを付与する際、現在のユーザーは付与対象のロールを所有しており、かつ `ADMIN OPTION` 権限を持っている必要があります。現在のユーザーが持っている権限を確認する操作については、[ユーザー権限の確認](../200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。

### 背景

現在、ユーザー `test1` が存在し、既に `employee` というロールが付与されていると仮定します。`employee` ロールに含まれる権限を確認するステートメントは以下のとおりです：

```shell
obclient [oceanbase]> SHOW GRANTS FOR employee;
```

結果は次のとおりです：

```shell
+--------------------------------------------------+
| Grants for employee@%                            |
+--------------------------------------------------+
| GRANT USAGE ON *.* TO 'employee'                 |
| GRANT UPDATE, SELECT ON `dbtest`.* TO 'employee' |
+--------------------------------------------------+
2 rows in set
```

現在のユーザーが `developer` ロールを持っている場合、`developer` ロールに含まれる権限を確認するステートメントは以下のとおりです：

```shell
obclient [oceanbase]> SHOW GRANTS FOR developer;
```

結果は次のとおりです：

```shell
+------------------------------------------+
| Grants for developer@%                   |
+------------------------------------------+
| GRANT ALTER SYSTEM ON *.* TO 'developer' |
+------------------------------------------+
1 row in set
```

### 手順例

今回は、`developer` ロールのすべての操作権限をユーザー `test1` に付与する必要があります。間接的な権限付与を実現するには、以下の方法を使用できます：

* ユーザーにロールを付与する

  1. 現在のユーザーが `developer` ロールをユーザー `test1` に付与します。

      ```shell
      obclient [oceanbase]> GRANT developer TO test1;
      ```

      ユーザーが後からこのロールを再付与できるようにしたい場合は、`WITH ADMIN OPTION` 句を追加します。

      ```shell
      obclient [oceanbase]> GRANT developer TO test1 WITH ADMIN OPTION;
      ```

  2. `SHOW GRANTS ... USING` ステートメントを使用して、ユーザーが `developer` から取得した権限を確認します。

      ```shell
      obclient [oceanbase]> SHOW GRANTS FOR test1 USING developer;
      ```

      結果は次のとおりです：

      ```shell
      +-----------------------------------------------------+
      | Grants for test1@%                                  |
      +-----------------------------------------------------+
      | GRANT ALTER SYSTEM ON *.* TO 'test1'                |
      | GRANT `developer`@`%`,`employee`@`%` TO `test1`@`%` |
      +-----------------------------------------------------+
      2 rows in set
      ```

* ユーザーにロールを付与するロール

  1. ロール `developer` をロール `employee` に付与します。

      ```shell
      obclient [oceanbase]> GRANT developer TO employee;
      ```

  2. `SHOW GRANTS ... USING` ステートメントを使用して、ユーザー `test1` が `employee` から取得した権限を確認できます。

      ```shell
      obclient [oceanbase]> SHOW GRANTS FOR test1 USING employee;
      ```

      結果は次のとおりです：

      ```shell
      +-----------------------------------------------+
      | Grants for test1@%                            |
      +-----------------------------------------------+
      | GRANT ALTER SYSTEM ON *.* TO 'test1'          |
      | GRANT UPDATE, SELECT ON `dbtest`.* TO 'test1' |
      | GRANT `employee`@`%` TO `test1`@`%`           |
      +-----------------------------------------------+
      3 rows in set
      ```

      クエリ結果によると、ユーザー `test1` は `employee` ロールから `ALTER SYSTEM` 権限を取得しました。次に、`employee` が付与されたロールや権限を確認します。

      ```shell
      obclient [(none)]> SHOW GRANTS FOR employee;
      ```

      結果は次のとおりで、`ALTER SYSTEM` 権限は `developer` ロールから取得されたことがわかります。

      ```shell
      +--------------------------------------------------+
      | Grants for employee@%                            |
      +--------------------------------------------------+
      | GRANT USAGE ON *.* TO 'employee'                 |
      | GRANT UPDATE, SELECT ON `dbtest`.* TO 'employee' |
      | GRANT `developer`@`%` TO `employee`@`%`          |
      +--------------------------------------------------+
      3 rows in set
      ```
