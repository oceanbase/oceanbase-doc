# ユーザーの削除

`DROP USER` ステートメントを使用して、もはや使用されないユーザーを削除できます。

## 前提条件

現在のユーザーがグローバルな `CREATE USER` 権限を持っている必要があります。これにより、`DROP USER` コマンドを正常に実行できます。現在のユーザーがこの権限を持っているかどうかを確認するには、[ユーザー権限の確認](../200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)を参照してください。この権限がない場合は、管理者に連絡して該当する権限を追加してもらい、ユーザーに権限を追加する手順については、[直接権限付与](../200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)を参照してください。

## 制限

`mysql.user` テーブルに対しては、`DELETE` による権限管理はできません。

## 手順

1. ユーザーがクラスタのMySQLテナントにログインします。

2. 以下のステートメントを実行して、1人または複数のユーザーを削除します。

   ステートメントは次のとおりです：

   ```sql
   DROP USER user_name [, user_name...];
   ```

   ここで、`user_name` は削除対象のユーザー名であり、複数のユーザーを同時に削除する場合は、ユーザー名を英語のカンマ（,）で区切ります。

   ユーザーの削除に成功すると、そのユーザーが作成したデータベースオブジェクトは削除されませんが、そのユーザーのすべての権限は一緒に削除されます。

   `sqluser02` ユーザーを削除する例は次のとおりです：

   ```shell
   obclient> DROP USER sqluser02;
   Query OK, 0 rows affected
   ```
