# ユーザーの削除

`DROP USER` ステートメントを使用して、不要になったユーザーを削除できます。

## 前提条件

現在のユーザーが `DROP USER` のシステム権限を持っている必要があります。権限の確認に関する操作については、[ユーザー権限の確認](../300.permission-of-oracle-mode/600.view-user-permissions-of-oracle-mode.md)を参照してください。`DROP USER` システム権限がない場合は、管理者に連絡し、追加してもらってください。ユーザー権限の付与に関する操作については、[直接権限付与](200.authority-of-oracle-mode.md)を参照してください。

## 注意事項

<main id="notice" type='notice'>
<h4>注意</h4>
<p>ユーザーを削除すると、そのユーザーが所有するすべてのオブジェクト（権限、データベース、テーブルなど）も削除されます。慎重に操作してください。</p>
</main>

## 操作手順

1.  クラスタのOracleテナントにユーザーとしてログインします。

2.  以下のステートメントを実行して、ユーザーを削除します。

   ステートメントは以下のとおりです：

   ```sql
   DROP USER username CASCADE;
   ```

   ステートメントの説明：

   *   `CASCADE` は、ユーザーを削除する前に、そのユーザーが所有するすべてのオブジェクト（権限、データベース、テーブルなど）をシステムが削除することを示します。

   *   `username` は削除対象のユーザーを表します。単一のユーザーのみの削除をサポートします。

   `sqluser` ユーザーを削除する例を以下に示します：

   ```shell
   obclient> DROP USER sqluser CASCADE;
   Query OK, 0 rows affected
   ```
