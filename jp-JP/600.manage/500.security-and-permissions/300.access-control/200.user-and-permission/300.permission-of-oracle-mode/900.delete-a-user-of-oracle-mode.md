# ユーザーの削除

`DROP USER` ステートメントを使用して、もはや使用されないユーザーを削除できます。

## 前提条件

現在のユーザーが `DROP USER` のシステム権限を持っている必要があります。`DROP USER` コマンドを使用するには、権限に関する操作の詳細については[ユーザー権限の確認](../300.permission-of-oracle-mode/600.view-user-permissions-of-oracle-mode.md)を参照してください。`DROP USER` システム権限がない場合は、管理者に連絡して追加してもらい、ユーザーに権限を付与する操作の詳細については[直接権限付与](../300.permission-of-oracle-mode/200.authority-of-oracle-mode.md)を参照してください。

## 注意事項

<main id="notice" type='notice'>
<h4>注意</h4>
<p>ユーザーを削除すると、そのユーザーが持つすべてのオブジェクト（権限、データベース、テーブルなど）も削除されますので、慎重に操作してください。</p>
</main>

## 手順

1. ユーザーがクラスタのOracleテナントにログインします。

2. 以下のステートメントを実行して、ユーザーを削除します。

   ステートメントは次のとおりです：

   ```sql
   DROP USER username CASCADE;
   ```

   ステートメントの使用方法：

   * `CASCADE` は、ユーザーを削除する前に、そのユーザーが持つすべてのオブジェクト（権限、データベース、テーブルなど）をシステムが削除することを意味します。

   * `username` は、削除対象のユーザーを表します。単一のユーザーのみを削除できます。

   `sqluser` ユーザーを削除する例は次のとおりです：

   ```shell
   obclient> DROP USER sqluser CASCADE;
   Query OK, 0 rows affected
   ```
