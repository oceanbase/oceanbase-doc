# ロールの取り消し

`REVOKE` ステートメントを使用して、ユーザーまたは他のロールからロールを取り消すことができます。

## 前提条件

ロールを取り消す際、現在のユーザーは取り消すロールを所有している必要があり、`GRANT OPTION` 権限、または `GRANT ANY ROLE` 権限を持っている必要があります。

現在のユーザーまたはロールが所有するロールを確認する操作については、[ロールの確認](../400.manage-roles-of-oracle-mode/600.view-roles-of-oracle-mode.md)を参照してください。

## 注意事項

ロールを付与する際に `GRANT OPTION` を指定しなかった場合、取り消し操作は連鎖しません。ロールを付与する際に `GRANT OPTION` を指定した場合、取り消し操作は連鎖します。

## ステートメントと例

ロールを取り消すSQLステートメントは以下のとおりです：

* ユーザーからのロールの取り消し

  ```sql
  obclient> REVOKE role_list FROM user_name;
  ```

* ロールからのロールの取り消し

  ```sql
  obclient> REVOKE role_list FROM role_name;
  ```

複数のロールを同時に取り消す場合、ロールを半角カンマ（,）で区切ります。

例：

```sql
obclient>  REVOKE role1 FROM test;
```

`REVOKE` ステートメントの詳細については、[REVOKE](../../../../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/300.dcl-of-oracle-mode/2900.revoke-of-oracle-mode.md)を参照してください。
