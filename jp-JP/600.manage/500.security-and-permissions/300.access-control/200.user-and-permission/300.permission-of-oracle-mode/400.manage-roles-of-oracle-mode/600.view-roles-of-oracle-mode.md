# ロールの確認

システム内に存在するロールや、各ロールが持つ権限を確認できます。

## ビューを使用したロールの確認

ロールを確認するシナリオは以下のとおりです：

* システム内のロールの確認

  管理者は `DBA_ROLES` ビューを使用して、システム内のすべてのロールを確認できます。

  ```sql
  obclient> SELECT * FROM DBA_ROLES;
  +---------------------+-------------------+---------------------+
  | ROLE                | PASSWORD_REQUIRED | AUTHENTICATION_TYPE |
  +---------------------+-------------------+---------------------+
  | CONNECT             | NO                | NONE                |
  | RESOURCE            | NO                | NONE                |
  | DBA                 | NO                | NONE                |
  | PUBLIC              | NO                | NONE                |
  | STANDBY_REPLICATION | NO                | NONE                |
  | ROLE1               | NO                | NONE                |
  +---------------------+-------------------+---------------------+
  6 rows in set
  ```

  `DBA_ROLES` ビューのフィールドと説明の詳細については、[DBA_ROLES](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/18300.dba_roles-of-oracle-mode.md)を参照してください。

* ロールに含まれるロールの確認

  クエリ対象のロールを持つユーザーは、`ROLE_ROLE_PRIVS` ビューを使用して、そのロールに含まれるロールを確認できます。そのロールに他のロールが含まれていない場合、クエリ結果は空になります。

  ```sql
  obclient> SELECT * FROM ROLE_ROLE_PRIVS WHERE role='ROLE1';
  +-------+--------------+--------------+
  | ROLE  | GRANTED_ROLE | ADMIN_OPTION |
  +-------+--------------+--------------+
  | ROLE1 | ROLE2        | NO           |
  +-------+--------------+--------------+
  1 row in set
  ```

  `ROLE_ROLE_PRIVS` ビューのフィールドと説明の詳細については、[ROLE_ROLE_PRIVS](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/24300.role_role_privs-of-oracle-mode.md)を参照してください。

* ロールが持つシステム権限の確認

  管理者は `ROLE_SYS_PRIVS` ビューを使用して、特定のロールが持つシステム権限を確認できます。

  ```sql
  obclient> SELECT * FROM ROLE_SYS_PRIVS WHERE role='CONNECT';
  +---------+----------------+--------------+
  | ROLE    | PRIVILEGE      | ADMIN_OPTION |
  +---------+----------------+--------------+
  | CONNECT | CREATE SESSION | NO           |
  +---------+----------------+--------------+
  1 row in set
  ```

  `ROLE_SYS_PRIVS` ビューのフィールドと説明の詳細については、[ROLE_SYS_PRIVS](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/24400.role_sys_privs-of-oracle-mode.md)を参照してください。

* ロールが持つオブジェクト権限の確認

  現在クエリ対象のロールを持つユーザーは、`ROLE_TAB_PRIVS` ビューを使用して、そのロールが持つオブジェクト権限を確認できます。

  ```sql
  obclient> SELECT * FROM ROLE_TAB_PRIVS WHERE role='ROLE1';
  +-------+-------+------------+-------------+-----------+-----------+
  | ROLE  | OWNER | TABLE_NAME | COLUMN_NAME | PRIVILEGE | GRANTABLE |
  +-------+-------+------------+-------------+-----------+-----------+
  | ROLE1 | SYS   | T1         | NULL        | SELECT    | NO        |
  +-------+-------+------------+-------------+-----------+-----------+
  1 row in set
  ```

  `ROLE_TAB_PRIVS` ビューのフィールドと説明の詳細については、[ROLE_TAB_PRIVS](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/24500.role_tab_privs-of-oracle-mode.md)を参照してください。
