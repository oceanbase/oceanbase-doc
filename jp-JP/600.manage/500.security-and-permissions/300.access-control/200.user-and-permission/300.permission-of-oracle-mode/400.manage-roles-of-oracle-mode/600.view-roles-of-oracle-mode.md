# ロールの確認

システム内に存在するロールや、各ロールが持つ権限を確認できます。

## ビューを使用したロールの確認

ロールを確認するシナリオは以下のとおりです：

* 現在のシステム内のロールを確認する

  管理者は `DBA_ROLES` ビューを使用して、システム内のすべてのロールを確認できます。

  ```sql
  obclient> SELECT * FROM DBA_ROLES;
  +---------------------+-------------------+---------------------+
  | ROLE                | PASSWORD_REQUIRED | AUTHENTICATION_TYPE |
  +---------------------+-------------------+---------------------+
  | CONNECT             | NO                | NONE                |
  | RESOURCE            | NO                | NONE                |
  | DBA                 | NO                | NONE                |
  | PUBLIC              | NO                | NONE                |
  | STANDBY_REPLICATION | NO                | NONE                |
  | ROLE1               | NO                | NONE                |
  +---------------------+-------------------+---------------------+
  6 rows in set
  ```

  `DBA_ROLES` ビューのフィールドとその説明については、[DBA_ROLES](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/17500.dba_roles-of-oracle-mode.md) を参照してください。

* ロールが含むロールを確認する

  クエリ対象のロールを持つユーザーは、`ROLE_ROLE_PRIVS` ビューを使用して、そのロールが含むロールを確認できます。そのロールに他のロールが含まれていない場合、クエリ結果は空になります。

  ```sql
  obclient> SELECT * FROM ROLE_ROLE_PRIVS WHERE role='ROLE1';
  +-------+--------------+--------------+
  | ROLE  | GRANTED_ROLE | ADMIN_OPTION |
  +-------+--------------+--------------+
  | ROLE1 | ROLE2        | NO           |
  +-------+--------------+--------------+
  1 row in set
  ```

  `ROLE_ROLE_PRIVS` ビューのフィールドとその説明については、[ROLE_ROLE_PRIVS](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/23600.role_role_privs-of-oracle-mode.md) を参照してください。

* ロールが持つシステム権限を確認する

  管理者は `ROLE_SYS_PRIVS` ビューを使用して、特定のロールが持つシステム権限を確認できます。

  ```sql
  obclient> SELECT * FROM ROLE_SYS_PRIVS WHERE role='CONNECT';
  +---------+----------------+--------------+
  | ROLE    | PRIVILEGE      | ADMIN_OPTION |
  +---------+----------------+--------------+
  | CONNECT | CREATE SESSION | NO           |
  +---------+----------------+--------------+
  1 row in set
  ```

  `ROLE_SYS_PRIVS` ビューのフィールドとその説明については、[ROLE_SYS_PRIVS](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/23700.role_sys_privs-of-oracle-mode.md) を参照してください。

* ロールが持つオブジェクト権限を確認する

  現在クエリ対象のロールを持つユーザーは、`ROLE_TAB_PRIVS` ビューを使用して、そのロールが持つオブジェクト権限を確認できます。

  ```sql
  obclient> SELECT * FROM ROLE_TAB_PRIVS WHERE role='ROLE1';
  +-------+-------+------------+-------------+-----------+-----------+
  | ROLE  | OWNER | TABLE_NAME | COLUMN_NAME | PRIVILEGE | GRANTABLE |
  +-------+-------+------------+-------------+-----------+-----------+
  | ROLE1 | SYS   | T1         | NULL        | SELECT    | NO        |
  +-------+-------+------------+-------------+-----------+-----------+
  1 row in set
  ```

  `ROLE_TAB_PRIVS` ビューのフィールドとその説明については、[ROLE_TAB_PRIVS](../../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/23800.role_tab_privs-of-oracle-mode.md) を参照してください。
