# ロールの削除

カスタムロールは削除できますが、システムのデフォルトロールは削除できません。不要なロールを削除するには、`DROP ROLE` ステートメントを使用します。

## 前提条件

ロールを削除するには、現在のユーザーが `DROP ANY ROLE` システム権限を持ち、かつそのロールに対する `WITH ADMIN OPTION` 権限が付与されている必要があります。

現在持っている権限を確認するには、[ユーザー権限の確認](../600.view-user-permissions-of-oracle-mode.md)を参照してください。該当する権限がない場合は、管理者に連絡し、追加してもらってください。ユーザー権限の付与に関する操作については、[直接権限付与](../200.authority-of-oracle-mode.md)を参照してください。

## 注意事項

ロールを削除すると、システムはそのロールを持つすべてのユーザーおよびロールからロールを取り消し、データベースから削除します。

<main id="notice" type='notice'>
    <h4>注意</h4>
    <p>ロールの削除操作は、そのロールを有効にしたユーザーのセッションには影響しません。ただし、ロールが削除された後に新しいユーザーセッションを開始すると、その新しいセッションではそのロールを有効にできなくなります。</p>
</main>

## ステートメントと例

ロールを削除するSQLステートメントは次のとおりです：

```sql
obclient> DROP ROLE role_name;
```

例：

```sql
obclient> DROP ROLE role1;
Query OK, 0 rows affected
```

`DROP ROLE` ステートメントの詳細については、[DROP ROLE](../../../../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/3600.drop-role-of-oracle-mode.md)を参照してください。
