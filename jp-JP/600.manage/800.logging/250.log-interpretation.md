# ログの解読

OceanBaseデータベースのログ解読ガイドを紹介します。各ログ機能の解説、ログの特定、ログ構造、重要なシナリオにおけるログ解読などを網羅しています。

## observer.log

マスターサービスプロセスの実行ログであり、選挙とRootServiceを除くすべてのモジュールの操作を記録します。これにはSQL解析、トランザクション実行、ストレージエンジンの動作などが含まれます。

### OBServer起動ログ

OBServer起動ログは、プロセスの初期化およびサービスの準備完了に関する重要なイベントを記録し、起動段階で発生した問題の診断に利用されます。

* **ログの特定方法**

  キーワード`[NOTICE]`を検索して特定します。

* **ログ特定コマンド**

  ```log
  [admin@OB /home/admin/oceanbase/log] $grep "NOTICE" observer.log
  ```

* **典型的な出力例**

  ```log
  [2023-05-11 14:19:09.703272] INFO  [SERVER] ob_server.cpp:533 [95303][0][Y0-0000000000000000-0-0] [lt=9] [dc=0] [NOTICE] server instance start succeed

  [2023-05-11 14:19:25.555836] INFO  [SERVER] ob_server.cpp:609 [95303][0][Y0-0000000000000000-0-0] [lt=16] [dc=0] [NOTICE] observer start service(start_service_time=1683785965555827)
  ```

* **主要フィールドの説明**

  | ログ情報                      | 説明                                                                                     |
  | ----------------------------- | ---------------------------------------------------------------------------------------- |
  | server instance start succeed | OBServerプロセスが正常に起動しました。                                                                  |
  | observer start service        | OBServerの起動が完了し、サービス提供を開始しました。`start_service_time`はOBServerがサービス提供を開始したタイムスタンプです。 |

### 統計ログ

#### テナントディスク統計

テナントのディスク使用状況を10秒ごとに出力します。

* **ログの特定方法**

  キーワード `ob_tenant_disk_usage_mgr.cpp` または `dump tenant disk usage update info` で検索して特定します。

* **ログの特定コマンド**

  ```log
  [admin@OB /home/admin/oceanbase/log] $grep "ob_tenant_disk_usage_mgr.cpp" observer.log
  ```

  または

  ```log
  [admin@OB /home/admin/oceanbase/log] $grep "dump tenant disk usage update info" observer.log
  ```

* **典型的な出力例**

  ```log
  [2023-05-15 17:30:59.055858] INFO  [STORAGE] ob_tenant_disk_usage_mgr.cpp:69 [87424][0][Y0-0000000000000000-0-0] [lt=11] [dc=0] dump tenant disk usage update info(disk_usage={tenant_id:1, max_disk_size:0, used_data_size:935329792, used_meta_size:56623104})
  ```

* **主要フィールドの説明**

  | ログ情報       | 説明                                                      |
  | -------------- | --------------------------------------------------------- |
  | tenant_id      | テナントID。                                                 |
  | max_disk_size  | テナントのディスク上限(V4.x より前のバージョンではテナントのディスク使用量に制限はありません)。 |
  | used_data_size | テナント内のユーザーデータが使用するディスク容量。                            |
  | used_meta_size | テナント内の管理データが使用するディスク容量。                            |
