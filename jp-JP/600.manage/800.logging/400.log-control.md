# ログ制御方式

ログ制御方式には、クラスタ構成パラメータ、テナントシステム変数、SQLヒント、シグナルなどが含まれます。これらの方法を使用して、システムログに関連する動作を管理および制御できます。

## パラメータによる制御

システムログ関連のクラスタパラメータ：

| パラメータ名 | デフォルト値 | 機能の説明 |
|----------------------------------------------------|--------|--------------------------------------------------------------------|
| [enable_syslog_recycle](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/9200.enable_syslog_recycle.md) | False | 起動前の古いログを記録するスイッチを有効にするかどうかを設定します。|
| [enable_syslog_wf](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/9300.enable_syslog_wf.md)                       | True  | WARN以上のレベルのシステムログを別のログファイル（ログファイルの拡張子は`wf`）に出力するかどうかを設定します。|
| [enable_async_syslog](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/6300.enable_async_syslog.md)                       | True  | `observer.log`、`election.log`、および`rootservice.log`に対してシステムログの非同期書き込みを有効にするかどうかを設定します。|
| [max_syslog_file_count](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/13600.max_syslog_file_count.md) | 0     | ログファイルの回収前に収容できる最大ログファイル数を設定します。|
| [syslog_io_bandwidth_limit](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22700.syslog_io_bandwidth_limit.md) | 30MB  | システムログが占用できるディスクI/O帯域幅の上限を設定します。帯域幅の上限容量を超えるシステムログは破棄されます。値が0の場合、システムログは無効になります。 |
| [syslog_level](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22800.syslog_level.md)                       | WDIAG  | システムログレベルを設定します。 |
| [syslog_disk_size](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22500.syslog_disk_size.md)                       | 0M | システムログのディスク容量上限を設定します。システムログの総サイズがこの上限に達しようとすると、最も古いログファイルが削除されます。圧縮済みのログファイルも含まれます。 |
| [syslog_compress_func](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22400.syslog_compress_func.md)  | none | システムログの圧縮アルゴリズムを設定します。 |
| [syslog_file_uncompressed_count](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22600.syslog_file_uncompressed_count.md) | 0 | システムログを圧縮しないファイル数を設定します。このパラメータは`syslog_compress_func`の値が`none`以外の場合にのみ有効であり、各種システムログファイルごとに個別にカウントされます。 |
| [alert_log_level](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/100.alert_log_level.md) | INFO | アラートログのレベルを設定します。 |

## システム変数による制御

テナントのシステム変数 `ob_log_level` は、セッションレベルのログレベルを制御します。`ob_log_level` の詳細については、[ob_log_level](../../700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/8000.ob_log_level-global.md)を参照してください。
