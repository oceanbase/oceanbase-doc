# テナントのホワイトリストの確認と設定

テナントのホワイトリスト機能を使用すると、現在のテナントにアクセスを許可するクライアントを設定できます。

## 背景情報

テナントのホワイトリストとは、そのテナントがログインを許可するクライアントのリストを指します。これは、システム変数 `ob_tcp_invited_nodes` の値によって決定され、デフォルトではローカルのIPアドレスです。業務のニーズに応じて、テナントのホワイトリストをカスタマイズできます。システムは以下の複数のテナントホワイトリスト形式をサポートしています：

* IPアドレスの形式：`10.10.10.10,10.10.10.11`

* サブネット/マスクの形式：`10.10.10.0/24`

* あいまい一致の形式：`10.10.10.%` または `10.10.10._`

* 複数形式の混合形式：`10.10.10.10,10.10.10.11,10.10.10.%,10.10.10._,10.10.10.0/24`

## テナントのホワイトリストの確認

1. テナント管理者がデータベースにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster  -A
    ```

2. テナントのホワイトリストを確認します。

    ```shell
    obclient> SHOW VARIABLES LIKE 'ob_tcp_invited_nodes';
    +----------------------+-------+
    | Variable_name        | Value |
    +----------------------+-------+
    | ob_tcp_invited_nodes | %     |
    +----------------------+-------+
    ```

## テナントのホワイトリストの設定

テナントのホワイトリストは、sysテナントの管理者ユーザーまたは該当テナントの管理者によって変更できます。

### sysテナント管理者によるテナントホワイトリストの変更

1. rootユーザーでクラスタのsysテナントにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. テナントのホワイトリスト設定を変更します。

    ```shell
    obclient> ALTER TENANT mq_t1 VARIABLES ob_tcp_invited_nodes = '10.10.10.%';
    ```

### ユーザーテナント管理者による自身テナントのホワイトリストの変更

1. テナント管理者がデータベースにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster  -A
    ```

2. テナントのホワイトリスト設定を変更します。

    ```shell
    obclient> SET GLOBAL ob_tcp_invited_nodes='10.10.10.%';
    ```

3. 設定が成功した後、現在のセッションを終了し、再ログインして設定を有効にします。

4. 変更結果を確認します。

    ```shell
    obclient> SHOW VARIABLES LIKE 'ob_tcp_invited_nodes';
    +----------------------+------------+
    | Variable_name        | Value      |
    +----------------------+------------+
    | ob_tcp_invited_nodes | 10.10.10.% |
    +----------------------+------------+
    ```
