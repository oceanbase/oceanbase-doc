# リソースグループの削除

使用されなくなったリソースグループを削除するには、`DBMS_RESOURCE_MANAGER`システムパッケージの`DELETE_CONSUMER_GROUP`サブルーチンを呼び出します。

## 前提条件

削除対象のリソースグループが存在していることを確認してください。

## 注意事項

リソースグループを削除すると、そのリソースグループに関連付けられたリソース管理計画の内容も連鎖的に削除されます。

## 手順

1. テナント管理者としてクラスタのOracleテナントにログインします。

2. `DBMS_RESOURCE_MANAGER`システムパッケージの`DELETE_CONSUMER_GROUP`サブルーチンを呼び出してリソースグループを削除します。

   ```sql
   obclient [SYS]> delimiter //

   obclient [SYS]]> BEGIN DBMS_RESOURCE_MANAGER.DELETE_CONSUMER_GROUP(
   CONSUMER_GROUP => 'big_group'
   );
   END ;//

   obclient [SYS]> delimiter ;
   ```

   ここで、`CONSUMER_GROUP`は削除対象のリソースグループ名を指定するために使用されます。

3. 実行が成功した後、`DBA_RSRC_CONSUMER_GROUPS`ビューを確認して確認できます。

   ```sql
   obclient [SYS]> SELECT CONSUMER_GROUP_ID, CONSUMER_GROUP, COMMENTS FROM DBA_RSRC_CONSUMER_GROUPS;
   +-------------------+----------------+-----------------+
   | CONSUMER_GROUP_ID | CONSUMER_GROUP | COMMENTS        |
   +-------------------+----------------+-----------------+
   |                 4 | GROUP1         | Transaction Processing Group |
   |                 0 | OTHER_GROUPS   | NULL            |
   |                 3 | SMALL_GROUP    | AP              |
   |                 1 | SYS_GROUP      | NULL            |
   +-------------------+----------------+-----------------+
   4 rows in set
   ```

   `DBA_RSRC_CONSUMER_GROUPS`ビューの詳細については、[DBA_RSRC_CONSUMER_GROUPS](../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/17600.dba_rsrc_consumer_groups-of-oracle-mode.md)を参照してください。
