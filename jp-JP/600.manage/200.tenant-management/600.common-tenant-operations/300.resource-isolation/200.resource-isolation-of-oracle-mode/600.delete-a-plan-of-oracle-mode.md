# リソース管理計画の削除

使用されていないリソース管理計画を削除するには、`DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_PLAN` サブプログラムを呼び出します。

## 前提条件

削除対象のリソース管理計画が存在することを確認してください。

## 注意事項

リソース管理計画を削除すると、そのリソース管理計画に関連付けられた内容も連鎖的に削除されます。

## 操作手順

1. テナント管理者としてクラスタのOracleテナントにログインします。

2. `DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_PLAN` サブプログラムを呼び出してリソース管理計画を削除します。

   ```sql
   obclient [SYS]> delimiter //

   obclient [SYS]> BEGIN DBMS_RESOURCE_MANAGER.DELETE_PLAN(
   PLAN => 'plan_a'
   );
   END ;//

   obclient [SYS]> delimiter ;
   ```

   ここで、`PLAN` は削除対象のリソース管理計画を指定するために使用されます。

3. 実行が成功した後、`DBA_RSRC_PLANS` ビューで確認できます。

   ```sql
   obclient [SYS]> SELECT PLAN_ID, PLAN, SUB_PLAN, COMMENTS FROM DBA_RSRC_PLANS;
   +---------+--------+----------+----------+
   | PLAN_ID | PLAN   | SUB_PLAN | COMMENTS |
   +---------+--------+----------+----------+
   |    NULL | PLAN_B | NULL     | NULL     |
   +---------+--------+----------+----------+
   1 row in set
   ```

   `DBA_RSRC_PLANS` ビューの詳細については、[DBA_RSRC_PLANS](../../../../../700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/18700.dba_rsrc_plans-of-oracle-mode.md)を参照してください。
