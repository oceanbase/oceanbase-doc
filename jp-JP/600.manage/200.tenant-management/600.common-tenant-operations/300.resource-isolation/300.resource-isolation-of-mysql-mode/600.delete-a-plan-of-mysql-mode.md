# リソース管理計画の削除

`DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_PLAN` サブプログラムを呼び出して、使用されていないリソース管理計画を削除できます。

## 前提条件

削除対象のリソース管理計画が存在することを確認してください。

## 注意事項

リソース管理計画を削除すると、そのリソース管理計画に関連する内容も連鎖的に削除されます。

## 手順

1. テナント管理者としてクラスタのMySQLテナントにログインします。

2. `DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_PLAN` サブプログラムを呼び出してリソース管理計画を削除します。

   ```sql
   obclient [test]> CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN(
   PLAN => 'daytime'
   );
   ```

   ここで、`PLAN` は削除対象のリソース管理計画を指定するために使用されます。

3. 実行が成功した後、`oceanbase.DBA_RSRC_PLANS` ビューで確認できます。

   ```sql
   +---------+------+----------+-----------------------------------+
   | PLAN_ID | PLAN | SUB_PLAN | COMMENTS                          |
   +---------+------+----------+-----------------------------------+
   |    NULL | DAY  | NULL     | 该资源计划用于事务处理              |
   +---------+------+----------+-----------------------------------+
   1 row in set
   ```

   `oceanbase.DBA_RSRC_PLANS` ビューの詳細については、[oceanbase.DBA_RSRC_PLANS](../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/14000.o-dba_rsrc_plans-mysql.md)を参照してください。
