# リソース管理計画の削除

`DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_PLAN` ステートメントを使用して、使用されていないリソース管理計画を削除できます。

## 前提条件

削除するリソース管理計画が存在することを確認してください。

## 注意事項

リソース管理計画を削除すると、そのリソース管理計画に関連付けられたリソース管理計画の内容も連鎖的に削除されます。

## 手順

1. テナント管理者としてクラスタのMySQLテナントにログインします。

2. `DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_PLAN` ステートメントを呼び出して、リソース管理計画を削除します。

   ```sql
   obclient [test]> CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN(
   PLAN => 'daytime'
   );
   ```

   ここで、`PLAN` は削除するリソース管理計画を指定するために使用されます。

3. 実行が成功した場合、`oceanbase.DBA_RSRC_PLANS` ビューを確認してください。

   ```sql
   +---------+------+----------+-----------------------------------+
   | PLAN_ID | PLAN | SUB_PLAN | COMMENTS                          |
   +---------+------+----------+-----------------------------------+
   |    NULL | DAY  | NULL     | このリソース計画はトランザクション処理に使用されます              |
   +---------+------+----------+-----------------------------------+
   1 row in set
   ```

   `oceanbase.DBA_RSRC_PLANS` ビューの詳細については、[oceanbase.DBA_RSRC_PLANS](../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/13700.o-dba_rsrc_plans-mysql.md)を参照してください。
