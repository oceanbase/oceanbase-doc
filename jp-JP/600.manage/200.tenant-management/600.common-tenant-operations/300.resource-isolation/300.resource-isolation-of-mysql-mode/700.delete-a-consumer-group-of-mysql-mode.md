# リソースグループの削除

使用されなくなったリソースグループを削除するには、`DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_CONSUMER_GROUP` サブプログラムを呼び出します。

## 前提条件

削除対象のリソースグループが存在することを確認してください。

## 注意事項

リソースグループを削除すると、そのリソースグループに関連付けられたリソース管理計画の内容も連鎖的に削除されます。

## 手順

1. テナント管理者としてクラスタのMySQLテナントにログインします。

2. `DBMS_RESOURCE_MANAGER` システムパッケージの `DELETE_CONSUMER_GROUP` サブプログラムを呼び出してリソースグループを削除します。

   ```sql
   obclient [test]> CALL DBMS_RESOURCE_MANAGER.DELETE_CONSUMER_GROUP(
   CONSUMER_GROUP => 'interactive_group'
   );
   ```

   ここで、`CONSUMER_GROUP` は削除対象のリソースグループ名を指定するために使用されます。

3. 実行が成功した後、`oceanbase.DBA_RSRC_CONSUMER_GROUPS` ビューを確認して確認できます。

   ```sql
   obclient [test]> SELECT CONSUMER_GROUP_ID, CONSUMER_GROUP, COMMENTS FROM oceanbase.DBA_RSRC_CONSUMER_GROUPS;
   +-------------------+----------------+-----------------+
   | CONSUMER_GROUP_ID | CONSUMER_GROUP | COMMENTS        |
   +-------------------+----------------+-----------------+
   |                 5 | batch_group    | AP              |
   |                 2 | group1         | トランザクション処理グループ      |
   |                 3 | group2         | 日常運用保守グループ      |
   |                 0 | OTHER_GROUPS   | NULL            |
   |                 1 | SYS_GROUP      | NULL            |
   +-------------------+----------------+-----------------+
   5 rows in set
   ```

   `oceanbase.DBA_RSRC_CONSUMER_GROUPS` ビューの詳細については、[oceanbase.DBA_RSRC_CONSUMER_GROUPS](../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/13800.o-dba_rsrc_group_mappings.md)を参照してください。
