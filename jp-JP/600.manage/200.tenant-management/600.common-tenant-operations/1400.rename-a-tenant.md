# テナントの名前変更

テナントを作成した後、`sys` テナントは通常のテナント名を変更できます。

現在、OceanBaseデータベースでは通常のテナント名の変更のみをサポートしています。

## 注意事項

コマンドライン（`ALTER TENANT` コマンド）を使用してテナント名を変更すると、OCP上でそのテナントが利用不可と表示されます。OCPを使用してテナントを管理する必要がある場合は、OCP上で関連操作を実行してください。OCP上でのテナント名変更に関する説明については、[OceanBase テナント FAQ](https://en.oceanbase.com/docs/common-ocp-10000000002169284)を参照してください。

## 手順

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 通常のテナント名を変更します。

   ステートメントは以下のとおりです：

   ```sql
   ALTER TENANT old_tenant_name RENAME GLOBAL_NAME TO new_tenant_name;
   ```

   テナント `tenant1` の名前を `tenant2` に変更する例を以下に示します：

   ```shell
   obclient> ALTER TENANT tenant1 RENAME GLOBAL_NAME TO tenant2;
   ```
