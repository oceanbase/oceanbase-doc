# テナントの名前変更

テナントを作成した後、`sys` テナントは通常のテナントの名前を変更できます。

現在、OceanBaseデータベースは通常のテナントの名前の変更のみをサポートしています。

## 注意事項

コマンドライン（`ALTER TENANT` コマンド）を使用してテナント名を変更すると、OCP上でそのテナントが利用不可と表示されるようになります。OCPを使用してテナントを管理する必要がある場合は、OCP上で関連操作を行ってください。OCP上でのテナント名前変更の詳細については、[OceanBaseテナントのよくある質問](https://www.oceanbase.com/docs/common-ocp-1000000002380975)を参照してください。

## 手順

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 通常のテナントの名前を変更します。

   ステートメントは以下のとおりです：

   ```sql
   ALTER TENANT old_tenant_name RENAME GLOBAL_NAME TO new_tenant_name;
   ```

   テナント `tenant1` のテナント名を `tenant2` に変更する例は以下のとおりです：

   ```shell
   obclient> ALTER TENANT tenant1 RENAME GLOBAL_NAME TO tenant2;
   ```
