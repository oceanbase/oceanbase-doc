# テナントのシステム変数を確認する

システム変数の設定により、OceanBaseデータベースの動作を業務要件に合わせることができます。本記事では、テナントのシステム変数を確認する方法について説明します。

## SHOWステートメントを使用してテナントのシステム変数を確認する

1. rootユーザーでクラスタのユーザーテナントにログインします。

   `mq_t1` テナントを例とします：

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
    ```

2. SHOWステートメントを使用してシステム変数情報をクエリします。

   構文は以下のとおりです：

   ```sql
   SHOW [SESSION | GLOBAL] VARIABLES [LIKE 'pattern' | WHERE expr]
   ```

   パラメータ説明：

   * `SESSION | GLOBAL`：SESSIONはセッション変数、GLOBALはグローバル変数を表します。指定しない場合、デフォルトでSession変数を確認します。
   * `pattern`：変数のキーワードを表します。

   例：

   * `ob_query_timeout` のSessionレベル変数をクエリします。

      ```shell
      obclient [oceanbase]> SHOW VARIABLES LIKE 'ob_query_timeout';
      ```

      または

      ```shell
      obclient [oceanbase]> SHOW SESSION VARIABLES LIKE 'ob_query_timeout';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +------------------+-------------+
      | Variable_name    | Value       |
      +------------------+-------------+
      | ob_query_timeout | 10000000    |
      +------------------+-------------+
      1 row in set
      ```

   * `ob_query_timeout` のGlobalレベル変数をクエリします。

      ```shell
      obclient [oceanbase]> SHOW GLOBAL VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +------------------+-------------+
      | Variable_name    | Value       |
      +------------------+-------------+
      | ob_query_timeout | 10000000    |
      +------------------+-------------+
      1 row in set
      ```

## ビューを使用してテナントのシステム変数を確認する

:::tab
tab MySQLモード

1. rootユーザーでクラスタの`mysql001`テナントにログインします。

      ```shell
      obclient -P2881 -h172.30.xx.xx -uroot@mysql001#cluster -p**** -A -Doceanbase
      ```

2. `oceanbase`データベースに移動します。

      ```shell
      obclient [(none)]> USE oceanbase;
      ```

3. ビューを使用して変数値をクエリします。

   * `INFORMATION_SCHEMA.SESSION_VARIABLES`ビューを使用して、`ob_query_timeout`のセッションレベル変数値をクエリします。

      ```shell
      obclient [oceanbase]> SELECT * FROM INFORMATION_SCHEMA.SESSION_VARIABLES WHERE VARIABLE_NAME = 'ob_query_timeout';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +------------------+----------------+
      | VARIABLE_NAME    | VARIABLE_VALUE |
      +------------------+----------------+
      | ob_query_timeout | 10000000       |
      +------------------+----------------+
      1 row in set
      ```

   * `INFORMATION_SCHEMA.GLOBAL_VARIABLES`ビューを使用して、`ob_query_timeout`のグローバルレベル変数値をクエリします。

      ```shell
      obclient [oceanbase]> SELECT * FROM INFORMATION_SCHEMA.GLOBAL_VARIABLES WHERE VARIABLE_NAME = 'ob_query_timeout';
      ```

      クエリ結果は次のとおりです：

      ```shell
      +------------------+----------------+
      | VARIABLE_NAME    | VARIABLE_VALUE |
      +------------------+----------------+
      | ob_query_timeout | 10000000       |
      +------------------+----------------+
      1 row in set
      ```

   * ビュー`DBA_OB_SYS_VARIABLES`を使用して、`ob_query_timeout`変数値の変更履歴とデフォルト値をクエリします。

     ```shell
     obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
     ```

     クエリ結果は次のとおりです：

     ```shell
     +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
     | CREATE_TIME                | MODIFY_TIME                | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
     +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
     | 2024-05-08 14:22:06.882646 | 2024-05-08 14:22:06.882646 | ob_query_timeout | 10000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | YES       |
     +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
     1 row in set
     ```

tab Oracleモード

1. `SYS`ユーザーでクラスタの`oracle001`テナントにログインします。

   ```shell
   obclient -h172.30.xx.xx -P2883 -usys@oracle001#cluster -p**** -A
   ```

2. ビューを使用して変数値を照会します。

   * `SYS.TENANT_VIRTUAL_SESSION_VARIABLE`ビューを使用して、`ob_query_timeout`のセッションレベル変数値をクエリします。

      ```shell
      obclient [SYS]> SELECT * FROM SYS.TENANT_VIRTUAL_SESSION_VARIABLE WHERE VARIABLE_NAME = 'ob_query_timeout';
      +------------------+----------+
      | VARIABLE_NAME    | VALUE    |
      +------------------+----------+
      | ob_query_timeout | 10000000 |
      +------------------+----------+
      1 row in set
      ```

   * `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`ビューを使用して、`ob_query_timeout`のグローバルレベル変数値をクエリします。

      ```shell
      obclient [SYS]> SELECT * FROM SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE WHERE VARIABLE_NAME = 'ob_query_timeout';
      +------------------+----------+
      | VARIABLE_NAME    | VALUE    |
      +------------------+----------+
      | ob_query_timeout | 10000000 |
      +------------------+----------+
      1 row in set
      ```

   * `DBA_OB_SYS_VARIABLES`ビューを使用して、`ob_query_timeout`変数値の変更履歴とデフォルト値をクエリします。

     ```shell
     obclient [SYS]> SELECT * FROM SYS.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
     ```

