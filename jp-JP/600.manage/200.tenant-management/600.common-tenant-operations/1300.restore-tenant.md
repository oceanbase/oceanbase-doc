# テナントのリストア

悪意のある、または誤った操作によって生じるデータの不可逆的な損失を防ぐため、OceanBaseデータベースはリサイクルビン機能を提供し、テナントレベルのデータの迅速なリストアをサポートしています。本記事では、リサイクルビン内のテナントをリストアする方法について説明します。

OceanBaseデータベースは `FLASHBACK TENANT` ステートメントを使用して、リサイクルビン内のテナントをリストアできます。

## 使用上の制限

現在、テナントを削除できるのは`sys`テナントのみであるため、MySQLモードおよびOracleモードのテナントが削除された場合、それらは`sys`テナントのリサイクルビンに移動します。また、テナントのリストア操作も`sys`テナントのみが実行できます。

## 操作手順

1. rootユーザーでクラスタのsysテナントにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. `oceanbase`データベースに入ります。

    ```shell
    obclient(root@sys)[(none)]> USE oceanbase;
    ```

3. `SHOW RECYCLEBIN`ステートメントを使用して、現在のシステムテナントのリサイクルビン内のオブジェクトを確認します。

    ```shell
    obclient(root@sys)[oceanbase]> SHOW RECYCLEBIN;
    ```

    実行結果は次のとおりです：

    ```shell
    +-------------------------------------+---------------+--------+----------------------------+
    | OBJECT_NAME                         | ORIGINAL_NAME | TYPE   | CREATETIME                 |
    +-------------------------------------+---------------+--------+----------------------------+
    | __recycle_$_100017_1673367572701376 | mq_t1         | TENANT | 2023-01-11 00:23:36.317242 |
    +-------------------------------------+---------------+--------+----------------------------+
    1 row in set
    ```

    リサイクルビン関連パラメータの詳細については、[recyclebin](../../../700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/11200.recyclebin-global.md)を参照してください。

4. `FLASHBACK TENANT`ステートメントを使用して、リサイクルビン内のテナントをリストアします。

    テナント`mq_t1`のリストアを例にします：

    ```shell
    obclient(root@sys)[oceanbase]> FLASHBACK TENANT mq_t1 TO BEFORE DROP;
    ```

    `FLASHBACK TENANT`ステートメントの詳細については、[FLASHBACK](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5400.flashback-database-of-mysql-mode.md)を参照してください。

5. `DBA_OB_TENANTS`ビューとリサイクルビンを確認し、実行結果を確認します。

    ```shell
    obclient(root@sys)[oceanbase]> SHOW RECYCLEBIN;
    Empty set
    ```

    クエリ結果が空の場合、`DBA_OB_TENANTS`ビューを確認し、テナントがリストアされたことを確認します。

    ```shell
    obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE, CREATE_TIME, MODIFY_TIME, PRIMARY_ZONE, LOCALITY, COMPATIBILITY_MODE, STATUS FROM DBA_OB_TENANTS WHERE TENANT_NAME = 'mq_t1';
    ```

    実行結果は次のとおりです：

    ```shell
    +-----------+-------------+-------------+----------------------------+----------------------------+--------------+------------------------------+--------------------+--------+
    | TENANT_ID | TENANT_NAME | TENANT_TYPE | CREATE_TIME                | MODIFY_TIME                | PRIMARY_ZONE | LOCALITY                     | COMPATIBILITY_MODE | STATUS |
    +-----------+-------------+-------------+----------------------------+----------------------------+--------------+------------------------------+--------------------+--------+
    |      1036 | mq_t1       | USER        | 2023-01-11 00:23:36.317242 | 2023-05-18 15:49:12.857944 | zone1;zone2  | FULL{1}@zone1, FULL{1}@zone2 | MYSQL              | NORMAL |
    +-----------+-------------+-------------+----------------------------+----------------------------+--------------+------------------------------+--------------------+--------+
    1 row in set
    ```
