# リソース仕様の確認

リソースプールを作成する前に、適切なリソーステンプレートを選択するために、リソース仕様を確認する必要があります。

## 手順

リソースユニットとは、サーバーリソースの使用テンプレートと考えることができます。ビューを照会することで、現在のクラスタ内に既存するリソースユニットの構成情報を知ることができます。

確認方法は以下のとおりです：

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

2. 以下のステートメントを実行して、クラスタ内のすべてのリソース仕様を確認します。

   ```sql
   obclient> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS\G
   *************************** 1. row ***************************
   UNIT_CONFIG_ID: 1
             NAME: sys_unit_config
          MAX_CPU: 2.5
          MIN_CPU: 2.5
      MEMORY_SIZE: 17179869184
    LOG_DISK_SIZE: 17179869184
         MAX_IOPS: 25000
         MIN_IOPS: 25000
      IOPS_WEIGHT: 2
   *************************** 2. row ***************************
   UNIT_CONFIG_ID: 1001
             NAME: unit001
          MAX_CPU: 1
          MIN_CPU: 1
      MEMORY_SIZE: 6442450944
    LOG_DISK_SIZE: 19327352832
         MAX_IOPS: 10000
         MIN_IOPS: 10000
      IOPS_WEIGHT: 1
   *************************** 3. row ***************************
   UNIT_CONFIG_ID: 1002
             NAME: unit002
          MAX_CPU: 1
          MIN_CPU: 1
      MEMORY_SIZE: 6442450944
    LOG_DISK_SIZE: 19327352832
         MAX_IOPS: 10000
         MIN_IOPS: 10000
      IOPS_WEIGHT: 1
   3 rows in set
   ```
