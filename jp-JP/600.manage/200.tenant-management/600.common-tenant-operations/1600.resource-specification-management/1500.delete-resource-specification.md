# リソーススペックの削除

本記事では、リソーススペックを削除する方法について説明します。

## 前提条件

リソーススペックを削除する前に、現在のリソース仕様が使用されていないことを確認する必要があります。リソース仕様が使用中の場合は、まずリソースプールからリソース仕様を削除してから、リソース仕様を削除する必要があります。詳細な操作については、[リソースプールの属性の変更](../900.modify-resource-pool-properties.md)を参照してください。

## 操作手順

1. rootユーザーでクラスタのsysテナントにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. `oceanbase` データベースに移動します。

    ```shell
    obclient [(none)]> USE oceanbase;
    ```

3. `DBA_OB_UNIT_CONFIGS` および `DBA_OB_RESOURCE_POOLS` ビューを確認し、リソーススペックの使用状況を確認します。

    例：クエリ結果の `UNIT_NAME` 列に該当するリソーススペック名がない場合、そのリソース構成はリソースプールに割り当てられていないことを意味します。クエリ結果の `UNIT_NAME` 列に該当するリソース構成名がある場合、そのリソース構成はリソースプールに割り当てられていることを意味します。

    リソーススペック `S2_unit_config` が使用されていないことを確認します。

    ```shell
    obclient [oceanbase]> SELECT a.UNIT_CONFIG_ID, a.NAME AS UNIT_NAME, b.NAME AS POOL_NAME FROM oceanbase.DBA_OB_UNIT_CONFIGS a,oceanbase.DBA_OB_RESOURCE_POOLS b WHERE b.UNIT_CONFIG_ID=a.UNIT_CONFIG_ID;
    +----------------+-------------------------------+--------------------------+
    | UNIT_CONFIG_ID | UNIT_NAME                     | POOL_NAME                |
    +----------------+-------------------------------+--------------------------+
    |              1 | sys_unit_config               | sys_pool                 |
    |           1001 | config_mysql001_zone1_S1_okz  | pool_mysql001_zone1_okz  |
    |           1002 | config_mysql001_zone2_S1_pme  | pool_mysql001_zone2_pme  |
    |           1003 | config_mysql001_zone3_S1_jsu  | pool_mysql001_zone3_jsu  |
    |           1013 | config_oracle001_zone3_S1_exu | pool_oracle001_zone3_exu |
    |           1014 | config_oracle001_zone2_S1_hli | pool_oracle001_zone2_hli |
    |           1015 | config_oracle001_zone1_S1_owy | pool_oracle001_zone1_owy |
    |           1020 | S1_unit_config                | mq_pool_01               |
    +----------------+-------------------------------+--------------------------+
    8 rows in set
    ```

    `DBA_OB_UNIT_CONFIGS` ビューの詳細については、[DBA_OB_UNIT_CONFIGS](../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23700.o-dba_ob_unit_configs-of-sys-tenant.md)を参照してください。

    `DBA_OB_RESOURCE_POOLS` ビューの詳細については、[DBA_OB_RESOURCE_POOLS](../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/21000.o-dba_ob_resource_pools-of-sys-tenant.md)を参照してください。

4. `DROP RESOURCE UNIT` ステートメントを使用して、リソーススペックを削除します。

    リソース構成 `S2_unit_config` の削除を例とします：

    ```shell
    obclient [oceanbase]> DROP RESOURCE UNIT S2_unit_config;
    Query OK, 0 rows affected
    ```

    `DROP RESOURCE UNIT` ステートメントの詳細については、[DROP RESOURCE UNIT](../../../../700.reference/500.sql-reference/100.sql-syntax/100.system-tenants/1000.drop-resource-unit.md)を参照してください。

5. `DBA_OB_UNIT_CONFIGS` ビューを確認し、リソーススペックが正常に削除されたことを確認します。

    ```shell
    obclient [oceanbase]> SELECT * FROM DBA_OB_UNIT_CONFIGS WHERE NAME = 'S2_unit_config';
    Empty set
    ```
