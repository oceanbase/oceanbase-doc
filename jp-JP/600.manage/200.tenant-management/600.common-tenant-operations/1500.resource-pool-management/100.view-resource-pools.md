# リソースプールの確認

リソースプールが正常に作成された後、クラスタ内のリソースプールおよび各リソースプールの状況を確認できます。

## 手順

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

2. 以下のステートメントを実行して、クラスタ内のリソースプール情報を確認します。

    ```sql
    obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS\G
    *************************** 1. row ***************************
    RESOURCE_POOL_ID: 1
                NAME: sys_pool
           TENANT_ID: 1
         CREATE_TIME: 2022-11-15 14:26:23.038148
         MODIFY_TIME: 2022-11-15 14:26:23.044325
          UNIT_COUNT: 1
      UNIT_CONFIG_ID: 1
           ZONE_LIST: zone1
        REPLICA_TYPE: FULL
    *************************** 2. row ***************************
    RESOURCE_POOL_ID: 1001
                NAME: pool_mysql001_zone1_bmg
           TENANT_ID: 1002
         CREATE_TIME: 2022-11-15 14:50:41.839785
         MODIFY_TIME: 2022-11-15 14:50:41.923685
          UNIT_COUNT: 1
      UNIT_CONFIG_ID: 1001
           ZONE_LIST: zone1
        REPLICA_TYPE: FULL
    *************************** 3. row ***************************
    RESOURCE_POOL_ID: 1002
                NAME: pool_mysql002_zone1_pej
           TENANT_ID: 1004
         CREATE_TIME: 2022-11-15 14:51:22.271744
         MODIFY_TIME: 2022-11-15 14:51:22.321220
          UNIT_COUNT: 1
      UNIT_CONFIG_ID: 1002
           ZONE_LIST: zone1
        REPLICA_TYPE: FULL
    *************************** 4. row ***************************
    RESOURCE_POOL_ID: 1003
                NAME: pool_oracle001_zone1_zco
           TENANT_ID: 1006
         CREATE_TIME: 2022-11-15 14:51:49.622973
         MODIFY_TIME: 2022-11-15 14:51:49.675680
          UNIT_COUNT: 1
      UNIT_CONFIG_ID: 1003
           ZONE_LIST: zone1
        REPLICA_TYPE: FULL
    *************************** 5. row ***************************
    RESOURCE_POOL_ID: 1004
                NAME: pool_oracle002_zone1_mjh
           TENANT_ID: 1008
         CREATE_TIME: 2022-11-15 14:55:10.986570
         MODIFY_TIME: 2022-11-15 14:55:11.036814
          UNIT_COUNT: 1
      UNIT_CONFIG_ID: 1004
           ZONE_LIST: zone1
        REPLICA_TYPE: FULL
    5 rows in set
    ```

    ここで：

    * `RESOURCE_POOL_ID`：リソースプールID。各リソースプールには一意のIDが割り当てられます。

    * `TENANT_ID`：このリソースプールが属するテナントID。各テナントには一意のIDが割り当てられます。`sys`テナントのテナントIDは`1`です。現在のテナントの詳細情報の確認方法については、[テナントとリソース情報の確認](../400.view-tenant-information.md)を参照してください。

       クエリ結果で`TENANT_ID`が`NULL`の場合、現在のリソースプールにはテナントが紐づけられていないことを意味します。このリソースプールをテナントに割り当てることができます。リソースプールをテナントに割り当てる手順の詳細については、[リソースプールのテナントへの割り当て](../1500.resource-pool-management/200.assign-a-resource-pool-to-a-tenant.md)を参照してください。

    * `UNIT_COUNT`：リソースプール内のリソースユニットの数。

    * `UNIT_CONFIG_ID`：リソースプールに対応するリソースユニット構成ID。一つのリソースユニットには一つの構成IDが対応します。

       リソースユニットに対応するリソースユニット構成の確認方法については、[リソースユニット構成の確認](../1600.resource-specification-management/100.view-resource-unit-configuration.md)を参照してください。

    * `ZONE_LIST`：リソースプールのZoneリストを示し、そのリソースプールのリソースがどのZoneで使用されているかを示します。
