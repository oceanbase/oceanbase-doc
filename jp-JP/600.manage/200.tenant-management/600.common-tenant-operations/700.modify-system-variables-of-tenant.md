# テナントのシステム変数の変更

システム変数の設定により、OceanBaseデータベースの動作をビジネス要件に合わせることができます。本記事では、テナントのシステム変数を変更する方法について説明します。

テナントのシステム変数は `SET` ステートメントを使用して変更できます。

* セッションレベルの変数を設定しても、その変更は現在のセッション内でのみ有効であり、他のセッションには反映されません。
* グローバルレベルの変数を設定しても、現在のセッションには無効です。変更を有効にするには、再ログインして新しいセッションを確立する必要があります。

  <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>グローバルレベルの変数を設定する場合、MySQLテナントでは現在のユーザーが <code>SUPER</code> 権限または <code>ALTER SYSTEM</code> 権限を持っている必要があります。Oracleテナントでは、<code>ALTER SYSTEM</code> 権限が必要です。設定する前に、ご自身の権限を確認してください。ユーザー権限の詳細については、<a href="../../500.security-and-permissions/300.access-control/200.user-and-permission/100.user-and-permission-overview.md">ユーザーと権限の概要</a>を参照してください。</p>
  </main>

以下の例で使用されているシステム変数 `ob_query_timeout` は、SQL文のクエリ操作のタイムアウト時間を設定するために使用されます。単位はマイクロ秒です。大規模なデータのクエリ操作を実行する際に、システム変数 `ob_query_timeout` の値を大きく設定することで、クエリのタイムアウトによる文の実行失敗を防ぐことができます。

## セッションレベルのシステム変数の変更

1. rootユーザーでクラスタのユーザーテナントにログインします。

   `mq_t1` テナントにログインする例を示します：

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
    ```

2. テナントのセッションレベルのシステム変数を確認します。

    ```shell
    obclient [(none)]> SHOW VARIABLES LIKE 'ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 10000000 |
    +------------------+----------+
    1 row in set
    ```

3. `SET` を使用してセッションレベルの変数値を変更します。

    ```shell
    obclient [oceanbase]> SET ob_query_timeout = 20000000;
    ```

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>Oracleモードでは、<code>ALTER SESSION SET ob_query_timeout = 20000000;</code> ステートメントを使用してセッションレベルの変数値を変更することもできます。</p>
    </main>

4. 変更結果を確認します。

    ```shell
    obclient [(none)]> SHOW VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 20000000 |
    +------------------+----------+
    1 row in set
    ```

## グローバルレベルのシステム変数の変更

1. rootユーザーでクラスタのユーザーテナントにログインします。

   `mq_t1` テナントにログインする例を示します：

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
    ```

2. テナントのグローバル変数を確認します。

    ```shell
    obclient [(none)]> SHOW GLOBAL VARIABLES WHERE variable_name LIKE  'ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 10000000 |
    +------------------+----------+
    1 row in set
    ```

3. `SET` を使用してグローバル変数の値を変更します。

    ```shell
    obclient [oceanbase]> SET GLOBAL ob_query_timeout = 20000000;
    ```

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>Oracleモードでは、<code>ALTER SYSTEM SET ob_query_timeout = 20000000;</code> ステートメントを使用してグローバル変数の値を変更することもできます。</P>
    </main>

4. 変更結果を確認します。

    ```shell
    obclient [(none)]> SHOW GLOBAL VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 20000000 |
    +------------------+----------+
    1 row in set
    ```

    変更が成功した後、ビュー `DBA_OB_SYS_VARIABLES` を使用して `ob_query_timeout` 変数の詳細な変更履歴とデフォルト値を確認することもできます。ステートメントは以下のとおりです。

    ```shell
    obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    | CREATE_TIME                | MODIFY_TIME                | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    | 2024-05-08 14:20:28.885780 | 2024-05-09 15:11:11.654128 | ob_query_timeout | 20000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | NO        |
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    1 row in set
    ```

## ブール型変数の変更

`SHOW VARIABLES` コマンドでON/OFFとして表示される変数は、以下のいずれかの方法で変数値を設定できます。

```sql
SET foreign_key_checks = ON;
SET foreign_key_checks = TRUE;
SET foreign_key_checks = 1;

SET GLOBAL foreign_key_checks = OFF;
SET GLOBAL foreign_key_checks = FALSE;
SET GLOBAL foreign_key_checks = 0;
```

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>ON/OFF、TRUE/FALSE、または1/0の3つの方法でブール型変数を設定することは、同じ効果があります。</p>
</main>
