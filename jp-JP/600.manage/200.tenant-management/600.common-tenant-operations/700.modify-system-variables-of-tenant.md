# テナントシステム変数の変更

システム変数の設定により、OceanBaseデータベースの動作を業務要件に合わせることができます。本記事では、テナントシステム変数の変更方法について説明します。

テナントのシステム変数は、`SET` ステートメントを使用して変更できます。

* セッションレベルの変数は、現在のセッションにのみ有効であり、他のセッションには影響しません。
* グローバルレベルの変数は、現在のセッションには無効であり、再ログイン後に新しいセッションを確立すると有効になります。

  <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>グローバルレベルの変数を設定する場合、MySQLテナントでは現在のユーザーに <code>SUPER</code> 権限または <code>ALTER SYSTEM</code> 権限が付与されている必要があります。Oracleテナントでは、現在のユーザーに <code>ALTER SYSTEM</code> 権限が付与されている必要があります。設定する前に、ご自身の権限を確認してください。ユーザー権限の詳細については、<a href="../../500.security-and-permissions/300.access-control/200.user-and-permission/100.user-and-permission-overview.md">ユーザーと権限の概要</a> を参照してください。</p>
  </main>

以下の例で使用されるシステム変数 `ob_query_timeout` は、SQL文のクエリ操作に対するタイムアウト時間を設定します。単位はマイクロ秒です。大量データのクエリ操作を行う際には、システム変数 `ob_query_timeout` の値を大きくすることで、クエリのタイムアウトによる文の実行失敗を防ぐことができます。

## セッションレベルのシステム変数を変更する

1. 管理者ユーザーまたは一般ユーザーがクラスタにログインします。

   `mq_t1` テナントにログインする場合を例に説明します：

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
    ```

2. テナントのセッションレベルのシステム変数を照会します。

      ```shell
      obclient [(none)]> SHOW VARIABLES LIKE 'ob_query_timeout';
      ```

      照会結果は次のとおりです：

      ```shell
      +------------------+----------+
      | Variable_name    | Value    |
      +------------------+----------+
      | ob_query_timeout | 10000000 |
      +------------------+----------+
      1 row in set
      ```

3. `SET` を使用して、セッションレベルの変数値を変更します。

    :::tab
    タブ MySQLモード

    MySQLモードでは、以下の方法でセッションレベル変数を変更できます。

    ```shell
    obclient [oceanbase]> SET ob_query_timeout = 20000000;
    ```

    または

    ```shell
    obclient [oceanbase]> SET ob_query_timeout := 20000000;
    ```

    tab Oracleモード

    Oracleモードでは、以下の方法でセッションレベルの変数を変更できます。

    ```shell
    obclient [SYS]> SET ob_query_timeout = 20000000;
    ```

    または

    ```shell
    obclient [SYS]> ALTER SESSION SET ob_query_timeout = 20000000;
    ```

    :::

4. 変更結果を確認します。

    ```sql
    obclient [(none)]> SHOW VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
    ```

    照会結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 20000000 |
    +------------------+----------+
    1 row in set
    ```

## グローバルレベルのシステム変数を変更する

1. 管理者ユーザーでクラスタのユーザーテナントにログインします。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>MySQLモードのデフォルト管理者ユーザーは<code>root</code>ユーザー、Oracleモードのデフォルト管理者ユーザーは<code>SYS</code>ユーザーです。 </p>
   </main>

   `mq_t1`テナントにログインする場合を例にします：

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
    ```

2. テナントのグローバル変数を照会します。

    ```sql
    obclient [(none)]> SHOW GLOBAL VARIABLES WHERE variable_name LIKE  'ob_query_timeout';
    ```

    照会結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 10000000 |
    +------------------+----------+
    1 row in set
    ```

3. `SET`を使用してグローバル変数の値を変更します。

    :::tab
    タブ MySQLモード

    MySQLモードでは、以下の方法でグローバル変数を変更できます。

    ```shell
    obclient [oceanbase]> SET GLOBAL ob_query_timeout = 20000000;
    ```

    または

    ```shell
    obclient [oceanbase]> SET GLOBAL ob_query_timeout := 20000000;
    ```

    tab Oracleモード

    Oracleモードでは、以下の方法でグローバル変数を変更できます。

    ```shell
    obclient [SYS]> SET GLOBAL ob_query_timeout = 20000000;
    ```

    または

    ```shell
    obclient [SYS]> ALTER SYSTEM SET ob_query_timeout = 20000000;
    ```

    :::

4. 変更結果を確認します。

    ```shell
    obclient [(none)]> SHOW GLOBAL VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 20000000 |
    +------------------+----------+
    1 row in set
    ```

    変更が成功した後、ビュー`DBA_OB_SYS_VARIABLES`を使用して`ob_query_timeout`変数の詳細な変更状況とデフォルト値を照会することもできます。ステートメントは以下のとおりです。

    ```sql
    obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
    ```

    照会結果は次のとおりです：

    ```shell
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    | CREATE_TIME                | MODIFY_TIME                | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    | 2023-12-08 14:00:20.583506 | 2023-12-12 11:51:46.237099 | ob_query_timeout | 20000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | NO        |
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    1 row in set
    ```

## ブール型変数の変更

`SHOW VARIABLES` コマンドでON/OFFとして表示される変数は、以下のいずれかの方法で変数値を設定できます。

```sql
SET foreign_key_checks = ON;
SET foreign_key_checks = TRUE;
SET foreign_key_checks = 1;

SET GLOBAL foreign_key_checks = OFF;
SET GLOBAL foreign_key_checks = FALSE;
SET GLOBAL foreign_key_checks = 0;
```

<main id="notice" type='explain'>
 <h4>説明</h4>
 <p>ON/OFF、TRUE/FALSE、または1/0の3つの方法でブール型変数を設定することは、同等です。</p>
</main>
