# リソースプールのプロパティを変更する

リソースプールのプロパティを変更するとは、リソースプールの構成パラメータである `UNIT`、`UNIT_NUM`、`ZONE_LIST` などの値を調整することです。本記事では、リソースプールのプロパティを変更する方法について説明します。

リソースプールのプロパティは、`ALTER RESOURCE POOL` ステートメントを使用して変更できます。

テナントのリソースプールのプロパティを変更することは、テナントのスケーリングアップまたはスケーリングダウンを実現する別の方法です。例えば、`UNIT_NUM` を増やすことで、各ゾーン内のノード数を増やし、スケールアップを図ることができます。

## 手順

1. rootユーザーでクラスタのsysテナントにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. `oceanbase`データベースに移動します。

    ```shell
    obclient [(none)]> USE oceanbase;
    ```

3. `DBA_OB_RESOURCE_POOLS`ビューを使用して、リソースプールの構成情報を取得します。

    リソースプール`mq_pool_02`の構成情報を照会する例を示します：

    ```shell
    obclient(root@sys)[oceanbase]> SELECT * FROM DBA_OB_RESOURCE_POOLS WHERE NAME = 'mq_pool_02';
    ```

    照会結果は次のとおりです：

    ```shell
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------+--------------+
    | RESOURCE_POOL_ID | NAME       | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST   | REPLICA_TYPE |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------+--------------+
    |             1026 | mq_pool_02 |      NULL | 2023-01-10 23:54:24.177685 | 2023-01-10 23:54:24.177685 |          1 |           1020 | zone1;zone2 | FULL         |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------+--------------+
    1 row in set
    ```

    `DBA_OB_RESOURCE_POOLS`ビューの詳細については、[DBA_OB_RESOURCE_POOLS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/20000.o-dba_ob_resource_pools-of-sys-tenant.md)を参照してください。

4. `ALTER RESOURCE POOL`ステートメントを使用して、リソースプールの構成を変更します。

    <main id="notice" type='notice'>
     <h4>注意</h4>
     <p><ul><li>単一のステートメントでは1つのプロパティのみを変更できます。<code>UNIT</code>、<code>UNIT_NUM</code>、<code>ZONE_LIST</code>のうち2つ以上のプロパティを同時に変更する必要がある場合は、複数のステートメントで実行する必要があります。</li><li><code>ZONE_LIST</code>を変更する際は、一度に追加または削除できるゾーンは1つのみです。</li></ul></p>
    </main>

    構文は以下のとおりです：

    ```sql
    ALTER RESOURCE POOL pool_name
        UNIT [=] unit_name,
        UNIT_NUM [=] unit_num,
        ZONE_LIST [=] ('zone' [, 'zone' ...]);
    ```

    パラメータの説明：

    * `pool_name`：リソースプール名。
    * `UNIT`：このリソースプールのリソース仕様。
    * `UNIT_NUM`：リソースユニット数。Unit数を増やす場合、`UNIT_NUM`の値は各Zone内のOBServer数を超えてはなりません。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>V4.2.5バージョンでは、OceanBaseデータベースはV4.2.5 BP5バージョンから異種Zoneモードをサポートしています。<code>UNIT_NUM</code>を変更する際には、次の点に注意してください：<ul><li>同一構成Zoneモードでは、リソースプールが既にテナントによって使用されている場合、<code>ALTER RESOURCE POOL</code>ステートメントでの変更はできず、<code>ALTER RESOURCE TENANT</code>ステートメントを使用して変更する必要があります。</li>
      <li>異種Zoneモードでは、リソースプールが既にテナントによって使用されていても、<code>ALTER RESOURCE POOL</code>ステートメントで変更できます。ただし、変更時には、1テナント内の複数リソースプールで最大でも2種類の異なる<code>UNIT_NUM</code>であることが求められます。<p>例えば、あるテナントが3つのリソースプール<code>pool1</code>、<code>pool2</code>、<code>pool3</code>を持ち、それぞれの<code>unit_num</code>が2、4、4である場合、<code>pool3</code>の<code>unit_num</code>を1に変更すると、システムは<code>More than two distinct unit_num in a single tenant not allowed</code>エラーを返します。</p></li>
      </ul></p>
      </main>

    * `ZONE_LIST`：リソースプールのZone分布。

    例：

    :::tab
    tab 同型ゾーンモード

    * リソースプールがテナントに割り当てられていない場合

      リソースプール `mq_pool_02` のリソース仕様を `'S2_unit_config'` に変更し、リソースユニット数を3、`ZONE_LIST` を `'zone1','zone2','zone3'` に設定します。

        ```shell
        obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT='S2_unit_config';
        Query OK, 0 rows affected

        obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT_NUM=3;
        Query OK, 0 rows affected

        obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 ZONE_LIST=('zone1','zone2','zone3');
        Query OK, 0 rows affected
        ```

    * リソースプールがテナントに割り当てられている場合

      同型ゾーンモードでは、リソースプールがテナントに割り当てられた後、テナントのリソースプール構成を変更する際には、`UNIT_NUM` を `ALTER RESOURCE TENANT` ステートメントを使用して変更する必要があります。

      リソースプール `mq_pool_02` のリソース仕様を `'S2_unit_config'` に変更し、リソースユニット数を3、ZONE_LIST を `'zone1','zone2','zone3'` に設定します。

        ```shell
        obclient(root@sys)[oceanbase]>  ALTER RESOURCE POOL mq_pool_02 UNIT='S2_unit_config';
        Query OK, 0 rows affected

        obclient(root@sys)[oceanbase]> ALTER RESOURCE TENANT mq_t2 UNIT_NUM=3;
        Query OK, 0 rows affected

        obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 ZONE_LIST=('zone1','zone2','zone3');
        Query OK, 0 rows affected
        ```

    タブ 異種ゾーンモード

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>通常、既存のテナントまたはアップグレードされたテナントについては、デフォルトで同一種ゾーンモードとなります。異種ゾーンモードを有効にするには、テナントレベルの構成パラメータ <code>zone_deploy_mode</code> の値を <code>hetero</code>（異種ゾーンモード）に変更する必要があります。変更後、<code>homo</code>（同一種ゾーンモード）に戻すことはサポートされません。</p>
    </main>

    リソースプール `mq_pool_02` のリソース仕様をそれぞれ `'S2_unit_config'` に、リソースユニット数を3に、`ZONE_LIST` を `'zone1','zone2','zone3'` に変更します。

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT='S2_unit_config';
    ```

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT_NUM=3;
    ```

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE TENANT mq_t2 UNIT_NUM=3;
    ```

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 ZONE_LIST=('zone1','zone2','zone3');
    ```

    :::

5. `DBA_OB_RESOURCE_POOLS`ビューを確認し、リソースプールの構成変更結果を確認します。

    結果は次のとおりで、`UNIT_COUNT`、`UNIT_CONFIG_ID`、`ZONE_LIST`パラメータが更新されたことがわかります。

    ```shell
    obclient(root@sys)[oceanbase]> SELECT * FROM DBA_OB_RESOURCE_POOLS WHERE NAME = 'mq_pool_02';
    ```

    照会結果は次のとおりです：

    ```shell
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------------+--------------+
    | RESOURCE_POOL_ID | NAME       | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST         | REPLICA_TYPE |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------------+--------------+
    |             1026 | mq_pool_02 |      NULL | 2023-01-10 23:54:24.177685 | 2023-01-10 23:56:04.961771 |          2 |           1021 | zone1;zone2;zone3 | FULL         |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------------+--------------+
    1 row in set
    ```
