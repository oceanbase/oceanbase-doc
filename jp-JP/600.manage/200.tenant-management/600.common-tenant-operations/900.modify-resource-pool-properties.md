# リソースプール属性の変更

リソースプール属性を変更するとは、リソースプールの設定パラメータである `UNIT`、`UNIT_NUM`、`ZONE_LIST` などを調整することです。本記事では、リソースプール属性の変更方法について説明します。

リソースプール属性は `ALTER RESOURCE POOL` ステートメントを使用して変更できます。

テナントのリソースプール属性を変更することは、テナントのスケールアウトまたはスケールインを実現する別の方法です。例えば、`UNIT_NUM` を増やすことで、各ゾーン内のノード数を増やし、スケールアウトを実現できます。

## 手順

1. rootユーザーでクラスタのsysテナントにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. `oceanbase`データベースに入ります。

    ```shell
    obclient(root@sys)[(none)]> USE oceanbase;
    ```

3. `DBA_OB_RESOURCE_POOLS`ビューを使用して、リソースプールの設定情報を取得します。

    リソースプール`mq_pool_02`の設定情報を取得する例を示します：

    ```shell
    obclient(root@sys)[oceanbase]> SELECT * FROM DBA_OB_RESOURCE_POOLS WHERE NAME = 'mq_pool_02';
    ```

    クエリ結果は次のとおりです：

    ```shell
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------+--------------+
    | RESOURCE_POOL_ID | NAME       | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST   | REPLICA_TYPE |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------+--------------+
    |             1026 | mq_pool_02 |      NULL | 2023-01-10 23:54:24.177685 | 2023-01-10 23:54:24.177685 |          1 |           1020 | zone1;zone2 | FULL         |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------+--------------+
    1 row in set
    ```

    `DBA_OB_RESOURCE_POOLS`ビューの詳細については、[DBA_OB_RESOURCE_POOLS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/21000.o-dba_ob_resource_pools-of-sys-tenant.md)を参照してください。

4. `ALTER RESOURCE POOL`ステートメントを使用して、リソースプールの設定を変更します。

    <main id="notice" type='notice'>
     <h4>注意</h4>
     <p><ul><li>単一のステートメントでは1つのパラメータのみを変更できます。<code>UNIT</code>、<code>UNIT_NUM</code>、<code>ZONE_LIST</code>のうち2つ以上を同時に変更する必要がある場合は、複数のステートメントに分けて実行する必要があります。</li><li><code>ZONE_LIST</code>を変更する際は、1回につき1つのZoneの追加または削除のみをサポートします。</li></ul></p>
    </main>

    構文は以下のとおりです：

    ```sql
    ALTER RESOURCE POOL pool_name
        UNIT [=] unit_name,
        UNIT_NUM [=] unit_num,
        ZONE_LIST [=] ('zone' [, 'zone' ...]);
    ```

    パラメータの説明：

    * `pool_name`：リソースプール名。
    * `UNIT`：このリソースプールのリソース仕様。
    * `UNIT_NUM`：リソースユニットの数です。Unit数を増やす場合、`UNIT_NUM`の値は各Zone内のOBServerの数を超えてはなりません。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>現在のバージョンは異種Zoneモードをサポートしています。<code>UNIT_NUM</code>を変更する際：
      <ul><li>同種Zoneモードでは、このリソースプールが既にテナントで使用されている場合、<code>ALTER RESOURCE POOL</code>ステートメントでの変更はできません。<code>ALTER RESOURCE TENANT</code>ステートメントを使用して変更する必要があります。</li>
      <li>異種Zoneモードでは、リソースプールが既にテナントで使用されていても、<code>ALTER RESOURCE POOL</code>ステートメントで変更できます。ただし、変更時には、1つのテナント内の複数のリソースプールで、最大でも2種類の異なる<code>UNIT_NUM</code>を持つ必要があります。<p>例えば、あるテナントが3つのリソースプール<code>pool1</code>、<code>pool2</code>、<code>pool3</code>を持ち、それぞれの<code>unit_num</code>が2、4、4である場合、<code>pool3</code>の<code>unit_num</code>を1に変更すると、システムは<code>More than two distinct unit_num in a single tenant not allowed</code>エラーを返します。</p></li>
      </ul></p>
      </main>

      `ALTER RESOURCE POOL`ステートメントの詳細については、[ALTER RESOURCE POOL](../../../700.reference/500.sql-reference/100.sql-syntax/100.system-tenants/300.alter-resource-pool.md)を参照してください。

      `ALTER RESOURCE TENANT`ステートメントの詳細については、[ALTER RESOURCE TENANT](../../../700.reference/500.sql-reference/100.sql-syntax/100.system-tenants/300.alter-resource-tenant.md)を参照してください。

    * `ZONE_LIST`：リソースプールのZone配置。

    例：

    :::tab
    tab 同種ゾーンモード

    * リソースプールがテナントに割り当てられていない場合

      リソースプール `mq_pool_02` のリソース構成を `'S2_unit_config'`、リソースユニット数を3、`ZONE_LIST` を `'zone1','zone2','zone3'` に変更します。

      ```shell
      obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT='S2_unit_config';
      ```

      ```shell
      obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT_NUM=3;
      ```

      ```shell
      obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 ZONE_LIST=('zone1','zone2','zone3');
      ```

    * リソースプールがテナントに割り当てられている場合

      同一ゾーンモードでは、リソースプールがテナントに割り当てられた後、そのテナントのリソースプール構成を変更する場合、`UNIT_NUM` は `ALTER RESOURCE TENANT` ステートメントを使用して変更する必要があります。

      リソースプール `mq_pool_02` のリソース構成を `'S2_unit_config'`、リソースユニット数を3、ZONE_LIST を `'zone1','zone2','zone3'` に変更します。

      ```shell
      obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT='S2_unit_config';
      ```

      ```shell
      obclient(root@sys)[oceanbase]> ALTER RESOURCE TENANT mq_t2 UNIT_NUM=3;
      ```

      ```shell
      obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 ZONE_LIST=('zone1','zone2','zone3');
      ```

    tab 異種ゾーンモード

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>通常、既存のテナントまたはアップグレードされたテナントは、デフォルトで同種ゾーンモードになっています。異種ゾーンモードを有効にするには、テナントレベルの構成パラメータ <code>zone_deploy_mode</code> の値を <code>hetero</code>（異種ゾーンモード）に変更する必要があります。変更後は、<code>homo</code>（同種ゾーンモード）に戻すことはできません。</p>
    </main>

    リソースプール `mq_pool_02` のリソース仕様を `'S2_unit_config'`、リソースユニット数を3、`ZONE_LIST` を `'zone1','zone2','zone3'` にそれぞれ変更します。

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT='S2_unit_config';
    ```

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 UNIT_NUM=3;
    ```

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE TENANT mq_t2 UNIT_NUM=3;
    ```

    ```shell
    obclient(root@sys)[oceanbase]> ALTER RESOURCE POOL mq_pool_02 ZONE_LIST=('zone1','zone2','zone3');
    ```

    :::

5. `DBA_OB_RESOURCE_POOLS`ビューを確認し、リソースプール設定の変更結果を確認します。

    結果は以下のとおりで、`UNIT_COUNT`、`UNIT_CONFIG_ID`、`ZONE_LIST`パラメータが更新されていることが確認できます。

    ```shell
    obclient(root@sys)[oceanbase]> SELECT * FROM DBA_OB_RESOURCE_POOLS WHERE NAME = 'mq_pool_02';
    ```

    クエリ結果は次のとおりです：

    ```shell
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------------+--------------+
    | RESOURCE_POOL_ID | NAME       | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST         | REPLICA_TYPE |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------------+--------------+
    |             1026 | mq_pool_02 |      NULL | 2023-01-10 23:54:24.177685 | 2023-01-10 23:56:04.961771 |          2 |           1021 | zone1;zone2;zone3 | FULL         |
    +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-------------------+--------------+
    1 row in set
    ```
