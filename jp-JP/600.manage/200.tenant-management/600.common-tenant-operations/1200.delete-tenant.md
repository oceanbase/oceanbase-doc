# テナントの削除

OceanBaseデータベースでは、`DROP TENANT` ステートメントを使用してテナントを削除できます。

テナントを削除すると、そのテナント配下のデータベースやテーブルも同時に削除されます。ただし、テナントが使用していたリソースプールは削除されません。リソースプールは他のテナントで引き続き利用できます。

* システムテナントでリサイクルビン機能が有効な場合、`DROP TENANT` 操作により削除されるテナントはリサイクルビンに移動します。リサイクルビン内のテナントについては、システムテナントがテナントレベルのリサイクルビン機能を通じて、そのテナントを後から完全に削除またはリストアすることが可能です。リサイクルビンに関する操作の詳細は、[リサイクルビンの概要](../../400.high-availability/500.recyclebin-management/100.recyclebin-overview.md)を参照してください。

* システムテナントでゴミ箱機能が無効な場合、`DROP TENANT` 操作によりテナントは直接削除され、テナント配下のデータベースやテーブルも同時に削除されます。

## 操作手順

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. `oceanbase`データベースに移動します。

    ```shell
    obclient(root@sys)[(none)]> USE oceanbase;
    ```

3. `DBA_OB_TENANTS`ビューを使用して、テナント情報を確認します。テナントのID、作成日時、リソース割り当てなどの基本情報に基づき、削除対象のテナントを確認します。

   テナント`mq_t1`の情報を照会する例を以下に示します：

    ```shell
    obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE, CREATE_TIME, PRIMARY_ZONE, LOCALITY, COMPATIBILITY_MODE, STATUS FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'mq_t1';
    ```

    クエリ結果は次のとおりです：

    ```shell
    +-----------+-------------+-------------+----------------------------+--------------+---------------+--------------------+--------+
    | TENANT_ID | TENANT_NAME | TENANT_TYPE | CREATE_TIME                | PRIMARY_ZONE | LOCALITY      | COMPATIBILITY_MODE | STATUS |
    +-----------+-------------+-------------+----------------------------+--------------+---------------+--------------------+--------+
    |      1036 | mq_t1       | USER        | 2023-01-11 00:23:36.317242 | zone1;zone2  | FULL{1}@zone1 | MYSQL              | NORMAL |
    +-----------+-------------+-------------+----------------------------+--------------+---------------+--------------------+--------+
    1 row in set
    ```

    `DBA_OB_TENANTS`ビューの詳細については、[DBA_OB_TENANTS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23100.o-dba_ob_tenants-of-sys-tenant.md)を参照してください。

4. （オプション）悪意のある、または誤った操作によって生じるデータの不可逆的な損失を防ぐため、OceanBaseデータベースはテナントレベルのリサイクルビン機能を提供し、テナントレベルのデータの迅速なリストアをサポートします。リサイクルビンはデフォルトで無効になっていますが必要に応じて、テナントレベルのリサイクルビン機能を有効にすることができます。リサイクルビンの詳細については、[リサイクルビン](../../400.high-availability/500.recyclebin-management/100.recyclebin-overview.md)を参照してください。

    システムテナントで`SHOW RECYCLEBIN`ステートメントを使用すると、現在のシステムテナントRECYCLEBIN内のリサイクルビンオブジェクトを確認できます。例：

    ```shell
    obclient(root@sys)[oceanbase]> SHOW RECYCLEBIN;
    ```

    実行結果は次のとおりです：

    ```shell
    +--------------------------------+----------------+----------+----------------------------+
    | OBJECT_NAME                    | ORIGINAL_NAME  | TYPE     | CREATETIME                 |
    +--------------------------------+----------------+----------+----------------------------+
    | __recycle_$_1_1600136460199936 | obdemo_table   | TABLE    | 2020-09-15 10:21:00.207886 |
    | __recycle_$_1_1600136479664128 | obdemo_database| DATABASE | 2020-09-15 10:21:19.664534 |
    | __recycle_$_1_1600135793000960 | omysql         | TENANT   | 2020-09-15 10:23:25.773877 |
    +--------------------------------+----------------+----------+----------------------------+
    3 rows in set
    ```

    パラメータ説明：

    * `OBJECT_NAME`：リサイクルビン内のオブジェクト名を表します。
    * `ORIGINAL_NAME`：元のオブジェクト名を表します。
    * `TYPE`：リサイクルビンオブジェクトが属するタイプを表します。現在主にINDEX、TABLE、DATABASE、TENANTの4種類をサポートしています。この例では、omysqlはテナントタイプのごみ箱オブジェクトです。
    * `CREATETIME`：そのオブジェクトがリサイクルビンに入った時間を表します。

5. `DROP TENANT`ステートメントを使用して、テナントを削除します。

    ```shell
    obclient(root@sys)[oceanbase]> DROP TENANT mq_t1;
    ```

    `DROP TENANT`ステートメントの詳細については、[DROP TENANT](../../../700.reference/500.sql-reference/100.sql-syntax/100.system-tenants/1100.drop-tenant.md)を参照してください。

6. `DBA_OB_TENANTS`ビューを確認し、テナントが正常に削除されたことを確認します。

    ```shell
    obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'mq_t1';
    Empty set
    ```

7. （オプション）手順4でリサイクルビン機能を有効にした場合は、`SHOW RECYCLEBIN`ステートメントを使用してリサイクルビン内の情報を確認できます。

    ```shell
    obclient(root@sys)[oceanbase]> SHOW RECYCLEBIN;
    ```

    クエリ結果は次のとおりです：

    ```shell
    +-------------------------------------+---------------+--------+----------------------------+
    | OBJECT_NAME                         | ORIGINAL_NAME | TYPE   | CREATETIME                 |
    +-------------------------------------+---------------+--------+----------------------------+
    | __recycle_$_100017_1673367572701376 | mq_t1         | TENANT | 2023-01-11 00:23:36.317242 |
    +-------------------------------------+---------------+--------+----------------------------+
    1 row in set
    ```

    リサイクルビン関連パラメータの詳細については、[recyclebin](../../../700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/11200.recyclebin-global.md)を参照してください。
