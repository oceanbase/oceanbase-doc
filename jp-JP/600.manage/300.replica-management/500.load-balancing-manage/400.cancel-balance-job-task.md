# バランスジョブのキャンセル

各テナントは同一時刻に1つのロードバランシングジョブ（Balance Job）しか実行できません。現在進行中のバランスジョブが業務要件を満たしていない場合、このバランスジョブをキャンセルすることができます。また、パーティション移動（Transfer Partition）を開始したにもかかわらず、現在実行中のバランスジョブによりパーティション移動タスクのスケジューリングが遅延している場合は、まず現在のバランスジョブをキャンセルすることができます。

## 制限

Balance Jobのキャンセル操作は、プライマリデータベース（すなわちプライマリテナント）でのみ実行できます。

## 背景

各テナントでは同時に1つのロードバランシングジョブ（JOB）しか実行できません。これらのロードバランシングジョブには、スケールアップ、スケールダウン、移行バランシング、パーティションバランシングなどが含まれます。各ロードバランシングジョブは、複数のロードバランシングタスク（Task）を生成し、ロードバランシングの具体的な操作を実現します。Balance Jobをキャンセルすると、そのBalance Jobの下で実行中のすべてのタスクがキャンセルされます。

## システムテナントによる進行中のBalance Jobのキャンセル

1. `root`ユーザーでクラスタの`sys`テナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. ビュー`CDB_OB_BALANCE_JOBS`を照会して、現在実行中のタスクを取得します。

   ```shell
   obclient [oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   クエリ結果の例は次のとおりです：

   ```shell
   +-----------+---------+------------+--------+
   | TENANT_ID | JOB_ID  | JOB_TYPE   | STATUS |
   +-----------+---------+------------+--------+
   |      1002 | 1187958 | LS_BALANCE | DOING  |
   +-----------+---------+------------+--------+
   ```

3. クエリ結果に基づき、タスクが期待通りでない場合は、以下の操作を実行してBalance Jobをキャンセルできます。

   ```sql
   ALTER SYSTEM CANCEL BALANCE JOB TENANT = 'tenant_name';
   ```

   例：

   ```shell
   obclient [oceanbase]> ALTER SYSTEM CANCEL BALANCE JOB TENANT ='mysql_tenant';
   ```

## ユーザーテナントによる進行中のBalance Jobのキャンセル

1. MySQLモードまたはOracleモードのテナント管理者がデータベースに接続します。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. ビュー`DBA_OB_BALANCE_JOBS`を照会して、現在実行中のタスクを取得します。

   :::tab
   タブ MySQLモード

   MySQLモードのクエリステートメントは次のとおりです：

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

   tab Oracleモード

   Oracleモードのクエリステートメントは以下のとおりです：

   ```shell
   obclient [SYS]> SELECT * FROM SYS.DBA_OB_BALANCE_JOBS;
   ```
   :::

3. クエリ結果に基づき、期待に応えない場合は、以下の操作を実行してBalance Jobをキャンセルできます。

   ```shell
   obclient> ALTER SYSTEM CANCEL BALANCE JOB;
   ```
