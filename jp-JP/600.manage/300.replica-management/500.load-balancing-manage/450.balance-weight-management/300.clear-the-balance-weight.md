# パーティション重みのクリア

パーティション重みを設定した後、業務上の必要に応じて、元の設定をクリアすることができます。

## 制限事項

* V4.2.5バージョンでは、V4.2.5 BP2バージョンからパーティション重みの手動クリアがサポートされています。

* パーティション重みの手動クリアはユーザーテナントのみでサポートされており、システムテナントではサポートされていません。

* テーブルレベルのパーティション重みをクリアすると、すべてのパーティションに設定されたテーブルレベルの重みが削除されます。このテーブルにパーティションレベルの重みが設定されている場合、システムはパーティションレベルの重みを保持します。

## MySQLモードでのパーティション重みのクリア

1. ユーザーがクラスタのMySQLテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. テーブルのパーティション重み情報を取得します。

   ```shell
   obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   |   500002 |         NULL |            NULL |      1 | test          | tbl1_h     | NULL           | NULL              | NULL            |      500001 |          NULL |    500002 |
   |   500002 |       500003 |            NULL |      2 | test          | tbl1_h     | p0             | NULL              | NULL            |      500001 |          NULL |    500003 |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   2 rows in set
   ```

3. テーブルのパーティション重みをクリアします。

   * テーブルレベルの重みのクリア

      テーブル `tbl1_h` のパーティション重みをクリアするステートメントは以下のとおりです。

      ```shell
      obclient[test]> CALL DBMS_BALANCE.CLEAR_BALANCE_WEIGHT('test','tbl1_h');
      ```

   * パーティションレベルの重みのクリア

      テーブル `tbl1_h` 内のパーティション `p0` のパーティション重みをクリアするステートメントは以下のとおりです。

      ```shell
      obclient[test]> CALL DBMS_BALANCE.CLEAR_BALANCE_WEIGHT('test','tbl1_h','p0');
      ```

## Oracleモードでのパーティション重みのクリア

1. ユーザーがクラスタのOracleテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -usys@oracle_tenant_tenant#obdemo -p***** -A
   ```

2. テーブルのパーティション重み情報を取得します。

   ```shell
   obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
   ```

   クエリ結果の例は次のとおりです：

   ```shell
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   |   500002 |         NULL |            NULL |      1 | USR2          | TBL1_H     | NULL           | NULL              | NULL            |      201006 |          NULL |    500002 |
   |   500002 |       500003 |            NULL |      2 | USR2          | TBL1_H     | P0             | NULL              | NULL            |      201006 |          NULL |    500003 |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   2 rows in set
   ```

3. テーブルのパーティション重みをクリアします。

   * テーブルレベルの重みのクリア

      テーブル `TBL1_H` のパーティション重みをクリアするステートメントは以下のとおりです。

      ```shell
      obclient [USR2]> delimiter //
      ```

      ```shell
      obclient [USR2]>BEGIN
            DBMS_BALANCE.CLEAR_BALANCE_WEIGHT('USR2','TBL1_H');
            END;//
      ```

      ```shell
      obclient [USR2]> delimiter ;
      ```

   * パーティションレベルの重みのクリア

      テーブル `TBL1_H` 内のパーティション `P0` のパーティション重みをクリアするステートメントは以下のとおりです。

      ```shell
      obclient [USR2]> delimiter //
      ```

      ```shell
      obclient [USR2]> BEGIN
          DBMS_BALANCE.CLEAR_BALANCE_WEIGHT('USR2','TBL1_H','P0');
          END;//
      ```

      ```shell
      obclient [USR2]> delimiter ;
      ```

## 次のステップ

パーティションの重みをクリアすると、テーブル上のパーティション分布が不均衡になる可能性があります。できるだけ早くパーティションの均衡を達成する必要がある場合は、`DBMS_BALANCE.TRIGGER_PARTITION_BALANCE`サブルーチンを呼び出して、手動でパーティションの均衡をトリガーできます。手動でパーティションの均衡をトリガーする詳細な操作については、[手動でパーティションの均衡をトリガーする](../500.partition-balance-management/200.manually-trigger-a-partition-balancing-task.md)を参照してください。そうでない場合は、定期的なパーティションの均衡タスクのトリガーを待つことができます。定期的なパーティションの均衡タスクの詳細については、[定期的なパーティションの均衡タスクを設定する](../500.partition-balance-management/100.configure-a-scheduled-partition-balancing-task.md)を参照してください。
