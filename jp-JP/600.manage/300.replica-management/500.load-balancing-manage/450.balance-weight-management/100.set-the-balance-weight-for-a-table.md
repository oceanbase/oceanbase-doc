# パーティションの重みを設定する

業務ニーズに応じて、テーブルにパーティションの重みを設定できます。レベルは上から下へと、テーブルレベルおよびパーティションレベルのパーティションの重みを設定できます。

## 制限事項と注意点

* V4.2.5バージョンでは、V4.2.5 BP2以降のバージョンからパーティション重みを手動で設定できるようになりました。

* パーティション重みの手動設定はユーザーテナントのみがサポートしており、システムテナントでは設定できません。

* 現在、パーティション重みの設定はパーティションテーブルおよびパーティションテーブルのパーティションに対してのみサポートされており、サブパーティションへの重み設定はまだサポートされていません。

* 既存のエンティティパーティションに対してのみ重みを設定でき、テーブル作成時に重みを指定することはできません。つまり、まずテーブルを作成した後に、そのテーブルにパーティション重みを設定する必要があります。

* パーティション重みは整数のみをサポートし、値の範囲は[1, +∞)です。デフォルトでは、パーティションには重みが付けられていません。

* パーティション重みを設定する際は、できるだけ少ない段階で設定することを推奨します。最大でも3段階に分けることを推奨します：

  * 大重み = 100% × パーティション数

  * 中重み = 50% × パーティション数

  * 小重み = 1

* 重み均等化に参加する必要がないパーティションテーブルについては、パーティション重みを設定しないことを推奨します。

* パーティション重みを設定する際、下位パーティションは上位パーティションの重みをデフォルトで継承します。複数のレベルに同時にパーティション重みを設定した場合、下位の重みが上位の重みを上書きします。

* パーティション重みを設定した後、ユーザーがOffline DDL操作（例えばTruncate Table、Truncate Partitionなどの操作）を実行してパーティションエンティティに変更が生じた場合、元のパーティション重みも無効になり、ユーザーが再度パーティション重みを設定する必要があります。パーティション重みが無効になる可能性のあるOffline DDL操作については、[Online DDLとOffline DDL操作（MySQLモード）](../../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/700.ddl-function-of-mysql-mode/150.online-and-offline-ddl-list-of-mysql-mode.md)および[Online DDLとOffline DDL操作（Oracleモード）](../../../../700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/1000.ddl-function-of-oracle-mode/150.online-and-offline-ddl-list-of-oracle-mode.md)を参照してください。

## MySQLモードでのパーティション重みの設定

1. ユーザーがクラスタのMySQLテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. (オプション) パーティション重みを設定するテーブルを作成します。

   たとえば、Hashパーティションテーブル `tbl1_h` を作成します。

   ```shell
   obclient[test]> CREATE TABLE tbl1_h(col1 INT,col2 VARCHAR(50)) PARTITION BY HASH(col1) PARTITIONS 5;
   ```

3. (オプション) テーブルのパーティション情報を取得します。

   ```shell
   obclient[test]> SELECT TABLE_NAME, PARTITION_NAME FROM information_schema.PARTITIONS WHERE TABLE_NAME ='tbl1_h';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +------------+----------------+
   | TABLE_NAME | PARTITION_NAME |
   +------------+----------------+
   | tbl1_h     | p0             |
   | tbl1_h     | p3             |
   | tbl1_h     | p2             |
   | tbl1_h     | p4             |
   | tbl1_h     | p1             |
   +------------+----------------+
   5 rows in set
   ```

4. ビジネスニーズに応じて、適切なレベルを選択し、パーティション重みを設定します。

   パーティション重みは整数のみサポートされ、値の範囲は[1, +∞)です。デフォルトでは、パーティションには重みがありません。

   * テーブルレベルの重みの設定

      パーティションテーブルまたはパーティション化されていないテーブルのテーブルレベルのパーティション重みを設定できます。たとえば、パーティションテーブル `tbl1_h` のパーティション重みを1に設定するステートメントは次のとおりです。

      ```shell
      obclient[test]> CALL DBMS_BALANCE.SET_BALANCE_WEIGHT(1,'test','tbl1_h');
      ```

   * パーティションレベルの重みの設定

      テーブル `tbl1_h` 内のパーティション `p0` のパーティション重みを2に設定するステートメントは次のとおりです。

      ```shell
      obclient[test]> CALL DBMS_BALANCE.SET_BALANCE_WEIGHT(2,'test','tbl1_h','p0');
      ```

5. 完了後、テーブルのパーティション重み情報を確認します。

   ```shell
   obclient[test]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   |   500002 |         NULL |            NULL |      1 | test          | tbl1_h     | NULL           | NULL              | NULL            |      500001 |          NULL |    500002 |
   |   500002 |       500003 |            NULL |      2 | test          | tbl1_h     | p0             | NULL              | NULL            |      500001 |          NULL |    500003 |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   2 rows in set
   ```

## Oracleモードでのパーティション重みの設定

1. ユーザーがクラスタのOracleテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -usys@oracle_tenant_tenant#obdemo -p***** -A
   ```

2. （オプション）パーティション重みを設定するテーブルを作成します。

   たとえば、Hashパーティションテーブル `TBL1_H` を作成します。

   ```shell
   obclient[USR2]> CREATE TABLE TBL1_H(col1 INT,col2 VARCHAR(50)) PARTITION BY HASH(col1) PARTITIONS 5;
   ```

3. （オプション）テーブルのパーティション情報を取得します。

   ```shell
   obclient[USR2]> SELECT TABLE_NAME, PARTITION_NAME FROM USER_TAB_PARTITIONS WHERE TABLE_NAME = 'TBL1_H';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +------------+----------------+
   | TABLE_NAME | PARTITION_NAME |
   +------------+----------------+
   | TBL1_H     | P4             |
   | TBL1_H     | P3             |
   | TBL1_H     | P2             |
   | TBL1_H     | P1             |
   | TBL1_H     | P0             |
   +------------+----------------+
   5 rows in set
   ```

4. ビジネスニーズに応じて、適切なレベルを選択し、パーティション重みを設定します。

   パーティション重みは整数のみサポートしており、値の範囲は[1, +∞)です。デフォルトでは、パーティションには重みがありません。

   * テーブルレベルの重みの設定

      パーティションテーブルまたはパーティション化されていないテーブルのテーブルレベルのパーティション重みを設定できます。たとえば、パーティションテーブル `TBL1_H` のパーティション重みを1に設定するステートメントは次のとおりです。

      ```shell
      obclient [USR2]> delimiter //
      ```

      ```shell
      obclient[USR2]> BEGIN
                 DBMS_BALANCE.SET_BALANCE_WEIGHT(1,'USR2','TBL1_H');
                 END;//
      ```

      ```shell
      obclient [USR2]> delimiter ;
      ```

   * パーティションレベルの重みの設定

      テーブル `TBL1_H` のパーティション `P0` のパーティション重みを2に設定するステートメントは次のとおりです。

      ```shell
      obclient [USR2]> delimiter //
      ```

      ```shell
      obclient[USR2]> BEGIN
                 DBMS_BALANCE.SET_BALANCE_WEIGHT(2,'USR2','TBL1_H','P0');
                 END;//
      ```

      ```shell
      obclient [USR2]> delimiter ;
      ```

5. 完了後、テーブルのパーティション重み情報を確認します。

   ```shell
   obclient[USR2]> SELECT * FROM SYS.DBA_OB_OBJECT_BALANCE_WEIGHT;
   ```

   クエリ結果は次のとおりです：

   ```shell
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   | TABLE_ID | PARTITION_ID | SUBPARTITION_ID | WEIGHT | DATABASE_NAME | TABLE_NAME | PARTITION_NAME | SUBPARTITION_NAME | TABLEGROUP_NAME | DATABASE_ID | TABLEGROUP_ID | OBJECT_ID |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   |   500002 |         NULL |            NULL |      1 | USR2          | TBL1_H     | NULL           | NULL              | NULL            |      201006 |          NULL |    500002 |
   |   500002 |       500003 |            NULL |      2 | USR2          | TBL1_H     | P0             | NULL              | NULL            |      201006 |          NULL |    500003 |
   +----------+--------------+-----------------+--------+---------------+------------+----------------+-------------------+-----------------+-------------+---------------+-----------+
   2 rows in set
   ```

## 次のステップ

パーティションの重みを設定した後、できるだけ早くパーティションの重みの均衡を実行する必要がある場合は、`DBMS_BALANCE.TRIGGER_PARTITION_BALANCE`サブルーチンを呼び出して、手動でパーティションの均衡をトリガーできます。手動でパーティションの均衡をトリガーする詳細な操作については、[手動でパーティションの均衡をトリガーする](../500.partition-balance-management/200.manually-trigger-a-partition-balancing-task.md)を参照してください。そうでない場合は、定期的なパーティションの均衡タスクのトリガーを待機することができます。定期的なパーティションの均衡タスクの詳細については、[定期的なパーティションの均衡タスクを設定する](../500.partition-balance-management/100.configure-a-scheduled-partition-balancing-task.md)を参照してください。
