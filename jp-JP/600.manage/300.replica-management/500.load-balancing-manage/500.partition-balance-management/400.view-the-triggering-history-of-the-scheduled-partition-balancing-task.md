# 定時パーティション均衡タスクのトリガー履歴を確認する

定時にパーティション均衡タスクをトリガーした後、ビューを通じてそのトリガー履歴を確認できます。

## システムテナントで定期パーティション均衡タスクのトリガー履歴を確認する

1. `root` ユーザーでクラスタの `sys` テナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 指定されたテナントの定期パーティション均衡タスクの履歴スケジューリング状況を確認するには、次のコマンドを実行します。

   ビュー `CDB_SCHEDULER_JOB_RUN_DETAILS` には、すべてのテナントのSCHEDULED_TRIGGER_PARTITION_BALANCEジョブの実行レコードが表示されます。

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.CDB_SCHEDULER_JOB_RUN_DETAILS WHERE TENANT_ID = 1002 AND JOB_NAME = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

## ユーザーテナントがスケジュールされたパーティションのバランシングタスクのトリガー履歴を確認する

1. ユーザーテナントのテナント管理者は、クラスタのMySQLテナントまたはOracleテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のコマンドを実行して、このテナントのスケジュールされたパーティションのバランシングタスクの履歴を確認します。

   ビュー`DBA_SCHEDULER_JOB_RUN_DETAILS`には、現在のテナントのSCHEDULED_TRIGGER_PARTITION_BALANCEジョブの実行レコードが表示されます。

   :::tab
   tab MySQLモード

   ステートメントは以下のとおりです：

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SCHEDULER_JOB_RUN_DETAILS WHERE JOB_NAME = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

   tab Oracleモード

   ステートメントは以下のとおりです：

   ```shell
   obclient [SYS]> SELECT * FROM SYS.DBA_SCHEDULER_JOB_RUN_DETAILS WHERE JOB_NAME = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```
   :::
