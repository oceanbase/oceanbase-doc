# バックグラウンドのパーティション均等化タスク履歴を確認する

パーティション均等化タスクの実行が完了した後、ビューを通じてその実行履歴を確認できます。

## システムテナントからバックグラウンドのパーティション均衡タスクを確認する

1. `root`ユーザーでクラスタのsysテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 以下のステートメントを実行して、指定されたテナントのバックグラウンドのパーティション均衡タスク履歴を確認します。

   * 指定されたテナントのパーティション均衡タスク履歴を確認します。

     ビュー`CDB_OB_BALANCE_JOB_HISTORY`は、拡張、縮小、移行均衡、パーティション均衡など、すべてのテナントのマクロレベルの均衡タスクを表示します。

     ```shell
     obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_JOB_HISTORY WHERE TENANT_ID = 1002 AND JOB_TYPE = 'PARTITION_BALANCE';
     ```

     クエリ結果は次のとおりです：

     ```shell
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     | TENANT_ID | JOB_ID | CREATE_TIME                | FINISH_TIME                | BALANCE_STRATEGY                | JOB_TYPE          | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS    | COMMENT | MAX_END_TIME | ZONE_UNIT_NUM_LIST | PARAMETER_LIST                                                                               |
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     |      1002 | 312280 | 2024-06-14 11:00:49.034035 | 2024-06-14 11:01:04.528871 | partition attribution alignment | PARTITION_BALANCE |            NULL |                       1 | COMPLETED | NULL    | NULL         | zone1:1            | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+-----------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     1 row in set
     ```

     ビュー`CDB_OB_BALANCE_JOB_HISTORY`の各フィールドの詳細については、[CDB_OB_BALANCE_JOB_HISTORY](../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7300.o-cdb_ob_balance_job_history-of-sys-tenant.md)を参照してください。

   * 指定されたテナントのLSレベルのパーティション均衡タスク履歴を確認します。

     ビュー`CDB_OB_BALANCE_TASK_HISTORY`は、LS分割(LS_SPLIT)、LSマージ(LS_MERGE)、LS転送(LS_TRANSFER)、LS属性の変更(LS_ALTER)など、すべてのテナントのログストリームレベルのタスクを表示します。


     クエリ結果は次のとおりです：

   * 指定されたテナントのTabletレベルのパーティション均衡タスク履歴を確認します。

     ビュー`CDB_OB_TRANSFER_TASK_HISTORY`は、具体的にどのパーティションとTabletに対してTransfer操作が実行されたかを示す、すべてのテナントのTabletレベルのタスクを表示します。

## ユーザーテナントがバックグラウンドのパーティション均等化タスクを確認する

1. ユーザーテナントのテナント管理者は、クラスタのMySQLテナントまたはOracleテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のステートメントを実行して、このテナントのバックグラウンドのパーティション均等化タスク履歴を確認します。

     ```shell
     obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOB_HISTORY WHERE JOB_TYPE = 'PARTITION_BALANCE';
     ```
