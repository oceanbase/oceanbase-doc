# 定時パーティション均衡タスクの関連設定を確認する

システムには、定時パーティション均衡タスク `SCHEDULED_TRIGGER_PARTITION_BALANCE` が組み込まれており、ユーザーテナントは必要に応じて、定時パーティション均衡タスクの各パラメータ設定を確認できます。

## 手順

1. ユーザーがクラスタのMySQLユーザーテナントまたはOracleユーザーテナントにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に基づいてください。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. 以下のステートメントを実行して、このテナントのスケジュールされたパーティションバランシングタスクの関連構成を確認します。

   ビュー`DBA_SCHEDULER_JOBS`は、現在のテナントのすべてのスケジュールタスク情報を表示します。

   :::tab
   tab MySQLモード

   ステートメントは以下のとおりです：

   ```shell
   obclient [oceanbase]> SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE,MAX_RUN_DURATION, COMMENTS FROM oceanbase.DBA_SCHEDULER_JOBS WHERE job_name = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

   tab Oracleモード

   ステートメントは以下のとおりです：

   ```shell
   obclient [SYS]> SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE,MAX_RUN_DURATION, COMMENTS FROM SYS.DBA_SCHEDULER_JOBS WHERE job_name = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```
   :::

   クエリ結果の例は次のとおりです：

   ```shell
   *************************** 1. row ***************************
            JOB_NAME: SCHEDULED_TRIGGER_PARTITION_BALANCE
          JOB_ACTION: DBMS_BALANCE.TRIGGER_PARTITION_BALANCE()
          START_DATE: 2024-06-14 00:00:00.000000
     REPEAT_INTERVAL: FREQ=DAILY; INTERVAL=1
             ENABLED: 1
       NEXT_RUN_DATE: 2024-06-15 00:00:00.000000
    MAX_RUN_DURATION: 7200
            COMMENTS: used to auto trigger partition balance
   1 row in set
   ```

   クエリ結果には、以下の項目が含まれます：

   * `JOB_NAME`：スケジュールタスクの名前。この例では、`SCHEDULED_TRIGGER_PARTITION_BALANCE`がスケジュールされたパーティションバランシングタスクの名前です。
   * `JOB_ACTION`：スケジュールされたパーティションバランシングタスクが実行する内容を示します。
   * `START_DATE`：スケジュールされたパーティションバランシングタスクのトリガー時間を示します。デフォルトは毎日00:00です。
   * `REPEAT_INTERVAL`：スケジュールされたパーティションバランシングタスクのトリガー周期と頻度を示します。デフォルトは毎日1回です。
   * `ENABLED`：スケジュールされたパーティションバランシングタスクが有効になっているかどうかを示します。`1`は有効を表し、`0`は無効を表します。デフォルトは`1`です。
   * `NEXT_RUN_DATE`：スケジュールされたパーティションバランシングタスクの次回のトリガー時間を示します。
   * `MAX_RUN_DURATION`：`JOB_ACTION`の実行のタイムアウト時間を示します。デフォルトは7200秒です。

   ビュー`DBA_SCHEDULER_JOBS`の各フィールドの詳細については、[DBA_SCHEDULER_JOBS](../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/13900.o-dba_scheduler_jobs-of-mysql-mode.md)を参照してください。
