# 内部 Catalog

内部 Catalog 是 OceanBase 默认的数据库内部数据的目录，包含所有在当前租户中创建的数据库和表。每个租户都有且只有一个名为 internal 的内部数据目录。

- 所有通过标准 DDL（如 `CREATE DATABASE`、`CREATE TABLE`）在当前租户中创建的对象，默认均归属于 internal Catalog。  
- internal Catalog 与外部 Catalog（如 HMS Catalog）在逻辑上隔离，便于区分本地数据与外部数据源。  
- 不支持创建、删除或重命名 internal Catalog。

## 特点

- 无需显式声明，直接使用 `USE database;` 即可访问。  
- 支持完整的 DDL/DML 操作（`CREATE TABLE`、`INSERT` 等）。  
- 表数据存储在 OceanBase 分布式存储引擎中。

## 示例

```sql
-- 查询内部表（无需指定 catalog）
USE ap_db;
SELECT COUNT(*) FROM user_behavior;

-- 显式指定内部 catalog（可选）
SELECT COUNT(*) FROM internal.ap_db.user_behavior;

-- 切换为内部 catalog
SET CATALOG internal;

-- 或者使用 use internal.ap_db 或 use odps_catalog.table 一次性完成切换 Catalog 和 数据库的操作
USE internal.ap_db;
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>内部 Catalog 名称为 internal，但通常可省略。</p>
</main>
