# 使用工具迁移数据

本文说明通过 **OMS**、**obloader** 以及 **Flink 等生态工具**将数据迁移至 OceanBase（或 OceanBase 租户之间、迁出到其他数据库）时的选型与文档入口。异构场景需关注 Schema 与类型映射、并行与批量策略、以及割接后的数据校验；对接数仓与文件时还需关注格式转换与元数据对齐。

## 使用 OMS 迁移数据到 OceanBase

OMS（OceanBase Migration Service）提供从结构迁移、全量迁移到增量迁移的**一体化编排**，支持多种关系型源库与 OceanBase 租户类型组合，并具备任务监控与切换能力，适合企业级换库与长期同步项目。

## 使用 obloader 迁移数据到 OceanBase

obloader 适合 **文件导入**：将 CSV、Parquet、ORC、SQL 等文件从本地磁盘、对象存储或 HDFS 批量写入 OceanBase；可与 **旁路导入** 配合提升吞吐。典型用于离线导出文件已就绪、需由导入工具读取文件、解析格式并写入 OceanBase 的场景；若数据文件与 OBServer 网络隔离，也可由 obloader 完成数据导入。
