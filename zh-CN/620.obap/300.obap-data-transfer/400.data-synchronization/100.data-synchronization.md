# 数据同步

数据同步指由迁移或同步工具**持续读取上游变更**，并将结果**写入目标 OceanBase**（或其它下游），使目标与源库在业务可接受延迟内保持一致。与一次性迁移相比，更强调长链路运行、延迟监控与回放一致性。

在 OceanBase 生态中，**OMS（OceanBase Migration Service）** 是关系型源库到 OceanBase 的主力方案之一，通常覆盖**结构 + 全量 + 增量**，并支持切换编排。
