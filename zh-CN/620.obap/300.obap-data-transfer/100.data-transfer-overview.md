# 数据传输概述

在 OceanBase AP 场景中，**数据传输**涵盖**数据迁移**、**数据导入**、**数据同步**与**数据订阅**：分别面向换库割接、批量落表、持续写库对齐、以及变更事件分发。下文按**业务目标**归纳选型要点，并给出对应文档入口。

## 数据迁移

在明确时间点或阶段内完成**目标库搭建或替换**，使业务读写切换到 OceanBase（或新租户），并完成结构对齐与数据收敛。

* **典型场景**：MySQL/Oracle 等一次性或分阶段替换；OceanBase 版本升级、集群替换；TP 库迁入后再做 AP；仅需某时刻历史快照、无持续 CDC 的少数离线搬迁。

* **相关文档**：[数据迁移概述](200.data-migration/100.ap-data-migration-overview.md)、[使用工具迁移数据](200.data-migration/200.migrate-data-with-tools.md)、[数据导入策略与最佳实践](200.data-migration/500.best-practices-migrating-from-mainstream-databases-to-oceanbase.md)、[主流 AP 数据库迁移至 OceanBase 最佳实践](200.data-migration/500.best-practices-migrating-from-mainstream-databases-to-oceanbase.md)。

### 数据导入

将外部数据**导入到 OceanBase 内表**时，数据来源可以是本地文件、对象存储、HDFS 等；可通过 `LOAD DATA`、外表、`FILES` 表函数或 `INSERT INTO ... SELECT` 等方式完成导入。

* **典型场景**：历史明细、日志归档批量入仓；CSV/ORC/Parquet 等文件位于 OSS、HDFS 等远端路径；超大表或全量数据配合**旁路导入**以更高效的方式写入；通过外表或 `FILES` 读取湖仓数据后**导入到内表**。

* **相关文档**：[数据导入概述](300.data-import/100.data-import-overview.md)、[LOAD DATA FROM FILES](300.data-import/200.load-data-import.md)、[LOAD DATA INFILE](300.data-import/200.load-data-import.md)、[LOAD DATA LOCAL INFILE](300.data-import/200.load-data-import.md)、[旁路导入概述](300.data-import/100.data-import-overview.md)、[全量旁路导入](300.data-import/100.data-import-overview.md)、[INSERT INTO SELECT FROM FILES](300.data-import/300.insert-into/100.insert-into-select-from-files.md)、[通过外表 INSERT INTO SELECT 导入](300.data-import/300.insert-into/200.insert-into-select-from-external-table.md)、[使用 obloader 导入数据](300.data-import/500.import-data-with-obloader.md)。

### 数据同步

在**较长周期**内使目标库（常为 OceanBase）与源库保持**业务可接受的一致性**或延迟上界，由工具**持续写入目标库**。

* **典型场景**：同城/异地容灾、双机热备；割接前后短时双写与回滚窗口；多活或读写分离下从副本与主库对齐。

* **相关文档**：[数据同步概述](400.data-synchronization/100.data-synchronization.md)。

### 数据订阅

从上游持续读取**数据库日志或 CDC 事件**，解析后传输给 **Kafka、Flink** 等，由**多个下游**各自消费、加工或选择性写库。

* **典型场景**：使用 Canal、Flink CDC 等组件订阅数据库变更，并将变更数据写入 Kafka 等消息系统，供实时数仓、流处理任务或多个业务系统分别消费。

* **相关文档**：[数据订阅概述](400.data-synchronization/300.data-subscription.md)、[数据同步概述](400.data-synchronization/100.data-synchronization.md)（与 OMS 写库路径对照阅读）、[数据导入策略与最佳实践](200.data-migration/500.best-practices-migrating-from-mainstream-databases-to-oceanbase.md)。
