# OceanBase AP 部署概述

可以根据需要选择合适的产品形态、部署方案和部署方式。  

## 选择合适的产品形态

OceanBase 数据库提供企业版和社区版两种形态：

* OceanBase 数据库企业版：一款完全自研的企业级原生分布式数据库，在普通硬件上实现金融级高可用，首创“三地五中心”城市级故障自动无损容灾新标准，刷新过 TPC-C 标准测试世界纪录，单集群规模超过 1500 节点，具有云原生、强一致性、高度兼容 Oracle/MySQL 等特性。
* OceanBase 数据库社区版：一款完全自研的兼容 MySQL 的单机分布式一体化国产开源数据库，具有原生分布式架构，支持金融级高可用、透明水平扩展、分布式事务、多租户和语法兼容等企业级特性。

有关 OceanBase 企业版和社区版的功能差异，参见 [企业版和社区版的功能差异](../../100.learn-more-about-oceanbase/200.differences-between-enterprise-edition-and-community-edition.md)。

## 选择合适的部署方案

OceanBase 数据库支持单机（单机房部署 OceanBase 集群）、机房（同城多机房部署 OceanBase 集群，机房以下统称：IDC）、城市（多城市部署 OceanBase 集群）级别的高可用和容灾，可以进行单机房、双机房、两地三中心、三地五中心部署，且支持部署仲裁服务来降低成本。  

关于每种部署方案的详细介绍，参见 [OceanBase 集群高可用部署方案简介](../../400.deploy/200.introduction-to-oceanbase-cluster-high-availability-deployment-scheme.md)。

## 部署与使用列存副本

为支持 TP 与 AP 混合负载等场景，OceanBase 支持在独立 Zone 上部署**只读列存副本（C 副本）**。

访问方式与 OceanBase 版本有关：

* V4.6.0 之前，需要配置独立的 ODP，并通过 ODP 的配置项设置路由策略。

* V4.6.0 及以上，C 副本不需要部署独立的 ODP,由数据库自动选择路由策略。

两种形态、操作步骤与自动路由说明，见 [列存副本的使用方法与访问方式](150.uesing-columnstore-replica.md)；架构选型还可对照 [典型 AP 架构部署指南](50.ap-architecture-deployment-guide.md)。


### C 副本的产品行为

* **基线（major sstable）**：同一日志流上的用户表在 C 副本上，基线数据以**列存**组织，便于大范围扫描与 AP 计算。
* **增量与融合**：MemTable、转储（minor）等增量仍以**行存**组织；C 副本通过日志（clog）异步追平源副本并在本地回放；读路径会融合增量与列存基线（细节以当前版本说明为准）。
* **角色**：C 副本**不参与 Paxos 选举与投票**，不承担写入主路径。

### C 副本的两种部署与访问形态

#### OceanBase V4.6.0 之前：独立 ODP + ODP 路由策略

该形态下须**单独部署一套用于访问 C 副本的 ODP**（建议 **ODP V4.3.2 及以上**），与访问 F/R、承载 TP 流量的 ODP **分离**。在 **ODP（`proxysys`）配置项** 中需要显式设置例如：**弱读**、将弱读请求**路由到 C 副本所在 Zone 或 `ColumnStore` 副本类型**，并常通过 `init_sql` 注入 **`ob_route_policy = COLUMN_STORE_ONLY`** 等，使分析 SQL 在 C 副本上生成列存侧执行计划，从而实现 **TP 与 AP 接入链路隔离**。

#### OceanBase V4.6.0 及以上：无需独立的 ODP，库内自动路由

该形态下**不要求**再为 C 副本单独部署列存专用 ODP。应用可使用**与访问 F/R 相同的 ODP 入口**（**共用 ODP**），将请求统一转发至 OBServer。在租户 **Locality** 已配置 C 副本的前提下，是否将符合条件的只读查询规划到 C 副本，由 **OBServer** 侧的 **`ap_query_route_policy`、`ap_query_cost_threshold`、`ap_query_replica_fallback`** 等与优化器、读一致性变量共同决定，而**不再依赖**上一形态中 ODP 侧的列存专线配置。

在创建或变更租户时，通过 **Locality** 指定 C 副本后，按所选 OceanBase 版本选择适用形态，并按 [列存副本的使用方法与访问方式](150.uesing-columnstore-replica.md) 完成配置与验证。
