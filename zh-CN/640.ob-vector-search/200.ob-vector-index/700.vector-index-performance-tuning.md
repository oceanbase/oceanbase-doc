## 性能优化

+
3	
+
<main id="notice" type='notice'>
4	
+
  <h4>注意</h4>
5	
+
  <p>目前仅支持 IVF 索引。</p>
6

</main>
7

8	
+
SeekDB 向量搜索为 IVF 索引提供了自动性能优化机制，通过缓存管理和定期维护来提升搜索性能。
9	
+
10	
+
### 优化机制
11	
+
12	
+
IVF 索引性能优化包含两种自动任务：
13	
+
14	
+
1. 缓存预热任务：定期检查所有 IVF 索引，如果发现索引对应的缓存不存在，则自动触发缓存预热，将索引数据加载到内存中。此外，创建 IVF 索引时，会自动预热缓存。  
15	
+
2. 缓存清理任务：定期检查所有 IVF 缓存，如果发现缓存对应的索引已被删除，则自动清理失效的缓存，释放内存资源。此外，删除 IVF 索引时，会自动清理缓存。
16	
+
17	
+
### 配置优化执行周期
18	
+
19	
+
系统支持自定义性能优化任务的执行时间窗口，避免在业务高峰期执行影响性能。
20	
+
21	
+
在 `seekdb` 数据库下，通过配置项 `vector_index_optimize_duty_time` 设置执行周期：
22	
+
23	
+
```sql
24	
+
ALTER SYSTEM SET vector_index_optimize_duty_time='[23:00:00, 24:00:00]';
25	
+
```
26	
+
27	
+
配置说明如下：
28	
+
29	
+
* 时间格式为 `[开始时间, 结束时间]`。
30	
+
* 上述配置表示只在 23:00:00~24:00:00 时间段执行优化任务。
31	
+
* 其他时间段不会发起优化任务，避免影响正常业务。
32	
+
33	
+
### 监控优化任务
34	
+
35	
+
SeekDB 向量索引提供了监控优化任务的功能：
36	
+
37	
+
* 可以通过 [DBA_OB_VECTOR_INDEX_TASKS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/24150.o-dba_ob_vector_index_tasks-of-sys-tenant.md) 视图查看正在执行或等待执行的任务。
38	
+
* 可以通过 [DBA_OB_VECTOR_INDEX_TASK_HISTORY](../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/12960.o-dba_ob_vector_index_task_history-of-mysql-mode.md) 视图查看历史任务记录。

+
40

### 取消优化任务
93	
+
94	
+
通过以下命令可以取消指定任务。
95	
+
96	
+
```sql
97	
+
-- trace_id 从上文 DBA_OB_VECTOR_INDEX_TASKS_HISTORY 视图获取
98	
+
ALTER SYSTEM CANCEL TASK <trace_id>;
99	
+
```
100	
+
101	
+
<main id="notice" type='notice'>
102	
+
  <h4>注意</h4>
103	
+
  <p>只有在任务的失败重试阶段，且执行 <code>ALTER SYSTEM CANCEL TASK</code> 命令的情况下，才能取消任务。如果后台任务卡在某一次执行阶段，无法通过此命令取消后台任务。</p>
104	
+
</main>
