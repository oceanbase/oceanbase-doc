# 向量检索核心功能

OceanBase 提供了存储、索引、检索 Embedding 向量数据的能力。具体包括：

|**核心功能**|**描述**|
|---|---|
| 向量数据类型 | <ul><li>支持最大 16,000 维的 float 稠密向量数据存储。</li><li>支持稀疏向量数据存储。</li></ul> |
| 向量索引 | <ul><li>支持精确搜索和近似最近邻搜索。</li><li>支持 L2 距离、内积和余弦相似度计算。</li><li>支持 HNSW/HNSW_SQ/HNSW_BQ 索引，索引列最大维度为 4096。</li><li>支持 IVF 索引/IVF_SQ 索引/IVF_PQ 索引（实验特性），索引列最大维度为 4096。</li></ul> |
| 向量搜索 SQL 运算符 | 支持向量加、减、乘、比较、聚合等基础运算操作符。 |

## 使用限制

* OceanBase 默认采用 NULL first 比较模式，所以对 NULL 值进行排序时会将其放至最前，建议查询的时候加上 `NOT NULL` 条件。
