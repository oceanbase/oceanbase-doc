# 索引混合搜索（SQL 接口）

本文档介绍 OceanBase 的混合搜索 SQL 接口。该接口通过 `HYBRID_SEARCH(TABLE ..., 'DSL_JSON')` 在一条 SQL 中组合全文、向量搜索与过滤条件，并返回按相关性融合后的结果。

混合搜索（Hybrid Search）结合了基于向量的语义搜索和基于全文索引的关键词搜索，通过综合排序提供更准确、全面的搜索结果。向量搜索擅长语义近似匹配，但对精确的关键字、数字和专有名词等匹配能力较弱，而全文搜索能有效弥补这一不足。因此，混合搜索已成为向量数据库的关键特性之一，广泛应用于各类产品中。

## 注意事项

* 当前仅支持在**堆表**上使用混搜 SQL 接口。
* 向量搜索要求目标向量列已创建向量索引。
* 全文搜索要求目标文本列已创建全文索引。
* 标量过滤、JSON/ARRAY 过滤在无索引时也可执行，但建议创建相应索引以获得更好性能。
* 建议在 DSL 中显式指定 `_source`，避免返回不必要列（尤其向量列）导致响应变慢。
* 当前版本向量索引类型仅支持HNSW。
* 多路向量不支持稀疏向量
* 不支持列存表

语法细节：// TODO: 移动到语法文档

* 当前版本不支持rank_feature;
* 不支持在与混搜同层的stmt中加上order by\limit\where，基于混搜子查询结果再进行过滤或者排序则没有此限制。
* multi_match/query_string的type支持best_fields/most_fields，不支持cross_fields/phrase
* 标量查询，包括term/range/terms/json表达式/array表达式，不算分，不支持boost，不可以在bool的must/should中使用；
* bool中至少需要包含1个正向条件（must\should\filter），不支持只有1个must_not条件；
* 向量查询的query_vector，推荐用字符串输入向量；
* 部分嵌套 JSON/ARRAY 路径不支持下推，如json的path里如果是array，元素是json，不支持再对这个json元素指定路径
* 部分嵌套 JSON/ARRAY 路径不支持下推，如json的path里如果是array，元素是json，不支持再对这个json元素指定路径
* rank_window_size必须大于等于size
* 非顶层全文查询的boost、bool查询的boost、全文查询的列权重和词权重，要求大于0，其他情况的boost要求大于等于0

## 语法

```sql
SELECT select_list
FROM HYBRID_SEARCH(TABLE table_name, dsl_string);
```

参数说明如下：

* `table_name`：目标表名，仅支持堆表（`ORGANIZATION = HEAP`）。
* `dsl_string`：JSON 字符串，用于描述全文、向量搜索、过滤、排序融合等查询语义。

<main id="notice" type='notice'>
<h4>注意</h4>
<p><ul>
<li>不支持在与 <code>HYBRID_SEARCH</code> 同层直接使用 <code>WHERE</code> / <code>ORDER BY</code> / <code>LIMIT</code>。</li>
<li>若需要进一步过滤或排序，请将混搜结果作为子查询再处理。</li>
</ul></p>
</main>

```sql
-- 不支持：与 HYBRID_SEARCH 同层使用 WHERE
SELECT id
FROM HYBRID_SEARCH(TABLE doc_table, '{"knn":{"field":"vector","k":5,"query_vector":"[1,2,3]"}}')
WHERE id > 3;

-- 支持：先子查询，再过滤
SELECT id
FROM (
  SELECT id
  FROM HYBRID_SEARCH(TABLE doc_table, '{"knn":{"field":"vector","k":5,"query_vector":"[1,2,3]"}}')
) t
WHERE id > 3;
```

## 使用场景说明及示例

### 单路向量检索

```sql
SELECT c1, __score
FROM HYBRID_SEARCH(
  TABLE doc_table,
  '{
    "knn": {
      "field": "vector",
      "k": 3,
      "query_vector": "[1,2,3]"
    },
    "_source": ["c1"]
  }'
);
```

### 全文检索 + 标量过滤

```sql
SELECT c1, query, content, __score
FROM HYBRID_SEARCH(
  TABLE doc_table,
  '{
    "query": {
      "bool": {
        "must": [
          {"match": {"content": "oceanbase mysql"}}
        ],
        "filter": [
          {"range": {"c1": {"gte": 2}}}
        ]
      }
    },
    "_source": ["c1","query","content"]
  }'
);
```

### 向量 + 全文混合检索（RRF 融合）

```sql
SELECT c1, query, content, __score
FROM HYBRID_SEARCH(
  TABLE doc_table,
  '{
    "query": {
      "match": {"content": "oceanbase mysql"}
    },
    "knn": {
      "field": "vector",
      "k": 5,
      "query_vector": "[1,2,3]"
    },
    "rank": {
      "rrf": {
        "rank_constant": 60,
        "rank_window_size": 10
      }
    },
    "_source": ["c1","query","content"]
  }'
);
```

### 多路向量检索

```sql
SELECT product_id, product_name, __score
FROM HYBRID_SEARCH(
  TABLE products_multi_vector,
  '{
    "knn": [
      {"field":"vec1","k":5,"query_vector":"[0.5,0.1,0.6,0.9]"},
      {"field":"vec2","k":5,"query_vector":"[0.2,0.3,0.4,0.5]"},
      {"field":"vec3","k":5,"query_vector":"[0.1,0.2,0.3,0.4]"}
    ],
    "size": 5,
    "_source": ["product_id","product_name"]
  }'
);
```

### JSON 过滤（`json_contains`）

```sql
SELECT id, doc_json
FROM HYBRID_SEARCH(
  TABLE doc_tbl,
  '{
    "query": {
      "bool": {
        "filter": [
          {
            "json_contains": {
              "doc_json": {
                "candidate": "{\\"name\\":\\"doc2\\"}",
                "path": "$"
              }
            }
          }
        ]
      }
    },
    "_source": ["id","doc_json"]
  }'
);
```

### ARRAY 过滤（`array_overlaps`）

```sql
SELECT id, tags_array1
FROM HYBRID_SEARCH(
  TABLE doc_tbl,
  '{
    "query": {
      "bool": {
        "filter": [
          {"array_overlaps": {"tags_array1": ["database","oceanbase"]}}
        ]
      }
    },
    "_source": ["id","tags_array1"]
  }'
);
```

### 分数阈值过滤（`min_score`）

```sql
SELECT c1, __score
FROM HYBRID_SEARCH(
  TABLE doc_table,
  '{
    "query": {"match": {"content": "oceanbase mysql"}},
    "knn": {"field":"vector","k":5,"query_vector":"[1,2,3]"},
    "min_score": 0.5,
    "_source": ["c1"]
  }'
);
```

### 查看执行计划

可使用 `EXPLAIN` 查看混搜计划中各子查询节点、融合方式和是否使用索引：

```sql
EXPLAIN
SELECT c1
FROM HYBRID_SEARCH(
  TABLE doc_table,
  '{
    "query": {
      "bool": {
        "must": [{"match": {"content": "oceanbase mysql"}}],
        "filter": [{"range": {"c1": {"gte": 3}}}]
      }
    },
    "knn": {"field":"vector","k":10,"query_vector":"[1,2,3]"}
  }'
);
```

## DSL 关键参数说明

### 顶层参数

| 参数 | 说明 |
| --- | --- |
| `query` | 全文/标量/JSON/ARRAY 查询子句。 |
| `knn` | 向量检索子句，支持单路对象或多路数组。 |
| `rank` | 融合策略，支持 `weighted_sum` 与 `rrf`。 |
| `min_score` | 最终 `__score` 阈值。 |
| `from` / `size` | 结果分页参数。 |
| `_source` | 返回列控制，建议始终指定。 |

### `knn` 常用参数

| 参数 | 必选 | 说明 |
| --- | --- | --- |
| `field` | 是 | 向量列名。 |
| `k` | 是 | 召回行数。 |
| `query_vector` | 是 | 查询向量，推荐字符串形式（如 `"[1,2,3]"`）。 |
| `similarity` | 否 | 相似度阈值（可能导致返回少于 `k`）。 |
| `boost` | 否 | 路权重。 |
| `filter` | 否 | 当前向量路的过滤条件。 |
| `search_options` | 否 | 向量检索附加参数（如 `ef_search`、`refine_k`、`filter_mode`）。 |

### `bool` 子句说明

| 子句 | 说明 |
| --- | --- |
| `must` | 必须匹配，参与相关性计算。 |
| `should` | 应匹配，按 `minimum_should_match` 控制最小命中数。 |
| `filter` | 必须匹配，不参与打分。 |
| `must_not` | 必须不匹配。 |
