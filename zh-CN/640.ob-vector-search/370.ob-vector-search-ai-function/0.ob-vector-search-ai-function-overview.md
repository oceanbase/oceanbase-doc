# AI 函数服务概述

本文介绍 AI 函数服务的基本概念、功能分类、使用场景和限制。

## 基本概念

AI 函数服务是 OceanBase 数据库提供的一项创新能力，将 AI 模型能力和文档处理能力无缝集成到数据库内部的数据处理流程中。用户可以通过 SQL 表达式直接调用这些能力，从而大大简化 RAG 流程。

## 使用场景

AI 函数服务适用于以下场景：

* 文本分割：`AI_SPLIT_DOCUMENT` 函数将文本切分为多个片段，为后续处理做准备。
* 文本/图片嵌入：`AI_EMBED` 函数将读取或切分后的文本或图片转化为向量，为向量搜索和匹配打下基础。
* 结果重排：`AI_RERANK` 函数针对搜索结果，基于相似度或相关性进一步排序，提高结果的精准性。
* 模型推理：`AI_COMPLETE` 和 `AI_PROMPT` 函数调用大模型对文本或图片进行生成、总结、问答等高级推理处理，输出最终结果。

## 使用说明和限制

* 使用纯本地处理（`AI_SPLIT_DOCUMENT`）的函数时，不需要注册模型与端点，也不需要授予 AI 模型权限。
* 支持通过视图查看 AI 模型配置信息，具体请参见 [AI 函数语法及示例](300.ob-vector-search-ai-function.md)。
* 外部文本读取通过 SQL 函数 [LOAD_FILE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5920.load-file-of-mysql-mode-in-sql.md) 实现，无需授予 AI 模型权限，也无需注册 AI 模型与端点。`LOAD_FILE` 基于 [CREATE LOCATION](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2230.create-location-of-mysql-mode-in-sql.md) 创建的外表接口，将外部存储文件读入数据库内，以 `BLOB` 形式返回文件内容。
* 图片嵌入说明和限制如下：
    * 仅 `AI_EMBED`、`AI_COMPLETE` 和 `AI_PROMPT` 函数支持。
    * 支持的图片来源：HTTPS 图片 URL（图片大小通常限制在 5MB 以内）、二进制图片数据（通过 `FROM_BASE64(...)` 传入，系统自动识别格式）。
    * 支持的图片格式：JPEG、PNG、WebP、BMP、TIFF 等常见格式。
