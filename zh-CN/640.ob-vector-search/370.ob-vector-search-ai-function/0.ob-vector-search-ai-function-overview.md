# AI 函数服务概述

本文介绍 AI 函数服务的基本概念、功能分类、使用场景和限制。

## 基本概念

AI 函数服务是 OceanBase 数据库提供的一项创新能力，将 AI 模型能力和文档处理能力无缝集成到数据库内部的数据处理流程中。用户可以通过 SQL 表达式直接调用这些能力，从而大大简化 RAG 流程。这项功能是当前 AI 数据库领域的重要特性之一。

## 函数概览

| 函数 | 描述 | 应用场景 |
|------|----------|
| `AI_SPLIT_DOCUMENT` | 将文本切分为多个片段，为后续处理做准备。 | 文档切分 |
| `AI_EMBED` | 将文本转化为向量，为向量搜索和匹配打下基础。 | 文本嵌入 |
| `AI_RERANK` | 针对搜索结果，基于相似度或相关性进一步排序，提高结果的精准性。 | 结果重排 |
| `AI_COMPLETE` | 调用大模型对提取的内容或检索到的文本进行生成、总结、问答等高级推理处理，输出最终结果。 | 模型推理 |
| `AI_PROMPT` | 用于基于提示词模版动态构建格式化的提示词，支持动态插入数据。| 提示词构建 |

## 使用场景

AI 函数服务适用于以下场景：

* 文本分割：`AI_SPLIT_DOCUMENT` 函数将文本切分为多个片段，为后续处理做准备。
* 文本嵌入：`AI_EMBED` 函数将提取或切分后的文本转化为向量，为向量搜索和匹配打下基础。
* 结果重排：`AI_RERANK` 函数针对搜索结果，基于相似度或相关性进一步排序，提高结果的精准性。
* 模型推理：`AI_COMPLETE` 函数调用大模型对提取的内容或检索到的文本进行生成、总结、问答等高级推理处理，输出最终结果。

## 使用说明和限制

* AI 函数必须授予 `AI MODEL` 和 `ACCESS AI MODEL` 权限才能正常使用，且必须在 `DBMS_AI_SERVICE` 中注册对应 AI 模型与端点。
* AI 函数支持通过视图监控 AI 模型调用情况，具体请参见 [AI 函数语法及示例](300.ob-vector-search-ai-function.md)。
* 外部文本提取通过 SQL 函数 [LOAD_FILE](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2240.load-file-of-mysql-mode-in-sql.md) 实现，无需授予 AI 模型权限，也无需注册 AI 模型与端点。`LOAD_FILE` 基于 [CREATE LOCATION](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2230.create-location-of-mysql-mode-in-sql.md) 创建的外表接口，将外部存储文件读入数据库内（BLOB）。
