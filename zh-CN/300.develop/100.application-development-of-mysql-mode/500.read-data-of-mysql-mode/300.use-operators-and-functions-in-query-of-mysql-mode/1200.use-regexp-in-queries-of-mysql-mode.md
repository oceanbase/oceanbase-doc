正则表达式是一种模式匹配工具，用于在字符串中搜索和操作符合特定模式的文本。OceanBase 数据库 V4.1.0 之后完全兼容 MySQL 8.0 的正则表达式功能，支持 POSIX 1003.2 标准的扩展正则表达式语法。

OceanBase 使用 ICU 正则表达式引擎，提供高性能的正则表达式匹配和操作功能，同时也支持可选的 Hyperscan 正则表达式引擎以获得更好的性能。

## 基本语法

### 简单匹配

```sql
-- 基本匹配
SELECT 'hello world' REGEXP 'hello';  -- 返回 1 (匹配)
SELECT 'hello world' REGEXP 'goodbye'; -- 返回 0 (不匹配)

-- 使用 RLIKE
SELECT 'hello world' RLIKE '^hello';  -- 返回 1 (以 hello 开头)
```

### 字符类和量词

```sql
-- 点号匹配任意字符
SELECT 'abc' REGEXP 'a.c';  -- 返回 1

-- 字符类 [abc] 匹配 a、b 或 c
SELECT 'bat' REGEXP '[abc]at';  -- 返回 1

-- 量词 * (零次或多次)、+ (一次或多次)、? (零次或一次)
SELECT 'caaat' REGEXP 'ca*t';  -- 返回 1 (a 出现零次或多次)
SELECT 'caaat' REGEXP 'ca+t';  -- 返回 1 (a 出现一次或多次)
SELECT 'cat' REGEXP 'ca?t';    -- 返回 1 (a 出现零次或一次)
```

### 锚点

```sql
-- ^ 匹配字符串开头
SELECT 'hello world' REGEXP '^hello';  -- 返回 1

-- $ 匹配字符串结尾
SELECT 'hello world' REGEXP 'world$';  -- 返回 1

-- \b 匹配单词边界
SELECT 'hello world' REGEXP 'world\b'; -- 返回 1
```

### 分组和引用

```sql
-- 圆括号 () 用于分组
SELECT 'abab' REGEXP '(ab)+';  -- 返回 1

-- 反向引用 \1, \2 等
SELECT 'abab' REGEXP '(ab)\1';  -- 返回 1
```

## 字符类

### 标准字符类

| 字符类 | 含义 |
|--------|------|
| `[[:alnum:]]` | 字母和数字字符 |
| `[[:alpha:]]` | 字母字符 |
| `[[:blank:]]` | 空白字符（空格和制表符） |
| `[[:cntrl:]]` | 控制字符 |
| `[[:digit:]]` | 数字字符 |
| `[[:graph:]]` | 可打印字符（不包括空格） |
| `[[:lower:]]` | 小写字母 |
| `[[:print:]]` | 可打印字符（包括空格） |
| `[[:punct:]]` | 标点符号 |
| `[[:space:]]` | 空白字符（包括换行符、回车符等） |
| `[[:upper:]]` | 大写字母 |
| `[[:xdigit:]]` | 十六进制数字 |

```sql
-- 使用字符类
SELECT 'abc123' REGEXP '[[:alnum:]]+';  -- 返回 1
SELECT 'hello' REGEXP '[[:alpha:]]+';   -- 返回 1
SELECT '123' REGEXP '[[:digit:]]+';     -- 返回 1
```

### 特殊字符类

```sql
-- POSIX 字符类
SELECT 'a1' REGEXP '[[:alnum:]]';    -- 返回 1
SELECT 'A' REGEXP '[[:upper:]]';     -- 返回 1
SELECT 'a' REGEXP '[[:lower:]]';     -- 返回 1

-- 等价类 [=character=]
SELECT 'a' REGEXP '[[=a=]]';         -- 返回 1

-- 整理元素 [.character.]
SELECT '.' REGEXP '[[..]]';          -- 返回 1
```

## 转义字符

在正则表达式中，某些字符具有特殊含义。如果要匹配这些字符本身，需要使用反斜杠 `\` 进行转义。

| 特殊字符 | 转义写法 |
|----------|----------|
| `.` | `\.` |
| `*` | `\*` |
| `+` | `\+` |
| `?` | `\?` |
| `^` | `\^` |
| `$` | `\$` |
| `(` | `\(` |
| `)` | `\)` |
| `[` | `\[` |
| `]` | `\]` |
| `{` | `\{` |
| `}` | `\}` |
| <code>\|</code> | <code>\\&#124;</code> |
| `\` | `\\` |

```sql
-- 转义示例
SELECT 'a.c' REGEXP 'a\.c';        -- 返回 1 (匹配字面量点号)
SELECT 'a*c' REGEXP 'a\*c';        -- 返回 1 (匹配字面量星号)
SELECT 'a+c' REGEXP 'a\+c';        -- 返回 0 (匹配字面量加号)
SELECT 'price: $100' REGEXP '\\$'; -- 返回 1 (匹配美元符号)
```

## 字符集和排序规则

正则表达式操作根据输入字符串和正则模式参数的字符集及排序规则来确定匹配行为和比较方式：

* 如果参数具有不同的字符集或排序规则，则应用强制规则
* 如果任一参数是二进制字符串，则参数按二进制字符串以区分大小写的方式处理
* 支持 UTF-8、UTF-16 等多种字符集

```sql
-- 字符集示例
SELECT 'OceanBase' REGEXP 'oceanbase';     -- 返回 0 (区分大小写)

-- 二进制比较示例（需要使用二进制排序规则的字符集）
SELECT _utf8mb4'OceanBase' COLLATE utf8mb4_bin REGEXP _utf8mb4'oceanbase' COLLATE utf8mb4_bin; -- 返回 0
```

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OceanBase 中不支持在 <code>REGEXP</code> 函数中直接使用 <code>BINARY</code> 关键字。如果需要进行二进制比较，请使用 <code>COLLATE</code> 子句指定二进制排序规则的字符集。</p>
</main>

## 性能优化

OceanBase MySQL 模式对正则表达式进行了多项性能优化：

1. **表达式缓存**：编译后的正则表达式可以被缓存和复用
2. **常量优化**：对于常量模式的正则表达式，提供快速计算路径
3. **内存管理**：有效的临时内存分配和管理

<main id="notice" type='notice'>
<h4>注意</h4>
<p>复杂的正则表达式可能影响查询性能。建议在高并发场景下谨慎使用，并考虑使用数据库索引来优化查询性能。</p>
</main>

## 示例应用场景

### 数据提取

```sql
-- 提取字符串中的数字
SELECT REGEXP_SUBSTR('Price: $123.45', '\\d+\\.\\d+') AS price;

-- 提取URL中的域名
SELECT REGEXP_SUBSTR('https://www.example.com/path', 'https?://([^/]+)') AS domain;
```

### 数据清理

```sql
-- 移除多余的空白字符
SELECT REGEXP_REPLACE('hello   world', '\\s+', ' ') AS cleaned_text;

-- 格式化电话号码
SELECT REGEXP_REPLACE('12345678901', '(\\d{3})(\\d{4})(\\d{4})', '$1-$2-$3') AS formatted_phone;
```
