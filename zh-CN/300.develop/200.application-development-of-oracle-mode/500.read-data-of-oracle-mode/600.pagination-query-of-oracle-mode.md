# 分页查询

本文将向您介绍如何在 OceanBase 数据库 Oracle 模式下进行分页查询操作。

## 前提条件

* 您已连接 OceanBase 数据库 Oracle 模式租户。更多有关连接数据库的操作信息，请参见 [连接方式概述](../100.connect-to-oceanbase-database-of-oracle-mode/100.connection-methods-overview-of-oracle-mode.md)。
* 您已拥有 `SELECT` 权限。更多查看当前用户权限的相关操作信息，请参见 [查看用户权限](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/600.view-user-permissions-of-oracle-mode.md)。如果不具备该权限，请联系管理员为您授权，有关用户授权的相关操作信息，请参见 [直接授予权限](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/200.authority-of-oracle-mode.md)。

## 概述

在 OceanBase 数据库 Oracle 模式下，您可以使用 `Row_Limiting_Clause` 来实现分页查询。`Row_Limiting_Clause` 用于限制 `SELECT` 查询返回的行数，常用于分页操作。

`Row_Limiting_Clause` 的语法结构如下：

```sql
[ OFFSET offset { ROW | ROWS } ]
[ FETCH { FIRST | NEXT } [ { rowcount | percent PERCENT } ]
    { ROW | ROWS } { ONLY | WITH TIES } ]
```

**参数说明：**

| 参数 | 说明 |
|------|------|
| OFFSET offset | 指定要跳过的行数。`offset` 必须是一个非负整数。 |
| ROW \| ROWS | `ROW` 和 `ROWS` 是同义词，可以互换使用。 |
| FETCH | 指定要返回的行数或百分比。 |
| FIRST \| NEXT | `FIRST` 和 `NEXT` 是同义词，可以互换使用。 |
| rowcount | 要返回的行数，必须是一个正整数。使用方式：`FETCH FIRST rowcount ROWS ONLY`。 |
| percent PERCENT | 要返回的行数百分比。`percent` 是百分比数值参数，`PERCENT` 是关键字。使用方式：`FETCH FIRST percent PERCENT ROWS ONLY`。 |
| ONLY | 只返回指定的行数，不包含并列的行。 |
| WITH TIES | 返回指定的行数，如果最后一行有并列值，则包含所有并列的行。 |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><strong>分页查询必须使用 <code>ORDER BY</code> 子句</strong>，这是 Oracle 数据库的标准规范。如果不使用 <code>ORDER BY</code>，分页查询的结果顺序是不确定的，可能导致不同查询返回不同的结果，出现数据重复或遗漏的问题。</p>
</main>

1. 创建表 `employee_info`。

## 使用 ORDER BY 分页

**分页查询必须使用 `ORDER BY` 子句**。如果不使用 `ORDER BY`，数据库不保证查询结果的顺序，可能导致：

* 不同时间执行相同查询返回不同的结果顺序
* 分页查询出现数据重复或遗漏
* 分页结果不稳定，影响用户体验

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY employee_id 
OFFSET 0 ROWS FETCH NEXT 3 ROWS ONLY;
```

## 使用唯一字段排序

**您必须使用唯一字段（如主键）进行排序**，以确保分页结果的唯一性和稳定性。

如果 `ORDER BY` 使用的字段不是唯一的，对于具有相同排序值的行，它们的顺序是不确定的，可能导致分页查询时出现数据重复或遗漏。例如，如果按 `department_id` 排序，多个员工在同一个部门时，这些员工的相对顺序是任意的。

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY department_id, employee_id 
OFFSET 0 ROWS FETCH NEXT 3 ROWS ONLY;
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>如果必须按非唯一字段排序，您要在 <code>ORDER BY</code> 子句中添加唯一字段作为次要排序条件。例如：<code>ORDER BY department_id, employee_id</code>，这样可以确保排序结果的唯一性和稳定性。</p>
</main>

## 使用 FETCH 限制返回行数

查询前 3 条员工信息。

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY employee_id 
FETCH FIRST 3 ROWS ONLY;
```

## 使用 OFFSET 跳过指定行数

查询从第 4 行开始的所有员工信息。

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY employee_id 
OFFSET 3 ROWS;
```

## 使用 OFFSET 和 FETCH 实现分页

你可以使用 `OFFSET` 和 `FETCH` 实现分页查询。

查询第 2 页数据（每页 3 条）：

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY employee_id 
OFFSET 3 ROWS FETCH NEXT 3 ROWS ONLY;
```

## 使用百分比分页

除了使用固定行数进行分页外，您还可以使用 `PERCENT` 关键字按百分比返回数据。

### 查询前 30% 的数据

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY salary 
FETCH FIRST 30 PERCENT ROWS ONLY;
```

### 使用 WITH TIES 包含并列行

`WITH TIES` 选项会在返回指定行数的同时，如果最后一行有并列值，则包含所有并列的行。

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
ORDER BY salary 
FETCH FIRST 3 ROWS WITH TIES;
```

## 使用 ROWNUM 进行分页

在 Oracle 模式中，您也可以使用 `ROWNUM` 伪列进行分页查询，但这种方式相对复杂，需要配合子查询使用。建议您优先使用 `Row_Limiting_Clause` 进行分页查询，语法更简洁清晰。

### 使用 ROWNUM 查询前 N 条数据

查询前 3 条员工信息。

```sql
SELECT employee_id, employee_name, department_id, salary 
FROM employee_info 
WHERE ROWNUM <= 3 
ORDER BY employee_id;
```

### 使用 ROWNUM 实现分页查询

使用 `ROWNUM` 实现分页查询需要配合子查询。查询第 2 页（每页 3 条）的数据。

```sql
SELECT * FROM (
    SELECT employee_id, employee_name, department_id, salary, ROWNUM rn 
    FROM (
        SELECT employee_id, employee_name, department_id, salary 
        FROM employee_info 
        ORDER BY employee_id
    ) 
    WHERE ROWNUM <= 6
) 
WHERE rn > 3;
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>使用 <code>ROWNUM</code> 进行分页查询时， <code>ROWNUM</code> 是在数据返回后才分配的，您不能直接在 <code>WHERE</code> 子句中使用 <code>ROWNUM > N</code> 条件。因此，您要使用子查询来实现分页。</p>
</main>
