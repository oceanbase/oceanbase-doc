# OceanBase Connector/NET 连接 OceanBase 数据库示例程序

本文档介绍如何通过 OceanBase Connector/NET 驱动连接和使用 OceanBase 数据库 Oracle 模式。

## 环境准备

* 可访问的 OceanBase 数据库实例。
* 已获取数据库账号、密码、主机地址和端口信息。
* 已安装 .NET SDK（本文以 Linux/macOS 命令示例说明）。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>Linux 安装 .NET 10.0 前请先确认系统满足 glibc 版本要求。</p>
    </main>

## 操作步骤

### 步骤一：安装 .NET 运行环境

Windows 可直接从[微软官网](https://dotnet.microsoft.com/download/dotnet/10.0)下载安装包。Linux/macOS 可使用以下命令安装：

<main id="notice" type='explain'>
<h4>说明</h4>
<p>本文以 .NET 10.0 为示例。实际使用时，您可根据项目兼容性要求选择其他受支持的 .NET 版本，安装步骤一致。</p>
</main>

```shell
wget https://dot.net/v1/dotnet-install.sh -O dotnet-install.sh
chmod +x dotnet-install.sh
./dotnet-install.sh --channel 10.0
echo 'export PATH="$HOME/.dotnet:$HOME/.dotnet/tools:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

验证安装结果：

```shell
dotnet --version
```

若输出 `10.0.0` 或更高版本，说明安装成功。

### 步骤二：创建控制台项目

```shell
mkdir dotnet-test
cd dotnet-test
dotnet new console
dotnet run
```

若控制台输出 `Hello, World!`，说明项目创建成功。

### 步骤三：安装 OceanBase Connector/NET

将驱动下载到本地后，在项目目录中执行以下命令安装驱动：

```shell
dotnet add <你的项目.csproj> package Oceanbase.ManagedDataAccess --version 1.0.0 --source "<包所在仓库>" --source "https://api.nuget.org/v3/index.json"
```

<main id="notice" type='explain'>
<h4>说明</h4>
<p>如果使用官方 NuGet 包源，请保留 <code>--source "https://api.nuget.org/v3/index.json"</code>。</p>
</main>

也可以修改 `nuget.config` 配置，比如：

```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <add key="local-oceanbase" value="驱动下载目录" />
    <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
  </packageSources>
</configuration>
```

安装成功后，可在 `.csproj` 文件中看到如下配置：

```xml
<ItemGroup>
  <PackageReference Include="Oceanbase.ManagedDataAccess" Version="1.0.0" />
</ItemGroup>
```

## 步骤四：编写连接示例代码

将 `Program.cs` 修改为以下示例：

```csharp
using Oceanbase;

namespace Program
{
    class Program
    {
        static void Main(string[] args)
        {
            OracleConnection conn = new OracleConnection("Server=xxxxx;Port=5858;Database=test;User Id=test@oracle;Password=test;");

            try
            {
                conn.Open();
                OracleCommand cmd = new OracleCommand("select to_char(sysdate, 'yyyy-MM-dd HH24:mi:ss') from dual ", conn);
                var reader = cmd.ExecuteReader();
                while (reader.Read())
                {
                    Console.WriteLine("sysdate is:" + reader.GetString(0));
                }

            }
            catch (Exception ex)
            {
                Console.WriteLine(ex.Message);
            }
            finally
            {
                conn.Close();
            }
        }
    }
}
```

## 步骤五：运行连接验证

```shell
dotnet run
```

输出当前时间即表示连接和查询成功。

## 步骤六：连接测试

完成驱动安装后，您可以通过以下示例验证数据库连通性。OceanBase Connector/NET 使用 Oracle 兼容 API，连接方式与 Oracle ODP.NET 类似。

```csharp
using Oceanbase;

var connectionString = "Server=host;Port=port;Database=schema_name;User Id=username@tenant_name#cluster_name;Password=password;";
using var conn = new OracleConnection(connectionString);
conn.Open();

using var cmd = conn.CreateCommand();
cmd.CommandText = "SELECT 1 FROM DUAL";
var result = cmd.ExecuteScalar();
Console.WriteLine($"查询结果: {result}");

conn.Close();
```

相关参数解释如下表：

| 参数 | 说明 |
| ---- | ---- |
| Data Source | 数据源地址，**仅支持** <code>host</code> 或 <code>host:port</code>，不支持 <code>host:port/servicename</code>。host 为 OBServer 或 ODP 的 IP 或主机名，port 通常为 2881（直连）或 2883（通过 ODP）。服务名（若需要）请通过其他连接参数单独指定，勿写入 <code>Data Source</code>。 |
| User Id | 用户标识。经 ODP 连接时一般为三段式：<code>用户名@租户名#集群名</code>，与连接串中的 <code>User Id</code> 一致。云上部分场景支持一段式等简写。 |
| Password | 数据库密码。 |
| Database | **必填**。Oracle 模式下必须设置为 schema 名，否则 Open 会抛出 ArgumentException。 |
