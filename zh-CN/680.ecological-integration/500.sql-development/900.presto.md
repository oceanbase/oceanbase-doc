# 在 Presto 中连接 OceanBase 数据库

Presto 是一款开源的分布式 SQL 查询引擎，支持对多种数据源进行交互式分析查询。通过 MySQL Connector，Presto 可以连接 OceanBase 数据库，实现跨数据源的联邦查询和数据分析。本文介绍如何使用 Docker 部署 Presto 并连接 OceanBase 数据库。

## 版本兼容性

| 组件 | 版本要求 |
|------|---------|
| OceanBase | ≥ 4.2.5 |

## 前提条件

在使用 Presto 之前，确认：
* 已安装 Docker。Docker 安装参见 [Docker 官方文档](https://docs.docker.com/get-docker/)。
* 已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：准备 Presto 配置文件

1. 在宿主机上创建 Presto 配置目录，并进入该目录：

   ```bash
   mkdir -p ~/presto/catalog
   cd ~/presto
   ```

2. 创建 config.properties 文件，写入 Presto 基础配置：

   ```properties
   coordinator=true
   node-scheduler.include-coordinator=true
   http-server.http.port=8080
   discovery-server.enabled=true
   discovery.uri=http://127.0.0.1:8080
   ```

3. 创建 jvm.config 文件，写入 JVM 启动参数：

   ```
   -server
   -Xmx2G
   -XX:+UseG1GC
   -XX:G1HeapRegionSize=32M
   -XX:+UseGCOverheadLimit
   -XX:+ExplicitGCInvokesConcurrent
   -XX:+HeapDumpOnOutOfMemoryError
   -XX:+ExitOnOutOfMemoryError
   -Djdk.attach.allowAttachSelf=true
   ```

4. 创建 `catalog/oceanbase.properties` 文件，配置 OceanBase 连接信息：

   ```properties
   connector.name=mysql
   connection-url=jdbc:mysql://$host:$port?useSSL=false&serverTimezone=UTC
   connection-user=$user_name
   connection-password=$password
   ```

   将 <user_name> 和 <password> 替换为实际的 OceanBase 连接信息：
   **参数说明：**
   * `connector.name`：连接器类型，使用 `mysql` 连接 OceanBase。
   * `connection-url`：JDBC 连接串，将 `$host` 和 `$port` 替换为实际的 OceanBase 连接地址和端口，参见**步骤一**。
   * `connection-user`：OceanBase 连接用户名，格式为 `用户@租户`，参见**步骤一**。
   * `connection-password`：OceanBase 连接密码，参见**步骤一**。

### 步骤三：部署 Presto 容器

1. 拉取 Presto Docker 镜像：

   ```bash
   docker pull prestodb/presto:latest
   ```

2. 启动 Presto 容器，并挂载本地配置文件：

   ```bash
   docker run -d \
     --name presto \
     -v "$PWD/config.properties:/opt/presto-server/etc/config.properties" \
     -v "$PWD/jvm.config:/opt/presto-server/etc/jvm.config" \
     -v "$PWD/catalog:/opt/presto-server/etc/catalog" \
     prestodb/presto:latest
   ```

3. 查看容器日志，确认 Presto 启动成功：

   ```bash
   docker logs -f presto
   ```

   当日志中出现以下内容时，表示 Presto 已成功启动：

   ```text
   ======== SERVER STARTED ========
   ```

### 步骤四：连通性测试

1. 进入 Presto CLI：

   ```bash
   docker exec -it presto presto-cli
   ```

2. 查看当前已加载的 Catalog：

   ```sql
   SHOW CATALOGS;
   ```

   返回结果示例：

   ```
     Catalog
   -----------
    oceanbase
    system
   (2 rows)
   ```

3. 查看 OceanBase 中的 Schema：

   ```sql
   SHOW SCHEMAS FROM oceanbase;
   ```

   返回结果示例：

   ```
            Schema
   ------------------------
    information_schema
    oceanbase
    test
   (3 rows)
   ```

## 结果验证

当您在 Presto CLI 中执行 `SHOW CATALOGS` 能够看到 `oceanbase`，且执行 `SHOW SCHEMAS FROM oceanbase` 能够正常返回 Schema 列表时，说明 Presto 已成功连接 OceanBase 数据库。

您可以继续执行 SQL 查询语句验证数据访问功能，例如：

```sql
SHOW TABLES FROM oceanbase.test;
SELECT * FROM oceanbase.test.your_table_name LIMIT 10;
```
