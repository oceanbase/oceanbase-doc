# 通过 Trino 连接 OceanBase 数据库

Trino 是一款开源的分布式 SQL 查询引擎，支持对多种数据源进行高性能的交互式查询。通过 Trino OceanBase 连接器，您可以使用标准 SQL 对 OceanBase 数据库进行查询和分析，适用于数据探索、报表生成和跨数据源联合查询等场景。

## 版本兼容性

| 组件 | 版本要求 |
|------|---------|
| Trino | ≥ 433 |
| OceanBase | ≥ V4.2.5 |

## 前提条件

在使用 Trino 连接 OceanBase 数据库之前，需确认：
* 已安装 Docker。Docker 安装参见 [Docker 官方文档](https://docs.docker.com/get-docker/)。
* 已安装 Java 23.0.0 或更高版本（64-bit）。Java 安装参见 [Oracle Java 官方网站](https://www.oracle.com/java/)。
* 已完成部署 OceanBase 数据库并创建了 MySQL / Oracle 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>和<a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md">Oracle 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：构建 Trino OceanBase 插件

本文以 Trino 468 版本为例，介绍 Trino OceanBase 插件的构建与部署过程。

1. 克隆 Trino OceanBase 源码：

   ```shell
   git clone https://github.com/oceanbase/trino-oceanbase.git
   ```

2. 在项目根目录下执行以下命令构建插件：

   ```shell
   cd trino-oceanbase
   ./mvnw clean package -DskipTests
   ```

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>trino-oceanbase/pom.xml 中的 parent.versin 版本要与 Trino 保持一致。</p>
   </main>

3. 构建完成后，插件文件位于 `./target/trino-oceanbase-468` 目录下，使用以下命令可查看：

   ```shell
   ls -l ./target/trino-oceanbase-468
   ```

### 步骤三：部署 Trino 容器并配置连接

1. 创建日志配置文件 `log.properties`：

   ```shell
   cat > ./log.properties << EOF
   io.trino=DEBUG
   EOF
   ```

2. 创建 OceanBase 连接配置文件 `oceanbase.properties`：

   ```shell
   cat > ./oceanbase.properties << EOF
   connector.name=oceanbase
   connection-url=jdbc:oceanbase://\$host:\$port/\$database_name
   connection-user=\$user_name
   connection-password=\$password
   oceanbase.compatible-mode=mysql
   oceanbase.auto-reconnect=true
   oceanbase.remarks-reporting.enabled=true
   decimal-mapping=ALLOW_OVERFLOW
   decimal-rounding-mode=HALF_UP
   EOF
   ```

   **参数说明：**
   * `$host`：OceanBase 连接地址。
   * `$port`：OceanBase 连接端口。
   * `$database_name`：数据库名称。
   * `$user_name`：连接用户名。
   * `$password`：连接密码。

3. 启动 Trino Docker 容器：

   ```shell
   docker run -d \
     --name trino \
     -e TZ=Asia/Shanghai \
     -v ./target/trino-oceanbase-468:/usr/lib/trino/plugin/oceanbase \
     -v ./oceanbase.properties:/etc/trino/catalog/oceanbase.properties \
     -v ./log.properties:/etc/trino/log.properties \
     trinodb/trino:468

   # 查看容器状态。
   docker ps -a |grep trino
   ```

## 结果验证

在 Trino CLI 中执行 `SHOW CATALOGS;`

```shell
docker exec -it trino trino --execute 'SHOW CATALOGS;'
```

如果能够正常显示 OceanBase 数据库中的 Schema 列表，则表示连接配置正确。

```text
"jmx"
"memory"
"oceanbase"
"system"
"tpcds"
"tpch"
```
