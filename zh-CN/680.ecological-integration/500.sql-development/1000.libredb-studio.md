# 在 LibreDB Studio 中连接 OceanBase 数据库

LibreDB Studio 是一款开源、可自托管、在浏览器中运行的 SQL IDE。只需在服务器上部署一次，团队成员即可通过浏览器连接数据库，无需安装桌面客户端。本文以 OceanBase 数据库的 MySQL 模式租户和 LibreDB Studio 的 Docker 镜像为例，介绍如何在 LibreDB Studio 中连接 OceanBase 数据库。

## 前提条件

* 您已部署 LibreDB Studio。例如，执行 `docker run -p 3000:3000 ghcr.io/libredb/libredb-studio:latest`，然后在浏览器中打开 `http://localhost:3000`。首次启动时，管理员密码会输出到容器日志中。详情请参见 [LibreDB Studio GitHub 仓库](https://github.com/libredb/libredb-studio)。

* 请确保待连接的 OBServer 节点 IP 与 LibreDB Studio 所在服务器保持网络连通。

* 您已安装 OceanBase 数据库并且创建了 MySQL 模式租户。

## 操作步骤

### 步骤一：获取数据库连接串

联系 OceanBase 数据库部署人员或者管理员获取相应的数据库连接串，例如：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**

* `$host`：提供 OceanBase 数据库连接 IP。OceanBase 数据库代理（OceanBase Database Proxy，ODP）连接方式使用的是一个 ODP 地址；直连方式使用的是 OBServer 节点的 IP 地址。
* `$port`：提供 OceanBase 数据库连接端口。ODP 连接的方式默认是 `2883`，在部署 ODP 时可自定义；直连方式默认是 `2881`，在部署 OceanBase 数据库时可自定义。
* `$database_name`：需要访问的数据库名称。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>

* `$user_name`：提供租户的连接账户。ODP 连接的常用格式：`用户名@租户名#集群名` 或者 `集群名:租户名:用户名`；直连方式格式：`用户名@租户名`。
* `$password`：提供账户密码。

更多连接串的信息，请参见 [通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：在 LibreDB Studio 中创建 OceanBase 连接

1. 在浏览器中打开 LibreDB Studio 并登录。如果您以管理员身份登录，请先单击 **Editor** 进入编辑器。

2. 在左侧边栏顶部，单击 **LibreDB Studio** 右侧的加号（+），打开 **New Connection** 对话框。

3. 数据库类型选择 **MySQL**。

4. 根据 **步骤一：获取数据库连接串** 获取的连接串完成如下配置：

   |配置项|说明|
   |-----|----|
   |Connection Name|自定义的连接名称。|
   |Host & Instance|OceanBase 数据库连接地址和端口。在第一个输入框中填写连接串中 `-h` 参数的值，在第二个输入框中填写 `-P` 参数的值。|
   |Username|取自连接串中 `-u` 参数，账号名称，例如：`root@test`。|
   |Password|取自连接串中 `-p` 参数，账号密码。|
   |Database Name|取自连接串中 `-D` 参数，需要访问的数据库名称。|

5. 单击 **Test Connection**，测试是否能够成功连接。当界面显示以 **Connected successfully** 开头的提示时，表示连接成功。

6. 单击 **Establish Connection** 保存连接。连接会显示在侧边栏中，其下列出该租户的数据库。

## 后续操作

完成连接后，您可以在编辑器中执行 SQL 语句，并在侧边栏中浏览该租户的数据库和表。有关 LibreDB Studio 的详细使用说明，请参见 [LibreDB Studio GitHub 仓库](https://github.com/libredb/libredb-studio)。
