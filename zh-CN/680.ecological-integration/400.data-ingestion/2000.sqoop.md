# 使用 Sqoop 在 OceanBase 数据库与 HDFS 间迁移数据

Sqoop 是一款开源的数据迁移工具，主要用于在 Hadoop（Hive）与传统关系型数据库之间进行数据传递。Sqoop 支持将关系型数据库（如 MySQL、Oracle、PostgreSQL 等）中的数据导入到 Hadoop 的 HDFS 中，也可以将 HDFS 的数据导出到关系型数据库中，适用于数据迁移、数据同步、ETL 等场景。

## 版本兼容性

| 组件 | 版本要求 |
| --- | --- |
| Sqoop | V1.4.7 |
| OceanBase JDBC 驱动 | V2.4.0 |
| MySQL JDBC 驱动 | V5.1.47 |

## 使用限制

* 使用 OceanBase JDBC 驱动时，Oracle 模式下导出 HDFS 数据到 OceanBase 数据库不支持使用 `--table` 参数，会报语法错误 `ORA-00900`。
* Oracle 模式下导出数据时，必须使用 `--query` 参数指定查询语句。
* 使用 OceanBase JDBC 驱动时，必须手动指定 `--driver com.alipay.oceanbase.jdbc.Driver` 参数。

## 前提条件

在使用 Sqoop 之前，确认：
* 已安装 Hadoop 环境。Hadoop 安装请参考 [Hadoop 官方文档](https://hadoop.apache.org/docs/stable/hadoop-project-dist/hadoop-common/SingleCluster.html)。
* 已安装 Sqoop V1.4.7。安装方法请参考 [Sqoop 官方文档](https://sqoop.apache.org/docs/1.4.7/SqoopUserGuide.html)。
* 已安装 JDK 1.8 环境。JDK 安装请参考 [Oracle JDK 官方文档](https://www.oracle.com/java/technologies/javase/javase-jdk8-downloads.html)。
* 已下载 OceanBase JDBC 驱动（V2.4.0）或 MySQL JDBC 驱动（V5.1.47），并将驱动 JAR 包放置到 `$SQOOP_HOME/lib` 目录下。
* 您已完成部署 OceanBase 数据库并且创建了 MySQL / Oracle 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认 `2883`；直连默认 `2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群` 或 `集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：配置 Sqoop 环境

1. 下载并解压 Sqoop 安装包：

   访问 [Sqoop 官方下载页面](http://archive.apache.org/dist/sqoop/) 下载 `sqoop-1.4.7.bin__hadoop-2.6.0.tar.gz`，上传到 `/usr/local/sqoop` 目录并解压。

2. 配置环境变量：编辑 `/etc/profile` 文件，添加以下内容：

   ```shell
   export SQOOP_HOME=/usr/local/sqoop-1.4.7
   export PATH=$SQOOP_HOME/bin:$PATH
   ```

3. 使环境变量生效：执行 `source /etc/profile` 命令。

4. 将 JDBC 驱动 JAR 包放置到 `$SQOOP_HOME/lib` 目录下。

### 步骤三：使用 OceanBase 驱动导入数据到 HDFS

使用 OceanBase JDBC 驱动将 OceanBase 数据库中的数据导入到 HDFS。

**MySQL 模式示例：**

```shell
sqoop import --direct \
  --connect jdbc:oceanbase://$host:$port/$database_name \
  --username $user_name \
  --password $password \
  --query "select * from $table_name where \$CONDITIONS" \
  --target-dir /root/test \
  --delete-target-dir \
  --fields-terminated-by ',' \
  -m 1 \
  --bindir $SQOOP_HOME/lib \
  --driver com.alipay.oceanbase.jdbc.Driver
```

**Oracle 模式示例：**

```shell
sqoop import --direct \
  --connect jdbc:oceanbase://$host:$port/$database_name \
  --username $user_name \
  --password $password \
  --query "select * from $table_name where \$CONDITIONS" \
  --target-dir /root/test \
  --delete-target-dir \
  --fields-terminated-by ',' \
  -m 1 \
  --bindir $SQOOP_HOME/lib \
  --driver com.alipay.oceanbase.jdbc.Driver
```

<main id="notice" type='notice'>
    <h4>注意</h4>
    <p>Oracle 模式下必须使用 <code>--query</code> 参数，不支持使用 <code>--table</code> 参数，否则会报语法错误。</p>
</main>

**常用参数说明：**

| 参数 | 说明 |
| --- | --- |
| `--driver` | 手动指定 JDBC 驱动程序类。使用 OceanBase JDBC 驱动时必须指定为 `com.alipay.oceanbase.jdbc.Driver`。 |
| `--connect` | 指定数据库的 JDBC 连接 URL。 |
| `--username` | 数据库登录用户名。 |
| `--password` | 数据库登录密码。 |
| `--query` | 指定查询语句导入数据，必须配合 `--target-dir` 使用，查询条件中需包含 `\$CONDITIONS` 关键字。 |
| `--table` | 指定要导入的数据表名称，与 `--query` 参数二选一。 |
| `--target-dir` | 指定 HDFS 目标路径。 |
| `--delete-target-dir` | 如果目标路径已存在，则先删除。 |
| `--fields-terminated-by` | 设定字段分隔符，默认为逗号。 |
| `-m` 或 `--num-mappers` | 启动 N 个 Map 任务并行导入数据，默认为 4。 |
| `--bindir` | 指定编译生成的 class 文件存放路径。 |

### 步骤四：使用 OceanBase 驱动导出 HDFS 数据到 OceanBase

使用 OceanBase JDBC 驱动将 HDFS 中的数据导出到 OceanBase 数据库。

**MySQL 模式示例：**

```shell
sqoop export --direct \
  --connect jdbc:oceanbase://$host:$port/$database_name \
  --username $user_name \
  --password $password \
  --table $table_name \
  --export-dir /root/test \
  --input-fields-terminated-by ',' \
  -m 1 \
  --bindir $SQOOP_HOME/lib \
  --driver com.alipay.oceanbase.jdbc.Driver
```

<main id="notice" type='notice'>
    <h4>注意</h4>
    <p>Oracle 模式下导出功能不可用，使用 <code>--table</code> 参数会报语法错误 <code>ORA-00900</code>，原因是 Oracle 不支持表名使用 <code>AS</code> 语法。</p>
</main>

**常用参数说明：**

| 参数 | 说明 |
| --- | --- |
| `--driver` | 手动指定 JDBC 驱动程序类。使用 OceanBase JDBC 驱动时必须指定为 `com.alipay.oceanbase.jdbc.Driver`。 |
| `--connect` | 指定数据库的 JDBC 连接 URL。 |
| `--username` | 数据库登录用户名。 |
| `--password` | 数据库登录密码。 |
| `--table` | 指定要导出的目标数据表名称。 |
| `--export-dir` | 指定 HDFS 源数据路径。 |
| `--input-fields-terminated-by` | 指定输入字段分隔符。 |
| `-m` 或 `--num-mappers` | 启动 N 个 Map 任务并行导出数据，默认为 4。 |
| `--bindir` | 指定编译生成的 class 文件存放路径。 |

### 步骤五：使用 MySQL 驱动连接 MySQL 租户

使用 MySQL JDBC 驱动连接 OceanBase MySQL 模式租户，进行数据导入导出操作。

**测试连接：**

```shell
sqoop list-databases \
  --connect jdbc:mysql://$host:$port/$database_name \
  --username $user_name \
  --password $password
```

**导入数据到 HDFS：**

```shell
sqoop import \
  --connect jdbc:mysql://$host:$port/$database_name \
  --username $user_name \
  --password $password \
  --target-dir /root/test \
  --delete-target-dir \
  --table $table_name \
  --fields-terminated-by ',' \
  -m 1 \
  --bindir $SQOOP_HOME/lib
```

**导出 HDFS 数据到 OceanBase：**

```shell
sqoop export \
  --connect jdbc:mysql://$host:$port/$database_name \
  --username $user_name \
  --password $password \
  --table $table_name \
  --export-dir /root/test \
  --input-fields-terminated-by ',' \
  -m 1 \
  --bindir $SQOOP_HOME/lib
```

## 结果验证

### 验证数据导入到 HDFS

执行导入命令后，查看 HDFS 目标路径中的数据文件：

```shell
hdfs dfs -cat /root/test/part-m-00000
```

如果输出显示导入的数据记录，则表示导入成功。

### 验证数据导出到 OceanBase

执行导出命令后，连接到 OceanBase 数据库查询目标表：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name -e "SELECT COUNT(*) FROM $table_name;"
```

如果输出显示的记录数与 HDFS 源文件中的记录数一致，则表示导出成功。
