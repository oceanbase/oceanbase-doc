# 使用 mysqldump 导出 OceanBase 数据库数据

mysqldump 是 MySQL 自带的逻辑备份工具，通过协议连接到数据库，将需要备份的数据查询出来并转换成 INSERT 语句，用于数据还原。OceanBase 数据库兼容 MySQL 协议，支持使用 mysqldump 工具导出数据库、表、视图及数据，适用于数据迁移、备份和开发测试等场景。

## 版本兼容性

| 组件 | 版本要求 |
|------|---------|
| mysqldump | ≥ 8.0.40 |
| OceanBase | ≥ V2.0.4 |

## 使用限制

在使用 mysqldump 导出 OceanBase 数据库时，存在以下限制：

* **无法导出触发器**：所有版本的 mysqldump 都无法导出 OceanBase 的触发器。
* **无法导出存储过程**：所有版本的 mysqldump 都无法导出 OceanBase 的存储过程。
* **无法导出存储函数**：所有版本的 mysqldump 都无法导出 OceanBase 的存储函数。
* **无法直接导出所有库**：使用 `--all-databases` 参数导出所有数据库时会报错，建议逐个导出指定的数据库。

## 前提条件

在使用 mysqldump 之前，确认：

* 已安装 MySQL 客户端工具（包含 mysqldump）。mysqldump 是 MySQL 自带的工具，安装 MySQL 后即可使用。安装方法请参考 [MySQL 官方文档](https://dev.mysql.com/doc/refman/8.0/en/installing.html)。
* 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**

* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认 `2883`；直连默认 `2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群` 或 `集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：安装使用 mysqldump

以下以 mysqldump 8.0.45 版本为例，说明安装及导出操作。

1. 执行以下命令，安装 mysqldump ：

   ```shell
   apt install -y mysql-client-core-8.0
   ```

   安装完成后，可执行以下命令查看版本信息：

   ```text
   mysqldump --version
   ```

   示例输出如下：
   ```text
   mysqldump  Ver 8.0.45-0ubuntu0.22.04.1 for Linux on aarch64 ((Ubuntu))
   ```

2. 使用 mysqldump 导出指定的数据库，命令如下：

   ```shell
   mysqldump -h$host -P$port -u$user_name -p$password --databases $database_name > backup.sql
   ```

   **参数说明：**

   * `--databases`：指定要导出的数据库名称。可以指定多个数据库，用空格分隔。
   * `backup.sql`：导出的 SQL 文件名称。

   **示例：**

   ```shell
   mysqldump -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** --databases test > test_backup.sql
   ```

3. 导出指定表。

   如果只需要导出数据库中的某些表，可以使用以下命令：

   ```shell
   mysqldump -h$host -P$port -u$user_name -p$password $database_name $table_name1 $table_name2 > tables_backup.sql
   ```

   **参数说明：**

   * `$database_name`：数据库名称。
   * `$table_name1 $table_name2`：要导出的表名称，可以指定多个表。

   **示例：**

   ```shell
   mysqldump -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** test table1 table2 > tables_backup.sql
   ```

4. 导出表的部分数据。

   如果只需要导出表中的部分数据，可以使用 `--where` 参数指定条件：

   ```shell
   mysqldump -h$host -P$port -u$user_name -p$password $database_name $table_name --where="条件表达式" > partial_backup.sql
   ```

   **参数说明：**

   * `--where`：指定导出数据的条件表达式。

   **示例：**

   ```shell
   mysqldump -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** test table1 --where="id < 1000" > partial_backup.sql
   ```

## 结果验证

导出完成后，可以通过以下方式验证导出结果：

1. 查看导出的 SQL 文件大小，确认文件已生成且不为空。

   ```shell
   ls -lh backup.sql
   ```

2. 查看导出的 SQL 文件内容，确认包含表结构和数据。

   ```shell
   head -n 50 backup.sql
   ```

3. 在测试环境中导入导出的 SQL 文件，验证数据的完整性和正确性。

   ```shell
   mysql -h$host -P$port -u$user_name -p$password $database_name < backup.sql
   ```

## 常见问题

### Q1：使用 mysqldump 导出所有数据库时报错怎么办？

**原因**：OceanBase 的 `information_schema.views` 只包含用户创建的视图，不包含系统视图，导致 mysqldump 在导出所有数据库时无法获取系统视图的结构信息。

**解决方案**：不要使用 `--all-databases` 参数导出所有数据库，而是逐个导出指定的数据库。

### Q2：使用 mysqldump 8.0.26 或 8.0.40 导出时报错 "Unknown system variable 'information_schema_stats_expiry'" 怎么办？

**原因**：mysqldump 8.0.3 及以上版本会执行 `SET SESSION information_schema_stats_expiry=0`，而 OceanBase 低版本不支持该系统变量。

**解决方案**：
* 使用 mysqldump 10.19（MariaDB 版本）。
* 或升级 OceanBase 到 V4.2.5 及以上版本，该版本已支持 mysqldump 8.0.40。

### Q3：使用 mysqldump 导出云上的 OceanBase 需要开启 binlog 吗？

**原因**：mysqldump 是逻辑备份工具，通过查询数据生成 INSERT 语句，不依赖 binlog。

**解决方案**：不需要开启 binlog。

### Q4：如何导出 MySQL 兼容格式的表结构？

**原因**：默认情况下，OceanBase 的 `SHOW CREATE TABLE` 输出可能与 MySQL 格式不完全一致。

**解决方案**：
* 配置参数 `_show_ddl_in_compat_mode`为 1，，此时 `SHOW CREATE TABLE` 会显示成 MySQL 兼容格式。
