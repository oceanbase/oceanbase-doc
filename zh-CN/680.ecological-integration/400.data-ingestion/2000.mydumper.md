# 使用 mydumper 备份 OceanBase 数据库数据

mydumper 是一款社区开源的逻辑备份工具，由 C 语言编写，支持多线程导出、一致性备份、文件压缩、多线程恢复等功能，适用于数据迁移、备份恢复、数据同步等场景。OceanBase 数据库兼容 mydumper 工具，可通过配置特定参数实现高效的数据备份与恢复。

## 版本兼容性

| 组件 | 说明 |
|------|------|
| OceanBase 数据库 | ≥ V4.2.5 |

## 使用限制

使用 mydumper 备份 OceanBase 数据库时，需注意以下限制：

* OceanBase 不支持 `flush no_write_to_binlog tables` 语句，需使用 `--no-locks` 或 `--sync-thread-lock-mode NO_LOCK`  参数规避。
* OceanBase 不支持 `flush tables with read lock` 语句，需使用 `--no-locks` 或 `--sync-thread-lock-mode NO_LOCK` 参数规避。
* OceanBase 的 `EXPLAIN` 输出格式与 MySQL 不一致，可能导致 mydumper 报 `Segmentation fault` 错误，需使用 `--check-row-count` 参数规避。
* OceanBase 的 `show processlist` 结果字段与 MySQL 不一致，需在 obproxy 中执行 `alter proxyconfig set client_session_id_version = 2;` 配置。
* 偶发的 `Segmentation fault` 错误可通过使用 OBProxy ≥ V4.3.3 版本规避。

## 前提条件

在使用 mydumper 之前，确认：

* 已安装 mydumper。安装方法请参考 [mydumper 官方文档](https://github.com/mydumper/mydumper)。
* 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。
* 已获取 OceanBase 数据库连接信息，包括主机地址、端口、用户名、密码和数据库名。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**

* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：安装 mydumper

1. 下载 mydumper 安装包：

   访问 [mydumper releases 页面](https://github.com/mydumper/mydumper/releases)，下载对应版本的 RPM 包，例如 `mydumper-0.21.4-1.el7.x86_64.rpm`。

2. 安装 mydumper：执行以下命令安装 mydumper。

   ```shell
   yum install mydumper-0.21.4-1.el7.x86_64.rpm
   ```

### 步骤三：使用 mydumper 备份数据

1. 执行备份命令：使用 mydumper 备份 OceanBase 数据库，需添加 `--no-locks` 和 `--check-row-count` 参数以确保兼容性。

   ```shell
   mydumper -h $host -P $port -u $user_name -p $password -B $database_name --no-locks --check-row-count -o /path/to/backup
   ```

   **参数说明：**

   * `-h`：OceanBase 数据库连接地址。
   * `-P`：OceanBase 数据库连接端口。
   * `-u`：连接用户名。
   * `-p`：连接密码。
   * `-B`：要备份的数据库名称。
   * `--no-locks`：跳过锁表操作，规避 OceanBase 不支持 `flush tables with read lock` 的问题。
   * `--check-row-count`：跳过行数检查，规避 OceanBase `EXPLAIN` 输出格式不一致的问题。
   * `-o`：备份文件输出目录。

   **示例如下：**

   ```shell
   mydumper -h xxx.xxx.xxx.xxx -P 2883 -u test_user001@mysql001 -p ****** -B test --no-locks --check-row-count -o /backup/test
   ```

2. 检查备份文件：备份完成后，在指定的输出目录中查看备份文件。

   ```shell
   ls -l /backup/test
   ```

   备份文件包括：
   * `metadata`：备份元数据信息。
   * `*-schema-create.sql`：数据库创建语句。
   * `*-schema.sql`：表结构定义文件。
   * `*.sql`：表数据文件。

### 步骤四：使用 myloader 恢复数据

执行恢复命令：使用 myloader 将备份的数据恢复到 OceanBase 数据库。

```shell
myloader -h $host -P $port -u $user_name -p $password -B $database_name -d /path/to/backup
```

**参数说明：**

* `-h`：OceanBase 数据库连接地址。
* `-P`：OceanBase 数据库连接端口。
* `-u`：连接用户名。
* `-p`：连接密码。
* `-B`：要恢复的数据库名称。
* `-d`：备份文件目录。

**示例如下：**

```shell
myloader -h xxx.xxx.xxx.xxx -P 2883 -u test_user001@mysql001 -p ****** -B test -d /backup/test
```

## 结果验证

### 验证备份文件

备份完成后，检查备份目录中的文件：

```shell
ls -lh /backup/test
```

确认以下文件存在：
* `metadata`：包含备份时间、binlog 位置等元数据信息。
* `*-schema-create.sql`：数据库创建语句。
* `*-schema.sql`：表结构定义。
* `*.sql` 或 `*.sql.gz`：表数据文件（如果使用了压缩）。

### 验证数据完整性

1. 连接到 OceanBase 数据库，查看表数量和记录数。

   ```sql
   SELECT COUNT(*) FROM information_schema.tables WHERE table_schema = 'test';
   SELECT table_name, table_rows FROM information_schema.tables WHERE table_schema = 'test';
   ```

2. 对比备份前后的数据，确认数据一致性。
