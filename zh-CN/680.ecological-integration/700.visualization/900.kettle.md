# 在 Kettle 中连接 OceanBase 并获取数据

Kettle 是一款纯 Java 开发的开源 ETL 工具，用于数据库间的数据迁移，支持 Linux、Windows、Unix 等多平台运行。Kettle 提供图形化界面和命令行脚本，支持通过 JDBC 或 JNDI 方式连接 OceanBase 数据库，实现数据的抽取、转换和加载操作。

## 版本兼容性

| 组件 | 版本要求 |
| --- | --- |
| Kettle | ≥ V9.2 |
| OceanBase JDBC 驱动 | ≥ V2.4.0 |

## 前提条件

在使用 Kettle 之前，确认：
* 已安装 Kettle。Kettle 安装请参考 [Hitachi Vantara 官方下载页面](https://community.hitachivantara.com/resources/product-downloads)。
* 已安装 JDK V1.8 或更高版本。JDK 安装请参考 [Oracle 官方文档](https://www.oracle.com/java/technologies/javase/javase-jdk8-downloads.html)。
* 已完成 OceanBase 数据库部署并创建了 MySQL 模式用户租户。创建用户租户的详细信息，请参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认 `2883`；直连默认 `2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群` 或 `集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见 [通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：引入 OceanBase 驱动文件

1. 下载 OceanBase JDBC 驱动。下载地址请参见 [OceanBase 官方文档](https://mvnrepository.com/artifact/com.oceanbase/oceanbase-client)。
2. 将获取的驱动 JAR 文件（如 `oceanbase-client-2.4.0.jar`）复制到 Kettle 安装目录下的 `lib` 文件夹中。

### 步骤三：配置 JDBC 连接

1. 启动 Kettle：进入 Kettle 安装目录，双击 `spoon.bat`（Windows）或执行 `./spoon.sh`（Linux）启动图形界面。
2. 创建数据库连接：点击 **文件** > **新建** > **转换** > **新建** > **数据库连接**。
3. 配置连接参数：
   * **连接名称**：输入连接名称，如 `oceanbase`。
   * **连接类型**：选择 `Native（JDBC）`。
   * **数据库类型**：选择 `Generic database`。
   * **自定义连接 URL**：输入 JDBC 连接串，格式为 `jdbc:oceanbase://$host:$port/$database_name?characterEncoding=UTF-8`。
   * **自定义驱动类名称**：输入 `com.oceanbase.jdbc.Driver`。
   * **用户名**：输入 `$user_name`。
   * **密码**：输入 `$password`。
4. 点击 **测试** 按钮验证连接。如果显示"正确连接到数据库"，则连接成功。

### 步骤四：配置 JNDI 连接（可选）

如果需要使用 JNDI 方式连接 OceanBase，请按以下步骤操作：

1. 将 OceanBase JDBC 驱动 JAR 文件复制到 Kettle 安装目录下的 `lib` 文件夹中。
2. 打开 Kettle 安装目录下的 `simple-jndi/jdbc.properties` 文件，添加以下配置：

   ```properties
   ob_ora/type=javax.sql.DataSource
   ob_ora/driver=com.alipay.oceanbase.jdbc.Driver
   ob_ora/url=jdbc:oceanbase://$host:$port/$database_name
   ob_ora/user=$user_name
   ob_ora/password=$password
   ```

3. 在 Kettle 中创建数据库连接时，选择 **连接类型** 为 `JNDI`，并在 **JNDI 名称** 中输入配置文件中定义的名称（如 `ob_ora`）。
4. 点击 **测试** 按钮验证连接。

## 结果验证

连接成功后，可以在 Kettle 中执行以下操作验证功能：

* **数据库操作**：创建表、删除表、增加列、删除列、修改列、增加索引、删除索引。
* **数据操作**：插入数据（单个、批量）、删除数据（单个、批量）、修改数据（单个、批量）、查询数据（单个、批量）。


## 常见问题

### Q1：使用 Kettle 进行数据迁移时，Number 列出现精度丢失问题如何解决？

**原因**：Kettle 使用不同数据库时会采用不同的处理策略，导致与 Oracle 不兼容，从而在数据迁移过程中丢失精度。

**解决方案**：使用 OceanBase 连接插件。该插件继承自 Oracle 连接插件，使 Kettle 认为该 OB 驱动连接的是 Oracle 数据库，从而走 Oracle 的处理策略。联系 OceanBase 技术支持获取解决方案。

### Q2：在 Oracle 模式下修改列时报错如何处理？

**原因**：在 Oracle 模式下，修改列操作可能触发内部错误，错误信息为 `ORA-00600: internal error code, arguments: -4007, Truncate the data of column schema not supported`。

**解决方案**：联系 OceanBase 技术支持获取解决方案。
