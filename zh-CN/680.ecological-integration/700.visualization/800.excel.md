# 在 Excel 中连接 OceanBase 并获取数据

## 概述

Excel 是广泛使用的电子表格与数据可视化工具，通过 OceanBase ODBC 驱动可直接连接 OceanBase 数据库，实现高效的数据查询与分析。
本文将介绍如何在 WPS Office Excel 和 Microsoft Excel 中通过 ODBC 数据源方式连接 OceanBase 数据库。

## 版本兼容性

- OceanBase 数据库版本：≥ V4.2.5 BP2。

## 前提条件

在使用 Excel 连接 OceanBase 之前，确认：

- 已安装 Excel（WPS Office Excel 或 Microsoft Excel）。
- 已安装 OceanBase ODBC 驱动（版本 ≥ 2.0.9.5hotfix）。暂未公开下载，可联系技术支持人员获取。
- 您已完成部署 OceanBase 数据库并且创建了 Oracle / MySQL 模式用户租户。创建用户租户的详细信息，参见 <a href="../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md">创建租户</a>。

## 操作步骤

### 步骤一：获取数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认 `2883`；直连默认 `2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见<a href="../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md">通过 OBClient 连接 OceanBase 租户</a>。

**示例如下：**
```shell
obclient -h$host -P2881 -u$user_name -p$password -D$database_name
```

### 步骤二：配置 ODBC DSN

本文演示以 OceanBase Oracle 模式用户租户为例配置 ODBC DSN（ OceanBase MySQL 模式用户租户同理 ），操作如下：

1. 打开系统 ODBC 数据源管理器。
2. 在 **系统 DSN** 或 **用户 DSN** 选项卡中，点击 **添加**。
3. 选择 **OceanBase ODBC 2.0 Driver** 驱动。
4. 配置连接参数：
    - **Data Source Name**：输入 DSN 名称（如 `OBORACLE`）。
    - **Description**：可选描述。
    - **Server name**：OceanBase 服务器地址（对应 `$host`）。
    - **Port**：端口号（对应 `$port`）。
    - **Database**：数据库名称（对应 `$database_name`）。
    - **User name**：用户名（对应 `$user_name`）。
    - **Password**：密码（对应 `$password`）。

### 步骤三：连接 OceanBase

#### WPS Office Excel

1. 打开 WPS Office Excel。
2. 导航至 **数据** → **获取数据** → **导入数据** → **ODBC DSN**。
3. 在数据源选择对话框中，选择已配置的 **ODBC DSN**（如 `OBORACLE`）。
4. 选择需要导入的**表和字段**。
5. 在数据筛选与排序步骤中，可直接**输入 SQL 语句**进行查询。
6. 预览并完成**数据导入**。

#### Microsoft Excel

1. 打开 Microsoft Excel。
2. 导航至 **数据** → **获取数据** → **自其他源** → **从 ODBC**。
3. 选择已配置的 **ODBC DSN**（如 `OBORACLE`）。
4. 在高级选项中可直接**输入 SQL 语句**，例如：

```sql
SELECT * FROM T1;
```

5. 点击 **确定** 并加载数据。

## 常见问题

**Q1：连接 OceanBase 数据库时出现乱码问题怎么办？**
**原因**：ODBC 驱动版本过低。
**解决方案**：升级到 OceanBase ODBC 2.0.9.5hotfix 或更高版本。
