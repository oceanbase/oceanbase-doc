# 使用 TypeORM 连接 OceanBase 数据库

TypeORM 是一个支持 TypeScript 和 JavaScript 的 ORM 框架，支持多种数据库系统。本文将介绍如何使用 TypeORM 连接 OceanBase 数据库的 MySQL 模式。

## 前提条件

* 已安装 Node.js 14.0.0 或更高版本
* 已安装 npm 或 yarn 包管理器
* 已部署 OceanBase 数据库并且创建了 MySQL 模式租户
* TypeScript 环境（推荐）

## 操作步骤

1. 检查 Node.js 和 npm 版本
2. 安装必要的依赖
3. 获取 OceanBase 数据库连接信息
4. 创建并配置项目
5. 运行示例程序

### 步骤一：检查 Node.js 和 npm 版本

打开终端，运行以下命令检查 Node.js 和 npm 的版本：

```bash
node -v
npm -v
```

### 步骤二：安装必要的依赖

1. 创建项目目录并初始化：

    ```bash
    mkdir typeorm-oceanbase-demo
    cd typeorm-oceanbase-demo
    npm init -y
    ```

2. 安装 TypeORM 和 MySQL2 驱动：

    ```bash
    npm install typeorm mysql2 reflect-metadata
    
    # 如果使用 TypeScript
    npm install --save-dev typescript @types/node
    
    # 初始化 TypeScript 配置
    npx tsc --init
    ```

### 步骤三：获取 OceanBase 数据库连接信息

联系 OceanBase 数据库部署人员或者管理员获取相应的数据库连接信息。

```bash
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**

* `$host`：提供 OceanBase 数据库连接 IP
* `$port`：提供 OceanBase 数据库连接端口
* `$database_name`：需要访问的数据库名称
* `$user_name`：提供租户的连接账户
* `$password`：提供账户密码

### 步骤四：创建并配置项目

1. 创建项目结构：

    ```text
    typeorm-oceanbase-demo/
    ├── src/
    │   ├── entity/
    │   │   └── User.ts
    │   ├── migration/
    │   └── index.ts
    ├── ormconfig.json
    ├── .env
    └── package.json
    ```

2. 创建 TypeORM 配置文件：

创建 `ormconfig.json` 文件：

```json
{
  "type": "mysql",
  "host": "oceanbase-host",
  "port": 2881,
  "username": "your_username",
  "password": "your_password",
  "database": "your_database",
  "synchronize": true,
  "logging": false,
  "entities": ["src/entity/**/*.ts"],
  "migrations": ["src/migration/**/*.ts"],
  "subscribers": ["src/subscriber/**/*.ts"]
}
```

3. 创建数据库连接：

创建 `src/index.ts` 文件：

```typescript
import "reflect-metadata";
import { createConnection } from "typeorm";

createConnection().then(async connection => {
    console.log("数据库连接成功");
    // 在这里执行数据库操作
    
}).catch(error => console.log("数据库连接失败: ", error));
```

### 步骤五：运行示例程序

1. 定义实体：

创建 `src/entity/User.ts` 文件：

```typescript
import { Entity, PrimaryGeneratedColumn, Column } from "typeorm";

@Entity()
export class User {
    @PrimaryGeneratedColumn()
    id: number;

    @Column()
    firstName: string;

    @Column()
    lastName: string;

    
    @Column({ unique: true })
    email: string;

    @Column()
    age: number;
}
```

## CRUD 操作

### 创建记录

```typescript
const user = new User();
user.firstName = "张";
user.lastName = "三";
user.email = "zhangsan@example.com";
user.age = 25;

await connection.manager.save(user);
console.log("用户已保存，用户ID: ", user.id);
```

### 查询记录

```typescript
// 查询所有用户
const users = await connection.manager.find(User);
console.log("所有用户: ", users);

// 按条件查询
const specificUser = await connection.manager.findOne(User, { 
    where: { 
        firstName: "张",
        lastName: "三"
    } 
});

// 使用 QueryBuilder 进行复杂查询
const userRepository = connection.getRepository(User);
const users = await userRepository
    .createQueryBuilder("user")
    .where("user.age > :age", { age: 18 })
    .orderBy("user.age", "DESC")
    .getMany();
```

### 更新记录

```typescript
await connection
    .createQueryBuilder()
    .update(User)
    .set({ firstName: "李", lastName: "四" })
    .where("id = :id", { id: 1 })
    .execute();
```

### 删除记录

```typescript
await connection
    .createQueryBuilder()
    .delete()
    .from(User)
    .where("id = :id", { id: 1 })
    .execute();
```

## 关联关系

### 一对一关系

```typescript
import { Entity, PrimaryGeneratedColumn, Column, OneToOne, JoinColumn } from "typeorm";

@Entity()
export class Profile {
    @PrimaryGeneratedColumn()
    id: number;

    @Column()
    gender: string;

    @Column()
    photo: string;

    @OneToOne(() => User)
    @JoinColumn()
    user: User;
}

// 在 User 实体中添加
@OneToOne(() => Profile, profile => profile.user)
profile: Profile;
```

### 一对多/多对一关系

```typescript
@Entity()
export class Post {
    @PrimaryGeneratedColumn()
    id: number;

    @Column()
    title: string;

    @Column("text")
    content: string;

    @ManyToOne(() => User, user => user.posts)
    author: User;
}

// 在 User 实体中添加
@OneToMany(() => Post, post => post.author)
posts: Post[];
```

### 多对多关系

```typescript
@Entity()
export class Category {
    @PrimaryGeneratedColumn()
    id: number;

    @Column()
    name: string;

    @ManyToMany(() => Question, question => question.categories)
    questions: Question[];
}

// 在 Question 实体中
@Entity()
export class Question {
    @PrimaryGeneratedColumn()
    id: number;

    @Column()
    title: string;

    @ManyToMany(() => Category, category => category.questions)
    @JoinTable()
    categories: Category[];
}
```

## 高级用法

### 事务处理

```typescript
await connection.transaction(async transactionalEntityManager => {
    const user = new User();
    user.firstName = "王";
    user.lastName = "五";
    user.email = "wangwu@example.com";
    user.age = 30;
    
    await transactionalEntityManager.save(user);
    
    const post = new Post();
    post.title = "我的第一篇文章";
    post.content = "这是文章内容...";
    post.author = user;
    
    await transactionalEntityManager.save(post);
});
```

3. 使用 Repository 模式：

```typescript
const userRepository = connection.getRepository(User);

// 创建
const newUser = userRepository.create({
    firstName: "赵",
    lastName: "六",
    email: "zhaoliu@example.com",
    age: 28
});
await userRepository.save(newUser);

// 查询
const users = await userRepository.find({ 
    where: { 
        age: MoreThan(20) 
    },
    order: { age: "DESC" },
    take: 10
});

// 更新
await userRepository.update(1, { age: 29 });

// 删除
await userRepository.delete(1);
```

## 数据迁移

1. 在 `package.json` 中添加脚本：

```json
{
  "scripts": {
    "typeorm": "ts-node ./node_modules/typeorm/cli.js"
  }
}
```

2. 创建迁移：

```bash
npm run typeorm migration:create -- -n CreateUsersTable
```

3. 运行迁移：

```bash
npm run typeorm migration:run
```
