# zorm 连接 OceanBase 数据库示例程序

zorm 是一个基于原生 SQL 的 Go 语言轻量级 ORM 框架，专为 Go 应用程序设计。它具有以下特点：

* 通过 `Finder` 构造 SQL，保留原生 SQL 的灵活性，学习成本较低
* 核心库零依赖，数据库驱动按需引入
* 使用 `context.Context` 实现事务传播，支持多数据源和读写分离
* 支持 MySQL、PostgreSQL、Oracle、SQLite 等数据库

本文将介绍如何使用 zorm 连接 OceanBase 数据库，实现基本的数据库操作，包括创建表、插入数据、更新数据、查询数据和删除数据等。

<main id="notice" type='explain'>
  <h4>功能适用性</h4>
  <p>zorm ORM 适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 前提条件

* 您已安装 Go 1.13 或更高版本。
* 您已安装 OceanBase 数据库并且创建了 MySQL 模式租户。
* 您已获取 OceanBase 数据库连接串。

## 操作步骤

1. 获取 OceanBase 数据库连接串。
2. 安装 Go 语言和 zorm。
3. 编写 `main.go` 文件，实现数据库操作。
4. 运行程序并验证结果。

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员或者管理员获取相应的数据库连接串。

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**

* `$host`：提供 OceanBase 数据库连接 IP。OceanBase 数据库代理（OceanBase Database Proxy，ODP）连接方式使用的是一个 ODP 地址；直连方式使用的是 OBServer 节点的 IP 地址。
* `$port`：提供 OceanBase 数据库连接端口。ODP 连接的方式默认是 `2883`，在部署 ODP 时可自定义；直连方式默认是 `2881`，在部署 OceanBase 数据库时可自定义。
* `$database_name`：需要访问的数据库名称。

    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>UPDATE</code>、<code>SELECT</code> 和 <code>DELETE</code> 权限。更多有关用户权限的信息，请参见 <a href="../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>

* `$user_name`：提供租户的连接账户。ODP 连接的常用格式：`用户名@租户名#集群名` 或者 `集群名:租户名:用户名`；直连方式格式：`用户名@租户名`。
* `$password`：提供账户密码。

更多连接串的信息，请参见 [通过 OBClient 连接 OceanBase 租户](../../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：安装 Go 语言和 zorm

若您已经安装了 Go 语言和 zorm，可以直接跳过此步骤。若您未安装，可根据以下步骤进行安装。

1. 安装 Go 语言

    1. 更新系统包并安装必要的依赖：

        ```bash
        sudo apt update
        sudo apt install -y wget
        ```

    2. 下载并安装 Go 语言：

        ```bash
        # 下载 Go 1.25.14（请访问 https://go.dev/dl/ 获取最新版本）
        wget https://go.dev/dl/go1.25.14.linux-amd64.tar.gz

        # 解压到 /usr/local 目录
        sudo tar -C /usr/local -xzf go1.25.14.linux-amd64.tar.gz

        # 删除安装包
        rm go1.25.14.linux-amd64.tar.gz
        ```

    3. 配置环境变量：

        ```bash
        # 编辑 ~/.bashrc 文件
        echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
        echo 'export GOPATH=$HOME/go' >> ~/.bashrc
        echo 'export PATH=$PATH:$GOPATH/bin' >> ~/.bashrc

        # 使配置生效
        source ~/.bashrc
        ```

    4. 验证安装：

        ```bash
        go version
        ```

        如果安装成功，将显示类似以下内容：

        ```bash
        go version go1.25.14 linux/amd64
        ```

2. 安装 zorm 和 MySQL 驱动

    1. 创建工作目录并初始化 Go 模块：

       ```bash
       mkdir -p ~/go/src/zorm-oceanbase
       cd ~/go/src/zorm-oceanbase
       go mod init zorm-oceanbase
       ```

    2. 安装 zorm 和 MySQL 驱动：

       ```bash
       go get -u gitee.com/chunanyong/zorm
       go get -u github.com/go-sql-driver/mysql
       ```

    3. （可选）如果由于网络原因无法直接安装，可以设置 Go 代理：

       ```bash
       go env -w GOPROXY=https://goproxy.cn,direct
       ```

       然后重新执行安装命令。

3. 验证安装：

    ```bash
    go list -m gitee.com/chunanyong/zorm
    go list -m github.com/go-sql-driver/mysql
    ```

    如果安装成功，将显示相应的版本信息。

### 步骤三：编写 main.go 文件实现数据库操作

zorm 不提供自动迁移功能，且 `Insert`、`Update`、`Delete` 等写操作必须显式放在 `zorm.Transaction` 中执行。本示例通过 `UpdateFinder` 创建 `users` 表，并在事务中完成数据写入。生产环境中建议使用数据库版本管理工具维护表结构。

将以下代码中的 DSN 替换为实际的连接信息，然后保存为 `main.go`。

1. 创建一个名为 `main.go` 的文件，并添加以下代码：

    ```go
    package main

    import (
        "context"
        "fmt"
        "log"
        "time"

        "gitee.com/chunanyong/zorm"
        _ "github.com/go-sql-driver/mysql"
    )

    const usersTableName = "users"

    // User 定义用户模型
    type User struct {
        zorm.EntityStruct

        ID        int64     `column:"id"`
        Username  string    `column:"username"`
        Email     string    `column:"email"`
        Age       int       `column:"age"`
        CreatedAt time.Time `column:"created_at"`
        UpdatedAt time.Time `column:"updated_at"`
    }

    // GetTableName 指定表名
    func (u *User) GetTableName() string {
        return usersTableName
    }

    // GetPKColumnName 指定主键列名
    func (u *User) GetPKColumnName() string {
        return "id"
    }

    // initDB 初始化数据库连接
    func initDB() error {
        config := zorm.DataSourceConfig{
            // DSN 中 parseTime=true 会自动将时间类型转换为 time.Time，loc=Local 用于设置时区
            DSN:                   "root@mysql001:**********@tcp(xxx.xxx.xxx.xxx:2881)/db_test?charset=utf8mb4&parseTime=true&loc=Local",
            DriverName:            "mysql",
            Dialect:               "mysql",
            MaxOpenConns:          50,
            MaxIdleConns:          20,
            ConnMaxLifetimeSecond: 600,
            SlowSQLMillis:         -1,
        }

        if _, err := zorm.NewDBDao(&config); err != nil {
            return fmt.Errorf("初始化 zorm 失败: %w", err)
        }
        return nil
    }

    // createTable 创建用户表
    func createTable(ctx context.Context) error {
        const ddl = `CREATE TABLE IF NOT EXISTS users (
            id BIGINT NOT NULL AUTO_INCREMENT,
            username VARCHAR(100) NOT NULL,
            email VARCHAR(100) NOT NULL,
            age INT NOT NULL DEFAULT 0,
            created_at DATETIME NOT NULL,
            updated_at DATETIME NOT NULL,
            PRIMARY KEY (id)
        ) DEFAULT CHARSET = utf8mb4`

        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.UpdateFinder(ctx, zorm.NewFinder().Append(ddl))
            return nil, err
        })
        return err
    }

    // createUser 插入用户数据
    func createUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Insert(ctx, user)
            return nil, err
        })
        return err
    }

    // getUserByID 根据主键查询用户
    func getUserByID(ctx context.Context, id int64) (*User, error) {
        user := &User{}
        finder := zorm.NewSelectFinder(usersTableName).Append("WHERE id = ?", id)
        has, err := zorm.QueryRow(ctx, finder, user)
        if err != nil {
            return nil, err
        }
        if !has {
            return nil, fmt.Errorf("用户 %d 不存在", id)
        }
        return user, nil
    }

    // updateUser 更新用户数据
    func updateUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Update(ctx, user)
            return nil, err
        })
        return err
    }

    // listUsers 查询用户列表
    func listUsers(ctx context.Context) ([]User, error) {
        users := make([]User, 0)
        finder := zorm.NewSelectFinder(usersTableName).Append("ORDER BY id")
        if err := zorm.Query(ctx, finder, &users, nil); err != nil {
            return nil, err
        }
        return users, nil
    }

    // deleteUser 删除用户数据
    func deleteUser(ctx context.Context, user *User) error {
        _, err := zorm.Transaction(ctx, func(ctx context.Context) (interface{}, error) {
            _, err := zorm.Delete(ctx, user)
            return nil, err
        })
        return err
    }

    func main() {
        ctx := context.Background()

        // 初始化数据库连接
        if err := initDB(); err != nil {
            log.Fatal(err)
        }
        fmt.Println("zorm 初始化成功")

        // 创建数据表
        if err := createTable(ctx); err != nil {
            log.Fatalf("创建数据表失败: %v", err)
        }
        fmt.Println("数据表创建成功")

        // 插入一条用户数据
        now := time.Now()
        user := &User{
            Username:  "oceanbase_user",
            Email:     "zorm@oceanbase.com",
            Age:       28,
            CreatedAt: now,
            UpdatedAt: now,
        }
        if err := createUser(ctx, user); err != nil {
            log.Fatalf("插入数据失败: %v", err)
        }
        fmt.Printf("插入成功，ID: %d\n", user.ID)

        // 查询用户数据
        queried, err := getUserByID(ctx, user.ID)
        if err != nil {
            log.Fatalf("查询数据失败: %v", err)
        }
        fmt.Printf("查询成功: ID=%d, Username=%s, Age=%d\n", queried.ID, queried.Username, queried.Age)

        // 更新用户数据
        queried.Age = 29
        queried.UpdatedAt = time.Now()
        if err := updateUser(ctx, queried); err != nil {
            log.Fatalf("更新数据失败: %v", err)
        }
        fmt.Println("更新成功")

        // 查询用户列表
        users, err := listUsers(ctx)
        if err != nil {
            log.Fatalf("查询列表失败: %v", err)
        }
        fmt.Printf("查询到 %d 条记录\n", len(users))
        for _, item := range users {
            fmt.Printf("ID=%d, Username=%s, Age=%d\n", item.ID, item.Username, item.Age)
        }

        // 删除用户数据
        if err := deleteUser(ctx, queried); err != nil {
            log.Fatalf("删除数据失败: %v", err)
        }
        fmt.Println("删除成功")
    }
    ```

### 步骤四：运行程序并验证结果

1. 运行程序：

    ```bash
    cd ~/go/src/zorm-oceanbase
    go run main.go
    ```

2. 如果遇到 `go: command not found` 错误，请确保已按照步骤二中的说明正确设置了 Go 环境变量。

3. 程序执行完成后，您应该能看到类似以下的输出：

    ```bash
    zorm 初始化成功
    数据表创建成功
    插入成功，ID: 1
    查询成功: ID=1, Username=oceanbase_user, Age=28
    更新成功
    查询到 1 条记录
    ID=1, Username=oceanbase_user, Age=29
    删除成功
    ```
