# 通过 DataHub 管理 OceanBase 数据源

## 概述

DataHub 是一个现代数据目录，旨在实现端到端数据发现、数据可观察性和数据治理。
本文介绍如何使用 OceanBase 作为后端存储部署 DataHub 服务，以及通过简单示例演示 OceanBase 元数据管理。

## 版本兼容性

- OceanBase 版本：≥ V4.2.4。
- DataHub 版本：1.4.0.2（示例版本）。

## 前提条件

在使用 DataHub 之前，确认：
- 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 <a href="../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md">创建租户</a> 。
- 已完成 Docker 部署，Docker 服务正在运行，且当前用户具备执行 docker 命令的权限（可通过 docker info 验证）。
- 已安装 Docker Compose V2 (可通过 docker-compose 验证) 。
- 已安装 Python 3.10+ 和 pip 。

### 步骤一：获取数据库连接串

联系OceanBase数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接IP。ODP连接用ODP地址；直连用OBServer IP。
* `$port`：连接端口。ODP默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见<a href="../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md">通过 OBClient 连接 OceanBase 租户</a>。

**示例如下：**
```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：配置 DataHub 使用 OceanBase 作为后端存储

1. 安装依赖并配置环境变量。

```shell
python3 -m pip install pip wheel setuptools
python3 -m pip install acryl-datahub==1.4.0.2
datahub version #，获取datahub版本信息，例如1.4.0.2

# 1. 设置必要的环境变量
datahub_version="1.4.0.2"

cat > .env << EOF
DATAHUB_VERSION=v${datahub_version}
UI_INGESTION_DEFAULT_CLI_VERSION=${datahub_version}

# 数据库配置
host=your_database_host
port=your_database_port
user_name=your_database_username
password=your_database_password
database_name=your_database_dbname
EOF

source .env
```

获取数据库地址、端口号、数据库名、用户名和密码参见步骤一。

### 步骤三：访问 DataHub

1. 访问 DataHub UI 页面：`http://localhost:9002`,登录用户名和密码为：`datahub` 。
2. 确认 DataHub 服务正常运行，可以登录并查看界面 。

### 步骤四：管理 OceanBase 元数据

除了将 OceanBase 用作 DataHub 的后端存储，还可以对 OceanBase 元数据管理：

1. 在 DataSource 页面，点击 **Create source** 按钮。
2. 选择 **MySQL** 作为数据源类型。
3. 编辑 YAML 配置文件。

      ```yaml
       source:
           type: mysql
           config:
               host_port: '$host:$port'
               database: $database_name
               username: $user_name
               password: $password
               include_tables: true
               include_views: true
               profiling:
                   enabled: true
                   profile_table_level_only: true
               stateful_ingestion:
                   enabled: false
       sink:
           type: datahub-rest
           config:
               # docker inspect datahub-datahub-gms-quickstart-1 | grep "IPAddress"
               server: 'http://172.19.0.5:8080'
      ```
   获取数据库地址、端口号、数据库名、用户名和密码参见步骤一。
   YAML配置参数详情，参见[DataHub 官网](https://docs.datahub.com/docs/generated/ingestion/sources/mysql)。

4. 点击 **Next** 和 **Save & Run** 。
5. 在 DataHub UI 中查看摄取 OceanBase 的元数据信息。
