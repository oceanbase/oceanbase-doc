# 使用 goInception 管理 OceanBase 数据库

## 概述

goInception 是一款面向 MySQL 生态的 SQL 审核与运维工具，支持 SQL 审核、执行、备份以及回滚语句生成等功能。通过对待执行 SQL 进行语法解析和规则校验，goInception 可以返回审核结果，并支持执行变更（即支持执行和备份及生成回滚语句）操作。
本文介绍如何使用 goInception 连接 OceanBase 数据库，并进行 SQL 审核、执行和 DDL 变更管理。

## 版本兼容性

- OceanBase 数据库版本：≥ V4.2.5、≥ V4.3.5 BP2、≥ V4.4.0 。
- OBProxy 版本：≥ V4.3.1 。

## 前提条件

在使用 goInception 之前，确认：
- 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 <a href="../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md">创建租户</a> 。
- 您已部署 OBProxy，并且版本 ≥ V4.3.1。
- 您已在创建的 MySQL 兼容模式租户下开通 Binlog 服务。详情请参见 <a href="../../700.reference/1500.Components-and-Tools/300.data-integrate/100.oblogproxy-overview.md">OceanBase Binlog 服务</a> 。
- 您的数据库用户需要对目标具有 ALL 权限。
- 您已安装 [Go 语言环境](https://go.dev/dl/) > 1.22+和 Make 构建工具。
- 您已安装 Python 3.10+ 和 pip 。

## 操作步骤

### 步骤一：获取数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认 `2883`；直连默认 `2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见<a href="../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md">通过 OBClient 连接 OceanBase 租户</a>。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：部署 goInception

1. 克隆 OceanBase 组织下的 goInception 仓库：

   ```bash
   git clone -b Integration https://github.com/oceanbase/goInception.git
   cd goInception
   ```

2. 编译 parser：

   ```bash
   make parser
   #国内 Go 模块镜像
   #GOPROXY=https://goproxy.cn,direct GO111MODULE=on make parser
   ```

3. 构建 goInception：

   ```bash
   go build -o goInception tidb-server/main.go
   ```

4. 启动 goInception：

   ```bash
   cp config/config.toml.default  config/config.toml
   ./goInception -config=config/config.toml
   ```

### 步骤三：备份与回滚

如果您需要使用备份与回滚功能，请在 `config.toml` 中配置备份数据库信息：

```toml
[inc]
backup_host = "$backup_host"
backup_port = $backup_port
backup_user = "$backup_user"
backup_password = "$backup_password"
```

* 在备份服务器上，备份库的命名格式为：IP_PORT_库名，例如127_0_0_1_3306_test 。
* 在备份库上创建备份信息表$_$Inception_backup_information$_$，用来保存该库的执行信息和回滚语句信息。
* 对备份数据库用户要求具有：CREATE、INSERT 权限（建议给全部权限以确保备份功能正常）。
* 获取数据库地址、端口号、用户名和密码参见步骤一。

### 步骤四：DDL 变更工具

如果您需要使用 DDL 变更工具，goInception提供了两种工具 gh-ost、pt-online-schema-change（以下简称 pt-osc）。

#### 使用 gh-ost

1. 安装 gh-ost（binary 方式）， 安装包可联系技术支持人员获取。

2. 修改 goInception 配置文件，启用 gh-ost：

   ```yaml
   # OSC 的开关，如果设置为 0，则全部 ALTER 语句都走 OSC，如果设置为非 0，则当这个表占用空间大小大于这个值时才使用 OSC 方式
   osc_min_table_size = 0
   ghost_on = true
   ghost_bin_dir = "/path/to/gh-ost/bin/"
   enable_set_charset = true # 允许指定表和数据库的字符集
   check_column_position_change = true # 检查列位置/顺序变更
   ```

#### 使用 pt-osc

1. 安装 pt-osc（binary 方式），安装包可联系技术支持人员获取。

2. 修改 goInception 配置文件，启用 pt-osc：

   ```yaml
   # OSC 的开关，如果设置为 0，则全部 ALTER 语句都走 OSC，如果设置为非 0，则当这个表占用空间大小大于这个值时才使用 OSC 方式
   osc_min_table_size = 0
   osc_on = true
   osc_bin_dir = "/path/to/pt-osc/bin/"
   enable_set_charset = true # 允许指定表和数据库的字符集
   check_column_position_change = true # 检查列位置/顺序变更
   ```

### 步骤五：使用 goInception 执行 SQL

使用以下 Python 脚本连接 goInception 并执行 SQL 语句：

```python
#!/usr/bin/env python3
# -*- coding:utf-8 -*-
import pymysql
import prettytable as pt

tb = pt.PrettyTable()

# 重要：请根据您的实际环境修改目标数据库连接参数

sql = '''/*--user=$user_name;--password=$password;--host=$host;--port=$port;--execute=1;--backup=1;--ignore_warnings=1*/
inception_magic_start;
use $database_name;
inception set enable_drop_table = true;
inception set enable_null_index_name = true;
ALTER TABLE t1 ADD COLUMN age int(3) DEFAULT 0;
inception_magic_commit;'''

conn = pymysql.connect(host='127.0.0.1', user='', passwd='',
                       db='', port=4000, charset="utf8mb4")
cur = conn.cursor()
ret = cur.execute(sql)
result = cur.fetchall()
cur.close()
conn.close()

tb.field_names = [i[0] for i in cur.description]
for row in result:
    tb.add_row(row)

print(tb)
```

获取数据库地址、端口号、数据库名、用户名和密码参见步骤一。
