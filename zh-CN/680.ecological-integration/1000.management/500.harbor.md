# 部署 Harbor 并使用 OceanBase 作为元数据库

## 概述

Harbor 是一款开源容器镜像仓库，具备镜像存储、分发、访问控制和安全扫描等能力。本文介绍如何使用 OceanBase 数据库作为 Harbor 元数据库部署 Harbor 服务。

## 版本兼容性

- Harbor：支持 1.6.x 及更早版本（已验证 Harbor 1.6.x 版本可使用 OceanBase 作为元数据库。Harbor 1.7.0 及以上版本仅支持 PostgreSQL）。
- OceanBase 数据库版本：≥ 4.2.5 BP2 。

## 前提条件

在使用 Harbor 之前，确认：
- 已安装 Docker。请参考 [Docker 官方文档](https://docs.docker.com/engine/install/) 进行安装。
- 已安装 Docker Compose。请参考 [Docker 官方文档](https://docs.docker.com/compose/install/) 进行安装。
- 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md) 。
- [Harbor 官方文档](https://goharbor.io/docs/)

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接信息

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见<a href="../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md">通过 OBClient 连接 OceanBase 租户</a>。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：安装 Harbor 服务

本文以 Harbor V1.4.0 版本安装为示例，操作如下：

1. 下载安装包

   ```bash
   wget https://storage.googleapis.com/harbor-releases/release-1.4.0/harbor-offline-installer-v1.4.0.tgz
   #解压安装包
   tar -zxvf harbor-offline-installer-v1.4.0.tgz
   cd harbor/
   ```

2. Harbor 1.4.0 使用 harbor.cfg 作为配置文件。编辑该文件，配置 OceanBase 数据库连接信息：

   ```plain
   #######################################
   hostname = $harbor_host
   #The address of the Harbor database. Only need to change when using external db
   db_host = $host
   #The password for the root user of Harbor DB. Change this before any production use.
   db_password = $password
   #The port of Harbor database host
   db_port = $port
   #The user name of Harbor database
   db_user = $user_name
   #######################################
   ```

     **参数说明：**
     * `$harbor_host`：Harbor 服务的主机地址。
     * `$host`：OceanBase 数据库连接 IP。
     * `$port`：OceanBase 数据库连接端口。使用 ODP 连接时默认端口为 2883，直连 OBServer 时默认端口为 2881。
     * `$user_name`：OceanBase 数据库用户名。
     * `$password`：OceanBase 数据库用户密码。


3. 初始化 Harbor 数据库

   使用 OceanBase 连接串初始化 Harbor 数据库：

   ```shell
   mysql -h$host -u$user_name -P$port -p$password < ha/registry.sql
   ```

   > 💡 **提示**
   > ha/registry.sql 为 Harbor 安装包中的初始化脚本，请在 Harbor 解压目录下执行该命令。

4. 启动 Harbor 服务

   执行安装脚本启动 Harbor 服务：

   ```shell
   sudo ./install.sh
   ```

### 步骤三：访问 Harbor 管理界面

* 在浏览器中访问 `http://$harbor_host`。
* 使用默认凭据登录，默认用户名 `admin` 和密码 `Harbor12345`。首次登录后，请及时修改默认密码。

###  验证结果
成功部署后，您可以：

* 在浏览器访问 Harbor 管理界面
* 使用默认管理员账户登录
* 创建项目并尝试推送镜像
* 如果登录成功且可正常创建项目，说明 Harbor 已成功连接 OceanBase 元数据库。
