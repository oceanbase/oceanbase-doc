# V4.3.3 文档更新记录

本文主要介绍 OceanBase 数据库 V4.3.3 BP 版本配置项、系统变量、视图、函数、语法和数据类型等更新记录。更多功能变动信息介绍，参见 [OceanBase 数据库 V4.3.3](https://www.oceanbase.com/product/oceanbase-database-rn/releaseNote#V4.3.3)。

## V4.3.3 BP1（2024-10-18）

| **功能** | **描述** |
|----------|----------|
| 新增系统变量 `enable_sql_plan_monitor` | 新增 SESSION 级系统变量，用于控制当前会话的 SQL 是否记入 SQL PLAN MONITOR。默认为 False，表示默认不记入。开启时，无需考虑其他条件，当前会话的 SQL 均记入 SQL PLAN MONITOR；关闭时，满足 Hint 开启、执行时长超出阈值、并行度大于 1 其中一项条件后，当前会话的 SQL 才会记入 SQL PLAN MONITOR。更多信息，参见 [enable_sql_plan_monitor](700.reference/800.configuration-items-and-system-variables/200.system-variable/400.session-system-variable/90.enable_sql_plan_monitor-session.md)。|
| 视图 `[G]V$SQL_PLAN_MONITOR` 列语义变更| 对于 table scan 算子有字段含义发生变化：<ul><li>老版本 `otherstat_1_value`、`otherstat_2_value`、`otherstat_3_value` 表示 `IO_READ_BYTES`、`TOTAL_READ_BYTES`、`TOTAL_READ_ROW_COUNT`，在算子计算结束时统计。</li><li>新版本 `otherstat_1_value`、`otherstat_2_value`、`otherstat_3_value`、`otherstat_4_value` 表示 `IO_READ_BYTES`、`SSSTORE_READ_BYTES`、`SSSTORE_READ_ROW_COUNT`、`MEMSTORE_READ_ROW_COUNT`，支持实时统计。</li></ul> 更多信息，参见 [V$SQL_PLAN_MONITOR](700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/36000.v-sql_plan_monitor-of-sys-tenant.md)。|
