# V4.2.5 文档更新记录

## V4.2.5 BP1（2024-12-06）

| 功能 | 描述|
|------|------|
| 并行 DDL 支持 `DROP TABLE` 操作 | 在 OceanBase 数据库中，可以通过使用配置项 `_enable_parallel_table_creation` 和 `_parallel_ddl_control` 灵活控制并行 DDL 功能，包括 `CREATE TABLE`、`CREATE VIEW`、`TRUNCATE TABLE`、`COMMENT`、`DROP TABLE` 和 `CREATE INDEX` 操作。更多信息请参见 [并行 DDL](700.reference/1000.performance-tuning-guide/500.sql-optimization/300.distributed-execution-plan/1100.parallel-ddl.md)。 |
| 新增 `pid_file` 变量 | MySQL 模式下新增 GLOBAL 级只读系统变量，用于查询服务器写入其进程 ID 的文件的路径名。更多信息请参见 [pid_file](700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/10850.pid_file-global.md)。|
| 新增 `port` 变量     | MySQL 模式下新增 GLOBAL 级只读系统变量，用于在 OBServer 节点部署时，设置服务器监听 TCP/IP 连接的端口号。更多信息请参见 [port](700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/10950.port-global.md)。 |
| 新增 `socket` 变量   | MySQL 模式下新增 GLOBAL 级只读系统变量，用于查询本地客户端连接 `Socket` 文件的名称。更多信息请参见 [socket](700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/11550.socket-global.md)。 |
| `DBMS_SPM` 系统包新增子程序 `BATCH_LOAD_PLANS_FROM_CURSOR_CACHE` | `BATCH_LOAD_PLANS_FROM_CURSOR_CACHE` 用于将 Plan Cache 中存在的 SQL 计划批量添加到 SPM baseline 中。更多信息请参见 [BATCH_LOAD_PLANS_FROM_CURSOR_CACHE](700.reference/1000.performance-tuning-guide/500.sql-optimization/400.sql-optimization/700.manage-execution-plans/300.sql-execution-plan-management-spm.md)。 |
| 新增 `ALTER COMPILE` 语法 | MySQL 模式下新增 `ALTER COMPILE` 语句，用于触发 procedure 或 function 的重新编译。更多信息请参见 [ALTER COMPILE](700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1100.alter-compile-of-mysql-mode.md)。 |
| 新增 `UTL_TCP` 系统包 | Oracle 模式下新增 `UTL_TCP` 系统包，用于通过 TCP/IP 协议与外部服务器进行通信。更多信息请参见 [UTL_TCP](700.reference/500.sql-reference/300.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/27100.utl-tcp-oracle/100.utl-tcp-overview-oracle.md)。 |
| 新增 `UTL_SMTP` 系统包 | Oracle 模式下新增 `UTL_SMTP` 系统包，用于通过 SMTP（简单邮件传输协议）发送电子邮件。`UTL_SMTP` 依赖于 `UTL_TCP` 系统包，更多信息请参见 [UTL_SMTP](700.reference/500.sql-reference/300.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/27200.utl-smtp-oracle/100.utl-smtp-overview-oracle.md)。 |
| 新增 `COMMA_TO_TABLE` 程序包 | Oracle 模式下新增 `DBMS_UTILITY.COMMA_TO_TABLE` 程序包，用于将一个以逗号分隔的字符串转换成一个 PL/SQL 表。更多信息请参见 [COMMA_TO_TABLE](700.reference/500.sql-reference/300.pl-reference/300.pl-oracle/1400.pl-system-package-oracle/17900.dbms-utility-oracle/2200.comma-to-table-oracle.md)。 |
| 新增系统触发器 `logon/logoff` | 系统触发器可以创建在 schema（user）和 Database 上，分别用于指定用户登录和所有用户登录时触发。只能创建 `after logon`， `before logoff` 触发器，不能创建 `before logon`，`after logoff` 触发器。更多信息请参见 [系统触发器](700.reference/500.sql-reference/300.pl-reference/300.pl-oracle/800.trigger-oracle/800.system-trigger-oracle.md)。 |
| 物理备份恢复支持 NFS3.x 协议  | 在使用 NFS3.x 协议时，无法确定不同 NFS 服务器对文件锁的支持细节，建议挂载时添加 `nolock` 值。更多信息请参见 [部署 NFS](600.manage/600.backup-and-recovery/200.deploy-nfs.md)。 |
| 串行化隔离级别支持弱读请求 | 在 Repeatable Read 和 Serializable 隔离级别下支持弱读请求。更多信息请参见 [弱一致性读](700.reference/500.sql-reference/200.sql-specifications-and-practices/300.sql-statement-example/300.weak-consistency-read.md)。 |
| `MERGE INTO` 语法支持分区指定 | `MERGE INTO` 语法新增 `PARTITION(partition_name_list)` 字段，指定目标表或源表的分区。更多信息请参见 [MERGE INTO](700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/200.dml-of-oracle-mode/300.merge-of-oracle-mode.md)。 |
| OBCDC 数据字典 DUMP 调度优化 | 通过将数据字典的调度接入到 `DBMS_SCHEDULER` 中，并支持指定调度周期、暂停/恢复调度、立即触发调度数据字典的生成、回收数据字典历史记录以及调整字典历史记录保留时间等功能。更多信息请参见 [DBMS_DATA_DICT](700.reference/500.sql-reference/300.pl-reference/200.pl-mysql/1000.pl-system-package-mysql/21000.dbms-data-dict-mysql/100.dbms-data-dict-mysql.md)。 |
| 配置项 `dump_data_dictionary_to_log_interval` 默认值及取值范围变更 | <ul><li>默认值由 24H 调整为 0，取值为 0 时，将不会根据该配置项调度生成数据字典。</li> <li>取值范围由 (0s, +∞) 调整为 [0s, +∞)，配置为 0 时，表示不会通过配置项路径触发生成数据字典。</li></ul>更多信息请参见 [dump_data_dictionary_to_log_interval](700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2300.dump_data_dictionary_to_log_interval.md)。 |
| 支持在生成列上新建空间索引 | 支持在存储（STORED）生成列上创建空间索引，不支持在虚拟（VIRTUAL）生成列上创建。更多信息请参见 [创建空间索引](700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/900.spatial-data-type-of-mysql-mode/400.create-spatial-indexes-of-mysql-mode.md)。 |
| 新增 `ENHANCED_AES_ENCRYPT` 函数 | 该函数主要用于列加密功能，仅当用户同时具有 `ENCRYPT` 权限，以及相应的 DML 权限时，才能在 DML 语句中使用该加密函数。更多信息请参见 [ENHANCED_AES_ENCRYPT](700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md)。 |
| 新增 `ENHANCED_AES_DECRYPT` 函数 | 该函数主要用于列加密功能，仅当用户同时具有 `DECRYPT` 权限，以及相应的 DML 权限时，才能在 DML 语句中使用该加密函数。更多信息请参见 [ENHANCED_AES_DECRYPT](700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md)。 |
| 支持部分 latin1 字符序 | latin1 字符序进行补充支持，包括：`latin1_german1_ci`、`latin1_danish_ci`、`latin1_german2_ci`、`latin1_general_ci`、`latin1_general_cs`、`latin1_spanish_ci`。更多信息请参见 [字符集和字符序](700.reference/500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/300.basic-elements-of-oracle-mode/1000.character-set-and-collation-of-oracle-mode.md)。 |
| 支持租户预扩容 | 预扩容功能是通过配置租户从缩容到扩容所需的扩容系数（ls_scale_out_factor），提前产生足够多的日志流，使日志流的状态和位置与扩容后均能匹配的情况下，再开始租户的扩容或缩容操作，从而达到平滑扩缩容的目的。更多信息请参见 [租户预扩容](600.manage/200.tenant-management/600.common-tenant-operations/800.tenant-scale-in-and-out/170.pre-scaling-for-a-tenant.md)。 |
| 新增 `ls_scale_out_factor` 配置项 | 租户级配置项 `ls_scale_out_factor` 表示日志流的扩容系数，用于控制租户在每台服务节点上日志流的个数。更多信息请参见 [ls_scale_out_factor](700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/5530.ls_scale_out_factor.md)。 |
| 新增 `USER_SCHEDULER_JOBS` 视图 | 用于展示当前用户可访问的调度程序作业信息。更多信息请参见 [USER_SCHEDULER_JOBS](700.reference/700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/27650.user_scheduler_jobs-of-oracle-mode.md)。 |
| 新增 Redis 监控指标 | OBKV-Redis 为每个命令增加了对应的命令执行总数、总耗时以及耗时与执行数直方图，可通过系统视图访问对应的监控指标。更多信息请参见 [OBKV-Redis 监控指标](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001810119)。 |
| `ALTER TABLE` 语法支持 `DROP INDEX` 字段 | 在 MySQL 模式下，`ALTER TABLE` 语句新增 `DROP INDEX index_name` 字段来表示删除索引，更多信息请参见 [ALTER TABLE](700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1600.alter-table-of-mysql-mode.md)。 |
