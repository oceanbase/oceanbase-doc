# 使用华为云 CDM 实现 MySQL 到 OceanBase MySQL 的数据迁移

华为云 CDM（Cloud Data Migration）是华为云提供的数据迁移服务，支持多种数据源之间的数据迁移。华为云 CDM 支持通过 MySQL 连接器连接 OceanBase 数据库，实现 MySQL 到 OceanBase MySQL 的数据迁移。

## 版本兼容性

| 组件 | 说明 |
|------|------|
| OceanBase 数据库 | ≥ V4.2.3.0 |

## 前提条件

在使用华为云 CDM 之前，需确认：
* 已购买华为云 CDM。详情请参见 [华为云 CDM 官方文档](https://support.huaweicloud.com/productdesc-cdm/cdm_01_0143.html)。
* 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。
* 目标端 OceanBase 数据库和表已预先创建。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：配置数据源

1. 登录华为云 CDM 控制台，进入集群管理页面。
2. 点击 **创建数据源**，选择 **MySQL** 连接器类型。
3. 填写数据源基本信息：
   * **数据源名称**：自定义名称，如 `ob_source`。
   * **服务器地址**：填写 OceanBase 连接 IP。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>使用 PrivateLink 连接华为云 OceanBase 时，请填写 Endpoint IP 而非域名。</p>
    </main>
   * **端口**：填写 OceanBase 连接端口，默认 `2881`（直连）或 `2883`（ODP）。
   * **数据库名**：填写数据库名称。
   * **用户名**：填写连接账户。
   * **密码**：填写账户密码。
4. 在 **高级属性** 中，可根据性能需求调整以下参数：
   * **单次提交行数**：从源端获取指定条数后往目的端提交，默认值可调整以提高性能。
   * **单次写入行数**：每次往目的端写入的条数，默认值可调整以提高性能。
5. 点击 **测试连接**，确认连接成功后保存数据源。

### 步骤三：创建迁移作业

1. 在 CDM 控制台，点击 **创建作业**。
2. 选择作业类型为 **表/文件迁移**。
3. 配置源端和目的端：
   * **源端数据源**：选择已创建的 MySQL 源端数据源。
   * **目的端数据源**：选择已创建的 OceanBase 目的端数据源。
4. 配置作业参数：
   * 选择需要迁移的数据库和表。
   * 在 **作业配置** 中，可增加 **并发线程** 数以提高迁移性能。
5. 保存作业配置。

### 步骤四：执行迁移

1. 在作业列表中，选择已创建的迁移作业。
2. 点击 **启动**，开始执行数据迁移。
3. 监控作业执行状态，等待迁移完成。

## 结果验证

1. 登录目标端 OceanBase 数据库。
2. 执行以下 SQL 语句，验证数据是否迁移成功：

   ```sql
   SELECT COUNT(*) FROM $database_name.$table_name;
   ```

3. 对比源端和目标端的数据记录数，确认数据一致性。

## 常见问题

**Q1：使用本地 API 模式迁移时报语法错误怎么办？**

**原因**：本地 API 模式生成的 SQL 语法与 OceanBase 不兼容，例如分隔符语法 `fields terminated by X'0203'` 不被 OceanBase 支持。

**解决方案**：创建数据源时，请选择 **SQL 模式** 而非本地 API 模式。

**Q2：数据源测试连接成功，但无法被选为迁移目标怎么办？**

**原因**：可能是 CDM 集群版本问题。

**解决方案**：尝试更换 CDM 集群版本，或联系华为云技术支持获取帮助。
