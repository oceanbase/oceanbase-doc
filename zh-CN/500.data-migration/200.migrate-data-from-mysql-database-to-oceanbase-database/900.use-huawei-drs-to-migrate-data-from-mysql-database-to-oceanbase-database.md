# 使用华为 DRS 实现 MySQL 到 OceanBase MySQL 的数据迁移

华为 DRS（Data Replication Service，数据复制服务）是华为云提供的数据迁移与同步服务，支持多种数据库之间的数据迁移和数据同步，具备全量迁移、增量迁移和对象迁移等能力。您可以通过华为云控制台创建并配置迁移任务，实现从 MySQL 到 OceanBase MySQL 的数据迁移。

## 版本兼容性

华为 DRS 与 OceanBase 数据库的版本兼容性如下表所示。

| 组件 | 版本要求 |
|------|---------|
| OceanBase 数据库 | ≥ V4.2.5 BP1 |
| ODP（OceanBase Database Proxy） | ≥ V4.3.1 |

## 前提条件

在使用华为 DRS 之前，需确认：

* 已部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。
* 已开通华为云账号并订阅 DRS 服务。DRS 服务的详细信息，参见 [华为云 DRS 产品文档](https://support.huaweicloud.com/productdesc-drs/drs_01_0010.html)。
* 如需进行增量迁移，已在创建的 MySQL 兼容模式租户下开通 Binlog 服务。详情请参见 [OceanBase Binlog 服务](../../700.reference/1500.Components-and-Tools/300.data-integrate/100.oblogproxy-overview.md)。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**

* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认 `2883`；直连默认 `2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群` 或 `集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：配置 DRS 迁移任务

1. 登录华为云控制台，进入**数据复制服务 DRS** 服务页面。
2. 选择**实时迁移管理**，点击**创建迁移任务**，选择源数据库和目标数据库类型等信息。
3. **配置源数据库**连接信息（MySQL）。
4. **配置目标数据库**连接信息（OceanBase）。
5. 选择**迁移类型**（全量迁移、全量+增量迁移）和**迁移对象**。

### 步骤三：执行预检查

1. 完成迁移任务配置后，在 DRS 控制台启动**预检查**。
2. DRS 会对迁移环境进行检查，主要包括**网络连通性**、**数据库参数**、**磁盘空间**等项目。
3. 如果预检查未通过，请根据页面提示修复相关问题后重新执行预检查，直至检查通过。

### 步骤四：启动迁移任务

1. 预检查通过后，在 DRS 控制台**启动迁移任务**。
2. 任务启动后，可在控制台查看迁移进度和运行状态。
3. 迁移完成后，建议对源库和目标库进行数据一致性验证，确认迁移结果正确无误。

## 结果验证

迁移任务完成后，可通过以下方式验证迁移结果：

* 在 DRS 控制台查看迁移任务状态，确认显示为**成功**。
* 对比源数据库和目标数据库的数据量，确认数据一致性。
* 检查迁移的对象（表、视图、存储过程、函数等）是否完整。

## 常见问题

**Q1：预检查阶段出现超时错误，如何处理？**

**原因**：使用了三段式命名格式（如 `root@租户#集群`），DRS 无法在 `mysql.user` 表中查找到对应的用户记录，导致查询超时。

**解决方案**：使用一段式命名格式（如 `root`），避免使用三段式命名。

**Q2：对象迁移时 view 创建失败，如何处理？**

**原因**：OceanBase 不支持 `DEFINER='root'@'%'` 格式的 SQL 语法，导致视图创建失败。

**解决方案**：手动修改视图定义，将 `DEFINER='root'@'%'` 改为 `DEFINER='root'`。

**Q3：增量迁移时提示缺少 `default_collation_for_utf8mb4` 变量，如何处理？**

**原因**：OceanBase 在某些版本中未实现 `default_collation_for_utf8mb4` 变量，DRS 检测到该变量缺失时报错。

**解决方案**：升级 OceanBase 至 V4.2.5.1 或更高版本，该版本已支持相关变量。
