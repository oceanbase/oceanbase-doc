# 使用 DTS 实现 MySQL 与 OceanBase 双向数据同步

数据传输服务 DTS（Data Transmission Service）是阿里云提供的实时数据流服务，支持关系型数据库、非关系型数据库、数据多维分析等数据源间的数据交互，集数据同步、迁移、订阅、集成、加工于一体。您可以通过 DTS 实现 MySQL 与 OceanBase 之间的双向数据同步，包括 DDL 和 DML 操作。

## 版本兼容性

| 组件 | 版本要求 |
|------|---------|
| OceanBase 数据库 | ≥ V4.x |

## 前提条件

在使用 DTS 之前，需确认：
* 已开通阿里云 DTS 服务。
* 您已完成部署 OceanBase 数据库并且创建了 MySQL 模式用户租户。创建用户租户的详细信息，参见 [创建租户](../../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md)。
* 如需增量迁移，已在创建的 MySQL 兼容模式租户下开通 Binlog 服务。详情请参见 [OceanBase Binlog 服务](../../700.reference/1500.Components-and-Tools/300.data-integrate/100.oblogproxy-overview.md)。
* 已配置好网络连接，确保 DTS 可以通过私网访问 OceanBase。

## 操作步骤

### 步骤一：获取 OceanBase 数据库连接串

联系 OceanBase 数据库部署人员获取连接串，例如：

```
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**参数说明：**
* `$host`：连接 IP。ODP 连接用 ODP 地址；直连用 OBServer IP。
* `$port`：连接端口。ODP 默认`2883`；直连默认`2881`。
* `$database_name`：数据库名称。
    <main id="notice" type='notice'>
        <h4>注意</h4>
        <p>连接租户的用户需要拥有该数据库的 <code>CREATE</code>、<code>INSERT</code>、<code>DROP</code> 和 <code>SELECT</code> 权限。更多有关用户权限的信息，请参见 <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">MySQL 模式下的权限分类</a>。</p>
    </main>
* `$user_name`：连接账户。ODP 格式：`用户@租户#集群`或`集群:租户:用户`；直连格式：`用户@租户`。
* `$password`：账户密码。

更多连接串的信息，请参见[通过 OBClient 连接 OceanBase 租户](../../300.develop/100.application-development-of-mysql-mode/100.connect-to-oceanbase-database-of-mysql-mode/300.connect-to-an-oceanbase-tenant-by-using-obclient-of-mysql-mode.md)。

**示例如下：**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### 步骤二：配置并启动 DTS 同步任务

1. 登录阿里云 DTS 控制台，选择**数据同步**，点击**创建任务**。
2. 在**源库及目标库配置**页面，配置以下信息：
   * **任务名称**：填写任务名称。
   * **数据库类型**：源库及目标库都选择 MySQL。
   * **接入方式**：源库可选**云实**或者 **ECS 自建数据库**，目标库选择**专线/VPN网关/智能网关**。
   * **源库信息**：填写 MySQL 的连接信息。
   * **目标库信息**：填写 OceanBase 的连接信息（使用步骤一获取的连接串）。
3. **配置任务对象**，选择需要同步的数据库和表，配置数据校验规则，确保数据一致性。
4. **预检查**执行，确保配置正确。
5. **预检查**通过后，启动同步任务。
6. 在**同步任务列表**中查看**任务状态**，确保任务正常运行中。


## 步骤三：结果验证

### 正向同步验证

可在 MySQL 中执行 DDL 或 DML 操作，检查 OceanBase 中是否同步成功，如在 MySQL 中执行以下操作：

```sql
ALTER TABLE coffee_sales ADD COLUMN quantity INT NOT NULL DEFAULT 1 COMMENT 'Purchase quantity';
```

在 OceanBase 中查看表结构，确认字段已添加。

### 反向同步验证

可在 OceanBase 中执行 DML 操作，检查 MySQL 中是否同步成功。如在 OceanBase 中执行以下操作：

```sql
UPDATE coffee_sales SET quantity = 2 WHERE id = 1;
```

在 MySQL 中查询数据，确认更新已同步。
