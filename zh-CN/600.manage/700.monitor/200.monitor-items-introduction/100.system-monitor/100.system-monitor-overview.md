# 系统监控指标概述

## 概述

OceanBase 数据库通过采集一系列运行时的 SYSSTAT 指标，细粒度地反映了系统的运行状况。这些指标是判断数据库健康状态的核心依据之一，旨在满足多样化运维场景的需求，包括日常监控、故障诊断、性能优化等。

## 核心视图

OceanBase 数据库的 SYSSTAT 指标信息存储在一系列动态性能视图中，主要有以下视图：

* **V$STATNAME 视图**
  
  提供了所有可监控统计事件的定义（如名称、ID、分类）。

* **V$SESSTAT 视图**
  
  存储的是各个会话（Session）级别的监控项信息。这些数值仅对当前连接的会话有效，是临时性的。当会话断开连接后，该会话在 `V$SESSTAT` 视图中的相应记录会被清除。

* **V$SYSSTAT 视图**
  
  存储的是自 OBServer 实例（OBServer Instance）启动以来，所有监控项的累计值。这些数据是系统级别的全局信息，不会因个别会话的断开而被清除，只有在数据库实例关闭后才会被重置。


简单来说，`V$STATNAME` 是查询和理解 `V$SYSSTAT`、`V$SESSTAT` 等视图中具体统计数值的基础；`V$SESSTAT` 视图反映的是单个会话的活动量，其生命周期与会话一致；而 `V$SESSTAT` 视图反映的是 OBServer 实例从启动以来的总活动量，生命周期与实例保持一致。
