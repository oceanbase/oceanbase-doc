## 暂停和恢复 Balance Job

当租户有正在执行的 Balance Job 时，又有其他紧急变更需要执行，为了防止该 Balance Job 的执行影响紧急变更，用户可以选择先暂停当前正在执行的 Balance Job，待紧急变更执行完后，再恢复该 Job，继续执行。

## 使用限制

* 对于 V4.2.5 版本，从 V4.2.5 BP2 版本开始支持暂停和恢复 Balance Job。

* 暂停或恢复 Balance Job 的操作只能在主库（即主租户）上执行。

* 暂停或恢复 Balance Job 时，要求该 Balance Job 的状态不能是 `CANCELING`。

## 暂停正在进行的 Balance Job

### 系统租户暂停用户租户上正在进行的 Balance Job

1. 使用 `root` 用户登录到集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 获取租户相关信息。

   ```shell
   obclient> SELECT TENANT_ID, TENANT_NAME, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE tenant_name = 'mq_t1';
   ```

   查询结果的示例如下：

   ```shell
   +-------------+-----------+-------------+
   | TENANT_NAME | TENANT_ID | TENANT_ROLE |
   +-------------+-----------+-------------+
   | mq_t1       |      1002 | PRIMARY     |
   +-------------+-----------+-------------+
   1 row in set
   ```

3. 查询视图 `CDB_OB_BALANCE_JOBS`，获取当前正在执行的任务及状态。

   ```shell
   obclient [oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   查询结果的示例如下：

   ```shell
   +-----------+--------+--------------------+--------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS |
   +-----------+--------+--------------------+--------+
   |      1002 |  62944 | TRANSFER_PARTITION | DOING  |
   +-----------+--------+--------------------+--------+
   1 row in set
   ```

   根据查询结果，当前 Balance Job 的状态为 `DOING`，不是 `CANCELING`，可以暂停该 Job。

4. 执行以下语句，暂停该 Balance Job。

   ```sql
   ALTER SYSTEM SUSPEND BALANCE JOB TENANT = 'tenant_name';
   ```

   示例如下：

   ```shell
   obclient [oceanbase]> ALTER SYSTEM SUSPEND BALANCE JOB TENANT ='mq_t1';
   ```

5. 执行成功后，再次查询视图 `CDB_OB_BALANCE_JOBS`，可以看到当前任务的状态变为 `SUSPEND`。

   ```shell
   obclient [oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   查询结果如下：

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION | SUSPEND |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```

3. 执行以下语句，暂停该 Balance Job。
