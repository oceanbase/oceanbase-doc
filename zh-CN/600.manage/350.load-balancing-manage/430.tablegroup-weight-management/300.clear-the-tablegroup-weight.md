# 清除表组权重

设置表组权重后，因业务需要，可以清除原来设置的表组权重。

## 注意事项

清除表组权重是将表组上的权重删除。如果表组内的表设置过表级或分区级权重，则系统会保留表级和分区级权重。

## 清除权重

1. 用户登录集群的 MySQL 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 获取表组权重信息。

   ```shell
   obclient(root@mysql001)[test]> SELECT TABLEGROUP_NAME, WEIGHT, TABLEGROUP_ID, OBJECT_ID FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT WHERE TABLEGROUP_NAME = 'TG_DB_test';
   ```

   查询结果如下：

   ```shell
   +-----------------+--------+---------------+-----------+
   | TABLEGROUP_NAME | WEIGHT | TABLEGROUP_ID | OBJECT_ID |
   +-----------------+--------+---------------+-----------+
   | TG_DB_test      |     10 |        500007 |    500007 |
   +-----------------+--------+---------------+-----------+
   1 row in set
   ```

3. 清除表组权重。

   清除表组 `TG_DB_test` 的权重，语句如下。

   ```shell
   obclient(root@mysql001)[test]> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_DB_test');
   ```

   也支持 `sys` 租户为指定用户租户 `mysql001` 的表组清除权重，语句如下：

   ```shell
   obclient(root@sys)[(none)]> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_DB_test') TENANT = 'mysql001';
   ```

4. 清除表组权重后，可以再次查看表组权重信息。

   ```shell
   obclient(root@mysql001)[test]> SELECT TABLEGROUP_NAME, WEIGHT, TABLEGROUP_ID, OBJECT_ID FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT WHERE TABLEGROUP_NAME = 'TG_DB_test';
   ```

   如果查询结果为空，则表示表组权重清除成功。

## 后续操作

清除表组权重后，表组内表上的分区分布可能不均衡。如果用户期望尽快进行分区均衡，可以通过调用 `DBMS_BALANCE.TRIGGER_PARTITION_BALANCE` 子程序，手动触发一次分区均衡。手动触发分区均衡的详细操作，参见 [手动触发分区均衡](../600.partition-balance-management/200.manually-trigger-a-partition-balancing-task.md)。

或者，用户也可以等待定时分区均衡任务的触发。有关定时分区均衡任务的相关信息，参见 [配置定时分区均衡任务](../600.partition-balance-management/100.configure-a-scheduled-partition-balancing-task.md)。
