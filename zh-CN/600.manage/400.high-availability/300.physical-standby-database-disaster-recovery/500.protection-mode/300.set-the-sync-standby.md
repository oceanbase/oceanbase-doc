# 设置强同步的下游

默认情况下，主租户的保护模式为最大性能模式。如果需要将其设置为最大保护模式或最大可用模式，则需要先为主租户设置强同步的下游。

## 使用限制及注意事项

* 设置备租户进入强同步模式时，要求该备租户必须为基于网络的备库。

* 仅支持设置一个强同步的备租户，不支持设置多个强同步的备租户。

* 主备租户上均可以设置强同步的下游。需要注意的是，备租户设置强同步的下游通常情况下并无意义，但在 Switchover 场景下，如果希望主备租户仍然保持强同步关系，可以在备租户切成主租户前为备租户设置强同步下游为原主租户。

* 仅设置租户强同步的下游，不设置保护模式的情况下，并不会真的开启强同步模式。

## 操作步骤

1. 使用管理员用户登录主租户或主租户所在集群的 `sys` 租户。

   <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>MySQL 模式的管理员用户为 <code>root</code> 用户，Oracle 模式的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 执行以下语句，为主租户设置强同步的下游。

   语句如下：

   ```sql
   ALTER SYSTEM SET SYNC_STANDBY_DEST = 'SERVICE=ip_list NET_TIMEOUT=int_value HEALTH_CHECK_TIME=time USER=user_name@standby_tenant_name PASSWORD=password' [TENANT = tenant_name]；
   ```

   相关参数说明如下：

   * `ip_list`：下游备租户所在副本的 OBServer 节点的 IP 及 SQL 端口号（端口号默认为 2881），多个 IP 地址之间使用英文逗号（,）分隔。

     <main id="notice" type='explain'>
     <h4>说明</h4>
     <p>设置后，如果备租户因负载均衡或容灾场景，导致设置的 <code>ip_list</code> 信息发生了变化，主租户会秒级探测备租户上系统日志流的位置变化并自动更新，不需要用户再手动修改 <code>ip_list</code> 信息。</p>
     </main>

   * `NET_TIMEOUT`：用于指定最大可用模式下主租户等待强同步的备租户日志完成同步的超时时间，如果超过指定时间仍然未完成，则主租户会自动降级为异步同步模式。其他保护模式下，该参数没有意义。该参数的单位为秒，默认值为 30，表示 30s，取值范围为 [10, 1200]。

   * `HEALTH_CHECK_TIME`：用于指定最大可用模式下主租户检查备租户日志完成同步的检查时间，如果在指定时间内备租户均为同步状态，则主租户会自动升级为强同步模式。其他保护模式下，该参数没有意义。该参数的单位为秒，默认值为 60s，取值范围为 [0s, +∞)。

   * `user_name@standby_tenant_name`：`standby_tenant_name` 填写下游备租户的租户名；`user_name` 填写 [创建访问视图的专用用户](../200.create-a-standby-tenant/200.create-an-empty-standby-tenant.md) 中创建的用户，例如：用户 `rep_user`。

   * `password`：填写 [创建访问视图的专用用户](../200.create-a-standby-tenant/200.create-an-empty-standby-tenant.md) 中创建的用户的密码。

   * `tenant_name`：系统租户指定待执行该操作的主租户名。

   示例如下：

   * 系统租户为主租户 `mysql` 设置强同步的下游备租户 `standby_tenant`。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM SET SYNC_STANDBY_DEST = 'SERVICE=6.xx.xxx.xxx:2881 NET_TIMEOUT=20 HEALTH_CHECK_TIME=40s USER=rep_user@standby_tenant PASSWORD=xxxxxx' TENANT = mysql;
     ```

   * 主租户为本租户设置强同步的下游备租户 `standby_tenant`。

     ```shell
     obclient> ALTER SYSTEM SET SYNC_STANDBY_DEST = 'SERVICE=6.xx.xxx.xxx:2881 NET_TIMEOUT=20 HEALTH_CHECK_TIME=40s USER=rep_user@standby_tenant PASSWORD=xxxxxx';
     ```

3. 设置成功后，可以通过视图 `CDB_OB_SYNC_STANDBY_DEST`（系统租户）/`DBA_OB_SYNC_STANDBY_DEST`（用户租户）查看租户下强同步的下游的信息。

   * 系统租户下查看指定租户强同步的下游的信息。

     ```shell
     obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_SYNC_STANDBY_DEST WHERE TENANT_ID = tenant_id\G
     ```

   * 用户租户查看本租户下强同步的备租户信息。

     :::tab
     tab MySQL 模式

     MySQL 模式下的查询语句如下：

     ```shell
     obclient(root@mysql)[(none)]> SELECT * FROM oceanbase.DBA_OB_SYNC_STANDBY_DEST\G
     ```

     tab Oracle 模式

     Oracle 模式下的查询语句如下：

     ```shell
     obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_SYNC_STANDBY_DEST\G
     ```

     :::

   系统租户下查询结果的示例如下：

   ```shell
   *************************** 1. row ***************************
   TENANT_ID: 1002
   DEST_ID: 0
   VALUE: IP_LIST=6.xx.xxx.xxx:2881+2882,USER=rep_user@standby_tenant,PASSWORD=CFE754BE186DE38E5A98A964323C91206567A05704397DA148183F10E7E21D78,TENANT_ID=1002,CLUSTER_ID=10002,COMPATIBILITY_MODE=MYSQL,IS_ENCRYPTED=true,net_timeout=20000000,health_check_time=40000000
   1 row in set
   ```

## 后续操作

为主租户设置强同步的下游成功后，后续可以根据需要，进行以下操作：

* **清空强同步的下游**

  最大性能模式下的租户，可以直接清空设置的强同步的下游信息。示例如下：

  * 系统租户为主租户 `mysql` 强同步的下游信息。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM SET SYNC_STANDBY_DEST = '' TENANT = mysql;
     ```

  * 主租户清空本租户强同步的下游信息。

     ```shell
     obclient> ALTER SYSTEM SET SYNC_STANDBY_DEST = '';
     ```

* **修改强同步的下游**

  修改强同步的下游的属性包括：登录名(`user_name`)、密码（`password`）、租户地址（`ip_list`）、备租户名（`standby_tenant_name`）以及同步超时时间（`NET_TIMEOUT`）。

  备租户名与租户地址可以唯一确定一个备租户。当租户处于最大保护或最大可用模式下时，不允许修改备租户名，但是可以修改登录名(`user_name`)、密码（`password`）、租户地址（`ip_list`）等信息，因为修改这些信息不会改变这个唯一的备租户。当租户处于最大性能模式下时，所有的属性均可以修改。

  在修改强同步的下游的属性时，不支持单独修改某个属性，需要将上述几个属性全部重新设置一次。修改强同步的下游信息的语法与设置强同步的下游的语法相同。

需要注意的是，设置强同步的下游后，对于最大保护模式或最大可用模式下的主租户，如果需要将强同步的下游更改为其他备租户，需要进行如下操作。

1. 参考 [设置保护模式](400.set-protection-mode.md)，将保护模式设置为最大性能模式。
2. 参考本文 **清空强同步的下游** 中的命令，清空已设置的强同步的下游信息。
3. 参考本文档，重新设置强同步的下游。
4. 参考 [设置保护模式](400.set-protection-mode.md) ，重新将保护模式设置为最大保护模式或最大可用模式。
