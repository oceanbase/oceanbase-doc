# 保护模式与保护级别

本节主要介绍主备租户的保护模式和保护级别。

## 保护模式与保护级别的对应关系

保护模式功能本质上是用于定义主租户以何种方式（强同步或异步同步）向不同的备租户传输日志、备租户以何种方式来接收日志以及数据是否无损。

OceanBase 数据库的 `DBA_OB_TENANTS` 视图中提供了两个字段来描述保护模式的配置及主备租户的状态：保护模式（`PROTECTION_MODE`）和保护级别（`PROTECTION_LEVEL`）。

当前，保护模式（`PROTECTION_MODE`）的取值有以下三种：

* MAXIMUM PERFORMANCE：最大性能
* MAXIMUM PROTECTION：最大保护
* MAXIMUM AVAILABILITY：最大可用

对应的保护级别（`PROTECTION_LEVEL`）的取值有以下四种：

* MAXIMUM PERFORMANCE：最大性能
* MAXIMUM PROTECTION：最大保护
* MAXIMUM AVAILABILITY：最大可用
* RESYNCHRONIZATION：追赶日志状态

每个租户的保护模式和保护级别均保持独立，只有强同步的备租户，其保护模式和保护级别与主租户一致，异步同步的备租户的保护模式和保护级别一直维持在 `MAXIMUM PERFORMANCE`。

## 查看租户的保护模式和保护级别

主备租户查看保护模式和保护级别的语句如下：

* 系统租户下查看指定租户的保护模式和保护级别

  ```shell
  obclient(root@sys)[oceanbase]> SELECT TENANT_NAME, PROTECTION_MODE, PROTECTION_LEVEL FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'tenant_name';
  ```

* 用户租户查看本租户的保护模式和保护级别

  :::tab
  tab MySQL 模式

  MySQL 模式下，查询语句如下：

  ```shell
  obclient(root@mysql001)[oceanbase]> SELECT TENANT_NAME, PROTECTION_MODE, PROTECTION_LEVEL FROM oceanbase.DBA_OB_TENANTS;
  ```

  tab Oracle 模式

  Oracle 模式下，查询语句如下：

  ```shell
  obclient(sys@oracle001)[SYS]> SELECT TENANT_NAME, PROTECTION_MODE, PROTECTION_LEVEL FROM SYS.DBA_OB_TENANTS;
  ```

  :::
