# 附录：general_sql_command 支持的完整 SQL 类型

本文档用于列举当前版本 `general_sql_command` 可匹配的完整 SQL 类型清单，便于在安全审计过滤器中按语句类型进行精确过滤。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>本附录所对应功能从 V4.4.2 BP1 版本开始支持。</p>
</main>

## 使用说明

* 该清单用于 `AUDIT_LOG_FILTER_SET_FILTER` 的 `general_sql_command` 字段取值。
* 按字母序排列。
