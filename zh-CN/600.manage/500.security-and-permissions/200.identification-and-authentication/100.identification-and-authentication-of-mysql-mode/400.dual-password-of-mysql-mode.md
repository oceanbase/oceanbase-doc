# 双密码管理

MySQL 模式支持在修改用户密码时保留旧密码（双密码 / 密码轮转），以便应用在配置切换期间仍可使用旧口令连接，降低一次性全量改密带来的断连风险。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本功能从 V4.4.2 BP1 版本开始支持。</p>
</main>

## 语法

### 修改密码并保留当前密码

在设置新密码的同时保留原密码（新旧密码在一段时间内均可用于认证）：

```sql
ALTER USER 'user_name'@'host'
  IDENTIFIED BY 'new_password' RETAIN CURRENT PASSWORD;
```

* `user_name`、`host`：与创建用户时的账户名规则一致（例如 `'appuser'@'%'`）。
* `new_password`：新密码明文（由服务端按插件策略存储）。

### 丢弃旧密码

在已完成新密码切换后，显式丢弃已保留的旧密码，仅保留当前密码：

```sql
ALTER USER 'user_name'@'host' DISCARD OLD PASSWORD;
```

执行成功后，旧密码不可再用于登录。

## 使用说明

* 除修改当前用户自身口令的场景外，执行 `ALTER USER` 通常需要具备 `CREATE USER` 等相应管理权限；权限要求与通用 `ALTER USER` 一致，参见 [ALTER USER](../../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1800.alter-user-of-mysql-mode.md)。
* `RETAIN CURRENT PASSWORD` 仅在与 `IDENTIFIED BY` 同时指定时有意义；用于表达「本次改密进入双密码状态」。
* `DISCARD OLD PASSWORD` 用于在业务已全部切到新密码后，清理旧口令；若当前不存在有效旧密码，行为以实现及错误提示为准。

## 示例

将用户 `appuser` 从任意主机连接的账户密码改为 `NewPass`，并保留改密前的旧密码：

```sql
obclient> ALTER USER 'appuser'@'%' IDENTIFIED BY 'NewPass' RETAIN CURRENT PASSWORD;
```

确认业务已切换至新密码后，丢弃旧密码：

```sql
obclient> ALTER USER 'appuser'@'%' DISCARD OLD PASSWORD;
```

## 相关元数据

双密码及轮转相关信息会反映在系统表/视图中，便于审计与排查：

* `mysql.user`：新增 `user_attributes`（`longtext`），其中 JSON 的 `additional_password` 键存放与旧密码相关的属性；详见 [mysql.user](../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/4200.mysql-user-of-mysql-mode.md)。
* `oceanbase.DBA_OB_USERS` / `oceanbase.CDB_OB_USERS`：新增 `OLD_PASSWORD`、`OLD_PASSWORD_START_TIME` 等列（`OLD_PASSWORD_START_TIME` 为 `-1` 时表示无有效旧密码）；详见 [oceanbase.DBA_OB_USERS](../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/12900.o-dba_ob_users-of-mysql-mode.md) 与 [oceanbase.CDB_OB_USERS](../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/11900.o-cdb_ob_users-of-sys-tenant.md)（系统租户下查询 `CDB_OB_USERS`）。
