# 修改备份路径的源端配置

在数据备份过程中，用户可以根据业务实际情况，修改备份路径的源端配置，即 `zone`、`idc` 或 `region` 配置。修改后，新的配置信息将覆盖原来的配置信息。

## 使用限制

* 对于 V4.2.1 版本，从 V4.2.1 BP11 版本开始支持修改备份路径的源端配置。
* 仅支持用户租户修改本租户备份路径的源端配置，不支持系统租户修改指定用户租户备份路径的源端配置。

## 注意事项

* 修改备份路径的 `zone`、`idc` 或 `region` 配置时，如果需要设置 Region 层级或 IDC 层级，需要先通过 `ALTER SYSTEM MODIFY ZONE zone_name SET REGION=region_name;` 或 `ALTER SYSTEM MODIFY ZONE zone_name SET IDC=idc_name;` 语句设置 Region 信息或 IDC 信息。推荐设置 IDC 层级的源端配置，利用有较多网络带宽资源的 IDC 来执行备份任务的同时，备份任务有更多的可选节点范围，同时用户也不需要关注集群中 IDC 内 Zone 的变化情况。

* 修改备份路径的 `zone`、`idc` 或 `region` 配置时，要求 Root Service 的 Leader 节点在指定的 `zone`、`idc` 或 `region` 中，否则，备份任务将无法成功向目标备份路径写入备份元数据，最终导致备份任务执行失败。建议备份路径源端设置包含 Primary Zone 范围。

* 修改备份路径的 `zone`、`idc` 或 `region` 配置时，如果有备份任务正在执行，由于正在执行的任务至多需要分钟级时间才能感知到配置的变化，故在配置修改期间，仍可能会有配置范围外的节点访问备份路径，导致产生跨机房或跨地域的流量。

## 操作步骤

1. 租户管理员登录集群的用户租户。

2. 执行以下语句，修改备份路径的源端配置。

   SQL 语句如下：

   ```sql
   ALTER SYSTEM {ALTER|CHANGE|MODIFY} EXTERNAL_STORAGE_DEST PATH [=] 'path' SET ATTRIBUTE = '{zone=zone_name | idc=idc_name | region=region_name}';
   ```

   相关参数说明如下：

   * `path`：指定待修改配置的备份路径。如果归档介质为对象存储类型，则还需要包含对象存储的主机地址及访问密钥。例如，当归档介质为 OSS 时，该路径格式为 `oss://oceanbase-test-bucket/backup/databackup?host=xxxx`。

   * `zone=zone_name | idc=idc_name | region=region_name`：指定当前备份路径的源端。支持选择 `zone`、`idc` 或 `region` 三个不同层级的配置，只能同时选择一个层级或者不设置。

     如果需要设置多个 Zone、多个 IDC 或多个 Region，多个 Zone/IDC/Region 之间使用英文逗号（,）和英文分号（;）分隔。其中：

     * 英文逗号（,）表示在选择执行备份任务节点时，左右两边的 Zone/IDC/Region 内的节点具有相同的优先级。
     * 英文分号（;）表示左边 Zone/IDC/Region 内的节点优先级比右边的高，即优先选择左边的 Zone/IDC/Region 内的节点执行备份任务。

     例如，如果设置为 `zone=z1,z2;z3` 表示指定 `z1`、`z2`、`z3` 作为备份的源端，`z1`、`z2` 在同一优先级，且 `z1`、`z2` 的优先级高于 `z3`。

   * 设置时，如果设置的 `zone`、`idc` 或 `region` 不存在，将会报错提示源端信息不存在（错误码 `-9133`）。

   示例如下：

   * 将备份路径 `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com` 的源端配置从 `zone=z1,z2;z3` 更改为 `idc=idc1;idc2`。

      ```shell
      obclient> ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST PATH='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com' SET ATTRIBUTE = 'idc=idc1;idc2';
      ```

   * 将备份路径 `file:///data/nfs/backup/data` 的源端配置从 `zone=z1,z2;z3` 更改为 `region=region1`。

      ```shell
      obclient> ALTER SYSTEM CHANGE EXTERNAL_STORAGE_DEST PATH='file:///data/nfs/backup/data' SET ATTRIBUTE = 'region=region1';
      ```

   更多示例，参见 [ALTER/CHANGE/MODIFY EXTERNAL_STORAGE_DEST](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1430.alter-system-change-external-storage-dest-of-mysql-mode.md)。

3. 修改成功后，可以查询视图 `DBA_OB_BACKUP_STORAGE_INFO` 进行确认。

   有关查看备份路径源端配置的详细操作，参见 [查看数据备份相关参数](700.parameters-of-data-backup.md)。
