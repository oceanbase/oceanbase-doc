# 查看备份校验进度

发起备份校验后，可以通过视图来查看校验任务的状态及进度。

## 系统租户查看用户租户下的备份校验任务

系统租户可以通过视图 `CDB_OB_BACKUP_VALIDATE_JOBS` 和 `CDB_OB_BACKUP_VALIDATE_TASKS` 来查看各用户租户下所有校验任务的状态和进度。

其中：

* 视图 `CDB_OB_BACKUP_VALIDATE_JOBS` 中，每个 Job 对应一个校验指令。如果执行校验指令时，指令中涉及多个用户租户，则视图中可能会对应多个用户租户级别的子 Job。

* 视图 `CDB_OB_BACKUP_VALIDATE_TASKS` 中，每个 Task 对应一个备份集（backup_set）或日志归档 Piece（archive_piece）的校验任务。

系统租户下查看备份校验进度的操作如下：

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 查看 Job 级校验任务的状态及进度。

## 用户租户查看本租户下的备份校验任务

用户租户可以通过视图 `DBA_OB_BACKUP_VALIDATE_JOBS` 和 `DBA_OB_BACKUP_VALIDATE_TASKS` 来查看本租户下校验任务的状态和进度。

其中：

* 视图 `DBA_OB_BACKUP_VALIDATE_JOBS` 中，每个 Job 对应一个校验指令。

* 视图 `DBA_OB_BACKUP_VALIDATE_TASKS` 中，每个 Task 对应一个备份集（backup_set）或日志归档 Piece（archive_piece）的校验任务。

用户租户下查看备份校验进度的操作如下：

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 查看 Job 级校验任务的状态及进度。

   :::tab
   tab MySQL 模式

   MySQL 模式下的查询语句如下：

   ```shell
   obclient(root@mysqltenant)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS;
   ```

   tab Oracle 模式

   Oracle 模式下的查询语句如下：

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOBS;
   ```

   :::

3. 查看 Task 级备份校验任务，即备份集或日志归档 Piece 的备份校验情况。

   :::tab
   tab MySQL 模式

   MySQL 模式下的查询语句如下：

   ```shell
   obclient(root@mysqltenant)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_TASKS;
   ```

   tab Oracle 模式

   Oracle 模式下的查询语句如下：

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_TASKS;
   ```

   :::
