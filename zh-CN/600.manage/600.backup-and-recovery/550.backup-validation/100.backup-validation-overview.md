# 备份校验概述

OceanBase 数据库的备份校验功能主要用于解决备份和归档数据的完整性和正确性问题。用户可以在不执行实际恢复操作的情况下，主动校验备份集和归档日志是否存在文件缺失、物理数据损坏或逻辑不一致等问题。

备份校验按照校验级别，可以分为 Basic 校验和 Physical 校验。其中：

* Basic 校验：仅检查文件列表的完整性。

* Physical 校验：检查物理数据的正确性及逻辑一致性。

## 功能特点

OceanBase 数据库的备份校验功能具有以下特点：

* 提升恢复的成功率：通过提前校验，确保“有备无患”，消除“由于备份损坏导致无法恢复”的隐患。

* 多层级校验能力：提供 Basic 校验和 Physical 校验等两个校验等级，满足不同时效性和深度的校验需求。

* 灵活的校验粒度：支持对整个备份和归档路径、指定备份集、指定日志归档 Piece 进行校验，并且支持跨集群指定路径下的备份数据校验。

## 应用场景

备份校验功能通常用于以下场景：

* 数据搬迁完整性检查：备份数据在不同目录或存储介质间拷贝后，需要检查是否有文件遗漏未拷贝。

* 备份集可用性检查：不执行恢复操作，检查备份集是否可以支持恢复操作。

根据 OceanBase 数据库的校验等级和校验粒度，常见业务场景下推荐的校验方式如下表示。

| 业务场景                                                           | 推荐校验方案                                       | 参考文档    |
|-------------------------------------------------------------------|---------------------------------------------------|-------------|
| **例行巡检**：需要定期检查当前租户产生的备份集是否可用                      | 使用 Physical 级校验来校验整个备份和归档路径         | [校验整个备份路径和归档路径](200.validate-the-data-backup-dest-and-log-archive-dest.md) |
| **数据搬迁后的检查**：拷贝备份数据后，仅用于快速确认文件是否齐全             | 使用 Basic 级校验指定路径下的备份集                 | [校验指定路径下的备份集或日志归档 Piece](400.validate-the-backupset-or-archivepiece-at-the-specified-dest.md) |
| **异地恢复前的检查**：在集群 B上恢复集群 A 的备份数据，以验证备份数据的可用性 | 使用指定路径下的备份数据校验                        | [校验指定路径下的备份集或日志归档 Piece](400.validate-the-backupset-or-archivepiece-at-the-specified-dest.md) |
| **抽检或者快速验证特定的备份数据**：仅校验最近一次的全量备份                 | 通过指定 `backup_set_id` 的方式校验指定的备份集     | [校验指定备份集或日志归档 Piece](300.validate-the-backupset-and-archivepiece.md) |
