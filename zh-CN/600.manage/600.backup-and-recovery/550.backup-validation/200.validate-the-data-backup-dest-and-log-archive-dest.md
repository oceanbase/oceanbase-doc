# 校验当前备份和归档路径下的所有数据

物理备份成功后，可以对租户在当前备份和归档路径下的所有数据进行校验。该方式常用于例行巡检场景下，定期检查当前租户产生的备份集是否可用。

## 背景信息

备份校验按照校验级别，分为 BASIC 校验和 PHYSICAL 校验。其中：

* BASIC 校验：仅检查文件列表完整性。

* PHYSICAL 校验：检查物理数据正确性及逻辑一致性。

## 使用限制及注意事项

* 本文档仅用于校验 `DATA_BACKUP_DEST` 和 `LOG_ARCHIVE_DEST` 中当前指定的路径下的备份或归档数据，对于已更换备份目的端或归档目的端的场景，如果需要校验原备份路径或归档路径下的数据，可以参考 [校验指定路径下的备份集或日志归档 Piece](400.validate-the-backupset-or-archivepiece-at-the-specified-dest.md) 进行校验。

* 由于校验任务会频繁地通过访问备份介质来读取数据，进而抢占备份任务的网络资源，建议指定在未执行备份任务且低负载的用户租户上执行校验任务。

* 执行备份校验时：

  * 对于 V4.6.0 版本之前的备份集以及 V4.6.0 版本之前的日志归档 Piece，不支持 BASIC 校验，即不支持文件完整性校验。

  * 对于 V4.3.4 版本（不含 V4.3.4 版本）之前的备份集，不支持 PHYSICAL 校验，
