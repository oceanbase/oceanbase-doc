# 校验整个备份路径和归档路径

物理备份成功后，可以对用户租户在当前备份和归档路径下的所有备份集和归档 Piece 进行备份校验。支持对集群内所有用户租户或者单一租户进行备份校验。

## 使用限制及注意事项

* 本文档仅用于校验当前集群内租户下 `DATA_BACKUP_DEST` 和 `LOG_ARCHIVE_DEST` 中当前指定的路径下的所有备份集和日志归档 Piece。如果需要校验当前备份或归档路径下指定的备份集或日志归档 Piece，可参考 [校验指定备份集或日志归档 Piece](300.validate-the-backupset-and-archivepiece.md) 进行校验。

  此外，对于已更换备份目的端或归档目的端的场景，如果需要校验原备份路径或归档路径下的数据，可参考 [校验指定路径下的备份集或日志归档 Piece](400.validate-the-backupset-or-archivepiece-at-the-specified-dest.md) 进行校验。

* 由于校验任务会频繁地通过访问备份介质来读取数据，进而抢占备份任务的网络资源，建议在用户租户未执行备份任务且低负载时执行校验任务。

* 指定备份校验的校验等级时：

  * 对于 V4.4.2 版本，V4.4.2 BP2 版本（不含 V4.4.2 BP2 版本）之前的备份集以及日志归档 Piece，不支持 Basic 校验，即不支持文件的完整性校验。

  * 对于 V4.3.4 版本（不含 V4.3.4 版本）之前的备份集，不支持 Physical 校验，即不支持物理数据的正确性及逻辑一致性校验。

## 系统租户对用户租户的整个备份路径和归档路径发起备份校验

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 执行以下命令，发起备份校验。

   语句如下：

   ```sql
   ALTER SYSTEM VALIDATE BACKUP [LEVEL= { 'basic' | 'physical' }] [TENANT = tenant_name];
   ```

   语句中相关参数说明如下：

   * `LEVEL`：可选参数，表示校验等级。如果不指定，则默认值为 `physical`。其中：

     * `basic` 校验：仅检查文件列表的完整性。

     * `physical` 校验：检查物理数据的正确性及逻辑一致性。

   * `TENANT`：可选参数，用于指定执行校验任务的用户租户。如果不指定，则校验集群内的所有用户租户。

   示例如下：

   * 系统租户对集群内所有用户租户在当前备份和归档路径下的所有备份集和归档 Piece 发起 Basic 校验。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUP LEVEL = 'basic';
     ```

   * 系统租户对指定用户租户 `mysqltenant` 在当前备份和归档路径下的所有备份集和归档 Piece 发起 Physical 校验。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM VALIDATE BACKUP LEVEL = 'physical' TENANT = mysqltenant;
     ```

3. 语句执行成功后，可分别通过 `CDB_OB_BACKUP_VALIDATE_JOBS`、`CDB_OB_BACKUP_VALIDATE_TASKS`、`CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` 以及 `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY` 等视图查看校验任务的状态、进度及执行结果。

   查看备份校验进度的详细操作及介绍，参见 [查看备份校验进度](600.view-the-backup-validation-process.md)。

   查看备份校验结果的详细操作及介绍，参见 [查看备份校验结果](700.view-the-backup-validation-history.md)。

## 用户租户对本租户的整个备份路径和归档路径发起备份校验

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 执行以下命令，发起备份校验。

   语句如下：

   ```sql
   ALTER SYSTEM VALIDATE BACKUP [LEVEL = { 'basic' | 'physical' }];
   ```

   语句中，`LEVEL` 为可选参数，表示校验等级。如果不指定，则默认值为 `physical`。其中：

   * `basic` 校验：仅检查文件列表的完整性。

   * `physical` 校验：检查物理数据的正确性及逻辑一致性。

   用户租户对本租户在当前备份和归档路径下的所有备份集和归档 Piece 发起 Basic 校验，示例如下：

    ```shell
    obclient> ALTER SYSTEM VALIDATE BACKUP LEVEL = 'basic';
    ```

3. 语句执行成功后，可分别通过 `DBA_OB_BACKUP_VALIDATE_JOBS`、`DBA_OB_BACKUP_VALIDATE_TASKS`、`DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` 以及 `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` 等视图查看校验任务的状态、进度及执行结果。

   查看备份校验进度的详细操作及介绍，参见 [查看备份校验进度](600.view-the-backup-validation-process.md)。

   查看备份校验结果的详细操作及介绍，参见 [查看备份校验结果](700.view-the-backup-validation-history.md)。
