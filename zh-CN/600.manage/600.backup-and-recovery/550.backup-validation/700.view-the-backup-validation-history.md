# 查看备份校验结果

备份校验任务结束后，可以通过视图来查看校验任务的执行结果。

## 系统租户查看指定用户租户下的备份校验任务

系统租户可以通过视图 `CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` 和 `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY` 来查看各用户租户下所有校验任务的执行结果。

其中：

* 视图 `CDB_OB_BACKUP_VALIDATE_JOB_HISTORY` 中，每个 Job 对应一个校验指令。如果执行校验指令时，指令中涉及多个用户租户，则视图中可能会对应多个用户租户级别的子 Job。

* 视图 `CDB_OB_BACKUP_VALIDATE_TASK_HISTORY` 中，每个 Task 对应一个备份集（backup_set）或日志归档 Piece（archive_piece）的校验任务。

系统租户下查看备份校验结果的操作如下：

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 查看 Job 级校验任务的执行结果。

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_JOB_HISTORY\G
   ```

   查询结果如下：

   ```shell
   *************************** 1. row ***************************
             TENANT_ID: 1002
                JOB_ID: 2
           INCARNATION: 1
   INITIATOR_TENANT_ID: 1002
      INITIATOR_JOB_ID: 0
    EXECUTOR_TENANT_ID:
                  TYPE: DATABASE
                  PATH:
             PATH_TYPE:
                    ID:
        VALIDATE_LEVEL: basic
       START_TIMESTAMP: 2026-03-03 13:58:07.778690
         END_TIMESTAMP: 2026-03-03 13:58:09.864257
                STATUS: COMPLETED
           RETRY_COUNT: 0
            TASK_COUNT: 1
    SUCCESS_TASK_COUNT: 1
                RESULT: 0
           DESCRIPTION:
               COMMENT: all archive pieces are not support for backup validate or not find any piece
   1 row in set
   ```

   查询结果展示的是租户 ID 为 1002 的用户租户的 Job 级校验任务的执行结果。其中，`job_id` 为 2，发起此次 Job 的租户为本租户（`INITIATOR_TENANT_ID` 为 1002），需要执行校验任务的用户租户是本租户（`EXECUTOR_TENANT_ID` 为空），校验的是整个备份路径和归档路径下的所有备份集和日志归档 Piece（`TYPE` 为 `DATABASE`），且为非指定路径下的校验（`PATH`、`PATH_TYPE`、`ID` 等均为空），校验等级是 Basic 级校验（`VALIDATE_LEVEL` 为 `basic`），校验任务执行完成（`STATUS` 为 `COMPLETED`），校验结果是 `all archive pieces are not support for backup validate or not find any piece`。

3. 查看 Task 级备份校验任务，即备份集或日志归档 Piece 的备份校验结果。

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_VALIDATE_TASK_HISTORY\G
   ```

   查询结果如下：

   ```shell
   *************************** 1. row ***************************
           TENANT_ID: 1002
             TASK_ID: 3
         INCARNATION: 1
              JOB_ID: 2
           TASK_TYPE: BACKUPSET
                  ID: 1
                PATH: file:///data/nfs/backup/data/backup_set_1_full
           PATH_TYPE: BACKUP_SET_DEST
             DEST_ID: 1002
     PLUS_ARCHIVELOG: OFF
   INITIATOR_TASK_ID: 0
      VALIDATE_LEVEL: basic
            ROUND_ID: 0
     START_TIMESTAMP: 2026-03-03 13:58:07.802366
       END_TIMESTAMP: 2026-03-03 13:58:09.860637
              STATUS: COMPLETED
      TOTAL_LS_COUNT: 2
     FINISH_LS_COUNT: 2
         TOTAL_BYTES: 21126037
     VALIDATED_BYTES: 0
              RESULT: 0
             COMMENT:
   1 row in set
   ```

   查询结果展示的是租户 ID 为 1002 的用户租户的 Task 级校验任务的执行结果。其中，`task_id` 为 3，对应的 `job_id` 为 2，校验的是 `backup_set_id` 为 1 的备份集（`TASK_TYPE` 为 `BACKUPSET`、`ID` 为 1）；备份集所在的路径为 `file:///data/nfs/backup/data/backup_set_1_full`，备份路径的 ID 为 1002（`DEST_ID` 为 1002），该备份集不是补偿日志（`PLUS_ARCHIVELOG` 为 `OFF`），校验等级是 Basic 级校验（`VALIDATE_LEVEL` 为 `basic`），校验任务执行完成（`STATUS` 为 `COMPLETED`）。

## 用户租户查看本租户下的备份校验任务

用户租户可以通过视图 `DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` 和 `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` 来查看各用户租户下所有校验任务的执行结果。

其中：

* 视图 `DBA_OB_BACKUP_VALIDATE_JOB_HISTORY` 中，每个 Job 对应一个校验指令。

* 视图 `DBA_OB_BACKUP_VALIDATE_TASK_HISTORY` 中，每个 Task 对应一个备份集（backup_set）或日志归档 Piece（archive_piece）的校验任务。

用户租户下查看备份校验结果的操作如下：

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 查看 Job 级校验任务的执行结果。

   :::tab
   tab MySQL 模式

   MySQL 模式下的查询语句如下：

   ```shell
   obclient(root@mysqltenant)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY;
   ```

   tab Oracle 模式

   Oracle 模式下的查询语句如下：

   ```shell
   obclient(SYS@oracletenant)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOB_HISTORY;
   ```

   :::

   查询结果的示例如下：

   ```shell

            TASK_COUNT: 1
    SUCCESS_TASK_COUNT: 1
                RESULT: 0

   ```

3. 查看 Task 级备份校验任务，即备份集或日志归档 Piece 的备份校验结果。

   :::tab
   tab MySQL 模式

   MySQL 模式下的查询语句如下：

   tab Oracle 模式
