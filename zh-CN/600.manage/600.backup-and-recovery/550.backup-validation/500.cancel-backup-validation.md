# 取消备份校验

发起备份校验任务后，可以取消正在执行的校验任务。

## 系统租户取消用户租户的备份校验任务

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 执行以下命令，取消用户租户正在执行的校验任务。

   语句如下：

   ```sql
   ALTER SYSTEM CANCEL VALIDATE BACKUP [TENANT = tenant_name];
   ```

   语句中，`TENANT` 用于指定取消备份校验任务的租户，如果不指定，则取消集群中所有用户租户的备份校验任务。

   示例如下：

   * 系统租户取消所有用户租户的备份校验任务。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP;
     ```

   * 系统租户取消指定用户租户 `mysqltenant` 的备份校验任务。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP TENANT = mysqltenant;
     ```

## 用户租户取消本租户的备份校验任务

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 执行以下命令，取消本租户正在执行的校验任务。

   ```shell
   obclient> ALTER SYSTEM CANCEL VALIDATE BACKUP;
   ```
