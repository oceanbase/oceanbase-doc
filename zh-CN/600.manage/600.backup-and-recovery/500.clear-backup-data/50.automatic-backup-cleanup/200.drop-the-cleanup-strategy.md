# 删除清理策略

清理策略设置成功后，如果需要停止过期备份的自动清理或者更换清理策略，需要先删除清理策略。

## 注意事项及说明

* 删除清理策略时，当将租户下所有的清理策略都删除后，相当于关闭了该租户的自动清理功能。

* 删除清理策略并不会影响正在执行的清理任务，仅表示系统下次进行自动清理调度时，被删除的清理策略将不会再生成清理任务。

## 系统租户为指定用户租户删除清理策略

1. 使用 `root` 用户登录集群的 `sys` 租户。

2. 执行以下语句，删除清理策略。

   ```sql
   ALTER SYSTEM DROP DELETE BACKUP POLICY policy_name TENANT [=] tenant_name;
   ```

   其中：

   * `policy_name`：指定待删除的清理策略名, 可以从视图 `CDB_OB_BACKUP_DELETE_POLICY` 中获取。

   * `tenant_name`：指定用户租户的租户名，在系统租户下删除清理策略必须指定用户租户名，且仅支持指定一个用户租户名。

   示例如下：

   * 系统租户删除租户 `mysql001` 的清理策略

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM DROP DELETE BACKUP POLICY 'default' TENANT mysql001;
     ```

   * 系统租户删除租户 `oracle001` 的清理策略

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM DROP DELETE BACKUP POLICY 'log_only' TENANT oracle001;
     ```

3. 确认清理策略是否已被删除。

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_POLICY WHERE tenant_id = 1002;
   ```

   根据查询结果，当视图中已无对应租户的清理策略记录时，表示该租户的清理策略已删除成功。

## 用户租户删除本租户的清理策略

1. 租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

2. 执行以下语句，删除清理策略。

   语句如下：

   ```sql
   ALTER SYSTEM DROP DELETE BACKUP POLICY policy_name;
   ```

   其中，`policy_name` 用于指定待删除的清理策略名，可以通过查看视图 `oceanbase.DBA_OB_BACKUP_DELETE_POLICY` 或 `SYS.DBA_OB_BACKUP_DELETE_POLICY` 来获取当前租户所设置的清理策略。

   示例如下：

   :::tab
   tab MySQL 模式

   MySQL 模式下删除当前租户的清理策略 `default`。

   ```shell
   obclient(root@mysql001)[(none)]> ALTER SYSTEM DROP DELETE BACKUP POLICY 'default';
   ```

   tab Oracle 模式

   Oracle 模式下删除当前租户的清理策略 `log_only`。

   ```shell
   obclient(SYS@oracle001)[SYS]> ALTER SYSTEM DROP DELETE BACKUP POLICY 'log_only';
   ```

   :::

3. 确认清理策略是否已被删除。

   可以通过视图 `oceanbase.DBA_OB_BACKUP_DELETE_POLICY`（MySQL 模式）或 `SYS.DBA_OB_BACKUP_DELETE_POLICY`（Oracle 模式）来确认当前租户的清理策略是否已删除。

   :::tab
   tab MySQL 模式

   MySQL 模式下的查询示例如下：

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_POLICY;
   ```

   tab Oracle 模式

   Oracle 模式下的查询示例如下：

   ```shell
   obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_POLICY;
   ```

   :::

   根据查询结果，当视图中已无对应的清理策略记录时，表示该租户的清理策略已删除成功。

## 后续操作

删除清理策略后，为避免因备份文件未及时清理而导致的磁盘空间满最终影响到备份操作，请在删除清理策略后及时设置新的清理策略。设置清理策略的具体操作参见 [自动清理过期备份](100.cleaning-up-backed-up-data-automatically.md)。
