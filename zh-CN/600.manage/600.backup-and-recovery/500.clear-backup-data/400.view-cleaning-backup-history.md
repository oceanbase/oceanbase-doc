# 查看备份清理结果

成功设置清理策略，且自动清理已被触发，当清理任务执行完成，可通过历史表查看清理任务执行结果。

## 系统租户查看清理任务历史

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 查看清理任务的历史记录。

   * 查看 Job 级清理任务的历史记录。

      Job 级清理任务中记录了清理任务发起的相关信息。

## 用户租户查看清理任务历史

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 查看清理任务的历史记录。

   * 查看 Job 级清理任务的历史记录。

     Job 级清理任务中记录了清理任务发起的相关信息。

     :::tab
     tab MySQL 模式

     MySQL 模式下的查询示例如下：

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     tab Oracle 模式

     Oracle 模式下的查询示例如下：

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     :::

     除了缺少 `TENANT_ID` 字段，视图 `DBA_OB_BACKUP_DELETE_JOB_HISTORY` 的所有字段均与视图 `CDB_OB_BACKUP_DELETE_JOB_HISTORY` 相对应。有关查询结果的详细说明，参见 **系统租户查看清理任务历史**。

   * 查看 Task 级清理任务的历史记录。

     Task 级清理任务中记录了 `backup_set/backup_piece` 被清理的详细信息。

     :::tab
     tab MySQL 模式

     MySQL 模式下的查询示例如下：

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     tab Oracle 模式

     Oracle 模式下的查询示例如下：

     ```shell
     obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     :::

     除了缺少 `TENANT_ID` 字段，视图 `DBA_OB_BACKUP_DELETE_TASK_HISTORY` 的所有字段均与视图 `CDB_OB_BACKUP_DELETE_TASK_HISTORY` 相对应。有关查询结果的详细说明，参见 **系统租户查看清理任务历史**。
