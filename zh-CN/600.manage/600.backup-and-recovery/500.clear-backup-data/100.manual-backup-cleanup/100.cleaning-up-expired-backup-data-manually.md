# 手动触发备份的过期清理

设置清理策略后，如果用户期望尽快进行备份的过期清理，可以立即手动触发一次过期清理任务。手动触发过期清理后，系统会根据租户所配置的清理策略进行过期清理。

## 前提条件

请确认当前租户已设置自动清理策略。设置及确认自动清理策略的详细操作，参见 [自动清理过期备份](../50.automatic-backup-cleanup/100.cleaning-up-backed-up-data-automatically.md)。

## 系统租户触发指定用户租户的备份的过期清理

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 执行以下命令，手动触发备份的过期清理。

   语句如下：

   ```sql
   ALTER SYSTEM DELETE OBSOLETE BACKUP [TENANT [=] tenant_name]; 
   ```

   其中，`TENANT [=] tenant_name` 用于指定触发某个用户租户的备份的过期清理；如果不指定用户租户，则默认触发所有用户租户的备份的过期清理。

   示例如下：

   * 系统租户触发租户 `mysql001` 的备份的过期清理。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM DELETE OBSOLETE BACKUP TENANT mysql001;
     ```

   * 系统租户触发所有用户租户的备份的过期清理。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM DELETE OBSOLETE BACKUP;
     ```

## 用户租户触发本租户的备份的过期清理

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 执行以下命令，手动触发本租户的备份的过期清理。

   ```shell
   obclient> ALTER SYSTEM DELETE OBSOLETE BACKUP;
   ```
