# 清空备份或归档路径

替换备份或归档路径后，可以将替换掉的不再使用的备份或归档路径清空。

## 使用限制

* 仅支持清空被替换的备份或归档路径，不支持清空当前正在使用的备份或归档路径。
* 不支持将正在清空的备份或归档路径重新设置回原来的备份路径或归档路径。

## 清空备份路径

### 系统租户清空指定用户租户的备份路径

1. 使用 `root` 用户登录集群的 `sys` 租户。

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. 获取待清空的备份路径。

   ```shell
   obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_STORAGE_INFO WHERE TENANT_ID = tenant_id AND DEST_TYPE = 'backup_data'\G
   ```

   查询结果如下：

   ```shell
   ```

3. 执行以下命令，清空指定的备份路径。

   语句如下：

   ```sql
   ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST [=] 'data_backup_path' TENANT [=] tenant_name;
   ```

   其中：

   * `data_backup_path`：指定待清空的数据备份路径。

   * `tenant_name`：指定待清空的数据备份路径所属的租户。

   示例如下：

   :::tab
   tab OSS

   系统租户清空租户 `mysql001` 的 OSS 备份路径 `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com&access_id=****&access_key=****`。

   ```shell
   obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com&access_id=****&access_key=****' TENANT = mysql001;
   ```

   tab NFS

   系统租户清空租户 `mysql001` 的 NFS 备份路径 `file:///data/nfs/backup/data`。

   ```shell
   obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='file:///data/nfs/backup/data' TENANT = mysql001;
   ```

   :::

### 用户租户清空本租户的备份路径

1. 用户租户的租户管理员登录到数据库。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>MySQL 租户的管理员用户为 <code>root</code> 用户，Oracle 租户的管理员用户为 <code>SYS</code> 用户。</p>
   </main>

   连接示例如下，连接数据库时请以实际环境为准。

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. 获取待清空的备份路径。

   :::tab
   tab MySQL 模式

   MySQL 模式下的查询示例如下：

   ```shell
   obclient(root@mysql001)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO WHERE DEST_TYPE = 'backup_data'\G
   ```

   tab Oracle 模式

   Oracle 模式下的查询示例如下：

   ```shell
   obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_STORAGE_INFO WHERE DEST_TYPE = 'backup_data'\G

   :::

   查询结果的示例如下：

   ```shell
   ```

3. 执行以下命令，清空指定的备份路径。

   语句如下：

   ```sql
   ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST [=] 'data_backup_path';
   ```

   其中，`data_backup_path` 用于指定待清空的数据备份路径。

   示例如下：

   :::tab
   tab OSS

   用户租户清空本租户的 OSS 备份路径 `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com&access_id=****&access_key=****`。

   ```shell
   obclient> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com&access_id=****&access_key=****';

   ```shell
