# 租户资源水平扩缩容

租户资源的水平管理主要是通过调整资源池的 `UNIT_NUM` 来动态调整租户的可用资源。具体表现为，您可以通过调整资源池的 `UNIT_NUM` 来调整资源池下每个 Zone 内 Unit 数量，进而提高或降低该租户在对应 Zone 上的服务能力。

在 V4.x 之前版本中，OceanBase 数据库仅支持租户的同构 Zone 模式，同构 Zone 模式下，要求租户下各 Zone 的 `UNIT_NUM` 必须相同。

在 V4.2.5 版本中，OceanBase 数据库从 V4.2.5 BP5 版本开始，支持租户的异构 Zone 模式。异构 Zone 模式下，租户下各 Zone 的 `UNIT_NUM` 可以相同也可以不同，但一个租户的所有 Zone 最多只能有两种 `UNIT_NUM`。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>通常情况下，对于已有租户或者升级上来的租户，默认均为同构 Zone 模式，如果需要开启异构 Zone 模式，需要将租户级配置项 <code>zone_deploy_mode</code> 的值修改为 <code>hetero</code>（异构 Zone 模式）。修改后，不支持再改回 <code>homo</code>（同构 Zone 模式）。</p>
</main>

`UNIT_NUM` 的变更也分为两类，即调大 `UNIT_NUM` 和调小 `UNIT_NUM`：

* 对于同构 Zone 模式部署的租户：

  * 如果 Resource Pool 未授予租户，则可以单独调小或调大 Resource Pool 的 `UNIT_NUM`。

  * 如果 Resource Pool 已授予租户，只能同时调整所有已授予租户的 Resource Pool 的 `UNIT_NUM`，无法单独调整。

* 对于异构 Zone 模式部署的租户，无论 Resource Pool 是否授予租户，均可以已调整。即，支持同时调整所有已授予租户的 Resource Pool 的 `UNIT_NUM`，也支持单独调大调小 Resource Pool 的 `UNIT_NUM`。

调大或调小 `UNIT_NUM` 本质上是增加和删除 Unit。调整资源池 `UNIT_NUM` 的示例语句如下：

```shell
obclient> CREATE RESOURCE POOL rp1 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone1', 'zone2');
```

1. 对于异构 Zone 模式下的 Resource Pool，或者，同构 Zone 模式下，对于未授予租户的 Resource Pool，单独调整 Resource Pool 的 unit_num：

    ```shell
    obclient> ALTER RESOURCE POOL rp1 UNIT_NUM 3; // 调大 UNIT_NUM

    obclient> ALTER RESOURCE POOL rp1 UNIT_NUM 2; // 调小 UNIT_NUM

    obclient> ALTER RESOURCE POOL rp1 UNIT_NUM 1 DELETE UNIT = (1001, 1003); // 指定资源单元调小 UNIT_NUM
    ```

2. 同时调整租户所有资源池的 unit_num：

    ```shell
    obclient> CREATE RESOURCE POOL rp2 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone1', 'zone2');

    obclient> CREATE RESOURCE POOL rp3 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone3');

    obclient> CREATE TENANT tt RESOURCE_POOL_LIST = ('rp2', 'rp3') ...;

    obclient> ALTER RESOURCE TENANT tt UNIT_NUM = 3; // 同时调大两个resource pool的 UNIT_NUM

    obclient> ALTER RESOURCE TENANT tt UNIT_NUM = 1; // 同时调小两个 Resource Pool 的 UNIT_NUM
    ```

## 调大 UNIT_NUM

* `UNIT_NUM` 调大示例 1:

  创建 Resource Pool 后，可以单独调大单个 Resource Pool 的 `UNIT_NUM`。

  ```shell
  obclient> CREATE RESOURCE POOL r_p0 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone1', 'zone2', 'zone3');
  ```

  对于异构 Zone 模式下的 Resource Pool，或者，同构 Zone 模式下，对于未授予租户的 Resource Pool，单独调大 Resource Pool 的 `UNIT_NUM`，语句如下。

  ```shell
  obclient> ALTER RESOURCE POOL r_p0 UNIT_NUM 3;
  ```

* `UNIT_NUM` 调大示例 2:

  调大 `UNIT_NUM` 通常出现在租户扩容的场景中，例如，对于已授予租户的 Resource Pool：

  ```shell
  obclient> CREATE RESOURCE POOL r_p0 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone1', 'zone2', 'zone3');
  ```

  ```shell
  obclient> CREATE TENANT tt RESOURCE_POOL_LIST = ('r_p0');
  ```

  示例中，租户 `tt` 使用资源池 `r_p0`。在 `zone1`、`zone2`、`zone3` 每个 Zone 上分别有 2 个 Unit，随着业务量的不断变大，每个 Zone 上 2 个 Unit 无法承载当前的业务量，因此需要考虑调大 `UNIT_NUM` 来提高租户的服务能力，以满足新的业务需求。

  您可以使用以下语句将租户在资源池 `r_p0` 的 Unit 数量调整为 `3`，进而提高租户的服务能力。

  ```sql
  obclient> ALTER RESOURCE TENANT tt UNIT_NUM = 3;
  ```

## 调小 UNIT_NUM

* `UNIT_NUM` 调小示例 1:

  创建 Resource Pool 后，可以单独调小单个 Resource Pool 的 `UNIT_NUM`。

  ```shell
  obclient> CREATE RESOURCE POOL r_p0 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone1', 'zone2', 'zone3');
  ```

  对于异构 Zone 模式下的 Resource Pool，或者，同构 Zone 模式下，对于未授予租户的 Resource Pool，单独调小单个 Resource Pool 的 `UNIT_NUM`，语句如下：

  ```shell
  obclient> ALTER RESOURCE POOL r_p0 UNIT_NUM 1;
  ```

  也可以通过删除指定 UNIT 的方式来调小单个 Resource Pool 的 `UNIT_NUM`，语句如下：

  ```shell
  obclient> ALTER RESOURCE POOL r_p0 UNIT_NUM 1 DELETE UNIT=(1001,1002,1003);
  ```

* `UNIT_NUM` 调小示例 2:

  调小 `UNIT_NUM` 通常出现在租户缩容的场景中，例如，对于已授予租户的 Resource Pool：

  ```shell
  obclient> CREATE RESOURCE POOL r_p0 UNIT 'uc1', UNIT_NUM 2, ZONE_LIST ('zone1', 'zone2', 'zone3');
  ```

  ```shell
  obclient> CREATE TENANT tt RESOURCE_POOL_LIST = ('r_p0');
  ```

  示例中，租户 `tt` 使用资源池 `r_p0`。在 `zone1`、`zone2`、`zone3` 每个 Zone 上分别有 2 个 Unit，随着业务调整，不再需要每个 Zone 上 2 个 Unit，因此需要考虑调小 `UNIT_NUM`，以满足新的业务需求。

  您可以使用以下语句将租户在资源池 `r_p0` 的 Unit 数量调整为 `1`，进而降低租户的服务能力。

  ```shell
  obclient> ALTER RESOURCE TENANT tt UNIT_NUM = 1;
  ```

  或者，同构 Zone 模式下，也可以通过删除指定 `UNIT_GROUP` 的方式来调小 `UNIT_NUM` 的数量.

  ```shell
  obclient> ALTER RESOURCE TENANT tt  UNIT_NUM = 1 DELETE UNIT_GROUP =(1001);
  ```
