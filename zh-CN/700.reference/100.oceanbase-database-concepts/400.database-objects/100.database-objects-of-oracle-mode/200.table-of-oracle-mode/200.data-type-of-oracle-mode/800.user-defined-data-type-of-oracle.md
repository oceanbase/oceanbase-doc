# 自定义数据类型

UDT 全称用户自定义类型，用户可以根据业务结构创建适合的自定义类型。原先只支持在 PL 内使用，自OceanBase 数据库 V4.4.2 BP2 版本开始支持作为表列类型使用。提供更灵活的建表数据模型。

目前支持下面两种类型的UDT作为表列（支持复杂嵌套类型）

* OBJECT
* VARRAY

## 语法支持

目前支持以下语法功能：

* 支持 `create` 包含 UDT 列类型的表。
* 支持 `alter table add column`/`drop column`/`modify column` 添加、删除、修改 UDT 列。
* 支持 `insert` UDT 列数据。
* 支持 `update` UDT 列数组。
* 支持访问 UDT 列数据。
* 支持访问 UDT 列属性或成员函数。
* 支持 `table function` 使用 `varray` 类型的 UDT 列。

## 使用示例

* 创建对象类型

    ```sql
    CREATE TYPE type_obj1 AS OBJECT (
        a int,
        b int
    );

    CREATE TYPE type_array AS VARRAY(10) of int;
    ```

* 创建带UDT列的表

    ```sql
    CREATE TABLE t_udt (c1 int, c2 type_obj1, c3 type_array);
    ```

* 插入数据

    ```sql
    INSERT INTO T_UDT VALUES(1, TYPE_OBJ1(1,2), TYPE_ARRAY(1,2,3));
    ```

* UPDATE 数据

    ```sql
    UPDATE T_UDT SET C2 = TYPE_OBJ1(11,22);
    ```

* 查询 UDT 列

    ```sql
    SELECT C1, C2, C3 FROM T_UDT;
    ```

* 查询 UDT 列属性

    ```sql
    SELECT T.C2.A, T.C2.B FROM T_UDT T;
    ```

* 使用 `table function` 访问 `varray` 类型 UDT 列

    ```sql
    SELECT tf.* from T_UDT, table(T_UDT.c3) tf;
    ```

## 功能限制

* 被表列依赖的 UDT 不支持 `alter type` 修改属性。
* 被表依赖的 UDT 不支持 `drop force`。
* 约束或 `order by` 中不支持 `object.addr` 用法。
* update 不支持更新属性。
* 当前版本 OceanBase 写入的 UDT COLUMN 值需要 CDC 通过 online schema 模式处理。
