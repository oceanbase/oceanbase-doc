# 唯一索引和非唯一索引

索引表分为唯一索引和非唯一索引，其中唯一索引保证在表内的索引列上不存在两行有完全相同的值，而非唯一索引则可能存在完全相同的值。在 OceanBase 数据库中，NULL 值也会存储在索引中。

## 存储键

* 非唯一索引

  ​对于非唯一索引，索引表的存储键是用户指定的 **索引列 + 主表主键列**。

* 唯一索引列

  对于唯一索引列，索引表的存储键是用户指定的 **索引列 + 可变的主表主键列**。这里可变的含义是主键列的值是随索引列值的不同而不同：

  * 当 **索引列** 非 NULL 时，**可变的主表主键列** 不发挥作用，使用 **索引列** 的值来存储。
  * 当 **索引列** 为 NULL 时，**可变的主表主键列** 将设置为 **主表主键列** 相同的值，用来在唯一索引表上对多个 NULL 做区分。

**示例如下：**

* 对于非唯一索引表 `idx1_tbl1`，它的存储键是 `col2` 和 `col1`。
* 对于唯一索引表 `idx2_tbl1`：，它的存储键是：

  * 当索引列 `col3` 为 `NULL` 时，可变的 `col1` 列值是主表 `col1` 列的值，它的存储键是 `col1`。
  * 当索引列 `col3` 不为 `NULL` 时，可变的 `col1` 列值为 `NULL` 不发挥作用，它的存储键是 `col3`。

1. 创建表 `tbl1`。

    ```shell
    CREATE TABLE tbl1(col1 INT, col2 INT, col3 INT, col4 INT, PRIMARY KEY(col1));
    ```

2. 创建非唯一索引 `idx1_tbl1`。

    ```shell
    CREATE INDEX idx1_tbl1 ON tbl1(col2);
    ```

3. 创建唯一索引 `idx2_tbl1`。

    ```shell
    CREATE UNIQUE INDEX idx2_tbl1 ON tbl1(col3);
    ```
