# 全文索引

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.4.2 版本，Oracle 模式从 V4.4.2 BP2 版本开始支持创建全文索引。</p>
</main>

OceanBase 数据库在 Oracle 模式下支持全文索引功能，允许对文本类型的列进行高效的全文检索。全文索引可以显著提升关键词搜索操作的查询性能。

## 支持全文索引的列

在 OceanBase 数据库的 Oracle 模式下，全文索引可以应用于 `CHAR`、`VARCHAR`、`VARCHAR2`、`NCHAR`、`NVARCHAR2` 和 `CLOB` 类型的列。

| **数据类型** | **存储特点** | **适用场景** |
|--------------|--------------|--------------|
| CHAR(n)      | 定长字符串，不足补空格 | 固定长度编码、ID 等 |
| VARCHAR(n)   | 变长字符串 | 一般变长文本，实际等同于 `VARCHAR2` |
| VARCHAR2(n)  | 变长字符串 | 推荐用于普通文本字段 |
| NCHAR(n)     | 定长国家字符集字符串 | 多语言固定长度字段 |
| NVARCHAR2(n) | 变长国家字符集字符串 | 多语言变长文本（如中文、日文）|
| CLOB         | 大对象文本，支持海量字符 | 超长文本（文章、日志、JSON 文本等）|

## 全文索引支持的分词器

OceanBase 数据库的全文索引功能支持多种内置分词器，帮助用户根据业务场景选择最优的文本分词策略。在创建全文索引时，通过指定 `PARAMETERS('LEXER parser_name')` 设置分词器。OceanBase 数据库支持分词器如下所示：

* SPACE（默认）
* NGRAM
* NGRAM2
* IK
* BENG

有关分词器选择策略的详细介绍，参见 [全文索引](../../200.database-objects-of-mysql-mode/300.index-of-oracle-mode/320.full-text-indexes-of-mysql-mode-in-concepts.md) 下的 **全文索引的分词器** 章节。
