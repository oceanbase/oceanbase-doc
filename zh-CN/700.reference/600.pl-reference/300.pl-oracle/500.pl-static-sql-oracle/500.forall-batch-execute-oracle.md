# FORALL 批量执行

<main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版 Oracle 模式。</p>
</main>

`FORALL` 语句用于批量执行 `INSERT`、`UPDATE`、`DELETE`、`MERGE INTO` 等 DML 语句，批量执行依赖于 SQL 引擎的 `arraybinding` 功能。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>虽然 <code>MERGE INTO</code> 语句支持在 <code>FORALL</code> 中使用，但 SQL 引擎目前不支持 <code>MERGE INTO</code> 的 <code>arraybinding</code> 功能，因此会降级为 <code>FOR</code> 循环执行。</p>
</main>

`FORALL` 语句通过批量绑定变量（BULK IN-BIND）来批量执行 DML 语句，相比使用 `FOR` 循环逐条执行，可以显著提高性能。

## 配置要求

使用 `FORALL` 批量执行功能需要将配置项 `ob_enable_batched_multi_statement` 设置为 `true`。如果该配置项为 `false`，批量执行会降级为 `FOR` 循环执行。

## 使用限制

以下场景不支持批量执行，会在运行时降级为 `FOR` 循环执行：

* 动态 SQL 中使用了 `IN OUT` 方向的绑定变量。
* 动态 SQL 并非支持的 DML 语句（INSERT、UPDATE、DELETE、MERGE INTO），将退回成 `FOR` 循环执行。
* 部分非法 ·index· 使用的报错信息与 Oracle 存在差异。

## 语法

```sql
FORALL index IN { lower_bound .. upper_bound
                | INDICES OF collection [ BETWEEN lower_bound AND upper_bound ]
                | VALUES OF index_collection }
  [ SAVE EXCEPTIONS ]
  dml_statement;
```

## 使用示例

* 使用 `FORALL` 语句批量插入数据。

    ```shell
    obclient> CREATE TABLE employee_info (
        emp_id NUMBER,
        emp_name VARCHAR2(50),
        salary NUMBER
    );
    Query OK, 0 rows affected

    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        TYPE emp_name_array IS TABLE OF VARCHAR2(50);
        TYPE salary_array IS TABLE OF NUMBER;
        
        emp_ids emp_id_array := emp_id_array(1, 2, 3, 4, 5);
        emp_names emp_name_array := emp_name_array('Alice', 'Bob', 'Charlie', 'David', 'Eve');
        salaries salary_array := salary_array(5000, 6000, 7000, 8000, 9000);
    BEGIN
        FORALL i IN 1..emp_ids.COUNT
            INSERT INTO employee_info VALUES (emp_ids(i), emp_names(i), salaries(i));
        
        DBMS_OUTPUT.PUT_LINE('批量插入完成，共插入 ' || SQL%ROWCOUNT || ' 条记录');
    END;
    /
    ```

    查询结果如下：

    ```shell
    obclient> SELECT * FROM employee_info;
    +--------+----------+--------+
    | EMP_ID | EMP_NAME | SALARY |
    +--------+----------+--------+
    |      1 | Alice    |   5000 |
    |      2 | Bob      |   6000 |
    |      3 | Charlie  |   7000 |
    |      4 | David    |   8000 |
    |      5 | Eve      |   9000 |
    +--------+----------+--------+
    5 rows in set
    ```

* 当集合是稀疏数组（存在空元素）时，可以使用 `INDICES OF` 只处理有值的元素。

    ```shell
    obclient> DECLARE
        TYPE customer_array IS TABLE OF VARCHAR2(50);
        TYPE amount_array IS TABLE OF NUMBER;
        
        cust_tab customer_array := customer_array('Company1', NULL, 'Company3', NULL, 'Company5');
        amount_tab amount_array := amount_array(5000, NULL, 150, NULL, 4000);
    BEGIN
        FORALL i IN INDICES OF cust_tab
            INSERT INTO customer_orders (cust_name, amount) 
            VALUES (cust_tab(i), amount_tab(i));
        
        DBMS_OUTPUT.PUT_LINE('批量插入完成，共插入 ' || SQL%ROWCOUNT || ' 条记录');
    END;
    /
    ```

* 使用 `INDICES OF` 带 `BETWEEN` 子句，可以指定索引范围。

    ```shell
    obclient> DECLARE
        TYPE type_tab IS TABLE OF NUMBER;
        v_tb type_tab;
        v_int NUMBER := 1;
    BEGIN
        v_tb := type_tab(1, 2, 3);
        v_tb.DELETE(2);  -- 删除索引 2 的元素，形成稀疏数组
        
        FORALL i IN INDICES OF v_tb BETWEEN 1 AND 3
            INSERT INTO t_test1 VALUES (v_tb(i), v_int);
        
        DBMS_OUTPUT.PUT_LINE('批量插入完成，共插入 ' || SQL%ROWCOUNT || ' 条记录');
    END;
    /
    ```

* 使用 `VALUES OF` 根据索引集合的值来执行批量操作。

    ```shell
    obclient> DECLARE
        TYPE customer_array IS TABLE OF VARCHAR2(50);
        TYPE amount_array IS TABLE OF NUMBER;
        TYPE index_array IS TABLE OF PLS_INTEGER;
        
        cust_tab customer_array := customer_array('Company1', 'Company2', 'Company3', 'Company4', 'Company5');
        amount_tab amount_array := amount_array(5000, 0, 150, 4000, NULL);
        big_order_tab index_array := index_array();
    BEGIN
        -- 找出金额大于 2000 的订单索引
        FOR i IN cust_tab.FIRST .. cust_tab.LAST LOOP
            IF amount_tab(i) > 2000 THEN
                big_order_tab.EXTEND;
                big_order_tab(big_order_tab.LAST) := i;
            END IF;
        END LOOP;
        
        -- 只插入大额订单
        FORALL i IN VALUES OF big_order_tab
            INSERT INTO big_orders (cust_name, amount) 
            VALUES (cust_tab(i), amount_tab(i));
        
        DBMS_OUTPUT.PUT_LINE('批量插入完成，共插入 ' || SQL%ROWCOUNT || ' 条记录');
    END;
    /
    ```

* 当需要批量执行时，即使部分操作失败也继续执行，可以使用 `SAVE EXCEPTIONS`。

    ```shell
    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        TYPE emp_name_array IS TABLE OF VARCHAR2(50);
        
        emp_ids emp_id_array := emp_id_array(1, 2, 3, 4, 5);
        emp_names emp_name_array := emp_name_array('Alice', 'Bob', 'Charlie', 'David', 'Eve');
        
        dml_errors EXCEPTION;
        PRAGMA EXCEPTION_INIT(dml_errors, -24381);
    BEGIN
        FORALL i IN 1..emp_ids.COUNT SAVE EXCEPTIONS
            INSERT INTO employee_info VALUES (emp_ids(i), emp_names(i), 5000);
        
        DBMS_OUTPUT.PUT_LINE('批量插入完成，共插入 ' || SQL%ROWCOUNT || ' 条记录');
    EXCEPTION
        WHEN dml_errors THEN
            DBMS_OUTPUT.PUT_LINE('发生 ' || SQL%BULK_EXCEPTIONS.COUNT || ' 个错误：');
            FOR i IN 1..SQL%BULK_EXCEPTIONS.COUNT LOOP
                DBMS_OUTPUT.PUT_LINE('错误 ' || i || ': 索引 ' || 
                    SQL%BULK_EXCEPTIONS(i).ERROR_INDEX || 
                    ', 错误代码 ' || SQL%BULK_EXCEPTIONS(i).ERROR_CODE);
            END LOOP;
    END;
    /
    ```

* 在动态 SQL 字符串中可以使用 `FORALL` 语句。动态 SQL 中的 `FORALL` 支持批量执行。

    ```shell
    obclient> DECLARE
        TYPE my_type IS TABLE OF VARCHAR2(10);
        var my_type := my_type('1', '2', 'a', 'b', 'c', '10');
    BEGIN
        EXECUTE IMMEDIATE 'FORALL i IN 1..var.COUNT
            INSERT INTO tab1(s1) VALUES(var(i))';
        
        DBMS_OUTPUT.PUT_LINE('批量插入完成');
    END;
    /
    ```

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>动态 SQL 中的 <code>FORALL</code> 不支持 <code>IN OUT</code> 方向的绑定变量。</p>
    </main>

* 使用 `FORALL` 批量更新数据。

    ```shell
    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        TYPE salary_array IS TABLE OF NUMBER;
        
        emp_ids emp_id_array := emp_id_array(1, 2, 3);
        new_salaries salary_array := salary_array(5500, 6500, 7500);
    BEGIN
        FORALL i IN 1..emp_ids.COUNT
            UPDATE employee_info 
            SET salary = new_salaries(i) 
            WHERE emp_id = emp_ids(i);
        
        DBMS_OUTPUT.PUT_LINE('批量更新完成，共更新 ' || SQL%ROWCOUNT || ' 条记录');
    END;
    /
    ```

* 使用 `FORALL` 批量删除数据。

    ```shell
    obclient> DECLARE
        TYPE dept_array IS TABLE OF NUMBER;
        depts dept_array := dept_array(10, 30, 70);
    BEGIN
        FORALL i IN depts.FIRST..depts.LAST
            DELETE FROM department_table WHERE dept_id = depts(i);
        
        DBMS_OUTPUT.PUT_LINE('批量删除完成，共删除 ' || SQL%ROWCOUNT || ' 条记录');
    END;
    /
    ```
