# DBMS_DAILY_MAINTENANCE 概述

`DBMS_DAILY_MAINTENANCE` 系统包主要用于窗口合并的管理与维护，定时任务根据此系统包触发窗口合并。

## DBMS_DAILY_MAINTENANCE 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_DAILY_MAINTENANCE` 子程序及其简要描述。

|                               **子程序**                                |         **描述**          |
|----------------------------------------------------------------------|-------------------------|
| [TRIGGER_WINDOW_COMPACTION_PROC](200.trigger-window-compaction-proc-oracle.md)| 用于手动触发一次窗口合并。 |
| [SET_THREAD_COUNT](300.set-thread-count-oracle.md) | 用于设置窗口合并的线程数。|
