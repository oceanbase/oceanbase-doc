# TRIGGER_WINDOW_COMPACTION_PROC

`TRIGGER_WINDOW_COMPACTION_PROC` 子程序用于触发一次窗口合并。

## 语法

```sql
DBMS_DAILY_MAINTENANCE.TRIGGER_WINDOW_COMPACTION_PROC();
```

## 使用说明

该语句仅用于手动开启一次窗口合并，不会指定任务的结束时间，任务结束时间由 [DBMS_SCHEDULER.SET_ATTRIBUTE](../14200.dbms-scheduler-oracle/1100.set-attribute-oracle.md) 子程序中的 `duration` 属性决定。

## 示例

用户租户触发一次窗口合并。

```shell
obclient(sys@oracle001)[SYS]> DBMS_DAILY_MAINTENANCE.TRIGGER_WINDOW_COMPACTION_PROC();
```
