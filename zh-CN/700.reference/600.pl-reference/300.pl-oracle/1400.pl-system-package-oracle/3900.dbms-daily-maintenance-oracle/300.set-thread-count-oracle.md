# SET_THREAD_COUNT

`SET_THREAD_COUNT` 子程序用于设置窗口合并的线程数。

## 语法

```sql
DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT(thread_count INT);
```

## 参数说明

| 参数              | 说明                                            |
|------------------|-----------------------------------------------------|
| thread_count     | 用于设置窗口合并线程数。默认值为 0，表示系统根据租户相关配置自适应计算合并线程数。如果用户手动设置非 0 的值，则系统采用用户设置的值作为窗口合并线程数。|

## 使用说明

* 仅允许用户租户发起，系统租户（`sys` 租户）不支持。

* 窗口合并期间：

  * 对于已开启 cgroup 的集群，其合并线程数不受租户级配置项 `compaction_low_thread_score` 控制，只能通过 `DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT` 子程序中的 `thread_count` 进行设置。

  * 对于未开启 cgroup 的集群，如果用户修改了 <code>DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT</code> 子程序中 <code>thread_count</code> 的值（非默认值 0），则窗口合并期间，其合并线程数以 <code>thread_count</code> 的值为准；否则，合并线程数以租户级配置项 <a href="../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/1100.compaction_low_thread_score.md">compaction_low_thread_score</a> 的值为准。

  * 无论集群是否开启 cgroup，窗口合并期间，如果要调整窗口合并线程数，只能通过 <code>DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT</code> 子程序中的 <code>thread_count</code> 进行设置。

## 示例

* 设置窗口合并的线程数为 10。

  ```shell
  obclient(sys@oracle001)[SYS]> CALL DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT(10);
  ```

* 将窗口合并的线程数设置为系统自适应计算的值。

  ```shell
  obclient(sys@oracle001)[SYS]> CALL DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT(0);
  ```
