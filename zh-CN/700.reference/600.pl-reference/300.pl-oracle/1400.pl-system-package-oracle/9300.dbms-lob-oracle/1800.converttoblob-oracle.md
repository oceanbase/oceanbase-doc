# CONVERTTOBLOB

`CONVERTTOBLOB` 存储过程用于将源 `CLOB` 的字符数据转换为二进制数据并写入目标 `BLOB`。该过程根据指定的字符集 ID 将字符数据编码为二进制格式，适用于加密、压缩或需要二进制格式的网络传输等场景。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

## 语法

```sql
DBMS_LOB.CONVERTTOBLOB (
  dest_lob      IN OUT NOCOPY BLOB,
  src_clob      IN            CLOB CHARACTER SET ANY_CS,
  amount        IN            INTEGER,
  dest_offset   IN            INTEGER DEFAULT 1,
  src_offset    IN            INTEGER DEFAULT 1,
  blob_csid     IN            INTEGER,
  lang_context  IN OUT        INTEGER,
  warning       OUT           INTEGER);
```

## 参数解释

|     参数      |                   解释                    |
|-------------|-----------------------------------------|
| dest_lob    | 目标 `BLOB` 定位器，转换后的二进制数据将写入此处。需为可写 `LOB`。 |
| src_clob    | 源 `CLOB` 定位器，包含待转换的字符数据。 |
| amount      | 要转换的字符数。可使用 `DBMS_LOB.LOBMAXSIZE` 表示转换整个 `LOB`。 |
| dest_offset | 目标 `BLOB` 中写入的起始位置（以字节为单位，原点为 1）。默认值为 1。 |
| src_offset  | 源 `CLOB` 中读取的起始位置（以字符为单位，原点为 1）。默认值为 1。 |
| blob_csid   | 目标 `BLOB` 的字符集 ID，决定字符数据如何编码为二进制格式。 |
| lang_context | 字符集转换的内部语言上下文参数。首次调用前需初始化为默认值。 |
| warning     | 输出参数，用于返回警告信息（如数据截断等）。 |

## 异常情况

|        异常         |            描述           |
|-------------------|-------------------------------|
| VALUE_ERROR       | 任何输入参数均为 `NULL` 或无效。  |
| INVALID_ARGVAL    | 发生以下某种情况：<ul><li>`dest_offset` 或 `src_offset` 小于 1</li><li>`amount` 小于 1</li><li>`amount` 超出源 `CLOB` 中可用字符数</li></ul> |
| QUERY_WRITE       | 无法在查询中执行 `LOB` 写入。   |
| NOT_SUPPORTED     | 不支持对临时 Delta 类型 `LOB` 执行 `CONVERTTOBLOB`；或目标 `LOB` 为只读时无法修改。 |

## 使用说明

* 如果目标 `BLOB` 中指定的偏移量超出了当前数据的末尾，则将零字节填充符插入。如果偏移量小于目标 `BLOB` 的当前长度，则现有数据将被覆盖。

* 指定 `amount` 为 `DBMS_LOB.LOBMAXSIZE` 表示转换从 `src_offset` 开始到源 `CLOB` 末尾的全部数据。

* 不强制要求将 `LOB` 操作包裹在 Open/Close 接口中。如果在执行操作之前没有打开 `LOB`，则在调用过程中会更新 `LOB` 列上的功能索引和域索引。但是，如果在执行操作之前打开了 `LOB`，则必须在提交事务之前将其关闭。
