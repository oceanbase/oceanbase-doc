# CANCEL_GATHER_STATS

`CANCEL_GATHER_STATS` 用于取消统计信息收集命令。

## 语法

```sql
DBMS_STATS.cancel_gather_stats (
      taskid         VARCHAR2
    );
```

## 参数解释

|    参数    |        解释         |
|----------|-----------------------|
|taskid|表示正在收集任务的 ID。|

## 示例

```sql
obclient> CALL DBMS_STATS.CANCEL_GATHER_STATS(65565);
Query OK, 0 rows affected
```
