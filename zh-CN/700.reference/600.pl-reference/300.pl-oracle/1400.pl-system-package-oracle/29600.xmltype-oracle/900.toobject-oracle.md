# TOOBJECT

`TOOBJECT` 成员过程用于将 `XMLType` 实例中的 XML 内容映射到 PL/SQL 对象实例，即按对象类型结构将 XML 反序列化为 PL/SQL 对象。可与 `DBMS_XMLDOM.GETXMLTYPE` 配合使用：先通过 DOM 构造或解析 XML，再转换为 `XMLType`，最后映射到 PL/SQL 对象。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
MEMBER PROCEDURE toObject(
   SELF IN XMLTYPE,
   object OUT NOCOPY <object_type>);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| SELF | 当前 `XMLType` 实例。 |
| object | 用于接收映射结果的用户自定义对象类型实例（`OUT`）。 |

## 返回值

无返回值；结果写入 `object`。

## 使用说明

* `object` 的对象类型结构需与 XML 内容相匹配；类型不匹配或 XML 非法时按运行时报错处理。
* 调用前需确保目标对象类型已在当前模式中创建。

## 示例

如下示例将一段与对象类型结构对应的 XML 映射到 PL/SQL 对象实例。请将 `SOME_OBJECT_TYPE` 替换为实际对象类型名。

```sql
DECLARE
  x XMLTYPE;
  target_obj SOME_OBJECT_TYPE;
BEGIN
  x := XMLTYPE('<SOME_OBJECT_TYPE><FIELD1>hello</FIELD1></SOME_OBJECT_TYPE>');
  x.toObject(target_obj);
END;
/
```
