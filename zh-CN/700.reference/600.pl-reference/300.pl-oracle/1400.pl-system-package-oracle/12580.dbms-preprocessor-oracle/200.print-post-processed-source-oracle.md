# PRINT_POST_PROCESSED_SOURCE

`PRINT_POST_PROCESSED_SOURCE` 过程用于打印经过条件编译处理后的 PL 源代码。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

`PRINT_POST_PROCESSED_SOURCE` 过程支持以下三种重载形式：

### 通过对象类型、模式名和对象名获取

```sql
DBMS_PREPROCESSOR.PRINT_POST_PROCESSED_SOURCE(
    object_type  VARCHAR2,
    schema_name  VARCHAR2,
    object_name  VARCHAR2);
```

### 通过源代码字符串获取

```sql
DBMS_PREPROCESSOR.PRINT_POST_PROCESSED_SOURCE(
    source  VARCHAR2);
```

### 通过源代码集合获取

```sql
DBMS_PREPROCESSOR.PRINT_POST_PROCESSED_SOURCE(
    source  source_lines_t);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| object_type | 要处理的 PL 对象类型。支持的类型包括：`PACKAGE`、`PACKAGE BODY`、`PROCEDURE`、`FUNCTION`、`TRIGGER`、`TYPE`、`TYPE BODY`。 |
| schema_name | 对象所属的模式名称。如果为 `NULL`，则使用当前模式。 |
| object_name | 对象名称。 |
| source | PL 源代码字符串或 `source_lines_t` 集合。 |

## 使用说明

* `PRINT_POST_PROCESSED_SOURCE` 过程调用 `GET_POST_PROCESSED_SOURCE` 函数获取后处理源码后，通过 `DBMS_OUTPUT.PUT_LINE` 逐行打印输出。
* 在使用通过对象类型、模式名和对象名的重载形式时，需确保指定的对象在数据库中存在且类型匹配。
* 通过源代码集合的重载形式当前暂不支持。

## 示例

```sql
DECLARE
  source VARCHAR2(32767);
BEGIN
  source := 'CREATE OR REPLACE PACKAGE my_pkg IS
  $IF DBMS_DB_VERSION.VER_LE_21 $THEN
    SUBTYPE my_type IS NUMBER;
  $ELSE
    SUBTYPE my_type IS VARCHAR2(100);
  $END
  PROCEDURE p;
END;';
  DBMS_PREPROCESSOR.PRINT_POST_PROCESSED_SOURCE(source);
END;
/
```
