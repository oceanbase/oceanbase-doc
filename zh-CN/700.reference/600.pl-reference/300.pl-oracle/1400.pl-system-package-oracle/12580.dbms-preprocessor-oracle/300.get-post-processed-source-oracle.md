# GET_POST_PROCESSED_SOURCE

`GET_POST_PROCESSED_SOURCE` 函数用于获取经过条件编译处理后的 PL 源代码，返回 `source_lines_t` 集合类型。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

`GET_POST_PROCESSED_SOURCE` 函数支持以下三种重载形式：

### 通过对象类型、模式名和对象名获取

```sql
DBMS_PREPROCESSOR.GET_POST_PROCESSED_SOURCE(
    object_type  VARCHAR2,
    schema_name  VARCHAR2,
    object_name  VARCHAR2)
RETURN source_lines_t;
```

### 通过源代码字符串获取

```sql
DBMS_PREPROCESSOR.GET_POST_PROCESSED_SOURCE(
    source  VARCHAR2)
RETURN source_lines_t;
```

### 通过源代码集合获取

```sql
DBMS_PREPROCESSOR.GET_POST_PROCESSED_SOURCE(
    source  source_lines_t)
RETURN source_lines_t;
```

## 参数说明

| 参数 | 说明 |
|------|------|
| object_type | 要处理的 PL 对象类型。支持的类型包括：`PACKAGE`、`PACKAGE BODY`、`PROCEDURE`、`FUNCTION`、`TRIGGER`、`TYPE`、`TYPE BODY`。 |
| schema_name | 对象所属的模式名称。如果为 `NULL`，则使用当前模式。 |
| object_name | 对象名称。 |
| source | PL 源代码字符串或 `source_lines_t` 集合。 |

## 返回值

返回 `source_lines_t` 集合类型，定义如下：

```sql
TYPE source_lines_t IS
  TABLE OF VARCHAR2(32767) INDEX BY BINARY_INTEGER;
```

## 使用说明

* 通过对象类型、模式名和对象名的重载形式从数据库字典中获取 PL 对象的源码并进行预处理。
* 通过源代码字符串的重载形式直接对传入的字符串进行预处理。
* 结果中的每一行对应一行预处理后的源代码。
* 通过源代码集合的重载形式当前暂不支持。

## 示例

```sql
DECLARE
  result DBMS_PREPROCESSOR.source_lines_t;
  i      BINARY_INTEGER;
BEGIN
  result := DBMS_PREPROCESSOR.GET_POST_PROCESSED_SOURCE(
    'CREATE OR REPLACE PACKAGE my_pkg IS
  $IF DBMS_DB_VERSION.VER_LE_21 $THEN
    SUBTYPE my_type IS NUMBER;
  $ELSE
    SUBTYPE my_type IS VARCHAR2(100);
  $END
  PROCEDURE p;
END;');
  i := result.FIRST;
  WHILE i IS NOT NULL LOOP
    DBMS_OUTPUT.PUT_LINE(result(i));
    i := result.NEXT(i);
  END LOOP;
END;
/
```
