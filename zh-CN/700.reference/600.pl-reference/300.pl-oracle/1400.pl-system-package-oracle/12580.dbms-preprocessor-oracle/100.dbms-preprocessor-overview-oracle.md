# DBMS_PREPROCESSOR 概述

`DBMS_PREPROCESSOR` 系统包提供对 PL 源代码进行预处理的功能。您可以通过该包获取或打印经过条件编译处理后的 PL 源代码。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## DBMS_PREPROCESSOR 使用说明

`DBMS_PREPROCESSOR` 系统包支持对以下类型的 PL 对象进行预处理：`PACKAGE`、`PACKAGE BODY`、`PROCEDURE`、`FUNCTION`、`TRIGGER`、`TYPE`、`TYPE BODY`。

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_PREPROCESSOR` 子程序以及简要描述。

| [PRINT_POST_PROCESSED_SOURCE](200.print-post-processed-source-oracle.md) | 打印经过条件编译处理后的 PL 源代码。 |
