# DISPLAY_PROFILE

`auto_refresh_external_table` 用于展示 SQL 执行计划的性能分析数据。可查看指定 Trace 的聚合或线程级性能指标，辅助定位执行瓶颈。

## 语法

```sql
DBMS_XPROFILE.DISPLAY_PROFILE(
    trace_id    varchar2 default null,
    tenant_id   integer default 0,
    format      varchar2 default 'AGGREGATED',
    level       integer default 1,
    svr_ip      varchar2 default null,
    svr_port    integer default 0,
    op_id       integer default null
    )
```

## 参数说明

| **参数**  | **说明** |
|-----------|----------|
| trace_id  | 可选项，表示 trace id。默认会自动选择 last trace id。|
| tenant_id | 可选项，表示租户 ID。默认选择当前租户 ID，在系统租户查其他租户时使用，需要指定。|
| format    | 可选项，表示展示形式。取值如下：<ul><li>`AGGREGATED`：默认值，表示展示聚合后的 profile。</li><li>`ORIGINAL`：表示输出聚合前的线程级 profile。</li></ul>|
| level     | 可选项，表示展示等级。可取值：0、1 或 2，默认值为 1。每个指标都有各自的等级，低于 level 的指标将不会展示出来。|
| svr_ip    | 可选项，筛选只显示某个 IP 上的 profile。默认值为 `null`，表示全输出。|
| svr_port  | 可选项，筛选只显示某个 port 上的 profile。默认值为 0，表示全输出。|
| op_id     | 可选项，筛选只展示计划中编号为 ID 的算子的 profile。默认值为 `null`，表示全输出。|

## 示例

* sys 租户中查看其他租户的 profile。

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC2E689814-0-0', tenant_id);
    ```

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>只有 sys 租户才能查其他租户的 profile, 必须要指定 <code>tenant_id</code>。</p>
    </main>

* 用户租户（Oracle 模式）查询自己的 profile。

    ```shell
    obclient> SELECT * FROM TABLE(DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC2E689814-0-0'));
    ```
