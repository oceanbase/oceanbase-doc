# DBMS_PLSQL_CODE_COVERAGE 概述

`DBMS_PLSQL_CODE_COVERAGE` 系统包用于收集 PL/SQL 代码在运行时的覆盖率。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 V4.4.1 版本开始支持。</code>。</p>
</main>

## DBMS_PLSQL_CODE_COVERAGE 权限说明

该系统包权限为 `AUTHID CURRENT_USER`。

## 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_PLSQL_CODE_COVERAGE` 子程序和简要描述。

|                                   子程序                                 |           描述          |
|--------------------------------------------------------------------------|------------------------|
|[START_COVERAGE](200.start-coverage-oracle-mode.md)|用于启动覆盖率统计，启动后会记录当前 session 上 PL 的覆盖率情况。|
|[STOP_COVERAGE](300.stop-coverage-oracle-mode.md)|用于关闭覆盖率统计，关闭后将结果汇总到数据统计表。|
|[CREATE_COVERAGE_TABLES](400.create-coverage-oracle-mode.md)|用于创建 `DBMSPCC_RUNS`、`DBMSPCC_UNITS` 和 `DBMSPCC_BLOCKS` 三张覆盖率信息统计表。|
