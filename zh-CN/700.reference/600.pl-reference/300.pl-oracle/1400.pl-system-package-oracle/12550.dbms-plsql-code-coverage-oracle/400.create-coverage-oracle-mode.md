# CREATE_COVERAGE_TABLES

`CREATE_COVERAGE_TABLES` 用于创建 `DBMSPCC_RUNS`、`DBMSPCC_UNITS` 和 `DBMSPCC_BLOCKS` 三张覆盖率信息统计表。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包子程序从 V4.4.1 版本开始支持。</code>。</p>
</main>

## 语法

```sql
DBMS_PLSQL_CODE_COVERAGE.CREATE_COVERAGE_TABLES (
   FORCE_IT     IN BOOLEAN DEFAULT FALSE);
```

## 参数解释

|      参数      |   说明     |
|----------------|-----------|
|FORCE_IT|如果覆盖表已存在，则默认抛出错误。如果设置为 `TRUE`，则如果表已存在，则会静默删除该表，并创建新表。|

## 示例

创建覆盖率信息表:

```sql
BEGIN
  DBMS_PLSQL_CODE_COVERAGE.create_coverage_tables(true);
END;
/
```
