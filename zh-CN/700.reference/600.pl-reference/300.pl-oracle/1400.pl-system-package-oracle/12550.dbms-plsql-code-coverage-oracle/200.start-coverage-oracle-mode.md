# START_COVERAGE

`START_COVERAGE` 用于启动覆盖率统计，启动后会记录当前 session 上 PL 的覆盖率情况。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包子程序从 V4.4.1 版本开始支持。</code>。</p>
</main>

## 语法

```sql
DBMS_PLSQL_CODE_COVERAGE.START_COVERAGE (
   run_comment   IN VARCHAR2) 
   RETURN NUMBER;
```

## 参数解释

|      参数      |   说明     |
|----------------|-----------|
|run_comment|表示此次代码覆盖率运行任务的注释或描述信息。|

## 示例

开始收集覆盖率信息:

```sql
BEGIN
  l_run_id := DBMS_PLSQL_CODE_COVERAGE.start_coverage('TEST_RUN_1');
END;
/
```
