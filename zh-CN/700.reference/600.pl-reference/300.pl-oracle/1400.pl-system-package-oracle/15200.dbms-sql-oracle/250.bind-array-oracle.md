# BIND_ARRAY

`BIND_ARRAY` 存储过程用于将一个 PL/SQL 集合绑定到动态 SQL 语句的占位符。

与 `BIND_VARIABLE` 每次只为一个占位符绑定一个值不同，`BIND_ARRAY` 绑定的是整个集合。调用 `EXECUTE` 执行语句时，OceanBase 数据库会按集合元素逐轮执行语句，从而减少 SQL 执行次数。

从 V4.4.2 BP4 版本开始，OceanBase 数据库支持 `BIND_ARRAY` 存储过程。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
  </main>

## 语法

```sql
DBMS_SQL.BIND_ARRAY(
  c           IN INTEGER,
  name        IN VARCHAR2,
  table_value IN <table_type>,
  index1      IN INTEGER DEFAULT 1,
  index2      IN INTEGER DEFAULT -1);
```

其中 `table_value` 及其对应的 `<table_type>` 可以是以下匹配对，`BIND_ARRAY` 被重载以接受不同的集合类型：

```sql
<table_value>     <table_type>
n_tab             Number_Table
c_tab             Varchar2_Table
d_tab             Date_Table
bl_tab            Blob_Table
cl_tab            Clob_Table
bf_tab            Binary_Float_Table
bd_tab            Binary_Double_Table
```

## 参数解释

|   **参数**   |               **解释**                |
|------------|-------------------------------------|
| c          | 要绑定集合的游标 ID 号。                      |
| name       | 语句中占位符的名称，名称中可以包含前导冒号（`:`）。          |
| table_value | 要绑定的 PL/SQL 集合变量。                    |
| index1     | 绑定的起始下标。不指定 `index1` 和 `index2` 时，绑定整个集合。   |
| index2     | 绑定的结束下标。不指定 `index1` 和 `index2` 时，绑定整个集合。   |

## 使用说明

* 支持的集合类型包括 `Number_Table`、`Varchar2_Table`、`Date_Table`、`Blob_Table`、`Clob_Table`、`Binary_Float_Table` 和 `Binary_Double_Table`，集合本身可以是关联数组、嵌套表（Nested Table）或 VARRAY。

* `index1` 和 `index2` 必须同时指定或同时省略。同时省略时绑定集合的全部元素；同时指定时，只绑定下标在 `[index1, index2]` 区间内的元素。对于关联数组，被 `DELETE` 删除的元素不参与绑定。

* `index1` 和 `index2` 超出集合元素的下标范围时，报错 `ORA-06532`。

* 同一个占位符只能绑定一次。对同一个占位符重复调用 `BIND_ARRAY` 或 `BIND_VARIABLE` 时，后一次绑定会覆盖前一次绑定。

* 同一个游标中可以混用 `BIND_VARIABLE` 和 `BIND_ARRAY`，此时标量绑定的值在每一轮执行中重复使用。

* 语句的迭代次数为所有数组绑定参与绑定的元素个数的最小值。例如，同时绑定 3 个元素的 `:id` 和 2 个元素的 `:name`，`EXECUTE` 只执行 2 轮。

* `EXECUTE` 返回所有轮次影响行数的总和。

* 如果参与绑定的集合为空且语句中包含 `RETURNING INTO` 子句，则语句执行一次；如果语句中不包含 `RETURNING INTO` 子句，则报错 `ORA-06532`。

* `RETURNING INTO` 的输出占位符也需要通过 `BIND_ARRAY` 绑定一个同类型的空集合占位。`EXECUTE` 执行完成后，通过 `VARIABLE_VALUE` 取回所有返回行，返回的行数可能少于输入集合的元素个数。

## 示例

创建测试表 `t_bind_array_demo`。

```sql
CREATE TABLE t_bind_array_demo (id NUMBER, name VARCHAR2(20));
```

示例 1：使用 `Number_Table` 和 `Varchar2_Table` 批量插入 3 行数据，`EXECUTE` 返回影响的总行数。

```sql
DECLARE
  c INTEGER;
  v_ids DBMS_SQL.NUMBER_TABLE;
  v_names DBMS_SQL.VARCHAR2_TABLE;
  ret INTEGER;
BEGIN
  c := DBMS_SQL.OPEN_CURSOR;
  DBMS_SQL.PARSE(c, 'INSERT INTO t_bind_array_demo(id, name) VALUES(:id, :name)', DBMS_SQL.NATIVE);

  v_ids(1) := 1;
  v_ids(2) := 2;
  v_ids(3) := 3;
  v_names(1) := 'a';
  v_names(2) := 'b';
  v_names(3) := 'c';

  DBMS_SQL.BIND_ARRAY(c, ':id', v_ids);
  DBMS_SQL.BIND_ARRAY(c, ':name', v_names);

  ret := DBMS_SQL.EXECUTE(c);
  DBMS_OUTPUT.PUT_LINE('affected rows: ' || ret);

  DBMS_SQL.CLOSE_CURSOR(c);
END;
/
```

示例 2：使用 `index1` 和 `index2` 只绑定集合中下标为 2 到 3 的元素。

```sql
DECLARE
  c INTEGER;
  v_ids DBMS_SQL.NUMBER_TABLE;
  ret INTEGER;
BEGIN
  c := DBMS_SQL.OPEN_CURSOR;
  DBMS_SQL.PARSE(c, 'UPDATE t_bind_array_demo SET name = ''updated'' WHERE id = :id', DBMS_SQL.NATIVE);

  v_ids(1) := 1;
  v_ids(2) := 2;
  v_ids(3) := 3;
  v_ids(4) := 4;

  DBMS_SQL.BIND_ARRAY(c, ':id', v_ids, 2, 3);

  ret := DBMS_SQL.EXECUTE(c);
  DBMS_OUTPUT.PUT_LINE('affected rows: ' || ret);

  DBMS_SQL.CLOSE_CURSOR(c);
END;
/
```

示例 3：批量执行带 `RETURNING INTO` 子句的 `DELETE` 语句，并通过 `VARIABLE_VALUE` 取回删除的行。

```sql
DECLARE
  c INTEGER;
  v_ids DBMS_SQL.NUMBER_TABLE;
  v_deleted DBMS_SQL.NUMBER_TABLE;
  ret INTEGER;
BEGIN
  c := DBMS_SQL.OPEN_CURSOR;
  DBMS_SQL.PARSE(c, 'DELETE FROM t_bind_array_demo WHERE id = :id RETURNING id INTO :out_id', DBMS_SQL.NATIVE);

  v_ids(1) := 1;
  v_ids(2) := 2;

  DBMS_SQL.BIND_ARRAY(c, ':id', v_ids);
  DBMS_SQL.BIND_ARRAY(c, ':out_id', v_deleted);

  ret := DBMS_SQL.EXECUTE(c);
  DBMS_SQL.VARIABLE_VALUE(c, ':out_id', v_deleted);

  FOR i IN v_deleted.FIRST .. v_deleted.LAST LOOP
    DBMS_OUTPUT.PUT_LINE('deleted id: ' || v_deleted(i));
  END LOOP;

  DBMS_SQL.CLOSE_CURSOR(c);
END;
/
```

查询表中的数据，确认批量操作的结果。

```sql
SELECT * FROM t_bind_array_demo ORDER BY id;
```

删除测试表。

```sql
DROP TABLE t_bind_array_demo;
```
