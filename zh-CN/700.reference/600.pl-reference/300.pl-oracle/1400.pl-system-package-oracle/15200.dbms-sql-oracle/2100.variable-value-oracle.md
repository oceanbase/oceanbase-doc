# VARIABLE_VALUE

`VARIABLE_VALUE` 储过程用于在执行动态 SQL 语句后，获取输出变量的值。

## 语法

```sql
DBMS_SQL.VARIABLE_VALUE(  
  cursor      IN  NUMBER,  
  variable    IN  VARCHAR2,  
  value       OUT value_type  
);   
```

## 参数解释

|    **参数**     |           **解释**            |
|---------------|-----------------------------|
|cursor|已打开的动态 SQL 游标 ID。|
|variable|需要获取的变量名称。|
|value|存储返回值的目标变量。|

## 使用示例

```sql
DECLARE  
  DBMS_SQL.VARIABLE_VALUE(cursor_id, ':r', result);  
END;  
```
