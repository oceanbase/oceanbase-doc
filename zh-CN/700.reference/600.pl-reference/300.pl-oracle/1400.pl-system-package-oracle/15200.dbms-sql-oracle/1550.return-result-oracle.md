# RETURN_RESULT

`RETURN_RESULT` 存储过程用于将指定游标的结果集直接返回给客户端，调用方无需再通过 `FETCH_ROWS`、`COLUMN_VALUE` 等子程序逐行获取数据。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，从 V4.4.2.3 hotfix1 版本开始支持 <code>RETURN_RESULT</code> 子程序。</p>
</main>

## 使用限制及注意事项

* 仅 Oracle 模式支持该子程序。
* `cursor_number` 指 `DBMS_SQL.OPEN_CURSOR` 子程序返回的整型游标 ID（登记在会话的 DBMS_SQL 游标表中），不是 PL/SQL 中声明的游标变量；`SYS_REFCURSOR` 类型的游标请使用第二个重载。
* 参数 `cursor_number` 和 `rc` 均为 `IN OUT` 模式，调用时需传入变量，不能直接传入字面量或其他常量。
* `to_client` 参数当前仅支持 `TRUE`。指定为 `FALSE` 时会报不支持错误（错误码 `-4007`），提示 `DBMS_SQL.RETURN_RESULT with to_client => FALSE` 不支持。
* 传入无效的游标 ID（不是 `DBMS_SQL.OPEN_CURSOR` 返回的游标 ID）时报错 `ORA-29471`（`DBMS_SQL access denied`）。
* 使用 `cursor_number` 重载时，游标必须是已完成 `PARSE`（`SELECT` 语句）、`EXECUTE` 且结果尚未取尽的游标，否则报错 `ORA-01001`（`invalid cursor`）。
* 使用 `SYS_REFCURSOR` 重载时，`rc` 必须是已 `OPEN` 的游标，否则报错 `ORA-01001`（`invalid cursor`）。
* 一个存储过程中可以多次调用 `RETURN_RESULT`，多个结果集按调用顺序依次返回给客户端。
* 结果集发送完成后，该子程序会关闭游标的结果集，但不释放游标 ID。通过 `DBMS_SQL.OPEN_CURSOR` 打开的游标 ID 仍需调用 `DBMS_SQL.CLOSE_CURSOR` 释放。

## 语法

```sql
DBMS_SQL.RETURN_RESULT(
    cursor_number  IN OUT INTEGER,
    to_client      IN     BOOLEAN DEFAULT TRUE);

DBMS_SQL.RETURN_RESULT(
    rc             IN OUT SYS_REFCURSOR,
    to_client      IN     BOOLEAN DEFAULT TRUE);
```

## 参数解释

|  **参数**  | **说明** |
|------------|----------|
| cursor_number | 通过 `DBMS_SQL.OPEN_CURSOR` 打开、且已执行过 `SELECT` 语句的游标 ID。 |
| rc | 已通过 `OPEN ... FOR` 打开的 `SYS_REFCURSOR` 变量。 |
| to_client | 是否将结果集返回给客户端。默认值为 `TRUE`，当前仅支持 `TRUE`。 |

## 示例

### 示例 1：通过 cursor_number 返回结果集

创建测试表并插入数据。

```sql
obclient> CREATE TABLE return_result_tbl (id NUMBER, name VARCHAR2(20));
obclient> INSERT INTO return_result_tbl VALUES (1, 'one');
obclient> INSERT INTO return_result_tbl VALUES (2, 'two');
obclient> INSERT INTO return_result_tbl VALUES (3, 'three');
```

创建存储过程 `return_result_proc`，在动态 SQL 游标上调用 `RETURN_RESULT`。

```sql
obclient> CREATE OR REPLACE PROCEDURE return_result_proc IS
  cur_id  INTEGER;
  rows    INTEGER;
BEGIN
  cur_id := DBMS_SQL.OPEN_CURSOR;
  DBMS_SQL.PARSE(cur_id, 'SELECT id, name FROM return_result_tbl ORDER BY id', DBMS_SQL.NATIVE);
  rows := DBMS_SQL.EXECUTE(cur_id);
  DBMS_SQL.RETURN_RESULT(cur_id);
END;
/
```

调用存储过程，客户端直接收到结果集。

```sql
obclient> CALL return_result_proc();
```

返回结果如下：

```sql
+------+-------+
| ID   | NAME  |
+------+-------+
|    1 | one   |
|    2 | two   |
|    3 | three |
+------+-------+
3 rows in set
```

### 示例 2：通过 SYS_REFCURSOR 返回结果集

创建存储过程 `return_result_ref_proc`，通过 `SYS_REFCURSOR` 返回结果集。

```sql
obclient> CREATE OR REPLACE PROCEDURE return_result_ref_proc IS
  rc  SYS_REFCURSOR;
BEGIN
  OPEN rc FOR SELECT id FROM return_result_tbl WHERE id = 1;
  DBMS_SQL.RETURN_RESULT(rc);
END;
/
```

调用存储过程。

```sql
obclient> CALL return_result_ref_proc();
```

客户端收到如下结果集：

```sql
+------+
| ID   |
+------+
|    1 |
+------+
1 row in set
```

同一个存储过程中可以多次调用 `RETURN_RESULT`，多个结果集按调用顺序依次返回给客户端。
