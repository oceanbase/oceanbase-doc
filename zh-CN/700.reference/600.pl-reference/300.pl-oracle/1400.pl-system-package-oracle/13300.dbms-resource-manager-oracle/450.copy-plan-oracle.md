# COPY_PLAN

`COPY_PLAN` 子程序用于复制已有资源管理计划及其相关的资源计划指令。

## 语法

```sql
DBMS_RESOURCE_MANAGER.COPY_PLAN (
    source_plan IN VARCHAR2,
    target_plan IN VARCHAR2,
    comment     IN VARCHAR2 DEFAULT '');
```

## 参数说明

|        参数        |           说明          |
|-------------------|--------------------------|
| source_plan       | 源资源计划的名称 |
| target_plan       | 复制后的目标资源计划名称，目标资源计划不能是租户下已存在的资源计划。 |
| comment           | 用户注释 |

## 示例

假设已创建名为 `SOURCE_PLAN` 和 `TARGET_PLAN` 的资源计划，将 `SOURCE_PLAN` 及其对应的资源计划指令复制到资源计划 `TARGET_PLAN` 中。

```shell
obclient(sys@oracle001)[SYS]> CALL DBMS_RESOURCE_MANAGER.COPY_PLAN(
  SOURCE_PLAN => 'SOURCE_PLAN',
  TARGET_PLAN => 'TARGET_PLAN');
```
