# IS_ROLE_ENABLED

`IS_ROLE_ENABLED` 用于确定会话是否启用了指定的角色。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V4.4.1 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_SESSION.IS_ROLE_ENABLED (
   rolename    VARCHAR2) 
  RETURN BOOLEAN;
```

## 参数说明

`rolename` 表示角色的名称。返回 `TRUE` 表示该角色已启用，返回 `FALSE` 表示该角色未启用。

## 示例

```sql
BEGIN
  IF DBMS_SESSION.IS_ROLE_ENABLED('DBA') THEN
    DBMS_OUTPUT.PUT_LINE('角色 DBA 已激活');
  ELSE
    DBMS_OUTPUT.PUT_LINE('角色 DBA 未激活');
  END IF;
END;
/
```
