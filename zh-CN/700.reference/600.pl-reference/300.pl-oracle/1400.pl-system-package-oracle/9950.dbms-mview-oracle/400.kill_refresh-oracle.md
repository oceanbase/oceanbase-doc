# KILL_REFRESH

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，从 V4.4.2 BP2 版本开始引入 <code>KILL_REFRESH</code>。</p>
</main>

`KILL_REFRESH` 用于主动终止由新调度框架管理的、当前仍处于执行中的物化视图刷新批次。

## 功能描述

调用 `DBMS_MVIEW.KILL_REFRESH(refresh_id)` 后，系统将对指定 `refresh_id` 对应的刷新批次执行以下操作：

* 标记 `PENDING` 状态的任务为 `CANCELLED`：所有尚未被调度执行的任务将立即被取消，不再进入调度队列。
* 终止 `RUNNING` 状态的任务：对于正在执行的任务，系统将定位其执行 Session，并向其发起 `kill` 操作，强制中断其执行流程。
* 状态收敛处理：被 `kill` 的任务最终状态标记为 `CANCELLED`。
* 终态任务不受影响：已成功完成（`SUCCESS`）、失败（`FAILED`）或已被取消（`CANCELLED`）的任务不会受到此次终止操作的影响。

## 语法

```sql
DBMS_MVIEW.KILL_REFRESH(refresh_id)
```

## 参数解释

|  **参数**  | **说明** |
|------------|----------|
| refresh_id | 指定物化视图刷新批次的唯一标识符，由新调度框架分配。 <main id="notice" type='explain'><h4>说明</h4><p>可以通过视图 <a href="../../../../700.system-views/500.system-view-of-oracle-mode/200.dictionary-view-of-oracle-mode/9600.dba_mvref_run_stats-of-oracle-mode.md">DBA_MVREF_RUN_STATS</a> 查看 <code>refresh_id</code> 信息。</p></main>|

## 示例

终止 `refresh_id` 为 100023 的物化视图刷新。

```shell
obclient> CALL DBMS_MVIEW.KILL_REFRESH(100023);
```
