# DBMS_JAVA 概述

`DBMS_JAVA` 用于在数据库内集成和管理 Java 程序，支持 Java 存储过程、函数及安全策略的实现。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 OceanBase 数据库 V4.4.0 版本开始引入。</p>
</main>

## DBMS_JAVA 权限说明

出于安全原因，禁止 `DBMS_JAVA` 访问本地文件、网络等高危操作。

## DBMS_JAVA 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_JAVA` 子程序以及简要描述。

|                **子程序**             |                 **描述**                       |
|-----------------------------------------|------------------------------------------------|
| [LOADJAVA](100.dbms-java-overview.md) | 用于将 Jar 包作为外部资源上传到 OBServer。 |
| [DROPJAVA](200.loadjava-oracle.md) | 用于删除上传的外部资源 Jar 包。|
