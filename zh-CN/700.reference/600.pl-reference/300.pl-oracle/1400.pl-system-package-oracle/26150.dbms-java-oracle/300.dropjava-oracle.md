# DROPJAVA

`DBMS_JAVA.DROPJAVA` 用于删除上传的外部资源 Jar 包。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 OceanBase 数据库 V4.4.0 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_JAVA.DROPJAVA('options');
```

## 参数解释

* `options` 为字符串参数，支持以下关键选项：

  * `class <class_name>`：指定要删除的Java类名（全限定名）。
  * `file <file_name>`：通过文件名删除（支持.java、.class、.jar等）。
  * `user <username/password>`：数据库认证信息（若未指定，使用当前会话用户）。
  * `schema <schema_name>`：指定目标模式（默认为当前用户）38。
  * `resolve`：在删除前尝试解析依赖（可选）。

## 示例

执行如下命令删除上传的外部资源 Jar 包：

```shell
obclient> CALL DBMS_JAVA.DROPJAVA('my_add_jar');
```
