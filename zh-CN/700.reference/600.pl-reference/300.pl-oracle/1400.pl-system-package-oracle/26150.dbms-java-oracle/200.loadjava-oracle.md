# LOADJAVA

`DBMS_JAVA.LOADJAVA` 用于将 Jar 包作为外部资源上传到 OBServer。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 OceanBase 数据库 V4.4.0 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_JAVA.LOADJAVA(options_string VARCHAR2);
```

## 参数解释

`options_string`:字符串形式的命令行选项。

## 使用说明

调用 `DBMS_JAVA.LOADJAVA` 系统包将 Jar 包作为外部资源上传到 OBServer。此过程需要接受三个参数：

1. 资源名称，您可以自定义资源名，此资源名不区分大小写，并且在当前 Database 下必须是唯一的。可以通过这个资源名引用此外部资源。
2. 资源的 binary，即 Jar 包的二进制内容。
3. 资源的注释，您可以自定义注释内容。

## 示例

将 `HelloWorld.class` 加载到用户 `scott` 的 `schema`。

```sql
BEGIN
  DBMS_JAVA.LOADJAVA(
    '-user scott/tiger@orcl -resolve -force HelloWorld.class'
  );
END;
```

其中：

* `resolve` 指自动解析依赖类。
* `force` 指覆盖同名类。
