# RECYCLE_SCHEMA_HISTORY

`RECYCLE_SCHEMA_HISTORY` 用于手动对当前租户执行一轮 Schema 多版本历史数据的回收，清理过期的历史记录。Schema 多版本历史数据的过期时间由租户级配置项 `schema_history_expire_time` 控制。

## 使用限制及注意事项

仅用户租户支持手动执行 Schema 多版本历史数据的回收，系统租户不支持手动执行 Schema 多版本历史数据的回收。

## 语法

```sql
DBMS_SCHEMA.RECYCLE_SCHEMA_HISTORY();
```

## 使用说明

系统内置了定时任务 `SCHEDULED_RECYCLE_SCHEMA_HISTORY` 来定期对过期的 Schema 多版本历史数据的回收，默认间隔 10 分钟触发一次。定时任务触发的时间间隔可以通过 `DBMS_SCHEDULER.SET_ATTRIBUTE` 子程序的 `repeat_interval` 属性来进行设置。例如，将定时任务 `SCHEDULED_RECYCLE_SCHEMA_HISTORY` 触发的时间间隔修改为 60 分钟：

```shell
obclient(sys@oracle001)[SYS]> CALL DBMS_SCHEDULER.SET_ATTRIBUTE('SCHEDULED_RECYCLE_SCHEMA_HISTORY', 'repeat_interval', 'FREQ=MINUTELY; INTERVAL=60');
```

当未达到定时任务的执行时间时，用户可手动调用 `DBMS_SCHEMA.RECYCLE_SCHEMA_HISTORY()` 子程序快速执行一轮 Schema 多版本历史数据的回收。

## 示例

用户租户对本租户执行一轮 Schema 多版本历史数据的回收。

```shell
obclient(sys@oracle001)[SYS]> CALL DBMS_SCHEMA.RECYCLE_SCHEMA_HISTORY();
```
