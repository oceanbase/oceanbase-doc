# RUN_INSPECTION

`RUN_INSPECTION` 用于手动对当前租户执行一次 Root Service 自检，验证内部元数据的一致性。检查内容包括以下信息：

* 系统统计信息（sys_stat）的完整性
* 系统参数（sys_param）的完整性
* 系统表 schema 的一致性
* 数据版本（data_version）的正确性

## 使用限制及注意事项

系统租户和用户租户均可以对本租户执行一次 Root Service 自检。

## 语法

```sql
DBMS_SCHEMA.RUN_INSPECTION();
```

## 使用说明

系统内置了定时任务 `SCHEDULED_RUN_INSPECTION` 来定期执行 Root Service 自检，默认间隔时间为 1500 秒。定时任务触发的时间间隔可以通过 `DBMS_SCHEDULER.SET_ATTRIBUTE` 子程序的 `repeat_interval` 属性来进行设置。例如，将定时任务 `SCHEDULED_RUN_INSPECTION` 触发的时间间隔修改为 30 分钟：

```shell
obclient(sys@oracle001)[SYS]> CALL DBMS_SCHEDULER.SET_ATTRIBUTE('SCHEDULED_RUN_INSPECTION', 'repeat_interval', 'FREQ=SECONDLY; INTERVAL=1800');
```

当未达到定时任务的执行时间时，用户可手动调用 `DBMS_SCHEMA.RUN_INSPECTION()` 子程序快速执行一次 Root Service 自检。

## 示例

用户租户对本租户执行一次 Root Service 自检。

```shell
obclient(sys@oracle001)[SYS]> CALL DBMS_SCHEMA.RUN_INSPECTION();
```
