# FGETATTR

`FGETATTR` 存储过程用于读取并返回磁盘文件的属性。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.FGETATTR(
   location     IN VARCHAR2,
   filename     IN VARCHAR2,
   fexists      OUT BOOLEAN,
   file_length  OUT NUMBER,
   block_size   OUT BINARY_INTEGER);
```

## 参数解释

| 参数 | 解释 |
|------|------|
| location | 源文件所在的目录位置，即 `ALL_DIRECTORIES` 视图中的 `DIRECTORY_NAME`（大小写敏感）。 |
| filename | 待检查的文件名。 |
| fexists | 文件是否存在。 |
| file_length | 文件长度，单位为字节。如果文件不存在，则返回 `NULL`。 |
| block_size | 文件系统块大小，单位为字节。如果文件不存在，则返回 `NULL`。 |

## 使用说明

`FGETATTR` 用于在不打开文件的情况下获取文件是否存在、文件大小以及文件系统块大小等信息。`location` 必须是已通过 `CREATE DIRECTORY` 创建且当前用户具有访问权限的目录对象名称。
