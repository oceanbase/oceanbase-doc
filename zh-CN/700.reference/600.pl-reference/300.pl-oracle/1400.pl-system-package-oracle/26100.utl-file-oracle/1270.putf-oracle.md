# PUTF

`PUTF` 存储过程用于按格式串写入到指定的文件中。

<main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.PUTF (
    file   IN FILE_TYPE,
    format IN VARCHAR2,
    arg1   IN VARCHAR2 DEFAULT NULL,
    arg2   IN VARCHAR2 DEFAULT NULL,
    arg3   IN VARCHAR2 DEFAULT NULL,
    arg4   IN VARCHAR2 DEFAULT NULL,
    arg5   IN VARCHAR2 DEFAULT NULL
);
```

## 参数解释

|    参数     |           解释            |
|-----------|-------------------------|
|file|由调用 `FOPEN` 返回的活动文件句柄。|
|format|格式字符串，可包含：<ul><li><code>%s</code>：最多 5 个占位符，按顺序被 argN 参数值替换。<li><code>\n</code>：换行符，可在字符串中多次使用。</li></ul>|
|arg1 至 arg5|最多 5 个可选参数，依次替换 `format` 中的 `%s`。若参数少于占位符，未被替换的 `%s` 将保持原样或忽略。|
