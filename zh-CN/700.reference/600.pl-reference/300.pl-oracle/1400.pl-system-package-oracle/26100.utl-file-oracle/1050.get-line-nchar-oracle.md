# GET_LINE_NCHAR

`GET_LINE_NCHAR` 用于以 `Unicode` 方式从文本文件中读取一行内容。

 <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.GET_LINE_NCHAR (
    file    IN  UTL_FILE.FILE_TYPE,
    buffer  OUT NVARCHAR2,
    len     IN  PLS_INTEGER DEFAULT NULL
);
```

## 参数解释

|   参数   |                        解释                        |
|--------|--------------------------------------------------|
| file   | 读取文件的文件句柄。该文件至少需要以 `r` 的方式被打开。                   |
| buffer | 用来保存读取到的数据的输出参数。用户要确保这个字符串的长度要大于另外一个参数 `len`。    |
| len    | 读取的数据字节数，如果不指定，系统会按照打开文件时的参数 `max_linesize` 来指定。 |

## 使用说明

* 每次调用读取一行，从当前文件指针位置开始，直到遇到行终止符（操作系统决定，如 \n 或 \r\n）或文件结束为止。
* 读取的内容不包含行终止符本身。
* 读取后，文件指针会自动移动到下一行的开头。
