# FCOPY

`FCOPY` 用于从源文件复制第 `start_line` 行到 `end_line` 行（含）到目标文件。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.FCOPY (
    src_location   IN VARCHAR2,
    src_filename   IN VARCHAR2,
    dest_location  IN VARCHAR2,
    dest_filename  IN VARCHAR2,
    start_line     IN BINARY_INTEGER DEFAULT 1,
    end_line       IN BINARY_INTEGER DEFAULT NULL
);
```

## 参数解释

|  参数  |                   描述                   |
|------|----------------------------------------|
|src_location|源文件所在的目录别名。|
|src_filename|要复制的源文件的名称。|
|dest_location|目标文件所在的目录别名。|
|dest_filename|要创建或覆盖的目标文件的名称。|
|start_line|指定从源文件的第几行开始复制，默认为 `1`。|
|end_line|指定复制到源文件的第几行结束。|
