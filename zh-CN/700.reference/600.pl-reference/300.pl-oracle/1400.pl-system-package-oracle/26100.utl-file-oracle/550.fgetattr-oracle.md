# FGETATTR

`FGETATTR` 用于读取操作系统文件属性（如是否存在、大小等）的过程。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.FGETATTR (
    location     IN  VARCHAR2,
    filename     IN  VARCHAR2,
    fexists      OUT BOOLEAN,
    file_length  OUT NUMBER,
    block_size   OUT BINARY_INTEGER
);
```

## 参数解释

|  参数  |                   解释                   |
|------|----------------------------------------|
|location|文件所在的目录路径或已定义的目录对象名称。|
|filename|要检查的文件名。|
|fexists|返回文件是否存在。`TRUE` 表示文件存在，`FALSE` 表示不存在。|
|file_length|返回文件的长度（大小），单位为字节。|
|block_size|返回文件所在文件系统的数据块大小（字节）。|
