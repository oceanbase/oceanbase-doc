# PUT_LINE_NCHAR

`UT_LINE_NCHAR` 用于写入 Unicode 字符到文件的存储过程。

<main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.PUT_LINE_NCHAR (
    file      IN FILE_TYPE,
    buffer    IN NVARCHAR2,
    autoflush IN BOOLEAN DEFAULT FALSE
);
```

## 参数解释

|    参数     |           解释            |
|-----------|-------------------------|
| file      | 由调用 `FOPEN` 返回的活动文件句柄。  |
| buffer    | 文本缓冲区，包含要写入文件的行。        |
| autoflush | 可选，默认为 `FALSE`。若设为 `TRUE`，则表示在写入后立即将数据刷新到磁盘，确保数据持久化。|
