# IS_OPEN

`IS_OPEN` 函数用于测试文件句柄是否标识一个已打开的文件。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.IS_OPEN (
   file  IN FILE_TYPE)
  RETURN BOOLEAN;
```

## 参数解释

| 参数 | 解释 |
|------|------|
| file | 由 `FOPEN` 或 `FOPEN_NCHAR` 调用返回的活动文件句柄。 |

## 返回值

返回 `TRUE` 或 `FALSE`。

## 异常情况

* `INVALID_FILEHANDLE`

## 使用说明

`IS_OPEN` 仅报告文件句柄是否表示一个已打开但尚未关闭的文件，并不保证在使用该文件句柄时不会出现操作系统错误。
