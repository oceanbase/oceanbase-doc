# FCLOSE_ALL

`FCLOSE_ALL` 用于关闭当前会话下所有 `UTL_FILE` 已打开的文件。

<main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.FCLOSE_ALL;
```

## 使用说明

* 无参数过程：`FCLOSE_ALL` 是一个不接收任何输入参数的过程。调用时只需写出过程名即可。
* 批量操作：此过程会立即关闭当前会话中通过 `UTL_FILE` 包打开的所有文件。
* 安全执行：即使当前没有任何已打开的文件，调用该过程也会成功执行，不会抛出错误。
