# PUT_RAW

`PUT_RAW` 存储过程用于将输入参数按 RAW 写入到指定的文件中。

<main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
UTL_FILE.PUT_RAW (
    fid        IN UTL_FILE.FILE_TYPE,
    r          IN RAW,
    autoflush  IN BOOLEAN DEFAULT FALSE
);
```

## 参数解释

|    参数     |           解释            |
|-----------|-------------------------|
| fid      | 通过 `FOPEN` 打开的文件句柄。  |
| r        | 包含待写入二进制数据的缓冲区。        |
| autoflush | 可选参数，默认为 `FALSE`。若设为 `TRUE`，数据会立即刷新到磁盘，确保写入的实时性。 |
