# DBMS_SYS_ERROR 概述

`DBMS_SYS_ERROR` 系统包提供 `RAISE_SYSTEM_ERROR` 过程，用于在 PL 程序中引发用户定义的系统错误。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>
