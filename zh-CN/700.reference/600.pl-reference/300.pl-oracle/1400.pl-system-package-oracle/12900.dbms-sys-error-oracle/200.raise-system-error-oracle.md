# RAISE_SYSTEM_ERROR

`RAISE_SYSTEM_ERROR` 过程用于在 PL 程序中引发用户定义的系统错误。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

`RAISE_SYSTEM_ERROR` 过程支持以下重载形式：

```sql
-- 仅指定错误号
DBMS_SYS_ERROR.RAISE_SYSTEM_ERROR(
    num            BINARY_INTEGER,
    keeperrorstack BOOLEAN DEFAULT FALSE);

-- 指定错误号和 1 个参数
DBMS_SYS_ERROR.RAISE_SYSTEM_ERROR(
    num            BINARY_INTEGER,
    arg1           VARCHAR2,
    keeperrorstack BOOLEAN DEFAULT FALSE);

-- 指定错误号和 2 个参数
DBMS_SYS_ERROR.RAISE_SYSTEM_ERROR(
    num            BINARY_INTEGER,
    arg1           VARCHAR2,
    arg2           VARCHAR2,
    keeperrorstack BOOLEAN DEFAULT FALSE);

-- 指定错误号和 N 个参数（最多 8 个参数）
DBMS_SYS_ERROR.RAISE_SYSTEM_ERROR(
    num            BINARY_INTEGER,
    arg1           VARCHAR2,
    arg2           VARCHAR2,
    ...
    argN           VARCHAR2,
    keeperrorstack BOOLEAN DEFAULT FALSE);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| num | 错误号。 |
| arg1 ... argN | 错误消息中的参数，最多支持 8 个参数（`arg1` ~ `arg8`）。 |
| keeperrorstack | 是否保留错误栈。设置为 `TRUE` 时，保留当前错误栈并添加新的错误。默认为 `FALSE`。 |

## 使用说明

* `RAISE_SYSTEM_ERROR` 过程的 `PRAGMA RESTRICT_REFERENCES` 约束为 `WNDS`、`RNDS`、`WNPS`、`RNPS`，表示该过程不读写数据库状态，不修改包状态。
* 适合在自定义逻辑中需要抛出特定错误码的场景使用。

## 示例

```sql
DECLARE
  v_emp_id NUMBER := -1;
BEGIN
  IF v_emp_id < 0 THEN
    DBMS_SYS_ERROR.RAISE_SYSTEM_ERROR(-20001, 'Invalid employee ID: ' || v_emp_id);
  END IF;
END;
/
```
