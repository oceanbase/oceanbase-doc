# BEGIN_REQUEST

`BEGIN_REQUEST` 用于初始化 HTTP 请求。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 V4.4.1 版本开始引入。</p>
</main>

## 语法

```sql
UTL_HTTP.BEGIN_REQUEST (
   url               IN  VARCHAR2,
   method            IN  VARCHAR2 DEFAULT 'GET',
   http_version      IN  VARCHAR2 DEFAULT NULL,
   request_context   IN  request_context_key DEFAULT NULL,
   https_host        IN  VARCHAR2 DEFAULT NULL)
RETURN req;
```

## 参数解释

| **参数** |         **解释**         |
|--------|------------------------|
|url|HTTP 请求的 URL|
|method|请求方法，默认为 GET|
|http_version|发送请求时所使用的 HTTP 协议版本，默认为空，代表最新版本|
|request_context|请求体，包含 wallet 和 cookie 信息，默认为空，代表当前数据库 session 中的信息|
|https_host|主机名，默认为空，代表传入的URL通过 SNI 找到的主机名|
