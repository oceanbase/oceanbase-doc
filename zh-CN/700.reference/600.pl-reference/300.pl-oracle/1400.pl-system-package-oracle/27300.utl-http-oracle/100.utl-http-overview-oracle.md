# UTL_HTTP 概述

`UTL_HTTP` 系统包用于在 PL/SQL 环境中实现 HTTP 和 HTTPS 通信的系统工具包。它允许数据库直接与外部 Web 服务交互。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 V4.4.1 版本开始引入。</p>
</main>

## UTL_HTTP 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `UTL_HTTP` 子程序以及简要描述。

|                       **子程序**             |                **描述**                       |
|----------------------------------------------|-----------------------------------------------|
|[BEGIN_REQUEST](110.begin-request-oracle.md)|与给定的 URL 建立 HTTP 连接，并且向该 URL 发送 HTTP 请求，返回一个 `req` 变量|
|[END_REQUEST](200.end-request-oracle.md)|强制关闭一个 request，不论是否完成请求或后续的 response，同时会关闭 HTTP 连接|
|[GET_RESPONSE](300.get-response-oracle.md)|用于获取 HTTP 请求的响应 response|
|[END_RESPONSE](400.end-response-oracle.md)|用于在完成 HTTP 请求后终止 HTTP 请求的响应 response|
|[READ_LINE](500.read-line-oracle.md)|读取 HTTP 响应体的一行文本格式数据|
|[READ_RAW](600.read-raw-oracle.md)|用于读取 HTTP 响应体中的二进制数据|
|[READ_TEXT](700.read-text-oracle.md)|用于读取文本格式的数据|
|[WRITE_LINE](800.utl_http_write-line-oracle.md)|用于在 HTTP 请求体中写入一行文本数据|
|[WRITE_RAW](900.utl_http_write-raw-oracle.md)|用于在 HTTP 请求体中写入二进制数据|
|[WRITE_TEXT](1000.utl_http_write-text-oracle.md)|用于在 HTTP 请求体中写入文本数据|
|[SET_TRANSFER_TIMEOUT](1100.set-transfer-timeout-oracle.md)|用于设置 HTTP 传输数据的超时时间上限|
|[GET_TRANSFER_TIMEOUT](1200.get-transfer-timeout-oracle.md)|用于获取当前的 HTTP 传输数据的超时时间上限|

## 使用示例

发送 GET 请求：

```sql
DECLARE
  req  UTL_HTTP.REQ;
  resp UTL_HTTP.RESP;
  url  VARCHAR2(256) := 'https://api.example.com/data';
  buf  VARCHAR2(4000);
BEGIN
  req := UTL_HTTP.BEGIN_REQUEST(url, 'GET');
  resp := UTL_HTTP.GET_RESPONSE(req);
  LOOP
    UTL_HTTP.READ_TEXT(resp, buf);
    DBMS_OUTPUT.PUT_LINE(buf);
  END LOOP;
EXCEPTION
  WHEN UTL_HTTP.END_OF_BODY THEN
    UTL_HTTP.END_RESPONSE(resp);
END;
```
