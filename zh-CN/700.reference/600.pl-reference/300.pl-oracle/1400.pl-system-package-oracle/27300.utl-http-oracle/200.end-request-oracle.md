# END_REQUEST

`END_REQUEST` 用于强制关闭一个 request。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 V4.4.1 版本开始引入。</p>
</main>

## 语法

```sql
UTL_HTTP.END_RESPONSE (
   r  IN OUT NOCOPY resp);
```

## 参数解释

| **参数** |         **解释**         |
|--------|------------------------|
|r|需要终止的请求 req|
