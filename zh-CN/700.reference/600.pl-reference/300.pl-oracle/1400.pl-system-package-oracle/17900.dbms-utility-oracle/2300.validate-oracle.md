# VALIDATE

`VALIDATE` 存储过程用于通过对象 ID 验证并重新编译数据库对象。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
DBMS_UTILITY.VALIDATE (
    OBJECT_ID     NUMBER,
    IS_RECOMPILE  BOOLEAN DEFAULT FALSE);
```

## 参数解释

|    参数       |      解释      |
|-------------|---------------|
| OBJECT_ID   | 要验证的数据库对象的对象 ID。 |
| IS_RECOMPILE | 内置参数。默认值为 `FALSE`。 |

## 使用说明

* `VALIDATE` 存储过程首先根据 `OBJECT_ID` 从 `sys.all_objects` 视图中查询对象的拥有者、名称和类型，然后对该对象执行验证和重新编译操作。
* `VALIDATE` 执行完成后，若编译成功，编译结果会写入 PL Cache 与磁盘缓存，可用于预热 PL 对象。
* 支持的对象类型包括 `PROCEDURE`、`FUNCTION`、`TRIGGER`、`PACKAGE`、`PACKAGE BODY` 和 `TYPE`。
* 如果指定的 `OBJECT_ID` 在 `sys.all_objects` 中不存在，则存储过程静默返回，不会报错。
* 该子程序使用调用者权限（Invoker's Rights），允许普通用户编译其他 Schema 下的对象。
* 由于 `VALIDATE` 是 SQL 保留关键字，不支持使用 `CALL DBMS_UTILITY.VALIDATE(...)` 语法调用，需要在 PL/SQL 匿名块中调用。

## 示例

创建一个存储过程 `MY_PROC`。

```sql
obclient> CREATE OR REPLACE PROCEDURE MY_PROC IS
BEGIN
  NULL;
END;
/
```

查询 `MY_PROC` 的对象信息，获取其 `OBJECT_ID`。

```sql
obclient> SELECT OBJECT_ID, OBJECT_NAME, OBJECT_TYPE, STATUS FROM SYS.ALL_OBJECTS
  WHERE OBJECT_NAME = 'MY_PROC';
```

返回结果如下：

```sql
+-----------+-------------+-------------+--------+
| OBJECT_ID | OBJECT_NAME | OBJECT_TYPE | STATUS |
+-----------+-------------+-------------+--------+
|    500002 | MY_PROC     | PROCEDURE   | VALID  |
+-----------+-------------+-------------+--------+
1 row in set
```

在 PL/SQL 匿名块中调用 `VALIDATE` 存储过程。

```sql
obclient> DECLARE
  obj_id NUMBER;
BEGIN
  SELECT OBJECT_ID INTO obj_id FROM SYS.ALL_OBJECTS
    WHERE OBJECT_NAME = 'MY_PROC';
  DBMS_UTILITY.VALIDATE(obj_id);
END;
/
```

再次查询 `MY_PROC` 的状态。

```sql
obclient> SELECT OBJECT_ID, OBJECT_NAME, OBJECT_TYPE, STATUS FROM SYS.ALL_OBJECTS
  WHERE OBJECT_NAME = 'MY_PROC';
```

返回结果如下：

```sql
+-----------+-------------+-------------+--------+
| OBJECT_ID | OBJECT_NAME | OBJECT_TYPE | STATUS |
+-----------+-------------+-------------+--------+
|    500002 | MY_PROC     | PROCEDURE   | VALID  |
+-----------+-------------+-------------+--------+
1 row in set
```
