# CREATE_ERROR_LOG

`CREATE_ERROR_LOG` 过程用于为指定的 DML 表创建错误日志表。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
DBMS_ERRLOG.CREATE_ERROR_LOG(
    dml_table_name      IN VARCHAR2,
    err_log_table_name  IN VARCHAR2 DEFAULT NULL,
    err_log_table_owner IN VARCHAR2 DEFAULT NULL,
    err_log_table_space IN VARCHAR2 DEFAULT NULL,
    skip_unsupported    IN BOOLEAN  DEFAULT FALSE);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| dml_table_name | 要为其创建错误日志表的 DML 表名称。 |
| err_log_table_name | 错误日志表的名称。如果为 `NULL`，则默认使用 `ERR$_` 前缀加 DML 表名。 |
| err_log_table_owner | 错误日志表所属的模式。如果为 `NULL`，使用当前模式。 |
| err_log_table_space | 错误日志表所在的表空间。如果为 `NULL`，使用 DML 表的默认表空间。 |
| skip_unsupported | 是否跳过不支持的列类型。默认为 `FALSE`。 |

## 使用说明

错误日志表与 DML 错误记录功能结合使用。在 DML 语句中添加 `LOG ERRORS` 子句时，可将执行过程中出现的错误记录到错误日志表中，而不会导致整个事务回滚。

错误日志表包含以下系统字段：

- `ORA_ERR_NUMBER$`：错误号
- `ORA_ERR_MESG$`：错误消息
- `ORA_ERR_ROWID$`：行 ID
- `ORA_ERR_OPTYP$`：操作类型
- `ORA_ERR_TAG$`：错误标记
- 以及原始表中各列对应的错误记录列

## 示例

```sql
-- 创建测试表
CREATE TABLE employees (
  emp_id NUMBER PRIMARY KEY,
  emp_name VARCHAR2(50),
  salary NUMBER
);

-- 创建错误日志表，名称为 ERR$_employees
BEGIN
  DBMS_ERRLOG.CREATE_ERROR_LOG(
    dml_table_name => 'employees');
END;
/

-- 使用 LOG ERRORS 子句插入数据
INSERT INTO employees (emp_id, emp_name, salary)
VALUES (1, 'Alice', 5000)
LOG ERRORS REJECT LIMIT UNLIMITED;
```
