# DBMS_DATA_DICT

`DBMS_DATA_DICT` 用于控制数据字典的调度。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

### 禁止调度数据字典

```sql
DBMS_DATA_DICT.DISABLE_DUMP(
    unused_arg BINARY_INTEGER DEFAULT NULL);
```

### 允许调度数据字典

```sql
DBMS_DATA_DICT.ENABLE_DUMP(
    unused_arg BINARY_INTEGER DEFAULT NULL);
```

### 手动触发生成字典

```sql
DBMS_DATA_DICT.TRIGGER_DUMP(
    dict_item_retention_by_day BINARY_INTEGER DEFAULT NULL);
```

### 调整字典的定时 DUMP 周期

```sql
DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL(
    repeat_interval_expr IN VARCHAR2 DEFAULT NULL);
```

### 调整字典历史记录的回收间隔

```sql
DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(
    dict_item_retention_by_day BINARY_INTEGER DEFAULT NULL);
```

### 调整字典 DUMP 任务的最大执行时长

```sql
DBMS_DATA_DICT.MODIFY_RUN_DURATION(
    max_run_duration_by_sec BINARY_INTEGER DEFAULT NULL);
```

## 参数说明

| 参数 | 说明 | 数据类型 |
|------|------|---------|
| unused_arg | 未使用参数。预留参数。 | BINARY_INTEGER |
| dict_item_retention_by_day | 触发执行生成字典后，执行回收字典的历史 DUMP 记录：<ul><li>携带参数时，取值范围大于等于 `0`。</li><li>不携带参数或参数为 `0` 时，代表本次 DUMP 不回收字典。</li></ul> | BINARY_INTEGER |
| repeat_interval_expr | 表示期望的调度周期。该参数需遵循 `DBMS_SCHEDULER` 的 `REPEAT_INTERVAL` 的书写格式，并用单引号包裹。例如 `'FREQ=MINUTELY; INTERVAL=120'`。 | VARCHAR2 |
| max_run_duration_by_sec | 字典 DUMP 任务的最大执行时长，单位为秒。 | BINARY_INTEGER |
| dict_item_retention_by_day | 期望的字典历史记录回收时间，单位为天。 | BINARY_INTEGER |

## 使用说明

* 租户建立后会立即自动触发生成一次数据字典。
* 开启归档时会立即自动触发生成一次数据字典。

## 示例

### 禁止调度数据字典

```sql
obclient> BEGIN
  DBMS_DATA_DICT.DISABLE_DUMP();
END;
/
```
