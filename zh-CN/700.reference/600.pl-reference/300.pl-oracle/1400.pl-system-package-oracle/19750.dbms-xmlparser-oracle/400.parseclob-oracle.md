# PARSECLOB

`PARSECLOB` 过程可在指定的解析器实例上，将传入的 `CLOB` 字符序列解析为 XML 文档。解析成功后，会在解析器内部生成 DOM 树结构，后续可通过 `GETDOCUMENT` 方法获取该 DOM 树。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP2 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLPARSER.PARSE_CLOB (
   parser   IN DBMS_XMLPARSER.PARSER,
   xml_text IN CLOB);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| parser | 由 `NEWPARSER` 创建的 `DBMS_XMLPARSER.PARSER` 句柄。 |
| xml_text | 待解析的 XML 文本，以 `CLOB` 形式传入；也可传入可隐式转换为 `CLOB` 的字符串字面量。 |

## 使用说明

若解析过程遇到非法 XML 或空文档等异常情况，将会直接报错。解析成功后，建议立即使用 `GETDOCUMENT` 获取 `DBMS_XMLDOM.DOMDOCUMENT` 句柄，并通过 `DBMS_XMLDOM` 的相关子程序对 DOM 树进行遍历和节点读取操作。

## 示例

该示例通过 `DBMS_XMLPARSER` 系统包在解析器上解析 XML 文档，并以 CLOB 形式传入，最后释放解析器句柄：

```sql
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  xml CLOB;
BEGIN
  -- 创建解析器实例
  p := DBMS_XMLPARSER.NEWPARSER;
  -- 在解析器上解析 XML 文档
  xml := '<root/>';
  -- 在解析器上解析 XML 文档，以 CLOB 形式传入
  DBMS_XMLPARSER.PARSECLOB(p, xml);
  -- 释放解析器句柄
  DBMS_XMLPARSER.FREEPARSER(p);
END;
/
```
