# PARSEBUFFER

`PARSEBUFFER` 过程可在已创建的 XML 解析器上，解析 `VARCHAR2` 格式的 XML 文本。与 `PARSECLOB` 类似，适用于较短的 XML 文本；解析成功后可通过 `GETDOCUMENT` 获取 DOM 文档。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLPARSER.parseBuffer (
   parser     IN DBMS_XMLPARSER.PARSER,
   xml_buffer IN VARCHAR2);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| parser | 由 `NEWPARSER` 创建的 `DBMS_XMLPARSER.PARSER` 句柄。 |
| xml_buffer | 待解析的 XML 文本，以 `VARCHAR2` 形式传入。 |

## 返回值

无返回值。

## 使用说明

* 若解析过程遇到非法 XML 或空文档等异常情况，将会直接报错。
* 解析成功后，建议立即使用 `GETDOCUMENT` 获取 `DBMS_XMLDOM.DOMDOCUMENT` 句柄。
* 对于较长的 XML 文本，请继续使用 [PARSECLOB](400.parseclob-oracle.md)。

## 示例

该示例通过 `PARSEBUFFER` 解析短文本 XML，获取 DOM 文档后释放资源：

```sql
DECLARE
  parser DBMS_XMLPARSER.PARSER;
  doc    DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  parser := DBMS_XMLPARSER.newParser;
  DBMS_XMLPARSER.parseBuffer(parser, '<root><item>hello</item></root>');
  doc := DBMS_XMLPARSER.getDocument(parser);
  DBMS_XMLPARSER.freeParser(parser);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
