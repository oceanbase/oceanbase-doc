# DBMS_XMLPARSER 概述

`DBMS_XMLPARSER` 系统包用于从 `CLOB` 解析 XML 文本，构建可供 `DBMS_XMLDOM` 访问的 DOM 解析树。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该系统包从 OceanBase 数据库 V4.4.2 BP2 版本开始引入。</p>
</main>

## DBMS_XMLPARSER 权限说明

`DBMS_XMLPARSER` 系统包的 `EXECUTE` 权限被授予 `PUBLIC`。当前用户拥有该包中的子程序的使用权限。

## DBMS_XMLPARSER 使用说明

`DBMS_XMLPARSER` 读取 `CLOB` 中的 XML 并解析为 DOM 树。解析成功后，通过 `GETDOCUMENT` 获取 `DOMDOCUMENT` 句柄，再使用 `DBMS_XMLDOM` 中的子程序遍历节点、读取元素与节点值；解析失败时抛出应用错误。

典型处理流程如下：

1. 调用 `NEWPARSER` 创建解析器（`Parser` 句柄）。
2. 调用 `PARSECLOB` 解析 `CLOB` 中的 XML 文本。
3. 调用 `GETDOCUMENT` 获取 `DBMS_XMLDOM.DOMDOCUMENT` 句柄。
4. 使用 [DBMS_XMLDOM](../19500.dbms-xmldom-oracle/100.dbms-xmldom-overview-oracle.md) 相关子程序访问解析结果。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>当前版本通过 <code>PARSECLOB</code> 解析 <code>CLOB</code> 中的 XML，并构建可供 DOM 接口访问的解析树。自文件路径或 URL 解析、DTD 校验、错误日志等能力不在当前支持范围内。</p>
</main>

有关 `XMLType` 的创建与转换，请参见 [XMLType 概述](../29600.xmltype-oracle/100.xmltype-overview-oracle.md)。
