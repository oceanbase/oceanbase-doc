# GETLENGTH

`GETLENGTH` 函数用于返回节点列表中包含的节点数量，常用于遍历节点前获取上限，或与 `ITEM` 结合实现安全访问。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP2 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getLength (
   nodelist IN DBMS_XMLDOM.DOMNODELIST);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| nodelist | 待统计的 `DBMS_XMLDOM.DOMNODELIST` 句柄。 |

## 返回值

节点列表中的节点数量，类型为 `NUMBER`。

## 使用说明

下标从 0 开始，有效范围为 `[0, GETLENGTH(nodelist) - 1]`。列表为空时返回 0。
