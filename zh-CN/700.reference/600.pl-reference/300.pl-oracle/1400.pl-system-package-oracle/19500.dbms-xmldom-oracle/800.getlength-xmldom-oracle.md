# GETLENGTH

`GETLENGTH` 函数用于返回节点列表中包含的节点数量，常用于遍历节点前获取上限，或与 `ITEM` 结合实现安全访问。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP2 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getLength (
   nodelist IN DBMS_XMLDOM.DOMNODELIST);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| nodelist | 待统计的 `DBMS_XMLDOM.DOMNODELIST` 句柄。 |

## 返回值

节点列表中的节点数量，类型为 `NUMBER`。

## 使用说明

下标从 0 开始，有效范围为 `[0, GETLENGTH(nodelist) - 1]`。列表为空时返回 0。

## 示例

该示例通过 `DBMS_XMLPARSER` 系统包解析 XML 文档并获取 `DOMDOCUMENT` 句柄，然后通过 `DBMS_XMLDOM` 系统包获取 XML 文档的 `DOMNODELIST` 句柄，并获取列表中的节点数量：

```sql
-- 声明解析器和文档句柄变量
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  doc DBMS_XMLDOM.DOMDOCUMENT;
  nl  DBMS_XMLDOM.DOMNODELIST;
  len NUMBER;
BEGIN
  -- 创建解析器实例
  p := DBMS_XMLPARSER.NEWPARSER;
  -- 在解析器上解析 XML 文档
  DBMS_XMLPARSER.PARSECLOB(p, '<root><a/><b/></root>');
  -- 获取 XML 文档的 DOMDOCUMENT 句柄
  doc := DBMS_XMLPARSER.GETDOCUMENT(p);
  -- 释放解析器实例
  DBMS_XMLPARSER.FREEPARSER(p);
  -- 获取 XML 文档中所有元素列表
  nl := DBMS_XMLDOM.GETELEMENTSBYTAGNAME(doc, '*');
  -- 获取列表中的节点数量
  len := DBMS_XMLDOM.GETLENGTH(nl);
  -- 释放 XML 文档资源
  DBMS_XMLDOM.FREEDOCUMENT(doc);
END;
/
```
