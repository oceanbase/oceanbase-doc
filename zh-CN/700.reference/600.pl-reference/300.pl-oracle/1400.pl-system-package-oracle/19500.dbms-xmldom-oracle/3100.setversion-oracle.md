# SETVERSION

`SETVERSION` 过程用于设置 DOM 文档的 XML 版本信息，常见值为 `1.0`，用于后续文档序列化。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.setVersion (
   doc     IN DBMS_XMLDOM.DOMDOCUMENT,
   version IN VARCHAR2);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc | 目标 `DBMS_XMLDOM.DOMDOCUMENT` 句柄。 |
| version | XML 版本号，例如 `1.0`。 |

## 返回值

无返回值。

## 使用说明

通常在调用 `WRITETOBUFFER` 或 `WRITETOCLOB` 序列化前设置。

## 示例

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.setVersion(doc, '1.0');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
