# GETDATA

`GETDATA` 函数用于获取 DOM 字符数据节点中的文本内容，可从 `DOMCHARACTERDATA`、`DOMTEXT` 等字符数据节点读取文本。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getData (
   cd IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| cd | 字符数据节点 `DBMS_XMLDOM.DOMCHARACTERDATA` 句柄。 |

## 返回值

字符数据内容，类型为 `VARCHAR2`。

## 使用说明

若持有的是通用 `DOMNODE`，需先通过 `MAKECHARACTERDATA` 转换为 `DOMCHARACTERDATA` 再调用本函数。

## 示例

```sql
DECLARE
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
  data           VARCHAR2(32767);
BEGIN
  data := DBMS_XMLDOM.getData(character_data);
END;
/
```
