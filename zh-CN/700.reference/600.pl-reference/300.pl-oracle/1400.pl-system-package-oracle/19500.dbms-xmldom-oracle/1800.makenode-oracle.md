# MAKENODE

`MAKENODE` 函数用于将 `DOMDOCUMENT`、`DOMELEMENT`、`DOMTEXT`、`DOMATTR`、`DOMCHARACTERDATA` 等具体 DOM 对象转换为通用 `DOMNODE` 句柄，便于统一参与 `APPENDCHILD`、`REMOVECHILD`、`GETNODENAME` 等节点级接口。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.makeNode (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);

DBMS_XMLDOM.makeNode (
   elem IN DBMS_XMLDOM.DOMELEMENT);

DBMS_XMLDOM.makeNode (
   text IN DBMS_XMLDOM.DOMTEXT);

DBMS_XMLDOM.makeNode (
   attr IN DBMS_XMLDOM.DOMATTR);

DBMS_XMLDOM.makeNode (
   character_data IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc / elem / text / attr / character_data | 待转换的具体 DOM 对象句柄。 |

## 返回值

`DBMS_XMLDOM.DOMNODE` 通用节点句柄。

## 使用说明

不同重载分别接受文档、元素、文本、属性或字符数据句柄，返回统一的 `DOMNODE`，便于后续节点级操作。

## 示例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
  node DBMS_XMLDOM.DOMNODE;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  node := DBMS_XMLDOM.makeNode(elem);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
