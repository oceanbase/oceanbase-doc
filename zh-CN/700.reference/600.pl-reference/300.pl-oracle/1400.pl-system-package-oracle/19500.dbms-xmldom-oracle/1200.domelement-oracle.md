# DOMELEMENT

`DOMELEMENT` 表示 DOM 元素节点句柄类型，用于表示 XML 元素，可作为 `CREATEELEMENT`、`GETDOCUMENTELEMENT`、`SETATTRIBUTE` 等接口的返回值或入参。该句柄本身为不透明类型，仅用于传入/传出 DOM 相关 API，不可直接访问其内部结构。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该类型从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
elem DBMS_XMLDOM.DOMELEMENT;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| elem | 元素节点句柄。 |

## 返回值

元素节点句柄。

## 使用说明

`DOMELEMENT` 通常由 [CREATEELEMENT](1600.createelement-oracle.md) 或 [GETDOCUMENTELEMENT](2300.getdocumentelement-oracle.md) 返回；可通过 [MAKENODE](1800.makenode-oracle.md) 转换为通用 `DOMNODE`。

## 示例

```sql
DECLARE
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  NULL;
END;
/
```
