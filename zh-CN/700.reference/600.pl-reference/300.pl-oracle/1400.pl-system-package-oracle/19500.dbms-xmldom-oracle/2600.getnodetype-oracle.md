# GETNODETYPE

`GETNODETYPE` 函数用于获取 DOM 节点类型编号，以区分元素节点、属性节点、文本节点、文档节点等不同 DOM 节点类别。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getNodeType (
   n IN DBMS_XMLDOM.DOMNODE);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| n | 待查询的 `DBMS_XMLDOM.DOMNODE` 句柄。 |

## 返回值

节点类型编号，类型为 `NUMBER`。常见取值可与下列 `DBMS_XMLDOM` 常量比较：

| **常量** | **取值** | **说明** |
| --- | --- | --- |
| `ELEMENT_NODE` | 1 | 元素节点 |
| `ATTRIBUTE_NODE` | 2 | 属性节点 |
| `TEXT_NODE` | 3 | 文本节点 |
| `CDATA_SECTION_NODE` | 4 | CDATA 节点 |
| `ENTITY_REFERENCE_NODE` | 5 | 实体引用节点 |
| `ENTITY_NODE` | 6 | 实体节点 |
| `PROCESSING_INSTRUCTION_NODE` | 7 | 处理指令节点 |
| `COMMENT_NODE` | 8 | 注释节点 |
| `DOCUMENT_NODE` | 9 | 文档节点 |
| `DOCUMENT_TYPE_NODE` | 10 | 文档类型节点 |
| `DOCUMENT_FRAGMENT_NODE` | 11 | 文档片段节点 |
| `NOTATION_NODE` | 12 | 记号节点 |

## 使用说明

返回值语义与 Oracle DOM 节点类型常量一致，可直接与 `DBMS_XMLDOM.ELEMENT_NODE`、`DBMS_XMLDOM.TEXT_NODE` 等常量比较，用于分支处理不同节点类别。

## 示例

```sql
DECLARE
  n         DBMS_XMLDOM.DOMNODE;
  node_type NUMBER;
BEGIN
  node_type := DBMS_XMLDOM.getNodeType(n);
  IF node_type = DBMS_XMLDOM.ELEMENT_NODE THEN
    NULL; -- 元素节点处理
  ELSIF node_type = DBMS_XMLDOM.TEXT_NODE THEN
    NULL; -- 文本节点处理
  END IF;
END;
/
```
