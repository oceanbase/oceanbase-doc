# GETXMLTYPE

`GETXMLTYPE` 函数用于将 DOM 文档对象转换为 `XMLTYPE` 对象，便于继续使用 SQL/XML、`XMLType` 成员方法或 XML 到 PL/SQL 对象转换能力。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getXmlType (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc | 目标 `DBMS_XMLDOM.DOMDOCUMENT` 句柄。 |

## 返回值

`XMLTYPE` 实例。

## 使用说明

可与 `XMLTYPE.TOOBJECT` 配合使用：先通过 DOM 构造或解析 XML，再转换为 `XMLType`，最后映射到 PL/SQL 对象。

## 示例

```sql
DECLARE
  doc DBMS_XMLDOM.DOMDOCUMENT;
  x   XMLTYPE;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  x := DBMS_XMLDOM.getXmlType(doc);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
