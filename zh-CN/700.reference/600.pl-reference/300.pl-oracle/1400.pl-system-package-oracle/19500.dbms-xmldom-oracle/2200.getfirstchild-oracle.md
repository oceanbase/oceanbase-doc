# GETFIRSTCHILD

`GETFIRSTCHILD` 函数用于返回指定 DOM 节点的第一个子节点。若节点不存在子节点，返回空节点句柄；可配合 `ISNULL` 判断返回值是否为空。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getFirstChild (
   n IN DBMS_XMLDOM.DOMNODE);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| n | 待查询的 `DBMS_XMLDOM.DOMNODE` 句柄。 |

## 返回值

第一个子节点句柄；若不存在子节点则为空句柄。

## 使用说明

建议配合 [ISNULL](2800.isnull-oracle.md) 判断返回值是否为空，避免对空句柄继续操作。

## 示例

```sql
DECLARE
  n           DBMS_XMLDOM.DOMNODE;
  first_child DBMS_XMLDOM.DOMNODE;
BEGIN
  first_child := DBMS_XMLDOM.getFirstChild(n);
END;
/
```
