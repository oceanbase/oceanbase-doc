# DOMNODE

`DOMNODE` 是表示 DOM 树中单个节点（如元素、文本、注释等）的句柄，可用于操作和访问 XML 结构。常作为 `GETCHILDNODES`、`GETNODEVALUE` 及 `ITEM` 等函数的参数或返回值。该句柄本身为不透明类型。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该类型从 OceanBase 数据库 V4.4.2 BP2 版本开始引入。</p>
</main>

## 语法

```sql
node DBMS_XMLDOM.DOMNODE;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| node | 节点句柄。 |

## 返回值

节点句柄。

## 使用说明

`DOMNODE` 通常由 [ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) 从节点列表中取得，或通过 [GETCHILDNODES](../19500.dbms-xmldom-oracle/600.getchildnodes-oracle.md) 遍历子节点。
