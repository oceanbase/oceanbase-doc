# DOMNODE

`DOMNODE` 是表示 DOM 树中单个节点（如元素、文本、注释等）的句柄，可用于操作和访问 XML 结构。常作为 `GETCHILDNODES`、`GETNODEVALUE` 及 `ITEM` 等函数的参数或返回值。该句柄本身为不透明类型，表示已解析 XML 文档的引用对象，仅用于传入/传出 DOM 相关 API，不可直接访问其内部结构。

## 语法

```sql
node DBMS_XMLDOM.DOMNODE;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| node | 节点句柄。 |

## 返回值

节点句柄。

## 使用说明

`DOMNODE` 通常由 [ITEM](../19500.dbms-xmldom-oracle/1000.item-oracle.md) 从节点列表中取得，或通过 [GETCHILDNODES](../19500.dbms-xmldom-oracle/600.getchildnodes-oracle.md) 遍历子节点。

| **子程序** | **说明** |

## 示例

该示例通过 `DBMS_XMLPARSER` 系统包解析 XML 文档并获取 `DOMDOCUMENT` 句柄，然后通过 `DBMS_XMLDOM` 系统包获取 XML 文档的 `DOMNODE` 句柄，并读取节点值：

```sql
-- 声明解析器和文档句柄变量
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  doc DBMS_XMLDOM.DOMDOCUMENT;
  nl  DBMS_XMLDOM.DOMNODELIST;
  n   DBMS_XMLDOM.DOMNODE;
BEGIN
  -- 创建解析器实例
  p := DBMS_XMLPARSER.NEWPARSER;
  -- 在解析器上解析 XML 文档
  DBMS_XMLPARSER.PARSECLOB(p, '<root><a/></root>');
  -- 获取 XML 文档的 DOMDOCUMENT 句柄
  doc := DBMS_XMLPARSER.GETDOCUMENT(p);
  -- 释放解析器实例
  DBMS_XMLPARSER.FREEPARSER(p);
  -- 获取 XML 文档中所有名为 "a" 的元素列表
  nl := DBMS_XMLDOM.GETELEMENTSBYTAGNAME(doc, 'a');
  -- 获取列表中的第一个元素
  n  := DBMS_XMLDOM.ITEM(nl, 0);
  -- 释放 XML 文档资源
  DBMS_XMLDOM.FREEDOCUMENT(doc);
END;
/
```
