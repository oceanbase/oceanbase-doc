# WRITETOCLOB

`WRITETOCLOB` 过程用于将 DOM 文档或 DOM 节点序列化写入 `CLOB`，适用于 XML 内容超过 `VARCHAR2` 长度限制的场景。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.writeToClob (
   doc  IN DBMS_XMLDOM.DOMDOCUMENT,
   clob IN OUT CLOB);

DBMS_XMLDOM.writeToClob (
   n    IN DBMS_XMLDOM.DOMNODE,
   clob IN OUT CLOB);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc / n | 待序列化的 `DOMDOCUMENT` 或 `DOMNODE` 句柄。 |
| clob | 用于接收序列化结果的 `CLOB`（`IN OUT`）。 |

## 返回值

无返回值；结果写入 `clob`。

## 使用说明

调用前通常需先通过 `DBMS_LOB.CREATETEMPORARY` 创建临时 `CLOB`；使用完毕后按需释放。

## 示例

```sql
DECLARE
  doc         DBMS_XMLDOM.DOMDOCUMENT;
  clob_buffer CLOB;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_LOB.createtemporary(clob_buffer, TRUE);
  DBMS_XMLDOM.writeToClob(doc, clob_buffer);
  DBMS_LOB.freetemporary(clob_buffer);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
