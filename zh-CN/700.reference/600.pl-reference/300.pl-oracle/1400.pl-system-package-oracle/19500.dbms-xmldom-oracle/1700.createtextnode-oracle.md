# CREATETEXTNODE

`CREATETEXTNODE` 函数用于在指定 DOM 文档中创建文本节点，文本内容由 `data` 指定。该节点可作为元素节点的子节点追加到 DOM 树中。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.createTextNode (
   doc  IN DBMS_XMLDOM.DOMDOCUMENT,
   data IN VARCHAR2);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc | 目标 `DBMS_XMLDOM.DOMDOCUMENT` 句柄。 |
| data | 文本节点内容。 |

## 返回值

`DBMS_XMLDOM.DOMTEXT` 文本节点句柄。

## 使用说明

创建的文本节点通常通过 `MAKENODE` 转为 `DOMNODE` 后，再使用 `APPENDCHILD` 追加到元素节点下。

## 示例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  text DBMS_XMLDOM.DOMTEXT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  text := DBMS_XMLDOM.createTextNode(doc, 'hello');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
