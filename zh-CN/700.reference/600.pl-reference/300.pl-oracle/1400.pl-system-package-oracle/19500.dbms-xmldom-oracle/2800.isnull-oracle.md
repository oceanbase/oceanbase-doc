# ISNULL

`ISNULL` 函数用于判断 DOM 句柄是否为空，常用于 `GETFIRSTCHILD`、`GETDOCUMENTELEMENT`、`MAKENODE` 等接口返回值的空值检测。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.isNull (
   n IN DBMS_XMLDOM.DOMNODE);

DBMS_XMLDOM.isNull (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);

DBMS_XMLDOM.isNull (
   elem IN DBMS_XMLDOM.DOMELEMENT);

DBMS_XMLDOM.isNull (
   text IN DBMS_XMLDOM.DOMTEXT);

DBMS_XMLDOM.isNull (
   attr IN DBMS_XMLDOM.DOMATTR);

DBMS_XMLDOM.isNull (
   character_data IN DBMS_XMLDOM.DOMCHARACTERDATA);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| n / doc / elem / text / attr / character_data | 待检测的 DOM 句柄。 |

## 返回值

若句柄为空则返回 `TRUE`，否则返回 `FALSE`。

## 使用说明

不同重载分别接受各类 DOM 句柄；在继续访问节点前建议先调用本函数做空值判断。

## 示例

```sql
DECLARE
  n       DBMS_XMLDOM.DOMNODE;
  is_null BOOLEAN;
BEGIN
  is_null := DBMS_XMLDOM.isNull(n);
END;
/
```
