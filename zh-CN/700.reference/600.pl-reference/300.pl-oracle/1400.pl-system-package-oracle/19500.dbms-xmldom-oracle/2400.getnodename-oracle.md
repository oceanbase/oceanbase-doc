# GETNODENAME

`GETNODENAME` 函数用于获取指定 DOM 节点的节点名称。元素节点返回元素名，属性节点返回属性名，文本节点等按 Oracle DOM 语义返回对应节点名称。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getNodeName (
   n IN DBMS_XMLDOM.DOMNODE);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| n | 待查询的 `DBMS_XMLDOM.DOMNODE` 句柄。 |

## 返回值

节点名称，类型为 `VARCHAR2`。

## 使用说明

对带命名空间前缀的元素，返回值可包含前缀；若仅需本地名，请使用 `GETLOCALNAME`。

## 示例

```sql
DECLARE
  n         DBMS_XMLDOM.DOMNODE;
  node_name VARCHAR2(32767);
BEGIN
  node_name := DBMS_XMLDOM.getNodeName(n);
END;
/
```
