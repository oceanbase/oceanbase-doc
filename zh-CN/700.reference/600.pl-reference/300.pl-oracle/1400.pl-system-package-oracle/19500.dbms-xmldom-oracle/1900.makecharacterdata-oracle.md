# MAKECHARACTERDATA

`MAKECHARACTERDATA` 函数用于将通用 DOM 节点转换为字符数据节点句柄，可继续通过 `GETDATA` 获取节点中的字符内容。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.makeCharacterData (
   node IN DBMS_XMLDOM.DOMNODE);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| node | 待转换的 `DBMS_XMLDOM.DOMNODE` 句柄。 |

## 返回值

`DBMS_XMLDOM.DOMCHARACTERDATA` 字符数据节点句柄。

## 使用说明

仅当节点本身为字符数据类节点（如文本节点）时转换才有意义；转换后可调用 `GETDATA` 读取内容。

## 示例

```sql
DECLARE
  doc            DBMS_XMLDOM.DOMDOCUMENT;
  text           DBMS_XMLDOM.DOMTEXT;
  node           DBMS_XMLDOM.DOMNODE;
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  text := DBMS_XMLDOM.createTextNode(doc, 'hello');
  node := DBMS_XMLDOM.makeNode(text);
  character_data := DBMS_XMLDOM.makeCharacterData(node);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
