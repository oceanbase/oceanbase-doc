# DOMATTR

`DOMATTR` 表示 DOM 属性节点句柄类型，用于承载 XML 元素属性相关操作的返回值或入参。该句柄本身为不透明类型，仅用于传入/传出 DOM 相关 API，不可直接访问其内部结构。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该类型从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
attr DBMS_XMLDOM.DOMATTR;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| attr | 属性节点句柄。 |

## 返回值

属性节点句柄。

## 使用说明

`DOMATTR` 通常作为属性相关接口的返回值或入参；可通过 [MAKENODE](1800.makenode-oracle.md) 转换为通用 `DOMNODE`。

## 示例

```sql
DECLARE
  attr DBMS_XMLDOM.DOMATTR;
BEGIN
  NULL;
END;
/
```
