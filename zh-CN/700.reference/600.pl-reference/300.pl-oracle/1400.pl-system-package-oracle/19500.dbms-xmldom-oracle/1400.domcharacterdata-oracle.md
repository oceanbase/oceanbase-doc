# DOMCHARACTERDATA

`DOMCHARACTERDATA` 表示 DOM 字符数据节点句柄类型，用于文本、CDATA 等字符数据节点的统一处理，可配合 `GETDATA` 获取字符内容。该句柄本身为不透明类型，仅用于传入/传出 DOM 相关 API，不可直接访问其内部结构。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该类型从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
character_data DBMS_XMLDOM.DOMCHARACTERDATA;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| character_data | 字符数据节点句柄。 |

## 返回值

字符数据节点句柄。

## 使用说明

`DOMCHARACTERDATA` 通常由 [MAKECHARACTERDATA](1900.makecharacterdata-oracle.md) 从通用 `DOMNODE` 转换得到；可通过 [GETDATA](2700.getdata-oracle.md) 读取文本内容。

## 示例

```sql
DECLARE
  character_data DBMS_XMLDOM.DOMCHARACTERDATA;
BEGIN
  NULL;
END;
/
```
