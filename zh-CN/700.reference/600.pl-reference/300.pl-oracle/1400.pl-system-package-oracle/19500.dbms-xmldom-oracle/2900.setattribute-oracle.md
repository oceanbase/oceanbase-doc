# SETATTRIBUTE

`SETATTRIBUTE` 过程用于为 DOM 元素设置属性。若属性不存在则新增属性；若属性已存在则更新属性值。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.setAttribute (
   elem  IN DBMS_XMLDOM.DOMELEMENT,
   name  IN VARCHAR2,
   value IN VARCHAR2);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| elem | 目标 `DBMS_XMLDOM.DOMELEMENT` 句柄。 |
| name | 属性名。 |
| value | 属性值。 |

## 返回值

无返回值。

## 使用说明

对已存在的同名属性执行本过程会覆盖原值。

## 示例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.createElement(doc, 'item');
  DBMS_XMLDOM.setAttribute(elem, 'id', '1001');
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
