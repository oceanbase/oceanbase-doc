# GETDOCUMENTELEMENT

`GETDOCUMENTELEMENT` 函数用于返回 DOM 文档的根元素节点。该接口是从文档对象进入元素树遍历、属性读取、子节点操作的常用入口。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getDocumentElement (
   doc IN DBMS_XMLDOM.DOMDOCUMENT);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc | 目标 `DBMS_XMLDOM.DOMDOCUMENT` 句柄。 |

## 返回值

`DBMS_XMLDOM.DOMELEMENT` 根元素句柄。

## 使用说明

若文档尚无根元素，返回空句柄；可配合 `ISNULL` 判断返回值是否为空。

## 示例

```sql
DECLARE
  doc  DBMS_XMLDOM.DOMDOCUMENT;
  elem DBMS_XMLDOM.DOMELEMENT;
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  elem := DBMS_XMLDOM.getDocumentElement(doc);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
