# REMOVECHILD

`REMOVECHILD` 函数用于从父节点 `n` 下移除指定子节点 `oldchild`，用于 DOM 树结构调整。返回值为被移除的节点句柄。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.removeChild (
   n        IN DBMS_XMLDOM.DOMNODE,
   oldchild IN DBMS_XMLDOM.DOMNODE);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| n | 父节点 `DBMS_XMLDOM.DOMNODE` 句柄。 |
| oldchild | 待移除的子节点 `DBMS_XMLDOM.DOMNODE` 句柄。 |

## 返回值

被移除的子节点句柄（`DBMS_XMLDOM.DOMNODE`）。

## 使用说明

`oldchild` 必须是 `n` 的直接子节点；移除后返回该子节点句柄，便于后续处理。

## 示例

```sql
DECLARE
  parent_node DBMS_XMLDOM.DOMNODE;
  old_child   DBMS_XMLDOM.DOMNODE;
  ret_node    DBMS_XMLDOM.DOMNODE;
BEGIN
  ret_node := DBMS_XMLDOM.removeChild(parent_node, old_child);
END;
/
```
