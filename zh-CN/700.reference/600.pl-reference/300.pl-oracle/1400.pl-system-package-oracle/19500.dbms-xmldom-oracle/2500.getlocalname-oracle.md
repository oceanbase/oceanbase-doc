# GETLOCALNAME

`GETLOCALNAME` 函数用于获取指定节点的本地名称。对于带命名空间前缀的节点，返回不含前缀的本地名。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.getLocalName (
   n IN DBMS_XMLDOM.DOMNODE);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| n | 待查询的 `DBMS_XMLDOM.DOMNODE` 句柄。 |

## 返回值

节点本地名称，类型为 `VARCHAR2`。

## 使用说明

与 `GETNODENAME` 相比，本函数返回不含命名空间前缀的本地名。

## 示例

```sql
DECLARE
  n          DBMS_XMLDOM.DOMNODE;
  local_name VARCHAR2(32767);
BEGIN
  local_name := DBMS_XMLDOM.getLocalName(n);
END;
/
```
