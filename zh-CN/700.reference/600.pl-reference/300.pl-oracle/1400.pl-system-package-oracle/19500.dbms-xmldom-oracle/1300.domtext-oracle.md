# DOMTEXT

`DOMTEXT` 表示 DOM 文本节点句柄类型，用于表示 XML 文本节点，可由 `CREATETEXTNODE` 创建，也可通过 `MAKENODE` 转换为通用 `DOMNODE`。该句柄本身为不透明类型，仅用于传入/传出 DOM 相关 API，不可直接访问其内部结构。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该类型从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
text DBMS_XMLDOM.DOMTEXT;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| text | 文本节点句柄。 |

## 返回值

文本节点句柄。

## 使用说明

`DOMTEXT` 通常由 [CREATETEXTNODE](1700.createtextnode-oracle.md) 创建；可通过 [MAKENODE](1800.makenode-oracle.md) 转换为通用 `DOMNODE`，再参与节点级操作。

## 示例

```sql
DECLARE
  text DBMS_XMLDOM.DOMTEXT;
BEGIN
  NULL;
END;
/
```
