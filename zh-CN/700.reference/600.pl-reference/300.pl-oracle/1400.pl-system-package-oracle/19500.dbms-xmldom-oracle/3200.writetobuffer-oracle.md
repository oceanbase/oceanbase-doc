# WRITETOBUFFER

`WRITETOBUFFER` 过程用于将 DOM 文档或 DOM 节点序列化写入 `VARCHAR2` 缓冲区，便于在 PL/SQL 中继续传递或返回 XML 文本。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该子程序从 OceanBase 数据库 V4.4.2 BP3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_XMLDOM.writeToBuffer (
   doc    IN DBMS_XMLDOM.DOMDOCUMENT,
   buffer IN OUT VARCHAR2);

DBMS_XMLDOM.writeToBuffer (
   n      IN DBMS_XMLDOM.DOMNODE,
   buffer IN OUT VARCHAR2);
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc / n | 待序列化的 `DOMDOCUMENT` 或 `DOMNODE` 句柄。 |
| buffer | 用于接收序列化结果的 `VARCHAR2` 缓冲区（`IN OUT`）。 |

## 返回值

无返回值；结果写入 `buffer`。

## 使用说明

当 XML 内容可能超过 `VARCHAR2` 长度限制时，请改用 `WRITETOCLOB`。

## 示例

```sql
DECLARE
  doc    DBMS_XMLDOM.DOMDOCUMENT;
  buffer VARCHAR2(32767);
BEGIN
  doc := DBMS_XMLDOM.newDOMDocument;
  DBMS_XMLDOM.writeToBuffer(doc, buffer);
  DBMS_XMLDOM.freeDocument(doc);
END;
/
```
