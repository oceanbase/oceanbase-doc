# DOMDOCUMENT

`DOMDocument` 表示一整棵已解析 XML 文档的不透明句柄，作为 `getElementsByTagName`、`freeDocument` 等 API 的文档级入参。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
</main>

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该类型从 OceanBase 数据库 V4.4.2 BP2 版本开始引入。</p>
</main>

## 语法

```sql
doc DBMS_XMLDOM.DOMDocument;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc | 文档句柄。 |

## 返回值

文档句柄。

## 使用说明

`DBMS_XMLDOM.DOMDocument` 通常由 [DBMS_XMLPARSER.getDocument](../19750.dbms-xmlparser-oracle/500.getdocument-oracle.md) 返回，不可直接构造。
