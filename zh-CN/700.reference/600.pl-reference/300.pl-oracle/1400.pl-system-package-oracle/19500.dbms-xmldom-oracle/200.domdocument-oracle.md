# DOMDOCUMENT

`DOMDOCUMENT` 表示一整棵已解析 XML 文档的不透明句柄，作为 `GETELEMENTSBYTAGNAME`、`FREEDOCUMENT` 等 API 的文档级入参。不透明类型表示已解析 XML 文档的引用对象，仅用于传入/传出 DOM 相关 API，不可直接访问其内部结构。

## 语法

```sql
doc DBMS_XMLDOM.DOMDOCUMENT;
```

## 参数解释

| **参数** | **解释** |
|----------|----------|
| doc | 文档句柄。 |

## 返回值

文档句柄。

## 使用说明

`DBMS_XMLDOM.DOMDOCUMENT` 通常由 [DBMS_XMLPARSER.GETDOCUMENT](../19750.dbms-xmlparser-oracle/500.getdocument-oracle.md) 返回，不可直接构造。

## 相关子程序

| **子程序** | **说明** |
|------------|----------|
| [GETELEMENTSBYTAGNAME](../19500.dbms-xmldom-oracle/700.getelementbytagname-oracle.md) | 用于通过标签名从整个 XML 文档中批量获取所有匹配的元素节点。该方法需要传入 `DOMDOCUMENT` 类型的文档句柄作为输入参数。|
| [FREEDOCUMENT](../19500.dbms-xmldom-oracle/500.freedocument-oracle.md) | 释放由 `DOMDOCUMENT` 类型句柄所标识的 XML 文档资源，防止资源泄漏。使用时需将待释放的文档句柄作为输入参数传入。 |

## 示例

该示例通过 `DBMS_XMLPARSER` 系统包解析 XML 文档并获取 `DOMDOCUMENT` 句柄，最后通过 `DBMS_XMLDOM` 系统包释放文档资源：

```sql
-- 声明解析器和文档句柄变量
DECLARE
  p   DBMS_XMLPARSER.PARSER;
  doc DBMS_XMLDOM.DOMDOCUMENT;
BEGIN
  -- 创建解析器实例
  p := DBMS_XMLPARSER.NEWPARSER;
  -- 在解析器上解析 XML 文档
  DBMS_XMLPARSER.PARSECLOB(p, '<root/>');
  -- 获取 XML 文档的 DOMDOCUMENT 句柄
  doc := DBMS_XMLPARSER.GETDOCUMENT(p);
  -- 释放解析器实例
  DBMS_XMLPARSER.FREEPARSER(p);
  -- 释放 XML 文档资源
  DBMS_XMLDOM.FREEDOCUMENT(doc);
END;
/
```
