# DROP_GROUPED_POLICY

`DROP_GROUPED_POLICY` 过程用于从指定策略组删除策略。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

```sql
DBMS_RLS.DROP_GROUPED_POLICY(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    policy_group  IN VARCHAR2 := 'SYS_DEFAULT',
    policy_name   IN VARCHAR2);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| object_schema | 表或视图所属的模式名称。默认为 `NULL`，表示当前模式。 |
| object_name   | 表或视图的名称。 |
| policy_group  | 策略组名称。默认为 `SYS_DEFAULT`。 |
| policy_name   | 策略名称。 |

## 示例

```sql
BEGIN
  DBMS_RLS.DROP_GROUPED_POLICY(
    object_schema => 'hr',
    object_name   => 'employees',
    policy_group  => 'admin_group',
    policy_name   => 'emp_dept_policy');
END;
/
```
