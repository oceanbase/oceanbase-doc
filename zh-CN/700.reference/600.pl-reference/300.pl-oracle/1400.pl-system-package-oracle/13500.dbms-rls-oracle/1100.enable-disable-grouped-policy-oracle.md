# ENABLE_GROUPED_POLICY / DISABLE_GROUPED_POLICY

`ENABLE_GROUPED_POLICY` 过程用于启用指定策略组中的策略。`DISABLE_GROUPED_POLICY` 过程用于禁用指定策略组中的策略。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

### ENABLE_GROUPED_POLICY

```sql
DBMS_RLS.ENABLE_GROUPED_POLICY(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    group_name    IN VARCHAR2,
    policy_name   IN VARCHAR2,
    enable        IN BOOLEAN := TRUE);
```

### DISABLE_GROUPED_POLICY

```sql
DBMS_RLS.DISABLE_GROUPED_POLICY(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    group_name    IN VARCHAR2,
    policy_name   IN VARCHAR2);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| object_schema | 表或视图所属的模式名称。默认为 `NULL`，表示当前模式。 |
| object_name   | 表或视图的名称。 |
| group_name    | 策略组名称。 |
| policy_name   | 策略名称。 |
| enable        | 设置为 `TRUE` 启用策略，`FALSE` 禁用策略。仅适用于 `ENABLE_GROUPED_POLICY`。 |

## 示例

```sql
-- 启用分组策略
BEGIN
  DBMS_RLS.ENABLE_GROUPED_POLICY(
    object_schema => 'hr',
    object_name   => 'employees',
    group_name    => 'admin_group',
    policy_name   => 'emp_dept_policy',
    enable        => TRUE);
END;
/

-- 禁用分组策略
BEGIN
  DBMS_RLS.DISABLE_GROUPED_POLICY(
    object_schema => 'hr',
    object_name   => 'employees',
    group_name    => 'admin_group',
    policy_name   => 'emp_dept_policy');
END;
/
```
