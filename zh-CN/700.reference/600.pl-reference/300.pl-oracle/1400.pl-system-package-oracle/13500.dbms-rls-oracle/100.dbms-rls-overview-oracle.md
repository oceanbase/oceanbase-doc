# DBMS_RLS 概述

`DBMS_RLS` 系统包提供行级安全（Row-Level Security）管理功能。通过该包，您可以为数据库表或视图定义安全策略，控制用户对数据行的访问权限。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## DBMS_RLS 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_RLS` 子程序以及简要描述。

|        子程序            |      描述       |
|--------------------------|---------------|
| [ADD_POLICY](200.add-policy-oracle.md) | 为表或视图添加细粒度访问控制策略。 |
| [DROP_POLICY](300.drop-policy-oracle.md) | 删除指定表或视图上的安全策略。 |
| [ENABLE_POLICY](400.enable-policy-oracle.md) | 启用或禁用指定表或视图上的安全策略。 |
| [ALTER_POLICY](500.alter-policy-oracle.md) | 修改策略的命名空间和属性关联。 |
| [ADD_POLICY_CONTEXT](600.policy-context-oracle.md) | 为策略添加上下文关联。 |
| [DROP_POLICY_CONTEXT](600.policy-context-oracle.md) | 删除策略的上下文关联。 |
| [REFRESH_POLICY](700.refresh-policy-oracle.md) | 刷新指定策略。 |
| [REFRESH_GROUPED_POLICY](700.refresh-policy-oracle.md) | 刷新分组策略。 |
| [CREATE_POLICY_GROUP](800.policy-group-oracle.md) | 创建策略组。 |
| [DELETE_POLICY_GROUP](800.policy-group-oracle.md) | 删除策略组。 |
| [ADD_GROUPED_POLICY](900.add-grouped-policy-oracle.md) | 向指定策略组添加策略。 |
| [DROP_GROUPED_POLICY](1000.drop-grouped-policy-oracle.md) | 从指定策略组删除策略。 |
| [ENABLE_GROUPED_POLICY](1100.enable-disable-grouped-policy-oracle.md) | 启用指定策略组中的策略。 |
| [DISABLE_GROUPED_POLICY](1100.enable-disable-grouped-policy-oracle.md) | 禁用指定策略组中的策略。 |
| [ALTER_GROUPED_POLICY](1200.alter-grouped-policy-oracle.md) | 修改分组策略的命名空间和属性关联。 |
