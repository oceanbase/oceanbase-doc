# CREATE_POLICY_GROUP / DELETE_POLICY_GROUP

`CREATE_POLICY_GROUP` 过程用于创建策略组。`DELETE_POLICY_GROUP` 过程用于删除策略组。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

### CREATE_POLICY_GROUP

```sql
DBMS_RLS.CREATE_POLICY_GROUP(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    policy_group  IN VARCHAR2);
```

### DELETE_POLICY_GROUP

```sql
DBMS_RLS.DELETE_POLICY_GROUP(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    policy_group  IN VARCHAR2);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| object_schema | 表或视图所属的模式名称。默认为 `NULL`，表示当前模式。 |
| object_name   | 表或视图的名称。 |
| policy_group  | 策略组名称。 |

## 示例

```sql
-- 创建策略组
BEGIN
  DBMS_RLS.CREATE_POLICY_GROUP(
    object_schema => 'hr',
    object_name   => 'employees',
    policy_group  => 'admin_group');
END;
/

-- 删除策略组
BEGIN
  DBMS_RLS.DELETE_POLICY_GROUP(
    object_schema => 'hr',
    object_name   => 'employees',
    policy_group  => 'admin_group');
END;
/
```
