# ADD_POLICY_CONTEXT / DROP_POLICY_CONTEXT

`ADD_POLICY_CONTEXT` 过程用于为策略添加上下文关联。`DROP_POLICY_CONTEXT` 过程用于删除策略的上下文关联。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## 语法

### ADD_POLICY_CONTEXT

```sql
DBMS_RLS.ADD_POLICY_CONTEXT(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    namespace     IN VARCHAR2,
    attribute     IN VARCHAR2);
```

### DROP_POLICY_CONTEXT

```sql
DBMS_RLS.DROP_POLICY_CONTEXT(
    object_schema IN VARCHAR2 := NULL,
    object_name   IN VARCHAR2,
    namespace     IN VARCHAR2,
    attribute     IN VARCHAR2);
```

## 参数说明

| 参数 | 说明 |
|------|------|
| object_schema | 表或视图所属的模式名称。默认为 `NULL`，表示当前模式。 |
| object_name   | 表或视图的名称。 |
| namespace     | 命名空间。 |
| attribute     | 属性。 |

## 示例

```sql
-- 添加策略上下文
BEGIN
  DBMS_RLS.ADD_POLICY_CONTEXT(
    object_schema => 'hr',
    object_name   => 'employees',
    namespace     => 'emp_ns',
    attribute     => 'dept');
END;
/

-- 删除策略上下文
BEGIN
  DBMS_RLS.DROP_POLICY_CONTEXT(
    object_schema => 'hr',
    object_name   => 'employees',
    namespace     => 'emp_ns',
    attribute     => 'dept');
END;
/
```
