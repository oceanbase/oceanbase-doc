# SQL Transpiler

SQL Transpiler 功能旨在通过将 PL/SQL 函数自动转换为 SQL 表达式, 来减少 SQL 查询中函数调用的开销, 使得数据库在处理复杂查询时能够更高效地利用底层执行引擎, 提高查询执行效率。

## 启用 SQL Transpiler 功能

要启用 SQL Transpiler 功能，需要设置名为 `SQL_TRANSPILER` 的变量。此变量可以在 Global 级别或 Session 级别进行设置，以便灵活控制 SQL Transpiler 的启用状态。更多关于该变量的介绍请参考 [SQL_TRANSPILER](../../../../700.reference/800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/13050.sql_transpiler-global.md)

## 转换机制

SQL Transpiler 主要针对那些在 SQL 查询中经常被调用的 PL/SQL 函数。通过分析函数内部的逻辑, 系统会判断是否可以将其直接转换为 SQL 运算。例如, 如果函数内仅包含简单的算术运算或字符串处理, SQL Transpiler 就会将其转换为相应的 SQL 表达式。这样不仅能够减少上下文切换带来的性能损耗, 还能使查询计划更加简洁明了, 便于数据库优化器进行更高效的执行计划生成。

## 示例

1. 执行如下命令，创建一个名为 `add_numbers` 的函数。

    ```shell
    obclient> create function add_numbers(a int, b int)
    returns int
    begin
    return a + b;
    end;
    /
    ```

2. 执行如下命令查看未启用优化时的执行计划。

    ```shell
    obclient> EXPLAIN SELECT add_numbers(1, 2) FROM dual;
    Query Plan
    ==========================================
    |ID|OPERATOR  |NAME|EST.ROWS|EST.TIME(us)|
    ------------------------------------------
    |0 |EXPRESSION|    |1       |1           |
    ==========================================
    Outputs & filters:
    -------------------------------------
      0 - output([add_numbers(cast(1, INT(11, 0)), cast(2, INT(11, 0)))]), filter(nil)
          values({add_numbers(cast(1, INT(11, 0)), cast(2, INT(11, 0)))})
    ```

3. 查询验证结果。

    ```shell
    obclient> SELECT add_numbers(1, 2) FROM dual;
    +-------------------+
    | add_numbers(1, 2) |
    +-------------------+
    |                 3 |
    +-------------------+
    ```

4. 启用 SQL Transpiler 优化。

    ```shell
    obclient> SET sql_transpiler = 'on';
    ```

5. 查看启用优化后的执行计划。

    ```shell
    obclient> EXPLAIN SELECT add_numbers(1, 2) FROM dual;
    Query Plan
    ==========================================
    |ID|OPERATOR  |NAME|EST.ROWS|EST.TIME(us)|
    ------------------------------------------
    |0 |EXPRESSION|    |1       |1           |
    ==========================================
    Outputs & filters:
    -------------------------------------
      0 - output([column_conv(INT,PS:(11,0),NULL,cast(:0, INT(-1, 0))) + column_conv(INT,PS:(11,0),NULL,cast(:1, INT(-1, 0)))]), filter(nil)
          values({column_conv(INT,PS:(11,0),NULL,cast(:0, INT(-1, 0))) + column_conv(INT,PS:(11,0),NULL,cast(:1, INT(-1, 0)))})
    ```

    启用优化后的执行计划输出变为 `output([column_conv(INT...) + column_conv(INT...)])`。优化器的输出清楚地表明，原先的 `add_numbers(1, 2)` 函数调用已经被替换成了直接的加法表达式 `:0 + :1`（其中 :0 和 :1 代表参数占位符）。这正是 SQL Transpiler 起作用的核心表现。

6. 验证优化后的查询结果。

    ```shell
    obclient> SELECT add_numbers(1, 2) FROM dual;
    +------------------+
    | ADD_NUMBERS(1,2) |
    +------------------+
    |                3 |
    +------------------+
    ```
