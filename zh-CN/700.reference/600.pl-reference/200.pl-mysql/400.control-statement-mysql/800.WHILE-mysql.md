# WHILE

`WHILE` 语句用于构造条件循环语句，只要条件为 True 就重复执行语句列表。

## 语法

```sql
[begin_label:] WHILE search_condition DO
    statement_list
END WHILE [end_label]
```

## 参数解释

| **参数名称** | **说明** |
|--------------|----------|
| begin_label | 可选，循环开始处的标签名称。 |
| search_condition | 条件表达式，在每次循环迭代开始时计算。如果结果为 True，则执行 `statement_list`；如果为 False，则退出循环。 |
| statement_list | 要重复执行的 SQL/PL 语句列表。每个语句以分号（;）结尾。 |
| end_label | 可选，循环结束处的标签名称，必须与 `begin_label` 相同。 |

只要 `search_condition` 表达式为 True，`WHILE` 语句中的 `statement_list` 就会重复执行。`statement_list` 由一个或多个 SQL 语句组成，每个 SQL 语句以分号（;）结尾。可以使用 `label` 标记 `WHILE` 语句。

## 示例

**示例 1：基本的 WHILE 循环。**

```sql
obclient> DELIMITER //

obclient> CREATE PROCEDURE while_proc()
    BEGIN
        DECLARE v1 INT DEFAULT 10;
        WHILE v1 > 0 DO
            SET v1 = v1 - 1;
        END WHILE;
        SELECT v1;
    END //

obclient> DELIMITER ;

obclient> CALL while_proc();
```

查询结果如下：

```sql
+------+
| v1   |
+------+
|    0 |
+------+
1 row in set
```

**示例 2：使用标签的 WHILE 循环。**

```sql
obclient> DELIMITER //

obclient> CREATE PROCEDURE labeled_while()
    BEGIN
        DECLARE counter INT DEFAULT 0;
        DECLARE sum_result INT DEFAULT 0;
        while_label: WHILE counter < 10 DO
            SET counter = counter + 1;
            SET sum_result = sum_result + counter;
        END WHILE while_label;
        SELECT sum_result;
    END //

obclient> DELIMITER ;

obclient> CALL labeled_while();
```

查询结果如下：

```sql
+------------+
| sum_result |
+------------+
|         55 |
+------------+
1 row in set
```

**示例 3：在存储函数中使用 WHILE。**

```sql
obclient> DELIMITER //

obclient> CREATE FUNCTION factorial(n INT)
    RETURNS INT
    DETERMINISTIC
    BEGIN
        DECLARE result INT DEFAULT 1;
        DECLARE i INT DEFAULT 1;
        WHILE i <= n DO
            SET result = result * i;
            SET i = i + 1;
        END WHILE;
        RETURN result;
    END //

obclient> DELIMITER ;

obclient> SELECT factorial(5);
```

查询结果如下：

```sql
+------------+
| factorial(5) |
+------------+
|        120 |
+------------+
1 row in set
```
