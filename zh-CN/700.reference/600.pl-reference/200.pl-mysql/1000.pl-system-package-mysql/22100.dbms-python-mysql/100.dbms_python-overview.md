# DBMS_PYTHON 概述

`DBMS_PYTHON` 用于在数据库内集成和管理 Python 程序，支持 Python 存储过程、函数及安全策略的实现。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 OceanBase 数据库 V4.4.1 版本开始引入。</p>
</main>

## DBMS_PYTHON 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_PYTHON` 子程序以及简要描述。

|                **子程序**             |                 **描述**                       |
|-----------------------------------------|------------------------------------------------|
|[DROPPYTHON](200.dbms_python_droppython-mysql.md)|用于创建 Python 外部资源。|
|[LOADPYTHON](300.dbms_python_loadpython-mysql.md)|用于删除 Python 外部资源。|
