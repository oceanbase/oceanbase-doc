# DISPLAY_PROFILE

`DISPLAY_PROFILE` 用于展示 SQL 执行计划的性能分析数据，可查看指定 `trace_id` 对应的执行的算子级诊断信息。

## 语法

```sql
DBMS_XPROFILE.DISPLAY_PROFILE(
    trace_id    varchar2 default null,
    tenant_id   integer default 0,
    format      varchar2 default 'AGGREGATED',
    level       integer default 1,
    svr_ip      varchar2 default null,
    svr_port    integer default 0,
    op_id       integer default null
    )
```

## 参数说明

| **参数**  | **说明** |
|-----------|----------|
| trace_id  | 可选项，指定 trace id。展示指定 `trace_id` 下的 profile，省略、填 `null` 或者填 "" 时，默认选择当前 Session 上的 last trace id。|
| tenant_id | 可选项，指定租户 ID。省略或者填 0 时，默认选择当前当前租户 ID。除了系统租户外，用户租户指定了其他租户 ID 将会返回空结果。|
| format    | 可选项，指定展示形式。取值如下：<ul><li>`AGGREGATED`：默认值，表示展示聚合后的 profile。</li><li>`ORIGINAL`：表示输出聚合前的线程级 profile。</li></ul>|
| level     | 可选项，指定输出等级。每个指标都有各自的等级，高于 level 的指标将不会展示出来。取值如下：<ul><li>0：表示核心指标，一定会输出，比如吐行、dbtime 之类的信息。</li><li>1：默认值，表示标准指标，常用的一些指标可以设置为该等级。</li><li>2：表示排查指标，用于定位 BUG 或者进一步分析时用的指标，不常用，输出信息太多。</li></ul>|
| svr_ip    | 可选项，筛选只显示某个 IP 上的 profile。默认值为 `null`，表示全输出。|
| svr_port  | 可选项，筛选只显示某个 port 上的 profile。默认值为 0，表示全输出。|
| op_id     | 可选项，筛选只展示计划中编号为 ID 的算子的 profile。默认值为 `null`，表示全输出。|

## 示例

* sys 租户中查看其他租户的 profile。

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC30589818-0-0', tenant_id);
    ```

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>只有 sys 租户才能查其他租户的 profile, 必须要指定 <code>tenant_id</code>。</p>
    </main>

* 用户租户（MySQL 模式）查询自己的 profile。

    ```shell
    obclient> SELECT DBMS_XPROFILE.DISPLAY_PROFILE('Y7A8B64586C10-00063BAC30589818-0-0');
    ```
