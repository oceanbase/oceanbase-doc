# CLEAR_TABLEGROUP_BALANCE_WEIGHT

子程序 `CLEAR_TABLEGROUP_BALANCE_WEIGHT` 用于删除 `SHARDING NONE` 类型表组的权重。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V4.4.1 版本开始支持引入。</p>
</main>

## 语法

```sql
DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT(
    tablegroup_name       VARCHAR(65535)
    );
```

## 参数说明

| 参数 | 说明 |
|------|------|
| tablegroup_name | 表组名称。|

## 使用说明

`DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT` 指定名称删除 sharding none 表组权重。

## 示例

* 在 sys 租户中调用，删除租户 `mysql` 下表组 `TG_TD_test` 的权重。

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test') TENANT = 'mysql';
    ```

* 在用户租户调用，删除本租户下表组 `TG_TD_test` 的权重。

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test');
    ```
