# DBMS_JAVA 概述

`DBMS_JAVA` 用于在数据库内集成和管理 Java 程序，支持 Java 存储过程、函数及安全策略的实现。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 OceanBase 数据库 V4.4.0 版本开始引入。</p>
</main>

## DBMS_JAVA 权限说明

禁止 Java UDF 访问，`DBMS_JAVA` 包现在不支持访问文件和网络。

## DBMS_JAVA 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_JAVA` 子程序以及简要描述。

|                **子程序**             |                 **描述**                       |
|-----------------------------------------|------------------------------------------------|
| [LOADJAVA](200.loadjava-mysql.md) | 用于将 Jar 包作为外部资源上传到 OBServer。 |
| [DROPJAVA](300.dropjava-mysql.md) | 用于删除上传的外部资源 Jar 包。|
