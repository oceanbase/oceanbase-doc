# LOADJAVA

`DBMS_JAVA.LOADJAVA` 用于将 Jar 包作为外部资源上传到 OBServer。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该系统包从 OceanBase 数据库 V4.4.0 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_JAVA.LOADJAVA(IN jar_name VARCHAR(65535), IN content LONGBLOB, IN comment VARCHAR(65535) DEFAULT '');
```

## 参数说明

| **参数**           | **说明**                                            |
|------------------|-----------------------------------------------------|
| jar_name |对应外部资源名称，您可以在 `DBA_OB_EXTERNAL_RESOURCES` 或 `CDB_OB_EXTERNAL_RESOURCES` 视图中查询。|
| content | jar 包的 binary 内容。|
| comment | 可选，表示注释，您也可以在 `DBA_OB_EXTERNAL_RESOURCES` 或 `CDB_OB_EXTERNAL_RESOURCES` 视图中查询。|

## 使用说明

调用 `DBMS_JAVA.LOADJAVA` 系统包将 Jar 包作为外部资源上传到 OBServer。此过程需要接受三个参数：

1. 资源名称，您可以自定义资源名，此资源名不区分大小写，并且在当前 Database 下必须是唯一的。可以通过这个资源名引用此外部资源。
2. 资源的 binary，即 Jar 包的二进制内容。
3. 资源的注释，您可以自定义注释内容。

## 示例

使用 `DBMS_JAVA.LOADJAVA` 过程加载 JAR 包。

```java
String url = "<URL to Jar>";
InputStream is = new URL(url).openStream();

// conn is a connection to OceanBase
PreparedStatement ps = conn.prepareStatement("call dbms_java.loadjava(? ,? ,? )");
ps.setString(1, "my_add_jar");
ps.setBlob(2, is);
ps.setString(3, "my add UDF jar");

ps.execute();
```
