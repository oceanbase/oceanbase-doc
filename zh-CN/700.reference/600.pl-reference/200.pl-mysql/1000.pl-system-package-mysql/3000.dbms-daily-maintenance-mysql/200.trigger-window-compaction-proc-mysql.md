# TRIGGER_WINDOW_COMPACTION_PROC

`TRIGGER_WINDOW_COMPACTION_PROC` 子程序用于手动触发窗口合并。

## 语法

```sql
DBMS_DAILY_MAINTENANCE.TRIGGER_WINDOW_COMPACTION_PROC();
```

## 使用说明

* 仅允许用户租户发起，系统租户（`sys` 租户）不支持。

* 要手动触发窗口合并，要求已开启窗口合并功能（租户级配置项 [enable_window_compaction](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3150.enable_window_compaction.md) 的值为 `True`）且已启用窗口合并任务（`DAILY_MAINTENANCE_WINDOW`）。

* 该语句仅用于手动触发一次窗口合并，不会指定任务的结束时间，任务的结束时间由窗口合并任务（DAILY_MAINTENANCE_WINDOW）的 `max_run_duration` 属性决定，用户可以通过 `DBMS_SCHEDULER.SET_ATTRIBUTE` 子程序中窗口合并任务（DAILY_MAINTENANCE_WINDOW）的 `duration` 参数来进行设置。

## 示例

用户租户手动触发一次窗口合并。

```shell
obclient(root@mysql001)[(none)]> DBMS_DAILY_MAINTENANCE.TRIGGER_WINDOW_COMPACTION_PROC();
```
