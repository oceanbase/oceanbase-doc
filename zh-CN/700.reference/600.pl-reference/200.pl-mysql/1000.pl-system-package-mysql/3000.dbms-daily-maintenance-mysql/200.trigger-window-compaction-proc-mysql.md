# TRIGGER_WINDOW_COMPACTION_PROC

`TRIGGER_WINDOW_COMPACTION_PROC` 子程序用于触发一次窗口合并。

## 使用限制

仅允许用户租户发起，系统租户（`sys`）租户不支持。

## 语法

```sql
DBMS_DAILY_MAINTENANCE.TRIGGER_WINDOW_COMPACTION_PROC();
```

## 使用说明

该语句仅用于手动开启一次窗口合并，不会指定任务的结束时间，任务结束时间由 `DBMS_SCHEDULER.SET_ATTRIBUTE` 子程序中的 `duration` 属性决定。

## 示例

用户租户触发一次窗口合并。

```shell
obclient(root@mysql001)[(none)]> DBMS_DAILY_MAINTENANCE.TRIGGER_WINDOW_COMPACTION_PROC();
```
