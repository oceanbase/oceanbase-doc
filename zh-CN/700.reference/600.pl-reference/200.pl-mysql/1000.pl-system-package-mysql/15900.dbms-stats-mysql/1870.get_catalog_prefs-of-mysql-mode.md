# GET_CATALOG_PREFS

`GET_CATALOG_PREFS` 用于获取 Catalog 中表级偏好项的值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V5.0.1 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_STATS.GET_CATALOG_PREFS (
    pname           VARCHAR(65535),
    catname         VARCHAR(65535),
    dbname          VARCHAR(65535),
    tabname         VARCHAR(65535)
    ) RETURN VARCHAR(65535);
```

## 参数说明

| **参数** | **解释** |
|----------|----------|
| pname    | 指定要获取的偏好项名称。当前版本 Catalog 中仅支持偏好项 `CATALOG_STATS_BATCH_SIZE`。|
| catname  | 指定 Catalog 名称。|
| dbname   | 指定 Database 名称。|
| tabname  | 指定表名称。|

## 示例

```shell
obclient> SELECT DBMS_STATS.GET_CATALOG_PREFS (
    'CATALOG_STATS_BATCH_SIZE',
    'hive_catalog',
    'oss_tpch_1000g_hive_parquet_month_part_without_compression',
    'lineitem'
    );
```
