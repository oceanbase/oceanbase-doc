# SET_CATALOG_TABLE_PREFS

`SET_CATALOG_TABLE_PREFS` 用于设置 Catalog 中表级偏好项的值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V5.0.1 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_STATS.SET_CATALOG_TABLE_PREFS (
    catname        VARCHAR(65535),
    dbname         VARCHAR(65535),
    tabname        VARCHAR(65535),
    pname          VARCHAR(65535),
    pvalue         VARCHAR(65535)
    );
```

## 参数说明

| **参数** | **解释** |
|----------|----------|
| catname  | 指定 Catalog 名称。|
| dbname   | 指定 Database 名称。|
| tabname  | 指定表名称。|
| pname    | 指定要设置的偏好项名称，取值如下：<ul><li>`CATALOG_STATS_BATCH_SIZE`：用于指定在一次 Catalog 统计信息收集任务中，最多可并入处理的分区（`partition`）数量。</li></ul>|
| pvalue   | 指定偏好项的值。|

## 示例

设置 Catalog 名称 `hive_catalog` 和 Database 名称 `test_oss` 下表 `lineitem` 的 `CATALOG_STATS_BATCH_SIZE` 值为 `100`。

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'test_oss',
    'lineitem',
    'CATALOG_STATS_BATCH_SIZE',
    100
);
```
