# GET_CATALOG_GLOBAL_PREFS

`GET_CATALOG_GLOBAL_PREFS` 用于获取 Catalog 中全局偏好项的值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V5.0.1 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_STATS.GET_CATALOG_GLOBAL_PREFS (
    pname          VARCHAR(65535)
    ) RETURN VARCHAR(65535);
```

## 参数说明

| **参数** | **解释** |
|----------|----------|
| pname    | 指定要获取的偏好项名称，取值如下：<ul><li>`CATALOG_STATS_BATCH_SIZE`：用于指定在一次 Catalog 统计信息收集任务中，最多可并入处理的分区（`partition`）数量。</li></ul>|

## 示例

获取 Catalog 中全局偏好值。

```shell
obclient> SELECT DBMS_STATS.GET_CATALOG_GLOBAL_PREFS('CATALOG_STATS_BATCH_SIZE');
```

返回结果如下：

```shell
+-----------------------------------------------------------------+
| DBMS_STATS.GET_CATALOG_GLOBAL_PREFS('CATALOG_STATS_BATCH_SIZE') |
+-----------------------------------------------------------------+
| 100                                                             |
+-----------------------------------------------------------------+
1 row in set
```
