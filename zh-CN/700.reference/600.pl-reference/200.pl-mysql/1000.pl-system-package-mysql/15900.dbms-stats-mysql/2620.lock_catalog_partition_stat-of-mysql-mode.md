# LOCK_CATALOG_PARTITION_STAT

`LOCK_CATALOG_PARTITION_STAT` 用于锁定 Catalog 中分区统计信息。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V5.0.1 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_STATS.LOCK_CATALOG_PARTITION_STAT (
    catname            VARCHAR(65535),
    dbname             VARCHAR(65535),
    tabname            VARCHAR(65535),
    partname           VARCHAR(65535)
    );
```

## 参数说明

| **参数** | **解释** |
|----------|----------|
| catname  | 指定 Catalog 名称。|
| dbname   | 指定 Database 名称。|
| tabname  | 指定表名称。|
| partname | 指定分区名称。`NULL` 表示全表。|

## 示例

锁定 Catalog 名称 `hive_catalog` 和 Database 名称 `oss_tpch_1000g_hive_parquet_month_part_without_compression` 下表 `lineitem` 的分区 `l_shipdate=1998-01-01` 的统计信息。

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'oss_tpch_1000g_hive_parquet_month_part_without_compression',
    'lineitem',
    'l_shipdate=1998-01-01'
);
```
