# LOCK_CATALOG_TABLE_STAT

`LOCK_CATALOG_TABLE_STAT` 用于锁定 Catalog 中外表统计信息。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 V5.0.1 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_STATS.LOCK_CATALOG_TABLE_STAT (
    catname            VARCHAR(65535),
    dbname             VARCHAR(65535),
    tabname            VARCHAR(65535),
    partname           VARCHAR(65535) DEFAULT NULL,
    stattype           VARCHAR(65535) DEFAULT 'ALL'
    );
```

## 参数说明

| **参数** | **解释** |
|----------|----------|
| catname  | 指定 Catalog 名称。|
| dbname   | 指定 Database 名称。|
| tabname  | 指定要锁定表名称。|
| partname | 指定分区名称。`NULL` 表示全表。|
| stattype | 指定加锁的信息类型，即要针对哪一类统计信息加锁，取值如下：<ul><li>`ALL`：默认值，表示全部统计信息（映射 `TABLE_ALL_TYPE`）。</li><li>`DATA`：表示数据统计信息（映射 `DATA_TYPE`，比如行数、数据量这类）。</li><li>`CACHE`：表示缓存统计信息（映射 `CACHE_TYPE`）。</li><li>空字符串也按 `ALL` 取值处理。</li></ul>|

## 示例

锁定 Catalog 名称 `hive_catalog` 和 Database 名称 `test_oss` 下表 `lineitem` 全表的统计信息，锁类型为 `ALL`。

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'test_oss',
    'lineitem',
    NULL
    'ALL'
);
```
