# DROP_AI_MODEL

`DROP_AI_MODEL` 过程用于删除 AI 模型对象。

## 语法

```sql
PROCEDURE drop_ai_model(
    IN name VARCHAR(128));
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可空 |
|------|------|------|----------|----------|
| name | AI 模型对象的名称。 | VARCHAR(128) |  | No |

## 示例

删除 AI 模型对象。

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('my_ai_model_1');
```
