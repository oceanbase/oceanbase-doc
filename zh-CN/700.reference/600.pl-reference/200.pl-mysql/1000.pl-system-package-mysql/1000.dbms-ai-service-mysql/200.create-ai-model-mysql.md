# CREATE_AI_MODEL

`CREATE_AI_MODEL` 过程用于创建 AI 模型对象，需指定模型的名称、类型等属性。

## 语法

```sql
PROCEDURE create_ai_model(
    IN name VARCHAR(128), 
    IN params JSON);
```

## 示例

创建 AI 模型对象，类型为 `dense_embedding`，大模型为 `text-embedding-v2`。

```sql
CALL DBMS_AI_SERVICE.CREATE_AI_MODEL (
'my_ai_model_1', '{
    "type": "dense_embedding",
    "model_name": "text-embedding-v2"
  }');
```
