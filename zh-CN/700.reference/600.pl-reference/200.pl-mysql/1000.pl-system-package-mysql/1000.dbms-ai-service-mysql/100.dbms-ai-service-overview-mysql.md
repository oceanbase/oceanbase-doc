# DBMS_AI_SERVICE 概述

`DBMS_AI_SERVICE` 系统包用于管理 AI 服务，包括 AI 模型对象和 AI 模型服务连接点对象。

## DBMS_AI_SERVICE 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_AI_SERVICE` 子程序和简要描述。

| **子程序** | **描述** |
| --- | --- |
| [CREATE_AI_MODEL](200.create-ai-model-mysql.md) | 创建一个 AI 模型对象。 |
| [DROP_AI_MODEL](300.drop-ai-model-mysql.md) | 删除一个 AI 模型对象。 |
| [CREATE_AI_MODEL_ENDPOINT](400.create-ai-model-endpoint-mysql.md) | 创建一个 AI 模型服务端点对象。 |
| [ALTER_AI_MODEL_ENDPOINT](500.alter-ai-model-endpoint-mysql.md) | 修改一个 AI 模型服务端点对象。 |
| [DROP_AI_MODEL_ENDPOINT](600.drop-ai-model-endpoint-mysql.md) | 删除一个 AI 模型服务端点对象。 |
