# REFRESH_REPORT

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，从 V4.4.2 BP2 版本开始引入 <code>REFRESH_REPORT</code>。</p>
</main>

`REFRESH_REPORT` 用于生成单次物化视图刷新任务的分层诊断报告。

## 使用限制及注意事项

`refresh_id` 与 `mv_name` 至少指定其一。

## 语法

```sql
DBMS_MVIEW.REFRESH_REPORT(
    {refresh_id | mv_name}
    [, format]
    [, tenant_id])
```

## 参数解释

|  **参数**  | **说明** |
|------------|----------|
| refresh_id | 物化视图刷新批次的唯一标识符，由新调度框架分配。 <main id="notice" type='explain'><h4>说明</h4><p>可以通过视图 <a href="../../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5200.o-dba_mvref_run_stats-of-mysql-mode.md">DBA_MVREF_RUN_STATS</a> 查看 <code>refresh_id</code> 信息。</p></main>|
| mv_name | 指定物化视图的名称（如 `SCHEMA.MV_NAME`）。|
| format | 可选项，指定报告输出格式，取值如下：<ul><li>`XML`（默认值）</li><li>`JSON`</li></ul>|
| tenant_id | 当前仅 `sys` 租户可用，用于查询其他租户的物化视图刷新报告。|

## 返回值说明

* 返回类型：`CLOB`。
* 内容格式：取决于 `format` 参数，可为 `XML` 或 `JSON` 格式的文本内容。

## 示例

* 通过 `refresh_id` 获取 `XML` 格式的诊断报告。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023);
    ```

* 获取 JSON 格式的报告。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023, format => 'JSON');
    ```

* 通过物化视图名称获取最近一次刷新的报告。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(mv_name=> 'TEST.MV_SALES_DAILY');
    ```

* `sys` 租户查询其他租户的刷新报告。

    ```shell
    obclient> SELECT DBMS_MVIEW.REFRESH_REPORT(refresh_id=> 100023, tenant_id=> 1002);
    ```
