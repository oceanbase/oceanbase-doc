# SEARCH

`SEARCH` 函数用于以 Json 格式返回搜索的结果，返回结果会按照相关性进行排序。

## 语法

```sql
FUNCTION SEARCH (IN table_name VARCHAR(65535), 
                 IN search_params LONGTEXT)
RETURN JSON;
```

## 参数说明

| 参数 | 描述 | 是否必选 |
| --- | --- | --- |
| table_name | 表名，支持堆表和无主键表。| 必选 |
| search_params | 搜索参数，是 Json 格式的字符串。| 必选 |

一些其他说明：

* `bool` 表达式中的多个条件默认按 `AND` 逻辑组合。
* 在 `must`、`should`、`must_not` 和 `filter` 内部需要使用布尔逻辑时，必须嵌套 `bool` 关键字。

## 语法拓展说明

### 全文检索支持 `multi_match` 语法

全文搜索支持 `multi_match` 语法，其功能与 `query_string` 基本一致，并具有以下特点：

* 支持 `operator` 字段，其作用等同于 `query_string` 中的 `default_operator`。
* `query` 字段不支持 `^1.3` 形式的权重。分词时，任意空格和标点符号均被视为分隔符；连续的非空格非标点字符被视为一个单词。例如，`" 2yuan€€^^non-fulltext***~  "` 将被分词为 `"2yuan€€"`、`"non"`、`"fulltext"`。

### 全文检索支持 `terms` 语法

支持 `terms` 的语法解析，与 `term` 的区别是，`term` 支持精准匹配一个值，`terms` 则支持匹配指定集合中的多个值中任意一个，将其转化成 SQL 中的 `IN` 表达式。

示例如下：

```sql
-- 设置检索参数。
SET @terms_parm1 = '{
  "query": {
    "terms": {
      "category": ["fiction", "Mystery"], # 列名
      "boost" : 2.3 # 权重（可选项）
    }
  }
}';

-- 执行全文检索。
SELECT json_pretty(dbms_hybrid_search.search('books', @terms_parm1));

-- 转换成的 SQL。
SELECT book_id, title, author, category, description, price, 
vector_embedding, 
((category IN ('fiction', 'Mystery')) * 2.3) as _score 
FROM test.books 
WHERE category IN ('fiction', 'Mystery') ORDER BY _score DESC
```

### 全文与向量混合检索

创建示例表，其中包含一个向量列，并为其创建向量索引，以及分别为两个 `varchar` 列创建全文索引。

```sql
CREATE TABLE doc_table(c1 INT, vector VECTOR(3), query VARCHAR(255), content VARCHAR(255), VECTOR INDEX idx1(vector) WITH (distance=l2, type=hnsw, lib=vsag), FULLTEXT INDEX idx2(query), FULLTEXT INDEX idx3(content));
```

写入数据。

```sql
INSERT INTO doc_table VALUES(1, '[1,2,3]', "hello world", "oceanbase Elasticsearch database"),
                            (2, '[1,2,1]', "hello world, what is your name", "oceanbase mysql database"),
                            (3, '[1,1,1]', "hello world, how are you", "oceanbase oracle database"),
                            (4, '[1,3,1]', "real world, where are you from", "postgres oracle database"),
                            (5, '[1,3,2]', "real world, how old are you", "redis oracle database"),
                            (6, '[2,1,1]', "hello world, where are you from", "starrocks oceanbase database");
```

设置检索参数。

```sql
SET @parm = '{
      "query": {
        "bool": {
          "should": [
            {"match": {"query": "hi hello"}}, 
            {"match": { "content": "oceanbase mysql" }}
          ]
        }
      },
       "knn" : {
          "field": "vector",
          "k": 5,
          "query_vector": [1,2,3]
      },
      "_source" : ["query", "content", "_keyword_score", "_semantic_score"]
    }';
```

执行查询并返回查询结果。

```sql
SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm)); 
```
