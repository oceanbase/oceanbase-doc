# DBMS_HYBRID_SEARCH 概述

`DBMS_HYBRID_SEARCH` 系统包用于管理混合向量索引。

## DBMS_HYBRID_SEARCH 子函数概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_HYBRID_SEARCH` 子函数和简要描述。

| **子函数** | **描述** |
| --- | --- |
| [SEARCH](200.search-mysql.md) | 用于以 JSON 格式返回搜索的结果，返回结果会按照相关性进行排序。 |
| [GET_SQL](300.get_sql-mysql.md) | 以字符串形式返回实际执行的 SQL。 |
