## 查询关键字

您也可以通过查询 `V$OB_KEYWORDS` 视图获取当前租户的完整关键字列表，包括保留关键字和非保留关键字。有关该视图的详细说明，参见 [V$OB_KEYWORDS](../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/31470.v-ob-keywords-of-mysql-mode.md)。

* 查询所有 SQL 保留关键字：

  ```sql
  obclient> SELECT KEYWORD FROM oceanbase.V$OB_KEYWORDS WHERE TYPE = 'SQL' AND RESERVED = 1 ORDER BY KEYWORD;
  ```

* 查询所有 PL 保留关键字：

  ```sql
  obclient> SELECT KEYWORD FROM oceanbase.V$OB_KEYWORDS WHERE TYPE = 'PL' AND RESERVED = 1 ORDER BY KEYWORD;
  ```

* 查询某个标识符是否为保留关键字：

  ```sql
  obclient> SELECT KEYWORD, TYPE, RESERVED FROM oceanbase.V$OB_KEYWORDS WHERE KEYWORD = 'SELECT';
  ```
