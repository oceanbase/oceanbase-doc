# RESUME ROUTINE LOAD

## 描述

该语句用于恢复 Routine Load 任务，继续导入数据。

## 语法

```sql
RESUME ROUTINE LOAD FOR job_name;
```

## 参数说明

| **参数** |       **描述**           |
|----------|--------------------------|
| job_name | 表示要恢复 Routine Load 任务的作业名称。|

## 示例

恢复 Routine Load 作业 `load_job_0`。

```shell
obclient> RESUME ROUTINE LOAD FOR load_job_0;
```
