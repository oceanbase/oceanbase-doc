# STOP ROUTINE LOAD

## 描述

该语句用于结束 Routine Load 任务，无法恢复。

## 语法

```sql
STOP ROUTINE LOAD FOR job_name;
```

## 参数说明

| **参数** |       **描述**           |
|----------|--------------------------|
| job_name | 表示要结束 Routine Load 任务的作业名称。|

## 示例

结束 Routine Load 作业 `load_job_0`。

```shell
obclient> STOP ROUTINE LOAD FOR load_job_0;
```
