# PAUSE ROUTINE LOAD

## 语法

```sql
PAUSE ROUTINE LOAD FOR job_name;
```

## 参数说明

| **参数** |       **描述**           |
|----------|--------------------------|
| job_name | 表示要暂停 Routine Load 任务的作业名称。|

## 示例

暂停 Routine Load 任务 `load_job_0`。

```shell
obclient> PAUSE ROUTINE LOAD FOR load_job_0;
```
