# APPLY 子句

`APPLY` 是变体的 `ANSI CROSS JOIN` 或 `ANSI LEFT OUTER JOIN`，并且支持左相关（left correlation）的查询。`APPLY` 有两种形式，一个是 `OUTER APPLY`，一个是 `CROSS APPLY`。

* `CROSS APPLY` 类似于 `CROSS JOIN`，但右边可以引用左表的列（即左相关）。仅返回连接左侧表中由 `table_reference` 或 `collection_expression` 生成结果集的行。
* `OUTER APPLY` 类似于 `LEFT OUTER JOIN`，即使右侧没匹配值也会保留左表行。

## APPLY 右表约束

`APPLY` 约束：

* `table_reference`（表引用）：可以是普通表、内联视图（即子查询视图）、TABLE()。
* `collection_expression`（集合表达式）：可以是子查询、列、函数、集合构造器。
* `collection_expression` 要求：必须返回集合值, 即类型是嵌套表或可变数组。

## 使用示例

创建表 `t1` 和 `t2` 并插入几条数据。

```sql
CREATE TABLE t1 (c1 INT, c2 INT);
CREATE TABLE t2 (c1 INT, c2 INT);

INSERT INTO t1 VALUES (1, 10);
INSERT INTO t1 VALUES (2, 20);
INSERT INTO t1 VALUES (3, 30);

INSERT INTO t2 VALUES (1, 100);
INSERT INTO t2 VALUES (1, 101);
INSERT INTO t2 values (1, 102);
INSERT INTO t2 VALUES (2, 200);
```

当右表为普通表时，`CROSS APPLY` 查询结果如下：

```sql
obclient > SELECT * FROM t1 cross apply t2;
+------+------+------+------+
| C1   | C2   | C1   | C2   |
+------+------+------+------+
|    1 |   10 |    1 |  100 |
|    2 |   20 |    1 |  100 |
|    3 |   30 |    1 |  100 |
|    1 |   10 |    1 |  101 |
|    2 |   20 |    1 |  101 |
|    3 |   30 |    1 |  101 |
|    1 |   10 |    2 |  200 |
|    2 |   20 |    2 |  200 |
|    3 |   30 |    2 |  200 |
|    1 |   10 |    1 |  102 |
|    2 |   20 |    1 |  102 |
|    3 |   30 |    1 |  102 |
+------+------+------+------+
```

当右表为普通表时，`OUTER APPLY` 查询结果如下：

```sql
obclient > SELECT * FROM t1 outer apply t2;
+------+------+------+------+
| C1   | C2   | C1   | C2   |
+------+------+------+------+
|    1 |   10 |    1 |  100 |
|    1 |   10 |    1 |  101 |
|    1 |   10 |    1 |  102 |
|    1 |   10 |    2 |  200 |
|    2 |   20 |    1 |  100 |
|    2 |   20 |    1 |  101 |
|    2 |   20 |    1 |  102 |
|    2 |   20 |    2 |  200 |
|    3 |   30 |    1 |  100 |
|    3 |   30 |    1 |  101 |
|    3 |   30 |    1 |  102 |
|    3 |   30 |    2 |  200 |
+------+------+------+------+
```

当右表为子查询时，`CROSS APPLY` 查询结果如下：

```sql
obclient> SELECT * FROM t1 cross apply (SELECT * FROM t2 WHERE t1.c1 = t2.c1 AND rownum <= 2) v;
+------+------+------+------+
| C1   | C2   | C1   | C2   |
+------+------+------+------+
|    1 |   10 |    1 |  100 |
|    1 |   10 |    1 |  101 |
|    2 |   20 |    2 |  200 |
+------+------+------+------+
```

当右表为子查询时，`OUTER APPLY` 查询结果如下:

```sql
obclient> SELECT * FROM t1 outer apply (SELECT * FROM t2 WHERE t1.c1 = t2.c1 AND rownum <= 2) v;
+------+------+------+------+
| C1   | C2   | C1   | C2   |
+------+------+------+------+
|    1 |   10 |    1 |  100 |
|    1 |   10 |    1 |  101 |
|    2 |   20 |    2 |  200 |
|    3 |   30 | NULL | NULL |
+------+------+------+------+
```

当右表为函数表达式时，查询结果如下：

```sql
-- 定义嵌套表类型
CREATE TYPE t2_c2_ntt AS TABLE OF NUMBER;
/

-- 定义返回嵌套表的函数
CREATE OR REPLACE FUNCTION get_t2_c2(p_c1 INT)
  RETURN t2_c2_ntt
IS
  res t2_c2_ntt;
BEGIN
  SELECT c2
  BULK COLLECT INTO res
  FROM t2
  WHERE c1 = p_c1;
  RETURN res;
END;
/

obclient> SELECT t1.c1, t1.c2, t2item.COLUMN_VALUE AS t2_c2 FROM t1 CROSS APPLY TABLE(get_t2_c2(t1.c1)) t2item;
+------+------+-------+
| C1   | C2   | T2_C2 |
+------+------+-------+
|    1 |   10 |   100 |
|    1 |   10 |   101 |
|    1 |   10 |   102 |
|    2 |   20 |   200 |
+------+------+-------+
```

当右表为集合构造器时，查询结果如下：

```sql
obclient> SELECT t1.c1, t1.c2, t2item.COLUMN_VALUE AS t2_c2
    -> FROM t1
    -> CROSS APPLY TABLE(
    ->   CAST(MULTISET(
    ->     SELECT c2 FROM t2 WHERE t2.c1 = t1.c1
    ->   ) AS t2_c2_ntt)
    -> ) t2item;
    +------+------+-------+
    | C1   | C2   | T2_C2 |
    +------+------+-------+
    |    1 |   10 |   100 |
    |    1 |   10 |   101 |
    |    1 |   10 |   102 |
    |    2 |   20 |   200 |
    +------+------+-------+
```

当右表为 json table 时，查询结果如下：

```sql
obclient> CREATE TABLE t_json (
  id NUMBER,
  data CLOB  -- 存储JSON字符串
);

obclient> INSERT INTO t_json VALUES (1, '{"items":[{"name":"A","val":10},{"name":"B","val":20}]}');
obclient> INSERT INTO t_json VALUES (2, '{"items":[{"name":"C","val":30}]}');

obclient> SELECT
    ->   t.id,
    ->   jt.name,
    ->   jt.val
    -> FROM
    ->   t_json t
    -> CROSS APPLY
    ->   JSON_TABLE(
    ->     t.data,
    ->     '$.items[*]'
    ->     COLUMNS (
    ->       name VARCHAR2(10) PATH '$.name',
    ->       val  NUMBER       PATH '$.val'
    ->     )
    ->   ) jt;
    +------+------+------+
    | ID   | NAME | VAL  |
    +------+------+------+
    |    1 | A    |   10 |
    |    1 | B    |   20 |
    |    2 | C    |   30 |
    +------+------+------+
```
