# DROP CATALOG

## 描述

该语句用于删除外部数据目录（External Catalog）。

## 权限要求

执行 `DROP CATALOG` 语句，需要当前用户拥有 `CREATE CATALOG` 权限。有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 语法

```sql
DROP CATALOG external_catalog_name;
```

## 参数说明

|        **参数**       | **描述** |
|-----------------------|----------|
| external_catalog_name | 指定要删除的外部数据目录的名称。|

## 示例

```sql
DROP CATALOG test_odps_catalog;
```
