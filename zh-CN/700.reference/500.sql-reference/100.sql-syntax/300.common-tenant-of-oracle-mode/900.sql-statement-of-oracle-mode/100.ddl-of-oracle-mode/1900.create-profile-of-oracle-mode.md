# CREATE PROFILE

## 描述

该语句用于创建配置文件。配置文件是对数据库资源的一组限制，如果将配置文件分配给用户，则该用户不能超过这些使用限制。限制项包括资源限制参数（如会话最大空闲时间 `IDLE_TIME`）和密码管理参数。

## 语法

```sql
CREATE [WITH HINT] PROFILE [profile_name | DEFAULT] LIMIT
  { FAILED_LOGIN_ATTEMPTS { integer | UNLIMITED | DEFAULT }
  | IDLE_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_LOCK_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_LIFE_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_VERIFY_FUNCTION { function_name | NULL }
  | PASSWORD_GRACE_TIME { integer | UNLIMITED | DEFAULT }
  | PASSWORD_ROLLOVER_TIME { bigint(20) | UNLIMITED | DEFAULT }
  }
  [, ...]
```

## 参数解释

|          参数           |               描述                |
|-----------------------|---------------------------------|
| WITH HINT             | 可选，指定查询优化器使用的提示信息。                  |
| profile_name          | 指定要创建的配置文件的名称。可以是普通标识符、非保留关键字或 `DEFAULT`。                  |
| FAILED_LOGIN_ATTEMPTS | 指定在锁定账户之前允许的连续失败登录尝试次数。                |
| IDLE_TIME | 指定会话的最大空闲时间，单位为分钟。正整数表示会话空闲超过该时间后由数据库主动断开连接，并覆盖 `wait_timeout` 与 `interactive_timeout`；`0` 表示该参数不生效，空闲超时由 `wait_timeout` 控制（交互式连接为 `interactive_timeout`）；`UNLIMITED` 表示不限制空闲时间；`DEFAULT` 表示继承 `DEFAULT` profile 的取值。<main id="notice" type='explain'><h4>说明</h4><ul><li>对于 V4.4.x 版本，该参数从 V4.4.2 BP4 版本开始支持。</li><li>Oracle 中 <code>IDLE_TIME</code> 为 <code>0</code> 时，表示不限制空闲时间，OceanBase 中 <code>0</code> 表示该参数不生效；需要不限制空闲时间时，请设置为 <code>UNLIMITED</code>。</li></ul></main> |
| PASSWORD_LOCK_TIME    | 指定账户因登录失败被锁定的天数。 |
| PASSWORD_LIFE_TIME    | 指定密码的有效期（天）。             |
| PASSWORD_VERIFY_FUNCTION | 指定用于验证密码的函数。 |
| PASSWORD_GRACE_TIME   | 指定密码过期后的宽限期（天），在此期间用户仍可使用旧密码登录但会收到警告。          |
| PASSWORD_ROLLOVER_TIME | 指定密码轮转有效期，单位为天。在轮转有效期内，旧密码与新密码可同时用于认证。取值 `0` 表示禁用旧密码认证。<main id="notice" type="explain"><h4>说明</h4><p>该参数从 V4.4.2 BP1 版本开始支持；从 V4.4.2 BP4 版本开始校验参数取值：非 0 时取值范围为 10 秒 ~ 60 天，且不能大于 <code>PASSWORD_LIFE_TIME</code>，也不能大于非 0 且非 <code>UNLIMITED</code> 的 <code>PASSWORD_GRACE_TIME</code>，否则报错。</p></main> |
| integer               | 指定参数的具体整数值。             |
| UNLIMITED             | 指定参数无限制。                   |
| DEFAULT               | 使用系统默认值。                   |
| NULL                  | 将参数设置为 NULL。                  |
| function_name         | 指定验证函数的名称。                  |

## 使用限制及注意事项

* `IDLE_TIME` 仅适用于 OceanBase 数据库 Oracle 模式，MySQL 模式下不生效。

* `IDLE_TIME` 只限制会话的空闲时间。会话正在执行 SQL 时不计入空闲时间，长时间运行的查询不受该参数约束。

* `IDLE_TIME` 在连接建立时读取一次，修改后只对新建的会话生效，已建立的会话不受影响。

* 实际断开连接的时间最多比 `IDLE_TIME` 晚 5 秒。

* 负数会直接报错；`IDLE_TIME 1.5` 这类非整数值会报错。

* `DEFAULT` profile 自身不能用 `IDLE_TIME DEFAULT` 指定，否则会报无效的资源限制错误。

## 示例

创建密码限制的配置文件 `profile1`，并将 `FAILED_LOGIN_ATTEMPTS` 设置为 `5` 次，`PASSWORD_LOCK_TIME` 设置为 `1` 天，`PASSWORD_LIFE_TIME` 设置为 `60` 天，`PASSWORD_VERIFY_FUNCTION` 设置为 `NULL`，`PASSWORD_GRACE_TIME` 设置为默认限制，`PASSWORD_ROLLOVER_TIME` 设置为 `5` 天（示例值）。

```sql
obclient> CREATE PROFILE profile1 LIMIT
   FAILED_LOGIN_ATTEMPTS 5
   PASSWORD_LOCK_TIME 1
   PASSWORD_LIFE_TIME 60
   PASSWORD_VERIFY_FUNCTION NULL
   PASSWORD_GRACE_TIME DEFAULT
   PASSWORD_ROLLOVER_TIME 5;
```

<main id="notice" type='explain'>
<h4>说明</h4>
<p>如果您要在 <code>PASSWORD_VERIFY_FUNCTION</code> 中使用自定义函数，需要先创建该函数。如果不需要密码验证功能，可以设置为 <code>NULL</code>。</p>
</main>

创建包含会话最大空闲时间限制的配置文件 `profile2`，会话空闲超过 30 分钟后由数据库主动断开连接。

```sql
obclient> CREATE PROFILE profile2 LIMIT IDLE_TIME 30;
```
