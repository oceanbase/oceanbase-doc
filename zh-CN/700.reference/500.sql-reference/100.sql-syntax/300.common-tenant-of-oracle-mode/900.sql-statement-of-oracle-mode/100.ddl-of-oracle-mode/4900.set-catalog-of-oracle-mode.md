# SET CATALOG

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该语句从 V4.3.5 BP2 版本开始支持。</p>
</main>

## 描述

该语句用来切换当前会话的 Catalog（数据目录）。切换成功后，当前会话可以不携带 Catalog 前缀，直接以 `schema_name.object_name` 的形式访问目标 Catalog 下的对象。

每个会话默认的 Catalog 为 `INTERNAL`。可以使用 `CURRENT_CATALOG()` 或 `CATALOG()` 函数查看当前会话所在的 Catalog。

## 使用限制及注意事项

* Catalog 名不区分大小写，未使用双引号括起来的 Catalog 名会被统一转换为大写后进行匹配。
* 如果目标 Catalog 不存在，或者当前用户没有目标 Catalog 的 `USE CATALOG` 对象权限，则会报错，错误码为 `-11080` 或 `-11083`。

## 权限要求

切换到指定的 External Catalog，需要当前用户拥有该 Catalog 的 `USE CATALOG` 对象权限。有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 语法

```sql
SET CATALOG catalog_name
```

## 参数说明

|    **参数**     | **描述** |
|-----------------|----------|
| catalog_name | 表示目标 Catalog 的名称，可以为 `INTERNAL` 或者已创建的 External Catalog 的名称。不区分大小写，未使用双引号括起来时统一转换为大写后进行匹配。|

## 示例

* 切换到系统内部 Catalog `INTERNAL`。

  ```sql
  obclient> SET CATALOG internal;
  ```

* 创建一个 External Catalog，切换到该 Catalog，并通过 `CURRENT_CATALOG()` 函数确认当前 Catalog，最后删除该 Catalog。

  ```sql
  obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

  obclient> SET CATALOG tmp_catalog;

  obclient> SELECT CURRENT_CATALOG() FROM dual;
  ```

  查询结果如下：

  ```sql
  +-------------------+
  | CURRENT_CATALOG() |
  +-------------------+
  | TMP_CATALOG       |
  +-------------------+
  1 row in set
  ```

  ```sql
  obclient> SET CATALOG internal;

  obclient> DROP CATALOG tmp_catalog;
  ```
