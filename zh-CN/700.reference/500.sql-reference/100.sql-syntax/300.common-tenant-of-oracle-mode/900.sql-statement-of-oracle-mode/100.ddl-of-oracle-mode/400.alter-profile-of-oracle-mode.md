# ALTER PROFILE

## 描述

该语句用于在配置文件中添加、修改或删除资源限制参数和密码管理参数。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>对带有 <code>ALTER PROFILE</code> 语句的配置文件所做的更改仅影响其后续会话中的用户，而不影响其当前会话中的用户。</p>
  </main>

## 语法

```sql
ALTER PROFILE "profile_name"
   LIMIT
   {
     FAILED_LOGIN_ATTEMPTS integer | UNLIMITED | DEFAULT
   | IDLE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_LIFE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_LOCK_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_VERIFY_FUNCTION function_name | NULL | DEFAULT
   | PASSWORD_GRACE_TIME integer | UNLIMITED | DEFAULT
   | PASSWORD_ROLLOVER_TIME bigint(20) | UNLIMITED | DEFAULT
   };
```

## 参数解释

|          参数           |               描述                |
|-----------------------|---------------------------------|
| profile_name          | 指定要修改的配置文件的名称。                  |
| FAILED_LOGIN_ATTEMPTS | 指定连续登录用户账号失败的次数。                |
| IDLE_TIME | 指定会话的最大空闲时间，单位为分钟。正整数表示会话空闲超过该时间后由数据库主动断开连接，并覆盖 `wait_timeout` 与 `interactive_timeout`；`0` 表示该参数不生效，空闲超时由 `wait_timeout` 控制（交互式连接为 `interactive_timeout`）；`UNLIMITED` 表示不限制空闲时间；`DEFAULT` 表示继承 `DEFAULT` profile 的取值。<main id="notice" type='explain'><h4>说明</h4><ul><li>对于 V4.4.x 版本，该参数从 V4.4.2 BP4 版本开始支持。</li><li>Oracle 中 <code>IDLE_TIME</code> 为 <code>0</code> 时，表示不限制空闲时间，OceanBase 中 <code>0</code> 表示该参数不生效；需要不限制空闲时间时，请设置为 <code>UNLIMITED</code>。</li></ul></main> |
| PASSWORD_LOCK_TIME    | 当账户在限定的次数内连续尝试登录失败后，指定账户被锁定的天数。 |
| PASSWORD_LIFE_TIME    | 指定同一密码可用于身份验证的有效天数。             |
| PASSWORD_GRACE_TIME   | 指定解除警告并开始允许账户登录的宽限期天数。          |
| PASSWORD_VERIFY_FUNCTION | 指定用于验证密码的函数名称。                |
| PASSWORD_ROLLOVER_TIME | 指定密码轮转有效期，单位为天。在轮转有效期内，旧密码与新密码可同时用于认证。取值 `0` 表示禁用旧密码认证。<main id="notice" type="explain"><h4>说明</h4><p>该参数从 V4.4.2 BP1 版本开始支持；从 V4.4.2 BP4 版本开始校验参数取值：非 0 时取值范围为 10 秒 ~ 60 天，且不能大于 <code>PASSWORD_LIFE_TIME</code>，也不能大于非 0 且非 <code>UNLIMITED</code> 的 <code>PASSWORD_GRACE_TIME</code>，否则报错。</p></main> |
| integer               | 表示为该参数设置的限制类型格式为整数。             |
| UNLIMITED             | 表示没有为该参数设置限制。                   |
| DEFAULT               | 表示使用该参数的默认限制。                   |
| function_name         | 表示用于验证密码的函数名称。                   |
| NULL                  | 表示不使用任何验证函数。                     |

## 使用限制及注意事项

* 修改时只更新语句中指定的参数，未指定的参数（包括已设置的 `IDLE_TIME`）保持原有取值。

* 修改只对新建的会话生效，不影响已建立的会话。

## 示例

* 更改限制登录尝试和密码锁定时间：将配置文件 `profile1` 的 `FAILED_LOGIN_ATTEMPTS` 设置为 `5` 次，`PASSWORD_LOCK_TIME` 设置为 `1` 天。

  ```sql
  obclient> ALTER PROFILE "profile1" LIMIT FAILED_LOGIN_ATTEMPTS 5 PASSWORD_LOCK_TIME 1;
  ```

* 更改密码有效期和宽限期：将配置文件 `profile2` 的 `PASSWORD_LIFE_TIME` 设置为 `90` 天，`PASSWORD_GRACE_TIME` 设置为 `5` 天。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT PASSWORD_LIFE_TIME 90 PASSWORD_GRACE_TIME 5;
  ```

* 更改密码轮转有效期：将配置文件 `profile3` 的 `PASSWORD_ROLLOVER_TIME` 设置为 `5` 天（示例值）。

  ```sql
  obclient> ALTER PROFILE "profile3" LIMIT PASSWORD_ROLLOVER_TIME 5;
  ```

* 更改会话最大空闲时间：将配置文件 `profile2` 的 `IDLE_TIME` 设置为 `30` 分钟。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT IDLE_TIME 30;
  ```

* 取消会话最大空闲时间限制：将配置文件 `profile2` 的 `IDLE_TIME` 设置为 `UNLIMITED`。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT IDLE_TIME UNLIMITED;
  ```

* 将会话最大空闲时间恢复为继承 `DEFAULT` profile 的取值：将配置文件 `profile2` 的 `IDLE_TIME` 设置为 `DEFAULT`。

  ```sql
  obclient> ALTER PROFILE "profile2" LIMIT IDLE_TIME DEFAULT;
  ```
