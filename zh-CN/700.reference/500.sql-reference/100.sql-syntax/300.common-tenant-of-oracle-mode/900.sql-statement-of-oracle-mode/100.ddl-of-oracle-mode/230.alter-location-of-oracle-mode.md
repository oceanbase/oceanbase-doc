# ALTER LOCATION

## 描述

该语句用于修改 Location 对象属性。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.4.x 版本，从 V4.4.1 版本开始支持 <code>ALTER LOCATION</code> 语句。</p>
</main>

## 权限要求

* 执行权限：

    执行 `ALTER LOCATION` 语句，需要当前用户拥有 `CREATE LOCATION` 权限。有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

* 认证凭据权限：

    提供的 `ACCESSID` 和 `ACCESSKEY` 需具备目标存储服务的合法访问权限。

## 语法

```sql
ALTER LOCATION location_name SET
    {URL = 'file_path'
    | CREDENTIAL = (credential_list)
    };

credential_list:
    ACCESSID = 'string'
    ACCESSKEY = 'string'
    HOST = 'string'
    [S3_REGION = 'string']
    [PRINCIPAL = 'string']
    [KEYTAB = 'string']
    [KRB5CONF = 'string']
    [CONFIGS = 'string']
    [USERNAME = 'string']
```

## 参数说明

|      **参数**     | **描述** |
|-------------------|----------|
| location_name     | 表示要修改的 Location 对象的名称。|
| URL = 'file_path' | 用于修改外部存储路径。详细介绍可参见下文 [file_path](#file_path)。|
| CREDENTIAL        | 用于修改 HDFS 或对象存储访问路径所需的信息。详细介绍可参见下文 [credential_list](#credential_list)。|

### file_path

外表文件存放的路径有以下格式：

* 本地路径格式为：`URL = 'file://local_file_path'`，其中 `local_file_path` 可以为相对路径，也可以为绝对路径。

* HDFS 路径格式为：`URL = 'hdfs://localhost:port/PATH'`，其中 `localhost` 指的是 HDFS 的地址，`port` 指的是 HDFS 的端口号，`PATH` 指 HDFS 中的目录路径。

* 对象存储（OSS/S3）路径格式为：`URL = '{oss | s3}://bucket/remote_file_path'`。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>创建 Location 对象的路径中不应该带有参数。</p>
</main>

### credential_list

* `ACCESSID`：用于修改访问对象存储的用户 AccessKey ID。
* `ACCESSKEY`：用于修改访问对象存储的用户 AccessKey Secret。
* `HOST`：用于修改对象存储服务的主机地址。
* `S3_REGION`：可选项，用于修改 S3 对象存储的服务区域。
* `PRINCIPAL`：可选项，目标 HDFS 集群带 kerberos 环境时，用于修改登录认证用户。
* `KEYTAB`：可选项，目标 HDFS 集群带 kerberos 环境时，用于修改认证密钥文件路径。
* `KRB5CONF`：可选项，目标 HDFS 集群带 kerberos 环境时，用于修改用户使用 kerberos 环境的文件路径。
* `CONFIGS`：可选项，目标 HDFS 集群带 kerberos 环境时，用于修改额外的集群配置项。
* `USERNAME`：可选项，目标 HDFS 集群带 Kerberos 环境时，用于修改唯一标识用户身份。

## 示例

修改 Location 对象 `test_location_oss` 的 `CREDENTIAL` 信息。

```shell
obclient> CREATE LOCATION test_location_oss
    URL = 'oss://dir'
    CREDENTIAL = (
        ACCESSID = '******'
        ACCESSKEY = '******'
        HOST = '******'
        );
```
