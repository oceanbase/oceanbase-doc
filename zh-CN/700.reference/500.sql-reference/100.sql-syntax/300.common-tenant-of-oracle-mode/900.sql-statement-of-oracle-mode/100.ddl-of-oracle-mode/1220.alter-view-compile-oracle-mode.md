# ALTER VIEW COMPILE

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.x 版本，该语句从V4.4.2 BP1 版本开始引入。<br>对于 V5.0.x 版本，该语句从V5.0.1 版本开始引入。</p>
</main>

## 描述

该语句用于显式地重新编译无效视图或修改视图约束。

## 权限要求

执行该语句，您必须拥有 `ALTER ANY TABLE` 系统权限。有关 OceanBase 数据库权限的详细介绍，请参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 语法

```sql
ALTER VIEW [schema_name.]view_name COMPILE;
```

## 参数解释

|      参数      |         描述       |
|---------------|--------------------|
|schema_name|视图所属的模式名（可选）。|
|view_name|需要重新编译的视图名称。|
|COMPILE|关键字，指示数据库执行重新编译操作。|

## 示例

执行如下命令，编译名为 `customer_ro` 的视图。

```shell
obclient> ALTER VIEW customer_ro COMPILE;
```
