# DROP OUTLINE

## 描述

该语句用于删除 OceanBase 数据库中的 Outline。

## 语法

```sql
DROP [FORMAT] OUTLINE outline_name
    [BINDING_RULE (binding_item)];

binding_item:
    SCOPE = {DATABASE | TENANT}
```

## 参数解释

|   **参数**   | **描述** |
|--------------|----------|
| FORMAT       | 可选项，表示删除 `FORMAT OUTLINE`（模糊 Outline），包括 Format 模板 Outline。 <main id="notice" type='explain'><h4>说明</h4><p>对于 V4.4.x 版本，从 V4.4.2 BP4 版本开始支持删除 Format 模板 Outline。</p></main>|
| outline_name | 指定要删除的 Outline 名称。|
| BINDING_RULE (binding_item) | 可选项，用于指定删除 Outline 的级别。<ul><li>`BINDING_RULE (SCOPE = DATABASE)`：默认值，指定删除当前库级别的 Outline（等价于不显示指定 `BINDING_RULE` 参数）。</li><li>`BINDING_RULE (SCOPE = TENANT)`：删除指定名称的跨库（租户级）Outline。</li></ul> <main id="notice" type='explain'><h4>说明</h4><p>对于 V4.4.x 版本，从 V4.4.2 BP3 版本开始引入 <code>BINDING_RULE</code> 子句。</p></main>|

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><ul><li>删除 Format Outline（含 Format 模板 Outline）时必须指定 <code>FORMAT</code> 关键字。如果不指定 <code>FORMAT</code>，系统会按普通 Outline 查找，因找不到同名普通 Outline 而报错 <code>doesn't exist</code>。</li><li>Format Outline 与普通 Outline 相互独立，同名但类型不同的两个 Outline 可以同时存在，需要分别指定 <code>FORMAT</code> 删除。</li></ul></p>
</main>

## 示例

创建测试表和相关 Outline，再将其删除。

1. 创建表 `employees`。

    ```shell
    obclient> CREATE TABLE employees (emp_id INT, emp_name VARCHAR(20));
    ```

2. 向表 `employees` 中插入测试数据。

    ```shell
    obclient> INSERT INTO employees VALUES (1, 'John'), (2, 'Alice');
    ```

3. 创建 Outline。

    ```shell
    obclient> CREATE OUTLINE emp_query_outline
        ON SELECT * FROM employees WHERE emp_id=1;
    ```

4. 删除 Outline。

    ```shell
    obclient> DROP OUTLINE emp_query_outline;
    ```

5. 删除测试表。

    ```shell
    obclient> DROP TABLE employees;
    ```

删除 Format 模板 Outline。

```shell
obclient> DROP FORMAT OUTLINE emp_format_outline;
```
