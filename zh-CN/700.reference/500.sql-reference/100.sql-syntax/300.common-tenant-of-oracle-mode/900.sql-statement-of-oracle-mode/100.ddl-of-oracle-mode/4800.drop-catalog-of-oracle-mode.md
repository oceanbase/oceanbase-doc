# DROP CATALOG

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该语句从 V4.3.5 BP2 版本开始支持。</p>
</main>

## 描述

该语句用来删除一个外部数据目录（External Catalog）。

## 使用限制及注意事项

* Internal Catalog（`INTERNAL`）不可删除。
* 与 MySQL 模式不同，Oracle 模式下的 `DROP CATALOG` 语句不支持 `IF EXISTS` 子句。如果要删除的 Catalog 不存在，则会报错，错误码为 `-11080`，报错信息为 `Catalog 'xxx' doesn't exist`。
* Catalog 名不区分大小写，未使用双引号括起来的 Catalog 名会被统一转换为大写后进行匹配。
* 删除 Catalog 后，其他用户在该 Catalog 上的 `USE CATALOG` 对象权限会一并回收。

## 权限要求

执行 `DROP CATALOG` 语句，需要当前用户拥有 `CREATE CATALOG` 系统权限。有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 语法

```sql
DROP CATALOG external_catalog_name
```

## 参数说明

|    **参数**     | **描述** |
|-----------------|----------|
| external_catalog_name | 表示要删除的外部数据目录的名称。不区分大小写，未使用双引号括起来时统一转换为大写后进行匹配。|

## 示例

创建并删除一个名为 `tmp_catalog` 的 External Catalog。

```sql
obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

obclient> DROP CATALOG tmp_catalog;
```

如果要删除的 Catalog 不存在，则会报错：

```sql
obclient> DROP CATALOG tmp_catalog;
```

查询结果如下：

```sql
OBE-00600: internal error code, arguments: -11080, Catalog 'TMP_CATALOG' doesn't exist
```
