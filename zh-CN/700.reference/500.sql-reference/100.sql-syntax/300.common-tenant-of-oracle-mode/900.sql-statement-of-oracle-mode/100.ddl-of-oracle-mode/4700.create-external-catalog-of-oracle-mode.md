# CREATE EXTERNAL CATALOG

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该语句从 V4.3.5 BP2 版本开始支持。其中，JDBC 类型的 External Catalog 从 V4.4.2 BP4 版本开始支持。</p>
</main>

## 描述

该语句用来在数据库中创建外部数据目录（External Catalog），用于连接外部数据源，获取外部数据的元信息。可以通过它直接查询外部数据，无需进行数据导入或迁移。

## 使用限制及注意事项

* 当前支持创建 `ODPS`、`HMS` 和 `JDBC` 类型的 External Catalog。其中，`JDBC` 类型从 V4.4.2 BP4 版本开始支持，当前仅支持连接 SQL Server 数据源。
* 与 MySQL 模式不同，Oracle 模式下的 `CREATE EXTERNAL CATALOG` 语句不支持 `IF NOT EXISTS` 子句。如果要创建的 Catalog 已经存在，则会报错。
* Catalog 名不区分大小写，未使用双引号括起来的 Catalog 名会被统一转换为大写存储。如果需要保留大小写，可以使用双引号将 Catalog 名括起来。
* 创建 HMS Catalog 前，如果 HMS 预期访问底层存储的文件数据在 HDFS 上，则需要完成 Java SDK 环境部署。有关配置 JAVA SDK 环境的详细信息，参见 [部署 OceanBase 数据库 JAVA SDK 环境](../../../../../../400.deploy/300.deploy-oceanbase-enterprise-edition/500.deploy-the-ob-java-sdk-environment.md)。
* 创建 JDBC Catalog 前，需要完成 Java SDK 环境部署，且 devdeps-java-extensions RPM 包需为 1.0.6 及以上版本。有关配置 JAVA SDK 环境的详细信息，参见 [部署 OceanBase 数据库 JAVA SDK 环境](../../../../../../400.deploy/300.deploy-oceanbase-enterprise-edition/500.deploy-the-ob-java-sdk-environment.md)。
* External Catalog 下的对象为只读，不支持执行 `INSERT`、`UPDATE`、`DELETE`、`ALTER TABLE`、`DROP TABLE` 等修改语句。

## 权限要求

执行 `CREATE EXTERNAL CATALOG` 语句，需要当前用户拥有 `CREATE CATALOG` 系统权限。有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

用户创建 Catalog 成功后，会自动获得该 Catalog 的 `USE CATALOG` 对象权限，可以通过 `SYS.USER_TAB_PRIVS` 视图查看。

## 语法

```sql
CREATE EXTERNAL CATALOG external_catalog_name
    PROPERTIES [=] (properties_type_list)

properties_type_list:
    odps_type_list
    | hms_type_list
    | jdbc_type_list

odps_type_list:
    TYPE = 'ODPS',
    [ACCESSTYPE = 'accesstype_string',]
    ACCESSID = 'string',
    ACCESSKEY = 'string',
    STSTOKEN = 'string',
    ENDPOINT = 'string',
    TUNNEL_ENDPOINT = 'string',
    PROJECT_NAME = 'string',
    [QUOTA_NAME = 'string',]
    REGION = 'string'

hms_type_list:
    TYPE = 'HMS',
    URI = 'string'
    [, KRB5CONF = 'string']
    [, KEYTAB = 'string']
    [, PRINCIPAL = 'string']
    [, MAX_CLIENT_POOL_SIZE = 20]
    [, SOCKET_TIMEOUT = 10000000]

jdbc_type_list:
    TYPE = 'JDBC',
    URL = 'string'

accesstype_string:
    aliyun
    | sts
    | app
```

## 参数说明

|    **参数**     | **描述** |
|-----------------|----------|
| external_catalog_name | 表示要创建的外部数据目录的名称。不区分大小写，未使用双引号括起来时统一转换为大写存储。|
| PROPERTIES [=] (properties_type_list) | 用于指定外部数据目录类型的相关属性选项，详细介绍可参见下文 [properties_type_list](#properties_type_list)。|

### properties_type_list

* `odps_type_list`：表示 ODPS 类型外部数据目录（ODPS Catalog）的相关属性列表。详细介绍可参见下文 [odps_type_list](#odps_type_list)。
* `hms_type_list`：表示 HMS 类型外部数据目录（HMS Catalog）的相关属性列表。详细介绍可参见下文 [hms_type_list](#hms_type_list)。
* `jdbc_type_list`：表示 JDBC 类型外部数据目录（JDBC Catalog）的相关属性列表。详细介绍可参见下文 [jdbc_type_list](#jdbc_type_list)。

### odps_type_list

* `TYPE`：用于指定外部数据目录的类型取值为 `ODPS`，即外表读写 MaxCompute 数据时，取值为 `ODPS`。
* `ACCESSTYPE`：可选项，用于指定 MaxCompute 的账号类型，默认值为 `aliyun`。账号类型取值（不区分大小写）如下：

  * `aliyun`
  * `sts`
  * `app`

* `ACCESSID`：用于指定 AccessKey ID。当 `ACCESSTYPE` 的值是 `aliyun`/`app` 账号类型或者为空时，`aliyun`/`app` 账号或者具备 MaxCompute 访问权限的 RAM 用户的 AccessKey ID。
* `ACCESSKEY`：用于指定 AccessKey Secret。当 `ACCESSTYPE` 的值是 `aliyun`/`app` 账号类型或者为空时，`aliyun`/`app` 账号或者具备 MaxCompute 访问权限的 RAM 用户的 AccessKey Secret。
* `STSTOKEN`：用于指定 token。当 `ACCESSTYPE` 的值是 `sts` 账号类型时，这里是访问 MaxCompute 服务的 token。
* `ENDPOINT`：用于指定 MaxCompute 的 EndPoint（域名节点）。
* `TUNNEL_ENDPOINT`：用于指定 Tunnel Endpoint，MaxCompute Catalog 使用 Tunnel SDK 获取数据。
* `PROJECT_NAME`：用于指定 MaxCompute 中的项目空间名称。项目空间（Project）是 MaxCompute 的基本组织单元，它类似于传统数据库的 Database 或 Schema 的概念。
* `QUOTA_NAME`：可选项，用于指定 Quota。Quota 在 MaxCompute 中代表计算资源池（计算、访问、写入），如果用户配置了对应的 Quota，通过该参数指定特定的 Quota。
* `REGION`：用于指定 MaxCompute 开通的地域。

### hms_type_list

* `TYPE`：用于指定外部数据目录的类型取值为 `HMS`，即外表读取通过 Hive 组织管理的数据，取值 `HMS`。
* `URI`：用于指定需要访问的 `HMS` 服务的 `thrift` URI 链接，格式为：`thrift://$host:$port`，其中：

  * `$host`：表示 `thrift` IP 地址。
  * `$port`：表示 `thrift` 端口。`HMS` 的默认 `thrift` 端口为 9083。

* `KRB5CONF`：可选项，用于指定访问启用 Kerberos 认证的 `HMS` 服务时，所需的 Kerberos 配置文件路径。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>仅在 <code>HMS</code> 启用 Kerberos 认证时，需要设置参数 <code>KRB5CONF</code>。</p>
    </main>

* `KEYTAB`：可选项，用于指定访问启用 Kerberos 认证的 `HMS` 服务时，所需的 `KEYTAB` 密钥文件路径。如果 OceanBase 集群为分布式部署，那么相关的 OBServer 对应机器节点，相关路径都需要存在该文件。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>仅在 <code>HMS</code> 启用 Kerberos 认证时，需要设置参数 <code>KEYTAB</code>。</p>
    </main>

* `PRINCIPAL`：可选项，用于指定访问启用 Kerberos 认证的 `HMS` 服务时，所需的 Kerberos 主体（Principal）名称。通常以 `service/HOST@REGION.com` 形式存在，例如 `hive/hadoop@QA.COM`。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>仅在 <code>HMS</code> 启用 Kerberos 认证时，需要设置参数 <code>PRINCIPAL</code>。</p>
    </main>

* `MAX_CLIENT_POOL_SIZE`：可选项，用于指定 HMS 客户端连接池的最大连接数，默认值为 `20`。
* `SOCKET_TIMEOUT`：可选项，用于指定 HMS 客户端的 Socket 超时时间，单位为微秒，默认值为 `10000000`（即 10 秒）。

### jdbc_type_list

* `TYPE`：用于指定外部数据目录的类型取值为 `JDBC`，即外表读取通过 JDBC 协议访问的数据源，取值 `JDBC`。当前仅支持连接 SQL Server 数据源。
* `URL`：用于指定 JDBC 连接串，即连接 SQL Server 数据源的 JDBC URL，例如 `jdbc:sqlserver://10.10.10.1:1433;databaseName=master;encrypt=true;trustServerCertificate=true`。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><code>URL</code> 会加密存储。执行 <code>SHOW CREATE CATALOG</code> 语句查看 Catalog 的创建语句时，<code>URL</code> 会脱敏显示。</p>
</main>

JDBC Catalog 下外部表的列类型由 devdeps-java-extensions 提供的列元数据（`targetType`）决定，映射为 Oracle 模式下的数据类型。SQL Server 数据源的主要类型映射如下：

| **SQL Server 类型** | **Oracle 模式下的类型** |
|---------------------|-------------------------|
| BIT | NUMBER(1) |
| TINYINT | NUMBER(3) |
| SMALLINT | NUMBER(5) |
| INT | NUMBER(10) |
| BIGINT | NUMBER(19) |
| DECIMAL / NUMERIC | NUMBER(p,s) |
| SMALLMONEY | NUMBER(10,4) |
| MONEY | NUMBER(19,4) |
| REAL / FLOAT(24) | BINARY_FLOAT |
| FLOAT(53) / DOUBLE | BINARY_DOUBLE |
| CHAR(n) | VARCHAR2(n CHAR) |
| VARCHAR(n) | VARCHAR2(n CHAR) |
| NCHAR(n) | NVARCHAR2(n) |
| NVARCHAR(n) | NVARCHAR2(n) |
| BINARY(n) | RAW(n) |
| VARBINARY(n) | RAW(n) |
| DATE | DATE |
| TIME | INTERVAL DAY (1) TO SECOND (n) |
| SMALLDATETIME | TIMESTAMP(0) |
| DATETIME | TIMESTAMP(3) |
| DATETIME2 | TIMESTAMP(7) |
| 不支持的类型 | UNSUPPORTED |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>当外部表中存在数据类型显示为 <code>UNSUPPORTED</code> 的列时，该列不可查询，查询其他列不受影响。</p>
</main>

## 示例

* 创建一个 JDBC 类型的 External Catalog。

  ```sql
  obclient> CREATE EXTERNAL CATALOG tmp_jdbc_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

  obclient> DROP CATALOG tmp_jdbc_catalog;
  ```

* 创建一个 ODPS 类型的 External Catalog，并在不再使用时删除。

  ```sql
  obclient> CREATE EXTERNAL CATALOG tmp_odps_catalog PROPERTIES = (TYPE = 'ODPS', ACCESSID = '$odps_accessid', ACCESSKEY = '$odps_accesskey', ENDPOINT = '$odps_endpoint', TUNNEL_ENDPOINT = 'http://xxx.maxcompute.aliyun.com', PROJECT_NAME = 'odps_test_project');

  obclient> DROP CATALOG tmp_odps_catalog;
  ```
