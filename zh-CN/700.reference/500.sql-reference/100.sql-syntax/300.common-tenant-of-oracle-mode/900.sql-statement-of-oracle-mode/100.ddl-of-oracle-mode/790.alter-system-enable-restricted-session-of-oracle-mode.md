# ALTER SYSTEM ENABLE/DISABLE RESTRICTED SESSION

## 描述

`ALTER SYSTEM ENABLE RESTRICTED SESSION` 用于启用受限模式；`ALTER SYSTEM DISABLE RESTRICTED SESSION` 用于关闭受限模式。

启用受限模式后，数据库会拒绝建立新的普通连接，仅具有 `RESTRICTED SESSION` 系统权限的用户可继续登录，常用于应用升级与维护期间的访问管控。升级或维护完成后，可通过 `ALTER SYSTEM DISABLE RESTRICTED SESSION` 恢复为常规服务状态。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该语句从 V4.4.2 BP1 版本开始引入。</p>
</main>

## 语法

```sql
ALTER SYSTEM { ENABLE | DISABLE } RESTRICTED SESSION;
```

## 参数解释

| 参数 | 描述 |
|---------|------|
| ENABLE | 启用受限模式。开启后，数据库拒绝建立新的普通连接；具有 `RESTRICTED SESSION` 系统权限的用户访问不受影响。启用后受限模式不会随租户重启而失效。 |
| DISABLE | 关闭受限模式。关闭后，数据库恢复常规服务状态。 |

## 示例

* 启用受限模式。

  ```sql
  obclient> ALTER SYSTEM ENABLE RESTRICTED SESSION;
  ```

* 关闭受限模式。

  ```sql
  obclient> ALTER SYSTEM DISABLE RESTRICTED SESSION;
  ```
