# DROP TABLEGROUP

## 描述

该语句用来删除表组。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>如果有任何表的 <code>TABLEGROUP</code> 属性引用了目标表组，则该表组不允许被删除。</p>
  </main>

## 权限说明

执行 `DROP TABLEGROUP` 需要以下权限：

- 需要有 `DROP` 权限才能删除表组。
- 如果表组中有表，需要有这些表的 `ALTER` 权限才能修改其表组属性。

## 注意事项

- 删除表组不会删除其中的表，但会移除表与表组之间的关联关系。
- 在删除表组前，请确保没有业务依赖于该表组。

## 语法

```sql
DROP TABLEGROUP tablegroup_name
```

## 参数解释

|       参数        |     描述      |
|-----------------|-------------|
| tablegroup_name | 指定要删除的表组名称。 |

## 示例

### 示例 1：删除被引用的表组

当表组被表通过 `TABLEGROUP` 属性引用时，需要先解除这些引用关系才能删除表组。

1. 直接删除非空表组会报错：

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ```

   预期返回结果：

   ```sql
   OBE-00600: internal error code, arguments: -4615, tablegroup is not empty
   ```

2. 查看表组 `tblgroup1` 中的表：

   ```sql
   obclient> SHOW TABLEGROUPS;
   obclient> SHOW TABLES IN tblgroup1;
   ```

3. 将表 `tbl1` 移出表组 `tblgroup1`：

   ```sql
   obclient> ALTER TABLE tbl1 SET TABLEGROUP = '';
   ```

4. 再次删除表组 `tblgroup1`：

   ```sql
   obclient> DROP TABLEGROUP tblgroup1;
   ```

### 示例二：完整的表组使用流程

1. 创建表组：

   ```sql
   obclient> CREATE TABLEGROUP tg1;
   ```

2. 创建表并指定表组：

   ```sql
   obclient> CREATE TABLE t1 (id INT) TABLEGROUP = tg1;
   ```

3. 查看表组信息：

   ```sql
   obclient> SHOW TABLEGROUPS;
   ```

4. 将表 `t1` 移出表组 `tg1`：

   ```sql
   obclient> ALTER TABLE t1 SET TABLEGROUP = '';
   ```

5. 删除表组 `tg1`：

   ```sql
   obclient> DROP TABLEGROUP tg1;
   ```
