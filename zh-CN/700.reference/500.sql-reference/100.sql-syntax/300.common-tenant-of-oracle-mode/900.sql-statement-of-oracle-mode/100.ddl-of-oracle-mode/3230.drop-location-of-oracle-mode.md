# DROP LOCATION

## 描述

该语句用于删除 Location 对象。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.4.x 版本，从 V4.4.1 版本开始支持 <code>DROP LOCATION</code> 语句。</p>
</main>

## 权限要求

执行 `DROP LOCATION` 语句，需要当前用户拥有 `CREATE LOCATION` 权限。有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 语法

```sql
DROP LOCATION location_name;
```

## 参数说明

|   **参数**    | **描述** |
|---------------|----------|
| location_name | 表示要删除的 Location 对象的名称。|

## 示例

删除 Location 对象 `test_location_local`。

```shell
obclient> DROP LOCATION test_location_local;
```
