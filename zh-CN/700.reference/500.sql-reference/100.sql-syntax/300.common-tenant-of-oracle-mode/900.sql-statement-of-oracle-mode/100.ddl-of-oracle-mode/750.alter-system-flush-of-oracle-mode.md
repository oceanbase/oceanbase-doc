# ALTER SYSTEM FLUSH

## 描述

`ALTER SYSTEM FLUSH` 是一组用于清除或刷新数据库内部缓存、日志等临时数据的管理语句。

## 语法

```sql
ALTER SYSTEM FLUSH object_option;

object_option:
    SQL AUDIT
    | PS CACHE
```

## 参数解释

| 参数 | 描述 |
|------|------|
| SQL AUDIT | 用于强制刷新并清理 SQL 审计（SQL Audit）在内存中的记录。|
| PS CACHE  | 用于清空 PS Cache（Prepared Statement 缓存）。|

## 示例

* 刷新并清理本租户中 SQL 审计记录。

    ```shell
    obclient> ALTER SYSTEM FLUSH SQL AUDIT;
    ```

* 清空本租户中 PS Cache。

    ```shell
    obclient> ALTER SYSTEM FLUSH PS CACHE;
    ```
