# 表函数

表函数 (Table Function) 是生成行集合的函数，这些集合可以像数据库表一样进行查询。您可以在 `FROM` 查询子句中使用 Table Function 函数。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>OceanBase 数据库从 V4.2.5 BP5 版本开始，Table Function 支持复杂数据类型。</p>
</main>

## 示例

```sql
CREATE FUNCTION func_normal RETURN table_type AS
  v_result table_type := table_type();
BEGIN
  v_result.EXTEND;
  v_result(1) := obj_type(1, 'A');
  RETURN v_result;
END;
```

### 参数解释

|      参数    |                 说明                         |
|--------------|---------------------------------------------|
|CREATE FUNCTION func_normal|声明创建名为 `func_normal` 的函数。|
|RETURN table_type|指定函数返回类型为自定义表类型 `table_type`。|
|v_result|局部变量，类型为 `table_type`（嵌套表或数组类型）。|
|table_type()|初始化空表实例，类似构造函数。|
|v_result.EXTEND|扩展表容量。|
|v_result(1) := obj_type(1, 'A')|创建自定义对象类型 `obj_type` 的实例。|
|RETURN v_result|返回填充后的表变量，类型必须与声明一致。|

完整使用流程示例如下：

1. 定义对象类型。

    ```shell
    obclient> CREATE OR REPLACE TYPE obj_type AS OBJECT (
    id   NUMBER,
    name VARCHAR2(50)
    );
    ```

2. 定义表类型。

    ```shell
    obclient> CREATE OR REPLACE TYPE table_type IS TABLE OF obj_type;
    ```

3. 调用表函数。

    ```shell
    obclient> SELECT * FROM TABLE(func_normal());
    ```
