# ARG_MAX

## 声明

```sql
ARG_MAX([DISTINCT] maximize_col, return_col)
```

## 说明

`ARG_MAX` 函数用于在数据集中查找使目标表达式最大化的行，并返回该行对应的指定列值或完整记录。

其中：

* `maximize_col` 指待最大化的列。
* `return_col` 指返回值对应的列，如果为 `NULL` 的值则跳过。

## 示例

```shell
obclient> SELECT * FROM test;
+------+------+
| a    | b    |
+------+------+
| a    |    1 |
| b    |    2 |
| c    |    2 |
| NULL |    3 |
| NULL | NULL |
| d    | NULL |
+------+------+
6 rows in set (0.000 sec)
```

```shell
obclient> SELECT arg_max(a, b), max(b) FROM test;
+---------------+--------+
| arg_max(a, b) | max(b) |
+---------------+--------+
| b             |      3 |
+---------------+--------+
1 row in set (0.002 sec)
```
