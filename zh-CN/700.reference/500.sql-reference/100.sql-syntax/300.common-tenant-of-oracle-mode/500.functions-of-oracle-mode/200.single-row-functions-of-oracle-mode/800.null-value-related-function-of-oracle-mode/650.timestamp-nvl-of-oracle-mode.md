# TIMESTAMP_NVL

## 描述

该函数用于判断时间戳表达式是否为 `NULL`。如果第一个表达式不为 `NULL`，则返回第一个表达式；否则返回第二个表达式。

## 语法

```sql
TIMESTAMP_NVL(expr1, expr2)
```

## 参数解释

| 参数 | 说明 |
|------|------|
| expr1 | 指定第一个时间戳表达式。 |
| expr2 | 指定 `expr1` 为 `NULL` 时返回的时间戳表达式。 |

## 返回类型

返回时间戳数据类型。如果两个表达式都为 `NULL`，则返回 `NULL`。

## 示例

第一个表达式为 `NULL`，返回第二个时间戳表达式。

```sql
obclient> SELECT TIMESTAMP_NVL(
            CAST(NULL AS TIMESTAMP),
            TIMESTAMP '2026-10-09 10:00:00'
          ) AS result
          FROM DUAL;
+------------------------------+
| RESULT                       |
+------------------------------+
| 09-OCT-26 10.00.00.000000 AM |
+------------------------------+
1 row in set
```
