# EMPTY_BLOB

## 描述

该函数返回一个空的 `BLOB` 定位器。该定位器不为 `NULL`，LOB 长度为 0。

## 语法

```sql
EMPTY_BLOB()
```

## 返回类型

返回 `BLOB` 数据类型。

## 示例

返回一个空的 `BLOB` 定位器，并检查该定位器是否为 `NULL` 以及 LOB 长度。

```sql
obclient> SELECT CASE WHEN EMPTY_BLOB() IS NULL THEN 'NULL' ELSE 'NOT NULL' END AS blob_is_null,
          DBMS_LOB.GETLENGTH(EMPTY_BLOB()) AS blob_len
          FROM DUAL;
+--------------+----------+
| BLOB_IS_NULL | BLOB_LEN |
+--------------+----------+
| NOT NULL     |        0 |
+--------------+----------+
1 row in set
```
