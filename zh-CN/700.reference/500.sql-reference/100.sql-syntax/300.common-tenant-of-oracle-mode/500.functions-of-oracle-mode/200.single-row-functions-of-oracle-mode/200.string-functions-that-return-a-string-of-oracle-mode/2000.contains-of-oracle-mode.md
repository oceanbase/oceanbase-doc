# CONTAINS

## 描述

该函数主要用于在数据库字段中进行字符串匹配或全文检索。

## 语法

```sql
CONTAINS(indexed_column, 'search_query' [, score_label])
```

## 参数解释

* `indexed_column`：表示全文索引的列名。
* `search_query`：`VARCHAR2` 类型或 `CLOB` 类型，表示需要搜索的关键字或短语。
* `score_label`：可选参数，`NUMBER` 类型，表示返回结果的匹配编号。

## 示例

执行如下命令，从 `test` 表中筛选出 `c1` 列内容包含字符串 `city` 的数据行。

```sql
obclient> SELECT id, c1 FROM test WHERE CONTAINS(c1, 'city') > 0;
```
