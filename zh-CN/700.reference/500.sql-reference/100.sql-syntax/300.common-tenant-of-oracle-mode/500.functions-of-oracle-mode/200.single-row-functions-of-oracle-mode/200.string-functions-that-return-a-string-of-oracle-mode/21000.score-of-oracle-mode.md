# SCORE

## 描述

该函数主要用于在数据库字段中进行字符串匹配或全文检索。

## 语法

```sql
SCORE(score_label)
```

## 参数解释

* `score_label`：可选参数，`NUMBER` 类型，表示返回结果的匹配编号。

## 示例

执行如下命令，使用 `CONTAINS` 与 `SCORE` 实现全文检索排序查询。

```sql
obclient> SELECT column1, column2, ...
FROM table_name
WHERE CONTAINS(indexed_column, 'search_query'[, score_label]) > 0
ORDER BY SCORE(score_label) DESC;
```
