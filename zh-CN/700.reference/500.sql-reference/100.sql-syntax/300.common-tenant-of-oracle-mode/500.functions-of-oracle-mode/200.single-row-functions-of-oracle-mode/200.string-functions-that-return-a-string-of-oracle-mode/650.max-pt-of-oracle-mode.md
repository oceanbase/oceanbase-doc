# MAX_PT

## 描述

该函数用于返回分区表中有数据的分区的分区键的最大值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.6.x 版本，该函数从 V4.6.0 版本开始引入。</p>
</main>

## 使用限制及注意事项

* 要求查询的表为分区表，并且分区类型为 Range 分区或者 List 分区。
* 要求查询表为内表，不支持外表和 DBlink。
* 只支持单列作为分区键，不支持多列或者表达式作为分区键。
* 如果为二级分区表，只返回一级分区的值。
* 如果所有分区都为空，则返回 NULL。
* 如果在同一个分区中存在不同的分区值，`MAX_PT` 的结果是 `undefined`，会从这个分区中任意选择一行的值返回。
* Oracle 模式中 Schema 名称和表名称的需使用大写英文字母。

## 语法

```sql
MAX_PT('[schema_name.]table_name')
```

## 参数解释

* `database_name`：可选项，表示表所在的 Schema 名称。如果不指定，则默认为当前登录 Schema 中的表。
* `table_name`：表示表名称。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>Oracle 模式中 Schema 名称和表名称的需使用大写英文字母。</p>
</main>

## 返回值

返回最大（按照 `max()` 比较逻辑）有数据分区的分区值，数据类型和分区键类型相同。

## 示例

1. 创建分区表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY LIST (col1) (
            PARTITION P0 VALUES (1),
            PARTITION P1 VALUES (2),
            PARTITION P2 VALUES (3),
            PARTITION P3 VALUES (4)
        );
    ```

2. 插入测试数据

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1,1,1),
        (2,2,2),
        (3,3,3),
        (4,4,4),
        (1,1,2),
        (2,2,2);
    ```

    返回结果如下：

    ```shell
    Query OK, 6 rows affected
    Records: 6  Duplicates: 0  Warnings: 0
    ```

3. 查看表 `test_tbl1` 中有数据的分区的分区键的最大值。

    ```shell
    obclient> SELECT MAX_PT('TEST_TBL1') FROM DUAL;
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | MAX_PT('TEST_TBL1') |
    +---------------------+
    |                   4 |
    +---------------------+
    1 row in set
    ```
