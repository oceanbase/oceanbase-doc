# INSTRB

## 描述

该函数以字节为单位，在一个字符串中搜索指定的子字符串，并返回子字符串的起始字节位置。

## 语法

```sql
INSTRB(string, substring [, position [, occurrence]])
```

## 参数解释

| 参数 | 说明 |
|------|------|
| string | 指定被搜索的字符串。 |
| substring | 指定要搜索的子字符串。 |
| position | 可选。指定搜索的起始位置，默认值为 `1`。值为负数时，从字符串末尾反向搜索。 |
| occurrence | 可选。指定返回子字符串第几次出现的位置，默认值为 `1`。 |

## 返回类型

返回 `NUMBER` 数据类型。未找到指定子字符串时返回 `0`。

## 示例

字符串 `中OceanBase` 中的汉字 `中` 占 3 个字节，因此 `Base` 从第 9 个字节开始。

```sql
obclient> SELECT INSTRB('中OceanBase', 'Base') AS result FROM DUAL;
+--------+
| RESULT |
+--------+
|      9 |
+--------+
1 row in set
```
