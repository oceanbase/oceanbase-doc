# TO_PINYIN

## 声明

```sql
TO_PINYIN('chinese_string','option')
```

### 参数说明

`option` 表示可选项，以“数据库”为例，分场景为您介绍选项名称和输出结果。

|OPTION 选项|全小写|首字母大写|全大写|
|-----------|------|--------|-------|
|首字母|INITIAL<br>（sjk）|CAP_INITIAL<br>（Sjk）|ALL_CAP_INITIAL<br>（SJK）|
|全拼|FULL （不指定时的默认模式）<br>（shujuku）|CAP（ShuJuKu）<br>FIRST_CAP（Shujuku）|ALL_CAP<br>（SHUJUKU）|

## 说明

该函数用于将中文文本转换为拼音。

它接受一个中文字符串作为输入，并返回一个包含相应拼音的字符串。

## 示例

**示例一：**

执行如下命令，将中文字符串转换为对应的拼音字符串。

```sql
SELECT TO_PINYIN('数据库') FROM DUAL;
```

返回结果如下：

```shell
+------------------------+
| TO_PINYIN('数据库')    |
+------------------------+
| shùjùkù                |
+------------------------+
1 row in set
```

**示例二：**

执行如下命令，将中文字符串转换为对应的拼音字符串并且首字母大写。

```sql
SELECT TO_PINYIN('数据库','CAP') FROM DUAL;
```

返回结果如下：

```shell
+------------------------------+
| TO_PINYIN('数据库','CAP')    |
+------------------------------+
| ShùJùKù                      |
+------------------------------+
1 row in set (0.000 sec)
```
