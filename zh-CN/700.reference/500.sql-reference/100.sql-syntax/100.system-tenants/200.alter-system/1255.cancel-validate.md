# CANCEL VALIDATE

## 描述

`ALTER SYSTEM CANCEL VALIDATE` 语句用于取消正在执行的备份校验任务。

## 权限要求

需要由 `sys` 租户的 `root` 用户（`root@sys`） 或各租户的管理员用户执行。其中：

* MySQL 模式的默认管理员用户为 `root` 用户。
* Oracle 模式的默认管理员用户为 `SYS` 用户。

## 语法

```sql
ALTER SYSTEM CANCEL VALIDATE BACKUP [TENANT = mysql_tenant];
```

## 参数解释

|      参数        |        描述                                             |
|------------------|---------------------------------------------------------|
| TENANT           | 系统租户指定待取消校验任务的用户租户，仅系统租户可指定该参数。系统租户下，如果不指定具体用户租户，则默认取消集群内所有用户租户下正在执行的校验任务。  |

## 示例

* 系统租户取消用户用户正在执行的备份校验任务。

  * 系统租户取消所有用户租户的备份校验任务。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP;
    ```

  * 系统租户取消指定用户租户 `mysqltenant` 的备份校验任务。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM CANCEL VALIDATE BACKUP TENANT = mysqltenant;
    ```

* 用户租户取消本租户正在执行的备份校验任务。

  ```shell
  obclient> ALTER SYSTEM CANCEL VALIDATE BACKUP;
  ```
