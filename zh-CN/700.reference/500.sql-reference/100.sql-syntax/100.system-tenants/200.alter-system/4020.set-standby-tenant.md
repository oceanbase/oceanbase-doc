# SET STANDBY TENANT
## 描述
`ALTER SYSTEM SET STANDBY TENANT` 语句用于设置主租户的保护模式。

## 使用限制及注意事项
+ 对于 V4.4.2 版本，OceanBase 数据库从 V4.4.2 BP1 版本开始支持设置保护模式。
+ 保护模式只能在主租户上设置。
+ 对于处于最大性能模式的主租户，如果需要将保护模式设置为最大可用模式或最大保护模式，要求主租户已设置了强同步的备租户。为主租户设置强同步的备租户的 SQL 语句，参见 [SET SYNC_STANDBY_DEST](4000.set-sync-standby-dest.md)。对于处于最大保护模式或最大可用模式的租户，可以直接将保护模式修改为最大性能模式。
+ 不支持设置级联的备租户进入强同步模式。
+ 将租户从最大性能模式或者最大可用模式设置为最大保护模式时，要求强同步的备租户的同步位点与主租户的同步位点相差不超过 5 秒。

## 权限要求
需要由 `sys` 租户的 `root` 用户（`root@sys`） 或各租户的管理员用户执行。其中：

+ MySQL 模式的默认管理员用户为 `root` 用户。
+ Oracle 模式的默认管理员用户为 `SYS` 用户。

## 语法
```sql
ALTER SYSTEM SET STANDBY TENANT TO {MAXIMIZE PERFORMANCE} | {MAXIMIZE AVAILABILITY} | {MAXIMIZE PROTECTION} [TENANT = tenant_name];
```

## 参数说明
| 参数 | 描述 |
| --- | --- |
| {MAXIMIZE PERFORMANCE} | {MAXIMIZE AVAILABILITY} | {MAXIMIZE PROTECTION} | 指定保护模式为最大性能模式（MAXIMIZE PERFORMANCE）、最大可用模式（MAXIMIZE AVAILABILITY）还是最大保护模式（MAXIMIZE PROTECTION）。 |
| tenant_name | 系统租户指定待执行该操作的租户名。<br/>#### 注意<br/>仅系统租户在执行此命令时需要通过 `TENANT tenant_name` 子句指定待操作的租户，用户租户只能对本租户执行此命令，故不需要指定该子句。 |


## 示例
+ 系统租户将主租户 mysql 的保护模式设置为最大可用模式。

```shell
obclient(root@sys)[(none)]> ALTER SYSTEM SET STANDBY TENANT TO MAXIMIZE AVAILABILITY TENANT = mysql;
```

+ 用户租户将本租户的保护模式设置为最大可用模式。

```shell
obclient> ALTER SYSTEM SET STANDBY TENANT TO MAXIMIZE AVAILABILITY;
```
