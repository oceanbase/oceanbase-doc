# FLUSH SEQUENCE CACHE

## 描述

该语句用来清除 Sequence 缓存。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该语句从 V4.4.1 版本开始引入。</p>
</main>

## 权限要求

执行该语句需要当前用户拥有 `ALTER SYSTEM` 权限。更多有关 OceanBase 数据库权限的详细介绍，参见 [MySQL 模式下的权限分类](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)。

## 语法

```sql
ALTER SYSTEM FLUSH SEQUENCE CACHE
    SEQUENCE_NAME = sequence_name
    TENANT = 'tenant_name'
    DATABASES = 'database_name'
    [GLOBAL];
```

## 参数解释

|               参数              |         描述      |
|---------------------------------|------------------|
| SEQUENCE_NAME = 'sequence_name' | 用于指定需要清除本地缓存的 Sequence 的名称。|
| TENANT = 'tenant_name'          | 用于指定在哪个租户下执行本操作。|
| DATABASES = 'database_name'     | 用于指定在哪个 DataBase 下执行本操作。|
| GLOBAL                          | 可选项，表示清除所有节点上的缓存。如果不指定该参数，则只清除本节点缓存。|

## 示例

* 在 `mysql001` 租户和名为 `test` 的 DataBase 下，清除本节点上 Sequence 名为 `test_seq1` 的缓存。

    ```shell
    obclient> ALTER SYSTEM FLUSH SEQUENCE CACHE
        SEQUENCE_NAME = test_seq1
        DATABASES = 'test'
        TENANT = 'mysql001';
    ```

* 在 `mysql001` 租户和名为 `test` 的 DataBase 下，清除所有节点上 Sequence 名为 `test_seq1` 的缓存。

    ```shell
    obclient> ALTER SYSTEM FLUSH SEQUENCE CACHE
        SEQUENCE_NAME = test_seq1
        DATABASES = 'test'
        TENANT = 'mysql001'
        GLOBAL;
    ```
