# TRIGGER TTL

## 描述

`ALTER SYSTEM TRIGGER TTL` 语句用于手动触发一个租户级别的过期数据（TTL，Time-To-Live）任务。已过期的数据将在后续的 Compaction（合并）任务中被删除。

## 权限要求

执行 `ALTER SYSTEM TRIGGER TTL` 语句需要当前用户拥有 `ALTER SYSTEM` 权限。有关 OceanBase 数据库权限的详细介绍，请参见 [MySQL 模式下的权限分类](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md) 和 [Oracle 模式下的权限分类](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 语法

```sql
ALTER SYSTEM TRIGGER TTL [TENANT [=] all | all_user | tenant_list];

tenant_list:
  tenant_name[,tenant_name ...]
```

## 参数解释

|    参数        |        描述          |
|---------------|------------------------|
| TENANT        | 系统租户下指定待发起 TTL 任务的用户租户。系统租户下执行时，必须指定用户租户。支持同时指定多个租户名，不同租户名之间使用英文逗号（,）分隔。<main id="notice" type='notice'> <h4>注意</h4><p>仅系统租户在执行此命令时需要通过 <code>TENANT</code> 子句指定待操作的租户，用户租户只能对本租户执行此命令，故不能指定 <code>TENANT</code> 子句。</p></main>       |

## 示例

* 系统租户指定用户租户 `tenant1` 触发一次 TTL 任务。

  1. 为租户 `tenant1` 开启 TTL 功能。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM SET enable_ttl = True TENANT = tenant1;
     ```

  2. 指定用户租户 `tenant1` 手动触发一次 TTL 任务。

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM TRIGGER TTL TENANT = tenant1;
     ```

* 用户租户触发本租户的 TTL 任务。

  1. 开启 TTL 功能。

     ```shell
     obclient(root@mysql001)[(none)]> ALTER SYSTEM SET enable_ttl = True;
     ```

  2. 手动触发一次 TTL 任务。

     ```shell
     obclient(root@mysql001)[(none)]> ALTER SYSTEM TRIGGER TTL;
     ```
