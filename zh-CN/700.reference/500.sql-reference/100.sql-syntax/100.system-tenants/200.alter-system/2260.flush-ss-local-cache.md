# FLUSH LOCAL CACHE

<main id="notice" >
<h4>功能适用性</h4>
<p>该语句仅适用于共享存储（Shared-Storage，SS）模式。</p>
</main>

## 描述

`ALTER SYSTEM FLUSH LOCAL CACHE` 语句用于清理共享存储（Shared-Storage，SS）模式下指定租户的指定类型的本地缓存数据。

## 权限要求

需要由 `sys` 租户的 `root` 用户执行。用户租户不支持该语句。

## 语法

```sql
ALTER SYSTEM FLUSH LOCAL CACHE TENANT [=] tenant_name [CACHE [=] cache_type];

cache_type:
    micro_cache
  | macro_cache
  | mem_macro_cache
  | hot_macro_cache
```

## 参数说明

|       参数        |               描述                                   |
|-------------------|------------------------------------------------------|
| tenant_name       | 指定待清理本地缓存的用户租户。一条语句仅支持指定一个租户。|
| cache_type        | 指定待清理的本地缓存的类型。一条语句仅支持指定一个类型。支持指定的类型如下：<ul><li>`micro_cache`：本地持久化微块缓存</li> <li>`macro_cache`：本地持久化宏块缓存</li> <li>`mem_macro_cache`：本地内存宏块缓存</li> <li>`hot_macro_cache`：本地持久化用户热点数据缓存</li></ul><p>如果不使用 `CACHE [=] cache_type` 指定待清理的本地缓存类型，则默认清理本地缓存所有类型的数据。</p> |

## 示例

* `sys` 租户下，清理租户 `mysql_tenant` 本地缓存的所有类型的数据。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH LOCAL CACHE TENANT = 'mysql_tenant';
  ```

* `sys` 租户下，清理租户 `mysql_tenant` 本地缓存的内存宏块缓存数据。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH LOCAL CACHE TENANT = 'mysql_tenant' CACHE = 'mem_macro_cache';
  ```
