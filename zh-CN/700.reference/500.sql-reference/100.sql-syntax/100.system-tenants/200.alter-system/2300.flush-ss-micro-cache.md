# FLUSH ss_micro_cache

<main id="notice" >
<h4>功能适用性</h4>
<p>该语句仅适用于共享存储（Shared-Storage，SS）模式。</p>
</main>

## 描述

`ALTER SYSTEM FLUSH ss_micro_cache` 语句用于清理共享存储（Shared-Storage，SS）模式下指定租户的微块缓存数据。

## 权限要求

需要由 `sys` 租户的 `root` 用户执行。用户租户不支持该语句。

## 语法

```sql
ALTER SYSTEM FLUSH ss_micro_cache TENANT [=] tenant_name;
```

## 参数说明

|       参数        |               描述                                   |
|-------------------|------------------------------------------------------|
| tenant_name       | 指定待清理微块缓存的用户租户。一条语句仅支持指定一个租户。|

## 示例

`sys` 租户下，清理租户 `mysql_tenant` 的微块缓存数据。

```shell
obclient> ALTER SYSTEM FLUSH ss_micro_cache TENANT = 'mysql_tenant';
```
