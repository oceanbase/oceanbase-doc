# BALANCE JOB

## 描述

该语句用于暂停（SUSPEND）、恢复（RESUME）或取消（CANCEL）Balance Job。

当租户有正在执行的 Balance Job 时，又有其他紧急变更需要执行，为了防止该 Balance Job 的执行影响紧急变更，用户可以选择先暂停当前正在执行的 Balance Job，待紧急变更执行完后，再恢复该 Job，继续执行。

如果当前进行的 Balance Job 与您的需求不符，可以选择取消该任务。此外，若您启动了 Transfer Partition，但由于存在正在执行的 Balance Job 而导致任务启动延迟，也可以取消当前进行的 Balance Job。

## 使用限制及注意事项

* 该语句只能在主库（即主租户）上执行。

* 对于 V4.2.5 版本，从 V4.2.5 BP2 版本开始支持暂停和恢复 Balance Job。

* 暂停或恢复 Balance Job 的操作只能在主库（即主租户）上执行。

* 暂停或恢复 Balance Job 时，要求该 Balance Job 的状态不能是 `CANCELING`。

## 权限要求

当前用户拥有 `ALTER SYSTEM` 权限。

## 语法

```sql
ALTER SYSTEM {SUSPEND | RESUME | CANCEL} BALANCE JOB [TENANT = 'tenant_name'];
```

## 参数说明

| 参数         | 描述        |
|--------------|------------|
| tenant_name  | 指定要取消任务的租户名称。可选项，在系统租户下执行时必须指定。|

## 示例

以下以系统租户下的操作为例。

1. 查询当前正在执行的任务及状态。

    ```shell
    obclient> SELECT T.TENANT_NAME, J.TENANT_ID, J.JOB_ID, J.CREATE_TIME, J.MODIFY_TIME, J.BALANCE_STRATEGY, J.JOB_TYPE, j.STATUS
    FROM oceanbase.CDB_OB_BALANCE_JOBS J, oceanbase.DBA_OB_TENANTS T
    WHERE J.TENANT_ID = T.TENANT_ID;
    ```

    返回结果如下：

    ```shell
    +-------------+-----------+--------+----------------------------+----------------------------+---------------------------+--------------+--------+
    | TENANT_NAME | TENANT_ID | JOB_ID | CREATE_TIME                | MODIFY_TIME                | BALANCE_STRATEGY          | JOB_TYPE     | STATUS |
    +-------------+-----------+--------+----------------------------+----------------------------+---------------------------+--------------+--------+
    | oracle001   |      1004 | 300793 | 2024-02-29 16:45:12.864110 | 2024-02-29 16:45:12.864110 | LS balance by shrink      | LS_BALANCE   | DOING  |
    +-------------+-----------+--------+----------------------------+----------------------------+---------------------------+--------------+--------+
    1 row in set
    ```

2. 根据业务情况，选择合适的操作：

   * 暂停正在进行的 Balance Job

        ```shell
        obclient> ALTER SYSTEM SUSPEND BALANCE JOB TENANT = 'oracle001';
        ```

   * 恢复被暂停的 Balance Job

        ```shell
        obclient> ALTER SYSTEM RESUME BALANCE JOB TENANT = 'oracle001';
        ```

   * 取消不符合预期的 Balance Job

        ```shell
        obclient> ALTER SYSTEM CANCEL BALANCE JOB TENANT = 'oracle001';
        ```
