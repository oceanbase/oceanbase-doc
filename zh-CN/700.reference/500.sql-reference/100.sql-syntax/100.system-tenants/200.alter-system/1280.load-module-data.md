# LOAD MODULE DATA

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该语句从 V4.4.0 版本开始引入。</p>
</main>

## 描述

该语句用于向某个特定租户导入指定功能。

## 语法

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>仅 SYS 租户允许执行该命令。</p>
</main>

语法如下：

```sql
ALTER SYSTEM LOAD MODULE DATA
 module = {gis|timezone}
 tenant = <tenant_name>
 infile = <file_name>;
```

## 语法说明

|   **字段**  | **说明** |
| ----------- | -------- |
| module     | 必选。<ul><li>`module = gis`：表示操作 gis 功能。</li><li>`module = timezone`：表示操作 timezone 功能。</li></ul> |
| tenant     | 必选。对指定租户进行操作。|
| infile     | 可选。导入数据文件的路径。可以填绝对路径或者是 OBServer 工作目录的相对路径，如果不填使用内部默认文件路径及文件名。|

## 示例

向 MysQL 租户导入空间数据模块功能：

```sql
ALTER SYSTEM LOAD MODULE DATA module=gis tenant=mysql;
```
