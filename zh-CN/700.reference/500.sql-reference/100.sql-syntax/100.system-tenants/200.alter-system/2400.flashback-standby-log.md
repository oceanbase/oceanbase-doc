# FLASHBACK STANDBY LOG

## 描述

`ALTER SYSTEM FLASHBACK STANDBY LOG` 语句用于将备租户的日志裁剪到指定位点。该语句通常用于执行 Failover 后，将原主租户的备租户接入新主租户。

## 使用限制及注意事项

* 对于 V4.2.5 版本，从 V4.2.5 BP4 开始支持日志裁剪功能。

* 执行该语句需要保证当前备租户已停止日志同步并且其恢复源为空。

* 待进行日志裁剪的备租户不允许有合法副本在下线的机器上。

* 仅允许对备租户执行该语句，且要求该备租户的 `STATUS` 为 `NORMAL`，`SWITCHOVER_STATUS` 为 `NORMAL` 或者 `FLASHBACK_AND_STAY_STANDBY_STATUS`。

* 当备租户的 `SWITCHOVER_STATUS` 为 `FLASHBACK_AND_STAY_STANDBY_STATUS` 时，不允许该备租户继续进行日志同步，也不允许修改该备租户的恢复源。

* 指定日志裁剪位点时，要求指定的位点必须大于或等于该备租户的同步位点。

* 执行该语句会自动清除租户的服务名（`SERVICE_NAME`）。

## 权限要求

需要由 `sys` 租户的 `root` 用户（`root@sys`） 或各租户的管理员用户执行。其中：

* MySQL 模式的默认管理员用户为 `root` 用户。
* Oracle 模式的默认管理员用户为 `SYS` 用户。

## 语法

```sql
ALTER SYSTEM FLASHBACK STANDBY LOG TO SCN = flashback_log_scn [TENANT = 'tenant_name'];
```

## 参数说明

|            参数        |              描述                                                       |
|------------------------|-------------------------------------------------------------------------|
| flashback_log_scn      | 指定备租户日志裁剪到的指定位点。要求指定的位点必须大于或等于该备租户的同步位点。 |
| tenant_name            | 系统租户指定待执行日志裁剪的备租户。仅系统租户在执行该语句时需要指定租户。 |

## 示例

假设已确认的日志裁剪位点为 `4611686018427387903`，对备租户 `standby_tenant` 执行日志裁剪的示例如下。

* 系统租户将指定租户 `standby_tenant` 的日志裁剪到指定位点。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLASHBACK STANDBY LOG TO SCN = 4611686018427387903 TENANT = standby_tenant;
  ```

* 备租户将本租户的日志裁剪到指定位点。

  ```shell
  obclient> ALTER SYSTEM FLASHBACK STANDBY LOG TO SCN = 4611686018427387903;
  ```
