# DELETE BACKUP ALL

`DELETE BACKUP ALL` 语句用于清空指定路径（数据备份路径或归档路径）中的备份集或日志归档 Piece。

## 使用限制及注意事项

使用 `DELETE BACKUP ALL` 语句清空指定路径中的备份集或日志归档 Piece 时：

* 仅支持清空被替换的备份或归档路径，不支持清空当前正在使用的备份或归档路径。
* 不支持将正在清空的旧路径重新设置为备份路径或归档路径。
* 数据备份路径或归档路径被清空后，视图 [CDB_OB_BACKUP_STORAGE_INFO(sys 租户)](../../../../700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7300.o-cdb_ob_backup_storage_info-of-sys-tenant.md) 和 [DBA_OB_BACKUP_STORAGE_INFO（用户租户）](../../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/7300.o-dba_ob_backup_storage_info-of-mysql-mode.md) 中将会删除对应的路径信息。

## 权限要求

需要由 `sys` 租户的 `root` 用户（`root@sys`） 或各租户的管理员用户执行。其中：

* MySQL 模式的默认管理员用户为 `root` 用户。
* Oracle 模式的默认管理员用户为 `SYS` 用户。

## 语法

```sql
ALTER SYSTEM DELETE BACKUP ALL delete_backup_action [TENANT [=] tenant_name];

delete_backup_action:
  DATA_BACKUP_DEST [=] 'data_backup_path'
| LOG_ARCHIVE_DEST [=] 'log_archive_path'
```

## 参数说明

| 参数            | 描述                                                     |
|-----------------|---------------------------------------------------------|
| data_backup_path | 指定待清空的数据备份路径。 |
| log_archive_path | 指定待清空的归档路径。 |
| tenant_name     | 指定待清空路径的用户租户名称。可选，仅在系统租户下执行时需要指定。   |

## 示例

* 系统租户

  * 清空数据备份路径。

    :::tab
    tab OSS

    系统租户清空租户 `mysql001` 的 OSS 备份路径 `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com`。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com' TENANT = mysql001;
    ```

    tab NFS

    系统租户清空租户 `mysql001` 的 NFS 备份路径 `file:///data/nfs/backup/data`。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='file:///data/nfs/backup/data' TENANT = mysql001;
    ```

    :::

  * 清空归档路径。

    :::tab
    tab OSS

    系统租户清空租户 `mysql001` 的 OSS 归档路径 `oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com`。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com' TENANT = mysql001;
    ```

    tab NFS

    系统租户清空租户 `mysql001` 的 NFS 归档路径 `file:///data/nfs/backup/archive`。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='file:///data/nfs/backup/archive' TENANT = mysql001;
    ```

    :::

* 用户租户

  * 清空数据备份路径。

    :::tab
    tab OSS

    用户租户清空本租户的 OSS 备份路径 `oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com`。

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='oss://oceanbase-test-bucket/backup/data?host=****.aliyun-inc.com';
    ```

    tab NFS

    用户租户清空本租户的 NFS 备份路径 `file:///data/nfs/backup/data`。

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='file:///data/nfs/backup/data';
    ```

    :::

  * 清空归档路径。

    :::tab
    tab OSS

    用户租户清空本租户的 OSS 归档路径 `oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com`。

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='oss://oceanbase-test-bucket/backup/archive?host=****.aliyun-inc.com';
    ```

    tab NFS

    用户租户清空本租户的 NFS 归档路径 `file:///data/nfs/backup/archive`。

    ```shell
    obclient> ALTER SYSTEM DELETE BACKUP ALL LOG_ARCHIVE_DEST ='file:///data/nfs/backup/archive';
    ```

    :::
