# DELETE OBSOLETE BACKUP

`DELETE OBSOLETE BACKUP` 语句用于手动触发备份的过期清理。

## 使用限制

* `sys` 租户执行 `DELETE OBSOLETE BACKUP` 语句时，如果指定了用户租户，则要求被指定的用户租户已设置清理策略；如果未指定用户租户，则要求所有用户租户均已设置自动清理策略。

* 用户租户执行 `DELETE OBSOLETE BACKUP` 语句时，要求当前用户租户已设置自动清理策略。

设置自动清理策略的 SQL 语句，参见 [DELETE BACKUP POLICY](1270.delete-backup.md)。

## 权限要求

需要由 `sys` 租户的 `root` 用户（`root@sys`） 或各租户的管理员用户执行。其中：

* MySQL 模式的默认管理员用户为 `root` 用户。
* Oracle 模式的默认管理员用户为 `SYS` 用户。

## 语法

```sql
ALTER SYSTEM DELETE OBSOLETE BACKUP [TENANT [=] tenant_name]; 
```

## 参数说明

| 参数            | 描述                                                     |
|-----------------|---------------------------------------------------------|
| tenant_name     | 用于系统租户指定触发哪个用户租户备份或归档的过期清理。系统租户下，如果不指定用户租户，则默认触发所有用户租户备份或归档的过期清理。  |

## 示例

* 系统租户

  * 系统租户触发租户 `mysql001` 备份的过期清理。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE OBSOLETE BACKUP TENANT mysql001;
    ```

  * 系统租户触发所有用户租户备份的过期清理。

    ```shell
    obclient(root@sys)[(none)]> ALTER SYSTEM DELETE OBSOLETE BACKUP;
    ```

* 用户租户

  用户租户下，触发本租户备份的过期清理。

  ```shell
  obclient> ALTER SYSTEM DELETE OBSOLETE BACKUP;
  ```
