# DELETE BACKUPSET/ARCHIVELOG_PIECE

`DELETE BACKUPSET/ARCHIVELOG_PIECE` 语句用于清理指定的数据备份集或日志归档 Piece。

## 使用限制及注意事项

* 使用 `DELETE BACKUPSET` 语句清理指定的数据备份集时，需要注意以下事项：

  * 不能破坏数据备份之间的依赖关系。如果某个数据备份被关联的增量备份所依赖，则被依赖的数据备份只能在所有依赖它的增量备份被删除后，才能被删除。

  * 如果需要同时指定多个 `backup_set_id` 进行清理，则要求所有 `backup_set_id` 均在同一个备份路径下。不支持在同一条命令中清理多个路径下的数据备份。

  * 对于当前正在使用的备份路径，需要至少保留一份最新的且能够用于恢复的全量数据备份。即，保留一份可用于恢复的全量备份后，才可以删除在该备份集之前的其它备份集。

  * 如果待删除的数据备份集不在当前正在使用的备份路径中，需要保证 OceanBase 数据库有对应备份路径的访问权限。

* 使用 `DELETE ARCHIVELOG_PIECE` 语句清理指定的日志归档 Piece 时，需要注意以下事项：

  * 需要按照顺序清理日志归档 Piece。

  * 清理当前归档路径中的 Piece 时，要求被清理的 Piece 不被当前数据备份路径中的任何数据备份所依赖。

  * 如果需要同时指定多个 `piece_id` 进行清理，则要求所有 `piece_id` 均在同一个归档路径下。不支持在同一条命令中清理多个路径下的日志归档 Piece。

## 权限要求

需要由 `sys` 租户的 `root` 用户（`root@sys`） 或各租户的管理员用户执行。其中：

* MySQL 模式的默认管理员用户为 `root` 用户。
* Oracle 模式的默认管理员用户为 `SYS` 用户。

## 语法

```sql
ALTER SYSTEM DELETE delete_action [TENANT [=] tenant_name];

delete_action:
  BACKUPSET backup_set_id[,backup_set_id,...] 
| ARCHIVELOG_PIECE piece_id[,piece_id,...]
```

## 参数说明

| 参数            | 描述                                                     |
|-----------------|---------------------------------------------------------|
| backup_set_id   | 指定待删除的备份集的 ID，可通过视图 `CDB_OB_BACKUP_SET_FILES`（系统租户）或 `DBA_OB_BACKUP_SET_FILES`（用户租户）查询获取。单条命令中支持同时指定多个数据备份集，不同 `backup_set_id` 之间使用英文逗号间隔。同时指定多个 `backup_set_id` 进行清理时，要求所有 `backup_set_id` 均在同一个备份路径下。不支持在同一条命令中清理多个路径下的数据备份。 |
| piece_id        | 指定待删除的日志归档 Piece 的 ID，可通过视图 `CDB_OB_ARCHIVELOG_PIECE_FILES`（系统租户）或 `DBA_OB_ARCHIVELOG_PIECE_FILES`（用户租户）查询获取。单条命令中支持同时指定多个 Piece。同时指定多个 `piece_id` 进行清理时，要求所有 `piece_id` 均在同一个备份路径下。不支持在同一条命令中清理多个路径下的日志归档 Piece。 |
| tenant_name     | 指定待清理备份的用户租户名称。可选，仅在系统租户下执行时需要指定。   |

## 示例

* 系统租户

  * 清理指定的数据备份集。

    * 系统租户删除租户 `mysql001` 的 `backup_set_id` 为 3 的数据备份集。

      ```shell
      obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUPSET 3 TENANT = mysql001;
      ```

    * 系统租户同时删除租户 `mysql001` 的 `backup_set_id` 为 1、2、4 的 3 个数据备份集。

      ```shell
      obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUPSET 1,2,4 TENANT = mysql001;
      ```

  * 清理指定的日志归档 Piece。

    * 系统租户删除租户 `mysql001` 的 `piece_id` 为 5 的日志归档 Piece。

      ```shell
      obclient(root@sys)[(none)]> ALTER SYSTEM DELETE ARCHIVELOG_PIECE 5 TENANT = mysql001;
      ```

    * 系统租户同时删除租户 `mysql001` 的 `piece_id` 为 6、7、8、9 的 4 个日志归档 Piece。

      ```shell
      obclient(root@sys)[(none)]> ALTER SYSTEM DELETE ARCHIVELOG_PIECE 6,7,8,9 TENANT = mysql001;
      ```

* 用户租户

  * 清理指定的数据备份集。

    * 用户租户删除本租户 `backup_set_id` 为 3 的数据备份集。

      ```shell
      obclient> ALTER SYSTEM DELETE BACKUPSET 3;
      ```

    * 用户租户同时删除本租户 `backup_set_id` 为 1、2、4 的 4 个数据备份集。

      ```shell
      obclient> ALTER SYSTEM DELETE BACKUPSET 1,2,4;
      ```

  * 清理指定的日志归档 Piece。

    * 用户租户删除本租户 `piece_id` 为 5 的日志归档 Piece。

      ```shell
      obclient> ALTER SYSTEM DELETE ARCHIVELOG_PIECE 5;
      ```

    * 用户租户同时删本租户 `piece_id` 为 6、7、8、9 的 4 个日志归档 Piece。

      ```shell
      obclient> ALTER SYSTEM DELETE ARCHIVELOG_PIECE 6,7,8,9;
      ```
