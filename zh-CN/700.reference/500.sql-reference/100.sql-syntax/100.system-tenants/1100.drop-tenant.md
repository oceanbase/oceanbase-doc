# DROP TENANT

## 描述

`DROP TENANT` 语句用于删除一个 OceanBase 数据库租户。

## 权限要求

仅 `sys` 租户的 `root` 用户（`root@sys`）可以删除租户，其他租户不支持删除租户。

## 语法

```sql
DROP TENANT [IF EXISTS] tenant_name [PURGE | FORCE];
```

## 参数解释

|   **参数**    |                **描述**                |
|-------------|--------------------------------------|
| tenant_name | 指定要删除的租户名。                           |
| IF EXISTS   | 如果该租户不存在，系统不报错，也不会执行任何操作，但会给出信息提示。|
| PURGE       | 表示删除租户。删除后的租户不会进入回收站。当 `sys` 租户的回收站功能关闭时， `DROP TENANT` 语句与 `DROP TENANT... PURGE` 语句的效果一样。 |
| FORCE       | 表示强制删除租户，无法保证物理备份数据的完整性。删除后的租户不会进入回收站。 |

## 示例

- 删除一个存在的租户

如果你确定要删除名为 `example_tenant` 的租户，并且该租户存在，可以使用以下命令：

```shell
obclient> DROP TENANT example_tenant;
```

-  删除一个可能不存在的租户

如果不确定租户 `unsure_tenant` 是否存在，可以使用 `IF EXISTS` 选项来避免在租户不存在时抛出错误：

```shell
obclient> DROP TENANT IF EXISTS unsure_tenant;
```

- 延迟删除租户

如果你想要延迟删除租户 `delayed_tenant`，并且确保它不会进入回收站，可以使用 `PURGE` 选项：

```shell
obclient> DROP TENANT delayed_tenant PURGE;
```

- 立刻删除租户

如果你需要立即删除租户 `immediate_tenant`，不论回收站是否启用，可以使用 `FORCE` 选项：

```shell
obclient> DROP TENANT immediate_tenant FORCE;
```
