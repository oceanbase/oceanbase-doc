# 简单表达式

简单表达式（Simple Expression）可以是列、伪列、常量或空值。

简单表达式语法如下：

```sql
{ [database_name.]table_name.column_name
| column_name
| table_name.*
| literal
| NULL
| + simple_expr
| - simple_expr
| ~ simple_expr
| ! simple_expr
| ( expr )
| ROW ( expr [, expr ]... )
}
```

简单表达式的常见形式包括：

* **列引用**：`table_name.column_name` 或 `database_name.table_name.column_name`，例如 `employees.salary`。
* **常量**：字符串、数值等字面量，例如 `'welcome to OceanBase'`、`10`。
* **NULL**：空值。
* **一元运算符**：`+`、`-`、`~`（按位取反）、`!`（逻辑非）作用于单个简单表达式。
* **括号表达式**：`(expr)` 用于改变运算优先级。
* **行构造器**：`ROW(expr [, expr ]...)` 用于构造行值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><code>TRUE</code> 和 <code>FALSE</code> 不作为简单表达式字面量；它们仅用于布尔测试条件（<code>IS TRUE</code> / <code>IS FALSE</code>）。有关语法层次，请参见 <a href="200.expression-syntax-of-mysql-mode.md">表达式语法</a>。</p>
</main>

下列是一些有效的简单表达式示例：

* `employees.first_name`

* `'welcome to OceanBase'`

* `10`

* `-salary`
