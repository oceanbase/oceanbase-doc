# 复合表达式

复合表达式（Compound Expression）是由多种类型表达式经过算术运算、位运算或括号分组组合而成的表达式。

复合表达式语法如下：

```sql
{ simple_expr
| bit_expr { + | - | * | / | % | MOD | DIV } bit_expr
| bit_expr { & | | | ^ } bit_expr
| bit_expr { << | >> } bit_expr
| bit_expr { + | - } INTERVAL expr date_unit
}
```

其中：

* 算术运算符 `+`、`-`、`*`、`/`、`%`（或 `MOD`）、`DIV` 用于两个 `bit_expr` 之间的计算。
* 位运算符 `&`（与）、`|`（或）、`^`（异或）、`<<`（左移）、`>>`（右移）用于整数类型的表达式。
* `bit_expr + INTERVAL expr date_unit` 和 `bit_expr - INTERVAL expr date_unit` 用于日期时间运算，详见[日期时间表达式](250.date-and-time-expressions-of-mysql-mode.md)。

您可以使用任意内置函数作为一个简单表达式参与复合表达式的构建。

下列是一些有效的复合表达式示例：

* `(1 + 2) * 3`

* `LENGTH('OCEANBASE') * 2`

* `(salary + bonus) * 1.1`

* `NOW() + INTERVAL 7 DAY`
