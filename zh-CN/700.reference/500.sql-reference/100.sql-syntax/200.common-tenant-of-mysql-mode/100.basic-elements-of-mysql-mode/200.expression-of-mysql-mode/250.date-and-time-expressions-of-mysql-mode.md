# 日期时间表达式

日期时间表达式（Datetime Expression）用于生成日期时间数据类型的值，或在日期时间值上进行运算。

## 日期时间表达式语法

```sql
date_expr { + | - } INTERVAL expr date_unit
```

其中 `date_unit` 常用值包括：

* `DAY`、`WEEK`、`MONTH`、`QUARTER`、`YEAR`
* `HOUR`、`MINUTE`、`SECOND`、`MICROSECOND`
* 复合单位：`DAY_HOUR`、`DAY_MINUTE`、`DAY_SECOND`、`HOUR_MINUTE`、`HOUR_SECOND`、`YEAR_MONTH` 等

完整 `date_unit` 列表请参见 [表达式语法](200.expression-syntax-of-mysql-mode.md) 中的 `date_unit` 产生式。

## 使用说明

* `date_expr` 可以是 `DATE`、`DATETIME`、`TIMESTAMP` 类型的列或表达式。
* `INTERVAL expr date_unit` 用于指定一个时间间隔。
* 当 `date_expr` 与 `INTERVAL` 相加或相减时，结果为新的日期时间值。

## 示例

将当前日期增加 7 天：

```sql
obclient> SELECT NOW() + INTERVAL 7 DAY;
+----------------------------+
| NOW() + INTERVAL 7 DAY     |
+----------------------------+
| 2026-06-09 17:13:00        |
+----------------------------+
1 row in set
```

将当前日期减少 1 个月：

```sql
obclient> SELECT NOW() - INTERVAL 1 MONTH;
+----------------------------+
| NOW() - INTERVAL 1 MONTH   |
+----------------------------+
| 2026-05-02 17:13:00        |
+----------------------------+
1 row in set
```
