# 间隔表达式

间隔表达式（Interval Expression）用于表示和计算时间间隔。

在 MySQL 模式下，间隔表达式通常与日期时间表达式结合使用，语法如下：

```sql
INTERVAL expr date_unit
```

其中 `date_unit` 常用值包括：

* `DAY`、`WEEK`、`MONTH`、`QUARTER`、`YEAR`
* `HOUR`、`MINUTE`、`SECOND`、`MICROSECOND`
* 复合单位：`DAY_HOUR`、`DAY_MINUTE`、`DAY_SECOND`、`HOUR_MINUTE`、`HOUR_SECOND`、`YEAR_MONTH` 等

完整 `date_unit` 列表请参见 [表达式语法](200.expression-syntax-of-mysql-mode.md) 中的 `date_unit` 产生式。

## 使用说明

* 间隔表达式通常与 `+` 或 `-` 运算符一起使用，用于对日期时间值进行加减运算。
* `expr` 为一个整数值，表示时间间隔的数量。

## 示例

将当前日期增加 7 天：

```sql
obclient> SELECT DATE_ADD(NOW(), INTERVAL 7 DAY);
+--------------------------------+
| DATE_ADD(NOW(), INTERVAL 7 DAY) |
+--------------------------------+
| 2026-06-09 17:13:00            |
+--------------------------------+
1 row in set
```

计算两个日期之间的间隔：

```sql
obclient> SELECT TIMESTAMPDIFF(MONTH, '2026-01-01', '2026-06-01') AS month_diff;
+------------+
| month_diff |
+------------+
|          5 |
+------------+
1 row in set
```
