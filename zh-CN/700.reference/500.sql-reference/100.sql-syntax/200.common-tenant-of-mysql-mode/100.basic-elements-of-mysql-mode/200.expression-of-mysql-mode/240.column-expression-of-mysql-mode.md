# 列表达式

列表达式（Column Expression）是对表中列的引用，在表达式的语法中被命名为 `column_ref`。

列表达式的语法如下：

```sql
{ column_name
| table_name.column_name
| database_name.table_name.column_name
| table_name.*
}
```

列表达式可以出现在 SQL 语句的多个位置，例如：

* `SELECT` 语句的选择列中。
* `WHERE` 子句的条件中。
* `ORDER BY` 子句中。
* `GROUP BY` 子句中。
* `INSERT` 语句的 `VALUES` 子句中。
* `UPDATE` 语句的 `SET` 子句中。

列表达式是 SQL 语句中最基本的表达式形式之一。例如：

```sql
SELECT first_name, last_name FROM employees WHERE salary > 5000 ORDER BY last_name;
```

上述语句中，`first_name`、`last_name` 和 `salary` 均为列表达式。
