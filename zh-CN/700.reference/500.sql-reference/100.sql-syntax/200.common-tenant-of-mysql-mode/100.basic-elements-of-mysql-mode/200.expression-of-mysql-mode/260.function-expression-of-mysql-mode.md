# 函数表达式

函数表达式（Function Expression）使您可以使用任何内置 SQL 函数作为表达式。

函数表达式语法如下：

```sql
function_name ( [ expr [, expr ]... ] )
```

如下是一些有效的函数表达式：

* `LENGTH('OCEANBASE')`

* `ROUND(1234.5678, 2)`

* `NOW()`

* `CONCAT(first_name, ' ', last_name)`

* `ABS(salary - 5000)`

函数表达式支持窗口函数的使用。窗口函数语法如下：

```sql
function_name ( [ expr [, expr ]... ] ) OVER ( window_spec )
```

有关窗口函数的详细信息，请参见 [分析函数](../../400.functions-of-mysql-mode/400.analysis-functions-of-mysql-mode/)。
