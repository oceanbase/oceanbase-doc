# 表达式列表

表达式列表（Expression List）是一组由逗号分隔的表达式的组合，在语法中被命名为 `expr_list`。

表达式列表的语法如下：

```sql
expr [, expr ]...
```

行值构造器（Row Value Constructor）语法如下：

```sql
ROW ( expr [, expr ]... )
```

表达式列表可以出现在 `IN` 条件以及查询的 `GROUP BY` 子句中。在 `IN` 条件中的表达式列表有时被称为行构造器（Row Constructor）。

## 使用说明

* 在 `IN` 条件中，括号内的表达式列表表示候选值集合。
* `ROW(expr [, expr ]...)` 用于显式构造行值，语法等价于 `(expr [, expr ]...)`。

## 示例

下例是一些有效的表达式列表：

```sql
obclient> (100, 200, 300)
obclient> ('SCOTT', 'BLAIR', 'MARK')
obclient> ROW(1, 'apple', 'red')
```

在 `GROUP BY` 子句中，表达式列表示例如下：

```sql
obclient> SELECT dept_id, MIN(salary) min, MAX(salary) max FROM emp
    GROUP BY dept_id, salary
    ORDER BY dept_id, min, max;
```
