# IN 条件

`IN` 条件（IN Condition）是成员资格条件。它测试值或子查询列表中成员的值。

`IN` 条件语法如下：

```sql
expr [NOT] IN  ({ expression_list | subquery })
| (expr [, expr ...]) [NOT] IN ({expression_list [, expression_list ...]
                                  | subquery })
```

`IN` 条件可以测试表达式是否属于表达式列表或子查询的成员，或者多个表达式是否属于表达式列表或子查询的成员。每个表达式列表中的表达式必须在数量和数据类型上与运算符 `IN` 左边的表达式匹配。支持在 `expression_list` 中指定超过 1000 个表达式。 `IN` 条件主要有以下两种形式：

* `IN` 是匹配集合中的任一成员。如果想在集合中匹配任一成员，可以使用 `IN` 关键字。例如：`SELECT * FROM table_name WHERE column_name IN ('value1', 'value2');`。

* `NOT IN` 是不匹配集合中的所有成员：如果想在集合中不匹配任一成员，可以使用 `NOT IN` 关键字。例如：`SELECT * FROM table_name WHERE column_name NOT IN ('value1', 'value2');`。

## 示例

* `IN` 条件主要有以下两种形式：

  ```sql
  SELECT * FROM emp
  WHERE job_id IN ('PU_CLERK','SH_CLERK')
  ORDER BY emp_id;
  ```

  ```sql
  SELECT * FROM emp
  WHERE salary IN (SELECT salary  FROM emp WHERE dept_id =30)
  ORDER BY emp_id;
  ```

* `NOT IN` 条件主要有以下两种形式：

  ```sql
  SELECT * FROM emp
  WHERE salary NOT IN (SELECT salary FROM emp WHERE dept_id = 30)
  ORDER BY emp_id;
  ```

  ```sql
  SELECT * FROM emp
  WHERE job_id NOT IN ('PU_CLERK', 'SH_CLERK')
  ORDER BY emp_id;
  ```
