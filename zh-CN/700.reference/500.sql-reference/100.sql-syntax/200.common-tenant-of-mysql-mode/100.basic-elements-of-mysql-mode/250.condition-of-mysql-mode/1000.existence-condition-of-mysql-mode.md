# EXISTS 条件

EXISTS 条件（EXISTS Condition）用于测试子查询中是否存在指定的行。

## EXISTS 条件语法

EXISTS 条件语法如下：

```sql
EXISTS (subquery)
```

如果子查询至少返回一行，则说明存在您想要的数据。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.2.1 版本，<code>EXISTS</code> 子查询从 V4.2.1 BP9 版本开始支持返回外层表字段。例如，<code>SELECT * FROM t1 WHERE EXISTS (SELECT t1.* FROM t2 WHERE t1.c1 = t2.c1);</code>。</p>
</main>

## 示例

1. 创建测试表 `tbl1` 和 `tbl2`。

    ```sql
    CREATE TABLE tbl1(col1 INT, col2 varchar(50), col3 INT);
    ```

    ```sql
    CREATE TABLE tbl2(col1 INT, col2 varchar(50), col3 INT);
    ```

2. 向表 `tbl1` 和 `tbl2` 中插入测试数据。

    ``` sql
    INSERT INTO tbl1 VALUES(1, 'A1', 100),(2, 'A2', 200),(3, 'A3', 300);
    ```

    ```sql
    INSERT INTO tbl2 VALUES(1, 'A1', 100),(2, 'A1', 200),(3, 'A3', 300);
    ```

3. 查询 `tbl1` 中所有满足条件 `tbl1.col1 = tbl2.col1` 的行。

    ```sql
    SELECT * FROM tbl1 
    WHERE EXISTS (SELECT * FROM tbl2
                    WHERE tbl1.col1 = tbl2.col1);
    ```

    返回结果如下：

    ```shell
    +------+------+------+
    | col1 | col2 | col3 |
    +------+------+------+
    |    1 | A1   |  100 |
    |    2 | A2   |  200 |
    |    3 | A3   |  300 |
    +------+------+------+
    3 rows in set
    ```
