# SET NAMES

## 描述

该语句用于设置客户端、连接与结果字符集与字符序以及其他变量的值。

## 语法

```sql
SET NAMES charset_name [COLLATE collation_name] [var_and_val_list];

var_and_val_list:
    , var_and_val [,var_and_val ...]

var_and_val:
    var_value {TO | =} set_expr_or_default
    | var_value = (simple_select)
```

## 参数解释

|       参数     |                描述                |
|----------------|-----------------------------------|
| charset_name   | 指定表中列的默认字符集，可使用字符集如下：<ul><li>`binary` </li><li>`utf8mb4` </li><li>`gbk` </li><li>`utf16` </li><li>`gb18030` </li></ul>|
| collation_name | 可选项，指定表中列的默认字符序，可使用字符序如下：<ul><li>`binary` </li><li>`gbk_bin` </li><li>`gbk_chinese_ci` </li><li>`utf8mb4_general_ci` </li><li>`utf8mb4__general_cs` </li><li>`utf8mb4_bin` </li><li>`utf8mb4_unicode_ci` </li><li>`utf16_general_ci` </li><li>`utf16_bin` </li><li> `utf16_unicode_ci` </li><li> `gb18030_chinese_ci` </li><li>`gb18030_bin` </li></ul>|
| var_and_val_list | 可选项，用于设置一个或多个变量及其值的列表。设置多个变量，变量间使用英文逗号（`,`）分隔。详细信息请参见下文 [var_and_val](#var_and_val)。|

### var_and_val

`var_and_val`: 是设置单个系统变量及其值的表达式。

* `var_value {TO | =} set_expr_or_default`：

  * `var_value` 是变量的名称，
  * `set_expr_or_default`：变量应该被设置的值，或者关键字 `DEFAULT` 表示设置为默认值。

* `var_value = (simple_select)`：将变量设置为简单查询（`simple_select`）返回的值。

## 示例

* 指定客户端、连接与结果字符集为 `gbk` ，字符序为 `gbk_bin`。

    ```shell
    obclient [test]> SET NAMES gbk COLLATE gbk_bin;
    ```

* 指定客户端、连接与结果字符集为 `utf8mb4` ，字符序为 `utf8mb4_general_ci`。同时设置当前会话的 `wait_timeout` 变量值为 2147483 秒，对自定义的变量 @a 进行设定，将其值设置为 1。

    ```shell
    obclient [test]> SET NAMES utf8mb4 COLLATE utf8mb4_general_ci, @@session.wait_timeout = 2147483, @a = 1;
    ```
