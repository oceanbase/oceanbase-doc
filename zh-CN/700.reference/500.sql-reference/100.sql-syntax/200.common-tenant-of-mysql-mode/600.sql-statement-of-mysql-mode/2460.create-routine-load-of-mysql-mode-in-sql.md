# CREATE ROUTINE LOAD

## 描述

该语句用于创建 Routine Load 任务，将 Kafka 当作外表，持续从 Kafka 消费数据并导入到 OceanBase 数据库的表中。

## 权限要求

创建 Routine Load Job 需要当前用户具备目标表的 `INSERT` 权限。更多有关 OceanBase 数据库权限的详细介绍，请参见 [MySQL 模式下的权限分类](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)。

## 语法

```sql
CREATE ROUTINE LOAD job_name ON table_name
    [load_properties]
    FROM STREAM (job_properties);

load_properties:
    PARALLEL [=] int_value
    | COLUMNS (field_or_vars_list)
    | PARTITION (partition_name_list)
    | {IGNORE | REPLACE}
    | WHERE condition

job_properties:
    [TYPE = 'KAFKA']
    kafka_expr_list
    FORMAT [=] (format_options)

kafka_expr_list:
    "kafka_topic" = "string_value",
    ["kafka_partitions" = "string_value",] 
    ["kafka_offsets" = "string_value",]
    ["max_batch_interval" = "string_value",]
    ["max_batch_rows" = "string_value",]
    ["max_batch_size" = "string_value",]
    "bootstrap.servers" = "string_value",
    "security.protocol" = "string_value",
    "sasl.mechanism" = "string_value",
    "sasl.username" = "string_value",
    "sasl.password" = "string_value",

format_options:
    TYPE = 'CSV',
    LINE_DELIMITER = '<string>' | <expr>,
    FIELD_DELIMITER = '<string>' | <expr>,
    PARSE_HEADER = {TRUE | FALSE},
    ESCAPE = '<character>' | <expr>,
    FIELD_OPTIONALLY_ENCLOSED_BY = '<character>' | <expr>,
    ENCODING = 'charset',
    NULL_IF = ('<string>' | <expr>, '<string>' | <expr> ...),
    SKIP_HEADER = <int>,
    SKIP_BLANK_LINES = {TRUE | FALSE},
    TRIM_SPACE = {TRUE | FALSE},
    EMPTY_FIELD_AS_NULL = {TRUE | FALSE}
```

## 参数说明

| **参数** |       **描述**           |
|----------|--------------------------|
| job_name | 表示作业名称，用于标识一个 Routine Load 作业。|
| table_name | 表示目标表名，数据将导入到该表中。|
| load_properties | 可选项，表示数据加载属性配置。详细介绍可参见下文 [load_properties](#load_properties)。|
| job_properties | 表示数据源类型关配置参数。详细介绍可参见下文 [load_properties](#load_properties)。|

### load_properties

* `PARALLEL [=] int_value`：指定并行度，默认值为 1。
* `COLUMNS (field_or_vars_list)`：指定列映射关系。
* `PARTITION (partition_name_list)`：指定目标分区。
* `{IGNORE | REPLACE}`：指定处理重复数据的策略。

  * `IGNORE`：默认值，表示处理重复数据时忽略新数据。
  * `REPLACE`：表示处理重复数据时替换旧数据。

* `WHERE condition`：指定数据过滤条件，在数据写入目标表之前进行条件过滤。

### job_properties

* `TYPE = 'KAFKA'`：可选项，指定数据源类型。如果不指定，则默认是 `KAFKA`。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>当前版本数据源类型仅支持 <code>'KAFKA'</code>。</p>
    </main>

* `kafka_expr_list`：指定 Kafka 相关配置参数列表。具体如下：

  * `"kafka_topic"`：必选项，指定要消费的 Kafka topic 名称。
  * `"kafka_partitions"`：可选项，指定要消费的 Kafka 分区列表，用逗号分隔。如果不指定，则默认消费主题 Topic 下的所有分区。
  * `"kafka_offsets"`：可选项，指定消费的 Kafka offset，与 `"kafka_partitions"` 进行对应，即指定对应每个分区的起始 offset。如果不指定，则默认从 `OFFSET_END` 开始订阅 Topic 下的所有分区（Partition）。目前支持数字和 `OFFSET_BEGINNING`、`OFFSET_END` 混用。
  * `"max_batch_interval"`：可选项，Job 每轮 “每个导入线程” 最大运行时间，单位是秒，默认是 60s（导入线程数和并发度 `PARALLEL` 有关）。
  * `"max_batch_rows"`：可选项，Job 每轮 “每个导入线程” 最多读取的行数。必须大于等于 200000，默认是 10000000。
  * `"max_batch_size"`：可选项，Job 每轮 “每个加载线程” 最多读取的字节数，单位是字节，范围是 100MB 到 1GB，默认是 1GB。
  * `job_properties` 参数中支持 `librdkafka` 库的消费者配置属性，也对应 Kafka Consumer 的标准配置。具体如下：

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>不需要提供 "group.id"，任务执行的过程中会根据并发度分配线程消费 Kafka 不同的分区。</p>
    </main>

    * `"bootstrap.servers"`：指定 Kafka broker 地址，格式为 `ip:port`，用于连接 Kafka 集群。
    * `"security.protocol"`：指定安全协议类型。
    * `"sasl.mechanism"`：指定 SASL 认证机制。可以指定 `PLAIN`，表示用户名密码认证，然后指定以下参数：

      * `"sasl.username"`：指定 Kafka consumer 用户名。
      * `"sasl.password"`：指定 Kafka consumer 密码。

* `FORMAT [=] (format_options)`：指定 Kafka 数据格式相关的属性。`format_options` 表示 Kafka 数据格式选项，具体如下：

  * `TYPE`：指定数据格式，目前只支持 CSV 格式。
  * `LINE_DELIMITER`：指定 CSV 文件的行分隔符，默认为 `LINE_DELIMITER='\n'`。
  * `FIELD_DELIMITER`：可选项，指定 CSV 文件的列分隔符，默认为 `FIELD_DELIMITER='\t'`。
  * `PARSE_HEADER`：可选项，指定 CSV 文件的第一行是否为每列的列名。默认为 `FALSE`，表示不指定 CSV 文件的第一行为每列的列名。
  * `ESCAPE`：指定 CSV 文件的转义符号，只能为 1 个字节，默认为 `ESCAPE ='\'`。
  * `FIELD_OPTIONALLY_ENCLOSED_BY`：可选项，指定 CSV 文件中包裹字段值的符号，默认为空。使用此选项表示只对部分类型的字段（如 CHAR, VARCHAR, TEXT, JSON 等）加包裹符。
  * `ENCODING`：指定文件的字符集编码格式，如果不指定，默认值为 `UTF8MB4`。
  * `NULL_IF`：指定被当作 `NULL` 处理的字符串。默认值为空。
  * `SKIP_HEADER`：跳过文件头，并指定跳过的行数。
  * `SKIP_BLANK_LINES`：指定是否跳过空白行。默认值为 `FALSE`，表示不跳过空白的行。
  * `TRIM_SPACE`：指定是否删除文件中字段的头部和尾部空格。默认值为 `FALSE`，表示不删除文件中字段头尾的空格。
  * `EMPTY_FIELD_AS_NULL`：指定是否将空字符串当作 `NULL` 处理。默认值为 `FALSE`，表示不将空字符串当做 `NULL` 处理。

## 示例

创建从 Kafka 导入数据到 `test_db.test_tbl1` 的 Routine Load 作业 `load_job_0`。

```shell
obclient> CREATE ROUTINE LOAD load_job_0 ON test_db.test_tbl1
    PARALLEL = 3
    WHERE id > 0
    FROM STREAM (
        TYPE = 'KAFKA',
        "kafka_topic" = "test-topic",
        "kafka_partitions" = "0,1,2",
        "kafka_offsets" = "0,0,OFFSET_BEGINNING",
        "max_batch_interval" = "3000000",
        "max_batch_rows" = "200000",
        "max_batch_size" = "104857600",
        "bootstrap.servers" = "xxx.xxx.xxx.1:xxxx",
        "security.protocol" = "sasl_plaintext",
        "sasl.mechanism" = "PLAIN",
        "sasl.username" = "******",
        "sasl.password" = "******",
        FORMAT = (
            TYPE = 'CSV',
            FIELD_DELIMITER = ',',
            TRIM_SPACE = TRUE)
        );
```
