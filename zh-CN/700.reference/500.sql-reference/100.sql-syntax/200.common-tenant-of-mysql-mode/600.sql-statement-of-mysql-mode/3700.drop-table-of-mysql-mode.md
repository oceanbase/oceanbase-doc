# DROP TABLE

## 描述

该语句用于删除数据库中的表。

## 权限要求

执行 `DROP TABLE` 语句，需要当前用户拥有 `DROP` 权限。有关 OceanBase 数据库权限的详细介绍，请参见 [MySQL 模式下的权限分类](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)。

## 语法

```sql
DROP {TABLE | TABLES} [IF EXISTS] table_name_list [RESTRICT | CASCADE];

table_name_list:
    table_name [, table_name ...]
```

## 参数解释

|       **参数**      |                               **描述**                           |
|---------------------|------------------------------------------------------------------|
| table_name_list     | 指定要删除的表名列表。同时删除多个表时，表名间使用英文逗号（`,`）隔开。|
| table_name          | 表名。|
| IF EXISTS           | 可选项，如果要删除的表不存在则不报错。如果省略这个参数，如果要删除的表不存在则会报错，并且删除多个表时，存在的表也不会删除。|
| RESTRICT \| CASCADE | 可选项，指定在删除表时如何处理相关的对象。具体如下：<ul><li>`RESTRICT`：表示只有在没有任何外键引用时才能删除表。</li><li>`CASCADE`：表示将所有依赖于该表的外键、视图等一并删除。</li></ul><main id="notice" type='notice'><h4>注意</h4><p>当前版本仅支持删除选项语法，功能不生效。</p></main>|

## 示例

* 指定 `IF EXISTS`，同时删除表 `test_tbl1` 和 `test_tbl2`。

  ```sql
  DROP TABLE IF EXISTS test_tbl1, test_tbl2;
  ```

* 不指定 `IF EXISTS`，删除多张表时，只要有一张表不存在，则会报错。

  ```sql
  DROP TABLES test_tbl1, test_tbl3;
  ```

  返回结果如下：

  ```shell
  ERROR 1051 (42S02): Unknown table 'test.test_tbl1'
  ```
