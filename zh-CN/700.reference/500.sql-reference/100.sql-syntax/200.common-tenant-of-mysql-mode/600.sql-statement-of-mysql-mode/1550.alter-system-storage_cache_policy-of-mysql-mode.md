# ALTER SYSTEM STORAGE_CACHE_POLICY_EXECUTOR

## 描述

在共享存储模式下，该语句用于自定义热点缓存策略生效后，控制热点缓存任务执行的运维操作。

## 语法

```sql
ALTER SYSTEM {suspend|resume|trigger} STORAGE_CACHE_POLICY_EXECUTOR
```

## 参数解释

|          **参数**           |      **描述**      |
|---------------------------|------------------|
|suspend|用于将后台热点缓存任务挂起，通常用于热数据缓存任务影响到业务或系统稳定性的一个应急手段。|
|resume|用于重新激活处于挂起状态的后台热点缓存任务。|
|trigger|用于手动立即触发一次热数据缓存任务的执行。|

## 示例

* 执行如下命令将租户下所有热点缓存任务挂起。

    ```sql
    obclient> ALTER SYSTEM suspend STORAGE_CACHE_POLICY_EXECUTOR；
    ```

* 执行如下命令，重新激活租户下所有处于挂起状态的热点缓存任务。

    ```sql
    obclient> ALTER SYSTEM resume STORAGE_CACHE_POLICY_EXECUTOR；
    ```

* 执行如下命令将立即触发一次热点缓存任务。

    ```sql
    obclient> ALTER SYSTEM trigger STORAGE_CACHE_POLICY_EXECUTOR；
    ```
