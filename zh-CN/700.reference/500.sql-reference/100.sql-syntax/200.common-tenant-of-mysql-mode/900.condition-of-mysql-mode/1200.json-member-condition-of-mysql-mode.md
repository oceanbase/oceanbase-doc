# JSON 成员条件

JSON 成员条件（JSON Member Condition）用于检测一个值是否为 JSON 数组的成员。

## 语法

```sql
expr MEMBER [OF] ( json_expr )
```

其中 `OF` 关键字可选。

## 使用说明

* `expr` 为要检测的值。
* `json_expr` 为 JSON 数组表达式，可以是 JSON 字面量，也可以是 JSON 路径表达式（如 `column->'$.key'`）。
* 如果 `expr` 是 `json_expr` 所表示 JSON 数组的一个元素，则返回 TRUE；否则返回 FALSE。

## 示例

使用 JSON 字面量：

```sql
obclient> SELECT 1 MEMBER OF('[1, 2, 3]') AS result;
+--------+
| result |
+--------+
|      1 |
+--------+
1 row in set
```

使用 JSON 路径表达式：

```sql
obclient> CREATE TABLE t1 (profile JSON);
obclient> INSERT INTO t1 VALUES ('{"skills": ["python", "java", "go"]}');

obclient> SELECT * FROM t1
WHERE 'python' MEMBER OF (profile->'$.skills');
```
