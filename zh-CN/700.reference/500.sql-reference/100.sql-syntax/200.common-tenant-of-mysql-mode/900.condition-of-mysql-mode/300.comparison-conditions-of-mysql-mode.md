# 比较条件

比较条件（Comparison Condition）用于比较一个表达式与另一个表达式，比较的结果为 TRUE、FALSE 或 UNKNOWN。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>比较运算符的详细说明请参见 <a href="../200.operator-of-mysql-mode/500.comparison-operators-of-mysql-mode.md">比较运算符</a>。</p>
</main>

比较条件的详细信息如下表所示。

| 条件类型 | 功能 | 示例 |
|---------|------|------|
| = | 相等 | `SELECT * FROM emp WHERE salary = 2000 ORDER BY empno;` |
| != 或 <> | 不相等 | `SELECT * FROM emp WHERE salary != 2000 ORDER BY empno;` |
| > < | 大于 小于 | `SELECT * FROM emp WHERE salary > 2000 ORDER BY empno;` |
| >= <= | 大于等于 小于等于 | `SELECT * FROM emp WHERE salary >= 2000 ORDER BY empno;` |
| <=> | 安全等于（NULL 安全比较） | `SELECT * FROM emp WHERE salary <=> NULL ORDER BY empno;` |

## 简单比较条件

简单比较条件的语法如下：

```sql
expr {= | != | <> | < | > | <= | >= | <=>} expr
```

## 组比较条件

可以使用 `ANY`、`SOME` 和 `ALL` 将表达式与子查询结果进行比较。

### 与子查询比较

```sql
expr {= | != | <> | < | > | <= | >=} { ANY | SOME | ALL } ( subquery )
```

`ANY` 与 `SOME` 等价。示例如下：

```sql
obclient> SELECT * FROM emp WHERE salary = ANY (SELECT salary FROM emp WHERE deptno = 30) ORDER BY empno;
obclient> SELECT * FROM emp WHERE salary > ALL (SELECT salary FROM emp WHERE deptno = 30) ORDER BY empno;
```

### 与单元素列表比较

`= ANY (单元素列表)` 在解析时会被改写为 `array_contains` 运算，且括号内**只能包含一个表达式**：

```sql
-- 等价于 array_contains 语义
SELECT * FROM emp WHERE id = ANY ((100));
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>= ANY (多元素列表)</code> 不受支持；多值成员判断请使用 <code>IN</code> 条件。</p>
</main>
