# ARBITRARY

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
ARBITRARY(expr)
```

## 说明

该函数用于从一组行中非确定性地返回任意非 `NULL` 值。

## 示例

1. 创建测试表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(50), col3 INT);
    ```

2. 向表 `test_tbl1` 中插入数据。

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1, 'A001', 100),
        (2, 'A001', NULL),
        (3, 'A001', 110),
        (4, 'B002', 100),
        (5, 'B002', 130),
        (6, 'C001', 160);
    ```

3. 按 `col2` 列进行分组，并在每一组中随机返回 `col3` 列中的一个非空值。

    ```shell
    obclient> SELECT col2, ARBITRARY(col3)
        FROM test_tbl1
        GROUP BY col2;
    ```

    返回结果如下：

    ```shell
    +------+-----------------+
    | col2 | ARBITRARY(col3) |
    +------+-----------------+
    | A001 |             100 |
    | B002 |             100 |
    | C001 |             160 |
    +------+-----------------+
    3 rows in set
    ```
