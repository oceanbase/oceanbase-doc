# STRING_AGG

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.1 版本开始引入。</p>
</main>

## 声明

```sql
STRING_AGG([DISTINCT] expr, separator
           [ORDER BY {unsigned_integer | col_name | expr}
               [ASC | DESC] [,col_name ...]])
```

## 说明

`STRING_AGG` 是一个字符串聚合函数，用于将分组内的字符串值按指定分隔符连接为一个字符串，功能与 `GROUP_CONCAT` 类似。

### 参数说明

| 参数 | 说明 |
|------|------|
| expr | 待连接的字符串表达式。 |
| separator | 连接各字符串时使用的分隔符。 |
| DISTINCT | 可选，对 `expr` 去重后再连接。 |
| ORDER BY | 可选，指定连接前各值的排序方式。 |

### 返回说明

* 返回连接后的字符串。
* `expr` 为 `NULL` 的行将被跳过。
* 分组内所有 `expr` 均为 `NULL` 时，返回 `NULL`。

## 示例

```shell
obclient> CREATE TABLE t_string_agg (id INT, val VARCHAR(50));
Query OK, 0 rows affected

obclient> INSERT INTO t_string_agg VALUES (1, 'apple'), (1, 'banana'), (1, 'cherry'), (2, 'dog'), (2, 'cat');
Query OK, 5 rows affected

obclient> SELECT id, STRING_AGG(val, ',') AS agg_val FROM t_string_agg GROUP BY id;
```

返回结果如下：

```shell
+----+---------------+
| id | agg_val       |
+----+---------------+
|  1 | apple,banana,cherry |
|  2 | dog,cat       |
+----+---------------+
2 rows in set
```
