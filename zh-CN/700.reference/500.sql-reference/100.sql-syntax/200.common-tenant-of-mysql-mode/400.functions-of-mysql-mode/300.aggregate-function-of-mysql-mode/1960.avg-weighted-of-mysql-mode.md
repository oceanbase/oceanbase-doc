# AVG_WEIGHTED

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.1 版本开始引入。</p>
</main>

## 声明

```sql
AVGWEIGHTED([DISTINCT | ALL] value, weight)
```

## 说明

`AVGWEIGHTED`（亦写作 `avgWeighted`）是一个加权平均聚合函数，按以下公式计算结果：

```text
Σ(value × weight) / Σ(weight)
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

### 参数说明

| 参数 | 说明 |
|------|------|
| value | 参与计算的数值。 |
| weight | 对应 `value` 的权重。 |
| DISTINCT | 可选，对 `value` 去重后再计算。 |
| ALL | 可选，默认值，对所有行计算。 |

### 返回说明

* 返回加权平均值，类型与 `value` 一致。
* `value` 或 `weight` 为 `NULL` 的行将被跳过。
* 有效行的权重之和为 0 时，返回 `NULL`。
* 输入为空或所有行均为 `NULL` 时，返回 `NULL`。

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 计算加权平均值。

    ```shell
    obclient> SELECT AVGWEIGHTED(v, w) FROM (SELECT 10 AS v, 2 AS w UNION ALL SELECT 20, 3) t;
    ```

    返回结果如下：

    ```shell
    +-------------------+
    | AVGWEIGHTED(v, w) |
    +-------------------+
    |                16 |
    +-------------------+
    1 row in set
    ```

    计算过程为 `(10 × 2 + 20 × 3) / (2 + 3) = 16`。
