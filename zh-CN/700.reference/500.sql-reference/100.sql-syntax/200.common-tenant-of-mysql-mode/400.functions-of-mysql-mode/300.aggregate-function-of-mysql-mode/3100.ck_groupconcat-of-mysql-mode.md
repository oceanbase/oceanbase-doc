# GROUPCONCAT

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
GROUPCONCAT([DISTINCT] expr)
```

## 说明

该函数用于将组内多行 `expr` 的值连接成一个字符串。可以使用 `DISTINCT` 去重。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 创建测试表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 INT, col3 VARCHAR(50));
    ```

3. 向表 `test_tbl1` 中插入数据。

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1, 1, 'X'),
        (2, 1, 'Y'),
        (3, 1, 'X'),
        (4, 2, 'M'),
        (5, 2, 'N');
    ```

4. 对 `col2` 分组，使用 `GROUPCONCAT` 将所有不同的 `col3` 值拼接成一个字符串。

    ```shell
    obclient> SELECT col2, GROUPCONCAT(DISTINCT col3)
        FROM test_tbl1
        GROUP BY col2;
    ```

    返回结果如下：

    ```shell
    +------+----------------------------+
    | col2 | GROUPCONCAT(DISTINCT col3) |
    +------+----------------------------+
    |    2 | MN                         |
    |    1 | XY                         |
    +------+----------------------------+
    2 rows in set
    ```
