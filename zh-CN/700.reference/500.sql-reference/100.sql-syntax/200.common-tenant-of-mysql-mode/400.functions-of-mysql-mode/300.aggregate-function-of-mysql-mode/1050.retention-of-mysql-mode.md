# RETENTION

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该函数从 V4.4.2 BP3 版本开始引入。</p>
</main>

## 声明

```sql
RETENTION(event_1 [, event_2, ..., event_n])
```

## 说明

聚合函数 `RETENTION` 用于计算事件留存率，适用于用户行为分析、产品转化路径追踪等场景。兼容 Doris/ClickHouse 的语义。

### 参数说明

`event_1 [, event_2, ..., event_n]`：表示 1～32 个布尔类型表达式。

### 返回说明

返回一个 `ARRAY<TINYINT>`（值为 0 或 1） 类型的结果，每一位表示是否在分组内满足对应事件条件。

## 示例

1. 创建表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (
        col1 INT NOT NULL COMMENT '用户 ID',
        col2 DATETIME COMMENT '事件发生时间',
        col3 VARCHAR(32) COMMENT '事件类型，例如 login/view/pay'
    );
    ```

2. 向表 `test_tbl1` 插入测试数据。

    * 用户 1：`login`、`view`、`pay` 都发生过。
    * 用户 2：只发生过 `login`。
    * 用户 3：发生过 `view` 和 `pay`，但没有 `login`。
    * 用户 4：发生过 `login` 和 `pay`，但没有 `view`。

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1, '2025-01-01 10:00:00', 'login'),
        (1, '2025-01-01 10:01:00', 'view'),
        (1, '2025-01-01 10:02:00', 'pay'),
        (2, '2025-01-01 11:00:00', 'login'),
        (3, '2025-01-01 12:00:00', 'view'),
        (3, '2025-01-01 12:01:00', 'pay'),
        (4, '2025-01-01 13:00:00', 'login'),
        (4, '2025-01-01 13:02:00', 'pay');
    ```

3. 基础查询：按用户计算事件留存。

    事件的留存情况：

    * 第 1 个条件：`col3 = 'login'`。
    * 第 2 个条件：`col3 = 'view'`。
    * 第 3 个条件：`col3 = 'pay'`。

    ```shell
    obclient> SELECT
            col1,
            RETENTION(
                col3 = 'login',
                col3 = 'view',
                col3 = 'pay'
                ) AS retention_result
        FROM test_tbl1
        GROUP BY col1
        ORDER BY col1;
    ```

    返回结果如下：

    ```shell
    +------+------------------+
    | col1 | retention_result |
    +------+------------------+
    |    1 | [1,1,1]          |
    |    2 | [1,0,0]          |
    |    3 | [0,0,0]          |
    |    4 | [1,0,1]          |
    +------+------------------+
    4 rows in set
    ```

4. 带时间条件的查询示例。

    `RETENTION` 的参数是布尔表达式，因此也可以加入时间、属性等过滤条件。

    ```shell
    obclient> SELECT
            col1,
            RETENTION(
                col3 = 'login'
                    AND col2 >= '2025-01-01 00:00:00',
                col3 = 'view'
                    AND col2 >= '2025-01-01 00:00:00',
                col3 = 'pay'
                    AND col2 >= '2025-01-01 00:00:00'
                ) AS retention_result
        FROM test_tbl1
        GROUP BY col1
        ORDER BY col1;
    ```

    返回结果如下：

    ```shell
    +------+------------------+
    | col1 | retention_result |
    +------+------------------+
    |    1 | [1,1,1]          |
    |    2 | [1,0,0]          |
    |    3 | [0,0,0]          |
    |    4 | [1,0,1]          |
    +------+------------------+
    4 rows in set
    ```
