# ANY

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
ANY(expr)
```

## 说明

该函数用于从一组值中选择任意一个值，通常用于 `GROUP BY` 查询中。其中 `expr` 是希望从中选择任意值的列名。默认情况下，该函数会忽略 `NULL` 值。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 创建测试表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (
        col1 INT AUTO_INCREMENT PRIMARY KEY,
        col2 INT NOT NULL,
        col3 DATETIME NOT NULL);
    ```

3. 向表 `test_tbl1` 中插入数据。

    ```shell
    obclient> INSERT INTO test_tbl1(col2, col3) VALUES
        (1, '2026-03-01 10:00:00'),
        (1, '2026-03-01 11:00:00'),
        (2, '2026-03-01 12:00:00'),
        (1, '2026-03-02 10:00:00');
    ```

4. 使用 `ANY` 函数获取每个 `col2` 的任意访问日期（`col3`）。

    ```shell
    obclient> SELECT col2, ANY(col3)
        FROM test_tbl1
        GROUP BY col2;
    ```

    返回结果如下：

    ```shell
    +------+---------------------+
    | col2 | ANY(col3)           |
    +------+---------------------+
    |    1 | 2026-03-01 10:00:00 |
    |    2 | 2026-03-01 12:00:00 |
    +------+---------------------+
    2 rows in set
    ```
