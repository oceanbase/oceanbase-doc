# ARG_MIN

## 声明

```sql
ARG_MAX([DISTINCT] minimize_col, return_col)
```

## 说明

`ARG_MAX` 函数用于在数据集中查找使目标表达式最大化的行，并返回该行对应的指定列值或完整记录。

其中：

* `minimize_col` 指待最小化的列。
* `return_col` 指返回值对应的列，返回最小值行的该列值，如果是 `NULL` 则忽略该行。

## 示例

```shell
obclient> SELECT * FROM test;
+------+------+
| a    | b    |
+------+------+
| a    |    1 |
| b    |    2 |
| c    |    2 |
| NULL |    3 |
| NULL | NULL |
| d    | NULL |
+------+------+
6 rows in set (0.000 sec)
```

```sql
obclient> SELECT arg_min(a, b), min(b) FROM test;
+---------------+--------+
| arg_min(a, b) | min(b) |
+---------------+--------+
| a             |      1 |
+---------------+--------+
1 row in set (0.006 sec)
```
