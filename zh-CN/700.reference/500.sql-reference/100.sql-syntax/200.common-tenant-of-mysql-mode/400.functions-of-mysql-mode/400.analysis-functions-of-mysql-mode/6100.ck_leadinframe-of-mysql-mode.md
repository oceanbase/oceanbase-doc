# LEADINFRAME

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
LEADINFRAME(expr [, offset [, default]]) OVER (window_spec)
```

## 说明

该函数用于在当前窗口框架内，返回位于当前行之后 `offset`（默认为 1）行的 `expr` 值。如果该行不存在于窗口框架内，则返回 `default`（默认为 `NULL`）。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 创建测试表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(50), col3 INT, col4 DATE);
    ```

3. 向表 `test_tbl1` 中插入数据。

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1, 'a1', 100, '2026-03-01'),
        (2, 'a1', 120, '2026-03-02'),
        (3, 'a1', 110, '2026-03-01'),
        (4, 'a2', 150, '2026-03-02'),
        (5, 'a2', 130, '2026-03-03'),
        (6, 'a3', 160, '2026-03-04');
    ```

4. 使用 `LEADINFRAME` 将数据按 `col2` 分组，在每个分组内部按照 `col4` 排序后，取下一行的 `col3` 值，最终结果按 `col2` 和 `col4` 升序输出。

    ```shell
    obclient> SELECT col2, col3, col4, LEADINFRAME(col3) OVER (PARTITION BY col2 ORDER BY col4) AS laginframe_col3
        FROM test_tbl1
        ORDER BY col2, col4;
    ```

    返回结果如下：

    ```shell
    +------+------+------------+-----------------+
    | col2 | col3 | col4       | laginframe_col3 |
    +------+------+------------+-----------------+
    | a1   |  100 | 2026-03-01 |             110 |
    | a1   |  110 | 2026-03-01 |            NULL |
    | a1   |  120 | 2026-03-02 |            NULL |
    | a2   |  150 | 2026-03-02 |            NULL |
    | a2   |  130 | 2026-03-03 |            NULL |
    | a3   |  160 | 2026-03-04 |            NULL |
    +------+------+------------+-----------------+
    6 rows in set
    ```
