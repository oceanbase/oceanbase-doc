# SM3

## 声明

```sql
SM3(str)
```

## 说明

SM3 函数使用 SM3 算法计算给定字符串的散列值。`str` 是明文字符串。

## 示例

```shell
obclient> SELECT SM3('ABCDEFGHI');
+------------------------------------------------------------------+
| SM3('ABCDEFGHI')                                                 |
+------------------------------------------------------------------+
| a7a9bbc802329f3a1379ffcc88a32131500b693b41282093554d61e75022e6e0 |
+------------------------------------------------------------------+
1 row in set (0.001 sec)
```
