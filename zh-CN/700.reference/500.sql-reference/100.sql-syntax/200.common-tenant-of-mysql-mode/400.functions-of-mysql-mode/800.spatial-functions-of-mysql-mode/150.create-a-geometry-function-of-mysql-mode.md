# 创建几何值函数

创建几何值函数用于以各种格式（如 Well-Known Text (WKT) 或 Well-Known Binary (WKB)）创建几何图形。OceanBase 数据库当前版本支持二维和三维数据的创建几何值函数包括 `ST_GeomFromText()` 和 `ST_GeometryFromText()`、`ST_GeomFromWKB()` 和  `ST_GeometryFromWKB()`、`_ST_GeomFromEWKT()`、`_ST_GeogFromText()`、`_ST_GeographyFromText()`、`_ST_GeomFromEWKB()`。

- `ST_GeomFromText()`：从 WKT 格式的字符串中创建几何图形。
- `ST_GeometryFromText()`：功能上与 `ST_GeomFromText()` 相似，也是从 WKT 格式的字符串创建几何图形。不同的数据库系统可能会提供不同命名的函数，但功能类似。
- `ST_GeomFromWKB()`：从 WKB 格式的二进制数据中创建几何图形。
- `ST_GeometryFromWKB()`：功能上与 `ST_GeomFromWKB()` 相似，也是从 WKB 格式的二进制数据创建几何图形。
- `_ST_GeomFromEWKT()`：从 EWKT 格式的二进制数据中创建几何图形。
- `_ST_GeogFromText()`：从 WKT 格式的字符串中创建几何图形，默认 geography 坐标系。
- `_ST_GeographyFromText()`：和 `_ST_GeogFromText` 函数功能相同，相当于其别名。
- `_ST_GeomFromEWKB()`：从 EWKB 格式的二进制数据中创建几何图形。

## ST_GeomFromText 和 ST_GeometryFromText

`ST_GeomFromText()` 和 `ST_GeometryFromText()` 函数将 Well-Known Text（WKT） 表示形式和可选的空间参考系统标识符 (SRID) 作为参数，返回相应的几何图形。有关 WKT 格式的说明，请参见 [空间数据格式](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/900.spatial-data-type-of-mysql-mode/500.spatial-data-format-of-mysql-mode.md)。

`ST_GeomFromText()` 接受任何几何类型的 WKT 值作为其第一个参数。其他函数提供特定类型的构造函数，用于构造每种几何类型的几何值。
函数的语法如下：

```sql
ST_GeomFromText(wkt [, srid [, options]]), ST_GeometryFromText(wkt [, srid [, options]])
```

示例如下：

```shell
obclient [test]> SET @geo = "MULTILINESTRING((10 10, 11 11), (9 9, 10 10))";
Query OK, 0 rows affected

obclient [test]> SELECT ST_AsText(ST_GeomFromText(@geo));
+--------------------------------------------+
| ST_AsText(ST_GeomFromText(@geo))           |
+--------------------------------------------+
| MULTILINESTRING((10 10,11 11),(9 9,10 10)) |
+--------------------------------------------+
1 row in set
```

## ST_GeomFromWKB 和 ST_GeometryFromWKB

`ST_GeomFromWKB()` 和  `ST_GeometryFromWKB()` 函数将包含 Well-Known Binary (WKB) 表示和可选的空间参考系统标识符 (SRID) 的 `BLOB` 作为参数，返回相应的几何图形。有关 WKB 格式的说明，请参见 [空间数据格式](../../100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/900.spatial-data-type-of-mysql-mode/500.spatial-data-format-of-mysql-mode.md)。

函数的语法如下：

```sql
ST_GeomFromWKB(wkb [, srid [, options]]), ST_GeometryFromWKB(wkb [, srid [, options]])
```

## _ST_GeomFromEWKT

`_ST_GeomFromEWKT` 函数根据输入的 Extended Well-Known text (EWKT) 来构建一个空间几何图形。EWKT 和 WKT 的区别在于，可以在前面增加 SRID，例如：EWKT：`'SRID=4326;LINESTRING(0 0,10 10)'；`，WKT：`'LINESTRING(0 0,10 10)'；`。

函数的语法如下：

```sql
_ST_GeomFromEWKT([srid,] ewkt [, options])
```

示例如下：

```shell
obclient [test]>  SELECT _st_asewkt(_ST_GeomFromEWKT('SRID=4326;POINT(0 0)'));
```

返回结果如下：

```shell
SRID=4326;POINT(0 0)
```

## _ST_GeogFromText 和 _ST_GeographyFromText

`_ST_GeogFromText` 函数根据输入的 OGC Extended Well-Known text (EWKT) 来构建一个地理空间几何图形。

函数的语法如下：

```sql
_ST_GeogFromText([srid,] ewkt [, options])
```

示例如下：

```shell
OceanBase> SELECT _st_asewkt(_ST_GeogFromtext('SRID=4326;POINT(0 0)'));
+------------------------------------------------------+
| _st_asewkt(_ST_GeogFromtext('SRID=4326;POINT(0 0)')) |
+------------------------------------------------------+
| SRID=4326;POINT(0 0)                                 |
+------------------------------------------------------+
1 row in set
```

EWKT 输入的 SRID 只能是地理坐标系。否则返回如下报错：

```shell
// 3825 是平面坐标系，不是地理坐标系
OceanBase> SELECT _st_asewkt(_ST_GeogFromtext('SRID=3825;POINT(0 0)'));
ERROR 3726 (22S00): Function is only defined for geographic spatial reference systems, but one of its arguments is in SRID, which is not geographic.
```

`_ST_GeographyFromText` 函数和 `_ST_GeogFromText` 函数功能相同，相当于其别名。

## _ST_GeomFromEWKB

`_ST_GeomFromEWKB` 函数根据输入的 Extended Well-Known binary (EWKB) 来构建一个空间几何图形。支持指定坐标经纬度顺序。

函数的语法如下：

```sql
_ST_GeomFromEWKB(ewkb, ['axis-order'])
```

支持 ['axis-order'] 可选参数指定坐标经纬度顺序。

示例如下：

```shell
OceanBase> SELECT _st_asewkt(_ST_GeomFromEWKB(x'0101000020E6100000000000000000F03F0000000000000000'));
+-------------------------------------------------------------------------------------+
| _st_asewkt(_ST_GeomFromEWKB(x'0101000020E6100000000000000000F03F0000000000000000')) |
+-------------------------------------------------------------------------------------+
| SRID=4326;POINT(1 0)                                                                |
+-------------------------------------------------------------------------------------+
1 row in set
```

```shell
OceanBase> SELECT _st_asewkt(_ST_GeomFromEWKB(x'0101000020E6100000000000000000F03F0000000000000000','axis-order=long-lat'));
+-----------------------------------------------------------------------------------------------------------+
| _st_asewkt(_ST_GeomFromEWKB(x'0101000020E6100000000000000000F03F0000000000000000','axis-order=long-lat')) |
+-----------------------------------------------------------------------------------------------------------+
| SRID=4326;POINT(1 0)                                                                                      |
+-----------------------------------------------------------------------------------------------------------+
1 row in set
```

```shell
SELECT _st_asewkt(_ST_GeomFromEWKB(x'0101000020E6100000000000000000F03F0000000000000000','axis-order=lat-long'));
+-----------------------------------------------------------------------------------------------------------+
| _st_asewkt(_ST_GeomFromEWKB(x'0101000020E6100000000000000000F03F0000000000000000','axis-order=lat-long')) |
+-----------------------------------------------------------------------------------------------------------+
| SRID=4326;POINT(0 1)                                                                                      |
+-----------------------------------------------------------------------------------------------------------+
1 row in set
```

## 参数的注意事项

创建几何值函数中几何参数何参数的返回值为非 `NULL`，以下情况除外：

- 如果任何几何参数为 `NULL` 或不是语法格式不正确，则返回值为 `NULL`。

- 可选的 `options` 参数可以使地理坐标的纬度和经度按照几何参数的空间参考系统指定的顺序进行解析。`options` 由逗号分隔的 `key=value` 列表组成。`key` 值只能是 `axis-order`，允许的值为 `lat-long`、`long-lat` 和 `srid-defined`（默认值）。如果 `options` 参数为 `NULL`，则返回值为 `NULL`。如果选项参数无效，则会发生报错。

- 如果 `SRID` 参数引用未定义的空间参考系统 (SRS)，则会发生 `ER_SRS_NOT_FOUND` 错误。

- 对于地理 SRS 几何参数，如果任何参数的经度或纬度超出范围（范围以度为单位，如果 SRS 使用其他单位，则范围使用其单位中的相应值），则会发生报错：

   - 如果经度值不在范围 (-180, 180] 内，则会发生 `ER_LONGITUDE_OUT_OF_RANGE` 错误。

   - 如果纬度值不在 [−90, 90] 范围内，则会发生 `ER_LATITUDE_OUT_OF_RANGE` 错误。
