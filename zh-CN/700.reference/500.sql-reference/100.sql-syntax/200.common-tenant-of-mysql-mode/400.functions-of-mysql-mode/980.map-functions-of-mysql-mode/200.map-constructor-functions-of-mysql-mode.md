# 映射构造函数

映射构造函数/运算符用于构建新的映射数据类型。OceanBase 数据库当前所支持的映射构造函数包括 `map()`，支持的运算符包括 `{}`。

## map

`map()` 函数用于构建一个映射数据。语法如下：

```sql
map(key1, value1, key2, value2, ..., keyN, valueN)
```

输入参数说明如下：

* 输入的参数个数需为偶数，序数为奇数的参数构成 Key 数组 ，序数为偶数的参数构成 Value 数组。
* key1~keyN：目前支持数据元素类型为：TINYINT、SMALLINT、INT、BIGINT、FLOAT、DOUBLE、VARCHAR。
* value1~valueN：目前支持数据元素类型为：TINYINT、SMALLINT、INT、BIGINT、FLOAT、DOUBLE、VARCHAR、ARRAY。

返回值为映射数据类型（MAP）。

示例如下：

```sql
-- 构建出的映射数据只有一个键值对，key 为 1，value 为 2
SELECT map(1,2);
+----------+
| map(1,2) |
+----------+
| {1:2}    |
+----------+
1 row in set
```

```sql
-- 构建出的映射数据有 3 个键值对
SELECT map(1,"a",2,"b",3,"c");
+------------------------+
| map(1,"a",2,"b",3,"c") |
+------------------------+
| {1:"a",2:"b",3:"c"}    |
+------------------------+
1 row in set
```

```sql
-- Key 数组的数据类型由奇数序数的参数决定，Value 数组的数据类型由偶数序数的参数决定
SELECT map(1,"a","b",1.8,"ccc",3);
+-------------------------------+
| map(1,"a","b",1.8,"ccc",3)    |
+-------------------------------+
| {"1":"a","b":"1.8","ccc":"3"} |
+-------------------------------+
```

## {}

运算符 `{}` 也可以实现映射数据的构造。语法如下：

```sql
{key1:value1,key2:value2,...}
```

输入的每个键值对使用 `,` 分隔，Key 和 Value 之间使用 `:` 分隔。
