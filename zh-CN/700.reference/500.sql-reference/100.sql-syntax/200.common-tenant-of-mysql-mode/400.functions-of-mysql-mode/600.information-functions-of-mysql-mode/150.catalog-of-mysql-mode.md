# CATALOG

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V5.0.1 版本开始引入。</p>
</main>

## 声明

```sql
CATALOG()
```

## 说明

该函数用于查看当前 Catalog 环境，其功能与函数 `CURRENT_CATALOG()` 完全等价。

## 示例

```shell
obclient> SELECT CATALOG();
```

返回结果如下：

```shell
+-----------+
| CATALOG() |
+-----------+
| internal  |
+-----------+
1 row in set
```
