# TABLE FUNCTION 概述

## 描述

Table Function（表函数）用于把半结构化数据展开为关系行集，可在 `SELECT ... FROM` 中像表一样被引用。

MySQL 模式下常见的表函数入口包括：

- `JSON_TABLE(...)`：将 JSON 文档展开为行列。
- `FILES(...)`：从外部文件位置读取数据并作为行集参与查询。

## 语法特点

### 使用位置

表函数作为表因子使用，通常出现在 `FROM` 子句中。

### 别名要求

`JSON_TABLE` 需要指定表别名。

### JSON_TABLE 基本语法

```sql
JSON_TABLE(expr, path_literal COLUMNS (column_list)) [AS] alias
```

### FILES 基本语法

```sql
FILES(location_expr, format_expr [, pattern_expr])
```

### 列定义能力

`column_list` 支持以下类型：

- `column_name FOR ORDINALITY`
- `column_name data_type PATH path_literal [ON EMPTY] [ON ERROR]`
- `column_name data_type EXISTS PATH path_literal`
- `NESTED [PATH] path_literal COLUMNS (column_list)`

## 返回表结构的函数

| 名称 | 用途 |
|------|------|
| JSON_TABLE | 将 JSON 文档映射为关系行列 |
| FILES | 从外部文件生成可查询行集 |
