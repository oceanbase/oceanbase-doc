# TO_DATE

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
TO_DATE(string [, format])
```

## 说明

该函数用于将字符串 `string` 按照指定的 `format` 格式转换为 `DATE` 类型。如果省略 `format`，则使用会话的默认日期格式。

## 示例

```shell
obclient> SELECT TO_DATE('20260330', 'YYYY/MM/DD');
```

返回结果如下：

```shell
+-----------------------------------+
| TO_DATE('20260330', 'YYYY/MM/DD') |
+-----------------------------------+
| 2026-03-30 00:00:00               |
+-----------------------------------+
1 row in set
```
