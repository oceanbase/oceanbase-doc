# TO_CHAR(number)

## 描述

该函数用于将数值型数据转换为 `VARCHAR` 类型的数据。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.3.5 版本，该函数从 V4.3.5 BP1 版本开始支持。</p>
</main>

## 语法声明

```sql
TO_CHAR(number [, fmt])
```

## 参数解释

* `number`：表示要转换的数值型数据。
* `fmt`：可选项，用于指定数值输出格式的参数。如果省略 `fmt`，则 `number` 被转换为 `VARCHAR` 值。具体介绍参见下文 [fmt](#fmt)。

### fmt

`fmt` 参数取值如下：

* `9`：是一个占位符，表示一个数字位置，确保结果具有指定的位数。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(123, '999999'), TO_CHAR(123, '999');
    ```

    返回结果如下：

    ```shell
    +------------------------+---------------------+
    | TO_CHAR(123, '999999') | TO_CHAR(123, '999') |
    +------------------------+---------------------+
    |     123                |  123                |
    +------------------------+---------------------+
    1 row in set
    ```

* `0`：是一个占位符，表示一个数字位置。如果数值不足，前面会补零以达到指定的位数。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(123, '00000'), TO_CHAR(123, '000');
    ```

    返回结果如下：

    ```shell
    +-----------------------+---------------------+
    | TO_CHAR(123, '00000') | TO_CHAR(123, '000') |
    +-----------------------+---------------------+
    |  00123                |  123                |
    +-----------------------+---------------------+
    1 row in set
    ```

* `.`：表示小数点，位于指定位置。若小数部分不足，则补零；若小数部分多余 `fmt` 中指定的位数，则进行四舍五入。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>只能指定一个小数点。</p>
    </main>

    **示例如下：**

    ```sql
    SELECT TO_CHAR(123.555, '999.99'), TO_CHAR(123.5, '999.99');
    ```

    返回结果如下：

    ```shell
    +----------------------------+--------------------------+
    | TO_CHAR(123.555, '999.99') | TO_CHAR(123.5, '999.99') |
    +----------------------------+--------------------------+
    |  123.56                    |  123.50                  |
    +----------------------------+--------------------------+
    1 row in set
    ```

* `,`（英文逗号）：用于分隔数值的整数部分。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>格式模型数值不能以逗号开头，且逗号不能出现在小数字符或句点的右边。</p>
    </main>

    **示例如下：**

    ```sql
    SELECT TO_CHAR(123456, '99,99,99'), TO_CHAR(123456789, '999,999,999');
    ```

    返回结果如下：

    ```shell
    +-----------------------------+-----------------------------------+
    | TO_CHAR(123456, '99,99,99') | TO_CHAR(123456789, '999,999,999') |
    +-----------------------------+-----------------------------------+
    |  12,34,56                   |  123,456,789                      |
    +-----------------------------+-----------------------------------+
    1 row in set
    ```

* `V`：与 `.` 类似，表示小数点，用于分隔数值的整数部分和小数部分。与 `.` 不同的是，使用 `V` 的格式化结果会拼接整数和小数部分，而不显示小数点。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(123.456, '999V99'), TO_CHAR(123.4, '999V999');
    ```

    返回结果如下：

    ```shell
    +----------------------------+---------------------------+
    | TO_CHAR(123.456, '999V99') | TO_CHAR(123.4, '999V999') |
    +----------------------------+---------------------------+
    |  12346                     |  123400                   |
    +----------------------------+---------------------------+
    1 row in set
    ```

## 返回类型

* 返回 `VARCHAR` 类型的数据。
* `number` 值为 `NULL` 时，返回 `NULL`。

## 示例

```sql
SELECT
    TO_CHAR(11111.111, '999,999.9999'),
    TO_CHAR(11111.111, '000,000.0000'),
    TO_CHAR(55555.555, '99,999.99'),
    TO_CHAR(55555.555, '99,999V99'),
    TO_CHAR(NULL, '999.999');
```

返回结果如下：

```shell
+------------------------------------+------------------------------------+---------------------------------+---------------------------------+--------------------------+
| TO_CHAR(11111.111, '999,999.9999') | TO_CHAR(11111.111, '000,000.0000') | TO_CHAR(55555.555, '99,999.99') | TO_CHAR(55555.555, '99,999V99') | TO_CHAR(NULL, '999.999') |
+------------------------------------+------------------------------------+---------------------------------+---------------------------------+--------------------------+
|   11,111.1110                      |  011,111.1110                      |  55,555.56                      |  55,55556                       |                     NULL |
+------------------------------------+------------------------------------+---------------------------------+---------------------------------+--------------------------+
1 row in set
```
