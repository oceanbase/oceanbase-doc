# TO_PINYIN

## 声明

```sql
TO_PINYIN('chinese_string')
```

## 说明

该函数用于将中文文本转换为拼音。

它接受一个中文字符串作为输入，并返回一个包含相应拼音的字符串。

## 示例

```sql
SELECT TO_PINYIN('数据库');
```

返回结果如下：

```shell
+------------------------+
| TO_PINYIN('数据库')    |
+------------------------+
| shùjùkù                |
+------------------------+
1 row in set
```
