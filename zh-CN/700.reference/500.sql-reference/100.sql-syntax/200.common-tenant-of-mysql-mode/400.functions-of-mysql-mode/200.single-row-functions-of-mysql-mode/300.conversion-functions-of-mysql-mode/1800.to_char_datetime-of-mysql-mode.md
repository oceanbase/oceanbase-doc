# TO_CHAR(datetime)

## 描述

该函数用于将日期时间类型的值转换为 `VARCHAR` 类型的数据。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.3.5 版本，该函数从 V4.3.5 BP1 版本开始支持。</p>
</main>

## 语法声明

```sql
TO_CHAR(datetime [, fmt])
```

## 参数解释

* `datetime`：表示要转换的日期时间型数据。
* `fmt`：可选项，用于指定输出的格式。如果不指定参数 `fmt`，则将按参数 `datetime` 的格式转换为 `VARCHAR` 数据类型。具体介绍参见下文 [fmt](#fmt)。

### fmt

`fmt` 参数取值如下：

* `YYYY`：显示四位数的年份。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'YYYY');
    ```

    返回结果如下：

    ```shell
    +---------------------+----------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'YYYY') |
    +---------------------+----------------------------+
    | 2025-02-28 10:25:50 | 2025                       |
    +---------------------+----------------------------+
    1 row in set
    ```

* `MM`：显示两位数的月份。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'MM');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'MM') |
    +---------------------+--------------------------+
    | 2025-02-28 10:27:00 | 02                       |
    +---------------------+--------------------------+
    1 row in set
    ```

* `DD`：显示两位数的日期。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'DD');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'DD') |
    +---------------------+--------------------------+
    | 2025-02-28 10:27:42 | 28                       |
    +---------------------+--------------------------+
    1 row in set
    ```

* `HH24`：显示 24 小时制的小时。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'HH24');
    ```

    返回结果如下：

    ```shell
    +---------------------+----------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'HH24') |
    +---------------------+----------------------------+
    | 2025-02-28 10:28:16 | 10                         |
    +---------------------+----------------------------+
    1 row in set
    ```

* `HH`：显示 12 小时制的小时。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'HH');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'HH') |
    +---------------------+--------------------------+
    | 2025-02-28 10:29:17 | 10                       |
    +---------------------+--------------------------+
    1 row in set
    ```

* `MI`：显示分钟。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'MI');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'MI') |
    +---------------------+--------------------------+
    | 2025-02-28 10:30:06 | 30                       |
    +---------------------+--------------------------+
    1 row in set
    ```

* `SS`：显示秒。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'SS');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'SS') |
    +---------------------+--------------------------+
    | 2025-02-28 10:30:38 | 38                       |
    +---------------------+--------------------------+
    1 row in set
    ```

* `AM`/`PM`：显示上午或下午标识。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'AM'), TO_CHAR(SYSDATE(), 'PM');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'AM') | TO_CHAR(SYSDATE(), 'PM') |
    +---------------------+--------------------------+--------------------------+
    | 2025-02-28 10:32:13 | AM                       | AM                       |
    +---------------------+--------------------------+--------------------------+
    1 row in set
    ```

* `Month`：显示月份的全名。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'Month');
    ```

    返回结果如下：

    ```shell
    +---------------------+-----------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'Month') |
    +---------------------+-----------------------------+
    | 2025-02-28 10:34:35 | February                    |
    +---------------------+-----------------------------+
    1 row in set
    ```

* `DS`：将日期格式化为 **月份/日期/年份** 的形式，即 `MM/DD/YYYY`。

    **示例如下：**

    ```sql
    SELECT TO_CHAR(SYSDATE()), TO_CHAR(SYSDATE(), 'DS');
    ```

    返回结果如下：

    ```shell
    +---------------------+--------------------------+
    | TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'DS') |
    +---------------------+--------------------------+
    | 2025-02-28 10:53:46 | 2/28/2025                |
    +---------------------+--------------------------+
    1 row in set
    ```

## 返回类型

* 返回 `VARCHAR` 类型的数据。
* `datetime` 值为 `NULL` 时，返回 `NULL`。

## 示例

```sql
SELECT
    TO_CHAR(SYSDATE()),
    TO_CHAR(SYSDATE(), 'YYYY/MM/DD HH24:MI:SS'),
    TO_CHAR(SYSDATE(), 'DD Month YYYY'),
    TO_CHAR(SYSDATE(), 'DS HH:MI:SS AM'),
    TO_CHAR(NULL, 'HH:MI:SS');
```

返回结果如下：

```shell
+---------------------+---------------------------------------------+-------------------------------------+--------------------------------------+---------------------------+
| TO_CHAR(SYSDATE())  | TO_CHAR(SYSDATE(), 'YYYY/MM/DD HH24:MI:SS') | TO_CHAR(SYSDATE(), 'DD Month YYYY') | TO_CHAR(SYSDATE(), 'DS HH:MI:SS AM') | TO_CHAR(NULL, 'HH:MI:SS') |
+---------------------+---------------------------------------------+-------------------------------------+--------------------------------------+---------------------------+
| 2025-02-28 11:10:16 | 2025/02/28 11:10:16                         | 28 February  2025                   | 2/28/2025 11:10:16 AM                |                      NULL |
+---------------------+---------------------------------------------+-------------------------------------+--------------------------------------+---------------------------+
1 row in set
```
