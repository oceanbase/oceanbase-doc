# ADDDATE

## 声明

### 声明一

```sql
ADDDATE(date, INTERVAL expr unit)
```

### 声明二

```sql
ADDDATE(expr, days)
```

## 说明

* 该函数的第一种声明是 `DATE_ADD()` 的同义词，向日期值 `date` 添加指定的时间间隔。有关 `unit` 参数的详细信息，请参见 [DATE_ADD](../100.date-and-time-functions-of-mysql-mode/900.date-add-of-mysql-mode.md)。
* 该函数的第二种声明用于将 `days` 指定的天数与 `expr` 指定的日期相加。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 在指定日期上增加 3 天。

    ```shell
    obclient> SELECT ADDDATE('2026-03-30', 3);
    ```

    返回结果如下：

    ```shell
    +--------------------------+
    | ADDDATE('2026-03-30', 3) |
    +--------------------------+
    | 2026-04-02 00:00:00.000  |
    +--------------------------+
    1 row in set
    ```

3. 在指定日期时间上增加 1 小时 30 分钟。

    ```shell
    obclient> SELECT ADDDATE('2026-03-30 10:00:00', INTERVAL 90 MINUTE);
    ```

    返回结果如下：

    ```shell
    +----------------------------------------------------+
    | ADDDATE('2026-03-30 10:00:00', INTERVAL 90 MINUTE) |
    +----------------------------------------------------+
    | 2026-03-30 11:30:00.000                            |
    +----------------------------------------------------+
    1 row in set
    ```
