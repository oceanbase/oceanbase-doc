# MONTHS_ADD

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
MONTHS_ADD(date, months)
```

## 说明

该函数用于向日期 `date` 添加指定的月份数 `months`。

## 支持的数据类型

OceanBase 数据库的 `months_add` 函数支持多种时间相关数据类型作为输入，并根据输入类型决定返回类型，具体对应关系如下：

* 输入 `DATE` 返回 `DATE` 类型。
* 输入 `DATETIME` 返回 `DATETIME` 类型。
* 输入 `TIMESTAMP` 返回 `DATETIME` 类型。
* 输入 `VARCHAR` (可被解析为日期的字符串) 返回 `DATETIME` 类型。
* 输入 `TIME` 返回 `DATETIME` 类型。对于 `TIME` 类型，函数会取其年月日部分为当前实时日期，再与给定的月份数进行计算。

## 不兼容场景

OceanBase 数据库和 Doris 的差异：

* OceanBase 数据库中 `month_add` 在输入非法时都会返回 `NULL`，而不是报错。
* 可以处理 `TIME` 类型，年月日取实时时间。
* 根据 `ALLOW_INVALID_DATES` 控制是否允许对非法日期进行计算。
* 单条 `SELECT` 语句时参数是字符串时，统一转换成 `DATETIME` 类型输出。Doris 会输出 `DATE` 或者 `DATETIME`。

## 示例

在 `2026-01-31` 的基础上加 1 个月。

```shell
obclient> SELECT MONTHS_ADD('2026-01-31', 1);
```

返回结果如下：

```shell
+-----------------------------+
| MONTHS_ADD('2026-01-31', 1) |
+-----------------------------+
| 2026-02-28 00:00:00         |
+-----------------------------+
1 row in set
```
