# TOUNIXTIMESTAMP

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
TOUNIXTIMESTAMP(datetime)
```

## 说明

该函数用于将日期时间表达式 `datetime` 转换为 Unix 时间戳（自 ‘1970-01-01 00:00:00’ UTC 以来的秒数）。如果参数为 `DATE` 类型，则时间部分默认为午夜（00:00:00）。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 返回一个整数时间戳。

    ```shell
    obclient> SELECT TOUNIXTIMESTAMP('2026-03-30 12:00:00');
    ```

    返回结果如下：

    ```shell
    +----------------------------------------+
    | TOUNIXTIMESTAMP('2026-03-30 12:00:00') |
    +----------------------------------------+
    |                             1774843200 |
    +----------------------------------------+
    1 row in set
    ```

3. 返回当日 0 点的 Unix 时间戳。

    ```shell
    obclient> SELECT TOUNIXTIMESTAMP(DATE '2026-03-30');
    ```

    返回结果如下：

    ```shell
    +------------------------------------+
    | TOUNIXTIMESTAMP(DATE '2026-03-30') |
    +------------------------------------+
    |                         1774800000 |
    +------------------------------------+
    1 row in set
    ```
