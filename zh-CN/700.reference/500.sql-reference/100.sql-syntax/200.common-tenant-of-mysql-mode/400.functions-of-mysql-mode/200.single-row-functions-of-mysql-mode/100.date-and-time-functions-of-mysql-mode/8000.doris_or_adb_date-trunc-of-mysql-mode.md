# DATE_TRUNC

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入。</p>
</main>

## 声明

```sql
DATE_TRUNC(precision, source)
```

## 说明

该函数用于将日期时间 `source` 截断到指定的 `precision` 级别（如 `year`、`month`、`day`、`hour` 等），返回该时间单位起始点的值。

## 示例

使用 `date_trunc` 将 `2026-03-24 14:30:00` 截断到月的精度。

```shell
obclient> SELECT date_trunc('month', timestamp '2026-03-24 14:30:00');
```

返回结果如下：

```shell
+------------------------------------------------------+
| date_trunc('month', timestamp '2026-03-24 14:30:00') |
+------------------------------------------------------+
| 2026-03-01 00:00:00                                  |
+------------------------------------------------------+
1 row in set
```
