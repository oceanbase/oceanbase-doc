# DATE_TRUNC

`DATE_TRUNC(precision, source)` 将日期/时间值 `source` 截断到由 `precision` 指定的时间单位起点。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.0 版本开始引入，仅在 MySQL 模式下可用。</p>
</main>

## 语法

```sql
DATE_TRUNC(precision, source)
```

## 参数说明

| **参数**    | **说明**                                                                                                                              |
|-------------|---------------------------------------------------------------------------------------------------------------------------------------|
| `precision` | 字符串，指定截断的时间单位。匹配时**忽略大小写**。具体可选值见下表。                                                                   |
| `source`    | 待截断的日期/时间值。`DATETIME`、`DATE`（含 MySQL 模式下的对应类型）按原类型返回；其他类型按 `DATETIME` 处理并返回 `DATETIME`。        |

### 支持的 `precision` 取值

| **取值**       | **截断到**                       |
|----------------|----------------------------------|
| `microseconds` | 微秒                             |
| `milliseconds` | 毫秒                             |
| `second`       | 秒                               |
| `minute`       | 分                               |
| `hour`         | 时                               |
| `day`          | 日                               |
| `week`         | 周（按 ISO 周，周一为一周起点）  |
| `month`        | 月                               |
| `quarter`      | 季度                             |
| `year`         | 年                               |
| `decade`       | 十年                             |
| `century`      | 世纪                             |
| `millennium`   | 千年                             |

## 返回值

返回与 `source` 类型相同的截断后的日期/时间值。当 `source` 为非日期/时间类型时，先按 `DATETIME` 解释，再返回 `DATETIME`。

## 注意事项

* `precision` 取值若不在上述列表中（例如 `weeks`、`months` 复数形式），会按非法时间单位处理并报错。
* `precision` 大小写不敏感（例如 `MONTH`、`Month`、`month` 等价）。

## 示例

1. 将时间戳截断到月。

    ```sql
    obclient> SELECT DATE_TRUNC('month', TIMESTAMP '2026-03-24 14:30:00') AS d;
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | d                   |
    +---------------------+
    | 2026-03-01 00:00:00 |
    +---------------------+
    1 row in set
    ```

2. 截断到季度起点。

    ```sql
    obclient> SELECT DATE_TRUNC('quarter', TIMESTAMP '2026-08-15 09:00:00') AS d;
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | d                   |
    +---------------------+
    | 2026-07-01 00:00:00 |
    +---------------------+
    1 row in set
    ```

3. 截断到 ISO 周起点（周一）。

    ```sql
    obclient> SELECT DATE_TRUNC('week', TIMESTAMP '2026-04-29 10:00:00') AS d;
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | d                   |
    +---------------------+
    | 2026-04-27 00:00:00 |
    +---------------------+
    1 row in set
    ```

4. `DATE` 类型按原类型返回（不会被强转为 `DATETIME`）。

    ```sql
    obclient> SELECT DATE_TRUNC('month', DATE '2026-03-24') AS d;
    ```

    返回结果如下：

    ```shell
    +------------+
    | d          |
    +------------+
    | 2026-03-01 |
    +------------+
    1 row in set
    ```
