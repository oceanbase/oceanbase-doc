# parseDateTime

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数从 V4.6.1 版本开始引入。</p>
</main>

## 声明

```sql
parseDateTime(str [, format])
```

## 说明

`parseDateTime` 函数按照指定格式将字符串解析为 `DATETIME` 类型。当省略 `format` 参数时，使用默认格式解析字符串。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该函数为 ClickHouse 兼容函数，默认不开放，使用前需设置配置项 <code>sql_func_extension_mode</code> 来启用，详细信息参见 <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 参数说明

| 参数 | 必选/可选 | 说明 |
|------|-----------|------|
| str | 必选 | 待解析的日期时间字符串。 |
| format | 可选 | 格式字符串，使用 `%` 开头的格式说明符指定解析规则。省略时按默认格式解析。 |

常用格式说明符包括：

| 格式说明符 | 说明 |
|-----------|------|
| %Y | 四位年份 |
| %y | 两位年份 |
| %m | 月份（01-12） |
| %d | 日期（01-31） |
| %H | 小时（00-23） |
| %i | 分钟（00-59） |
| %s | 秒（00-59） |
| %f | 微秒 |
| %F | ISO 日期格式（YYYY-MM-DD） |
| %T | ISO 时间格式（HH:MM:SS） |

## 返回说明

* 返回 `DATETIME` 类型。
* 任一参数为 `NULL` 时，返回 `NULL`。
* 字符串与格式不匹配或日期时间值非法时，将报错。

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. 使用默认格式解析日期时间字符串。

    ```shell
    obclient> SELECT parseDateTime('2023-12-08 14:30:45') AS dt;
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | dt                  |
    +---------------------+
    | 2023-12-08 14:30:45 |
    +---------------------+
    1 row in set
    ```

3. 使用显式格式解析日期时间字符串。

    ```shell
    obclient> SELECT parseDateTime('12/08/2023 02:30:45 PM', '%m/%d/%Y %h:%i:%s %p') AS dt;
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | dt                  |
    +---------------------+
    | 2023-12-08 14:30:45 |
    +---------------------+
    1 row in set
    ```
