# EDITDISTANCE

`editDistance(string1, string2)` 与 `editDistanceUTF8(string1, string2)` 计算两个字符串之间的 Levenshtein 编辑距离，即将其中一个字符串通过最少次数的单字符插入、删除或替换变成另一个字符串所需的操作数。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本组函数从 V4.6.0 版本开始引入，为 ClickHouse 兼容函数。默认不开放，使用前需将租户级配置项 <code>sql_func_extension_mode</code> 设置为 <code>ClickHouse</code>，详见 <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>。</p>
</main>

## 语法

```sql
editDistance(string1, string2)
editDistanceUTF8(string1, string2)
```

## 参数说明

| **参数**             | **说明**             |
|----------------------|----------------------|
| `string1`、`string2` | 待比较的两个字符串。 |

## 返回类型

`BIGINT UNSIGNED` 类型，表示 `string1` 与 `string2` 之间的编辑距离。

## 行为说明

- `editDistance` 按 **字节** 计算距离，适合 ASCII 或单字节字符集；对多字节字符集（如 UTF-8）会把一个汉字按多个字节计入差异。
- `editDistanceUTF8` 先按 UTF-8 解码为字符（码点），再按 **字符** 计算距离，多字节字符按 1 个字符计入差异。
- 任一入参为 `NULL` 时，结果为 `NULL`。
- 任一入参为空字符串时，结果为另一字符串的长度（`editDistance` 按字节、`editDistanceUTF8` 按字符）。
- 每个入参的长度上限为 65536（`editDistance` 为字节数、`editDistanceUTF8` 为字符数），超过会报错 `ERROR 1153 (HY000): Got a packet bigger than 'max_allowed_packet' bytes`，对应内核错误码 `OB_ERR_PARAMETER_TOO_LONG`，提示 `string length is too long for edit distance, should be at most 65536`。

## 示例

1. 启用 ClickHouse 扩展函数模式。

    ```sql
    obclient> ALTER SYSTEM SET sql_func_extension_mode = 'ClickHouse';
    ```

2. 计算字符串 `Base` 和 `OceanBase` 之间的编辑距离。

    ```sql
    obclient> SELECT editDistance('Base', 'OceanBase') AS d;
    ```

    返回结果如下：

    ```shell
    +------+
    | d    |
    +------+
    |    5 |
    +------+
    1 row in set
    ```

3. 字节级与字符级的差异。`editDistance` 把"中"按 3 个 UTF-8 字节计入差异，`editDistanceUTF8` 按 1 个字符计入差异。

    ```sql
    obclient> SELECT editDistance('OB', '中OB') AS bytes_diff,
                     editDistanceUTF8('OB', '中OB') AS chars_diff;
    ```

    返回结果如下：

    ```shell
    +------------+------------+
    | bytes_diff | chars_diff |
    +------------+------------+
    |          3 |          1 |
    +------------+------------+
    1 row in set
    ```

4. 含 `NULL` 与空串的边界情况。

    ```sql
    obclient> SELECT editDistance(NULL, 'abc') AS null_case,
                     editDistance('', 'abc')   AS empty_case;
    ```

    返回结果如下：

    ```shell
    +-----------+------------+
    | null_case | empty_case |
    +-----------+------------+
    |      NULL |          3 |
    +-----------+------------+
    1 row in set
    ```
