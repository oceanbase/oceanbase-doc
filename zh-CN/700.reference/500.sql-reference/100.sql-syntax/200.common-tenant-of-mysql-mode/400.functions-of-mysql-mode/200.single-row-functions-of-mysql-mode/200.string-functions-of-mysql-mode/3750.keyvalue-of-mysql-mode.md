# KEYVALUE

## 描述

该函数用于从键值对字符串中提取特定键对应的值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.3.5 版本，该函数从 V4.3.5 BP1 版本开始支持。</p>
</main>

## 语法声明

```sql
KEYVALUE(key_value_pair, [split1, split2,] key)
```

## 参数解释

* `key_value_pair`: 表示包含多个键值对的字符串。每个键值对由指定的分隔符分隔。
* `split1, split2,`：可选项，表示分隔符。具体如下：

  * `split1`：表示键值对之间的分隔符，默认为 `;`。
  * `split2`：表示键值对内部的分隔符，默认为 `:`。

* `key`: 表示要提取的键，即将 `key_value_pair` 按照 `split1` 和 `split2` 拆分后，返回 `key` 值对应的 `value`。

## 返回类型

返回一个 `VARCHAR` 类型的字符串。返回规则如下：

* `key_value_pair` 值为 `NULL` 时，返回 `NULL`。
* `split1` 或 `split2` 值为 `NULL` 时，返回 `NULL`。
* `key` 值为 `NULL` 时，返回 `NULL`。
* 如果未找到对应的键，函数将返回 `NULL`。
* 如果有多个键值对匹配，返回第一个匹配上的 `key` 对应的 `value`。

## 示例

```sql
SELECT
    KEYVALUE(NULL, ',', '=', 'b') AS key_value_null,
    KEYVALUE('a=1,b=2,c=3', NULL, '=', 'b') AS split1_null,
    KEYVALUE('a=1,b=2,c=3', ',', NULL, 'b') AS split2_null,
    KEYVALUE('a=1,b=2,c=3', ',', '=', NULL) AS key_null,
    KEYVALUE('a=1,b=2,c=3', ',', '=', 'b') AS b,
    KEYVALUE('a=1,b=2,c=3,b=4', ',', '=', 'b') AS bs,
    KEYVALUE('a:1;b:2;c:3', 'b') split_default;
```

返回结果如下：

```shell
+----------------+-------------+-------------+----------+------+------+---------------+
| key_value_null | split1_null | split2_null | key_null | b    | bs   | split_default |
+----------------+-------------+-------------+----------+------+------+---------------+
| NULL           | NULL        | NULL        | NULL     | 2    | 2    | 2             |
+----------------+-------------+-------------+----------+------+------+---------------+
1 row in set
```
