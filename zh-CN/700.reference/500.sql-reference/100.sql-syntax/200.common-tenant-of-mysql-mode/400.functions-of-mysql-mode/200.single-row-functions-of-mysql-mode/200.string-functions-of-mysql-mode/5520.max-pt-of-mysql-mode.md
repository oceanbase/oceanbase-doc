# MAX_PT

## 描述

该函数用于返回分区表中有数据的分区的分区键的最大值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.6.x 版本，该函数从 V4.6.0 版本开始引入。</p>
</main>

## 使用限制及注意事项

* 调用者需对目标表具备 **SELECT** 权限（MySQL 模式按表级权限校验）；无权限时调用失败。
* 参数中的表名须为**常量**（解析阶段可确定的字符串字面量），不支持变量或非常量表达式作为表名参数。
* 要求查询的表为分区表，并且分区类型为 **Range** 或 **List**。
* 要求查询表为**内表**，不支持外表和 DBlink。
* 只支持**单列**分区键；不支持**多列**分区键。
* 不支持**表达式分区**（分区键不是单列直接引用、而是分区定义中带表达式时），此时不能使用 `MAX_PT`。
* 如果为二级分区表，只返回一级分区的值。
* 如果所有分区都为空，则返回 NULL。
* 如果在同一个分区中存在不同的分区值，`MAX_PT` 的结果是 `undefined`，会从这个分区中任意选择一行的值返回。

## 语法

```sql
MAX_PT('[database_name.]table_name')
```

## 参数解释

* `database_name`：可选项，表示表所在的数据库名称。如果不指定，则默认为**当前会话**下的默认库中的表。也可使用 `'db_name.table_name'` 形式在第一个字符串参数中同时给出库名与表名（至多一层 `.` 分隔）。
* `table_name`：表示表名称。库名、表名会按当前会话的大小写策略与合法字符规则解析，需与数据字典中存储的名称一致（含大小写）。

## 返回值

返回最大（按照 `max()` 比较逻辑）有数据分区的分区值，数据类型和分区键类型相同。

## 示例

1. 创建分区表 `test_tbl1`。

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT, col2 INT, col3 INT)
        PARTITION BY LIST (col1) (
            PARTITION P0 VALUES IN (1),
            PARTITION P1 VALUES IN (2),
            PARTITION P2 VALUES IN (3),
            PARTITION P3 VALUES IN (4)
        );
    ```

2. 插入测试数据

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1,1,1),
        (2,2,2),
        (3,3,3),
        (4,4,4),
        (1,1,2),
        (2,2,2);
    ```

    返回结果如下：

    ```shell
    Query OK, 6 rows affected
    Records: 6  Duplicates: 0  Warnings: 0
    ```

3. 查看表 `test_tbl1` 中有数据的分区的分区键的最大值。

    ```shell
    obclient> SELECT MAX_PT('test_tbl1');
    ```

    返回结果如下：

    ```shell
    +---------------------+
    | MAX_PT('test_tbl1') |
    +---------------------+
    |                   4 |
    +---------------------+
    1 row in set
    ```
