# SPLIT_PART

## 描述

该函数用于将经过 URL 编码的字符串解码为可读的常规字符。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.3.5 版本，该函数从 V4.3.5 BP1 版本开始支持。</p>
</main>

## 语法声明

```sql
URL_DECODE(encoded_string)
```

## 参数解释

`encoded_string`：必须是有效的 URL 编码字符串。每个编码由百分号（%）后跟两个十六进制字符表示。编码规则如下：

* a~z、A~Z 保持不变。

* 英文句点（.）、短划线（-）、星号（*）和下划线（_）保持不变。

* 其余的字符保持不变。

## 返回类型

返回一个 `VARCHAR` 类型的字符串。`encoded_string` 值为 `NULL` 时，返回 `NULL`。

## 示例

```sql
SELECT URL_DECODE('hello%20world!'), URL_DECODE(NULL);
```

返回结果如下：

```shell
+------------------------------+------------------+
| URL_DECODE('hello%20world!') | URL_DECODE(NULL) |
+------------------------------+------------------+
| hello world!                 | NULL             |
+------------------------------+------------------+
1 row in set
```
