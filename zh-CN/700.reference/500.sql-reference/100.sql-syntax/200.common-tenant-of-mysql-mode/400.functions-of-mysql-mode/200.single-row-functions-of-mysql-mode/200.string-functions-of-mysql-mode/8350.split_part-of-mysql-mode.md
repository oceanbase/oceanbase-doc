# SPLIT_PART

## 描述

该函数用于将输入字符串按分隔符分割成多个子字符串，并返回从起始位置到结束位置（可选）之间的部分。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 OceanBase 数据库 V4.3.5 版本，该函数从 V4.3.5 BP1 版本开始支持。</p>
</main>

## 语法声明

```sql
SPLIT_PART(string, separator, start[, end])
```

## 参数解释

* `string`：表示需要分割的原始字符串。
* `separator`：表示用于分割字符串的分隔符。
* `start`：指定返回部分的起始位置。正数表示从字符串开头开始计数，负数表示从字符串末尾开始计数。如果 `start` 为 0，返回第一个部分。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>当 <code>start</code> 取值为负数时，不能指定 <code>end</code>，否则报错。</p>
    </main>

* `end`：可选项，指定返回部分的结束位置。如果未提供 `end`，只返回 `start` 位置的字符串。

## 返回类型

返回一个 `VARCHAR` 类型的字符串。如果 `start` 或 `end` 超出范围，返回空字符串。

## 示例

```sql
SELECT
    SPLIT_PART('a,b,c,d', ',', 1),
    SPLIT_PART('a,b,c,d', ',', 1, 2),
    SPLIT_PART('a,b,c,d', ',', 0),
    SPLIT_PART('a,b,c,d', ',', -2),
    SPLIT_PART('a,b,c,d', ',', 5),
    SPLIT_PART('a,b,c,d', ',', -5);
```

返回结果如下：

```shell
+-------------------------------+----------------------------------+-------------------------------+--------------------------------+-------------------------------+--------------------------------+
| SPLIT_PART('a,b,c,d', ',', 1) | SPLIT_PART('a,b,c,d', ',', 1, 2) | SPLIT_PART('a,b,c,d', ',', 0) | SPLIT_PART('a,b,c,d', ',', -2) | SPLIT_PART('a,b,c,d', ',', 5) | SPLIT_PART('a,b,c,d', ',', -5) |
+-------------------------------+----------------------------------+-------------------------------+--------------------------------+-------------------------------+--------------------------------+
| a                             | a,b                              | a                             | c                              |                               |                                |
+-------------------------------+----------------------------------+-------------------------------+--------------------------------+-------------------------------+--------------------------------+
1 row in set
```
