# 数组转换函数

数组转换函数用于将输入的数组数据转换为其他类型。OceanBase 数据库当前所支持的数组转换函数包括 `arrayMap()`、`array_to_string()`、`array_to_json()`。

## arrayMap


`arrayMap()` 函数用于将输入的数组中的每个元素按照定义的匿名函数进行转换，并将每次转换后得到的所有新元素组成 1 个新的数组作为输出结果。语法如下：

```sql
arrayMap((x1,...,xn) -> (expression), arr1,...,arrn)
```

输入参数说明如下：

* `(x1,...,xn) -> (expression)` 匿名函数 lambda function。
* `arr1,...,arrn` 输入的数组。传入的类型必须是一个数组类型，数组元素个数必须是一样的；`n` 必须和 lambda function 参数个数一致。

返回值为数组类型。

功能约束限制如下：

* 匿名函数的 `expression` 不支持子查询语句。
* 匿名函数的 `expression` 不支持汇聚函数。
* 匿名函数的 `expression` 不支持做为生成列的表达式。

示例如下：

```sql
SELECT array_append([1,2,3], 2);
+--------------------------+
| array_append([1,2,3], 2) |
+--------------------------+
| [1,2,3,2]                |
+--------------------------+
1 row in set
```
