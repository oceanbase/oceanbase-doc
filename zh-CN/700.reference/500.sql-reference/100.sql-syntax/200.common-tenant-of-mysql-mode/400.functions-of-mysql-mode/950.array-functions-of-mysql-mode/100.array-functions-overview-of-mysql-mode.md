# 数组函数概述

数组函数是 OceanBase 数据库系统中提供的一组专门用于处理数组数据的函数。这些函数允许用户执行复杂的数组查询和分析。

以下是一些 OceanBase 的数组函数及其用途的概述：

## 数组函数类型

| 数组函数类型                               | 描述                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [数组构造函数](200.array-constructor-functions-of-mysql-mode.md) | 用于构建新的数组数据类型的函数。 |
| [数组判断函数](300.array-decision-functions-of-mysql-mode.md)  | 对输入的数组数据进行逻辑判断，并返回布尔值的函数。 |
| [数组转换函数](400.array-conversion-functions-of-mysql-mode.md)  | 对输入的数组数据进行转换，并返回转换后的数组数据。 |
| [数组输出函数](500.array-output-functions-of-mysql-mode.md)  | 对输入的数组数据进行输出，并返回输出后的数组数据。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md)  | 对输入的数组数据进行基本操作，如添加元素、删除元素、查找元素等，并返回操作后的数组数据。 |

## 数组函数全览

OceanBase 数据库当前支持的所有数组函数如下所示：

| 函数类型 | 函数名称 | 描述 |
|---------|---------|------|
| [数组构造函数](200.array-constructor-functions-of-mysql-mode.md) | array | 用于构建一个数组数据。 |
| [数组构造函数](200.array-constructor-functions-of-mysql-mode.md) | rb_build | 用于将基础类型为整数的数组数据转换为高效压缩位图数据（RoaringBitmap）。 |
| [运算符](200.array-constructor-functions-of-mysql-mode.md) | [] | 用于构建一个数组数据。 |
| [数组判断函数](300.array-decision-functions-of-mysql-mode.md) | array_contains | 判断数组中是否含有某个元素。 |
| [数组判断函数](300.array-decision-functions-of-mysql-mode.md) | array_contains_all | 判断输入的数组是否包含另一个数组中的所有元素。 |
| [数组判断函数](300.array-decision-functions-of-mysql-mode.md) | array_overlaps | 判断两个数组是否存在交集。 |
| [运算符](300.array-decision-functions-of-mysql-mode.md) | ANY | 判断数组中是否含有某个元素，和 `array_contains()` 函数功能相同。 |
| [数组输出函数](500.array-output-functions-of-mysql-mode.md) | array_to_string | 将数组转换为字符串。具体而言，即根据指定的分隔符和空元素符将数组中的所有基础元素打印成字符串。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | array_append | 用于向目标数组中新增指定元素。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | array_distinct | 用于对目标数组进行去重操作。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | array_remove | 用于对目标数组进行删除指定元素操作。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | cardinality | 用于返回目标数组的基础元素数量。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | element_at | 根据索引，返回目标数组中指定位置的元素。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | string_to_array | 用于将字符转换为数组。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | array_agg | 用于将指定列上的多行数据汇聚成 1 个数组值并返回结果。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | unnest | 用于将数组中的元素展开为多行，并返回一个包含这些元素的集合。 |
| [数组操作函数](600.array-manipulation-functions-of-mysql-mode.md) | array_map | 用于将输入的数组中的每个元素按照定义的匿名函数进行转换，并将每次转换后得到的所有新元素组成 1 个新的数组作为输出结果。 |
