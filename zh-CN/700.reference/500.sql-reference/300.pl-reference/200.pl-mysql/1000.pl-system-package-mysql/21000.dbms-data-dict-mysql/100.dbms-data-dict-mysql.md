# DBMS_DATA_DICT

`DBMS_DATA_DICT` 用于控制数据字典的调度。

## 语法

### 禁止调度数据字典

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>如果执行时字典配置项 <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2300.dump_data_dictionary_to_log_interval.md">dump_data_dictionary_to_log_interval</a> 不为 <code>0</code>，则执行失败，并提示用户设置该配置项为 <code>0</code>。</p>
</main>

### 允许调度数据字典

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
```

### 手动触发生成字典

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(DICT_ITEM_RETENTION_BY_DAY);
```

### 调整字典的定时 DUMP 周期

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL(INTERVAL_EXPR);
```

会触发调度生成字典的场景：

* 租户建立后会立即自动触发生成一次数据字典。

* 开启归档时会立即自动触发生成一次数据字典。

<main id="notice" >
  <h4>注意</h4>
  <p>执行时需要字典 DUMP 服务为开启状态（即先执行 <code>ALL DBMS_DATA_DICT.ENABLE_DUMP()</code> ），否则会执行失败。</p>
</main>

### 调整字典历史记录的回收间隔

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(DICT_ITEM_RETENTION_BY_DAY)
```

## 参数解释

| **参数**           | **说明**                       |**数据类型**   |
|------------------|---------------------------------|-------|
|DICT_ITEM_RETENTION_BY_DAY|<ul>触发执行生成字典后，执行回收字典的历史 DUMP 记录：<li>携带参数时，取值范围大于等于 `0`。</li><li>不携带参数或参数为 `0` 时，代表本次 DUMP 不回收字典。</li></ul>| INT |
|INTERVAL_EXPR|表示期望的调度周期。该参数需遵循 `DBMS_SCHEDULER` 的 `REPEAT_INTERVAL` 的书写格式，并用单引号包裹。例如 `'FREQ=MINUTELY; INTERVAL=120'`。其中：<ul><li>`FREQ` 可选 `SECONDLY`/`DAILY`/`HOURLY`/`WEEKLY`/`YEARLY`。</li><li>`INTERVAL` 是执行周期，填写期望执行周期的相应数字即可。</li></ul>两者拼到一起就是 `INTERVAL_EXPR`。 | TEXT |
|DICT_ITEM_RETENTION_BY_DAY|表示期望的字典历史记录回收时间，单位为天。<br/>和 `DBMS_DATA_DICT.TRIGGER_DUMP` 携带参数的调用相比，这个存储过程执行后，后续的字典 DUMP 默认都会按照本次指定的时间来回收字典历史记录（除非手动执行带参数的 `DBMS_DATA_DICT.TRIGGER_DUMP` 存储过程）。| INT |

## 示例

### 禁止调度数据字典

```sql
CALL DBMS_DATA_DICT.DISABLE_DUMP();
Query OK, 0 rows affected
```

### 允许调度数据字典

```sql
CALL DBMS_DATA_DICT.ENABLE_DUMP();
Query OK, 0 rows affected
```

### 手动触发生成字典

```sql
CALL DBMS_DATA_DICT.TRIGGER_DUMP(7);
Query OK, 0 rows affected
```

### 调整字典的定时 DUMP 周期

```sql
CALL DBMS_DATA_DICT.MODIFY_DUMP_INTERVAL('FREQ=MINUTELY; INTERVAL=120');
Query OK, 0 rows affected
```

### 调整字典历史记录的回收间隔

```sql
CALL DBMS_DATA_DICT.MODIFY_DICT_ITEM_RETENTION(7);
Query OK, 0 rows affected
```
