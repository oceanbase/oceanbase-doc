# FORALL 与 BULK COLLECT

<main id="notice">
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版 Oracle 模式。</p>
</main>

批量绑定（Bulk Binding）是在 PL/SQL 与 SQL 之间批量传递数据的机制，可减少逐行 FETCH、INSERT、UPDATE、DELETE 的开销。OceanBase Oracle 模式支持两个核心语法：**FORALL 语句**（批量执行 DML）与 **BULK COLLECT 子句**（批量取回查询结果到集合）。当一次操作涉及多行时，可明显提升性能。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>虽然 <code>MERGE INTO</code> 支持在 <code>FORALL</code> 中使用，但 SQL 引擎目前不支持 <code>MERGE INTO</code> 的 array binding，会降级为 <code>FOR</code> 循环执行。</p>
</main>

## 示例用表

以下示例均基于同一张表。请先执行建表语句后再运行各示例。

```sql
obclient> CREATE TABLE employee_info (
    emp_id NUMBER,
    emp_name VARCHAR2(50),
    salary NUMBER
);
```

## FORALL 语句

`FORALL` 通过批量绑定变量执行 DML，依赖 SQL 引擎的 array binding，比 `FOR` 循环逐条执行更高效。

### 配置要求

将配置项 `ob_enable_batched_multi_statement` 设置为 `true`。为 `false` 时会降级为 `FOR` 循环执行。

### 使用限制

`FORALL` 用于批量执行 `insert`、`update`、`delete`、`merge into` 等 DML 语句，批量执行依赖 SQL 引擎的 arraybinding 功能。

OceanBase 内的 `FORALL` 语句批量执行只放开了部分场景，以下情况会降级为 `FOR` 循环执行：

* DML 语句是静态 SQL，动态 SQL 不支持批量执行。
* `FORALL` 语句的 `bounds_clause` 是 `lower_bound..upper_bound` 格式，`indices of collection` 和 `values of index_collection` 不支持批量执行。
* `insert`、`update`、`delete` 语句，`merge into` 由于 SQL 引擎不支持 arraybinding，所以不支持批量执行。
* collection 的成员是复杂类型（`pl_extend`、`json`、`geoetry`、`user_defined_sql_type`）。
* 非 batch 绑定变量是复杂类型在处理绑定变量时会误判为 batch 绑定变量。
* 动态 SQL 中使用了 `IN OUT` 绑定变量。
* 动态 SQL 并非支持的 DML（`INSERT`、`UPDATE`、`DELETE`、`MERGE INTO`）。
* 部分非法 `index` 使用的报错信息与 Oracle 存在差异。

### 语法

```sql
FORALL index IN { lower_bound .. upper_bound
                | INDICES OF collection [ BETWEEN lower_bound AND upper_bound ]
                | VALUES OF index_collection }
  [ SAVE EXCEPTIONS ]
  dml_statement
```

### 使用示例

* **批量插入**

    ```sql
    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        TYPE emp_name_array IS TABLE OF VARCHAR2(50);
        TYPE salary_array IS TABLE OF NUMBER;
        emp_ids emp_id_array := emp_id_array(1, 2, 3, 4, 5);
        emp_names emp_name_array := emp_name_array('Alice', 'Bob', 'Charlie', 'David', 'Eve');
        salaries salary_array := salary_array(5000, 6000, 7000, 8000, 9000);
    BEGIN
        FORALL i IN 1..emp_ids.COUNT
            INSERT INTO employee_info VALUES (emp_ids(i), emp_names(i), salaries(i));
        DBMS_OUTPUT.PUT_LINE('共插入 ' || SQL%ROWCOUNT || ' 条');
    END;
    /
    ```

* **批量更新**（可用 `SQL%BULK_ROWCOUNT(i)` 查看第 i 次 DML 影响行数）

    ```sql
    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        TYPE salary_array IS TABLE OF NUMBER;
        emp_ids emp_id_array := emp_id_array(1, 2, 3);
        new_salaries salary_array := salary_array(5500, 6500, 7500);
    BEGIN
        FORALL i IN 1..emp_ids.COUNT
            UPDATE employee_info SET salary = new_salaries(i) WHERE emp_id = emp_ids(i);
        DBMS_OUTPUT.PUT_LINE('共更新 ' || SQL%ROWCOUNT || ' 条');
    END;
    /
    ```

* **批量删除**

    ```sql
    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        emp_ids emp_id_array := emp_id_array(1, 2, 3);
    BEGIN
        FORALL i IN emp_ids.FIRST..emp_ids.LAST
            DELETE FROM employee_info WHERE emp_id = emp_ids(i);
        DBMS_OUTPUT.PUT_LINE('共删除 ' || SQL%ROWCOUNT || ' 条');
    END;
    /
    ```

* **INDICES OF（稀疏集合）**：集合有空元素时，只对有值的下标执行 DML。

    ```sql
    obclient> DECLARE
        TYPE num_tab IS TABLE OF NUMBER;
        v_tb num_tab := num_tab(10, 20, 30);
        v_int NUMBER := 1;
    BEGIN
        v_tb.DELETE(2);  -- 稀疏：仅保留下标 1、3
        FORALL i IN INDICES OF v_tb BETWEEN 1 AND 3
            INSERT INTO employee_info (emp_id, emp_name, salary) VALUES (v_tb(i), 'X', v_int);
        DBMS_OUTPUT.PUT_LINE('共插入 ' || SQL%ROWCOUNT || ' 条');
    END;
    /
    ```

* **SAVE EXCEPTIONS**：部分 DML 失败时继续执行，结束后通过 `SQL%BULK_EXCEPTIONS` 查看失败下标与错误码。

    ```sql
    obclient> DECLARE
        TYPE emp_id_array IS TABLE OF NUMBER;
        TYPE emp_name_array IS TABLE OF VARCHAR2(50);
        emp_ids emp_id_array := emp_id_array(1, 2, 3, 4, 5);
        emp_names emp_name_array := emp_name_array('A', 'B', 'C', 'D', 'E');
        dml_errors EXCEPTION;
        PRAGMA EXCEPTION_INIT(dml_errors, -24381);
    BEGIN
        FORALL i IN 1..emp_ids.COUNT SAVE EXCEPTIONS
            INSERT INTO employee_info VALUES (emp_ids(i), emp_names(i), 5000);
    EXCEPTION
        WHEN dml_errors THEN
            FOR j IN 1..SQL%BULK_EXCEPTIONS.COUNT LOOP
                DBMS_OUTPUT.PUT_LINE('失败下标: ' || SQL%BULK_EXCEPTIONS(j).ERROR_INDEX || ', 错误码: ' || SQL%BULK_EXCEPTIONS(j).ERROR_CODE);
            END LOOP;
    END;
    /
    ```

* **动态 SQL 中的 FORALL**：动态块内需自行声明集合，不能直接引用外层变量。

    ```sql
    obclient> BEGIN
        EXECUTE IMMEDIATE 'DECLARE TYPE my_type IS TABLE OF VARCHAR2(10); var my_type := my_type(''1'', ''2'', ''3''); BEGIN FORALL i IN 1..var.COUNT INSERT INTO employee_info(emp_id, emp_name, salary) VALUES(var(i), ''X'', 1000); END;';
        DBMS_OUTPUT.PUT_LINE('批量插入完成');
    END;
    /
    ```

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>动态 SQL 中的 <code>FORALL</code> 不支持 <code>IN OUT</code> 绑定变量。</p>
    </main>

## BULK COLLECT 子句

`BULK COLLECT` 将 SQL 返回的多行一次性取入 PL/SQL 集合，可出现在 `SELECT INTO`、`FETCH`、`RETURNING INTO` 中。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>语句未返回任何行时，PL/SQL 不抛出 NO_DATA_FOUND，目标集合为空，需在代码中判断集合是否为空。</p>
</main>

### BULK COLLECT 使用示例

* **SELECT INTO + BULK COLLECT**：多列批量放入多个集合。

    ```sql
    obclient> DECLARE
        TYPE num_tab IS TABLE OF employee_info.emp_id%TYPE;
        TYPE name_tab IS TABLE OF employee_info.emp_name%TYPE;
        v_ids   num_tab;
        v_names name_tab;
    BEGIN
        SELECT emp_id, emp_name BULK COLLECT INTO v_ids, v_names FROM employee_info ORDER BY emp_id;
        FOR i IN 1..v_ids.COUNT LOOP
            DBMS_OUTPUT.PUT_LINE(v_ids(i) || ': ' || v_names(i));
        END LOOP;
    END;
    /
    ```

* **FETCH + BULK COLLECT**：游标一次取多行入集合。

    ```sql
    obclient> DECLARE
        CURSOR c IS SELECT emp_id, emp_name, salary FROM employee_info ORDER BY emp_id;
        TYPE emp_tab IS TABLE OF c%ROWTYPE;
        v_emps emp_tab;
    BEGIN
        OPEN c;
        FETCH c BULK COLLECT INTO v_emps;
        CLOSE c;
        FOR i IN 1..v_emps.COUNT LOOP
            DBMS_OUTPUT.PUT_LINE(v_emps(i).emp_id || ' ' || v_emps(i).emp_name || ' ' || v_emps(i).salary);
        END LOOP;
    END;
    /
    ```

* **RETURNING INTO + BULK COLLECT**：DML 批量返回列写入集合。

    ```sql
    obclient> DECLARE
        TYPE id_tab IS TABLE OF employee_info.emp_id%TYPE;
        v_ids id_tab;
    BEGIN
        DELETE FROM employee_info WHERE salary < 6000 RETURNING emp_id BULK COLLECT INTO v_ids;
        DBMS_OUTPUT.PUT_LINE('删除 ' || v_ids.COUNT || ' 条');
    END;
    /
    ```

## FORALL 与 BULK COLLECT 一起使用

先 `BULK COLLECT` 取键值到集合，再 `FORALL` 按集合批量执行 DML。

```sql
obclient> DECLARE
    TYPE id_tab IS TABLE OF employee_info.emp_id%TYPE;
    v_emp_ids id_tab;
BEGIN
    SELECT emp_id BULK COLLECT INTO v_emp_ids FROM employee_info WHERE salary < 8000;
    FORALL i IN 1..v_emp_ids.COUNT
        UPDATE employee_info SET salary = salary * 1.1 WHERE emp_id = v_emp_ids(i);
    DBMS_OUTPUT.PUT_LINE('共更新 ' || SQL%ROWCOUNT || ' 条');
END;
/
```
