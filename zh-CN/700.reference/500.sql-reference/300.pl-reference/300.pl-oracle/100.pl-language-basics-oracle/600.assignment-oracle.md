# 赋值

声明变量后，可以通过不同方式为变量赋值。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
  </main>

为变量赋值的方式如下：

* 使用赋值语句为变量指定表达式的值。

* 使用 `SELECT INTO` 或 `FETCH` 语句为变量赋值。

* 将其作为输出参数 `OUT` 或可同时用作输入和输出的参数 `IN OUT` 参数传递给子程序，然后在子程序中为变量赋值。

  + `IN` 参数：`IN` 参数是传递给存储过程的值，用来提供过程执行所需的数据。调用过程时必须提供 `IN` 参数的值，且过程内部不能修改 `IN` 参数的值。

  + `OUT` 参数：`OUT` 参数用于从存储过程返回数据。过程可以修改 `OUT` 参数的值，调用过程的程序或块可以在过程执行完成后读取这些值。

  + `IN OUT` 参数：`IN OUT` 参数既是输入又是输出参数。它们可以带有初始值传递给过程，过程执行时可以修改它们的值，执行完成后，修改后的值可以被调用程序读取。

## 使用赋值语句为变量赋值

声明变量后，可以使用赋值语句为变量指定表达式的值。

PL 使用 `:=` 进行赋值操作，语法如下：

```sql
variable  := expression ;
```

其中，`variable` 为 PL 变量，`expression` 为 PL 表达式。

示例：使用赋值语句为变量赋值。

```sql
obclient> DECLARE
     pi     CONSTANT NUMBER := 3.14159;
     radius NUMBER NOT NULL := 1;
     area   NUMBER := (pi * radius**2);
BEGIN
    DBMS_OUTPUT.PUT_LINE('The area of the circle is '||area);
END;
/
Query OK, 0 rows affected

The area of the circle is 3.14159
```

示例中声明了变量 `pi` 、`radius` 和 `area`，并指定了 `pi` 和 `radius` 的初始值，使用赋值语句为变量 `area` 指定表达式的值。

## 使用 SELECT INTO 语句为变量赋值

使用 `SELECT INTO` 语句可以直接赋值给变量，每次执行 `SELECT INTO` 语句就会赋值一次，要求被赋值的变量类型与 `SELECT` 中的列一一对应。

`SELECT INTO` 语句的一种简单形式如下：

```javascript
SELECT select_item [, select_item ]...
INTO variable_name [, variable_name ]...
FROM table_name;
```

对于每个 `select_item`，必须对应一个与其类型兼容的 `variable_name`。因为 SQL 没有 `BOOLEAN` 类型，所以 `variable_name` 不能是 `BOOLEAN` 变量。

示例：使用 `SELECT INTO` 语句为变量赋值。

```sql
obclient> CREATE TABLE employees(
   employee_id    NUMBER(4,0),  
   name           VARCHAR(10),  
   salary         NUMBER(7,2)
  );
Query OK, 0 rows affected

obclient> INSERT INTO employees (employee_id,name,salary)VALUES(105,'Sam Smith',15000);
Query OK, 1 row affected

obclient> DECLARE
    emp_id      employees.employee_id%TYPE :=105;
    emp_name    employees.name%TYPE;
    wages       employees.salary%TYPE;
BEGIN
    SELECT name, NVL(salary,0) INTO emp_name, wages
    FROM employees WHERE employee_id = emp_id;
    DBMS_OUTPUT.PUT_LINE(emp_name||'----'||to_char(wages));
END;
/
Query OK, 0 rows affected

Sam Smith----15000
```

## 赋值给变量作为子程序的参数

如果将变量作为 `OUT` 或 `IN OUT` 参数传递给子程序，并且子程序为该参数分配了一个值，则该变量在子程序完成运行后保留该值。

示例：赋值给变量作为子程序的参数。

```sql
obclient> DECLARE
  wages   employees.salary%TYPE;

  PROCEDURE new_salary (
    emp_id        employees.employee_id%TYPE :=105,
    salary    IN OUT NUMBER,
    add_salary    NUMBER
  ) IS
  BEGIN
    salary := salary + add_salary;
  END;

BEGIN
  SELECT salary INTO wages
  FROM employees
  WHERE employee_id = 105;

  DBMS_OUTPUT.PUT_LINE
   ('The original wages is ' || wages);

  new_salary (105, wages, 1000);--调用procedure

  DBMS_OUTPUT.PUT_LINE
   ('The new wages is ' || wages);
END;
/
 Query OK, 0 rows affected

The original wages is 15000 --调用过程前
The new wages is 16000 --调用过程后
```

`NOCOPY` 参数可以与 `OUT` 或 `IN OUT` 参数一起使用。OceanBase 数据库中的 `NOCOPY` 参数使用方式与 Oracle 存在差异。

在 OceanBase 数据库中，当一个参数被标记为 `NOCOPY` 时，系统会在执行前记录下哪些参数是以 `NOCOPY` 方式传递的。系统使用一个数组来追踪 `NOCOPY` 参数和可能需要级联修改的参数。当过程内部修改了标记为 `NOCOPY` 的参数时，它会检查数组，以确定是否需要修改与 `NOCOPY` 参数关联的其他参数。

OceanBase 数据库和 Oracle 中 `NOCOPY` 参数与不同类型参数行为的差异如下表所示：

|参数类型              |	Oracle 行为	          |OceanBase 行为       |
|---------------------|-----------------------|--------------------|
|基础类型 (NOCOPY)      |	不适用 NOCOPY，按值传递	|在存储过程结束后反映更改|
|复杂类型 INOUT (NOCOPY)|	传地址，更改立即反映     |	传地址，更改立即反映 |
|复杂类型 OUT (NOCOPY)  |	传地址，更改立即反映     |	在存储过程结束后反映更改|

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><ul><li>基础类型：通常指的是不包含子元素的简单数据类型，包括，字符数据类型、数值数据类型、日期时间数据类型、布尔数据类型、Rowid 数据类型。</li></ul><ul><li>复杂类型：通常指的是如记录、集合、对象和其他包含子元素或是更复杂结构的数据类型。<ul><!-- start of nested list-->
                <li>记录（Records）：由多个不同数据类型的字段组成的集合。每个字段可以存储一个数据项，例如一个数值、一个字符串或者另一个复合类型。</li>
                <li>集合（Collections）：用于存储一组元素，这些元素可以是基础类型或复杂类型，例如 Oracle 中的 VARRAYS, NESTED TABLES, 和 ASSOCIATIVE ARRAYS；OceanBase 数据中的集合为关联数组（又叫索引表）、可变数组和嵌套表。</li>
                <li>对象：通常是用户定义的对象类型（UDT）。</li>
            </ul><!--end of nested list--></li></ul></p>
</main>

```sql
CREATE OR REPLACE PROCEDURE proc(x IN INT, y OUT NOCOPY) IS
BEGIN
  y := 1024;
  DBMS_OUTPUT.PUT_LINE('y = ' || y || ' x = ' || x);
END;
/
DECLARE
x INT;
BEGIN
CALL proc(x, x);
END;
/
```

上述例子展示了一个过程 proc，该过程接受一个 `IN` 参数 x 和一个 `OUT NOCOPY` 参数 y。然后在调用例程时，传递了两个相同的实参 x，数组 {2, 2} 描述了 y 被标记为 `NOCOPY`，并且 x 和 y 是相同的值。

## 为 BOOLEAN 变量赋值

布尔值（`BOOLEAN`）支持逻辑运算，`BOOLEAN` 变量只可以被赋值为 `TRUE`、`FALSE` 和 `NULL`。

示例：为 `BOOLEAN` 变量赋值。

```javascript
obclient> DECLARE
  done BOOLEAN;     --初始值默认为 NULL
BEGIN
    done := FALSE;  --指定字面量的值
    WHILE NOT done LOOP
        Null;
        done := TRUE;
    END LOOP;
END;
/
```
