# 查看合并信息

发起合并后，您可以通过视图来查看合并信息。

合并的过程可以通过视图进行查看，通常合并的时间是取决于两次合并之间的数据变化量。两次合并之间的数据变化大，合并的时间会更长。同时，合并的线程数、合并时的集群压力等都影响合并的时间长短。

## 系统租户查看所有租户的合并信息
