# compaction_high_thread_score

`compaction_high_thread_score` 用于设置高优先级 Compaction 的工作线程数。高优先级是指对 Mini SSTable 进行 Compaction 操作。

|      **属性**      |  **描述**  |
|------------------|----------|
| 参数类型             | 整型       |
| 默认值              | 0，表示使用内部默认值 6         |
| 取值范围             | \[0, 100\] |
| 是否重启 OBServer 节点生效 | 否        |
