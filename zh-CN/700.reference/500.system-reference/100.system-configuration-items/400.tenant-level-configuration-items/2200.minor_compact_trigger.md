# minor_compact_trigger 


`minor_compact_trigger` 用于配置触发转储（Minor Compaction）的 SSTable 个数的阈值。当 Mini SSTable 和 Minor SSTable 的个数总和达到配置项 `minor_compact_trigger` 所指定的值时，系统后台会尝试触发 Minor Compaction。


|      **属性**      |  **描述**   |
|------------------|-----------|
| 参数类型             | 整型        |
| 默认值              | 2         |
| 取值范围             | \[0, 16\] |
| 是否重启 OBServer 节点生效 | 否         |
