# GV$OB_TENANT_WORKER_GROUPS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.1 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_TENANT_WORKER_GROUPS` 用于展示当前租户的所有节点上工作线程组的状态。

## 字段说明

| 字段名称  |  类型  | 是否可以为 NULL |     描述     |
|----------|--------|-----------------|-------------|

## 查询示例

1. 用户租户的管理员登录数据库。

2. 查询本租户的资源组信息。

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_CONSUMER_GROUPS;
   ```

3. 查询本租户每个节点上各工作线程组的状态。

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_WORKER_GROUPS;
   ```
