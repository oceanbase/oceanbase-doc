# GV$OB_HNWS_INDEX_INFO

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

该视图展示了当前租户在所有 OBServer 节点上 HNSW 向量索引的基本信息和实时状态。

## 字段说明

|             字段名称          |      数据类型    | 是否可以为 NULL |            描述                                            |  信息类型 |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | 副本所在的节点地址                                              | 基本信息 |
| SVR_PORT                     | bigint(20)   | NO             | 副本所在的节点 RPC_PORT                                              | 基本信息 |
| TENANT_ID                    | bigint(20)   | NO             | 租户 ID：<ul><li>1：系统租户 ID</li> <li>其他值：用户租户或者 Meta 租户 ID</li></ul>                                                    | 基本信息 |
| DATA_TABLE_ID                | bigint(20)   | NO             | 数据表 ID                                                    | 基本信息 |
| DATA_TABLET_ID               | bigint(20)   | NO             | 分区 ID                                                    | 基本信息 |
| TABLE_NAME                   | varchar(256) | NO             | 表名                                                    | 基本信息 |
| INDEX_NAME                   | varchar(256) | NO             | 索引名称                                                    | 索引信息 |
| ROLE                         | varchar(8)   | NO             | 角色：<ul><li>leader：主副本</li> <li>follower：从副本</li></ul>                                                    | 基本信息 |
| INDEX_PARAM                  | longtext     | NO             | 索引参数                                                    | 索引信息 |
| MEMORY_USED                  | bigint(20)   | NO             | 内存使用                                                    | 索引信息 |
| MEMORY_HOLD                  | bigint(20)   | NO             | 占用内存                                                    | 索引信息 |
| INCR_MEM_HOLD                | bigint(20)   | NO             | 增量内存占用                                                    | 索引信息 |
| SNAP_MEM_HOLD                | bigint(20)   | NO             | 快照内存占用                                                    | 索引信息 |
| INCR_VECTOR_CNT               | bigint(20)   | NO             | 增量向量数量                                                    | 索引信息 |
| SNAP_VECTOR_CNT               | bigint(20)   | NO             | 快照向量数量                                                    | 索引信息 |
| INCR_DATA_SCN                | bigint(20) unsigned  | NO             | 增量数据版本                                                    | 索引信息 |
| SNAP_DATA_SCN                | bigint(20) unsigned  | NO             | 快照数据版本                                                    | 索引信息 |
| LAST_SUCC_SYNC_TIME          | datetime     | NO             | 最后一次成功时间                                                    | 同步信息 |
| LAST_FAILED_SYNC_TIME        | datetime     | NO             | 最近失败时间                                                    | 同步信息 |
| LAST_FAILED_CODE             | bigint(20)   | NO             | 最近失败的报错码                                                    | 同步信息 |

SELECT * FROM oceanbase.GV$OB_HNSW_INDEX_INFO;
