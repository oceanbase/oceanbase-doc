# V$OB_SS_SSTABLES

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.0 版本开始引入。</p>
</main>

## 功能描述

展示本租户共享存储上的 SSTable 信息。

<main id="notice" >
<h4>功能适用性</h4>
<p>该视图仅适用于共享存储（Shared-Storage，SS）模式。无共享（Shared-Nothing，SN）模式下，该视图的查询结果为空。</p>
</main>

## 字段说明

|          字段名称        |     类型    | 是否可以为 NULL |     描述                        |
|-------------------------|-------------|----------------|---------------------------------|
| TENANT_ID               | bigint(20)  | NO   |  租户 ID           |
| LS_ID                   | bigint(20)  | NO   |  日志流 ID          |
| TABLET_ID               | bigint(20)  | NO   |  分区 ID           |
| TRANSFER_SCN            | bigint(20)  | NO   |  Transfer 版本号          |
| TABLE_TYPE              | varchar(20) | NO   |  SSTable 类型，包括 MAJOR、MINOR、MINI、META、DDL_DUMP、CO_MAJOR、NORMAL_CG、ROWKEY_CG、COL_ORIENTED_META、DDL_MERGE_CO、DDL_MERGE_CG、DDL_MEM_CO、DDL_MEM_CG、DDL_MEM_MINI_SSTABLE、MDS_MINI、MDS_MINOR、INVALID 等          |
| CG_IDX                  | bigint(20)  | NO   |  列存数据对应第几列的 SSTable          |
| START_LOG_SCN           | bigint(20)  | NO   |  SSTable 的左边界          |
| END_LOG_SCN             | bigint(20)  | NO   |  SSTable 的右边界          |
| DATA_CHECKSUM           | bigint(20)  | NO   |  数据校验和          |
| SIZE                    | bigint(20)  | NO   |  SSTable 实际占用的磁盘空间大小，单位为字节          |
| REC_SCN                 | bigint(20)  | NO   |  该 SSTable 上传以后，所需的日志回放位点          |
| UPPER_TRANS_VERSION     | bigint(20)  | NO   |  SSTable 中最大的事务提交版本号         |
| CONTAIN_UNCOMMITTED_ROW | varchar(3)  | NO   |  是否包含未提交的数据          |

## 查询示例

用户租户下，查看本租户下指定日志流下指定 `TABLET_ID` 的 SSTable 信息。

```shell
obclient> SELECT * FROM oceanbase.V$OB_SS_SSTABLES WHERE LS_ID=1 AND TABLET_ID=60263;
```
