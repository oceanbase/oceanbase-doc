# V$OB_KEYWORDS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V5.0.1 版本开始引入。</p>
</main>

## 功能描述

该视图用于对外提供关键字查询能力。

## 字段说明

| **字段** | **类型** | **是否为 NULL** | **描述** |
| --- | --- | --- | --- |
| KEYWORD  | varchar(128) | NO   |  关键字名称    |
| LENGTH   | bigint(20)   | NO   |  关键字长度    |
| TYPE     | varchar(16)  | NO   |  关键字类型，当前的取值只能是 `SQL` 或 `PL`    |
| RESERVED | bigint(20)   | NO   |  是否为保留关键字 |

## 使用说明

该视图可能会被用于检查某个字符串能否用作 identifier，但 OceanBase 数据库当前的实现里，有一小部分非保留关键字，实际上也不能作为 identifier 使用。

以下非保留关键字在 MySQL 模式下不能够作为 identifier 使用:

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>并非所有的场合都不适用，例如有一些关键字不能作为表别名，但是可以作为列名。建议您在创建对象、表名或列名等用到 identifier 的场合避开这些关键字。</p>
</main>

* `EXCEPT`
* `INTERSECT`
* `MINUS`
* `MEMBER`
* `SOUNDS`
* `WINDOW`

## 查询示例

```shell
obclient > SELECT * FROM oceanbase.V$OB_KEYWORDS limit 5;
```

查询结果如下：

```shell
+------------+--------+------+----------+
| KEYWORD    | LENGTH | TYPE | RESERVED |
+------------+--------+------+----------+
| accessible |     10 | SQL  |        1 |
| add        |      3 | SQL  |        1 |
| all        |      3 | SQL  |        1 |
| alter      |      5 | SQL  |        1 |
| analyze    |      7 | SQL  |        1 |
+------------+--------+------+----------+
```
