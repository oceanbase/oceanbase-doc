# GV$OB_SHARED_STORAGE_QUOTA

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.3.4 版本开始引入。</p>
</main>

## 功能描述

展示本租户所有 OBServer 节点上对象存储的各项指标（包括 IOPS、IPS、OPS、IOBW、IBW、OBW 等）的申请配额及限制配额。

## 字段说明

| 字段名称     | 类型          | 是否可以为 NULL | 描述                                                        |
|-------------|---------------|----------------|-------------------------------------------------------------|
| SVR_IP      | varchar(46)   | NO   | 服务器 IP 地址     |
| SVR_PORT    | bigint(20)    | NO   | 服务器端口号     |
| ENDPOINT    | varchar(256)  | NO   | 共享存储的 Endpoint。SN（Shared-Nothing） 模式下，该字段值为空。     |
| PATH        | varchar(1024) | NO   | 对象存储的路径。SN（Shared-Nothing） 模式下，展示为本地路径。</br> 路径通常以类型开头，例如：`local://`、`oss://`、`file://`、`s3://` 等   |
| CLASS_ID    | bigint(20)    | NO   |      |
| TYPE        | varchar(32)   | NO   | 指标类型，主要包含以下类型：<ul><li>`IPS`：每秒的指令数</li> <li>`OPS`：每秒执行的操作次数</li> <li>`IOPS`：每秒输入或输出的操作数</li> <li>`IBW`：输入带宽</li> <li>`OBW`：输出带宽</li> <li>`IOBW`：输入或输出带宽</li> <li>`TAG`：标签</li></ul>     |
| REQUIREMENT | bigint(20)    | NO   | 服务器所需的各项资源    |
| ASSIGN      | bigint(20)    | NO   | 服务器备限速算法所设定的各项资源的上限     |

## 查询示例

用户租户查询本租户所有 OBServer 节点上对象存储的各项指标的申请配额及限制配额。

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SHARED_STORAGE_QUOTA;
```
