# V$OB_EXTERNAL_CATALOG_CLIENT_POOL_STAT

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.6.x 版本，该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `V$OB_EXTERNAL_CATALOG_CLIENT_POOL_STAT` 用于获取执行该 SQL 的 OBServer 的 Catalog 池化信息。

## 字段说明

|    **字段**    |    **类型**   | **是否为 NULL** | **描述** |
|----------------|---------------|-----------------|----------|
| SVR_IP         | varchar(46)   | NO              | 副本所在的节点地址。|
| SVR_PORT       | bigint(20)    | NO              | 副本所在的节点端口。|
| TENANT_ID      | bigint(20)    | NO              | 租户 ID：<ul><li>1：系统租户 ID。</li><li>其他值：用户租户或者 Meta 租户 ID。</li></ul>|
| CLIENT_TYPE    | varchar(128)  | NO              | Client 类型。|
| CATALOG_ID     | bigint(20)    | NO              | 租户下某个 Catalog 的 ID。|
| URI            | varchar(4096) | NO              | Client 所连接的 Server 地址。|
| TOTAL_CLIENTS  | bigint(20)    | NO              | `TENANT_ID` 对应的租户下对应 `CATALOG_ID` 的 Catalog 所创建的客户端总数。|
| IN_USE_CLIENTS | bigint(20)    | NO              | `TENANT_ID` 对应的租户下对应 `CATALOG_ID` 的 Catalog 正在使用的客户端数量。|
| IDLE_CLIENTS   | bigint(20)    | NO              | `TENANT_ID` 对应的租户下对应 `CATALOG_ID` 的 Catalog 空闲的客户端数量。|

## 查询示例

查询执行该 SQL 的 OBServer 的 Catalog 池化信息。

```shell
obclient> SELECT * FROM oceanbase.V$OB_EXTERNAL_CATALOG_CLIENT_POOL_STAT;
```

查询结果如下：

```shell
+-------------+----------+-----------+-------------+------------+-------------------------------+---------------+----------------+--------------+
| SVR_IP      | SVR_PORT | TENANT_ID | CLIENT_TYPE | CATALOG_ID | URI                           | TOTAL_CLIENTS | IN_USE_CLIENTS | IDLE_CLIENTS |
+-------------+----------+-----------+-------------+------------+-------------------------------+---------------+----------------+--------------+
| xx.xx.xx.xx |    10203 |      1004 | rest        |     500005 | http://localhost:9001/iceberg |             1 |              0 |            1 |
+-------------+----------+-----------+-------------+------------+-------------------------------+---------------+----------------+--------------+
1 row in set
```
