# oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.2.5 BP4 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN` 用于展示本租户下每一次日志裁剪的有关信息。

## 字段说明

| 字段        | 类型         | 是否为 NULL | 描述                                       |
|------------|--------------|-------------|------------------------------------------|
| TIMESTAMP         | timestamp(6) | NO          | 创建时间，单位微秒                   |
| OP_TYPE           | varchar(64)  | NO          | 操作类型，包括：<ul><li>`FAILOVER_TO_PRIMARY`：这是 Failover 操作的类型，当主租户不可用时，将备租户切换为主租户的操作</li><li>`FLASHBACK_STANDBY_LOG`：这是备租户日志裁剪操作的类型
用于将备租户的日志裁剪到指定的 SCN 位置</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20)   | YES         | 租户日志从后往前裁剪的终点             |
| SWITCHOVER_EPOCH  | bigint(20)   | YES         | 租户角色切换为 `NORMAL` 状态时的 `SWITCHOVER_EPOCH`。`SWITCHOVER_EPOCH` 是一个用于标识租户角色切换（Switchover/Failover）操作的唯一标识符 |

## 查询示例

```shell
obclient [oceanbase]> SELECT * FROM DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```

返回结果如下：

```shell
+-----------+----------------------------+------------------+---------------------+---------------------+
| TENANT_ID | TIMESTAMP                  | SWITCHOVER_EPOCH | OP_TYPE             | FLASHBACK_LOG_SCN   |
+-----------+----------------------------+------------------+---------------------+---------------------+
|      1006 | 2025-05-21 16:48:53.583749 | 1747817333380437 | FAILOVER TO PRIMARY | 1747817331313513000 |
+-----------+----------------------------+------------------+---------------------+---------------------+
1 row in set
```
