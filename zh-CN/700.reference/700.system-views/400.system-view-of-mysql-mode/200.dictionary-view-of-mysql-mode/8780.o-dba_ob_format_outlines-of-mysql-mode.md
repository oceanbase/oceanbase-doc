# DBA_OB_FORMAT_OUTLINES

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><ul><li>对于 V4.2.x 版本，该视图从 V4.2.3 版本开始引入。</li><li>对于 V4.3.x 版本，该视图从 V4.3.4 版本开始引入。</li></ul></p>
</main>

## 功能描述

视图 `DBA_OB_FORMAT_OUTLINES` 用于记录当前租户 Format Outline 的详细信息。

## 字段说明

|   **字段名称**    |    **类型**   | **是否可以为 NULL** | **描述** |
|-------------------|---------------|------|-------------------------|
| CREATE_TIME       | timestamp(6)  | YES  | 表示创建时间戳。|
| MODIFY_TIME       | timestamp(6)  | YES  | 表示修改时间戳。|
| TENANT_ID         | bigint(20)    | NO   | 表示租户 ID。|
| DATABASE_ID       | bigint(20)    | NO   | 表示数据库 ID。|
| OUTLINE_ID        | bigint(20)    | NO   | 表示执行计划 Outline ID。|
| DATABASE_NAME     | varchar(128)  | NO   | 表示数据库名称。|
| OUTLINE_NAME      | varchar(128)  | NO   | 表示执行计划 Outline 名称。|
| VISIBLE_SIGNATURE | longtext      | NO   | 表示 Signature 反序列化结果。|
| FORMAT_SQL_TEXT   | longtext      | YES  | 表示创建执行计划 Outline 时，在 `ON` 子句中指定的 SQL 生成的 `FORMAT SQL TEXT`。|
| OUTLINE_TARGET    | longtext      | NO   | 表示创建执行计划 Outline 时，在 `TO` 子句中指定的 SQL。|
| OUTLINE_SQL       | longtext      | NO   | 表示具有完整执行计划 Outline 信息的 SQL。|
| FORMAT_SQL_ID     | varbinary(32) | NO   | 表示表示该条记录通过 `FORMAT SQL TEXT` 生成的 md5 值。|
| OUTLINE_CONTENT   | longtext      | NO   | 表示完整的执行计划 Outline 信息。|

## 查询示例

查询当前租户下一条 Format Outline 的信息。

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_FORMAT_OUTLINES LIMIT 1\G
```
