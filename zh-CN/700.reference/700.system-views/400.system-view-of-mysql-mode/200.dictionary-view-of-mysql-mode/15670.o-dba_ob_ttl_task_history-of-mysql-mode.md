# oceanbase.DBA_OB_TTL_TASK_HISTORY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.DBA_OB_TTL_TASK_HISTORY` 用于展示 SQL 模式下当前租户 TTL 任务的执行历史。

## 字段说明

| 字段           | 类型         | 是否为 NULL | 描述                                       |
|---------------|--------------|-------------|-------------------------------------------|
| TABLE_NAME    | varchar(256) | NO   | 表名     |
| TABLE_ID      | bigint(20)   | NO   | 表 ID     |
| TASK_ID       | bigint(20)   | NO   | 当前批次任务的 ID     |
| START_TIME    | timestamp(6) | NO   | 任务的开始时间     |
| MODIFIED_TIME | timestamp(6) | NO   | 行的更新时间   |
| TRIGGER_TYPE  | varchar(8)   | NO   | 任务触发类型：<ul><li>`PERIODIC`：系统定期触发</li> <li>`USER`：用户手动触发</li></ul>       |
| STATUS        | varchar(10)  | NO   | 任务的状态：<ul><li>`CANCELED`：任务被取消</li> <li>`FINISHED`：任务已结束</li> <li>`SKIP`：未达到可执行状态，跳过本轮次执行</li> <li>`FAILED`：任务执行失败</li></ul>     |
| RET_CODE      | varchar(512) | NO   | 任务结束时返回的错误码    |
| TASK_TYPE     | varchar(10)  | NO   | TTL 任务类型：<ul><li>`NORMAL`：租户级别信息展示</li> <li>`COMPACTION`：表级任务类型，通过 Compaction 做过期数据删除</li></ul>     |

## 查询示例

用户租户查询本租户 TTL 任务的执行历史。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TTL_TASK_HISTORY;
```
