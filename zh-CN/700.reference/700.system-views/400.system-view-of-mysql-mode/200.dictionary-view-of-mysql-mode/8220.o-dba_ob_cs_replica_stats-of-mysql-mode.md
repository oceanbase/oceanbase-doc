# oceanbase.DBA_OB_CS_REPLICA_STATS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.3.5 版本，该视图从 V4.3.5 BP1 版本开始引入。</p>
</main>

## 功能描述

展示当前租户的各个列存副本上各个日志流转换为列存的进度。

## 字段说明

| 字段名称                   | 类型          | 是否可以为 NULL      | 描述                                |
|---------------------------|---------------|---------------------|-------------------------------------|
| SVR_IP                    | varchar(46)   | NO   | 列存副本所在的服务器 IP |
| SVR_PORT                  | bigint(20)    | NO   | 列存副本所在的服务器的端口号  |
| LS_ID                     | bigint(20)    | NO   | 日志流 ID  |
| TOTAL_TABLET_CNT          | bigint(20)    | NO   | 需要转为列存的分区数量  |
| AVAILABLE_TABLET_CNT      | decimal(42,0) | NO   | 可用的分区数量    |
| TOTAL_MACRO_BLOCK_CNT     | decimal(42,0) | NO   | 总的基线数据宏块数（不考虑多版本） |
| AVAILABLE_MACRO_BLOCK_CNT | decimal(42,0) | NO   | 可用的基线数据宏块数（不考虑多版本）   |
| AVAILABLE                 | varchar(5)    | NO   | 日志流是否已经完全可用：<ul><li>`TRUE`：可用</li> <li>`FALSE`：不可用</li></ul>  |
