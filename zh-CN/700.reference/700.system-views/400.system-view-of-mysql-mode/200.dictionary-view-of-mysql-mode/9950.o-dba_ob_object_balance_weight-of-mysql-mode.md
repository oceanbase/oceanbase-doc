# oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.2.5 版本，该视图从 V4.2.5 BP2 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_OBJECT_BALANCE_WEIGHT` 用于展示当前用户租户下所有设置过特殊权重的分区。

## 字段说明

|       字段名称     |      类型    | 是否可以为 NULL |         描述                                 |
|-------------------|--------------|----------------|----------------------------------------------|
| TABLE_ID          | bigint(20)   | NO             | 表 ID     |
| PARTITION_ID      | bigint(20)   | NO             | 一级分区 ID，未设置分区权重时，值为 `NULL`     |
| SUBPARTITION_ID   | bigint(20)   | NO             | 二级分区 ID，未设置分区权重时，值为 `NULL`，当前暂不支持设置二级分区权重     |
| WEIGHT            | bigint(20)   | NO             | 分区权重值     |
| DATABASE_NAME     | varchar(128) | NO             | 表所属的数据库名     |
| TABLE_NAME        | varchar(256) | NO             | 表名     |
| PARTITION_NAME    | varchar(64)  | NO             | 一级分区名     |
| SUBPARTITION_NAME | varchar(64)  | NO             | 二级分区名     |
| TABLEGROUP_NAME   | varchar(128) | NO             | 表所属的表组名     |
| DATABASE_ID       | bigint(20)   | NO             | 表所属的数据库 ID     |
| TABLEGROUP_ID     | bigint(20)   | NO             | 表所属的表组 ID     |
| OBJECT_ID         | bigint(20)   | NO             | 表所属的对象 ID     |

## 查询示例

用户租户查询本租户下设置过特殊权重的分区。

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.DBA_OB_OBJECT_BALANCE_WEIGHT;
```
