# oceanbase.DBA_OB_AI_MODELS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

展示本租户的 AI 模型信息。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| MODEL_ID | int(20) | NO | 大模型唯一标识。 |
| NAME | varchar(128) | NO | 用户定义的大模型唯一名称。在调用 AI 函数/`DBMS_AI_SERVICE` 系统包时，使用该名称即可。 |
| TYPE | varchar(128) | NO | 大模型类型。必须为以下值中的一项：<ul><li><code>dense_embedding</code>：稠密向量模型</li><li><code>sparse_embedding</code>：稀疏向量模型</li><li><code>completion</code>：文本补全模型</li><li><code>rerank</code>：重排序模型</li></ul><main id="notice" type='notice'><h4>注意</h4><p>稀疏向量模型暂时不支持使用。</p></main> |
| MODEL_NAME | varchar(128) | NO | 大模型名称，例如 `text-embedding-v2`。 |

## 查询示例

用户租户查询本租户的 AI 模型信息。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_MODELS;
```

查询结果如下：

```shell
+----------+---------------+-----------------+-------------------+
| MODEL_ID | NAME          | TYPE            | MODEL_NAME        |
+----------+---------------+-----------------+-------------------+
|   500005 | my_ai_model_1 | DENSE_EMBEDDING | text-embedding-v1 |
+----------+---------------+-----------------+-------------------+
1 row in set
```
