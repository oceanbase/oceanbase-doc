# oceanbase.DBA_OB_EXTERNAL_RESOURCES

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.4.0 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.DBA_OB_EXTERNAL_RESOURCES` 用于展示已上传的资源文件。

## 字段说明

| **字段名称** | **类型**  | **是否可以为 NULL** | **描述**               |
|------------|-------------|---------------------|----------------------------------------|
|RESOURCE_ID|bigint(20)|NO|资源 ID，资源的唯一标识符。|
|DATABASE_ID|bigint(20)|NO|资源所属数据库 ID。|
|DATABASE_NAME| varchar(128)  | NO|用于展示该外部资源所在的数据库名称。|
| NAME        | varchar(256)  | NO   |   资源名称。   |
| TYPE        | varchar(12)   | NO   |   资源类型，用于区分 Java jar 或 Python 源码等资源。 目前取值范围为 {'JAVA_JAR', 'PYTHON_PY'}。  |
| CONTENT     | longblob      | NO   |   资源的二进制内容。   |
| COMMENT     | varchar(4096) | NO   |   上传资源时添加的注释。   |

## 查询示例

执行如下 SQL 查询当前租户已上传的资源文件。

```shell
obclient > SELECT * FROM oceanbase.DBA_OB_EXTERNAL_RESOURCES;
```
