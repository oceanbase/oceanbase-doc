# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>说明</h4>
<p>从 V4.0.0 版本开始引入。</p>
</main>

## 功能描述

展示本租户的数据备份参数信息。

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | 参数名 |
| VALUE | longtext | NO | 参数值 |

## 查询示例

用户租户查看本租户的数据备份参数信息。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_PARAMETER;
```

查询结果如下：

```shell
+------------------+-----------------------------------------+
| NAME             | VALUE                                   |
+------------------+-----------------------------------------+
| data_backup_dest | file:///home/admin/oceanbase/backupdata |
+------------------+-----------------------------------------+
1 row in set
```
