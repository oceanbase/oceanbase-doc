GV$INSTANCE 
================================

功能 
-----------

该视图展示了当前数据库实例的状态。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
  </main>
