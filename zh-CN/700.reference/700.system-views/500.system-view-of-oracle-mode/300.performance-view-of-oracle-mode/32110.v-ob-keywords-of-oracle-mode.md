# V$OB_KEYWORDS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V4.6.1 版本开始引入。</p>
</main>

## 功能描述

该视图用于对外提供关键字查询能力。

## 字段说明

| **字段** | **类型** | **是否为 NULL** | **描述** |
| --- | --- | --- | --- |
| KEYWORD  | VARCHAR2(128) | NO   |  关键字名称    |
| LENGTH   | NUMBER   | NO   |  关键字长度    |
| TYPE     | VARCHAR2(16)  | NO   |  关键字类型    |
| RESERVED | NUMBER(38)   | NO   |  是否为保留关键字 |

## 查询示例

```shell
obclient > SELECT * FROM sys.V$OB_KEYWORDS where TYPE = 'PL' and rownum <= 5;
```

查询结果如下：

```shell
+------------+--------+------+----------+
| KEYWORD    | LENGTH | TYPE | RESERVED |
+------------+--------+------+----------+
| accessible |     10 | SQL  |        1 |
| add        |      3 | SQL  |        1 |
| all        |      3 | SQL  |        1 |
| alter      |      5 | SQL  |        1 |
| analyze    |      7 | SQL  |        1 |
+------------+--------+------+----------+
```
