# GV$OB_KVCACHE

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.0.0 版本开始引入。</p>
</main>

## 功能描述

展示本租户在每台 OBServer 节点上的 KVcache 信息。

## 字段说明

|      字段名称      |      类型       | 是否可以为 NULL |    描述     |
|----------------|---------------|------------|-----------|
| SVR_IP         | VARCHAR2(46)  | NO         | 服务器 IP 地址 |
| SVR_PORT       | NUMBER(38)    | NO         | 服务器端口号    |
| TENANT_ID      | NUMBER(38)    | NO         | 租户 ID     |
| CACHE_NAME     | VARCHAR2(128) | NO         | Cache 项名称 |
| PRIORITY       | NUMBER(38)    | NO         | 优先级       |
| CACHE_SIZE     | NUMBER(38)    | NO         | Cache 大小，单位为字节  |
| HIT_RATIO      | NUMBER(38,3)  | NO         | 命中率       |
| TOTAL_PUT_CNT  | NUMBER(38)    | NO         | PUT 次数    |
| TOTAL_HIT_CNT  | NUMBER(38)    | NO         | 命中次数      |
| TOTAL_MISS_CNT | NUMBER(38)    | NO         | 未命中次数     |

## 查询示例

用户租户查询本租户在每台 OBServer 节点上的 KVcache 信息。

```shell
obclient [SYS]> SELECT * FROM SYS.GV$OB_KVCACHE;
```
