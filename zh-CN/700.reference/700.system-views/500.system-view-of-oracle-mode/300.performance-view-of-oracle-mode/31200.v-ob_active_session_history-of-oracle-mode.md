# V$OB_ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.2.2 版本开始引入。</p>
</main>

## 功能描述

视图 `V$OB_ACTIVE_SESSION_HISTORY` 用于展示当前活跃会话历史记录。

## 字段说明

| SVR_IP                      | VARCHAR2(46)    | NO | 样本所属服务器 IP。 |
