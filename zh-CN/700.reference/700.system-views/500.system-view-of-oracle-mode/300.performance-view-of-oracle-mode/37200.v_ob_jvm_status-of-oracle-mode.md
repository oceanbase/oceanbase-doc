# V$OB_JVM_STATUS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该视图从 V4.4.2 BP4 版本开始引入。</p>
</main>

## 功能描述

该视图展示当前 OBServer 节点上 OBServer 进程内 JVM 的运行状态和资源使用情况，包括 JVM 状态、堆内存、元空间、GC、线程数和文件描述符数等信息。每个 OBServer 节点对应一行记录。

使用说明如下：

* 只有开启配置项 `ob_enable_java_env` 后，OBServer 进程才会启动 JVM。未开启时，`STATUS` 为 `DISABLED`。
* JVM 启动后，系统默认每 60 秒采集一次 JVM 状态。查询该视图返回的是最近一次采集的结果，不会触发 JVM 启动或采集。
* 尚未成功采集或无法获取的指标显示为 NULL，以区别于实际值为 `0` 的指标。
* Java UDF 在沙箱进程中执行时，沙箱 JVM 的状态请参见 [V$OB_JAVA_SANDBOX_STATUS](37400.v_ob_java_sandbox_status-of-oracle-mode.md)。

## 字段说明

|     字段名称    |     类型    | 是否可以为 NULL |      描述      |
|----------------|-------------|----------------|----------------|
| SVR_IP | VARCHAR2(46) | NO | OBServer 节点的 IP 地址。 |
| SVR_PORT | NUMBER(38) | NO | OBServer 节点的端口号。 |
| PROCESS_PID | NUMBER(38) | YES |
| STATUS | VARCHAR2(32) | NO | OBServer 进程内 JVM 的状态：<ul><li>`DISABLED`：未开启 Java 环境（配置项 `ob_enable_java_env` 为 `False`）</li><li>`NOT_STARTED`：JVM 尚未启动</li><li>`STARTING`：JVM 正在启动，或已启动但尚未完成首次采集</li><li>`UP`：JVM 运行中，且最近一次采集成功</li><li>`INIT_FAILED`：JVM 初始化失败</li><li>`COLLECT_ERROR`：JVM 状态采集失败</li><li>`DOWN`：OBServer 进程正在退出，或 JVM 监控已停止</li></ul> |
| INIT_ATTEMPT_COUNT | NUMBER(38) | YES |
| INIT_FAILURE_COUNT | NUMBER(38) | YES |
| LAST_INIT_ERROR_CODE | NUMBER(38) | YES |
| LAST_INIT_ERROR_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES |
| JVM_START_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | YES |
| JVM_UPTIME_MS | NUMBER(38) | YES |
| MONITOR_BRIDGE_VERSION | NUMBER(38) | YES |
| HEAP_USED_BYTES | NUMBER(38) | YES |
| HEAP_COMMITTED_BYTES | NUMBER(38) | YES |
| HEAP_MAX_BYTES | NUMBER(38) | YES |
| YOUNG_USED_BYTES | NUMBER(38) | YES |

| DIRECT_BUFFER_COUNT | NUMBER(38) | YES |

## 查询示例

```shell
obclient> SELECT SVR_IP, SVR_PORT, STATUS, HEAP_USED_BYTES, HEAP_MAX_BYTES, GC_COUNT, THREAD_COUNT, SNAPSHOT_TIME FROM SYS.V$OB_JVM_STATUS;
```
