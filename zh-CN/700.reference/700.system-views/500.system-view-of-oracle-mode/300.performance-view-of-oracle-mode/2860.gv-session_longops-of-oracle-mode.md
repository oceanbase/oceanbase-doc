# GV$SESSION_LONGOPS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V1.4 版本开始引入。</p>
</main>

## 功能描述

展示集群 DDL 操作的执行状态和进度。

## 字段说明

|     **字段名称**     |    **类型**     | **是否可以为 NULL** |  **描述**   |
|------------------|---------------|----------------|-----------|
| SID              | NUMBER    | NO             | 会话 ID     |
| TRACE_ID         | VARCHAR(64)  | NO   | 该语句的 trace_id    |
| OPNAME           | VARCHAR(64)  | NO             | 操作名称      |
| TARGET           | VARCHAR(64)  | NO             | 操作对象      |
| SVR_IP           | VARCHAR(46)   | NO             | 操作所在机器 IP |
| SVR_PORT         | NUMBER    | NO             | 操作所在机器端口号 |
| START_TIME       | VARCHAR(256)    | NO             | 开始时间      |
| ELAPSED_SECONDS  | NUMBER | NO             | 已经消耗的时间    |
| TIME_REMAINING   | NUMBER    | NO             | 预估剩余需要的时间  |
| LAST_UPDATE_TIME | VARCHAR(256)   | NO             | 统计信息更新时间  |
| MESSAGE          | VARCHAR(512)  | NO             | 备注信息      |
