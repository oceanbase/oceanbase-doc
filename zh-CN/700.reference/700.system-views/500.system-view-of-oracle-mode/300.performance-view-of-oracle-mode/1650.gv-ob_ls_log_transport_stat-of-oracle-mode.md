# GV$OB_LS_LOG_TRANSPORT_STAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该视图从 V4.4.2 BP2 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_LS_LOG_TRANSPORT_STAT` 用于展示强同步模式下租户所有节点上每个 LS（日志流）向备库推送日志的传输状态。查询时需要登录主租户（主库）或主租户（主库）所在的集群的 `sys` 租户进行查询。

## 字段说明

|      字段名称    |      类型           | 是否可以为 NULL |    描述     |
|-----------------|---------------------|----------------|-------------|
| TENANT_ID       | NUMBER(38)          | NO   | 租户 ID     |
| LS_ID           | NUMBER(38)          | NO   | 日志流 ID     |
| SVR_IP          | VARCHAR2(46)        | NO   | 服务器的 IP 地址    |
| SVR_PORT        | NUMBER(38)          | NO   | 服务器端口号     |
| ROLE            | VARCHAR2(32)        | NO   | 日志流副本角色：<ul><li>`LEADER`：主副本</li> <li>`FOLLOWER`：从副本</li></ul>     |
| ENABLED         | NUMBER(38)          | NO   | 日志传输服务（Transport Service）是否启用   |
| END_LSN         | NUMBER(38)          | NO   | 主租户（主库）Palf 已提交的 LSN    |
| END_SCN         | NUMBER(38)          | NO   | 主租户（主库）Palf 已提交的 SCN     |
| LAST_SENT_LSN   | NUMBER(38)          | NO   | 最后发送给备租户（备库）的 LSN     |
| LAST_SENT_SCN   | NUMBER(38)          | NO   | 最后发送给备租户（备库）的 SCN      |
| STANDBY_END_LSN | NUMBER(38)          | NO   | 备租户（备库）已确认写入的 LSN     |
| STANDBY_END_SCN | NUMBER(38)          | NO   | 备租户（备库）已确认写入的 SCN     |
| STANDBY_ADDR    | VARCHAR2(52)        | NO   | 备租户（备库）当前日志流 Leader 的地址。如果为 `0.0.0.0:0`，则表示无效    |

## 查询示例

主租户下，查询本租户所有节点上每个 LS 向备租户推送日志的传输状态。

1. 确认主租户 LS 的同步模式。

   ```shell
   obclient(root@oracle001)[SYS]> SELECT SVR_IP, SVR_PORT, LS_ID, ROLE, SYNC_MODE FROM SYS.GV$OB_LOG_STAT WHERE ROLE = 'LEADER';
   ```

   查询结果如下：

   ```shell
   +-------------+----------+-------+--------+-----------+
   | SVR_IP      | SVR_PORT | LS_ID | ROLE   | SYNC_MODE |
   +-------------+----------+-------+--------+-----------+
   | 6.xx.xxx.91 |     2882 |     1 | LEADER | SYNC      |
   | 6.xx.xxx.91 |     2882 |  1001 | LEADER | SYNC      |
   +-------------+----------+-------+--------+-----------+
   2 rows in set
   ```

   结果显示为 `SYNC`，表示当前租户的日志流同步模式为强同步模式。

2. 查询该主租户所有节点上每个日志流向备租户推送日志的传输状态。

   ```shell
   obclient(root@oracle001)[SYS]> SELECT SVR_IP, SVR_PORT, LS_ID, ROLE, ENABLED,
       END_LSN, LAST_SENT_LSN, STANDBY_END_LSN, STANDBY_ADDR
       FROM SYS.GV$OB_LS_LOG_TRANSPORT_STAT WHERE ROLE = 'LEADER';
   ```

   查询结果如下：

   ```shell
   +-------------+----------+-------+--------+---------+-----------+---------------+-----------------+-------------------+
   | SVR_IP      | SVR_PORT | LS_ID | ROLE   | ENABLED | END_LSN   | LAST_SENT_LSN | STANDBY_END_LSN | STANDBY_ADDR      |
   +-------------+----------+-------+--------+---------+-----------+---------------+-----------------+-------------------+
   | 6.xx.xxx.91 |     2882 |     1 | LEADER |       1 | 305150963 |     305150963 |       305150963 | 6.xx.xxx.160:2882 |
   | 6.xx.xxx.91 |     2882 |  1001 | LEADER |       1 | 201294294 |     201294294 |       201294294 | 6.xx.xxx.160:2882 |
   +-------------+----------+-------+--------+---------+-----------+---------------+-----------------+-------------------+
   2 rows in set
   ```
