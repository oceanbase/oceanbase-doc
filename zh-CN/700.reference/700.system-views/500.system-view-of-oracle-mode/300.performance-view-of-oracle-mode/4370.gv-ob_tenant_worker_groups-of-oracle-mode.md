# GV$OB_TENANT_WORKER_GROUPS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.1 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_TENANT_WORKER_GROUPS` 用于展示当前租户的所有节点上工作线程组的状态。

## 字段说明

| 字段名称           |  类型       | 是否可以为 NULL |     描述     |
|-------------------|-------------|-----------------|-------------|
| SVR_IP            | VARCHAR2(46)| NO   | 服务器 IP 地址     |
| SVR_PORT          | NUMBER(38)  | NO   | 服务器端口号    |
| TENANT_ID         | NUMBER(38)  | NO   | 租户 ID     |
| GROUP_ID          | NUMBER(38)  | NO   | 资源组 ID     |
| WORKERS_SIZE      | NUMBER(38)  | NO   | 当前工作线程数     |
| REQ_QUEUE_SIZE    | NUMBER(38)  | NO   | 普通请求队列的长度     |
| RECV_REQ_CNT      | NUMBER(38)  | NO   | 累计接收的请求数量     |
| DELETED           | tinyint(4)  | NO   | 资源组是否已标记删除：<ul><li>`0`：未删除</li> <li> `1`：已删除</li></ul>     |
| TOKEN_CHANGE_TS   | NUMBER(38)  | NO   | Token（工作线程资源令牌）变更的时间戳     |
| THROTTLED_TIME_US | NUMBER(38)  | NO   | 限流累计时间，单位为微秒     |
| IDLE_CNT          | NUMBER(38)  | NO   | 空闲的工作线程数     |
| LAST_NOT_EMPTY_TS | NUMBER(38)  | NO   | 队列最后一次非空的时间戳     |

## 查询示例

用户租户查询本租户每个节点上各工作线程组的状态。

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.GV$OB_TENANT_WORKER_GROUPS;
```
