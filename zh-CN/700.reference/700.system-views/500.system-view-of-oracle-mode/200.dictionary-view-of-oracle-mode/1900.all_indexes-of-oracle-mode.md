# ALL_INDEXES


## 功能描述

ALL_INDEXES 用于查看用户可访问的所有表的索引的索引列信息。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
  </main>
