# ALL_LOCATIONS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V4.4.0 版本开始引入。</p>
</main>

## 功能描述

`ALL_LOCATIONS` 用于查看当前租户的 External Location 对象信息。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该视图仅适用于 OceanBase 数据库 Oracle 模式。</p>
</main>

## 字段说明

|        **字段名称**         |     **类型**     | **是否可以为 NULL** |               **描述**               |
|-------------------------|----------------|----------------|--------------------------------------------------------------------|
| OWNER         | VARCHAR2(128)  | NO   | 所属的 Owner |
| LOCATION_NAME | VARCHAR2(128)  | YES  | 名称 |
| LOCATION_URL  | VARCHAR2(4000) | YES  | 路径 |
| ORIGIN_CON_ID | NUMBER(38)     | NO   | 租户 ID |
| ACCESS_INFO   | VARCHAR2(8000) | YES  | 访问信息 |
|---------------|----------------|------|------|

## 查询示例

查询当前租户的 External Location 对象信息。

```shell
obclient [SYS]> SELECT * FROM SYS.ALL_LOCATIONS ;
```
