# USER_AUDIT_OBJECT

## 功能描述

视图 `USER_AUDIT_OBJECT` 显示当前用户可访问的对象的审计跟踪记录。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该视图仅适用于 OceanBase 数据库 Oracle 模式。</p>
  </main>

## 查询示例

查询当前用户可访问的对象的审计跟踪记录。

```shell
obclient [SYS]> SELECT * FROM SYS.USER_AUDIT_OBJECT WHERE ROWNUM =1\G
```
