# DBA_OB_SYNC_STANDBY_DEST

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该视图从 V4.4.2 BP1 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_SYNC_STANDBY_DEST` 用于展示本租户的强同步下游信息。

## 字段说明

| 字段名称   | 类型          | 是否可以为 NULL | 描述                          |
|-----------|---------------|----------------|-------------------------------|
| TENANT_ID | NUMBER(38)   | NO             | 租户 ID     |
| DEST_ID   | NUMBER(38)   | NO             | 强同步备租户的 ID，当前限制一个主租户只能有一个 ID 为 0 的强同步备租户     |
| VALUE     | CLOB         | NO             | 强同步的备租户的信息，包含 ip_list、登录名、密码、cluster_id 等     |

## 查询示例

用户租户查询本租户的强同步下游信息。

```shell
obclient(SYS@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_SYNC_STANDBY_DEST\G
```

查询结果如下：

```shell
*************************** 1. row ***************************
TENANT_ID: 1004
  DEST_ID: 0
    VALUE: IP_LIST=6.xx.xxx.xx:2881+2882,USER=rep_user@standby_tenant,PASSWORD=*****************************************************************,TENANT_ID=1002,CLUSTER_ID=10002,COMPATIBILITY_MODE=MYSQL,IS_ENCRYPTED=true,net_timeout=20000000,health_check_time=40000000
1 row in set
```
