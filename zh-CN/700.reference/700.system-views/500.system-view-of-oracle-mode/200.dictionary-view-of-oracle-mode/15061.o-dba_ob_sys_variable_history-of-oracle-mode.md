# DBA_OB_SYS_VARIABLE_HISTORY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V5.0.1 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_SYS_VARIABLE_HISTORY` 用于展示当前租户的所有 Global 级别系统变量的修改历史。

## 字段说明

| 字段名称     | 类型                              | 是否可以为 NULL | 描述 |
|-------------|-----------------------------------|----------------|------|
| NAME        | VARCHAR2(128)                     | YES  | 变量名 |
| VALUE       | VARCHAR2(65536)                   | YES  | 变量值 |
| MODIFY_TIME | TIMESTAMP(6) WITH LOCAL TIME ZONE | NO   | 变量值修改的时间 |

## 查询示例

用户租户查询本租户的系统变量 `ob_query_timeout` Global 级别变量值的修改历史。

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_SYS_VARIABLE_HISTORY WHERE NAME = 'ob_query_timeout';
```

查询结果如下：

```shell
+------------------+-----------+------------------------------+
| NAME             | VALUE     | MODIFY_TIME                  |
+------------------+-----------+------------------------------+
| ob_query_timeout | 10000000  | 24-JUN-26 05.34.44.384848 PM |
| ob_query_timeout | 20000000  | 25-JUN-26 11.26.13.139296 AM |
+------------------+-----------+------------------------------+
2 rows in set
```
