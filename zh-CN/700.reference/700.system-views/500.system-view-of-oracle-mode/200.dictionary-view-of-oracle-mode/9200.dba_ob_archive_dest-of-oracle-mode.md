# DBA_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>说明</h4>
<p>从 V4.0.0 版本开始引入。</p>
</main>

## 功能描述

展示本租户的归档路径配置。

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| DEST_NO | NUMBER(38) | NO | 标识 log_archive_dest_n |
| NAME | VARCHAR2(1024) | NO | 字段名 |
| VALUE | VARCHAR2(4096) | NO | 字段值 |

## 查询示例

用户租户查询本租户的归档路径配置。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_ARCHIVE_DEST;
```

查询结果如下：

```shell
+---------+-----------------------+----------------------------------------+
| DEST_NO | NAME                  | VALUE                                  |
+---------+-----------------------+----------------------------------------+
|       0 | binding               | OPTIONAL                               |
|       0 | dest_id               | 1002                                   |
|       0 | path                  | file:///home/admin/oceanbase/arglogorc |
|       0 | piece_switch_interval | 1d                                     |
|       0 | state                 | ENABLE                                 |
+---------+-----------------------+----------------------------------------+
5 rows in set
```
