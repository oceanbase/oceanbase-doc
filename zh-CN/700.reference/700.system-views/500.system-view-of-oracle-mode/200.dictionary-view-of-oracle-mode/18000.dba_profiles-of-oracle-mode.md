# DBA_PROFILES

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V2.2.30 版本开始引入。</p>
</main>

## 功能描述

展示当前租户内的所有 Profile 文件及其参数信息。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该视图仅适用于 OceanBase 数据库 Oracle 模式。</p>
  </main>

## 字段说明

|   **字段名称**    |    **类型**    | **是否可以为 NULL** |              **描述**              |
|---------------|--------------|----------------|----------------------------------|
| PROFILE       | VARCHAR2(30) | NO             | Profile 文件名称                            |
| RESOURCE_NAME | VARCHAR2(32) | NO             | 参数名称，包括：<ul><li>`FAILED_LOGIN_ATTEMPTS`</li><li>`PASSWORD_GRACE_TIME`</li><li>`PASSWORD_LIFE_TIME`</li><li>`PASSWORD_LOCK_TIME`</li><li>`PASSWORD_VERIFY_FUNCTION`</li><li>`PASSWORD_ROLLOVER_TIME`</li><li>`IDLE_TIME`：会话最大空闲时间（单位：分钟）。对于 V4.4.x 版本，从 V4.4.2 BP4 版本开始支持</li></ul> |
| RESOURCE_TYPE | VARCHAR2(8)  | NO             | 参数类型：<ul><li>`KERNEL`</li> <li>`PASSWORD`</li></ul>  |
| LIMIT         | VARCHAR2(128) | NO             | 参数的限制值。`IDLE_TIME` 的取值可能是分钟数、`0`、`UNLIMITED` 或 `DEFAULT`，具体含义见下方注意。 |

## 查询示例

查看当前租户内的所有 Profile 文件及其参数信息。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_PROFILES;
```

查询结果如下：

```shell
+----------+--------------------------+---------------+-----------------+
| PROFILE  | RESOURCE_NAME            | RESOURCE_TYPE | LIMIT           |
+----------+--------------------------+---------------+-----------------+
| DEFAULT  | IDLE_TIME                | KERNEL        | 0               |
| DEFAULT  | FAILED_LOGIN_ATTEMPTS    | PASSWORD      | UNLIMITED       |
| DEFAULT  | PASSWORD_GRACE_TIME      | PASSWORD      | UNLIMITED       |
| DEFAULT  | PASSWORD_LIFE_TIME       | PASSWORD      | UNLIMITED       |
| DEFAULT  | PASSWORD_LOCK_TIME       | PASSWORD      | 86400000000     |
| DEFAULT  | PASSWORD_VERIFY_FUNCTION | PASSWORD      | NULL            |
| DEFAULT  | PASSWORD_ROLLOVER_TIME   | PASSWORD      | DEFAULT         |
| profile1 | IDLE_TIME                | KERNEL        | DEFAULT         |
| profile1 | FAILED_LOGIN_ATTEMPTS    | PASSWORD      | 5               |
| profile1 | PASSWORD_GRACE_TIME      | PASSWORD      | DEFAULT         |
| profile1 | PASSWORD_LIFE_TIME       | PASSWORD      | 5184000000000   |
| profile1 | PASSWORD_LOCK_TIME       | PASSWORD      | 86400000000     |
| profile1 | PASSWORD_VERIFY_FUNCTION | PASSWORD      | VERIFY_FUNCTION |
+----------+--------------------------+---------------+-----------------+
13 rows in set
```

<main id="notice" type='notice'>
<h4>注意</h4>
<p><code>IDLE_TIME</code> 的显示值含义如下：<code>0</code> 表示该参数不生效；正整数表示会话允许的最大空闲分钟数；<code>UNLIMITED</code> 表示不限制空闲时间；<code>DEFAULT</code> 表示继承 <code>DEFAULT</code> profile 的取值。新建 Profile 时如果没有指定 <code>IDLE_TIME</code>，该参数的取值为 <code>DEFAULT</code>，视图中也显示为 <code>DEFAULT</code>；由于 <code>DEFAULT</code> Profile 的 <code>IDLE_TIME</code> 为 <code>0</code>，此时该参数实际不生效。</p>
</main>
