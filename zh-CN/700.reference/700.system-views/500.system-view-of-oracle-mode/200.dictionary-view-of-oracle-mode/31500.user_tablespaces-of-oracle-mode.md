USER_TABLESPACES
=====================================

功能
-----------

查看当前用户可以访问的表空间。其列与 `DBA_TABLESPACES` 中的列相同，去除了 `PLUGGED_IN` 字段。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
  </main>
