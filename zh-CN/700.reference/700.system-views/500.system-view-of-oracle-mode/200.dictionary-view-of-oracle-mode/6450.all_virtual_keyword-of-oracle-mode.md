# ALL_VIRTUAL_KEYWORD

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V5.0.1 版本开始引入。</p>
</main>

## 功能描述

用于展示关键字信息。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该视图仅适用于 OceanBase 数据库 Oracle 模式。</p>
</main>

## 字段说明

|  **字段名称**  |    **类型**   | **是否可以为 NULL** | **描述** |
|----------------|---------------|--------------------|-----------|
| KEYWORD_NAME   | VARCHAR2(128) | NO                 | 表示关键字名称。|
| KEYWORD_LENGTH | NUMBER(38)    | NO                 | 表示关键字长度。|
| KEYWORD_TYPE   | VARCHAR2(16)  | NO                 | 表示关键字属于哪种语法，取值如下：<ul><li>`SQL`</li><li>`PL`</li></ul>|
| RESERVED       | NUMBER(38)    | NO                 | 表示是否为保留关键字，取值如下：<ul><li>1：表示保留关键字。</li><li>0：表示非保留关键字。</li></ul>|

## 查询示例

获取一条关键字的信息。

```shell
obclient> SELECT * FROM SYS.ALL_VIRTUAL_KEYWORD WHERE ROWNUM = 1\G
```

查询结果如下：

```shell
*************************** 1. row ***************************
  KEYWORD_NAME: access
KEYWORD_LENGTH: 6
  KEYWORD_TYPE: SQL
      RESERVED: 1
1 row in set
```
