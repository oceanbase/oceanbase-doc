# DBA_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_BACKUP_VALIDATE_JOBS` 用于展示本租户发起的 Job 级备份校验任务的相关信息。每个 Job 对应一个备份校验指令。

## 字段说明

| 字段名称             | 类型           | 是否可以为 NULL | 描述           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | NUMBER(38)     | NO   | 任务 ID     |
| INCARNATION         | NUMBER(38)     | NO   | 分身 ID     |
| INITIATOR_TENANT_ID | NUMBER(38)     | NO   | 发起此次 Job 的租户 ID   |
| INITIATOR_JOB_ID    | NUMBER(38)     | NO   | 发起此次 Job 的 job_id。如果值为 0，表示发起此次 Job 的是当前 Job     |
| EXECUTOR_TENANT_ID  | VARCHAR2(65536)| NO   | 此次 Job 对应的需要执行校验任务的用户租户的 tenant_id。如果值为 0，表示执行校验任务的是当前租户     |
| TYPE                | VARCHAR2(64)   | NO   | 校验任务类型：<ul><li>`DATABASE`：校验整个备份路径和归档路径下的所有备份集和日志归档 Piece</li> <li>`BACKUPSET`：校验指定的备份集</li> <li>`ARCHIVELOG_PIECE`：校验指定的日志归档 Piece</li></ul>     |
| PATH                | CLOB           | YES  | 用户指定校验的备份路径或日志归档路径，如果值为空，则表示该任务为非指定路径的校验     |
| PATH_TYPE           | VARCHAR2(64)   | YES  | 用户指定路径下校验的类型（如果值为空，则表示该任务为非指定路径的校验）：<ul><li>`BACKUPSET`：校验指定路径下的备份集</li> <li>`ARCHIVELOG_PIECE`：校验指定路径下的日志归档 Piece</li></ul>     |
| ID                  | CLOB           | YES  | <p>校验的备份集的 `backup_set_id` 或归档 Piece 的 `piece_id`</p><p>默认为空，表示当前备份路径和归档路径下的所有备份集和日志归档 Piece，当用户指定校验备份集的 `backup_set_id` 或归档 Piece 的 `piece_id` 时，值会变更为对应的 ID 或 ID 列表</p>     |
| VALIDATE_LEVEL      | VARCHAR2(64)   | NO   | 校验等级：<ul><li>`basic`：仅检查文件列表的完整性。</li> <li>`physical`：检查物理数据的正确性及逻辑一致性。</li></ul>    |
| START_TIMESTAMP     | VARCHAR2(256)  | NO   | 校验任务的开始时间     |
| END_TIMESTAMP       | VARCHAR2(256)  | NO   | 校验任务的结束时间     |
| STATUS              | VARCHAR2(64)   | NO   | Job 状态：<ul><li>`INIT`：校验任务正在初始化</li> <li>`DOING`：校验任务正在执行中</li> <li>`COMPLETED`：校验任务已执行完成</li> <li>`FAILED`：校验任务执行失败</li> <li>`CANCELED`：校验任务已取消</li></ul>   |
| RETRY_COUNT         | NUMBER(38)     | YES  | 重试次数     |
| TASK_COUNT          | NUMBER(38)     | YES  | 备份集或日志归档 Piece 的总校验任务数     |
| SUCCESS_TASK_COUNT  | NUMBER(38)     | YES  | 备份集或日志归档 Piece 校验成功的任务数     |
| RESULT              | NUMBER(38)     | NO   | 校验结果的错误码信息    |
| DESCRIPTION         | VARCHAR2(4096) | YES  | OCP 提供的外部信息    |
| COMMENT             | VARCHAR2(4096) | YES  | 校验任务失败的原因描述      |

## 查询示例

用户租户查看本租户发起的 Job 级备份校验任务的相关信息。

```shell
obclient(sys@oracle001)[SYS]> SELECT * FROM SYS.DBA_OB_BACKUP_VALIDATE_JOBS\G
```

