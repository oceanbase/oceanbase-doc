# DBA_WR_SQL_PLAN

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V4.2.5 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_WR_SQL_PLAN` 用于展示 WR 采集的 [GV$OB_SQL_PLAN](../300.performance-view-of-oracle-mode/3100.gv-ob_sql_plan-of-oracle-mode.md) 数据。

## 字段说明

| **字段** | **类型** | **是否为 NULL** | **描述** |
| -------- | -------- | -------------- | -------- |
| TENANT_ID          | NUMBER(38)          | NO   | 租户 ID     |
| CLUSTER_ID         | NUMBER(38)          | NO   | 集群 ID     |
| SNAP_ID            | NUMBER(38)          | NO   | 快照 ID     |
| SVR_IP             | VARCHAR2(46)        | NO   | 节点 IP     |
| SVR_PORT           | NUMBER(38)          | NO   | 节点 PORT     |
| SQL_ID             | VARCHAR2(32)        | NO   | SQL 语句 ID     |
| PLAN_HASH          | NUMBER(38)          | NO   | 执行计划 HASH 值     |
| PLAN_ID            | NUMBER(38)          | NO   | 执行计划 ID     |
| ID                 | NUMBER(38)          | NO   | 算子 ID    |
| DB_ID              | NUMBER(38)          | NO   | 数据库 ID     |
| GMT_CREATE         | TIMESTAMP(6) WITH LOCAL TIME ZONE        | NO   | 记录生成时间     |
| OPERATOR           | VARCHAR2(255)        | NO   | 算子名称     |
| OPTIONS            | VARCHAR2(255)        | NO   | 选项     |
| OBJECT_NODE        | VARCHAR2(40)         | NO   | 如果当前算子是 DBLINK 相关，则表示 DBlink 的名称     |
| OBJECT_ID          | NUMBER(38)           | NO   | 算子操作的表或索引对象号     |
| OBJECT_OWNER       | VARCHAR2(128)        | NO   | 对象属主     |
| OBJECT_NAME        | VARCHAR2(128)        | NO   | 对象名称     |
| OBJECT_ALIAS       | VARCHAR2(261)        | NO   | 语句中对象的别名     |
| OBJECT_TYPE        | VARCHAR2(20)         | NO   | 对象类型     |
| OPTIMIZER          | VARCHAR2(4000)       | NO   | 索引相关信息（例如：物理行、逻辑行、回表行数、使用的统计信息类型，统计信息版本号）     |
| PARENT_ID          | NUMBER(38)           | NO   | 父算子的 ID     |
| DEPTH              | NUMBER(38)           | NO   | 算子层次深度。根算子的深度为 0     |
| POSITION           | NUMBER(38)           | NO   | 在所有具有相同父算子的算子中的顺序位置     |
| IS_LAST_CHILD      | NUMBER(38)           | NO   | 当前逻辑算子是父算子的最后一个孩子节点     |
| COST               | NUMBER(38)           | NO   | 优化器估计的代价     |
| REAL_COST          | NUMBER(38)           | NO   | 首次执行时实际的代价     |
| CARDINALITY        | NUMBER(38)           | NO   | 优化器估计的输出行数     |
| REAL_CARDINALITY   | NUMBER(38)           | NO   | 首次执行时实际的输出行数    |
| BYTES              | NUMBER(38)           | NO   | 优化器估算当前算子数据数据的宽度     |
| ROWSET             | NUMBER(38)           | NO   | 当前算子的向量化大小     |
| OTHER_TAG          | VARCHAR2(4000)       | NO   | 当前查询使用过的 Hint，只在计划的第一行记录存放     |
| PARTITION_START    | VARCHAR2(4000)       | NO   | 扫描的分区信息     |
| OTHER              | VARCHAR2(4000)       | NO   | 优化信息，例如：计划类型、Fast Parser 的参数化信息、Plan Note、计划命中的约束信息    |
| CPU_COST           | NUMBER(38)           | NO   | 计划第一次执行时当前算子的实际 CPU 开销（执行反馈信息）     |
| IO_COST            | NUMBER(38)           | NO   | 计划第一次执行时当前算子的实际 IO 开销（执行反馈信息）     |
| ACCESS_PREDICATES  | VARCHAR2(4000)       | NO   | 当前算子需要访问的表达式信息     |
| FILTER_PREDICATES  | VARCHAR2(4000)       | NO   | 当前算子的过滤条件     |
| FILTER_PREDICATES  | VARCHAR2(4000)       | NO   | 当前算子的过滤条件     |
| PROJECTION         | VARCHAR2(4000)       | NO   | 当前算子的输出表达式信息     |
| SPECIAL_PREDICATES | VARCHAR2(4000)       | NO   | 当前算子的特有表达式信息，例如：Join Condition、GROUP EXPRS、SORT EXPRS 等等     |
| QBLOCK_NAME        | VARCHAR2(128)        | NO   | 当前算子所处查询块的名称     |
| REMARKS            | VARCHAR2(4000)       | NO   | qb_name 的修改追踪信息     |
| OTHER_XML          | VARCHAR2(4000)       | NO   | OUTLINE DATA     |
