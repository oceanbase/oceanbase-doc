# DBA_OB_SENSITIVE_COLUMNS

## 功能描述

展示当前租户下的所有受敏感规则保护的列。

## 字段说明

|        字段名称         |      类型       | 是否可以为 NULL |                      描述                                |
|---------------------|---------------|------------|-----------------------------------------------------------------|
| RULE_NAME         | varchar(256)    | NO         | 敏感规则名称                                           |
| USER_NAME      | varchar(128)    | NO         | 用户名称                                        |
| TABLE_NAME         | varchar(128)    | NO         | 表名称                                      |
| COLUMN_NAME        | varchar(128)    | NO         | 列名称                                                     |

## 查询示例

查看当前租户下的所有受敏感规则保护的列。

```shell
obclient [SYS]> SELECT * FROM SYS.DBA_OB_SENSITIVE_COLUMNS;
```

查询结果如下：

```shell
+-----------+-----------+------------+-------------+
| RULE_NAME | USER_NAME | TABLE_NAME | COLUMN_NAME |
+-----------+-----------+------------+-------------+
| r1        | u1        | t2         | c           |
| r1        | u1        | t1         | a           |
+-----------+-----------+------------+-------------+
2 row in set
```
