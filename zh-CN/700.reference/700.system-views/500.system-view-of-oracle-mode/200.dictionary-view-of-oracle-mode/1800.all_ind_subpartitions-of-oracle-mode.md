# ALL_IND_SUBPARTITIONS 


## 功能描述


查看数据库中用户可以访问的所有索引子分区的信息。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版仅提供 MySQL 模式。</p>
  </main>
