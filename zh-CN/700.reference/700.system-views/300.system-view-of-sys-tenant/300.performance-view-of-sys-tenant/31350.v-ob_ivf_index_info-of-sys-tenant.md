# V$OB_IVF_INDEX_INFO

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

该视图展示了所有租户在当前 OBServer 节点上 IVF 向量索引的基本信息和实时状态。

## 字段说明

|             字段名称          |      数据类型    | 是否可以为 NULL |            描述                                            |  信息类型 |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | 副本所在的节点地址                                              | 基本信息 |
| SVR_PORT                     | bigint(20)   | NO             | 副本所在的节点 RPC_PORT                                              | 基本信息 |
| TENANT_ID                    | bigint(20)   | NO             | 租户 ID：<ul><li>1：系统租户 ID</li> <li>其他值：用户租户或者 Meta 租户 ID</li></ul>                                                    | 基本信息 |
| DATA_TABLE_ID                | bigint(20)   | NO             | 数据表 ID                                                    | 基本信息 |
| TABLE_NAME                   | varchar(256) | NO             | 表名                                                    | 基本信息 |
| INDEX_NAME                   | varchar(256) | NO             | 索引名称                                                    | 索引信息 |
| INDEX_TABLE_ID               | bigint(20)   | NO             | 索引表 ID                                                    | 索引信息 |
| INDEX_TABLET_ID              | bigint(20)   | NO             | 索引表分区 ID                                                    | 索引信息 |
| INDEX_PARAM                  | varchar(1024)     | NO             | 索引参数                                                    | 索引信息 |
| CACHE_TYPE                   | varchar(29)   | NO             | IVF 索引缓存类型：<ul><li>IVF_CENTROID_CACHE：IVF 索引的中心点缓存</li> <li>IVF_PQ_CENTROID_CACHE：IVF_PQ 索引的中心点缓存</li> <li>IVF_PQ_PRECOMPUTE_TABLE_CACHE：IVF_PQ 索引的预计算表缓存</li></ul>                                                    | 缓存信息 |
| IS_INIT                      | varchar(5)   | NO             | 是否初始化：<ul><li>TRUE：已初始化</li> <li>FALSE：未初始化</li></ul>                                                    | 缓存信息 |
| MEMORY_USED                  | bigint(20)   | NO             | 内存使用                                                    | 索引信息 |
| MEMORY_HOLD                  | bigint(20)   | NO             | 占用内存                                                    | 索引信息 |
| CACHE_INFO                   | varchar(512)     | NO             | Json 格式的缓存属性信息                                                    | 缓存信息 |
