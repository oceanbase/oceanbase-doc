# GV$SQL

<main id="notice" type='explain'>
 <h4>说明</h4>
  <ul>
   <li>由于 V4.x 版本对系统架构进行了优化调整，该视图已不再适用于 V4.x 版本，从 V4.0.0 版本开始删除。</li>
   <li>在 V4.x 版本中，可以通过视图 <a href="2200.gv-sql_audit-of-sys-tenant.md">GV$OB_SQL_AUDIT</a> 和 <a href="6900.v-sql_audit-of-sys-tenant.md">V$OB_SQL_AUDIT</a> 查询 OBServer 节点上每一次 SQL 请求的来源、执行状态等统计信息。</li>
 </ul>
</main>

## 功能描述

视图 `GV$SQL` 展示所有热更新的 SQL 相关统计信息，记录每个 Plan 上的统计信息，汇总单个 Plan 多次执行的统计信息；每个 Plan 都会在表中有一行。
