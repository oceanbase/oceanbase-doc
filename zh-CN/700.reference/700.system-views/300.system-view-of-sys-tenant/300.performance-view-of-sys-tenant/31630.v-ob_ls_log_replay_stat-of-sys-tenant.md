# V$OB_LS_LOG_REPLAY_STAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该视图从 V4.4.2 BP2 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_LS_LOG_REPLAY_STAT` 用于展示租户当前节点上每个 LS（日志流）副本的日志回放进度。查询时，需要在备库（或在主库上查询 Follower 副本）上查询。

由于主租户（主库）的 Leader 副本上不会回放日志，故查询结果中，当主租户上的 `ROLE = LEADER` 时，该行记录无意义。

## 字段说明

|      字段名称       |      类型           | 是否可以为 NULL |    描述     |
|--------------------|---------------------|----------------|-------------|
| TENANT_ID          | bigint(20)          | NO   | 租户 ID     |
| SVR_IP             | varchar(46)         | NO   | 日志流 ID     |
| SVR_PORT           | bigint(20)          | NO   | 服务器 IP 地址     |
| LS_ID              | bigint(20)          | NO   | 服务器端口号     |
| ROLE               | varchar(32)         | NO   | 日志流副本角色：<ul><li>`LEADER`：主副本</li> <li>`FOLLOWER`：从副本</li></ul>      |
| ENABLED            | tinyint(4)          | NO   | 日志回放服务（Replay Service）是否启用    |
| END_LSN            | bigint(20) unsigned | NO   | Palf 已写入的 LSN（日志回放的右边界）      |
| UNSUBMITTED_LSN    | bigint(20) unsigned | NO   | 下一个待提交到回放队列的日志的 LSN     |
| UNSUBMITTED_SCN    | bigint(20) unsigned | NO   | 下一个待提交到回放队列的日志的 SCN     |
| MIN_UNREPLAYED_LSN | bigint(20) unsigned | NO   | 回放队列中最小未回放的日志的 LSN     |
| MIN_UNREPLAYED_SCN | bigint(20) unsigned | NO   | 回放队列中最小未回放的日志的 SCN     |
| PENDING_CNT        | bigint(20)          | NO   | 内存中待回放的任务数     |

## 查询示例

备租户所在集群的 `sys` 租户下，查看租户 ID 为 1002 的备租户当前节点上每个日志流副本的日志回放进度。

```shell
obclient(root@sys)[oceanbase]> SELECT TENANT_ID, LS_ID, ROLE, ENABLED,
        END_LSN, UNSUBMITTED_LSN, MIN_UNREPLAYED_LSN, PENDING_CNT
        FROM oceanbase.V$OB_LS_LOG_REPLAY_STAT WHERE TENANT_ID = 1002;
```

查询结果如下：

```shell
+-----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
| TENANT_ID | LS_ID | ROLE     | ENABLED | END_LSN   | UNSUBMITTED_LSN | MIN_UNREPLAYED_LSN | PENDING_CNT |
+-----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
|      1002 |     1 | FOLLOWER |       1 | 300636581 |       300060582 |          300060582 |           0 |
|      1002 |  1001 | FOLLOWER |       1 | 197547054 |       197052262 |          197052262 |           0 |
+-----------+-------+----------+---------+-----------+-----------------+--------------------+-------------+
2 rows in set
```
