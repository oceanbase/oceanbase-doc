# V$OB_JVM_STATUS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该视图从 V4.4.2 BP4 版本开始引入。</p>
</main>

## 功能描述

该视图展示当前 OBServer 节点上 OBServer 进程内 JVM 的运行状态和资源使用情况，包括 JVM 状态、堆内存、元空间、GC、线程数和文件描述符数等信息。每个 OBServer 节点对应一行记录。

使用说明如下：

* 只有开启配置项 `ob_enable_java_env` 后，OBServer 进程才会启动 JVM。未开启时，`STATUS` 为 `DISABLED`。
* JVM 启动后，系统默认每 60 秒采集一次 JVM 状态。查询该视图返回的是最近一次采集的结果，不会触发 JVM 启动或采集。
* 尚未成功采集或无法获取的指标显示为 NULL，以区别于实际值为 `0` 的指标。
* Java UDF 在沙箱进程中执行时，沙箱 JVM 的状态请参见 [V$OB_JAVA_SANDBOX_STATUS](31360.v-ob_java_sandbox_status-of-sys-tenant.md)。

## 字段说明

|     字段名称    |     类型    | 是否可以为 NULL |      描述      |
|----------------|-------------|----------------|----------------|
| SVR_IP | varchar(46) | NO | OBServer 节点的 IP 地址。 |
| SVR_PORT | bigint(20) | NO | OBServer 节点的端口号。 |
| PROCESS_PID | bigint(20) | YES | OBServer 进程的进程 ID。 |
| STATUS | varchar(32) | NO | OBServer 进程内 JVM 的状态：<ul><li>`DISABLED`：未开启 Java 环境（配置项 `ob_enable_java_env` 为 `False`）</li><li>`NOT_STARTED`：JVM 尚未启动</li><li>`STARTING`：JVM 正在启动，或已启动但尚未完成首次采集</li><li>`UP`：JVM 运行中，且最近一次采集成功</li><li>`INIT_FAILED`：JVM 初始化失败</li><li>`COLLECT_ERROR`：JVM 状态采集失败</li><li>`DOWN`：OBServer 进程正在退出，或 JVM 监控已停止</li></ul> |
| INIT_ATTEMPT_COUNT | bigint(20) | YES | JVM 初始化的累计尝试次数。 |
| INIT_FAILURE_COUNT | bigint(20) | YES | JVM 初始化的累计失败次数。 |
| LAST_INIT_ERROR_CODE | bigint(20) | YES | 最近一次 JVM 初始化失败的错误码。未发生过初始化失败时为 NULL。 |
| LAST_INIT_ERROR_TIME | timestamp(6) | YES | 最近一次 JVM 初始化失败的时间。未发生过初始化失败时为 NULL。 |
| JVM_START_TIME | timestamp(6) | YES | JVM 的启动时间。 |
| JVM_UPTIME_MS | bigint(20) | YES | JVM 已运行的时长，单位为毫秒。 |
| MONITOR_BRIDGE_VERSION | bigint(20) | YES | JVM 监控接口的版本号。 |
| HEAP_USED_BYTES | bigint(20) | YES | JVM 堆内存已使用的大小，单位为字节。 |
| HEAP_COMMITTED_BYTES | bigint(20) | YES | JVM 堆内存已提交（Committed）的大小，单位为字节。 |
| HEAP_MAX_BYTES | bigint(20) | YES | JVM 堆内存的最大可用大小，单位为字节。 |
| YOUNG_USED_BYTES | bigint(20) | YES | JVM 年轻代已使用的大小，单位为字节。 |
| OLD_USED_BYTES | bigint(20) | YES | JVM 老年代已使用的大小，单位为字节。 |
| METASPACE_USED_BYTES | bigint(20) | YES | JVM 元空间（Metaspace）已使用的大小，单位为字节。 |
| METASPACE_COMMITTED_BYTES | bigint(20) | YES | JVM 元空间已提交的大小，单位为字节。 |
| METASPACE_MAX_BYTES | bigint(20) | YES | JVM 元空间的最大可用大小，单位为字节。 |
| CODE_CACHE_USED_BYTES | bigint(20) | YES | JVM 代码缓存（Code Cache）已使用的大小，单位为字节。 |
| DIRECT_BUFFER_USED_BYTES | bigint(20) | YES | JVM 直接缓冲区（Direct Buffer）已使用的内存大小，单位为字节。 |
| DIRECT_BUFFER_COUNT | bigint(20) | YES | JVM 直接缓冲区的数量。 |
| GC_COUNT | bigint(20) | YES | JVM 累计 GC 次数。 |
| GC_TIME_MS | bigint(20) | YES | JVM 累计 GC 耗时，单位为毫秒。 |
| YOUNG_GC_COUNT | bigint(20) | YES | JVM 累计年轻代 GC 次数。 |
| YOUNG_GC_TIME_MS | bigint(20) | YES | JVM 累计年轻代 GC 耗时，单位为毫秒。 |
| MAJOR_GC_COUNT | bigint(20) | YES | JVM 累计 Major GC（老年代 GC）次数。 |
| MAJOR_GC_TIME_MS | bigint(20) | YES | JVM 累计 Major GC 耗时，单位为毫秒。 |
| THREAD_COUNT | bigint(20) | YES | JVM 当前的线程数。 |
| PEAK_THREAD_COUNT | bigint(20) | YES | JVM 的峰值线程数。 |
| OPEN_FD_COUNT | bigint(20) | YES | OBServer 进程当前打开的文件描述符数量。 |
| MAX_FD_COUNT | bigint(20) | YES | OBServer 进程可打开的文件描述符数量上限。 |
| COLLECT_ERROR_CODE | bigint(20) | YES | 最近一次采集的错误码。`0` 表示采集成功。 |
| COLLECT_COST_US | bigint(20) | YES | 最近一次采集的耗时，单位为微秒。 |
| LAST_COLLECT_ATTEMPT_TIME | timestamp(6) | YES | 最近一次尝试采集的时间。 |
| SNAPSHOT_TIME | timestamp(6) | YES | 最近一次采集成功的时间。 |
| SNAPSHOT_AGE_US | bigint(20) | YES | 距离最近一次采集成功经过的时间，单位为微秒。 |

## 查询示例

查询当前 OBServer 节点上 OBServer 进程内 JVM 的状态、堆内存、GC 次数和线程数。

```shell
obclient> SELECT SVR_IP, SVR_PORT, STATUS, HEAP_USED_BYTES, HEAP_MAX_BYTES, GC_COUNT, THREAD_COUNT, SNAPSHOT_TIME FROM oceanbase.V$OB_JVM_STATUS;
```
