# V$OB_SERVER_STORAGE

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.3.4 版本开始引入。</p>
</main>

## 功能描述

展示当前 OBServer 节点上对象存储的相关信息。

## 字段说明

| 字段名称              | 类型          | 是否可以为 NULL | 描述                          |
|----------------------|---------------|----------------|-------------------------------|
| SVR_IP               | varchar(46)   | NO   | OBServer 节点的 IP 地址    |
| SVR_PORT             | bigint(20)    | NO   | OBServer 节点的端口号     |
| PATH                 | varchar(1024) | NO   | 对象存储的路径。SN（Shared-Nothing） 模式下，展示为本地路径。</br>该路径通常以对象存储的类型开头，例如：`local://`、`oss://`、`file://`、`s3://` 等。     |
| ENDPOINT             | varchar(1024) | NO   | 共享存储的 Endpoint。SN（Shared-Nothing） 模式下，该字段值为空。     |
| USED_FOR             | varchar(256)  | NO   | 对象存储的使用者：<ul><li>`DATA`：数据存储，包含 SSTable、临时文件等</li> <li>`LOG`：日志存储，包括 clog、slog</li></ul>      |
| ZONE                 | varchar(128)  | NO   | Zone 名称    |
| STORAGE_ID           | bigint(20)    | NO   | 对象存储路径的编号，相同路径有相同的 STORAGE_ID     |
| MAX_IOPS             | bigint(20)    | NO   | 对象存储的最大 IOPS      |
| MAX_BANDWIDTH        | bigint(20)    | NO   | 对象存储的最大带宽，单位为字节     |
| CREATE_TIME          | timestamp(6)  | NO   | 对象存储的创建时间     |
| AUTHORIZATION        | varchar(1024) | NO   | 对象存储的授权信息     |
| STATE                | varchar(256)  | NO   | 对象存储的状态：<ul><li>`ADDING`：正在添加状态 </li> <li>`ADDED`：已添加成功</li> <li>`DROPPING`：正在删除状态</li> <li>`ROTATING`：正在轮转 AK/SK</li> <li>`ROTATED`：AK/SK 轮转已完成</li></ul>      |
| STATE_INFO           | varchar(1024) | NO   | 对象存储的状态信息     |
| LAST_CHECK_TIMESTAMP | timestamp(6)  | NO   | 最后一次检查时间     |
| EXTENSION            | varchar(4096) | NO   | 对象存储的其它信息     |
