# GV$OB_PLUGINS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.3.5 BP1 版本开始引入。</p>
</main>

## 功能描述

展示插件列表以及各插件的详细信息。

## 字段说明

|     字段名称     |     类型      | 是否可以为 NULL |                描述                 |
|-------------------|----------------|------|------|
| SVR_IP            | varchar(46)    | NO   | 副本所在的节点地址 |
| SVR_PORT          | bigint(20)     | NO   | 副本端口号 |
| NAME              | varchar(64)    | YES  | 插件名称 |
| STATUS            | varchar(64)    | YES  | 插件状态：<ul><li>READY：有效的</li><li>UNINIT：未初始化</li><li>DEAD：已失效</li></ul> |
| TYPE              | varchar(80)    | YES  | 插件类型：FTPARSER(分词插件) |
| LIBRARY           | varchar(128)   | YES  | 插件动态链接库名称（内置插件没有对应链接库） |
| LIBRARY_VERSION   | varchar(80)    | YES  | 该插件依赖的插件基础库版本 |
| LIBRARY_REVISION  | varchar(80)    | YES  | 插件库修订版本 |
| INTERFACE_VERSION | varchar(80)    | YES  | 该插件实现的具体接口 API 版本 |
| AUTHOR            | varchar(64)    | YES  | 插件作者信息 |
| LICENSE           | varchar(64)    | YES  | 插件 LICENSE |
| DESCRIPTION       | varchar(65535) | YES  | 插件描述信息 |

## 查询示例

系统租户下，查看所有插件列表以及各插件的详细信息。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_PLUGINS;
```
