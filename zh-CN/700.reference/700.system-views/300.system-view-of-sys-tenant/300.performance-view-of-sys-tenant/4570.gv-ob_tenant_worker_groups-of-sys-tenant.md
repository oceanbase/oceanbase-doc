# GV$OB_TENANT_WORKER_GROUPS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V5.0.1 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_TENANT_WORKER_GROUPS` 用于展示所有租户的所有节点上工作线程组的状态。

## 字段说明

| 字段名称           |  类型       | 是否可以为 NULL |     描述     |
|-------------------|-------------|-----------------|-------------|
| SVR_IP            | varchar(46) | NO   | 服务器 IP 地址     |
| SVR_PORT          | bigint(20)  | NO   | 服务器端口号    |
| TENANT_ID         | bigint(20)  | NO   | 租户 ID     |
| GROUP_ID          | bigint(20)  | NO   | 资源组 ID     |
| WORKERS_SIZE      | bigint(20)  | NO   | 当前工作线程数     |
| REQ_QUEUE_SIZE    | bigint(20)  | NO   | 普通请求队列的长度     |
| RECV_REQ_CNT      | bigint(20)  | NO   | 累计接收的请求数量     |
| DELETED           | tinyint(4)  | NO   | 资源组是否已标记删除：<ul><li>`0`：未删除</li> <li> `1`：已删除</li></ul>     |
| TOKEN_CHANGE_TS   | bigint(20)  | NO   | Token（工作线程资源令牌）变更的时间戳     |
| THROTTLED_TIME_US | bigint(20)  | NO   | 限流累计时间，单位为微秒     |
| IDLE_CNT          | bigint(20)  | NO   | 空闲的工作线程数     |
| LAST_NOT_EMPTY_TS | bigint(20)  | NO   | 队列最后一次非空的时间戳     |

## 查询示例

系统租户下，查询租户 ID 为 1002 的租户在每个节点上工作线程组的状态。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_WORKER_GROUPS WHERE TENANT_ID = 1002;
```
