# GV$OB_TENANT_WORKER_GROUPS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.1 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_TENANT_WORKER_GROUPS` 用于展示所有租户的所有节点上工作线程组的状态。

## 字段说明

| 字段名称  |  类型  | 是否可以为 NULL |     描述     |
|----------|--------|-----------------|-------------|

## 查询示例

系统租户下，查询租户 ID 为 1002 的租户在每个节点上工作线程组的状态。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_WORKER_GROUPS WHERE TENANT_ID = 1002;
```
