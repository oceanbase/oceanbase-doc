# GV$OB_HNSW_INDEX_SEGMENT_INFO

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

该视图展示了所有租户在所有 OBServer 节点上 HNSW 系列索引表的单分区中每个数据段（Segment）的基本信息和实时状态。`SEGMENT_TYPE`、`SEGMENT_STATE` 等字段与基线段、增量段（活跃/冻结/已持久化）及转储、合并流程的对应关系，请参见 [向量索引原理](../../../../100.oceanbase-database-concepts/400.database-objects/200.database-objects-of-mysql-mode/300.index-of-mysql-mode/330.vector-indexes-of-mysql-mode-in-concepts.md)。

## 字段说明

|             字段名称          |      数据类型    | 是否可以为 NULL |            描述                                            |  信息类型 |
|------------------------------|--------------|----------------|------------------------------------------------------------|------------|
| SVR_IP                       | varchar(46)  | NO             | 副本所在的节点地址                                              | 基本信息 |
| SVR_PORT                     | bigint(20)   | NO             | 副本所在的节点 RPC_PORT                                              | 基本信息 |
| TENANT_ID                    | bigint(20)   | NO             | 租户 ID<ul><li>1：系统租户 ID</li> <li>其他值：用户租户或者 Meta 租户 ID</li></ul>                                                    | 基本信息 |
| DATA_TABLE_ID                | bigint(20)   | NO             | 数据表 ID                                                    | 基本信息 |
| DATA_TABLET_ID               | bigint(20)   | NO             | 分区 ID                                                    | 基本信息 |
| VBITMAP_TABLET_ID             | bigint(20)   | NO             | 存储辅助表（index_id）对应分区的 ID。         | 基本信息 |
| INC_INDEX_TABLET_ID           | bigint(20)   | NO             | 存储增量数据的 delta_buffer 表分区 ID。        | 基本信息 |
| SNAPSHOT_INDEX_TABLET_ID      | bigint(20)   | NO             | 存储数据快照的 index_snapshot_data 表分区 ID。 | 基本信息 |
| BLOCK_COUNT                   | bigint(20)   | NO             | 快照 Segment 在 index_snapshot_data 表里包含的数据块数量。 | 基本信息 |
| SEGMENT_TYPE                  | varchar(20)  | NO             | Segment 类型：<ul><li>INVALID：默认值或未初始化</li> <li>IN_MEMORY：未持久化的 Segment，即仅在内存中未落盘</li> <li>PERSISTED_INCR：已持久化的 Segment，即已落盘</li> <li>MERGED_INCR：经过合并的 Incremental Segment</li> <li>PERSISTED_BASE：已持久化的 Baseline Segment</li></ul> | 基本信息 |
| INDEX_TYPE                    | varchar(20)  | NO             | 向量索引类型：<ul><li>HNSW</li> <li>HNSW_SQ</li> <li>HNSW_BQ</li> <li>HGRAPH</li></ul> | 基本信息 |
| MEM_USED                      | bigint(20)   | NO             | 当前 Segment 占用的内存大小（字节）。           | 基本信息 |
| MIN_VID                       | bigint(20)   | NO             | Segment 中包含的最小向量 ID（vid）。           | 基本信息 |
| MAX_VID                       | bigint(20)   | NO             | Segment 中包含的最大向量 ID（vid）。           | 基本信息 |
| VECTOR_CNT                    | bigint(20)   | NO             | Segment 里的向量（数据）数量。                 | 基本信息 |
| REF_CNT                       | bigint(20)   | NO             | Segment 引用计数。通常代表被索引或被查询引用的次数。 | 基本信息 |
| SEGMENT_STATE                 | varchar(20)  | NO             | 当前 Segment 的状态：<ul><li>DEFAULT：未初始化或默认状态</li> <li>ACTIVE：正在写入的活跃段</li> <li>FROZEN：写入已停止、进入冻结状态</li> <li>FLUSHING：正在持久化到磁盘</li> <li>PERSISTED：持久化完成，可供查询</li></ul> | 基本信息 |
| PERSISTENCE_TIMESTAMP         | timestamp    | NO             | Segment 持久化完成的时间戳（由 Segment 的 SCN 转换得到）。 | 基本信息 |

## 查询示例

SYS 租户查询所有租户在所有 OBServer 节点上 HNSW 向量索引的实时状态。

```sql
SELECT * FROM oceanbase.GV$OB_HNSW_INDEX_SEGMENT_INFO ORDER BY PERSISTENCE_TIME DESC\G;
```
