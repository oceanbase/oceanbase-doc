# V$OB_SS_OBJECT_TYPE_IO_STAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

视图 `V$OB_SS_OBJECT_TYPE_IO_STAT` 用于展示租户在当前节点上不同类型对象的读、写和删除操作的统计信息。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图仅适用于共享存储（Shared-Storage，SS）模式。无共享（Shared-Nothing，SN）模式下，该视图的查询结果为空。</p>
</main>

## 查询示例

系统租户查看租户 ID 为 1002 的租户在当前节点上不同种类的对象的读、写及删除的使用量。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.V$OB_SS_OBJECT_TYPE_IO_STAT WHERE tenant_id = 1002 LIMIT 10;
```
