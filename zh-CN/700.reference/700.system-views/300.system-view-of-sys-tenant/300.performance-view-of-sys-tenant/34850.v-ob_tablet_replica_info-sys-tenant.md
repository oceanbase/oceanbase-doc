# V$OB_TABLET_REPLICA_INFO

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `V$OB_TABLET_REPLICA_INFO` 用于展示当前节点上所有租户的所有 Tablet 副本的基本信息，包括所属租户、日志流、表、库以及磁盘占用等信息。

## 字段说明

|      字段名称         |         类型  | 是否可以为 NULL |                       描述      |
|----------------------|---------------|----------------|---------------------------------|
| SVR_IP               | varchar(46)   | NO             | 节点 IP 地址                    |
| SVR_PORT             | bigint(20)    | NO             | 节点端口号                      |
| TENANT_ID            | bigint(20)    | NO             | 租户 ID                        |
| LS_ID                | bigint(20)    | NO             | 日志流 ID     |
| TABLET_ID            | bigint(20)    | NO             | Tablet 副本的 ID     |
| ROLE                 | varchar(8)    | NO             | 日志流的角色：<ul><li>`LEADER`：主副本</li> <li>`FOLLOWER`：从副本</li></ul>     |
| ZONE                 | varchar(128)  | NO             | Tablet 副本所在的 Zone     |
| TABLE_ID             | bigint(20)    | NO             | Tablet 副本所属表的 ID     |
| TABLE_NAME           | varchar(256)  | NO             | Tablet 副本所属的表名     |
| DATABASE_ID          | bigint(20)    | NO             | 表所属的数据库 ID     |
| DATABASE_NAME        | varchar(128)  | NO             | 表所属的数据库名     |
| TABLE_TYPE           | varchar(21)   | NO             | 表类型：<ul><li>`SYSTEM_TABLE`：系统表</li> <li>`USER_TABLE`：用户表</li> <li>`INDEX`：索引表</li> <li>`LOB AUX TABLE`：LOB 辅助表，系统自建的表，用于辅助实现 LOB 列</li> <li>`MATERIALIZED VIEW LOG`：物化视图日志</li></ul>     |
| TABLEGROUP_ID        | bigint(20)    | NO             | 表所属的表组 ID    |
| TABLEGROUP_NAME      | varchar(128)  | NO             | 表所属的表组名     |
| DATA_TABLE_ID        | bigint(20)    | NO             | 表的 data_table_id     |
| OCCUPY_SIZE          | bigint(20)    | NO             | Tablet 副本数据占用空间的实际大小，单位为字节     |
| REQUIRED_SIZE        | bigint(20)    | NO             | Tablet 副本数据需要的空间大小，单位为字节     |
| OBJECT_ID            | bigint(20)    | NO             | 分区或子分区对象的 ID。如果是非分区表，则显示为表的 table_id     |
| PARTITION_NAME       | varchar(64)   | NO             | 一级分区名，如果是非分区表，则显示为空。     |
| SUBPARTITION_NAME    | varchar(64)   | NO             | 二级分区名，如果是非分区表，则显示为空。    |

## 查询示例

系统租户查看租户 ID 为 1002 的租户在当前节点上的所有 Tablet 副本的基本信息，展示前 2 条记录。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.V$OB_TABLET_REPLICA_INFO WHERE TENANT_ID = 1002 LIMIT 2\G
```
