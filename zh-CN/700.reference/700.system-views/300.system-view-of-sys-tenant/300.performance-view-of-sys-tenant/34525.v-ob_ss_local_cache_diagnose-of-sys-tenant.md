# V$OB_SS_LOCAL_CACHE_DIAGNOSE

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `V$OB_SS_LOCAL_CACHE_DIAGNOSE` 用于诊断共享存储模式下所有租户在当前 OBServer 节点上的本地缓存子模块的运行状态。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图仅适用于共享存储（Shared-Storage，SS）模式。无共享（Shared-Nothing，SN）模式下，该视图的查询结果为空。</p>
</main>

## 字段说明

|    字段名称      |    类型   | 是否可以为  |  描述  |
|-----------------|-----------|----------------|--------|
| SVR_IP        | varchar(46)   | NO   | 副本所在的节点地址     |
| SVR_PORT      | bigint(20)    | NO   | 副本所在的节点端口     |
| TENANT_ID     | bigint(20)    | NO   | 租户 ID     |
| MOD_NAME      | varchar(64)   | NO   | 本地缓存内模块名称     |
| SUB_MOD_NAME  | varchar(64)   | NO   | 本地缓存内子模块名称     |
| STATUS        | varchar(7)    | NO   | 对应子模块运行状态：<ul><li>NORMAL/1：正常</li><li>WARN/2：轻微异常</li><li>ERROR/3：严重异常</li></ul>     |
| MODIFY_TIME   | timestamp(6)  | NO   | 对应子模块最近状态变化的时间戳     |
| DIAGNOSE_INFO | varchar(1024) | NO   | 对应子模块的诊断信息    |
| EXTRA_INFO    | varchar(1024) | NO   | 对应子模块状态的补充信息     |

## 查询示例

查询租户 ID 为 1004 的本地缓存各子模块的运行状态和诊断信息：

```shell
obclient(root@sys)[(none)]> SELECT * FROM oceanbase.V$OB_SS_LOCAL_CACHE_DIAGNOSE WHERE tenant_id=1004;
```

查询结果如下：

```shell
+--------------+----------+-----------+----------------+--------------+--------+----------------------------+-------------------------------------------------+------------+
| SVR_IP       | SVR_PORT | TENANT_ID | MOD_NAME       | SUB_MOD_NAME | STATUS | MODIFY_TIME                | DIAGNOSE_INFO                                   | EXTRA_INFO |
+--------------+----------+-----------+----------------+--------------+--------+----------------------------+-------------------------------------------------+------------+
| xx.xx.xx.xx  |    11404 |      1004 | ss_micro_cache | micro_cache  | NORMAL | 2026-01-12 20:09:28.004202 | valid_micro_cnt: 1608, valid_micro_size: 484085 |            |
+--------------+----------+-----------+----------------+--------------+--------+----------------------------+-------------------------------------------------+------------+
```
