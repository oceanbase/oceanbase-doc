# GV$OB_SS_OBJECT_TYPE_IO_STAT

<main id="notice" type='explain'>

## 功能描述

视图 `GV$OB_SS_OBJECT_TYPE_IO_STAT` 用于展示各节点上不同种类的 Object 文件的读、写或删除的使用量。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图仅适用于共享存储（Shared-Storage，SS）模式。无共享（Shared-Nothing，SN）模式下，该视图的查询结果为空。</p>
</main>
