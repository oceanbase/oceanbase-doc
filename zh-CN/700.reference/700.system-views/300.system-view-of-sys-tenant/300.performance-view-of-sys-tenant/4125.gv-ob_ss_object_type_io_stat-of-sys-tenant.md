# GV$OB_SS_OBJECT_TYPE_IO_STAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

视图 `GV$OB_SS_OBJECT_TYPE_IO_STAT` 用于展示租户各节点上不同种类的对象的读、写或删除的使用量。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图仅适用于共享存储（Shared-Storage，SS）模式。无共享（Shared-Nothing，SN）模式下，该视图的查询结果为空。</p>
</main>

## 字段说明

|      字段名称    |         类型 | 是否可以为 NULL |                       描述      |
|-----------------|--------------|----------------|---------------------------------|
| SVR_IP          | varchar(46)  | NO   | OBServer 节点的 IP 地址     |
| SVR_PORT        | bigint(20)   | NO   | OBServer 节点的端口号      |
| TENANT_ID       | bigint(20)   | NO   | 租户 ID     |
| OBJECT_TYPE     | varchar(128) | NO   | 对象的类型     |
| MODE            | varchar(32)  | NO   | 统计数据的来源：<ul><li>`local`：本地</li><li>`remote`：对象存储</li></ul>     |
| READ_CNT        | bigint(20)   | NO   | IO 读的总次数     |
| READ_SIZE       | bigint(20)   | NO   | IO 读的总大小，单位为字节     |
| READ_FAIL_CNT   | bigint(20)   | NO   | IO 读失败的总次数     |
| READ_IOPS       | bigint(20)   | NO   | IO 读的平均 IOPS     |
| WRITE_CNT       | bigint(20)   | NO   | IO 写的总次数     |
| WRITE_SIZE      | bigint(20)   | NO   | IO 写的总大小，单位为字节     |
| WRITE_FAIL_CNT  | bigint(20)   | NO   | IO 写失败的总次数     |
| WRITE_IOPS      | bigint(20)   | NO   | IO 写的平均 IOPS     |
| DELETE_CNT      | bigint(20)   | NO   | 对象删除的总次数     |
| DELETE_FAIL_CNT | bigint(20)   | NO   | 对象删除失败的总次数    |
| DELETE_IOPS     | bigint(20)   | NO   | 对象删除的 IOPS     |

## 查询示例

系统租户查看租户 ID 为 1002 的租户在所有节点上不同种类的对象的读、写及删除的使用量。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.GV$OB_SS_OBJECT_TYPE_IO_STAT WHERE tenant_id = 1002 LIMIT 10;
```
