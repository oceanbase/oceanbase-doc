# V$OB_JAVA_UDF_STATS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该视图从 V4.4.2 BP4 版本开始引入。</p>
</main>

## 功能描述

该视图展示所有租户在当前 OBServer 节点上 Java UDF 的执行统计信息，包括调用次数、成功和失败次数、并发数、耗时分布以及各执行阶段的耗时等。每个 Java UDF 按函数类型和执行模式分别统计。

使用说明如下：

* 统计信息仅保存在内存中，OBServer 节点重启后清零。
* 每个租户在每个 OBServer 节点上最多保留 1024 条统计信息。超出时优先淘汰已删除的 Java UDF 的统计信息，再淘汰最久未调用的统计信息。统计信息的淘汰或丢弃不影响 Java UDF 的执行。
* 系统租户可以查看所有租户的统计信息，包括已删除的 Java UDF 的统计信息。

## 字段说明

|     字段名称    |     类型    | 是否可以为 NULL |      描述      |
|----------------|-------------|----------------|----------------|
| SVR_IP | varchar(46) | NO | OBServer 节点的 IP 地址。 |
| SVR_PORT | bigint(20) | NO | OBServer 节点的端口号。 |
| TENANT_ID | bigint(20) | NO | 租户 ID。 |
| PACKAGE_ID | bigint(20) | NO | Java UDF 所属包的 ID。 |
| UDF_ID | bigint(20) | NO | Java UDF 的 ID。 |
| DATABASE_ID | bigint(20) | YES | Java UDF 所属数据库的 ID。无法获取时为 NULL。 |
| UDF_NAME | varchar(128) | NO | Java UDF 的名称。 |
| SCHEMA_STATUS | varchar(16) | NO | Java UDF 的 Schema 状态：<ul><li>`ACTIVE`：Java UDF 存在</li><li>`DROPPED`：Java UDF 已被删除</li><li>`UNKNOWN`：无法确认 Java UDF 的状态</li></ul> |
| CLASS_NAME | varchar(1024) | YES | Java UDF 对应的 Java 类名。无法获取时为 NULL。 |
| ROUTINE_TYPE | varchar(32) | NO | 函数类型：<ul><li>`UDF`：Java UDF</li><li>`UDAF`：Java UDAF</li><li>`UDTF`：Java UDTF</li><li>`UNKNOWN`：未知类型</li></ul> |
| EXECUTION_MODE | varchar(16) | NO | 执行模式：<ul><li>`IN_PROCESS`：通过 JNI 在 OBServer 进程内执行</li><li>`SANDBOX`：在独立的沙箱进程中执行</li></ul> |
| CALL_COUNT | bigint(20) unsigned | NO | 累计调用次数。一次向量化批量调用计为 1 次。 |
| ROW_COUNT | bigint(20) unsigned | NO | 累计处理的输入行数。 |
| SUCCESS_COUNT | bigint(20) unsigned | NO | 累计成功的调用次数。 |
| FAIL_COUNT | bigint(20) unsigned | NO | 累计失败的调用次数，包含超时和被中断的调用。 |
| TIMEOUT_COUNT | bigint(20) unsigned | NO | 累计超时的调用次数，包含在 `FAIL_COUNT` 中。 |
| INTERRUPT_COUNT | bigint(20) unsigned | NO | 累计被中断（例如被 Kill 或取消）的调用次数，包含在 `FAIL_COUNT` 中。 |
| CURRENT_CONCURRENCY | bigint(20) | NO | 当前正在执行的调用数。 |
| PEAK_CONCURRENCY | bigint(20) | NO | 峰值并发调用数。 |
| CALL_COUNT_1M | bigint(20) unsigned | NO | 最近 1 分钟内的调用次数。 |
| QPS_1M | double | NO | 最近 1 分钟内的平均每秒调用次数。 |
| TOTAL_ELAPSED_US | bigint(20) unsigned | NO | 已完成调用的累计耗时，单位为微秒。 |
| AVG_ELAPSED_US | bigint(20) unsigned | YES | 已完成调用的平均耗时，单位为微秒。没有已完成的调用时为 NULL。 |
| MAX_ELAPSED_US | bigint(20) | NO | 单次调用的最大耗时，单位为微秒。 |
| P95_ELAPSED_US_5M | bigint(20) | YES | 最近 5 分钟内调用耗时的 P95 值，单位为微秒。无法计算时为 NULL。 |
| P99_ELAPSED_US_5M | bigint(20) | YES | 最近 5 分钟内调用耗时的 P99 值，单位为微秒。无法计算时为 NULL。 |
| SERIALIZE_TIME_US | bigint(20) unsigned | NO | 将 OceanBase 参数转换为 Java 参数或沙箱请求的累计耗时，单位为微秒。 |
| DISPATCH_TIME_US | bigint(20) unsigned | NO | 从输入准备完成到收到 Java 执行结果或沙箱响应的累计耗时，单位为微秒。 |
| JAVA_TIME_US | bigint(20) unsigned | YES | Java 代码执行的累计耗时，单位为微秒。无法获取时为 NULL。 |
| DESERIALIZE_TIME_US | bigint(20) unsigned | NO | 将 Java 执行结果或沙箱响应转换为 OceanBase 结果的累计耗时，单位为微秒。 |
| INPUT_BYTES | bigint(20) unsigned | YES | 发送给沙箱进程的累计请求数据量，单位为字节。仅统计 `SANDBOX` 执行模式，无法统计时为 NULL。 |
| OUTPUT_BYTES | bigint(20) unsigned | YES | 从沙箱进程接收的累计响应数据量，单位为字节。仅统计 `SANDBOX` 执行模式，无法统计时为 NULL。 |
| LAST_CALL_TIME | timestamp(6) | YES | 最近一次调用的时间。 |
| LAST_ERROR_CODE | bigint(20) | YES | 最近一次调用失败的错误码。未发生过错误时为 NULL。 |
| LAST_ERROR_TIME | timestamp(6) | YES | 最近一次调用失败的时间。未发生过错误时为 NULL。 |
| STAT_START_TIME | timestamp(6) | NO | 该条统计信息开始记录的时间。 |

## 查询示例

查询所有租户在当前 OBServer 节点上调用次数最多的 10 个 Java UDF 的执行统计信息。

```shell
obclient> SELECT SVR_IP, TENANT_ID, UDF_NAME, ROUTINE_TYPE, EXECUTION_MODE, CALL_COUNT, FAIL_COUNT, AVG_ELAPSED_US, P99_ELAPSED_US_5M FROM oceanbase.V$OB_JAVA_UDF_STATS ORDER BY CALL_COUNT DESC LIMIT 10;
```
