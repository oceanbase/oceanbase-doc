# oceanbase.DBA_OB_LOB_CHECK_EXCEPTION_RESULT

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.DBA_OB_LOB_CHECK_EXCEPTION_RESULT` 用于展示当前租户下 LOB 一致性校验的异常 table 和 tablet 以及异常类型。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
|--------------|-----------|---------------------|-----------|
| LS_ID | bigint(20) | NO | 日志流 ID |
| CREATE_TIME | timestamp(6) | NO | 异常结果创建时间 |
| UPDATE_TIME | timestamp(6) | NO | 异常结果修改时间 |
| TABLE_NAME | varchar(256) | NO | 异常的表名 |
| TABLE_ID | bigint(20) | NO | 异常表对象的 ID |
| INCONSISTENCY_TYPE | varchar(16) | NO | 异常类型 <ul<li>LOB_NOT_FOUND：主表指向一个不存在的 LOB</li><li>LOB_LEN_MISMATCH：元数据长度与实际长度不相等 </li><li>LOB_ORPHANED：LOB 存在但主表没有 locator</li></ul>  |
| TABLET_IDS | longtext | YES | 异常分区 ID |

## 查询示例

```shell
obclient > SELECT * FROM oceanbase.DBA_OB_LOB_CHECK_EXCEPTION_RESULT;
```
