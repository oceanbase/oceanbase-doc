# oceanbase.CDB_OB_BACKUP_VALIDATE_TASKS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.CDB_OB_BACKUP_VALIDATE_TASKS` 用于展示所有租户发起的备份校验 Task 级任务的相关信息。每个 Task 对应一个备份集或日志归档 Piece 校验任务。

## 字段说明

| 字段名称           | 类型          | 是否可以为 NULL | 描述           |
| ----------------- | ------------- | -------------- | -------------- |
| TENANT_ID         | bigint(20)    | NO   | 租户 ID，执行校验任务的租户 ID     |
| TASK_ID           | bigint(20)    | NO   | 任务的 task_id     |
| INCARNATION       | bigint(20)    | NO   | 分身 ID     |
| JOB_ID            | bigint(20)    | NO   | 任务的 job_id     |
| TASK_TYPE         | varchar(64)   | NO   | 校验任务类型：<ul><li>`BACKUPSET`：校验指定的备份集</li> <li>`ARCHIVELOG_PIECE`：校验指定的日志归档 Piece</li></ul>       |
| ID                | bigint(20)    | YES  | 校验的备份集的 `backup_set_id` 或归档 Piece 的 `piece_id`       |
| PATH              | longtext      | YES  | 校验的备份路径或日志归档路径      |
| PATH_TYPE         | varchar(64)   | YES  | 校验的路径类型：<ul><li>`BACKUP_SET_DEST`：数据备份路径</li> <li>`ARCHIVELOG_PIECE_DEST`：日志归档路径</li></ul>      |
| DEST_ID           | bigint(20)    | YES  | 校验的备份路径或归档路径的 ID     |
| PLUS_ARCHIVELOG   | varchar(64)   | NO   | 是否包含补偿日志      |
| INITIATOR_TASK_ID | bigint(20)    | NO   | 补偿日志校验任务的父 task_id，否则为 0     |
| VALIDATE_LEVEL    | varchar(64)   | NO   | 校验等级：<ul><li>`basic`：仅检查文件列表的完整性。</li> <li>`physical`：检查物理数据的正确性及逻辑一致性。</li></ul>      |
| ROUND_ID          | bigint(20)    | NO   | 校验日志归档 Piece 时所属的 Round ID，否则为 0|
| START_TIMESTAMP   | timestamp(6)  | NO   | 校验任务的开始时间     |
| END_TIMESTAMP     | timestamp(6)  | NO   | 校验任务的结束时间     |
| STATUS            | varchar(64)   | NO   | Task 状态：<ul><li>`INIT`：校验任务正在初始化</li> <li>`DOING`：校验任务正在执行中</li> <li>`COMPLETED`：校验任务已执行完成</li> <li>`FAILED`：校验任务执行失败</li> <li>`CANCELED`：校验任务已取消</li></ul>       |
| TOTAL_LS_COUNT    | bigint(20)    | YES  | Task 所包含的日志流数     |
| FINISH_LS_COUNT   | bigint(20)    | YES  | 已校验完成的日志流数     |
| TOTAL_BYTES       | bigint(20)    | YES  | 预计需要校验的数据量，单位为字节     |
| VALIDATED_BYTES   | bigint(20)    | YES  | 已完成校验的数据量，单位为字节     |
| RESULT            | bigint(20)    | NO   | 校验结果的错误码信息     |
| COMMENT           | varchar(4096) | YES  | 校验任务失败的原因描述      |
