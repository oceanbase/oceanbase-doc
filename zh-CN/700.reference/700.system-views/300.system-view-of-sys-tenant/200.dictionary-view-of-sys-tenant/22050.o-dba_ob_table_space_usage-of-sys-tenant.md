# oceanbase.DBA_OB_TABLE_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.3.5 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_TABLE_SPACE_USAGE` 用于查看某个租户下表的逻辑大小以及多副本环境中 Leader 副本的大小。

## 字段说明

| **字段名称** | **类型**  | **是否可以为 NULL** | **描述**                               |
|------------|-------------|---------------------|----------------------------------------|
| TABLE_ID      | bigint(20)    | NO   | 表 ID     |
| DATABASE_NAME | varchar(128)  | NO   | 数据库名     |
| TABLE_NAME    | varchar(256)  | NO   | 表名     |
| OCCUPY_SIZE   | decimal(42,0) | NO   | 压缩后落盘的数据量，单位为字节。比如 2G 数据压缩成了 1MB，占用了 1 个宏块，那么这个宏块的 `OCCUPY_SIZE =1MB`     |
| REQUIRED_SIZE | decimal(42,0) | NO   | 压缩后落盘的数据量占用了多少空间，单位为字节。比如 2G 数据压缩成了 1MB，占用了 1 个宏块，那么这个宏块的 `REQUIRED_SIZE =1MB`（宏块默认占用 2MB）     |

## 查询示例

SN 模式下，用户租户查看表的逻辑大小以及多副本环境中 Leader 副本的大小。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLE_SPACE_USAGE LIMIT 10;
```

查询结果如下：

```shell
+----------+---------------+--------------------------------+-------------+---------------+
| TABLE_ID | DATABASE_NAME | TABLE_NAME                     | OCCUPY_SIZE | REQUIRED_SIZE |
+----------+---------------+--------------------------------+-------------+---------------+
|   500011 | test          | wide_table_row_storage2        |  4495925120 |    4613763072 |
|   500012 | test          | wide_table_column_storage2     |  3915023145 |    4195397632 |
|   500014 | test          | wide_table_row_column_storage2 |  8410964107 |    9805275136 |
+----------+---------------+--------------------------------+-------------+---------------+
3 rows in set (0.052 sec)
```
