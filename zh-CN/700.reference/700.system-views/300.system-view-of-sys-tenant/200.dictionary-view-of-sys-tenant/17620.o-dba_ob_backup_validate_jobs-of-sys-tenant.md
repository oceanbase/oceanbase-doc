# oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.DBA_OB_BACKUP_VALIDATE_JOBS` 用于展示本租户发起的 Job 级备份校验任务的相关信息。每个 Job 对应一个备份校验指令。

## 字段说明

| 字段名称             | 类型           | 是否可以为 NULL | 描述           |
| ------------------- | -------------- | -------------- | -------------- |
| JOB_ID              | bigint(20)     | NO   | 任务 ID     |
| INCARNATION         | bigint(20)     | NO   | 分身 ID     |
| INITIATOR_TENANT_ID | bigint(20)     | NO   | 发起此次 Job 的租户 ID   |
| INITIATOR_JOB_ID    | bigint(20)     | NO   | 发起此次 Job 的 job_id     |
| EXECUTOR_TENANT_ID  | varchar(65536) | NO   | 此次 Job 对应的需要执行校验任务的用户租户的 tenant_id     |
| TYPE                | varchar(64)    | NO   | 校验任务类型：<ul><li>`BACKUP`：校验整个备份路径和归档路径下的所有备份集和日志归档 Piece</li> <li>`BACKUP_SET`：校验指定的备份集</li> <li>`ARCHIVE_PIECE`：校验指定的日志归档 Piece</li></ul>     |
| PATH                | longtext       | YES  | 用户指定校验的备份路径或日志归档路径，如果值为空，则表示该任务为非指定路径的校验     |
| PATH_TYPE           | varchar(64)    | YES  | 用户指定路径下校验的类型： <ul><li>`BACKUP_SET`：校验指定的备份集</li> <li>`ARCHIVE_PIECE`：校验指定的日志归档 Piece</li></ul>     |
| ID                  | longtext       | YES  | <p>校验的备份集的 `backup_set_id` 或归档 Piece 的 `piece_id`</p><p>默认为 0，表示当前备份路径和归档路径下的所有备份集和日志归档 Piece，当用户指定校验备份集的 `backup_set_id` 或归档 Piece 的 `piece_id` 时，值会变更为对应的 ID 或 ID 列表</p>     |
| VALIDATE_LEVEL      | varchar(64)    | NO   | 校验等级： <ul><li>`basic`：仅检查文件列表的完整性。</li> <li>`physical`：检查物理数据的正确性及逻辑一致性。</li></ul>    |
| START_TIMESTAMP     | timestamp(6)   | NO   | 校验任务的开始时间     |
| END_TIMESTAMP       | timestamp(6)   | NO   | 校验任务的结束时间     |
| STATUS              | varchar(64)    | NO   |  Job 状态： <ul><li>`INIT`：校验任务正在初始化</li> <li>`DOING`：校验任务正在执行中</li> <li>`COMPLETED`：校验任务已执行完成</li> <li>`FAILED`：校验任务执行失败</li> <li>`CANCELED`：校验任务已取消</li></ul>   |
| RETRY_COUNT         | bigint(20)     | YES  | 重试次数     |
| TASK_COUNT          | bigint(20)     | YES  | 备份集或日志归档 Piece 的总校验任务数     |
| SUCCESS_TASK_COUNT  | bigint(20)     | YES  | 备份集或日志归档 Piece 校验成功的任务数     |
| RESULT              | bigint(20)     | NO   | 校验结果的错误码信息    |
| DESCRIPTION         | varchar(4096)  | YES  | OCP 提供的外部信息    |
| COMMENT             | varchar(4096)  | YES  | 校验任务失败的原因描述      |
