# information_schema.TRIGGERS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V3.2.3 版本开始引入。</p>
</main>

## 功能描述

视图 `information_schema.TRIGGERS` 展示有关触发器的信息。

## 字段说明

|      字段名称    |         类型       | 是否可以为 NULL |    描述     |
|-----------------|--------------------|----------------|-------------|
| TRIGGER_CATALOG            | varchar(512) | NO   | 触发器所属目录的名称。此值始终为 def。 |
| TRIGGER_SCHEMA             | varchar(64)  | NO   | 触发器所属 Shema（数据库）的名称。|
| TRIGGER_NAME               | varchar(64)  | NO   | 触发器名称。 |
| EVENT_MANIPULATION         | varchar(6)   | NO   | 触发事件。这是激活触发器所关联表上的操作类型。该值可以为 INSERT（插入了一行）、DELETE（删除了一行）或者 UPDATE（修改了一行）。     |
| EVENT_OBJECT_CATALOG       | varchar(512) | NO   | 与该触发器相关联的表所在的目录，该值始终为 def |
| EVENT_OBJECT_SCHEMA        | varchar(64)  | NO   | 与该触发器相关联的表所在的 Schema（数据库）    |
| EVENT_OBJECT_TABLE         | varchar(64)  | NO   | 与该触发器相关联的表名    |
| ACTION_ORDER               | bigint(20)   | NO   | 在具有相同 `EVENT_MANIPULATION` 和 `ACTION_TIMING` 值的同一表上的触发器列表中的触发器操作的顺序和位置。     |
| ACTION_CONDITION           | longtext     | NO   | 此值始终为 NULL    |
| ACTION_STATEMENT           | longtext     | NO   | 触发器激活时所执行的语句|
| ACTION_ORIENTATION         | varchar(9)   | NO   | 此值始终为 ROW     |
| ACTION_TIMING              | varchar(6)   | NO   | 触发器是在触发事件之前还是之后激活。该值可以为 BEFORE 或者 AFTER     |
| ACTION_REFERENCE_OLD_TABLE | varchar(64)  | NO   | 此值始终为 NULL     |
| ACTION_REFERENCE_NEW_TABLE | varchar(64)  | NO   | 此值始终为 NULL     |
| ACTION_REFERENCE_OLD_ROW   | varchar(3)   | NO   | 旧列标识符，该值总是为 OLD 该     |
| ACTION_REFERENCE_NEW_ROW   | varchar(3)   | NO   | 新列标识符，值总是为 NEW     |
| CREATED                    | datetime(2)  | YES  | 创建触发器的日期和时间     |
| SQL_MODE                   | text         | NO   | 创建触发器时生效的 SQL 模式     |
| DEFINER                    | varchar(93)  | YES  | `DEFINER` 子句中指定的账号（通常是创建触发器的用户），格式为 `'user_name'@'host_name'`     |
| CHARACTER_SET_CLIENT       | varchar(32)  | NO   | 创建触发器时 `character_set_client` 系统变量在当前会话的值     |
| COLLATION_CONNECTION       | varchar(32)  | NO   | 创建触发器时 `collation_connection` 系统变量在当前会话的值     |
| DATABASE_COLLATION         | varchar(32)  | NO   | 与触发器关联的数据库的排序规则     |
|----------------------------|--------------|------|------|

## 查询示例

查询表 `t1` 的详细信息。

```sql
SELECT * FROM information_schema.TRIGGERS;
```
