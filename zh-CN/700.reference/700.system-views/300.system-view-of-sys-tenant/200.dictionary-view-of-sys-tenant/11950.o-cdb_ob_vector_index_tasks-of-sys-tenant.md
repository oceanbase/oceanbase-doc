# oceanbase.CDB_OB_VECTOR_INDEX_TASKS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.3.5 版本，该视图从 V4.3.5 BP2 版本开始引入。</p>
</main>

## 功能描述

视图 `CDB_OB_VECTOR_INDEX_TASKS` 展示了集群中所有租户下所有向量索引分区重建任务的信息。

## 字段说明

| **字段名称**   | **类型**     | **是否可以为 NULL**  | **描述**        |
|----------------|--------------|----------------------|-----------------|
| tenant_id        | bigint(20)  |  YES    | 租户 ID      |
| table_id        | bigint(20)  |  YES    | 索引表 ID      |
| tablet_id        | bigint(20)  |  YES    | 索引表块 ID      |
| task_id        | bigint(20)  |  YES    | 任务 ID      |
| trigger_type        | bigint(20)  |  NO    | 任务触发类型：<ul><li>`0`：自动触发</li><li>`1` ：手动触发</li></ul>      |
| task_type        | bigint(20)  |  YES    | 任务类型：<ul><li>`0`：异步构建</li><li>`1`：索引分区重建</li></ul>      |
| status        | bigint(20)  |  YES    | 任务状态：<ul><li>`0`：任务准备中</li><li>`1`：任务执行中</li><li>`2`：任务暂停</li><li>`3`：任务结束</li></ul>      |
| target_scn        | bigint(20)  |  YES    | 本轮任务使用的读快照版本     |
| ret_code        | bigint(20)  |  NO    | 任务结束时候的状态：<ul><li>`0`：成功</li><li>`非 0`：失败</li></ul>      |
| trace_id        | varchar(OB_MAX_ERROR_MSG_LEN)  |  YES    | 任务执行追踪 ID      |
