# oceanbase.CDB_OB_SS_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

视图 `CDB_OB_SS_SPACE_USAGE` 用于记录各租户的对象存储上存储空间的占用情况。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图仅适用于共享存储（Shared-Storage，SS） 模式。无共享（Shared-Nothing，SN） 模式下，该视图的查询结果为空。</p>
</main>

## 字段说明

| 字段名称       | 类型          | 是否可以为 NULL      | 描述                                        |
|---------------|---------------|---------------------|----------------------------------------|
| TENANT_ID     | bigint(20)    | NO   | 租户 ID。     |
| TENANT_NAME   | varchar(128)  | NO   | 租户名。     |
| ENDPOINT      | varchar(128)  | NO   | 共享存储的 Endpoint。      |
| PATH          | varchar(128)  | NO   | 共享存储的 Path。      |
| STORAGE_TYPE  | varchar(32)   | NO   | 存储类型：<ul><li>`Local All Bytes`：对象存储上本地目录的所有数据</li> <li>`Shared Data Bytes`：对象存储上公共目录的数据</li> <li>`Shared Meta Bytes`：对象存储上的所有元数据</li></ul>    |
| VALUE         | bigint(20)    | NO   | `STORAGE_TYPE` 对应的空间占用大小，单位为字节。   |

## 查询示例

共享存储模式下，查看各租户的对象存储上存储空间的占用情况。

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_SS_SPACE_USAGE;
```

查询结果如下：

```shell

|      1002 | oracle001   | UNUSE    | UNUSE | Shared Meta Bytes |  6406144 |

|      1004 | mysql001    | UNUSE    | UNUSE | Shared Meta Bytes |  6508544 |

6 rows in set
```
