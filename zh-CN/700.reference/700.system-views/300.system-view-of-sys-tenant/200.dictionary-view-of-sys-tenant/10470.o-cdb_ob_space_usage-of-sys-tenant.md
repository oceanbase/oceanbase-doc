# oceanbase.CDB_OB_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.3.4 版本开始引入。</p>
</main>

## 功能描述

视图 `CDB_OB_SPACE_USAGE` 用于记录各个节点占用存储空间的详细情况。

## 字段说明

| **字段名称** | **类型**  | **是否可以为 NULL** | **描述**                               |
|------------|-------------|---------------------|----------------------------------------|
| TENANT_ID   | varchar(128)  | NO   | 租户 ID     |
| TENANT_NAME | varchar(128)  | NO   | 租户名     |
| ENDPOINT    | varchar(1024) | NO   | 共享存储 ENDPOINT     |
| PATH        | varchar(1024) | NO   | 共享存储 PATH     |
| SPACE_TYPE  | varchar(11)   | NO   | 类型分为：<ul><li>非共享存储模式下：<ul><li>DATA：本地部署模式下的所有宏块（租户所有副本节点的所有数据、所有元数据、所有临时文件） </li><li>CLOG：本地部署模式下的 clog（租户所有副本节点的 clog） </li><li>PRIVATE：多副本多版本总和、临时文件 </li><li>DATA_SHARED：展示为 NULL </li><li>CLOG_SHARED：展示为 NULL </li></ul> </li><li>共享存储模式下：<ul><li>DATA：本地部署模式下的所有宏块（租户所有副本节点的私有数据、所有元数据、所有临时文件） </li><li>CLOG：本地部署模式下的 clog（租户所有副本节点的私有 clog） </li><li>PRIVATE：多副本多版本总和、临时文件 </li><li>DATA_SHARED：租户共享多版本基线 </li><li>CLOG_SHARED：租户所有节点的 clog </li></ul> </li></ul>     |
| USAGE_BYTES | decimal(42,0) | NO   | 数据实际占用磁盘的大小 required_size，单位为字节   |

## 查询示例

查看各个节点占用磁盘空间的使用情况。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SPACE_USAGE LIMIT 10;
```
