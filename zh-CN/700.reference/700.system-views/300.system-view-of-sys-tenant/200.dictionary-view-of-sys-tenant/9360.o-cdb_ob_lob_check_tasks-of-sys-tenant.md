# oceanbase.CDB_OB_LOB_CHECK_TASKS

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

视图 `oceanbase.CDB_OB_LOB_CHECK_TASKS` 用于在系统租户下记录 LOB 一致性校验和恢复的任务扫描的进度。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
|--------------|-----------|---------------------|-----------|
| TENANT_ID | bigint(20) | NO | 租户 ID |
| LS_ID | bigint(20) | NO | 日志流 ID |
| TABLE_NAME | varchar(256) | NO | 表名称 |
| TABLE_ID | bigint(20) | NO | 表 ID |
| TABLET_ID | bigint(20) | NO | 分区 ID |
| TASK_ID | bigint(20) | NO | 当前批次任务的 ID |
| START_TIME | timestamp(6) | NO | 任务开始时间 |
| END_TIME | timestamp(6) | NO | 任务结束时间 |
| TRIGGER_TYPE | varchar(8) | NO | 任务触发类型，系统或者用户触发 |
| STATUS | varchar(10) | NO | 任务的状态 <ul><li>LS 级任务状态：<ul><li>PREPARED：准备状态，还未开始扫描数据</li><li>RUNNING：运行状态，正在扫描主表或者辅助表数据</li><li>PENDING：挂起状态，可以通过命令恢复执行</li><li>CANCELED：取消状态，无法恢复执行</li><li>FINISHED：完成状态</li></ul></li><li>租户级任务状态：<ul><li>TRIGGERING：表示租户 LOB 一致性校验或者恢复任务正在触发</li><li>SUSPENDING：表示租户 LOB 一致性校验或者恢复任务正在挂起</li><li>CANCELING：表示租户 LOB 一致性校验或者恢复任务正在取消</li><li>CLEANING：表示正在清理 LOB 一致性校验或者恢复任务记录</li><li>INVALID：非法状态</li></ul></li></ul>|
| MISS_CNT | bigint(20) | NO | 一致性校验扫描出的辅助表缺失数据数量 |
| MISMATCH_LEN_CNT | bigint(20) | NO | 一致性校验扫描出的主表辅助表 byte_len 不相等的数据数量 |
| ORPHAN_CNT | bigint(20) | NO | 一致性校验扫描出的辅助表残留数据数量 |
| CORRECT_CNT | bigint(20) | NO | 一致性恢复删除的辅助表的异常数量 |
| RET_CODE | varchar(512) | NO | 任务结束时候的状态 |
| TASK_TYPE | varchar(10) | NO | TTL 任务类型（"LOB_CHECK" 或 "LOB_CORRECT"） |
| TASK_SCOPE | varchar(6) | NO | 任务类型 <ul><li>TENANT: 租户级任务</li><li>LS：LS 级任务</li></ul> |
