# oceanbase.DBA_OB_BACKUP_PARAMETER

<main id="notice" type='explain'>
<h4>说明</h4>
<p>从 V4.0.0 版本开始引入。</p>
</main>

## 功能描述

展示本租户的数据备份参数信息。`sys` 租户和 Meta 租户不支持物理备份。

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | 参数名 |
| VALUE | longtext | NO | 参数值 |
