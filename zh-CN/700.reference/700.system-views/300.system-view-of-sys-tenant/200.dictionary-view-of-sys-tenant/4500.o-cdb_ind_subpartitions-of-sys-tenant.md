# oceanbase.CDB_IND_SUBPARTITIONS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>从 V4.0.0 版本开始引入。</p>

## 功能描述

查看数据库中所有索引子分区的信息。
