# oceanbase.CDB_SCHEDULER_JOBS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V4.4.2 版本开始引入。</p>
</main>

## 功能描述

该视图用于展示所有租户下的所有 job。

## 字段说明

|          字段名称           |       类型        | 是否可以为 NULL |     描述     |
|-------------------------|-----------------|------------|--------------------------------------|
