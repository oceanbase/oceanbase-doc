# oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_VECTOR_INDEX_TASK_HISTORY` 展示了当前租户下所有向量索引分区重建任务的历史信息。

## 字段说明

| 字段名称                   | 字段类型      | 是否可以为 NULL | 描述 |
|---------------------------|---------------|------|----|
| TABLE_ID	                | bigint(20)	| YES   | 表 ID |
| TABLET_ID	                | bigint(20)	| YES   | 分区 ID |
| TASK_ID	                | bigint(20)	| YES   | 任务 ID |
| START_TIME	                | timestamp(6)	| YES   | 任务开始时间 |
| MODIFY_TIME	                | timestamp(6)	| YES   | 任务结束时间 |
| TRIGGER_TYPE	                | varchar(16)	| NO   | 任务触发类型：<ul><li><code>0</code>：自动触发</li><li><code>1</code>：手动触发</li></ul> |
| STATUS	                | varchar(16)	| NO   | 任务状态：<ul><li><code>0</code>：任务准备中</li><li><code>1</code>：任务执行中</li><li><code>2</code>：任务暂停</li><li><code>3</code>：任务结束</li></ul> |
| TASK_TYPE	                | bigint(20)	| NO   | 任务类型：<ul><li><code>0</code>：异步构建</li><li><code>1</code>：索引分区重建</li><li><code>5</code>：冻结转储任务</li><li><code>6</code>：合并任务</li></ul>     |
| TASK_SCN	                | bigint(20)	| NO   | 任务版本号 |
| RET_CODE	                | bigint(20)	| NO   | 任务结束时候的状态：<ul><li><code>0</code>：成功</li><li><code>非 0</code>：失败</li></ul> |
| TRACE_ID	                | varchar(512)	| NO   | 任务执行追踪 ID |
| TASK_INFO                  | long text    | NO   | 任务的详细进度信息。以 JSON 格式展示，内容包括对合并数据段（Segment）任务的中各个 Segment 的详细信息，如 SCN、Key 范围、索引及内存占用信息等，便于全面了解任务执行过程。 |

## 查询示例

系统租户下，查看所有租户的向量索引性能优化任务历史信息。

```sql
SELECT * FROM oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY ORDER BY MODIFY_TIME DESC\G;
```

TASK_INFO 字段 JSON 字符串说明：

| 字段名 | JSON 字段类型 | 含义 |
|---|---|---|
| merge_segments_cnt | string | 需要被合并的 Segment 数量 |
| merge_segments | array | 合并前的 Segment 信息，数量和 merge_segments_cnt 相等 |
| result_segments | array | 合并后的 Segment 结果信息 |
| scn | string | 内部时间戳 |
| start_key | string | Segment 存储范围的上界 |
| end_key | string | Segment 存储范围的下界 |
| index_type | string | Segment 处理向量的索引类型，包含值有：<ul><li>HNSW</li><li>HNSW_SQ</li><li>HNSW_BQ</li><li>HGRAPH</li><li>SINDI</li></ul> |
| mem_used | string | Segment 使用的内存 |
| min_vid | string | Segment 最小的向量 ID |
| max_vid | string | Segment 最大的向量 ID |
