# oceanbase.CDB_OB_ARCHIVE_DEST

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.0.0 版本开始引入。</p>
</main>

## 功能描述

展示所有租户的归档路径配置。

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 租户 ID |
| DEST_NO | bigint(20) | NO | 标识 log_archive_dest_n |
| NAME | varchar(1024) | NO | 字段名 |
| VALUE | varchar(4096) | NO | 字段值 |

## 查询示例

系统租户查看租户 ID 为 1002 的租户的归档路径配置。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_ARCHIVE_DEST WHERE TENANT_ID = 1002;
```

查询结果如下：

```shell
+-----------+---------+-----------------------+-------------------------------------+
| TENANT_ID | DEST_NO | NAME                  | VALUE                               |
+-----------+---------+-----------------------+-------------------------------------+
|      1002 |       0 | binding               | OPTIONAL                            |
|      1002 |       0 | dest_id               | 1001                                |
|      1002 |       0 | path                  | file:///home/admin/oceanbase/arglog |
|      1002 |       0 | piece_switch_interval | 1d                                  |
|      1002 |       0 | state                 | ENABLE                              |
+-----------+---------+-----------------------+-------------------------------------+
5 rows in set
```
