# oceanbase.DBA_WR_RES_MGR_SYSSTAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.2.5 BP1 版本开始引入。</p>
</main>

## 功能描述

展示资源组粒度的 sysstat。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20)  | NO   |  集群 ID    |
| TENANT_ID  | bigint(20)  | NO   |  租户 ID    |
| GROUP_ID   | bigint(20)  | NO   |  consumer_group_id   |
| SNAP_ID    | bigint(20)  | NO   |  快照 ID    |
| SVR_IP     | varchar(46) | NO   |  节点 IP    |
| SVR_PORT   | bigint(20)  | NO   |  节点 Port   |
| STAT_ID    | bigint(20)  | NO   |  统计项 id    |
| VALUE      | bigint(20)  | YES  |  统计项值    |

## 查询示例

查看资源组粒度的 sysstat。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_RES_MGR_SYSSTAT limit 1;
```

查询结果如下：

```shell
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
| CLUSTER_ID | TENANT_ID | SNAP_ID | SVR_IP          | SVR_PORT | STAT_ID | VALUE  | group_id |
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
|          1 |         1 |       1 | xxx.xxx.xxx.198 |    49708 |   10000 | 460384 |        1 |
+------------+-----------+---------+-----------------+----------+---------+--------+----------+
1 row in set
```
