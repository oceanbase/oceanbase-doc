# oceanbase.CDB_OB_SERVER_SPACE_USAGE

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>该视图从 V4.3.4 版本开始引入。</p>
</main>

## 功能描述

视图 `CDB_OB_SERVER_SPACE_USAGE` 用于监控各个节点存储空间使用的详细信息。

## 字段说明

| **字段名称** | **类型**  | **是否可以为 NULL** | **描述**                               |
|------------|-------------|---------------------|----------------------------------------|
| TENANT_ID   | varchar(128)  | NO   | 租户 ID    |
| TENANT_NAME | varchar(128)  | NO   | 租户名     |
| SERVER_IP   | varchar(46)   | NO   | 包含租户 Uint 的节点 IP      |
| SERVER_PORT | bigint(20)    | NO   | 包含租户 Uint 的节点 PORT     |
| SPACE_TYPE  | varchar(9)    | NO   | 非共享模式下展示为 BULL；共享存储模式下只统计节点私有数据，可分为几类：<ul><li>DATA_TABLE：所有主表 Tablet 的数据，包含 Lob Tablet </li><li>INDEX_TABLE：所有索引表 Tablet 的数据 </li><li>META：所有元数据 </li><li>TMP_FILE：临时文件 </li><li>CLOG：节点上的 clog 总大小 </li><li>SLOG：节点上的 slog 总大小，共享存储没有改行 </li></ul>     |
| DATA_BYTES  | decimal(42,0) | NO   | 数据内容大小     |
| USAGE_BYTES | decimal(42,0) | NO   | 实际占用磁盘空间大小     |

## 查询示例

查询各个节点存储空间使用的详细信息。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SERVER_SPACE_USAGE LIMIT 10;
```
