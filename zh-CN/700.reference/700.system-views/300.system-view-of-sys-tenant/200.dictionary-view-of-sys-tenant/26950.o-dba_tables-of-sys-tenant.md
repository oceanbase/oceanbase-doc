# oceanbase.DBA_TABLES

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><ul><li>对于 V4.4.x 版本，该视图从 V4.4.2 版本开始引入。</li><li>对于 V4.5.x 版本，该视图从 V4.5.0 版本开始引入。</li></ul></p>

该视图用于展示当前租户所有表信息。
