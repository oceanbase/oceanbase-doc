# oceanbase.CDB_OB_TABLEGROUPS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.0.0 版本开始引入。</p>
</main>

## 功能描述

系统租户下展示所有租户的表组的元信息，主要是展示表组的分区信息。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>从 V4.2.0 版本开始，该视图中的分区属性字段将不再有含义，统一展示为 <code>NONE</code> 或 </code>NULL</code>。</p>
</main>

## 字段说明

|           字段名称            |      类型      | 是否可以为 NULL |            描述            |
|---------------------------|--------------|------------|-------------------------------------|
| TENANT_ID                 | bigint(20)   | NO         | 租户 ID                    |
| TABLEGROUP_NAME           | varchar(128) | NO         | 表组名                      |
| PARTITIONING_TYPE         | varchar(13)  | NO         | 分区的表组一级分区的分区类型：<ul><li>`NONE`：非分区表组   </li><li> `HASH`：HASH 分区（单分区键）   </li><li> `KEY`：KEY 分区   </li><li> `RANGE`：RANGE 分区（单分区键）   </li><li> `RANGE COLUMNS`：RANGE COLUMNS 分区   </li><li> `LIST`：LIST 分区（单分区键）   </li><li> `LIST COLUMNS`：LIST COLUMNS 分区   </li><li> `UNKNOWN`：异常类型</li></ul> <main id="notice" type='explain'><h4>说明</h4><p>该字段从 V4.2.0 版本开始 值为 <code>NULL</code></p></main>            |
| SUBPARTITIONING_TYPE      | varchar(13)  | NO         | 分区的表组二级分区的分区类型：<ul><li>`NONE`：非分区表组、一级分区表组   </li><li> `HASH`：HASH 分区（单分区键）   </li><li> `KEY`：KEY 分区   </li><li> `RANGE`：RANGE 分区（单分区键）   </li><li> `RANGE COLUMNS`：RANGE COLUMNS 分区   </li><li> `LIST`：LIST 分区（单分区键）   </li><li> `LIST COLUMNS`：LIST COLUMNS 分区   </li><li> `UNKNOWN`：异常类型</li></ul> <main id="notice" type='explain'><h4>说明</h4><p>该字段从 V4.2.0 版本开始 值为 <code>NULL</code></p></main>     |
| PARTITION_COUNT           | bigint(0)   | NO         | 该值为 `NULL`            |
| DEF_SUBPARTITION_COUNT    | bigint(0)    | NO         | 该值为 `NULL`            |
| PARTITIONING_KEY_COUNT    | bigint(0)   | NO         | 该值为 `NULL`            |
| SUBPARTITIONING_KEY_COUNT | bigint(0)   | NO         | 该值为 `NULL`            |
| SHARDING                  | varchar(20)  | NO         | 表组的 SHARDING 属性。取值如下：<ul><li>`NONE`：对于该属性的表组，表组内的所有表的所有分区均聚集在同一台机器上，并且对加入表组的表没有任何限制。</li> <li>`PARTITION`：对于该属性的表组，表组内每一张表的数据按一级分区打散；如果是二级分区表，则一级分区下的所有二级分区聚集在一起。</li> <li>`ADAPTIVE`：对于该属性的表组，表组内每一张表的数据根据自适应方式打散。即，如果表组内的表是一级分区表，则按一级分区打散；如果表组内的表是二级分区表，则按每个一级分区下的二级分区打散。</li></ul>  <main id="notice" type='explain'><h4>说明</h4><p>该字段从 V4.2.0 版本开始引入。</p></main> |
| SCOPE                     | varchar(20)  | NO         | 表组的 `SCOPE` 属性。取值如下：<ul><li>`SERVER`：表示所有分区组的 Leader 分布在同一节点上。 </li><li>`ZONE`：表示所有分区组的 Leader 分布在同一 Zone 内，且打散在 Zone 内各节点。 </li><li>`CLUSTER`：表示所有分区组的 Leader 打散在集群内各节点。</li></ul> <main id="notice" type='explain'><h4>说明</h4><p>对于 V4.4.2 版本，该字段从 V4.4.2 BP1 版本开始引入。</p></main>|

## 查询示例

查看表组 `tblgroup1` 的属性。

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TABLEGROUPS
    WHERE tablegroup_name = 'tblgroup1'
    LIMIT 1\G
```

返回结果如下：

```shell
*************************** 1. row ***************************
                TENANT_ID: 1002
          TABLEGROUP_NAME: tblgroup1
        PARTITIONING_TYPE: NONE
     SUBPARTITIONING_TYPE: NONE
          PARTITION_COUNT: NULL
   DEF_SUBPARTITION_COUNT: NULL
   PARTITIONING_KEY_COUNT: NULL
SUBPARTITIONING_KEY_COUNT: NULL
                 SHARDING: NONE
                    SCOPE: ZONE
1 row in set
```
