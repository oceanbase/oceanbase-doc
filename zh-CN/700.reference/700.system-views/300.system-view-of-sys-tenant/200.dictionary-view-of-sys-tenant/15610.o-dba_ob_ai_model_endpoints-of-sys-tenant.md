# oceanbase.DBA_OB_AI_MODEL_ENDPOINTS

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

展示查询本租户模型访问信息。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| ENDPOINT_ID | int(20) | NO | 模型访问信息唯一 ID。 |
| ENDPOINT_NAME | varchar(128) | NO | 用户自定义的模型访问信息唯一名称。 |
| AI_MODEL_NAME | varchar(128) | NO | 访问信息所属的 AI 模型名称。 |
| SCOPE | varchar(128) | NO | 预留字段，默认为 `all`。未来可用于实现跨地域/可用区（region/zone）的模型访问信息配置。 |
| URL | varchar(2048) | NO | 模型的调用地址，URL 支持 HTTP、HTTPS。例如：`https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings`。 |
| ACCESS_KEY | varchar(2048) | NO | 模型调用时使用的 API Key。 |
| PROVIDER | varchar(128) | NO | AI 模型供应商，例如 `openai`、`aliyun`、`deepseek`、`ollama` 等。用于数据库内部 API 消息格式适配；若为空，需提供 UDF 函数，否则将报错。 |
| REQUEST_MODEL_NAME | varchar(128) | YES | 请求消息体中用户自定义的模型名称，例如 `bge-m3-custom`。 |
| PARAMETERS | varchar(2048) | YES | 预留字段，可选参数，用于配置模型调用的额外参数，例如 `context_window` 和 `max_output_tokens`，以支持批量操作。示例：`{"context_window": 128000,"max_output_tokens": 8000}`。 |
| REQUEST_TRANSFORM_FN | varchar(64) | YES | 预留字段，用于构造发送给 AI 模型的请求数据。如果为空，系统将根据 `PROVIDER` 和模型类型（`embedding`/`rerank`/`completion`）使用默认的消息格式发送请求。 |
| RESPONSE_TRANSFORM_FN | varchar(64) | YES | 预留字段，用于解析 AI 模型返回的数据。如果为空，系统将根据 `PROVIDER` 和模型类型（`embedding`/`rerank`/`completion`）使用默认的回复格式进行处理。 |


## 查询示例

用户租户查询本租户的 AI 模型访问信息。

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_MODEL_ENDPOINTS;
```
