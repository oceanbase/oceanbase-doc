## ERROR 10516 (HY000) : When invoking the Increment interface, only HBase cells with a length of 8 can be converted to int64_t. the current length of the HBase cell is '%d'

* OceanBase 错误码：10516

* 错误原因：在 OBKV-HBase 中使用 Increment 接口时，要求要进行加减操作的 cell 的值（value）必须是 8 字节的 long 类型（Java long/int64），并且采用大端格式（Big-Endian，表示高位字节放在前面，低位字节放在后面）。如果不是 8 字节 long，操作会失败。常见原因如下：
  * 客户端写入的增量数据不是 8 字节 long，比如写成了字符串、文本、int32 等格式，未用 long 类型编码。
  * 该列之前用 Put 或 Append 写入过不是 8 字节的数据（比如字符串、变长二进制等），导致当前值类型不是 long。

* 解决方法如下：
  * 客户端写入增量数据时，务必以 8 字节大端 long（Java 可用 org.apache.hadoop.hbase.util.Bytes.toBytes(long)）编码。
  * 如果某个 cell 已经有数据且不是 long，可先删除或覆盖为合法的 8 字节 long 后再进行 Increment 操作。

</main>
