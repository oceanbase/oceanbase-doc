* 错误原因：用户指定的 AI 模型已经存在。

* 解决方法：使用其他的 AI 模型名称创建。

## ERROR 11120 (HY000) : Got error during COMMIT: %s

* OceanBase 错误码：11120

* 兼容 MySQL 错误码：1180

* 错误原因：事务在提交阶段发生了错误。

* 解决方法：解决方案的核心在于通过详细日志定位根本原因，建议在获得具体错误信息后，寻求官方技术支持以获得最准确的解决方案。
