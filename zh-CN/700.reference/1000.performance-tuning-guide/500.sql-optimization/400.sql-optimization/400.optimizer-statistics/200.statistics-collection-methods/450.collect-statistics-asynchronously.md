# 异步统计信息收集

异步统计信息收集用于及时处理数据量发生较大变化的表或分区。系统定期检查表或分区的数据变化情况，并根据独立的判断阈值确定是否将其加入异步收集候选范围。

异步统计信息收集与[自动收集统计信息](400.collect-statistics-automatically.md)是两种独立的收集机制。自动统计信息收集通过维护窗口收集缺失或过期的统计信息；异步统计信息收集通过独立的后台任务检查数据变化情况。

OceanBase 数据库从 V4.2.4 版本开始支持异步统计信息收集。从 V4.3.5 BP2 版本开始，系统按照自上次收集统计信息以来的数据变化比例判断表或分区是否进入异步收集候选范围。

## 判断异步收集候选条件

数据变化比例的计算方式如下：

```text
数据变化比例 = （新增行数 + 更新行数 + 删除行数）/ 上次统计信息记录的行数
```

其中，新增行数、更新行数和删除行数均为自上次收集统计信息以来累计影响的行数。默认情况下，数据变化比例大于 2（即累计影响行数超过上次统计信息记录行数的 2 倍）时，表或分区进入异步收集候选范围。

当上次统计信息记录的行数为 0 时，如果当前监控到的累计新增行数减去累计删除行数大于 0，则表或分区进入异步收集候选范围；如果计算结果为 0，则不会仅因上次统计信息记录的行数为 0 而进入候选范围。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>满足上述条件表示表或分区进入异步收集候选范围，不代表统计信息会立即完成收集。异步统计信息收集的默认判断阈值为 2；自动统计信息收集通过 <code>STALE_PERCENT</code> 控制统计信息过期阈值，其默认值为 10（即 10%）。</p>
</main>

## 分区表的判断粒度

对于不同类型的表，系统采用以下粒度独立判断异步收集候选条件：

* 对于非分区表，按表判断。

* 对于一级分区表，按分区判断。

* 对于二级分区表，按子分区判断。
