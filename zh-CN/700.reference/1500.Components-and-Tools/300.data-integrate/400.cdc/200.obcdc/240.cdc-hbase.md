# CDC HBase

OceanBase 数据库内部使用 KQTV 四列存储 HBase 数据，其中：

* K 表示 rowkey，起索引和区分不同行记录的作用。

* Q（Qualifer）表示 Column Name。

* T 表示宽表的 Version，一般是时间戳字段。

* V 表示具体的 Value，为 bianry 类型数据。V 列与 AnyType 具有类似的功能，即可以容纳任意类型的数据，通过序列化和反序列化技术来支持多种数据类型的存储和读取。

OBCDC 4.x 版本支持 HBase 模型数据，包括：

* 将 HBase 的 PUT 语义转为 INSERT

* 支持 T 列同步为正值（OceanBase 数据库内部存储时间列为负值）

## CDC HBase 配置项介绍

CDC 中和 HBase 相关的配置项如下。

| 配置项 | 描述 | 默认值 | 取值范围 | 是否支持动态变更 | 备注 |
|--------|-------|--------|---------------|-----|----|
| enable_hbase_mode | 控制是否允许 HBase 模式生效 | 0 | {0, 1} | 否 | 取值为 0 时表示不允许 HBase 模式生效，同步的表中有 HBase 模式的表时需要开启该配置 |
