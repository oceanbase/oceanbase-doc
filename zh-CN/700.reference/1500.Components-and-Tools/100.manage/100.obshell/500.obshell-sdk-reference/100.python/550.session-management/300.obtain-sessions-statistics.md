# 获取会话统计

本文介绍如何通过 obshell-sdk-python 获取会话统计信息。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>建议先查看 <a href='../100.quickstart-of-python.md'>obshell-sdk-python 快速上手</a> 内容，了解如何使用 obshell-sdk-python。</p>
</main>

## 注意事项

* 请确保 obshell 正常运行。

* 请求的 client 对应的节点需在已初始化的集群中。

* 租户名称区分大小写，请确保使用正确的租户名称。

## 示例代码

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth

# 创建 client 实例
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# 获取租户会话统计信息
stats = client.v1.get_tenant_sessions_stats(tenant_name="sys")
print(f"Total sessions: {stats.total_count}")
print(f"Active sessions: {stats.active_count}")
print(f"User stats: {stats.user_stats}")
print(f"DB stats: {stats.db_stats}")
```
