# 更新凭据

本文介绍如何通过 obshell-sdk-python 更新凭据。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>建议先查看 <a href='../100.quickstart-of-python.md'>obshell-sdk-python 快速上手</a> 内容，了解如何使用 obshell-sdk-python。</p>
</main>

## 注意事项

* 请确保 obshell 正常运行。

* 请求的 client 对应的节点需在已初始化的集群中。

## 示例代码

```python
from obshell import ClientSet
from obshell.auth import PasswordAuth
from obshell.model import SshTarget

# 创建 client 实例
client = ClientSet("10.10.10.1", 2886, PasswordAuth("****"))

# 更新凭据
targets = [SshTarget({"ip": "10.10.10.2", "port": 22})]
credential = client.v1.update_credential(
    credential_id=1,
    name="updated_credential",
    username="admin",
    targets=targets,
    passphrase="new_password",
    description="Updated credential"
)
print(f"Updated credential: {credential.name}")
```
