# 本地集群命令行工具 OceanBase Shell V4.3.2.0

## 版本信息

* 前置版本：obshell V4.3.2.1

* 发布时间：2025 年 9 月 25 日

* 版本号：V4.3.2.0

* RPM 版本号：obshell-4.3.2.0-52025092411

## 新增特性

### OB-Dashboard 新增功能

1. 备份恢复管理：支持租户级别的备份与恢复功能。

2. 告警中心：支持集成统一的告警管理与通知系统。

3. 性能监控：支持集群和租户级别的精细化性能监控。
   
4. 租户创建优化：增强创建流程，支持业务负载类型、时区、大小写敏感（MySQL 租户）等配置选项。

### obshell 新增功能

1. 多租户支持：支持创建和管理 Oracle 类型租户。

2. 监控集成：支持 Prometheus 和 Alertmanager 组件配置，并提供完整的性能监控与告警解决方案。


## 修复问题

1. 修复若干 OB-Dashboard 的页面展示问题。

2. 修复获取租户可恢复时间区间不准的问题。
