## 安全漏洞修复

1. 修复间接依赖组件 babel-traverse 的 Babel 安全漏洞。

2. 修复 SheetJS 安全漏洞。

3. 修复 Mock.js 安全漏洞。

4. 删除 Axios 依赖，修复 Axios 跨站请求伪造漏洞、Axios 安全漏洞、Axios 代码问题漏洞，Regular Expression Denial of Service (ReDoS)。

5. 修复 ServerConfig 中 PublicKeyCallback 授权绕过漏洞、Google Go 拒绝服务漏洞。

6. 修复 Google Go 安全漏洞、解析函数拒绝服务漏洞、Google Go 安全漏洞。漏洞编号为：CVE-2025-22870，CVE-2024-45338，CVE-2025-22872。

7. 修复 PGX 安全漏洞。

8. 修复 Google Go 资源分配未加限制漏洞。

9. 修复 Azure Identity Libraries 和 Microsoft Authentication Library 权限提升漏洞。

10. 修复 HashiCorp go-retryablehttp 日志信息泄露漏洞。
