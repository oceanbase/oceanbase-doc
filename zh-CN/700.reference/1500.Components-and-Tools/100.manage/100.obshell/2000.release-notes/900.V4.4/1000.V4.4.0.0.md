# 本地集群命令行工具 OceanBase Shell V4.4.0.0

## 版本信息

* 发布时间：2026 年 1 月 7 日

* 版本号：V4.4.0.0

* RPM 版本号：obshell-4.4.0.0-32026010814

## 新增特性

1. 基于 obdiag 提供集群及租户巡检功能，帮忙用户提前发现系统隐患，提升系统稳定性。具体操作可参见 [巡检服务管理](../../350.ob-dashboard/480.inspection-service.md)。
   支持从系统内核参数、内部表等方式对 OceanBase 集群进行分析，发现已存在或可能会导致集群出现异常问题。

2. 支持会话管理能力，具体操作可参见 [会话管理](../../350.ob-dashboard/400.ob-dashboard-tenant/450.session-management.md)。具体功能包括：

   * 会话操作：支持关闭指定会话、中止当前查询等精细化控制。
  
   * 会话分析：提供会话统计功能，全面掌握连接状态和资源消耗情况。

   * 死锁管理：支持开启/关闭死锁检测机制，并可追溯查看死锁历史记录。

3. 支持凭据管理能力，具体操作可参见 [凭据管理](../../350.ob-dashboard/650.credential-management.md)。具体功能包括：

   * 凭据生命周期管理：实现主机凭据的新建、编辑、删除完整流程。

   * 批量操作：支持凭据的批量验证和批量删除，提升管理效率。

4. 支持软件包删除功能，通过清理不必要的软件包，优化系统存储空间。具体操作可参见 [软件包管理](../../350.ob-dashboard/600.ob-dashboard-package.md)。

5. 集群停止前默认开启转储功能，通过预转储机制显著加快集群重新启动的速度。
