# 查询租户会话列表

本文介绍如何通过 API 查询租户的会话列表，支持分页、过滤和排序功能。

## 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

### 请求路径

GET /api/v1/tenant/:name/sessions

### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| name | string | 是 | t1 | 租户名称。该参数通过路径参数指定。 |
| page | uint64 | 否 | 1 | 页码，默认为 1。该参数通过 query param 指定。 |
| size | uint64 | 否 | 10 | 每页大小，默认为 2147483647。该参数通过 query param 指定。 |
| user | string | 否 | root | 数据库用户名。该参数通过 query param 指定。 |
| db | string | 否 | test | 数据库名称。该参数通过 query param 指定。 |
| host | string | 否 | 10.10.10.1 | 客户端主机地址 IP。该参数通过 query param 指定。 |
| id | uint64 | 否 | 12345 | 会话 ID。该参数通过 query param 指定。 |
| observer_list | string | 否 | 10.10.10.1,10.10.10.2 | OBServer 节点列表，多个 IP 用逗号分隔。该参数通过 query param 指定。 |
| active_only | boolean | 否 | true | 是否仅查询活跃会话。该参数通过 query param 指定。 |
| sort | string | 否 | time,desc | 排序参数，格式为 "字段名,排序顺序"（如 "time,desc"）。该参数通过 query param 指定。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | PaginatedTenantSessions | 返回的分页会话列表，包含如下信息：<ul><li>`contents`：会话列表。详情参见下文 **TenantSession 的数据结构**。</li><li>`page`：分页信息。详情参见下文 **CustomPage 的数据结构**。</li></ul> |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

TenantSession 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int64 | 会话 ID。 |
| svr_ip | string | 服务器 IP 地址。 |
| svr_port | int64 | 服务器端口。 |
| sql_port | int64 | SQL 端口。 |
| user | string | 数据库用户名。 |
| db | string | 数据库名称。 |
| tenant | string | 租户名称。 |
| host | string | 客户端主机地址（格式：IP:端口）。 |
| command | string | 当前执行的命令。 |
| time | float64 | 会话持续时间（秒）。 |
| state | string | 会话状态，例如 `ACTIVE`。 |
| info | string | 当前执行的 SQL 语句。 |
| proxy_sess_id | int64 | 代理会话 ID。 |
| proxy_ip | string | 代理 IP 地址（当 ProxySessId 不为空时从 Host 解析）。 |
| action | string | 动作。 |
| module | string | 模块。 |
| client_info | string | 客户端信息。 |
| level | int64 | 级别。 |
| sample_percentage | int | 采样百分比。 |
| record_policy | string | 记录策略。 |
| sql_id | string | SQL ID。 |
| total_cpu_time | int64 | 总 CPU 时间。 |
| memory_usage | int64 | 内存使用量。 |

CustomPage 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| total_elements | uint64 | 总记录数。 |
| total_pages | uint64 | 总页数。 |
| size | uint64 | 每页大小。 |
| number | uint64 | 当前页码。 |
