# 凭证管理

## 创建凭据

介绍如何通过 API 创建凭据。创建凭据时会进行 SSH 验证，密码会被加密存储。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

POST /api/v1/security/credential

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| target_type | string | 是 | HOST | 目标类型，目前仅支持 "HOST"。 |
| name | string | 是 | my-credential | 凭据名称。 |
| description | string | 否 | SSH credential for hosts | 凭据描述。 |
| ssh_credential_property | SshCredentialProperty | 是 | - | SSH 凭据属性。详情参见下文 **SshCredentialProperty 的数据结构。** |

SshCredentialProperty 的数据结构：

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| targets | []Target | 是 | [{"ip": "10.10.10.1", "port": 22}] | 目标主机列表，每个 Target 包含 ip 和 port。如果未提供 port，默认端口为 22。列表不能为空，必须包含至少一个目标。 |
| username | string | 是 | root | SSH 连接的用户名。 |
| type | string | 是 | PASSWORD | 认证类型，目前仅支持 "PASSWORD"。 |
| passphrase | string | 是 | password123 | SSH 连接的密码（明文，存储前会被加密），可以为空。 |

Target 的数据结构：

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| ip | string | 是 | 10.10.10.1 | IP 地址。 |
| port | int | 否 | 22 | 端口号，如果未提供，默认为 22。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | Credential | 返回的凭据信息。详情参见下文 **Credential 的数据结构。** |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

Credential 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| credential_id | int64 | 凭据 ID。 |
| name | string | 凭据名称。 |
| target_type | string | 目标类型。 |
| description | string | 凭据描述。 |
| ssh_secret | SshSecret | SSH 密钥信息（不包含密码）。详情参见下文 **SshSecret 的数据结构。** |
| create_time | time.Time | 创建时间。 |
| update_time | time.Time | 更新时间。 |

SshSecret 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| targets | []Target | 目标主机列表。 |
| username | string | 用户名。 |
| type | string | 认证类型。 |

### 示例

#### 请求示例

POST 10.10.10.1:2886/api/v1/security/credential

```json
{
    "target_type": "HOST",
    "name": "my-credential",
    "description": "SSH credential for hosts",
    "ssh_credential_property": {
        "targets": [
            {
                "ip": "10.10.10.1",
                "port": 22
            }
        ],
        "username": "root",
        "type": "PASSWORD",
        "passphrase": "password123"
    }
}
```

#### 返回示例

```json
{
    "successful": true,
    "timestamp": "2025-10-14T15:14:01.277047628+08:00",
    "duration": 36,
    "status": 200,
    "traceId": "e6f64ba7f54e7a47",
    "data": {
        "credential_id": 1,
        "name": "my-credential",
        "target_type": "HOST",
        "description": "SSH credential for hosts",
        "ssh_secret": {
            "targets": [
                {
                    "ip": "10.10.10.1",
                    "port": 22
                }
            ],
            "username": "root",
            "type": "PASSWORD"
        },
        "create_time": "2025-10-14T15:14:01.277047628+08:00",
        "update_time": "2025-10-14T15:14:01.277047628+08:00"
    }
```

## 查询凭据列表

介绍如何通过 API 查询凭据列表，支持过滤、分页和排序功能。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

GET /api/v1/security/credentials

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| credential_id | int | 否 | 1 | 凭据 ID。该参数通过 `query param` 指定。 |
| target_type | string | 否 | HOST | 目标类型，目前仅支持 "HOST"。该参数通过 `query param` 指定。 |
| key_word | string | 否 | my | 关键字，用于搜索凭据名称或用户名。该参数通过 `query param` 指定。 |
| page | int | 否 | 1 | 页码，默认为 1。该参数通过 `query param` 指定。 |
| page_size | int | 否 | 10 | 每页大小，默认为 10。该参数通过 `query param` 指定。 |
| sort | string | 否 | create_time | 排序字段。该参数通过 `query param` 指定。 |
| sort_order	string | string | 否 | desc | 排序顺序（asc/desc）。该参数通过 `query param` 指定。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | PaginatedCredentialResponse | 返回的分页凭据列表。详情参见下文 **PaginatedCredentialResponse 的数据结构**。 |

PaginatedCredentialResponse 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| contents | []Credential | 凭据列表。详情参见上文 **Credential 的数据结构**。 |
| page | CustomPage | 分页信息。详情参见下文 **CustomPage 的数据结构**。 |

CustomPage 的数据结构：

| total_elements | uint64 | 总记录数。 |
| total_pages | uint64 | 总页数。 |
| size | uint64 | 每页大小。 |
| number | uint64 | 当前页码。 |

## 验证凭据

介绍如何通过 API 验证凭据的有效性。验证操作不会存储凭据，仅用于测试 SSH 连接是否成功。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

POST /api/v1/security/credential/validate

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| target_type | string | 是 | HOST | 目标类型，目前仅支持 "HOST"。 |
| ssh_credential_property | SshCredentialProperty | 是 | - | SSH 凭据属性。详情参见上文 **SshCredentialProperty 的数据结构**。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | ValidationResult | 返回的验证结果。详情参见下文 **ValidationResult 的数据结构**。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

ValidationResult 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| target_type | string | 目标类型，例如 "HOST"。 |
| succeeded_count | int | 成功验证的目标数量。 |
| failed_count | int | 失败验证的目标数量。 |
| details | []ValidationDetail | 验证详情，每个目标一个详情。详情参见下文 **ValidationDetail 的数据结构**。 |

ValidationDetail 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| target | Target | 目标信息，包含 ip 和 port。详情参见上文 **Target 的数据结构**。 |
| connection_result | string | 连接结果，例如 "SUCCESS"、"CONNECT_FAILED" 等（用于扩展性）。 |
| message | string | 错误信息（验证成功时为空字符串）。 |

### 示例

POST 10.10.10.1:2886/api/v1/security/credential/validate

```json
{
    "target_type": "HOST",
    "ssh_credential_property": {
        "targets": [
            {
                "ip": "10.10.10.1",
                "port": 22
            }
        ],
        "username": "root",
        "type": "PASSWORD",
        "passphrase": "password123"
    }
}
```

#### 返回示例

```json
{
    "successful": true,
    "timestamp": "2025-10-14T15:19:01.277047628+08:00",
    "duration": 1500,
    "status": 200,
    "traceId": "e6f64ba7f54e7a53",
    "data": {
        "target_type": "HOST",
        "succeeded_count": 1,
        "failed_count": 0,
        "details": [
            {
                "target": {
                    "ip": "10.10.10.1",
                    "port": 22
                },
                "connection_result": "SUCCESS",
                "message": ""
            }
        ]
    }
}
```

## 更新凭据加密密钥

介绍如何通过 API 更新凭据的 AES 加密密钥。更新密钥后，系统会使用新密钥重新加密所有已存储的凭据密码。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

PUT /api/v1/security/credential/encrypt-secret-key

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| aes_key | string | 是 | dGhpc2lzYXRlc3RrZXk= | 新的 AES 密钥（Base64 编码的原始密钥字节）。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | - | 无返回数据。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

PUT 10.10.10.1:2886/api/v1/security/credential/encrypt-secret-key

```json
    "aes_key": "dGhpc2lzYXRlc3RrZXk="
}
```
