# 巡检服务

## 触发巡检

本章节介绍如何通过 API 触发集群巡检。巡检支持基础巡检（basic）和性能巡检（performance）两种场景。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

POST /api/v1/obcluster/inspection

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| scenario | string | 是 | basic | 巡检场景，支持以 "basic"（基础巡检）或 "performance"（性能巡检）。大小写不敏感。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | DagDetailDTO | 返回的任务 DAG 详情。详情参见下文 **DagDetailDTO 的数据结构**。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

DagDetailDTO 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | string | DAG 通用 ID。 |
| dag_id | int | DAG id，是记录在 OceanBase 数据库中的主键。 |
| name | string | DAG 名称。 |
| stage | int | DAG 的当前执行阶段。 |
| max_stage | int | DAG 执行过程中的总阶段数。 |
| state | string | DAG 执行状态。 |
| operator | string | DAG 执行操作类型。 |
| start_time | time.Time | DAG 执行起始时间。 |
| end_time | time.Time | DAG 执行结束时间。 |
| additional_data | map[string]any | DAG 其他数据。 |
| nodes | []NodeDetailDTO | DAG 内的所有 Node 信息，详见 获取 Node 的详细信息。 |

### 示例

#### 请求示例

POST 10.10.10.1:2886/api/v1/obcluster/inspection

```json
{
    "scenario": "basic"
}
```

## 查询巡检历史

本章节介绍如何通过 API 查询巡检历史记录，支持分页、过滤和排序功能。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

GET /api/v1/obcluster/inspection/reports

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| page | int | 否 | 1 | 页码，默认为 1。该参数通过 `query param` 指定。 |
|  | int | 否 | 10 | 每页大小，默认为 10。该参数通过 `query param` 指定。 |
| scenario | string | 是 | basic | 场景过滤，支持 "basic" 或 "performance"。该参数通过 `query param` 指定。 |
| sort | string | 否 | start_time,desc | 排序参数，格式为 "字段名,排序顺序"（如 "start_time,desc"），默认为 "start_time,desc"。该参数通过 `query param` 指定。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | PaginatedInspectionHistoryResponse | 返回的分页巡检历史列表。详情参见下文 **PaginatedInspectionHistoryResponse** 的数据结构。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

PaginatedInspectionHistoryResponse 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| contents | []InspectionReportBriefInfo | []InspectionReportBriefInfo	巡检报告简要信息列表。详情参见下文 **InspectionReportBriefInfo** 的数据结构。 |
| page | CustomPage | 分页信息。详情参见下文 **CustomPage** 的数据结构。 |

InspectionReportBriefInfo 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 巡检报告 ID。 |
| scenario | string | 巡检场景，例如 "basic" 或 "performance"。 |
| critical_count | int | 严重问题数量。 |
| failed_count | int | 失败项数量。 |
| warning_count | int | 警告项数量。 |
| pass_count | int | 通过项数量。 |
| start_time | time.Time | 开始时间。 |
| finish_time | time.Time | 完成时间。 |
| local_task_id | string | 本地任务 ID。 |
| status | string | 状态。 |
| error_message | string | 错误信息。 |

CustomPage 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| total_elements | uint64 | 总记录数。 |
| total_pages | uint64 | 总页数。 |
| size | uint64 | 每页大小。 |
| number | uint64 | 当前页码。 |

### 示例

#### 请求示例

GET 10.10.10.1:2886/api/v1/obcluster/inspection/reports?page=1&size=10&scenario=basic&sort=start_time,desc

## 获取巡检报告

本章节介绍如何通过 API 根据巡检报告 ID 获取详细的巡检报告信息。

### 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

#### 请求路径

GET /api/v1/obcluster/inspection/report/:id

#### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| id | string | 是 | 1 | 巡检报告 ID。该参数通过路径参数指定。 |

#### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | InspectionReport | 返回的巡检报告详情。详情参见下文 **InspectionReport** 的数据结构。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

InspectionReport 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 巡检报告 ID。 |
| scenario | string | 巡检场景，例如 "basic" 或 "performance"。 |
| critical_count | int | 严重问题数量。 |
| failed_count | int | 失败项数量。 |
| warning_count | int | 警告项数量。 |
| pass_count | int | 通过项数量。 |
| start_time | time.Time | 开始时间。 |
| finish_time | time.Time | 完成时间。 |
| local_task_id | string | 本地任务 ID。 |
| status | string | 状态。 |
| error_message | string | 错误信息。 |
| result_detail | ResultDetail | 结果详情。详情参见下文 **ResultDetail 的数据结构**。 |

ResultDetail 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| critical_items | []InspectionItem | 严重问题项列表。详情参见下文 **InspectionItem 的数据结构**。 |
| warning_items | []InspectionItem | 警告项列表。详情参见下文 **InspectionItem 的数据结构**。 |
| failed_items | []InspectionItem | 失败项列表。详情参见下文 **InspectionItem 的数据结构**。 |
| pass_items | []InspectionItem | 通过项列表。详情参见下文 **InspectionItem 的数据结构**。 |

InspectionItem 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 巡检项名称。 |
| results | []string | 巡检结果列表。 |
