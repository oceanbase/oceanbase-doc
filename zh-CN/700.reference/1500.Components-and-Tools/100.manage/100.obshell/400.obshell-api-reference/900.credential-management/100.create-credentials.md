# 创建凭据

本文介绍如何通过 API 创建用于 **连接集群内节点所位于的主机** 的连接凭据。创建凭据时会进行 SSH 验证，密码会被加密存储。

## 调用说明

### 接口约束

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

### 请求路径

POST /api/v1/security/credential

### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| target_type | string | 是 | HOST | 目标类型，目前仅支持 "HOST"。 |
| name | string | 是 | my-credential | 凭据名称。 |
| description | string | 否 | SSH credential for hosts | 凭据描述。 |
| ssh_credential_property | SshCredentialProperty | 是 | - | SSH 凭据属性。详情参见下文 **SshCredentialProperty 的数据结构。** |

SshCredentialProperty 的数据结构：

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| targets | []Target | 是 | [{"ip": "10.10.10.1", "port": 22}] | 目标主机列表，每个 Target 包含 ip 和 port。详情参见下文 **Target 的数据结构**。 |
| username | string | 是 | root | SSH 连接的用户名。 |
| type | string | 是 | PASSWORD | 认证类型，目前仅支持 "PASSWORD"。 |
| passphrase | string | 是 | *********** | SSH 连接的密码（明文，存储前会被加密），可以为空。 |

Target 的数据结构：

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| ip | string | 是 | 10.10.10.1 | IP 地址。 |
| port | int | 否 | 22 | 端口号，如果未提供，默认为 22。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | Credential | 返回的凭据信息。详情参见下文 **Credential 的数据结构。** |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

Credential 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| credential_id | int64 | 凭据 ID。 |
| name | string | 凭据名称。 |
| target_type | string | 目标类型。 |
| description | string | 凭据描述。 |
| ssh_secret | SshSecret | SSH 密钥信息（不包含密码）。详情参见下文 **SshSecret 的数据结构。** |
| create_time | time.Time | 创建时间。 |
| update_time | time.Time | 更新时间。 |

SshSecret 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| targets | []Target | 目标主机列表。 |
| username | string | 用户名。 |
| type | string | 认证类型。 |

## 示例

### 请求示例

POST 10.10.10.1:2886/api/v1/security/credential

```json
{
    "target_type": "HOST",
    "name": "my-credential",
    "description": "SSH credential for hosts",
    "ssh_credential_property": {
        "targets": [
            {
                "ip": "10.10.10.1",
                "port": 22
            }
        ],
        "username": "root",
        "type": "PASSWORD",
        "passphrase": "********"
    }
}
```
