# 更新凭据加密密钥

本文介绍如何通过 API 更新凭据的 AES 加密密钥。更新密钥后，系统会使用新密钥重新加密所有已存储的凭据密码。

## 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

### 请求路径

PUT /api/v1/security/credential/encrypt-secret-key

### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| aes_key | string | 是 | dG***********Xk= | 新的 AES 密钥（Base64 编码的原始密钥字节）。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

## 示例

### 请求示例

PUT 10.10.10.1:2886/api/v1/security/credential/encrypt-secret-key

```json
{
    "aes_key": "dG***********Xk="
}
```

### 返回示例

```json
{
    "successful": true,
    "timestamp": "2025-10-14T15:21:01.277047628+08:00",
    "duration": 500,
    "status": 200,
    "traceId": "e6f64ba7f54e7a55"
}
```
