# 验证凭据

本文介绍如何通过 API 验证凭据的有效性。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>验证操作不会存储凭据，仅用于测试 SSH 连接是否成功。</p>
</main>

## 调用说明

如果设置了密码，则需要通过认证。详情可参见 [API 混合加密](../20.api-hybrid-encryption.md)。

### 请求路径

POST /api/v1/security/credential/validate

### 请求参数

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| target_type | string | 是 | HOST | 目标类型，目前仅支持 "HOST"。 |
| ssh_credential_property | SshCredentialProperty | 是 | - | SSH 凭据属性。详情参见下文 **SshCredentialProperty 的数据结构**。 |

SshCredentialProperty 的数据结构：

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| targets | []Target | 是 | [{"ip": "10.10.10.1", "port": 22}] | 目标主机列表，每个 Target 包含 ip 和 port。如果未提供 port，默认端口为 22。列表不能为空，必须包含至少一个目标。 |
| username | string | 是 | root | SSH 连接的用户名。 |
| type | string | 是 | PASSWORD | 认证类型，目前仅支持 "PASSWORD"。 |
| passphrase | string | 是 | *********** | SSH 连接的密码（明文，存储前会被加密），可以为空。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | bool | 请求是否成功。 |
| timestamp | time.Time | 服务端完成请求的时间戳。 |
| duration | int | 服务端处理请求的时间（毫秒）。 |
| status | int | 符合 HTTP Status 规范的编码。 |
| traceId | string | 请求的 Trace ID。 |
| data | ValidationResult | 返回的验证结果。详情参见下文 **ValidationResult 的数据结构**。 |
| error | ApiError | 请求产生的 Error，包含如下信息：<ul><li>`code`：错误码。</li><li>`message`：错误详细信息。</li><li>`subErrors`：子错误信息。</li></ul> |

ValidationResult 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| target_type | string | 目标类型，例如 "HOST"。 |
| succeeded_count | int | 成功验证的目标数量。 |
| failed_count | int | 失败验证的目标数量。 |
| details | []ValidationDetail | 验证详情，每个目标一个详情。详情参见下文 **ValidationDetail 的数据结构**。 |

ValidationDetail 的数据结构：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| target | Target | 目标信息，包含 ip 和 port。详情参见下文 **Target 的数据结构**。 |
| connection_result | string | 连接结果，例如 "SUCCESS"、"CONNECT_FAILED" 等（用于扩展性）。 |
| message | string | 错误信息（验证成功时为空字符串）。 |

Target 的数据结构：

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| ip | string | 是 | 10.10.10.1 | IP 地址。 |
| port | int | 否 | 22 | 端口号，如果未提供，默认为 22。 |

## 示例

### 请求示例

POST 10.10.10.1:2886/api/v1/security/credential/validate

```json
{
    "target_type": "HOST",
    "ssh_credential_property": {
        "targets": [
            {
                "ip": "10.10.10.1",
                "port": 22
            }
        ],
        "username": "root",
        "type": "PASSWORD",
        "passphrase": "***********"
    }
}
```

### 返回示例

```json
{
    "successful": true,
    "timestamp": "2025-10-14T15:19:01.277047628+08:00",
    "duration": 1500,
    "status": 200,
    "traceId": "e6f64ba7f54e7a53",
    "data": {
        "target_type": "HOST",
        "succeeded_count": 1,
        "failed_count": 0,
        "details": [
            {
                "target": {
                    "ip": "10.10.10.1",
                    "port": 22
                },
                "connection_result": "SUCCESS",
                "message": ""
            }
        ]
    }
}
```
