# 巡检服务管理

单击左侧导航栏 **巡检服务** 进入 **巡检服务** 页面。本节介绍如何使用 obshell Dashboard 发起巡检。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>obshell 自 V4.4.0 起支持巡检服务功能，您可访问 <a href="https://mirrors.aliyun.com/oceanbase/community/stable/el/?spm=a2c6h.25603864.0.0.1f4328b3mIcuek">阿里云镜像站</a> 获取相应安装包，使用 obshell 直接进行升级，升级操作详参：<a href="300.ob-dashboard-cluster/500.ob-dashboard-obshell-upgrade.md">升级 obshell</a>。</p>
</main>

您可在巡检服务页面查看巡检任务的 ID、巡检场景、开始时间、结束时间、任务状态、巡检结果、操作。您可以单击 **巡检场景** 后的图标，对巡检场景进行筛选。也可以单击 **开始时间** 或 **结束时间** 后的排序图标，选择按照升序、降序方式展示巡检任务信息。

| 参数  | 说明  |
|-------|------|
| ID | 巡检任务的唯一标识。 |
| 巡检场景 | 分为 **基础巡检** 和 **性能巡检** 两种。基础巡检和性能巡检的具体巡检任务介绍详见 [触发巡检](../400.obshell-api-reference/750.inspection-service-management/100.trigger-inspection.md)。 |
| 开始时间 | 巡检任务的开始时间。 |
| 结束时间 | 巡检任务的结束时间。  |
| 任务状态 | 分为 **成功**、**失败**、**运行中** 三种状态。  |
| 巡检结果 | <ul><li>当巡检任务的状态为 **成功** 时，将展示 **失败**、**高风险**、**中风险** 的巡检结果个数。</li><li>当巡检任务的状态为 **失败** 时，巡检结果为空。</li></ul>  |
| 操作 | <ul><li>当巡检任务的状态为 **成功** 时，可单击 **查看报告** 查看巡检报告。</li><li>当巡检任务的状态为 **失败** 时，可单击 **错误信息** 查看具体错误信息。</li></ul>  |

## 发起巡检

将光标悬停在 **巡检服务** 页面右上角的 **发起巡检** 按钮，在下拉列表中选择 **基础巡检** 或 **性能巡检**，即可发起基础巡检或性能巡检。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>在发起巡检服务前，需确保已在任一 OBServer 节点安装 obdiag V3.7.2 或以上版本，或已在 <b>软件包管理</b> 上传 obdiag V3.7.2 或以上版本的安装包，否则无法成功发起巡检并提示“工作目录或系统路径下不存在可用的 obdiag(>=3.7.2)，请上传或安装（升级）oceanbase-diagnostic-tool 包，前往 <b>软件包管理</b>”。obdiag 安装方法详见文档 <a href="https://www.oceanbase.com/docs/common-obdiag-cn-1000000004494302">obdiag 安装</a>。</p>
</main>

## 查看巡检报告

单击巡检任务操作列的 **查看报告**，将跳转到 **巡检报告** 详情页。**巡检报告** 详情页包括基本信息、巡检结果概览、结果概览和全部结果四部分，展示了巡检报告的具体信息。

* 基本信息栏展示了巡检任务的巡检场景、开始时间、结束时间。

* 巡检结果概览页展示了巡检任务的总巡检结果、高风险结果、中风险结果、失败结果的个数。

* 结果概览页签展示了巡检结果大致概览，分为高风险巡检项和巡检结果、中风险巡检项和巡检结果、失败目标对象。

* 全部结果页签展示了每一个巡检项及对应的巡检结果。
