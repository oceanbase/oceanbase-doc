# 凭据管理

单击左侧导航栏 **系统管理** > **凭据管理** 进入 **凭据管理** 页面。本节介绍如何新建 obshell Dashboard 连接主机的凭据。

## 新建凭据

单击 **凭据管理** 页面右上方 **新建凭据** 按钮，在弹出的 **新建凭据** 对话框填写凭据相关信息。设置完成后单击 **确定** 即完成新建。

![新建凭据](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E6%96%B0%E5%BB%BA%E5%87%AD%E6%8D%AE.png)

| 对象类型  | 填写信息  |
|-------|------|
| 凭据名 | 设置新建凭据的名称，用户名需满足如下要求：<ul><li>长度为 2 ~ 64 个字符。</li><li>可包含小写英文字母、数字和下划线，但需以英文字母开头。</li><li>需确保凭据名唯一。</li></ul> |
| 用户类型 | 包括 **root 用户** 和 **普通用户** 两种类型。 |
| 用户名 | 新建凭据使用的用户名。若所选用户类型为 **root 用户** 时，则不需要填写用户名。 |
| 密码 | 用户名中配置用户的登录密码。<main id="notice" type='explain'><h4>说明</h4><p>目前凭据对象的授权类型仅支持密码验证，需确保使用该用户名和用户密码可以成功连接该凭据对象的应用主机。</p></main> |
| 应用主机 | 新建凭据中主机的 IP 地址。 |
| ssh 端口 | 主机间 ssh 所用端口。 |
| 说明（可选） | 可添加凭据对象说明，方便后续查看识别以及使用。 |

## 验证凭据

在 **凭据管理** 页面的凭据列表中找到需要验证的凭据对象，单击该凭据对象 **操作** 列的 **验证** 按钮，若凭据验证成功，页面上方会提示 **验证成功**，该凭据对象凭据名后将展示 **验证成功** 标签；若验证失败，您需重新输入凭据信息。

![验证凭据](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E9%AA%8C%E8%AF%81%E5%87%AD%E6%8D%AE.png)

## 编辑凭据

在 **凭据管理** 页面的凭据列表中找到需要验证的凭据，将光标悬停或单击该凭据 **操作** 列的 **...** 按钮，单击出现的 **编辑** 按钮，在弹出的 **编辑凭据** 对话框中修改凭据信息，包括 **凭据名**、**用户类型**、**用户名**、**密码**、**应用主机** 和 **说明**。修改完成后单击 **确定** 即完成编辑。

![编辑凭据](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E7%BC%96%E8%BE%91%E5%87%AD%E6%8D%AE.png)

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>同时勾选多个凭据，可批量编辑多个凭据。</p>
</main>

## 删除凭据

在 **凭据管理** 页面的凭据列表中找到需要验证的凭据对象，将光标悬停或单击该凭据对象 **操作** 列的 **...** 按钮，单击出现的 **删除** 按钮，在跳出的二次确认框中单击 **删除**，即成功删除凭据对象。

![删除凭据](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/650.credential-management-%E5%88%A0%E9%99%A4%E5%87%AD%E6%8D%AE.png)

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>同时勾选多个凭据，可批量删除多个凭据。</p>
</main>
