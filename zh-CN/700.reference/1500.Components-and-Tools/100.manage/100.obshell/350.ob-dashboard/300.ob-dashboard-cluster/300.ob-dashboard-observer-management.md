# 管理 OBServer

本文为您介绍目前支持的管理 OBServer 节点的操作，包含启停 OBServer 节点服务、启停 OBServer 进程。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><ul><li>停止 OBServer 节点服务指后台通过 <code>alter system stop server 'xx.xx.xx.xx:xxxx'</code> 命令隔离节点，可能会导致切主等动作，不会直接停止 OBServer 进程，隔离节点前的限制详参：<a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004476050">隔离节点</a>。停止 OBServer 进程指直接 kill OBServer 进程，将强制杀掉 OBServer 进程。</li><li>obshell Dashboard 自 V4.4.1 起支持启停 OBServer 节点服务和 OBServer 进程，您可访问 <a href="https://mirrors.aliyun.com/oceanbase/community/stable/el/?spm=a2c6h.25603864.0.0.1f4328b3mIcuek">阿里云镜像站</a> 获取相应安装包，使用 obshell Dashboard 直接进行升级，升级操作详参：<a href="../300.ob-dashboard-cluster/500.ob-dashboard-obshell-upgrade.md">升级 obshell</a>。</li></ul></p>
</main>

## 停止 OBServer 节点服务

停止 OBServer 节点服务会将所有流量和主副本的角色切到其他 OBServer 节点，请谨慎操作。

### 操作步骤

1. 登录 obshell Dashboard。

2. 在左侧导航栏单击 **集群管理**，进入 **集群管理** 页面。

3. 在 **拓扑结构** 模块，光标悬停于对应 OBServer 节点 **操作** 列的 **···** 上，单击出现的 **停止服务**。

   ![停止服务](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.1/300.ob-dashboard-observer-management-%E5%81%9C%E6%AD%A2%E6%9C%8D%E5%8A%A1.png)

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p><ul><li>不允许同时启停多个 OBServer 节点服务。</li><li>不允许同时在多个 Zone 内停止 OBServer 节点服务，如果已存在 Zone 内 OBServer 节点服务被停止，再次停止其它 Zone 内的 OBServer 节点服务将报错。</li></ul></p>
   </main>

4. 在弹出的二次确认框中单击 **停止服务**。

5. 任务提交后，您可通过弹出框中的 **查看任务** 按钮，查看停止进度；也可在 **任务中心** 中查看该任务的进度。

   当该任务状态为 **完成**，且 **拓扑结构** 模块的 IP 列表中该 OBServer 节点的状态为 **服务已停止** 时，则停止成功。

6. 如您需启用该 OBServer 节点服务，可将光标悬停 **拓扑结构** 模块对应 OBServer 节点 IP 列表 **操作** 列的 **···**，单击出现的 **启动**，重新进行启用。

## 停止 OBServer 进程

停止 OBServer 进程会导致 OBServer 节点不可用，无法提供服务，请谨慎操作。

### 操作步骤

1. 登录 obshell Dashboard。

2. 在左侧导航栏单击 **集群管理**，进入 **集群管理** 页面。

3. 在 **拓扑结构** 模块，光标悬停于对应 OBServer 节点 **操作** 列的 **···** 上，单击出现的 **停止进程**。

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p><ul><li>不允许同时启停多个 OBServer 进程。</li><li>不允许同时在多个 Zone 内停止 OBServer 进程，如果已存在 Zone 内的 OBServer 进程被停止，再次停止其它 Zone 内的 OBServer 进程将报错。</li></ul></p>
   </main>

4. 在弹出的二次确认框中，选择是否在停止进程前执行转储操作（默认执行），并单击 **停止进程**。

   ![停止进程](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.1/300.ob-dashboard-observer-management-%E5%81%9C%E6%AD%A2%E8%BF%9B%E7%A8%8B.png)

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>停止 OBServer 进程前执行转储操作会延长停止进程的响应时间，但可以显著缩短 OBServer 节点启动时间。</p>
   </main>

5. 任务提交后，您可通过弹出框中的 **查看任务** 按钮，查看停止进度；也可在 **任务中心** 中查看该任务的进度。

   当该任务状态为 **完成**，且 **拓扑结构** 模块的 IP 列表中该 OBServer 进程的状态为 **进程已停止** 时，则停止成功。

6. 如您需启用该 OBServer 节点进程，可将光标悬停 **拓扑结构** 模块对应 OBServer 节点 IP 列表 **操作** 列的 **···**，单击出现的 **启动**，重新进行启用。
