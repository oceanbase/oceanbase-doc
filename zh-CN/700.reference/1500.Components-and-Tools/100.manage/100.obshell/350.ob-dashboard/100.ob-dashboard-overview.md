# OB-Dashboard

OB-Dashboard 是一个基于 Web 的 OceanBase 4.x 管理工具，它集成在 OceanBase 数据库集群中，支持数据库集群关键性能指标查看及基本数据库管理功能。OB-Dashboard 脱胎于 OceanBase 云平台（OceanBase Cloud Platform，OCP），在保留云平台核心能力的基础上，调整了整体的功能布局，给予用户全新的使用体验；同时也进一步调整了功能配置，使得 OB-Dashboard 可以以极小的资源消耗部署在任意一台数据库节点上，使得 OB-Dashboard 用户以最小的成本，获取全新的 OceanBase 4.x 管控体验。

## 特性介绍

OB-Dashboard 目前支持 OceanBase 集群管理的以下特性：

* 集群管理：查看 [集群信息](200.ob-dashboard-cluster-overview.md)，包含状态信息、资源消耗、拓扑结构等核心信息，以及 [管理集群](300.ob-dashboard-cluster.md)、[管理参数](500.ob-dashboard-parameter.md) 等功能。

* 租户管理：管理集群下的租户及租户中的数据库、用户和参数，具体介绍可参见 [租户管理](400.ob-dashboard-tenant/100.ob-dashboard-tenant.md) 章节。

* 软件包管理：上传、删除软件包，升级集群和 obshell 需保证已上传目标版本的软件包。具体操作可参见 [软件包管理](600.ob-dashboard-package.md)。

## 登录与退出

obshell 自 V4.3.0.0 起支持白屏管理集群，在成功安装 obshell 后，使用 obshell 节点 IP 和 obshell 端口即可访问 OB-Dashboard（obshell 白屏页面）。访问时默认使用 sys 租户下的 root 用户登录，密码为部署 OceanBase 集群时设置的 root@sys 用户密码，若 root@sys 密码为空，可直接单击 **登录** 按钮登陆。

## 查看版本

登录 OB-Dashboard 控制台后，单击页面右上角 **帮助** > **关于 OB-Dashboard**，即可查看 OB-Dashboard 的版本。
