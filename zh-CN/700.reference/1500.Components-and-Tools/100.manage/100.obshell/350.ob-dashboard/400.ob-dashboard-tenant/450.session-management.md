# 会话管理

在左侧导航栏中单击 **租户管理**，在 **租户管理** 页面单击 **租户列表** 中租户名，进入对应租户 **总览** 页面后单击左侧导航栏 **会话管理**，默认进入 **会话管理** 页面的 **租户会话** 页签。**会话管理** 页面包含 **租户会话**、**会话统计**、**查看死锁历史** 三个页签，本文介绍 **会话管理** 页面的信息及该页面可进行的操作。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>obshell 自 V4.4.0 起支持会话管理功能，您可访问 <a href="https://mirrors.aliyun.com/oceanbase/community/stable/el/?spm=a2c6h.25603864.0.0.1f4328b3mIcuek">阿里云镜像站</a> 获取相应安装包，使用 obshell 直接进行升级，升级操作详参：<a href="../300.ob-dashboard-cluster/500.ob-dashboard-obshell-upgrade.md">升级 obshell</a>。</p>
</main>

## 管理租户会话

**租户会话** 页签展示租户当前的所有会话信息，包括会话 ID 、 SQL 、 SQL ID 、用户、来源、数据库名、命令、执行时间（s）、状态、 OBServer 和 OBProxy。支持按会话 ID 、用户、来源、数据库名检索相应会话。

![租户会话](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E7%A7%9F%E6%88%B7%E4%BC%9A%E8%AF%9D.png)

* 查看 SQL 信息。

  当会话状态为 **ACTIVE** 时，单击 **SQL** 列内容，可在弹窗中查看该会话的 SQL 详情，单击 **复制** 按钮，可直接复制 SQL 信息。

  ![查看SQL信息](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%9F%A5%E7%9C%8B%20SQL%20%E4%BF%A1%E6%81%AF.png)

  ![复制SQL信息](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/obshell/V4.4.0/450.session-management-%E5%A4%8D%E5%88%B6SQL.png)

* 检索会话。

  用户、来源、数据库名这三列支持检索功能。单击列名右侧的放大镜按钮，可打开检索输入框，输入检索的用户或来源、数据库名，单击 **搜索**，将仅展示对应检索对象的所有会话。

  ![检索会话](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%A3%80%E7%B4%A2%E4%BC%9A%E8%AF%9D.png)

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>您也直接可以在 <b>会话管理</b> 页面右上角输入会话 ID 检索对应会话详情。</p>
  </main>

* 查看活跃会话。

  勾选会话列表右上角的 **仅查看活跃会话** 后，会话列表会按照会话状态进行过滤，仅展示状态为 **ACTIVE** 的会话。

  ![查看活跃会话](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%9F%A5%E7%9C%8B%E6%B4%BB%E8%B7%83%E4%BC%9A%E8%AF%9D.png)

* 关闭会话。

  单击会话列表操作列的 **关闭会话**，在弹出的二次确认框中单击 **确定**，可关闭当前会话。勾选单个或多个会话，在 **会话管理** 页面右下角会弹出 **关闭会话** 按钮，单击 **关闭会话** 按钮并在弹出的二次确认框中单击 **确定**，可同时关闭单个或多个会话。

* 关闭当前会话查询。

  在会话列表操作列选择 **···** > **关闭当前查询**，在弹出的二次确认框中单击 **确定**，可关闭当前会话查询。勾选单个或多个会话， **会话管理** 页面右下角会弹出 **关闭当前查询** 按钮，单击弹出的 **关闭当前查询** 按钮并在弹出的二次确认框中单击 **确定**，可同时关闭单个或多个会话查询。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>关闭会话指终止给定的会话 ID（Client Session ID），关闭当前会话查询可终止连接当前正在执行的语句，但是会保持会话连接的原状，详细介绍参见 <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004479616">KILL</a>。</p>
  </main>

## 查看会话统计

单击 **会话管理** 页面上方 **会话统计** 进入相应页签，页面中展示租户当前的所有会话的统计信息。

统计信息包括会话总体情况的统计，例如 **会话总数**、**活跃会话数**、**活跃会话最长时间（s）** 等。同时 **会话统计** 页签按照 **用户**、**访问来源** 和 **数据库** 统计了用户的 **活跃会话数** 和 **会话总数**。

![查看会话统计](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E4%BC%9A%E8%AF%9D%E7%BB%9F%E8%AE%A1.png)

* 支持按照用户、来源、数据库统计相应对象的会话活跃数和总数。例如您可以单击会话统计列表中 **用户** 列名右侧的放大镜按钮，将打开检索输入框，输入检索的用户，单击 **搜索**，将仅展示对应用户的会话活跃数和总数。

* 支持按照 **活跃数** 和 **总数** 的升序、降序方式展示各统计信息。您可以单击会话统计列表的活跃数和总数列后的排序图标，选择按照升序、降序方式展示会话。

* 单击 **用户**、**访问来源** 和 **数据库** 统计信息的总数列的个数，将跳转到相应用户、访问来源、数据库的会话详情，并展示所有统计的会话信息，展示信息及可进行的操作同上文管理租户会话一致，详情请参见上文 [管理租户会话](#管理租户会话)。

## 查看死锁历史信息

单击 **会话管理** 页面上方 **查看死锁历史** 进入相应页签，可查看死锁历史。

![查看死锁历史信息](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-standalone/V4.3.5/obshell/V4.4.0/480.session-management-%E6%9F%A5%E7%9C%8B%E6%AD%BB%E9%94%81%E5%8E%86%E5%8F%B2.png)

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>死锁自动检测是集群级别行为，默认是开启状态，若需关闭死锁自动检测，您可单击 <b>集群管理</b> 页面右上角 <b>···</b>，在下拉列表中单击 <b>关闭死锁自动检测</b> 按钮，在弹出的二次确认框中单击 <b>确定</b> 即可成功关闭。关闭后，可在 <b>集群管理</b> 页面开启死锁自动检测，步骤同关闭一致。</p>
</main>
