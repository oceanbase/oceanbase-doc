# ob_ivf_nprobes

`ob_ivf_nprobes` 用于设置在进行向量索引查询时，本次查询搜索多少个最近的聚类中心。该变量影响 IVF 类查询性能和召回率：值越大，召回率越高，但同时搜索时间也会增加。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该变量从 V4.3.5 BP1 版本开始引入，只支持 MySQL 租户。</p>
</main>

| **属性**  | **描述**  |
|---------|---------|
| 参数类型    | int |
| 默认值     | 8    |
| 取值范围    | [1,65536]    |
| 生效范围    | SESSION |
| 是否参与序列化 | 是       |

**示例**

```sql
SET ob_ivf_nprobes = 10;
```
