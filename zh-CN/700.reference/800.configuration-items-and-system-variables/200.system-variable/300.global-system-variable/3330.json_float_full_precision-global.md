# json_float_full_precision

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该变量从 V4.4.2 BP1 版本开始引入。</p>
</main>

## 功能描述

`json_float_full_precision` 用于控制解析 JSON 中数值的精度模式。

## 权限要求

* 查询变量

  * Global 级别

    `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句或视图 `SYS.TENANT_VIRTUAL_GLOBAL_VARIABLE`（Oracle 模式）及视图 `information_schema.GLOBAL_VARIABLES`（MySQL 模式）查看 Global 系统变量的值。

  * Session 级别

    `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句或视图 `SYS.TENANT_VIRTUAL_SESSION_VARIABLE`（Oracle 模式）及视图 `information_schema.SESSION_VARIABLES`（MySQL 模式）查看 Session 系统变量的值。

* 修改变量

  * Global 生效

    * `sys` 租户可以直接修改 Global 系统变量的值。
    * MySQL 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。
    * Oracle 用户租户需要拥有 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

  * Session 生效

    `sys` 租户和所有用户租户均可以直接修改本租户的 Session 系统变量的值。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型 | Bool |
| 默认值 | False |
| 取值范围 | <ul><li>`True`：表示以高精度解析 JSON 中的数值。</li><li>`False`：表示以低精度解析 JSON 中的数值。</li></ul> |
| 生效范围 | <ul><li>Global</li><li>Session</li></ul> |
| 是否可修改 | 是，支持通过 `SET` 语句修改。|

## 使用说明

`json_float_full_precision` 功能主要是为了在从其他支持类似选项的数据库（如 PolarDB）迁移时，提供兼容性支持。取值如下：

* `True`：表示以高精度解析 JSON 中的数值，但会降低解析速度。
* `False`：表示以低精度解析 JSON 中的数值，解析速度更快。

## 配置示例

* Session 生效：

  * 以低精度解析 JSON 中的数值，速度更快。

      ```shell
      obclient> SET json_float_full_precision = False;
      ```

  * 以高精度解析 JSON 中的数值，速度更慢。

      ```shell
      obclient> SET json_float_full_precision = True;
      ```

* Global 生效：

  * 以低精度解析 JSON 中的数值，速度更快。

      ```shell
      obclient> SET GLOBAL json_float_full_precision = False;
      ```

  * 以高精度解析 JSON 中的数值，速度更慢。

      ```shell
      obclient> SET GLOBAL json_float_full_precision = True;
      ```
