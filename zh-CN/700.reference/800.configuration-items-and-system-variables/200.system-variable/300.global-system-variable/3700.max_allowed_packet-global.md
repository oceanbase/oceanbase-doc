# max_allowed_packet

## 功能描述

`max_allowed_packet` 用于设置最大网络包大小，单位是 Byte。

## 属性说明

| **属性**  |                                                       **描述**                                                       |
|---------|--------------------------------------------------------------------------------------------------------------------|
| 参数类型    | Int                             |
| 默认值     | 16777216 <main id="notice" type='explain'><h4>说明</h4><p>从 V4.2.1 版本开始，默认值由 4194304 调整为 16777216。</p></main>                        |
| 取值范围    | \[1024,1073741824\]             |
| 生效范围    | Global    |
| 是否可修改   | 该变量可通过 `SET GLOBAL` 语句修改 Global 生效方式下的取值，不可通过 `SET SESSION` 语句修改 Session 生效方式下的取值。<br>使用时，客户端与 Server 端一般均需要调整。 |
