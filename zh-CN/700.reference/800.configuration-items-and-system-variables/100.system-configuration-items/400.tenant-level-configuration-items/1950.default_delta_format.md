# default_delta_format

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`default_delta_format` 用于设置创建表时默认的增量数据存储格式。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | String |
| 默认值 | flat |
| 取值范围 | <ul><li>`flat`：flat 数据格式。</li><li>`encoding`：encoding 数据格式。</li></ul> |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

可以通过修改配置项 `default_delta_format` 来调整表的默认增量数据格式，无需建表时反复指定：

* `flat` 格式：写入速度快，压缩率较低，面向 OLTP 场景。
* `encoding` 格式：写入相对较慢，压缩率高，可以提高 OLAP 场景的查询性能，降低增量数据的存储空间，当表的 `MERGE_ENGINE` 为 `delete_insert` 时，查询效果更优。有关设置表 `MERGE_ENGINE` 的信息，可参见 [创建表（MySQL 模式）](../../../300.database-object-management/100.manage-object-of-mysql-mode/200.manage-tables-of-mysql-mode/200.create-a-table-for-mysql-tenant-of-mysql-mode.md) 或 [创建表（Oracle 模式）](../../../300.database-object-management/200.manage-object-of-oracle-mode/100.manage-tables-of-oracle-mode/200.create-a-table-for-oracle-tenant-of-oracle-mode.md) 中 **指定表的更新模型** 章节。

## 配置示例

* 设置用户租户采用 `encoding` 作为此后创建的表的增量数据格式默认值。

    ```shell
    obclient> ALTER SYSTEM SET default_delta_format = "encoding";
    ```

* 设置用户租户采用 `flat` 作为此后创建的表的增量数据格式默认值。

    ```shell
    obclient> ALTER SYSTEM SET default_delta_format = "flat";
    ```
