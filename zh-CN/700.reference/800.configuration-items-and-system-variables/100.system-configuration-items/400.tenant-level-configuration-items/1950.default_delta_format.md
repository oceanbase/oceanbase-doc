# default_delta_format

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`default_delta_format` 用于设置创建表时默认的增量数据转储格式。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | String |
| 默认值 | flat |
| 取值范围 | <ul><li>`flat`：和现有增量数据格式一致。</li><li>`encoding`：增量数据格式使用 encoding。</li></ul> |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

可以通过修改配置项 `default_delta_format` 来调整表的默认增量数据格式，无需建表时反复指定，从而控制增量格式是否使用 `encoding`。

* `flat` 格式为过去增量数据的格式，面向 OLTP 场景。
* 使用新的 `encoding` 格式可以提高 OLAP 场景的查询性能，降低增量数据的存储空间，但是可能会降低写入性能。

## 配置示例

* 设置用户租户采用 `encoding` 作为此后创建的表的增量数据格式默认值。

    ```shell
    obclient> ALTER SYSTEM SET default_delta_format = "encoding";
    ```

* 设置用户租户采用 `flat` 作为此后创建的表的增量数据格式默认值。

    ```shell
    obclient> ALTER SYSTEM SET default_delta_format = "flat";
    ```
