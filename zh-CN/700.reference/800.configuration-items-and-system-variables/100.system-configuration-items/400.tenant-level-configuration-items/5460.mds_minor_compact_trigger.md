# mds_minor_compact_trigger

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

`mds_minor_compact_trigger` 用于控制触发 MDS Minor Compaction 的 SSTable 数量。当 MDS SSTable 的总量大于或等于该阈值时，就会触发 MDS Minor Compaction，将所有 MDS SSTable 合成一个新的 MDS Minor SSTable。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

|      **属性**      |    **描述**    |
|------------------|--------------|
| 参数类型             | Int      |
| 默认值               | 2        |
| 取值范围             | [2,16] |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。     |

## 配置示例

* 用户租户设置本租户触发 MDS Minor Compaction 的 SSTable 数量为 2。

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2;
  ```

* 系统租户（`sys` 租户）设置租户 `mysql` 触发 MDS Minor Compaction 的 SSTable 数量为 2。

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2 TENANT = 'mysql';
  ```
