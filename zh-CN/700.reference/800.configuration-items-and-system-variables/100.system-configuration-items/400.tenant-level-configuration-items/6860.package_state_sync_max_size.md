# package_state_sync_max_size

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.5 BP1 版本引入。</p>
</main>

## 功能描述

`package_state_sync_max_size` 配置项用于控制控制单个 package state (包状态管理) 能序列化的长度。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 Oracle 模式。</p>
</main>

## 权限要求

* 查询配置项

    `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

    `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |    Int              |
| 默认值      |  8192  |
| 取值范围    |      [0, 16777216]          |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否 |

## 使用说明

* 该配置项是控制单个 package state 同步包变量的最大序列化长度，Proxy 部署场景下，OBServer 侧发现包变量同步所需序列化长度超过设定值时，会通过同步特殊值来使得 Proxy 将后续语句继续路由给原节点执行。

* 分布式计划场景，远端节点构造 package state 时，收到该特殊值时，会报错，该场景是 SQL 带 udf/trigger 且显式标记 `parallel_enable` 子句，如遇到这种场景，可以去掉 `parallel_enable` 子句，或者调大该配置项值。

## 配置示例

```shell
obclient> ALTER SYSTEM SET package_state_sync_max_size=8193
```
