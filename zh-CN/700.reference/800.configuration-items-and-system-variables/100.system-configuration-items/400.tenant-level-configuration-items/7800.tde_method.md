# tde_method

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V2.2.50 版本开始引入。</p>
</main>

## 功能描述

`tde_method` 用于设置透明表空间加密的方式。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

|        属性      |  描述  |
|------------------|-------|
| 参数类型             | String                          |
| 默认值               | none                           |
| 取值范围             | <ul><li>none：表示无法使用透明表空间加密 </li><li>internal：表示透明加密采用内部表的形式 </li><li>bkmi：表示透明加密采用外部 bkmi 的形式 </li><li>obcloud：表示透明加密采用 OceanBase Cloud KMS 的形式 </li></ul>  |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。   |

## 使用说明

以下功能均通过本参数进行开启与关闭：

* 列加密功能：启用该功能需要将 `tde_method` 参数设置为 `internal` 或 `obcloud`，功能说明详见 [列加密功能概述](../../../../600.manage/500.security-and-permissions/550.column-encryption/100.column-encryption-overview.md)。
* 通过手动调用函数进行 AES 加密/解密功能：启用该功能需要将 `tde_method` 参数设置为非 `none` 的值，函数加密功能和语法说明详见 [ENHANCED_AES_ENCRYPT](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md) 和 [ENHANCED_AES_DECRYPT](../../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md)。

## 配置示例

设置透明表空间加密的方式为 `internal`。

```shell
obclient> ALTER SYSTEM SET tde_method= 'internal';
```
