# default_table_store_format

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.5 BP1 版本开始引入。</p>
</main>

## 功能描述

`default_table_store_format` 配置选项允许您在创建新表时，将默认表组织模式设置为 `HEAP`（用于 OLAP 的无序数据存储）或 `INDEX`（用于 OLTP 的索引组织存储）。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型  | String |
| 默认值    | <ul><li>通用场景（即原 `ob_parameter_seed.ipp` 中的值）：`INDEX`。</li><li>HTAP 场景：`INDEX`。</li><li>简单 OLTP 场景（互联网应用）：`INDEX`。</li><li>复杂 OLTP 场景（传统应用）：`INDEX`。</li><li>KV 场景：`INDEX`。</li><li>简单 OLTP POC 场景：`INDEX`。</li><li>OLAP 场景：`HEAP`。</li></ul>|
| 取值范围   | <ul><li>`HEAP`</li><li>`INDEX`</li></ul>|
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否 |

## 使用说明

使用配置项 `default_table_organization` 可以灵活地控制默认创建表的表组织模式。该配置项可以设置为以下两个值：

* `HEAP`（堆表）：

  * 堆表表示表中的数据行没有特定的顺序。
  * 在 OLAP（联机分析处理）参数模板中，堆表是默认选项，适用于需要处理大量数据并进行复杂查询分析的场景。

* `INDEX`（索引表）：

  * 索引表表示表作为索引组织表创建，数据行会保存在定义在表的主键上的索引中。
  * 在 OLTP（联机事务处理）参数模板中，索引表是默认选项，适用于需要快速查询和频繁更新的事务处理场景。

通过设置 `default_table_organization`，您可以根据具体需求选择合适的表组织模式，从而优化系统性能并提高数据管理效率。

    ```sql
    SHOW PARAMETERS LIKE 'default_table_organization';
    ```

    返回结果如下：


    ```sql
    SHOW PARAMETERS LIKE 'default_table_organization';
    ```


