# compaction_high_thread_score


`compaction_high_thread_score` 用于设置高优先级 compaction 的工作线程数。

|      **属性**      |  **描述**  |
|------------------|----------|
| 参数类型             | 整型       |
| 默认值              | 0        |
| 取值范围             | \[0, 100\] |
| 是否重启 OBServer 节点生效 | 否        |
