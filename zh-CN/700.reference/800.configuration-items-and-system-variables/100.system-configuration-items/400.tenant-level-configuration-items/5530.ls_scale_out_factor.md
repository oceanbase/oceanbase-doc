# ls_scale_out_factor

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.2.5 版本，该配置项从 V4.2.5 BP1 版本开始引入。</p>
</main>

## 功能描述

`ls_scale_out_factor` 表示日志流的扩容系数，用于控制租户在每台服务节点上日志流的个数。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户都可以使用 `ALTER SYSTEM SET` 语句修改该配置项。

## 属性说明

| 属性          | 描述                |
|---------------|--------------------|
| 参数类型             | Int          |
| 默认值               | 1            |
| 取值范围             | \[1, 10\]    |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效	| 否，设置后立即生效。|

## 配置示例

* 系统租户下，设置租户 `mytest` 的扩容系数为 2。

  ```shell
  obclient> ALTER SYSTEM SET ls_scale_out_factor = 2 TENANT = mytest;
  ```

* 用户租户下，设置本租户的扩容系数为 2。

  ```shell
  obclient> ALTER SYSTEM SET ls_scale_out_factor = 2;
  ```
