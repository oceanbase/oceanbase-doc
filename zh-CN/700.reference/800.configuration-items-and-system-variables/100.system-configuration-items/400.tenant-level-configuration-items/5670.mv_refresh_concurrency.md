# mv_refresh_concurrency

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.4.2 版本，该配置项从 V4.4.2 BP2 版本开始引入。</p>
</main>

## 功能描述

`mv_refresh_concurrency` 用于控制同一租户内可同时运行的物化视图刷新任务的数量，即物化视图刷新任务的最大并发数。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型  | INT |
| 默认值    | 10 |
| 取值范围  | [1, +∞) |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 生效模式 | 动态生效。|

## 使用说明

根据实际系统负载调整，TP 密集场景建议降低该值，AP 分析场景可适当调高。

## 配置示例

将最大并发刷新任务数调整为 5。

```shell
obclient> ALTER SYSTEM SET mv_refresh_concurrency = 5;
```
