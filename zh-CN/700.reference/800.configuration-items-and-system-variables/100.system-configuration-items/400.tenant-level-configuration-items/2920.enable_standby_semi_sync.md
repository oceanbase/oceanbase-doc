# enable_standby_semi_sync

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该配置项从 V4.4.2 BP2 版本开始引入。</p>
</main>

## 功能描述

配置项 `enable_standby_semi_sync` 用于控制备库（备租户）是否开启半同步模式。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性**                   | **描述**                                          |
| -------------------------- | ------------------------------------------------- |
| 参数类型                   | Bool                                              |
| 默认值                     | False                                               |
| 取值范围                   | <ul><li>`True`：开启备库的半同步模式</li> <li>`False`：关闭备库的半同步模式</li></ul> |
| 是否可修改                 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。          |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。                              |

## 使用说明

* 仅当备库的保护模式为 `MAXIMUM PERFORMANCE`（最大性能模式）时，可以修改该配置项的值。

* 建议在业务低峰期操作，等待一段时间（约 10s）后再恢复正常流量。

* 其他保护模式（非 `MAXIMUM PERFORMANCE`）下，如果希望备库进入半同步模式，可以在备库处于 `MAXIMUM PERFORMANCE`（最大性能）模式时，先将该配置项 `enable_standby_semi_sync` 的值设置为 `True`后，再切换为 `MAXIMUM AVAILABILITY`（最大可用）或 `MAXIMUM PROTECTION`（最大保护）模式。切换成功后，该配置项将变成只读。

## 配置示例

开启备库的半同步模式。

```shell
obclient> ALTER SYSTEM SET enable_standby_semi_sync = True;
```
