# enable_window_compaction

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`enable_window_compaction` 用于指定当前租户是否使用窗口合并。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型             | Bool |
| 默认值               | False |
| 取值范围             |<ul><li>`True`：每日合并执行的是窗口合并，且合并开始时间以系统变量 [time_zone](../../200.system-variable/300.global-system-variable/13300.time_zone-global.md) 指定时区的时间一致。</li><li>`False`：每日合并执行的是租户合并，且合并开始时间以 Root Service 所在机器的本地时间一致。 </li></ul>|
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。  |

## 使用说明

窗口合并由配置项 `enable_window_compaction` 和窗口合并任务 `DAILY_MAINTENANCE_WINDOW` 共同控制，其取值与每日合并行为之间的关系如下：
| enable_window_compaction  | DAILY_MAINTENANCE_WINDOW                                           | 每日合并行为   |
|---------------------------|--------------------------------------------------------------------|---------------|
| False                     | False（`CALL DBMS_SCHEDULER.DISABLE('DAILY_MAINTENANCE_WINDOW');`） |  触发每日租户合并      |
| False                     | True（`CALL DBMS_SCHEDULER.ENABLE('DAILY_MAINTENANCE_WINDOW');`）   |  触发每日租户合并      （
| True                      | False （`CALL DBMS_SCHEDULER.DISABLE('DAILY_MAINTENANCE_WINDOW');`）|  不发任何合并，即既不触发窗口合并，也不触发每日租户合并      |
| True                      | True（`CALL DBMS_SCHEDULER.ENABLE('DAILY_MAINTENANCE_WINDOW');`）   |  触发窗口合并 |

## 配置示例

开启窗口合并功能。

```shell
obclient> ALTER SYSTEM SET enable_window_compaction = True;
```
