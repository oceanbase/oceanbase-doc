# px_node_policy

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.5 BP1 版本引入。</p>
</main>

`px_node_policy` 用于支持 PX 计算节点资源的独立伸缩，表示计算节点的候选池。

* 值为 `DATA` 时，PX 计算节点可以选择当前 SQL 涉及的所有数据节点。
* 值为 `ZONE` 时，PX 计算节点可以选择当前 SQL 涉及的 zone 中属于该租户的所有节点。
* 值为 `CLUSTER` 时，PX 计算节点可以选择集群中当前租户涉及的所有节点。

|属性|描述|
|-----|----|
|参数类型|String|
|取值范围|DATA, ZONE, CLUSTER|
|默认值|DATA|
|是否重启 OBServer 节点生效|否，立即生效|

## 使用示例

```shell
obclient> ALTER SYSTEM SET px_node_policy = "DATA" tenant = 'mysql';
```
