# attach_shared_sstable_thread_score

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.4.0 版本开始引入。</p>
</main>

## 功能描述

`attach_shared_sstable_thread_score` 用于配置租户可用来执行共享存储模式下计算节点共享数据引用的线程数。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该配置项仅适用于共享存储（Shared-Storage，SS）模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户都可以使用 `ALTER SYSTEM SET` 语句修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型   | Int |
| 默认值     | 0，表示默认线程数为 6 |
| 取值范围   | [0, 100] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。   |

## 使用说明

通过 `inc_sstable_upload_thread_score` 配置同时可用来执行引用共享 SSTable 到本地任务的线程数。

## 配置示例

用户租户下，设置用于处理共享存储增量数据引用到本地任务的线程数为 10。

```shell
obclient> ALTER SYSTEM SET attach_shared_sstable_thread_score = 10;
```
