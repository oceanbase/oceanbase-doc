# document_ai_file_max_size

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`document_ai_file_max_size` 用于限制 `LOAD_FILE` 函数一次处理的文件最大大小。该函数主要用于 OceanBase AI RAG 中的外部文本提取。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型  | Int |
| 默认值    | 100 MB |
| 取值范围  |[0, 500MB] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

通过执行 `ALTER SYSTEM SET` 修改配置项，`document_ai_file_max_size` 的值会被调整。

## 配置示例

执行如下命令修改 `document_ai_file_max_size` 的值为 `10 MB`。

```shell
obclient> ALTER SYSTEM SET document_ai_file_max_size = 10MB;
```
