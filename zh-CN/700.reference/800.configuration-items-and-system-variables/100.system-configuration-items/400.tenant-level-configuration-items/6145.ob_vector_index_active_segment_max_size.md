# ob_vector_index_active_segment_max_size

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`ob_vector_index_active_segment_max_size` 用于控制单个分区的向量索引 Active Segment 最大内存占用量（单位：字节）。当新写入的向量数据占用的内存超过该阈值时，系统会强制触发冻结（freeze）及持久化操作，将内存中的数据落盘。

<main id="notice" type='notice'>
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和 MySQL 用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和 MySQL 用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Capacity |
| 默认值 | 256M |
| 取值范围 | [0, +∞)，单位为字节，支持 `K`、`M`、`G` 等容量单位 |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 为保证索引写入性能，内存阈值不宜过大；阈值过小则可能导致冻结操作过于频繁，影响整体查询性能。
* 重启数据库时，系统需要恢复内存数据，阈值过大将增加重启恢复时间。

## 配置示例

设置单个分区的向量索引 Active Segment 最大内存占用量为 512M。

```shell
obclient> ALTER SYSTEM SET ob_vector_index_active_segment_max_size = '512M';
```

查看当前配置。

```shell
obclient> SHOW PARAMETERS LIKE 'ob_vector_index_active_segment_max_size';
```
