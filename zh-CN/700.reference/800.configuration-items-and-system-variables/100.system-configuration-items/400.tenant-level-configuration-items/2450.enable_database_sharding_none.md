# enable_database_sharding_none

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

`enable_database_sharding_none` 配置项用于控制创建 DataBase 时用户表是否开启自动聚合（自动绑定表组）的开关。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

|      **属性**    |      **描述**      |
|------------------|--------------------|
| 参数类型          | Bool                |
| 默认值            | False  |
| 取值范围          | <ul><li>True：开启 </li><li>False：不开启</li></ul>|
| 是否可修改        | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

* 配置项 `enable_database_sharding_none` 的值由 `False` 设置为 `True`：

  * 新创建 DataBase 时，默认绑定一个 `SHARDING = 'NONE'` 的表组，该 DataBase 下所有用户表绑定在同一个日志流上。
  * 不影响已创建的 DataBase。

* 配置项 `enable_database_sharding_none` 的值由 `True` 设置为 `False`：

  * 不会对已有的 DataBase 进行变更。

## 配置示例

设置创建 DataBase 时用户表开启自动聚合。

```shell
obclient> ALTER SYSTEM SET enable_database_sharding_none = True;
```
