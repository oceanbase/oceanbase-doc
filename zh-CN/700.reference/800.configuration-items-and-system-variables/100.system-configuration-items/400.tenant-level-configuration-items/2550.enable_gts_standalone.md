# enable_gts_standalone

<main id="notice" type='explain'>
<h4>说明</h4>
<ul><li>对于 V4.4.x 版本，该配置项从 V4.4.2 版本开始引入。</li>
<li>对于 V4.2.5 版本，该配置项从 V4.2.5 BP5 版本开始引入。</li></ul>
</main>

## 功能描述

`enable_gts_standalone` 用于设置是否开启租户 GTS 服务独占一组 Unit 的功能。开启 GTS 独占后，可以提升 GTS 服务的性能和稳定性。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| 属性                | 描述      |
|---------------------|-----------|
| 参数类型             | Bool |
| 默认值               | False |
| 取值范围             |<ul><li>`True`：开启 GTS 独占 </li><li>`False`：不开启 GTS 独占 </li></ul>|
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否 |

## 使用说明

租户的 GTS 服务由系统日志流所在的 Unit 承担。当 GTS 服务与用户日志流在相同的 Unit 时，有一定风险会受到用户日志流的访问压力以及运维操作的影响。为了防止 GTS 服务影响租户的整体可用性，OceanBase 数据库提供了 GTS 服务独占一组 Unit 的功能。

开启 GTS 独占功能后，负载均衡会自动选择一组 Unit 分配给系统日志流（优先为日志流运维命令中指定的 unit_list 或者当前所在的 unit_list）。之后，用户日志流会自动分布在其他 Unit 上。

开启 GTS 独占功能后，需要确保租户的所有 Zone 的 `UNIT_NUM` 数均大于或等于 2，并且配置项 [enable_rebalance](2800.enable_rebalance.md) 处于开启状态，GTS 独占才能生效。

## 配置示例

开启 GTS 独占功能。

```shell
obclient> ALTER SYSTEM SET enable_gts_standalone = 'True';
```
