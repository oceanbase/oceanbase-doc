# kv_ttl_delete_max_ops

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`kv_ttl_delete_max_ops` 用于设置 TTL 任务删除的最大操作数。通过该配置项，可以对 TTL 任务进行限速，避免因删除操作过多导致性能下降。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

|      **属性**    |   **描述**   |
|------------------|--------------|
| 参数类型             | Int       |
| 默认值               | 0，表示不限速。   |
| 取值范围             | [0, +∞)，表示限制 TTL 任务每秒执行的最大删除操作数。 |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。  |

## 配置示例

设置 TTL 任务每秒执行的最大删除操作数为 `1000`。

```sql
ALTER SYSTEM SET kv_ttl_delete_max_ops = 1000;
```
