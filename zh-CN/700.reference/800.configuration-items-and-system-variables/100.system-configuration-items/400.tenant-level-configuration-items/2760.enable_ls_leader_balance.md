# enable_ls_leader_balance

<main id="notice" type='explain'>
<h4>说明</h4>
<ul><li>对于 V4.4.x 版本，该配置项从 V4.4.2 版本开始引入。</li>
<li>对于 V4.2.5 版本，该配置项从 V4.2.5 BP6 版本开始引入。</li></ul>
</main>

## 功能描述

`enable_ls_leader_balance` 用于控制是否开启日志流 Leader 的自动均衡。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户都可以使用 `ALTER SYSTEM SET` 语句修改该配置项。

## 属性说明

|  **属性** | **描述** |
|-----------|----------|
| 参数类型   | Bool |
| 默认值     | True |
| 取值范围   | <ul><li>`True`：开启日志流 Leader 的自动均衡</li><li>`False`：关闭日志流 Leader 的自动均衡</li></ul>|
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

* 在 [enable_rebalance](2800.enable_rebalance.md) 开启（值为 `True`）时，`enable_ls_leader_balance` 可以单独控制关闭日志流 Leader 的自动均衡。

* 当该配置项关闭时（值为 `False`），日志流级别不会发生自动切主，但分区级别仍可能由于不同 Leader 的日志流之间进行 Transfer 而发生切主。

## 配置示例

* 用户租户关闭本租户日志流 Leader 的自动均衡。

  ```shell
  obclient> ALTER SYSTEM SET enable_ls_leader_balance = False;
  ```

* 系统租户指定关闭 `mysql` 租户日志流 Leader 的自动均衡。

  ```shell
  obclient> ALTER SYSTEM SET enable_ls_leader_balance = False TENANT = 'mysql';
  ```
