# enable_adaptive_plan_cache

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.5 BP1 版本开始引入。</p>
</main>

## 功能描述

`enable_adaptive_plan_cache` 用于控制开启、关闭 Plan Cache 自适应的能力。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该配置项适用于 OceanBase 数据库 MySQL 模式和 Oracle 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。/`sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |    BOOL              |
| 默认值      |  False  |
| 取值范围    |      <li>True：开启</li><li>False：关闭</li>          |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否 |

## 使用说明

开启 plan cache 自适应功能后，会自动根据 SQL 特征自动开启/关闭计划缓存。

## 配置示例

执行如下命令开启 Plan Cache 自适应的能力：

```shell
obclient> ALTER SYSTEM SET enable_adaptive_plan_cache = true;
```
