# partition_balance_schedule_interval

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.2.0 版本开始引入。</p>
</main>

## 功能描述

`partition_balance_schedule_interval` 用于分区均衡调度周期。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型       |  Time |
| 默认值         | 2h<main id="notice" type='explain'><h4>说明</h4><ul><li>在 V4.2.1 版本中，从 V4.2.1 BP9 及之后版本开始新建的用户租户，其默认值为 0。</li> <li>在 V4.2.x 其他版本中，从 V4.2.4 及之后版本开始新建的用户租户，其默认值为 0。</li></ul></main>  |
| 取值范围       | [0s,+∞) <main id="notice" type='explain'><h4>说明</h4><p>取值为 0s 时表示关闭后台自动分区均衡。</p></main>   |
| 是否可修改     |  是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

* 配置项 `partition_balance_schedule_interval` 的值大于配置项 [balancer_idle_time](600.balancer_idle_time.md) 的值时，才能启用分区均衡。

* **在 V4.2.x 版本中（除 V4.2.1 版本），分区均衡的行为有所不同：**

  * V4.2.4 之前版本

   自动分区均衡间隔由该配置项控制。

  * V4.2.4 及之后版本

    * 从 V4.2.4 版本开始，支持定时分区均衡任务，不再建议通过配置项 `partition_balance_schedule_interval` 来控制分区均衡。对于 V4.2.4 版本新建的用户租户，配置项 `partition_balance_schedule_interval` 的值默认为 0，定时分区均衡任务默认开启，分区均衡的触发依赖定时任务以及用户手动触发。

    * 对于从其他版本升级至 V4.2.4 版本的用户租户，配置项 `partition_balance_schedule_interval` 的值与升级前保持一致，定时分区均衡任务默认关闭。

## 配置示例

* 用户租户下仅修改本租户的配置项信息：

  ```shell
  obclient [test]> ALTER SYSTEM SET partition_balance_schedule_interval = '1h';
  ```

* 系统租户下可修改任意租户的配置项信息：

  ```shell
  obclient [test]> ALTER SYSTEM SET partition_balance_schedule_interval = '1h' tenant = all;
  obclient [test]> ALTER SYSTEM SET partition_balance_schedule_interval = '1h' tenant = 'tenant_name';
  ```
