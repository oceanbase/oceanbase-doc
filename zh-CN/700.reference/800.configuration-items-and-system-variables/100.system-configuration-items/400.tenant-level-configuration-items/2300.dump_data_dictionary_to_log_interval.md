# dump_data_dictionary_to_log_interval

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.1.0 版本开始引入。</p>
</main>

## 功能描述

`dump_data_dictionary_to_log_interval` 用于控制租户数据字典持久化的周期。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

<main id="notice" type='explain'>
  <h4>注意</h4>
  <p>从低版本升级到 V4.2.5 BP1 版本，该配置项值会维持低版本的值不变。</p>
</main>

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Time |
| 默认值   | 0，默认单位为秒<main id="notice" type='explain'><h4>说明</h4><p>对于 V4.2.x 版本，从 V4.2.5 BP1 版本开始默认值由 24H 调整为 0。值为 0 时，将不会根据该配置项调度生成数据字典；如需停止生产数据字典，需要配合 `DBMS_DATA_DICT.DISABLE_DUMP()` 命令。</p></main> |
| 取值范围 | (0s, +∞)<main id="notice" type='explain'><h4>说明</h4><p>对于 V4.2.x 版本，从 V4.2.5 BP1 版本开始取值范围由 (0s, +∞) 调整为 [0s, +∞) 。</p></main><br/>|
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBSever 节点生效 | 否 |

## 配置示例

设置租户数据字典持久化的周期为 24H。

```shell
obclient> ALTER SYSTEM SET dump_data_dictionary_to_log_interval = 24H;
```
