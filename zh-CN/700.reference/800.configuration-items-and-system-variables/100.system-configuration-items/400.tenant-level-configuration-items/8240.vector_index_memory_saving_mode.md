# vector_index_memory_saving_mode

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>对于 V4.5.x 版本，该配置项从 V4.5.0 版本开始引入。</p>
  <p></p>
</main>

## 功能描述

`vector_index_memory_saving_mode` 用于控制是否开启向量索引的内存节省模式。开启此模式可以显著降低分区表向量索引重建（rebuild）过程中的内存消耗。在内存资源有限的环境中，该模式允许以更少的内存成功完成索引重建，避免因内存不足导致的重建失败。

根据向量索引原理，重建通常涉及增量段与基线段的数据处理；开启该模式后，系统会在分区级构建过程中尽早释放阶段性内存，以降低峰值内存占用。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型             | Bool         |
| 默认值               | true       |
| 取值范围             | true/false |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 配置示例

设置该配置项为 `true`，降低分区表向量索引重建过程中需要的内存。

```sql
ALTER SYSTEM SET vector_index_memory_saving_mode = true;
```
