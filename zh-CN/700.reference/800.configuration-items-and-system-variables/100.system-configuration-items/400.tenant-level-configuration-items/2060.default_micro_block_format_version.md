# default_micro_block_format_version

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.4.1 版本开始引入。</p>
</main>

## 功能描述

`default_micro_block_format_version` 用于指定创建表时默认的微块存储格式版本号。

## 权限要求

* 查询配置项

    `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句查询该配置项。

* 修改配置项

    `sys` 租户和所有用户租户均可以使用 `ALTER SYSTEM SET` 语句修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型  | Int|
| 默认值    | 1 |
| 取值范围  |[1,+∞) <ul>其中：<ul><li> 1：表示和现有微块存储格式一致。</li><li>2：表示启用新的 Flat 行存储格式。</li><li>其他取值：会提示非法报错。</li></ul>|
| 是否可修改| 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

可以通过修改该配置项来调整表的默认微块存储格式版本号，从而控制是否启用新的 Flat 行存储格式。

## 配置示例

用户租户执行如下命令，采用微块存储格式版本号 2 作为此后创建的表的微块存储格式版本号默认值：

```shell
obclient> ALTER SYSTEM SET default_micro_block_format_version = 2;
```
