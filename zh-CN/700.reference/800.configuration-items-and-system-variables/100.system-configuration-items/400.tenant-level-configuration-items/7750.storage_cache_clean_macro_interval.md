# storage_cache_clean_macro_interval

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

配置项 `storage_cache_clean_macro_interval` 用于控制共享存储（Shared-Storage，SS）模式下宏块级别的热点宏块缓存清理任务的执行频率。

在 SS 模式下，系统会将热点数据缓存在本地存储中以提升访问性能。随着时间推移，部分缓存的宏块可能不再是热点数据，需要定期清理以释放缓存空间。本配置项用于控制该清理任务的调度时间间隔。

<main id="notice" >
<h4>功能适用性</h4>
<p>该配置项仅适用于共享存储（Shared-Storage，SS）模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    | Time              |
| 默认值      | 24h  |
| 取值范围    | [0s, +∞)                |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 配置示例

设置存储缓存清理宏块任务的调度时间间隔为 12 小时。

```shell
obclient> ALTER SYSTEM SET storage_cache_clean_macro_interval = '12h';
```
