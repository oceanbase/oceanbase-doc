# px_target_low_watermark

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`px_target_low_watermark` 用于设置并行线程数的低水位线百分比阈值，超过该阈值时开始对新调度 DFO 的并行度进行降级控制，避免 CPU 资源耗尽。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型 | Int |
| 默认值 | 60 |
| 取值范围 | [0, 100] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

配置项 `px_target_low_watermark` 的值应该满足以下关系：

`px_target_low_watermark` <= [px_target_high_watermark](6860.px_target_high_watermark.md) <= [px_target_workers_per_cpu](6880.px_target_workers_per_cpu.md)

## 配置示例

设置并行线程数的低水位线百分比阈值为 5。

```shell
obclient> ALTER SYSTEM SET px_target_low_watermark = 5;
```
