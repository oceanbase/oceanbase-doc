# sql_func_extension_mode

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`sql_func_extension_mode` 用于控制是否启用命名风格与 MySQL 不一致的主流兼容模式函数。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型 | Varchar |
| 默认值 | 空 |
| 取值范围 | <ul><li>空：不开启任何兼容模式函数扩展。</li><li>ClickHouse：开启 ClickHouse 兼容模式函数。</li></ul> |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

OceanBase 数据库为每个兼容模式特有的函数维护一个名单，名单中的函数默认不透出。当设置配置项 `sql_func_extension_mode` 为对应模式时，相应名单中的函数将全部透出，用户可以在 SQL 语句中调用这些函数。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>MySQL 模式下默认透出的函数可见性不受此配置项影响。</p>
</main>

### 兼容模式叠加

兼容模式支持叠加使用，叠加使用时可同时开启多种兼容模式的函数扩展。当需要同时开启多种兼容模式的函数扩展时，可使用逗号分隔多个模式名称：

```shell
ALTER SYSTEM SET sql_func_extension_mode = "mode1, mode2";
```

## 配置示例

开启 ClickHouse 兼容模式函数扩展。

```shell
obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
```
