# schema_history_expire_time

<main id="notice" type='explain'>
<h4>说明</h4>
<ul><li>由于内部改造优化，对于 V4.4.2 版本，该配置项从 V4.4.2 BP1 版本开始，由集群级变更为租户级。</li>
<li>该配置项从 V1.4 版本开始引入。</li></ul>
</main>

## 功能描述

`schema_history_expire_time` 可用于设置 Schema 多版本历史数据的保留时间，也可用于设置延迟删除的租户的保留时间。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

|      **属性**      |  **描述**  |
|------------------|----------|
| 参数类型             | Time     |
| 默认值               | 7d，d 表示天<main id="notice" type='explain'><h4>说明</h4><p>该配置项从 V4.0.0 版本开始默认值由 30d 调整为 7d。</p></main>    |
| 取值范围             | [1m, 30d]<main id="notice" type='explain'><h4>说明</h4><p>该配置项从 V4.0.0 版本开始取值范围由 [1m, 365d] 调整为 [1m, 30d]。</p></main> |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。      |

## 配置示例

设置 Schema 多版本历史数据的保留时间为 7d。

```shell
obclient> ALTER SYSTEM SET schema_history_expire_time = '7d';
```

当该配置项的值设置为 7d 时，表示最新 7 天内产生的 Schema 多版本历史数据需要被保留，过期且不再使用的 Schema 多版本历史数据会被回收。
