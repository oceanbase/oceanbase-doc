# default_skip_index_level

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><ul><li>对于 V4.6.x 版本，该配置项从 V4.6.0 版本开始引入。</li><li>对于 V4.3.5 版本，该配置项从 V4.3.5 BP5 版本开始引入。</li><li>对于 V4.4.x 版本，该配置项从 V4.4.2 版本开始引入。</li></ul></p>
</main>

## 功能描述

`default_skip_index_level` 用于设置租户中创建表时 `skip_index_level` 的默认值。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型  | INT |
| 默认值    | 0 |
| 取值范围   | <ul><li>0：表示表的列存基线都生成 Skip Index 聚合信息，行存基线根据 Schema 生成 Skip Index 聚合信息，增量 SSTable 不生成 Skip Index 聚合信息。</li><li>1：表示在 0 的基础上，表的增量 SSTable 会根据基线的行为生成 Skip Index 聚合信息。</li></ul>|
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

配置项 `default_skip_index_level` 只会影响用户租户创建主表的默认格式，`meta` 租户和 `sys` 租户不影响。并且只在建表语句中没有显示指定 `skip_index_level` 的情况下生效，若用户显式指定了表的 `skip_index_level`，最终表的 `skip_index_level` 按用户指定格式进行解析。

该配置项可以设置为以下值：

* 1：若建表语句中没有指定 skip_index_level，用户租户建表的 skip_index_level = 1。
* 0：若建表语句中没有指定 skip_index_level，用户租户建表的 skip_index_level = 0。

修改该配置项的值时，不影响已经创建的表。

## 配置示例

* MySQL 模式：设置用户租户创建表的 `skip_index_level` 默认为 1。

    ```shell
    obclient> ALTER SYSTEM SET default_skip_index_level = 1;
    ```

* Oracle 模式：设置用户租户创建表的 `skip_index_level` 默认为 1。

    ```shell
    obclient> ALTER SYSTEM SET "default_skip_index_level" = 1;
    ```
