# zone_deploy_mode

<main id="notice" type='explain'>
<h4>说明</h4>
<ul><li>对于 V4.4.x 版本，该配置项从 V4.4.2 版本开始引入。</li>
<li>对于 V4.2.5 版本，该配置项从 V4.2.5 BP5 版本开始引入。</li></ul>
</main>

## 功能描述

`zone_deploy_mode` 用于设置租户在各 Zone 的分布模式。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| 属性                | 描述      |
|---------------------|-----------|
| 参数类型             | String |
| 默认值               | homo |
| 取值范围             |<ul><li>`homo`：同构 Zone 模式 </li><li>`hetero`：异构 Zone 模式</li></ul>|
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否 |

## 使用说明

对于新创建的租户或升级上来的已有租户，默认情况下均为同构 Zone 模式。同构 Zone 模式下，各 Zone 的 Unit 数量必须相同，日志流在各个 Zone 下对称分布，日志流与 Unit Group 进行绑定：

* 一个 Unit Group 由每个 Zone 的一个 Unit 构成，每个 Unit 只属于一个 Unit Group。

* 一个日志流只属于一个 Unit Group，各日志流副本分布在该 Unit Group 下的各个 Unit 上。

* 对于 Unit 的扩缩容，只能以 Unit Group 为粒度，每个 Zone 的 UNIT_NUM 必须同步调整，保持一致。

如果需要启用异构 Zone 模式，则需要将配置项 `zone_deploy_mode` 的值修改为 `hetero`。修改后，配置项 `zone_deploy_mode` 的值将无法再修改回 `homo`。

相较于同构 Zone 模式，异构 Zone 模式在使用上主要有以下区别：

* 日志流分布不再有 Unit Group 的概念，各 Zone 的日志流副本不再限制在对称的 Unit 上。

* 租户下各资源池的 `UNIT_NUM` 可以不同，但是最多只能有两种不同的 `UNIT_NUM`。

* 支持单独修改租户下某一个资源池的 `UNIT_NUM`，以实现资源池粒度的扩缩容。

* 使用 `ALTER RESOURCE TENANT` 语句通过减少 `UNIT_NUM` 进行缩容时，不支持指定 `UNIT_GROUP` 进行删除。

* 使用日志流运维命令 `ALTER SYSTEM CREATE LS` 和 `ALTER SYSTEM MODIFY LS` 时，不支持指定 `UNIT_GROUP` 参数。 

## 配置示例

设置租户各 Zone 的分布模式为异构 Zone 模式。

```shell
obclient> ALTER SYSTEM SET zone_deploy_mode = 'hetero';
```
