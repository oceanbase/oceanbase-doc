# zone_disk_balance_tolerance_percentage

<main id="notice" type='explain'>
<h4>说明</h4>
<p>对于 V4.4.2 版本，该配置项从 V4.4.2 BP1 版本开始引入。</p>
</main>

## 功能描述

配置项 `zone_disk_balance_tolerance_percentage` 用于控制 Zone 间表组磁盘均衡算法对不均衡的容忍程度。当磁盘占用最大的 Zone 和最小的 Zone 之间的差值超过最大 Zone 磁盘使用量乘以该百分比时，才会触发 Zone 间的磁盘均衡。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |    Int              |
| 默认值      |  10  |
| 取值范围    | [1, 100]               |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

负载均衡模块会自动尝试交换不同 Zone 上的 `SCOPE=ZONE` 表组，使各 Zone 的 `SCOPE=ZONE` 表组的磁盘总量尽量均衡。为了控制均衡的触发频率，只有当 Zone 间 `SCOPE=ZONE` 表组磁盘总量差异达到以下两个条件时，才会尝试进行交换：

1.表组的磁盘总量差异超过最大的 Zone 的总量乘以 `zone_disk_balance_tolerance_percentage/100`。

2. 最大的 Zone 的磁盘总量超过 `50 GB * 日志流组个数`。

一般情况下，配置项 `zone_disk_balance_tolerance_percentage` 的值保持默认值 **10** 即可。

* 当 `SCOPE = 'ZONE'` 表组的磁盘使用情况变化较大，导致 Zone 间磁盘均衡发起频率偏高，希望降低均衡频率时，可以适当增大该值。

* 当需要完全关闭 Zone 间磁盘均衡时，可以将该值设置为 **100**。

## 配置示例

设置 Zone 间磁盘均衡的容忍百分比为 20%。

```shell
obclient> ALTER SYSTEM SET zone_disk_balance_tolerance_percentage = 20;
```
