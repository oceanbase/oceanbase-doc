# ob_vector_index_merge_trigger_percentage

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`ob_vector_index_merge_trigger_percentage` 用于控制增量段（Incremental Segment）向量内存占整个分区向量索引内存的最大比例。当增量向量数据占比超过该值时，系统会自动触发与基线段（Baseline Segment）的段合并（Segment Merge）操作，将增量数据合并到基线中。

<main id="notice" type='notice'>
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和 MySQL 用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和 MySQL 用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Int |
| 默认值 | 20 |
| 取值范围 | [0, 100)，单位为百分比 |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 默认配置（20%）：大部分场景用默认值即可。
* 提高配置：降低增量段与基线段的合并频率，以规避在写入速度过大时合并频率过高、消耗过多资源。
* 降低配置：除特殊测试场景外，不建议调小阈值。
* 设置为 `0`：当前相当于使用默认值。

## 配置示例

设置增量段（Incremental Segment）占整个分区索引的最大比例为 30%。

```sql
ALTER SYSTEM SET ob_vector_index_merge_trigger_percentage = 30;
```

查看当前配置。

```sql
SHOW PARAMETERS LIKE 'ob_vector_index_merge_trigger_percentage';
```
