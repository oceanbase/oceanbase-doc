# ob_vector_index_merge_trigger_percentage

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`ob_vector_index_merge_trigger_percentage` 用于控制 Incremental Segment 向量内存占用占整个分区索引向量的最大比例（单位为百分比）。当增量向量数据占比超过该值时，系统会自动触发与 Baseline Segment 的合并操作，将增量数据合并到基线中。

<main id="notice" type='notice'>
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和 MySQL 用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和 MySQL 用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Int |
| 默认值 | 20 |
| 取值范围 | [1, 100]，单位为百分比 |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

该配置项与 `ob_vector_index_active_segment_max_size` 的区别如下：

| 配置项 | 控制范围 | 触发操作 |
|--------|----------|----------|
| ob_vector_index_active_segment_max_size | 新写入的向量数据（绝对值） | 冻结并落盘 |
| ob_vector_index_merge_trigger_percentage | 增量向量占整个分区的比例 | 与已有索引合并 |

## 配置示例

设置 Incremental Segment 占整个分区索引的最大比例为 30%。

```shell
obclient> ALTER SYSTEM SET ob_vector_index_merge_trigger_percentage = 30;
```

查看当前配置。

```shell
obclient> SHOW PARAMETERS LIKE 'ob_vector_index_merge_trigger_percentage';
```
