# enable_ps_meta_response_optimize

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.4.2 BP3 版本开始引入。</p>
</main>

## 功能描述

`enable_ps_meta_response_optimize` 用于控制 PS（Prepared Statement）协议下 observer 与客户端之间是否开启 meta 响应优化。该配置项开启后，当 observer 与具备 meta cache 能力的 ob-jdbc 交互时，只在 PS 语句第一次执行时返回结果集的 meta 信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>创建租户时，系统默认将该配置项设置为 True，即新建租户默认开启该功能。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

# 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型             | Bool |
| 默认值               | False |
| 取值范围             |<ul><li>True：开启 </li><li> False：不开启 </li></ul>|
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 配置示例

* 开启 PS 协议 meta 响应优化。

    ```shell
    obclient> ALTER SYSTEM SET enable_ps_meta_response_optimize = TRUE;
    ```

* 关闭 PS 协议 meta 响应优化。

    ```shell
    obclient> ALTER SYSTEM SET enable_ps_meta_response_optimize = FALSE;
    ```
