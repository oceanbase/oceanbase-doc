# sys_bkgd_io_low_percentage

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本实现了租户的 IO 隔离，该配置项已不适用，从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`sys_bkgd_io_low_percentage` 用于设置系统后台 IO 最少占用的百分比。

## 属性说明

|      **属性**                |   **描述**   |
|------------------------------|------------|
| 参数类型                      | Int         |
| 默认值                        | 0，表示系统根据实际环境自动配置比例。          |
| 取值范围                      | \[0, 100\] |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 配置示例

设置系统后台 IO 最少占用 40%。

```shell
obclient> ALTER SYSTEM SET sys_bkgd_io_low_percentage = 40;
```
