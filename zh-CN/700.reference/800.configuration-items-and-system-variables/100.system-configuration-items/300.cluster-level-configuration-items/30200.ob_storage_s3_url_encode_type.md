# ob_storage_s3_url_encode_type

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.2.1 BP9 版本开始引入。</p>
</main>

## 功能描述

`ob_storage_s3_url_encode_type` 用于设置 S3 发送请求时的 URL 编码方式是否兼容 Rfc3986 标准。

## 属性说明

| **属性** | **描述**    |
|-----------|------------|
| 参数类型 | String |
| 默认值   | default |
| 取值范围 | compliantRfc3986Encoding/default |
| 是否重启 OBServer 节点生效 | 否 |

## 使用说明

该配置项适用于部分兼容 S3 协议但可能不支持 AWS S3 SDK 默认的 URL 编码方式的对象存储，相关操作请参见[日志归档的准备工作](../../../../600.manage/600.backup-and-recovery/300.log-archive/200.preparation-before-log-archive.md)。

## 配置示例

设置 AWS S3 发送请求时的 URL 编码方式兼容 Rfc3986 标准。

```shell
obclient> ALTER SYSTEM SET ob_storage_s3_url_encode_type='compliantRfc3986Encoding';
```
