# ob_storage_s3_url_encode_type

`ob_storage_s3_url_encode_type` 用于设置 S3 发送请求时的 URL 编码方式是否兼容 Rfc3986 标准。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.2.1 BP9 版本开始引入。</p>
</main>

| **属性** | **描述**    |
|-----------|------------|
| 参数类型 | String |
| 默认值   | default |
| 取值范围 | compliantRfc3986Encoding/default |
| 是否重启 OBServer 节点生效 | 否 |

该配置项用于通过 S3 协议访问对象存储，具体请参见[日志归档的准备工作](../../../../600.manage/600.backup-and-recovery/300.log-archive/200.preparation-before-log-archive.md)。

**示例**

```sql
ALTER SYSTEM SET ob_storage_s3_url_encode_type='compliantRfc3986Encoding';
```
