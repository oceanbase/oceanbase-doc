# enable_election_group

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本对系统架构进行了优化调整，不再有选举组的概念，该配置项从 V4.0.0 版本开始弃用。</p>
</main>

## 功能描述

`enable_election_group` 用于设置是否打开选举组策略。

## 属性说明

|        属性                  |                                                   描述                                                   |
|------------------------------|--------------------------------------------------------------------------------------------------------|
| 参数类型                      | Bool                                                                                                   |
| 默认值                        | True                                                                                                   |
| 取值范围                      | </li><li> True 或 1   </li><li> False 或 0   |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 配置示例

开启选举组策略。

```shell
obclient> ALTER SYSTEM SET enable_election_group = True;
```

或者

```shell
obclient> ALTER SYSTEM SET enable_election_group = 1;
```
