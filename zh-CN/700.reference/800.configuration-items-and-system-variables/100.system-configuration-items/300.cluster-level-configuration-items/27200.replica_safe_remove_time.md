# replica_safe_remove_time

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本对副本管理功能进行了优化调整，不再需要控制无效副本信息的删除时间了，该配置项从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`replica_safe_remove_time` 用于设置已删除副本可以被清理的安全保留时间。

## 属性说明

|      **属性**                |  **描述**   |
|------------------------------|-----------|
| 参数类型                      | Time     |
| 默认值                        | 2h        |
| 取值范围                      | \[1m, +∞)|
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

修改配置项值时，支持数字后的单位为 us（微秒）、ms（毫秒）、s（秒）、m（分钟）或 h（小时）。

## 配置示例

设置已删除副本可以被清理的安全保留时间为 2 小时。超过指定时间后，该副本将会被清理。

```sql
obclient> ALTER SYSTEM SET replica_safe_remove_time = '2h';
```

或者

```shell
obclient> ALTER SYSTEM SET replica_safe_remove_time = '7200s';
```
