# external_table_disk_cache_max_percentage

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p> 该配置项从 V4.4.1 版本开始引入。 </p>
</main>

## 功能描述

`external_table_disk_cache_max_percentage` 用于设置 SN 模式下外表磁盘缓存空间占 [datafile_size](4700.datafile_size.md) 的最大比例。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该配置项只有在无共享（Shared-Nothing，SN）模式才有效。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型  | INT |
| 默认值    | 50 |
| 取值范围  | [0, 95] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。|

## 使用说明

当配置项 `external_table_disk_cache_max_percentage` 的值被调小时，多余的磁盘缓存会在后台淘汰，直到满足要求。该配置项的值设置为 0 时，表示外表数据不使用磁盘缓存。

## 配置示例

设置外表磁盘缓存空间占 `datafile_size` 的最大比例为 60%。

```shell
obclient> ALTER SYSTEM SET external_table_disk_cache_max_percentage = 60;
```
