# plugins_load

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.5 BP1 版本开始引入。</p>
</main>

## 功能描述

`plugins_load` 用于配置 Observer 启动时需要加载的插件。该配置项支持指定多个动态链接库插件及其加载策略，插件仅在 Observer 进程初始化时加载，不支持动态加载。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    | String |
| 默认值      | ""（空字符串） |
| 取值范围    | 格式为 `libname1.so:option1,libname2.so:option2,...`，其中：<ul><li>`libname.so`：动态链接库文件名</li><li>`option`：加载选项，可选值为<ul><li>`on`：加载插件，加载失败不影响进程启动（默认值）。</li><li>`off`：不加载该插件。</li><li>`force`：加载插件，加载失败会导致进程启动失败。</li></ul></li></ul> |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 是，修改后需要重启 OBServer 节点生效。 |

## 使用说明

OceanBase 提供的插件能力可以帮助您更容易地扩展系统功能。您可以在部署集群以及在运行过程中调整集群下次启动需要加载的插件。

### 插件加载流程

1. 将动态链接库文件（如 `libsoname.so`）放置在每个 Observer 进程的 `plugin_dir` 目录下
2. 通过启动参数或配置项指定需要加载的插件
3. 重启整个集群或依次重启各个 OBServer 节点

### 配置格式说明

配置值采用特定格式，支持同时指定多个插件及其加载策略：

```shell
libsoname1.so:on,libsoname2.so:off,libsoname3.so:force
```

各字段含义：

* **libsoname1.so:on**：加载 `libsoname1.so` 插件，加载失败不影响进程启动
* **libsoname2.so:off**：不加载 `libsoname2.so` 插件
* **libsoname3.so:force**：加载 `libsoname3.so` 插件，加载失败会导致进程启动失败

### 配置方式

**方式一：通过命令行参数（集群首次部署时）**

在启动 observer 进程时指定 `-L` 参数：

```shell
observer -Llibsoname1.so:on,libsoname2.so:off,libsoname3.so:force
```

**方式二：通过系统配置项（运行期间调整）**

在集群运行期间修改配置项，指定下次启动时加载的插件：

```shell
obclient> ALTER SYSTEM SET plugins_load='libsoname1.so:on,libsoname2.so:off,libsoname3.so:force';
```

配置修改后需要重启 OBServer 节点才能生效。

### 插件类型说明

* **动态库插件**：通过 `dlopen` 方式加载到进程中的独立动态链接库（`.so` 文件）
* **静态插件**：与 observer 可执行程序编译在一起的插件

当前 OceanBase 主要提供全文索引分词插件接口，用户可以基于此接口开发自定义插件或适配第三方分词库。

### 注意事项

* 插件无法动态加载，配置修改后必须重启进程才能生效
* 仅支持以动态库为单位加载，不支持加载单个动态库中的部分插件
* 一个动态库中的插件通常作为一套协同工作，不建议拆分加载
* 插件文件必须放置在 `plugin_dir` 目录下，否则无法加载

## 配置示例

设置 Observer 下次启动时加载 `libob_tokenizer.so` 插件，加载失败不影响进程启动：

```shell
obclient> ALTER SYSTEM SET plugins_load='libob_tokenizer.so:on';
```
