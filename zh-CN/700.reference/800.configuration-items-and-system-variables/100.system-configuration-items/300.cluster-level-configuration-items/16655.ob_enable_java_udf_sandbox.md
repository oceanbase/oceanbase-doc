# ob_enable_java_udf_sandbox

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.4.2 BP3 版本开始引入。</p>
</main>

## 功能描述

`ob_enable_java_udf_sandbox` 用于控制 Java UDF 的执行模式：

* 设置为 `TRUE` 时，Java UDF 运行在独立的沙箱子进程中，JVM 与 Observer 主进程隔离运行，降低 Java UDF 执行对数据库主进程的影响。
* 设置为 `FALSE` 时，Java UDF 通过 JNI 内嵌在 Observer 进程中执行。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |    Bool              |
| 默认值      |  FALSE  |
| 取值范围    |  TRUE/FALSE              |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 该配置项需要与 [ob_enable_java_udf](../400.tenant-level-configuration-items/5860.ob_enable_java_udf.md) 和 [ob_enable_java_env](16630.ob_enable_java_env.md) 配合使用。在开启 `ob_enable_java_udf` 和 `ob_enable_java_env` 之后，可根据需要决定是否开启 `ob_enable_java_udf_sandbox` 以启用沙箱隔离。
* 公有云部署场景建议开启该配置项，以增强 Java UDF 执行的安全性和稳定性，避免 JVM 异常影响 Observer 主进程。

## 配置示例

* 开启 Java UDF 沙箱模式

  ```sql
  obclient> ALTER SYSTEM SET ob_enable_java_udf_sandbox = TRUE;
  ```

* 关闭 Java UDF 沙箱模式

  ```sql
  obclient> ALTER SYSTEM SET ob_enable_java_udf_sandbox = FALSE;
  ```
