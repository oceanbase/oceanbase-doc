# utl_file_open_max

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.2.5 BP2 Hotfix1 版本开始引入。</p>
</main>

## 功能描述

`utl_file_open_max` 用于控制在 Oracle 模式下单节点可同时打开的 `UTL_FILE` 文件最大数量。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 Oracle 模式。</p>
</main>

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |      Int            |
| 默认值      |  50  |
| 取值范围    |        [50, 600]       |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否 |

## 配置示例

执行如下命令将 Oracle 模式下单节点可同时打开的 `UTL_FILE` 文件最大数量设置为60。

```shell
obclient> ALTER SYSTEM SET utl_file_open_max=60;
Query OK, 0 rows affected (0.023 sec)
```
