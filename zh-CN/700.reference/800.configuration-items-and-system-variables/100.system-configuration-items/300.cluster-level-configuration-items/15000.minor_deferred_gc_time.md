# minor_deferred_gc_time

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于该配置项从 V2.2.3x 版本开始已不再建议用户使用，该配置项从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`minor_deferred_gc_time` 用于设置合并之后，SSTable 延迟回收的时间间隔。

## 属性说明

|      **属性**             |   **描述**    |
|---------------------------|-------------|
| 参数类型                   | Time        |
| 默认值                     | 0s          |
| 取值范围                   | \[0s, 24h] |
| 是否可修改                 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。          |

## 使用说明

修改配置项值时，支持数字后的单位为 us（微秒）、ms（毫秒）、s（秒）或 m（分钟）。

## 配置示例

设置合并之后，SSTable 延迟回收的时间间隔为 10 分钟。

```shell
obclient> ALTER SYSTEM SET minor_deferred_gc_time = '10m';
```

或者

```shell
obclient> ALTER SYSTEM SET minor_deferred_gc_time = '600s';
```
