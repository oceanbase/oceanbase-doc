# plan_cache_evict_interval

## 功能描述

`plan_cache_evict_interval` 用于设置执行计划缓存的淘汰时间间隔。

## 属性说明

|      **属性**      |  **描述**   |
|------------------|-----------|
| 参数类型             | Time      |
| 默认值              | 5s <main id="notice" type='explain'><h4>说明</h4><p>该配置项从 V4.2.0 版本开始默认值由 1s 调整为 5s。</p></main>      |
| 取值范围             | \[0s, +∞) |
| 是否重启 OBServer 节点生效 | 否         |
