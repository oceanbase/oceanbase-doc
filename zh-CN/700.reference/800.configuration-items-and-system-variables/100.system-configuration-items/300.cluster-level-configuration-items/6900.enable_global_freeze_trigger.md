# enable_global_freeze_trigger

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本调整为租户级冻结，该配置项已不适用，从 V4.0.0 版本开始删除。  </p>
</main>

## 功能描述

`enable_global_freeze_trigger` 用于设置是否开启自动触发全局冻结。

## 属性说明

|      **属性**                |                                                 **描述**        |
|------------------------------|-----------------------------------------------------------------|
| 参数类型                      | Bool                                                         |
| 默认值                        | False                                                           |
| 取值范围                      | </li><li> True 或 1  </li><li> False 或 0    |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

该配置项保持默认值即可，不推荐修改。

## 配置示例

开启自动触发全局冻结开关。

```shell
obclient> ALTER SYSTEM SET enable_global_freeze_trigger = False;
```

或者

```shell
obclient> ALTER SYSTEM SET enable_global_freeze_trigger = 0;
```
