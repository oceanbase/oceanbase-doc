# enable_logservice

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p> 该配置项从 V4.4.0 版本开始引入。 </p>
</main>

## 功能描述

`enable_logservice` 用于控制日志服务模式的开关。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  该配置项需通过 OBServer 节点的 `-o` 启动参数配置，在集群 RS 节点首次启动时被指定，且生效后不可动态修改。用户租户无权限修改此配置项。

## 属性说明

| **属性** | **描述** |
| -------- | ------- |
| 参数类型           | Bool                              |
| 默认值             | False                              |
| 取值范围            | <ul><li>True：开启 </li><li>False：关闭 </li></ul>     |
| 是否可修改          | 否，第一次启动时指定，不支持修改。|
| 是否重启 OBServer 节点生效 | 否，仅支持只读。 |

## 使用说明

在集群扩容时，新增节点的 `enable_logservice` 配置必须与集群现有节点保持一致，否则可能导致日志服务状态异常或根服务选举失败。即整个集群中所有节点的 `enable_logservice` 配置必须始终保持全局一致性。

## 配置示例

设置以日志服务模式（logservice）启动 OBServer 节点，在命令行的 `-o` 参数中指定配置项 `enable_logservice` 的值为 True。

```shell
./observer -P 42904 -p 42905
-z zone1
-n ob22.xxxx.qqq.xx.xx.xx.xx
-c 1
-o memory_limit=400G,enable_logservice=True
```
