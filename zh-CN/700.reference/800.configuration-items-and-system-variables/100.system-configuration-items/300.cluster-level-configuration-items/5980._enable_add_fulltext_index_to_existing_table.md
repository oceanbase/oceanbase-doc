# _enable_add_fulltext_index_to_existing_table

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.3.5 版本开始引入。</p>
</main>

`_enable_add_fulltext_index_to_existing_table` 用于管理是否开启后建全文索引，包含 `ALTER TABLE` 以及 `CREATE FULLTEXT INDEX` 两种后建 SQL 语句。

|      **属性**      |  **描述**   |
|------------------|-----------|
| 参数类型                     | Boolean    |
| 默认值              | false         |
| 取值范围             | true/false |
| 是否重启 OBServer 节点生效 | 否         |

## 配置示例

设置后建全文索引为开启状态。

```shell
obclient> ALTER SYSTEM SET _enable_add_fulltext_index_to_existing_table = true;
```
