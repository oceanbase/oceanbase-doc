# zone_merge_timeout

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本不再支持按 Zone 控制合并，该配置项从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`zone_merge_timeout` 用于设置单个 zone 的合并超时时间。

## 属性说明

|      **属性**                |  **描述**   |
|------------------------------|-----------|
| 参数类型                      | Time      |
| 默认值                        | 3h，表示 3 小时       |
| 取值范围                      | \[1s, +∞) |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

修改配置项值时，支持数字后的单位为 us（微秒）、ms（毫秒）、s（秒）、m（分钟）或 h（小时）。

## 配置示例

设置单个 zone 的合并超时时间为 3 小时。

```shell
obclient> ALTER SYSTEM SET zone_merge_timeout = '3h';
```

或者

```shell
obclient> ALTER SYSTEM SET zone_merge_timeout = '180m';
```
