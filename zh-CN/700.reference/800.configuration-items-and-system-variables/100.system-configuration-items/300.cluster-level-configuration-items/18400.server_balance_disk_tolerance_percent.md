# server_balance_disk_tolerance_percent

`server_balance_disk_tolerance_percent` 用于设置在节点间资源单元（Unit）均衡策略中，对磁盘不均衡程度的容忍度。只有当某节点的磁盘水位超出同 Zone 节点平均磁盘水位且超出幅度达到该容忍值时，该节点才会参与基于磁盘的资源单元均衡。

|      **属性**      |   **描述**   |
|------------------|------------|
| 参数类型             | 整型         |
| 默认值              | 1          |
| 取值范围             | \[1, 100\] |
| 是否重启 OBServer 节点生效 | 否          |
