# resource_soft_limit

<main id="notice" type='explain'>
<h4>说明</h4>
<ul><li>由于 V4.x 版本对存储架构进行了升级，该配置项所描述的语义已不再适用，从 V4.0.0 版本开始删除。</li>
<li>在 V4.x 版本中，仅由租户级配置项 <code>enable_rebalance</code> 来控制 Unit 迁移的开关。有关配置项 <code>enable_rebalance</code> 的详细说明，参见 <a href="../400.tenant-level-configuration-items/6700.enable_rebalance.md">enable_rebalance</a>。</li></ul>
</main>

## 功能描述

`resource_soft_limit` 用于设置是否开启 Unit 均衡。

## 属性说明

|      **属性**               |    **描述**    |
|-----------------------------|--------------|
| 参数类型                     | Int           |
| 默认值                       | 50           |
| 取值范围                     | \[1, 10000\] |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

`resource_soft_limit` 的值与配置项 `enable_rebalance` 的取值有关。当 `enable_rebalance` 为 `False` 时，资源单元均衡和分区副本均衡均关闭；仅当 `enable_rebalance` 为 True 时，是否开启 Unit 均衡需要参考 `resource_soft_limit` 的值，即如果 `resource_soft_limit` 配置项的取值小于 `100`， 则表示 Unit 均衡开关开启；如果 `resource_soft_limit` 配置项的取值大于等于 `100`，表示 Unit 均衡开关关闭。

## 配置示例

开启 Unit 均衡。

```shell
obclient> ALTER SYSTEM SET enable_rebalance = true;
```

并且

```shell
obclient> ALTER SYSTEM SET resource_soft_limit = 50;
```
