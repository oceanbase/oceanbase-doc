# cluster_id

<main id="notice" type='notice'>
<h4>注意</h4>
<p>该配置项仅支持在部署集群时设置，集群生效后，无法修改。</p>
</main>

## 功能描述

`cluster_id` 用于设置本 OceanBase 集群的 ID。

## 属性说明


|      **属性**      |      **描述**       |
|------------------|-------------------|
| 参数类型             | Int                |
| 默认值              | 0                 |
| 取值范围             | \[1, 4294901759\] |
| 是否可修改                | 否，不支持通过 `ALTER SYSTEM SET` 语句修改。  |
| 是否重启 OBServer 节点生效 | 否                 |
