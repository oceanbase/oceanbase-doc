# enable_smooth_leader_switch

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本不再支持分区 Leader 切换，该配置项从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`enable_smooth_leader_switch` 是平滑切主特性（主动切换分区 Leader）的开关。

## 属性说明

|      **属性**      |                                                 **描述**                                |
|------------------------------|-------------------------------------------------------------------------------|
| 参数类型                      | Bool                                                                      |
| 默认值                        | True                                                                          |
| 取值范围                      | </li><li> True 或 1  </li><li> False 或 0   |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 配置示例

开启分区平滑切主功能。

```shell
obclient> ALTER SYSTEM SET enable_smooth_leader_switch = True;
```

或者

```shell
obclient> ALTER SYSTEM SET enable_smooth_leader_switch = 1;
```
