# rpc_port

<main id="notice" type='notice'>
<h4>注意</h4>
<p>该配置项仅支持在部署集群时设置，集群生效后，无法再修改。</p>
</main>

## 功能描述

`rpc_port` 用于设置远程访问的协议端口号。

## 属性说明

|      **属性**      |     **描述**      |
|------------------|-----------------|
| 参数类型             | Int              |
| 默认值              | 2882  <main id="notice" type='explain'><h4>说明</h4><p>从 V3.2.4 版本开始，默认值由 2500 调整为 2882。</p></main>          |
| 取值范围             | \[1025, 65535\] |
| 是否可修改                | 否，不支持通过 `ALTER SYSTEM SET` 语句修改。  |
| 是否重启 OBServer 节点生效 | 否               |
