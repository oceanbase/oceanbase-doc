# system_protected_sys_variables

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`system_protected_sys_variables` 用于配置被锁定的系统变量列表。在该列表中的 Global 系统变量，不允许普通用户对其进行修改。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型 | String |
| 默认值 | 空字符串（""），表示不锁定任何系统变量。 |
| 取值范围 | 最大为 4KB |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 对于不希望普通用户修改的 GLOBAL 系统变量，可以将系统变量名称添加到该配置项中。添加后，普通用户（包括具有 Super 权限的用户）将无法修改这些系统变量，只有 SYS（Oracle 模式）或 ROOT（MySQL 模式）用户可以修改。
* 配置项取值说明：
  
  配置项间以英文逗号分隔，系统变量大小写不敏感，逗号前后不允许有空格，不允许用英文逗号开头或结尾。格式为 `"para1"` 或 `"para1,...,paran"`

  **允许配置示例：**
  * `"param1"`
  * `"param1,param2"`
  * `"param1,param2,param3"`

  **不允许配置示例：**
  * `","`
  * `"param1,"`
  * `"param1, param2"`（逗号后有空格）
  * `"param1,param2,"`

## 配置示例

锁定 `ob_enable_sql_audit` 系统变量，禁止普通用户修改。

```shell
obclient> ALTER SYSTEM SET system_protected_sys_variables = "ob_enable_sql_audit";
```

锁定多个系统变量 `ob_enable_sql_audit` 和 `ob_sql_audit_percentage`。

```shell
obclient> ALTER SYSTEM SET system_protected_sys_variables = "ob_enable_sql_audit,ob_sql_audit_percentage";
```
