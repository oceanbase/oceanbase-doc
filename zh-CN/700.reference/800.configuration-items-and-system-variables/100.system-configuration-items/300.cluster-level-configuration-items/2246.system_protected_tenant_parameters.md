# system_protected_tenant_parameters

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.6.0 版本开始引入。</p>
</main>

## 功能描述

`system_protected_tenant_parameters` 用于配置被锁定的租户级配置项列表。在该列表中的租户级配置项，不允许普通用户对其进行修改。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性** | **描述** |
|----------|----------|
| 参数类型 | String |
| 默认值 | 空字符串（""），表示不锁定任何配置项。 |
| 取值范围 | 最大 4KB |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 对于不希望普通用户修改的租户级配置项，可以将配置项名称添加到该配置项中。添加后，普通用户（包括具有 Super 权限的用户）将无法修改这些配置项，只有 SYS（Oracle 模式）或 ROOT（MySQL 模式）用户可以修改。

* 配置项取值说明：
  
  配置项间以英文逗号分隔，配置项大小写不敏感，逗号前后不允许有空格，不允许用英文逗号开头或结尾。格式为 `"para1"` 或 `"para1,...,paran"`

  **允许配置示例：**

  * `"param1"`
  * `"param1,param2"`
  * `"param1,param2,param3"`

  **不允许配置示例：**

  * `","`
  * `"param1,"`
  * `"param1, param2"`（逗号后有空格）
  * `"param1,param2,"`

## 配置示例

将 `backup_dest` 配置项添加到保护列表中：

```shell
obclient> ALTER SYSTEM SET system_protected_tenant_parameters = "backup_dest";
```

同时保护多个租户级配置项：

```shell
obclient> ALTER SYSTEM SET system_protected_tenant_parameters = "backup_dest,sts_credential";
```

清空保护列表（允许所有普通用户修改租户级配置项）：

```shell
obclient> ALTER SYSTEM SET system_protected_tenant_parameters = "";
```
