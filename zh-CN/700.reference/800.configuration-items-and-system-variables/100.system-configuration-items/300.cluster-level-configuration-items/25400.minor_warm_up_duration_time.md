# minor_warm_up_duration_time

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于该配置项从 V2.2.3x 版本开始已不再建议用户使用，该配置项从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`minor_warm_up_duration_time` 用于设置小合并（Minor Merge）产生新转储文件的预热时间。

## 属性说明

|      **属性**                |   **描述**    |
|------------------------------|-------------|
| 参数类型                      | Time       |
| 默认值                        | 30s         |
| 取值范围                      | \[0s, 60m\] |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

* 当配置项 `minor_warm_up_duration_time` 的值为 `0s` 时，表示不对 Minor Merge 产生的新转储文件进行预热。

* 修改配置项值时，支持数字后的单位为 us（微秒）、ms（毫秒）、s（秒）、m（分钟）或 h（小时）。

## 配置示例

设置 Minor Merge 产生的新转储文件的预热时间为 30 秒。

```shell
obclient> ALTER SYSTEM SET minor_warm_up_duration_time = '30s';
```

或者

```shell
obclient> ALTER SYSTEM SET minor_warm_up_duration_time = '30000ms';
```
