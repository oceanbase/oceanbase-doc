# balancer_timeout_check_interval

<main id="notice" type='explain'>
<h4>说明</h4>
<p>由于 V4.x 版本对存储架构进行了升级，该配置项不再适用，从 V4.0.0 版本开始删除。</p>
</main>

## 功能描述

`balancer_timeout_check_interval` 用于设置检查负载均衡等后台任务超时的时间间隔。

## 属性说明

|      **属性**                |   **描述**   |
|------------------------------|------------|
| 参数类型                      | Time      |
| 默认值                        | 1m，表示 1 分钟 |
| 取值范围                      | \[1s, +∞)  |
| 是否可修改                    | 是，支持通过 `ALTER SYSTEM SET` 语句修改。         |
| 是否重启 OBServer 节点生效    | 否，设置后立即生效。     |

## 使用说明

修改配置项值时，支持数字后的单位为 us（微秒）、ms（毫秒）、s（秒）、m（分钟）或 h（小时）。

## 配置示例

设置检查负载均衡等后台任务超时的时间间隔为 1 分钟。

```shell
obclient> ALTER SYSTEM SET balancer_timeout_check_interval = '1m';
```

或者

```shell
obclient> ALTER SYSTEM SET balancer_timeout_check_interval = '60s';
```
