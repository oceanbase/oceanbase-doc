# syslog_sync_size_threshold

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.4.2 版本开始引入。</p>
</main>

## 功能描述

`syslog_sync_size_threshold` 用于控制触发 syslog 磁盘同步的累积数据量阈值。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型             | Capacity |
| 默认值               | 0M，表示禁用此同步机制。 |
| 取值范围             | [0M, +∞) |
| 是否可修改           | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBSever 节点生效 | 否，设置后立即生效。 |

## 使用说明

当累计写入 syslog 的数据量超过某个阈值时，主动触发刷盘，提前分散 I/O 压力，避免积攒到后续集中刷盘。可以实现更平滑的磁盘写入负载，避免瞬间高 I/O 对业务的影响。

## 配置示例

设置触发 syslog 磁盘同步的累积数据量阈值为 128K。

```shell
obclient> ALTER SYSTEM SET syslog_sync_size_threshold = '128K';
```
