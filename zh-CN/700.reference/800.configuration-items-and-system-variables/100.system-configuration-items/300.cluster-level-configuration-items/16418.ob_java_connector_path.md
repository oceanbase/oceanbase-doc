# ob_java_connector_path

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.5 版本开始引入。</p>
</main>

## 功能描述

`ob_java_connector_path` 用于设置 JNI（Java Native Interface）为访问和执行外部表（如 ODPS 外表）所需的 Connector Jar 包的根路径。该路径将与 `ob_java_home` 配置项指定的路径拼接，共同构成 JVM 的类加载路径。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该配置项仅适用于 OceanBase 数据库 MySQL 模式。</p>
</main>

## 权限要求

* 查询配置项
  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。
* 修改配置项
  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性**  | **描述** |
|---|---|
| 参数类型 | String |
| 默认值 | `""` (空字符串) |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 该配置项是启用 OceanBase 数据库 Java 环境以支持 ODPS 外表等 JNI 功能的一部分。通常需要与 `ob_enable_java_env`、`ob_java_home` 和 `ob_java_opts` 配置项配合使用。
* **初始化耗时**：首次初始化 Java 环境可能需要较长时间，可能导致首次查询相关外部表时超时。建议适当调整查询超时时间，后续查询将不会再次初始化。
* **部署一致性**：在多机部署环境下，需要确保所有 OBServer 节点上配置的路径指向相同且存在的目录，以保证功能正常。
* **路径要求**：配置的路径应是存放 Connector Jar 包的根目录。例如，解压 `jni_packages_new.tar` 得到的 `jni_package` 目录即可作为 `ob_java_connector_path` 的值。
* **环境依赖**：使用此功能前，需要在服务器上正确安装 Java 环境（如 OpenJDK 8）并配置好必要的环境变量（如 `LD_LIBRARY_PATH` 指向 `libhdfs.so` 所在的目录）。

## 配置示例

设置 Java Connector 的根路径为 `/home/admin/jni_packages/`。

```shell
obclient> ALTER SYSTEM SET ob_java_connector_path = '/home/admin/jni_packages/';
```
