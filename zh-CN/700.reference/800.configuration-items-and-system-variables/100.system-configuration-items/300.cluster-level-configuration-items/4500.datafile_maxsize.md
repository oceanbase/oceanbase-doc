# datafile_maxsize

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V3.1.5 版本开始引入。</p>
</main>

## 功能描述

* 无共享（Shared-Nothing，SN）模式下，配置项 `datafile_maxsize` 用于设置磁盘文件自动扩容的空间最大值。

* 共享模式（Shared-Storage，SN）模式下，配置项 `datafile_maxsize` 的值无意义，不支持修改，修改会报错。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | Capacity |
| 默认值 | 0 |
| 取值范围 | [0M, +∞) |
| 是否重启 OBServer 节点生效 | 否 |

## 配置示例

SN 模式下，设置磁盘文件自动扩容的空间最大值为 10G。

```shell
obclient> ALTER SYSTEM SET datafile_maxsize = '10G';
```
