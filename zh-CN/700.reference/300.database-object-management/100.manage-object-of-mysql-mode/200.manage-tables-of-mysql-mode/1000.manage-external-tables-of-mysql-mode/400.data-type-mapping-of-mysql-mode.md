# 数据类型映射

数据类型映射确保在数据从 OceanBase 数据库导出为 Parquet 或 ORC 格式时，能够准确地将原始数据与目标格式的数据类型进行对应。在 OceanBase 数据库 V4.3.5 版本中，通过明确的映射表，将 MySQL 和 Oracle 的各类数据类型与 Parquet 或 ORC 支持的数据类型进行关联，从而确保数据在导出过程中不丢失、不过载，并保持其语义不变。
