# 删除 Catalog

当一个 Catalog 不再使用时，可以使用 `DROP CATALOG external_catalog_name;` 语句将其删除。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>与 MySQL 模式不同，Oracle 模式下的 <code>DROP CATALOG</code> 语句不支持 <code>IF EXISTS</code> 子句。如果要删除的 Catalog 不存在，则会报错，错误码为 <code>-11080</code>。</p>
</main>

删除 Catalog 后，其他用户在该 Catalog 上的 `USE CATALOG` 对象权限会一并回收。

## 权限要求

删除 External Catalog，需要当前用户拥有 `CREATE CATALOG` 系统权限。

有关 OceanBase 数据库权限的详细介绍，参见 [Oracle 模式下的权限分类](../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/300.permission-of-oracle-mode/000.permission-classification-of-oracle-mode.md)。

## 示例

```sql
obclient> CREATE EXTERNAL CATALOG tmp_catalog PROPERTIES = (TYPE = 'JDBC', URL = 'jdbc:sqlserver://10.10.10.1:1433');

obclient> DROP CATALOG tmp_catalog;
```
