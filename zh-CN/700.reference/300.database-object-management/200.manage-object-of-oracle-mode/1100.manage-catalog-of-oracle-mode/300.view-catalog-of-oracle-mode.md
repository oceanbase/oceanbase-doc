# 查看 Catalog

创建 Catalog 后，可以通过 SQL 语句查看 Catalog 的相关信息。

## 查看创建 Catalog 的语句

可以使用 `SHOW CREATE CATALOG external_catalog_name;` 查看 Catalog 的创建语句。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>出于安全考虑，创建语句中的敏感属性（例如 ODPS 的 <code>ACCESSID</code>、<code>ACCESSKEY</code>、<code>STSTOKEN</code>，JDBC 的 <code>URL</code> 等）会脱敏显示。</p>
</main>

**示例如下：**

```sql
obclient> SHOW CREATE CATALOG test_jdbc_catalog;
```

## 查看当前用户可见的 Catalog

可以使用 `SHOW CATALOGS;` 查看当前用户可见的 Catalog。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>当前用户没有 <code>USE CATALOG</code> 权限的 Catalog 不会出现在结果中。</p>
</main>

**示例如下：**

```sql
obclient> SHOW CATALOGS;
```

## 查看当前所在的 Catalog

可以使用 `CURRENT_CATALOG()` 或 `CATALOG()` 函数查看当前会话所在的 Catalog。

**示例如下：**

```sql
obclient> SELECT CURRENT_CATALOG() FROM dual;
```

## 查看 Catalog 中的数据

在 Catalog 中，可以和数据库内的表一样执行查询操作，也可以跨 Catalog 进行联合查询。

**示例如下：**

* 通过三段式命名（Catalog 名.Schema 名.表名）直接访问外部表。

  ```text
  SELECT * FROM test_jdbc_catalog.dbo.table_name;
  ```

* 跨 Catalog 联合查询。

  ```text
  SELECT * FROM internal.system.test_t1, test_odps_catalog.project_name.test_t1;
  ```

## Catalog 切换

可以使用 `SET CATALOG catalog_name;` 语句切换 Catalog。详细信息参见 [SET CATALOG](../../../500.sql-reference/100.sql-syntax/300.common-tenant-of-oracle-mode/900.sql-statement-of-oracle-mode/100.ddl-of-oracle-mode/4900.set-catalog-of-oracle-mode.md)。

**示例如下：**

* 切换成系统内部 Catalog。

  ```sql
  obclient> SET CATALOG internal;
  ```

* 切换成外部 Catalog。

  ```sql
  obclient> SET CATALOG test_jdbc_catalog;
  ```
