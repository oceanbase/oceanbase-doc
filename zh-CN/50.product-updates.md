# What's New

OceanBase 数据库 V4.6.0 版本是一次面向现代化数据处理的重要版本升级。在这个版本中，OceanBase 数据库围绕 AI 检索、HTAP 分析性能、兼容与生态集成、安全可靠性与运维可观测性进行了显著增强。

## 关键特性说明

### AI 检索与向量能力增强

* **原生 SQL 混合搜索能力上线**

  新增 `HYBRID_SEARCH` SQL 路径，支持向量、全文与标量条件的混合检索，并支持 RRF/WRRF 等融合策略。可以以更统一的 SQL 方式接入混合检索场景，降低使用门槛。

* **全文检索与混合搜索执行增强**

  新增 Match Phrase（含 `slop`），扩展全文索引类型并优化全文索引查询与构建性能；重构混合搜索执行框架，提升混搜场景下全文相关路径的效率。在知识库与问答检索等对短语匹配与检索性能有更高要求的场景中，可获得更好的体验。

* **搜索索引（Search Index）**

  新增 Search Index，面向混搜场景下 JSON 等复杂类型的高效检索需求，支持按路径与类型配置索引范围，提升相关查询效率。

* **向量数据库能力增强**

  HNSW 增量场景优化、IVF 支持无主键表，新增召回率评估能力和稀疏向量相关优化。向量检索从“可用”进一步走向“可观测、可优化、可运营”。

* **Document AI 能力补齐**

  新增文档读取、解析和切分能力，可与向量检索和混合搜索组合使用。文档类数据从解析到检索的链路更完整，便于构建 RAG 类应用。

### HTAP 与分析性能优化

* **列存副本自动路由与统一接入增强**

  支持列存副本与 F 副本统一入口，并可按策略自动分流 AP 查询。在 TP/AP 混合负载场景下，可以降低接入改造成本并提高流量治理灵活性。

* **列存副本支持强一致读**

  在列存副本访问路径上补充强一致读能力。对一致性要求更高的分析查询获得更明确的能力选项。

* **并行执行与增量查询能力增强**

  增强 PX 排队与任务重均衡机制，支持增量 Encoding/Skip Index 优化。大查询在高负载和数据倾斜场景下的性能更稳定、可预测。

### SQL/PL 执行效率与开发体验增强

* **查询优化器与执行器持续优化**

  在硬解析、谓词推导、下推、窗口计算等路径进行多项增强。 复杂 SQL 的计划生成与执行效率进一步提升，有助于降低资源消耗。

* **PL 引擎能力与性能增强**

  涵盖动态 SQL 参数化、FORALL 扩展、事务异步提交、流式游标优化等。存储过程与批处理类业务在高并发场景下具备更好的吞吐与响应表现。

### 兼容性与生态集成增强

* **MySQL/Oracle 兼容能力增强**

  支持 MySQL Session 临时表，并优化 Oracle 模式全局临时表性能。迁移与双模使用场景的适配成本进一步降低。

* **物化视图能力增强**

  增量刷新场景扩展、嵌套物化视图级联刷新、MLOG 自动化管理与改写能力增强。数据仓库与报表场景中的预计算维护更加灵活，运维复杂度降低。

* **湖仓生态集成能力增强**

  增强 Iceberg（含 V3、Time Travel）与 REST Catalog 相关能力，完善 Parquet/ORC 复杂类型支持。与主流数据湖生态对接更顺畅，数据分析链路更完整。

### 安全、可靠性与运维可观测性增强

* **数据安全与认证能力增强**

  新增列级敏感数据保护能力，支持 `caching_sha2_password` 认证。在不改变主要业务访问方式的前提下，获得更细粒度的数据保护能力。

* **备份可验证能力增强**

  新增备份校验能力，支持在恢复前检查备份和归档数据可用性。降低恢复阶段才暴露问题的风险，提升容灾流程确定性。

* **可观测与运维诊断能力增强**

  增强 SQLSTAT、ASH 与 Plan Cache 等相关能力，细化等待事件并完善诊断路径。故障定位与性能诊断效率提升，日常运维更可控。

* **窗口合并（Window Compaction）**

  新增窗口合并能力，支持在指定维护窗口内按需调度合并，并可结合资源配置控制合并对业务的影响，便于大规模环境下的存储与合并治理。

### KV 与同步链路增强

* **OBKV 能力增强**

  支持弱读与就近机房读，完善 TTL 任务与 HBase 监控及热点查询优化能力。在时序、宽表和热点访问场景下，可获得更好的延迟与可观测性。

* **OBCDC 能力增强**

  支持表级恢复后增量同步，并增强虚拟生成列同步兼容能力。数据同步链路在复杂变更场景下更稳定，降低下游兼容成本。
